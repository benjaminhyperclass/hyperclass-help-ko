# 이메일 통계

하이퍼클래스에서 이메일 통계를 보는 위치와 각 지표의 뜻을 설명해요. 통계를 보면 캠페인 성과를 확인하고 수신자의 반응을 높이는 데 도움이 돼요.

## 이메일 통계란?

이메일 통계는 수신자가 이메일에 어떻게 반응하는지 보여 줘요. 캠페인, 워크플로우, 일괄 작업으로 보낸 이메일을 모두 확인할 수 있어요. 이 수치를 바탕으로 이메일 전달률을 높이고, 콘텐츠 전략을 다듬고, 발신자 평판을 관리할 수 있어요.

## 이메일 통계로 할 수 있는 일

- 열림, 클릭, 반송, 스팸 지표를 실시간으로 확인해요.
- 캠페인, 워크플로우, 일괄 이메일 단위로 통계를 나눠 봐요.
- 반응이 좋은 제목과 템플릿을 찾아요.
- 연락처별 결과를 확인해서 문제 원인을 자세히 살펴봐요.
- 통계를 기준으로 스마트 리스트를 나누고 자동화에 활용해요.
- 구독취소나 전달 실패 같은 문제를 빠르게 찾아요.

## 이메일 마케팅 통계

한 번 보내는 이메일과 예약 발송 이메일의 성과를 볼 수 있어요. **마케팅 > 이메일**로 이동하세요.

### 참여 요약

이 그래프에서 이메일의 전달, 반응, 전환 상황을 한눈에 확인할 수 있어요.

![참여 요약 그래프](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047443663/original/uDOyxXUTTVdB9hcUinOrd8chxwugCgQjng.png?1748532751)

### 성과 분석

전달률, 반송률, 구독취소, 스팸 신고 같은 주요 지표가 시간에 따라 어떻게 변하는지 볼 수 있어요. 드롭다운으로 지표를 바꿔 가며 선택한 기간 동안 캠페인 유형별 성과를 비교해 보세요.

![성과 분석 그래프](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047443908/original/pCFujPNHT4GYiMwU43HXeFAqHz_c0uh8Pg.png?1748532997)

### 성과가 좋은 이메일

열림률이나 클릭률이 높은 이메일을 순위로 보여 줘요. 어떤 이메일이나 발송 시간대가 수신자에게 반응이 좋은지 파악할 수 있어요.

![성과가 좋은 이메일 순위](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047444373/original/vXEspSdC_ruYOQnmkJpcuHVIardnXpOBaA.png?1748533403)

## 워크플로우 이메일 통계

워크플로우 안에 있는 자동 이메일 단계별 성과를 바로 확인할 수 있어요. 자동으로 보낸 메시지가 수신자에게 잘 도착하고 반응을 얻는지 알 수 있어요. 워크플로우 이메일의 통계를 보려면 다음과 같이 하세요.

1. **자동화 > 워크플로우**로 이동하세요.
2. 워크플로우를 열고 이메일 액션인 **Email**(이메일)을 선택하세요.
3. 오른쪽 패널에서 **Statistics**(통계)를 클릭하세요.

{% hint style="info" %}
워크플로우 빌더는 영어 화면으로 표시돼요.
{% endhint %}

다음 지표를 확인할 수 있어요.

- 전달됨
- 열림
- 클릭됨
- 답장됨
- 반송됨
- 구독취소
- 스팸 신고
- 수락됨
- 거부됨

{% hint style="info" %}
워크플로우 이메일 통계는 요약 화면과 결과를 맞추기 위해 기본으로 **최근 30일** 기준으로 표시돼요.
{% endhint %}

![워크플로우 이메일 통계 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047444702/original/Z2UIfHmUNTtgGi2GxUcuPxgzx8BKRHC-yQ.png?1748533775)

## 일괄 이메일 통계

**연락처 > 일괄 작업** 탭에서 한 번에 보낸 일괄 이메일의 성과를 볼 수 있어요. 자동화나 캠페인과 별개로 대량 발송한 결과를 확인할 때 좋아요. 수신자별 결과도 볼 수 있어서, 전달 문제의 원인을 찾거나 후속 작업 대상을 나눌 때도 편해요. 통계를 확인하려면 다음과 같이 하세요.

1. **연락처 > 일괄 작업**으로 이동하세요.
2. 활동 목록에서 확인할 이메일 발송 건을 찾으세요.

다음 항목을 확인할 수 있어요.

- 총 발송 시도
- 전달됨
- 열림
- 클릭됨
- 답장됨
- 반송됨
- 구독취소

## 이메일 지표 설명

| 지표 | 뜻 |
| --- | --- |
| **수신자** | 발송 대상이 된 연락처 수 |
| **전달됨** | 수신자의 메일 서버가 정상적으로 받은 이메일 |
| **열림** | 이메일을 한 번 이상 열어 본 경우 |
| **클릭됨** | 이메일 안의 링크를 클릭한 경우 |
| **소프트 바운스** | 일시적인 문제로 전달되지 않은 경우 (예: 받은편지함이 가득 참) |
| **하드 바운스** | 영구적인 문제로 전달되지 않은 경우 (예: 존재하지 않는 이메일 주소) |
| **구독취소** | 이메일 하단의 링크로 수신을 중단한 경우 |
| **실패** | 잘못된 이메일 주소나 잘못된 API 키 등으로 발송하지 못한 경우 |
| **스팸 신고** | 수신자가 스팸으로 신고한 경우 |
| **답장됨** | 연락처가 이메일에 답장한 경우 |
| **수락됨 / 거부됨 (수락되지 않음)** | SMTP 단계에서 메일 서버가 이메일을 받아 주었는지 여부 |

## 자주 묻는 질문

### 소프트 바운스와 하드 바운스는 무엇이 다른가요?
소프트 바운스는 받은편지함이 가득 찬 경우처럼 일시적인 문제예요. 하드 바운스는 존재하지 않는 이메일 주소처럼 영구적인 문제예요. 하드 바운스가 많으면 발신자 평판에 나쁜 영향을 줄 수 있어요.

### 이메일 통계는 얼마나 지나야 업데이트되나요?
대부분의 통계는 거의 실시간으로 업데이트돼요. 다만 클릭, 구독취소, 스팸 신고 같은 일부 항목은 수신자의 활동이나 이메일 서비스 제공업체의 지연 때문에 반영되기까지 몇 분 걸릴 수 있어요.

### 이메일 통계를 모두 보려면 Mailgun을 써야 하나요?
네. 전달됨, 반송됨, 구독취소, 스팸 신고 같은 주요 지표를 모두 확인할 수 있는 곳은 Mailgun뿐이에요. 다른 SMTP 제공업체를 쓰면 열림이나 클릭 같은 기본 추적만 가능할 수 있어요.
