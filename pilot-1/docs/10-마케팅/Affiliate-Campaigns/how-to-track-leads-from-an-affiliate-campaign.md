# 제휴 캠페인에서 리드 추적하기

제휴 캠페인에 폼, 설문, 캘린더를 연결하면 제휴 파트너가 만들어 온 리드를 자동으로 추적할 수 있어요. 이 문서에서는 캠페인을 만들면서 리드 추적을 설정하는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/WY\_KdYwzuhA?&wmode=opaque)

## 리드 추적 설정하기

1. **마케팅** 메뉴에서 **제휴 관리자**(Affiliate Manager)로 이동한 다음, 캠페인 페이지를 열어요.
2. **추가**를 눌러 리드 추적용 새 캠페인을 만들어요.

   ![캠페인 페이지에서 추가 버튼을 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033783420/original/OJJxADubEl5Wm2ZheJMKTdXQhASzjw7X2g.jpeg?1727691963)

3. 캠페인의 소스로 **폼**, **설문**, **캘린더** 중 하나를 선택해요. 선택한 소스를 통해 들어온 리드가 제휴 파트너의 실적으로 추적돼요.

   ![소스로 폼, 설문, 캘린더 중 하나를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033783421/original/HGm1Q1kW6UY5XM4U6AnVuaDetBVjsne1qg.jpeg?1727691963)

4. **소스 선택** 드롭다운에서 추적할 폼, 설문 또는 캘린더를 골라요.

   ![드롭다운에서 추적할 소스를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033783419/original/xYJCHZRkvozpHlWIWkBRlcnYP18hSsC5Dg.jpeg?1727691963)

5. 캠페인에 자동으로 만들어진 기본 제휴 캠페인 URL을 확인해요.

{% hint style="info" %}
계정에 브랜드 도메인을 추가하지 않았다면 제휴 캠페인 URL에는 시스템 도메인이 사용돼요. 내 브랜드 도메인을 쓰려면 **설정 > 비즈니스 프로필 > 브랜드 도메인**에서 추가하세요. 브랜드 도메인을 추가하면 모든 제휴 캠페인 URL이 자동으로 바뀌어요.
{% endhint %}

6. (선택) 제휴 파트너가 리드를 만들 때마다 보상을 주려면 **커미션** 탭에서 **리드당 지급**(Pay Per Lead)을 활성화해요. 자세한 설정 방법은 '제휴 파트너에게 리드 생성 보상 설정하고 지급하기' 문서를 참고하세요.
7. (선택) 캠페인 설명을 입력하거나 제휴 파트너를 지정하고, 필요한 다른 설정을 조정해요.

   ![캠페인 설명과 제휴 파트너 지정 등 추가 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033783417/original/ZTRR-lA0FNUA2GYiIXqj6gCJkqdx2A-T2w.jpeg?1727691962)

8. 설정을 모두 확인했다면 **게시**를 눌러 캠페인을 시작해요.

## 추적된 리드 확인하기

캠페인을 게시하면 리드가 각 제휴 파트너의 프로필 페이지에 자동으로 기록돼요.

1. 제휴 파트너의 프로필 페이지에서 **리드** 탭을 열어요.
2. 폼, 설문, 캘린더를 통해 들어온 리드를 확인해요.
3. **소스** 필드를 보면 각 리드가 어디에서 들어왔는지 알 수 있어요.

![제휴 파트너 프로필의 리드 탭에서 소스별 리드를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033783418/original/tScA8p17VPCMhgpVjAROIzSw3l8eKJaxBw.jpeg?1727691963)

## 꼭 알아 두세요

{% hint style="warning" %}
**커스텀 임베드와 iframe은 지원되지 않아요.** 폼, 설문, 캘린더를 퍼널이나 웹사이트 페이지 안에 구성 요소로 직접 추가한 경우에만 리드가 추적돼요. 제휴 캠페인의 소스로 쓰기 전에 해당 구성 요소가 퍼널에 제대로 들어가 있는지 확인하세요.
{% endhint %}

{% hint style="info" %}
**브랜드 도메인이 필요해요.** 제휴 URL에 내 브랜드 도메인이 표시되길 원한다면 **설정 > 비즈니스 프로필 > 브랜드 도메인**에서 먼저 도메인을 추가해야 해요.
{% endhint %}
