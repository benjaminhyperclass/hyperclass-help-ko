# 전화번호 구성 편집: 수신 통화 설정

수신 통화를 어디로, 어떻게 연결할지 한 화면에서 확인하고 바꿀 수 있어요. 통화 연결 순서, 벨 울림, 음성 메시지, 대체 연결 설정이 모두 이 화면에 모여 있어요. 이제 적절한 **수신 통화 시간 초과** 값을 안내해 주기 때문에, 통화가 통신사 음성 메시지가 아니라 하이퍼클래스 음성 메시지로 연결되고 통화 상태도 더 정확하게 기록돼요.

## 개요

통화를 연결하거나 가로채거나 다른 곳으로 넘기는 설정이 모두 한 화면에 모여 있어요. 통화 전달, 팀원 호출, IVR, 음성 AI, 음성 메시지, 시간 초과 동작이 여기에 포함돼요.

통화 연결 우선순위를 한눈에 볼 수 있고 권장 설정 안내도 나와요. 그래서 통화 연결에 문제가 생겼을 때 원인을 찾기 쉽고, 잘못된 설정도 줄일 수 있어요.

## 구성 편집(수신 통화 설정)이란?

수신 통화를 어디로 연결할지 정하는 모든 규칙을 한 창에 보여 주는 화면이에요. 각 항목에서 다음 내용을 확인할 수 있어요.

- 해당 연결 방식이 켜져 있는지
- 어떤 사용자, 번호, 시스템이 통화를 받는지
- 통화 연결 대상을 확인하는 우선순위

전화가 울리지 않거나 예상과 다르게 연결될 때 원인을 추측하지 않아도 돼요.

## 이 화면의 장점

- **투명한 확인**: 어떤 규칙이 1순위, 2순위, 3순위로 통화를 받는지 정확히 볼 수 있어요.
- **바로 편집**: 대부분의 설정을 페이지를 벗어나지 않고 바꿀 수 있어요.
- **명확한 우선순위**: 시스템이 연결 대상을 어떤 순서로 확인하는지 알 수 있어요.
- **빠른 문제 해결**: 잘못 설정된 시간 초과 값이나 사용자를 빨리 찾을 수 있어요.
- **통화 처리 개선**: 부재중 통화와 연결 오류를 줄일 수 있어요.

## 전화번호 구성 편집 화면 열기

1. **설정 > 전화번호**로 이동하세요.
2. **전화번호** 탭을 여세요.
3. 원하는 전화번호 옆의 **점 세 개 메뉴**를 클릭하세요.
4. **구성 편집**을 선택하세요.

![전화번호 옆 점 세 개 메뉴에서 구성 편집 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080608868/original/AtbjavgK3cMjQRikg_FoaoZ8QEkbs6FdUA.png?1789046927)

## 기본 정보

**기본 정보** 탭에서 다음 항목을 설정할 수 있어요.

- **표시 이름**: 전화번호의 이름을 바꿔요.
- **통화 연결 대상**: 기본으로 통화를 받을 팀원을 선택해요.
- **벨 울림 옵션**: 통화가 동시에 울릴 위치를 선택해요.
  - 웹 앱
  - 모바일 앱
  - 전화번호
  - VoIP 데스크폰
- **통화 녹음**
  - 녹음을 활성화하거나 비활성화해요.
  - 녹음 안내 메시지를 재생해요.

![기본 정보 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064214874/original/ovnJ2z2iR_tB-wPOo_EWfO_uIJdePvX2yw.png?1770236898)

## 통화 전달 탭

**통화 전달** 탭에서는 전화를 바로 받지 않을 때 어떻게 연결할지 정해요.

### 통화 연결 대상(우선순위)

- **IVR**: 워크플로우나 메뉴 입력에 따라 통화를 연결해요.
- 팀원(**1순위**)
- **외부 전화번호**(**2순위**)
- **음성 AI**(**3순위**)

우선순위에 따라 한 번에 한 곳만 울려요.

### 팀원 추가 호출

- 켜면 최대 **6명**의 사용자를 추가로 호출할 수 있어요.
- 기기 아이콘으로 각 사용자가 어떤 기기를 켜 두었는지 확인할 수 있어요.

## 수신 통화 시간 초과 안내

**수신 통화 시간 초과**는 통화가 대체 연결 대상(**음성 AI** 또는 **음성 메시지**)으로 넘어가기 전에 몇 초 동안 울릴지 정하는 값이에요.

### 권장 시간 범위

값이 적정 범위를 벗어나면 하이퍼클래스가 안내 메시지를 보여 줘요.

- **너무 긴 경우(약 20초 초과)**
  - 통화가 하이퍼클래스 음성 메시지가 아니라 **통신사 음성 메시지**로 연결될 수 있어요.
  - 통화 상태가 **음성 메시지**가 아니라 **완료**로 기록될 수 있어요.
- **너무 짧은 경우(약 15초 미만)**
  - 벨이 너무 짧게 울리거나 연결되지 않을 수 있어요.
  - 발신자가 전화를 받을 시간이 부족할 수 있어요.
- **추천**: **약 20초**

권장 범위를 벗어난 값을 입력하면 **경고 메시지**가 나타나요. 메시지를 참고해 적절한 시간을 선택하세요.

![수신 통화 시간 초과 경고 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064214884/original/45JX6qVuEXUbp-EZxDcpm-1w3sSX8rWzgw.png?1770236921)

{% hint style="info" %}
이 안내는 참고용이에요. 권장 범위를 벗어난 값도 저장할 수 있어요. 다만 음성 메시지 연결과 통화 상태 기록의 정확도에 영향을 줄 수 있어요.
{% endhint %}

## 대체 연결 동작

**수신 통화 시간 초과**에 도달하면 통화는 대체 연결 대상으로 넘어가요.

- **음성 AI**: 통화를 AI 에이전트에게 연결해요.
- **음성 메시지**: 통화를 하이퍼클래스 음성 메시지로 연결해요.

적절한 시간 초과 값을 선택하면 통화가 통신사 음성 메시지 시스템이 아니라 하이퍼클래스 음성 메시지로 연결돼요.

![대체 연결 대상 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064214892/original/S0QLDr-aqPrHzaLAl-v_59BiHisgBLg8gQ.jpeg?1770236939)

## 통화 연결 우선순위 이해하기

시스템은 수신 통화를 다음 순서로 확인해서 연결해요.

1. 전화번호에 연결된 워크플로우, IVR, 자동화
2. 전화번호에 직접 지정된 사용자
3. 연락처 레코드에 지정된 사용자
4. 여러 사용자에게 수신 전화 동시 호출(Ring-All)
5. 착신 전환 번호

이 중 **사용할 수 있는 가장 높은 순위** 한 곳만 울려요. 통화가 받아지거나 연결되면 그보다 낮은 순위는 건너뛰어요.

{% hint style="info" %}
비공개 번호나 발신자 표시 제한 번호의 수신 통화를 허용하려면 **설정 > 전화 시스템 > 음성 > 기타 설정 > 수신 통화**로 이동해 **비공개 통화 허용**을 켜세요.
{% endhint %}

## 자주 묻는 질문

### 수신 통화 설정은 누가 사용할 수 있나요?
전화번호를 관리할 권한이 있는 사용자라면 누구나 사용할 수 있어요.

### 새로 생긴 시간 초과 안내가 통화 연결 방식을 자동으로 바꾸나요?
아니요. 권장 값만 보여 줄 뿐이에요. 설정한 값을 강제로 바꾸거나 덮어쓰지 않아요.

### 예전에 어떤 통화는 왜 **음성 메시지**가 아니라 **완료**로 표시됐나요?
시간 초과 값이 너무 길면 통화가 하이퍼클래스 음성 메시지가 아니라 통신사 음성 메시지로 연결될 수 있어요. 이 경우 통화 상태가 잘못 기록돼요.

### 발신 통화에도 영향을 주나요?
아니요. **발신 통화 시간 제한**은 따로 설정하며, 이 안내의 영향을 받지 않아요.

### 시간 초과 값을 아주 길게 또는 짧게 설정해도 되나요?
설정은 할 수 있어요. 하지만 통화 연결과 상태 기록이 부정확해질 수 있어서 권장하지 않아요.
