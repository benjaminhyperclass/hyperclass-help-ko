# 회사 사이드 패널 사용하기

회사 사이드 패널에서는 회사 한 곳의 정보와 작업을 한 화면에서 처리할 수 있어요. 회사 필드, 연결된 연락처와 기회, 예약, 작업, 메모, 대화를 한곳에서 확인하고, 패널을 닫지 않고도 대화를 시작하거나 예약을 잡거나 연결할 수 있어요. 뒤에 있는 회사 목록은 그대로 열려 있어요.

{% hint style="info" %}
이 기능은 비공개 베타로만 제공돼요. 기능이 활성화된 서브 계정에서만 쓸 수 있어요.
{% endhint %}

## 회사를 계정 허브로 활용하기

각 탭에서 내용을 확인하는 데서 그치지 않고 바로 작업까지 할 수 있어서, 팀이 회사 단위로 계정을 관리하기 좋아요.

- **계정 정보 파악:** 통화나 미팅 전에 회사와 연결된 연락처, 기회, 그 밖의 레코드를 한 화면에서 확인해요.
- **후속 조치:** **대화** 탭에서 회사 담당 연락처와 대화를 시작해요. 회사는 이미 연결된 상태예요.
- **미팅:** **예약** 탭에서 회사가 미리 선택된 상태로 미팅을 예약하거나, 이미 있는 예약을 연결해요.

---

## 회사 열기

1. **연락처 > 회사**로 이동한 뒤 회사명을 클릭하세요.

회사가 사이드 패널에 열려요. 위쪽 화살표를 누르면 현재 목록에서 이전 회사나 다음 회사로 이동해요. 목록으로 돌아가려면 **닫기**를 클릭하세요.

---

## 회사 상세 정보 확인하기

**상세 정보** 탭에는 회사명, 연관 항목, 필드가 표시돼요.

- **연관:** 연결된 레코드가 관계별로 묶여 보여요. 관계 옆의 추가 버튼을 누르면 연관 항목을 고르는 창이 열려요. **전체 보기**가 보이면 클릭해서 더 많은 연관 항목을 확인하세요.
- **필드 검색:** 전체 레코드를 스크롤하지 않고도 필드나 폴더를 찾을 수 있어요.
- **빈 필드 숨기기:** 값이 있는 필드만 모아서 볼 수 있어요.
- **폴더와 개수:** 폴더를 펼치면 안에 있는 필드와 필드 개수를 확인할 수 있어요.
- **필드 편집:** 필드 값을 클릭하면 편집 창이 열려요.

**1단계:** **연락처 > 회사**로 이동해서 회사명을 클릭하세요.

**2단계:** **상세 정보**에서 연관 항목과 필드를 확인하세요. **필드 검색**과 **빈 필드 숨기기**를 쓰면 보고 싶은 내용만 추릴 수 있어요.

![상세 정보에서 연관 항목과 필드 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084159006/original/LSUnWhBlGNTcRjzbEj3VoBYQokVn0O6VPQ.png?1792995605)

## 탭 전환하기

패널 오른쪽 가장자리의 아이콘으로 탭을 전환해요.

| 탭 | 용도 |
| --- | --- |
| 상세 정보 | 레코드의 필드와 연관 항목을 확인해요 |
| 예약 | 레코드에 연결된 예약을 확인하고, 예약을 잡거나 기존 예약을 연결해요 |
| 연관 | 레코드의 연관 영역을 열어요 |
| 작업 | 레코드의 작업 영역을 열어요 |
| 메모 | 레코드의 메모 영역을 열어요 |
| 대화 | 레코드와 연결된 대화를 확인하거나 새로 만들어요 |

## 대화 탭 사용하기

1. 회사를 열고 **대화**를 선택하세요.
2. 대화 목록을 확인하세요. 연결된 대화가 없으면 빈 화면이 나와요.
3. **대화 만들기** 또는 **새 대화 만들기**를 클릭하세요.
4. **연락처**를 선택하세요. 현재 회사는 이미 **연결됨**으로 표시돼 있어요.
5. **대화 만들기**를 클릭해 계속 진행하세요.

연락처는 대화에 참여하는 사람이에요. 연결된 회사는 그 대화가 어느 계정과 관련된 것인지 알려 줘요.

**6단계:** **대화**에서 **대화 만들기**를 클릭하세요. 회사는 이미 **연결됨**으로 표시돼요. **연락처**를 선택하고 계속 진행하세요.

![대화 탭에서 대화 만들기 후 연락처 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084159003/original/tZpZmqyVuPAeCnGAK9kT3OxE6GQIDrfPUg.png?1792995605)

## 예약 탭 사용하기

1. 회사를 열고 **예약**을 선택하세요.
2. **예정**과 **지난 이벤트**를 전환하며 확인하세요.
3. 예약을 찾으려면 **캘린더 이름**으로 검색하세요.
4. **추가**를 클릭한 뒤 **미팅**, **서비스**, **기존 항목 연결** 중에서 선택하세요.

**7단계:** **예약**에서 **추가**를 클릭한 뒤 **미팅**, **서비스**, **기존 항목 연결** 중 하나를 선택하세요.

![예약 탭에서 추가 메뉴 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084159002/original/Kh4gtscwaNom_vN8M2dmTosv6yzE56cW5Q.png?1792995605)

---

### 미팅 예약하기

1. **추가 > 미팅**을 선택하세요.
2. 캘린더, 예약 상세 내용, 날짜, 시간, 연락처를 선택하세요.
3. **연결된 객체**를 확인하세요. 현재 회사가 미리 선택돼 있어요.
4. 나머지 예약 내용을 확인한 뒤 **예약하기**를 선택하세요.

**8단계:** 미팅을 예약할 때 **연결된 객체**를 열어 현재 회사가 미리 선택돼 있는지 확인하세요.

![연결된 객체에서 현재 회사 선택 여부 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084159010/original/kymCDdOkTVUPwVjP3sPKwXbxwTG4uDaE8A.png?1792995605)

---

### 기존 예약 연결하기

1. **추가 > 기존 항목 연결**을 선택하세요.
2. 현재 서브 계정에서 예약을 검색하세요.
3. 이 회사에 연결할 예약 옆의 **링크**를 선택하세요.

**9단계:** 이미 있는 예약을 쓰려면 **기존 항목 연결**을 선택하고 검색한 뒤 **링크**를 클릭하세요.

![기존 항목 연결에서 예약 검색 후 링크 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084159005/original/IpucPfQVJVGZJCR9DPwpU2SeAPV0WxCSgw.png?1792995605)

## 레코드 작업

패널 위쪽의 점 세 개 메뉴를 열면 **레코드 ID 복사**, **감사 로그 보기**, **삭제**를 쓸 수 있어요.

## 자주 묻는 질문

### 대화 탭이 비어 있는 이유가 뭔가요?
선택한 회사에 아직 대화가 없기 때문이에요. **대화 만들기**를 클릭하고 연락처를 선택하면 대화를 시작할 수 있어요.

### 이미 있는 예약을 회사에 연결할 수 있나요?
네, 할 수 있어요. **예약 > 추가 > 기존 항목 연결**을 선택해 예약을 검색한 뒤, 해당 예약 옆의 **링크**를 선택하세요.

### 왜 연락처를 꼭 선택해야 하나요?
대화를 만들려면 연락처가 필요해요. 현재 회사는 따로 연결돼서 계정 정보를 보여 주는 역할을 해요. 미팅 예약 화면에서도 연락처를 선택해야 해요.

### 회사 패널에 기회 파이프라인 기능이나 결제 탭도 있나요?
회사 패널에는 **상세 정보**, **예약**, **연관**, **작업**, **메모**, **대화**의 6개 탭이 있어요. 기회 파이프라인과 관련된 기능과 결제 탭은 이 패널에 없어요.
