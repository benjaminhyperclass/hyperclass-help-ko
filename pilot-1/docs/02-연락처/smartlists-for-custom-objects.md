# 사용자 지정 객체에서 스마트 리스트 사용하기

**사용자 지정 객체**(Custom Objects) 데이터를 원하는 조건으로 걸러 보고, 그 화면을 스마트 리스트로 저장해 팀과 공유하는 방법을 안내해요. 자주 보는 조건을 매번 다시 설정하지 않아도 되고, 팀원 모두가 같은 화면을 볼 수 있어요.

## 사용자 지정 객체 스마트 리스트로 할 수 있는 일

- **스마트 리스트 만들기**: 사용자 지정 객체 데이터를 원하는 조건으로 모아 볼 수 있어요.
- **스마트 리스트 검색**: **스마트 리스트 관리**에서 이름으로 원하는 스마트 리스트를 바로 찾을 수 있어요.
- **간편한 전환**: 여러 스마트 리스트를 오가며 볼 수 있어요.
- **열 너비 조절**: 열 너비를 원하는 대로 바꾸고 저장할 수 있어요.
- **공유**
  - 팀 전체 또는 선택한 팀원과 스마트 리스트를 공유할 수 있어요.
  - 사용자별로 보기 전용 또는 편집 **권한**을 줄 수 있어요.
  - 링크로 바로 공유하면 팀원 모두가 같은 화면을 볼 수 있어요.
- **정리**
  - 기존 스마트 리스트를 복제해서 조금씩 다른 버전을 빠르게 만들 수 있어요.
  - 필요에 따라 이름 변경, 내보내기, 삭제를 할 수 있어요.
  - 관리자는 모든 스마트 리스트를 관리하고 확인할 수 있어요.

## 사용 방법

### 1. 사용자 지정 객체 열기

사용자 지정 객체(예: Jobs)로 이동해요.

![사용자 지정 객체 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607627/original/UjYr3rXU7qfGlRjkeWbW5etZnpSKyvqtBg.png?1745503204)

### 2. 필터와 열 설정하기

스마트 리스트는 **상세 필터**, 정렬, 표시할 열의 조합을 저장해 두는 기능이에요. 스마트 리스트마다 이 조합이 따로 있어서 데이터를 목적에 맞게 정리하기 좋아요.

1. **상세 필터**를 클릭하고 필터 조건을 선택해요.
2. 화면에 표시할 열을 선택하고 정렬 순서를 정해요.

![상세 필터 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045606731/original/LoHD0N6tsB3RYssAl1_-ME2dd9VjGCxmxg.png?1745502572)

![열 선택 및 정렬 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045606732/original/If4arwqvvFM9deXsgThTAZJDDCEkQ2OsEg.png?1745502572)

### 3. 스마트 리스트 만들기

1. **+ 목록** 아이콘을 클릭해요.
2. 목록 이름을 입력해요.
3. 필터, 열, 정렬이 맞는지 확인하고 **만들기**를 클릭해요.

### 4. 스마트 리스트 관리하기

**편집**

1. **목록 사용자 지정**을 클릭해요.
2. 필터, 정렬 순서, 열을 원하는 대로 바꿔요.

![목록 사용자 지정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607892/original/yusWObNPbovAuNvRiuCRXsXQ0vtr303UTg.png?1745503419)

**복제**

1. **복제**를 선택해요.
2. 새 이름을 입력하고 **만들기**를 클릭해요.

![스마트 리스트 복제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045604846/original/N6VQvpGeD1WPdHC2py765NPNyXehttOFjA.png?1745501203)

**내보내기**

- **내보내기**를 클릭하면 스마트 리스트의 데이터를 내려받을 수 있어요.

**삭제**

- 필요 없는 스마트 리스트는 **옵션 삭제**로 지워요.

### 5. 공유와 권한 설정하기

기본적으로 스마트 리스트는 서브 계정의 관리자와 사용자에게 보여요. 접근 권한을 바꾸려면 다음 순서로 진행하세요.

1. **공유**를 클릭해요.
2. 선택한 사용자에게 **보기** 또는 **편집** 권한을 지정해요.

![공유 및 권한 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045604845/original/FDDKQ_qeAfD6Rljc2qrRu2Ah7YxSooTkJQ.png?1745501203)

### 6. 스마트 리스트 빠르게 만들기

상세 필터를 적용한 뒤 바로 스마트 리스트로 저장할 수 있어요.

1. **상세 필터**에서 원하는 조건을 적용한 다음, **저장되지 않은 변경 사항**을 클릭해요.

   ![저장되지 않은 변경 사항 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607918/original/Yw2C_lGgO4jStwMFX0HnT957Aw_baHyPRQ.png?1745503442)

2. 오른쪽 위의 **저장되지 않은 변경 사항**을 클릭하고 **새 스마트 리스트로 저장**을 선택해요.

   ![새 스마트 리스트로 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045604844/original/0MMzTQVFsB5CMrzr9wzEm5WXz8-PSjMU3g.png?1745501203)

### 7. 스마트 리스트 검색하기

스마트 리스트가 많을 때는 검색으로 빠르게 찾을 수 있어요.

1. **•••** 메뉴를 클릭하고 **스마트 리스트 관리**를 선택해요.
2. 검색창에 키워드를 입력해요.

![스마트 리스트 관리 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045608172/original/-Lmc4ClVA-t-aNdKy06b1Dwlcdq-x2fqww.png?1745503658)

![스마트 리스트 검색 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607976/original/36io1Rg12jUIAkmWJ8y5JEdgX1cKA5ez6w.png?1745503498)
