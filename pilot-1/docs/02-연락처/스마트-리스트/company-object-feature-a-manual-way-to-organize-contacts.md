# 회사 오브젝트로 연락처를 회사별로 묶어 관리하기

같은 회사에 속한 연락처를 하나의 회사 프로필로 묶어 관리하는 기능이에요. 한 고객사의 여러 담당자를 팀이 함께 응대할 때 관계와 활동 내역을 한곳에서 볼 수 있어요.

## 회사 오브젝트란?

회사 오브젝트(Company Object)는 여러 연락처를 하나의 회사에 연결하는 기능이에요. 같은 회사의 여러 사람과 소통할 때 특히 유용해요. 연락처를 회사 하나로 묶으면 그 회사와의 전체 소통 내역을 한눈에 보고, 정보를 한곳에 모아 둘 수 있어요. 접점마다 흩어진 소통도 정리할 수 있어요.

## 회사 오브젝트를 쓰면 좋은 점

- **연락처 정리**: 여러 연락처를 한 회사 아래에 간단히 묶을 수 있어요.
- **활동 내역 모아 보기**: 회사와 관련된 소통과 활동을 한곳에서 확인해요.
- **관계 파악**: 우리 팀이 그 회사와 어떻게 소통하고 있는지 전체 모습을 볼 수 있어요.
- **편리한 소통**: 회사에 연결된 모든 연락처와 쉽게 소통할 수 있어요.
- **정확한 데이터 유지**: 회사에 연결된 연락처들의 정보를 일관되고 최신으로 관리할 수 있어요.

## 회사 만들기

### 1단계. 회사 화면으로 이동하기

1. 왼쪽 메인 메뉴에서 **연락처**를 선택해요.
2. 화면 위쪽 보조 메뉴에서 **회사** 탭을 선택해요.

![연락처 메뉴의 회사 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041969865/original/afPxEFXXuOBxnAqTaV3LFBqNvqJ_8oglww.png?1740065034)

### 2단계. 새 회사 추가하기

1. 오른쪽 위의 파란색 **+ 새 회사** 버튼을 눌러요.

![새 회사 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041969989/original/h0xP2Ge9B26gWwWxU6549DHsoSBCwKFHVA.png?1740065114)

### 3단계. 회사 정보 입력하기

화면 오른쪽에 열린 입력 창에 회사 정보를 입력해요. 입력할 수 있는 항목은 다음과 같아요.

- **회사명** (필수)
- **전화번호**
- **이메일**
- **웹사이트**
- **설명**
- **주소 상세정보** (거리, 도시, 우편번호, 국가)

{% hint style="info" %}
필수 항목은 회사명뿐이에요. 다른 정보도 함께 입력해 두면 나중에 활용하기 더 좋아요.
{% endhint %}

![회사 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041970367/original/LbLWS8aCQVKZDC4wUpWeqzJFaU4RmCQzJg.gif?1740065352)

## 회사 정보 수정하기

1. 왼쪽 메인 메뉴에서 **연락처**를 선택해요.
2. 위쪽 메뉴에서 **회사** 탭을 선택해 **회사 목록**을 열어요.
3. 수정할 회사 오른쪽의 점 3개(**...**)를 누르고 **회사 수정**을 선택해요.
4. 바꿀 항목을 수정해요.
5. **저장**을 눌러 변경사항을 적용해요.

## 회사 삭제하기

1. 왼쪽 메인 메뉴에서 **연락처**를 선택해요.
2. 위쪽 메뉴에서 **회사** 탭을 선택해 **회사 목록**을 열어요.
3. 삭제할 회사 오른쪽의 점 3개(**...**)를 누르고 **회사 삭제**를 선택해요.
4. **삭제 확인** 창에서 **예**를 눌러요.

{% hint style="info" %}
회사를 삭제하면 연결된 연락처의 회사 항목만 비워져요. 연락처 자체는 삭제되지 않아요.
{% endhint %}

## 회사에 연락처 추가하기

1. 왼쪽 메인 메뉴에서 **연락처**를 선택해요.
2. 회사에 추가할 연락처를 찾아 이름을 눌러요.
3. 화면 왼쪽 보조 메뉴에서 **회사** 탭을 선택해요.
4. 연결할 회사를 검색해서 선택해요.
5. **저장**을 눌러 연결 내용을 반영해요.

{% hint style="info" %}
여러 연락처를 선택해 한 번에 같은 회사에 지정할 수도 있어요.
{% endhint %}

![연락처 상세 화면의 회사 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045226266/original/hB0MXzNuW4JiT_N6tcQE2IUWCEYF2s689Q.jpeg?1744827285)

## 회사에서 연락처 제거하기

1. 왼쪽 메인 메뉴에서 **연락처**를 선택해요.
2. 위쪽 메뉴에서 **회사** 탭을 선택해요.
3. 연락처를 제거할 회사를 선택해요.
4. 회사 프로필에서 **연락처** 탭을 선택하면 연결된 연락처를 볼 수 있어요.
5. 제거할 연락처 옆의 휴지통 아이콘을 눌러요.
6. 확인 창에서 **예**를 눌러 마무리해요.

{% hint style="info" %}
회사에서 연락처를 제거해도 연락처는 삭제되지 않아요. 회사와의 연결만 해제돼요.
{% endhint %}

## 연락처와 회사 연결 자동화하기

연락처의 **사업자명** 항목을 기준으로 회사 연결을 자동화할 수 있어요.

1. **설정 > 오브젝트 > 회사**로 이동해요.
2. **연락처의 사업자명으로 회사를 자동 생성하고 연결** 옵션을 켜요.

{% hint style="info" %}
자세한 내용은 [회사 오브젝트 자동화](../../11-설정/company-object-automation.md) 문서를 참고하세요.
{% endhint %}

## 자주 묻는 질문

### 연락처 하나에 여러 회사를 지정할 수 있나요?
아니요. 연락처는 한 번에 하나의 회사에만 연결할 수 있어요.

### 회사를 삭제하면 그 회사의 연락처도 모두 삭제되나요?
아니요. 회사와의 연결만 해제되고, 연락처는 그대로 남아요.

### 여러 연락처를 한 번에 회사에 지정할 수 있나요?
네. 연락처 목록에서 여러 연락처를 선택한 뒤 한 번에 회사에 지정하면 돼요.

### 특정 회사에 연결된 연락처를 한꺼번에 보려면 어떻게 하나요?
**연락처 > 회사**로 이동해 해당 회사를 선택한 다음, **연락처** 탭을 확인하세요.

### 직접 지정하지 않고도 연락처와 회사를 자동으로 연결할 수 있나요?
네. **설정 > 오브젝트 > 회사**에서 **연락처의 사업자명으로 회사를 자동 생성하고 연결** 옵션을 켜면 돼요.
