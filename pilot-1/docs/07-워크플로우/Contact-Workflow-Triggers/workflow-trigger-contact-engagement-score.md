# 워크플로우 트리거: 연락처 참여 점수

**연락처 참여 점수**(Contact Engagement Score) 트리거는 연락처의 참여 점수와 다른 조건을 기준으로 연락처를 워크플로우에 넣어 줘요. 연락처가 얼마나 반응했는지에 따라 후속 작업을 자동화하고 싶을 때 쓰세요.

## 개요

이 트리거는 **참여 점수**와 연락처의 다른 정보를 조건으로 삼아, 조건에 맞는 연락처만 워크플로우에 들어오게 해요. 이를 활용하면 다음과 같은 작업을 자동화할 수 있어요.

- 후속 연락 보내기
- 참여도가 높은 연락처만 따로 분류하기
- 조건에 따라 마케팅 방식 바꾸기

## 트리거 세부 항목

| 필드 이름 | 설명 | 필수 여부 |
| --- | --- | --- |
| 점수 | 연락처의 참여 점수예요. 설정한 조건에 맞는 연락처만 트리거돼요. | 예 |
| 비즈니스 니치 | 연락처와 연결된 업종 분류예요. 예를 들어 학력, 의료 등이 있어요. | 아니요 |

![연락처 참여 점수 트리거 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033065696/original/RevefXKprkOBwX7qFdxChkT3dIs5xV6SFg.png?1726648831)

조건에는 아래 연산자를 쓸 수 있어요.

| 연산자 | 설명 |
| --- | --- |
| 같음 | 점수나 필드 값이 입력한 값과 같으면 트리거돼요. |
| **초과** | 점수나 필드 값이 입력한 값보다 크면 트리거돼요. |
| 이상 | 점수나 필드 값이 입력한 값보다 크거나 같으면 트리거돼요. |
| 미만 | 점수나 필드 값이 입력한 값보다 작으면 트리거돼요. |
| 이하 | 점수나 필드 값이 입력한 값보다 작거나 같으면 트리거돼요. |
| 비어있음 | 필드 값이 비어 있으면 트리거돼요. |
| **비어있지 않음** | 필드 값이 비어 있지 않으면 트리거돼요. |
| 포함 | 필드에 입력한 문구가 들어 있으면 트리거돼요. |
| **포함하지 않음** | 필드에 입력한 문구가 들어 있지 않으면 트리거돼요. |

## 트리거 설정하기

1. 워크플로우 빌더의 트리거 목록에서 **연락처 참여 점수**를 선택하세요.
2. **트리거 이름**에 알아보기 쉬운 이름을 입력하세요. 예를 들어 "참여도 높은 연락처"처럼 쓰면 돼요.
3. 필터를 추가해서 참여 점수나 다른 조건을 정하세요.
   - 필터 드롭다운에서 **점수**를 고르고 **초과**를 선택한 다음, **값을 입력하세요** 칸에 **195** 같은 숫자를 입력하세요.
   - 필요하면 필터를 더 추가할 수 있어요. 예를 들어 **비즈니스 니치**를 고르고 **포함**을 선택한 다음, 업종(예: **학력**)을 입력하세요.
4. 트리거 설정을 저장하세요. 이어서 필요한 액션이나 단계를 워크플로우에 추가하면 돼요.

## 설정 예시

**연락처 참여 점수** 트리거에 아래 두 조건을 설정한 경우예요.

- **점수**가 **195 초과**
- **비즈니스 니치**에 **학력** 포함

연락처가 두 조건을 모두 만족하면 워크플로우에 들어와요. 이후 후속 이메일 캠페인이 이어지도록 구성할 수 있어요.
