# 워크플로우 첫 화면: 새로워진 시작 가이드

처음 **워크플로우**(Workflows)를 쓰는 사용자를 위해 첫 화면이 새로 바뀌었어요. AI로 워크플로우를 만들 수 있고, 선택한 비즈니스 니치에 맞는 템플릿과 안내 영상도 바로 볼 수 있어요. 이 문서에서는 새 화면의 구성과 AI 빌더를 켜고 끄는 방법을 설명해요.

처음 시작하는 사용자는 이제 업종에 맞는 예시와 추천을 처음부터 볼 수 있어요. 그래서 자동화가 어떻게 돌아가는지 이해하고 첫 워크플로우를 만들기가 훨씬 쉬워요.

시작하는 방법은 세 가지예요.

- **AI 빌더**에 만들고 싶은 자동화를 쉬운 말로 적어요.
- 미리 만들어진 템플릿을 둘러보며 아이디어를 얻어요.
- **워크플로우 만들기**를 눌러 처음부터 직접 만들어요.

{% hint style="warning" %}
워크플로우 AI 빌더는 Labs를 통해 모든 에이전시에 기본으로 켜져 있어요. **AI 빌더**가 보이지 않는다면 에이전시나 서브 계정 단위에서 꺼져 있을 수 있어요.
{% endhint %}

## 워크플로우 AI 빌더

워크플로우 첫 화면 위쪽에 **AI 빌더**가 눈에 띄게 자리 잡았어요. 자동화하고 싶은 일을 쉬운 말로 적으면 AI가 워크플로우를 만들어 줘요.

화면 위쪽에서 "What do you want to automate?"(어떤 작업을 자동화하고 싶으세요?)라는 입력창을 찾아보세요. 아래처럼 원하는 흐름을 한 번에 적을 수 있어요.

```
When form is submitted, send SMS to lead, wait 5 minutes for response - if no response create call task, if they respond add tag
```

위 예시는 "폼이 제출되면 리드에게 SMS를 보내고 5분 동안 답을 기다려요. 답이 없으면 전화 작업을 만들고, 답이 오면 태그를 추가해요."라는 뜻이에요.

입력창 아래에는 빠른 시작용 추천 항목도 있어요. 리드 육성(Lead Nurturing), 폼 자동화(Form Automation), **이메일 캠페인** 같은 항목을 누르면 더 빠르게 시작할 수 있어요.

## 비즈니스 니치에 맞춘 시작 화면

워크플로우를 처음 쓰면 **비즈니스 니치**(업종)를 고르라는 안내가 나와요. 하이퍼클래스는 고른 니치에 맞춰 예시와 추천 템플릿을 보여 줘요.

![비즈니스 니치 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060472773/original/4tockivB27MYSUG3Bno4xKEOTfKHXpsLFA.png?1765530961)

- **학력**, **건강**, **금융**, **부동산** 같은 인기 니치에는 바로 쓸 수 있는 템플릿이 준비되어 있어요. 각 업종에서 자주 쓰는 자동화 상황을 담았어요. 예를 들어 부동산 중개인에게는 새 매물 문의에 후속 연락을 하는 템플릿이, 병원에는 예약 알림 템플릿이 보일 수 있어요. 처음부터 만들 필요 없이 니치별 템플릿을 시작점으로 삼아 내 상황에 맞게 고치면 돼요.
- **모든 템플릿** 링크를 누르면 첫 화면에서 모든 템플릿을 바로 둘러볼 수 있어요. 아이디어가 필요하거나 빠르게 시작하고 싶을 때 좋아요.

![모든 템플릿 링크가 있는 첫 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060473194/original/E6qoXfLEk9FZ_g5lpbMkDyCKwgHeqxt_6A.png?1765531167)

### 대화 메시지에서 바로 실행 내역 열기

문제를 확인할 때는 대화 메시지에서 해당 워크플로우의 실행 내역을 바로 열 수 있어요.

- **대화**에서 열기: 메시지 상세 > **워크플로우** > **실행 상세 정보**를 차례로 선택해요. 해당 메시지의 실행 내용이 바로 열려요.
- 워크플로우에서 열기: **워크플로우** > 워크플로우 열기 > **로그**를 차례로 선택해요.

## 트리거와 작업을 캔버스로 끌어다 놓기

사이드바에서 트리거와 작업을 워크플로우 캔버스로 바로 끌어다 놓아 단계를 더 빠르게 추가할 수 있어요. 워크플로우 빌더는 영어 화면으로 표시돼요.

**사용 방법**

1. 워크플로우 빌더에서 **Triggers**(트리거) 또는 **Actions**(작업) 사이드바를 열어요.
2. 트리거나 작업을 누른 채로 캔버스까지 끌어요.
3. 놓을 수 있는 위치 위에 마우스를 올려요. **+** 표시나 기존 단계 사이가 그 위치예요. 단계가 들어갈 자리가 강조되어 보여요.
4. 항목을 놓고 설정한 뒤 **저장**하면 워크플로우에 추가돼요.

![트리거와 작업을 캔버스로 끌어다 놓는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064712764/original/OXfbIYzBFxXo0ngPp2k3FnOXM0JGPQkz7A.gif?1770826719)

{% hint style="warning" %}
저장하지 않고 워크플로우를 나가면 끌어다 놓은 트리거나 작업은 캔버스에 추가되지 않아요.
{% endhint %}

## AI 빌더 사용 범위와 제어

워크플로우 AI 빌더는 모든 에이전시에 기본으로 켜져 있어요. 에이전시 관리자는 아래 방법으로 끄거나 켤 수 있어요.

**에이전시 전체(모든 서브 계정 포함)에서 끄기**

**설정 > Labs**로 이동해 워크플로우 AI 빌더를 비활성화하세요.

**특정 서브 계정에서만 끄기**

**자동화 > 글로벌 워크플로우 설정 > 워크플로우 AI**로 이동해 **AI 빌더**를 끄세요.

![글로벌 워크플로우 설정에서 AI 빌더를 끄는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071093803/original/4gIwSQd6Mf19iYzJgl1X4URN46hpi5_8gQ.png?1778570385)

### 서브 계정에서 보이는 소유자용 팝업

AI 빌더가 새로 적용된 서브 계정에 에이전시 소유자가 들어가면 확인 팝업이 나타나요. 팝업에서 **비활성화**를 눌러 해당 서브 계정에서 바로 끌 수도 있어요.

처음부터 직접 만드는 방법은 이전처럼 **워크플로우 만들기** 아래 **드롭다운 옵션**에서 그대로 쓸 수 있어요.

## 자주 묻는 질문

### 서브 계정에서 새 화면이 보이지 않아요. 왜 그런가요?
새 화면을 쓰려면 먼저 Labs에서 AI 빌더가 켜져 있어야 해요. **설정 > Labs**로 이동해 AI 빌더 기능을 활성화하면 새 워크플로우 첫 화면을 볼 수 있어요.

### 사용자에게 AI가 들어간 새 화면을 보여 주고 싶지 않아요. 어떻게 없애나요?
AI 빌더는 두 곳에서 끌 수 있어요.

- **에이전시**: **설정 > Labs**로 이동해 워크플로우 AI 빌더를 비활성화하세요.
- **위치**: **자동화 > 글로벌 워크플로우 설정 > 워크플로우 AI**로 이동해 **AI 빌더**를 끄세요.
