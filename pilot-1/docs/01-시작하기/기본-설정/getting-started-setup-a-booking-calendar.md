# 예약 캘린더 설정하기

예약 캘린더를 만들어 두면 고객이 원하는 시간에 직접 예약할 수 있어요. 이 문서에서는 개인 예약 캘린더 만들기, 스태프로 나를 추가하기, 자동 리마인더 설정하기, 내 캘린더 연결하기, 예약 링크 공유하기를 차례로 안내해요.

## 개인 예약 캘린더 만들기

개인 예약 캘린더에서는 예약 가능 시간, 예약 사이 간격, 미팅 시간, 리마인더 같은 예약 규칙을 정해요.

Google 캘린더로 예약을 받으려면 먼저 하이퍼클래스에서 개인 예약 캘린더를 만들어야 해요. Google 캘린더를 매일 쓰더라도 마찬가지예요. 하이퍼클래스 안에서 예약을 어떻게 받고 보여 줄지는 이 캘린더에서 정하기 때문이에요.

1. **캘린더 > 캘린더 설정**으로 이동하세요.

   ![캘린더 설정 메뉴로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066592799/original/z9nVrbIH5ziNObPoQJWmABjrzbrlyxe0RA.png?1773144800)
2. **+ 새 캘린더**를 클릭하세요.

   ![새 캘린더 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066221388/original/i0KgyPsA8ygTbGvKczimClmFQQgzZSvr_w.png?1772653939)
3. 캘린더 유형을 선택하세요. 1:1 미팅이라면 **개인 예약**을 선택하세요.

   ![캘린더 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066221401/original/iIRSFaAMr2iQg1XPih0fKwe6weLO4QDa6Q.png?1772653976)
4. 캘린더 정보를 입력하세요. 아래 항목을 채우면 돼요.
   - 알아보기 쉬운 캘린더 이름
   - 호스트(본인 선택)
   - 커스텀 URL 확인
   - 예약 시간 길이
   - 예약 가능한 시간
5. **확인**을 클릭하세요.

   ![캘린더 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046581684/original/w_jfRs4qEjTzZY8tjdID9d54ZYKM1U83vw.png?1747182590)

   캘린더 설정은 빠르게 찾아갈 수 있도록 **기본 세부 정보**, **스태프 및 위치**, **가용성**, **예약 규칙**, **고급 설정** 섹션으로 나뉘어 있어요.

   ![캘린더 설정 섹션 구성](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066592686/original/d1Y3-9gB28e1z4WOabePsJ4H3epFc9g_lg.png?1773144729)
6. 캘린더 링크 또는 임베드 코드를 복사하세요.

   ![링크와 임베드 코드 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066221479/original/xzDvgh3Mo4DKQoLy_zldlRZSBw2ebsCwAw.png?1772654105)
7. 복사한 캘린더 링크를 공유하면 예약을 받기 시작해요.

다음으로, 브랜드에 맞게 캘린더 모양을 꾸밀 수 있어요.

{% hint style="info" %}
예약 과정에서 커스텀 폼을 쓴다면 폼 제출 후 화면을 **고급 설정 > 폼 및 확인 > 확인 페이지**에서 정할 수 있어요. 커스텀 폼 규칙 사용을 선택하면 제출 후에 폼에 설정한 이동 페이지나 안내 메시지가 그대로 적용돼요.
{% endhint %}

## 스태프로 나를 추가하기

혼자 일하더라도 스태프로 나를 추가해 두면 예약 기능이 문제없이 동작해요.

1. **설정 > 스태프 관리**로 이동하세요.
2. **사용자 추가**를 클릭하세요.
3. 내 정보를 입력하고 **저장**을 클릭하세요.

다음으로, 나와 다른 팀원에게 필요한 권한을 따로 설정해 업무 흐름을 간단하게 만들 수 있어요.

## 자동 리마인더 설정하기

자동 리마인더를 설정하면 고객이 예약 시간을 잊지 않도록 미리 알려 줘서 노쇼를 줄일 수 있어요.

1. **자동화**로 이동하세요.
2. **워크플로우 만들기**를 클릭하고 **레시피**를 선택하세요.

   ![워크플로우 만들기에서 레시피 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582042/original/X0KXph5Qggv6ls_gtEKqdD6gJd_GTgIOrg.png?1747184480)
3. 레시피 중 **Appointment Confirmation + Reminder**(예약 확인 + 리마인더)를 선택하세요.

   ![예약 확인 + 리마인더 레시피 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582055/original/Y6Y4q8Sd5uM3TAT6Pr2Ohu-XfrZJhRt7tQ.png?1747184652)
4. **Confirmation Email**(확인 이메일) 액션을 편집하세요.
5. 미팅 링크(Zoom, Google Meet 등)를 내 링크로 바꾸고 **Save Action**(액션 저장)을 클릭하세요.

   ![미팅 링크 수정 후 액션 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582067/original/zwK15IKOBl0WlNnqnTP_tlBBcjUYKdk8Yg.png?1747184728)
6. 나머지 액션도 모두 확인하세요.
7. **Publish**(게시)를 클릭하세요.
8. **Save**(저장)를 클릭하세요.

   ![워크플로우 게시 및 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582073/original/oqAx0Yzr78U2Z1i-kUPeDx5B1v1HCCWp4Q.png?1747184767)

다음으로, 리마인더 메시지를 내 말투로 고쳐 쓰면 고객과 더 가까워질 수 있어요.

### 저장할 때 빠진 필수 항목 찾기

필수 항목을 비워 둔 채 **변경사항 저장**을 클릭하면 하이퍼클래스가 문제가 있는 곳을 자동으로 찾아 줘요.

- 빠진 항목이 지금 보는 탭에 있으면, 화면이 그 항목으로 이동하고 강조 표시를 해요.
- 빠진 항목이 다른 탭에 있으면, 해당 탭을 열고 그 항목을 강조해요.

캘린더를 저장하기 전에 빠진 내용을 빠르게 고칠 수 있어요.

## 내 캘린더 연결하기

예약 시스템에 내 캘린더를 연결하면 일정이 서로 동기화돼요. 그래서 중복 예약이나 놓치는 미팅을 막을 수 있어요.

1. **캘린더 > 캘린더 설정**으로 이동하세요.

   ![캘린더 설정으로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582081/original/DosSWHTt2THvSPzLG8neIvdu_7_Y1QY67A.png?1747184874)
2. **연결** 탭을 선택하고 **새로 추가**를 클릭해 내 캘린더를 연결하세요.

   ![연결 탭에서 새로 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582097/original/OL5bIDvosxda9GtMpgvjvYhP-rNFQZT6ww.png?1747184942)
3. **화상 회의** 탭을 선택하고 **새로 추가**를 클릭해 쓰고 있는 화상 회의 도구를 연결하세요.

   ![화상 회의 탭에서 새로 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582104/original/KE9SnwYzFVB8Eb0-C2mJqKhvd8hvPHwiEw.png?1747185004)

다음으로, 연동이 제대로 동기화되고 있는지 한 번 더 확인해 보세요.

## 캘린더 화면 상단에서 바로 공유하기

편집 중인 캘린더에서 바로 공유하면 시간도 아끼고 링크를 잘못 복사하는 일도 막을 수 있어요.

**설정 > 캘린더 > [내 캘린더]**를 열고, 오른쪽 상단의 **공유**를 클릭하면 아래 기능을 쓸 수 있어요.

- **복사**: 예약 링크 복사
- **일회용 링크** 만들기
- **임베드 코드** 가져오기
- **미리보기**: 방문자에게 보이는 캘린더 화면 확인

![캘린더 상단의 공유 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064116937/original/VW3GXgSdWHyuZ2vVZsSVXQKadZ6ZV-u-Fg.png?1770138871)

## 자주 묻는 질문

### 예약 링크는 어디에서 찾나요?
**설정 > 캘린더 > [내 캘린더]**를 열고 오른쪽 상단의 **공유**를 클릭한 다음 **링크 복사**를 클릭하세요.

### 일회용 링크는 어떻게 만드나요?
상단의 **공유**를 클릭하고 **일회용 링크**를 선택하세요. 안내에 따라 링크를 만들고 복사하면 돼요.

### 웹사이트에 넣을 임베드 코드는 어디에 있나요?
상단의 **공유**를 클릭하고 **임베드 코드**를 선택하면 HTML 스니펫을 복사할 수 있어요.

### 방문자 입장에서 캘린더를 미리 볼 수 있나요?
네, 할 수 있어요. **공유**를 클릭하고 **미리보기**를 선택하세요. 복사한 링크를 시크릿 창에서 열어 확인해도 돼요.

### "캘린더 문제 해결"은 어떤 기능인가요?
캘린더 설정과 가용성에 문제가 있는지 진단해 주는 기능이에요. 문제를 찾으면 해결 방법도 안내해 줘요.

### 이 버튼들을 누르면 기존 링크가 바뀌나요?
아니요. 이 버튼들은 자주 쓰는 기능으로 바로 갈 수 있게 한 것뿐이에요. 새 일회용 링크를 만들지 않는 한 기존 예약 링크는 그대로예요.
