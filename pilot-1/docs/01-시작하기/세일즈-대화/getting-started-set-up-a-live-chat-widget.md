# 시작하기: 라이브 채팅 위젯 설정

**채팅 위젯**을 쓰면 웹사이트에 다양한 방식의 채팅 창을 붙일 수 있어요. 이 글에서는 방문자가 팀 또는 대화 AI와 실시간으로 대화를 시작할 수 있는 **라이브 채팅** 위젯을 만들어요. 위젯을 내 브랜드에 맞게 꾸미고, 하이퍼클래스 웹사이트나 퍼널에 적용하는 방법도 함께 알아봐요.

## 라이브 채팅 위젯 만들기

웹사이트에 라이브 채팅을 붙이려면 **채팅 위젯** 화면에서 새 위젯을 만들고, 채팅 유형으로 **라이브 채팅**을 선택하세요.

1. **사이트 > 채팅 위젯**으로 이동하세요.
2. **신규**를 클릭하세요. 올인원 채팅, SMS/이메일 채팅, 라이브 채팅, WhatsApp 중에서 유형을 고를 수 있어요.

   ![채팅 위젯 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078737592/original/A_CPwrjS-U_f-QoywQ3FE3AxrC4r98FzuQ.png?1787081674)

3. **라이브 채팅**을 선택하세요.
4. 내 브랜드에 맞게 위젯을 꾸며 보세요.
5. **저장**을 클릭하세요.

   ![위젯을 꾸민 뒤 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960759/original/SRZNNj26lxreHm5VbkHahfNcCrcphc350g.png?1747784131)

6. **코드 가져오기 > 복사**를 클릭하세요.
7. 표시된 임베드 코드를 복사하세요.

   ![임베드 코드를 복사하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960766/original/VoU2x6UeSm_BfBCXsNEwBdH-IvD1n80R3Q.png?1747784179)

**자세히 보기**

- [라이브 채팅](../../03-대화/대화/live-chat.md): 라이브 채팅 대화가 어떻게 전달되고 하이퍼클래스 대화에서 어떻게 관리되는지 알아봐요.
- [채팅 위젯 사용자 지정 살펴보기](../../06-사이트/overview-of-chat-widget-customizations.md): 채팅 위젯의 모양과 동작을 바꾸는 다양한 옵션을 확인해요.
- [채팅 위젯 시작하기](../../06-사이트/getting-started-with-chat-widget.md): 사용할 수 있는 채팅 위젯 유형, 설정 옵션, 꾸미기 설정을 한눈에 살펴봐요.

위젯을 만들었다면 이제 웹사이트에 적용할 차례예요. 아래에서 편한 방법을 골라 보세요.

## 임베드 코드로 적용하기

웹사이트나 퍼널에 스크립트를 직접 넣어 본 적이 있다면 이 방법이 가장 빨라요. 편집기에 코드를 붙여 넣기만 하면 돼요.

1. **사이트 > 웹사이트** 또는 **사이트 > 퍼널**로 이동하세요.
2. 위젯을 붙일 웹사이트나 퍼널을 찾아 편집 화면을 여세요.

   ![웹사이트 또는 퍼널 편집 화면 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960787/original/gl7U7-ugo-EDySww14EHX-4Gj2WR2rk96w.png?1747784281)

3. 편집기에서 **추적 코드** 아이콘(`</>`)을 클릭하세요.
4. 복사해 둔 채팅 위젯 코드를 붙여 넣으세요.
5. **저장**을 클릭하세요.

   ![추적 코드에 위젯 코드를 붙여 넣고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960800/original/7j7RzpFPTEufQWAwRrPbk8r82cQKIsBZpg.png?1747784365)

**자세히 보기**

- 다른 설치 방법이나 문제 해결이 필요하면 [하이퍼클래스 채팅 위젯 설치하기](../../06-사이트/how-to-install-hyperclass-s-chat-widget.md)를 참고하세요.

적용이 끝났어요. 다음에는 위젯이 제대로 작동하는지 직접 테스트해 보세요.

## 설정에서 적용하기

코드를 직접 다루는 게 부담스럽다면 웹사이트 설정에서 바로 적용할 수 있어요. 이 방법이 더 간단해요.

1. **사이트 > 웹사이트** 또는 **사이트 > 퍼널**로 이동하세요.
2. 위젯을 붙일 웹사이트나 퍼널을 찾아 설정을 여세요.

   ![웹사이트 또는 퍼널 설정 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960805/original/qO6x3foY4mdlFGpt9mJMtShG_K95UyCF2A.png?1747784390)

3. **채팅 위젯** 섹션에서 만들어 둔 라이브 채팅 위젯을 선택하세요.

   ![채팅 위젯 섹션에서 라이브 채팅 위젯 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960820/original/w-Ubwt6xqJS_-CIIhHTfhfcnFa96K3PU5g.png?1747784475)

4. **저장**을 클릭하세요.

   ![설정을 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960834/original/1BsYAyKDH_J3qdvsMEAcrssP0JqZCeQLFA.png?1747784529)

이제 설정이 끝났어요. 다음에는 고급 꾸미기 옵션으로 채팅 창을 내 브랜드답게 다듬어 보세요.
