# 301 리다이렉트 완전 가이드

301 리다이렉트가 무엇인지, SEO와 사용자 경험에 왜 중요한지, 하이퍼클래스에서 어떻게 설정하는지 알아봐요. 페이지 주소(URL)가 바뀌어도 방문자와 검색 엔진이 올바른 페이지로 이동하도록 단계에 따라 설정해 보세요.

## 301 리다이렉트란?

**301 리다이렉트**는 한 URL을 다른 URL로 영구적으로 연결하는 설정이에요. URL이 바뀌어도 사용자와 검색 엔진이 올바른 웹페이지로 이동해요.

## 301 리다이렉트를 사용하는 이유

- **SEO 순위 유지**: 깨진 링크를 막아서 검색 엔진에서 쌓은 평가를 지켜요.
- **사용자 경험 개선**: 방문자가 막힘없이 올바른 페이지에 도착해요.
- **도메인 통합**: 여러 형태의 도메인 주소를 하나로 모아요. 예를 들어 www.yoursite.com을 yoursite.com으로 보낼 수 있어요.
- **오래된 링크 수정**: 예전 URL로 들어와도 관련 있는 페이지로 이어져요.

## 하이퍼클래스에서 301 리다이렉트 설정하기

도메인에 301 리다이렉트를 설정하려면 아래 순서대로 따라 하세요.

### 1단계: URL 리다이렉트 열기

**URL 리다이렉트**는 서브 계정의 **설정** 아래에 있어요.

![URL 리다이렉트 메뉴 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046423137/original/zgC_ZlmZbqaewhk5pRPBUDEyxNAMDjS0RA.png?1746881207)

### 2단계: 리다이렉트 유형 선택

하이퍼클래스에서는 네 가지 유형의 리다이렉트를 쓸 수 있어요.

#### 1. 다른 URL로 리다이렉트

- 특정 URL로 들어온 방문자를 다른 URL로 보낼 때 써요.
- 해당 도메인이 하이퍼클래스 서브 계정에 추가되어 있어야 해요.
- 입력 방법은 다음과 같아요.
  - **경로**: 페이지 이름 앞에 /를 붙여 입력해요. 예: /old-page
  - **대상 URL**: 방문자를 보낼 전체 URL을 입력해요.

![다른 URL로 리다이렉트 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046423287/original/wM0qlZiVit9GZzM-DqhdvKqIoyp8I7D1yg.gif?1746881733)

리다이렉트할 도메인이 이미 하이퍼클래스 서브 계정에 추가되어 있어야 해요.

#### 2. 퍼널 단계로 리다이렉트

- 하이퍼클래스에 만든 퍼널의 특정 단계로 방문자를 보내요.
- 퍼널이 서브 계정의 도메인과 연결되어 있어야 해요.

![퍼널 단계로 리다이렉트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043395223/original/8UraJujxBCgsPgem_vlsXKHvb0Xb482OoQ.png?1742204091)

#### 3. 웹사이트 페이지로 리다이렉트

- 하이퍼클래스 웹사이트의 특정 페이지로 방문자를 보내요.
- 웹사이트가 서브 계정의 도메인과 연결되어 있어야 해요.

![웹사이트 페이지로 리다이렉트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043395315/original/6uOm35lhHVhKI1WnyLyD3nr1ephmFUgtSQ.png?1742204143)

#### 4. 모든 경로 리다이렉트(REGEX 리다이렉트)

- 한 도메인의 모든 경로를 다른 도메인으로 보내요.
- www가 붙은 주소를 루트 도메인(www가 없는 주소)으로 보낼 때 유용해요.
- 예: www.mysite.com/*을 mysite.com/*으로 리다이렉트해요.

![모든 경로 리다이렉트 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043395403/original/aVN2NxwMPEbVwxP-ZndJSlOO6EJYKNLJxg.png?1742204177)

### 3단계: 리다이렉트 저장하고 확인하기

1. 리다이렉트 내용을 입력한 뒤 **저장**을 클릭하세요.
2. 브라우저를 열고 원래 URL을 입력해서 올바른 페이지로 이동하는지 확인하세요.
3. 온라인 리다이렉트 체커 도구로 한 번 더 확인하세요.

## 301 리다이렉트 모범 사례

- 오류를 줄이려면 https://newsite.com/page 처럼 전체 주소(절대 URL)를 입력하세요.
- 리다이렉트가 여러 번 이어지지 않게 하세요. 기존 URL을 최종 목적지로 바로 연결하는 것이 좋아요.
- 깨진 리다이렉트가 없는지 정기적으로 확인하세요.
- REGEX는 신중하게 쓰세요. 잘못 쓰면 엉뚱한 곳으로 이동할 수 있어요.

## 자주 생기는 문제와 해결 방법

❌ **리다이렉트 루프**: URL이 자기 자신으로 리다이렉트되지 않는지 확인하세요.

❌ **404 오류**: 대상 페이지가 실제로 있는지 다시 확인하세요.

❌ **느린 로딩**: 리다이렉트가 너무 많으면 페이지가 느려질 수 있어요.

## 마무리

하이퍼클래스에서 301 리다이렉트를 제대로 설정하면 SEO와 사용자 경험, 웹사이트의 일관성을 높일 수 있어요. 위 모범 사례를 따르면 방문자와 검색 엔진 모두 새 주소로 자연스럽게 이동해요.

301 리다이렉트는 상단 메뉴의 **사이트** > **URL 리다이렉트**에서도 만들 수 있어요.
