# 파이프라인 이해하기

**파이프라인**을 쓰면 영업이나 서비스 과정의 각 단계에서 기회가 어떻게 진행되는지 한눈에 볼 수 있어요. 이 문서에서는 파이프라인의 개념과 단계 편집·삭제 방법, 활용 예시를 안내해요.

## 개요

파이프라인은 리드나 고객이 시작부터 끝까지 어디까지 왔는지 보여 주는 시각적인 워크플로우 도구예요. 기회는 정해진 단계를 차례로 거쳐요. 그래서 팀이 지금 해야 할 일과 진행이 막힌 곳을 쉽게 알 수 있어요.

{% hint style="info" %}
**새로워진 파이프라인 화면 (실험실)**

파이프라인 페이지에 새 디자인이 적용되어 더 깔끔하고 일관된 화면으로 쓸 수 있어요. 이 화면을 켜려면 **서브 계정 > 실험실**로 이동하세요.
{% endhint %}

파이프라인은 아래 경로에서 열 수 있어요.

**서브 계정 > 기회 관리**(Opportunities) **> 파이프라인**

## 파이프라인이 필요한 이유

파이프라인을 쓰면 다음과 같은 점이 좋아요.

- **현황을 한눈에 파악해요**

  모든 기회가 지금 어느 단계에 있는지 바로 확인할 수 있어요.
- **진행 방식을 통일해요**

  리드나 고객이 거치는 과정을 같은 기준으로 맞출 수 있어요.
- **업무 효율이 올라가요**

  단계가 바뀔 때 후속 연락, 알림, 업무 배정을 자동화할 수 있어요.
- **성과를 추적해요**

  전환율을 확인하고, 막히는 구간을 찾고, 파이프라인 전체 상태를 가늠할 수 있어요.

## 파이프라인 단계

파이프라인은 여러 **파이프라인 단계**로 이루어져 있어요. 각 단계는 영업 과정이나 고객 여정의 한 걸음을 뜻해요. 기회는 진행될수록 왼쪽에서 오른쪽으로 이동해요.

단계 이름은 무엇을 하는 단계인지 분명하게 정하세요. 그래야 기회를 언제 다음 단계로 옮겨야 하는지 누구나 알 수 있어요.

## 파이프라인과 단계 편집하기

## 파이프라인 단계 삭제하기

이제 파이프라인 단계를 삭제할 때 기존 기회를 잃지 않고 **다른 단계로 옮길 수 있어요.**

### 작동 방식

1. **기회 관리 > 파이프라인**으로 이동하세요.
2. 편집할 파이프라인을 여세요.
3. 삭제할 단계 옆의 **삭제** 아이콘을 클릭하세요.
4. 기존 기회를 옮길 단계를 선택하세요.
5. 삭제를 확인하세요.

삭제한 단계에 있던 기회는 선택한 단계로 자동으로 옮겨져요.

## 파이프라인 단계 예시

### 예시: 영업 파이프라인

- **리드 확보** – 폼, 전화, 채팅으로 들어온 새 문의
- **자격 확인** – 예산, 필요, 적합성을 확인하는 단계
- **예약 완료** – 상담 통화나 데모가 잡힌 단계
- **제안서 / 협상** – 제안을 전달하고 협의하는 단계
- **마무리** – 기회를 고객전환성공 또는 고객전환실패로 표시하는 단계

### 예시: 서비스 업종 파이프라인

- 신규 문의
- 상담 통화 예약 완료
- 서비스 또는 패키지 선택
- 결제 완료
- 온보딩

{% hint style="info" %}
**팁:** 단계 이름은 해야 할 행동이 드러나게 짓고, 다음 단계로 넘어가는 기준을 분명히 정해 두세요.

예시: 캘린더에서 미팅이 확정된 뒤에만 기회를 *예약 완료* 단계로 옮겨요.
{% endhint %}

## 활용 팁

### 단순하게 유지하세요

꼭 필요한 단계만 두세요. 단계가 너무 많으면 업무가 느려지고 흐름도 알아보기 어려워요.

### 자동화를 똑똑하게 쓰세요

파이프라인과 연결한 자동화로 수작업을 줄일 수 있어요.

- 기회가 한 단계에 너무 오래 머물면 후속 연락을 보내요.
- 기회가 주요 단계에 도달하면 업무를 배정해요.

### 정기적으로 점검하세요

매주 또는 매월 아래 내용을 살펴보세요.

- 오래된 기회를 제거해요.
- 업무 방식이 달라지면 단계 정의도 함께 고쳐요.
- 전환 데이터와 성과 추이를 확인해요.

## 데이터를 활용해 개선하기

파이프라인은 정리 도구일 뿐 아니라 비즈니스를 이해하는 데도 도움이 돼요. 파이프라인 리포팅으로 다음 질문에 답해 보세요.

- 기회가 가장 많이 이탈하는 구간은 어디인가요?
- 가장 오래 걸리는 단계는 무엇인가요?
- 단계별 고객전환성공률은 얼마인가요?

이렇게 얻은 정보로 워크플로우와 전환율을 계속 개선할 수 있어요.

## 자주 쓰는 활용 사례

- **부동산**

  신규 리드 → 매물 방문 → 제안 → 계약 체결 → 종료됨
- **코칭**

  문의 → 상담 통화 → 프로그램 선택 → 결제 → 온보딩
- **에이전시 고객 관리**

  리드 → 전략 상담 → 제안서 → 계약 → 온보딩 완료

이 예시들은 대부분의 업종에 맞게 바꿔 쓸 수 있어요.

## 자주 묻는 질문

### 파이프라인 단계를 삭제하면 기회도 사라지나요?

아니요. 단계를 삭제할 때 기존 기회를 옮길 다른 단계를 선택할 수 있어요.

### 새로워진 파이프라인 화면을 꼭 써야 하나요?

아니요. 지금은 선택 사항이에요. **서브 계정 > 실험실**에서 켤 수 있어요.

### 파이프라인 기능이 달라졌나요?

핵심 기능은 달라지지 않았어요. 화면이 개선되었고, 단계를 더 안전하게 관리할 수 있게 바뀐 점이 달라요.

### 기존 자동화도 그대로 작동하나요?

네. 파이프라인과 연결된 기존 자동화와 트리거는 모두 평소처럼 작동해요.
