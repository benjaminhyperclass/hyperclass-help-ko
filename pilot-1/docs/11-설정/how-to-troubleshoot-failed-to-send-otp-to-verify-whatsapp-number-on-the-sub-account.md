# 서브 계정에서 왓츠앱 번호 인증 OTP가 전송되지 않을 때

서브 계정에서 왓츠앱 번호를 인증하는데 OTP(일회용 비밀번호)가 오지 않는다면, 이 문서에서 원인을 확인하고 해결할 수 있어요.

## 문제가 생기는 원인

OTP 인증이 실패하는 가장 흔한 이유는 등록하려는 전화번호가 이미 왓츠앱 비즈니스 앱이나 일반 왓츠앱 메신저에 등록되어 있기 때문이에요. 하나의 번호는 한 번에 하나의 왓츠앱 플랫폼에서만 사용할 수 있어요.

## 번호가 이미 등록되어 있는지 확인하기

아래 두 곳에서 해당 번호가 지금 사용 중인지 확인해 보세요.

- 왓츠앱 비즈니스 앱
- 일반 왓츠앱 메신저

번호가 이미 등록되어 있으면 온보딩 과정에서 왓츠앱이 OTP 전송을 막아요.

번호가 왓츠앱에 등록되어 있는지 확인하는 방법은 두 가지예요.

### 방법 1: 왓츠앱 공식 채팅 링크(Click to Chat) 사용하기

1. 브라우저를 열어요.
2. 주소창에 아래 URL을 입력하세요. `<국가코드><전화번호>` 자리에는 국가 코드를 포함한 전체 번호를 넣어요.

   ```
   https://wa.me/<국가코드><전화번호>
   ```

   예시:

   ```
   https://wa.me/919876543210
   ```

3. Enter를 눌러요.

**결과 확인하기**

- 왓츠앱이 열리면 해당 번호가 왓츠앱에 등록되어 있다는 뜻이에요. 개인용인지 비즈니스용인지는 이것만으로 알 수 없어요.
- "Phone number shared via url is invalid"라는 메시지가 보이면 해당 번호가 왓츠앱에 등록되어 있지 않다는 뜻이에요.

### 방법 2: 왓츠앱 앱에서 확인하기

1. 확인할 번호를 휴대폰 연락처에 저장해요.
2. 왓츠앱을 열어요.
3. 새 채팅을 시작하고 저장한 연락처를 검색해요.

**결과 확인하기**

- 연락처가 나타나면 해당 번호가 왓츠앱에 등록되어 있어요.
- 연락처가 나타나지 않으면 등록되어 있지 않아요.

**비즈니스 앱 사용 여부 확인하기**

- 상대 프로필에 **비즈니스 계정** 또는 "인증된 비즈니스(Verified Business)"가 표시되면, 그 번호는 왓츠앱 비즈니스에 등록되어 있어요.
- 비즈니스 계정에는 보통 아래 정보가 표시돼요.
  - 비즈니스 이름
  - 비즈니스 카테고리
  - 카탈로그(없을 수도 있어요)

## 해결 방법

아래 중 하나를 선택하세요.

### 옵션 1: 다른 전화번호 사용하기 (권장)

1. 왓츠앱에 등록된 적이 없는 새 전화번호를 준비해요.
2. 새 번호로 온보딩을 진행해요.

### 옵션 2: 기존 왓츠앱 계정 삭제하기

꼭 같은 번호를 써야 한다면 아래 순서를 신중하게 따라 하세요.

1. 해당 번호로 모바일 기기에 왓츠앱(비즈니스 앱 또는 일반 메신저)을 설치해요.
2. 왓츠앱을 열고 **설정**으로 이동해요.
3. **설정 > 계정 > 계정 삭제**를 선택해요.
4. 모바일 기기에서 왓츠앱 계정 삭제를 확인해요.
5. 몇 분 기다린 뒤, 서브 계정에서 온보딩과 OTP 인증을 다시 시도해요.

{% hint style="warning" %}
왓츠앱 계정을 삭제하면 해당 번호와 연결된 채팅 기록과 데이터가 영구적으로 삭제돼요. 삭제하기 전에 꼭 필요한 내용은 미리 백업해 두세요.
{% endhint %}

## 그래도 OTP가 오지 않을 때

아래 두 가지에 모두 해당하는데도 OTP를 받을 수 없다면 하이퍼클래스 고객지원에 문의하세요.

- 해당 번호가 왓츠앱이나 왓츠앱 비즈니스에 등록되어 있지 않아요.
- 그런데도 OTP가 오지 않아요.

문의할 때 아래 정보를 함께 보내 주세요.

- 전화번호 (국가 코드 포함)
- 서브 계정 ID
- OTP 인증 중 나타난 화면 스크린샷 또는 정확한 오류 메시지
- OTP 전송이 실패한 대략적인 시간
