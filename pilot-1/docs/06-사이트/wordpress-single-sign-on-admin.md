# WordPress 싱글 사인온(SSO)으로 WP Admin에 바로 접속하기

**WP Admin** 버튼을 누르면 WordPress 관리자 화면에 한 번에 로그인할 수 있어요. 아이디와 비밀번호를 따로 입력하지 않아도 돼서, 여러 WordPress 사이트를 관리할 때 특히 편해요.

[동영상](https://www.youtube.com/embed/b8niIpmUbf8?&wmode=opaque)

## 주요 특징

- **한 번에 로그인**: WordPress 대시보드에서 버튼 하나만 누르면 WP Admin이 바로 열려요.
- **싱글 사인온(SSO)**: 비밀번호를 입력하거나 노출하지 않고도 안전하게 로그인할 수 있어요.
- **별도 플러그인 불필요**: 추가 플러그인을 설치하지 않아도 WordPress와 매끄럽게 연결돼요.

## 이럴 때 편해요

- **에이전시**: 여러 고객사의 웹사이트를 관리한다면, 비밀번호를 일일이 기억하지 않아도 각 사이트의 WP Admin을 빠르게 열 수 있어요.
- **사이트 운영자**: 내 사이트 하나만 관리하더라도 로그인 과정 없이 버튼 한 번으로 WP Admin에 들어갈 수 있어요.

## 사용 방법

1. 하이퍼클래스에 로그인한 뒤, **대시보드로 이동**을 선택해 WordPress 대시보드를 여세요.

   ![WordPress 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036344521/original/ElAzZg_lJq6zOxBf3_9nSBAlXhNcF2u3VA.png?1731329783)

2. 각 사이트 옆에 있는 **WP Admin** 버튼을 찾으세요.

   ![사이트 옆의 WP Admin 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036344537/original/eH98xg4l8ybOKn_6W_mU1nmIkBXZTtAqFg.png?1731329799)

3. **WP Admin** 버튼을 누르세요. 로그인 화면 없이 바로 WP Admin으로 이동해요.

   ![WP Admin으로 바로 접속한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036345893/original/HNoDROTwXv9oyHABA8LCsLgzLGaxNVHXTg.png?1731330733)

이제 클릭 한 번으로 안전하게 WordPress 관리자 화면에 들어가 사이트를 관리할 수 있어요. 싱글 사인온 덕분에 비밀번호 없이도 로그인 정보가 안전하게 보호돼요.
