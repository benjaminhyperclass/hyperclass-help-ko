# 메가 메뉴 헤더 추가하기

하이퍼클래스 비주얼 에디터에서 미리 만들어진 메가 메뉴 헤더를 퍼널이나 웹사이트에 추가하는 방법을 안내해요. 코드를 짜거나 복잡하게 설정하지 않아도, 사이트 내비게이션을 깔끔하게 정리할 수 있어요.

## 메가 메뉴 헤더란?

메가 메뉴 헤더는 퍼널이나 웹사이트 페이지에 바로 붙여 쓸 수 있도록 미리 만들어 둔 내비게이션 영역이에요. 드롭다운 메뉴가 구조화된 레이아웃으로 펼쳐져서, 카테고리나 링크, 서비스 분야가 많은 웹사이트에 잘 맞아요. 모든 요소를 원하는 대로 바꿀 수 있고, 방문자가 원하는 정보를 더 쉽게 찾도록 도와줘요.

## 메가 메뉴 헤더의 장점

메가 메뉴를 쓰면 복잡한 내비게이션을 처음부터 만들지 않아도 돼서 시간을 아낄 수 있고, 사이트도 더 쓰기 편해져요.

- **바로 쓸 수 있는 디자인**: 전문적으로 구성된 여러 템플릿 중에서 고를 수 있어요.
- **편리한 탐색 경험**: 규모가 크거나 구조가 복잡한 웹사이트에서도 방문자가 원하는 곳을 빠르게 찾아가요.
- **자유로운 레이아웃 편집**: 텍스트, 색상, 간격, 아이콘, 링크 연결 주소를 브랜드에 맞게 바꿀 수 있어요.
- **빠른 적용**: 끌어다 놓고 게시하면 끝이에요. 전문 지식이 필요 없어요.
- **일관된 모양**: 여러 페이지에 같은 내비게이션을 두어 사이트 전체의 통일감을 지킬 수 있어요.

## 메가 메뉴 헤더 추가하는 순서

1. 하이퍼클래스 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. 메가 메뉴를 넣을 **퍼널 또는 웹사이트**를 선택하고, 비주얼 에디터에서 해당 페이지를 여세요.
3. 비주얼 에디터 오른쪽 위에 있는 **요소 추가** 버튼을 클릭하세요.
4. 사이드바 메뉴에서 **프리빌트 섹션**(Prebuilt Sections)을 선택하세요.
5. 메가 메뉴 디자인 목록을 둘러보세요. **클릭하여 미리보기**로 디자인을 확인한 뒤, 내 사이트 구조에 가장 잘 맞는 것을 선택하세요.
6. 비주얼 에디터에서 메뉴를 내 사이트에 맞게 편집하세요. 아래 작업을 할 수 있어요.
   - 링크 텍스트와 연결 주소 편집
   - 색상, 글꼴, 간격 조정
   - 아이콘과 하위 카테고리 추가 또는 제거
   - 필요에 따라 열이나 콘텐츠 블록 순서 바꾸기
7. 레이아웃과 스타일이 마음에 들면 **저장**을 클릭한 다음, 페이지를 **게시**하세요.

## 자주 묻는 질문

### 같은 메가 메뉴를 여러 페이지에서 쓰려면 어떻게 하나요?
편집을 마친 섹션을 저장해 두면 다른 퍼널이나 웹사이트 페이지에서도 다시 불러와 쓸 수 있어요. 이렇게 하면 모든 페이지에서 같은 내비게이션을 유지할 수 있어요.

### 메가 메뉴 템플릿은 모바일에서도 잘 보이나요?
네. 메가 메뉴 헤더는 모바일 환경을 고려해 만들어져서, 작은 화면에서는 자동으로 크기와 배치가 조정돼요.

### 메가 메뉴에 원하는 링크나 버튼을 직접 넣을 수 있나요?
네. 메가 메뉴 요소에서 내부 페이지나 외부 URL로 연결할 수 있고, 팝업이나 특정 동작을 실행하도록 설정할 수도 있어요.

### 메가 메뉴의 열 개수를 바꿀 수 있나요?
네. 비주얼 에디터에서 열을 추가하거나 제거하고, 너비를 바꾸고, 콘텐츠 블록 순서를 다시 배치할 수 있어요.

### 메가 메뉴에 드롭다운 애니메이션도 적용되나요?
네. 미리 만들어진 디자인 중에는 드롭다운 동작이 기본으로 들어 있는 것이 많아요. 편집하면서 그 동작을 켜거나 바꿀 수 있어요.

## 다음 단계

- 홈페이지에 메가 메뉴를 추가해 최상위 내비게이션을 개선해 보세요.
- 브랜드의 시각적 정체성에 맞게 디자인을 편집해 보세요.
- 편집한 헤더를 재사용 가능한 섹션으로 저장해 두면 사이트 곳곳에 쉽게 복제해 쓸 수 있어요.
- 모바일 기기에서도 확인해서 방문자가 불편 없이 이용하는지 점검해 보세요.
