# Facebook·Instagram 채팅 위젯 만들기

웹사이트 방문자가 Messenger나 Instagram DM으로 바로 대화를 시작할 수 있는 채팅 위젯을 만드는 방법을 안내해요. 방문자가 이미 쓰고 있는 Meta 채널에서 인사를 건네면 응답률을 높이고 후속 대화도 쉽게 이어 갈 수 있어요.

## Facebook·Instagram 채팅 위젯이란?

Facebook 채팅과 Instagram 채팅은 채팅 위젯 안에서 **채널별로 나뉜 위젯 유형**이에요. 웹사이트 안에서 메신저 창을 열지 않고, 방문자를 선택한 Meta 채널(Messenger 또는 Instagram DM)로 **이동**시켜요. 그래서 대화는 Facebook이나 Instagram 안에서 그대로 이어져요.

위젯 편집 화면에는 유형별 설정 패널이 따로 있어요. 여기서 사용할 Facebook 페이지나 Instagram 비즈니스 계정을 고르거나 연결해요.

## 이런 점이 좋아요

- **간편한 대화 시작**: 방문자는 사이트 안에 별도의 채팅 대화를 만들지 않고 Messenger나 Instagram DM에서 바로 이어서 대화해요.
- **선호 채널에서 만나기**: 고객이 평소 메시지를 주고받는 소셜 플랫폼에서 대화할 수 있어요.
- **높은 이용률**: 방문자가 이미 쓰는 Facebook·Instagram 로그인과 앱을 그대로 활용해요.
- **한곳에서 확인**: 모든 Meta 대화를 문자(SMS), 이메일, WhatsApp 대화와 함께 하이퍼클래스의 **대화**(Conversations) 받은편지함에서 확인할 수 있어요.
- **기기를 바꿔도 이어지는 대화**: 대화가 사용자의 Messenger·Instagram 앱에 남아 있어서, 기기를 바꿔도 이전 내용이 그대로 보여요.

## Facebook·Instagram 채팅 위젯 설정하기

아래 단계를 따라 Facebook 또는 Instagram 채팅 위젯을 만들고 웹사이트에 설치해 보세요.

### 1단계: 새 위젯 만들기

1. **사이트 > 채팅 위젯**으로 이동해요.
2. 파란색 **신규** 버튼을 눌러요.

![채팅 위젯 화면에서 신규 버튼 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060348475/original/elOj_5dm-_s2o0sUdzfnGJj623Dq3ovuUw.png?1765388725)

### 2단계: 채팅 유형 선택하기

1. **채팅 유형 선택** 팝업에서 **Facebook 채팅** 또는 **Instagram 채팅**을 골라요.
2. Facebook 또는 Instagram 계정은 연결되어 있는데 선택한 페이지가 없다면, 페이지 선택 창이 열려요. 위젯에 사용할 페이지를 골라요.

![채팅 유형 선택 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350088/original/yO7fZsVYCVXXsGVHatbDlcCq6bgQDfR5Vg.jpeg?1765390979)

{% hint style="warning" %}
**중요**: 서브 계정에 해당 계정이 이미 연결되어 있어야 이 화면에서 Facebook 채팅이나 Instagram 채팅을 고를 수 있어요. 아직 연결한 계정이 없으면 팝업 안의 링크가 계정 연결 화면(예: 연동 메뉴의 **Facebook 연결**, **Instagram 연결**)으로 안내해요. 링크를 눌러 계정을 연결한 뒤, 이 화면으로 돌아와 채팅 유형을 선택하세요.
{% endhint %}

![계정 연결을 안내하는 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350092/original/jsVdwN__K5cjKScy1fhL_BpcM8DtY01HBQ.png?1765390994)

### 3단계: 위젯 꾸미기

1. **스타일**, **채팅 창**, **메시지** 탭에서 색상, 인사말, 런처 아이콘 등을 브랜드에 맞게 설정해요. 디자인 옵션을 더 보고 싶다면 채팅 위젯 꾸미기 관련 문서를 참고하세요.
2. 위젯에 연결된 Facebook·Instagram 계정을 바꾸려면 **채팅 창** 탭에서 변경해요.
3. 페이지나 계정을 더 추가해야 하면, Facebook/Instagram 계정을 연결하는 버튼을 눌러 새 연결 창을 열고 추가해요.
4. 필요한 설정을 마쳤으면 위젯을 저장해요.

![채팅 창 탭에서 연결 계정 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350150/original/hCpviuit3NtfBrynsJe5_HGgO4PThscLtA.png?1765391093)

### 4단계: 위젯 설치하기

1. 외부 사이트에 설치하려면 **코드 받기**를 눌러요.
2. 위젯을 보여 주고 싶은 웹사이트나 퍼널의 위치에 코드 조각을 붙여 넣어요.
3. 워드프레스 사이트에 설치한다면 **워드프레스용 받기**를 눌러요.

하이퍼클래스의 퍼널 및 웹사이트 빌더에서도 이 위젯을 바로 설치할 수 있어요. 설치 방법은 채팅 위젯 설치 관련 문서에서 자세히 볼 수 있어요.

![코드 받기 버튼으로 위젯 설치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060349629/original/tkuC8Q7A2ZfTxvzZkN4MegGTa8PChiaJaw.png?1765390165)

## 자주 묻는 질문

### 위젯 하나에서 Facebook과 Instagram을 함께 쓸 수 있나요?
아니요. 위젯 하나에는 채널 하나만 연결할 수 있어요. 여러 채널을 한 번에 보여 주는 버블이 필요하면 올인원 채팅 위젯을 사용하세요.

### Facebook·Instagram 대화도 하이퍼클래스 대화 메뉴에 보이나요?
네. Facebook·Instagram 연동과 권한이 올바르게 연결되어 있고 메시지 접근이 활성화되어 있다면 **대화**에서 확인할 수 있어요.

### 들어온 메시지에 자동화를 적용할 수 있나요?
네. 워크플로우의 **Facebook Message**(Facebook 메시지) 트리거나 **Instagram Message**(Instagram 메시지) 트리거를 사용하면 태그를 붙이거나 담당자를 지정하고, 대화를 원하는 곳으로 분류할 수 있어요.

### 방문자가 Facebook이나 Instagram에 로그인해 있어야 하나요?
네. 로그인하지 않은 방문자에게는 Meta 로그인 화면이 먼저 열려요.

### Facebook·Instagram 위젯은 스타일과 메시지 설정이 다른가요?
아니요. 스타일과 위치 설정은 다른 채팅 유형과 똑같이 동작해요. 다른 점은 대화가 이루어지는 **장소**예요. 웹사이트 안이 아니라 Meta 채널에서 대화가 이어져요.
