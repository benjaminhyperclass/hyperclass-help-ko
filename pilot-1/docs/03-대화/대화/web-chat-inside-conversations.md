# 대화에서 웹 채팅 사용하기

웹사이트 방문자가 채팅 위젯으로 보낸 메시지를 **대화**(Conversations) 받은편지함에서 바로 확인하고 답할 수 있어요. 이 문서에서는 웹 채팅이 어떻게 동작하는지, 채팅 위젯은 어떻게 설정하는지, 들어온 웹 채팅 대화는 어떻게 관리하는지 알려 드려요.

{% hint style="warning" %}
**중요:** 웹 채팅은 라이브 채팅과 다릅니다. 두 기능을 쉽게 구분할 수 있도록 플랫폼 전체에서 채널 이름을 통일했어요.
{% endhint %}

## 웹 채팅은 이렇게 동작해요

웹사이트 방문자는 채팅 위젯으로 바로 대화를 시작할 수 있어요. 방문자가 보낸 메시지는 서브 계정의 **대화** 받은편지함으로 곧바로 들어와요.

**대화**에서는 웹 채팅 메시지가 실시간으로 보여요. 팀원은 대화를 열어 바로 답하고, 담당자를 지정하고, 다른 채널의 대화와 똑같이 관리할 수 있어요.

웹사이트에서 오는 대화가 한곳에 모이니, 여러 플랫폼을 오갈 필요가 없어요.

## 웹 채팅 설정하기

웹 채팅을 쓰려면 채팅 위젯을 만들고 설정해야 해요.

1. **사이트 > 채팅 위젯**으로 이동하세요.
2. **+ 새로 만들기**를 클릭해 위젯을 만드세요.

   ![사이트 > 채팅 위젯 화면에서 새 위젯 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064712895/original/YYkwwOk7UdKbICVBGF7Bi966rwqh1rMOTA.png?1770826807)

   ![채팅 위젯 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713569/original/FxlWfSBKlVY305W8RQ9nPQJEc-ITSM1Jjw.png?1770827200)

3. 채팅 유형에서 **실시간 채팅**을 선택하세요. 설정 화면에는 '실시간 채팅'이라고 보이지만, 이 옵션이 웹사이트 메시지를 **대화**로 보내 주는 웹 채팅 채널을 설정해요.
4. 필요에 맞게 위젯 설정을 바꾸세요.

   ![채팅 위젯 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713593/original/OC_HIOJgXVHQfE8HqK9tfrSU1lMGHmru3Q.png?1770827226)

   설정할 수 있는 항목은 다음과 같아요.

   - **인트로 메시지**
   - 상담원 아바타와 브랜딩
   - 일정 시간 응답이 없을 때 보내는 안내 메시지
   - 채팅 시간 초과 메시지

5. 위젯을 저장하세요.
6. 안내되는 스크립트를 복사해 웹사이트의 푸터나 body 영역에 붙여 넣으세요. WordPress를 쓴다면 하이퍼클래스 플러그인을 설치하면 위젯을 사용할 수 있어요.

설치가 끝나면 방문자가 웹사이트에서 웹 채팅 메시지를 보낼 수 있어요.

## 웹 채팅 대화 관리하기

방문자가 메시지를 보내면 **대화**에 바로 나타나요.

![대화 받은편지함에 들어온 웹 채팅 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713051/original/M9s2JNrW0_rpY2_OZcdoRPmYeArr7JCNBA.png?1770826888)

받은편지함에서 채팅 아이콘이 붙은 대화가 웹 채팅이에요. 대화를 열면 실시간으로 답할 수 있어요. 담당자는 직접 지정할 수도 있고, 워크플로우나 담당자 지정 규칙으로 자동 배정할 수도 있어요.

웹 채팅 메시지만 모아 보려면 **대화**의 필터를 사용하세요.

![대화에서 웹 채팅 필터 적용하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713123/original/LT60iImtWOgmPVqFgRHF9JM-KmgcemlLng.png?1770826906)

**마지막 메시지 채널**에서 **라이브 채팅**을 선택하고 필터를 적용하세요. 웹사이트에서 시작된 웹 채팅 대화만 표시돼요.

대화가 끝나면 **채팅 종료**를 사용할 수 있어요. 위젯에 설정한 무응답 시간이 지나면 채팅이 자동으로 종료되기도 해요.

## 자주 묻는 질문

### 웹 채팅 메시지가 대화에 나타나게 하려면 어떻게 하나요?
채팅 위젯을 설치하고 활성화한 다음, **사이트 > 채팅 위젯**에서 **실시간 채팅**을 선택하세요. 이후 메시지는 자동으로 **대화**에 들어와요.

### 웹 채팅인데 설정 화면에는 왜 '실시간 채팅'이라고 나오나요?
현재 위젯 설정 화면에서는 '실시간 채팅'이라는 이름을 쓰고 있어요. 하지만 실제로는 웹사이트 대화를 **대화**로 보내 주는 웹 채팅 채널을 설정하는 거예요.

### 웹 채팅 메시지에 아무도 답하지 않으면 어떻게 되나요?
설정해 둔 시간 안에 응답이 없으면 안내 메시지가 나가요. 이 메시지로 방문자에게 연락처를 남겨 달라고 요청하면, 나중에 이어서 연락할 수 있어요.

### 웹 채팅 대화를 특정 팀원에게 배정할 수 있나요?
네. 직접 배정할 수도 있고, 워크플로우나 담당자 지정 규칙으로 자동 배정할 수도 있어요.

### 웹 채팅 대화만 따로 볼 수 있나요?
네. **대화**의 필터에서 메시지 채널 항목의 **라이브 채팅**을 선택하세요.
