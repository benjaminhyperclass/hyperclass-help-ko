# 모바일 앱에서 템플릿으로 견적서 만들기 (v3.98.1)

하이퍼클래스 웹에서 팀이 만들어 둔 견적서 템플릿을 모바일 앱에서 불러와 새 견적서를 만드는 방법을 설명해요. 외근 중이거나 고객과 함께 있을 때도 몇 분 안에 견적서를 만들어 보낼 수 있어요.

[동영상](https://www.youtube.com/embed/wJgy67\_h1gU?&wmode=opaque)

## 모바일 견적서 템플릿이란?

모바일 앱의 **견적서**(Estimates) 화면에서 웹에 저장된 템플릿을 골라 새 견적서를 시작할 수 있어요. 모바일 앱이 웹에서 만든 템플릿을 그대로 불러오기 때문에, 레이아웃·항목·약관을 처음부터 다시 만들 필요가 없어요. 담당자마다 같은 형식으로, 실수 없이 견적서를 만들 수 있어요.

## 이럴 때 편해요

템플릿은 빠르게 만들어야 할 때, 브랜드 형식을 맞춰야 할 때, 가격 구성이 정해져 있을 때 특히 유용해요. 빌더에서 처음부터 만들지, 템플릿을 쓸지 고를 때 참고하세요.

- **시간 절약:** 미리 만든 템플릿으로 몇 번만 탭해서 견적서를 만들 수 있어요.
- **일관성:** 담당자가 달라도 브랜딩, 구성, 가격 표기 형식을 똑같이 유지할 수 있어요.
- **이동 중에도 작업:** 고객과 함께 있는 자리에서 바로 견적서를 만들어 보낼 수 있어요.
- **별도 설정 없이 사용:** 웹에서 만든 템플릿이 모바일에서 자동으로 보여요.
- **전문적인 견적서:** 직접 입력할 때 생기는 실수를 줄이고 깔끔한 견적서를 보낼 수 있어요.

## 사용 전 확인할 사항

미리 확인해 두면 나중에 설정 문제를 줄일 수 있어요.

- 모바일 앱 버전: **하이퍼클래스 모바일 앱 v3.98.1** 이상이어야 해요.
- 화이트라벨 앱을 쓰고 있다면 하이퍼클래스 고객지원에 문의해 **v3.98.1 업데이트를 요청**하세요.
- 템플릿은 **웹에서 만들고 관리**해요. 모바일에서는 템플릿을 **사용**만 할 수 있고, 만들거나 편집하거나 삭제할 수는 없어요.
- 사용하는 계정에 해당 서브 계정과 **결제 > 견적서** 메뉴에 대한 접근 권한이 있어야 해요.

## 템플릿으로 견적서 만들기

아래 순서대로 따라 하면 첫 견적서를 템플릿으로 만들 수 있어요. 앱 버전이 맞는지 먼저 확인하세요.

1. 모바일 앱에 로그인한 뒤 사용할 서브 계정을 열고, 왼쪽 내비게이션 메뉴에서 **견적서**를 누르세요.

   ![모바일 앱 왼쪽 메뉴에서 견적서 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051458055/original/EknmG3cw1HGZlz4TVtwgxKFSO9fUsYTxYw.png?1755011004)

2. 견적서 첫 화면에 **견적서**와 **템플릿** 두 개의 탭이 보여요. **템플릿** 탭으로 이동하세요.

   ![견적서 화면의 템플릿 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051458163/original/I4qq-ZdvsvkOnM4l2pjDzhyofEj9j3YFIQ.png?1755011036)

3. 사용할 템플릿을 선택하면 그 템플릿으로 바로 견적서를 만들 수 있어요.

## 자주 묻는 질문

### 모바일 앱에서 견적서 템플릿을 만들거나 편집할 수 있나요?
아니요. 템플릿은 **웹**에서 만들고 관리해요. 모바일 앱에서는 그 템플릿을 사용해 새 견적서를 만들 수 있어요.

### 웹에서 만든 템플릿이 모바일 앱에도 자동으로 보이나요?
네. 웹에서 만든 템플릿은 모바일 앱의 **템플릿** 탭에 나타나요.

### 어떤 버전부터 이 기능을 쓸 수 있나요?
**하이퍼클래스 모바일 앱 v3.98.1** 이상에서 쓸 수 있어요. 화이트라벨 앱은 하이퍼클래스 고객지원에 **v3.98.1 업데이트를 요청**한 뒤에 쓸 수 있어요.

### 템플릿을 고른 뒤에 항목을 바꿀 수 있나요?
네. 보내기 전에 새 견적서에서 수량이나 가격 같은 항목을 편집할 수 있어요.

### 템플릿 탭이 보이지 않아요. 무엇을 확인해야 하나요?
다음 세 가지를 확인하세요.
- 앱 버전이 **v3.98.1** 이상인지
- 올바른 **서브 계정**에 들어와 있는지
- 사용하는 계정에 **결제 > 견적서** 접근 권한이 있는지

화이트라벨 앱이라면 v3.98.1 버전이 배포되었는지도 확인하세요.

### 템플릿의 **첨부파일**도 모바일에서 그대로 적용되나요?
**첨부파일**은 일반 견적서·템플릿과 같은 규칙을 따라요. 자세한 내용과 제한 사항은 하이퍼클래스 고객지원에 문의하세요.

### 고객이 견적서를 수락하는 즉시 결제하게 하려면 어떻게 하나요?
모바일 앱의 견적서에서 직접 결제를 사용하세요. 고객이 한 번에 수락하고 결제할 수 있어요. 자세한 방법은 [모바일 앱 견적서에서 직접 결제 사용하기](../../30-모바일-데스크톱/Mobile-Payments/how-to-use-direct-payments-in-estimates-in-the-mobile-app.md)를 참고하세요.
