# 워크플로우 액션: 예약하기

**예약하기** 액션은 트리거가 실행될 때 선택한 캘린더에 예약을 자동으로 만들어 줘요. 폼 제출, 인바운드 웹훅, 연락처 정보 변경 같은 이벤트가 생기면 후속 일정을 사람이 직접 잡지 않아도 돼요.

## 예약하기 액션이란?

**예약하기** 액션은 지정한 캘린더에 지정한 시간으로 새 예약을 만들어요. 워크플로우에 이 액션을 넣으면 트리거 이벤트가 생길 때마다 예약이 자동으로 만들어져요. 특정 트리거로 예약을 자동화하고 싶은 비즈니스에 잘 맞아요.

**꼭 알아 둘 점**

- 예약을 받을 캘린더를 반드시 선택해야 해요.
- 팀원은 **Calendar Default**(캘린더 기본값, 예: 라운드 로빈)로 두거나 특정 팀원으로 지정할 수 있어요.
- 예약 시간은 트리거 데이터(웹훅 페이로드, 폼 필드 등)에서 가져올 수 있어요. 들어오는 날짜·시간 형식이 지원 형식과 다르면 **Date Time Formatter**(날짜·시간 형식 변환) 액션을 사용하세요.
- 예약 가능한 팀원이 없고 가용 시간 무시 옵션이 꺼져 있으면 예약이 만들어지지 않아요.

{% hint style="warning" %}
**반복**이 활성화된 캘린더는 **예약하기** 액션에서 선택할 수 없어요.
{% endhint %}

## 이럴 때 편해요

실제 예약 가능 시간을 지키면서 예약을 자동으로 만들고, 성공·실패에 따라 다음 단계를 나눌 수 있어요.

- **빠른 후속 대응**: 폼, 채팅, 웹훅에서 들어온 요청을 자동으로 예약해요.
- **전환율 향상**: 고객의 관심이 높을 때 바로 일정을 확정할 수 있어요.
- **유연한 담당자 지정**: 캘린더 기본값(예: 라운드 로빈)을 따르거나 특정 팀원을 지정해요.
- **확실한 후속 처리**: **예약 완료** 결과에 따라 확인 메시지, 리마인드, 대체 액션을 나눠 실행해요.

## 예약하기 액션 설정하기

**예약하기** 단계를 추가하면 워크플로우가 대상 캘린더와 연결돼요. 언제, 누구와 예약을 만들지도 이 단계에서 정해요.

### 1단계: 자동화로 이동하기

**자동화 > 새 워크플로우 만들기 > 처음부터 만들기**로 이동해요. 그다음 트리거를 추가하세요. 예를 들어 **폼 제출**이나 **Inbound Webhook**(외부에서 데이터를 받는 웹훅)을 쓸 수 있어요.

![워크플로우에 트리거를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052586842/original/0riEYOvbFN-W1cUn2lcfd4jm7A_8xWP-NA.gif?1756384342)

### 2단계: 액션 추가하기

**액션 추가 > 예약하기**를 클릭하세요. **액션 이름**에는 알아보기 쉬운 이름을 입력해요. 예: "영업팀 데모 예약"

![액션 추가에서 예약하기를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052587208/original/PlSK-h6vSCDjLAUPpKBZr9mgvrSW9O0V5Q.png?1756384481)

### 3단계: 캘린더, 팀원, 예약 날짜·시간 설정하기

**캘린더**: 예약을 받을 대상 캘린더를 선택해요.

**팀원**: 예약을 맡을 담당자를 정해요.

- **Calendar Default**(캘린더 기본값): 캘린더에 설정된 배정 규칙(예: 라운드 로빈)을 따라요.
- **특정 팀원**: 한 사람을 직접 지정해요.

**Set Appointment Date & Time**(예약 날짜·시간 설정): 예약 시작 날짜와 시간을 정해요.

- **표준**: 이 워크플로우로 만드는 모든 예약에 같은 날짜·시간을 써요.
- **동적**: 트리거 데이터(웹훅 페이로드, 폼 필드, 커스텀 값 등)에서 날짜·시간을 가져와요.

**동적**을 쓸 때는 날짜·시간 형식이 맞아야 해요. 아래는 **지원 형식**의 예시예요.

- MM-DD-YYYY HH:MM → 12-21-2021 08:30 AM
- DD-MMM-YYYY HH:MM → 21-OCT-2021 08:30 AM

입력 값이 지원 형식과 다르면 **예약하기** 앞에 **Date Time Formatter** 단계를 넣어 형식을 바꿔 주세요.

![캘린더, 팀원, 예약 날짜·시간을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052589247/original/kB3ftIpttgUl3WnvXJc-OGTR13VAvEksbQ.png?1756385194)

{% hint style="warning" %}
**Override availability**(가용 시간 무시) 옵션은 신중하게 쓰세요.

1. 끄면: 예약을 만들기 전에 가용 시간을 확인해요.
2. 켜면: 가용 시간을 확인하지 않고 예약을 만들어요.
{% endhint %}

템플릿에 **액션 설명**이나 내부 메모 입력란이 있으면 필요에 따라 적어 두세요.

## 자주 묻는 질문

### 이 액션은 캘린더의 가용 시간을 지키나요?
네, 지켜요. 단, **Override availability**를 켜면 가용 시간을 확인하지 않아요.

### 예약 성공·실패에 따라 다음 단계를 나눌 수 있나요?
네, 나눌 수 있어요. **만약** 조건을 추가하고 **예약 완료** 값(참/거짓)을 기준으로 결과를 나누세요.

### 동적 시간에는 어떤 날짜·시간 형식을 쓸 수 있나요?
3단계의 **지원 형식**을 확인하세요. 형식이 다르면 **Date Time Formatter** 단계를 추가하면 돼요.

### 라운드 로빈으로 예약을 배정할 수 있나요?
네, **팀원**에서 **Calendar Default**를 선택하면 캘린더의 배정 규칙을 따라 배정돼요.

### 예약이 실패하면 어떻게 하나요?
거짓(False) 분기를 활용하세요. 팀에 알림을 보내거나, 작업을 만들거나, 다른 시간으로 다시 예약해 볼 수 있어요.

### 예약하기 액션에 제한이 있나요?
**반복**이 활성화된 캘린더는 **예약하기** 액션에서 선택할 수 없어요.
