# 하이퍼클래스 도움말

하이퍼클래스의 기능을 한국어 화면 그대로 따라 할 수 있도록 정리한 가이드예요. 문서에 나오는 메뉴와 버튼 이름은 실제 하이퍼클래스 화면에 보이는 이름과 같아요.

## 처음이라면 이 순서로

1. **궁금한 것부터** — [하이퍼클래스 알아보기](docs/_groups/faq/faq-about.md) · [요금 · 결제](docs/_groups/faq/faq-pricing.md)
2. **첫 세팅** — [가입하면 무엇부터 설정하나요?](docs/00-자주묻는질문/first-setup.md) → [계정 첫 세팅](docs/_groups/getting-started/setup-basics.md)
3. **한국에서 꼭 필요한 연결** — [토스페이먼츠로 원화 결제 받기](docs/43-한국-앱/tosspayments-getting-started.md) · [카카오 커넥터로 카카오톡 상담 받기](docs/43-한국-앱/kaka/README.md)

{% hint style="success" %}
문서 곳곳의 **▶ 영상** 링크를 누르면 무료 창업 챌린지 강의에서 그 장면부터 바로 볼 수 있어요.
{% endhint %}

{% hint style="info" %}
**자동화 › 워크플로우**의 편집 화면(빌더)은 계정에 따라 영어로 보일 수 있어요. 그래서 워크플로우 문서에서는 트리거·액션 이름을 영어로 적고, 처음 나올 때 한국어 뜻을 괄호로 붙였어요.
{% endhint %}
