# 하이퍼클래스 도움말 센터

하이퍼클래스의 모든 기능을 한국어 화면 그대로 따라 할 수 있도록 정리한 가이드예요.
문서에 나오는 메뉴와 버튼 이름은 실제 하이퍼클래스 화면에 보이는 이름과 같아요.

## 처음이라면 여기부터

1. [자주 묻는 질문](docs/00-자주묻는질문/README.md) — 요금제, 처음 세팅 순서, 카카오톡·결제 연동 같은 궁금증
2. **시작하기** — 연락처 가져오기, 예약 캘린더, 첫 퍼널·이메일 캠페인 만들기
3. [한국 전용 앱](docs/43-한국-앱/README.md) — 원화 결제(토스페이먼츠)와 카카오톡 상담(KAKA AI)

## 기능별로 찾기

| 하고 싶은 일 | 볼 곳 |
| --- | --- |
| 고객 정보를 모으고 정리하기 | 연락처 |
| 문자·이메일·채팅·SNS 메시지를 한곳에서 답하기 | 대화 |
| 상담·수업 예약 받기 | 캘린더 · 예약 |
| 영업 단계를 관리하기 | 기회 관리 · 파이프라인 |
| 랜딩 페이지·웹사이트·폼 만들기 | 사이트 |
| 반복 업무를 자동으로 처리하기 | 자동화 · 워크플로우 |
| 결제 받기·인보이스 보내기 | 결제 |
| 이메일·SNS 마케팅 | 이메일 · 마케팅 |
| 온라인 강의·커뮤니티 운영 | 멤버십 · 커뮤니티 |
| AI 상담원·음성 AI 쓰기 | AI 직원 |
| 성과 보기 | 대시보드 · 리포팅 |

왼쪽 메뉴에서 원하는 카테고리를 고르거나, 위쪽 검색창에서 화면에 보이는 메뉴 이름으로 검색해 보세요.

{% hint style="info" %}
**자동화 > 워크플로우**의 편집 화면(빌더)은 영어로 표시돼요. 워크플로우 문서에서는 트리거·액션 이름을 화면과 같은 영어로 적고, 처음 나올 때 뜻을 괄호로 붙였어요.
{% endhint %}
