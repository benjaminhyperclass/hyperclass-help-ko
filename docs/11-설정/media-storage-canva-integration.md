# 미디어 저장소에서 Canva 연동하기

**미디어 저장소**에 Canva를 연결하면 팀원들이 전용 Canva 화면에서 디자인을 바로 볼 수 있어요. 이 문서에서는 연동 방식, 연결 방법, 미디어 저장소에서 Canva 디자인을 쓰는 방법을 설명해요.

## 미디어 저장소의 Canva 연동이란?

Canva 연동은 Canva 계정 하나를 하이퍼클래스 서브 계정 하나에 연결하는 기능이에요. 연결하면 **미디어 저장소** 안의 전용 Canva 화면에서 Canva 디자인을 볼 수 있어요. 이 화면에서 디자인 둘러보기, 내보낸 파일 다운로드, 지원되는 디자인의 Canva 편집기 열기, **My Media**(내 미디어)로 사본 가져오기를 할 수 있어요. **My Media**로 가져온 파일은 하이퍼클래스 곳곳에서 쓸 수 있어요.

## 미디어 저장소 Canva 연동의 장점

- 작업 속도: **미디어 저장소**를 벗어나지 않고 Canva 디자인을 둘러보고, 열고, 다운로드하고, 가져올 수 있어요.
- 자산 통합 관리: 완성한 디자인을 **My Media**로 가져오면 하이퍼클래스 곳곳에서 저장하고 다시 쓸 수 있어요.
- 팀 공유: 연결하고 나면 같은 서브 계정의 모든 사용자가 Canva 자산을 볼 수 있어요.
- 협업 편의: 가져오기를 하면 독립된 자산이 만들어져요. 공유 링크나 수동 다운로드 때문에 생기는 혼선이 줄어요.

## Canva 연동 설정하기

Canva를 올바르게 연결하면 서브 계정에서 디자인을 둘러보고, 파일을 내보내고, 완성한 자산을 **My Media**로 가져올 때 권한 문제가 생기지 않아요.

1. **미디어 저장소**로 이동하세요.
2. **Canva 연결**을 클릭하세요.

   ![미디어 저장소의 Canva 연결 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066028220/original/8ZtlBbA23V07jmwI_JJiGl3s8zTByn7Yag.png?1772469057)
3. 새로 열린 브라우저 탭에서 Canva 로그인(OAuth)을 완료하세요.
4. **허용**을 클릭해 접근 권한을 승인하세요.

   ![Canva 접근 권한 허용 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066028267/original/tI9QrRb9WX9S7tqeaiJC773ppBpd_C5cLA.png?1772469127)
5. **미디어 저장소**로 돌아오면 Canva 버튼이 **연결됨**으로 표시돼요.
6. **My Media** 드롭다운에서 **Canva**를 선택하면 디자인을 보고, 편집하고, 가져올 수 있어요.

   ![My Media 드롭다운에서 Canva 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066028393/original/0ep1BxPsJrWKrtQvnYMVyDahOG8npU_adQ.png?1772469202)

## Canva에서 편집하기

하이퍼클래스에서 편집을 시작하면 새 브라우저 탭에서 Canva 편집기가 열려요. 편집 권한은 서브 계정에 Canva를 연결한 사용자가 누구인지, 그리고 Canva 파일 권한이 어떤지에 따라 달라져요.

편집할 수 있는 항목

- Canva 화면에서 연 Canva 디자인(편집이 허용된 경우)
- 다음 파일 형식의 **My Media** 파일
  - PNG
  - JPG
  - JPEG

편집 제한

- 비공개 Canva 파일은 편집할 수 없어요.
- Canva를 연결한 사용자가 아닌 사람이 Canva 디자인을 편집하려고 하면 다음 메시지가 나와요.

  “**You have view-only access to this media. To make changes, import it into your own storage or reach out to your admin for access.**”

  (이 미디어는 보기만 할 수 있으니, 수정하려면 내 저장소로 가져오거나 관리자에게 권한을 요청하라는 뜻이에요.)

편집 방법

1. **미디어 저장소**에서 디자인 오른쪽 위의 점 세 개 아이콘을 클릭하세요.
2. **Canva에서 편집** 버튼을 클릭하세요.

   ![디자인 메뉴의 Canva에서 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066028873/original/yInQar0nnPrOfqpOcjby44tas5v7Jo6I8g.png?1772469555)

## Canva 디자인 다운로드하기

다운로드하면 Canva에서 디자인을 내보내요. 파일 형식은 페이지 수에 따라 정해져요.

다운로드 형식

- 1페이지 디자인 → PNG
- 여러 페이지 디자인 → PDF

**미디어 라이브러리**에서 Canva 디자인을 내 컴퓨터로 바로 받으려면 디자인 오른쪽 위의 **Download**(다운로드) 버튼을 클릭하세요.

![디자인 오른쪽 위의 다운로드 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066020786/original/w_AeNf0_ySAr7vKtj3PkbTyKkRZBpBnG1A.png?1772464899)

## Canva 디자인을 미디어 라이브러리로 가져오기

가져오기를 하면 **My Media**에 새 독립 자산이 만들어져요. 가져온 파일은 원래 Canva 디자인과 연결되지 않아요. 나중에 Canva에서 디자인을 바꿔도 가져온 사본은 자동으로 바뀌지 않아요.

알아 두세요

- 하이퍼클래스의 다른 곳에서 쓰려면 먼저 Canva 디자인을 가져와야 해요.
- 같은 Canva 디자인을 여러 번 가져올 수 있어요(Unsplash와 같은 방식이에요).

가져오기 형식

- 1페이지 디자인 → PNG
- 여러 페이지 디자인 → PDF

가져오는 방법

1. **미디어 저장소**로 가져올 디자인 오른쪽 위의 점 세 개 아이콘을 클릭하세요.
2. **Import to Media Library**(미디어 라이브러리로 가져오기) 버튼을 클릭하세요.

   ![디자인 메뉴의 미디어 라이브러리로 가져오기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066029349/original/PmWd6hlkjm1C-xmsl7wPNYGrNfRX4QS2lA.png?1772469876)

## 여러 사용자의 접근 권한

Canva 연결은 서브 계정 단위로 설치돼요. 그래서 연동을 직접 연결한 사용자인지에 따라 접근 권한이 달라요.

연결한 사용자(Canva를 연결한 사람)

- Canva에서 전체 편집 권한이 있어요(Canva 파일이 편집을 허용하는 경우).
- 디자인을 가져올 수 있어요.

같은 서브 계정의 다른 사용자

- Canva 자산을 보고, 검색하고, 둘러볼 수 있어요.
- 디자인을 다운로드할 수 있어요.
- 디자인을 자기 **My Media**로 가져올 수 있어요.
- 연동을 제거하기 전에는 다른 Canva 계정을 연결할 수 없어요.
- Canva 디자인을 직접 편집할 수 없어요(보기 전용).

**지원되지 않음**

- 대리 로그인(Login As) 사용자는 접근할 수 없어요.

## Canva 연결 해제하기

연결을 해제하면 OAuth 연결이 끊기고, **미디어 저장소**에 Canva 디자인이 더 이상 나타나지 않아요. 이미 **My Media**로 가져온 자산은 그대로 남아 있어요.

해제하는 방법

- **앱 마켓플레이스 > 설치된 앱 > Canva > 제거**로 이동하세요.

![설치된 앱에서 Canva 제거](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066030009/original/QuMYjB-79qba9H4gf6kE79qlGLTP6G722Q.png?1772470257)

연결을 해제하면

- OAuth 접근 권한이 취소돼요.
- Canva 화면에 Canva 디자인이 더 이상 나타나지 않아요.
- 이전에 가져온 파일은 **미디어 저장소**에 남아 있어요.
- 제거한 뒤 다시 연결하면 다른 Canva 계정을 연결할 수 있어요.

## 자주 묻는 질문

### Canva는 에이전시 단위로 연결되나요, 서브 계정 단위로 연결되나요?
Canva는 서브 계정 단위로 연결돼요. 서브 계정마다 Canva 계정 하나를 연결할 수 있어요.

### 한 서브 계정에 Canva 계정을 여러 개 연결할 수 있나요?
아니요. 서브 계정마다 Canva 계정 하나만 지원돼요.

### Canva 디자인이 보이는데 편집이 안 돼요.
Canva 마켓플레이스 제약 때문에 Canva를 연결한 사용자만 직접 편집할 수 있어요. 다른 사용자는 디자인을 둘러보고, 다운로드하고, 가져올 수 있지만 편집하려고 하면 보기 전용으로 열려요.

### 편집할 때 나오는 "view-only access"는 무슨 뜻인가요?
Canva를 연결한 사용자가 아니면 “You have view-only access to this media. To make changes, import it into your own storage or reach out to your admin for access.”라는 메시지가 나올 수 있어요. 디자인을 가져오면 **My Media**에 나만의 독립된 사본이 만들어져요.

### 하이퍼클래스에서 쓰려면 왜 Canva 디자인을 먼저 가져와야 하나요?
Canva 화면에 보이는 디자인은 콘텐츠 소스예요. 하이퍼클래스 곳곳에서 자산을 쓰려면 먼저 **My Media**로 가져와야 해요.

### 가져온 Canva 파일은 원래 Canva 디자인과 연결되나요?
아니요. 가져오기를 하면 **My Media**에 새 독립 자산이 만들어지고, 이후 Canva에서 바뀐 내용은 동기화되지 않아요.

### **My Media**에서 편집할 때 Canva 디자인이 중복으로 만들어지지 않나요?
**My Media**의 지원되는 파일을 Canva에서 편집하면 하이퍼클래스가 기존 Canva 디자인 ID가 있는지 확인해요. 있으면 새로 만들지 않고 같은 디자인을 다시 열어요.

### **My Media**에서 Canva로 편집할 수 있는 파일 형식은 무엇인가요?
PNG, JPG, JPEG예요.

### 디자인은 어떤 형식으로 다운로드하거나 가져오나요?
1페이지 디자인은 PNG로, 여러 페이지 디자인은 PDF로 내보내요.
