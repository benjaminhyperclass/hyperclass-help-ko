# 사용자 지정 객체 시작하기

사용자 지정 객체가 무엇인지 알아보고, 내 비즈니스에 맞는지 판단하는 데 도움이 되는 문서예요.

사용자 지정 객체를 쓰면 연락처, 회사, 기회에 딱 맞지 않지만 비즈니스에서 꼭 관리해야 하는 데이터를 CRM에 담을 수 있어요. 비즈니스에만 있는 대상, 관계, 프로세스를 CRM에 그대로 반영하고 싶을 때 알맞아요.

관리자는 **Object Settings**(객체 설정)에서 사용자 지정 객체를 정의하고, 커스텀 필드와 연관 관계(Associations)를 추가할 수 있어요. 만든 객체는 **워크플로우**, **폼**, **리포팅** 같은 도구에서 사용해요.

{% hint style="info" %}
이 문서는 사용자 지정 객체가 무엇인지 이해하고, 내 상황에 맞는지 판단하는 데 도움을 줘요.
{% endhint %}

## 사용자 지정 객체를 쓰면 좋은 점

사용자 지정 객체를 쓰면 사람 중심 CRM에서 벗어나, 비즈니스가 실제로 돌아가는 방식을 그대로 담은 데이터 구조를 만들 수 있어요.

사용자 지정 객체로 할 수 있는 일은 다음과 같아요.

- CRM을 규모가 커져도 깔끔하게 유지해요. 관련 없는 데이터를 연락처나 기회에 억지로 넣으면 레코드가 지저분해지고 쓰기 불편해져요.
- 현실의 대상을 독립된 레코드로 관리해요. 부동산, 반려동물, 프로젝트, 보험 증권 같은 대상을 각자의 필드와 자동화를 가진 별도 레코드로 다뤄요.
- 자동화와 리포팅을 더 깔끔하게 만들어요. 데이터가 알맞게 구조화되어 있으면 워크플로우, 필터, 대시보드가 더 단순하고 정확해지며 관리하기도 쉬워요.
- 복잡한 관계를 자연스럽게 다뤄요. 일대다, 다대다 관계(예: 연락처 한 명이 반려동물이나 부동산 여러 개를 소유)를 관리하고 이해하기 쉬워져요.

{% hint style="info" %}
한마디로, 사용자 지정 객체는 CRM을 깔끔하고 확장하기 쉽게 유지하면서 비즈니스가 실제로 운영되는 방식에 맞춰 줘요.
{% endhint %}

## 사용자 지정 객체란?

사용자 지정 객체는 다음과 같은 대상을 CRM 안에서 독립된 레코드로 다루는 기능이에요.

- 부동산
- 반려동물
- 프로젝트
- 구독
- 보험 증권

각 사용자 지정 객체에는 다음이 있어요.

- 고유한 레코드와 필드
- 다른 CRM 객체와의 연관 관계
- 워크플로우와 자동화에서의 지원

## 사용자 지정 객체를 써야 하는 경우

다음과 같을 때 사용자 지정 객체가 잘 맞아요.

- 데이터가 사람이나 회사에 속하지 않을 때: 자산, 매물, 보험 증권, 반려동물처럼 사람이 아닌 '대상'을 관리한다면 보통 사용자 지정 객체가 맞아요.
- 구조화된 반복 레코드가 필요할 때: 같은 종류의 대상이 많고, 일관된 필드, 보기, 자동화가 필요한 경우예요.
- CRM에서 더 깊은 관계를 맺고 싶을 때: 사용자 지정 객체는 연락처, 회사, 기회, 심지어 다른 사용자 지정 객체와도 연결할 수 있어요. 덕분에 더 고급 워크플로우를 만들 수 있어요.

예시

- 구매자, 중개인과 연결된 부동산 매물
- 소유자와 연결된 여러 마리의 반려동물
- 고객, 기회와 연결된 프로젝트

## 기본 CRM 객체를 그대로 쓰는 것이 좋은 경우

사용자 지정 객체는 유용하지만 항상 맞는 답은 아니에요. 다음과 같다면 사용하지 않는 편이 좋아요.

- 기본 객체로 충분할 때: 연락처, 회사, 기회에는 기본 기능이 내장되어 있어요. 사용자 지정 객체는 이런 기능을 항상 지원하지는 않아요.
- 연락처 전용 기능이 필요할 때: 단체 이메일, 마케팅 캠페인, 일부 커뮤니케이션 도구는 연락처에서만 쓸 수 있어요.
- 같은 데이터를 중복해서 만들게 될 때: 기존 객체와 똑같은 사용자 지정 객체를 만들면 혼란이 생기고 데이터가 서로 맞지 않을 수 있어요.

이럴 때는 **스마트 리스트**로 기본 객체 안에서 여러 가지 세그먼트를 만들어 보세요.

## 예시

### 활용하기 좋은 사례

부동산 – 주택
: "주택(Homes)" 객체를 만들어 가격, 상태, 위치 같은 매물 정보를 관리해요. 구매자, 판매자, 중개인과 연결할 수도 있어요.

동물병원 – 반려동물
: "반려동물(Pets)" 객체에 진료 기록, 예방접종, 예약을 저장해요. 반려동물의 보호자와 연결해 둘 수 있어요.

### 권장하지 않음

행사 참석자
: 이메일, 리마인더, 후속 연락이 주된 목적이라면 연락처가 더 잘 맞아요.

내부 메모나 활동
: 사용자 지정 객체로 메모, 작업, 활동을 대체하지 않는 것이 좋아요. 불필요하게 복잡해져요.

## 다음 단계

사용자 지정 객체를 만들고 나면 다음을 할 수 있어요.

- 커스텀 필드 추가
- 연관 관계와 레이블 정의
- 워크플로우와 자동화 구성
- 사용자 지정 객체에 데이터를 모으는 폼 만들기
- 대시보드로 데이터 시각화
