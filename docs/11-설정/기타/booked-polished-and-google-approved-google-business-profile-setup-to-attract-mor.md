# 뷰티 살롱을 위한 Google 비즈니스 프로필 설정 가이드

뷰티 살롱이 Google에서 더 잘 보이고 예약으로 이어지도록 Google 비즈니스 프로필을 처음부터 끝까지 채우는 순서를 안내해요. 프로필을 새로 만들 때도, 이미 있는 프로필을 다듬을 때도 참고하세요.

## 알아 두면 좋은 숫자

- 사람들의 97%는 동네 업체를 방문하기 전에 온라인에서 먼저 알아봐요.
- 근처 서비스를 검색한 사람의 76%는 그 업체가 믿을 만하다고 느끼면 24시간 안에 방문해요.
- Google 비즈니스 프로필을 빠짐없이 채운 살롱은 클릭이 7배 많고, 예약 문의는 70% 더 많이 받아요.

뷰티 살롱이 Google에서 제대로 정리되어 있지 않다면 고객과 매출을 놓치고 있는 셈이에요.

프로필을 잘 관리하면 이런 효과를 기대할 수 있어요.

- 방문 고객 증가
- 예약 증가
- 리뷰와 평판 향상
- 매출 증가

온라인에서 보이지 않아서 살롱 의자가 비어 있으면 안 되겠죠.

## 완벽한 뷰티 살롱 프로필 만들기

### 1. 프로필 확인하기 또는 새로 만들기

1. [Google 비즈니스 프로필 관리자](https://business.google.com/)로 이동하세요.
2. 업무용 이메일로 로그인하세요. 웹사이트 도메인과 같은 이메일이 가장 좋아요.
3. 살롱 이름을 검색하세요.
   - 이미 등록되어 있다면 바로 소유권을 확인받으세요.
   - 등록되어 있지 않다면 새로 만드세요.

{% hint style="info" %}
팁: 모든 플랫폼에서 공식 브랜딩을 일관되게 사용하세요.
{% endhint %}

### 2. 카테고리 전략적으로 고르기

**기본 카테고리**는 살롱의 대표 정체성을 보여 주는 항목 하나만 고르세요.

- 뷰티 살롱
- 헤어 살롱
- 네일 살롱
- 메이크업 아티스트
- 페이셜 스파

보조 카테고리는 제공하는 서비스를 보완하는 용도로 고르세요.

- 헤어드레서
- 스킨케어 클리닉
- 왁싱 제모
- 웨딩 숍

{% hint style="info" %}
팁: 관련 없는 카테고리를 너무 많이 추가하면 Google이 헷갈려서 검색 노출에 오히려 불리해요.
{% endhint %}

### 3. 살롱 정보 정확하게 입력하기

- 이름: 브랜딩과 똑같이 입력하세요.
- 주소: 정확하게 입력하고 Google 지도에서 잘 찾아지는지 확인하세요.
- **비즈니스 전화번호**: 개인 번호와 분리해서 입력하세요.
- 웹사이트 URL: 온라인 예약 링크가 있는 주소가 좋아요.

{% hint style="warning" %}
중요: 이름, 주소, 전화번호(NAP)는 웹사이트, Facebook, Instagram 소개란, Yelp 등 모든 곳에서 똑같아야 해요.
{% endhint %}

### 4. 뷰티 감성의 살롱 소개글 쓰기

소개글은 아래 공식으로 쓰세요.

- 대표 서비스를 앞세워요. 예: 헤어 컬러, 웨딩 메이크업, 럭셔리 페이셜
- 살롱만의 강점을 보여 줘요. 예: 수상 경력이 있는 스타일리스트, 유기농 제품, 유명인 고객
- 지역 키워드를 넣어요. 예: "오스틴 다운타운에 있어요."

예시: "Glow Beauty Lounge는 럭셔리 뷰티 서비스를 현실로 만들어 드려요. 맞춤 헤어 컬러 변신부터 완벽한 웨딩 룩까지, 오스틴의 수상 경력 팀이 안팎으로 빛나는 모습을 만들어 드립니다. Glow에서 뷰티의 예술을 경험해 보세요."

{% hint style="info" %}
팁: 살롱의 강점 3가지를 먼저 적어 보고, 소개글에 녹여 보세요.
{% endhint %}

### 5. 눈길을 끄는 사진 추가하기

Google에 따르면 사진이 있는 업체 정보는 길 찾기 요청이 42% 더 많고, 웹사이트 클릭도 35% 더 많아요.

사진 체크리스트:

- 외관: 매장 정면. 아름답고 들어가고 싶은 입구
- 내부: 의자, 거울, 매장 분위기
- 작업 모습: 스타일링, 메이크업, 페이셜 장면(동의를 받은 경우)
- 제품 진열: 프리미엄 뷰티 브랜드
- 고객 변신 사례: 시술 전후 사진(고객의 서명 동의를 받은 경우)

{% hint style="info" %}
팁: 밝고 깔끔하고 웃는 모습이 담긴 사진이 어둡거나 어수선한 사진보다 반응이 좋아요.
{% endhint %}

### 6. 서비스와 가격 자세히 적기

제공하는 서비스를 구체적으로 적으세요.

- 여성 커트 및 블로우 드라이: $45부터
- 케라틴 스무딩 트리트먼트: $150부터
- 풀 웨딩 메이크업: $250부터

{% hint style="info" %}
통계: 서비스를 등록한 살롱은 직접 예약 행동이 28% 더 많아요.
{% endhint %}

### 7. 메시지 기능 켜기

1. Google 비즈니스 프로필 대시보드에서 **Chat with customers**(고객과 채팅)를 켜세요.
2. 자동 답장을 설정하세요. 예: "[살롱 이름]에 문의해 주셔서 감사합니다! 1시간 이내에 답변드릴게요."

{% hint style="info" %}
팁: 빠르게 답하세요. Google은 응답이 빠른 업체를 검색 순위에서 더 높게 평가해요.
{% endhint %}

### 8. 좋은 리뷰 모으고 꾸준히 답글 달기

뷰티 업계는 평판이 가장 중요해요.

만족한 고객에게 리뷰를 부탁하세요.

- 계산대에 QR 코드를 두세요.
- 예약 후 문자로 리뷰 링크를 바로 보내세요.

리뷰에 답글을 달 때는 이렇게 하세요.

- 받은 서비스를 언급하세요.
- 따뜻하고 전문적이면서 개인적인 느낌으로 답하세요.

## 보너스: 뷰티 살롱 프로필 성공을 위한 비법 3가지

| 비법 | 효과가 있는 이유 |
| --- | --- |
| 매주 프로모션 올리기(예: 헤어 스파 10% 할인) | Google은 활발하게 운영되는 프로필을 선호해요 |
| **예약하기** 버튼을 추가하고 하이퍼클래스 캘린더로 연결하기 | 고객이 바로 예약할 수 있어서 번거로움이 줄어요 |
| 계절마다 사진 바꾸기(여름 스타일, 웨딩 시즌 특별 메뉴) | 프로필이 항상 새롭고 관련성 있게 유지돼요 |

## 마무리

Google 비즈니스 프로필은 디지털 세상의 뷰티 광고판이에요.

누군가 "내 주변 최고의 헤어 컬러리스트"나 "내 주변 웨딩 메이크업 리허설"을 검색했을 때, 가장 먼저 보이는 이름이 우리 살롱이어야 해요. 신뢰와 아름다움, 스타일이 반짝이는 모습으로요.

지금 설정하고, 매달 다듬으세요. 매주 살롱 의자가 채워지는 모습을 보게 될 거예요.
