# 스냅샷 버전 관리

스냅샷을 새로고침할 때마다 무엇이 바뀌었는지 확인하는 기능이에요. **버전 기록**에서 추가됨, 제거됨, 동기화됨 자산을 살펴보고, **계정 스냅샷**의 버전 정보로 팀이 같은 버전을 쓰고 있는지 맞춰 볼 수 있어요. 이 문서에서는 버전을 확인하는 방법, 변경 내용을 읽는 방법, 점검을 더 깔끔하게 하는 활용 방법을 설명해요.

## 스냅샷 버전 관리란?

스냅샷 버전 관리는 하이퍼클래스의 **스냅샷 자산 뷰어**에 추가된 기능이에요. 스냅샷을 성공적으로 새로고침할 때마다 새 버전을 하나씩 기록해요. 버전을 시간순으로 훑어보다가 원하는 버전을 열면 바로 이전 버전과 비교해 무엇이 바뀌었는지 알 수 있어요. 서브 계정으로 자산을 복사할 때 쓰는 템플릿의 변경 내용을 정확히 확인할 수 있어요.

스냅샷을 새로고침할 때마다 업데이트 기록이 남아요. 각 업데이트에서 지난번과 비교해 무엇이 추가되고, 무엇이 제거되고, 무엇이 그대로인지 보여 줘요. 스냅샷을 관리하거나 공유하는 곳에는 버전이 함께 표시돼서 팀과 고객이 늘 같은 버전을 보게 돼요. 각 항목에는 계정 안에서 어디에 있는지도 표시돼 있어서 나중에 찾아 수정하기 쉬워요.

---

## 스냅샷 버전 관리의 장점

시간에 따른 변경을 파악하는 일은 협업과 문제 해결에 꼭 필요해요. 버전 관리를 쓰면 이 정보가 한곳에 모여서 스냅샷 내용을 빠르게 점검하고, 고객·팀원과 쉽게 맞춰 볼 수 있어요.

- 변경 이력 확인: 버전을 시간순 목록으로 보고, 버전별 변경 요약을 확인해요.
- 빠른 문제 해결: 버전끼리 비교해서 공유한 시점과 가져온 시점 사이에 무엇이 바뀌었는지 확인해요.
- 팀 간 일치: 모두 같은 버전을 쓰고 있는지 확인해서 팀이 같은 기준으로 일해요.
- 정확한 작업: 상품 카테고리 라벨을 보면 서브 계정의 어느 영역에서 자산을 찾아야 하는지 알 수 있어요.
- 수작업 감소: 직접 만들던 스프레드시트 대신, 기본 제공되는 기록을 기준으로 삼을 수 있어요.

## 버전 기록 패널

**버전 기록** 패널에는 스냅샷을 성공적으로 새로고침해서 만들어진 모든 버전이 날짜순으로 나와요. 누가 새로고침했고 무엇이 바뀌었는지 한눈에 훑어볼 수 있어요.

패널에서 볼 수 있는 내용이에요.

- 버전의 시간순 목록과 각 버전의 생성 날짜·시간
- 버전별 변경 요약: 이전 버전과 비교한 **추가됨**, **제거됨**, **동기화됨** 개수
- 버전을 선택해 상세 요약을 여는 기능

## 버전 상세 내용 (추가됨, 제거됨, 동기화됨)

버전을 열면 자산이 종류별로 묶여 나와서 이전 버전과 달라진 점을 이해하기 쉬워요. 특정 퍼널, 워크플로우, 다른 자산이 바뀌었는지 확인할 때 추측할 필요가 없어요.

상세 화면에서는 다음을 할 수 있어요.

- 자산을 종류별로 묶어서 보기(예: **퍼널**, **워크플로우**, **이메일** 등)
- 바로 이전 버전과 비교해 어떤 자산이 **추가됨**, **제거됨**, **동기화됨**인지 확인하기
- 공유하거나 가져오기 전에 해당 버전에 정확히 무엇이 들어 있는지 확인하기

## 스냅샷 목록의 버전 정보

주요 스냅샷 목록에 버전 정보가 표시돼요. 파트너나 고객과 협업할 때 어떤 버전을 공유하고 가져왔는지 바로 확인할 수 있어요.

버전 정보가 표시되는 곳이에요.

- **내 스냅샷**
- **가져온 스냅샷**
- **공유된 스냅샷**

## 스냅샷 버전 관리 사용하기

버전이 빠짐없이 기록되고 검토할 때 **버전 기록**을 믿고 쓸 수 있으려면 아래 순서로 사용해 보세요.

1. **Agency view**(에이전시 뷰) > **계정 스냅샷** > **내 스냅샷**으로 이동해요.

   ![내 스냅샷 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055597317/original/rEXKDKbkUDdJPI-CvIy21q9JyNFSssGO8w.png?1760004905)
2. 스냅샷 이름을 클릭해서 **스냅샷 자산 뷰어**를 열어요.

   ![스냅샷 자산 뷰어](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055597565/original/uNsdQ3in6y80bpvNF74F1FAzrkQevGcw2Q.png?1760005018)
3. **버전 기록** 탭으로 이동하면 기록된 모든 버전이 보여요.

   ![버전 기록 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055597936/original/hKfQ6SXM8gBmu4iSd3md-PHuhhos9mMYfA.png?1760005109)
4. **버전 기록**에서 원하는 버전 행을 클릭하면 **Version Details**(버전 상세) 요약(추가됨/제거됨/동기화됨)이 열려요.

   ![버전 상세 요약](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055598205/original/ud2H4r-SGSmiS3b1aH2o075k5HieRugoLQ.png?1760005285)
5. 자산을 추가하거나 업데이트했다면 **내 스냅샷** 목록에서 **스냅샷 새로고침**을 클릭해요. 새로고침이 성공하면 새 버전이 만들어져요.

   ![스냅샷 새로고침](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055598717/original/jecfRzO9tbE-1i1455jJMqLIUzBrV5I6fQ.png?1760005455)
6. 공유하거나 가져올 때는 **내 스냅샷**, **가져온 스냅샷**, **공유된 스냅샷**의 버전 정보를 보고 협업하는 상대와 같은 버전인지 확인해요.

## 활용 예시

버전 기록과 버전 정보를 실제로 어떻게 쓸 수 있는지 보여 주는 상황들이에요. 배포를 조율하고, 고객과 주고받는 확인을 줄이고, "무엇이 바뀌었지?"라는 질문에 빠르게 답할 때 도움이 돼요.

- 많은 서브 계정에 한꺼번에 반영하기 전에 확인: 여러 서브 계정에 업데이트를 반영하기 전에 **버전 기록**에서 의도한 버전이 맞는지 확인하고, 달라진 내용을 훑어보세요. 완성되지 않은 변경을 반영하는 실수를 막을 수 있어요. 그다음 평소 하던 방식대로 반영하세요. 자세한 내용은 '고객 계정에 스냅샷 업데이트 반영·불러오기' 문서와 [스냅샷 반영 업데이트 기록](../../19-에이전시-뷰/Snapshots/snapshot-push-update-history.md)을 참고하세요.
- 공유 전 새로고침 결과 점검: 자산을 업데이트한 뒤 **버전 기록**을 열어 최신 버전의 **추가됨**/**제거됨**/**동기화됨** 요약을 확인하세요. 스냅샷을 공유하기 전에 의도한 변경만 들어갔는지 알 수 있어요. 자세한 내용은 [스냅샷 공유하기](../../19-에이전시-뷰/Snapshots/how-to-share-snapshots.md)를 참고하세요.
- 파트너·고객과 정확히 같은 빌드로 맞추기: 다른 에이전시나 서브 계정과 협업할 때 **내 스냅샷**의 버전 정보와 상대가 **가져온 스냅샷**/**공유된 스냅샷**에서 보는 버전 정보를 비교해 보세요. 모두 같은 버전으로 작업할 수 있어요.
- 가져온 뒤 자산이 없거나 예상과 다를 때 원인 찾기: 서브 계정에서 퍼널이나 워크플로우가 없다고 알려 오면, 그 계정이 가져온 버전의 **Version Details**를 열어 해당 자산이 **제거됨**인지 **동기화됨**인지 확인하세요. 그런 다음 상품 카테고리 라벨을 보고 사용자가 올바른 영역으로 찾아가도록 안내하세요. 관련 문서: '스냅샷 가져오기'.
- 정리 작업 확인: 템플릿에서 더 이상 쓰지 않을 자산을 정리한다면 스냅샷을 새로고침한 뒤 해당 항목이 최신 버전의 **제거됨**에 나타나는지 확인하세요. 정리한 내용이 스냅샷에 반영됐다는 확인이 돼요.

## 자주 묻는 질문

### 버전은 언제 만들어지나요?
스냅샷을 성공적으로 새로고침한 뒤에 새 버전이 만들어져요. 새로고침하지 않고 스냅샷을 열기만 하거나 편집만 하면 버전은 만들어지지 않아요.

### 스냅샷을 이전 버전으로 되돌릴 수 있나요?
버전 관리는 점검을 위한 확인 기능과 버전 정보를 제공해요. 이전 버전으로 되돌리거나 복원하는 기능은 기본으로 들어 있지 않아요.

### 새로고침이 실패해도 버전이 만들어지나요?
아니요. 성공한 새로고침에 대해서만 버전이 만들어져요.

### 버전 정보는 어디에서 볼 수 있나요?
**내 스냅샷**, **가져온 스냅샷**, **공유된 스냅샷** 목록에서 볼 수 있어요.

### 누가 버전 기록과 버전 상세를 볼 수 있나요?
사용자 역할과 권한에 따라 달라요. 자세한 내용은 [스냅샷 세부 권한](../../19-에이전시-뷰/Snapshots/granular-permissions-for-snapshots.md)을 참고하세요.

### 버전 상세에서 "동기화됨"은 무슨 뜻인가요?
이전 버전과 현재 버전에 모두 들어 있어서 추가되거나 제거되지 않은 자산이라는 뜻이에요.

### 버전 관리를 쓰면 고객 서브 계정이 자동으로 업데이트되나요?
아니요. 버전 관리는 정보를 보여 주는 기능이에요. 서브 계정에 업데이트를 반영하거나 불러오는 일은 별도의 작업이에요.

### 여러 서브 계정에 반영하기 전에 버전 기록을 어떻게 활용하면 좋을까요?
먼저 **버전 기록**에서 반영하려는 스냅샷 버전이 맞는지 확인한 다음 반영을 진행하세요. 반영할 때 알림이 어떻게 동작하는지는 [스냅샷 반영 시 순차 알림](../../19-에이전시-뷰/Snapshots/rolling-notifications-for-snapshot-push.md)을 참고하세요.
