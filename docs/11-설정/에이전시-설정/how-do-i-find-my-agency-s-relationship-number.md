# 에이전시 관계 번호 찾기

하이퍼클래스 에이전시 계정의 **관계 번호**를 확인하는 방법을 알려 드려요. 하이퍼클래스 고객지원에서 계정을 확인해야 할 때 이 번호를 물어볼 수 있어요.

**관계 번호**는 하이퍼클래스 에이전시 계정마다 부여되는 7자리 고유 번호예요. 보통 아래와 같은 형식으로 표시돼요.

`X-XXX-XXX`

하이퍼클래스 고객지원, 서비스, 고객 성공팀, 제품 팀에서 올바른 에이전시 계정을 확인하려고 관계 번호를 요청할 수 있어요.

{% hint style="warning" %}
에이전시마다 관계 번호가 달라요. **에이전시 관리자**와 **에이전시 소유자**만 볼 수 있어요.
{% endhint %}

---

## 방법 1: 회사 설정에서 관계 번호 찾기

**회사 설정**에서 에이전시의 관계 번호를 확인할 수 있어요.

1. 왼쪽 위 메뉴에 있는 **Sub-Account Switcher**(서브 계정 전환기)를 클릭하세요.
2. **에이전시 보기로 전환**을 선택하세요.

   ![서브 계정 전환기에서 에이전시 보기로 전환 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078719175/original/YUYQqVy1PSQhByEMfced66vdvh3ZR7NDdw.png?1787066638)
3. 왼쪽 메뉴 아래쪽에서 **설정**을 클릭하세요.

   ![왼쪽 메뉴 아래쪽의 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078719234/original/A4KQ13s7Of7FlXYPKj_lgRgYQ9Ox7BzFDw.png?1787066680)
4. **회사**를 선택하세요.
5. **Company Data**(회사 데이터) 아래에서 **관계 번호**를 찾으세요.

   ![회사 데이터 아래의 관계 번호](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078721062/original/jlxycwkf_S_ich1Z1ydVcfg3VTHTUJ2tCQ.png?1787067820)
6. 관계 번호 옆의 **copy icon**(복사 아이콘)을 클릭해 번호를 복사하세요.

{% hint style="info" %}
여러 에이전시에 접근할 수 있다면, 관계 번호를 복사하기 전에 올바른 **에이전시 보기**에 있는지 확인하세요.
{% endhint %}

## 방법 2: 도움말 메뉴에서 관계 번호 찾기

에이전시 관리자는 도움말 메뉴에서도 관계 번호를 빠르게 확인할 수 있어요.

1. 에이전시 수준의 권한이 있는 계정으로 로그인했는지 확인하세요.
2. 하이퍼클래스 오른쪽 위에 있는 **파란색 물음표(?)** 를 클릭하세요.

   ![오른쪽 위의 파란색 물음표 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078721213/original/H-q-Ly6o3pX51B0SYAtAM_bPOcInxhaxqA.png?1787067882)
3. 에이전시 정보에서 **관계 번호**를 찾으세요.

   ![도움말 메뉴에 표시된 에이전시 정보와 관계 번호](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078721638/original/Y8enY3m07tn8i3l4cHy6nDOEPMgYJdonSg.png?1787068105)
4. 필요하면 관계 번호를 복사하세요.

## 관계 번호가 안 보일 때

관계 번호가 보이지 않으면 아래 내용을 확인해 보세요.

### 사용자 권한 확인하기

**에이전시 관리자**와 **에이전시 소유자**만 관계 번호를 볼 수 있어요. 둘 중 어느 역할도 아니라면, 에이전시 관리자나 에이전시 소유자에게 관계 번호를 확인해 달라고 요청하세요.

### 에이전시 보기인지 확인하기

관계 번호는 개별 서브 계정이 아니라 **에이전시**를 구분하는 번호예요. 지금 서브 계정 안에 있다면 아래와 같이 하세요.

1. **Sub-Account Switcher**를 여세요.
2. **에이전시 보기로 전환**을 선택하세요.

   ![서브 계정 전환기에서 에이전시 보기로 전환 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078721750/original/y-k6zBuIPf2QOgkKy6bsKbK5vrriWr5ecw.png?1787068174)
3. **설정 > 회사**로 이동하세요.
4. **Company Data** 아래에서 관계 번호를 찾으세요.

### 올바른 에이전시인지 확인하기

에이전시가 둘 이상이라면, 관계 번호를 복사하기 전에 올바른 에이전시를 보고 있는지 확인하세요. 에이전시마다 관계 번호가 다르기 때문에, 다른 에이전시 보기에서 복사하면 엉뚱한 에이전시 계정을 알려 주게 될 수 있어요.

## 관계 번호와 위치 ID의 차이

**관계 번호**와 **위치 ID**는 하이퍼클래스 계정에서 서로 다른 단위를 구분해요.

| 구분 | 무엇을 구분하나요? | 예시 |
| --- | --- | --- |
| **관계 번호** | 하이퍼클래스 **에이전시 계정** | `X-XXX-XXX` |
| **위치 ID** | 에이전시 안의 특정 **서브 계정(위치)** | 영문과 숫자로 된 고유 ID |

하이퍼클래스 고객지원이나 다른 하이퍼클래스 워크플로우에서 식별 정보를 요청하면, 요청한 종류에 맞는 값을 알려 주세요.

{% hint style="info" %}
어떤 값이 필요한지 헷갈리나요? 에이전시를 확인하는 경우라면 관계 번호를, 특정 서브 계정(위치)을 확인하는 경우라면 그 서브 계정의 위치 ID를 쓰세요.
{% endhint %}

## 자주 묻는 질문

### 에이전시 관계 번호는 누가 볼 수 있나요?

**에이전시 관리자**와 **에이전시 소유자**만 관계 번호를 볼 수 있어요.

### 서브 계정마다 관계 번호가 다른가요?

아니요. 관계 번호는 **에이전시 계정**을 구분해요. 개별 서브 계정은 각각의 **위치 ID**로 구분해요.

### 에이전시가 여러 개인데 어떤 관계 번호를 써야 하나요?

확인하려는 에이전시의 에이전시 보기로 전환한 다음, **설정 > 회사 > Company Data**에서 관계 번호를 확인하세요.

### 에이전시 관리자나 에이전시 소유자가 아니면 어떻게 하나요?

해당 에이전시의 에이전시 관리자나 에이전시 소유자에게 관계 번호를 확인해 달라고 요청하세요.

### 관계 번호를 가장 확실하게 확인할 수 있는 곳은 어디인가요?

**에이전시 보기 > 설정 > 회사**로 이동해서 **Company Data** 아래의 관계 번호를 확인하세요.
