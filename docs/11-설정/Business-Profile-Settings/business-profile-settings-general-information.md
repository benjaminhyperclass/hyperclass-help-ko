# 비즈니스 프로필 일반 정보 설정

**일반 정보**에서는 브랜드 아이덴티티와 계정의 주요 정보를 설정해요. 로고, 비즈니스 이름, 이메일·전화번호, 브랜드 도메인, 웹사이트, 니치, API 키를 입력해 두면 다른 기능에서도 정확한 브랜드 정보를 쓸 수 있어요.

**비즈니스 프로필** 설정 화면으로 이동하는 방법 등 전체 내용은 [비즈니스 프로필 설정 개요](business-profile-settings.md)를 참고하세요.

## 일반 정보 설정

이 항목들은 하이퍼클래스 전체에서 쓰는 브랜드 자산과 회사 식별 정보의 기준이 돼요. 각 항목을 꼼꼼히 입력하고, 안내가 있는 항목은 공식 기록과 똑같이 맞춰 주세요. 변경한 뒤에는 저장하고, 캘린더 링크나 이메일 템플릿 같은 몇 가지 자산에 새 값이 제대로 나오는지 확인해 보세요.

![일반 정보 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052721902/original/rwfEn8KcBuBqCMCJByYkhT6vckUNzMiHcQ.png?1756501586)

### 위치 ID

하이퍼클래스 고객지원에 문의하면 문제가 생긴 계정의 위치 ID를 요청받을 수 있어요. **위치 ID**는 에이전시 계정 아래 모든 서브 계정에 하나씩 부여되는 고유 ID예요. 고객지원팀은 이 ID로 고객사 계정을 찾아 문제 원인을 더 빠르게 좁혀요.

### 비즈니스 로고

이 서브 계정을 대표할 **비즈니스 로고**를 업로드하세요. 이 로고는 **에이전시 대시보드**의 **계정** 목록에서 해당 서브 계정을 나타내요. 인보이스와 이메일 등 하이퍼클래스의 여러 기능에도 쓰이고, 메시지에서는 커스텀 필드로도 쓸 수 있어요.

예시: `{{location.logo_url}}`

### 비즈니스 표시명

**비즈니스 표시명**은 메시지, 워크플로우 등 앱 곳곳에서 커스텀 필드 **계정 > 이름**을 쓸 때 서브 계정(위치)의 이름으로 나오는 값이에요.

예시: `{{location.name}}`

### 법인 비즈니스명

**법인 비즈니스명**은 앞으로 진행할 컴플라이언스 등록에 쓰이는 이름이에요. 사업자 등록증 같은 법적 서류에 적힌 비즈니스 이름과 정확히 똑같이 입력하세요.

### 비즈니스 이메일

메시지, 이메일, 워크플로우 등 커스텀 필드를 쓸 수 있는 곳에서 커스텀 필드 **계정 > 이메일**을 추가하면, 여기에 입력한 이메일이 이 계정의 이메일로 나와요.

예시: `{{location.email}}`

### 비즈니스 전화번호

메시지, 이메일, 워크플로우 등 커스텀 필드를 쓸 수 있는 곳에서 커스텀 필드 **계정 > 전화번호**를 추가하면, 여기에 입력한 번호가 이 계정의 전화번호로 나와요.

예시: `{{location.phone}}`

```
이 번호를 통화·문자 발송에 쓰는 번호와 같게 하려면, 먼저 하이퍼클래스 전화 번호를 설정한 다음 구매한 번호를 복사해 "비즈니스 전화번호" 필드에 붙여 넣으세요.
```

### 브랜드 도메인

서브 계정(위치)마다 호스팅 업체의 서브도메인을 연결해 브랜드 도메인을 만들 수 있어요. 이 브랜드 도메인은 **트리거 링크**, **캘린더**, **폼**, **설문** 등의 URL 주소로 쓰여요.

브랜드 도메인의 자세한 설명과 서브 계정에 설정하는 방법은 아래 문서를 참고하세요.

- [하이퍼클래스의 도메인](../../06-사이트/일반-설정/how-to-set-up-different-domain-types-in-hyperclass-websites-email-wordpress-more.md)

### 비즈니스 웹사이트

메시지, 이메일, 워크플로우 등 커스텀 필드를 쓸 수 있는 곳에서 커스텀 필드 **계정 > 웹사이트**를 추가하면, 여기에 입력한 웹사이트 URL이 이 계정의 웹사이트로 나와요.

예시: `{{location.website}}`

### 비즈니스 니치

드롭다운 목록에서 서브 계정에 맞는 **비즈니스 니치**를 선택하세요. 여러 니치를 대상으로 한다면, 타깃 시장을 가장 잘 나타내는 니치를 고르세요.

### Business Currency

**Business Currency**(비즈니스 통화)에서는 서브 계정의 기본 통화를 선택해요. 선택한 통화는 결제와 관련된 모든 페이지와 흐름에 자동으로 적용돼요. 통화를 선택하지 않으면 **비즈니스 주소**에 입력한 국가의 통화가 기본값이 돼요. 사업장이 있는 나라와 다른 나라에서 영업하는 비즈니스에 유용한 설정이에요.

### API 키

API 키는 둘 이상의 소프트웨어 애플리케이션을 서로 연결할 때 쓰는 값이에요. 연결해서 정보를 주고받거나, 관련된 애플리케이션 사이의 승인과 검증이 필요한 작업을 실행할 때 쓰여요.

예를 들어 Zapier에서 Zap을 만드는 일도 여러 소프트웨어의 API에 연결하는 일이에요. Zapier는 이 과정을 사용자가 보기 쉽고 깔끔하게 만들어 줄 뿐이고, 그 안에서는 Zap 설정에 따라 여러 API 키가 서로 연결되어 움직여요.

서브 계정(위치)의 **API 키**는 Zapier처럼 특정 서브 계정(위치)과 정보를 주고받으려고 API 키를 요구하는 애플리케이션을 연결할 때 쓸 수 있어요.

### 정보 업데이트 버튼

일반 정보를 모두 수정했다면 **정보 업데이트**를 눌러 저장하세요.
