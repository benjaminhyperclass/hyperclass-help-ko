# 비즈니스 프로필 설정

**비즈니스 프로필**(Business Profile)에는 비즈니스 이름, 주소 등 여러 설정이 모여 있어요. 이 문서에서는 비즈니스 프로필의 위치와, 안에 어떤 섹션이 있는지 한눈에 살펴봐요.

## 비즈니스 프로필이란?

**비즈니스 프로필**은 서브 계정 설정 안에서 회사 정보를 입력하고, 서브 계정 전체에 적용되는 설정을 정하는 곳이에요. 이 섹션을 몇 분 들여 설정해 두는 것은 서브 계정이 동작하는 방식에 매우 중요해요.

각 섹션과 설정을 하나씩 살펴보면서 설정 방법을 알려 드려요. 설정이 어떤 결과로 이어지는지 이해할 수 있도록 활용 예시도 함께 소개해요.

---

## 비즈니스 프로필은 어디에 있나요?

**비즈니스 프로필**은 금방 찾을 수 있어요. 화면을 보며 따라 할 수 있도록 스크린샷도 함께 넣었어요. ▶ 영상 [2강 58:31](https://www.youtube.com/watch?v=woau-D9kDKE&t=3511s)

1. 사용할 서브 계정에 들어와 있는지 확인하세요.
2. 화면 왼쪽의 **설정**을 클릭하세요.

   ![왼쪽 메뉴의 설정 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052720909/original/8QoKf92HzhpdK0FzMP7HQPs77-cnVGd86Q.jpg?1756499151)
3. **설정**에 들어가면 왼쪽 **설정** 메뉴의 첫 번째 항목이 **비즈니스 프로필**이에요.
4. **비즈니스 프로필**은 설정의 첫 화면이기도 해요. **설정**을 클릭하면 비즈니스 프로필이 바로 열려요.

   ![설정 메뉴의 비즈니스 프로필 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052720925/original/K6U5dWOqpenrzsAySk2xyLoY2KuSwhfDcg.jpg?1756499168)

```
하이퍼클래스 로그인 -> 서브 계정 선택 -> 설정 클릭 -> 비즈니스 프로필
```

## 비즈니스 프로필 설정에는 무엇이 있나요?

비즈니스 프로필 설정은 7개 섹션으로 나뉘어요. 각 섹션이 무엇을 다루는지 아래에서 확인하세요.

#### 일반 정보

브랜드 정체성과 주요 계정 정보를 저장해요. 로고, 비즈니스 이름, 이메일·전화번호, 브랜드(API) 도메인, 웹사이트, 업종, 기본 통화, API 키가 여기에 들어가요. 자세한 내용은 해당 섹션 문서를 참고하세요.

#### 비즈니스 주소

공식 주소와 기본 지역 설정을 담아요. **Business Time Zone**(비즈니스 시간대), **플랫폼 언어**, **Outbound Communication Language**(발신 커뮤니케이션 언어)가 있고, 날짜와 숫자 형식에 쓰여요. 자세한 내용은 해당 섹션 문서를 참고하세요.

#### 비즈니스 정보

법인 유형, 업종, 등록 ID/번호, 운영 지역을 정해요. 이 정보는 규정 준수, 승인, 리포팅에 쓰여요. 자세한 내용은 해당 섹션 문서를 참고하세요.

#### 공식 대표자

규정 준수 심사나 통신사 승인 때 비즈니스를 확인해 줄 담당자(이름, 직함, 이메일, 전화번호)를 기록해요. 자세한 내용은 해당 섹션 문서를 참고하세요.

#### 일반

중복, 예약 시간대, 인증, 규정 준수 기본값, 봇 감지 등 전체 동작에 영향을 주는 토글이 모여 있어요. 관련 커뮤니케이션 동작도 여기서 정해요. 자세한 내용은 해당 섹션 문서를 참고하세요.

#### Contact Deduplication Preferences(연락처 중복 제거 환경설정)

중복 연락처를 허용할지 정해요. 새로 제출된 정보를 기존 연락처와 맞춰 볼 때 쓰는 기본·보조 필드(이메일, 전화번호)도 여기서 지정해요. 자세한 내용은 해당 섹션 문서를 참고하세요.

#### Enable / Disable Deprecated Features(지원 중단 예정 기능 활성화/비활성화)

예전 모듈을 표시하거나 숨겨요. 팀이 오래된 자산을 점검하거나 옮기면서, 워크플로우 같은 최신 기능으로 통일할 수 있어요. 자세한 내용은 해당 섹션 문서를 참고하세요.

## 자주 묻는 질문

### 이 설정은 서브 계정의 모든 사용자에게 적용되나요?

네. 서브 계정 전체에 적용돼요. 다만 일부 페이지는 사용자의 개인 시간대로 표시될 수 있어요.

### 나중에 설정을 바꿀 수 있나요?

네. 나중에 필요할 때 업데이트할 수 있어요. 변경한 내용은 테스트해 보세요.
