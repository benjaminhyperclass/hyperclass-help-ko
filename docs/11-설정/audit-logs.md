# 감사 로그

**감사 로그**는 하이퍼클래스 계정에서 누가 언제 무엇을 바꿨는지 기록해 두는 곳이에요. 새 디자인 시스템 UI에 맞춰 화면이 새로워졌고, 오른쪽 패널과 키보드 이동으로 기록을 더 빠르게 살펴볼 수 있어요. 이 문서에서는 영역별 필터 차이, 데이터 보관 기간(60일), 변경 내역을 효율적으로 조사하는 방법을 안내해요.

## 감사 로그란?

감사 로그는 하이퍼클래스 계정 전반에서 누가, 언제, 무엇을 했는지 확인할 수 있는 기준 기록이에요. 각 항목에는 시간과 함께 사용자, 모듈, 액션 정보가 남아요. 관리자는 이 기록으로 변경 사항의 원인을 찾고, 책임 소재를 확인하고, 규정 준수 요건을 충족할 수 있어요.

감사 로그는 계정에서 이루어진 주요 작업을 시간순으로 기록해서 관리자와 파워 유저가 투명하게 추적할 수 있게 해 줘요. 새 UI에서는 같은 정보를 더 깔끔하고 빠른 흐름으로 볼 수 있고, 새 디자인 시스템을 쓰는 다른 화면과도 일관돼요. 표를 벗어나지 않고도 상세 내용을 확인할 수 있어요.

---

## 새 감사 로그 UI의 장점

달라진 점을 알아 두면 팀이 빠르게 적응하고 조사할 때 자신 있게 쓸 수 있어요.

- 드로어 보기: 상세 내용이 오른쪽 패널에서 열려서 표에서 보던 위치를 잃지 않아요.
- 키보드 이동: `←`/`→` 키로 패널을 연 채 항목 사이를 빠르게 넘길 수 있어요.
- 일관된 구성 요소: 새 디자인 시스템의 여백과 글꼴 덕분에 읽기 편하고 눈이 덜 피로해요.
- 빠른 선별: 화면을 다시 불러오지 않고도 변경 내용을 확인하고, 근거를 남기고, 다음 항목으로 넘어갈 수 있어요.
- 더 높은 가시성과 책임성: 사용자, 계정, 설정에 이루어진 모든 변경을 추적해 수정 내역을 명확하게 남겨요.
- 빠른 문제 해결: 예상치 못한 변경을 빠르게 찾아 원인을 확인할 수 있어서 시간과 노력을 아껴요.
- 보안 및 규정 준수 강화: 사용자 작업을 모니터링해 무단 변경을 막고 정책 준수 여부를 확인해요.
- 효율적인 사용자 관리: 계정 생성, 수정, 삭제 같은 사용자 활동을 파악해 팀을 더 잘 관리해요.

## 드로어와 키보드 이동

오른쪽 드로어를 쓰면 변경 내역을 조사하는 동안 보던 위치를 그대로 유지할 수 있어요. 드로어를 연 뒤에는 닫지 않고 키보드로 기록 사이를 이동할 수 있어서, 긴 감사 기록도 빠르고 정확하게 훑어볼 수 있어요.

- 그 자리에서 상세 열기: 아무 행이나 클릭하면 오른쪽 드로어가 열리고 필드별 변경 전/후 값, 사용자, 시간이 보여요. 화면을 다시 불러오지 않고, 스크롤 위치도 그대로예요.

{% hint style="info" %}
**알림 설정 감사 상세 정보(서브 계정)**

**알림 설정** 변경은 업데이트 작업으로 표시돼요. 항목을 열면 상세 드로어에 바뀐 필드만 변경 전/후 값과 함께 보여요.

- 처음 저장할 때: 감사 로그에 모든 알림 설정이 기록돼요.
- 이후 업데이트: 감사 로그에는 수정한 설정만 기록돼요.
{% endhint %}

- 방향키로 이동: 드로어가 열린 상태에서 왼쪽·오른쪽 방향키를 누르면 이전 또는 다음 기록으로 넘어가요. 드로어가 그 자리에서 바뀌어서 집중이 끊기지 않아요.
- 클릭은 줄이고 속도는 높이기: 키보드에서 손을 떼지 않아도 되니 잘못 클릭할 일이 줄고, 오래 조사할 때도 빠르게 볼 수 있어요.
- 직접 제어하기: X 아이콘이나 `Esc` 키로 드로어를 닫으면 표에서 보던 위치로 정확히 돌아가요.

![드로어를 열고 방향키로 기록을 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055833940/original/_wW25CG9R1VywBJZ0THe7kcEgEnOKJEUOw.gif?1760346977)

## 삭제된 페이지 빌더 자산도 기록돼요

사용자가 저장해 둔 페이지 빌더 자산을 삭제하면 감사 로그에 **삭제됨** 항목이 만들어져요. 대상은 다음과 같아요.

- **섹션 템플릿**
- **Global Sections**(글로벌 섹션)
- **Universal Sections**(유니버설 섹션)
- **Element Templates**(요소 템플릿)
- **Universal Element Templates**(유니버설 요소 템플릿)

삭제 항목에는 에셋 이름과 에셋 ID가 함께 기록돼요. **퍼널**, **웹사이트**, **스토어**, **웨비나**에서 쓰는 자산에 적용돼요.

![삭제된 페이지 빌더 자산이 기록된 감사 로그 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066486228/original/qxFvwpbp4uWKvy8-bPGvc1qK3EeG9Cn14A.png?1773051169)

## 감사 로그 필터 이해하기

필터를 쓰면 결과가 좁혀져서 필요한 이벤트만 빠르게 골라낼 수 있어요. 각 옵션의 역할을 알아 두면 클릭 수를 줄여 더 빨리 확인할 수 있어요.

- **사용자**: 특정 팀원을 선택하면 그 사람이 한 작업만 볼 수 있어요. 개별 팀원의 활동을 모니터링하거나 수정이 의심될 때 조사하기 좋아요.

  ![사용자 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055831976/original/8XutF7qifjQ5ZCxF1n-1MWDDCmahm8XHDg.png?1760346219)
- **모듈**: 변경이 일어난 영역을 선택해요. 예를 들어 **사용자**, **Accounts**(계정), **연락처**, **기회 관리**, **웹사이트**/**퍼널**/**스토어**, **사용자 지정 객체**, **리스팅**, **알림 설정**, **대화 AI 활동**이 있어요. **대화 AI 활동**을 선택하면 에이전트 상태 변경과 인계 내역을 볼 수 있어요.

  ![모듈 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055832012/original/0gndVsLkGlGh1R6_bx-3uo6CwSS5jGSxhg.png?1760346234)
- **작업 유형**: **만들기**, **업데이트**, **삭제** 같은 변경 유형별로 결과를 좁혀요. 중요한 변경을 빠르게 찾을 때 유용해요.

  ![작업 유형 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055832024/original/emKTcDtli8VRTbJjO79_c-xCEZDlVSZA0Q.png?1760346246)
- **시간 범위**: 오늘, 최근 7일, 최대 **60일**처럼 기간을 정해서 변경이 일어난 시점에 맞춰 볼 수 있어요.

  ![시간 범위 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055832034/original/rKVwzwK1WHGuhVvCoGqa7rhI2bcpcTVxyw.png?1760346257)

## 감사 로그 내보내기(CSV 다운로드)

필터를 적용한 감사 로그를 CSV 파일로 내보낼 수 있어요. 내보내기는 백그라운드에서 진행돼요. 진행 상황을 확인하고 완성된 파일을 내려받으려면 **내보내기** 탭을 이용하세요.

자세한 순서는 [감사 로그 내보내기](감사-로그/exporting-audit-logs.md)를 참고하세요.

## 감사 로그 열기

새 디자인은 **에이전시**와 **서브 계정**(로케이션) 모두에 적용돼 있어요. 확인하려는 위치에서 감사 로그를 열면 돼요. 각 화면에는 해당 범위의 기록만 보여요(에이전시 전체 또는 해당 로케이션).

{% hint style="info" %}
**알림 설정** 감사 로그는 서브 계정(로케이션)의 감사 로그에서만 볼 수 있어요.
{% endhint %}

1. 확인할 범위를 선택해요.
   - 에이전시 전체 활동: **에이전시 > 설정 > 감사 로그**로 이동하세요.
   - 서브 계정 활동: **서브 계정 > 설정 > 감사 로그**로 이동하세요.

   ![감사 로그 메뉴로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055835291/original/Pnzxpj5NKxcRNUrlIRqd1WHHRGBOkjTxuQ.gif?1760347591)
2. 감사 로그 목록에서 **미리보기**(눈 모양) 버튼이나 행의 아무 곳이나 클릭해 해당 로그의 상세 드로어를 열어요.

   ![감사 로그 상세 드로어가 열린 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055834650/original/9Oft3dRvCq76JHfDu5NXJqJ3he3bWvYu-w.png?1760347370)
3. 드로어를 연 채로 키보드의 `←`/`→` 키를 눌러 항목을 차례로 넘겨 보세요.

   ![방향키로 항목을 넘겨 보는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055835409/original/6jLq2dLOG-Y7jIhz1YI2mt45liW0QYgLOA.gif?1760347629)
4. **필터 적용**으로 결과를 좁혀요. **사용자** 필터는 에이전시와 서브 계정 감사 로그 모두에서 쓸 수 있어요. **모듈**, **액션** 같은 다른 필터 옵션은 모듈에 따라 다를 수 있어요.

   ![필터를 적용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055834175/original/6gWoK2woPaa6YUu0lT01f52tQSHzqWG1Dw.png?1760347099)
5. **퍼널**/**웹사이트**/**웨비나**/**스토어**처럼 모듈별로 확인하려면 해당 서브 계정 안에서 **설정 > 감사 로그**를 열어 보세요.

## 감사 로그에서 보는 대화 AI 활동

감사 로그는 **대화 AI** 활동도 기록해요. 에이전트를 켜거나, 끄거나, 일시중지하거나, 다른 담당으로 바꾼 내역이 여기에 남아요. 이 기록으로 무엇이 변경을 일으켰는지, 언제 일어났는지, 누가(또는 무엇이) 시작했는지 확인할 수 있어요.

기록을 보려면 서브 계정에서 **설정 > 감사 로그**로 이동한 뒤 **모듈** 필터에서 **대화 AI 활동**을 선택하세요. 특정 연락처의 감사 기록은 **대화 > 연락처 세부정보 > 감사 로그**에서도 볼 수 있어요.

추적되는 활동, 사용할 수 있는 필터, 감사 로그 상세 내용은 [감사 로그의 대화 AI 활동](감사-로그/how-to-track-conversation-ai-activity-in-audit-logs.md)에서 자세히 확인하세요.

## 자주 묻는 질문

### 감사 로그는 누가 볼 수 있고, 어디서 찾나요?
에이전시 단위 로그는 에이전시 관리자가 **에이전시 > 설정 > 감사 로그**에서 볼 수 있어요. 서브 계정 안의 모듈별 로그는 보통 계정 관리자가 **서브 계정 > 설정 > 감사 로그**에서 볼 수 있어요.

### 로그는 얼마 동안 보관되나요?
감사 로그 항목은 **60일** 동안 보관된 뒤 삭제돼요. 필요한 증거는 이 기간 안에 확보해 두세요.

### 감사 로그를 내보낼 수 있나요?
네. 오른쪽 위의 **감사 로그 내보내기**를 이용하세요.

### 많은 항목을 가장 빠르게 확인하려면 어떻게 하나요?
먼저 **날짜**를 적용하고, 이어서 **액션**/**모듈**로 목록을 좁히세요. 첫 번째 행을 열고 `←`/`→` 키를 누르면 드로어를 연 채로 결과를 차례로 넘겨 볼 수 있어요.

### 삭제된 항목(예: 기회)을 빠르게 찾아 복원하려면 어떻게 하나요?
**액션**을 **삭제됨**으로, **모듈**을 해당 모듈(예: 기회)로 필터링하세요. 항목을 열면 복원을 지원하는 경우 복원 옵션을 쓸 수 있어요. 자세한 내용은 [기회와 파이프라인 삭제 및 복원](../05-기회-파이프라인/시작하기/deleting-and-restoring-opportunities-pipelines.md)을 참고하세요.

### 팀이나 기기마다 시간이 다르게 보이는 이유가 뭔가요?
시간대 차이 때문에 시간이 서로 다르게 보일 수 있어요. 기기의 시간대와 서브 계정의 지역 설정을 확인해 보세요.

### WordPress 접근/활동 로그는 감사 로그와 어떤 관계인가요?
WordPress 로그는 사이트 생성·삭제 같은 주요 이벤트에 대해 플랫폼의 감사 로그를 보완해 줘요. 두 로그를 함께 보면 처음부터 끝까지 이어지는 감사 기록을 만들 수 있어요. 자세한 내용은 [WordPress 접근 및 활동 로그](../06-사이트/워드프레스/wordpress-access-activity-logs.md)를 참고하세요.
