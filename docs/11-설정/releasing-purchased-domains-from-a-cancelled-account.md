# 해지된 계정에서 구매한 도메인 해제 요청하기

하이퍼클래스에서 도메인을 구매한 뒤 계정이 해지되면, 그 도메인을 해제하거나 이전할 때 도움이 필요할 수 있어요. 이 문서에서는 도메인 해제 요청 폼을 언제 쓰는지, 어떤 정보를 준비해야 하는지, 요청이 어떻게 담당 지원 큐로 전달되는지 안내해요. 하이퍼클래스 계정에서 구매한 도메인을 더 이상 관리할 수 없을 때 이 방법을 이용하세요.

## 해지된 계정의 구매 도메인 해제란?

구매 도메인 해제 요청은 계정이 해지된 고객이 하이퍼클래스 고객지원에 도움을 요청하는 방법이에요. 하이퍼클래스에서 처음 구매한 도메인을 해제하거나 이전하고 싶을 때 쓸 수 있어요. 하이퍼클래스에서 구매한 도메인은 계정이 활성 상태일 때 플랫폼 안에서 직접 관리해요.

**구매한 도메인** 영역에서는 A, CNAME, AAAA, MX, TXT 같은 DNS 레코드를 관리할 수 있어요. 계정이 해지되어 평소처럼 도메인 관리 설정에 들어갈 수 없다면, 도메인 해제 요청 폼으로 고객지원에 바로 요청을 보낼 수 있어요.

---

## 이 절차의 장점

이 절차를 이용하면 해지 후에도 도메인을 지킬 수 있어요. 고객지원은 요청을 빠르게 검토하는 데 필요한 정보를 받아요.

- 요청 경로가 분명해요: 계정이 해지된 고객은 일반 도메인 문서를 찾아다니거나 관련 없는 티켓을 열 필요 없이, 전용 폼 하나만 쓰면 돼요.
- 고객지원으로 바로 전달돼요: 폼으로 제출한 요청은 검토를 맡은 티켓 큐로 곧바로 전달돼요.
- 다음 단계를 쉽게 찾을 수 있어요: 앱 안에서 도메인 설정에 들어갈 수 없을 때 어떻게 해야 하는지 도메인 문서에서 확인할 수 있어요.
- 헷갈리지 않아요: 이 폼은 해지된 계정의 해제 요청을 구분해 줘요. 활성 계정의 도메인 설정이나 Cloudflare 이전(transfer-out) 절차와는 달라요.
- 도메인을 이어서 관리할 수 있어요: 하이퍼클래스에서 구매한 도메인은 여러 해 동안 등록한 도메인도 도움을 요청할 수 있어요.

---

## 도메인 해제 요청 폼을 쓰는 경우

도메인 해제 요청 폼은 하이퍼클래스에서 도메인을 구매했고, 계정이 해지된 뒤 도움이 필요한 고객을 위한 폼이에요.

```
아래에 해당하면 이 폼을 사용하세요.

하이퍼클래스 계정이 해지되었어요.

하이퍼클래스에서 도메인을 구매했어요.

구매한 도메인을 관리하려고 해도 계정에 더 이상 들어갈 수 없어요.

도메인 해제 또는 이전에 도움이 필요해요.

해지된 계정에 남아 있는 도메인의 관리 권한을 되찾으려고 해요.
```

계정이 아직 활성 상태라면 일반적인 DNS 설정에는 이 폼을 쓰지 마세요. 활성 계정은 서브 계정에서 **설정 > 도메인 > 구매한 도메인**으로 들어가 구매한 도메인을 관리하세요. 그곳에서 DNS 레코드와 도메인 연결을 직접 설정할 수 있어요.

---

## 폼을 제출하면 어떻게 되나요?

폼을 제출하면 하이퍼클래스 고객지원이 검토할 요청이 만들어져요. 요청은 후속 처리를 맡은 티켓 큐로 바로 전달돼요.

제출한 뒤에는 아래 순서로 진행돼요.

1. 하이퍼클래스 고객지원이 요청 내용을 검토해요.
2. 고객지원이 계정, 도메인, 소유권 정보를 확인할 수 있어요.
3. 추가 정보가 필요하면 고객지원이 티켓으로 다시 연락해요.
4. 도메인과 계정 상태에 따라 도메인 해제 또는 이전 요청을 처리해요.

폼을 제출한다고 도메인이 바로 해제되거나 이전되지는 않아요. 제출하면 고객지원의 검토가 시작돼요.

---

## 해지된 계정의 구매 도메인 해제를 요청하는 방법

요청서를 빠짐없이 작성하면 고객지원이 도메인을 찾고 해지된 계정의 상황을 검토하는 데 필요한 정보를 얻을 수 있어요.

1. [도메인 해제 요청 폼](https://api.golevel.bid/widget/form/IDn1mHxUWwEKay1LH2Yr)을 열어요.
2. 요청하는 연락처와 계정 정보를 입력해요.
3. 해제하거나 이전해야 하는 구매 도메인 이름을 입력해요.
4. 해지된 계정을 찾는 데 도움이 될 만한 정보를 추가해요. 예를 들어 계정 이메일, 에이전시 이름, 서브 계정 이름이 있어요.

   ![도메인 해제 요청 폼 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073018858/original/ld9SILrJ-eGPuR12V1b7EoFzWvdE0dlntQ.jpeg?1780669355)
5. 폼을 제출해요.
6. 정보가 더 필요하면 고객지원에서 연락이 오니 확인하세요.

## 자주 묻는 질문

### 도메인 해제 요청 폼은 누가 사용해야 하나요?
계정이 해지되었고, 하이퍼클래스에서 구매한 도메인의 해제나 이전에 도움이 필요한 고객이 사용하세요.

### 계정이 아직 활성 상태인데 이 폼을 써도 되나요?
아니요. 계정이 활성 상태라면 서브 계정에서 **설정 > 도메인 > 구매한 도메인**으로 들어가 구매한 도메인을 관리하세요.

### 폼을 제출하면 도메인이 자동으로 이전되나요?
아니요. 폼을 제출하면 검토를 위한 지원 요청이 만들어져요. 고객지원이 처리하기 전에 계정, 도메인, 소유권 정보를 확인할 수 있어요.

### 다른 등록 업체에서 연결한 도메인에도 이 폼을 쓸 수 있나요?
아니요. 이 절차는 하이퍼클래스에서 구매한 도메인에만 해당해요. 다른 등록 업체에서 구매한 도메인은 그 등록 업체에서 관리하세요.

### 도메인을 여러 해 동안 등록했는데 어떻게 하나요?
하이퍼클래스에서 구매한 도메인이고 계정이 해지되었다면 이 폼을 제출할 수 있어요. 여러 해 등록은 등록 기간에만 영향을 줘요. 해지된 계정의 해제 요청은 그대로 도메인 해제 요청 폼으로 접수하세요.

### 폼에 어떤 정보를 넣어야 하나요?
도메인 이름, 계정 이메일, 아는 경우 에이전시 이름이나 서브 계정 이름을 적어 주세요. 고객지원이 올바른 계정을 찾을 수 있도록 폼에서 요청하는 다른 정보도 함께 입력하세요.

### Cloudflare로 도메인을 이전하는 것과 같은 절차인가요?
아니요. Cloudflare 이전(transfer-out)은 별도의 이전 절차예요. 해지된 계정의 해제나 이전 요청은 도메인 해제 요청 폼으로 접수하세요.

### 해지된 계정의 도메인을 고객지원이 모두 해제해 주나요?
고객지원은 제출한 도메인과 계정 정보를 바탕으로 요청을 검토해요. 추가 확인이 필요할 수 있어요.
