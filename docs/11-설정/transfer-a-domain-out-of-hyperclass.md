# 하이퍼클래스에서 다른 등록 기관으로 도메인 이전하기

하이퍼클래스에 있는 도메인의 등록과 갱신 관리를 다른 도메인 등록 기관으로 옮기는 방법을 안내해요. 일반적인 이전은 고객지원에 문의하지 않고 직접 진행할 수 있어요. 하이퍼클래스가 도메인이 이전 가능한지 확인해 주고, 잠금 해제와 함께 받는 쪽 등록 기관에 필요한 EPP 인증 코드 발송까지 처리해 줘요.

## 도메인 이전이란?

도메인 이전(Transfer-Out)은 하이퍼클래스에서 구매했거나 하이퍼클래스로 이전해 온 도메인을 다른 등록 기관으로 옮기는 셀프 서비스 기능이에요. 이전 가능 여부 확인, 필요한 경우 잠금 해제, 요청 확인용 EPP 인증 코드 발송까지 이전의 첫 단계를 간단하게 해 줘요.

이전은 하이퍼클래스에서 해당 도메인의 **고급 설정**에서 시작해요. 인증 코드를 받은 뒤에는 받는 쪽 등록 기관에서 나머지 이전 절차를 직접 마쳐야 해요.

{% hint style="warning" %}
Cloudflare로 이전할 때는 별도 절차를 따라야 하며, 일반적인 EPP 코드 방식으로 진행하면 안 돼요. 최신 Cloudflare 전용 안내는 [하이퍼클래스에서 Cloudflare로 도메인 이전하기](Domain-Purchase/Transfer/domain-transfer-out-to-cloudflare.md)를 참고하세요.
{% endhint %}

{% hint style="info" %}
.uk 도메인 계열(.uk, .co.uk, .org.uk, .me.uk)은 이전하려면 고객지원의 도움이 필요해요.
{% endhint %}

## 도메인 이전의 장점

- 셀프 서비스 이전: 이전 가능한 도메인은 하이퍼클래스에서 바로 이전을 시작할 수 있어요.
- 자동 이전 가능 여부 확인: 인증 코드를 요청하기 전에 이전을 막는 제한 사항을 미리 알 수 있어요.
- 간편한 잠금 해제: 필요할 때 같은 이전 화면에서 도메인 잠금을 풀 수 있어요.
- 안전한 인증: 받는 쪽 등록 기관에서 이전을 확인하는 데 쓰는 EPP 코드를 받아요.
- 등록 기관 선택의 자유: 이전 가능한 도메인을 지원하는 다른 등록 기관으로 옮길 수 있어요.
- 예외 상황 안내: Cloudflare, .uk 도메인, 해지된 계정의 도메인은 각각 별도 절차가 있어요.

## 이전 가능 여부

이전 가능 여부 확인은 도메인이 무단으로 옮겨지는 것을 막고, 등록 기관과 레지스트리의 요건을 충족하는지 확인하기 위한 절차예요. 이전을 시작하기 전에 결과를 확인하면 바로 진행할 수 있는지, 먼저 해결할 제한이 있는지 알 수 있어요.

다음 경우에는 도메인을 이전할 수 없어요.

- 최근 60일 이내에 등록했거나 이전해 온 경우
- 현재 등록 기관이나 레지스트리에서 이전을 금지한 경우
- 이미 다른 이전이 진행 중인 경우

이전할 수 없다고 나오면 이전 가능 여부 결과에 표시된 메시지를 확인하고, 제한 사항을 해결한 뒤 다시 시도하세요.

{% hint style="warning" %}
기본 셀프 서비스 절차는 사용 중인 하이퍼클래스 계정으로 접근할 수 있는 도메인을 위한 방법이에요. 계정이 이미 해지된 경우에는 도메인 해제 요청을 제출하세요. 해지된 계정의 구매한 도메인 해제 안내 문서를 따라 소유권과 계정 정보를 제공해야 해요.
{% endhint %}

## 도메인 이전 절차

각 단계를 순서대로 진행하면 하이퍼클래스가 도메인 상태를 확인하고 인증 코드를 안전하게 보내 줘요. EPP 코드를 요청한다고 해서 이전이 끝나지는 않아요. 이전 신청과 완료는 받는 쪽 등록 기관에서 해야 해요.

### 1단계: 도메인 설정 열기

1. **설정 > 도메인 & URL 리다이렉트**로 이동하세요.
2. 이전하려는 도메인을 찾아 **관리**를 클릭하세요.

![도메인 목록에서 관리 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077835124/original/TO7ooxYzoiB_oj2Z_bUcQNhawRh4rnTMQw.png?1786047378)

### 2단계: 고급 설정 열기

1. 해당 도메인의 **고급 설정** 탭을 선택하세요.
2. **구성**을 클릭한 다음 **다른 등록 기관으로 이전** 옵션을 찾으세요.
3. **다른 등록 기관으로 이전**을 클릭하면 도메인의 이전 가능 여부 확인이 자동으로 진행돼요.

![고급 설정의 다른 등록 기관으로 이전 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077835274/original/-B-vdUvLaGqBesqto4hTn2li6k9wnvhAPA.png?1786047512)

### 3단계: 등록 기관 선택

드롭다운에서 도메인을 받을 등록 기관을 선택하세요. 등록 기관을 선택해도 이전이 끝나지는 않아요. 인증 코드를 요청하기 전에 도메인을 어디로 옮길지 알려 주는 단계예요.

![받을 등록 기관 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077835441/original/0yGOdtyhkKfz_D4W7sTQiysS_ER3azitrw.png?1786047695)

### 4단계: 도메인 잠금 해제

도메인이 잠겨 있으면 **도메인 잠금 해제**를 사용해 잠금을 풀어 주세요. 등록 기관의 잠금은 도메인이 무단으로 이전되는 것을 막아 줘요. 받는 쪽 등록 기관이 이전을 마치려면 먼저 도메인 잠금을 풀어야 해요.

![도메인 잠금 해제](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077835463/original/zxRcDWDc3oqqNwfgGXs2Awse3AfTzvmlPA.png?1786047764)

### 5단계: EPP 인증 코드 요청

**코드 가져오기**를 클릭해 EPP 인증 코드를 요청하세요. EPP 코드는 이전을 요청한 사람이 도메인을 옮길 권한이 있다는 것을 확인해 줘요.

요청이 성공하면 인증 코드를 보낸 이메일 주소가 일부 가려진 상태로 표시돼요. 이 화면에는 EPP 코드 자체가 표시되지 않아요.

![코드 가져오기 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077835500/original/t7ccbwJ2j2xyf6ZH269wlqVnz3h5OQP-IQ.png?1786047841)

### 6단계: 인증 코드를 받은 이메일함 확인

EPP 인증 코드를 요청하면 확인 화면에 코드를 보낸 이메일 주소가 일부 가려진 상태로 표시돼요.

이메일 주소는 전체 주소를 보호하기 위해 다음과 같이 가려져요.

1. 앞부분(@ 앞) 또는 도메인 부분이 3자 이상이면 첫 글자와 마지막 글자만 보이고, 그 사이 글자는 가려져요.
2. 2자이면 첫 글자만 보여요.
3. 1자이면 그 글자를 완전히 가려요.
4. .com, .org 같은 최상위 도메인은 그대로 보여요.

코드를 받는 이메일 주소가 3개 이상이면 처음 두 개의 가려진 주소와 **+N more**(N개 더)가 표시돼요. **+N more**에 마우스를 올리면 나머지 주소를 볼 수 있어요.

표시된 이메일 주소의 받은 편지함, 스팸 폴더, 필터링된 폴더를 모두 확인하세요. EPP 인증 코드는 이메일로 발송되며, 이전 확인 화면에는 표시되지 않아요.

코드가 오지 않거나 새 코드가 필요하면 최소 5분 기다린 뒤 다시 요청하세요. 이전을 마칠 때는 가장 최근에 받은 코드를 사용하세요.

![인증 코드를 보낸 이메일 주소 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077835588/original/UTOv-ihw2VaWIlUtvo3Mu5XpDZrxV1tnmA.png?1786047961)

![가려진 이메일 주소 표시 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080115814/original/4Fg357w8bLvA0XMmxhdN1JnupTe6EHv98g.png?1788528440)

### 7단계: 받는 쪽 등록 기관에서 이전 완료

받는 쪽 등록 기관에 로그인해서 도메인 이전 절차를 여세요. 도메인 이름과 EPP 인증 코드를 입력한 다음, 필요한 결제, 연락처 인증, 이전 승인 절차를 마치세요.

받는 쪽 등록 기관 계정과 인증 코드를 받은 이메일함에서 진행 상황 알림이나 승인 요청이 오는지 확인하세요. 이전이 끝나면 새 등록 기관 계정에 도메인이 보이는지 확인하세요. 그리고 네임서버와 DNS 레코드를 점검하고, 연결된 웹사이트, 퍼널, 이메일 서비스가 잘 동작하는지 테스트하세요.

## 자주 묻는 질문

### EPP 코드를 요청하면 이전이 완료되나요?

아니요. EPP 코드를 요청하면 받는 쪽 등록 기관에서 이전을 시작할 수 있는 인증만 받을 뿐이에요. 이전 신청과 완료는 그 등록 기관에서 해야 해요.

### 다른 곳에서 구매해 하이퍼클래스에 연결한 도메인도 이전할 수 있나요?

다른 등록 기관에서 구매한 도메인은 계속 그 등록 기관에서 관리해요. 현재 도메인이 등록된 등록 기관에서 이전을 시작하세요.

### Cloudflare로 일반 절차대로 이전할 수 있나요?

아니요. Cloudflare 이전은 별도 절차를 따라야 해요. 해당 단계는 [하이퍼클래스에서 Cloudflare로 도메인 이전하기](Domain-Purchase/Transfer/domain-transfer-out-to-cloudflare.md) 문서를 참고하세요.

### .uk 도메인도 EPP 코드로 이전할 수 있나요?

.uk 계열 도메인은 이전 절차가 달라요. 하이퍼클래스 고객지원에 문의하세요.

### 하이퍼클래스 계정이 해지되었어요. 어떻게 해야 하나요?

해지된 계정의 도메인은 도메인 해제 요청 절차를 이용하세요. 계정에 접근할 수 없게 되면 일반 이전 기능을 쓸 수 없을 수 있어요.
