# 인증 앱으로 이중 인증(2FA) 사용하기

이중 인증(2FA)에 앱 기반 인증 방식이 추가됐어요. TOTP 방식의 인증 앱을 연결하면 로그인할 때와 그 밖의 보안 확인 단계에서 시간제 인증 코드를 쓸 수 있어요. 계정을 복구할 때 쓸 백업 코드도 저장해 둘 수 있어요.

## 인증 앱 2FA란?

인증 앱 2FA는 시간제 일회용 비밀번호(TOTP)를 계정의 추가 인증 수단으로 쓰는 기능이에요.

TOTP를 지원하는 인증 앱이면 모두 쓸 수 있어요. Google Authenticator, Microsoft Authenticator, Authy 등이 대표적이에요.

설정을 마치면 인증 앱이 임시 인증 코드를 만들어 줘요. 이 코드는 로그인할 때와 그 밖의 보안 확인 단계에서 쓸 수 있어요.

## 주요 장점

- 앱 기반 인증: SMS나 이메일 전송에만 의존하지 않고 시간제 인증 코드를 만들 수 있어요.
- 간편한 설정: QR 코드 또는 수동 설정 키로 인증 앱을 연결할 수 있어요.
- 백업 수단: 인증 앱에 접근할 수 없게 될 때를 대비해 일회용 백업 코드를 저장해 둘 수 있어요.
- 계정 보안 강화: TOTP 인증은 SMS 인증에 대한 의존을 줄여 주고, SIM 스와핑 공격 같은 위험을 막는 데 도움이 돼요.

인증 앱 코드는 로그인 이메일 변경 확인처럼 중요한 계정 작업에서 인증이 필요할 때도 쓸 수 있어요.

## 인증 앱 연결하기

아래 순서대로 계정에 인증 앱을 연결하세요.

### 1단계: 내 프로필에서 보안 설정 열기

1. **에이전시 보기**에서 **설정 > 내 프로필 > 보안**으로 이동하세요.
2. **Two-Factor Authentication**(이중 인증) 영역에서 **인증 앱** 설정을 여세요.
3. 사용 중인 인증 앱으로 화면에 나온 QR 코드를 스캔하거나, 제공된 설정 키를 직접 입력하세요.

{% hint style="info" %}
**보안**은 에이전시 화면과 서브 계정 화면 모두에서 **내 프로필**에 있어요.
{% endhint %}

![이중 인증 영역에서 인증 앱 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082696215/original/uuWGUfqD3jti1HfjA3XiQw-7Ftx_6EPwKQ.png?1791348933)

### 2단계: 인증 앱 확인하기

QR 코드를 스캔하거나 설정 키를 입력하면 인증 앱이 일회용 인증 코드를 만들어 줘요.

1. 안내에 따라 인증 앱에 표시된 현재 코드를 입력하세요.
2. 인증 절차를 마무리하세요.

![인증 앱 코드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082696123/original/rSrtdqSfIjwUHjw9JVqufIn5yOdbRZE70A.png?1791348622)

### 3단계: 백업 코드 저장하기

설정이 끝나면 만들어진 **백업 코드**를 안전한 곳에 보관하세요. 인증 앱에 접근할 수 없을 때 이 코드를 쓸 수 있어요.

백업 코드를 잃어버렸거나 노출됐거나 이미 다 썼다면 **내 프로필 > 보안**에서 새로 만들 수 있어요.

![백업 코드 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082696141/original/FI5Qc6gqScl1kJVD0VHpu660qgT-MedJoQ.png?1791348666)

### 로그인할 때 인증 앱 사용하기

로그인 중 이중 인증을 요청하면 **인증 앱** 옵션을 선택하고, 앱에 표시된 현재 인증 코드를 입력하세요.

## 중요 사항

- 현재 로그인한 사용자만 자기 계정에 인증 앱을 설정할 수 있어요. 관리자가 **로그인** 기능으로 다른 사용자의 인증 앱을 대신 설정할 수는 없어요.
- 백업 코드는 한 번에 10개가 만들어지고, 각 코드는 한 번만 쓸 수 있어요.
- 인증 앱에 에이전시 이름이 표시될 수 있어요. 인증 앱 설정은 해당 사용자와 에이전시 조합에 연결돼요.
- 백업 코드는 안전하게 보관하고 다른 사용자와 공유하지 마세요.

## 자주 묻는 질문

### 아무 인증 앱이나 써도 되나요?

네. TOTP를 지원하는 인증 앱이면 모두 쓸 수 있어요. Google Authenticator, Microsoft Authenticator, Authy 등이 있어요.

### 인증 앱에 접근할 수 없게 되면 어떻게 하나요?

가지고 있는 백업 코드를 사용하세요. 계정에 접근할 수 있을 때 **내 프로필 > 보안**에서 백업 코드를 관리하거나 다시 만들 수 있어요.

### 인증 앱은 누가 설정할 수 있나요?

현재 로그인한 사용자만 자기 계정의 인증 앱을 설정할 수 있어요. 관리자가 **로그인** 기능으로 다른 사용자의 인증 앱을 대신 설정할 수는 없어요.

### 백업 코드는 몇 개가 만들어지나요?

한 번에 10개가 만들어져요. 각 백업 코드는 한 번만 쓸 수 있어요.

### SMS 인증과 비교하면 인증 앱은 보안상 어떤 점이 좋나요?

인증 앱은 SMS 전송에 의존하지 않고 시간제 인증 코드를 만들어요. 그래서 SIM 스와핑 공격 같은 위험에 덜 노출돼요.
