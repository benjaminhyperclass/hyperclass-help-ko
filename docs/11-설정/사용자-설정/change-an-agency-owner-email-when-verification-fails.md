# 인증이 안 될 때 에이전시 소유자 이메일 변경하기

하이퍼클래스에서는 이메일, SMS, 인증 앱(Authenticator App) 같은 인증 방법으로 로그인 이메일을 바꿀 수 있어요. **에이전시 소유자**가 이 방법으로 인증을 마칠 수 없을 때는 원하는 이메일로 대체 **에이전시 관리자**를 만들고, 그 사용자에게 에이전시 소유권을 이전하면 돼요. 이 문서에서는 이 방법을 언제 쓰는지, 대체 사용자를 어떻게 준비하는지, 소유권을 안전하게 이전하는 방법을 안내해요.

{% hint style="warning" %}
현재 이메일 주소로 인증 메시지를 받을 수 없다는 이유만으로 대체 사용자를 만들지 마세요. 현재 에이전시 소유자가 SMS나 인증 앱 같은 다른 방법으로 로그인 이메일 변경을 인증할 수 있다면, 일반 이메일 변경 절차를 사용하세요.
{% endhint %}

## 에이전시 소유자 이메일 변경 대체 절차란?

일반 이메일 변경 절차를 마칠 수 없을 때, 올바른 에이전시 소유자 로그인을 만드는 다른 방법이에요. 기존 사용자 프로필을 고치는 대신, 원하는 이메일 주소로 에이전시 수준의 관리자를 한 명 더 만들고 그 사용자에게 에이전시 소유권을 이전해요.

하이퍼클래스의 일반 로그인 이메일 변경 절차는 이메일, SMS, 인증 앱 등 사용 가능한 인증 방법을 쓸 수 있어요. 이 방법 중 하나로 현재 에이전시 소유자가 이메일을 바꿀 수 있다면 대체 프로필은 필요 없어요.

소유권 이전 절차는 다음 경우에만 사용하세요.

- 일반 이메일 변경을 여전히 마칠 수 없을 때
- 계정 접근 문제 때문에 일반 절차를 진행할 수 없을 때
- 하이퍼클래스 고객지원이 대체 사용자 방식을 안내했을 때

### 이 절차의 장점

현재 에이전시 소유자 프로필로 일반 로그인 이메일 변경을 마칠 수 없을 때, 대체 에이전시 관리자를 쓰면 통제된 방식으로 해결할 수 있어요. 대체 계정이 준비되어 소유권을 이전하기 전까지는 기존 소유자가 계속 권한을 갖고 있어요.

- 에이전시 접근 유지: 소유권 이전이 끝날 때까지 기존 에이전시 소유자를 그대로 사용할 수 있어요.
- 로그인 정보 바로잡기: 올바르고 접근 가능한 이메일 주소가 있는 사용자 프로필로 에이전시 소유권을 옮겨요.
- 로그인 정보 사전 확인: 소유권을 이전하기 전에 대체 사용자의 로그인 정보를 테스트해서 또 다른 접근 문제가 생길 위험을 줄여요.
- 통제된 소유권 이전: 에이전시 소유자 기능으로, 자격이 있는 에이전시 관리자에게 소유권을 이전해요.
- 지원 경로 확보: 직접 해결할 수 없는 로그인·인증 문제는 하이퍼클래스 고객지원에 문의할 수 있어요.

### 이 절차를 쓰는 경우

가능하면 일반 이메일 변경 절차를 먼저 쓰세요. 그러면 사용자를 새로 만들거나 역할을 바꾸지 않아도 돼요. 대체 사용자 방식은 로그인 이메일 변경이 계속 막힐 때를 위한 방법이에요.

다음과 같은 경우에 이 대체 절차를 사용하세요.

- 에이전시 소유자가 사용 가능한 인증 방법으로 일반 로그인 이메일 변경을 마칠 수 없을 때
- 현재 로그인 이메일이 잘못되었거나 접근할 수 없고, 다른 인증 방법으로도 이메일 변경 문제가 해결되지 않을 때
- 계정 접근이나 인증 문제 때문에 일반 이메일 변경을 마칠 수 없을 때
- 하이퍼클래스 고객지원이 에이전시 관리자를 새로 만들고 에이전시 소유권을 이전하라고 안내했을 때

일반 절차를 먼저 시도하세요. 기존 에이전시 소유자가 이메일, SMS, 인증 앱 등 사용 가능한 방법으로 로그인 이메일 변경을 인증할 수 있다면, 대체 사용자를 만들지 말고 기존 프로필을 수정하세요.

{% hint style="warning" %}
에이전시 소유자 로그인 이메일은 로그인에 쓰는 개별 사용자 프로필에 속해 있어요. 에이전시 **설정 > 회사 설정**에 등록된 **회사 이메일**과는 달라요.
{% endhint %}

## 시작하기 전에

소유권 이전은 현재 에이전시 소유자 프로필에서 시작해야 해요. 그래서 현재 소유자에 접근할 수 있어야 해요. 이전을 시작하기 전에 접근 가능 여부, 대체 이메일, 새 사용자의 역할을 확인하세요.

- 현재 에이전시 소유자 계정에 접근할 수 있는지 확인하세요.
- 대체할 이메일 주소가 올바르고 접근 가능한지 확인하세요.
- 하이퍼클래스가 본인 확인을 요청하면 사용 가능한 인증 방법으로 진행하세요.
- 대체 사용자를 에이전시 수준의 관리자로 준비하세요.
- 현재 에이전시 소유자 계정에 접근할 수 없거나 필요한 인증을 마칠 수 없다면, 계속 진행하기 전에 하이퍼클래스 고객지원에 문의하세요.

## 대체 사용자 요건

에이전시 소유권은 자격이 있는 에이전시 관리자에게만 이전할 수 있어요. 대체 사용자를 올바른 사용자 유형과 역할로 만들어야 소유권 이전 때 선택할 수 있어요.

대체 프로필은 다음과 같이 설정하세요.

- 에이전시 소유자의 올바른 이름
- 올바른 로그인 이메일 또는 사용하려는 로그인 이메일
- 해당하는 경우 유효한 전화번호
- **사용자 유형**: **에이전시**
- **역할**: **관리자**

### 로그인 정보 사전 확인(권장)

소유권을 이전하기 전에 대체 프로필로 로그인해서 로그인 정보와 인증 방법이 잘 작동하는지 확인해 두면 좋아요. 에이전시에 접근하지 못하는 사용자에게 소유권을 넘기는 위험을 줄일 수 있어요.

## 하이퍼클래스 고객지원에 문의해야 하는 경우

로그인이나 인증에 문제가 있으면 현재 에이전시 소유자가 일반 이메일 변경도, 소유권 이전 대체 절차도 마치지 못할 수 있어요. 현재 소유자 프로필에 안전하게 접근할 수 없다면, 역할을 바꾸기 전에 먼저 문의하세요.

다음과 같은 경우 하이퍼클래스 고객지원에 문의하세요.

- 현재 에이전시 소유자 프로필에 로그인할 수 없을 때
- 필요한 인증 방법으로 인증 코드를 받거나 인증을 마칠 수 없을 때
- 사용 가능한 인증 방법이 계속 실패할 때
- **소유권 이전**을 사용할 수 없을 때
- 사용자를 올바르게 설정했는데도 대체 에이전시 관리자가 소유권 이전 대상에 나타나지 않을 때

하이퍼클래스에 로그인할 수 있다면 도움말 메뉴의 고객지원 옵션을 이용하세요. 로그인할 수 없다면 24/7 고객 지원 옵션에 안내된 외부 연락 방법을 이용하세요.

## 인증이 안 될 때 에이전시 소유자 이메일 변경 절차

소유권을 바꾸기 전에 대체 에이전시 관리자를 먼저 만들고, 대체 계정의 로그인 정보가 쓸 수 있는지 확인하세요. 그런 다음 현재 에이전시 소유자 프로필로 돌아가 이전을 마무리해요. 마지막 이전 전까지 현재 소유자를 그대로 두면 에이전시에 계속 접근할 수 있어요.

### 1단계: 현재 에이전시 소유자 계정으로 로그인하기

최종 소유권 이전은 현재 에이전시 소유자만 할 수 있으므로, 현재 소유자 프로필에서 시작해요.

1. 하이퍼클래스 로그인 페이지로 이동해요.
2. 현재 에이전시 소유자의 로그인 이메일을 입력해요.
3. 현재 비밀번호를 입력해요.
4. 사용 가능한 인증 방법으로 인증을 마쳐요.
5. **에이전시 보기**를 열어요.

현재 소유자 계정에 접근할 수 없다면 계속 진행하기 전에 하이퍼클래스 고객지원에 문의하세요. 접근할 수 없는 에이전시 소유자 계정을 우회하려고 다른 사용자나 권한을 바꾸지 마세요.

### 2단계: 대체 에이전시 관리자 만들기

소유권을 이전받을 대상은 에이전시 수준의 관리자여야 해요. 소유권 이전을 시작하기 전에 원하는 로그인 이메일로 대체 사용자를 설정하세요.

1. **에이전시 보기**에서 **설정 > 팀**으로 이동해요.
2. **+ Add User**(사용자 추가)를 클릭해요.
3. 에이전시 소유자의 이름을 입력해요.
4. 올바른 로그인 이메일 또는 사용하려는 로그인 이메일을 입력해요.
5. 나머지 필수 사용자 정보를 입력해요.
6. 사용자의 역할 및 권한 설정에서 **사용자 유형**을 **에이전시**로 설정해요.
7. 사용자의 **역할**을 **관리자**로 설정해요.
8. 새 사용자를 저장해요.

![대체 에이전시 관리자 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081706341/original/YvPc7Qdr4MAzgPD7EKQO0SlMex4CElXOYg.png?1790217368)

### 3단계: 대체 사용자 확인하기

소유권을 이전하기 전에 대체 사용자의 로그인 정보를 테스트하면 원하는 이메일과 인증 설정이 제대로 작동하는지 확인할 수 있어요.

1. 현재 에이전시 소유자 프로필에서 로그아웃해요.
2. 새로 만든 에이전시 관리자의 이메일과 로그인 정보로 로그인해요.
3. 필요한 인증이나 확인 절차를 마쳐요.
4. 대체 사용자로 하이퍼클래스에 정상적으로 접근할 수 있는지 확인해요.
5. 대체 프로필에서 로그아웃해요.

{% hint style="info" %}
대체 사용자로 로그인해 보는 것은 에이전시 소유권을 옮기기 전에 새 로그인 정보가 작동하는지 확인하기 위한 예방 조치예요.
{% endhint %}

### 4단계: 에이전시 소유권 이전하기

현재 에이전시 소유자 프로필로 돌아가서 에이전시 소유자 역할을 대체 에이전시 관리자에게 이전해요. 에이전시에는 한 번에 한 명의 에이전시 소유자만 있을 수 있어요.

1. **현재 에이전시 소유자 프로필**로 다시 로그인해요.
2. 필요한 인증을 마쳐요.
3. **에이전시 보기 > 설정 > 팀**으로 이동해요.
4. 현재 에이전시 소유자를 편집해요.
5. **사용자 역할**을 열어요.
6. **소유권 이전**을 선택해요.
7. 대체 **에이전시 관리자**를 선택해요.
8. 소유권 이전을 확인해요.

![에이전시 소유권 이전 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081706406/original/e4gZ8_keURAuCr7NhmNlmTTvTNyooivBWg.png?1790217604)

{% hint style="info" %}
이전이 끝나면 선택한 에이전시 관리자가 에이전시 소유자가 돼요. 이전의 에이전시 소유자는 자동으로 에이전시 관리자가 돼요.
{% endhint %}

### 5단계: 새 에이전시 소유자 확인하기

마지막으로 로그인해 보면 대체 계정에 에이전시 소유자 권한이 제대로 부여되었는지, 원하는 로그인 이메일이 잘 작동하는지 확인할 수 있어요.

1. 이전의 에이전시 소유자 프로필에서 로그아웃해요.
2. **새 에이전시 소유자의 이메일과 로그인 정보**로 로그인해요.
3. **에이전시 보기**를 열어요.
4. **설정 > 팀**으로 이동해요.
5. 대체 사용자가 에이전시 소유자로 표시되는지 확인해요.

![새 에이전시 소유자 확인 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081706305/original/qpGu9SYPNBkZpw2vlhk40gMwW9OQDAbksA.gif?1790217170)

## 자주 묻는 질문

### 에이전시 소유자 이메일을 바꿀 때 항상 사용자를 새로 만들어야 하나요?

아니요. 먼저 일반 로그인 이메일 변경 절차를 사용하세요. 에이전시 소유자가 이메일, SMS, 인증 앱 같은 방법으로 변경을 인증할 수 있다면 대체 사용자는 필요 없어요.

### 에이전시 소유자가 인증 이메일을 받을 수 없으면 어떻게 하나요?

가능하면 사용 가능한 다른 인증 방법을 쓰세요. 쓸 수 있는 인증 방법이 없거나 인증이 계속 실패하면 하이퍼클래스 고객지원에 문의하세요.

### 소유권을 이전할 때 대체 사용자를 선택할 수 없어요.

대체 사용자가 **사용자 유형**: **에이전시**, **역할**: **관리자**로 설정되어 있는지 확인하세요. 올바르게 설정한 에이전시 관리자가 계속 나타나지 않으면 하이퍼클래스 고객지원에 문의하세요.

### 소유권을 이전하기 전에 대체 사용자로 꼭 로그인해 봐야 하나요?

대체 사용자로 로그인해 보기를 권장해요. 소유권을 이전하기 전에 새 로그인 정보가 작동하는지 확인할 수 있기 때문이에요. 다만 소유권 이전 대상이 되려면 대체 사용자가 에이전시 관리자 요건을 갖춰야 해요.

### 소유권을 이전하면 이전 에이전시 소유자는 어떻게 되나요?

소유권 이전이 끝나면 이전 에이전시 소유자는 자동으로 에이전시 관리자가 돼요.

### 에이전시에 에이전시 소유자를 여러 명 둘 수 있나요?

아니요. 에이전시에는 한 번에 한 명의 에이전시 소유자만 있을 수 있어요.

### 에이전시 회사 이메일을 바꾸는 것과 에이전시 소유자 로그인 이메일을 바꾸는 것은 같은가요?

아니요. 에이전시 회사 이메일은 에이전시의 회사 정보에 포함된 항목이에요. 에이전시 소유자 로그인 이메일은 로그인에 쓰는 개별 사용자 프로필에 속해 있어요.

### 현재 에이전시 소유자 계정에 아예 로그인할 수 없으면 어떻게 하나요?

대체 사용자 방식이나 소유권 이전 절차를 시도하기 전에 하이퍼클래스 고객지원에 문의해서 계정 접근을 도움받으세요.
