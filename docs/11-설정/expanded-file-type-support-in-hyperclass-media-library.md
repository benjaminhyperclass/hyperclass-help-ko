# 미디어 라이브러리 파일 형식 지원 확대

**미디어 라이브러리**(Media Library)에 RAW 사진, 디자인 원본 파일, CAD 모델, 오디오 프로젝트, 데이터베이스 등 60개 이상의 파일 형식을 올릴 수 있어요. 업로드 검사와 오류 안내도 더 정확해졌어요.

이 문서에서는 새로 지원하는 형식, 개선된 업로드 검사와 오류 안내, 브라우저에서 바로 볼 수 없는 파일을 다루는 방법을 안내해요.

## 파일 형식 지원 확대란?

파일 형식 지원 확대는 하이퍼클래스 **미디어 라이브러리**의 업로드 기능을 크게 개선한 업데이트예요. 전문 사진, 디자인, 모션 그래픽, 오디오 제작, CAD/3D 모델링, 데이터베이스 관리, 특수 문서 등 60개 이상의 형식을 새로 올릴 수 있어요.

이전에는 일반적인 이미지 형식, 기본 문서(PDF, Office 파일), MP4 계열 동영상, MP3 계열 오디오, ZIP 압축 파일만 올릴 수 있었어요. 이 목록에 없는 파일은 업무에 꼭 필요한 정상 파일이어도 "허용되지 않는 파일 유형입니다"라는 일반적인 오류로 거부됐어요.

이번 업데이트로 이런 제한이 없어졌어요. 보안과 성능 기준은 그대로 유지돼요. 기존에 지원하던 파일 형식은 달라지지 않고 그대로 쓸 수 있어요. 오류 안내가 구체적으로 바뀌었고, 브라우저가 직접 보여 줄 수 없는 파일에는 통일된 미리보기 화면이 나와요.

## 주요 이점

파일 형식 지원이 넓어져서 고객 자산과 프로젝트 파일을 하이퍼클래스 안에 더 많이 모아 둘 수 있어요.

- 전문 사진 작업: Canon, Nikon, Sony 등 전문 카메라의 RAW 파일(CR2, NEF, ARW, DNG)과 최신 iPhone 및 고급 기기의 HEIF 형식을 올릴 수 있어요.
- 디자인 원본 파일: Adobe InDesign 프로젝트(INDD, IDML), CorelDRAW 파일(CDR), Photoshop 문서(PSD, PSB), Apple Keynote 프레젠테이션, OpenDocument 형식(ODT, ODS, ODP)을 보관할 수 있어요.
- 모션 그래픽 및 오디오 제작: Adobe After Effects(AEP), Adobe Premiere Pro(PRPROJ), Sony Vegas(VEG), Ableton Live(ALS), FL Studio(FLP), Logic Pro(LOGICX)의 프로젝트 파일을 올릴 수 있어요.
- CAD 및 3D 모델링: 건축, 엔지니어링, 제품 디자인, 제조 작업에 쓰는 AutoCAD 파일(DWG, DXF)과 3D 모델 형식(OBJ, FBX, STL)을 보관할 수 있어요.
- 데이터베이스 및 데이터 파일: Microsoft Access 데이터베이스(MDB, ACCDB), SQLite 파일, SQL 스크립트, 캘린더 데이터(ICS), LDAP 디렉터리 파일(LDIF)을 올릴 수 있어요.
- 추가 동영상·오디오 형식: Flash Video(FLV), Matroska(MKV), AVCHD(MTS, M2TS), 3GPP 모바일 동영상, AAC 오디오, FLAC 무손실 오디오, RealAudio 형식을 지원해요.
- 더 명확한 오류 메시지: 일반적인 "허용되지 않는 파일 유형입니다" 오류 대신 구체적인 거부 사유가 나와요. 허용되지 않는 파일을 선택해도 업로드 창이 멈추지 않아요.

## 지원하는 파일 카테고리

새로 지원하는 파일 형식은 일곱 가지 카테고리로 나뉘어요. 형식마다 고유한 아이콘이 표시되고, 저장·정리·미리보기도 같은 방식으로 처리돼요.

### 카테고리 1. RAW 및 고급 사진 형식

- RAW 카메라 파일: CR2(Canon), NEF(Nikon), ARW(Sony), DNG(Adobe 범용 RAW)
- 고효율 형식: HEIF(iPhone 7 이상 및 최신 기기에서 쓰는 High Efficiency Image Format)
- 기타 형식: BMP(비트맵), SVGZ(압축 SVG), PSD(Photoshop 문서), PSB(대용량 Photoshop 문서)

### 카테고리 2. 디자인 및 출판 파일

- Adobe InDesign: INDD(프로젝트 파일), IDML(호환성을 위한 InDesign Markup Language)
- CorelDRAW: CDR(벡터 그래픽)
- Apple Keynote: Keynote 프레젠테이션 파일
- OpenDocument 형식: ODT(문서), ODS(스프레드시트), ODP(프레젠테이션)
- 전자책 및 출판: EPUB(리플로우 전자책), XPS(XML Paper Specification), PPSX(PowerPoint 슬라이드쇼)

### 카테고리 3. 모션 그래픽 및 오디오 제작 프로젝트

- Adobe Creative Cloud: AEP(After Effects 프로젝트), PRPROJ(Premiere Pro 프로젝트)
- Sony Vegas: VEG(동영상 편집 프로젝트)
- 디지털 오디오 워크스테이션: ALS(Ableton Live 세트), FLP(FL Studio 프로젝트), LOGICX(Logic Pro 프로젝트)

### 카테고리 4. CAD 및 3D 모델링 파일

- AutoCAD: DWG(도면 파일), DXF(Drawing Exchange Format)
- 3D 모델 형식: OBJ(형상 정의), FBX(Autodesk 교환 형식), STL(3D 프린팅용 스테레오리소그래피)

### 카테고리 5. 데이터베이스 및 데이터 파일

- Microsoft Access: MDB(Access 2003 이하), ACCDB(Access 2007 이상)
- SQLite 및 SQL: SQLITE(데이터베이스 파일), SQL(스크립트 파일)
- 데이터 교환: LDIF(LDAP 디렉터리), ICS(캘린더 데이터)

### 카테고리 6. 추가 동영상 및 오디오 형식

- 동영상: FLV(Flash Video), MKV(Matroska), MTS/M2TS(캠코더의 AVCHD), 3GPP(모바일 동영상)
- 오디오: AAC(Advanced Audio Coding), FLAC(무손실 압축), RealAudio 형식

### 카테고리 7. 글꼴 및 압축 파일

- 글꼴 파일: EOT(구형 브라우저용 Embedded OpenType)
- 압축 파일: 7z(7-Zip 압축 파일)

{% hint style="info" %}
RAW 사진부터 CAD 파일, 오디오 제작 프로젝트까지 60개 이상의 새 파일 형식을 올릴 수 있어요.
{% endhint %}

## 파일 미리보기 이해하기

새로 지원하는 파일 형식 중에는 웹 브라우저가 직접 보여 줄 수 없는 형식이 많아요. 이런 파일은 "미리보기를 제공하지 않습니다" 화면이 나오고, 파일 아이콘, 이름, 크기, 형식 정보가 표시돼요.

아래에서 어떤 파일을 미리 볼 수 있고, 어떤 파일에 이 화면이 나오는지 확인하세요.

### 경우 1. "미리보기를 제공하지 않습니다"가 나오는 파일

- RAW 카메라 파일: CR2, NEF, ARW, DNG — 브라우저가 카메라 제조사의 전용 RAW 형식을 해석할 수 없어요.
- 고효율 이미지: HEIC, HEIF — 최신 이미지 코덱은 별도의 렌더링 라이브러리가 필요한데, 브라우저에서 널리 지원되지 않아요.
- 디자인 원본 파일: PSD, PSB, INDD, IDML, CDR — 전용 프로그램이 있어야 열 수 있는 복잡한 프로젝트 파일이에요.
- CAD 파일: DWG, DXF — AutoCAD 형식은 전용 CAD 뷰어가 필요해요.
- 3D 모델: OBJ, FBX, STL — 3D 형식을 보려면 WebGL 렌더링 엔진이 필요한데, **미디어 라이브러리**에서는 기본으로 켜져 있지 않아요.
- 제작 프로젝트 파일: AEP, PRPROJ, VEG, ALS, FLP, LOGICX — 해당 프로그램에서만 열리는 전용 프로젝트 파일이에요.
- 압축 SVG: SVGZ — SVG는 브라우저가 바로 보여 주지만, 압축된 SVGZ는 압축을 푼 뒤에야 표시할 수 있어요.
- 모든 오디오 파일: 미리보기 화면에서는 오디오를 재생할 수 없어요. 파일 정보만 표시돼요.

### 경우 2. 브라우저에서 바로 미리 볼 수 있는 파일

- 일반 이미지 형식(JPEG, PNG, GIF, WebP, SVG)은 **미디어 라이브러리** 미리보기에 그대로 표시돼요.
- 브라우저가 지원하는 코덱의 동영상 파일(H.264 또는 VP9를 사용하는 MP4, WebM)은 화면 안에서 바로 재생돼요.
- PDF는 브라우저에 내장된 PDF 뷰어로 표시돼요.

{% hint style="info" %}
"미리보기를 제공하지 않습니다"가 나오는 파일은 다운로드 버튼을 눌러 컴퓨터에 저장한 다음, 해당 프로그램(Adobe Creative Cloud, AutoCAD, Ableton Live 등)에서 열어 보세요.
{% endhint %}

## 업로드 검사 개선 사항

더 많은 파일 형식을 받을 뿐 아니라, 예외 상황을 처리하고 결과를 더 명확하게 알려 주도록 업로드 검사도 크게 좋아졌어요.

### 개선 1. 확장자 기반 MIME 추론

브라우저가 모호한 MIME 유형을 보고하는 경우가 있어요. 예를 들어 인식하지 못한 파일은 "application/octet-stream"으로 보고해요. 이제 시스템이 파일 확장자를 전체 매핑 표와 대조해 올바른 MIME 유형을 추론하고 파일을 검사해요. 브라우저 정보가 맞지 않아서 정상 파일이 잘못 거부되는 일을 막아 줘요.

### 개선 2. 복수 후보 MIME 확인

확장자 하나가 여러 콘텐츠 유형을 나타낼 수도 있어요. 예를 들어 .webm은 동영상일 수도, 오디오일 수도 있어요. 시스템은 해당 확장자의 유효한 MIME 후보를 모두 확인하고, 하나라도 허용된 유형과 맞으면 파일을 받아요. 그래서 확장자가 겹치는 형식도 올바르게 처리돼요.

### 개선 3. 콘텐츠 유형별 용량 제한

이전에는 모든 업로드에 같은 용량 제한을 적용했어요. 이제는 콘텐츠 유형에 맞는 용량 제한을 적용해요. 예를 들어 동영상은 문서나 이미지와 제한이 다를 수 있어요. 올리는 자산의 종류에 맞는 기준이 적용돼요.

### 개선 4. 구체적인 거부 사유

업로드가 거부되면 파일이 막힌 이유가 오류 메시지에 나와요. 예를 들면 "지원하지 않는 파일 형식입니다", "동영상 용량 제한 50MB를 초과했습니다", "파일 확장자가 콘텐츠 유형과 일치하지 않습니다" 같은 메시지예요. 원인을 추측할 필요 없이 문제를 빠르게 해결할 수 있어요.

### 개선 5. 무한 로딩 오류 수정

이전에는 허용되지 않는 파일 형식을 선택하면 업로드 창에 로딩 표시가 계속 돌고 오류 상태로 넘어가지 않는 경우가 있었어요. 이제 거부된 업로드는 바로 오류 메시지가 표시되고, **닫기** 버튼으로 실패한 업로드를 목록에서 지울 수 있어요.

{% hint style="info" %}
이 개선으로 정상 파일은 안정적으로 업로드되고, 실패했을 때는 일반적인 실패 메시지 대신 바로 조치할 수 있는 정보가 나와요.
{% endhint %}

## 자주 묻는 질문

### 새 파일 형식을 쓰려면 따로 설정을 켜야 하나요?

아니요. 새로 지원하는 파일 형식은 모든 하이퍼클래스 계정에서 자동으로 켜져 있어요. 지원하는 확장자의 파일을 올리기만 하면 돼요.

### 이미 올린 파일에 영향이 있나요?

아니요. **미디어 라이브러리**에 있는 기존 파일은 그대로이고 이전과 똑같이 작동해요. 기능을 추가하는 업데이트여서 이미 올린 콘텐츠를 수정하거나 옮기거나 바꾸지 않아요.

### 미디어 라이브러리에서 RAW 사진 파일을 미리 볼 수 있나요?

아니요. RAW 카메라 파일(CR2, NEF, ARW, DNG)은 웹 브라우저가 직접 보여 줄 수 없어요. RAW 파일을 클릭하면 파일 정보와 함께 "미리보기를 제공하지 않습니다" 화면이 나와요. 파일을 보려면 다운로드한 뒤 Adobe Lightroom이나 Photoshop 같은 사진 편집 프로그램에서 여세요.

### 새로 지원하는 형식의 파일 용량 제한은 얼마인가요?

용량 제한은 콘텐츠 유형에 따라 달라요. 보통 동영상은 문서나 이미지보다 제한이 높아요. 해당 유형의 용량 제한을 넘는 파일을 올리면, 허용되는 최대 용량이 적힌 구체적인 오류 메시지가 나와요.

### 이 파일들을 이메일 캠페인이나 워크플로우에서 쓸 수 있나요?

네. **미디어 라이브러리**에 올린 파일은 기존 이미지·문서 파일과 똑같은 방식으로 워크플로우, 이메일 캠페인 등 하이퍼클래스의 다른 기능에서 사용할 수 있어요. 예를 들어 이메일에 PDF나 데이터베이스 파일을 첨부하거나, 워크플로우 액션에서 디자인 파일을 불러올 수 있어요.

### 파일이 화면에 표시되지 않고 "미리보기를 제공하지 않습니다"라고 나와요. 왜 그런가요?

브라우저가 직접 보여 줄 수 있는 파일 형식은 한정돼 있어요. 일반 이미지, 지원하는 코덱의 동영상, PDF, 일부 문서 유형 정도예요. RAW 사진, CAD 도면, 3D 모델, 제작 프로젝트 파일 같은 파일은 열려면 전용 프로그램이 필요해요. "미리보기를 제공하지 않습니다" 화면은 파일이 정상적으로 업로드되었다는 뜻이고, 파일 정보도 함께 보여 줘요. 파일을 다운로드해서 해당 프로그램에서 열어 보세요.

### 아직 지원하지 않는 파일 형식도 있나요?

네. **미디어 라이브러리**는 실행 파일(.exe, .app, .bat, .sh), 시스템 파일, 보안 위험이 있는 형식은 받지 않아요. 지원하지 않는 파일을 올리면 거부된 이유가 적힌 구체적인 오류 메시지가 나와요.

### 브라우저가 파일의 MIME 유형을 잘못 보고하면 어떻게 되나요?

브라우저가 모호하거나 잘못된 콘텐츠 유형(예: "application/octet-stream")을 보내면, 업로드 검사 시스템이 확장자 기반 MIME 추론을 사용해요. 파일 확장자를 전체 매핑 표와 대조해 올바른 MIME 유형을 찾고 그에 맞게 검사해요. 브라우저 정보 문제로 정상 파일이 잘못 거부되는 일을 막아 줘요.
