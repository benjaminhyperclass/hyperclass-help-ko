# 스코어링 관리 페이지 살펴보기 (HiRise 디자인)

하이퍼클래스의 **스코어링 관리** 페이지가 HiRise 디자인으로 새로 바뀌었어요. 화면이 더 깔끔하고 빨라졌고, 검색·페이지 설정이 그대로 담긴 링크를 팀원과 공유할 수 있어요. 이 문서에서 새 화면의 특징과 사용 방법을 확인해 보세요.

## 스코어링 관리란?

**스코어링 관리**에서는 연락처가 특정 행동(이메일 열람, 클릭, 결제 등)을 할 때 점수를 더하거나 뺄 수 있어요. 이 점수는 **연락처 참여 점수**로 합산돼요. 이 점수를 활용하면 연락처를 분류하고 후속 조치를 자동화할 수 있어요.

새 HiRise 화면에서도 기존 스코어링 로직은 그대로예요. 페이지 레이아웃, 성능, 협업 기능만 달라졌어요.

## HiRise 업그레이드의 장점

- 깔끔하고 현대적인 HiRise 스타일 덕분에 규칙을 훑어보고 편집하기가 쉬워졌어요.
- 규칙이 많아도 로딩 속도가 최대 2배 빨라져 스크롤이 부드러워요.
- 공유 링크에 검색어, 페이지 번호, 페이지당 행 수 설정이 그대로 담겨요. 팀원이 같은 화면을 바로 볼 수 있어서 다시 필터링할 필요가 없어요.
- 다른 HiRise 기반 페이지와 사용 방식이 같아서 처음 쓰는 사용자도 금방 익숙해져요.
- 접근성과 키보드 탐색이 좋아져 규칙을 더 빠르게 관리할 수 있어요.

## 더 깔끔해진 레이아웃

이제 페이지는 한 개의 열에 넓은 표를 보여 주는 구조예요. 여백이 넉넉해지고, 점수 값은 색으로 구분돼요. 스크롤해도 액션 머리글이 고정되어 있어요. 덕분에 중복되거나 오래된 규칙을 한눈에 찾을 수 있어요.

## 보기 상태가 유지되는 공유 링크

검색 상자, 페이지 이동, 페이지당 행 수 설정을 바꿀 때마다 그 내용이 주소(URL)에 저장돼요. 이 링크를 북마크해 두었다가 나중에 다시 열 수 있어요. 팀원에게 보내면 내가 작업하던 것과 같은 필터 상태로 열려요.

## 성능 개선과 확장성

HiRise는 프런트엔드 자원이 더 가볍고 새로운 캐싱 방식을 써서 로딩 시간이 크게 줄었어요. 특히 스코어링 규칙이 50개 이상인 서브 계정에서 효과가 커요. 기다리는 시간이 줄어든 만큼 참여 점수 로직을 다듬는 데 더 집중할 수 있어요.

## 스코어링 관리 설정 방법

참여 점수를 조정하는 방법은 예전과 같고, 화면만 새로워졌어요.

### 스코어링 관리 열기

서브 계정에서 **설정 > 스코어링 관리**를 클릭하세요.

![설정 메뉴에서 스코어링 관리 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056056490/original/sAK8CgThZ0A5dFexBbGSy5ukjc4k3mWMDQ.png?1760533290)

### 임시 저장과 게시

변경 사항을 실제 점수에 반영하지 않고 먼저 준비해 두고 싶다면, 오른쪽 위의 **임시 저장** 토글을 켜세요.

![오른쪽 위의 임시 저장 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056056556/original/AJb0SdADJ1q5sPLnPdFvK4001Rg9c4EeOQ.png?1760533311)

### 새 규칙 추가

1. **+ Add New Rule**(새 규칙 추가)을 클릭하세요.
2. **Action Type**(액션 유형)을 선택하세요. 예를 들어 이메일 열람을 고를 수 있어요.
3. 더할 점수(양수) 또는 뺄 점수(음수)를 입력하세요.

![새 규칙 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056056574/original/BMfMbRB0oRQVaCYobmF1DtCTO9hIqAmJnA.png?1760533329)

### 편집과 삭제 메뉴

각 규칙 옆의 점 3개 메뉴에서 **편집** 또는 **삭제**를 선택하세요.

![규칙 옆의 점 3개 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056056733/original/In35bg2s-C3VzP_kIetBvBPD9S3erUfkxg.png?1760533407)

### 규칙 설정과 수정

1. **Scoring Rules Table**(스코어링 규칙 표)에서 변경 내용을 모두 확인하세요.
2. 반영할 준비가 되면 **임시 저장** 토글을 **게시**로 바꾸세요.
3. 필터링한 화면을 팀원과 공유하려면 페이지 URL을 복사하세요.

![스코어링 규칙 표와 게시 전환](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056056936/original/fU8IEHjTrWAkkFW-p45nlU_vQVYtj-bJhg.png?1760533500)

## 자주 묻는 질문

### 기존 스코어링 규칙이 바뀌나요?

아니요. 이번 업그레이드는 화면 디자인과 성능 개선이라서 기존 규칙과 점수 합계는 그대로 유지돼요.

### 공유 링크에도 임시 저장과 게시 모드가 적용되나요?

네. 링크를 열면 저장해 둔 모드 그대로 열려요. 그래서 공동 작업자가 임시 저장 상태의 내용을 안전하게 검토할 수 있어요.

### 새 화면에서 여러 규칙을 한 번에 편집할 수 있나요?

일괄 편집은 아직 지원하지 않아요. 지금은 점 3개 메뉴로 규칙을 하나씩 편집해야 해요.

### 로딩 속도 개선은 모든 브라우저에서 적용되나요?

네. HiRise는 더 가벼운 자원과 브라우저 수준 캐싱을 사용해서 Chrome, Firefox, Edge, Safari 모두에서 효과가 있어요.

### 두 사람이 동시에 규칙을 편집하면 어떻게 되나요?

마지막으로 저장한 버전이 적용돼요. 공유 링크와 **임시 저장** 모드를 활용해 미리 조율하는 걸 권해요.

### 규칙 변경 내역을 확인할 수 있는 감사 로그가 있나요?

**스코어링 관리** 페이지 자체에는 없어요. 다만 워크스페이스 활동 로그에서 누가 변경 사항을 게시했는지 확인할 수 있어요.

### 스코어링 규칙을 내보낼 수 있나요?

내보내기 기능은 아직 기본으로 제공되지 않아요. 대신 API를 사용하거나 표를 복사해 CSV로 저장하는 방법을 쓸 수 있어요.
