# 미디어 저장소에서 파일 여러 개 한 번에 선택하기

**미디어 저장소**에서 파일이나 폴더를 여러 개 선택해 한꺼번에 이동, 다운로드, 삭제할 수 있어요. 반복 작업이 줄어들어 파일을 훨씬 빠르게 정리할 수 있어요.

## 미디어 저장소의 다중 선택이란?

다중 선택은 파일이나 폴더를 동시에 여러 개 고르는 기능이에요. 고른 항목에 일괄 작업을 적용할 수 있어서 파일 관리가 편해져요.

![미디어 저장소에서 여러 파일을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036267746/original/NX3e9TZYTp7wD72Bz6lOrv6fpVOQPkp4aA.png?1731093113)

## 다중 선택의 장점

- 파일 관리가 쉬워져요: 체크 표시를 누르거나 마우스를 끌어서 파일을 한 번에 여러 개 고를 수 있어요. 파일이 많을 때 특히 편해요.
- 일괄 작업을 할 수 있어요: 고른 파일을 한 번에 이동, 다운로드, 삭제할 수 있어요.
- 사용하기 쉬워요: 마우스를 끌어서 선택하거나 점 세 개 메뉴에서 **선택**을 누르면 다중 선택 모드가 시작돼요. 선택한 파일은 왼쪽 위 모서리에 체크 표시가 나타나요.

## 격자 보기에서 여러 파일 선택하기

선택할 파일 위로 마우스를 클릭한 채 끌거나, 점 세 개 메뉴에서 **선택**을 누르세요. 선택한 파일과 폴더에는 체크 표시가 나타나요.

![격자 보기에서 마우스를 끌어 파일을 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036267856/original/rTHYSN7slGc1QsR4Bhbcx2hKqoVWGKjbYw.gif?1731093366)

## 목록 보기에서 여러 파일 선택하기

파일이나 폴더 옆의 체크박스를 눌러 여러 항목을 선택하세요.

![목록 보기에서 체크박스로 파일을 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036267862/original/s3fnMKdvkKSEddCkUViwjhOVgXUbY46bGg.gif?1731093389)

## 선택한 파일에 일괄 작업 적용하기

파일을 선택한 뒤 해당 버튼을 눌러 이동, 다운로드, 삭제를 한 번에 할 수 있어요.

![선택한 파일을 일괄 이동, 다운로드, 삭제하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036271616/original/g0Ii1Km_oycg71fndZ5wRMkzoi81d0dqEw.gif?1731105664)

```
- 한 번에 최대 100개의 파일을 선택하고 다운로드할 수 있어요.
- 파일 크기가 2GB를 넘으면 여러 파일 다운로드에서 제외돼요. 이런 파일은 따로 다운로드해야 해요.
- 다중 선택 모드에서는 일괄 작업을 단순하게 유지하기 위해, 선택한 파일의 "이름 변경"과 "링크 받기" 옵션이 비활성화돼요.
```

## 자주 묻는 질문

### 다중 선택으로 서로 다른 폴더에 있는 파일을 함께 선택할 수 있나요?

현재 다중 선택은 한 폴더 안에서만 쓸 수 있어요. 여러 폴더의 파일을 관리하려면 폴더별로 따로 작업하세요.

### 다중 선택으로 선택할 수 없는 파일 형식이 있나요?

**미디어 저장소**에 있는 모든 파일 형식을 선택할 수 있어요. 다만 파일 형식에 따라 일부 작업은 제한될 수 있어요. 예를 들어 어떤 파일 형식은 미리보기가 되지 않을 수 있어요.

### 일괄 작업 중에 이름이 같은 파일은 어떻게 처리되나요?

이름이 같은 파일을 여러 개 이동하거나 다운로드하면, 기존 파일을 덮어쓰지 않도록 이름을 바꾸거나 건너뛰라는 안내가 나타나요.

### 한 번에 선택할 수 있는 파일 수에 제한이 있나요?

일괄 작업을 위해 한 번에 최대 100개까지 선택할 수 있어요. 이 한도를 넘겨 선택하려고 하면 알림이 나타나요.
