# 부재중 전화 문자 회신 설정 및 발송 번호 선택 방식

부재중 전화 문자 회신은 놓친 전화의 발신자에게 자동으로 문자를 보내는 기능이에요. 이 문서에서는 설정 위치와 방법, 음성사서함 설정과의 관계, 그리고 문자를 보낼 번호를 고르는 방식을 안내해요.

## 개요

놓친 전화는 놓친 기회가 될 수 있어요. 하이퍼클래스의 **부재중 전화 문자 회신** 기능은 전화를 받지 못했을 때 발신자에게 자동으로 문자를 보내요. 영업시간 외에 온 전화도 바로 응대할 수 있어요.

발신자가 전화한 번호가 SMS를 보낼 수 없는 번호여도, 이제는 발송 가능한 다른 번호로 문자를 보내요.

{% hint style="info" %}
**새로운 소식**: 발신자가 전화한 번호에서 SMS를 보낼 수 없으면, 하이퍼클래스가 발송 가능한 번호를 자동으로 골라 문자를 보내요. 후속 문자가 실패하지 않고 고객에게 도달할 가능성이 높아져요. 자세한 내용은 [더 똑똑해진 발송 번호 선택](#더-똑똑해진-발송-번호-선택)을 참고하세요.
{% endhint %}

{% hint style="warning" %}
**중요**: 부재중 전화 문자 회신은 부재중 전화 **한 통마다** SMS 알림을 보내요. 같은 발신자가 짧은 시간 안에 여러 번 전화해도 마찬가지예요.

같은 발신자에게 문자가 여러 번 가지 않게 하려면 **워크플로우**의 기존 레시피를 을 참고해서 원하는 대로 바꿔 보세요. 예를 들어 약 20분 정도의 **Wait**(대기) 스텝을 넣거나, '1번째 전화', '2번째 전화' 같은 태그로 걸러 낼 수 있어요.
{% endhint %}

## 부재중 전화 문자 회신이란?

부재중 전화 문자 회신은 걸려 온 전화를 받지 못했을 때 발신자에게 문자를 자동으로 보내는 기능이에요. 통화를 놓쳤다는 사실을 바로 알려 주고, 팀이 전화를 받을 수 없는 동안 문자로 대화를 이어 가도록 안내할 수 있어요.

영업시간 외 전화가 많거나, 걸려 오는 전화량이 많거나, 직접 다시 전화하지 않고도 빠르게 첫 응답을 하고 싶은 비즈니스에 특히 도움이 돼요.

{% hint style="info" %}
**왜 중요할까요?** 전화를 못 받았을 때 처음 보내는 후속 연락이 예약으로 이어질지, 리드를 놓칠지를 가를 수 있어요. 자동 문자는 직접 손대지 않아도 대화를 이어 가게 해 줘요.
{% endhint %}

## 부재중 전화 문자 회신의 주요 장점

- 빠른 후속 대응: 부재중 전화 발신자에게 바로 문자를 보내 전화를 확인했다는 사실을 알려요.
- 더 나은 고객 경험: 빠른 응답으로 발신자를 안심시키고, 대화를 이어 갈 다른 방법을 제공해요.
- 더 쉬운 개인화: 병합 필드를 써서 연락처 이름이나 비즈니스 이름 같은 정보를 메시지에 넣을 수 있어요.
- 간단한 설정: 기능을 켜고, 메시지를 작성하고, 테스트를 보낸 뒤 저장하면 끝이에요.
- 리드 응답 개선: 팀이 전화를 받을 수 없을 때도 잠재 리드와의 접점을 유지해요.
- 더 높은 전달률: 하이퍼클래스가 발송 가능한 번호를 자동으로 골라 더 많은 후속 문자가 실제로 발송돼요.

## 부재중 전화 문자 회신 설정하기

**설정**에서 **전화 시스템** 아래의 기능을 찾아 켜고, 메시지를 작성한 뒤 테스트를 보내면 돼요.

1. 서브 계정에서 왼쪽 아래에 있는 **설정**을 클릭하세요.

   ![서브 계정 왼쪽 아래의 설정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066734906/original/OjFHNIoeULj0h8e-0ZPWraTyv3Akzr7Zhw.png?1773264995)

2. **설정** 안에서 아래 순서로 이동하세요.
   - 왼쪽 메뉴에서 **전화 시스템**을 클릭하세요.
   - 위쪽 탭에서 **음성**을 클릭하세요.
   - **음성** 아래에서 **Voicemail & Missed Call Text Back**(음성사서함 & 부재중 전화 문자 회신)을 여세요.
   - 옆 패널에서 **부재중 전화 문자 회신**을 클릭하세요.

   ![전화 시스템 > 음성 아래의 음성사서함 및 부재중 전화 문자 회신 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066734967/original/hCHydUVEIyYEVu_BVFFDM246xJXztOXPSw.png?1773265066)

3. **Enable Missed Call Text Back**(부재중 전화 문자 회신 켜기) 체크박스를 선택해 기능을 켜세요. 그런 다음 **커스터마이징**을 클릭해 부재중 전화 시 나갈 메시지를 설정하세요.

   ![부재중 전화 문자 회신 켜기 체크박스와 커스터마이징 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066735467/original/4EWpJaWoQ9luC5sgv6_WANHjVeaO3_e4jA.png?1773266017)

4. **커스터마이징**을 클릭하면 팝업이 열려요. **메시지 입력** 필드에 부재중 전화일 때 보낼 내용을 입력하세요.

   커스텀 값 태그 아이콘을 눌러 연락처 이름 같은 변수를 넣을 수도 있어요. 이전 상호작용으로 시스템이 이미 아는 연락처일 때만 값이 채워져요.

   ![메시지 입력 필드와 커스텀 값 태그 아이콘이 있는 커스터마이징 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066735521/original/pMhp0ohGahjc31N7CeMboNaTo8iHB28GJg.jpeg?1773266117)

5. 메시지 편집기 아래에서 테스트 메시지를 보낼 수 있는 필드를 찾으세요. 고객에게 메시지가 어떻게 보일지 확인할 번호를 선택하세요.

6. 내용을 확인한 뒤 **저장**을 클릭하면 설정이 적용되고 부재중 전화 문자 회신이 활성화돼요.

   ![부재중 전화 문자 회신 설정의 테스트 메시지 필드와 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066735539/original/r7OeTZfb0lEhUEmClUY-X3M8JnQH4dPtvA.png?1773266177)

{% hint style="info" %}
설정이 끝났어요. 이제 걸려 온 전화를 통화 대기 시간 안에 받지 못하면 발신자에게 메시지가 자동으로 가요.
{% endhint %}

## 음성사서함 설정

음성사서함 설정은 걸려 온 전화를 받지 않았을 때 어떻게 처리할지 정해요. 음성사서함이 작동하기 전까지 전화가 울리는 시간을 조절할 수 있고, 기본 음성사서함 인사말을 직접 녹음한 파일로 바꿀 수도 있어요.

### 수신 통화 시간 초과 조절하기

**수신 통화 시간 초과**는 부재중 전화 문자 회신이 작동하기 전까지 전화가 울리는 시간을 정해요. 슬라이더로 시간을 고르세요. 보통 10~20초를 권장해요.

![음성사서함 설정의 수신 통화 시간 초과 슬라이더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066036199/original/NTcwyGYzj0J8NJgwbl1AhEdPpRwY4k4xBA.png?1772475723)

### 음성사서함 오디오 파일 업로드하기 (선택)

원하면 직접 만든 음성사서함 메시지를 추가할 수 있어요. mp3, wav 같은 형식으로 미리 녹음한 파일을 업로드하세요. 이 파일은 통신사의 기본 음성사서함 인사말 대신 재생돼요.

![음성사서함 설정의 오디오 파일 업로드 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066036213/original/375vNtucIblJVv2XLsfRPNTC-B-cJAWcJw.png?1772475746)

{% hint style="info" %}
여기서 정한 통화 시간 초과가 '부재중 전화'로 보는 기준이에요. 시간을 너무 길게 잡으면 문자 회신이 늦어지고, 너무 짧게 잡으면 전화를 받을 수 있었던 발신자의 통화가 끊길 수 있어요.
{% endhint %}

## 더 똑똑해진 발송 번호 선택

놓친 전화는 놓친 기회가 될 수 있어요. 고객이 전화한 번호가 SMS를 보낼 수 없다는 이유만으로 후속 문자가 실패해서는 안 돼요.

### 무엇이 달라졌나요?

- 이전: 부재중 전화 문자 회신은 항상 고객이 전화한 바로 그 번호로 후속 SMS를 보내려고 했어요. 전화 수신용으로 만든 번호도 있고, 지금은 SMS를 보낼 수 없는 번호도 있어요. 그래서 계정에 문자를 보낼 수 있는 다른 번호가 있어도 문자 회신이 실패할 수 있었어요.
- 지금: 하이퍼클래스가 발송 가능한 번호를 자동으로 골라요. 메시지 발송 요건을 지키면서 더 많은 부재중 전화 후속 문자가 고객에게 도달하도록 도와요.

### 발송 번호는 어떻게 정하나요?

고객이 전화했는데 받지 못하면, 먼저 **고객이 전화한 번호**로 문자를 보내려고 해요. 그 번호가 SMS를 보낼 수 있을 때만 그렇게 해요. 보낼 수 없으면 아래 순서로 다음 후보를 찾아요.

| 우선순위 | 문자 회신에 사용하는 번호 |
| --- | --- |
| 1 | 고객이 전화한 번호 — SMS를 보낼 수 있는 경우 |
| 2 | 이전에 이 연락처에게 문자를 성공적으로 보낸 적이 있는 번호 |
| 3 | 기본 발신 번호 |
| 4 | 서브 계정에서 사용할 수 있는 다른 발송 가능 메시지 번호 |

{% hint style="info" %}
**특히 도움이 되는 경우**: 번호 풀, 콜 트래킹 번호, 인증되지 않은 수신자 부담(toll-free) 번호처럼 SMS를 보낼 수 없는 번호로 전화가 들어올 때예요. 문자를 보낼 수 없는 번호로 시도하는 대신, 쓸 수 있는 번호가 있으면 그 번호를 사용해요.
{% endhint %}

### 사용자에게 보이는 변화

대부분은 달라지는 게 없어요. 부재중 전화 발신자는 지금처럼 후속 문자를 받아요.

{% hint style="info" %}
경우에 따라 **SMS가 고객이 처음 전화한 번호와 다른 번호에서 갈 수 있어요.** 의도된 동작이에요. 중요한 후속 문자를 실패시키지 않고, 실제로 보낼 수 있는 번호를 골라 보내는 거예요.
{% endhint %}

### 왜 중요할까요?

더 똑똑해진 번호 선택으로 이런 점이 좋아져요.

- 번호 하나가 SMS를 보내지 못해 후속 문자를 놓치는 일 없이 더 많은 부재중 발신자에게 연락할 수 있어요.
- 어떤 번호를 쓸지 직접 관리하지 않아도 후속 문자가 자동으로 나가요.
- A2P, 수신자 부담(toll-free) 번호 인증 같은 메시지 발송 요건을 계속 지킬 수 있어요.
- 처음 전화를 놓쳐도 잠재 리드에게 더 빨리 응답하고 대화를 이어 갈 수 있어요.

요약하면, 발송 가능한 번호가 있으면 자동으로 그 번호를 써서 부재중 전화 문자가 고객에게 도달할 가능성을 높여 줘요.

### 알아 두면 좋은 점

- 받은 전화는 지금처럼 동작하고, 문자 회신이 나가지 않아요.
- **전화 시스템** 설정에서 **부재중 전화 문자 회신**을 꺼 두면 메시지가 나가지 않아요.
- 연락처의 수신 설정과 수신거부 설정은 계속 지켜져요.
- 발송 가능한 번호가 하나도 없으면, 대화에 실패한 시도와 그 이유가 표시돼요. 무슨 일이 있었는지 바로 확인할 수 있어요.

## 자주 묻는 질문

### 부재중 전화 문자 회신 메시지는 어떤 번호로 보내나요?
먼저 고객이 전화한 번호로 시도해요. 그 번호가 SMS를 보낼 수 있을 때만 그래요. 보낼 수 없으면 하이퍼클래스가 자동으로 이전에 이 연락처에게 문자를 성공적으로 보낸 적이 있는 번호, 기본 발신 번호, 서브 계정의 다른 발송 가능 메시지 번호 순서로 찾아요. 전체 순서는 [더 똑똑해진 발송 번호 선택](#더-똑똑해진-발송-번호-선택)에서 확인하세요.

### 부재중 전화 문자가 왜 다른 번호로 왔나요?
정상적인 동작이에요. 발신자가 건 번호가 번호 풀 번호, 콜 트래킹 번호, 인증되지 않은 수신자 부담(toll-free) 번호처럼 SMS를 보낼 수 없는 번호였을 가능성이 높아요. 그래서 후속 문자를 실패시키지 않고 발송 가능한 번호로 대신 보낸 거예요.

### 발송 가능한 번호가 하나도 없으면 어떻게 되나요?
연락처의 대화에 실패한 시도와 그 이유가 기록돼서 상황을 바로 확인할 수 있어요. 해결하려면 서브 계정에 SMS를 보낼 수 있도록 인증된 번호가 하나 이상 있어야 해요. 로컬 번호는 A2P 10DLC 등록을, 수신자 부담(toll-free) 번호는 toll-free 인증을 완료하세요.

### 부재중 전화 문자 회신 메시지도 메시지 한도에 포함되나요?
네, 이 SMS 메시지도 전화 메시지 사용량 한도에 포함돼요.

### 연락처가 수신거부 상태이면 문자가 가나요?
아니요. 어떤 발송 번호가 선택되든 연락처의 수신 설정과 수신거부 설정은 항상 지켜져요.

### 더 똑똑해진 번호 선택을 쓰려면 설정을 바꿔야 하나요?
아니요. 따로 켤 항목이 없어요. **설정 > 전화 시스템 > 음성**에서 부재중 전화 문자 회신이 켜져 있으면 개선된 번호 선택이 자동으로 적용돼요.

### 부재중 전화 후속 연락을 SMS 대신 WhatsApp으로 보낼 수 있나요?
SMS 기반의 부재중 전화 문자 회신 기능으로는 할 수 없어요. 부재중 발신자에게 WhatsApp으로 메시지를 보내려면 하이퍼클래스의 별도 기능인 **Missed Call WhatsApp Back**(부재중 전화 WhatsApp 회신)을 사용하세요.

### 영업시간 외에 온 전화에도 부재중 전화 문자 회신이 작동하나요?
네. 팀이 전화를 받을 수 없는 시간에도 발신자에게 자동으로 알리고 문자로 대화를 이어 갈 수 있어서, 영업시간 외 부재중 전화에 특히 유용해요.

### 받은 전화에도 문자 회신이 가나요?
아니요. **수신 통화 시간 초과**를 넘겨서까지 받지 않은 전화만 부재중 전화로 처리돼요. 받은 전화에는 문자 회신이 나가지 않아요.
