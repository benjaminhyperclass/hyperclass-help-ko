# 청구 대시보드 살펴보기

**청구 대시보드**(Billing Dashboard)에서는 서브 계정의 구독, 결제 수단, 결제 정보, 인보이스, 거래 내역, 지갑 잔액을 한곳에서 관리해요. 저장된 카드 관리와, 서브 계정의 활성 SaaS 구독에 적용되는 SaaS V2 기본 카드 동기화도 지원해요. 이 문서에서 각 영역의 역할과 자주 하는 작업을 알아보세요.

## 청구 대시보드란?

청구 대시보드는 하이퍼클래스 서브 계정의 금전 활동을 관리하는 중심 화면이에요. 결제 설정이 한곳에 모여 있어서 현재 구독, 결제 수단, 인보이스, 거래 내역, 지갑 자금을 쉽게 확인할 수 있어요.

청구 대시보드에서 관리할 수 있는 항목은 다음과 같아요.

- 구독
- 결제 수단
- 결제 정보
- 청구 내역, 인보이스, 거래 내역
- 지갑 잔액

청구 대시보드를 열려면 서브 계정에서 **설정 > 청구/결제**로 이동하세요.

![설정에 있는 서브 계정 청구 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957125/original/XnSTGWITHWlGr40gmEhrph5NXcZZVdgm-A.png?1790572666)

## 구독 관리

**구독** 영역에서는 서브 계정에 연결된 정기 서비스를 한눈에 볼 수 있어요. 현재 활성 상태인 결제 관계를 이곳에서 확인하세요.

- SaaS 구독: 서브 계정과 연결된 SaaS(소프트웨어 서비스) 구독을 관리해요.
- 재판매 구독: 재판매 서비스와 관련된 구독을 확인해요.
- 마켓플레이스 앱 구독: 계정에 연결된 마켓플레이스 앱의 구독을 관리해요.

![서브 계정 구독을 보여 주는 청구 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957130/original/D8q1vWiONvWxXEgMClXu8y6XjPdV6fVngA.png?1790572675)

## 결제 방법

**결제 방법** 영역에서는 지원되는 결제 활동에 쓸 저장된 카드를 관리해요. **기본 카드**를 최신 상태로 유지하면 지갑 충전이 중단될 가능성이 줄어요. 대상이 되는 SaaS V2 계정이라면 활성 SaaS 구독도 선택한 기본 카드와 맞춰져요.

- 새 카드 추가: 다른 카드가 필요할 때 새 결제 수단을 추가해요.
- 기존 카드 삭제: 오래되었거나 쓰지 않는 저장된 결제 수단을 제거해요.
- 기본 카드 설정: 지원되는 결제 활동에 기본으로 쓸 카드를 정해요.

| 결제 용도 | 기본 카드 동작 |
| --- | --- |
| SaaS V2 | 활성 SaaS V2 구독이 있는 경우, 서브 계정의 기본 카드를 바꾸면 그 서브 계정의 SaaS 구독에 쓰는 결제 수단도 함께 바뀌어요. 같은 연락처와 연결된 다른 구독은 바뀌지 않아요. |
| 지갑 충전 | SaaS V2 서브 계정에서는 지갑 충전에도 계속 기본 카드를 사용해요. |

![저장된 카드와 기본 카드 설정을 보여 주는 결제 방법 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957132/original/LyHhV1CifVXzP-OOhhpvrLmO0r4rXL3aRg.png?1790572686)

## 저장된 결제 수단 삭제하기

쓰지 않는 카드를 삭제하면 청구 대시보드가 깔끔해지고, 오래된 결제 수단을 실수로 선택할 일도 줄어요. SaaS V2 서브 계정도 청구 대시보드에서 바로 저장된 결제 수단을 삭제할 수 있어요.

1. 서브 계정에서 왼쪽 메뉴의 **설정**을 선택하세요.
2. **청구/결제**를 선택하세요.
3. **결제** 탭을 선택하세요.
4. **결제 수단** 영역에서 **결제 수단 관리**를 여세요.
5. 삭제할 저장된 카드를 찾으세요.
6. 카드 옆의 점 세 개(⋮) 아이콘을 클릭하세요.
7. **카드 삭제**를 선택하세요.

![카드 삭제 메뉴가 보이는 저장된 결제 수단 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957139/original/3EAmVCmSwW1MPQATrCwjAOTNhAqGUVj3mA.png?1790572713)

8. 삭제 확인 안내를 읽어 보세요.
9. 저장된 결제 수단을 삭제하려면 **지금 삭제**를 클릭하세요. 취소하려면 **나중에**를 클릭하세요.

{% hint style="warning" %}
선택한 카드가 활성 구독의 결제에 쓰이고 있으면 하이퍼클래스에서 경고가 표시될 수 있어요. 나중에 결제가 실패할 위험을 줄이려면 카드를 삭제하기 전에 해당 구독을 검토하고 업데이트하세요.
{% endhint %}

![저장된 카드 삭제 시 표시되는 확인 경고](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957162/original/WFXch_IZwvgKAtRtQ0VflQk1H5A_DPmgTg.png?1790572759)

{% hint style="info" %}
저장된 결제 수단 삭제는 SaaS V2 서브 계정에서 쓸 수 있어요. SaaS V1에서는 이미 저장된 카드를 삭제할 수 있었어요.
{% endhint %}

## 결제 정보 업데이트하기

결제 정보가 정확해야 거래가 잘 처리돼요. 정기 상품에 최신 청구지 주소가 필요한 지역에서는 요건을 충족하는 데도 도움이 돼요.

- **청구지 주소 업데이트**: **청구지 주소**를 수정해서 계정의 **결제 정보**를 최신으로 유지해요.

![서브 계정 청구지 주소를 업데이트하는 결제 정보 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957107/original/7xvNk8z1AoXZySBtFptMkHKVTysMdTKsAw.png?1790572636)

## 청구 내역과 거래 내역 보기

청구 내역과 거래 내역에서는 서브 계정에 어떤 금액이 청구되었는지 확인할 수 있어요. 인보이스, 상품, 거래 ID, 외부 청구도 쉽게 찾을 수 있어요.

- 상세 청구 내역: 계정과 연결된 청구 목록을 확인해요.
- **인보이스**: 인보이스 상세 정보를 보고, 각 청구와 연결된 상품을 확인하고, 필요하면 인보이스를 내려받아요.
- 거래 내역: 지난 거래를 살펴보며 계정 지출을 확인해요.

![청구 내역과 거래 내역 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957167/original/bifsfRPnj7Oa2D2vDFmGyabrtECoeQpfLQ.png?1790572781)

### 인보이스 보기와 관리

인보이스 목록에서는 인보이스를 열거나 내려받기 전에 각 청구의 내용을 파악할 수 있어요.

![청구 상세와 상품이 보이는 인보이스 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079551373/original/AnrFdRJVtKAyTU6Oz9b0omNs4ZC8_bjrqQ.png?1787922325)

#### 인보이스의 상품 확인하기

**상품** 열에서는 인보이스를 열기 전에 어떤 상품이 청구에 포함되었는지 확인할 수 있어요.

상품이 여러 개인 인보이스는 첫 번째 상품 이름 옆에 추가 상품 수를 알려 주는 **+n** 배지가 표시돼요. 배지 위에 마우스를 올리면 인보이스에 포함된 모든 상품 이름을 볼 수 있어요. 상품이 하나인 인보이스에는 상품 이름만 표시되고, 이름이 길면 말줄임표(…)로 줄어들 수 있어요.

![인보이스 한 건에 여러 상품이 표시된 상품 열](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079551615/original/qQDhqDImThUqXk5bemVluHgIF__aEVM7ug.png?1787922454)

#### 거래 ID 확인하고 복사하기

특정 결제 건을 언급해야 할 때 **거래 ID**로 인보이스 행을 구분할 수 있어요.

표에서는 **거래 ID**가 일부만 표시돼요. 전체 ID를 복사하려면 **거래 ID** 옆의 복사 아이콘을 클릭하세요. 인보이스 상세 정보에서도 전체 **거래 ID**를 볼 수 있어요.

![인보이스 목록에서 복사 아이콘이 있는 거래 ID](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079551681/original/0zEb6abZZc2Mza97IydkE8MUW9XEW60Qfw.png?1787922503)

#### 인보이스 상세 정보 보기

인보이스 상세 정보에서는 인보이스 PDF를 자동으로 내려받지 않고 청구 내용만 살펴볼 수 있어요.

인보이스의 **보기**를 클릭하면 다음 정보가 포함된 상세 창이 열려요.

- 인보이스 ID
- 인보이스 유형
- 날짜
- 금액
- 카드
- 상태
- 상품

상세 창을 닫으려면 **X**를 클릭하거나 창 바깥을 클릭하세요.

#### 인보이스 보기 또는 내려받기

Stripe에서 자세한 내용을 확인하거나, 보관용 PDF 사본을 내려받을 수 있어요.

![Stripe에서 보기와 인보이스 다운로드 버튼이 보이는 인보이스 상세 정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079551873/original/opglcUuV60zVqEeC-npIg9UDiOlHvxvUYg.png?1787922594)

- **View in Stripe**(Stripe에서 보기): 새 브라우저 탭에서 Stripe 인보이스를 열어요.
- **인보이스 다운로드**: 인보이스를 PDF로 내려받아요.

#### 외부 청구 구분하기

하이퍼클래스 플랫폼 밖에서 발생한 인보이스와 상품에는 인보이스 목록과 상세 정보에 **외부** 배지가 표시돼요. 이 배지로 하이퍼클래스 안에서 발생한 청구와 외부 청구를 구분하세요.

## 지갑 잔액 이해하기

**Wallet**(지갑)을 쓰면 서브 계정에 미리 자금을 충전해 두고, 그 자금을 유료 서비스의 크레딧으로 사용할 수 있어요. 자동 충전을 켜 두면 크레딧이 설정한 기준 금액 아래로 내려가도 지갑 잔액이 유지되어 지원되는 서비스를 끊김 없이 쓸 수 있어요.

지갑 크레딧이 설정한 금액 아래로 떨어지면 기본 카드로 자동 결제되고, 지갑에 크레딧이 추가돼요.

- **현재 잔액** 확인: 사용할 수 있는 지갑 자금을 한눈에 확인해요.
- **무료 크레딧** 확인: 계정에 제공된 무료 크레딧을 살펴봐요.
- 자금 관리: 자금을 추가해서 지원되는 유료 서비스가 계속 작동하게 해요.

![청구 대시보드의 지갑 잔액과 자금 충전 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081957118/original/W0F-vgajOf7GlcOjwqkqg1L7yGzI9Q6lVA.png?1790572657)

## 자주 묻는 질문

### 지갑 충전이나 SaaS 플랜 재청구에 대한 영수증을 고객이 받지 못해요. 왜 그런가요?

지갑 크레딧 충전에 대한 영수증은 고객에게 자동으로 발송되지 않아요. 이런 지갑 거래는 에이전시에서는 볼 수 있지만, 기본적으로 고객사에는 전송되지 않아요. SaaS 플랜 재청구의 영수증은 Stripe에서 처리해요. 영수증을 보내려면 Stripe 계정의 이메일 영수증 설정에서 결제 성공 시 영수증 이메일을 켜세요.

### 새 결제 수단을 추가하려면 어떻게 하나요?

**청구/결제**에서 **결제 방법** 영역을 열고 **새 카드 추가**를 클릭한 다음 필요한 카드 정보를 입력하세요.

### 활성 구독을 여러 개 가질 수 있나요?

네. SaaS, 재판매, 마켓플레이스 앱 구독을 **구독** 영역에서 관리할 수 있어요.

### 청구지 주소를 업데이트하려면 어떻게 하나요?

**청구/결제**에서 **결제 정보** 영역을 찾아 편집 버튼으로 청구지 주소를 수정하세요.

### 지난 인보이스는 어디에서 볼 수 있나요?

**청구/결제**의 청구 내역 및 거래 내역 영역에서 인보이스 상세 정보를 보고, 내려받을 수 있는 인보이스를 다운로드하세요.

### 지갑에 자금을 추가하려면 어떻게 하나요?

**Wallet**(지갑) 영역에서 **Add Funds**(자금 추가)를 클릭하고, 안내에 따라 지갑 잔액에 추가할 금액을 입력하세요.
