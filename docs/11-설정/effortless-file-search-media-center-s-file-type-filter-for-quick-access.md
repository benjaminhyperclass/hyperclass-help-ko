# 미디어 센터 파일 유형 필터로 원하는 파일 빠르게 찾기

**Media Center**(미디어 센터)에 새로 생긴 **File Type**(파일 유형) 필터를 쓰면 사진, 동영상, 오디오, 문서, PDF 등을 한 번의 클릭으로 골라 볼 수 있어요. 스크롤하는 시간은 줄이고, 콘텐츠를 만드는 시간은 늘려 보세요.

---

## 미디어 센터의 파일 유형 필터란?

**File Type** 필터는 **Media Center** 도구 모음에 추가된 드롭다운이에요. 선택한 유형과 맞지 않는 파일은 숨기고, 고른 유형만 보여 줘요. 고를 수 있는 유형은 **사진**, **동영상**, **오디오**, **문서**, **PDFs**(PDF 파일), **기타**, **전체**예요.

이 필터는 **내 미디어**, Google Drive, 연결된 라이브러리에서 모두 쓸 수 있어요. Unsplash처럼 파일 유형으로 거르는 게 의미 없는 곳에서는 자동으로 꺼져요.

---

## 파일 유형 필터의 장점

- **파일 찾기가 쉬워져요:** 필요한 파일을 몇 초 만에 찾을 수 있어요.
- **작업 공간이 깔끔해져요:** 파일이 많은 라이브러리에서 필요 없는 형식을 숨길 수 있어요.
- **클릭이 줄어요:** 한 번 적용하면 계속 둘러볼 수 있고, 탭을 옮겨도 검색어가 유지돼요.
- **어디서나 같은 방식이에요:** **내 미디어**, Google Drive, **External Libraries**(외부 라이브러리)에서 같은 드롭다운을 써요.
- **상황에 맞게 작동해요:** Unsplash, Pixabay처럼 이미지만 있는 라이브러리를 보면 자동으로 비활성화돼요.
- **결과가 빨리 나와요:** 서버에서 필터링하므로 파일이 아주 많은 폴더에서도 결과가 더 빨리 나와요.

---

## 파일 유형 분류

파일 형식을 하나하나 기억하지 않아도 되도록, 확장자를 알기 쉬운 묶음으로 나눴어요.

- **사진** – JPG, PNG, SVG, GIF
- **동영상** – MP4, MOV, WEBM, AVI
- **오디오** – MP3, WAV, OGG
- **문서** – DOCX, TXT, CSV, XLSX, PPTX
- **PDFs** – PDF 파일
- **기타** – ZIP, RAW 등 그 밖의 형식

---

## 상황 인식 기능

검색 대상에 파일 유형이 하나뿐이면 드롭다운이 자동으로 비활성화돼요. 예를 들어 Unsplash는 이미지만 보여 주기 때문이에요. 이 기능 덕분에 아무것도 없는 화면이 나오는 혼란을 막고, 화면도 깔끔하게 유지돼요.

---

## 검색어 유지

**Media Center**에 입력한 검색어는 **내 미디어**, Google Drive, **External Libraries** 사이를 옮겨 다녀도 그대로 남아요. **File Type** 필터도 이 검색어를 그대로 유지해서, 처음부터 다시 검색하지 않고 결과를 좁힐 수 있어요.

---

## 모든 메뉴에서 같은 경험

**Media Center**는 소셜 플래너, 퍼널, 이메일 빌더, 커뮤니티 등에서 파일을 올릴 때 함께 쓰여요. 그래서 미디어 창을 여는 모든 작업에서 **File Type** 필터를 쓸 수 있어요. 미디어 저장소를 공통으로 쓰기 때문에, 한 메뉴에서 바꾼 내용은 다른 메뉴에도 똑같이 반영돼요.

---

## 파일 유형 필터 사용하기

여기서는 **File Type** 필터만 다뤄요. 필터로 결과를 좁히고, 검색과 함께 쓰고, 검색 대상을 바꿀 때 필터가 어떻게 초기화되는지 알아봐요.

1. **미디어 저장소**에서 상단 도구 모음의 **File Type** 드롭다운을 찾으세요. **정렬** 옆에 있어요.
2. **File Type**을 클릭하고 **사진**, **동영상**, **오디오**, **문서**, **PDFs**, **기타**, **전체** 중 하나를 고르세요. 기본값은 **전체**예요.

   ![파일 유형 드롭다운에서 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062714550/original/goMsKWhXmElG6c5RW5VZeswsy8vrxqvM7w.png?1768471662)

3. 파일을 둘러보거나 **검색**을 사용하세요. 조건에 맞는 파일만 보여요.
4. 필터를 초기화하는 방법은 두 가지예요.

   - **File Type**을 다시 **전체**로 바꾸면 현재 보고 있는 곳의 모든 파일이 보여요.
   - 검색 대상(**내 미디어**, Google Drive, **External Libraries**)을 바꾸면 **File Type** 선택이 해제돼요. **검색**한 내용은 그대로 남아요.

     ![검색 대상을 바꾸면 파일 유형 선택이 해제된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062730578/original/EhW6vtnY48konJF0u5tIsO-KDBOAHwR7Mw.png?1768479554)

{% hint style="info" %}
- **저장 용량에는 영향이 없어요:** 필터는 보이는 파일만 바꾸고, 저장된 파일은 그대로예요.
- **가용성:** 데스크톱 앱과 웹에서 쓸 수 있어요. 모바일에서는 아직 필터링을 쓸 수 없어요.
{% endhint %}

## 자주 묻는 질문

### 필터가 업로드 한도나 저장 용량에 영향을 주나요?

아니요. 필터는 보이는 파일만 바꿔요. 저장소 정책은 그대로예요.

### 필터를 적용한 뒤에 서로 다른 유형의 파일을 함께 선택할 수 있나요?

네. **전체**로 돌아간 다음 여러 파일을 선택하세요. 여러 파일 선택은 현재 보고 있는 화면 안에서만 할 수 있어요.

### Unsplash에서는 드롭다운이 왜 회색으로 나오나요?

Unsplash처럼 모든 파일이 이미지인 곳에서는 필터링이 필요 없어서, 상황 인식 기능이 드롭다운을 비활성화해요.

### 제가 고른 필터가 다른 팀원에게도 적용되나요?

아니요. **File Type**은 사용자별 설정이고, 사용자마다 세션이 바뀔 때 초기화돼요.

### 모바일 앱에서도 필터를 쓸 수 있나요?

아직은 쓸 수 없어요. 모바일 앱의 **미디어 라이브러리**에는 기본 검색 기능이 이미 있고, 이후 업데이트에서 모바일 필터링이 추가될 예정이에요.

### 개발자용 백엔드 필터링은 어떤 API 엔드포인트를 쓰나요?

MediaService → /medias?type={photo|video|audio|doc|pdf|other} 예요. OAuth로 인증된 채널에서는 이 엔드포인트가 `type` 파라미터를 일관되게 적용해요. 올바른 type 값을 보내면 파일뿐 아니라 폴더도 함께 반환할 수 있어요.

### **문서**에 Google Docs 링크도 포함되나요?

아니요. **문서**는 업로드한 문서 파일(DOCX, TXT 등)을 말해요. 링크로 연결한 Google Docs는 **기타**에 나와요.
