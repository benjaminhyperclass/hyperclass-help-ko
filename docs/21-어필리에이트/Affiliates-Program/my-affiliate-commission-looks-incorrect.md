# 제휴 커미션 금액이 예상과 달라요

제휴 커미션 금액이 예상과 다를 때 확인해 볼 만한 원인을 정리했어요.

커미션 금액이 생각했던 것과 다르게 보이나요? 다음과 같은 원인이 있을 수 있어요.

- 하이퍼클래스에서 블랙 프라이데이/사이버 먼데이 같은 프로모션을 진행 중이면 평소보다 커미션 금액이 낮을 수 있어요.
- 추천한 고객이 하이퍼클래스 요금제를 업그레이드해서 생긴 커미션이라면, 업그레이드한 날짜에 따라 금액이 일할 계산돼요.
- 추천한 고객이 하이퍼클래스 팀에서 환불을 받으면 제휴 포털에 마이너스 잔액으로 표시돼요.
  {% hint style="info" %}
  전체 잔액이 마이너스여도 돈을 내야 한다는 뜻은 아니에요. 다만 지급을 받으려면 마이너스 금액을 상쇄할 만큼 커미션이 쌓여야 해요.
  {% endhint %}

커미션 금액은 맞는데 지급이 들어오지 않는다면 [제휴 지급금은 어디서 확인하나요?](where-is-my-affiliate-payout.md)를 참고하세요.
