# 게시할 때 스키마 마크업 자동 생성하기 (퍼널·웹사이트·웨비나)

페이지를 게시할 때 구조화된 데이터(스키마 마크업)를 자동으로 추가하는 기능이에요. 따로 작업하지 않아도 모든 페이지가 검색엔진과 AI 답변 엔진에 잘 보이도록 도와줘요. 이 문서에서는 하이퍼클래스의 AI 스키마 자동 생성이 어떻게 동작하는지, 웹사이트·퍼널·웨비나에서 어떻게 켜는지 알려 드려요.

## 스키마 마크업 자동 생성이란?

스키마 마크업 자동 생성은 스키마 마크업이 없는 채로 게시되는 페이지에 AI가 스키마 마크업을 만들어 넣어 주는 설정이에요. 스키마 마크업은 검색엔진과 AI 답변 엔진이 내 콘텐츠를 이해하고 풍부한 검색 결과로 보여 주도록 돕는 데이터예요. 그래서 SEO와 AEO(Answer Engine Optimization, 답변 엔진 최적화) 노출에 모두 도움이 돼요.

이전에는 페이지 편집기에서 페이지마다 스키마 마크업을 직접 추가해야 했어요. 깜빡하거나 시간이 없으면 구조화된 데이터 없이 페이지가 게시돼서, 검색 노출과 AI 인용 기회가 줄어들 수 있었어요.

**스키마 자동 생성**을 켜 두면, 스키마 마크업이 없는 페이지를 게시할 때 하이퍼클래스가 자동으로 추가해 줘요. 페이지가 공개되는 순간부터 구조화된 데이터가 들어 있고, 추가 작업이나 게시 지연도 없어요.

## 주요 장점

- 직접 할 일이 없어요. 스키마 마크업이 없는 페이지를 게시하면 AI가 백그라운드에서 자동으로 만들어요.
- 게시가 늦어지지 않아요. 스키마 생성은 게시와 동시에 진행돼서 페이지 공개를 막지 않아요.
- 기존 스키마는 안전해요. 이미 스키마 마크업이 있는 페이지는 덮어쓰거나 수정하지 않아요.
- 어떤 방식으로 게시해도 동작해요. 빌더에서 게시할 때, 저장하면서 게시될 때, 버전 기록에서 게시할 때 모두 자동 생성이 실행돼요.
- 웹사이트, 퍼널, 웨비나에서 쓸 수 있어요. 스키마 마크업을 지원하는 항목이면 모두 설정을 켤 수 있어요.
- SEO와 AEO/GEO 노출에 도움이 돼요. 스키마 마크업은 Google의 풍부한 검색 결과에 쓰이고, AI 답변 엔진이 내 콘텐츠를 이해하고 인용하는 데도 도움이 돼요.

## 게시할 때 자동 생성되는 과정

**스키마 자동 생성**을 켜 둔 상태에서 페이지를 게시하면, 하이퍼클래스가 먼저 스키마 마크업이 이미 있는지 확인해요. 스키마가 없으면 AI가 백그라운드에서 자동으로 만들어요.

1. 페이지를 게시해요. 빌더에서 **게시**를 클릭하거나, 저장하면서 게시되게 하거나, 버전 기록에서 이전 버전을 복원하는 경우예요.
2. 하이퍼클래스가 기존 스키마가 있는지 확인해요. 이미 스키마 마크업이 있으면 그대로 두고 페이지를 바로 게시해요.
3. 스키마가 없으면 AI가 페이지의 구조화된 데이터를 백그라운드에서 만들어요. 이 작업은 게시와 동시에 진행되고 게시를 늦추지 않아요.
4. 만들어진 스키마 마크업이 페이지에 자동으로 추가돼요. 페이지가 공개되는 순간부터 구조화된 데이터가 들어 있어요.

{% hint style="warning" %}
기존 스키마는 덮어쓰지 않아요. 자동 생성은 게시 시점에 페이지에 스키마 마크업이 없을 때만 실행돼요.
{% endhint %}

## 새 항목과 기존 항목의 기본 설정

**스키마 자동 생성**의 기본 설정은 웹사이트, 퍼널, 웨비나를 만든 시점에 따라 달라요.

**기존 항목 (이 기능이 출시되기 전에 만든 항목)**

**스키마 자동 생성**이 기본적으로 **끄기** 상태예요. 직접 켜기 전에는 아무것도 바뀌지 않아요. 기존 스키마와 게시 방식도 그대로예요.

**새 항목 (이 기능이 출시된 후에 만든 항목)**

**스키마 자동 생성**이 기본적으로 **켜짐** 상태예요. 스키마 없이 게시된 페이지에는 AI가 만든 구조화된 데이터가 자동으로 추가돼요. 원하지 않으면 **설정**에서 언제든 끌 수 있어요.

**항목별로 따로 설정해요**

**스키마 자동 생성**은 웹사이트, 퍼널, 웨비나마다 따로 설정해요. 각 항목의 **설정**에 있는 **SEO & AEO**(검색엔진·답변 엔진 최적화) 섹션에서 켜거나 끌 수 있어요.

## 스키마 자동 생성 켜는 방법

이미 만들어 둔 웹사이트, 퍼널, 웨비나에서 **스키마 자동 생성**을 켜는 방법이에요.

1. 왼쪽 메뉴에서 **사이트**를 클릭해요. 설정할 항목 종류에 맞게 **퍼널**, **웹사이트**, **웨비나** 탭 중 하나를 선택하세요.

   ![사이트 메뉴에서 탭 선택하기](https://jumpshare.com/share/iLgB1uPDKXvnW28Xcitw+/Screen+Shot+2026-07-29+at+23.41.34.png)

2. 항목 이름을 클릭하거나, 항목 옆의 점 세 개(⋮) 메뉴에서 **편집**을 선택해요.

   ![항목 이름 또는 점 세 개 메뉴에서 편집 선택하기](https://jumpshare.com/share/hhQ2Thl15JveVQA4Mihq+/Screen+Shot+2026-07-29+at+23.43.22.png)

3. 편집기에서 **설정** 탭을 클릭해요.

   ![편집기의 설정 탭](https://jumpshare.com/share/IVzCuL4YGv8GG2pJpzhT+/Screen+Shot+2026-07-29+at+23.45.04.png)

4. **SEO & AEO** 섹션에서 **스키마 자동 생성** 토글을 켜요. 토글 설명에는 "게시할 때 스키마 마크업이 없는 페이지에 자동으로 추가합니다."라는 뜻의 문구가 나와요.

   ![SEO & AEO 섹션의 스키마 자동 생성 토글](https://jumpshare.com/share/NBduj9vl9HzSqEETyCYU+/Screen+Shot+2026-07-29+at+23.46.53.png)

5. **설정** 페이지 아래쪽의 **저장**을 클릭해 변경 내용을 적용해요.

   ![설정 페이지 아래쪽의 저장 버튼](https://jumpshare.com/share/ie80dNHNGjUfPlkJKpKh+/Screen+Shot+2026-07-29+at+23.48.08.png)

이제 **스키마 자동 생성**이 켜졌어요. 스키마 없이 게시된 페이지에는 AI가 만든 구조화된 데이터가 자동으로 추가돼요.

## 자주 묻는 질문

### 자동 생성된 스키마가 페이지의 기존 스키마를 덮어쓰나요?
아니요. 스키마 자동 생성은 게시 시점에 스키마가 없는 페이지에만 마크업을 추가해요. 이미 스키마 마크업이 있는 페이지는 그대로 둬요.

### 자동 생성 때문에 게시가 늦어지나요?
아니요. 스키마 생성은 게시와 동시에 백그라운드에서 진행돼요. 페이지는 바로 공개되고, 스키마는 지연 없이 추가돼요.

### 어떤 항목에서 스키마 자동 생성을 쓸 수 있나요?
웹사이트, 퍼널, 웨비나에서 쓸 수 있어요. 각 항목의 **설정**에 있는 **SEO & AEO** 섹션에서 항목마다 따로 켜요.

### 기존 웹사이트와 퍼널에도 스키마 자동 생성이 기본으로 켜져 있나요?
아니요. 이 기능이 출시되기 전에 만든 항목은 기본값이 **끄기**예요. 직접 켜기 전에는 아무것도 바뀌지 않아요. 출시 이후에 만든 항목은 기본값이 **켜짐**이에요.

### 스키마 자동 생성을 켠 뒤에 다시 끌 수 있나요?
네. **설정**의 **SEO & AEO** 섹션에서 언제든 켜거나 끌 수 있어요. 변경한 뒤에는 꼭 **저장**을 클릭하세요.

### 스키마 자동 생성이 SEO와 AEO에 어떻게 도움이 되나요?
스키마 마크업은 검색엔진이 내 콘텐츠를 이해하고, 별점·자주 묻는 질문·이벤트 정보 같은 풍부한 검색 결과를 보여 주도록 도와요. ChatGPT, Perplexity, Gemini 같은 AI 답변 엔진이 내 콘텐츠를 정확하게 인용하고 참조하는 데도 도움이 돼서, AI가 만든 답변에서의 노출도 좋아져요.

### 버전 기록에서 게시할 때도 스키마 자동 생성이 동작하나요?
네. 빌더에서 게시할 때, 저장하면서 게시될 때, 버전 기록에서 게시할 때처럼 페이지별 게시 방식 모두에서 자동 생성이 실행돼요.

### 스키마 자동 생성을 켠 뒤에 기존 페이지에서 따로 할 일이 있나요?
아니요. 자동 생성은 페이지를 게시할 때만 실행돼요. 이미 게시된 페이지는 다시 게시하지 않으면 그대로예요. 이미 스키마가 있는 페이지라면 다시 게시해도 덮어쓰지 않아요.
