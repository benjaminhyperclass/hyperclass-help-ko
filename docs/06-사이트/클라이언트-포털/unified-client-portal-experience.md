# 통합 클라이언트 포탈

통합 **클라이언트 포탈**은 대시보드, 코스, 커뮤니티, 청구/결제, 공유 파일, 계정 설정을 로그인 한 번, 내비게이션 하나로 묶어 주는 고객용 홈이에요. 이 문서에서는 통합 포탈의 장점과 고객 경험이 어떻게 달라지는지, 그리고 켜는 방법을 안내해요.

이전에는 코스, 커뮤니티, 청구/결제, 파일을 보려면 탭을 따로 옮겨 다녀야 했어요. 통합 포탈에서는 고객이 브랜드가 적용된 하나의 환경 안에서 모든 고객용 앱을 매끄럽게 오갈 수 있어요.

{% hint style="info" %}
통합 클라이언트 포탈은 하이퍼클래스 실험실(Labs) 기능이에요. 플랫폼의 큰 업그레이드이고, 사용자 의견에 따라 다듬어질 수 있어요. **클라이언트 포탈**의 **대시보드**에서 직접 켜서 고객에게 더 나은 경험을 제공해 보세요.
{% endhint %}

## 통합 클라이언트 포탈이란?

통합 클라이언트 포탈은 **대시보드**, 코스, 커뮤니티, 청구/결제, 공유 파일, 계정 설정을 하나로 연결된 브랜드 환경에 모아 줘요. 예전에는 이 기능들이 서로 다른 화면과 내비게이션으로 나뉘어 있어서, 고객이 탭을 옮길 때마다 화면 구성을 다시 파악해야 했어요.

이제 고객은 로그인 한 번, 내비게이션 하나로 비즈니스와 관련된 모든 활동을 이어서 할 수 있어요.

![통합 클라이언트 포탈 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077955926/original/J9biLsv67hOcsvrfJn9eMQlYy0O6DUAMUQ.png?1786249103)

이번 업그레이드로 **클라이언트 포탈**, 코스, 커뮤니티가 기존 플랫폼에서 공통의 최신 기반으로 옮겨졌어요. 그 덕분에 서로 다른 앱을 쓰는 느낌이 아니라 하나의 제품처럼 더 빠르고 매끄럽고 일관된 고객 여정을 만들 수 있어요.

## 주요 장점

통합 클라이언트 포탈은 불편을 줄이고 성능을 높이며 브랜드 경험을 더 전문적으로 만들어 줘요. 비즈니스와 고객 모두에게 도움이 돼요.

- **탭을 오가는 번거로움이 사라져요.** 고객이 코스, 커뮤니티, 대시보드, 청구/결제, 공유 파일 사이를 별개의 제품을 오가는 느낌 없이 자연스럽게 이동해요.
- **더 빨라져요.** 데스크톱과 모바일 모두에서 페이지가 더 빨리 뜨고, 화면 전환이 부드러워요.
- **콘텐츠를 더 쉽게 찾아요.** 새로 디자인한 대시보드와 통합 내비게이션 덕분에 진행 중인 코스, 커뮤니티 활동, 청구/결제 항목, 공유 파일, 계정 설정을 빠르게 찾을 수 있어요.
- **브랜드 경험이 일관돼요.** 로그인부터 포탈의 모든 섹션까지, 비즈니스 브랜드가 앞에 드러나는 정돈된 화면을 만나요.
- **앞으로의 개선이 더 빨라져요.** 공통 기반 위에 만들었기 때문에, 따로 떨어진 제품을 더하지 않고도 개선 사항과 새 기능을 더 빠르게 선보일 수 있어요.

고객은 이동에 쓰는 시간이 줄고, 콘텐츠와 서비스, 커뮤니티에 더 집중할 수 있어요.

## 고객이 느끼는 변화

통합 포탈로 바뀌면 고객은 더 매끄럽고 빠르고 직관적인 경험을 하게 돼요.

### 1. 앱 전환이 더 부드러워요

고객이 코스, 커뮤니티, 대시보드, 청구/결제, 공유 파일 사이를 끊김 없이 오가요. 따로 만든 제품을 이어 붙인 느낌이 아니라, 하나의 여정처럼 느껴져요.

![앱 간 전환 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077955931/original/ah_aS0idgPCoAVrm2T97PZvNnV1Ovu-auw.png?1786249154)

### 2. 성능이 더 빨라요

데스크톱과 모바일 모두 페이지가 더 빨리 열리고, 전환이 부드럽고, 반응이 좋아요. 고객은 기다리는 시간이 줄고 콘텐츠와 서비스를 이용하는 시간이 늘어요.

### 3. 콘텐츠를 더 쉽게 찾아요

새 대시보드와 통합 내비게이션에서 고객이 쉽게 찾을 수 있는 항목은 다음과 같아요.

- 진행 중인 코스
- 커뮤니티 활동
- **Continue Watching**(이어서 보기) 콘텐츠
- **Pinned Communities**(고정한 커뮤니티)
- 청구/결제 항목
- 공유 파일

![새 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077955930/original/KeXJy6KYr8hpRBuyYQUc5gD_bgOKf6esxQ.png?1786249142)

고객은 지금 어디에 있는지, 다음에 무엇을 하면 되는지 바로 알 수 있어요.

### 4. 브랜드 경험이 일관돼요

새로 디자인한 로그인 화면과 포탈에서 비즈니스 브랜드가 앞에 드러나요. 로그인부터 코스, 커뮤니티, 청구/결제, 파일까지 더 일관되고 전문적인 경험을 해요.

## SEO와 검색 노출

통합 포탈 덕분에 포탈 밖에서도 고객을 만날 수 있어요. 조건에 맞는 공개 코스·커뮤니티 페이지는 이제 SEO에 맞게 준비돼요. 검색에 적합한 방식으로 표시되고, 검색 엔진이 수집할 수 있는 URL과 페이지 메타데이터를 갖추고 있어서 검색 엔진이 콘텐츠를 이해하고 찾기 쉬워요.

이를 통해 더 많은 사람에게 도달하고, 새로운 고객이 유용한 콘텐츠를 발견하게 하고, 전문성을 바탕으로 자연 검색 노출을 키우고, 공개 콘텐츠를 성장 채널로 활용할 수 있어요.

{% hint style="warning" %}
비공개 콘텐츠, 접근이 제한된 콘텐츠, 고객 전용 콘텐츠는 그대로 보호돼요. 검색 엔진에 색인될 수 있는 것은 공개 코스·커뮤니티 페이지뿐이에요.
{% endhint %}

## 플랫폼 구조

통합 클라이언트 포탈은 단순히 화면만 바뀐 것이 아니에요. 하이퍼클래스는 **클라이언트 포탈**, 코스, 커뮤니티를 각각 따로 운영하던 기존 방식에서, 공통의 최신 구조 위에서 서로 연결된 앱으로 옮겼어요.

이 구조 업그레이드로 다음과 같은 점이 좋아졌어요.

- **더 빠르고 매끄러운 이동**: 모든 고객용 앱의 성능이 좋아져요.
- **일관된 로그인과 고객 여정**: 처음부터 끝까지 하나로 이어진 경험을 제공해요.
- **기기에 관계없는 성능**: 데스크톱과 모바일에 맞게 최적화돼 있어요.
- **검색 엔진에 친화적인 공개 페이지**: 조건에 맞는 콘텐츠의 노출 범위가 넓어져요.
- **고객용 제품 전반의 공통 기반**: 앞으로의 개선을 더 빠르게 선보일 수 있어요.
- **브랜딩과 사용자 지정의 유연성**: 고객 경험을 더 폭넓게 조정할 수 있어요.

고객은 더 단순하고 빠른 경험을 하고, 비즈니스는 또 하나의 분리된 제품이나 탭을 늘리지 않고도 계속 성장할 수 있는 플랫폼을 갖게 돼요.

## 출시 예정

통합 포탈의 새 기반 덕분에, 앞으로 업데이트에서 다음 기능이 추가될 예정이에요.

- **클라이언트 포탈** 안에서 예약
- 사용자 지정 내비게이션 링크
- 더 깊은 포탈 사용자 지정
- 더 다양한 브랜딩 옵션
- 더 풍부한 커뮤니티와 이벤트 경험
- 고객이 직접 할 수 있는 셀프서비스 기능 확대

## 통합 클라이언트 포탈 켜기

다음 단계를 따르면 비즈니스와 고객에게 통합 클라이언트 포탈을 켤 수 있어요.

1. 하이퍼클래스에서 **클라이언트 포탈 > 대시보드**로 이동하세요.
2. 통합 포탈을 켜는 버튼을 찾아 클릭하세요.3. 켜고 나면 고객이 통합 포탈을 바로 사용할 수 있어요. 라우팅 등 시스템의 다른 부분은 달라지지 않아요.

고객은 이제 **대시보드**, 코스, 커뮤니티, 청구/결제, 공유 파일, 계정 설정을 하나의 통합 환경에서 매끄럽게 오갈 수 있어요.

## 자주 묻는 질문

### 통합 클라이언트 포탈을 켜면 무엇이 달라지나요?

통합 포탈을 켜면 고객은 **대시보드**, 코스, 커뮤니티, 청구/결제, 공유 파일, 계정 설정이 하나의 환경으로 이어진 새 화면을 보게 돼요. 백엔드 라우팅과 시스템의 다른 부분은 그대로예요.

### 고객이 다시 로그인해야 하나요?

아니요. 고객은 지금 쓰는 로그인 정보를 그대로 써요. 통합 포탈은 **대시보드**, 코스, 커뮤니티, 청구/결제, 파일, 계정 설정 전체에서 한 번의 로그인으로 이용할 수 있어요.

### 공개 코스와 커뮤니티가 검색 엔진에 자동으로 색인되나요?

조건에 맞는 공개 코스·커뮤니티 페이지는 이제 SEO에 맞게 준비돼요. 검색에 적합한 방식으로 표시되고, 수집 가능한 URL과 페이지 메타데이터를 갖추고 있어요. 비공개 콘텐츠, 접근이 제한된 콘텐츠, 고객 전용 콘텐츠는 계속 보호되고 검색 엔진에 색인되지 않아요.

### 통합 포탈이 기존 워크플로우나 자동화에 영향을 주나요?

아니요. 통합 포탈은 고객이 보는 화면만 바꾸고, 백엔드 라우팅, 워크플로우, 자동화, 연동에는 영향을 주지 않아요. 기존 설정은 그대로 유지돼요.

### 통합 포탈에 우리 브랜드를 적용할 수 있나요?

네. 통합 포탈은 고객 경험 내내 비즈니스 브랜드를 앞에 보여 줘요. 추가 브랜딩·사용자 지정 옵션은 이후 업데이트에서 제공할 예정이에요.

### 통합 포탈을 모바일에서도 쓸 수 있나요?

네. 통합 포탈은 데스크톱과 모바일 모두에 맞게 최적화돼 있어서, 어떤 화면 크기에서도 더 빠르고 반응이 좋아요.

### 앞으로 통합 포탈에 어떤 기능이 추가되나요?

앞으로 업데이트에서 **클라이언트 포탈** 안의 예약, 사용자 지정 내비게이션 링크, 더 깊은 포탈 사용자 지정, 더 다양한 브랜딩 옵션, 더 풍부한 커뮤니티와 이벤트 경험, 고객 셀프서비스 기능 확대가 추가될 예정이에요.

### 통합 포탈을 켠 뒤에 다시 끌 수 있나요?

통합 포탈은 **클라이언트 포탈**이 나아갈 방향이고, 지속적인 개선을 위해 최신 구조 위에 만들어졌어요. 켠 뒤에 문제가 생기면 하이퍼클래스 고객지원에 문의하세요.
