# 채팅 위젯의 메시지 필드 설정

WhatsApp, 이메일/SMS, 올인원 채팅, 음성 AI 위젯에서 새 대화마다 첫 메시지를 미리 입력해 둘 수 있어요. 방문자의 첫 메시지로 대화의 맥락을 바로 파악하고, 연락처 정보는 보호하며, 워크플로우도 그대로 작동해요.

## 메시지 필드란?

메시지 필드는 새로 만드는 채팅 위젯(실시간 채팅 제외)의 문의 폼에 나타나는, 미리 입력된 **메시지** 입력란이에요. "안녕하세요, ...에 대해 더 알고 싶어요."처럼 기본 문구를 정해 두면 방문자는 항상 첫 메시지를 남기게 돼요. 이름·전화번호·이메일 같은 개인 정보는 대화 내용이 아니라 CRM에 비공개로 저장돼요.

폼에 다른 메시지 필드가 없으면 이 필드는 필수예요. 이미 메시지 필드가 있으면 선택 사항이에요. 방문자는 메시지를 보내기 전에 미리 입력된 문구를 자유롭게 고치거나 바꿀 수 있어요.

## 메시지 필드의 장점

기본 메시지를 정해 두면 이런 점이 좋아요.

- 모든 채팅이 명확하고 일관된 첫 메시지로 시작해요.
- 연락처 정보가 채팅 내용에 드러나지 않고 CRM 레코드 안에 보관돼요.
- 문의 폼에 메시지 필드가 이미 있든 없든 똑같이 쓸 수 있어요.
- 상담 담당자가 처음부터 맥락을 알고 응대할 수 있어요.
- 모든 대화가 방문자의 의도로 시작하므로 마케팅 어트리뷰션에 도움이 돼요.

## 메시지 필드 기본 동작

WhatsApp, 이메일/SMS, 올인원 채팅, 음성 AI 위젯을 만들 때마다 빌더에 기본 **메시지** 필드가 나타나요.

- 문의 폼에 메시지 필드가 없으면 이 필드는 필수이고, 수정할 수 있는 기본 문구가 미리 입력돼요.
- 문의 폼에 메시지 필드가 이미 있으면 이 필드는 선택 사항이에요. 그대로 두거나, 삭제하거나, 순서를 바꿀 수 있어요.
- 어느 경우든 위젯 저장, 삽입, 코드 생성이 문제없이 이뤄져요.

## 미리 입력할 메시지 설정하기

위젯 빌더에서 다음 작업을 할 수 있어요.

- **메시지** 필드를 클릭하고 기본 문구를 입력해요(최대 255자).
- 병합 필드를 넣어 상황에 맞는 문구를 만들 수 있어요.
- 드래그 앤 드롭으로 필드 순서를 바꿔요.
- 필드가 선택 사항일 때는 **필수** 설정을 켜거나 꺼요.

## 방문자가 보는 화면

사이트에 위젯이 로드되면 방문자는 메시지 입력란에 미리 입력된 문구를 보게 돼요. 방문자는 이렇게 할 수 있어요.

- 문구를 그대로 보내서 빠르게 대화를 시작해요.
- 보내기 전에 내용을 고치거나 지워요.
- 따로 입력하지 않아도 바로 맥락이 담긴 메시지를 보낼 수 있어요.

## 지원하는 채팅 위젯 유형

이 기능은 다음 위젯에서 쓸 수 있어요.

- WhatsApp 채팅 위젯
- 이메일/SMS 채팅 위젯
- 올인원 채팅 위젯(멀티 채널)
- 음성 AI 채팅 위젯

{% hint style="info" %}
실시간 채팅 위젯은 기존의 자유 입력 메시지 상자를 그대로 쓰며, 이 새 필드는 들어 있지 않아요.
{% endhint %}

## 메시지 필드 설정 방법

설정은 2분이면 끝나요.

1. 왼쪽 메뉴에서 **사이트**로 이동한 뒤, 위쪽의 **채팅 위젯**을 선택하세요. 계정에서 만든 모든 채팅 위젯을 보고, 관리하고, 편집할 수 있는 화면이 열려요.

   ![채팅 위젯 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058667619/original/Qdy0n-OyD2aRTTQRwlhI9FVuy-Rvw_Mtlw.png?1763478164)

2. **채팅 위젯** 페이지 오른쪽 위의 **+ 신규** 버튼을 클릭하세요. 위젯 유형을 고르고 디자인과 동작을 설정하는 과정이 시작돼요.

   ![신규 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058667862/original/0R7FpvESyr4fjh4S5F4LObeslB68_2aNOA.png?1763478225)

3. **채팅 유형 선택** 화면에서 만들 채팅 위젯 유형을 고르세요. **All-In-One Chat**(올인원 채팅), **SMS/Email Chat**(SMS/이메일 채팅), **Live Chat**(실시간 채팅), **WhatsApp Chat**, **음성 AI** 중에서 선택할 수 있어요. 유형마다 지원하는 소통 방식이 달라요. 방문자와 소통하려는 방식에 가장 잘 맞는 유형을 고르세요.

   ![채팅 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058668667/original/t6n4k6De1nY0TyrLrFeaVWU8blUED4ScSA.png?1763478540)

4. 채팅 유형을 고른 뒤 **채팅 창** 탭을 열어 방문자에게 보이는 내용을 설정하세요. 여기서 **채팅 창 제목**을 고치고, **인트로 메시지**를 추가하고, **미리 입력된 메시지 텍스트**를 정할 수 있어요. 미리 입력된 메시지 텍스트는 방문자가 채팅을 시작할 때 보이는 기본 메시지이고, 방문자가 보내기 전에 수정할 수 있어요.

   ![채팅 창 탭 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058670237/original/XjJVDrvwCXSWYX-gvR-WC1wpnXyYhLXE3g.png?1763479314)

## 자주 묻는 질문

### 이 기능이 기존 메시지 필드를 대체하나요?
아니요. 폼에 메시지 필드가 이미 있으면 새 필드는 선택 사항이에요. 둘 중 유지할 필드를 직접 고르면 돼요.

### 페이지마다 다른 기본 메시지를 쓸 수 있나요?
네. 미리 입력할 문구를 다르게 설정한 위젯을 여러 개 만들고, 각 위젯을 원하는 페이지에 삽입하세요.

### 방문자가 수정한 메시지도 연락처 레코드에 저장되나요?
최종 메시지는 대화 내용에 표시돼요. 개인 정보는 CRM 연락처에 그대로 남아요.

### 실시간 채팅에서도 이 기능을 쓸 수 있나요?
아직 지원하지 않아요. 실시간 채팅은 미리 입력된 값이 없는 기본 자유 입력란을 계속 사용해요.

### 나중에 필드를 지워도 삽입한 코드가 문제없이 작동하나요?
네. 하이퍼클래스에서 위젯을 편집해 필드를 제거하고 저장하면, 이미 게시된 위젯에 자동으로 반영돼요.

### 기본 문구는 몇 자까지 입력할 수 있나요?
공백을 포함해 최대 255자까지 입력할 수 있어요.

### **Customer Replied**(고객 답장) 트리거를 쓰는 워크플로우도 계속 작동하나요?
네. 방문자가 처음 제출한 메시지가 미리 입력된 문구든 수정한 문구든, **Customer Replied** 자동화가 실행돼요.
