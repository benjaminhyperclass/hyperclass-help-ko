# 채팅 위젯의 커스터마이징 가능한 메시지 필드

하이퍼클래스의 커스터마이징 가능한 메시지 필드를 활용해서 왓츠앱(WhatsApp), 이메일/SMS, 올인원(All-in-One) 채팅, 음성 AI(Voice AI) 위젯에서 새로운 모든 대화에 바로 맥락을 담아보세요. 의미 있는 첫 메시지를 받으면서도 연락처 정보는 안전하게 보호하고, 워크플로우도 원활하게 유지할 수 있어요.

# **채팅 위젯의 커스터마이징 가능한 메시지 필드란?**

커스터마이징 가능한 메시지 필드는 새로 만든 채팅 위젯(라이브 채팅 제외)의 연락처 양식에 표시되는 사전 입력된 "메시지" 텍스트 박스예요. "안녕하세요, ~에 대해 더 알고 싶어요" 같은 기본 텍스트를 미리 설정해두면, 방문자는 항상 첫 메시지를 남기게 되고, 이름·전화번호·이메일 같은 개인 정보는 대화 내용이 아닌 CRM에 비공개로 저장돼요.

이 필드는 다른 메시지 필드가 없을 때는 필수이고, 이미 메시지 필드가 있는 양식(Form)에서는 선택 사항이에요. 방문자는 전송 전에 사전 입력된 텍스트를 자유롭게 수정하거나 바꿀 수 있어요.

---

## **커스터마이징 가능한 메시지 필드의 주요 장점**

기본 메시지를 제공하면 바로 다음과 같은 효과를 얻을 수 있어요:

- 모든 채팅에서 명확하고 일관된 첫 메시지를 보장해요.
- 연락처 정보가 채팅 대화 내용에 노출되지 않고 CRM 레코드 안에만 유지돼요.
- 연락처 양식에 메시지 필드가 있든 없든 유연하게 적용할 수 있어요.
- 상담원이 미리 맥락을 파악할 수 있어 업무 효율이 높아져요.
- 모든 대화 내용이 방문자의 의도로 시작되므로 마케팅 어트리뷰션(Attribution)도 개선돼요.

---

## 사전 정의된 메시지 필드 로직

왓츠앱, 이메일/SMS, 올인원 채팅, 음성 AI 위젯을 만들 때마다 빌더(Builder)에 기본 "메시지" 필드가 나타나요.

- 연락처 양식에 메시지 필드가 없다면 이 필드는 필수이며, 편집 가능한 텍스트가 사전 입력돼요.
- 연락처 양식에 이미 메시지 필드가 있다면 이 필드는 선택 사항이며, 유지하거나 삭제하거나 순서를 바꿀 수 있어요.
- 어느 경우든 위젯은 문제없이 저장되고, 삽입(Embed)되며, 코드가 생성돼요.

---

## **사전 입력 메시지 커스터마이징**

위젯 빌더 안에서 다음을 할 수 있어요:

- 메시지 필드를 클릭해서 원하는 기본 텍스트를 입력하세요(최대 255자).
- 동적 브랜딩을 위해 병합 필드(Merge Field)를 삽입할 수 있어요.
- 드래그 앤 드롭으로 필드 순서를 재배치할 수 있어요.
- 필드가 선택 사항일 때는 "필수" 여부를 토글(Toggle)로 켜고 끌 수 있어요.

---

## **방문자의 편집 경험**

위젯이 사이트에 로드되면 방문자는 메시지 박스 안에 미리 입력된 텍스트를 보게 돼요. 방문자는 다음과 같이 할 수 있어요:

- 그대로 전송해서 빠르게 대화를 시작할 수 있어요.
- 전송 전에 내용을 수정하거나 삭제할 수 있어요.
- 별도로 타이핑하지 않아도 바로 맥락이 담긴 메시지를 보낼 수 있어요.

---

## **지원되는 채팅 위젯 유형**

이 기능은 다음 위젯에서 사용할 수 있어요:

- 왓츠앱 채팅 위젯
- 이메일/SMS 채팅 위젯
- 올인원 채팅 위젯(멀티 채널)
- 음성 AI 채팅 위젯

참고: 라이브 채팅(Live Chat) 위젯은 기존의 자유 입력 메시지 박스를 그대로 사용하며, 이 새로운 필드는 포함되지 않아요.

---

## **커스터마이징 가능한 메시지 필드 설정 방법**

설정은 2분도 채 걸리지 않아요:

### 채팅 위젯 설정 열기

왼쪽 네비게이션 메뉴에서 **사이트(Sites)** 로 이동한 후 상단의 **채팅 위젯(Chat Widget)** 을 선택하세요.

이렇게 하면 계정에 생성된 모든 채팅 위젯을 확인, 관리, 편집할 수 있는 메인 대시보드가 열려요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058667619/original/Qdy0n-OyD2aRTTQRwlhI9FVuy-Rvw_Mtlw.png?1763478164)

### 새 위젯 만들기

채팅 위젯 페이지 오른쪽 상단의 **+ New** 버튼을 클릭하세요.

이렇게 하면 설정 프로세스가 시작되며, 위젯 유형(왓츠앱, 이메일/SMS, 올인원 채팅, 음성 AI)을 선택하고 디자인과 동작을 커스터마이징할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058667862/original/0R7FpvESyr4fjh4S5F4LObeslB68_2aNOA.png?1763478225)

### **채팅 유형 선택**

제공되는 옵션 중에서 만들고 싶은 채팅 위젯 유형을 선택하세요 — **올인원 채팅(All-In-One Chat), SMS/이메일 채팅, 라이브 채팅(Live Chat), 왓츠앱 채팅(WhatsApp Chat), 음성 AI(Voice AI)**.

각 옵션은 서로 다른 커뮤니케이션 방식을 지원하므로, 웹사이트 방문자와 어떤 방식으로 소통하고 싶은지에 맞게 선택하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058668667/original/t6n4k6De1nY0TyrLrFeaVWU8blUED4ScSA.png?1763478540)

### **채팅 창 설정**

채팅 유형을 선택한 후, **채팅 창(Chat Window)** 탭을 열어 방문자에게 보이는 세부 항목을 커스터마이징하세요.

여기서 **채팅 창 제목(Chat Window Title)** 을 수정하고, **인트로 메시지(Intro Message)** 를 추가하고, **사전 입력 메시지 텍스트(Prefilled Message Text)** 를 정의할 수 있어요. 이는 방문자가 채팅을 시작할 때 보게 되는 기본 메시지이며, 전송 전에 수정할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058670237/original/XjJVDrvwCXSWYX-gvR-WC1wpnXyYhLXE3g.png?1763479314)

## **자주 묻는 질문**

**Q: 기존 메시지 필드를 대체하나요?**

아니요. 양식에 이미 메시지 필드가 있다면 새 필드는 선택 사항이며, 어떤 것을 유지할지 직접 선택할 수 있어요.

**Q: 페이지마다 다른 기본 메시지를 사용할 수 있나요?**

네. 각각 고유한 사전 입력 텍스트를 가진 여러 위젯을 만들어서 특정 페이지마다 삽입할 수 있어요.

**Q: 방문자가 수정한 메시지가 연락처 레코드에 저장되나요?**

최종 메시지는 대화 내용(Transcript)에 표시되고, 개인 정보는 CRM 연락처에 그대로 유지돼요.

**Q: 라이브 채팅도 이 기능을 지원하나요?**

아직은 아니에요. 라이브 채팅은 계속해서 사전 입력 값이 없는 기존의 자유 입력 텍스트 박스를 사용해요.

**Q: 나중에 코드 삽입을 깨뜨리지 않고 필드를 제거할 수 있나요?**

물론이에요. 하이퍼클래스에서 위젯을 편집하고 필드를 제거한 후 저장하면, 실제 운영 중인 위젯도 자동으로 업데이트돼요.

**Q: 기본 텍스트는 최대 몇 자까지 입력할 수 있나요?**

공백 포함 최대 255자까지 입력할 수 있어요.

**Q: "고객 답장(Customer Replied)" 트리거로 실행되는 워크플로우도 계속 작동하나요?**

네. 방문자가 제출한 첫 메시지(사전 입력된 것이든 수정된 것이든)가 "고객 답장" 자동화를 트리거해요.
