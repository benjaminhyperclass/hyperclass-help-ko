# 채팅 위젯의 알림 소리 옵션

새 채팅 메시지에 대해 방문자에게 알림을 제공하세요! 하이퍼클래스의 올인원(All-in-One) 및 라이브 채팅(Live Chat) 위젯에 있는 **알림 소리(Notification Sound) 설정**은 소리와 시각적 신호를 함께 보여줘서 놓치는 답장을 줄여줍니다. 이 글에서는 알림 소리 설정이 어떤 기능인지, 어디에서 설정할 수 있는지, 어떻게 구성하는지 설명해 드릴게요.

# 채팅 위젯의 알림 소리 설정이란 무엇인가요?

알림 소리(Notification Sound)는 채팅 위젯(Chat Widget) 빌더에서 웹사이트의 새 메시지에 대한 방문자용 알림을 제어하는 설정이에요. 올인원과 라이브 채팅 위젯에 적용되며, 기본값은 **켜짐(ON)**이에요. 알림 소리가 **켜짐** 상태일 때 위젯은 다음과 같이 작동합니다:

- 방문자에게 지원되는 메시지가 표시될 때마다 소리를 재생해요. 여기에는 채팅 메시지뿐 아니라 환영 메시지, 폼 관련 안내, 리다이렉트(Redirect) 등 다른 위젯 메시지도 포함돼요.

- 팝업, 알림 배지, 브라우저 탭 제목 업데이트 등 시각적 신호를 함께 보여줘서 방문자가 업데이트를 알아차릴 수 있도록 도와줘요.

**꺼짐(OFF)** 상태로 설정하면 채팅 위젯은 소리나 시각적 알림 없이 조용하게 메시지를 계속 수신해요.

## 채팅 위젯 알림 소리의 주요 이점

- **방문자 인지도 향상**: 새 메시지를 즉시 알려줘서 놓치는 답장과 이탈을 줄여줘요.

- **참여도 향상**: 적절한 타이밍의 소리와 시각 신호가 대화의 흐름을 이어가도록 도와줘요.

- **브랜드 일관성**: 소리 알림이 브랜드 톤에 맞는지 선택할 수 있어요.

- **코드 수정 불필요**: 이 설정을 변경하기 위해 임베드 코드를 수정할 필요가 없어요.

---

## 소리 알림을 발생시키는 지원 메시지

알림 소리가 켜짐 상태일 때, 다음과 같은 추가 시스템 및 생명주기 메시지 유형에서도 소리 알림이 재생될 수 있어요:

- **라이브 채팅 및 세션 흐름**
**라이브 채팅 시작 메시지** (채팅 시작 시, 연락처 폼 제출 성공 후)
**확인 메시지** (채팅이 확인되거나 종료될 때)

- **영업시간 처리**
영업시간 외 **환영 메시지** (영업시간이 비활성화된 경우, 연락처 폼이 표시될 때, 활성 세션 중 수신된 경우)

- **시스템 및 인사 메시지**
**부제목 메시지** (신규 방문자에게 보여지는 최초 인사, 이전 채팅 기록이 없을 때, 인라인 모드 초기화 중)

- **폼 및 리다이렉트**
**연락처 정보** 요청 메시지 (연락처 폼이 표시될 때)
**리다이렉트 메시지** (리다이렉트가 활성화된 상태에서 폼 제출 후)

## 알림 소리 설정 조정 방법

지원되는 채팅 유형인 **올인원**과 라이브 채팅에 대해 채팅 위젯 빌더에서 직접 알림 소리를 구성할 수 있어요. 이 설정은 지원되는 위젯에 대해 기본적으로 **켜짐** 상태이며, 더 조용한 환경을 원할 경우 위젯별로 **꺼짐**으로 전환할 수 있어요. 아래 단계에서 설정 위치와 저장 방법을 확인해 보세요.

- **사이트(Sites) → 채팅 위젯(Chat Widgets)**으로 이동한 후 편집하려는 위젯을 열어주세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355860/original/eWerku0Ofk7r0YQi96sOBxU5BMLVfRdVRw.png?1765403925)

- 왼쪽 메뉴에서 **채팅 창(Chat Window)** 탭을 선택한 다음 추가 옵션(Additional Options) 드롭다운을 열어주세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355890/original/zLaqIcthVzL5wlYWuLp78KKnrwrf8mSniw.png?1765404001)

- 페이지 전략에 따라 알림 소리를 **켜짐**(권장) 또는 **꺼짐**으로 토글하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355898/original/Bp_U16UuunuW2hEstOj-9UP4xt3zuyQGCw.png?1765404026)

- 우측 상단의 **저장(Save)**을 클릭하세요. 임베드 코드가 이미 사이트에 적용되어 있다면, 페이지를 새로고침해서 변경사항을 확인하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355916/original/z6jx_WeugE9XdEws0fkHq66uJtpS3r3YGg.png?1765404057)

## 자주 묻는 질문

**Q: 이 설정이 하이퍼클래스의 직원/운영자 알림도 변경하나요?**
아니요. 이 설정은 웹사이트 위젯에서 방문자 쪽 알림만 제어해요. 팀 알림은 사용자 알림 설정에서 별도로 관리돼요.

**Q: 커스텀 사운드를 업로드하거나 볼륨을 조절할 수 있나요?**
현재는 불가능해요. 이 기능은 단순한 켜짐/꺼짐 토글이에요.

**Q: 사이트에 여러 개의 위젯이 있으면 어떻게 되나요?**
이 설정은 위젯별로 적용돼요. 각 위젯은 자체적인 켜짐/꺼짐 토글을 따라요.

**Q: 꺼짐으로 설정해도 배지나 팝업이 표시되나요?**
아니요. 꺼짐은 무음 모드로, 소리나 시각적 알림이 전혀 표시되지 않아요.

**Q: 어떤 위젯이 알림 소리를 지원하나요?**
올인원과 라이브 채팅 위젯만 지원해요.
