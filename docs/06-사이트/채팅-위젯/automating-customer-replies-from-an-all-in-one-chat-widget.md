# All-in-One Chat 위젯 답장에 자동으로 응답하는 워크플로우 만들기

고객이 All-in-One Chat 위젯에서 답장을 보냈을 때 실행되는 워크플로우를 만드는 방법을 안내해요. **Customer Replied**(고객 답장) 트리거에 필터를 걸어, 원하는 위젯의 답장에서만 자동화가 실행되도록 설정해요. 담당자 배정, 태그, 알림, 에스컬레이션, 문의 분류 같은 활용 예시도 함께 소개해요.

## 이 문서에서 다루는 내용

- 고객이 **All-in-One Chat** 채널로 답장할 때 실행되는 워크플로우 설정하기
- 트리거를 특정 **Chat Type**(채팅 유형)으로 좁히기: **Chat Widget** 또는 **Live Chat**
- 특정 위젯 설정에서 온 답장에서만 실행되도록 제한하기
- 라우팅, 태그, 담당자 배정, 알림, 에스컬레이션, 문의 분류 로직 구성하기
- 채팅 진입 경로가 여러 개일 때 자동화를 깔끔하게 관리하기

이 문서를 끝까지 따라 하면 답장 기반 워크플로우를 원하는 대상에만 정확히 적용할 수 있어요.

---

## 트리거 로직의 구조

트리거는 아래 세 단계의 필터로 구성돼요.

### 1단계: 이벤트

**Customer Replied**
고객이 답장 메시지를 보내면 워크플로우가 시작돼요.

### 2단계: 답장 채널

**All-in-One Chat**
통합 채팅 위젯에서 온 답장에서만 실행되도록 제한해요.

### 3단계: 범위 필터 (선택에 따라 달라져요)

**All-in-One Chat**을 선택하면 추가 필터가 나타나요.

1. **Chat Type**

   - **Chat Widget**
   - **Live Chat**
2. 세부 설정

   - **Chat Type**이 **Chat Widget**이면 > 정확한 위젯을 선택해요
   - **Chat Type**이 **Live Chat**이면 > 정확한 **Live Chat** 설정을 선택해요

선택한 조건을 모두 만족할 때만 워크플로우가 실행돼요.

---

## 시작하기 전에

자동화를 설정하기 전에 아래 내용을 확인하세요.

- All-in-One Chat 위젯이 하나 이상 설정되어 있어야 해요.
- **자동화 > 워크플로우** 메뉴에 접근할 수 있어야 해요.
- 담당자 배정 로직을 쓴다면 사용자와 팀이 먼저 설정되어 있어야 해요.
- 태그나 파이프라인 라우팅을 쓴다면 이름 규칙을 미리 정해 두세요.

---

## 설정 방법

### 1단계. 워크플로우 만들기 또는 열기

1. **자동화 > 워크플로우**로 이동해요.
2. **Create Workflow**(워크플로우 만들기)를 클릭해요. 기존 워크플로우를 열어도 돼요.
3. 워크플로우 빌더에서 **Add Trigger**(트리거 추가)를 선택해요.

---

### 2단계. 트리거 이벤트 선택

1. **Customer Replied**를 선택해요.
2. 트리거 설정 패널이 열려요.

---

### 3단계. 답장 채널 설정

1. **Reply Channel**(답장 채널) 드롭다운을 찾아요.
2. **All-in-One Chat**을 선택해요.

이렇게 선택하면 세부 필터가 나타나요.

![Reply Channel에서 All-in-One Chat을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066465347/original/Z6BwUSOsUiXq9TvVO8VEHfS8bSfIwm4HMA.png?1773035278)

---

### 4단계. 채팅 유형 선택

**Chat Type**에서 둘 중 하나를 선택해요.

#### 옵션 A: Chat Widget

위젯 화면에서 보낸 답장을 대상으로 할 때 선택해요.

#### 옵션 B: Live Chat

통합 채팅 시스템 안의 Live Chat 설정과 연결된 답장을 대상으로 할 때 선택해요.

여기서 선택한 값에 따라 다음 단계에 나오는 설정 목록이 달라져요.

![Chat Type을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066465352/original/Vs4G-gEYSpfYeSEvWY4GT_7CSlWaCR-ymA.png?1773035297)

마지막 드롭다운은 **Chat Type**에 따라 바뀌어요.

- **Chat Type**이 **Chat Widget**이면
  **Chat Widget is** 아래 목록에서 선택해요.
  ![Chat Widget is 목록에서 위젯을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066465410/original/_Zi3lQxdUwkPcVr61RvtKRzFKI8x4fLH9w.png?1773035371)

  **Live Chat is** 아래 목록에서 선택해요.

![Live Chat is 목록에서 설정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066465390/original/nPa5N5fNL-0Iqv-QhTvmJvSJjeg0oukXpg.png?1773035332)

이 단계를 거치면 선택한 위젯 설정에서 온 답장에만 워크플로우가 실행돼요.

---

### 6단계. 트리거 저장

**Save Trigger**(트리거 저장)를 클릭해요.

이제 워크플로우는 선택한 All-in-One Chat 설정에서 온 고객 답장에만 실행돼요.

## 활용 예시

이 트리거를 실제로 어떻게 쓸 수 있는지 예시를 소개해요.

### 1. 자동 접수 확인

#### 사용 상황

고객이 답장하면 바로 접수 확인 메시지를 보내요.

#### 트리거

- **Customer Replied**
- **Reply Channel** = **All-in-One Chat**
- **Chat Type** = **Chat Widget**
- **Chat Widget is** = 고객지원 위젯

#### 액션

- **Send message**(메시지 전송): "메시지를 받았어요. 곧 답변드릴게요."
- 대화 또는 연락처를 팀원에게 배정
- 태그 추가: `Reply Received`
- 선택 사항: 내부 작업 만들기

#### 권장 사항

접수 확인 메시지는 짧게 쓰고, 자동 발송처럼 느껴지지 않는 말투로 쓰세요.

---

### 2. 부서별 라우팅 (영업 vs 고객지원)

#### 목표

위젯마다 다른 팀으로 답장을 보내요.

#### 워크플로우 A: 영업 위젯

트리거 범위: 영업 위젯

액션:

- 영업 담당자에게 배정 (또는 라운드 로빈)
- 태그 추가: `Sales Inquiry`
- **Create opportunity**(기회 만들기)
- 영업 채널에 내부 알림 보내기

#### 워크플로우 B: 고객지원 위젯

트리거 범위: 고객지원 위젯

액션:

- 고객지원 담당자에게 배정
- 태그 추가: `Support`
- 서비스 작업 만들기
- 접수 확인 메시지 보내기

이렇게 하면 답장이 오는 즉시 라우팅돼요.

---

### 3. 우선순위가 높은 답장 알림

#### 목표

중요한 위젯에서 답장이 오면 리더에게 알려요.

트리거 범위: 임원용 또는 VIP 위젯

액션:

- 내부 알림 보내기
- 우선순위가 높은 작업 만들기
- 태그 추가: `VIP`
- 상위 팀원에게 담당자 변경(에스컬레이션)

---

### 4. 답장 내용에 따른 문의 분류

#### 목표

답장 내용으로 고객의 의도를 구분해요.

트리거 범위: 메인 채팅 위젯

액션:

- 메시지에 "price" 또는 "cost"가 들어 있으면 > 태그 `Pricing Interest` 추가
- 메시지에 "cancel" 또는 "refund"가 들어 있으면 → 태그 `Retention Risk` 추가
- 알맞은 팀으로 라우팅
- 상황에 맞는 후속 질문 보내기

---

### 5. 에스컬레이션 (답변이 없을 때)

#### 목표

답장이 제때 처리되지 않으면 상위 담당자에게 넘겨요.

트리거 범위: Live Chat 설정

액션:

1. 10분 기다리기
2. 아무 조치가 없으면 (직접 정한 기준에 따라):

   - 백업 담당자에게 알림
   - 대화 담당자 변경
   - 전화 연락을 제안하는 메시지 보내기

---

### 6. 위젯이 여러 개인 환경

웹사이트, 퍼널, 브랜드가 여러 개라면 아래처럼 관리하세요.

- 위젯마다 워크플로우를 하나씩 만들어요.
- 워크플로우 이름을 알아보기 쉽게 지어요. 예: `답장 - 고객지원 위젯 - 라우팅`
- 태그 이름 규칙을 일관되게 유지해요.
- 관련 없는 위젯을 한 워크플로우에 묶지 않아요.

이렇게 하면 나중에 관리하기 쉬워요.

---

## 운영 팁

- 위젯이 여러 개라면 항상 특정 위젯/설정을 선택하세요.
- 라우팅 로직은 기능별로 나누어 두세요.
- 의도한 경우가 아니라면 **Live Chat**과 **Chat Widget** 로직을 한 워크플로우에 섞지 마세요.
- 분기마다 워크플로우를 점검해서 서로 겹치는 것이 없는지 확인하세요.
- 문제를 쉽게 찾을 수 있도록 이름 규칙을 유지하세요.

---

## 문제 해결

### Reply Channel에 All-in-One Chat이 보이지 않아요

아래 내용을 확인하세요.

- 선택한 트리거가 **Customer Replied**인지 확인하세요.
- 계정에 All-in-One Chat 위젯이 있는지 확인하세요.

---

### 원하는 위젯이 목록에 나타나지 않아요

- **Chat Type**을 바꿔 보세요(**Chat Widget** ↔ **Live Chat**).
- 위젯 설정이 있고 활성 상태인지 확인하세요.

---

### 워크플로우가 의도하지 않게 실행돼요

- 특정 설정을 선택했는지 확인하세요.
- 중복된 워크플로우가 있는지 확인하세요.
- 서로 겹치는 트리거 조건이 없는지 검토하세요.

---

## 정리

**Customer Replied** 트리거에 **All-in-One Chat** 필터를 쓰면 아래 작업을 할 수 있어요.

- 통합 채팅에서 온 답장만 정확히 골라내기
- 위젯 유형과 설정별로 자동화 범위 정하기
- 대화를 알맞은 곳으로 라우팅하기
- 접수 확인, 에스컬레이션, 문의 분류, 내부 알림 실행하기
- 워크플로우 구조를 깔끔하게 유지하고 확장하기

제대로 설정하면 이 트리거는 채팅 채널 전반에서 답장에 실시간으로 반응하는 자동화의 기본이 돼요.
