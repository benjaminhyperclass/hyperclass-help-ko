# 페이스북 & 인스타그램 채팅 위젯

실시간 메신저와 DM 대화를 웹사이트로 바로 가져오세요. 새로운 페이스북 채팅(Facebook Chat)과 인스타그램 채팅(Instagram Chat) 위젯 유형을 사용하면 방문자가 이미 사용 중인 메타(Meta) 채널에서 인사를 건넬 수 있어, 응답률을 높이고 후속 작업을 더욱 간편하게 만들어줍니다.

# 페이스북 & 인스타그램 채팅 위젯이란?

페이스북 채팅과 인스타그램 채팅은 하이퍼클래스 채팅 위젯(Chat Widget) 안에 있는 채널별 옵션이에요. 이 위젯 유형들은 웹사이트 자체 메신저 창을 여는 대신, 방문자를 선택한 메타 채널(메신저 또는 인스타그램 DM)로 연결해줘서 대화가 페이스북이나 인스타그램에서 자연스럽게 이어지도록 해줘요. 각 유형마다 올바른 페이스북 페이지 또는 인스타그램 비즈니스 계정을 선택(또는 연결)할 수 있는 전용 설정 패널이 빌더 안에 마련되어 있어요.

---

## 페이스북 & 인스타그램 채팅의 주요 장점

- 
원활한 참여: 방문자는 별도의 사이트 내 채팅 스레드를 만들 필요 없이 메신저나 인스타그램 DM에서 대화를 이어갈 수 있어요.


- 
채널 선호도: 고객이 평소 일상 메시지를 주고받는 소셜 플랫폼에서 만날 수 있어요.


- 
높은 채택률: 사용자가 이미 로그인되어 있는 페이스북/인스타그램 앱을 그대로 활용해요.


- 
통합 인박스(Inbox): 모든 메타 대화를 SMS, 이메일, 왓츠앱(WhatsApp)과 함께 하이퍼클래스 대화(Conversations) 인박스 안에서 한 번에 관리할 수 있어요.


- 
기기 간 연속성: 대화 내용이 사용자의 메신저/인스타그램 앱에 그대로 남기 때문에, 기기를 바꿔도 기록이 끊기지 않고 이어져요.

## **페이스북 & 인스타그램 채팅 위젯 설정 방법**

웹사이트에 설치할 수 있는 페이스북 또는 인스타그램 채팅 위젯을 빠르고 쉽게 만드는 방법을 알려드릴게요!

#### **1단계:** 새 위젯 만들기

**Sites(사이트)** → **Chat Widgets(채팅 위젯)**로 이동한 다음, 파란색 **+ New(새로 만들기)** 버튼을 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060348475/original/elOj_5dm-_s2o0sUdzfnGJj623Dq3ovuUw.png?1765388725)

#### 2단계: 채팅 유형 선택

"Select the type of chat(채팅 유형 선택)" 팝업에서 **Facebook Chat(페이스북 채팅)** 또는 **Instagram Chat(인스타그램 채팅)**을 선택하세요.

페이스북/인스타그램 계정이 연결되어 있지만 페이지가 선택되지 않은 경우, 위젯에서 사용할 페이지를 고를 수 있는 페이지 선택 창이 열려요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350088/original/yO7fZsVYCVXXsGVHatbDlcCq6bgQDfR5Vg.jpeg?1765390979)

**중요:** 해당 하위 계정(Sub-account)에 이미 연결된 계정이 없으면 여기서 페이스북 채팅이나 인스타그램 채팅을 선택할 수 없어요. 아직 연결된 계정이 없다면, 팝업 안의 링크가 계정 연결(예: Integration(연동) 메뉴 아래 Connect Facebook/Instagram)을 안내해줄 거예요. 이 링크를 열어 계정을 연결한 다음, 다시 이 선택 화면으로 돌아와 채팅 유형을 선택하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350092/original/jsVdwN__K5cjKScy1fhL_BpcM8DtY01HBQ.png?1765390994)

#### **3단계:** 위젯 커스터마이징

**Style(스타일)**, **Chat Window(채팅 창)**, **Messaging(메시지)** 탭에서 색상, 인사 문구, 런처 아이콘 등을 원하는 대로 설정해서 브랜드에 맞는 위젯을 만들어보세요. 추가 디자인 옵션은 [채팅 위젯 커스터마이징 개요](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000002960)를 참고해주세요.

**Chat Window(채팅 창)** 탭에서는 위젯에 연결된 페이스북/인스타그램 계정을 변경할 수 있어요. 필요한 경우 Connect a linked Facebook/Instagram account(연결된 페이스북/인스타그램 계정 연결하기) 버튼을 클릭하면 새 연결 창이 열리고, 추가 페이지/계정을 연결할 수 있어요.

필요한 편집을 모두 마쳤다면 위젯을 저장하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350150/original/hCpviuit3NtfBrynsJe5_HGgO4PThscLtA.png?1765391093)

#### **4단계:** 위젯 공유하기

외부 사이트에 이 위젯을 설치하려면 Get Code(코드 받기)를 클릭한 후, 위젯을 표시하고 싶은 웹사이트나 퍼널(Funnel)에 코드 스니펫을 삽입하세요. 워드프레스(Wordpress) 사이트에 설치하는 경우에는 Get it for Wordpress(워드프레스용 받기)를 클릭하세요. 이 위젯은 하이퍼클래스 퍼널 빌더와 웹사이트 빌더 안에서도 바로 설치할 수 있어요.

자세한 내용은 [하이퍼클래스 채팅 위젯 설치 방법](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/48000984860)을 참고해주세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060349629/original/tkuC8Q7A2ZfTxvzZkN4MegGTa8PChiaJaw.png?1765390165)

## **자주 묻는 질문**

**Q: 하나의 위젯에서 페이스북과 인스타그램을 동시에 활성화할 수 있나요?**

아니요. 위젯 하나당 하나의 채널만 연결할 수 있어요. 여러 채널을 하나의 버블로 통합하고 싶다면 올인원 채팅(All-in-One Chat) 위젯을 사용해주세요.

**Q: 대화 내용이 하이퍼클래스의 대화(Conversations) 탭에도 표시되나요?**

네, 페이스북/인스타그램 연동 및 권한이 올바르게 연결되어 있고 메시지 수신 권한이 활성화되어 있다면 표시돼요.

**Q: 수신된 메시지에 자동화를 적용할 수 있나요?**

물론이에요! Facebook Message(페이스북 메시지) 또는 Instagram Message(인스타그램 메시지) 워크플로우(Workflow) 트리거(Trigger)를 사용해서 태그 추가, 담당자 배정, 대화 라우팅 등을 할 수 있어요.

**Q: 방문자가 반드시 페이스북이나 인스타그램에 로그인되어 있어야 하나요?**

네. 로그인되어 있지 않으면 메타 로그인 화면이 먼저 나타나요.

**Q: 페이스북/인스타그램 위젯도 Style(스타일)과 Messaging(메시지) 설정이 다르게 작동하나요?**

아니요. 스타일과 배치 방식은 다른 채팅 유형과 동일하게 작동해요. 가장 큰 차이점은 대화가 **어디서** 이루어지는지(메타 앱 내부 vs 사이트 내부)예요.
