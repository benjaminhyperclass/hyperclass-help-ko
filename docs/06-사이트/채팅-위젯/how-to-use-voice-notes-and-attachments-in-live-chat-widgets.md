# 실시간 채팅 위젯에서 음성 메모와 첨부파일 사용하기

이제 실시간 채팅 위젯(Live Chat Widget)을 통해 웹사이트 방문자가 긴 메시지를 입력하지 않고도 상황을 쉽게 전달할 수 있어요. 방문자는 위젯에서 직접 파일, 이미지, PDF, 오디오 파일, 음성 메모를 보낼 수 있으며, 첨부파일만 보내는 것도 가능해요. 팀원들은 대화(Conversations)에서 이러한 메시지를 확인할 수 있고, 대화 AI(Conversation AI)를 활성화하면 지원되는 이미지와 음성 메모에 자동으로 응답할 수 있어요.

## **실시간 채팅 위젯의 음성 메모와 첨부파일이란?**

음성 메모와 첨부파일 기능을 사용하면 웹사이트 방문자가 하이퍼클래스의 실시간 채팅 위젯을 통해 일반 텍스트 이상의 정보를 전달할 수 있어요. 방문자는 지원되는 파일을 업로드하거나, 오디오 첨부파일을 보내거나, 위젯 안에서 직접 음성 메모를 녹음할 수 있어요. 이러한 메시지는 대화(Conversations) 메뉴에 표시되며, 담당자는 파일 유형에 따라 확인, 미리보기, 재생, 다운로드, 답장을 할 수 있어요.

실시간 채팅(Live Chat)은 웹사이트 메시지를 대화(Conversations)로 바로 전달하기 때문에, 방문자 메시지와 업로드된 파일, 음성 메모가 팀에서 이미 사용하고 있는 실시간 대화 관리용 인박스(Inbox)에 그대로 모여요.

## 실시간 채팅 위젯의 음성 메모와 첨부파일의 주요 장점

- 더 빠른 방문자 소통: 방문자가 긴 설명을 입력하는 대신 파일을 업로드하거나 오디오를 보내거나 음성 메모를 녹음할 수 있어요.

- 담당자를 위한 더 나은 맥락 파악: 스크린샷, PDF, 이미지, 음성 메모를 통해 담당자가 답장하기 전에 문제 상황을 더 잘 이해할 수 있어요.

- 첨부파일만 보내는 메시지: 방문자는 텍스트를 반드시 추가하지 않고도 파일이나 오디오만 보낼 수 있어요.

- 전송 전 오디오 미리듣기: 방문자는 녹음한 음성 메모를 제출하기 전에 미리 들어볼 수 있어요.

- 인라인 오디오 재생: 오디오 메시지는 재생, 일시정지, 탐색, 음소거, 처음부터 다시 재생, 재생 속도 조절이 가능한 재생형 오디오 카드로 표시돼요.

- 향상된 AI 워크플로우: 올바른 AI 응답 설정이 활성화되어 있으면 대화 AI가 지원되는 이미지와 음성 메모를 처리할 수 있어요.

- 더 깔끔한 위젯 제어: 하위 계정(Sub-account) 사용자는 실시간 채팅 위젯에 첨부파일 아이콘과 마이크 아이콘을 표시할지 선택할 수 있어요.

## **지원되는 메시지 유형, 파일 형식, 제한 사항**

지원되는 파일 규칙은 방문자 경험을 보호하고, 지원되지 않거나 용량이 너무 큰 파일이 위젯을 통해 전송되는 것을 방지해줘요. 아래 형식을 참고해서 방문자가 파일을 성공적으로 공유할 수 있도록 하고, 담당자가 대화(Conversations)에서 파일을 문제없이 열 수 있도록 하세요.

### 방문자가 할 수 있는 작업

방문자는 다음을 할 수 있어요:

- 실시간 채팅 위젯에서 음성 메모를 녹음하고 전송
- 지원되는 오디오 파일 업로드
- 지원되는 이미지 및 문서 파일 업로드
- 텍스트를 추가하지 않고 파일, 오디오, 음성 메모 전송
- 전송 전 오디오 미리듣기
- 파일 첨부 중 업로드 진행 상태 확인

### **지원되는 이미지 및 문서 파일 형식**

- .jpg
- .jpeg
- .png
- .heic
- .pdf

JPG와 PNG 파일은 인라인 미리보기로 표시되며, HEIC와 PDF 파일은 인라인 미리보기 대신 다운로드 가능한 파일명으로 표시될 수 있어요.

### **지원되는 오디오 동작**

음성 메모와 오디오 첨부파일은 위젯과 대화(Conversations)에서 재생형 오디오 카드로 표시돼요. 인라인 플레이어에는 다음이 포함돼요:

- 재생/일시정지
- 파형(Waveform)
- 탐색 컨트롤
- 음소거/음소거 해제
- 1배속, 1.5배속, 2배속 재생
- 처음부터 다시 재생

대화 AI 오디오 응답(Conversation AI Audio Response)은 음성 메모와 오디오 파일 입력을 지원해요. 기존 대화 AI 오디오 문서에는 OGG, MP3, MP4(오디오 전용), AAC, M4A, MPEG 등 지원되는 업로드 오디오 형식이 안내되어 있어요.

### **파일 제한 사항**

- 메시지당 최대 파일 수: 최대 5개
- 파일당 용량 제한: 최대 25MB
- 지원되지 않는 파일 형식, 용량이 너무 큰 파일, 중복 선택된 파일은 자동으로 차단될 수 있어요.

## **방문자 측에서 파일과 음성 메모 업로드하기**

방문자 측 업로드 흐름은 데스크톱과 모바일에서 모두 간단하게 이용할 수 있도록 설계되어 있어요. 방문자는 첨부파일 아이콘을 이용해 파일을 업로드하거나, 데스크톱에서는 파일을 위젯으로 드래그하거나, 마이크 아이콘을 이용해 음성 메모를 녹음할 수 있어요.

### 웹사이트에서 파일 업로드하기

- 웹사이트에서 실시간 채팅 위젯을 열어요.
- 첨부파일 아이콘을 클릭하거나 지원되는 파일을 채팅 입력창으로 드래그해요.
- 첨부할 파일을 하나 또는 여러 개 선택해요.
- 업로드 진행률 표시가 완료될 때까지 기다려요.
- 메시지를 전송해요.

방문자는 첨부파일만 있는 메시지를 보낼 수 있으므로, 지원되는 파일이나 오디오를 보낼 때 별도로 텍스트를 입력할 필요가 없어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072190231/original/E1qkHcvOXvFGOxOqHw1wFaJFeLb0V-fRaQ.gif?1779786142)

### 음성 메모 녹음하고 전송하기

- 실시간 채팅 위젯을 열어요. 마이크 아이콘을 클릭하거나 탭해요.
- 브라우저에서 권한을 요청하면 마이크 접근을 허용해요.
- 음성 메모를 녹음해요.
- 전송 전에 오디오를 미리 들어봐요.
- 음성 메모를 전송해요.

마이크 권한이 거부된 경우, 위젯에서 방문자가 문제를 해결할 수 있도록 안내하는 토스트 메시지가 표시돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072190058/original/uADDnmB4Qn-LTg4WDgollXfxJcvt246mbA.gif?1779786042)

## 실시간 채팅 위젯에서 음성 메모와 첨부파일 설정하는 방법

올바른 설정을 통해 방문자가 원하는 유형의 메시지를 보낼 수 있고, 팀에서 대화(Conversations)에서 이를 확인할 수 있어요. 실시간 채팅이 웹사이트에 설치되고 삽입되어 있어야 메시지가 대화(Conversations)로 전달되므로, 먼저 위젯이 활성화되어 있고 올바르게 설정되어 있으며 방문자가 이용할 수 있는 상태인지 확인하세요.

- `Sites(사이트) → Chat Widget(채팅 위젯)`으로 이동해요. 실시간 채팅 위젯을 새로 만들거나 기존 위젯을 열어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072187036/original/5N-9UKSbiLraJ5ROVt49eRvgxejkft5VRw.png?1779784514)

- `Chat Window(채팅 창) → Additional Options(추가 옵션)`으로 이동해요.

방문자가 음성 메모를 보낼 수 있도록 하려면 Allow sending voice notes(음성 메모 전송 허용) 옵션이 활성화되어 있는지 확인하세요.
방문자가 파일을 업로드할 수 있도록 하려면 Allow sending attachments(첨부파일 전송 허용) 옵션이 활성화되어 있는지 확인하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072187230/original/pNCtMfo5r2M4rgY-7dfCKpGZoemPJOTpTg.png?1779784611)

- 위젯을 저장해요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072187294/original/KLsDdK_nu7P3KWvUzpMwgOQAzCkTOoypUA.png?1779784647)

- 채팅 위젯 삽입 코드를 복사하여 웹사이트에 추가하거나, 페이지가 하이퍼클래스로 제작된 경우 웹사이트 또는 퍼널 설정에서 위젯을 활성화하여 위젯을 웹사이트에 삽입해요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072187414/original/0jCDMaRCNH6fJOM3Drq-7H069O98_iTSDw.png?1779784694)

- 방문자 입장에서 웹사이트를 열고 위젯을 테스트해요.

- 파일, 첨부파일만 있는 메시지, 음성 메모를 각각 전송해봐요.

- 각 메시지가 대화(Conversations)에 올바르게 표시되는지 확인해요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072187670/original/fvmQvus73shFXd1VHPbeA0gnYZlRV9EFeQ.png?1779784768)

## 대화에서 첨부파일과 음성 메모 확인하기

대화(Conversations)는 담당자가 방문자 메시지, 파일, 음성 메모를 한곳에서 확인할 수 있는 공간이에요. 실시간 채팅 메시지가 대화(Conversations)로 전달되기 때문에, 담당자는 다른 도구로 전환하지 않고도 방문자의 맥락을 파악할 수 있어요.

담당자는 대화 스레드에서 수신된 파일과 음성 메모를 확인할 수 있어요:

- JPG와 PNG 파일은 인라인 미리보기로 표시될 수 있어요.
- HEIC와 PDF 파일은 다운로드 가능한 파일명으로 표시될 수 있어요.
- 오디오 메시지는 원본 링크가 아닌 재생형 오디오 카드로 표시돼요.
- 담당자는 파일 유형에 따라 미리보기, 재생, 다운로드, 답장을 할 수 있어요.
- 메시지 옵션에서 지원하는 경우, 파일을 미디어 라이브러리(Media Library)에 저장하거나 연락처의 문서(Documents) 탭에 추가할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072190324/original/s0Hm9YkD9agyDQwitY7eaEuEGmBJdtWxPQ.png?1779786180)

## **대화 AI로 이미지와 음성 메모 처리하기**

AI 에이전트에 이미지와 음성 메모 응답 설정이 활성화되어 있으면 대화 AI가 더 풍부한 방문자 메시지에 응답할 수 있어요. 워크플로우에 맞게 봇이 이미지, 음성 메모, 또는 둘 다에 응답하도록 설정할 수 있어요. 이를 통해 봇이 단순히 입력된 텍스트에만 의존하지 않고, 방문자 메시지의 시각적/청각적 맥락을 활용할 수 있어요.

이미지, 음성 메모, 또는 둘 다에 대한 대화 AI 응답을 활성화하려면:

- `AI Agents(AI 에이전트) → Conversation AI(대화 AI) → Agent List(에이전트 목록)`로 이동해요.
- 설정하려는 봇 옆의 점 세 개(⋮) 아이콘을 클릭해요. Edit(편집)을 선택해요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072187992/original/ppDC17zkGlHcwvoZpmkm0F35AO3rB_qpIw.png?1779784984)

- **Bot Settings(봇 설정) → Also allow this bot to respond to(다음 항목에 대해서도 이 봇이 응답할 수 있도록 허용)** 아래에서 다음 중 하나 또는 둘 다 활성화해요:
- Images(이미지)
- Voice Notes(음성 메모)

- 변경 사항을 저장해요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072188234/original/htXnEaw0T3SmgaDYSC0OOTvhL82BYqwUvg.png?1779785109)

Images(이미지) 옵션이 활성화되면 대화 AI가 고객이 공유한 지원 이미지를 분석하고, 맥락에 맞는 메시지로 답변할 수 있어요. 현재 지원되는 이미지 형식은 JPG, JPEG, PNG예요. HEIC 파일은 실시간 채팅 첨부파일로 업로드될 수 있지만, AI 이미지 응답에서의 HEIC 지원은 제한적일 수 있어요.

Voice Notes(음성 메모) 옵션이 활성화되면 대화 AI가 음성 메모를 텍스트로 변환(전사)하고, 그 텍스트를 봇에 전달하여 맥락에 맞는 답변을 생성함으로써 지원되는 오디오를 처리할 수 있어요. 대화 AI의 음성 메모 처리 기능이 활성화되어 있으면 봇이 음성 메모를 자동으로 처리하고 답변할 수 있어요. 비활성화되어 있으면 설정된 대체(fallback) 메시지가 표시돼요.

참고: PDF 파일은 대화 AI의 이미지 응답 기능에서 지원되지 않아요.

## **음성 메모 및 첨부파일 문제 해결하기**

업로드 및 녹음 관련 문제를 해결하면 방문자가 채팅을 중단하지 않고 대화를 완료할 수 있어요. 대부분의 문제는 지원되지 않는 파일 형식, 큰 용량의 파일, 중복 첨부파일, 브라우저 권한, 느린 네트워크 연결로 인해 발생해요.

- 파일 용량이 너무 큼: 파일을 압축하거나 더 작은 버전을 선택하세요.

- 지원되지 않는 파일 형식: 업로드 전에 지원되는 형식으로 파일을 변환하세요.

- 중복 파일 경고가 표시됨: 중복된 파일을 제거하고 다른 파일을 첨부하세요.

- 업로드가 느림: 진행률 표시가 완료될 때까지 기다리거나 더 안정적인 네트워크에서 다시 시도하세요.

- 드래그 앤 드롭이 작동하지 않음: 컴퓨터의 파일 탐색기에서 파일을 드래그하거나, 대신 첨부파일 아이콘을 사용하세요.

- 마이크 권한이 거부됨: 브라우저 설정에서 마이크 접근을 허용한 후 다시 녹음을 시도하세요.
- AI가 이미지나 음성 메모에 응답하지 않음: 해당 AI 에이전트 설정에서 Images(이미지) 또는 Voice Notes(음성 메모) 옵션이 활성화되어 있는지 확인하세요.

## **자주 묻는 질문**

**Q: 방문자가 텍스트 없이 첨부파일만 보낼 수 있나요?**
네, 가능해요. 방문자는 실시간 채팅 위젯에서 첨부파일만 있는 메시지를 보낼 수 있어요.

**Q: 방문자가 실시간 채팅 위젯 안에서 음성 메모를 녹음할 수 있나요?**
네, 가능해요. Allow sending voice notes(음성 메모 전송 허용) 옵션이 활성화되어 있으면, 방문자는 위젯에서 직접 음성 메모를 녹음하고 미리 듣고 전송할 수 있어요.

**Q: 파일 업로드는 끄고 음성 메모는 그대로 켜둘 수 있나요?**
네, 가능해요. 첨부파일과 음성 메모 옵션은 별도로 제어되므로, 원하는 방문자 경험에 맞춰 각각 활성화하거나 비활성화할 수 있어요.

**Q: 방문자가 PDF 파일을 보낼 수 있나요?**
네, 가능해요. PDF는 실시간 채팅 첨부파일로 지원되지만, 인라인 미리보기 대신 다운로드 가능한 파일명으로 표시될 수 있어요.

**Q: 대화 AI가 실시간 채팅으로 전송된 PDF를 읽을 수 있나요?**
아니요, 불가능해요. 대화 AI의 이미지 응답 기능은 지원되는 이미지 형식에만 적용돼요. 현재 PDF는 AI 이미지 응답에서 지원되지 않아요.

**Q: 대화 AI가 음성 메모에 응답할 수 있나요?**
네, 봇에 음성 메모 응답 기능이 활성화되어 있으면 가능해요. 하이퍼클래스가 오디오를 텍스트로 변환하여 봇에 전달하므로 봇이 이를 바탕으로 응답할 수 있어요.

**Q: 봇이 오디오 메시지로 답장하나요?**
아니요. 대화 AI는 호환성을 위해 일반적으로 표준 채널 메시지, 주로 텍스트로 답장해요.

**Q: HEIC 파일이 인라인으로 미리보기되지 않는 이유는 무엇인가요?**
HEIC 파일은 실시간 채팅 첨부파일로 업로드될 수 있지만, 브라우저 지원 여부에 따라 인라인 미리보기가 되지 않을 수 있어요. 미리보기가 불가능한 경우 파일을 다운로드하여 로컬에서 열어보세요.
