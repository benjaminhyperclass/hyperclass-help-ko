# 임베드형 음성 AI 채팅 위젯 만들기

웹사이트나 퍼널(Funnel) 콘텐츠 안에 직접 음성 AI 채팅 위젯을 추가하면 더 자연스럽고 페이지에 어우러지는 대화 경험을 제공할 수 있어요. 하이퍼클래스의 임베드(Embedded)/인라인(Inline) 배치 방식을 사용하면 위젯이 표시되는 위치를 더 세밀하게 제어할 수 있어서 레이아웃, 브랜딩, 전환 흐름에 맞추기가 훨씬 쉬워져요. 이 방식은 위젯이 화면에 떠 있는 형태가 아니라 페이지의 일부처럼 느껴지길 원하는 비즈니스에 적합해요.

# 임베드형 음성 AI 위젯이란?

임베드형 음성 AI 채팅 위젯은 화면 모서리에 떠 있는 형태가 아니라 웹사이트나 퍼널 콘텐츠 안에 인라인(inline)으로 표시되는 음성 AI 위젯이에요. 랜딩 페이지, 리드 수집 페이지, 서비스 페이지, 오퍼(Offer) 섹션 등 주요 페이지에서 음성 AI를 어떻게 노출할지 더 유연하게 구성할 수 있어요.

기본값인 스티키(Sticky) 배치와 달리, 임베드/인라인 배치는 위젯이 페이지 레이아웃의 일부가 될 수 있게 해줘요. 이를 통해 더 매끄럽고 몰입감 있는 방문자 경험을 만들면서도 대화 흐름을 주변 콘텐츠와 자연스럽게 맞출 수 있어요.

---

## 임베드형 음성 AI 채팅 위젯의 주요 장점

임베드형 음성 AI 채팅 위젯은 방문자가 가장 많이 참여할 만한 위치에 대화를 배치함으로써 더 의도적인 페이지 경험을 만들 수 있게 도와줘요.

- 인라인 배치의 유연성: 떠 있는 채팅 버블에 의존하지 않고 페이지 섹션 안에 음성 AI 위젯을 직접 추가할 수 있어요.

- 더 자연스러운 사용자 경험: 대화가 별도의 오버레이가 아니라 웹사이트 콘텐츠의 일부처럼 느껴지게 만들어요.

- 더 정돈된 페이지 디자인 제어: 퍼널이나 웹사이트 레이아웃에 위젯을 맞춰서 더 브랜딩된 경험을 만들 수 있어요.
- 모바일 대응 경험: 임베드형 위젯은 기본적으로 모바일 방문자에게 반응형으로 표시돼요.

- 유연한 배포 옵션: 여러 개의 인라인 배치를 사용하거나, 같은 웹사이트/퍼널 안에서 임베드형과 스티키형 위젯을 함께 조합할 수 있어요.

---

## 임베드형 음성 AI 채팅이 가장 효과적인 곳

임베드형 음성 AI 채팅은 다음과 같은 곳에서 사용할 수 있어요:

- 퍼널(Funnels)

- 웹사이트(Websites)

- 랜딩 페이지

- 커스텀 HTML 사이트

- 채팅 위젯(Chat Widget) 설치가 지원되는 기타 페이지

임베드형 위젯은 기본적으로 모바일 반응형이기 때문에, 작은 화면에서도 자동으로 조정되면서 페이지 콘텐츠의 일부로 유지돼요.

## 임베드형 음성 AI 채팅 위젯 만드는 방법

올바르게 설정하면 위젯이 원하는 위치에 정확히 표시되고, 웹사이트나 퍼널 전반에서 일관되게 동작해요.

#### 1단계: 새 채팅 위젯 만들기

Sites(사이트) → Chat Widget(채팅 위젯) 메뉴로 이동한 후 **+ New**를 클릭하거나 기존 위젯을 여세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069727496/original/9bw1eW0iksbWHLRoSKoBswB3hp0xJ826tA.png?1776872089)

#### 2단계: 음성 AI 채팅 선택

Voice AI chat(음성 AI 채팅) 옵션을 선택하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069727655/original/qXH-6HMXpq7qBhhDIuOeaqC1wHFeQWdTZQ.png?1776872176)

#### 3단계: 위젯 배치를 임베드형으로 설정

- Style(스타일) 탭으로 이동하세요

- Widget Placement(위젯 배치) 항목에서 다음을 선택하세요: **Embedded / Inline (Renders inside content)**

이렇게 하면 위젯이 화면에 떠 있는 형태가 아니라 페이지 레이아웃 안에 표시돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069727741/original/dj154NLfaKUa1PpzcyWzC93kWDQtWUakPQ.png?1776872225)

#### 4단계: 위젯 커스터마이징

사용 가능한 스타일 옵션을 활용해서 위젯을 페이지 디자인에 맞게 조정하세요.

임베드형 음성 AI 위젯의 경우 다음 옵션들을 설정하세요:

1. Widget placement(위젯 배치) 항목에서 웹사이트에 음성 AI 위젯이 어떻게 표시될지 선택하세요:

- **Sticky:** 위젯을 페이지 모서리에 고정된 형태로 유지해요.
- **Embedded/Inline:** 위젯을 페이지 콘텐츠 안에 인라인으로 렌더링해요.

2. Embedded/Inline 위젯의 경우, Display Mode(표시 모드)를 설정하세요:

- **Avatar:** 정적인 시각적 표현을 보여줘요.
- **Visualiser:** 음성 기반의 동적인 시각적 신호를 보여줘요. Visualiser를 선택하면 Interface Size(인터페이스 크기): Small, Medium, Large 중 하나를 선택할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073729673/original/fQIvJqTTLwP5jMpWgi3CcgP0Ik1btvj9kw.gif?1781585870)

3. Chat Window(채팅 창) 탭에서 Button Text(버튼 텍스트)를 편집하세요. 이 텍스트는 인라인 레이아웃에서 아바타 아래에 표시돼요.

- 예시: "Call us here"를 "Talk to our AI" 또는 "Ask a Question"으로 변경하세요.

선택적으로 **Additional Options(추가 옵션)**을 열어서 비즈니스 이름이나 컴플라이언스 푸터 같은 브랜딩 요소를 조정할 수 있어요. 오른쪽 미리보기 화면이 실시간으로 업데이트되면서 임베드형 위젯 디자인을 보여줘요.

[채팅 위젯 커스터마이징에 대한 자세한 내용은 여기를 클릭하세요.](https://help.gohighlevel.com/en/support/solutions/articles/155000002960)

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073729682/original/QiZHVS1JXICxmOh_YgywBlIgO1QqePWucg.png?1781585894)

#### 5단계: 임베드 코드 생성

위젯이 원하는 대로 완성되면 오른콽 상단의 **Get Code(코드 받기)** 버튼을 클릭하세요. 고유한 임베드 코드 스니펫이 담긴 팝업 창이 나타나요. **Copy(복사)**를 클릭해서 클립보드에 저장하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818713/original/G_qn00fF8x7AfFOKqFHJOrz-YSSQH_AIEw.png?1762513569)

#### 6단계: 웹사이트 또는 퍼널에 위젯 임베드하기

Code(코드) 블록 요소(Element)를 사용하면 사이트나 퍼널의 원하는 곳 어디에나 위젯을 배치할 수 있어요.

퍼널에 임베드하려면:

- **Sites(사이트)** > **Funnels(퍼널)**로 이동해서 위젯을 추가하려는 퍼널 페이지를 여세요.

- **Edit Page(페이지 편집)**를 클릭하세요.

- 왼쪽 사이드바에서 Quick Add(빠른 추가) > Custom(커스텀) 항목에서 "**Code**"를 검색하고 **Code** 요소를 페이지에 드래그하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818772/original/sNKOu6GEeWooDycr2qTZDfJw3YQozJHCyw.png?1762513600)

- **Open Code Editor(코드 편집기 열기)**를 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818893/original/kr_T4sKxXSt9dgrUjDi9a4BaHUDnT4_j0w.png?1762513635)

- 채팅 위젯 빌더에서 복사한 임베드 코드를 붙여넣으세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818964/original/9ZvyZF_rvhmfWvpc282yCc28pFdaQ7NzXg.png?1762513656)

- **Save(저장)**를 클릭한 후 페이지를 **Publish(발행)**하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818975/original/Y-Xg-ZENYtVB9JyQ4MCGgctMv8wyNEHKcQ.png?1762513671)

발행이 완료되면 음성 AI 위젯이 다른 콘텐츠 블록과 마찬가지로 인라인으로 임베드되어 표시돼요.

## 주요 동작 참고사항

- 임베드형 위젯은 완전히 모바일 반응형이며, 작은 화면에서 자동으로 크기가 조정돼요.

- **Embedded/Inline** 모드에서는 일부 커스터마이징 옵션이 비활성화되어 있어요. 이는 떠 있는 형태의 위젯에만 적용되는 옵션이기 때문이에요. 예를 들어 위젯 위치 설정이나 문의 양식(Contact Form) 토글 설정 등이 해당돼요.

- Display Mode(표시 모드) 옵션은 현재 음성 AI 경험에 최적화되어 있어요.

- 같은 사이트나 퍼널 안에 여러 개의 임베드형 위젯을 배치할 수 있으며, 모두 동일한 음성 AI 에이전트에 연결돼요.

- 서로 다른 섹션에 임베드형과 스티키형 위젯을 혼합해서 사용하면 참여도를 최대화할 수 있어요.

## 모범 사례

위젯을 적절한 위치에 배치하면 페이지 경험을 방해하지 않으면서 전환을 지원할 수 있어요. 목표는 채팅이 방해가 아니라 도움이 되고 시기적절하게 느껴지도록 만드는 것이에요.

- 폼, 오퍼, 예약 영역, 지원 안내처럼 구매 의도가 높은 콘텐츠 근처에 위젯을 배치하세요.

- 페이지와 위젯 브랜딩을 맞춰서 더 자연스러운 느낌을 주세요.

- 좁은 섹션 안에서 위젯이 답답해 보이지 않도록 간격과 정렬을 테스트하세요.

- 발행 후 모바일 레이아웃을 검토해서 가독성과 간격을 확인하세요.

- 인트로 메시지와 응답 메시지는 명확하고 행동 유도적으로 작성하세요.

## 자주 묻는 질문

**Q: 페이지에서 임베드형 위젯을 어디에 배치해야 하나요?**
히어로 섹션, 오퍼 섹션, 리드 수집 영역, 서비스 페이지 등 방문자의 참여 가능성이 높은 영역이 좋은 배치 위치예요.

**Q: Embedded/Inline을 선택했더니 일부 커스터마이징 설정이 사라졌어요. 왜 그런가요?**
일부 컨트롤은 떠 있는 형태의 위젯에만 적용되기 때문에 자동으로 숨겨져요. Embedded/Inline 모드에서는 하이퍼클래스가 인라인 배치와 관련된 설정만 표시해줘요.

**Q: 라이브 채팅(Live Chat) 위젯에도 Embedded/Inline 배치를 사용할 수 있나요?**
네, 라이브 채팅에서도 임베드/인라인이 지원돼요. 자세한 내용은 [여기를 클릭하세요.](https://help.gohighlevel.com/en/support/solutions/articles/155000007601)

**Q: 어떤 채팅 위젯 유형이 Embedded/Inline 배치를 지원하나요?**

Embedded/Inline 배치는 올인원 채팅(All-in-One Chat), 이메일/SMS, 왓츠앱(WhatsApp), 페이스북(Facebook), 인스타그램(Instagram), 라이브 채팅(Live Chat), 음성 AI(Voice AI)에서 사용할 수 있어요.
