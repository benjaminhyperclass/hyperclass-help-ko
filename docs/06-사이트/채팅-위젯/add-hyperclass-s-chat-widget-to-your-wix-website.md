# Wix 웹사이트에 하이퍼클래스 채팅 위젯 추가하기

하이퍼클래스 채팅 위젯 코드를 Wix 웹사이트에 붙여 넣으면 방문자와 바로 대화할 수 있어요. 이 문서에서는 코드를 가져오는 방법과, Wix에 코드를 넣는 두 가지 방법을 안내해요.

## 웹사이트용 채팅 임베드 코드 가져오기

**사이트 > 채팅 위젯 > 코드 가져오기**에서 임베드 코드를 복사하세요.

![채팅 위젯 임베드 코드를 복사하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297599341/original/Xz6_1VYAkpYxA8I4zFVvELcqJXZwruPKpA.gif?1684168613)

## Wix 웹사이트에 채팅 위젯 추가하기

## 방법 1: 사용자 지정 코드로 추가하기

1. Wix 계정에 로그인한 다음, 웹사이트 대시보드로 이동하세요.
2. 왼쪽 메뉴에서 **설정**을 클릭하고, **고급** 탭의 **Custom Code**(사용자 지정 코드)를 선택하세요.

   ![Wix 설정의 고급 탭에서 Custom Code를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297317762/original/afvuactXKgGh8MrZioPfgp44yPZvZ9dVMQ.jpeg?1683921093)

3. 해당 섹션에서 **Add Custom Code**(사용자 지정 코드 추가)를 클릭하세요.
4. 팝업 창의 **Code Settings**(코드 설정)에 복사한 코드를 붙여 넣으세요.
5. 아래 옵션을 설정하세요.
   - **이름**: 코드를 구분할 이름을 입력하세요.
   - **Add Code to Pages**(코드를 추가할 페이지): **모든 페이지**를 선택하고, **Load code once**(코드 한 번만 로드)를 선택하세요.
   - **Place Code In**(코드 위치): **Head**(헤드)를 선택하세요.
6. **적용**을 클릭해 저장하세요.

   ![코드 설정 옵션을 입력하고 적용을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297317756/original/w4V_CFuVKnEFUt7QitNud1aLOySbUz5emQ.png?1683921092)

이제 Wix 사이트의 모든 페이지에 채팅 위젯이 나타나요.

## 방법 2: HTML 임베드로 추가하기

1. Wix 계정에 로그인하고 Wix Editor를 실행하세요. 대시보드에서 **Edit Site**(사이트 편집)를 클릭하면 돼요.

   ![Wix 대시보드에서 Edit Site를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297317759/original/9B-EBPNVDe9gBv25cEYvyoVTLUMwuVXzNQ.jpeg?1683921093)

2. 왼쪽 메뉴의 더하기(+) 아이콘을 클릭해 **요소 추가**를 여세요.
3. 왼쪽 사이드바 메뉴에서 **임베드**를 선택하세요.
4. **Popular Embeds**(인기 임베드)에서 **Embed HTML**(HTML 임베드)을 선택하세요.

   ![Popular Embeds에서 Embed HTML을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297317761/original/If6mts5CUAfyzOaTOstmGhmjsYsATMm4MA.jpeg?1683921093)

5. 새로 나타난 HTML 상자에서 **코드**를 클릭하세요.
6. 입력란에 위젯 코드를 붙여 넣고 **업데이트**를 누르세요.

   ![HTML 상자의 입력란에 위젯 코드를 붙여 넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297317760/original/KLsgOAnNolAWPwLltKgtg67R88vUyXUHug.jpeg?1683921093)

7. **HTML Settings**(HTML 설정) 상자를 닫으세요.

이제 페이지의 HTML 상자 안에 채팅 위젯이 보여요.
