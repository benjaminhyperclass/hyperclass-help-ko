# 실시간 채팅 시작 전에 방문자 정보 수집하기

방문자가 실시간 채팅을 시작하기 전에 이름, 이메일, 전화번호 같은 연락처 정보를 받는 방법을 설명해요. 정보를 먼저 받아 두면 연락처 데이터가 더 정확해지고, 누구인지 모르는 채팅이 줄어요. 자동화와 후속 연락에도 쓸 수 있어요.

## 채팅 위젯의 문의 폼이란?

문의 폼은 실시간 채팅 위젯 안에 나타나는 채팅 전 안내 폼이에요. 문의 폼을 켜 두면 방문자는 폼을 제출해 연락처 세부정보를 남겨야 메시지 입력창을 쓸 수 있어요. 그래서 누구와 대화하는지 항상 알 수 있고, 대화가 끝난 뒤에도 후속 연락을 할 수 있어요.

## 문의 폼의 주요 장점

- 리드 확보: 모든 대화가 연락처 기록과 연결돼요. 누구인지 모르는 채팅이 사라져요.
- 빠른 후속 연락: 미리 받은 연락처 세부정보로 팀이나 자동화가 바로 후속 연락을 할 수 있어요.
- 재방문자 재입장: 진행 중인 채팅이 있는 재방문자는 폼을 건너뛰고 바로 대화를 이어가요. 이전 채팅이 삭제됐거나 종료됐다면 폼이 다시 나타나요.
- 안정적인 세션 유지: 페이지를 새로고침해도 자동으로 다시 연결되어 메시지 기록이 그대로 남아요.
- 깔끔한 CRM 데이터: 입력 방식이 일정해서 미완성 대화가 줄고 리포트의 정확도가 높아져요.

## 문의 폼 켜고 끄기

문의 폼 설정은 간단해요. 채팅을 시작하기 전에 어떤 정보를 받을지 직접 정할 수 있어요.

1. 서브 계정에서 **사이트 > 채팅 위젯**으로 이동하세요.
2. 설정할 채팅 위젯을 선택하세요.

   ![채팅 위젯 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052322845/original/igS2WIw7f0gHGx7-zXEQV8Ha1St1krq_CA.gif?1756139281)
3. **채팅 창** 탭으로 이동하세요.
4. **실시간 채팅 배정됨** 드롭다운을 여세요.
5. **문의 폼 활성화** 토글을 **켜짐**으로 바꾸세요.

   ![문의 폼 활성화 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052323082/original/CWICw4jTrOLySuLP4GUiDk28OEcniCYsyg.png?1756139368)
6. **저장**을 클릭해 변경 사항을 게시하세요.

   ![저장 버튼 클릭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052364828/original/NOE6MAboLd1IjlMpdKWvSURLRUl6iC1_tg.png?1756199779)

{% hint style="info" %}
폼을 끄려면 **문의 폼 활성화** 토글을 끄세요. 문의 폼이 꺼져 있으면 채팅 위젯이 연락처 정보를 먼저 묻지 않고 바로 채팅을 시작해요.
{% endhint %}

## 문의 폼 메시지 사용자 지정

채팅 위젯에 표시되는 "연락처 세부정보를 남겨 주세요" 안내 문구를 바꿀 수 있어요. 수정할 수 있는 메시지 필드는 두 가지이고, 연락처 정보를 언제, 어떻게 요청할지 정할 수 있어요. 이 설정은 실시간 채팅과 올인원(실시간) 채팅에만 적용돼요.

### 문의 폼 소개 메시지 (자동 안내)

**문의 폼 활성화**가 **켜짐**이면 문의 폼 바로 앞에 이 메시지가 자동으로 나타나요. 기본 문구는 "Please share your contact details."예요. 이 필드를 비워 두면 안내 문구 없이 폼이 바로 표시돼요.

이 메시지를 수정하려면 **채팅 창** 탭으로 이동해서 **문의 폼 소개 메시지** 필드의 문구를 바꾸세요.

{% hint style="info" %}
이 필드는 **문의 폼 활성화** 토글이 **켜짐**일 때만 빌더에 보여요.
{% endhint %}

![문의 폼 소개 메시지 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063194537/original/Sxv7wpge8cPd4bTY_DPmTePb55nrBn_kvA.png?1769021670)

### 문의 폼 시스템 메시지 (상담원이 요청할 때)

상담원이 **대화**에서 **Request Contact Details**(연락처 세부정보 요청)를 클릭하면 이 메시지가 표시돼요. **문의 폼 소개 메시지**가 이미 나타난 뒤에도 상담원은 이 메시지를 보낼 수 있어요.

![상담원이 연락처 세부정보를 요청하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063195294/original/m-R2DxtIkhj8mEqWNqHBAbneN5vhiflH5Q.png?1769022987)

이 메시지를 수정하려면 **채팅 창** 탭으로 이동해서 **문의 폼 시스템 메시지** 필드의 문구를 바꾸세요.

기본 문구는 "Please share your contact details."예요. 이 필드를 비워 두면 안내 문구 없이 폼이 바로 열려요.

{% hint style="info" %}
이 필드는 **문의 폼 활성화** 토글이 켜져 있든 꺼져 있든 빌더에 보여요.
{% endhint %}

![문의 폼 시스템 메시지 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063195342/original/7pZ-nnXSrZJ05Ib1ONHH7uYRHbcvvvWbBg.png?1769023036)

{% hint style="info" %}
위젯에 **알림 소리**를 켜 두면, 연락처 세부정보 요청 메시지가 나타날 때(문의 폼이 표시될 때) 방문자에게 소리가 들릴 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 문의 폼에서 어떤 필드를 필수로 지정할 수 있나요?
이름은 필수예요. 연락처를 만들려면 전화번호나 이메일 중 하나 이상이 필요해요. 지원되는 연락처 커스텀 필드도 추가할 수 있고, 이름을 포함해 전체 필드는 5개까지예요. 위젯 빌더에서 커스텀 필드를 필수로 지정하면, 방문자는 그 항목을 모두 입력해야 폼을 제출할 수 있어요.

### 재입장 때 "진행 중인 채팅"은 정확히 어떤 채팅인가요?
직접 종료하지 않았고 비활성 시간이 지나 만료되지도 않은 세션이에요. 아직 진행 중이면 방문자는 폼을 다시 작성하지 않고 대화를 이어가요.

### 채팅 도중 방문자가 페이지를 새로고침하면 어떻게 되나요?
위젯이 자동으로 다시 연결되고 대화가 그대로 유지돼요. 사라지는 메시지는 없어요.

### 문의 폼 필수 설정은 모든 위젯에 적용되나요, 아니면 하나에만 적용되나요?
설정한 위젯 하나에만 적용돼요. 토글을 켜기 전에 올바른 위젯을 선택했는지 꼭 확인하세요.

### 영업시간 설정과는 어떻게 함께 동작하나요?
영업시간이 아닐 때는 위젯이 연락처 세부정보 폼을 보내요. 방문자가 폼을 제출하면 채팅은 자동으로 종료돼요.

### 문의 폼 제출을 기준으로 워크플로우를 실행할 수 있나요?
네. **Customer Replied**(고객 답장) 같은 트리거로 자동 후속 연락이나 작업 배정을 시작할 수 있어요.

### 개인정보를 수집할 때 개인정보처리방침 링크를 추가해야 하나요?
추가하는 것을 권장해요. 채팅 창의 텍스트나 설명에 **개인정보처리방침** 링크를 넣으면 규정 준수 측면에서 투명하게 안내할 수 있어요.

### 사이트에 채팅 위젯이 여러 개예요. 위젯마다 폼 규칙이 따로 적용되나요?
네. 위젯마다 설정이 따로 있어서, 어떤 위젯이나 페이지에는 폼을 적용하고 다른 곳에는 적용하지 않을 수 있어요.
