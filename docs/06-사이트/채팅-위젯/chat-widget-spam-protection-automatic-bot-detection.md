# 채팅 위젯 스팸 방지 — 자동 봇 감지

**채팅 위젯** 폼으로 들어오는 스팸·봇 제출을 자동으로 찾아 태그를 붙이는 기능이에요. CAPTCHA를 넣지 않고, 실제 방문자를 기다리게 하지도 않아요.

채팅 위젯 폼에는 가짜 제출이나 봇이 만든 제출이 많이 들어올 수 있어요. 이런 제출은 메시지 발송 비용을 낭비하게 하고 발신자 평판도 떨어뜨려요. **스팸 방지**를 켜면 의심스러운 리드에 자동으로 표시하고, 해당 연락처로 나가는 메시지를 멈추고, 검토용 태그를 붙여요. 정상 방문자는 아무 차이도 느끼지 못해요.

이 문서에서는 기능이 어떻게 동작하는지, 채팅 위젯에서 어떻게 켜는지, 표시된 리드를 어떻게 검토하는지 안내해요.

## 채팅 위젯 스팸 방지란?

채팅 위젯 스팸 방지는 봇이나 스팸처럼 보이는 제출을 자동으로 찾아 태그를 붙여요. 리드가 의심스럽다고 판단되면 하이퍼클래스는 선택한 채널의 발신 메시지를 멈춰요. 그러면 SMS 크레딧이 낭비되지 않고 이메일 발신자 평판도 지킬 수 있어요. 연락처 기록은 그대로 만들어지고, 검토할 수 있도록 태그가 붙어요.

이 기능은 서버에서 동작해요. CAPTCHA나 추가 입력란을 넣지 않고, 눈에 띄는 지연도 없어요. 정상 방문자가 보는 채팅 위젯 폼은 달라지지 않아요.

의심스러운 리드는 **연락처** 목록에 `chat_widget_high_volume_flag` 태그가 붙은 채로 들어와요. 표시된 연락처를 검토하고, 정상 리드는 한 번의 클릭으로 복원하고, 스팸으로 확인된 연락처는 삭제할 수 있어요. 최종 판단은 직접 해요.
## 주요 이점

스팸 방지는 전환 퍼널을 방해하거나, 검토가 필요한 리드를 버리지 않고도 봇을 자동으로 감지해요.

- 방문자에게 불편 없음: CAPTCHA도, 추가 입력란도, 추가 대기 시간도 없어요. 방문자는 전과 똑같이 빠르고 간단한 채팅 위젯을 써요.
- 의심스러운 리드도 보관: 표시된 연락처는 삭제되지 않고 만들어진 뒤 태그만 붙어요. 애매한 경우에도 실제 고객을 놓치지 않아요. 마지막 판단은 직접 해요.
- 발신자 평판 보호: 일시중지된 채널로는 표시된 리드에게 발신 메시지가 나가지 않아요. 정상 캠페인의 전달률을 떨어뜨리는 반송이 계정에 쌓이지 않아요.
- 위젯별 설정: 채팅 위젯마다 따로 설정해요. 태그만, SMS 일시중지, 이메일 일시중지, 둘 다 일시중지 중에서 고를 수 있어요.
- 정확하고 되돌릴 수 있음: 선택한 채널만 일시중지돼요. 통화, 수신 메시지, 그 밖의 수신거부 설정은 그대로예요. 연락처는 한 번에 복원할 수 있어요.
- 명확한 기록: 활동 로그에 "DnD enabled by chat widget spam protection"(채팅 위젯 스팸 방지로 수신거부 활성화)이라는 기록과 함께 일시중지된 채널 이름이 표시돼요. 메시지가 왜 나가지 않았는지 알 수 있어요.

## 보호 옵션

표시된 리드를 어떻게 처리할지 네 가지 옵션 중에서 골라요. 필요한 보호 수준과 감수할 수 있는 위험에 맞게 선택하세요.

### 옵션 1. 검토용으로만 태그됨

표시된 리드에 `chat_widget_high_volume_flag` 태그만 붙고, 메시지는 멈추지 않아요. 발신 메시지는 막지 않고 의심스러운 제출만 확인하고 싶을 때 쓰세요.

### 옵션 2. 태그 추가됨 + SMS 발송 일시중지됨

표시된 리드에 태그가 붙고 SMS 발송이 멈춰요. 이메일은 계속 보낼 수 있어요. SMS 비용은 지키면서 이메일 후속 연락은 이어 가고 싶을 때 알맞아요.

### 옵션 3. 태그 지정됨 + 이메일 발송 일시중지됨

표시된 리드에 태그가 붙고 이메일 발송이 멈춰요. SMS는 계속 보낼 수 있어요. 이메일 발신자 평판은 지키면서 SMS 연락은 이어 가고 싶을 때 쓰세요.

### 옵션 4. Pause Both(둘 다 일시중지)

표시된 리드에 태그가 붙고 SMS와 이메일 발송이 모두 멈춰요. 새로 만드는 채팅 위젯의 기본 설정이고, 가장 폭넓게 보호해 줘요.

{% hint style="info" %}
통화, 수신 메시지, 그 밖의 수신거부 설정은 스팸 방지의 영향을 받지 않아요. 표시된 연락처에서 선택한 발신 채널만 일시중지돼요.
{% endhint %}

## 스팸 방지 켜는 방법

스팸 방지는 채팅 위젯마다 따로 설정해요. 아래 순서대로 기존 위젯에서 켜거나, 새 위젯의 기본 설정을 확인하세요.

1. **사이트 > 채팅 위젯**으로 이동해요.
2. 설정할 위젯을 선택해 채팅 위젯 빌더를 열어요.

   ![채팅 위젯 빌더 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080611354/original/kHVBwLAhBBGXgANtjrNy15cyAHoCYMBEPg.jpeg?1789047621)

3. 빌더 사이드바에서 **스팸 방지** 섹션을 찾아 펼쳐요.

   ![스팸 방지 섹션 펼치기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080611691/original/OcuEUZJ3cJBr5zIQC3ZG9RKZI2UAkPv8rQ.png?1789047763)

4. **스팸 방지 켜기** 토글을 켜요. 기존 위젯은 기본적으로 꺼져 있고, 새 위젯은 기본적으로 켜져 있어요.

   ![스팸 방지 켜기 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080611793/original/9xn1sJioGlrjNVlBOs2Acw073pdroOUQmw.png?1789047800)

5. 네 가지 옵션 중 하나를 선택해요.

   ![보호 수준 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080611841/original/dJbtYj-SB3p4WVU9T-PIqe9QNEI1IIfB2A.png?1789047841)

6. **저장**을 클릭해 변경 사항을 적용해요. 저장한 뒤에 들어오는 제출부터 바로 보호가 적용돼요.

{% hint style="info" %}
빌더에서 새로 만든 채팅 위젯은 스팸 방지가 기본으로 켜져 있고 Pause Both(둘 다 일시중지)가 선택돼 있어요. 기존 위젯은 직접 켜기 전까지 꺼진 상태로 유지돼요.
{% endhint %}

## 표시된 리드 검토하기

표시된 연락처는 **연락처** 목록에 `chat_widget_high_volume_flag` 태그가 붙어서 나타나요. 실수로 표시된 정상 리드를 찾아 메시지 발송 권한을 되돌릴 수 있도록 주기적으로 검토하세요.

1. **연락처**로 이동해 `chat_widget_high_volume_flag` 태그로 필터링해요. 표시된 제출이 모두 보여요.

   ![태그로 연락처 필터링](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080613182/original/Qw6YfBfVDBeUxfdRZbRYttb3nGVa5akbhw.png?1789048352)

2. 연락처를 하나씩 열어 제출 내용을 확인해요. 활동 로그에서 "DnD enabled by chat widget spam protection" 기록을 찾으면 어떤 채널이 일시중지됐는지 알 수 있어요.
3. 정상 연락처라면 일시중지된 채널의 수신거부 설정을 직접 해제하고 `chat_widget_high_volume_flag` 태그를 제거해요. 발신 메시지는 바로 다시 나가요.
4. 스팸으로 확인된 연락처는 여러 개를 한꺼번에 선택해 삭제해요. 연락처 목록이 깨끗해지고, 잘못된 주소로 실수로 연락하는 일도 막을 수 있어요.

{% hint style="info" %}
표시된 연락처는 매주 또는 캠페인이 끝난 뒤처럼 정기적으로 검토하세요. 정상 리드가 오래되기 전에 복원할 수 있어요.
{% endhint %}

## 정상적인 제출 급증 관리하기

제품 출시, 유료 광고 캠페인, 행사, 언론 보도 때문에 채팅 위젯 제출이 갑자기 늘 수 있어요. 자동 감지 입장에서는 이런 급증이 스팸 공세와 비슷해 보일 수 있어요. 이런 기간에는 정상 리드에 태그가 붙지 않도록 스팸 방지를 잠시 꺼 두세요.

제출이 몰리는 행사 전후로 보호를 끄고 다시 켜는 방법이에요.

1. 캠페인이나 행사가 시작되기 전에 **사이트 > 채팅 위젯**으로 이동해 위젯을 열고 **스팸 방지 켜기** 토글을 꺼요.
2. 행사가 끝나고 제출량이 평소 수준으로 돌아오면 **스팸 방지 켜기** 토글을 다시 켜고 보호 설정을 원래대로 복원해요.

{% hint style="info" %}
정상적인 급증 기간에 보호를 끄는 것을 깜빡했다면, 행사가 끝난 뒤 표시된 연락처를 검토해서 일시중지된 정상 리드를 복원하세요.
{% endhint %}

## 자주 묻는 질문

### 스팸 방지를 켜면 채팅 위젯에 CAPTCHA나 입력란이 추가되나요?

아니요. 스팸 방지는 서버에서 동작하고 방문자가 보는 폼은 바꾸지 않아요. 정상 방문자는 CAPTCHA도, 추가 단계도, 눈에 띄는 지연도 겪지 않아요.

### 표시된 리드는 자동으로 삭제되나요?

아니요. 표시된 연락처는 계정에 만들어지고 `chat_widget_high_volume_flag` 태그가 붙어요. 선택한 채널의 발신 메시지는 일시중지되지만, 리드는 그대로 남아 있어서 직접 검토하고 정상이면 복원할 수 있어요.

### 정상 연락처가 표시됐다면 복원할 수 있나요?

네. 연락처 기록을 열어 일시중지된 채널의 수신거부 설정을 해제하고 `chat_widget_high_volume_flag` 태그를 삭제하세요. 발신 메시지가 바로 다시 나가요.

### 스팸 방지가 기존 리드나 워크플로우에도 영향을 주나요?

아니요. 스팸 방지는 켠 뒤에 들어오는 새 제출에만 적용돼요. 기존 연락처와 실행 중인 워크플로우는 영향을 받지 않아요. 기존 채팅 위젯은 기본적으로 꺼져 있으니 직접 켜야 해요.

### 표시된 연락처의 수신 통화와 메시지는 어떻게 되나요?

아무 영향이 없어요. 스팸 방지는 선택한 채널(SMS, 이메일 또는 둘 다)의 발신 메시지만 일시중지해요. 수신 통화, 문자 답장, 그 밖의 연락처 상호작용은 평소처럼 동작해요.

### 표시된 연락처에서 어떤 채널이 일시중지됐는지 어떻게 알 수 있나요?

연락처 기록을 열어 활동 로그를 확인하세요. "DnD enabled by chat widget spam protection" 기록과 함께 일시중지된 채널(SMS, 이메일 또는 둘 다)이 표시돼요.

### 스팸 방지를 켜면 폼 전환율이 떨어지나요?

아니요. 이 기능은 서버에서 동작하고 눈에 보이는 불편을 만들지 않아서 방문자 경험에 영향을 주지 않아요. 정상 방문자는 보호를 켜기 전과 똑같이 폼을 작성해요.

### 여러 채팅 위젯에 스팸 방지를 쓸 수 있나요?

네. 보호 설정은 채팅 위젯마다 따로 해요. 일부 위젯에서만 켜고 나머지는 꺼 둘 수도 있어요. 위젯의 용도에 맞춰 위젯마다 다른 보호 수준(태그만, SMS 일시중지, 이메일 일시중지, 둘 다 일시중지)을 적용할 수도 있어요.
