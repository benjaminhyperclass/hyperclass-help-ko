# 블로그 분석이란?

블로그 분석은 하이퍼클래스 내에서 블로그와 게시물의 핵심 성과 지표를 한곳에 모아 보여주는 분석 기능이에요. 페이지 조회수, 클릭, 기기 사용 현황 등의 데이터를 수집해서 독자의 행동 패턴을 이해하고, 참여도를 극대화할 수 있도록 콘텐츠 전략을 개선하는 데 도움을 줘요.

## 블로그 분석의 주요 장점

블로그 분석은 콘텐츠 제작자와 마케터가 정보에 기반한 데이터 중심 의사결정을 내릴 수 있도록 다양한 이점을 제공해요:

- **한눈에 파악**: 상위 레벨 지표로 전체 블로그 성과를 빠르게 확인할 수 있어요.
- **성공 패턴 반복**: 성과가 좋은 게시물을 파악해서 성공을 재현할 수 있어요.
- **독자 이해**: 기기 및 카테고리 인사이트를 통해 독자 행동을 이해할 수 있어요.
- **참여도 확인**: 링크 클릭 활동을 모니터링해서 관심도를 가늠할 수 있어요.
- **콘텐츠 소스 비교**: 가져온 게시물과 직접 작성한 콘텐츠의 성과 차이를 구분할 수 있어요.

## 블로그 분석 찾고 활용하는 방법

**참고**: 데이터는 2024년 8월 28일부터 수집되었어요. 이 날짜 이전의 데이터는 "알 수 없음(Unknown)"으로 표시돼요.

- 하위 계정(Sub-account)에 로그인하세요.
- Sites(사이트) 탭을 클릭하세요.
- Analytics(분석) 탭을 클릭하세요.
- 카테고리 선택 드롭다운을 클릭하고 Blogs(블로그)를 선택하세요.
- 대시보드가 로드될 때까지 기다리면, 블로그 성과 지표가 표시돼요.

- 날짜 범위 선택기와 블로그 사이트 선택기를 활용해서 원하는 데이터 뷰로 맞춤 설정할 수 있어요.
- 각 하위 섹션(예: 빠른 성과 개요, 시간별 트렌드)을 확인해서 블로그 활동에 대한 자세한 인사이트를 얻어보세요.

## 빠른 성과 개요

빠른 성과 개요(Quick Performance Overview)는 블로그의 핵심 성과 지표를 상위 레벨에서 보여주는 요약 정보예요. 전체 페이지 조회수, 발행된 블로그 사이트 수, 전체 발행 게시물 수를 강조해서 블로그의 전반적인 상태를 빠르고 쉽게 파악할 수 있도록 도와줘요.

- 전체 페이지 조회수를 즉시 표시
- 발행된 블로그 사이트 수 집계
- 발행된 게시물 수 집계

![](https://jumpshare.com/share/5utcidcI7TheXSFw34d8+/Screen+Shot+2025-09-03+at+8.00.49+PM.png)

## 시간별 트렌드

시간별 트렌드(Trends Over Time)를 통해 선택한 날짜 범위에서 페이지 조회수가 어떻게 변화하는지 모니터링할 수 있어요. 직관적인 인터랙티브 그래프로 계절적 트렌드, 급증 또는 하락 추세를 파악해서 필요에 따라 전략을 조정할 수 있어요.

- 시간에 따른 페이지 조회수를 그래프로 시각화
- 맞춤형 인사이트를 위한 유연한 날짜 범위 선택
- 빠른 분석을 위한 트렌드 라인 시각화

![](https://jumpshare.com/share/gRDfrfR8NNRIUFr9PnHg+/GIF+Recording+2025-09-03+at+8.03.28+PM.gif)

## 인기 게시물

인기 게시물(Top Performing Posts)은 가장 많은 조회수와 참여율을 기록한 게시물을 보여줘서 참여도가 가장 높은 콘텐츠를 한눈에 확인할 수 있게 해줘요. 썸네일과 제목을 함께 표시해서 독자에게 가장 호응이 좋은 콘텐츠를 빠르게 파악할 수 있어요.

- 썸네일과 제목을 표시해서 쉽게 식별 가능
- 조회수와 참여도 기준으로 게시물 순위 표시
- 콘텐츠 성공 요인을 파악하는 데 도움

![](https://jumpshare.com/share/bQR0X2gwp8JV1XI9msos+/Screen+Shot+2025-09-03+at+8.09.21+PM.png)

## 링크 클릭 수

링크 클릭 추적(Link Click Tracking)은 게시물 내 어떤 링크가 클릭을 많이 받았는지에 대한 정확한 데이터를 제공해요. 이 인사이트를 통해 콘텐츠 내 CTA(행동 유도)와 하이퍼링크 배치의 효과를 측정할 수 있어요.

- 각 삽입된 링크의 클릭 수를 상세하게 집계
- 활발한 참여 지점을 추적하는 시각적 표시
- 데이터 기반 콘텐츠 개선 의사결정 지원

![](https://jumpshare.com/share/Ryry2R8DiCsLkNLt6WgF+/Screenshot+2025-08-25+at+12.17.24%E2%80%AFPM.png)

## 기기별 분석

기기별 분석(Device Breakdown)은 독자들이 블로그에 접속할 때 사용하는 기기(데스크톱, 모바일, 태블릿)에 대한 정보를 제공해요. 이 정보는 다양한 플랫폼에서 사용자 경험을 최적화하고 접근성을 보장하는 데 매우 중요해요.

- 기기(데스크톱, 모바일, 태블릿)별 조회수 세분화
- 기기 유형별 콘텐츠 맞춤화에 도움이 되는 인사이트
- 반응형 디자인 및 플랫폼별 조정에 활용

![](https://jumpshare.com/share/Nu2I8YYmyLfEHzZfT6ST+/Screen+Shot+2025-09-03+at+8.16.34+PM.png)

## 카테고리별 게시물 방문

카테고리 인사이트(Category Insights)는 게시물 방문을 각 콘텐츠 카테고리별로 구분해줘요. 이 기능을 통해 어떤 주제나 테마가 가장 많은 관심을 끌고 있는지 파악해서 더 타겟팅된 콘텐츠 기획이 가능해요.

- 콘텐츠 카테고리별로 구분된 방문 수 표시
- 독자 호응도가 높은 주제 영역을 파악하는 데 도움
- 콘텐츠 타겟팅 전략 개선 지원

![](https://jumpshare.com/share/ZFBiqFlSvfgP0P3q6Sa0+/Screen+Shot+2025-09-03+at+8.18.53+PM.png)

## 작성자 링크 클릭

작성자 인사이트(Author Insights)는 작성자 링크 클릭을 추적해서 어떤 기고자가 참여도를 이끌어내고 있는지 보여줘요. 이 데이터는 우수한 성과를 낸 작성자를 치하하거나 협업 콘텐츠 전략을 수립하는 데 활용할 수 있어요.

- 작성자 링크 클릭을 통한 참여도 모니터링
- 개별 기고자의 성과에 대한 피드백 제공
- 콘텐츠 협업에 대한 데이터 기반 의사결정 지원

![](https://jumpshare.com/share/ctzN9KN17zXbX7fnzMgS+/Screen+Shot+2025-09-03+at+8.19.56+PM.png)

## 가져오기 vs. 수동 추적

가져오기 vs. 수동 추적(Import vs. Manual Tracking)은 가져온 게시물과 직접 작성한 게시물을 구분해서 보여줘요. 이 비교를 통해 다양한 콘텐츠 제작 방식 간의 성과 차이를 평가하고, 게시 전략을 더 정교하게 다듬을 수 있어요.

- 콘텐츠 제작 방식에 대한 인사이트 제공
- 가져온 게시물과 직접 작성한 게시물 간의 성과 차이 강조
- 콘텐츠 큐레이션 기법에 대한 의사결정 지원

## 자주 묻는 질문

**Q: 블로그 분석은 누가 사용할 수 있나요?**

블로그 분석은 모든 3가지 요금제의 전체 사용자가 이용할 수 있어요.


**Q: 데이터는 언제부터 제공되나요?**

블로그 분석은 2024년 8월 28일부터 데이터가 수집되었어요. 이 날짜 이전의 블로그 활동은 리포트에 "알 수 없음(Unknown)"으로 표시돼요.


**Q: 날짜별로 데이터를 필터링하려면 어떻게 하나요?**

날짜 범위 선택기를 사용하면 원하는 기간의 데이터를 확인할 수 있어요.


**Q: 어떤 게시물이 가장 참여도가 높은지 어떻게 확인하나요?**

인기 게시물 섹션에서 썸네일과 제목을 통해 참여도가 가장 높은 게시물을 빠르게 파악할 수 있어요.


**Q: 데이터는 실시간으로 업데이트되나요?**

데이터는 정기적으로 갱신되지만, 처리 주기로 인해 실시간 업데이트에 약간의 지연이 있을 수 있어요.
