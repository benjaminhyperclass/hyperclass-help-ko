# AI로 블로그 글 만들기

블로그 글 AI(Blog Post AI)를 쓰면 SEO에 맞는 블로그 글을 더 빠르게 만들 수 있어요. 이 AI 글쓰기 도우미는 **Blog Editor**(블로그 편집기) 안에서 글을 생성하고, 다듬고, 게시까지 할 수 있게 도와줘요. 도구를 바꿔 가며 작업하지 않아도 아이디어에서 초안까지 한 번에 갈 수 있어요.

{% hint style="warning" %}
블로그 글 AI는 **실험실**에서 제공해요. 사용하기 전에 서브 계정에서 먼저 켜 주세요.
{% endhint %}

## 블로그 글 AI란?

블로그 글 AI는 하이퍼클래스에 내장된 AI 글쓰기 도우미예요. **Blog Editor** 안에서 SEO에 맞는 콘텐츠를 만들 수 있어요. 빈 페이지에서 시작하거나 외부 글쓰기 도구를 쓰지 않아도, 한곳에서 블로그 콘텐츠를 생성하고 다듬을 수 있어요.

블로그 글 AI는 글을 만들기 전에 웹을 실시간으로 검색해 최신 정보를 모아요. 관련 출처를 찾아 최근 소식을 정리한 뒤, 이 정보로 구조가 잡힌 블로그 콘텐츠를 만들어요.

모든 과정을 자동으로 맡기고 싶을 때도, 세세하게 직접 조절하고 싶을 때도 쓸 수 있어요. **지원** 모드와 **빌드** 모드 중에서 고르면 돼요. 블로그 글 AI로 할 수 있는 일은 다음과 같아요.

- 주제만으로 블로그 글 생성하기
- 직접 쓴 프롬프트로 긴 글이나 맞춤형 콘텐츠 만들기
- 이미지 자동 생성하기
- SEO에 맞춘 제목, 설명, 키워드 받기
- 블로그의 어느 부분이든 편집, 다시 쓰기, 다시 생성하기
- 바로 게시하거나 임시 저장하기

이제 하이퍼클래스 안에서 콘텐츠 제작을 처음부터 끝까지 할 수 있어요.

## 블로그 글 AI의 장점

- **빠른 초안 작성**: 섹션을 하나하나 직접 쓰지 않아도 몇 분 안에 블로그 글 초안을 완성해요.
- **SEO 지원 내장**: SEO를 고려한 구조, 메타데이터, 키워드 안내를 편집기 안에서 바로 받을 수 있어요.
- **유연한 생성 방식**: 목표에 따라 안내에 따라 주제로 생성하는 방식과 직접 쓴 프롬프트로 생성하는 방식 중에서 골라요.
- **더 쉬운 편집**: **Blog Editor**를 벗어나지 않고 어조, 명확성, 가독성, 글 길이를 개선해요.
- **간편한 게시**: 임시 저장하거나, 최종 내용을 확인한 뒤 바로 게시해요.

## AI 모드 알아보기

AI 글쓰기 모드는 두 가지예요.

### 지원 모드 (주제 기반 블로그 생성)

간단한 주제만으로 AI가 블로그 글 전체를 만들어 주길 원할 때 **지원** 모드를 쓰세요. 블로그 주제는 정해져 있지만 구성, SEO 방향, 초안 작성에 도움이 필요할 때 좋아요.

**작동 방식**

주제와 원하는 조건(글자 수, 타깃 독자, 키워드)을 입력하면, 하이퍼클래스가 읽기 쉽고 SEO에 맞는 블로그 초안을 만들어 줘요. 초안에는 전체 개요, 제목과 소제목, SEO 메타데이터(제목, 설명, 키워드), 글에 어울리는 AI 생성 이미지가 들어 있어요.

**이럴 때 좋아요**

- 간단한 주제 아이디어로 첫 초안을 만들 때
- SEO 중심 콘텐츠를 만들 때
- 프롬프트를 거의 쓰지 않고 빠르게 콘텐츠를 만들 때
- 에이전시가 블로그를 대량으로 제작할 때

![지원 모드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067327301/original/6LXfSQ9c3rma66gOPU6VSH0sRYI5dsWhxw.png?1773938881)

### 빌드 모드 (프롬프트 직접 작성)

**빌드** 모드는 긴 글이나 개인화 정도가 높은 결과물이 필요한 고급 사용자를 위한 모드예요. 직접 프롬프트를 입력하기 때문에 콘텐츠의 방향, 어조, 구성, 창작 스타일을 더 세밀하게 조절할 수 있어요.

**작동 방식**

원하는 프롬프트를 자유롭게 쓰면 AI가 맞춤형 블로그 글을 만들어 줘요. 예를 들면 이런 프롬프트가 있어요.

- “초보자를 위한 지속 가능한 패션 가이드를 1,500단어 분량으로 써 줘.”
- “마그네슘의 효능에 관한 블로그 글을 연구 결과에 근거한 내용으로 만들어 줘.”

**이럴 때 좋아요**

- 특수한 업종을 다룰 때
- 기술적이거나 전문가 수준의 주제를 다룰 때
- 숙련된 마케터와 에이전시일 때
- 창작을 직접 조절하고 싶은 작성자일 때

## 스마트 편집 도구

콘텐츠를 생성한 뒤에는 편집기 안에서 바로 글을 다듬을 수 있어요. 할 수 있는 작업은 다음과 같아요.

- 문단 다시 생성하기
- 어조, 명확성, 글 길이 개선하기
- AI 이미지 교체하거나 다시 생성하기
- 쓰지 않는 섹션 삭제하기
- SEO 개선 제안 적용하기

모든 작업이 한곳에서 이뤄지니 복사하거나 탭을 오갈 필요가 없어요.

## 언어 번역

블로그 글 AI는 여러 언어로 콘텐츠를 생성하고 번역할 수 있어요. 편집기 안에서 블로그 콘텐츠를 다른 언어로 만들거나 번역할 수 있어서, 비즈니스와 에이전시가 전 세계 독자를 위한 콘텐츠를 더 쉽게 게시할 수 있어요.

2. 드롭다운에서 원하는 언어를 선택하세요. 같은 화면에서 글의 어조도 바꿀 수 있어요.

## URL과 이미지 참고하기

참고 자료를 넣어 주면 블로그 글 AI가 더 맥락에 맞고 적절한 결과를 만들어요. 특정 출처, 캠페인, 주제, 이미지 방향을 따르는 콘텐츠를 원할 때 출처 URL이나 이미지를 넣으면 결과가 원하는 방향에 더 가까워질 수 있어요.

블로그 글 AI는 다음을 활용해요.

- 콘텐츠를 생성할 때 맥락 정보로 쓰는 참고 URL
- 블로그 섹션이나 관련 콘텐츠를 생성할 때 쓰는 이미지

## 블로그 글 AI 사용 방법

1. **사이트 > 블로그**로 이동하세요.

   ![사이트 > 블로그 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069057370/original/8hsWhhn2m-OrgF9PxLMBB81tsTgAEWCPLA.png?1776106160)
2. 블로그를 열고 새 블로그 글을 만들거나 기존 초안을 여세요.

   ![블로그 글 만들기 또는 초안 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069057383/original/vzXDJDM_l0KwEn_yfJmOdbZY6pfn4G2fyw.png?1776106206)
3. **Blog Editor**에서 **AI에게 문의** 패널을 여세요.

   ![AI에게 문의 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069057496/original/l0DAkVWx7tV2lka_dI5t4-ADNOQ0TMD44w.png?1776106361)
4. 콘텐츠를 만들 방식에 따라 **지원**(주제 기반) 또는 **빌드**(자유 프롬프트)를 선택하세요.

   ![지원 또는 빌드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069057526/original/JqWllgQdxEecCfqi_CzKLTiRjPzE-hXdUg.png?1776106416)

8. AI가 만든 SEO 정보를 확인하고, 필요한 부분을 수정하세요.

   ![AI가 생성한 SEO 정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069058599/original/D5__Afg5om0FAQgAmV_BYtAv24sYqeb0Ww.png?1776108387)

## 자주 묻는 질문

### 특정 섹션만 다시 생성할 수 있나요?
네. 원하는 문단 위에 마우스를 올린 뒤 **Regenerate**(다시 생성), **Rewrite**(다시 쓰기), **Adjust Tone**(어조 조정) 중에서 선택하세요.

### AI가 만든 이미지를 바꿀 수 있나요?
네. 이미지를 교체하거나, 다시 생성하거나, 삭제할 수 있어요. 언제든 가능해요.

### SEO 메타데이터는 자동으로 생성되나요?
네. 블로그 글 AI가 SEO 제목, 메타 설명, 키워드를 만들어 줘요. 모두 직접 수정할 수 있어요.

### 같은 블로그 글에서 두 모드를 함께 쓸 수 있나요?
네. **지원** 모드로 시작한 뒤, 추가 섹션은 **빌드** 모드 프롬프트로 만들 수 있어요.

### 지원 모드와 빌드 모드는 어떻게 다른가요?
**지원** 모드는 간단한 주제만 입력하면 블로그 글 전체를 만들어 줘요. **빌드** 모드는 직접 쓴 프롬프트로 특정 주제나 브랜드에 맞춘 콘텐츠를 더 세밀하게 조절해서 만들 수 있어요.
