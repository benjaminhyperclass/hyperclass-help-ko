# 블로그 게시글 편집기에서 자동 저장 사용하기

블로그 게시글 편집기의 새 기능인 자동 저장을 소개해요. 글을 쓰는 동안 변경 내용이 자동으로 저장되므로, 내용이 사라질 위험이 줄고 매번 직접 저장하지 않아도 돼요.

## 블로그 게시글 편집기의 자동 저장이란?

자동 저장은 블로그 게시글을 수정하는 내용을 약간의 지연을 두고 실시간으로 저장하는 기능이에요. 브라우저가 갑자기 꺼지거나 페이지를 실수로 닫아도 내용을 지킬 수 있어서, 안심하고 글을 쓸 수 있어요.

![블로그 게시글 편집기의 자동 저장 표시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049315117/original/jcUzJF3HRc6S2wSk8-W4rtCfuncqy7Qrbw.png?1751565250)

## 자동 저장의 장점

자동 저장은 글을 쓰는 동안 내용을 알아서 지켜 줘요.

- 편집 중에 내용이 사라질 위험이 줄어요.
- 직접 저장하는 횟수가 줄어서 글쓰기에 집중할 수 있어요.
- 저장 상태가 화면에 바로 표시돼요.
- 필요할 때 간단히 켜고 끌 수 있어요.

![자동 저장의 장점을 보여 주는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049315118/original/kOZUb5if3cWoacnITQGbeB0KXi4hIlI_LA.png?1751565250)

## 자동 저장 켜고 끄기

자동 저장은 쉽게 켜고 끌 수 있어요. 아래 순서대로 따라 해 보세요.

1. 대시보드에서 블로그 게시글 편집기를 열어요.
2. 상단 작업 표시줄에서 **Autosave Toggle**(자동 저장 토글)을 찾아요.
3. 기본으로 자동 저장이 켜져 있고, **자동 저장 켜짐**이라고 표시돼요.
4. 자동 저장을 끄려면 다음과 같이 해요.

   - **자동 저장 켜짐** 표시 위에 마우스를 올려요.
   - 팝오버가 나타나면 **Disable Autosave**(자동 저장 끄기) 버튼을 눌러요.
5. 자동 저장을 끄면 표시가 **마지막 저장**으로 바뀌고, 가장 최근에 저장된 시각이 함께 나와요. (예: **마지막 저장** 5월 22일 오후 6:30)
6. 다시 켜려면 **마지막 저장** 표시 위에 마우스를 올려요. 팝오버가 나타나면 **Enable Autosave**(자동 저장 켜기) 버튼을 누르세요.
7. 자동 저장 설정은 브라우저의 로컬 저장소에 저장돼요. 같은 브라우저에서는 다음에 접속해도 설정이 그대로 유지돼요.

![자동 저장 켜기·끄기 팝오버 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049315116/original/o59TG0cnjJl8cFym_ILsqmBuJQ5ze--1Ag.png?1751565250)

## 중요 사항

- 자동 저장 설정은 브라우저별로 적용되며, 로컬 저장소에 `blog-editor-autosave-enabled` 키로 저장돼요.
- 설정은 다른 기기나 다른 브라우저와 동기화되지 않아요.
- 자동 저장이 꺼져 있고 마지막 저장 기록이 없으면 **자동 저장 꺼짐**이라고 표시돼요.

## 자주 묻는 질문

### 자동 저장이 켜져 있을 때 브라우저가 꺼지면 어떻게 되나요?
변경 내용이 자동으로 저장되어 있어서, 최근에 수정한 내용을 잃지 않을 수 있어요.

### 여러 기기에서 자동 저장을 켜 둘 수 있나요?
아니요, 자동 저장 설정은 브라우저와 기기마다 따로 적용돼요.

### 직접 저장하는 방식이 더 편해요. 어떻게 하나요?
토글에서 자동 저장을 끄면 돼요. 그러면 원하는 때에 직접 저장할 수 있어요.

### 자동 저장을 켜면 편집기가 느려지나요?
아니요, 자동 저장은 약간의 지연을 두고 작동하도록 만들어져서, 편집기 속도에는 영향을 주지 않으면서 수정 내용을 저장해요.

## 다음 단계

- 자동 저장을 켜고 걱정 없이 글을 써 보세요.
- 내 글쓰기 방식에 맞게 토글 설정을 바꿔 보세요.
- 브라우저의 로컬 저장소에 설정을 저장해 두면, 다음에 접속해도 원하는 설정 그대로 쓸 수 있어요.
- 블로그의 다른 기능도 살펴보고 게시 과정을 더 편하게 만들어 보세요.
