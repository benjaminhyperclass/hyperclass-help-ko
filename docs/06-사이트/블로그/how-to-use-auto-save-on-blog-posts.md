# 블로그 게시물에서 자동 저장 사용하는 방법

이번 아티클에서는 블로그 게시물 편집기(Blog Post Editor)에 새롭게 추가된 자동 저장(Auto Save) 기능 사용법을 안내해 드려요! 자동 저장 기능을 사용하면 작업하는 동안 변경 사항이 자동으로 저장되어, 콘텐츠 손실 위험을 줄이고 매번 수동으로 저장해야 하는 번거로움을 없앨 수 있어요.

## 블로그 게시물 편집기의 자동 저장이란?

자동 저장(Auto Save)은 블로그 게시물 수정 내용을 약간의 지연 시간을 두고 실시간으로 자동 저장해 주는 새로운 기능이에요. 브라우저 충돌이나 실수로 페이지를 닫는 것과 같은 예기치 못한 상황으로부터 콘텐츠를 안전하게 보호해 주기 때문에, 마음 편히 콘텐츠 작성에 집중할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049315117/original/jcUzJF3HRc6S2wSk8-W4rtCfuncqy7Qrbw.png?1751565250)

## 자동 저장의 주요 장점

자동 저장 기능은 매끄럽고 자동화된 보호 기능을 제공하여 콘텐츠 제작 워크플로우를 개선해 줘요. 주요 장점은 다음과 같아요.

- 편집 중 콘텐츠 손실 위험을 최소화해요.

- 수동 저장의 필요성을 줄여, 글쓰기에만 집중할 수 있어요.

- 시각적인 저장 상태 표시로 실시간 피드백을 제공해요.

- 필요에 따라 손쉽게 켜고 끌 수 있어 유연하게 사용할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049315118/original/kOZUb5if3cWoacnITQGbeB0KXi4hIlI_LA.png?1751565250)

## 블로그 게시물 편집기에서 자동 저장 사용하는 방법

자동 저장 기능은 직관적으로 관리할 수 있도록 설계되었어요. 활성화하거나 비활성화하려면 아래 단계를 따라주세요.

- 대시보드에서 블로그 게시물 편집기(Blog Post Editor)를 엽니다.

- 상단 액션 바에서 자동 저장 토글(Autosave Toggle)을 찾아주세요.

- 기본적으로 자동 저장은 활성화되어 있으며, "Autosave on" 태그로 표시돼요.

- 자동 저장을 비활성화하려면:

"Autosave on" 태그 위에 마우스를 올려주세요.

- Disable Autosave(자동 저장 비활성화) 버튼이 있는 팝오버가 나타나요.

- 자동 저장이 비활성화되면, 태그가 가장 최근 저장 시각이 표시된 "Last saved"로 바뀌어요. (예: "Last saved May 22, 6:30 PM")

- 다시 활성화하고 싶다면, "Last saved" 태그 위에 마우스를 올려 Enable Autosave(자동 저장 활성화) 버튼이 있는 팝오버를 확인하세요.

- 자동 저장 설정은 브라우저의 로컬 스토리지(local storage)에 저장되며, 동일한 브라우저에서는 이후 세션에서도 계속 유지돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049315116/original/o59TG0cnjJl8cFym_ILsqmBuJQ5ze--1Ag.png?1751565250)

## 주의 사항

- 자동 저장 설정은 브라우저별로 적용되며, 로컬 스토리지에 `blog-editor-autosave-enabled`라는 키로 저장돼요.

- 설정 값은 기기나 브라우저 간에 동기화되지 않아요.

- 자동 저장이 꺼져 있고 마지막으로 저장된 데이터가 없는 경우, "Autosave off"로 표시돼요.

## 자주 묻는 질문

**Q: 자동 저장이 켜진 상태에서 브라우저가 충돌하면 어떻게 되나요?**
변경 사항이 자동으로 저장되기 때문에, 최근 편집 내용을 잃어버리지 않도록 도와줘요.

**Q: 여러 기기에서 자동 저장을 활성화할 수 있나요?**
아니요, 자동 저장 설정은 각 브라우저와 기기별로 개별 적용돼요.

**Q: 수동 저장을 선호한다면 어떻게 하나요?**
토글을 이용해 자동 저장을 비활성화하면, 원하는 시점에 직접 저장할 수 있어요.

**Q: 자동 저장 기능이 편집기 속도를 느리게 만드나요?**
아니요, 자동 저장은 약간의 지연 시간을 두고 변경 사항을 반영하도록 설계되어 있어, 성능에 영향을 주지 않고 부드럽게 작동해요.

### 다음 단계

- 자동 저장을 활성화해서 걱정 없는 편집 경험을 직접 느껴보세요.

- 자신의 작업 스타일과 편의에 맞게 토글 설정을 조정해 보세요.

- 브라우저의 로컬 스토리지 설정을 유지해서, 다음에도 동일한 환경으로 편리하게 이용해 보세요.

- 게시물 작성 워크플로우를 더욱 향상시켜 줄 다른 블로그 기능들도 함께 살펴보세요.
