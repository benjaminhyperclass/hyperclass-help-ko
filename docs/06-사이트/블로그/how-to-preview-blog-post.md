# 블로그 게시물 미리보기

블로그 게시물을 다 썼다면 공개하기 전에 데스크톱과 모바일에서 어떻게 보이는지 미리 확인해 보세요. 이 문서에서는 빌더 안에서 게시물을 미리 보는 방법을 안내해요.

{% hint style="info" %}
블로그를 게시한 뒤에는 카테고리, 키워드, 작성자, 슬러그를 수정할 수 없어요. 개발팀이 해결 방법을 준비하고 있고, 곧 출시될 예정이에요.
{% endhint %}

## 미리보기 모드에서 보이는 항목

미리보기 모드에서는 하이퍼링크, 동영상, 작성자 정보를 클릭할 수 있어요. 다음 항목이 화면에 표시돼요.

- SEO 블로그 게시물의 대표 이미지
- 블로그 게시물 제목
- 카테고리 (게시 화면에서 추가한 경우)
- **게시일**
- 읽는 시간
- 블로그 게시물 본문
- 태그 (게시 화면에서 추가한 경우)
- 작성자 (게시 화면에서 추가한 경우)
- **Back to blog**(블로그로 돌아가기) 버튼 (미리보기에서는 작동하지 않아요)

## 빌더에서 게시물 미리보기

1. 빌더 오른쪽 위 메뉴에서 점 3개 아이콘을 클릭하세요.
2. 메뉴가 열리면 **게시물 미리보기**를 선택하세요.

![빌더 오른쪽 위 메뉴에서 게시물 미리보기를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48265308606/original/6wm6onsN2a0r1VhnJOdzUU7hLGMN-pwjmg.png?1669273837)

## 모바일·데스크톱 화면으로 전환하기

미리보기 모드에서는 모바일 화면과 데스크톱 화면을 오가며 볼 수 있어요. 화면 위쪽에 있는 전환 버튼을 클릭하면 두 화면이 서로 바뀌어요.
