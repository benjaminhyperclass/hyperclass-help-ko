# 블로그 RSS 피드 만들기

하이퍼클래스 블로그에서 RSS 피드를 만드는 방법을 안내해요. 피드 주소를 만들어 두면 최신 글을 **이메일 캠페인**이나 **소셜 플래너**로 자동 배포할 수 있어요.

## 블로그 RSS 피드란?

RSS는 Really Simple Syndication의 약자예요. 웹사이트를 일일이 돌아다니거나 검색하지 않아도, 관심 있는 소식과 정보를 한곳에서 받아 볼 수 있는 방식이에요.

블로그 RSS 링크는 두 가지로 쓸 수 있어요.

- **이메일 캠페인**으로 뉴스레터 보내기
- **소셜 플래너**의 RSS 기능으로 게시물 자동 예약하기

## 블로그 RSS 피드를 쓰면 좋은 점

- 이메일과 소셜 채널로 콘텐츠를 자동으로 전달해요.
- 직접 게시하지 않아도 되어 시간이 절약돼요.
- 바쁠 때도 콘텐츠를 꾸준히, 최신 상태로 유지할 수 있어요.
- **이메일 캠페인**과 **소셜 플래너** 게시 등 여러 채널에서 쓸 수 있어요.

## 블로그 RSS 피드 설정하기

하이퍼클래스 블로그에서 RSS 피드 링크를 바로 만들 수 있어요. 이 링크로 이메일 캠페인이나 소셜 미디어 자동화에 콘텐츠를 연결하면, 따로 업데이트하지 않아도 돼요.

{% hint style="warning" %}
**중요 사전 조건:** 도메인이 하이퍼클래스 계정에 연결되어 있어야 해요.
{% endhint %}

### 1단계: **사이트 > 블로그**로 이동하기

![사이트 메뉴에서 블로그로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051636512/original/Mia1euvydxZF72BbKvlN9dm7SQzjhVFZdw.png?1755181181)

### 2단계: 톱니바퀴 모양의 **설정** 아이콘을 클릭하고 **RSS** 섹션으로 이동하기

**블로그** 화면에서 톱니바퀴 모양의 **설정** 아이콘을 클릭한 다음, **RSS** 섹션으로 들어가세요.

![설정 아이콘을 클릭해 RSS 섹션으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051636927/original/tny6ZVw2eeScOupBzlV8x2Pe-U-ZqsRzaw.gif?1755181478)

### 3단계: RSS 피드 추가하기

**Add RSS Feed**(RSS 피드 추가) 창이 열려요. 이 창에서 다음 항목을 설정하고, 만들어진 RSS URL을 복사할 수 있어요.

- 피드 이름 정하기
- 블로그 선택하기
- 게시글 수 설정하기
- 전체 콘텐츠 포함 여부 선택하기
- 생성된 RSS URL 복사하기

![RSS 피드 추가 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051637826/original/wUr8xFA0mypVhpts6d3LHJHY3Xtmf2szBA.png?1755182066)

{% hint style="warning" %}
**중요:** URL을 복사하면 이메일 RSS 캠페인이나 RSS 소셜 게시 어디에서든 쓸 수 있어요.
또한 RSS 드롭다운에서 옵션을 바꿔도, 이미 복사해서 쓰고 있는 다른 RSS URL에는 영향이 없어요. 기존 URL은 계속 작동해요.
{% endhint %}

## 자주 묻는 질문

### RSS를 만든 뒤 드롭다운에서 블로그를 바꾸면 어떻게 되나요?
처음에 만든 URL은 그대로 작동해요. 드롭다운을 바꿔도 이전 URL에서 계속 피드가 만들어져요.

### 게시글 수에 최대 한도가 있나요?
네, 현재 화면에서 최대 게시글 수가 정해져 있어요.

### 임시 저장한 글도 RSS로 가져올 수 있나요?
아니요, RSS 피드에는 게시된 글만 나와요.

### 이미 만든 RSS 설정에서 피드 길이를 바꾸려면 어떻게 하나요?
블로그 **설정** 화면에서 피드 설정을 관리하고 편집할 수 있어요.
