# URL로 블로그 게시물 가져오기

다른 웹사이트의 블로그 게시물을 하이퍼클래스로 옮기는 방법을 안내해요. 홈페이지 URL을 스캔해 게시물을 찾아 주는 URL 블로그 가져오기 도구의 작동 방식, 가져오는 중 메타데이터를 매핑하는 방법, 매핑된 게시물과 매핑되지 않은 게시물이 어떻게 처리되는지 알 수 있어요.

## 블로그 게시물 가져오기 도구란?

블로그 게시물 가져오기 도구는 외부 웹사이트의 홈페이지 URL을 스캔해서 게시물을 찾고, 그 게시물을 하이퍼클래스 블로그로 옮겨 줘요. 복사해서 붙여 넣는 수작업을 줄여 주고, 옮기는 과정을 한눈에 확인할 수 있어요.

---

## 블로그 게시물 가져오기 도구의 장점

- 단계별 가져오기: 스캔, 검토, 매핑, 가져오기 순서로 진행해서 과정을 이해하기 쉬워요.
- 가져오기 전 확인: 찾은 게시물을 블로그로 가져오기 전에 먼저 검토할 수 있어요.
- 메타데이터 직접 매핑: 빠진 작성자, 카테고리, 태그를 가져오는 중에 추가할 수 있어요.
- 유연한 가져오기: 매핑된 게시물과 매핑되지 않은 게시물을 모두 막힘없이 가져올 수 있어요.
- 빠른 게시 준비: 매핑된 게시물은 게시된 상태로, 매핑되지 않은 게시물은 임시 저장 상태로 가져와서 나중에 이어서 손볼 수 있어요.

---

## URL로 블로그 게시물 가져오는 순서

### 1단계: 블로그 목록 열기

1. **사이트 > 블로그**로 이동해 블로그 목록을 확인하세요.
2. 기존 블로그를 클릭하거나 [블로그를 새로 만드세요](../create-blog-posts.md).

   ![블로그 목록 화면](https://jumpshare.com/share/43G7UZ1hz9B3j3DKsOga+/Screen+Shot+2026-03-11+at+19.37.44.png)

### 2단계: 블로그 게시물 가져오기 도구 열기

1. 기존 블로그나 새 블로그의 **블로그 게시물 목록**으로 이동하세요.
2. **새 게시물** > **Import Blog Posts from URL**(URL로 블로그 게시물 가져오기)을 클릭하세요.

   ![새 게시물 메뉴에서 URL로 가져오기를 선택하는 화면](https://jumpshare.com/share/bUz6DJ4prqCWzRlYTwRo+/GIF+Recording+2026-03-11+at+19.44.15.gif)

### 3단계: 가져오기 시작

1. **블로그 홈페이지** URL을 입력하세요.
2. **recent post URL**(최근 게시물 URL)을 입력하세요.
3. **platform**(플랫폼)을 선택하세요.
4. **계속**을 클릭하세요. 매핑이 끝날 때까지 기다려야 한다는 안내가 나와요.

   ![블로그 홈페이지 URL 입력 화면](https://jumpshare.com/share/cePF5mvLLheYwuZikCCU+/Screen+Shot+2026-03-11+at+19.49.10.png)

### 4단계: 콘텐츠 매핑(Map Contents)

{% hint style="info" %}
가져오는 데 걸리는 시간: 게시물 1,000개를 가져오는 데 약 10~20분이 걸려요.
{% endhint %}

{% hint style="warning" %}
스캔 결과 오류: 블로그 사이트맵에 URL이 없으면 블로그 게시물을 가져올 수 없어요. 현재는 중간 단계인 **실패** 상태가 **스캔 진행 중**으로 표시되고, 이를 클릭하면 빈 페이지가 나와요.
{% endhint %}

1. 화면의 안내에 따라 페이지의 각 요소가 블로그 게시물의 어떤 정보에 해당하는지 지정하세요.
2. 체크 표시가 모두 초록색으로 바뀌면 매핑이 끝난 거예요.

   ![콘텐츠 매핑 화면에서 체크 표시가 초록색으로 바뀌는 모습](https://jumpshare.com/share/oqpbM800rIPkOA8QzkIV+/GIF+Recording+2026-03-11+at+20.00.17.gif)
3. 가져오기가 끝나면 **게시물 수**와 가져온 날짜를 알려 주는 메시지가 나와요.

   ![가져오기 완료 메시지 화면](https://jumpshare.com/share/1rpHqWbvTeKPgB8DURYF+/Screen+Shot+2026-03-11+at+20.18.06.png)

### 5단계: 게시물 게시

1. 블로그에 가져온 게시물을 검토하세요.

   - 매핑이 모두 끝난 게시물은 **게시됨** 상태로 가져와요.
   - 매핑되지 않은 게시물은 **임시 저장** 상태로 가져와요.
2. 가져올 블로그 게시물을 선택하세요.
3. **Import Selected**(선택 항목 가져오기)를 클릭하세요.

   ![가져올 게시물을 선택하는 화면](https://jumpshare.com/share/Q7ZT6xifO8jUyrGY0FER+/Screen+Shot+2026-03-11+at+20.22.36.png)

## 자주 묻는 질문

### 가져온 블로그 게시물은 모두 임시 저장 상태로 남나요?
아니요. 매핑된 게시물은 **게시됨** 상태로, 매핑되지 않은 게시물은 **임시 저장** 상태로 가져와요.

### 메타데이터가 일부 없어도 게시물을 가져올 수 있나요?
네, 가져올 수 있어요. 빠진 작성자, 카테고리, 태그는 가져오는 중에 직접 추가하거나 매핑할 수 있어요.

### 일부 게시물만 매핑되어 있으면 어떻게 되나요?
두 종류 모두 가져올 수 있어요. 매핑이 끝난 게시물은 게시된 상태로, 매핑이 덜 끝난 게시물은 임시 저장 상태로 가져와요.

### 블로그를 가져오면 SEO에는 어떤 영향이 있나요? SEO 영향력이나 검색 순위도 그대로 옮겨지나요?
가져오기 도구는 게시물 콘텐츠와 함께 제목, 설명 같은 SEO 메타데이터를 옮겨 줘요. 하지만 콘텐츠를 가져온다고 해서 SEO 영향력까지 자동으로 넘어가지는 않아요. 검색 순위와 링크 영향력을 지키려면 301 리디렉션을 설정하고, 가능하면 도메인과 URL 구조를 그대로 유지하세요. 리디렉션이 없으면 검색 엔진이 가져온 게시물을 새 페이지로 볼 수 있어요.

### 가져온 뒤에 카테고리, 작성자, 태그를 직접 다시 만들어야 하나요?
항상 그런 건 아니에요. 가져오는 중에 해당 메타데이터가 없으면 매핑 단계에서 추가하거나 매핑할 수 있어요.
