# 블로그에 목차 추가하기

블로그 글의 제목(헤딩)을 바탕으로 **목차**(Table of Contents)를 자동으로 만들 수 있어요. 목차를 넣으면 글 구조가 한눈에 보이고, 독자가 링크를 눌러 원하는 부분으로 바로 이동할 수 있어요.

- 독자가 클릭 가능한 링크로 글 안을 쉽게 이동할 수 있어요.
- 블로그 테마에 맞게 목차의 스타일을 바꿀 수 있어요.

## 작동 방식

1. **블로그**로 이동한 뒤 **블로그 사이트 편집**을 선택하세요.
2. 블로그 글 편집기에서 새로 생긴 **목차** 아이콘을 찾으세요. 아이콘을 누르면 레이아웃 3가지가 나와요.

   ![목차 아이콘과 레이아웃 옵션 3가지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039083312/original/HXFy12Tp_0qaLZbJjpncKnYKp8ftjjhRHw.png?1735631501)

3. 레이아웃을 고르세요. 선택한 들여쓰기에 따라, 각 제목으로 연결되는 링크가 걸린 목차가 만들어져요.

   ![선택한 들여쓰기로 생성된 목차](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039083313/original/vWt9WIbLyYlFtjMeTWSah4LLnOqNrBjkug.png?1735631501)

4. 도구 모음에서 굵게, 기울임꼴, 밑줄, 취소선, 글꼴 크기 같은 스타일을 조정하세요.

   ![도구 모음에서 목차 스타일을 조정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039083314/original/ANtFdIZsXwPTpWGbiVzDqA40e4e0Y1-IdA.png?1735631501)

이렇게 하면 목차 설정이 끝나요.

## 이 기능이 좋은 이유

긴 글도 읽기 편해져요. 글 구조가 잘 정리되어 SEO에도 도움이 되고, 독자는 끊김 없이 글을 읽을 수 있어요.
