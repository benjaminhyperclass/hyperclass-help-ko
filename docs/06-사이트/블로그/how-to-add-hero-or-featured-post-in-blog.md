# 블로그에 히어로(추천) 게시글 추가하기

블로그 상단에 추천 게시글(히어로 게시글)을 보여 주는 방법을 안내해요. 추천 게시글을 지정하면 어떤 주제를 중점으로 보여 줄지 정해서 콘텐츠 마케팅을 더 전략적으로 운영할 수 있어요.

## 추천 게시글을 추가하면 좋은 이유

블로그에 추천 게시글을 추가하면 다음과 같은 효과를 기대할 수 있어요.

1. 중요한 콘텐츠 강조: 공지, 핵심 콘텐츠, 인기 게시글처럼 꼭 보여 주고 싶은 글이 독자에게 계속 눈에 띄어요.
2. 참여도 향상: 반응이 좋거나 핵심이 되는 게시글을 맨 위에 두어 노출과 상호작용을 늘릴 수 있어요.
3. SEO 및 체류 시간 개선: 고정한 게시글에 방문이 자주 이어지면 검색 순위와 사용자 유지에 도움이 될 수 있어요.
4. 에버그린 콘텐츠 홍보: 시간이 지나도 가치가 있는 글이나 자주 참고하는 글을 쉽게 찾을 수 있어요.

## 추천 게시글 추가 방법

1. **사이트 > 블로그**로 이동하세요.
2. 블로그 목록에서 블로그 이름을 클릭하세요.

   ![블로그 목록에서 블로그 이름을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041933345/original/IbeXyPwLDXHVqTDV41dYPF5QjH4_gwCpUw.png?1740041571)

3. 블로그 사이트를 편집할 수 있는 화면으로 이동하세요.

   ![블로그 사이트 편집 화면으로 이동하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041933544/original/WnfmiaJNddSQn-cJEVunj8qSbcn2pb-s3Q.png?1740041696)

4. 추천 게시글(Featured Post) 요소를 추가하세요.

   ![추천 게시글 요소를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041933873/original/YLBchr3NRTriFZOnUgOnOLABTYCHHtiBeg.png?1740041902)

5. 추천 게시글로 보여 줄 블로그 게시글을 선택하세요.

   ![추천할 블로그 게시글을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041933739/original/72zGHXo--XWgU7eu-d2P8HUO4sHcKGUf1Q.png?1740041813)

6. 레이아웃을 선택하고, 추천 게시글에 보여 줄 항목을 고르세요.
7. 블로그 사이트를 게시하세요.
