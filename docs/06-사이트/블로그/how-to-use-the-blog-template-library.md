# 블로그 템플릿 라이브러리 사용하기

하이퍼클래스의 블로그 템플릿 라이브러리에서 미리 만들어진 블로그 구조를 골라 글 작성 시간을 줄일 수 있어요. 템플릿을 고른 뒤 클릭 몇 번이면 바로 내용을 채워 넣기 시작할 수 있어요.

## 블로그 템플릿 라이브러리란?

블로그 템플릿 라이브러리는 하이퍼클래스 블로그 시스템에 들어 있는 기능이에요. 미리 만들어 둔 블로그 레이아웃을 제공해서 콘텐츠 제작을 쉽게 해 줘요. 처음부터 시작하지 않고, 교육용 가이드, 홍보 콘텐츠, 스토리텔링 형식처럼 흔한 콘텐츠 목적에 맞춰 디자인된 템플릿 중에서 고를 수 있어요.

## 블로그 템플릿을 쓰면 좋은 점

블로그 템플릿을 쓰면 워크플로우이 간단해지고, 글의 품질과 일관성도 높일 수 있어요.

- 구조가 잡힌 형식으로 시작해서 시간을 아낄 수 있어요.
- 전문가가 디자인한 다양한 블로그 유형 중에서 고를 수 있어요.
- 여러 글에서 시각적·구조적 일관성을 유지할 수 있어요.
- 편집기에서 각 템플릿을 쉽게 수정할 수 있어요.
- 모바일 대응과 접근성이 갖춰져 있어요.
- 콘텐츠 영감을 얻고 시작해서 글이 막히는 일을 줄일 수 있어요.

## 템플릿 라이브러리로 블로그 글 만들기

**템플릿 라이브러리**는 쉽게 열 수 있고, 구조가 이미 잡힌 새 블로그 글을 바로 만들 수 있어요.

1. 왼쪽 메뉴에서 **사이트 > 블로그**를 클릭하세요.
2. 오른쪽 위에 있는 **Create Blog**(블로그 만들기) 버튼을 클릭한 다음, **템플릿으로 만들기**를 선택하세요.
3. 사용할 수 있는 블로그 템플릿을 둘러보세요. 템플릿을 클릭하면 미리 볼 수 있어요.
4. 마음에 드는 템플릿을 골랐으면 **Continue**(계속)를 클릭하세요.
5. 템플릿이 블로그 편집기에서 열려요. 이제 내용, 서식, 미디어를 원하는 대로 바꿀 수 있어요.
6. 편집을 마치면 **저장**을 클릭하거나 글을 **게시**하세요.

## 제공되는 블로그 템플릿 유형

다양한 템플릿 중에서 콘텐츠 목적에 맞는 것을 고르면 내용이 더 분명하게 전달되고 독자의 반응도 높아져요. 각 레이아웃은 전문적으로 구성되어 있어서 콘텐츠가 효과적이고 보기 좋게 흘러가도록 도와줘요.

## 자주 묻는 질문

### 템플릿을 선택한 뒤에 레이아웃을 수정할 수 있나요?
네. 템플릿을 고른 뒤에는 블로그 편집기에서 레이아웃, 텍스트, 미디어를 모두 자유롭게 수정할 수 있어요.

### 템플릿을 쓰면 SEO 설정에 제한이 생기나요?
아니요. 템플릿은 SEO 권장 사항에 맞춰 최적화되어 있어요. 그래도 좋은 결과를 얻으려면 **SEO 메타데이터**는 직접 입력하세요.

### 직접 만든 템플릿을 저장해서 나중에 쓸 수 있나요?
지금은 안 돼요. 라이브러리에는 시스템에서 제공하는 템플릿만 있어요.

### 블로그 템플릿은 모바일에서도 잘 보이나요?
네. 모든 템플릿이 반응형으로 디자인되어 있어서 데스크톱과 모바일 모두에서 잘 표시돼요.

### 편집하다가 중간에 다른 템플릿으로 바꾸고 싶으면 어떻게 하나요?
글 작성을 시작한 뒤에는 템플릿을 바꿀 수 없어요. 다른 템플릿을 쓰려면 새 블로그 글을 만드세요.
