# 블로그 게시글에 댓글 기능 쓰기

블로그 댓글을 켜면 독자가 게시글에 댓글을 달고, 서로 답글을 주고받고, 반응을 남길 수 있어요. 운영하는 쪽에서는 모든 댓글을 한곳에서 승인하고, 답하고, 관리할 수 있습니다. 이 문서에서는 게시글에 댓글을 추가하는 방법, 독자에게 보이는 화면, 댓글 관리 방법, 댓글 설정 방법을 안내해요.

## 블로그 댓글이란?

블로그 댓글은 게시글에 댓글 영역을 붙여 주는 기능이에요. 블로그 게시글 페이지에 **댓글** 요소를 한 번만 추가하면, 그 블로그 사이트의 모든 게시글에 댓글 영역이 생겨요. 독자는 이메일로 로그인해서 댓글을 남기고, 운영하는 쪽에서는 블로그 사이트의 **댓글** 탭에서 댓글을 확인하고 답할 수 있어요.

### 블로그 댓글의 장점

- 커뮤니티를 키울 수 있어요: 독자가 질문하고, 의견을 나누고, 다시 찾아올 수 있는 공간이 생겨요.
- 브랜드 이름으로 답할 수 있어요: 팀이 남긴 답글에는 **운영자** 배지가 붙어서, 독자가 다른 댓글과 구분할 수 있어요.
- 직접 관리할 수 있어요: 댓글이 공개되기 전에 승인을 받도록 설정하고, 어떤 댓글이든 답하거나 승인하거나 삭제할 수 있어요.
- 한곳에서 모두 관리해요: 블로그 사이트 전체의 댓글을 합계, 추이, 필터, 검색으로 볼 수 있어요.
- 검색에 유리해요: 게시된 댓글은 페이지 내용의 일부라서 검색 엔진이 읽을 수 있어요.

## 블로그 게시글에 댓글 추가하기

댓글은 블로그 사이트의 게시글 페이지에 추가해요. 한 번 추가하면 그 블로그 사이트의 모든 게시글에 댓글 영역이 나타나요.

### 1단계: 블로그 게시글 페이지 열기

1. **사이트**로 이동하세요.
2. **블로그**를 클릭하고 블로그 사이트를 여세요.
3. **블로그 사이트 편집**을 클릭한 뒤, 빌더에서 블로그 게시글 페이지를 여세요.

### 2단계: 댓글 요소 추가하기

1. 요소 패널을 열고 **댓글** 요소(**신규** 표시)를 찾으세요.
2. 게시글 페이지로 끌어다 놓으세요. 보통 게시글 본문 아래에 놓아요.

### 3단계: 댓글 영역 꾸미기

1. 독자가 이모지와 이미지 첨부를 쓸 수 있게 할지 선택하세요.
2. 제목과 독자에게 보이는 로그인 안내 문구를 수정하세요.
3. 색상, 글꼴, 크기를 사이트의 다른 부분과 어울리게 맞추세요.

### 4단계: 저장하고 게시하기

1. **저장**을 클릭한 뒤 **게시**를 클릭하세요.
2. 블로그 사이트의 아무 게시글이나 열어서 댓글 영역이 나타나는지 확인하세요.

{% hint style="info" %}
**댓글** 요소는 블로그 게시글 페이지에서만 쓸 수 있어요. 블로그 홈 페이지에는 추가되지 않아요.
{% endhint %}

## 독자에게 보이는 화면

### 로그인하고 댓글 남기기

독자는 로그인하지 않아도 댓글을 읽을 수 있어요. 댓글을 쓰거나, 답글을 달거나, 좋아요·싫어요를 누르려면 댓글 영역에서 로그인해야 해요.

- 다시 방문한 독자는 이메일을 입력하고 일회용 코드를 받아요. 비밀번호는 필요 없어요.
- 처음 방문한 독자는 **계정 만들기**를 클릭하고 이름, 이메일, 비밀번호를 입력해요.

### 댓글, 답글, 반응

- 댓글과 답글: 독자는 댓글을 쓰거나 다른 독자의 댓글에 답글을 달 수 있어요. 답글은 3단계까지 이어질 수 있어요.
- 이모지와 이미지: 독자는 이모지를 넣고, 댓글 하나에 이미지를 한 장 첨부할 수 있어요.
- 좋아요/싫어요: 독자는 모든 댓글에 반응을 남길 수 있어요.
- **운영자** 배지: 팀이 남긴 답글에는 **운영자** 배지가 표시돼요.
- **더 보기**: 긴 토론은 나눠서 불러오고, **댓글 더 보기**를 누르면 이어서 볼 수 있어요.

![운영자 답글이 달린 블로그 게시글 댓글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084161326/original/PY3MNtbJHLgx3wi_0ydnUETNOfOeqT9b4w.png?1792998488)

{% hint style="info" %}
승인이 필요하도록 설정한 경우, 새 댓글은 승인하기 전까지 댓글을 쓴 독자에게만 보여요.
{% endhint %}

## 댓글 관리하기

### 1단계: 댓글 탭 열기

1. **사이트 > 블로그**로 이동해서 블로그 사이트를 여세요.
2. **댓글** 탭을 클릭하세요.

### 2단계: 댓글 확인하기

1. 맨 위에서 **전체 블로그 댓글**, **이번 달 댓글**, **대기 중인 댓글**을 확인하세요. 각 항목에 추이 선이 함께 표시돼요.
2. **상태**, **게시글** 필터나 검색을 사용해 원하는 댓글을 찾으세요.
3. 각 행의 작업 버튼으로 댓글에 **답글**을 달거나, **승인**하거나, **삭제**할 수 있어요.

![댓글 합계와 목록이 보이는 댓글 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084161355/original/DP-Tk2Ag-69s0A_byfkiuJvDc2kOGHP9Wg.png?1792998509)

### 3단계: 대기 중인 댓글에 하나씩 답하기

1. 대기 중인 댓글에서 **답글**을 클릭하세요. **대기 중인 댓글** 창이 열리고, 앞뒤 맥락을 볼 수 있도록 전체 대화가 함께 표시돼요.
2. 답글 입력란의 드롭다운에서 어떤 작성자로 답할지 선택하세요.
3. 답글을 입력하고 **답글**을 클릭하세요. 입력한 답글이 **운영자** 배지와 함께 게시글에 표시돼요.
4. 화살표를 눌러 다음 대기 중인 댓글로 넘어가거나, **게시된 페이지 보기**를 클릭해 게시글을 여세요.

![대기 중인 댓글 검토 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084161393/original/hKPxPXQgbRjooBO3Kg1y9QeT4NamMrwLpw.png?1792998534)

## 댓글 설정하기

1. **댓글** 탭에서 검색창 옆의 **설정** 아이콘을 클릭하세요.
2. 새 댓글을 공개하기 전에 검토하려면 **승인 필요**를 켜세요.
3. **이메일 알림**을 켜고 **발송 주기**를 선택하세요. **Every comment**(모든 댓글)와 **일일 요약** 중에서 고를 수 있어요.
4. **알림 받을 사람**에서 이 블로그 사이트의 댓글 이메일을 받을 사람을 선택하세요.
5. 서브 계정의 모든 블로그 사이트에 같은 설정을 쓰려면 **모든 블로그 사이트에 적용**을 선택하세요. 알림 받을 사람은 다른 블로그 사이트로 복사되지 않아요.
6. **변경사항 저장**을 클릭하세요.

## 자주 묻는 질문

### 댓글을 읽으려면 독자도 계정이 필요한가요?

아니요. 게시된 댓글은 누구나 읽을 수 있어요. 독자는 댓글을 쓰거나, 답글을 달거나, 좋아요·싫어요를 누를 때만 로그인하면 돼요.

### 게시글 하나에서만 댓글을 끌 수 있나요?

지금은 할 수 없어요. 댓글은 블로그 게시글 페이지에 추가되기 때문에, **댓글** 요소를 지우면 그 블로그 사이트의 모든 게시글에서 댓글이 없어져요.

### 승인 대기 중인 댓글은 누구에게 보이나요?

댓글을 쓴 독자와, **댓글** 탭에서 확인하는 팀원에게만 보여요. 승인하면 모두에게 공개돼요.

### 댓글 하나에 이미지를 몇 장까지 첨부할 수 있나요?

댓글 하나에 한 장까지 첨부할 수 있어요.

### 답글은 몇 단계까지 달 수 있나요?

답글은 3단계까지 이어질 수 있어요.

### 댓글 알림 이메일은 누가 받나요?

**댓글 설정**의 **알림 받을 사람**에서 선택한 사람이 받아요. 모든 댓글마다 받거나 **일일 요약**으로 받을 수 있어요.

### 검색 엔진에서 댓글이 보이나요?

네. 게시된 댓글은 페이지 내용의 일부라서 검색 엔진이 읽을 수 있어요.
