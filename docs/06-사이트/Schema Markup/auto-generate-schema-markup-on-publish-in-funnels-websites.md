# 발행 시 스키마 마크업 자동 생성

페이지를 발행할 때 구조화된 데이터를 자동으로 추가해서, 수동 작업 없이도 모든 페이지가 검색 엔진과 AI 답변 엔진에 최적화되도록 해줍니다.

배우게 될 내용

이 아티클에서는 하이퍼클래스의 AI 기반 스키마 자동 생성 기능이 어떻게 작동하는지, 그리고 웹사이트(Websites), 퍼널(Funnels), 웨비나(Webinars)에서 이 기능을 어떻게 활성화하는지 설명합니다.

추가 작업이나 발행 지연 없이 모든 발행 페이지에 구조화된 데이터가 포함되도록 함으로써 이 기능이 SEO와 AI 검색 노출을 어떻게 보호하는지 배우게 됩니다.

## 스키마 마크업 자동 생성이란 무엇인가요?

스키마 마크업 자동 생성은 하이퍼클래스에서 AI를 활용해, 구조화된 데이터 없이 발행된 페이지에 자동으로 스키마 마크업을 생성해주는 설정입니다. 스키마 마크업은 검색 엔진과 AI 답변 엔진이 콘텐츠를 이해하고 리치 결과(Rich Results)로 표시하는 데 도움을 줘서, SEO와 AEO(Answer Engine Optimization, 답변 엔진 최적화) 노출을 모두 개선해줘요.

이전에는 스키마 마크업을 페이지 편집기에서 한 페이지씩 직접 추가해야 했어요. 깜빡하거나 시간이 없으면 구조화된 데이터 없이 페이지가 게시됐고, 이는 검색 노출과 AI 인용 기회를 줄일 수 있었죠.

스키마 마크업 자동 생성을 활성화하면, 하이퍼클래스가 스키마 마크업이 없는 페이지가 발행될 때 자동으로 스키마 마크업을 추가해줘요. 이를 통해 페이지가 게시되는 순간부터 별도의 작업이나 발행 지연 없이 구조화된 데이터를 갖게 됩니다.

## 발행 시 스키마 마크업 자동 생성의 주요 장점

**수동 작업 불필요** — 스키마 마크업이 없는 페이지를 발행하면 AI가 백그라운드에서 자동으로 스키마 마크업을 생성해줘요

**발행 지연 없음** — 스키마 생성은 발행과 동시에 병렬로 처리되며, 페이지가 게시되는 과정을 절대 지연시키지 않아요

**기존 스키마 보호** — 이미 스키마 마크업이 있는 페이지는 절대 덮어쓰거나 수정되지 않아요

**모든 발행 경로에서 작동** — 빌더(Builder)에서 발행하든, 저장 기반 발행이든, 버전 기록(Version History) 발행이든 자동 생성이 작동해요

**웹사이트, 퍼널, 웨비나에서 사용 가능** — 스키마 마크업을 지원하는 모든 자산 유형에서 이 설정을 활성화할 수 있어요

**SEO 및 AEO/GEO 노출 개선** — 스키마 마크업은 구글의 리치 결과를 강화하고, AI 답변 엔진이 콘텐츠를 이해하고 인용하는 데 도움을 줘요

## 발행 시 스키마 마크업 자동 생성 작동 방식

스키마 마크업 자동 생성이 활성화된 상태에서 페이지를 발행하면, 하이퍼클래스가 이미 스키마 마크업이 존재하는지 확인해요. 페이지에 스키마가 없으면 AI가 백그라운드에서 자동으로 생성해줘요.

1단계

페이지 발행

빌더(Builder)에서 발행(Publish)을 클릭하거나, 저장 기반 발행을 트리거하거나, 버전 기록(History)에서 특정 버전을 복원해요.

2단계

하이퍼클래스가 기존 스키마 확인

페이지에 이미 스키마 마크업이 있으면 하이퍼클래스는 이를 그대로 두고 즉시 페이지를 발행해요.

3단계

AI가 스키마 마크업 생성

스키마가 없으면 AI가 백그라운드에서 페이지의 구조화된 데이터를 생성해요. 이 과정은 병렬로 처리되며 발행을 지연시키지 않아요.

4단계

페이지에 스키마 추가

생성된 스키마 마크업이 자동으로 페이지에 추가되어, 게시되는 순간부터 구조화된 데이터를 갖게 돼요.

중요

기존 스키마는 절대 덮어쓰지 않아요. 자동 생성은 발행 시점에 페이지에 스키마 마크업이 없을 때만 실행됩니다.

## 신규 및 기존 자산의 기본 동작

스키마 마크업 자동 생성은 웹사이트, 퍼널, 웨비나가 생성된 시점에 따라 기본 설정이 다르게 적용돼요.

기존 자산

이번 릴리스 이전에 생성된 경우

스키마 마크업 자동 생성은 기본값이 **꺼짐(OFF)** 이에요. 직접 설정을 활성화하지 않는 이상 아무것도 변경되지 않아요. 기존 스키마와 발행 동작은 그대로 유지됩니다.

신규 자산

이번 릴리스 이후에 생성된 경우

스키마 마크업 자동 생성은 기본값이 **켜짐(ON)** 이에요. 스키마 없이 발행된 페이지는 자동으로 AI 생성 구조화 데이터를 받게 돼요. 설정(Settings)에서 언제든지 이 기능을 비활성화할 수 있어요.

자산별 개별 제어

스키마 마크업 자동 생성은 각 웹사이트, 퍼널, 웨비나마다 개별적으로 설정돼요. 설정(Settings)의 SEO & AEO 섹션에서 자산별로 활성화 또는 비활성화할 수 있습니다.

## 스키마 마크업 자동 생성 활성화 방법

기존 웹사이트, 퍼널, 웨비나에서 스키마 마크업 자동 생성을 활성화하려면 다음 단계를 따라주세요.

1단계

사이트(Sites)로 이동

왼쪽 사이드바에서 **사이트(Sites)** 를 클릭하세요. 설정하려는 자산 유형에 따라 **퍼널(Funnels)**, 웹사이트(Websites) 또는 웨비나(Webinar) 탭을 선택하세요.

![](https://jumpshare.com/share/iLgB1uPDKXvnW28Xcitw+/Screen+Shot+2026-07-29+at+23.41.34.png)

2단계

자산 편집

자산 **이름** 또는 옆에 있는 **점 세 개(⋮)** 메뉴를 클릭한 다음 **편집(Edit)** 을 선택하세요.

![](https://jumpshare.com/share/hhQ2Thl15JveVQA4Mihq+/Screen+Shot+2026-07-29+at+23.43.22.png)

3단계

설정(Settings)으로 이동

자산 편집기에서 **설정(Settings)** 탭을 클릭하세요.

![](https://jumpshare.com/share/IVzCuL4YGv8GG2pJpzhT+/Screen+Shot+2026-07-29+at+23.45.04.png)

4단계

토글 활성화

**SEO & AEO** 섹션 아래에 있는 **스키마 자동 생성(Auto-generate schema)** 토글을 켜세요. 설명 문구는 다음과 같아요: "발행 시 스키마 마크업이 없는 페이지에 자동으로 스키마 마크업을 추가합니다."

![](https://jumpshare.com/share/NBduj9vl9HzSqEETyCYU+/Screen+Shot+2026-07-29+at+23.46.53.png)

5단계

변경사항 저장

설정 페이지 하단의 **저장(Save)** 을 클릭해서 변경사항을 적용하세요.

![](https://jumpshare.com/share/ie80dNHNGjUfPlkJKpKh+/Screen+Shot+2026-07-29+at+23.48.08.png)

완료

이제 스키마 마크업 자동 생성이 활성화되었어요. 스키마 없이 발행된 페이지는 자동으로 AI 생성 구조화 데이터를 받게 됩니다.

## 자주 묻는 질문

Q: 자동 생성된 스키마가 제 페이지의 기존 스키마를 덮어쓰나요?

아니요. 스키마 마크업 자동 생성은 발행 시점에 스키마가 없는 페이지에만 마크업을 추가해요. 페이지에 이미 스키마 마크업이 있다면 하이퍼클래스는 이를 그대로 둡니다.

Q: 자동 생성이 발행을 지연시키나요?

아니요. 스키마 생성은 발행과 병렬로 백그라운드에서 실행돼요. 페이지는 즉시 게시되고, 스키마는 지연 없이 추가됩니다.

Q: 어떤 유형의 자산에서 스키마 마크업 자동 생성을 사용할 수 있나요?

스키마 마크업 자동 생성은 웹사이트, 퍼널, 웨비나에서 사용할 수 있어요. 각 자산의 설정(Settings) 안 SEO & AEO 섹션에서 개별적으로 활성화할 수 있습니다.

Q: 기존 웹사이트와 퍼널에서는 스키마 마크업 자동 생성이 기본으로 활성화되어 있나요?

아니요. 이번 릴리스 이전에 생성된 자산은 기본값이 **꺼짐(OFF)** 이에요. 직접 설정을 활성화하지 않는 이상 아무것도 변경되지 않아요. 릴리스 이후 생성된 자산은 기본값이 **켜짐(ON)** 입니다.

Q: 활성화한 후에 스키마 마크업 자동 생성을 다시 끌 수 있나요?

네. 설정(Settings)의 SEO & AEO 섹션에서 언제든지 스키마 마크업 자동 생성을 켜거나 끌 수 있어요. 변경 후에는 반드시 **저장(Save)** 을 클릭해주세요.

Q: 스키마 마크업 자동 생성이 SEO와 AEO에 어떻게 도움이 되나요?

스키마 마크업은 검색 엔진이 콘텐츠를 이해하고 별점, FAQ, 이벤트 정보 같은 리치 결과를 표시하는 데 도움을 줘요. 또한 ChatGPT, Perplexity, Gemini 같은 AI 답변 엔진이 콘텐츠를 정확하게 인용하고 참조하는 데 도움을 줘서 AI 생성 답변에서의 노출을 개선해줍니다.

Q: 버전 기록(Version History)에서 발행할 때도 스키마 마크업 자동 생성이 작동하나요?

네. 자동 생성은 빌더 발행(Builder Publish), 저장 기반 발행, 버전 기록 발행을 포함한 모든 페이지별 발행 경로에서 작동해요.

Q: 스키마 마크업 자동 생성을 활성화한 후 기존 페이지에도 별도 작업이 필요한가요?

아니요. 자동 생성은 페이지를 발행할 때만 실행돼요. 다시 발행하지 않는 이상 기존에 게시된 페이지는 변경되지 않아요. 이미 스키마가 있는 경우에는 덮어쓰지 않습니다.
