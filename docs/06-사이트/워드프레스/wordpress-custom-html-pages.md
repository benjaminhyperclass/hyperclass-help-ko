# WordPress 커스텀 HTML 페이지 올리기

빌더 없이 HTML 파일만으로 페이지를 만들고, 미리 보고, 게시하는 방법을 안내해요. 정적 사이트 생성기나 AI 페이지 빌더에서 내보낸 코드, 직접 작성한 HTML을 하이퍼클래스 WordPress 환경에 올려 바로 쓸 수 있어요.

## 커스텀 HTML 페이지란?

커스텀 HTML 페이지는 .html 파일 하나를 하이퍼클래스에서 운영하는 WordPress 사이트에 올려, 연결된 도메인의 실제 페이지로 게시하는 기능이에요. 드래그 앤 드롭 편집기를 쓰지 않고, 어떤 도구에서 만든 코드든 그대로 올릴 수 있어요. 개발자와 에이전시가 코드를 직접 다루면서도 하이퍼클래스 호스팅의 편리함과 보안을 그대로 누릴 수 있어요.

## 커스텀 HTML 페이지의 장점

하이퍼클래스 호스팅의 안정성과 성능은 그대로 두고, 웹사이트 제작 방식을 넓힐 수 있어요.

- 올인원 호스팅: 빌더로 만든 페이지와 코드로 만든 페이지를 같은 WordPress 사이트에서 함께 관리해요.
- 성능 최적화: 정적 HTML 파일은 바로 불러와져 사이트 속도가 빨라요.
- 유연한 연동: AI 도구, 정적 사이트 생성기(SSG), 직접 작성한 HTML 코드와 잘 맞아요.
- 간편한 SSL·도메인 설정: 이미 쓰고 있는 하이퍼클래스 SSL 인증서와 도메인 연결을 그대로 사용해요.
- 앞으로도 쓰기 좋은 구조: 마이크로사이트, 맞춤 랜딩 페이지, 일회성 캠페인 페이지에 잘 맞아요.

## 파일 요건과 제한 사항

업로드 전에 아래 요건을 확인하면 게시 오류를 막을 수 있어요.

- 한 번에 .html 파일 하나만 업로드할 수 있어요.
- 최대 파일 크기는 5MB예요.
- 이미지, CSS, JavaScript 파일은 절대 URL로 연결해야 해요(예: CDN이나 미디어 라이브러리 주소).
- 상대 경로와 여러 폴더 업로드는 아직 지원하지 않아요.
- 업로드 한 번이 페이지 하나예요. 여러 페이지가 필요하면 파일마다 따로 업로드하세요.

## WordPress에 커스텀 HTML 페이지 업로드하기

별도의 외부 호스팅 설정 없이 몇 번의 클릭만으로 페이지를 게시할 수 있어요. 아래 순서대로 따라 하면 몇 분 안에 페이지를 열 수 있어요.

### 1단계: WordPress 호스팅으로 이동하기

1. **사이트 > WordPress**로 이동하세요.
2. 아직 활성화하지 않았다면 **Activate WordPress**(WordPress 활성화)를 클릭하세요.

   ![WordPress 활성화 화면](https://jumpshare.com/share/bSdM7fHuQ5ndmosboTsA+/Screen+Shot+2025-11-07+at+12.01.27+AM.png)

### 2단계: 페이지 탭으로 이동하기

1. HTML 파일을 올릴 WordPress 사이트에서 **Manage Website**(웹사이트 관리) 버튼을 클릭하세요.

   ![웹사이트 관리 버튼](https://jumpshare.com/share/lTu1FCashr7S9CNfRRca+/Screen+Shot+2025-11-06+at+9.13.02+PM.png)
2. 화면 위쪽의 **페이지** 탭을 클릭하세요.

   ![페이지 탭](https://jumpshare.com/share/VAKqXtSJ6Hs7wAdOZa02+/Screen+Shot+2025-11-06+at+9.14.58+PM.png)

### 3단계: 새 HTML 페이지 업로드하기

1. **Upload New HTML Page**(새 HTML 페이지 업로드) 버튼을 클릭하세요.

   ![새 HTML 페이지 업로드 버튼](https://jumpshare.com/share/1J4VR8KJQove9uL1ISQ8+/Screen+Shot+2025-11-06+at+9.21.11+PM.png)
2. **페이지 이름**(예: "식료품 페이지")과 **Custom Site Slug**(사용자 지정 사이트 슬러그, 예: /grocery-3)를 입력하세요.
3. 업로드 영역을 클릭해 .html 파일을 선택하세요.

   ![HTML 파일 업로드 영역](https://jumpshare.com/share/40u6HsO7MhfnZ3Ka2W40+/Screen+Shot+2025-11-06+at+10.27.18+PM.png)

### 4단계: 확인하고 미리 본 뒤 게시하기

1. **Confirm & Preview**(확인 및 미리보기)를 클릭해 페이지 레이아웃과 내용을 확인하세요.

   ![확인 및 미리보기 버튼](https://jumpshare.com/share/R6fEwaecvzES6U25B1Ez+/Screen+Shot+2025-11-06+at+11.57.56+PM.png)
2. 페이지를 더 올리려면 **Upload More Pages**(페이지 더 업로드) 버튼을 클릭하세요.
3. 준비가 끝나면 **게시**를 클릭해 HTML 페이지를 공개하세요.

   ![게시 버튼](https://jumpshare.com/share/EFE1zz5PD6nq1jxhn2aX+/image+%2874%29.png)

## 자주 묻는 질문

### 여러 페이지를 한 번에 업로드할 수 있나요?
아니요. 업로드 한 번에 .html 파일 하나만 올릴 수 있어요. 여러 페이지가 들어 있는 ZIP 업로드는 이후 업데이트에서 지원할 예정이에요.

### CSS, 이미지, 스크립트는 어떻게 추가하나요?
CDN이나 WordPress 미디어 라이브러리 같은 외부에 파일을 올려 두고, 절대 URL로 연결하세요. 분석이나 트래킹 픽셀 같은 클라이언트 측 스크립트도 지원해요.

### 업로드한 페이지를 수정할 수 있나요?
하이퍼클래스에서 HTML을 직접 수정할 수는 없어요. 내 컴퓨터에서 HTML 파일을 고친 뒤 새 버전을 업로드해 기존 파일을 교체하세요.

### 이미 올린 페이지를 교체하려면 어떻게 하나요?
WordPress 사이트의 **페이지** 탭을 열고, 페이지 이름 옆의 **Action Menu**(작업 메뉴, ⋮)를 클릭한 다음 **Upload New Version**(새 버전 업로드)을 선택하세요. 기존 파일이 새 파일로 바뀌고, 원래 URL과 설정은 그대로 유지돼요.

### 이 기능을 쓰려면 호스팅 비용이 추가로 드나요?
아니요. 이미 쓰고 있는 하이퍼클래스 WordPress 호스팅 요금제에 포함되어 있어요.
