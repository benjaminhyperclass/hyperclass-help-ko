# WordPress에서 커스텀 값 사용하기

하이퍼클래스 WordPress 플러그인의 **커스텀 값** 연동을 쓰면 하이퍼클래스의 최신 데이터를 WordPress 페이지나 글에 숏코드로 보여 줄 수 있어요. 퍼널, 이메일, 자동화에서 쓰던 개인화 기능을 WordPress에서도 그대로 쓸 수 있고, 코딩이나 복잡한 설정은 필요 없어요.

## WordPress의 커스텀 값이란?

하이퍼클래스 서브 계정의 *key:value* 쌍(시스템 값과 직접 만든 값)을 WordPress 숏코드로 쓸 수 있게 동기화하는 기능이에요.

방문자가 페이지를 열면 플러그인이 최신 데이터를 자동으로 가져와요. 콘텐츠를 직접 고치지 않아도 항상 최신 상태로 유지돼요.

![WordPress에서 커스텀 값을 사용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055562835/original/IEUOx-L1w_JNUDMJSTd6AzdFhvfLTXBE0A.png?1759961095)

## 주요 장점

- 모든 채널에서 일관된 정보: 자동화, 이메일, 웹사이트에서 같은 데이터를 써요.
- 실시간 업데이트: 하이퍼클래스에서 값을 한 번만 바꾸면 WordPress에도 바로 반영돼요.
- 노코드 설정: 코드를 고치는 대신 숏코드를 붙여 넣기만 하면 돼요.
- 재사용 가능한 템플릿: 동기화할 때 자동으로 채워지는 자리표시자를 넣어 고객 사이트를 만들 수 있어요.
- 매끄러운 연동: WordPress가 하이퍼클래스 생태계의 일부가 돼요.

## 하이퍼클래스와 기본 동기화

플러그인은 보안 OAuth 방식으로 WordPress 사이트와 하이퍼클래스 서브 계정을 연결해요. 승인이 끝나면 다음과 같이 동작해요.

- 시스템 커스텀 값과 직접 만든 커스텀 값을 모두 가져와요.
- 가져온 값을 사이트 안에 저장해 빠르게 불러와요.
- 12시간마다 자동으로 다시 동기화해요. **Sync Now**(지금 동기화)로 직접 동기화할 수도 있어요.

그래서 따로 동기화하지 않아도 WordPress의 데이터가 하이퍼클래스 계정과 같은 상태로 유지돼요.

## WordPress에서 숏코드 사용하기

숏코드를 쓰면 페이지 빌더, 블록, 클래식 글 등 WordPress 콘텐츠 어디에든 실시간 데이터를 보여 줄 수 있어요.

**형식:**

```
[hl_custom_value name="custom_values.your_key"]
```

**예시:**

```
Wish You a Very [hl_custom_value name="custom_values.festive_greeting"]
```

![WordPress 페이지에 숏코드를 넣은 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055562839/original/N08SHblr1WdL7Yy4LhsF4AQ5bmm3xjOsaA.png?1759961130)

Elementor, Divi, Bricks, Beaver Builder, Gutenberg, Classic Editor 등 WordPress 기본 숏코드를 지원하는 빌더라면 어디서든 쓸 수 있어요.

## 커스텀 값 관리자 (WP 관리자 화면)

WordPress 안에서 하이퍼클래스 **커스텀 값** 섹션을 열면 동기화된 키를 확인하고 관리할 수 있어요.

이 화면에서 할 수 있는 일은 다음과 같아요.

- 동기화된 커스텀 값과 현재 데이터를 하나씩 확인해요.
- 클릭 한 번으로 숏코드를 복사해요.
- 직접 다시 동기화하거나 자동 동기화를 켜요.
- 하이퍼클래스의 폴더 구조와 같은 폴더별로 필터링해요.

동기화된 모든 데이터를 WordPress 대시보드에서 바로 정리하고 찾을 수 있어요.

## 동적 렌더링과 페이지 출력

방문자가 페이지를 열면 플러그인이 커스텀 값을 실시간으로 불러와 보여 줘요.

캐싱 플러그인을 쓰고 있다면 알맞은 캐시 규칙을 적용하지 않는 한 예전 데이터가 보일 수 있어요.

권장 사항:

- 캐싱을 쓰고 있다면 **Purge cache on resync**(재동기화 시 캐시 비우기)를 켜세요.
- 연락처별 값을 보여 주는 페이지는 캐시하지 마세요.
- 하이퍼클래스에서 값을 수정한 뒤에는 항상 다시 동기화하세요.

![캐시 설정과 페이지 출력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055562869/original/WKGPdC6c-hXDD7rPHW9xvTsOChaDHjGJZw.png?1759961240)

## 설정 방법

WordPress 사이트를 하이퍼클래스와 연결하려면 플러그인 버전이 3.5.0 이상이어야 해요.

1. WordPress 관리자 화면에서 하이퍼클래스 설정을 열어요.
2. **Connect Account**(계정 연결)를 선택해요.
3. 하이퍼클래스 로그인을 승인해요.
4. 사용할 서브 계정을 선택하고 접근 권한을 허용해요.
5. 연결이 끝나면 플러그인이 자동으로 동기화해요. **연결 대상**이라는 문구와 함께 연결 확인 메시지가 표시돼요.
6. 동기화가 끝나면 하이퍼클래스의 **커스텀 값** 섹션을 열어 데이터를 가져왔는지 확인해요.
7. 숏코드를 복사해 사용하는 빌더로 페이지나 글에 붙여 넣어요.
8. 게시하면 WordPress 콘텐츠에 동기화된 하이퍼클래스 데이터가 실시간으로 표시돼요.

## 자주 묻는 질문

### 연락처별 값도 쓸 수 있나요?
네. 방문자가 쿠키나 URL 파라미터로 추적되는 경우에는 쓸 수 있어요.

### 사이트가 느려지지 않나요?
느려지지 않아요. 값은 사이트 안에 저장되어 있고, 동기화할 때만 새로 고쳐져요.

### 서브 계정을 여러 개 연결할 수 있나요?
WordPress 설치 하나당 서브 계정 하나만 연결할 수 있어요. 고객이 여러 명이라면 멀티사이트를 사용하세요.

### 하이퍼클래스에서 값을 삭제하면 어떻게 되나요?
다시 동기화하거나 다른 값으로 바꾸기 전까지는 빈칸으로 표시돼요.

### 누가 연결을 승인할 수 있나요?
서브 계정에 대한 API 접근 권한이 있는 하이퍼클래스 사용자만 WordPress를 연결할 수 있어요.
