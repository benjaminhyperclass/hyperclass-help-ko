# WordPress 디스크 공간 애드온

WordPress 호스팅 플랜을 바꾸지 않고도 25GB 단위로 저장 공간을 추가할 수 있어요. 이 문서에서는 디스크 공간 애드온을 구매하고, 관리하고, 사용량을 확인하는 방법을 안내해요. 에이전시 관리자만 쓸 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## WordPress 호스팅의 디스크 공간 애드온이란?

디스크 공간 애드온을 쓰면 플랜을 업그레이드하지 않고도 필요할 때마다 WordPress 저장 공간을 25GB씩 늘릴 수 있어요. 사이트가 커지는 만큼 용량을 알맞게 조정할 수 있어서, 성능이 끊기지 않고 요금도 예측하기 쉬워요.

{% hint style="info" %}
추가한 저장 공간은 에이전시의 모든 서브 계정에 있는 WordPress 사이트가 함께 사용해요.
{% endhint %}

## 디스크 공간 애드온의 장점

- **유연한 확장**: 필요한 때에 맞춰 25GB 단위로 저장 공간을 늘릴 수 있어요.
- **플랜과 별개로 확장**: 호스팅 플랜 전체를 업그레이드하지 않아도 용량을 늘릴 수 있어요.
- **중단 없는 운영**: 공간이 부족해서 업로드, 백업, 업데이트가 멈추는 일을 막을 수 있어요.
- **한곳에서 관리**: **에이전시 > 재판매 > WordPress > 관리**에서 애드온과 사용량을 확인할 수 있어요.
- **명확한 요금**: 25GB당 월 $12예요. 필요한 만큼 여러 블록을 추가할 수 있어요.
- **안전한 관리**: 사용하지 않는 애드온은 25GB 이상 비어 있을 때만 비활성화할 수 있어서, 실수로 용량이 모자라는 일을 막아 줘요.

## WordPress 호스팅에 디스크 공간 추가하기

아래 순서대로 용량을 안전하게 추가하세요. 대규모 업데이트나 마이그레이션을 하기 전에 추가한 저장 공간이 반영됐는지 확인하는 것이 좋아요.

1. 에이전시 계정으로 로그인하세요.
2. **재판매 > WordPress > 관리**로 이동하세요.

   ![재판매 > WordPress > 관리 화면](https://jumpshare.com/share/nL9tI1yAybCgTGFg4v6p+/Screen+Shot+2025-10-27+at+7.46.09+PM.png)
3. **애드온** 탭을 클릭하세요.
4. **quantity**(수량)를 설정하세요. 수량 1개는 디스크 공간 25GB이고, 월 $12예요.

   ![애드온 수량 설정 화면](https://jumpshare.com/share/g0Btw9oLymXF6nB9B2Z2+/Screen+Shot+2025-10-27+at+7.53.55+PM.png)
5. **애드온 활성화** 버튼을 클릭하세요.

   ![애드온 활성화 버튼](https://jumpshare.com/share/ZPefodwsIkRCRRdOsXm4+/Screen+Shot+2025-10-27+at+7.55.15+PM.png)
6. 확인 체크박스를 선택한 뒤 **계속**을 클릭하세요.

   ![확인 체크박스와 계속 버튼](https://jumpshare.com/share/6CX133ztELsBs3iHlTvz+/Screen+Shot+2025-10-27+at+7.56.54+PM.png)
7. 추가한 디스크 공간과 그중 사용 중인 용량이 **애드온** 화면에 표시돼요.

   ![추가한 디스크 공간과 사용량 화면](https://jumpshare.com/share/WjBiLKhw58CAP30GpzQH+/Screen+Shot+2025-10-27+at+7.59.33+PM.png)
8. 나중에 쓰지 않는 용량을 줄이려면, 사용하지 않는 공간이 25GB 이상인지 확인한 뒤 **애드온 비활성화**를 클릭하세요.
9. **All or Particular Add-ons**(전체 또는 특정 애드온)를 선택하고 **비활성화**를 클릭하세요.

   ![애드온 비활성화 선택 화면](https://jumpshare.com/share/Jy5vKo07GFPKEPOFGThb+/Screen+Shot+2025-10-27+at+8.03.47+PM.png)

## 자주 묻는 질문

### 저장 공간을 늘리려면 플랜을 업그레이드해야 하나요?

아니요. 디스크 공간 애드온으로 25GB 단위로 구매할 수 있고, 지금 쓰는 플랜은 그대로 유지돼요.

### 25GB 블록을 여러 개 추가할 수 있나요?

네. 블록을 여러 개 추가해서 필요한 만큼 저장 공간을 늘릴 수 있어요.

### 애드온은 언제 비활성화할 수 있나요?

사용하지 않는 공간이 25GB 이상일 때만 비활성화할 수 있어요. 용량이 거의 찼다면 먼저 공간을 비워 주세요.

### 요금은 얼마인가요?

25GB당 월 $12예요.

### 애드온을 추가하면 사이트의 플랜 한도가 바뀌나요?

플랜을 업그레이드하지 않아도 저장 공간만 늘어나요. 그 외 한도는 선택한 호스팅 플랜에 정해진 그대로예요.
