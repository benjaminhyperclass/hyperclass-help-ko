# WordPress 관리자에서 결제 실패 알림 받기 (이메일·하이퍼클래스 플러그인)

결제가 실패하면 하이퍼클래스 플러그인이 WordPress 관리자 대시보드에 바로 알림을 띄워 줘요. 결제 문제를 빠르게 확인하고 해결해서 서비스가 끊기지 않게 할 때 활용하세요.

## WordPress 관리자의 결제 실패 알림이란?

결제가 실패할 때마다 WordPress 관리자 대시보드에 상황을 알려 주는 하이퍼클래스 기능이에요. 하이퍼클래스 플러그인을 통해 실시간으로 알림을 보여 주므로, 작업하던 화면을 떠나지 않고 결제 문제를 해결할 수 있어요.

알림은 wp-admin 화면 안에 눈에 잘 띄게 표시돼요. 미납 인보이스 때문에 사이트에 문제가 생기는 일을 줄이려면 바로 조치하세요.

## 주요 장점

결제 문제를 바로 확인하고 조치할 수 있어서, 서비스가 중단되는 상황을 막는 데 도움이 돼요.

- 즉시 확인: 결제가 실패하는 즉시 대시보드에 알림이 표시돼요.
- 3일 유예 기간: 결제 문제를 해결하는 동안에도 사이트를 그대로 쓸 수 있어요.
- 반복 알림: 알림을 잠시 닫아도 문제가 해결될 때까지 다시 나타나요.
- 간편한 연동: 하이퍼클래스 플러그인만 있으면 별도 설정이 거의 필요 없어요.
- 해지·중단 감소: 빠른 해결을 유도해 서비스가 계속 유지되도록 도와요.

## 유예 기간 처리

결제 문제를 고치는 데 3일의 여유를 주는 방식이에요. 이 기간에는 사이트 접속에 영향이 없어서, 서비스가 갑자기 끊기지 않으면서도 계정을 제때 관리하도록 유도해요.

- 알림은 결제 실패 후 3일 동안 표시돼요.
- 이 기간에는 사이트를 문제없이 이용할 수 있어요.
- 3일이 지나도 문제가 해결되지 않으면 사이트 잠금이 적용돼요.
- 서비스가 갑자기 중단되지 않으면서 조치를 유도해요.

## 알림 닫기와 재표시

해결되지 않은 문제를 계속 알려 주되, 작업을 방해하지 않도록 만든 기능이에요. 알림을 잠시 숨길 수는 있지만, 문제가 해결될 때까지 다시 나타나요.

- 알림을 잠시 닫아 방해를 줄일 수 있어요.
- 페이지를 새로고침하거나 다음에 로그인하면 알림이 다시 나타나요.
- 결제 실패가 해결될 때까지 계속 표시돼요.
- 문제를 빠르게 해결하도록 책임감을 높여 줘요.

## 결제 실패 이메일 알림 일정

WordPress 호스팅 결제가 실패하면, 시스템이 시간이 지날수록 긴급도가 높아지는 이메일을 자동으로 보내요. 21일이 지나도 결제되지 않으면 WordPress 구독이 자동으로 취소되고 웹사이트가 삭제돼요.

{% hint style="info" %}
이 알림은 자동으로 발송돼요. 고객지원팀이 수동으로 처리할 필요가 없어요.
{% endhint %}

일정은 다음과 같아요.

- 1일 차: WordPress 결제 기한 경과 ⏳
- 3일 차: 안내: 접근 제한
- 7일 차: 최종 안내: WordPress 사이트 호스팅 결제가 필요해요
- 14일 차: WordPress 사이트 호스팅에 즉시 조치가 필요해요 ⛔
- 21일 차: WordPress 구독이 취소되었어요 (구독이 취소되고 웹사이트가 삭제돼요) ❌

## 결제 실패 알림 설정하기

아래 순서대로 확인하면 WordPress 관리자 대시보드에서 결제 실패 알림을 받을 수 있어요.

1. WordPress 관리자 대시보드에 로그인하세요.

   ![WordPress 관리자 로그인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051535356/original/uEK2yRnvrwy2qL0c-D4SHOQwv-B_Sq7wXQ.png?1755091285)
2. **플러그인 > Installed Plugins**(설치된 플러그인)로 이동해, 하이퍼클래스 플러그인이 설치되고 활성화되어 있는지 확인하세요.

   ![설치된 플러그인 목록에서 하이퍼클래스 플러그인 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051536217/original/wk8cVCJEQDIseyyQnXmqWPhgmn_sfURB-w.png?1755091535)
3. 이후에는 따로 설정할 것이 없어요. 결제가 실패하면 알림이 자동으로 표시돼요.

   ![결제 실패 시 표시되는 알림 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051536379/original/P3Z1r8Te4uAXwR0bKpwkwR4eja9GvH2qTw.png?1755091593)

## 자주 묻는 질문

### 결제 실패 알림은 어떤 기능인가요?
결제가 실패하면 WordPress 관리자 화면에 알림을 표시해서 바로 조치하도록 안내해 줘요.

### 사이트가 잠기기 전 유예 기간은 얼마나 되나요?
3일이에요. 이 기간에는 사이트를 계속 사용할 수 있어서 문제를 해결할 시간이 있어요.

### 알림을 닫으면 계속 닫힌 상태로 유지되나요?
아니요. 문제가 해결될 때까지 페이지를 새로고침하거나 다음에 로그인할 때 알림이 다시 나타나요.

### 이 기능을 쓰려면 무엇이 필요한가요?
WordPress 사이트에서 하이퍼클래스 플러그인이 활성화되어 있어야 해요.

### 알림 메시지를 원하는 대로 바꿀 수 있나요?
알림은 명확하게 전달되도록 표준 문구로 제공돼요. 현재는 메시지를 바꾸는 기능이 제한적이에요.
