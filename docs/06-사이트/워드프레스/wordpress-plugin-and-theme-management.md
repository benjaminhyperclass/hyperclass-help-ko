# WordPress 플러그인·테마 관리

하이퍼클래스에서 설치된 WordPress 플러그인과 테마를 바로 관리할 수 있어요. 버전을 확인하고, 업데이트할 수 있는 항목은 업데이트하고, 항목을 활성화·비활성화·삭제할 수 있어요.

일상적인 변경 작업은 WordPress 관리자 화면을 열지 않고 하이퍼클래스에서 처리할 수 있어요.

## 이런 점이 편해요

플러그인과 테마를 한곳에서 관리하면 WordPress 유지 관리가 더 빠르고 쉬워져요.

- 설치된 플러그인과 테마를 하이퍼클래스에서 한꺼번에 관리해요.
- 현재 버전과 사용 가능한 버전을 비교해 볼 수 있어요.
- 지원되는 플러그인과 테마를 최신 버전으로 빠르게 업데이트해요.
- WordPress 설정이 더 필요하면 **WP Admin**(WordPress 관리자)을 사용하세요.
- 변경 사항을 **라이브**에 게시하기 전에 **스테이징**에서 먼저 테스트할 수 있어요.

---

## 플러그인·테마 작업

작업마다 설치된 플러그인이나 테마에 미치는 영향이 달라요. 원하는 결과에 맞는 작업을 고르세요.

- **활성화**: 설치된 항목을 켜요.
- **비활성화**: 항목을 삭제하지 않고 꺼요.
- **삭제**: 설치된 항목을 제거해요.
- **업데이트**: 항목을 사용 가능한 최신 버전으로 업데이트해요.

  버전 정보를 보면 어떤 플러그인이나 테마를 업데이트해야 하는지 알 수 있어요.

  - **현재 버전**: 내 사이트에 설치된 버전이에요.
  - **Available Version**(사용 가능한 버전): 받을 수 있는 최신 버전이에요.

하이퍼클래스는 이 대시보드에서 플러그인이나 테마를 이전 버전으로 되돌리는 기능을 지원하지 않아요.

## 새 WordPress 플러그인 설치

이 관리 대시보드는 이미 설치된 확장 기능을 관리하는 용도예요. 새 플러그인은 아래처럼 다른 방법으로 추가해야 해요.

- WordPress 사이트를 만들 때 지원되는 플러그인을 선택해요.
- 기본 WordPress의 **플러그인 > 새로 추가**에서 플러그인을 추가로 설치해요.
- 설치한 뒤에는 하이퍼클래스에서 관리해요.

## 라이브와 스테이징 환경

**스테이징**에서는 실제 웹사이트와 분리된 곳에서 플러그인과 테마 변경을 테스트할 수 있어요. 큰 업데이트를 하거나 사이트 동작 문제를 점검할 때 위험을 줄일 수 있어요.

**스테이징**에서 한 변경은 스테이징을 **라이브**에 게시하기 전까지 실제 사이트에 영향을 주지 않아요. **라이브** 환경에서 한 변경은 운영 중인 사이트에 바로 반영돼요.

## 플러그인과 테마 관리하기

아래 순서대로 하면 원하는 사이트와 환경에서 정확하게 변경할 수 있어요.

1. **사이트 > WordPress**로 이동해요. 관리할 WordPress 사이트에서 **Manage Site**(사이트 관리)를 클릭해 사이트를 열어요.

   ![사이트 관리 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080399129/original/0qIAfh3_zfC6MIvTtwsnCBmUh4iQUfrg2g.png?1788880485)
2. **라이브**와 **스테이징** 중 어느 환경에서 작업 중인지 확인해요.

   ![라이브와 스테이징 환경 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080399420/original/UYU1dCq2D8WwIztYSwmiJkLziI33b-GtCg.png?1788880626)
3. **플러그인** 또는 **테마**를 열고, 관리할 항목을 찾아요.
4. **현재 버전**과 **Available Version**을 확인해요.
5. 새 버전이 있으면 항목을 업데이트해요.
6. 작업 메뉴를 열어 항목을 **활성화**, **비활성화**, **삭제**해요.

   ![작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080399666/original/0KxoeeVOzqGQ5QAD-szVttlhOocIDerH6Q.png?1788880733)
7. 변경한 뒤에는 웹사이트가 잘 보이는지 확인해요.

## 자주 묻는 질문

### 이 대시보드에서 새 플러그인을 설치할 수 있나요?
아니요. 새 플러그인은 사이트를 만들 때 선택하거나 기본 WordPress에서 설치하세요.

### 플러그인이나 테마를 이전 버전으로 되돌릴 수 있나요?
아니요. 하이퍼클래스 관리 대시보드에서는 사용 가능한 최신 버전으로 업데이트하는 것만 지원해요.

### 플러그인 때문에 사이트에 문제가 생기면 어떻게 하나요?
[WordPress 플러그인 문제 해결 도구](how-to-use-the-wordpress-plugin-troubleshooter.md)를 사용하거나, 사용할 수 있는 백업으로 사이트를 복원하세요.

### 스테이징에서 한 변경이 바로 라이브 사이트에 반영되나요?
아니요. 스테이징을 라이브에 게시하기 전까지는 스테이징 변경 사항이 따로 유지돼요.

### 기본 WordPress에서도 플러그인과 테마를 관리할 수 있나요?
네. **WP Admin** 버튼을 눌러 기본 WordPress 대시보드로 들어가세요.

### 특정 플러그인을 쓸 수 없는 이유가 뭔가요?
하이퍼클래스의 WordPress 호스팅 환경에서는 일부 플러그인이 제한돼요. 현재 제한 목록은 [차단된 WordPress 플러그인 목록](list-of-blocked-wordpress-plugins.md)에서 확인하세요.
