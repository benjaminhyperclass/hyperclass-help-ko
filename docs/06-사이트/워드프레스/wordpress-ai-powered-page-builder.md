# WordPress AI 페이지 빌더로 랜딩 페이지 만들기

하이퍼클래스에서 AI로 WordPress 랜딩 페이지를 빠르게 만들 수 있어요. 이 문서에서는 페이지를 생성하고, 내용과 스타일을 다듬고, Elementor에서 이어서 편집하는 방법을 안내해요.

## AI 기반 WordPress 페이지 빌더란?

AI 기반 WordPress 페이지 빌더는 하이퍼클래스 안에서 AI로 WordPress 랜딩 페이지를 생성하는 기능이에요. 새로 생성한 AI 페이지는 기본적으로 **임시 저장** 상태로 만들어져요. 그래서 게시하기 전에 내용을 확인하고, 사용자 지정하고, 미리 볼 수 있어요. 페이지가 준비되면 게시하고, 나중에 내려야 할 때는 게시를 취소할 수 있어요.

{% hint style="warning" %}
AI 페이지의 임시 저장 및 미리보기 모드를 쓰려면 하이퍼클래스 플러그인 4.0.3 버전 이상이 필요해요.
{% endhint %}

## AI 기반 WordPress 페이지 빌더 사용하기

처음에 설정을 꼼꼼히 해 두면 더 나은 초안을 만들 수 있고, AI에게 방향을 더 잘 알려 줄 수 있어요. 페이지를 생성한 뒤 수정하는 속도도 빨라져요.

1. **사이트 > WordPress > All Sites**(전체 사이트)로 이동하세요.

   ![사이트 목록 화면](https://jumpshare.com/share/CRMKdeovNN6jb4ZPPIqz+/Screen+Shot+2026-03-30+at+16.43.03.png)
2. **Manage Website**(웹사이트 관리)를 클릭하세요.

   ![웹사이트 관리 버튼](https://jumpshare.com/share/zSh7zyeDN0jpNIRgfsCR+/Screen+Shot+2026-03-30+at+16.45.09.png)
3. **페이지**로 이동하세요.
4. **AI Generated Pages**(AI 생성 페이지)를 선택하세요.
5. **Generate New AI Page**(새 AI 페이지 생성)를 클릭하세요.

   ![새 AI 페이지 생성 버튼](https://jumpshare.com/share/4MF1FH8siMxkqnq0omEd+/Screen+Shot+2026-03-30+at+16.46.50.png)
6. 페이지 정보를 입력하세요.

   - **페이지 이름**을 입력하세요.
   - **Custom Site Slug**(사용자 지정 사이트 슬러그)를 입력하세요.
   - **사업체명**을 입력하세요.
   - **다음**을 클릭하세요.

     ![페이지 정보 입력 화면](https://jumpshare.com/share/MUanHQ3qSfrMTTVANMQh+/Screen+Shot+2026-03-30+at+16.50.26.png)
7. 디자인 취향을 선택하세요.

   - 사업 분야를 선택하세요.
   - 사업 목표를 선택하세요.
   - 콘텐츠가 어떤 느낌이면 좋을지 선택하세요.
   - **다음**을 클릭하세요.

     ![디자인 취향 선택 화면](https://jumpshare.com/share/Cw6xkjOB4GqS4WToh8if+/GIF+Recording+2026-03-30+at+16.53.05.gif)
8. 만들고 싶은 페이지를 설명하세요. AI가 만들 페이지의 종류를 일상적인 말로 적으면 돼요. 혜택, 섹션, 서비스, 브랜드 스타일, 콜투액션 같은 중요한 내용을 함께 적어 주세요.
   하이퍼클래스가 프롬프트를 다듬어 주길 원하면 **즉흥 대응**을 클릭하세요.
9. **페이지 생성**을 클릭하세요.

   ![페이지 생성 화면](https://jumpshare.com/share/epLrldYhO0PeuMqZwEvA+/GIF+Recording+2026-03-30+at+17.02.56.gif)
10. 생성된 페이지를 확인하세요. 새로 생성한 AI 페이지는 기본적으로 **임시 저장** 상태라서, 게시하기 전에 확인하고 사용자 지정할 수 있어요.
11. **사용자 지정** 패널에서 내용과 스타일을 수정하세요.
12. 콘텐츠 수정 옵션은 다음과 같아요.

    - 편집기에서 생성된 문구를 바로 수정할 수 있어요.
    - 선택한 문구를 개선하려면 **다듬기**를 사용하세요.
    - 가능한 경우 **줄이기**나 **Elaborate**(늘리기) 같은 다시 쓰기 옵션을 쓸 수 있어요.
    - **Change Tone**(어조 변경)으로 콘텐츠의 말투를 조정하세요.
13. 선택할 수 있는 어조는 다음과 같아요.

    - **Professional**(전문적)
    - **Friendly**(친근한)
    - **Compelling**(설득력 있는)
    - **Confident**(자신감 있는)
14. AI가 생성한 이미지를 바꾸려면 다음과 같이 하세요.

    1. 바꾸고 싶은 이미지 위에 마우스를 올리세요.
    2. **Regenerate Image**(이미지 재생성)를 클릭하세요.
    3. **Generate custom image**(사용자 지정 이미지 생성) 창에서 다음 중 하나를 선택하세요.

       - **AI로 생성**: **Describe your vision**(원하는 모습 설명)에 원하는 이미지를 설명한 다음 **재생성**을 클릭하세요.
       - **이미지 업로드**: 내 기기에서 이미지를 선택하세요. 지원 형식은 JPEG, PNG, WebP, GIF이고, 최대 10MB까지 올릴 수 있어요.
    4. **실시간 미리보기**에서 교체할 이미지를 확인하세요.
    5. **이미지 삽입**을 클릭하면 선택한 이미지가 교체돼요.
    6. **변경사항 저장**을 클릭해 수정 내용을 적용하세요.

       페이지 전체를 다시 생성하지 않고 이미지를 하나씩 교체할 수 있어요.

       ![이미지 교체 과정](https://jumpshare.com/share/6ErmsL5E3n9XlglCdGLL+/GIF+Recording+2026-10-13+at+16.46.17.gif)
15. 스타일 옵션은 다음과 같아요.

    - **사용자 지정** 안의 **스타일** 탭을 여세요.
    - **기본**, **Marine**(마린), **Nature**(네이처), **어스** 같은 **색상 팔레트** 중에서 고르세요.
    - 제목, 본문 텍스트, 버튼, 배경, 강조 색상에 팔레트 변경이 어떻게 적용되는지 실시간으로 미리 볼 수 있어요.
    - 스타일 변경을 적용하려면 **Update Page**(페이지 업데이트)를 클릭하세요.
16. 필요에 따라 **변경사항 저장**, **Update Page**(페이지 업데이트), **Save & View**(저장 후 보기)를 클릭하세요.

    ![저장 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083199888/original/3ASxfCPnFnONf-G6PlWBtI3hnXOFLATo6w.png?1791895388)
17. Elementor에서 페이지를 이어서 편집하려면 **Edit on Elementor**(Elementor에서 편집)를 클릭하세요.

    ![Elementor에서 편집 버튼](https://jumpshare.com/share/GXF5yFNzod07lxgMMqMe+/Screen+Shot+2026-03-30+at+17.41.05.png)

## AI 생성 페이지 미리보기, 게시, 게시 취소

AI가 생성한 페이지는 기본적으로 **임시 저장** 상태로 남아 있어요. 그래서 웹사이트에 공개되는 시점을 직접 정할 수 있어요.

1. 페이지가 **임시 저장** 상태일 때 내용을 확인하고 사용자 지정하세요.
2. **AI Generated Pages**(AI 생성 페이지)에서 임시 저장 페이지의 점 3개 메뉴를 열고 **Preview Page**(페이지 미리보기)를 선택해 게시 전에 확인하세요.
3. 페이지가 준비되면 점 3개 메뉴에서 **게시**를 선택하세요. 페이지 미리보기에서 **저장 후 게시**를 클릭해도 돼요.
4. 게시한 AI 페이지를 내리려면 **게시 취소**를 사용하세요.

![AI 페이지 게시 및 게시 취소 과정](https://jumpshare.com/share/WBQ3fzuzFv06BidrSLDp+/GIF+Recording+2026-10-13+at+18.18.50.gif)

{% hint style="warning" %}
임시 저장, 미리보기, 게시, 게시 취소 기능을 쓰려면 하이퍼클래스 플러그인 4.0.3 버전 이상이 필요해요.
{% endhint %}

## AI 생성 페이지에 피드백 남기기

AI가 생성한 WordPress 페이지를 평가하고 의견을 남길 수 있어요. 남겨 주신 의견은 이후 AI 생성 결과를 개선하는 데 쓰여요.

1. 페이지 미리보기에서 AI가 생성한 WordPress 페이지를 여세요.
2. **Give feedback**(피드백 남기기)을 클릭하세요.
3. **How well does this page match what you had in mind?**(이 페이지가 생각하신 모습과 얼마나 비슷한가요?) 아래에서 평가를 선택하세요.

   - **Not at all**(전혀 아니에요)
   - **A little off**(조금 달라요)
   - **It's okay**(괜찮아요)
   - **Pretty close**(꽤 비슷해요)
   - **Nailed it!**(딱 맞아요!)
4. 원하면 **What could be improved?**(개선할 점이 있나요?)에 의견을 입력하세요.
5. **제출**을 클릭하세요.

남겨 주신 피드백은 AI 페이지 사용 경험을 개선하는 데 도움이 돼요.

![피드백 남기기 과정](https://jumpshare.com/share/6NECIlgp4VGcTKm6pMQB+/GIF+Recording+2026-10-13+at+16.55.37.gif)

## 자주 묻는 질문

### AI가 만든 페이지를 생성한 뒤에도 수정할 수 있나요?
네. **사용자 지정** 패널에서 내용과 스타일을 수정할 수 있고, Elementor에서 이어서 편집할 수도 있어요.

### 새 페이지를 만들 때 AI 페이지가 내 사업체 정보를 기억하나요?
네. AI 페이지는 사업체 정보, 브랜딩, 선호 설정을 WordPress 사이트 단위로 저장해 두고, 이후 페이지를 생성할 때 이 정보를 다시 활용해요.

### AI가 만든 WordPress 페이지에 내 이미지를 올릴 수 있나요?
네. 지원되는 이미지는 JPEG, PNG, WebP, GIF 파일로, 최대 10MB까지 직접 올린 이미지로 교체할 수 있어요. **Regenerate Image > 이미지 업로드**를 선택하고, 파일을 고른 다음 **이미지 삽입**을 클릭하세요.

### AI가 만든 페이지에 피드백을 남길 수 있나요?
네. 페이지 미리보기에서 **Give feedback**을 클릭하고, 평가를 선택한 뒤, 원하면 의견을 적고 **제출**을 클릭하세요.

### 페이지를 생성하기 전에 프롬프트를 개선할 수 있나요?
네. **즉흥 대응**을 사용하면 생성하기 전에 프롬프트를 더 좋게 다듬을 수 있어요.

### 생성된 콘텐츠의 어조를 바꿀 수 있나요?
네. **Professional**, **Friendly**, **Compelling**, **Confident** 같은 어조 옵션으로 콘텐츠의 어조를 바꿀 수 있어요.

### 페이지를 생성한 뒤에 색상을 바꿀 수 있나요?
네. **사용자 지정** 패널의 **스타일** 탭에서 다른 색상 팔레트로 바꿀 수 있어요.

### AI 페이지 생성 크레딧은 몇 개가 포함되어 있나요?
하이퍼클래스는 사이트당 매월 AI 페이지 생성 크레딧 12개를 제공해요.

### 남은 크레딧은 어디에서 볼 수 있나요?
남은 AI 페이지 생성 크레딧은 **AI Generated Pages** 영역에 표시돼요.

### 색상 팔레트를 바꾸면 바로 적용되나요?
팔레트를 둘러보는 동안에는 변경 내용이 실시간으로 미리보기로 보여요. **Update Page**를 클릭해야 변경 내용이 저장돼요.

### AI가 만든 페이지에서 이미지 하나만 다시 생성할 수 있나요?
네. 이미지 위에 마우스를 올리고 **Regenerate Image**를 클릭하세요. 프롬프트를 입력해 미리보기를 생성한 다음 새 이미지를 삽입하면 돼요. 선택한 이미지만 교체돼요.

### 한 페이지에서 섹션 변형을 섞어 쓸 수 있나요?
네. 사용할 수 있는 섹션 변형을 페이지 안에서 자유롭게 섞어 쓸 수 있어요.

### 새로 만든 AI 페이지는 자동으로 게시되나요?
아니요. 새로 만든 AI 페이지는 기본적으로 **임시 저장** 상태로 만들어져요. 게시하기 전에 확인하고 사용자 지정할 수 있어요.

### 게시하기 전에 AI가 만든 페이지를 미리 볼 수 있나요?
네. 게시하기 전에 미리보기로 웹사이트에 어떻게 보일지 확인할 수 있어요.

### 게시한 AI 페이지를 내릴 수 있나요?
네. **게시 취소**를 사용하면 게시한 AI 페이지를 내릴 수 있어요.
