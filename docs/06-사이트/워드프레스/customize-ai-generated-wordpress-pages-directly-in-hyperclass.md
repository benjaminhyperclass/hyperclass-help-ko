# AI로 생성한 WordPress 페이지를 하이퍼클래스에서 바로 수정하기

AI로 생성한 WordPress 페이지의 글과 이미지를 Elementor를 열지 않고 하이퍼클래스 미리보기에서 바로 고칠 수 있어요. 자주 하는 콘텐츠 수정은 여기서 빠르게 끝내고, 디자인을 크게 바꿀 때만 Elementor를 쓰면 돼요.

## 범용 콘텐츠 사용자 지정이란?

범용 콘텐츠 사용자 지정(Universal Content Customization)을 쓰면 AI로 생성한 WordPress 페이지의 일부 콘텐츠를 하이퍼클래스 미리보기에서 바로 편집할 수 있어요. 문구를 바꾸거나 이미지를 교체할 때마다 Elementor로 넘어갈 필요 없이 **사용자 지정** 패널에서 많은 수정을 할 수 있어요.

편집할 수 있는 요소는 다음과 같아요.

- 제목
- 단락
- 버튼
- 아이콘 박스(Icon Box) 제목
- 아이콘 박스 설명
- 이미지

수정할 요소를 선택해서 내용을 직접 바꾸거나, AI 편집 옵션을 쓰고, 결과를 저장하세요. 저장한 내용은 WordPress 페이지에 반영돼요.

{% hint style="warning" %}
범용 콘텐츠 사용자 지정을 쓰려면 하이퍼클래스 WordPress 플러그인 v4.0.4 이상이 필요해요.
{% endhint %}

## 요구 사항

WordPress 연동 버전이 맞아야 이 기능이 제대로 작동해요. 먼저 플러그인 버전을 확인하면 편집 컨트롤이 보이지 않거나 지원되지 않는 동작이 생기는 일을 막을 수 있어요.

필요한 것은 다음과 같아요.

- 하이퍼클래스에 있는 AI로 생성한 WordPress 페이지
- 하이퍼클래스 WordPress 플러그인 v4.0.4 이상

하이퍼클래스를 통해 호스팅하려고 새로 만든 WordPress 사이트에는 플러그인이 자동으로 설치돼요. 플러그인 연결 상태는 하이퍼클래스의 WordPress 영역에서도 확인할 수 있어요.

플러그인을 직접 내려받거나 업데이트해야 한다면 [하이퍼클래스 WordPress 플러그인 허브](wordpress-hyperclass-plugin-hub.md)에서 최신 버전을 받을 수 있어요.

## 편집할 수 있는 콘텐츠 요소

이 기능은 미리 정해진 몇몇 섹션만 고치던 방식보다 편집 범위가 넓어요. 미리보기에서 지원되는 콘텐츠를 바로 선택하면 AI로 생성한 페이지 어디에 있든 문구를 쉽게 고칠 수 있어요.

지원되는 요소는 다음과 같아요.

- 제목: 페이지 제목과 섹션 제목을 바꿀 수 있어요.
- 단락: 긴 설명이나 본문을 수정할 수 있어요.
- 버튼: 지원되는 버튼 내용을 바꿀 수 있어요.
- 아이콘 박스 제목: 아이콘 박스에 달린 제목을 편집할 수 있어요.
- 아이콘 박스 설명: 아이콘 박스 아래의 설명 글을 수정할 수 있어요.
- 이미지: 지원되는 AI 생성 이미지를 다시 생성하거나, 업로드한 이미지로 교체할 수 있어요.

모든 Elementor 요소를 바로 수정할 수 있는 것은 아니에요. 하이퍼클래스 미리보기에서 선택되지 않는 요소는 Elementor에서 편집하세요.

![지원되는 콘텐츠 요소를 보여 주는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079992204/original/FA46BcGuxRUbrE9M-J4_XvjG0plZHNxYiA.png?1788430229)

## 페이지 미리보기에서 텍스트 바로 수정하기

미리보기 화면을 벗어나지 않고 문구를 바로잡거나 사업 정보를 업데이트할 수 있어요. 생성된 문구를 다듬을 때도 편해요. 텍스트를 선택하면 현재 내용이 **사용자 지정** 패널에 열려서 화면을 보면서 바로 고칠 수 있어요.

지원되는 텍스트를 수정하려면 다음 순서로 진행하세요.

1. AI로 생성한 WordPress 페이지 미리보기를 엽니다.
2. 바꾸려는 텍스트 위에 마우스를 올립니다.
3. 지원되는 요소를 클릭합니다.
4. **사용자 지정** 패널에서 선택한 텍스트를 확인합니다.
5. 텍스트를 바꾸거나 수정합니다.
6. 필요하면 변경 내용을 미리 확인합니다.
7. 마음에 들면 **변경사항 저장**을 클릭합니다.

![사용자 지정 패널에서 텍스트를 수정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079992646/original/Re_VTta_mIgryuGYGWwKf9cmogt14KF08g.jpeg?1788430422)

## AI로 텍스트 편집하기

처음부터 새로 쓰지 않아도 AI의 도움으로 기존 문구를 개선할 수 있어요. 페이지 구조는 그대로 두고, 선택한 콘텐츠의 길이·표현·스타일을 조정할 수 있어요.

사용할 수 있는 옵션은 다음과 같아요.

- **다르게 표현**: 선택한 내용을 다른 표현으로 다시 써요.
- **줄이기**: 더 간결한 버전을 만들어요.
- **Elaborate**(내용 늘리기): 기존 텍스트에 세부 내용을 더해요.
- **Change Tone**(어조 변경): 다른 전달 스타일로 다시 써요.

결과를 페이지에 저장하기 전에 먼저 확인할 수 있어요.

![AI 텍스트 편집 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080002864/original/pfL8spCQ5XcZrNV02KvGg4WPLlT_FW7FKQ.png?1788435404)

## 페이지 콘텐츠의 어조 바꾸기

어조를 바꾸면 페이지 문구를 우리 사업의 말투에 맞출 수 있어요. 선택한 텍스트를 직접 다시 쓰지 않고, 미리 정해진 어조 중 하나를 골라 원하는 스타일에 가까운 버전을 만들 수 있어요.

선택할 수 있는 어조는 다음과 같아요.

- **전문적인**
- **친근한**
- **Compelling**(설득력 있는)
- **자신감 있게**

페이지에 가장 잘 맞는 어조를 고른 다음, 생성된 문구를 확인하고 저장하세요.

![어조 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080003423/original/p6R_KYkyFGrKbs3zGok9ykWrRkAYn5SbmA.png?1788435665)

## AI로 생성한 WordPress 페이지 수정하기

아래 순서를 따르면 지원되는 요소를 선택하고, 결과를 확인하고, 변경 내용을 제대로 저장할 수 있어요. 페이지의 다른 텍스트와 이미지에도 같은 방법을 반복하면 돼요.

### 1단계: AI로 생성한 페이지 열기

1. **사이트 > WordPress > All Sites**(전체 사이트)로 이동합니다.
2. 해당 WordPress 사이트를 엽니다.

   ![WordPress 사이트 목록 화면](https://jumpshare.com/share/NOJVS6j7u7CmuYxRCc2Y+/1+%283%29+%281%29.png)
3. **페이지**로 이동합니다.
4. 수정하려는 AI 생성 페이지를 엽니다.

   ![AI로 생성한 페이지 목록 화면](https://jumpshare.com/share/RBGYgCtLBjdkbOYLGFXg+/Screen+Shot+2026-10-13+at+17.41.58.png)

### 2단계: 지원되는 요소 선택하기

1. 페이지 미리보기 위로 마우스를 옮깁니다.
2. 바꾸려는 텍스트나 이미지 위에 마우스를 올립니다.
3. 지원되는 요소를 클릭합니다.
4. 오른쪽에 **사용자 지정** 패널이 열립니다.

![지원되는 요소를 선택해 사용자 지정 패널이 열린 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080004243/original/w6eVcdzdgegD7jzjP8PF_TFa1xZNTiUHPA.jpeg?1788436126)

### 3단계: 콘텐츠 수정하기

텍스트는 다음과 같이 수정해요.

1. 내용을 직접 고치거나 AI 편집 옵션을 선택합니다.
2. 하이퍼클래스가 수정본을 만들어 주길 원하면 **다르게 표현**, **줄이기**, **Elaborate**(내용 늘리기) 중 하나를 사용합니다.
3. 글의 어조를 조정하려면 **Change Tone**(어조 변경)을 사용합니다.
4. 결과를 확인합니다.

![텍스트 수정 결과를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080003791/original/5CTyuUvyDkPSkqIYS4O2RbihMA51PYvgDA.png?1788435859)

### 4단계: 필요하면 이미지 수정하기

지원되는 이미지를 교체하려면 다음 순서로 진행하세요.

1. 페이지 미리보기에서 이미지 위에 마우스를 올립니다.
2. **Regenerate Image**(이미지 다시 생성)를 클릭합니다.
3. 새 이미지를 만들려면 **AI로 생성**을, 가지고 있는 파일을 쓰려면 **이미지 업로드**를 선택합니다.
4. 교체할 이미지를 생성하거나 업로드합니다.
5. **실시간 미리보기**에서 결과를 확인합니다.
6. **이미지 삽입**을 클릭합니다.

![이미지를 다시 생성하거나 업로드해서 교체하는 과정](https://jumpshare.com/share/6ErmsL5E3n9XlglCdGLL+/GIF+Recording+2026-10-13+at+16.46.17.gif)

### 5단계: 변경사항 저장하기

페이지가 마음에 들면 **변경사항 저장**을 클릭하세요.

저장한 내용은 WordPress 페이지에 적용돼요.

### 6단계: 추가 수정은 Elementor에서 하기

하이퍼클래스 미리보기에서 제공하지 않는 편집 기능이 필요하면 **Edit on Elementor**(Elementor에서 편집)를 클릭하고 그곳에서 이어서 수정하세요.

![Elementor에서 편집 버튼이 보이는 화면](https://jumpshare.com/share/YSEA5cS1wHmCTLNJ1nWV+/Screen+Shot+2026-10-13+at+17.36.30.png)

## 자주 묻는 질문

### AI로 생성한 WordPress 페이지의 모든 요소를 편집할 수 있나요?
아니요. 범용 콘텐츠 사용자 지정은 지원되는 요소에만 적용돼요. 하이퍼클래스 미리보기에서 선택하거나 수정할 수 없는 요소는 Elementor에서 편집하세요.

### 그래도 Elementor가 필요한가요?
자주 하는 콘텐츠 수정에는 필요하지 않아요. 지원되는 텍스트와 이미지는 하이퍼클래스에서 바로 수정할 수 있어요. 다만 고급 레이아웃, 스타일링, 지원되지 않는 요소를 편집할 때는 Elementor를 쓸 수 있어요.

### 어떤 버전의 플러그인이 필요한가요?
범용 콘텐츠 사용자 지정에는 하이퍼클래스 WordPress 플러그인 v4.0.4 이상이 필요해요.

### 사용자 지정 컨트롤이 보이지 않아요.
지원되는 AI 생성 WordPress 페이지에서 작업하고 있는지 확인하세요. 하이퍼클래스 WordPress 플러그인이 필요한 버전 이상인지도 확인하세요.

### 생성된 콘텐츠의 어조를 바꿀 수 있나요?
네. 지원되는 텍스트에는 **전문적인**, **친근한**, **Compelling**, **자신감 있게** 같은 어조 옵션을 쓸 수 있어요.

### 이미지 한 장만 다시 생성할 수 있나요?
네. 지원되는 AI 생성 이미지는 페이지 전체를 다시 만들지 않고 하나씩 다시 생성할 수 있어요.

### **Preview Changes**와 **변경사항 저장**은 어떻게 다른가요?
**Preview Changes**(변경사항 미리보기)로는 수정을 확정하기 전에 업데이트된 페이지를 확인할 수 있어요. **변경사항 저장**을 누르면 사용자 지정한 내용이 적용돼요.

### 나중에 Elementor에서 페이지를 계속 편집할 수 있나요?
네. 생성된 WordPress 페이지는 Elementor에서 열어 편집할 수 있어요.

### AI 생성 이미지 대신 직접 가진 이미지를 업로드할 수 있나요?
네. 지원되는 이미지를 선택하고 **Regenerate Image**(이미지 다시 생성)를 클릭한 다음 **이미지 업로드**를 선택하세요. JPEG, PNG, WebP, GIF 파일을 10MB까지 올릴 수 있어요. 페이지에 넣기 전에 업로드한 이미지를 확인하세요.
