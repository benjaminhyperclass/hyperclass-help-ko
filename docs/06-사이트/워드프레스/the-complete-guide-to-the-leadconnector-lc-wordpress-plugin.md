# LeadConnector(LC) 워드프레스 플러그인 완벽 가이드

CRM과 워드프레스 웹사이트 사이의 간극을 좁히는 일이 이보다 쉬울 수 없어요. LeadConnector(LC) 플러그인은 하이퍼클래스의 다양한 기능을 워드프레스 환경에 매끄럽게 통합해주는 강력한 도구예요.

지저분한 임베드 코드나 번거로운 서드파티 커넥터는 이제 그만! LC 플러그인을 사용하면 워드프레스 대시보드 안에서 바로 채팅 위젯을 배포하고, 전환율 높은 퍼널을 삽입하고, 동적 커스텀 값(Custom Value)을 활용할 수 있어요.

## 강력한 연동 기능

LC 플러그인은 일반적인 워드프레스 사이트를 CRM 기반의 역동적인 리드 생성 머신으로 바꿔줘요.

- **실시간 채팅 위젯 연동**: 웹사이트 방문자를 즉시 리드로 전환하세요. 클릭 한 번으로 CRM의 채팅 위젯(Chat Widget)을 워드프레스 사이트에 활성화할 수 있어요—수동으로 코드를 삽입할 필요가 없어요! 모든 채팅은 CRM의 대화(Conversations) 탭으로 바로 연결돼요.

- **매끄러운 퍼널 페이지**: 전환율 높은 CRM 퍼널을 워드프레스 도메인 안으로 그대로 가져오세요. 이 플러그인을 사용하면 퍼널 단계(Funnel Step)를 워드프레스 네이티브 페이지로 호스팅할 수 있어서, 통일된 브랜드 경험과 더 빠른 로딩 속도를 보장해요.

- **동적 커스텀 값**: 워드프레스 사이트를 손쉽게 개인화하세요. 숏코드(shortcode)를 통해 사이트 어디서든 CRM의 커스텀 값(Custom Value)을 사용할 수 있어요. CRM에서 전화번호, 주소, 프로모션 오퍼를 업데이트하면 워드프레스 사이트 전체에 즉시 반영돼요.

- **폼, 설문, 캘린더**: 전용 워드프레스 블록이나 간단한 숏코드를 사용해서 CRM의 폼(Form), 설문(Survey), 캘린더(Calendar)를 어떤 페이지나 게시물에든 손쉽게 불러올 수 있어요.

## 플러그인 설치 및 연결하기

설치 과정은 워드프레스 사이트가 어디에 호스팅되어 있는지에 따라 달라져요.

### 시나리오 A: 하이퍼클래스에서 호스팅하는 경우 (자동 설치)

하이퍼클래스의 통합 워드프레스 호스팅을 통해 사이트를 운영하고 있다면, LC 플러그인이 자동으로 설치 및 설정돼요!

1. 워드프레스 대시보드에 로그인하세요.

2. 왼쪽 메뉴에서 LeadConnector 탭을 찾으세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608242/original/NAtwxrxbNx8cROb3Bk9GIsYc6W3nsa25SQ.png?1783594105)

3. 연결 상태가 Connected(연결됨)로 표시되는지 확인하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608244/original/xzW8SUfYK1OgZ34t5wr7C3QF_QgUAMrDMw.png?1783594105)

### 시나리오 B: 외부 워드프레스 호스팅을 사용하는 경우

하이퍼클래스 플랫폼 외부에서 호스팅 중인 워드프레스 사이트를 관리하고 있다면, 다음과 같이 플러그인을 직접 설치할 수 있어요:

- 워드프레스 대시보드에서 Plugins(플러그인) > Add New(새로 추가)로 이동하세요.

- 플러그인 저장소에서 "LeadConnector"를 검색하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608250/original/Wx1J9H7VBAvF0qYAtiNu621jJS0-8i2EDg.png?1783594106)

- Install Now(지금 설치)를 클릭한 다음 Activate(활성화)를 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608248/original/9tQo--37uUoyOndgqY_j6j_djfmTmx7GtQ.png?1783594106)

- 이제 LeadConnector 플러그인에서 로그인(sign in)을 클릭하고 CRM 계정으로 로그인하세요.

## LC 플러그인 기능 사용법

연결이 완료되면 워드프레스 안에서 CRM의 강력한 기능을 간단하게 활용할 수 있어요.

### 1. 채팅 위젯 활성화하기

이제 채팅 위젯을 노출하기 위해 사이트 헤더에 HTML 스크립트를 복사해서 붙여넣을 필요가 없어요.

- 워드프레스에서 LeadConnector 플러그인 설정으로 이동하세요.

- 채팅 위젯(Chat Widget) 설정을 찾으세요.

- Enable Chat Widget(채팅 위젯 활성화) 체크박스를 선택하세요.

- 저장(Save)을 클릭하세요. CRM에서 설정한 위젯이 즉시 사이트에 나타나요!

### 2. 워드프레스 페이지에 퍼널 삽입하기

CRM 퍼널을 워드프레스 도메인에서 바로 호스팅해서 URL 구조를 깔끔하고 전문적으로 유지하세요.

- 워드프레스 메뉴에서 LeadConnector > Funnels(퍼널)로 이동하세요.

- Add New(새로 추가)를 클릭하세요.

- 드롭다운 메뉴를 사용해서 CRM에서 가져올 특정 퍼널(Funnel)과 퍼널 단계(Funnel Step)를 선택하세요.

- 워드프레스 슬러그를 지정하세요 (예: yourdomain.com/special-offer).

- 변경 사항을 저장하세요. 이제 퍼널이 워드프레스 도메인에서 바로 작동해요!

### 3. 숏코드로 커스텀 값 사용하기

동적 숏코드를 사용해서 사이트 데이터를 CRM과 완벽하게 동기화된 상태로 유지하세요.

- 워드프레스에서는 다음과 같은 숏코드 형식을 사용할 수 있어요: `[lc_custom_value key="your_custom_value_key"]`

- 예시: 사업장 전화번호에 대한 커스텀 값의 키가 `{{custom_values.business_phone}}`라면, 워드프레스 텍스트 편집기에 `[lc_custom_value key="business_phone"]`이라고 입력하면 돼요.

- CRM에서 해당 값이 업데이트될 때마다 워드프레스 사이트의 텍스트도 자동으로 업데이트돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608241/original/gFIwHijk1IOGw51NPNsd8vLKKlgHLXVq8w.png?1783594105)

## 문제 해결 및 FAQ

**Q: 채팅 위젯을 활성화했는데 실제 사이트에 안 보여요. 뭐가 문제인가요?**

A: 거의 대부분 캐싱(caching) 문제예요. 워드프레스 캐싱 플러그인(WP Rocket, W3 Total Cache 등)의 캐시를 삭제하고, 호스팅 대시보드에서 서버 캐시도 지운 다음, 브라우저에서 강력 새로고침을 해보세요.

**Q: 커스텀 값 숏코드가 빈 텍스트로만 표시돼요. 왜 그런가요?**

A: 두 가지를 확인해보세요. 첫째, CRM 안에서 해당 커스텀 값에 실제로 데이터가 입력되어 있는지 확인하세요. 둘째, 워드프레스 숏코드 안에 중괄호 `{{ }}` 없이 정확한 키(key) 이름만 사용했는지 다시 확인하세요.

**Q: 플러그인이 "Disconnected(연결 끊김)"로 표시돼요. 어떻게 해결하나요?**

A: 최근에 CRM 안에서 API 키(API Key)를 재발급했다면 플러그인 연결이 끊길 수 있어요. 워드프레스의 LeadConnector 탭으로 돌아가서 기존 키를 지우고, 새로 발급받은 API 키를 붙여넣은 다음 저장하세요.

여전히 문제가 해결되지 않나요? 위 방법을 모두 시도했는데도 플러그인이 제대로 동기화되지 않는다면, 하이퍼클래스 고객지원팀에 문의해서 바로 도움을 받아보세요!
