# 차단된 워드프레스 플러그인 목록

저희는 워드프레스 사이트의 안정성, 성능, 보안을 개선하기 위해 끊임없이 노력하고 있어요. 하지만 안타깝게도 일부 플러그인은 저희 플랫폼에 이미 내장된 기능을 중복으로 구현하려고 하거나, 저희 환경과 호환성이 좋지 않은 경우가 있어요.

시스템 관리자가 특정 플러그인과 관련된 문제를 발견하면, 해당 플러그인을 제한 플러그인으로 분류하는 조치를 취해요. 이런 플러그인은 성능 문제를 일으키거나 웹사이트의 원활한 운영을 방해할 수 있기 때문이에요.

아래는 현재 저희 플랫폼에서 제한되고 있는 워드프레스 플러그인 목록이에요. 플러그인 관련 문제가 발견될 때마다 이 목록을 지속적으로 업데이트하여, 더 안전하고 안정적인 웹사이트 환경을 제공하기 위해 노력하고 있다는 점 참고해 주세요.
