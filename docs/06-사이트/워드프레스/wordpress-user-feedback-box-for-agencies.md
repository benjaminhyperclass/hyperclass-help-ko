# WordPress 피드백 상자 사용하기 (에이전시용)

WP Hosting 대시보드에서 에이전시 사용자가 바로 의견을 보낼 수 있는 피드백 상자를 소개해요. 인사이트, 제안, 불편한 점을 곧바로 전달하고 싶을 때 쓰세요.

## 에이전시 사용자 피드백 상자란?

WordPress 에이전시 사용자 피드백 상자는 WP Hosting 대시보드 안에 들어 있는 기능이에요. 에이전시 운영자가 WordPress를 벗어나지 않고 의견을 보낼 수 있어요. 인사이트, 제안, 불만 등 사용자의 생각을 담당 팀이 빠르게 확인하고, 호스팅 환경을 꾸준히 개선하는 데 쓰려고 만든 기능이에요.

## 피드백 상자의 장점

피드백 상자는 평소 쓰는 화면에 의견 전달 기능을 넣어서, 서비스 품질과 사용자 만족도를 높이는 데 도움이 돼요.

- 간편한 연동: 피드백 상자가 WP Hosting 대시보드 안에 있어서 별도 로그인이나 플러그인이 필요 없어요.
- 쉬운 제출: 안내에 따라 작성하는 간단한 폼이라 몇 초면 아이디어나 문제를 전달할 수 있어요.
- 즉시 전달: 각 의견은 전용 Slack 채널로 전달되어 실시간으로 분류돼요.
- 빠른 개선: 의견이 담당 팀에 바로 닿아서 수정과 업그레이드가 더 빨리 이어져요.

## 피드백 상자 사용 방법

사용 방법은 간단해서 바로 의견을 보낼 수 있어요. 아래 단계를 따라 해 보세요.

{% hint style="info" %}
이 기능은 에이전시에만 표시돼요.
{% endhint %}

1. 서브 계정에 로그인하세요.
2. **사이트** 탭을 클릭하세요.
3. **WordPress** 탭을 클릭하세요.

   ![WordPress 탭 화면](https://jumpshare.com/share/4VDxXPdBjQpU3FiKWfnH+/Screen+Shot+2025-08-04+at+7.39.40+PM.png)
4. **+ Create Site**(+ 사이트 만들기) 버튼 옆의 **Feedback Box**(피드백 상자)를 클릭하세요.

   ![사이트 만들기 버튼 옆의 피드백 상자](https://jumpshare.com/share/u9H1Fi9NHTWL7DndEjQ8+/Screen+Shot+2025-08-04+at+7.43.43+PM.png)
5. **피드백** 입력란에 아이디어, 불편한 점, 궁금한 점을 알기 쉽게 적으세요.
6. **메시지 보내기** 버튼을 클릭하면 의견이 제출돼요.

   ![메시지 보내기 버튼](https://jumpshare.com/share/WyETM7aDh3H4hnbROSXS+/Screen+Shot+2025-08-04+at+7.51.25+PM.png)

## 자주 묻는 질문

### 제출한 피드백은 어디로 전달되나요?
모든 피드백은 전용 Slack 채널로 바로 전달돼요. 의견이 담당 팀에 지체 없이 닿아요.

### 피드백 폼에서 이메일 주소를 바꿀 수 있나요?
네, 피드백을 제출하기 전에 이메일 주소를 수정할 수 있어요.

### 피드백이 제대로 제출됐는지 어떻게 알 수 있나요?
제출하면 "Thanks for helping us improve!"(더 나은 서비스를 위해 도와주셔서 감사합니다!)라는 확인 메시지가 표시돼요.

### 피드백 상자는 WP Hosting 대시보드의 모든 에이전시 사용자가 쓸 수 있나요?
네, WP Hosting 대시보드에 접근할 수 있는 에이전시 사용자라면 누구나 이 기능으로 의견을 보낼 수 있어요.

### 피드백을 여러 번 보내도 되나요?
네, 호스팅 환경을 계속 개선할 수 있도록 필요한 만큼 자주 보내 주세요.
