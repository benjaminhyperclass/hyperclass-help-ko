# WordPress 웹사이트 성능 리포트 확인하기

WordPress 사이트의 속도와 사용자 경험을 하이퍼클래스 안에서 확인하는 방법을 설명해요. 웹사이트 성능 리포트는 PageSpeed Insights 점수와 Core Web Vitals를 보여 주고, 개선 항목을 영향도에 따라 정리해 줘요.

## WordPress 웹사이트 성능 리포트란?

웹사이트 성능 리포트는 하이퍼클래스 WordPress 호스팅에 들어 있는 대시보드예요. 페이지가 얼마나 빨리 열리는지, 반응이 얼마나 빠른지, 레이아웃이 얼마나 안정적인지 평가해요. 방문자에게 가장 큰 영향을 주는 문제를 짚어 주고, 지금 쓰는 WordPress 환경에서 할 수 있는 개선 방법도 알려 줘요.

리포트는 게시된 페이지를 분석해서 모바일과 데스크톱 결과를 따로 보여 줘요. 결과는 PageSpeed/Lighthouse의 랩 테스트를 기준으로 하고, Google의 Core Web Vitals를 중심으로 구성돼요. 그래서 실제 방문자의 경험을 개선하는 데 도움이 돼요.

## 웹사이트 성능 리포트로 얻을 수 있는 것

하이퍼클래스 안에서 작업하면서 로딩 속도를 높이고, 무엇부터 고칠지 정하고, 전환과 검색 성과를 개선할 수 있어요.

- 모바일과 데스크톱 구분: 기기별 점수를 따로 볼 수 있어서 휴대폰이나 큰 화면에서만 나타나는 문제를 찾을 수 있어요.
- Core Web Vitals 확인: 체감 속도와 안정성에 가장 중요한 세 가지 지표(LCP, INP, CLS)를 확인해요.
- 우선순위가 보이는 상태 점검: 항목이 통과, 수정 고려(Consider), 수정 필요(Fix)로 나뉘어 있어서 무엇부터 봐야 할지 알 수 있어요.
- 바로 실행할 수 있는 권장 사항: 쉬운 말로 된 설명과 예상 단축 시간을 보고 다음 할 일을 정할 수 있어요.
- SEO에 맞춘 개선: 참여도와 검색 성과에 영향을 주는 기술 요소를 최적화할 수 있어요.
- 대시보드 중심 작업: WordPress 호스팅 대시보드에서 바로 확인할 수 있어요. 외부 도구는 필요할 때만 쓰면 돼요.

## 성능 리포트 만들고 확인하기

다음 순서로 대시보드를 찾고, 기기별 화면을 전환하고, 결과를 확인해 보세요.

### 1단계: WordPress 영역 열기

1. 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **사이트**를 클릭하세요.
3. **WordPress**를 클릭하세요.

   ![사이트 메뉴에서 WordPress 선택](https://jumpshare.com/share/xJIYbn1Mv1xJdw1QZ8Aw+/Screen+Shot+2025-10-08+at+8.23.54+PM.png)

### 2단계: 사이트 관리 화면 열기

1. 분석하려는 WordPress 사이트에서 **Manage Website**(웹사이트 관리)를 클릭하세요.

   ![Manage Website 버튼](https://jumpshare.com/share/l8a5syPGErn3X5xXT9wH+/Screen+Shot+2025-10-08+at+8.32.07+PM.png)
2. **분석** 탭을 클릭하세요.
3. 분석 아래에서 **Performance Reports**(성능 리포트)를 클릭하세요.

   ![분석 탭의 Performance Reports 메뉴](https://jumpshare.com/share/69wL4XQnFwFa8wLHd1lw+/Screen+Shot+2025-10-08+at+8.34.55+PM.png)

### 3단계: 성능 리포트 만들기

1. **리포트 가져오기**를 클릭하세요.
2. 리포트가 사이트를 분석할 때까지 기다리세요.
3. 웹사이트 성능 리포트가 나타나요. **페이지 속도**(모바일 & 데스크톱), **Core 웹 Vitals**, **페이지 Health 리포트**(페이지 상태 리포트) 섹션으로 구성돼요.

   ![성능 리포트가 만들어진 화면](https://jumpshare.com/share/WLzhqzqghDk7LWUuFBNf+/GIF+Recording+2025-10-08+at+8.39.12+PM.gif)

### 4단계: 페이지 속도 확인하기(모바일 & 데스크톱)

1. **페이지 속도**에서 **모바일**과 **데스크톱** 점수를 확인하세요.
2. 모바일과 데스크톱의 로딩 시간을 확인하고, 화면에 표시된 **전역 Averages**(전역 평균)와 비교해 보세요.

   ![모바일과 데스크톱 페이지 속도 점수](https://jumpshare.com/share/nsorHV4iy8nSn3yKOvPP+/Screen+Shot+2025-10-08+at+8.44.28+PM.png)

### 5단계: Core Web Vitals 살펴보기

```
왜 중요할까요? Google 검색은 페이지 경험을 평가할 때 Core Web Vitals를 사용해요. 이 지표를 꾸준히 확인하고 개선하면 성능과 검색 노출에 도움이 돼요.
```

1. Google이 페이지 경험을 평가할 때 쓰는 핵심 지표를 확인하세요.
2. 세부 지표별 점수를 확인하세요. (예: 페이지 속도, 상호작용, 큰 콘텐츠, SEO)
3. 빨간색으로 표시되거나 나쁨으로 표시된 항목부터 먼저 처리하세요.

   ![Core Web Vitals 세부 지표 점수](https://jumpshare.com/share/akJygYNCS1TXp7XihPSj+/Screen+Shot+2025-10-08+at+8.52.15+PM.png)

### 6단계: 페이지 Health 리포트 점검하기(데스크톱 & 모바일)

1. **데스크톱** 리포트와 **모바일** 리포트를 오가면서 기기별 결과를 확인하세요.
2. 각 기기에서 **Should fix**(수정 필요), **Consider fix**(수정 고려), **통과** 그룹을 차례로 살펴보세요.

   ![수정 필요, 수정 고려, 통과 그룹](https://jumpshare.com/share/IKZM0IP4jjS1OVOnV27w+/Screen+Shot+2025-10-08+at+8.59.11+PM.png)
3. 문제가 있는 항목은 **보기**를 클릭해서 펼치고, 바로 적용할 수 있는 수정 방법을 확인하세요.
4. 표시된 항목을 펼치면 문제가 무엇인지, 왜 중요한지, 어떻게 해결하는지 설명이 나와요. 비전문가는 추측할 필요가 없고, 개발자는 더 빨리 작업할 수 있어요.

   ![항목을 펼쳐 수정 방법을 확인하는 화면](https://jumpshare.com/share/35WXAwH46Xn0NNCZIHp7+/GIF+Recording+2025-10-08+at+9.00.35+PM.gif)

## 자주 묻는 질문

### 하이퍼클래스가 아닌 WordPress 사이트에도 웹사이트 성능 리포트를 쓸 수 있나요?

이 리포트는 하이퍼클래스 WordPress 호스팅에서 운영하는 사이트를 대상으로 해요. 외부나 타사 WordPress 환경은 포함되지 않아요.

### 랩 점수는 올랐는데 Core Web Vitals는 그대로예요. 왜 그런가요?

랩 테스트에는 변경 사항이 바로 반영돼요. 실제 방문자 데이터를 모아서 집계하는 지표는, 업데이트된 페이지를 경험한 방문자가 충분히 쌓일 때까지 반영이 늦어질 수 있어요.

### 모바일 점수가 데스크톱보다 훨씬 낮으면 무엇부터 확인해야 하나요?

이미지 크기와 압축, 핵심 CSS, 타사 스크립트부터 확인하세요. 서버 지역이 주요 방문자와 가까운지도 함께 확인해 보세요.

### 플러그인이 성능 점수에 영향을 주나요?

네, 영향을 줄 수 있어요. 무겁거나 서로 충돌하는 플러그인은 LCP와 INP를 떨어뜨릴 수 있어요. 성능 도구를 추가하기 전에 설치된 플러그인을 점검하고 차단된 플러그인(Blocked Plugins) 목록을 확인하세요.
