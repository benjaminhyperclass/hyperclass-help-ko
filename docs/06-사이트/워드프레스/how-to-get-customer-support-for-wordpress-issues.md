# WordPress 문제가 생겼을 때 고객 지원 받기

하이퍼클래스의 **WordPress Setup Guide**(WordPress 설정 가이드)에 빠른 링크 3개가 생겼어요. WordPress 고객 성공팀과 통화를 예약하고, 상품 타운홀에 참여하고, 앱 안에서 WordPress 지식 베이스를 열 수 있어요. 문제 해결이 빨라지고, 제품 로드맵 이야기에도 바로 참여할 수 있어요. 이 문서에서 각 링크가 하는 일과 사용 방법을 안내해요.

{% hint style="info" %}
이 빠른 링크는 에이전시 관리자에게만 보여요.
{% endhint %}

## WordPress 고객 지원 업그레이드란?

WordPress 설정 가이드 안에서 지원 수단 3가지를 바로 쓸 수 있어요. 에이전시 관리자는 하이퍼클래스를 떠나지 않고도 전문가 도움, 스스로 찾아보는 답변, 실시간 제품 소식을 얻을 수 있어요. 링크마다 쓰임새가 달라요(상담, 제품 소식, 지식 검색). 사이트를 설정하는 중이나 그 이후에 생기는 지연을 줄이는 데 도움이 돼요.

- WordPress 고객 성공팀과 통화 예약: WordPress 고객 성공팀과 상담 통화 일정을 잡아요.
- 상품 타운홀 직접 참여: 라이브 타운홀에 참여해 로드맵 소식을 듣고 의견을 전할 수 있어요.
- 앱 안의 WordPress 지식 베이스: 하이퍼클래스 안에서 WordPress 지식 베이스 전체를 열어 검색하고 직접 해결할 수 있어요.

## WordPress 고객 지원 업그레이드의 주요 이점

- 빠른 문제 해결: 고객 성공팀과 통화를 예약하거나 지식 베이스를 바로 열어 문제에서 해결책으로 빠르게 넘어갈 수 있어요.
- 능동적인 활용: 작업 화면을 벗어나지 않고 배우고, 직접 답을 찾고, 제품이 나아가는 방향을 확인할 수 있어요.
- 전 세계 지원: 대부분의 시간대에서 지원을 받을 수 있어, 거의 항상 도움을 받을 수 있어요.
- 신뢰와 유지: 전문가 안내, 투명한 로드맵 공개, 믿을 수 있는 문서가 더해져 고객사의 신뢰를 쌓는 데 도움이 돼요.

## WordPress 고객 지원 빠른 링크 위치

아래 순서대로 따라 하면 빠른 링크를 찾을 수 있어요.

1. 서브 계정에 로그인하세요.
2. **사이트 > WordPress**로 이동하세요.

   ![사이트 메뉴의 WordPress 화면](https://jumpshare.com/share/fEiejTN50wKjEjwYsnxQ+/Screen+Shot+2025-11-07+at+9.32.34+PM.png)
3. **빠른 시작** 버튼을 클릭하세요.

   ![빠른 시작 버튼](https://jumpshare.com/share/SwkGr2vq0Jx6WHmTwSc4+/Screen+Shot+2025-11-07+at+9.46.24+PM.png)
4. **빠른 링크**까지 스크롤하세요. 에이전시 관리자에게만 보여요.
5. **통화 예약**, **상품 타운홀 참여**, **WordPress 지식 베이스** 중 하나를 선택하세요.

## 자주 묻는 질문

### 이 빠른 링크는 누가 볼 수 있나요?

WordPress 설정 가이드 안의 빠른 링크는 에이전시 관리자만 볼 수 있어요.

### 예약 가능한 시간이 보이지 않아요. 어떻게 하나요?

대부분의 시간대에 걸쳐 새 예약 시간이 계속 추가돼요. 잠시 후 다시 확인해 보세요. 바로 안내가 필요하면 앱 안의 지식 베이스를 이용하세요.

### 앱 안의 지식 베이스는 웹 버전과 같은가요?

앱 안에서도 WordPress 지식 베이스 전체를 볼 수 있어요. 하이퍼클래스를 벗어나지 않고 검색하고 가이드를 따라 할 수 있어요.

### 이 기능을 쓰려면 특정 요금제나 애드온이 필요한가요?

이 기능은 하이퍼클래스 WordPress 기능의 일부예요. WordPress를 사용할 수 있다면 에이전시 관리자 계정에서 이 기능이 보일 거예요.
