# WordPress File Manager로 사이트 파일 관리하기

WordPress File Manager(파일 매니저)를 쓰면 WordPress 사이트의 파일을 하이퍼클래스 안에서 찾아보고, 올리고, 내려받고, 편집하고, 정리할 수 있어요. FTP 프로그램 같은 외부 도구는 필요 없어요. 이 문서에서는 파일과 폴더를 둘러보고, 올리고, 편집하고, 정리하고, 권한을 바꾸는 방법을 안내해요.

## WordPress File Manager란?

WordPress File Manager는 하이퍼클래스 안에서 WordPress 사이트의 파일 시스템에 바로 접근하게 해 주는 기본 제공 도구예요. 외부 FTP 프로그램이나 cPanel 없이도 파일과 폴더를 관리할 수 있어요.

File Manager에서는 다음 작업을 한 곳에서 할 수 있어요.

- 사이트의 폴더 구조 둘러보기
- 파일 올리기와 내려받기
- 파일 내용 편집하기
- 폴더 만들기와 삭제하기
- 압축 파일 관리하기
- 파일 권한 바꾸기

테마 수정, 플러그인 수정, 문제 해결, 콘텐츠 관리처럼 WordPress 사이트를 운영하면서 자주 하는 작업에 쓸 수 있어요.

## 이럴 때 좋아요

File Manager는 파일 작업을 한 화면에 모아 사이트 관리를 간편하게 해 줘요.

- 한 곳에서 모든 파일 접근: FTP 프로그램, cPanel, SSH 터미널을 오가지 않고 WordPress 파일 시스템 전체를 관리해요.
- 빠른 작업: 검색, 필터, 정렬, 페이지 나누기로 폴더가 많아도 원하는 파일을 빠르게 찾고, 올리고, 편집하고, 정리해요.
- 안전한 편집: 바꾸기 전에 파일 내용을 미리 볼 수 있어요. 충돌 방지 보호 기능이 있어서 더 최신 버전의 파일을 실수로 덮어쓰는 일을 줄여 줘요.
- 완전한 파일 작업: 외부 도구 없이 파일과 폴더를 만들고, 삭제하고, 압축하고, 압축을 풀고, 권한을 관리해요.
- 간편한 유지 관리: 문제 해결, 테마 수정, 플러그인 수정을 File Manager에서 바로 해서 플랫폼을 오가는 시간을 줄여요.

## File Manager로 할 수 있는 일

### 파일과 폴더 찾아보기

사이트의 파일 시스템을 둘러볼 수 있어요. 검색으로 특정 파일을 찾고, 필터로 결과를 좁히고, 이름이나 날짜순으로 정렬하세요. 파일이 많은 폴더는 페이지를 넘기며 확인할 수 있어요.

### 올리기와 내려받기

지원되는 형식의 파일을 WordPress 사이트의 원하는 폴더에 바로 올릴 수 있어요. 백업하거나, 오프라인에서 편집하거나, 협업하는 사람과 공유할 때는 파일을 내려받으세요. FTP 프로그램 없이 파일을 주고받을 수 있어요.

### 파일 편집

바꾸기 전에 파일 내용을 미리 보고 올바른 파일인지 확인할 수 있어요. File Manager에서 바로 편집하고 저장할 수 있어요. 다른 사용자나 프로세스가 올린 더 최신 내용을 덮어쓰지 않도록 충돌 방지 보호 기능이 도와줘요. 데이터를 실수로 잃을 위험이 줄어요.

### 파일·폴더 관리

기본적인 파일과 폴더 작업을 쉽게 할 수 있어요.

- 새 파일과 폴더를 만들어 사이트 구조 정리하기
- 필요 없는 파일과 폴더를 삭제해 공간 확보하기
- 백업이나 배포를 위해 파일과 폴더를 압축 파일로 묶기
- 압축 파일의 압축을 풀어 백업 복원하기, 플러그인·테마 풀기

### 파일 권한

호스팅 환경에서 지원하는 경우 chmod 값을 바꿔 파일과 폴더의 접근 권한과 보안 설정을 조정할 수 있어요. WordPress 핵심 파일, 테마, 플러그인, 업로드 폴더에 알맞은 읽기·쓰기·실행 권한을 설정하세요.

### 하이퍼클래스 안에서 한 번에 관리

FTP 수준의 제어를 하이퍼클래스에서 바로 쓸 수 있어요. 외부 도구 없이 사이트 관리를 간단하게 할 수 있어요.

## WordPress File Manager 사용 방법

다음 단계를 따라 File Manager를 열고 사이트의 파일과 폴더를 관리해 보세요.

### 1단계. File Manager 열기

하이퍼클래스에서 WordPress 관리 화면으로 이동하세요. **File Manager**(파일 매니저) 옵션을 찾아 클릭하면 파일 브라우저가 열려요.

![File Manager 열기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077593453/original/j_uVoXrIQv8bGGHqwUk12oE9wIGEIOfwbg.png?1785848450)

### 2단계. 파일 찾아보기와 검색

파일 브라우저에서 사이트의 폴더 구조를 둘러보세요. 폴더를 클릭하면 펼쳐져요. 검색창으로 특정 파일을 찾고, 필터로 결과를 좁히고, 이름이나 수정 날짜순으로 정렬할 수 있어요. 파일이 많은 폴더는 페이지 이동 버튼으로 편하게 넘겨 볼 수 있어요.

![파일 찾아보기와 검색 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077594797/original/i8ypnHL9yGbWrmLAeag2F2y1WwezVF0krQ.gif?1785849004)

### 3단계. 파일 올리기와 내려받기

파일을 올리려면 다음을 따르세요.

- 올릴 폴더로 이동하세요.
- **파일 업로드**를 클릭하세요.
- 컴퓨터에서 지원되는 형식의 파일을 선택하세요.

![파일 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077594180/original/6kQeGODNv8xAvJ_wJfyU5kqmuYA-OAD-Dw.png?1785848781)

파일을 내려받으려면 다음을 따르세요.

- 내려받을 파일이나 폴더를 선택하세요.
- **Download**(다운로드) 버튼을 클릭하세요.
- 파일이 내 기기에 저장돼요.

![파일 내려받기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077594651/original/hFw_9Wa04Pi-OB5MuERkNBhirfdOgEFyIQ.png?1785848937)

### 4단계. 파일 안전하게 편집하기

파일을 편집하려면 다음을 따르세요.

1. 편집할 파일을 선택하세요.
2. **편집**을 클릭해 파일 내용을 확인하세요.

   ![파일 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077595045/original/qPEZsIA0qv3JQH0UQaORDi0SBSglmVIBkA.png?1785849099)
3. 편집기에서 내용을 수정하세요.
4. **저장**을 클릭해 변경 사항을 적용하세요.

   ![파일 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077595173/original/5U837Pxy7NxDpUyHD46zXM8ZdBAnQIWPJA.png?1785849134)

File Manager에는 충돌 방지 보호 기능이 있어요. 파일을 연 뒤에 다른 사용자나 프로세스가 그 파일을 수정하면 알려 줘서 실수로 덮어쓰는 일을 막아 줘요.

{% hint style="info" %}
wp-config.php나 .htaccess처럼 중요한 파일을 편집하기 전에는 항상 파일 내용을 미리 보세요. 올바른 파일인지, 현재 상태가 어떤지 확인할 수 있어요.
{% endhint %}

### 5단계. 파일과 폴더 관리하기

File Manager의 도구 모음과 오른쪽 클릭 메뉴로 기본 작업을 할 수 있어요.

- **만들기**: **New File**(새 파일) 또는 **New Folder**(새 폴더) 버튼을 클릭하면 현재 폴더에 새 항목이 만들어져요.
- **삭제**: 파일이나 폴더를 선택하고 **삭제**를 클릭하면 사이트에서 지워져요.
- **압축**: 파일이나 폴더를 선택하고 **압축**을 클릭하면 .zip 같은 압축 파일이 만들어져요.
- **Extract**(압축 풀기): 압축 파일을 선택하고 **Extract** 버튼을 클릭하면 내용이 풀려요.

[스크린샷: 만들기, 삭제, 압축, 압축 풀기 옵션이 표시된 File Manager 도구 모음]

### 6단계. 파일 권한(chmod) 바꾸기

파일이나 폴더의 권한을 바꾸려면 다음을 따르세요.

1. 파일이나 폴더를 선택하세요.
2. **Permissions**(권한) 또는 **Properties**(속성) 버튼을 클릭하세요.
3. 소유자, 그룹, 기타 사용자별로 읽기·쓰기·실행 권한을 조정하세요.
4. **저장**을 클릭해 새 권한을 적용하세요.

권한 관리는 호스팅 환경이 chmod 작업을 지원해야 쓸 수 있어요. 이 기능을 쓸 수 없다면 호스팅 업체에 문의하세요.

{% hint style="warning" %}
파일 권한을 잘못 설정하면 사이트 보안이 약해지거나 기능이 작동하지 않을 수 있어요. 권한을 바꾸기 전에 WordPress 핵심 파일, 테마, 플러그인에 권장되는 권한 설정을 항상 확인하세요.
{% endhint %}

## 자주 묻는 질문

### WordPress File Manager를 쓰려면 FTP 계정 정보가 필요한가요?

아니요. WordPress File Manager는 하이퍼클래스에서 바로 작동해서 FTP 계정 정보가 필요하지 않아요. 외부 FTP 프로그램이나 cPanel 없이 사이트의 파일 시스템에 접근할 수 있어요.

### File Manager로 어떤 형식의 파일을 올릴 수 있나요?

이미지, 문서, 스크립트, 스타일시트, 압축 파일 등 WordPress 환경에서 흔히 쓰는 표준 형식을 모두 올릴 수 있어요. 제한된 형식이 있으면 업로드할 때 File Manager가 알려 줘요.

### 다른 사람이 수정한 파일을 저장하려고 하면 어떻게 되나요?

File Manager의 충돌 방지 보호 기능이 내가 파일을 연 뒤에 수정되었는지 감지해요. 충돌이 감지되면 알림이 나타나요. 그때 변경 내용을 검토하거나, 수정 내용을 병합하거나, 저장을 취소해서 실수로 덮어쓰는 일을 막을 수 있어요.

### File Manager에서 파일을 압축하고 압축을 풀 수 있나요?

네. 파일과 폴더를 .zip 같은 압축 파일로 묶을 수 있고, 압축 파일을 풀어 백업을 복원하거나 플러그인, 테마 등을 풀 수도 있어요. 압축할 파일이나 폴더, 또는 압축을 풀 파일을 선택한 뒤 도구 모음의 **압축** 또는 **Extract** 버튼을 사용하세요.

### 파일 권한 옵션이 보이지 않으면 어떻게 하나요?

파일 권한(chmod) 관리는 호스팅 환경이 지원해야 쓸 수 있어요. File Manager에 권한 옵션이 없다면 호스팅 업체의 제어판을 쓰거나 호스팅 업체 고객지원에 문의해 파일과 폴더 권한을 바꿔야 할 수 있어요.

### File Manager로 테마나 플러그인 파일을 편집할 수 있나요?

네. 테마와 플러그인 파일을 찾아보고, 미리 보고, 편집할 수 있어요. 수정하기 전에 항상 파일을 백업하세요. 가능하면 스테이징 사이트에서 먼저 테스트해서 운영 중인 사이트에 문제가 생기지 않게 하세요.

### 업로드 파일 크기에 제한이 있나요?

업로드 크기 제한은 호스팅 환경의 PHP 설정에 따라 정해져요. 크기 제한에 걸리면 호스팅 설정을 조정하거나 호스팅 업체에 문의해 최대 업로드 크기를 늘려야 할 수 있어요.

### 여러 파일이나 폴더를 한 번에 삭제할 수 있나요?

네. File Manager 화면에서 체크박스로 파일이나 폴더를 여러 개 선택한 뒤 **삭제**를 클릭하면 선택한 항목이 한꺼번에 지워져요. 중요한 파일을 실수로 지우지 않도록 여러 항목을 삭제할 때는 주의하세요.
