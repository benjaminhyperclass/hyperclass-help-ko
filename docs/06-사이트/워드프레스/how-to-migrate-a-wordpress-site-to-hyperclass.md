# WordPress 사이트를 하이퍼클래스로 옮기기

기존 WordPress 사이트를 하이퍼클래스의 통합 호스팅 플랫폼으로 옮기는 방법을 안내해요. 직접 옮기는 방법과 하이퍼클래스 팀에 맡기는 방법, 두 가지가 있어요. 이 문서에서는 두 방법과 사용자 유형별 화면, 보안 접속 링크로 화이트글러브 마이그레이션을 요청하는 방법을 설명해요.

## 마이그레이션 방법 두 가지

하이퍼클래스 마이그레이터 플러그인으로 직접 옮기거나, 화이트글러브 마이그레이션을 요청해 하이퍼클래스 팀이 대신 옮기도록 할 수 있어요. 이 플랫폼은 에이전시와 에이전시의 고객사가 함께 쓰기 때문에, WordPress 대시보드는 로그인한 사용자에 따라 다르게 보여요.

- 하이퍼클래스 마이그레이터 플러그인: 원본 사이트에 설치해서 직접 마이그레이션을 실행하는 가벼운 플러그인이에요. 파일 크기 제한이 없어서 큰 사이트에도 쓸 수 있어요.
- 화이트글러브 마이그레이션(에이전시 사용자 전용): 요청을 제출하면 하이퍼클래스 마이그레이션 팀이 사이트를 대신 옮겨 줘요. 대부분 영업일 기준 1~3일 안에 끝나며, 원본 사이트 크기에 따라 달라져요.

## 에이전시에서 보이는 화면

에이전시 관리자는 마이그레이션 전체 과정을 직접 관리하고, 모든 고객사의 진행 상황을 한곳에서 확인할 수 있어요.

마이그레이션을 시작하려면 **에이전시 대시보드 > 사이트 > WordPress**로 이동하세요. 여기서 새 마이그레이션을 시작하면서, 하이퍼클래스 마이그레이터로 직접 옮길지 화이트글러브 요청을 제출할지 고를 수 있어요.

## 하이퍼클래스 마이그레이터 플러그인으로 직접 옮기기

원본 사이트에 하이퍼클래스 마이그레이터 플러그인을 설치한 뒤, 하이퍼클래스에서 이전을 시작해요.

1. 대시보드에서 하이퍼클래스 마이그레이터 플러그인을 다운로드하세요.

   ![플러그인 다운로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609155/original/Gu91vhdTS8S-iWcnHpo9ZgwZtIh6SeKzow.png?1783594559)
2. 옮기려는 WordPress 사이트인 원본 사이트에 플러그인을 설치하세요.

   ![원본 사이트에 플러그인 설치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609152/original/1aD4CSPRl4D98QvnCZqJxfS896T4SBPO_Q.png?1783594558)
3. 하이퍼클래스에 로그인한 뒤, 마이그레이션 대상 WordPress 사이트를 선택하세요.

   ![마이그레이션할 WordPress 사이트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609154/original/ivr9JwLTLlMfPS3CMhmJgz_8KmVHhXWomg.png?1783594559)
4. **Start migration**(마이그레이션 시작)을 클릭하세요.

   ![마이그레이션 시작 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609145/original/ywjCM2azrBohtgydp4CzDsUovc6EVugoJQ.png?1783594558)
5. 플러그인이 마이그레이션하는 동안 원본 사이트에서 진행률 표시줄을 확인하세요.

   ![원본 사이트의 진행률 표시줄](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609147/original/fq0H4qm_qWibl1WBlMmE3NVNZLKjsYqxNA.png?1783594558)
6. 마이그레이션이 끝나면 **View Your New Website**(새 웹사이트 보기)를 클릭해서 새로 옮긴 사이트를 확인하세요. 원하면 사용 경험을 평가해 주세요.

![마이그레이션 완료 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609151/original/2rnoBunsN-D0ZZkR7afUyo9W4Aa4BHgdzQ.png?1783594558)

## 보안 접속 링크로 화이트글러브 마이그레이션 요청하기

화이트글러브 마이그레이션을 요청할 때는 WordPress 아이디와 비밀번호를 넘기지 않아요. 대신 하이퍼클래스 마이그레이터 플러그인으로 보안 접속 링크를 만들어 그 링크를 공유해요. 이 링크로 하이퍼클래스 전문가가 로그인해서 마이그레이션을 진행해요. 링크는 직접 정한 시간이 지나면 자동으로 만료되고, 원하면 언제든 폐기할 수 있어요. 관리자 권한을 주는 링크이지만 하이퍼클래스 전문가만 쓸 수 있어서, 다른 사람은 이 링크로 로그인할 수 없어요.

시작하기 전에 마이그레이션할 WordPress 사이트의 관리자 권한이 있는지 확인하세요.

### 1단계: 하이퍼클래스 마이그레이터 플러그인 설치하기

1. 하이퍼클래스 마이그레이터 플러그인을 다운로드하세요. .zip 파일로 저장되며, 압축은 풀지 마세요.
2. WordPress 관리자 화면에서 **Plugins**(플러그인) > **Add Plugin**(새 플러그인 추가)으로 이동하세요.

   ![Add Plugin이 보이는 WordPress Plugins 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609136/original/U7bUCcx2h7Wn8XhjKwSOCPHxLsCrafzVHg.png?1783594558)
3. **Upload Plugin**(플러그인 업로드)을 클릭하세요.

   ![Upload Plugin 버튼이 보이는 Add Plugins 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609135/original/h2R0fjKr3kwOaSzArXIw2Pbc3X66YjyTXA.png?1783594558)
4. **Choose File**(파일 선택)을 클릭해 다운로드한 .zip 파일을 고른 뒤, **Install Now**(지금 설치)를 클릭하세요.

   ![파일 선택과 지금 설치 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609139/original/71is1f3O9LvJxaQbS18v0vaA9RpnaCqtBQ.png?1783594558)
5. 설치가 끝나면 **Activate Plugin**(플러그인 활성화)을 클릭하세요.

   ![플러그인 활성화 버튼이 보이는 설치 완료 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609140/original/1rHlGWP6LdmVrOO7lpPHiAHPkqJ_X-Oqow.png?1783594558)

### 2단계: 보안 접속 링크 만들기

1. WordPress 관리자 화면의 사이드바에서 하이퍼클래스 마이그레이터를 여세요. **Welcome**(환영) 화면이 나타나요.

   ![하이퍼클래스 마이그레이터 환영 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609149/original/xQWWwT1d4YKvMszrVVQI1YxrMMafEaVtrQ.png?1783594558)
2. **Generate secure access link**(보안 접속 링크 생성)를 클릭하세요. 이때 계정에 로그인하지 않아도 돼요.
3. **Link active for**(링크 유지 기간)에서 링크를 유지할 기간을 24시간에서 7일 사이로 고르세요. 기본값은 3일이에요. 이 기간이 지나면 자동으로 만료되고, 그전에 언제든 폐기할 수도 있어요.

   - 주말 안내: 금요일, 토요일, 일요일에 링크를 만들면 최소 기간이 4일이에요. 업무 주간이 시작된 뒤에도 하이퍼클래스 전문가가 링크를 쓸 수 있도록 하기 위해서예요.

     ![링크 유지 기간 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609153/original/2vtP69AVLuWC-sAAEzX_fX7pd2PRZY9s-w.png?1783594559)
4. 이 링크가 전체 관리자 권한을 주며 하이퍼클래스 전문가만 쓸 수 있다는 안내를 확인하세요.
5. **Generate secure access link**(보안 접속 링크 생성)를 클릭하세요.
6. 확인 창에 링크의 기능이 안내돼요. 전체 관리자 권한을 주고, 자동으로 만료되며, 언제든 폐기할 수 있다는 내용이에요. **링크 생성**을 클릭해 확정하세요.

   ![보안 접속 링크 생성 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609141/original/-m92oTdVJIxG-xaQgnYWCiSon_Ni7aN3fQ.png?1783594558)

### 3단계: 링크를 공유하고 요청 제출하기

1. 링크가 활성화되고 클립보드에 자동으로 복사돼요. 다시 필요하면 **Copy**(복사)를 클릭하세요.

   ![활성화된 보안 접속 링크 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609148/original/wGFy3sGu1mmsUvTDUM0KJr4ZZlZAw5WZUA.png?1783594558)
2. **White-Glove Migration**(화이트글러브 마이그레이션) 요청의 **Secure access link**(보안 접속 링크) 필드에 링크를 붙여 넣고 요청을 제출하세요. 하이퍼클래스 전문가가 이 링크로 로그인해 마이그레이션을 진행하며, 비밀번호는 전혀 공유되지 않아요.

   ![링크를 붙여 넣은 화이트글러브 마이그레이션 양식](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609150/original/mrEkqfTb396wAksauTNvDzAnwiadUftaDw.png?1783594558)

링크는 다음과 같은 모양이에요.

```
https://your-wordpress-site.com/wp-json/leadconnector-token/secure/<token>
```

### 링크 관리하기

링크가 활성화되어 있는 동안에는 만료까지 남은 시간이 표시돼요. 같은 화면에서 다음 작업을 할 수 있어요.

- **Regenerate**(다시 생성): 새 링크를 만들고 기존 링크는 즉시 무효로 만들어요. 한 번에 하나의 링크만 활성화할 수 있어요.
- **Revoke**(폐기): 접근을 즉시 차단해요. 나중에 다시 접근 권한을 주려면 새 링크를 만들어 공유하세요.

  ![보안 접속 링크 폐기 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075609144/original/I0PaAqxW2_q-LksK1w1oretTTQbDasyR1A.png?1783594558)

아무것도 하지 않으면 타이머가 끝날 때 링크가 자동으로 작동을 멈춰요.

## 자주 묻는 질문

### 보안 접속 링크는 안전한가요?
네. WordPress 비밀번호는 공유되지 않아요. 링크는 하이퍼클래스 전문가만 쓸 수 있고, 자동으로 만료되며, 원할 때 폐기할 수 있어요.

### WordPress 아이디와 비밀번호를 꼭 알려 줘야 하나요?
아니요. 보안 접속 링크가 비밀번호 공유를 대신해요.

### 마이그레이션이 실패하면 고객사에도 알림이 가나요?
아니요. 실패 알림과 오류 로그는 에이전시 화면에만 나타나서 화이트라벨 환경이 그대로 유지돼요. 문제를 해결하기 전까지 고객사에는 마이그레이션이 대기 중이거나 진행 중인 것으로 계속 보여요.

### 서브 계정 사용자가 직접 마이그레이션을 실행하게 할 수 있나요?
처음 설정은 에이전시 관리자가 시작해야 해요. 하이퍼클래스 마이그레이터 링크를 만들거나 화이트글러브 양식을 제출하는 작업이 여기에 해당해요. 사이트가 라이브 상태가 된 뒤에는 고객사가 부여받은 권한에 따라 사이트를 관리할 수 있어요.

### 화이트글러브 마이그레이션은 얼마나 걸리나요?
대부분 영업일 기준 1~3일 안에 끝나며, 원본 사이트의 크기와 복잡도에 따라 달라져요. 진행 상태는 에이전시 화면에서 실시간으로 확인할 수 있어요.

### 마이그레이션에 시간이 더 필요해요. 어떻게 하나요?
새 링크를 만들고 최대 7일까지 더 긴 기간을 고르세요.

### 지금 바로 접근을 차단하려면 어떻게 하나요?
보안 접속 링크 화면을 열고 **Revoke link**(링크 폐기)를 클릭하세요.

### 링크가 만료되면 어떻게 되나요?
링크가 자동으로 작동을 멈춰요. 접근이 계속 필요하면 새 링크를 만들어 하이퍼클래스 전문가에게 공유하세요.

---

까다로운 마이그레이션이 걱정된다면 대시보드에서 화이트글러브 요청을 제출하세요. 고객지원 팀이 맡아서 처리해 드려요.
