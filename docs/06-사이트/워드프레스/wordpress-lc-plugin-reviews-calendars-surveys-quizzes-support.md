# WordPress 하이퍼클래스 플러그인: 리뷰·캘린더·설문·퀴즈 지원

WordPress용 하이퍼클래스 플러그인에서 리뷰 위젯, **캘린더**, **설문**, **퀴즈**를 쓸 수 있어요. WordPress를 떠나지 않고도 하이퍼클래스와 연결된 사이트를 만들 수 있습니다. 이 문서에서는 Gutenberg, Elementor, Divi 같은 페이지 빌더에서 각 기능을 넣는 방법을 안내해요.

# 리뷰·캘린더·설문·퀴즈 지원이란?

하이퍼클래스 플러그인은 WordPress와 하이퍼클래스를 이어 주어, 하이퍼클래스에서 만든 요소를 사이트에 바로 넣을 수 있게 해 줘요. v3.0.13부터는 기존 위젯에 더해 리뷰 위젯, 캘린더, 설문, 퀴즈도 쓸 수 있어요. 이 요소들은 하이퍼클래스에서 설정한 대로 표시되고, 연결된 서브 계정과 동기화됩니다. 별도 플러그인이나 직접 넣는 임베드 코드는 필요 없어요.

{% hint style="info" %}
하이퍼클래스 플러그인을 켜고 WordPress와 연결하는 방법은 'WordPress 하이퍼클래스 플러그인' 문서를 참고하세요.
{% endhint %}

## 이 기능의 장점

- 한곳에서 관리: 임베드는 하이퍼클래스 플러그인에서 관리하고, 설정과 데이터는 하이퍼클래스에 그대로 둘 수 있어요.
- 간단한 설정: WordPress 사이트를 하이퍼클래스 서브 계정에 한 번만 연결하면, 지원하는 상품을 바로 넣을 수 있어요.
- 일관된 브랜드: 하이퍼클래스에서 정한 글꼴, 색상, 브랜드 스타일이 여러 페이지와 사이트에 똑같이 적용돼요.
- 관리할 플러그인 감소: 하이퍼클래스 공식 블록과 숏코드를 쓰면 코드를 붙여 넣거나 외부 도구에 의존할 일이 줄어요.
- 쉬운 협업: 코드를 몰라도 캘린더, 설문, 퀴즈, 리뷰를 페이지에 추가할 수 있어요.
- 안정적인 동기화: 제출, 예약, 리뷰가 하이퍼클래스로 들어와서 분석과 후속 조치를 한곳에서 할 수 있어요.

## 리뷰 위젯

리뷰 위젯은 고객 후기 같은 사회적 증거를 랜딩 페이지, 가격 페이지, 서비스 페이지에 보여 줘요. 신뢰도와 전환율을 높이는 데 도움이 됩니다.

1. 하이퍼클래스에서 평소처럼 리뷰 위젯을 만들고 꾸며요.
2. WordPress에서 **하이퍼클래스 > 리뷰**로 이동해 넣을 위젯을 고르고 숏코드를 복사해요.
3. 편집기에서 원하는 섹션이나 열에 블록 또는 숏코드를 넣어요.
4. 페이지를 게시해요. 하이퍼클래스에서 설정한 필터와 스타일대로 리뷰가 표시됩니다.

{% hint style="info" %}
- 홈페이지에는 리뷰 캐러셀을, 서비스 페이지에는 고정된 그리드를 쓰면 한눈에 보기 좋아요.
- 한 페이지에 위젯을 여러 개 넣을 때는 위젯마다 블록 또는 숏코드를 따로 넣고, 레이아웃 안에 알맞게 배치하세요.
{% endhint %}

## 캘린더

캘린더를 넣으면 방문자가 사이트에서 바로 예약할 수 있어서 예약 과정이 한결 쉬워져요. 예약 페이지, 푸터, 서비스 안내 흐름 중간 등에 활용해 보세요.

1. 하이퍼클래스에서 **캘린더**를 만들거나 수정해요. 가용 시간, 팀, 라우팅, 확인 메시지 등을 설정할 수 있어요.
2. WordPress에서 **하이퍼클래스 > 캘린더**로 이동해 넣을 캘린더를 선택해요.
3. 복사한 숏코드를 예약을 받고 싶은 위치에 붙여 넣어 **캘린더**를 삽입해요.
4. 페이지를 업데이트하고 게시해요. 예약은 연결된 하이퍼클래스 서브 계정으로 들어갑니다.

{% hint style="info" %}
- 캘린더는 행동 유도 문구(CTA) 가까이에 두고, 주변 내용은 간단하게 해서 예약에 집중하게 하세요.
- 서비스별로 캘린더가 여러 개 필요한 페이지에서는 캘린더마다 해당 임베드를 넣고, 제목을 달아 구분하세요.
{% endhint %}

## 설문

설문으로 체계적인 피드백과 조사 결과를 모을 수 있어요. NPS 측정, 온보딩 정보 수집, 리드 선별 등에 쓰세요.

1. 하이퍼클래스에서 **설문**을 만들어요. 질문, 로직, 완료 후 액션을 설정할 수 있어요.
2. WordPress에서 **하이퍼클래스 > 설문**으로 이동해 설문 임베드를 복사해요.
3. 페이지에 넣고, 화면 크기에 맞게 잘 보이는지 미리 확인한 뒤 게시해요.
4. 응답과 분석 결과는 하이퍼클래스에 남아 있어서 후속 조치와 리포팅에 쓸 수 있어요.

{% hint style="info" %}
- 설문은 짧게 유지하고, 하이퍼클래스에서 설정한 진행 표시와 완료 메시지를 활용하세요.
- 감사 페이지나 블로그 글 안에 설문을 두면 상황에 맞는 의견을 얻을 수 있어요.
{% endhint %}

## 퀴즈

퀴즈는 참여를 이끌고 리드를 모으는 인터랙티브 콘텐츠예요. 결과 매핑을 쓰면 연락처를 구분하고, 하이퍼클래스에서 결과에 맞는 자동화를 실행할 수 있어요.

1. 하이퍼클래스에서 **퀴즈**를 만들어요. 질문, 점수, 결과, 결과 페이지를 설정할 수 있어요.
2. WordPress에서 **하이퍼클래스 > 퀴즈**로 이동해 퀴즈를 숏코드로 삽입해요.
3. 페이지를 게시해요. 퀴즈 완료 내역이 하이퍼클래스로 동기화되고, 결과를 자동화에 활용할 수 있어요.

{% hint style="info" %}
- 퀴즈는 퍼널 초반 단계의 페이지에 두고, 분명한 혜택을 함께 제시하세요.
- 결과별 CTA를 만들어 가장 알맞은 다음 단계로 안내하세요.
{% endhint %}

## 자주 묻는 질문

### 제출 내역, 예약, 결과는 어디에 저장되나요?
하이퍼클래스에 저장돼요. WordPress에는 임베드만 표시되고, 데이터와 분석 결과는 연결된 서브 계정에 남아 있어요.

### 한 페이지에 캘린더나 리뷰 위젯을 여러 개 넣을 수 있나요?
네, 넣을 수 있어요. 각각 블록 또는 숏코드를 따로 넣으세요. 가장 좋은 성능을 내려면 레이아웃을 단순하게 유지하세요.

### Elementor와 Divi에서도 쓸 수 있나요?
네, 쓸 수 있어요. 페이지 빌더의 숏코드 요소(위젯)를 쓰거나, Gutenberg에서는 해당하는 경우 블록으로 삽입하세요.
