# WordPress PHP 버전 업데이트

**고급 설정**의 PHP 버전 업데이트 기능으로 WordPress 사이트가 사용할 PHP 버전을 직접 고를 수 있어요. 보안과 호환성을 높이고 속도를 개선하고 싶을 때 사용하세요.

## 제공 기능

- PHP 버전 자유 선택: 지원되는 PHP 버전 중에서 골라 바꿀 수 있어요. 안정적으로 운영하기에 알맞은 버전을 선택하세요.
- 간편한 설정: 복잡한 설정 없이 몇 번의 클릭만으로 PHP 버전을 바꿀 수 있어요.
- 보안 강화: 중요한 보안 패치가 적용된 최신 버전을 사용해 사이트를 안전하게 지킬 수 있어요.
- 플러그인·테마 호환성 향상: 더 높은 PHP 버전이 필요한 플러그인과 테마도 문제없이 쓸 수 있어요.
- 성능 향상: 업데이트된 PHP 버전에서는 로딩 속도가 빨라지고 리소스를 더 효율적으로 쓸 수 있어요.

## PHP 버전 업데이트하기

1. **WordPress > 고급 설정 > Server Settings > Choose PHP Version**으로 이동해요. (**Server Settings**는 서버 설정, **Choose PHP Version**은 PHP 버전 선택이라는 뜻이에요.)
2. 사용 가능한 목록에서 원하는 PHP 버전을 선택해요.
3. **확인**을 클릭해요. 사이트가 선택한 PHP 버전으로 자동 업데이트돼요.

이렇게 하면 속도, 호환성, 보안 면에서 최신 개선 사항을 항상 누릴 수 있어요.

## 자주 묻는 질문

### PHP 버전을 왜 업데이트해야 하나요?
업데이트하면 최신 성능 최적화와 보안 패치가 적용되고, 플러그인과 테마와의 호환성도 확보할 수 있어요.

### PHP를 업데이트하면 웹사이트 콘텐츠에 영향이 있나요?
아니요. 콘텐츠와 디자인은 그대로예요. 업데이트는 사이트가 내부적으로 데이터를 처리하는 방식에만 영향을 줘요.

### 플러그인이 최신 PHP 버전과 호환되지 않으면 어떻게 하나요?
호환성 문제가 보이면 같은 설정 메뉴에서 이전에 지원되던 PHP 버전으로 쉽게 되돌릴 수 있어요.

### 업데이트는 얼마나 자주 확인해야 하나요?
몇 달에 한 번 이상, 또는 새 플러그인이나 테마를 설치할 때마다 PHP 버전을 점검하길 권해요.

### PHP를 업데이트할 때 사이트가 중단되나요?
업데이트는 끊김 없이 적용되고, 사이트 중단은 최소화되거나 거의 없어요.
