# 퀴즈 결과 페이지 꾸미기

**퀴즈 빌더**에서 결과 페이지의 섹션 순서를 바꾸고, 섹션 템플릿을 추가하고, 섹션을 숨기고, 점수 구간을 설정하는 방법을 안내해요. 섹션은 끌어서 옮길 수 있고, 모든 퀴즈의 점수는 0~100 기준으로 통일돼요.

이 기능을 쓰면 퀴즈를 만들고, 결과를 분석하고, 관리하는 일이 더 빨라져요. 계정 안의 모든 퀴즈에 같은 기준이 적용되는 점도 장점이에요.

---

# 글로벌 점수 구간 관리란?

결과 페이지의 구성을 직관적으로 정리하고, 모든 퀴즈의 점수를 같은 기준으로 매길 수 있는 기능이에요. 결과 페이지의 섹션을 한곳에서 보고, 순서를 바꾸고, 추가하고, 숨길 수 있어요. 점수 구간 설정으로 모든 퀴즈가 0~100 범위로 환산된 점수를 쓰기 때문에, 퀴즈끼리 비교하거나 자동화를 걸 때도 믿고 쓸 수 있어요.

각 퀴즈에는 다음 기능이 들어 있어요.

- 결과 페이지의 모든 요소를 보여 주는 왼쪽 **Section Visibility**(섹션 표시) 패널
- 끌어서 놓는 방식의 섹션 순서 변경
- 빠르게 만들 수 있는 **섹션 템플릿**
- 레이아웃을 깔끔하게 정리하는 숨기기·삭제 도구
- 글로벌 점수 체계를 정하는 **Configure Score Tiers**(점수 구간 설정)

---

## 섹션 관리와 점수 구간의 장점

결과 페이지를 꾸미는 일이 쉬워지고, 퀴즈 점수가 같은 방식으로 표시되기 때문에 분석·리포팅·자동화가 더 정확해져요.

- **한곳에서 섹션 관리:** 패널 하나에서 모든 섹션으로 바로 이동할 수 있어요.
- **끌어서 놓는 편집:** 퀴즈 요소를 다시 만들 필요 없이 순서를 바로 바꿀 수 있어요.
- **미리 만들어진 섹션 템플릿:** **Overall Score**(전체 점수)나 **행동 유도** 같은 서식 있는 블록을 한 번에 추가할 수 있어요.
- **표시 여부 전환:** 섹션 내용은 그대로 두고 퀴즈 응답자에게만 보이지 않게 숨길 수 있어요.
- **통일된 점수 체계:** 모든 결과가 0~100 퍼센트 기준을 따르므로 퀴즈 간에 일관성이 유지돼요.

## 섹션 관리와 점수 구간을 적용해 퀴즈 설정하기

설정을 제대로 해 두면 퀴즈 섹션과 점수가 올바르게 표시되고, 글로벌 점수 기준도 유지돼요. 아래 순서대로 퀴즈를 만들고 꾸며 보세요.

### 퀴즈 메뉴 열기

**사이트 > 퀴즈**로 이동한 뒤 **+ Add Quiz**(퀴즈 추가)를 클릭하세요.

![사이트 > 퀴즈 화면에서 퀴즈 추가 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055679014/original/jppCPx1LFgCITxJ05VJuO_5LhnPmG3K8nQ.png?1760084003)

### 템플릿 사용하기

템플릿을 쓰면 미리 디자인된 블록을 넣어 퀴즈를 빠르게 만들 수 있어요. **Overall Score**(전체 점수), **Category Score**(카테고리별 점수), **행동 유도** 같은 섹션이 있고, 퀴즈 디자인에 맞게 자동으로 어울려요.

**퀴즈 빌더**에서는 퀴즈 내용을 편집하고, 질문을 추가하고, **Result Template**(결과 템플릿)을 확인할 수 있어요.

![퀴즈 빌더에서 질문과 결과 템플릿을 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055679051/original/pQwMph45D0cMFPAhO1h9DlNLSw3WJrEG-Q.png?1760084027)

### 템플릿 라이브러리

**템플릿 라이브러리**에서는 여러 카테고리의 템플릿 중 원하는 것을 고를 수 있어요. 마음에 드는 템플릿에 마우스를 올리고 **템플릿 선택**을 클릭하면 퀴즈에 적용돼요.

![템플릿 라이브러리에서 템플릿 선택 버튼을 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055679864/original/nyLlW6_C-X4c2nq7jpFtl6uEb3tisb_zZg.png?1760084472)

### 결과 템플릿 열기

1. **퀴즈 빌더** 맨 아래에서 **Result Template**(결과 템플릿) 카드를 찾으세요.
2. **템플릿 수정**을 클릭하세요.

결과 페이지 편집 화면이 열려요. 여기서 섹션 관리, 순서 변경, 점수 구간 설정을 할 수 있어요.

![퀴즈 빌더 아래쪽의 결과 템플릿 카드와 템플릿 수정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055684315/original/GyyZgQzZFY5p6PbhkrINd29crXiqGKMLQQ.png?1760086874)

### 섹션 표시 패널과 끌어서 놓기

**Section Visibility** 패널에는 퀴즈 결과 페이지의 모든 섹션이 순서대로 보여요. 이 패널에서 원하는 섹션으로 바로 이동하거나, 레이아웃 순서를 바꾸거나, 섹션을 잠시 숨길 수 있어요.

왼쪽 패널에서 섹션을 끌어 옮기기만 하면 순서가 바뀌어요. 페이지를 직접 다시 정렬하거나 새로 만들 필요가 없어요.

![왼쪽 섹션 표시 패널에서 결과 페이지 섹션을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055683151/original/o5Jxyp1g3Fr7DuxAl54J_7Bq8UbxudRk7w.png?1760086336)

### 섹션 순서 바꾸기

1. 섹션 이름에 마우스를 올려 끌기 핸들이 나타나게 하세요.
2. 핸들을 클릭한 채로 누르고 있으세요.
3. 섹션을 원하는 위치로 옮기세요.
4. 마우스를 놓으면 라이브 미리보기에 바로 반영돼요.

![섹션을 끌어서 순서를 바꾸는 동작](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055685747/original/B5_RzW9qYeAbG6t3m0AXHWLMA4JUim6I1g.gif?1760087260)

### 섹션 숨기기와 삭제하기

섹션 패널에서 결과 페이지를 꾸밀 수 있어요. 필요에 따라 섹션을 추가하거나, 순서를 바꾸거나, 숨기세요. 표시 여부를 조절하면 결과 페이지를 깔끔하고 핵심 위주로 유지할 수 있어요.

섹션을 숨기면 설정은 그대로 남고 외부 화면에서만 보이지 않아요. 삭제하면 섹션이 완전히 사라져요.

섹션을 숨기거나 삭제하려면 이렇게 하세요.

- **눈 아이콘**을 클릭하면 표시 여부를 켜고 끌 수 있어요.
- **휴지통 아이콘**을 클릭하면 섹션이 영구 삭제돼요.
- 숨긴 섹션은 섹션 패널에서 회색으로 표시돼요.

![섹션 패널의 눈 아이콘과 휴지통 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055684599/original/43NJUyDIZS0rePuev_iLpY7jt9IaFCQLYQ.jpeg?1760086937)

### 글로벌 점수 구간 설정하기

글로벌 점수 구간은 낮음·보통·높음 같은 점수 범위를 퍼센트로 정하는 기능이에요. 이렇게 하면 모든 퀴즈 결과가 같은 기준으로 측정돼요. 이 구간은 워크플로우 트리거와 조건부 자동화에도 쓰여요.

점수 구간을 설정하려면 이렇게 하세요.

1. 결과 페이지 편집기 오른쪽 위의 **Configure Score Tiers**(점수 구간 설정)를 클릭하세요.
2. 점수 레이블과 퍼센트 범위를 정하세요.
3. 각 범위는 **0~100** 사이여야 해요.
4. **저장**을 클릭하면 전체에 적용돼요.

예시는 다음과 같아요.

- 낮음: 0~39%
- 보통: 40~79%
- 높음: 80~100%

**Configure Score Tiers**에서 낮음·보통·높음 기준을 정하고 **저장**을 클릭한 다음, 퀴즈를 **미리보기**로 열어 흐름과 점수가 제대로 나오는지 확인하세요.

![점수 구간 설정 화면에서 낮음, 보통, 높음 범위를 정하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055683016/original/TzAgzJj4gB29dtX8GDnVmLZMjyzRVYEFIw.jpeg?1760086301)

## 자주 묻는 질문

### 숨긴 섹션도 퀴즈 점수에 영향을 주나요?
아니요. 숨긴 섹션은 화면 표시와 점수 계산에서 모두 제외돼요.

### 점수 구간 레이블을 바꿀 수 있나요?
네. 점수 구간 창에서 레이블을 수정할 수 있어요. 다만 모든 값은 0~100 사이여야 해요.

### 기존 퀴즈는 새 방식에서 어떻게 되나요?
기존 퀴즈는 통일된 점수 체계를 쓰도록 자동으로 전환돼요. 전환 후에는 점수 구간 범위가 맞는지 확인하세요.

### 특정 점수 구간에 따라 워크플로우를 실행할 수 있나요?
네. **Quiz Submitted**(퀴즈 제출) 트리거를 사용하고, **Overall Score Tier**(전체 점수 구간)를 Low, Medium, High 중 하나로 필터링하세요.

### 섹션을 삭제하면 이미 제출된 응답은 어떻게 되나요?
삭제는 앞으로 퀴즈를 푸는 사람에게만 적용돼요. 기존 데이터는 그대로 유지돼요.

### 모바일에서도 끌어서 놓기를 쓸 수 있나요?
현재 섹션 순서 변경은 데스크톱 브라우저에서만 쓸 수 있어요. 모바일 지원은 출시 예정이에요.

### 여러 섹션을 한 번에 숨길 수 있나요?
네. **Shift**(또는 **Cmd/Ctrl**) 키를 누른 채 여러 섹션을 선택하면 한 번에 표시 여부를 전환할 수 있어요.
