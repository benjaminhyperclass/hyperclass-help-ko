# 퍼널에 2단계 주문 폼 추가하기

퍼널에 2단계 주문 폼을 추가하고 설정하는 방법을 알려 드려요. 상품과 가격을 연결하고, 폼을 꾸미고, 카트 모드·주문 범프·쿠폰 코드 같은 옵션을 켜는 방법까지 다뤄요.

## 2단계 주문 폼이란?

2단계 주문 폼은 결제 과정을 가벼운 화면 두 개로 나눈 폼이에요. 보통 1단계에서는 연락처와 배송 정보를 받고, 2단계에서는 결제 정보를 받아 주문을 마쳐요. 이렇게 나누면 고객이 느끼는 부담이 줄어 전환율을 높이는 데 도움이 돼요. 이 폼은 어떤 퍼널 단계에든 쉽게 추가할 수 있어서 바로 상품 판매를 시작할 수 있어요.

## 2단계 주문 폼의 장점

- 전환율 높이기: 결제를 짧은 두 단계로 나누면 입력 피로가 줄어 주문 완료율이 높아질 수 있어요.
- 유연한 입력 항목: 항목마다 표시·숨김, 필수·선택을 정해서 필요에 맞게 구성할 수 있어요.
- 카트 모드: 카트 모드와 수량 제한을 쓰면 고객이 원하는 상품만 골라 담을 수 있고, 합계도 한눈에 볼 수 있어요.
- 매출 늘리기: 주문 범프를 지원해서 결제 화면에서 함께 사면 좋은 상품을 쉽게 제안할 수 있어요.
- 명확한 설정: 단계별로 레이블, 머리글, 버튼을 따로 정할 수 있어서 브랜드 톤에 맞는 안내를 이어 갈 수 있어요.

## 상품 설정하기 (사전 준비)

2단계 주문 폼에서 상품을 보여 주고 결제를 받으려면, 먼저 퍼널 단계에 상품을 연결해야 해요. 아래 순서대로 폼에서 쓸 상품과 가격을 준비하세요.

{% hint style="info" %}
이 과정을 시작하기 전에 상품을 먼저 만들어 두세요. 상품 만드는 방법은 '시작하기 - 상품 만들기와 판매' 문서에서 확인할 수 있어요.
{% endhint %}

1. 왼쪽 메뉴에서 **사이트**를 누르고, 사용할 **퍼널**을 연 다음 주문 폼을 넣을 퍼널 단계를 선택하세요.

   ![퍼널 단계 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061956299/original/JndMMDn8gEmdJKnU1k6pzIGGrFxqKMxzfQ.jpeg?1767653151)
2. 오른쪽의 **상품** 탭을 열고 **+ Add Product**(+ 상품 추가)를 누르세요.

   ![상품 탭에서 상품 추가 버튼 누르기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061956301/original/dcb4G5PEHEBkfY7_eRiQpNO7tX0H_GYiNg.jpeg?1767653173)
3. **상품** 드롭다운에서 판매할 상품을 선택하세요. 새 상품이 필요하면 아래의 텍스트 링크를 눌러 새로 만들 수 있어요.

   ![상품 드롭다운에서 상품 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061956365/original/HCf7p1PkhPlU6GKU5nromrqd0WPwz8ZGrA.png?1767653443)
4. **가격**에서 기존 가격을 고르세요. 새 가격이 필요하면 아래의 텍스트 링크를 눌러 새로 만들 수 있어요.

   필요하면 **Product Name Override**(상품명 덮어쓰기)로 주문 폼에 보이는 상품명을 바꾸거나, **Price Display Override**(가격 표시 덮어쓰기)로 주문 폼에 가격이 보이는 방식을 바꿀 수 있어요.

   ![가격 선택 및 덮어쓰기 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061956386/original/GqtqcHzgl3r6U9MRT3RcyacJ7Ygzl_ZbAg.png?1767653578)
5. **추가 옵션**을 눌러 상품을 구매하는 방식을 설정하세요.

   - **다중 허용**을 켜면 고객이 한 번에 상품을 2개 이상 살 수 있어요.
   - **Max per order**(주문당 최대 수량)로 한 번의 주문에서 살 수 있는 최대 수량을 정해요. 1~999개까지 설정할 수 있어요.
   - 상품을 **Main product**(메인 상품)로 쓸지 **Bump product**(범프 상품)로 쓸지 선택하세요.

   ![추가 옵션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061956405/original/tMSy-2mZSUHmLv0lrgOwDdBF_1WeBiV-zA.png?1767653725)
6. 필요한 만큼 같은 방법으로 상품을 더 추가하세요.

## 퍼널에 2단계 주문 폼 추가하기

퍼널 단계에 상품을 연결했다면, 이제 퍼널에 2단계 주문 폼 요소를 추가하고 설정해 보세요.

### 1. 퍼널 단계 열기

**사이트 > 퍼널**로 이동해 퍼널을 열고, 결제 화면을 넣을 퍼널 단계를 선택하세요.

![퍼널 단계로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061955165/original/Xkqp6dN-PmkiG6wYRrvr8508N9kYFKo9qA.png?1767650735)

### 2. 2단계 주문 폼 요소 추가하기

왼쪽 위의 **요소 추가** **(+)**를 누르고, **Order elements**(주문 요소)에서 **2단계 주문 폼** 요소를 선택하세요. 이 요소를 디자인 영역으로 끌어다 놓으세요.

![요소 추가에서 2단계 주문 폼 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061955313/original/G22r2IveUsFhdBWOVPBo6j_m6T0csqkSoQ.png?1767650986)

### 3. 1단계 설정하기

1단계에서는 연락처 정보와 배송 정보를 받아요. 요소 설정에서 **Form options**(폼 옵션)를 열고 **1단계**를 선택하세요. 여기에서 다음 항목을 설정할 수 있어요.

- 제목(Headline)과 부제목(Sub‑headline)
- **회사명**: 숨김, 선택, 필수 중에서 고르세요.
- 화면에 보이는 항목의 플레이스홀더와 표시 이름
- 전화번호: 필수, 선택, 숨김 중에서 고르세요.
- 배송: 켜기 또는 끄기
- 2단계로 넘어가는 버튼의 텍스트

![1단계 폼 옵션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061955499/original/oOvCg0nxSLXWq1pDkLjd0EOUBcpWPn3T5Q.png?1767651206)

### 4. 2단계 설정하기

2단계에서는 결제 정보를 받고 구매를 마쳐요. 요소 설정에서 **Form options**(폼 옵션)를 열고 **2단계**를 선택하세요.

여기에서 결제와 주문 확인 화면의 레이블, 머리글, 버튼 텍스트를 수정할 수 있어요.

![2단계 폼 옵션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061955501/original/Hyz22YJPXZekPnvvvzLLiAbioNqonoXcug.png?1767651232)

### 5. 기타 설정 (선택)

추가 설정으로 상품을 보여 주는 방식, 애드온 제공 여부, 고객의 할인 적용 여부를 정할 수 있어요.

- **Enable cart mode**(카트 모드 켜기)를 켜세요. 퍼널 버전에 따라 보이지 않을 수 있어요.

  카트 모드를 켜면 고객이 같은 주문 폼에서 여러 상품을 구매할 수 있어요. 고객은 원하는 상품을 고르고, **다중 허용**이 켜진 상품은 수량도 조절할 수 있어요.

  카트 모드를 켜지 않으면 주문 폼에서 상품 하나만 선택할 수 있어요. 카트 모드는 지원되는 V2 퍼널 주문 폼에서 쓸 수 있어요.
- **상품 설명**: 주문 폼에 상품 설명과 가격 정보를 보여 줄지 정해요. 정기 결제 상품이라면 상품 설명에 설정 수수료, 체험 기간, 체험 일수, 정기 결제 정보 같은 가격 내역을 보여 줄 수 있어요. 이런 내용을 보여 주고 싶지 않다면 **상품 설명**을 끄세요.
- **Order Bump**(주문 범프)를 켜고 설정하세요. 폼에서 주문 범프를 쓰는 방법은 '폼에서 주문 업셀 사용하기' 문서에서 자세히 볼 수 있어요.
- **Coupon Codes**(쿠폰 코드)를 켜세요.

![기타 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062046385/original/71Kv8sPvzyT3KvfMyMtuAZd3p5ierDZdrA.png?1767718761)

### 6. 폼 꾸미기

요소 설정의 **색상**에서 버튼, 텍스트, 배경 색을 브랜드에 맞게 바꾸세요.

![색상 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061955516/original/7Zn-5E6sEfMORcYuatz8k6cHBC4JOQ1yJg.png?1767651331)

### 7. 미리보기 후 게시하기

퍼널을 게시하기 전에 오른쪽 위의 **미리보기** 버튼을 눌러 주문 폼이 잘 작동하는지 확인하세요. 확인했다면 파란색 **게시** 버튼을 누르세요.

![미리보기와 게시 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061955522/original/DQgK4xQ1pN2ncMim5kA8hjg-FTZZ8dQYSw.png?1767651358)

## 자주 묻는 질문

### 2단계 주문 폼에 상품이 보이지 않아요.
같은 퍼널 단계의 **상품** 탭에 상품과 가격이 하나 이상 추가되어 있는지 확인하세요.

### 고객이 여러 개를 한 번에 살 수 있게 하려면 어떻게 하나요?
**상품 > 추가 옵션**에서 **다중 허용**을 켜고 **Max per order**(주문당 최대 수량)를 설정하세요.

### V1 퍼널에서도 2단계 주문 폼을 쓸 수 있나요?
퍼널에 2단계 주문 폼을 추가할 수 있어요. 카트 모드 같은 최신 설정을 쓰려면 해당 단계를 V2로 옮기는 것을 고려해 보세요.

### 주문 폼에서 구독 상품과 일회성 상품을 모두 판매할 수 있나요?
네. 주문 폼에는 상품에 연결한 **가격**(일회성 또는 정기 결제)이 그대로 반영돼요.

### 모든 주문에 플랫폼 수수료나 처리 수수료를 붙일 수 있나요?
네. 결제 설정에서 처리 요금이나 플랫폼 수수료를 추가할 수 있어요. 자세한 내용은 '고객 결제에 처리 요금 또는 추가 수수료 추가하기' 문서를 참고하세요.
