# 퍼널 안에서 폼 빌더로 폼 편집하기

퍼널 작업 화면을 벗어나지 않고 폼을 편집하고 관리할 수 있어요. 퍼널 빌더 위에 뜨는 **폼 빌더** 팝업에서 폼을 바로 고칠 수 있어, 워크플로우이 끊기지 않아요.

## 퍼널 빌더의 폼 빌더 팝업이란?

폼 빌더 팝업은 퍼널 빌더 위에 큰 창으로 열려요. 이 창에서 폼을 새로 만들거나 편집할 수 있어요. 다른 화면으로 이동하거나 탭을 옮길 필요가 없어서 퍼널 작업에 집중할 수 있어요. 폼 요소, **커스텀 필드**, 스타일 옵션, 테마를 모두 같은 팝업 창에서 쓸 수 있어요.

## 폼 빌더 팝업의 장점

내장 편집기를 쓰면 작업이 중간에 끊기는 일이 줄어요.

- 퍼널 안에서 편집: 퍼널 빌더 안에서 바로 폼을 수정해요.
- 탭 전환 없음: 한 화면에서 편집, 스타일 지정, 저장까지 마쳐요.
- 작업 위치 유지: 퍼널에서 작업하던 위치가 그대로 유지돼요.
- 한 곳에서 모두 관리: 필드, 스타일, 테마를 같은 팝업에서 관리해요.
- 빠른 전환: 폼을 편집하고 퍼널 작업으로 돌아올 때 로딩 시간이 줄어요.

## 폼 빌더 팝업으로 폼 편집하기

다음 순서대로 폼 빌더 팝업을 열고 사용해 보세요.

1. **퍼널 목록 열기**

   왼쪽 메뉴에서 **사이트**를 클릭한 다음, 위쪽의 **퍼널** 탭을 선택하세요. 폼이 들어 있는 퍼널 페이지를 관리하거나 새로 만들 수 있는 퍼널 목록이 열려요.

   ![사이트 메뉴의 퍼널 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935733/original/aCWv-d_I7PuDucHFcwB7hLXoogwh5ZMpaw.png?1750948570)

2. **퍼널 열기 또는 새로 만들기**

   **Search for Funnels**(퍼널 검색) 창에서 기존 퍼널을 찾거나, **+ New Funnel**(새 퍼널 추가)을 클릭해 새 퍼널을 만드세요. 그러면 페이지를 편집하고 폼 요소를 추가할 수 있는 퍼널 작업 화면으로 들어가요.

   ![퍼널 검색 창과 새 퍼널 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935756/original/qNDP0mdVai3YEpmvzT7GFlys4Mjb8LKH4w.png?1750948591)

3. **퍼널 단계 선택하기**

   **단계** 탭을 클릭하면 선택한 퍼널의 모든 단계가 보여요. 폼을 추가하거나 편집할 단계를 고르세요.

   ![퍼널의 단계 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935775/original/7NsC41QzCA9JT3NfneeVWkVQg7dSDve2dw.png?1750948620)

4. **페이지 편집기 열기**

   퍼널 단계 미리보기 아래의 **편집** 버튼을 클릭해 페이지 편집을 시작하세요. 기본 설정을 바꾸려면 **페이지 세부 정보 편집**을 선택하세요. 페이지 전체를 편집하려면 **새 탭에서 편집**을 선택하세요. 퍼널 페이지 빌더가 별도 탭에서 열려요.

   ![편집 버튼과 편집 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935818/original/53D4_SCRwk5exbKD0OsxudpPLtjRQdh2Gg.png?1750948647)

5. **폼 요소 추가하기**

   위쪽 도구 모음의 **+** 아이콘을 클릭해 사이드바를 연 다음, 메뉴에서 **Elements**(요소)를 선택하세요. **Form**(폼) 섹션까지 스크롤해서 **Form** 요소를 페이지로 끌어다 놓으면 설정을 시작할 수 있어요.

   ![요소 메뉴에서 폼 요소를 페이지로 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935841/original/H2kN5ygX6ZYaqOIyRUyvbo-HJYJqwH1TzA.png?1750948678)

6. **기존 폼 선택하기 또는 새 폼 만들기**

   **Form Picker**(폼 선택기)가 나타나면 드롭다운에서 기존 폼을 선택하세요.

   새 폼을 만들려면 **Click Here**(여기를 클릭) 링크를 클릭하세요. **사이트** 메뉴의 **폼** 하위 메뉴가 열리고, 여기에서 새 폼을 만들어 저장할 수 있어요.

   ![폼 선택기에서 폼을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935876/original/R8QYx9u0QiPzhOmq7qWG39-dG7IojhNBpg.png?1750948709)

7. **폼 편집 열기**

   폼을 선택했다면 오른쪽 패널에 있는 **Edit form**(폼 편집) 버튼을 클릭해 **폼 빌더**를 여세요.

   퍼널 빌더 위에 큰 팝업 창이 열려요. 퍼널을 벗어나지 않고 폼 필드, 스타일, 설정을 편집할 수 있어요.

   ![오른쪽 패널의 폼 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935890/original/5ILY-yEugwqvNoYkDQROx8OgLGh1aIycqQ.png?1750948732)

8. **퍼널 페이지 안에서 폼 편집하기**

   팝업에서 폼 빌더가 열리면 **Quick Add**(빠른 추가) 패널과 **커스텀 필드** 패널로 폼을 구성하세요.

   - **Quick Add**: 이름, 이메일, 전화번호처럼 자주 쓰는 필드를 폼으로 바로 끌어다 놓을 수 있어요.
   - **Add Object Fields**(오브젝트 필드 추가): 리드 수집 전략에 맞는 입력 유형을 추가해요. 개인화된 정보나 캠페인별 정보를 모을 때 좋아요.

   편집하는 동안 퍼널 페이지가 배경에 그대로 보여서, 디자인 흐름을 유지한 채 폼을 정확하게 수정할 수 있어요.

   ![폼 빌더 팝업에서 필드를 추가하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071190220/original/8l7ZtA4TuKhgcy9s1GeB8aPJejb5dRaViQ.gif?1778637802)

9. **변경 사항 저장하기**

   폼 편집을 마쳤으면 팝업 오른쪽 위의 **저장** 버튼을 클릭하세요. 수정 내용이 바로 적용되고 팝업이 닫혀요. 페이지를 새로 불러오거나 탭을 옮기지 않아도 퍼널 빌더의 원래 위치로 돌아와요. 퍼널 워크플로우이 끊기지 않아요.

   ![팝업 오른쪽 위의 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048935962/original/-v3fFeR8m0BUpOHQHdxTvEsvW9_gWUs3fw.png?1750948800)

## 폼 빌더의 언어 설정

하이퍼클래스는 계정에 설정된 언어에 맞춰 폼 빌더 화면을 자동으로 바꿔 줘요. 퍼널 빌더 안에서 폼을 편집할 때도 같은 언어로 일관되게 쓸 수 있어요.

### 언어가 적용되는 항목

다음 화면 요소는 시스템에 정해진 번역 키에 따라 자동으로 번역돼요.

- 폼 레이블, 버튼 텍스트, 안내 메시지
- 안전 결제 안내를 포함한 결제 하단 문구
- 상품이 없을 때 나오는 안내 메시지(예: "아직 추가된 상품이 없습니다")
- **General**(일반) 설정 패널과 **고급 설정** 패널의 레이블 및 툴팁

### 적용 방식

계정의 언어 설정에 따라 적용돼요. 언어를 선택하면 폼 빌더에서 지원하는 모든 화면 텍스트가 자동으로 바뀌어요. 따로 설정할 필요는 없어요.

{% hint style="warning" %}
- 폼 빌더 화면에만 적용돼요. 폼 안에 직접 입력한 텍스트에는 적용되지 않아요.
- 사용할 수 있는 번역 언어는 하이퍼클래스에서 지원하는 언어에 따라 달라요.
{% endhint %}

## 자주 묻는 질문

### 기존 폼이나 퍼널에 영향이 있나요?
아니요, 폼과 퍼널은 그대로예요. 팝업은 폼을 열고 편집하는 방식만 바꿔요.

### 팝업에서 폼의 모든 설정을 바꿀 수 있나요?
네, 팝업 창 안에서 필드, 스타일, 테마를 바로 바꿀 수 있어요.

### 저장하지 않고 팝업을 닫으면 어떻게 되나요?
저장하지 않은 변경 사항은 사라져요. 닫기 전에 꼭 저장하세요.

### 모든 사용자가 쓸 수 있나요?
네, 퍼널 빌더와 폼 빌더를 사용할 수 있는 사용자라면 내장 팝업 화면을 볼 수 있어요.

### 이 화면에서 새 폼도 만들 수 있나요?
네, 팝업에서 새 폼 만들기와 편집을 모두 할 수 있어요.
