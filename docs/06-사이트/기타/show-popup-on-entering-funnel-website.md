# 퍼널·웹사이트 페이지에 들어오면 팝업 자동으로 띄우기

방문자가 퍼널이나 웹사이트 페이지에 들어온 뒤 팝업이 자동으로 나타나게 설정하는 방법을 안내해요. 하이퍼클래스는 한 페이지에 팝업을 여러 개 둘 수 있고, 팝업마다 시간 지연을 포함한 트리거를 따로 정할 수 있어요. 방문자가 클릭하거나 스크롤하기를 기다리지 않고 바로 눈길을 끌 수 있어서 전환율을 높이는 데 도움이 돼요.

## 페이지 로드 팝업이란?

페이지 로드 팝업은 방문자가 웹사이트나 퍼널 페이지에 도착하고 잠시 뒤에 저절로 나타나는 메시지나 폼이에요. 방문자가 클릭하거나 스크롤하지 않아도 돼요. 2초 지연 같은 시간 설정으로 작동하며, 방문자의 주의를 바로 끌고 싶을 때 써요.

기간 한정 오퍼를 알리거나, 리드를 모으거나, 방문 초반에 행동을 유도하는 환영 메시지를 보여 줄 때 자주 쓰여요. 한 페이지에 팝업이 여러 개 있으면 지연 시간은 팝업마다 따로 설정해요.

## 페이지 로드 팝업을 쓰면 좋은 점

- 자동화: 방문자가 아무것도 클릭하지 않아도 팝업이 자동으로 열려요.
- 리드 생성: 방문자가 들어온 바로 그 순간에 이메일 목록을 늘리거나 기간 한정 혜택을 안내하기 좋아요.
- 전환 최적화: 시간이 제한된 콜투액션(CTA)을 즉시 띄워 퍼널 전환율을 높일 수 있어요.
- 행동 타기팅: 지연 타이머를 조절해 팝업이 나타나는 시점을 직접 정해요.
- 폭넓은 호환성: 하이퍼클래스 안의 퍼널과 웹사이트 모두에서 쓸 수 있어요.

## 페이지 로드 시 팝업이 뜨도록 설정하기

하이퍼클래스는 한 퍼널 또는 웹사이트 페이지에 팝업을 여러 개 둘 수 있어요. 팝업마다 콘텐츠, 스타일, 트리거를 따로 정할 수 있어요.

사용할 수 있는 트리거 옵션은 다음과 같아요.

- **Delay**(지연): 설정한 시간(초)이 지난 뒤 팝업을 보여 줘요.
- **종료**(Exit Intent): 데스크톱에서 마우스 커서의 움직임으로 보아 방문자가 페이지를 떠나려는 것 같을 때 팝업을 보여 줘요.
- **없음**: 팝업을 자동으로 띄우지 않고, 버튼·이미지·텍스트 링크 같은 수동 트리거로 열 수 있게 둬요.

여러 팝업이 같은 트리거 조건을 쓰면 **Popup Settings**(팝업 설정) 패널에서 우선순위가 더 높은 팝업이 먼저 나타나요.

아래 순서대로 따라 하면 방문자가 페이지에 들어온 뒤 팝업이 자동으로 나타나게 설정할 수 있어요.

#### 1단계: 팝업 설정 열기

1. 서브 계정 대시보드 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. 위쪽 탐색 막대에서 **퍼널** 또는 **웹사이트** 탭을 선택하세요.
3. 원하는 퍼널이나 웹사이트를 열고, 팝업을 추가할 단계(페이지)를 클릭하세요.
4. 파란색 **편집** 버튼을 눌러 페이지 편집기를 여세요.
5. 빌더 위쪽 메뉴 막대에서 **Popup Settings**(팝업 설정) 아이콘을 클릭하세요.

![팝업 설정 아이콘을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046955271/original/a195Uqak0HIUOVjM8Ts8xT_xMOhgN_OkgQ.png?1747767733)

#### 2단계: 팝업 설정하기

1. **Popup Settings** 패널에서 설정할 팝업을 선택하세요.
2. **설정** 탭을 열고, **Show Popup On**(팝업 표시 조건)에서 **Delay**를 선택하세요.
3. 팝업이 나타나기 전에 기다릴 시간(초)을 입력하세요.
4. 팝업 설정을 마치면 페이지를 저장하거나 게시하세요.

![팝업 표시 조건에서 지연을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046955315/original/bpbwilGX2PGqGsAk5ylcztjZsUhBKkVMKA.png?1747767821)

## 자주 묻는 질문

### 방문 한 번(세션)당 팝업을 한 번만 보여 줄 수 있나요?

현재 안내된 팝업 설정은 지연, 종료(Exit Intent), 수동 트리거 같은 트리거 유형 중심이에요. 세션 단위로 표시 횟수를 제한하는 설정은 현재 팝업 설정 절차에 나와 있지 않아요.

### 방문자가 페이지를 떠나려 할 때 팝업을 보여 주려면 어떻게 하나요?

**Show Popup On**(팝업 표시 조건)에서 **종료**(Exit Intent) 트리거를 선택하세요. 데스크톱에서 마우스 커서의 움직임으로 보아 방문자가 페이지를 떠나려는 것 같을 때 팝업이 나타나요.

{% hint style="info" %}
종료(Exit Intent) 감지는 마우스 커서의 움직임을 이용해요. 그래서 데스크톱에서 작동하고, 모바일 터치스크린에서는 같은 방식으로 작동하지 않아요.
{% endhint %}

### 퍼널과 웹사이트 모두에서 쓸 수 있나요?

네. 팝업 트리거는 하이퍼클래스 페이지 빌더의 퍼널과 웹사이트 모두에서 지원돼요.

### 지연 시간이 되기 전에 팝업을 수동으로 열면 어떻게 되나요?

같은 팝업을 지연 타이머가 끝나기 전에 수동으로 열면, 그 페이지 조회에서는 지연 표시가 취소돼요. 팝업이 두 번 나타나는 일을 막아 줘요.

### 한 페이지에 팝업을 두 개 이상 써도 되나요?

네. 하이퍼클래스는 한 퍼널 또는 웹사이트 페이지에 팝업을 여러 개 둘 수 있어요. 팝업마다 콘텐츠, 스타일, 트리거를 따로 정할 수 있어요.

### 여러 팝업이 같은 트리거를 쓰면 어떻게 되나요?

여러 팝업이 같은 트리거 조건을 쓰면 **Popup Settings**(팝업 설정) 패널에서 우선순위가 더 높은 팝업이 먼저 나타나요.
