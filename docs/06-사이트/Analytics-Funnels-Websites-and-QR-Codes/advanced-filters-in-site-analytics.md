# 사이트 분석에서 상세 필터 사용하기

**상세 필터**를 쓰면 도시, 국가, 페이지 제목, 브라우저 같은 조건으로 사이트 분석 데이터를 좁혀 볼 수 있어요. 꼭 확인하고 싶은 방문자 그룹의 데이터만 골라 볼 때 사용하세요.

## 상세 필터란?

**상세 필터**는 퍼널, 웹사이트, 웨비나의 분석 결과에 조건을 하나 이상 걸어 필요한 데이터만 보여 주는 기능이에요. 특정 방문자 그룹만 따로 보고, 방문자 유형별 행동을 비교할 수 있어요. 더 깊이 분석하려고 데이터를 내보낼 필요도 없어요.

필터 기준은 도시, 주 또는 도, 국가, 페이지 제목, 브라우저, 기기 유형, 소스, 매체 중에서 고를 수 있어요. 여러 조건은 **그리고**, **또는** 로 묶어요. 관련 있는 조건끼리 묶고 싶다면 중첩 필터를 만들어 더 세밀하게 나눌 수도 있어요.

사이트 분석 대시보드에 대한 자세한 내용은 "하이퍼클래스에서 사이트 및 퍼널 분석 사용하기" 문서를 참고하세요.

## 상세 필터로 할 수 있는 일

전체 합계만 보는 데서 한 걸음 더 나아가, 비즈니스에 바로 쓸 만한 인사이트를 찾을 수 있어요.

- 데이터를 더 정확하게 나누기: 지역, 트래픽 소스, 페이지 제목, 브라우저 같은 속성으로 분석 범위를 좁혀요.
- 여러 조건을 한꺼번에 분석하기: 필터를 조합해 아주 구체적인 방문자 그룹과 트래픽 패턴을 확인해요.
- 유연한 필터 논리 사용하기: **그리고**, **또는** 조건으로 원하는 분석 화면을 만들어요.
- 필터를 더 세분화해 묶기: 관련 있는 조건을 한데 모으려면 중첩 필터를 추가해요.
- 필터를 쉽게 초기화하거나 조정하기: 필터를 하나씩 제거하거나 전체를 지우고 처음부터 다시 시작할 수 있어요.

## 지원하는 대상

다음 대상에서 상세 필터를 쓸 수 있어요.

- 퍼널
- 웹사이트
- 웨비나

## 상세 필터를 여는 위치

상세 필터는 사이트 분석 대시보드에서 시작해요. 먼저 대상 유형을 고른 뒤 필터 화면을 열어요.

1. 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. 상단 메뉴에서 **분석**을 클릭하세요.
3. 지원하는 대상 유형(퍼널, 웹사이트, 웨비나) 중 하나를 선택하세요.
4. 분석 대시보드 오른쪽 위에 있는 **상세 필터**를 클릭하세요.

![분석 대시보드 오른쪽 위의 상세 필터 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068638220/original/zDjWpmaerO_nrs3k4scgVXF30xNYgeGdpA.png?1775584211)

## 상세 필터 만들고 적용하기

필터를 정확히 만들어야 보고 싶은 방문자 그룹만 골라 볼 수 있어요. 아래 순서대로 따라 하세요.

1. **필터 추가**를 클릭하세요.

   ![필터 추가 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068638774/original/T29dMjCisB-1upKS8br3LzhfGu3HuDZVwg.png?1775584948)
2. 사용할 필터 필드를 고르세요. 그다음 조건(**Is**(같음) 또는 **Is not**(같지 않음))을 선택하고, 포함하거나 제외할 값을 하나 이상 고르세요.

   ![필터 필드, 조건, 값을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068638966/original/beFDOg7mwiqzNFrhViGaShqbsQ5J0oMuvQ.png?1775585107)
3. 다른 필터를 더하려면 **필터 추가**를 클릭하세요.

   ![필터를 추가로 더하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068639132/original/PaWSgbwn83BMyAbkKYQ9AednVy7BDU5OYA.png?1775585195)
4. 전체 필터 논리 안에 조건을 묶어서 넣으려면 **Add Nested Filter**(중첩 필터 추가)를 클릭하세요.

   ![중첩 필터를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068639193/original/qsMOLwhhJ-R1XN_FNLCRzEOJEJgPAN6eNA.png?1775585250)
5. 필터끼리 어떻게 연결할지 **그리고** 또는 **또는**을 선택하세요.

   ![그리고, 또는 연결 방식을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068639229/original/SCXbB0-XdF3LH_kJ-4BNiQzmd49-ETUamA.png?1775585297)
6. **적용**을 클릭하면 분석 대시보드에 필터 결과가 반영돼요.

   ![적용 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068639241/original/ieXe_J0h5VH9Nq-fyqC72UBA9y2pWkV-GQ.png?1775585329)

## 자주 묻는 질문

### 상세 필터를 적용해도 기본 필터가 계속 적용되나요?

네. 선택한 대상이나 기간 같은 기본 필터는 지금 보는 데이터를 그대로 정해요. 상세 필터는 그 결과를 한 번 더 좁혀 줘요.

### 필터 추가와 Add Nested Filter(중첩 필터 추가)는 뭐가 다른가요?

**필터 추가**는 현재 단계의 필터 설정에 조건을 하나 더 넣어요. **Add Nested Filter**는 묶음 필터 안에 조건을 더 넣어요. 그래서 그 조건들이 서로 어떻게 작동할지 먼저 정한 뒤, 나머지 논리와 합칠 수 있어요.

### 페이지를 새로고침하거나 사이트 분석에서 나가면 상세 필터는 어떻게 되나요?

페이지를 새로고침하거나 분석 페이지를 벗어나면 상세 필터가 유지되지 않아요. 나중에 다시 돌아오면 상세 필터를 새로 만들어야 해요.
