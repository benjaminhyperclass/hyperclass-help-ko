# 외부 트래킹을 위한 애널리틱스 (Analytics for External Tracking)

하이퍼클래스의 외부 트래킹을 위한 애널리틱스(Analytics for External Tracking) 기능을 사용하면 중앙화된 애널리틱스 대시보드를 통해 외부에서 호스팅되는 웹사이트와 폼의 방문자 행동을 모니터링할 수 있어요.

서드파티 도구에 의존하지 않고도 페이지 조회수, 폼 제출, 완료율 같은 핵심 성과 지표를 추적할 수 있어요. 이 기능은 외부 데이터를 하이퍼클래스 안으로 직접 가져와서 하나로 통합된 애널리틱스 경험을 제공해요.

## **외부 트래킹을 위한 애널리틱스란?**

외부 트래킹을 위한 애널리틱스는 하이퍼클래스 밖에서 호스팅되는 웹사이트와 폼의 방문자 활동을 추적하고 분석할 수 있게 해주는 기능이에요. 외부 페이지에 트래킹 스크립트를 설치하면, 하이퍼클래스가 핵심 참여 지표를 수집해서 전용 애널리틱스 대시보드에 보여줘요. 이를 통해 여러 플랫폼을 오가지 않고도 성과를 측정하고, 트렌드를 파악하고, 데이터 기반 의사결정을 내릴 수 있어요.

---

## **외부 트래킹을 위한 애널리틱스의 주요 장점**

외부 페이지와 폼에서 방문자가 어떻게 상호작용하는지 이해하면 성과를 최적화하고 전환율을 높이는 데 도움이 돼요. 이 기능은 하이퍼클래스 안에서 바로 중앙화된 가시성과 실행 가능한 인사이트를 제공해요.

- 중앙화된 애널리틱스 대시보드: 서드파티 도구 없이도 모든 외부 페이지와 폼의 성과 데이터를 한곳에서 확인할 수 있어요.

- 전환 인사이트 개선: 폼 조회수, 응답, 완료율을 추적해서 이탈 지점을 파악할 수 있어요.

- 고급 필터링: 도메인, 페이지, 폼별로 성과를 분석해서 더 정확한 인사이트를 얻을 수 있어요.

- 방문자 인텔리전스: 트래픽 소스, 기기, 브라우저, 지역 분포를 파악할 수 있어요.

- 기간별 분석: 날짜 범위 필터와 시각화 차트를 활용해 시간에 따른 트렌드를 모니터링할 수 있어요.

---

## **애널리틱스 대시보드 개요**

애널리틱스 대시보드에서는 외부에서 트래킹되는 자산에 사용자가 어떻게 상호작용하는지 종합적으로 확인할 수 있어요. 핵심 성과 지표를 한데 모으고 트렌드를 시각화해서 성과를 빠르게 파악할 수 있도록 도와줘요.

제공되는 지표:

- 총 페이지 조회수

- 총 폼 조회수

- 응답 수

- 완료율

참여 지표:

- 페이지 평균 체류 시간

- 30초 이내 이탈 (이탈률)

## 기간별 인사이트

시간에 따른 성과를 추적하면 패턴, 참여도가 높은 시기, 전환에 영향을 미치는 문제를 파악하는 데 도움이 돼요. 하이퍼클래스는 트렌드를 효율적으로 분석할 수 있는 시각화 도구를 제공해요.

- 날짜 범위 선택기를 사용해 보고 기간을 원하는 대로 설정할 수 있어요

- 아래 항목에 대해 일별로 나뉜 라인 차트를 확인할 수 있어요:

페이지 조회수

- 폼 조회수

- 응답 수

- 완료율

필터를 사용하면 특정 데이터 포인트만 따로 확인해서 가장 중요한 부분에 집중할 수 있어요. 이를 통해 불필요한 데이터를 줄이고 더 세밀한 수준으로 성과를 분석할 수 있어요.

사용 가능한 필터:

- 도메인

- 페이지

- 폼

필터 활용 예시:

- 특정 랜딩 페이지의 성과 평가하기

- 여러 페이지 간 폼 성과 비교하기

- 성과가 저조한 자산 파악하기

## **방문자 및 트래픽 분석**

방문자를 이해하면 콘텐츠를 더 잘 맞춤화하고 참여 전략을 개선할 수 있어요. 하이퍼클래스는 익명화되고 집계된 방문자 행동 인사이트를 제공해요.

트래픽 분석에 포함되는 항목:

- 기기 유형 (데스크톱, 태블릿, 모바일)

- 상위 브라우저

- 상위 클라이언트 IP (집계 기준)

- 지역 데이터:

국가

- 주/도

- 도시

## 폼 단위 애널리틱스

폼 단위 인사이트를 통해 방문자를 리드로 얼마나 효과적으로 전환시키고 있는지 평가할 수 있어요. 외부 폼이나 HTML 기반 폼을 최적화하는 데 특히 유용해요.

폼별로 확인할 수 있는 데이터:

- 총 조회수

- 응답 수

- 완료율

- 빠른 확인을 위한 최근 업데이트 시각 표시 포함

## **외부 트래킹을 위한 애널리틱스 설정 방법**

정확한 설정을 해야 데이터가 제대로 수집되고 애널리틱스 대시보드가 올바르게 작동해요. 트래킹 스크립트를 설치하지 않으면 애널리틱스 데이터를 확인할 수 없어요.

### **1단계:** 외부 트래킹 스크립트 설치하기

- 하이퍼클래스에서 사이트(Sites) > External Tracking(외부 트래킹) 메뉴로 이동하세요

- 제공된 트래킹 스크립트를 복사하세요

- 외부 웹사이트 또는 퍼널 페이지의 `<head>` 섹션에 스크립트를 붙여넣으세요

- 변경사항을 저장하고 게시(Publish)하세요

### **2단계:** 애널리틱스 대시보드 접속하기

- 사이트(Sites) > Analytics(애널리틱스) 메뉴로 이동하세요

- Analytics 드롭다운을 클릭하세요

- External Tracking(외부 트래킹) 항목을 선택하세요 (스크립트가 연결된 경우에만 표시돼요)

**다른 접속 방법:**

- External Tracking 모달을 여세요

- Analytics 버튼을 클릭하면 자동으로 이동돼요

### **3단계:** 데이터 트래킹 확인하기

- 외부 사이트를 방문해서 활동 데이터를 발생시키세요

- 애널리틱스 대시보드로 돌아가세요

- 페이지 조회수, 폼 조회수 등의 지표가 표시되는지 확인하세요

## **자주 묻는 질문**

**Q: 애널리틱스에서 External Tracking 옵션이 안 보여요.**
트래킹 스크립트가 올바르게 설치되고 연결되어 있어야만 이 옵션이 표시돼요.

**Q: 데이터가 반영되기까지 얼마나 걸리나요?**
활동이 발생한 후 대시보드에 데이터가 반영되기까지 약간의 지연이 있을 수 있어요.

**Q: 폼 조회수(Form Views)와 응답(Responses)의 차이는 무엇인가요?**
폼 조회수는 폼이 노출된 횟수를 집계하는 것이고, 응답은 실제로 제출이 완료된 횟수를 추적하는 거예요.

**Q: 완료율(Completion Rate)은 어떻게 계산되나요?**
완료율은 전체 폼 조회수 대비 실제로 폼을 제출한 사용자의 비율이에요.

**Q: 30초 이내 이탈(Exit Before 30s)은 무슨 의미인가요?**
페이지 방문 후 30초 이내에 이탈한 사용자를 의미하며, 흔히 이탈률(Bounce Rate)이라고 불러요.

**Q: 이전 데이터에는 왜 페이지 평균 체류 시간이 없나요?**
이 지표는 2026년 1월 20일부터 트래킹을 시작했기 때문에, 그 이전 데이터는 제공되지 않아요.

**Q: 여러 도메인을 트래킹할 수 있나요?**
네, 각 도메인에 트래킹 스크립트를 설치하기만 하면 가능해요.
