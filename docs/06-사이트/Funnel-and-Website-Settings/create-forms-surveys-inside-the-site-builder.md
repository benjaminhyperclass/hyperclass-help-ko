# 퍼널·웹사이트 빌더 안에서 폼과 설문 만들기

퍼널 빌더와 웹사이트 빌더를 벗어나지 않고 폼과 설문을 만들고 관리하는 방법을 안내해요. 큰 편집 창에서 바로 작업하고, **Form Picker**(폼 선택기)로 기존 폼과 설문을 다시 쓰고, 준비된 템플릿으로 빠르게 시작할 수 있어요. 주문형 폼에서는 결제도 받을 수 있어요.

## 빌더 안의 폼과 설문이란?

하이퍼클래스는 퍼널이나 웹사이트 캔버스를 떠나지 않고 폼과 설문을 만들고, 추가하고, 관리하는 기능을 제공해요. 큰 팝업 편집 창에서 새 폼을 만들 수 있어요. **Form Picker**로 기존 항목을 추가하고, 필드와 디자인을 바꿀 수도 있어요. 만든 항목은 한곳에 모여서 퍼널, 웹사이트, 웨비나, 이커머스 스토어에서 다시 쓸 수 있어요.

---

## 이런 점이 좋아요

새로 만들지, 기존 항목을 다시 쓸지 정할 때 참고하세요. 페이지를 더 빠르게 만들고, 제출 내역과 성과를 어디서 관리하는지 알아 두는 데도 도움이 돼요.

- **빌더 안에서 바로 작업해요:** 탭을 옮기지 않고 큰 편집 창에서 작업하니 페이지 디자인 흐름이 끊기지 않아요.
- **기존 항목을 다시 쓸 수 있어요:** **Form Picker**로 기존 폼이나 설문을 추가하면 페이지마다 브랜딩과 로직을 똑같이 유지할 수 있어요.
- **템플릿으로 빠르게 시작해요:** 테마 기반 템플릿(신청, 문의, 후원, 주문, 등록, 요청, 구독)에서 시작하면 처음부터 만들지 않아도 돼요.
- **한 번에 편집해요:** 폼이나 설문을 캔버스로 끌어다 놓으면 바로 편집 창이 열려서 필드, 스타일, 동작을 다듬을 수 있어요.
- **한곳에서 관리해요:** 새로 만들거나 추가한 항목이 자동으로 중앙 목록에 모여서 찾고, 복제하고, 다시 쓰기 쉬워요.
- **폼에서 결제를 받아요:** 주문형 템플릿과 **Payment**(결제) 요소를 쓰면 폼에서 바로 상품을 판매하거나 후원금을 받을 수 있어요.

---

## 템플릿과 테마, 뭐가 다른가요?

템플릿은 주문이나 문의처럼 미리 만들어진 폼 구조이고, **테마**는 디자인을 입히는 시각 프리셋이에요. 시작점을 잘 고르면 작업 시간이 줄어요. 둘의 차이를 알아 두면 실수로 스타일을 덮어쓰는 일도 막을 수 있어요.

- **템플릿(구조):** 신청, 문의, 후원, 주문, 등록, 요청, 구독 템플릿이 있어요. 필요에 따라 필드와 설정을 바꿀 수 있어요.
- **테마(시각 스타일):** 원하는 분위기를 빠르게 적용해요. 테마를 바꾸면 지금까지 바꾼 스타일이 모두 사라지니 주의하세요.

![템플릿과 테마 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056126636/original/glfSSZgoBWR2DLqqhl8RNelyJU787RjMWA.png?1760608503)

## Form Picker(폼 선택기)

**Form Picker**를 쓰면 기존 폼이나 설문을 여러 퍼널과 웹사이트에서 다시 쓸 수 있어요. 어느 페이지에서나 같은 경험을 주고 성과도 한 기준으로 측정할 수 있어요.

- 기존 항목을 검색하고, 미리 보고, 선택할 수 있어요.
- 선택한 항목은 캔버스로 끌어다 놓을 수 있고, **편집**을 눌러 바로 수정할 수 있어요.

---

## 한곳에서 관리하기(목록 보기)

직접 만들거나 추가한 폼과 설문은 자동으로 하나의 목록에 모여요. 그래서 계정 안에서 찾고, 복제하고, 다시 쓰기 쉬워요.

- **한 곳에서 관리해요:** 퍼널 빌더나 웹사이트 빌더에서 만든 폼과 설문은 **사이트 > 폼 > 빌더**와 **사이트 > 설문 > 빌더**에도 나타나요. **Form Picker**에서도 선택할 수 있어요.
- 모든 항목을 보고 검색할 수 있어요. 변형본이 필요하면 복제해도 돼요.
- 이름 규칙을 일관되게 유지하면 분석과 재사용이 정확해져요.

---

## 디자인 설정(오른쪽 사이드바)

폼 빌더와 설문 빌더의 오른쪽 사이드바에 디자인과 동작 설정이 모여 있어요. 겉모습과 고급 설정을 빠르게 조정할 수 있어요.

- **필드:** 필드를 추가, 제거하고 순서를 바꿔요. 필요하면 커스텀 필드와 연결해요.
- **스타일:** 글꼴, 간격, 테두리, 배경, 버튼 스타일을 설정해요.
- **고급:** 제출 후 동작, 리디렉션, 로직(설문 전용), 트래킹 등 여러 옵션을 설정해요. 로직은 [폼과 설문의 조건부 로직 V2](../폼/conditional-logic-v2-in-forms-and-surveys.md) 문서에서 자세히 볼 수 있어요.

![폼·설문 빌더의 오른쪽 사이드바](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056145461/original/toH27fwqCzknwNrKLilrLojIYwSUwsNC_w.png?1760618003)

퍼널 안의 폼을 꾸미는 방법은 [폼 빌더로 퍼널 안의 폼 꾸미기](../기타/customizing-forms-inside-funnels-using-the-form-builder.md) 문서를 참고하세요.

### 빌더의 기본 스타일이 새로워졌어요

폼과 설문의 기본 테마가 새롭게 바뀌었어요.

아래와 같은 점이 달라졌어요.

- 페이지나 컴포넌트에 내용이 없을 때의 빈 화면이 더 알아보기 쉬워졌어요.
- 체크박스, 라디오 버튼, 금액 필드 같은 입력 요소의 스타일이 더 다듬어졌어요.
- 플레이스홀더, 레이블 등 지원되는 요소의 모양이 더 일관돼졌어요.

이 변경은 기본 테마와 지원되는 컴포넌트에 자동으로 적용돼요.

---

## 폼·설문 빌더 화면 언어

하이퍼클래스는 계정에 선택된 언어에 맞춰 폼 빌더와 설문 빌더 화면 언어를 자동으로 바꿔요. 다른 언어를 쓰는 사용자도 같은 방식으로 편하게 쓸 수 있어요.

### 번역되는 항목

아래 화면 요소는 시스템에 정해진 번역으로 자동 번역돼요.

- 폼 레이블, 버튼 텍스트, 안내 메시지
- 보안 결제 안내를 포함한 결제 하단 문구
- 상품이 없을 때 나오는 메시지(예: "아직 추가된 상품이 없습니다")
- **General**(일반) 설정 패널과 **고급 설정** 패널의 레이블과 툴팁

### 적용 방식

계정의 언어 설정에 따라 바뀌어요. 언어를 선택하면 빌더 안에서 지원되는 모든 화면 텍스트가 자동으로 바뀌고, 따로 설정할 것은 없어요.

{% hint style="warning" %}
- 빌더 화면에만 적용돼요. 폼이나 설문 안에 직접 입력한 텍스트는 번역되지 않아요.
- 번역은 하이퍼클래스가 지원하는 언어에서만 쓸 수 있어요.
{% endhint %}

## 퍼널·웹사이트 빌더에서 폼과 설문 설정하기

아래 순서대로 하면 폼과 설문을 새로 만들거나 다시 쓰고, 그 자리에서 수정하고, 제출과 결제가 잘 들어오는지 확인할 수 있어요. **Funnel Builder**(퍼널 빌더)와 **웹사이트 빌더** 모두 같은 방식이에요.

1. 빌더를 열어요.
   - **Funnel Builder**에서는 퍼널을 열고 단계를 선택한 다음 편집기로 들어가요.
   - **웹사이트 빌더**에서는 웹사이트를 열고 페이지를 선택한 다음 편집기로 들어가요.

   {% hint style="info" %}
   폼과 설문 기능은 웨비나 빌더와 이커머스 스토어 빌더에서도 쓸 수 있어요.
   {% endhint %}

   ![빌더 편집기에 들어가는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056142567/original/0mJmKU9rEJPdqO2vviPfJY02sF1aeGuzXg.gif?1760616761)

2. 왼쪽 사이드바에서 **Forms & Surveys**(폼 & 설문)를 열어요.
3. 아래 중 하나를 선택해요.
   - **새로 만들기**: 처음부터 새로 만들어요.
   - **Prebuilt Form/Survey Categories**(미리 만든 폼/설문 카테고리): 원하는 카테고리를 골라요.
   - **Add Existing**(기존 항목 추가): **Form Picker**를 열어요.
4. 새 폼이나 기존 폼을 퍼널 페이지로 끌어다 놓아요.

   ![폼과 설문을 선택하는 왼쪽 사이드바](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056142777/original/l4kPmff0Yj0B3ExIkzLNd0yale-Y1TQmgQ.png?1760616823)

5. 폼이나 설문을 만들거나 수정해요.
   - **새로 만들기**를 선택하면 화면의 90% 크기 팝업으로 폼/설문 빌더가 열려요. 여기서 필드를 추가하고, 디자인을 바꾸고, 저장해요.

     ![새로 만들기로 열린 폼 빌더 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056142978/original/VrhC0Ko8RxSfVhOuPiUlVVTHH5OCoAYRlQ.png?1760616919)

   - **Add Existing**(기존 항목 추가)나 **편집**을 선택하면 **Form Picker**가 열려요. 여기서 이전에 만든 항목을 검색하고 선택해요.

     ![Form Picker로 기존 항목을 선택하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056143758/original/9UPt4XVjsn0-BsrwSEotDDxf2nOUUIDcNw.gif?1760617239)

6. 페이지를 저장한 뒤 미리보기에서 테스트 제출을 해 봐요.
7. 제출 내역이 **사이트 > 폼 > 제출** 또는 **사이트 > 설문 > 제출**에 잘 들어왔는지 확인해요.

## 자주 묻는 질문

### 미리 만들어진 템플릿도 수정할 수 있나요?
네. 원하는 템플릿에서 시작한 다음, 큰 빌더 편집 창에서 필드, 스타일, 동작을 바꾸면 돼요.

### 템플릿과 테마는 뭐가 다른가요?
템플릿은 주문이나 문의처럼 시작용 폼 구조예요. 테마는 디자인 프리셋이에요. 테마를 바꾸면 기존에 바꾼 스타일이 모두 사라져요.

### 폼에서 결제를 받으려면 어떻게 하나요?
주문형 템플릿을 고르고 **Payment**(결제) 요소를 추가한 다음, 지원되는 결제 게이트웨이를 연결하세요. **상품**에서 판매할 상품을 설정하고, 실제로 열기 전에 테스트해 보세요. 자세한 내용은 [폼에서 결제 받기(후원 포함)](../폼/payment-in-forms-including-donations.md)와 [폼에서 오더 범프 설정하고 사용하기](../폼/forms-how-to-setup-and-use-order-bumps.md) 문서를 참고하세요.

### 제출 내역과 분석은 어디서 볼 수 있나요?
**사이트 > 폼 > 제출** 또는 **사이트 > 설문 > 제출**에서 제출 내역을 볼 수 있어요. 전환과 이탈 같은 성과는 **분석**에서 확인하세요. 자세한 내용은 [폼과 설문 분석](../폼/analytics-for-forms-and-surveys.md) 문서를 참고하세요.

### 폼을 설문으로(또는 설문을 폼으로) 바꿀 수 있나요?
유형 변환은 지원되지 않아요. 데이터가 올바르게 유지되도록 항목을 복제한 다음, 다른 형식으로 다시 만들어 주세요.

### 주문 폼에도 수동 결제 방식이 나오나요?
결제 설정에서 켜 두었다면 착불 같은 수동 결제 방식이 해당 폼에 나타날 수 있어요. 자세한 내용은 [폼과 설문의 수동 결제 지원](../../08-결제/기타/manual-payment-support-for-forms-surveys.md) 문서를 참고하세요.
