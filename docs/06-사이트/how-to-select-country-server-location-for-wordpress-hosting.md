# WordPress 호스팅 서버 위치(국가) 선택하기

하이퍼클래스에서 WordPress 호스팅으로 사이트를 만들 때 데이터 센터 지역을 고르는 방법을 안내해요. 방문자와 가까운 서버를 고르면 페이지가 더 빨리 열리고 사용자 경험도 좋아져요. 추가 플러그인이나 CDN 설정은 필요 없어요.

## 국가별 서버 선택이란?

국가별 서버 선택은 하이퍼클래스 대시보드에서 바로 쓸 수 있는 WordPress 호스팅 기능이에요. 서버가 만들어지기 전에 사이트 파일을 보관할 데이터 센터(Ashburn, Phoenix, London 등)를 직접 고를 수 있어요. 방문자는 가장 가까운 서버에서 페이지를 불러오므로 성능이 좋아져요. 설정 중에 고른 지역은 사이트 메타데이터에 영구적으로 저장되고, 사이트 카드에도 표시돼요.

## 국가별 서버 선택의 장점

이 기능은 사이트 성능과 사용자 경험에 직접 영향을 줘요.

- 가까운 방문자에게 더 빠르게 로딩돼요. 서버가 가까울수록 페이지가 빨리 열려요.
- 사이트 속도가 좋아져요. 사이트 반응이 빨라져 방문자 만족도가 높아져요.
- 데이터 규정을 쉽게 지킬 수 있어요. EU 트래픽은 EU 서버에, APAC 트래픽은 Sydney나 Singapore 서버에 둘 수 있어요.
- 한 번에 설정할 수 있어요. 지역을 한 번만 고르면 나중에 복잡한 이전 작업을 하지 않아도 돼요.
- 지역이 고정돼요. 캐싱이나 SSL 같은 설정이 실수로 바뀌어 문제가 생기는 일을 막아 줘요.
- 호스팅 정보가 한눈에 보여요. 사이트의 서버 위치와 설정 시간을 대시보드에서 언제든 확인할 수 있어요.

## 선택할 수 있는 위치

{% hint style="info" %}
선택한 위치는 사이트 메타데이터에 저장되고 사이트 카드에 표시돼요. 설정이 끝난 뒤에는 이 구성을 바꿀 수 없어요. 덕분에 성능이 꾸준히 유지돼요.
{% endhint %}

- US – Ashburn
- US – Phoenix
- US – Dallas
- GB – London
- DE – Frankfurt
- NL – Amsterdam
- AU – Sydney
- SG – Singapore

## 사이트의 서버 위치 선택하기

서버 위치 선택은 일반적인 WordPress 사이트 만들기 과정 안에 들어 있어요. 아래 순서대로 원하는 서버 위치를 선택하세요.

### 1단계: 사이트 만들기 시작하기

1. 서브 계정에 로그인한 뒤 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. **WordPress** 탭을 클릭하세요.
3. **+ Create Site**(+ 사이트 만들기) 버튼을 클릭하세요.

   ![사이트 > WordPress 탭에서 사이트 만들기 버튼을 누르는 화면](https://jumpshare.com/share/uQmYN1NqNjuhRC6jYUzw+/Screen+Shot+2025-07-29+at+9.25.33+PM.png)
4. WordPress 플랜을 **구독**하세요.

   ![WordPress 플랜 구독 화면](https://jumpshare.com/share/QFtdSbjKW33eJMu0e9Gw+/Screen+Shot+2025-07-29+at+9.28.54+PM.png)
5. 이미 구독한 사이트가 있다면 해당 사이트의 **설정 완료** 버튼을 클릭해도 돼요.

   ![이미 구독한 사이트의 설정 완료 버튼](https://jumpshare.com/share/nF8KXRuQArGGGzGAMAF8+/Screen+Shot+2025-07-29+at+9.30.44+PM.png)

### 2단계: 설정 방법 선택하기

1. 원하는 생성 방법의 **선택**을 클릭하세요.
   1. **비어 있음** (처음부터 시작)
   2. **Existing Site**(기존 사이트) (다른 WordPress 사이트 복제)
   3. **템플릿** (미리 만들어 둔 레이아웃 사용)
2. 방법을 고른 뒤 **만들기**를 클릭하세요.

   ![생성 방법을 선택하고 만들기를 누르는 화면](https://jumpshare.com/share/YXydGhKJ6PWFvdcVw2jg+/Screen+Shot+2025-07-29+at+9.35.48+PM.png)

### 3단계: 서버 위치 선택하기

1. **Server Location**(서버 위치) 드롭다운을 클릭하세요.
2. 대상 고객과 가장 가까운 데이터 센터를 선택하세요.
3. **WordPress 사이트 생성**(또는 **만들기**)을 클릭하면 선택한 서버 위치로 사이트가 만들어져요.

   ![서버 위치를 선택하고 사이트를 만드는 화면](https://jumpshare.com/share/GPFKpmHHuhF7Xf8V9fZi+/GIF+Recording+2025-07-29+at+9.41.00+PM.gif)

## 서버 위치를 바꿀 수 없는 이유

파일과 데이터베이스가 실제 하드웨어에 저장되기 때문에, 서버가 만들어지는 순간 지역이 고정돼요.

- 나중에 다른 지역이 필요하면 사이트를 새 위치로 복제한 뒤 DNS를 다시 연결하세요.
- 사이트를 삭제하고 다시 만드는 방법도 있지만, 이 경우 데이터가 사라져요.

## 자주 묻는 질문

### 사이트를 만든 뒤에 서버 위치를 바꿀 수 있나요?

아니요. 사이트 설정이 끝나면 서버 위치는 바꿀 수 없어요.

### 서버 위치 선택은 모든 WordPress 사이트 설정 방법에서 쓸 수 있나요?

네. 비어 있음, 기존 사이트 복제, 템플릿 기반 설정 모두에서 쓸 수 있어요.

### 내 사이트에 가장 알맞은 서버 위치는 어떻게 정하나요?

대상 고객이 주로 있는 지역을 생각하고, 가장 가까운 데이터 센터를 선택하세요. 지연 시간을 줄일 수 있어요.

### 특정 서버 위치를 고르면 사이트 성능이 반드시 좋아지나요?

가까운 데이터 센터를 고르면 지연 시간이 줄고 성능이 좋아질 수 있어요. 다만 전체 속도에는 다른 요인도 영향을 줄 수 있어요.

### 고른 지역에 따라 호스팅 요금이 달라지나요?

아니요. 모든 데이터 센터의 요금은 같아요.

### 실수로 잘못된 위치를 골랐다면 어떻게 하나요?

사이트를 삭제한 뒤 다시 만들거나, 올바른 지역으로 사이트를 복제해서 콘텐츠를 옮기세요.

### 그래도 CDN이 필요한가요?

CDN은 선택 사항이지만, 전 세계 방문자를 대상으로 한다면 쓰기를 권해요. 지역 호스팅은 원본 서버의 응답을 빠르게 해 주고, CDN은 전 세계에서 엣지 캐싱을 더해 줘요.
