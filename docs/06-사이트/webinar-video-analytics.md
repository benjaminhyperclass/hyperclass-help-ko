# 웨비나 동영상 분석

라이브, 온디맨드, 반복 웨비나의 시청자 데이터를 대시보드로 확인하는 기능이에요. 시청자가 어느 지점에서 떠나는지, 어떤 세션 성과가 좋은지, 어느 시간대에 열면 전환이 잘 되는지 파악할 수 있어요.

## 웨비나 동영상 분석이란?

웨비나 동영상 분석은 하이퍼클래스의 사이트 분석에 새로 추가된 리포트 영역이에요. 라이브, 온디맨드, 반복 등 모든 웨비나 형식에서 참석자가 어떻게 행동했는지 보여 줘요. 시간대별 그래프, 참여 지표, 세션별 상세 내역을 통해 시청 기록을 등록과 매출을 늘리는 데 쓸 수 있는 정보로 바꿔 줘요.

## 웨비나 동영상 분석의 장점

- 참여가 몰리는 구간과 시청자가 떠나는 구간을 찾아 콘텐츠 흐름을 개선할 수 있어요.
- 등록자 수와 실제 참석자 수를 비교해 홍보 효과를 가늠할 수 있어요.
- 시리즈에서 반복 참석하는 사람을 확인해 충성 고객과 반응이 좋은 주제를 찾을 수 있어요.
- 추세선으로 성과가 좋은 요일과 시간대를 확인해 일정을 최적화할 수 있어요.
- 시각 자료로 된 리포트를 고객이나 팀원과 공유해 빠르게 데이터 기반으로 결정할 수 있어요.

## 온디맨드 웨비나 분석

온디맨드 대시보드는 잠재 고객이 언제든 볼 수 있는 녹화 세션을 중심으로 보여 줘요. 다음 항목이 포함돼요.

- **Total Views**(총 조회수): 누적 재생 횟수
- **Average Watch Time**(평균 시청 시간): 시청자 1명당 평균 시청 시간(분)
- **Engagement Events**(참여 이벤트): 재생(Plays), 일시정지(Pauses), 완료율(Completion %)
- **Drop-off Analysis**(이탈 분석): 시청자가 가장 많이 나가는 시점과 그 시점에 이탈하는 비율

![온디맨드 웨비나 분석 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055529185/original/U67jkNdctcDF8wMaCRn3kY1lb6UuHU3D8g.png?1759931253)

이 지표를 보면 상시 공개 콘텐츠가 지금도 반응을 얻고 있는지, 어느 지점에 더 강한 콜투액션을 넣으면 좋을지 알 수 있어요.

## 라이브 웨비나 분석

라이브 분석은 예정된 방송과 실시간 참석 현황을 집중해서 보여 줘요.

- **Total Registrations vs. Total Attendees**(총 등록자 vs 총 참석자): 불참자가 얼마나 되는지 바로 확인할 수 있어요.
- **Peak Live Viewers**(최대 동시 시청자): 동시에 시청한 최대 인원이며, 타임라인 그래프에 표시돼요.
- **Engagement Spikes**(참여 급증 구간): 재생, 일시정지, 채팅이 몰린 시점을 방송 시간에 맞춰 보여 줘요.

이 데이터로 리마인더 워크플로우와 소통 타이밍을 다듬어 보세요.

## 반복 웨비나 분석

반복 분석은 시리즈에 속한 모든 세션의 데이터를 합쳐서 보여 줘요.

- **Series Overview**(시리즈 개요): **Registrations**(등록자 수), **Attendees**(참석자 수), **Repeat Attendees**(재참석자 수), **Avg Attendance %**(평균 참석률), **Avg Conversion %**(평균 전환율), **Session Count**(세션 수)

  ![반복 웨비나 시리즈 개요 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055525004/original/C7w0i7T-iBh97y2c3U-T1ZJqKCfLueC_-g.png?1759929536)
- **Trend Graphs**(추세 그래프): 세션별 등록·참석 추이를 선으로 보여 줘서 상승세인지 피로감이 쌓이고 있는지 알 수 있어요.

전체를 한눈에 볼 수 있어서, 상시 운영하는 웨비나 프로그램의 주기와 주제를 정할 때 도움이 돼요.

## 웨비나 동영상 분석 설정하기

새 대시보드는 몇 번의 클릭으로 쓸 수 있어요. 다만 설정을 제대로 해 두어야 데이터가 빠짐없이 정확하게 쌓여요.

1. **사이트 > 웨비나**에서 웨비나(라이브, 온디맨드, 반복)를 만들거나 가져오세요.

![웨비나 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055524224/original/vEZ1WGMnNmzQLv7-w8y34e2W-c68TwvXAw.png?1759929193)

{% hint style="info" %}
도움이 필요하면 웨비나 만들기 전체 가이드를 참고하세요.
{% endhint %}

{% hint style="warning" %}
등록 페이지를 게시하고, 폼의 정보가 **연락처**로 들어오는지 확인하세요. 그래야 시청 활동이 CRM 기록과 연결돼요. 그다음 세션을 진행하거나 공개하세요. 하이퍼클래스가 모든 재생, 일시정지, 이탈 이벤트를 자동으로 기록해요.
{% endhint %}

2. **사이트 > 분석 > 웨비나**로 이동하세요. **On-Demand**(온디맨드), **Live**(라이브), **Recurring**(반복) 탭 중 하나를 선택한 다음, 오른쪽 위 필터에서 기간을 고르세요.
3. 그래프의 각 지점에 마우스를 올리면 정확한 수치와 비율을 볼 수 있어요.
4. **빠른 필터**로 기기, 지역 등 조건을 좁혀서 볼 수 있어요. 위젯 자체는 바뀌지 않아요.

![빠른 필터 사용 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055524545/original/LCbvI7hPdzQlIGAqdyAExsd40NbT8jAAdQ.png?1759929375)

## 자주 묻는 질문

### 웨비나 동영상 분석을 쓰려면 추적 코드를 따로 넣어야 하나요?
아니요. 하이퍼클래스 웨비나에는 추적 기능이 기본으로 들어 있어요. 웨비나를 게시하면 자동으로 켜져요.

### 웨비나가 끝나면 얼마 뒤에 지표를 볼 수 있나요?
라이브 웨비나 데이터는 거의 실시간으로 쌓여요. 최종 집계와 완료율은 세션이 끝난 뒤 10~15분 안에 모두 처리돼요.

### 기기 유형이나 유입 경로별로 분석을 나눠 볼 수 있나요?
네. 대시보드 위쪽의 **빠른 필터** 버튼으로 기기, UTM 소스, 커스텀 필드 등 기준을 골라 위젯을 필터링할 수 있어요.

### 시리즈에서 '재참석자'는 어떤 사람을 말하나요?
선택한 기간 안에 같은 반복 웨비나 시리즈의 세션 2개 이상에 참석한 연락처를 말해요.

### 같은 온디맨드 웨비나를 한 사람이 두 번 보면 어떻게 집계되나요?
재생할 때마다 **Total Views**(총 조회수)가 올라가요. 반면 같은 연락처는 **Unique Viewers**(고유 시청자)에 한 번만 집계돼요.

### 웨비나 분석을 내보낼 수 있나요?
네. 위젯이나 표의 오른쪽 위에 있는 점 세 개 메뉴를 클릭한 뒤 CSV 또는 PDF 내보내기를 선택하면 관계자와 공유할 수 있어요.

### 시청 비율이 일정 수준에 도달했을 때 자동화를 실행하려면 어떻게 하나요?
워크플로우 트리거 **Video Tracking**(동영상 트래킹)을 사용하고, 기준이 되는 비율을 설정하세요(예: 50% 시청).

### 새 세션을 추가하면 반복 웨비나 그래프도 자동으로 바뀌나요?
네. 새 세션의 데이터가 수집되는 즉시 **Series Overview**(시리즈 개요)와 **Trend Graphs**(추세 그래프)에 반영돼요.
