# 도메인에 편집 버튼이 보이지 않는 이유

도메인에 **편집** 버튼이 보이지 않을 때 확인해 볼 내용을 안내해요.

## 편집 버튼은 도메인을 처음 추가한 곳에서만 보여요

**편집** 버튼은 도메인을 처음 추가한 위치에서만 표시돼요. 다른 위치에서는 보이지 않아요. 기본 페이지에는 값을 하나만 지정할 수 있기 때문이에요.
