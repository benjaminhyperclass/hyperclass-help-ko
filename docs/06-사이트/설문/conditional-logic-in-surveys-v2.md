# 설문 조건부 로직(Conditional Logic) v2 사용하기

조건부 로직 v2를 쓰면 응답자의 답변이나 상품 선택에 따라 달라지는 설문을 만들 수 있어요. 필드·상품·상품 변형을 표시하거나 숨기고, 응답자를 다른 페이지로 보내거나, 사용자 지정 메시지를 보여 주거나, 리드를 부적격 처리하거나, 설문의 다른 슬라이드로 안내할 수 있어요. 고객마다 설문이나 주문 폼을 따로 만들지 않아도 돼요.

## 설문에서 조건부 로직을 쓰면 좋은 점

조건부 로직은 응답자의 답변에 따라 질문, 상품, 결과를 자동으로 바꿔서 설문을 더 알맞게 만들어 줘요.

- 맞춤 경험: 고객의 선택에 맞는 질문, 상품, 콘텐츠를 보여 줘요.
- 더 똑똑한 주문 폼: 개별 상품과 상품 변형을 상황에 따라 표시하거나 숨길 수 있어요.
- 리드 자격 자동 검증: 응답이나 선택한 상품에 따라 응답자를 적격 또는 부적격으로 처리해요.
- 유연한 설문 분기: 응답자를 다른 슬라이드, 메시지, URL로 안내해요.
- 더 편한 설문 완료: 필요 없는 질문과 관련 없는 상품 옵션을 줄여요.
- 간편한 규칙 관리: 규칙 빌더로 복잡한 조건도 쉽게 관리해요.

---

## 사용할 수 있는 조건부 로직 액션

조건부 로직은 응답자의 답변이나 선택이 정해 둔 조건에 맞을 때 어떤 일이 일어날지 정해요. 하이퍼클래스에서는 다섯 가지 액션을 쓸 수 있어요.

| 액션 | 설명 |
| --- | --- |
| **Show/Hide Fields**(필드 표시/숨기기) | 필드, 요소, 개별 상품, 상품 변형을 표시하거나 숨겨요. |
| **사용자 지정 메시지** | 응답이나 상품 선택에 따라 맞춤 메시지를 보여 줘요. |
| **URL로 리디렉션** | 응답자를 특정 웹페이지로 보내요. |
| **Disqualify Lead**(리드 부적격 처리) | 미리 정한 기준에 따라 응답자를 부적격 처리해요. |
| **Jump To**(이동) | 응답자를 설문의 다른 슬라이드로 보내요. |

{% hint style="info" %}
상품 기반 IF 조건은 **URL로 리디렉션**, **사용자 지정 메시지**, **Disqualify Lead**, **Show/Hide Fields**에서 쓸 수 있어요. **Jump To**는 별도의 설문 이동 액션으로 남아 있어요.
{% endhint %}

---

## 상품 단위 조건부 로직

상품 단위 조건부 로직을 쓰면 고객이 선택한 상품에 따라 주문 폼을 맞춤으로 구성할 수 있어요. 일반 설문 필드의 답변만 조건으로 쓰던 방식에서 나아가, 이제는 개별 상품도 조건으로 써서 설문 결과와 상품 표시를 조절할 수 있어요.

### 상품 기반 조건

개별 상품은 네 가지 조건부 로직 액션에서 IF 조건으로 쓸 수 있어요.

- **URL로 리디렉션**: 고객이 선택한 상품에 따라 특정 웹페이지로 보내요.
- **사용자 지정 메시지**: 상품 선택에 따라 맞춤 메시지를 보여 줘요.
- **Disqualify Lead**: 특정 상품을 선택하면 응답자를 부적격 처리해요.
- **Show/Hide Fields**: 선택한 상품에 따라 필드와 지원되는 요소를 표시하거나 숨겨요.

예시: 고객이 상담 상품을 선택하면 비즈니스 요구 사항을 묻는 질문을 추가로 보여 줘요.

### 개별 상품과 상품 변형 표시/숨기기

이전에는 **Sell Products**(상품 판매) 요소 전체만 표시하거나 숨길 수 있었어요. 이제는 상품 섹션 전체를 숨기지 않고도 더 세밀하게 표시 여부를 조절할 수 있어요.

- 상품 전체 표시/숨기기: **Sell Products** 요소 안의 개별 상품을 조절해요.
- 상품 변형 표시/숨기기: 사이즈나 색상처럼 특정 변형만 보여 줘요.
- 조건부 표시 적용: 고객의 응답이나 선택에 따라 보이는 상품을 바꿔요.
- **Sell Products** 요소 표시/숨기기: 기존처럼 요소 전체를 조절할 수도 있어요.

예시: 티셔츠를 사이즈와 색상별로 파는 주문 폼이 있다고 해 볼게요. 고객의 선택에 따라 관련 있는 상품이나 변형만 보여 주고, 관련 없는 옵션은 숨길 수 있어요.

적용 범위: 상품 단위 조건부 로직은 기존 폼·설문과 새 폼·설문 모두에서 쓸 수 있어요.

## 지원하는 필드와 연산자

조건부 로직은 필드 유형별로 다른 연산자를 지원해요. 연산자를 알맞게 고르면 규칙이 답변과 선택에 맞게 동작해요.

| 필드 유형 | 지원하는 연산자 |
| --- | --- |
| 텍스트 | **Equal To**(같음), **Not Equal To**(같지 않음), **Contains**(포함), **Starts With**(~로 시작), **Ends With**(~로 끝남), **Is Empty**(비어 있음), **Is Filled**(입력됨) |
| 숫자, 점수, 금액 | **Equal To**, **Greater Than**(보다 큼), **Less Than**(보다 작음), **Between**(사이), **Is Empty**, **Is Filled** |
| 날짜 | **Equal To**, **Before**(이전), **After**(이후), **Between**, **Is Empty**, **Is Filled** |
| 드롭다운, 라디오, 체크박스 | **Equal To**, **Not Equal To**, **Is Empty**, **Is Filled** |
| 이용약관(Terms & Conditions) | **Is Checked**(체크됨), **Is Not Checked**(체크 안 됨) |
| 파일 업로드, 서명 | **Is Empty**, **Is Filled** |

표시 여부를 조절할 수 있는 요소로는 텍스트, HTML, 이미지, 상품 관련 요소도 있어요.

{% hint style="info" %}
캘린더 필드는 지원하지 않아요. 상품 기반 조건은 조건부 로직 빌더에 나오는 상품 선택 옵션을 사용해요.
{% endhint %}

## 설문에 조건부 로직 설정하기

조건부 로직을 설정하면 응답자가 설문을 어떻게 진행하고 어떤 상품과 필드를 보게 될지 정할 수 있어요. 규칙을 만들기 전에 필요한 설문 질문, 상품, 상품 변형, 슬라이드를 먼저 준비해 주세요.

### 1단계: 설문 빌더 열기

1. **사이트 > 설문**으로 이동하세요.
2. 기존 설문을 열거나 새 설문을 만드세요.
3. 필요한 질문, 슬라이드, **Sell Products** 요소를 추가하세요.
4. **설문 빌더**에서 **Conditional Logic**(조건부 로직)을 클릭하세요.

   ![설문 빌더에서 Conditional Logic 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084140334/original/kH-u_pby8vFjxcuM0J-yK7TD6wXFL3LGHg.png?1792928604)

### 2단계: 조건부 로직 규칙 만들기

1. **Add New Condition**(새 조건 추가)을 클릭하세요.
2. **액션 선택**에서 다음 중 하나를 고르세요: **Show/Hide Fields**, **URL로 리디렉션**, **사용자 지정 메시지**, **Disqualify Lead**, **Jump To**.
   ![조건부 로직 액션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084140345/original/47yvSUYzPnxxk3NOcP19KBsriq7prWpWGw.png?1792928638)
3. 다음 항목으로 IF 조건을 설정하세요.

   - **필드 선택**: 지원하는 설문 필드나 상품을 고르세요.
   - **주/도 선택**: 알맞은 비교 연산자를 고르세요.
   - **Provide Value**(값 입력): 필요한 경우 비교할 값을 입력하거나 선택하세요.
4. 필요하면 **그리고** 또는 **OR**(또는)로 조건을 더 추가하세요.

{% hint style="info" %}
규칙 하나에는 **그리고** 조건이나 **OR** 조건 중 한 가지만 쓸 수 있어요. 두 가지를 함께 쓸 수는 없어요.
{% endhint %}

### 3단계: 상품 표시 설정하기

상품과 상품 변형을 상황에 따라 표시하거나 숨기려면 다음과 같이 설정하세요.

1. 액션으로 **Show/Hide Fields**를 선택하세요.

   ![Show/Hide Fields 액션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084140354/original/IbV6T91mGcmtuyje5KWLV9rNt_ENaUKtdA.png?1792928677)
2. 규칙이 적용될 조건을 설정하세요.
3. 표시 여부를 적용할 대상을 고르세요.

   - **Sell Products** 요소 전체
   - 개별 상품
   - 특정 상품 변형
4. 대상을 **표시**할지 **숨기기**할지 고르세요.
5. 규칙을 저장하세요.

예시: 고객이 "Premium Package"를 선택하면 프리미엄 상품 옵션을 보여 주고 관련 없는 상품은 숨겨요.

### 4단계: 규칙 저장하고 테스트하기

1. 설정한 조건을 저장하세요.
2. 설문 미리보기를 여세요.
3. 여러 가지 응답과 상품 선택으로 테스트하세요.
4. 필드, 상품, 상품 변형이 알맞게 나타나거나 사라지는지 확인하세요.
5. 해당하는 경우 리디렉션, 사용자 지정 메시지, 부적격 처리, 슬라이드 이동도 테스트하세요.

## 규칙 동작 방식과 알아둘 점

조건부 로직은 정해진 순서로 규칙을 평가해서 어떤 액션을 실행할지 정해요. 규칙의 우선순위와 지원 범위를 알아 두면 예상 밖의 결과를 막을 수 있어요.

- 규칙 우선순위: 규칙은 위에서 아래로 평가해요.
- 제출 시 액션: 리디렉션, 메시지 표시, 부적격 처리는 처음으로 조건에 맞는 규칙을 사용해요.
- 표시/숨기기 규칙: 나중에 조건에 맞는 규칙이 앞선 표시 규칙을 덮어쓸 수 있어요.
- **Jump To**: 응답자가 다른 슬라이드로 넘어갈 때 규칙을 평가해요.
- **그리고**/**OR** 조건: 규칙마다 연결 방식을 한 가지만 쓸 수 있어요.
- 설문 호환성: 조건부 로직 v2는 새로 만들었거나 복제한 설문에서 쓸 수 있어요.
- 상품 호환성: 상품 단위 조건부 로직은 기존 폼·설문과 새 폼·설문 모두에서 쓸 수 있어요.
- 스냅샷: 계정 스냅샷에는 조건부 로직 규칙이 포함되지 않아요.
- **Query Key**(쿼리 키): 설정 문제를 막으려면 설문 필드마다 고유한 **Query Key**를 지정해야 해요.

{% hint style="info" %}
게시하기 전에 모든 설문 경로와 상품 선택 조합을 미리보기로 확인하세요. 특히 여러 표시 규칙이 같은 상품이나 상품 변형을 조절할 때 꼭 확인해 보세요.
{% endhint %}

## 자주 묻는 질문

### 개별 상품 선택을 조건으로 쓸 수 있나요?
네. 개별 상품을 **URL로 리디렉션**, **사용자 지정 메시지**, **Disqualify Lead**, **Show/Hide Fields**의 IF 조건으로 쓸 수 있어요.

### **Sell Products** 요소 전체를 숨기지 않고 개별 상품만 숨길 수 있나요?
네. **Sell Products** 요소는 그대로 보이게 두고 개별 상품만 조절할 수 있어요.

### 특정 상품 변형만 표시하거나 숨길 수 있나요?
네. 조건부 로직은 상품 변형 단위의 표시 설정을 지원해요. 설정한 조건에 따라 관련 있는 상품 옵션만 보여 줄 수 있어요.

### 이전 버전의 폼과 설문에서도 상품 단위 조건부 로직을 쓸 수 있나요?
네. 상품 단위 기능은 기존 폼·설문과 새 폼·설문 모두에서 쓸 수 있어요.

### **Sell Products** 요소 전체를 숨기는 기능도 계속 쓸 수 있나요?
네. **Sell Products** 요소 전체에 쓰던 기존 표시/숨기기 기능도 그대로 쓸 수 있어요.

### 상품 선택으로 **Jump To** 액션을 실행할 수 있나요?
이번 상품 단위 기능에서 안내하는 액션은 **URL로 리디렉션**, **사용자 지정 메시지**, **Disqualify Lead**, **Show/Hide Fields** 네 가지예요. 상품 기반 **Jump To** 조건은 이번 업데이트에 명시되어 있지 않아요.

### 여러 표시 규칙이 동시에 조건에 맞으면 어떻게 되나요?
규칙은 위에서 아래로 평가하고, 나중에 조건에 맞는 **Show/Hide Fields** 규칙이 앞선 규칙을 덮어쓸 수 있어요.
