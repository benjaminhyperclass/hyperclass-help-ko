# 설문 응답을 확인하고 내보내는 방법

하이퍼클래스 설문(Survey)을 사용하면 연락처(Contacts)로부터 소중한 피드백과 데이터를 수집할 수 있어요. 그런데 누군가 응답을 제출하면 그 답변들은 실제로 어디로 가는 걸까요? 이 글에서는 설문 응답이 정확히 어디에 저장되는지, 어떻게 확인할 수 있는지, 연락처 상세(레코드)와 어떻게 연결되는지, 그리고 응답을 내보내는(Export) 방법은 무엇인지 자세히 설명해요.

# **설문 응답이란?**

설문 응답(Survey Submissions)은 연락처가 설문(Surveys)을 작성하고 제출한 답변 기록이에요. 이 응답들은 하이퍼클래스의 설문(Surveys) 섹션 안 응답(Submissions) 탭에 저장되며, 사용된 필드에 따라 연락처 프로필에도 함께 반영돼요.

---

## **설문 응답 확인의 주요 장점**

설문 답변이 어디에 저장되는지 알아두면 소중한 고객 인사이트를 놓치지 않고, 피드백에 빠르게 대응할 수 있어요.

- 
모든 응답을 한 곳에서 쉽게 확인

- 
분석이나 기록 보관을 위해 응답 내보내기(Export)

- 
제출된 데이터로 연락처 상세 자동 업데이트

- 
작성된 설문을 기준으로 응답 필터링

---

## 설문 응답 확인하는 방법

### **설문 메뉴에서 응답 확인하기**

설문을 통해 제출된 답변을 확인하려면:

- 
왼쪽 메인 네비게이션 메뉴에서 **사이트(Sites)**를 클릭하세요.

- 
**설문(Surveys)**에 마우스를 올린 후, 드롭다운 메뉴에서 응답(Submissions)을 선택하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080333122/original/koZpCc0FhdaVJuaXw0VtMaejrkx6Eb7HaQ.png?1788852260)

- 
응답(Responses) 테이블에는 각 응답의 연락처 정보, 제출 시간, 그리고 답변한 모든 질문이 표시돼요.

- 
개별 항목을 클릭하면 상세 응답 데이터를 열람할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080333249/original/5Anaw4RK76Md3ORdlpavlmK3ph2K8LKw4w.png?1788852319)

- 
좌측 상단의 설문 필터(Filter) 드롭다운을 사용하면 특정 설문의 결과만 필터링해서 볼 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080333293/original/7zJ16O7BVxAXS50UsFpJscUMHw94ysG1YQ.png?1788852355)

### 설문 빌더 안에서 응답 확인하기

이미 설문을 작업하는 중이고 바로 그 응답을 확인하고 싶을 때 사용하는 방법이에요.

- **사이트(Sites) → 설문(Surveys) → 빌더(Builder)**로 이동하세요.
- 응답을 확인하고 싶은 설문을 여세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080333700/original/0-Y9SO3EiYVI6r1w2IfJKHjW8s3b5baOyg.png?1788852660)

- 설문 빌더(Survey Builder)에서 **응답(Submissions)**을 클릭하세요. 선택한 설문에 대해 받은 응답을 확인할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080334887/original/J5JVimRQYm09BDw7bLSF1ELk7gVV_T1b8A.png?1788853328)

- 개별 응답을 열어 응답자의 전체 답변을 확인하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080335045/original/lp35ennplnzXmnVzawW7OYueHH9uRduZAQ.png?1788853382)

## **연락처 상세에서 설문 답변 확인하기**

설문 답변은 연락처 상세(레코드)에서도 확인할 수 있어요:

- 
매핑된 필드(이름, 이메일, 전화번호 등)에 대한 답변은 자동으로 연락처 상세에 반영돼요.

- 그 외의 답변들은 연락처 정보 내 **설문(Survey) | 설문 이름** 드롭다운에서 확인할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080335188/original/W15Zr9G2TKou9v66O9gY5k6HedcFj1dK1A.png?1788853492)

## **설문 응답 내보내기**

응답 화면 우측 상단의 파란색 내보내기(Export) 버튼을 클릭하면 오프라인 분석이나 기록 보관을 위해 응답을 다운로드할 수 있어요. 설문 응답을 다운로드할 수 있는 링크가 이메일로 발송돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080333386/original/cNIyxbFCliMOj_b12VQRcj137p_8QlDWcQ.png?1788852430)

## **자주 묻는 질문**

**Q: 설문 답변을 기준으로 자동화를 실행할 수 있나요?**
네, 워크플로우(Workflow)에서 "Survey Submitted(설문 제출됨)" 트리거(Trigger)를 사용하면 자동화를 시작할 수 있어요.

**Q: 설문 답변이 CRM에 자동으로 반영되나요?**
설문에 연락처 속성과 일치하는 필드(예: 이메일)가 포함되어 있다면, 해당 필드는 연락처 상세에 자동으로 업데이트돼요.

**Q: 같은 연락처가 여러 번 제출한 응답도 각각 추적할 수 있나요?**

네, 같은 연락처가 동일한 설문을 여러 번 제출하더라도 모든 응답은 개별적으로 추적돼요. 반복적인 피드백 수집이나 이벤트 체크인에 유용해요.

**Q: 여러 설문을 운영 중일 때, 응답이 어느 설문에 속하는지 확인할 수 있나요?**

네, 각 응답 기록에는 연결된 설문의 이름이 표시되며, 드롭다운을 사용해 설문 이름으로 결과를 필터링할 수도 있어요.
