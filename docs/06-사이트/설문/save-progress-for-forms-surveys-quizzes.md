# 폼, 설문, 퀴즈의 진행 상황 저장하기

응답자가 여러 단계로 구성된 폼(Form), 설문(Survey), 퀴즈를 작성하다가 중단해도 내용을 잃지 않고 나중에 이어서 작성할 수 있게 해줍니다

이 문서에서 배울 내용

이 문서에서는 진행 상황 저장(Save Progress) 기능이 여러 단계로 구성된 폼, 설문, 퀴즈에서 응답자의 데이터를 자동으로 보존하여, 응답자가 원할 때 돌아와서 제출을 완료할 수 있도록 하는 방법을 설명해요.

기능을 활성화하는 방법, 응답자 입장에서 어떻게 작동하는지, 그리고 진행 상황 이어하기(Resume Progress) 모달이 브랜딩에 자동으로 맞춰지는 방식을 알아볼게요.

## 1. 진행 상황 저장이란?

진행 상황 저장(Save Progress)은 응답자가 여러 단계로 구성된 폼, 설문, 퀴즈를 완료하지 않고 이탈할 때 데이터를 자동으로 보존하는 기능이에요. 이 기능이 활성화되어 있으면, 응답자가 브라우저를 닫거나 페이지를 새로고침하거나 다른 곳으로 이동하더라도 입력한 답변이 안전하게 저장돼요.

응답자가 동일한 폼, 설문, 퀴즈로 다시 돌아오면 진행 상황 이어하기(Resume Progress) 모달이 표시되어, 이전에 작성하던 내용을 이어서 진행할지 새로 시작할지 선택할 수 있어요. 이 기능은 시간이 오래 걸리거나 많은 정보를 입력해야 하는 긴 폼에 특히 유용해요.

진행 상황 저장은 설정(Settings) 탭에 있는 나가기 시 저장 확인(Save Exit Confirmation) 토글로 제어하며, 하이퍼클래스의 모든 다단계 폼, 설문, 퀴즈에서 사용할 수 있어요.

## 2. 주요 장점

진행 상황 저장은 응답자 경험을 개선하고, 작업 내용을 잃어버리는 불편함을 없애 제출 완료율을 높여줘요. 주요 장점은 다음과 같아요:

**자동 진행 상황 저장** — 응답자가 다단계 폼, 설문, 퀴즈를 제출하기 전에 이탈하면 별도의 수동 작업 없이 데이터가 자동으로 저장돼요.

**간단한 토글 제어** — 설정(Settings) 탭의 나가기 시 저장 확인 토글로 진행 상황 저장을 켜거나 끌 수 있어서, 기능 활성화 여부를 완전히 제어할 수 있어요.

**끊김 없는 재개** — 응답자는 나중에 다시 돌아와서 중단했던 지점부터 정확히 이어서 작성할 수 있어, 맥락을 유지하고 불편함을 줄일 수 있어요.

**유연한 재개 옵션** — 진행 상황 이어하기 모달을 통해 응답자는 저장된 제출 내용을 이어서 작성하거나 새로 시작하는 것 중 선택할 수 있어요.

**자동 브랜딩 적용** — 진행 상황 이어하기 모달은 CTA(행동 유도) 버튼 색상과 레이블 폰트를 포함해 폼, 설문, 퀴즈의 브랜딩을 자동으로 반영해요.

**기기 간 호환성** — 진행 상황 저장은 데스크톱과 모바일 환경 모두에서 완벽하게 지원되어, 기기와 상관없이 일관된 기능을 제공해요.

## 3. 진행 상황 저장 작동 방식

진행 상황 저장이 활성화되면, 하이퍼클래스는 응답자의 활동을 자동으로 감지하고 제출을 완료하기 전에 이탈할 경우 데이터를 보존해요. 응답자 입장에서 이 기능이 작동하는 방식은 다음과 같아요:

**1단계: 응답자가 폼 작성 시작**
응답자가 진행 상황 저장이 활성화된 다단계 폼, 설문, 퀴즈를 작성하기 시작해요. 질문에 답하며 여러 단계를 거쳐 이동해요.

**2단계: 제출 전 이탈**
응답자가 폼을 완료하고 제출하기 전에 브라우저를 닫거나, 페이지를 새로고침하거나, 다른 웹사이트로 이동해요. 이때 진행 상황이 자동으로 저장돼요.

**3단계: 폼으로 재방문**
응답자가 동일한 폼, 설문, 퀴즈 URL로 다시 돌아오면 화면에 "제출 진행 중(Submission in progress)" 모달이 자동으로 표시돼요.

**4단계: 이어하기 또는 새로 시작 선택**
모달에는 중단했던 지점부터 이어서 진행하거나, 새로 제출을 시작하는 두 가지 옵션이 표시돼요. 응답자는 원하는 옵션을 선택하여 진행해요.

자동 동작

진행 상황은 나가기 시 저장 확인 토글이 활성화되어 있을 때만 저장돼요. 이 기능이 비활성화되어 있으면, 폼을 이탈한 응답자는 돌아왔을 때 처음부터 다시 시작해야 해요.

## 4. 진행 상황 저장 활성화 방법

다단계 폼, 설문, 퀴즈에서 진행 상황 저장을 활성화하는 과정은 매우 간단해요. 다음 단계를 따라 기능을 활성화하세요:

**1단계: 폼, 설문, 퀴즈 열기**
진행 상황 저장을 활성화하려는 폼, 설문, 퀴즈로 이동하세요. 해당 항목을 편집 모드로 여세요.

**2단계: 설정 탭으로 이동**
폼, 설문, 퀴즈 빌더 화면에서 설정(Settings) 탭을 클릭하세요.

**3단계: 나가기 시 저장 확인 토글 활성화**
설정 탭에서 나가기 시 저장 확인(Save Exit Confirmation) 토글을 찾으세요. 토글을 켜짐 위치로 전환하여 진행 상황 저장을 활성화하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077169076/original/F9MqzU5XoKPFz5p-itqeF2W-kBo3eQVddg.png?1785342832)

**4단계: 변경 사항 저장**
변경 사항을 적용하려면 폼, 설문, 퀴즈를 저장하세요. 이제 진행 상황 저장 기능이 활성화되어 이후 응답자의 데이터를 보존해요.

참고

기존의 폼, 설문, 퀴즈는 나가기 시 저장 확인 토글을 직접 활성화하기 전까지는 변경되지 않아요. 이 기능은 선택적으로 켜야 하는 옵트인(opt-in) 방식이며, 자동으로 활성화되지 않아요.

## 5. 진행 상황 이어하기 모달 브랜딩

진행 상황 이어하기 모달은 폼, 설문, 퀴즈의 브랜딩 설정을 자동으로 상속받아, 응답자에게 일관된 시각적 경험을 제공해요. 이 자동 스타일링은 두 가지 핵심 디자인 요소에 적용돼요:

**브랜딩 요소 1: CTA 버튼 색상**
진행 상황 이어하기 모달의 CTA(행동 유도) 버튼(이어하기, 새로 시작)은 폼, 설문, 퀴즈 설정에서 지정한 푸터 색상을 그대로 사용해요. 이를 통해 별도의 추가 설정 없이도 모달 버튼이 기존 브랜드 색상과 일치하게 돼요.

**브랜딩 요소 2: 텍스트 폰트**
진행 상황 이어하기 모달에 표시되는 모든 텍스트는 폼, 설문, 퀴즈 설정에서 지정한 레이블 폰트를 사용해요. 이를 통해 모달과 나머지 폼 화면 간의 타이포그래피 일관성이 유지돼요.

자동 설정

진행 상황 이어하기 모달은 별도로 설정할 필요가 없어요. 모든 브랜딩 설정은 폼, 설문, 퀴즈 설정에서 자동으로 상속돼요.

## 7. 자주 묻는 질문

**Q: 진행 상황 저장이 단일 단계 폼에서도 작동하나요?**
아니요. 진행 상황 저장은 여러 단계로 구성된 폼, 설문, 퀴즈에서만 사용할 수 있어요. 단일 단계 폼은 보통 한 번에 완료되기 때문에 이 기능을 지원하지 않아요.

**Q: 응답자의 진행 상황은 얼마나 오래 저장되나요?**
공식 변경 내역에는 저장 기간에 대한 제한이 명시되어 있지 않아요. 응답자는 언제든지 돌아와서 제출을 완료할 수 있으며, 다시 폼에 접속하면 저장된 데이터를 확인할 수 있어요.

**Q: 진행 상황 이어하기 모달을 커스터마이즈할 수 있나요?**
진행 상황 이어하기 모달은 폼의 푸터 색상과 레이블 폰트를 자동으로 상속받아요. 추가 커스터마이즈 옵션에 대해서는 공식 변경 내역에 언급되어 있지 않아요. 이 모달은 별도의 수동 설정 없이도 기존 브랜딩과 일치하도록 설계되어 있어요.

**Q: 진행 상황 저장을 활성화하면 기존 응답자 데이터에 영향이 있나요?**
아니요. 진행 상황 저장을 활성화해도 이전에 제출된 데이터나, 이 기능이 활성화되기 전에 진행 중이던 제출 내용에는 영향을 주지 않아요. 이 기능은 토글이 활성화된 이후의 새로운 폼 세션에만 적용돼요.

**Q: 진행 상황 저장이 모바일 기기에서도 작동하나요?**
네. 진행 상황 저장은 데스크톱과 모바일 환경 모두에서 완벽하게 지원돼요. 응답자는 어떤 기기에서든 폼을 이탈했다가 다시 돌아올 수 있으며, 진행 상황이 보존돼요.

**Q: 활성화한 후 진행 상황 저장을 다시 비활성화하면 어떻게 되나요?**
나가기 시 저장 확인 토글을 비활성화하면, 이후 폼을 이탈하는 응답자의 진행 상황은 저장되지 않아요. 이 기능은 토글이 켜져 있을 때만 진행 상황을 저장해요.

**Q: 응답자가 다른 기기에서 저장된 진행 상황에 접근할 수 있나요?**
공식 변경 내역에는 저장된 진행 상황이 기기별로 구분되는지, 계정 기반인지에 대한 명시가 없어요. 진행 상황은 응답자가 동일한 폼 URL로 돌아왔을 때 저장되지만, 기기 간 접근에 대한 세부 내용은 제공된 정보에 포함되어 있지 않아요.

**Q: 나가기 시 저장 확인 토글은 어디에 있나요?**
나가기 시 저장 확인 토글은 폼, 설문, 퀴즈 빌더 화면의 설정(Settings) 탭에 있어요. 해당 항목을 편집 모드로 열고 설정으로 이동하면 토글을 찾을 수 있어요.
