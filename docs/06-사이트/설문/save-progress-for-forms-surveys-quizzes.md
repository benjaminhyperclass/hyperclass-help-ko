# 폼·설문·퀴즈 진행 상황 저장 기능 사용하기

여러 단계로 이루어진 폼, 설문, 퀴즈에서 응답자가 중간에 나갔다가 작성하던 내용을 잃지 않고 이어서 작성할 수 있게 하는 기능이에요. 이 문서에서는 기능을 켜는 방법, 응답자 화면에서 동작하는 방식, 이어하기 모달에 브랜딩이 적용되는 방식을 알려 드려요.

## 진행 상황 저장이란?

진행 상황 저장은 응답자가 여러 단계로 된 폼, 설문, 퀴즈를 끝내기 전에 나가면 입력한 내용을 자동으로 보관해 주는 기능이에요. 이 기능을 켜 두면 응답자가 브라우저를 닫거나 페이지를 새로고침하거나 다른 곳으로 이동해도 답변이 안전하게 저장돼요.

응답자가 같은 폼, 설문, 퀴즈로 다시 들어오면 **Resume Progress**(진행 상황 이어하기) 모달이 나타나요. 응답자는 작성하던 곳에서 이어서 하거나, 새 제출로 처음부터 다시 시작할 수 있어요. 시간이 오래 걸리거나 정보를 찾아가며 작성해야 하는 긴 폼에서 특히 유용해요.

진행 상황 저장은 **설정** 탭의 **Save Exit Confirmation**(나가기 전 저장 확인) 토글로 켜고 끄며, 하이퍼클래스의 여러 단계로 된 모든 폼, 설문, 퀴즈에서 쓸 수 있어요.

## 주요 장점

진행 상황 저장을 쓰면 작성하던 내용이 사라지는 불편이 줄어서 응답자 경험이 좋아지고 완료율도 높아져요.

- 자동 진행 저장: 응답자가 여러 단계로 된 폼, 설문, 퀴즈를 제출하기 전에 나가면 입력한 내용이 자동으로 저장돼요. 따로 할 일은 없어요.
- 간단한 토글 설정: **설정** 탭의 **Save Exit Confirmation** 토글로 기능을 켜고 끌 수 있어요. 언제 사용할지 직접 정할 수 있어요.
- 끊김 없는 이어하기: 응답자가 나중에 돌아와서 중단한 지점부터 바로 이어서 작성할 수 있어요.
- 선택할 수 있는 이어하기 옵션: **Resume Progress** 모달에서 저장된 제출을 이어서 할지, 새 폼으로 다시 시작할지 고를 수 있어요.
- 브랜딩 자동 적용: **Resume Progress** 모달에는 폼, 설문, 퀴즈의 브랜딩이 자동으로 적용돼요. CTA 버튼 색상과 레이블 글꼴도 포함돼요.
- 모든 기기 지원: 데스크톱과 모바일에서 똑같이 동작해요.

## 진행 상황 저장이 동작하는 방식

진행 상황 저장을 켜 두면 하이퍼클래스가 응답자의 활동을 자동으로 확인하고, 제출을 마치기 전에 나가면 입력한 내용을 보관해요. 응답자 입장에서는 이렇게 진행돼요.

1. 응답자가 폼을 작성하기 시작해요. 진행 상황 저장이 켜진 여러 단계 폼, 설문, 퀴즈에서 질문에 답하며 여러 단계를 넘어가요.
2. 제출하기 전에 나가요. 응답자가 브라우저를 닫거나 페이지를 새로고침하거나 다른 웹사이트로 이동해요. 이때까지의 진행 상황이 자동으로 저장돼요.
3. 응답자가 같은 폼, 설문, 퀴즈 URL로 다시 들어와요. 화면에 **Submission in progress**(진행 중인 제출) 모달이 자동으로 나타나요.
4. 응답자가 계속할지, 다시 시작할지 선택해요. 모달에는 두 가지 옵션이 있어요. 작성하던 곳에서 이어서 하거나, 새 제출로 처음부터 다시 시작할 수 있어요. 응답자가 원하는 옵션을 고르면 그에 맞게 진행돼요.

{% hint style="info" %}
**설정** 탭의 **Save Exit Confirmation** 토글을 켰을 때만 진행 상황이 저장돼요. 기능이 꺼져 있으면 응답자가 중간에 나갔다가 돌아왔을 때 처음부터 다시 작성해야 해요.
{% endhint %}

## 진행 상황 저장 켜기

여러 단계로 된 폼, 설문, 퀴즈에서 진행 상황 저장을 켜는 방법은 간단해요. 다음 단계를 따르세요.

1. 진행 상황 저장을 켜려는 폼, 설문, 퀴즈로 이동해서 편집 화면을 열어요.
2. 빌더 화면에서 **설정** 탭을 클릭해요.
3. **설정** 탭에서 **Save Exit Confirmation** 토글을 찾아 켜짐 상태로 바꿔요.

   ![설정 탭의 Save Exit Confirmation 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077169076/original/F9MqzU5XoKPFz5p-itqeF2W-kBo3eQVddg.png?1785342832)

4. **저장**을 클릭해서 변경 사항을 적용해요. 이제 진행 상황 저장이 켜지고, 이후부터 응답자의 입력 내용이 보관돼요.

{% hint style="info" %}
기존 폼, 설문, 퀴즈는 **Save Exit Confirmation** 토글을 직접 켜기 전까지 그대로예요. 이 기능은 자동으로 켜지지 않고, 직접 선택해서 켜야 해요.
{% endhint %}

## Resume Progress 모달 브랜딩

**Resume Progress** 모달에는 폼, 설문, 퀴즈의 브랜딩 설정이 자동으로 적용돼요. 그래서 응답자는 일관된 디자인으로 화면을 볼 수 있어요. 자동으로 적용되는 디자인 요소는 두 가지예요.

### CTA 버튼 색상

**Resume Progress** 모달의 콜투액션 버튼(**Continue**(계속하기), **Start Over**(처음부터 다시 시작))에는 폼, 설문, 퀴즈 설정에서 지정한 푸터 색상이 적용돼요. 따로 설정하지 않아도 모달 버튼이 기존 브랜드 색상과 어울려요.

### 텍스트 글꼴

**Resume Progress** 모달에 표시되는 모든 텍스트에는 폼, 설문, 퀴즈 설정에서 지정한 레이블 글꼴이 쓰여요. 그래서 모달과 나머지 폼 화면의 글꼴이 통일돼요.

{% hint style="info" %}
**Resume Progress** 모달은 따로 설정할 필요가 없어요. 모든 브랜딩 설정이 폼, 설문, 퀴즈 설정에서 자동으로 적용돼요.
{% endhint %}
