# 폼과 설문의 이미지 레이아웃 설정하기

폼과 설문에서 이미지를 어디에 어떻게 보여 줄지 정하는 방법을 안내해요. 레이아웃 5가지, 이미지 스타일 조정, 초점 위치 지정, 설문 슬라이드별 이미지 설정을 다뤄요.

하이퍼클래스에서는 브랜드와 콘텐츠에 맞게 이미지 배치 방식을 고를 수 있어요. 레이아웃마다 쓸 수 있는 스타일 설정이 따로 있고, 고정 이미지에는 초점 위치를 정할 수 있어요. 설문에서는 슬라이드마다 이미지를 다르게 설정할 수도 있어요.

## 이미지 레이아웃이란?

이미지 레이아웃은 폼 필드나 설문 내용 옆에 이미지를 어떻게 보여 줄지 정하는 설정이에요. 레이아웃을 잘 고르면 시선의 흐름이 자연스러워지고, 중요한 내용이 눈에 잘 띄어요.

이미지 배치 방식을 고르고, 지원하는 레이아웃에서는 간격과 이미지 스타일을 조정할 수 있어요. 설문 슬라이드는 슬라이드마다 이미지 레이아웃을 따로 정할 수 있어요.

## 이미지 레이아웃의 장점

- 다양한 레이아웃: 이미지 배치 방식 5가지 중에서 디자인에 맞는 것을 고를 수 있어요.
- 이미지를 더 알맞게 표시: **Focal Point**(초점 위치)를 지정하면 이미지에서 가장 중요한 부분이 계속 보여요.
- 깔끔한 스타일: 이미지 모서리 반경과 간격을 조정해 더 깔끔하고 현대적인 느낌을 낼 수 있어요.
- 설문 맞춤 설정: 설문 슬라이드마다 다른 이미지와 레이아웃을 적용할 수 있어요.
- 완성도 높은 디자인: 균형 잡힌 폼과 설문을 만들 수 있어요.

## 사용할 수 있는 이미지 레이아웃

레이아웃마다 이미지를 보여 주는 방식이 달라요. 내용을 읽기 쉽고 디자인 목표에 맞는 레이아웃을 고르세요.

### Left Center(왼쪽 중앙)

폼이나 설문의 왼쪽에 이미지를 표시해요. 이미지는 내용 옆에서 세로 가운데에 놓여요.

이런 경우에 잘 맞아요.

- 등록 폼
- 문의 폼
- 리드 확보 폼
- 마케팅 폼

지원하는 설정은 다음과 같아요.

- **모서리 반경**
- **Image-Field Spacing**(이미지와 필드 사이 간격)

### 오른쪽 중앙

폼이나 설문의 오른쪽에 이미지를 표시해요. 이미지는 내용 옆에서 세로 가운데에 놓여요.

이런 경우에 잘 맞아요.

- 마케팅 페이지
- 예약 폼
- 프로모션 폼

지원하는 설정은 다음과 같아요.

- **모서리 반경**
- **Image-Field Spacing**

### Left Fixed(왼쪽 고정)

폼의 왼쪽에 고정 이미지를 표시하고, 폼 내용은 그 옆에 나란히 보여요.

이런 경우에 잘 맞아요.

- 히어로 이미지
- 큰 프로모션 그래픽
- 라이프스타일 사진

지원하는 설정은 다음과 같아요.

- **Focal Point**

### Right Fixed(오른쪽 고정)

폼의 오른쪽에 고정 이미지를 표시하고, 폼 내용은 반대쪽에 보여요.

이런 경우에 잘 맞아요.

- 프로모션 캠페인
- 이벤트 등록 페이지
- 랜딩 페이지

지원하는 설정은 다음과 같아요.

- **Focal Point**

### 배경

업로드한 이미지를 폼이나 설문 뒤의 배경으로 사용해요.

이런 경우에 잘 맞아요.

- 랜딩 페이지
- 프로모션 캠페인
- 브랜드 경험을 살린 페이지

## 이미지 스타일 설정

지원하는 레이아웃에서는 이미지가 보이는 방식을 더 세밀하게 다듬을 수 있어요. 간격을 정리하고 더 깔끔한 디자인을 만들 때 써요.

### 모서리 반경

**모서리 반경**으로 이미지의 모서리를 둥글게 만들 수 있어요.

지원하는 레이아웃은 다음과 같아요.

- **Left Center**
- **오른쪽 중앙**

이럴 때 사용해요.

- 웹사이트 브랜딩과 맞추고 싶을 때
- 더 부드러운 느낌으로 디자인하고 싶을 때
- 이미지를 더 현대적으로 보이게 하고 싶을 때

### Image-Field Spacing

**Image-Field Spacing**(이미지와 필드 사이 간격)은 이미지와 폼 필드 사이의 거리를 정해요.

지원하는 레이아웃은 다음과 같아요.

- **Left Center**
- **오른쪽 중앙**

간격을 늘리면 다음과 같은 효과가 있어요.

- 읽기 쉬워져요.
- 화면이 덜 복잡해 보여요.
- 레이아웃의 균형이 좋아져요.

### Focal Point

화면 크기와 가로세로 비율에 따라 고정 이미지의 일부가 잘릴 수 있어요. **Focal Point**(초점 위치)를 지정하면 이미지에서 계속 보여 줄 영역을 고를 수 있어서, 가장 중요한 부분을 지킬 수 있어요.

지원하는 레이아웃은 다음과 같아요.

- **Left Fixed**
- **Right Fixed**

초점 위치를 조정하려면 다음 순서로 진행하세요.

1. **Left Fixed** 또는 **Right Fixed** 레이아웃을 선택하세요.
2. 업로드한 이미지를 클릭하세요.
3. 가운데에 두고 싶은 영역을 선택하세요.
4. **변경사항 저장**을 클릭하세요.

## 설문 슬라이드별 이미지 레이아웃 설정

기본적으로 모든 설문 슬라이드는 설문 전체에 설정한 이미지 레이아웃을 그대로 따라가요. 특정 슬라이드만 다르게 보여 주고 싶다면, 기본 설정 대신 해당 슬라이드에 이미지와 레이아웃을 따로 지정할 수 있어요.

{% hint style="info" %}
슬라이드별 이미지 레이아웃 설정은 현재 **설문**에서만 쓸 수 있어요.
{% endhint %}

슬라이드마다 다음 항목을 설정할 수 있어요.

- 이미지
- **Image Layout**(이미지 레이아웃)
- 레이아웃 동작

이럴 때 유용해요.

- 질문마다 다른 이미지가 필요할 때
- 슬라이드마다 주제가 다를 때
- 설문의 특정 부분을 강조하고 싶을 때

## 폼에서 이미지 레이아웃 설정하기

이미지 레이아웃을 잘 설정하면 여러 기기에서도 폼이 일관되게 보이고, 화면 공간을 효율적으로 쓸 수 있어요.

1. **사이트 > 폼**으로 이동하세요.

   ![사이트 메뉴에서 폼으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078044870/original/lbGeI14fYzXdF02fMYbz99ZRf5ATEnzWUw.png?1786373313)

2. 새 폼을 만들거나 기존 폼을 여세요.
3. 오른쪽 사이드바에서 **Styles and Options**(스타일 및 옵션) 탭을 여세요.

   ![오른쪽 사이드바의 스타일 및 옵션 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078045063/original/f1DogrVeuHpJiLMu2EcKRAROhWs2Fxcz3Q.png?1786373375)

4. **레이아웃**을 펼치세요.
5. **Show Image**(이미지 표시)를 켜세요.

   ![이미지 표시 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078045184/original/kMpvrjGiKObahaCpUQ2MXRdTJenTLPfz0Q.png?1786373414)

6. 이미지를 업로드하거나 선택하세요.
7. **Image Layout**(이미지 레이아웃)을 선택하세요.

   ![이미지 레이아웃을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078045355/original/GI5yP1d7dlZh3NFbNyVE2VZqBTCU4ejfxA.png?1786373478)

8. 선택한 레이아웃에서 쓸 수 있는 옵션을 설정하세요.
   - **Left Center** 또는 **오른쪽 중앙**
     - **모서리 반경**
     - **Image-Field Spacing**
   - **Left Fixed** 또는 **Right Fixed**
     - **Focal Point**
9. **미리보기**로 폼을 확인하세요.
10. **변경사항 저장**을 클릭하세요.

    ![이미지 레이아웃 설정 후 저장하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078045409/original/nrwwILjBcI3a8YUNn6KOiKnsaxC9hzJjDg.gif?1786373511)

## 설문에서 이미지 레이아웃 설정하기

설문의 이미지 레이아웃은 설문 전체에 한꺼번에 적용할 수도 있고, 슬라이드별로 따로 설정할 수도 있어요. 여러 단계로 된 설문을 디자인할 때 더 유연하게 쓸 수 있어요.

### 설문 전체 이미지 레이아웃 설정

1. **사이트 > 설문**으로 이동하세요.

   ![사이트 메뉴에서 설문으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078045719/original/WKxfabgZKufNXXtZCBSWBBN6qYjNSVzVGw.png?1786373589)

2. 설문을 만들거나 기존 설문을 편집하세요.
3. **스타일** 탭을 여세요.
4. **Show Image**(이미지 표시)를 켜세요.

   ![설문에서 이미지 표시를 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078045865/original/CZK9U96JaXKMkI2keQx_5gm_jIOhp0xDUQ.png?1786373638)

5. 이미지를 업로드하거나 선택하세요.
6. **Image Layout**(이미지 레이아웃)을 선택하세요.

   ![설문에서 이미지 레이아웃을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078046001/original/ankna6-IsQqeS82-mp4dLd-EvqWzxgGR1g.png?1786373682)

7. 선택한 레이아웃에서 쓸 수 있는 설정을 지정하세요.
8. **저장**을 클릭해 설문을 저장하세요.

### 슬라이드 하나만 레이아웃 바꾸기

1. 설문 빌더를 여세요.
2. 설정을 바꿀 슬라이드를 선택하세요.
3. 해당 슬라이드의 **설정** 아이콘을 클릭하세요.
4. **Image Layout Settings**(이미지 레이아웃 설정)를 찾으세요.
5. 설정을 **Independent**(독립)로 바꾸세요.
6. 원하면 다른 이미지를 업로드하세요.
7. 다른 **Image Layout**을 선택하세요.
8. **변경사항 저장**을 클릭하세요.

   ![설문 슬라이드에서 이미지 레이아웃을 독립 설정하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078046627/original/k4C1TZDLjG9a5VsbshB5f6Lo0zX6r4Sj-w.gif?1786373951)

## 활용 팁

몇 가지만 지키면 폼과 설문을 더 균형 있게 꾸미고 사용 경험도 좋아져요.

- 이미지가 작은 폼에는 **Left Center**나 **오른쪽 중앙** 레이아웃을 쓰세요.
- 큰 프로모션 이미지나 히어로 이미지에는 **Left Fixed**나 **Right Fixed** 레이아웃을 쓰세요.
- 고정 레이아웃은 게시하기 전에 **Focal Point**를 지정해 중요한 내용이 계속 보이게 하세요.
- 폼에 필드가 많다면 **Image-Field Spacing**을 늘려 가독성을 높이세요.
- **모서리 반경**으로 브랜드의 시각적 스타일에 맞추세요.
- 설문 슬라이드 레이아웃은 슬라이드마다 고유한 이미지가 도움이 될 때만 따로 설정하세요.

## 자주 묻는 질문

### 어떤 이미지 레이아웃에서 모서리 반경을 쓸 수 있나요?
**모서리 반경**은 **Left Center**와 **오른쪽 중앙** 레이아웃에서만 쓸 수 있어요.

### 어떤 이미지 레이아웃에서 Image-Field Spacing을 쓸 수 있나요?
**Image-Field Spacing**은 **Left Center**와 **오른쪽 중앙** 레이아웃에서만 쓸 수 있어요.

### 어떤 이미지 레이아웃에서 Focal Point를 쓸 수 있나요?
**Focal Point**는 **Left Fixed**와 **Right Fixed** 레이아웃에서만 쓸 수 있어요.

### 설문 슬라이드마다 다른 이미지를 쓸 수 있나요?
네. 사용자 지정할 슬라이드의 **Image Layout Settings**에서 **Independent**로 설정하세요.

### 폼에서도 슬라이드별 이미지 레이아웃을 쓸 수 있나요?
아니요. 슬라이드별 이미지 레이아웃 설정은 현재 **설문**에서만 쓸 수 있어요.

### 설문 슬라이드에서 Independent를 설정하지 않으면 어떻게 되나요?
해당 슬라이드는 설문 전체의 이미지와 이미지 레이아웃 설정을 그대로 따라가요.

### 설문 이미지를 바꾸면 모든 슬라이드가 바뀌나요?
네. **Independent** 이미지 설정을 지정하지 않은 슬라이드는 설문의 기본 이미지와 레이아웃을 사용해요.
