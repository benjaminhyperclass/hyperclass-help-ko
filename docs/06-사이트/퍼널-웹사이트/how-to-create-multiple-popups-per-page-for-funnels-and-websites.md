# 한 페이지에 팝업 여러 개 만들기 (퍼널·웹사이트)

퍼널이나 웹사이트 페이지 하나에 팝업을 개수 제한 없이 만들 수 있어요. 팝업마다 트리거, 스타일, 내용을 따로 정할 수 있어요. 예를 들어 3초 뒤에 환영 혜택을 띄우고, 방문자가 떠나려 할 때 설문을 보여 주고, 버튼을 눌렀을 때 보너스 폼을 열 수 있어요. 페이지를 복제하거나 스크립트를 직접 작성할 필요가 없어요.

## 여러 팝업 기능이란?

한 퍼널 또는 웹사이트 페이지 안에 서로 다른 팝업을 여러 개 만들고 꾸미고 관리하는 기능이에요. 팝업마다 내용, 위치, 트리거 조건을 다르게 정할 수 있어요. 그래서 방문자의 행동에 맞는 메시지를 따로 보여 주기 쉬워요. 여러 마케팅 메시지를 우회 방법이나 코딩 없이 관리할 수 있어요.

## 한 페이지에 팝업을 여러 개 쓰면 좋은 점

- 정확한 타기팅: 방문자의 행동이나 단계에 맞는 메시지를 보여 줄 수 있어요.
- 더 나은 사용자 경험: 본문 레이아웃을 복잡하게 하지 않고, 필요한 순간에 맞춰 혜택을 보여 줄 수 있어요.
- 전환율 향상: 페이지를 떠나려는 순간처럼 가장 효과적인 때에 맞춤 혜택이나 리드 수집 폼을 보여 줄 수 있어요.
- 쉬운 관리: 기술적인 어려움 없이 팝업별로 설정하고 관리할 수 있어요.
- 단순한 구성: 페이지를 여러 개 만들거나 스크립트를 쓰는 복잡한 우회 방법이 필요 없어요.

## 새 팝업 만들기

처음 팝업이든 다섯 번째 팝업이든, 아래 순서로 금방 만들 수 있어요. ▶ 영상 [4강 2부 19:21](https://www.youtube.com/watch?v=AVOIIs3fMSg&t=1161s)

1. 사이트 빌더 또는 퍼널 빌더에서 페이지를 열고, 상단 내비게이션 바에서 **Popup Settings**(팝업 설정) 버튼을 클릭하세요.

   ![상단 내비게이션 바의 Popup Settings 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050681668/original/xEZtXGNeQGbjBp9AvsaUR-e0jRMuqI71zw.jpeg?1753889352)
2. 사이드바에서 **+ Create New Popup**(새 팝업 만들기)을 누르고, 알아보기 쉬운 이름을 입력하세요.

   ![사이드바에서 새 팝업을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050681697/original/E79QL34XyB_D4E_-r5zR0NGbnXKGo7CpBQ.jpeg?1753889370)
3. 만든 팝업 옆의 **편집**(연필) 아이콘을 클릭하세요. 섹션을 편집하듯이 팝업을 편집할 수 있어요. 텍스트, 폼, 버튼, 이미지, 동영상, 카운트다운을 추가해 보세요.

   ![팝업 옆의 편집 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050681945/original/XL0mbjSbQ2ITRbv1xKVtr1cjnyT8hqyDaA.png?1753889508)

## 여러 팝업 관리하기

페이지 빌더의 **Popup Settings** 패널에서 팝업을 쉽게 추가하고 관리할 수 있어요.

- **새로 만들기**: **+ Create New Popup**을 눌러 팝업을 더 추가하세요.
- 편집 또는 삭제: 필요 없는 팝업은 **휴지통** 아이콘을 눌러 삭제하고, 기존 팝업을 고치려면 **편집**(연필) 아이콘을 누르세요.
- 순서 변경: 줄 두 개 모양의 아이콘을 끌어서 팝업의 우선순위(Z-index)를 바꾸세요.

![Popup Settings 패널에서 팝업을 관리하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050682308/original/6p_I__XPsSBB920PTpuW9pfUtD37fBeEWQ.png?1753889847)

## 팝업 모양과 위치 꾸미기

디자인과 목표에 맞게 팝업마다 모양과 표시 위치를 정할 수 있어요. 팝업에서도 섹션에서 쓰던 디자인 도구를 똑같이 쓸 수 있어요. **Popup Settings**의 옵션으로 팝업을 하나씩 꾸미세요.

- 팝업 위치: 팝업 설정에서 팝업 위치를 왼쪽, 가운데, 오른쪽 중에서 정할 수 있어요.
- 시각적 꾸미기: 일반 페이지 섹션처럼 배경 색상, 오버레이, 간격, 콘텐츠 요소를 바꿀 수 있어요.
- 간격과 크기: 데스크톱, 태블릿, 모바일별로 패딩, 마진, 최대 너비를 조정할 수 있어요.
- 팝업 트리거: 팝업마다 트리거를 따로 정할 수 있어요. 지연, 이탈 의도, 버튼·이미지·텍스트 링크 클릭 같은 상호작용 트리거를 고를 수 있어요.

## 최근 팝업 개선 사항

최근 개선으로 팝업 레이아웃이 더 안정적으로 유지되고, 모바일에서도 더 매끄럽게 동작해요.

### 열 크기 조절 개선

팝업 안에서 열 크기를 조절할 때 동작이 더 일관돼요. 열 너비를 바꿔도 레이아웃 구조가 더 안정적으로 유지돼서, 의도하지 않게 밀리거나 틀어지는 일이 줄어요.

### 모바일 터치 지원 개선

모바일 기기에서 팝업이 터치 동작에 더 부드럽게 반응해요. 스크롤하기, 탭하기, 팝업 닫기가 더 자연스러워서 스마트폰과 태블릿에서 쓰기 편해요.

이 개선으로 여러 기기에서 팝업이 더 예측 가능하게 동작하고, 화면 모양도 일관되게 유지돼요.

## 팝업 트리거 설정하기

트리거를 설정하면 각 팝업이 언제, 어떤 조건에서 나타날지 정할 수 있어요. 사용할 수 있는 트리거 옵션은 다음과 같아요.

- **Delay**(지연): 페이지가 로드된 뒤 몇 초 후에 보여 줄지 정해요.
- **Exit Intent**(이탈 의도): 방문자가 페이지를 떠나려 할 때 팝업을 띄워요.
- **없음**: 직접 열어야 하는 팝업이에요. 보통 버튼, 이미지, 텍스트에 연결해서 써요.

[링크를 연결한 버튼, 이미지, 텍스트를 클릭해서 팝업을 열 수도 있어요.](#버튼-이미지-텍스트에-팝업-연결하기)

#### 트리거 설정 방법

1. 사이드바에서 팝업을 선택하세요.
2. **설정** 탭을 여세요.
3. **Show Popup On**(팝업 표시 시점) 드롭다운에서 **Delay**, **Exit Intent**, **없음** 중에서 고르세요. 클릭으로만 열리는 팝업은 **없음**을 고르세요.
4. **Delay**를 골랐다면 초 단위로 시간을 입력하세요.

![Show Popup On 드롭다운에서 트리거를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050687408/original/VJr1gLGaisCnF9rNzUeKibJO7HFWl5_VaQ.png?1753895127)

## 버튼, 이미지, 텍스트에 팝업 연결하기

버튼, 이미지, 텍스트에 팝업을 연결하면 방문자가 더 적극적으로 반응하는 페이지를 만들 수 있어요. 클릭 트리거를 쓰면 방문자의 흐름을 끊지 않고 상황에 맞는 혜택을 보여 줄 수 있어요.

1. 버튼, 이미지, 텍스트 요소 중 하나를 선택하세요.
2. **Link To**(링크 대상) 드롭다운에서 **Open Popup**(팝업 열기)을 고르세요.
3. 드롭다운 메뉴에서 연결할 팝업을 선택하세요.

![Link To 드롭다운에서 Open Popup을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050687626/original/pZqfuIo1pRXABqUAzLtIQ9LfZ-7L5dD1mA.png?1753895484)

## 자주 묻는 질문

### 팝업 우선순위는 어떻게 정하나요?

사이드바에서 팝업 순서를 조정하세요. 순위가 높은 팝업이 위에 표시돼요.

### 팝업마다 다른 트리거를 설정할 수 있나요?

네, 팝업마다 고유한 트리거(지연, 이탈 의도, 버튼·이미지 클릭)를 설정할 수 있어요.

### 여러 팝업의 트리거 조건이 같으면 어떻게 되나요?

트리거가 같은 팝업이 여러 개면, 우선순위가 가장 높은 팝업(사이드바 목록의 맨 위)이 먼저 나타나요.

### 방문자가 팝업을 직접 닫을 수 있나요?

네, 방문자는 닫기(X) 버튼을 클릭하거나 팝업 바깥을 클릭해서 닫을 수 있어요. 어떤 방식으로 닫히는지는 선택한 설정에 따라 달라요.

### 팝업 전환은 어떻게 추적하나요?

페이지의 **Statistics**(통계) 탭을 확인하거나, 폼 제출을 CRM 파이프라인에 연결해서 추적하세요.
