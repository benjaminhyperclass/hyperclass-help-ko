# 페이지 로드 시 표시되는 팝업이란?

페이지 로드 팝업은 방문자가 웹사이트나 퍼널 페이지에 도착한 직후, 클릭이나 스크롤 없이도 자동으로 나타나는 메시지 또는 폼 형태의 팝업이에요. 이런 유형의 팝업은 타이밍 설정(예: 2초 지연)에 의해 트리거되며, 방문자의 관심을 즉시 끌기 위해 사용돼요. 주로 기간 한정 프로모션을 홍보하거나, 리드를 수집하거나, 방문 초반부터 행동을 유도하는 환영 메시지를 보여주는 데 많이 활용돼요.

## 페이지 로드 팝업 사용 시 주요 이점

- **자동화:** 사용자가 아무것도 클릭하지 않아도 팝업이 자동으로 실행돼요.

- **리드 생성:** 이메일 리스트를 늘리거나 사용자가 도착하는 순간 기간 한정 혜택을 제공하기에 완벽해요.

- **전환 최적화:** 즉각적으로 뜨는 팝업과 긴급성 있는 CTA(행동 유도)를 활용해 퍼널 전환율을 높일 수 있어요.

- **행동 타기팅:** 조정 가능한 지연 타이머로 팝업이 나타나는 시점을 정확히 설정할 수 있어요.

- **폭넓은 호환성:** 하이퍼클래스 플랫폼 내 퍼널(Funnel)과 웹사이트(Website) 모두에서 작동해요.

## 페이지 로드 시 팝업이 표시되도록 설정하는 방법

사용자가 페이지에 도착한 후 팝업이 자동으로 나타나도록 설정하는 단계를 따라해 보세요.

#### 1단계: 팝업 설정으로 이동하기

- 하위 계정(Sub-account) 대시보드 왼쪽 메뉴에서 사이트(Sites)를 클릭하세요. 그다음 상단 네비게이션 바에서 Funnels(퍼널) 또는 Websites(웹사이트) 탭을 선택하세요.

- 팝업을 추가하고 싶은 퍼널 또는 웹사이트를 열고, 팝업을 넣을 특정 스텝(단계)이나 페이지를 클릭하세요.

- 파란색 버튼인 **Edit(편집)**을 클릭해 페이지 편집기를 실행하세요.

- 웹사이트 빌더 상단 메뉴 바에서 **Popup Settings(팝업 설정)** 아이콘을 클릭해 팝업 설정을 열어주세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046955271/original/a195Uqak0HIUOVjM8Ts8xT_xMOhgN_OkgQ.png?1747767733)

**2단계: 팝업 설정 구성하기**

- 오른쪽 Popup Settings(팝업 설정) 패널에서 아래로 스크롤하면 Show Popup on(팝업 표시 조건) 드롭다운이 보여요. 목록에서 **Delay(지연)**를 선택하세요.

- 드롭다운 바로 아래에 있는 슬라이더를 사용해 페이지 로드 후 몇 초 뒤에 팝업이 나타날지 설정하세요.

- 편집기 오른쪽 상단의 **Save(저장)** 또는 **Publish(발행)**를 클릭해 팝업 설정을 적용하세요.

## 자주 묻는 질문

**Q: 방문 또는 세션당 한 번만 팝업이 표시되도록 설정할 수 있나요?**
아니요, 방문자가 같은 페이지에 머무르지 않는 이상 페이지가 로드될 때마다 팝업이 다시 나타나요.

**Q: 사용자가 페이지를 나가려고 할 때 팝업을 표시하고 싶어요.**
"Show popup on(팝업 표시 조건)" 드롭다운에서 "Exit(나가기)" 옵션을 사용하면 사용자가 커서를 브라우저 툴바 쪽으로 이동할 때 팝업이 트리거되도록 만들 수 있어요.

**Q: 퍼널과 웹사이트 모두에서 이 기능을 사용할 수 있나요?**
네! 두 경우 모두 동일하게 작동하며, 설정 과정도 완전히 똑같아요.

**Q: 지연 시간이 되기 전에 팝업이 수동으로 열리면 어떻게 되나요?**
지연 타이머가 끝나기 전에 팝업이 수동으로(예: 버튼 클릭으로) 트리거되면, 자동 팝업은 취소돼요. 이렇게 하면 같은 페이지뷰에서 동일한 팝업이 두 번 나타나는 것을 방지할 수 있어요.
