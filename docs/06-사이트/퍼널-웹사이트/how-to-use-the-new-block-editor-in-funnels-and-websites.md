# 퍼널과 웹사이트의 새 Block Editor(블록 편집기) 사용하기

퍼널과 **웹사이트 빌더**에서 텍스트를 꾸밀 때 쓰는 **Block Editor**(블록 편집기)가 새롭게 바뀌었어요. 이 문서에서는 새로 추가된 기능과 사용 방법을 안내해요.

새 Block Editor는 화면이 더 간결해져서 퍼널과 웹사이트를 편하게 꾸밀 수 있어요. 새 기능도 함께 추가됐어요.

---

## 주요 기능과 장점

- 사용성 개선: 인터페이스를 간결하게 다듬어서 더 매끄럽고 직관적으로 편집할 수 있어요.
- 선택한 텍스트에 사용자 지정 글꼴 적용: Block Editor에서 바로 글꼴을 골라 선택한 텍스트 블록의 글꼴을 바꿀 수 있어요. 디자인을 더 개성 있게 꾸밀 수 있어요.
- 아래 첨자·위 첨자 메뉴 추가: 새 메뉴 옵션으로 텍스트를 아래 첨자나 위 첨자로 쉽게 바꿀 수 있어요.
- 글머리 기호 목록 전용 섹션: 글머리 기호 목록이 별도 섹션으로 분리되어 목록을 더 쉽게 만들고 관리할 수 있어요. 편집기에서 기본 목록 기호 스타일도 고를 수 있어요.
  - 순서 없는 목록: 디스크(●), 원(○), 사각형(■)
  - 순서 있는 목록: 소문자 알파벳(a, b, c), 대문자 알파벳(A, B, C), 소문자 로마 숫자(i, ii, iii), 대문자 로마 숫자(I, II, III)
  - 디자인을 세밀하게 직접 정하고 싶다면 사용자 지정 아이콘도 계속 쓸 수 있어요.
- 불필요한 단락 옵션 제거: 쓸모없는 옵션을 없애서 누구나 더 쉽게 쓸 수 있어요.

Block Editor는 요소 안의 텍스트를 직접 꾸밀 때 쓰는 도구예요. 예를 들어 텍스트를 굵게 하거나, 글머리 기호를 넣거나, 일부 글자만 서식을 바꿀 수 있어요. 섹션 전체를 고치거나 페이지 전체 스타일을 바꾸는 것처럼 더 넓은 범위를 AI로 수정하려면, 퍼널 & 웹사이트 AI 워크플로우의 **AI Page Revisions**(AI 페이지 수정)를 사용하세요.

### 어떤 도구를 쓸까요?

- 텍스트 요소 하나 안에서 문구를 빠르게 직접 고치려면 **Block Editor**를 사용하세요.
- 레이아웃을 새로 만들지 않고 섹션이나 페이지 전체의 문구·디자인을 고치려면 **AI Page Revisions**를 사용하세요.

---

## 사용 방법

1. 왼쪽 메뉴에서 **사이트**를 선택한 뒤, 편집할 퍼널이나 웹사이트를 열어 편집기를 실행하세요.
2. **요소 추가**를 클릭하고, 서식을 적용할 텍스트 요소를 선택하세요.
3. 새 Block Editor로 사용자 지정 글꼴, 아래 첨자, 위 첨자를 적용하고 글머리 기호 목록을 정리하세요.

사용자 지정 글꼴과 다양한 텍스트 서식 옵션이 추가되고 편집 화면도 더 편해졌어요. 덕분에 더 눈길을 끄는 콘텐츠를 만들 수 있어요. 작업 과정이 간소해지고 번거로움이 줄어서 원하는 디자인을 더 효율적으로 완성할 수 있어요.
