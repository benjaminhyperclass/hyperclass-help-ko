# 버튼·이미지·SVG에 파일 다운로드 액션 설정하기

퍼널과 웹사이트의 버튼, 이미지, SVG 요소에 **파일 다운로드** 액션을 설정하는 방법을 안내해요. 방문자가 클릭 한 번으로 PDF나 이미지 같은 파일을 받을 수 있게 만들 수 있어요.

## 파일 다운로드 액션이란?

**파일 다운로드** 액션을 설정하면 방문자가 퍼널이나 웹사이트의 **버튼**, **이미지**, **SVG** 요소를 클릭할 때 파일(PDF, 이미지, ZIP 등)이 내려받아져요. 리드 마그넷, 브로슈어, 디지털 자료를 바로 제공하고 싶을 때 알맞아요. 코드는 필요 없어요.

## 파일 다운로드 액션의 장점

간단한 다운로드 기능으로 방문자 경험을 매끄럽게 만들 수 있어요.

- eBook, 이미지, 템플릿 같은 파일을 바로 제공할 수 있어요.
- 외부 다운로드 서비스를 따로 쓰지 않아도 돼요.
- 버튼, 이미지 요소, SVG 그래픽에서 모두 쓸 수 있어요.
- 클릭 한 번으로 설정할 수 있고, 기술 지식은 필요 없어요.
- 다운로드되는 파일 이름을 브랜드에 맞게 바꿀 수 있어요.
- 방문자에게 원하는 자료를 빠르게 전달해 참여를 높일 수 있어요.

## 파일 다운로드 액션 켜기

아래 순서대로 기능을 켜고 파일을 연결하세요.

1. 편집기에서 퍼널이나 웹사이트를 여세요.
2. **버튼**, **이미지**, **SVG** 요소 중 하나를 선택하세요.
3. 오른쪽 설정 패널에서 **Download**(다운로드) 토글을 켜세요.
4. **Link File**(파일 연결)을 클릭해 **Media Picker**(미디어 선택기)를 여세요.
5. **미디어 라이브러리**에서 파일을 선택하거나 새로 업로드하세요.
6. (선택) 다운로드될 파일 이름을 바꿔요.
7. **저장**한 뒤 **미리보기**로 퍼널이나 사이트를 확인하세요.

## 지원하는 요소

자주 쓰는 시각 요소에서 이 기능을 쓸 수 있어요.

- **버튼**: "지금 다운로드"처럼 행동 유도(CTA) 버튼에 쓰기 좋아요.
- **이미지**: 아이콘이나 포스터 같은 이미지를 클릭하면 다운로드되게 만들 수 있어요.
- **SVG**: 직접 만든 그래픽에도 다운로드 기능을 연결할 수 있어요.

## 다운로드 파일 이름 바꾸기

브랜드에 맞게, 또는 더 알아보기 쉽게 다운로드 파일 이름을 바꿀 수 있어요.

파일을 연결할 때 다음을 할 수 있어요.

- 방문자에게 보이는 파일 이름을 바꿔요. 예를 들어 "file_123.pdf"를 "2025_Pricing_Guide.pdf"로 바꿀 수 있어요.
- 알아보기 어려운 파일 이름을 피해 더 전문적인 인상을 줄 수 있어요.

## 자주 묻는 질문

### 버튼 하나에 다운로드 파일을 두 개 이상 연결할 수 있나요?

아니요. 요소 하나에는 다운로드 파일을 하나만 연결할 수 있어요.

### 어떤 파일 형식을 쓸 수 있나요?

**미디어 라이브러리**에 저장된 파일이면 PDF, 이미지, ZIP 등 모두 쓸 수 있어요.

### 누가 파일을 다운로드했는지 확인할 수 있나요?

현재는 다운로드를 개별로 추적하지 않아요. 추적이 필요하면 폼 제출과 자동화 트리거를 함께 쓰는 방법을 고려해 보세요.

### 방문자에게 미리보기가 나오나요, 바로 다운로드되나요?

요소를 클릭하면 파일이 바로 다운로드돼요. 미리보기로 열리지 않아요.
