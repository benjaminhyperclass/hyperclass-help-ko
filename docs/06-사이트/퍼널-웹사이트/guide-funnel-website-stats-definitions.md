## 페이지 조회수

퍼널 페이지가 방문된 횟수예요.

|  |  |
| --- | --- |
| 유형 | 설명 |
| 전체 | 반복 방문을 포함한 모든 페이지 조회수예요. |
| 고유 | 페이지를 방문한 고유 방문자 수예요. |

> 예시: 한 사람이 두 번 방문하면 전체 = 2, 고유 = 1이에요.

---

## 수신 동의

오퍼에 관심을 보인 사용자를 집계해요.

|  |  |
| --- | --- |
| 유형 | 설명 |
| 전체 | 상품 수신 동의를 했거나, 상품을 구매했거나, 폼/설문을 제출했거나, 캘린더로 예약한 사용자 수예요. |
| 비율 | 전체 수신 동의를 고유 페이지 조회수로 나눈 값이에요. |

> 예시: 고유 조회 200회에서 수신 동의가 50건이면 비율 = 25%예요.

---

## Sales - Orders(판매 - 주문)

퍼널에서 이뤄진 구매를 집계해요.

|  |  |
| --- | --- |
| 기준 | 설명 |
| 퍼널 단계 기준 | 발생한 판매 주문 수예요. 접수된 주문이 몇 건인지를 세며, 구매한 상품 수나 수량은 반영하지 않아요. |
| 개별 상품 기준 | 해당 상품이 구매된 횟수예요. |
| 범프 상품 | 범프 상품이 구매된 횟수예요. |

> 예시: 한 단계에서 주문이 30건 들어왔고, 그중 18건에 상품 A가, 5건에 범프 상품이 포함됐어요. 이 경우 퍼널 단계 기준 = 30, 개별 상품 기준 = 18, 범프 상품 = 5예요.

---

## Sales - Rate(판매 - 비율)

조회가 구매로 이어진 비율을 보여 줘요.

|  |  |
| --- | --- |
| 기준 | 설명 |
| 퍼널 단계 기준 | 어떤 상품이든 구매된 횟수를 고유 페이지 조회수로 나눈 값이에요. |
| 개별 상품 기준 | 해당 상품이 구매된 횟수를 고유 페이지 조회수로 나눈 값이에요. |
| 범프 상품 | 범프 상품이 구매된 횟수를 해당 단계의 전체 주문 수로 나눈 값이에요. |

> 예시: 주문 100건 중 범프 구매가 20건이면 비율 = 20%예요.

---

## Sales - Quantity(판매 - 수량)

판매된 전체 품목 수예요.

|  |  |
| --- | --- |
| 기준 | 설명 |
| 퍼널 단계 기준 | 이 퍼널 단계에서 구매된 모든 상품의 총 수량이에요. |
| 상품 기준 | 해당 퍼널 단계에서 특정 상품이 판매된 총 수량이에요. |

> 예시: 주문 10건에 각각 3개씩 들어 있으면 수량 = 30이에요.

---

## Sales - Amount(판매 - 금액)

발생한 총 수익이에요.

|  |  |
| --- | --- |
| 기준 | 설명 |
| 퍼널 단계 기준 | 해당 퍼널 단계에서 구매된 모든 상품의 총 금액이에요. |
| 상품 기준 | 해당 퍼널 단계에서 특정 상품의 총 판매 금액이에요. |

---

## Average Cart Value(평균 장바구니 금액)

주문 1건당 평균 매출이에요.

|  |  |
| --- | --- |
| 기준 | 설명 |
| 퍼널 단계 기준 | 총 금액을 전체 주문 수로 나눈 값이에요. |
| 상품 기준 | 해당 없음 |

> 예시: 주문 20건에서 $1,000가 판매됐다면 Average Cart Value = $50이에요.

---

## 수익/페이지 조회수

페이지 조회 1회당 수익이에요.

|  |  |
| --- | --- |
| 유형 | 설명 |
| 전체 | 총 판매 금액을 전체 페이지 조회수로 나눈 값이에요. 고유 페이지 조회수가 아니라는 점에 주의하세요. (총 판매 금액 ÷ 전체 페이지 조회수) |
| 고유 | 수익을 고유 페이지 조회수로 나눈 값이에요. (총 판매 금액 ÷ 고유 페이지 조회수) |

> 예시: 페이지 조회수 5,000회에 판매 금액이 $5,000이면 조회 1회당 $1이에요.

---

## Performance Indicators(성과 지표)

#### 이런 흐름을 목표로 하세요

1. 고유 방문자와 수신 동의가 늘고 있어요.
2. 전환율이 건강하고 안정적이에요.
3. 평균 장바구니 금액이 높고 조회 1회당 수익도 높아요.

#### 이런 경우는 주의하세요

1. 고유 트래픽이 줄어들거나 계속 낮아요.
2. 수신 동의율이나 판매 전환율이 낮아요.
3. 주문 금액이 작거나 업셀 성과가 부진해요.
