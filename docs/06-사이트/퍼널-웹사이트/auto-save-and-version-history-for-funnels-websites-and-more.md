# 퍼널, 웹사이트 등에서 쓰는 자동 저장과 버전 기록

**자동 저장**과 개선된 **버전 기록** 기능으로 편집 중인 내용을 더 안전하게 지킬 수 있어요. 퍼널, 웹사이트, 블로그, 웨비나, 이커머스에서 모두 쓸 수 있어요. 변경 내용이 자동으로 저장되고, 필요할 때 이전 버전을 쉽게 불러올 수 있어요.

## 자동 저장은 이렇게 작동해요

- 실시간 자동 저장: 내용을 바꾸면 그때그때 자동으로 저장돼요. **저장**을 직접 누르지 않아도 돼요.
- 저장 상태 표시: **저장 중…**, **자동 저장됨** 같은 표시로 저장되고 있는지 확인할 수 있어요.
- 직접 저장도 가능: 직접 저장하고 싶다면 **저장** 버튼을 그대로 쓸 수 있어요.

## 버전 기록 살펴보기

**버전 기록**에서는 콘텐츠의 이전 버전을 확인하고 복원할 수 있어요. 변경을 되돌리거나, 예전 디자인으로 돌아가거나, 작업 과정을 확인할 때 유용해요.

### 주요 내용

- 시간이 표시된 버전: 각 버전에 저장된 날짜와 시간이 표시돼서 쉽게 찾을 수 있어요.
- 자동 저장 주기: 새 버전은 10분마다 저장돼요. 단, 그 10분 사이에 변경한 내용이 있을 때만 저장돼요.
- 버전 수 제한: 항목마다 자동 저장과 직접 저장을 합쳐 최대 50개 버전이 보관돼요. 50개가 넘으면 가장 오래된 버전부터 삭제돼요.
- 글로벌 섹션 알림: **Global Section**(글로벌 섹션)을 편집하면 팝업이 나타나요. 그 섹션을 쓰는 모든 곳에 변경 내용이 적용된다는 안내예요.

  ![글로벌 섹션 편집 시 나타나는 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044447474/original/qF3QQyAgMlB8WCXZM5xISDI2C-3OGDREPA.png?1743666767)

### 버전 기록 확인하고 복원하기

1. 사이트 편집기 오른쪽 위의 **시계 아이콘**을 클릭하세요. 버전 기록 창이 열려요.

   ![편집기 오른쪽 위의 시계 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057874534/original/dDXP5cwdgT-rsoJ_-owooxq6WHaplhkPlQ.png?1762552613)

2. 왼쪽에 이전 버전 목록이 나타나요. 보고 싶은 버전을 클릭하세요.

   ![왼쪽에 표시된 이전 버전 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057874597/original/1yFctx8cVs8ZgRR5zaoNDUve8e6P68_Ukw.png?1762552902)

3. 이전 버전을 게시하거나 복원하려면 원하는 버전을 선택하세요. 그다음 오른쪽 위의 **게시** 또는 **Restore Version**(버전 복원) 버튼을 클릭하세요.

   ![오른쪽 위의 게시, 버전 복원 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057874653/original/Iao8YxuEQkYAEbPSTusG61c2fcahwbKZRw.png?1762553107)

## 사용할 수 있는 곳

**자동 저장**과 **버전 기록**은 아래 영역에서 쓸 수 있어요.

- **퍼널**: 모든 단계, 요소, 섹션
- **웹사이트**: 모든 페이지와 구성 요소
- **블로그**
- **웨비나**
- **이커머스**

## 추가 정보

- 편집하면 자동 시작: 변경 내용이 감지되면 자동 저장이 저절로 시작돼요.
- 비정상 종료와 탭 닫힘 대비: 브라우저가 갑자기 종료되거나 탭이 닫혀도 작업 내용을 잃을 위험을 줄여 줘요.
- 성능 최적화: 복잡하거나 콘텐츠가 많은 페이지에서도 편집이 부드럽게 이어지도록 만들었어요.

자동 저장이나 버전 기록 복원에 대해 궁금한 점이 있으면 하이퍼클래스 고객지원에 문의하세요.
