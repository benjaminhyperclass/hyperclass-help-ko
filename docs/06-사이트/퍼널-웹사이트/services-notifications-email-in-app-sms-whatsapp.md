# 서비스 알림 설정 — 이메일, 인앱, SMS, WhatsApp

서비스 예약 과정에서 고객과 팀원에게 이메일, 인앱, SMS, WhatsApp으로 알림을 보내는 방법을 안내해요. 예약 이벤트별로 알림을 설정하고, 수신자를 고르고, 메시지를 직접 꾸미고, 서비스 전용 커스텀 값도 넣을 수 있어요. 모든 설정은 서비스 알림 설정 한곳에서 해요.

{% hint style="info" %}
이 기능은 현재 비공개 베타(Private Beta)로 제공돼요.
{% endhint %}

## 개요

서비스 알림은 서비스 예약용 메시지를 워크플로우 없이 보낼 수 있는 기본 기능이에요. 일반 캘린더 알림 대신 이벤트별 메시지를 정해 두면 모든 서비스 예약에 자동으로 적용돼요.

이번 업데이트에는 새 알림 트리거, 수신자 옵션, 템플릿 사용자 지정, 서비스 전용 커스텀 값이 포함돼요. 같은 알림이 여러 번 가지 않도록 알림을 하나로 묶어 주는 기능도 있어요.

## 서비스 알림에서 새로 생긴 기능

### 알림 트리거

다음 서비스 예약 이벤트마다 알림을 설정할 수 있어요.

- **예약 완료**(미확정)

  고객이 서비스를 예약했고 예약이 아직 확정되지 않은 상태일 때 보내요.
- **예약 완료**(확정)

  예약이 자동으로 확정되거나 직접 승인됐을 때 보내요.
- **취소**

  서비스 예약이 취소됐을 때 보내요.
- **일정 변경**

  예약이 다른 날짜나 시간으로 옮겨졌을 때 보내요.
- **알림**

  예약 전에 보내는 리마인더예요. 노쇼를 줄이는 데 도움이 돼요.
- **Follow-Up**(후속 메시지)

  예약이 끝난 뒤 고객과 소통하거나 피드백을 받을 때 쓰는 메시지예요.

### 수신자 옵션

알림마다 아래 수신자 중 한 명 이상에게 보낼 수 있어요.

- **연락처**

  서비스를 예약한 고객이에요.
- **할당된 사용자**

  서비스에 배정된 직원이에요.
- **이메일 주소**

  접수 담당 직원, 매니저 등 다른 내부 팀원이에요.

## 발송 채널

서비스 예약 단계마다 가장 알맞은 채널을 고르세요. 서비스 알림은 아래 채널을 지원해요.

- **이메일**: 예약 안내와 일정 관련 메시지를 이메일로 보내요.
- **인앱**: 하이퍼클래스 안에서 할당된 사용자에게 알려 줘요.
- SMS: 예약 안내를 문자 메시지로 보내요.
- WhatsApp: 예약 확인, 리마인더, 후속 메시지 등 지원되는 일정 관련 메시지를 WhatsApp으로 보내요.

예약 이벤트마다 고객과 팀에 맞는 채널을 따로 설정할 수 있어요.

## 템플릿 사용자 지정

서비스 알림에는 편집기가 내장되어 있어요. 편집기에서 다음을 할 수 있어요.

- 제목 수정
- 메시지 내용 편집
- 서식과 레이아웃 조정

미리 만들어진 템플릿을 골라 쓰면 설정 시간을 줄이고 메시지를 일관되게 유지할 수 있어요.

## 지역화된 기본 알림 템플릿

기본 알림 템플릿은 이메일, SMS, WhatsApp 채널에서 **비즈니스 프로필**의 **플랫폼 언어**를 따라요.

- 서비스를 새로 쓰기 시작한 서브 계정: 따로 할 일은 없어요. 기본 템플릿이 자동으로 해당 언어로 바뀌어요.
- 이미 서비스를 쓰고 있는 서브 계정: **글로벌 설정 > 알림**으로 이동해, 해당 템플릿에서 **기본값으로 초기화**를 선택하면 지역화된 버전이 불러와져요.

직접 수정한 템플릿은 직접 초기화하지 않는 한 그대로 유지돼요.

## 서비스 전용 커스텀 값

서비스 알림에서는 서비스 예약에 맞는 커스텀 값을 쓸 수 있어요. 예를 들면 다음과 같아요.

- **서비스 이름**
- 소요 시간
- 가격
- 애드온
- 담당 직원 정보
- 그 밖의 서비스 속성

이 값을 넣으면 알림에 예약한 서비스 내용이 정확하게 표시돼요.

## 알림 자동 통합

예약에 여러 서비스가 포함되어 있어도 전체 서비스 예약에 대해 알림은 한 번만 가요.

같은 예약에 대해 고객과 팀원이 비슷한 이메일을 여러 통 받지 않아도 돼요.

## 서비스 알림 설정 방법

서비스 알림을 설정하려면 다음 순서로 진행하세요.

1. **캘린더 설정 > 서비스 > 글로벌 설정 > 알림**으로 이동하세요.
2. 설정할 알림 트리거를 선택하세요.
3. 알림 템플릿을 원하는 대로 편집하세요.
4. 설정할 발송 채널(**이메일**, **인앱**, SMS, WhatsApp)을 선택하세요.
5. 수신자를 선택하세요.
6. 서비스 전용 커스텀 값을 넣으세요.
7. **변경사항 저장**을 선택하세요.

## 서비스 알림이 적용되는 방식

설정을 마치면 다음과 같이 동작해요.

- 서비스 이벤트가 생기면 알림이 자동으로 나가요.
- 같은 템플릿이 모든 예약에 일관되게 쓰여요.
- 여러 서비스를 한 번에 예약하면 통합 규칙이 자동으로 적용돼요.
- 기본적인 서비스 안내에는 워크플로우가 필요 없어요.

## 달라지지 않는 점

이번 업데이트는 다음 사항에는 영향을 주지 않아요.

- 워크플로우 기반 알림을 대체하지 않아요.
- 서비스가 아닌 일반 캘린더 예약에는 영향이 없어요.
- 예약 가능 시간이나 예약 규칙은 바뀌지 않아요.
- **서비스**(비공개 베타) 밖에서는 적용되지 않아요.

## 자주 묻는 질문

### 모든 캘린더 예약에서 쓸 수 있나요?
아니요. 이 알림은 **서비스**로 받은 예약에만 적용돼요.

### 이메일과 인앱 알림을 둘 다 보낼 수 있나요?
서비스 알림은 이메일, 인앱, SMS, WhatsApp을 지원해요. 서비스 예약 이벤트와 소통 목적에 맞는 채널을 설정하세요.

### 알림은 서비스마다 가나요, 예약마다 가나요?
알림은 예약 단위로 통합돼요. 여러 서비스를 예약해도 알림은 한 번만 가요.

### 서비스 알림에도 워크플로우가 필요한가요?
아니요. 서비스 알림은 자주 쓰는 예약 안내용 기본 기능이에요. 필요하면 워크플로우도 계속 쓸 수 있어요.

### 모든 계정에서 이 기능을 쓸 수 있나요?
아니요. 서비스 알림은 현재 비공개 베타로 제공돼요.
