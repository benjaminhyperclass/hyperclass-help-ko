# 웹사이트·퍼널·이커머스·웨비나의 중첩 URL 경로

URL 경로를 계층 구조로 깔끔하게 만들면 검색 노출에 도움이 되고, 방문자도 지금 어디에 있는지 쉽게 알 수 있어요. 하이퍼클래스는 퍼널, 웹사이트, 이커머스, 웨비나에서 중첩(여러 단계) URL 경로를 지원해요. 이 문서에서는 중첩 URL 경로가 무엇인지, 왜 필요한지, 어떻게 설정하는지 설명해요.

{% hint style="info" %}
이 기능은 현재 베타 버전이에요. 앞으로 업데이트되거나 일부 내용이 달라질 수 있어요.
{% endhint %}

## 중첩 URL 경로란?

중첩 URL 경로는 슬래시(/)로 사이트 구조를 나타내는 계층형 URL이에요. 퍼널, 웹사이트, 웨비나의 URL을 이 방식으로 만들 수 있어요. 콘텐츠 구성이 URL에 그대로 드러나서 사람이 이해하기 쉽고 SEO에도 도움이 돼요.

중첩 경로 예시:
`/resources/courses/sales-funnel``/webinars/2025/summer-session``/campaigns/holiday/blackfridayoffer``/funnels/product-launch/step1`

## 중첩 URL 경로의 장점

- SEO 최적화: 깔끔한 계층형 URL은 사이트 구조를 정리해 줘요. 검색 엔진이 콘텐츠를 더 쉽게 색인하고 이해해서 SEO 순위에 도움이 돼요.
- 더 나은 사용자 경험: 방문자는 주소창에서 알아보기 쉽고 잘 정리된 경로를 보게 돼요. 사이트가 더 전문적으로 보이고 이동하기도 편해요.
- 유연한 편집: 여러 경로 구간을 가진 페이지와 단계를 만들거나 편집할 수 있어요. 복잡한 사이트, 상품 카탈로그, 콘텐츠 섹션, 여러 단계로 된 퍼널과 웨비나를 구성할 때 알맞아요.
- 정확한 사이트맵: 사이트맵에 올바른 중첩 경로가 반영돼요. Google 같은 검색 엔진이 더 잘 색인하고 찾을 수 있어요.
- 모듈 간 일관성: 퍼널, 웹사이트, 이커머스, 웨비나에서 모두 똑같이 쓸 수 있어요.

## 경로 검증, 제한 사항

시스템 제한을 미리 알아 두면 오류를 막고 깔끔한 URL을 만들 수 있어요.

### 예약된 경로

일부 경로는 시스템 기능을 위해 예약되어 있어서 쓸 수 없어요. 예약된 경로를 입력하면 오류 메시지가 표시돼요.
`/b/`: 블로그 기능용`/c/`: 카테고리용`/product/`: 상품 페이지용`/collections/`: 컬렉션 페이지용`/post/`: 블로그 게시글용`/category/`: 카테고리 페이지용`/author/`: 작성자 페이지용`/tag/`: 태그 페이지용`/store/account`: 스토어 계정 기능용

![예약된 경로를 입력했을 때 나오는 오류 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050251324/original/J28loAbkYih3VctfmNakOc_EpWGp1w1-sA.png?1753198305)

### 최대 깊이

중첩 URL은 최대 5단계까지 지원해요(예: `/level1/level2/level3/level4/level5`).

슬래시(/) 사이의 구간 하나가 1단계예요. 메인 도메인과 서브도메인은 단계 수에 포함되지 않아요. 5단계를 넘기면 빌더에서 저장이 막히고 **"URL path is too deep. Maximum 5 levels allowed."**(URL 경로가 너무 깊습니다. 최대 5단계까지 허용돼요.)라는 메시지가 나와요.

![5단계를 초과했을 때 나오는 오류 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050251411/original/an32vTeoLR8LKNchgjeX3ojEXHaWiDnpsg.png?1753198355)

## 중첩 URL 경로 사용하기

1. 퍼널, 웹사이트, 이커머스, 웨비나 중 원하는 곳의 페이지나 단계로 이동하세요.
2. **편집**을 클릭하세요.
3. 원하는 중첩 URL 경로를 입력하세요. 계층 구조는 `/`로 만들어요.

![중첩 URL 경로를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050250315/original/ojywG_xXo1WdOXTwGE-jo2BvoXXMuOFZaw.png?1753197485)

## 권장 사항

- 끝에 슬래시를 붙이지 마세요. 끝에 슬래시가 없는 깔끔한 경로를 쓰세요(예: `/path/subpath/` 대신 `/path/subpath`).
- 슬래시를 연달아 쓰지 마세요. 경로에 슬래시가 중복되지 않게 하세요(예: `/path//subpath`가 아니라 `/path/subpath`).
- 빈 구간을 두지 마세요. 슬래시 사이를 비워 두지 마세요(예: `/category//item`이 아니라 `/category/item`).
- 내용을 알 수 있는 경로를 쓰세요. 콘텐츠와 계층이 한눈에 보이도록 읽기 쉬운 URL을 만드세요(예: `/b/123` 대신 `/blog/seo-tips`).
- 논리적으로 구성하세요. 방문자가 이해하기 쉽고 사이트의 메뉴나 콘텐츠 계층과 맞는 구조로 경로를 만드세요.
- SEO를 고려하세요. 키워드가 들어간 잘 중첩된 경로는 콘텐츠 사이의 관계를 분명히 보여 줘서 검색 순위에 도움이 될 수 있어요.

## 자주 묻는 질문

### 예전에는 슬래시가 하이픈으로 바뀌었는데, 지금은 왜 안 바뀌나요?
예전에는 슬래시를 입력하면 자동으로 하이픈으로 바뀌어 단일 경로가 만들어졌어요. 중첩 URL에서는 슬래시가 그대로 유지돼서 폴더 같은 계층 구조를 만들 수 있어요.

### 이미 게시한 URL을 바꾸면 기존 링크가 깨지나요?
네, 깨질 수 있어요. 이전 주소에서 새 주소로 301 리디렉션을 설정하세요. 그러면 SEO 효과를 유지하고 404 오류를 피할 수 있어요.

### 대문자나 공백을 써도 되나요?
소문자, 숫자, 하이픈만 쓰는 것이 좋아요. 그래야 검색 엔진이 읽기 쉬운 깔끔한 슬러그가 돼요.

### 구간 안에 하이픈이나 숫자를 넣어도 되나요?
네. `/blog/2025/july-updates`나 `/course/lesson-1` 같은 경로도 사용할 수 있어요.

### 같은 사이트나 퍼널 안에서 중첩 URL과 단일 URL을 함께 써도 되나요?
네. 같은 웹사이트나 퍼널 안에서 일부 페이지는 한 단계(예: `/about`)로, 다른 페이지는 중첩 경로(예: `/blog/topic/10-22`)로 만들 수 있어요.
