# 퍼널과 웹사이트에 트래킹 코드/스크립트 추가하기

트래킹 코드를 사용하면 분석, 광고, 전환 추적 도구를 하이퍼클래스 퍼널(Funnel)과 웹사이트(Website)에 연결할 수 있어요. 스크립트가 실행되어야 하는 위치에 따라 특정 페이지에만 트래킹 코드를 추가하거나, 퍼널 또는 웹사이트 전체에 걸쳐 추가할 수 있습니다.

이 아티클에서는 페이지 단위 트래킹과 사이트 전체 트래킹의 차이, 각 유형의 코드를 어디에 추가해야 하는지, 그리고 트래킹이 제대로 작동하는지 확인하는 방법을 설명해요.

## **트래킹 코드란?**

트래킹 코드는 방문자가 퍼널이나 웹사이트와 상호작용할 때 정보를 수집하거나 이벤트를 발생시키는 스크립트예요.

대표적인 예시는 다음과 같습니다:

- Google Analytics
- Google Tag Manager
- Meta Pixel
- 분석 스크립트
- 광고 픽셀
- 전환 이벤트 스크립트

일반적으로 스크립트 제공처에서 코드를 어디에 배치해야 하는지 안내해줘요.

**중요: **트래킹 스크립트를 생성한 서비스에서 제공하는 배치 안내를 항상 따라주세요.

---

## **페이지 단위 트래킹 vs. 사이트 전체 트래킹**

스크립트를 추가하기 전에, 특정 페이지 하나에서만 실행되어야 하는지 아니면 퍼널이나 웹사이트 전체에서 실행되어야 하는지 먼저 결정해야 해요.

| 트래킹 유형 | 적합한 경우 | 추가 위치 |
|---|---|---|
| 페이지 단위 트래킹 | 특정 퍼널 단계(Funnel Step)나 웹사이트 페이지에서만 실행되어야 하는 스크립트나 이벤트 | 빌더에서 페이지를 열고 Tracking Code(트래킹 코드)에서 Header Tracking(헤더 트래킹) 또는 Footer Tracking(푸터 트래킹) 아래에 스크립트를 추가 |
| 사이트 전체 트래킹 | 선택한 퍼널 또는 웹사이트의 모든 페이지/단계에서 실행되어야 하는 스크립트 | 퍼널 또는 웹사이트의 Settings(설정)를 열고 Head tracking code(헤드 트래킹 코드) 또는 Body tracking code(바디 트래킹 코드) 아래에 스크립트를 추가 |

예를 들어, 모든 페이지에서 실행되어야 하는 Google Analytics나 Meta Pixel 기본 스크립트는 사이트 전체 레벨에 추가하면 돼요. 확인 페이지에 도달했을 때만 발생해야 하는 전환 이벤트는 페이지 단위로 추가하면 됩니다.

## **특정 페이지에 트래킹 코드 추가하는 방법**

특정 퍼널 단계나 웹사이트 페이지 하나에서만 스크립트가 실행되어야 할 때는 페이지 단위 트래킹을 사용하세요.

**1단계: 퍼널 또는 웹사이트 열기**

Sites(사이트)로 이동한 후 Funnels(퍼널) 또는 Websites(웹사이트)를 선택하세요.

트래킹 코드를 추가할 페이지가 포함된 퍼널 또는 웹사이트를 엽니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082921977/original/T635P65jZHddUkQdOCls9ncGPRZ90OChog.png?1791535735)

**2단계: 빌더에서 페이지 열기**

해당 페이지 또는 퍼널 단계를 선택해서 빌더(Builder)에서 엽니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922042/original/k0pNxnPNkcQeA7b8L9e_Lc5bljmm5WypCA.png?1791535752)

**3단계: Tracking Code 열기**

빌더에서 Tracking Code(트래킹 코드) 옵션을 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922090/original/Wvvn25l2h1vqIqCuS03qur4c9swQr7FukA.png?1791535767)

**4단계: 스크립트 추가**

다음 중 하나에 스크립트를 붙여넣으세요:

- Header Tracking(헤더 트래킹), 또는
- Footer Tracking(푸터 트래킹)

트래킹 제공처에서 지정한 위치를 사용하세요.

Save(저장)를 클릭합니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922200/original/gLXYLPfxBV7H5QB-P9U_aEWtx3Bu0W4Tdw.png?1791535793)

**5단계: 트래킹 확인**

발행된 페이지를 열어서 트래킹 코드가 예상대로 작동하는지 확인하세요.

가능하다면 분석 또는 광고 제공처의 테스트 도구를 사용해서 스크립트나 이벤트가 정상적으로 감지되는지 확인하세요.

## **퍼널 또는 웹사이트 전체에 트래킹 코드 추가하는 방법**

동일한 스크립트가 퍼널이나 웹사이트 내 모든 페이지/단계에서 실행되어야 할 때는 사이트 전체 트래킹을 사용하세요.

**1단계: 퍼널 또는 웹사이트 열기**

Sites(사이트) > Funnels(퍼널) 또는 Sites(사이트) > Websites(웹사이트)로 이동한 후 해당 퍼널 또는 웹사이트를 엽니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922334/original/8lie1QAuuQcAk7MARd2ZUxK4Hj_AirAcOA.png?1791535832)

**2단계: Settings 열기**

Settings(설정) 탭을 클릭하세요.

**3단계: 트래킹 코드 추가**

트래킹 코드 입력란을 찾으세요:

- Head tracking code(헤드 트래킹 코드)
- Body tracking code(바디 트래킹 코드)

트래킹 제공처에서 지정한 위치에 스크립트를 붙여넣으세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922455/original/u9IIc1iu9GLtSfxniqamJ4p0fxIcfpEXKA.png?1791535886)

**4단계: 저장 및 확인**

Save(저장)를 클릭해서 트래킹 코드를 적용하세요.

그런 다음 스크립트가 실행되어야 할 발행된 페이지에서 확인하세요.

가능하다면 분석 또는 광고 제공처의 테스트 도구를 사용해서 스크립트나 이벤트가 정상적으로 감지되는지 확인하세요.

## 트래킹 코드는 어디에 추가해야 할까요?

스크립트를 어디에 배치할지 결정할 때 다음 가이드를 참고하세요.

| 요구사항 | 권장 배치 위치 |
|---|---|
| 특정 페이지 하나에서만 실행 | 페이지 단위 Header Tracking 또는 Footer Tracking |
| 퍼널 또는 웹사이트 전체에서 실행 | 사이트 전체 Head tracking code 또는 Body tracking code |
| 모든 페이지에서 실행되어야 하는 Google Analytics 또는 Meta Pixel 기본 스크립트 | 사이트 전체 트래킹 |
| 특정 페이지에서만 실행되어야 하는 전환 이벤트 | 페이지 단위 트래킹 |
| 제공처가 스크립트를 페이지 헤드에 배치해야 한다고 명시한 경우 | Header Tracking 또는 Head tracking code |

정확한 배치 위치는 서드파티 서비스에서 제공하는 요구사항에 따라 달라져요.

## **트래킹 코드 확인하는 방법**

트래킹 코드를 추가한 후에는 제대로 작동하는지 테스트해보세요.

- 트래킹 코드를 저장합니다.
- 트래킹이 실행되어야 할 발행된 페이지를 엽니다.
- 페이지 열기, 폼 제출, 확인 페이지 도달 등 추적하려는 동작을 직접 수행해봅니다.
- 가능하다면 분석 또는 광고 제공처의 테스트 도구를 사용해서 스크립트나 이벤트가 감지되는지 확인합니다.
- 트래킹이 의도한 페이지(들)에서 실행되는지 확인합니다.

**참고:** 하이퍼클래스를 통해 추가된 트래킹 스크립트는 브라우저에서 동적으로 삽입될 수 있어서, 정적인 View Page Source(페이지 소스 보기) 결과에는 나타나지 않을 수 있어요. 스크립트를 검증할 때는 브라우저 개발자 도구나 트래킹 제공처의 테스트 도구를 사용하세요.

## **주의할 점**

### **동일한 스크립트를 두 번 추가하지 마세요**

페이지 단위 트래킹을 추가하기 전에, 동일한 스크립트가 이미 퍼널이나 웹사이트 레벨에 설정되어 있는지 먼저 확인하세요.

동일한 트래킹 스크립트를 양쪽 레벨에 모두 추가하면 다음과 같은 데이터가 중복될 수 있어요:

- 페이지뷰
- 이벤트
- 전환
- 리포팅 데이터

스크립트가 실행되어야 하는 위치에 따라 페이지 단위 또는 사이트 전체 트래킹 중 하나만 사용하세요.

### **페이지를 복제해도 페이지 단위 트래킹은 복사되지 않아요**

퍼널 단계나 웹사이트 페이지를 복사할 때, 페이지 단위 트래킹 코드는 의도적으로 복사된 페이지에서 제외돼요.

이는 페이지별 픽셀, 분석 스크립트, 전환 이벤트가 엉뚱한 페이지로 옮겨지는 것을 방지하기 위함이에요.

사이트 전체 트래킹은 개별 페이지가 아니라 퍼널이나 웹사이트 레벨에서 설정되기 때문에 계속 적용됩니다.

### **쿠키 동의 요구사항을 고려하세요**

분석 및 광고 스크립트는 쿠키나 다른 트래킹 기술을 사용할 수 있어요.

하이퍼클래스는 퍼널과 웹사이트를 위한 Cookie Consent Banner(쿠키 동의 배너)를 제공해요. 방문자 정보를 저장하거나 접근하는 스크립트를 사용할 때는 트래킹 설정과 해당되는 개인정보보호 요구사항을 검토하세요.

## **자주 묻는 질문**

**Q: Google Analytics를 모든 페이지에 개별적으로 추가해야 하나요?**
Google Analytics 기본 스크립트가 퍼널이나 웹사이트 전체에서 실행되어야 한다면, 모든 페이지에 개별적으로 추가하는 대신 사이트 전체 레벨에 추가하세요.

**Q: 감사 페이지(Thank-you Page)에만 트래킹을 추가할 수 있나요?**
네. 스크립트나 전환 이벤트가 특정 페이지에서만 실행되어야 할 때는 페이지 단위 트래킹을 사용하세요.

**Q: 하이퍼클래스에서 Google Tag Manager를 사용할 수 있나요?**
네. Google Tag Manager와 유사한 도구들은 하이퍼클래스의 트래킹 코드와 함께 사용할 수 있어요. 트래킹 제공처에서 제공하는 배치 안내를 따르세요.

**Q: 트래킹 코드가 View Page Source에 보이지 않는 이유는 무엇인가요?**
하이퍼클래스는 트래킹 코드를 브라우저에서 동적으로 삽입할 수 있어요. 스크립트가 실행 중인지 확인하려면 브라우저 개발자 도구나 트래킹 제공처의 테스트 도구를 사용하세요.

**Q: 이벤트가 두 번씩 발생하는 이유는 무엇인가요?**
동일한 트래킹 스크립트가 페이지 레벨과 퍼널 또는 웹사이트 레벨 양쪽에 모두 설치되어 있는지 확인해보세요. 중복 설치되면 같은 이벤트가 두 번 이상 발생할 수 있어요.

**Q: 페이지를 복제하면 트래킹 코드도 복사되나요?**
퍼널 단계나 웹사이트 페이지를 복제할 때 페이지 단위 트래킹 코드는 복사되지 않아요. 복사된 페이지를 검토한 후 필요하다면 해당 페이지에 맞는 트래킹 코드를 직접 추가하세요.

**Q: 퍼널이나 웹사이트에 Meta Pixel을 추가할 수 있나요?**
네. Meta Pixel은 픽셀이 실행되어야 하는 위치에 따라 페이지 단위로 추가하거나 퍼널/웹사이트 전체에 추가할 수 있어요. Meta Pixel과 Conversions API의 전체 설정 방법은 별도의 Meta Pixel 및 Conversion API 문서를 참고하세요.
