# 버튼을 클릭하면 요소 숨기기·표시하기 (퍼널·웹사이트)

버튼을 클릭했을 때 페이지의 요소를 숨기거나, 숨겨 둔 요소를 보이게 할 수 있어요. 모바일과 데스크톱 화면 모두에서 쓸 수 있어서 페이지를 더 인터랙티브하게 꾸밀 수 있어요.

## 기능 한눈에 보기

버튼을 클릭하면 요소가 사라지거나 나타나도록 설정할 수 있어요. 방문자가 페이지와 상호작용하는 방식을 더 다양하게 만들 수 있어요.

![버튼 클릭으로 요소를 숨기고 표시하는 동작 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155016827693/original/GHvFa800a2sgDhIy2-DyynGFwuhNtjPSSQ.gif?1704402287)

## 버튼을 클릭하면 요소 숨기기

버튼을 클릭할 때 특정 요소가 사라지도록 설정해요.

{% hint style="warning" %}
요소를 표시하려면 그 요소가 먼저 숨겨진 상태여야 해요. **Show Elements** 드롭다운에 요소가 하나도 보이지 않으면, 먼저 요소를 하나 숨겨야 해요.
{% endhint %}

1. 퍼널 빌더 또는 **웹사이트 빌더**에서 사용할 **버튼** 요소를 선택하세요.

   ![버튼 요소 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443023/original/t79cLrkg8_o2_Wr8VytkCiYc-pqddVhFxA.png?1763147219)

2. 화면 오른쪽에 요소 설정이 보여요. **일반** 아래에서 맨 아래까지 스크롤해 **Button Actions**(버튼 액션)를 찾으세요.
3. **Link To**(링크 대상) 드롭다운에서 **Hide & Show Elements**(요소 숨기기 및 표시)를 선택하세요.

   ![Link To 드롭다운에서 Hide & Show Elements 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443161/original/jhbFosfHIBKJdcYbXg6ZWFrgt54P4buGoQ.png?1763147343)

4. **Hide Elements**(요소 숨기기)를 클릭하면 페이지에 있는 모든 요소가 드롭다운 목록으로 나와요. 버튼을 클릭할 때 숨길 요소를 하나 이상 선택하세요. 요소, 섹션, 열, 열 안의 행 중에서 고를 수 있어요.

   ![Hide Elements 드롭다운에서 숨길 요소 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443284/original/k6pr-gDTp6oF4BH2bEbAwFY_TgaZAAUx5w.png?1763147471)

5. 숨길 요소를 다 골랐으면 **저장** 버튼을 눌러 변경사항을 저장하세요. 퍼널이나 웹사이트에서 동작을 확인하려면 **미리보기** 버튼을 누르세요.

   ![저장과 미리보기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443841/original/OYZG839cxFEys-ueO7YQTtgCWeCIs5t8Hg.png?1763148432)

## 버튼을 클릭하면 요소 표시하기

숨겨 둔 요소를 버튼을 클릭할 때 보이게 설정할 수도 있어요.

1. 보이게 할 요소를 선택하세요. 이 요소는 **숨김** 상태여야 해요. 왼쪽 설정에서 **스타일** 탭으로 이동한 뒤 아래로 스크롤해 **공개 범위**를 찾으세요.

   ![스타일 탭의 공개 범위 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443524/original/mRF1EVBn3ga7hXU6AHmVI0cUkGe8EL_nfw.png?1763147762)

2. 모바일과 데스크톱 **공개 범위** 버튼을 각각 클릭해 두 화면 모두에서 요소를 숨기세요. 숨겨지면 아이콘이 회색으로 바뀌어요.

   ![모바일과 데스크톱 공개 범위 버튼을 회색으로 바꾼 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443568/original/5rTzWTU7YMOQ3YuTMUhwLHmsIGtcgB-PLA.png?1763147876)

3. 퍼널 빌더 또는 **웹사이트 빌더**에서 사용할 **버튼** 요소를 선택하세요.

   ![버튼 요소 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443023/original/t79cLrkg8_o2_Wr8VytkCiYc-pqddVhFxA.png?1763147219)

4. 화면 오른쪽에 요소 설정이 보여요. **일반** 아래에서 맨 아래까지 스크롤해 **Button Actions**를 찾으세요.
5. **Link To** 드롭다운에서 **Hide & Show Elements**를 선택하세요.

   ![Link To 드롭다운에서 Hide & Show Elements 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443161/original/jhbFosfHIBKJdcYbXg6ZWFrgt54P4buGoQ.png?1763147343)

6. **Show Elements**(요소 표시)를 클릭하면 페이지에서 숨겨진 요소가 모두 드롭다운 목록으로 나와요. 버튼을 클릭할 때 보이게 할 요소를 하나 이상 선택하세요. 요소, 섹션, 열, 열 안의 행 중에서 고를 수 있어요.

   {% hint style="info" %}
   **Show Elements** 드롭다운에 요소가 하나도 보이지 않으면, 먼저 요소를 하나 숨겨야 해요.
   {% endhint %}

   ![Show Elements 드롭다운에서 표시할 요소 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443776/original/38xyjPc5JH-wXMdehq4uGE1RSYjKZiEa5g.png?1763148309)

7. 요소 선택을 마쳤으면 **저장** 버튼을 눌러 변경사항을 저장하세요. 퍼널이나 웹사이트에서 동작을 확인하려면 **미리보기** 버튼을 누르세요.

   ![저장과 미리보기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058443809/original/s5IhrbPiEL45pzSFwx2IySKOFIu4XMKgBg.png?1763148352)

## 숨겨진 요소 편집하기

요소를 데스크톱과 모바일 화면 모두에서 실수로 숨겼다면 캔버스에서는 그 요소가 보이지 않고 클릭할 수도 없어요. 하지만 빌더의 **레이어** 패널에서 요소를 찾아 편집할 수 있어요.

1. 퍼널 빌더 또는 **웹사이트 빌더** 왼쪽 위에서 **레이어** 아이콘(겹쳐진 레이어 모양)을 클릭하세요. 섹션이나 페이지의 모든 요소가 목록으로 나와요. 숨겨진 요소도 함께 보여요.
2. 목록을 스크롤해 숨긴 요소를 찾으세요. 흐리게 표시되거나, 두 화면 어디에서도 보이지 않는다는 뜻의 눈 모양 아이콘이 붙어 있을 수 있어요.
3. 목록에서 요소 이름을 클릭해 선택하세요. 빌더에서 그 요소가 강조 표시되고 설정 패널이 나타나요.
4. 요소를 선택한 상태에서 상단 바의 **공개 범위**(눈 모양 아이콘) 토글을 클릭하면 데스크톱, 모바일 또는 둘 다에서 요소를 다시 보이게 할 수 있어요.

![레이어 패널에서 숨겨진 요소를 찾아 공개 범위를 되돌리는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045152011/original/rQIdpQimPLgnlcYPpS4Jc9WiBloXE7h4qw.png?1744740041)
