# 버튼·이미지·SVG에 파일 다운로드 액션 추가하기

버튼, 이미지, SVG에 파일을 연결하면 방문자가 클릭 한 번으로 PDF, 이미지, 동영상, ZIP 같은 자료를 바로 받을 수 있어요. 퍼널이나 웹사이트를 벗어나지 않고 자료를 전달하고 싶을 때 사용하세요.

## 파일 다운로드 액션이란?

파일 다운로드 액션을 쓰면 버튼, 이미지, SVG가 미디어 라이브러리와 방문자를 바로 이어 주는 통로가 돼요. 방문자는 클릭만 하면 파일을 받아요. 링크를 복사하거나 다른 페이지로 이동하거나 외부 저장소를 쓸 필요가 없어요. 하이퍼클래스 빌더 안에서 설정하므로 코드를 한 줄도 쓰지 않아도 돼요.

## 주요 장점

방문자에게 페이지 안에서 바로 자료를 제공하면서 브랜드 일관성을 지키고 참여도를 높일 수 있어요.

- **즉시 전달:** 방문자가 클릭하는 순간 파일을 받아요. 다른 페이지로 이동하거나 기다릴 필요가 없어요.
- **코드 없이 설정:** 웹사이트 빌더 안에서 다운로드를 켤 수 있어요.
- **다양한 요소 지원:** 버튼, 이미지, SVG에서 쓸 수 있어서 디자인을 자유롭게 구성할 수 있어요.
- **파일 이름 지정:** 방문자의 다운로드 폴더에 표시될 파일 이름을 직접 정할 수 있어요. 브랜드에 맞는 이름을 붙여 보세요.
- **미디어 선택기 연동:** 하이퍼클래스 미디어 라이브러리에 이미 있는 파일을 그대로 고를 수 있어요.
- **여러 파일 형식 지원:** PDF, 동영상, ZIP 등을 제공할 수 있어요. 미디어 라이브러리에 올릴 수 있는 파일이면 모두 쓸 수 있어요.
- **사용자 경험 개선:** 방문자가 페이지를 떠나지 않아 퍼널이 짧아지고 전환율을 높이는 데 도움이 돼요.

## 요구 사항 및 제한 사항

먼저 아래 내용을 확인하면 설정할 때 헷갈리지 않아요.

- **요소당 파일 1개:** 버튼, 이미지, SVG 하나에는 다운로드 파일을 하나만 연결할 수 있어요.
- **파일 보관 위치:** 안정적으로 쓰려면 파일이 하이퍼클래스 미디어 라이브러리에 있어야 해요.
- **파일 크기 제한:** 미디어 라이브러리의 기본 업로드 제한이 그대로 적용돼요. 자세한 내용은 '미디어 라이브러리 사양 및 형식' 문서를 참고하세요.
- **지원 요소:** 버튼, 이미지, SVG에서 다운로드를 실행할 수 있어요.
- **지원 파일 형식:** 미디어 선택기에서 허용하는 형식이면 모두 쓸 수 있어요(PDF, PNG/JPG, MP3, MP4, DOCX, XLSX, ZIP 등).

{% hint style="info" %}
팁: 파일을 여러 개 제공하고 싶다면 하나의 ZIP 파일로 압축하세요. 그러면 파일 하나만 연결해도 돼요.
{% endhint %}

## 다운로드 자료 운영 팁

아래 내용을 지키면 빠르고 깔끔하게 자료를 전달할 수 있어요.

- **알아보기 쉬운 파일 이름 쓰기:** *Brand_Name_Checklist.pdf*처럼 브랜드 이름이 드러나는 이름을 쓰세요.
- **파일 크기와 형식 최적화:** 이미지나 동영상은 압축해서 다운로드 시간을 줄이세요.
- ****행동 유도(CTA)** 문구를 분명하게 쓰기:** '레시피 PDF 다운로드'처럼 무엇을 받는지 바로 알 수 있게 쓰세요.
- **최종본만 사용하기:** 미디어 라이브러리의 파일을 교체하거나 삭제하면 다운로드 액션에 저장된 링크가 끊어질 수 있어요.

## 파일 다운로드 액션 설정하기

버튼, 이미지, SVG에 클릭 한 번으로 받는 다운로드 액션을 추가하는 방법이에요.

### 1단계: 웹사이트 페이지 또는 퍼널 단계 열기

1. 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. **웹사이트** 또는 **퍼널** 탭을 선택하세요.
3. 원하는 웹사이트나 퍼널을 클릭한 다음, 해당 페이지나 퍼널 단계로 이동하세요.
4. **편집**을 클릭해 빌더를 여세요.

![사이트 메뉴에서 웹사이트 또는 퍼널 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049550103/original/usnFC82i2ztXKdQdhPt-2llEGr2fuFVF0Q.png?1752004518)

### 2단계: 요소를 선택하고 다운로드 액션 지정하기

1. 다운로드를 걸고 싶은 버튼, 이미지, SVG를 클릭하세요.
2. 요소에 따라 아래와 같이 설정하세요.
   - **버튼:** **설정** 패널을 열고 **Button Actions**(버튼 액션) 아래의 **Link To**(링크 대상) 드롭다운에서 **파일 다운로드**를 선택하세요.
   - **이미지:** **설정** 패널을 열고 **Image Action**(이미지 액션) 드롭다운에서 **파일 다운로드**를 선택하세요.
   - **SVG:** **설정** 패널을 열고 **SVG Action**(SVG 액션) 드롭다운에서 **파일 다운로드**를 선택하세요.

### 3단계: 다운로드할 파일 추가하기

1. **파일 선택**을 클릭해 미디어 라이브러리에서 파일을 고르거나 새 파일을 올리세요.
2. **파일 이름** 입력란에 방문자가 파일을 저장할 때 보게 될 이름을 입력하세요.

![파일 선택과 파일 이름 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049550529/original/a8QyOdK51YnMw7dxERI0jQACokKFuoqD8g.png?1752005603)

## 문제 해결

자주 생기는 문제와 해결 방법이에요.

- **클릭해도 아무 일도 일어나지 않아요:** **파일 다운로드** 액션이 선택되어 있는지, 파일이 연결되어 있는지 확인하세요.
- **404 오류가 나거나 링크가 끊어져요:** 미디어 라이브러리에 파일이 아직 있는지, URL이 바뀌지 않았는지 확인하세요.
- **파일이 중간에 멈춰요:** 파일 크기가 미디어 라이브러리 제한을 넘지 않는지 확인하고, 필요하면 압축하세요.
- **파일이 여러 개 필요해요:** 파일을 하나의 ZIP 파일로 묶어서 그 파일을 연결하세요.

## 자주 묻는 질문

### 요소 하나에 파일을 두 개 이상 연결할 수 있나요?

아니요. 요소 하나에는 다운로드 파일을 하나만 연결할 수 있어요. 파일이 여러 개 필요하면 하나의 ZIP 파일로 묶으세요.

### 파일을 다운로드하지 않고 새 탭에서 열려면 어떻게 하나요?

파일 다운로드 액션은 바로 내려받도록 만들어진 기능이에요. 브라우저에서 바로 보여 주고 싶다면 **Open URL in New Tab**(새 탭에서 URL 열기)을 사용하세요.

### 동적 URL에도 쓸 수 있나요?

미디어 라이브러리에서 선택한 정적 파일만 지원해요.

### 모바일에서도 똑같이 동작하나요?

네, 다만 일부 모바일 브라우저는 파일을 열 앱을 고르라고 안내할 수 있어요.

### Dropbox나 Google Drive 같은 외부 서비스에 파일을 보관해야 하나요?

아니요. 하이퍼클래스 미디어 라이브러리에 파일을 올리고 연결하면 돼요. 파일 다운로드 액션이 외부 서비스 없이 파일을 전달해요.
