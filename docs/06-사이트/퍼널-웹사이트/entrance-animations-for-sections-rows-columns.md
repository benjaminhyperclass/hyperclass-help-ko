# 섹션·행·열에 진입 애니메이션 적용하기

하이퍼클래스 페이지 빌더에서 **Section**(섹션), **Row**(행), **Column**(열) 전체에 진입 애니메이션을 적용하는 방법을 안내해요. 방문자가 스크롤할 때 블록이 순서대로 나타나도록 만들고 싶을 때 쓰세요.

애니메이션 스타일은 수십 가지 중에서 고를 수 있고, 시간과 이징을 세밀하게 조절할 수 있어요. 적용하기 전에 미리 확인하는 방법과 모바일에서 재생할지 정하는 방법도 함께 다뤄요.

## 레이아웃 블록 진입 애니메이션이란?

섹션, 행, 열에 진입 애니메이션을 적용하면 레이아웃 블록 전체가 한꺼번에 움직여요. 요소를 하나씩 설정할 필요 없이 섹션, 행, 열 중 하나에 애니메이션을 지정하면 그 안의 모든 내용이 함께 움직여요.

방문자가 스크롤해서 블록이 화면에 들어오면 애니메이션이 자동으로 재생돼요. 빌더는 섹션, 행, 열, 콘텐츠 순서로 애니메이션을 이어 붙여요. 각 블록은 바로 위 블록의 애니메이션이 끝난 뒤에 시작해요. 그래서 지연 시간을 직접 계산하지 않아도 페이지가 의도한 순서대로 나타나요.

애니메이션이 끝난 블록은 계속 보여요. 아직 차례가 오지 않은 콘텐츠는 사라져 있지 않고 원래 상태로 있어요. 그래서 스크롤할 때 빈 공간이 보이거나 화면이 깜빡이지 않아요.

## 주요 장점

요소를 하나씩 움직이는 것보다 레이아웃 블록에 적용하면 좋은 점이 많아요.

- 지연 시간을 직접 계산하지 않아도 돼요. 빌더가 애니메이션 순서를 자동으로 맞춰요. 블록을 추가하거나 삭제하거나 순서를 바꿔도 마찬가지예요.
- 페이지가 한 번에 자연스럽게 나타나요. 섹션, 행, 열 전체를 한 번에 움직여서 별도의 CSS 없이도 정돈된 느낌을 줄 수 있어요.
- 스크롤하면 재생돼요. 블록이 화면에 들어올 때 애니메이션이 시작되므로 화면 밖에서 미리 재생되는 일이 없어요.
- 블록마다 모바일 재생 여부를 정할 수 있어요. 모바일에서는 애니메이션이 기본으로 꺼져 있어요. 휴대폰에서도 움직임을 보여 주고 싶은 섹션, 행, 열만 골라서 켜세요.
- 이미 게시한 페이지도 자동으로 보정돼요. 게시된 페이지는 화면이 렌더링될 때 순서가 자동으로 바로잡혀서 다시 저장하지 않아도 돼요.

## 사용할 수 있는 애니메이션 종류

하이퍼클래스는 수십 가지 진입 애니메이션을 아홉 개 카테고리로 나누어 제공해요. 각 카테고리에는 방향이나 스타일이 다른 여러 효과가 있어요.

- **Fade**(페이드): **In**, **Up**, **Down**, **Left**, **Right**. 블록이 지정한 방향에서 미끄러지듯 들어오며 서서히 나타나요.
- **Slide**(슬라이드): **Up**, **Down**, **Left**, **Right**. 블록이 화면 밖에서 지정한 방향으로 밀려 들어와요.
- **Bounce**(바운스): **In**, **Up**, **Down**, **Left**, **Right**. 블록이 지정한 방향에서 탄성 있게 튕기며 제자리로 들어와요.
- **Flip**(플립): **Flip**, **Flip In X**, **Flip In Y**. 블록이 가로축이나 세로축을 중심으로 회전해요.
- **Rotate**(회전): **In**. 블록이 시계 방향으로 회전하며 서서히 나타나요.
- **Zoom**(줌): **In**. 블록이 작은 크기에서 커지며 서서히 나타나요.
- **Light Speed**(라이트 스피드): **Left**, **Right**. 블록이 기울어지듯 빠르고 역동적으로 들어와요.
- **Infinite Loop**(무한 반복): **Glow**, **Rocking**, **Bounce**. 블록이 들어온 뒤에도 애니메이션이 계속 반복돼요. 콜투액션 섹션에 잘 어울려요.

## 애니메이션 설정

진입 애니메이션을 고르면 네 가지 설정으로 블록이 들어오는 방식을 조절할 수 있어요.

![애니메이션 설정 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077504212/original/wpVV2t3QyaCLTW-g2VFV9Lmzn8HzQV48SQ.png?1785770963)

| 설정 | 범위 | 용도 |
| --- | --- | --- |
| **소요 시간** | 0.1초~3초 | 애니메이션이 끝날 때까지 걸리는 시간 |
| **Delay**(지연) | 0초~5초 | 애니메이션을 시작하기 전에 기다리는 시간 |
| **스케일** | 0.5배~2배 | 애니메이션을 시작할 때의 크기 배율(줌 효과) |
| **Easing**(이징) | **Linear**, **Ease-in**, **Ease-out**, **Ease-in-out** | 애니메이션의 가속 곡선 |

{% hint style="info" %}
미리보기는 바로 확인할 수 있어요. 사이드바에서 진입 애니메이션 카드에 마우스를 올리면 캔버스에서 선택한 블록에 애니메이션이 재생돼요. 마우스를 치우면 미리보기가 사라져요. 적용하기 전에 여러 효과를 나란히 비교해 보세요.
{% endhint %}

## 자동 순서 지정 방식

하이퍼클래스는 진입 애니메이션을 계층 순서대로 이어서 재생해요.

1. 섹션이 가장 먼저 움직여요.
2. 섹션 안의 행은 섹션 애니메이션이 끝난 뒤에 움직여요.
3. 각 행 안의 열은 행 애니메이션이 끝난 뒤에 움직여요.
4. 각 열 안의 콘텐츠(요소)는 열 애니메이션이 끝난 뒤에 움직여요.

각 블록은 바로 위 블록이 끝나야 시작해요. 기존 행 두 개 사이에 새 행을 추가하면 빌더가 그 행을 순서에 자동으로 끼워 넣어요. 블록을 삭제하면 빈자리를 메워서 순서를 다시 이어 줘요. 지연 시간을 다시 계산할 필요가 없어요.

애니메이션은 블록이 화면에 들어올 때 시작돼요. 이미 재생된 블록은 계속 보여요. 차례를 기다리는 콘텐츠는 사라지지 않고 원래 상태로 있어서, 깜빡임이나 빈 공간 없이 부드럽게 나타나요.

게시한 페이지에서도 페이지가 렌더링될 때 순서가 자동으로 바로잡혀요. 이미 게시된 페이지도 새 순서 로직이 적용되며 다시 저장하지 않아도 돼요.

{% hint style="info" %}
한눈에 보기: 하이퍼클래스는 섹션, 행, 열, 콘텐츠를 계층 순서대로 자동으로 이어 재생해요. 각 블록은 바로 위 블록이 끝나야 시작하므로, 블록을 추가하거나 삭제하거나 순서를 바꿔도 지연 시간을 직접 계산할 필요가 없어요.
{% endhint %}

## 진입 애니메이션 적용하기

다음 단계를 따르세요. 섹션, 행, 열 중 하나에 진입 애니메이션을 적용할 수 있어요.

1. 캔버스에서 섹션, 행, 열 중 하나를 클릭해서 선택하세요. 선택한 블록에 크기 조절 핸들이 달린 경계 상자가 나타나요.
2. 오른쪽 사이드바에서 **Animations**(애니메이션) 탭을 클릭하세요.
3. **Entrance Animation**(진입 애니메이션) 섹션을 펼치세요.

   ![애니메이션 탭의 진입 애니메이션 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077483438/original/QcQlk1o3TSVD2GqvFyhIdGACg882g7ygig.png?1785760450)

4. 진입 애니메이션 카드 위에 마우스를 올려 보세요. 캔버스에서 선택한 블록에 애니메이션이 바로 재생돼요. 마우스를 치우면 미리보기가 사라져요.
5. 적용할 애니메이션 카드를 클릭하세요. 애니메이션이 블록에 지정되고 **Entrance Animation** 섹션에 표시돼요.

   ![애니메이션 카드를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077483158/original/wilEsaPE24eEaoooJ9aEfBcG4q4uOrYqiA.gif?1785760276)

6. 슬라이더와 드롭다운으로 애니메이션 설정을 조절하세요.
   - **소요 시간**: 0.1초~3초
   - **Delay**: 0초~5초. 순서 지정에 따른 대기 시간에 더해서, 이 블록이 움직이기 전에 기다리는 시간을 추가해요.
   - **스케일**: 0.5배~2배. 줌 효과를 시작할 때의 크기예요.
   - **Easing**: **Linear**, **Ease-in**, **Ease-out**, **Ease-in-out**

   ![애니메이션 설정을 조절하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077483354/original/2nOnf_kmiKS_aq2ljP8Udh573Ezy2jAQAA.gif?1785760402)

7. 페이지 빌더 오른쪽 위에서 **저장**을 클릭한 다음 페이지를 게시하세요. 방문자가 블록을 스크롤해서 화면에 들어오면 게시된 페이지에서 애니메이션이 재생돼요.

   ![저장 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077483628/original/fVQ5ZhMPTF3eJ4AmqWz12RKNNyn_rVSSYg.png?1785760520)

## 모바일 애니메이션 설정

진입 애니메이션은 모바일 기기에서 기본으로 꺼져 있어요. 모바일 페이지를 빠르게 유지하고, 휴대폰을 느리게 하거나 방문자의 시선을 분산시키는 움직임을 없애기 위해서예요.

**Animations** 탭의 **Enable animations on mobile**(모바일에서 애니메이션 켜기) 토글로 섹션, 행, 열마다 모바일 애니메이션을 켤 수 있어요. 토글을 켜면 그 블록은 모바일 기기에서도 애니메이션이 재생돼요. 토글을 꺼 두면 모바일에서는 애니메이션 없이 바로 나타나요.

빌더는 토글이 꺼진 블록을 건너뛰고 모바일 애니메이션 순서를 다시 맞춰요. 예를 들어 섹션은 모바일에서 애니메이션이 켜져 있고 그 안의 행은 꺼져 있다면, 행은 바로 나타나요. 계층에서 그다음 블록은 섹션 애니메이션이 끝난 뒤에 시작해요. 이렇게 하면 기기가 달라도 순서가 맞게 유지돼요.

{% hint style="info" %}
모바일 토글은 블록마다 따로 설정해요. 중요한 섹션만 모바일 애니메이션을 켜고 나머지는 꺼 두면, 모바일 성능과 사용자 경험을 세밀하게 조절할 수 있어요.
{% endhint %}
