# 퍼널·웹사이트에 동영상 요소 추가하기

**동영상** 요소를 쓰면 퍼널과 웹사이트 페이지에 YouTube, Vimeo, Wistia, 사용자 지정 임베드 코드, HTML5 동영상을 보여 줄 수 있어요. 이 문서에서는 동영상 요소를 추가하는 방법과 동영상 종류별 설정 방법을 안내해요.

## 동영상 요소란?

**동영상** 요소는 퍼널과 웹사이트 페이지에 동영상을 바로 넣을 수 있는 요소예요. 동영상이 올라가 있는 곳에 맞춰 동영상 유형을 고르고, URL, 임베드 코드, 동영상 파일 URL 중 알맞은 것으로 추가하면 돼요.

지원하는 동영상 소스는 YouTube(YouTube Shorts 포함), Vimeo, Wistia, **Custom Embed**(사용자 지정 임베드), HTML5예요. 동영상을 추가한 뒤에는 자동 재생, 너비, 색상, 배경 같은 표시·재생 옵션도 설정할 수 있어요.

## 퍼널·웹사이트에 동영상 요소 추가하기

동영상 요소를 추가하면 지원하는 동영상 유형과 유형별 설정 옵션을 사용할 수 있어요.

1. **사이트**로 이동하세요.
2. **퍼널** 또는 **웹사이트**를 여세요.
3. 퍼널이나 웹사이트를 새로 **만들기**하거나, 기존 퍼널이나 웹사이트를 편집하세요.
4. 빌더에서 동영상을 넣을 페이지를 여세요.

   ![빌더에서 페이지 열기](https://jumpshare.com/share/AGX7i37qoLWUvmc03uW3+/GIF+Recording+2026-09-28+at+20.25.01.gif)
5. **요소 추가 (+)**를 클릭하세요.
6. **동영상**을 검색하세요.
7. **동영상** 요소를 페이지에서 원하는 위치로 끌어다 놓으세요.
8. 동영상 요소를 클릭해 설정을 여세요.

   ![동영상 요소 설정 열기](https://jumpshare.com/share/07F0DG61PEQ3k3YNOWqG+/GIF+Recording+2026-09-28+at+20.27.48.gif)

### YouTube

YouTube 동영상은 공개 동영상 URL로 추가해요. 일반 YouTube 동영상과 YouTube Shorts 모두 같은 방법으로 추가할 수 있어요.

{% hint style="info" %}
YouTube Shorts도 같은 방법으로 추가해요. YouTube Shorts의 URL을 복사한 다음, **YouTube**를 선택하고 **동영상 URL** 필드에 붙여넣으세요.
{% endhint %}

1. YouTube에서 동영상을 여세요.
2. **공유**를 클릭하고 동영상 링크를 복사하세요.
3. 동영상 요소로 돌아오세요.
4. 동영상 유형으로 **YouTube**를 선택하세요.
5. 복사한 링크를 **동영상 URL** 필드에 붙여넣으세요.

![YouTube 동영상 링크 붙여넣기](https://jumpshare.com/share/fRLZNmkqi7yxMM2pFgyO+/GIF+Recording+2026-09-28+at+20.57.39.gif)

### Vimeo

Vimeo 동영상은 페이지에서 접근할 수 있는 공유 URL로 보여 줄 수 있어요.

1. Vimeo에서 동영상을 여세요.
2. 동영상의 개인정보 보호 설정에서 공유 링크로 접근할 수 있는지 확인하세요.
3. **공유**를 클릭하고 동영상 링크를 복사하세요.
4. 동영상 요소로 돌아오세요.
5. 동영상 유형으로 **Vimeo**를 선택하세요.
6. 복사한 링크를 **동영상 URL** 필드에 붙여넣으세요.

![Vimeo 동영상 링크 붙여넣기](https://jumpshare.com/share/rE8qMv0kzvqxRwhmOZKA+/GIF+Recording+2026-09-28+at+21.02.20.gif)

### Wistia

Wistia 동영상은 공유 가능한 동영상 URL로 추가해요.

1. Wistia에서 동영상을 여세요.
2. 동영상의 공유 설정에서 링크가 있는 사람은 누구나 접근할 수 있는지 확인하세요.
3. 동영상의 공유 링크를 복사하세요.
4. 동영상 요소로 돌아오세요.
5. 동영상 유형으로 **Wistia**를 선택하세요.
6. 복사한 링크를 **동영상 URL** 필드에 붙여넣으세요.

![Wistia 동영상 링크 붙여넣기](https://jumpshare.com/share/ZFcOtogZCo9oSFaEPKQ1+/GIF+Recording+2026-09-28+at+21.04.07.gif)

### Custom Embed

**Custom Embed**(사용자 지정 임베드)는 동영상 URL 대신, 지원하는 동영상 플랫폼에서 제공하는 임베드 코드로 동영상을 추가하는 방법이에요.

1. 동영상이 올라가 있는 플랫폼에서 동영상을 여세요.
2. 동영상의 **임베드** 옵션을 찾으세요.
3. 제공된 임베드 코드를 복사하세요.
4. 동영상 요소로 돌아오세요.
5. 동영상 유형으로 **Custom Embed**를 선택하세요.
6. 복사한 코드를 **Video Embed**(동영상 임베드) 필드에 붙여넣으세요.

![임베드 코드 붙여넣기](https://jumpshare.com/share/LgzahvZ0MvwqsvHwTsDp+/GIF+Recording+2026-09-28+at+21.07.23.gif)

### HTML5

HTML5는 동영상 공유 플랫폼 대신 동영상 파일 URL로 직접 동영상을 보여 주는 방법이에요.

동영상 유형으로 **HTML5**를 선택하면 다음 항목을 입력할 수 있어요.

- **MP4 URL**(MP4 파일 주소)
- **WebM URL**(WebM 파일 주소)
- **썸네일 URL**

각 필드에 알맞은 URL을 입력하면 동영상이 표시돼요.

## 동영상 요소 설정

**비디오 설정**에서 동영상이 페이지에 보이는 모습과 동작을 조정할 수 있어요. 동영상 소스를 추가한 뒤에 설정할 수 있어요.

주요 설정은 다음과 같아요.

- **자동 재생**: 자동 재생을 켜거나 꺼요.
- **너비**: 동영상이 가로로 차지하는 공간을 조정해요.
- **색상**: 해당되는 색상을 사용자 지정해요.
- **배경**: 요소 주변의 배경 스타일을 설정해요.

![비디오 설정 화면](https://jumpshare.com/share/g4NZxJ6ToToCdGWIRU0j+/Screen+Shot+2026-09-28+at+21.08.56.png)

## Hosted Video

**Hosted Video**(호스팅 동영상)는 외부 동영상 URL이나 임베드 코드 대신 동영상 요소에서 동영상을 직접 추가하는 별도 옵션이에요.

설정 방법과 사용할 수 있는 설정은 [퍼널용 호스팅 동영상 플레이어](../기타/hosted-video-player-for-funnels.md) 문서를 참고하세요.

## 자주 묻는 질문

### YouTube Shorts도 추가할 수 있나요?
네. YouTube Shorts의 URL을 복사하고, 동영상 유형으로 YouTube를 선택한 다음 **동영상 URL** 필드에 붙여넣으세요.

### YouTube, Vimeo, Wistia 동영상이 불러와지지 않아요.
동영상 URL에 접근할 수 있는지 확인하세요. 그리고 동영상의 개인정보 보호 설정이나 공유 설정에서 입력한 링크로 동영상을 볼 수 있게 되어 있는지도 확인하세요.

### 동영상 URL 대신 Custom Embed는 언제 쓰나요?
동영상 플랫폼의 기본 동영상 URL이 아니라 해당 플랫폼에서 제공하는 임베드 코드를 쓰고 싶을 때 Custom Embed를 사용하세요.

### MP4나 WebM 동영상 URL도 사용할 수 있나요?
네. HTML5를 선택하고 알맞은 MP4 URL이나 WebM URL을 입력하세요. **썸네일 URL**도 함께 입력할 수 있어요.

### 추가한 동영상의 너비를 바꾸거나 자동 재생을 켤 수 있나요?
네. 동영상 요소에는 자동 재생, 너비, 색상, 배경 같은 설정이 있어요.
