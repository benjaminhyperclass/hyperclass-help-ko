# 퍼널·웹사이트 빌더의 자동 계층 레이아웃과 드래그 앤 드롭

요소를 캔버스 어디에나 끌어다 놓으면 빌더가 섹션, 행, 열을 알아서 만들어 줘요. 이 문서에서는 향상된 드래그 앤 드롭을 켜는 방법과 사용법을 안내해요. 하이퍼클래스의 자동 계층 기능으로 페이지를 더 빠르게 만들어 보세요.

## 향상된 드래그 앤 드롭과 자동 계층 레이아웃이란?

빌더에서 레이아웃 구조를 미리 만들어 두지 않아도 요소를 바로 캔버스에 추가할 수 있어요. 올바른 구조를 먼저 설정할 필요 없이, 요소를 캔버스에 그냥 놓으면 돼요. 필요한 레이아웃 계층은 빌더가 뒤에서 자동으로 만들어 줘요. 클릭 수가 줄고 헷갈릴 일도 적어서 페이지와 퍼널을 훨씬 빠르게 만들 수 있어요.

![향상된 드래그 앤 드롭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050739839/original/Mk3DK-Q-Wc9V_EXyYJKOgFef2fL24wgrMg.png?1753969518)

시스템은 각 요소를 섹션, 행, 열 같은 알맞은 레이아웃 컨테이너로 자동으로 감싸요. 설정 시간이 줄고 구조도 깔끔하고 일관되게 유지돼요. 자동 계층 로직과 시각적인 드롭 안내 덕분에 더 매끄럽고 직관적으로 작업할 수 있어요.

## 주요 장점

이 기능은 하이퍼클래스에서 페이지를 만드는 속도와 사용성을 크게 높여 줘요.

- 자유로운 드래그 앤 드롭: 레이아웃을 준비하지 않아도 어떤 요소든 캔버스에 바로 놓을 수 있어요.
- 자동 감싸기: 빌더가 올바른 구조(섹션 > 행 > 열)를 뒤에서 자동으로 만들어요.
- 스마트 배치 감지: 놓을 수 있는 위치를 자동으로 찾아 요소를 알맞게 맞춰 넣어요.
- 인라인 열 컨트롤: 캔버스에서 바로 기존 행에 새 열을 추가할 수 있어요.
- 더 나은 시각적 피드백: 고스트 윤곽선과 드롭 영역이 보여서 요소가 들어갈 위치를 미리 확인할 수 있어요.

## 사용 방법

**Enhanced Drag & Drop**(향상된 드래그 앤 드롭)이 켜져 있을 때 이 기능을 쓸 수 있어요. 이 설정은 **실험실**에 있어요. 켜면 새 요소를 캔버스로 끌어다 놓을 수 있고, 이미 있는 요소도 요소의 어느 부분이든 잡고 옮길 수 있어요.

서브 계정에서 이 기능을 쓰려면 에이전시 관리자가 **에이전시 보기 > 실험실**에서 켜야 해요.

### 직접 해 보기

1. 웹사이트 빌더에서 퍼널 또는 웹사이트 페이지를 열어요.
2. 사이드바에서 요소(예: **문자**, **버튼**, **이미지**)를 캔버스의 빈 곳으로 끌어다 놓아요.
3. 빌더가 요소를 알맞은 레이아웃 컨테이너로 자동으로 감싸는지 확인해요.
4. 요소의 아무 곳이나 잡고 원하는 위치로 끌어요. 이동 핸들은 필요 없어요.
5. 행 위에 마우스를 올리고 **+ Add Column**(열 추가)을 클릭해 새 열을 추가해요.
6. 고스트 윤곽선 같은 시각적 안내를 보며 요소를 정확하게 맞춰요.

![드래그 앤 드롭으로 요소를 배치하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050330879/original/M94lI-0H2eEViSy7mkixQ5WskCHSUysw3A.gif?1753294004)

## 행 안에서 열 순서 변경

같은 행 안에서는 섹션을 새로 만들지 않고도 **열 순서 변경**으로 레이아웃과 콘텐츠 흐름을 조정할 수 있어요.

1. 행 위에 마우스를 올려 열 경계와 드롭 영역이 나타나게 해요.
2. 열을 잡고 같은 행 안에서 왼쪽이나 오른쪽으로 끌어요.
3. 드롭 표시선을 보며 새 위치를 정하고, 마우스를 놓아 열을 내려놓아요.

{% hint style="info" %}
열 순서 변경은 현재 같은 행 안에서만 할 수 있어요. 열 순서를 바꾸면 반응형에서 쌓이는 순서가 달라질 수 있어요. 순서를 바꾼 뒤에는 태블릿과 모바일 보기를 다시 확인하세요.
{% endhint %}

### 정확하게 배치하는 팁

- 확대/축소 기능을 쓰면 작은 위치 조정이 더 쉬워요.
- 눈금자나 가이드가 있으면 요소를 일정하게 정렬하는 데 활용하세요.
- **실행 취소**와 **다시 실행**을 쓰면 부담 없이 시도해 보고, 잘못 놓았을 때 바로 되돌릴 수 있어요.

## 사용 예시

빌더가 레이아웃을 어떻게 자동으로 만드는지 보여 주는 예시예요.

- 빈 캔버스에 문자 요소를 끌어다 놓으면: 빌더가 섹션 > 행 > 열 > 문자 구조를 자동으로 만들어요.
- 빈 캔버스에 행을 끌어다 놓으면: 빌더가 섹션 > 행(기본 열 포함) 구조를 자동으로 만들어요.
- 기존 행에 열을 추가하려면: 캔버스에서 **+ Add Column** 버튼을 바로 클릭하면 레이아웃이 넓어져요.

## 자주 묻는 질문

### 섹션이나 행을 직접 추가해야 하나요?

아니요. 어떤 요소를 어디에 놓느냐에 따라 빌더가 자동으로 만들어 줘요.

### 자동으로 감싸는 동작을 끌 수 있나요?

현재는 이 동작이 자동으로 적용되고, 끌 수 없어요.

### 레이아웃 구조를 직접 만들고 싶으면 어떻게 하나요?

원하면 기존 방식대로 섹션, 행, 열을 직접 추가할 수 있어요. 구조를 세밀하게 직접 관리하고 싶을 때 쓰세요.

### 퍼널과 웹사이트 모두에서 쓸 수 있나요?

네. 드래그 앤 드롭 개선 사항은 퍼널과 웹사이트 모두에 적용돼요.

### 기존에 만든 페이지에도 영향이 있나요?

아니요. 앞으로 새 요소를 만들거나 편집할 때의 경험에만 영향을 줘요.

### 이동 핸들이 아직 필요한가요?

아니요. 요소의 어느 부분이든 잡고 옮길 수 있어요.

### 모바일 보기에서도 쓸 수 있나요?

네. 열 순서를 바꾼 뒤에는 반응형 순서를 다시 확인해서 태블릿과 모바일 레이아웃이 의도대로인지 살펴보세요.
