# 페이지 빌더에서 유니버설 요소 만들고 재사용하기

유니버설 요소(Universal Elements)를 쓰면 요소를 한 번만 디자인해 두고 퍼널, 웹사이트, 블로그, 웨비나, 스토어 페이지에서 계속 가져다 쓸 수 있어요. 모든 곳에서 같은 모양을 유지할 수 있어요. 이 문서에서는 유니버설 요소가 무엇인지, 다른 저장 항목과 어떻게 다른지, 만들고 배치하고 수정하는 방법을 안내해요. 게시 방법, 되돌리는 방법, 라이브러리를 정리하는 팁도 함께 알아봐요.

웹사이트 전반에 대해 알고 싶다면 [웹사이트 개요](../기타/websites-overview.md)를 참고하세요.

---

# 유니버설 요소란?

유니버설 요소는 **Saved Assets**(저장된 자산) 라이브러리에 저장하는 단일 요소예요. 저장해 두면 어디에 쓰든 원본과 *연결된* 상태로 유지돼요. 연결된 유니버설 요소를 수정하고 게시하면 배치된 모든 곳에 변경 내용이 반영돼요. 그래서 브랜드를 일관되게 유지하고, 페이지마다 같은 수정을 반복하지 않아도 돼요.

---

## 유니버설 요소의 장점

어떤 경우에 유니버설 요소가 맞고 어떤 경우에 다른 저장 항목이 맞는지 판단하는 데 도움이 돼요.

- 브랜드 일관성: 글꼴, 색상, 스타일을 직접 일일이 고치지 않아도 모든 곳에서 똑같이 유지해요.
- 빠른 제작: 자주 쓰는 요소를 다시 디자인하지 않고 **Saved Assets** 라이브러리에서 끌어다 놓으면 돼요.
- 한 번에 수정: 한 번 수정한 뒤 해당 페이지를 게시하면 모든 인스턴스에 변경 내용이 반영돼요.
- 정리된 라이브러리: **Saved Assets**의 썸네일과 검색으로 자주 쓰는 요소를 쉽게 찾아요.
- 팀 작업에 편리: 핵심 구성 요소를 표준화해 두면 팀원들이 승인된 패턴으로 페이지를 만들어요.

---

## 유니버설 요소, 요소 템플릿, 유니버설 섹션 비교

하이퍼클래스에서는 콘텐츠를 저장해 다시 쓰는 방법이 여러 가지예요. 알맞은 방법을 고르면 헷갈리지 않고, 의도치 않게 디자인이 달라지는 일도 막을 수 있어요. 아래 표를 보고 상황에 맞게 선택하세요.

| 저장 유형 | 범위 | 동기화 방식 | 주요 용도 | 위치 |
| --- | --- | --- | --- | --- |
| **Universal Elements**(유니버설 요소) | 단일 요소 | 연결된 상태로 재사용해요. 해당 페이지를 게시하면 배치된 인스턴스에 수정 내용이 반영돼요. | 버튼, 로고, 아이콘, 메뉴 | **Saved Assets > Universal Elements** |
| **Element Templates**(요소 템플릿) | 단일 요소 | 출발점으로 삽입돼요(복사본). 이후 수정해도 이미 배치된 요소에는 동기화되지 않아요. | 일회성 변형, 빠른 시작 패턴 | **Saved Assets > Element Templates** |
| **Universal Sections**(유니버설 섹션) | 섹션(여러 요소의 묶음) | 섹션 단위로 연결된 상태로 재사용해요. 게시 후 수정 내용이 배치된 인스턴스에 동기화될 수 있어요. | 헤더, 푸터, 공지 바 | **Saved Assets > 섹션**(유니버설) |

{% hint style="info" %}
버튼, 배지처럼 작고 반복되는 항목에는 유니버설 요소를 쓰세요. 헤더·푸터처럼 레이아웃 블록 전체를 재사용해야 할 때는 유니버설 섹션을 쓰세요.
{% endhint %}

섹션 저장에 대해서는 [저장된 섹션 – 퍼널, 웹사이트, 웨비나, 이커머스 스토어](saved-sections-funnels-websites-webinars-and-e-commerce-store.md)를, 요소 템플릿에 대해서는 [페이지 빌더에서 요소 템플릿 저장하고 사용하기](../Funnel-and-Website-Builder/how-to-save-use-element-templates-in-page-builder.md)를 참고하세요.

## 유니버설 요소 설정하기

처음부터 제대로 저장해야 다시 작업하지 않아도 돼요. 동기화되지 않는 템플릿이 아니라 *연결된* 유니버설 요소로 저장되도록 아래 순서를 따르세요.

1. 페이지 빌더에서 페이지를 열어요. 퍼널, 웹사이트, 블로그, 웨비나, 스토어 페이지 모두 가능해요.

   ![페이지 빌더에서 페이지를 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060208344/original/6gFjDPKXGd047GR-2ccJTY5x9wMgrfeMyg.png?1765279297)
2. 재사용할 요소(버튼, 이미지, 아이콘, 헤드라인, 메뉴 등)를 선택해요. 아래 두 위치 중 한 곳에서 **Universal Element**(유니버설 요소)로 저장해요.

   - 요소의 주황색 툴바에서 **저장** 아이콘을 클릭해요.

     ![요소 툴바의 저장 아이콘으로 저장하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060249962/original/IcrWNS_DjkYfFStNMGrj4blWU92FutX9gg.gif?1765298839)
   - **레이어** 패널에서 **⋯** 메뉴를 열고 **Save as Universal Element**(유니버설 요소로 저장)를 클릭해요.

     ![레이어 패널의 메뉴에서 유니버설 요소로 저장하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060250012/original/4ezdLDN7CvJ7FwrDV9fTdL3cEOzFH15Ppg.gif?1765298876)
3. 나중에 쉽게 검색할 수 있도록 알아보기 쉬운 이름을 지어요. 예: `버튼 — 기본 CTA`

   ![저장할 요소의 이름을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060209724/original/3IYT1URUkMZ7qIHPIdcZ9jjidGD1YjEB0w.png?1765279809)
4. 저장을 확인해요. 이제 **Saved Assets > Universal Elements**에 썸네일과 함께 표시돼요.

   ![저장된 유니버설 요소가 썸네일과 함께 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060320698/original/ltWTVk6J7W6wtXg42IkFcJxrRnhRLHqkaA.png?1765372871)

## 유니버설 요소 배치하고 수정하기

각 인스턴스가 연결된 상태로 유지되도록 **Saved Assets** 라이브러리에서 유니버설 요소를 배치하세요. 유니버설 요소를 수정한 뒤에는 **게시**해야 해당 페이지에 변경 내용이 실제로 반영돼요. 게시에 대한 자세한 내용은 [퍼널과 웹사이트 저장, 초안, 게시](../기타/save-draft-and-publish-funnels-and-websites.md)를 참고하세요.

AI 페이지 수정 기능은 연결된 유니버설 요소를 존중하고, 대상으로 지정한 콘텐츠 위주로 변경하도록 설계되어 있어요. 수정이 끝나면 수정 후 요약에서 연결된 요소가 바뀌었는지 확인하세요.

**권장 사항**

- 수정을 실행하기 전에 대상 영역에 연결된 유니버설 요소가 있는지 확인하세요.
- 해당 페이지에서만 다른 모습이 필요하다면, 수정하기 전에 유니버설 요소를 이 페이지 안에서 복제해(연결되지 않은 복사본으로 전환) 쓰세요.
- 수정으로 연결된 요소가 바뀌었다면, 변경 요약을 검토하고 확인이 끝난 뒤에 전체 변경을 신중하게 게시하세요.

**유니버설 요소 배치하기**

- **요소 추가 > Saved Assets > Universal Elements**를 열어요.
- 검색하거나 썸네일을 둘러본 다음, 요소를 캔버스로 끌어다 놓아요.

**유니버설 요소 수정하기**

- 배치된 유니버설 요소를 선택해 디자인이나 설정을 바꿔요.
- 페이지 변경 내용을 **저장**해요.
- 방문자에게 수정 내용이 보이도록 페이지를 **게시**해요.

![유니버설 요소를 수정하고 게시하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060321656/original/sHDh0V9FTNioEFGmiFKDSzYw2_A-8W4FOw.gif?1765373452)

## 저장된 유니버설 요소 관리하기

라이브러리를 깔끔하게 정리해 두면 제작 속도가 빨라지고 실수도 줄어요. 이름을 알아보기 쉽게 짓고, 검색을 잘 활용하고, 필요할 때는 쓰지 않는 항목을 정리하세요.

- 찾아보기와 검색: **요소 추가 > Saved Assets > Universal Elements**에서 썸네일을 보거나 키워드로 검색할 수 있어요.
- 이름으로 구분: `버튼 —`, `아이콘 —`, `메뉴 —`처럼 일정한 접두어를 붙이세요.
- 삭제는 신중하게: 저장된 항목을 삭제하면 라이브러리에서 빠져서 앞으로 쓸 수 없어요. 삭제하기 전에 그 항목을 쓰고 있는 페이지를 먼저 확인하세요.

  ![저장된 유니버설 요소를 관리하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060321228/original/_LsnzQW608YEoqH32qpuyYNYXhZBbH9nRw.png?1765373116)

**템플릿 라이브러리**에 대한 자세한 내용은 [템플릿 라이브러리 개요 및 설정](../../10-마케팅/template-library-overview-setup.md)을 참고하세요.

## 자주 묻는 질문

### 변경 내용을 방문자에게 보여 주려면 꼭 게시해야 하나요?

네. **저장**하면 수정 내용이 빌더에만 남아요. 해당 페이지를 **게시**해야 수정 내용이 실제로 반영돼요.

### 저장된 유니버설 요소는 어디에서 찾나요?

페이지 빌더에서 **요소 추가 > Saved Assets > Universal Elements**를 열어요. 썸네일을 둘러보거나 이름으로 검색할 수 있어요.

### 나중에 유니버설 요소의 이름을 바꾸거나 삭제할 수 있나요?

이름은 알아보기 쉽게 바꿀 수 있어요. 삭제하면 저장된 항목이 라이브러리에서 빠져서 앞으로 쓸 수 없어요. 삭제하기 전에 그 항목을 쓰고 있는 페이지를 먼저 확인하세요.

### 한 페이지에서만 조금 다르게 쓰고 싶어요.

**Element Templates**(요소 템플릿)의 요소를 배치하거나 이 페이지 안에서 복사본을 만들어 쓰세요. 그러면 변경 내용이 다른 페이지에 영향을 주지 않아요.

### 수정한 뒤 이상해 보일 때 이전 상태로 되돌리려면 어떻게 하나요?

해당 페이지의 **버전 기록**에서 이전 버전을 복원한 다음 다시 게시하세요. 자동 저장과 버전 기록에 대한 자세한 내용은 [자동 저장과 버전 기록](auto-save-and-version-history-for-funnels-websites-and-more.md)을 참고하세요.
