# 폼으로 웨비나 시간대를 고르게 하고 확인 이메일 보내기

하이퍼클래스에서 참가자가 웨비나 시간대를 직접 고르는 폼을 만들고, 선택한 시간이 담긴 확인 이메일을 자동으로 보내는 방법이에요. 등록 폼은 하나만 두고, 시간대 선택지는 여러 개 주고, 등록 직후 확인 메시지를 보내고 싶을 때 쓰세요.

## 개요

- 웨비나 시간대를 저장할 커스텀 필드를 만들어요.
- 이 필드를 등록 폼에 추가해요.
- 워크플로우로 폼이 제출될 때 확인 이메일을 보내요.
- 필요하면 웨비나 전에 리마인더도 보내요.

---

## 1단계: 웨비나 시간대용 커스텀 필드 만들기

1. **설정 > 커스텀 필드**로 이동하세요.
2. **+ Add Field**(필드 추가)를 클릭하세요.
3. **드롭다운** 또는 **라디오 선택**을 고르세요.
4. 필드 이름을 `Choose Your Webinar Time`으로 입력하세요.
5. **오브젝트**를 **연락처**로 설정하세요.
6. 시간대 선택지를 추가하세요. 예를 들면 다음과 같아요.

   - 화요일 오후 7시
   - 목요일 오후 2시
   - 토요일 오전 11시
7. **Allow Custom Values**(커스텀 값 허용)는 체크하지 마세요. 그러면 참가자가 미리 정해 둔 시간대 중에서만 고를 수 있어요.
8. **저장**을 클릭하세요.

---

## 2단계: 폼에 필드 추가하기

1. **사이트 > 폼**으로 이동해 새 폼을 **만들기**하거나 기존 폼을 **편집**하세요.
2. **커스텀 필드** 탭에서 방금 만든 `Choose Your Webinar Time` 필드를 폼으로 끌어다 놓으세요.
3. 이름, 성, 이메일 등 필요한 다른 필드도 추가하세요.
4. 폼을 **저장**하세요.

이제 참가자가 등록할 때 웨비나 시간대를 고를 수 있어요.

---

## 3단계: 확인 이메일 설정하기

**폼 설정**으로는 제출 후 페이지에서 보이는 동작(감사 메시지, 리디렉션, 픽셀)만 정할 수 있어요. 이메일을 보내려면 워크플로우가 필요해요.

1. **자동화 > 워크플로우**로 이동해 **Create Workflow**(워크플로우 만들기)를 클릭하세요.
2. 트리거를 추가하고 **Form Submitted**(폼 제출)를 선택하세요.
3. 웨비나 폼을 선택하세요.
4. **Send Email**(이메일 보내기) 액션을 추가하세요.

   - **Subject**(제목): 웨비나 등록이 완료되었어요
   - **Body**(본문):

     ```
     {{contact.first_name}}님, 안녕하세요.

     등록해 주셔서 감사합니다. 선택하신 시간대는 {{custom_values.choose_your_webinar_time}} 입니다.

     웨비나 링크는 다음과 같습니다: [Zoom/미팅 링크 입력]

     그때 뵙겠습니다.
     ```
5. 워크플로우를 저장하고 게시하세요.

이제 등록하는 모든 참가자에게 선택한 시간대가 들어간 확인 이메일이 바로 발송돼요.

---

## 4단계: 리마인더 이메일·SMS 보내기 (선택)

웨비나 전에 리마인더를 보내고 싶다면 다음과 같이 하세요.

1. 같은 워크플로우에 웨비나 시간을 기준으로 **Wait Until**(지정한 시점까지 대기) 액션을 추가하세요.
2. 리마인더를 보내세요. 예를 들면 다음과 같아요.

   - 24시간 전
   - 1시간 전
   - 10분 전

여러 회차를 운영한다면 워크플로우에 **If/Else**(조건 분기)를 추가해 선택한 시간대별로 나눌 수 있어요.

---

## 자주 묻는 질문

### 드롭다운/라디오 필드에서 커스텀 값을 허용해야 하나요?
아니요. 체크하지 않은 상태로 두세요. 그러면 등록자가 정해 둔 웨비나 시간 중에서만 고를 수 있어요.

### 워크플로우 없이도 설정할 수 있나요?
페이지에 감사 메시지만 보여 주고 싶다면 가능해요. 확인 이메일을 보내려면 항상 자동화가 필요해요.

### 시간대별로 리마인더를 나눠 보낼 수 있나요?
네. 워크플로우에 **If/Else**(조건 분기) 단계를 추가하고, `Choose Your Webinar Time` 필드 값을 기준으로 나누세요.
