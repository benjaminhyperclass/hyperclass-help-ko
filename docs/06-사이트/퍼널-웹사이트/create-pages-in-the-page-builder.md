# 페이지 빌더에서 페이지 만들기

페이지 빌더 화면을 벗어나지 않고 페이지를 만들고, 순서를 정리하고, 다른 페이지로 옮겨 갈 수 있어요. 여러 페이지로 이루어진 퍼널이나 웹사이트를 만들 때 쓰세요.

## 이 문서에서 알 수 있는 내용

하이퍼클래스 페이지 빌더 안에서 새 페이지를 만들고, 페이지 순서를 바꾸고, 페이지 사이를 빠르게 이동하는 방법을 설명해요. 퍼널과 웹사이트를 만들 때 화면을 오가는 일이 줄어서 작업이 빨라져요.

**페이지** 패널, 페이지 선택 팝오버, 드래그 앤 드롭 순서 변경, **검색**을 사용해요. 화면 이동에 신경 쓰지 않고 디자인과 전환에 집중할 수 있어요.

## 페이지 빌더에서 새 페이지 만들기란?

퍼널·웹사이트 기능의 하나로, 하이퍼클래스 페이지 빌더를 벗어나지 않고 페이지를 만들고 설정하고 정리할 수 있어요. 예전에는 퍼널이나 웹사이트 설정으로 돌아가서 페이지를 추가하거나 순서를 바꿔야 했어요. 이제는 편집 화면 안의 **페이지** 패널과 페이지 선택 팝오버에서 모두 할 수 있어요.

퍼널과 웹사이트 모두 쓸 수 있어요. 드래그 앤 드롭 레이아웃이나 새 내비게이션 메뉴 같은 기존 빌더 개선 사항과 함께 쓰면 여러 페이지를 더 빠르게 만들고 관리할 수 있어요.

이 기능에는 네 가지 도구가 있어요.

- **페이지** 패널의 **새 페이지 추가** 버튼
- 빠른 이동을 위해 액션 바에 있는 페이지 선택 팝오버
- 드래그 앤 드롭 페이지 순서 변경
- 페이지가 많을 때 원하는 페이지를 찾는 **검색** 창

## 이럴 때 편해요

페이지 관리 도구가 모두 편집 화면 안에 있어서, 여러 페이지를 만들 때도 이후에 관리할 때도 번거로움이 줄어요.

- 여러 페이지를 더 빠르게 만들 수 있어요. 설정 화면으로 나가지 않고, 디자인하던 자리에서 바로 새 퍼널 단계나 웹사이트 페이지를 만들 수 있어요.
- 화면 전환이 줄어요. 빌더 캔버스에서 페이지 이름, 경로, 순서를 함께 관리하니 레이아웃과 전환에 더 집중할 수 있어요.
- 익숙한 방식으로 순서를 바꿀 수 있어요. 하이퍼클래스의 다른 곳에서 쓰던 드래그 앤 드롭으로 페이지 순서를 내비게이션이나 퍼널 흐름에 맞춰 정리해요.
- 페이지 사이를 빠르게 이동할 수 있어요. 작은 페이지 선택 팝오버에서 바로 이동하니, 헤더·푸터·공통 섹션을 오가며 작업할 때 좋아요.
- 큰 프로젝트에도 잘 맞아요. 단계가 수십 개이거나 콘텐츠가 많은 사이트라면 **페이지** 패널의 **검색**으로 원하는 페이지를 바로 찾을 수 있어요.

## 페이지 패널에서 새 페이지 추가하기

**페이지** 패널의 **새 페이지 추가**는 디자인하면서 바로 페이지를 만드는 기본 방법이에요. 페이지 생성, 이름 짓기, 경로 설정을 편집 화면에서 한 번에 할 수 있어서 퍼널이나 사이트 전체를 한 흐름으로 만들 수 있어요.

1. 빌더에서 퍼널이나 웹사이트를 열어요.

   **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동한 뒤, 아무 페이지에서나 **편집**을 클릭하면 페이지 빌더가 열려요.

   ![사이트 메뉴에서 페이지를 편집해 페이지 빌더를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081948715/original/kroOnhY5lr5X2v4-0L1TkWbJd8iIlKfwBA.png?1790537471)

2. **페이지** 패널을 열어요.

   빌더에서 **페이지** 패널을 열어요. 레이아웃에 따라 왼쪽이나 옆쪽 메뉴에서 열 수 있어요. 현재 퍼널이나 웹사이트의 모든 페이지(단계)가 목록으로 보여요.

   ![페이지 패널에 표시된 페이지 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077809302/original/BUWt5LHYOqxbriKbxxx3TulaCQ2iukwDsQ.png?1786025418)

3. **새 페이지 추가**를 클릭해요.

   페이지 목록 위쪽이나 아래쪽에 있어요. 빌더를 나가지 않고 새 페이지를 설정할 수 있는 입력 창이 열려요.

   ![새 페이지 추가 입력 창이 열린 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077809365/original/vuepBNxIrbugl38IOPGM4Qr9WJZ8ghoLzw.png?1786025470)

4. 새 페이지를 설정해요.

   - **페이지 이름**: 알아보기 쉬운 이름을 입력해요. 예: "가격", "감사", "웨비나 확인"
   - **URL Path / Slug**(URL 경로): 방문자가 접속할 경로를 정해요. 예: /pricing, /thank-you. 짧고 읽기 쉽고 페이지 내용과 관련 있게 써요.

   같은 퍼널이나 웹사이트 안의 다른 페이지와 경로가 겹치면, URL이 겹치지 않게 경로를 바꿔 주세요.

   ![페이지 이름과 URL 경로를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077809692/original/h2olIuQk_joofQPaDFThIrI3XS4sQoH0bQ.png?1786025629)

5. 페이지를 만들어요.

   새 페이지가 **페이지** 패널 목록에 바로 나타나고, 빌더에서 편집할 수 있게 돼요.

   ![새 페이지가 패널 목록에 추가된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077809617/original/vQqJNAkHG8mWsdgIY1Tpni-49ngO1YtF2Q.png?1786025590)

6. 디자인을 시작해요.

   패널에서 새 페이지를 선택하면 캔버스가 그 페이지로 바뀌어요. 섹션, 행, 요소를 추가해 보세요.

   ![새 페이지를 선택해 캔버스에서 디자인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077809784/original/rdqDSD_GmxCIHp3_UxASAA0FB1vJB4trNw.png?1786025693)

{% hint style="info" %}
퍼널과 웹사이트 모두 이름을 일관되게 지으세요. 예를 들어 "홈", "소개", "서비스", "연락처"처럼 정하면 나중에 페이지를 검색하고 관리하기 편해요.
{% endhint %}

## 액션 바의 페이지 선택 팝오버

페이지 선택 팝오버는 보조 액션 바에 있어요. 모든 페이지를 작게 한눈에 보여 주기 때문에, **페이지** 패널을 열지 않고 빠르게 페이지를 옮길 때 좋아요. 화면이 작을 때도 작업 공간을 깔끔하게 유지하면서 내비게이션, 랜딩 페이지 등 주요 단계로 바로 이동할 수 있어요.

1. 페이지 선택기를 찾아요.

   빌더의 보조 액션 바(보통 화면 위쪽)에서 현재 페이지 이름이나 페이지 드롭다운 아이콘을 찾아요.

2. 팝오버를 열어요.

   페이지 이름이나 드롭다운을 클릭하면 페이지 선택 팝오버가 열려요. 현재 퍼널이나 웹사이트의 모든 페이지가 나오고, 보통 **페이지** 패널의 순서와 같아요.

   ![페이지 선택 팝오버가 열린 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077809898/original/EY7wXDxs8t95W046iIevTUgXa4EDJ5bAsA.png?1786025768)

3. 페이지를 옮겨 다녀요.

   목록에서 페이지를 클릭하면 캔버스가 바로 그 페이지로 바뀌어요. 여러 페이지에 걸쳐 나오는 내비게이션 메뉴나 푸터 같은 공통 요소를 오가며 작업할 때 특히 편해요.

4. 팝오버에서 바로 새 페이지를 추가해요.

   팝오버 안에서 새 페이지 입력란이나 **새 페이지 추가** 옵션을 찾아요.

   - 팝오버 안에서 바로 **페이지 이름**과 URL 경로를 입력해요.
   - 저장하면 퍼널이나 웹사이트에 페이지가 추가되고, 팝오버와 **페이지** 패널 목록에 모두 나타나요.

5. 팝오버를 닫아요.

   팝오버 바깥을 클릭하거나 닫기 아이콘을 누르면 선택한 페이지에서 계속 디자인할 수 있어요.

{% hint style="info" %}
옵트인 → 판매 → 감사 페이지처럼 3단계 퍼널을 만들 때는 팝오버를 열어 두세요. 헤드라인, 내비게이션 레이블, 공통 섹션을 고치면서 단계 사이를 빠르게 오갈 수 있어요.
{% endhint %}

## 드래그 앤 드롭으로 페이지 순서 바꾸기

페이지 빌더에서 작업하면서 페이지 순서를 정리할 수 있어요. 웹사이트 페이지는 빌더를 열지 않고 **페이지** 그리드에서 바로 순서를 바꿀 수도 있어요.

순서를 바꿀 수 있는 곳은 다음과 같아요.

- **페이지** 패널: 페이지 빌더에서 작업하면서 순서를 바꿔요.
- 페이지 선택 팝오버: 빌더 캔버스에서 눈을 떼지 않고 빠르게 순서를 조정해요.
- **웹사이트 페이지** 그리드: **페이지** 영역에서 웹사이트 페이지 카드를 바로 옮겨요. 원하는 자리에 놓으면 새 순서가 자동으로 저장되고, 확인 단계는 없어요.

1. **페이지** 패널이나 페이지 선택 팝오버를 열어요.

   편한 쪽을 사용하세요.

2. 옮길 페이지를 클릭한 채로 누르고 있어요.

   페이지 항목 위에 마우스를 올리면 드래그 핸들(가로줄 세 개 같은 모양)이 보이거나 커서가 바뀌어요.

3. 새 위치로 끌어 놓아요.

   페이지를 목록에서 위나 아래로 끌어요. 원하는 위치에서 마우스를 놓아요.

   ![페이지를 끌어서 순서를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077810123/original/mo6biQo_4W4XGdOdYtJgSoipyeHIwfxWwg.gif?1786025926)

4. 확인 창이 나오면 내용을 확인해요.

   **페이지** 패널이나 페이지 선택 팝오버에서 순서를 바꿀 때, 웨비나 퍼널처럼 순서가 중요한 흐름이라면 하이퍼클래스가 확인 창을 보여 줄 수 있어요. 경고 내용을 꼼꼼히 읽고, 순서를 바꿔도 의도한 흐름에 문제가 없을 때만 확인하세요.

5. 내비게이션을 확인해요.

   페이지로 연결되는 내비게이션 메뉴 요소를 쓰고 있다면, 순서를 바꾼 뒤에도 메뉴의 순서와 이동 위치가 맞는지 확인하세요.

{% hint style="warning" %}
순서를 바꿔도 바뀌는 것은 페이지 순서일 뿐 URL은 그대로예요. 앞서 정한 URL 경로는 따로 편집하지 않는 한 유지돼요. 그래서 기존 링크와 SEO는 지키면서 방문자 흐름만 다듬을 수 있어요.
{% endhint %}

## 페이지 패널에서 검색하기

**페이지** 패널의 **검색**은 페이지가 많은 퍼널이나 콘텐츠가 많은 웹사이트를 관리할 때 유용해요. 페이지 이름(대부분 URL 경로도)으로 원하는 페이지를 바로 찾을 수 있어서, 목록을 끝없이 넘길 필요가 없어요.

1. **페이지** 패널을 열어요.

   빌더에서 **페이지** 패널을 열어 페이지 목록을 확인해요.

2. **검색** 창을 찾아요.

   패널 맨 위에 있는 **검색** 입력란을 찾아요.

3. 검색어를 입력해요.

   페이지 이름의 일부(예: "가격", "웨비나", "감사")나 URL 경로의 키워드를 입력해요. 입력하는 대로 목록이 걸러져서 검색어와 맞는 페이지만 보여요.

4. 페이지를 선택해요.

   걸러진 목록에서 원하는 페이지를 클릭하면 캔버스가 그 페이지로 바뀌어요. 검색어를 지우면 전체 목록으로 돌아와요.

검색하기 좋게 페이지를 관리하는 방법이에요.

- 페이지를 만들 때 이름을 분명하고 일관되게 지어요. 예: "웨비나 – 등록", "웨비나 – 라이브룸", "웨비나 – 다시보기"
- 여러 고객 계정에서 같은 퍼널 패턴을 재사용한다면 표준 이름 규칙을 정해 두세요. 팀원 누구나 필요한 페이지를 빨리 찾을 수 있어요.

## 페이지 빌더에서 새 페이지 만들기 시작하기

이 기능은 퍼널·웹사이트 페이지 빌더에서 기본으로 켜져 있어서, 따로 켜는 토글이 없어요. 평소 워크플로우에 어떻게 넣어 쓰느냐가 중요해요.

1. 퍼널이나 웹사이트를 열거나 새로 만들어요.

   서브 계정에서 **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동해요. 기존 퍼널이나 웹사이트를 열거나 새로 만든 뒤(퍼널은 **새 퍼널 만들기**), 아무 단계나 페이지에서 **편집**을 클릭해 빌더를 열어요.

   ![사이트 메뉴에서 퍼널이나 웹사이트를 열어 빌더를 실행하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081948717/original/flLaoSPedMfm6DQqfoXYwyjCANrmXFB_UQ.png?1790537493)

2. 페이지 구조를 계획해요.

   필요한 페이지를 정해요. 예: 홈, 소개, 서비스, 가격, 블로그, 연락처 또는 옵트인, 세일즈 페이지, 주문 폼, 업셀, 감사 페이지. 목록을 미리 정리해 두면 한 번에 페이지를 만들기 쉬워요.

3. **페이지** 패널에서 필요한 페이지를 모두 만들어요.

   - **페이지** 패널을 열어요.
   - **새 페이지 추가**를 클릭하고, 계획한 페이지마다 **페이지 이름**과 URL 경로를 설정해요.
   - 필요한 페이지가 모두 생길 때까지 반복해요.

   ![페이지 패널에서 필요한 페이지를 차례로 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081948722/original/AhEASDXKJCXlARGN14Hq0WpNMd8AGSi_Sg.png?1790537511)

4. 드래그 앤 드롭으로 페이지 순서를 정리해요.

   **페이지** 패널이나 페이지 선택 팝오버에서 페이지를 끌어 올바른 순서로 놓아요. 확인 창이 나오면, 특히 웨비나 퍼널에서는 새 순서가 확실할 때만 확인하세요.

5. 디자인하면서 페이지를 빠르게 오가요.

   다음과 같은 작업을 할 때 페이지 선택 팝오버로 페이지 사이를 이동해요.

   - 여러 페이지로 연결되는 내비게이션 메뉴를 재사용할 때
   - 색상, 글꼴, 섹션 등 브랜딩을 일관되게 유지할 때
   - 헤더, 푸터 같은 공통 섹션이나 글로벌 섹션을 여러 페이지에 적용할 때

6. 큰 프로젝트에서는 검색을 사용해요.

   멤버십 퍼널, 웨비나 퍼널, 규모가 큰 웹사이트처럼 페이지가 많다면 **페이지** 패널의 **검색**으로 필요한 페이지로 바로 이동하세요.

7. 게시하고 전체 흐름을 테스트해요.

   디자인을 마친 뒤 옵트인에서 감사 페이지까지 같은 주요 흐름을 미리보기로 확인하고, 다음을 점검하세요.

   - 내비게이션 메뉴가 올바른 페이지로 연결되는지
   - 페이지 순서가 전환 경로와 맞는지
   - URL과 내부 링크(버튼, 메뉴, QR 코드)가 올바른 목적지로 연결되는지
