# 내비게이션 메뉴 개편: 메가 메뉴 지원

메가 메뉴를 쓰면 웹사이트에 더 많은 정보를 보기 좋게 정리해서 보여 줄 수 있어요. 메뉴 편집 화면도 새로 바뀌어서 꾸미기가 더 쉬워졌고, 방문자가 사이트를 이용하기도 한결 편해져요.

## 메가 메뉴란

메가 메뉴 지원

- 많은 정보를 정리해서 보여 주는 메가 메뉴를 쉽게 만들고 꾸밀 수 있어요.
- 이미지, 링크, 텍스트 같은 요소를 메가 메뉴에 넣고 직접 꾸밀 수 있어요.
- 방문자가 메뉴 항목에 마우스를 올리면 메가 메뉴가 나타나요. 그래서 끊김 없이 자연스럽게 사이트를 둘러볼 수 있어요.

새로운 스타일 편집기 설정

- 내비게이션 메뉴 편집기가 새로 바뀌었어요. 설정을 정리해서 보고 더 쉽게 꾸밀 수 있어요.

메가 메뉴 편집용 오버레이

- 메가 메뉴 편집 모드에서는 오버레이가 표시돼요. 주변이 어두워져 방해 요소가 줄고 편집에만 집중할 수 있어요.

## 메가 메뉴 사용 방법

1. 하이퍼클래스의 퍼널·웹사이트 빌더에서 왼쪽 사이드바로 이동해 **Elements**(요소)를 선택해요.
2. 새 내비게이션 메뉴 요소를 추가해요.
3. 오른쪽 사이드바 설정에서 개선된 스타일 편집기로 내비게이션 메뉴의 레이아웃과 스타일을 정해요.
4. **Add item**(항목 추가)을 클릭한 다음 **Mega Menu**(메가 메뉴)를 클릭하면 내비게이션 메뉴에 메가 메뉴가 추가돼요.
5. 이미지, 텍스트, 링크 같은 요소를 추가해서 메가 메뉴를 꾸며요.
6. 배경 색상, 글꼴, 간격 등을 조정해 웹사이트의 브랜딩과 스타일에 맞춰요.
7. 메가 메뉴 안의 요소를 끌어다 놓으면서 콘텐츠를 쉽게 정리해요.
8. 실시간 미리보기 기능으로 실제 웹사이트에서 메가 메뉴가 어떻게 보일지 확인해요. 게시하기 전에 모든 게 제자리에 있는지 점검할 수 있어요.
