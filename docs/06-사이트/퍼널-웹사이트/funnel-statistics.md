# 퍼널 통계에 접속하는 방법


#### **1단계:** 사이트(Site) 또는 퍼널로 이동하기


- 
왼쪽 사이드 네비게이션 메뉴에서 사이트(Sites) 메뉴로 이동하세요


- 
상단 네비게이션 리본에서 퍼널(Funnels) 또는 사이트(Sites)를 선택하세요


- 
분석하려는 퍼널 또는 사이트 옆의 점 3개를 클릭하고 편집(Edit)을 선택하세요

#### **2단계: **통계(Stats) 열기


- 
상단 보조 네비게이션 바에서 통계(Stats) 탭을 클릭하세요


- 
우측 상단의 기간 드롭다운을 사용해서 원하는 날짜 범위로 필터링할 수 있어요.

#### 
**3단계: **통계 분석하기


통계 테이블에는 다음과 같은 열이 표시돼요:


- 
Page(페이지): 퍼널 단계(Funnel Step) 또는 페이지


- 
Views(조회수) (All/Uniques): 전체 방문자 수와 순 방문자 수


- 
Opt-ins(옵트인) (Count/Rate): 제출 건수와 옵트인 비율


- 
Sales(판매) (Count/Rate/Value): 거래 건수, 전환율, 총매출


- 
Earnings/Page View(페이지뷰당 수익): 조회수 대비 수익

## **지표 상세 설명**


#### **페이지 조회수(Page Views)**


- **All(전체):** 전체 페이지 방문 횟수
  
- **Uniques(순 방문자):  **순 방문자 기준 페이지 조회수   


#### **옵트인 (폼 제출, 설문 제출, 2단계 주문 폼 제출)**


- **All(전체): **옵트인 건수


- **Rate(비율):** (옵트인 수 × 100) / (순 페이지 조회수) 


#### **판매(Sales)**


- **Count(건수):** 판매된 상품 수


- **Rate(비율):** (판매된 상품 수 × 100) / (순 페이지 조회수)
 
- **Value(금액): **판매된 상품의 총 금액


#### **페이지뷰당 수익(Earnings / Pageview)**


- **All(전체):**  (판매된 상품의 총 금액) / (페이지 조회수)

## 사이트 및 퍼널 분석


퍼널 내부의 통계(Stats) 탭이 페이지 단위의 성과 데이터를 보여준다면, 분석(Analytics) 대시보드는 모든 퍼널과 웹사이트(Website)를 아우르는 더 폭넓고 시각적인 개요를 제공해요. 인터랙티브 그래프, 비교 도구, 방문자 세분화 기능이 포함되어 있어서 트렌드를 파악하고 최적화 기회를 찾기가 더 쉬워져요.


이 통합 리포팅 화면을 확인하려면 사이트(Sites) > 분석(Analytics)으로 이동하세요.


자세한 내용은 [하이퍼클래스에서 사이트 및 퍼널 분석 사용하는 방법](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000003094-how-to-use-site-and-funnel-analytics-in-하이퍼클래스)을 참고해 주세요

## **자주 묻는 질문**


Q: 왜 제 통계가 Google Analytics 데이터와 일치하지 않나요?Google Analytics는 하이퍼클래스와 세션을 추적하는 방식이 달라요. 이탈 필터링, 광고 차단 프로그램, 또는 퍼널 외부 유입 경로 등으로 인해 차이가 발생할 수 있어요.


Q: 페이지 조회수를 기준으로 액션을 자동화할 수 있나요?네! 연락처(Contacts)가 특정 퍼널 페이지를 조회했을 때 워크플로우(Workflow)를 실행시킬 수 있어요. 자세한 내용은 [퍼널 및 웹사이트 조회 트리거](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000002027)를 참고해 주세요


Q: '옵트인(opt-in)'의 기준은 무엇인가요?폼 블록이 포함된 퍼널 단계에서 성공적으로 제출된 폼은 모두 옵트인으로 집계돼요.


**Q: 일부 퍼널 통계 메시지가 다른 언어로 표시되는 이유는 무엇인가요?**

퍼널 통계는 현지화된 유효성 검사, 오류, 성공 메시지를 지원해요. 이 메시지들은 가능한 경우 로케이션(Location)의 로케일 설정을 따라요. 적용 가능한 로케이션 로케일이 없는 경우, 하이퍼클래스는 사용자의 플랫폼 언어를 사용하며, 그마저도 없으면 기본 언어인 영어를 사용해요.
