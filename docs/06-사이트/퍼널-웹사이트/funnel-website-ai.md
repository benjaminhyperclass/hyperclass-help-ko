# 퍼널·웹사이트 AI로 페이지 만들고 다듬기 (Funnel & Website AI)

Funnel & Website AI는 퍼널과 웹사이트 페이지를 AI로 만들고 편집하는 기능이에요. 프롬프트, 안내형 입력, URL, 이미지로 페이지를 만들 수 있고, 대화하듯 요청해서 계속 다듬을 수 있어요.

기존 콘텐츠와 디자인을 수정하거나 새 섹션을 추가할 수 있어요. 페이지의 일부만 다시 생성할 수도 있고, 기본 빌더 컨트롤로 직접 손볼 수도 있어요. 처음 쓰는 분도 숙련자도 처음부터 다시 만들지 않고 페이지를 빠르게 만들고 개선할 수 있어요.

---

## Funnel & Website AI란?

하이퍼클래스의 AI 페이지 제작 기능이에요. 프롬프트, 안내형 입력, URL, 이미지를 바탕으로 퍼널·웹사이트 페이지를 만들어 줘요. 레이아웃, 문구, 비주얼, 페이지 구성을 빠르게 만들어 주고, 빌더 컨트롤로 직접 수정할 수도 있어요.

**사용할 수 있는 도구**

| 경로/기능 | 설명 |
| --- | --- |
| **지원** | 비즈니스 틈새 시장, 목표, 고객, 말투, 레이아웃 선호도 같은 입력과 프리셋의 안내를 받으며 페이지를 만들어요. |
| **빌드** | 원하는 내용을 직접 설명해서 AI에게 만들게 해요. 더 자유롭게 만들 수 있어요. |
| 채팅으로 편집 | 페이지 빌더 안에서 문구, 섹션, 레이아웃 아이디어, 디자인 방향을 실시간으로 바꿀 수 있어요. |
| **AI에게 문의** + **설정** 나란히 보기 | AI 도움과 빌더 컨트롤을 가까이 두어, 화면을 자주 오가지 않고 내용과 스타일을 다듬을 수 있어요. |
| 링크·이미지로 가져오기 | 공개 URL이나 참고 이미지에서 영감을 받아 페이지를 만들어요. |
| SEO 지원 | 페이지 제목, 설명, 콘텐츠 제안을 만들어 페이지 최적화를 도와줘요. |

---

## 주요 장점

아이디어에서 완성도 있는 페이지까지 더 빠르게 갈 수 있어요. 대화로 편집하면 바꾸지 않을 부분은 건드리지 않고 필요한 부분만 개선할 수 있어요.

- 빠른 페이지 제작: 처음부터 시작하지 않고도 페이지 구조, 문구, 비주얼, 레이아웃 방향을 만들 수 있어요.
- 안내형 또는 자유형 제작: **지원**의 구조화된 입력을 따르거나, **빌드**에서 원하는 내용을 직접 설명할 수 있어요.
- 세분화된 AI 수정: 섹션 또는 페이지 단위로 문구, 테마, 디자인을 수정할 수 있어요. 더 큰 변경이 필요하면 콘텐츠를 다시 생성할 수 있어요.
- 새 섹션 추가: 가격, 후기, FAQ 같은 섹션을 나머지 페이지를 다시 생성하지 않고 추가할 수 있어요.
- 빌더에서 계속 편집: AI가 적용한 색상과 타이포그래피도 기본 빌더 컨트롤로 계속 조정할 수 있어요.
- 백그라운드 생성: 브라우저를 닫거나 연결이 잠시 끊겨도 페이지 생성이 이어질 수 있어요.
- 참고 자료 기반 생성: 링크나 이미지로 시각적·구조적 방향을 알려 줄 수 있어요.
- SEO 지원: SEO 제안을 만들어 게시 전에 검토하고 다듬을 수 있어요.

## AI 제작 경로 선택: 지원 또는 빌드

Funnel & Website AI에는 퍼널 페이지를 만드는 주요 방법이 두 가지 있어요. 얼마나 안내를 받고 싶은지, 얼마나 직접 조절하고 싶은지에 따라 고르면 돼요. 처음에 맞는 경로를 고르면 더 알맞은 결과가 나오고 작업도 수월해요. 이 두 경로는 **AI에게 문의** 패널 안에 바로 나와요.

| 모드 | 이런 분께 맞아요 |
| --- | --- |
| **지원** | 안내형 입력으로 도움을 받으며 페이지를 구성하고 싶은 분 |
| **빌드** | 원하는 내용이 분명하고 직접 프롬프트를 입력하고 싶은 분 |

### 1. 지원

**지원**은 페이지를 생성하기 전에 하이퍼클래스가 구성을 도와주는 안내형 경로예요. 퍼널 페이지 이름, 비즈니스 틈새 시장, 페이지 목표, 타겟 고객, 제안 내용 같은 구조화된 입력을 바탕으로 더 알맞은 출발점을 만들어 줘요. 방향을 잡고 싶을 때, 빨리 시작하고 싶을 때, 자세한 프롬프트를 어떻게 쓸지 막막할 때 특히 도움이 돼요.

다음 항목을 입력할 수 있어요.

- 퍼널 페이지 이름
- **비즈니스 틈새 시장**
- 퍼널 페이지의 목표
- **타겟 고객**
- 제공하는 상품이나 서비스

입력을 마치면 바로 페이지를 생성하거나, 더 사용자 지정한 뒤 생성할 수 있어요.

![지원 경로의 안내형 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068214474/original/H2zQrvTrNAOPKiZBSWSvYiyHCbuh51Arbw.png?1775029087)

### 2. 빌드

**빌드**는 퍼널의 모습을 이미 분명하게 그리고 있는 분을 위한 자유형 경로예요. 안내 입력란 대신 요청을 직접 입력하면, AI가 그 지시에 따라 페이지를 기획하고 만들거나 수정해요. 더 자유롭게 만들고 싶거나, 염두에 둔 캠페인 구조가 있거나, 문구와 디자인 방향을 내 말로 설명하고 싶을 때 알맞아요.

**빌드**에는 더 빨리 시작할 수 있도록 추천 프롬프트도 있어요. 예를 들어 전환율 높은 퍼널 만들기, 임팩트 있게 문구 개선하기 같은 프롬프트예요.

![빌드 경로의 프롬프트 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068214751/original/jl4JD-3FexCFb8BEUXvgZhLzO2XYSRZ37g.png?1775029135)

## 채팅 모드와 나란히 편집하기

채팅으로 편집하면 요소를 하나하나 직접 다시 만들지 않고도 기존 페이지를 다듬을 수 있어요. 대화로 원하는 변경을 요청하고, AI 옆에서 기본 빌더 컨트롤도 그대로 쓸 수 있어요.

Funnel & Website AI에 요청할 수 있는 변경은 다음과 같아요.

- 문구 수정: 전체 디자인은 그대로 두고, 한 섹션 또는 페이지 전체의 메시지를 바꿔요.
- 테마 수정: 기존 콘텐츠는 유지한 채 시각적 테마를 조정해요.
- 리디자인: 다른 시각적 방향을 원할 때 특정 섹션이나 페이지 전체의 디자인을 바꿔요.
- 재생성: 더 큰 변경이 필요할 때 섹션이나 페이지의 새 버전을 만들어요.
- 새 섹션 추가: 가격표, 후기 섹션, FAQ 섹션 같은 새 콘텐츠를 나머지 페이지를 다시 생성하지 않고 추가해요.

AI가 적용한 색상과 타이포그래피는 기본 빌더 컨트롤로 계속 편집할 수 있어요. 채팅으로 바꾼 뒤 이 컨트롤로 최종 결과를 세밀하게 다듬어 보세요.

## 링크 또는 이미지로 가져오기

링크나 이미지로 가져오기를 쓰면 이미 있는 시각 자료에서 영감을 받아 페이지를 만들 수 있어요. 처음부터 시작하지 않고 스타일, 구조, 창의적인 방향을 가져오고 싶을 때 유용해요.

이 방법으로 할 수 있는 일은 다음과 같아요.

- 공개 웹페이지에서 영감 얻기
- 원하는 디자인 방향의 분위기 재현하기
- 이미지에 담긴 브랜드 스타일에 맞춰 만들기
- 원하는 룩이 이미 있을 때 아이디어 구상 속도 높이기

![링크 또는 이미지로 가져오기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068222195/original/6AiqWx9_gqqzwDhVDqAhG_IvvOJ44BTKRw.png?1775032573)

{% hint style="warning" %}
링크나 이미지로 가져오면 AI가 페이지를 생성할 때 참고할 자료가 될 뿐이에요. 원본 페이지를 똑같이 복제하지 않으며, 모든 디자인 요소, 레이아웃, 인터랙션, 콘텐츠가 그대로 재현된다고 보장하지도 않아요.
{% endhint %}

## AI SEO 제안

Funnel & Website AI는 페이지를 만들 때 제목, 설명, 콘텐츠 방향을 제안해서 SEO 작업을 빠르게 시작할 수 있게 도와줘요. 검색에 잘 보이도록 페이지를 준비할 때 더 탄탄한 출발점이 돼요.

그래도 AI가 만든 SEO 제안은 게시 전에 검토해야 해요. 페이지 목표, 브랜드 표현, 검색 의도에 따라 직접 다듬어야 할 수 있기 때문이에요.

AI 생성 후에 하면 좋은 작업은 다음과 같아요.

- 페이지 제목이 명확하고 내용과 맞는지 확인하기
- 검색 의도에 맞게 메타 설명 다듬기
- 제목(헤딩)이 페이지 목적과 맞는지 확인하기
- 브랜드 목소리가 드러나도록 페이지 문구 수정하기
- 게시 전에 필요한 사용자 지정 메타데이터 추가하기

![AI가 제안한 SEO 항목 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068222370/original/_tnew_AwdU0o81teGxdeHVlhVlDqf4lZLA.png?1775032685)

{% hint style="info" %}
AI가 만든 SEO 콘텐츠는 출발점일 뿐이에요. 게시 전에 페이지 제목, 설명, 제목(헤딩), 키워드, 페이지 문구가 정확한지, 검색 의도와 브랜드에 맞는지 검토하세요.
{% endhint %}

## Funnel & Website AI 사용 방법

처음에 설정을 잘 해 두면 첫 결과가 더 좋고, 나중에 고칠 부분도 줄어요. 알맞은 모드와 입력으로 시작하면 AI 결과가 더 적절하고 다듬기도 쉬워요.

1. 하이퍼클래스 서브 계정에서 **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동해요. **AI로 빌드하기**를 클릭하면 새 퍼널이나 웹사이트를 만들 수 있어요. 기존 웹사이트나 퍼널을 열어도 돼요.

   ![사이트 메뉴에서 AI로 빌드하기를 시작하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068222784/original/Ghr7x1RQlfjTMyo0XjXQlLH38rZirK3d_g.png?1775032966)
2. AI 제작 경로를 선택해요.

   AI 화면이 열리면 **지원** 또는 **빌드**로 첫 페이지를 만들어요. 빌더에 들어간 뒤에는 AI 채팅과 기본 빌더 컨트롤을 함께 쓰며 생성된 페이지를 다듬을 수 있어요.

   ![지원과 빌드 중 경로를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068224821/original/_-cLLM6lPyMDjQlFeK_9x2Ar53bWzNxZrg.png?1775033924)
3. **지원**을 골랐다면 퍼널 페이지 이름, **비즈니스 틈새 시장**, 페이지 목표, **타겟 고객**, 제안 내용을 입력해요.

   **빌드**를 골랐다면 페이지의 목적, 고객, 메시지, 원하는 스타일을 설명하는 프롬프트를 자세히 입력해요.

   ![지원 또는 빌드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068224868/original/T2HaGKnHAzr1IPmm2Fpa9JXKx9xH8Pctew.png?1775033947)
4. **AI에게 문의** 채팅과 빌더 설정으로 페이지를 다듬어요. 문구, 테마, 디자인 변경을 요청할 수 있어요. 섹션이나 페이지를 재생성하거나, 나머지 페이지를 다시 만들지 않고 새 섹션을 추가해 달라고 할 수도 있어요.

   콘텐츠, 색상, 타이포그래피, 이미지, 여백 등 지원되는 페이지 설정을 직접 조정하고 싶을 때는 기본 빌더 컨트롤을 계속 쓰세요.

   ![AI에게 문의 채팅과 빌더 설정으로 페이지를 다듬는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068224485/original/KXmqtrhEJnhchaQ_btT5-K9uM783fi700Q.png?1775033755)
5. 페이지의 SEO 항목을 검토하고, 게시하기 전에 마지막 수정을 마쳐요.

   ![SEO 항목을 검토하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068224668/original/AFeRYbwBJ0RYL9Q8jwJJn_hpDVECAQemmw.gif?1775033842)
6. 콘텐츠, 레이아웃, 설정이 준비되면 페이지를 게시해요.

   ![페이지를 게시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068225013/original/5wDENthA4zejrgj3bHeb2I1Ci5HeOLyRmg.png?1775034037)

## 알아 두세요

- AI가 만든 콘텐츠는 게시 전에 검토하세요: 생성된 문구, 주장, 연락처 정보, 제안 내용, 링크, 이미지 등 비즈니스 관련 정보가 정확한지 확인하세요.
- 참고 자료 기반 생성은 정확한 복제가 아니에요: 링크나 이미지는 창의적·구조적 방향만 알려 줄 뿐, 똑같이 재현된다고 보장하지 않아요.
- SEO 제안도 검토가 필요해요: AI가 만든 제목, 설명, 콘텐츠 제안은 타겟 고객, 검색 의도, 브랜드에 맞게 다듬어야 해요.
- 직접 편집을 이어갈 수 있어요: AI가 만든 페이지도 퍼널과 **웹사이트 빌더**의 기본 컨트롤로 계속 편집할 수 있어요.
- 현재 AI 사용 한도를 확인하세요: Funnel & Website AI는 현재 추가 AI 사용 요금 없이 쓸 수 있지만, 사용 한도가 적용돼요. 자세한 내용은 [AI 상품 가격 문서](../../13-AI-Employee/ai-product-pricing-update.md)를 참고하세요.

## 자주 묻는 질문

### **지원** 대신 **빌드**는 언제 쓰나요?
안내형 시작점이 필요하고 프리셋이나 구조화된 입력이 도움이 된다면 **지원**을 쓰세요. 만들고 싶은 페이지가 이미 분명하고 직접 설명하고 싶다면 **빌드**를 쓰세요.

### Funnel & Website AI로 기존 페이지도 편집할 수 있나요?
네. 기존 퍼널이나 웹사이트를 열어서 AI 도구로 다듬을 수 있어요.

### 링크나 이미지로 가져오는 것도 퍼널·웹사이트를 복제하는 것과 같은가요?
아니요. AI의 참고 자료 기반 제작은 영감을 바탕으로 한 생성으로 보는 것이 가장 알맞아요.

### AI가 페이지를 만든 뒤에도 직접 편집할 수 있나요?
네. AI는 제작 속도를 높여 주는 기능이고, 이후에도 채팅 편집과 기본 빌더 설정으로 페이지를 계속 다듬을 수 있어요.

### AI가 만든 SEO 콘텐츠만으로 충분한가요?
좋은 출발점이지만, 게시 전에 정확성, 검색 의도, 브랜드 목소리를 검토해야 해요. 하이퍼클래스에서는 메타데이터를 직접 수정할 수도 있어요.

### Funnel & Website AI를 쓰려면 디자인 경험이 필요한가요?
아니요. 레이아웃, 문구, 페이지 구조를 대신 만들어 주기 때문에 디자인 부담이 줄어드는 것이 이 도구의 큰 장점이에요.
