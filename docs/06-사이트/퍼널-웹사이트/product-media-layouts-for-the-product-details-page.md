# 상품 상세정보 페이지의 상품 미디어 레이아웃 설정

상품 이미지와 동영상, 갤러리가 **상품 상세정보** 페이지에 어떻게 보일지 정하는 방법을 안내해요. 캐러셀, 그리드, 세로 나열 레이아웃 중에서 고르고, 확대 방식과 키보드 단축키까지 설정할 수 있어요.

이 문서에서는 선택할 수 있는 레이아웃, 새로 추가된 키보드 탐색을 포함한 이미지 확대 설정, 하이퍼클래스 스토어에서 미디어 레이아웃을 설정하는 순서를 다뤄요.

## 상품 미디어 레이아웃이란

상품 미디어 레이아웃은 **상품 상세정보** 페이지에서 이미지와 동영상이 보이는 방식을 정해요. 스토어의 페이지 빌더에 있는 **상품 상세정보** 요소에서 설정하고, 기본 **상품 상세정보** 페이지와 직접 만든 **상품 상세정보** 페이지에 모두 적용돼요.

이미지 한 장만 보여 주는 단순한 방식부터 썸네일로 넘겨 보는 캐러셀까지, 레이아웃마다 상품 미디어를 보여 주는 방식이 달라요. 확대 설정과 키보드 단축키를 함께 쓰면 고객이 구매 전에 상품을 더 다양하게 살펴볼 수 있어요.

{% hint style="info" %}
알맞은 미디어 레이아웃을 고르면 전환율을 높이는 데 도움이 돼요. 고객이 여러 각도에서 상품을 보고, 세부 모습을 확대하고, 마우스·터치·키보드로 이미지를 빠르게 넘겨 볼 수 있기 때문이에요.
{% endhint %}

## 선택할 수 있는 레이아웃

하이퍼클래스에서는 스토어 디자인과 판매하는 상품 종류에 맞춰 고를 수 있는 상품 미디어 레이아웃을 여러 개 제공해요. 레이아웃마다 이미지를 넘기는 방식과 보이는 모습이 달라요.

### **Carousel with Thumbnails**(썸네일이 있는 캐러셀)

큰 대표 이미지 아래나 옆에 썸네일 줄을 보여 줘요. 고객은 썸네일을 눌러 메인 이미지를 바꾸거나, 화살표 버튼으로 갤러리를 넘겨 볼 수 있어요. 여러 각도에서 찍은 사진이나 연출 컷이 많은 상품에 잘 어울려요.

### **Grid Gallery**(그리드 갤러리)

상품 이미지를 격자 형태로 한꺼번에 보여 줘요. 고객은 캐러셀을 넘기지 않고도 여러 이미지를 한눈에 볼 수 있어요. 이미지가 3~6장 정도여서 나란히 비교하는 것이 도움이 되는 상품에 알맞아요.

### **Stacked Vertical**(세로 나열)

이미지를 스크롤할 수 있는 세로 열로 배치해요. 고객은 아래로 스크롤하면서 이미지를 차례대로 볼 수 있어요. 모바일 기기에서 잘 맞고, 세부 컷이나 사용 설명 이미지가 많은 상품에도 알맞아요.

### **Single Image**(단일 이미지)

대표 상품 이미지 한 장을 보여 주고, 필요하면 확대 기능을 쓸 수 있어요. 단순한 상품, 디지털 상품, 대표 이미지 한 장이면 충분한 미니멀한 스토어 디자인에 알맞아요.

{% hint style="info" %}
계정에서 보이는 레이아웃 종류와 이름은 하이퍼클래스 버전과 테마에 따라 다를 수 있어요. 내 계정에서 쓸 수 있는 레이아웃은 스토어 빌더의 **상품 상세정보** 요소 설정에서 확인하세요.
{% endhint %}

## 이미지 확대 설정

**Image Zoom**(이미지 확대)은 고객이 상품 이미지를 더 자세히 보고 싶을 때 어떻게 반응할지 정하는 설정이에요. 어떤 상품 미디어 레이아웃을 쓰든 아래 세 가지 방식 중에서 고를 수 있어요.

### **Open Lightbox**(라이트박스 열기)

상품 이미지를 누르면 전체 화면 라이트박스가 열려요. 라이트박스에는 확대 컨트롤, 이동 화살표, 썸네일 줄이 함께 나와요. 가장 몰입감 있게 이미지를 볼 수 있는 방식이고, 키보드 단축키로 이미지를 더 빠르게 넘길 수 있어요.

추천 대상: 상품 사진 품질이 높은 스토어, 패션·주얼리·전자제품처럼 자세히 살펴볼수록 구매 확신이 커지는 상품

### **Click & Hover Zoom**(클릭·호버 확대)

이미지를 누르거나 마우스를 올리면 별도 창을 열지 않고 **상품 상세정보** 페이지 안에서 이미지가 확대돼요.

추천 대상: 확대 기능은 쓰고 싶지만 팝업 때문에 고객이 흐름을 잃지 않기를 바라는 스토어

### **No Zoom**(확대 없음)

상품 이미지가 기본 크기로만 표시되고 확대 기능은 없어요. 따로 설정하지 않으면 이미지를 눌러도 아무 동작이 없어요.

추천 대상: 디지털 상품, 서비스, 이미지가 단순해서 확대가 필요 없거나 오히려 구매 과정에 방해가 되는 스토어

{% hint style="info" %}
팁: 키보드 단축키(Escape, 방향키)를 지원하는 확대 방식은 **Open Lightbox** 하나뿐이에요. 키보드로 이미지를 넘겨 볼 수 있게 하려면 **Image Zoom**을 **Open Lightbox**로 선택하세요.
{% endhint %}

## Open Lightbox의 키보드 탐색

**Image Zoom**을 **Open Lightbox**로 설정하면 고객이 키보드 단축키로 상품 이미지를 더 빠르고 편하게 넘겨 볼 수 있어요. 데스크톱 사용자, 쇼핑을 자주 하는 고객, 접근성 때문에 키보드만 쓰는 고객에게 특히 유용해요.

{% hint style="info" %}
새 기능: 이제 라이트박스가 열린 상태에서 Escape 키와 방향키로 상품 이미지를 넘길 수 있어요. 이미지 탐색이 더 빠르고 접근하기 쉬워졌어요.
{% endhint %}

### 지원하는 키보드 단축키

고객이 상품 이미지를 눌러 **Open Lightbox**가 열리면 아래 키가 동작해요.

- Escape(Esc): 라이트박스를 닫고 **상품 상세정보** 페이지로 돌아가요.
- 오른쪽 방향키(→): 상품 갤러리의 다음 이미지로 이동해요.
- 왼쪽 방향키(←): 상품 갤러리의 이전 이미지로 이동해요.

### 키보드 탐색이 동작하는 방식

#### 열리면 자동으로 포커스

라이트박스가 열리면 키보드 포커스가 자동으로 라이트박스에 맞춰져요. 고객은 라이트박스 안을 먼저 클릭하지 않아도 바로 Escape 키나 방향키를 누를 수 있어요.

#### 처음과 끝이 이어지는 순환 이동

마지막 이미지에서 오른쪽 방향키를 누르면 첫 번째 이미지로, 첫 번째 이미지에서 왼쪽 방향키를 누르면 마지막 이미지로 이동해요. 끝에서 막히거나 방향을 직접 되돌릴 필요 없이 모든 이미지를 계속 둘러볼 수 있어요.

#### 페이지 스크롤 방지

라이트박스가 열려 있는 동안에는 방향키를 눌러도 뒤에 있는 페이지가 스크롤되지 않아요. 키보드 입력은 모두 이미지 갤러리를 조작하는 데만 쓰여서, 실수로 페이지가 움직이지 않고 상품 보기에 집중할 수 있어요.

#### 썸네일 줄 동기화

방향키로 이미지를 넘기면 썸네일 줄도 자동으로 스크롤되어 현재 이미지의 썸네일이 항상 보여요. 지금 보고 있는 이미지는 썸네일 줄에서 강조 표시되어, 갤러리에서 몇 번째 이미지인지 한눈에 알 수 있어요.

### 마우스와 터치 동작 (변경 없음)

키보드 단축키는 기존 라이트박스 컨트롤에 더해진 기능이에요. 익숙한 마우스·터치 동작은 그대로 사용할 수 있어요.

- 화살표 버튼을 누르면 이미지 사이를 이동해요.
- 썸네일을 누르면 해당 이미지로 바로 이동해요.
- 닫기 아이콘을 누르면 라이트박스가 닫혀요.
- 확대·축소와 초기화 컨트롤도 그대로 쓸 수 있어요.
- 그리드 또는 보기 전환 컨트롤도 그대로예요.

{% hint style="info" %}
키보드 탐색은 키보드만 쓰는 고객을 지원하고, 접근성 모범 사례를 따르는 데 도움이 돼요. 마우스 클릭보다 키보드 단축키를 선호하는 사용자에게는 더 빠른 탐색 경험도 제공해요.
{% endhint %}

## 상품 미디어 레이아웃 설정하기

상품 미디어 레이아웃과 **Image Zoom** 설정은 스토어 페이지 빌더의 **상품 상세정보** 요소에서 해요. 아래 순서대로 원하는 레이아웃을 고르고 키보드 탐색을 켜 보세요.

1. 하이퍼클래스 계정에서 **사이트 > 스토어**로 이동해요. 설정하려는 **상품 상세정보** 페이지가 있는 스토어를 선택하세요.

   ![스토어 목록에서 스토어를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077298088/original/phXZraMlFGn-Cqmx6MIZvkl7nj9_du3fRw.png?1785477655)

2. 스토어의 페이지 목록에서 **상품 상세정보 페이지**를 눌러 편집해요. 직접 만든 상품 상세정보 페이지를 설정하려면 그 페이지를 누르세요. 페이지 빌더 편집기가 열려요.

   ![페이지 목록에서 상품 상세정보 페이지를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077298147/original/lZOVeB-bPCdPKjYg4YTAOsIQNqP3fFhr-Q.png?1785477760)

3. 상품 이미지와 정보가 표시되는 **상품 상세정보** 또는 **상품** 요소를 눌러요. 이 요소에서 페이지의 미디어 레이아웃과 확대 설정을 모두 정해요.

4. 요소 설정 패널(보통 빌더 오른쪽)에서 **Product Media Layout**(상품 미디어 레이아웃) 또는 **Desktop Media**(데스크톱 미디어) 섹션을 찾아요. 선택할 수 있는 레이아웃(예: **Carousel with Thumbnails**, **Grid Gallery**, **Stacked Vertical**, **Single Image**) 중에서 원하는 것을 고르세요.

   ![설정 패널에서 상품 미디어 레이아웃을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077298172/original/9mzQLjJ3bchK9bGl434PERKeOD8fe6i-gg.png?1785477782)

5. 설정 패널에서 **Image Zoom** 드롭다운을 찾아 **Open Lightbox**, **Click & Hover Zoom**, **No Zoom** 중에서 골라요. 키보드 탐색 단축키를 쓰려면 **Open Lightbox**를 선택하세요.

   ![Image Zoom 드롭다운에서 확대 방식을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077298190/original/ZRFI8vs4kwDPqVvlNvj1P-V5POCG68-dAw.png?1785477807)

6. 페이지 빌더에서 **저장**을 누른 다음 **게시**를 눌러 변경 사항을 실제 스토어에 반영해요. 새 미디어 레이아웃과 확대 설정이 해당 **상품 상세정보** 페이지의 모든 상품에 적용돼요.

   ![저장과 게시 버튼으로 변경 사항을 반영하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077298208/original/K8oLEiEUOqX4QVJFpzwetdFJ40cJ-RSmiw.png?1785477834)

7. (선택) 키보드 탐색을 확인해 봐요. **Builder Preview**(빌더 미리보기)를 열거나 실제 스토어의 상품 페이지에 들어가세요. 상품 이미지를 눌러 라이트박스를 열고 아래 단축키를 시험해 보세요.

   - 오른쪽 방향키와 왼쪽 방향키를 눌러 이미지 사이를 이동해요.
   - Escape 키를 눌러 라이트박스를 닫아요.
   - 라이트박스가 열려 있는 동안 방향키로 페이지가 스크롤되지 않는지 확인해요.

   ![라이트박스에서 키보드 단축키를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077298228/original/qog62wFZb1m0TLh_MKlGynEtsTbseZlnNA.png?1785477861)

{% hint style="warning" %}
키보드 단축키는 **Image Zoom**이 **Open Lightbox**일 때만 동작해요. **Click & Hover Zoom**이나 **No Zoom**을 고르면 전체 화면 라이트박스가 열리지 않기 때문에 라이트박스 탐색 단축키를 쓸 수 없어요.
{% endhint %}

## 상품 미디어 활용 팁

상품 미디어 레이아웃과 확대 설정을 잘 맞춰 두면 고객 경험이 좋아지고, 전환율이 오르고, 상품 반품이 줄어들어요. 아래 내용을 참고해 상품 이미지를 더 잘 활용해 보세요.

- 고해상도 이미지를 쓰세요. 확대해도 픽셀이 깨지지 않을 만큼 큰 이미지를 올려요. 패션·전자제품·주얼리처럼 세부 모습이 중요한 상품은 긴 변을 1,200~1,500픽셀 이상으로 맞추는 것이 좋아요.
- 여러 각도의 사진을 보여 주세요. 앞면, 뒷면, 옆면, 세부 컷을 넣으면 고객이 상품을 꼼꼼히 살펴볼 수 있어요. 이미지가 많을수록 구매 확신이 커지고 "어떻게 생겼나요?" 같은 문의가 줄어요.
- 파일 크기를 최적화하세요. 이미지를 압축해서 화질과 로딩 속도의 균형을 맞춰요. 파일이 크면 페이지 속도가 느려져 전환율에 좋지 않아요. 모바일 기기에서는 특히 그래요.
- 설명이 담긴 대체 텍스트를 쓰세요. 모든 상품 이미지에 이미지 내용을 알려 주는 대체 텍스트를 넣어요. 접근성과 SEO에 좋고, 스크린 리더와 검색 엔진이 이미지가 무엇을 보여 주는지 이해하는 데 도움이 돼요.
