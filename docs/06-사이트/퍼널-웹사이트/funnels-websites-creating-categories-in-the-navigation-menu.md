# 내비게이션 메뉴에 드롭다운 카테고리 만들기

웹사이트나 퍼널의 내비게이션 메뉴에서 메뉴 항목을 상위 항목 아래에 넣어 드롭다운 카테고리를 만드는 방법을 안내해요. 메뉴가 깔끔하게 정리되고, 방문자도 원하는 페이지를 더 쉽게 찾을 수 있어요.

---

## 내비게이션 메뉴 카테고리란?

내비게이션 메뉴 카테고리는 관련 있는 링크를 상위 메뉴 항목 아래에 묶어 두고, 방문자가 드롭다운으로 열어 볼 수 있게 하는 구조예요. 같은 주제의 페이지가 여러 개일 때 모두 최상위 메뉴에 놓으면 메뉴가 복잡해지는데, 이럴 때 유용해요.

내비게이션 카테고리는 다음으로 구성돼요.

- 상위 항목: 드롭다운을 담고 있는 최상위 메뉴 항목이에요.
- 하위 항목: 상위 항목 아래에 들어가는 메뉴 항목이에요.
- 드롭다운 메뉴: 방문자가 상위 항목에 마우스를 올리거나 누르면 보이는 메뉴예요.

예를 들어 "서비스"를 상위 항목으로 두고, 그 아래에 "컨설팅", "코칭", "교육"을 하위 항목으로 넣을 수 있어요.

기본 내비게이션 메뉴는 하위 항목을 한 단계까지만 넣을 수 있어요.

---

## 카테고리의 장점

관련 링크를 드롭다운 카테고리로 묶으면 방문자가 사이트 구조를 이해하기 쉽고 화면도 덜 복잡해 보여요. 웹사이트나 퍼널에 관련 있는 이동 경로가 여러 개 있을 때 특히 도움이 돼요.

- 깔끔한 내비게이션: 관련 링크를 하위로 묶어 메인 메뉴 바를 정돈해요.
- 사용성 향상: 방문자가 묶여 있는 페이지를 빠르고 직관적으로 찾아요.
- 간편한 드래그 앤 드롭: 코드 없이 드롭다운 메뉴를 만들 수 있어요.
- 유연한 구조: 항목을 끌어서 카테고리 순서를 바꾸거나 수정해요.
- 반응형 지원: 데스크톱과 모바일 레이아웃에 맞게 메뉴가 바뀌어요.

---

## 카테고리가 동작하는 방식

내비게이션 카테고리는 상위-하위 관계로 어떤 항목이 최상위에 보이고 어떤 항목이 드롭다운 안에 들어갈지 정해요. 이 구조를 이해하고 나면 페이지를 게시하기 전에 메뉴를 알맞게 정리하기 쉬워요.

기본 내비게이션 메뉴에는 다음을 넣을 수 있어요.

- 최상위 메뉴 항목
- 드롭다운을 포함한 상위 항목
- 같은 상위 항목 아래의 여러 하위 항목
- 한 단계로 중첩된 하위 항목

메뉴 항목을 다른 항목 아래에 넣으면 하이퍼클래스가 그 항목을 해당 상위 항목의 드롭다운 메뉴에 표시해요.

**Add Sub Item**(하위 항목 추가) 옵션으로 하위 항목을 만들 수 있어요. 이미 있는 메뉴 항목을 드래그해서 들여쓰기하는 방법으로 정리해도 돼요.

{% hint style="info" %}
기본 내비게이션 메뉴의 드롭다운은 중첩을 한 단계까지만 지원해요. 더 크고 시각적인 내비게이션 구조가 필요하면 메가 메뉴(Mega Menu)를 사용해 보세요.
{% endhint %}

## 내비게이션 메뉴에서 카테고리 만들기

먼저 상위 항목을 정한 다음, 관련 메뉴 항목을 그 아래에 추가하거나 옮겨 넣어요. 계층을 올바르게 만들어 두면 방문자가 의도한 드롭다운 구조로 메뉴를 볼 수 있어요.

1. 빌더에서 퍼널 또는 웹사이트를 엽니다.
2. 레이아웃에서 **Navigation Menu**(내비게이션 메뉴) 요소를 선택합니다.

   ![내비게이션 메뉴 요소 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050091978/original/f97PmFrGYYKhDEy_PFu2n_EU1o2yH6P2pQ.png?1752860966)
3. 오른쪽 패널에서 **항목 추가 > New Menu Item**(새 메뉴 항목)을 클릭합니다.

   ![항목 추가에서 새 메뉴 항목을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050091935/original/tB7qSTdcg8RCz0FfRbdRau_LfxdReoI78g.png?1752860887)
4. 항목 이름을 알아보기 쉽게 입력합니다.
5. 새 항목을 상위 항목(예: "홈") 아래로 끌어다 놓습니다. 항목이 살짝 들여쓰기되면 하위 항목으로 들어간 거예요. 이 항목은 드롭다운으로 표시돼요.

   ![메뉴 항목을 상위 항목 아래로 끌어 들여쓰기한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050092023/original/vqRAKvDU-o5f-NvmmZIFg7lOX5kgqK_nZg.png?1752861022)
6. **저장**을 클릭한 다음 **미리보기**를 열고, 상위 항목에 마우스를 올려 드롭다운이 나타나는지 확인합니다.

---

## 메뉴 항목 미리 보고 정리하기

메뉴를 점검할 때는 다음을 확인하세요.

- 각 하위 항목이 알맞은 상위 항목 아래에 있는지 확인합니다.
- 각 메뉴 항목이 연결된 이동 경로를 확인합니다.
- 메뉴 항목을 끌어서 순서를 바꿉니다.
- 이름이 불분명하거나 너무 길면 이름을 바꿉니다.
- 더 이상 필요 없는 메뉴 항목은 제거합니다.
- 데스크톱과 모바일 레이아웃을 모두 미리 봅니다.
- 게시하기 전에 각 드롭다운을 테스트합니다.

---

## 자주 묻는 질문

### 드롭다운을 두 단계 이상 만들 수 있나요?
아니요. 특히 모바일에서도 쓰기 편한 내비게이션을 유지하려고 중첩 페이지를 한 단계까지만 지원해요.

### 메뉴 항목을 같은 페이지 안의 섹션에 연결할 수 있나요?
네. 앵커 링크를 사용하면 페이지 안의 섹션으로 스크롤해서 이동해요. 자세한 내용은 "Scroll to Elements or Sections in Websites or Funnels" 문서를 참고하세요.

### 항목을 제거하거나 이름을 바꾸려면 어떻게 하나요?
사이드바에서 해당 항목 옆의 점 3개 아이콘을 클릭하세요. 이름을 수정하거나 **삭제** 버튼을 눌러 항목을 삭제할 수 있어요.

### 퍼널과 웹사이트에서 이 방법이 같나요?
네. **Navigation Menu** 요소는 퍼널과 웹사이트에서 똑같이 동작해요.

### 카테고리 만드는 과정이 퍼널과 웹사이트에서 같나요?
네. 퍼널과 웹사이트는 내비게이션 메뉴를 설정할 때 같은 빌더 환경을 사용해요.
