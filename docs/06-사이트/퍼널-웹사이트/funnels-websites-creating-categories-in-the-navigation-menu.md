# 퍼널 & 웹사이트 | 네비게이션 메뉴에서 카테고리 만들기

이 아티클에서는 상위 메뉴 항목 아래에 하위 메뉴 항목을 중첩시켜서 웹사이트나 퍼널(Funnel)의 네비게이션 메뉴(Navigation Menu)에 드롭다운 카테고리를 만드는 방법을 안내해요. 이를 통해 네비게이션을 체계적으로 정리하고, 더 깔끔하고 직관적인 메뉴로 사용자 경험을 개선할 수 있어요.

---

## 네비게이션 메뉴의 카테고리란 무엇인가요?

네비게이션 메뉴에서 카테고리를 만든다는 것은 관련 있는 메뉴 항목들을 하나의 상위 항목 아래로 묶어서 드롭다운 메뉴를 구성하는 것을 의미해요. 이렇게 하면 네비게이션 구조를 더 명확하고 효율적으로 만들 수 있어요. 하이퍼클래스에서는 네비게이션 메뉴 요소(엘리먼트) 안에서 드래그 앤 드롭으로 간단히 들여쓰기를 하는 방식으로 이 작업을 할 수 있어요.

---

## 네비게이션 메뉴 카테고리의 주요 장점

- **깔끔한 네비게이션**: 관련 링크를 하위 항목으로 중첩시켜 메인 네비게이션 바를 정리할 수 있어요
- **향상된 사용자 경험(UX)**: 사용자가 관련 페이지를 빠르고 직관적으로 찾을 수 있어요
- **드래그 앤 드롭의 간편함**: 코드 없이도 쉽게 드롭다운 메뉴를 만들 수 있어요
- **유연한 구조**: 항목을 드래그해서 카테고리를 재배치하거나 업데이트할 수 있어요
- **반응형 지원**: 메뉴가 데스크톱과 모바일 레이아웃에 맞게 자동으로 조정돼요

---

## 네비게이션 메뉴에서 카테고리 만드는 방법

드롭다운 메뉴(카테고리)를 만들려면 아래 단계를 따라주세요:

- 빌더(Builder)에서 퍼널이나 웹사이트를 열어주세요
- 레이아웃에서 네비게이션 메뉴 요소를 선택하세요

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050091978/original/f97PmFrGYYKhDEy_PFu2n_EU1o2yH6P2pQ.png?1752860966)

- 오른쪽 패널에서 **Add Item(항목 추가) → New Menu Item(새 메뉴 항목)**을 클릭하세요

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050091935/original/tB7qSTdcg8RCz0FfRbdRau_LfxdReoI78g.png?1752860887)

- 항목에 알아보기 쉬운 이름을 붙여주세요
- 새 항목을 상위 항목(예: "Home") 아래로 드래그 앤 드롭하세요. 항목이 살짝 들여쓰기가 되면 중첩된 것이며, 드롭다운 형태로 표시돼요

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050092023/original/vqRAKvDU-o5f-NvmmZIFg7lOX5kgqK_nZg.png?1752861022)

- **Save(저장)**를 클릭한 뒤 **Preview(미리보기)**로 상위 항목에 마우스를 올려보면 드롭다운이 나타나는 것을 확인할 수 있어요

---

## 메뉴 항목 미리보기 및 정리하기

- 네비게이션 메뉴를 미리보기해서 구조를 확인하세요
- 상위 항목(예: "Home")에 마우스를 올려 드롭다운 기능이 제대로 작동하는지 확인하세요
- 드래그 앤 드롭 인터페이스를 사용해 메뉴 항목의 순서를 바꾸거나 이름을 수정하세요
- 같은 상위 항목 아래에 여러 개의 항목을 중첩시킬 수 있어요

---

## 자주 묻는 질문

**Q: 드롭다운을 여러 단계로 만들 수 있나요?**
아니요. 특히 모바일에서 네비게이션이 사용하기 편하도록 유지하기 위해, 중첩 페이지는 한 단계로만 제한돼요.

**Q: 메뉴 항목이 같은 페이지 내의 특정 섹션(Section)으로 연결되게 할 수 있나요?**
네, 가능해요. 앵커 링크(Anchor Link)를 사용해서 특정 섹션으로 스크롤하도록 설정할 수 있어요. 자세한 내용은 [웹사이트나 퍼널에서 요소나 섹션으로 스크롤하기](https://help.gohighlevel.com/en/support/solutions/articles/48001158589) 문서를 참고하세요.

**Q: 항목을 삭제하거나 이름을 변경하려면 어떻게 하나요?**
사이드바에서 해당 항목 옆의 점 3개 아이콘을 클릭하세요. 이름을 수정하거나 **Delete(삭제)** 버튼을 눌러 삭제할 수 있어요.

**Q: 이 과정은 퍼널과 웹사이트에서 동일한가요?**
네, 네비게이션 메뉴 요소는 퍼널과 웹사이트 모두에서 동일하게 작동해요.
