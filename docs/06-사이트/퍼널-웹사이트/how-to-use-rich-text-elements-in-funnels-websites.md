# 퍼널·웹사이트에서 리치 텍스트 요소 사용하기

제목, 인용문, 코드 블록, 색상 강조, 여러 단계로 겹친 목록을 HTML 블록이나 외부 도구 없이 만들 수 있어요. 퍼널이나 웹사이트 페이지에 **리치 텍스트** 요소를 넣고, 빌더 안에서 워드 프로세서처럼 글을 꾸미는 방법을 안내해요.

## 리치 텍스트 요소란?

**리치 텍스트** 요소는 편집기 안에서 고급 서식을 바로 쓸 수 있는 요소예요. 텍스트 상자 하나에서 제목, 인용문, 인라인 코드, 여러 단계 목록, 강조 색상을 모두 쓸 수 있어요.

모든 기능이 요소 하나에 들어 있고, **단락** 요소와 같은 사이드바를 쓰기 때문에 더 빠르게 스타일을 지정할 수 있어요. 기본 **단락** 요소와 달리 텍스트 스타일을 자유롭게 바꾸고, 인용문을 넣고, 텍스트를 강조하고, 코드 블록을 넣을 수 있어요. 별도의 HTML이나 CSS는 필요 없어요.

## 리치 텍스트 요소의 주요 장점

- 쉬운 서식 지정: 단락, 제목, 스타일을 간단히 바꿀 수 있어요.
- 다양한 목록: 글머리 기호(원, 빈 원, 사각형)와 번호 형식(숫자, 알파벳, 로마 숫자)으로 내용을 정리할 수 있어요.
- 강조와 인용: 강조 색상과 인용문으로 중요한 내용을 눈에 띄게 할 수 있어요.
- 마크다운 방식 단축 입력: `>`, `` `code` ``, ` ``` `를 입력하면 인용문과 코드 블록이 자동으로 만들어져요.
- 코딩 불필요: 외부 도구나 HTML 블록이 필요 없어서 작업이 더 간편해요.
- 익숙한 사용법: 사이드바가 기존 **단락** 요소와 같아서 처음 써도 낯설지 않아요.

## 고급 서식 기능

**리치 텍스트** 요소에서 쓸 수 있는 서식 기능을 소개해요.

### 단락과 제목 전환하기

플로팅 툴바에서 텍스트를 단락에서 제목(H1~H6)으로 바로 바꿀 수 있어요.

1. **리치 텍스트** 요소에서 바꿀 텍스트를 드래그해 선택하세요.
2. **단락** 드롭다운을 클릭하세요.
3. 목록에서 원하는 제목 스타일을 선택하세요.

![단락 드롭다운에서 제목 스타일을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050692767/original/YpE5Nj6LcxJumaDYcYj3C67JqP58IdQMdQ.png?1753906571)

### 인용문 만들기

중요한 인용구나 고객 후기를 눈에 띄게 보여 줄 수 있어요.

1. **리치 텍스트** 요소 안에 **꺾쇠 기호(>)** 를 입력하세요.
2. **Enter** 키를 눌러 인용문을 만드세요.
3. 인용문에 내용을 입력하세요.

![리치 텍스트 요소 안에 만든 인용문](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050693065/original/THdKO-sNXsXv2tY5EXePx_4mKuB_VPihqA.png?1753907220)

### 인라인 코드

본문 안에 짧은 코드를 보여 줄 수 있어요.

- **리치 텍스트** 요소에서 코드로 표시할 텍스트를 **백틱 하나(`)** 로 감싸세요.

![본문 안에 표시된 인라인 코드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050693292/original/uVP3xWMcCWsHtWmo27qoF3Cb-p9RO5UCRQ.png?1753907762)

### 전체 코드 블록

긴 코드를 블록으로 보여 줄 수 있어요.

1. **리치 텍스트** 요소 안에 **백틱 세 개(```)** 를 입력하세요.
2. **Enter** 키를 눌러 전체 코드 블록을 만드세요.
3. 코드 블록에 내용을 입력하세요.

![리치 텍스트 요소 안에 만든 전체 코드 블록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050693393/original/J21l1gxYDkr462mjelXdZPouVgDFYxu-2w.png?1753907980)

### 고급 목록과 중첩 목록

여러 가지 목록 유형으로 내용을 보기 좋게 정리할 수 있어요.

1. **리치 텍스트** 요소에서 목록을 만드는 방법은 두 가지예요.

   - **별표(\*)** 를 입력한 뒤 스페이스바를 누르세요.
   - 텍스트를 선택한 뒤 플로팅 툴바에서 **Unordered List**(글머리 기호 목록) 또는 **번호 목록**을 클릭하세요.
2. 글머리 기호 옆 드롭다운을 클릭해 목록 유형을 선택하세요.

   - 글머리 기호 목록에서 고를 수 있는 유형은 다음과 같아요.

     - • (원)
     - ○ (빈 원)
     - ■ (사각형)
   - 번호 목록에서 고를 수 있는 유형은 다음과 같아요.

     - 1 2 3 (숫자)
     - a b c (소문자 알파벳)
     - A B C (대문자 알파벳)
     - i ii iii (소문자 로마 숫자)
     - I II III (대문자 로마 숫자)
3. Tab 키를 누르면 들여쓰기(중첩 단계 만들기)가 되고, Shift + Tab 키를 누르면 내어쓰기가 돼요.

![중첩 목록을 만든 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050693816/original/F7dJYAquvx0g7CuiAHzqMT8jNEW3rhippg.png?1753909108)

### 배경 색상으로 텍스트 강조하기

핵심 문구나 요점에 시선을 끌 수 있어요.

- **리치 텍스트** 요소에서 강조할 텍스트를 선택하세요.
- 플로팅 툴바의 **Color Picker**(색상 선택기) 아이콘을 클릭하고 강조 색상을 고르세요.

![색상 선택기로 텍스트를 강조하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050693562/original/cI3rZZ7beCE6CXa4kWLKEH0Zk1g60fjTMg.png?1753908312)

## 사이드바 스타일 옵션

**단락** 블록에서 조정할 수 있는 글꼴, 크기, 줄 간격, 그림자, 애니메이션을 여기서도 똑같이 쓸 수 있어요. 그래서 **리치 텍스트** 요소도 브랜드 스타일에 맞게 꾸밀 수 있어요.

- **타이포그래피**: 글꼴 패밀리, 굵기, 크기, 줄 간격을 정해요.
- **간격**: 데스크톱, 태블릿, 모바일별로 바깥 여백(margin)과 안쪽 여백(padding)을 조정해요.
- **효과**: 그림자나 등장 애니메이션을 추가해요.
- **공개 범위**: 특정 기기에서 요소를 표시하거나 숨겨요.
- **고급**: 테마 전체 설정을 덮어쓰고 싶을 때 사용자 지정 CSS 클래스를 적용해요.

### 목록 항목 간격 (리치 텍스트 및 글머리 기호 목록)

**List Item Spacing**(목록 항목 간격)은 목록 항목 사이의 세로 간격을 조절해요. 텍스트의 줄 간격과는 별개로 적용돼요. 이 값을 조정하면 긴 목록이 더 읽기 쉬워지고, 기기마다 알맞은 간격을 유지할 수 있어요.

주요 장점은 다음과 같아요.

- 가독성: 빽빽한 목록이 덜 답답해 보여요.
- 모바일 편의: 작은 화면에서도 여유 있게 보여요.
- 정밀한 조정: 단락의 줄 간격은 그대로 두고 항목 간격만 세밀하게 맞출 수 있어요.

**작동 방식**

1. 페이지에서 **리치 텍스트** 요소 또는 **Bullet List**(글머리 기호 목록) 요소를 선택하세요.
2. **스타일** 패널을 열고 **줄 간격** 옆에 있는 **List Item Spacing**을 찾으세요.
3. 슬라이더를 끌거나 값을 입력해서 목록 항목 사이 간격을 늘리거나 줄이세요.

{% hint style="info" %}
목록 항목 안에서 단락 간격을 조절할 때는 **줄 간격**을, 항목과 항목 사이의 간격을 조절할 때는 **List Item Spacing**을 사용하세요.
{% endhint %}

지원하는 요소: **리치 텍스트**, **Bullet List**

## 리치 텍스트 요소 추가하기

아래 세 단계를 따라 캔버스에 요소를 추가하고 바로 입력해 보세요.

1. 해당 페이지의 퍼널 또는 웹사이트 빌더를 여세요.
2. 왼쪽 패널에서 **Quick Add**(빠른 추가) > **리치 텍스트**를 클릭하세요.
3. 요소를 원하는 행이나 열로 끌어다 놓고, 한 번 클릭해서 편집을 시작하세요.

![빠른 추가에서 리치 텍스트 요소를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050693872/original/gbvm5Bsc0PBLnbFzPQPGvNNNCDY8t5_R8Q.png?1753909297)

## 자주 묻는 질문

### 기존 단락 요소를 리치 텍스트로 바꿀 수 있나요?
아니요. 제목과 단락을 서로 전환하려면 처음부터 **리치 텍스트** 요소여야 해요.

### 중첩 목록은 어떻게 만드나요?
먼저 기본 목록 항목을 만든 뒤 Tab 키를 누르거나 들여쓰기 옵션을 사용하면 하위 항목이 만들어져요.

### 단락을 쓸 때 리치 텍스트 요소와 단락 요소를 번갈아 써도 되나요?
네, 쓸 수 있어요. 다만 **리치 텍스트** 요소에는 기본 **단락** 요소에 없는 고급 서식 도구가 있어요.

### 전체 글꼴과 색상이 자동으로 적용되나요?
네. 요소가 전체 테마 설정을 그대로 따라요.
