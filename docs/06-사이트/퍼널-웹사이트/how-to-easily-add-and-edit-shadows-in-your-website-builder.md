# 퍼널·웹사이트 빌더에서 그림자 추가하고 편집하기

퍼널·웹사이트 빌더 편집기에서 요소에 박스 그림자와 텍스트 그림자를 넣는 방법을 안내해요. 그림자를 넣으면 요소에 깊이감이 생겨서 퍼널과 웹사이트를 더 입체적으로 꾸밀 수 있어요.

## 새로 생긴 기능

### 박스 그림자와 텍스트 그림자 추가

- 다양한 그림자 옵션: 텍스트, 제목, 단락, 이미지, 버튼 등 모든 요소에 박스 그림자를 넣을 수 있어요. 텍스트 그림자는 텍스트 기반 요소에 넣을 수 있고, 글자에 깊이감과 입체감을 더해요.
- 세부 맞춤 설정: **고급 설정** 탭에서 그림자 설정을 열고, 디자인에 맞게 그림자를 조정해요.

### 쉬운 그림자 편집기

- 두 가지 영역: 드롭다운에서 **Box Shadow**(박스 그림자)와 **Text Shadow**(텍스트 그림자) 중 원하는 영역을 골라요.
- 기본 설정으로 간편하게 적용: 플러스(+) 버튼을 누르면 미리 정해진 값의 기본 바깥쪽 그림자가 적용돼요. 이후 **추가 맞춤 설정**에서 세부 값을 조정할 수 있어요.
- 여러 개의 그림자: 플러스(+) 버튼을 눌러 한 요소에 그림자를 여러 개 겹쳐서 더 복잡한 디자인을 만들 수 있어요.
- 세부 편집: 그림자마다 **Outer**(바깥쪽)인지 **Inner**(안쪽)인지 고르고, **X Value**(X 값), **Y Value**(Y 값), **Blur**(흐림), **Spread**(확산), **Color**(색상)를 조정해요.

### 그림자 설정 항목

- **Outer**(바깥쪽) / **Inner**(안쪽): 바깥쪽 그림자는 요소가 배경 위로 떠 있는 듯한 높이감과 깊이감을 줘요. 안쪽 그림자는 요소 안쪽이 움푹 들어간 듯한 효과를 줘요.
- **X Value**(X 값): 그림자가 가로 방향으로 떨어지는 거리를 정해요.
- **Y Value**(Y 값): 그림자가 세로 방향으로 떨어지는 거리를 정해요.
- **Blur**(흐림): 그림자 가장자리가 얼마나 선명하거나 부드러울지 정해요.
- **Spread**(확산): 그림자 크기를 넓히거나 줄여요.
- **Color**(색상): 디자인 색상에 맞춰 그림자 색을 골라요.

## 사용 방법

1. 퍼널 또는 웹사이트 빌더 편집기를 열고 **고급 설정** 탭으로 이동해요.
2. 맨 위의 **Shadow**(그림자) 제목을 클릭해 그림자 편집기 드롭다운을 펼쳐요.
3. 박스 그림자와 텍스트 그림자 중 하나를 골라요. 각 제목 옆의 플러스(+) 버튼을 누르면 돼요. 텍스트 그림자는 텍스트 기반 요소에만 쓸 수 있어요.
4. 미리 정해진 값의 기본 바깥쪽 그림자가 적용돼요. 필요하면 값을 조정해요.
5. 한 요소에 그림자를 더 넣으려면 플러스(+) 버튼을 눌러 그림자를 추가해요.
6. 각 그림자의 제목을 클릭해 **Outer**(바깥쪽)/**Inner**(안쪽), **X Value**(X 값), **Y Value**(Y 값), **Blur**(흐림), **Spread**(확산), **Color**(색상)를 설정해요.
7. 그림자를 여러 방식으로 조합해 보면서 원하는 시각 효과를 찾아보세요.

그림자는 요소에 깊이감과 입체감을 더해 눈에 더 잘 띄게 해 줘요. 설정을 직접 조정할 수 있어서 퍼널과 웹사이트를 원하는 분위기로 꾸밀 수 있어요.
