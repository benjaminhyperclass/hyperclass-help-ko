# Stripe 문제 해결 | 퍼널(Funnel) 상품에 Stripe 플랜이 보이지 않을 때

Stripe • 퍼널 상품 • 문제 해결

Stripe 플랜이 퍼널 상품에 표시되지 않을 때: 문제 해결

Stripe 플랜을 지원되는 퍼널(Funnel) 결제 화면에서 선택하려면, 퍼널을 만들고 있는 하이퍼클래스 하위 계정(Sub-account) 안에 먼저 해당 상품이 등록되어 있어야 해요. Stripe 플랜이 보이지 않는다면 아직 가격(Price)이 가져오기(Import)되지 않았거나, 테스트(Test) 모드에 있거나, 이미 가져오기가 완료되었거나, 가져오기 대상이 아닐 수 있어요. 이 가이드에서는 현재 Stripe 상품 가져오기 워크플로우와 반복 결제(recurring) 가격이 보이지 않는 가장 흔한 원인을 설명해요.

이 문서에서 배울 내용

어떤 Stripe 가격을 가져올 수 있는지, 가져오기 대상 반복 결제 가격을 올바른 하위 계정으로 가져오는 방법, SaaS V1과 SaaS V2의 차이점, 그리고 퍼널 상품(Funnel Products)에서 Stripe 플랜이 보이지 않을 때 문제를 해결하는 방법을 알아봐요.

중요

**Import From Stripe(Stripe에서 가져오기)** 워크플로우는 가져오기 대상이 되는 반복(recurring) 또는 구독(subscription) 가격에 적용돼요. 일회성(one-time) 가격과 사용량 기반(metered) 반복 가격은 이 반복 가격 가져오기 워크플로우로 가져올 수 없어요. SaaS V1 퍼널 판매의 경우, 판매용 하위 계정이 에이전시(Agency)에서 사용하는 것과 동일한 Stripe 계정에 연결되어 있는지도 함께 확인해야 해요.

# 퍼널 상품을 위한 Stripe 플랜 가져오기란?

Stripe 플랜을 가져오면 선택한 하위 계정 안에 해당 하이퍼클래스 상품과 반복 결제 가격이 생성되어, 퍼널 주문서(order form)와 같이 지원되는 결제 환경에서 그 상품을 사용할 수 있게 돼요.

상품이 Stripe에 존재한다고 해서 자동으로 퍼널에서 선택 가능한 상태가 되는 건 아니에요. 가져오기 대상이 되는 반복 결제 가격을 먼저 퍼널을 구성하고 있는 동일한 하이퍼클래스 하위 계정으로 가져와야 해요.

SaaS V1의 경우, 에이전시가 Stripe 기반 SaaS 플랜을 만든 다음 퍼널이나 지원되는 결제 플로우에 추가하기 전에, 해당 SaaS 상품을 에이전시 소유의 판매용 하위 계정으로 가져올 때도 이 워크플로우가 사용돼요.

2

## Stripe 상품 가져오기의 주요 장점

가져오기 대상인 Stripe 가격을 가져오면, 선택한 하위 계정 안에서 지원되는 결제 환경에 해당 항목을 사용하는 데 필요한 상품 및 가격 정보가 하이퍼클래스에 제공돼요.

- **퍼널에서 사용 가능:** 가져온 상품과 반복 결제 가격은 지원되는 퍼널 주문서에서 선택할 수 있어요.
- **중앙 집중형 상품 관리:** 가져온 상품은 해당 하위 계정의 **Payments(결제) → Products(상품)** 메뉴에서 확인할 수 있어요.
- **반복 결제 지원:** 가져오기 대상인 Stripe 반복 결제 가격을 원래의 구독 상품을 수동으로 다시 만들 필요 없이 하이퍼클래스로 가져올 수 있어요.
- **SaaS V1 판매 지원:** SaaS V1 워크플로우를 사용하는 에이전시는 퍼널을 통해 판매하기 전에 Stripe 기반 SaaS 상품을 판매용 하위 계정으로 가져올 수 있어요.

3

## 사전 조건 및 제한 사항

퍼널 자체를 문제 해결하기 전에, Stripe 가격이 현재 가져오기 요건을 충족하는지 먼저 확인하세요. 가져오기 대상이 아닌 가격은 이 워크플로우를 통해 사용할 수 없어요.

| 요건 | 의미 |
|---|---|
| **반복/구독 가격** | Stripe 가격이 반복 구독 결제 방식을 사용해야 해요. |
| **라이브(Live) 모드** | 가격이 Stripe 라이브 모드에 존재해야 해요. 테스트 모드 가격은 라이브 가져오기 워크플로우의 대상이 아니에요. |
| **사용량 기반(metered) 아님** | 사용량 기반 반복 가격은 이 워크플로우로 가져올 수 없어요. |
| **이전에 가져온 적 없음** | 이미 가져오기가 완료된 Stripe 가격은 **Import From Stripe**에서 더 이상 선택 가능한 옵션으로 표시되지 않아요. |
| **올바른 하위 계정** | 퍼널에서 해당 상품을 판매할 동일한 하위 계정으로 가격을 가져와야 해요. |
| **SaaS V1 Stripe 연결** | SaaS V1의 판매용 하위 계정 패턴을 사용하는 경우, 에이전시와 판매용 하위 계정이 동일한 Stripe 계정을 사용해야 해요. |

**일회성 가격:** 일회성 Stripe 가격은 반복 가격 가져오기 워크플로우로 가져올 수 없어요. 대신 해당 일회성 상품 또는 가격을 하이퍼클래스에서 직접 만들어야 해요.

## SaaS V1 vs. SaaS V2: 어떤 상품 소스를 사용해야 할까요?

SaaS V1과 SaaS V2는 서로 다른 결제 아키텍처를 사용해요. 어떤 아키텍처가 상품을 관리하는지 파악하면 불필요한 Stripe 문제 해결 과정을 줄이고, 올바른 퍼널 상품 워크플로우를 사용할 수 있어요.

| 아키텍처 | 시스템 오브 레코드(System of Record) | 퍼널 상품 워크플로우 |
|---|---|---|
| **SaaS V1** | Stripe | 해당 Stripe SaaS 상품과 가격을 판매용 하위 계정으로 가져온 다음, 퍼널에서 선택하세요. |
| **SaaS V2** | 선택된 에이전시 하위 계정(Agency Sub-Account) | 선택된 에이전시 하위 계정의 **Payments → Products**에 SaaS 상품이 존재하는지 확인한 다음, 퍼널에서 바로 선택하세요. Stripe 가져오기는 V2 상품 소스 워크플로우가 아니에요. |

**SaaS V1 구독 동기화 참고사항:** 판매용 하위 계정을 통해 판매된 가져오기 대상 SaaS V1 구독은, 지원되는 업그레이드나 다운그레이드 이후 Stripe 구독과 판매용 하위 계정의 해당 구독을 서로 일치된 상태로 유지할 수 있어요. 다만 이는 최초의 Stripe 상품 가져오기 요건을 대체하지 않으며, 해당 요건을 충족하는 플랜 변경이 발생하지 않는 한 기존의 불일치 문제를 소급해서 고쳐주지는 않아요.

## 퍼널 상품을 위한 Stripe 플랜 가져오는 방법

퍼널을 구성하고 있는 동일한 하이퍼클래스 하위 계정으로 가져오기 대상 Stripe 가격을 가져오세요. 가져오기가 완료되면, 결제(Checkout)에 추가하기 전에 Payments(결제) 메뉴에서 상품이 등록되었는지 확인하세요.

- 상품을 판매할 하이퍼클래스 하위 계정을 여세요.
- 왼쪽 네비게이션 메뉴에서 **Payments(결제)**를 선택하세요.
- **Products(상품)**를 선택하세요.
- **Import From Stripe(Stripe에서 가져오기)**를 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130352/original/aXDWiozf0sJe8I-NJFYK5QjPwxdtN4M9pw.png?1789610903)

- 해당 Stripe 상품을 검색하세요.
- 사용 가능한 반복 결제 가격을 확인하세요.
- 가져오려는 가져오기 대상 상품과 가격을 선택하세요.
- 가져오기를 완료하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130354/original/O3i0h-3jl2uwUv2zOkJKgq3n7-3T9BguPw.png?1789610929)

- 가져온 상품이 **Payments → Products**에 표시되는지 확인하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130313/original/4b9YL8bLTIwpZd56txU9Obk5RVmniXU5YA.png?1789610776)

- 왼쪽 네비게이션 메뉴에서 **Sites(사이트)**를 선택하세요.
- **Funnels(퍼널)**를 선택하세요.
- 상품을 판매할 퍼널을 여세요.
- 해당 주문서(order form) 또는 상품 구성 화면을 여세요.
- 가져온 하이퍼클래스 상품과 반복 결제 가격을 선택하세요.
- 결제 구성을 테스트한 후 퍼널을 저장하고 발행하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130369/original/NMFxrBLVuXJrBYRQg3-YWG0J3SUs1R6TWQ.png?1789610960)

## 표시되지 않는 Stripe 플랜 문제 해결

설정을 변경하기 전에 상품이 어디서 누락되었는지부터 파악하세요. Stripe 가져오기 선택 목록에서 플랜이 보이지 않는 것과, 이미 가져오기는 되었지만 퍼널에 표시되지 않는 것은 원인이 서로 달라요.

| 문제 | 확인할 사항 |
|---|---|
| **가격이 이미 가져오기 완료됨** | 이미 가져오기가 완료된 Stripe 가격은 사용 가능한 **Import From Stripe** 선택 목록에서 제거돼요. 가져오기가 실패했다고 생각하기 전에 **Payments → Products**를 먼저 확인하세요. |
| **가격이 Stripe 테스트(Test) 모드 상태** | 가져오기 워크플로우는 가져오기 대상이 되는 라이브(Live) 모드 Stripe 가격이 필요해요. 테스트 모드 가격은 퍼널에서 사용되는 라이브 반복 결제 가격으로 표시되지 않아요. |
| **가격이 일회성(one-time)** | 일회성 Stripe 가격은 이 반복 가격 가져오기 워크플로우로 가져올 수 없어요. 해당 일회성 상품이나 가격을 하이퍼클래스에서 직접 만드세요. |
| **가격이 사용량 기반(metered)** | 사용량 기반 반복 가격은 Stripe 반복 가격 가져오기 워크플로우에서 지원되지 않아요. |
| **상품을 잘못된 하위 계정으로 가져오는 중** | 상품은 퍼널을 구성하고 있는 동일한 하위 계정의 **Payments → Products**에 존재해야 해요. |
| **SaaS V1 에이전시와 판매용 하위 계정이 서로 다른 Stripe 계정을 사용 중** | **Agency View(에이전시 뷰) → Settings(설정) → Stripe**에서 확인되는 Stripe 연결과, 판매용 하위 계정의 **Payments → Integrations(연동)**에서 확인되는 Stripe 연결을 비교해 보세요. 지원되는 V1 퍼널 워크플로우는 동일한 Stripe 계정을 전제로 해요. |
| **가격을 Stripe에서 직접 변경함** | Stripe 쪽에서 가격을 변경해도 해당 하이퍼클래스 상품이나 가격이 자동으로 업데이트되지 않아요. 지원되는 워크플로우에 따라 새로운 가져오기 대상 Stripe 가격을 새로운 하이퍼클래스 상품 또는 가격으로 가져오세요. |
| **SaaS Configurator(SaaS 구성기)에서 SaaS V1 상품을 만들었지만 판매용 하위 계정으로 가져오지 않음** | 에이전시에서 V1 SaaS 플랜을 만드는 것만으로는 해당 Stripe 상품이 판매용 하위 계정의 퍼널에서 자동으로 사용 가능해지지 않아요. 먼저 해당 Stripe 상품을 그 판매용 하위 계정으로 가져오세요. |
| **SaaS V2를 사용 중인 경우** | SaaS V2는 선택된 에이전시 하위 계정(Agency Sub-Account)을 시스템 오브 레코드로 사용해요. V1 Stripe 가져오기 경로를 문제 해결하는 대신, 해당 하위 계정에 상품이 존재하는지 확인하세요. |

**빠른 진단 방법:** **Payments → Products**에서는 상품이 보이지만 퍼널에서는 보이지 않는다면, 퍼널을 문제 해결하고 동일한 하위 계정에서 작업하고 있는지 확인하세요. **Import From Stripe**에서 가격이 보이지 않는다면, 가져오기 가능 여부, 라이브 모드 여부, 이전 가져오기 여부, Stripe 계정 연결 상태를 먼저 확인하세요.

## 자주 묻는 질문

Q: Stripe에서는 상품이 보이는데 퍼널에서는 안 보여요. 왜 그런가요?

Stripe 기반 가져오기 워크플로우에서는, 가져오기 대상인 반복 결제 가격을 해당 하이퍼클래스 하위 계정으로 먼저 가져와야 해요. 퍼널을 구성하기 전에 **Payments → Products**를 확인하세요.

Q: Import From Stripe에서 제 Stripe 가격을 찾을 수가 없어요. 왜 그런가요?

해당 가격이 반복(recurring) 방식인지, 라이브(Live) 모드인지, 사용량 기반(metered)이 아닌지, 그리고 이미 가져오기가 되지 않았는지 확인하세요. SaaS V1의 경우, 판매용 하위 계정이 올바른 Stripe 계정에 연결되어 있는지도 함께 확인하세요.

Q: 일회성 Stripe 가격도 가져올 수 있나요?

반복 Stripe 가격 가져오기 워크플로우로는 불가능해요. 일회성 상품이나 가격은 하이퍼클래스에서 직접 만들어야 해요.

Q: 사용량 기반 반복 가격도 가져올 수 있나요?

안 돼요. 사용량 기반 반복 가격은 이 Stripe 반복 가격 가져오기 워크플로우에서 지원되지 않아요.

Q: Stripe에서 가격을 직접 변경했어요. 하이퍼클래스 상품도 자동으로 업데이트되나요?

아니요. Stripe 쪽에서의 가격 변경은 해당 하이퍼클래스 가격을 자동으로 업데이트하지 않아요. 지원되는 가져오기 워크플로우를 사용해서 새로운 가져오기 대상 Stripe 가격을 가져오세요.

Q: 이전에 가져왔던 Stripe 가격이 가져오기 목록에서 왜 사라졌나요?

이미 가져오기가 완료된 Stripe 가격은 더 이상 사용 가능한 가져오기 선택 목록에 표시되지 않아요. 기존 상품은 **Payments → Products**에서 확인하세요.

Q: SaaS V1의 경우 에이전시와 판매용 하위 계정이 동일한 Stripe 계정을 사용해야 하나요?

네, 공식적으로 안내되는 SaaS V1 판매용 하위 계정 퍼널 워크플로우에서는, 에이전시 레벨에 연결된 Stripe 계정과 판매용 하위 계정에 연결된 Stripe 계정이 일치하는지 확인해야 해요.

Q: 새로운 SaaS V1 구독 동기화 기능이 적용되면 누락된 상품이 퍼널에 나타나나요?

아니요. V1 구독 동기화 기능 개선은 가져오기 대상 구독에 대해 지원되는 업그레이드나 다운그레이드가 이루어진 이후에 적용돼요. 퍼널에서 사용하려면 Stripe 상품을 여전히 판매용 하위 계정으로 먼저 가져와야 해요.

Q: SaaS V2도 동일한 Stripe 가져오기 워크플로우를 사용하나요?

아니요. SaaS V2는 선택된 에이전시 하위 계정(Agency Sub-Account)을 시스템 오브 레코드로 사용해요. 해당 하위 계정의 Payments 영역에 상품이 존재하는지 확인한 다음, 그곳에서 퍼널을 통해 선택하세요.
