# 퍼널 상품에 Stripe 플랜이 보이지 않을 때

Stripe 플랜을 퍼널 결제 화면에서 선택하려면, 먼저 퍼널을 만드는 하이퍼클래스 서브 계정에 상품으로 있어야 해요. 이 문서에서는 가져올 수 있는 Stripe 가격, 반복 결제 가격을 서브 계정으로 가져오는 방법, SaaS V1과 SaaS V2의 차이, 플랜이 보이지 않을 때 확인할 내용을 안내해요.

Stripe 플랜이 보이지 않는 이유는 보통 다음 중 하나예요.
- 가격을 아직 가져오지 않았어요.
- 가격이 Test 모드에 있어요.
- 이미 가져온 가격이에요.
- 가져올 수 없는 가격이에요.

{% hint style="warning" %}
**Import From Stripe**(Stripe에서 가져오기)는 반복 결제(구독) 가격 중 조건에 맞는 가격에만 쓸 수 있어요. 일회성 가격과 사용량 기반(metered) 반복 가격은 이 방법으로 가져올 수 없어요. SaaS V1로 퍼널에서 판매한다면, 판매하는 서브 계정이 에이전시와 같은 Stripe 계정에 연결되어 있는지도 확인하세요.
{% endhint %}

## Stripe 플랜을 가져온다는 건 무슨 뜻인가요?

Stripe 플랜을 가져오면 선택한 서브 계정 안에 같은 이름의 하이퍼클래스 상품과 반복 결제 가격이 만들어져요. 그러면 퍼널 주문 폼 같은 결제 화면에서 그 상품을 쓸 수 있어요.

Stripe에 상품이 있다고 해서 퍼널에서 바로 선택할 수 있는 것은 아니에요. 조건에 맞는 반복 결제 가격을 퍼널을 설정하는 서브 계정으로 먼저 가져와야 해요.

SaaS V1에서는 에이전시가 Stripe 기반 SaaS 플랜을 만든 뒤, 그 SaaS 상품을 에이전시가 가진 판매용 서브 계정으로 가져올 때도 이 방법을 써요. 그런 다음 퍼널이나 결제 화면에 상품을 추가해요.

### 가져오면 좋은 점

조건에 맞는 Stripe 가격을 가져오면 선택한 서브 계정의 결제 화면에서 그 상품을 쓸 수 있어요.

- 퍼널에서 선택 가능: 가져온 상품과 반복 결제 가격을 지원되는 퍼널 주문 폼에서 선택할 수 있어요.
- 상품 한곳에서 관리: 가져온 상품이 해당 서브 계정의 **결제 > 상품**에 표시돼요.
- 반복 결제 지원: 기존 구독 상품을 처음부터 다시 만들지 않아도, 조건에 맞는 Stripe 반복 결제 가격을 하이퍼클래스로 가져올 수 있어요.
- SaaS V1 판매 지원: SaaS V1을 쓰는 에이전시는 Stripe 기반 SaaS 상품을 판매용 서브 계정으로 가져와 퍼널로 판매할 수 있어요.

## 가져오기 전 확인할 조건

퍼널 설정을 살펴보기 전에, 먼저 Stripe 가격이 가져오기 조건에 맞는지 확인하세요. 조건에 맞지 않는 가격은 이 방법으로 가져올 수 없어요.

| 조건 | 의미 |
| --- | --- |
| 반복 결제(구독) 가격 | Stripe 가격이 반복 구독 결제 방식이어야 해요. |
| Live 모드 | 가격이 Stripe Live 모드에 있어야 해요. Test 모드 가격은 Live 가져오기 방법으로 가져올 수 없어요. |
| 사용량 기반이 아님 | 사용량 기반(metered) 반복 가격은 이 방법으로 가져올 수 없어요. |
| 아직 가져오지 않음 | 이미 가져온 Stripe 가격은 **Import From Stripe** 목록에 더 이상 나타나지 않아요. |
| 올바른 서브 계정 | 퍼널에서 상품을 판매할 서브 계정으로 가격을 가져와야 해요. |
| SaaS V1 Stripe 연결 | SaaS V1의 판매용 서브 계정 방식에서는 에이전시와 판매용 서브 계정이 같은 Stripe 계정을 써야 해요. |

일회성 가격: 일회성 Stripe 가격은 반복 가격 가져오기 방법으로 가져올 수 없어요. 대신 하이퍼클래스에서 일회성 상품이나 가격을 직접 만드세요.

## SaaS V1과 SaaS V2, 어떤 상품 출처를 써야 하나요?

SaaS V1과 SaaS V2는 결제 구조가 달라요. 상품을 어느 쪽에서 관리하는지 먼저 확인하면 불필요한 Stripe 점검을 줄이고, 맞는 퍼널 상품 설정 방법을 쓸 수 있어요.

| 구조 | 기준이 되는 곳 | 퍼널 상품 설정 방법 |
| --- | --- | --- |
| SaaS V1 | Stripe | 해당 Stripe SaaS 상품과 가격을 판매용 서브 계정으로 가져온 뒤, 퍼널에서 선택해요. |
| SaaS V2 | 선택한 에이전시 서브 계정 | 선택한 에이전시 서브 계정의 **결제 > 상품**에 SaaS 상품이 있는지 확인한 뒤, 퍼널에서 바로 선택해요. V2에서는 Stripe 가져오기를 상품 출처로 쓰지 않아요. |

SaaS V1 구독 동기화 안내: 판매용 서브 계정으로 판매한 SaaS V1 구독 중 조건에 맞는 구독은, 지원되는 업그레이드나 다운그레이드 후에도 Stripe 구독과 판매용 서브 계정의 구독이 서로 맞춰져요. 다만 처음에 Stripe 상품을 가져와야 하는 조건은 그대로예요. 또 플랜 변경이 새로 일어나지 않으면, 예전에 어긋난 내용은 자동으로 바로잡히지 않아요.

## 퍼널 상품용 Stripe 플랜 가져오는 방법

조건에 맞는 Stripe 가격을, 퍼널을 설정하는 하이퍼클래스 서브 계정으로 가져오세요. 가져오기가 끝나면 결제 화면에 추가하기 전에 **결제**에서 상품이 생겼는지 확인하세요.

1. 상품을 판매할 하이퍼클래스 서브 계정을 여세요.
2. 왼쪽 메뉴에서 **결제**를 선택하세요.
3. **상품**을 선택하세요.
4. **Import From Stripe**(Stripe에서 가져오기)를 클릭하세요.

![상품 화면에서 Stripe에서 가져오기 버튼을 클릭하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130352/original/aXDWiozf0sJe8I-NJFYK5QjPwxdtN4M9pw.png?1789610903)

5. 가져올 Stripe 상품을 검색하세요.
6. 사용할 수 있는 반복 결제 가격을 확인하세요.
7. 가져올 상품과 가격을 선택하세요.
8. 가져오기를 완료하세요.

![가져올 Stripe 상품과 가격을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130354/original/O3i0h-3jl2uwUv2zOkJKgq3n7-3T9BguPw.png?1789610929)

9. **결제 > 상품**에 가져온 상품이 보이는지 확인하세요.

![결제 > 상품에 가져온 상품이 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130313/original/4b9YL8bLTIwpZd56txU9Obk5RVmniXU5YA.png?1789610776)

10. 왼쪽 메뉴에서 **사이트**를 선택하세요.
11. **퍼널**을 선택하세요.
12. 상품을 판매할 퍼널을 여세요.
13. 해당 주문 폼이나 상품 설정을 여세요.
14. 가져온 하이퍼클래스 상품과 반복 결제 가격을 선택하세요.
15. 결제 설정을 테스트한 다음 **저장 및 게시**를 선택해 퍼널을 게시하세요.

![퍼널 주문 폼에서 가져온 상품을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081130369/original/NMFxrBLVuXJrBYRQg3-YWG0J3SUs1R6TWQ.png?1789610960)

## Stripe 플랜이 보이지 않을 때 확인할 내용

설정을 바꾸기 전에, 상품이 어디에서 보이지 않는지부터 확인하세요. Stripe 가져오기 목록에 플랜이 없는 경우와, 이미 가져온 상품이 퍼널에서만 보이지 않는 경우는 원인이 달라요.

| 문제 | 확인할 내용 |
| --- | --- |
| 이미 가져온 가격이에요 | 이미 가져온 Stripe 가격은 **Import From Stripe** 선택 목록에서 빠져요. 가져오기에 실패했다고 판단하기 전에 **결제 > 상품**을 먼저 확인하세요. |
| 가격이 Stripe Test 모드에 있어요 | 가져오기에는 조건에 맞는 Live 모드 Stripe 가격이 필요해요. Test 모드 가격은 퍼널에서 쓰는 Live 반복 가격으로 나타나지 않아요. |
| 일회성 가격이에요 | 일회성 Stripe 가격은 이 반복 가격 가져오기 방법으로 가져올 수 없어요. 하이퍼클래스에서 일회성 상품이나 가격을 직접 만드세요. |
| 사용량 기반 가격이에요 | 사용량 기반 반복 가격은 Stripe 반복 가격 가져오기에서 지원하지 않아요. |
| 다른 서브 계정으로 가져오고 있어요 | 퍼널을 설정하는 서브 계정의 **결제 > 상품**에 상품이 있어야 해요. |
| SaaS V1에서 에이전시와 판매용 서브 계정이 서로 다른 Stripe 계정을 쓰고 있어요 | **Agency View**(에이전시 보기) > **설정** > **Stripe**의 Stripe 연결과, 판매용 서브 계정의 **결제 > 연동**에 있는 Stripe 연결을 비교해 보세요. 지원되는 V1 퍼널 방식은 같은 Stripe 계정을 전제로 해요. |
| Stripe에서 가격을 직접 바꿨어요 | Stripe에서 바꾼 가격은 해당 하이퍼클래스 상품이나 가격에 자동으로 반영되지 않아요. 지원되는 방법에 따라, 조건에 맞는 새 Stripe 가격을 새 하이퍼클래스 상품이나 가격으로 가져오세요. |
| SaaS V1 상품을 **SaaS 구성기**에서 만들었지만 판매용 서브 계정으로 가져오지 않았어요 | 에이전시에서 V1 SaaS 플랜을 만든다고 해서 판매용 서브 계정의 퍼널에서 Stripe 상품을 바로 쓸 수 있는 건 아니에요. 해당 Stripe 상품을 그 판매용 서브 계정으로 먼저 가져오세요. |
| SaaS V2를 쓰고 있어요 | SaaS V2는 선택한 에이전시 서브 계정이 기준이에요. V1의 Stripe 가져오기 경로를 점검하지 말고, 그 서브 계정에 상품이 있는지 확인하세요. |

간단 진단: **결제 > 상품**에는 상품이 보이는데 퍼널에서만 보이지 않으면, 퍼널 쪽을 점검하고 같은 서브 계정에서 작업하고 있는지 확인하세요. **Import From Stripe**에서 가격이 보이지 않으면, 가져오기 조건과 Live 모드, 이미 가져왔는지 여부, Stripe 계정 연결을 먼저 확인하세요.

## 자주 묻는 질문

### Stripe에는 상품이 보이는데 퍼널에서는 왜 안 보이나요?
Stripe 기반 가져오기 방법에서는, 조건에 맞는 반복 결제 가격을 해당 하이퍼클래스 서브 계정으로 먼저 가져와야 해요. 퍼널을 설정하기 전에 **결제 > 상품**을 확인하세요.

### Import From Stripe에서 Stripe 가격을 찾을 수 없어요.
가격이 반복 결제인지, Live 모드인지, 사용량 기반이 아닌지, 이미 가져온 가격이 아닌지 확인하세요. SaaS V1이라면 판매용 서브 계정이 올바른 Stripe 계정에 연결되어 있는지도 확인하세요.

### 일회성 Stripe 가격도 가져올 수 있나요?
반복 가격 가져오기 방법으로는 가져올 수 없어요. 일회성 상품이나 가격은 하이퍼클래스에서 직접 만드세요.

### 사용량 기반 반복 가격도 가져올 수 있나요?
아니요. 이 Stripe 반복 가격 가져오기 방법은 사용량 기반 반복 가격을 지원하지 않아요.

### Stripe에서 가격을 직접 바꿨는데 하이퍼클래스 상품도 자동으로 바뀌나요?
아니요. Stripe에서 바꾼 가격은 해당 하이퍼클래스 가격에 자동으로 반영되지 않아요. 지원되는 가져오기 방법으로 조건에 맞는 새 Stripe 가격을 가져오세요.

### 전에 가져온 Stripe 가격이 가져오기 목록에서 사라졌어요.
이미 가져온 Stripe 가격은 가져오기 선택 목록에 더 이상 표시되지 않아요. **결제 > 상품**에서 이미 만들어진 상품을 확인하세요.

### SaaS V1에서는 에이전시와 판매용 서브 계정이 같은 Stripe 계정을 써야 하나요?
네. 문서에 안내된 SaaS V1 판매용 서브 계정 퍼널 방식에서는, 에이전시 수준에 연결된 Stripe 계정과 판매용 서브 계정에 연결된 Stripe 계정이 같은지 확인하세요.

### 새로 생긴 SaaS V1 구독 동기화 기능을 쓰면 없던 상품이 퍼널에 나타나나요?
아니요. V1 구독 동기화 개선은 조건에 맞는 구독이 지원되는 업그레이드나 다운그레이드를 한 뒤에 적용돼요. 퍼널에서 쓰려면 Stripe 상품을 판매용 서브 계정으로 가져와야 하는 점은 그대로예요.

### SaaS V2에서도 같은 Stripe 가져오기 방법을 쓰나요?
아니요. SaaS V2는 선택한 에이전시 서브 계정을 기준으로 해요. 그 서브 계정의 **결제** 영역에 상품이 있는지 확인하고, 퍼널에서 선택하세요.
