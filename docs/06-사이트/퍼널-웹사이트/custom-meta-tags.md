# 커스텀 메타 태그 설정

하이퍼클래스의 퍼널과 웹사이트 페이지에 커스텀 메타 태그를 추가하는 방법을 안내해요. 메타 태그는 검색엔진에 정보와 지시를 전달하는 데 쓰여요.

## 커스텀 메타 태그란?

커스텀 메타 태그를 쓰면 검색엔진, 브라우저, 소셜 미디어에서 내 페이지를 어떻게 설명할지 직접 정할 수 있어요. 화면에는 보이지 않는 HTML 코드 조각이고, 사이트의 노출과 검색 순위를 조절하는 데 도움이 돼요.

Google이 지원하는 메타 태그 목록은 여기에서 확인할 수 있어요: <https://developers.google.com/search/docs/crawling-indexing/special-tags>

## 커스텀 메타 태그를 쓰면 좋은 점

커스텀 메타 태그는 웹사이트의 SEO 성과와 온라인 노출 모습을 조절할 때 꼭 필요해요.

- 검색엔진에 내 페이지가 표시되는 모습을 개선할 수 있어요.
- 페이지를 공유할 때 보이는 제목, 설명, 이미지를 정할 수 있어요.
- 초안이나 비공개 페이지가 검색엔진에 색인되지 않게 막을 수 있어요.
- 캐싱이나 리디렉션 같은 브라우저 동작을 원하는 대로 바꿀 수 있어요.
- 코딩 없이도 SEO를 더 세밀하게 조절할 수 있어요.

---

## 커스텀 메타 태그 추가하기

빌더 상단의 **SEO Meta Data**(SEO 메타 데이터) 아이콘을 눌러도 퍼널과 웹사이트 페이지에 커스텀 메타 태그를 추가할 수 있어요.

1. **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동하세요.
2. 편집할 퍼널이나 웹사이트를 선택하세요.
3. 태그를 추가할 페이지나 단계를 클릭해 들어가세요.
4. **SEO Meta Data** 탭으로 이동하세요.
5. 아래로 스크롤해서 **Links and Tags**(링크 및 태그) 드롭다운을 찾으세요.
6. **Custom Meta Tags**(커스텀 메타 태그) 옆의 **+ 추가**를 클릭하세요.
7. 태그 이름과 내용을 입력하세요.
8. **추가**를 클릭하세요.
9. **Update SEO Meta**(SEO 메타 업데이트)를 클릭해 변경 내용을 저장하세요.

```
예시: 특정 페이지를 검색엔진이 색인하지 않게 하려면, 새 커스텀 메타 태그의 이름을 "robots", 내용을 "noindex"로 입력하세요. 아래 화면처럼 설정하면 돼요.
```

## 자주 묻는 질문

### 수정한 메타 태그를 Google이 인식하기까지 얼마나 걸리나요?
Google의 크롤링 일정에 따라 몇 시간에서 며칠까지 걸릴 수 있어요.

### 한 페이지에 커스텀 메타 태그를 여러 개 추가할 수 있나요?
네, 가능해요. 페이지를 최적화하는 데 필요한 만큼 추가하세요.

### 메타 태그가 없으면 SEO에 불리한가요?
description이나 Open Graph 데이터 같은 주요 메타 태그가 없으면 검색 순위와 소셜 미디어 미리보기에 나쁜 영향을 줄 수 있어요.

### "noindex" 태그를 추가하면 어떻게 되나요?
Google 같은 검색엔진이 해당 페이지를 색인하지 않고 건너뛰어요.
