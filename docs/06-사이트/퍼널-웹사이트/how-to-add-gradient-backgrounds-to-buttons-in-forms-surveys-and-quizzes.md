# 폼·설문·퀴즈 버튼에 그라데이션 배경 적용하기

하이퍼클래스 폼, 설문, 퀴즈의 버튼 배경에 그라데이션을 적용하는 방법을 안내해요. 버튼 설정에서 바로 그라데이션 스타일을 고를 수 있어서, 일반적인 그라데이션 버튼은 별도의 CSS 없이 만들 수 있어요.

## 그라데이션 버튼 배경이란?

그라데이션 버튼 배경은 버튼에 여러 색이 섞인 배경 효과를 주는 기능이에요. **폼 빌더**, **설문 빌더**, **퀴즈 빌더**에서 쓸 수 있어요. 한 가지 단색 대신 두 가지 이상의 색을 지원되는 그라데이션 유형으로 섞어요.

브랜드, 랜딩 페이지 디자인, 캠페인 분위기에 맞는 버튼을 만들 때 유용해요. 단색 배경과 그라데이션 배경 중에서 고른 뒤, 빌더에서 바로 그라데이션 유형, 색상, 각도, 색상 정지점(color stop)을 설정해요.

## 그라데이션 버튼 배경의 장점

폼, 설문, 퀴즈에서 버튼이 보이는 모습을 더 세밀하게 조정할 수 있어요. 코드 없이 간단하게 설정하면서도 행동 유도 버튼을 눈에 띄게 만들고 싶을 때 특히 좋아요.

- 디자인 폭이 넓어져요: 단색보다 세련되고 역동적인 버튼을 만들 수 있어요.
- 코드가 필요 없어요: 일반적인 그라데이션 버튼 배경은 버튼 설정에서 바로 적용해요.
- 브랜드에 맞출 수 있어요: 여러 브랜드 색상을 섞어 나만의 느낌을 낼 수 있어요.
- 다양한 그라데이션 스타일을 쓸 수 있어요: 선형, 원형, 각도형 중에서 고를 수 있어요.
- 색 전환을 직접 조절해요: 색상 정지점을 여러 개 추가하고 편집해서 버튼 위에서 색이 바뀌는 방식을 정해요.
- 기존 스타일도 그대로예요: 지금 쓰는 단색 버튼 배경은 계속 작동하고, 그라데이션은 선택지가 하나 더 늘어난 거예요.

## 버튼 배경 옵션

**버튼 배경** 설정에서는 선택한 버튼에 단색을 쓸지, 그라데이션을 쓸지 정해요. 폼, 설문, 퀴즈의 목적에 맞는 배경 유형을 고르세요.

고를 수 있는 옵션은 다음과 같아요.

- **Solid Color**(단색): 버튼에 배경색 하나를 써요.
- **그라데이션**: 여러 색이 버튼 위에서 자연스럽게 섞여요.

깔끔하고 단순한 버튼을 원하면 단색을 쓰세요. 버튼을 더 눈에 띄게 하거나 역동적인 페이지 디자인에 맞추고 싶으면 그라데이션을 쓰세요.

## 그라데이션 유형

그라데이션 유형에 따라 버튼 위에서 색이 섞이는 방식이 달라져요. 유형마다 시각 효과가 달라서 최종 버튼 모양을 더 세밀하게 정할 수 있어요.

지원하는 그라데이션 유형은 다음과 같아요.

- **Linear Gradient**(선형 그라데이션): 색이 한 방향으로 곧게 섞여요.
- **Radial Gradient**(원형 그라데이션): 가운데 한 점에서 바깥쪽으로 색이 퍼지며 섞여요.
- **Angular Gradient**(각도형 그라데이션): 각도를 기준으로 한 패턴으로 색이 섞여요.

일부 그라데이션 스타일은 각도를 조정할 수 있어서 그라데이션의 방향을 바꿀 수 있어요.

## 그라데이션 각도

그라데이션 각도는 지원되는 그라데이션 스타일의 방향을 정해요. 각도를 바꾸면 버튼 위에서 색이 흐르는 방향이 달라져서, 주변 페이지 디자인과 더 잘 어울리게 만들 수 있어요.

예를 들어 선형 그라데이션은 선택한 각도에 따라 왼쪽에서 오른쪽, 위에서 아래, 또는 대각선으로 흐를 수 있어요. 선택한 그라데이션 유형이 각도 조정을 지원하면, 각도 조절 기능으로 색이 섞이는 방향을 세밀하게 맞추세요.

## 색상 정지점

색상 정지점(color stop)은 그라데이션에 쓸 색과, 그 색이 섞임 속에서 나타나는 위치를 정해요. 색상 정지점을 여러 개 추가하면 한 색에서 다른 색으로 바뀌는 방식을 더 세밀하게 조절할 수 있어요.

색상 정지점으로 할 수 있는 일은 다음과 같아요.

- 버튼 배경에 색을 두 개 이상 추가해요.
- 각 색이 얼마나 강하게 보일지 조정해요.
- 더 부드럽거나 원하는 대로 바뀌는 전환을 만들어요.
- 브랜드 색상 조합을 더 정확하게 맞춰요.

## 그라데이션 버튼 배경 설정하기

바꾸려는 버튼을 먼저 선택해야 빌더에 그 버튼의 스타일 설정이 나타나요. 올바른 요소에 스타일이 적용되도록 이 순서대로 진행하세요.

1. 하이퍼클래스에서 **폼 빌더**, **설문 빌더**, **퀴즈 빌더** 중 하나를 열어요.
2. 꾸밀 버튼 요소를 선택해요.
3. 버튼 스타일 설정을 열어요.

   ![버튼 스타일 설정 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072470717/original/leKrNtFShxH8F4B7MGlXmQllArzC5LrHTw.png?1780057283)
4. **버튼 배경** 섹션을 찾아요.

   ![버튼 배경 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072471334/original/xlvUjjgr7RZ-an4I_hfEkHNqzcz6PuvJnQ.png?1780057453)
5. **Solid Color**(단색) 대신 **그라데이션**을 선택해요.

   ![그라데이션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072471504/original/STXFotmx430lKQ0KE4-TLMJLIYKWLdMXOA.png?1780057526)
6. 그라데이션 유형을 선택해요.

   ![그라데이션 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072471669/original/dtH-reNjhNgdvnbET2WfJRjijgRN7iPGBA.gif?1780057637)
7. 그라데이션 색상 정지점을 추가하거나 편집해요.

   ![색상 정지점 추가 및 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072471737/original/wM7SqU_rUY468WbcfdylV29Z0eboCVpdyw.png?1780057695)
8. 선택한 그라데이션 유형이 각도 조정을 지원하면 그라데이션 각도를 조정해요.

   ![그라데이션 각도 조정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072471778/original/9t-PPrz8h2F1icXjvD16begl0BhVx3mRyA.png?1780057731)
9. **미리보기**로 폼, 설문 또는 퀴즈에서 버튼이 원하는 대로 보이는지 확인해요.

   ![버튼 미리보기 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072471850/original/zgWahThbUWoMQVEkTwkAQhrpdef0lK61-w.png?1780057775)
10. **저장**하거나 **게시**해요.

## 자주 묻는 질문

### 버튼에 단색도 계속 쓸 수 있나요?
네. 단색 배경과 그라데이션 배경 중에서 고를 수 있어요.

### 어떤 빌더에서 그라데이션 버튼 배경을 쓸 수 있나요?
**폼 빌더**, **설문 빌더**, **퀴즈 빌더**에서 쓸 수 있어요.

### 그라데이션 버튼 배경을 만들려면 CSS를 써야 하나요?
아니요. 일반적인 그라데이션 버튼 배경은 이제 버튼 설정에서 바로 설정할 수 있어요. 다만 기본 제공 기능으로 할 수 없는 고급 스타일링이 필요하다면 CSS가 여전히 도움이 될 수 있어요.

### 그라데이션에 두 가지보다 많은 색을 쓸 수 있나요?
네. 색상 정지점을 여러 개 추가하고 편집해서 더 다양한 버튼 디자인을 만들 수 있어요.

### 기존 버튼 스타일이 자동으로 바뀌나요?
아니요. 기존 버튼 스타일은 그대로 작동해요. 새 스타일을 쓰고 싶을 때 버튼의 배경을 단색에서 그라데이션으로 직접 바꾸면 돼요.
