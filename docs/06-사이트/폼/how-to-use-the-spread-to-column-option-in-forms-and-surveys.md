# 폼과 설문에서 Spread to Column 옵션 사용하기

폼과 설문의 라디오 버튼, 라디오 이미지, 체크박스 항목을 여러 열로 나눠 보여 주는 기능이에요. 항목이 많을 때 **Spread to Column**(열로 펼치기) 옵션으로 열 개수를 정하면 폼이 더 깔끔해져요.

## 사용 방법

1. **Form Builder**(폼 빌더) 또는 **설문 빌더**를 엽니다.
2. **Radio**(라디오), **Checkbox**(체크박스), **Radio Image**(라디오 이미지) 필드 중 하나를 클릭하세요.
3. 오른쪽 설정 패널에서 **Spread to Column** 옵션을 켜세요.
4. 열 개수를 입력하세요.

## 주요 기능과 장점

스타일 개선:

라디오 옵션과 체크박스를 여러 열로 나누면 폼이 보기 좋고 정돈돼요.

## 응답자가 더 편하게 쓸 수 있어요

폼이 더 알아보기 쉬워져서 응답자가 항목을 훑어보고 선택하기 편해요.

## 참고 사항

- **1단 레이아웃**에서는 열을 최대 5개까지 만들 수 있어요.
- **Two Column**(2단)에서는 열을 최대 2개까지 만들 수 있어요.
- **Single Line Column**(한 줄 열)에서는 열을 최대 5개까지 만들 수 있어요.
- 이전에 만든 폼에는 영향을 주지 않아요.
