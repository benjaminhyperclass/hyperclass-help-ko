# 폼과 설문에서 주소 자동완성 사용하기

주소 자동완성은 폼과 설문의 주소 입력란에 글자를 입력하면 맞는 주소를 추천해 주는 기능이에요. 이제 모든 하이퍼클래스 계정에서 무료로, 횟수 제한 없이 쓸 수 있어요. 리드와 고객이 주소를 정확하고 빠르게 입력할 수 있도록 도와줘요.

## 주소 자동완성이란?

주소 자동완성은 하이퍼클래스 폼과 설문의 기본 **주소** 필드를 추천 검색창으로 바꿔 줘요. 글로벌 주소 데이터베이스를 연동해, 사용자가 입력하는 동안 관련 주소를 추천해요.

주소 데이터가 정확해야 워크플로우, 세분화, 리포팅, 배송 관련 작업을 제대로 할 수 있어요. 주소 자동완성을 쓰면 오타가 줄고 형식이 일정해지며 폼 작성도 빨라져요. 사용자는 더 편하게 입력하고, 여러분은 더 믿을 만한 데이터를 얻을 수 있어요.

### 검색 추천

사용자가 **주소** 필드에 글자를 입력하면, 실제 주소 데이터를 바탕으로 추천 주소가 실시간으로 나타나요.

### 주소 필드 자동 채우기

사용자가 목록에서 주소를 고르면 거리, 도시, 주/도, 국가, 우편번호 필드가 자동으로 채워져요. 형식이 일정하게 유지되고, 직접 입력하다 생기는 실수도 줄어요.

## 주소 자동완성의 장점

주소 자동완성을 쓰면 폼이 제출될 때마다 연락처 데이터가 검증되고, 형식이 일정하며, 올바르게 입력돼요. 나중에 데이터를 고치는 일이 줄고, 사용자 만족도도 높아져요.

- 무료, 무제한: 모든 하이퍼클래스 계정에 포함되어 있고 사용 제한이 없어요.
- 더 정확한 데이터: 검증된 주소가 일정한 형식으로 입력돼요.
- 더 빠른 제출: 리드와 고객이 입력해야 할 글자가 줄어요.
- 더 높은 전환율: 불편함이 적어서 폼을 끝까지 작성하는 사람이 늘어요.
- 더 나은 리포팅 데이터: 주소 형식이 통일되어 자동화의 정확도가 높아져요.

## 주소 자동완성 켜기

### 주소 필드 추가하기

1. **사이트 > 폼**(또는 **설문**)으로 이동해서, 주소 자동완성을 쓰려는 폼 빌더를 열어요.
2. **Form Elements**(폼 요소) 패널에서 **주소** 필드를 폼 레이아웃으로 끌어다 놓아요. **주소** 요소에 **수정일** 표시가 있으면 자동완성 기능을 지원한다는 뜻이에요.

![폼 요소 패널의 주소 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758329/original/1keSyOM9IjxVc9cggUh6vpY5sReynZIdUQ.png?1760147263)

### 주소 필드 설정 열기

1. 추가한 **주소** 필드를 클릭해요. 화면 오른쪽에 설정 패널이 열려요.

이 패널에서 주소 입력 방식을 조정하고, 자동완성을 켜고, 검증된 주소를 반드시 선택하게 할지 정할 수 있어요.

![주소 필드 설정 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758336/original/pFSPtlYwSv71eVBrmuOAC8FmwNJFsykfug.png?1760147347)

### 주소 자동완성 켜기

1. 설정 패널에서 **주소 자동완성** 토글을 찾아 **켜짐**으로 바꿔요.

켜면 기본 주소 입력란이 추천 검색창으로 바뀌어서, 입력하는 동안 정확한 주소를 추천해 줘요.

![주소 자동완성 토글을 켠 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758423/original/LW7dk4ZxDjLJEfzjjsy-vKEb3AyAzSizFQ.png?1760147656)

### 주소 선택을 필수로 만들기

검증된 주소만 제출되게 하려면 **Mandatory to Select Address in Search Bar**(검색창에서 주소 선택 필수) 토글을 **켜짐**으로 바꿔요.

이 토글을 켜면 사용자는 추천 주소 중 하나를 골라야 폼을 제출할 수 있어요. 꺼 두면 주소를 직접 입력할 수도 있어요.

![주소 선택 필수 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758426/original/RxZTM2OVNrnwIzCdd8ip3sbi6f63t_is_w.jpeg?1760147670)

### 폼 미리보기

1. 폼 빌더 오른쪽 위에서 **미리보기**를 클릭해요. 실제 폼에서 **주소** 필드가 어떻게 보이는지 확인할 수 있어요.

이제 **주소** 필드가 검색창으로 표시돼요. 글자를 입력하기 시작하면 바로 추천 주소가 나타나요.

![폼 미리보기에서 검색창으로 바뀐 주소 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758436/original/zGD2LeIC6RMs_jDGsds9JgI1fDnGEbLNOQ.jpeg?1760147782)

### 추천 주소 테스트하기

1. 미리보기에서 **주소** 필드에 몇 글자(예: 도로 이름 일부)를 입력해요.
2. 검색창 아래에 추천 주소가 나타나요. 하나를 선택하면 거리, 도시, 주/도, 국가, 우편번호 필드가 자동으로 채워져요.

![추천 주소를 선택해 자동으로 채워진 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758434/original/_pK5PJkq8QF9qLUAgJBfLtgDmsd7GQeIrA.jpeg?1760147771)

### 저장하고 게시하기

1. 자동완성이 의도대로 동작하는지 확인한 뒤 **저장**을 클릭해 변경 사항을 적용해요.

게시하고 나면, 폼을 작성하는 모든 방문자가 내장된 자동완성으로 빠르고 정확하게 주소를 입력할 수 있어요.

![저장 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080506215/original/ldcmBZqziAekjXyvMkoMPT_V0fse3xtbnw.png?1788963052)

## 자주 묻는 질문

### 주소 자동완성은 아직도 유료 기능인가요?
아니요. 이제 모든 하이퍼클래스 계정에서 완전히 무료이고, 사용 횟수 제한도 없어요.

### 사용자가 주소를 직접 입력하게 할 수도 있나요?
네. 직접 입력을 허용하려면 **주소 자동완성** 토글을 끄세요.

### 주소 자동완성은 해외에서도 되나요?
네. 전 세계 대부분의 국가와 우편번호 형식을 지원해요.

### 예전에 만든 폼에도 자동완성이 자동으로 켜지나요?
아니요. 폼이나 설문을 하나씩 열어서 토글을 직접 켜야 해요.

### 사용자가 추천 주소를 선택하지 않으면 어떻게 되나요?
**Mandatory to Select Address in Search Bar** 토글이 켜짐이면 추천 주소를 골라야 폼을 제출할 수 있어요. 꺼져 있으면 자유롭게 입력할 수 있어요.

### 자동완성이 기존 연락처 데이터를 덮어쓰나요?
아니요. 제출된 내용은 평소의 연락처 업데이트 규칙과 매핑 설정을 그대로 따라요.
