# 폼·설문에서 커스텀 필드 빠르게 추가하고 수정하기

폼·설문 빌더에서 커스텀 필드를 끌어다 놓아 바로 추가하고, 이미 있는 필드도 빌더 안에서 수정할 수 있어요. 예전처럼 여러 단계를 거치지 않아도 돼요. ▶ 영상 [4강 3부 1:07:44](https://www.youtube.com/watch?v=oEDq8IGJ3-c&t=4064s)

{% hint style="info" %}
커스텀 필드 이름에 "score"가 들어 있으면 시스템이 그 필드를 숫자 점수 요소로 자동 인식해요. **폼**, **설문**, **퀴즈** 모두 마찬가지예요. 이 동작은 현재 점수 요소를 구분하는 방식에 고정되어 있어요.
{% endhint %}

## 새로 생긴 기능

### 커스텀 필드 빠른 추가

예전에는 **커스텀 필드 추가** 창에서 여러 단계를 거쳐야 커스텀 필드를 만들 수 있었어요. 이제는 빠른 추가로 필드를 폼에 끌어다 놓기만 하면 만들어져요.

### 끌어다 놓을 수 있는 커스텀 필드

- **라디오 선택**
- **Single and Multi Dropdown**(단일·다중 드롭다운)
- **Checkbox**(체크박스)
- **File upload**(파일 업로드)
- **Single Line**(한 줄 입력)
- **Multi line**(여러 줄 입력)
- **Textbox List**(텍스트박스 목록)
- **Date picker**(날짜 선택)
- **Number**(숫자)
- **Monetary**(금액)

### 커스터마이징 옵션

드롭다운, 라디오 버튼, 체크박스의 옵션을 직접 정할 수 있어요. 파일 업로드 필드는 파일 입력 옵션도 설정할 수 있어요. 커스텀 필드 이름과 고유 키(unique key)도 지정할 수 있어요.

### 간단해진 작업 순서

폼이나 설문을 저장하면 커스텀 필드도 함께 저장돼요. 저장된 필드는 모든 곳에서 사용할 수 있어요.

### 수정 기능

새로 만든 커스텀 필드와 기존 커스텀 필드의 속성을 수정할 수 있어요. 옵션 편집·순서 변경·삭제, 파일 입력 옵션 등을 바꿀 수 있어요.

폼이나 설문에 추가한 커스텀 필드를 수정하려면 다음과 같이 하세요.

1. 폼 또는 설문 빌더에서 수정할 커스텀 필드를 클릭하세요.
2. 오른쪽에 탐색 바가 나타나요.
3. **일반 설정**과 **고급 설정** 드롭다운에서 필요한 내용을 바꾸세요.

### 필드 잠금

폼이나 설문을 저장하면 커스텀 필드 이름과 고유 키가 잠겨요. 이 둘은 커스텀 필드 섹션에서 수정할 수 있어요.

## 사용 방법

### 새 폼 만들기 또는 기존 폼 열기

**사이트 > 폼 > 빌더**로 이동하세요.

![사이트 > 폼 > 빌더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066200103/original/JtQyI-S7B8Zsb1UMb-LbQvGvy9ngxji7yQ.png?1772636976)

### 필드 하나 또는 여러 개 추가하기

필드를 하나씩 추가해도 되고, 여러 개를 먼저 선택한 뒤 한꺼번에 빌더에 추가해도 돼요.

**Add Object Fields**(오브젝트 필드 추가)를 열면 추가할 수 있는 필드를 둘러보거나 검색할 수 있어요. 원하는 필드를 체크박스로 선택한 다음, 아래 두 방법 중 하나로 추가하세요.

- **Add N fields**(N개 필드 추가)를 클릭하면 선택한 필드가 한 번에 모두 추가돼요.
- 선택한 필드 중 하나를 캔버스로 끌어다 놓으면 선택한 필드가 그룹으로 추가돼요.

여러 필드를 한꺼번에 추가하면 사이드바에 보이는 순서대로 들어가요. 캔버스에서 선택된 요소가 있으면 그 요소 뒤에 들어가고, 선택된 요소가 없으면 페이지나 슬라이드 맨 끝에 추가돼요.

필드를 하나씩 캔버스로 끌어다 놓는 방법도 그대로 쓸 수 있어요. 끌 때 움직임이 부드럽고 시각적 표시가 나타나요. 폼이나 설문이 길면 빌더 위쪽이나 아래쪽 가까이로 끌 때 화면이 자동으로 스크롤돼요.

오브젝트별로 필드를 선택하는 방법, 유형과 쿼리 키로 필드를 구분하는 방법, 여러 필드 선택을 관리하는 방법은 「폼, 설문, 퀴즈의 커스텀 오브젝트와 회사 오브젝트」 문서를 참고하세요.

### 커스터마이징

드롭다운, 라디오 버튼, 체크박스의 옵션을 설정하세요. 파일 업로드 필드는 파일 입력 옵션을 설정하세요. 필요하면 커스텀 필드 이름과 고유 키도 지정하세요.

### 저장

폼이나 설문을 저장하면 커스텀 필드도 함께 저장되고, 모든 곳에서 사용할 수 있어요.

### 편집

새로 만든 커스텀 필드나 기존 커스텀 필드의 속성을 커스텀 필드 섹션에서 수정한 뒤, 폼이나 설문을 저장하세요.

## 왜 이 기능이 생겼나요?

커스텀 필드를 관리하는 시간과 번거로움을 줄이려고 만든 기능이에요. 필요할 때 바로 필드를 추가할 수 있어서 작업이 더 편해져요.

## 오래되었거나 필요 없는 커스텀 필드 삭제하기

폼에서 지웠는데도 폼 빌더에 오래된 커스텀 필드가 계속 보인다면, CRM의 커스텀 필드 목록에 그대로 남아 있는 경우예요.

완전히 삭제하려면 다음과 같이 하세요.

1. **설정 > 커스텀 필드**로 이동하세요.
2. 목록에서 오래된 필드를 찾으세요.
3. 휴지통 아이콘을 클릭해 영구 삭제하세요.

{% hint style="warning" %}
이 섹션에서 커스텀 필드를 삭제하면 그 필드를 사용하던 모든 폼, 설문, 연락처에서 함께 제거돼요.
{% endhint %}

커스텀 필드 이름에 "score"가 들어 있으면 시스템이 그 필드를 숫자 점수 요소로 자동 인식해요. 다음 위치에서 모두 그래요.

- **폼**
- **설문**
- **퀴즈**

이 동작은 현재 점수 요소를 구분하는 방식에 고정되어 있어요.
