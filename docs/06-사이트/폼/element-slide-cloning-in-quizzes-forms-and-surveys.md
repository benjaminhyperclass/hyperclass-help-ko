# 퀴즈·폼·설문에서 요소와 슬라이드 복제하기

하이퍼클래스의 폼, 설문, 퀴즈 빌더에서 요소와 슬라이드를 한 번의 클릭으로 복제할 수 있어요. 스타일과 설정이 그대로 복제되므로, 여러 단계로 이어지는 폼·설문·퀴즈도 일관된 디자인으로 빠르게 만들 수 있어요.

## 요소·슬라이드 복제란?

이미 설정해 둔 요소를 폼, 퀴즈, 설문 안에서 바로 복제하는 기능이에요. 커스텀 필드, 텍스트 상자, 이미지 요소 등을 빠르게 복제할 수 있어요.

복제본은 원본 바로 아래에 만들어져요. 스타일, 유효성 검사, 그 밖의 설정이 그대로 유지되기 때문에, 처음부터 다시 만들지 않고 검증된 블록을 다시 쓸 수 있어요. 복제한 뒤에 새 요소나 슬라이드를 수정해도 원본에는 영향이 없어요.

설문과 퀴즈에서는 슬라이드 전체도 복제할 수 있어요. 여러 단계로 이어지는 설문을 만들거나 같은 형식의 질문을 반복할 때 시간을 아낄 수 있어요.

## 요소·슬라이드 복제의 장점

- 속도: 클릭 한 번으로 어떤 요소든 복제할 수 있어요. 슬라이드를 복제하면 여러 단계로 된 설문도 더 빨리 만들 수 있어요.
- 일관성: 반복되는 섹션에서 간격, 레이블, 스타일, 서식을 똑같이 유지할 수 있어요.
- 효율성: 공들여 설정한 요소를 다시 만들지 않고 재사용할 수 있어요.
- 확장성: 기존 구조를 재사용해서 더 큰 폼과 설문을 빠르게 만들 수 있어요.
- 정확도: 유효성 검사와 필수 규칙이 그대로 복제되므로 설정을 빠뜨리는 일을 막을 수 있어요.
- 디자인 재사용: 스타일을 적용한 이미지·텍스트 블록을 복제해서 통일된 모양을 유지할 수 있어요.

## 복제하면 함께 복제되는 항목

무엇이 복제되는지 알아 두면, 복제한 뒤에 어떤 부분을 수정할지 계획하기 쉬워요. 데이터 수집도 정확하게 유지하고 사용자 경험도 일관되게 지킬 수 있어요.

- 스타일 및 레이아웃: 글꼴, 간격, 너비, 정렬, 테마
- 유효성 검사: 원본 요소에 설정한 필수 토글과 유효성 검사 규칙
- 콘텐츠: 레이블, 플레이스홀더, 선택지, 도움말 텍스트
- 이미지: 소스, 정렬, 크기 설정
- 슬라이드(설문/퀴즈): 시각 디자인과 레이아웃

## 폼·설문·퀴즈에서 요소 복제하기

폼, 설문, 퀴즈에서 설정해 둔 입력 항목, 텍스트, 이미지, 질문 블록을 복제할 수 있어요. 원본 바로 아래에 똑같은 복제본이 만들어지고 스타일, 유효성 검사, 콘텐츠가 그대로 유지돼요. 일관된 모양을 지키면서 같은 구성을 빠르게 반복할 수 있어요.

1. **폼 빌더**, 설문 빌더, **퀴즈 빌더** 중 하나에서 폼, 설문 또는 퀴즈를 열어요.
2. 복제할 요소 위에 마우스를 올려요.
3. **복제**(사각형 두 개 모양 아이콘)를 클릭해요. 복제본이 원본 바로 **아래**에 바로 나타나요.
4. 복제된 요소를 클릭해서 필요한 부분을 수정해요.

## 슬라이드 전체 복제하기 (설문·퀴즈)

슬라이드를 복제하면 레이아웃, 디자인 블록, 질문 요소를 포함한 슬라이드 전체가 복제돼요. 여러 단계로 이어지는 흐름을 더 빠르게 만들 수 있고, 단계마다 서식도 일관되게 유지할 수 있어요.

1. 설문 빌더 또는 **퀴즈 빌더**에서 설문이나 퀴즈를 열어요.
2. 슬라이드의 **오른쪽 위**로 커서를 옮겨요.
3. **Clone Slide**(슬라이드 복제)를 클릭해요. 슬라이드 전체가 복제돼요.
4. 새 슬라이드에서 필요한 부분을 수정해요.

{% hint style="info" %}
슬라이드 복제는 폼에서는 사용할 수 없어요.
{% endhint %}

## 자주 묻는 질문

### 복제 기능은 폼, 설문, 퀴즈에서 모두 쓸 수 있나요?
네. 요소 복제는 폼, 설문, 퀴즈에서 모두 쓸 수 있어요. 슬라이드 복제는 설문과 퀴즈에서만 쓸 수 있어요.

### 복제본은 어디에 만들어지나요?
원본 요소나 슬라이드 바로 아래에 만들어져요.

### 복제한 요소에도 유효성 검사와 스타일이 그대로 유지되나요?
네. 필수 항목 설정, 유효성 검사 규칙, 스타일 같은 설정이 복제본에도 유지돼요. 복제한 뒤에는 내용을 확인하고 필요한 부분을 조정하세요.

### 같은 요소를 여러 번 복제할 수 있나요?
네. 한 요소를 복제할 수 있는 횟수에 정해진 제한은 없어요.

### 실수로 복제한 요소를 지우려면 어떻게 하나요?
요소나 슬라이드 위에 마우스를 올리고 **삭제**(휴지통 아이콘)를 클릭하세요.
