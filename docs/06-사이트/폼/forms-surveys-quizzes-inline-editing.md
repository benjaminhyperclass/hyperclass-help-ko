# 폼·설문·퀴즈 인라인 편집으로 더 빠르게 만들기

인라인 편집기를 쓰면 폼 빌더 미리보기 화면에서 바로 텍스트를 고칠 수 있어요. 옆쪽 설정 패널을 열지 않고도 레이블, 질문, 선택지를 빠르고 쉽게 바꿀 수 있어요. ▶ 영상 [6강 48:41](https://www.youtube.com/watch?v=yyvk6kgvbXw&t=2921s)

## 인라인 편집기란?

인라인 편집기(Inline Editor)는 폼, 설문, 퀴즈 안의 텍스트 필드, 레이블, 선택지를 라이브 미리보기에서 바로 클릭해 고치는 기능이에요. 요소마다 설정 패널로 이동할 필요가 없어요. 바꾸고 싶은 텍스트를 클릭해서 입력하면 변경 내용이 바로 반영돼요.

![인라인 편집기로 미리보기에서 텍스트를 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043960220/original/vej4i6qWtU1aqmHj3orNKQ2dSFNYfRQt0Q.png?1742933694)

## 인라인 편집기의 장점

불필요한 단계를 줄여 주기 때문에 더 직관적으로 편집할 수 있어요.

- 설정 패널을 열지 않고 바로 클릭해서 편집할 수 있어요.
- 빌더 안에서 변경 내용을 실시간으로 미리 볼 수 있어요.
- 플레이스홀더, 버튼 레이블, 객관식 선택지처럼 자주 고치는 요소를 빠르게 편집할 수 있어요.
- 폼, 설문, 퀴즈를 같은 방식으로 편집할 수 있어요.
- 번거로움이 줄어 폼을 더 빨리 만들 수 있어요. 수정이 잦은 팀에 특히 좋아요.

## 문자, 제목, TnC를 더 다양하게 꾸미기

서식을 활용하면 별도 코드 없이도 글이 더 읽기 쉬워지고 브랜드 느낌도 맞출 수 있어요. 입력하는 자리에서 바로 강조와 크기를 적용하고, 미리보기로 확인해 보세요.

**적용할 수 있는 서식**

- **문자**와 **제목**: 굵게, 기울임, 밑줄, 글꼴 크기, 색상- **TnC**(이용 약관): 같은 인라인 편집기로 편집할 수 있고, 플레이스홀더 텍스트도 포함돼요.

**사용 방법**

1. 빌더에서 **문자**, **제목**, **TnC** 요소 중 하나를 선택해요.
2. 내용을 클릭하면 인라인 편집기 툴바가 나타나요.
3. 굵게, 크기, 색상 같은 서식을 적용한 뒤 미리보기에서 확인해요.

![인라인 편집기 툴바로 서식을 적용하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064142301/original/EVhl-gG9NocJOXkRMEoq8c-051TCtXJePA.gif?1770190954)

## 모바일 전용 텍스트

작은 화면에 맞게 문구를 다듬으면 내용이 더 잘 전달되고 전환율도 높아져요. 공간이 좁으니 제목을 더 짧게 쓰거나 다른 플레이스홀더를 써 보세요.

**작동 방식**

- 기기 전환 토글에서 **모바일**을 선택한 다음 모바일 텍스트를 편집해요.
- 데스크톱과 모바일 콘텐츠는 따로 관리돼서 서로 덮어쓰지 않아요.
- 대체 동작: 모바일 텍스트가 비어 있으면 데스크톱 텍스트가 표시되거나 아무것도 표시되지 않아요.
## 인라인 편집기 사용 방법

클릭하고 입력하기만 하면 바로 반영되는 방식으로 빌더에서 직접 수정할 수 있어요.

1. 폼·설문 빌더나 **퀴즈 빌더**를 열어요.
   - **사이트 > 폼**으로 이동해서 빌더를 열어요. 설문이나 퀴즈라면 해당하는 메뉴에서 열어요.
2. 바꾸고 싶은 텍스트를 클릭해요.
   - 레이블, 플레이스홀더, 드롭다운 선택지, 라디오 버튼, 버튼 텍스트 등을 찾아 텍스트를 클릭하세요.

   ![편집할 텍스트를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071190534/original/Y8q5wowFpha93Zymj8hFHSwMjpDV_2N42A.png?1778638890)

3. 입력해서 텍스트를 바꿔요.
   - 입력을 시작하면 기존 텍스트가 바뀌고, 변경 내용이 미리보기에 바로 나타나요.

4. 다른 요소도 이어서 편집해요.
   - 같은 방법을 반복하세요. 레이블, 객관식 답변, CTA 버튼 등을 편집할 수 있어요.
5. 수정이 끝나면 **저장 후 게시**를 진행해요.
   - **저장**을 클릭해 변경 내용을 확정해요.
   - 폼을 공유할 준비가 되면 **게시**를 클릭해요.

## 인라인 편집이 되는 요소

인라인 편집은 폼과 설문의 주요 요소 전반에서 쓸 수 있어요.

- 텍스트 필드: 필드 레이블과 플레이스홀더 텍스트를 바로 편집해요.
- 드롭다운: 클릭한 뒤 입력해서 드롭다운 선택지를 바꿔요.
- 체크박스와 라디오 버튼: 선택지 레이블을 그 자리에서 수정해요.
- **버튼**: 클릭해서 CTA(행동 유도) 버튼 텍스트를 편집해요.
- 헤더 텍스트와 단락: 설정 사이드바를 열지 않고 문구를 빠르게 고쳐요.

```
수식 안 어디에나 커서를 놓고 바로 편집할 수 있어요. 방향키, Home, End 키도 쓸 수 있어요.
```

## 자주 묻는 질문

### 인라인 편집은 모든 폼 유형에서 쓸 수 있나요?

네. 인라인 편집은 폼, 설문, 퀴즈에서 모두 쓸 수 있어요.

### 인라인 편집으로 무엇을 편집할 수 있나요?

필드 레이블, 플레이스홀더 텍스트, 버튼 레이블, 드롭다운 항목, 체크박스와 라디오 선택지 등을 편집할 수 있어요.

### 설정 패널도 계속 쓸 수 있나요?

네. 고급 설정은 지금도 설정 패널에서 할 수 있어요. 인라인 편집은 더 빠르게 수정하기 위한 추가 방법이에요.

### 인라인 편집을 쓰려면 따로 켜야 하나요?

따로 설정할 필요가 없어요. 모든 사용자가 기본으로 인라인 편집을 사용할 수 있어요.

### 변경 내용이 자동으로 저장되나요?

변경 내용은 실시간으로 보이지만, 반영하려면 **저장**을 클릭해야 해요.
