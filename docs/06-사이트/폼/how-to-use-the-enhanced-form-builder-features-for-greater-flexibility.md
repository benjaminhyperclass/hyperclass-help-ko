# 폼 빌더 레이아웃과 필드 너비 설정 활용하기

폼 빌더에 새 레이아웃 옵션과 필드 너비 설정이 추가됐어요. 이 문서에서는 레이아웃 종류와 필드 너비를 설정하는 방법을 안내해요.

## 새로 추가된 기능

### 1단 레이아웃

기존에 쓰던 기본 레이아웃이에요. 모든 필드를 위에서 아래로 세로로 한 줄씩 배치해요.

### 2단 레이아웃

이전에 인라인 폼이라고 부르던 레이아웃이에요. 필드를 두 열로 나란히 배치해서 균형 있고 간결한 폼을 만들 수 있어요.

### 한 줄 레이아웃

가로 한 줄에 필드를 최대 5개까지 넣을 수 있어요. 군더더기 없이 깔끔한 폼을 만들 때 알맞아요.

### 필드 너비

필드 너비를 퍼센트(%) 단위로 정할 수 있는 기능이에요. 폼 전체 너비에서 각 필드가 차지할 비율을 정하면, 화면 크기에 맞춰 필드 크기도 같은 비율로 달라져요. 반응형 디자인은 물론 다양한 폼 디자인도 만들 수 있어요.

## 사용 방법

1. 대시보드에서 폼 빌더로 이동하세요.
2. 원하는 레이아웃을 고르세요: **1단 레이아웃**, **Two Column**(2단 레이아웃), **Single Line**(한 줄 레이아웃)
3. **Field Width**(필드 너비) 설정으로 각 필드의 크기를 조절하세요.

## 주요 기능과 장점

- 세 가지 레이아웃 옵션: **1단 레이아웃**, **Two Column**, **Single Line** 중에서 폼의 목적과 모양에 맞는 것을 고를 수 있어요.
- **Single Line** 레이아웃: 한 줄에 필드를 최대 5개까지 넣어, 간결한 가로형 폼을 만들 수 있어요.
- **Field Width** 설정: 필드마다 너비를 조절해서 원하는 모양으로 폼을 꾸밀 수 있어요.

{% hint style="info" %}
- 기존 폼을 빌더에서 열면 **Inline Form**(인라인 폼) 옵션이 켜져 있었는지 꺼져 있었는지에 따라 **1단 레이아웃** 또는 **Two Column** 레이아웃이 자동으로 선택돼요.
- 기존 폼은 미리보기에서도 그대로 동작하며, 이전 **Inline Form** 설정을 따라요.
- 현재 **Single Line** 폼에는 필드를 최대 5개까지 넣을 수 있어요.
{% endhint %}
