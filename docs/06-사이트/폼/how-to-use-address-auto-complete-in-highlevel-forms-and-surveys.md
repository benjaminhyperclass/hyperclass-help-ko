# 하이퍼클래스 폼과 설문에서 주소 자동완성 사용하기

주소 자동완성(Address Auto-Complete)이 이제 모든 하이퍼클래스 계정에서 **무료로 무제한** 제공됩니다. 이 기능을 사용하면 리드와 고객이 폼과 설문에서 정확한 주소 정보를 훨씬 쉽게 입력할 수 있어요. 사용자가 주소 필드(Address)에 입력하는 동안 실시간으로 추천 주소가 표시되고, 도로명(Street), 시/도(City), 주(State), 국가(Country), 우편번호(Postal Code) 필드가 자동으로 채워져서 빠르고 정확하며 일관된 데이터 수집이 가능해집니다.

---

## 주소 자동완성이란?

주소 자동완성은 하이퍼클래스 폼과 설문의 일반 주소 필드를 스마트한 예측 검색창으로 바꿔주는 기능이에요. 글로벌 주소 데이터베이스와 연동되어 사용자가 입력하는 즉시 관련 주소를 추천해줌으로써, 폼 작성을 더 빠르고 오류 없이 완료할 수 있게 해줍니다.

정확한 주소 데이터는 워크플로우(Workflow), 세그멘테이션, 리포팅, 배송 기반 액션(Action)에 필수적이에요. 주소 자동완성 기능은 오타를 없애고, 일관된 형식을 보장하며, 폼 작성 속도를 높여서 사용자 경험과 데이터 신뢰도를 동시에 개선해줍니다.

### **스마트 검색 추천**

사용자가 주소 필드에 입력하면, 하이퍼클래스는 실제 주소 데이터를 기반으로 실시간 예측 추천을 제공해요.

### **자동 필드 채우기**

사용자가 드롭다운에서 주소를 선택하면 관련된 모든 필드(도로명, 시/도, 주, 국가, 우편번호)가 자동으로 채워집니다. 이를 통해 형식을 일관되게 유지하고 수동 입력으로 인한 오류를 없앨 수 있어요.

---

## 주소 자동완성의 주요 장점

주소 자동완성 기능은 모든 폼 제출 시 연락처(Contacts) 데이터가 검증되고 일관되며 올바른 형식으로 저장되도록 도와줍니다. 이를 통해 사후 데이터 수정 작업이 줄어들고 사용자 만족도가 높아져요.

- **무료 & 무제한:** 모든 하이퍼클래스 계정에 사용량 제한 없이 기본 포함되어 있어요.

- **데이터 정확도 향상:** 일관되고 검증된 주소 입력을 보장해요.

- **빠른 제출:** 리드와 고객의 입력 부담을 줄여줘요.

- **전환율 향상:** 매끄러운 사용자 경험 덕분에 폼 완료율이 높아져요.

- **리포팅 데이터 품질 향상:** 표준화된 주소 형식으로 자동화 정확도가 개선돼요.

---

## 주소 자동완성 활성화하는 방법

### **주소 필드 추가하기**

`Sites(사이트) → Forms(폼)` (또는 `Surveys(설문)`) 메뉴로 이동해서, 주소 자동완성을 사용하고 싶은 폼의 빌더를 엽니다.

**Form Elements(폼 요소)** 패널에서 **Address(주소)** 필드를 폼 레이아웃으로 드래그하세요. 주소 요소에는 **Updated(업데이트됨)** 표시가 있는데, 이는 자동완성 기능을 지원한다는 뜻이에요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758329/original/1keSyOM9IjxVc9cggUh6vpY5sReynZIdUQ.png?1760147263)

### 주소 필드 설정에 접근하기

주소 필드를 추가한 후 클릭하면 화면 오른쪽에 설정 패널이 열려요.

이 패널에서 주소 입력 방식을 커스터마이즈하고, 자동완성을 활성화하며, 사용자가 반드시 검증된 주소를 선택해야 하는지 여부를 설정할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758336/original/pFSPtlYwSv71eVBrmuOAC8FmwNJFsykfug.png?1760147347)

### 주소 자동완성 활성화하기

설정 패널에서 **Auto-Complete Address(주소 자동완성)** 토글(Toggle)을 찾아 **ON(켜짐)** 으로 전환하세요.

활성화하면 일반 주소 입력창이 스마트 검색창으로 바뀌어서, 사용자가 입력하는 대로 정확한 주소를 추천해줍니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758423/original/LW7dk4ZxDjLJEfzjjsy-vKEb3AyAzSizFQ.png?1760147656)

### 주소 선택을 필수로 설정하기

사용자가 검증된 주소만 제출하도록 하고 싶다면, **Mandatory to Select Address in Search Bar(검색창에서 주소 선택 필수)** 토글을 **ON(켜짐)** 으로 전환하세요.

이 옵션을 켜면 사용자는 폼을 제출하기 전에 반드시 추천된 주소 중 하나를 선택해야 해요. 꺼두면(OFF) 사용자가 직접 주소를 입력할 수도 있습니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758426/original/RxZTM2OVNrnwIzCdd8ip3sbi6f63t_is_w.jpeg?1760147670)

### 폼 미리보기

폼 빌더 오른쪽 상단의 **Preview(미리보기)** 를 클릭해서, 실제 폼에서 주소 필드가 어떻게 표시되는지 확인하세요.

이제 주소 필드는 **검색창** 형태로 표시되며, 사용자가 입력을 시작하면 즉시 추천 주소가 나타납니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758436/original/zGD2LeIC6RMs_jDGsds9JgI1fDnGEbLNOQ.jpeg?1760147782)

### 실시간 주소 추천 테스트하기

미리보기 화면에서 주소 필드에 몇 글자(예: 도로명 일부)를 입력해보세요.

검색창 아래에 예측 추천 목록이 나타나고, 이 중 하나를 선택하면 도로명, 시/도, 주, 국가, 우편번호 필드가 자동으로 채워집니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055758434/original/_pK5PJkq8QF9qLUAgJBfLtgDmsd7GQeIrA.jpeg?1760147771)

### 저장 및 발행하기

자동완성이 정상적으로 작동하는 것을 확인했다면 **Save(저장)** 를 클릭해서 변경 사항을 적용하세요.

발행(Published)한 이후에는 폼을 작성하는 모든 방문자가 내장된 자동완성 기능을 통해 빠르고 정확하게 주소를 입력할 수 있게 됩니다.

## 자주 묻는 질문

**Q: 주소 자동완성이 아직 유료 기능인가요?**

아니요. 이제 모든 하이퍼클래스 계정에서 완전히 무료로, 무제한 사용할 수 있어요.

**Q: 사용자가 직접 주소를 입력하도록 계속 허용할 수 있나요?**

네. 수동 입력을 원하신다면 자동완성 토글을 비활성화(Disable)하시면 됩니다.

**Q: 주소 자동완성은 전 세계적으로 작동하나요?**

네. 대부분의 국가와 우편번호 형식을 지원해요.

**Q: 기존에 만들어둔 폼에도 자동완성이 자동으로 적용되나요?**

아니요. 각 폼이나 설문을 열어서 토글을 직접 활성화해주셔야 해요.

**Q: 사용자가 추천 주소를 선택하지 않으면 어떻게 되나요?**

"Mandatory to Select Address in Search Bar(검색창에서 주소 선택 필수)" 토글이 ON 상태라면 사용자는 반드시 추천 주소 중 하나를 선택해야 폼을 제출할 수 있어요. OFF 상태라면 자유롭게 직접 입력할 수 있습니다.

**Q: 자동완성이 기존 연락처 데이터를 덮어쓰나요?**

아니요. 제출된 데이터는 기존에 설정해둔 연락처 업데이트 규칙과 매핑 설정을 그대로 따릅니다.
