# 폼과 설문의 이메일 인증 기능

폼과 설문에 이메일 인증 기능이 추가됐어요. 참여자가 폼이나 설문 안에서 바로 자신의 이메일 주소를 인증할 수 있어서, 수집한 데이터를 더 믿을 수 있고 참여자도 더 편하게 쓸 수 있어요.

## 이메일 인증 버튼

![이메일 입력란 옆에 표시된 이메일 인증 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027788086/original/dXp-CiWScwGbgG-pSkv_exCpXDB_S2vF9Q.png?1718692402)

폼과 설문의 이메일 입력란 옆에 **Verify Email**(이메일 인증) 버튼이 표시돼요. 이 버튼은 참여자가 올바른 형식의 이메일 주소를 입력한 뒤에만 보여요. 버튼을 클릭하면 입력한 이메일 주소로 인증 코드가 발송되고, 인증 절차가 시작돼요.

## 인증 코드

![인증 코드를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027788179/original/G5Et7r-kk6CJ-mHOOLDbdMgyP3B5sVZ1IQ.png?1718692530)

참여자가 **Verify Email** 버튼을 클릭하면 고유한 인증 코드가 이메일로 도착해요. 참여자는 이 코드를 폼이나 설문에 다시 입력해서 이메일 주소를 확인해요. 이 과정을 거치면 입력한 이메일 주소가 올바르고, 참여자가 실제로 받아 볼 수 있는 주소라는 점을 확인할 수 있어서 데이터가 더 정확해져요.

## 작동 방식

1. 이메일 입력: 참여자가 폼이나 설문의 이메일 입력란에 이메일 주소를 입력해요.
2. 인증 안내: 올바른 이메일 주소를 입력하면 이메일 입력란 옆에 **Verify Email** 버튼이 나타나요.
3. 인증 코드 발송: 참여자가 이 버튼을 클릭하면 고유한 인증 코드가 해당 이메일 주소로 발송돼요.
4. 인증 코드 입력: 참여자가 받은 코드를 폼이나 설문에 다시 입력해 이메일 주소를 인증해요.
5. 인증 완료: 코드를 올바르게 입력하면 이메일 주소가 인증되고, 제출 데이터에 인증 완료로 표시돼요.

## 자주 묻는 질문

### 폼과 설문에서 이메일 인증 기능을 왜 사용해야 하나요?
이메일 인증 기능을 쓰면 수집한 이메일 주소가 유효한지 확인할 수 있어서, 가짜이거나 잘못된 제출이 줄어들어요. 그 결과 리드의 품질이 좋아지고, 마케팅 캠페인에 쓸 데이터도 더 믿을 수 있어요.

### 이메일 인증은 데이터 정확도를 어떻게 높이나요?
참여자가 받은 편지함으로 전송된 고유 코드를 입력해야 하므로, 입력한 이메일 주소가 실제로 존재하고 받아 볼 수 있는 주소인지 확인할 수 있어요. 부정확하거나 가짜인 이메일 주소가 수집될 가능성이 줄어서 마케팅을 더 정확하고 효과적으로 할 수 있어요.

### 사용자에게 발송되는 인증 이메일을 수정할 수 있나요?
지금은 일관성과 안정성을 위해 인증 이메일이 정해진 형식으로 발송돼요. 앞으로 업데이트에서 수정 옵션이 추가될 수도 있으니 소식을 기다려 주세요.

### 폼과 설문에서 이메일 인증 기능을 켜려면 어떻게 하나요?
폼이나 설문의 설정으로 이동해서 이메일 필드에 있는 이메일 인증 옵션을 켜세요. 그러면 폼과 설문의 이메일 입력란 옆에 **Verify Email** 버튼이 자동으로 나타나요.

### 참여자가 이메일 인증을 끝내지 않으면 어떻게 되나요?
참여자가 이메일 인증을 완료하지 않으면 제출이 접수되지 않을 수 있어요. 이렇게 하면 인증된 이메일 주소가 있는 제출만 수집되어 데이터의 신뢰도를 지킬 수 있어요.

### 어떤 이메일 주소가 인증됐는지 확인하려면 어떻게 하나요?
폼과 설문의 제출 데이터에 **Verified Email**(인증된 이메일) 필드가 있어요. 이메일 인증에 성공하면 이 필드에 **예**로 표시되므로, 인증된 이메일 주소를 쉽게 구분할 수 있어요.
