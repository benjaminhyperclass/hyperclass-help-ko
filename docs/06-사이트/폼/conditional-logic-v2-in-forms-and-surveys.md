# 폼의 조건부 로직 V2

조건부 로직 V2를 쓰면 고객의 답변에 따라 필드를 보이거나 숨기고, 다른 페이지로 보내고, 메시지를 보여 주고, 리드를 자격 미달로 처리하는 폼을 만들 수 있어요. 이 문서에서는 사용 방법과 주요 기능, 지원하는 필드를 안내해요.

## 폼의 조건부 로직 V2란?

조건부 로직 V2를 쓰면 하이퍼클래스 폼이 고객의 답변과 상품 선택에 맞춰 반응해요. 필드를 보이거나 숨기고, 고객을 다른 페이지로 보내고, 사용자 지정 메시지를 보여 주고, 리드를 자격 미달로 처리할 수 있어요. 상품 단위 조건부 로직을 쓰면 **Sell Products**(상품 판매) 요소 안의 개별 상품과 변형(variant)을 보이거나 숨기는 것도 조절할 수 있어요.

---

## 조건부 로직 V2의 장점

조건부 로직 V2는 고객 응답에 따라 필드, 상품, 결과를 자동으로 바꿔서 폼을 더 인터랙티브하게 만들어 줘요.

- 맞춤형 폼: 고객의 답변에 맞는 필드만 보여 줘요.
- 더 정확한 리드 자격 검증: 기준에 맞지 않는 리드를 자동으로 자격 미달 처리해요.
- 상품 노출 조절: 개별 상품과 변형을 보이거나 숨길 수 있어요.
- 유연한 리디렉션: 제출 후 고객을 알맞은 페이지로 보내요.
- 간편한 폼 관리: 하나의 폼으로 여러 고객 상황을 처리해요.

---

## 사용할 수 있는 조건부 로직 액션

조건부 로직 V2에는 고객이 특정 조건을 충족했을 때 실행할 액션이 네 가지 있어요.

- **URL로 리디렉션**: 고객을 지정한 웹페이지로 보내요.
- **Display Custom Message**(사용자 지정 메시지 표시): 제출 후 맞춤 메시지를 보여 줘요.
- **Disqualify Lead**(리드 자격 박탈): 자격 미달 조건에 해당하는 리드가 다음 단계로 진행하지 못하게 막아요.
- **Show/Hide Fields**(필드 표시/숨기기): 폼 필드와 지원되는 요소를 동적으로 보이거나 숨겨요.

{% hint style="info" %}
앞의 세 가지 액션은 폼을 제출할 때 적용돼요. **Show/Hide Fields**는 고객이 폼을 채우는 동안 바로바로 바뀌어요.
{% endhint %}

---

## 상품 단위 조건부 로직 사용하기

상품 단위 조건부 로직을 쓰면 고객의 선택에 따라 맞춤형 주문 폼을 만들 수 있어요. 개별 상품을 조건으로 쓸 수 있고, **Sell Products** 요소 안에서 어떤 상품이나 변형을 보여 줄지 조절할 수 있어요.

### 상품을 IF 조건으로 사용하기

개별 상품은 네 가지 액션을 모두 실행하는 조건이 될 수 있어요.

- **URL로 리디렉션**: 선택한 상품에 따라 고객을 다른 페이지로 보내요.
- **Display Custom Message**: 상품과 관련된 메시지를 보여 줘요.
- **Disqualify Lead**: 상품 선택에 따라 리드를 자격 미달 처리해요.
- **Show/Hide Fields**: 선택한 상품에 맞는 필드나 요소를 보여 줘요.

예를 들어 고객이 엔터프라이즈 패키지를 선택하면 전용 상담 페이지로 보낼 수 있어요.

### 개별 상품과 변형 보이기·숨기기

**Show/Hide Fields** 액션은 세 단계로 노출 범위를 정할 수 있어요.

- **Sell Products** 요소 전체: 요소 전체를 보이거나 숨겨요.
- 개별 상품: **Sell Products** 요소는 그대로 두고 특정 상품만 조절해요.
- 상품 변형: 한 상품 안의 특정 변형만 보이거나 숨겨요.

예를 들어 고객이 "Ecommerce Website"를 선택하면 해당 웹사이트 패키지만 보여 주고 관련 없는 상품은 숨길 수 있어요.

{% hint style="warning" %}
상품 단위 조건부 로직은 이전 폼 빌더와 새 폼 빌더 모두에서 작동해요. **Sell Products** 요소 전체를 보이거나 숨기는 기존 기능도 그대로 쓸 수 있어요.
{% endhint %}

## 지원하는 필드와 연산자

조건부 로직 V2는 여러 필드 유형과 비교 연산자를 지원해요. 쓸 수 있는 연산자는 선택한 필드에 따라 달라요.

| 필드 유형 | 지원하는 연산자 |
| --- | --- |
| **Text**(텍스트) | **Equal to**(같음), **같지 않음**, **Contains**(포함), **포함하지 않음**, **Starts with**(~로 시작), **Ends with**(~로 끝남), **Is empty**(비어 있음), **Is filled**(입력됨) |
| **Number**(숫자), **Monetary**(금액), **Score**(점수) | **Equal to**, **같지 않음**, **초과**, **Less than**(미만), **Between**(사이), **Is empty**, **Is filled** |
| **Date**(날짜) | **Equal to**, **Before**(이전), **After**(이후), **Between**, **Is empty**, **Is filled** |
| **단일 드롭다운** | **Is equal to**(다음과 같음), **다음과 같지 않음**, **Is empty**, **Is filled** |
| **Multi Dropdown**(다중 드롭다운), **Checkbox**(체크박스) | **Is equal to**, **다음과 같지 않음**, **Is empty**, **Is filled** |
| **Terms & Conditions**(이용약관) | **Is checked**(체크됨), **Is not checked**(체크 안 됨) |
| **File Upload**(파일 업로드), **서명** | **Is empty**, **Is filled** |

상품 선택도 IF 조건으로 쓸 수 있어요. 보이거나 숨길 대상으로는 **Text**, **HTML**, **이미지**, **결제**, **Sell Products** 요소를 쓸 수 있어요.

{% hint style="info" %}
**Between** 연산자는 양쪽 경계값을 모두 포함해요.
{% endhint %}

## 조건부 로직 규칙이 적용되는 순서

하이퍼클래스는 조건부 규칙을 정해진 순서대로 평가해요. 규칙 우선순위를 알아 두면 액션끼리 충돌하거나 필드·상품이 예상과 다르게 보이는 일을 막을 수 있어요.

- 제출 액션: **URL로 리디렉션**, 사용자 지정 메시지, 리드 자격 박탈 규칙 중 처음 조건에 맞는 규칙 하나만 적용돼요.
- **Show/Hide Fields**: 나중에 조건에 맞는 규칙이 앞선 노출 규칙을 덮어쓸 수 있어요.
- AND 조건: 모든 조건이 맞아야 해요.
- OR 조건: 조건 중 하나 이상이 맞으면 돼요.

한 규칙 안에서는 AND와 OR 연결을 함께 쓸 수 없어요.

예를 들어 한 규칙이 상품을 보여 주고, 나중에 조건에 맞는 다른 규칙이 그 상품을 숨기면 나중 규칙에 따라 숨겨져요.

## 캘린더 예약 폼에서의 조건부 로직

조건부 로직 V2는 지원되는 캘린더 예약 흐름의 사용자 지정 폼에서도 쓸 수 있어요. 이를 통해 고객을 선별하고 예약 결과를 맞춤으로 설정할 수 있어요.

- 보이기/숨기기 규칙으로 필드 노출을 조절해요.
- 자격 미달 조건에 해당하면 예약이 만들어지지 않고 결제도 받지 않아요.
- 리디렉션과 사용자 지정 메시지로 예약 확인 화면을 맞춤 설정할 수 있어요.

조건부 리디렉션이나 메시지를 쓰려면 캘린더 확인 설정에서 **Use custom form rules**(사용자 지정 폼 규칙 사용)를 선택하세요.

자세한 내용은 [캘린더에 사용자 지정 폼 추가하기](../../04-캘린더-예약/Customizing-Calendars/adding-custom-forms-to-calendars.md)를 참고하세요.

## 조건부 로직 V2 설정하기

설정을 제대로 해 두면 고객의 답변에 따라 알맞은 필드, 상품, 제출 결과가 나타나요.

1. **사이트 > 폼**으로 이동해 폼을 열거나 새로 만드세요.
2. **폼 빌더**에서 **Conditional Logic**(조건부 로직)을 클릭하세요.

   ![폼 빌더에서 조건부 로직 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084139706/original/-MbWvRG6fk5OYkAfbk6Hs4CZqTQtT_cxTg.png?1792926983)
3. **Add New Condition**(새 조건 추가)을 선택하세요.
4. **액션 선택**에서 **URL로 리디렉션**, **Display Custom Message**, **Disqualify Lead**, **Show/Hide Fields** 중 하나를 고르세요.

   ![액션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084139720/original/I05L517P6M5UfFuQdmLHNQ3e731Ge9Gb6Q.png?1792927021)
5. **IF**(조건) 항목에서 필드 또는 지원되는 상품, 연산자, 값을 선택하세요.

   ![IF 조건 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084139728/original/PqJuVsSia-4_RHoWkWbbFW_C08RsMQFfxQ.png?1792927063)
6. **THEN**(동작) 항목에서 실행할 동작을 설정하세요. 필드 보이기, 상품 숨기기, 사용자 리디렉션, 메시지 표시 등을 고를 수 있어요.
7. 조건을 저장한 뒤 폼을 미리보기로 열어 의도한 대로 작동하는지 확인하세요.

### 상품 단위 노출 설정하기

개별 상품이나 변형의 노출을 조절하려면 다음과 같이 하세요.

1. **Conditional Logic > Add New Condition**을 여세요.
2. **Show/Hide Fields**를 선택하세요.

   ![Show/Hide Fields 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084139774/original/Gr7NWl5lVUsF7gDa-ypC0x1Td7Msr-GQFg.png?1792927274)
3. 고객 응답이나 상품 선택으로 조건을 정하세요.
4. **Sell Products** 요소 전체, 개별 상품, 특정 변형 중 대상을 선택하세요.
5. 선택한 대상이 나타나게 할지, 사라지게 할지 설정하세요.
6. 규칙을 저장하고 테스트하세요.

## 자주 묻는 질문

### 개별 상품으로 조건부 액션을 실행할 수 있나요?
네. 상품 선택으로 **URL로 리디렉션**, **Display Custom Message**, **Disqualify Lead**, **Show/Hide Fields**를 실행할 수 있어요.

### **Sell Products** 요소 전체를 숨기지 않고 특정 상품만 숨길 수 있나요?
네. **Sell Products** 요소는 그대로 보이게 두고 개별 상품만 조절할 수 있어요.

### 특정 상품 변형만 보이거나 숨길 수 있나요?
네. 개별 상품 변형마다 조건부 노출을 설정할 수 있어요.

### 상품 단위 조건부 로직이 이전 폼 빌더에서도 작동하나요?
네. 이전 폼 빌더와 새 폼 빌더 모두에서 지원돼요.

### 조건부 규칙이 여러 개 맞으면 어떻게 되나요?
제출 액션은 처음 조건에 맞는 규칙이 적용돼요. **Show/Hide Fields** 규칙은 나중에 조건에 맞는 규칙이 앞선 규칙을 덮어쓸 수 있어요.

### 조건부 규칙이 저장되지 않아요.
필수 필드, 연산자, 값, 액션 설정이 모두 입력되어 있는지 확인하세요.
