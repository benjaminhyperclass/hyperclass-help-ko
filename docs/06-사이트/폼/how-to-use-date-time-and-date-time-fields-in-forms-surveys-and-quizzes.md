# 폼·설문·퀴즈에서 날짜, 시간, 날짜와 시간 필드 사용하기

폼, 설문, 퀴즈에서 날짜만, 시간만, 또는 날짜와 시간을 함께 받고 싶을 때 쓰는 필드예요. 응답자가 무엇을 입력할지 고르고, 표시 형식·기본값·선택 가능 범위를 원하는 대로 정할 수 있어요. 잘못된 입력이 줄고 제출된 정보도 더 일관되게 모여요. 이미 만들어 둔 폼, 설문, 퀴즈를 다시 만들 필요 없이 그대로 적용할 수 있어요.

## 날짜와 시간 필드란?

날짜와 시간 필드는 날짜, 시간, 또는 둘을 함께 받을 수 있는 입력 요소예요. 수집 유형마다 표시 형식, 선택 가능 범위, 기본값 같은 설정이 있어서 응답자가 입력하는 방식을 조절할 수 있어요. 유형을 알맞게 고르면 비즈니스에 필요한 정보만 받을 수 있어요.

수집 유형은 세 가지예요.

- 날짜(**Date**): 시간 없이 캘린더 날짜만 받아요. 생일, 갱신일, 행사 날짜, 마감일을 받을 때 알맞아요.
- 시간(**Time**): 날짜 없이 특정 시간만 받아요. 연락받고 싶은 시간, 영업시간, 가능한 시간대를 받을 때 알맞아요.
- 날짜와 시간(**Date & Time**): 캘린더 날짜와 특정 시간을 함께 받아요. 원하는 행사 일시, 예정된 후속 연락 일시처럼 날짜와 시간이 모두 필요한 정보를 받을 때 알맞아요.

개선된 날짜 필드와 새로 추가된 시간, 날짜와 시간 필드 유형은 새 폼·설문·퀴즈와 기존 폼·설문·퀴즈 모두에서 쓸 수 있어요.

## 날짜, 시간, 날짜와 시간 필드의 장점

이 필드를 쓰면 날짜와 시간을 받는 방식을 더 세밀하게 정할 수 있어요. 응답 형식이 통일되고 직접 고쳐야 할 일도 줄어들어요. 입력 유형과 제한을 알맞게 설정하면 응답자는 더 쉽게 입력하고, 데이터는 더 정확해져요.

- 유연한 데이터 수집: 필요한 정보에 따라 날짜, 시간, 또는 둘 다 받을 수 있어요.
- 입력값 검증 강화: 선택할 수 있는 날짜와 시간을 제한해서 의도한 범위를 벗어난 응답을 막아요.
- 날짜 형식 선택: 원하는 날짜 형식과 구분 기호로 보여 줄 수 있어요.
- 시간 형식 선택: 24시간제나 AM/PM 형식 중에서 골라 표시할 수 있어요.

## 날짜와 시간 필드 설정

**Date & Time** 필드는 날짜 입력과 시간 입력을 하나로 합친 요소예요. 후속 연락을 원하는 날짜와 시간처럼, 한 일정에 대해 두 값을 모두 받아야 할 때 유용해요. 두 입력을 한 필드로 묶으면 날짜와 시간 제한을 함께 관리할 수 있고, 데이터 수집도 간단해져요.

다음 설정을 쓸 수 있어요.

| 설정 | 설명 |
| --- | --- |
| **Date Format**(날짜 형식) | 날짜를 표시하는 방식을 MM.DD.YYYY, YYYY.MM.DD, DD.MM.YYYY 중에서 골라요. |
| **Date Separator**(날짜 구분 기호) | 날짜 구성 요소를 나누는 기호를 하이픈(-), 슬래시(/), 마침표(.) 중에서 골라요. |
| **Time Format**(시간 형식) | 24시간제와 AM/PM 형식 중에서 골라요. |
| **Default Time**(기본 시간) | **None**(없음), **Current**(현재), **Custom**(사용자 지정) 중에서 골라 기본 시간 값을 정해요. |
| **Allowed Date Range**(허용 날짜 범위) | 모든 날짜, 미래 날짜만, 과거 날짜만, 특정 기간 안의 날짜만 중에서 허용 범위를 정해요. |
| **Available Days**(선택 가능 요일) | 응답자가 선택할 수 있는 요일을 지정해요. |
| **Allowed Time Range**(허용 시간 범위) | 응답자가 선택할 수 있는 시간 범위를 정해요. |
| **Picker Settings**(선택기 설정) | 사용할 수 있는 캘린더·시간 선택기 옵션을 설정해요. 선택기 팝업을 끄고 직접 입력하게 할 수도 있어요. |

예를 들어 서비스 문의 폼에서 **Date & Time** 필드를 쓰면, 고객이 원하는 후속 연락 일시를 받으면서 선택 가능한 날짜를 비즈니스의 운영 요일과 시간으로 제한할 수 있어요.

## 일반 필드 설정

일반 설정은 날짜, 시간, 날짜와 시간 필드가 폼·설문·퀴즈에서 어떻게 보이고 동작할지 정해요. 레이블, 플레이스홀더, 필드 속성을 분명하게 설정하면 응답자가 어떤 정보를 입력해야 하는지 알기 쉽고, 필드가 데이터 수집 요건에 맞게 동작해요.

빌더에 **Date & Time** 요소를 추가한 뒤 선택하면 오른쪽 사이드바에서 **일반 설정** 탭을 열 수 있어요.

| 설정 | 설명 |
| --- | --- |
| **Field Type**(필드 유형) | 필드가 날짜, 시간, 날짜와 시간 중 무엇을 수집할지 골라요. |
| **Label**(레이블) | 수집할 정보를 알려 주도록 필드 위에 표시할 이름을 입력해요. |
| **Label Alignment**(레이블 정렬) | 레이블 위치를 조정하거나 폼의 기본 정렬을 그대로 써요. |
| **Placeholder**(플레이스홀더) | 값을 입력하기 전에 입력란 안에 보이는 안내 문구를 입력해요. |
| **Short Label**(짧은 레이블) | 추가 설명이 필요할 때 짧은 레이블을 넣어요. 선택 사항이에요. |
| **Query Key**(쿼리 키) | 필드를 구분하는 고유 쿼리 키를 확인해요. |
| **Field Width**(필드 너비) | 폼에서 쓸 수 있는 공간 대비 필드 너비를 퍼센트로 조정해요. |
| **Required**(필수) | 응답자가 폼을 제출하기 전에 반드시 입력하게 해요. |
| **Hidden**(숨김) | 필요할 때 응답자에게 필드를 보이지 않게 해요. |
| **고급 설정** | 해당하는 커스텀 필드 설정을 포함한 추가 필드 속성을 열어요. |

{% hint style="warning" %}
커스텀 필드를 저장한 뒤에는 선택한 수집 유형(날짜, 시간, 날짜와 시간)을 바꿀 수 없어요. 저장하기 전에 올바른 유형을 골랐는지 확인하세요.
{% endhint %}

## 날짜, 시간, 날짜와 시간 필드 설정하는 방법

**Date & Time** 요소를 추가하고 설정하면 응답자가 필요한 형식으로, 허용된 범위 안에서 정보를 입력할 수 있어요. 새 폼·설문·퀴즈는 물론 기존 폼·설문·퀴즈에도 바로 추가할 수 있고, 세부 설정은 오른쪽 사이드바에서 해요.

1. 하이퍼클래스 서브 계정에서 **사이트**로 이동한 뒤 **폼**, **설문**, **퀴즈** 중 하나를 선택하세요.
2. 새 폼, 설문, 퀴즈를 만들거나 기존 항목을 빌더에서 여세요.
3. 왼쪽 사이드바에서 **Quick Add**(빠른 추가)를 선택하고, **Other Elements**(기타 요소) 아래에서 **Date & time** 요소를 찾으세요.
4. **Date & time** 요소를 캔버스에서 원하는 위치로 끌어다 놓으세요.
5. 추가한 필드를 선택하고 오른쪽 사이드바에서 **일반 설정** 탭을 여세요.
6. **이 필드가 수집할 항목을 선택하세요** 아래에서 응답자에게 받을 정보에 맞게 **Date**(날짜), **Time**(시간), **Date & time**(날짜와 시간) 중 하나를 고르세요.

   ![수집할 항목을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083555345/original/dOV1Qf8hATN88m7Ju3hIRHnKaMnabxch6Q.png?1792186059)
7. **Label**, **Placeholder**, **Field Width** 등 필요한 속성을 설정하세요. 응답자가 꼭 입력해야 하면 **Required**를 켜세요.
8. **Field settings**(필드 설정) 탭을 열고 선택한 필드 유형에 해당하는 날짜·시간 옵션을 설정하세요. 형식, 구분 기호, 기본값, 허용 범위, 선택 가능 요일, 선택기 동작 등이 있어요.

   ![필드 설정 탭의 날짜·시간 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083555348/original/FOIgKzV6nk8BMNKilo0ZgMc6RiRK6FeDXw.png?1792186083)
9. 설정을 확인하고 빌더 오른쪽 위의 **저장**을 클릭하세요. 커스텀 필드를 저장한 뒤에는 선택한 필드 유형을 바꿀 수 없으니 유의하세요.

## 자주 묻는 질문

### 날짜와 시간 필드를 추가하면 하이퍼클래스 캘린더에 예약이 자동으로 잡히나요?
아니요. 날짜와 시간 필드는 응답자가 원하는 날짜와 시간을 수집할 뿐, 예약을 자동으로 잡지는 않아요. 예약 일정을 잡으려면 그에 맞는 캘린더 기능이 필요해요.

### 날짜 필드를 저장한 뒤에 시간이나 날짜와 시간 필드로 바꿀 수 있나요?
아니요. 커스텀 필드를 저장한 뒤에는 수집 유형을 바꿀 수 없어요. 다른 수집 유형이 필요하면 새 커스텀 필드를 만들어야 해요.

### 이미 만든 날짜, 시간, 날짜와 시간 커스텀 필드를 다시 쓸 수 있나요?
네. 선택한 오브젝트와 빌더에서 해당 커스텀 필드를 쓸 수 있다면, 중복해서 만들 필요 없이 **Add Object Fields**(오브젝트 필드 추가)에서 추가하면 돼요.

### 선택할 수 있는 날짜를 제한하면 폼·설문·퀴즈가 제출을 받는 기간도 제한되나요?
아니요. 날짜 제한은 응답자가 필드에 입력할 수 있는 날짜만 제어해요. 제출을 받는 기간은 해당 일정 설정에서 따로 관리해요.

### 한 응답자에게 원하는 날짜나 시간을 여러 개 받을 수 있나요?
네. 날짜, 시간, 날짜와 시간 필드를 여러 개 추가하고 '1순위', '2순위'처럼 레이블을 다르게 지정하면 각각 따로 응답을 받을 수 있어요.
