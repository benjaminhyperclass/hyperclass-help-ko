# 폼과 설문에서 출처 필드 사용하기

하이퍼클래스 폼과 설문의 **출처** 필드를 쓰면 응답자에게 보이지 않게 미리 정해 둔 출처 값을 제출 내용에 저장할 수 있어요. 리드가 어디서 들어왔는지 확인하고 **연락처 출처** 값을 일관되게 관리할 때 유용해요.

---

## 출처 필드란?

**출처** 필드는 폼이나 설문 제출 내용에 미리 정한 출처 값을 함께 저장해 줘요. 이 필드는 응답자에게 보이지 않아서, 하이퍼클래스가 백그라운드에서 출처 정보를 자동으로 가져와요.

제출이 끝나면 이 값은 제출 내용에 표시되고, 해당 연락처의 **연락처 출처**로도 들어가요.

---

## 출처 필드의 주요 장점

응답자에게 출처를 직접 입력하게 하지 않아도 리드 출처 정보를 일정하게 유지할 수 있어요.

- **출처 자동 저장:** 미리 정한 출처 값을 백그라운드에서 저장해요.
- **연락처 정리:** **연락처 출처** 값을 통일하는 데 도움이 돼요.
- **URL로 유연하게 추적:** URL 파라미터로 설정된 출처를 덮어쓸 수 있어요.
- **폼과 설문 재사용:** 폼이나 설문 하나로 접속 링크에 따라 서로 다른 출처 값을 받을 수 있어요.

---

## URL로 출처 값 지정하기

같은 폼이나 설문을 여러 캠페인이나 채널에서 함께 쓸 때 URL로 출처 값을 지정하면 편해요.

폼이나 설문 URL 뒤에 `source` 쿼리 파라미터를 붙이세요.

`?source=alternative_source`

빌더에 설정한 출처 값과 URL의 출처 값이 다르면, 해당 제출에서는 URL의 값이 빌더에 설정한 출처 값을 덮어써요.

{% hint style="warning" %}
**출처** 필드는 **첫 번째 어트리뷰션**, **최근 어트리뷰션**, **세션 소스**, `utm_source` 같은 하이퍼클래스 어트리뷰션 데이터와 달라요.
{% endhint %}

---

## 출처 필드 설정하기

설정을 제대로 해 두면 제출할 때마다 원하는 출처 값이 저장돼요. 연락처 폼을 만드는 방법은 [하이퍼클래스에서 연락처 폼 만들기](../../02-연락처/기타/how-to-create-a-contact-form-in-hyperclass.md)를 참고하세요.

1. **사이트 > 폼** 또는 **사이트 > 설문**으로 이동해서 편집할 폼이나 설문을 엽니다.
2. 폼이나 설문에 **출처** 요소를 추가합니다.
3. 하이퍼클래스에 저장할 출처 값을 입력합니다.

   ![출처 요소에 출처 값을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080330759/original/KCKyDGLOw50_F61qwG9k72IxdzOCMBl-yQ.png?1788850572)
4. 폼이나 설문을 저장합니다.
5. 테스트로 응답을 제출합니다.
6. 제출 내용을 열어 출처 값을 확인합니다. 설문 제출 내용을 찾는 방법은 [설문 제출 내용 확인하고 내보내기](../설문/how-to-access-and-export-survey-submissions.md)를 참고하세요.

   ![제출 내용에서 출처 값을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080330917/original/hmnEm1ozp_UFm6rGcKdQtlKvLZeQ4cUQXg.png?1788850726)
7. 해당 연락처 상세 화면을 열어 **연락처 출처**를 확인합니다.

![연락처 상세 화면에서 연락처 출처를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080331193/original/RzytOhZrzby3EWvq6yG0iyusInXsEzWpDQ.png?1788850872)

## 자주 묻는 질문

### 출처와 어트리뷰션 소스는 같은 건가요?
아니요. 출처는 연락처에 저장되는 원본 출처 값이에요. 하이퍼클래스 어트리뷰션은 **첫 번째 어트리뷰션**, **최근 어트리뷰션**, **세션 소스**, UTM 파라미터 같은 별도 데이터를 사용해요. 자세한 내용은 [어트리뷰션 소스 이해하기](../../18-리포팅/understanding-attribution-source.md)를 참고하세요.

### `source`와 `utm_source`는 같은 건가요?
아니요. `source`는 이 문서에서 설명하는 **출처** 필드를 제어해요. `utm_source`는 어트리뷰션 추적에 쓰여요.

### 같은 폼이나 설문에 서로 다른 출처 값을 쓸 수 있나요?
네, 가능해요. URL에 다른 `source` 값을 붙이면 빌더에 설정한 값을 덮어써요.

### 연락처 출처로 연락처를 필터링할 수 있나요?
네, 가능해요. **연락처 출처**는 지원되는 연락처 필터와 리포팅 영역에서 쓸 수 있어요.
