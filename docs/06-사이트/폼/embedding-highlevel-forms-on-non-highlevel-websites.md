# 하이퍼클래스 폼 삽입이란?

하이퍼클래스 폼(Form) 삽입이란, 여러분이 사용하는 웹사이트 편집기를 통해 폼을 웹사이트에 직접 통합하는 것을 의미해요. 이렇게 하면 방문자가 다른 페이지로 이동하지 않고도 폼을 작성할 수 있어요. 덕분에 리드 수집, 고객 문의, 예약 접수 등이 여러분의 브랜드 환경 안에서 끊김 없이 이루어질 수 있어요. 가장 좋은 점은, 여러 플랫폼을 오가거나 여기저기서 설정을 바꿀 필요가 없다는 거예요—하이퍼클래스에서 삽입 코드를 복사해서 웹사이트 편집기에 붙여넣기만 하면 돼요.

## 하이퍼클래스 폼 삽입의 주요 이점

하이퍼클래스 폼을 삽입하면 웹사이트의 참여도와 리드 생성이 크게 향상될 수 있어요. 주요 이점은 다음과 같아요:

- **더 많은 리드 확보**: 하이퍼클래스 폼을 사용하면 사이트에서 직접 방문자 정보를 수집할 수 있어서 리드를 더 쉽게 육성할 수 있어요.
- **크로스 플랫폼 연동**: SquareSpace, Wix, Shopify, WordPress, Duda 등 다양한 웹사이트 플랫폼에서 폼을 사용할 수 있어요.
- **원활한 CRM 동기화**: 수집된 데이터가 하이퍼클래스 CRM과 자동으로 동기화되어 후속 조치와 자동화를 간편하게 진행할 수 있어요.
- **참여도 향상**: 맞춤 설정이 가능한 폼으로 타깃 메시지, 프로모션, 설문을 보여줄 수 있어요.
- **성과 추적**: 하이퍼클래스의 내장 분석 기능을 활용해 폼의 성과를 모니터링하고 최적화할 수 있어요.

## 하이퍼클래스에서 삽입 링크 찾는 방법

하이퍼클래스 폼을 웹사이트에 삽입하려면, 먼저 하이퍼클래스 계정에서 삽입 링크를 찾아야 해요. 이 링크는 여러분이 선택한 웹사이트에 폼이 나타나게 해주는 스크립트를 제공해요. 찾는 방법은 다음과 같아요:

### 폼 빌더 접근하기

대시보드에서 메인 네비게이션 메뉴의 "Sites(사이트)" 섹션으로 이동하세요. 상단 메뉴에 있는 "Forms(폼)" 메뉴를 클릭하면 전체 폼 목록 화면으로 이동해요.

![하이퍼클래스 폼 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080331882/original/ayYeCk3wBGOzzUWIMwROzK9j48lHweorYw.png?1788851382)

### 폼 선택 또는 생성하기

폼을 삽입하려면 목록에서 기존 폼을 선택하거나 새 폼을 만들 수 있어요. 처음부터 시작하는 경우, "+ Add Form(+ 폼 추가)" 버튼을 클릭해서 폼을 만들어 보세요. 이미 준비된 폼이 있다면 사용 가능한 옵션에서 선택하기만 하면 돼요.

![폼 선택 또는 생성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080331986/original/dY5w0UVaQIHzZAjEN9yL_en-BL59e_CN8A.png?1788851484)

### 삽입 링크 가져오기

폼이 준비되면, 폼 빌더(Form Builder) 우측 상단에 있는 "Integrate(연동)" 탭으로 이동하세요. 옵션에서 폼 유형을 선택하고 "Copy Embed Code(삽입 코드 복사)" 옵션을 클릭하세요.

![삽입 코드 복사 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080332076/original/FBadsdVSRVv5-_MUTQoKCjO3HB05UXMXPA.png?1788851548)

### 사용할 준비 완료

이제 삽입 링크가 준비되었어요. 아래에 설명된 플랫폼별 안내에 따라 여러분의 웹사이트 코드에 붙여넣기만 하면 돼요.

## 하이퍼클래스 팝업 폼 삽입 방법

팝업 폼의 삽입 코드를 확보했다면, 이제 웹사이트에 원활하게 통합하는 단계를 살펴볼게요. 가장 많이 사용되는 웹사이트 빌더별로 자세한 안내를 정리했어요.

### Squarespace

#### Squarespace는 코드 삽입(Code Injection) 도구를 통해 커스텀 코드를 추가할 수 있도록 지원하며, 다양한 유형의 폼을 쉽게 삽입할 수 있게 해줘요. 각 단계를 자세히 살펴볼게요: 설정 접근하기

먼저 웹사이트 빌더 계정에 로그인하고 대시보드의 설정(Settings) 메뉴로 이동하세요.

![Squarespace 설정 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040477944/original/0efeb-o3eyVRogzafuxyphxpWLA14s1QsQ.png?1737958124)

#### Advanced(고급) 클릭하기

설정 메뉴 안에서 Advanced(고급) 옵션을 찾아 클릭하면 추가 커스터마이징 기능에 접근할 수 있어요.

![Advanced 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040477951/original/ybMVQtR9MD5CDh4TS0gy0ZRq2iJyXrtdtQ.png?1737958139)

#### Code Injection(코드 삽입) 선택하기

고급 설정에서 "Code Injection(코드 삽입)"이라고 표시된 탭을 찾으세요.

![Code Injection 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040477953/original/ls5P9Hb6iFA7aYZiHxwV04uEsTny_IigwQ.png?1737958150)

#### 삽입 코드 추가하기

삽입 코드를 어디에 추가할지 결정하세요:

모든 페이지에 폼을 표시하려면, Code Injection 패널의 Header(헤더) 또는 Footer(푸터) 섹션에 코드를 붙여넣으세요.

![헤더/푸터 코드 삽입 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040478489/original/y3ZB1pWgpRXjY0kExdLTfGBhDd4cTiQ-QA.png?1737958972)

#### 저장 및 발행하기

코드를 추가한 후, Code Injection 패널 또는 페이지별 코드 삽입(Per-Page Code Injection) 필드에서 Save(저장)를 클릭하세요.

변경 사항을 적용하려면 웹사이트를 발행(Publish)하세요.

** SquareSpace는 결제(Checkout) 페이지에서의 폼 삽입을 지원하지 않아요. 웹사이트의 다른 영역에 폼을 배치하도록 해주세요.

### Wix 연동

#### Wix 웹사이트 빌더 옵션

- "+" 버튼을 클릭해 삽입(Embed) 옵션을 찾으세요.
- Embed(삽입) 옵션을 클릭하세요.
- "Embed a Widget(위젯 삽입)" 옵션을 선택하세요.

![Wix 위젯 삽입 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040484664/original/Y6uNfx7-bWPgkTHjD8Sjk3EEleRNldLKmw.png?1737964819)

#### Wix 편집기에 코드 붙여넣기

Code(코드) 옵션을 선택하세요. 삽입 스크립트를 붙여넣고 "Update(업데이트)" 옵션을 클릭해 변경 사항을 저장하세요.

![Wix 코드 붙여넣기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040484717/original/0yBNSWCitojfaCx_5c2QkASUvCfwCz0FzQ.png?1737964859)

#### 웹사이트 발행하기

폼이 올바르게 표시되는지 사이트를 미리보기로 확인하세요. 확인이 끝나면 Wix 웹사이트를 발행하세요.

### Shopify 연동

#### 테마(Themes) 메뉴로 이동하기

Shopify 계정에 로그인한 후, 왼쪽 메뉴에서 Online Store(온라인 스토어)로 이동해 스토어 테마를 관리하세요. Themes(테마)를 클릭하면 사용 가능한 모든 테마를 볼 수 있으며, 활성화된 테마가 상단에 표시돼요.

![Shopify 테마 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040520091/original/kzaaeFItx4w9RQRR-ToI52ELG1mJVi4ecg.png?1737987592)

#### 테마 코드 접근 및 편집하기

편집하려는 테마를 찾아 이름 옆에 있는 점 세 개(⋮) Actions(작업) 버튼을 클릭해 커스터마이징 옵션에 접근하세요. 드롭다운 메뉴에서 "Edit Code(코드 편집)"를 선택하면 커스텀 코드를 추가하거나 수정할 수 있는 테마 파일이 열려요.

![Shopify 테마 코드 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040520123/original/N5u6tEeT775a005hG4_xhm3nczxL7ccJlg.png?1737987619)

#### 헤더 또는 푸터에 코드 추가하기

Layout(레이아웃) 섹션에서 theme.liquid 파일을 찾으세요. 폼을 배치하고 싶은 위치에 따라 `<head>` 또는 `<footer>` 태그 안에 삽입 코드를 붙여넣으세요.

![theme.liquid 코드 삽입 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040520422/original/Un3FZzn3oE6dyXFREC6MF8PKSWSZM-TtNw.png?1737987869)

### WordPress 연동

WordPress는 플러그인이나 테마 설정을 통해 스크립트 삽입을 지원하므로, 팝업 폼을 추가하는 데 매우 유연해요.

#### 편집기 접근하기

먼저 웹사이트 관리자 대시보드의 Pages(페이지) 섹션으로 이동하세요. 여기서 사이트의 비주얼 설정과 디자인 요소를 관리할 수 있어요. 편집 모드로 들어가려면, 하이퍼클래스 폼을 삽입하려는 페이지에 마우스를 올리고 Edit(편집) 버튼을 클릭하세요.

![WordPress 페이지 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574447/original/Sn1fU2qwIsCMN1lw-COpW7NLryJquimxew.png?1738064144)

#### 블록 메뉴 열기

편집기에서 "+" 아이콘을 클릭하면 페이지를 커스터마이징할 수 있는 블록 목록이 나타나요.

![WordPress 블록 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574471/original/aig7pzyEvRb_1S6_Sugwdj7dQy5YqVIX4A.png?1738064169)

#### Custom HTML(커스텀 HTML) 블록 선택하기

아래로 스크롤해서 Custom HTML(커스텀 HTML) 옵션을 선택하면 페이지 레이아웃에 직접 코드를 삽입할 수 있어요.

![Custom HTML 블록 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574498/original/-zABymPaYB2OW21Swd_0oXHgzXV4o8S17A.png?1738064197)

#### 삽입 코드 입력하기

선택한 파일의 적절한 섹션에 삽입 코드를 붙여넣으세요. 제대로 작동하려면 `<head>` 또는 `<footer>` 태그 사이에 올바르게 배치되었는지 확인하세요. 완료되면 변경 사항을 저장하세요.

![삽입 코드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574521/original/z-cfbrRl8pPi1KEPF9M8qjrhz-VGVYQmHQ.png?1738064220)

#### 업데이트 및 테스트

변경 사항을 저장하고 웹사이트를 새로고침해서 폼이 올바르게 나타나는지 확인하세요.

### Duda 연동

Duda는 커스텀 코드를 위한 내장 위젯을 제공해서 폼을 쉽게 추가할 수 있어요.

#### 커스텀 위젯 추가하기

Duda 편집기를 열고 팝업 폼을 넣고 싶은 페이지로 이동하세요.

Widgets(위젯) > HTML Widget(HTML 위젯)을 선택해서 페이지로 드래그하세요.

![Duda HTML 위젯 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040522898/original/2oeKD8a6jLRKisgK04HdWp6De_cfhSSbsw.png?1737989414)

#### 삽입 코드 붙여넣기

하이퍼클래스 스크립트를 HTML 위젯에 붙여넣고 원하는 위치에 배치하세요.

![Duda 삽입 코드 붙여넣기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040522939/original/PrUHoi24-N-vA8NbexDmk9Rm7BLgFsxXFw.png?1737989426)

저장 및 발행: 삽입 코드를 추가한 후, 웹사이트 설정의 해당 섹션에서 변경 사항을 저장하세요. 변경 사항이 발행되거나 실제로 적용되었는지 확인하세요.

웹사이트 테스트하기: 브라우저에서 웹사이트를 열어 삽입된 팝업 폼이 의도한 대로 표시되고 작동하는지 확인하세요.

폼이 나타나지 않는 경우: 복사/붙여넣기 과정에서 삽입 코드에 오류나 누락된 부분이 없는지 검토하세요. 코드가 올바르게 로드되려면 정확한 섹션에 배치되었는지 확인하세요.

## 자주 묻는 질문

**Q: 폼의 디자인을 커스터마이징할 수 있나요?**

네, 하이퍼클래스 안에서 폼의 디자인과 내용을 커스터마이징한 후 사이트에 삽입할 수 있어요.

**Q: 여러 페이지에 각각 다른 폼을 사용할 수 있나요?**

물론이에요! 각 폼마다 고유한 삽입 코드를 생성해서 해당 페이지에 붙여넣으면 돼요.

**Q: 코딩 경험이 필요한가요?**

아니요! 각 플랫폼은 커스텀 스크립트를 삽입할 수 있는 사용하기 쉬운 편집기를 제공해요.
