# 폼과 설문에서 0달러 주문의 카드 입력 건너뛰기

폼과 설문의 **Sell Products**(상품 판매) 요소에는 **Require Credit Card**(신용카드 필수) 설정이 있어요. 주문 금액이 $0이고 이후에 반복 결제도 없으면, 이 설정을 꺼서 결제 필드를 숨길 수 있어요. 이 문서에서는 설정 방법, 결제 필드가 숨겨지는 조건, 쿠폰·구독·퍼널에 삽입된 폼 같은 예외 상황을 설명해요.

## 0달러 결제란?

0달러 결제(Zero-Dollar Checkout)를 쓰면 고객이 신용카드 정보를 입력하지 않고도 폼이나 설문에서 무료 주문을 마칠 수 있어요. 상품 주문 금액이 $0이고 예정된 반복 결제가 없으면 결제 필드가 자동으로 숨겨져서, 무료 오퍼를 더 간단하게 받을 수 있어요.

이 기능은 **Sell Products** 요소의 **Require Credit Card** 토글로 조절해요. 토글을 끄면 시스템이 주문 합계와 반복 결제 일정을 확인해요. 둘 다 0이면 결제 정보 수집을 건너뛰어요. 무료 주문도 제출 내역과 주문 내역에 그대로 기록되기 때문에 추적에는 문제가 없어요.

데스크톱과 모바일의 폼·설문에서 모두 쓸 수 있어요. 쿠폰, 오더 범프, 퍼널에 삽입된 폼과도 함께 작동해요.

## 이럴 때 좋아요

- 전환율이 올라가요. 무료 주문에서 카드 입력을 없애면 중도 이탈이 줄고 완료율이 높아져요. 리드 마그넷, 오늘 결제액이 $0인 무료 체험, 프로모션 상품에 잘 맞아요.
- 쿠폰을 유연하게 쓸 수 있어요. 100% 할인 쿠폰을 적용해 합계가 $0이 되면 결제 필드가 자동으로 숨겨져요.
- 주문 추적이 그대로 유지돼요. 무료 주문도 생성되어 제출 내역에 기록되므로 분석과 리포트가 정확해요.
- 기존 폼과 설문은 달라지지 않아요. 설정의 기본값은 켜짐(카드 필수)이라서, 직접 끄지 않으면 이전과 똑같이 작동해요.
- 데스크톱과 모바일에서 똑같이 작동해요.
- 합계를 확인할 수 없으면 카드 입력란을 항상 보여 줘요. 예를 들어 가격 요약을 불러오지 못했을 때 결제 오류가 생기는 일을 막아 줘요.

## 결제 필드가 숨겨지는 조건

**Require Credit Card** 토글이 꺼져 있고 아래 조건을 모두 충족하면 결제 필드가 자동으로 숨겨져요. 시스템은 주문 상태를 실시간으로 확인해서 결제 영역을 보여 줄지 정해요.

1. 주문 합계가 $0이에요.
   - 선택한 상품, 옵션(variant), 오더 범프의 가격을 모두 더한 금액이 0이어야 해요. 기본 가격, 수량 변경, 적용된 쿠폰이 모두 포함돼요.
2. 예정된 반복 결제가 없어요.
   - 나중에 고객에게 결제가 청구될 구독, 반복 결제, 무료 체험이 주문에 없어야 해요. 오늘 합계가 $0이어도 이후 결제가 예정되어 있으면 카드가 필요해요.
3. 합계가 확인되었고 변하지 않아요.
   - 가격 요약이 정상적으로 불러와져서 안정된 상태여야 해요. 상품, 옵션, 쿠폰, 오더 범프를 바꾼 직후 합계가 갱신되는 중에 고객이 제출하면 결제 오류를 막기 위해 카드 입력란을 보여 줘요.

{% hint style="info" %}
조건 중 하나라도 충족하지 못하거나 확인할 수 없으면, 시스템은 결제 필드를 보여 주고 카드 정보를 받아요. 이 안전 장치 덕분에 유료 주문이 무료로 잘못 처리되는 일은 없어요.
{% endhint %}

모든 조건을 충족하면 결제 요소가 폼에서 완전히 사라져요. 고객은 카드 입력란 없이 바로 제출할 수 있어요.

## 0달러 결제 켜는 방법

폼이나 설문의 **Sell Products** 요소에서 **Require Credit Card** 토글을 꺼야 0달러 결제를 쓸 수 있어요. 다음 단계를 따르세요.

1. 0달러 결제를 켜려는 폼이나 설문에서 **Form Builder**(폼 빌더) 또는 **설문 빌더**를 열어요. 요소 설정에 접근하려면 빌더 화면이 필요해요.

   ![폼 또는 설문 빌더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079392729/original/pqr9nSYrPynPZqnBYOTShEeUq4QmiK5riw.png?1787786060)

2. 폼에서 **Sell Products** 요소를 클릭해요. 아직 추가하지 않았다면 요소 패널에서 **Sell Products** 요소를 새로 추가하세요.

   ![Sell Products 요소 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079392797/original/Z2nK3Dh4VSJ_yNzYzbiKn5YqEPs1unG2TQ.png?1787786344)

3. 요소 설정 패널에서 **Require card for $0 orders**($0 주문에 카드 필수) 토글을 찾아 꺼요. 토글을 끄면 합계가 $0이고 반복 결제가 없는 주문에서 결제 필드가 자동으로 숨겨져요.

   ![Require card for $0 orders 토글 끄기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079392759/original/pLFiEHEALqlBfhpPlGzLAqYcdJW9LQtyzQ.png?1787786231)

4. **변경사항 저장**을 클릭한 다음 폼이나 설문을 **게시**해요. 0달러 결제 조건에 맞는 주문부터 바로 새 동작이 적용돼요.

{% hint style="info" %}
설정의 기본값은 켜짐(카드 필수)이에요. 0달러 결제를 허용하려는 **Sell Products** 요소마다 직접 꺼야 해요. 이렇게 해서 기존 폼이 예전처럼 작동하도록 지켜 줘요.
{% endhint %}

## 예외 상황과 동작 방식

0달러 결제는 여러 예외 상황에서도 결제가 안정적으로 처리되도록 만들어져 있어요. 아래 내용을 알아 두면 상황에 맞게 폼을 설계할 수 있어요.

### 퍼널에 삽입된 폼과 설문

폼이나 설문이 퍼널에 삽입되어 있으면, 요소에서 한 설정보다 퍼널의 **Require Credit Card** 설정이 우선 적용돼요. 삽입된 폼의 0달러 주문 동작을 바꾸려면 퍼널의 결제 설정을 조정하세요.

### 구독과 무료 체험

구독과 무료 체험은 지금 결제 금액이 $0이어도 항상 신용카드가 필요해요. 이후의 반복 결제를 처리하려면 카드가 있어야 하기 때문이에요. 그래서 **Require Credit Card** 설정과 관계없이 결제 필드가 표시돼요.

### 100% 할인 쿠폰

고객이 100% 할인 쿠폰을 적용해서 주문 합계가 $0이 되면, 합계가 갱신되는 즉시 결제 필드가 자동으로 숨겨져요. 고객이 폼을 조작하는 동안 실시간으로 반영돼요.

### 합계가 불안정하거나 확인되지 않을 때

가격 요약을 불러오지 못했거나, 상품·옵션·쿠폰·오더 범프를 바꾼 뒤 합계가 갱신되는 중에 고객이 폼을 제출하면 결제 필드를 보여 주고 카드 정보를 받아요. 이 안전 장치가 결제 처리 오류를 막아 줘요.

### 후원금과 직접 입력 금액 결제 유형

후원금(donation)과 직접 입력 금액(custom-amount) 결제 유형은 이 기능의 대상이 아니에요. 동작은 그대로이고, **Require Credit Card** 설정과 관계없이 결제 필드가 항상 표시돼요.

### 유료 주문에서 카드 세부 정보 유지

유료 주문에서 입력한 카드 세부 정보가 수량을 바꾸거나 쿠폰을 적용해도 유지돼요. 고객이 주문을 수정할 때 결제 정보를 다시 입력하지 않아도 돼요.

### 개선된 점

$0 주문에서 결제 요소가 잠깐 나타났다가 사라지던 현상이 없어져서 화면이 더 부드럽게 보여요. 또 퍼널에 삽입된 설문도 퍼널 정보를 제대로 전달받아서, 모든 폼 유형에서 동작이 일관돼요.

## 자주 묻는 질문

### Require Credit Card 설정이 기존 폼과 설문에도 영향을 주나요?
아니요. 설정의 기본값은 켜짐(카드 필수)이라서 기존 폼과 설문은 예전과 똑같이 작동해요. 0달러 결제를 쓰려면 토글을 직접 꺼야 해요.

### 무료 주문도 제출 내역과 주문 내역에 기록되나요?
네. 무료 주문도 생성되어 기록되기 때문에 제출 내역과 주문 내역이 빠짐없이 남아요. 하이퍼클래스 계정에서 무료·유료 주문을 모두 확인할 수 있어요.

### 폼이나 설문이 퍼널에 삽입되어 있으면 어떻게 되나요?
요소에서 한 설정보다 퍼널의 **Require Credit Card** 설정이 우선 적용돼요. 삽입된 폼에서 $0 주문에 카드를 받을지 정하려면 퍼널의 결제 설정을 조정하세요.

### 합계가 $0이어도 구독이나 무료 체험에는 신용카드가 필요한가요?
네. 오늘 결제할 금액이 없어도 구독과 무료 체험에는 항상 신용카드가 필요해요. 이후의 반복 결제를 처리하려면 카드가 있어야 하기 때문이에요.

### 0달러 결제를 쿠폰 코드와 함께 쓸 수 있나요?
네. 고객이 100% 할인 쿠폰을 적용해서 주문 합계가 $0이 되면, 합계가 갱신되는 즉시 결제 필드가 자동으로 숨겨져요. 고객이 폼을 조작하는 동안 실시간으로 반영돼요.

### 가격 요약을 불러오지 못하면 어떻게 되나요?
가격 요약을 불러오지 못했거나 합계가 $0인지 확인할 수 없으면, 시스템은 결제 필드를 보여 주고 카드 정보를 받아요. 이 안전 장치 덕분에 유료 주문이 무료로 잘못 처리되는 일은 없어요.

### 모바일에서도 0달러 결제를 쓸 수 있나요?
네. 데스크톱과 모바일에서 모두 지원돼서, 어떤 기기에서든 같은 방식으로 결제가 진행돼요.

### 후원금이나 직접 입력 금액 결제 유형에도 이 기능을 쓸 수 있나요?
아니요. 후원금과 직접 입력 금액 결제 유형은 이 기능의 대상이 아니에요. 동작은 그대로이고 결제 필드가 항상 표시돼요.
