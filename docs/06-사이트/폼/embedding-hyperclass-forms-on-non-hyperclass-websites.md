# 하이퍼클래스 폼을 외부 웹사이트에 임베드하기

이 문서는 Squarespace, Wix, Shopify, WordPress, Duda에서 하이퍼클래스 폼을 임베드하는 순서를 안내해요. 하이퍼클래스에서 호스팅하지 않는 웹사이트에서도 폼으로 리드를 모으고 방문자와 소통하며 전환율을 높일 수 있어요.

## 하이퍼클래스 폼 임베드란?

폼 임베드는 사용 중인 웹사이트 편집기로 폼을 웹사이트에 직접 넣는 것을 말해요. 방문자는 다른 곳으로 이동하지 않고 그 자리에서 폼을 작성할 수 있어요. 리드 수집, 고객 문의, 예약 신청이 모두 내 브랜드 사이트 안에서 이루어져요. 여러 플랫폼을 오가거나 곳곳에서 설정을 바꿀 필요도 없어요. 하이퍼클래스에서 임베드 코드를 복사해 웹사이트 편집기에 붙여넣기만 하면 돼요.

---

## 하이퍼클래스 폼을 임베드하면 좋은 점

하이퍼클래스 폼을 임베드하면 웹사이트의 참여도와 리드 확보 성과를 높이는 데 도움이 돼요.

- 더 많은 리드 확보: 사이트에서 방문자 정보를 바로 수집할 수 있어서 리드를 육성하기 쉬워요.
- 여러 플랫폼에서 사용: Squarespace, Wix, Shopify, WordPress, Duda 같은 웹사이트 플랫폼에서 폼을 쓸 수 있어요.
- CRM 자동 동기화: 수집한 데이터가 하이퍼클래스 CRM에 자동으로 동기화돼서 후속 관리와 자동화가 편해져요.
- 참여도 향상: 커스터마이즈할 수 있는 폼으로 맞춤 메시지, 프로모션, 설문을 보여 줄 수 있어요.
- 성과 추적: 하이퍼클래스에 기본 제공되는 분석으로 폼 성과를 확인하고 개선할 수 있어요.

## 임베드 링크 찾기

웹사이트에 하이퍼클래스 폼을 임베드하려면 먼저 하이퍼클래스 계정에서 임베드 링크를 찾아야 해요. 이 링크에는 선택한 웹사이트에 폼을 표시해 주는 스크립트가 들어 있어요. 찾는 순서는 다음과 같아요.

### 폼 빌더 열기

대시보드의 왼쪽 메뉴에서 **사이트**로 이동해요. 위쪽 메뉴에서 **폼**을 클릭하면 전체 폼 목록이 나와요.

![사이트 메뉴의 폼 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080331882/original/ayYeCk3wBGOzzUWIMwROzK9j48lHweorYw.png?1788851382)

### 폼 선택하거나 만들기

목록에서 기존 폼을 선택하거나 새 폼을 만들 수 있어요. 처음부터 시작한다면 **+ Add Form**(폼 추가) 버튼을 클릭해 폼을 만드세요. 이미 만들어 둔 폼이 있으면 목록에서 선택하면 돼요.

![폼 선택 또는 새 폼 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080331986/original/dY5w0UVaQIHzZAjEN9yL_en-BL59e_CN8A.png?1788851484)

### 임베드 링크 가져오기

폼이 준비되면 **폼 빌더**의 오른쪽 위에 있는 **Integrate**(연동) 탭으로 이동해요. 옵션에서 폼 유형을 선택하고 **임베드 코드 복사**를 클릭하세요.

![Integrate 탭에서 임베드 코드 복사를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080332076/original/FBadsdVSRVv5-_MUTQoKCjO3HB05UXMXPA.png?1788851548)

### 사용 준비 완료

이제 임베드 링크를 웹사이트 코드에 붙여넣을 수 있어요. 아래에서 사용 중인 플랫폼에 맞는 안내를 따라 하세요.

## 하이퍼클래스 팝업 폼 임베드하기

팝업 폼의 임베드 코드를 가져왔다면 이제 웹사이트에 넣어 볼게요. 많이 쓰는 웹사이트 빌더별로 순서를 정리했어요.

### Squarespace

Squarespace는 코드 삽입 도구로 사용자 지정 코드를 추가할 수 있어서 여러 유형의 폼을 쉽게 임베드할 수 있어요. 단계별로 살펴볼게요.

#### 설정 열기

웹사이트 빌더 계정에 로그인한 뒤 대시보드에서 **설정** 메뉴로 이동해요.

![Squarespace 설정 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040477944/original/0efeb-o3eyVRogzafuxyphxpWLA14s1QsQ.png?1737958124)

#### 고급 클릭하기

**설정** 메뉴에서 **고급**을 찾아 클릭하면 추가 사용자 지정 기능이 나와요.

![설정 메뉴의 고급 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040477951/original/ybMVQtR9MD5CDh4TS0gy0ZRq2iJyXrtdtQ.png?1737958139)

#### Code Injection 선택하기

**고급 설정**에서 **Code Injection**(코드 삽입) 탭을 찾아 클릭해요.

![고급 설정의 Code Injection 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040477953/original/ls5P9Hb6iFA7aYZiHxwV04uEsTny_IigwQ.png?1737958150)

#### 임베드 코드 추가하기

임베드 코드를 넣을 위치를 정해요.

모든 페이지에 폼을 표시하려면 **Code Injection** 패널의 **머리글** 또는 **Footer**(바닥글) 섹션에 코드를 붙여넣으세요.

![Code Injection 패널에 임베드 코드를 붙여넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040478489/original/y3ZB1pWgpRXjY0kExdLTfGBhDd4cTiQ-QA.png?1737958972)

#### 저장하고 게시하기

코드를 추가했으면 **Code Injection** 패널 또는 **Per-Page Code Injection**(페이지별 코드 삽입) 필드에서 **저장**을 클릭해요.

웹사이트를 게시하면 변경사항이 적용돼요.

```
** Squarespace는 결제(체크아웃) 페이지에 폼을 임베드하는 것을 지원하지 않습니다. 웹사이트의 다른 영역에 폼을 넣으세요.
```

### Wix

#### Wix 웹사이트 빌더에서 임베드 옵션 찾기

1. **"+"** 버튼을 클릭해 임베드 옵션을 찾아요.
2. **임베드**를 클릭해요.
3. **Embed a Widget**(위젯 임베드)을 선택해요.

![Wix에서 위젯 임베드를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040484664/original/Y6uNfx7-bWPgkTHjD8Sjk3EEleRNldLKmw.png?1737964819)

#### Wix 편집기에 코드 붙여넣기

**코드**를 선택해요. 임베드 스크립트를 붙여넣고 **업데이트**를 클릭해 변경사항을 저장하세요.

![Wix 편집기에 임베드 스크립트를 붙여넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040484717/original/0yBNSWCitojfaCx_5c2QkASUvCfwCz0FzQ.png?1737964859)

#### 웹사이트 게시하기

사이트를 미리 보고 폼이 제대로 표시되는지 확인해요. 확인했으면 Wix 웹사이트를 게시하세요.

### Shopify

#### 테마 메뉴로 이동하기

Shopify 계정에 로그인한 뒤 왼쪽 메뉴에서 **Online Store**(온라인 스토어)로 이동해 스토어 테마를 관리해요. **테마**를 클릭하면 사용할 수 있는 모든 테마가 나오고, 현재 사용 중인 테마가 맨 위에 표시돼요.

![Shopify 테마 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040520091/original/kzaaeFItx4w9RQRR-ToI52ELG1mJVi4ecg.png?1737987592)

#### 테마 코드 열기

편집할 테마를 찾아 이름 옆의 점 세 개 아이콘(**Actions**, 작업)을 클릭해 사용자 지정 옵션을 열어요. 드롭다운 메뉴에서 **코드 수정**을 선택하면 사용자 지정 코드를 추가하거나 수정할 수 있도록 테마 파일이 열려요.

![테마 작업 메뉴에서 코드 수정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040520123/original/N5u6tEeT775a005hG4_xhm3nczxL7ccJlg.png?1737987619)

#### 머리글 또는 바닥글에 코드 추가하기

**레이아웃** 섹션에서 `theme.liquid` 파일을 찾아요. 폼을 넣고 싶은 위치에 따라 `<head>` 또는 `<footer>` 태그 안에 임베드 코드를 붙여넣으세요.

![theme.liquid 파일에 임베드 코드를 붙여넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040520422/original/Un3FZzn3oE6dyXFREC6MF8PKSWSZM-TtNw.png?1737987869)

### WordPress

WordPress는 플러그인이나 테마 설정으로 스크립트를 임베드할 수 있어서 팝업 폼을 추가하기에 활용도가 높아요.

#### 편집기 열기

웹사이트 관리자 대시보드에서 **페이지**로 이동해요. 여기에서 사이트의 시각 설정과 디자인 요소를 관리할 수 있어요. 편집기 모드로 들어가려면 하이퍼클래스 폼을 넣을 페이지 위에 마우스를 올리고 **편집** 버튼을 클릭하세요.

![WordPress 페이지 목록에서 편집을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574447/original/Sn1fU2qwIsCMN1lw-COpW7NLryJquimxew.png?1738064144)

#### 블록 메뉴 열기

편집기에서 **"+"** 아이콘을 클릭하면 페이지를 꾸밀 때 쓸 수 있는 블록 목록이 나와요.

![편집기에서 블록 목록을 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574471/original/aig7pzyEvRb_1S6_Sugwdj7dQy5YqVIX4A.png?1738064169)

#### Custom HTML 블록 선택하기

아래로 스크롤해서 **Custom HTML**(사용자 지정 HTML)을 선택하면 페이지 레이아웃에 직접 만든 코드를 넣을 수 있어요.

![Custom HTML 블록을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574498/original/-zABymPaYB2OW21Swd_0oXHgzXV4o8S17A.png?1738064197)

#### 임베드 코드 넣기

선택한 파일의 알맞은 위치에 임베드 코드를 붙여넣어요. 제대로 작동하려면 코드가 `<head>` 또는 `<footer>` 태그 사이에 정확히 들어가야 해요. 작업을 마치면 **변경사항 저장**을 클릭하세요.

![Custom HTML 블록에 임베드 코드를 붙여넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040574521/original/z-cfbrRl8pPi1KEPF9M8qjrhz-VGVYQmHQ.png?1738064220)

#### 업데이트하고 확인하기

**변경사항 저장**을 클릭한 뒤 웹사이트를 새로고침해서 폼이 제대로 표시되는지 확인하세요.

### Duda

Duda에는 사용자 지정 코드를 넣을 수 있는 기본 위젯이 있어서 폼을 쉽게 추가할 수 있어요.

#### 커스텀 위젯 추가하기

Duda 편집기를 열고 팝업 폼을 넣을 페이지로 이동해요.

**위젯 > HTML Widget**(HTML 위젯)을 선택하고 페이지로 끌어다 놓으세요.

![Duda에서 HTML 위젯을 페이지에 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040522898/original/2oeKD8a6jLRKisgK04HdWp6De_cfhSSbsw.png?1737989414)

#### 임베드 코드 붙여넣기

하이퍼클래스 스크립트를 HTML 위젯에 붙여넣고 원하는 위치에 배치하세요.

![HTML 위젯에 하이퍼클래스 스크립트를 붙여넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040522939/original/PrUHoi24-N-vA8NbexDmk9Rm7BLgFsxXFw.png?1737989426)

```
저장하고 게시하기: 임베드 코드를 추가한 뒤 웹사이트 설정의 해당 영역에서 변경사항을 저장하세요. 변경사항이 적용되도록 게시하거나 라이브로 전환하세요.

웹사이트 테스트하기: 브라우저에서 웹사이트를 열어 임베드한 팝업 폼이 의도한 대로 표시되고 작동하는지 확인하세요.

폼이 표시되지 않는 경우:

복사해 붙여넣는 과정에서 임베드 코드에 오류나 누락이 없는지 확인하세요.

코드가 올바르게 로드되는 위치에 들어 있는지 확인하세요.
```

## 자주 묻는 질문

### 폼 모양을 바꿀 수 있나요?

네, 사이트에 임베드하기 전에 하이퍼클래스에서 폼의 디자인과 내용을 원하는 대로 바꿀 수 있어요.

### 여러 페이지에 서로 다른 폼을 쓸 수 있나요?

네, 가능해요. 폼마다 임베드 코드를 따로 만들어서 해당 페이지에 붙여넣으세요.

### 코딩 경험이 있어야 하나요?

아니요. 각 플랫폼에 사용하기 쉬운 편집기가 있어서 사용자 지정 스크립트를 임베드할 수 있어요.
