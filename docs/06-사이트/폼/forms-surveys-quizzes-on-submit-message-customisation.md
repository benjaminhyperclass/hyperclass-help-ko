# 폼·설문·퀴즈 제출 후 메시지 꾸미기

폼, 설문, 퀴즈를 제출한 직후 보이는 확인 화면을 브랜드에 맞게 꾸밀 수 있어요. 이 문서에서는 제출 후 메시지 편집기가 무엇인지, 어떤 점이 좋은지, 어떻게 설정하는지 알려 드려요.

## 제출 후 메시지 편집기란?

제출 후 메시지 편집기는 연락처가 폼, 설문, 퀴즈를 제출한 직후 보게 되는 화면을 만드는 도구예요. 단순한 확인 문구 대신 제목, 이미지, 레이아웃을 넣은 브랜드 메시지를 만들 수 있고, 데스크톱과 모바일 화면에 맞게 조정할 수 있어요.

## 제출 후 메시지 편집기의 장점

- **서식을 다양하게 쓸 수 있어요:** 편집기 안에서 굵게, 기울임, 글자 크기, 색상, 이모지, 링크, 이미지를 넣어 제목과 보조 문구를 만들 수 있어요.
- **브랜드를 일관되게 유지해요:** 글꼴, 글자 굵기, 여백, 마진, 모서리 둥글기를 브랜드 이미지에 맞출 수 있어요.
- **배경 흐림 효과를 쓸 수 있어요:** 복잡한 배경을 부드럽게 흐려 글자가 잘 보이게 해요. 원하면 메시지 상자에 단색 또는 투명 색상도 넣을 수 있어요.
- **기기별로 따로 꾸밀 수 있어요:** **데스크톱**과 **모바일**을 각각 설정해서 읽기 편하게 만들 수 있어요.
- **실시간으로 미리 볼 수 있어요:** 편집하는 동안 실제 배경 위에서 어떻게 보이는지 확인할 수 있어요.
- **다시 만들 일이 줄어요:** 별도 페이지나 리디렉션을 만들지 않고도 제출 후 화면을 꾸밀 수 있어요.

## 제출 후 메시지 설정하기

아래 순서대로 하면 제출 후 메시지를 설정하고, 두 기기에 맞게 꾸민 뒤, 미리보기로 확인하고 저장할 수 있어요.

1. 서브 계정에 로그인하세요.
2. **사이트 > 폼/설문/퀴즈 > 빌더**로 이동하세요. 폼, 설문, 퀴즈 중 꾸미고 싶은 항목을 고르면 돼요.

   ![사이트 메뉴에서 빌더로 이동하는 화면 녹화](https://jumpshare.com/share/eLLHtJi0Nwvn4C3uBLlm+/GIF+Recording+2025-12-18+at+5.30.07+PM.gif)
3. 새로 만들려면 **+ Add Form/Survey/Quiz**(폼/설문/퀴즈 추가) 버튼을 클릭하세요. 기존 항목을 고치려면 **⋮**(점 세 개)를 클릭하고 **편집**을 선택해서 빌더를 여세요.

   ![폼 추가 버튼과 편집 메뉴 화면](https://jumpshare.com/share/FJohJIApZsddPtwqyhVA+/Screen+Shot+2025-12-18+at+5.31.37+PM.png)
4. 폼, 설문, 퀴즈를 원하는 대로 꾸민 다음 **설정 > On Submit**(제출 후)을 클릭하세요.
5. 드롭다운에서 **메시지**를 선택하세요.
6. 리치 텍스트 편집기에서 제목과 보조 문구를 쓰세요.
7. 필요에 따라 텍스트 서식을 적용하세요. 글자 크기, 글자색과 배경색, 정렬을 바꾸고, 글머리 기호 또는 번호 목록, 링크, 이미지, 커스텀 값을 넣을 수 있어요.

   ![텍스트 서식을 적용하는 화면 녹화](https://jumpshare.com/share/4LUevsy268SyHEWQoS1S+/GIF+Recording+2025-12-18+at+5.42.06+PM.gif)
8. **Message Styling**(메시지 스타일)에서 배경 색상, 글자 굵기, 모서리 둥글기를 설정하세요.
9. **마진**과 **여백**을 조정하세요.
10. **배경 흐림**을 켜거나 끄세요. 배경으로 이미지를 설정했을 때만 쓸 수 있는 옵션이에요.

    ![배경 흐림 옵션을 켜고 끄는 화면 녹화](https://jumpshare.com/share/d4888inTYpjNdSgePfEC+/GIF+Recording+2025-12-18+at+6.01.28+PM.gif)
11. **데스크톱**과 **모바일** 보기를 번갈아 전환하며 각각 확인하세요.

    ![데스크톱과 모바일 보기 전환 화면](https://jumpshare.com/share/7nJj4ZRnb2WqTn1h4wZA+/Screen+Shot+2025-12-18+at+6.04.05+PM.png)
12. **미리보기** 패널에서 꾸민 결과가 어떻게 보이는지 확인하세요.

    ![미리보기 패널 화면](https://jumpshare.com/share/gP0Gaq03j4ywPOIIjE6a+/Screen+Shot+2025-12-18+at+6.00.18+PM.png)
13. 모두 꾸몄으면 빌더에서 **저장**을 클릭하세요.

    ![빌더의 저장 버튼 화면](https://jumpshare.com/share/cS06Q9PX94eOdju0eU6w+/Screen+Shot+2025-12-18+at+6.06.11+PM.png)

## 자주 묻는 질문

### 메시지와 리디렉션을 동시에 쓸 수 있나요?
아니요. 기본 동작은 하나만 고를 수 있어요. 다만 **조건부 로직**의 조건이 맞으면 기본 동작 대신 다른 메시지나 리디렉션을 보여 줄 수 있어요.

### 워크플로우가 제출 후 메시지에 영향을 받나요?
아니요. 폼, 설문, 퀴즈 제출 시 실행되는 워크플로우는 화면에 보이는 확인 메시지와 상관없이 따로 실행돼요.

### 미리보기에서 이미지나 커스텀 값이 보이지 않아요. 정상인가요?
네, 정상일 수 있어요. 일부 커스텀 값은 실제로 제출했을 때만 값이 채워져요.
