# 퀴즈 템플릿 라이브러리로 퀴즈 빠르게 만들기

하이퍼클래스 퀴즈 빌더의 **템플릿 라이브러리**를 사용하면 미리 만들어진 템플릿으로 퀴즈를 빠르게 만들 수 있어요. 리드 수집, 고객군 분류, 지식 테스트 등 목적에 맞는 템플릿을 골라 몇 번의 클릭으로 시작해 보세요.

## 퀴즈 템플릿 라이브러리란?

**템플릿 라이브러리**(Template Library)는 전문가가 디자인한 퀴즈 템플릿을 모아 둔 기능이에요. 처음부터 만들지 않아도 효과적인 퀴즈를 빠르게 만들 수 있어요. 템플릿은 퀴즈 유형과 목적별로 나뉘어 있어서 필요한 템플릿을 쉽게 찾을 수 있어요.

## 퀴즈 템플릿 라이브러리의 장점

템플릿 라이브러리를 쓰면 전환을 높이거나, 정보를 전달하거나, 참여를 이끄는 퀴즈를 더 짧은 시간에 만들 수 있어요.

- 시간 절약: 빈 화면에서 시작하지 않고, 바로 쓸 수 있는 퀴즈 구조에서 시작해요.
- 다양한 선택지: 리드 생성, 점수 계산, 평가 등 여러 퀴즈 유형 중에서 고를 수 있어요.
- 목적별 템플릿: 템플릿이 목적별로 분류되어 있어 상황에 맞는 템플릿을 고르기 쉬워요.
- 자유로운 편집: 질문, 답변, 로직, 디자인까지 템플릿의 모든 부분을 수정할 수 있어요.
- 참여도 향상: 사용자가 의미 있게 참여하도록 이끄는 검증된 구조예요.
- 시작하기 좋은 출발점: 퀴즈를 처음 만드는 팀이나 더 빨리 출시하고 싶은 팀에 알맞아요.

## 퀴즈 템플릿 라이브러리 사용하기

템플릿을 고르고 수정하면 몇 분 안에 퀴즈를 만들 수 있어요. 품질은 유지하면서 더 빨리 출시할 수 있어요.

![퀴즈 템플릿 라이브러리를 여는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046574233/original/i5DhnfR5_cPknol3lOfzPaDGWfzlogiyfw.gif?1747160884)

1. 하이퍼클래스 대시보드에서 **사이트 > 퀴즈**로 이동해요.
2. **퀴즈** 대시보드 오른쪽 위의 **신규** 버튼을 클릭해요.
3. 드롭다운 메뉴에서 **Start with Template Library**(템플릿 라이브러리로 시작)를 선택해서 **템플릿 라이브러리**를 열어요.
4. 사용할 수 있는 퀴즈 템플릿을 둘러봐요. 템플릿에는 제목과 간단한 설명이 있어서 용도나 목적에 맞게 고를 수 있어요.
5. 템플릿을 클릭하면 구조를 미리 볼 수 있어요.
6. 사용할 템플릿을 정했으면 **계속**을 클릭해요. 템플릿이 불러와진 상태로 퀴즈 편집기가 열려서 바로 수정을 시작할 수 있어요.

{% hint style="info" %}
팁: 질문, 답변, 결과, 디자인, 로직까지 모든 항목을 수정할 수 있어요. 템플릿으로 시작해도 나만의 퀴즈로 만들 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 템플릿을 선택한 뒤에도 수정할 수 있나요?
네, 수정할 수 있어요. **계속**을 클릭하면 질문, 답변, 스타일, 로직, 결과를 모두 편집할 수 있어요.

### 템플릿은 모바일에 최적화되어 있나요?
네, 모든 템플릿은 반응형이라 모바일 기기에서도 보기 좋게 표시돼요.

### 내가 만든 템플릿을 저장할 수 있나요?
현재 **템플릿 라이브러리**에는 하이퍼클래스에서 제공하는 템플릿만 있어요. 직접 만든 템플릿 저장은 아직 지원하지 않아요.

### 템플릿을 사용하면 기존 퀴즈가 덮어써지나요?
아니요. 템플릿을 사용하면 새 퀴즈가 만들어지고, 기존 퀴즈에는 영향이 없어요.

### 리드 생성용 템플릿도 있나요?
네, 있어요. 이메일 수신 동의 받기, 퍼널 연동 등 리드 수집에 맞춰진 템플릿이 많아요.
