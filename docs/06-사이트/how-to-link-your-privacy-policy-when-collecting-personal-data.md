# 개인정보를 수집할 때 개인정보처리방침 링크 걸기

개인정보처리방침은 이름, 전화번호, 이메일 같은 개인정보를 사업자가 어떻게 수집하고 사용하고 보호하는지 알리는 문서예요. GDPR, CCPA, A2P 10DLC 통신사 규정 같은 법과 규정에서 요구하는 경우가 많아서, 단순히 갖춰 두면 좋은 정도를 넘어요. 하이퍼클래스에서는 사용자에게서 정보를 받는 곳마다 개인정보처리방침 링크를 걸 수 있어요. 이 문서에서 방법을 알아보세요.

```
면책 조항: 이 문서는 법률 자문이 아닙니다. 정보 제공을 위한 도움말이며, 반드시 법률 전문가와 상담하세요.
```

---

## 개인정보처리방침 준비 시 고려할 점

1. 어떤 개인정보를 수집하나요?
2. 어디에서 개인정보를 수집할 수 있나요?

   - 퍼널 및 웹사이트
   - 폼
   - 설문
   - 웹 채팅
   - 주문 폼
   - 캘린더
3. 퍼널이나 웹사이트로 개인정보처리방침을 만들려면 어떻게 하나요?

   - 퍼널 또는 웹사이트 안에 전용 페이지를 만들어요. URL을 쉽게 참조할 수 있도록 첫 페이지에 만드는 경우가 많아요.
   - Google에서 참고 자료를 검색해 보세요: [https://www.google.com/search?q=privacy+policy+templates](https://www.google.com/search?q=privacy+policy+templates)
   - 사업과 사용 목적에 맞는 개인정보처리방침을 작성하고 확정할 때는 법률 전문가와 상담하세요.

---

## 개인정보처리방침 링크를 넣을 위치

하이퍼클래스에서 개인정보를 수집하는 기능마다 개인정보처리방침 링크를 넣을 자리가 있어요. 기능별 방법은 아래와 같아요.

### 퍼널 및 웹사이트

- **Text**(텍스트) 요소: 텍스트 요소를 끌어다 놓고 안내 문구를 입력하세요. 예를 들면 "제출하시면 개인정보처리방침에 동의하는 것으로 간주됩니다"처럼 쓰면 돼요. 그다음 "개인정보처리방침"을 드래그해서 선택하고 **링크**를 클릭한 뒤 URL을 붙여넣으세요.

### 폼

- **Text** 요소: 텍스트 요소를 끌어다 놓고 안내 문구를 입력하세요. 예를 들면 "제출하시면 개인정보처리방침에 동의하는 것으로 간주됩니다"처럼 쓰면 돼요. 그다음 "개인정보처리방침"을 드래그해서 선택하고 **링크**를 클릭한 뒤 URL을 붙여넣으세요.
- **이용약관** 요소: 이용약관 요소를 끌어다 놓고 **Edit Link**(링크 편집)를 선택하세요. 그다음 개인정보처리방침 URL을 붙여넣고 문구를 원하는 대로 수정하세요.

### 설문

- **Text** 요소: 텍스트 요소를 끌어다 놓고 안내 문구를 입력하세요. 예를 들면 "제출하시면 개인정보처리방침에 동의하는 것으로 간주됩니다"처럼 쓰면 돼요. 그다음 "개인정보처리방침"을 드래그해서 선택하고 **링크**를 클릭한 뒤 URL을 붙여넣으세요.

### 캘린더

- **Text** 요소: 캘린더를 삽입한 페이지에 텍스트와 링크를 넣으세요.
- **이용약관** 요소: 링크가 들어 있는 이용약관 요소를 넣은 커스텀 폼을 사용하세요.

{% hint style="info" %}
참조용으로 웹사이트에서 이용약관이 담긴 페이지로 링크를 걸어야 해요.
{% endhint %}

### 주문 폼

- **Text** 요소: 주문 페이지에 텍스트와 링크를 넣으세요.
- **고급 설정**: 주문 폼의 **고급 설정**에서 **Enable Terms and Conditions**(이용약관 활성화)를 켜고, 그곳에서 링크를 만드세요.

### 웹 채팅

- **링크**: 위젯 설명의 텍스트에 URL을 링크로 거세요.

### 스토어 결제 페이지

스토어 **결제** 페이지의 필수 **동의 체크박스**에 개인정보처리방침 링크를 넣을 수 있어요.

1. **사이트 > 스토어**로 이동하세요. 스토어를 열고 **결제** 페이지를 편집하세요.
2. **결제** 요소를 선택하세요.
3. 오른쪽 패널에서 **이용약관**까지 스크롤하세요. **Enable Terms and Conditions**(이용약관 활성화)를 켜세요.
4. 동의 문구를 원하는 대로 수정하고 개인정보처리방침 링크를 추가하세요.

## 개인정보처리방침 페이지 만들기

링크를 걸려면 먼저 독립된 페이지가 필요해요. 하이퍼클래스 안에 만들어도 되고, 외부에서 호스팅하는 페이지여도 돼요. 하이퍼클래스 안에 만드는 방법은 다음과 같아요.

1. **사이트 > 퍼널** 또는 **웹사이트**로 이동하세요.
2. 새 퍼널 또는 웹사이트를 만들거나 기존 항목을 여세요.
3. 새 페이지를 추가하고 제목을 "개인정보처리방침"으로 정하세요.
4. 개인정보처리방침 전문을 붙여넣으세요.
5. 페이지를 게시하고 페이지 URL을 복사하세요.
