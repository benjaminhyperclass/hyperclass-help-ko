## 블로그 게시물이란?

하이퍼클래스의 블로그 게시물 기능을 쓰면 대시보드에서 바로 SEO에 맞춘 글을 쓰고, 서식을 정리하고, 게시할 수 있어요. 브랜드의 콘텐츠 마케팅을 한곳에서 운영할 수 있어요.

## 블로그 게시물의 장점

하이퍼클래스 안에서 콘텐츠를 만들면 마케팅 작업이 간편해지고, SEO에도 도움이 돼요. 플랫폼을 벗어나지 않고도 독자의 관심을 이어 갈 수 있어요.

- 콘텐츠를 한곳에서 관리
- SEO 필드와 캐노니컬 URL 설정 기능 기본 제공
- 서식 있는 텍스트와 멀티미디어를 다루는 편집기
- 클릭 한 번으로 예약 게시 또는 즉시 게시
- AI로 개요 작성과 본문 초안 생성

## 블로그 게시물 만들기

처음부터 직접 쓰거나 AI의 도움을 받아 글을 쓰기 시작하는 방법이에요.

1. **사이트 > 블로그**로 이동해 블로그 목록을 확인해요. 새 게시물을 올릴 기존 블로그를 선택하거나, 새 블로그를 만드세요.

   ![사이트 > 블로그 화면의 블로그 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049321817/original/uty5ICI3EeVza_k8mI3MYvsMM7kdcbTabQ.png?1751586564)
2. 블로그의 게시물 목록에서 **새 게시물**을 클릭하세요.

   ![게시물 목록의 새 게시물 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049321825/original/g4r2UG1WLx6FTbyfSatL2JFyMHhGFFq9Mw.png?1751586622)
3. 비어 있는 블로그 게시물 편집기를 확인하세요.

   ![비어 있는 블로그 게시물 편집기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049321841/original/RZ1XK_fizsVwGhr4vwnU23ZV4x9AKR5BIA.png?1751586741)

## 블로그 게시물 편집기

편집기에는 기능이 많지만, 새 게시물을 게시하는 데 전부 알 필요는 없어요.

1. **자동 저장**: 오른쪽 위 **뒤로** 버튼 옆에서 **자동 저장**을 켜 두세요.
2. **문자**: 글을 쓰고 서식을 지정해요.
3. **제목**: 글의 내용을 잘 나타내는 제목을 입력해요.
4. **저장 후 계속**: 직접 저장할 수 있어요. 글 작성을 마치면 이 버튼으로 다음 단계로 넘어가요.

![블로그 게시물 편집기의 주요 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049321914/original/a0PKDJ4usXOqvQ6WtkZ6cCCrIt6ZvkUl4w.png?1751587255)

```
편집기에 줄 간격 설정이 있으면 새 게시물과 기존 게시물 모두 줄 간격을 바꿀 수 있어요.

이미 게시한 글에 변경 사항을 적용하려면 게시물을 다시 열어 줄 간격을 조정한 뒤 저장하고 다시 게시하세요.
```

## 고급 옵션

**고급 옵션**을 쓰면 글에 하이퍼링크와 멀티미디어를 넣어 내용을 더 풍성하게 만들 수 있어요.

1. 하이퍼링크를 추가하려면 텍스트를 선택한 뒤 도구 모음의 체인 아이콘을 클릭하세요. **URL**과 옵션을 설정하고 **Add Link**(링크 추가)를 클릭하면 돼요.

   ![하이퍼링크 추가 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049322214/original/ZhdaQV1xkCS0v7Kvm4sxlYjHV4MQaGB66w.png?1751589117)
2. **이미지**를 추가하려면 넣을 위치에 커서를 두고 도구 모음의 이미지 아이콘을 클릭하세요. **URL**, **미디어 라이브러리**, **이미지 AI**(새 이미지 생성) 중 한 가지로 이미지를 넣을 수 있어요.

   ![이미지 삽입 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049322235/original/NvrkDXY6d283HN8qtKai25lqr6Uvm8Hrgw.png?1751589247)
3. **오디오**를 추가하려면 도구 모음의 헤드폰 아이콘을 클릭하세요. **미디어 라이브러리**에서 오디오 파일을 고르고 설정한 다음 **Insert Audio**(오디오 삽입)를 클릭해요.

   ![오디오 삽입 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049322249/original/Z_pSrNO1UVS2HoOjZrgIbAu6KFyLfwB9Og.png?1751589398)
4. **동영상**을 추가하려면 도구 모음의 비디오 카메라 아이콘을 클릭하세요. **미디어 라이브러리**나 YouTube에서 동영상을 가져올 수 있어요. 설정을 마친 뒤 **동영상 삽입**을 클릭하세요.

   ![동영상 삽입 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049322268/original/eEohnSihtixXNqHf1ibH6ldcbtA9NrP2Fg.png?1751589508)

## 게시와 SEO

글 작성을 마치고 **저장 후 계속**을 클릭하면 **상태**와 **SEO 메타데이터**를 설정하는 화면으로 넘어가요. 이 화면도 모든 항목을 알아야 새 게시물을 게시할 수 있는 건 아니에요.

1. **상태**: 게시물을 **Draft**(초안), **게시**(오늘 또는 과거 날짜), **예약**(미래 날짜) 중 하나로 정해요.
2. **Record Keeping**(기록 관리): 게시물에 **URL slug**(URL 슬러그), **카테고리**, **Author**(작성자), **Keywords**(키워드)를 지정해요. 블로그 전체를 체계적으로 정리하는 데 도움이 돼요.
3. **SEO**: 게시물의 **제목**, **대체 텍스트**, **Cover Image**(커버 이미지), **설명**을 설정해요. 바꾼 내용은 **미리보기**로 확인할 수 있어요.
4. **완료**: 모든 설정을 마쳤다면 오른쪽 위 버튼을 클릭하세요. 선택한 **상태**에 따라 버튼이 **Draft**, **게시**, **예약** 중 하나로 표시돼요.
