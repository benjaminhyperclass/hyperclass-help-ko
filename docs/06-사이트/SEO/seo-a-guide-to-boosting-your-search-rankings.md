# SEO로 검색 순위 높이기 가이드

하이퍼클래스의 SEO 기능이 무엇이고 어떤 기능과 장점이 있는지 알려 드려요. 요금 구조, 기능별 할당량, 처음 시작하는 방법도 함께 정리했어요.

## 하이퍼클래스의 SEO 기능이란?

SEO는 Search Atlas 기반의 검색엔진 최적화(SEO) 솔루션이에요. 별도의 외부 도구 없이 기업과 에이전시가 웹사이트를 최적화할 수 있어요. 키워드 조사, 웹사이트 감사, 백링크 분석, 콘텐츠 최적화, SEO 리포트 기능을 제공해요.

자동화와 화이트라벨 기능이 있어서, 에이전시는 자사 브랜딩을 일관되게 유지하면서 고객사에 SEO 서비스를 제공할 수 있어요.

## SEO 주요 기능

SEO에는 웹사이트 최적화, 순위 추적, 감사, SEO 캠페인 관리를 위한 도구가 모여 있어요. 주요 기능은 다음과 같아요.

#### 여러 사이트 관리

- 하나의 대시보드에서 여러 웹사이트의 SEO 성과를 최적화하고 추적할 수 있어요.
- 통합 관리 덕분에 에이전시가 여러 고객사 웹사이트를 효율적으로 다룰 수 있어요.
- 사이트마다 다른 SEO 전략을 지정하면서도 데이터를 체계적으로 정리해 둘 수 있어요.

#### AI로 문제 자동 수정

- AI가 흔한 SEO 오류를 바로 해결하도록 추천해 줘요.
- 다음 항목은 자동으로 수정해요.
  - 메타 설명 문제
  - 제목 태그 문제
  - 누락된 이미지 대체 텍스트 태그
  - 키워드 문제

#### 온페이지 감사

- 순위에 영향을 주는 오류를 찾아내는 상세한 온페이지 SEO 감사를 실행해요.
- 다음과 같은 핵심 온페이지 요소를 분석하고 최적화해요.
  - 제목 태그와 메타 설명
  - 헤더 구조(H1, H2 등)
  - 이미지 최적화와 대체 텍스트 태그
  - 내부 링크 구조
- 문제를 우선순위대로 정리하고, 수정 방법에 대한 AI 추천을 함께 보여 줘요.

#### 키워드 조사 및 추적

- 고급 조사 도구로 내 분야에서 성과가 좋은 키워드를 찾아요.
- 키워드 난이도, 검색량, 순위 상승 가능성을 분석해요.
- 시간에 따른 키워드 순위 변화를 실시간으로 추적해요.
- 히트맵으로 키워드 성과 추이를 한눈에 확인해요.

#### 웹사이트 감사 및 최적화

- 사이트 전체를 감사해서 검색 노출에 영향을 주는 문제를 찾아요.
- 다음 문제를 자동으로 감지하고 해결해요.
  - 중복 콘텐츠
  - 깨진 링크와 404 오류
  - 스키마 마크업 오류
  - 페이지 로딩 속도 문제
- 로컬 SEO 도구로 지역 기반 검색 결과를 최적화해요.
- **Site Explorer**(사이트 탐색기)로 도메인과 경쟁사를 깊이 있게 분석해요.

#### 키워드 순위 추적기

- 최대 1,000개 키워드의 순위를 추적해요.
- 검색엔진별 순위 변동을 모니터링해요.
- 성장 기회와 개선이 필요한 부분을 찾아요.
- 여러 고객사를 관리하는 에이전시를 위해 여러 사이트의 키워드를 함께 추적해요.

#### 백링크 분석 및 모니터링

- 내 웹사이트의 백링크를 분석해서 품질과 순위에 미치는 영향을 평가해요.
- 유해 백링크를 찾아 거부(disavow) 처리해서 검색 페널티를 예방해요.
- 새로 생기거나 사라진 백링크를 자동으로 추적해요.
- 경쟁사 백링크를 분석해서 링크 구축 전략을 다듬어요.

#### Content Genius – AI 기반 콘텐츠 최적화

- NLP 콘텐츠 분석: AI가 키워드 사용, 의미적 관련성, 제목, 메타 데이터, 내부 링크, 사용자 의도를 기준으로 콘텐츠를 검토해요.
- 즉시 수정 제안: 누락된 제목, 약한 내부 링크, 불완전한 메타데이터를 짚어 줘요. 수정을 적용하면 크레딧이 사용되고, 보기만 할 때는 사용되지 않아요.
- 내부 링크 가이드: 콘텐츠의 신뢰도와 참여도를 높일 수 있는 내부 링크를 추천해요.
- 무한 스크롤 화면: 모든 AI 추천을 한 화면에서 이어서 보고, 필터와 정렬로 빠르게 분류할 수 있어요.
- 정확한 문제 집계: 표시된 페이지 수와 수정 건수가 이제 모든 보기에서 똑같이 유지돼요.
- 크레딧 관리: 수정을 적용하면 AI 할당량이 차감돼요. 예를 들어 프리미엄 플랜에서는 글 1개당 3크레딧이 사용돼요.
- 대량 작업에 최적화: 연속 스크롤로 많은 항목을 한꺼번에 검토할 수 있어요. 상세 패널을 닫고 필터를 사용하면 더 부드럽게 작동해요.

#### Content Planner

- 콘텐츠 전략을 효율적으로 정리하고 구조화해요.
- 타깃 콘텐츠 제작을 위한 토픽 클러스터를 최대 15개까지 계획할 수 있어요.
- 필러 페이지와 보조 콘텐츠에 대한 AI 추천을 받아요.
- 콘텐츠가 검색 의도와 SEO 모범 사례에 맞는지 확인해요.

#### SEO 리포팅 및 분석

- 실행에 옮길 수 있는 인사이트가 담긴, 데이터 기반의 상세 SEO 리포트를 만들어요.
- 다음과 같은 핵심 SEO 성과 지표를 추적해요.
  - 키워드 순위
  - 오가닉 트래픽 추이
  - 참여도 지표
- 여러 고객사를 관리하는 에이전시를 위해 여러 사이트를 묶어 리포트를 만들어요.
- 화이트라벨 리포트로 내 브랜드 이름을 달고 고객에게 전문적인 SEO 인사이트를 전달해요.

#### 퍼널·웹사이트와 긴밀한 연동

- 퍼널 페이지를 최적화해서 오가닉 트래픽과 전환율을 높여요.
- 전환율이 높은 세일즈 페이지를 위한 AI 기반 SEO 추천을 받아요.
- SEO 전략과 리드 확보용 퍼널이 매끄럽게 이어지도록 해요.

## 할당량 표시와 소진 안내

- 글 생성에 쓰는 프리미엄 AI 할당량은 **Quota Info**(할당량 정보)/**Quota Usage**(할당량 사용량) 영역에 표시돼서, 남은 사용량을 확인할 수 있어요.
- 할당량이 모두 소진되면 소진된 할당량만 빨간색으로 표시돼요. 같은 행의 다른 할당량은 평소 모습 그대로라서, 아직 남아 있는 할당량을 한눈에 알 수 있어요.

## 시작하기

{% hint style="info" %}
SEO 모듈은 에이전시가 해당 서브 계정에 SEO 재판매를 활성화한 뒤에야 서브 계정에 나타나요.
{% endhint %}

1. 서브 계정에 로그인한 뒤 **사이트 > SEO**로 이동하세요.

   ![사이트 메뉴의 SEO 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058753768/original/hO9rFp7foN54lbfFDSiGihJ5B2HUzCxfcw.png?1763558735)
2. SEO 대시보드에는 세 가지 주요 탭이 있어요: **Site Projects**(사이트 프로젝트), **Local SEO**(로컬 SEO), **설정**.
   - **Site Projects**: 웹사이트(도메인)를 모니터링해요. 사이트 전체 지표, 상태, 백링크, 트래픽 등을 볼 수 있어요.
   - **Local SEO**: 지역 업체의 Google 지도 순위를 추적해요. 지역 키워드 순위를 인터랙티브 히트맵으로 보여 줘요.
   - **설정**: 할당량 사용량을 확인해요.
3. SEO 대시보드에 있는 **Launch Advanced SEO**(고급 SEO 실행) 버튼을 클릭하세요. 새 창에서 전체 SEO 도구가 열려요. 심층 분석, 콘텐츠 제작, 리포트를 위한 확장된 도구를 쓸 수 있어요.

## 자주 묻는 질문

### 사이트 메뉴에 SEO 탭이 안 보여요.
SEO 탭은 에이전시가 해당 서브 계정에 SEO 재판매를 활성화한 뒤에야 나타나요.

### 여러 사이트를 관리할 수 있나요?
네. 하나의 대시보드에서 여러 웹사이트를 추적하고 최적화할 수 있어요. 사이트별 전략도 지정할 수 있어요.

### AI가 자동으로 고쳐 주는 항목은 무엇인가요?
메타 설명, 제목 태그, 누락된 이미지 대체 텍스트, 키워드 문제를 고쳐 줘요. AI 추천과 즉시 수정 기능을 함께 사용해요.

### 순위 추적기의 한도는 얼마인가요?
검색엔진과 여러 사이트를 통틀어 최대 1,000개 키워드를 추적할 수 있어요.
