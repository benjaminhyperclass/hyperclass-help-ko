# 페이지 빌더에서 요소 템플릿 저장하고 사용하기

자주 쓰는 버튼, 폼, 이미지 같은 요소를 요소 템플릿으로 저장해 두면 클릭 한 번으로 어느 페이지에나 넣을 수 있어요. 작업 시간을 줄이고, 모든 퍼널과 웹사이트의 브랜드 디자인도 일관되게 유지할 수 있어요.

## 요소 템플릿이란?

요소 템플릿은 페이지 빌더의 요소 하나(버튼, 제목, 폼 등)를 스타일까지 그대로 저장해 두는 기능이에요. 저장한 템플릿은 서브 계정 전체에서 공유하는 라이브러리에 보관돼요. 같은 요소를 페이지마다 새로 만들 필요 없이, 필요할 때 **Saved Assets**(저장된 자산) 패널에서 템플릿을 불러와 넣으면 돼요.

## 요소 템플릿의 장점

- 일관된 브랜딩: 승인된 디자인 요소를 반복해서 써서 모든 퍼널과 웹사이트의 브랜드 이미지를 맞출 수 있어요.
- 빠른 페이지 제작: 처음부터 다시 만드는 대신, 검증된 디자인 블록을 넣어 제작 속도를 높일 수 있어요.
- 한곳에 모인 라이브러리: 저장한 템플릿을 한곳에서 확인하고, 서브 계정의 모든 사용자가 쓸 수 있어요.
- 스타일 유지: 글꼴, 색상, 간격이 그대로 저장돼서 페이지마다 똑같은 모양을 유지할 수 있어요.
- 간편한 관리: 수정이 필요할 때 템플릿 이름을 바꾸거나 삭제할 수 있어요.

## 요소 템플릿 저장하고 사용하기

1. 서브 계정에서 **사이트**를 클릭해요.

   ![사이트 메뉴](https://jumpshare.com/share/G65n4X1DyWaOnmwmvjQZ+/Screen+Shot+2025-09-29+at+8.22.17+PM.png)
2. **만들기**로 새 퍼널 또는 웹사이트를 만들거나, 기존 퍼널 또는 웹사이트를 **편집**해요.

   ![퍼널 또는 웹사이트 만들기와 편집](https://jumpshare.com/share/hhkDdIIQG8twWZ56NAoA+/GIF+Recording+2025-09-29+at+8.28.42+PM.gif)
3. 버튼, 텍스트, 이미지 같은 요소를 추가하거나 편집해요.
4. 아래 두 방법 중 하나로 요소를 저장해요.

   - 요소 외곽선 툴바의 **저장 아이콘**을 클릭해요.
   - **레이어 > ⋯ > Save Element**(요소 저장)를 열어요.
5. 저장 창이 열리면 어떤 요소인지 알 수 있게 템플릿 이름을 입력해요. 예: *기본 CTA 버튼*

   ![저장 창에서 템플릿 이름 입력](https://jumpshare.com/share/qvjPsWfFGbarIHqlWG8a+/GIF+Recording+2025-10-03+at+12.35.56+PM.gif)
6. 요소와 스타일이 **Element Templates**(요소 템플릿) 라이브러리에 저장돼요.
7. 다시 사용하려면 **요소 추가(+) > Saved Assets > Element Templates**를 클릭하고, 원하는 템플릿을 페이지에 넣어요.

   ![저장한 요소 템플릿을 페이지에 추가](https://jumpshare.com/share/LGcbAeEbYpeSg2qTDUfr+/GIF+Recording+2025-10-03+at+12.52.04+PM.gif)

## 자주 묻는 질문

### 요소 템플릿도 글로벌 섹션이나 유니버설 섹션처럼 동기화되나요?
아니요. 요소 템플릿은 고정된 복사본이에요. 한 곳에서 수정해도 다른 곳에 넣은 요소에는 영향이 없어요.

### 저장한 요소는 누가 쓸 수 있나요?
같은 서브 계정(로케이션)에서 편집 권한이 있는 사용자라면 누구나 쓸 수 있어요.

### 이미 게시된 페이지에 있는 요소도 템플릿으로 만들 수 있나요?
네, 빌더에서 페이지를 열고 요소를 선택한 다음 **저장**을 클릭하세요.

### 글꼴과 색상도 그대로 저장되나요?
네, 스타일이 템플릿과 함께 저장돼서 다시 써도 똑같은 모양을 유지해요.

### 요소 템플릿을 몇 개까지 만들 수 있나요?
현재는 정해진 한도가 없어요. 나중에 쉽게 찾을 수 있도록 이름을 체계적으로 정리해 두세요.

### 템플릿을 폴더로 정리할 수 있나요?
아직은 안 돼요. 알아보기 쉬운 이름 규칙을 정해 라이브러리를 깔끔하게 관리하세요.
