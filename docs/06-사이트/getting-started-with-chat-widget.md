# 채팅 위젯 시작하기

채팅 위젯은 웹사이트 방문자를 리드로 바꾸는 방법 중 하나예요. 고객이 도움이 필요한 순간에 바로 지원해서 고객 경험을 높일 수 있어요. 이 문서에서는 채팅 위젯의 종류와 설치 방법을 알려 드려요.

## 채팅 위젯이란?

하이퍼클래스 채팅 위젯은 웹사이트에 넣는 메신저예요. 방문자는 웹 채팅(설정 화면에서는 **라이브 채팅**으로 표시돼요), 이메일/SMS, Facebook, Instagram, 음성 AI, WhatsApp으로 팀과 실시간 대화를 시작할 수 있어요. 모든 대화는 하이퍼클래스 인박스로 바로 들어와요.

---

## 채팅 위젯을 쓰면 좋은 점

채팅 위젯은 고객 참여를 높이고, 지원 업무를 효율적으로 하고, 전환을 늘리고 싶은 비즈니스에 도움이 돼요. 주요 장점은 다음과 같아요.

- 실시간 고객 지원: 방문자가 궁금한 점에 바로 답을 얻어서 대기 시간이 줄고 고객 경험이 좋아져요.
- 고객 경험 개선: 문제를 바로 해결할 수 있어서 고객 만족도와 충성도가 높아져요.
- 전환율 상승: 고객이 도움이 필요할 때 먼저 말을 걸어서 장바구니 이탈을 줄이고 전환율을 높여요.
- 참여도 상승: 상품 페이지에 오래 머무는 것처럼 방문자의 행동에 맞춰 먼저 대화를 시작할 수 있어요.
- 비용 절감: 챗봇이 자주 나오는 질문에 자동으로 답하면 사람이 처리해야 하는 문의가 줄어서 인건비를 아낄 수 있어요.
- 효율 향상: 여러 대화를 동시에 처리할 수 있어서 지원 업무가 더 효율적이에요.

## 채팅 유형 종류

채팅 위젯은 여러 유형으로 제공돼요. ▶ 영상 [5강 28:54](https://www.youtube.com/watch?v=g2fcpLnUI8M&t=1734s)

#### 1. All-In-One Chat(올인원 채팅)

**All-In-One Chat**은 라이브 채팅, 이메일/SMS, WhatsApp, Facebook, Instagram, 음성 AI 채널을 하나의 채팅 화면으로 묶어 줘요. **스타일** 탭의 **채팅 유형** 다중 선택에서 위젯에 표시할 연결된 채널을 고를 수 있어요.

![올인원 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060494000/original/aPWt_0m5G0Z0793QndgoplaIw3ElfiqMgA.png?1765542382)

#### 2. Email and SMS Chat(이메일·SMS 채팅)

방문자의 정보를 받아 두었다가 나중에 SMS나 이메일로 답하는 유형이에요. 24시간 상주하기 어려운 소규모 팀에 잘 맞아요. 자세한 내용은 [하이퍼클래스 이메일 소개](../09-이메일/what-is-lc-email.md)와 [하이퍼클래스 전화 시스템 소개](../15-전화-시스템/기타/what-is-lc-phone-system.md)를 참고하세요.

![이메일·SMS 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035796726/original/5P6cb8PnO-C-EUC3XtR6WElGVBMWdy2hEg.png?1730384123)

#### 3. 라이브 채팅

**라이브 채팅**(웹 채팅)은 채팅 위젯 안에서 방문자와 실시간으로 주고받는 양방향 대화예요. 방문자의 메시지가 **대화**로 바로 들어와요. 설정 화면에는 **라이브 채팅**으로 표시되지만, 웹사이트 메시지에 쓰는 웹 채팅 채널을 가리켜요. 24시간 대응할 수 있는 팀에 알맞아요.

![라이브 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035797746/original/tsHXwfjVDSYeSyxT8EXm1VWCcaAI0XIhsw.png?1730384798)

#### 4. Facebook Chat(Facebook 채팅)

**Facebook Chat**을 쓰면 방문자가 웹사이트에서 바로 연결된 Facebook 페이지와 Messenger 대화를 시작할 수 있어요. Facebook으로 리드와 DM이 많이 들어오는 브랜드에 잘 맞아요. 자세한 내용은 Facebook 채팅 위젯 도움말을 참고하세요.

![Facebook 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060344496/original/6GRVKKs3N9W5Sc65iojVTe-Tqc2px9f1rw.png?1765385227)

#### 5. Instagram Chat(Instagram 채팅)

**Instagram Chat**을 쓰면 방문자가 연결된 Instagram 비즈니스 계정과 Instagram DM 대화를 시작할 수 있어요. 첫 메시지 이후에는 대화가 Instagram과 하이퍼클래스 양쪽에 남아요. 고객 대부분이 Instagram으로 소통한다면 알맞아요. 자세한 내용은 Instagram 채팅 위젯 도움말을 참고하세요.

![Instagram 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060344526/original/_MrT3LBlKwOpF4pAIxQPsecHJt7GXnFbKw.png?1765385238)

#### 6. WhatsApp Chat(WhatsApp 채팅)

채팅 위젯에서 WhatsApp으로 양방향 대화를 나누는 유형이에요. WhatsApp 승인을 받은 번호가 필요해요. 24시간 상주하기 어려운 소규모 팀에도 잘 맞아요.

![WhatsApp 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035797815/original/qZbQA-zVtB8uSaV0hmdRwyBLv0s4ICE9zQ.png?1730384847)

#### 7. Voice AI Chat(음성 AI 채팅)

**Voice AI Chat**은 음성 중심 채팅 유형이에요. 방문자가 브라우저에서 AI 에이전트와 말로 대화해요. 사람처럼 자연스러운 음성 대화를 24시간 제공하고, 리드 수집·분류·배정까지 자동으로 처리하도록 만들어졌어요. 전화 상담 같은 경험을 주고 싶지만 상담원이나 콜센터를 두기 어려운 비즈니스에 잘 맞아요. 자세한 내용은 음성 AI 채팅 위젯 도움말을 참고하세요.

![음성 AI 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060345613/original/wOuJK1aGUKGaZHK2pZGkMNTpqp01w5oL1g.png?1765386014)

## 채팅 위젯에서 대화 AI 사용하기

채팅 위젯 안에서 대화 AI를 쓰면 방문자에게 인사하고 즉시 답변할 수 있어요. 팀이 자리를 비운 시간에도 모든 문의에 응답이 나가요.

설정 방법과 고급 옵션은 Conversation AI 봇 도움말을 참고하세요.

## 채팅 위젯 설치하기

▶ 영상 [10강 1부 40:19](https://www.youtube.com/watch?v=c4QmTGpfdCc&t=2419s) · [10강 1부 45:11](https://www.youtube.com/watch?v=c4QmTGpfdCc&t=2711s)

#### 1단계: 채팅 위젯으로 이동하기

**사이트 > 채팅 위젯**으로 이동하세요.

![사이트 메뉴의 채팅 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060345709/original/Mlexx3uznkA2IRronSM9iRx5noeOtMoA0A.png?1765386066)

#### 2단계: 새 위젯 만들기

**신규** 버튼을 클릭해 채팅 위젯 만들기를 시작하세요.

![신규 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035798154/original/DWQhKNeI2uBT9CnqcKnvZrJ1dYzLAC1bgQ.png?1730385093)

#### 3단계: 채팅 유형 선택

채팅 위젯 유형은 All-In-One Chat, SMS/Email Chat, 라이브 채팅(웹 채팅), Facebook Chat, Instagram Chat, WhatsApp Chat, Voice AI가 있어요.

![채팅 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060345751/original/rX1H7PBYHcTmCuO53qfIqpILOkFmtv-28w.png?1765386101)

#### 4단계: 위젯 사용자 지정

채팅 위젯 유형을 고르면 위젯을 배포하기 전에 사용자 지정할 수 있는 페이지가 3개 나타나요. 채팅 유형이 AI를 지원하면 4개예요.

{% hint style="info" %}
채팅 위젯 유형에 따라 설정 항목이 추가돼요.
{% endhint %}

- **스타일**: 테마, 아이콘, 환영 메시지, 아바타, 채팅 위젯 배치, 채팅 위젯 크기를 설정해요. 위젯 배치에서는 **고정** 또는 **임베드/인라인**을 선택할 수 있어요. **임베드/인라인** 배치는 지원하는 모든 채팅 위젯 유형에서 쓸 수 있어요.

  ![스타일 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060347414/original/f6s2mdzpV4ZXnYyNacuQDaSVh7eimwKKyw.png?1765387459)
- **Video Avatar**(비디오 아바타): **고정** 배치에서 쓸 수 있고, **임베드/인라인** 배치에서는 쓸 수 없어요. **Chat Launcher**(채팅 런처) 옆에 짧은 영상 인사말을 반복 재생하는 기능이에요. 설정 방법, 영상 요건, 방문자 제어, 제한 사항은 [채팅 위젯 사용자 지정 개요](overview-of-chat-widget-customizations.md)를 참고하세요.
- **채팅 창**: 제목, 인트로 메시지, 문의 폼, 브랜딩 등 채팅 창 옵션을 설정해요. **추가 옵션 > 규정 준수 고지 및 동의**에서는 법적 고지와 동의 체크박스를 각각 따로 설정할 수 있어요. 동의 체크박스를 필수로 만들거나 기본으로 선택된 상태로 둘 수도 있어요.

  {% hint style="info" %}
  첫 페이지 로딩 속도를 높이려면 **채팅 창 > 추가 옵션**에서 **사용자 상호작용 시 로드**를 켜세요. 방문자가 스크롤·클릭·터치하면 위젯이 로드돼요. 상호작용이 없어도 약 8초 뒤에 자동으로 로드돼요.
  {% endhint %}

  ![채팅 창 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060347459/original/gILumKvE-3NwMDZprahF0xcPW5u4b5E2dQ.png?1765387535)
- **메시지**: 메시지 확인 방식과 아이콘을 설정해요. 채팅 위젯의 언어도 설정할 수 있어요.

  ![메시지 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060347511/original/ZWxJuodd5cwBylUwtW86CmPV2hmWV_9IEQ.png?1765387587)
- **에이전트**: 고객이 대화할 음성 에이전트를 선택해요. 에이전트 이름과 설명도 여기에서 설정해요. 이 페이지는 AI를 지원하는 채팅 유형에서만 나타나요.

  ![에이전트 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060347525/original/AsGtxz6AP14aSIjjjV-vS-EmtvgH4QHqmg.png?1765387626)

#### 5단계: 채팅 위젯 설치하기

채팅 위젯 설정을 마치면 랜딩 페이지용 코드나 Google Tag Manager용 코드를 복사해서 WordPress에 추가할 수 있어요. **퍼널**, **웹사이트**, **블로그**에서 채팅 위젯 유형을 선택하면 바로 추가할 수도 있어요.

일부 등록 절차는 제출 전에 하이퍼클래스 채팅 위젯이 웹사이트에 게시되어 있는지 확인해요. 등록 절차에 규정 준수 검토 단계가 있다면 위젯이 설치되어 사이트에 보이는지 먼저 확인하세요.

## 자주 묻는 질문

### 페이지마다 채팅 위젯 메시지를 다르게 설정할 수 있나요?

현재 웹 채팅 위젯은 메시지를 동적으로 바꾸는 기능을 지원하지 않아요. 위젯을 여러 페이지에서 쓸 수는 있지만, 메시지는 처음 설정한 내용 그대로 유지돼요.

### 서브 계정 하나에 채팅 위젯을 여러 개 만들 수 있나요?

네, 만들 수 있어요. 여러 개 추가하는 방법은 '같은 웹사이트에 채팅 위젯 여러 개 추가하기' 도움말을 참고하세요.

### 하이퍼클래스에서 웹 채팅과 라이브 채팅은 어떻게 다른가요?

웹 채팅은 웹사이트에서 주고받는 실시간 메시지로, **대화**로 들어와요. 설정 화면에서는 이 옵션이 **라이브 채팅**으로 표시되지만, 실제로는 웹사이트 메시지에 쓰는 웹 채팅 채널을 설정하는 거예요.

### 채팅 유형을 바꾸면 기존 대화에 영향이 있나요?

아니요. 채팅 유형을 수정하거나 설정해도 기존 대화에는 영향이 없어요. 모든 메시지는 선택한 채널에 따라 계속 **대화**로 들어와요.
