# 이커머스 스토어 빌더의 인터랙티브 라이브 데이터 미리보기

이커머스 스토어 빌더(Ecommerce Store Builder)의 라이브 미리보기(Live Preview)를 사용하면 발행 전에 실제 상품 데이터로 스토어를 테스트할 수 있어요. 상품을 둘러보고, 옵션(variant)을 선택하고, 장바구니 담기(Add to Cart)를 사용하고, 수량을 변경하고, 지원되는 스토어 페이지들을 빌더 안에서 직접 이동해볼 수 있습니다.

더미 상품 데이터로 돌아가고 싶을 때는 언제든지 라이브 미리보기를 꺼주세요. 이 가이드에서는 라이브 미리보기가 어떻게 작동하는지, 무엇을 테스트할 수 있는지, 그리고 스토어 페이지별로 미리보기 동작이 어떻게 달라지는지 설명해요.

## **이커머스 스토어 빌더의 라이브 미리보기란?**

라이브 미리보기(Live Preview)를 사용하면 스토어 빌더(Store Builder) 안에서 이커머스 스토어를 디자인하고 검토할 때 실제 상품 데이터를 사용할 수 있어요.

이 기능을 켜면 지원되는 스토어 페이지와 상품 요소(엘리먼트)에 더미 미리보기 데이터 대신 실제 상품이 표시됩니다.
그러면 빌더를 벗어나지 않고도 지원되는 상품, 내비게이션, 장바구니 관련 상호작용을 테스트할 수 있어요.

더미 상품 데이터로 돌아가고 싶을 때는 언제든지 **라이브 미리보기**를 꺼주세요.

---

## **라이브 미리보기의 주요 장점**

라이브 미리보기는 발행하기 전에 스토어 경험을 더 현실적으로 검토할 수 있는 방법을 제공해요.

- **실제 상품 데이터:** 계정에 등록된 실제 상품으로 스토어를 미리 볼 수 있어요.

- **인터랙티브한 상품 테스트:** 상품을 탐색하고, 옵션을 선택하고, 지원되는 장바구니 담기 동작을 테스트할 수 있어요.

- **장바구니 테스트:** 상품을 담고, 수량을 변경하고, 항목을 삭제할 수 있어요.

- **페이지 간 미리보기:** 미리보기용 장바구니에 담긴 상품을 Cart(장바구니), Checkout(결제), Thank You(감사 페이지)까지 그대로 이어서 확인할 수 있어요.

- **유연한 미리보기:** 디자인 작업 중에 실제 상품 데이터와 더미 상품 데이터를 자유롭게 전환할 수 있어요.

---

## **사전 조건 및 제한 사항**

라이브 미리보기 동작은 계정에 등록된 상품이 있는지, 그리고 현재 편집 중인 스토어 페이지가 무엇인지에 따라 달라져요.

- 계정에 상품이 있는 경우, **라이브 미리보기는 기본적으로 켜져(ON) 있어요**.

- 계정에 상품이 없는 경우, **라이브 미리보기는 기본적으로 꺼져(OFF) 있으며** 더미 상품이 표시됩니다.

- 커스텀 상품 상세 페이지(Custom Product Details Page)에는 라이브 미리보기 토글이 포함되어 있지 않으며, 계속 더미 미리보기 데이터를 사용해요.

- 라이브 미리보기 안의 Checkout(결제) 페이지는 미리보기 전용 경험이에요.

- 현재 Checkout 미리보기에서는 실시간 배송비, 세금, 다중 결제 수단, 실제로 작동하는 결제 입력 필드가 지원되지 않아요.

**참고:** 이 아티클에서 설명하는 Checkout 관련 제한 사항은 **스토어 빌더의 라이브 미리보기** 경험에만 해당돼요. 실제 발행된 이커머스 스토어의 결제 페이지 동작과는 무관합니다.

## **라이브 미리보기 사용 방법**

스토어를 검토하는 동안 라이브 미리보기 토글을 사용해서 실제 상품 데이터와 더미 상품 데이터를 전환해보세요.

- **Sub-Account View(하위 계정 화면)**에서 **Sites(사이트)** 메뉴로 이동하세요.

- **Stores(스토어)**를 선택하세요.

- 편집할 이커머스 스토어를 여세요.

- 검토할 스토어 페이지를 여세요.

- 스토어 빌더(Store Builder)에서 **라이브 미리보기** 토글을 찾으세요.

- 사용 가능한 실제 상품 데이터를 사용하려면 **라이브 미리보기를 켜세요(ON)**.

- 지원되는 상품, 옵션, 내비게이션, 장바구니 관련 동작을 테스트해보세요.

- 더미 상품 데이터로 돌아가려면 **라이브 미리보기를 끄세요(OFF)**.

## **상품 및 스토어 상호작용 미리보기**

라이브 미리보기를 사용하면 각 페이지를 정적인 상품 데이터로 따로따로 검토하는 대신, 스토어 전체 흐름 속에서 지원되는 상호작용을 테스트할 수 있어요.

### **상품 목록 페이지와 상품 상세 페이지**

상품 목록 페이지(Product List Page)와 상품 상세 페이지(Product Details Page)를 통해 빌더 안에서 실제 상품이 어떻게 동작하는지 검토해보세요.

라이브 미리보기를 활성화하면 다음을 할 수 있어요:

- 상품 목록 페이지(PLP)에서 상품 상세 페이지로 이동하기

- 상품 상세 페이지(PDP)에서 실제 상품 데이터 확인하기

- 사용 가능한 상품 옵션(variant) 선택하기

- 지원되는 장바구니 담기 동작 사용하기

- 지원되는 스토어 페이지 간 이동하기

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082986800/original/iJauy84vygJsKroIGEjfhonTI153O4O0gg.gif?1791572057)

빌더에서 기본 PDP를 직접 열면, 하이퍼클래스가 계정에 등록된 실제 상품 중 하나를 무작위로 보여줘요.

**참고:** 커스텀 상품 상세 페이지는 계속 더미 미리보기 동작을 사용하며, 라이브 미리보기 토글이 포함되어 있지 않아요.

### **상품 위젯**

상품 위젯(Product Widget)은 스토어를 미리 보는 동안에도 설정된 동작을 그대로 사용해요.

지원되는 위젯은 다음과 같아요:

- **Featured Product(추천 상품)**

- **Featured Products(추천 상품 목록)**

- **Upsell(업셀)**

위젯이 더미 상품 데이터를 보여줄지 실제 상품 데이터를 보여줄지는 라이브 미리보기 상태와 해당 위젯에 설정된 상품 할당 방식에 따라 달라져요.

### **Cart(장바구니), Checkout(결제), Thank You(감사 페이지)**

미리보기용 장바구니는 지원되는 상품 데이터를 스토어 흐름 전체에 이어서 반영하므로, 여러 페이지를 현실감 있는 콘텐츠로 검토할 수 있어요.

라이브 미리보기를 활성화하면 다음을 할 수 있어요:

- 장바구니에 상품 담기

- 수량 변경하기

- 항목 삭제하기

- Cart(장바구니) 페이지에서 상품 확인하기

- 미리보기 장바구니 내용을 Checkout과 Thank You 페이지까지 이어서 가져가기

미리보기 장바구니가 비어 있어도, Checkout과 Thank You 페이지는 계정에 등록된 상품 1~2개를 표시해서 페이지 디자인을 검토할 수 있도록 해줘요.

Checkout은 빌더 안에서 여전히 미리보기 전용으로 동작해요. 현재 라이브 미리보기 경험에는 실시간 배송비, 세금, 다중 결제 수단, 실제로 작동하는 결제 입력 필드가 포함되어 있지 않아요.

## **빌더 내 섹션과 상호작용하기**

스토어 빌더(Store Builder)는 편집을 위해 섹션을 선택하는 것과 해당 섹션 안의 실행 가능한 요소와 상호작용하는 것을 구분해서 처리해요.

섹션을 처음 클릭하면 해당 섹션이 편집용으로 선택돼요.

섹션이 선택된 후에는, 지원되는 실행 가능한 요소들이 다음을 포함한 예상된 미리보기 동작을 수행할 수 있어요:

- 상품 페이지 이동

- 리다이렉션(이동)

- 장바구니 담기(Add to Cart)

이를 통해 스토어를 편집하면서 동시에 지원되는 고객 상호작용을 빌더 안에서 직접 테스트할 수 있어요.

## 자주 묻는 질문

**Q: 라이브 미리보기를 켜면 어떻게 되나요?**

지원되는 스토어 페이지와 상품 요소가 더미 미리보기 데이터 대신 사용 가능한 실제 상품 데이터를 사용하게 돼요.

**Q: 라이브 미리보기는 자동으로 켜지나요?**

네, 계정에 상품이 있는 경우에는 자동으로 켜져요. 상품이 없는 경우에는 기본적으로 꺼져 있고 더미 상품이 표시돼요.

**Q: 더미 상품 데이터로 다시 전환할 수 있나요?**

네. 언제든지 **라이브 미리보기**를 끄면 돼요.

**Q: 라이브 미리보기가 커스텀 상품 상세 페이지에서도 작동하나요?**

아니요. 커스텀 PDP는 계속 더미 미리보기 동작을 사용하며, 라이브 미리보기 토글이 포함되어 있지 않아요.

**Q: 기본 상품 상세 페이지를 직접 열면 어떻게 되나요?**

라이브 미리보기가 켜져 있는 상태에서는 빌더가 계정에 등록된 실제 상품 중 하나를 무작위로 보여줘요.

**Q: 미리보기 장바구니가 비어 있으면 어떻게 되나요?**

Checkout과 Thank You 페이지는 계정에 등록된 상품 1~2개를 표시해서 페이지 디자인을 검토할 수 있도록 해줘요.

**Q: 라이브 미리보기 안에서 실제 결제를 완료할 수 있나요?**

아니요. 라이브 미리보기 안의 Checkout은 스토어 경험을 검토하기 위한 용도예요. 현재 라이브 미리보기 경험에서는 실제로 작동하는 결제 입력 필드, 실시간 배송비, 세금, 다중 결제 수단이 지원되지 않아요.
