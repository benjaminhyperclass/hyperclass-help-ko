# 퍼널·웹사이트 분석에서 상위 브라우저와 클라이언트 IP 확인하기

퍼널과 웹사이트 분석 대시보드에서 방문자가 많이 쓰는 브라우저와 접속이 잦은 IP 주소를 볼 수 있어요. 방문자가 어떤 환경에서 접속하는지 파악해 사이트를 다듬고, 평소와 다른 트래픽을 찾아낼 때 활용하세요.

웹사이트 트래픽을 이해하면 성능과 보안을 함께 개선할 수 있어요. 이번 업데이트로 **Top Browsers**(상위 브라우저)와 **Top Client IPs**(상위 클라이언트 IP)가 **페이지 조회수** 영역에 추가됐어요. 방문자가 퍼널과 웹사이트를 어떻게 이용하는지 확인하고, 평소와 다른 트래픽 패턴도 찾아볼 수 있어요.

## 주요 활용 효과

퍼널·웹사이트 분석의 새 지표로 방문자 행동을 더 자세히 살펴보세요.

### 상위 브라우저 분석

- 방문자가 많이 쓰는 상위 10개 브라우저를 확인해요(예: Chrome, Firefox, Safari, Edge).
- 비율로 브라우저 사용 추이를 분석해요.
- 가장 많이 쓰는 브라우저에 맞춰 사이트를 최적화하고, 호환성 문제를 예방해요.

### 클라이언트 IP 추적

- 사이트에 접속한 상위 10개 IP 주소를 확인해요.
- 봇이나 자주 방문하는 사용자처럼 평소와 다른 트래픽 활동을 찾아내요.
- 활동량이 많은 IP를 살펴보며 보안을 강화해요.

## 상위 브라우저와 클라이언트 IP 확인하기

퍼널·웹사이트 분석에서 브라우저와 IP 데이터를 확인하려면 다음 단계를 따르세요.

1. 계정에 로그인한 뒤 **사이트**로 이동하세요.
2. **분석** 탭을 클릭하세요.
3. 드롭다운 메뉴에서 **퍼널**, **웹사이트**, 또는 둘 다 선택하세요.
4. 날짜 범위를 선택하세요(예: 지난주, 지난달, 직접 지정).
5. 아래로 스크롤해 **Top Browsers**와 **Top Client IPs** 정보를 확인하세요.
6. 데이터를 분석해 사이트 최적화와 보안에 필요한 결정을 내리세요.

## 이 기능이 중요한 이유

- 최적화 강화: 가장 많이 쓰는 브라우저에서 사이트가 문제없이 작동하는지 확인할 수 있어요.
- 보안 모니터링: 한 주소에서 반복 접속하는 것처럼 의심스러운 IP 활동을 찾아낼 수 있어요.
- 데이터 기반 의사결정: 실제 방문자 행동을 바탕으로 콘텐츠와 기술 설정을 조정할 수 있어요.

## 앞으로 추가될 기능

분석 대시보드에 다음 개선 사항이 예정되어 있어요.

- Geolocation Heatmaps(지역 히트맵): 방문자의 지리적 분포를 볼 수 있어요.
- Device Analytics(기기 분석): 모바일과 데스크톱 사용자 비율을 파악해 SEO와 사용자 경험(UX)을 개선할 수 있어요.

이 지표들을 활용하면 보안 위협을 살피면서 퍼널과 웹사이트의 사용자 경험도 높일 수 있어요.

## 자주 묻는 질문

### 새로 생긴 Top Browsers와 Top Client IPs 데이터는 어디서 볼 수 있나요?
**사이트 > 분석**으로 이동한 뒤 **페이지 조회수** 영역 아래를 확인하세요.

### 이 데이터를 사이트 개선에 어떻게 활용하나요?
브라우저 정보로 가장 많이 쓰는 브라우저와의 호환성을 확인하세요. 클라이언트 IP는 봇이나 스팸 트래픽일 수 있는 평소와 다른 활동이 있는지 살펴보세요.

### 과거 브라우저·IP 데이터도 확인할 수 있나요?
네, 직접 날짜 범위를 지정하면 시간에 따른 추이를 분석할 수 있어요.

### 특정 IP에서 의심스러운 활동이 보이면 어떻게 하나요?
특정 IP가 과도하게 요청을 보낸다면 해당 IP를 차단하거나 봇 방지 조치를 설정해 보세요.
