# 고정 단계 이메일 도메인 워밍업 작동 방식

이메일 도메인 워밍업은 발송량을 조금씩 늘려 가면서 좋은 발신자 평판을 쌓는 과정이에요. 이 문서에서는 고정 단계 워밍업이 어떻게 작동하는지, 어떻게 켜는지, 진행 상황을 어떻게 확인하는지 설명해요.

하이퍼클래스의 고정 단계 워밍업은 하루 발송 기준치를 미리 정해 두고, 새 전용 발송 도메인과 기존 전용 발송 도메인이 단계별로 발송량을 늘려 가도록 안내해요. 갑자기 발송량을 늘렸을 때 생길 수 있는 스팸 필터링, 전달 지연, 평판 문제의 위험을 줄이는 데 도움이 돼요.

## 이메일 도메인 워밍업이란

이메일 도메인 워밍업은 전용 도메인에서 보내는 이메일 수를 조금씩 늘려 가는 과정이에요. 이렇게 하면 Gmail, Outlook, Yahoo 같은 메일 서비스가 그 도메인의 발송 패턴을 살펴볼 수 있어요. 하이퍼클래스의 고정 단계 방식은 이 과정을 15단계로 나누고, 단계마다 하루 발송 기준치를 둬요.

도메인이 현재 단계의 기준치에 도달하면 다음 단계로 올라갈 수 있어요. 발송량을 체계적으로 늘리면서 평판을 고려한 꾸준한 발송 습관을 들일 수 있어요.

{% hint style="warning" %}
고정 단계 도메인 워밍업은 에이전시와 서브 계정 모두에서 전용 발송 도메인에 쓸 수 있어요. 단계적으로 제공하고 있어서 계정마다 사용 가능 여부가 다를 수 있어요. 이 기능을 쓸 수 있는 경우, 새 도메인은 생성과 인증이 끝나면 자동으로 워밍업에 들어가요. 기존 도메인은 직접 시작해야 해요.
{% endhint %}

## 이메일 도메인 워밍업의 장점

발송량을 조금씩 늘리면 메일 서비스가 갑작스럽고 낯선 발송 활동 대신 도메인의 발송 패턴을 파악할 수 있어요. 하이퍼클래스의 고정 단계 워밍업은 명확한 진행 경로를 제공하고, 더 꾸준한 발송 습관을 들이도록 도와요.

- 이메일 전달률 향상: 발송량을 서서히 늘리면 이메일이 스팸함으로 분류될 가능성이 줄어요.
- 발신자 평판 강화: 꾸준히 발송하면 시간이 지나면서 메일 서비스의 신뢰를 쌓는 데 도움이 돼요.
- 체계적인 발송량 확대: 미리 정해진 워밍업 단계가 발송 수요가 늘어날 때 하루 발송량 목표를 알려 줘요.
- 맞춤 시작 단계: 기존 도메인은 과거 발송 이력과 확인 가능한 Google Postmaster 데이터를 바탕으로 권장 시작 단계를 받을 수 있어요.
- 자동 단계 진행: 현재 단계의 하루 발송 기준치에 도달하면 다음 단계로 올라가요. 단계를 일일이 직접 고를 필요가 없어요.
- 유연한 도메인 관리: 에이전시와 서브 계정이 각자 사용 가능한 전용 발송 도메인의 워밍업을 관리할 수 있어요.

## 고정 단계 도메인 워밍업의 작동 방식

고정 단계 워밍업은 이메일 발송량을 제한 없이 늘리는 대신, 미리 정한 하루 기준치에 맞춰 발송량을 늘려 가는 방식이에요. 이 기준치를 이해해 두면 이메일 캠페인을 계획하고 도메인이 언제 다음 단계로 올라갈 수 있는지 판단하기 쉬워요.

워밍업 모델의 규칙은 다음과 같아요.

- 워밍업 단계마다 하루 발송 기준치가 정해져 있어요.
- 다음 단계로 올라가려면 현재 단계의 하루 기준치를 모두 채워야 해요.
- 기준치에 도달하지 못하면 도메인은 현재 단계에 머물러요.
- 고정 단계 워밍업 모델은 시간당 발송 한도를 적용하지 않아요.
- 시스템이 진행 상황을 추적하려면 워밍업 중인 도메인으로 이메일을 보내야 해요.
- 단계 진행은 자동으로 관리돼요.

예시:

1단계 도메인의 하루 발송 기준치는 1,000통이에요.

- 하루에 600통을 보내면 1단계에 그대로 머물러요.
- 하루에 1,000통에 도달하면 2단계로 올라가기 위한 조건을 채운 거예요.
- 2단계의 하루 기준치는 2,500통이에요.

{% hint style="warning" %}
현재는 전용 도메인의 워밍업 기준치에 도달하거나 넘겨도 추가 이메일 발송이 자동으로 막히지 않아요. 이후 업데이트에서 엄격한 제한이 도입될 예정이에요. 그때까지는 전달률을 지키기 위해 권장 발송량을 따라 주세요.
{% endhint %}

워밍업 기준치는 계정 단위의 다른 발송 제한, 수신 메일 서비스의 발송 속도 제한, 이메일 컴플라이언스 제어와는 별개예요.

## 워밍업 단계와 하루 발송 기준치

고정 단계 워밍업은 총 15단계예요. 하루 1,000통에서 시작해 하루 250,000통까지 늘어나요. 미리 정해진 기준치를 보면 다음 단계로 올라가려면 얼마나 보내야 하는지 알 수 있어요.

| 워밍업 단계 | 하루 발송 기준치 |
| --- | --- |
| 1단계 | 1,000 |
| 2단계 | 2,500 |
| 3단계 | 5,000 |
| 4단계 | 6,500 |
| 5단계 | 8,000 |
| 6단계 | 10,000 |
| 7단계 | 14,000 |
| 8단계 | 20,000 |
| 9단계 | 25,000 |
| 10단계 | 35,000 |
| 11단계 | 50,000 |
| 12단계 | 80,000 |
| 13단계 | 125,000 |
| 14단계 | 175,000 |
| 15단계 | 250,000 |

### 단계 진행 방식

하이퍼클래스는 워밍업 중인 도메인의 발송 활동을 추적해요. 도메인이 현재 단계에 정해진 하루 기준치에 도달하면 다음 단계로 올라가기 위한 발송량 조건을 채운 거예요.

기준치에 도달하지 못하면 도메인은 현재 단계에 머물러요. 며칠이 지났다는 이유만으로 워밍업이 진행되지는 않아요.

{% hint style="info" %}
15단계 모델은 전용 도메인 워밍업에 적용돼요. 공유 도메인의 램프업은 별도 규칙으로 운영되고, 실제 발송 제한이 적용될 수 있어요.
{% endhint %}

## 새 도메인과 기존 도메인의 워밍업

새 전용 발송 도메인과 기존 전용 발송 도메인은 발송 이력이 다를 수 있어서 워밍업에 들어가는 방식도 달라요. 새 도메인은 인증이 끝나면 자동으로 시작해요. 기존 도메인은 이전 발송 활동과 평판 데이터를 바탕으로 권장 시작 단계를 받을 수 있어요.

### 새 전용 발송 도메인

새로 만든 도메인은 생성과 인증이 정상적으로 끝나면 워밍업이 자동으로 켜져요. 단, 계정에서 이 기능을 쓸 수 있어야 해요.

- 전용 발송 도메인을 만들어요.
- 필요한 DNS 인증을 마쳐요.
- 워밍업이 자동으로 시작돼요.
- 인증된 도메인으로 이메일을 보내면서 워밍업을 진행해요.

새로 만든 도메인에는 **Start Warmup**(워밍업 시작)을 따로 누를 필요가 없어요.

### 기존 전용 발송 도메인

기존 전용 도메인은 워밍업을 직접 켜야 해요. **Start Warmup**을 클릭하면 하이퍼클래스가 확인할 수 있는 발송 정보를 분석해서 알맞은 시작 단계를 권장해 줘요.

분석에는 다음 정보가 포함될 수 있어요.

- 과거 이메일 발송 이력
- 확인 가능한 도메인 평판 정보
- 연결되어 있는 경우 Google Postmaster 데이터

기존 도메인은 이전 발송 이력에 따라 새로 만든 도메인보다 더 높은 시작 단계를 권장받을 수 있어요.

{% hint style="info" %}
권장 시작 단계는 도메인이 쌓아 온 이력을 반영하기 위한 거예요. 워밍업 단계를 마음대로 건너뛸 수 있는 일반 옵션은 아니에요.
{% endhint %}

## 이메일 도메인 워밍업 켜는 방법

전용 발송 도메인을 올바르게 설정하고 인증해야 하이퍼클래스가 이메일 활동을 인식하고 워밍업 진행 상황을 추적할 수 있어요. 에이전시와 서브 계정 모두 **이메일 서비스**에서 이 기능에 들어갈 수 있어요. 켜는 방법은 도메인이 새것인지 기존 것인지에 따라 달라요.

### 에이전시 도메인의 워밍업 켜기

에이전시는 에이전시 설정에서 사용 가능한 전용 발송 도메인의 워밍업을 관리할 수 있어요. 에이전시 관리자만 쓸 수 있어요.

1. 하이퍼클래스 에이전시 계정을 열어요.
2. **에이전시 설정**으로 이동해요.

   ![에이전시 설정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082835978/original/hHpK2phTVCdUP9xWPo4Yji-kSJcWeoLpfA.png?1791456253)
3. **이메일 서비스**를 선택해요.
4. **SMTP 서비스** 탭을 열어요.
5. **Dedicated Domain and IP**(전용 도메인 및 IP)를 선택해요.

   ![Dedicated Domain and IP 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082835870/original/NHoZxkV18yvqftx97p8yoT-R4CPpMFPMrg.png?1791456200)
6. 워밍업할 기존 전용 도메인을 찾아요.
7. **Start Warmup**(워밍업 시작)을 클릭해요.
8. 하이퍼클래스가 알려 주는 권장 시작 단계를 확인해요.

   ![권장 시작 단계 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082836259/original/qxcqMv_O8cw73yWtbbwz9zggpsfHBqXsuw.png?1791456366)
9. 설정한 도메인으로 이메일을 보내면서 워밍업을 진행해요.

### 서브 계정 도메인의 워밍업 켜기

서브 계정은 자체 이메일 서비스 설정에서 기존 전용 발송 도메인의 워밍업을 켤 수 있어요.

1. 해당 **서브 계정**을 열어요.
2. **설정**으로 이동해요.
3. **이메일 서비스**를 선택해요.
4. **SMTP 서비스**를 열어요.
5. **Dedicated Domain and IP**를 선택해요.
6. 기존 전용 발송 도메인을 찾아요.
7. **Start Warmup**을 클릭해요.
8. 권장 시작 단계를 확인해요.

   ![서브 계정의 권장 시작 단계 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082836374/original/b33Y7ip-Pnd5qQDUt-1DHLXCBZrEv3Dh8A.png?1791456460)
9. 선택한 도메인으로 이메일을 보내면서 워밍업 단계를 진행해요.

## 워밍업 진행 상황 확인하기

도메인의 워밍업 상태를 확인하면 지금의 발송 활동이 다음 단계로 올라가기에 충분한지 알 수 있어요. 발송량을 크게 늘리기 전에 평판 문제를 미리 발견할 기회도 돼요.

![워밍업 진행 상황 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082836414/original/PAAvYEMVh1pz7h7K7Q3O_FGuWlYE6govLg.png?1791456491)

도메인을 확인하는 방법은 다음과 같아요.

1. 해당하는 계정 수준에서 **설정 > 이메일 서비스 > SMTP 서비스 > Dedicated Domain and IP**로 이동해요.
2. 워밍업 중인 도메인을 찾아요.
3. 표시된 워밍업 단계와 상태를 확인해요.
4. 그 단계의 하루 기준치와 내 발송 활동을 비교해요.
5. 확인할 수 있는 전달률과 평판 정보를 살펴봐요.

워밍업 진행 상황을 볼 때는 다음 내용을 기억해 두세요.

- 발송량이 단계 기준치보다 계속 낮으면 현재 단계에 머물러요.
- 다른 도메인으로 보낸 이메일은 워밍업 중인 도메인의 진행에 포함되지 않아요.
- 플랫폼에서 발송이 허용되더라도 발송량을 너무 빠르게 늘리면 평판에 나쁜 영향을 줄 수 있어요.
- 확인 가능한 Google Postmaster 데이터를 보면 도메인의 발송 상태를 더 자세히 알 수 있어요.

## 자주 묻는 질문

### 외부 SMTP 제공업체에서도 고정 단계 워밍업을 쓸 수 있나요?

이 문서에서 설명하는 기능은 하이퍼클래스 이메일 서비스로 관리하는, 조건에 맞는 전용 발송 도메인에 적용돼요. 외부 SMTP 서비스는 자체 워밍업 방식과 발송 제한이 있을 수 있어요.

### 워밍업 시스템이 이메일을 대신 보내 주나요?

아니요. 고정 단계 방식은 설정한 도메인에서 실제로 보낸 발송 활동을 추적해요. 워밍업이 진행되려면 그 도메인으로 직접 이메일을 보내야 해요.

### **Start Warmup** 버튼이 안 보여요.

이 기능은 단계적으로 제공하고 있어서 모든 계정에서 동시에 쓸 수 있지는 않아요. 또 새로 만든 도메인은 인증이 끝난 뒤 직접 켜지 않아도 돼요. 조건에 맞는 전용 발송 도메인을 올바른 설정 화면에서 보고 있는지 확인해 보세요.

### 워밍업 기준치를 넘기면 추가로 보낸 이메일도 모두 전달되나요?

아니요. 현재 전용 도메인 워밍업 기준치는 초과 발송을 막지 않지만, 플랫폼의 다른 제한, 메일 서비스의 필터링, 발송 속도 제한이 전달에 영향을 줄 수 있어요.

### Google Postmaster를 연결하면 현재 워밍업 단계가 자동으로 바뀌나요?

아니요. 워밍업을 시작한 뒤에 Google Postmaster를 연결하면 평판 데이터를 더 볼 수 있지만, 현재 단계가 소급해서 바뀌지는 않아요.

### 전용 발송 도메인 여러 개를 동시에 워밍업할 수 있나요?

워밍업 진행 상황은 이메일을 보낸 도메인에 연결돼요. 도메인 여러 개로 캠페인을 계획할 때는 각 도메인의 발송 활동을 따로 따져 봐야 해요.
