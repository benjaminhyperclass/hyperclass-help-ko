# WordPress 사이트 복제하기

기존 WordPress 사이트를 설정, 테마, 플러그인까지 그대로 복제해 새 사이트를 만드는 방법을 안내해요. 복제 기능을 쓸 수 있는 권한과 단계별 절차를 함께 설명해요.

## WordPress 사이트 복제란?

WordPress 사이트 복제는 기존 사이트를 복사해, 완전히 독립된 새 사이트를 만드는 기능이에요. 원본 사이트의 설정, 테마, 플러그인, 콘텐츠가 그대로 유지돼요. 레이아웃, 디자인, 설정이 비슷한 사이트를 여러 개 만들 때 특히 유용해요.

## WordPress 사이트를 복제하는 이유

- 효율성: 처음부터 만들지 않고 기존 사이트의 구성을 재사용해서 시간을 아낄 수 있어요.
- 일관성: 여러 사이트에서 테마, 플러그인, 설정을 똑같이 맞출 수 있어요.
- 유연성: 사이트가 서로 독립적이라, 한 사이트를 바꿔도 다른 사이트에는 영향이 없어요.
- 사용 편의성: 업데이트를 테스트하거나 개발 환경을 만드는 것처럼 복잡한 작업이 간단해져요.

## 복제 권한

보안을 위해 사용자 역할에 따라 복제 기능을 쓸 수 있는지가 정해져요. 다음 역할의 사용자만 WordPress 사이트를 복제할 수 있어요.

- 에이전시 소유자
- 에이전시 사용자
- 계정 사용자(같은 서브 계정 안에서)

필요한 권한이 없으면 처음부터 새 사이트를 만드는 것만 할 수 있어요. 이렇게 해서 권한이 있는 사람만 사이트를 복제하도록 해요.

## 하이퍼클래스에서 WordPress 사이트 복제하기

1. **WordPress Dashboard**(WordPress 대시보드)로 이동해요.

   - 하이퍼클래스에 로그인한 뒤 **WordPress Dashboard**로 들어가세요.
   - **새로 만들기** 또는 **Select Blank WordPress**(빈 WordPress 선택)를 선택하세요.

     ![WordPress 대시보드에서 새로 만들기를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080490848/original/2JmX39iStGrCxD_Y4eUT6hta-CwqsCwMpQ.png?1788957436)
2. 복제 옵션을 열어요.

   - **설정 미완료** 카드를 클릭하세요.
   - **Choose From Existing Site**(기존 사이트에서 선택)를 선택하세요.
3. 원본 사이트와 새 사이트를 정해요.

   - 새 사이트를 둘 **서브 계정**을 선택하세요.
   - 복제할 **Source Site**(원본 사이트)를 선택하세요.
   - **New Website Name**(새 웹사이트 이름)을 입력하세요.

     ![원본 사이트와 서브 계정을 선택하고 새 웹사이트 이름을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080491111/original/q8zC_nbvWfzTTZoGFGzMENMATQW7gNE5tQ.png?1788957535)
4. 복제를 시작해요.

   - **복제**를 클릭하면 복제가 시작돼요.
5. 진행 상황을 확인해요.

   - 복제가 진행되는 동안 진행 상태가 실시간으로 표시돼요.
6. 새 사이트를 확인해요.

   - 복제가 끝나면 새 사이트가 WordPress 대시보드에 독립된 사이트로 나타나요.
   - 복제한 사이트를 수정해도 원본에는 영향이 없어요.

## 자주 묻는 질문

### 복제 기능은 누가 쓸 수 있나요?
에이전시 소유자, 에이전시 사용자, 계정 사용자(같은 서브 계정 안에서) 역할을 가진 사용자만 복제 기능을 쓸 수 있어요.

### 필요한 권한이 없으면 어떻게 되나요?
역할상 복제 권한이 없으면 복제 대신 새 사이트를 만드는 과정으로 진행돼요.

### 한 사이트를 바꾸면 다른 사이트에도 영향이 있나요?
아니요. 복제한 사이트는 원본과 완전히 독립돼 있어서, 한쪽을 수정해도 다른 쪽에는 영향이 없어요.

### 복제 진행 상황을 확인할 수 있나요?
네. 복제하는 동안 진행 상태가 실시간으로 표시돼요.

### 복제하면 무엇이 그대로 유지되나요?
원본 사이트의 설정, 테마, 플러그인이 모두 복제한 사이트에 그대로 유지돼요.
