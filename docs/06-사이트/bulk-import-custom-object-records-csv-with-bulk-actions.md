# CSV로 사용자 지정 객체 레코드 한꺼번에 가져오기와 일괄 작업

CSV 파일로 사용자 지정 객체 레코드를 한 번에 만들거나 업데이트하는 방법을 설명해요. 가져오기 모드, 중복 확인, **일괄 작업** 페이지에서 가져오기를 관리하는 방법도 함께 다뤄요.

## 사용자 지정 객체 일괄 가져오기란?

CSV 파일을 올려서 새 사용자 지정 객체 레코드를 만들거나, 기존 레코드를 업데이트하거나, 두 가지를 한 번에 처리할 수 있어요. 고유 필드를 기준으로 중복을 확인할 수 있고, **일괄 작업** 페이지에서 진행 상황을 확인하고 문제를 해결할 수 있어요. 덕분에 사용자 지정 객체 데이터를 더 빠르게 준비하면서 중복과 가져오기 충돌도 줄일 수 있어요.

## 일괄 가져오기의 장점

안정적인 일괄 가져오기는 수작업을 줄이고, 데이터가 늘어나도 사용자 지정 객체 데이터를 일관되게 유지해 줘요.

- 빠른 준비: 레코드를 하나씩 만들지 않고 CSV로 대량의 사용자 지정 객체 레코드를 가져올 수 있어요.
- 유연한 가져오기 모드: 상황에 따라 **만들기**, **업데이트**, **만들기 + 업데이트** 중에서 선택할 수 있어요.
- 중복 확인으로 깔끔한 데이터: 고유 필드로 중복을 막고 레코드 충돌을 줄일 수 있어요.
- 작업 제어: **일괄 작업** 페이지에서 가져오기를 일시 중지, 재개, 취소할 수 있어요.
- 확인하기 쉬운 결과: 가져오기 통계, 행별 오류와 경고, 해결 안내를 볼 수 있어요.

## 가져오기 설정 순서

CSV 파일을 깔끔하게 준비하고 필드를 올바르게 매핑하면 가져오기가 순조롭게 끝나요. 같은 순서로 설정하면 중복과 행별 오류를 줄이고, 레코드를 정확하게 만들거나 업데이트할 수 있어요.

1. 서브 계정에서 **사용자 지정 객체**를 열고, 레코드를 가져올 사용자 지정 객체를 선택하세요.

   ![사용자 지정 객체 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065774/original/rURyE1iwWflD_PUpiaQse66Y64S2cOB6Pg.png?1772528385)
2. 오른쪽 위의 **가져오기**를 클릭하세요.

   ![가져오기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065600/original/UIMsXatm_JyFA7sfVL9VwolmksI0EKlQgQ.png?1772528322)
3. **오브젝트 선택**에서 가져올 오브젝트를 골라 가져오기를 시작하세요.

   ![오브젝트 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065232/original/zaZPN74OlyQ5g-HV8ifGUAEBsN0PLYQ4Gw.png?1772528144)
4. 가져오기 모드를 선택하세요. **만들기**, **업데이트**, **만들기 + 업데이트** 중에서 고를 수 있어요.

   ![가져오기 모드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065429/original/5fGsoLWs8irXuFFaDil3tdUvPgkeKfSHww.png?1772528241)
5. 중복 확인 기준이 되는 고유 필드를 선택하라는 안내가 나오면 선택하세요. 고유 필드를 여러 개 매핑한 경우에만 나타나요.

   ![중복 확인 고유 필드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065098/original/T8NBcPtgyGTdyLgLJrTj_5Tu5A2vD4Yw8w.png?1772528085)
6. 필드를 매핑하세요.

   - **기본** 필드와 **필수 필드**를 먼저 매핑하세요.
   - 그다음 나머지 필드를 매핑하세요. 필요하면 **소유자**와 **팔로워**도 매핑할 수 있어요.

     ![필드 매핑 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066064856/original/KKUgprH5g-oxMfptQen1ATJ6REsMcsS47w.jpeg?1772527939)
7. 업데이트 가져오기에서 빈 값도 적용해야 한다면 **빈 값 업데이트**를 켜세요. 기본 필드와 필수 필드는 빈 값 업데이트에서 제외돼요.

   ![빈 값 업데이트 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066066159/original/ehIpY0AMaOwb4bcZe_gW6Ydf9-QeB7ohbg.png?1772528616)
8. **가져오기 시작**을 클릭하세요.
9. **일괄 작업 > 사용자 지정 객체**에서 가져오기를 확인하고 제어하세요.

   - 필요하면 **일시 중지**, **재개**, **취소**를 선택할 수 있어요.
   - 가져오기 항목을 열면 통계와 행별 결과를 볼 수 있어요.

## 자주 묻는 질문

### 만들기, 업데이트, 만들기 + 업데이트는 각각 언제 쓰나요?
완전히 새로운 데이터를 가져올 때는 **만들기**를 쓰세요. 기존 레코드만 수정하려면 **업데이트**를 쓰세요. CSV에 새 레코드와 기존 레코드가 섞여 있으면 **만들기 + 업데이트**를 쓰세요.

### 왜 중복 확인용 필드를 선택하라고 하나요?
고유 필드를 여러 개 매핑하면, 가져오는 동안 어떤 고유 필드로 중복 여부를 비교할지 하이퍼클래스가 물어봐요.

### "고유 필드 간 엄격한 충돌 처리"는 무슨 뜻인가요?
어떤 행이 고유 필드 규칙을 어기면, 가져오기에서 그 행에 오류나 경고가 표시돼요. 예를 들어 다른 레코드에 이미 있는 고유 값을 넣으려 하는 경우가 그래요. 표시된 행을 보고 직접 수정할 수 있어요.

### 빈 값 업데이트는 어떤 기능인가요?
업데이트할 때 CSV의 빈 값도 그대로 적용해요. 다만 기본 필드와 필수 필드는 빈 값 업데이트에서 제외돼요.

### 가져오기를 일시 중지했다가 나중에 다시 시작할 수 있나요?
네. **일괄 작업 > 사용자 지정 객체**에서 가져오기를 **일시 중지**하고 **재개**할 수 있어요.

### 가져오기를 취소하면 어떻게 되나요?
취소하면 가져오기가 더 이상 진행되지 않아요. 취소하기 전에 이미 처리된 행은 그대로 적용되어 있을 수 있어요.

### 어떤 행이 실패했는지, 어떻게 고치는지는 어디서 보나요?
가져오기 상세 화면을 열고 **통계** 창의 탭에서 **오류**와 **경고**를 확인하세요. 행별 메시지에는 **How to Resolve**(해결 방법) 안내가 들어 있어요.

### CSV 파일 하나로 여러 사용자 지정 객체를 가져올 수 있나요?
아직은 안 돼요. 여러 오브젝트를 한 번에 가져오는 기능은 현재 사용할 수 없고, **출시 예정**이라고 표시돼요.
