# SEO 구독 취소와 프로젝트 상태(동결 상태)

SEO 구독을 취소하면 시스템이 자동으로 정리 절차를 시작해요. 이미 적용한 최적화는 그대로 두고, 진행 중인 자동화만 멈춰요. 이 문서에서 구독 취소 후 SEO 프로젝트가 어떻게 되는지 확인하세요.

## SEO 구독 취소 흐름 한눈에 보기

SEO 구독을 취소하면 프로젝트 데이터와 SEO Pixel로 적용한 수정 사항은 그대로 남아요. 사이트 크롤링이나 새 추천 같은 자동화만 멈춰요.

구독을 취소하면 SEO Pixel을 쓰는 프로젝트는 동결 상태(Frozen State)로 바뀌어요. SEO Pixel 스크립트가 설치되어 있는 동안에는 이미 적용한 수정 사항이 웹사이트에 계속 반영돼요. 대신 자동화는 멈춰요. 프로젝트 설정과 적용한 수정 사항은 계정에 보관되므로 나중에 다시 활성화하기 쉬워요.

### 이 흐름의 장점

- 수정 사항 유지: SEO Pixel로 이미 적용한 SEO 추천과 수정 사항이 구독 취소 후에도 웹사이트에 남아 있을 수 있어요. 그동안 진행한 작업이 사라지지 않아요.
- 자동 정리: 프로젝트가 자동으로 동결 상태가 돼요. 따로 정리 작업을 할 필요가 없어요.
- 프로젝트 보관: 프로젝트 설정과 적용한 수정 사항이 계정에 연결된 채로 남아 있어서 나중에 다시 활성화하기 쉬워요.

---

## SEO 구독 취소하기

1. 하이퍼클래스의 서브 계정에서 **사이트 > SEO**로 이동하세요.
2. **Site Projects**(사이트 프로젝트) 탭에서 SEO 페이지 오른쪽 위에 있는 점 세 개 메뉴를 클릭하고 **구독 취소**를 선택하세요.

   ![SEO 페이지 점 세 개 메뉴에서 구독 취소를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067928851/original/PXwzirYdR9Uf5RIMohbfi99PVG-xXYYRLA.png?1774632033)
3. 확인 창이 나타나면 **예, 취소합니다**를 클릭해 취소를 확정하세요.

## 동결 상태(Frozen State)

SEO Pixel을 쓰는 활성 프로젝트가 있으면, 구독을 취소하는 즉시 해당 프로젝트가 자동으로 동결 상태로 바뀌어요. 이 과정은 모두 백그라운드에서 진행돼요. 직접 할 일은 없어요.

### 동결된 프로젝트의 특징

- 수정 사항 유지: Pixel 스크립트로 이미 적용한 SEO 추천과 수정 사항이 웹사이트에 그대로 남아요. 구독이 끝나도 작업 내용이 사라지지 않아요.
- 자동화 일시중지: 시스템이 사이트 크롤링을 멈추고, 새 SEO 감사 추천도 만들지 않아요.
- 데이터 보관: 기존 프로젝트 설정과 적용한 수정 사항이 계정에 보관돼요.

---

## 적용된 최적화 관리하기

구독을 취소한 뒤에도 SEO 변경 사항을 사이트에 어떻게 반영할지는 직접 정할 수 있어요.

- 변경 사항을 유지하려면: 웹사이트에 SEO Pixel 스크립트를 그대로 두세요. 스크립트가 온전히 남아 있는 동안에는 적용한 최적화가 방문자에게 계속 보여요.
- 변경 사항을 없애려면: 최적화가 사이트에 나타나지 않게 하고 싶다면 웹사이트 코드에서 SEO Pixel 스크립트를 직접 삭제하세요. 삭제하면 사이트가 바로 원래 상태로 돌아가요.

---

## 다시 구독하고 재활성화하기

다시 구독하면 활성 상태로 쉽게 돌아갈 수 있어요.

1. 사용 가능한 플랜으로 다시 구독하세요.
2. 대시보드에서 프로젝트를 다시 연결하세요.
3. 프로젝트가 동결 해제 상태(Unfrozen State)로 바뀌어요. 그러면 바로 다시 크롤링하고, 새 추천을 받고, 새 SEO 수정 사항을 적용할 수 있어요.

---

## 프로젝트 상태 비교

### 구독 중

- 기존 Pixel 수정 사항: 적용 중, 편집 가능
- 사이트 크롤링: 사용 가능
- 새 추천: 사용 가능
- 시스템 동작: 전체 자동화

### 동결 상태(구독 취소)

- 기존 Pixel 수정 사항: 적용 중, 읽기 전용
- 사이트 크롤링: 일시중지
- 새 추천: 일시중지
- 시스템 동작: 자동 중단
