# Facebook 연동 시 페이지 관리에 Facebook 페이지가 보이지 않을 때

Facebook을 하이퍼클래스 계정에 연동할 때 Facebook 비즈니스 페이지가 목록에 나타나지 않는 경우가 꽤 있어요. 이 문서에서는 **페이지 관리**에 페이지가 보이지 않을 때 해결하는 방법을 안내해요.

## 페이지가 보이지 않을 때 해결하는 방법

1. [Facebook](http://www.Facebook.com)에 로그인해요.
2. 오른쪽 위에 있는 프로필 사진 아이콘을 클릭하고 **Settings and Privacy**(설정 및 개인정보)로 이동해요.

   ![Facebook 오른쪽 위 프로필 아이콘에서 Settings and Privacy 메뉴를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48285091296/original/jyxWYZ4ZcuGHSZ3Y-Takz5Y5Xjvxwexk2w.png?1677853417)

3. **Settings and Privacy** 안에서 **설정**을 클릭해요.

   ![Settings and Privacy 안에서 설정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48285091548/original/MY4la9WnthkRntpMaAdBlu_f6dhJhKsRpA.png?1677853476)

4. 왼쪽 메뉴에서 [**Business Integrations**(비즈니스 연동)](https://www.facebook.com/settings?tab=business_tools&ref=settings)를 클릭해요.

   ![왼쪽 메뉴의 Business Integrations 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48285091853/original/s3zujjbzAF5uRlCs2fykCNKLtuEIPjggTA.png?1677853560)

5. **하이퍼클래스** 앱 옆의 **view and edit**(보기 및 수정)을 클릭해요.

   ![하이퍼클래스 앱 옆의 view and edit 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48285092344/original/jlqQEEAyTN6cIIlaiDZTsdKyR7qG1tUgoA.png?1677853642)

6. 모든 토글이 켜져 있는지 확인해요. 맨 아래까지 스크롤하면서 꺼진 토글을 모두 켜 주세요.

   ![모든 토글을 켠 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48285092785/original/ZlVTDWKCD6_Afo0yub7nrhW66R5N-1waog.png?1677853718)

{% hint style="info" %}
Facebook 페이지를 연동한 사용자만 페이지 드롭다운 목록에서 해당 페이지를 볼 수 있어요. 그 사용자가 해당 Facebook 페이지의 관리자여야 드롭다운 목록에 페이지가 보여요. 다른 계정의 Facebook 페이지는 더 이상 목록에 나타나지 않아요.

![드롭다운 목록에 연동한 페이지만 표시되는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48291400274/original/g41sAjRNyGtEtdYy-9Cv6ezS7sGvCqVccA.png?1680771876)
{% endhint %}

7. 페이지 목록이 체크박스와 함께 나타나면, 에이전시의 서브 계정과 관련된 페이지를 모두 선택해요.

   ![페이지 목록에서 관련 페이지를 체크박스로 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48285093690/original/GnmWUdLTUrDK53xlp16hxtC5P-W0QY5R_g.png?1677853807)

8. 선택을 마쳤으면 **저장**을 클릭해요.

   ![저장 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48285094456/original/VcAwN-8XK9TNOxA3JBA3wZUSYbzILsQNmw.png?1677853940)

{% hint style="warning" %}
이미 선택되어 있는 페이지가 있다면 선택을 해제하지 마세요. 해제하면 지금 이 서브 계정에 연동하려는 페이지가 아니더라도, 그 페이지와 에이전시의 서브 계정 사이의 연동이 끊어져요.
{% endhint %}
