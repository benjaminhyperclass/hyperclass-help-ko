# Jobber 연동 설정

Jobber와 하이퍼클래스를 연동하면 현장 운영 데이터와 마케팅 데이터를 같은 상태로 유지할 수 있어요. 이 문서에서는 연동으로 할 수 있는 일과 에이전시·서브 계정별 설정 방법을 안내해요.

## 하이퍼클래스와 Jobber 연동이란?

Jobber 연동은 Jobber의 현장 서비스 운영과 하이퍼클래스의 영업·마케팅을 하나로 이어 줘요. 클라이언트와 연락처 정보가 두 플랫폼에서 같게 유지돼요. 그래서 일상 업무는 Jobber에서 처리하고, 고객 소통과 파이프라인은 하이퍼클래스에서 자동화할 수 있어요. 데이터를 다시 입력하지 않아도 되고, 기록이 서로 어긋날 걱정도 없어요.

## 주요 장점

- 양방향 클라이언트 동기화: 이름, 이메일, 전화번호, 주소 등을 두 시스템에서 똑같이 유지해요.
- 정확한 매칭: Jobber 클라이언트 ID로 연결하기 때문에 이메일이나 전화번호가 바뀌어도 중복 기록이 생기지 않아요.
- 과거 데이터와 실시간 동기화: 선택한 날짜부터의 과거 클라이언트 데이터를 가져온 뒤, 새 클라이언트는 자동으로 계속 동기화돼요.
- 스냅샷 포함: 미리 만들어진 워크플로우와 메시지 템플릿으로 더 빠르게 시작할 수 있어요.
- 마케팅과 운영의 연결: 작업은 Jobber에서 진행하고, 퍼널·CRM·자동화는 하이퍼클래스에서 활용해요.
- 수작업 감소: 반복 입력을 없애고 입력 오류를 줄여요.
- 일관된 리포팅: 클라이언트 데이터가 통합되어 어트리뷰션과 캠페인 타기팅이 더 정확해져요.

## 설정 방법

설정을 제대로 마치면 데이터가 정확하게 동기화되고, 포함된 스냅샷과 워크플로우를 바로 쓸 수 있어요. 에이전시와 각 서브 계정에서 아래 단계를 차례로 진행하세요.

{% hint style="info" %}
앱은 에이전시 관리자만 보고 설치할 수 있어요. 에이전시가 앱을 설치하기 전에는 서브 계정에 앱이 보이지 않고 사용할 수도 없어요.
{% endhint %}

### 1단계: 에이전시에서 설치하고 한꺼번에 배포하기

1. 하이퍼클래스 에이전시 화면에서 **앱 마켓플레이스**(App Marketplace)를 여세요.
2. **Jobber**를 검색하세요.
3. **Jobber Integration** 앱을 클릭하세요.

   ![Jobber Integration 앱 선택 화면](https://jumpshare.com/share/n6A7mU6pwuHOatG3Pl35+/Screen+Shot+2025-10-22+at+7.33.22+PM.png)
4. **설치**를 클릭하세요.

   ![설치 버튼 화면](https://jumpshare.com/share/XQ0IkNwoYjm7F0MYeXeC+/Screen+Shot+2025-10-22+at+7.42.35+PM.png)
5. 앱을 배포할 서브 계정을 선택하세요.
6. **계속하기**를 클릭하세요.

   ![서브 계정 선택 후 계속하기 화면](https://jumpshare.com/share/ocpCcjM4aRBMoWE2bJ4A+/Screen+Shot+2025-10-22+at+7.44.23+PM.png)
7. 스냅샷에서 푸시하거나 업데이트할 **자산**을 선택하세요.
8. 서브 계정의 현재 데이터와 충돌 확인 없이 진행하려면 **Proceed without conflict check**(충돌 확인 없이 계속)를 클릭하세요.
9. 충돌을 확인하고 진행하려면 **Proceed to check conflicts**(충돌 확인 후 계속)를 클릭하세요.

   ![충돌 확인 선택 화면](https://jumpshare.com/share/diQxQLRosdELsPSGwwbL+/Screen+Shot+2025-10-22+at+7.46.21+PM.png)
10. 충돌 확인을 선택했다면 **+** 아이콘을 클릭해 서브 계정의 충돌 항목을 펼쳐서 확인하세요. 이어서 덮어쓸 자산을 선택하세요.
11. **계속하기**를 클릭하세요.
12. 입력란에 Confirm을 입력하고 **계속하기**를 클릭하세요.

    ![확인 문구 입력 화면](https://jumpshare.com/share/3JnSuod7JPUJ6yWgmMj1+/GIF+Recording+2025-10-22+at+7.55.26+PM.gif)
13. **허용 및 설치**를 클릭하세요.

    ![허용 및 설치 화면](https://jumpshare.com/share/NtA4zxh7aAlnpDXkl7da+/Screen+Shot+2025-10-22+at+7.58.28+PM.png)

### 2단계: 서브 계정 연결하기

1. 설치한 서브 계정으로 전환하세요.
2. **앱 마켓플레이스 > 설치된 앱 > Jobber**를 클릭하세요.
3. **연결**을 클릭하고 안내에 따라 인증을 완료하세요.

   ![서브 계정에서 Jobber 연결 화면](https://jumpshare.com/share/y8TfIa2QF5TlEeIIdDgd+/GIF+Recording+2025-10-22+at+8.23.20+PM.gif)

## 자주 묻는 질문

### Jobber 계정 하나에 서브 계정을 여러 개 연결할 수 있나요?
아니요. Jobber는 활성 연결을 하나만 지원해요. 그래서 Jobber 계정 하나에는 하이퍼클래스 서브 계정을 하나만 연결할 수 있어요.

### 하이퍼클래스와 Jobber 사이의 첫 연락처·클라이언트 동기화에는 시간이 얼마나 걸리나요?
Jobber는 5분마다 약 2,500건의 기록을 동기화할 수 있어요. Jobber 앱의 **데이터 동기화** 탭에서 선택한 시작일에 따라 전체 클라이언트 데이터를 하이퍼클래스로 가져오는 데 필요한 만큼 시간이 걸려요.

### 하이퍼클래스와 Jobber 사이에 어떤 필드가 동기화되나요?
**First Name**(이름), **Last Name**(성), **Email**(이메일), **전화번호**, **Address**(주소), **Lead Source**(리드 소스), **Jobber Client URL**(Jobber 클라이언트 URL), Jobber **생성일**, 태그가 동기화돼요.

### 하이퍼클래스와 Jobber 사이에 동기화되지 않는 정보는 무엇인가요?
Jobber의 **커스텀 필드**, 메모, 첨부파일은 동기화되지 않아요.

### 하이퍼클래스는 클라이언트와 연락처를 어떻게 매칭하나요?
하이퍼클래스는 Jobber 클라이언트의 고유 ID를 보관해요. 그래서 이메일이나 전화번호를 바꿔도 동기화가 유지돼요.

### 양방향 동기화를 일시 중지하거나 중단할 수 있나요?
아니요. 현재는 그 기능이 없어요. Jobber에서 만든 워크플로우에 영향을 주지 않고 동기화를 멈추려면, Jobber에서 앱 연결을 해제해야 해요. Jobber의 **App Marketplace > Connected Apps**(연결된 앱)에서 하이퍼클래스 앱을 찾아 **Disconnect**(연결 해제) 버튼을 클릭하세요.

### 동기화를 시작한 뒤에 과거 클라이언트 데이터의 동기화 시작일을 바꿀 수 있나요?
아니요. Jobber의 과거 데이터 동기화는 Jobber 데이터 동기화를 시작할 때 한 번만 할 수 있어요. 과거 데이터를 한 번 동기화하고 나면 기간을 바꾸거나 다른 시작일로 동기화를 다시 시작할 수 없어요.

### 동기화된 클라이언트 데이터의 로그를 볼 수 있나요?
동기화 로그는 현재 제공되지 않아요.
