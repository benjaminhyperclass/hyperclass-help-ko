# Printify 연동으로 이커머스 스토어에서 주문제작 상품 판매하기

재고 부담 없이 브랜드 굿즈를 판매하고 싶을 때 쓰는 기능이에요. 하이퍼클래스 스토어를 Printify의 상품 1,000개 이상, 글로벌 프린트 제공업체 85곳 이상과 연결하면, 모든 주문이 주문 후 제작 방식으로 만들어져요. 상자를 쌓아 둘 필요도, 대량으로 사들일 필요도 없어요.

## Printify 연동이란?

Printify 연동은 하이퍼클래스 이커머스 스토어를 Printify의 주문제작(POD, Print-on-Demand) 플랫폼에 연결해 줘요. 연결하면 다음을 할 수 있어요.

- Printify에서 디자인한 상품 가져오기
- 고객 주문을 제작 업체로 자동 전달
- 처리 상태를 실시간으로 받아보기

주문제작은 판매가 이루어진 뒤에 상품을 인쇄하는 방식이에요. 그래서 재고 비용이나 대량 주문 부담 없이 맞춤 상품을 팔 수 있어요.

## Printify 연동의 주요 장점

- 빠른 출시: 맞춤 제작이 가능한 상품 1,000개 이상으로 새 상품 라인을 빠르게 만들 수 있어요.
- 지역별 속도와 가격: 프린트 제공업체 85곳 이상 중에서 경쟁력 있는 가격과 빠른 현지 배송을 고를 수 있어요.
- 항상 정확한 상품 정보: 옵션, 가격, 이미지가 자동으로 동기화돼요.
- 자동 주문 처리: 주문이 Printify로 자동 전송되어 제작에 들어가요. 직접 다시 입력할 필요가 없어요.
- 처음부터 끝까지 추적: 부분 배송과 전체 배송 상태를 자동으로 받아볼 수 있어요.
- 여러 스토어 관리: 하나의 Printify 계정으로 여러 스토어를 관리하고, 위치별 실적을 확인할 수 있어요.

## 알아 두세요

- 가져온 상품은 기본적으로 바로 게시돼요. 판매를 시작하기 전에 꼭 다시 확인하세요.
- 연동을 제거해도 이전에 가져온 상품은 삭제되지 않아요.
- Printify는 선택한 배송 국가, 옵션, 배송 방법을 처리할 수 있는 프린트 제공업체가 있을 때만 주문을 만들어요.
- 디자인 작업은 모두 Printify에서 해요. 하이퍼클래스는 이미 동기화된 상품의 재고와 주문만 관리해요.
- 연동을 인증하려면 Printify API 토큰이 필요해요.

## Printify API 토큰 생성하기

1. Printify에 로그인한 뒤 **계정**을 클릭하세요.
2. **연결**을 클릭하세요.
3. **API Tokens**(API 토큰) 아래의 **생성** 버튼을 클릭하세요.

   ![Printify API 토큰 생성 버튼](https://jumpshare.com/share/U105nFY9b0MhE4HQt6nG+/Screen+Shot+2025-10-09+at+5.04.05+PM.png)
4. 토큰 이름을 입력하고 권한 범위를 선택한 뒤 **생성**을 클릭하세요.

   ![토큰 이름과 권한 범위 선택 화면](https://jumpshare.com/share/63sQkEA5sAuHz8U9zD2c+/Screen+Shot+2025-10-09+at+5.08.30+PM.png)
5. **클립보드에 복사**를 클릭해 토큰을 복사하세요.

   ![생성된 토큰을 클립보드에 복사하는 화면](https://jumpshare.com/share/aDZSEWopXynzDjjzFkUQ+/Screen+Shot+2025-10-09+at+5.09.24+PM.png)

## Printify를 하이퍼클래스에 연결하기

연결은 몇 분이면 끝나요. 아래 순서대로 설정하면 주문이 문제없이 이어져요.

1. 서브 계정에서 **앱 마켓플레이스**(App Marketplace)를 여세요.

   ![앱 마켓플레이스 메뉴](https://jumpshare.com/share/UrEIyVGIqHEfB3XYCVvx+/Screen+Shot+2025-10-09+at+5.12.38+PM.png)
2. **Printify**를 검색한 뒤 **설치** 버튼을 클릭하세요.

   ![Printify 앱 설치 화면](https://jumpshare.com/share/IenovVwFcwvX3FM93Lvu+/SCR-20251006-moze.png)
3. **Printify Token**(Printify 토큰) 입력란에 복사해 둔 Printify API 토큰을 붙여 넣고 **계속**을 클릭하세요.

   ![Printify 토큰 입력 화면](https://jumpshare.com/share/hKr14Fg8eL06i8YqLpBC+/image+%282%29.png)
4. 기존 Printify 스토어를 선택하거나 새로 만드세요. **Convert Product Currency to**(상품 통화 변환 기준)에서 가져온 Printify 상품 가격에 쓸 통화를 선택하고 **연결**을 클릭하세요.
5. 상품을 가져와 스토어에 바로 게시하세요.
6. 판매를 시작하세요. 주문은 처리를 위해 Printify로 자동 동기화돼요. Printify에서 자동 주문 처리(automatic fulfillment)를 켜 두세요.

   ![Printify 자동 주문 처리 설정 화면](https://jumpshare.com/share/OBF8Ct54xT2VeUgg5ZT9+/image+%283%29+%281%29.png)

## 배송 프로필과 결제 시 실시간 배송비

Printify는 전용 배송 프로필을 사용해서 결제 단계에서 동기화된 상품의 실시간 배송 옵션을 보여 줘요. Printify 상품을 이 프로필에 계속 연결해 두면, 고객이 결제할 때 Printify의 실시간 배송비를 이용할 수 있어요.

Printify 상품을 동기화하면 하이퍼클래스가 필요한 Printify 배송 프로필을 자동으로 만들어요.

- Printify 배송 프로필에 연결된 상품은 결제 시 Printify 실시간 배송비가 표시돼요.
- 결제 시 실시간 배송비를 받으려면 상품이 Printify 배송 프로필에 계속 연결되어 있어야 해요.

## 자주 묻는 질문

### 하이퍼클래스에서 상품을 직접 디자인할 수 있나요?
아니요. 디자인과 목업은 Printify에서 만들어요. 하이퍼클래스에는 가져온 내용이 그대로 반영돼요.

### Printify에서 상품을 삭제하면 어떻게 되나요?
다음 동기화 때 하이퍼클래스 카탈로그에서 해당 상품이 비활성화돼요.

### Printify가 가장 가까운 프린트 제공업체를 자동으로 선택하나요?
선택한 제공업체에 시설이 여러 곳이면 Printify가 가장 가까운 시설로 주문을 보내요.

### Printify 대신 주문을 직접 처리할 수 있나요?
네. 자동 주문 처리를 끄고 Printify에서 직접 처리하세요. 이 경우에도 하이퍼클래스는 상태 업데이트를 계속 받아요.

### Printify 연동을 쓰면 하이퍼클래스에 추가 요금이 있나요?
아니요. 요금은 제작과 배송에 대해 Printify에서만 발생해요.

### 환불은 어떻게 처리하나요?
하이퍼클래스에서 환불을 처리하세요. 아직 배송되지 않은 상품에 대해서는 Printify로 환불 요청이 전송돼요.

### 고객 주소가 제공업체의 배송 가능 지역이 아니면 어떻게 되나요?
Printify가 주문을 거절하고, 하이퍼클래스에는 "Unfulfilled – No provider available."(미처리 – 이용 가능한 제공업체 없음)이 표시돼요. 주문을 편집해서 배송 가능한 옵션이나 제공업체를 선택하세요.

### Printify에서 바꾼 상품 정보가 하이퍼클래스에도 반영되나요?
네. 설명, 목업, 옵션, 가격, 이미지가 자동으로 동기화돼요.

### Printify 주문이 자동으로 만들어지나요?
네. 하이퍼클래스에서 결제가 이루어질 때마다 그에 맞는 Printify 주문이 만들어져요.

### 세금과 배송 설정도 함께 전달되나요?
네. 세금과 배송 정보가 동기화된 주문에 포함돼요.

### 주문 정보를 직접 다시 입력해야 하나요?
아니요. 자동화되어 있어서 중복 입력이 필요 없고, 주문 처리도 빨라져요.

### 배송 및 제작 상태도 하이퍼클래스로 다시 동기화되나요?
네. Printify가 제작 중, 배송 중, 배송 완료 같은 상태를 실시간으로 보내 줘요.

### 부분 배송도 지원하나요?
네. 상품이 배송될 때마다 항목별 추적 정보와 상태 업데이트가 동기화돼요.

### Printify 계정 하나를 여러 스토어에 연결할 수 있나요?
네. Printify 계정 하나를 하이퍼클래스 스토어 여러 곳에 연결할 수 있어요.

### 위치별로 주문이 구분되어 관리되나요?
네. 주문과 지표는 스토어별로 묶여서 표시돼요. 상품 생성과 결제(청구)는 한곳에서 통합 관리돼요.
