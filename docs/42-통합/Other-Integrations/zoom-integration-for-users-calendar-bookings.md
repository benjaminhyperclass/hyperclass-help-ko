# 사용자 캘린더 예약에 Zoom 연동하기

Zoom 계정을 캘린더와 연동하면 예약이 잡힐 때마다 고유한 Zoom 미팅 링크가 자동으로 만들어져요. 이 문서에서는 연동 방법과 예약 리마인더 워크플로우 설정 방법, 자주 묻는 질문을 안내해요.

{% hint style="info" %}
동적 Zoom 링크는 **Personal**(개인), **Round Robin**(라운드 로빈), **Collective**(공동) 캘린더에서만 쓸 수 있어요.
{% endhint %}

Zoom은 영상, 음성, 전화, 채팅으로 동시에 소통할 수 있는 커뮤니케이션 플랫폼이에요. Zoom 계정을 그룹 캘린더와 연동하면 예약을 만들고, 리마인더를 보내고, 다가오는 일정을 한곳에서 관리할 수 있어요.

---

## Zoom 연동이란?

Zoom 연동을 쓰면 하이퍼클래스 안에서 바로 Zoom 미팅을 예약하고, 시작하고, 관리할 수 있어요. 앱을 오가며 작업할 필요가 없어요.

하이퍼클래스에서 Zoom 연동을 설정해 두면 새 미팅이 잡힐 때마다 고유한 Zoom 미팅 링크가 동적으로 만들어져요. 사용자 가용성과 캘린더 설정의 미팅 장소가 Zoom으로 되어 있으면 이 과정은 자동으로 진행돼요.

미팅마다 고유한 링크가 만들어지면 보안이 높아지고, 원치 않는 방해도 줄어들어요. 참석자마다 다른 링크를 받기 때문에 권한 없는 사람이 들어오기 어려워요.

예를 들어 고객과 미팅을 잡을 때 미팅 장소를 Zoom으로 선택하면, 하이퍼클래스가 새 Zoom 미팅을 만들고 고유한 링크를 캘린더 이벤트에 넣어요. 고객은 이 Zoom 링크가 담긴 초대장을 받아요. 이 링크는 해당 미팅 한 번에만 쓰여서, 참여하는 모두에게 편리하고 안전해요.

또한 예약된 Zoom 미팅은 모두 하이퍼클래스에 자동으로 기록돼요. 예약을 관리하고 일정을 파악하기가 더 쉬워요.

### 활용 사례

- 팀 미팅: 미팅이 잡힐 때마다 고유한 Zoom 링크가 자동으로 만들어져서 팀 안에서 소통하기가 간편해요.
- 고객 상담: 고객이 미팅을 예약할 때마다 고유한 Zoom 링크가 자동으로 만들어져서, 상담 과정이 더 매끄럽고 전문적이에요.
- 웨비나: 참가자가 등록하면 개인별 Zoom 링크가 자동으로 만들어져서 웨비나 운영이 수월해요.
- 온라인 오피스 아워: 교사나 교수가 오피스 아워나 보충 수업을 효율적으로 운영할 수 있어요. 학생이 시간대를 예약하면 고유한 Zoom 미팅이 만들어져서 일정 조율의 번거로움이 사라져요.
- 온라인 피트니스 수업: 강사가 수업을 편하게 운영할 수 있어요. 회원이 수업을 예약할 때마다 고유한 Zoom 링크가 발송돼요.
- 가상 부동산 투어: 구매 희망자가 투어를 예약하면 고유한 Zoom 미팅이 만들어져서, 집에서 편하게 매물을 볼 수 있어요.
- 원격 진료 예약: 환자가 진료를 예약하면 고유한 Zoom 미팅이 만들어져서, 의료 서비스를 집에서 받을 수 있어요.
- 온라인 요리 수업: 참가자가 등록하면 개인별 Zoom 링크가 만들어져서, 참가자의 주방에서 요리 수업을 진행할 수 있어요.

### 이 기능의 장점

Zoom 연동의 장점은 다음과 같아요.

- 미팅 예약 자동화: 연동을 설정하면 미팅마다 고유한 Zoom 링크가 자동으로 만들어져요. 수동 설정에 드는 시간을 줄이고 실수를 막아 줘요.
- 중앙 관리: 예약, 일정 변경, 취소 등 미팅과 관련된 모든 작업을 하이퍼클래스에서 바로 처리할 수 있어요. 한곳에서 관리하니 효율이 높아지고 전달 오류가 줄어요.
- 다중 사용자 접근: 참석자 수와 관계없이 참석자마다 고유한 Zoom 링크가 자동으로 만들어져요. 보안을 지키고 미팅 경험도 좋아져요.
- 캘린더 동기화: Zoom 미팅 예약이 하이퍼클래스 캘린더와 바로 동기화돼요. 중복 예약을 막고 시간 관리에도 도움이 돼요.
- 실시간 업데이트: 하이퍼클래스에서 일정을 바꾸거나 취소하면 Zoom에도 실시간으로 반영돼요. 정보가 어긋나는 일이 줄고 조율이 쉬워져요.
- 보안 강화: 미팅마다 고유한 링크를 쓰기 때문에 초대받지 않은 사람이 들어올 위험이 줄어요.
- 자동 알림: 미팅 상세 정보와 변경 사항을 참석자에게 자동으로 알려 줘요. 메시지를 직접 보내는 수고를 덜고 참석률도 높아져요.
- 데이터 추적: 참석 여부, 미팅 시간 등 미팅 데이터를 폭넓게 추적할 수 있어요. 패턴을 분석하고 업무 프로세스를 개선하는 데 도움이 돼요.

## 연동 전 확인할 점

- 모든 사용자가 캘린더용 Zoom 연동을 쓸 수 있어요.
- 사용자가 각자 자신의 Zoom 계정을 **프로필**에 연결해요. 그러면 그 사용자가 배정된 그룹 캘린더에서 예약이 잡힐 때마다 고유한 링크가 만들어져요.
- 동적 Zoom 링크는 Round Robin과 Collective 캘린더에서만 쓸 수 있어요.

### 같은 Zoom 계정을 여러 사용자에 연동하기

Zoom 연동은 이메일 주소가 아니라 내부적으로 사용자 고유 ID에 연결돼요. Zoom 연결은 이제 같은 Zoom 계정을 여러 사용자와 여러 서브 계정에서 쓸 수 있도록 지원해요. 공유된 연결을 관리하려면 **캘린더 > 설정 > 연결 > Video Conferencing**(화상 회의)을 이용하세요.

같은 에이전시 안에서 이메일 주소가 서로 다른 사용자나, 여러 에이전시에 걸쳐 Zoom 계정을 연결해야 하는 사용자는 문제를 겪을 수 있어요.

특정한 경우에는 하이퍼클래스 고객지원의 도움으로 삭제된 사용자 계정을 복원하면, 같은 이메일 주소에 사용자 ID가 두 개 생길 수 있어요. 이때 복원된 계정은 새 사용자 ID 때문에 원래의 Zoom 계정에 다시 연결하지 못할 수 있어요.

시스템에서는 사용자 ID와 이메일 주소를 서로 다른 식별자로 다루고, Zoom 연동은 사용자 ID를 기준으로 해요. 연동의 고유 식별자는 이메일 주소가 아니라 사용자 ID라는 점을 기억하세요.

조금 복잡해 보이지만 이 차이를 알아 두면 연동 문제를 피할 수 있어요. 예시로 살펴볼게요.

"ABC Marketing"이라는 에이전시에 사용자가 세 명 있다고 해요.

- 사용자 A: 사용자 ID "A001", 이메일 "a@abcmarketing.com"
- 사용자 B: 사용자 ID "B002", 이메일 "b@abcmarketing.com"
- 사용자 C: 사용자 ID "C003", 이메일 "c@abcmarketing.com"

이 사용자들은 각자 자신의 Zoom 계정을 에이전시 플랫폼의 프로필에 연동하려고 해요.

사용자 A는 사용자 ID "A001"로 Zoom 계정을 연결했어요. 그런데 어떤 이유로 사용자 A의 프로필이 삭제되었고, 고객이 하이퍼클래스 고객지원에 문의해 복원했다고 해요. 복원하면서 사용자 A에게 새 사용자 ID "A004"가 부여되었고, 이메일은 그대로 "a@abcmarketing.com"이에요.

여기서 혼란이 생길 수 있어요. 사용자 A가 Zoom 계정을 다시 연결하려 해도, 이 Zoom 계정은 여전히 이전 사용자 ID "A001"에 연결되어 있어요. 그래서 새 사용자 ID "A004"로 연결하려고 하면 시스템이 막아요. 시스템 입장에서는 이 Zoom 계정이 이미 다른 사용자 ID에 연결된 상태이기 때문이에요.

그래서 Zoom 연동은 이메일 주소가 아니라 사용자 ID에 연결된다는 점을 기억해야 해요. 이메일 주소가 같아도 시스템은 사용자 ID를 고유 식별자로 봐요.

또 다른 경우로, 사용자 A는 자신의 Zoom 계정을 사용자 B의 프로필에도 연동할 수 없어요. 이 Zoom 계정이 여전히 사용자 ID "A001"에 연결되어 있기 때문이에요. 같은 에이전시 안이라도 사용자 ID가 서로 다르면 Zoom 계정을 공유할 수 없어요.

이 원리를 이해하면 혼란을 줄이고 연동을 더 쉽게 진행할 수 있어요.

{% hint style="info" %}
같은 사용자가 여러 서브 계정에 서로 다른 Zoom 계정을 연결하거나, 같은 Zoom 계정을 여러 사용자에게 쓰는 것은 권장하지 않아요.
{% endhint %}

## 하나의 Zoom 계정을 여러 서브 계정·사용자에서 쓰기

같은 Zoom 계정을 여러 서브 계정에 연결하고, 여러 사용자가 함께 쓸 수 있어요.

- 여러 서브 계정에서 같은 계정 사용: 같은 Zoom 계정을 여러 서브 계정에 연결할 수 있어요.
- 여러 사용자가 같은 계정 사용: 여러 사용자가 같은 Zoom 계정을 연결해서 쓸 수 있어요.
- 제한: 사용자 한 명은 서브 계정마다 Zoom 계정을 하나만 연결할 수 있어요.

### 동적 링크 조건

연결된 Zoom 계정을 캘린더의 미팅 장소로 선택했을 때만 동적 Zoom 링크가 만들어져요.

### 연결된 Zoom 계정 해제하거나 바꾸기

**캘린더 > 설정 > 연결 > Video Conferencing**에서 연결된 Zoom 계정을 해제하거나 다른 계정으로 바꿀 수 있어요.

1. **캘린더 > 설정 > 연결 > Video Conferencing**으로 이동해요.
2. 기존 Zoom 연결을 해제하거나, 다른 Zoom 계정을 연결해요.
3. 동적 Zoom 링크를 만들어야 하는 캘린더마다 **미팅 장소** 설정을 확인해요.

## 1단계: Zoom 연동 설치하기

예약된 미팅에 Zoom을 설정하는 방법은 세 가지예요.

- 프로필의 연동에서 설정
  - **프로필 > 연동 > Zoom > 연결**을 클릭해요.
  - 대화 상자에서 **Connect to Zoom**(Zoom에 연결)을 클릭해요. 아직 연결하지 않은 경우에만 나타나요.
  - Zoom 로그인 정보를 입력하고 **로그인**을 클릭해요.
  - Zoom이 회원님의 Zoom 계정에 접근해도 되는지 묻는 창이 나와요. **허용**을 클릭해요.
  - 하이퍼클래스로 돌아오면 프로필의 **연동**에 Zoom이 표시돼요.
- 기본 미팅 장소에서 설정
  - **프로필 > Default Meeting Location**(기본 미팅 장소) **> Zoom > 연결**을 클릭해요.
  - 대화 상자에서 **Connect to Zoom**을 클릭해요. 아직 연결하지 않은 경우에만 나타나요.
  - Zoom 로그인 정보를 입력하고 **로그인**을 클릭해요.
  - Zoom이 회원님의 Zoom 계정에 접근해도 되는지 묻는 창이 나와요. **허용**을 클릭해요.
  - 하이퍼클래스로 돌아오면 프로필의 **연동**에 Zoom이 표시돼요.
  - 드롭다운에서 Zoom을 선택하고 **저장**을 누르면, 다른 모든 캘린더의 기존 미팅 장소도 Zoom으로 바꿀지 묻는 창이 나와요.
- 캘린더 설정에서 설정
  - **설정 > 캘린더 설정 > 사용자 [x] > 미팅 장소**로 이동해요.
  - 대화 상자에서 **Connect to Zoom**을 클릭해요. 아직 연결하지 않은 경우에만 나타나요.
  - Zoom 로그인 정보를 입력하고 **로그인**을 클릭해요.
  - Zoom이 회원님의 Zoom 계정에 접근해도 되는지 묻는 창이 나와요. **허용**을 클릭해요.
  - 하이퍼클래스로 돌아오면 프로필의 **연동**에 Zoom이 표시돼요.
  - 드롭다운에서 Zoom을 선택하면 예약할 때마다 미팅에 Zoom 링크가 포함돼요.

{% hint style="info" %}
프로필 설정에서 연동하려면 해당 사용자로 로그인해 있어야 해요. 서브 계정 설정에서 **프로필** 옵션이 보이지 않으면, 에이전시 수준의 **팀** 설정에서 해당 사용자의 역할을 편집해 그 서브 계정에 배정해야 해요.
{% endhint %}

## 다른 사용자의 Zoom을 관리자로 설정하기

해당 사용자가 이미 Zoom 연동을 설치했다면, **팀 관리**에서 그 Zoom을 사용자의 **Default Meeting Location**(기본 미팅 장소)으로 선택할 수 있어요.

{% hint style="info" %}
Zoom을 연동하려면 각 사용자가 자신의 계정에 로그인해 있어야 해요. 에이전시 관리자는 "Login As User"(사용자로 로그인) 기능으로 에이전시 안의 모든 사용자 대신 이 과정을 진행할 수 있어요.
{% endhint %}

## 2단계: Zoom 장소가 포함된 예약 리마인더 워크플로우 만들기

**워크플로우 빌더**(Workflow Builder)는 활용도가 높은 도구예요. 여기서는 다가오는 예약을 알리는 내부·외부 리마인더를 동적 Zoom 링크와 함께 자동화하는 데 써요. 아래 트리거와 액션을 조합해 직접 만들거나, 제공되는 레시피 템플릿을 쓸 수도 있어요.

{% hint style="info" %}
워크플로우 빌더 화면은 영어로 표시돼요. 아래 이름은 화면에 보이는 그대로 적었어요.
{% endhint %}

1. **Add New Workflow Trigger**(새 워크플로우 트리거 추가)를 클릭해요.

   ![워크플로우 트리거 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206660/original/S3Jj3DZ7tw5oVVrf675riHl1iYjyzSLZsA.png?1685555017)

2. 트리거로 **Appointment Status**(예약 상태)를 선택하고 다음 필터를 추가해요.
   - **Event Type**(이벤트 유형): 일회성 예약인지, 반복 예약인지, 둘 다 해당되게 할지 정해요.
   - **Appointment Status**: 캘린더 설정에서 예약 자동 확정을 켜 두면 모든 예약이 이 필터에 해당돼요.
   - **In Calendar**(캘린더 내): 특정 캘린더나 특정 사용자로 범위를 좁힐 때 선택해요. 필수는 아니에요.

   ![예약 상태 트리거와 필터 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206662/original/yPxrWPmscg8nb2ajniYeIIK41mZBuhgzNQ.png?1685555017)

3. **Add your first Action**(첫 번째 액션 추가)을 클릭해요.

   ![첫 번째 액션 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206661/original/UKPzULnHxI0XGo-sHcaDI4wjAnTXDNAEFQ.png?1685555017)

4. 첫 번째 액션으로 **Wait**(대기) 단계를 1분으로 추가해요. 미팅 장소 값이 업데이트될 시간을 확보하기 위해서예요.

   ![1분 대기 단계 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206664/original/iGbrgntY2P6mG-d7jRX-OOtWDozGO88BpQ.png?1685555018)

5. 이어서 예약 완료 알림을 보내는 액션을 추가해요. **Send Email/SMS**(이메일/SMS 보내기)는 연락처에 등록된 기본 이메일과 전화번호로 알림을 보내요. 동적 Zoom 링크가 전달되도록 메시지에 커스텀 값 `{{appointment.meeting_location}}`을 꼭 넣으세요.

   사용할 수 있는 커스텀 값과 머지 필드 목록이 궁금하다면 하이퍼클래스 고객지원에 문의하세요.

   ![이메일/SMS 보내기 액션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206666/original/n3MremtNoREea-aDu7-xIMMGxJS8Pxlo3g.png?1685555020)

6. 필요하면 **Internal Notification**(내부 알림) 액션으로 담당 사용자나 외부 연락처에게 이메일, SMS, 앱 내 예약 리마인더를 보낼 수 있어요.

   {% hint style="info" %}
   내부 알림 이메일을 보낼 때는 do-not-reply@agency.com이나 notifications@agency.com 같은 주소를 쓰세요. 연락처가 먼저 시작한 대화와 헷갈리지 않아요.
   {% endhint %}

   ![내부 알림 액션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206665/original/IzaXTOV1gVRvWBNGhf3wL1g1fRhL_0kHYw.png?1685555020)

7. 마지막으로 **Event/Appointment Time**(이벤트/예약 시간) 대기 액션으로 알림 주기를 정해요. 앞에서 만든 **Send Email/SMS**, **Internal Notification** 액션과 함께 쓰세요.
   - 이벤트 전에 다음 리마인더를 얼마나 앞서 보낼지 정해요. 이 예시에서는 24시간을 기다린 뒤 다음 액션(이메일/SMS 보내기 또는 내부 알림)이 실행돼요.
   - 다음 중에서 선택해요.     - **Move to the next step**(다음 단계로 이동): 다음 액션을 실행하고 워크플로우를 순서대로 진행해요.
     - **Move to a specific step**(특정 단계로 이동): 리드를 워크플로우의 특정 액션으로 이동시켜요.
     - **Skip all outbound communication actions until the next wait step**(다음 대기 단계까지 모든 발신 커뮤니케이션 액션 건너뛰기): 이메일과 SMS를 보내지 않고, 다음 대기 단계까지 리드를 워크플로우 순서대로 진행시켜요.

   ![이벤트/예약 시간 대기 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206669/original/HpmFx3C2NsvtOxSYnc1ydHloPe5Gyx_iIA.png?1685555020)

## 자주 묻는 질문

### 사이드바에 프로필 탭이 없어요.

사이드바에 **프로필** 탭이 보이지 않으면, 해당 서브 계정의 사용자(직원)가 아니라는 뜻이에요. **스태프 관리 > + 직원 추가 > 직원 추가 > 저장**을 눌러 직접 사용자로 추가하세요.

![스태프 관리에서 직원 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206667/original/Nzf6NA_NPQE2hJ4Tx1ZhVUIwnKewEeCvVg.png?1685555020)

에이전시 사용자 프로필을 이 서브 계정에 직원으로 추가하려면 다음과 같이 해요.

1. **에이전시 보기 > 에이전시 설정**으로 이동해요.
2. **팀** 탭을 클릭해요.
3. 사용자를 검색해요.
4. **사용자 역할**을 클릭해요.
5. **Add to Sub-account**(서브 계정에 추가)를 클릭해요.
6. 추가할 서브 계정을 선택해요.

{% hint style="info" %}
에이전시 프로필과 서브 계정 프로필을 오갈 때는 에이전시 관리자가 쓸 수 있는 "login-as" 기능을 이용하세요.
{% endhint %}

### 미팅을 수정하면 미팅 링크는 어떻게 되나요?

미팅 날짜와 시간이 그대로라면, 이전에 만들어진 Zoom 미팅 링크는 계속 정상적으로 작동해요.

### 미팅을 삭제하면 미팅 링크는 어떻게 되나요?

미팅이 취소되거나 삭제되면 Zoom 미팅 링크는 영구적으로 삭제돼요. 같은 시간대에 같은 미팅 링크를 쓰는 다른 미팅이 있으면 삭제되지 않아요.

### 미팅 일정을 다른 시간으로 변경하면 미팅 링크는 어떻게 되나요?

미팅 일정을 변경하면 새 미팅 링크가 만들어져요. 같은 시간대에 다른 예약이 있으면 이전에 만들어진 링크를 다시 사용해요.

### 같은 시간대에 Zoom 미팅이 여러 개 있으면 어떻게 되나요?

**캘린더 설정**에서 한 시간대에 여러 예약을 받도록 해 두면, 그 미팅들 모두에 같은 미팅 링크가 재사용돼요.

{% hint style="info" %}
현재 사용자 한 명은 하루(UTC 기준)에 미팅을 만들고, 수정하고, 삭제하는 요청을 최대 100건까지 쓸 수 있어요. 이 24시간 주기는 사용자나 계정의 현지 시간대가 아니라 UTC 00:00에 초기화돼요.
{% endhint %}

### Zoom에 있는 기존 이벤트가 캘린더에 보이지 않아요.

현재 Zoom 연동은 Zoom에서 이벤트를 가져오지 않아요. Zoom에서 직접 만든 미팅에 미리 만들어진 미팅 링크를 쓰지도 않아요.

### 어떤 캘린더 버전에서 쓸 수 있나요?

현재 동적 Zoom 연동은 그룹 캘린더에서만 작동해요.

### 배정되지 않은 캘린더에 Zoom을 연동하려면 어떻게 하나요?

배정되지 않은 예약 캘린더는 고정 링크나 미리 만들어 둔 Zoom 미팅 링크를 쓸 수 있어요. **Team and Event Setup**(팀 및 이벤트 설정) 아래 **미팅 장소** 설정에 고정 링크를 직접 입력하세요.

![팀 및 이벤트 설정의 미팅 장소에 고정 링크 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000206668/original/-jTZ-dQlZq3LjkIa24xsFk24aelYjLVvYg.png?1685555020)
