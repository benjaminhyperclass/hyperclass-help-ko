# Stripe 일회성 결제 트리거(Stripe One Time Charge)는 어떻게 작동하나요?

**Stripe One Time Charge**(Stripe 일회성 결제) 트리거가 어떤 설정과 연결되어 있는지, 사용하려면 무엇이 필요한지 알려 드려요.

이 트리거는 항상 **에이전시 설정**에 있는 Stripe 연동과 연결되어 있어요.

{% hint style="warning" %}
일회성 결제(OTC)가 작동하려면 Stripe에서 카드 하나를 기본 카드로 설정해 두어야 해요.
{% endhint %}
