# Facebook 페이지가 여러 개일 때 연동 문제 해결하기 — Troubleshoot와 Sync Leads

Facebook 연동에 새로 생긴 **Troubleshoot**(문제 해결) 버튼과 바뀐 화면을 소개해요. 폼 매핑이나 권한 문제를 직접 해결하고 리드를 동기화할 수 있어서 고객지원에 문의하는 일이 줄어요.

## Facebook 연동의 Troubleshoot 버튼이란?

**Troubleshoot** 버튼을 누르면 안내에 따라 Facebook 연동 문제를 찾아서 고칠 수 있어요. 권한이 빠졌거나 폼이 매핑되지 않은 경우처럼 자주 생기는 문제를 다뤄요. 처리되지 않은 리드는 개선된 **Sync Leads**(리드 동기화) 기능으로 몇 번만 클릭해서 처리할 수 있어요. 직접 하나씩 점검하지 않아도 돼요.

## Troubleshoot 버튼을 쓰면 좋은 점

고객지원 도움 없이도 Facebook 연동을 직접 관리할 수 있어요.

- 권한과 폼 매핑 문제를 직접 해결하기 쉬워요.
- 폼이 올바르게 매핑되고 권한이 최신 상태로 유지되어 놓치는 리드가 줄어요.
- 수동 동기화보다 자동 리드 동기화를 제대로 쓰도록 도와줘요.
- 화면이 더 깔끔해져서 집중해서 쓰기 편해요.

## Troubleshoot 버튼으로 Facebook 연동 문제 해결하기

1. 계정에서 **Facebook Integration**(Facebook 연동) 카드를 여세요.
2. 바뀐 화면을 확인하세요. **설정**과 **Disconnect**(연결 해제) 버튼은 점 세 개 메뉴 안으로 옮겨져서 화면이 더 깔끔해졌어요.
3. 문제가 있으면 경고 아이콘이 표시돼요.

   - Facebook 폼이 매핑되지 않았으면 경고 아이콘이 나타나요.

     - 아이콘을 클릭하면 **폼 필드 매핑** 화면으로 이동해서 문제를 해결할 수 있어요.
   - 권한이 빠져 있으면 다른 모양의 경고 아이콘이 나타나요.

     - 아이콘을 클릭하면 연결 문제 해결(**Troubleshoot**)을 안내하는 창이 열려요.

4. **Troubleshoot**를 클릭해 문제 해결 안내 화면으로 들어가요.
5. 문제 해결 화면에서 다음을 진행해요.

   - 강조 표시된 권한 문제나 매핑 경고를 확인하세요.
   - 필요하면 **Sync Leads** 옵션으로 처리되지 않은 리드를 처리해요.
6. **Sync Leads**를 사용할 때는 아래 순서대로 진행해요.

   - 드롭다운에서 시간 범위를 선택합니다(예: 최근 7일, 30일).
   - 동기화할 내용을 요약해서 보여 주는 창이 열리면 내용을 확인하세요.

7. **확인**을 클릭하면 서브 계정에 연결된 모든 Facebook 페이지의 매핑된 폼 전체에 대해 리드 동기화가 시작돼요.
8. 동기화가 끝나면 Facebook 리드가 CRM에 제대로 들어왔는지 확인하세요.

## 중요 참고 사항

- **Sync Leads**는 수동 작업 절차로 잘못 쓰이지 않도록 일부러 **Troubleshoot** 안으로 옮겼어요. 리드가 자동으로 동기화되지 않을 때만 사용하세요.
- 이제 한 페이지씩이 아니라, 서브 계정에 매핑된 모든 페이지와 폼을 한 번에 동기화해요.
- 경고 아이콘을 따라가면 해결되지 않은 문제로 바로 이동해요. 헷갈리거나 고객지원에 문의할 일이 줄어요.
- Facebook 연동은 올바른 폼 매핑과 권한이 있어야 작동해요. 리드를 계속 동기화하려면 경고를 꼭 해결해야 해요.

## 자주 묻는 질문

### Sync Leads가 왜 Troubleshoot 안으로 옮겨졌나요?
많은 사용자가 근본 문제를 해결하지 않고 수동 동기화 단계로 **Sync Leads**를 써 왔어요. **Troubleshoot** 안으로 옮겨서 문제 해결용 기능이라는 점을 분명히 했어요.

### Sync Leads를 쓰지 않아도 리드가 자동으로 동기화되나요?
네. 폼 매핑과 권한이 올바르면 리드는 자동으로 동기화돼요.

### 페이지 하나만 골라서 리드를 동기화할 수 있나요?
아니요. 새 디자인은 놓치는 리드가 없도록 모든 페이지의 매핑된 폼을 한꺼번에 동기화해요.

### 폼이 매핑되지 않으면 어떻게 되나요?
경고 아이콘이 표시돼요. 아이콘을 클릭하면 Facebook 폼 필드를 매핑하는 화면으로 바로 이동해요.

## 다음 단계

- **Facebook Integration** 카드에 경고가 있는지 확인하세요.
- **Troubleshoot** 버튼으로 권한과 매핑 문제를 해결하세요.
- 자동 동기화가 되지 않을 때만 처리되지 않은 리드를 동기화하세요.
- 다음 주에 UI 개선이 더 예정되어 있으니 계속 확인해 주세요.
