# Facebook·Instagram 메시징 설정 및 문제 해결

Facebook 페이지와 Instagram 비즈니스 계정을 연결해서, 하이퍼클래스 안에서 바로 대화를 관리할 수 있도록 설정하는 방법을 안내해요. 메시지가 오가지 않을 때 확인할 항목도 함께 정리했어요.

## Facebook 페이지 메시징 설정

1. 하이퍼클래스가 해당 페이지의 메시지를 보내고 받을 수 있는 권한을 가지고 있는지 확인하세요. 확인은 [Facebook 비즈니스 도구 설정](https://www.facebook.com/settings?tab=business_tools&ref=settings)에서 할 수 있어요.

2. 사용 중인 사용자 계정에 페이지 전체 권한과 메시지 권한이 있는지 확인하세요. 확인은 [Facebook 비즈니스 설정](https://business.facebook.com/latest/settings)에서 할 수 있어요.

   [![Facebook 비즈니스 설정에서 페이지 권한을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051975374/original/cp0IkVvwNzY-Ovfo4YuShCC4JyALOaiK9Q.jpeg?1755682293)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046618449/original/jD5YyOakvOAc3JTp5SfO-NdLt6qeSc-1vQ.png?1747225602)

3. **설정 > 연동** 메뉴에서 **Facebook** 카드의 **설정**을 열고, Facebook Messenger가 켜져 있는지 확인하세요.

   [![연동 화면의 Facebook 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051975370/original/ubh0Lx2BwLcsbdL_e6QNzWcPkwidz_0A-Q.jpeg?1755682293)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046618680/original/fXU2j4i8_yMPm5b_vp4sgqbteIBBnFBnIw.png?1747225743)

   [![Facebook Messenger 사용 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051975368/original/a41m_xMR_kzMScBsSDM4Ro8SfMgMvXNxPw.jpeg?1755682292)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046618711/original/Kw8mxcMbUAe45MoZsidRgdE5GNORLGLDdg.png?1747225761)

## Instagram 메시징 설정

1. 하이퍼클래스가 해당 페이지의 메시지를 보내고 받을 수 있는 권한을 가지고 있는지 확인하세요. 확인은 [Facebook 비즈니스 도구 설정](https://www.facebook.com/settings?tab=business_tools&ref=settings)에서 할 수 있어요.

2. [Facebook 비즈니스 설정](https://business.facebook.com/latest/settings)의 **Instagram accounts**(Instagram 계정) 아래에서, Instagram 메시지를 보내고 받을 수 있는 권한이 있는지 확인하세요.

   [![Instagram 계정의 메시지 권한을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051975369/original/nhErqFoGV5OIegyHIHcNcbDrovfqJf9NCQ.jpeg?1755682293)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046820921/original/tLINkNzirrxoXfTSJdGxULjH4cx8k9f3Ug.png?1747628845)

3. 연결된 페이지의 연결된 자산 목록에 Instagram 계정이 있는지 확인하세요.

   [![연결된 자산 목록에서 Instagram 계정을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051975371/original/rhD9Rep3yoErxPaN6MV6KiE2NpVJ1UIaRw.jpeg?1755682293)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046820913/original/rThbgLELyFW3QsFfS1WTuVteuNKAyl2-ag.png?1747628832)

4. **설정 > 연동** 메뉴에서 **Facebook** 카드의 **설정**을 열고, Instagram 메시징이 켜져 있는지 확인하세요.

   [![Instagram 메시징 사용 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051975372/original/DAyCnypW3ZQUyFnsnFIGJUt3SbX3qGNf5w.jpeg?1755682293)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046820968/original/rYafkZPj6wQIXvvuNGOOqY4P2wQWSO_S0Q.png?1747629000)
