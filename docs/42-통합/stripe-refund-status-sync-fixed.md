# Stripe 환불 상태 동기화 오류 수정

Stripe와 하이퍼클래스 사이에서 환불 상태가 어긋나던 문제를 수정했어요. 이제 Stripe에서 직접 처리한 환불도 하이퍼클래스 대시보드에 자동으로 반영돼요. 결제 데이터가 더 정확해지고 환불 관련 오류도 줄어들어요.

## 수정된 내용

- 환불 상태가 Stripe에서 하이퍼클래스로 올바르게 동기화돼요.
- 서로 맞지 않거나 업데이트되지 않은 결제 기록이 없어져요.
- 환불이 중복으로 시도되는 일을 막아요.
- 하이퍼클래스에서 환불할 때 나던 오류가 사라져요.

## 동기화 방식

Stripe에서 환불이 처리되면 하이퍼클래스가 거래 상태를 자동으로 바꿔 줘요.

이 동기화는 백그라운드에서 실행돼요. 따로 설정할 것은 없어요.

## 할 일

따로 할 일은 없어요.

Stripe 연동이 활성화된 모든 계정에 이 수정이 자동으로 적용돼요.

## 이 수정이 중요한 이유

이전에는 환불 상태가 서로 맞지 않아 다음과 같은 문제가 생길 수 있었어요.

- 결제 기록이 헷갈림
- 환불 중복 시도
- 하이퍼클래스에서 환불을 처리할 때 오류 발생

이제 두 플랫폼의 결제 데이터가 일치하고, 환불 작업도 더 안정적으로 진행돼요.

## 권장 사용 방법

추적과 리포팅을 가장 일관되게 하려면, 가능하면 하이퍼클래스 대시보드에서 직접 환불을 처리하세요.

## 앞으로의 계획

플랫폼 간 결제 동기화를 계속 개선하고 있어요.

PayPal을 비롯한 다른 결제 제공업체도 실시간으로 업데이트되도록 지원을 준비 중이에요.

## 자주 묻는 질문

### 이 수정이 적용되려면 Stripe를 다시 연결해야 하나요?
아니요. 기존 Stripe 연동에 자동으로 적용돼요.

### 지금도 Stripe에서 직접 환불할 수 있나요?
네. 이제 Stripe에서 처리한 환불도 하이퍼클래스에 올바르게 동기화돼요.

### 이 수정은 왜 필요했나요?
이전에는 Stripe와 하이퍼클래스 사이에서 환불 상태가 서로 달라질 수 있었어요. 그 때문에 오류가 나거나 같은 작업이 중복으로 실행되기도 했어요.

### 환불이 동기화되지 않으면 어떻게 하나요?
먼저 Stripe 계정이 연결되어 있는지 확인하세요. 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.
