# 카운트다운 타이머 V3 공개 API 사용하기

하이퍼클래스의 카운트다운 타이머 V3 공개 API를 쓰면 타이머를 코드로 만들고, 조회하고, 수정하고, 삭제할 수 있어요. 고정·동적·반복 타이머를 모두 지원하고, 세부 스타일 설정, 템플릿 둘러보기, 필터링도 쓸 수 있어요. 이 문서에서는 사용할 수 있는 API 작업과, 연동으로 카운트다운 타이머를 관리하는 방법을 안내해요.

## V3 카운트다운 타이머 API란?

V3 카운트다운 타이머 API로 하이퍼클래스의 카운트다운 타이머를 코드로 관리할 수 있어요. 화면에서 타이머를 하나씩 설정하지 않아도 타이머의 생성부터 삭제까지 전 과정을 다룰 수 있어요.

이 API는 토큰으로 서브 계정을 확인하는 방식으로 인증해요. 그래서 엔드포인트 URL에 `locationId`를 넣지 않아도 돼요. 응답에도 디자인 메타데이터, 미리보기·트래킹 링크, 썸네일 같은 정보가 더 많이 담겨요.

### V3 API의 장점

V3 API를 쓰면 카운트다운 타이머 관리가 간단해지고, 타이머 설정과 연동을 더 세밀하게 제어할 수 있어요.

- 전체 수명 주기 관리: 타이머를 코드로 만들고, 조회하고, 수정하고, 소프트 삭제할 수 있어요.
- 여러 타이머 유형: 고정, 동적, 반복 카운트다운 타이머를 관리할 수 있어요.
- 템플릿 접근: 공유 타이머 템플릿을 둘러보고 더 빠르게 설정할 수 있어요.
- 세부 사용자 지정: `designMeta`로 타이머 모양을 설정할 수 있어요.
- 유연한 필터링: 페이지 나누기(페이지네이션)와 함께 타이머를 검색하고 필터링할 수 있어요.
- 간단한 API 접근: URL에 `locationId` 없이 토큰 기반 엔드포인트를 쓸 수 있어요.
- 풍부한 응답: 디자인 메타데이터, 미리보기·트래킹 링크, 썸네일을 받을 수 있어요.

## 지원하는 카운트다운 타이머 유형

V3 API는 세 가지 타이머 유형을 지원해요. 캠페인 목적에 맞는 유형을 골라 설정하세요.

| 타이머 유형 | 설명 |
| --- | --- |
| 고정(Fixed) | 정해진 날짜와 시간까지 카운트다운해요. |
| 동적(Dynamic) | 연락처 개인의 활동이나 트리거를 기준으로 시작해요. |
| 반복(Recurring) | 설정한 카운트다운 일정에 따라 반복돼요. |

동적 타이머는 다음 API 트리거를 지원해요.
`sent` — 이메일 발송`opened` — 이메일 열람`whatsapp_sent` — WhatsApp 메시지 발송`whatsapp_opened` — WhatsApp 열람 트리거

자세한 내용은 [동적 카운트다운 타이머 가이드](../10-마케팅/카운트다운-타이머/guide-dynamic-countdown-timer.md)를 참고하세요.

## 사용할 수 있는 API 작업

V3 API는 카운트다운 타이머를 관리하고 공유 템플릿 목록에 접근하는 여섯 가지 작업을 제공해요.

| API 작업 | 기능 |
| --- | --- |
| List Countdown Timers (타이머 목록 조회) | 필터링과 페이지 나누기로 타이머를 조회해요. |
| Create Countdown Timer (타이머 만들기) | 고정, 동적, 반복 타이머를 만들어요. |
| Get Countdown Timer (타이머 단건 조회) | ID로 기존 타이머를 조회해요. |
| Update Countdown Timer (타이머 수정) | PATCH로 타이머 설정을 변경해요. |
| Delete Countdown Timer (타이머 삭제) | 기존 타이머를 소프트 삭제해요. |
| List Timer Templates (타이머 템플릿 목록 조회) | 사용할 수 있는 카운트다운 타이머 템플릿을 둘러봐요. |

{% hint style="info" %}
삭제는 소프트 삭제로 처리돼요. 이번 릴리스에서는 복원 기능이 정해져 있지 않아요.
{% endhint %}

각 API의 자세한 요청 형식이 필요하면 하이퍼클래스 고객지원에 문의하세요.

## 타이머 템플릿과 디자인 설정

V3 API로 공유 카운트다운 타이머 템플릿을 둘러보고, 타이머 모양을 코드로 설정할 수 있어요. 캠페인과 연동 전반에서 브랜드를 일관되게 유지하는 데 도움이 돼요.

`designMeta`로 다음과 같은 항목을 설정할 수 있어요.

- 글꼴과 텍스트 스타일
- 색상과 레이블
- 카운트다운 단위 표시 여부
- 테두리와 여백
- 그 밖의 타이머 디자인 속성

사용할 수 있는 템플릿을 조회한 뒤, 타이머를 만들거나 수정할 때 알맞은 설정 옵션을 적용하세요.

## 필터링, 페이지 나누기, API 응답

List Countdown Timers API는 필터링과 페이지 나누기를 지원해서, 타이머가 많아도 쉽게 찾고 관리할 수 있어요.

사용할 수 있는 필터는 다음과 같아요.

- 타이머 유형
- 타이머 상태
- 검색어
- 만료 여부
- 페이지 나누기

API 응답에는 디자인 메타데이터, 미리보기·트래킹 링크, 썸네일 같은 추가 정보도 들어 있어요.

## V3 카운트다운 타이머 API 사용 순서

인증된 연동으로 V3 API를 사용해 카운트다운 타이머를 관리할 수 있어요. 작업이 성공하려면 올바른 API 권한과 요청 파라미터가 필요해요.

1. API 접근 설정: 애플리케이션의 인증과 필요한 권한을 설정하세요.
2. 템플릿 둘러보기: List Timer Templates API로 사용할 수 있는 디자인을 살펴보세요.
3. 타이머 만들기: Create Countdown Timer API를 사용하고, 알맞은 타이머 유형을 선택하세요.
4. 타이머 사용자 지정: `designMeta`로 지원하는 스타일 속성을 설정하세요.
5. 타이머 조회: List 또는 Get API로 기존 타이머 정보를 확인하세요.
6. 타이머 수정: PATCH 엔드포인트로 지원하는 설정을 변경하세요.
7. 타이머 삭제: 타이머가 더 필요 없을 때 Delete API를 사용하세요.

API는 엔드포인트 URL에 `locationId`를 요구하지 않고, 인증된 토큰으로 해당 서브 계정을 확인해요.

인증 방법은 [개발자 마켓플레이스 시작하기](Developer-Resources/how-to-get-started-with-the-developer-s-marketplace.md)를 참고하세요.

## 자주 묻는 질문

### 어떤 카운트다운 타이머 유형을 지원하나요?
V3 API는 고정, 동적, 반복 카운트다운 타이머를 지원해요.

### 하이퍼클래스 화면을 쓰지 않고도 타이머를 관리할 수 있나요?
네. 카운트다운 타이머를 코드로 만들고, 조회하고, 수정하고, 삭제할 수 있어요.

### API URL에 locationId가 꼭 필요한가요?
아니요. 새 API는 인증 토큰으로 서브 계정 정보를 확인해요.

### API로 타이머 모양도 바꿀 수 있나요?
네. `designMeta`로 글꼴, 색상, 레이블, 단위 표시 여부, 테두리, 여백 같은 스타일 속성을 설정할 수 있어요.

### 사용할 수 있는 타이머 템플릿을 조회할 수 있나요?
네. List Timer Templates API로 공유 타이머 템플릿 목록에 접근할 수 있어요.

### 필터링과 페이지 나누기를 지원하나요?
네. List Countdown Timers API는 유형, 상태, 검색어, 만료 여부로 필터링할 수 있고 페이지 나누기도 지원해요.

### API로 타이머를 삭제하면 어떻게 되나요?
API가 소프트 삭제로 처리해요. 이번 릴리스에서는 삭제한 타이머를 복원할 수 있는지 정해져 있지 않아요.
