# 이메일 마케팅 V2 퍼블릭 API

이메일 V2 퍼블릭 API로 이메일 캠페인, 템플릿, 리포팅을 외부 시스템과 연동해 관리할 수 있어요. 이 문서에서는 V2 API의 기능과 장점, 사용 전에 알아 둘 점을 설명해요.

V2 API는 데이터 구조가 개선됐고 응답에 담기는 정보도 더 풍부해요. 일괄 예약 같은 기능도 추가됐어요. 확장성과 앞으로의 개선을 염두에 두고 만들어서, 개발자와 기업이 이메일 워크플로우를 더 효율적으로 자동화하고 최적화할 수 있어요.

## 이메일 V2 퍼블릭 API란?

이메일 V2 퍼블릭 API는 업그레이드된 엔드포인트 모음이에요. 개발자가 이메일 캠페인, 템플릿, 성과 데이터를 코드로 만들고, 관리하고, 분석할 수 있어요. 개선된 구조와 응답 형식 덕분에 기존 버전보다 유연하게 제어할 수 있어요.

V2 API를 쓰면 하이퍼클래스의 이메일 기능을 외부 시스템에 연동하고, 워크플로우를 자동화하고, 더 풍부한 캠페인 인사이트를 확인할 수 있어요.

## V2 퍼블릭 API의 주요 장점

이메일 V2 API는 기능과 개발 편의성을 모두 높여서, 확장 가능하고 효율적인 연동을 만들기 쉬워요.

- 향상된 캠페인 관리: 캠페인을 코드로 만들고, 업데이트하고, 삭제하고, 예약할 수 있어요. 제어 범위도 더 넓어졌어요.
- 일괄 예약: 여러 캠페인을 한 번에 예약해서 대량 이메일 발송 작업을 간소화할 수 있어요.
- 개선된 데이터 응답: 제목, 발송 세부 정보 같은 캠페인 데이터를 더 풍부하게 가져올 수 있어요.
- 더 깔끔한 API 구조: 엔드포인트 설계가 더 일관되고 체계적이에요.
- 상세한 리포팅 조회: 캠페인 통계를 자세히 가져와 분석하고 최적화할 수 있어요.
- 앞으로를 고려한 구조: 계속 개선될 API 위에 연동을 만들 수 있어요.

## 캠페인 관리 API (V2)

캠페인 관리 API로 이메일 캠페인의 전 과정을 제어할 수 있어요. 하이퍼클래스 화면에서 하는 작업을 넘어 자동화할 수 있고, 대량의 캠페인을 관리하거나 캠페인 워크플로우를 외부 도구·시스템과 연동할 수도 있어요.

- 캠페인을 코드로 만들기
- PATCH 요청으로 캠페인 세부 정보 업데이트하기
- 더 이상 필요 없는 캠페인 삭제하기
- 일괄 예약을 포함한 캠페인 예약하기

사용할 수 있는 엔드포인트는 다음과 같아요.
`Create Campaign V2`: 캠페인 만들기`Update Campaign V2`: 캠페인 업데이트`Delete Campaign V2`: 캠페인 삭제`Schedule Campaign V2`: 캠페인 예약`Campaigns V2 Overview`: 캠페인 V2 개요

{% hint style="info" %}
엔드포인트별 API 문서가 필요하면 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

## 템플릿 V2 API

템플릿 V2 API로 이메일 템플릿을 한곳에서 코드로 관리할 수 있어요. 캠페인과 계정 전반에 걸쳐 일관성을 유지하기 쉬워요. 템플릿을 동적으로 만들거나 업데이트해야 하는 에이전시나 시스템에 특히 유용해요.

- API로 이메일 템플릿 조회·관리하기
- 캠페인 전반에서 템플릿 사용 방식 표준화하기
- 템플릿 자동 업데이트 지원하기

사용할 수 있는 엔드포인트: `Templates V2`

## 통계 V2 API

통계 V2 API로 이메일 캠페인의 상세 성과 지표를 가져올 수 있어요. 맞춤 대시보드를 만들거나 외부 리포팅 도구에 분석 데이터를 연동할 수 있어요. 응답 데이터가 개선되어 캠페인 효과를 더 깊이 파악할 수 있어요.

- 캠페인 성과 데이터 조회하기
- 향상된 리포팅 필드 사용하기
- 서드파티 시스템에 분석 데이터 연동하기

사용할 수 있는 엔드포인트: `Statistics V2`

## 레거시 API와 V2 API 비교

레거시 API와 V2 API의 차이를 알아 두면 더 확장성 있고 오래 쓸 수 있는 기반 위에 연동을 만들 수 있어요. 기존 API도 계속 작동하지만, 앞으로의 개선은 V2 API에 집중돼요.

- 레거시 API는 중단 없이 계속 작동해요.
- 레거시 API에는 새 기능이나 개선이 추가되지 않아요.
- 앞으로의 모든 업데이트와 개선은 V2 API로 제공돼요.
- V2 API는 더 나은 구조와 데이터, 확장된 기능을 제공해요.

## 자주 묻는 질문

### 지금 바로 레거시 API에서 옮겨 가야 하나요?
아니요, 레거시 API는 계속 작동해요. 다만 새로 연동을 만들거나 앞으로의 확장성을 생각한다면 V2 API를 권장해요.

### 이메일 V2 API의 일괄 예약이란 무엇인가요?
API 호출 한 번으로 여러 이메일 캠페인을 한꺼번에 예약하는 기능이에요. 시간을 아끼고 작업 효율을 높일 수 있어요.

### V2 API를 써도 하이퍼클래스 화면에서 캠페인을 관리할 수 있나요?
네, 하이퍼클래스 화면은 그대로 모두 사용할 수 있어요. API는 캠페인을 코드로 관리하는 또 하나의 방법이에요.

### V2 API에서는 어떤 데이터를 추가로 받을 수 있나요?
제목, 발송 세부 정보, 개선된 캠페인 메타데이터처럼 더 풍부한 응답 데이터를 받을 수 있어요.

### 템플릿과 통계도 V2 API에서 쓸 수 있나요?
네, 템플릿과 캠페인 통계 모두 전용 V2 엔드포인트로 완전하게 지원돼요.

### 이메일 V2 API는 누가 쓰면 좋나요?
이메일 워크플로우를 자동화하거나 외부 시스템과 연동하려는 개발자, 에이전시, 기업에 가장 도움이 돼요.
