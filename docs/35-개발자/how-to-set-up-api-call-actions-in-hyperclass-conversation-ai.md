# 대화 AI에서 API 호출 작업 설정하기

API 호출 작업을 쓰면 대화 AI 에이전트가 고객과 대화하는 중에 외부 시스템의 실시간 정보를 가져올 수 있어요. 주문 관리 시스템, 재고 데이터베이스, 예약 플랫폼, 자체 개발한 애플리케이션을 연결하면 직접 조회하지 않아도 정확하고 맞춤화된 답변을 보낼 수 있어요.

## 대화 AI의 API 호출이란?

API 호출은 대화 AI 에이전트가 외부 HTTPS 엔드포인트로 요청을 보내고, 돌려받은 정보를 답변에 활용하는 기능이에요. 고객의 요청이 설정해 둔 트리거 조건에 맞으면 에이전트가 연결된 시스템에서 필요한 데이터를 가져와요. 예를 들어 고객이 알려 준 주문 번호를 조회해서 최신 주문 상태를 안내할 수 있어요.

## API 호출의 주요 장점

API 호출은 대화를 외부 비즈니스 시스템과 연결해서, 에이전트가 시의적절하고 정확한 정보를 전달하도록 도와줘요.

- 실시간 정보: 현재 주문 상태, 재고, 예약 내역 같은 비즈니스 데이터를 가져와요.
- 자동 조회: 대화 중에 정보를 자동으로 가져오므로 수작업이 줄어요.
- 동적 파라미터: 고객에게서 받은 정보로 API 요청 값을 채워요.
- 안전한 인증: 인증 정보를 쓰기 전용으로 보호해서 저장해요.
- 맞춤 응답: 에이전트가 사용할 API 결과와 전달 방식을 직접 정할 수 있어요.
- 테스트와 모니터링: 요청을 테스트하고, 대화와 대시보드 리포트에서 API 호출 내역을 확인해요.

## 트리거 조건

**트리거 조건**은 에이전트가 API 호출을 언제 실행할지 알려 주는 설명이에요. 조건을 분명하게 적어 두면 관련 있는 고객 요청에서만 작업이 실행돼요.

트리거 조건 예시:

"고객이 기존 주문에 대해 문의하면서 주문 번호를 알려 줄 때 이 작업을 사용하세요. 받은 주문 번호로 최신 주문 상태를 조회하세요."

작업을 언제 실행해야 하는지, 어떤 정보가 필요한지를 함께 적어 주면 결과가 더 좋아요.

## HTTP 요청 구성과 동적 변수

API 호출 작업에서는 HTTPS 엔드포인트, 헤더, 쿼리 파라미터, 요청 본문 템플릿을 설정할 수 있어요. `{{variable}}` 형태의 동적 변수 자리 표시자를 쓰면 에이전트가 대화에서 얻은 정보로 요청 값을 채워요.

요청 본문 예시:

```
{
  "order_id": "{{order_id}}",
  "email": "{{customer_email}}"
}
```

예를 들어 고객이 12345번 주문에 대해 물어보면, 에이전트가 이 값을 뽑아서 설정해 둔 `{{order_id}}` 파라미터에 넣어요. 파라미터는 연결하는 API의 요구 사항에 맞게 설정하세요.

## 인증과 인증 정보 보안

인증은 대화 AI와 외부 시스템 사이의 연결을 보호해요. API 호출 작업마다 인증 설정이 따로 저장되고, 비밀 값은 쓰기 전용이에요. 한 번 저장한 인증 비밀 값은 다시 볼 수 없어요. 적절한 권한만 가진 인증 정보를 사용하고, 프롬프트나 불필요한 응답 필드에는 민감한 정보를 넣지 마세요.

## 출력 필드와 작업 후 프롬프트

출력 필드는 API 응답 중에서 에이전트가 사용할 수 있는 부분을 정해요. 작업 후 프롬프트는 그 정보를 고객에게 어떻게 전달할지 안내해요. 예를 들어 주문 상태 API가 다음과 같은 응답을 돌려준다고 해 볼게요.

```
{
  "status": "Shipped",
  "estimated_delivery": "October 25, 2026"
}
```

필요한 출력 필드를 선택하고, 작업 후 프롬프트를 이렇게 설정할 수 있어요.

"돌려받은 상태와 도착 예정일로 친근하게 주문 상황을 안내하세요. 없는 정보를 지어내지 마세요."

응답 예시: "주문하신 상품이 발송되었어요! 도착 예정일은 10월 25일이에요."

## API 호출 테스트와 모니터링

에이전트가 실제 요청을 처리하기 전에 테스트하면, API 설정이 쓸 만한 정보를 돌려주는지 확인할 수 있어요. **Test**(테스트) 탭에서 요청을 실행하고 샘플 응답을 저장할 수 있어요. 저장한 샘플 응답은 에이전트의 프롬프트 컨텍스트에 포함되어, 에이전트가 예상 데이터 구조를 이해하는 데 도움이 돼요.

API 호출 작업의 타임아웃은 최대 **60초**까지 설정할 수 있어요. API 호출 내역은 다음 위치에서 확인해요.

- 대화의 **action pills**(작업 표시)
- **AI 응답 정보** 패널
- **AI 직원** 대시보드의 **API Calls**(API 호출) 카드

## 공개 API로 API 호출 작업 관리하기

대화 AI 퍼블릭 API를 쓰면 개발자가 API 호출 작업을 코드로 만들고 업데이트할 수 있어요. 팀이 자체 시스템에서 에이전트 설정을 관리할 때 유용해요.

- 만들기: 트리거 조건과 HTTP 구성을 포함해요.
- 업데이트: 바꿀 필드만 보내요.

더 자세한 내용은 [대화 AI 퍼블릭 API](../13-AI-Employee/Conversation-AI/conversation-ai-public-api.md)를 참고하세요.

## 대화 AI에서 API 호출 설정하기

설정을 제대로 해 두면 에이전트가 언제 외부 정보를 요청할지, 어떤 데이터를 보낼지, 응답을 어떻게 활용할지 알 수 있어요.

1. **AI 에이전트 > 대화 AI**로 이동한 뒤 에이전트를 열어 **Agent Builder**(에이전트 빌더)로 들어가세요.
2. **작업 > API 호출**로 이동하세요.

   ![작업 메뉴에서 API 호출 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083923192/original/7wgfEsl_YpIoCCyiSK-qBV2p6pHalKGDmQ.png?1792652333)
3. **트리거 조건**에 에이전트가 이 작업을 언제 실행해야 하는지 적으세요.
4. **요청 구성**에서 HTTPS 엔드포인트를 입력하고, 필요한 헤더, 쿼리 파라미터, **요청 본문** 템플릿을 설정하세요.

   ![HTTP 요청 구성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083923466/original/uFWtEHAs1ce4AxE-fK31gMztK35ua6BBKQ.png?1792652457)
5. 에이전트가 수집해야 할 정보를 파라미터로 추가하고, `{{variable}}` 자리 표시자로 참조하세요.
6. 외부 API에 필요한 인증 정보를 설정하세요. 저장한 비밀 값은 쓰기 전용이에요.

   ![인증 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083923538/original/63RmeMaDzpO9BVE6sww3ZmdAttUKJZN4pw.png?1792652507)
7. API 응답 중에서 에이전트에 필요한 정보를 출력 필드로 선택하세요.
8. 돌려받은 정보를 에이전트가 어떻게 전달해야 하는지 작업 후 프롬프트에 적으세요.
9. 타임아웃을 적절하게 설정하세요. 최대 60초까지 설정할 수 있어요.

   ![타임아웃 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083923674/original/dghlZ8tQjLXV1YvG0bcU0iOrYR8S4zHHGw.png?1792652580)
10. **Test**(테스트) 탭에서 요청을 확인하고, 샘플 응답을 검토해 저장한 다음 작업을 저장하세요. 고객에게 사용하기 전에 대화에서 에이전트를 먼저 테스트해 보세요.

    ![테스트 탭에서 요청 확인 후 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083923835/original/rYjvLms6nu5_PkiHrZ_T9gAUv73Tr0n2kQ.png?1792652641)

## 자주 묻는 질문

### 대화 AI를 우리 회사 백엔드에 연결할 수 있나요?
네, 가능해요. API 호출 작업은 호환되는 HTTPS 엔드포인트를 제공하는 자체 시스템에 연결할 수 있어요.

### API 요청에 고객 정보를 사용할 수 있나요?
네, 가능해요. 동적 변수를 쓰면 에이전트가 대화에서 얻은 정보로 요청 파라미터를 채워요.

### 인증 정보를 저장한 뒤에 다시 볼 수 있나요?
아니요. 인증 비밀 값은 쓰기 전용이라, 저장한 뒤에는 다시 볼 수 없어요.

### API 요청이 너무 오래 걸리면 어떻게 되나요?
API 호출 작업은 최대 60초까지 타임아웃을 설정할 수 있어요. 작업을 배포하기 전에 타임아웃이 걸렸을 때의 동작을 테스트해 보세요.

### 에이전트는 API 응답의 어떤 필드를 쓸지 어떻게 알죠?
출력 필드를 설정하고 작업 후 지침을 적어 두면, 돌려받은 정보를 어떻게 사용할지 에이전트가 알 수 있어요.

### API 호출 내역은 어디에서 확인하나요?
API 호출 실행 내역은 대화의 action pills, **AI 응답 정보**, **AI 직원** 대시보드의 **API Calls** 카드에서 볼 수 있어요.

### API 호출 작업을 코드로 관리할 수 있나요?
네, 가능해요. 대화 AI 퍼블릭 API로 API 호출 작업을 만들고 업데이트할 수 있어요.
