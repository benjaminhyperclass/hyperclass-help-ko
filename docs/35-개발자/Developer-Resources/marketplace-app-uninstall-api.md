# 마켓플레이스 앱 제거 API(App Uninstall API)

하이퍼클래스 마켓플레이스의 앱 제거 API를 쓰면 개발자가 사용하지 않는 계정에서 자기 앱을 코드로 제거할 수 있어요. 불필요한 웹훅 발생을 줄여 성능을 높이고 싶을 때 사용하세요. 이 문서에서는 설정 방법과 앞으로 추가될 웹훅 구독 관리 기능도 함께 안내해요.

## 앱 제거 API란?

앱 제거 API는 하이퍼클래스 마켓플레이스에서 앱 개발자에게 제공하는 기능이에요. 사용하지 않는(휴면) 계정에서 내 앱을 프로그램으로 제거할 수 있어요.

쓰지 않는 계정에서 앱을 제거하면 앱 관리가 간편해져요. 불필요한 웹훅 이벤트 처리도 줄어들어, 활성 사용자와의 상호작용에 리소스를 집중할 수 있어요.

## 앱 제거 API를 쓰면 좋은 점

이 기능은 앱 운영의 효율과 성능을 높이는 데 도움이 돼요.

- 운영 비용 절감: 휴면 계정에서 앱을 제거하면 불필요한 웹훅 발생이 줄고 처리 비용이 낮아져요.
- 지연 시간 개선: 불필요한 이벤트가 줄어들어 활성 사용자는 더 빠르고 부드럽게 앱을 쓸 수 있어요.
- 앱 관리 간소화: 비활성 계정 정리를 자동화해서 앱 배포 환경을 깔끔하게 관리할 수 있어요.
- 비용 효율: 처리 능력을 수익을 내는 활성 계정에 집중해서 리소스 사용량을 줄일 수 있어요.

## 웹훅 구독 관리

앱 제거 API는 휴면 계정에서 발생하는 불필요한 웹훅 이벤트를 줄이는 데 쓰여요. 앞으로는 계정별로 웹훅 구독을 관리하는 기능이 추가될 예정이에요. 이벤트 알림을 더 세밀하게 조절해 운영 상황에 맞게 성능을 개선할 수 있도록 만들어지고 있어요.

- 유연성 향상: 계정마다 웹훅 이벤트를 어떻게 구독할지 직접 정할 수 있어요.
- 맞춤 설정 개선: 이벤트 트리거를 조정해서 활성 계정과 비활성 계정의 활동을 더 잘 구분할 수 있어요.
- 리소스 관리 최적화: 웹훅 설정을 세밀하게 조정해서 처리 부하를 더 줄일 수 있어요.

## 앱 제거 API 설정하기

앱 제거 API는 기존 워크플로우에 쉽게 연결할 수 있어요. 바로 적용해서 불필요한 웹훅 트래픽을 줄여 보세요. 다음 단계를 따르세요.

1. 인증: 요청 권한을 얻을 수 있도록 하이퍼클래스에서 발급받은 유효한 API 자격 증명이 있는지 확인하세요.

2. 휴면 계정 찾기: 앱의 분석 자료나 데이터베이스를 활용해서 앱을 제거해야 할 비활성 사용자 계정을 찾으세요.

3. API 엔드포인트 호출: 공개 API 문서(Public API documentation)에 안내된 앱 제거 API 엔드포인트를 호출해서 제거를 시작하세요.

   ![앱 제거 API 호출 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055533358/original/YHVXP1etZ8BJdZMFB_6OxgDQR1xSstvPMg.png?1759933243)

4. 웹훅 활동 모니터링: 웹훅 로그를 확인해서 앱을 제거한 휴면 계정의 이벤트가 더 이상 발생하지 않는지 살펴보세요. 그러면 활성 계정이 더 효율적으로 동작하는지 확인할 수 있어요.

5. 프로세스 자동화: 정기 점검이나 모니터링 스크립트에 API 호출을 넣어 휴면 계정을 계속 자동으로 관리하세요.

이렇게 단계별로 진행하면 앱을 가볍고 빠르게 유지하면서, 리소스를 꼭 필요한 곳에 쓸 수 있어요.

## 자주 묻는 질문

### 앱 제거 API가 무엇인가요?
하이퍼클래스 마켓플레이스 기능이에요. 개발자가 휴면 사용자 계정에서 자기 앱을 코드로 제거할 수 있어요.

### 휴면 계정에서 앱을 제거하면 내 앱에 어떤 도움이 되나요?
불필요한 웹훅 이벤트가 줄어서 운영 비용이 낮아지고, 활성 계정의 지연 시간이 개선돼요.

### 앱 제거 API 문서는 어디에서 볼 수 있나요?
자세한 사용 방법과 엔드포인트 정보는 공개 API 문서(Public API documentation)의 "Uninstall an application" 항목에 있어요. 문서 위치를 찾기 어려우면 하이퍼클래스 고객지원에 문의하세요.

### 이 API를 자동화에 연결할 수 있나요?
네. API 호출을 자동화 스크립트에 넣어서 휴면 계정을 정기적으로 관리할 수 있어요.

### 앞으로 웹훅 이벤트와 관련된 기능이 더 추가되나요?
네. 4분기에 계정별 웹훅 구독을 관리할 수 있는 API가 추가될 예정이에요. 지금보다 더 유연하게 설정할 수 있게 돼요.

### 이 API를 쓰기 전에 무엇을 준비해야 하나요?
유효한 API 자격 증명이 있어야 해요. 그리고 앱의 분석 자료로 휴면 계정을 찾아낼 수 있는 믿을 만한 방법도 필요해요.
