# 하이퍼클래스 API 문서

하이퍼클래스 API로 CRM과 마켓플레이스에 연결되는 연동, 자동화, 맞춤 애플리케이션을 만들 수 있어요. 이 문서에서는 API 문서를 보는 방법, 요금제별 API 사용 범위, 호출 제한, 도움을 받을 수 있는 곳을 안내해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

하이퍼클래스 API에는 연락처, 메시지, 워크플로우, 캘린더, 결제, 웹훅 등을 다루는 REST 엔드포인트가 있어요.

{% hint style="warning" %}
V1 API는 2025년 12월 31일부로 지원이 종료되었어요.

- 전체 API 문서의 주소는 하이퍼클래스 고객지원에 문의하세요.
- 기존 연결과 연동은 계속 작동해요. 다만 V1 API에는 지원이나 업데이트가 제공되지 않아요.
- V1에서 V2로 옮기고 싶다면 **비공개 연동**을 확인해 보세요. V2에는 새로운 기능과 보안 기능이 많이 추가되었어요.
- 이전 버전의 API 문서도 참고용으로 볼 수 있어요. 기존 연동을 계속 운영하면서, 업그레이드할 준비가 되었을 때 새 버전을 살펴볼 수 있어요.
{% endhint %}

![V1 API 지원 종료 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071237828/original/agPxoZA9mVFfTooy5bnPNeeqwWHAGxwCPg.png?1778677506)

{% hint style="info" %}
앞으로 새 API 키를 만드는 기능은 에이전시 **설정**과 **서브 계정 설정**에서 사라져요. 아직 API 키를 만든 적이 없거나 현재 API 키를 쓰고 있지 않은 계정에 적용돼요.
{% endhint %}

## 하이퍼클래스 API 문서 위치

하이퍼클래스 API 문서는 새 주소로 옮겼어요. 문서 주소는 하이퍼클래스 고객지원에 문의하세요. 이전 Stoplight 문서를 쓰고 있었다면 북마크를 새 주소로 바꿔 주세요. Stoplight 문서는 앞으로 몇 달 안에 종료될 예정이에요.

API 문서에서는 이제 버전별 API 레퍼런스를 볼 수 있어요. 문서 안의 버전 전환기로 특정 API 버전의 엔드포인트, 스키마, 파라미터, 예시를 확인할 수 있어요. 덕분에 연동을 안정적으로 유지하고, 필요할 때 이전 버전을 참고하고, 새 버전으로의 업그레이드도 더 자신 있게 계획할 수 있어요.

{% hint style="info" %}
지원되는 엔드포인트에는 API v3를 사용할 수 있어요. 하이퍼클래스는 기존 연동을 지원하기 위해 이전 API 버전 문서도 계속 관리해요. 지원되는 버전과 엔드포인트별 요구 사항은 공식 API 문서와 API 버전 관리 가이드(API Versioning guide)에서 확인하세요.
{% endhint %}

## 버전별 API 문서 보기

버전별 API 문서를 쓰면 특정 API 버전에 맞춰 연동을 만들고 유지할 수 있어요. 운영 중인 시스템을 관리하거나 마이그레이션을 계획할 때 엔드포인트 구조, 요청 스키마, 응답 형식을 잘못 참고할 위험이 줄어요.

1. 하이퍼클래스 공식 API 문서를 열어요.
2. 문서의 **version switcher**(버전 전환기)에서 참고할 API 버전을 선택해요.

   ![API 문서의 버전 전환기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083329157/original/mznbmeAejFQKt4JPRUoZ-aCQjPCmZ0mKWQ.png?1791989654)
3. 선택한 버전의 엔드포인트, 요청 파라미터, 스키마, 응답 상세 내용을 확인해요.
4. 기존 연동을 유지할 때는 이전 API 버전을 참고해요.
5. 업그레이드를 계획하거나 새 연동을 만들 때는 새 버전을 확인해요.

버전별 문서는 기존 연동에 영향을 주지 않아요. 개발자가 API 레퍼런스를 더 명확하고 안정적으로 볼 수 있도록 만든 기능이에요.

## 에이전시 서브 계정

에이전시 서브 계정을 지원하면, 조건을 갖춘 에이전시가 온보딩과 설정에 쓰는 대표 서브 계정을 확인하고 관리할 수 있어요.

문서화할 내용:

- 사용 조건 또는 요금제 범위
- 조회/업데이트 엔드포인트의 동작
- API 응답에 포함될 때의 감사(audit) 관련 사항
- 에이전시당 에이전시 서브 계정을 하나만 만들 수 있는지 등의 고유성 규칙

## 하이퍼클래스 API 관련 도움 받기

{% hint style="warning" %}
현재 하이퍼클래스 고객지원은 설정 코드 점검이나 API 관련 개발 컨설팅을 제공하지 않아요. 다만 설정을 올바르게 마쳤는데도 오류가 계속된다면 하이퍼클래스가 고쳐야 할 API 버그일 수 있어요. 개발자 지원 양식으로 버그를 신고할 수 있어요. 양식 주소는 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

하이퍼클래스 API에 관한 질문은 개발자 Slack 그룹에 올려 보세요. 실력 있는 고객 커뮤니티에 물어볼 수 있어요. 참여 방법은 하이퍼클래스 고객지원에 문의하세요.

하이퍼클래스 개발팀은 매달 끝에서 두 번째 금요일에 개발자 협의회 콜(Developer Council Call)을 열어요. 일정은 이벤트 캘린더에서 볼 수 있어요.

개발자 랜딩 페이지에서는 개발자 마켓플레이스, 문서, Slack 채널 등을 한곳에서 볼 수 있어요.

**에이전트 스튜디오**에서도 에이전트를 프로그래밍 방식으로 관리하는 공개 API를 지원해요. 에이전트 스튜디오 전용 엔드포인트와 사용 안내는 별도의 에이전트 스튜디오 API 문서를 참고하세요.

## 요금제별 API 사용 범위

하이퍼클래스는 Starter, Unlimited, Agency Pro를 포함한 모든 요금제에서 API를 쓸 수 있어요.

OAuth 2.0과 비공개 연동 토큰(Private Integration Token, PIT)은 모든 요금제에서 사용할 수 있어요. Agency Pro를 구독하지 않아도 연동을 만들고 지원되는 API를 쓸 수 있어요.

API 사용 가능 여부

| API 기능 | Starter ($97) | Unlimited ($297) | Agency Pro ($497) |
| --- | --- | --- | --- |
| OAuth 2.0 인증 | 사용 가능 | 사용 가능 | 사용 가능 |
| 비공개 연동 토큰(PIT) | 사용 가능 | 사용 가능 | 사용 가능 |
| 표준 API 엔드포인트 | 사용 가능 | 사용 가능 | 사용 가능 |
| Agency Pro 전용 엔드포인트 | 사용 불가 | 사용 불가 | 사용 가능 |

### Agency Pro 전용 엔드포인트

표준 API는 모든 요금제에서 쓸 수 있지만, 일부 엔드포인트는 Agency Pro($497/월) 구독이 필요해요.

현재 Agency Pro가 필요하다고 문서에 나와 있는 엔드포인트는 다음과 같아요.

| 엔드포인트 | 용도 |
| --- | --- |
| 서브 계정 만들기(Create Sub-Account) | API로 새 서브 계정을 만들어요. |
| 서브 계정에 SaaS 켜기(Enable SaaS for Sub-Account) | 서브 계정에서 SaaS 기능을 켜요. |

{% hint style="info" %}
엔드포인트별로 다른 제한이 더 있을 수 있어요. 최신 요구 사항과 지원되는 API 버전은 공식 API 문서에서 확인하세요.
{% endhint %}

{% hint style="warning" %}
- OAuth 2.0과 PIT는 구독 등급에 따라 제한되지 않아요.
- 개별 엔드포인트를 쓸 수 있는지는 필요한 권한, 스코프, 해당 요금제 제한에 따라 달라져요.
- Agency Pro는 그 요금제 전용으로 명시된 엔드포인트나 기능에만 필요해요.
{% endhint %}

## API 1.0과 API 2.0의 호출 제한

하이퍼클래스는 OAuth를 쓰는 공개 V2 API에 호출 제한을 두어 성능과 안정성을 유지해요. 제한은 다음과 같이 조정되었어요.

- 순간 호출 제한(Burst limit): 마켓플레이스 앱(클라이언트)마다, 리소스(Location 또는 Company)마다 10초에 최대 100건의 API 요청
- 일일 제한(Daily limit): 마켓플레이스 앱(클라이언트)마다, 리소스(Location 또는 Company)마다 하루 200,000건의 API 요청

이 제한으로 시스템 전체의 성능과 안정성이 좋아져요.

사용량은 다음 API 응답 헤더로 확인할 수 있어요.
`X-RateLimit-Limit-Daily`: 일일 제한`X-RateLimit-Daily-Remaining`: 오늘 남은 요청 수`X-RateLimit-Interval-Milliseconds`: 순간 호출 제한이 적용되는 시간 간격`X-RateLimit-Max`: 해당 시간 간격 안에서 허용되는 최대 요청 수`X-RateLimit-Remaining`: 현재 시간 간격에서 남은 요청 수

## 자주 묻는 질문

### 하이퍼클래스 API는 어떤 용도로 쓰나요?

하이퍼클래스 API로 맞춤 연동을 만들고, 워크플로우를 자동화하고, 외부 애플리케이션을 하이퍼클래스 플랫폼과 연결할 수 있어요. 연락처, 대화, 캘린더, 워크플로우, 결제 등을 다루는 REST 엔드포인트를 제공해요.

### 하이퍼클래스는 아직 API V1을 지원하나요?

아니요. API V1은 지원이 종료되었어요. 기존 연동은 계속 작동할 수 있지만 업데이트나 기술 지원은 제공되지 않아요. 계속 지원을 받고 새 기능을 쓰려면 API V2로 옮기세요.

### 하이퍼클래스 API는 어떤 인증 방식을 지원하나요?

다음 두 가지를 지원해요.

- 비공개 연동 토큰: 내부용 연동이나 단일 Location 연동에 쓰는 방식
- OAuth 2.0: 공개 연동이나 사용자 승인이 필요한 마켓플레이스 앱에 쓰는 방식

### 비공개 연동 토큰 대신 OAuth 2.0은 언제 쓰나요?

다음 경우에는 OAuth 2.0을 쓰세요.

- 공개 앱이나 마켓플레이스 앱을 만들 때
- 여러 Location이나 계정에 접근할 때
- 사용자가 승인한 안전한 접근이 필요할 때

비공개 연동 토큰은 내부 도구나 단일 계정에서 쓸 때 가장 알맞아요.

### 하이퍼클래스 API의 호출 제한은 어떻게 되나요?

다음과 같이 제한해요.

- 리소스당 10초에 100건 요청
- 리소스당 하루 200,000건 요청

API 응답에 호출 제한 헤더가 포함되어 있어서 사용량을 확인할 수 있어요.

### 하이퍼클래스 고객지원에서 API 연동 개발이나 디버깅을 도와주나요?

아니요. 하이퍼클래스 고객지원은 API 개발이나 디버깅을 직접 도와주지 않아요. 도움이 필요하면 다음 방법을 이용하세요.

- 공식 API 문서 확인
- 하이퍼클래스 개발자 커뮤니티 참여
- 개발자 지원 포털로 버그 신고

### 공식 API 문서는 어디에서 볼 수 있나요?

공식 API 문서는 하이퍼클래스 개발자 마켓플레이스에서 볼 수 있어요. 주소는 하이퍼클래스 고객지원에 문의하세요.

### 모든 요금제에서 API를 쓸 수 있나요?

요금제에 따라 API 사용 범위가 달라요.

- Starter와 Unlimited: 기본 API 사용
- Founder 요금제: OAuth와 에이전시 수준 토큰을 포함한 고급 API 사용

일부 엔드포인트는 더 높은 요금제에서만 쓸 수 있어요.

### 새 API 기능이나 엔드포인트를 요청하려면 어떻게 하나요?

하이퍼클래스 API 문서의 공식 GitHub 저장소에 이슈를 등록해서 API 기능을 요청하거나 문서 문제를 알릴 수 있어요.

### 하이퍼클래스에서 SDK나 웹훅을 제공하나요?

네. 하이퍼클래스는 실시간 이벤트 업데이트용 웹훅을 제공하고, 일부 연동에는 SDK를 쓸 수 있거나 지원돼요. 지원하는 웹훅 이벤트와 SDK 상세 내용은 API 문서를 참고하세요.

### 다른 API 버전의 문서도 볼 수 있나요?

네. API 문서에서 이제 버전별 레퍼런스를 볼 수 있어요. **version switcher**에서 보고 싶은 API 버전을 선택하세요.

### API 문서 버전 관리가 기존 연동에 영향을 주나요?

아니요. 버전별 문서는 기존 연동에 영향을 주지 않아요. 알맞은 API 버전을 참고하고 연동을 안정적으로 유지하는 데 도움이 돼요.

### 문서에서 특정 API 버전을 선택해야 하는 이유가 뭔가요?

특정 API 버전을 선택하면 내 연동이 쓰는 버전의 엔드포인트, 스키마, 요청 파라미터, 응답 상세 내용을 정확하게 확인할 수 있어요.

### 이전 API 버전도 문서로 볼 수 있나요?

네. 이전 API 버전도 문서로 남아 있어서, 기존 연동을 유지하고 마이그레이션을 더 쉽게 계획할 수 있어요.

### API v3를 지금 쓸 수 있나요?

네. 코스를 포함해 지원되는 엔드포인트에서 API v3를 쓸 수 있어요. 지원되는 버전은 API 버전 관리 가이드(API Versioning guide)에서, 코스 관리 작업은 코스 API v3 문서에서 확인하세요.

## 도움말 및 지원

하이퍼클래스 고객지원은 API 코딩을 직접 도와주거나 설정을 점검해 주지 않아요. 문제가 생기면 다음 방법을 이용하세요.

1. API 버그: 개발자 지원 페이지에서 버그를 직접 신고하세요. 주소는 하이퍼클래스 고객지원에 문의하세요.
2. 개발자 커뮤니티: 하이퍼클래스 개발자 Slack에 참여해 다른 개발자와 함께 문제를 풀어 보세요. 참여 방법은 하이퍼클래스 고객지원에 문의하세요.
