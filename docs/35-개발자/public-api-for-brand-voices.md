# 브랜드 보이스 공개 API

브랜드 보이스 API를 쓰면 여러 서브 계정의 브랜드 보이스를 코드로 만들고, 관리하고, 수정할 수 있어요. 외부 시스템과 연동하거나, 온보딩 과정을 자동화하거나, 콘텐츠를 상황에 맞게 바꿔 쓰고 싶을 때 활용하세요. 만들기 방식이 여러 가지이고 생성·조회·수정·삭제를 모두 지원해서, 개발자와 에이전시가 브랜드 관리를 더 큰 규모로 처리할 수 있어요.

{% hint style="warning" %}
사용할 수 있는 전체 API 목록과 자세한 설명은 공식 API 문서의 Brand Voices 항목을 참고하세요.
{% endhint %}

## 브랜드 보이스 API란?

브랜드 보이스 API로 하이퍼클래스 안의 브랜드 보이스를 만들고, 조회하고, 수정하고, 삭제하고, 관리할 수 있어요. 외부 애플리케이션, 연동, 자동화 시스템이 브랜드 정체성을 정의하고 쓰는 방식을 제어할 수 있어요. 이 브랜드 정체성은 **콘텐츠 AI**(Content AI)와 **에이전트 스튜디오**(Agent Studio) 같은 AI 기능에서 쓰여요.

화면에서 브랜드 보이스를 하나씩 설정하는 대신 과정을 자동화할 수 있어요. 그러면 여러 계정, 고객사, 시스템에서 일관성을 유지할 수 있어요. 대규모 운영을 하는 에이전시, SaaS 플랫폼, 개발자에게 특히 유용해요.

## 브랜드 보이스 API의 장점

브랜드 보이스 API로 자동화와 확장이 쉬워져서, 모든 고객 응대와 AI가 만든 콘텐츠에서 브랜딩을 일관되게 유지하기 편해요.

- **대규모 자동화**: 직접 입력하지 않아도 여러 서브 계정의 브랜드 보이스를 자동으로 만들고 관리할 수 있어요.
- **다양한 만들기 방식**: 직접 입력, 웹사이트 URL, 설명 글 중 하나로 브랜드 보이스를 만들 수 있어요.
- **손쉬운 연동**: 하이퍼클래스를 외부 플랫폼, CRM, 온보딩 시스템과 연결할 수 있어요.
- **브랜드 중앙 관리**: 여러 도구에서 어조, 메시지, 타겟 고객 설정을 일관되게 유지할 수 있어요.
- **실시간 업데이트**: 비즈니스가 달라지면 브랜드 보이스를 바로 수정할 수 있어요.

## 브랜드 보이스 API 엔드포인트

사용할 수 있는 엔드포인트를 알아 두면 브랜드 보이스를 효율적으로 관리하고 워크플로우에 정확하게 연결할 수 있어요.
`GET /locations/:locationId/voices`
  - 브랜드 보이스 목록을 가져와요. 페이지 나누기, 검색, 필터(삭제된 항목 포함)를 지원해요.`GET /locations/:locationId/voices/:brandVoiceId`
  - 특정 브랜드 보이스의 전체 정보를 가져와요.`POST /locations/:locationId/voices`
  - 지원하는 만들기 방식 중 하나로 새 브랜드 보이스를 만들어요.`PATCH /locations/:locationId/voices/:brandVoiceId`
  - 기존 브랜드 보이스를 수정해요. 수정할 때는 모든 필드가 선택 사항이에요.`DELETE /locations/:locationId/voices/:brandVoiceId`
  - 브랜드 보이스를 삭제해요.`POST /locations/:locationId/voices/:brandVoiceId/default`
  - 해당 브랜드 보이스를 서브 계정의 기본값으로 설정해요.

## 브랜드 보이스 만들기 방식

가진 정보와 원하는 자동화 수준에 따라 브랜드 보이스를 만드는 방식을 고를 수 있어요.

- **직접 입력 방식**(`manual`)
  - 다음과 같은 브랜드 보이스 입력값을 직접 넣어요.
    - **Brand name**(브랜드 이름)
    - **어조**
    - **타겟 고객**
    - **고객 불편사항**
  - 세밀하게 제어하고 맞춤 설정할 때 알맞아요.
- **URL 방식**(`url`)
  - 웹사이트 URL을 넣어요.
  - 하이퍼클래스 AI가 사이트를 분석해서 브랜드 보이스 내용을 만들어요.
  - 기존 웹 채널이 있다면 빠르게 온보딩하기 좋아요.
- **설명 방식**(`description`)
  - 비즈니스를 설명하는 글을 넣어요.
  - AI가 설명을 바탕으로 브랜드 보이스 세부 내용을 만들어요.
  - 웹사이트가 없을 때 쓸모 있어요.

## 유효성 검사 규칙과 요구 사항

유효성 검사 규칙을 알아 두면 API 요청이 성공하고, 브랜드 보이스를 만들거나 수정할 때 생기는 흔한 오류를 막을 수 있어요.

- 직접 입력 방식으로 만들 때 필수인 필드`brandName``toneOfVoice``targetAudience``customerPainPoints`
- 만들 때 필수인 필드`type` (`manual`, `url`, `description` 중 하나여야 해요)
- 필드 제한`url` 또는 `description` 유형에는 직접 입력용 필드를 함께 보낼 수 없어요.`manual` 유형에는 URL 필드를 쓸 수 없어요.
  - AI가 만드는 방식에는 직접 입력용 답변 필드를 넣지 않아야 해요.
- 수정할 때의 동작
  - 수정할 때는 모든 필드가 선택 사항이에요.
  - 보낸 필드만 바뀌어요.

## 자주 묻는 질문

### 직접 입력 방식과 AI 생성 방식은 언제 쓰면 좋나요?
세밀하게 제어하고 싶다면 직접 입력 방식이 알맞아요. URL 방식과 설명 방식은 빠르고 자동화된 설정에 알맞아요.

### 브랜드 보이스에서 필드 하나만 수정할 수 있나요?
네, `PATCH` 요청은 일부만 수정할 수 있어요. 보낸 필드만 바뀌어요.

### 만들기 방식에 맞지 않는 필드를 보내면 어떻게 되나요?
선택한 유형과 맞지 않는 필드가 있으면 API가 유효성 검사 오류를 돌려줘요.

### 서브 계정 하나에 브랜드 보이스를 여러 개 둘 수 있나요?
네, 브랜드 보이스를 여러 개 만들어 관리하고 그중 하나를 기본값으로 설정할 수 있어요.

### 삭제한 브랜드 보이스를 복구할 수 있나요?
시스템 동작에 따라 삭제한 브랜드 보이스를 다시 가져올 수도 있어요. 그래도 삭제하기 전에 한 번 더 확인하세요.

### API로 만든 브랜드 보이스도 콘텐츠 AI와 에이전트 스튜디오에서 쓸 수 있나요?
네, API로 만든 브랜드 보이스는 모두 하이퍼클래스 AI 기능과 완전히 호환돼요.
