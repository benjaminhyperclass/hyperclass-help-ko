# 커뮤니티 게시글·댓글에서 코스 태그하기

게시글이나 댓글에 코스를 직접 태그하면 커뮤니티 대화에서 바로 다음 행동으로 이어갈 수 있어요. 멤버는 `#` 태그로 알맞은 코스를 빠르게 찾아 이동할 수 있고, 토론은 주제에서 벗어나지 않아요.

## 코스 태그란?

**커뮤니티**(Communities)에서 게시글이나 댓글을 쓸 때 `#`을 입력하면 검색할 수 있는 선택 목록이 열려요. 여기서 기존 코스를 골라 참조하는 기능이 코스 태그예요.

태그는 코스 아이콘이 붙은 클릭 가능한 라벨로 표시돼요. 읽는 사람이 태그를 클릭하면 코스 페이지로 이동해서, 코스 설정에 따라 자세한 내용을 보거나 수강 신청을 할 수 있어요.

## 코스 태그의 장점

코스 태그가 어떤 점에서 도움이 되는지 알아 두면 언제 쓰면 좋을지 판단하기 쉬워요.

- 대화 속에서 바로 발견: 대화가 이어지는 바로 그 자리에서 관련 코스를 보여 줄 수 있어요.
- 빠른 이동: 코스 태그를 클릭하면 멤버가 코스 페이지로 바로 이동해요.
- 깔끔한 게시글: 긴 URL 대신 짧고 읽기 쉬운 코스 태그를 쓸 수 있어요.
- 다음 단계 안내: 스레드를 벗어나지 않고 알맞은 강의나 프로그램을 추천할 수 있어요.
- 일관된 사용 방식: 채널과 이벤트에 쓰던 `#` 방식을 그대로 써요.

## 게시글과 댓글에서 코스 태그하는 방법

코스 태그는 게시글 편집기와 답글, 두 곳에서 추가할 수 있어요. 질문이 올라오거나 추천이 필요한 순간에 바로 학습자를 안내할 수 있어요.

### 방법 A — 게시글을 작성할 때

1. 서브 계정에서 **멤버십 > 커뮤니티**로 이동한 뒤, 원하는 그룹에 로그인하세요.

   ![커뮤니티 그룹 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056916805/original/A5Z6rNgUZOzAKDTjUy378l4cgXG1Yttk5w.png?1761573678)
2. **새 게시물**을 클릭하세요. 편집기에서 `#`을 입력하면 선택 목록이 열려요.

   ![편집기에서 # 입력 시 열리는 선택 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056917254/original/TWNb_G0_Fk-LVTXP1koBoBuvipGLjk2azQ.png?1761573949)
3. 코스를 검색하거나 스크롤해서 찾은 뒤 클릭하세요. 태그가 삽입되고 라벨 옆에 코스 아이콘이 표시돼요.
4. 게시글 내용을 마저 작성하고 **게시글**을 클릭하세요.

   ![코스 태그가 들어간 게시글 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056917300/original/Jqw0-UGf2hkhD9Tl0v_7e3MWTyH_NRSuXw.png?1761573982)

### 방법 B — 댓글을 작성할 때

1. 답글을 달 게시글을 열고 **답글**을 클릭하세요.
2. `#`을 입력해 선택 목록을 열고 코스를 선택하세요.
3. 메시지를 입력하고 **게시글**을 클릭하세요.

## 태그된 코스로 이동하기

코스 태그를 클릭하면 어떻게 되는지 알아 두면, 멤버에게 액세스 방법과 다음 단계를 미리 안내할 수 있어요.

- 태그된 코스를 클릭하면 해당 코스 페이지로 이동해요.
- 클릭한 뒤 보이는 화면은 코스 설정(예: 무료, 유료, 제한)에 따라 달라요.
- 액세스 권한이 있는 멤버는 코스 상세 정보나 커리큘럼을 볼 수 있어요. 권한이 없는 멤버에게는 코스 설정에 따라 액세스를 얻도록 안내가 나올 수 있어요.

## 자주 묻는 질문

### 코스는 누가 태그할 수 있나요?
그룹에서 게시글이나 댓글을 쓸 수 있는 멤버라면 누구나 코스 태그를 추가할 수 있어요. 태그를 클릭한 뒤 코스를 볼 수 있는지는 코스 설정에 따라 달라요.

### `#` 선택 목록에는 어떤 코스가 나오나요?
공개 범위와 액세스 설정에 따라 해당 멤버가 이용할 수 있는 코스가 나와요. 코스 이름이 명확하고 검색어가 잘 맞을수록 찾기 쉬워요.

### 게시글이나 댓글 하나에 코스를 여러 개 태그할 수 있나요?
네, 가능해요. 학습 경로를 안내하려면 필요한 만큼 코스 태그를 넣으세요.

### 태그된 코스에 액세스 권한이 없는 멤버는 어떻게 되나요?
설정해 둔 액세스 방식에 따라 안내를 받아요(예: 구매가 필요하거나 액세스를 요청해야 하는 경우). 실제 화면은 코스 설정에 따라 달라요.

### 모바일에서도 쓸 수 있나요?
커뮤니티 게시글·댓글 편집기가 `#` 선택 목록을 지원하는 환경이라면 어디서든 태그할 수 있어요.
