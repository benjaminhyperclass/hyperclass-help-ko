# 멤버십 댓글 관리하기

멤버십 강의에 달리는 댓글을 활성화하거나 숨기고, 잠그는 방법을 안내해요. 수강생이 쓴 댓글의 공개 범위를 바꾸거나, 댓글을 삭제하고 복원하는 방법도 함께 다뤄요.

코스 제작자와 강사는 자신의 코스가 수강생의 학습에 도움이 되는지 알고 싶어 해요. 피드백은 학습에서 중요한 부분이에요. 적절한 때에 효과적인 피드백을 주면 수강생의 성과가 좋아지고 더 나은 학습자로 성장할 수 있어요. 멤버십에 댓글을 추가하면 이런 피드백이 오갈 수 있는 환경을 만들 수 있어요.

## 멤버십 댓글을 활성화하고, 숨기고, 잠그기

### 카테고리 안의 모든 강의에 댓글 활성화하기

1. **상품** 탭을 엽니다.
2. 기존 **상품**을 선택하거나 새로 만듭니다.
3. **Comments**(댓글) 섹션을 클릭합니다.
4. 댓글을 **활성화됨**, **숨김**, **잠김**으로 설정할 카테고리를 선택합니다.

![카테고리 전체 강의의 댓글 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48247121266/original/KnFljltjZc4Bg8k1VoLxbxE3wuI7cNZv0A.gif?1661349365)

### 카테고리 안의 선택한 강의에만 댓글 활성화하기

1. **상품** 탭을 엽니다.
2. 기존 **상품**을 선택하거나 새로 만듭니다.
3. **Comments**(댓글) 섹션을 클릭합니다.
4. 카테고리 안에서 댓글을 **활성화됨**, **숨김**, **잠김**으로 설정할 강의를 선택합니다.

![선택한 강의의 댓글 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48247122489/original/jHinaoId928a-e1tDJQZUcG8sy_nlGvWXg.gif?1661349614)

상품별로 댓글을 필터링하는 모습은 아래 화면을 참고하세요.

## 댓글 상태별로 달라지는 점

### 활성화됨

**활성화됨** 상태에서는 페이지에 댓글 입력란이 보여요. 기존 댓글도 함께 표시되고, 수강생이 새 댓글을 쓸 수 있어요.

![댓글이 활성화됨 상태인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48247132423/original/bDRB-oOw7oJ6L3uAkaxw6d_UUcx0vW-CVQ.png?1661351622)

### 숨김

**숨김** 상태에서는 페이지에 댓글 입력란이 보이지 않아요. 기존 댓글도 표시되지 않아요.

### 잠김

**잠김** 상태에서는 수강생이 새 댓글을 쓸 수 없어요. 기존 댓글은 그대로 보여요.

![댓글이 잠김 상태인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48247131060/original/c_bpU9vdFLb7rAqOBUN5WzqZ0UxEenE17A.png?1661351345)

## 모든 상품의 댓글 관리하기

**상품** 탭 > **상품** > **댓글 관리**를 클릭하면 모든 상품의 댓글을 한곳에서 관리할 수 있어요.

![댓글 관리 화면으로 이동하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48247145417/original/_AAxNN_OFKH0skO296tse1R2LRT9mKy-ww.gif?1661354429)

### 댓글 공개 범위를 User Only에서 공개로 바꾸기

**댓글 관리** 화면에서 공개 범위를 바꿀 댓글의 드롭다운을 열고 **User Only**(사용자 전용) 또는 **공개**를 선택하세요.

- **User Only**: 코스 제작자와 댓글을 쓴 수강생에게만 보여요.
- **공개**: 모든 수강생과 코스 제작자에게만 보여요.

### 댓글 삭제하고 복원하기

#### 댓글 삭제하기

1. **상품** > **댓글 관리**를 클릭합니다.
2. 삭제할 댓글을 찾아 선택합니다.
3. **삭제**를 클릭합니다.

![댓글을 삭제하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48247156145/original/mFzDPtiK27ieMR3ImxGO51TTEasvJmjh6w.gif?1661357097)

#### 삭제한 댓글 복원하기

1. **상품** > **댓글 관리**를 클릭합니다.
2. **삭제됨** 탭을 클릭합니다.
3. 복원할 댓글을 찾아 선택합니다.
4. **복원**을 클릭합니다.

![삭제한 댓글을 복원하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48247157253/original/f-GkDVNdfc_gqTbe6GybY4VNUke_3dGyZg.gif?1661357314)
