# 커뮤니티 게시글 작성 넛지

코스나 이벤트를 만들거나 코스를 수료한 직후에 게시글 공유를 안내해 주는 기능이에요. 미리 채워진 게시글과 자동 멘션 덕분에 소식을 한 번에 공유할 수 있고, 커뮤니티 참여도 이어 가기 쉬워져요.

## 이 문서에서 알아볼 내용

게시글 작성 넛지(Post Creation Nudges)는 주요 작업을 마친 직후 중요한 소식을 바로 공유하도록 안내해요. 이 문서에서는 넛지가 어떻게 동작하는지, 어떤 작업에서 공유 안내가 나타나는지, 커뮤니티 참여를 높이려면 어떻게 활용하는지 설명해요.

## 게시글 작성 넛지란?

게시글 작성 넛지는 하이퍼클래스 커뮤니티(GoKollab)에서 코스 만들기, 이벤트 만들기, 코스 수료 같은 주요 작업 직후에 나타나는 안내예요. 관리자나 학습자가 직접 게시글을 올리는 것을 기억하길 기다리는 대신, 미리 채워진 메시지와 자동 멘션이 담긴 **Share as Post**(게시글로 공유) 안내가 나타나요. 그래서 중요한 소식을 한 번의 클릭으로 공유할 수 있어요.

이 넛지는 멤버들이 이미 서식 있는 게시글을 쓰고 채널을 고르던 기본 게시글 작성기를 그대로 사용해요. 그래서 익숙하고 관리하기도 쉬워요.

## 주요 장점

이 넛지가 왜 있는지 알면 참여 전략에 자연스럽게 녹여 쓰기 좋아요. 게시글 작성 넛지는 번거로움을 줄이고, 눈에 띄는 기회를 늘리고, 커뮤니티 안의 의미 있는 활동을 함께 축하하게 해 줘요.

- 새 콘텐츠가 바로 눈에 띄어요: 새 코스와 이벤트를 만든 직후 게시글로 공유할 수 있어서, 멤버들이 여러 탭과 메뉴를 뒤지지 않고도 찾을 수 있어요.
- 작업한 바로 그 순간에 안내해요: 관리자나 학습자가 무언가를 만들거나 마친 직후, 가장 몰입해 있을 때 넛지가 나타나요. 그만큼 공유할 가능성이 크게 높아져요.
- 미리 채워진 게시글에 멘션이 자동으로 들어가요: 코스와 이벤트 멘션이 자동으로 삽입돼서 멤버가 해당 콘텐츠로 바로 이동할 수 있어요. 이벤트 신청과 코스 시작을 늘리는 데 도움이 돼요.
- 커뮤니티 소통이 더 꾸준해져요: 새 학습 기회와 다가오는 이벤트 소식을 잊고 넘어갈 가능성이 줄어서, 커뮤니티가 커져도 참여가 꾸준히 이어져요.
- 학습자의 성과가 동기부여와 사회적 증거가 돼요: 코스 수료 넛지로 학습자가 성과를 공유하면, 다른 멤버도 등록하고 끝까지 수강하도록 자극받아요.
- 설정이 거의 필요 없고 별도 도구도 필요 없어요: 넛지는 GoKollab 커뮤니티 안에서 바로 동작하고, 이미 관리하고 있는 게시글 작성 흐름과 채널을 그대로 사용해요.

## 새 코스를 만들 때의 넛지

새 코스 넛지를 쓰면 처음부터 게시글을 쓰지 않아도 코스 출시를 눈에 띄는 공지로 바꿀 수 있어요. 코스를 그룹에 추가하는 즉시, 관리자가 해당 멤버들에게 몇 초 만에 공유할 수 있어요.

커뮤니티 안에서 새 코스를 추가하거나 코스를 그룹에 연결할 때(보통 커뮤니티의 **Learning**(학습) 영역이나 Kollab Studio를 통해) 코스 상세 정보, 가격, 접근 권한을 설정해요. 게시글 작성 넛지는 이 흐름에 이어서, 적절한 대상에게 코스를 알리도록 안내해요.

새 코스에서 넛지는 이렇게 동작해요.

- 그룹 관리자가 새 코스를 만들고 커뮤니티 그룹에 연결하면 **Share as Post** 안내가 나타나요.
- 게시글에는 코스 제목과 코스 멘션이 미리 채워져 있어서, 멤버가 공지를 쉽게 이해하고 바로 클릭해 들어갈 수 있어요.
- 관리자는 게시하기 전에 게시글 내용을 수정할 수 있어요. 대상 커뮤니티 그룹과 채널도 확인하거나 바꿀 수 있고, 공지, 일반 대화 등 기존 채널 구조를 그대로 써요. 준비가 되면 한 번의 클릭으로 바로 게시해요.

## 이벤트를 만들 때의 넛지

워크숍, Q&A, 라이브 룸 세션 같은 커뮤니티 이벤트를 만들 때 게시글로도 함께 공유하면, 멤버들이 이벤트를 보고 빠르게 신청할 수 있어요. 이벤트 넛지는 이를 도와줘요.

커뮤니티 이벤트에는 날짜, 시간, 설명, 무료 또는 유료 여부, 특정 그룹·코스·멤버십 등급에 대한 공개 범위 같은 이벤트 정보가 이미 한곳에 모여 있어요. 게시글 작성 넛지는 이벤트를 만든 직후를 바로 게시 기회로 이어 줘요.

이벤트에서 넛지는 이렇게 동작해요.

- 그룹 소유자나 관리자처럼 권한이 있는 사용자가 새 커뮤니티 이벤트를 만들고 저장하면 **Share as Post** 안내가 나타나요.
- 생성된 게시글에는 미리 채워진 이벤트 공지와, 이벤트로 연결되는 이벤트 멘션이 들어 있어요. 멤버가 상세 정보를 확인하고 신청하기 쉬워져요.
- 게시하기 전에 작성자가 게시글 문구를 분위기나 대상에 맞게 고칠 수 있어요. 가장 알맞은 그룹과 채널도 고를 수 있어요. 예를 들어 주요 이벤트는 공지 채널에, 소규모 모임은 해당 주제 채널에 올릴 수 있어요.

## 코스를 수료할 때의 넛지

코스 수료 넛지는 학습자 경험에 초점을 맞춰요. 수료할 때마다 인정과 격려의 순간을 만들어서, 다른 멤버도 계속 배우도록 자극해요.

학습자가 커뮤니티의 **Learning** 영역에서 코스를 마치면, 하이퍼클래스는 진행 상황을 추적하고 다음 단계나 관련 콘텐츠를 보여 줄 수 있어요. 게시글 작성 넛지는 여기에 축하 요소를 더해, 학습자가 이룬 성과를 공유하도록 안내해요.

코스 수료에서 넛지는 이렇게 동작해요.

- 학습자가 코스를 수료하면 **Share as Post**를 권하는 축하 안내가 나타나요.
- 미리 채워진 게시글에는 보통 짧은 축하 또는 소감 메시지와 수료한 코스 멘션이 들어 있어요. 다른 멤버가 코스를 쉽게 찾아 등록할 수 있어요.
- 학습자는 메시지를 자기 말로 바꿀 수 있어요. 예를 들어 배운 점을 적거나 강사에게 감사 인사를 전할 수 있어요. 성과를 올릴 그룹과 채널도 고를 수 있는데, 해당 커뮤니티에서 가진 게시 권한에 따라 달라져요.

## 게시글로 공유 안내 사용 흐름

**Share as Post** 안내는 다른 커뮤니티 게시글과 같은 기본 게시글 작성기를 써요. 그래서 관리자와 멤버가 새로운 화면을 따로 익힐 필요가 없어요. 직접 올린 게시글, 예약한 게시글, 넛지로 올린 게시글이 모두 같은 채널과 권한 모델을 거쳐요.

넛지가 나타났을 때는 이렇게 진행돼요.

1. 해당하는 작업을 해요.
   - 그룹에 새 코스를 추가하거나, 새 커뮤니티 이벤트를 만들거나, 학습자로서 코스를 수료해요.
2. **Share as Post** 안내를 확인해요.
   - 미리 채워진 게시글이 담긴 모달 또는 패널이 나타나요. 게시글에 코스나 이벤트 멘션이 이미 들어 있어서 바로 공유할 수 있어요.
3. 게시글을 검토하고 다듬어요.
   - 제목이나 본문을 내 말투나 행동 유도 문구에 맞게 수정해요.
   - 다른 커뮤니티 게시글처럼 이모지, 첨부파일(이미지, 동영상, PDF, GIF), 임베드 미디어를 추가할 수도 있어요.
4. 그룹과 채널을 선택해요.
   - 게시글을 올릴 커뮤니티 그룹을 확인해요.
   - 커뮤니티에 이미 만들어 둔 채널 구조에서 알맞은 채널(예: 공지, 일반, 주제별 채널)을 골라요.
5. 게시글을 게시해요.
   - **Post**(게시)를 클릭하면 선택한 그룹과 채널에 바로 게시돼요. 멤버들은 커뮤니티 피드에서 다른 게시글, 이벤트, 콘텐츠와 함께 이 소식을 볼 수 있어요.

## 게시글 작성 넛지 설정하기

게시글 작성 넛지는 복잡한 설정이 필요하지 않아요. GoKollab(새 UI/베타) 커뮤니티 환경 안에서 자동으로 동작하도록 만들어졌어요. 다만 커뮤니티, 코스, 이벤트를 잘 갖춰 두면 넛지가 알맞은 곳에 나타나고 멤버에게 실제로 도움이 돼요.

다음 단계를 따르세요. 넛지를 효과적으로 쓸 준비가 돼요.

1. GoKollab(새 커뮤니티 UI)을 사용하고 있는지 확인해요.
   - Kollab Studio에 접속해요. Kollab Studio는 커뮤니티와 코스를 한곳에서 관리하는 크리에이터 허브예요.
   - 내 커뮤니티와 코스가 목록에 보이는지 확인해요. 아직 이전 커뮤니티 환경을 쓰고 있다면 하이퍼클래스 고객지원이나 하이퍼클래스 담당자에게 문의해서 GoKollab 사용 가능 여부를 확인하세요.

   ![Kollab Studio 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077900107/original/flRNpvBwpPrNCNlYbTYpbTSPtom7rPt67w.png?1786110612)

2. 커뮤니티와 그룹을 만들거나 확인해요.
   - **커뮤니티**에서 커뮤니티를 만들고(아직 없다면), 멤버 토론을 구성할 그룹과 채널을 설정해요. 예를 들어 공지, 일반, 주제별 룸이 있어요.
   - 해당 커뮤니티에서 코스와 이벤트를 만들 수 있도록 내가 소유자 또는 관리자인지 확인해요.
3. 커뮤니티에 코스를 추가해요.
   - 커뮤니티에 연결된 **Learning** 또는 **코스** 영역을 사용하거나, Kollab Studio를 통해 코스에 접근해요.
   - 새 코스를 만들거나, 기존 코스가 알맞은 그룹에 제대로 연결되어 있는지 확인해요.
   - 코스를 저장할 때 **Share as Post** 넛지가 나타나는지 확인하고, 안내에 따라 공지를 게시해요.

   ![코스 저장 후 게시글 공유 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077793898/original/hD7SZl_TCzm7AzoSrhY2lEzYb9_42etQfg.png?1786018227)

4. 커뮤니티 이벤트를 활성화하고 만들어요.
   - 커뮤니티 안에서 **이벤트** 또는 커뮤니티 이벤트 영역으로 이동해요.
   - 제목, 시간, 설명, 장소(라이브 룸, Zoom 또는 다른 링크), 대상에 맞는 공개 범위 설정을 입력해 이벤트를 만들어요.
   - 저장한 후 게시글 작성 넛지를 사용해, 이벤트 멘션이 자동으로 들어간 커뮤니티 게시글로 이벤트를 공유해요.

   ![이벤트 저장 후 게시글 공유 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077793756/original/zdbkdFY50BL0i5fh0LaEasNVyuzRVlYzHg.png?1786018159)

5. 코스 수료 시 학습자 경험을 테스트해요.
   - 커뮤니티 **Learning** 영역에서 테스트 멤버(또는 본인)를 코스 중 하나에 등록해요.
   - 코스를 끝까지 진행해 수료하면 코스 수료 넛지가 나타나요.
   - 미리 채워진 게시글을 다듬고, 원하는 커뮤니티 그룹과 채널을 선택해 축하 게시글을 올린 뒤 잘 보이는지 확인해요.

   ![코스 수료 넛지 테스트 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077794068/original/W4kbbbaiDWGeecBM2JAf8ld6uS3BoN1HFg.png?1786018305)

   ![코스 수료 넛지 테스트 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077794170/original/HdjLMMTArmlJ4Kvj4hVJDb3tLbRh65-cYw.png?1786018351)

6. 넛지를 참여 계획에 포함해요.
   - 새 코스 공지, 이벤트 홍보와 리마인더(설정해 둔 캘린더·이메일 리마인더와 함께), 코스 수료 축하 게시글을 각각 어느 채널에 올릴지 정해요.
   - 운영자와 강사에게 넛지가 나타나면 꾸준히 활용하도록 기대 사항을 알려요.

{% hint style="info" %}
팁: 학습자가 코스 수료 게시글에 소감, 사진, 감사 인사를 덧붙여 자기만의 글로 쓰도록 권해 보세요. 커뮤니티 문화가 만들어지고, 다른 멤버도 코스에 참여하도록 자극할 수 있어요.
{% endhint %}
