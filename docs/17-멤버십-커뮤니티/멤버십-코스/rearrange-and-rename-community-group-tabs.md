# 커뮤니티 탭 순서와 이름 바꾸기

커뮤니티 설정에서 탭 순서를 바꾸고, 탭 이름을 고치고, 쓰지 않는 탭을 끌 수 있어요. 커뮤니티 관리자와 소유자가 우리 커뮤니티의 운영 방식과 브랜드에 맞게 탭 구성을 바꾸고 싶을 때 이 문서를 참고하세요.

이 문서에서는 드래그 앤 드롭으로 탭 순서를 바꾸는 방법, 탭 이름을 원하는 문구로 바꾸는 방법, 쓰지 않는 탭을 끄는 방법을 알려 드려요. 단, **Discussion**(토론)과 **About**(소개) 탭은 필수 탭이라 끌 수 없어요.

## 탭 사용자 지정이란?

탭 사용자 지정은 관리자와 소유자가 멤버에게 보이는 커뮤니티 탐색 화면을 직접 꾸미는 기능이에요. 하이퍼클래스의 기본 탭 이름과 순서를 그대로 쓰지 않고, 다음과 같이 바꿀 수 있어요.

- 커뮤니티 운영 방식에 맞게 탭 순서를 바꿔요.
- 브랜드에 어울리는 말로 탭 이름을 바꿔요.
- 커뮤니티에서 쓰지 않는 탭을 꺼요.

모든 설정은 커뮤니티 설정 패널에 있고, 기존의 **Show/Hide Tabs**(탭 표시/숨기기) 설정 바로 옆에서 찾을 수 있어요. 바꾼 내용은 바로 저장되고 다음에 접속해도 유지돼요. 멤버는 커뮤니티에 들어올 때마다 바뀐 탭 구성을 보게 돼요.

## 이럴 때 좋아요

- 운영 방식에 맞게 배치할 수 있어요: **이벤트**나 **학습**처럼 중요한 탭을 앞쪽에 두면 멤버가 자주 쓰는 기능에 빨리 들어갈 수 있어요.
- 우리 말투로 이름을 붙일 수 있어요: 브랜드와 용어에 맞게 탭 이름을 바꿔 보세요. 예를 들어 **학습**을 "코스"로, **이벤트**를 "모임"으로 바꿀 수 있어요.
- 탐색 화면이 단순해져요: 쓰지 않는 탭을 꺼 두면 화면이 깔끔해지고, 멤버가 꼭 필요한 기능에 집중할 수 있어요.
- 바로 반영돼요: 바꾼 내용은 즉시 적용되고 다음 접속에도 유지돼요.

## 커뮤니티 탭 바꾸는 방법

아래 단계를 따라 탭 순서를 바꾸거나, 이름을 고치거나, 탭을 꺼 보세요. 바꾼 내용은 자동으로 저장되고 바로 적용돼요.

### 1단계. 커뮤니티 그룹 열기

하이퍼클래스에서 **멤버십 > 커뮤니티 > 그룹**으로 이동하세요. 바꾸려는 그룹을 찾아 들어가세요.

![커뮤니티 그룹 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077815613/original/zN_Zphh3sfATQ3SSg30skJOol5SGGZlZzA.png?1786028433)

### 2단계. 커뮤니티 설정 열기

**설정** 아이콘(톱니바퀴 모양)을 클릭해 커뮤니티 설정 패널을 여세요. 기존 **Show/Hide Tabs** 설정 옆에서 탭 사용자 지정 항목을 찾을 수 있어요.

![커뮤니티 설정 아이콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077815655/original/XKsU71Cp4K3P2epX3OC4wuLPNRP_13nPFQ.png?1786028468)

### 3단계. 탭 순서 바꾸기

탭 이름 옆의 드래그 핸들(점 6개 아이콘)을 클릭한 채로 누르고 있으세요. 탭을 원하는 위치까지 위나 아래로 끌어 옮기세요. 마우스 버튼을 놓으면 새 순서가 정해져요. 여기서 정한 순서가 멤버에게 보이는 커뮤니티 탐색 바의 탭 순서가 돼요.

![탭을 드래그해 순서를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077816307/original/uz-DZUbPCsLNAMXVRS6j8ImNTAdUeGuJdg.gif?1786028689)

### 4단계. 탭 이름 바꾸기

탭 기본 이름 옆의 텍스트 입력란을 클릭하세요. 기존 글자를 지우고 원하는 이름을 입력하세요. 직접 입력한 탭 이름은 번역되지 않아요. 입력한 그대로 저장되고, 멤버의 언어 설정과 관계없이 입력한 그대로 표시돼요.

![탭 이름을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077816510/original/s4m4foIRJNAqu1pm-KVYsjEreXh-MY6zAw.png?1786028788)

### 5단계. 쓰지 않는 탭 끄기

커뮤니티에서 쓰지 않는 탭은 탭 이름 옆의 토글 스위치를 클릭해 끄세요. 토글이 꺼짐 위치로 바뀌고, 그 탭은 모든 커뮤니티 멤버에게 보이지 않아요. **Discussion**과 **About** 탭은 필수 탭이라 끌 수 없어요. 이 두 탭에는 끄기 토글이 나타나지 않아요.

### 6단계. 바뀐 내용 확인하기

바꾼 내용은 자동으로 저장돼요. 잘 바뀌었는지 확인하려면 커뮤니티 페이지를 새로고침하거나 멤버 계정으로 로그인해 보세요. 정한 순서대로, 입력한 이름으로 탭이 나타나고 꺼 둔 탭은 보이지 않아요. 설정은 다음 접속에도 유지되기 때문에 멤버는 들어올 때마다 바뀐 구성을 보게 돼요.

{% hint style="info" %}
바꾼 내용은 바로 적용돼요. 탭 설정은 자동으로 저장되고 페이지를 다시 불러와도 유지돼요. 멤버는 로그아웃하거나 새로고침하지 않아도 바뀐 탭 구성을 바로 볼 수 있어요.
{% endhint %}

## 권한과 제한 사항

탭 사용자 지정은 관리자용 기능이라서 권한 조건과 몇 가지 제한이 있어요.

### 관리자와 소유자만 쓸 수 있어요

커뮤니티 관리자와 소유자만 탭 순서를 바꾸고, 이름을 고치고, 탭을 끌 수 있어요. 일반 멤버와 운영자(모더레이터)에게는 커뮤니티 설정에 탭 사용자 지정 항목이 보이지 않아요.

### 필수 탭은 끌 수 없어요

**Discussion**과 **About** 탭은 커뮤니티의 핵심 기능이라 끌 수 없어요. 이 두 탭에는 끄기 토글이 없어요. 대신 순서를 바꾸고 이름을 고치는 건 다른 탭처럼 할 수 있어요.

### 직접 입력한 탭 이름은 번역되지 않아요

직접 입력한 탭 이름은 입력한 그대로 저장되고 표시돼요. 하이퍼클래스는 직접 입력한 탭 이름을 번역하지 않아요. 입력한 문구는 멤버의 언어 설정과 관계없이 모두에게 똑같이 보여요. 여러 언어를 쓰는 멤버가 있다면 이 점을 감안해 탭 이름을 정하세요.

{% hint style="info" %}
여러 언어를 쓰는 멤버가 있는 커뮤니티라면, 탭 이름을 바꿀 때 누구나 알아볼 수 있는 용어나 아이콘을 쓰는 것을 고려해 보세요. 직접 입력한 탭 이름은 번역되지 않고 모든 멤버에게 똑같이 보여요.
{% endhint %}

## 자주 묻는 질문

### Discussion과 About 탭도 순서를 바꿀 수 있나요?

네, 할 수 있어요. **Discussion**과 **About** 탭은 끌 수 없지만, 다른 탭처럼 순서를 바꾸고 이름도 고칠 수 있어요. 드래그 핸들로 원하는 위치로 옮겨 보세요.

### 직접 입력한 탭 이름도 멤버의 언어에 맞게 번역되나요?

아니요. 직접 입력한 탭 이름은 입력한 그대로 저장되고 표시돼요. 하이퍼클래스는 직접 입력한 탭 이름을 번역하지 않기 때문에, 입력한 문구는 멤버의 언어 설정과 관계없이 모두에게 똑같이 보여요. 여러 언어를 쓰는 멤버가 있다면 누구나 알아볼 수 있는 용어로 이름을 바꾸는 것을 고려해 보세요.

### 멤버가 쓰고 있는 탭을 끄면 어떻게 되나요?

탭을 끄면 모든 멤버의 커뮤니티 탐색 바에서 그 탭이 바로 숨겨져요. 탭 안의 콘텐츠(예: 이벤트나 코스)는 삭제되지 않고, 탐색 메뉴로 들어갈 수 없게 될 뿐이에요. 나중에 탭을 다시 켜면 콘텐츠를 그대로 볼 수 있어요.

### 운영자(모더레이터)도 탭을 바꿀 수 있나요?

아니요. 커뮤니티 관리자와 소유자만 탭 순서를 바꾸고, 이름을 고치고, 탭을 끌 수 있어요. 운영자와 일반 멤버에게는 커뮤니티 설정에 탭 사용자 지정 항목이 보이지 않아요.

### 탭 설정은 자동으로 저장되나요?

네, 바꾸는 즉시 자동으로 저장돼요. 저장 버튼은 따로 없어요. 바꾼 내용은 바로 적용되고 다음에 접속해도 유지되기 때문에, 멤버는 들어올 때마다 바뀐 탭 구성을 보게 돼요.

### 탭을 기본 이름과 순서로 되돌릴 수 있나요?

지금은 자동으로 되돌리는 버튼이 없어요. 기본 상태로 돌리려면 탭 이름을 하나씩 원래 이름(**Discussion**, **학습**, **이벤트**, **Leaderboard**, **Members**, **About**)으로 직접 바꾸고, 원래 순서대로 다시 끌어 놓으세요.

### 페이지를 새로고침하면 탭 설정이 사라지나요?

아니요. 탭 설정은 페이지를 다시 불러오거나 다시 접속해도 유지돼요. 순서를 바꾸거나, 이름을 고치거나, 탭을 끄면 직접 다시 바꾸기 전까지 그대로 저장돼요. 이름과 순서를 바꾼 탭이 새로고침 후에도 잘 유지되는지는 통합 테스트와 엔드 투 엔드 테스트로도 확인했어요.

### 어떤 탭이 꺼져 있는지 어떻게 알 수 있나요?

커뮤니티 설정 패널에서 꺼진 탭은 토글 스위치가 꺼짐 위치로 표시돼요. 멤버에게는 꺼진 탭이 커뮤니티 탐색 바에 보이지 않아요. 탭을 다시 켜려면 토글 스위치를 켜짐 위치로 돌리세요.
