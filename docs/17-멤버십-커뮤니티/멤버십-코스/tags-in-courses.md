# 코스 태그로 코스 분류하고 찾기

코스 태그는 코스를 분류하고, 수강생이 라이브러리에서 필요한 코스를 빨리 찾도록 돕는 기능이에요. 만드는 사람이 코스 **설정**에서 **언어**, **난이도**, **주제** 값을 고르면, 수강생은 그 값으로 **All Courses**(전체 코스)와 **My Courses**(내 코스)의 코스를 필터링할 수 있어요. 커스텀 필드를 만들거나 직접 정렬하지 않아도 카탈로그처럼 정돈된 화면을 만들 수 있어요.

## 코스 태그란?

코스 태그는 코스의 언어, 난이도, 주제를 나타내는 미리 정해진 레이블이에요. 수강생은 코스를 열기 전에 내용을 가늠할 수 있고, 코스가 많아도 훑어보기 쉬워요.

코스에는 다음 태그 유형을 지정할 수 있어요.

- **언어**: 코스에서 사용하는 언어예요.
- **난이도**: 코스가 대상으로 하는 실력이나 경험 수준이에요.
- **주제**: 코스의 주된 주제로 코스를 분류해요.

코스를 저장하면 선택한 태그가 수강생 라이브러리의 코스 카드에 표시돼요. 수강생은 이에 맞는 필터로 **All Courses**와 **My Courses**에 보이는 코스를 좁힐 수도 있어요.

코스 태그는 코스를 분류하고 찾기 쉽게 하려는 기능이에요. 코스 만들기, 편집, 오퍼, 접근 권한은 각각 **멤버십**의 해당 기능에서 관리해요. 코스는 **멤버십 > 코스 > 상품**에서 해당 코스를 선택해 만들고 관리할 수 있어요.

## 코스 태그를 쓰면 좋은 점

모든 코스에 같은 형식의 정보를 붙이면 코스 라이브러리를 정리하고 둘러보기가 쉬워져요.

- 코스를 더 빨리 찾아요: 수강생이 언어, 난이도, 주제로 라이브러리를 좁힐 수 있어요.
- 기대하는 내용이 분명해져요: 코스 카드만 봐도 코스를 열기 전에 내용을 파악할 수 있어요.
- 분류가 일관돼요: 미리 정해진 값을 쓰기 때문에 전체 코스에 표준화된 레이블이 붙어요.
- 코스 관리가 간단해져요: 커스텀 필드를 만들거나 콘텐츠를 직접 정렬하지 않고도 코스를 정리할 수 있어요.
- 수강생 경험이 좋아져요: 필터 덕분에 카탈로그처럼 깔끔하게 둘러볼 수 있어요.
- 여러 라이브러리 화면에서 쓸 수 있어요: **All Courses**와 **My Courses** 모두에서 코스 필터를 쓸 수 있어요.

## 코스 태그 유형

태그 유형마다 학습 경험의 다른 부분을 알려 줘요. 값을 정확히 고르면 수강생이 자신의 언어, 경험 수준, 관심사에 맞는 코스인지 판단하기 쉬워요.

### 언어

**언어** 태그는 코스가 어떤 언어로 진행되는지 알려 줘요. 수강생은 이 값으로 편하게 이해할 수 있는 코스를 찾을 수 있어요.

### 난이도

**난이도** 태그는 코스에 필요한 실력이나 지식 수준을 알려 줘요. 수강생이 자신의 경험에 맞는 콘텐츠를 고르는 데 도움이 돼요.

### 주제

**주제** 태그는 코스의 주된 주제 영역을 알려 줘요. 수강생은 **주제** 필터로 관심사나 목표와 관련된 콘텐츠만 모아 볼 수 있어요.

{% hint style="info" %}
코스 태그는 일관된 레이블을 위해 미리 정해진 값을 써요. 이 값을 사용자 지정할 수 있는지, 태그 유형마다 값을 둘 이상 선택할 수 있는지는 아직 확인되지 않았어요.
{% endhint %}

## 수강생 라이브러리에 태그가 표시되는 방식

코스 카드에 태그가 표시되면 수강생은 코스를 하나씩 열지 않아도 필요한 정보를 볼 수 있어요. 라이브러리 필터를 쓰면 선택한 조건에 맞는 코스만 남길 수 있어요.

태그를 지정하고 코스를 저장하면 다음과 같이 보여요.

- 선택한 **언어**, **난이도**, **주제** 값이 코스 카드에 표시돼요.
- 수강생이 **언어**, **난이도**, **주제**로 라이브러리를 필터링할 수 있어요.
- 필터는 **All Courses**와 **My Courses**에서 쓸 수 있어요.
- 수강생은 **모든 필터 지우기**를 선택해 적용한 필터를 모두 해제할 수 있어요.

멤버십 코스는 고객이 **클라이언트 포탈**에서 이용할 수 있는 콘텐츠 중 하나예요.

{% hint style="info" %}
화면 캡처에 나온 Radiant Life 코스의 태그 값은 캡처마다 달라요. 각 캡처는 서로 다른 설정 예시예요.
{% endhint %}

## 코스 태그 설정하기

태그를 정확하게 지정하면 수강생이 코스를 이해하고 찾기 쉬워져요. 코스의 **설정** 페이지에서 태그를 지정한 뒤 코스를 저장하면, 선택한 값이 수강생 라이브러리에 표시돼요.

1. 왼쪽 메뉴에서 **멤버십**으로 이동하세요.
2. **코스**를 선택한 다음 **상품**을 여세요.
3. 분류하려는 코스를 여세요.
4. 코스 메뉴에서 **설정**을 선택하세요.
5. **코스 태그** 영역까지 스크롤하세요.
6. **언어** 드롭다운에서 값을 선택하세요.
7. **난이도** 드롭다운에서 값을 선택하세요.
8. **주제** 드롭다운에서 값을 선택하세요.
9. 선택한 값이 코스를 정확히 설명하는지 확인하세요.
10. **저장**을 클릭하세요.

![코스 설정의 코스 태그 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076929437/original/dI-jOIJua8V9VrpgGpFfx1hymjB-b0GRWg.png?1785155694)

저장한 태그는 수강생 라이브러리에 반영돼요. 코스 카드에 표시되고 필터로도 쓸 수 있어요.

## 수강생이 코스 필터링하기

수강생은 필터로 원하는 언어, 현재 경험 수준, 관심 주제에 맞는 콘텐츠만 볼 수 있어요. 라이브러리에 코스가 많을 때 특히 편리해요.

코스 라이브러리를 필터링하려면 다음과 같이 하세요.

1. **클라이언트 포탈**에서 코스 라이브러리를 여세요.
2. **All Courses** 또는 **My Courses**를 선택하세요.
3. 사용할 수 있는 필터 중 하나를 선택하세요.
   - **언어**
   - **난이도**
   - **주제**
4. 적용할 값을 고르세요.
5. 필터링된 결과에 표시된 코스를 확인하세요.
6. 필터를 해제하고 전체 라이브러리로 돌아가려면 **모든 필터 지우기**를 선택하세요.

![코스 라이브러리에서 언어, 난이도, 주제 필터를 쓰는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076929291/original/Pg22AAbCd-fuKyHKmyazZ5NIzGjgZA6i3Q.png?1785155644)

이 필터는 **All Courses**와 **My Courses** 모두에서 작동해요. 수강생이 페이지를 나간 뒤에도 필터 선택이 유지되는지는 아직 확인되지 않았어요.

## 자주 묻는 질문

### 코스 태그는 커뮤니티 게시글에서 코스에 태그를 거는 것과 같은 기능인가요?

아니요. 코스 태그는 코스를 **언어**, **난이도**, **주제**로 분류해서 코스 라이브러리에 표시하고 필터링하는 기능이에요. 커뮤니티 게시글이나 댓글에서 코스를 언급하는 기능은 별개예요.

### 코스 태그가 코스 오퍼나 접근 설정을 대신하나요?

아니요. 코스 태그는 코스를 정리하고 설명하는 데 쓰여요. 코스 접근 권한은 오퍼, 워크플로우 등 다른 방법으로 부여할 수 있어요.

### 수강생은 코스 태그를 어디에서 볼 수 있나요?

수강생 라이브러리의 코스 카드에 선택한 태그가 표시돼요.

### 새 필터는 어느 라이브러리 화면에서 쓸 수 있나요?

수강생은 **All Courses**와 **My Courses** 모두에서 코스를 필터링할 수 있어요.

### 태그 값을 직접 입력할 수 있나요?

코스 태그는 일관된 레이블을 위해 미리 정해진 값을 써요. 이 값을 수정하거나 추가할 수 있는지는 아직 확인되지 않았어요.

### 한 코스에 언어, 난이도, 주제를 여러 개 지정할 수 있나요?

태그 유형마다 값을 여러 개 선택할 수 있는지는 아직 확인되지 않았어요.

### 태그가 없는 코스는 어떻게 표시되나요?

수강생이 필터를 적용했을 때 태그가 없는 코스가 어떻게 표시되는지는 아직 확인되지 않았어요. 새 필터 옵션으로 코스를 분류하려면 각 코스에 태그를 추가하세요.

### 코스 태그가 수강 등록이나 권한에 영향을 주나요?

코스 태그는 분류와 탐색을 위한 도구예요. 수강 등록과 접근 권한은 별도의 코스 접근 권한 기능에서 관리해요.

### 커뮤니티의 **Learning**(학습) 탭에서도 코스 태그를 쓸 수 있나요?

**All Courses**와 **My Courses** 라이브러리 화면에서 쓸 수 있다는 점은 확인됐어요. 커뮤니티의 **Learning** 탭에서 지원하는지는 아직 확인되지 않았어요.

### 태그를 바꾸면 수강생에게 자동으로 반영되나요?

저장한 태그는 수강생 라이브러리에 동기화돼요. 반영까지 걸리는 시간은 따로 안내된 바가 없어요.
