# 코스의 새 테마 — 네오 클래식 테마

코스에 새로 추가된 **네오 클래식 테마**를 소개하고, 기존 코스에 적용하는 방법을 안내해요. 코스를 만들거나 꾸밀 때 참고하세요.

## 네오 클래식 테마란?

**네오 클래식 테마**는 익숙한 클래식 분위기에 깔끔하고 현대적인 화면을 더한 코스 테마예요.

- 탐색이 쉬워졌어요. 길게 스크롤하지 않아도 강의 사이를 편하게 오갈 수 있어요. 퀴즈를 보고 싶으면 한 번만 클릭하면 되고, 모듈을 다시 보고 싶을 때도 간단하게 이동할 수 있어요.
- 색상은 화사하면서도 단정해요. 선명한 포인트 색상과 깔끔한 색 구성이 어우러져서 클릭하고 사용하는 과정이 자연스럽고 보기 좋아요.
- 사용 경험이 더 생생해졌어요. 애니메이션과 피드백이 개선되어 화면을 쓸 때 반응이 더 살아 있는 느낌이 들어요.
- 로딩이 빨라졌어요. 백엔드를 최적화하고 코드를 정리해서 모든 페이지가 이전보다 빠르게 열려요. 기다리는 시간이 줄어드니 수강생이 학습에 끊김 없이 집중할 수 있어요.

> 네오 클래식 테마는 단순한 테마를 넘어, 코스가 돋보이고 수강생이 계속 몰입하도록 돕는 경험을 목표로 해요. 시간이 지나도 변하지 않는 우아함도 담았어요.

{% hint style="info" %}
새로 만드는 코스는 **네오 클래식 테마**가 기본 테마로 적용돼요.
{% endhint %}

## 개선 사항과 수정 사항

- 퀴즈 해설: 퀴즈 답안에 해설을 추가해 두면 이제 화면에 표시돼요. 수강생이 틀린 문제에서 배우고 다음 시도에 더 잘 풀 수 있어요.
- 단일 선택과 복수 선택 구분: **단일 선택** 문제와 복수 선택(MCQ) 문제 옆에 태그가 눈에 띄게 표시돼요. 수강생이 문제 유형을 바로 알 수 있어요.
- 코스 진행률 표시줄: 코스 화면에서 **코스 진행 상황** 진행률 표시줄을 볼 수 있어요. 어디까지 학습했고 얼마나 남았는지 한눈에 알 수 있어요.
- 잠금·드립 강의 표시: 잠겨 있거나 드립으로 공개되는 카테고리와 강의가 더 뚜렷하게 구분돼요. 수강생이 잠금을 풀어야 하는지, 공개를 기다려야 하는지 쉽게 알 수 있어요.
- 시작 페이지 개선: 퀴즈나 과제를 시작할 때 보이는 시작 페이지를 다듬어서 더 부드럽게 시작할 수 있어요.
- 퀴즈·과제 상태 페이지 개선: 결과가 **In Review**(검토 중), **Pass**(통과), **실패**로 분명하게 표시돼요. 강사 메모도 같은 화면에서 확인할 수 있어요.
- 퀴즈 전체 검토: 퀴즈를 마치면 수강생이 푼 문제, 정답, 총점을 볼 수 있어요.
- 문제 간 이동: 퀴즈 문제 사이를 더 쉽고 빠르게 오갈 수 있어요.
- 다운로드 제어: 파일 다운로드를 중지할 수 있고 다운로드 진행 상황도 볼 수 있어요.
- 이미지 미리보기: 이미지를 확대하지 않아도 미리보기로 편하게 볼 수 있어요.
- 로딩 표시 변경: 기존 로딩 스피너 대신 셔머 효과를 사용해서 로딩 화면이 더 깔끔해졌어요.
- 코드 최적화: 알고리즘을 다듬고 코드를 정리해서 전반적인 성능과 안정성이 좋아졌어요. 화면 반응이 더 매끄러워요.

## 관리자 미리보기에서 잠긴 강의와 잠금 해제된 강의 보기

**네오 클래식 테마**의 미리보기 모드에서 관리자가 강의 접근 상태를 더 유연하게 확인할 수 있어요.

- 미리보기 모드에서 잠긴 강의 화면과 잠금 해제된 강의 화면을 번갈아 볼 수 있어요.
- 수강생이 보는 제한된 화면과 전체 강의 화면을 둘 다 쉽게 확인할 수 있어요.
- 미리보기 모드의 이동 방식이 더 일관되어 업데이트된 화면이 올바르게 표시돼요.

관리자는 수강생에게 변경 사항을 게시하기 전에 코스 접근 방식을 더 정확하게 점검할 수 있어요.

## 네오 클래식 테마 적용하기

이미 만든 코스도 코스 개요에서 **네오 클래식 테마**로 바꿀 수 있어요.

1. 코스 상품을 열고 **Course Outline**(코스 개요)에서 **Customize**(사용자 지정)를 선택하세요.
2. **템플릿 둘러보기**를 클릭하세요.
3. **네오 클래식 테마**를 선택하세요.
