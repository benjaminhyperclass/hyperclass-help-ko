# 상품을 만들어 멤버십 오퍼에 연결하기

멤버십 코스로 판매할 상품을 만들고, 게시된 멤버십 오퍼에 연결하는 전체 과정을 안내해요. 상품 설정, 가격 입력, 오퍼 연결 방법을 알 수 있어요. 구매자가 상품을 구매하면 연결된 코스에 자동으로 접근 권한이 생기고, 구매 후에 따로 설정할 것은 없어요.

## 코스 오퍼란?

코스 오퍼는 멤버십 코스를 하나 이상 묶어 정해진 가격에 판매하는 방식이에요. 고객이 이 오퍼에 연결된 상품을 구매하면, 오퍼에 포함된 코스에 자동으로 접근 권한이 생겨요.

## 유료 코스 오퍼를 만들 때 좋은 점

상품으로 유료 코스 오퍼를 만들면 디지털 교육 콘텐츠를 다양한 방식으로 구성해 판매할 수 있어요.

- 결제가 끝나면 코스 접근 권한이 자동으로 부여돼요.
- 1회성 가격과 반복 가격을 모두 설정할 수 있어요.
- 멤버십 코스 제공과 바로 연결돼요.
- 여러 코스를 묶어 판매할 수 있어요.
- 추적과 리포팅이 쉬워져요.
- 업셀링과 오퍼 맞춤 설정이 가능해요.

## 상품을 설정하고 코스 오퍼에 연결하기

아래 순서대로 새 상품을 만들고 코스 오퍼에 연결해요.

### 1단계. 상품 만들기 화면 열기

1. 왼쪽 메뉴에서 **결제**(Payments)를 클릭해요.
2. 상단 메뉴의 **상품** 드롭다운에 마우스를 올리고, 목록에서 **상품**을 클릭해요. 기존 상품이 모두 보이는 상품 관리 페이지가 열려요.
3. 화면 오른쪽 위에 있는 파란색 **상품 만들기** 버튼을 클릭해요.

상품 만들기 화면이 열리면 상품 이름, 가격, 멤버십 설정 같은 핵심 정보를 입력할 수 있어요.

![상품 만들기 버튼이 있는 상품 관리 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044389908/original/99FpjutYgmbYqg6_ggyoxjmOjKv_-cIz1Q.png?1743591693)

### 2단계. 상품 정보 입력하기

**상품 정보** 섹션에서 상품의 기본 정보를 정해요.

- **Include in Online Store**(온라인 스토어에 포함): 이 상품을 온라인 스토어에서 보이게 하고 구매할 수 있게 할지 정하는 토글이에요. 상품을 공개하려면 켜 두세요.
- **제목**: 필수 항목이에요. 상품 이름을 입력해요. 이 이름은 결제 화면, 내부 화면, 공개 목록 등에 표시될 수 있어요.
- **설명**: 상품을 자세히 소개하는 곳이에요. 굵게, 기울임, 링크, 글머리 기호, 글꼴 설정 같은 서식을 써서 읽기 쉽게 꾸밀 수 있어요.
- **미디어**: 상품을 보여 주는 이미지나 동영상 파일을 올려요. 구매자가 어떤 상품인지 한눈에 알 수 있어요. 가장 잘 표시되려면 해상도 1024×1024, 용량 10MB 이하 파일을 권장해요.
- **상품 라벨 활성화**: 체크하면 상품에 "신상품", "추천" 같은 사용자 지정 라벨을 붙일 수 있어요. 라벨은 시각적인 배지나 내부 분류에 쓰일 수 있어요.
- **상품 컬렉션**: 이 상품을 기존 컬렉션에 넣는 드롭다운이에요. 비슷한 상품을 묶어 두면 상품이 많을 때 정리와 노출이 편해요.

![상품 정보 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044379584/original/3AilEGgO1T1HzsycekFlp1x0jNkS3FHULA.jpeg?1743585848)

### 3단계. 세금 옵션 설정하기

**상품 정보** 섹션에는 상품이 어떻게 표시되고 세금이 어떻게 적용될지 정하는 항목도 있어요.

- **상품 세금 코드**: 상품에 맞는 세금 분류를 선택해요. 결제할 때 세금을 자동으로 계산하려면 필요한 설정이에요. 비워 두면 기본 글로벌 세금 설정이 적용돼요.
- **가격에 세금 포함**: 상품 가격을 세금 포함으로 보여 줄지, 세금 별도로 보여 줄지 정해요. 글로벌 설정을 따르거나, **예**를 선택해 표시 가격에 세금을 포함하거나, **아니오**를 선택해 세금을 별도 요금으로 표시할 수 있어요.
- **Attach Tax Rates**(세율 연결): 세금을 직접 처리하거나 미국 외 지역에 구매자가 있을 때 유용해요.
- **명세서 표시 문구**: 고객의 카드·은행 명세서에 표시되는 기본 계정 이름 대신 쓸 문구를 입력해요. 구매자가 결제 내역을 알아보기 쉬워서 결제 분쟁이나 혼동을 줄이는 데 도움이 돼요.

![세금 옵션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044379732/original/BMzD5p8HcEubcmcBf0yki9myuiJrsKTdog.png?1743585941)

### 4단계. 가격 설정하기

**가격** 섹션에서 고객에게 상품을 어떤 조건으로 판매할지 정해요.

- **요금제 이름**: 내부에서 쓰는 이름이에요. 요금제나 플랜을 여러 개 운영할 때 서로 구분하는 용도예요.
- **유형**: 드롭다운에서 가격 유형을 선택해요.
  - **1회성**: 고객에게 한 번만 요금을 청구해요.
  - **반복**: 청구 주기, 체험 기간, 설정 비용 같은 옵션이 추가돼요.
- **금액**: 상품에 청구할 정확한 가격을 입력해요.
- **Compare-at Price**(비교 가격): 선택 입력 항목이에요. 실제 청구 가격 옆에 원래 가격을 함께 보여 줘서 할인 가격을 강조할 때 유용해요.
- **통화**: 결제에 사용할 통화를 선택해요. 예를 들면 USD가 있어요.
- **재고 추적**: 재고를 관리해야 한다면 체크하고 판매 가능한 수량을 입력해요.
- **추가 옵션**: 클릭하면 구매 한도, 메타데이터 필드 같은 고급 가격 설정이 나타나요.
- **가격 설명**: 이 가격 항목에 대한 짧은 메모나 설명을 입력해요. 내부에서만 보여요.

![가격 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044387970/original/pvfajS8UNYtH7UVEQROG6LQua9ApXxC0bg.png?1743590553)

{% hint style="warning" %}
반복 결제 오퍼 구독을 만들면서 결제 횟수를 입력하면, 선택한 횟수만큼 결제된 뒤 구독이 종료되고 취소돼요. 직접 취소할 때까지 구독을 계속 유지하려면 결제 횟수를 입력하는 필드를 비워 두세요.
{% endhint %}

![반복 결제 횟수 입력 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061506833/original/D7g0PqaxWZbqZ7_LjwDFsh0mVHCZEQk5TA.png?1767014394)

### 5단계. 상품을 멤버십 오퍼에 연결하기

가격 설정을 마쳤다면 접근 권한을 연결하기 위해 **멤버십 오퍼** 토글을 켜야 해요.

1. **멤버십 오퍼** 토글을 켜요. 그러면 **멤버십 오퍼 선택** 드롭다운이 나타나요.
2. 드롭다운에서 이 상품을 구매했을 때 부여할 멤버십 오퍼를 선택해요.

게시된 오퍼만 이 목록에 나타나요. 아직 게시하지 않은 오퍼는 선택할 수 없어요.

이 단계는 꼭 필요해요. 결제가 끝나면 오퍼에 연결된 코스나 교육 묶음에 구매자가 자동으로 등록되기 때문이에요. 이 설정을 켜고 오퍼를 선택하지 않으면, 구매를 완료해도 멤버십 콘텐츠에 접근할 수 없어요.

![멤버십 오퍼 토글과 멤버십 오퍼 선택 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044388238/original/thfApsA_zbktSfT-r0TTO95ZB-6lHMAZPQ.png?1743590737)

{% hint style="warning" %}
**중요**

상품을 만들기 전에 멤버십 오퍼를 먼저 만들고 게시해 두세요. 상품을 설정할 때 **멤버십 오퍼** 드롭다운에는 게시된 오퍼만 나타나요. 오퍼가 아직 초안 상태라면 상품 설정 중에 선택할 수 없어요.

**코스 오퍼 만드는 방법**

1. **멤버십** 탭으로 이동해요.
2. 드롭다운을 클릭하고 **오퍼**를 선택해요.
3. **+ 오퍼 만들기**를 클릭해요.
4. 제목을 입력하고, 코스를 선택하고, 가격을 설정한 뒤 **만들기**를 클릭해요.
5. 오퍼를 **게시**해요.

![코스 오퍼를 만드는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044393542/original/tgtQTi0bwRXrBWQxdk1AR2XPb-sjshk20w.gif?1743594515)
{% endhint %}

### 6단계. 상품 배리언트 추가하기

**배리언트** 섹션에서는 가격 단계, 콘텐츠 수준, 이용 기간처럼 한 상품의 여러 버전을 만들 수 있어요.

1. **옵션 이름**을 입력해요. 예를 들면 "코스 레벨"이나 "이용 플랜"이에요.
2. **옵션 값**에 구체적인 배리언트를 입력해요. 예를 들면 "베이직", "프리미엄", "프로"예요.
3. **완료**를 클릭해요.

배리언트마다 **가격**, **Compare-at Price**, **Available Quantity**(구매 가능 수량)를 따로 정할 수 있어서 옵션별 재고와 가격을 쉽게 관리할 수 있어요. 배리언트별 판매 수량을 제한하고 싶다면 **재고 추적**을 켜세요. 묶음 상품이나 기간 한정 등록을 운영할 때 특히 유용해요.

![배리언트 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044388415/original/aBmpqqgQbiMK2PZdg80DQa1Qea-IXT_Q4w.png?1743590844)

### 7단계. 검색 엔진 설정 최적화하기

**검색 엔진 리스팅** 섹션에서는 검색 엔진에서 상품이 더 잘 보이도록 설정할 수 있어요.

- **SEO 제목**: 상품을 분명히 나타내고, 사용자가 검색할 만한 키워드를 담은 간결한 제목을 입력해요.
- **SEO 설명**: 관련 키워드를 포함해 상품을 짧게 요약해요. 검색 결과에서 노출에 도움이 돼요.
- **핸들**: 상품의 고유 URL 주소(slug)예요. 예를 들면 /product/my-course-name 같은 형태예요. 링크를 읽기 쉽고 SEO에 유리하게 직접 바꿀 수 있어요.

이 섹션은 선택 사항이지만, 온라인에서 더 많은 사람에게 닿으려면 설정하기를 권장해요.

![검색 엔진 리스팅 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044388643/original/go1RsdO4eWNYU8bl1KYGtz5-de2Vpoclnw.png?1743591000)

### 8단계. 상품 저장하기

오른쪽 아래의 **저장** 버튼을 클릭해요. 저장하고 나면 이 상품을 구매한 사용자는 연결된 코스 오퍼에 자동으로 접근할 수 있어요.

## 자주 묻는 질문

### 멤버십 오퍼가 상품 드롭다운에 나타나지 않아요.
오퍼가 게시되어 있는지 확인하세요. 상품을 만들 때 **멤버십 오퍼** 드롭다운에는 게시된 오퍼만 나타나요.

### 한 상품에 1회성 가격과 반복 가격을 둘 다 만들 수 있나요?
네. **가격 추가**를 클릭하면 같은 상품 안에서 두 가지 가격 유형을 모두 설정할 수 있어요.

### 상품을 구매하면 어떻게 되나요?
연결된 오퍼에 포함된 멤버십 코스에 자동으로 접근할 수 있어요. 따로 할 일은 없어요.

### 구매자에게 로그인 정보를 보내려면 어떻게 하나요?
멤버십 설정에서 **환영 이메일 보내기** 옵션을 켜세요. 구매 후 로그인 정보가 자동으로 발송돼요.

### 결제 상품을 삭제하려면 어떻게 하나요?
결제 상품을 삭제하려면 연결된 오퍼를 삭제하세요. 결제 상품은 자동으로 삭제돼요.
