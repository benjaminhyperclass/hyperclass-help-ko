# 멤버십(코스)의 매직 링크

매직 링크를 쓰면 고객이 비밀번호 없이 하이퍼클래스의 코스와 커뮤니티 그룹에 안전하게 들어올 수 있어요. 링크마다 대상 고객 한 명이 로그인되고, 그 고객이 이미 볼 권한이 있는 콘텐츠로 안내돼요. 링크에는 유효 시간이 있어서 고객 계정을 보호하고, 이메일로 받은 링크가 만료되면 새 링크를 쉽게 요청할 수 있어요.

{% hint style="info" %}
새로 만든 서브 계정은 클라이언트 포탈 매직 링크를 사용해야 해요. 매직 링크는 **클라이언트 포탈**에서 만들 수 있어요. **사이트 > 클라이언트 포탈 > 대시보드**로 이동해 고객용 매직 링크를 생성하세요. 자세한 내용은 클라이언트 포탈 매직 링크 문서를 참고하세요.
{% endhint %}

## 멤버십에서 매직 링크란?

매직 링크는 고객별로 발급되는 보안 URL이에요. 이 링크로 사용자 이름이나 비밀번호를 입력하지 않고 **클라이언트 포탈**에 들어갈 수 있어요. 유효 시간이 있는 인증 방식이라 계정을 보호하면서 코스와 커뮤니티에 쉽게 접근할 수 있어요.

고객이 매직 링크를 누르면 하이퍼클래스가 그 고객을 로그인시키고, 알맞은 코스, 커뮤니티 또는 **클라이언트 포탈** 화면으로 안내해요. 고객에게는 이미 접근 권한이 있는 콘텐츠만 보여요.

{% hint style="info" %}
에이전시 관리자 계정으로 로그인한 상태에서 매직 링크를 사용하면, 해당 서브 계정의 코스가 모두 보여요.
{% endhint %}

## 매직 링크의 장점

- 비밀번호 없이 접근: 고객이 비밀번호를 기억하거나 재설정하지 않아도 로그인할 수 있어요.
- 안전한 인증: 토큰 방식의 링크라서 계속 유효하지 않고 정해진 시간이 지나면 만료돼요.
- 빠른 접근: 고객이 이메일에서 바로 코스나 그룹으로 이동할 수 있어요.
- 간편한 링크 재발급: 만료 안내 페이지에서 고객이 새 링크를 이메일로 직접 요청할 수 있어요.
- 콘텐츠 기준 권한: 고객에게는 이미 배정된 코스, 그룹 등의 콘텐츠만 보여요.
- 로그인 문제 감소: 접근이 쉬워져서 비밀번호 분실로 인한 문의가 줄어들 수 있어요.

## 매직 링크 생성하기

**클라이언트 포탈**에서 매직 링크를 생성하면 특정 고객이 바로 비밀번호 없이 접근할 수 있어요. 이 링크는 15분 후에 만료되므로 생성한 뒤 바로 보내고, 고객도 바로 열어야 해요.

1. **멤버십 > 클라이언트 포탈**로 이동하세요.
2. **작업** 영역까지 스크롤하세요.
3. **생성**을 선택하세요.
4. 생성된 매직 링크를 복사하세요.
5. 대상 고객에게 링크를 직접 보내세요.

{% hint style="info" %}
매직 링크를 생성하면 만료까지 남은 시간이 카운트다운 타이머로 표시돼요. 현재 링크가 만료되면 **매직 링크 생성** 버튼이 다시 활성화되어 새 링크를 만들 수 있어요.
{% endhint %}

![매직 링크 생성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077633367/original/fiR0ZTXIA8SozFWuxylf3NmLsKkc8D0_Uw.png?1785873172)

{% hint style="warning" %}
서브 계정에서 직접 생성한 링크는 15분 후에 만료돼요. 고객이 그 시간 안에 링크를 열지 못하면 새 링크를 생성하세요.
{% endhint %}

## 매직 링크 만료

매직 링크의 만료 시간은 링크를 전달하는 방법에 따라 달라요.

- 이메일로 보낸 링크: 24시간 후에 만료돼요. 만료되면 고객이 **Send New Link**(새 링크 보내기)를 선택해서 등록된 이메일 주소로 새 링크를 받을 수 있어요.
- **멤버십 > 클라이언트 포탈**에서 생성한 링크: 15분 후에 만료돼요. 고객이 시간 안에 열지 못하면 새 링크를 생성하세요.

![매직 링크 만료 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077928451/original/Um-8daZIicHj-rBWapyVeXtXU4btvw6KpQ.png?1786133591)

{% hint style="warning" %}
중요: 매직 링크는 고객을 로그인시킬 뿐, 콘텐츠 접근 권한을 주지는 않아요. 링크를 보내기 전에 고객에게 알맞은 코스나 그룹 권한이 있는지 확인하세요.
{% endhint %}

## 워크플로우와 이메일로 매직 링크 보내기

### 1단계. 코스 트리거 설정하기

**워크플로우**로 이동해서 코스 트리거를 설정하세요.

![워크플로우에서 코스 트리거를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029533660/original/HGoeFs54iW8jMwlhcO-KIzyeQrtMFm6NxQ.png?1721378637)

**Learner Magic Link**(학습자 매직 링크)는 모든 코스 트리거에서 쓸 수 있어요.

학습자 매직 링크는 코스 트리거에서만 쓸 수 있어요. 사용할 수 있는 트리거는 다음과 같아요: **Category Started**(카테고리 시작), **Category Completed**(카테고리 완료), **Lesson Started**(강의 시작), **Lesson Completed**(강의 완료), **New Sign Up**(신규 가입), **Offer Access Granted**(오퍼 접근 권한 부여), **Offer Access Removed**(오퍼 접근 권한 제거), **Product Access Granted**(상품 접근 권한 부여), **Product Access Removed**(상품 접근 권한 제거), **Product Started**(상품 시작), **Product Completed**(상품 완료)

### 2단계. 로그인 URL을 선택할 수 있는 액션 추가하기

**Login Url(Magic Link)**(로그인 URL(매직 링크))을 선택할 수 있는 이메일이나 SMS 같은 액션을 추가하세요.

![이메일 액션에서 로그인 URL을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029534395/original/NCkXxSJ1y8kjEA9H_qRFW0bBuKNQLwD-4w.png?1721379260)

![SMS 액션에서 로그인 URL을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029534474/original/zVJpTrGLl6u1T4KO_8XbPqSRg-fAQbqkkA.png?1721379335)

이메일이 발송될 때 해당 연락처의 **Learner Magic Link**가 자동으로 채워져요.

{% hint style="info" %}
매직 링크는 사전에 동의를 받은 경우에만 공유하세요. 링크를 가진 사람은 누구나 코스 자료에 접근할 수 있어요.
{% endhint %}

### 이메일 캠페인(이메일 템플릿)으로 학습자 매직 링크 보내기

![이메일 템플릿에 로그인 URL 커스텀 값을 넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029536404/original/TR9dnVE3XFd6MszvdB4sLZJ_WZFJo81YwQ.png?1721380667)

**Login Url(Magic Link)** 커스텀 값을 쓰면 이메일 캠페인으로도 매직 링크를 보낼 수 있어요.

## 매직 링크 테스트와 문제 해결

코스나 그룹 접근 권한이 올바르게 있는 실제 연락처로 매직 링크를 테스트하세요. 링크는 시크릿(비공개) 창에서 열어 보세요. 관리자 로그인 세션의 영향 없이 이동하는 화면과 권한이 올바른지 확인할 수 있어요.

### 자주 발생하는 문제

- 링크가 만료됐어요: 이메일로 받은 링크라면 **Send New Link**를 선택하세요. **멤버십 > 클라이언트 포탈**에서 생성한 링크라면 **작업**으로 돌아가 **생성**을 다시 선택하세요.
- 다시 보낸 이메일이 오지 않아요: 스팸함과 필터링된 폴더를 확인하세요. 그런 다음 연락처 정보에 등록된 이메일 주소가 맞는지 확인하세요.
- 고객에게 기대한 콘텐츠가 보이지 않아요: 알맞은 코스, 오퍼, 상품 또는 커뮤니티 그룹 접근 권한이 배정되었는지 확인하세요.
- 다른 계정이 열려요: 고객별 링크를 재사용하거나 전달하지 마세요. 해당 연락처에 맞는 새 링크를 생성하세요.
- 테스트할 때 더 많은 콘텐츠가 보여요: 시크릿(비공개) 창에서 링크를 열어 관리자 권한이 결과에 영향을 주지 않게 하세요.

## 자주 묻는 질문

### 매직 링크는 얼마 동안 유효한가요?

이메일로 보낸 매직 링크는 24시간 동안 유효해요. **멤버십 > 클라이언트 포탈**에서 직접 생성한 링크는 15분 동안 유효해요.

### 이메일로 받은 매직 링크가 만료되면 어떻게 하나요?

고객이 만료 안내 페이지에서 **Send New Link**를 선택하면 돼요. 하이퍼클래스가 고객의 등록된 이메일 주소로 새 링크를 보내 드려요.

### 매직 링크로 코스나 그룹에 접근 권한이 생기나요?

아니요. 매직 링크는 고객을 로그인시킬 뿐이에요. 코스나 그룹에 접근하려면 고객에게 이미 권한이 있어야 해요.

### 고객이 로그인은 되는데 기대한 콘텐츠가 보이지 않아요

고객의 연락처 정보에 알맞은 코스 오퍼, 상품 또는 그룹 접근 권한이 배정되어 있는지 확인하세요.
