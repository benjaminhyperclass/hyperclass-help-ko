# 레거시 멤버십에서 클라이언트 포탈로 옮기기

레거시 멤버십에서 **클라이언트 포탈**로 마이그레이션하는 방법을 안내해요. 클라이언트 포탈과 레거시 멤버십에 대해 자주 묻는 질문도 함께 정리했어요.

## 코스 설정에서 마이그레이션 시작하기

레거시 멤버십에서 **클라이언트 포탈**로 옮기면 코스와 멤버십을 한곳에서 설정할 수 있어요. 설정 화면도 새로 바뀌어서 마이그레이션 안내를 쉽게 찾고 따라갈 수 있어요.

마이그레이션을 시작하려면 다음 순서대로 하세요.

1. **멤버십**으로 이동하세요.
2. **코스**를 여세요.
3. 사이트의 설정 영역으로 이동하세요.
4. 설정 화면에 표시된 마이그레이션 안내 메시지를 확인하세요.
5. 화면의 안내에 따라 **클라이언트 포탈** 설정으로 이동하세요.

![코스 설정 화면의 마이그레이션 안내](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071115798/original/oQYRIfs3y17uF9wTR8jJKcQHJy357laJLA.png?1778580376)

{% hint style="info" %}
마이그레이션이 끝나면 브랜딩, 도메인, 이메일 설정, 앱 설정을 확인해서 현재 사용 중인 설정과 같은지 살펴보세요.
{% endhint %}

## 클라이언트 포탈 FAQ

### 클라이언트 포탈을 쓰면 어떤 점이 좋은가요?
클라이언트 포탈에서는 코스, 커뮤니티, 제휴 등 다양한 기능을 하나의 플랫폼에서 같은 로그인 정보로 쓸 수 있어요.

### 클라이언트 포탈로 옮기면 사용자가 새 계정을 만들어야 하나요?
아니요. 새 클라이언트 포탈에서도 레거시 멤버십 로그인 정보를 그대로 쓸 수 있어요.

### 레거시 멤버십의 기능을 새 클라이언트 포탈에서도 모두 쓸 수 있나요?
네. 레거시 멤버십의 모든 기능을 새 클라이언트 포탈에서 쓸 수 있어요. 여기에 알림, 모바일 앱, 구독 관리 같은 새 기능도 더해져 더 나은 환경을 쓸 수 있고, 앞으로 기능이 더 추가될 예정이에요.

## 레거시 멤버십 FAQ

### 레거시 멤버십이 무엇인가요?
레거시 멤버십은 멤버십 코스를 관리하던 기존 방식이에요. 학습자가 로그인해서 강의 자료를 볼 수 있는 플랫폼이에요. 반면 클라이언트 포탈에서는 코스뿐 아니라 커뮤니티, 구독 관리 등 더 다양한 기능을 쓸 수 있어요.

### 기존 멤버십 PWA를 새 클라이언트 포탈에서도 쓸 수 있나요?
기존 PWA는 새 클라이언트 포탈과 호환되지 않아요. 대신 새로운 네이티브 모바일 앱을 현재 개발하고 있고, 완성되면 클라이언트 포탈에서 완전히 지원될 예정이에요. 이 모바일 앱은 서브 계정별 화이트라벨 옵션도 제공해요.

{% hint style="info" %}
레거시 멤버십에서 클라이언트 포탈로 마이그레이션하려면 **멤버십 > 설정 > Site Settings**(사이트 설정)로 이동하세요.
{% endhint %}
