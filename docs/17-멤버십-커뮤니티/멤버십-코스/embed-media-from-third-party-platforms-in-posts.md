# 코스 강의에 외부 플랫폼 미디어 삽입하기

외부 플랫폼에 올려 둔 영상이나 오디오를 iframe 임베드 코드로 하이퍼클래스 코스 강의에 바로 넣을 수 있어요. 이 문서에서는 지원하는 플랫폼, 삽입 순서, 사용할 때 지켜야 할 점을 안내해요.

## 코스에서 외부 플랫폼 미디어 삽입이란?

iframe 임베드 코드를 사용해 외부에 올려 둔 영상이나 오디오를 하이퍼클래스 코스 강의에 바로 추가하는 기능이에요. 수강생은 강의 안에서 지원되는 미디어를 바로 볼 수 있어요. 미디어 파일을 하이퍼클래스에 따로 올릴 필요도 없어요.

지원하는 외부 플랫폼의 영상, 팟캐스트, 데모, 오디오를 코스 강의에 바로 넣을 수 있어요.

## 지원하는 플랫폼

현재 아래 플랫폼의 미디어를 삽입할 수 있어요.

- YouTube
- Vimeo
- Loom

**오디오**

- SoundCloud
- Wistia
- Spotify
- Mixcloud

이 플랫폼들의 iframe 임베드 코드를 사용하세요.

## 외부 플랫폼 미디어를 삽입하는 방법

강의 미디어 영역에 임베드 코드를 넣으면, 외부에 올려 둔 미디어가 코스 강의 안에 바로 표시돼요.

1. **멤버십 > 코스 > 상품**으로 이동하세요.

   ![멤버십 > 코스 > 상품 화면](https://jumpshare.com/share/A7WHVC6w3l9bcV00Qyl4+/Screenshot+2026-09-01+at+20.41.15.png)
2. 편집할 코스를 여세요.
3. 미디어를 추가할 강의나 모듈을 여세요.
4. **강의 미디어** 또는 **설명** 영역에서 **미디어 삽입**을 선택하세요.

   ![강의 미디어 영역에서 미디어 삽입을 선택하는 화면](https://jumpshare.com/share/zb03QtrUa3qpGpu4hr7l+/GIF+Recording+2026-09-01+at+20.44.08.gif)
5. 지원하는 외부 플랫폼에서 iframe 임베드 코드를 복사하세요.

   YouTube 예시:

   - YouTube 영상을 여세요.
   - **공유**를 클릭하세요.
   - **임베드**를 선택하세요.
   - iframe 코드를 복사하세요.

     ![YouTube에서 iframe 코드를 복사하는 화면](https://jumpshare.com/share/TeekGpZfye0qdK4DFi2U+/GIF+Recording+2026-09-01+at+20.51.52.gif)
6. 코스로 돌아와 **미디어 삽입** 필드에 복사한 iframe 코드를 붙여 넣으세요.
7. **임베드**를 클릭하세요.
8. 강의에 미디어가 제대로 표시되는지 확인하세요.
9. 필요에 따라 **저장 및 게시**를 눌러 강의를 저장하고 게시하세요.

   ![강의를 저장하고 게시하는 화면](https://jumpshare.com/share/OUZQcblM8CIHZTj41Hwx+/GIF+Recording+2026-09-01+at+20.53.42.gif)

## 저작권 및 사용 규정

```
안내: 외부 콘텐츠를 삽입할 권리가 있는지는 직접 확인해야 해요.
```

삽입하기 전에 아래 내용을 확인하세요.

- 공개된 콘텐츠이거나, 공유를 허락받은 콘텐츠예요.
- 해당 콘텐츠를 표시할 법적 권리가 있어요.
- 원본 플랫폼의 서비스 이용약관과 이용 가이드라인을 지키고 있어요.
- 비공개 콘텐츠, 허락 없이 라이선스를 받은 콘텐츠, 공유할 수 없다고 표시된 콘텐츠는 삽입하지 마세요.

## 활용 팁

- 작성한 내용을 **미리보기** 기능으로 확인해서 삽입한 미디어가 제대로 불러와지는지 항상 확인하세요.
- 짧게 줄인 링크나 다른 곳으로 이동하는 링크는 피하고, 공식 임베드 코드를 사용하세요.
- 라이선스 위반을 막으려면 팀원에게 콘텐츠 라이선스에 대해 알려 주세요.

## 자주 묻는 질문

### 어떤 외부 플랫폼이든 미디어를 삽입할 수 있나요?
아니요. 위에 나열한 지원 영상·오디오 플랫폼 중 하나의 iframe 임베드 코드를 사용하세요.

### 영상이나 오디오 파일을 하이퍼클래스에 먼저 올려야 하나요?
아니요. 미디어는 외부 플랫폼에 그대로 두고, iframe 임베드 코드를 통해 강의에 표시돼요.

### iframe 임베드 코드는 어디서 받나요?
플랫폼마다 달라요. 해당 플랫폼의 공유 또는 임베드 옵션을 찾아보세요. 예를 들어 YouTube에서는 **공유 > 임베드**에서 코드를 받을 수 있어요.

### 삽입한 미디어가 제대로 표시되지 않아요. 어떻게 해야 하나요?
지원하는 플랫폼에서 공식 iframe 임베드 코드를 복사했는지 확인하세요. 원본 미디어를 공개로 공유할 수 있는 상태인지도 확인하세요.
