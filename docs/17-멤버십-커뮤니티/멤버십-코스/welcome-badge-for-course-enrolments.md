# 코스 수강 등록 시 환영 배지 자동 발급

환영 배지는 학습자가 코스에 처음 수강 등록하는 순간 자동으로 발급되는 배지예요. 새 코스를 만들면 환영 배지가 기본으로 들어가므로 따로 설정하지 않아도 학습자를 바로 맞이할 수 있어요.

## 코스의 환영 배지란?

환영 배지는 학습자가 코스에 수강 등록하는 즉시 자동으로 발급되는 자격 증명이에요. 하이퍼클래스에서 새 코스를 만들 때 기본으로 포함되므로 별도 설정 없이 학습자에게 바로 인정을 표시할 수 있어요.

코스 수료 인증서나 워크플로우로 발급하는 배지와 달리, 환영 배지는 수강 등록 단계에서 발급돼요. 학습 과정에서 가장 먼저 받는 인정인 셈이에요. 처음부터 학습자의 참여를 이끌어 낼 수 있고, 하이퍼클래스의 [자격 증명 기능](hyperclass-credentials-preview-memberships.md)과도 자연스럽게 이어져요.

## 코스 환영 배지의 장점

환영 배지는 자격 증명을 쉽게 쓰게 해 주고, 학습자 경험도 처음부터 좋아지게 해 줘요.

- 학습자 즉시 인정: 학습자가 처음 수강 등록하면 바로 배지를 받아요. 첫날부터 참여 의욕을 높일 수 있어요.
- 기본 자격 증명 적용: 새 코스에는 환영 배지가 자동으로 포함돼요. 모든 코스에서 일관되게 쓸 수 있어요.
- 간편한 설정: 워크플로우나 수동 설정이 필요 없어서 코스 제작자의 설정 시간이 줄어요.
- 간추린 템플릿 선택: 엄선한 환영 배지 템플릿 중에서 전문적인 디자인을 빠르게 고를 수 있어요.
- 학습자 프로필 강화: 자동 발급된 배지가 **클라이언트 포탈**의 학습자 자격 증명 이력에 쌓여요.

## 새 코스의 환영 배지 기본 동작

환영 배지는 새로 만든 코스의 기본 동작에 포함돼 있어요. 추가 설정 없이 학습자에게 인정을 전달할 수 있어요.

- 새로 만든 모든 코스에 자동으로 연결돼요.
- 학습자가 처음 수강 등록할 때 발급돼요.
- 이미 만들어 둔 기존 코스에는 소급해서 적용되지 않아요.
- 워크플로우나 자동화 설정이 필요 없어요.

## 환영 배지와 다른 자격 증명 비교

자격 증명 유형마다 학습 과정에서 쓰이는 시점이 달라요. 차이를 알아 두면 더 완성도 높은 학습 경험을 설계할 수 있어요.

| 자격 증명 유형 | 발급 시점 | 발급 방식 | 목적 |
| --- | --- | --- | --- |
| 환영 배지 | 처음 수강 등록할 때 | 자동(새 코스의 기본값) | 학습자를 바로 인정하고 참여 유도 |
| 수료 인증서 | 코스를 수료한 뒤 | 코스 수료 설정 | 코스 수료 확인 |
| 워크플로우로 발급하는 배지/인증서 | 사용자 지정 동작에 따라 | 워크플로우 자동화 | 마일스톤, 퀴즈, 맞춤 성과에 대한 보상 |

수료 인증서는 [코스 기본 인증서와 카테고리 수료 인증서](../../38-인증서/Issue-Certificates/default-certificates-in-courses-category-completion-certificate.md) 문서에서, 워크플로우 발급은 [워크플로우에서 배지 발급 자동화하기](../../38-인증서/Issue-Badge/automate-badge-issuance-in-workflows-using-issue-certificate-action.md) 문서에서 자세히 볼 수 있어요.

## 코스에 환영 배지 설정하기

환영 배지는 새 코스에 자동으로 포함되므로 설정할 게 거의 없어요. 필요하면 원하는 대로 바꿀 수 있어요.

1. **멤버십 > 코스 > 상품**으로 이동해 새 코스를 만들어요. 환영 배지가 자동으로 추가돼요.

   ![새 코스 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067088559/original/Dq_uxFDh7_KnMnKtgcTFQ2cb1sNp9y3E9g.png?1773736543)
2. 코스 설정을 열고 **환영 배지** 섹션을 찾아요.

   ![코스 설정의 환영 배지 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067088726/original/BaiLEj2nh2LnfnSew0zb0cQJesX6splz3A.png?1773736627)
3. **템플릿을 선택하세요**에서 엄선된 환영 배지 템플릿 5개 중 하나를 고르고, 선택한 내용을 저장해요.

   ![환영 배지 템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067088879/original/1d2jUfZI5GtmkVSbFv33evqPY2xXbdyU5g.png?1773736697)
4. 디자인을 바꾸고 싶다면 **멤버십 > 자격 증명**으로 이동해 **Certificate Builder**(인증서 빌더)에서 배지를 편집해요. 배지 사용법은 [인증서 빌더에서 배지 사용하기](../../38-인증서/Issue-Badge/how-to-use-badges-in-certificate-builder.md) 문서를 참고하세요.
5. 자동 발급을 끄고 싶다면 **자격 증명**에서 배지 상태를 **Draft**(초안)로 바꿔요.

## 자주 묻는 질문

### 환영 배지가 기존 코스에도 적용되나요?
아니요. 새로 만든 코스에만 자동으로 추가돼요.

### 학습자가 다시 수강 등록하면 배지를 여러 번 받나요?
아니요. 배지는 처음 수강 등록할 때 한 번만 발급돼요.

### 다른 배지 템플릿을 환영 배지로 쓸 수 있나요?
네. **내 템플릿**에서 배지를 선택하세요.

### 워크플로우로도 배지를 발급할 수 있나요?
네. 고급 설정이나 맞춤 시나리오를 위해 워크플로우 기반 배지 발급을 계속 쓸 수 있어요.

### 환영 배지의 디자인을 바꿀 수 있나요?
네. 모든 디자인 변경은 **자격 증명**(Certificate Builder) 영역에서 해요.

### 환영 배지를 껐다가 다시 켤 수 있나요?
네. 배지 상태를 다시 **Published**(게시됨)로 바꾸면 돼요.
