# Legacy Memberships에서 화이트라벨 멤버십 PWA 만들기

화이트라벨 멤버십 PWA(Progressive Web App)를 만들면 별도의 모바일 앱 없이도 우리 브랜드를 담은 앱 같은 환경을 제공할 수 있어요. 이 문서에서는 하이퍼클래스에서 PWA를 설정하고 꾸며서 배포하는 방법, 설치 방법, 네이티브 모바일 앱과의 차이를 안내해요.

{% hint style="warning" %}
멤버십 PWA는 **Legacy Memberships**(기존 멤버십) 환경에서만 쓸 수 있어요. **클라이언트 포탈** 환경에서는 지원하지 않아요. 로케이션에서 **클라이언트 포탈**을 쓰고 있다면 PWA를 설정하기 전에 **Legacy Memberships**로 전환하세요.
{% endhint %}

---

## 화이트라벨 멤버십 PWA란?

PWA는 앱 스토어에서 내려받지 않아도 모바일 앱처럼 쓸 수 있는 웹 기반 애플리케이션이에요. 하이퍼클래스의 화이트라벨 멤버십 PWA를 쓰면 멤버십 사이트의 디자인, 브랜딩, 기능을 원하는 대로 꾸미면서 콘텐츠와 사용자 경험도 직접 관리할 수 있어요.

PWA는 네이티브 모바일 앱과 달리 웹 브라우저로 접속하고, Apple의 App Store나 Google Play를 거치지 않고 사용자의 기기에 바로 설치해요. 그래서 네이티브 앱을 개발하는 복잡함 없이 앱 같은 경험을 제공하고 싶은 사업자에게 유연하고 비용 부담이 적은 선택지예요.

하이퍼클래스에서 멤버십 PWA는 **Legacy Memberships** 환경의 기능이에요. **클라이언트 포탈**, 그리고 **클라이언트 포탈** 모바일 앱과는 별개예요.

---

## 화이트라벨 멤버십 PWA의 장점

- 모든 기기에서 사용: 별도 개발 없이 모바일, 태블릿, 데스크톱에서 모두 접속할 수 있어요.
- 앱 같은 경험: 학습자가 홈 화면, 데스크톱, 앱 실행기에서 멤버십 포털을 바로 열 수 있어요.

## PWA와 네이티브 모바일 앱, 무엇이 다를까요?

| 항목 | PWA | 네이티브 모바일 앱 |
| --- | --- | --- |
| 설치 | 브라우저에서 설치하며 앱 스토어가 필요 없어요 | App Store/Google Play에서 내려받아요 |
| 업데이트 | 새로 고침하면 자동으로 업데이트돼요 | 앱 스토어에서 직접 업데이트해야 해요 |
| 오프라인 사용 | 대체로 인터넷 연결이 필요해요. 이전에 불러온 콘텐츠를 볼 수 있는지는 상황에 따라 달라요. | 오프라인 기능을 모두 쓸 수 있어요 |
| 푸시 알림 | 기기, 브라우저, 운영체제, 하이퍼클래스의 기능 지원 여부에 따라 달라요. | 완전히 지원돼요 |
| 성능 | 빠르고 가벼워요 | 복잡한 앱은 대체로 더 빨라요 |
| 승인 절차 | 앱 스토어 승인이 필요 없어요 | App Store/Google Play 가이드라인을 따라야 해요 |

## 시작 전 준비: 멤버십과 브랜딩 정리하기

멤버십 PWA를 설정하기 전에 브랜딩과 멤버십 구조를 먼저 갖춰 두세요. 이렇게 준비해 두면 사용자 경험이 좋아지고 PWA도 더 깔끔하고 전문적으로 보여요.

1. 브랜딩 설정: **Legacy Memberships**로 전환한 다음 **멤버십 > 코스 > 설정 > 브랜딩**으로 이동해 브랜딩과 앱 설정을 구성하세요. 비즈니스 로고를 올리고, 브라우저 탭에 보일 파비콘도 추가하세요. 이 이미지들은 앱 곳곳에 표시되어 브랜드 정체성을 알려 줘요.
2. 멤버십 구조 설정: **Legacy Memberships**에서 **멤버십 > 코스 > 상품**으로 이동해 코스, 오퍼, 접근 수준과 관련 콘텐츠를 만들거나 확인하세요. 상품 등급을 만들고 코스를 추가한 다음 가격과 접근 수준을 설정하세요. 콘텐츠를 미리 정리해 두면 PWA 안에서 학습 흐름이 매끄러워져요.
3. 사용자 지정 도메인 연결(선택): **설정 > 도메인**에서 app.yourbrand.com 같은 사용자 지정 도메인을 연결하세요. 브랜드 도메인을 쓰면 신뢰도가 높아지고 PWA가 더 앱처럼 느껴져요.

여기까지 마쳤다면 멤버십 PWA를 설정할 준비가 끝났어요.

## 화이트라벨 멤버십 PWA 설정하기

### 1단계: 멤버십 열기

서브 계정에서 **멤버십**으로 이동하세요. **클라이언트 포탈**이 열리면 **멤버십** 전환기를 사용해 **Legacy Memberships**로 이동하세요. 그다음 상단 메뉴에서 **코스 > 설정**을 선택하세요. 멤버십 설정 영역이 열리고 주요 구성 옵션을 볼 수 있어요.

{% hint style="warning" %}
멤버십 PWA는 **Legacy Memberships** 환경에서만 쓸 수 있어요. **클라이언트 포탈** 환경에서는 지원하지 않아요.
{% endhint %}

![멤버십 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043790988/original/Jw_NBG-BSTHD4Pr_3QhBnvoaUZbm9u2adA.png?1742714853)

### 2단계: 앱 설정 선택하기

**코스 > 설정**으로 이동했다면 **앱 설정**(App Details) 타일을 찾으세요. 여기서 PWA가 데스크톱과 모바일 기기에서 어떻게 보이고 동작할지 설정해요.

**앱 설정** 타일이 보이지 않으면 로케이션이 **클라이언트 포탈**이 아니라 **Legacy Memberships**를 쓰고 있는지 확인하세요.

![앱 설정 타일](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077162932/original/b9H9zmARpQR_3EiWzEgvQZYRi5LqdabqGw.png?1785339077)

### 3단계: PWA 설치 켜기

PWA 설치를 켜면 사용자가 네이티브 앱처럼 자기 기기에 앱을 "설치"할 수 있어요. 그만큼 접근하기 쉬워지고 참여도도 높아져요. 설치를 켜 두면 학습자가 지원되는 브라우저에서 설치할 수 있어요. 설치 옵션과 표시되는 문구는 브라우저, 운영체제, 기기에 따라 달라요.

![PWA 설치 켜기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076517577/original/BOTGuB2amhBSSHAJ6yt9yLrov4SsGlvq4w.png?1784648504)

### 4단계: PWA 설정 꾸미기

**앱 설정** 영역에서 **Enable PWA**(PWA 활성화) 토글을 켰다면, 이제 PWA의 모양과 동작을 정할 수 있어요. 앱의 이름과 정체성, 외형을 만드는 단계예요.

#### 앱 이름, 짧은 이름, 설명

이 항목들은 기기마다 앱이 어떻게 소개될지 정해요.

- **이름**: 앱의 전체 이름이에요. 설치 안내 창과 앱 제목 표시줄에 표시돼요.
- **짧은 이름**: 앱 이름을 줄인 버전이에요. 홈 화면이나 앱 폴더처럼 공간이 좁은 곳에 표시돼요.
- **설명**: 앱이 무엇인지 알려 주는 짧은 문장이에요. 사용자가 브라우저 설치 안내 창에서 설치할 때 참고가 돼요.

![이름, 짧은 이름, 설명 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077163368/original/viPTzwiwRrLODd58BceOHplB2Y3j-MZ77Q.png?1785339246)

#### 앱 아이콘

아이콘은 큰 버전(512x512)과 작은 버전(192x192), 두 가지를 올려야 해요. 스플래시 화면, 앱 목록, 홈 화면처럼 기기와 플랫폼마다 다른 곳에 쓰여요. 화면 크기에 맞춰 시스템이 자동으로 아이콘을 고르지만, 각 크기에 정확히 맞는 파일을 올리기를 권장해요. 아이콘은 .jpg 또는 .png 형식이어야 하고, 브랜드 일관성을 위해 두 아이콘의 모양은 똑같아야 해요.

![앱 아이콘 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077163400/original/BjqqFc4oNuK6oy9BOJQ9iv8aoh2CPAiicw.png?1785339269)

#### 앱 색상

앱 테마에 쓸 색상 팔레트가 미리 준비되어 있어요. 이 색상은 버튼, 헤더 같은 화면 요소의 스타일에 반영돼요. 지금은 색상 코드(hex)를 직접 입력할 수 없지만, 팔레트는 어떤 기기에서도 대비가 뚜렷하고 잘 보이도록 만들어졌어요. 브랜드에 가장 잘 맞는 팔레트를 클릭해서 고르세요.

![앱 색상 팔레트 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077163435/original/Q784u70VOrL6eO2wYuB0-NPJWH4LPE0Bxw.png?1785339290)

### 5단계: 설정 저장하기

앱 정보를 입력하고, 아이콘을 올리고, 테마 색상을 고른 뒤에는 오른쪽 위의 **저장**을 클릭하세요. 저장하지 않으면 사용자가 PWA를 설치할 때 변경 사항이 하나도 적용되지 않아요.

### Mac 컴퓨터에 설치하기

#### Chrome 또는 Microsoft Edge

1. 멤버십 로그인 포털을 여세요.
2. 멤버십 계정으로 로그인하세요.
3. 브라우저 주소 표시줄에서 설치 아이콘을 선택하세요.
4. 설치를 확인하세요.

#### 지원되는 macOS 버전의 Safari

1. Safari에서 멤버십 포털을 여세요.
2. **파일 > Add to Dock**(Dock에 추가)을 선택하세요.
3. 앱 이름을 입력하세요.
4. **추가**를 선택하세요.

### Android 기기에 설치하기

가장 안정적으로 설치하려면 Google Chrome에서 멤버십 로그인 포털을 여세요. 아래 영상처럼 Chrome 브라우저에서 PWA를 홈 화면에 추가하면 설치할 수 있어요.

1. 멤버십 계정으로 로그인하세요.
2. Chrome 메뉴를 여세요.
3. **Install app**(앱 설치) 또는 **Add to Home screen**(홈 화면에 추가)을 선택하세요.
4. 화면의 안내를 따르세요.

---

### iOS 모바일 기기에 설치하기

1. Safari에서 멤버십 로그인 포털을 여세요.
2. 멤버십 계정으로 로그인하세요.
3. **공유** 아이콘을 누르세요.
4. **Add to Home Screen**(홈 화면에 추가)을 선택하세요.
5. 앱 이름을 확인하고 **추가**를 누르세요.

## 멤버십 PWA 문제 해결

### 앱 설정이 보이지 않아요

로케이션이 **Legacy Memberships**를 쓰고 있는지 확인하세요. 멤버십 PWA는 **클라이언트 포탈** 환경에서는 설정할 수 없어요.

### 설치 옵션이 나타나지 않아요

PWA 설치가 켜져 있고 설정을 저장했는지 확인하세요. 게시된 멤버십 포털을 HTTPS로 열고, 지원되는 브라우저에서 로그인한 다음 브라우저 메뉴에 **Install app**(앱 설치) 또는 **Add to Home Screen**(홈 화면에 추가)이 있는지 확인하세요.

### 변경한 브랜딩이 보이지 않아요

이전에 설치한 PWA를 삭제하고 관련 브라우저 캐시를 지운 다음, 멤버십 포털을 다시 열어 PWA를 새로 설치하세요.

### 사용자가 **클라이언트 포탈**로 들어가요

현재 어떤 멤버십 환경을 쓰고 있는지 확인하고, 멤버십 PWA를 쓰기 전에 **Legacy Memberships**로 전환하세요.

## 자주 묻는 질문

### PWA를 App Store에 제출할 수 있나요?
멤버십 PWA는 지원되는 브라우저에서 바로 설치하도록 만들어졌어요. 서드파티 네이티브 래퍼로 패키징하는 방법은 하이퍼클래스의 기본 멤버십 PWA 설정 범위 밖이에요. 개발자의 도움이 필요할 수 있고, Apple이나 Google의 요건도 따로 충족해야 해요.

지원되는 브랜드 네이티브 앱이 필요하면 **클라이언트 포탈**의 **브랜드 모바일 앱** 옵션을 확인해 보세요.

### PWA는 오프라인에서도 되나요?
로그인하고, 코스를 불러오고, 최신 멤버십 콘텐츠를 보려면 대체로 인터넷 연결이 필요해요. 이전에 불러온 콘텐츠는 기기와 브라우저에 따라 잠시 볼 수 있지만, 완전한 오프라인 사용은 보장되지 않아요.

### PWA로 푸시 알림을 보낼 수 있나요?
푸시 알림을 쓸 수 있는지는 기기, 브라우저, 운영체제, 그리고 하이퍼클래스가 지원하는 알림 기능에 따라 달라요. 멤버십 PWA를 설치했다고 해서 푸시 알림이 자동으로 켜지지는 않아요.

### 화이트라벨 PWA를 설정하려면 개발자가 필요한가요?
아니요, 하이퍼클래스 화면에서 코딩 없이 쉽게 설정할 수 있어요.
