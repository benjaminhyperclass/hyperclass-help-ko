# 다른 코스에서 콘텐츠 가져오기

이미 만들어 둔 코스의 강의, 모듈, 전체 구조를 다른 코스로 복사해 재사용하는 기능이에요. 비슷한 코스를 만들거나, 온보딩 자료를 다시 쓰거나, 코스 템플릿으로 빠르게 제작할 때 쓰면 좋아요. 가져온 콘텐츠는 대상 코스에 추가되므로, 수강생에게 공개하기 전에 확인하고 편집할 수 있어요.

## 다른 코스에서 콘텐츠 가져오기란?

**하이퍼클래스 코스** 기능으로, 기존 코스의 콘텐츠를 다른 코스로 복사해 올 수 있어요. 필요한 만큼 강의, 모듈, 하위 모듈, 코스 전체 구조 중에서 골라 가져와요.

비슷한 코스를 여러 개 만들 때 시간을 아끼고 교육 자료를 일관되게 유지하도록 만든 기능이에요. 가져온 콘텐츠는 대상 코스로 복사되기 때문에, 가져온 뒤에는 그 코스 안에서 자유롭게 편집할 수 있어요.

### 주요 장점

- 시간 절약: 기존 강의, 모듈, 하위 모듈, 코스 전체 구조를 직접 다시 만들지 않고 재사용할 수 있어요.
- 일관성 유지: 검증된 구조, 강의 형식, 보조 자료를 복사해 비슷한 코스끼리 맞출 수 있어요.
- 중복 작업 방지: 여러 코스가 같은 온보딩, 교육 콘텐츠를 쓸 때 같은 작업을 반복하지 않아도 돼요.
- 유연한 가져오기: 강의 하나, 선택한 모듈, 코스 전체 중에서 필요한 범위만 가져올 수 있어요.
- 가져온 뒤 편집 가능: 대상 코스에 추가된 콘텐츠를 그 코스 안에서 자유롭게 수정할 수 있어요.

## 가져올 때 함께 복사되는 내용

코스 콘텐츠를 가져오면 선택한 항목이 대상 코스로 복사돼요. 가져온 뒤에는 코스 구조, 미디어, 보조 자료가 수강생에게 보여 줄 준비가 됐는지 확인해 보세요.

다른 코스에서 가져올 때 다음 내용이 포함될 수 있어요.

- 강의 제목과 구조
- 모듈 및 하위 모듈 계층
- 동영상과 첨부 미디어
- 썸네일
- 설명과 서식이 적용된 콘텐츠
- 퀴즈 문항
- 과제와 자료

## 가져오기 전에 알아 둘 점

가져오기가 어떻게 동작하는지 알아 두면 헷갈리지 않아요. 가져오기는 콘텐츠를 대상 코스로 복사할 뿐, 원본 코스와 가져온 사본을 서로 연결하지는 않아요.

- 가져온 콘텐츠는 복사본이며 연결되어 있지 않아요.
- 나중에 원본 코스를 수정해도 가져온 사본은 자동으로 바뀌지 않아요.
- 가져온 사본을 수정해도 대상 코스에만 반영돼요.
- 대상 코스에 이미 있던 콘텐츠는 덮어쓰지 않아요.
- 가져온 항목은 코스의 기존 콘텐츠 옆에 추가돼요.
- 코스를 게시하거나 수강생에게 공개하기 전에 가져온 콘텐츠를 확인하세요.

## 다른 코스에서 콘텐츠 가져오는 방법

대상 코스가 이미 만들어져 있고, 재사용할 콘텐츠가 어느 원본 코스에 있는지 알고 있을 때 가장 편해요. 가져온 뒤에는 대상 코스에서 강의 순서, 미디어, 퀴즈, 과제, 공개 범위 설정이 의도한 수강 경험과 맞는지 확인하세요.

1. **멤버십 > 코스 > 상품**으로 이동해, 콘텐츠를 가져올 코스를 열어요.

   ![멤버십 > 코스 > 상품에서 코스 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071177260/original/WMYYhOlhixqkc31bvk8nn5vlEAViuNYDag.png?1778608118)
2. **코스 빌더**에서 **+ Add Content**(콘텐츠 추가)를 클릭해요. 드롭다운 메뉴에서 **다른 코스에서 가져오기**를 선택해요.

   ![코스 빌더의 콘텐츠 추가 드롭다운에서 다른 코스에서 가져오기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071177420/original/492YqrICPFBein-qvNc8TACWnYWOPCLyOQ.png?1778608224)
3. 팝업 창에서 콘텐츠를 가져올 코스를 검색하거나 목록에서 찾아요. 원본 코스에서 **선택**을 클릭해요.

   ![원본 코스에서 선택 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071177645/original/buPdrIWRiGb7cTvAojhrtSajbmNNDxz-dg.png?1778608519)
4. 가져올 콘텐츠를 골라요. 강의, 모듈, 하위 모듈을 개별로 선택하거나 코스 전체 구조를 선택할 수 있어요. 선택한 범위에 따라 **선택한 항목 가져오기** 또는 **코스 전체 가져오기**를 클릭해요.

   ![가져올 콘텐츠 선택 후 가져오기 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071177798/original/JPaxlZqlF7B0DkaTkIfIvdy75tuVbSvU9Q.png?1778608642)
5. 콘텐츠가 대상 코스에 추가되는 동안 가져오기 진행 상황 창을 확인해요. 가져오기는 백그라운드에서 계속 진행되므로, 끝날 때까지 다른 작업을 해도 돼요. 가져오기가 끝나면 대상 코스에서 가져온 콘텐츠를 확인해요.

   ![가져오기 진행 상황 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071177816/original/sMEAkQ1fILjRPi_IdY2pu29IG3eznQEL7g.png?1778608661)
6. 가져온 모듈, 하위 모듈, 강의, 동영상, 썸네일, 설명, 퀴즈, 과제, 자료가 제대로 보이는지 확인해요.

## 이럴 때 활용해 보세요

여러 코스가 비슷한 강의, 구조, 교육 자료를 쓴다면 특히 유용해요. 빠르게 시작할 기반을 만들어 주고, 대상이나 상품에 맞게 다시 고칠 수도 있어요.

- 온보딩 모듈을 여러 코스에서 재사용할 때
- 공통 템플릿으로 비슷한 코스를 여러 개 만들 때
- 기초 강의가 반복되는 번들 코스 프로그램을 만들 때
- 검증된 강의를 새 버전의 코스로 복사할 때

## 자주 묻는 질문

### 다른 코스에서 강의 하나만 가져올 수 있나요?
네, 가능해요. 원본 코스에서 가져올 항목을 고를 때 강의를 개별로 선택할 수 있어요.

### 코스 전체를 가져올 수 있나요?
네, 가능해요. 모듈, 하위 모듈, 강의를 모두 대상 코스로 복사하려면 코스 전체 구조를 가져오세요.

### 가져오면 기존 코스 콘텐츠가 덮어씌워지나요?
아니요. 가져온 콘텐츠는 대상 코스의 기존 콘텐츠 옆에 추가되고, 현재 콘텐츠를 덮어쓰지 않아요.

### 가져온 항목이 원본 코스와 연결되어 있나요?
아니요. 가져온 콘텐츠는 복사본이라 연결되어 있지 않아요. 이후 원본 코스를 수정해도 가져온 버전은 자동으로 바뀌지 않아요.

### 가져온 콘텐츠를 가져온 뒤에 편집할 수 있나요?
네, 가능해요. 가져온 콘텐츠는 바로 대상 코스에서 편집할 수 있어요.
