# 코스 미리보기와 드립 일정 개선 사항

Kajabi 코스 가져오기, 드립 일정 값 검증, 관리자 미리보기가 개선되었어요. 이 문서에서 달라진 점과 사용 방법을 확인해 보세요.

## 관리자 미리보기·안정성 개선이란?

이번 업데이트에서는 다음 세 가지가 개선되었어요.

- Kajabi 코스 가져오기
- 드립 일정 값 검증
- **네오 클래식 테마**의 관리자 미리보기 동작

덕분에 가져오기가 더 안정적으로 진행돼요. 잘못된 일정 값은 저장되지 않고, 관리자는 잠긴 강의와 잠금이 풀린 강의 상태를 더 정확하게 미리 볼 수 있어요.

## 주요 장점

- 규모가 큰 코스 구조도 Kajabi에서 더 안정적으로 가져올 수 있어요.
- 중첩된 강의와 숨겨진 콘텐츠를 더 잘 처리해요.
- 잘못된 드립 일정 값이 저장되지 않아요.
- 수강생이 보는 화면을 관리자가 더 쉽게 미리 볼 수 있어요.
- 미리보기 모드에서 화면 이동이 더 자연스러워졌어요.

## Kajabi 가져오기 개선

이제 Kajabi에서 규모가 크거나 중첩된 코스 구조를 더 잘 가져올 수 있어요.

개선된 내용은 다음과 같아요.

- **더 보기** 영역을 자동으로 감지해요.
- 중첩된 카테고리와 하위 카테고리를 더 잘 추출해요.
- 규모가 큰 코스도 더 안정적으로 가져와요.

덕분에 강의와 모듈이 더 일관되게 가져와져요.

### 왜 중요한가요?

규모가 큰 Kajabi 코스를 옮길 때 가져오기가 더 안정적이고, 빠지는 강의도 줄어들어요.

## 드립 설정 값 검증

이제 하이퍼클래스는 잘못된 드립 값이 저장되지 않도록 막아요.

예를 들면 다음과 같아요.
`0` 같은 드립 값은 저장할 수 없어요.
- 올바르지 않은 일정 값은 더 이상 저장되지 않아요.

덕분에 강의 공개 방식이 일관되게 유지되고, 일정 관련 문제도 줄어들어요.

### 드립 설정 방법

1. 코스 상품을 엽니다.
2. 강의 또는 카테고리를 선택합니다.
3. **드립 설정**을 엽니다.
4. `0`보다 큰 올바른 드립 지연 값을 입력합니다.
5. **변경사항 저장**을 클릭합니다.

{% hint style="info" %}
이제 코스 드립 설정에는 올바른 드립 일정 값만 저장할 수 있어요.
{% endhint %}

## 관리자 모드 미리보기 (네오 클래식 테마)

**Admin Mode**(관리자 모드)에 미리보기 토글이 추가되었어요. 이 토글로 아래 두 보기를 오갈 수 있어요.

- 잠긴 강의 보기
- 잠금이 모두 풀린 강의 보기

이 미리보기로 다음을 확인할 수 있어요.

- 수강생이 보는 화면
- 강의 전체에 접근할 수 있는지
- 강의 상태에 따른 화면 이동 동작

화면 이동도 개선되어, 바뀐 강의 보기가 올바르게 표시돼요.

![잠긴 강의 미리보기 화면과 콘텐츠 보기(잠금 해제) 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070953327/original/bKZHDlz8v3tF2g7GSlzlBtr1OoKGcbE7vA.png?1778378942)

이 스크린샷에서 볼 수 있는 내용은 다음과 같아요.

- 잠긴 강의 미리보기
- **View Content (Unlocked)**(콘텐츠 보기(잠금 해제)) 토글
- **네오 클래식 테마**의 미리보기 동작

## 잠긴 강의와 잠금 해제된 강의 미리보기

1. **상품 > 코스**로 이동합니다.
2. **네오 클래식 테마**를 사용하는 코스를 엽니다.
3. **미리보기 모드**로 들어갑니다.
4. 오른쪽 위에 있는 **View Content (Unlocked)** 토글을 사용합니다.
5. 아래 두 보기를 오가며 확인합니다.
   - 잠긴 수강생 보기
   - 잠금이 모두 풀린 관리자 보기

미리보기 모드에서는 다음을 확인해 보세요.

- 강의 접근 동작
- 드립 일정이 어떻게 보이는지
- 강의 사이의 화면 이동 흐름

## 자주 묻는 질문

### 관리자가 잠긴 강의 보기를 미리 볼 수 있나요?
네. 이제 **Admin Mode**에서 잠긴 강의 미리보기와 잠금 해제된 강의 미리보기를 전환할 수 있어요.

### 미리보기 토글이 실제 수강생에게도 영향을 주나요?
아니요. 이 토글은 미리보기용으로 **Admin Mode** 안에서만 쓸 수 있어요.

### 드립 값을 0으로 설정할 수 있나요?
아니요. 일정 문제를 막기 위해 `0` 같은 잘못된 드립 값은 이제 저장할 수 없어요.

### Kajabi를 가져올 때 중첩된 카테고리와 하위 카테고리도 지원되나요?
네. 중첩된 강의 구조도 이제 더 안정적으로 가져와져요.

### Kajabi를 가져오면 **더 보기** 뒤에 숨겨진 강의도 포함되나요?
네. 이제 Kajabi를 가져올 때 숨겨진 강의가 있으면 자동으로 감지해서 가져와요.

### 미리보기 토글은 모든 코스 테마에서 쓸 수 있나요?
아니요. 현재는 **네오 클래식 테마**에서만 쓸 수 있어요.
