# Learning 탭에서 무료 코스 추가하고 관리하기

커뮤니티 그룹의 **Learning**(학습) 탭에 무료 코스를 추가하고 삭제하는 방법을 안내해요. 관리자와 소유자가 코스를 추가하면 커뮤니티 멤버가 바로 코스를 볼 수 있어요.

## 

---

## 코스 추가하기

관리자와 소유자는 **Learning** 탭에서 무료 코스를 간단히 추가할 수 있어요.

1. **Learning** 탭에서 **Add Courses**(코스 추가)를 클릭하세요.
2. 추가할 코스를 선택하세요.
3. 코스가 추가되면 해당 페이지에서 코스를 볼 수 있어요.

{% hint style="info" %}
하이퍼클래스로 멤버십·코스 웹사이트를 만드는 방법은 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

## 코스 삭제하기

코스를 없애려면 **삭제** 버튼을 클릭하세요.

![코스 삭제 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010513815/original/pRvq1bPTr4bPtP80StBq5nAEKIGouiQuZQ.png?1697702467)

## 코스 접근 권한

관리자나 소유자가 그룹의 **Learning** 탭에 코스를 추가하면, 그룹의 모든 멤버가 바로 그 코스에 접근할 수 있어요.

## 알림

관리자나 소유자가 그룹에 새 코스를 추가할 때마다 모든 사용자에게 이메일로 알림이 가요.
