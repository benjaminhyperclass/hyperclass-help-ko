# 커뮤니티 코스를 비공개 채널 멤버에게만 공개하기

커뮤니티 그룹 안의 특정 비공개 채널 멤버에게만 코스를 보여 주고 싶을 때 쓰는 기능이에요. 코스의 공개 범위를 **Private Channel**(비공개 채널)로 설정하는 방법과 활용 예시를 안내해요.

## 비공개 채널 기반 코스 액세스란?

비공개 채널 기반 코스 액세스는 코스 공개 범위 설정 중 하나예요. 그룹 관리자는 하이퍼클래스 커뮤니티 그룹 안의 특정 비공개 채널 멤버에게만 코스를 공개할 수 있어요. 코스를 **Private Channel** 공개 범위로 설정하면, 선택한 비공개 채널에 속한 멤버만 코스 콘텐츠를 보고 이용할 수 있어요.

지정한 비공개 채널에 속하지 않은 멤버는 코스 목록에서 이 코스를 볼 수 없어요. 그 채널에 들어가면 코스가 보여요. 이렇게 하면 커뮤니티 안에서 누가 교육 콘텐츠를 볼 수 있는지 세밀하게 관리할 수 있어요.

비공개 채널 기반 액세스를 적용한 코스에는 **Private-channel based access**(비공개 채널 기반 액세스) 태그가 표시돼요. 관리자가 접근이 제한된 코스를 한눈에 알아볼 수 있어요.

## 비공개 채널 기반 코스 액세스의 장점

- **세밀한 액세스 제어**: 커뮤니티 그룹 전체가 아니라 특정 비공개 채널 멤버에게만 코스를 공개해서 콘텐츠를 정확하게 나눠 줄 수 있어요.
- **프리미엄 콘텐츠 관리**: 일반 커뮤니티 이용에는 영향을 주지 않고, 선택한 멤버 그룹에만 전용 교육 자료나 유료 콘텐츠를 제공할 수 있어요.
- **간편한 관리**: 접근이 제한된 코스를 태그로 쉽게 구분하고, 한곳에서 공개 범위를 관리할 수 있어요.
- **대상별 구분**: 멤버 등급, 역할, 구독 수준에 따라 맞춤 학습 경험을 만들 수 있어요.
- **콘텐츠 정리**: 접근 권한이 없는 멤버의 코스 목록이 불필요한 코스로 어수선해지지 않아요.

## 비공개 채널 기반 코스 액세스 설정하기

하이퍼클래스 커뮤니티 그룹에서 코스의 공개 범위를 비공개 채널로 설정하는 순서예요. 코스 공개 범위는 그룹 관리자와 소유자만 바꿀 수 있어요.

1. 하이퍼클래스 계정에 로그인한 뒤 왼쪽 메뉴에서 **멤버십 > 커뮤니티 > 그룹**으로 이동해요. 코스 액세스를 설정할 그룹에서 **로그인** 버튼을 눌러요.

   ![커뮤니티 그룹 목록에서 로그인 버튼을 선택하는 화면](https://jumpshare.com/share/7LIoTQ2pcLFAUYAGbHeu+/Screenshot+2026-08-11+at+19.23.49.png)

2. 그룹 안에서 페이지 위쪽의 **학습** 탭을 눌러요. 커뮤니티 그룹에서 이용할 수 있는 모든 코스가 보여요.

   ![그룹 상단의 학습 탭 화면](https://jumpshare.com/share/7aFDFs9yuLBdI3sonmM7+/Screen+Shot+2026-08-11+at+19.29.11.png)

3. 접근을 제한할 코스를 찾아 코스 카드 오른쪽 위의 점 세 개 메뉴 아이콘을 누르고, 드롭다운 메뉴에서 **편집**을 선택해요.

   ![코스 카드의 점 세 개 메뉴에서 편집을 선택하는 화면](https://jumpshare.com/share/2zuvaUVaQ66UQpcEfrPk+/Screenshot+2026-08-11+at+19.35.17.png)

4. **Edit Course**(코스 편집) 창에서 **공개 범위** 드롭다운을 눌러요. 아래로 스크롤해서 **Private Channel** 옵션을 선택해요. 드롭다운에는 **Members of a private channel**(비공개 채널 멤버)이라고 표시돼요.

   ![공개 범위 드롭다운에서 비공개 채널 옵션을 선택하는 화면](https://jumpshare.com/share/5foBGfgYyit8iHgHa3cL+/Screenshot+2026-08-11+at+19.38.10.png)

5. **Private Channel** 공개 범위를 선택하면 사용할 수 있는 비공개 채널 목록이 나타나요. 코스를 공개할 비공개 채널을 선택해요. 선택한 채널의 멤버만 코스를 볼 수 있어요.

   ![코스를 공개할 비공개 채널을 선택하는 화면](https://jumpshare.com/share/cx3g0aLKA002pFGA97RO+/Screenshot+2026-08-11+at+19.40.31.png)

6. **코스 업데이트**를 눌러 공개 범위 설정을 저장해요. **학습** 탭에서 코스 이름 옆에 **Private-channel based access** 태그가 표시되고, 선택한 비공개 채널 멤버만 코스 목록에서 이 코스를 볼 수 있어요.

   ![저장 후 코스 이름 옆에 비공개 채널 기반 액세스 태그가 표시된 화면](https://jumpshare.com/share/68TMOgVBP9zFnreuRu5f+/Screen+Shot+2026-08-11+at+19.41.58.png)

{% hint style="info" %}
이제 코스는 선택한 비공개 채널 멤버에게만 공개돼요. 설정은 **Edit Course** 창으로 돌아가 공개 범위를 바꾸면 언제든 수정할 수 있어요.
{% endhint %}

## 활용 예시

비공개 채널 기반 코스 액세스는 커뮤니티 운영자, 교육자, 멤버십 사이트 운영자가 다양한 방식으로 콘텐츠를 나눠 줄 때 쓸 수 있어요.

### 활용 예시 1. 유료 멤버 전용 프리미엄 콘텐츠

프리미엄 구독자 전용 비공개 채널에만 코스를 공개해서 유료 멤버 전용 코스를 만들 수 있어요. 커뮤니티에 무료 이용 등급을 유지하면서 교육 콘텐츠로 수익도 낼 수 있어요.

### 활용 예시 2. 운영진 전용 교육

운영진 전용 비공개 채널 멤버에게만 접근 권한을 줘서 커뮤니티 운영진에게 전문 교육 코스를 제공할 수 있어요. 내부 교육 자료를 일반 커뮤니티에 노출하지 않고도 운영팀에 필요한 자료를 전달할 수 있어요.

### 활용 예시 3. 내부용 또는 베타 콘텐츠

팀원, 베타 테스터, 얼리 어답터용 비공개 채널로 공개 범위를 한정해서 내부 문서, 사내 교육 자료, 베타 코스 콘텐츠의 접근을 제한할 수 있어요.

### 활용 예시 4. 등급별 멤버십 모델

코스를 서로 다른 비공개 채널에 지정해서 멤버십 등급을 나눌 수 있어요. 예를 들어 브론즈 멤버는 채널 A의 코스를, 실버 멤버는 채널 A와 B의 코스를, 골드 멤버는 전용 채널 C의 콘텐츠를 포함한 모든 채널의 코스를 볼 수 있게 설정해요.

### 활용 예시 5. 역할별 학습 경로

영업, 지원, 리더십 같은 직무별 비공개 채널을 만들고, 관련 코스를 해당 채널에만 공개해서 역할에 맞는 교육을 제공할 수 있어요.

## 자주 묻는 질문

### 코스 공개 범위는 누가 바꿀 수 있나요?
그룹 관리자와 그룹 소유자만 코스 공개 범위를 편집할 수 있어요. 일반 멤버는 이 설정을 바꿀 수 없어요.

### 접근 권한이 없는 멤버도 제한된 코스가 있다는 걸 알 수 있나요?
아니요. 지정한 비공개 채널에 속하지 않은 멤버는 **학습** 탭에서 이 코스를 전혀 볼 수 없어요. 코스가 완전히 숨겨져요.

### 이 기능을 쓰려면 비공개 채널을 먼저 만들어야 하나요?
네. **Private Channel** 공개 범위 옵션이 나타나려면 커뮤니티 그룹에 비공개 채널이 하나 이상 있어야 해요. 비공개 채널이 없으면 **공개 범위** 드롭다운에 이 옵션이 보이지 않아요.

### 비공개 채널 액세스를 다시 전체 공개로 바꿀 수 있나요?
네. 언제든 코스를 편집해서 공개 범위를 **Private Channel**에서 다른 옵션으로 바꿀 수 있어요.

### 어떤 코스에 비공개 채널 액세스가 적용됐는지 어떻게 알 수 있나요?
비공개 채널 액세스를 적용한 코스는 **학습** 탭에서 코스 이름 옆에 태그가 표시돼요. 이 표시로 관리자가 접근이 제한된 코스를 빠르게 알아볼 수 있어요.
