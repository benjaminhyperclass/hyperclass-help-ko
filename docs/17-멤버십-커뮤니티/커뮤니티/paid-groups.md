# 커뮤니티 유료 그룹

커뮤니티의 공개 그룹과 비공개 그룹에서 가입비를 받을 수 있어요. 관리자와 오너는 그룹의 콘텐츠와 기능을 이용하려는 사용자에게 요금을 청구할 수 있어요.

## 공개 그룹과 비공개 그룹

커뮤니티 안의 **설정** 버튼에서 그룹을 **Public**(공개)으로 할지 **Private**(비공개)으로 할지 정할 수 있어요. 관리자와 오너가 설정할 수 있어요.

![공개·비공개 그룹 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010441060/original/r-2_24WatpySg2CeP4LZveKRaY6__tX63g.png?1697632634)

## 일회성 결제

일회성 결제는 한 번 결제하고 그룹 접근 권한을 받으면 기간 제한 없이 그룹을 이용할 수 있어요. 일회성 결제를 설정하는 순서는 다음과 같아요.

1. 커뮤니티에 로그인해요.
2. **설정 > 구독**으로 이동해요.
3. **Add new price**(새 가격 추가)를 클릭하고, **Amount**(금액)를 입력한 뒤 **Type**(유형)을 one-time(일회성)으로 선택해요.
4. **추가**를 클릭한 다음 **저장**을 클릭해요. 일회성 결제가 적용된 유료 그룹이 만들어져요.

   {% hint style="info" %}
   결제를 테스트하려면 **Test Mode**(테스트 모드)를 켜세요.
   {% endhint %}
5. 저장하면 그룹에 가입하려는 멤버에게 보이는 그룹 설명에도 같은 내용이 표시돼요.

## 정기 구독

정기 구독은 결제 후 그룹 접근 권한을 받으면 접근 기간이 제한돼요. 정기 구독을 설정하는 순서는 다음과 같아요.

1. 커뮤니티에 로그인해요.
2. **설정 > 구독**으로 이동해요.
3. **Add new price**(새 가격 추가)를 클릭해요. **Amount**(금액)를 입력하고, **Type**(유형)을 **Recurring**(정기)으로 선택해요. 체험 기간이 있다면 **Trial Days**(체험 일수)를 입력하고, **결제 주기**를 **Monthly**(월간) 또는 **Annually**(연간)로 선택해요.
4. **추가**를 클릭한 다음 **저장**을 클릭해요. 정기 구독이 적용된 유료 그룹이 만들어져요.
5. 결제를 테스트하려면 **Test Mode**(테스트 모드)를 켜세요.
6. 저장하면 그룹에 가입하려는 멤버에게 보이는 그룹 설명에도 같은 내용이 표시돼요.

## 세금

유료 그룹 결제에도 이미 설정해 둔 **결제 > 설정 > 세금** 구성이 적용돼요. **결제**에서 **자동 세금** 또는 **Manual Tax Rates**(수동 세율)를 설정해 두었다면, 해당하는 유료 그룹 구매에는 결제 화면에서 세금이 표시될 수 있어요.

자세한 내용은 [커뮤니티 결제의 세금 지원](../멤버십-코스/tax-support-in-communities.md)을 참고하세요.

## 그룹 접근 권한 부여

결제가 끝난 뒤 접근 권한을 주는 방법은 그룹 유형에 따라 달라요.

- 비공개 그룹: 결제가 끝나면 관리자와 오너가 기존 비공개 그룹과 같은 방식으로 멤버에게 접근 권한을 줘야 해요. **People**(멤버) 탭으로 이동해 **필터**를 클릭하고 **Requested**(요청됨)를 선택한 다음, **Accept or Deny Membership**(멤버십 수락 또는 거절)에서 처리하세요.
- 공개 그룹: 결제가 끝나면 사용자가 가입하고 바로 멤버가 돼요.

![멤버십 요청을 수락하거나 거절하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010488248/original/vxnbdvM81OlRIfLr0YbVvXCf2k_9J9D_KA.png?1697655047)

## 알림

- 사용자가 그룹에 가입하기 위해 결제하고 이어서 멤버십을 요청하면(그룹 유형에 따라 다름), 모든 관리자와 오너가 상세 내용이 담긴 이메일 알림을 받아요.
- 사용자도 결제 내용이 담긴 결제 확인 이메일을 받아요.
- 관리자나 오너가 멤버십을 승인하면, 사용자에게 멤버십 승인과 그룹 접근 권한에 대한 알림이 가요.

## 취소와 환불

### 멤버가 하이퍼클래스 결제 화면에서 구독을 취소하면 어떻게 되나요?

사용자가 하이퍼클래스 결제 화면에서 구독을 취소하면 다음과 같이 처리돼요.

- 사용자에게 취소 확인 이메일이 가요.
- 해당 구독과 연결된 그룹의 관리자와 오너에게 취소 접수 이메일이 가요.
- 사용자가 그룹에서 자동으로 제외돼요.

### 멤버가 Stripe 화면에서 구독을 취소하면 어떻게 되나요?

사용자가 Stripe 화면에서 구독을 취소하면 다음과 같이 처리돼요.

- 사용자에게 취소 확인 이메일이 가요.
- 해당 구독과 연결된 그룹의 관리자와 오너에게 취소 접수 이메일이 가요.
- 사용자가 그룹에서 자동으로 제외돼요.

### 멤버가 결제한 금액을 환불받으려면 어떻게 하나요?

Stripe와 하이퍼클래스 결제, 두 곳 모두에서 환불받을 수 있어요.

1. 하이퍼클래스에서: **결제 > 거래 내역**으로 이동해요. 거래 항목 오른쪽의 점 세 개 아이콘을 클릭한 다음 **환불**을 클릭하세요.
2. Stripe에서: 연락처 상세 화면에서 Stripe로 환불할 수 있어요.

### 연락처를 삭제했다가 복원하면 사용자가 다시 결제해야 하나요?

현재 시스템 기능 기준으로, 사용자의 연락처를 실수로 삭제했다가 복원하면 사용자는 다시 결제하지 않고도 그룹에 복귀할 수 있어요.

### 통화별 최소·최대 결제 금액은 얼마인가요?

최소·최대 결제 금액은 <https://stripe.com/docs/currencies>에서 확인하세요.
