# 커뮤니티 게시글과 댓글에서 음성 메모 사용하기

커뮤니티 게시글과 댓글에 음성 메모를 녹음하거나 오디오 파일을 올릴 수 있어요. 긴 글을 쓰지 않고도 멤버에게 빠르고 생생하게 이야기를 전할 수 있어요.

하이퍼클래스 커뮤니티 멤버는 게시글과 댓글 작성 창에서 바로 음성 메모를 녹음해 보낼 수 있어요. 이미 가지고 있는 오디오 파일도 다른 첨부파일과 함께 올릴 수 있어요.

이 문서에서는 음성 메모 녹음, 오디오 파일 업로드, 재생 컨트롤 사용, 녹음한 음성 메모와 업로드한 오디오의 차이, 댓글에 음성 메모 추가하는 방법을 안내해요.

## 커뮤니티의 음성 메모란?

음성 메모를 쓰면 긴 메시지를 입력하지 않고도 빠르게 의견을 나눌 수 있어요. 게시글이나 댓글에 모든 내용을 글로 쓰는 대신, 마이크 버튼으로 메시지를 녹음해 대화에 올리면 돼요.

간단한 근황 공유, 설명, 피드백, 안내처럼 말하는 편이 타이핑보다 쉬운 상황에서 유용해요. 멤버는 커뮤니티 게시글이나 댓글에서 바로 녹음을 들을 수 있어요.

하이퍼클래스에서는 오디오 파일 업로드도 지원해요. 커뮤니티 게시글 하나에 작성 창에서 직접 녹음한 음성 메모, 업로드한 오디오 파일, 또는 둘 다 넣을 수 있어요.

{% hint style="info" %}
대화를 떠나지 않고 음성으로 소통할 수 있어요. 짧은 음성 근황을 전하려고 별도의 대화로 옮겨 갈 필요 없이, 커뮤니티 게시글과 댓글에 바로 음성을 추가할 수 있어요.
{% endhint %}

## 커뮤니티 게시글에 음성 메모 녹음하기

게시글을 만드는 중에 새 음성 메모를 녹음할 수 있어요. 녹음 컨트롤은 게시글 작성 창에서 다른 첨부 옵션과 함께 바로 쓸 수 있어요.

1. 게시글을 올릴 커뮤니티 채널을 열고 새 게시글 작성을 시작해요. 게시글에 필요한 제목과 설명을 입력해요.
2. 작성 창에서 **microphone**(마이크) 버튼을 선택해 음성 메모 녹음을 시작해요.
3. 메시지를 말해요. 녹음하는 동안 작성 창에 오디오 파형과 녹음 시간이 표시돼서, 목소리가 녹음되고 있는지 확인할 수 있어요.

![게시글 작성 창에서 음성 메모를 녹음하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080953098/original/5IUJ9WM8rup1zUbgvrXn39L9cT1el7NupA.png?1789467569)

## 게시하기 전에 녹음 관리하기

말하기 시작하자마자 바로 게시하지 않아도 돼요. 음성 메모 컨트롤로 게시글을 올리기 전에 녹음을 관리할 수 있어요.

- **일시정지**: 음성 메모를 끝내지 않고 녹음을 잠시 멈춰요.
- **다시 시작**: 일시정지한 뒤 녹음을 이어서 해요.
- **취소**: 지금 녹음한 내용을 버려요. 녹음을 남기고 싶지 않을 때 써요.

녹음을 마치면 음성 메모가 오디오 첨부파일로 게시글에 추가돼요. 이후 게시글의 나머지 내용을 계속 작성한 뒤 게시하면 돼요.

{% hint style="info" %}
게시하기 전에 확인하세요. 필요하면 재생 컨트롤로 녹음한 오디오를 먼저 들어 본 뒤 게시글을 게시할 수 있어요.
{% endhint %}

## 이미 있는 오디오 파일 업로드하기

새로 녹음하는 대신 이미 가지고 있는 오디오 파일을 첨부할 수도 있어요. 파일로 저장해 둔 오디오 소식, 녹음본, 강의 등 다른 오디오 콘텐츠를 올릴 때 편리해요.

1. 게시글을 만드는 중에 작성 창의 첨부 컨트롤을 사용해요.
2. 포함하려는 오디오 파일을 선택해요. 커뮤니티 게시글에서 지원하는 다른 첨부파일과 함께 오디오를 추가할 수 있어요.
3. 업로드한 오디오가 작성 창의 다른 첨부파일과 함께 표시되는지 확인해요. 녹음한 음성 메모와 업로드한 오디오 파일을 같은 게시글에 함께 넣을 수 있어요.

![게시글 작성 창에 오디오 파일을 첨부한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080956863/original/DgSAOEmUbRKd3tBpnH-3swLcZPMakFgTvQ.png?1789469103)

{% hint style="info" %}
말하고, 올리고, 듣는 일을 커뮤니티 안에서 모두 할 수 있어요. 음성 메모를 쓰면 멤버가 게시글과 댓글에서 바로 음성으로 이야기를 전할 수 있어서 커뮤니티 토론이 더 유연해져요.
{% endhint %}

## 음성 메모와 오디오 파일 재생하기

게시글이 게시되면 멤버는 게시글에서 바로 음성 메모와 업로드된 오디오를 재생할 수 있어요. 오디오마다 재생 컨트롤이 따로 있어서 커뮤니티 토론을 벗어나지 않고 들을 수 있어요.

녹음한 음성 메모는 파형으로 표시돼요. 업로드한 오디오 파일은 타임라인 형태의 플레이어로 표시돼서, 파일의 재생 진행 상황을 따라갈 수 있어요.

{% hint style="info" %}
오디오가 대화와 함께 남아요. 멤버는 게시글과 토론을 보면서 오디오를 들을 수 있어서, 음성 정보를 다른 커뮤니티 콘텐츠와 같은 곳에서 확인하기 쉬워요.
{% endhint %}

## 댓글에 음성 메모 추가하기

음성 메모는 게시글 본문에만 쓰는 기능이 아니에요. 댓글 작성 창을 쓸 수 있을 때는 음성으로 답변을 녹음해 바로 댓글로 올릴 수 있어요.

1. 답변하려는 커뮤니티 게시글로 이동해 댓글 입력란을 선택해요.
2. 댓글 작성 창의 **microphone** 버튼을 선택해 답변 녹음을 시작해요.
3. 녹음을 마치고 댓글을 보내요. 음성 메모가 오디오 재생 컨트롤과 함께 댓글 스레드에 표시돼요.

![댓글 스레드에 음성 메모가 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080957088/original/kUbvbZruCHx0S5rDnJ6rsqD87AWtHwBCmg.png?1789469196)

## 녹음한 음성 메모와 업로드한 오디오의 차이

녹음한 음성 메모와 업로드한 오디오 모두 멤버가 커뮤니티 안에서 음성이나 오디오 콘텐츠를 바로 들을 수 있게 해 줘요. 오디오를 어떤 방식으로 추가했는지 쉽게 알 수 있도록 표시 방식은 서로 달라요.

- 녹음한 음성 메모
  - 작성 창에서 바로 만들어요.
  - 게시글이나 댓글을 만들면서 마이크 버튼으로 녹음해요. 게시 후에는 파형 형태의 플레이어로 표시돼요.
- 업로드한 오디오
  - 이미 있는 파일을 추가해요.
  - 커뮤니티에 추가하기 전에 이미 파일로 존재하는 오디오예요. 게시 후에는 음성 메모의 파형 대신 타임라인 형태의 플레이어로 표시돼요.

{% hint style="info" %}
같은 게시글에 둘 다 쓸 수 있어요. 커뮤니티 게시글 하나에 새로 녹음한 음성 메모와 업로드한 오디오를 함께 넣을 수 있어요. 짧은 인사는 직접 녹음하고, 길게 준비한 오디오 콘텐츠는 파일로 올리는 식으로 조합할 수 있어요.
{% endhint %}

## 재생 속도와 연속 재생

멤버는 오디오가 재생되는 속도를 조절할 수 있어요. 긴 소식을 들을 때나 음성 정보를 더 빨리 확인하고 싶을 때 유용해요.

- **1x**: 녹음을 원래 속도로 재생해요.
- **1.5x**: 따라가기 쉬운 정도로 더 빠르게 재생해요.
- **2x**: 원래 속도의 두 배로 재생해요.

오디오 플레이어의 속도 버튼을 선택하면 **1x, 1.5x, 2x** 순서로 바뀌어요.

하이퍼클래스는 연속 재생도 지원해요. 현재 오디오가 끝나면 다음 오디오나 음성 메모로 자동으로 넘어가요. 오디오가 여러 개여도 하나씩 직접 재생하지 않고 이어서 들을 수 있어요.

## 자주 묻는 질문

### 커뮤니티 게시글에서 음성 메모를 바로 녹음할 수 있나요?
네. 게시글 작성 창의 마이크 버튼으로 음성 메모를 녹음한 뒤 게시글을 게시하세요.

### 녹음을 잠시 멈췄다가 이어서 할 수 있나요?
네. 녹음하는 중에 음성 메모를 일시정지했다가, 녹음을 끝내기 전에 다시 시작할 수 있어요.

### 음성 메모를 게시하기 전에 취소할 수 있나요?
네. 녹음을 남기고 싶지 않으면 취소하고, 필요하면 다시 녹음하세요.

### 음성 메모를 녹음하는 대신 오디오 파일을 올릴 수 있나요?
네. 이미 있는 오디오 파일을 지원되는 다른 첨부파일과 함께 커뮤니티 게시글에 올릴 수 있어요.

### 게시글 하나에 음성 메모와 업로드한 오디오를 함께 넣을 수 있나요?
네. 녹음한 음성 메모와 업로드한 오디오 파일을 같은 커뮤니티 게시글에 함께 넣을 수 있어요.

### 댓글에도 음성 메모를 추가할 수 있나요?
네. 댓글 작성 창을 쓸 수 있을 때는 마이크 버튼으로 음성 메모를 녹음해 댓글로 보낼 수 있어요.

### 어떤 재생 속도를 쓸 수 있나요?
**1x, 1.5x, 2x** 재생 속도를 번갈아 선택할 수 있어요.

### 어떤 오디오는 파형으로, 어떤 오디오는 타임라인으로 표시되는 이유가 뭐예요?
작성 창에서 직접 녹음한 음성 메모는 파형으로 표시돼요. 게시글에 업로드한 기존 오디오 파일은 타임라인 형태의 오디오 플레이어로 표시돼요.
