# 커뮤니티 게시물·댓글에서 채널과 이벤트 태그하기

커뮤니티 게시물이나 댓글에 `#`을 입력해 채널과 예정된 커뮤니티 이벤트를 클릭 가능한 태그로 넣을 수 있어요. 멤버를 알맞은 곳으로 안내하거나 다가오는 이벤트를 알릴 때 쓰면 편해요.

## 채널·이벤트 태그란?

채널·이벤트 태그는 게시물이나 댓글 안에서 커뮤니티 채널과 예정된 커뮤니티 이벤트를 바로 연결해 주는 기능이에요. 링크를 복사해 붙이거나 어디로 가야 하는지 일일이 설명하지 않아도 돼요. `#`을 입력하고 채널이나 이벤트를 고르면 메시지 안에 그대로 들어가요.

태그를 추가하면 채널인지 이벤트인지 알아볼 수 있도록 각각의 아이콘과 함께 표시돼요. 멤버가 태그를 클릭하면, 접근 권한이 있을 때 해당 채널이나 이벤트로 이동해요. 이 기능은 `#` 태그로 권한을 반영한 클릭 가능한 링크를 게시물과 댓글 안에 넣어 줘요.

## 채널·이벤트 태그의 장점

태그로 대화를 알맞은 목적지와 연결하면 커뮤니티를 더 편하게 쓸 수 있어요. 관리자, 소유자, 멤버 모두 헷갈리지 않고 참여하기 쉬워지며 콘텐츠도 찾아보기 쉬워져요.

- 빠른 이동: 멤버가 채널이나 이벤트를 직접 찾지 않고 태그를 클릭해서 바로 이동할 수 있어요.
- 참여 확대: 게시물과 댓글에서 관련 토론, 다가오는 이벤트, 후속 공간으로 멤버를 안내할 수 있어요.
- 깔끔한 소통: 태그를 쓰면 URL을 붙여 넣거나 긴 안내문을 쓸 필요가 줄어요.
- 권한 반영: 태그 선택 목록에는 내가 접근할 수 있는 채널과 이벤트만 보여요.
- 더 분명한 행동 유도: 이벤트 참여나 특정 채널에서 대화 이어 가기처럼, 다음에 할 일을 모든 게시물과 댓글에서 안내할 수 있어요.

## 채널·이벤트 태그를 쓸 수 있는 곳

채널·이벤트 태그는 멤버가 콘텐츠를 작성하거나 댓글을 다는 커뮤니티 대화에서 쓸 수 있어요. 대화에서 이어서 가면 좋을 곳으로 멤버를 안내해 줘요.

다음 위치에서 쓸 수 있어요.

- 커뮤니티 게시물
- 커뮤니티 댓글
- 지원되는 커뮤니티 게시물/댓글 편집기

특정 주제 영역에서 대화를 이어 가길 원하면 채널 태그를 쓰세요. 예정된 커뮤니티 이벤트를 알리거나 이벤트 상세 페이지로 안내하고 싶으면 이벤트 태그를 쓰세요.

하이퍼클래스의 커뮤니티 콘텐츠는 게시물, 댓글, 채널, 멤버 간 상호작용을 중심으로 구성돼요. 그래서 태그를 쓰면 대화를 서로 연결하고 따라가기 쉽게 만들 수 있어요.

## 권한에 따른 태그 표시

권한 기반 태그는 비공개이거나 접근이 제한된 커뮤니티 영역을 보호해 줘요. 태그 선택 목록에는 사용자에게 접근 권한이 있는 채널과 이벤트만 나와요. 그래서 볼 수 없어야 하는 곳을 태그하는 일을 막아 줘요.

권한과 관련해 알아 둘 점이에요.

- 접근할 수 있는 채널과 이벤트만 보여요.
- 비공개 채널은 해당 채널에 접근 권한이 있어야 선택 목록에 나타나요.
- 제한된 커뮤니티 이벤트는 볼 수 있는 권한이 있어야 나타나요.
- 태그된 채널이나 이벤트를 클릭하면, 접근 권한이 있는 멤버는 해당 위치로 이동해요.
- 선택 목록에서 채널이나 이벤트가 보이지 않으면 먼저 접근 권한을 확인하세요.

하이퍼클래스 커뮤니티의 비공개 채널은 멤버 전용 토론을 위한 공간이라서, 접근 권한에 따라 채널이 보이는지가 달라져요. 커뮤니티 이벤트에도 공개 범위 설정이 있어서 알맞은 대상에게만 이벤트를 보여 줄 수 있어요.

## 채널·이벤트 태그 사용하는 방법

채널과 이벤트 태그를 잘 쓰면 멤버가 별도 안내 없이 대화에서 알맞은 커뮤니티 목적지로 바로 이동할 수 있어요. 태그하기 전에 해당 채널이나 이벤트가 이미 만들어져 있는지, 내게 접근 권한이 있는지 확인하세요.

1. 해당 커뮤니티를 여세요.
2. 새 게시물을 만들거나 댓글 편집기를 여세요.
3. 채널이나 이벤트 태그를 넣을 위치에 `#`을 입력해요.
4. 팝업으로 나타나는 채널·이벤트 목록을 확인하세요.

   ![`#` 입력 시 나타나는 채널·이벤트 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074488045/original/0e6Q-oqbD5Iz9vihUgjrA1utdq-tWPn-eQ.png?1782389045)

5. 태그할 채널이나 이벤트를 클릭하거나 키보드로 선택하세요.
6. 선택한 태그가 아이콘과 함께 게시물이나 댓글 안에 표시되는지 확인하세요.
7. 나머지 내용을 작성하세요.
8. 게시물이나 댓글을 **저장**하거나 **게시**해요.

   ![태그가 포함된 게시물을 저장하거나 게시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074488137/original/L03vPE4AEQi2S-hNzSLmZDNVZT61zQXHdg.png?1782389120)

내용을 저장하고 나면 멤버에게 태그된 채널이나 이벤트가 본문 안에 표시돼요. 멤버가 태그를 클릭하면 접근 권한이 있는 경우 하이퍼클래스가 태그된 위치로 이동시켜 줘요.

## 채널·이벤트 태그 활용 팁

의도를 갖고 태그하면 커뮤니티 콘텐츠가 어수선해지지 않고 도움이 돼요. 태그는 가장 관련 있는 곳으로 멤버를 안내하고, 대화의 목적을 뒷받침하도록 쓰세요.

권장 사용 방법이에요.

- 주제별 토론을 이어 가길 원하면 채널을 태그하세요.
- 이벤트 상세를 보거나 등록하거나 참석하길 원하면 이벤트를 태그하세요.
- 게시물이나 댓글의 주제와 관련 있는 태그만 쓰세요.
- 한 메시지에 태그를 너무 많이 넣지 마세요.
- 채널이나 이벤트를 왜 언급하는지 멤버가 알 수 있도록 앞뒤 문장을 분명하게 쓰세요.
- 멤버가 태그된 곳을 열 수 없다고 하면 접근 권한 설정을 확인하세요.

```
예시:

“오늘 세션이 끝나면 #공지사항 에서 이야기를 이어가 보세요.”

“금요일 전에 #주간 코칭 콜 에 등록해 주세요.”

“신규 멤버는 #자기소개 에서 인사를 남겨 주세요.”
```

## 자주 묻는 질문

### `#`을 입력했는데 일부 채널이나 이벤트가 보이지 않아요.
선택 목록에는 내가 접근할 수 있는 채널과 이벤트만 나와요. 항목이 보이지 않으면 비공개인지, 접근이 제한됐는지, 게시되지 않았는지, 내 사용자 역할로 볼 수 없는지 확인하세요.

### 멤버가 태그된 채널이나 이벤트를 클릭할 수 있나요?
네. 태그는 클릭할 수 있어요. 접근 권한이 있는 멤버는 게시물이나 댓글에서 태그된 채널이나 이벤트를 열 수 있어요.

### 비공개 채널도 태그할 수 있나요?
접근 권한이 있는 비공개 채널만 태그할 수 있어요. 접근 권한이 없는 사용자의 선택 목록에는 해당 비공개 채널이 나타나지 않아요.

### 특정 멤버에게만 공개된 커뮤니티 이벤트도 태그할 수 있나요?
제한된 이벤트는 볼 수 있는 권한이 있는 사용자에게만 나타날 수 있어요. 이벤트에 누가 접근할 수 있는지는 **이벤트 공개 범위** 설정에 따라 정해져요.

### `@`로 멤버를 태그하는 것과 같은 기능인가요?
아니요. 멤버를 태그하거나 언급할 때는 `@`를 쓰고, 채널, 이벤트, 지원되는 코스 태그 같은 커뮤니티 리소스를 태그할 때는 `#`을 써요. 게시물과 댓글에서 `@`로 멤버를 태그하는 방법은 별도 문서에서 안내해요.

### 태그를 추가한 뒤에 지울 수 있나요?
네. 게시물이나 댓글을 편집해서 편집기에서 태그를 지우고, 수정한 내용을 저장하세요.

### 이 문서에 편집기 버그 수정 내용도 포함되나요?
아니요. 편집기 윤곽선과 불필요한 줄바꿈 수정은 채널·이벤트 태그 사용 방법과 관련이 없어요. 이 내용은 릴리스 노트나 편집기 관련 별도 문서에서 다뤄야 해요.
