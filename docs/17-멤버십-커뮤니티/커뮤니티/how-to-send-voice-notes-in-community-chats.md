# 커뮤니티 채팅에서 음성 메시지 보내기

커뮤니티 채팅에서 글 대신 목소리를 녹음해 보낼 수 있어요. 타자로 치는 것보다 빠르고, 말투와 감정까지 전할 수 있어요.

## 이 문서에서 다루는 내용

이 문서에서는 커뮤니티 채팅의 음성 메시지가 어떤 기능인지 설명해요. 하이퍼클래스 웹 앱과 GoKollab 모바일 앱에서 음성 메시지를 녹음하고 보내는 방법, 재생 컨트롤로 듣고 원하는 구간으로 이동하는 방법도 안내해요.

마이크 권한을 허용하는 방법과, 파형으로 음성 메시지를 알아보는 방법도 함께 알아봐요.

## 커뮤니티 채팅의 음성 메시지란?

커뮤니티 채팅의 음성 메시지는 멤버가 1:1 커뮤니티 대화에서 바로 녹음해 보내는 짧은 오디오 메시지예요. 긴 답장을 쓰는 대신 채팅 입력창의 마이크 아이콘을 누르고 말하면 돼요. 녹음한 메시지는 채팅 안에서 바로 재생돼요.

하이퍼클래스 커뮤니티에서는 이미 커뮤니티 채팅과 GoKollab 채팅으로 멤버끼리 비공개 메시지, 미디어, 파일을 주고받을 수 있어요. 음성 메시지는 여기에 더해, 실시간 통화 없이도 아이디어를 이야기하거나 토론 후 후속 대화를 이어 가거나 진행 상황을 확인할 수 있게 해 줘요.

## 음성 메시지의 장점

- 긴 메시지를 쓰는 것보다 빨라요. 웹이든 모바일이든 말하는 쪽이 더 빠를 때가 많아요. 복잡한 내용을 설명하거나 맥락이 많은 소식을 전할 때 특히 그래요.
- 더 인간적이에요. 목소리에는 어조, 감정, 강조가 그대로 담겨서 글만 주고받을 때보다 멤버끼리 더 가깝게 느낄 수 있어요.
- 비동기 대화에 알맞아요. 보내는 사람은 편한 때에 말하고, 받는 사람은 시간이 날 때 들어도 실제 대화의 뉘앙스를 느낄 수 있어요.
- 채팅 안에서 바로 재생해요. 음성 메시지에는 탐색 막대와 재생/일시정지 컨트롤이 있는 오디오 플레이어가 들어 있어요. 별도의 창이나 화면을 열지 않고도 듣고, 원하는 구간으로 이동하고, 다시 들을 수 있어요.
- 대화 목록에서 쉽게 눈에 띄어요. 음성 메시지마다 파형이 표시돼서 바쁜 대화 속에서도 한눈에 찾을 수 있어요.
- 웹과 모바일에서 모두 쓸 수 있어요. 새 커뮤니티 웹 화면(Communities New UI)과 GoKollab iOS·Android 앱에서 지원해요. 책상 앞에서도, 이동 중에도 참여할 수 있어요.

## 음성 메시지 녹음하고 보내기

웹과 GoKollab 모바일 앱 모두 같은 방식으로 음성 메시지를 보낼 수 있어요. 마이크 아이콘의 위치와 녹음·전송 순서만 알면 평소 채팅하던 방식 그대로 쓸 수 있어요.

녹음하는 순서는 다음과 같아요.

1. 음성 메시지를 보낼 수 있는 커뮤니티 채팅이나 GoKollab 다이렉트 메시지를 열어요.
2. 메시지 입력창의 마이크 아이콘으로 녹음을 시작해요.
3. 실시간 파형을 보면서 메시지를 말해요.
4. 손을 떼거나 탭해서 음성 메시지를 보내요. 보낸 메시지는 대화 안에 바로 표시돼요.

### 웹 – 새 커뮤니티 화면(Communities New UI)

1. **멤버십 > 커뮤니티 > 그룹**으로 이동해요. 이어서 해당 **그룹**에서 **Login to**(그룹에 로그인)를 눌러 들어가요.

   ![멤버십 > 커뮤니티 > 그룹 화면](https://jumpshare.com/share/j8iSDADf6IXXM58tCt19+/Screenshot+2026-07-31+at+19.27.50.png)

2. **멤버**로 이동해서 메시지를 보낼 멤버 이름 옆의 **채팅** 버튼을 클릭해요.

   ![멤버 이름 옆의 채팅 버튼](https://jumpshare.com/share/elQEWB2TBYpD8o6dTpaF+/Screen+Shot+2026-07-31+at+19.32.10.png)

3. 채팅 화면 아래쪽의 메시지 입력창에서 마이크 아이콘을 길게 눌러 녹음을 시작해요. 소리가 녹음되고 있으면 움직이는 실시간 파형이 나타나요.
4. 마이크에 대고 또렷하게 말해요.
5. **보내기** 버튼을 클릭해 음성 메시지를 보내요.

   ![음성 메시지를 녹음하고 보내는 모습](https://jumpshare.com/share/RsszRj5uPPTGNg13jw0a+/GIF+Recording+2026-07-31+at+19.47.27.gif)

### GoKollab – iOS와 Android

1. GoKollab 앱을 열고 로그인해요.
2. 메시지를 보낼 커뮤니티로 이동해요.
3. 기존 채팅을 열거나, 다른 멤버에게 새 다이렉트 메시지를 시작해요.
4. 채팅 입력창에서 마이크 아이콘을 길게 눌러 녹음을 시작해요. 말하는 동안 파형이 움직이면 소리가 녹음되고 있는 거예요.

   ![마이크 아이콘을 길게 눌러 녹음하는 GoKollab 채팅 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077350987/original/wIpeuA_pixUzDRhmOT4yw_LcsLvKRkydcA.png?1785506101)

5. 마이크에서 손을 떼면 음성 메시지가 전송돼요.

   ![마이크에서 손을 떼 음성 메시지를 보내는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077351029/original/BitRaJ83tjj4q2GW0QN78X77MsONHdTBbA.png?1785506120)

{% hint style="info" %}
녹음하려면 브라우저나 기기에서 마이크 권한을 허용해야 해요. 마이크 사용 권한을 묻는 창이 뜨면 허용(Allow)을 선택하세요. 그래야 음성 메시지를 보낼 수 있어요.
{% endhint %}

## 지원 플랫폼

음성 메시지를 어디에서 쓸 수 있는지 알아 두면 팀과 커뮤니티 멤버가 기기에 상관없이 같은 방식으로 이용할 수 있어요.

커뮤니티 채팅의 음성 메시지는 다음 환경에서 쓸 수 있어요.

- 웹 – 새 커뮤니티 화면(Communities New UI): 새로워진 하이퍼클래스 웹 화면의 커뮤니티 채팅에서 음성 메시지를 쓸 수 있어요.
- GoKollab iOS 앱: iPhone에서 GoKollab 채팅의 음성 메시지를 녹음하고 들을 수 있어요.
- GoKollab Android 앱: Android 기기에서 GoKollab 채팅의 음성 메시지를 녹음하고 들을 수 있어요.

## 자주 묻는 질문

### 음성 메시지는 커뮤니티 토론에서도 쓸 수 있나요, 비공개 채팅에서만 쓸 수 있나요?

비공개 커뮤니티 채팅과 커뮤니티 게시글·댓글 모두에서 음성 메시지를 쓸 수 있어요. 커뮤니티 채팅이나 GoKollab의 1:1 대화에서는 멤버가 음성 메시지를 녹음해 보낼 수 있어요. 커뮤니티 게시글과 댓글에서는 녹음 방식이 달라요. 자세한 방법은 [커뮤니티 게시글과 댓글에서 음성 메시지 사용하기](how-to-use-voice-notes-in-community-posts-and-comments.md)를 참고하세요.

### 음성 메시지도 텍스트 메시지처럼 알림이 오나요?

네. 커뮤니티 채팅이나 GoKollab 채팅에서 음성 메시지를 보내면 새 메시지로 표시되고, 텍스트 메시지와 같은 앱 내 알림 방식이 적용돼요. 그래서 멤버가 새 소식을 놓치지 않을 수 있어요.

### 모바일에서 녹음한 음성 메시지를 데스크톱에서 들을 수 있나요? 반대도 되나요?

네. 음성 메시지는 채팅 대화와 함께 저장돼요. GoKollab 모바일 앱에서 녹음한 메시지를 나중에 새 커뮤니티 웹 화면에서 들을 수 있고, 반대로도 가능해요. 단, 계정이 해당 대화에 접근할 수 있어야 해요.

### 음성 메시지가 자동으로 텍스트로 변환되나요? 음성 AI와도 연결되나요?

아니요. 커뮤니티 채팅의 음성 메시지는 사람끼리 주고받는 단순한 오디오 메시지예요. 하이퍼클래스에는 WhatsApp 음성 메시지 전사나 음성 AI 같은 다른 음성·전사 기능이 있지만, 커뮤니티 채팅의 음성 메시지와는 별개의 기능이에요.
