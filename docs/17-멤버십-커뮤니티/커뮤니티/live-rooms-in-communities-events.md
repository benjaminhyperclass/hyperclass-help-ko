# 커뮤니티 이벤트에서 Live Room 사용하기

커뮤니티 이벤트를 만들 때 **Live Room**(라이브룸)을 위치로 고르면, 하이퍼클래스 안에서 바로 실시간 세션을 진행할 수 있어요. 관리자와 소유자는 Live Room 대신 Zoom, Google Meet 또는 직접 만든 미팅 링크도 계속 쓸 수 있어요. 이 문서에서는 Live Room의 작동 방식, 위치 유형별 사용 시점, 워크숍·Q&A·코칭 콜·론칭 이벤트를 준비하는 방법을 안내해요.

## 커뮤니티 이벤트의 Live Room이란?

Live Room은 하이퍼클래스 커뮤니티 안에서 실시간 세션을 바로 진행할 수 있는 이벤트 위치 옵션이에요. 외부 미팅 링크를 따로 넣지 않고, 이벤트를 만들 때 **Live Room**을 선택하면 멤버가 이벤트 페이지에서 바로 입장할 수 있어요.

Live Room은 **Go Live**(실시간 방송) 기능을 바탕으로 해요. 영상, 음성, 채팅, 리액션, 화면 공유, 호스트 제어를 지원하는 양방향 세션을 열 수 있어요. 커뮤니티 이벤트에는 이미 이벤트 정보, 등록, 캘린더 추가, 공개 범위, 가격, 알림이 한곳에 모여 있어요. Live Room은 이 이벤트 흐름에 하이퍼클래스 자체 미팅 옵션을 더해 줘요.

{% hint style="info" %}
예약된 커뮤니티 이벤트 없이 바로 실시간 방송을 시작하고 싶다면 [커뮤니티 - Go Live로 미팅·방송 진행하기](communities-use-go-live-to-host-meetings-broadcasts.md) 문서를 참고하세요.
{% endhint %}

## Live Room 사용 시 좋은 점

- 별도 도구 없이 진행: 멤버가 다른 미팅 도구를 설치하지 않아도 커뮤니티 안에서 바로 실시간 세션을 열 수 있어요.
- 다양한 미팅 옵션: 이벤트 운영 방식에 따라 Live Room, Zoom, Google Meet, 직접 만든 링크 중에서 고를 수 있어요.
- 간단한 참석 과정: 멤버가 이벤트 페이지 한 곳에서 상세 정보를 확인하고, 등록하고, 캘린더에 추가하고, 입장할 수 있어요.
- 기본 제공 참여 기능: 채팅, 리액션, 손 들기, 화면 공유, 호스트 제어 같은 Go Live 기능으로 세션 중 멤버의 참여를 이끌 수 있어요.
- 커뮤니티 알림: 커뮤니티 이벤트 알림 이메일과 캘린더 옵션으로 멤버가 예정된 세션을 잊지 않도록 도울 수 있어요.
- 웹과 모바일 지원: 멤버는 웹과 모바일에서 커뮤니티 이벤트를 찾고 등록할 수 있어요. 로그인한 상태라면 지원되는 브라우저나 하이퍼클래스 모바일 앱에서 Live Room 이벤트에 입장할 수 있어요.

## Live Room 화면 구성

Live Room은 호스트와 멤버가 함께 쓰는 양방향 미팅 공간이에요. 라이브 대화, 이벤트 정보, 이후 활동이 멤버들이 이미 활동하는 커뮤니티 가까이에 있어서 흐름이 끊기지 않아요.

Live Room은 Go Live 미팅 환경을 쓰고, 다음 기능을 포함해요.

- 영상·음성 참여
- 발표자 보기, 갤러리 보기 같은 레이아웃
- 화면 공유
- 실시간 채팅
- 이모지 리액션
- 손 들기
- 호스트와 참석자 역할
- 참가자 접근과 세션 제어를 관리하는 호스트 권한

## 참석자의 등록·입장 과정

참석 과정이 분명하면 이벤트가 시작되기 전에 멤버가 헷갈리지 않아요. 멤버는 같은 커뮤니티 화면에서 예정된 이벤트를 찾고, 등록하고, 캘린더에 추가하고, 알림을 받고, 입장할 수 있어요.

멤버는 다음을 할 수 있어요.

- 그룹의 **이벤트** 탭에서 이벤트를 찾아요.
- 참석하고 싶은 이벤트에 등록해요.
- 이벤트를 Google Calendar나 iCal에 추가해요.
- 예정된 이벤트에 대한 앱 내 알림과 이메일 알림을 받아요.
- 이벤트 페이지에서 Live Room 이벤트에 바로 입장해요.
- Zoom, Meet, Other 이벤트는 설정된 외부 링크를 열어 입장해요.

## 커뮤니티 이벤트에 Live Room 설정하기

설정을 제대로 해 두면 멤버가 이벤트를 쉽게 이해하고, 등록하고, 세션이 시작될 때 알맞은 위치에서 입장할 수 있어요. Live Room도 기존 커뮤니티 이벤트 만들기 과정과 같고, 외부 미팅 플랫폼이 필요한 이벤트에는 Zoom, Google Meet, 직접 만든 링크를 그대로 쓸 수 있어요.

1. **멤버십 > 커뮤니티 > 그룹**으로 이동해요. 이벤트를 만들 그룹에서 **로그인**을 클릭해요.

   ![그룹에서 로그인 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070745686/original/eAGqDqmw9shMdUEzB1Mc8H0jbJxLD8irtA.png?1778097689)
2. **이벤트** 탭을 열고 **Create Event**(이벤트 만들기)를 클릭해요.

   ![이벤트 탭에서 이벤트 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070746126/original/eoBjJlfKUAehD7biTbae-KA2aOffNUI1og.png?1778098302)
3. 이벤트 제목, 설명, 날짜, 시간, 진행 시간, 시간대를 입력해요.
   필요하면 이벤트 이미지나 배너를 추가해요.
   **위치 유형** 필드에서 **Live Room**을 선택하면 하이퍼클래스 커뮤니티 안에서 바로 이벤트를 진행할 수 있어요.

   ![위치 유형에서 Live Room 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070746155/original/d1irQNlJdDVdIG9gpHtQ9MoYipYrBgGujQ.png?1778098361)
4. 이벤트를 볼 수 있거나 참석할 수 있는 대상을 정해요. 사용할 수 있는 경우에는 코스, 그룹, 비공개 채널, 멤버십 등급별 제한도 설정해요. 설정을 마치면 **다음**을 클릭해요.

   ![이벤트 공개 대상 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070746186/original/fa5kLf1vdn7iNX2TnY88ahgXwbYGhyw6tA.png?1778098462)
5. 이벤트가 무료인지 유료인지 선택해요. 유료 이벤트라면 가격과 통화를 입력해요. 그다음 **Create Event**를 클릭해요.

   ![무료·유료 선택 후 이벤트 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070746298/original/ZWBWCQZ87C2GOt5mv4iT7DZAWU8jeFcnBg.png?1778098610)
6. 커뮤니티 게시글, 공지, 이메일, SMS 등 원하는 소통 채널로 멤버에게 이벤트를 알려요.
7. 예정된 시간이 되면 **이벤트** 탭에서 이벤트를 열고 **Live Room**을 클릭해요.

   ![이벤트에서 Live Room 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070746398/original/SKQ4zO26VyffSLOsVT1AA4SLsFzdqa71sQ.png?1778098815)

## 자주 묻는 질문

### Live Room 이벤트에 입장하려면 참석자가 따로 설치해야 하는 게 있나요?
아니요. 멤버가 로그인한 상태라면 지원되는 브라우저나 하이퍼클래스 모바일 앱에서 바로 입장할 수 있어요.

### 커뮤니티 이벤트에서 Zoom이나 Google Meet도 계속 쓸 수 있나요?
네. Live Room은 추가된 위치 옵션이에요. **Zoom**, **Meet**, **Other**를 선택하고 외부 미팅 링크를 넣는 방법도 그대로 쓸 수 있어요.

### Live Room을 쓰는 커뮤니티 이벤트를 유료로 운영할 수 있나요?
네. 커뮤니티 이벤트는 무료 또는 유료로 만들 수 있고, 가격은 이벤트를 만들 때 설정해요.

### Live Room 이벤트에 참석할 수 있는 사람을 제한할 수 있나요?
네. 사용할 수 있는 경우에는 코스, 그룹, 비공개 채널, 멤버십 등급 같은 옵션으로 커뮤니티 이벤트 참석 대상을 제한할 수 있어요.

### Live Room이 커뮤니티의 Go Live 게시를 대체하나요?
아니요. Live Room은 예약된 이벤트에서 하이퍼클래스 자체 라이브 환경을 쓸 수 있게 해 주는 방식이에요. 예약된 커뮤니티 이벤트 없이 미팅이나 방송을 할 때는 커뮤니티에서 Go Live를 그대로 쓸 수 있어요.
