# 커뮤니티에서 그룹을 비공개로 만들기

비공개 그룹은 승인받은 멤버만 들어올 수 있는 커뮤니티예요. 소유자와 관리자가 그룹을 만들고 관리하며, 역할을 정하고 참여 요청을 승인해요. 외부에 공개하지 않을 모임이나 민감한 프로젝트에 쓰기 좋아요.

{% hint style="info" %}
아래 표는 비공개 그룹에서 역할별로 할 수 있는 일을 정리한 거예요.
{% endhint %}

## 비공개·공개 그룹 전환이란?

비공개 그룹은 접근을 제한하고 대화 내용을 보호하기 위한 커뮤니티예요. 초대받았거나 승인받은 멤버만 그룹의 콘텐츠와 대화를 볼 수 있어요.

소유자와 관리자는 일반(공개) 그룹을 비공개 그룹으로 바꿀 수 있어요. 그룹 안에는 소유자(Owner), 관리자(Admin), 참여자(Contributor) 역할이 있고, 역할마다 맡는 책임과 권한이 달라요.

| 역할 | 접근 수준과 책임 |
| --- | --- |
| 소유자(Owner) | 그룹을 만든 사람이에요. 사용자를 관리자나 참여자로 지정하고, 그룹을 공개·비공개로 바꾸고, 멤버십 요청을 검토해 수락할 수 있어요. 소유자 역할은 다른 사용자에게 지정할 수 없어요. |
| 관리자(Admin) | 사용자를 관리자나 참여자로 지정하고, 그룹을 공개·비공개로 바꾸고, 멤버십 요청을 검토해 수락할 수 있어요. 참여자와 다른 관리자의 역할도 바꿀 수 있어요. |
| 참여자(Contributor) | 그룹에서 토론에 참여해요. 그룹 설정이나 멤버십을 관리할 권한은 없어요. |

비공개 그룹에 들어오려면 멤버가 참여를 요청하고, 관리자나 소유자가 승인해야 해요. 그래서 실제로 관심 있고 승인받은 사람만 그룹 활동에 참여할 수 있어요. 요청이 수락되면 멤버에게 매직 링크가 담긴 확인 이메일이 가요. 이 링크로 바로 접속할 수 있어요.

비공개 그룹은 공개 그룹으로, 공개 그룹은 비공개 그룹으로 바꿀 수 있어요. 그룹 목적에 맞게 콘텐츠 공개 범위를 조절할 수 있어요. 회사 내부 소통, 멤버 전용 커뮤니티, 집중 협업 등 어떤 용도로든 안전하고 체계적인 공간이 돼요.

소유자와 관리자는 간단한 화면에서 그룹 유형을 바꾸고, 브랜딩을 꾸미고, 그룹 멤버가 아닌 사람에게 보이는 범위를 조절할 수 있어요.

## 그룹을 비공개·공개로 바꾸면 좋은 점

| 장점 | 설명 |
| --- | --- |
| 접근 제어 | 승인받은 멤버만 토론을 보고 참여할 수 있어서 민감한 정보와 개인정보를 지킬 수 있어요. |
| 협업 강화 | 특정 프로젝트나 주제에 집중하는 환경이 만들어져서, 관련 없는 멤버나 콘텐츠에 방해받지 않고 협업할 수 있어요. |
| 체계적인 커뮤니티 운영 | 소유자, 관리자, 참여자 역할이 분명해서 소유자와 관리자가 멤버십과 역할을 효율적으로 관리할 수 있어요. |
| 브랜딩과 모양 설정 | 브랜딩, 색상, 이미지 등을 꾸밀 수 있어서 그룹을 원하는 테마나 조직 브랜드에 맞출 수 있어요. |
| 편리한 멤버십 관리 | 관리자와 소유자가 멤버십 요청을 쉽게 검토하고 승인하며, 그룹 안의 역할과 접근 권한도 조정할 수 있어요. |
| 자유로운 전환 | 그룹을 공개에서 비공개로(또는 반대로) 바꿀 수 있어서 그룹 상황에 맞게 접근과 공개 범위를 조절할 수 있어요. |
| 안전한 소통 | 승인받은 사람만 들어올 수 있어서 기밀 대화와 정보 공유를 안전하게 할 수 있어요. |

## 활용 사례

| 사례 | 설명 |
| --- | --- |
| 기밀 대화 | 멤버끼리 안전하게 대화할 수 있고, 권한이 있는 사람만 공유된 콘텐츠를 볼 수 있어요. |
| 집중 협업 | 외부 방해를 줄여야 하는 프로젝트, 주제, 업무에서 팀원끼리 협업하기에 알맞아요. |
| 멤버십 요청과 승인 | 참여를 원하는 멤버가 요청을 보내고, 관리자나 소유자만 요청을 검토해 수락해요. 그래서 입장을 직접 관리할 수 있어요. |
| 공개 그룹 ↔ 비공개 그룹 전환 | 공개 그룹을 비공개로 바꾸면 이후 콘텐츠는 현재 멤버에게만 공개돼요. 반대로 비공개 그룹을 공개로 바꾸면 모든 요청이 자동으로 수락돼요.|
| 역할별 관리 | 소유자, 관리자, 참여자 역할로 멤버별 권한과 책임을 나눠서 커뮤니티를 체계적으로 운영할 수 있어요. |

## 그룹을 비공개로 만드는 방법

그룹을 만드는 것부터 멤버를 관리하는 것까지 순서대로 안내해요.

### 1단계: 그룹 만들기와 관리

1. 그룹 만들기: **멤버십** 메뉴에서 **커뮤니티** 탭으로 이동한 뒤 **+ 그룹 생성**을 클릭해요.
2. 그룹 이름을 입력하고 모양을 꾸민 다음 **그룹 생성**을 클릭해요.

   ![그룹 생성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053402439/original/aIxYu2LiQ94lu1VSVb0a92Kd21v9s2ccYw.png?1757430461)

### 2단계: 비공개로 전환하기

{% hint style="info" %}
비공개에서 공개로 바꾸면 대기 중인 모든 요청이 자동으로 승인돼요.

공개에서 비공개로 바꾸면 이전 콘텐츠는 현재 멤버에게만 공개돼요.
{% endhint %}

관리자와 소유자는 그룹 설정을 바꿔서 그룹을 비공개로 만들 수 있어요. 기밀 대화가 필요한 그룹에 알맞아요.

1. **Group area**(그룹 영역)에서 **설정**을 클릭해요.

   ![그룹 영역의 설정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058875498/original/aJMoRgtOTXMFpseBcA73hh6tdsvzV2qREg.jpeg?1763654129)
2. **상세 정보**에서 **비공개**로 바꾼 뒤 **저장**을 클릭해요.

   ![상세 정보에서 비공개로 전환](https://jumpshare.com/share/fFedkIHU3JHrvpiXkHaR+/Screen+Shot+2025-11-20+at+9.27.10+PM.png)

## 멤버십 관리

- 참여 요청: 참여하려는 멤버가 그룹 URL로 들어가 참여를 요청해요. 요청하면 요청 버튼이 **Membership Pending**(멤버십 대기 중)으로 바뀌어요.

  ![멤버십 대기 중 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053401019/original/nMBx024qfFjuQfbyq5GNCG05JFlNDMuuMw.png?1757429703)
- 요청 검토와 승인: 관리자와 소유자는 **멤버** 섹션의 **Requested**(요청됨) 탭에서 요청을 검토하고 수락하거나 거절할 수 있어요.

  ![멤버 섹션의 요청됨 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053402127/original/_CactdE-uoiOOFP6RTjczKYOr0oezRkauA.png?1757430258)
- 역할 조정: 소유자와 관리자는 멤버에게 **Admin**(관리자) 또는 **Contributor**(참여자) 역할을 지정할 수 있어요. 소유자 역할은 다시 지정할 수 없어요.

  ![멤버 역할 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053402182/original/0nUkcMyEt9LOv9IuCG9-FNynR6Y5ngOBJA.png?1757430299)

## 그룹 공개 범위

- 접근 제어: 역할을 조정해서 누가 그룹을 보고 참여할 수 있는지 관리해요.
- 그룹 멤버가 아닌 사람의 접근: **Accessible from switcher**(전환기에서 접근 가능)를 선택하면 멤버가 아닌 사람에게도 그룹이 보이게 할 수 있어요. 이 설정은 이 그룹의 멤버는 아니지만 서브 계정의 다른 그룹에는 접근할 수 있는 사람에게, 왼쪽 위 그룹 전환기에 이 그룹이 보일지 정해요.

  ![전환기에서 접근 가능 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053400165/original/apSXMKBLUE4awI-EAizEL7BCkUsErRf5eQ.png?1757429349)

## 자주 묻는 질문

### 비공개 그룹은 누가 만들고 관리할 수 있나요?

소유자와 관리자가 그룹을 만들고 관리할 수 있어요. 그룹을 공개·비공개로 바꾸는 것도 소유자와 관리자가 할 수 있어요.

### 비공개 그룹에는 어떻게 참여하나요?

그룹 URL로 들어가 **Request to join**(참여 요청)을 클릭하면 돼요. 그러면 버튼이 **Membership Pending**(멤버십 대기 중)으로 바뀌어요.

### 멤버십 요청은 누가 승인하나요?

소유자와 관리자가 **멤버 > Requested**(요청됨)에서 승인해요.

### 참여자는 무엇을 할 수 있나요?

토론에 참여할 수 있어요. 설정이나 멤버십은 관리할 수 없어요.

### 그룹에 브랜딩을 적용할 수 있나요?

네, 그룹 설정에서 색상, 이미지, 브랜딩을 꾸밀 수 있어요.

### 비공개 그룹은 언제 쓰면 좋나요?

기밀 대화, 집중해서 해야 하는 프로젝트 협업, 요청과 승인으로 멤버를 관리하는 모임, 공개·비공개 전환, 역할별 체계적인 관리가 필요할 때 쓰면 좋아요.
