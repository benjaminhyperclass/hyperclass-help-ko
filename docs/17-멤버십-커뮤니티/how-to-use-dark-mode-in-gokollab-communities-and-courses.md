# GoKollab 커뮤니티와 코스에서 다크 모드 사용하기

다크 모드를 켜면 GoKollab의 커뮤니티, 코스 등 지원되는 화면이 어두운 색으로 바뀌어요. 멤버는 상단 내비게이션에서 화면 스타일을 바꿀 수 있고, 커뮤니티 운영자는 라이트 모드와 다크 모드의 브랜드 색상을 따로 정할 수 있어요. 선택한 화면 스타일은 새로고침해도, 그리고 지원되는 대부분의 화면을 이동해도 유지돼요.

## GoKollab 다크 모드란?

GoKollab 다크 모드는 지원되는 화면을 어두운 색 구성으로 바꿔 주는 웹 화면 스타일 옵션이에요. 텍스트, 컨트롤, 커뮤니티 브랜딩은 읽기 쉽게 유지돼요. 멤버는 자신에게 맞는 화면 스타일을 고르고, 커뮤니티 운영자는 라이트 모드와 다크 모드에서 브랜드가 어떻게 보일지 따로 설정해요. 색을 자동으로 반전하는 방식이 아니라서, 보는 취향이 다른 멤버들을 모두 지원할 수 있어요.

## 다크 모드의 장점

- 한 번에 화면 스타일 전환: 멤버는 GoKollab 상단 내비게이션에서 바로 라이트 모드와 다크 모드를 오갈 수 있어요.
- 모드별 브랜드 색상: 커뮤니티 운영자가 라이트 팔레트와 다크 팔레트를 따로 설정해요. 한쪽을 바꿔도 다른 쪽은 그대로예요.
- 더 편안한 화면: 오래 보거나 어두운 곳에서 볼 때 어두운 화면이 더 편할 수 있어요.
- 넓은 적용 범위: 커뮤니티, 코스, 탐색, 온보딩, 계정 화면 등 지원되는 영역에 적용돼요.
- 선택 유지: 멤버가 고른 화면 스타일은 새로고침 후에도, 지원되는 대부분의 화면 이동 중에도 자동으로 다시 적용돼요.
- 기존 커뮤니티 호환: 기존 커뮤니티는 다크 모드를 새로 설정하지 않아도 그대로 작동해요.

## 다크 모드를 쓸 수 있는 곳

다크 모드는 GoKollab 웹에서 지원되는 영역 전반에서 쓸 수 있어요. 커뮤니티, 코스, 계정 화면, 탐색, 온보딩 등 멤버가 보는 화면이 포함돼요. 배경, 텍스트, 폼, 메뉴, 탭, 컨트롤 같은 요소가 선택한 화면 스타일에 맞게 자동으로 바뀌어요.

선택한 화면 스타일은 코스 내비게이션, 강의, 평가, 과제, 퀴즈, 라이브 세션 화면 같은 학습 영역에도 적용돼요. 코스용 화면 스타일을 따로 설정할 필요는 없어요. 코스에 대한 자세한 내용은 [Learning Tab (Courses)](커뮤니티/learning-tab-courses.md) 문서를 참고하세요.

다크 모드는 웹에서 쓰는 GoKollab에서만 지원돼요. [GoKollab Studio](manage-your-communities-and-courses-with-gokollab-studio.md) 등 일부 영역에서는 화면을 이동할 때 화면 스타일 선택이 유지되지 않을 수 있어요.

## 다크 모드 설정하기

멤버는 자신이 보는 화면 스타일만 바꾸면 돼요. 커뮤니티 운영자는 각 모드를 선택했을 때 커뮤니티가 어떻게 보일지 따로 설정할 수 있어요.

### 멤버

1. 웹에서 GoKollab 또는 커뮤니티를 열어요.
2. 상단 내비게이션에서 **appearance switcher**(화면 스타일 전환 버튼)를 찾아요.
3. **다크**를 선택해요.
4. GoKollab을 평소처럼 사용하세요. 선택한 화면 스타일은 새로고침해도, 지원되는 대부분의 화면에서도 유지돼요.
5. 라이트 모드로 돌아가고 싶으면 전환 버튼에서 **라이트**를 선택하세요.

![상단 내비게이션의 화면 스타일 전환 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081340041/original/i6vc3JJkdcSKA29SbZlgnqJJ8OVtX1KhNQ.png?1789762009)

### 커뮤니티 운영자

커뮤니티 설정 방법은 [How to Setup, Customize, and Manage Your Communities](how-to-setup-customize-and-manage-your-communities.md) 문서에서도 볼 수 있어요.

1. 설정하려는 커뮤니티를 열어요.

   ![커뮤니티 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081340395/original/8X27qVzii3X-sX9UzZOF5IN39y8OW-oKZw.png?1789762315)
2. **설정 > 화면 스타일**을 선택해요.
3. **Color Mode**(색상 모드) 아래에서 설정하려는 팔레트에 맞게 **라이트** 또는 **다크**를 선택해요.
4. 커뮤니티 테마를 고르거나, 제공되는 사용자 지정 컨트롤로 직접 꾸며요. 테마를 바꾸는 방법은 [Communities - Change your group theme](커뮤니티/communities-change-your-group-theme.md) 문서를 참고하세요.

   ![커뮤니티 테마 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081340460/original/ShkGSnQ3TA2uES3JZJuSjN9S-TOIjFrM5A.png?1789762424)
5. **미리보기**에서 선택한 화면 스타일이 어떻게 보이는지 확인해요.

   ![미리보기로 화면 스타일 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081340482/original/8HNDS_oSoEWXQrwboEgGUMVD0GpUZ4Ds8g.png?1789762460)
6. 라이트 모드와 다크 모드의 브랜딩을 따로 만들려면 다른 색상 모드에서도 같은 과정을 반복해요.
7. **변경사항 저장**을 클릭해요.

다크 팔레트를 바꿔도 라이트 팔레트는 바뀌지 않고, 라이트 팔레트를 바꿔도 다크 팔레트는 바뀌지 않아요.

## 자주 묻는 질문

### 제가 다크 모드로 바꾸면 커뮤니티 멤버 모두의 화면이 바뀌나요?
아니요. 멤버는 각자 자신이 보는 화면 스타일을 선택해요. 커뮤니티 운영자는 멤버가 각 모드를 사용할 때 커뮤니티 브랜딩이 어떻게 보일지만 설정해요.

### 커뮤니티 운영자가 모든 멤버에게 다크 모드를 쓰게 할 수 있나요?
아니요. 화면 스타일 전환 버튼은 멤버가 직접 고르는 설정이라서, 멤버마다 원하는 화면 스타일을 선택할 수 있어요.

### GoKollab 모바일에서도 다크 모드를 쓸 수 있나요?
다크 모드는 현재 웹에서 쓰는 GoKollab에서만 지원돼요. 모바일에서 같은 화면 스타일 설정은 아직 지원되지 않아요.

### 다크 모드를 켜면 업로드한 이미지나 동영상 색도 자동으로 바뀌나요?
다크 모드는 배경, 텍스트, 테두리, 폼, 메뉴, 탭, 컨트롤 같은 지원되는 화면 요소를 조정해요. 업로드한 이미지와 동영상은 원래 모습 그대로 유지돼요.

### Studio에서 이동하면 화면 스타일이 바뀔 때가 있어요. 왜 그런가요?
아직 모든 화면에서 선택한 화면 스타일이 유지되는 것은 아니에요. Studio는 이동 중에 선택한 모드가 계속 적용되지 않을 수 있는 영역으로 알려져 있어요. Studio에 대해서는 [Manage Your Communities and Courses with GoKollab Studio](manage-your-communities-and-courses-with-gokollab-studio.md) 문서를 참고하세요.

### 다크 모드에서만 커뮤니티가 이상하게 보여요. 무엇을 확인해야 하나요?
커뮤니티에 사용자 지정 CSS를 쓰고 있다면, 라이트 모드나 다크 모드에만 영향을 주는 스타일이 있는지 확인해 보세요. 그런 다음 두 화면 스타일에서 모두 커뮤니티를 테스트해 보세요. CSS 추가 방법은 [Communities - How to Add Custom CSS/JS to Groups](커뮤니티/communities-how-to-add-custom-css-js-to-groups.md) 문서를 참고하세요.
