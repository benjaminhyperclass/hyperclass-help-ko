# GoKollab에서 Stripe 연동하기

GoKollab 그룹 소유자는 Stripe 계정을 연동해 결제를 받을 수 있어요. 연동하면 GoKollab 안에서 유료 그룹을 만들고 관리할 수 있어요. 이 문서에서는 결제 연동 페이지로 들어가는 두 가지 방법을 안내해요.

## 결제 연동 페이지로 들어가는 방법

결제 연동 페이지는 두 가지 방법으로 열 수 있어요.

### 1. 프로필에서 열기

1. 프로필 사진을 클릭하세요.
2. 프로필 카드 아래에 있는 **결제** 아이콘을 클릭하세요.
3. 결제 연동 페이지가 열리면서 보안 코드를 입력하라는 안내가 나와요.

![프로필 카드 아래의 결제 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042132317/original/2m8SF4JFefooUcByfP3gx7BdTrD04mTD7w.png?1740404315)

![보안 코드 입력을 안내하는 결제 연동 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042132346/original/qzcg4T1sxhJdN1jdmAqcoqtsF8Y46gDf9g.png?1740404325)

### 2. 그룹 설정에서 열기

1. **그룹 설정**으로 이동하세요.
2. **구독** 탭을 클릭하세요.
3. 결제 연동 항목을 찾아 선택하세요.

결제 연동에 대한 더 자세한 내용은 [Stripe 서브 계정 연동 문서](../42-통합/Stripe-Integration/how-to-connect-stripe-to-your-sub-account.md)를 참고하세요.
