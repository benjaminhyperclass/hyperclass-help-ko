# 멤버십 코스 결제 오케스트레이터(Checkout Orchestrator)

결제 오케스트레이터는 멤버십 코스의 결제 과정을 새로 만든 결제 엔진이에요. 중복 주문을 막고 대기 시간을 줄이며, 모든 구매 과정을 실시간으로 확인할 수 있어요. 결제가 빨리 끝나서 수강생도 바로 콘텐츠를 이용할 수 있어요.

## 결제 오케스트레이터란?

결제 오케스트레이터는 멤버십 코스용으로 하이퍼클래스가 새로 만든 결제 처리 방식이에요. 화면 뒤에서 결제, 접근 권한 부여, 알림 단계를 순차 처리와 병렬 처리를 섞은 방식으로 조율해요. 그래서 구매 과정이 훨씬 빠르고 투명해지고, 중간에 오류가 나도 이어서 처리돼요.

## 주요 장점

고객이 **결제** 버튼을 누르는 순간부터 다음 효과를 볼 수 있어요.

- 평균 결제 시간이 약 70% 빨라져요. 기존 8~12초에서 **3~4초**로 줄어요.
- **자동 중복 방지** 덕분에 대규모 상황에서도 성공률 100%를 유지해요.
- **자동 재시도**(최대 5회)가 실패한 지점부터 정확히 이어서 처리해요.
- 단계별 실시간 추적 기록으로 **문제를 바로 확인하고 지원할 수 있어요.**
- 기존과 완전히 호환돼요. **기존 오퍼나 퍼널을 수정할 필요가 없어요.**

## 결제 오케스트레이터 확인하기

멤버십 오퍼 결제를 쓰는 모든 서브 계정에 이 업그레이드가 자동으로 적용돼요. 아래 순서대로 따라 하면 잘 작동하는지 확인할 수 있어요.

1. **사이트 > 멤버십 > 오퍼**로 이동해 기존 오퍼를 선택하세요.
2. **Checkout**(결제)을 클릭하고 **결제 미리보기**를 클릭하세요.
3. $0 테스트 주문을 넣고 3~4초 만에 처리되는지 확인하세요.
4. **사이트 > 멤버십 > Checkouts**(결제 내역) > **Activity Log**(활동 로그)를 여세요.
5. 각 단계에 **성공**이 표시되는지 확인하세요.
6. (선택) **Activity Log**에서 **Developer Mode**(개발자 모드)를 켜면 페이로드와 오류 재시도 내역을 볼 수 있어요.
7. 출시 당일처럼 접속이 몰리는 시간대에 테스트를 한 번 더 해 보세요. 자동 확장이 작동하는 모습을 볼 수 있어요.

```
별도 설정은 필요 없어요. 퍼널, 폼, 스마트 리스트, 클라이언트 포탈은 이전과 똑같이 작동해요.
```

## 자주 묻는 질문

### 기존 멤버십 오퍼나 결제 페이지를 업데이트해야 하나요?
아니요. 결제 오케스트레이터는 기존 방식과 호환돼요. 현재 쓰는 페이지에 새 방식이 자동으로 적용돼요.

### 결제 오류 로그는 어디에서 볼 수 있나요?
**사이트 > 멤버십 > Checkouts > Activity Log**로 이동하세요. 실패한 단계를 클릭하면 오류 내용을 자세히 볼 수 있어요.

### 재시도는 몇 번까지 하나요?
지수 백오프 방식으로 최대 5번까지 자동 재시도해요.

### 재시도가 일어나면 고객에게 두 번 결제될 수 있나요?
아니요. 중복 방지 토큰이 있어서 연락처는 주문 한 건당 한 번만 결제돼요.

### 멤버십의 원클릭 업셀에도 영향을 주나요?
**원클릭 업셀**은 그대로 작동해요. 이제 더 빨라진 처리 속도도 함께 적용돼요.
