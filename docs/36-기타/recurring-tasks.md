# 반복 작업 설정하기

반복 작업을 쓰면 정해 둔 간격마다 작업이 자동으로 만들어져요. 같은 작업을 매번 새로 만들 필요가 없고, 반복 주기와 종료 시점을 설정해 계속되는 작업을 쉽게 관리할 수 있어요.

### 

## 개요

반복 작업은 정해진 간격마다 자동으로 반복해서 만들어지는 작업이에요. 반복 주기와 종료일을 설정하고, 이어지는 작업을 한곳에서 관리할 수 있어요.

## 기능 설명

- **빈도 설정**: 작업을 얼마나 자주 반복할지 정해요.
  - 시간, 일, 주, 월, 연 단위 중에서 업무 흐름에 맞는 간격을 고르세요.
- 종료 시점: 반복을 언제 끝낼지 정해요.
  - **없음**: 작업이 계속 반복돼요.
  - **사용자 지정 날짜**: 반복 작업의 종료일을 직접 정해요.
  - **After a set number of occurrences**(지정한 횟수 이후): 작업이 반복될 횟수를 정해요.
- **Create Even if Previous Task is Overdue**(이전 작업이 기한을 넘겨도 새 작업 만들기): 이 옵션을 켜면 이전 작업이 끝나지 않았거나 기한이 지났더라도 일정에 맞춰 다음 작업이 만들어져요.
- 작업 만들기와 변경
  - 새 작업 만들기: 새 반복 작업을 설정해요.
  - 기존 작업을 반복 작업으로 바꾸기: 이미 있는 작업이 정해진 간격으로 반복되도록 바꿔요.
- **반복 작업 수정**: 앞으로 만들어질 모든 반복 작업에 변경 내용을 적용하거나, 한 건에만 적용할 수 있어요. 필요에 맞게 고르세요.
- 반복 작업 삭제: 시리즈에서 앞으로 만들어질 작업을 모두 삭제하거나, 특정 회차 하나만 삭제할 수 있어요.
- 삭제한 작업 복원: 실수로 삭제한 작업을 복원해서 이전에 지운 회차를 되살릴 수 있어요.

{% hint style="info" %}
삭제한 작업을 복원해도, 삭제되어 있던 기간에 해당하는 반복 작업은 다시 만들어지지 않아요.
{% endhint %}

## 사용 방법

1. **새 작업 추가** 창을 여세요. **작업**, **연락처**, **회사** 페이지에서 열 수 있어요.
2. 작업 이름, 설명 등 필요한 정보를 입력하세요.
3. 반복을 설정하세요.
   - **반복 작업** 토글을 켜세요.
   - **Repeats Every**(반복 간격) 필드에 반복 간격을 입력하세요. 예를 들면 1일마다, 2주마다처럼 입력해요.
   - **Ends On**(종료 조건)에서 종료 시점을 고르세요.
     - **없음**
     - **사용자 지정 날짜**
     - **After a set number of occurrences**(지정한 횟수 이후)
   - 필요하면 **Create a new task even if the previous one is overdue**(이전 작업이 기한을 넘겨도 새 작업 만들기)를 체크하세요. 작업이 일정대로 만들어져요.

   {% hint style="info" %}
   다음 작업은 이전 작업을 닫은 직후에 바로 만들어지지 않아요. 작업을 만든 날짜를 기준으로 정해진 시간에 만들어져요.
   {% endhint %}
4. **작업 할당**에서 **담당자**와 **연락처**(해당하는 경우)를 선택하세요.
5. **저장**을 클릭하면 작업이 만들어지고 반복 일정이 시작돼요.
