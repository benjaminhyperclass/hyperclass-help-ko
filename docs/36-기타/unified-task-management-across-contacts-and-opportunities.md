# 연락처와 기회 관리에서 쓰는 통합 작업 관리

하이퍼클래스의 통합 작업 관리는 **연락처**(Contacts)와 **기회 관리**(Opportunities)에서 같은 화면으로 작업을 만들고, 편집하고, 관리하는 기능이에요. 이 문서에서는 작업을 만들고 관리하는 방법을 순서대로 안내해요.

## 통합 작업 관리란?

통합 작업 관리를 쓰면 **연락처**와 **기회 관리**에서 같은 화면으로 작업을 만들고 관리할 수 있어요. 화면이 깔끔하고 필터와 고급 작업 옵션도 있어서, 플랫폼 어디에서 일하든 할 일을 쉽게 챙길 수 있어요.

- **연락처**: 연락처 상세 화면에서 작업 패널을 열어, 그 연락처와 연결된 작업을 만들고 확인하고 관리할 수 있어요.
- **기회 관리**: 기회를 클릭하면 비슷한 작업 패널이 열려요. 그 딜이나 파이프라인 단계에 연결된 작업을 같은 화면으로 관리할 수 있어요.

## 통합 작업 관리의 장점

- 모든 화면에서 같은 인터페이스: 연락처에서 작업하든 기회에서 작업하든 화면과 동작이 같아서 헷갈리지 않고, 작업을 일정한 방식으로 처리할 수 있어요.
- 간단한 작업 만들기: 제목, 설명, 마감일, 담당자 입력란이 한눈에 정리되어 있어서 작업 내용을 빠르게 입력할 수 있어요.
- 반복 작업 옵션: 정해진 일정에 따라 작업이 반복되도록 설정할 수 있어요. 정기 알림이나 업무를 따로 챙기지 않아도 돼요.
- 한곳에서 필터와 검색: 어느 화면에서든 쓸 수 있는 필터와 검색창으로 작업을 쉽게 찾을 수 있어요.
- 빠른 작업 편집: 같은 레이아웃에서 작업을 바로 열어 간단하게 수정할 수 있어요.

## 통합 작업 관리 사용 방법

### 연락처 목록 열기

왼쪽 메뉴에서 **연락처**를 클릭한 다음 **스마트 리스트** 탭을 선택하세요. 서브 계정의 모든 연락처가 목록으로 나타나고, 이름·전화번호·이메일 같은 기본 정보를 볼 수 있어요. 연락처를 클릭하면 전체 프로필을 열고 작업 도구를 쓸 수 있어요.

![연락처 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048627832/original/Fs3OV-aZ8vOOmel75jZ0tlEi35aGZgJDlA.png?1750429054)

### 연락처 상세 화면 열기

연락처를 클릭하면 이메일, 전화번호, 환경설정, 활동 기록이 담긴 상세 프로필이 열려요. 작업을 관리하려면 연락처 화면 오른쪽 위 모서리의 **작업** 아이콘을 클릭하세요.

![연락처 상세 화면의 작업 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048628418/original/xNgcfDS_0LOagSXlKSKSAJ-8AIGfYOdsfw.png?1750429535)

### 팀 또는 상태별로 작업 필터링하기

필터 아이콘을 클릭하면 작업 목록을 빠르게 좁혀 볼 수 있어요. 담당자나 작업 상태로 필터링해서 지금 필요한 작업만 볼 수 있어요. 팀의 업무량을 관리하고 담당을 분명히 하는 데 도움이 돼요.

![작업 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048630461/original/PVVgimYhfyNsX3em2MJqQvzrMeE44OkcIw.png?1750430988)

### 작업 정렬하기

정렬 아이콘을 클릭하면 마감일이나 생성일 기준으로 작업을 정렬할 수 있어요. 오름차순과 내림차순을 번갈아 선택해서 먼저 처리할 작업을 앞에 둘 수 있어요. 작업이 많아도 목록을 보기 편해요.

![작업 정렬 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048630531/original/bsUQ1R6cBfmriXZD6jwmQ0AD33I2gA8Z7w.png?1750431034)

### 작업 편집 또는 삭제하기

작업 옆의 점 세 개 메뉴를 클릭하면 편집·삭제 옵션이 나타나요. 작업 내용을 바꾸려면 **편집**을, 해당 레코드에서 작업을 영구적으로 지우려면 **삭제**를 선택하세요.

![작업 편집 및 삭제 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048630700/original/7uilwSm4pnYvb1ntErEkAUFwrxyr-ZaxJw.png?1750431104)

### 새 작업 추가하기

연락처나 기회 레코드의 작업 패널에서 새 작업을 만들려면 **+ Add Task**(작업 추가) 버튼을 클릭하세요. 작업 정보를 모두 입력할 수 있는 작업 만들기 폼이 열려요.

![작업 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048628712/original/xXWceuxFIFjurCwDFWTM6E9_EMoh0zsckQ.png?1750429739)

### 작업 제목 입력하기

**Title**(제목) 입력란에 작업 제목을 짧고 분명하게 입력하세요. 필수 입력란이에요. 목록을 보거나 필터링할 때 작업을 구분하는 기준이 돼요.

![작업 제목 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048628830/original/QSdu8k7Wg6kC_j6C_UYJpkgd8JfMX6SB3Q.png?1750429830)

### 작업 설명 추가하기

**설명 추가**를 클릭하면 작업에 대한 자세한 내용을 적을 수 있어요. 담당자가 작업의 목적을 이해할 수 있도록 배경, 지시 사항, 중요한 메모를 남겨 보세요.

![작업 설명 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048628967/original/swWxUXWry4nGt7DOkFuE5uSjj_yy9qk2Zw.png?1750429907)

### 마감 날짜와 시간 정하기

**날짜 및 시간**에서 캘린더와 시간 선택기를 사용해 작업을 끝내야 하는 날짜와 시간을 고르세요. 마감 기한을 정해 두면 팀의 책임 소재도 분명해져요.

![마감 날짜 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048629128/original/us1Gox9eoYk2bXrOszqpP5hyeQcsnO3cmg.png?1750430001)

### 작업 시간 선택하기

시간 드롭다운을 클릭해 작업 마감 시간을 정하세요. 시·분까지 정확하게 골라서 작업 알림을 세밀하게 예약할 수 있어요.

![작업 시간 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048629194/original/cWPjBYIX6yiJW-F_YPTSS7IM6DBd1jHd8A.png?1750430059)

### 반복 작업 설정하기

1. **반복 작업** 토글을 켜세요.
2. **반복 주기**에서 작업이 얼마나 자주 반복될지 정하세요. 예를 들어 며칠, 몇 주, 몇 달마다 반복하도록 정할 수 있어요.
3. **종료**에서 반복이 끝나는 조건을 선택하세요.
   - **없음**: 계속 반복해요.
   - **날짜**: 정해 둔 날짜에 반복이 끝나요.
   - **횟수**: 정해 둔 횟수만큼 반복한 뒤 끝나요.
4. 필요하면 **create a new task even if the previous task is overdue**(이전 작업이 기한을 넘겨도 새 작업 만들기) 옵션을 켜세요. 이전 작업을 끝냈는지와 상관없이 정해진 일정대로 반복이 이어져요.

반복되는 업무를 자동으로 챙기고 일정한 후속 조치를 이어 가고 싶을 때 쓰기 좋아요.

![반복 작업 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048629266/original/C37PxsvhdJsemfJLsoD279A1ltYFh_1FHw.png?1750430133)

### 팀원에게 배정하기

**배정 대상** 드롭다운에서 작업을 맡을 사용자를 선택하세요. 계정에 속한 모든 팀원이 목록에 나타나요. 작업을 끝낼 담당자를 골라 지정하면 후속 조치의 담당이 분명해져요.

![작업 배정 대상 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048629545/original/cv6NP791uQJV-9b5jEXgCE9jHAlZ1l0C3A.png?1750430309)

### 저장하거나 다른 작업 이어서 추가하기

작업 정보를 모두 입력했으면 **저장**을 클릭해 작업을 만드세요. 이어서 작업을 더 만들려면 **Save and Add Another**(저장하고 다른 작업 추가)를 선택하세요. 작업을 여러 개 입력할 때 폼을 매번 다시 열지 않아도 돼요.

![저장 및 다른 작업 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048629630/original/oY2gbtnYs4H1eEKFcBB8UqBQb3-jKH4tLQ.png?1750430381)

## 자주 묻는 질문

### 통합 작업 관리는 모든 사용자가 쓸 수 있나요?
서브 계정마다 **실험실**에서 직접 켜야 쓸 수 있어요.

### 이전 작업 시스템으로 돌아갈 수 있나요?
네, **실험실**에서 토글을 끄면 이전 버전으로 돌아갈 수 있어요.

### 기존 작업에 영향이 있나요?
아니요. 기존 작업은 모두 통합 화면에서 그대로 쓸 수 있고, 데이터도 사라지지 않아요.

### 연락처와 기회 관리 모두에서 반복 작업을 만들 수 있나요?
네. 작업 탭이 있는 모든 레코드에서 반복 작업 기능을 쓸 수 있어요.

### 이번 변경이 자동화나 워크플로우에 영향을 주나요?
아니요. 이번 업데이트는 사용자 인터페이스와 작업 관리 화면에만 적용돼요.
