# 작업에 커스텀 필드 사용하기

작업에는 상태, 담당자, 날짜, 우선순위가 기본으로 들어 있어요. 이 밖에 업무에 필요한 정보(예: 고객사 참조 번호, 예산, 콘텐츠 유형)는 커스텀 필드로 기록할 수 있어요. 이 문서에서는 커스텀 필드의 작동 방식, 설정 위치, 필드 유형, 팀이 실제로 채워 넣는 필드 구성법을 안내해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

{% hint style="info" %}
이제 에이전시 $497 요금제를 사용 중이라면 **프로젝트 관리**(Project Management)를 쓸 수 있어요. 켜려면 **Agency settings**(에이전시 설정) 또는 **서브 계정 설정** > **실험실**로 이동해 **프로젝트 관리** 토글을 켜세요.
{% endhint %}

## 커스텀 필드로 할 수 있는 일

커스텀 필드는 작업에 저장하는 추가 정보예요. 상태나 담당자는 누구에게나 같은 질문에 답하지만, 커스텀 필드는 우리 비즈니스에만 해당하는 질문에 답해요. 예를 들면 어느 고객사를 위한 작업인지, 승인된 예산이 얼마인지, 콘텐츠를 어느 채널에 올릴지 같은 정보예요.

작업 상세 패널에서는 커스텀 필드가 **모든 필드** 섹션에 표시되고, 필드 개수도 함께 보여요. 값을 입력하지 않은 필드는 대시(-)로 표시되어서, 아직 비어 있는 항목을 한눈에 알 수 있어요.

작업 상세 패널의 **모든 필드** 섹션이에요. 필드 개수가 보이고, 입력한 필드와 빈 필드가 함께 있어요.

![작업 상세 패널의 모든 필드 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078512536/original/oN1uO2uAcxqQkDW551Vglb1FWbCsIYmjDA.png?1786806753)

## 각 계층에서 커스텀 필드 설정하기

커스텀 필드는 스페이스(Space), 폴더, 리스트 계층에서 추가할 수 있어요. 상위 계층에서 만든 필드는 그 아래 계층이 물려받아요. 반대로 하위 계층에서 만든 필드는 그 계층에만 적용되고, 상위 계층의 커스텀 필드 설정에는 추가되지 않아요.

예를 들어 스페이스에서 만든 커스텀 필드는 그 스페이스의 리스트에서도 쓸 수 있어요. 하지만 특정 리스트에서 만든 필드는 그 리스트 안에서만 쓸 수 있고, 스페이스의 커스텀 필드에는 추가되지 않아요.

이렇게 하면 업무 흐름마다 필요한 정보가 달라도 대응할 수 있어요. 자주 쓰는 필드는 상위 계층에서 한 번 정의해 두고 아래 계층에서 함께 쓸 수도 있어요.

## 사용할 수 있는 필드 유형

사용 중인 것으로 확인된 필드 유형은 다음과 같아요.

1. **Single line text**(한 줄 텍스트): 참조 코드처럼 짧은 자유 입력 값이에요.
2. **Text box**(텍스트 박스): 여러 줄로 입력하는 긴 텍스트 값이에요.
3. **Number**(숫자): 숫자 값이에요.
4. **Monetary**(금액): 통화 기호와 함께 표시되는 금액 값이에요.
5. **Phone**(전화번호): 국가를 선택해서 입력하는 전화번호예요.
6. **Date picker**(날짜 선택): 캘린더에서 고르는 날짜예요.
7. **Single select dropdown**(단일 선택 드롭다운): 정해 둔 목록에서 값 하나를 고르는 필드예요.
8. **Multi select dropdown**(다중 선택 드롭다운): 정해 둔 목록에서 값 여러 개를 고르는 필드예요.
9. **Radio**(라디오): 화면에 보이는 몇 개의 선택지 중 하나를 고르는 필드예요.
10. **Checkbox**(체크박스): 예 또는 아니요 값이에요.
11. **텍스트 박스 목록**: 서로 관련 있는 텍스트 항목 여러 개를 필드 하나에 담아요.
12. **Rich text field**(서식 있는 텍스트 필드)와 **URL**: 일부 서브 계정에서 쓸 수 있어요.

## 커스텀 필드 추가하기

1. 왼쪽 메뉴에서 **연락처**로 이동한 뒤 **작업** 탭을 선택하세요.
2. 왼쪽 패널에서 필드를 추가할 스페이스에 마우스를 올리세요.
3. 스페이스 행에 있는 옵션 버튼을 클릭해 스페이스 옵션 메뉴를 여세요. 메뉴에는 **이름 변경**, **설정**, **Create list**(리스트 만들기), **폴더 만들기**, **커스텀 필드**, **상태 옵션**, **삭제**가 있어요.

   ![스페이스 옵션 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078512532/original/pKgLr62MdBXIa9xy5kVly2SA5FypLmrtdg.png?1786806753)

4. **커스텀 필드**를 선택하세요. 스페이스의 커스텀 필드 설정 화면이 열려요.

   ![스페이스의 커스텀 필드 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078512534/original/ZP7FvTOhBloQIoUObINTtdFTC7_XVkce0A.png?1786806753)

5. 새 필드를 만들고 유형을 고른 다음, 팀원이 따로 설명 없이도 알아볼 수 있는 이름을 붙이세요.

   ![새 필드 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078512537/original/YVDQwbjgfHPZei8EHFdkUoxmLq9RD1Am9A.png?1786806754)

6. 필드 옵션을 설정하세요. 드롭다운과 라디오 필드는 사용자가 고를 값을 입력하세요. 금액 필드는 통화를 확인하세요.

   ![필드 옵션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078512535/original/MijmdSAIowu02KftczGDyq-hU0-nq0UmZw.png?1786806753)

7. **저장**을 선택하세요. 저장하면 그 스페이스에 있는 모든 작업의 **모든 필드** 섹션에 이 필드가 나타나요.

   ![저장 후 모든 필드 섹션에 나타난 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081097613/original/V8iIg8KeUDZHySVvar7tCUuwvUk7krt6xg.png?1789569710)

## 작업에서 커스텀 필드 입력하기

1. 작업 카드를 클릭해 상세 패널을 여세요.
2. **모든 필드** 섹션을 찾으세요. 제목에 그 스페이스가 가진 필드 개수가 표시돼요.
3. 해당하는 필드에 값을 입력하세요. 비워 둔 필드는 대시(-)로 표시돼요.

   ![작업 상세 패널에서 필드 값 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078512533/original/n4k8pLBeZrnB5GxHmiapQICyIsyC7tSpag.png?1786806753)

4. 변경사항을 저장하세요. **저장**을 선택하면 입력한 내용이 반영되고, **취소**를 선택하면 입력한 내용이 버려져요.

## 사람들이 실제로 쓰는 필드 구성하기

커스텀 필드는 추가하기 쉬운 만큼 너무 많이 만들기도 쉬워요. 다음 방법을 참고하세요.

1. 자주 반복되는 질문에서 시작하세요: 작업마다 "어느 고객사 건이에요?"라고 물어봐야 한다면 그게 필드가 되어야 해요. 아무도 묻지 않는 정보라면 필드로 만들 필요가 없어요.
2. 필터나 리포트에 쓸 정보는 자유 입력 대신 드롭다운으로 만드세요: 자유 입력은 표기가 제각각이 되기 쉬워서, 같은 고객사가 세 가지 방식으로 적히기도 해요.
3. 목록을 짧게 유지하세요: 필드가 스무 개나 되는 작업 패널은 아무도 끝까지 채우지 않아요. 반쯤만 채워진 필드는 아예 없는 것보다 나빠요.
4. 필드 이름은 쉽게 지으세요: '채널'이라는 이름은 바로 이해되지만 '유형 2'는 그렇지 않아요.
5. 필드가 스페이스 전체에 적용된다는 점을 기억하세요: 리스트 하나에만 해당하는 필드는 같은 스페이스의 다른 모든 작업에서 빈 채로 남아요.
## 자주 묻는 질문

### 커스텀 필드는 어디에서 설정하나요?

스페이스, 폴더, 리스트 어느 계층에서든 설정할 수 있어요. 각 옵션 메뉴의 **커스텀 필드**에서 설정하세요.

### 같은 스페이스에 있는 리스트끼리 다른 필드를 쓸 수 있나요?

네, 같은 스페이스 안에서도 리스트 단위로 커스텀 필드를 설정할 수 있어서 리스트마다 다른 커스텀 필드를 쓸 수 있어요.

### 커스텀 필드를 필수 항목으로 만들 수 있나요?

아니요, 커스텀 필드는 필수로 지정할 수 없어요.

### 커스텀 필드로 보드를 필터링하거나 그룹화할 수 있나요?

네, 일부 커스텀 필드는 기준으로 보드를 그룹화하거나 필터링할 수 있어요.

### 새 필드를 추가하면 기존 작업은 어떻게 되나요?

그 스페이스의 모든 작업에 필드가 나타나요. 누군가 값을 채우기 전까지는 비어 있고 대시(-)로 표시돼요.
