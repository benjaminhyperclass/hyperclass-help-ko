# 작업 상태 관리

상태는 작업이 거치는 단계를 나타내며, 칸반 보드에서 열(column)로 표시돼요. 상태는 스페이스마다 설정하고, 고정된 상태 그룹 4개(**시작 안 함**, **활성**, **완료**, **종료됨**) 아래에 정리돼요. 이 문서에서는 상태 그룹의 구조, 지원하는 그룹에 사용자 지정 상태를 추가하는 방법, 팀의 업무 방식에 맞게 상태를 구성하는 방법을 안내해요.

{% hint style="info" %}
이제 $497 요금제를 쓰는 에이전시에서 **프로젝트 관리**(Project Management)를 쓸 수 있어요. 새 환경을 사용하려면 **에이전시 설정** 또는 **서브 계정 설정** > **실험실**로 이동해 **프로젝트 관리**를 켜세요.
{% endhint %}

## 상태란?

상태는 작업이 어느 단계에 있는지를 나타내요. 예를 들면 할 일, 진행 중, 완료됨 같은 단계예요. 작업 하나에는 한 번에 상태 하나만 지정돼요. 각 상태는 작업의 전체 진행 정도를 나타내는 상태 그룹에 속해요.

## 상태 그룹 4개

작업 상태는 고정된 그룹 4개로 나뉘어요. 이 그룹은 작업이 거치는 단계를 나타내요.

1. **시작 안 함**(이전 이름: 할 일): 아직 시작하지 않은 작업이에요.
2. **활성**(이전 이름: 진행 중): 현재 진행 중인 작업이에요.
3. **완료**: 끝났지만 검토나 후속 조치 등이 더 필요할 수 있는 작업이에요.
4. **종료됨**: 완전히 끝나서 더 할 일이 없는 작업이에요.

**시작 안 함**, **활성**, **완료** 그룹에는 팀의 업무 방식에 맞게 사용자 지정 상태를 만들 수 있어요.

**종료됨**은 시스템에서 정해 둔 그룹이에요. 기본 상태가 하나만 있고, 사용자 지정 상태는 추가할 수 없어요.

**상태 옵션** 패널에서 상태 그룹과 각 그룹에 속한 상태를 확인할 수 있어요.

**완료**와 **종료됨**을 나누면, 끝났지만 아직 확인이 필요한 작업과 완전히 마무리된 작업을 구분할 수 있어요.

![상태 옵션 패널에 표시된 상태 그룹 4개](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083527379/original/cZ4zap8SPr1a1-_kQbtZhBDS_LZx_6Wnaw.png?1792160559)

{% hint style="info" %}
그룹은 시스템이 상태의 의미를 알 수 있게 해 줘요. **완료** 그룹에 있는 상태는 이름을 무엇으로 붙였든 끝난 작업을 뜻해요. 그래서 팀마다 다른 용어를 써도 보드의 열 순서가 자연스럽게 유지돼요.
{% endhint %}

## 상태는 왜 스페이스에 속할까요?

상태는 개별 리스트나 폴더가 아니라 스페이스에 설정해요. 한 스페이스 안의 모든 리스트가 같은 상태를 써요.

구조를 만들기 전에 알아 두면 좋아요. 예를 들어 콘텐츠 제작은 6단계, 고객 문의 대응은 3단계처럼 단계가 정말 달라야 한다면, 한 스페이스에 리스트 두 개를 두지 말고 스페이스를 따로 만드세요.

## 상태 확인하기

1. 왼쪽 메뉴에서 **연락처**를 누르고 **작업** 탭을 선택하세요.
2. 왼쪽 패널에서 상태를 확인할 스페이스 위에 마우스를 올리세요.
3. 스페이스 행의 옵션 버튼을 클릭하세요. 메뉴에 **이름 변경**, **설정**, **Create list**(리스트 만들기), **폴더 만들기**, **커스텀 필드**, **상태 옵션**, **삭제**가 표시돼요.

   ![스페이스 옵션 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078468782/original/kFftg2m8Ydu_DVpgUyo-8NbAAvTR4U9H1w.png?1786721271)

4. **상태 옵션**을 선택하세요. 스페이스 이름과 상태 그룹 4개(**시작 안 함**, **활성**, **완료**, **종료됨**), 그리고 각 그룹의 상태가 패널에 표시돼요.

## 상태 추가하기

작업 단계를 가장 잘 나타내는 그룹을 고르세요.

- **시작 안 함**: 작업을 아직 시작하지 않았어요.
- **활성**: 작업이 진행 중이에요.
- **완료**: 작업은 끝났지만 검토, 후속 조치 등이 더 필요할 수 있어요.

**종료됨** 그룹은 완전히 끝나서 더 할 일이 없는 작업을 나타내요. 이 그룹에는 사용자 지정 상태를 추가할 수 없어요.

![상태를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083528280/original/rbSdiMNAqj0iaKADDkIS7v0s0lMUjoHHZw.gif?1792160880)

{% hint style="info" %}
상태는 보기 전용이에요. 스페이스 수준에서만 변경할 수 있어요.
{% endhint %}

## 작업 상태 변경하기

방법은 두 가지이고, 결과는 같아요.

### 방법 1. 카드 끌어다 놓기

칸반 보기에서 작업 카드를 현재 열에서 원하는 열로 끌어다 놓으세요. 보드에서 작업하고 있을 때 가장 빠른 방법이에요.

![작업 카드를 다른 열로 끌어다 놓는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083528704/original/j0XAVDG0OZWiqZhunaBK9OaWZ2M2cS1vSA.gif?1792161170)

### 방법 2. 작업 편집하기

작업을 열고 상세 패널에서 **Status**(상태) 속성을 변경하세요. 이미 작업을 열어 내용을 채우고 있을 때 편리해요.

![상세 패널에서 상태 속성을 변경하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083528853/original/UZIr06GKMKpvYS5kpHW6v1-E9t8IlNy46Q.gif?1792161249)

## 좋은 상태 구성 방법

1. 상태는 적을수록 대체로 좋아요. 상태 하나가 열 하나라서, 열이 12개인 보드는 5개인 보드보다 보기 어려워요.
2. 모든 상태는 실제 단계를 나타내야 해요. 어떤 상태에 있어도 작업에 달라지는 일이 없다면, 그 상태는 필요 없을 가능성이 커요.
3. 알맞은 상태 그룹을 고르세요. 시작하지 않은 작업은 **시작 안 함**, 진행 중인 작업은 **활성**, 끝났지만 확인이 더 필요한 작업은 **완료**에 두세요. **종료됨**은 완전히 끝나서 더 할 일이 없는 작업을 나타내요.
4. 작업을 추가하기 전에 계획하세요. 팀이 스페이스를 채우기 전에 상태를 살펴보면, 나중에 작업이 쌓인 보드를 다시 정리하는 것보다 훨씬 수월해요.
5. 비슷한 상태가 없는지 살펴보세요. 한 그룹에 이름이 비슷한 상태가 둘 있다면, 업무 절차가 제대로 합의되지 않았다는 신호인 경우가 많아요.

## 자주 묻는 질문

### 상태 그룹을 직접 추가할 수 있나요?

아니요. 상태 그룹 4개(**시작 안 함**, **활성**, **완료**, **종료됨**)는 고정돼 있어요. **시작 안 함**, **활성**, **완료** 안에는 사용자 지정 상태를 만들 수 있어요. **종료됨**은 시스템에서 정해 둔 그룹이라 사용자 지정 상태를 추가할 수 없어요.

### 한 그룹에 상태를 몇 개까지 둘 수 있나요?

**시작 안 함**, **활성**, **완료** 그룹에는 사용자 지정 상태를 추가할 수 있어요. **종료됨** 그룹에는 시스템에서 정해 둔 기본 상태가 하나 있고, 사용자 지정 상태는 더 추가할 수 없어요.

### 상태는 어디에서 설정하나요?

스페이스의 옵션 메뉴에서 **상태 옵션**으로 설정해요. 설정한 상태는 그 스페이스 안의 모든 리스트에 적용돼요.

### 같은 스페이스 안의 리스트마다 다른 상태를 쓸 수 있나요?

아니요. 상태는 스페이스에 속해요. 단계가 달라야 한다면 스페이스를 따로 사용하세요.

### 상태 이름을 바꾸거나 삭제할 수 있나요?

이름은 바꿀 수 있지만 삭제할 수는 없어요.

### 그룹 안에서 상태 순서를 바꿀 수 있나요?

네, 상태 순서를 바꿀 수 있고, 순서를 바꾸면 보드의 열 순서도 바뀌어요.

### 상태에 색을 지정할 수 있나요?

네, 상태에 색을 지정할 수 있어요.

### 보드에 빈 열이 계속 표시돼요.

그 상태가 스페이스에 있기 때문이에요. 빈 열이 보이는 것은 정상이고, 해당 단계로 작업을 끌어다 놓을 수 있어요.

### 상태를 바꾸면 기존 작업에 영향이 있나요?

새 상태를 추가해도 기존 작업은 옮겨지지 않아요. 누군가 변경하기 전까지 작업은 원래 상태에 그대로 있어요.
