# 프로젝트 관리에서 AI에게 문의 활용하기

**AI에게 문의**를 쓰면 원하는 내용을 말로 설명해서 하이퍼클래스의 프로젝트를 만들고 관리할 수 있어요. 작업 만들기, 마감일 바꾸기, 아직 끝나지 않은 작업 찾기, 프로젝트 정리를 하나하나 직접 하지 않아도 돼요. **AI에게 문의**는 변경 내용을 먼저 보여 주고, 승인한 뒤에 적용해요. 이 문서에서는 **프로젝트 관리**에서 **AI에게 문의**로 할 수 있는 일과 시작하는 방법을 안내해요.

{% hint style="info" %}
**프로젝트 관리**는 이제 $497 요금제를 쓰는 에이전시에서 사용할 수 있어요. 에이전시 또는 서브 계정의 **설정 > 실험실**로 이동해 **프로젝트 관리**를 켜면 새 화면을 쓸 수 있어요.
{% endhint %}

---

## 프로젝트 관리에서 AI에게 문의란?

**AI에게 문의**(Ask AI)는 하이퍼클래스에 내장된 [AI 어시스턴트](../13-AI-Employee/introduction-to-ask-ai-assistant.md)예요. 만들거나 찾거나 바꾸고 싶은 내용을 말로 설명하면 [프로젝트 관리](introduction-to-project-management.md)를 대신 도와줘요.

예를 들어 작업, 마감일, 하위 작업이 들어 있는 고객 온보딩 프로젝트를 만들어 달라고 요청할 수 있어요. **AI에게 문의**가 프로젝트 구조를 준비해 보여 주면, 승인한 뒤에 항목을 만들어 줘요.

제공 현황: **프로젝트 관리**는 현재 프라이빗 베타예요. 이 기능을 쓰려면 **AI에게 문의**도 사용할 수 있어야 해요.

---

## AI에게 문의로 프로젝트와 작업 만들기

**AI에게 문의**는 요청 한 번으로 프로젝트 구조 전체를 만들 수 있어요. 항목을 따로따로 설정하지 않아도 돼요.

프로젝트에는 다음 항목이 들어갈 수 있어요. 자세한 내용은 [스페이스, 폴더, 목록으로 업무 정리하기](organize-work-with-spaces-folders-and-lists.md)와 [작업 또는 하위 작업 만들기](create-a-task-or-subtask.md)에서 볼 수 있어요.

- **스페이스**: 프로젝트를 정리하는 가장 큰 단위예요.
- **폴더**: 관련 있는 목록을 묶을 때 쓰는 선택 항목이에요.
- **목록**: 작업을 모아 둔 곳이에요.
- **작업**: 끝내야 할 개별 활동이에요.
- **하위 작업**: 작업 안에 들어가는 더 작은 활동이에요.

작업 설명, 담당자, 상태, 우선순위, 날짜도 함께 설정해 달라고 요청할 수 있어요.

예시 요청:

"Bright Smile Dental의 고객 온보딩 프로젝트를 만들어 줘. Launch Plan 목록을 추가하고, Kickoff call, Build website, Launch ads 작업을 넣어 줘. Build website 아래에는 Design homepage와 Set up booking form 하위 작업을 추가해 줘."

**AI에게 문의**는 프로젝트 구조를 준비한 뒤, 만들기 전에 승인을 요청해요.

---

## 작업 찾기와 수정하기

**AI에게 문의**는 이미 있는 작업을 검색하고, 요청 하나로 여러 항목을 한꺼번에 수정할 수 있어요. 여러 목록에 걸쳐 있는 업무를 관리할 때 편해요.

다음과 같은 일을 요청할 수 있어요.

- 마감일이나 다른 조건으로 작업 찾기
- 작업 상태와 마감일 수정하기
- 작업을 다른 목록으로 옮기기
- 작업을 두 개 이상의 목록에 추가하기

예시 요청:

- "앞으로 7일 안에 마감인 작업을 모두 보여 줘."
- "Launch Plan에서 기한이 지난 작업을 모두 In Progress(진행 중)로 옮겨 줘."
- "Build website 작업의 마감일을 다음 주 금요일로 바꿔 줘."

작업을 검색만 할 때는 작업이 바뀌지 않아요. 수정 내용은 **AI에게 문의**가 승인을 요청한 뒤에 적용돼요.

---

## 댓글, CRM 레코드, 액세스 관리하기

**AI에게 문의**는 작업과 연결된 정보도 관리해 줘요. 댓글, 고객 레코드, 팀원의 액세스가 여기에 해당해요.

다음과 같이 쓸 수 있어요.

- **댓글 관리**: 작업 댓글을 추가, 편집, 삭제해요.
- CRM 레코드 연결: 작업을 연락처, 기회, 비즈니스와 연결해요.
- **액세스 관리**: 스페이스, 폴더, 목록에 대한 사용자 액세스를 부여하거나 제거해요.

예를 들어 이렇게 요청할 수 있어요.

"Build website 작업을 Bright Smile Dental 연락처에 연결해 줘."

**AI에게 문의**가 실행할 내용을 준비해 승인을 요청해요. 액세스 변경은 내 사용자 권한 범위 안에서만 가능해요.

---

## 변경 내용 검토하고 승인하기

**AI에게 문의**는 프로젝트 정보를 만들거나 수정하기 전에 실행할 내용을 먼저 보여 줘요. 원하지 않는 변경을 막는 데 도움이 돼요.

승인 카드에는 다음 내용이 표시될 수 있어요.

- **AI에게 문의**가 실행하려는 작업
- 그 작업의 영향을 받는 항목
- 변경 사항별 위험도
- 수정 시 이전 값과 새 값

"내일", "7일 후"처럼 말하면 **AI에게 문의**가 해당하는 실제 날짜를 보여 줘요. 승인하기 전에 날짜를 확인하세요.

![승인 카드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083611829/original/-HfYNYEMAwRzMlRswYx4AXQ8oFW6SqjazA.png?1792388952)

{% hint style="warning" %}
프로젝트 생성과 수정은 승인하기 전까지 적용되지 않아요.
{% endhint %}

---

## AI에게 문의 진행 상황 확인하기

승인한 작업을 처리하는 동안 **AI에게 문의**는 진행 상황을 사이드 패널에 보여 줘요. 진행 과정을 따라가고, 완료하지 못한 작업이 있으면 바로 알 수 있어요.

작업이 끝나면 **AI에게 문의**가 완료된 내용을 요약해 줘요. 요청한 변경이 제대로 됐는지 요약을 확인하세요.

---

## 프로젝트 관리에서 AI에게 문의 사용하는 순서

필요한 내용을 설명하고, 제안된 작업을 검토한 뒤 승인하면 프로젝트를 만들 수 있어요. 아래 단계는 고객 온보딩 프로젝트를 예로 들었어요.

### 1단계: AI에게 문의 열기

1. 하이퍼클래스 서브 계정에 로그인하세요.
2. 왼쪽 사이드바 또는 상단 메뉴에서 **AI에게 문의**를 클릭하세요.
3. **대화 시작**을 선택하세요.

### 2단계: 요청 입력하기

만들고 싶은 프로젝트의 구조와 작업을 설명하세요.

예를 들어 이렇게 입력해요.

"Client Onboarding이라는 스페이스를 만들어 줘. 그 안에 Bright Smile Dental 폴더와 Launch Plan 목록을 만들어 줘. Kickoff call 작업은 마감일을 내일로, Build website 작업은 7일 후로, Launch ads 작업은 14일 후로 추가해 줘. Build website 아래에는 하위 작업 두 개, Design homepage와 Set up booking form을 추가해 줘."

요청을 보내세요.

### 3단계: 검토하고 승인하기

**AI에게 문의**가 실행할 작업을 보여 줘요.

1. 스페이스, 폴더, 목록 이름을 확인하세요.
2. 작업 이름, 마감일 등 세부 내용을 살펴보세요.
3. 요청과 다른 부분이 있으면 고치세요.
4. 제안된 작업을 승인하세요.

승인하면 **AI에게 문의**가 프로젝트를 만들기 시작하고 진행 상황을 보여 줘요.

### 4단계: 결과 확인하기

**AI에게 문의**가 작업을 마치면 완료 요약을 열어 무엇이 만들어졌는지, 실패한 작업은 없는지 확인하세요.

![AI에게 문의 완료 요약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083611961/original/jPnyGEbzrjUMJPzJtCGt1TqXGGm_0Q3bEg.png?1792389165)

하이퍼클래스에서 프로젝트를 직접 확인하려면 다음 순서로 진행하세요.

1. **연락처 > 작업**으로 이동하세요.
2. "Client Onboarding" 스페이스를 여세요.
3. "Bright Smile Dental" 폴더를 펼치세요.
4. "Launch Plan" 목록을 선택하세요.
5. 작업과 하위 작업이 올바른 내용으로 표시되는지 확인하세요.

![만들어진 프로젝트 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083611938/original/0tSYA66PeMShKCf4liTbHHfO34ZIOqqMYQ.png?1792389115)

빠졌거나 잘못된 내용이 있으면 **AI에게 문의**의 요약을 확인하고 필요한 부분을 고치세요.

## 자주 묻는 질문

### 프로젝트 관리의 AI에게 문의는 누구나 쓸 수 있나요?
**프로젝트 관리**는 현재 프라이빗 베타예요. **AI에게 문의**도 사용할 수 있어야 해요.

### AI에게 문의를 쓰기 전에 스페이스나 목록을 먼저 만들어야 하나요?
아니요. 요청 한 번으로 프로젝트 구조 전체를 만들어 달라고 할 수 있어요.

### AI에게 문의로 여러 작업을 한 번에 수정할 수 있나요?
네. 요청 하나로 여러 작업의 상태, 마감일, 목록 배정을 수정할 수 있어요.

### 작업을 바꾸지 않고 내 작업에 대해 물어볼 수도 있나요?
네. "이번 주에 마감인 작업이 뭐야?"처럼 물어보면 작업을 바꾸지 않고 정보만 가져와요.

### AI에게 문의가 잘못된 변경을 준비했어요. 어떻게 하나요?
승인하기 전에 제안된 작업을 검토하고 고치세요.

### AI에게 문의가 작업을 끝내지 못하면 어떻게 되나요?
**AI에게 문의**가 응답에서 완료하지 못한 작업을 알려 줘요. 그 내용을 확인하고 다음에 어떻게 할지 정하면 돼요.
