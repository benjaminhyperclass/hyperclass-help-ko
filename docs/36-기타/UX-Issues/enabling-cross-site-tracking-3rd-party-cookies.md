# 사이트 간 추적(서드파티 쿠키) 허용하기

브라우저가 사이트 간 추적(서드파티 쿠키)을 막고 있으면 일부 기능이 제대로 동작하지 않을 수 있어요. 이 문서에서는 브라우저별로 사이트 간 추적을 허용하는 방법을 안내해요. 지금은 macOS의 Safari만 안내하고, 나머지 브라우저는 준비 중이에요.

## macOS에서 Safari 설정하기

1. **Safari 실행하기**

   Dock에 있는 Safari 아이콘을 클릭해 Safari를 열어요. Spotlight(Cmd + Space)에서 "Safari"를 검색해 선택해도 돼요.
2. **Safari 환경설정 열기**

   화면 맨 위 메뉴에서 **Safari**를 클릭한 다음, 드롭다운 메뉴에서 **환경설정** 또는 **설정**을 선택해요. 단축키 Cmd + 쉼표(,)를 누르면 **환경설정** 창이 바로 열려요.
3. **개인정보 보호 탭 열기**

   **환경설정** 창이 나타나면 위쪽의 **개인정보 보호** 탭을 클릭해요.

   ![Safari 환경설정 창의 개인정보 보호 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001126903/original/t9DjEvz-StiF4hKtrGhQ8061SFbw1XM9ow.png?1686834080)
4. **웹사이트 추적 옵션 조정하기**

   **개인정보 보호** 탭에는 웹사이트 추적과 관련된 여러 옵션이 있어요. Safari는 기본적으로 사이트 간 추적을 막고 있어요. 이를 허용하려면 **Prevent cross-site tracking**(사이트 간 추적 방지) 옆의 체크박스를 해제하세요.

   ![사이트 간 추적 방지 체크박스를 해제한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001127020/original/0qNxY7Sl5uHxCI6iJNaHdPXRyqmcjwbcFQ.png?1686834172)
5. **환경설정 닫기**

   원하는 대로 설정했으면 **환경설정** 창을 닫아요.
