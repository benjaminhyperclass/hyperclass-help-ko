# 이탈 의도 팝업 만들기

하이퍼클래스의 웹사이트·퍼널 빌더에서 이탈 의도 팝업을 만들고 설정하는 방법을 안내해요. 이탈 의도 팝업은 방문자가 페이지를 떠나기 전에 다시 관심을 끌어, 가입이나 리드 확보, 특별 혜택 안내로 이어지게 도와줘요.

## 이탈 의도 팝업(Exit-Intent Pop-up)이란?

이탈 의도 팝업은 방문자의 커서 움직임으로 곧 사이트를 떠날 것 같다고 판단될 때 나타나요. 보통 커서가 브라우저 주소창이나 닫기 버튼 쪽으로 움직일 때예요. 하이퍼클래스에서는 웹사이트·퍼널 빌더 안에서 팝업을 디자인하고, 이탈 의도에 따라 나타나도록 설정할 수 있어요.

## 이탈 의도 팝업의 장점

이탈 의도 팝업은 마지막 순간에 행동을 유도하는 문구를 보여 주어 리드 확보와 전환을 크게 높일 수 있어요. 주요 장점은 다음과 같아요.

- 이탈률 줄이기: 방문자가 나가기 직전에 혜택을 보여 주어, 아무 행동 없이 떠나는 일을 줄여요.
- 떠나려는 방문자 붙잡기: 마지막 메시지나 혜택으로 방문자가 떠나기 전에 리드 정보를 받을 수 있어요.
- 전환율 높이기: 기간 한정 특가나 할인으로 망설이는 방문자를 리드로 바꿀 수 있어요.
- 콘텐츠 사용자 지정: 팝업의 모양, 레이아웃, 폼 필드를 브랜드에 맞게 디자인할 수 있어요.
- 폼 연동: 하이퍼클래스 폼을 삽입해 이메일, 전화번호 등 필요한 정보를 받을 수 있어요.
- 퍼널·웹사이트 빌더에서 바로 사용: 별도의 외부 도구 없이, 이탈 의도 기능이 하이퍼클래스 편집기에 들어 있어요.

## 이탈 의도 팝업 만들기

폼을 만드는 단계부터 트리거를 설정하는 단계까지 순서대로 따라 하세요.

#### 1단계: 팝업에 쓸 폼 만들기

팝업에서 방문자의 정보를 받으려면 폼이 필요해요. 팝업에 사용할 폼을 새로 만들거나, 이미 만들어 둔 폼을 찾아 두세요.

폼 만드는 방법은 「하이퍼클래스에서 문의 폼을 만드는 방법」 문서를 참고하세요.

#### 2단계: 팝업 만들기

퍼널이나 웹사이트 빌더의 페이지 안에서 팝업을 만들고, 앞서 준비한 폼을 넣어요.

1. **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동해, 사용할 퍼널이나 웹사이트를 선택하세요.
2. 팝업을 넣을 퍼널 단계나 페이지를 찾으세요. 파란색 **편집** 버튼을 클릭하면 해당 웹사이트 페이지나 퍼널 단계가 빌더에서 열려요.
3. 웹사이트 빌더 상단 메뉴에서 **Pop-up Settings**(팝업 설정)를 클릭하세요.
4. **Add Row**(행 추가)를 클릭한 뒤 **요소 추가**를 클릭해 폼 요소를 팝업에 넣으세요.
5. **form picker**(폼 선택기)에서 사용할 폼을 선택하세요.
6. 브랜드에 맞게 팝업 디자인을 꾸미세요.
7. (선택) 처음 폼을 추가한 뒤 다른 폼으로 바꾸고 싶다면, 사이드바의 드롭다운에서 폼을 바꿀 수 있어요.

#### 3단계: 이탈 의도 시 팝업이 나타나도록 설정하기

방문자가 페이지를 떠나려 할 때 팝업이 나타나게 하려면 올바른 옵션을 선택해야 해요.

1. 팝업 상단에 있는 톱니바퀴 아이콘이 붙은 파란색 **Pop Up Settings**(팝업 설정) 버튼을 클릭하세요.
2. 사이드바에서 **Show Pop-up On**(팝업 표시 시점)까지 스크롤하세요.
3. 드롭다운에서 **종료**를 선택하세요. **없음**이나 **Delay**(지연)를 선택하면 의도한 동작이 꺼지거나 달라져요.

![팝업 표시 시점에서 종료를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046636982/original/BqOxZQAZontEUwA4RxcSWbT7CKi3wh0MZg.jpeg?1747237609)

#### 4단계: 팝업 테스트하기

저장하고 게시한 뒤에는 팝업이 의도대로 동작하는지 테스트하세요.

1. 페이지나 퍼널 단계를 미리 보세요.
2. 나가려는 것처럼 커서를 브라우저 위쪽으로 움직여 보세요.
3. 팝업이 나타나는지 확인하세요.
4. 필요하면 스타일과 내용을 조정하세요.

## 데스크톱과 모바일의 차이

이탈 의도는 마우스 커서의 움직임으로 감지하기 때문에 데스크톱에서만 작동해요. 터치스크린에는 커서가 없어서 모바일에서는 작동하지 않아요.

모바일 방문자를 위한 활용법은 「모바일 반응형 디자인 쉽게 만들기」 문서를 참고하세요.

## 자주 묻는 질문

### 하이퍼클래스로 만들지 않은 웹사이트에도 이탈 의도 팝업을 쓸 수 있나요?
아니요. 이탈 의도 팝업은 하이퍼클래스 안에서 만든 퍼널과 웹사이트에서만 지원돼요.

### **종료** 대신 **없음**이나 **Delay**를 선택하면 어떻게 되나요?
팝업이 이탈 의도 팝업처럼 동작하지 않아요. **없음**을 선택하면 팝업이 꺼지고, **Delay**를 선택하면 커서가 나가려는 순간이 아니라 일정 시간이 지난 뒤에 팝업이 나타나요.

### 팝업마다 다른 폼을 쓸 수 있나요?
네. 퍼널 단계나 페이지별로 각각의 팝업에 다른 폼을 지정할 수 있어요.

### 게시하기 전에 팝업을 미리 볼 수 있나요?
네. 빌더 안의 페이지 미리보기 기능으로 게시하기 전에 동작을 테스트할 수 있어요.

### 팝업 스타일을 내 사이트에 맞출 수 있나요?
팝업의 행, 열, 배경, 폼 스타일을 모두 사용자 지정해서 사이트 브랜딩에 맞출 수 있어요.
