# 메모와 작업 설명에 리치 텍스트 서식 쓰기

메모와 작업 설명에 굵게, 목록, 하이퍼링크 같은 서식을 넣을 수 있어요. 내용이 한눈에 들어와서 팀원이 빠르게 이해하고 바로 행동할 수 있어요. 이 문서에서는 지원하는 서식, 사용 방법, 서식이 표시되는 위치를 안내해요.

## 메모와 작업 설명의 리치 텍스트란?

리치 텍스트는 메모와 작업 설명에 간단한 서식을 더해 주는 기능이에요. 중요한 내용을 강조하고, 후속 조치를 목록으로 정리하고, 관련 자료로 연결하는 일을 하이퍼클래스를 벗어나지 않고 할 수 있어요.

사용할 수 있는 기능은 다음과 같아요.

- 서식: 굵게, 기울임, 밑줄, 취소선
- 글머리 기호 목록과 번호 목록
- 하이퍼링크
- 실행 취소/다시 실행
- 붙여넣을 때 기본 서식 유지

이 서식은 메모와 작업이 표시되는 모든 곳에서 똑같이 보여요.

## 리치 텍스트의 장점

장점을 알아 두면 리치 텍스트를 언제 쓸지, 팀의 메모 작성 방식을 어떻게 맞출지 정하기 쉬워요.

- 명확성: 핵심 내용을 강조해서 팀원이 정보를 빠르게 훑어볼 수 있어요.
- 일관성: **연락처**, **기회 관리**, **회사**, **대화**, **캘린더**에서 똑같이 보여요.
- 속도: 강조, 목록, 링크를 바로 적용할 수 있어요. 다른 도구로 옮겨 가거나 URL을 그대로 붙여넣을 필요가 없어요.
- 되돌리기: 실행 취소/다시 실행으로 긴 글을 고치다 생기는 실수를 줄일 수 있어요.
- 협업: 메모 형식을 공유하고 관련 링크를 남기면 팀 간 인수인계가 쉬워져요.
- 정리 시간 단축: 문서나 이메일에서 복사해 붙여넣어도 기본 서식이 유지돼서 다시 손볼 일이 줄어요.

## 서식 툴바

툴바에서 자주 쓰는 서식을 바로 고를 수 있어요.

- 굵게, 기울임, 밑줄, 취소선
- 글머리 기호 목록과 번호 목록
- 하이퍼링크(삽입/편집)
- 실행 취소/다시 실행

## 목록으로 내용 정리하기

목록을 쓰면 해야 할 일과 회의 메모를 읽기 쉽고 오래 관리하기 좋아요.

- 아이디어, 논의 주제, 일반 메모에는 글머리 기호 목록을 써요.
- 진행 순서, 후속 조치, 순서가 있는 작업에는 번호 목록을 써요.

## 하이퍼링크

문서, 드라이브 폴더, 티켓 같은 외부 자료의 링크를 넣으면 팀원이 하이퍼클래스에서 바로 상세 내용으로 이동할 수 있어요.

메모나 작업 설명에 링크를 넣거나 편집하는 방법은 다음과 같아요.

1. 링크를 걸 텍스트를 선택하세요.
2. 툴바에서 **링크** 아이콘을 클릭하세요.
3. URL을 붙여넣고 확인하세요.
4. 메모나 작업을 **저장**하세요. 메모나 작업이 표시되는 곳마다 링크가 클릭 가능한 텍스트로 보여요.

## 하이퍼클래스 전반에서의 표시

메모와 작업 설명은 여러 곳에 나타나요. 리치 텍스트를 쓰면 어디서 보더라도 같은 내용을 읽기 쉽게 볼 수 있어요.

리치 텍스트 서식은 다음 위치에서 똑같이 표시돼요.

- **연락처**
- **기회 관리**
- **회사**
- **대화**
- **캘린더**

## 제한 사항

미리 알아 두면 헷갈리지 않고 리치 텍스트를 편하게 쓸 수 있어요.

- 현재 버전은 간단한 서식에 초점을 맞췄어요. 이미지, 표, 제목, 텍스트 색상, 텍스트 정렬, 코드 블록, 체크박스형 작업 목록은 지원하지 않아요.
- 붙여넣을 때는 기본 서식(강조, 목록, 링크)만 유지돼요. 복잡한 레이아웃과 미디어는 빠져요.
- 공개 API: 이 기능으로 바뀌는 내용은 없어요.

## 메모와 작업 설명에서 리치 텍스트 사용하기

메모와 작업 설명의 리치 텍스트는 이제 하이퍼클래스 전체에서 정식으로 사용할 수 있어요. 에디터를 쓸 수 있고, 메모와 작업이 표시되는 곳마다 서식이 똑같이 보여요.

1. 기존 메모나 작업, 또는 새 메모나 작업을 여세요.
   - 예를 들어 서브 계정에서 **연락처**로 이동해 기존 연락처를 열거나 새 연락처를 만든 뒤, 그 안의 메모나 작업을 열 수 있어요.
2. 메모의 **설명** 필드를 클릭하세요.
3. 툴바에서 서식을 적용하거나, 링크를 넣거나, 목록을 만드세요.
4. **저장**을 클릭해 변경 내용을 적용하세요.

## 자주 묻는 질문

### 리치 텍스트를 쓰면 메모나 작업이 저장되거나 내보내지는 방식이 달라지나요?

리치 텍스트는 화면에서 읽기 쉽게 만드는 데 초점을 둔 기능이에요. 내보내기나 인쇄를 할 때는 내용이 단순하게 바뀔 수 있어요. 필요한 모양인지 내보낸 결과를 확인해 보세요.

### 작업이나 메모에 이미지, 표, 제목을 넣을 수 있나요?

아니요. 메모와 작업 설명에서는 강조, 목록, 링크, 실행 취소/다시 실행, 붙여넣기 기본 서식 같은 간단한 기능만 지원해요.

### 하이퍼링크 클릭 수도 추적되나요?

하이퍼링크는 빠르게 이동하는 용도로만 제공돼요. 이 기능으로 링크 클릭 추적이 추가되지는 않아요.

### 모바일에서도 서식이 보이나요?

서식은 플랫폼 어디서든 읽을 수 있게 만들어졌어요. 모바일에서 툴바가 보이지 않으면 데스크톱/웹 앱에서 편집하세요. 보는 데는 문제가 없어요.

### API가 바뀌었나요?

아니요. 이번 출시로 공개 API 엔드포인트가 추가되거나 바뀌지 않았어요.

### 대화의 내부 댓글도 메모와 같은 에디터를 쓰나요?

내부 댓글은 메모와 달라요. 이 기능은 메모와 작업 설명 편집을 개선한 것이라서, 내부 댓글은 쓸 수 있는 기능이 다를 수 있어요.

### 텍스트 색상이나 정렬도 쓸 수 있나요?

아니요. 이 기능은 명확하고 일관된 내용 전달에 필요한 기본 서식에 초점을 맞췄어요.
