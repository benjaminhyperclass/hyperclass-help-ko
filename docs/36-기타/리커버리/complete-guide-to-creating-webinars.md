# 웨비나 만들기 완벽 가이드

웨비나는 라이브 또는 온디맨드 발표로 리드를 모으고, 참석자를 교육하고, 전환을 이끄는 데 쓰여요. 이 문서에서는 하이퍼클래스에서 웨비나를 설정하고, 일정을 잡고, 템플릿·복제·자동화·리마인더를 쓰는 방법과 운영 팁을 안내해요.

하이퍼클래스는 두 가지 웨비나를 지원해요.

- 라이브 웨비나: 정해진 시간에 실시간으로 진행하는 이벤트
- 온디맨드 웨비나: 언제든 자동으로 볼 수 있는 상시 시청형 웨비나

## 하이퍼클래스의 웨비나 유형

### 라이브 웨비나

라이브 웨비나는 참석자가 정해진 날짜와 시간에 접속하는 이벤트예요.

이런 경우에 쓰면 좋아요.

- 제품 출시
- 라이브 교육
- Q&A 세션
- 워크숍
- 코칭 세션

### 온디맨드 웨비나

온디맨드 웨비나는 미리 녹화한 영상을 쓰며, 참석자는 등록한 뒤 언제든 볼 수 있어요.

이런 경우에 쓰면 좋아요.

- 상시 리드 확보
- 자동화된 판매 퍼널
- 교육 자료 라이브러리
- 자기 속도에 맞춘 학습

## 주요 기능과 장점

하이퍼클래스 웨비나에는 다음 기능이 있어요.

- 라이브·온디맨드 웨비나 지원
- 미리 만들어 둔 웨비나 퍼널 템플릿
- 등록 페이지와 확인 페이지
- CRM 리드 수집 연동
- 자동 리마인더와 후속 메시지
- 웨비나 복제와 재사용 가능한 템플릿
- 워크플로우 자동화 지원

## 라이브 웨비나 만들기

1. **사이트 > 웨비나**로 이동해요.
2. **New Webinar Funnel**(새 웨비나 퍼널)을 클릭해요.
3. **Live Webinar**(라이브 웨비나)를 선택해요.

### 1단계: 웨비나 세부 정보 입력

다음 필수 필드를 입력해요.

- **Webinar Name**(웨비나 이름)
- **Timezone**(시간대)
- **Date**(날짜)
- **Time**(시간)

필수 항목이 비어 있으면 웨비나를 만들 수 없어요.

## 웨비나 설정 개선 사항

웨비나 설정 과정에 다음 기능이 추가되었어요.

- 개선된 날짜·시간 선택기
- 더 편해진 시간대 선택
- 필수 항목 검증
- 웨비나 항목 자동 저장

이 개선 덕분에 웨비나를 만들 때 일정을 잘못 입력하는 실수를 줄일 수 있어요.

### 2단계: 등록 폼 선택

**폼 선택**에서 **사이트 > 폼**에 만들어 둔 폼을 골라요.

등록 폼으로 다음 작업을 할 수 있어요.

- 참석자 정보 수집
- 워크플로우 실행
- 리마인더 자동화 시작
- 리드를 CRM에 동기화

### 3단계: 웨비나 링크 추가

웨비나를 송출하는 URL을 입력해요.

지원하는 플랫폼은 다음과 같아요.

- Zoom
- YouTube Live
- WebinarJam
- 사용자 지정 웨비나 링크

### 4단계: 웨비나 템플릿 선택

미리 만들어 둔 웨비나 퍼널 템플릿 중에서 고르거나, 직접 만들 수도 있어요.

템플릿에는 보통 다음 페이지가 들어 있어요.

- 등록 페이지
- 확인 페이지
- 방송 페이지

## 웨비나 템플릿과 퍼널 페이지

웨비나 퍼널을 만들면 참석자 등록과 시청에 쓰는 웨비나 페이지가 자동으로 만들어져요.

만들어지는 페이지는 다음과 같아요.

- **웨비나 등록**
- **Webinar Confirmation**(웨비나 확인)
- **Webinar Broadcast**(웨비나 방송)

## 온디맨드 웨비나 만들기

**On-Demand Webinar**(온디맨드 웨비나)를 선택해요.

### 필수 필드

온디맨드 웨비나에는 다음 항목이 필요해요.

- **Webinar Name**(웨비나 이름)
- **Webinar Video or Link**(웨비나 영상 또는 링크)

온디맨드 웨비나에는 날짜, 시간, 시간대가 필요하지 않아요.

### 웨비나 영상 업로드

미리 녹화한 웨비나 영상을 업로드하거나, 미디어 라이브러리에서 영상을 선택해요.

#### 지원 형식

- MP4
- MOV
- AVI

### 웨비나 복제

기존 웨비나를 복제하면 더 빠르게 설정하고 다시 쓸 수 있어요.

웨비나를 복제할 때 이제 다음 작업을 할 수 있어요.

- 웨비나 날짜 수정
- 웨비나 시간 수정
- 웨비나 템플릿과 설정 재사용

정기적으로 여는 웨비나의 일정을 잡을 때 편해요.

## 웨비나 자동화와 리마인더

웨비나 퍼널은 워크플로우 자동화를 기본으로 지원해요.

자주 쓰는 자동화는 다음과 같아요.

- 등록 확인 메시지
- 리마인더 이메일과 SMS
- 웨비나 후속 메시지
- 다시보기 전달
- 웨비나 종료 후 육성 캠페인

일반적인 리마인더 발송 시점은 다음과 같아요.

- 24시간 전
- 1시간 전
- 10분 전

## 개선된 웨비나 툴팁

웨비나 설정 화면의 툴팁이 더 명확한 안내를 제공해요.

툴팁 내용을 불러오지 못하면 대체 안내가 자동으로 표시되어, 설정할 때 헷갈리는 일을 줄여 줘요.

## 운영 팁

### 라이브 웨비나

- 시작 전에 웨비나 링크를 테스트해요.
- 시간대를 고려해서 일정을 잡아요.
- 홍보를 일찍 시작해요.
- 예비 송출 방법을 준비해 둬요.
- 참석자가 참여할 수 있도록 유도해요.

### 온디맨드 웨비나

- 화질이 좋은 녹화본을 써요.
- 웨비나를 간결하게 구성해요.
- 콘텐츠를 주기적으로 새로 고쳐요.
- 미디어 라이브러리의 자료를 체계적으로 정리해요.

### 웨비나 자동화

- 리마인더 워크플로우를 켜 둬요.
- 병합 필드로 메시지를 개인화해요.
- 다시보기와 후속 메시지 시퀀스를 추가해요.
- 게시하기 전에 자동화를 테스트해요.

## 문제 해결

### 라이브 웨비나 문제

#### 웨비나 링크가 작동하지 않아요

게시하기 전에 웨비나 URL을 확인하세요.

#### 시간대가 잘못 표시돼요

설정할 때 웨비나 시간대를 제대로 골랐는지 다시 확인하세요.

### 온디맨드 웨비나 문제

#### 영상 업로드에 실패해요

파일 형식과 업로드 용량을 확인하세요.

#### 영상 화질이 좋지 않아요

해상도가 더 높은 미디어 파일을 업로드하세요.

### 일반 웨비나 문제

#### 웨비나가 저장되지 않아요

필수 항목을 모두 입력했는지 확인하세요.

#### 등록 폼이 작동하지 않아요

폼 연동과 워크플로우 설정을 확인하세요.

## 자주 묻는 질문

### 라이브 웨비나에는 어떤 필드가 필요한가요?

라이브 웨비나에는 제목, 날짜, 시간, 시간대, 웨비나 링크 또는 영상이 필요해요.

### 온디맨드 웨비나에는 어떤 필드가 필요한가요?

온디맨드 웨비나에는 웨비나 제목과 영상 또는 웨비나 링크가 필요해요.

### 웨비나를 복제할 때 날짜와 시간을 수정할 수 있나요?

네. 이제 복제하는 중에 웨비나 날짜와 시간을 수정할 수 있어요.

### 웨비나 항목은 자동으로 저장되나요?

네. 웨비나 항목은 자동으로 저장되고, 웨비나 목록에도 바로 표시돼요.

### 웨비나 등록으로 워크플로우를 실행할 수 있나요?

네. 웨비나 폼으로 리마인더, 후속 메시지, 태그 추가, CRM 업데이트 같은 워크플로우를 실행할 수 있어요.
