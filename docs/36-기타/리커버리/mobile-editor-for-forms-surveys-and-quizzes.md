# 폼, 설문, 퀴즈의 모바일 편집기 사용하기

하이퍼클래스의 폼, 설문, 퀴즈 빌더에 있는 모바일 편집기로 모바일 화면의 이미지와 글꼴을 따로 꾸밀 수 있어요. 데스크톱 레이아웃은 그대로 두고 모바일에 맞는 화면을 만들 수 있어요.

## 모바일 편집기란?

모바일 편집기는 폼, 설문, 퀴즈가 모바일 기기에서 보이는 모습을 따로 꾸미는 기능이에요. 모바일과 데스크톱 중 한쪽에 맞추려고 다른 쪽을 포기하지 않아도 돼요. 기기별로 스타일을 따로 설정하니, 어떤 화면 크기에서도 깔끔하게 보여요.

## 모바일 편집기의 장점

모바일에서 쓰기 편해야 사용자가 끝까지 입력해요. 이 기능을 쓰면 데스크톱 디자인은 그대로 두고 모바일 화면 요소만 세밀하게 조정할 수 있어요.

- 모바일 전용 헤더 이미지와 배경 이미지를 업로드할 수 있어요.
- 폰트, 글꼴 크기, 글꼴 굵기를 따로 조정할 수 있어요.
- **라벨**, **Short Labels**(짧은 라벨), **플레이스홀더 텍스트**처럼 텍스트 요소별로 스타일을 정할 수 있어요.
- 게시하기 전에 모바일 디자인을 미리 보고 테스트할 수 있어요.
- 어떤 기기에서든 사용하기 편하고 브랜드 느낌이 유지되는 폼을 만들 수 있어요.
- 모바일 사용 경험이 좋아지면 작성 완료율을 높이는 데 도움이 돼요.

## 모바일 편집기 사용 방법

아래 순서대로 폼, 설문, 퀴즈에서 모바일 편집기를 켜고 설정해 보세요.

1. 빌더 대시보드에서 폼, 설문, 퀴즈 중 하나를 열어요.

   ![빌더에서 폼 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047765746/original/WLW2pIjU1oURMGynOfMxSUyYBiGyWTG7lQ.png?1749068777)
2. 화면 위쪽의 **Device Toggle**(기기 전환 토글)을 눌러 **모바일 보기**로 바꿔요.

   ![기기 전환 토글로 모바일 보기로 전환](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047765949/original/OqX7HBaCddbhDXWsaMDIy4hpofLBWXfKZw.png?1749069210)
3. **모바일 보기**에서는 오른쪽 패널에 모바일 전용 설정이 나타나요.

   - **Layout Style**(레이아웃 스타일): 원하는 모바일 레이아웃을 선택해요.
   - **Mobile Header Image**(모바일 헤더 이미지): 모바일 헤더에 쓸 이미지를 업로드해요.
   - **Mobile Background Image**(모바일 배경 이미지): 모바일 전용 배경 이미지를 업로드해요.
   - **Font Settings**(글꼴 설정):

     - **폰트**를 조정해요.
     - **글꼴 크기**를 바꿔요.
     - **글꼴 굵기**를 바꿔요.
4. 글꼴 설정은 아래 요소마다 따로 적용돼요.

   - **라벨**(예: "이름")
   - **Short Labels**(예: 줄여 쓰는 형식의 필드 제목)
   - **플레이스홀더 텍스트**(예: "이메일을 입력하세요")

   설정을 마치면 **저장**을 누르고, **미리보기**로 모바일 디자인을 확인해요.
5. 마음에 들면 폼을 **게시**하세요. 모바일에 맞게 다듬어진 폼이 게시돼요.

### 데스크톱과 모바일 스타일 패널 따로 쓰기

기기별 스타일 설정이 따로 있어서 CSS를 덮어쓰지 않아도 각 기기에서 깔끔하게 보여요. 화면 크기에 맞게 레이아웃을 정하면서 브랜드 일관성도 지킬 수 있어요.

기기별로 설정할 수 있는 스타일 속성

- 배경 색상, 패딩, 테두리, 글꼴 굵기
- **모바일**에서 정한 스타일은 **데스크톱** 스타일을 덮어쓰지 않아요. 반대로 **데스크톱** 스타일도 **모바일**을 덮어쓰지 않아요.
- 모바일에서 패딩을 완전히 0px로 만들 수 있어요. **모바일 보기**에서 **Top**(위)과 **Bottom**(아래) 패딩을 0px로 설정하면 여백이 완전히 없어져요. 모바일 스타일은 기기별로 적용되므로 데스크톱 패딩은 바뀌지 않아요.

![모바일 보기에서 패딩 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064146055/original/siER8o4XuLfkF-Ub9l_XoXO6AVO2pzP5RA.gif?1770193571)

## 모바일에서 콘텐츠와 스타일 설정하기

콘텐츠와 디자인은 따로 설정해요. 모바일 화면에서 이해하기 쉽게 문구를 고치고, 읽기 편하도록 모바일 전용 스타일을 다듬어 보세요.

적용 방식

- 콘텐츠: 모바일에서는 데스크톱과 다른 문구를 쓸 수 있어요.
- 스타일: 간격, 테두리, 글꼴은 기기별로 적용돼요.
- 초기화/복사: 사용할 수 있는 경우 **Reset**(초기화)이나 **Copy from Desktop**(데스크톱에서 복사)을 쓰면 설정 시간을 줄일 수 있어요.

## 모바일 헤더 및 배경 이미지

이미지는 모바일 화면에서 보이는 방식이 달라요. 작은 기기에 맞춘 이미지를 따로 올리면 디자인이 깔끔하게 보여요.

모바일 전용 이미지가 필요한 이유

- 모바일 사용자는 화면을 세로로 보므로, 폭이 좁은 세로형 이미지를 쓰는 편이 좋아요.
- 데스크톱용 이미지를 줄일 때 흔히 생기는 잘림이나 찌그러짐을 막을 수 있어요.

## 모바일 글꼴 스타일

데스크톱에서는 잘 읽히던 글자가 모바일에서는 답답하거나 너무 크게 느껴질 수 있어요. 모바일 편집기에서 글꼴 요소를 하나씩 조정하면 모바일에서도 편하게 읽을 수 있어요.

설정할 수 있는 항목

- **폰트**: 사용할 수 있는 시스템 폰트나 커스텀 폰트 중에서 선택해요.
- **글꼴 크기**: 작은 화면에서도 잘 보이도록 px 단위로 정확한 크기를 정해요.
- **글꼴 굵기**: 굵게, 가늘게, 보통 중에서 골라 가독성을 높여요.

적용되는 요소

- **라벨**: 사용자가 필드를 올바르게 입력하도록 안내해요.
- **Short Labels**: 줄여 쓰는 레이아웃이나 여러 열로 나뉜 영역에 알맞아요.
- **플레이스홀더 텍스트**: 입력 칸에서 은은하게 입력 방법을 알려 줄 때 유용해요.

## 자주 묻는 질문

### 모바일 보기에서 바꾼 내용이 데스크톱 레이아웃에도 영향을 주나요?
아니요. **모바일 보기**에서 한 편집은 모바일에만 적용돼요. 데스크톱 디자인은 그대로 유지돼요.

### 모바일 전용 헤더 이미지와 배경 이미지를 따로 쓸 수 있나요?
네. 작은 화면 비율에 더 잘 맞는 모바일 전용 이미지를 올릴 수 있어요. 데스크톱 버전에는 영향을 주지 않아요.

### 게시하기 전에 모바일 버전만 미리 볼 수 있나요?
네. **모바일 보기**에서 **미리보기**를 누르면 사용자가 모바일에서 보게 될 화면을 확인할 수 있어요.

### 글꼴 변경은 전체에 적용되나요, 요소별로 적용되나요?
글꼴 설정은 **라벨**, **Short Labels**, **플레이스홀더 텍스트**마다 따로 설정할 수 있어요.

### 모든 요금제에 모바일 편집기가 포함되나요?
네. 폼, 설문, 퀴즈를 제공하는 모든 요금제에 포함돼요.
