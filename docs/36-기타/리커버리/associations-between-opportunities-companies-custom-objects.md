# 기회, 회사, 사용자 지정 객체 간 연관 설정하기

기회(딜), 회사, 사용자 지정 객체를 서로 연결해 실제 업무 관계를 그대로 담을 수 있어요. 예를 들어 기회를 회사나 부동산 매물 같은 사용자 지정 객체와 연결하거나, 회사를 사용자 지정 객체에 바로 연결할 수 있어요. 비즈니스 기록을 한 화면에서 맥락 있게 볼 수 있어서 팀이 더 빠르게 일하고 판단할 수 있어요.

## 이 기능이 필요한 이유

연관을 설정하면 CRM의 데이터가 서로 이어져서 쓰기 편해져요.

- 기회, 회사, 사용자 지정 객체를 가로질러 360° 관점으로 볼 수 있어요.
- 딜 ↔ 회사 ↔ 부동산 매물·보험 증권 같은 자산처럼, 실제 비즈니스 관계를 그대로 표현할 수 있어요.
- 관련 정보를 한곳에서 관리하니 레코드를 오가며 찾는 시간이 줄어요.
- 연관 데이터를 워크플로우, 리포트, 내보내기에 활용해 추적과 개인화를 더 잘할 수 있어요.

## 주요 특징

- 다음 조합의 연관을 지원해요.
  - 기회 ↔ 사용자 지정 객체
  - 회사 ↔ 사용자 지정 객체
  - 회사 ↔ 기회
- 일대일, 일대다, 다대일, 다대다 관계를 지원해요.
- 레코드 패널에서 바로 연관을 만들고 관리할 수 있어요.
- 워크플로우을 벗어나지 않고 기존 레코드를 검색해 바로 연결할 수 있어요.
- 레코드 상세 정보, 칸반 카드, **목록 보기**에서 연관된 레코드를 볼 수 있어요.
- **필드 관리 > Association Label (Object Types)**(연관 레이블(오브젝트 유형))에서 연관 필드를 추가할 수 있어요.

## 연관 만드는 방법

### 1단계: 연관 탭 열기

1. **설정 > 사용자 지정 객체 > [사용할 객체]** 로 이동하세요.
2. **연관** 탭을 클릭하세요.
3. **Create Association**(연관 만들기)을 클릭하세요.

![연관 탭에서 연관 만들기를 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055756163/original/GSVW_zRGJRjoL0vseXdaRvn0VUla61-5AQ.png?1760135540)

### 2단계: 연관 설정하기

1. 연결할 대상을 선택하세요. **기회 관리** 또는 **회사**를 고를 수 있어요.
2. 연관 이름을 정하세요.
   - **Single Label**(단일 레이블): 예) "딜"
   - **Pair of Labels**(레이블 쌍): 예) "구매자 ↔ 판매자"
3. 관계 유형을 선택하세요.
   - **One-to-One**(일대일)
   - **One-to-Many / Many-to-One**(일대다 / 다대일)
   - **Many-to-Many**(다대다)
4. 필요하면 레코드 수 제한을 설정하세요. 최대 1,000개까지 설정할 수 있어요.
5. 미리보기를 확인하고 **저장**을 클릭하세요.

![연관 이름과 관계 유형을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055756453/original/SB9gwCmMaEzSmrtNsUZe79XRd8RxyFIhfQ.png?1760135929)

## 레코드에서 연관 관리하기

지원하는 레코드라면 어디서든 연관을 관리할 수 있어요.

### 기회에서

1. 기회를 여세요.
2. **Associated Objects**(연관된 오브젝트)로 이동하세요.
3. **+ Associate**(+ 연관)를 클릭하세요.
4. 회사 또는 사용자 지정 객체를 선택하세요.

### 회사에서

1. 회사를 여세요.
2. **Associations / Related Objects**(연관 / 관련 오브젝트)로 이동하세요.
3. 연결할 기회나 사용자 지정 객체를 선택하세요.

### 사용자 지정 객체에서

1. 사용자 지정 객체 레코드를 여세요.
2. 연결할 기회나 회사를 추가하세요.

연관은 바로 화면에 나타나고, 언제든지 수정할 수 있어요.

![레코드에서 연관을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055756614/original/uksM61_7i9OYEHlF_fOkZzRBI8oAYZdFXA.png?1760136841)

## CRM에서 연관 확인하기

### 레코드 상세 정보

- 연결된 모든 레코드(기회, 회사, 사용자 지정 객체)가 **Associated Objects** 패널에 표시돼요.
- 현재 화면을 벗어나지 않고 연결된 레코드를 사이드 패널로 열 수 있어요.

### 칸반 보기 (Kanban View)

기회 관리에서 쓰는 보기예요.

1. **기회 관리 > 필드 관리**로 이동하세요.
2. 카드에 **Association Label (Object Type)**을 추가하세요.
3. 카드에서 연결된 회사나 사용자 지정 객체를 바로 확인하세요.

![칸반 카드에 연관 레이블이 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055812605/original/p2-PEiWc-OGfiznohmbrNGhLJrTAsFX2VQ.png?1760331692)

### 목록 보기

1. 연관 필드를 열로 추가하세요.
2. 연결된 모든 레코드를 한곳에서 확인하세요.

필터링, 일괄 작업, 내보내기에 유용해요.

![목록 보기에 연관 필드가 열로 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055812981/original/1i5aZaVtwmrqD25nTBYWvpdUvJulEUw4hg.png?1760332266)

## 팁

- 객체 쌍마다 레이블을 최대 10개까지 만들 수 있어요.
- 레이블 하나당 한쪽에 최대 1,000개의 레코드를 연결할 수 있어요.
- 레코드를 삭제하면 해당 연관도 자동으로 제거돼요.
- **필드 관리**에서 연관 필드를 추가하면 리포트와 내보내기에도 쓸 수 있어요.
- API와 자동화 지원은 곧 제공될 예정이에요.

## 활용 예시

- 부동산: 부동산 매물(사용자 지정 객체) ↔ 기회 ↔ 회사를 연결해 구매자, 매물, 중개사를 한곳에서 추적해요.
- 이벤트: 이벤트(사용자 지정 객체) ↔ 회사 ↔ 후원 기회를 연결해요.
- 보험: 보험 증권/견적(사용자 지정 객체) ↔ 기회 ↔ 회사를 연결해 전체 과정을 추적해요.

## 자주 묻는 질문

### 관계에 제한을 둘 수 있나요?
네. **One-to-One**(일대일)을 선택하거나, 설정할 때 레코드 수 제한을 지정하면 돼요.

### 레이블 이름을 바꾸면 연관이 끊기나요?
아니요. 화면에 표시되는 레이블 이름만 바뀌어요.

### 연관을 한꺼번에 가져올 수 있나요?
아직 지원하지 않아요.

### 리포트에서 연관 데이터를 쓸 수 있나요?
네. 연관 필드를 통해 쓸 수 있어요.

### 레코드를 삭제하면 연관은 어떻게 되나요?
연관이 자동으로 제거돼요.
