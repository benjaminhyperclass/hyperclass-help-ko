# 상품 상세정보 페이지의 이미지 확대(Image Zoom) 설정

**Image Zoom**(이미지 확대)을 설정하면 고객이 하이퍼클래스 스토어의 상품 이미지를 더 자세히 살펴볼 수 있어요. 고객이 이미지를 클릭하거나 마우스를 올리거나 크게 볼 때 이미지가 어떻게 반응할지 직접 정할 수 있어요. 고객이 상품 페이지에서 바로 세부 모습을 확인하면 구매 전에 더 안심할 수 있어요.

## 상품 상세정보 페이지의 Image Zoom이란?

**Image Zoom** 옵션은 **상품 상세정보** 요소 설정 안에 있어요. 상품 이미지에 확대 기능을 쓰지 않거나, 클릭하거나 마우스를 올릴 때 확대하거나, 전체 화면 라이트박스로 열도록 고를 수 있어요.

## Image Zoom을 쓰면 좋은 점

상품 이미지는 고객이 무엇을 사는지 이해하는 데 큰 역할을 해요. Image Zoom을 쓰면 고객이 페이지를 벗어나지 않고도 세부 모습을 볼 수 있어서 상품 페이지를 더 편하게 둘러볼 수 있어요.

- 상품을 더 잘 보여 줘요: 고객이 질감, 라벨, 포장, 색상, 디자인 요소 같은 세부 모습을 가까이서 확인할 수 있어요.
- 쇼핑 경험이 좋아져요: 확대 기능 덕분에 상품 상세정보 페이지를 더 쉽게 살펴볼 수 있어요.
- 상품을 보여 주는 방식을 직접 정할 수 있어요: 상품 종류와 스토어 스타일에 가장 잘 맞는 확대 방식을 고르세요.
- 전체 화면으로 이미지를 볼 수 있어요: 라이트박스 옵션을 쓰면 확대·축소와 이동 버튼이 있는 큰 팝업으로 상품 이미지를 볼 수 있어요.
- 지원하는 미디어 레이아웃에서 모두 작동해요: **Stack Gallery**(스택 갤러리), **Stack Carousel**(스택 캐러셀), **Two-Column Layout**(2열 레이아웃) 미디어 표시 방식에서 Image Zoom을 쓸 수 있어요.

## Image Zoom 옵션

Image Zoom 옵션은 고객이 상품 상세정보 페이지에서 상품 이미지를 어떻게 다루는지 정해요. 상품과 고객의 둘러보기 방식에 맞는 옵션을 고르면 이미지를 보는 경험을 알맞게 맞출 수 있어요.

### No Zoom(확대 없음)

**No Zoom**은 상품 이미지를 단순하게 보여 줘요. 고객은 별도의 확대 동작 없이 상품 이미지를 그대로 볼 수 있어요.

```
이런 경우에 No Zoom을 쓰세요:

상품 이미지를 가까이서 살펴볼 필요가 없을 때

상품 상세정보 페이지를 단순하게 유지하고 싶을 때

이미지를 클릭하거나 마우스를 올려도 확대되지 않게 하고 싶을 때
```

### Click & Hover Zoom(클릭·호버 확대)

**Click & Hover Zoom**을 쓰면 고객이 상품 이미지를 클릭하거나 마우스를 올려서 원하는 부분을 확대할 수 있어요. 고객이 작은 세부 모습을 페이지에서 바로 확인해야 할 때 유용해요.

{% hint style="info" %}
**Click & Hover Zoom**은 마우스나 트랙패드를 쓰는 데스크톱 환경에서 가장 잘 작동해요.
{% endhint %}

```
이런 경우에 Click & Hover Zoom을 쓰세요:

고객이 자세히 살펴보고 싶어 할 만한 세부 모습이 상품에 있을 때

고객이 주로 데스크톱에서 둘러볼 때

별도의 전체 화면을 열지 않고 확대하게 하고 싶을 때
```

### Open Lightbox Zoom(라이트박스 확대)

**Open Lightbox Zoom**을 쓰면 고객이 이미지를 클릭할 때 상품 이미지가 전체 화면 팝업으로 열려요. 고객은 라이트박스 안에서 확대·축소하고, 이미지 사이를 이동하고, 썸네일을 둘러볼 수 있어요.

```
이런 경우에 Open Lightbox Zoom을 쓰세요:

스토어에서 상품 이미지를 여러 장 쓸 때

고객이 이미지를 더 크게 보게 하고 싶을 때

이동 버튼이 있는 안내형 이미지 보기를 제공하고 싶을 때
```

## 지원하는 상품 미디어 레이아웃

Image Zoom 옵션은 지원하는 상품 상세정보 페이지의 상품 미디어 레이아웃에서 모두 쓸 수 있어요. 이미지를 페이지에 어떻게 배치할지와 고객이 이미지를 어떻게 다룰지를 따로 정할 수 있다는 뜻이에요.

Image Zoom은 다음 미디어 레이아웃에서 작동해요.

- **Stack Gallery**
- **Stack Carousel**
- **Two-Column Layout**

상품 이미지 레이아웃 설정에 대한 자세한 내용은 '상품 상세정보 페이지의 상품 미디어 레이아웃' 문서를 참고하세요.

{% hint style="warning" %}
Image Zoom은 상품 이미지에만 적용돼요. 상품 동영상은 미디어 영역에 계속 표시될 수 있지만 확대 기능에서는 제외돼요.
{% endhint %}

## 상품 상세정보 페이지에 Image Zoom 설정하기

설정을 제대로 해 두면 고객이 상품 페이지에서 원하는 이미지 동작을 볼 수 있어요. 원하는 확대 방식을 고른 뒤에는 변경사항을 저장하고 게시해야 실제 스토어에 바뀐 상품 이미지 경험이 나타나요.

1. 하이퍼클래스에서 스토어를 열어요.

   ![스토어 열기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071141259/original/9HrLVMaLpXuZdFaPpSDB0qaLjlaNEoc1HQ.png?1778590996)
2. **상품 상세정보** 페이지를 편집해요.
3. **상품 상세정보** 요소를 선택해요.
4. **Layout Settings**(레이아웃 설정)에서 **Image Zoom** 옵션을 찾아요.

   ![레이아웃 설정의 Image Zoom 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071143550/original/gD5S5QE6voLUGsBgiNfjQEuP6uQAbwFK9A.png?1778591899)
5. 원하는 확대 방식(**No Zoom**, **Click & Hover Zoom**, **Open Lightbox Zoom**)을 골라요.
6. **변경사항 저장**을 클릭해요.
7. **게시**를 클릭해서 바뀐 Image Zoom 설정을 실제 페이지에 적용해요.

## 자주 묻는 질문

### 모든 상품 상세정보 페이지 미디어 레이아웃에서 Image Zoom을 쓸 수 있나요?
Image Zoom은 **Stack Gallery**, **Stack Carousel**, **Two-Column Layout** 미디어 레이아웃에서 작동해요.

### 상품 동영상에도 Image Zoom이 적용되나요?
아니요. Image Zoom은 상품 이미지에만 적용돼요. 동영상은 확대 기능에서 제외돼요.

### 데스크톱 고객에게는 어떤 확대 옵션이 좋은가요?
마우스나 트랙패드를 쓰는 데스크톱 고객에게는 **Click & Hover Zoom**이 가장 잘 맞아요.

### Open Lightbox Zoom을 고르면 어떻게 되나요?
상품 이미지를 클릭하면 전체 화면 팝업이 열려요. 고객은 이 팝업에서 확대·축소하고, 이미지 사이를 이동하고, 썸네일을 둘러볼 수 있어요.

### 라이트박스에서 상품 이미지 사이를 이동할 수 있나요?
네. 라이트박스에는 이전·다음 버튼과 상품 이미지를 둘러볼 수 있는 썸네일 목록이 있어요.

### No Zoom도 계속 쓸 수 있나요?
네. 상품 이미지를 확대 기능 없이 보여 주고 싶다면 **No Zoom**을 쓸 수 있어요.

### Image Zoom 설정을 바꾼 뒤에 페이지를 게시해야 하나요?
네. 변경사항을 저장하고 게시해야 고객이 실제 상품 상세정보 페이지에서 바뀐 이미지 확대 동작을 볼 수 있어요.

### 사용자 지정 상품 상세정보 페이지에서도 Image Zoom을 쓸 수 있나요?
네. 상품 상세정보 페이지의 **상품 상세정보** 요소 설정에서 Image Zoom을 설정할 수 있어요.
