# 상품 원가와 마진 추가하고 추적하기

상품의 가격이나 배리언트에 원가와 마진을 입력하면 상품별 수익성을 하이퍼클래스 안에서 바로 확인할 수 있어요. 외부 스프레드시트나 직접 계산 없이, 판매할 때마다 얼마를 버는지 파악할 수 있어요.

## 원가와 마진 추적이란?

상품 원가와 마진은 하이퍼클래스에서 상품이나 배리언트마다 켜 둘 수 있는 선택 입력 항목이에요. 켜 두면 **상품** 메뉴 안에서 상품별 수익성을 체계적이고 정확하게 볼 수 있어요. 원가를 입력해 두면 거래 내역 CSV 내보내기에 **Line Item Cost Price**(항목별 원가) 열이 따로 생겨서 거래 단위로 수익성을 분석할 수 있어요.

팀원끼리 같은 기준으로 원가와 마진을 다루려면 아래 용어를 알아 두세요.

- **원가**: 상품을 제공하거나 구입하는 데 드는 비용이에요. 항상 0 이상이에요.
- 마진(금액): 판매가에서 원가를 뺀 값이에요(판매가 − 원가). 양수일 수도, 음수일 수도 있어요.
- 마진(퍼센트): 그 차이를 원가에 대한 비율로 나타낸 값이에요((판매가 − 원가) ÷ 원가 × 100). 원가가 0이면 마진율은 100%로 처리돼요.

---

## 원가와 마진을 추적하면 좋은 점

- 플랫폼 안에서 바로 확인: 플랫폼을 벗어나지 않고도 상품별 마진을 한눈에 볼 수 있어요.
- 자동 계산: 원가나 마진(금액 또는 퍼센트) 중 하나만 입력하면 나머지는 자동으로 계산돼요.
- 유연한 적용: 일회성 상품과 반복 결제 상품 모두, 가격과 배리언트에 쓸 수 있어요.
- 일관된 원가: 인보이스나 캘린더에서 가격을 직접 바꿔도 원가는 그대로 유지돼요.
- 내보내기 가능한 데이터: 거래 단위 원가 데이터를 CSV로 내보내 재무 정리와 대조 작업에 쓸 수 있어요.

---

## 사전 준비

- 계정에서 **결제 > 상품** 메뉴에 접근할 수 있어야 해요.
- 새 상품이든 기존 상품이든 상품이 하나 이상 있어야 해요.
- **권한**: 원가와 마진을 설정하려면 상품을 만들고 편집할 수 있는 권한이 있어야 해요.

## 상품에 마진 추적 켜기

원가와 마진은 일반 상품이면 가격 단위로, 배리언트가 있는 상품이면 배리언트 단위로 설정해요. 상품을 만들거나 편집할 때 **가격** 섹션 안에 입력란이 나타나요.

상품의 원가와 마진을 추적하려면 아래 순서대로 따라 하세요.

#### 1단계: 상품 페이지로 이동하기

왼쪽 메뉴에서 **결제**를 클릭하세요. 위쪽 메뉴에서 **상품**을 클릭하면 상품 페이지가 열려요.

![결제 메뉴에서 상품 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066312095/original/QRHvMabHtkIQiXCMf2qvcvf3g7bcNK6wVg.png?1772731792)

#### 2단계: 상품 만들기

**+ 상품 만들기** 버튼을 클릭해 새 상품을 만들거나, 기존 상품을 클릭해 편집하세요.

![상품 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066312144/original/YwAAhd9z1I3AN19DKvm9jsPlooLjeQNcpQ.png?1772731840)

#### 3단계: 가격 섹션으로 이동하기

상품을 만들거나 편집하는 화면에서 **가격** 섹션까지 스크롤하세요. 기존 상품이라면 설정할 가격 옆의 **편집**을 클릭하세요.

![가격 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066312257/original/HUa0lCxjraGY5RsbENG4sz3_w82pq58Zlg.png?1772731934)

#### 4단계: 마진 추가 체크박스 켜기

**가격** 섹션에서 **마진 추가** 체크박스를 선택하세요. 그러면 **원가**와 **마진** 입력란이 나타나요. 이 체크박스는 기본적으로 해제되어 있고, 켜도 기존 거래에는 영향이 없어요.

![마진 추가 체크박스](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066312360/original/qDwDri7DUyGDEgektLq5l6l4mUj3s-3U3g.png?1772732014)

#### 5단계: 원가 또는 마진 입력하기

마진을 금액으로 볼지 퍼센트로 볼지 먼저 선택하세요. 그런 다음 원가나 마진 중 한쪽만 입력하면 판매가를 기준으로 나머지가 자동으로 계산돼요.

- **원가**: 이 상품을 제공하는 데 드는 비용이에요. 음수는 입력할 수 없어요.
- **마진**: 원가를 넘는 이익이에요. 입력란 옆의 토글로 **Amount**(금액) 모드와 **Percentage**(퍼센트) 모드를 바꿀 수 있어요.

{% hint style="info" %}
**마진 추가**를 선택하고 두 입력란을 모두 비워 두면, 시스템은 원가를 판매가와 같은 값으로 처리해 내보내요. 이때 마진은 0으로 유지돼요.
{% endhint %}

![원가와 마진 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066313691/original/K1o1pI6PZ0Kv4JyvoPwh95HyG7-gd22N-Q.png?1772733275)

#### 6단계: 상품 저장하기

**저장**을 클릭하세요. 이 상품의 가격 단위로 원가와 마진이 저장되고, 이후 내보내기에 반영돼요.

![저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066313766/original/IgeMZQSK3Ka6YR0XPItA8aPzO7gTlaTtCg.png?1772733326)

{% hint style="info" %}

{% endhint %}

## 원가와 마진이 연동되는 방식

두 입력란은 판매가를 기준으로 자동으로 맞춰져요. 모드를 바꾸거나 판매가를 바꾸면 연동된 다른 입력란이 바로 다시 계산돼요.

### 금액 모드

- 마진 = 판매가 − 원가
- 원가 = 판매가 − 마진
- 원가는 0 이상이어야 해요.
- 마진은 양수일 수도, 음수일 수도 있어요.

### 퍼센트 모드

- 마진율(%) = ((판매가 − 원가) ÷ 원가) × 100

{% hint style="info" %}
마진율이 100%를 넘는 값은 올바르지 않아요. 100을 넘을 수 있는 마크업(markup)과는 달라요. 마진은 원가로 나누기 때문에 위쪽은 100%, 아래쪽은 -100%로 제한돼요.
{% endhint %}

### 판매가를 바꿀 때

상품의 판매가를 수정하면 시스템이 기존 원가를 기준으로 마진을 자동으로 다시 계산해요. 금액 모드와 퍼센트 모드를 오갈 때도 입력한 데이터는 사라지지 않고 다시 계산돼요.

## 인보이스와 캘린더에서 원가가 표시되는 방식

인보이스와 캘린더에서는 항목별로 판매가를 직접 바꿀 수 있어요. 이런 경우 원가는 다음과 같이 처리돼요.

- 원가는 항상 원래 상품 가격에서 가져와요. 현재는 직접 바꾼 판매가를 기준으로 다시 계산하지 않아요.
- 인보이스나 캘린더에서는 마진을 다시 계산하지 않아요.
- 반복 결제 상품의 셋업 수수료는 마진 계산에서 제외돼요.
- 구독 상품은 셋업 수수료가 아니라 반복 결제 금액만 마진 계산에 써요.

## 거래 내역 CSV: Line Item Cost Price(항목별 원가)

거래 내역 CSV 내보내기에 **Line Item Cost Price** 열이 새로 추가됐어요. 이 열로 거래별, 항목별 수익성을 분석할 수 있어요.

### 내보내기 방법

1. **결제 > 거래 내역**으로 이동하세요.
2. **CSV 내보내기**를 클릭하세요.
3. 원가를 설정해 둔 상품이 포함된 거래라면, 모든 상품에 대해 **Line Item Cost Price** 열이 자동으로 나타나요.

![거래 내역 CSV 내보내기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066214875/original/Y0KxlOGHp7_JMeTBru-vfwd8pwQJd4f-sw.png?1772645261)

### 열 표시 기준

- 상품에 원가가 설정되어 있으면 원가 금액이 표시돼요.
- 원가가 설정되어 있지 않으면 열이 비어 있어요.
- 인보이스나 캘린더에서 가격을 직접 바꾼 경우에는 원래 상품의 원가가 표시돼요.
- 일회성 결제, 구독 결제, 부분 결제에 모두 적용돼요.
- 부분 결제는 일할 계산한 금액이 아니라 상품 원가 전체가 표시돼요.

{% hint style="warning" %}
원가 데이터는 과거 거래에 소급 적용되지 않아요. 상품에 원가를 설정한 뒤에 만들어진 거래에만 이 열의 값이 채워져요.
{% endhint %}

## 자주 묻는 질문

### 기존 상품에도 원가를 추가할 수 있나요?

네, 할 수 있어요. 기존 상품을 열어 가격이나 배리언트를 편집하고 **마진 추가** 체크박스를 선택하세요. 과거 거래에는 영향이 없고, 이후 거래부터 원가 데이터가 반영돼요.

### 마진 추가를 선택하고 입력란을 비워 두면 어떻게 되나요?

**마진 추가** 체크박스를 선택하고 값을 입력하지 않으면, 시스템은 원가를 판매가와 같은 값으로 처리해요. 이 값은 CSV 내보내기에도 그대로 전달돼요.

### 원가가 고객에게도 보이나요?

아니요. 원가는 내부용 항목이라 결제 화면, 영수증, 인보이스에서 고객에게 표시되지 않아요.

### 배리언트마다 원가를 다르게 설정할 수 있나요?

네, 할 수 있어요. 배리언트 조합마다 원가와 마진 입력란이 따로 있어서 배리언트별로 수익성을 다르게 추적할 수 있어요.

### 상품의 판매가를 바꾸면 원가도 자동으로 바뀌나요?

아니요. 판매가가 바뀌면 기존 원가를 기준으로 마진이 다시 계산되고, 원가 자체는 바뀌지 않아요. 입력한 값은 그대로 유지되면서 마진은 정확하게 맞춰져요.

### 여러 상품의 원가를 한꺼번에 편집할 수 있나요?

이번 릴리스에서는 할 수 없어요. 원가 일괄 편집은 일괄 편집 기능의 일부로 이후 단계에서 제공할 계획이에요.

### 반복 결제 상품의 마진 계산에 셋업 수수료도 포함되나요?

아니요. 셋업 수수료는 마진 계산에서 제외돼요. 구독 상품의 원가와 마진은 반복 결제 금액만 기준으로 계산해요.

### 상품에 원가를 추가하면 과거 거래도 업데이트되나요?

아니요. 원가 데이터는 소급 적용되지 않아요. 상품에 원가를 설정한 뒤에 만들어진 거래만 내보내기에서 **Line Item Cost Price** 값이 채워져요.
