# 쿠폰 시작하기

쿠폰을 만들어 상품에 할인을 제공하고, 결제 전환율을 높이는 방법을 안내해요. 쿠폰은 일회성 상품과 반복 결제 상품 모두에 적용할 수 있어요. 사용 방법, 장소, 횟수도 직접 정할 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 쿠폰이란?

쿠폰을 쓰면 상품 할인을 제공하고 여러 결제 화면에서 전환율을 높일 수 있어요. 쿠폰으로 할 수 있는 일은 다음과 같아요.

- 비율 할인 또는 고정 금액 할인 제공
- 전체 장바구니 또는 특정 상품에 할인 적용
- 사용 한도와 제한 조건으로 사용 방식 관리
- 구독 상품에 기간을 정해 할인 적용
- 사용 및 사용 내역 추적

쿠폰은 다음 위치에서 사용할 수 있어요.

- **이벤트**: 이벤트에서는 **결제 > 쿠폰**에서 만든 기존 쿠폰을 쓸 수 있어요. 개별 이벤트 안에서 만드는 이벤트 전용 쿠폰도 지원해요.
- **퍼널**(주문 폼)
- **스토어**
- **웹사이트**
- **결제 링크**
- **캘린더**
- **서비스**
- 기프트 카드 판매 페이지
- 비즈니스용 **구독 만들기**

{% hint style="warning" %}
쿠폰은 견적서와 인보이스에서는 지원하지 않아요. PayPal로 결제하는 구독에서는 일부 쿠폰 설정을 지원하지 않아요.
{% endhint %}

## 쿠폰 만드는 방법

### 1단계: 쿠폰 화면으로 이동하기

**결제 > 쿠폰 > 쿠폰 만들기**로 이동하세요.

![결제 메뉴의 쿠폰 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067095692/original/bXahrvIuWIAvgNTrKzos4JrrvBDe-9cLFw.png?1773739904)

![쿠폰 만들기 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067274628/original/JkrjdFQtc4tIxL3Rnnt7W-X79xocw9fYFA.png?1773901987)

### 2단계: 기본 정보 입력하기

**기본 정보**에서 다음 항목을 입력해요.

#### Coupon Name(쿠폰 이름)

- 내부에서 쿠폰을 구분하기 위한 이름이에요.
- 예: `SUMMER SALE 2025`

#### 쿠폰 코드

- 고객이 결제할 때 입력하는 코드예요.
- 다음 조건을 지켜야 해요.
  - 영문자와 숫자만 쓸 수 있어요.
  - 공백이나 특수문자는 쓸 수 없어요.
  - 대소문자를 구분하지 않아요. 입력하면 자동으로 대문자로 바뀌어요.
- **생성**을 클릭하면 코드를 자동으로 만들 수 있어요.

![쿠폰 이름과 쿠폰 코드 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067298017/original/jqwGXNit07EQDY8NMffBuG4sCCftLNnu9Q.png?1773919127)

### 3단계: 쿠폰 유형 선택하기

쿠폰 유형은 두 가지 중에서 고를 수 있어요.

#### 1. 비율 할인 쿠폰

- 총금액에 정해진 비율만큼 할인해요.
- 예:
  - 장바구니 금액 = $100
  - 쿠폰 = 25%
  - 최종 금액 = $75

![비율 할인 쿠폰 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067298055/original/kYtJhdCVYauIBfmA1zyuzVSrxUYWbC9ELw.png?1773919160)

#### 2. 고정 금액 쿠폰

- 주문 금액과 상관없이 정해진 금액만큼 할인해요. 쿠폰을 만들 때 **고정 금액**을 선택하세요.
- 예:
  - 장바구니 금액 = $100
  - 쿠폰 = $25
  - 최종 금액 = $75

![고정 금액 쿠폰 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067298093/original/36kr_pbEV_6P6fcQaSZQLfPsh137mTXx1g.png?1773919196)

### 쿠폰 통화

- 쿠폰 통화는 서브 계정의 통화로 자동 설정돼요.
- 직접 바꿀 수 없어요.

### 4단계: 유효 기간 설정하기 (선택)

쿠폰을 사용할 수 있는 기간을 정할 수 있어요.

- **시작 날짜 시간**: 쿠폰이 활성화되는 시점
- **종료 날짜 및 시간**: 쿠폰이 만료되는 시점

종료 날짜를 정하지 않으면 쿠폰은 계속 사용할 수 있어요.

![유효 기간 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067298143/original/-nlSVBYAQMFWsJRrktsurBBaUzE9ICniew.png?1773919223)

### 5단계: 사용 제한 설정하기

다음 제한을 설정할 수 있어요.

#### 1. Limit Total Redemptions(총 사용 횟수 제한)

- 쿠폰을 사용할 수 있는 횟수를 제한해요.
- 예: 100번까지만 사용 가능

#### 2. Limit to Selected Products(선택된 상품으로 제한)

- 특정 상품에만 쿠폰을 쓸 수 있게 제한해요.
- 예:
  - 쿠폰을 "Premium Plan"에서만 사용할 수 있어요.
  - 다른 상품에는 사용할 수 없어요.
- 상품 전체가 아니라 특정 가격이나 옵션(변형)으로만 제한할 수도 있어요.

![선택한 상품으로 제한하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067297860/original/rpJemNEmBQm5_GgtsWaZrEn5Ls87WvxjFg.png?1773918991)

![상품별 가격과 옵션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067297906/original/-SC0iex1rPRmyAEGlC-mW7aHHqXxtprvpg.png?1773919028)

#### 3. Limit to One Use per Customer(고객당 1회 사용으로 제한)

- 한 고객이 같은 쿠폰을 여러 번 쓰지 못하게 해요.

### 6단계: 구독 설정하기 (해당하는 경우)

반복 결제 상품에서는 할인이 적용되는 기간을 정할 수 있어요.

#### Apply to Future Payments(향후 결제에 적용)

다음 중에서 선택해요.

- **영구**: 모든 결제 주기에 할인이 적용돼요.
- **여러 달**: 정해진 기간 동안만 할인이 적용돼요.

예:

- 구독 = 월 $100
- 쿠폰 = 3개월간 20% 할인
- 처음 3개월은 매월 $80을 결제해요.
- 그 이후에는 다시 월 $100을 결제해요.

{% hint style="info" %}
결제 주기와 상관없이 적용돼요.
{% endhint %}

![구독 할인 기간 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067298181/original/cucHH0eRoLNkVRF2swJ0Z7MZAXMhjwVhOQ.png?1773919266)

### 7단계: 쿠폰 만들기

**만들기**를 클릭하세요.

설정에 따라 쿠폰이 바로 활성화되거나 예약돼요.

![쿠폰 만들기 완료 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067298370/original/ikZsXZqCY4m9GcSLvV78rakbyCYpiTjp0Q.png?1773919338)

## 결제할 때 쿠폰이 적용되는 방식

- 사용할 수 있는 쿠폰이 있을 때만 쿠폰 입력란이 보여요.
- 적용 가능한 쿠폰이 없으면 입력란이 자동으로 숨겨져요.
- 할인은 다음과 같이 처리돼요.
  - 결제 요약에 표시돼요.
  - 적용 가능한 상품에 비례해서 나누어 적용돼요.
  - 주문 상세에서 확인할 수 있어요.
- **퍼널**, **결제 링크** 등 많은 결제 화면은 빌더에서 결제 중 쿠폰 표시와 적용 여부를 켜거나 끌 수 있어요.

## 알아 둘 동작과 제한 사항

- 쿠폰은 다음 상품에 적용돼요.
  - 일회성 상품
  - 반복 결제 상품
- 쿠폰은 원클릭 업셀에는 적용되지 않아요(퍼널의 경우).
- 쿠폰으로 장바구니 금액이 $0이 될 수 있어요.
  - 빌더에서 이를 위한 설정을 켜 두었다면, 고객은 확인을 위해 카드 정보를 입력해야 해요. 빌더에 $0 거래를 관리하는 설정이 없으면 카드 정보를 항상 입력해야 해요.
- 100% 할인은 PayPal을 제외한 대부분의 결제 제공업체에서 지원해요.
- **쿠폰 코드**는 다음과 같아요.
  - 대소문자를 구분하지 않아요.
  - 고유해야 해요.
- 할인은 상품별로 비례해서 나누어 적용돼요.

## 자주 묻는 질문

### 쿠폰으로 무료 상품을 만들 수 있나요?

네, 100% 할인 쿠폰을 사용하면 돼요.

### 쿠폰을 나중에 수정하거나 삭제할 수 있나요?

네, 언제든 수정하거나 삭제할 수 있고 사용 내역도 확인할 수 있어요.

### 한 주문에서 일회성 상품과 구독 상품에 같은 쿠폰을 적용할 수 있나요?

네. 한 주문 안에서 일회성 상품과 반복 결제 상품 모두에 쿠폰이 적용돼요. 구독 상품에는 설정한 기간(예: 일회성, **여러 달**, **영구**)에 따라 쿠폰이 적용돼요.

### 수량이 여러 개인 상품에 쿠폰을 적용하면 어떻게 되나요?

할인은 해당 상품의 총액(수량 × 가격)을 기준으로 계산돼요. 예를 들어 20달러짜리 상품을 5개 구매하고 10% 쿠폰을 쓰면, 할인 금액은 $10(100달러의 10%)이에요.

### 이미 사용된 쿠폰도 수정할 수 있나요?

이름, 한도, 유효 기간 같은 일부 설정은 수정할 수 있어요. 다만 수정한 내용은 이후 사용분에만 적용되고, 쿠폰이 이미 적용된 이전 주문은 그대로예요.

### 셋업 비용에도 쿠폰이 적용되나요?

네. 구독 상품의 셋업 비용(Set-up Fee)에도 쿠폰이 적용돼요.

### PayPal에서 지원하지 않는 쿠폰 설정은 무엇인가요?

PayPal에서는 다음 설정을 지원하지 않아요.

1. **영구** 대신 개월 수를 정한 구독 설정은 PayPal에서 작동하지 않아요. 정해진 개월 동안만이 아니라 구독 전체 기간에 대해 결제가 이루어져요.

2. 주문 금액을 $0으로 만드는 쿠폰은, 결제에 구독 상품이 포함되어 있으면 PayPal에서 작동하지 않아요. 100% 할인 쿠폰이나, 최종 주문 금액이 $0이 되는 고정 금액 쿠폰이 여기에 해당해요.
