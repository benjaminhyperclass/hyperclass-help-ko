# 모바일 앱에서 정기 인보이스 자동 결제 설정하기

하이퍼클래스 모바일 앱에서 정기 인보이스를 보낼 때 자동 결제를 켜면, 정해진 일정에 맞춰 고객의 카드가 자동으로 결제돼요. 직접 독촉하지 않아도 제때 결제를 받을 수 있어요. 이 문서에서는 자동 결제가 무엇인지, POS와 어떻게 함께 쓰는지, 어떻게 설정하는지 안내해요.

## 정기 인보이스 자동 결제(모바일)란?

자동 결제는 하이퍼클래스 모바일 앱에서 보낸 **정기 인보이스**가 청구될 때마다 고객의 **카드**로 자동 결제하는 기능이에요. 결제에 쓸 카드는 직접 정해요. 이미 등록해 둔 **저장된 카드**를 쓰거나, 결제 과정에서 받아 둔 **고객 카드**를 쓸 수 있어요. 이후 결제는 정해 둔 일정에 따라 시스템이 처리해요.

## 사전 준비

- **인보이스** 또는 POS 모듈에서 만든 정기 인보이스가 있어야 해요.
- 고객의 결제 수단이 등록되어 있어야 해요(등록된 카드 또는 온라인 카드 등록).
- 카드 결제만 가능해요. 현금이나 수기 입력 결제에는 자동 결제를 쓸 수 없어요.

## 자동 결제의 장점

장점을 알아 두면 언제 자동 결제를 켜고 어떤 카드를 쓸지 정하기 쉬워요.

- 손 안 대고 결제 받기: 청구일마다 결제가 자동으로 진행돼요.
- 다양한 결제 카드 선택: 등록된 **저장된 카드**나 결제 중에 받아 둔 **고객 카드**를 고를 수 있어요.
- 고객 편의: 첫 결제 이후 고객이 따로 할 일이 없어요.
- 예측 가능한 현금 흐름: 정해진 날짜에 결제되므로 수익 공백이 줄어요.
- 관리 업무 감소: 일정을 만들 때 한 번만 설정하면 따로 독촉하거나 수동으로 결제할 필요가 없어요.

## 결제 수단 옵션

결제 카드를 알맞게 고르면 결제 성공률이 높아지고 결제 실패가 줄어요. 선택할 수 있는 옵션과 쓰기 좋은 상황은 다음과 같아요.

- **저장된 카드**: 연락처에 이미 저장된 카드로 결제해요. 등록된 카드가 있고, 한 번 설정해 두면 계속 안정적으로 결제되기를 원할 때 알맞아요.
- **고객 카드**: Tap to Pay, 등록된 카드, 온라인 결제 중에 받은 카드를 써요. 방금 현장이나 온라인에서 결제를 받았고, 같은 카드로 다음 결제 주기에도 이어서 결제하고 싶을 때 유용해요.

{% hint style="info" %}
모바일 자동 결제는 카드 결제만 지원해요. 현금과 수기 입력 결제는 자동 결제를 지원하지 않아요.
{% endhint %}

## 정기 인보이스 자동 결제 설정하기

설정을 올바르게 해 두면 일정에 맞춰 알맞은 카드로 결제가 이뤄져요. 모바일에서 정기 인보이스를 만들 때마다 아래 순서를 따라 하세요.

{% hint style="warning" %}
먼저 **인보이스** 또는 POS에서 정기 인보이스를 시작하고, 세부 정보와 고객, 항목, 청구 주기를 선택하세요. 이 단계는 [정기 인보이스 만들기](how-to-create-and-manage-recurring-invoices-in-hyperclass.md)를 참고하세요.
{% endhint %}

### 1단계: 자동 결제 켜기

일정 설정 화면에서 **Enable Auto-Payment**(자동 결제 사용) 토글을 켜세요.

![일정 설정 화면에서 자동 결제 토글을 켜는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052184061/original/87vR7wa99LIQY9kUJWs7amA6TQRRFzgO3A.png?1755875475)

### 2단계: 결제 수단 선택

결제에 쓸 카드를 골라요.

- **저장된 카드**: 저장된 결제 수단 중에서 선택해요.
- **고객 카드**: Tap to Pay나 온라인 결제 중에 받아 둔 결제 카드를 사용해요.

![자동 결제에 사용할 카드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052186809/original/_HRV8Cdr2amzy8dD1Pwk9rXs6kR7f8npCw.png?1755877242)

### 3단계: 선택한 카드 확인 후 보내기/일정 등록

카드를 선택하면 끝 4자리와 함께 카드 정보가 요약돼요. 다른 카드를 쓰려면 **Change Card**(카드 변경)를 누르세요. 확인이 끝나면 **보내기**(또는 **일정**)를 눌러 자동 결제가 켜진 정기 인보이스를 시작하세요. 이후에는 정해 둔 청구일마다 시스템이 자동으로 결제해요.

![선택한 카드를 확인하고 보내기를 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052186888/original/nx7nGrX6WK9NsEJyo0HvWJGp7PKIvgas5g.png?1755877318)

## 자주 묻는 질문

### 자동 결제로 현금, 수기 입력, 은행 결제도 받을 수 있나요?
아니요. 모바일에서 자동 결제는 카드 결제만 지원해요.

### 모바일에서 자동 결제는 어디서 켜나요?
정기 인보이스의 보내기/일정 화면에서 켜요. **Enable Auto-Payment** 토글을 켜고 카드 종류를 선택하세요.

### 자동 결제를 POS와 함께 쓸 수 있나요?
네. 정기 상품이 담긴 POS 장바구니가 인보이스로 전환되면 쓸 수 있어요. 일정을 설정할 때 자동 결제를 켜세요.

### 저장된 카드와 고객 카드는 어떻게 다른가요?
**저장된 카드**는 연락처에 이미 저장되어 있는 카드예요. **고객 카드**는 Tap to Pay, 등록된 카드, 온라인 결제 중에 받은 카드예요.

### 자동 결제에 쓰는 카드를 바꾸려면 어떻게 하나요?
인보이스를 보내기 전에 **Change Card**를 선택하세요. 그런 다음 다른 **저장된 카드**를 고르거나, 새 카드를 받은 뒤 **고객 카드**를 선택하면 돼요.

### 예약된 결제가 실패하면 어떻게 하나요?
고객과 함께 등록된 카드를 업데이트하고, 새 카드를 선택해 일정을 이어 가세요. 카드를 최신 상태로 유지하면 이후 결제 실패를 줄일 수 있어요.

### 정기 인보이스를 설정하거나 편집할 때 자동 결제 관리 옵션은 어디에 있나요?
자동 결제를 켜거나 끄고, 자동 결제에 쓸 고객의 저장된 카드를 관리하는 옵션은 인보이스 편집 화면 안에 있어요. 숨겨진 메뉴에서 찾을 수 있어요.

1. 기존 정기 인보이스나 새 정기 인보이스를 열어요(일회성 인보이스를 정기 인보이스로 전환해도 돼요).
2. 인보이스 편집 화면 오른쪽 위에서 점 세 개(⋮) 메뉴를 찾아요.
3. 점 세 개(⋮)를 누르고 **자동 결제 관리**를 선택하세요.
4. 이 화면에서 고객의 저장된 카드를 선택하거나 새 카드를 추가하고, 앞으로의 모든 정기 결제에 자동 결제를 켤 수 있어요.
