# 인보이스·영수증 PDF 생성 속도 개선

인보이스와 영수증 PDF를 만드는 시스템이 새로 개선됐어요. 이 문서에서는 개선된 내용과 달라진 성능을 안내해요. PDF를 내려받거나 이메일로 보내는 모든 과정이 더 빠르고 안정적으로 동작해요.

## PDF 생성 시스템이란?

PDF 생성 시스템은 인보이스와 영수증을 PDF 문서로 만들어 주는 시스템이에요. 내려받거나 이메일로 보낼 수 있는 형태로 문서를 만들어요. 화면에서 인보이스를 바로 내려받을 때나, 자동화된 워크플로우로 영수증을 보낼 때 이 시스템이 쓰여요.

고객이 결제와 청구 내역을 정확한 문서로 제때 받으려면 꼭 필요한 시스템이에요.

## 개선으로 달라진 점

속도와 안정성이 크게 좋아졌어요. 직접 내려받을 때도, 인보이스와 영수증을 이메일로 보내는 자동화 워크플로우에서도 효과가 나타나요.

- PDF 한 건을 만드는 평균 시간이 약 80% 줄었어요.
- P95 지연 시간이 75% 줄었어요. 요청이 몰리는 상황에서도 더 빠르게 응답해요.
- 운영 환경에서 시간 초과로 인한 실패가 모두 사라졌어요.
- 인보이스·영수증 워크플로우가 이전보다 빠르고 안정적으로 끝나요.
- PDF가 생성되지 않거나 누락되어 들어오는 지원 문의가 줄었어요.
- 문서가 거의 즉시 전달되어 고객의 신뢰와 만족도가 높아졌어요.

## 새 PDF 엔진 사용하기

따로 해야 할 일은 없어요. 개선 사항은 이미 플랫폼 전체에 적용되어 있고, 관련된 모든 경우에 바로 반영돼요.

- 화면에서 인보이스와 영수증을 내려받을 때 속도가 훨씬 빨라졌어요.
- 연락처에게 영수증이나 인보이스를 이메일로 보내는 자동화 워크플로우가 시간 초과 오류 없이 끝나요.
- 설정을 바꾸거나 업데이트할 필요가 없어요.

## 성능 비교

새 PDF 생성 시스템 적용 전후의 성능을 표로 정리했어요.

| 항목 | 개선 전 | 개선 후 | 개선율 |

## 자주 묻는 질문

### 개선된 시스템을 쓰려면 따로 켜거나 설정해야 하나요?
아니요. 새 시스템은 이미 켜져 있어요. 인보이스와 영수증 PDF가 쓰이는 모든 워크플로우와 다운로드에 적용돼요.

### PDF가 생성되지 않거나 늦게 만들어지면 어떻게 하나요?
적용 이후 시간 초과로 생기는 문제는 모두 해결됐어요. 새로 생기는 문제는 다른 원인일 수 있으니 하이퍼클래스 고객지원에 문의해 주세요. 자세히 확인해 드려요.

### 기존 워크플로우도 자동으로 개선되나요?
네. 인보이스나 영수증 PDF를 만들거나 이메일로 보내는 액션이 들어 있는 워크플로우는 자동으로 개선 효과를 받아요.

### 속도가 얼마나 빨라졌는지 직접 확인할 수 있나요?
네. 인보이스를 직접 내려받아 보거나, 워크플로우로 영수증 이메일을 보내 보면 빨라진 속도를 느낄 수 있어요.

### 이번 변경이 다른 문서 유형에도 영향을 주나요?
아니요. 이번 업데이트는 인보이스와 영수증 PDF에만 적용돼요. 다른 문서 유형은 영향을 받지 않아요.
