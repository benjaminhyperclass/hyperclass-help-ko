# Layout AI Builder로 사용자 지정 인보이스 레이아웃 만들기

**Layout AI Builder**(레이아웃 AI 빌더)는 문장으로 설명하거나 기존 인보이스 디자인을 올리면 사용자 지정 인보이스 레이아웃을 만들어 주는 기능이에요. 결과물은 AI로 다듬거나 비주얼 빌더에서 직접 편집할 수 있어요. 레이아웃을 여러 개 게시하고, 버전 기록을 관리하고, 인보이스를 만들 때 게시된 디자인을 골라 쓸 수 있어요. 이 문서에서는 실험실 활성화부터 인보이스에 적용하기까지의 전체 과정을 설명해요.

## Layout AI Builder란?

**Layout AI Builder**는 하이퍼클래스에서 사용자 지정 인보이스 디자인을 만들고 관리하는 **실험실**(Labs) 기능이에요. AI가 디자인을 생성해 주고, 비주얼 편집기, 버전 관리, 게시, 인보이스별 레이아웃 선택 기능을 함께 쓸 수 있어요.

원하는 인보이스를 글로 설명해서 시작할 수도 있고, 기존 인보이스를 올려서 AI가 다시 만들게 할 수도 있어요. 디자인이 생성된 뒤에는 Layout AI에 계속 요청하거나 직접 편집하면 돼요.

전체 흐름은 다음과 같아요.

만들기 → 다듬기 → 미리보기 → 게시 → 인보이스에서 선택

**Layout AI Builder**는 기존 서브 계정의 인보이스 사용자 지정 설정과는 별개예요. 기존 설정은 지금처럼 인보이스 브랜딩, 레이블, 필드 표시 여부를 관리해요.

사용자 지정 레이아웃은 일회성 인보이스와 반복 인보이스 모두에서 쓸 수 있어요.

{% hint style="info" %}
**Layout AI Builder**는 현재 인보이스만 지원해요.
{% endhint %}

자세한 내용은 [인보이스 레이아웃 사용자 지정](customizing-invoice-layouts.md) 문서도 함께 참고하세요.

## Layout AI Builder의 주요 장점

AI 생성과 직접 편집 도구를 함께 쓸 수 있어서, 인보이스 디자인을 매번 처음부터 만들지 않아도 여러 가지로 운영할 수 있어요.

- **AI로 만들기**: 원하는 인보이스 레이아웃을 자연어로 설명하면 Layout AI가 만들어 줘요.
- 기존 디자인 다시 만들기: 이미 쓰고 있는 인보이스를 첨부하거나 설명해서, 빈 레이아웃에서 시작하지 않고 만들 수 있어요.
- **AI로 다듬기**: 첫 버전이 만들어진 뒤에도 Layout AI에 계속 요청해서 수정할 수 있어요.
- 시각적으로 편집하기: 레이아웃 요소를 직접 추가, 제거, 정렬, 수정할 수 있어요.
- 이전 버전 복원하기: AI가 변경할 때마다 복원 지점이 만들어지고, 채팅에서 그 시점으로 돌아갈 수 있어요.
- 빌더 변경 되돌리기: 도구 모음의 **실행 취소**로 직접 편집한 내용을 되돌릴 수 있어요.
- 여러 레이아웃 관리하기: 고객, 서비스, 업무 상황에 맞춰 인보이스 디자인을 따로 둘 수 있어요.
- 레이아웃 활동 확인하기: 누가 언제 레이아웃을 만들고, 편집하고, 게시하고, 복사했는지 볼 수 있어요.
- 인보이스별로 레이아웃 적용하기: 인보이스 편집기에서 게시된 디자인을 선택할 수 있어요.
- 이미 발송한 인보이스 보존하기: 레이아웃을 삭제해도 이미 발송된 인보이스는 바뀌지 않아요.

## Layout AI Builder 설정하기

먼저 실험실 기능을 활성화한 다음, **인보이스 & 견적서** 아래의 레이아웃 작업 공간을 열어요. 실험실 기능에 대한 자세한 설명은 [실험실 기능 전체 개요](../../19-에이전시-뷰/Agency-Settings/labs-features-complete-overview.md)를 참고하세요.

### 레이아웃 페이지 열기

**레이아웃** 페이지는 사용자 지정 인보이스 레이아웃을 만들고, 게시하고, 관리하는 중심 작업 공간이에요.

1. **결제**로 이동해요.
2. **인보이스 & 견적서**를 열어요.
3. **레이아웃**을 선택해요.

화면 제목은 **인보이스 레이아웃**이고, **Layout AI** 입력창, 레이아웃 관리 기능, 기존 레이아웃 카드가 보여요.

![레이아웃 페이지 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083544019/original/Hj48ZanO2ToKNk7bTDwW0lILvM8u7zxzyQ.png?1792170111)

### AI로 인보이스 레이아웃 만들기

**Layout AI**(레이아웃 AI)는 글로 쓴 설명을 편집할 수 있는 인보이스 레이아웃으로 바꿔 줘요.

{% hint style="info" %}
Layout AI는 현재 **브랜드 보드**의 브랜딩을 가져오지 않아요. 원하는 색상은 AI 프롬프트에 직접 설명하거나, 비주얼 빌더의 **스타일** 섹션에서 조정하세요.
{% endhint %}

1. **결제 > 인보이스 & 견적서 > 레이아웃**을 열어요.
2. **Layout AI** 입력창에 원하는 인보이스 디자인을 입력해요.
3. 필요하면 **A4** 같은 페이지 크기를 선택해요.
4. 프롬프트를 제출해요.
5. Layout AI가 디자인을 생성할 때까지 기다려요.
6. 편집기에서 생성된 레이아웃을 확인해요.

프롬프트는 최대 1,000자까지 입력할 수 있어요.

**레이아웃** 페이지에는 **SaaS subscription**(SaaS 구독), **Product sales invoice**(상품 판매 인보이스), **Boutique store invoice**(부티크 매장 인보이스), **Add service items**(서비스 항목 추가) 같은 시작용 추천 문구도 있어요.

![AI로 인보이스 레이아웃을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083544365/original/G7a7oVH4YL2YTWuor5H0HLJA1LxgCv7oTA.png?1792170425)

### 기존 인보이스 레이아웃 다시 만들기

Layout AI는 기존 인보이스를 출발점으로 삼아 새 디자인을 만들 수도 있어요.

1. **결제 > 인보이스 & 견적서 > 레이아웃**으로 이동해요.
2. **Layout AI** 입력창에서 첨부 아이콘을 클릭해요.
3. Layout AI가 참고할 기존 인보이스를 첨부해요.
4. 인보이스를 어떻게 다시 만들거나 조정할지 설명을 입력해요.
5. 요청을 제출해요.
6. 생성된 레이아웃을 확인해요.

파일을 첨부하지 않고 기존 인보이스를 글로 설명해도 돼요.

{% hint style="info" %}
업로드할 수 있는 파일: PNG, JPG, WEBP, SVG, PDF 중 하나를 3MB 이하로 1개 올릴 수 있어요.
{% endhint %}

![기존 인보이스를 첨부하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083544597/original/hZlJx9PDg9wwPKafxrcDcL016nJ6VIbhag.png?1792170719)

## 인보이스 레이아웃 다듬기와 미리보기

레이아웃이 생성된 뒤에는 AI로 계속 다듬거나, 직접 편집으로 전환해서 더 세밀하게 조정할 수 있어요.

### Layout AI로 계속 편집하기

생성된 디자인 옆에 Layout AI가 계속 표시돼서 추가 변경을 요청할 수 있어요.

1. **Plan, build, modify anything...**(무엇이든 계획하고, 만들고, 수정하세요...) 입력창을 사용해요.
2. 원하는 변경 내용을 설명해요.
3. 요청을 제출해요.
4. 업데이트된 레이아웃을 확인해요.
5. 원하는 결과가 나올 때까지 계속 요청해요.

AI가 변경할 때마다 복원 지점이 만들어져요.

{% hint style="info" %}
AI 응답에 좋아요나 싫어요를 눌러 주면 이후 결과를 개선하는 데 도움이 돼요.
{% endhint %}

![Layout AI로 레이아웃을 계속 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083545029/original/0wExO58y9o6O-35g0LhkN2HQejxMwmmJIA.png?1792171134)

### 비주얼 빌더에서 레이아웃 편집하기

비주얼 빌더에서는 AI 프롬프트 없이 레이아웃을 직접 바꿀 수 있어요.

1. 생성된 레이아웃을 열어요.
2. **+** 버튼을 클릭해 **Add elements**(요소 추가)를 열어요.
3. 요소를 검색하거나 카테고리에서 골라요.
4. 디자인에 필요한 요소를 추가하고 배치해요.
5. 구조와 내용이 준비될 때까지 계속 편집해요.

![요소 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083545255/original/8SQq8_Q5ijNuojVW44g_Xv7VM3eIT2SKKw.png?1792171290)

레이아웃에서 요소를 선택하면 오른쪽에 속성 패널이 열려요. **콘텐츠**, **스타일**, **고급** 탭에서 해당 요소의 설정을 조정할 수 있어요.

![요소 속성 패널 사용 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084738102/original/5spkdxA2tLZOLFQ_X1zx4sTpOACFBQOovw.gif?1793621843)

### HTML 및 CSS 코드 편집기

레이아웃의 HTML과 CSS를 직접 편집할 수도 있어요. 위쪽 도구 모음에서 **Code (</>)**(코드)를 클릭한 다음, **HTML**과 **CSS** 탭을 오가며 수정하세요.

![HTML 및 CSS 코드 편집기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084738773/original/0b2x7z-uHawOCfz6JYUEEopKyepMDxgYOA.png?1793622203)

### 직접 변경한 내용 되돌리기

편집기 도구 모음에는 직접 변경한 내용을 되돌리는 기능이 있어요.

가장 최근에 빌더에서 편집한 내용을 되돌리려면 위쪽 도구 모음의 **실행 취소** 아이콘을 사용하세요.

### 레이아웃 미리보기

게시하기 전에 미리보기로 디자인이 인보이스 데이터와 어떻게 어울리는지 확인할 수 있어요.

1. 레이아웃 편집기를 열어요.
2. **미리보기**를 클릭해요.
3. 샘플 인보이스 데이터로 디자인을 보려면 **Sample Invoice**(샘플 인보이스) 선택 상자를 사용해요.
4. 게시하기 전에 레이아웃을 확인해요.

## 인보이스 레이아웃 게시하기

게시하면 인보이스에서 쓸 수 있는 버전이 만들어져요. 게시한 뒤에도 계속 편집할 수 있지만, 이후 편집 내용은 레이아웃을 다시 게시해야 적용돼요.

1. 완성된 레이아웃을 확인해요.
2. 오른쪽 위에서 **게시**를 클릭해요.
3. **Publish layout**(레이아웃 게시) 대화상자를 확인해요.
4. 원하면 **변경 사항**(선택 사항) 입력란에 메모를 입력해요.
5. **Publish layout**을 클릭해요.

![레이아웃 게시 대화상자](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083545469/original/9B-1ws4nE_lR-dKcYgJ7-il81O8GBq-zDA.png?1792171581)

### 다운로드 옵션

빌더 안에서 레이아웃 인보이스 템플릿을 다운로드할 수 있어요.

![레이아웃 템플릿 다운로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083544482/original/AzPtHRulPpatOIWIJGTkvSYXVDS0ocPCPg.png?1792170568)

## 인보이스 레이아웃 관리하기

**레이아웃** 페이지에서는 만든 사용자 지정 인보이스 레이아웃을 한곳에서 찾고, 미리 보고, 편집하고, 복사하고, 기록을 확인할 수 있어요.

### 레이아웃 찾기와 정리하기

검색과 보기 옵션으로 사용자 지정 인보이스 레이아웃을 찾고 정리할 수 있어요.

**결제 > 인보이스 & 견적서 > 레이아웃**에서 다음을 할 수 있어요.

- **Search by layout name**(레이아웃 이름으로 검색)을 사용해요.
- **필터 추가**를 클릭해요.
- **정렬 기준**을 클릭해요.
- 이름이나 마지막 업데이트 날짜 같은 기준으로 레이아웃을 정렬해요.
- 그리드 보기와 **목록** 보기를 전환해요.

### 레이아웃 편집, 미리보기, 복제, 이름 변경, 삭제하기

게시된 레이아웃 카드마다 디자인을 다루는 기능이 바로 표시돼요.

- **편집**을 클릭하면 레이아웃 편집기가 열려요.
- **미리보기**를 클릭하면 디자인을 확인할 수 있어요.
- 점 세 개 메뉴를 열어 다음 중에서 선택해요.
  - **기록 보기**
  - **이름 변경**
  - **복제**
  - **삭제**

카드에는 레이아웃 이름, 페이지 크기, 게시된 버전, 업데이트 날짜와 시간도 표시돼요.

{% hint style="info" %}
레이아웃을 복제하면 초안 사본이 만들어져요. 복제한 레이아웃은 게시해야 인보이스에서 선택할 수 있어요.
{% endhint %}

![레이아웃 카드와 관리 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083558011/original/A-Ux-pIW9yiT3tTnno64d59ZncI-FgEqww.png?1792196594)

### 레이아웃 기록 보기

레이아웃 기록에서는 레이아웃의 주요 변경 내역을 확인할 수 있어요.

1. 레이아웃 카드에서 점 세 개 메뉴를 열어요.
2. **기록 보기**를 클릭해요.
3. **View layout history**(레이아웃 기록 보기) 패널을 확인해요.

기록에는 다음 정보가 표시될 수 있어요.

- 작업을 수행한 사용자
- 사용자의 이메일 주소
- 수행한 작업
- 날짜
- **생성일**, **수정됨**, **게시됨** 같은 상태 레이블

![레이아웃 기록 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083558641/original/yXdWpU8X5y9JjrcxJiK9Qv47yWlAMjNJxg.png?1792201909)

## 게시된 레이아웃을 인보이스에 적용하기

인보이스를 새로 만들거나 초안 인보이스를 편집할 때 게시된 레이아웃을 선택할 수 있어요. 선택한 디자인이 해당 인보이스의 레이아웃이 돼요.

1. **결제 > 인보이스 & 견적서 > 전체 인보이스**로 이동해요.
2. 새 인보이스를 만들거나 초안 인보이스를 열어요.
3. **인보이스 설정**에서 **인보이스 레이아웃**을 찾아요.
4. **인보이스 레이아웃** 드롭다운을 열어요.
5. 사용할 게시된 레이아웃을 선택해요.
6. 보내기 전에 인보이스 레이아웃을 확인해요.

선택 목록에는 **Default Layout**(기본 레이아웃)과 사용할 수 있는 게시된 사용자 지정 레이아웃이 함께 표시돼요.

**레이아웃** 작업 공간으로 돌아가려면 선택 목록 옆의 **Manage layouts**(레이아웃 관리)를 클릭하세요.

{% hint style="info" %}
사용자 지정 레이아웃은 현재 기본 인보이스 레이아웃으로 설정할 수 없어요. 인보이스를 만들 때마다 원하는 사용자 지정 레이아웃을 직접 선택해야 해요.
{% endhint %}

편집기 오른쪽의 미리보기로 레이아웃 구조를 확인할 수 있어요. 고객에게 보이는 실제 결과를 보려면 인보이스를 저장한 뒤, **저장** 옆 메뉴에 있는 **미리보기**를 사용하세요.

인보이스를 만들고 보내는 방법은 [인보이스 만들고 보내기](../invoices-new-revamped-ui.md)와 [하이퍼클래스로 첫 인보이스 보내기](how-to-send-your-first-invoice-using-hyperclass.md)를 참고하세요.

## 인보이스를 사용한 뒤의 레이아웃 동작

인보이스가 초안 단계를 넘어가면 레이아웃 동작이 달라져요. 이 규칙은 고객에게 보이는 인보이스의 디자인을 그대로 유지하고, 기존 인보이스 기록을 보호해요.

### 인보이스가 발송되었거나 부분 결제되었을 때

인보이스가 발송되거나 **부분 결제됨** 상태가 되면 선택한 인보이스 레이아웃이 잠겨요.

이 잠금은 선택한 레이아웃에만 적용돼요. 부분 결제 후에 모든 인보이스 필드를 편집할 수 없다는 뜻은 아니에요. 하이퍼클래스에서는 부분 결제된 인보이스의 편집 가능한 세부 정보를 별도로 수정할 수 있어요. 자세한 내용은 [부분 결제된 인보이스의 유연한 편집](flexible-invoice-editing-for-partially-paid-invoices.md)을 참고하세요.

### 레이아웃을 삭제했을 때

사용자 지정 레이아웃을 삭제하면 초안 인보이스와 발송된 인보이스에 미치는 영향이 달라요.

- 이미 발송된 인보이스는 원래 디자인 그대로 표시돼요.
- 삭제된 레이아웃을 쓰던 초안 인보이스는 기본 레이아웃으로 바뀌어요.

아직 사용 중인 레이아웃을 삭제하기 전에 영향을 받는 초안을 확인하세요.

## 자주 묻는 질문

### Layout AI Builder를 사용하기 전에 활성화해야 하나요?
네. **설정 > 실험실 > 서브 계정**으로 이동해서 **AI-Powered Custom Invoice Layouts**(AI 기반 사용자 지정 인보이스 레이아웃)를 검색한 다음 **기능 활성화**를 클릭하세요.

### 글로 설명해서 인보이스 레이아웃을 만들 수 있나요?
네. **Layout AI**에 자연어로 설명을 입력하고 프롬프트를 제출하면 레이아웃이 생성돼요.

### 인보이스 & 견적서 아래에 레이아웃 메뉴가 안 보여요.
서브 계정에서 실험실 기능이 활성화되지 않았으면 **레이아웃** 메뉴가 보이지 않을 수 있어요. **설정 > 실험실 > 서브 계정**으로 이동해서 **AI-Powered Custom Invoice Layouts**를 검색한 다음 **기능 활성화**를 클릭하세요.

### 브랜드 보드 색상이 적용되지 않아요.
**Layout AI Builder**는 현재 브랜드 보드 연동을 지원하지 않아요. 당분간은 원하는 색상을 AI 프롬프트에 설명하거나, 비주얼 빌더의 **스타일** 섹션에서 조정하세요.

### 사용자 지정 레이아웃이 인보이스에 나타나지 않아요.
사용자 지정 레이아웃은 게시해야 선택할 수 있어요. 이미 발송한 인보이스에서는 선택한 레이아웃을 바꿀 수도 없어요. 레이아웃이 게시되었는지, 인보이스가 아직 초안 상태인지 확인하세요.

### 인보이스 참고 파일이 업로드되지 않아요.
파일이 PNG, JPG, WEBP, SVG, PDF 형식이고 3MB를 넘지 않는지 확인하세요. 한 번에 파일 하나만 올릴 수 있어요.

### 지금 쓰는 인보이스 디자인을 다시 만들 수 있나요?
네. 기존 인보이스를 첨부하거나, Layout AI가 다시 만들 디자인을 글로 설명하면 돼요.

### AI가 만든 레이아웃을 직접 편집할 수 있나요?
네. 비주얼 빌더에서 지원하는 요소를 추가, 제거, 배치, 편집할 수 있어요.

### 이전에 AI가 만든 버전으로 돌아갈 수 있나요?
네. AI가 변경할 때마다 복원 지점이 만들어지므로 이전 버전으로 돌아갈 수 있어요.

### 레이아웃은 언제 게시할 수 있나요?
레이아웃에 내용이 있으면 **게시**를 사용할 수 있어요.

### 게시한 뒤에도 계속 편집할 수 있나요?
네. 계속 편집하는 동안에도 게시된 버전은 그대로 유지돼요. 이후 편집 내용은 레이아웃을 다시 게시해야 적용돼요.

### 인보이스 레이아웃을 여러 개 만들 수 있나요?
네. **레이아웃** 페이지에서 고객, 서비스, 업무 상황에 맞는 사용자 지정 레이아웃을 여러 개 만들 수 있어요.

### 인보이스를 발송하거나 부분 결제된 뒤에는 레이아웃이 어떻게 되나요?
해당 인보이스에서는 선택한 레이아웃이 잠겨요.

### 이미 사용 중인 레이아웃을 삭제하면 어떻게 되나요?
발송된 인보이스는 원래 디자인을 유지해요. 삭제된 레이아웃을 쓰던 초안 인보이스는 기본 레이아웃으로 바뀌어요.
