# 모바일 앱에서 템플릿으로 견적서 만들기 (v3.98.1)

하이퍼클래스 웹 앱에서 팀이 만들어 둔 템플릿을 모바일 앱에서 불러와 견적서를 빠르게 만들 수 있어요. 이 문서에서는 기능 소개, 장점, 사용 조건, 사용 방법과 자주 묻는 질문을 안내해요.

---

---

## 모바일에서 템플릿으로 견적서 만들기란?

모바일 앱에서 하이퍼클래스 웹 앱에 저장된 견적서 템플릿으로 새 견적서를 시작할 수 있는 기능이에요. 모바일 앱이 웹에서 만든 템플릿을 그대로 불러오기 때문에, 영업 담당자가 레이아웃, 항목, 약관을 처음부터 다시 만들지 않아도 돼요. 덕분에 일정한 형식의 견적서를 실수 없이 만들 수 있어요.

---

## 주요 장점

템플릿은 속도, 브랜드 일관성, 일정한 가격 표기가 필요할 때 특히 유용해요. 빌더에서 처음부터 만들지, 템플릿을 쓸지 고를 때 참고하세요.

- 시간 절약: 만들어 둔 템플릿으로 몇 번만 눌러 새 견적서를 만들 수 있어요.
- 일관성: 담당자가 달라도 브랜딩, 섹션 구성, 가격 표기 형식을 똑같이 유지할 수 있어요.
- 이동성: 고객을 만나는 자리에서 바로 견적서를 만들어 보낼 수 있어요.
- 간편한 접근: 웹에서 만든 템플릿을 모바일에서 자동으로 쓸 수 있어요.
- 전문성: 수작업 실수를 줄이고 매번 깔끔한 견적서를 보낼 수 있어요.

---

## 사용 조건

미리 확인해 두면 나중에 설정 문제를 피할 수 있어요. 앱 버전과 템플릿을 관리하는 곳을 확인하세요.

- 모바일 앱 버전: 하이퍼클래스 모바일 앱 v3.98.1
- 화이트라벨 앱: 담당 매니저 또는 고객지원에 v3.98.1 업데이트를 요청하세요.
- 템플릿은 웹에서 만들고 관리해요. 모바일에서는 템플릿을 사용할 수만 있고, 만들거나 편집하거나 삭제할 수는 없어요.
- 사용자에게 해당 서브 계정과 **결제 > 견적서** 접근 권한이 있어야 해요.

## 자주 묻는 질문

### 모바일 앱에서 견적서 템플릿을 만들거나 편집할 수 있나요?

아니요. 템플릿은 웹에서 만들고 관리해요. 모바일 앱에서는 그 템플릿으로 새 견적서를 만들 수 있어요.

### 웹에서 만든 템플릿이 모바일 앱에서도 자동으로 보이나요?

네. 웹에서 만든 템플릿은 모바일 앱의 **템플릿** 탭에 나타나요.

### 어떤 버전에서 이 기능을 쓸 수 있나요?

하이퍼클래스 모바일 앱 v3.98.1부터 쓸 수 있어요. 화이트라벨 앱은 v3.98.1 업데이트를 요청한 뒤에 쓸 수 있어요.

### 템플릿을 고른 뒤에 항목을 바꿀 수 있나요?

네. 견적서를 보내기 전에 수량이나 가격처럼 수정할 수 있는 필드를 새 견적서에서 편집할 수 있어요.

### **템플릿** 탭이 보이지 않아요. 무엇을 확인해야 하나요?

앱 버전이 v3.98.1인지, 올바른 서브 계정에 들어와 있는지, 사용자에게 **결제 > 견적서** 접근 권한이 있는지 확인하세요. 화이트라벨 앱이라면 v3.98.1 빌드가 배포되었는지도 확인하세요.

### 템플릿의 첨부파일도 모바일에서 그대로 적용되나요?

첨부파일은 일반 견적서·템플릿 규칙을 따라요. 자세한 내용과 제한은 아래에 링크된 **첨부파일** 문서를 참고하세요.
### 고객이 견적서를 수락할 때 바로 결제받으려면 어떻게 하나요?

모바일 견적서에서 **Direct Payments**(직접 결제)를 사용하세요. 고객이 한 번에 수락하고 결제할 수 있어요. 자세한 방법은 [모바일 앱에서 견적서의 직접 결제 사용하기](../../30-모바일-데스크톱/Mobile-Payments/how-to-use-direct-payments-in-estimates-in-the-mobile-app.md) 문서를 참고하세요.
