# Xero 연동 후 계정과목표(Chart of Accounts) 전체 보기

Xero를 연결했는데 하이퍼클래스에서 **Chart of Accounts**(계정과목표)가 보이지 않을 때 보는 문서예요. Xero에서 계정의 결제 옵션을 켜면 하이퍼클래스에서 그 계정을 볼 수 있어요.

{% hint style="info" %}
Xero 화면은 Xero에서 쓰는 영어 이름 그대로 안내해요.
{% endhint %}

## 1단계: Xero에서 설정 열기

1. Xero 대시보드에서 조직을 선택하세요.
2. 드롭다운 메뉴에서 **Settings**(설정)를 클릭하세요.

![Xero 드롭다운 메뉴에서 설정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052650330/original/5_XZCY86_ZHc2dPXrhldibblRqN87dogZA.png?1756455000)

## 2단계: 고급 설정 열기

1. **Organization settings**(조직 설정) 화면에서 아래로 스크롤하세요.
2. **Looking for advanced settings?**(고급 설정을 찾고 계신가요?)를 클릭하세요.

![조직 설정 화면에서 고급 설정 링크를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052650367/original/jBCzMxCrQomq1eUS8pNZtOUgBhzh22z9DA.png?1756455020)

## 3단계: 계정과목표 열기

1. **Advanced Accounting**(고급 회계) 아래에서 **Chart of accounts**(계정과목표)를 클릭하세요.

![고급 회계 아래의 계정과목표 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052650378/original/xKkZ8mHLKOSt3o5JuFCY_pOU-V_6JpdnPg.png?1756455037)

## 4단계: 연결할 계정 선택하기

1. 계정 목록에서 연결할 계정을 고르세요. 예를 들어 "Prepayments"를 고를 수 있어요.
2. **Edit the details of this account**(이 계정의 세부 정보 편집)를 클릭하세요.

![계정 목록에서 계정을 선택하고 세부 정보 편집을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052650391/original/jbHFs4sPiZLTfRSD3pueoBxuMUYgOID8dg.png?1756455051)

## 5단계: 계정에 결제 활성화하기

1. 편집 팝업에서 **Enable payments to this account**(이 계정으로 결제 활성화)를 체크하세요.
2. **Save**(저장)를 클릭하세요.

![편집 팝업에서 결제 활성화를 체크하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052650409/original/hGFDs2N5-dDy7YwODn13cQrfz_fUPSys4g.png?1756455070)

## 6단계: 하이퍼클래스에서 연결하기

1. 하이퍼클래스의 Xero 연동 화면으로 돌아가세요.
2. **연결된 계정**에서 방금 결제를 활성화한 계정을 선택하세요. 예를 들어 "Prepayments"를 선택해요.

![하이퍼클래스 Xero 연동에서 연결된 계정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052650454/original/gnKyh9uVAVrjp1XMuFF9QxOSivfo0RJgaw.png?1756455111)

✅ 여기까지 마치면 하이퍼클래스에서 계정과목표가 보이고, 바로 사용할 수 있어요.
