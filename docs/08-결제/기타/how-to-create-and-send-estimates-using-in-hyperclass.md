# 견적서 만들고 보내기

최종 인보이스를 보내기 전에 견적서를 만들어 고객과 공유할 수 있어요. 이 문서에서는 견적서를 만들고 보내는 방법, 결제 일정을 추가하는 방법, 수락된 견적서를 인보이스로 바꾸는 방법을 안내해요.

## 새로 생긴 기능

- 견적서 기능이 새로 나왔어요.
- 견적서를 만들어 고객에게 먼저 공유할 수 있어요. 최종 인보이스는 그다음에 보내면 돼요.
- 고객은 견적서를 간단히 수락하거나 거절할 수 있어요.
- 견적서를 바로 인보이스로 바꿔서 보낼 수 있어요.

## 사용 방법

### 견적서 열기

1. 서브 계정에서 **결제**를 선택해요.
2. **인보이스 & 견적서**를 클릭한 뒤 **견적서**를 선택해요.

![견적서 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906697/original/4iDRwJTvq3KG8ZYtl61ONnuZOXECOU24eQ.jpeg?1727834340)

### 견적서 만들기

1. **신규** 버튼을 클릭해요.
2. 사업자 정보, 고객 정보, 견적서 번호, 만료일 같은 내용을 입력해요.

![견적서 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906696/original/mzTO1YnsOF0euWT0oywMMcnZpt0Y0lReuw.jpeg?1727834340)

3. **상품 추가**를 클릭해 견적서에 상품을 추가해요.
4. **보내기**를 클릭해요.
5. 견적서 내용을 확인한 뒤 이메일이나 SMS로 고객에게 바로 보내요.

![견적서 보내기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906695/original/HsB6j0eymE8lDG4fCzwSrC1l41G14O0Uag.jpeg?1727834340)
![견적서 발송 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906688/original/NGuK4JCPQyeCn09P-s03sMBbEWXGHeG4-A.jpeg?1727834340)

### 견적서에 결제 일정 추가하기

**결제 일정**을 쓰면 견적서 금액을 여러 번에 나눠 받을 수 있어요. 비율이나 고정 금액으로 나눌 수 있고, 회차마다 결제 기한도 정할 수 있어요.

#### 결제 일정 설정하기

1. **결제 > 인보이스 & 견적서 > 견적서**로 이동해 견적서를 새로 만들거나 기존 견적서를 열어요.
2. **Amount Due**(결제 금액) 아래에서 **결제 일정 추가**를 클릭해요.

   ![결제 일정 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084540511/original/lkI1_1OnZxCQ2PbUb7EFwFB-4OdWifLBmA.png?1793297741)
3. **Percentage**(비율) 또는 **고정 금액**을 선택하고, 결제 금액이나 비율과 **결제 횟수**를 입력해요.
4. **결제 구성**에서 다음을 설정해요.
   - **첫 결제**: **견적서 수락 시** 또는 **Custom Date**(지정 날짜)
   - **후속 결제**: **Regular intervals**(일정 간격) 또는 **Custom Date**(지정 날짜)
5. 나눠진 결제 내역을 확인하고 **일정 추가**를 클릭해요.

   ![결제 일정 구성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084540526/original/EaMAhxqIZzNXEMsJb_mZbjE8_zWuFB4-Iw.png?1793297782)

설정한 일정은 **Amount Due** 아래에 표시돼요. 일정을 고치려면 **결제 일정 변경**을 클릭하세요.

#### 견적서 미리보기와 보내기

1. 견적서 미리보기에서 회차별 금액과 결제 기한을 확인해요.

   ![견적서 미리보기의 결제 일정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084540535/original/_s7uYqyxiuo4kDvefgWGq35duvUqFimwCA.png?1793297822)
2. **추가 옵션**에서 **인보이스 보내기**를 선택하고 **직접 결제 켜기**를 켜요.
3. **저장**한 뒤 견적서를 보내요.

#### 고객이 수락하면 어떻게 되나요?

고객이 견적서를 수락하면 하이퍼클래스가 자동으로 인보이스를 만들고, 고객을 인보이스 결제 페이지로 이동시켜요.

인보이스에는 회차별 금액, 결제 기한, 결제 상태가 표시돼요. 고객은 여기서 해당 회차를 결제할 수 있어요.

### 견적서 수락·거절하기

사용자나 발신자는 견적서를 수락하거나 거절할 수 있어요.

- **Accept**(수락)를 클릭하면 견적서가 수락됨으로 표시돼요.

  ![견적서 수락 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906692/original/1mVFnaw_U8etfLfIINiyZL8J9hHf8pJEnQ.jpeg?1727834340)

- **Reject**(거절)를 클릭하고 메모를 남기면 견적서가 거절됨으로 표시돼요.

  ![견적서 거절 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906693/original/2UIhjV4ysOlb7JG3ZjTtQEF7MNci63vmAA.jpeg?1727834340)

- 전화로 이미 확인받았다면 **Mark as accepted/rejected**(수락/거절로 표시)를 클릭해 상태를 바꿀 수 있어요.

  ![수락 또는 거절로 표시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906689/original/hC2x2Cp3oM8uF1cQwVEZe6ypD0bdz2tm5Q.jpeg?1727834340)

### 인보이스로 변환하기

1. 발송된 항목을 클릭해요.

   ![발송된 항목 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906690/original/_CBQ8DKjHtzz-gLRrO5Wh_p3DA_eQQJj4A.jpeg?1727834340)

2. 고객이 견적서를 승인하면 인보이스로 바꿀 수 있어요. 대시보드에서 **create an invoice**(인보이스 만들기)를 선택하거나, 수락된 견적서를 열어 **create an invoice**를 클릭하세요.

   ![인보이스로 변환하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906691/original/IkAojIbBURxokJT9IHRQx6iddxraBxcr6w.jpeg?1727834340)

### 추적

- 견적서의 단계별 현황을 한눈에 볼 수 있어요. 단계는 **Draft**(초안), **Sent**(발송됨), **Accepted**(수락됨), **Declined**(거절됨), **Invoiced**(인보이스 발행됨)가 있어요.
- 대시보드 상단 카드에서 진행 중인 견적서의 금액을 확인할 수 있어요.
- 사용자가 남긴 메모는 대시보드와 견적서 작성 화면에서 확인할 수 있어요.

![견적서 추적 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033906694/original/TGP8lYPQQDZn4ep7PPIKKEelcRvhNHHyFA.jpeg?1727834340)

### 기타

- 회사 브랜딩과 약관을 추가하고 설정에서 조정해 견적서를 꾸밀 수 있어요.

## 이 기능을 만든 이유

견적서 기능은 비즈니스에 필요한 결제 기능을 완성하려고 만들었어요. 이제 아래 순서로 진행할 수 있어요.

1. 견적서 만들기
2. 문서 서명 받기
3. 인보이스 보내기
