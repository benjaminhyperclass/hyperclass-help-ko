# Adyen 결제 연동 설정하기

하이퍼클래스의 Adyen 결제 연동으로 유럽과 북미에서 신용카드·체크카드 결제를 받을 수 있어요. 이 문서에서는 연동이 어떻게 동작하는지, 어떤 기능과 지역을 지원하는지, Adyen 계정을 연결하는 방법, 테스트·환불 방법, 자주 묻는 질문을 안내해요. Adyen을 표준으로 쓰는 기업 고객을 상대하는 에이전시에 특히 잘 맞아요.

## Adyen 결제 연동이란?

Adyen 결제 연동은 이미 가지고 있는 Adyen 가맹점 계정을 하이퍼클래스에 연결하는 기능이에요. 연결하면 Adyen의 PCI 인증 인프라로 지원되는 판매 채널의 카드 결제를 처리할 수 있어요. 에이전시와 서브 계정은 기업 구매 요건을 충족하면서도 결제 수납은 하이퍼클래스 안에서 그대로 할 수 있어요.

관리자가 Adyen 인증 정보(**회사 API 키**, 라이브 모드에서는 **라이브 URL 접두사** 추가)를 하이퍼클래스에 등록하면, 인보이스나 [결제 링크](../payment-links.md) 같은 선택한 채널의 카드 결제를 Adyen으로 처리해요.

## Adyen 결제 연동의 장점

서브 계정에 연결된 다른 결제 에이전시 대신 Adyen을 고를지 판단할 때 아래 내용을 참고하세요. 기업 환경, 지원 지역, 보안 측면의 장점이에요.

- 기업 환경 대응: Adyen을 표준으로 쓰는 회사와 계약을 따낼 수 있어요.
- 3D Secure(3DS) 지원: 위험도가 높거나 해외에서 이루어지는 결제에 인증 단계를 한 번 더 거쳐요.
- 유럽·북미 폭넓은 지원: 해당 지역에서 사업하는 업체를 하나의 제공업체로 연결할 수 있어요.
- 빠른 고객 도입: 이미 Adyen 가맹점인 고객은 인증 정보만 입력하면 바로 판매를 시작할 수 있어요.

## 사전 준비

아래 항목을 미리 준비하면 연결 오류를 줄이고 설정 시간을 아낄 수 있어요.

- 결제 처리 승인이 완료된 Adyen 가맹점 계정 (테스트와 라이브 모두)
- 테스트 환경과 라이브 환경 각각의 **회사 API 키**
- Adyen 계정에서 확인할 수 있는 **라이브 URL 접두사** (라이브에서만 사용해요)
- **결제** 메뉴에 관리자 권한이 있는 하이퍼클래스 계정

## 한눈에 보기: 인증 정보, 지원 기능, 지원 지역

어떤 인증 정보가 필요한지, 현재 무엇을 지원하는지, 어느 지역에서 쓸 수 있는지 한눈에 확인하세요. 설정할 때나 고객과 범위를 정할 때 옆에 두면 잘못 설정하거나 과하게 약속하는 일을 막을 수 있어요.

| 구분 | 항목 | 세부 내용 |
| --- | --- | --- |
| 인증 정보 요건 | 라이브 모드 | **회사 API 키**와 **라이브 URL 접두사** 모두 필요 |
| | 테스트(샌드박스) | **회사 API 키** |
| | 라이브 URL 접두사 | 라이브 엔드포인트 앞에 붙는 16진수 문자열 (예: `1797a841fbb37ca7-MyStore`). Adyen 개발자 설정에서 확인 |
| 지원 기능 | 결제 수단 | 카드 결제 (신용/체크) |
| | 인증 | 3D Secure(3DS) 지원 |
| | 하이퍼클래스에서 쓸 수 있는 곳 | 인보이스, 결제 링크, 스토어, 폼/퍼널 주문 폼 (카드 결제를 지원하는 경우) |
| 지원 지역 및 통화 | 지역 | EU/영국, 미국, 캐나다 |
| | 통화 및 정산 | Adyen 계정의 승인 내용과 설정에 따라 결정 |

## Adyen 결제 연동 설정하기

아래 순서대로 Adyen을 안전하게 연결하고, 실제 결제를 시작하기 전에 정상 동작하는지 확인하세요.

1. 하이퍼클래스 서브 계정에서 **결제 > 연동**으로 이동해요. **Connect Adyen**(Adyen 연결)을 클릭하세요.

   ![결제 연동 화면에서 Adyen 연결 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059386395/original/9yJ_eT8Sjjer8_wN3uJIyeZEDkTb6ahUbA.png?1764253233)
2. 토글에서 **라이브** 또는 **테스트**를 선택하세요.

   ![라이브와 테스트 모드를 고르는 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059386481/original/cAJQ1d8VKPzNQ-p7opNk7BbDAAnzpHOc3Q.png?1764253309)
3. **회사 API 키**를 입력하세요. Adyen API 키는 어디서 확인하나요? [Adyen 안내 문서](https://docs.adyen.com/development-resources/api-credentials)를 참고하세요.
4. (라이브 모드에서만) **라이브 URL 접두사**를 붙여넣으세요.
5. **저장**을 클릭하세요. 연결이 완료되면 성공 메시지가 나타나요.

## Adyen으로 테스트하기 (샌드박스)

테스트를 거치면 의도하지 않은 결제를 막을 수 있고, 라이브로 바꾸기 전에 3DS 동작도 확인할 수 있어요.

- **테스트** 모드로 카드 결제를 시뮬레이션해 보세요. 실제 결제는 일어나지 않아요.
- Adyen이 제공하는 테스트 카드 번호를 사용하고, 3DS 안내가 나오면 따라 하면서 인증 흐름을 확인하세요.
- 테스트에 성공하면 연동을 **라이브**로 바꾸고 **라이브 URL 접두사**를 입력한 뒤, 소액으로 결제를 한 번 더 확인하세요.

![Adyen 테스트 모드 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059386305/original/Nthj7Hy3KCgoG29Bk2RXKFreQZQ9Gbldbw.png?1764253202)

## 환불 및 분쟁

환불과 분쟁을 어디서 처리하는지 알아 두면 처리 지연과 지급 거절(차지백) 위험을 줄일 수 있어요.

- 환불: 하이퍼클래스에서 계정의 환불 기능이 켜져 있다면 **결제 > 거래 내역**(또는 해당 인보이스)에서 전액 환불이나 부분 환불을 할 수 있어요. 그렇지 않으면 Adyen 대시보드에서 직접 환불을 진행하세요.
- 분쟁/차지백: 분쟁은 Adyen에서 관리해요. 분쟁 알림을 확인하고, Adyen의 기한과 안내에 맞춰 증빙 자료를 제출하세요.
- 환불 시점, 수수료, 정산 조정은 Adyen이 정해요.

## 자주 묻는 질문

### 하이퍼클래스에서 Adyen으로 Apple Pay나 Google Pay를 켤 수 있나요?
출시 시점에는 지원하지 않아요. 현재 연동은 카드 결제만 지원해요.

### Adyen 수수료 외에 하이퍼클래스 거래 수수료가 따로 붙나요?
아니요. 거래는 기존 Adyen 요금 기준으로 Adyen이 처리해요.

### 라이브 모드에서 라이브 URL 접두사를 비워 두면 어떻게 되나요?
Adyen이 접두사 없이는 요청을 보낼 곳을 찾지 못해서 라이브 결제가 실패해요.

### 같은 서브 계정에 Stripe와 Adyen을 함께 연결할 수 있나요?
네. 여러 결제 게이트웨이를 연결해 두고, 채널마다 **기본 제공업체**를 선택하세요.

### 3DS를 쓰려면 하이퍼클래스에서 따로 설정해야 하나요?
아니요. 3DS 인증이 필요한 결제라면 결제 과정에서 Adyen이 인증 절차를 처리해요.

### Adyen 지급 내역과 수수료는 어디서 볼 수 있나요?
Adyen 대시보드에서 확인하세요. 정산 시점과 수수료는 Adyen이 정해요.

### 현재 Adyen 연동은 카드 결제만 되나요?
네. 현재 버전은 신용/체크카드 결제를 지원해요. 지갑형 결제(Apple Pay, Google Pay), 후불결제(BNPL), 단말기는 아직 사용할 수 없어요.
