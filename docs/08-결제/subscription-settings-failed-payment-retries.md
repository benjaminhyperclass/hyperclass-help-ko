# 구독 설정 — 결제 실패 시 자동 재시도

구독 결제가 실패했을 때 결제를 몇 번, 어떤 간격으로 다시 시도할지 정하는 방법을 안내해요. 재시도 설정을 쓰면 구독 갱신을 더 매끄럽게 관리할 수 있어요.

## 결제 실패 재시도 설정이란?

구독 결제가 실패했을 때 자동으로 다시 결제를 시도하도록 설정할 수 있어요. 결제 실패에 대응하는 방식을 비즈니스에 맞게 조정할 수 있어요.

## 결제 실패 재시도 설정의 장점

- 재시도 횟수 직접 설정: 비즈니스에 맞게 최대 3번까지 재시도를 정할 수 있어요. 재시도 사이의 간격은 1일, 3일, 5일, 7일 중에서 고를 수 있어요.
- 기본 설정: 기본값은 1일 간격으로 3번 재시도예요. 필요하면 바꿀 수 있어요.
- 신규·기존 구독에 모두 적용: 재시도 설정을 바꾸면 신규 구독과 기존 구독에 모두 적용돼요. 모든 거래에 같은 기준이 적용돼요.
- 최종 실패 시 구독 처리: 모든 재시도가 실패하면 구독을 **Unpaid**(미결제) 상태로 그대로 둘 수 있어요. 설정에서 체크박스를 선택하면 자동으로 **Cancelled**(취소됨) 상태로 옮길 수도 있어요.

## 결제 실패 재시도 설정하기

몇 단계만 거치면 설정할 수 있어요.

1. **결제 > 설정 > 구독**으로 이동해 구독 설정 화면을 열어요.
2. 비즈니스에 맞게 재시도 횟수(최대 3번)를 선택해요.
   ![재시도 횟수 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042231191/original/InXm5z2v6ePnNtu1kOWfhv6Kc4hKvEYwoA.png?1740504381)
3. 재시도 사이의 간격(1일, 3일, 5일, 7일)을 선택해요.
   ![재시도 간격 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042231211/original/U7jBHLSHg9jX4ef-JIfXT2BL966335N1RA.png?1740504421)
4. 기존 설정을 바꾸면 신규 구독뿐 아니라 이미 진행 중인 구독의 재시도에도 변경 내용이 적용돼요.
5. 마지막 재시도까지 실패했을 때 구독을 자동으로 **Cancelled** 상태로 옮길지 선택해요. 이 옵션은 켜거나 끌 수 있어요.
   ![최종 실패 시 구독 상태 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042231228/original/pcfrThpO9U5E6fh0dkusXXOGQgOtUnL3QA.png?1740504467)
6. **설정 저장**을 클릭하면 변경 사항이 바로 적용돼요.

## 예시

어떤 구독이 '3번 재시도, 재시도마다 3일 간격'으로 설정돼 있고, 이미 한 번 재시도한 상태라고 가정해요. 두 번째 재시도 전에 설정을 '2번 재시도, 간격은 각각 3일과 5일'로 바꾸면 이렇게 돼요.

- 두 번째 재시도는 3일이 아니라 5일 뒤에 진행돼요.
- 세 번째 재시도는 진행되지 않아요.

## 지원하는 결제 제공업체

이 기능은 다음 결제 제공업체에서 쓸 수 있어요.

- NMI
- Authorize.net
- Square

## 자주 묻는 질문

### 결제 실패 시 재시도는 몇 번까지 설정할 수 있나요?
최대 3번까지 설정할 수 있어요. 재시도 사이의 간격은 1일, 3일, 5일, 7일 중에서 고를 수 있어요.

### 재시도 설정을 바꾸면 기존 구독에도 적용되나요?
네. 신규 구독과 진행 중인 구독에 모두 적용돼요. 이미 재시도가 진행 중인 구독도 포함돼요.

### 모든 재시도가 실패하면 어떻게 되나요?
구독을 **Unpaid** 상태로 그대로 둘 수도 있고, 설정에서 해당 옵션을 선택해 자동으로 **Cancelled** 상태로 옮길 수도 있어요.

### 결제 실패 재시도는 어디에서 설정하나요?
**결제 > 설정 > 구독**으로 이동하면 재시도 설정 옵션이 나와요.

### 어떤 결제 제공업체에서 이 기능을 쓸 수 있나요?
현재 NMI, Authorize.net, Square에서 지원해요.

### 고객에게 월 구독 요금이 청구되지 않았어요. 왜 그런가요?
**결제 > 상품**에서 구독에 연결된 상품의 이름을 바꾸거나 수정하면 Stripe와의 동기화가 끊어질 수 있어요. 이럴 때 주로 이런 일이 생겨요. 아래 순서로 해결해 보세요.

1. **결제 > 구독**으로 이동해요.
2. 해당 구독을 찾아 점 3개 아이콘을 클릭하고 **구독 업데이트**를 선택해요.
3. 수정된 상품을 추가하고 기존 상품은 제거해요.
4. **저장**을 클릭하면 이후 청구가 다시 정상적으로 진행돼요.

{% hint style="info" %}
청구되지 않은 결제는 자동으로 다시 청구되지 않아요. 해당 금액을 받으려면 수동으로 인보이스를 보내거나 일회성 결제 링크를 보내세요.
{% endhint %}
