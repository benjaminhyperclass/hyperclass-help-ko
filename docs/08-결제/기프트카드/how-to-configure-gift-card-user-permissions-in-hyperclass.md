# 기프트 카드 사용자 권한 설정

기프트 카드 사용자 권한을 쓰면 관리자가 팀원별로 기프트 카드 정보를 볼 수 있는지, 민감한 기프트 카드 작업을 할 수 있는지 정할 수 있어요. 기프트 카드 주문, 상품, 보내기, 판매, 전체 기프트 카드 코드, 상세 페이지, 상품 관리 권한을 각각 따로 줄 수 있어요. 이 문서에서는 권한별 역할과 직원의 기프트 카드 접근 권한을 설정하는 방법을 안내해요.

각 권한이 무엇을 제어하는지, **사용자** 계정에 권한을 설정하는 방법, 전체 기프트 카드 코드 접근이 어떻게 보호되는지, 할당된 데이터 제한이 기프트 카드 권한과 어떻게 함께 쓰이는지 알 수 있어요.

## 기프트 카드 사용자 권한이란?

기프트 카드 사용자 권한은 직원이 **기프트 카드**에서 무엇을 보고 무엇을 할 수 있는지 세밀하게 정하는 접근 제어예요.

관리자는 **사용자**가 기프트 카드 주문을 볼 수 있게 하면서, 기프트 카드 보내기, 기프트 카드 상품 관리, 기프트 카드 상세 페이지 열기, 전체 기프트 카드 코드 확인 같은 작업은 따로 제한할 수 있어요.

이렇게 하면 직원의 역할에 필요한 기능만 열어 주고, 모든 기프트 카드 작업이나 민감한 정보까지 자동으로 허용하지 않아도 돼요.

### 기프트 카드 사용자 권한의 장점

권한을 세분화하면 일상적인 기프트 카드 업무와, 민감한 정보를 보여 주거나 기프트 카드 상품을 바꾸는 작업을 구분할 수 있어요.

- 기프트 카드 정보 보호: 기프트 카드 주문, 상세 정보, 상품, 민감한 기프트 카드 코드에 대한 접근을 제어해요.
- 보기와 관리 분리: 직원이 기프트 카드 상품을 볼 수 있어도 상품을 만들거나 편집할 권한은 자동으로 주어지지 않아요.
- 기프트 카드 발급 제어: 고객에게 기프트 카드를 직접 보낼 수 있는 사용자를 정할 수 있어요.
- 상품 작업 제한: 기프트 카드 상품을 만들고, 편집하고, 삭제하고, 비활성화하는 작업을 제한할 수 있어요.
- 판매 접근 제어: 기프트 카드 판매 링크에 접근하거나 QR 코드로 기프트 카드 상품을 공유할 수 있는 사람을 정할 수 있어요.
- 역할 기반 접근 지원: 사용자에게 맡은 업무에 필요한 기능만 줄 수 있어요.

## 사전 준비와 제한 사항

기프트 카드 권한을 바꾸기 전에 직원의 역할을 먼저 확인해서, 접근 권한이 맡은 업무와 맞는지 살펴보세요.

- 기프트 카드 권한은 직원의 서브 계정 **Roles and Permissions**(역할 및 권한) 설정에서 지정해요.
- **관리자** 계정은 기본적으로 서브 계정 전체에 접근할 수 있어요.
- **사용자** 계정에는 기프트 카드 권한을 세분화해서 설정할 수 있어요.
- **View Full Gift Card Code**(기프트 카드 전체 코드 보기)는 일반 기프트 카드 주문·상세 접근 권한과 별개예요.
- 데이터 할당에 따라 접근 범위도 제한하고 싶다면, 해당하는 **사용자** 계정에 할당된 데이터 제한을 함께 쓸 수 있어요.
- 기프트 카드 권한에는 기프트 카드 사용(redemption)만 따로 다루는 권한이 없어요.
- 기프트 카드를 사용하는 결제 영역에는 사용자에게 해당 접근 권한이 따로 필요해요.

## 기프트 카드 권한 종류

각 권한은 기프트 카드 기능의 특정 부분을 보호해요. 그래서 읽기 전용 접근과 발급, 판매, 상품 관리, 민감한 기프트 카드 정보를 나눠서 줄 수 있어요.

| 권한 | 제어하는 기능 |
| --- | --- |
| **View Gift Card Orders**(기프트 카드 주문 보기) | 발급된 기프트 카드 목록과 기프트 카드 주문 정보에 접근할 수 있어요. |
| **Access Gift Card Details Page**(기프트 카드 상세 페이지 접근) | 개별 기프트 카드 주문의 상세 페이지를 열 수 있어요. |
| **View Full Gift Card Code**(기프트 카드 전체 코드 보기) | 기프트 카드 주문 상세 페이지에서 전체 기프트 카드 코드를 확인할 수 있어요. |
| **View Gift Card Products**(기프트 카드 상품 보기) | 기프트 카드 상품과 구성을 볼 수 있어요. 편집 권한은 자동으로 주어지지 않아요. |
| **Create/Edit Gift Card Products**(기프트 카드 상품 만들기/편집) | 새 기프트 카드 상품을 만들거나 기존 상품을 수정할 수 있어요. |
| **Access Sell Link / Share via QR**(판매 링크 접근 / QR로 공유) | 기프트 카드 판매 링크와 QR 기반 공유 옵션에 접근할 수 있어요. |
| **Send Gift Card (Issue Directly)**(기프트 카드 보내기, 직접 발급) | **기프트 카드 보내기** 과정을 통해 고객에게 기프트 카드를 직접 발급할 수 있어요. |
| **Delete/Deactivate Gift Card**(기프트 카드 삭제/비활성화) | 기프트 카드 상품의 삭제와 비활성화 작업에 대한 접근을 제어해요. |

## 기프트 카드 사용자 권한 설정하기

직원의 **Roles and Permissions** 설정에서 기프트 카드 권한을 지정하면, 직원이 해야 할 기프트 카드 업무에 맞게 접근 범위를 정할 수 있어요.

1. 서브 계정 화면에서 **설정**을 선택하세요.
2. **스태프 관리**를 선택하세요.
3. 기프트 카드 접근 권한을 설정할 직원을 찾으세요.
4. 연필 모양 **편집** 아이콘을 클릭하세요.
5. **Roles and Permissions**를 여세요.
6. 직원에게 알맞은 역할이 지정되어 있는지 확인하세요.
7. **기프트 카드** 권한 섹션을 찾으세요.
8. 직원에게 필요한 기프트 카드 권한만 켜세요.
9. 사용자가 접근하면 안 되는 정보나 작업의 권한은 꺼 두세요.
10. 사용자의 데이터 공개 범위도 제한해야 한다면 **할당된 데이터만**을 확인하세요.
11. 변경 사항을 저장하세요.

## 할당된 데이터와 기프트 카드의 관계

기프트 카드 권한은 사용자가 쓸 수 있는 기프트 카드 기능과 작업을 정해요. 할당된 데이터 제어는 그 사용자가 볼 수 있는 데이터의 범위를 더 좁혀 줘요.

전체 데이터를 보는 대신 자신에게 할당된 정보만 보게 해야 하는 사용자에게는 **할당된 데이터만**을 쓰세요. 해당하는 경우에 사용할 수 있어요.

할당된 데이터 제한은 기프트 카드 권한을 대신하지 않아요. 사용자가 접근하려는 페이지나 작업에 필요한 기프트 카드 권한은 여전히 있어야 해요.

## 자주 묻는 질문

### 기프트 카드를 보낼 수 없게 하면서 기프트 카드 주문만 볼 수 있게 할 수 있나요?
네, 가능해요. **View Gift Card Orders**와 **Send Gift Card (Issue Directly)**는 서로 별개의 권한이에요.

### 전체 기프트 카드 코드는 못 보게 하고 기프트 카드 상세 페이지만 열 수 있게 할 수 있나요?
네, 가능해요. **View Full Gift Card Code**는 기프트 카드 상세 페이지 접근 권한과 따로 제어해요.

### 기프트 카드 상품을 볼 수만 있고 편집은 못 하게 할 수 있나요?
네, 가능해요. **View Gift Card Products**와 **Create/Edit Gift Card Products**는 서로 별개의 권한이에요.

### 기프트 카드 판매 링크나 QR 코드에 접근할 수 있는 사람을 정할 수 있나요?
네, 가능해요. **Access Sell Link / Share via QR**로 해당 옵션에 대한 접근을 제어하세요.

### 기프트 카드 권한과 할당된 데이터만 설정을 함께 쓸 수 있나요?
네, 가능해요. 해당하는 **사용자** 계정에서는 할당된 데이터 제한으로 데이터 공개 범위를 더 좁힐 수 있어요. 기능과 작업에 대한 접근은 기프트 카드 권한이 계속 제어해요.

### 기프트 카드 사용만 따로 허용하는 권한이 있나요?
아니요. 기프트 카드 권한에는 사용(redemption)만 따로 다루는 권한이 없어요. 기프트 카드를 사용하는 결제 영역에는 사용자에게 해당 접근 권한이 따로 필요해요.

### 관리자 계정도 기프트 카드 권한을 하나씩 켜야 하나요?
아니요. **관리자** 계정은 기본적으로 서브 계정 전체에 접근할 수 있어요. 세분화된 기프트 카드 권한은 **사용자** 계정의 접근을 제어할 때 사용해요.
