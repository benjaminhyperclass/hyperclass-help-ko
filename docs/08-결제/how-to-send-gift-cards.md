# 기프트 카드 직접 보내기

고객이 구매하거나 결제하지 않아도, 원하는 고객에게 기프트 카드를 바로 발급해 보낼 수 있어요. 이 문서에서는 하이퍼클래스에서 받는 사람에게 기프트 카드를 직접 보내는 방법을 안내해요.

## 기프트 카드 직접 보내기란?

기프트 카드를 보내면 1회용 선불 크레딧이 만들어지고, 고르신 받는 사람에게 이메일, SMS, PDF, QR 코드 중 한 가지로 전달돼요. 연락처가 따로 구매하지 않아도 돼요. 보상 차원의 보전, 로열티 선물, VIP 혜택, 내부 테스트에 알맞아요.

기프트 카드는 하이퍼클래스에서 기프트 카드를 받는 결제 화면에서 사용할 수 있어요. 현재 보내기 과정은 **라이브 모드**에서만 작동해요. 그래서 실제로 쓸 수 있는 기프트 카드만 전달돼요.

---

## 기프트 카드 직접 보내기의 장점

- 1:1 발급: 받는 사람 한 명에게 바로, 또는 예약해서 기프트 카드를 보낼 수 있어요.
- 결제 없이 발급: 받는 사람에게 요금을 청구하지 않고 선불 금액을 줄 수 있어요.
- 다양한 전달 방식: 연락처 정보와 용도에 맞게 이메일, SMS, PDF, QR 코드로 전달해요.
- 간편한 사용: 받는 사람은 코드나 링크로 지원되는 결제 화면에서 바로 사용할 수 있어요.
- 현황 확인: **Gift Card Orders**(기프트 카드 주문)에서 주문, 코드, 금액, 상태를 확인할 수 있어요.
- 고객 응대 보상: 지원 문제가 생겼을 때 빠르고 깔끔하게 보상할 수 있어요.

---

## 이럴 때 쓰세요

기프트 카드를 직접 보내는 방법은 다음과 같은 경우에 알맞아요.

- 로열티·리워드: 구매 횟수 같은 기준을 달성했거나, 추천해 줬거나, 프리미엄 플랜을 갱신한 고객에게 보상해요.
- 고객 지원 보상: 수동 크레딧이나 환불 대신 기프트 카드를 발급해요.
- 프로모션: 경품 행사, 명절 선물, 인플루언서 캠페인, 특정 대상 혜택에 활용해요.
- 내부 테스트: QA 팀, 관리자, 개발자가 기프트 카드 사용 흐름을 테스트해요.
- 수동 대량 배포: VIP 고객이나 행사 참석자에게 선불 잔액을 선물해요.

---

## 시작하기 전에 확인하세요

기프트 카드를 보내기 전에 다음을 확인하세요.

1. 기프트 카드 상품이 있어야 해요.
2. 기프트 카드 상품이 **활성** 상태여야 해요. 비활성화되었거나 보관된 상품은 보낼 수 없어요.
3. 기프트 카드를 받을 고객에게 다음 중 하나가 있어야 해요.

   - 이메일 주소
   - 전화번호 (SMS로 전달할 때)

## 기프트 카드 보내는 순서

### 1단계: 기프트 카드로 이동

1. 서브 계정에 로그인하세요.
2. **결제 > 기프트 카드**로 이동하세요.

   ![결제 메뉴의 기프트 카드 화면](https://jumpshare.com/share/WO8nSGZWS8RLjB2nvM4m+/Screen+Shot+2025-11-26+at+9.02.39+PM.png)
3. **Create a Gift Card**(기프트 카드 만들기)를 누르거나, **모든 기프트 카드** 목록에서 기존 기프트 카드를 선택하세요.

   ![모든 기프트 카드 목록](https://jumpshare.com/share/lwAqTaYBJlHZUyLQOnHW+/Screen+Shot+2025-11-26+at+9.07.49+PM.png)
4. 보내려는 기프트 카드에서 **보내기** 버튼을 누르세요. 보내기 과정이 시작돼요.

   ![기프트 카드의 보내기 버튼](https://jumpshare.com/share/BfuXE2nejTPExaY10OSk+/Screen+Shot+2025-11-26+at+9.10.09+PM.png)

### 2단계: 고객/연락처 선택

1. 목록에서 기존 고객/연락처를 받는 사람으로 선택하세요.
2. 목록에 없으면 보내기 전에 **연락처 추가**를 누르세요.
3. **continue**(계속)를 누르세요.

   ![받는 사람 선택 화면](https://jumpshare.com/share/loy8HURAsCLH25bOIfTb+/Screen+Shot+2025-11-26+at+9.15.10+PM.png)

### 3단계: 개인 메시지 추가

다음 중 한 가지 방법으로 메시지를 넣을 수 있어요.

- 직접 쓴 인사말, 특별 안내, 감사 메시지
- 미리 준비된 메시지 중 하나
- **Write with AI**(AI로 작성)로 만든 메시지

메시지를 정했으면 **continue**를 누르세요.

![개인 메시지 입력 화면](https://jumpshare.com/share/wUpCkc5IeaOSTyVzG2rN+/Screen+Shot+2025-11-26+at+9.21.05+PM.png)

### 4단계: 금액 선택

1. 상품에 설정되어 있는 미리 정해진 금액 중 하나를 고르세요.

   ![금액 선택 화면](https://jumpshare.com/share/0Jfwr6zimU6IGHcdZIMo+/Screenshot+2025-11-26+at+9.29.28%E2%80%AFPM.png)

### 5단계: 전달 방식 선택

{% hint style="info" %}
고객의 이메일이나 전화번호 정보로 쓸 수 있는 방식만 활성화돼요.
{% endhint %}

다음 방식 중 하나를 골라 기프트 카드를 전달할 수 있어요.

- **이메일**
- **SMS**
- **QR Code (via email)**(QR 코드, 이메일로)
- **PDF (이메일로)**

![전달 방식 선택 화면](https://jumpshare.com/share/2s6Cy4C4QE85akAC0ifg+/Screen+Shot+2025-11-26+at+9.39.03+PM.png)

### 6단계: 배송일 선택

{% hint style="info" %}
기프트 카드에 설정된 만료 조건에 따라 고를 수 있는 배송일 범위가 달라져요. 만료일이 있는 기프트 카드는 오늘부터 만료일 사이에서 배송일을 골라야 해요. 만료일이 없는 기프트 카드는 앞으로의 어느 날짜로든 예약할 수 있어요.
{% endhint %}

다음 중 하나를 고를 수 있어요.

- 프리셋: 바로 보내기, 내일, 1주일 뒤
- **Future Date**(미래 날짜)를 골라 예약 전달

배송일을 정했으면 **continue**를 누르세요.

![배송일 선택 화면](https://jumpshare.com/share/fXBLYnUAf7ab0c2nbQEB+/GIF+Recording+2025-11-26+at+9.54.26+PM.gif)

### 7단계: 확인 후 보내기

1. 확정하기 전에 자동으로 만들어진 이메일 또는 SMS 미리보기를 확인하세요. 미리보기에는 다음 내용이 들어 있어요.

   - 기프트 카드 금액
   - **사용자 지정 메시지**
   - 만료일
   - 사용 방법 안내
   - 아트워크(카드 디자인)
2. **기프트 카드 보내기**를 누르세요.

   ![기프트 카드 보내기 확인 화면](https://jumpshare.com/share/Dx07l8CphQzWnfDpO63v+/GIF+Recording+2025-11-26+at+10.20.40+PM.gif)

## 전달 방식별 차이

### 이메일

- 아트워크가 들어간 기프트 카드 이미지 전체가 전달돼요.
- 만료일, 잔액, 사용 링크가 포함돼요.
- 대부분의 경우에 이 방식을 권해요.

![이메일로 받은 기프트 카드](https://jumpshare.com/share/nE4p8Ho3cp0j09xXcDCu+/Screen+Shot+2025-11-26+at+10.40.12+PM.png)

### SMS

- 기프트 카드 링크가 담긴 간단한 메시지가 전달돼요.
- SMS 형식상 아트워크는 포함되지 않아요.

![SMS로 받은 기프트 카드](https://jumpshare.com/share/zcbVS0C3sqcyIU6lnTJd+/Screen+Shot+2025-11-26+at+10.42.47+PM.png)

### PDF (이메일로)

- 내려받아 인쇄할 수 있는 PDF가 전달돼요.
- 매장에서 선물할 때, 실물 포장을 할 때, 행사에서 쓰기 좋아요.

![PDF로 받은 기프트 카드](https://jumpshare.com/share/4J3mtirC8dkp0JPOZJNp+/Screen+Shot+2025-11-26+at+10.44.51+PM.png)

### QR Code (via email)

- 스캔하면 기프트 카드가 열리는 QR 코드가 전달돼요.
- 직접 만나서 선물하거나 행사에서 쓸 때 유용해요.

![QR 코드로 받은 기프트 카드](https://jumpshare.com/share/R9SYiFnfOc0WsAnmTeVP+/GIF+Recording+2025-11-26+at+10.47.14+PM.gif)

## 기프트 카드를 보낸 뒤에는

기프트 카드를 보내면 다음 위치에 표시돼요.

**결제 > 기프트 카드 > Gift Card Orders**

![Gift Card Orders 목록](https://jumpshare.com/share/sZYp5xQTee7yLigsfBll+/Screen+Shot+2025-11-26+at+10.50.18+PM.png)

기프트 카드의 **주문 상세**에는 다음 정보가 들어 있어요.

- 받는 사람 정보
- 전달 방식
- 전달 시각
- 금액
- 만료일
- **남은 잔액**
- 상태: **예약됨**, **활성**, **Inactive**(비활성)
- 가려진 기프트 카드 코드

![기프트 카드 주문 상세 화면](https://jumpshare.com/share/OWNNCXZESfhm7DusXHwM+/Screen+Shot+2025-11-26+at+10.53.18+PM.png)

## 알아 두면 좋은 동작과 제한

- 보내기 과정은 **라이브 모드**에서만 작동해요.
- 한 번에 고객 1명에게 기프트 카드 1장만 보낼 수 있어요.
- 보내기 과정에서는 결제가 이루어지지 않아요.
- 직접 보낸 기프트 카드는 **결제 > 주문**에 나타나지 않아요. 주문도, 거래도 생기지 않아요.
- 보내기로 발급한 기프트 카드는 어디서나 전액 또는 일부 금액으로 사용할 수 있어요.
- 전달하려면 고객의 이메일 주소나 전화번호가 있어야 해요.

## 자주 묻는 질문

### 예약한 기프트 카드는 언제 전달되나요?

선택한 배송일 오전 12시(자정)에 전달돼요.

### 테스트 모드에서도 기프트 카드를 보낼 수 있나요?

아직은 안 돼요. 보내기 과정은 **라이브 모드**만 지원해요. **Test Mode**(테스트 모드) 지원은 이후 업데이트에서 추가될 예정이에요.

### 일부 고객에게는 기프트 카드를 보낼 수 없어요. 왜 그런가요?

고객에게 유효한 이메일 주소나 유효한 전화번호 중 하나는 있어야 해요. 둘 다 없으면 쓸 수 있는 전달 방식이 없어요.

### 기프트 카드를 여러 장 한꺼번에 보낼 수 있나요?

아직은 안 돼요. 보내기 과정 한 번에 고객 1명에게 기프트 카드 1장만 보낼 수 있어요. 대량 발송은 이후 버전에서 지원할 예정이에요.

### 보낸 기프트 카드는 어디서나 사용할 수 있나요?

네, 기프트 카드 사용을 지원하는 모든 결제 화면에서 쓸 수 있어요. 예를 들면 다음과 같아요.

- 퍼널
- 폼
- 인보이스
- 스토어
- 결제 링크
- 캘린더 (상품을 지원하는 경우)

### 예약한 기프트 카드는 전달 시각 전에 어떤 상태인가요?

예약된 전달 시각이 되기 전까지 기프트 카드는 **예약됨** 상태로 남아 있어요. 하지만 활성 상태라서 사용할 수 있어요.

### 예약한 기프트 카드를 전달 시각 전에 사용할 수 있나요?

네, 사용할 수 있어요. 기프트 카드 코드를 알고 있는 사람이 예약된 전달 시각 전에 결제 화면에서 코드를 입력하면 사용돼요.

### 보내기 전에 이메일/SMS 템플릿을 수정할 수 있나요?

템플릿은 시스템에서 자동으로 만들어지고, 현재는 수정할 수 없어요. 이메일과 SMS 템플릿 사용자 지정은 이후에 지원될 예정이에요.

### 보낸 기프트 카드가 결제의 주문에도 나타나나요?

아니요. 구매된 기프트 카드만 **결제 > 주문**에 나타나요. 직접 보낸 기프트 카드는 **Gift Card Orders**에만 표시돼요.

### 기프트 카드를 익명으로 보낼 수 있나요?

아직은 안 돼요. 받는 사람에게는 이메일/SMS 템플릿에 설정된 보내는 비즈니스의 정보가 항상 표시돼요.
