# 주문을 CSV 파일로 내보내기

주문 기록을 CSV 파일로 내보내는 방법을 안내해요. 리포트 작성, 대조(정산 확인), 재무 분석, 배송 처리, 상품 성과 추적에 쓸 수 있어요.

## 개요

**주문 CSV 내보내기** 기능을 쓰면 **결제 > 주문** 화면의 상세 주문 기록을 내려받을 수 있어요.

내보낼 수 있는 범위는 다음과 같아요.

- 전체 주문
- 필터나 검색으로 골라낸 주문만

내보낸 파일은 보안 다운로드 링크로 이메일에 전달돼요.

## 주문 내보내기

1. **결제 > 주문**으로 이동해요.
2. (선택) 다음과 같은 필터를 적용해요.
   - **주문 상태**
   - 날짜 범위
   - **Source type**(소스 유형): 퍼널, 결제 링크, 스토어 결제 등
   - **상품 유형**: 일회성 상품 또는 반복 결제 상품
3. **다운로드**를 클릭해요.
4. 이메일로 온 다운로드 링크를 확인해요.

{% hint style="warning" %}
**보안 안내:** 내보내기 링크는 **7일 후** 만료돼요. 만료되면 내보내기를 새로 시작하세요.
{% endhint %}

## CSV 형식 이해하기

주문 하나에 여러 개의 다음 항목이 들어 있을 수 있어요.

- 상품
- 세금

그래서 **주문 하나가 파일에서 여러 행으로 나뉘어 표시될 수 있어요.**

이렇게 하면 장부 정리와 분석에 필요한 상품별 가격과 세금 내역을 한눈에 볼 수 있어요.

## 데이터 일관성 보장 (내보내기 개선)

주문 내보내기 파일은 상품, 세금, 결제 항목을 믿고 대조하고 리포트에 쓸 수 있도록 정리되어 있어요.

**0과 빈 값의 차이**
`0`은 해당 항목이 적용되고 값이 실제로 0일 때만 표시돼요.
- 빈 값은 해당 항목이 적용되지 않을 때만 표시돼요. 예를 들어 결제하지 않은 주문의 결제 수단이 그래요.

**리포트용으로 고정된 구조**

- 열 순서가 항상 같아서 피벗, 가져오기, BI 파이프라인에 쓰기 좋아요.
- 상품과 세금 항목이 있으면 한 주문이 여러 행으로 나오는 것이 정상이에요. 합계를 묶어서 계산할 때는 **내부 주문 ID**를 기준으로 하세요.

## 여러 행으로 나뉘는 주문 이해하기 (중요)

예시 1:

한 주문에 다음이 들어 있어요.

- 상품 3개
- 세금 2개 (둘 다 가격 외 별도 세금)

CSV에는 총 **6행**이 만들어질 수 있어요.

- **상품마다 2행**
- **세금은 6행: 상품별로 세금 이름마다 세금 금액이 새 행으로 들어가요.**
  → 모두 같은 내부 주문 ID를 공유해요.

예시 2:

한 주문에 다음이 들어 있어요.

- 상품 3개
- 세금 2개 (상품 1에는 둘 다 별도 세금, 상품 2에는 둘 다 가격에 포함된 세금이 붙고, 상품 3에는 세금 없음)

CSV에는 총 **5행**이 만들어질 수 있어요.

- **상품 2개는 각각 2행, 세 번째 상품은 1행**
- **세금은 4행: 처음 2개는 `<Tax Name 1>`, `<Tax Name 2>` 형식이고, 다음 2개는 `<Tax Name 1 (가격에 포함됨)>`, `<Tax Name 2 (가격에 포함됨)>` 형식이에요. 5번째 행은 세금 열에 값이 없어요.**
  → 모두 같은 내부 주문 ID를 공유해요.

## 자주 묻는 질문

### 같은 주문이 여러 행으로 나오는 이유가 뭔가요?

정확한 리포트를 위해 상품과 상품별 세금마다 회계용 행이 따로 필요하기 때문이에요.

### 일부 주문의 결제 수단이 비어 있는 이유가 뭔가요?

거래가 발생한 주문에만 **결제 수단**이 표시돼요.

### 결제하지 않았거나 미완료인 주문도 포함되나요?

네. 필터로 제외하지 않으면 포함돼요.

### 이 파일에서 구독 결제 내역도 확인할 수 있나요?

이 파일에는 주문 기준으로 구독 상품이 있는지(개수)만 나와요. 구독 결제 이력은 들어 있지 않아요. 결제 이력은 구독 CSV 내보내기를 이용하세요.

### 지난 주문을 다시 내보낼 수 있나요?

네. 내보내기는 매번 새로 만들어져요.

### 주문 내보내기는 누가 할 수 있나요?

다음 권한이 있는 사용자가 할 수 있어요.

- ✔ **View Orders**(주문 보기)
- ✔ **Export Orders**(주문 내보내기)
