# 배송 프로필: 맞춤 배송비와 앱 연동 설정

배송 프로필을 쓰면 스토어 전체에서 상품별로 배송비를 다르게 정할 수 있어요. 상품 종류나 앱 연동에 맞춰 정확한 배송비를 받을 수 있고, 어떤 프로필에도 속하지 않은 상품은 **일반 프로필**이 자동으로 처리해요.

## 배송 프로필이란?

배송 프로필은 특정 상품, 스토어, 앱 연동에 별도의 배송 규칙을 적용하는 기능이에요. 지역과 요금 유형을 기준으로 고객이 결제할 때 내는 배송비가 정해져요.

상품이 맞춤 프로필에 속해 있지 않으면 **일반 프로필**이 자동으로 적용돼요. 그래서 결제 화면에는 항상 유효한 배송비가 표시돼요.

### 배송 프로필의 장점

- **유연한 설정:** 부피가 큰 상품과 가벼운 상품에 서로 다른 배송비를 정할 수 있어요.
- **다양한 요금 방식:** 정액, 무게 기준, 금액 기준, 무료 배송 중에서 고를 수 있어요.
- **앱 연동:** 외부 배송 앱의 배송비를 자동으로 가져와요.
- **정확한 결제 금액:** 여러 배송 프로필의 배송비를 하나로 합쳐서 보여 줘요.
- **안전장치:** 어떤 프로필에도 속하지 않은 상품은 자동으로 **일반 프로필**을 사용해요.

## 일반 프로필

**일반 프로필**은 스토어를 만들 때 자동으로 생겨요. 맞춤 프로필이나 앱이 정한 프로필에 속하지 않은 모든 상품에 적용돼요.

기본 배송비로 쓰거나, 외부 앱이 배송비를 가져오지 못할 때 대신 쓰는 용도로 활용하세요.

## 맞춤 프로필

맞춤 프로필을 쓰면 특정 상품이나 상품 그룹에 원하는 배송비를 따로 정할 수 있어요.

프로필마다 다음을 설정할 수 있어요.

- 하나 이상의 스토어에 적용
- 포함할 상품 선택
- 국가, 지역, 도·주 단위로 배송 지역 지정
- 요금 유형(정액, 금액 기준, 무게 기준, 무료 배송)을 자유롭게 조합

상품은 한 번에 맞춤 프로필 하나에만 속할 수 있어요. 상품을 다른 프로필에 다시 지정하면 이전 프로필 설정은 덮어써져요.

![맞춤 프로필 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055669280/original/5hBunWaBUGORsnuuDCQ4j4917nxI_S9UdA.png?1760076786)

## 결제 시 배송비 계산 방식

고객이 여러 프로필의 상품을 함께 사면 하이퍼클래스가 배송비 합계를 자동으로 계산해요.

- 프로필 이름이 서로 다르면 결제 화면에 “배송”이라는 한 줄로 표시돼요.
- 프로필 이름이 같으면 배송비를 합쳐서 그 이름으로 표시돼요.

이렇게 하면 여러 프로필의 상품이 섞인 주문에도 배송비가 정확하고 투명하게 표시돼요.

### 결제 화면의 배송 옵션 표시 순서

결제 화면에 배송 옵션이 여러 개 나오면 하이퍼클래스는 가격이 낮은 순서로 정렬하고 가장 저렴한 옵션을 미리 선택해 둬요. **Free Shipping**(무료 배송)을 쓸 수 있으면 맨 위에 표시되고 선택돼요. 주소나 장바구니가 바뀌어 배송비가 다시 계산되면 정렬과 기본 선택도 다시 적용돼요.

![결제 화면의 배송 옵션 표시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073331229/original/9tNtAkEeWEteS8_r-r0Ku-W4VrkdsUdBeQ.png?1781079794)

## 배송 프로필 설정하기

다음 단계를 따라 새 프로필을 만들고 배송비를 정하세요.

1. **결제 > 설정 > 배송 > 맞춤 프로필**로 이동하세요.
2. **커스텀 추가**를 클릭하세요.
3. 겹치지 않는 프로필 이름을 입력하세요. 이 이름은 내부에서만 쓰여요.
4. 이 프로필을 적용할 스토어를 선택하세요.
5. 포함할 상품이나 상품 그룹을 선택하세요.
6. **지역 추가**를 클릭하고 배송할 국가나 지역을 선택하세요.

   ![지역 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055669365/original/G3q_IcTpmFoKIqvTDDAuEf9GIKBZreuACg.png?1760076895)

7. 지역마다 요금 유형을 하나 이상 추가하세요.
   - 정액 요금(예: $5)
   - 금액 기준(예: $50 이상 무료)
   - 무게 기준(예: 0~10 lb에 $10)
   - 무료 배송
8. 설정이 끝나면 **저장**을 클릭하세요.
9. 테스트 주문을 해서 결제 화면에 배송비가 올바르게 표시되는지 확인하세요.

{% hint style="info" %}
**팁:** **일반 프로필**을 먼저 설정한 다음, 배송비를 따로 정해야 하는 상품이나 지역에만 맞춤 프로필을 더하세요.
{% endhint %}

## 우편번호로 배송 지역 제한하기

배송 지역을 만들거나 편집할 때 특정 우편번호에만 적용되도록 제한할 수 있어요. 아주 좁은 지역만 배송하거나, 원하지 않는 지역에 배송 지역이 적용되는 것을 막을 때 유용해요.

### 우편번호 제한 켜기

1. 배송 지역에서 **Limit Shipping to Specific ZIP/Postcodes**(특정 우편번호로 배송 제한)를 켜세요.
2. 우편번호를 하나 이상 입력하세요. 다음 형식을 쓸 수 있어요.
   - 코드 하나: `100210`
   - 쉼표로 구분한 여러 코드: `100210,122021`
   - 앞자리가 같은 코드 전체(와일드카드): `46*` 은 "46"으로 시작하는 모든 우편번호에 해당해요.

![우편번호 제한 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064557369/original/WOF4431SGZsN8YlsvocBa0KMZjSeB8olUg.png?1770715257)

### 입력 규칙

- 와일드카드는 끝에 붙이는 별표(`*`)로만 쓸 수 있어요. 예: `56*`
- 우편번호 제한을 켰는데 올바른 값이 하나도 없으면 배송 지역을 저장할 수 없어요.
- 올바르지 않거나 중복된 값은 입력할 때 막혀요.

## 자주 묻는 질문

### 맞춤 프로필 두 개가 같은 이름을 쓸 수 있나요?

아니요. 결제 화면에서 헷갈리지 않도록 프로필 이름은 겹치지 않아야 해요.

### Printful 상품의 실시간 배송비는 어떻게 적용되나요?

Printful 연동을 연결하고 Printful 상품을 동기화하면 시스템이 결제 시 실시간 배송비를 적용하도록 Printful 배송 프로필을 자동으로 만들어요.

주요 동작은 다음과 같아요.

- Printful 배송 프로필은 배송비가 올바르게 계산되도록 시스템이 만든 프로필이에요. 직접 수정하지 않는 것을 권장해요.
- 결제 시 실시간 배송비를 받으려면 상품이 Printful 프로필에 계속 속해 있어야 해요.
- 상품을 Printful 프로필에서 빼면 그 상품의 배송비가 비활성화돼요.
- Printful 배송 프로필을 삭제하면 자동으로 다시 만들어지지 않아요. 프로필을 되살리려면 Printful 연동을 다시 설치하세요.

### Printify 상품의 실시간 배송비는 어떻게 적용되나요?

Printify를 연결하고 상품을 동기화하면 하이퍼클래스가 Printify 전용 배송 프로필을 자동으로 만들어요.

이 프로필에 속한 상품은 결제 시 Printify의 실시간 배송비를 받아요. 실시간 배송비를 계속 받으려면 상품이 Printify 배송 프로필에 계속 속해 있어야 해요.

### 맞춤 프로필을 삭제하면 어떻게 되나요?

그 프로필에 속해 있던 상품은 자동으로 **일반 프로필**로 돌아가요.

### 여러 프로필의 상품이 섞인 장바구니는 배송비를 어떻게 계산하나요?

해당하는 모든 프로필의 배송비를 더해서 하나의 배송비 줄로 보여 줘요.

### 앱 연동이 가져온 배송비를 직접 바꿀 수 있나요?

네. 같은 상품에 맞춤 프로필을 만들면 앱이 정한 배송비를 덮어쓸 수 있어요.

### 앱이 배송비를 가져오지 못하면 어떻게 되나요?

하이퍼클래스가 **일반 프로필**의 배송비를 대신 적용해요.

### 고객의 우편번호가 제한한 배송 지역과 맞지 않으면 어떻게 되나요?

고객의 우편번호가 설정한 값이나 와일드카드 패턴과 하나도 맞지 않으면 그 배송 지역은 결제 시 적용되지 않아요.

### 우편번호 범위는 어떻게 입력하나요?

입력값 끝에 별표(`*`)를 붙인 와일드카드를 쓰세요. 예를 들어 `56*` 은 `56`으로 시작하는 모든 우편번호에 해당해요.
