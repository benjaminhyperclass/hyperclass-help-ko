# 거래 내역을 CSV로 내보내기

거래 내역을 CSV 파일로 내려받는 방법을 안내해요. 파일이 어떻게 전달되는지, CSV 안의 한 거래가 여러 행으로 나뉘는 이유와 각 열의 의미도 함께 설명해요.

## 개요

거래 내역 CSV 내보내기를 쓰면 결제 기록을 자세히 내려받을 수 있어요. 리포트 작성, 대조, 회계, 컴플라이언스 업무에 활용해요.

내보내기 범위는 두 가지예요.

- 전체 거래
- 적용한 필터나 검색 결과에 해당하는 거래

내보낸 파일은 이메일로 받는 다운로드 링크로 전달돼요. 어떤 스프레드시트 도구로든 열 수 있어요.

## 거래 내역 내보내는 방법

1. **결제 > 거래 내역**으로 이동해요.
2. 필요하면 필터나 검색을 적용해요. *(예: 날짜 범위, 결제 상태, 소스 유형)*
3. **다운로드** 아이콘을 클릭해요.
4. 로그인한 사용자의 이메일로 보안 다운로드 링크가 발송돼요.

{% hint style="info" %}
이메일 링크는 7일 동안 유효하고, 내보내기를 요청한 사용자 전용이에요.
{% endhint %}

## 이메일 전달 방식

- 다운로드 링크는 몇 분 안에 도착해요.
- 앱 안에서 바로 내려받는 것이 아니라, 이메일로 받은 링크로 파일을 내려받아요.
- 링크가 만료되면 내보내기를 새로 요청하면 돼요.

## CSV 구조와 서식 규칙

CSV의 한 행이 항상 한 거래는 아니에요.

한 거래에는 아래 항목이 여러 개 들어갈 수 있어요.

- 상품: 상품마다 행이 따로 만들어져요.
- 세금: 상품별로 세금 이름이 다르면 그 수만큼 행이 만들어져요.
- 기타 요금(처리 요금, 연체료, 팁)

이렇게 하면 금액 항목을 하나씩 구분해서 볼 수 있어요. 같은 거래가 여러 행이면 모든 열이 매 행에 채워지지는 않아요. 각 행에는 주로 해당 상품이나 세금과 관련된 데이터만 들어가고, 거래 전체 데이터는 거래당 1개 행에만 들어 있어요.

## 데이터 일관성(내보내기 개선)

이 내보내기는 대조, 회계, BI 작업에 맞게 서식과 값이 일정하도록 만들어졌어요.

**0과 빈 값**

- 0은 해당 항목이 적용되고 값이 실제로 0일 때만 나와요.
- 빈 값은 해당 항목이 그 행(기록)에 적용되지 않을 때만 나와요.

**리포트용으로 고정된 구조**

- 열 순서가 항상 같아서 피벗, 가져오기, BI 파이프라인에 쓰기 좋아요.
- 여러 행으로 나뉘는 형식은 상품별·세금별로 금액을 배분하기 위한 의도된 구조예요. "한 행 = 한 거래"라고 가정하지 마세요.

## 서식 참고 사항

- 상품이 여러 개이면 같은 **거래 ID** 아래에 행이 여러 개 만들어져요.
- 세금이 여러 개이면 세금마다 행이 따로 나뉘고, 각 세금은 상품 항목에 속해요. 즉 상품 하나당 세금별로 행이 하나씩 생겨요.
  
  예를 들어 상품 2개에 같은 세금 2개가 붙으면 거래의 행은 모두 4개예요. 항목 1에 세금 1·세금 2가 붙어 2개 행, 항목 2에 세금 1·세금 2가 붙어 2개 행이 더해져요.
- 복합 결제(예: 카드 + 기프트 카드)는 금액 열에 구분되어 표시돼요. 합계 기준으로 필터링할 때는 스프레드시트에서 항상 신중하게 집계하세요.
- 세율 정밀도: 세율(퍼센트) 값은 소수점 4자리(예: 7.1250%)로 내보내져요. 소수 세율도 담고 리포트를 일관되게 유지하기 위해서예요. 세액은 통화 기준에 따라 소수점 2자리로 반올림돼요.

## 자주 묻는 질문

### 한 거래가 CSV에서 여러 행으로 나오는 이유가 뭔가요?

상품은 항목별로, 세금은 고유한 세금 이름별로 기록하기 때문이에요. 회계용 리포트에서는 일반적인 방식이에요.

### 총 미납 금액과 총 결제 금액이 다른 이유가 뭔가요?

처리 요금, 팁, 부분 결제는 처음 청구된 금액이 아니라 최종 결제 금액에 영향을 줘요.

### 내보낸 파일에 일부 거래가 안 보여요

아래를 확인해 보세요.

- 필터가 해제되어 있는지
- 날짜 범위가 올바른지

### 내보내기에 실패한 거래도 포함되나요?

네, 포함돼요. 성공이나 환불 거래만 보이도록 필터를 설정하면 제외돼요.

### 부분 환불도 내보내기에 포함되나요?

네, **Amount refunded**(환불 금액)에는 지금까지 환불된 전체 누적 금액이 표시돼요.

### 이전에 내보낸 파일을 다시 만들 수 있나요?

네, 내보내기는 언제든 다시 할 수 있어요.

### 누가 거래 내역을 내보낼 수 있나요?

거래 내역을 조회할 권한과 기록을 내보낼 권한이 모두 있는 사용자만 가능해요.
