# 주문 폼·캘린더·인보이스 결제의 영수증 관리

영수증은 고객에게 결제 내역을 확인해 주는 문서예요. 결제했다는 증빙이 되고, 사업자와 고객 모두 거래 기록을 정확하게 남길 수 있어요. 이 문서에서는 주문 폼, 캘린더 예약, 인보이스 결제에 대해 영수증을 자동으로 보내는 방법과 영수증을 사용자 지정하는 방법을 안내해요.

## 자동 영수증 켜기

자동 영수증을 켜면 주문 폼으로 구매한 연락처에게 영수증이 자동으로 발송돼요. 1단계·2단계 주문 폼의 기본 상품, 범프, 업셀 구매가 모두 해당돼요. 구독, 캘린더 예약 결제, 인보이스 결제에도 적용돼요.

![자동 영수증을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001928761/original/4w9wJHJTDuaiCHFEv_ZSWgZ_Yil6Ha-0YQ.gif?1687959346)

## 영수증 사용자 지정하기

하이퍼클래스에서는 영수증을 다음과 같이 사용자 지정할 수 있어요.

- 영수증 제목: 브랜드에 맞게 영수증 제목을 바꿀 수 있어요.
- 영수증 번호: 영수증 번호의 접두어와 시작 번호를 정할 수 있어요. 거래를 추적하고 관리하기가 쉬워져요.
- **이메일 템플릿**: 고객에게 영수증을 보낼 때 쓰는 이메일 내용을 원하는 대로 꾸밀 수 있어요. 브랜드 이미지에 맞는 일관된 이메일을 보낼 수 있어요.

## 영수증 발송 방식

영수증은 PDF 파일로 만들어져 이메일에 첨부된 채 연락처의 이메일 주소로 바로 발송돼요. 고객은 PDF를 내려받아 보관할 수 있어요.

## 사용자 지정 템플릿 활용하기

영수증을 보낼 때 사용자 지정 템플릿을 쓸 수 있어요. **이메일 빌더**에서 제공하는 커스텀 값을 활용하면, 브랜드에 맞는 영수증 템플릿을 직접 만들 수 있어요.

## 자주 묻는 질문

### 특정 결제 유형에만 영수증을 자동으로 보낼 수 있나요?

아니요. 영수증 발송을 켜면 주문 폼, 캘린더 예약, 인보이스로 이루어지는 모든 결제에 똑같이 적용돼요. 일부 결제에만 영수증을 보내고 싶다면 자동 영수증을 끄고, 필요한 결제에 대해서만 직접 보내야 해요.

### 영수증에 커스텀 필드나 개인 메시지를 넣을 수 있나요?

현재는 기본 거래 정보 외에 커스텀 필드나 개인 메시지를 영수증에 추가할 수 없어요. 대신 영수증에 연결된 **이메일 템플릿**을 수정해서 일반 안내 문구나 브랜딩 요소를 넣을 수 있어요.

### 결제가 처리되면 영수증이 바로 발송되나요?

네. 결제가 정상적으로 처리되면 영수증이 고객에게 자동으로 발송돼요. 다만 받는 사람의 이메일 서버처럼 하이퍼클래스가 통제할 수 없는 이메일 전달 요인 때문에 늦어질 수 있어요.

### 영수증이 고객에게 잘 전달됐는지 어떻게 확인하나요?

서브 계정의 **Email Reporting**(이메일 리포팅)에서 확인할 수 있어요.

1. **마케팅 > 이메일 > Email Reporting**으로 이동하세요.
2. 필터를 사용해 받는 사람의 이메일 주소나 영수증 이메일 제목으로 검색하세요.

리포팅 화면에서 이메일이 전달됐는지, 열람됐는지, 반송됐는지 등 발송 상태를 볼 수 있어요. 이 정보로 고객이 영수증을 받았는지 확인할 수 있어요.

### 고객에게 영수증 이메일이 자동으로 발송되지 않게 하려면 어떻게 하나요?

영수증을 직접 보내거나 Stripe 같은 외부 플랫폼으로 보내고 싶다면, 기본 자동 영수증을 끄면 돼요.

1. 왼쪽 메뉴에서 **결제**로 이동하세요.
2. 페이지 위쪽의 **설정**을 클릭하세요.
3. **Receipts**(영수증) 탭을 선택하세요.
4. **결제 시 자동 영수증 발송 활성화** 토글을 찾으세요.
5. 토글을 끄고 **저장**을 클릭하세요.

### 영수증 번호를 더 짧거나 낮은 번호로 바꿀 수 있나요?

아니요. 영수증 번호는 자동으로 생성되고, 항상 직전에 쓴 번호보다 커야 해요. 수정하거나 초기화하거나 덮어쓸 수 없어요.

### 자동 영수증을 끄면 결제 기록은 남나요?

네. 이메일 발송을 꺼도 내부 장부 기록에는 영향이 없어요. 성공한 결제는 모두 **거래 내역** 탭에 그대로 기록돼요.

### 이 설정은 일회성 결제와 반복 결제 모두에 적용되나요?

네. 이 토글을 끄면 연결된 결제 게이트웨이로 처리되는 모든 거래 유형에서 자동 영수증 이메일이 발송되지 않아요.
