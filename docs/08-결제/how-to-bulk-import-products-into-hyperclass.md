# CSV 파일로 상품 한꺼번에 가져오기

CSV 파일 하나로 여러 상품을 한 번에 하이퍼클래스로 가져오는 방법을 안내해요. 재고가 많거나 Shopify 같은 다른 곳에서 상품을 옮겨 올 때 쓰면 편해요.

## 시작하기 전에

다음 세 가지를 준비하세요.

- **결제 > 상품** 페이지에 접근할 수 있는 권한
- 상품 정보를 담은 CSV 파일(형식이 맞아야 해요)
- 하이퍼클래스에서 내려받은 참고용 샘플 CSV 파일

## 상품 가져오기 절차

### 1단계: 상품 페이지 열기

1. 하이퍼클래스 계정에 로그인하세요.
2. **결제 > 상품**으로 이동하세요.

![결제 > 상품 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034842506/original/3umRXzbM9xZMwYElr-IR0-e7Hbp6ZE32EA.png?1729108671)

### 2단계: 샘플 CSV 내려받기

1. 상품 페이지에서 **CSV로 가져오기**를 클릭하세요.
2. 팝업 창이 열려요. 창 아래쪽에 샘플 CSV 파일을 내려받는 항목이 있어요.
3. 샘플 파일을 내려받아 필요한 형식과 필드를 확인하세요.

![CSV로 가져오기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034842586/original/q4bkzD20ec-QWmtOl0_3KdGjkQ_ztWP1EA.png?1729108801)

![샘플 CSV 파일 내려받기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034842591/original/rLs6KJ1OgtwUTcZquwkTUYth8P4YeVaDUg.png?1729108811)

### 3단계: CSV 파일 준비하기

1. 내려받은 샘플 CSV 파일을 Excel, Google Sheets 등 편한 스프레드시트 도구로 여세요.
2. 상품마다 필요한 필드를 채우세요. 다음과 같은 필수 필드가 있을 수 있어요.
   - 상품명
   - **Price**(가격)
   - **SKU**(재고 관리 단위)
   - 설명
   - 카테고리
3. 가져오는 중에 오류가 생기지 않게, 각 필드를 샘플 파일의 형식과 똑같이 맞추세요.
4. 작성을 마친 파일을 .csv 형식으로 저장하세요.

{% hint style="info" %}
팁: 중복된 SKU나 특수문자가 없는지 한 번 더 확인하세요. 문제를 일으킬 수 있어요.
{% endhint %}

{% hint style="warning" %}
서비스 상품을 가져올 때는 샘플 파일의 일부 필드(무게, 재고, 이미지 소스 등)가 필요 없을 수 있어요. 그런 필드는 값을 비워 두면 돼요. 단, 열 머리글은 지우지 마세요. 서식 오류를 막으려면 모든 열 머리글이 그대로 있어야 해요.
{% endhint %}

![스프레드시트에서 CSV 파일 작성](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034842604/original/TUKWiKIpnKGr-TaN6BcEMpeeOjaYyUNiyA.png?1729108834)

### 4단계: CSV 파일 업로드하기

1. **결제 > 상품** 페이지로 돌아가세요.
2. **CSV로 가져오기** 버튼을 클릭하세요.
3. 준비한 CSV 파일을 내 기기에서 선택하세요.
4. 파일 내용의 미리보기가 나타나요.

### 5단계: 미리보기 확인하기

1. 미리보기에서 상품 정보가 모두 정확한지 확인하세요.
2. 문제가 있으면 CSV 파일에서 바로 고친 뒤 다시 업로드하세요.
3. 내용에 이상이 없는지 확인하세요.

![가져올 상품 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034842623/original/bB7cV2piSf2tAfbJEcBqUXtr68Qw7TYcfQ.png?1729108852)

### 6단계: 상품 가져오기

1. **상품 가져오기**를 클릭하면 마무리돼요.
2. 가져오기가 성공하면 상품이 하이퍼클래스에 등록되어 바로 쓸 수 있어요.

## 알아 두면 좋은 점

- 오류: CSV 파일에 문제가 있으면 무엇을 고쳐야 하는지 알려 주는 오류 메시지가 나타나요. 파일에서 오류를 고친 뒤 다시 업로드하세요.
- 기존 상품 업데이트: 같은 방법으로 상품 정보를 업데이트할 수 있어요. SKU가 서로 일치해야 매끄럽게 업데이트돼요.- 제한 사항: CSV 업로드에는 최대 파일 크기 제한이 있을 수 있어요. 업로드하기 전에 파일 크기를 확인하세요.

## 자주 생기는 문제

상품을 한꺼번에 가져올 때 자주 겪는 문제예요.

- 파일 형식 오류: 파일을 .csv 형식으로 저장했는지, 각 필드가 샘플 형식과 맞는지 확인하세요.
- 필수 필드 누락: 상품명, SKU, 가격 같은 필수 필드가 모두 채워져 있는지 다시 확인하세요.
- 특수문자: 가져오는 중에 문제를 일으킬 수 있는 특수문자는 지우세요.

{% hint style="info" %}
직접 해결하기 어려운 문제가 있으면 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

## 자주 묻는 질문

### CSV로 가져오기로 기존 상품을 업데이트할 수 있나요?
아니요, CSV로 가져오기로는 기존 상품을 업데이트할 수 없어요.
### 가져오는 중에 CSV 파일에 오류가 있으면 어떻게 되나요?
화면에 오류 메시지가 나타나요. 오류를 모두 해결한 뒤 파일을 다시 업로드해야 해요.

### CSV 파일 하나로 가져올 수 있는 상품 수에 제한이 있나요?
CSV 파일 하나당 10MB까지예요.

### 물리적인 상품이 아니라 서비스를 가져오는데, 무게나 재고처럼 해당되지 않는 필드는 어떻게 하나요?
서비스처럼 물리적이지 않은 상품은 해당되지 않는 필드(무게, 크기, 이미지 소스, 재고 등)를 비워 둘 수 있어요. 하지만 열 머리글은 CSV 파일에 그대로 있어야 해요.

열을 통째로 지우거나 머리글 이름을 바꾸면 “Column 1 is not correct.” 같은 오류가 나요. 값이 비어 있더라도 항상 샘플 CSV의 열 구조를 그대로 따르세요.

### CSV 파일을 가져오면 하이퍼클래스에 있는 기존 상품 데이터를 덮어쓰나요?
아니요, 이 기능으로는 상품을 업데이트할 수 없어서 덮어쓰기도 일어나지 않아요.
