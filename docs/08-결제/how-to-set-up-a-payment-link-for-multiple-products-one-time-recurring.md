# 여러 상품(일회성·반복)을 담은 결제 링크 만들기

일회성 상품과 반복 상품을 한 개의 하이퍼클래스 결제 링크로 묶는 방법을 안내해요. 디지털 상품, 구독, 서비스 패키지를 한 곳에서 설정하고 결제 과정을 간단하게 만들고 싶을 때 따라 해 보세요.

## 여러 상품을 담은 결제 링크란?

하이퍼클래스의 결제 링크를 쓰면 일회성 상품과 반복 상품 여러 개를 하나의 결제 화면으로 합칠 수 있어요. 묶음 패키지, 디지털 상품, 구독 서비스를 함께 판매하는 비즈니스에 특히 유용해요. 상품마다 링크를 따로 만들 필요 없이 하나의 결제 흐름에서 모두 관리할 수 있어요. 고객의 구매 경험도 좋아지고, 내부에서 결제 내역을 추적하기도 쉬워져요.

## 결제 링크에 여러 상품을 담을 때 좋은 점

- **통합 결제 화면**: 고객이 일회성 상품과 반복 상품 옵션을 한 화면에서 정리된 상태로 볼 수 있어요.
- **판매 전략 개선**: 업셀과 교차 판매 옵션을 함께 보여 주어 주문 금액을 높일 수 있어요.
- **깔끔한 고객 경험**: 반복 상품은 한 번에 하나만 선택할 수 있고, 일회성 상품은 여러 개를 선택할 수 있어요.
- **관리할 링크 감소**: 모든 상품이 공유와 추적이 가능한 링크 하나로 묶여요.
- **브랜드에 맞는 설정**: 페이지 디자인, URL, 결제 후 동작을 브랜드에 맞게 조정할 수 있어요.

## 여러 상품을 담은 결제 링크 설정하기

### 결제 링크 화면으로 이동하기

왼쪽 메뉴에서 **결제**를 클릭한 다음, 화면 상단의 **결제 링크**를 클릭하세요. 이 화면에서 기존 결제 링크와 새 결제 링크를 만들고, 관리하고, 확인할 수 있어요.

![왼쪽 메뉴의 결제에서 결제 링크 화면으로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600532/original/-4K_Wq7MBjQbV2qbIdygu9XOjxGBFrIVNg.png?1750410002)

### 새 결제 링크 만들기

**결제 링크** 화면 오른쪽 위의 **+ 새 결제 링크 만들기** 버튼을 클릭하세요. 여기서부터 상품 선택, 결제 페이지 꾸미기, 추가 옵션 설정을 진행해요.

![결제 링크 화면 오른쪽 위의 새 결제 링크 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600598/original/cjUFrlzCpJYslgapPWF5y1O9W6M6oTCkqQ.png?1750410072)

### 상품 선택하기

결제 링크에 넣을 첫 번째 상품을 **상품을 선택하세요**에서 고르세요. 상품 라이브러리에 있는 일회성 상품과 반복 상품 중에서 고를 수 있어요. 이 첫 번째 선택을 마쳐야 다른 상품을 추가하거나 결제 설정을 이어서 할 수 있어요.

![상품을 선택하세요 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600644/original/wQxAwsPoZ_D3amZMFYn01DBl-SZBIHnv4w.png?1750410107)

### 다른 상품 추가하기

**+ 다른 상품 추가** 버튼을 클릭하면 같은 결제 링크에 상품을 더 넣을 수 있어요. 일회성 상품은 여러 개, 반복 상품은 한 개를 함께 담을 수 있고, 고객은 한 번의 결제 과정에서 여러 상품을 선택할 수 있어요. 결제 페이지에서 반복 상품은 따로 묶여서 보여요.

![다른 상품 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600727/original/_CiLXvT6B-RwQFRQD7b6Zn8td3jCrM1Mag.png?1750410157)

### 상품 수량 선택 켜기

**고객이 수량을 조정하도록 허용** 체크박스를 선택하면 고객이 일회성 상품을 몇 개 살지 직접 정할 수 있어요. 최소·최대 수량을 정해서 대량 주문을 조절할 수도 있어요. 여러 개가 필요한 고객에게 더 편한 결제 환경이 돼요.

![고객이 수량을 조정하도록 허용 체크박스](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600756/original/BfjtTmvOSX5WiuqZWT08CWZ3KNmsu1NVCQ.png?1750410195)

### 고객 전화번호 수집하기

**Require customers to add a phone number**(고객에게 전화번호 입력 필수로 요청) 옵션을 켜면 결제할 때 전화번호를 꼭 입력하게 할 수 있어요. 후속 연락, 서비스 조율, 본인 확인에 도움이 돼요. 전화번호 입력란은 폼의 다른 연락처 정보와 함께 표시돼요.

![전화번호 입력 필수 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600801/original/5vp0oMLXrfzSg1GoqGqnXS1U8V7i5ijLeg.png?1750410235)

### 고객 주소 수집하기

배송지나 청구지 정보가 필요하면 **고객 주소 수집** 옵션을 켜세요. 켜면 결제 페이지에 도로명, 도시, 주(시·도), 국가, 우편번호 입력란이 나타나요. 실물 상품을 배송하거나 규정을 지켜야 할 때 알맞아요.

![고객 주소 수집 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600876/original/LoixILuUX1P3pohukwL8jX1YycZG73oapA.png?1750410269)

### 결제 시 쿠폰 코드 사용하게 하기

**쿠폰 코드 허용** 옵션을 선택하면 결제 페이지에 쿠폰 코드 입력란이 표시돼요. 고객이 할인 코드를 적용할 수 있어서 프로모션 캠페인을 진행하고 전환을 높이는 데 도움이 돼요.

![쿠폰 코드 허용 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600962/original/xyC73GpDSPrUvi4LbXP_qSKfZNHNjuwLHw.png?1750410324)

### 결제 후 리다이렉트 URL 추가하기

**커스텀 URL로 리디렉션 켜기** 옵션을 켜면 결제를 마친 고객을 원하는 페이지로 자동 이동시킬 수 있어요. 이동할 주소를 정하고, 새 탭에서 열지 현재 탭에서 열지 선택할 수 있어요. 감사 페이지나 다음 단계 안내 페이지로 보내기에 좋아요.

![커스텀 URL로 리디렉션 켜기 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048600983/original/v2m03c5md8G2K14FeQZNzCDVlvis1X2Gzw.png?1750410364)

### 행동 유도 버튼 문구 바꾸기

**행동 유도 문구** 아래의 드롭다운에서 결제 링크 버튼에 표시할 문구를 상품에 맞게 고를 수 있어요. “결제”, “예약”, “기부” 같은 옵션 중에서 상품 유형이나 고객의 이용 흐름에 맞는 문구를 선택하세요. 고객에게 무엇을 하게 되는지 분명히 알려 주어 전환에 도움이 돼요.

![행동 유도 문구 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601002/original/03PzJFoAfUkcIf36kBteTwAiMx_UsfqH3w.png?1750410394)

{% hint style="info" %}
버튼 문구 변경은 모든 결제 링크 유형에서 쓸 수 있어요. 고객은 모든 기기에서 바꾼 문구를 보게 돼요. 이미 결제 페이지를 열어 둔 고객은 페이지를 새로고침해야 바뀐 문구가 보여요.
{% endhint %}

### 브랜딩 메시지 추가하기

**브랜딩** 옵션을 켜면 결제 페이지에 직접 정한 “Powered by” 문구를 넣을 수 있어요. 문구를 수정해서 에이전시나 비즈니스 이름을 표시하면, 결제하는 동안 브랜드를 더 잘 알리고 신뢰를 줄 수 있어요.

![브랜딩 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601034/original/eJWkFLuqr5KLotXLkAIVcIIdlk2mKxh-VA.png?1750410427)

### 이용약관 추가하기

**이용약관** 옵션을 사용하면 거래와 관련된 법적 내용이나 정책 안내를 넣을 수 있어요. 입력한 내용은 결제 페이지의 결제 버튼 바로 아래에 표시돼서, 고객이 결제를 완료하기 전에 주요 약관을 확인하게 돼요. 읽기 쉽도록 텍스트 서식을 지정하거나 강조할 수도 있어요.

![이용약관 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601053/original/9t7fgIL0owliEUJ56VyapoVfKby-bGMfIg.png?1750410448)

### 자동 비활성화 날짜 정하기

**자동 비활성화** 설정에서 결제 링크가 만료될 날짜를 정할 수 있어요. 기간 한정 오퍼, 제한된 캠페인, 구독 가입 기간이 정해진 경우에 유용해요. 정한 날짜가 되면 고객이 더 이상 그 링크에 접근할 수 없어요.

![자동 비활성화 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601113/original/Nk2MWmjph7o4kRkJ1QlQB08lXGSIHXcGhA.png?1750410487)

### 테스트 모드와 라이브 모드 선택하기

**결제 모드** 토글로 **테스트**와 **라이브** 환경을 전환할 수 있어요. **테스트** 모드에서는 실제 결제 없이 테스트 카드 번호로 결제를 시험해 볼 수 있어요. 고객에게서 실제 결제를 받을 준비가 되면 **라이브** 모드로 바꾸세요.

![결제 모드 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601161/original/jwui0qEAgW9MWF_4o-uafCRNZ3JGWJ_icQ.png?1750410517)

### 결제 링크 이름 정하기

화면 위쪽의 입력란에 결제 링크 이름을 입력하세요. 이 이름은 대시보드에서 링크를 구분하고 정리하기 위한 내부용 이름이에요. 고객이 보는 결제 페이지에는 영향을 주지 않아요.

![결제 링크 이름 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601199/original/E1evz36kl3gPxes3NuHXlfUs4Yp_HP2VkA.png?1750410561)

### 결제 링크 공유하기

**복사 / 보내기** 버튼을 클릭하면 결제 링크를 전달하는 옵션이 나와요. 누구에게나 공유할 수 있는 일반 링크를 복사하거나, 하이퍼클래스에서 이메일이나 SMS로 개인별 링크를 바로 보낼 수 있어요.

![복사 / 보내기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601261/original/Yt1Vv9QawWQkYRxAo_fuql2M_V0q4EpAHA.png?1750410598)

### 결제 링크 복사하거나 개인별 링크 만들기

일반 용도로 쓸 표준 링크를 복사하거나, 고객 정보가 미리 채워진 개인별 결제 링크를 만들 수 있어요. 드롭다운 메뉴에서 연락처를 선택하면 그 연락처 전용 결제 링크가 만들어져요.

![표준 링크 복사 또는 개인별 링크 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601413/original/qsKn9wSPse8-AQ35QHVj1yTbitkygLbTiA.png?1750410664)

### 연락처에 링크 보내기

**Send to Contacts**(연락처에 보내기) 옵션으로 결제 링크를 이메일, SMS 또는 둘 다로 보낼 수 있어요. 연락처를 선택하고, 보내는 방법을 고른 다음, 제목과 템플릿을 캠페인이나 오퍼에 맞게 수정하세요.

![연락처에 결제 링크 보내기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601640/original/LajFAuBQcQO8NBhvq4kxoUhyzBI-JlF2pw.png?1750410851)

### 결제 링크의 결제 페이지 미리보기

**미리보기** 버튼을 클릭하면 고객에게 결제 링크가 어떻게 보이는지 확인할 수 있어요. 링크를 공개하기 전에 상품 묶음, 브랜딩 요소, 폼 입력란, 전체 레이아웃을 점검해 보세요.

![결제 페이지 미리보기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601696/original/8uQYT_C-9jLmcX6bjWJ1lcRvHkegiU8tYQ.png?1750410918)

### 결제 링크 저장하기

상품과 설정을 모두 확정했다면 **저장** 버튼을 클릭해서 결제 링크를 게시하세요. 그러면 링크가 활성화되고, 원하는 채널로 고객에게 공유할 수 있어요.

![저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048601773/original/WnE_sAbHgCi8kb_MkdZewSSM1fvD3If9XA.png?1750410955)

## 자주 묻는 질문

### 일회성 상품은 몇 개까지 추가할 수 있나요?

제한이 없어요. 비즈니스에 필요한 만큼 일회성 상품을 넣을 수 있어요.

### 쿠폰 코드를 모든 상품에 적용할 수 있나요?

네, 결제할 때 쿠폰 코드를 입력할 수 있고, 장바구니에 있는 적용 가능한 상품에 할인이 적용돼요.

### 결제 화면에서 상품은 어떻게 나뉘어 보이나요?

**일회성 상품**과 **반복 상품**으로 나뉘어 표시돼서 구분하기 쉬워요.

### 결제 링크를 웹사이트에 삽입하거나 공유할 수 있나요?

네. 이메일이나 소셜 미디어로 링크를 공유할 수 있고, 웹사이트에 삽입할 수도 있어요.
