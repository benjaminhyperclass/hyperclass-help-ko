# CSV 파일로 거래 내역과 주문 가져오기

과거 거래 내역과 주문을 CSV 파일로 하이퍼클래스 서브 계정에 한꺼번에 가져오는 방법을 안내해요. 다른 플랫폼에 흩어져 있던 결제 데이터를 한곳에 모아 대시보드를 정확하게 유지하고, 매출 리포팅도 편하게 관리할 수 있어요.

## 거래 내역·주문 가져오기란?

CSV 파일을 이용해 과거 거래 내역과 주문을 한꺼번에 가져올 수 있어요. 과거 결제 데이터가 서브 계정에 모이므로, 대시보드와 연락처 타임라인에 정확한 매출 이력이 반영돼요.

## 거래 내역·주문 가져오기의 장점

가져오기를 쓰면 결제 기록을 깔끔하게 한곳에서 관리할 수 있어요. 이 기능으로 할 수 있는 일은 다음과 같아요.

- 이전에 쓰던 플랫폼의 과거 데이터를 쉽게 가져올 수 있어요.
- 매출 대시보드와 지표에 자동으로 반영돼요.
- 가져오기로 고객 정보를 만들거나 업데이트할 수 있어요.
- 데이터를 가져온 시각과 실제 거래 시각을 따로 기록해요.
- 업로드 전에 미리보기로 간단히 확인하고 검증할 수 있어요.
- 형식 안내와 내려받을 수 있는 샘플 CSV가 제공돼요.

## 거래 내역 가져오기

거래 내역을 가져오면 실제 결제 내역을 그대로 불러올 수 있어요. 연결된 주문 항목을 꼭 만들어야 하는 것은 아니에요.

1. **결제 > 거래 내역**으로 이동하세요.
2. **가져오기** 버튼을 클릭하세요.
3. **Sample CSV**(샘플 CSV)를 내려받아 내 데이터가 필요한 형식과 같은지 확인하세요.
4. **파일 업로드**에서 파일을 올리고, 미리보기 창에서 검증 결과를 확인하세요.
5. 가져오기를 확정하세요.  
   ![거래 내역 가져오기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048479428/original/8zRY5lm6EdGJmGSyl0fa1mna_mBBuzAu0Q.png?1750253844)

{% hint style="info" %}
거래 내역은 추가되는 즉시 매출 지표에 반영돼요.
{% endhint %}

## 주문 가져오기

주문은 항목별 판매 내역이에요. 주문을 가져오면 연결된 거래 내역이 자동으로 함께 만들어져요.

1. **결제 > 주문**으로 이동하세요.
2. **가져오기**를 선택한 다음, 형식에 맞게 작성한 CSV 파일을 업로드하세요.
3. 미리보기에서 데이터를 확인하세요.
4. 주문 기록마다 거래 내역이 자동으로 만들어지고 매출에 반영돼요.  
   ![주문 가져오기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048479458/original/xJI-izG6J90dtTt715A6igSaT5OPjE3xaA.png?1750253871)

{% hint style="info" %}
주문과 거래 내역 모두 대시보드와 리포팅에 반영돼요.
{% endhint %}

## CSV 파일 필드 형식

필요한 구조를 미리 알아 두면 오류 없이 업로드할 수 있어요.

- 필드 이름은 정해진 이름과 정확히 같아야 해요.
- 연락처를 찾거나 새로 만들 수 있도록 고객 세부 정보를 포함해야 해요.
- 거래 실행 날짜와 하이퍼클래스에 가져오는 날짜를 올바르게 입력해야 해요.

## 자주 묻는 질문

### 이미 하이퍼클래스에 있는 연락처가 중복으로 만들어지나요?

아니요. 하이퍼클래스는 새 연락처를 만들기 전에 이메일이나 전화번호로 기존 연락처와 일치하는지 먼저 확인해요.

### 거래 날짜를 과거로 지정할 수 있나요?

네. 거래가 실행된 날짜를 하이퍼클래스에 추가되는 날짜와 따로 지정할 수 있어요.

### CSV 파일에 오류가 있으면 어떻게 되나요?

가져오기를 진행하기 전에 미리보기에서 검증 문제가 표시돼요.

### 환불이나 무효 처리된 거래도 가져올 수 있나요?

아니요, 아직은 안 돼요. 성공적으로 완료된 거래와 주문만 가져올 수 있어요.

### 가져오기가 매출 집계에 영향을 주나요?

네. 가져온 내용에 따라 매출 대시보드와 다른 재무 대시보드가 업데이트돼요.

## 다음 단계

- **Revenue Dashboard**(매출 대시보드)에서 가져온 데이터가 반영됐는지 확인해 보세요.
- 연락처 타임라인에서 가져온 활동을 살펴보세요.
- 새 주문이나 거래 내역이 생기면 실행되는 자동화 워크플로우를 설정해 보세요.
