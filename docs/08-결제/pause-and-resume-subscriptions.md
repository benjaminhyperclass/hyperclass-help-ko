# 구독 일시정지 및 다시 시작

구독을 취소하지 않고 잠시 멈추고 싶을 때 쓰는 기능이에요. 구독을 **무기한**으로 또는 특정 날짜까지 일시정지하고, 일시정지 중 인보이스를 어떻게 처리할지 고른 뒤, 필요할 때 직접 다시 시작할 수 있어요. 이 문서에서는 일시정지와 다시 시작이 가능한 조건, 인보이스 처리 방식, 결제 재개 방법, 구독 관리에 영향을 주는 권한을 설명해요.

{% hint style="warning" %}
모든 구독에서 일시정지와 다시 시작을 쓸 수 있는 것은 아니에요. 결제 서비스 제공업체, 구독의 현재 상태, 내게 배정된 **결제** 권한에 따라 보이는 메뉴가 달라져요. 결제 관련 변경을 하기 전에 해당 구독에서 쓸 수 있는 작업을 항상 먼저 확인하세요.
{% endhint %}

## 구독 일시정지와 다시 시작이란?

정기 결제 중인 구독을 취소하지 않고 잠시 멈출 수 있는 기능이에요. 고객이 잠시 결제를 쉬었다가 나중에 구독을 이어 가려 할 때 유용해요.

대상 구독은 **무기한**으로 일시정지하거나 **사용자 지정 날짜**를 골라 일시정지할 수 있어요. **사용자 지정 날짜**로 일시정지하면 선택한 기간이 끝날 때 구독이 다시 시작돼요. **무기한**으로 일시정지하면 직접 다시 시작할 때까지 멈춘 상태로 있어요.

**사용자 지정 날짜**로 일시정지한 구독을 예정일보다 일찍 시작해야 한다면, **다시 시작**을 쓸 수 있는 경우에 직접 다시 시작할 수 있어요.

## 이럴 때 편해요

구독을 취소했다가 나중에 새로 만들 필요 없이, 고객이 잠시 쉬어 가야 할 때 유연하게 대응할 수 있어요.

- 일시적인 결제 유연성: 대상 정기 구독을 취소하지 않고 일시정지할 수 있어요.
- 유연한 일시정지 기간: 무기한 일시정지를 고르거나 다시 시작할 날짜를 직접 정할 수 있어요.
- 일찍 직접 다시 시작: **사용자 지정 날짜**로 일시정지한 구독을 선택한 기간이 끝나기 전에 다시 시작할 수 있어요.
- 인보이스 관리: 일시정지 중 인보이스를 **임시 저장**으로 둘지 **Mark as void**(무효 처리)로 처리할지 고를 수 있어요.
- 일시정지 이력 확인: 구독 데이터를 내보낼 때 일시정지 관련 날짜도 함께 내보내 결제 분석과 기록 관리에 쓸 수 있어요.

## 사용 조건과 제한 사항

구독 상태를 바꾸는 기능은 상황에 따라 보이는 메뉴가 달라요. 일시정지나 다시 시작 메뉴가 보이지 않을 때는 먼저 아래 조건을 확인하세요.

- 구독이 **결제 > 구독**에 있어야 해요.
- 일시정지와 다시 시작을 쓸 수 있는지는 구독의 결제 서비스 제공업체에 따라 달라질 수 있어요.
- 구독의 현재 상태에 따라 쓸 수 있는 작업이 달라질 수 있어요.
- 사용자에게 **결제** 모듈의 **구독** 관련 권한이 있어야 해요.
- 모든 결제 서비스 제공업체나 구독 상태에서 모든 작업을 지원하는 것은 아니에요.

정기 결제를 만들 수 있는 제공업체라고 해서 일시정지와 다시 시작까지 지원한다고 단정하지 마세요. 해당 구독에서 쓸 수 있는 작업을 직접 확인하세요.

### 사용자의 구독 권한 확인하기

구독 권한에 따라 스태프가 정기 결제 상태를 보고 관리할 수 있는지가 정해져요. 한 사용자는 구독을 관리할 수 있는데 다른 사용자는 할 수 없다면 이 권한을 확인해 보세요.

1. 해당 **서브 계정**에서 **설정**을 선택하세요.
2. **스태프 관리**를 선택하세요.
3. 권한을 확인할 사용자를 여세요.
4. **Roles & Permissions**(역할 및 권한)를 펼치세요.
5. **구독** 아래 권한을 확인하고, 사용자의 역할에 필요한 권한만 부여하세요.
6. **저장**을 선택해 권한 변경을 저장하세요.

## 구독 일시정지하기

대상 구독을 일시정지할 때는 일시정지 시간과, 그동안 예정된 인보이스를 어떻게 처리할지 함께 정해요. 확인하기 전에 두 설정을 꼼꼼히 살펴보세요.

1. 해당 **서브 계정**을 여세요.
2. **결제 > 구독**으로 이동하세요.
3. 일시정지할 구독을 찾으세요.
4. 구독의 **three-dot menu**(점 3개 메뉴)를 여세요.
5. 일시정지 항목을 선택하세요.

![구독의 점 3개 메뉴에서 일시정지 항목을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081216168/original/bVtDcJwSHQFrSZKuuZClEpOwAgm5cYyiyQ.png?1789662357)

6. **일시정지 시간**을 선택하세요.
   - **무기한**: 직접 다시 시작할 때까지 구독이 일시정지된 상태로 유지돼요.
   - **사용자 지정 날짜**: 일시정지가 끝나는 날짜를 직접 정해요. 이 경우에도 날짜 전에 직접 다시 시작할 수 있어요.
7. 일시정지 중 적용할 인보이스 처리 방식을 선택하세요.

![일시정지 기간과 인보이스 처리 방식을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081216190/original/i2RCZALOeJL4uenEWDoUgmQ1JQ8ZlZZNQA.png?1789662371)

8. 선택한 내용을 확인한 뒤 일시정지를 확정하세요.

## 일시정지 중 인보이스는 어떻게 처리되나요?

인보이스 처리 방식에 따라 일시정지 기간 동안 예정된 결제가 어떻게 다뤄질지 정해져요. 하이퍼클래스에서는 현재 **임시 저장**과 **Mark as void** 두 가지를 안내하고 있어요.

| 옵션 | 사용 방식 |
| --- | --- |
| **임시 저장** | 해당 인보이스를 임시 저장 상태로 두어 나중에 검토하고 처리할 수 있어요. |
| **Mark as void**(무효 처리) | 선택한 일시정지 기간 동안 예정된 결제에 안내된 무효 처리 방식을 적용해요. |

**임시 저장**과 **Mark as void**는 쓰임새가 달라요. 구독이 일시정지된 동안 예정된 결제 기록을 어떻게 처리할 계획인지에 맞춰 신중하게 고르세요.

## 구독 다시 시작하기

결제 서비스 제공업체, 구독 상태, 내 권한이 모두 허용하면 일시정지된 구독을 다시 정기 결제 상태로 되돌릴 수 있어요. **사용자 지정 날짜**로 일시정지한 구독은 직접 다시 시작하지 않아도 선택한 기간이 끝나면 다시 시작돼요.

1. 해당 **서브 계정**을 여세요.
2. **결제 > 구독**으로 이동하세요.
3. 일시정지된 구독을 찾으세요.
4. **three-dot menu**(점 3개 메뉴)를 여세요.
5. **다시 시작**을 선택하세요.
6. 확인 창의 내용을 살펴본 뒤 다시 시작을 확정하세요.

![일시정지된 구독에서 다시 시작을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081216228/original/u_X4smAXNXAVvQsUCPK-tKQSRQ1wdXFfFA.png?1789662386)

**사용자 지정 날짜**와 **무기한**의 차이: **사용자 지정 날짜**로 일시정지한 구독은 선택한 시점에 끝나거나 그 전에 직접 다시 시작할 수 있어요. **무기한**으로 일시정지한 구독은 반드시 직접 다시 시작해야 해요.

## 내보내기에서 일시정지·다시 시작 기록 확인하기

구독을 내보내면 **결제** 대시보드 밖에서도 일시정지 현황을 분석할 수 있어요. 현재 CSV 내보내기에는 리포트 작성, 대조, 이탈 방지 분석에 쓸 수 있는 일시정지 관련 날짜가 들어 있어요.

| 내보내기 필드 | 의미 |
| --- | --- |
| **Last paused on date**(마지막 일시정지 날짜) | 해당 구독의 가장 최근 일시정지 시각이에요. |
| **Resumed on date**(다시 시작한 날짜) | 구독이 일시정지 상태에서 실제로 다시 시작된 날짜예요. |
| **Pause end date**(일시정지 종료일) | 가장 최근에 날짜를 지정한 일시정지의 종료 예정일이에요(해당하는 경우). |

## 자주 묻는 질문

### 사용자 지정 다시 시작 날짜 전에 구독을 다시 시작할 수 있나요?
네. **사용자 지정 날짜**까지 일시정지한 구독은 **다시 시작**을 쓸 수 있을 때 선택한 기간이 끝나기 전에 직접 다시 시작할 수 있어요.

### 무기한 일시정지는 자동으로 다시 시작되나요?
아니요. **무기한**으로 일시정지한 구독은 직접 다시 시작할 때까지 일시정지 상태로 유지돼요.

### 구독을 일시정지할 때 어떤 인보이스 옵션을 고를 수 있나요?
현재 일시정지 과정에서는 인보이스 처리 방식으로 **임시 저장**과 **Mark as void**(무효 처리)를 안내하고 있어요.

### 구독에 일시정지나 다시 시작 메뉴가 안 보여요
쓸 수 있는 작업은 구독의 결제 서비스 제공업체, 현재 상태, 내 **결제** 권한에 따라 달라질 수 있어요. 메뉴가 없다고 오류로 판단하기 전에 이 세 가지를 모두 확인하세요.

### 같은 서브 계정을 쓰는데 사용자마다 보이는 구독 작업이 다를 수 있나요?
네. 두 사용자가 같은 서브 계정에 접근할 수 있어도, **결제** 권한에 따라 각 사용자가 할 수 있는 구독 작업이 제한될 수 있어요.

### 구독을 언제 일시정지하고 다시 시작했는지 리포트로 볼 수 있나요?
네. 구독 CSV 내보내기에는 마지막 일시정지 날짜, 다시 시작한 날짜, 일시정지 종료일(해당하는 경우) 같은 일시정지 관련 필드가 들어 있어요.

### 고객의 구독을 일시정지하는 것과 서브 계정을 일시정지하는 것은 같은 건가요?
아니요. 구독을 일시정지하면 정기 결제 구독의 상태가 바뀌어요. 서브 계정 일시정지는 서브 계정 접근에 영향을 주는 별도의 에이전시 단위 기능이에요.
