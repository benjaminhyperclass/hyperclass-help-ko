# 고객의 저장된 카드 추가·관리

연락처 화면에서 고객의 저장된 카드를 추가하고, 확인하고, 삭제하는 방법을 안내해요. 웹과 하이퍼클래스 모바일 앱에서 모두 쓸 수 있어요.

## 기능 소개

고객의 결제 수단을 잘 관리하면 결제가 빨라지고 고객 경험도 매끄러워져요. 저장된 카드 기능으로 다음 작업을 할 수 있어요.

- 저장된 카드 추가
- 저장된 카드 관리

결제 제공업체에서 카드 정보를 안전하게 불러와 화면에 보여 줘요. 이때 카드 번호 끝 3~4자리와 유효기간만 가져와요.

## 어디에서 찾나요?

**연락처 > 연락처 세부정보 > $ 아이콘(결제) > 작업**

![연락처 세부정보의 결제 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040240689/original/WVYWWuJI7Jv4y8Qyp5t3RmJK6pqb9iWUGQ.png?1737533686)

## 저장된 카드 추가하기

1. **작업** 아래의 **저장된 카드 추가** 버튼을 클릭하세요.
2. 카드 번호, 유효기간, CVV를 입력하고 국가를 선택하세요.
3. 입력한 내용을 확인한 뒤 **카드 추가**를 클릭하세요.

라이브 모드와 테스트 모드 카드 모두 추가할 수 있어요.

![카드 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040240066/original/kbLwbfrThQJCpo5GuFfFmlQ5uoYjVGtOdQ.png?1737533266)

## 저장된 카드 확인하기

1. **작업** 아래의 **카드 관리** 버튼을 클릭하세요.
2. 결제 제공업체별로 불러온 카드가 목록으로 표시돼요. 카드 번호 끝 3~4자리와 유효기간을 볼 수 있어요.

각 카드 항목에는 카드 번호 끝 4자리, 유효기간, 연결된 레이블이 표시돼요. 테스트 모드 카드와 라이브 모드 카드는 각각의 목록에 따로 나와요.

{% hint style="info" %}
규정상 카드 정보는 저장되지 않고, 저장할 수도 없어요. 그래서 어떤 고객이든 이 창에 들어올 때마다 결제 제공업체에서 카드 정보를 새로 불러와요.
{% endhint %}

![저장된 카드 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040240509/original/tdYVqXUe5dNHLmw6dNjJPSCWu6Y3wLMGag.png?1737533562)

## 저장된 카드 삭제하기

1. 제거할 카드를 찾으세요.
2. 카드 옆의 **삭제** 버튼을 클릭하세요.
3. 팝업 창에서 삭제를 확인하세요.

테스트 모드 카드와 라이브 모드 카드 모두 각각의 목록에서 삭제할 수 있어요.

하이퍼클래스에서 진행 중인 구독에 쓰이는 카드라면, 삭제를 확인하기 전에 팝업 창에서 그 사실을 알려 줘요. 안내를 보고도 카드를 삭제하면, 그 카드에 연결된 구독에는 자동 결제에 쓸 결제 수단이 없어져요.

![카드 삭제 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040240629/original/Js8bL097vaMfi0SU0nuyBPZRBZqDvEHEXw.png?1737533646)

![카드 삭제 확인 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040240539/original/44boYjs8sReSoKdtVfWatQbZjfOq__--9w.png?1737533586)

{% hint style="info" %}
규정상 카드 정보는 하이퍼클래스에 저장하지 않아요. 어떤 고객이든 이 창에 들어올 때마다 카드 번호 끝 3~4자리, 유효기간, 카드 브랜드(Visa/MasterCard 등)를 안전하게 불러와요. 이 정보는 결제 제공업체에서 직접 가져오고, 삭제도 결제 제공업체를 통해 처리돼요.
{% endhint %}

## 모바일 앱에서 저장된 카드 관리하기

하이퍼클래스 모바일 앱에서는 연락처 화면에서 바로 결제 수단을 저장해 두고, 이후 결제 작업에 다시 쓸 수 있어요. 반복 구매가 빨라지고 고객의 결제 정보도 깔끔하게 정리돼요.

이제 하이퍼클래스 모바일 앱의 연락처 결제 영역에서 고객의 카드를 저장하고, 확인하고, 제거할 수 있어요.

![모바일 앱의 연락처 결제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069168662/original/HHAjALdMGaFZFoDzlpi1DunR4pd3pzL6zw.png?1776234727)

### 모바일 앱에서 저장된 카드 추가하기

연락처에서 카드를 저장해 두면, 고객이 매번 결제 정보를 다시 입력하지 않아도 반복 구매와 후속 결제를 더 빠르게 처리할 수 있어요.

1. 하이퍼클래스 모바일 앱을 여세요.
2. **연락처**로 이동하세요.
3. 수정할 연락처를 선택하세요.
4. **결제** 탭을 여세요.
5. **카드 관리**를 탭하세요.
6. **New card**(새 카드)를 탭하세요.
7. 고객의 카드 정보를 입력하세요.
8. 카드를 저장하세요.

![카드 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069168662/original/HHAjALdMGaFZFoDzlpi1DunR4pd3pzL6zw.png?1776234727)

![새 카드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069169058/original/gpuJLIUlDdiH3CyDfZ4-8Hv2r3d6w7aldw.png?1776235034)

### 저장된 카드로 다음 결제하기

저장된 카드를 쓰면 재방문 고객의 결제 과정이 한결 간단해져요. 연락처에 카드를 저장해 두면, 그 연락처와 연결된 결제 흐름에서 해당 카드를 쓸 수 있어요.

연락처의 결제 관련 항목을 만들 때 저장된 카드가 사용 가능한 결제 수단으로 표시될 수 있어요. 예를 들면 다음과 같아요.

- 거래 내역
- 인보이스
- 견적서
- 현장 결제

### 모바일 앱에서 저장된 카드 제거하기

오래되었거나 쓰지 않는 카드를 제거하면 고객의 결제 수단을 정확하게 관리하기 쉬워요.

1. 해당 연락처의 **카드 관리**를 여세요.
2. 제거할 저장된 카드를 찾으세요.
3. 카드를 왼쪽으로 밀어 주세요.
4. 화면에 표시된 이름에 따라 **삭제** 또는 **제거**를 탭하세요.
5. 작업을 확인하세요.

![카드를 밀어서 삭제하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069169108/original/NrzQmMJUOWgHtxPQ02Ck6PzjXkjaqqTzPQ.png?1776235090)

### 모바일 앱에서 저장된 카드를 관리하면 좋은 점

모바일 앱에서 저장된 카드를 관리하면 팀이 더 빠르게 일하고, 고객은 더 매끄럽게 결제할 수 있어요.

- 반복 결제가 빨라져요: 저장된 카드를 재방문 고객에게 다시 사용해 시간을 아낄 수 있어요.
- 연락처별로 정리하기 쉬워요: 결제 수단을 알맞은 연락처에 연결해 둘 수 있어요.
- 모바일 작업이 편해져요: 모바일 앱을 벗어나지 않고 결제 수단을 관리할 수 있어요.
- 고객 경험이 매끄러워져요: 이후 결제 때 고객이 카드 정보를 다시 알려 줄 일이 줄어요.
