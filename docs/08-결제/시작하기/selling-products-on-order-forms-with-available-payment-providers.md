# 주문 폼에서 결제 제공업체별로 상품 판매하기

퍼널 버전 2의 1단계·2단계 주문 폼에서는 일회성 상품과 반복 결제 상품을 모두 판매할 수 있어요. 이 문서에서는 주문 폼에서 상품을 파는 여러 경우와, 결제 흐름을 설계할 때 알아 둘 제한 사항을 안내해요.

{% hint style="info" %}
새로 만드는 퍼널과 웹사이트는 모두 버전 2로 만들어져요.
{% endhint %}

## 사용 가능한 결제 제공업체

주문 폼에서 상품을 판매할 때 아래 결제 제공업체를 쓸 수 있어요.

- Stripe
- Authorize.net
- NMI
- PayPal
- Square
- 사용자 지정 결제 제공업체 (마켓플레이스에서 설치)

## 주문 폼에서 판매하는 방법

- 메인/기본 상품: 주문 폼에서 판매하는 주된 상품이에요.
- 범프 상품: 연락처(리드)가 기본 상품을 구매하는 동안 선택해서 함께 살 수 있는 추가 상품이에요.
- 업셀: 리드가 기본 상품을 구매한 직후, 버튼 한 번으로 다른 서비스나 상품을 바로 제안할 때 써요.

## 알아 둘 점

1. Apple Pay와 Google Pay는 Stripe에서만 지원돼요. 결제 수단에 Apple Pay를 표시하려면 **결제 > 연동**에서 Stripe 연결 카드의 토글을 켜야 해요.
2. Stripe에 연결되어 있으면 Google Pay가 기본으로 표시돼요. 구매자의 국가에서 지원하는 경우에 한해요.
3. 어떤 결제 제공업체에서도 서로 다른 반복 결제 상품 두 개를 한 번의 결제로 판매할 수 없어요. 한 흐름에서 반복 결제 상품 두 가지를 팔려면 업셀 구매를 활용하세요.
4. PayPal은 리드가 반복 결제 상품을 구매할 때 범프 상품 구매를 지원하지 않아요.
5. **결제 > 상품**에서 반복 결제 상품을 만들 때 셋업 비용, 체험 기간, 결제 횟수를 설정할 수 있어요. 리드가 그 상품을 구매하면 설정이 자동으로 적용돼요.
6. 접수된 모든 주문은 **결제 > 주문**에서, 생성된 구독은 **결제 > 구독**에서 확인할 수 있어요. 환불은 **거래 내역** 표에서 관리해요.
7. 상품에 체험 기간이 있고 체험이 시작되기 전에 따로 청구하는 셋업 비용이 없으면, 주문을 완료할 때 금액이 차감되거나 청구되지 않고 '0'으로 표시돼요. 요금은 체험 기간이 끝날 때 청구돼요.

## PayPortal 기능

**결제 수단을 선택하세요**(Select Payment Method) 목록에는 아래 항목이 표시돼요.

- Stripe (Card)
- Stripe > Apple Pay / Google Pay
- Stripe > Affirm/Klarna/Afterpay
- Stripe > ACH Direct Debit
- PayPal
- Square (Card)
- Razor Pay
- 서드파티 연동
