# Stripe 결제 수단을 하이퍼클래스에서 관리하기

이제 Stripe 결제 수단을 하이퍼클래스 안에서 바로 관리할 수 있어요. Stripe 대시보드를 오갈 필요 없이 인보이스, 퍼널, 스토어 등의 결제 설정을 한곳에서 정리하고, 비즈니스에 맞게 더 유연하게 조정할 수 있어요.

## Stripe 결제 수단 관리란?

Stripe 결제 수단 관리를 쓰면 신용카드, 전자지갑, 계좌 이체 같은 결제 수단 중 어떤 것을 하이퍼클래스의 각 기능 영역에서 쓸 수 있게 할지 하이퍼클래스 계정 안에서 직접 정할 수 있어요. Stripe 대시보드에서 따로 설정하지 않아도 되므로 운영이 간단해지고 결제 설정을 더 잘 통제할 수 있어요.

### 주요 장점

- 한곳에서 관리: 하이퍼클래스를 벗어나지 않고 모든 Stripe 결제 수단을 관리해요.
- 라이브와 테스트 환경 분리: 라이브 환경과 테스트 환경의 결제 수단을 각각 설정할 수 있어요.
- 결제 화면별 표시: 사용할 수 있는 결제 수단만 각 결제 화면에 표시돼요.
- 구독 전용 설정: 구독 상품에만 적용되는 결제 설정을 따로 관리할 수 있어요.
- Stripe 대시보드 의존도 감소: 더 이상 Stripe에서 결제 수단을 편집하지 않아도 돼요.
- 매끄러운 사용 경험: 설정이 간단해져 인보이스, 퍼널, 폼, 스토어에 더 빠르게 적용할 수 있어요.

## Stripe 결제 수단 관리하는 방법

Stripe 결제 수단을 알맞게 설정해 두면 모든 기능 영역에서 결제가 원활하게 이루어져요. 아래 순서대로 하이퍼클래스 안에서 바로 관리해 보세요.

### 1단계: 결제 설정으로 이동하기

1. 서브 계정에서 **결제** 탭을 클릭하세요.

   ![결제 탭 선택 화면](https://jumpshare.com/share/QBmLPdkT6Pk1AOPpvIza+/Screen+Shot+2025-09-26+at+6.59.40+PM.png)
2. **연동**을 클릭하세요.

   ![연동 메뉴 선택 화면](https://jumpshare.com/share/JHbfPz7KSctOW0sm6dES+/Screen+Shot+2025-09-26+at+7.01.17+PM.png)
3. 연결된 Stripe 계정 옆의 **관리** 버튼을 클릭하세요.

   ![Stripe 계정 옆 관리 버튼 화면](https://jumpshare.com/share/BFqx1iYlIkdYvuxdfizA+/Screen+Shot+2025-09-26+at+7.02.22+PM.png)

### 2단계: 결제 수단 켜기·끄기

1. **결제 수단 관리** 옵션을 클릭하세요.

   ![결제 수단 관리 옵션 화면](https://jumpshare.com/share/h45km1PT8AsRjI6HFKjq+/Screen+Shot+2025-09-26+at+7.05.08+PM.png)
2. 기능 영역별로 사용할 수 있는 결제 수단 목록이 보여요.
3. 특정 기능 영역에서 쓰고 싶은 결제 수단은 켜고, 쓰지 않을 결제 수단은 꺼 주세요.

   ![결제 수단 토글을 켜고 끄는 화면](https://jumpshare.com/share/CXTT1QrIgg0QHMeEoDA3+/GIF+Recording+2025-09-26+at+7.16.56+PM.gif)
4. 구독 상품을 판매 중이라면 **구독**이라는 드롭다운이 따로 보여요. 여기에서 구독 결제 화면에 적용할 결제 수단을 설정하세요.

   ![구독 드롭다운에서 결제 수단을 설정하는 화면](https://jumpshare.com/share/Bcz0GPsSUjrRv3ycBAcA+/GIF+Recording+2025-09-26+at+7.20.02+PM.gif)

## 고급 결제 수단 설정 및 문제 해결

일부 결제 수단은 추가 설정을 마쳐야 결제 화면에 나타나요. 사용 가능 여부는 계정 인증 상태, 국가 지원 여부, 결제 수단 자격 조건, 테스트 모드와 라이브 모드 중 어느 쪽을 쓰는지 등에 따라 달라져요.

### 디지털 지갑 켜기

디지털 지갑 결제는 지원되는 기기와 브라우저를 쓰는 고객에게 더 빠른 결제 경험을 제공해요.

#### Apple Pay

결제 화면에 Apple Pay가 나타나려면 아래 조건을 갖춰야 해요.

- 결제 계정이 완전히 활성화되어 있어야 해요.
- 도메인 인증이 완료되어 있어야 해요.
- 결제 서비스 설정에서 Apple Pay가 켜져 있어야 해요.

Apple Pay를 켜는 방법은 다음과 같아요.

- **결제 > 연동**으로 이동하세요.
- 연결된 결제 계정을 여세요.
- **결제 수단 관리**를 선택하세요.
- 사용할 수 있는 경우 Apple Pay를 켜세요.
- **변경사항 저장**을 클릭하세요.

#### Google Pay

Google Pay를 쓸 수 있는지는 지원 기기, 브라우저, 결제 계정 자격에 따라 달라져요.

Google Pay를 켜는 방법은 다음과 같아요.

- **결제 > 연동**을 여세요.
- **결제 수단 관리**를 선택하세요.
- Google Pay를 켜세요.
- 설정을 저장하세요.

### 계좌 기반 결제 수단 켜기

계좌 기반 결제 수단은 추가 계정 인증을 마쳐야 사용할 수 있는 경우가 있어요.

#### ACH 결제

ACH 결제는 지원되는 지역과 자격을 갖춘 결제 계정에서만 사용할 수 있어요.

ACH를 켜는 방법은 다음과 같아요.

- **결제 > 연동**을 여세요.
- **결제 수단 관리**를 선택하세요.
- 사용할 수 있는 경우 ACH를 켜세요.
- **변경사항 저장**을 클릭하세요.

#### iDEAL, SEPA

iDEAL, SEPA 같은 지역별 결제 수단은 결제 계정이 지원하고 고객의 위치가 해당될 때만 나타날 수 있어요.

이 결제 수단을 켜는 방법은 다음과 같아요.

- **결제 > 연동**을 여세요.
- **결제 수단 관리**를 선택하세요.
- 사용할 결제 수단을 켜세요.
- 설정을 저장하세요.

### 선구매 후결제(Buy Now, Pay Later) 결제 수단

지원되는 금융·할부 결제 옵션은 활성화하기 전에 결제 서비스 제공업체의 승인이 필요할 수 있어요.

예를 들면 다음과 같아요.

- Affirm
- Klarna
- Afterpay
- Clearpay

사용할 수 있는 할부 옵션을 켜는 방법은 다음과 같아요.

- **결제 > 연동**을 여세요.
- **결제 수단 관리**를 선택하세요.
- 지원되는 할부 결제 수단을 켜세요.
- **변경사항 저장**을 클릭하세요.

### 테스트 모드와 라이브 모드 전환

결제 수단은 테스트 환경과 라이브 환경에서 각각 따로 설정할 수 있어요.

결제 수단이 보이지 않을 때는 아래를 확인해 보세요.

- 지금 어떤 모드가 선택되어 있는지 확인하세요.
- 알맞은 환경에서 해당 결제 수단이 켜져 있는지 확인하세요.
- 결제 화면을 다시 테스트하기 전에 변경사항을 저장하세요.

## 기능 영역별 Stripe 결제 수단 설정

기능 영역별로 결제 수단을 관리하면 고객이 보는 화면에 알맞은 결제 수단만 표시돼요. 설정이 적용되는 영역은 다음과 같아요.

- **인보이스**
- **Invoices with AutoPayments**(자동 결제 인보이스)
- **결제 링크**
- **Funnels - One-Step Order Form**(퍼널 - 원스텝 주문 폼)
- **Funnels - Two-Step Order Form**(퍼널 - 투스텝 주문 폼)
- **폼**
- **이커머스 스토어**
- **캘린더**
- **코스**
- **커뮤니티**
- **구독**

```
SaaS 구성기에서 만든 SaaS 구독용 결제 링크는 카드 결제만 지원해요.

Stripe나 하이퍼클래스의 다른 기능 영역에서는 다른 결제 수단을 쓸 수 있더라도, SaaS 구독 온보딩에서는 제외돼요.
```

각 결제 화면에는 설정한 내용이 그대로 적용돼요. 고객이 결제 화면에서 예상치 못한 상황을 겪을 일이 없어요.

## 자주 묻는 질문

### Stripe 거래 수수료는 얼마인가요?

Stripe 거래 수수료는 국가와 결제 수단에 따라 달라요. 일반적으로 Stripe는 거래마다 일정 비율에 고정 수수료를 더해 부과해요. 지역마다 요금이 다르므로 가장 정확하고 최신인 정보는 [Stripe 공식 요금 페이지](https://stripe.com/pricing)에서 확인하세요.

### 하이퍼클래스에서 구독 목록이 보이지 않아요.

**구독** 목록은 해당 서브 계정의 **라이브 모드**에서 구독 상품을 하나 이상 추가한 뒤에야 나타나요. 이 조건은 Stripe에서 정한 요건이에요.

### Stripe에 이미 결제 수단을 설정해 두었는데 어떻게 되나요?

기존 설정은 그대로 유지돼요. 하이퍼클래스에서 따로 바꾸지 않는 한, 기능 영역이나 결제 화면의 기본 결제 수단은 기존 Stripe 설정과 같아요.

### 라이브 모드와 테스트 모드의 설정은 따로 적용되나요?

네, 맞아요. 라이브 환경과 테스트 환경의 결제 수단을 각각 설정할 수 있어서, 개발 단계와 실제 운영 단계에서 모두 유연하게 쓸 수 있어요.

### 구독 드롭다운이 보이지 않아요.

Stripe 규정에 따라 **구독** 설정은 해당 서브 계정의 **라이브 모드**에서 구독 상품을 하나 이상 추가한 뒤에만 나타나요.

### 이 변경 사항이 모든 서브 계정에 적용되나요?

Stripe에 연결된 서브 계정은 각각 자신의 **결제** 설정에서 결제 수단을 따로 설정해야 해요.

### Stripe에서는 BLIK가 켜져 있는데 결제 페이지와 PMC 페이지에 표시되지 않아요. 어떻게 켜나요?

현재 연동에서는 BLIK가 표시되지 않아요. Stripe는 연결된 계정의 Payment Method Configuration(결제 수단 구성)과 결제 상황에 따라 실행 시점에 표시할 결제 수단을 정해요. BLIK는 결제 시점에 PaymentIntent를 즉시 확인해야 하는데, 이 방식은 하이퍼클래스의 지연 결제 흐름과 맞지 않아 이 흐름에서는 지원되지 않아요. 지금은 이 구성을 바꿀 계획이 없지만, 현재 사용 사례를 지원하기 위해 Stripe와 함께 결제 수단 지원 범위를 정기적으로 검토하고 있어요.

### 결제 수단을 켰는데 결제 화면에 나타나지 않아요.

계정 제한, 지원되지 않는 결제 화면 유형, 지역 제한, 인증 요건 미충족 때문에 결제 수단이 숨겨질 수 있어요. **라이브 모드**가 아니라 테스트 모드에서만 켜져 있어도 나타나지 않아요.
