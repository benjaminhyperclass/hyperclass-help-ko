# 인보이스 리마인더로 결제 안내 자동화하기

인보이스 설정에서 바로 결제 리마인더를 만들어 고객에게 자동으로 보낼 수 있어요. 워크플로우로 고객에게 알림을 보내 왔다면, 이제 설정만으로 인보이스 결제 전환율을 높일 수 있어요.

## 새로운 기능

- 새 리마인더를 추가하고, 토글로 켜고 끄면서 리마인더를 여러 개 설정할 수 있어요.
- 필요 없는 리마인더는 삭제할 수 있어요.
- 리마인더 횟수와 사용자 지정 이메일을 설정하고, **인보이스 만기일** 또는 인보이스 발송일을 기준으로 발송 시점을 바꿀 수 있어요.

## 사용 방법

1. **인보이스**에서 **설정**으로 이동하세요.

   ![인보이스 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030185444/original/VMJYJzneKUpXplnAnLu9aSoU4wECUJQMyg.jpeg?1722368251)

2. **리마인더 설정**을 클릭하세요.

   ![리마인더 설정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030185445/original/uPBhX7ZNehkXR3EOU4NkXDlCeIjQh6Ya-A.jpeg?1722368250)

3. 리마인더마다 아래 항목을 설정하세요.

   1. **리마인더 이름**을 입력해요.
   2. 이메일과 SMS에 쓸 **Reminder Template**(리마인더 템플릿)을 정해요. **기존 항목 사용**을 선택하거나, 기존 템플릿을 편집해 그 자리에서 새로 만들 수 있어요.
   3. 이메일 제목을 수정해요.
   4. 리마인더 발송 주기를 정해요. 형식은 다음과 같아요. [X]일/개월/시간 등 [후/전] [**인보이스 만기일**/**Invoice sent date**(인보이스 발송일)] 기준으로 반복해서 보내요.
   5. **Maximum reminders**(최대 리마인더 횟수)를 설정해 리마인더 발송을 멈출 시점을 정해요.

   ![리마인더 항목 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030185443/original/As47VMX6JTO773Yik8CN6JJ7lP-ObF2RCw.jpeg?1722368250)

4. 리마인더를 하나 더 만들려면 **Add New Reminder**(새 리마인더 추가)를 클릭하세요.
5. 필요 없는 리마인더는 삭제하거나, 토글로 끄세요.

## 인보이스 리마인더 동작 방식과 수동 발송

### 1. 리마인더 템플릿 동작

- **인보이스 설정**에서 미리보기로 보이는 리마인더 템플릿이 자동 리마인더에 실제로 쓰이는 템플릿이에요.
- 리마인더를 여러 개 설정할 수 있어요(예: 리마인더 1, 리마인더 2). 각 리마인더마다 발송 시점을 따로 정해요.
- 리마인더 자동화는 켠 이후부터 작동해요.

---

### 2. 이미 기한이 지난 인보이스

- 리마인더 기능을 켜기 전에 이미 기한이 지난 인보이스에는 자동 리마인더가 적용되지 않아요.
- 시스템은 설정을 켠 이후에 만든 인보이스에 대해서만 리마인더를 보내요.
- 이전에 기한이 지난 인보이스는 직접 처리해야 해요.

---

### 3. 리마인더 수동 발송

- 기한이 지난 인보이스가 있는 고객에게 리마인더를 직접 보낼 수 있어요.
- 직접 보낼 때는 다음을 알아 두세요.

  - 연락처를 선택하면 연락처 정보만 채워져요.
  - 수동 메시지 작성 창에서 보낼 때는 인보이스 금액, 만기일, 인보이스 번호 같은 동적 인보이스 필드가 자동으로 채워지지 않아요.
- 템플릿이 맞지 않는 문제를 피하려면 꼭 필요할 때만 수동으로 리마인더를 보내는 것을 권장해요.

---

### 4. 인보이스 만기일 설정

- **결제 설정**에서 **Invoice Due After (days)**(인보이스 만기 기준 일수)를 바꾸면 앞으로 만드는 인보이스에만 적용돼요.
- 이미 만든 인보이스는 소급해서 바뀌지 않아요. 이미 생성된 반복 인보이스도 마찬가지예요.
- 변경 내용은 업데이트 이후에 생성되는 인보이스에만 적용돼요.

---

### 5. 운영 시 참고 사항

- 리마인더 자동화를 켜기 전에 만든 인보이스의 리마인더는 직접 처리해야 해요.
- 수동 리마인더 이메일에서 동적 필드가 어떻게 동작하는지 사용자에게 미리 안내해 주세요.
- 만기일 설정 변경은 소급 적용되지 않아요. 반복 청구를 설정하는 사용자에게 이 점을 분명히 알려 주세요.
