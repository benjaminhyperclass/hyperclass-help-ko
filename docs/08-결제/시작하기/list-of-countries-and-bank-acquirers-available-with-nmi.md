# NMI에서 사용할 수 있는 국가 및 매입사 목록

NMI 연동으로 결제를 받을 수 있는 국가와 매입사(acquirer)를 정리한 문서예요. 가맹점은 NMI 연동으로 하이퍼클래스 안에서 결제를 처리할 수 있어요. 아래 목록에서 해당하는 매입사에 계정을 열고, NMI에 계정을 만들어 API 키를 발급받으세요. 발급받은 키는 **결제 > 연동**에 입력하면 돼요.

이 문서에서 확인할 수 있는 내용은 다음과 같아요.

- NMI가 매입사 네트워크를 통해 지원하는 국가 목록
- 상위 25개 매입사가 가맹점을 지원하는 국가 목록
- NMI와 연결된 매입 은행 목록
