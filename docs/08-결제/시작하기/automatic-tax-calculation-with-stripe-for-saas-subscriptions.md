# Stripe로 SaaS 구독 세금 자동 계산하기

Stripe Tax를 사용하면 세율을 직접 관리하지 않아도 SaaS V1 구독에 적용되는 세금을 자동으로 계산할 수 있어요. 이 문서에서는 **SaaS 구성기**(SaaS Configurator)에서 세금 등록, 상품 세금 코드, 세금 처리 방식, 카테고리별 오버라이드를 설정하는 방법과, 지원되는 플랜 변경 뒤에 세금이 어떻게 다시 계산되는지 안내해요.

{% hint style="warning" %}
SaaS 구독의 자동 세금은 Stripe 기반 SaaS V1에서만 쓸 수 있어요. SaaS V2와 Stripe가 아닌 다른 SaaS 결제 제공업체에서는 아직 지원하지 않아요. 또 자동 세금을 켜거나 세금 설정을 바꿔도 이미 활성 상태인 구독에는 소급해서 반영되지 않아요.
{% endhint %}

## Stripe 자동 세금 계산이란?

에이전시는 Stripe Tax로 SaaS 구독에 적용되는 세금을 계산할 수 있어요. 계산에는 설정해 둔 세금 등록, 고객의 청구 주소, 상품의 세금 처리 기준, SaaS 오퍼에 선택한 세금 처리 방식 등이 쓰여요.

에이전시는 **SaaS 구성기 > Automatic Tax**(자동 세금)에서 SaaS 세금 설정을 관리해요. 세금 등록은 연결된 Stripe 계정에서 관리하고요. 그러면 Stripe가 해당하는 결제 시점에 지원되는 세금 계산을 처리해요.

{% hint style="info" %}
세금 및 규정 준수 안내: 하이퍼클래스는 세금, 법률, 규정 준수에 관한 자문을 제공하지 않아요. 어느 지역에서 등록하고, 세금을 징수·신고·납부해야 하는지는 에이전시가 직접 판단해야 해요. 비즈니스와 해당 지역에 맞는 안내는 자격을 갖춘 세무 전문가와 상의하세요.
{% endhint %}

### 자동 세금 계산의 장점

세금 계산을 자동화하면 수동 결제 작업이 줄고, 지원되는 SaaS 거래 전반에 일관된 세금 처리를 적용할 수 있어요. 세금 분류, 가격 정책, SaaS 카테고리가 달라도 설정으로 유연하게 맞출 수 있어요.

- 세금 자동 계산: Stripe Tax가 등록 정보, 고객 정보, 선택한 상품 세금 처리 기준에 따라 해당 세금을 계산해요.
- 유연한 가격 설정: 가격을 어떻게 보여 줄지에 따라 **Automatic**(자동), **Inclusive**(세금 포함), **Exclusive**(세금 별도) 중에서 세금 처리 방식을 고를 수 있어요.
- 상품 분류: **상품 세금 코드**를 선택하면 Stripe가 SaaS 상품에 맞는 세금 처리를 판단하는 데 도움이 돼요.
- 카테고리별 제어: SaaS 카테고리마다 세금 처리 방식이 달라야 하면 전체 설정 대신 카테고리 단위로 따로 정할 수 있어요.
- 투명한 청구: 설정한 세금 처리 방식에 따라 결제 화면과 청구 합계에 해당 세금이 반영될 수 있어요.
- 플랜 변경 시 일관성: 이미 세금 설정이 적용된 자격 있는 V1 구독은, 지원되는 업그레이드·다운그레이드 후 세금을 다시 계산할 때 현재 플랜 정보를 사용할 수 있어요.

## Automatic, Inclusive, Exclusive 세금 처리 방식

세금 처리 방식은 해당 세금을 설정한 가격에 포함할지, 따로 더할지 정해요. 판매하는 시장과 청구 방식에 맞게 골라야 화면에 보이는 가격이 일관돼요.

| 세금 처리 방식 | 동작 방식 |
| --- | --- |
| **Automatic** | 미국과 캐나다에서는 세금 별도(exclusive) 가격을, 그 밖의 지원 지역에서는 세금 포함(inclusive) 가격을 사용해요. |
| **Inclusive** | 해당 세금이 따로 더해지지 않고 표시된 가격에 포함돼요. |
| **Exclusive** | 해당 세금을 따로 계산해서 설정한 기본 가격에 더해요. |

![SaaS 자동 세금 설정에서 선택할 수 있는 세금 처리 방식 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070232083/original/Z93B6K2yiVGlCNFXbBhe_ZMga9uH3ZUs3Q.png?1777473608)

## SaaS 상품 세금 코드

**상품 세금 코드**는 판매하는 상품을 분류하는 코드예요. 이 코드를 보고 Stripe Tax가 지원 지역에서 알맞은 세금 처리를 적용해요. SaaS 상품에 맞는 코드를 고르는 것이 정확한 자동 세금 계산의 중요한 부분이에요.

1. **SaaS 구성기 > Automatic Tax**로 이동하세요.
2. **상품 세금 코드**를 찾으세요.
3. 판매하는 SaaS 상품이나 서비스를 가장 잘 나타내는 세금 코드를 선택하세요.
4. **저장**을 클릭하세요.

코드 사용 방식: **SaaS 구성기**에서 선택한 코드를 Stripe Tax가 세금 처리를 판단할 때 사용해요. 판매하는 상품과 세무 전문가의 안내를 바탕으로 분류를 선택하세요.

![SaaS 자동 세금 설정의 상품 세금 코드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070232027/original/mGhjjkjyrNe0ZOzSAoYfqbZENIulUY7uIg.png?1777473582)

## 카테고리별 세금 오버라이드

카테고리별 오버라이드를 쓰면 모든 플랜의 전체 설정을 바꾸지 않고도 특정 SaaS 카테고리에만 다른 세금 처리 방식을 적용할 수 있어요. 오버라이드는 선택한 카테고리에서 기본 세금 설정보다 우선해요.

1. 자동 세금 설정에서 **Category Level Overrides**(카테고리별 오버라이드)까지 스크롤하세요.
2. 설정을 바꿀 카테고리 옆의 **편집** 아이콘을 선택하세요.
3. 그 카테고리의 세금 징수를 켜거나 끄세요.
4. 원하는 세금 처리 방식을 고르세요. **Inclusive**, **Exclusive** 또는 기본 설정 중에서 선택할 수 있어요.
5. 오버라이드를 저장하세요.

![SaaS 자동 세금 설정의 카테고리별 세금 오버라이드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070232126/original/hMo-B2DT7fnyCWgeJrgvl9B1EcHJkcBEBg.png?1777473634)

## SaaS V1 플랜 변경 후 세금 재계산

판매 서브 계정을 통해 판매된 자격 있는 SaaS V1 구독은, 지원되는 업그레이드와 다운그레이드가 일어나면 Stripe 구독과 그에 대응하는 판매 서브 계정 구독이 함께 업데이트될 수 있어요. 구독에 이미 세금 설정이 적용되어 있다면, 세금을 다시 계산할 때 업데이트된 플랜 정보가 사용될 수 있어요.

| 플랜 변경 단계 | 세금에 미치는 영향 |
| --- | --- |
| 지원되는 변경 전 | 구독은 기존 세금 설정과 현재 플랜 정보를 계속 사용해요. |
| 지원되는 업그레이드 또는 다운그레이드 | 조건에 맞는 V1 흐름에서 Stripe의 현재 상품·가격과 그에 대응하는 판매 서브 계정 구독이 업데이트돼요. |
| 해당 세금 재계산 | 세금이 이미 설정되어 있고 적용 대상이면, 현재 플랜 정보로 업데이트된 과세 금액을 정할 수 있어요. |

이 기능은 기존 구독에 세금을 새로 켜 주지 않아요. 지원되는 세금 설정에서 해당 구독에 자동 세금이 설정되어 있지 않았다면, 플랜을 바꿔도 Stripe Tax가 자동으로 켜지는 것으로 보면 안 돼요.

소급 적용되지 않아요: 기존 구독, 인보이스, 세금 데이터가 서로 맞지 않는 경우에도 자동으로 채워 넣지 않아요. 동기화는 지원되는 흐름으로 조건에 맞는 SaaS 업그레이드나 다운그레이드가 일어날 때 적용돼요.

Stripe에서 직접 변경하는 경우: Stripe의 상품, 가격, 구독, 세금 설정을 직접 임의로 수정해도 판매 서브 계정 동기화가 실행된다고 가정하지 마세요. 이 연동은 지원되는 SaaS 업그레이드·다운그레이드 이벤트에 대해서만 안내되어 있어요.

## Stripe 자동 세금 설정 방법

먼저 **SaaS 구성기**에서 자동 세금을 켜고, Stripe Tax가 사용할 세금 등록, 분류, 가격 처리 방식을 정해요. 새 SaaS 구독을 판매하기 전에 전체 설정을 확인하세요. 그래야 의도한 설정대로 세금이 계산돼요.

### 1단계: 자동 세금 징수 켜기

자동 세금을 켜면 앞으로 만드는 새 구독이나 그 밖의 자격 있는 구독 흐름에 SaaS V1 세금 설정을 쓸 수 있어요.

1. **에이전시 보기**에서 **SaaS 구성기 > Automatic Tax**로 이동하세요.
2. **자동 세금 활성화** 토글을 켜세요.

### 2단계: 세금 등록 설정하기

세금 등록은 에이전시가 세금 징수를 설정한 지역을 나타내요. 세금 등록은 Stripe에서 관리하고, 그 내용이 SaaS 세금 설정에 반영돼요.

1. **Tax Registrations**(세금 등록) 아래에서 **Manage Tax Registrations**(세금 등록 관리)를 클릭하세요.
2. 연결된 Stripe 계정에서 해당 등록을 완료하거나 업데이트하세요.
3. SaaS 세금 설정 화면으로 돌아와 등록 정보가 표시되는지 확인하세요.

![세금 등록과 징수 설정을 보여 주는 Stripe Tax 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070231962/original/LotPwvHAB2eR9tx4AQGJwd-7lBpO72E4Hg.png?1777473531)

### 3단계: 상품 세금 코드 선택하기

**상품 세금 코드**는 Stripe가 어떤 종류의 상품을 판매하는지 파악하고, 지원 지역에서 알맞은 세금 처리를 판단하는 데 도움이 돼요.

1. **상품 세금 코드**를 찾으세요.
2. SaaS 상품을 가장 잘 나타내는 코드를 선택하세요.
3. **저장**을 클릭하세요.

![SaaS 자동 세금의 상품 세금 코드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070232027/original/mGhjjkjyrNe0ZOzSAoYfqbZENIulUY7uIg.png?1777473582)

### 4단계: 세금 처리 방식 설정하기

카테고리별 오버라이드가 없을 때, 기본 세금 처리 방식에 따라 해당 세금을 설정한 가격에 포함할지 따로 더할지가 정해져요.

1. **Tax Behaviour**(세금 처리 방식)를 찾으세요.
2. **Automatic**, **Inclusive**, **Exclusive** 중에서 선택하세요.
3. **저장**을 클릭하세요.

![Automatic, Inclusive, Exclusive 옵션이 보이는 세금 처리 방식 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070232083/original/Z93B6K2yiVGlCNFXbBhe_ZMga9uH3ZUs3Q.png?1777473608)

### 5단계: 카테고리별 오버라이드 설정하기

특정 SaaS 카테고리만 전체 기본값과 다른 세금 징수나 가격 처리 방식이 필요할 때 오버라이드를 사용하세요.

1. **Category Level Overrides**까지 스크롤하세요.
2. 해당 카테고리의 **편집** 아이콘을 클릭하세요.
3. 세금 징수를 켤지 정하세요.
4. 그 카테고리의 세금 처리 방식을 선택하세요.
5. 변경사항을 저장하세요.

![SaaS 자동 세금의 카테고리별 오버라이드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070232126/original/hMo-B2DT7fnyCWgeJrgvl9B1EcHJkcBEBg.png?1777473654)

### 6단계: 결제 화면 테스트하기

고객에게 판매하기 전에 테스트하면 의도한 세금 설정, 가격 처리 방식, 합계가 제대로 적용되는지 확인할 수 있어요.

1. 판매하려는 SaaS 오퍼로 테스트 구독을 만드세요.
2. 테스트하려는 지역에 맞는 고객 정보를 사용하세요.
3. 세금 금액과 최종 합계를 확인하세요.
4. 화면에 표시된 결과가 설정한 **Inclusive**, **Exclusive**, **Automatic** 방식과 일치하는지 확인하세요.

![계산된 세금과 최종 구독 합계가 표시된 SaaS 결제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070232160/original/d45e8ZWgq_N8WY0JGS1mOopnDjVB3eKDKg.png?1777473654)

기존 활성 구독: 자동 세금을 켜거나 세금 설정을 바꿔도 이미 활성 상태인 구독의 세금 설정은 소급해서 바뀌지 않아요. 세금 설정은 지원되는 구독 흐름에 따라 앞으로 적용돼요.

## 자주 묻는 질문

### SaaS V2에서도 자동 세금을 쓸 수 있나요?
아니요. 이 SaaS 자동 세금 설정은 현재 Stripe 기반 SaaS V1용으로 안내되어 있어요. SaaS V2와 Stripe가 아닌 SaaS 결제 제공업체에서는 쓸 수 없어요.

### 자동 세금을 켜면 기존 활성 구독이 모두 업데이트되나요?
아니요. 세금 설정은 앞으로 적용돼요. 설정을 켜거나 바꾼다고 해서 기존 활성 구독에 소급해서 반영되지 않아요.

### 기존 V1 구독도 플랜을 바꾸면 세금이 다시 계산되나요?
자격 있는 V1 구독에 이미 세금 설정이 적용되어 있다면, 지원되는 SaaS 업그레이드나 다운그레이드 후 세금을 다시 계산할 때 업데이트된 플랜 정보가 사용될 수 있어요. 이전에 세금이 설정되지 않았던 구독에는 세금이 자동으로 켜지지 않아요.

### 과거의 세금이나 구독 불일치도 자동으로 고쳐지나요?
아니요. 과거의 불일치는 자동으로 채워 넣지 않아요. 새 동기화는 조건에 맞는 SaaS 플랜 변경에 앞으로 적용돼요.

### Stripe에서 구독을 직접 바꾸면 SaaS V1 동기화가 실행되나요?
Stripe에서 직접 바꾼 내용이 판매 서브 계정 동기화를 실행한다고 가정하지 마세요. 이 연동은 지원되는 SaaS 업그레이드와 다운그레이드 이벤트에 대해서만 안내되어 있어요.

### 상품 세금 코드를 잘못 고르면 어떻게 되나요?
선택한 코드는 Stripe Tax가 SaaS 상품을 분류하는 방식에 영향을 줘요. 판매하는 상품을 정확히 나타내는 코드를 선택하세요. 어떤 분류가 맞는지 확실하지 않다면 자격을 갖춘 세무 전문가와 상의하세요.

### SaaS 카테고리마다 다른 세금 처리 방식을 쓸 수 있나요?
네. **Category Level Overrides**에서 카테고리별로 세금 징수를 켜거나 끌 수 있고, 카테고리에 맞는 세금 처리 방식을 적용할 수 있어요. 이 설정은 전체 기본값보다 우선해요.
