# 해외 자동 세금 설정하고 사용하기

여러 국가나 지역에서 사업을 운영할 때, 부가가치세(VAT)를 포함한 세금을 결제 시점에 자동으로 계산하도록 설정하는 방법을 안내해요. 설정해 두면 고객 주소와 사업체의 세금 납부 의무에 따라 알맞은 세금이 적용돼요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 해외 자동 세금이란?

해외 자동 세금(International Automatic Taxes)은 여러 국가에서 사업을 운영하는 경우 세금 계산을 자동으로 처리하는 하이퍼클래스 기능이에요. VAT와 각 지역의 세금을 지원해요. 결제나 인보이스 결제 때 고객 주소와 사업체의 세금 납부 의무를 기준으로 알맞은 세금을 자동으로 적용해요.

퍼널, 결제 링크, 인보이스, 견적서, 이커머스 스토어 등 모든 결제 유형에서 쓸 수 있고, 모든 결제 대행 서비스와 호환돼요.

## 해외 자동 세금의 주요 장점

해외 자동 세금은 전 세계 세금 규정 준수와 결제 과정을 간편하게 해 줘요.

- VAT와 지역 세금을 포함해, 여러 국가의 세금을 정확하게 계산해요.
- 세금 납부 의무가 있는 국가나 주를 한꺼번에 추가할 수 있어요.
- 고객 주소를 기준으로 세금을 자동 적용해 수작업 오류를 줄여요.
- 국가별 VAT ID나 지역 세금 ID를 입력하고 관리할 수 있어요.
- 하이퍼클래스의 모든 결제 유형과 결제 대행 서비스에서 문제없이 작동해요.
- 상품별로 세금을 세밀하게 설정할 수 있어요.
- 기존 미국 자동 세금 사용자를 위한 안내형 전환 과정을 제공해요.
- 세금 설정을 한곳에서 관리하고 업데이트할 수 있어요.

## 자동 세금 설정하고 사용하기

자동 세금을 설정해 두면 사업체가 세금 규정을 지키고, 고객에게 알맞은 세금이 청구돼요.

{% hint style="info" %}
세금을 징수하거나 납부하는 각 관할 지역의 세금 규정을 지킬 책임은 사용자에게 있어요.
{% endhint %}

### 1단계: 세금 설정 열기

1. 하이퍼클래스 계정의 왼쪽 메뉴에서 **결제**를 클릭하세요.
2. **결제** 화면에서 **설정** 탭을 클릭하세요.
3. **설정** 아래의 **세금** 하위 탭을 선택하세요.

![결제 설정의 세금 탭](https://jumpshare.com/v/bab65vDCSTlbN6b9EWN8+/Screen+Shot+2025-07-01+at+1.23.56+AM.png)

### 2단계: 글로벌 세금 설정 켜기

1. **Include Tax in Prices**(가격에 세금 포함) 옵션을 찾으세요.
2. 가격에 세금을 포함할지에 따라 **예** 또는 **아니오**를 선택하세요.
   - **예** - 세금이 항상 상품 가격에 포함돼요. 세금을 포함한 최종 가격은 고정이고, 세금액은 세율에 따라 달라지지만 항상 이 가격 안에서 계산돼요.
     예를 들어 상품 가격을 $100으로 설정했는데 결제 시 적용된 세율이 다음과 같다면:
     - 10%이면 세금액은 $9.1이고, 세금 포함 총액은 $100 그대로예요.
     - 0%이면 세금액은 $0이고, 세금 포함 총액은 $100 그대로예요.
     - 20%이면 세금액은 $16.67이고, 세금 포함 총액은 $100 그대로예요.
   - **아니오** - 상품 가격과 세금을 따로 두고 싶을 때 선택하세요. 세금액은 상품 가격에 더해져요.
     예를 들어 상품 가격을 $100으로 설정했는데 결제 시 적용된 세율이 다음과 같다면:
     - 10%이면 세금액은 $10이고, 세금 포함 총액은 $110이 돼요.
     - 0%이면 세금액은 $0이고, 세금 포함 총액은 $100 그대로예요.
     - 20%이면 세금액은 $20이고, 세금 포함 총액은 $120이 돼요.

![가격에 세금 포함 옵션](https://jumpshare.com/v/tVMqOcvCyy5C3hf4kRrB+/Screen+Shot+2025-07-01+at+1.27.42+AM.png)

### 3단계: 자동 세금 계산 켜기

1. 아래로 스크롤해 **자동 세금** 섹션을 찾으세요.
2. **자동 세금 활성화** 토글을 켜세요.

![자동 세금 활성화 토글을 켜는 화면](https://jumpshare.com/v/jPYyEcc5cwfcHwlwdYgh+/GIF+Recording+2025-07-01+at+1.36.10+AM.gif)

### 4단계: 기본 세금 카테고리 선택하기 (선택 사항)

1. **기본 세금 카테고리** 드롭다운에서 내 사업이나 상품에 가장 잘 맞는 카테고리를 선택하세요.

{% hint style="info" %}
개별 상품에 세금 카테고리를 선택해 두면, 기본 카테고리보다 상품에 선택한 카테고리가 우선 적용돼요.
{% endhint %}

![기본 세금 카테고리 선택](https://jumpshare.com/v/51rJgCg90YIE8BLq8xjx+/GIF+Recording+2025-07-01+at+1.39.56+AM.gif)

### 5단계: 넥서스 주소 추가하기

1. **넥서스 주소 추가**를 클릭하세요.
2. 드롭다운에서 **군/카운티/국가**를 선택하세요.
   - **미국**을 선택하면 58개 주 전체에서 고를 수 있어요.
   - **캐나다**는 13개 주/준주 중에서 고를 수 있어요.
   - 그 밖의 국가는 국가 단위로만 선택할 수 있어요.
3. 국가나 주별로 **세금 ID**를 입력하세요. 현지 규정에서 요구하는 경우 결제 시 세금을 계산할 때 이 ID가 반영돼요. (선택 사항)
4. **추가**를 클릭해 넥서스 주소를 저장하세요.

{% hint style="info" %}
주를 따로 추가한 국가(예: 캐나다)를 삭제하면 그 국가의 주도 함께 삭제돼요. 국가는 한 번에 하나씩만 삭제할 수 있어요.
{% endhint %}

![넥서스 주소 추가 화면](https://jumpshare.com/v/uG5jJdS4xw6M79VltCzz+/GIF+Recording+2025-07-01+at+1.45.16+AM.gif)

### 6단계: 결제 시 세금 확인하기

자동 세금과 넥서스 주소를 설정하고 나면:

- 고객 주소를 기준으로 세금이 자동 적용돼요.
  - 결제 화면

    ![결제 화면에 적용된 세금](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049112665/original/wCusNhJivThp8kDnPlMGHNm8P0NEdlLPwA.png?1751319085)
  - 인보이스 결제 화면

    ![인보이스 결제 화면에 적용된 세금](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049112689/original/fMIcj80dC5EJgicBPeuXcxBqQFRbNxu3uQ.png?1751319187)
- 적용된 세금액은 고객의 결제 요약에 별도 항목으로 표시돼요.
- 지역별로 사업체의 **세금 ID**를 설정해 두면, 현지 세금 규정에 따라 세금을 계산할 때 반영돼요.

## 상품별 세금 설정

상품별 세금 코드를 쓰면 특정 상품에 세금을 어떻게 적용할지 세밀하게 정할 수 있어요.

1. **결제 > 상품**으로 이동하세요.
2. 다음 중 하나를 선택하세요.
   - **상품 만들기**를 클릭하거나,
   - 기존 상품 옆의 **점 세 개** 메뉴를 클릭한 뒤 **편집**을 선택하세요.
3. **상품 세금 코드** 섹션까지 스크롤하세요.
4. 드롭다운에서 해당 상품의 **세금 카테고리**를 선택하세요.
5. **Include taxes in prices**(가격에 세금 포함)에서 다음 중 하나를 선택하세요.
   - **As per global settings**(글로벌 설정에 따름) - 위에서 설정한 전체 토글의 동작을 그대로 따라요.
   - **예** - 글로벌 설정과 상관없이 이 상품에는 항상 세금을 포함해요.
   - **아니오** - 글로벌 설정과 상관없이 이 상품에는 세금을 포함하지 않아요.
6. **저장**을 클릭해 변경 사항을 적용하세요.

{% hint style="info" %}
상품에 세금 코드를 직접 설정하지 않으면, 글로벌 세금 설정에 정의된 기본 코드가 적용돼요.
{% endhint %}

![상품별 세금 코드 설정](https://jumpshare.com/v/o5OvWJqsZLtm4QxZ703w+/GIF+Recording+2025-07-01+at+2.04.16+AM.gif)

## 기존 미국 자동 세금 시스템에서 전환하기

이전에 미국 전용 자동 세금 시스템을 쓰던 계정은 **자동 세금** 설정 화면의 안내 과정을 따라 글로벌 세금 시스템으로 전환할 수 있어요.

{% hint style="warning" %}
기존 미국 전용 세금 시스템은 2025년 9월 1일 이전에 종료될 예정이에요. 그때까지 전환하지 않은 계정은 다시 연결할 때까지 자동 세금 계산이 비활성화돼요.
{% endhint %}

전환 방법은 다음과 같아요.

1. 계정에서 **결제**를 클릭하세요.
2. **설정** 탭을 클릭하세요.

   ![결제 화면의 설정 탭](https://jumpshare.com/v/HqoznEc0OCji2tDiOe3R+/Screen+Shot+2025-07-01+at+12.07.56+AM.png)
3. **세금** 탭을 클릭하세요.

   ![설정 화면의 세금 탭](https://jumpshare.com/v/hlgsUImw33AEVsUQVaG1+/Screen+Shot+2025-07-01+at+12.11.27+AM.png)
4. 아래로 스크롤해 **자동 세금** 섹션에서 **재설정** 버튼을 클릭하세요.

   ![자동 세금 섹션의 재설정 버튼](https://jumpshare.com/v/K4vyLK8Ms98X3MC6mmld+/Screen+Shot+2025-07-01+at+12.18.51+AM.png)
5. 안내 내용을 읽고 **확인**을 클릭하세요.

   ![전환 안내 확인 화면](https://jumpshare.com/v/26GoeOr4zBk0KwwVmmuE+/Screen+Shot+2025-07-01+at+12.20.45+AM.png)

## 넥서스 주소 관리하기

넥서스 주소는 사업체에 세금 납부 의무가 있는 지역을 정해요. 이를 제대로 관리해야 필요한 지역에만 세금이 적용돼요.

- 사업 규모가 커지거나 줄어들면 국가나 주를 추가하거나 제거하세요.
- 주를 따로 추가한 국가(예: 캐나다)를 삭제하면, 그 주도 **Nexus 주소** 목록에서 함께 삭제돼요.
- 바뀌는 규정을 계속 지킬 수 있도록 넥서스 주소를 정기적으로 확인하고 업데이트하세요.

## 자주 묻는 질문

### 상품을 판매하는 모든 국가에 대해 세금을 설정해야 하나요?

네. 세금이 정확하게 계산되려면 세금 납부 의무가 있는 국가(미국과 캐나다는 주)를 각각 추가해야 해요.

### 넥서스 주소에 추가한 사업체의 세금 ID를 수정할 수 있나요?

네. 세금 ID는 **Nexus 주소** 목록에서 언제든 수정할 수 있어요.

### 이 기능은 하이퍼클래스의 모든 결제 대행 서비스와 호환되나요?

네. 해외 자동 세금은 하이퍼클래스가 지원하는 모든 결제 대행 서비스에서 작동해요.

### 세금 계산을 위한 국가와 주를 한꺼번에 추가할 수 있나요?

네. 일괄 추가 기능으로 여러 국가나 주를 한 번에 선택해 추가할 수 있어요.

### 결제할 때 세금은 어떻게 계산되나요?

세금은 다음 기준으로 자동 계산돼요.

- 고객의 청구지 또는 배송지 주소
- 설정해 둔 넥서스 지역
- 상품에 지정된 세금 코드
- 해당하는 경우 연결된 세금 ID

세금액은 최종 주문 요약에 별도 항목으로 표시돼요.

### 어떤 결제 유형에서 자동 세금을 지원하나요?

퍼널, 결제 링크, 인보이스 & 견적서, 이커머스 스토어 결제에서 자동 세금 계산을 쓸 수 있어요.

### 자동 세금 계산을 지원하는 국가 목록은 어디서 볼 수 있나요?

자동 세금을 설정할 때 **넥서스 주소 추가** 메뉴 안에서 볼 수 있어요. 드롭다운에서 고르거나 국가/주 이름으로 검색하세요.

### 인도에서도 자동 세금 계산이 되나요?

아니요. 현재 인도에서는 자동 세금 계산을 지원하지 않아요. 인도 거래의 세금은 상품과 결제 설정에서 세율을 직접 설정하거나, 상품 가격에 세금액을 직접 포함해서 처리해야 해요.

인도의 GST 및 세금계산서 발행 규정을 지키려면 세무 전문가와 상담하시길 권해요.

### 세금 카테고리별로 어떤 세금 코드를 써야 하는지 어디서 확인하나요?

세금 카테고리와 코드 매핑은 [세금 코드 목록 보기](https://taxcode.avatax.avalara.com/)에서 확인할 수 있어요. 상품 설정에서 **상품 세금 코드**를 지정할 때 이 목록을 참고하면, 결제와 인보이스 발행 시 세금이 정확하게 계산돼요.

### 하이퍼클래스에서 자동 세금은 어디에서 쓸 수 있나요?

인보이스 & 견적서, 결제 링크, 퍼널, 이커머스 스토어 결제에서 자동 세금을 확인하고 추가할 수 있어요.
