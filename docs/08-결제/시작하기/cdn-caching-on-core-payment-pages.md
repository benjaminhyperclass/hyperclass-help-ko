# 핵심 결제 페이지의 CDN 캐싱

하이퍼클래스는 핵심 결제 페이지에 CDN 캐싱을 적용해 로딩 속도를 크게 높였어요. 이 문서에서는 CDN 캐싱이 무엇인지, 어떤 페이지에 적용됐는지, 결제 전환에 어떤 도움이 되는지 설명해요.

## CDN 캐싱이란?

CDN(Content Delivery Network) 캐싱은 정적 콘텐츠를 전 세계에 흩어진 서버에 나눠 두는 성능 개선 방식이에요. 사용자와 가장 가까운 엣지 서버에서 데이터를 보내므로 지연 시간이 줄고 페이지가 더 빨리 열려요. 접속량이 많은 고객용 페이지에서 특히 효과가 커요. 덕분에 고객은 결제할 때 끊김 없이 매끄럽게 이용할 수 있어요.

## CDN 캐싱의 주요 이점

CDN 캐싱을 적용한 뒤 하이퍼클래스 결제 시스템을 쓰는 비즈니스에서 성능, 사용자 경험, 매출 증가 가능성이 모두 눈에 띄게 좋아졌어요.

- 핵심 고객용 페이지의 로딩 속도가 최대 78% 빨라졌어요.
- 인보이스 페이지 로딩 시간이 4.6초에서 1.3초로 줄었어요.
- 속도가 빨라진 만큼 결제 전환율이 높아질 수 있어요.
- 모바일과 데스크톱 모두에서 불편 없이 이용할 수 있어요.
- 해외 지역에서도 성능이 좋아졌어요.
- 로딩 시간이 줄어든 만큼 매출 증가로 이어질 수 있어요.

## CDN 캐싱 적용 방식

가장 자주 쓰는 결제 화면부터 콘텐츠 전송 속도를 개선했어요. HTML, JavaScript, 스타일 시트 같은 정적 자산을 CDN 제공업체를 통해 캐싱해서 아주 빠르게 불러올 수 있어요.

성능 개선 결과는 다음과 같아요.

| 페이지 유형 | 적용 전 로딩 시간 | 적용 후 로딩 시간 | 개선율 |
| --- | --- | --- | --- |
| 인보이스 | 4.6초 | 1.3초 | 약 71% |
| 견적서 | 약 4.5초 | 약 1.3초 | 약 70% 이상 |
| 결제 링크 | 약 4.5초 | 약 1.3초 | 약 70% 이상 |
| 영수증 | 약 4.5초 | 약 1.3초 | 약 70% 이상 |
| Shippo Marketplace | 개선됨 | 개선됨 | 예 |
| Razorpay Marketplace | 개선됨 | 개선됨 | 예 |
| 구독 업데이트 링크 | 개선됨 | 개선됨 | 예 |
| 모바일 카드 추가 페이지 | 개선됨 | 개선됨 | 예 |

## 적용되는 페이지

이번 성능 개선은 고객이 직접 보는 결제 페이지에 적용돼요. 이런 페이지는 속도가 전환율과 고객 만족도를 좌우해요.

- ✅ 인보이스 결제 페이지
- ✅ 견적서 페이지
- ✅ 결제 링크
- ✅ 영수증
- ✅ Shippo Marketplace 페이지
- ✅ Razorpay Marketplace 페이지
- ✅ 구독 결제 수단 업데이트 공유 링크
- ✅ 모바일 카드 추가 페이지

## 비즈니스 효과 및 수익 증가

**수익 증가**(Revenue Uplift)는 페이지가 빨라진 만큼 결제 성공 건수가 늘어나는 효과를 말해요. AWS 조사에 따르면 로딩이 100ms 늦어질 때마다 매출이 1%씩 줄어들 수 있어요. 이번에 3.3초가 단축됐으니 기대할 수 있는 효과는 다음과 같아요.

- 결제 완료율이 최대 35% 높아질 수 있어요.
- 총 결제 규모(TPV)에 직접 영향을 줘요.
- 모바일 결제 경험이 좋아져서 이탈이 줄어요.
- 결제 과정의 안정성과 신뢰도가 높아져요.

## 자주 묻는 질문

### 모든 고객사가 같은 효과를 보나요?
하이퍼클래스가 호스팅하는 표준 결제 페이지를 쓰는 고객사는 대부분 바로 이 개선 효과를 볼 수 있어요.

### 실시간 업데이트나 분석에 영향을 주지는 않나요?
아니요. 동적 콘텐츠는 캐싱에서 제외해요. 분석과 실시간 거래 추적도 그대로 지원해요.

### 캐시를 직접 지워야 하면 어떻게 하나요?
CDN 캐싱은 자동으로 관리돼요. 콘텐츠나 설정을 바꾸면 변경 내용이 CDN에 자동으로 반영돼요.

### 커스텀 도메인을 쓰면 적용되지 않나요?
하이퍼클래스의 도메인 라우팅과 페이지 템플릿을 쓰고 있다면 커스텀 도메인에서도 개선 효과가 자동으로 적용돼요.

## 다음 단계

- Chrome 개발자 도구로 내 하이퍼클래스 계정의 로딩 성능을 직접 측정해 보세요.
- CDN 업데이트 이후 사용자 행동과 이탈률을 살펴보세요.
- 고객사가 모든 결제에 이렇게 최적화된 화면을 쓰도록 안내하세요.
- 아직 CDN 캐싱을 쓰지 않는 커스텀 앱이나 워크플로우에 적용하려면 하이퍼클래스 고객지원에 문의하세요.
