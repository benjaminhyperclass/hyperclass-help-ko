# 상품 상세정보 페이지의 상품 선택기 스타일 설정하기

상품 선택기 스타일을 바꾸면 **상품 상세정보** 페이지에서 고객이 옵션, 가격 옵션, 수량, 업셀 상품을 고르는 방식을 조정할 수 있어요. **드롭다운**과 **Pills**(알약형 버튼) 중에서 고르면 스토어 디자인에 맞는 쇼핑 화면을 만들 수 있어요. 이 문서에서는 선택기 스타일이 어떻게 동작하는지, 각 스타일을 언제 쓰면 좋은지, 어떻게 설정하는지 안내해요.

## 상품 선택기 스타일이란?

상품 선택기 스타일은 **상품 상세정보** 페이지에서 고객이 고를 수 있는 상품 옵션이 어떻게 보일지 정해요. 여기에는 옵션, 가격 선택지, 수량, 업셀 상품 선택이 포함돼요. 선택기 스타일을 잘 고르면 고객이 선택지를 빠르게 이해하고 더 수월하게 구매를 마칠 수 있어요.

현재 지원하는 표시 방식은 두 가지예요.

- **드롭다운**: 상품 옵션을 간결한 드롭다운 메뉴 안에 보여 줘요.
- **Pills**(알약형 버튼): 상품 옵션을 페이지에 버튼 형태로 바로 보여 주고, 고객이 그중에서 선택해요.

## 상품 선택기 스타일의 장점

선택기 스타일을 직접 정하면 판매자가 구매 경험을 더 세밀하게 조정할 수 있어요. 선택기 배치가 명확하면 고객이 옵션을 비교하고, 원하는 상품 구성을 고르고, 결제까지 더 자신 있게 진행할 수 있어요.

- **상품 옵션이 더 잘 보여요**: **Pills**는 선택 가능한 항목을 처음부터 모두 보여 줘서 고객이 옵션을 쉽게 찾을 수 있어요.
- **스토어 화면이 일관돼요**: 옵션 선택기, 수량 선택기, 업셀 선택지, 다중 가격 선택기가 같은 시각적 패턴을 따라요.
- **모바일에서 더 편해요**: 데스크톱과 모바일 스토어 화면 모두에서 선택기가 잘 동작하도록 최적화되어 있어요.
- **디자인을 유연하게 정할 수 있어요**: 간결한 **드롭다운** 배치와 더 시각적인 **Pills** 배치 중에서 고를 수 있어요.
- **미리보기가 정확해요**: 선택기 동작이 **Page Builder**(페이지 빌더)와 **Builder Preview**(빌더 미리보기)에 모두 반영돼서, 게시하기 전에 변경 내용을 확인할 수 있어요.

## 드롭다운과 Pills 스타일 비교

**드롭다운**과 **Pills**는 서로 다른 스토어 환경에 맞게 만들어졌어요. 상품 선택지가 몇 개인지, 선택지를 페이지에서 얼마나 눈에 띄게 보여 주고 싶은지에 따라 알맞은 스타일을 고르세요.

```
이런 경우에 좋아요:

옵션이 많은 상품

간결한 페이지 레이아웃

전통적인 선택 방식을 선호하는 스토어

기본 선택기 동작을 그대로 유지하려는 기존 스토어
```

**Pills** 스타일은 상품 옵션을 페이지에 선택 가능한 버튼으로 바로 보여 줘요. 선택지가 더 잘 보이고, 고객이 옵션을 더 빠르게 비교할 수 있어요.

```
이런 경우에 좋아요:

옵션이 적은 상품

더 시각적인 선택 경험을 원하는 스토어

옵션이 눈에 잘 띄는 것이 중요한 상품 페이지

선택됨/선택 안 됨 상태의 색상을 직접 바꾸고 싶은 판매자
```

## 상품 선택기 스타일 설정하기

설정을 제대로 해 두면 고객이 **상품 상세정보** 페이지에서 의도한 선택기 배치를 볼 수 있어요. 게시하기 전에 **Builder Preview**에서 선택기 스타일을 확인하면 옵션, 가격 옵션, 수량 조절이 여러 기기에서 올바르게 표시되는지 알 수 있어요.

1. 하이퍼클래스에서 **Store Builder**(스토어 빌더)를 열어요.

   ![스토어 빌더 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070816160/original/OJWnZjf2pQYPIvkRQ1q6S_5AJpAJyd9YrA.png?1778167048)
2. **상품 상세정보** 페이지를 편집해요.
3. 페이지에서 **Product Element**(상품 요소)를 선택해요.
4. 일반 설정 패널에서 **Variants styling**(옵션 스타일)을 찾아요.

   ![일반 설정 패널의 Variants styling](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070818766/original/V_Uv0wYNeSUSv_99kAafSZIBXKsHMJQG8w.png?1778168661)
5. 사용할 수 있는 표시 스타일 중 하나를 골라요.

   - **드롭다운**

     ![드롭다운 스타일 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070818956/original/L2gcpDbzsmWhLHCTwtgP7DCOkVihgeTUYA.png?1778168806)
   - **Pills**

     ![Pills 스타일 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070819115/original/uplInD32Ov4MW8HXx6iFqAhWMhIWakht9w.png?1778168884)
6. **Builder Preview**에서 **상품 상세정보** 페이지를 확인해요.
7. **저장 및 게시**를 클릭해요.

{% hint style="warning" %}
**중요 사항**

- 기존 스토어의 기본 옵션 표시 방식은 계속 **드롭다운**이에요.
- 기존 스토어가 자동으로 **Pills**로 바뀌지는 않아요.
- **Pills**는 모든 옵션을 **상품 상세정보** 페이지에 시각적으로 보여 줘요.
- **Pills**는 옵션 그룹마다 하나만 선택할 수 있어요.
- 수량 색상 사용자 지정은 **Pills** 스타일을 선택했을 때만 쓸 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 이 기능을 쓰면 기존 스토어의 레이아웃이 자동으로 바뀌나요?
아니요. 기존 스토어는 **Product Element** 설정을 직접 **Pills**로 바꾸지 않는 한 계속 **드롭다운**을 기본 표시 스타일로 사용해요.

### 드롭다운과 Pills는 무엇이 다른가요?
**드롭다운**은 옵션을 메뉴 안에 넣고, **Pills**는 옵션을 **상품 상세정보** 페이지에 선택 가능한 버튼 형태로 바로 보여 줘요.

### 드롭다운 대신 Pills를 쓰면 좋은 경우는 언제인가요?
고객이 선택 가능한 옵션을 한눈에 보게 하고 싶을 때 **Pills**를 쓰세요. 옵션이 적은 상품이나 더 시각적인 쇼핑 경험을 원하는 스토어에 잘 맞아요.

### Pills 대신 드롭다운을 쓰면 좋은 경우는 언제인가요?
상품 옵션이 많거나 **상품 상세정보** 페이지를 더 간결하게 유지하고 싶을 때 **드롭다운**을 쓰세요.

### 고객이 같은 옵션 그룹에서 두 개 이상 선택할 수 있나요?
아니요. **Pills**는 옵션 그룹마다 하나만 선택할 수 있어요. 예를 들어 고객은 사이즈 그룹에서 사이즈 하나, 색상 그룹에서 색상 하나를 선택할 수 있어요.

### 다중 가격 선택기도 옵션 선택기와 같은 스타일을 따르나요?
네. 다중 가격 선택기도 옵션 선택기와 같은 **드롭다운** 또는 **Pills** 설정과 스타일 동작을 따라요.

### 드롭다운 스타일에서는 수량 선택기 색상을 바꿀 수 없는 이유가 뭔가요?
선택기 디자인 동작을 일관되게 유지하기 위해, 수량 색상 사용자 지정은 **Pills** 스타일에서만 쓸 수 있어요.

### 게시하기 전에 선택기 스타일을 미리 볼 수 있나요?
네. 선택기 동작이 **Page Builder**와 **Builder Preview**에 모두 반영되므로 게시하기 전에 확인할 수 있어요.

### 이 업데이트는 모바일 스토어 화면에도 적용되나요?
네. 데스크톱과 모바일 스토어 화면 모두에서 선택기 동작이 개선되었어요.

### 옵션을 선택하면 상품 이미지도 바뀌나요?
네. 고객이 옵션을 선택하면 하이퍼클래스가 그 옵션에 지정된 이미지를 자동으로 선택해요. 선택한 옵션에 지정된 이미지가 없으면 표시된 이미지는 그대로 유지돼요. 상품 이미지를 선택해도 선택된 옵션은 바뀌지 않아요.
