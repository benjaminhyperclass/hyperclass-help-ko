# VAT 자주 묻는 질문

하이퍼클래스 요금에 VAT/GST/HST가 붙는 이유, 세금 ID 번호 등록, 환불 문의처를 정리한 FAQ예요. 미국 외 지역 고객이 결제 중 세금 관련 궁금증이 생겼을 때 참고하세요.

{% hint style="info" %}
이 문서는 미국 외 지역 고객에게만 해당돼요.
{% endhint %}

에이전시의 세금 ID(Tax ID) 정보를 업데이트하는 자세한 방법은 관련 도움말을 참고하세요.

### 하이퍼클래스에서 왜 VAT/GST/HST를 부과하나요?

국제 세금 규정을 따르기 위해 VAT/GST/HST를 부과해요.

VAT/GST 적용 여부는 관할 지역에 따라 달라질 수 있어요. 대부분의 고객은 청구 프로필에 세금 ID 번호를 입력하지 않았을 때만 VAT/GST가 부과돼요. 일부 지역(멕시코, 스위스, 남아프리카공화국, 말레이시아, 인도네시아, 세르비아, 캐나다 일부 주 등)은 세금 ID 번호를 입력했더라도 VAT/GST를 부과해야 해요.

### 세금은 언제부터 부과되나요?

정확한 시점은 관할 지역에 따라 달라요. 2025년 초부터 인보이스에 VAT/GST가 추가될 거예요.

### 해외 고객 모두에게 VAT/GST/HST가 부과되나요?

네, 하이퍼클래스는 적용 대상인 모든 곳에서 VAT/GST를 부과해요. 다만 예외가 있을 수 있어요. 예를 들어 다음 경우에는 VAT/GST를 받지 않아요.

- 해당 국가가 등록된 사업자에 대한 판매에 세금을 부과하지 않고, 청구 프로필에 세금 ID 번호를 입력한 경우
- 하이퍼클래스가 단독 재량으로 해당 거래에 VAT/GST가 적용되지 않는다고 판단한 경우. 세금 관련 법은 수시로 바뀔 수 있고, 법이 바뀌면 인보이스에 부과되는 세금의 적용 여부나 금액이 달라질 수 있어요.

### 프로필에 세금 ID 번호를 입력했는데 왜 VAT/GST/HST가 부과되나요?

일부 국가는 세금 ID 번호를 입력한 B2B 고객을 포함해 모든 고객에게 세금을 적용하도록 요구하기 때문이에요. 해당 국가에는 남아프리카공화국, 멕시코, 스위스, 세르비아, 말레이시아, 인도네시아, 캐나다 일부 주 등이 있으며, 이 외에도 더 있을 수 있어요.

### 프로필에 세금 ID 번호를 입력하려는데 오류 메시지가 나와요. 어떻게 해야 하나요?

하이퍼클래스 고객지원에 문의하세요.

### **I don’t have a Tax ID number**(세금 ID 번호 없음) 체크박스를 선택해서 VAT/GST/HST가 부과되고 있어요. 최근에 세금 ID 번호를 받았는데, 프로필에 어떻게 입력하나요?

**설정 > 청구/결제** 화면의 **결제** 탭에서 결제 정보를 확인하세요.

### **I don’t have a Tax ID number** 체크박스를 선택해서 VAT/GST/HST가 부과되고 있어요. 세금 ID 번호를 뒤늦게 찾았는데, 이미 낸 세금을 환불받을 수 있나요?

건별로 검토해요. 하이퍼클래스 고객지원에 문의하세요.

### 더 궁금한 점이 있으면 어디에 문의하나요?

세금의 성격이나 적용 여부가 궁금하다면 회사의 세무 전문가와 상담하거나 하이퍼클래스 고객지원에 문의하세요.
