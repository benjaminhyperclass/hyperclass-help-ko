# Eliza 에이전트 플랫폼 검색 도구

Eliza 에이전트 플랫폼의 검색 도구로 연락처와 대화를 찾고, 연락처를 에이전트에게 배정하는 방법을 안내해요.

## 연락처 검색

**검색 > 연락처**에서 연락처를 검색할 수 있어요.

![검색 > 연락처 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48290427971/original/M5YV-pUoDrS0Jp6FRFYQduTM13OP2t2G5g.png?1680263410)

이 화면에서 연락처를 검색할 서브 계정을 선택하면, Eliza 에이전트 플랫폼이 해당 서브 계정의 연락처를 모두 보여 줘요.

서브 계정 안에서는 이름, 성, 태그, 전화번호, 주소로 연락처를 검색할 수 있어요.

연락처를 선택한 뒤 **Add to Conversations**(대화에 추가)를 클릭하면 특정 에이전트의 인박스에 그 연락처를 추가할 수 있어요.

![연락처를 선택해 에이전트 인박스에 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48290416644/original/qz5ZDeB73Ne2wQXYKGddnUO22dPzozjavQ.png?1680260295)

### 연락처 추가

Eliza 사용자는 **검색 > 연락처**에서 Eliza를 통해 서브 계정에 연락처를 추가할 수 있어요. 이렇게 추가한 연락처는 해당 서브 계정에 동기화되고, 연락처 소스 필드에는 `Eliza_User`로 표시돼요.

Eliza를 통해 서브 계정에 연락처를 추가한 뒤에는 Eliza 에이전트가 그 연락처를 본인이나 다른 에이전트에게 직접 배정해야 해요. 서브 계정의 감사 로그에는 추가된 연락처 기록이 남아요.

![연락처 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48290416793/original/QD4ShMwXJ5d9yjaLT7SjggNH3CD54Rwk4Q.png?1680260325)

![연락처 추가 후 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48290411412/original/R_f7ThWHHh2-e1aMQTA5-1_PKQ6mC5kNHw.jpeg?1680259102)

### 대화에 추가

리드와 대화를 시작하려면 연락처를 선택한 뒤 드롭다운에서 에이전트를 골라 배정하세요. 선택한 연락처는 그 에이전트의 인박스에 추가돼요.

### 감사 로그

연락처를 선택하면 해당 연락처와 나눈 모든 대화의 감사 기록을 볼 수 있어요.

감사 기록에는 Eliza 에이전트와 연락처 사이의 모든 대화 내용, 지정된 처리 결과(disposition), 날짜가 담겨 있어요.

![연락처의 감사 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48290417377/original/HLMf_GahdUYxNsMyDUJuiwRKRoS00tExJA.png?1680260534)

### 대화 검색

대화 검색에서는 Eliza 에이전트 플랫폼이 지원하는 모든 채널에서 에이전트와 연락처가 나눈 대화를 읽기 전용으로 볼 수 있어요.

{% hint style="info" %}
이 검색으로는 Eliza 에이전트 플랫폼 안에서 관리한 연락처만 찾을 수 있어요.
{% endhint %}
