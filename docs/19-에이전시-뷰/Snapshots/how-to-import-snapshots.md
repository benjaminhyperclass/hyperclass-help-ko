# 스냅샷 가져오기

공유받은 스냅샷을 하이퍼클래스 에이전시의 스냅샷 라이브러리에 추가하면, 지원되는 에셋을 서브 계정에서 확인하고 다시 쓸 수 있어요. 새로 바뀐 가져오기 화면에서는 스냅샷 이름을 바꾸고, 처리 상태를 확인하고, 공유 링크 오류의 원인을 더 쉽게 파악할 수 있어요. 보호된 에셋은 가져온 뒤에도 에이전시 안에서 쓸 수 있고, 에이전시 밖으로 나가는 것은 계속 제한돼요.

## 이 문서에서 다루는 내용

스냅샷 가져오기와 불러오기가 어떻게 다른지, 공유 링크나 이메일 초대로 가져오는 방법, 처리 상태 확인과 가져오기 실패 대처법, 보호된 에셋이 들어 있는 스냅샷을 가져올 때 어떻게 되는지 설명해요.

{% hint style="warning" %}
가져오기와 불러오기는 서로 다른 작업이에요. 가져오기는 공유받은 스냅샷을 에이전시 단위의 스냅샷 라이브러리에 추가하는 작업이고, 불러오기는 그 스냅샷의 에셋을 선택해서 특정 서브 계정에 적용하는 작업이에요.
{% endhint %}

## 스냅샷 가져오기란?

스냅샷 가져오기는 스냅샷 공유 링크나 이메일 초대를 이용해, 공유받은 스냅샷을 하이퍼클래스 에이전시에 추가하는 작업이에요. 가져온 스냅샷은 에이전시 단위의 스냅샷 라이브러리에 저장돼요. 서브 계정에 적용하기 전에 여기서 먼저 내용을 살펴볼 수 있어요.

가져오기만 해서는 스냅샷의 에셋이 고객 계정에 자동으로 들어가지 않아요. 에셋을 적용하려면 가져온 스냅샷을 원하는 서브 계정에 불러오고, 포함할 에셋을 직접 골라야 해요.

전체 흐름은 이렇게 간단해요: 공유 → 에이전시 라이브러리로 가져오기 → 서브 계정에 불러오기

## 스냅샷 가져오기의 장점

새로워진 가져오기 화면에서는 공유받은 스냅샷을 열 때부터 사용할 준비가 끝날 때까지 상황을 더 분명하게 알 수 있어요. 이름 변경, 처리 상태, 오류 안내, 보호 표시 덕분에 가져온 스냅샷을 관리하기 쉬워졌어요.

- 정리하기 쉬워요: 가져오면서 스냅샷 이름을 바꿔 두면 에이전시 라이브러리에서 쉽게 알아볼 수 있어요.
- 설정이 빨라요: 유효한 스냅샷 공유 링크나 이메일 초대만 있으면 바로 에이전시 라이브러리에 추가할 수 있어요.
- 가져오는 상황이 잘 보여요: 처리 중인 스냅샷은 회색으로 표시되고, 사용할 준비가 되면 언제 활성화되는지 알 수 있어요.
- 오류 안내가 구체적이에요: 만료됐거나, 이미 사용됐거나, 제한됐거나, 사용할 수 없는 공유 링크를 더 빨리 구분할 수 있어요.
- 보호 여부가 한눈에 보여요: **보안 실드** 표시로 보호된 에셋이 들어 있는 스냅샷을 알아볼 수 있고, 그 에셋을 내부에서 쓰는 데도 문제가 없어요.
- 내부에서 다시 쓰기 좋아요: 보호된 스냅샷을 정상적으로 가져온 뒤에는, 같은 에이전시의 서브 계정과 내부 스냅샷 작업에서 보호된 에셋을 다시 쓸 수 있어요.

## 에셋 보호 스냅샷을 가져올 때

에셋 보호는 스냅샷을 만든 쪽이 외부 재배포는 막으면서도, 받은 에이전시 안에서의 정상적인 사용은 막지 않도록 하는 기능이에요. 에셋 보호 스냅샷을 가져와도 보호는 해제되지 않아요. 그렇다고 에이전시 안에서 보호된 에셋을 쓰는 데 지장이 생기지도 않아요.

| 작업 | 보호된 에셋의 동작 |
| --- | --- |
| 유효한 보호 스냅샷 가져오기 | 허용 |
| 받은 에이전시의 서브 계정에 보호된 에셋 불러오기 | 허용 |
| 같은 에이전시의 다른 서브 계정에서 보호된 에셋 다시 사용하기 | 허용 |
| 보호된 에셋으로 다른 스냅샷을 만들거나 새로고침하기 | 에이전시 안에서는 허용 |
| 보호된 에셋을 다른 에이전시에 공유하거나 재판매하기 | 제한됨 |
| 혼합 스냅샷을 외부에 공유하기 | 보호되지 않은 에셋 중 공유할 수 있는 것은 계속 진행되고, 보호된 에셋은 제외돼요. |

에이전시 안에서 보호된 에셋을 불러오거나, 복사하거나, 다시 사용해도 보호 상태는 해제되거나 약해지지 않고 그대로 유지돼요.

![보호된 에셋이 포함된 스냅샷에 표시가 붙은 스냅샷 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079639457/original/SayeIS7KD2v9iLiKcpL_pBNxONlmmWLmhA.png?1788099028=)

보호 방식 전체는 [에셋 보호 스냅샷(예전 이름: IP 보호)](assets-protected-snapshots-called-ip-protected-earlier.md) 문서에서 확인하세요.

## 스냅샷 가져오기 진행 상황 확인

가져오기 상태를 보면 아직 처리 중인 스냅샷과 바로 쓸 수 있는 스냅샷을 구분할 수 있어요. 처리가 끝날 때까지 기다리면 가져오기를 중복으로 시도하거나, 아직 완성되지 않은 스냅샷을 불러오려는 일을 피할 수 있어요.

- 가져오기를 시작하면 스냅샷이 **가져온 스냅샷** 목록에 나타나요.
- 처리가 진행되는 동안에는 스냅샷이 회색으로 표시돼요.
- 회색으로 보인다고 해서 가져오기를 다시 시작할 필요는 없어요.
- 처리가 끝나면 스냅샷이 활성화되어 사용할 수 있어요.

{% hint style="info" %}
스냅샷이 활성화될 때까지 기다렸다가 서브 계정에 불러오세요.
{% endhint %}

## 스냅샷 가져오기 오류 이해하기

공유 링크는 여러 이유로 실패할 수 있어요. 링크가 만료됐는지, 이미 사용됐는지, 다른 대상으로 제한돼 있는지, 스냅샷을 사용할 수 없는지에 따라 다음에 할 일이 달라요. 원인을 먼저 확인하면 불필요하게 다시 시도하지 않아도 돼요.

| 상황 | 의미 | 해야 할 일 |
| --- | --- | --- |
| 만료된 스냅샷 공유 링크 | 공유 링크가 더 이상 유효하지 않아요. | 스냅샷 소유자에게 새 공유 링크를 만들어 달라고 요청하세요. |
| 이미 사용된 일회용 링크 | 허용된 가져오기가 이미 끝났어요. | 보낸 사람에게 일회용 링크를 다시 만들어 달라고 요청하세요. |
| 제한된 링크 | 링크가 특정 에이전시나 서브 계정으로 제한되어 있을 수 있어요. | 가져오려는 에이전시에 로그인했는지, 보낸 사람이 제한 대상을 올바르게 설정했는지 확인하세요. |
| 사용할 수 없는 스냅샷 | 원본 스냅샷이 없어졌거나, 이 공유로는 더 이상 쓸 수 없을 수 있어요. | 보낸 사람에게 스냅샷을 확인하고, 필요하면 새로 공유해 달라고 요청하세요. |
| 일반적인 가져오기 실패 | 가져오기가 정상적으로 끝나지 않았어요. | 공유가 아직 유효한지 확인한 뒤 다시 시도하세요. 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요. |
| 보안 실드 / 에셋 보호 표시 | 스냅샷에 보호된 에셋이 들어 있어요. | 오류가 아니에요. 유효한 가져오기를 그대로 진행하세요. 해당 에셋의 보호 상태는 그대로 유지돼요. |

## 스냅샷 가져오는 방법

먼저 스냅샷을 가져와 올바른 에이전시 라이브러리에 저장해 두면, 그다음에 서브 계정에서 에셋을 안전하게 쓸 수 있어요. 스냅샷 공유 링크나 이메일 초대 중 어느 쪽으로든 시작할 수 있어요.

{% hint style="info" %}
스냅샷을 가져올 수 없다면 사용자에게 **Share/Import Snapshots**(스냅샷 공유/가져오기) 등 스냅샷 관련 권한이 있는지 확인하세요.
{% endhint %}

### 방법 1. 스냅샷 공유 링크로 가져오기

스냅샷 공유 링크를 열면 받는 사람용 가져오기 화면이 바로 나타나요. 링크를 열기 전에 스냅샷을 저장할 에이전시에 먼저 로그인하세요.

1. 스냅샷을 가져올 하이퍼클래스 에이전시에 로그인하세요.
2. 보낸 사람이 준 스냅샷 공유 링크를 여세요. 필요하면 새 브라우저 탭에 붙여 넣어도 돼요.
3. 스냅샷 가져오기 팝업을 확인하세요.
4. 가져오기 전에 이름을 바꾸려면 **스냅샷 이름**에 원하는 이름을 입력하세요.
5. **Import Now**(지금 가져오기)를 클릭하세요.
6. 스냅샷이 **가져온 스냅샷** 목록에 나타나는지 확인하세요.
7. 회색 처리 중 상태가 사라지고 스냅샷을 쓸 수 있을 때까지 기다리세요.

![스냅샷 이름 입력란과 지금 가져오기 버튼이 있는 스냅샷 가져오기 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071794433/original/_TcGehhSTyMP6Ce-mnS7Gm1xlFcvh810Cg.png?1779279980)
![처리 중이라 회색으로 표시된 스냅샷이 있는 가져온 스냅샷 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071794510/original/Z9STIZhBAXLpIBgqwIVB63VfusmnL5cfJA.png?1779280031)

### 방법 2. 이메일로 가져오기

이메일 초대로 시작해도 가져오기 화면은 기본적으로 같아요. 초대는 받는 사람에게 바로 전달돼요.

1. 스냅샷을 가져올 하이퍼클래스 에이전시에 로그인하세요.
2. 스냅샷 초대 이메일을 여세요.
3. 이메일 안의 스냅샷 가져오기 링크를 클릭하세요.
4. 스냅샷 가져오기 팝업을 확인하세요.
5. 필요하면 스냅샷 이름을 바꾸세요.
6. **가져오기**를 클릭하세요.
7. 처리가 끝날 때까지 기다린 뒤에 스냅샷을 서브 계정에 불러오세요.

![스냅샷 가져오기 링크가 들어 있는 스냅샷 초대 이메일](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071822070/original/V0Yo8P0R7BTka8EfVImswQPqqWpa1Bnrzg.png?1779290724)

## 가져온 스냅샷을 서브 계정에 불러오기

가져온 스냅샷은 서브 계정에 직접 불러오기 전까지 에이전시 단계에 머물러 있어요. 불러올 때 대상 계정, 적용할 에셋, 서브 계정에 이미 있는 에셋과의 충돌을 직접 정할 수 있어요.

가져온 스냅샷에 보호된 에셋이 들어 있어도, 같은 에이전시의 서브 계정에는 그 에셋을 선택해서 불러올 수 있어요. 불러와도 보호 상태는 해제되지 않아요.

### 1단계. 대상 서브 계정 열기

**에이전시 보기**에서 스냅샷을 불러올 서브 계정을 찾으세요. 해당 서브 계정의 작업 메뉴를 열고 **고객 관리**를 선택하세요.

![대상 서브 계정의 작업 메뉴가 보이는 에이전시 서브 계정 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080791240/original/ZH-0zrpdbvaNafkINQVtWru29MUT0ktZeg.png?1789246310)
![고객 관리 항목이 보이는 서브 계정 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071796844/original/s8mSERi6DDizLkg3Bb_c9X-67e3Oy6jFuA.png?1779280978)

### 2단계. 스냅샷 불러오기 선택

**작업**을 클릭한 다음 **Load Snapshot**(스냅샷 불러오기)을 선택하세요.

![스냅샷 불러오기 항목이 보이는 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071797037/original/BhMgfjVjco6zQqf4Zmdcl2hGkKTScz0-hg.png?1779281048)

### 3단계. 가져온 스냅샷 고르기

스냅샷 목록에서 방금 가져온 스냅샷을 선택하세요.

![스냅샷 선택란이 보이는 스냅샷 불러오기 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071797198/original/ZwO0VK7C06xezVfe93oI1CdtJNxIBs5tOA.png?1779281121)

### 4단계. 불러올 에셋 선택하기

대상 서브 계정에 적용할 스냅샷 에셋을 선택하세요. 지원되는 에셋만 선택할 수 있어요.

![서브 계정에 불러올 에셋을 고르는 스냅샷 에셋 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080791243/original/_CgHPFYFJIYjDv0n00plhjAMGv59oQ4heA.png?1789246325)

### 5단계. 충돌 확인 후 불러오기 확정하기

감지된 충돌이 있으면 확인하고, 이미 있는 에셋을 어떻게 처리할지 선택하세요. 모두 맞게 설정했다면 스냅샷 불러오기를 확정하세요.

![에셋 선택과 충돌 확인을 마친 뒤 나오는 스냅샷 불러오기 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071797395/original/QFEwFaHZw2zXaPahOxnbeAk_FhbaeYlPmQ.png?1779281235)

## 자주 묻는 질문

### 스냅샷을 가져오면서 이름을 바꿀 수 있나요?
네. 가져오기 팝업에서 가져오기를 마치기 전에 원하는 스냅샷 이름을 입력할 수 있어요.

### 가져온 스냅샷이 회색으로 보여요.
스냅샷이 아직 처리 중이라는 뜻이에요. 가져오기를 다시 시작하거나 바로 불러오려고 하지 말고, 스냅샷이 활성화될 때까지 기다리세요.

### 보안 실드 아이콘은 무슨 뜻인가요?
스냅샷에 보호된 에셋이 들어 있다는 표시예요. 이 에셋들은 에이전시 안에서 가져오고, 불러오고, 다시 사용할 수 있어요. 다만 보호 상태가 그대로 유지되기 때문에 외부 재배포는 제한돼요.

### 가져온 보호된 에셋을 서브 계정 여러 개에 불러올 수 있나요?
네. 보호된 에셋은 받은 에이전시 안의 여러 서브 계정에서 다시 사용할 수 있어요. 보호 상태는 그대로 유지돼요.

### 가져온 보호된 에셋으로 다른 스냅샷을 만들거나 새로고침할 수 있나요?
네. 보호된 에셋은 에이전시 안의 내부 만들기·새로고침 작업에 포함할 수 있어요. 다시 사용해도 보호는 해제되지 않아요.

### 가져온 보호된 에셋을 다른 에이전시에 공유할 수 있나요?
아니요. 보호된 에셋이 에이전시 밖으로 나가게 되는 경우에는 계속 제한돼요. 혼합 스냅샷을 외부에 공유하면 보호된 에셋은 제외되고, 공유할 수 있는 보호되지 않은 에셋만 계속 진행돼요.

### 스냅샷 공유 링크가 만료됐어요. 어떻게 하나요?
처음에 스냅샷을 공유한 사람이나 에이전시에 새 스냅샷 공유 링크를 요청하세요.

### 스냅샷을 가져오면 서브 계정에 자동으로 불러와지나요?
아니요. 가져오기는 스냅샷을 에이전시 라이브러리에 저장하는 작업이에요. 선택한 에셋을 적용하려면 원하는 서브 계정에 따로 불러와야 해요.
