# 문서 & 계약 설정을 다른 계정에 복제하기

스냅샷에 문서 & 계약이 포함돼요. 스냅샷을 쓰면 문서 템플릿을 여러 서브 계정에 똑같이 복제할 수 있어요. 에이전시 관리자만 쓸 수 있어요.

에이전시는 새 고객을 맞이할 때 시간을 아끼고, 여러 서브 계정에서 같은 문서 템플릿을 쓸 수 있어요.

## 사용 방법

1. **Agency View**(에이전시 뷰)에서 **계정 스냅샷**으로 이동하세요.
2. 새 스냅샷을 만들고 원본 계정을 선택하세요.
3. 스냅샷을 저장하세요.
4. 문서 템플릿을 넣을 서브 계정에 스냅샷을 불러오세요.
5. 해당 서브 계정에 불러올 문서 템플릿을 모두 선택하세요.

## 이 기능이 필요한 이유

- 고객 온보딩 과정이 간편해져요. 문서 & 계약 설정을 여러 계정에 쉽게 복제할 수 있어요.
- 문서 템플릿을 미리 구성해 두면 고객에게 기본 템플릿을 빠르게 제공할 수 있어요. 모든 계정에서 일관된 사용 경험도 유지할 수 있어요.
