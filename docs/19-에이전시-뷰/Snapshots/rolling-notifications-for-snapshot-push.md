# 스냅샷 푸시 롤링 알림

여러 서브 계정에 스냅샷을 푸시할 때 하이퍼클래스의 롤링 알림이 어떻게 동작하는지 설명해요. 서브 계정마다 알림을 따로 받지 않고 묶음 알림으로 받아서, 알림 목록이 깔끔해지고 진행 상황을 따라가기 쉬워요.

{% hint style="info" %}
이 문서는 스냅샷을 푸시할 때 앱 안에 표시되는 롤링 알림만 설명해요. 이메일 알림이 궁금하다면 [스냅샷 알림 설정](snapshot-notification-preferences.md) 문서를 참고하세요.
{% endhint %}

## 스냅샷 푸시란?

스냅샷 푸시는 미리 만들어 둔 설정, 퍼널, 워크플로우, 또는 계정 전체 설정을 하이퍼클래스 계정(주로 에이전시 템플릿)에서 다른 서브 계정으로 복사하는 작업이에요. 에이전시는 이 기능으로 표준 설정을 여러 고객사 계정에 한 번에 적용할 수 있어요. 계정마다 처음부터 새로 만들 필요가 없어요.

## 롤링 알림이란?

롤링 알림은 여러 서브 계정에 스냅샷을 푸시할 때 알림을 보내는 방식을 간단하게 바꾼 기능이에요. 예전에는 서브 계정(로케이션)마다 알림이 하나씩 왔어요. 이제는 10개를 넘는 서브 계정에 푸시하면 알림을 묶어서, 진행률 10%, 30%, 70%, 100%에 맞춰 보내요.

## 롤링 알림의 장점

묶음 알림은 알림 목록이 어수선해지는 것을 줄이고, 스냅샷 푸시가 어디까지 진행됐는지 보기 쉽게 해 줘요.

- 서브 계정 10개 이상에 푸시할 때 알림이 한꺼번에 쏟아지는 것을 줄여 줘요.
- 주요 4개 시점(10%, 30%, 70%, 100%)마다 묶음 진행 알림을 보내요.
- 서브 계정이 10개 미만이면 지금처럼 개별 알림을 보내요.
- 관리자가 대규모 스냅샷 푸시를 더 쉽게 확인할 수 있어요.
- 따로 설정할 필요 없이 자동으로 켜져 있어요.
- 스냅샷 푸시에 실패하면 개별 알림으로 알려 줘서 실패한 건을 놓치지 않아요.

## 서브 계정 10개 이하에 푸시한 경우

스냅샷을 10개 미만의 로케이션에 푸시하면 예전처럼 로케이션마다 개별 알림을 받아요.

![서브 계정 10개 이하에 푸시했을 때 로케이션별로 오는 개별 알림](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051041063/original/oRRnEeLnAvd1053xoXA8aRtD4NKex1ne1A.png?1754488280)

## 스마트 알림 묶음 (서브 계정 10개 초과에 푸시한 경우)

스마트 알림 묶음은 이 기능의 핵심이에요. 스냅샷을 푸시할 때 대상 로케이션 수에 따라 알림 방식을 나눠요.

- 10개 미만의 로케이션에 푸시하면 예전처럼 개별 알림을 보내요. 로케이션별로 자세한 내용을 확인할 수 있어요.
- 10개 이상의 로케이션에 푸시하면 알림을 묶어서 보내요. 처리된 로케이션이 10%, 30%, 70%, 마지막으로 100%에 이르는 시점마다 롤링 알림이 와요.
- 이렇게 묶으면 알림이 덜 어수선하고, 중요한 단계는 놓치지 않으면서 전체 진행 상황에 집중할 수 있어요.

![서브 계정 10개 초과 푸시에서 진행률 시점마다 오는 묶음 알림](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051043116/original/BUqjVZeIkOkBG6K5mnZMQmq_WNfEdpjxAQ.png?1754489193)

## 실패 개별 알림

묶음 방식으로 알림을 받더라도 실패한 푸시는 놓치지 않도록 개별 알림으로 알려 줘요.

- 스냅샷 푸시가 실패할 때마다 알림이 따로 와서 바로 눈에 띄어요.
- 실패 알림 덕분에 문제를 빠르게 확인하고 해결할 수 있어서, 같은 문제가 여러 계정에 계속 남아 있을 위험이 줄어요.
- 스냅샷 푸시 전 과정을 투명하게 확인할 수 있어서 이후 관리와 문제 해결이 더 빨라져요.

![푸시에 실패했을 때 오는 개별 실패 알림](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051042781/original/SiU5Nf1-sjOCe3bcDX2K11CQNrDwSFzAbA.png?1754489052)

{% hint style="warning" %}
진행률 알림과 실패 알림에는 모두 파란색 **상세 보기** 링크가 있어요. 이 링크를 누르면 **스냅샷 > Push History**(푸시 이력) 화면이 열리고, 해당 푸시 건만 걸러서 보여 줘서 여러 번 클릭하지 않아도 돼요.
{% endhint %}

## 자주 묻는 질문

### 개별 알림을 받을지 롤링 알림을 받을지는 무엇으로 정해지나요?

스냅샷을 10개 미만의 로케이션에 푸시하면 개별 알림을 받아요. 10개 이상의 로케이션에 푸시하면 주요 시점마다 롤링 알림으로 묶어서 받아요.

### 대규모 푸시를 하면 롤링 알림을 몇 번 받나요?

진행률 10%, 30%, 70%, 100% 시점에 묶음 알림을 총 네 번 받아요.

### 스냅샷 푸시 실패 알림도 묶여서 오나요?

아니요. 푸시가 실패하면 실패한 건마다 개별 알림이 와서 바로 확인할 수 있어요.

### 스냅샷 푸시의 자세한 내용은 어디에서 볼 수 있나요?

모든 알림에 **상세 보기** 링크가 있어요. 이 링크를 누르면 스냅샷 푸시 전체 이력으로 바로 이동해요.

### 묶음 알림을 끌 수 있나요?

아니요. 시스템 차원에서 적용되는 개선 사항이라 켜고 끌 수 없어요.
