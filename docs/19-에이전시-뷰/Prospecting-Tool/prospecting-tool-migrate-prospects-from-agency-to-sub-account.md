# 잠재고객 발굴 — 에이전시의 잠재고객을 서브 계정으로 마이그레이션하기

에이전시 단위로 만든 잠재고객을 연결된 서브 계정으로 옮기는 기능이에요. 서브 계정에서 잠재고객을 더 세밀하게 관리할 수 있고, 고급 잠재고객 발굴 도구도 모두 쓸 수 있어요. 에이전시 관리자가 쓰는 기능이에요.

## 잠재고객 마이그레이션이란?

잠재고객 마이그레이션은 에이전시의 잠재고객 발굴 대시보드에 있는 잠재고객 중 원하는 대상만 골라 특정 서브 계정으로 옮기는 기능이에요. 서브 계정은 자체 워크플로우와 도구로 해당 잠재고객을 직접 관리할 수 있어요.

잠재고객을 서브 계정으로 옮기면 후속 업무를 각 팀이나 고객사에 맡기면서도 에이전시에서 계속 확인하고 관리할 수 있어요. 마케팅을 더 집중해서 운영할 수 있고 리드 전환에도 도움이 돼요.

## 사전 준비

1. 옮겨 받을 서브 계정에서 프리미엄 잠재고객 발굴이 활성화되어 있어야 해요.
2. 에이전시에 이미 만들어 둔 잠재고객이 있어야 해요.

## 잠재고객 마이그레이션의 장점

에이전시가 잠재고객 발굴을 유연하게 운영하고 규모를 키우는 데 도움이 돼요.

- 고급 육성: 서브 계정의 자동화, 파이프라인, 소통 기능을 활용할 수 있어요.
- 업무 분담: 후속 관리를 맡을 서브 계정으로 잠재고객을 배정할 수 있어요.
- 잠재고객 추적 개선: 잠재고객과의 모든 상호작용을 계정별로 한곳에 정리해서 볼 수 있어요.
- 에이전시 통제: 마이그레이션한 잠재고객도 에이전시에서 계속 볼 수 있어서 나중에 다시 쓸 수 있어요.

## 잠재고객 마이그레이션 사용 방법

잠재고객을 서브 계정으로 옮기는 과정은 간단해요. 아래 순서대로 진행하세요.

### 1단계: 잠재고객 발굴 대시보드 열기

1. 하이퍼클래스 에이전시 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **잠재고객 발굴**(Prospecting)을 클릭하세요.

![잠재고객 발굴 메뉴](https://jumpshare.com/v/aLIT8F4APsdh1jBLczxc+/Screen+Shot+2025-06-23+at+8.18.34+PM.png)

### 2단계: 마이그레이션 탭 열기

1. **잠재고객 발굴** 화면 위쪽에서 **설정** 탭을 클릭하세요.
2. **설정** 안에서 **마이그레이션** 하위 탭을 선택하세요.
3. **Migrate Prospects**(잠재고객 마이그레이션) 버튼을 클릭하세요.

![마이그레이션 하위 탭과 버튼](https://jumpshare.com/v/Ixb5j4rjx15W92zqBs7T+/Screen+Shot+2025-06-23+at+8.21.10+PM.png)

### 3단계: 서브 계정 선택

1. 팝업이나 드롭다운에 나온 목록에서 서브 계정을 선택하세요.

{% hint style="info" %}
활성화된 잠재고객 발굴 프리미엄 구독이 있는 서브 계정만 목록에 나와요.
{% endhint %}

![서브 계정 선택 화면](https://jumpshare.com/v/37RJbMb6WD6zjTQ3k1W2+/Screen+Shot+2025-06-23+at+9.51.27+PM.png)

### 4단계: 옮길 잠재고객 선택

1. **Select Prospects**(잠재고객 선택) 버튼을 클릭하세요.
2. 드롭다운 목록에서 아래 방법 중 하나로 선택하세요.

   - 잠재고객을 한 명 선택해요.
   - 여러 명을 선택해요.
   - **전체 선택**을 눌러 옮길 수 있는 잠재고객을 모두 선택해요.

![잠재고객 선택 과정](https://jumpshare.com/v/fJJwAxCpWenpWbV5HTYs+/GIF+Recording+2025-06-23+at+9.53.14+PM.gif)

### 5단계: 마이그레이션 실행

1. 선택을 마쳤으면 **마이그레이션** 버튼을 클릭해 옮기기를 시작하세요.

![마이그레이션 버튼](https://jumpshare.com/v/cS9oCsLOtv9w1Mp5qM0m+/Screen+Shot+2025-06-23+at+9.58.21+PM.png)

## 마이그레이션 후에는 어떻게 되나요?

마이그레이션이 끝나면 선택한 잠재고객은 다음과 같이 처리돼요.

- 서브 계정의 **연락처**에 추가돼요.
- 모든 데이터, 메모, 기록이 그대로 유지돼요.
- 에이전시 계정에도 그대로 남아 있어서 이후에 다시 마이그레이션하거나 다른 작업을 할 수 있어요.

이렇게 양쪽에 모두 남아 있어서 에이전시는 전체 현황을 계속 확인하고 관리할 수 있어요.

## 잠재고객 재사용

- 같은 잠재고객을 시간을 두고 여러 서브 계정으로 마이그레이션할 수 있어요.
- 잠재고객 데이터는 여러 위치에서 일관되게 최신 상태로 유지돼요.

## 자주 묻는 질문

### 마이그레이션하면 에이전시에서 잠재고객이 삭제되나요?
아니요. 잠재고객은 서브 계정으로 복사되고, 에이전시에도 그대로 남아 있어요.

### 같은 잠재고객을 여러 서브 계정으로 마이그레이션할 수 있나요?
네, 필요에 따라 서로 다른 서브 계정으로 마이그레이션할 수 있어요.

### 마이그레이션 후에도 잠재고객의 기록, 메모, 데이터가 유지되나요?
네, 관련 데이터는 마이그레이션 중에도 모두 그대로 유지돼요.

### 여러 명을 한꺼번에 마이그레이션할 수 있나요?
네, 여러 잠재고객을 선택해서 한 번에 마이그레이션할 수 있어요.

### 마이그레이션 기능은 구독에 포함되어 있나요?
네, 이 기능은 잠재고객 발굴 프리미엄 구독에 포함되어 있어서 추가 비용이 들지 않아요.

### 마이그레이션을 되돌릴 수 있나요?
마이그레이션한 뒤에도 잠재고객은 에이전시에 그대로 남아 있어요. 다만 서브 계정에서 바뀐 내용은 직접 관리해야 해요.
