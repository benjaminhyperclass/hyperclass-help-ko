# 마케팅 감사 PDF 리포트 사용자 지정 및 내보내기 (다국어 지원)

마케팅 감사 PDF를 웹 리포트처럼 브랜드에 맞춰 깔끔하게 만들 수 있어요. 하이퍼클래스의 **잠재고객 발굴**(Prospecting) 도구에서 색상, 테두리, 제목, 연락처 세부정보를 직접 정하면 어떤 형식으로 공유해도 에이전시의 브랜드가 일관되게 보여요.

## 마케팅 감사 리포트의 PDF 사용자 지정이란?

Report Builder(리포트 빌더)에서 설정한 브랜드 테마, 머리글, 바닥글을 내보내는 PDF 감사 리포트에 그대로 적용하는 기능이에요. 모든 PDF가 웹 리포트와 같은 브랜딩으로 자동 구성되니 따로 디자인 작업을 할 필요가 없어요. 잠재 고객에게 일관된 경험을 주고, 설정에 드는 시간도 아낄 수 있어요.

{% hint style="info" %}
이 기능을 쓰려면 프리미엄 잠재고객 발굴 구독이 필요해요. **미리보기 모드**는 에이전시와 서브 계정 모두 무료로 쓸 수 있어요.
{% endhint %}

## PDF 사용자 지정의 장점

- 일관된 브랜딩: 웹 링크와 PDF가 항상 같은 모습이라 통일된 경험을 줘요.
- 바로 전달 가능한 완성도: 전문적인 모습으로 잠재 고객의 신뢰를 쌓을 수 있어요.
- 한 번 설정하면 어디서나 동기화: Report Builder에서 설정하면 모든 리포트에 변경 사항이 적용돼요.
- 브랜드에 맞춘 스타일: 테두리와 제목 색상을 원하는 팔레트에 맞출 수 있어요.
- 분명한 연락처 정보: 표지와 바닥글에 에이전시 정보를 넣어 잠재 고객이 빠르게 연락할 수 있어요.

## 잠재고객 발굴에서 Report Builder 열기

**Report Builder**(리포트 빌더)는 **프리미엄 잠재고객 발굴 구독**을 쓰는 사용자라면 에이전시와 서브 계정 양쪽에서 열 수 있어요. 기본 잠재고객 발굴을 쓰고 있다면 Report Builder를 둘러볼 수는 있지만, 변경 사항은 저장할 수 없어요.

### 에이전시에서 열기

1. 에이전시 계정에 로그인하세요.
2. 메인 메뉴에서 **잠재고객 발굴** 탭을 클릭하세요.
3. **Report Builder** 탭을 선택하면 리포트 사용자 지정을 시작할 수 있어요.

![에이전시에서 Report Builder 탭 열기](https://jumpshare.com/v/8pGNdQIymy3P4VACl5iU+/Screen+Shot+2025-07-07+at+9.42.04+PM.png)

### 서브 계정에서 열기

1. 서브 계정에 로그인하세요.
2. **마케팅** 탭을 클릭하세요.
3. **잠재고객 발굴**을 클릭하세요.
4. **Report Builder** 탭을 클릭하면 리포트 작성을 시작할 수 있어요.

![서브 계정에서 Report Builder 탭 열기](https://jumpshare.com/v/q2r18oyQVX3NUdA3iAiB+/Screen+Shot+2025-07-07+at+9.46.07+PM.png)

## PDF 사용자 지정 설정하고 사용하기

처음에 제대로 설정해 두면 모든 리포트가 깔끔하게 나오고, 일일이 수정할 일도 줄어요.

{% hint style="info" %}
웹 전용 머리글/바닥글 블록은 PDF에 나타나지 않아요.
{% endhint %}

### 1단계: 브랜딩 및 테마 설정

1. **Brand Name**(브랜드 이름) 및 **연락처 세부정보** – Report Builder에 에이전시 이름, 전화번호, 이메일, 웹사이트를 입력하세요.

   ![브랜드 이름과 연락처 세부정보 입력 화면](https://jumpshare.com/share/DsQNQ3uFjWlSWeHCkniT+/Screenshot+2025-10-02+at+6.05.06%E2%80%AFPM+%281%29.png)
2. 테두리와 색상 – **테두리 사용자 지정**에서 테두리 색상을 브랜드에 맞게 정하세요.
3. **Heading Colours**(제목 색상) – Local Rank Tracker, Tech Stack Analysis 같은 섹션 제목의 색을 브랜드 색상과 맞추세요.
4. 리포트 사용자 지정에 대한 자세한 안내는 "잠재고객 발굴 도구 - 완전히 사용자 지정할 수 있는 잠재 고객 리포트 빌더(Prospecting Tool - Fully Customizable Prospect Report Builder)" 문서를 참고하세요.

   ![리포트 사용자 지정 화면](https://jumpshare.com/share/2WaHW6naTKrLmio6qq5k+/Screenshot+2025-10-02+at+6.04.06%E2%80%AFPM.png)

### 2단계: 리포트 미리보기 및 저장

1. **미리보기**를 클릭하면 리포트 디자인을 실시간으로 확인할 수 있어요.
2. 테두리, 제목, 머리글/바닥글 정보에 브랜드 색상이 잘 적용됐는지 살펴보세요.
3. **저장**을 클릭하세요. 선택한 내용이 빌더에 적용되고, 이후 만드는 PDF나 웹 리포트에도 별도 작업 없이 반영돼요.

   ![리포트 미리보기 후 저장하는 모습](https://jumpshare.com/share/QuqoMeQj55SuPUp13qG8+/GIF+Recording+2025-10-09+at+9.39.47+PM.gif)

### 3단계: PDF 리포트 내보내기

1. **잠재고객 발굴** → **모든 계정**(잠재 고객 목록)으로 이동하세요.
2. 원하는 잠재 고객에서 **리포트 보기**를 클릭한 다음 **PDF 내보내기**를 클릭하세요.

   ![리포트 보기에서 PDF 내보내기 선택](https://jumpshare.com/share/WvjWQ0ghnPtZSrfIMN7a+/GIF+Recording+2025-10-09+at+9+50.06+PM.gif)
3. 또는 목록에서 바로 PDF 내보내기를 클릭하고 PDF 언어를 고르세요. 내보낸 PDF 안에서 시스템이 만든 텍스트(섹션 제목, 버튼 레이블, 리포트 안내 문구 등)는 모두 선택한 언어로 자동 표시돼요.
4. **PDF 내보내기**를 클릭하세요.

   ![언어를 선택하고 PDF 내보내기](https://jumpshare.com/share/0SgZyl51esAFtS7qgnzQ+/GIF+Recording+2025-10-09+at+9.54.03+PM.gif)
5. 준비가 끝나면 앞서 설정한 브랜드 사용자 지정이 모두 적용된 PDF 리포트가 새 탭에서 열려요.

   ![브랜드가 적용된 PDF 리포트가 새 탭에서 열린 모습](https://jumpshare.com/share/NA3YCMEoKveas0EBBHuS+/GIF+Recording+2025-10-09+at+9.58.42+PM.gif)

{% hint style="info" %}
내용과 섹션이 많은 리포트도 PDF로 안정적으로 내보낼 수 있도록 마케팅 감사 리포트의 PDF 내보내기가 개선됐어요. 오래된 리포트에 최신 감사 결과가 반영되어 있지 않다면, 리포트를 새로고침한 뒤 PDF를 내보내세요.
{% endhint %}

## 자주 묻는 질문

### 다국어 PDF 내보내기를 지원하나요?
네. PDF를 내보낼 때 원하는 언어를 선택할 수 있어요. 리포트 안에서 시스템이 만든 텍스트(제목, 안내 문구, 레이블 등)는 선택한 언어에 맞게 자동으로 바뀌어요.

### 에이전시 로고가 PDF 머리글에서 크기에 맞게 조정되나요?
네. **Header Customization**(머리글 사용자 지정)의 로고 필드는 이미지를 최대 너비 300px까지 자동으로 조정해서 인쇄 품질이 최적이 되도록 해요.

### 이 기능을 쓰려면 프리미엄 잠재고객 발굴이 꼭 필요한가요?
네, 필요해요.

### 변경 사항을 실시간으로 볼 수 있나요?
네. 빌더에서 실시간 미리보기를 제공하니, 게시하기 전에 바뀐 모습을 바로 확인할 수 있어요.
