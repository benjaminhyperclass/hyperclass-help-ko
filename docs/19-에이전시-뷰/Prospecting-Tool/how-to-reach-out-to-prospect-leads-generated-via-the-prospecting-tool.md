# 잠재고객 발굴로 찾은 프로스펙트에게 연락하기

**잠재고객 발굴**(Prospecting)에서 AI, 직접 검색, 잠재고객 발굴 위젯으로 찾은 프로스펙트(발굴 대상)는 서브 계정 CRM의 연락처 목록에 자동으로 추가돼요. 이 문서에서는 추가된 프로스펙트를 찾는 방법과, 이메일·SMS·워크플로우로 연락해 고객으로 전환하는 방법을 안내해요.

---

## 잠재고객 발굴은 어디에서 쓸 수 있나요?

잠재고객 발굴은 두 곳에서 쓸 수 있어요.

- **에이전시 보기**: 리드를 찾고 기본적인 발굴을 할 때 써요.
- **서브 계정 보기**: 고객과 적극적으로 소통하고 자동화할 때 써요.

{% hint style="info" %}
이메일과 SMS를 보내고 워크플로우를 실행할 수 있는 곳은 서브 계정뿐이에요. 그래서 잠재고객 발굴은 서브 계정 안에서 하거나, 에이전시에서 서브 계정으로 이전해 활용할 때 효과가 가장 커요.
{% endhint %}

### 서브 계정에서 잠재고객 발굴을 켜는 방법

1. 에이전시에 이미 사용 중인 잠재고객 발굴 구독이 있는 경우
   1. [서브 계정을 연결](../Prospecting-Subscription/how-to-share-agency-prospecting-premium-subscription-with-a-sub-account.md)하면 사용할 수 있어요.
   2. 그다음 해당 서브 계정으로 [프로스펙트를 이전](prospecting-tool-migrate-prospects-from-agency-to-sub-account.md)하세요. 이전하면 연락처로 자동 복사되고, 워크플로우가 있으면 함께 실행돼요.
   3. 해당 서브 계정의 **마케팅** 메뉴에서 **잠재고객 발굴**을 찾으세요.
2. 서브 계정 여러 개에서 쓰고 싶은 경우
   1. **에이전시 보기**에서 [**재판매**](how-to-resell-and-use-prospecting-tool-for-sub-accounts.md) 탭으로 이동하세요.
   2. **잠재고객 발굴** 토글을 켜세요.
3. 이미 서브 계정이 있는 경우
   1. 에이전시에서 서브 계정으로 [프로스펙트를 이전](prospecting-tool-migrate-prospects-from-agency-to-sub-account.md)하면 돼요. 이전하면 연락처에 자동으로 추가되고, 워크플로우가 있으면 함께 실행돼요.

---

## 프로스펙트가 연락처 목록에 추가되는 방식

이 기능은 서브 계정 단계에서 잠재고객 발굴을 했을 때 사용할 수 있어요.

따로 설정할 필요는 없어요. 아래 방법으로 프로스펙트를 만들면 서브 계정의 **연락처**에 자동으로 추가돼요.

- [AI로 프로스펙트 생성하기](../Core-Functionality/step-by-step-how-to-generate-prospects-by-ai.md)
- Google 비즈니스 직접 검색
- 내 사이트에 넣은 잠재고객 발굴 위젯

추가된 뒤에는 바로 이런 일을 할 수 있어요.

- 이메일/SMS로 연락 시작하기
- **기회 관리**의 **파이프라인**에 추가하기
- 워크플로우를 실행해 자동으로 육성하기
- 에이전시에서 서브 계정으로 이전(복사)하기

새 프로스펙트가 만들어지면 알림도 받아요.

## 연락처 목록에서 프로스펙트 찾기

1. 서브 계정으로 들어가세요.
   에이전시 보기에서 잠재고객 발굴을 한 서브 계정을 선택해 들어가면 돼요.
2. 왼쪽 메뉴에서 **연락처**를 클릭하세요.
3. 프로스펙트만 걸러 보세요.
   1. **연락처** 페이지 오른쪽 위의 **더 많은 필터** 버튼을 클릭하세요.
   2. 필터 드롭다운에서 아래처럼 선택하세요.
      - **필드**: 태그
      - **조건**: is
      - **값**: `New Prospect Received`

      ![필터 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047915809/original/VUVVU1FuBeAGnXyTSuFRIpVkHwgDT5d5iQ.png?1749408463)
4. 필터를 적용하세요.
   잠재고객 발굴로 만들어진 연락처 목록이 나타나요.

![프로스펙트 연락처 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047915810/original/VEA1SXXwtgx8pssE9b-yBBBIjCHejLTvfw.jpeg?1749408477)

## 프로스펙트에게 연락하기

1. **잠재고객 발굴** 안에서 프로스펙트 리포트를 열고 **Share**(공유) 옵션을 클릭하면 SMS나 이메일로 공유할 수 있어요.

   ![프로스펙트 리포트 공유 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047915739/original/oN-5XoXyAvmXBFehllng8kRXZnbvEW3kpg.png?1749407725)
2. 연락처 목록에서 프로스펙트를 찾았다면 아래 방법으로 연락할 수 있어요.
   - 연락처 카드를 클릭하세요.
     연락처 상세 정보를 모두 보고, 이메일이나 SMS를 직접 보낼 수 있어요. 연결된 마케팅 감사 리포트도 볼 수 있어요.
   - 연락처의 점 세 개(⋮) 아이콘을 클릭하세요.
     **빠른 작업**에서 다음을 할 수 있어요.
     - **기회 관리** / **파이프라인**에 추가
     - 예약 일정 잡기

## 프로스펙트 카드에서 연락하기 (잠재고객 발굴 화면)

서브 계정의 **잠재고객 발굴**에서는 프로스펙트 카드의 **액션 아이콘**으로 다음을 할 수 있어요.

- 연락처 상세 정보 보기
- 같은 화면에서 최근 대화(SMS, 이메일, 통화) 열기

에이전시의 **잠재고객 발굴**에서는 이 작업을 하려고 하면, 연결된 서브 계정으로 전환하거나 서브 계정을 새로 만들라는 안내가 나올 수 있어요. 전환한 뒤에 이어서 리드와 소통하세요.

---

## 워크플로우로 후속 연락 자동화하기

후속 연락을 자동으로 하고 싶으세요? 잠재고객 발굴 **워크플로우 트리거**를 쓰면 프로스펙트가 CRM에 추가되는 순간 바로 연락할 수 있어요.

자동화로 이런 일을 할 수 있어요.

- 마케팅 감사 리포트를 담은 환영 이메일이나 SMS를 바로 보내기
- 영업팀을 위한 작업을 만들거나 내부 알림 보내기
- 리드를 파이프라인이나 육성 시퀀스에 추가하기
- 데이터를 보강하거나 태그를 자동으로 지정하기

### [잠재고객 발굴 워크플로우 트리거 전체 가이드 보기 →](../Premium-Prospecting/workflow-trigger-for-new-prospects-in-the-prospecting-tool.md)

한 번만 설정해 두면 새 프로스펙트마다 시스템이 알아서 처리해 줘요.

---

## 프로스펙트가 연락처에 보이지 않아요

일시적인 동기화 지연이나 중단 때문에 드물게 프로스펙트가 연락처에 자동으로 나타나지 않을 수 있어요.

### 이렇게 해 보세요

- 잠재고객 발굴 도구에 나온 정보로 연락처를 직접 만드세요.
- 일관성을 위해 `New Prospect Received` 태그를 지정하세요.
- 필요하면 워크플로우나 파이프라인에 추가하세요.

{% hint style="info" %}
팁: 서브 계정에서 **잠재고객 발굴**이 켜져 있고 활성 상태인지 먼저 확인하세요. 그래야 프로스펙트가 CRM에 제대로 동기화돼요.
{% endhint %}

---

## 활용 팁
`New Prospect Received` 태그를 기준으로, 새 프로스펙트가 추가되면 실행되는 자동 워크플로우를 만들어 보세요.
- **연락처**의 **스마트 리스트**로 프로스펙트를 출처별로 나누고 성과를 확인해 보세요.
- SMS/이메일 연락에 AI 메시지 추천을 바로 넣어 더 빠르게 후속 연락을 할 수 있어요. (출시 예정)
