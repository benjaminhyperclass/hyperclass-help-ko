# 에이전시 대시보드의 SaaS Analytics와 월간 반복 매출(MRR) 보기

이 문서는 **에이전시 대시보드**에서 **SaaS Analytics**(SaaS 분석) 탭을 보는 방법을 설명해요. SaaS 운영 판단에 이 탭을 어떻게 쓰는지, **월간 반복 매출**(MRR)을 어떻게 정의하고 계산하고 보여 주는지도 함께 다뤄요. 에이전시 관리자만 쓸 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## SaaS Analytics란?

```
이용 조건: SaaS Analytics는 $497 Founder 플랜을 쓰는 고객만 이용할 수 있어요.
```

SaaS Analytics는 구독 관련 핵심 지표를 한곳에 모아 보여 줘요. 성장, 유지, 플랜별 성과를 한눈에 파악할 수 있어요. 매출 추이, MRR 구성 요소, 고객 수, 플랜 구성, 코호트를 합산해서 보여 주기 때문에 잘되는 부분과 손봐야 할 부분을 찾기 쉬워요.

**SaaS Analytics** 탭에서는 하이퍼클래스에서 운영하는 SaaS 비즈니스를 깊이 있게 분석해 볼 수 있어요. 매출·고객 지표에 플랜별 인사이트와 코호트를 더해, MRR, 이탈, 업그레이드/다운그레이드, ARPA 등을 한곳에서 확인해요.

## SaaS Analytics 탭의 장점

- 한눈에 보기: MRR, 총 SaaS 매출, 플랜별 MRR, 이탈, 업그레이드, 다운그레이드, 코호트, ARPA를 한 화면에서 확인해요.
- 더 나은 의사 결정: 플랜별 MRR과 ARPA 추이를 보면서 플랜 구성과 가격을 평가해요.
- 성장에 집중: 확장과 재활성화 기회를 빠르게 찾아요.
- 위험 관리: 축소와 이탈을 일찍 발견하고, 맞춤형 고객 유지 조치로 대응해요.
- 운영 효율: 이벤트 기반 계산으로 수작업 대조와 외부 도구 의존이 줄어요.

## SaaS 지표 이해하기

SaaS Analytics의 지표를 보면 반복 매출과 고객 기반이 시간이 지나면서 어떻게 달라지는지 알 수 있어요.

| 지표 | 의미 | 중요한 이유 |
| --- | --- | --- |
| **월간 반복 수익 (MRR)** | 조건을 충족하는 활성 SaaS 구독에서 발생하는 월간 반복 매출이에요. 반복 결제 금액은 월 단위 값으로 환산해요. | 현재 반복 SaaS 매출 규모를 보여 줘요. |
| **신규 MRR** | 고객이 처음으로 유료 SaaS 구독을 시작해서 발생한 반복 매출이에요. | 새로 확보한 고객에게서 얼마나 매출이 늘었는지 알 수 있어요. |
| **확장 MRR** | 기존 고객이 더 비싼 플랜으로 옮기는 등 구독 금액을 높였을 때 늘어나는 반복 매출이에요. | 기존 고객층 안에서 반복 매출이 얼마나 늘고 있는지 보여 줘요. |
| **축소 MRR** | 기존 고객이 구독을 완전히 취소하지 않고 더 낮은 구독 금액으로 옮겼을 때 줄어드는 반복 매출이에요. | 다운그레이드나 구독 금액 감소로 매출이 얼마나 줄었는지 파악할 수 있어요. |
| **이탈 MRR** | 기존 유료 구독이 끝났을 때 잃게 되는 반복 매출이에요. | 고객 이탈로 반복 매출이 얼마나 빠져나가는지 보여 줘요. |
| **재활성화 MRR** | 이전에 비활성이던 SaaS 구독이 다시 활성화되어 되찾은 반복 매출이에요. | 돌아온 고객에게서 회복한 매출을 추적할 수 있어요. |
| **총 SaaS 매출** | 선택한 리포팅 기간 동안 발생한 전체 SaaS 매출이에요. | MRR 같은 반복 매출 지표와 함께 SaaS 매출을 더 넓게 볼 수 있어요. |
| **총 SaaS 고객 수** | 선택한 리포팅 기간에 해당하는 SaaS 고객 수예요. | SaaS 고객 기반의 규모와 성장을 추적할 수 있어요. |
| **ARPA**(계정당 평균 매출) | Average Revenue Per Account의 약자로, SaaS 계정 하나당 발생한 평균 매출이에요. | SaaS 고객의 평균 가치와 그 가치가 시간에 따라 어떻게 달라지는지 알 수 있어요. |
| **순 MRR 이탈률** | 확장으로 늘어난 매출을 반영한 뒤, 기존 고객에게서 잃은 반복 매출을 측정해요. | 기존 고객에게서 얻은 성장이 이탈과 축소로 잃은 매출을 상쇄하는지 판단할 수 있어요. |

## SaaS Analytics 열고 읽기

구독을 하이퍼클래스에서 만들고 관리해야 SaaS Analytics에 나타나요.

1. 에이전시 계정에 로그인하세요.
2. **에이전시 대시보드** > **SaaS**로 이동하세요.

   ![에이전시 대시보드의 SaaS 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078640035/original/6Gv_FWLHbKt4sB8M2oe04dixbGIWNQMSUQ.png?1786998631)
3. **상품** 버튼을 클릭하면 기존 SaaS 상품별로 필터링할 수 있어요.
4. **날짜 범위**에서 원하는 기간을 선택하세요.
5. **새로고침** 버튼을 클릭하면 데이터를 새로 불러와요.
6. **내보내기**를 클릭하면 선택한 사용자에게 CSV 파일을 보내요. 보통 7~10분 정도 걸려요.

   ![내보내기 동작 화면](https://jumpshare.com/share/Y2eMgK44iYdQayKRQIpK+/GIF+Recording+2025-12-16+at+3.35.45+PM.gif)
7. MRR 구성 요소를 확인하세요.

   - **월간 반복 수익 (MRR)**: 월간 반복 매출 합계예요.
   - **신규 MRR**: 처음 유료로 시작한 구독이나 트라이얼에서 유료로 전환된 구독이에요.
   - **확장 MRR**: 업그레이드 또는 늘어난 반복 금액이에요.
   - **축소 MRR**: 다운그레이드 또는 줄어든 반복 금액이에요.
   - **이탈 MRR**: 취소 또는 완전한 중단이에요.
   - **재활성화 MRR**: 이전에 취소되었거나 일시 중지되었던 구독이 다시 유료로 돌아온 경우예요.

   ![MRR 구성 요소 화면](https://jumpshare.com/share/veCiFl2FL6Of5MnWiMyJ+/Screen+Shot+2025-12-16+at+4.03.02+PM.png)
8. 월별 **총 SaaS 고객 수**와 **매출**을 확인하세요.

   ![월별 총 SaaS 고객 수와 매출 화면](https://jumpshare.com/share/wRNIZdZsbwPlNAlxcfM7+/Screen+Shot+2025-12-16+at+4.04.58+PM.png)
9. **MRR by Month and Amount**(월별 MRR 금액)와 **ARPA**(계정당 평균 매출)를 확인하세요.

   ![월별 MRR 금액과 ARPA 화면](https://jumpshare.com/share/08ex4WDeMSOsPVV1tk0h+/Screen+Shot+2025-12-16+at+4.08.48+PM.png)
10. **플랜별 MRR**을 확인하세요. SaaS 플랜 하나하나에서 나오는 월간 반복 매출이에요.

    ![플랜별 MRR 화면](https://jumpshare.com/share/dGKVyDXUI9kPR36OAlhW+/Screen+Shot+2025-12-16+at+4.10.46+PM.png)
11. **Customer Plan Expansion/Contraction**(고객 플랜 확장/축소, 업그레이드/다운그레이드)을 월별 및 **고객 수** 기준으로 확인하세요.

    ![고객 플랜 확장/축소 화면](https://jumpshare.com/share/qHSYluNbhzeNxiu35lD5+/Screen+Shot+2025-12-16+at+4.12.56+PM.png)
12. **순 MRR 이탈률**을 확인하세요. 일정 기간 동안 기존 고객에게서 잃은 월간 반복 매출의 비율이에요. 업그레이드와 확장분을 반영한 값이에요.
13. **플랜별 고객 분포**를 확인하세요. 전체 고객이 구독 플랜별로 어떻게 나뉘는지 보여 줘요.

### 상태 전환과 MRR 유형

| 변경 전 → 변경 후 | 해당 MRR | 비고 |
| --- | --- | --- |
| 트라이얼 진행 중 → 활성(결제) | **신규 MRR** | 트라이얼 이후 첫 유료 결제 월이에요. |
| 없음 → 활성(신규 결제) | **신규 MRR** | 트라이얼 없이 처음 구매한 경우예요. |
| 활성 → 활성(상위 플랜) | **확장 MRR** | 업그레이드 또는 늘어난 반복 금액이에요. |
| 활성 → 활성(하위 플랜) | **축소 MRR** | 다운그레이드 또는 줄어든 반복 금액이에요. |
| 활성 → 취소됨 | **이탈 MRR** | 정책에 따라 기간 종료 시점에 취소되거나 즉시 취소돼요. |
| 취소됨/일시 중지 → 활성 | **재활성화 MRR** | 구독이 다시 유료/활성 상태로 돌아온 경우예요. |

### 구독 상태의 의미

구독 상태에 따라 매출이 집계에 포함되는지, 구성 요소에 어떻게 나타나는지가 달라져요.

| 상태 | 의미 | MRR에 포함되나요? |
| --- | --- | --- |
| **활성** | 정상적으로 유지되는 현재 유료 구독이에요. | 예 |
| **연체됨** | 결제에 실패한 상태예요. 유예 로직이 적용될 수 있어요. | 예, 정책에 따라 취소될 때까지 |
| **트라이얼 진행 중** | 첫 결제 전의 무료 또는 할인 트라이얼이에요. | 아니요(결제되기 전까지) |
| **일시 중지** | 고객 또는 에이전시의 조치로 일시적으로 중단된 상태예요. | 아니요, 다시 활성화되지 않는 한 |
| **취소됨** | 종료된 구독으로, 활성 청구가 없어요. | 아니요(취소가 발생한 시점에 이탈로 집계돼요) |
| **미결제/미완료** | 결제 설정이 끝나지 않았거나 결제되지 않은 상태예요. | 아니요 |

### 하이퍼클래스 MRR에 포함되는 것과 제외되는 것

범위를 분명히 알아 두면 다른 도구와 비교할 때 헷갈리지 않아요.

**포함됨**

- 하이퍼클래스 안에서 만들고 관리하는 SaaS 구독
- 월 단위 값으로 환산한 반복 결제 금액(예: 연간 금액을 12로 나눔)

**제외됨**

- 하이퍼클래스 밖에서 청구되는 구독(예: 하이퍼클래스에서 관리하지 않는 Stripe 직접 결제 항목)
- 일회성 결제, 설정 비용, 사용량 기반의 비반복 항목

### 계산 방식과 통화 처리

일관된 계산 방식과 통화 처리 덕분에 결과를 비교하고 검증할 수 있어요.

- 이벤트 기반 MRR: 구독 생애주기 이벤트(신규, 업그레이드, 다운그레이드, 취소, 재활성화)를 기준으로 MRR 변동을 기록해요. 그래서 신규 MRR, 확장 MRR, 축소 MRR, 이탈 MRR, 재활성화 MRR 값을 추적하고 검증할 수 있어요.
- 정확도를 높인 백엔드: MRR과 이탈 계산은 업데이트된 백엔드에서 처리해서 정확도와 일관성이 더 높아요.
- 통화 환산: 일관성을 위해 값을 USD로 환산해요. 별도 안내가 없는 한 다중 통화는 MRR 합계에 포함되지 않아요.
- 다른 도구와 숫자가 다른 이유: 포함 기준, 시점, 일할 계산, 통화 처리 방식이 도구마다 달라요. 하이퍼클래스는 하이퍼클래스 안에서 관리하는 구독만 집계하고, 이벤트 기반 방식으로 월 단위 값으로 환산해요.

## 자주 묻는 질문

### SaaS Analytics 탭은 누가 이용할 수 있나요?

$497 Founder 플랜을 쓰는 고객이 이용할 수 있어요.

### 트라이얼도 MRR에 포함되나요?

아니요. 구독이 유료/활성 상태가 될 때부터 MRR에 잡혀요.

### 일회성 결제나 설정 비용도 포함되나요?

아니요. 월 단위 값으로 환산한 반복 구독 금액만 포함돼요.

### 업그레이드와 다운그레이드는 어떻게 표시되나요?

업그레이드는 **확장 MRR**로, 다운그레이드는 **축소 MRR**로 나타나요.

### 이탈 MRR로 집계되는 건 무엇인가요?

취소되었거나 완전히 중단된 구독의 월 환산 금액이에요.

### 취소된 계정도 다시 집계될 수 있나요?

네. 유료 구독을 다시 시작하면 그 월 환산 금액이 **재활성화 MRR**로 집계돼요.

### 금액은 어떤 통화로 표시되나요?

USD로 환산해서 표시해요.

### 일시 중지된 구독도 집계되나요?

일시 중지된 동안에는 집계되지 않아요. 유료/활성 상태로 돌아오면 **재활성화 MRR**에 반영돼요.
