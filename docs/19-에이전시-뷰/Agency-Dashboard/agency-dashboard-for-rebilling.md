# 에이전시 대시보드의 재청구 탭으로 매출·비용·수익 확인하기

**에이전시 대시보드**의 **재청구** 탭에서는 에이전시의 리빌링 현황을 한 화면에서 볼 수 있어요. 서브 계정과 서비스 전체의 매출, 공급업체 비용, 전체 재무 성과를 확인할 수 있어요. 서브 계정, 상품 카테고리, 날짜 범위로 데이터를 걸러서 성과와 추이를 분석해 보세요.

에이전시 관리자만 쓸 수 있어요.

## 에이전시 대시보드(재청구)란?

**에이전시 대시보드**의 **재청구** 탭은 대상이 되는 모든 서브 계정의 리빌링 매출, 비용, 수익, 사용량을 한곳에 모아 보여 줘요.

이 대시보드로 할 수 있는 일은 다음과 같아요.

- 리빌링 매출과 비용 추적
- 서비스별 수익 분석
- 사용량 추이 확인
- 대조(정산 확인)를 위한 거래 데이터 내보내기
- 날짜, 상품, 서브 계정별 데이터 필터링

{% hint style="info" %}
대시보드에는 최근 **6개월** 데이터가 표시돼요.

**취소, 환불, 일할 계산 조정** 때문에 매출이 마이너스로 표시될 수 있어요.
{% endhint %}

## 시작하기 전에

대시보드를 쓰기 전에 아래 내용을 알아 두세요.

- 대시보드에는 최근 6개월 데이터가 표시돼요.
- 지표는 리빌링 설정과 확인 가능한 거래 데이터를 기준으로 계산돼요.
- 필터, 환불, 수수료, 거래 시점에 따라 일부 금액이 외부 결제 처리업체나 내보낸 리포트와 다를 수 있어요.

2. 왼쪽 메뉴에서 **에이전시 대시보드**를 클릭하세요.

## 주요 지표와 리포트 위젯

### 요약 카드

- **총 리빌링 매출**
- **Total Cost**(총 비용)
- **총이익**

### 차트

- **매출 분포**
- **비용 분포**
- **이익 분포**

### 추이

- **매출 성장**
- **이익 성장**

## 리빌링된 거래만 포함

**리빌링된 거래만 포함** 토글을 켜면 다음과 같이 표시돼요.

- 결제가 정상적으로 이루어진 거래만 포함돼요.

끄면 다음과 같이 표시돼요.

- 리빌링되지 않은 비용도 나타날 수 있어요.

정확한 수익 분석을 하려면 켜 두세요.

## 재판매 리포트 구성

대시보드는 다음 두 가지로 나뉘어 있어요.

- **사용량형 상품** → 쓴 만큼 내는(종량제) 서비스
- **구독형 상품** → 정기적으로 결제하는 서비스

## 재무 지표 이해하기

- **매출**: 고객에게 청구한 금액
- **비용**: 공급업체가 청구한 금액
- **수익**: 매출에서 비용을 뺀 금액

> 수익 = 매출 – 비용

## 분포 리포트

이 차트는 매출, 비용, 수익이 상품별로 어떻게 나뉘는지 보여 줘요.

다음을 파악하는 데 도움이 돼요.

- 성과가 좋은 서비스
- 비용이 많이 드는 서비스

## 성장 리포트

성장 차트는 시간에 따른 성과를 추적해요.

- **매출 성장** → 수입 추이
- **이익 성장** → 마진 추이

## 예시로 살펴보기

예시 상황은 다음과 같아요.

- 매출: 15,000달러
- 비용: 11,000달러
- 수익: 4,000달러

## 내보낸 데이터와 수익 계산 이해하기

대시보드에는 **집계된 데이터**가 표시되고, 내보낸 파일에는 **거래 단위의 원본 데이터**가 들어 있어요. 이 차이 때문에 내보낸 파일은 해석하기가 더 어려울 수 있어요.

### 내보낸 데이터가 뭉뚱그려져 보이는 이유

- 데이터가 미리 묶여 있지 않아요.
- 수익이 열로 나타나지 않을 수 있어요.
- 고객이나 서비스마다 행이 여러 개일 수 있어요.

### 내보낸 데이터의 주요 필드

- Charge(매출)
- Usage Cost(비용)
- **위치**(서브 계정)
- **서비스**/상품
- 날짜

### 수익 계산하기

1. CSV 파일을 Excel이나 Google Sheets에서 여세요.
2. Charge와 Usage Cost 열을 찾으세요.
3. 새 열을 추가하고 이름을 **Profit**(수익)으로 정하세요.

```
Profit = Charge – Usage Cost
```

### 수익 분석하기

피벗 테이블을 쓰면 편해요.

- 행 → **위치**
- 열 → **서비스**
- 값 → Charge와 Cost

그다음 합계로 수익을 계산하세요.

### 알아 둘 제한 사항

- 수익이 항상 미리 계산되어 있지는 않아요.
- 데이터를 직접 묶어야 할 수 있어요.
- 필터가 다르면 내보낸 합계가 대시보드와 다를 수 있어요.

| **지표** | **권장 정의** |
| --- | --- |
| **매출** | 고객이 사용한 서비스에 대해 고객에게 청구한 금액이에요. |
| **비용** | 고객이 사용한 서비스에 대해 하이퍼클래스에서 실제로 청구하고 에이전시 지갑에서 차감된 금액이에요. |
| **수익** | 매출 − 비용 |

## 자동 충전과 비용·매출의 차이 이해하기

자동 충전(Auto-Recharge) 금액은 에이전시 대시보드에 표시되는 비용이나 매출과 직접 비교하면 안 돼요.

- **비용**은 고객이 사용한 서비스에 대해 하이퍼클래스에서 실제로 청구한 금액이에요. 이 금액은 에이전시 지갑에서 차감돼요.
- **매출**은 고객이 사용한 서비스에 대해 고객에게 청구한 금액이에요.
- **자동 충전**은 잔액을 유지하려고 고객 지갑에 넣는 돈이에요. 지갑 충전금이라서 서비스 사용량을 뜻하지 않아요.

자동 충전으로 들어온 돈이 바로 쓰이지 않을 수도 있어요. 그래서 자동 충전 금액은 에이전시 대시보드의 비용이나 매출과 일치하지 않는 게 정상이에요.

에이전시 대시보드는 선택한 기간에 실제로 사용한 만큼의 청구 금액과 매출을 보여 줘요. 지갑에 충전된 금액은 해당 기간이나 이후 청구 기간에 쓰일 수 있어요.

## 문제 해결

에이전시 재청구 대시보드의 데이터가 예상과 다르면 아래 경우를 확인해 보세요.

### 1. 대시보드 합계가 내보낸 리포트와 달라요

대시보드에는 **집계된 재무 데이터**가 표시되고, 내보낸 리포트에는 **거래 단위 기록**이 들어 있어요.

다음과 같은 경우 차이가 생길 수 있어요.

- 대시보드와 내보내기에서 날짜 범위가 달라요.
- 상품이나 서브 계정 같은 필터가 서로 달라요.
- 대시보드에서는 여러 거래가 하나로 묶여 있지만, 내보낸 파일에서는 각각 별도 행으로 나와요.

합계를 정확히 비교하려면 대시보드와 내보낸 리포트에 같은 필터와 날짜 범위를 적용하세요.

### 2. 대시보드가 Stripe와 달라요

에이전시 재청구 대시보드와 Stripe는 거래의 서로 다른 면을 추적하기 때문에 합계가 다를 수 있어요.

다음과 같은 이유로 차이가 날 수 있어요.

- Stripe 처리 수수료
- Stripe에서 직접 처리한 환불
- 거래와 정산 사이의 시점 차이

비교할 때는 재청구 대시보드가 리빌링 활동을, Stripe가 결제 처리 활동을 보여 준다는 점을 기억하세요.

### 3. 매출이 왜 마이너스인가요?

이미 청구한 거래에 환불, 취소, 일할 계산 조정이 적용되면 매출이 마이너스가 될 수 있어요.

최근 계정 활동과 환불 내역을 살펴보면 대시보드에 반영된 조정 내용을 확인할 수 있어요.

### 4. 내보낸 CSV에 수익 열이 없어요

대시보드는 매출과 비용을 비교해서 **수익**을 계산해요.

내보낸 리포트에는 대시보드에서 계산한 지표가 아니라 거래 단위 데이터가 담겨 있어요. 필요하면 내보낸 매출과 비용 값을 비교해서 수익을 직접 계산하세요.

### 5. 6개월치 데이터만 보여요

에이전시 재청구 대시보드에는 현재 최근 **6개월**의 리빌링 데이터만 표시돼요.

대시보드 리포트의 현재 시스템 제한이에요.

### 6. 수익이 예상보다 낮아 보여요

수익 계산을 살펴보기 전에 아래 사항을 먼저 확인하세요.

- 날짜 범위가 올바르게 선택되어 있어요.
- 알맞은 상품 필터와 서브 계정 필터가 적용되어 있어요.
- **리빌링된 거래만 포함** 설정이 분석하려는 데이터와 맞아요.

이 필터를 바꾸면 대시보드의 매출, 비용, 수익 값이 달라질 수 있어요.

### 7. 거래가 빠져 있어요

예상한 거래가 보이지 않으면 다음을 확인하세요.

- 올바른 필터가 선택되어 있는지 확인하세요.
- 알맞은 날짜 범위를 보고 있는지 확인하세요.
- 해당 거래가 대시보드의 6개월 리포트 기간 안에 있는지 확인하세요.
- 보려는 거래에 맞게 **리빌링된 거래만 포함** 필터를 켜거나 꺼 두었는지 확인하세요.

## 더 도움이 필요하신가요?

위 내용을 모두 확인했는데도 대시보드에 예상한 데이터가 나오지 않으면 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 총이익은 어떻게 계산하나요?

수익 = 매출 – 비용으로 계산해요.

### 대시보드에 매출이 마이너스로 나와요. 왜 그런가요?

환불, 취소, 조정 때문이에요.

### 숫자가 Stripe 지급액과 달라요. 왜 그런가요?

Stripe 수수료, 시점 차이, 외부 환불은 대시보드에 포함되지 않아요.

### 데이터가 왜 6개월치만 보이나요?

시스템 제한 때문이에요.

### **리빌링된 거래만 포함**을 끄면 어떻게 되나요?

리빌링되지 않은 비용이 포함될 수 있어요.

### 자동 충전 금액이 에이전시 대시보드의 비용이나 매출과 왜 다른가요?

자동 충전은 고객 지갑에 돈을 넣는 것이고, 에이전시 대시보드는 실제 서비스 사용량과 그에 따른 비용·매출을 보여 줘요.

자동 충전으로 들어온 돈은 고객 지갑에 남아 있다가 나중에 쓰일 수 있어요. 그래서 같은 날짜 범위라도 자동 충전 합계는 에이전시 대시보드의 비용이나 매출과 일치하지 않는 게 정상이에요.
