# 에이전시 런치패드

에이전시 런치패드는 에이전시 계정을 처음 쓰는 사용자에게 짧은 영상으로 초기 설정 순서를 안내하는 기능이에요. 무엇부터 해야 할지 몰라도 안내를 따라가며 빠르게 시작할 수 있어요.

{% hint style="warning" %}
새 에이전시 런치패드는 2025년 6월 5일 이후에 만든 에이전시 계정 중 97달러, 297달러, 497달러 플랜을 쓰는 계정에서 사용할 수 있어요. 이 날짜 이전에 만든 에이전시 계정에서는 아직 새 에이전시 런치패드를 쓸 수 없어요.
{% endhint %}

## 에이전시 런치패드란?

에이전시 런치패드는 하이퍼클래스를 쓰는 마케팅 에이전시와 SaaS 사업자를 위한 온보딩 도구예요. 새 에이전시 계정에 들어와서 무엇부터 해야 할지 막막할 때, 짧은 튜토리얼 영상과 바로 실행할 수 있는 안내로 꼭 필요한 설정 단계를 알려 줘요. 덕분에 새 관리자도 다음 할 일을 쉽게 알 수 있고, 더 빨리 자리를 잡을 수 있어요.

![에이전시 런치패드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048034191/original/f7lZPRFM5fGXv5TtXt8Urne9HZAGQwQUQA.png?1749581307)

에이전시 런치패드를 쓰면 이런 점이 좋아요.

- 빠른 온보딩: 핵심 설정 작업을 순서대로 안내해 주어서, 익히는 시간과 효과를 보기까지 걸리는 시간이 줄어요.
- 영상 안내: 작업마다 짧은 튜토리얼 영상이 있어서 어려운 단계도 쉽게 따라 할 수 있어요.
- 명확한 다음 단계: 해야 할 일이 구체적으로 나와 있어서, 에이전시가 다음에 뭘 해야 할지 바로 알 수 있어요.

{% hint style="info" %}
Unlimited 플랜을 쓰는 에이전시라면, 지정한 에이전시 서브 계정을 온보딩 기준 서브 계정으로 삼아 표준화할 수 있어요.
{% endhint %}

## 에이전시 런치패드 사용하기

에이전시 런치패드는 사용 조건을 충족하는 에이전시 계정에서 자동으로 켜져요. 시작하기 전에 내 에이전시 계정이 위의 사용 조건에 해당하는지 확인하세요.

1. 하이퍼클래스 에이전시 계정에 로그인하세요.
2. 에이전시 뷰의 메뉴에서 **런치패드**를 찾으세요.
3. 조건에 맞는 계정인데 **런치패드**가 보이지 않으면, 내 사용자 역할에 접근 권한이 있는지 확인하세요.
4. 권한을 확인한 뒤에도 **런치패드**가 보이지 않으면 하이퍼클래스 고객지원에 문의하세요.
5. 에이전시 계정을 2025년 6월 5일 이전에 만들었다면, 그 계정에서는 새 에이전시 런치패드를 아직 쓸 수 없어요.
6. **런치패드**로 이동하세요. 보이지 않으면 순차 적용을 기다리거나 고객지원에 활성화를 요청할 수 있어요.7. 관리자는 역할 권한에 따라 **런치패드**를 숨길 수 있어요. 보이지 않으면 내 역할 권한을 확인하거나 에이전시 관리자에게 문의하세요.
8. 안내된 작업을 살펴보세요. 런치패드에는 핵심 온보딩 작업이 여러 개 나와요. 나에게 가장 필요한 작업부터 시작하면 돼요.
9. 작업을 클릭해서 영상을 보고 직접 해 보세요. 작업을 클릭하면 하이퍼클래스의 해당 화면으로 바로 이동해요. 영상을 보며 할 일을 익힌 다음, 플랫폼에서 그 작업을 직접 해 보세요.
10. **런치패드**로 돌아오세요.
11. 진행 상황을 확인하세요. 작업을 완료할 때마다 런치패드에 진행 상황이 반영돼요.

{% hint style="info" %}
런치패드 튜토리얼은 PiP(Picture-in-Picture, 화면 속 화면)를 지원해요. 같은 탭에서 작업을 하면서 영상을 함께 볼 수 있어요.
{% endhint %}

## 런치패드 접근성

런치패드는 화면 낭독기나 키보드만으로도 안내된 온보딩 작업을 끝낼 수 있도록 개선되었어요.

- 화면 낭독기가 단계 진행 상황을 읽어 주고, 모달 창의 맥락과 폼 입력 검증 결과를 더 분명하게 전달해요.
- 키보드만으로도 버튼과 입력 요소에 예측 가능한 순서로 접근할 수 있어요. 지원되는 곳에서는 Enter/Space 키로 실행하고, Escape 키로 모달을 닫을 수 있어요.
- 대화 상자와 각 단계에서 포커스 표시와 포커스 이동 방식이 더 일관되게 동작해요.
- 접근성 레이블, 안내 음성, 대체 텍스트가 영어, 스페인어, 프랑스어, 독일어를 포함한 13개 언어로 번역되어 있어서 발음과 이해가 더 쉬워요.

## 자주 묻는 질문

### 에이전시 런치패드는 어떤 계정에서 쓸 수 있나요?

97달러, 297달러, 497달러 플랜을 쓰는 에이전시 계정 중 2025년 6월 5일 이후에 만든 계정에서 쓸 수 있어요.

2025년 6월 5일 이전에 만든 에이전시 계정에서는 아직 새 에이전시 런치패드를 쓸 수 없어요.

### 에이전시 런치패드가 보이지 않으면 어떻게 하나요?

계정을 만든 시점에 따라 달라요.

- 2025년 6월 5일 이후에 만든 계정: 내 사용자 역할에 런치패드 접근 권한이 있는지 확인하세요. 조건에 맞는데도 런치패드가 보이지 않으면 하이퍼클래스 고객지원에 문의하세요.
- 2025년 6월 5일 이전에 만든 계정: 이 계정에서는 새 에이전시 런치패드를 아직 쓸 수 없어요. 순차 적용을 기다리거나 고객지원에 활성화를 요청하지 않아도 돼요.

### 런치패드 밖에서도 튜토리얼 영상을 볼 수 있나요?

지금은 영상이 런치패드 안에 들어 있어요. 따로 모아 볼 수 있는 영상 라이브러리는 없어요.

### 서브 계정 온보딩에는 어떤 영향이 있나요?

서브 계정에도 에이전시 런치패드와 비슷한 자체 런치패드가 있어요.

### 일부 사용자나 계정에서만 런치패드를 숨길 수 있나요?

네. 관리자는 역할별로 런치패드 표시 여부를 정할 수 있어요. 해당하는 경우에는 서브 계정별, SaaS 플랜별로도 런치패드를 켜거나 끌 수 있어요.
