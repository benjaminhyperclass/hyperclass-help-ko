# AI로 잠재고객 추천받기

**Prospect by AI**(AI 잠재고객 추천)를 켜면 선택한 업종과 지역에 맞는 잠재고객을 매주 2~3개씩 추천받을 수 있어요. AI가 점수와 데이터 신호를 바탕으로 후보를 골라 주기 때문에, 직접 찾지 않아도 더 좋은 리드를 더 빨리 만날 수 있어요.

기능을 켜고 업종과 지역을 설정하면, AI가 조건에 가장 잘 맞는 업체를 찾아 대시보드에 보여 줘요. 바로 영업을 시작할 수 있는 상태로 전달돼요.

## 사용할 수 있는 곳

1. 모든 에이전시 – **실험실**에서 켤 수 있어요.
2. 모든 서브 계정 – **실험실**에서 켤 수 있어요.

{% hint style="info" %}
**Premium Prospecting**(프리미엄 잠재고객 발굴)을 구독 중이면 AI가 프리미엄 리포트를 만들어 줘요. 구독하지 않았다면 기본적으로 기본 리포트가 만들어져요.
{% endhint %}

## 켜는 방법

### 에이전시에서 켜기

1. 에이전시에서 **실험실**로 이동하세요.
2. **Prospect by AI**를 켜세요.
3. **잠재고객 발굴 > 설정 > AI Report Configuration**(AI 리포트 설정)으로 이동하세요.
4. **AI Recommendations**(AI 추천) 토글을 켜고 **저장**을 누르세요.
5. 무료 요금제(Free Plan)여도 이 AI 기능을 모두 쓸 수 있어요. AI가 만든 잠재고객 2~3개를 받을 수 있어요. 다만 리포트는 기본 리포트로만 만들어지고, 프리미엄 리포트는 만들어지지 않아요.

### 서브 계정에서 켜기

1. 서브 계정에서 **실험실**로 이동하세요.
2. **Prospect by AI**를 켜세요.
3. **마케팅** 탭 > **잠재고객 발굴 > 설정 > AI Report Configuration**으로 이동하세요.
4. 켜세요.

{% hint style="info" %}
서브 계정에서 **잠재고객 발굴**을 쓰려면 먼저 에이전시의 **재판매** 탭에서 해당 기능을 켜 두어야 해요.
{% endhint %}

## 설정하는 방법

1. 잠재고객을 찾고 싶은 업종을 최대 3개까지 선택하세요.
2. 국가, 도시, 지역, 우편번호를 입력하세요. AI가 이 정보를 사용해 알맞은 잠재고객을 찾아요.
3. 기본 리포트는 누구나 쓸 수 있어요. 프리미엄 리포트를 만들려면 먼저 **Premium Prospecting**을 구독해야 해요.

## 추천받은 잠재고객은 어디서 볼 수 있나요?

- 새 잠재고객은 **잠재고객 발굴** 대시보드에 바로 나타나요.
- **AI Recommended**(AI 추천) 카드를 확인하세요. 2~3일마다 새로 바뀌어요.
- 새 추천이 준비되면, **잠재고객 발굴** 대시보드를 여는 순간 알림 배지로 알려 줘요.
