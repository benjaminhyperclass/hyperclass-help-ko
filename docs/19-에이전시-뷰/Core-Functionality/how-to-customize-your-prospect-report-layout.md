# 잠재고객 리포트 레이아웃 사용자 지정

하이퍼클래스에서 잠재고객 리포트에 보여 줄 섹션과 표시 순서를 직접 정할 수 있어요. 영업 전략에 맞게 마케팅 감사 리포트를 구성하고, 중요한 내용은 앞에 두고, 필요 없는 데이터는 뺄 수 있어요. 모든 리포트에 적용되는 기본 레이아웃을 정해도 되고, 리포트 하나만 따로 바꿔도 돼요.

# 잠재고객 리포트 레이아웃 사용자 지정이란?

이 기능을 쓰면 **잠재고객 발굴 도구**(Prospecting tool)로 만든 마케팅 감사 리포트의 구성을 직접 정할 수 있어요. 리포트 섹션을 켜거나 끄고, 발표 흐름에 맞게 순서도 바꿀 수 있어요. 에이전시의 영업 과정과 고객이 중점을 두는 영역에 맞게 리포트를 구성하면서, 필요할 때는 한 건만 따로 조정할 수도 있어요.

---

## 잠재고객 리포트 레이아웃 사용자 지정의 장점

레이아웃을 직접 정하면 제안에 힘이 실리고 고객이 중요하게 보는 내용을 먼저 보여 줄 수 있어요.

- 흐름 만들기: 영업 대화에 맞는 순서로 섹션을 배치해요.
- 핵심 내용 강조: **Overall Score**(종합 점수)나 **SEO Analysis**(SEO 분석) 같은 핵심 인사이트를 맨 위로 올려요.
- 불필요한 섹션 숨기기: 잠재고객과 관련 없는 **Techno Stack**(기술 스택) 같은 섹션은 숨겨요.
- 전체 기본값 설정: 앞으로 만드는 모든 리포트에 같은 레이아웃이 적용되도록 표준 구성을 정해요.
- 리포트별 사용자 지정: 기본 구성은 그대로 두고 한 건만 따로 조정해요.
- 일관된 PDF 출력: 섹션 표시 여부와 순서가 웹 리포트와 내보낸 PDF에 똑같이 적용돼요.

---

## 전체 리포트 레이아웃 (모든 리포트의 기본값)

전체 레이아웃 설정은 앞으로 만드는 잠재고객 리포트의 기본 구성을 정해요. 모든 영업 자료를 같은 형식으로 맞추고 싶은 에이전시에 알맞아요.

### 전체 리포트 레이아웃 설정 화면 열기

전체 레이아웃을 미리 설정해 두면 새 리포트가 자동으로 원하는 구성을 따라요.

1. **마케팅**을 선택해요.
2. **잠재고객 발굴**을 선택해요.
3. **Prospect Accounts**(잠재고객 계정)를 클릭해요.
4. **설정** 탭을 열어요.
5. **Report Settings**(리포트 설정)를 선택해요.

![리포트 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066407975/original/GFKSq3tMM8PsV2ie5q-yhUs8rhk3fa_N0A.png?1772837485)

이 화면에는 **Customize Report Layout**(리포트 레이아웃 사용자 지정) 패널이 나타나요. 여기서 섹션 표시 여부와 순서를 조정해요.

### 섹션 표시 여부 조정하기

영업 방향과 맞지 않는 내용은 숨길 수 있어요.

- 처음에는 모든 섹션이 켜져 있어요.
- 리포트에 넣고 싶지 않은 섹션은 체크를 해제해요.
- 해제한 섹션은 언제든 다시 켤 수 있어요.

예: SEO와 평판 관리 서비스에만 집중하는 에이전시라면 **Techno Stack**을 숨겨 보세요.

### 섹션 순서 바꾸기

섹션 순서를 정하면 잠재고객이 전략적인 흐름으로 인사이트를 볼 수 있어요.

- 각 섹션 옆의 드래그 핸들을 사용해요.
- 보여 주고 싶은 순서대로 섹션을 배치해요.

예: **Overall Score**를 맨 위로 옮기면 성과 지표를 바로 보여 줄 수 있어요.

### 전체 레이아웃 저장하기

저장하면 표준 레이아웃을 쓰는 리포트의 기본 구성으로 적용돼요.

1. **저장**을 클릭해요.
2. 업데이트한 구성이 앞으로 만드는 리포트의 기본 레이아웃이 돼요.

{% hint style="warning" %}
**중요**

- **저장** = 전체 기본 레이아웃
- 이전에 따로 사용자 지정한 리포트는 자동으로 업데이트되지 않아요.
{% endhint %}

이 설정 화면에는 언제든 다시 들어와서 섹션을 포함하거나 제외하고 순서를 바꿀 수 있어요.

## 특정 리포트만 사용자 지정하기

잠재고객 한 곳에만 다른 구성이 필요하다면 전체 설정은 그대로 두고 해당 리포트만 조정할 수 있어요.

### 리포트 안에서 섹션 설정 열기

리포트별로 조정하면 표준 템플릿은 유지한 채 특별한 영업 상황에 유연하게 대응할 수 있어요.

1. 원하는 **Marketing Audit Report**(마케팅 감사 리포트)를 열어요.
2. 오른쪽 위에 있는 **섹션**을 클릭해요.

![리포트 안의 섹션 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066407982/original/opzFhjGd_zYjgQGss0bxplmTwWWVuCzDPA.jpeg?1772837513)

**섹션** 패널에서는 다음 작업을 할 수 있어요.

- 섹션을 체크하거나 체크 해제해서 표시 여부를 정해요.
- 섹션을 드래그해서 순서를 바꿔요.
- **적용**을 클릭해서 변경 사항을 확정해요.

**적용** = 이 리포트에만 변경 사항이 반영돼요.

전체 레이아웃은 바뀌지 않아요.

## 잠재고객 리포트 레이아웃 설정 순서

레이아웃을 제대로 설정해 두면 리포트마다 에이전시의 포지셔닝과 우선순위가 일관되게 담겨요.

### 전체 기본 레이아웃 설정하기

1. **마케팅 > 잠재고객 발굴 > Prospect Accounts**로 이동해요.
2. **설정**을 클릭해요.
3. **Report Settings**를 선택해요.
4. 필요에 따라 섹션을 켜거나 꺼요.
5. 섹션을 원하는 순서로 드래그해요.
6. **저장**을 클릭해요.

### 개별 리포트 사용자 지정하기

1. 해당 **Marketing Audit Report**를 열어요.
2. **섹션**을 클릭해요.
3. 섹션 순서를 바꾸거나 숨겨요.
4. **적용**을 클릭해요.

### 변경 사항 확인하기

- 변경 사항이 바로 보이지 않으면 리포트 안에서 **새로고침**을 클릭해요.
- 리포트 생성 시각을 확인해요.
- **Export PDF**(PDF 내보내기)로 리포트를 내보내서 구성이 똑같이 유지되는지 확인해요.
- 감사 기능이 크게 개선된 뒤에는 기존 리포트를 새로고침해서 최신 점수, 감지, 분석 업데이트를 불러와요.

{% hint style="info" %}
**참고**

일부 리포트 개선 사항은 백엔드 처리를 통해 적용돼요. 기존 리포트는 직접 새로고침해야 업데이트된 결과가 나타날 수 있어요.
{% endhint %}

섹션 순서와 표시 여부는 다음에 모두 적용돼요.

- 웹 리포트 화면
- 공유한 리포트 링크
- 내보낸 PDF

## 자주 묻는 질문

### 전체 레이아웃을 바꾸면 모든 리포트에 적용되나요?

전체 레이아웃 변경은 앞으로 만드는 리포트 중 표준 구성을 쓰는 리포트의 기본 레이아웃이 돼요.

### 리포트 한 건에서만 섹션을 숨기려면 어떻게 하나요?

해당 리포트 안의 **섹션** 패널에서 숨길 섹션의 체크를 해제하고 **적용**을 클릭하세요.

### 전체 레이아웃을 바꾸면 이전에 따로 사용자 지정한 리포트도 업데이트되나요?

아니요. 개별로 사용자 지정한 리포트는 자기만의 레이아웃 설정을 그대로 유지해요.

### 섹션 순서가 내보낸 PDF에도 적용되나요?

네. 섹션 순서와 표시 여부는 웹 리포트와 내보낸 PDF에 모두 적용돼요.

### 실수로 섹션을 제거했어요. 어떻게 하나요?

전체 레이아웃 설정 화면이나 해당 리포트의 **섹션** 패널로 돌아가서 그 섹션을 다시 켜세요.

### 레이아웃 변경 사항이 나타나지 않아요

전체 설정이라면 **저장**, 개별 리포트라면 **적용**을 클릭했는지 확인한 뒤 **새로고침**을 클릭하세요. 그래도 해결되지 않으면 브라우저 캐시를 삭제해 보세요.
