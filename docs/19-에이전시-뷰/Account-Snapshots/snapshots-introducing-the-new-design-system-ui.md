# 스냅샷의 새 디자인 시스템(UI) 소개

스냅샷 화면이 새 디자인 시스템(UI)으로 바뀌었어요. 화면 이동이 빨라지고 스타일이 통일됐으며, 데이터를 거르는 도구가 더해져 에이전시의 모든 스냅샷을 더 쉽게 만들고, 새로고침하고, 배포하고, 확인할 수 있어요.

## 스냅샷 새 디자인 시스템(UI)이란?

새 디자인 시스템은 하이퍼클래스의 차세대 화면 구성 방식이에요. 이제 모든 스냅샷 화면에 적용돼요. 새 UI로 옮기면서 스냅샷 화면의 모양과 사용감이 통일되고 성능이 좋아졌어요. 필터, 정렬, 검색 도구도 새로 생겨서 스냅샷이 많아도 원하는 것을 더 빨리 찾고 관리할 수 있어요.

## 새 디자인 시스템의 주요 장점

- **일관된 사용 경험**: 모든 스냅샷 탭에서 스타일, 아이콘, 화면 이동 방식이 같아요.
- **빠른 탐색**: 즉시 검색, 열 정렬, 여러 항목을 고르는 필터로 스냅샷을 찾는 시간이 줄어요.
- **믿을 수 있는 데이터**: 캘린더 필터로 정해진 기간에 만들었거나 가져왔거나 공유한 스냅샷을 바로 볼 수 있어 점검이 쉬워요.
- **매끄러운 작업**: **스냅샷 만들기**, **새로고침**, **Push**(배포), **기록**, **설정**이 한곳에 묶여 있어 클릭 수가 줄고 헷갈릴 일이 적어요.
- **앞으로를 위한 기반**: 새 디자인 시스템은 계속 확대 적용될 예정이에요. 여기서 익혀 두면 다른 화면이 바뀌어도 쉽게 적응할 수 있어요.

## 새 UI의 핵심 스냅샷 작업

주요 작업 버튼은 위치가 고정된 하나의 작업 표시줄에 모여 있어서 스크롤할 일이 줄어요.

- **스냅샷 만들기**: 원하는 서브 계정에서 새 템플릿을 만들어요.

  ![스냅샷 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055722087/original/6FBdCwZIEup75UVZd8P3Rlqt36cZtNVD0A.png?1760102770)
- **새로고침**: 기존 스냅샷을 원본의 최신 자산과 설정으로 업데이트해요.

  ![새로고침 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055721889/original/28XOuFX6326L52WPJzSRI2dELhUfFKVQEw.png?1760102694)
- **Push**(배포): 스냅샷 전체 또는 선택한 자산만 서브 계정 하나 또는 여러 곳에 배포해요.

  ![Push 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055719859/original/4PxBH4Yp9OEvrKGfsiLadz6MJacqXsjeBg.png?1760102128)
- **기록**: 누가 스냅샷을 만들고, 새로고침하고, 배포했는지 전체 이력을 열어 봐요.

  ![기록 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055719904/original/ETVI_dpRg525t-UHEI153dk2MScL_hin8w.png?1760102155)
- **설정**: 스냅샷 이름을 바꾸거나, 포함된 자산을 편집하거나, 배포 대상을 조정해요.

## 고급 필터, 정렬, 검색

스냅샷 목록 위에 데이터 도구가 있어요.

- **검색창**: 스냅샷 이름이나 ID의 일부만 입력해도 바로 목록이 좁혀져요.

  ![스냅샷 검색창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055720743/original/2liRXXg4gdEEuJkYQLi6Lk8zYUUJ2-fyhg.png?1760102493)
- **열 정렬**: **Name**(이름), **Size**(크기), **최근 수정** 같은 열 머리글을 클릭하면 오름차순 또는 내림차순으로 정렬돼요.

  ![열 머리글 정렬](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055720339/original/o8yrpOFK5FhrsstRyaQnbsNXFSEocyDrbg.png?1760102350)
- **캘린더 선택기**: 날짜 범위를 절대 날짜나 상대 기간(**Today**(오늘), **최근 30일**, **사용자 지정**)으로 골라서 가져오기, 공유, 배포한 스냅샷을 찾아요.

  ![캘린더 날짜 선택기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055720051/original/mGUpfaNLsfJOGZ2pnD77SRhMLHfNLjDV2A.png?1760102210)

이 도구들은 함께 쓸 수 있어요. 다시 돌아오면 하이퍼클래스가 마지막에 사용한 필터 조합을 기억해요.

## 통일된 디자인 시스템 요소

레이블, 아이콘, 버튼, 여백이 새로 바뀐 다른 하이퍼클래스 화면(예: **인보이스**, **Activity Section**(활동 섹션))과 같아졌어요. 그래서 화면 이동이 자연스럽고, 새 직원이 배우는 시간도 줄어들어요.

![통일된 디자인 시스템 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055719605/original/QaQpeG7DpkcN2AmsOViip9i2vDKnbo52NQ.png?1760102093)

## 자주 묻는 질문

### 새 UI에서 스냅샷에 포함되는 내용이 달라지나요?
아니요. 포함되는 자산의 범위는 그대로예요. 화면과 데이터 도구만 바뀌었어요.

### 이전 UI로 되돌릴 수 있나요?
이전 UI는 곧 지원이 종료될 예정이에요. 전환 기간에는 **Legacy View**(이전 보기) 토글이 보일 수도 있지만, 지금 새 UI로 작업 방식을 옮기시길 권장해요.

### 세분화해 둔 기존 권한이 그대로 적용되나요?
네. **설정 > 팀**에서 정한 사용자 권한이 **스냅샷 만들기**, **Push**, **새로고침** 등에 계속 적용돼요.

### 내가 설정한 필터가 다른 사용자에게도 영향을 주나요?
필터는 사용자별, 세션별로 적용돼요. 팀원의 목록 화면은 바뀌지 않아요.

### 키보드 단축키가 있나요?
⌘/Ctrl + F를 누르면 검색창으로 이동해요. 목록에 포커스가 있을 때는 ↑/↓ 키로 목록의 행을 이동할 수 있어요.

### 한 번에 몇 개의 스냅샷까지 볼 수 있나요?
목록이 가상화되어 있어서 수천 개가 있어도 성능이 부드럽게 유지돼요. 표시 개수에 따로 제한은 없어요.

### 날짜 필터는 내 현지 시간대를 따르나요?
네. 캘린더 필터는 내 프로필에 설정된 시간대를 따라요.
