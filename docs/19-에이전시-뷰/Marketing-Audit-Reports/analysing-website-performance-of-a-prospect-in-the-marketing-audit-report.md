# 마케팅 감사 리포트에서 잠재고객의 웹사이트 성능 분석하기

잠재고객 발굴 도구의 마케팅 감사 리포트에는 잠재고객 웹사이트의 성능을 보여 주는 **Website Performance**(웹사이트 성능) 섹션이 있어요. 에이전시는 이 섹션으로 사용자 경험, 검색엔진 노출, 경쟁사 비교, 전환율을 점검하고 고객에게 개선 방향을 안내할 수 있어요.

## 웹사이트 성능 리포트 확인하기

1. **잠재고객 발굴** 탭으로 이동한 뒤 **Add a Prospect**(잠재고객 추가)를 클릭하세요.
2. 주변 잠재고객을 검색하세요.
3. **Save Prospect**(잠재고객 저장)를 클릭하세요. 그러면 해당 잠재고객의 마케팅 감사 리포트가 만들어져요.

![잠재고객 발굴 탭에서 잠재고객을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155021781932/original/zfC4Q6cCGHlZK4UALXSQJc8WS6e7lSk4Tw.png?1709120302)

4. 마케팅 감사 리포트에서 아래로 스크롤해 **Website Performance** 섹션을 확인하세요.

![마케팅 감사 리포트의 웹사이트 성능 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155021782839/original/boPFnYSB4ovVhxyN6GOxkq0z1sCM_SlOOA.png?1709120841)![웹사이트 성능 섹션의 세부 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155021782958/original/BNdybOqBu1YtcuMTg7IV3r3lWQVdXaUJQw.png?1709120872)

## 웹사이트 성능 리포트의 구성 요소

1. **Page Speed**(페이지 속도): 잠재고객 웹사이트의 페이지 속도를 데스크톱과 모바일 기기별로 자세히 볼 수 있어요. 방문자가 끊김 없이 사이트를 쓰려면 로딩 시간을 파악하는 것이 중요해요.
2. **Critical Information Presence**(핵심 정보 확인): 페이지 속도, 상호작용성, 전체 SEO 점수, 큰 콘텐츠 존재 여부 같은 핵심 정보를 확인할 수 있어요. 잠재고객의 웹사이트가 성능과 노출에 필요한 기본 기준을 갖췄는지 살펴보세요.
3. **Comprehensive Page Health Report**(종합 페이지 상태 리포트): 잠재고객 웹사이트의 데스크톱 버전과 모바일 버전을 모두 다룬 상세 페이지 상태 리포트를 볼 수 있어요. 에이전시는 이를 바탕으로 잠재고객이 문제점이나 개선할 부분을 찾도록 도울 수 있어요.

## 리포트에 웹사이트 평가가 있으면 좋은 점

잠재고객 발굴 도구의 마케팅 감사 리포트에서 **Website Performance** 섹션이 중요한 이유는 다음과 같아요.

- 사용자 경험 최적화: 페이지 속도와 전반적인 웹사이트 성능은 사용자 경험에 직접 영향을 줘요. 로딩이 느린 웹사이트나 페이지는 방문자를 답답하게 만들어 이탈률을 높일 수 있어요. 성능 지표를 분석하면 사용자 경험과 참여도를 높일 부분을 찾을 수 있어요.
- 검색엔진 노출: Google 같은 검색엔진은 웹사이트 성능을 순위 요소로 봐요. 로딩 시간이 짧고 성능이 좋은 웹사이트는 검색 결과 페이지(SERP)에서 유리한 경우가 많아요. 그래서 성능을 개선하면 검색엔진 노출에 긍정적인 영향을 주고, 웹사이트로 들어오는 자연 유입 트래픽도 늘릴 수 있어요.
- 경쟁 분석: 잠재고객의 웹사이트 성능을 경쟁사와 비교해 보는 것은 전략을 세울 때 중요해요. **Website Performance** 섹션에서는 잠재고객의 웹사이트를 업계 기준 및 경쟁사와 비교해 강점, 약점, 개선 기회를 파악할 수 있어요.
- 전환율 최적화: 웹사이트 성능은 전환율에 직접 영향을 줘요. 로딩이 빠른 웹사이트일수록 전환율이 높은 경향이 있다는 연구 결과도 있어요. 성능 지표를 분석하면 전환을 방해하는 병목이나 문제를 찾고, 전환율을 높일 방안을 실행할 수 있어요.
- 고객 교육 및 컨설팅: **Website Performance** 섹션은 웹사이트 성능의 중요성과 그것이 사업 목표에 미치는 영향을 잠재고객에게 설명할 때 쓸 수 있는 자료를 제공해요. 에이전시는 이 내용을 활용해 맞춤 제안과 컨설팅 서비스를 제공하고, 디지털 마케팅과 웹사이트 최적화 분야에서 믿을 수 있는 조언자로 자리 잡을 수 있어요.
