# 감사 리포트 섹션 선택하고 순서 바꾸기

리포트에 어떤 내용을 넣을지, 어떤 순서로 보여 줄지 직접 정할 수 있어요. 이 문서에서는 리포트에 넣을 섹션을 고르고 순서를 바꾸는 방법을 안내해요.

{% hint style="info" %}
섹션 순서를 바꾸면 외부 리포트와 PDF 모두에 같은 순서로 반영돼요.
{% endhint %}

## 1. 리포트 사용자 지정 화면 열기

1. 리포트를 만들거나 관리하는 대시보드로 이동하세요.
2. 사용자 지정할 리포트를 선택하세요.
3. 리포트 레이아웃을 편집하려면 **섹션** 버튼을 클릭하세요.

## 2. 리포트에 넣을 섹션 고르기

1. 리포트에 넣을 섹션 옆의 체크박스를 선택하세요.
2. 필요에 따라 섹션을 많이 고르거나 적게 골라도 돼요.

![섹션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035142278/original/ect_vUzfPw9TUPUPeiPUrQs4tfekrxWmiw.png?1729574592)

## 3. 섹션 순서 바꾸기

1. 섹션을 고른 뒤, 원하는 레이아웃에 맞게 순서를 바꿀 수 있어요.
2. 섹션 이름 위에 마우스를 올리면 옆에 드래그 핸들이 나타나요. 이 핸들을 클릭한 채로 누르고 있으세요.
3. 섹션을 위나 아래로 끌어서 순서를 바꾸세요.
4. 원하는 위치에 오면 마우스 버튼을 놓으세요.

## 4. 저장하고 리포트 생성하기

1. 설정이 마음에 들면 **적용**을 클릭하세요. 선택한 섹션과 순서가 확정돼요.
2. 이제 평소처럼 리포트를 생성하세요. 방금 만든 레이아웃대로 리포트가 만들어져요.

![적용 후 리포트 생성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035142340/original/TePCxG70pK5LUTEaOA647FhO3EgvGCeC3A.png?1729574684)

## 리포트를 사용자 지정할 때 참고할 팁

- 중요한 정보를 먼저 보여 주세요. 가장 관련 있거나 영향이 큰 섹션을 맨 위에 두면 눈에 잘 띄어요.
- 자연스러운 흐름으로 구성하세요. 전체 지표를 먼저 보여 주고, 이어서 더 자세한 분석을 배치하면 하나의 이야기처럼 읽혀요.
- 리포트를 간결하게 유지하세요. 도움이 되는 섹션만 넣으면 정보가 너무 많아 읽는 사람이 부담스러워하지 않아요.

이 순서대로 따라 하면 필요에 맞게 리포트를 구성할 수 있고, 내용이 충실하면서 읽기 좋은 리포트를 만들 수 있어요.
