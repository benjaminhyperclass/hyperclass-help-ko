# 워크플로우 액션 — Generate Marketing Audit Report(마케팅 감사 리포트 생성)

새 연락처나 정보가 바뀐 연락처의 마케팅 감사 리포트를 자동으로 만드는 워크플로우 액션이에요. 사업자명, 웹사이트 같은 연락처 정보로 감사 리포트를 만들기 때문에, 팀이 리드를 더 빨리 가려내고 맞춤형 영업을 시작할 수 있어요. 만들어진 리포트는 검토하고 공유하고 영업 대화에 활용할 수 있어요.

## Generate Marketing Audit Report 액션이란?

**Generate Marketing Audit Report**(마케팅 감사 리포트 생성) 액션을 쓰면 서브 계정에 새 리드(연락처)가 들어올 때마다 마케팅 감사 리포트를 자동으로 만들 수 있어요. 새 연락처의 온라인 현황을 바로 파악하고 후속 연락을 맞춤형으로 준비할 수 있어요. 직접 작업할 필요가 없어요.

이 액션을 쓰려면 서브 계정에서 **잠재고객 발굴**이 켜져 있고 구독 중이어야 해요.

{% hint style="info" %}
이전에는 **잠재고객 발굴**에서 만든 리드만 마케팅 감사 리포트를 만들 수 있었어요. 이제 이 워크플로우 액션으로 Facebook Ads, 퍼널, 폼, 가져오기, 연동, 웨비나 등 어떤 경로로 들어온 연락처든 감사 리포트를 만들 수 있어요.
{% endhint %}

## 액션 이름

Generate Marketing Audit Report

## 액션 설명

이 액션은 연락처 프로필에 있는 다음과 같은 정보로 마케팅 감사 리포트를 자동으로 만들어요.

- **사업자명**
- **Website URL**(웹사이트 URL)
- **Address**(주소)
- **Email**(이메일)
- **전화번호**

연락처 정보가 충실할수록 감사 리포트도 더 정확하고 자세해져요.

### 마케팅 감사 리포트란?

마케팅 감사 리포트는 비즈니스의 지역 마케팅 현황을 자동으로 정리해 보여 주는 리포트예요. 비즈니스 리스팅 정확도, 웹사이트 성능, Google Business Profile, SEO 순위, 온라인 평판 같은 핵심 영역을 분석해요.

이 결과로 온라인에서 부족한 부분과 성장을 가로막는 요인을 파악하고, 다음에 할 일을 정할 수 있어요. 성과 개선, 신규 고객 온보딩, 앞으로의 마케팅 계획에 활용하기 좋아요.

## 사전 준비

1. 서브 계정에 **잠재고객 발굴** 구독이 활성화되어 있어야 해요.
2. 계정에서 **잠재고객 발굴**이 켜져 있는지 확인하세요.
3. 연락처가 생기는 시점에 시작되는 워크플로우에 이 액션을 추가하세요. 추천 트리거는 **Contact Created**(연락처 생성됨)예요.

## 작동 방식

1. 연락처가 워크플로우에 들어와요.
2. **Generate Marketing Audit Report** 액션이 자동으로 실행돼요.
3. **잠재고객 발굴**이 사업자명, 웹사이트, 이메일 등 연락처의 비즈니스 정보로 해당 비즈니스를 찾아낸 다음, 자세한 감사를 실행해요.
4. 만들어진 리포트는 **잠재고객 발굴** 안의 해당 잠재고객에 연결돼요.

## 중복 방지

**잠재고객 발굴**에서 처음 만든 연락처는 다음 두 가지를 자동으로 막아요.

- 마케팅 감사 리포트 중복 생성
- 같은 감사 워크플로우의 반복 실행

덕분에 데이터가 깔끔하게 유지되고, **잠재고객 발굴**에서 이미 처리한 리드에 불필요한 감사가 만들어지지 않아요.

## 만들어진 감사 리포트 확인하기

워크플로우가 실행된 뒤에 아래 순서로 확인하세요.

1. **마케팅 > 잠재고객 발굴**로 이동하세요.
2. **잠재고객 발굴** 탭을 여세요.
3. 확인하려는 잠재고객(연락처)을 검색하세요.
4. 해당 연락처에 새로 만들어진 마케팅 감사 리포트가 보여요.

{% hint style="info" %}
**잠재고객 발굴** 탭이 보이지 않으면 계정에서 잠재고객 발굴이 켜져 있지 않은 것일 수 있어요.
{% endhint %}

## 예시

사용 사례: 새 리드를 모두 자동으로 감사하기

Facebook Ads, 퍼널, 이벤트, 추천, 가져오기 등 어디서 들어왔든 새 연락처를 모두 감사하고 싶은 경우예요.

1. 트리거를 **Contact Created**(연락처 생성됨)로 해서 워크플로우를 만드세요.
2. **Generate Marketing Audit Report** 액션을 추가하세요.
3. 워크플로우를 게시하세요.

이제 CRM에 새 연락처가 추가될 때마다 다음이 자동으로 이루어져요.

- 비즈니스 정보 분석
- 맞춤 마케팅 감사 리포트 생성
- 검토할 수 있도록 **잠재고객 발굴**에 표시

팀이 바로 인사이트를 얻고, 각 리드의 현재 마케팅 성과에 맞춰 영업을 준비할 수 있어요.

## 자주 묻는 질문

### 마케팅 감사 리포트를 PDF로 내보내고 사용자 지정할 수 있나요?
하이퍼클래스는 **잠재고객 발굴**에서 PDF 내보내기 사용자 지정을 지원해요. 그래서 감사 PDF를 브랜드에 맞게 꾸밀 수 있어요.

### 다른 언어로 리포트를 잠재고객에게 공유할 수 있나요?
네. 다국어 잠재고객 리포트 공유 기능으로 마케팅 감사 리포트를 현지 언어로 바꿀 수 있어요. 공유 링크를 만들 때나 이메일·SMS로 보낼 때 언어를 고르면 돼요.
