# 실험실 기능 전체 안내

**실험실**(Labs)은 새로 나오는 기능을 정식 출시 전에 먼저 써 볼 수 있는 곳이에요. 변경 사항을 미리 테스트하고, 의견을 보내고, 팀이 준비할 수 있어요. 이 문서에서는 실험실을 찾는 위치, 토글 사용법, 켤 수 있는 사람, 서브 계정 지정 방법, 피드백 제출 방법을 안내해요.

# 실험실이란?

실험실은 하이퍼클래스의 조기 액세스 프로그램이에요. 선택한 기능을 모든 사용자에게 공개하기 전에 먼저 켜서 써 볼 수 있어요. 개발이 계속되면서 실험실 기능은 바뀔 수 있고, 보내 주신 의견은 최종 동작과 출시 일정에 반영돼요. 실험실에는 에이전시 계정에 적용되는 항목과 서브 계정에 적용되는 항목이 함께 있어요.

테스트 환경에서 기능을 켜 보고, 영향을 확인하고, 의견을 보내면 정식 적용 때 생길 위험을 줄일 수 있어요. 제품 방향에도 의견을 낼 수 있고요.

## 실험실의 주요 장점

실험실을 쓰면 새 기능을 더 빨리 도입하면서도 운영 중인 서브 계정은 안전하게 지킬 수 있어요.

- **조기 액세스:** 정식 출시 전에 새 기능을 써 보고 업무 방식과 교육을 미리 계획할 수 있어요.
- **선택적 적용:** 선택한 서브 계정에만 켜서 통제된 시범 운영을 할 수 있어요.
- **빠른 피드백:** 스크린샷이나 영상과 함께 의견을 바로 보내 제품 개선에 반영할 수 있어요.
- **변경 대비:** 정식 출시(General Availability) 전에 업무 절차(SOP)와 자료를 미리 고쳐 혼란을 줄일 수 있어요.
- **위험 감소:** 모든 고객사에 켜기 전에 동작, 성능, 호환성을 확인할 수 있어요.

| **기능을 받을 서브 계정을 정할 수 있나요?** | 네. 지원되는 서브 계정 실험실 기능은 에이전시 소유자나 관리자가 **관리**로 선택한 서브 계정의 공개 범위나 활성화를 조정할 수 있어요. | 아니요. 여기서 바꾼 내용은 지금 보고 있는 서브 계정에만 적용돼요. |
| **언제 쓰면 좋나요?** | 한곳에서 통제하거나, 선택한 서브 계정 여러 곳에서 기능을 테스트하거나, 넓은 범위로 적용할 때 좋아요. | 다른 서브 계정에 영향 없이 특정 서브 계정 하나에서 기능을 테스트하거나 켤 때 좋아요. |

## 실험실 기능 카드 읽는 법

실험실 기능은 모두 '카드' 형태로 보여요. 카드의 각 요소를 알면 자신 있게 기능을 켜고, 관계자에게 일정도 설명할 수 있어요.

카드에는 보통 다음 내용이 있어요.

1. **제목:** 기능 이름이에요.
2. **설명:** 기능이 제공하는 변경 사항이나 기능이에요.
3. **Live in X Days**(출시까지 X일): 정식 출시까지 남은 예상 일수예요. 바뀔 수 있어요.
4. **토글 켜짐/끄기:** 현재 위치에서 기능을 켜거나 꺼요.
5. **피드백 제출:** 의견, 문제, 요청을 제품 팀에 바로 보내요.
6. **Change Log URL**(변경 로그 URL): 출시 상세 내용을 볼 수 있어요.
7. **Support Doc URL**(지원 문서 URL): 기능에 대한 도움말과 문서예요.
8. **Media URLs**(미디어 URL): 이미지, 데모, 설명 영상이에요.

{% hint style="info" %}
실험실 기능은 아직 테스트와 개선이 진행 중이라서 기능, 디자인, 제공 여부, 출시 일정이 바뀔 수 있어요. 기능 카드에 **Live in X Days**가 보이면 정식 출시까지 남은 예상 기간이에요. 이 일정은 예상치이고 바뀔 수 있어요.
{% endhint %}

## 공개 범위와 활성화 설정 (서브 계정 실험실 기능)

실험실은 서로 다른 두 가지 설정으로 제어해요.

1. **공개 범위:** 실험실 기능이 **서브 계정 보기 > 설정 > 실험실**에 보이는지 정해요.
2. **Enabled**(활성화됨): 그 서브 계정에서 기능이 켜져 있는지 정해요.

{% hint style="warning" %}
Unlimited 요금제와 Pro 요금제에서는 공개 범위와 활성화의 기본값을 정할 수 있고, 서브 계정별로 공개 범위와 활성화를 관리할 수 있어요. 스타터 요금제에서는 실험실 기능이 기본적으로 보이고, 공개 범위나 활성화 설정은 나타나지 않아요.
{% endhint %}

![공개 범위와 활성화 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064178284/original/_lyXouZNCWkLXYkZks0wq-x1eYYU5ZnzTg.png?1770209216)

기능이 보이지만 켜져 있지 않을 수도 있어요. 기능을 실제로 켜지 않고 먼저 소개만 하고 싶을 때 쓸 수 있어요.

### 기본 공개 범위와 개별 변경 (에이전시 보기)

해당 요금제에서는 에이전시 관리자가 다음 작업을 할 수 있어요.

- 새 실험실 기능의 기본 공개 범위를 **표시** 또는 **숨김**으로 정해요.
- 필요하면 서브 계정별로 공개 범위를 따로 바꿔요.

![기본 공개 범위 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064178404/original/wqn04XHF8YfLS1E0hD2MYYxjlvgCmPlOkw.png?1770209281)

## 실험실 사용하기

올바른 작업 공간에서 실험실을 쓰는 게 중요해요. 에이전시 보기에서는 에이전시 수준 기능과 서브 계정 기능을 지정하는 도구가 보이고, 서브 계정 보기에서는 해당 서브 계정에서 직접 켤 수 있는 기능이 보여요.

### 1. 에이전시 전용 기능 켜기 (에이전시 보기)

1. 에이전시 계정에 로그인하세요.
2. **설정 > 실험실**로 이동한 다음 **에이전시** 탭을 선택하세요.
3. 기능 카드를 찾아 **설명**과 **Release Timeline**(출시 일정)을 확인하세요.
4. 토글을 **켜짐**으로 바꾸세요.

![에이전시 전용 기능을 켜는 화면](https://jumpshare.com/share/txIBztOpI4GLQo1U1lUA+/GIF+Recording+2025-08-12+at+12.03.52+AM.gif)

### 2. 에이전시 지정으로 서브 계정 기능 켜기

{% hint style="info" %}
일부 서브 계정 기능은 에이전시가 먼저 허용해야 쓸 수 있어요. 에이전시 관리자와 소유자는 **관리**로 조기 액세스를 받을 서브 계정을 고를 수 있어요.
{% endhint %}

1. 에이전시 계정에 로그인하세요.
2. **설정 > 실험실**로 이동한 다음 **서브 계정** 탭을 선택하세요.
3. 기능 카드를 찾아 **설명**과 **Release Timeline**(출시 일정)을 확인하세요.
4. **관리**를 클릭하고, **공개 범위**나 **Enabled**(활성화됨)를 줄 서브 계정을 선택하세요.
5. **저장**을 클릭하세요.
6. 지정한 서브 계정으로 전환해서 해당 화면을 새로고침한 뒤, 기능이 보이는지 또는 **Enabled** 상태인지 확인하세요.

![서브 계정 기능을 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064179682/original/ypYnjb8wnXAoH9HBaTUlEcCaU15WlA0ACw.gif?1770209920)

### 3. 서브 계정 기능 직접 켜기

일부 서브 계정 기능은 에이전시가 지정하지 않아도 서브 계정 안에서 바로 켤 수 있어요.

1. 대상 서브 계정에서 **설정 > 실험실**을 여세요.
2. 기능 카드를 찾아 토글을 **켜짐**으로 바꾸세요.
3. 변경 사항을 보려면 관련 모듈(빌더, CRM 등)을 새로고침하거나 다시 여세요.

![서브 계정에서 기능을 직접 켜는 화면](https://jumpshare.com/share/5KUEORHRlnYiDNfFANZw+/GIF+Recording+2025-08-12+at+12.16.19+AM.gif)

## 피드백 제출하기

실험실에서 보낸 피드백은 제품 팀에 바로 전달돼요. 수정과 개선의 우선순위를 정하는 데 도움이 되고, 구체적인 피드백일수록 모두에게 더 좋은 결과로 이어져요.

피드백을 제출하려면 다음 순서로 진행하세요.

1. 에이전시 또는 서브 계정에서 **설정**을 클릭하세요.

   ![설정 메뉴 화면](https://jumpshare.com/share/MiaKBmexb4ZQb4Rlwcqz+/Screen+Shot+2025-08-12+at+12.28.49+AM.png)
2. **실험실**을 클릭하세요.
3. 해당 기능 카드에서 **피드백 제출**을 클릭하세요.

   ![기능 카드의 피드백 제출 버튼](https://jumpshare.com/share/DXKBF80DUqjfywcUkzFE+/Screen+Shot+2025-08-12+at+12.30.48+AM.png)
4. **제목**과 알아보기 쉬운 **Message**(메시지)를 입력하세요.
5. 필요하면 사용 사례나 문제를 보여 주는 스크린샷이나 영상을 올리세요.
6. **제출**을 클릭하세요.

![피드백 제출 화면](https://jumpshare.com/share/nK7g4skJbDR3xcsDLQco+/Screen+Shot+2025-08-12+at+12.36.20+AM.png)

## 실험실 변경 내역 확인하기

실험실 기능 플래그를 바꾼 내역은 이제 **감사 로그**에 기록돼요. 회사 수준, 위치 수준에서 바꾼 내용과 고객지원 포털(Support Portal) 도구로 바꾼 내용이 모두 포함돼요.

실험실 기능이 언제 바뀌었는지, 누가 바꿨는지, 고객지원 포털에서 바꾼 것인지 확인하려면 **감사 로그**를 사용하세요.

## 자주 묻는 질문

### 실험실은 누가 쓸 수 있나요?
모든 에이전시 관리자와 서브 계정 관리자, 그리고 **View & Manage Settings**(설정 보기 및 관리) 권한이 있는 사용자가 쓸 수 있어요.

### 실험실이 안 보여요. 무엇을 확인해야 하나요?
에이전시 보기인지 서브 계정 보기인지 현재 위치가 맞는지, 그리고 내 역할에 **설정**에 접근할 권한이 있는지 확인하세요. 그래도 실험실이 보이지 않으면 계정 관리자에게 문의하세요.

### 실험실 기능을 나중에 끌 수 있나요?
네, 기능을 켠 곳에서 토글을 **끄기**로 바꾸면 돼요.

### "Live in X days"는 정확히 무슨 뜻인가요?
정식 출시까지 남은 예상 기간이에요. 피드백과 개발 상황에 따라 바뀔 수 있어요.

### 버그와 기능 요청은 각각 어디에 알려야 하나요?
제품 의견이나 작은 문제는 카드의 **피드백 제출**을 사용하세요. 팀 업무가 막힐 만큼 급한 지원이 필요하면 평소 쓰는 지원 요청(티켓) 절차를 따르세요.

### 서브 계정에서 특정 실험실 기능만 안 보이는 이유가 뭔가요?
해당 요금제에서는 에이전시가 그 기능의 공개 범위를 **숨김**으로 설정했을 수 있어요. 에이전시 소유자나 관리자에게 기능의 공개 범위를 바꿔 달라고 요청한 다음 서브 계정을 새로고침하세요.

### 모든 요금제에서 공개 범위 설정을 쓸 수 있나요?
아니요. Unlimited와 Pro 요금제에서는 공개 범위 기본값과 서브 계정별 공개 범위 관리를 쓸 수 있어요. 스타터 요금제에서는 실험실 기능이 기본적으로 보이고, 공개 범위 설정은 나타나지 않아요.
