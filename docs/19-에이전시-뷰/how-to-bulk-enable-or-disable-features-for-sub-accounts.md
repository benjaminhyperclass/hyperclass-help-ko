# 서브 계정 기능 일괄 활성화·비활성화

**Update features**(기능 업데이트) 일괄 작업을 쓰면 여러 서브 계정의 기능을 한 번에 켜거나 끌 수 있어요. 계정마다 따로 바꾸지 않아도 돼서 고객 온보딩, 기능 단계적 공개, 서브 계정 간 기능 접근 권한 통일에 편리해요. 에이전시 관리자만 쓸 수 있어요.

## 서브 계정 기능 일괄 관리란?

**에이전시 보기**의 **서브 계정** 목록에서 여러 서브 계정을 선택해 기능을 한꺼번에 켜거나 끌 수 있어요. 서브 계정과 바꿀 기능을 고른 뒤, 한 번의 일괄 작업으로 접근 권한을 적용해요.

기능은 카테고리와 하위 그룹으로 나뉘어 있어서 기능을 하나씩 고르거나 그룹 전체를 한 번에 고를 수 있어요. 선택한 기능만 바뀌고, 선택하지 않은 기능은 기존 설정이 그대로 유지돼요.

## 서브 계정 기능을 일괄로 켜거나 끄는 방법

서브 계정을 선택하고, 바꿀 기능을 고른 다음, 원하는 접근 설정을 적용하면 돼요.

1. **에이전시 보기**에서 **서브 계정** 탭으로 이동하세요.
2. 업데이트할 서브 계정 옆의 체크박스를 선택하고, **일괄 작업** 도구 모음에서 **Update features**(기능 업데이트)를 클릭하세요.

   ![서브 계정을 선택한 뒤 일괄 작업 도구 모음에서 Update features를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083703420/original/XyaRm4e14sstX3dJnajZdUyIMpbT9rc8lA.png?1792445078)

3. **Update feature access**(기능 접근 권한 업데이트) 창에서 바꿀 기능을 선택하세요. 기능을 검색하거나, 기능 또는 그룹을 하나씩 선택할 수 있어요. **전체 선택**과 **모두 제거**로 선택 범위를 한 번에 조정할 수도 있어요.
4. **다음**을 클릭하세요.

   ![Update feature access 창에서 기능을 선택하고 다음을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083703423/original/TndeKEqN0q2RfdMLRLyl-0UTLOQ4Unul6Q.png?1792445104)

5. 선택한 기능마다 **활성화** 또는 **비활성화**를 고르세요. **모두 켜기**나 **모두 끄기**를 누르면 여러 기능에 같은 설정을 한 번에 적용할 수 있어요.
6. **Apply changes**(변경 사항 적용)를 클릭해 일괄 업데이트를 제출하세요.
7. 제출하면 확인 메시지가 나타나요. 변경 사항이 반영되기까지 보통 2~5분 걸려요. 진행 상황은 **View bulk action history**(일괄 작업 기록 보기)를 클릭해 확인하세요.

   ![일괄 업데이트 제출 후 나타나는 확인 메시지와 View bulk action history 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083703436/original/liZ7ZOLZyihhvFy8GjF4NUXPnJW8IcO3TA.png?1792445152)
