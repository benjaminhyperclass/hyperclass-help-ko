# 서브 계정 목록 새 화면 (Unlimited·Founder 플랜)

하이퍼클래스의 서브 계정 목록이 새로운 화면으로 바뀌었어요. Unlimited($297)와 Founder($497) 플랜을 쓰는 에이전시는 상세 필터, 일괄 작업, 빨라진 속도를 사용할 수 있어요.

## 서브 계정 목록 개편이란?

서브 계정 목록 개편은 Unlimited($297)와 Founder($497) 플랜 에이전시를 위한 서브 계정 관리 페이지 업데이트예요. 화면 디자인이 새로워지고 성능이 좋아졌으며, 새 관리 도구가 추가됐어요. 이 모듈이 하이퍼클래스의 마이크로 앱 프레임워크로 옮겨졌기 때문이에요. 덕분에 모든 고객사 계정을 한곳에서 더 효율적이고 편하게 관리할 수 있어요.

## 서브 계정 목록 개편의 주요 장점

새 서브 계정 목록은 고객사 계정을 더 효율적으로 관리하도록 다음과 같이 개선됐어요.

- **통일감 있는 최신 화면:** 글꼴, 간격, 아이콘, 레이아웃이 새롭게 바뀌어 일관된 화면으로 쓸 수 있어요.
- **빨라진 속도:** 페이지가 더 빨리 열리고 동작이 부드러워져 일상적인 관리 작업에 드는 시간이 줄어요.
- **상세 필터:** 직관적인 필터로 원하는 서브 계정을 빠르게 찾을 수 있어요.
- **일괄 작업:** 여러 서브 계정에 한 번에 작업을 실행해 반복 업무를 줄일 수 있어요.
- **반응형 디자인:** 데스크톱, 태블릿, 모바일 화면에 맞게 레이아웃이 최적화되어 어떤 기기에서도 계정을 관리할 수 있어요.
- **앞으로를 위한 기반:** 마이크로 앱 구조 덕분에 서브 계정 태그 지정, 열 사용자 지정 같은 기능을 더 빠르게 선보일 수 있어요.

## 서브 계정 목록에서 상세 필터 사용하기

하이퍼클래스의 새 서브 계정 목록에는 **상세 필터** 기능이 있어요. Unlimited($297)와 Founder($497) 플랜 에이전시가 쓸 수 있어요. 이 필터를 쓰면 특정 플랫폼 기능, 설정, 상태를 기준으로 서브 계정을 빠르게 찾을 수 있어요.

### 1단계: 기본 필터 추가하기

1. 서브 계정 목록 맨 위의 **상세 필터** 버튼을 클릭하세요.
2. **상세 필터** 패널이 옆에서 열리고 필터 카테고리 네 개가 보여요.
   - **일반** (예: 추가한 날짜, 스냅샷)
   - **재판매** (예: 리스팅, WhatsApp, 이메일, AI 도구)
   - **재청구** (예: 이메일/전화 인증, 하이퍼클래스 프리미엄)
   - **하이퍼클래스** (예: 하이퍼클래스 이메일, 하이퍼클래스 전화)
3. 위 네 카테고리 중 원하는 곳에서 **검색** 필드를 클릭하세요.
4. 해당 검색 필드에서 필터링할 **조건**을 선택하세요.
5. **+ Add Filter**(필터 추가) 버튼을 눌러 OR 조건 필터를 추가하세요.

```
OR 조건: 조건 중 하나 이상이 참이면 결과에 표시됩니다. 조건 중 하나라도 일치하는 데이터가 포함되도록 필터가 적용됩니다.

예시: (하이퍼클래스 이메일이 활성화됨 또는 하이퍼클래스 전화가 활성화됨)으로 필터링하면, 하이퍼클래스 이메일이나 하이퍼클래스 전화 중 하나라도 활성화된 서브 계정(둘 다 활성화된 경우 포함)이 표시됩니다.
```

![상세 필터 패널에서 필터를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079164137/original/By-_Pessr8QYXp7_vIs9SqcULoIxHdxvqg.png?1787576012)

### 2단계: 중첩 필터 추가하기 (선택)

1. **+ Add Nested Filter**(중첩 필터 추가) 버튼을 클릭하세요.
2. 이 필터는 AND 조건으로 작동해요.

```
AND 조건: 모든 조건이 참이어야 결과에 표시됩니다. 지정한 모든 조건에 일치하는 데이터만 나오도록 필터가 결합됩니다.

예시: **생성일**이 1월 1일 이후이고 상태가 체험(Trial)인 서브 계정으로 필터링하면, 두 조건에 모두 맞는 서브 계정만 표시됩니다.
```

![중첩 필터를 추가하는 화면 녹화](https://jumpshare.com/v/yBrNDQAwVcwAGZKCHts6+/GIF+Recording+2025-07-16+at+9.27.42+PM.gif)

### 3단계: 필터 적용하고 결과 확인하기

1. **적용**을 클릭해 선택한 필터를 실행하세요.
2. 조건에 맞는 서브 계정이 나오면 결과를 확인하세요.
3. 일치하는 결과가 없으면 찾을 수 있는 서브 계정이 없다는 메시지가 표시돼요.
4. 필터를 적용하면 목록 페이지에 적용 중인 필터 상태가 계속 보여요. 어떤 조건이 쓰이고 있는지 바로 확인할 수 있어요.

![필터를 적용한 서브 계정 목록 화면](https://jumpshare.com/v/7vhv6D9Z9MaLL00FoGPV+/Screen+Shot+2025-07-16+at+9.32.58+PM.png)

### 4단계: 적용한 필터 확인하고 관리하기

필터 상태가 화면에 보이기 때문에 특정 서브 계정이 왜 목록에 나오는지 이해하기 쉬워요. 필터 설정 화면을 매번 다시 열지 않고도 결과를 더 빠르게 좁힐 수 있어요.

1. 현재 적용 중인 필터가 몇 개인지 화면에 표시돼요.
2. 한 번의 동작으로 필터를 제거하거나 조정해 결과를 더 효율적으로 좁힐 수 있어요.

![적용 중인 필터 개수가 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079164528/original/SnNw_yySwSnxP4C_YBThldTTrpALyoC_tA.png?1787576195)

## Unlimited 플랜의 에이전시 서브 계정 지정

에이전시 서브 계정 지정을 쓰면 Unlimited 플랜 에이전시가 온보딩과 핵심 설정에 사용하는 주 서브 계정을 일관되게 구분할 수 있어요. 설정 워크플로우의 기준이 더 분명해지고, 에이전시가 커져도 팀이 온보딩을 더 안정적으로 관리할 수 있어요.

**이 지정을 사용하면 에이전시와 내부 팀은 다음을 할 수 있어요.**

- 온보딩에 사용하는 주 서브 계정 확인
- 설정과 진행 상황 추적에 시스템 기반의 일관된 기준 사용
- 감사 기록으로 상태 변경 내역 확인
- API 기반 관리로 프로그래밍 방식의 온보딩 워크플로우 지원

{% hint style="warning" %}
이 기능은 **Unlimited 플랜($297)** 에이전시에 적용돼요.
{% endhint %}

## 서브 계정 관리를 위한 일괄 작업

일괄 작업을 쓰면 여러 서브 계정을 한 번에 관리할 수 있어서 반복되는 수작업이 줄어요.

- 체크박스로 서브 계정을 하나씩 선택하거나 **Select all**(전체 선택) 체크박스를 클릭하세요.
- 원하는 서브 계정을 선택하면 목록 위에 **일괄 작업** 메뉴가 나타나요.
- 사용할 수 있는 일괄 작업은 네 가지예요: **서브 계정 일시중지**, **캘린더 설정**, **Enable SaaS Mode**(SaaS 모드 활성화), **재청구 활성화**
- **Bulk Action History**(일괄 작업 기록, 시계 아이콘)를 클릭하면 이전 일괄 작업 기록을 볼 수 있어요.

![서브 계정을 선택하면 나타나는 일괄 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079165598/original/hMocgpGKtkwWYh_Q0YK7YenVHlcwaNeoUw.png?1787576742)

## 자주 묻는 질문

### 새 서브 계정 목록은 모든 하이퍼클래스 사용자가 쓸 수 있나요?
새 서브 계정 목록은 Unlimited($297)와 Founder($497) 플랜 에이전시가 쓸 수 있어요. Starter($97) 플랜 에이전시는 계속 카드 보기로 표시돼요.

### 새 화면을 쓰면 기존 서브 계정이나 데이터에 영향이 있나요?
아니요. 이번 업데이트는 화면과 관리 도구만 바꿔요. 서브 계정 데이터는 그대로예요.

### 새 서브 계정 목록은 모바일에서도 쓸 수 있나요?
네. 새 화면은 반응형이라 모든 화면 크기에 맞게 최적화되어 있어요.

### 새 서브 계정 목록을 쓰려면 추가 요금을 내야 하나요?
아니요. 새 서브 계정 목록은 Unlimited($297)와 Founder($497) 플랜에 추가 비용 없이 포함되어 있어요.
