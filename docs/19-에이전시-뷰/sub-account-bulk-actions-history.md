# 서브 계정 일괄 작업과 작업 기록

여러 서브 계정을 한 번에 선택해 지원되는 일괄 작업을 적용하고, **Bulk Action History**(일괄 작업 기록)에서 작업별 결과를 확인하는 방법을 안내해요.

## 이 문서에서 배울 내용

서브 계정 일괄 작업을 쓰면 에이전시 관리자가 서브 계정을 여러 개 선택해, 계정을 하나씩 열지 않고도 지원되는 관리 변경을 적용할 수 있어요. 자주 쓰는 작업으로는 SaaS 모드 켜기, 서브 계정 일시중지, 재청구 켜기, 지원되는 계정 기능 관리 등이 있어요. 어떤 작업을 쓸 수 있는지는 요금제, 권한, 설정에 따라 달라요.

**Bulk Action History**는 제출한 작업의 기록을 한곳에 모아 보여 줘요. 작업 유형, 상태, 사용자, 완료 정보와 계정별 성공·실패 내역을 확인할 수 있어요. 이 문서에서는 서브 계정을 선택하는 방법, 사용할 수 있는 일괄 작업, 결과를 안전하게 확인하는 방법을 설명해요.

{% hint style="info" %}
**일괄 작업** 아래에 표시되는 작업은 에이전시 요금제, 사용자 권한, SaaS 설정, 기능 제공 여부, 선택한 서브 계정에 따라 달라질 수 있어요. 지금 쓸 수 있는 작업은 내 계정에 표시되는 옵션을 기준으로 확인하세요.
{% endhint %}

## 서브 계정 일괄 작업과 작업 기록이란?

서브 계정 일괄 작업은 선택한 여러 서브 계정에 지원되는 작업 하나를 한꺼번에 적용하는 에이전시 수준의 관리 도구예요. 같은 과정을 계정마다 반복하는 대신, 에이전시 관리자가 **서브 계정** 목록을 검색하거나 필터링해 대상 계정을 고르고, 일괄 작업을 선택하고, 필요한 설정을 마친 뒤 작업 하나로 제출하면 돼요.

**Bulk Action History**는 제출한 작업을 기록하고 계정별 결과를 보여 줘요. 많은 서브 계정을 한꺼번에 처리했을 때 완료 여부를 확인하고, 개별 실패 원인을 살펴보기 쉬워요.

### 주요 장점

여러 서브 계정에 같은 운영 변경이 필요할 때 일괄 관리가 가장 유용해요. 선택, 설정, 결과 확인을 한곳에서 하면 반복 작업이 줄고, 무엇을 제출했고 계정별로 어떻게 처리됐는지 더 분명하게 알 수 있어요.

- 빠른 계정 관리: 계정을 하나씩 열지 않고도 지원되는 변경을 여러 서브 계정에 적용해요.
- 필터링된 선택: 검색, 필터, 개별 체크박스, **전체 선택**으로 원하는 계정만 골라요.
- 일관된 SaaS 요금제 지정: 안내에 따라 선택한 SaaS 요금제를 대상 서브 계정에 적용해요.
- 더 안전한 일시중지 결정: SaaS 구독과 해당하는 전화·A2P 리소스를 어떻게 처리할지 선택해요.
- 작업별 확인: 작업 유형, 상태, 제출한 사용자, 생성 시간, 완료 시간을 확인해요.
- 실패 원인 진단: 작업 세부정보를 열어 성공한 계정, 실패한 계정, 확인 가능한 오류 정보를 살펴봐요.

## 시작하기 전에

일괄 작업은 많은 서브 계정의 결제, 접근 권한, 구독, 계정 리소스에 한꺼번에 영향을 줄 수 있어요. 작업을 제출하기 전에 선택한 계정이 맞는지, 선택한 작업의 결과가 어떨지 꼭 확인하세요.

- 작업에 필요한 권한이 있는 **에이전시 관리자** 계정을 사용하세요.
- **전체 선택**을 누르기 전에 검색이나 필터로 **서브 계정** 목록을 먼저 좁히세요.
- SaaS를 켜려면 적용하려는 결제 제공업체 설정과 SaaS 요금제를 확인하세요.
- 계정 그룹마다 다른 SaaS 요금제가 필요하면 작업을 나눠서 처리하세요.
- 일시중지할 때는 활성 SaaS 구독의 청구를 멈출지, 접근만 막고 청구는 계속할지 정하세요.
- 전화번호와 A2P 처리 옵션을 꼼꼼히 살펴보세요. 전화 리소스를 연결 해제하고 종료하면 연결된 번호와 캠페인이 영구적으로 삭제될 수 있어요.

## 지원되는 일괄 작업

**서브 계정** 페이지가 에이전시 수준 일괄 관리의 시작점이에요. 사용할 수 있는 옵션은 계정의 요금제와 설정에 따라 달라서, 내 계정에 표시되는 메뉴가 지금 쓸 수 있는 작업을 결정해요.

| 일괄 작업 | 용도 |
| --- | --- |
| **Enable SaaS Mode**(SaaS 모드 활성화) | 조건에 맞는 SaaS 결제 설정과 선택한 SaaS 요금제를 기존 서브 계정 여러 개에 적용해요. |
| **서브 계정 일시중지** | 여러 서브 계정의 접근을 일시중지해요. 구독과 해당하는 전화·A2P 리소스를 어떻게 처리할지 선택할 수 있어요. |
| **재청구 활성화** | 지원되는 경우 재청구 또는 사용량 마크업 설정을 여러 서브 계정에 한 번에 설정해요. |
| 기타 지원 작업 | 일괄 관리 기능이 확장되면서 다른 작업이 추가로 표시될 수 있어요. |

## 서브 계정 일괄 작업 사용하기

모든 일괄 작업은 올바른 서브 계정을 선택하는 것부터 시작해요. 가능하면 대상을 좁혀서 선택하고, 진행하기 전에 작업별 확인 화면을 꼭 살펴보세요.

### 1단계: 서브 계정 열고 선택하기

**서브 계정** 목록에는 이 작업에 쓰는 검색, 필터, 선택, 일괄 작업, 기록 기능이 모여 있어요.

1. **에이전시 보기**에서 **서브 계정**으로 이동하세요.
2. 필요하면 검색, 정렬, 날짜, 열, 필터 기능으로 목록을 좁히세요.
3. 대상 서브 계정마다 체크박스를 선택하거나, 해당 선택 범위에 맞게 **전체 선택**을 누르세요.

  
![서브 계정 목록에서 계정 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547580/original/0tkIGb8ibSr4lsCkgH8RnmMye8hyPBxD9A.png?1789014501)

### 2단계: 일괄 작업 선택하기

계정을 하나 이상 선택하면 **일괄 작업** 메뉴에서 내 계정에서 쓸 수 있는 관리 작업을 시작할 수 있어요.

1. 선택한 계정 수를 확인하세요.
2. **일괄 작업**을 클릭하세요.
3. 실행할 작업을 선택하세요.

  
![일괄 작업 메뉴에서 작업 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547575/original/VZ5VJB7333yLjDOwqfDZ8AzmjS-XC1nqKA.png?1789014490)

## SaaS 모드 일괄 켜기

기존 서브 계정 여러 개를 같은 SaaS 요금제로 옮길 때 일괄 SaaS 활성화가 유용해요. 결제 설정을 고르고, 요금제를 선택하고, 설정을 검토한 뒤, 계정을 확인하고 작업을 제출하는 순서로 진행해요.

### 결제 제공업체 선택하기

사용할 수 있는 결제 제공업체 옵션은 에이전시의 SaaS 결제 설정에 따라 달라요. SaaS 요금제를 고르기 전에 해당하는 제공업체를 먼저 선택하세요.

1. **일괄 작업**에서 **Enable SaaS**(SaaS 활성화)를 선택하세요.
2. **결제 제공업체**에서 사용할 수 있는 옵션을 선택하세요.
3. **계속**을 클릭하세요.

  
![결제 제공업체 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547568/original/03FDFdDjxvYyt4kOKMztm8uc7oCUMPC0LA.png?1789014481)

### SaaS 요금제 선택하기

선택한 요금제는 이번 일괄 작업에 포함된 서브 계정에 적용돼요. 요금제를 고르기 전에 결제 주기, 요금제 가격, 포함된 기능, 사용할 수 있는 옵션을 확인하세요.

![SaaS 요금제 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547566/original/99HcmOnPbGUsDTiJHT1uGQqKF2mtOKAIfw.png?1789014473)

### SaaS 활성화 검토하고 확인하기

확인 창은 작업을 제출하기 전의 마지막 점검 단계예요. 진행하기 전에 선택한 계정 수와 SaaS 요금제를 확인하세요.

1. 선택한 서브 계정 수를 확인하세요.
2. 선택한 SaaS 요금제와 표시된 가격을 확인하세요.
3. 설정이 맞으면 **계속하기**를 클릭하세요.

![SaaS 활성화 검토 및 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547562/original/4PIHMsDjnp6hYSW08jL_EhcUanQtQeWlkA.png?1789014465)

{% hint style="info" %}
결제 수단 관련 안내: 고객이 아직 결제 정보를 입력하지 않았더라도 서브 계정은 SaaS 모드로 처리될 수 있어요. 필요한 결제 수단이 없으면 SaaS 구독이 보류(On Hold) 상태로 남고, 올바른 결제 정보가 추가될 때까지 접근이 제한될 수 있어요.
{% endhint %}

## 서브 계정 일괄 일시중지

일괄 일시중지를 쓰면 여러 서브 계정의 접근을 한 번에 제한하면서, 활성 SaaS 구독과 해당하는 전화·A2P 리소스를 어떻게 처리할지 정할 수 있어요. 계정 접근을 일시중지해도 관련 요금이 모두 자동으로 멈추는 것은 아니므로, 결제와 리소스 옵션은 따로 꼼꼼히 확인하세요.

1. 대상 서브 계정을 선택하세요.
2. **일괄 작업**을 열고 **서브 계정 일시중지**를 선택하세요.
3. **Subscription Preferences**(구독 설정)에서 활성 구독을 일시중지할지, 접근이 중지된 동안에도 고객에게 계속 청구할지 선택하세요.
4. 전화번호와 A2P 캠페인 옵션을 확인하세요.
5. 선택한 옵션마다 결과를 확인한 뒤에만 **계속하기**를 클릭하세요.

![서브 계정 일시중지 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547560/original/4fEixD_3Wkbgs1FxG701yZ7Vi2Ppp15HYQ.png?1789014456)

{% hint style="warning" %}
전화 리소스를 연결 해제하고 종료하도록 선택하면, 선택한 서브 계정에 연결된 전화번호와 A2P 캠페인이 영구적으로 삭제될 수 있어요. 리소스를 연결된 상태로 두면 서브 계정이 일시중지된 동안에도 해당하는 사용 요금이 계속 발생할 수 있어요.
{% endhint %}

## 일괄 작업 기록 확인하기

**Bulk Action History**는 제출한 작업의 감사 기록이며, 작업이 제대로 끝났는지 확인하기에 가장 좋은 곳이에요. 먼저 작업별 요약을 살펴보고, 실패한 작업은 전체 세부정보를 열어 계정별 문제를 찾으세요.

### Bulk Action History 열기

1. **에이전시 보기 > 서브 계정**으로 이동하세요.
2. **Bulk Action History** 시계 아이콘을 클릭하세요.
3. 날짜 범위나 사용할 수 있는 필터로 확인할 작업을 찾으세요.
4. **Job ID**(작업 ID), **작업 유형**, **상태**, **사용자**, **생성일**, **완료** 열을 확인하세요.

![일괄 작업 기록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547551/original/rN2cqG3RsHhvj3v5Hdyax4wIECrotDTzrw.png?1789014445)

### 계정별 결과 확인하기

완료된 일괄 작업에 성공한 서브 계정과 실패한 서브 계정이 섞여 있을 수 있어요. 작업 세부정보를 열어 어떤 계정이 정상 처리됐는지 확인하고, 완료되지 않은 계정은 확인 가능한 오류 정보를 살펴보세요.

1. 해당 작업에서 **Show Full Details**(전체 세부정보 보기)를 클릭하세요.
2. 서브 계정 ID, 이름, **상태**, **오류 세부정보**를 확인하세요.
3. **전체 서브 계정**, **성공**, **실패** 건수를 비교하세요.
4. 실패한 계정에 지원되는 작업을 다시 시도하기 전에 원인이 되는 문제를 먼저 해결하세요.

![계정별 결과를 보여 주는 전체 세부정보 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080547549/original/06Yh2PTKrBIMiWS8F105G-WJ-XXiJqOXZQ.png?1789014437)

## 문제 해결

일괄 작업이 보이지 않거나, 실패하거나, 결과가 섞여 있다면 전체 작업을 바로 다시 제출하기 전에 대상 자격과 설정을 먼저 확인하세요. **Bulk Action History**를 보면 문제가 작업 전체에 해당하는지, 특정 서브 계정에만 해당하는지 판단할 수 있어요.

| 문제 | 확인할 내용 |
| --- | --- |
| 원하는 일괄 작업이 보이지 않아요 | 에이전시 요금제, 사용자 권한, 계정 설정, 기능 제공 여부, 선택한 서브 계정이 대상 조건에 맞는지 확인하세요. |
| Enable SaaS에서 다음으로 넘어갈 수 없어요 | SaaS 결제 설정, 결제 제공업체, 선택한 요금제, 계정 자격을 확인하세요. |
| SaaS 활성화는 끝났는데 접근이 제한돼요 | 고객이 올바른 결제 수단을 아직 추가하지 않았는지, 구독이 보류(On Hold) 상태로 남아 있는지 확인하세요. |
| 일시중지한 계정에서 전화 사용 요금이 계속 발생해요 | 전화 리소스를 연결된 상태로 두었는지 확인하세요. 접근을 일시중지해도 연결된 전화 리소스가 자동으로 종료되지는 않아요. |
| 일부 계정은 성공하고 일부는 실패했어요 | **Bulk Action History**를 열어 **Show Full Details**를 선택하고, 실패한 계정마다 확인 가능한 오류 정보를 살펴보세요. |
| 작업이 아직 처리 중이에요 | 작업이 처리될 시간을 주고, 같은 작업을 중복 제출하기 전에 **Bulk Action History**를 새로고침하세요. |

## 자주 묻는 질문

### 서브 계정 일괄 작업은 누가 사용할 수 있나요?
일괄 관리 기능은 에이전시 요금제, 사용자 권한, SaaS 설정, 기능 제공 여부, 계정 자격에 따라 사용 가능 여부가 달라질 수 있어요. **일괄 작업** 메뉴에 표시되는 옵션을 기준으로 내 계정에서 쓸 수 있는 작업을 확인하세요.

### 일괄 작업 하나로 서브 계정마다 다른 SaaS 요금제를 적용할 수 있나요?
일괄 SaaS 작업은 해당 작업에 포함된 계정에 선택한 요금제를 적용해요. 그룹마다 다른 요금제가 필요하면 일괄 작업을 따로 실행하세요.

### SaaS를 켰는데 고객에게 결제 수단이 없으면 어떻게 되나요?
서브 계정은 SaaS 모드로 처리될 수 있지만, 구독이 보류(On Hold) 상태로 남고 고객이 올바른 결제 정보를 입력할 때까지 접근이 제한될 수 있어요.

### 접근은 일시중지하면서 SaaS 고객에게는 계속 청구할 수 있나요?
일괄 일시중지에서는 구독 설정을 따로 고를 수 있어요. 활성 구독을 일시중지할 수도 있고, 계정 접근이 중지된 동안에도 고객 청구를 계속 유지할 수도 있어요.

### 서브 계정을 일시중지하면 전화 관련 사용 요금도 자동으로 멈추나요?
아니요. 일시중지 과정에서 전화번호와 A2P 옵션을 확인하세요. 연결된 전화 리소스가 그대로 남아 있으면 해당하는 사용 요금이 계속 발생할 수 있어요.

### 일괄 작업 하나에 성공한 계정과 실패한 계정이 함께 있을 수 있나요?
네. **Bulk Action History**를 열고 **Show Full Details**에서 서브 계정별 결과와 확인 가능한 실패 정보를 확인하세요.

### 계정 하나만 실패했다면 일괄 작업 전체를 다시 시도해야 하나요?
먼저 실패한 계정의 오류 세부정보를 확인하세요. 원인이 되는 문제를 해결한 다음, 지원되는 작업으로 해당 계정만 다시 시도하세요.

### 이전 일괄 작업은 어디에서 찾을 수 있나요?
**에이전시 보기**에서 **서브 계정**을 열고 **Bulk Action History** 시계 아이콘을 클릭하세요. 기록 표와 **Show Full Details**에서 이전 작업과 계정별 결과를 확인할 수 있어요.
