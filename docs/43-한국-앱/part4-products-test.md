# Part 4. 상품 만들기 + 결제 테스트 🟡

결제경로 문서(Part 5)의 재료가 되는 단계입니다. **일반결제용과 빌링용 상품을 각각 만들어 각각 테스트**해야 두 벌의 결제경로를 캡처할 수 있습니다.

## 4-1. 상품 만들기 — 최소 2종 (권장 4종)

본인 계정 → **Payments → Products → [+ Create Product]**

**A. 일반결제(단건) 상품 — 일반결제 MID 심사용 (필수)**

- Pricing Type: **One-time** / Currency: **KRW**
- 예: "베이직 강의" 49,000원
- 실판매 상품과 동일한 이름·가격이면 가장 좋습니다

**B. 월간 구독 상품 — 빌링 MID 심사용 (빌링 신청 시 필수)**

- Pricing Type: **Recurring** / Billing Period: **Monthly** / Currency: KRW
- 예: "프리미엄 멤버십" 49,000원/월
- ⚠️ 빌링 심사에는 정기결제용 상품이 홈페이지/결제 페이지에서 확인 가능해야 합니다

**C. 연간 구독 상품 (선택)** — Recurring / Yearly. 월간×10~10.5개월 가격이 일반적. **선불 기간이 12개월을 넘지 않게** 하세요

**D. 무료 체험 → 자동 전환 상품 (선택)** — Recurring / Monthly + Trial Period 설정 + Setup payment 활성화(카드 등록만 받고 0원 → 체험 종료 후 자동 청구). 체험 모델을 쓸 계획이 있으면 만들어 두세요

**E. 인보이스 (선택)** — Payments → Invoices → 항목·금액 입력 → 발송. 1:1 견적 판매 모델용

## 4-2. 결제 링크 만들기

1. Payments → **Payment Links** (또는 Order Forms) → [+ New]
2. 상품 A 선택 → 저장 → URL 복사
3. 상품 B(구독)도 동일하게 별도 링크 생성
4. 이 URL들이 결제 테스트와 캡처의 출발점입니다

## 4-3. 결제 테스트 ① — 일반결제 (상품 A)

1. 일반결제 링크 열기 → 주문서 작성 (이름·이메일·연락처)
2. 결제수단: 신용/체크카드 → **토스페이먼츠 결제창**이 뜨는지 확인
3. 테스트 키 상태이므로 실제 청구 없이 결제 흐름이 완주됩니다
4. 완료 후 본인 계정 **Payments → Transactions** 에서 결제 건 확인

## 4-4. 결제 테스트 ② — 빌링/정기결제 (상품 B)

1. 구독 상품 링크 열기 → 주문서 작성
2. **토스 카드 등록창(빌링)** 이 열리는지 확인 — 일반 결제창과 다르게 "카드 등록" 흐름입니다
3. 카드 등록 → 1회차 결제 완료
4. 본인 계정 **Payments → Subscriptions** 에서 Status: **Active** + 다음 결제일(= 오늘+1개월) 확인

> 💡 이 두 테스트의 화면을 그대로 캡처해서 Part 5에 쓰게 되므로, 테스트할 때부터 **캡처 규칙(도메인 노출, PC 시간 노출)** 을 지키며 진행하면 두 번 일하지 않아도 됩니다.
