# Part 3. 하이퍼클래스 앱 연동 🟡 (막히면 🔴 지원)

토스페이먼츠 개발자센터에서 키를 발급받아 하이퍼클래스 결제 앱에 연결합니다.

## 3-1. API 키 확인

1. tosspayments.com 로그인 → 내 상점 선택 → **개발자센터 → API 키**
2. MID마다 키가 2쌍 있습니다:
   - **테스트 키**: `test_ck_...` (클라이언트) / `test_sk_...` (시크릿) — 결제 테스트용, 실제 돈이 나가지 않음
   - **라이브 키**: `live_ck_...` / `live_sk_...` — 카드사 심사 완료 후 실결제용
3. 지금 단계에서는 **테스트 키**를 사용합니다

**키 기록란** (시크릿 키는 타인에게 절대 공유하지 마세요)

| MID | Client Key (test_ck_) | Secret Key (test_sk_) |
|---|---|---|
| 일반결제 | ____________ | ____________ |
| 빌링 | ____________ | ____________ |

## 3-2. 하이퍼클래스 앱 설치 + 키 입력

1. 하이퍼클래스에서 안내한 **토스페이먼츠 앱 설치 링크**로 본인 계정에 앱을 설치합니다 (설치 시 자동 인증)
2. 설치 후 열리는 **결제 설정** 페이지에서 MID별로 키를 입력합니다:
   - 일반결제 탭 → 일반결제 MID의 Client/Secret 키
   - 빌링 탭 → 빌링 MID의 Client/Secret 키
   - 테스트/라이브 키 슬롯이 구분되어 있으니 **지금은 테스트 슬롯에** 입력
3. [연결] 저장 → 본인 계정의 **Payments → Integrations** 에 토스페이먼츠가 결제수단으로 표시되는지 확인
4. 이후 체크아웃·인보이스·결제 링크에서 토스페이먼츠 결제창이 자동으로 열립니다
