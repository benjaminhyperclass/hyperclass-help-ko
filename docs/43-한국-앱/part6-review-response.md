# Part 6. 심사 제출 후 — 보완 요청 대응 🟡

심사 중 보완 요청은 흔한 일입니다. 당황하지 말고 유형별로 대응하세요. **빠르게 보완할수록 심사가 빨리 끝납니다.**

| 받은 회신 | 의미 | 대응 |
|---|---|---|
| "결제방식(단건/빌링) 확인 부탁드립니다" | 제출한 결제경로가 어느 심사용인지 불분명 | 파일 표지·파일명·메일 본문에 결제방식과 MID를 명시해 재제출 (Part 5 규칙) |
| "빌링 결제경로 파일을 제출해 주세요" | 빌링 심사용 자료 누락 | 파일 2 (5-2 구성)를 만들어 제출 |
| "결제경로 파일 보완 요청" | 캡처 요건 미충족 (도메인/시간 미노출, 흐름 끊김 등) | 5-0 공통 규칙 재확인 후 해당 슬라이드 재캡처 |
| "협약서(확약서) 서명 요청" | 강의·구독 업종 필수 서류 미회신 | 2-2 절차로 즉시 서명·회신 |
| "홈페이지 하단 정보 보완" | footer 6종 불일치/누락 | 0-2 기준으로 수정 후 회신 |
| "상품이 확인되지 않습니다" | 상품 미노출·비공개 상태 | 0-1 기준으로 노출 후 회신 |
| 모두싸인 전자서명 요청 | 해외카드 등 추가 약정 | 메일 링크에서 서명 (스팸함도 확인) |

## 심사 완료 후 → 라이브 전환

1. 카드사 심사 완료 메일 수신 → 개발자센터에서 **라이브 키** (`live_ck_` / `live_sk_`) 확인
2. 하이퍼클래스 결제 설정 페이지의 **라이브 키 슬롯**에 MID별로 입력 (Part 3-2와 동일 화면)
3. 소액(1,000원) 실결제 1건 → 즉시 환불로 최종 확인
4. 🎉 결제 오픈 완료. 정산 주기·수수료는 계약 조건에 따라 상점관리자에서 확인
