# Part 1. 정보·서류 준비 🟡

## 1-1. 기본 정보 (신청서에 입력할 값)

사업자등록증을 옆에 두고 **완전히 동일하게** 준비하세요.

| 항목 | 메모 |
|---|---|
| 상호명 * | 사업자등록증 기준 |
| 대표자명 * | |
| 사업자등록번호 * | 예: 123-45-67890 |
| 법인등록번호 | 법인만 |
| 통신판매업 신고번호 * | 예: 2025-인천연수구-0000 |
| 유선 전화번호 * | 070·0505·080·휴대폰 가능 |
| 사업장 주소 * | 사업자등록증과 동일 |
| 홈페이지 URL * | https:// 포함 |
| 담당자 이름 / 이메일 / 연락처 * | 토스페이먼츠 연락 수신용 |
| 정산 계좌 (통장사본) * | 대표자/법인 명의 |

## 1-2. 카드사 심사 답변 5종 (신청 중 반드시 물어봅니다)

미리 적어두면 신청이 10분 만에 끝납니다.

1. **결제 가능한 URL** — 상품이 보이는 페이지 주소
2. **환불정책 URL** — 환불 규정 페이지 주소
3. **상품/서비스 상세 내용** — 예: "온라인 강의 — AI 마케팅 부트캠프, 12주 과정"
4. **단건 결제 최고가** — 가장 비싼 단일 상품 가격
5. **최대 서비스 제공 기간** — 예: 12개월

## 1-3. 서류 준비 (모두 3개월 이내 발급본)

**개인사업자**
- 사업자등록증
- 대표자 신분증 사본 (마스킹 없이)
- 통장사본 (정산 계좌)

**법인사업자**
- 사업자등록증
- 법인등기부등본 (말소사항 포함, 발급용)
- 주주명부 (주민번호 앞 7자리 + 지분율, 법인인감 날인)
- 법인인감증명서
- 통장사본

> 💡 서류는 **휴대폰으로 찍은 사진도 제출 가능**합니다. 전체 페이지가 다 나오게 찍으세요. 등기우편 발송은 토스페이먼츠가 별도로 요청하는 경우에만 진행하면 됩니다 (요청 메일에 주소·담당자 안내됨).

## 1-4. 어떤 상점(MID)을 신청할지 결정

토스페이먼츠는 결제 종류별로 별도의 상점 아이디(MID)를 발급합니다.

| MID | 용도 | 누구에게 필요한가 |
|---|---|---|
| **일반결제** | 카드·계좌이체·가상계좌·간편결제 단건 결제 | 모든 고객사 (필수) |
| **빌링(정기결제)** | 구독·멤버십 자동결제 (빌링키) | 월 구독/멤버십 모델이면 필수 |
| 해외결제(PayPal) | 해외 카드·외화 결제 | 해외 고객 비중이 높을 때만 |

> 💡 하이퍼클래스 고객사의 표준 조합은 **일반결제 + 빌링** 2종입니다.
> ⚠️ 빌링은 "정기 구독형 서비스"에만 허용됩니다. 신청 시 **어떤 구독 상품에 쓸 것인지 목적을 명확히** 답해야 하고, 심사 시점에 정기결제용 상품이 홈페이지에 있어야 합니다. 심사 난이도도 일반결제보다 높습니다 (그래서 결제경로 문서도 별도로 제출합니다 — Part 5).
