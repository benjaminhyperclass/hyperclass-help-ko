# 토스페이먼츠 셀프 신청 매뉴얼 v5

**하이퍼클래스 고객사용 — PG 계약부터 결제 오픈까지 스스로 완주하는 가이드**

> 이 매뉴얼 하나로 토스페이먼츠 신청 → 서류 제출 → 앱 연동 → 결제 테스트 → 카드사 심사 통과까지 전 과정을 직접 진행할 수 있습니다.
> 막히는 단계가 있을 때만 benjamin@hyperclass.ai 로 문의해 주세요.

## 이 매뉴얼이 v4와 달라진 점 (중요)

실제 심사에서 받은 보완 요청을 반영해 다음이 바뀌었습니다.

| # | 변경 | 이유 (실제 심사 회신) |
|---|---|---|
| 1 | **결제경로 문서를 2벌로 분리 제작** — ① 일반결제용, ② 빌링(정기결제)용 | "결제방식(단건결제 or 빌링) 확인 요청" + "빌링 결제경로 파일 별도 제출 요청" 회신이 실제로 왔습니다. 카드사 심사는 결제방식별로 따로 진행되므로 결제경로 문서도 각각 필요합니다 |
| 2 | **온라인 강의 협약서(확약서)를 필수 단계로 승격** | 강의·구독 업종은 협약서 서명 없이는 심사가 완료되지 않습니다. 부록이 아닌 본문 필수 체크 항목입니다 |
| 3 | 결제경로 표지에 **결제방식 명시 필수** | 심사관이 문서만 보고 어떤 방식의 심사 자료인지 즉시 알 수 있어야 합니다 |
| 4 | 빌링 전용 캡처 순서 신설 (카드 등록창 → 등록 완료 → 구독 활성) | 일반결제 캡처로는 빌링 심사가 불가능합니다 |
| 5 | 최신 정책 반영: 서류 사진 제출 가능, 보증보험 면제 기준, 미리 오픈 | 2026년 현재 토스페이먼츠 절차 기준 |

## 전체 진행 지도

```
Part 0  홈페이지 사전 점검      ← 최다 반려 원인, 가장 먼저
Part 1  정보·서류 준비
Part 2  토스페이먼츠 신청       ← MID별 전자계약 + 협약서
Part 3  하이퍼클래스 앱 연동    ← Test Key 입력
Part 4  상품 만들기 + 결제 테스트
Part 5  결제경로 문서 제작      ← ★ 일반용·빌링용 2벌
Part 6  심사 제출 + 보완 대응
```

- 소요 기간(평균): 신청 → 계약 완료 약 5일, 카드사 심사 약 7영업일. 보완 요청이 나오면 그만큼 늘어납니다. **Part 0을 먼저 끝내는 것이 전체 기간을 줄이는 최선의 방법입니다.**
- 표기 규칙: 🟡 = 고객님이 직접 / 🔴 = 하이퍼클래스가 지원
