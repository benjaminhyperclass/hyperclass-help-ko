# 한국 전용 앱

하이퍼클래스에는 한국 고객을 위한 전용 앱 두 가지가 준비되어 있어요.
**앱 마켓플레이스**에서 설치하고, 원화 결제와 카카오톡 상담을 바로 시작할 수 있어요.

## 앱 목록

| 앱 | 하는 일 | 시작하기 |
|---|---|---|
| **토스페이먼츠** | 원화(KRW) 결제 · 정기구독 · 환불 | [토스페이먼츠 앱 설치하기](tosspayments-installation.md) · [셀프 신청 매뉴얼](tosspayments-getting-started.md) |
| **KAKA AI** | 카카오톡 채널 문의를 **대화**에서 주고받기 · AI 자동 응답 · 예약 알림톡 | [KAKA AI 설치 가이드](kaka/README.md) |

## 어떤 순서로 보면 되나요?

1. 결제를 받으려면 → [토스페이먼츠 셀프 신청 매뉴얼](tosspayments-getting-started.md)로 가맹 신청부터 시작하세요. 심사에 시간이 걸리니 가장 먼저 하는 게 좋아요.
2. 카카오톡으로 상담을 받으려면 → [KAKA AI 설치 가이드](kaka/README.md)의 1~6단계를 따라 하세요. 40분 정도 걸려요.
