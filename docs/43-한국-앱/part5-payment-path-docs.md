> ### 결제경로 문서는 결제방식별로 "따로 2벌" 만듭니다
> - 📄 **파일 1: 일반결제(단건) 결제경로** — 일반결제 MID 심사용

>
> 파일명 예: `결제경로_일반결제_상호명.pptx` / `결제경로_빌링_상호명.pptx`

## 5-0. 캡처 공통 규칙 (두 파일 모두 적용)

1. **PPT 형식**으로 제작 (카드사별 양식 수정 요청에 대응하기 위함)
2. **주소창 도메인이 보이게** 캡처 (북마크바 제거)
3. **PC 시계가 함께 보이게** 캡처 (카드사가 시간 흐름으로 조작 여부 판단)
4. 상품명·이미지·상세설명·금액 → 결제까지 **자연스러운 흐름**이 이어져야 함
5. 테스트 키 결제창도 심사 가능 (라이브 결제 불필요)
6. 회원 전용이면 테스트 계정 ID/PW 기재 + 로그인 화면 캡처

## 5-1. 📄 파일 1 — 일반결제 결제경로 (슬라이드 구성)

| 슬라이드 | 내용 |
|---|---|
| ① 표지 | 상호명 / 사업자등록번호 / 홈페이지 URL / 테스트 계정 ID·PW / **"결제방식: 일반결제(단건)"** / **MID: (일반결제 상점아이디)** |
| ② 하단 정보 | footer 사업자 정보 6종이 모두 보이는 캡처 |
| ③ 환불 규정 | 환불 정책 페이지 캡처 |
| ④ 로그인/회원가입 | 로그인 화면 (비회원 구매 가능 시 그 경로) |
| ⑤ 상품 → 주문 | 상품 목록 → 상세(이름·가격·설명) → 주문서 작성 흐름 |
| ⑥ 결제창 | 결제수단 선택 → **토스페이먼츠 결제창** → 카드 정보 입력 화면까지 |

> BC카드 대응: 카드 인증 화면 직전까지가 아니라 **인증 화면까지** 캡처해 두면 재요청이 없습니다.

## 5-2. 📄 파일 2 — 빌링(정기결제) 결제경로 (슬라이드 구성)

①~④는 파일 1과 동일하되 표지에 **"결제방식: 빌링(정기결제)" + 빌링 MID** 를 명시하고, ⑤부터가 다릅니다:

| 슬라이드 | 내용 |
|---|---|
| ① 표지 | 파일 1과 동일 + **"결제방식: 빌링(정기결제)"** / **MID: (빌링 상점아이디)** |
| ②~④ | 하단 정보 / 환불 규정(**구독 해지 규정 포함 부분**) / 로그인 |
| ⑤ 구독 상품 | **구독 상품** 상세 — "월 49,000원", "매월 자동결제" 등 **정기결제임이 드러나는 문구·가격 표기**가 보여야 함 |
| ⑥ 카드 등록창 | 주문서 → **토스 카드 등록(빌링) 창** — 일반 결제창이 아닌 카드 등록 흐름임이 보이게 |
| ⑦ 등록 완료 + 구독 활성 | 결제/등록 완료 화면 + 계정 내 **Subscription Active + 다음 결제일** 화면 |
| ⑧ (권장) 해지 경로 | 구독 해지 버튼/메뉴가 있는 화면 — 자동결제 심사에서 소비자 보호 관점으로 확인하는 항목 |

## 5-3. 제출

- 계약 완료 후 토스페이먼츠 담당자 메일(또는 상점관리자 안내 경로)로 두 파일을 제출합니다
- 메일 본문에 한 줄씩 명시: "일반결제 MID ____ 결제경로 첨부 / 빌링 MID ____ 결제경로 첨부"
- 제출 후 카드사 심사 평균 7영업일 (카드사·업종에 따라 지연 가능)
