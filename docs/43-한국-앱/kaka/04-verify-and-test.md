# 4~6단계 · 연결 확인과 실제 테스트

## 4단계 · 연결 확인

여기까지 왔으면 실제 카카오톡으로 최종 확인해요. 스킬 테스트나 봇 테스트로는 확인이 안 돼요. **반드시 휴대폰 카카오톡에서 보내세요.**

1. 휴대폰 카카오톡에서 내 채널을 검색해 **채널 추가**(친구 추가)를 하세요.
2. **KAKA ai 설정** 2단계 맨 아래 **연결 확인**을 누르세요.
3. **60초 안에** 채널 채팅방에 아무 말이나 보내세요.
4. "✅ 메시지가 도착했어요"가 뜨면 완료예요.
5. **대화**에 방금 보낸 말이 새 연락처(`카카오 ○○○○`)로 떠 있는지 확인하세요.

### 안 될 때 — 화면 문구별로 보세요

| 화면 문구 | 원인 | 해결 |
| --- | --- | --- |
| 아직 메시지가 오지 않았어요 | 카카오가 하이퍼클래스를 호출하지 않음 | 아래 **체크리스트**를 순서대로 |
| 스킬 테스트는 통과했어요. 실제 카카오톡으로… | 서버 연결은 됐지만 실제 발화가 없음 | 휴대폰에서 다시 보내기 |
| 토큰이 일치하지 않아요 | 연결 암호가 다름 | [3-2](03-openbuilder-bot.md#3-2-스킬-등록)에서 헤더를 **지우고 손으로 다시 입력** → 저장 → 배포 |
| 다른 봇에서 신호가 왔어요 | 봇 ID가 다른 봇 것 | [3-1](03-openbuilder-bot.md#3-1-봇-만들기)의 봇 ID를 이 봇 것으로 다시 복사 |

### "아직 메시지가 오지 않았어요" 체크리스트

위에서부터 하나씩 확인하고, 하나라도 고쳤으면 **배포를 다시** 한 뒤 재시도하세요.

1. **배포했나요?** 오픈빌더 왼쪽 메뉴 **배포 > 배포 히스토리**에 최근 시각이 있어야 해요(열에 아홉은 이 문제예요).
2. **채널이 연결됐나요?** **설정 > 챗봇 관리 > 운영 채널**에 내 채널 이름이 있어야 해요.
3. **Callback이 켜져 있나요?** 폴백 블록 **⋯ > Callback 설정**이 켜져 있어야 해요.
4. **폴백 블록이 스킬데이터인가요?** 봇 응답이 "스킬데이터 사용" 하나여야 해요.
5. **채널 채팅(상담)이 꺼져 있나요?** 채널 관리자센터 **채팅** 꺼짐, 운영시간 24시간이어야 해요.
6. **헤더에 공백이 섞였나요?** 3-2 헤더를 지우고 손으로 다시 입력하세요.
7. **카카오 쪽 장애인가요?** 오픈빌더 스킬 화면의 Test URL 칸에 [webhook.site](https://webhook.site/)에서 받은 주소를 넣고 저장한 뒤, 스킬 테스트에서 **Test URL**을 선택해 **스킬서버로 전송**을 누르세요. 결과 로그에 `bot-proxy … timeout`이 뜨면 카카오 장애예요. 기다렸다가 다시 시도하세요. 확인한 뒤 Test URL은 비우고 저장하세요.

### 스킬 테스트로 서버 연결만 먼저 볼 수 있어요

스킬 화면 맨 아래 **스킬 테스트 > 스킬서버로 전송**(URL 모드)을 누르세요.

* "올바른 스킬 서버 응답입니다" → 카카오에서 하이퍼클래스까지의 연결은 정상이에요. 남은 건 봇·채널 설정(체크리스트 1~5)이에요.
* "올바르지 않은 스킬 서버 응답" + 1초 만에 실패 → 헤더 문제예요(6번).
* `bot-proxy … timeout` → 카카오 장애예요(7번).

스킬 테스트로는 연락처가 만들어지지 않아요. 최종 확인은 항상 실제 카카오톡으로 하세요.

## 5단계 · 답변 방식 고르기

**KAKA ai 설정** 3단계에서 선택해요.

* **상담원이 직접 답장**(기본, 추천) — 사람이 **대화**에서 답해요. 추가 설정도 AI 비용도 없어요.
* **AI가 먼저 답하고 상담원이 이어받기** — [선택 D](08-ai-chatbot.md)를 함께 보세요. AI 답변은 고객 화면에 **10~20초** 뒤에 떠요. 정상 범위예요.

## 6단계 · 실제로 되는지 확인

휴대폰으로 5분이면 돼요.

1. 카카오톡에서 채널에 **"안녕하세요"**를 보내세요.
2. **대화**에 왼쪽 말풍선으로 뜨는지 확인하세요.
3. 그 대화에 **1분 안에 답장**을 보내고, 카카오톡에 도착하는지 확인하세요(0원).
4. **3분 기다린 뒤 한 번 더 답장**하고, 카카오톡에 도착하는지 확인하세요(약 15원, 3-7·3-8을 마쳤을 때).

다 되면 설치 완료예요. 🎉

### 안 될 때

* **대화**에 안 뜬다 → 위 4단계 체크리스트
* 1분 안 답장이 안 간다 → [3-3 Callback 설정](03-openbuilder-bot.md#3-3-폴백-블록에-스킬-연결), [3-5 배포](03-openbuilder-bot.md#3-5-배포)
* 1분 지난 답장이 안 간다 → 답장 옆 ⚠️를 눌러 사유를 확인하세요
  * "REST API 키가 설정되지 않아…" → [3-8](03-openbuilder-bot.md#3-8-카카오-rest-api-키-저장)
  * 고객이 **채널을 추가**(친구)하지 않았으면 전달되지 않아요
  * 비즈월렛 미연결·잔액 부족 → [3-7](03-openbuilder-bot.md#3-7-비즈월렛-연결)
  * 3-4 이벤트 블록의 이벤트 이름과 배포를 확인하세요
