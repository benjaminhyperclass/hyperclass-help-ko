# 4단계 · 연결 확인

실제 카카오톡으로 최종 확인해요. 오픈빌더의 스킬 테스트나 봇테스트로는 확인되지 않아요. **반드시 휴대폰 카카오톡에서 보내세요.**

{% hint style="warning" %}
채널 **관리자(운영자) 카카오 계정**으로는 손님 화면을 그대로 볼 수 없어요. 채널 홈에 관리자 화면이 뜨고, 친구 목록에도 채널이 나오지 않아 친구 추가·해제를 해 볼 수 없어요. 손님 입장 확인, 특히 **채널을 추가하지 않은 손님** 확인은 **채널을 관리하지 않는 다른 카카오 계정**으로 하세요.
{% endhint %}

## 4-1. 첫 신호 받기

1. 휴대폰 카카오톡에서 내 채널을 검색해 **채널 추가**(친구 추가)를 하세요.
2. 카톡채팅연결 2단계 화면을 열어 둔 채 채널 채팅방에 아무 말이나 보내세요.
3. 위쪽 배너가 "**✓ 카카오에서 신호가 왔어요 — 챗봇 연결 완료**"로 바뀌면 통로가 열린 거예요.
4. **대화** 메뉴에 방금 보낸 말이 새 연락처(`카카오 ○○○○`)로 떠 있는지 확인하세요.

## 4-2. 설정 화면 3단계 — 연결 확인 코드

카카오톡 → 하이퍼클래스 연결이 내 채널과 이 계정 사이에서 제대로 이루어지는지 마지막으로 확인해요.

1. 노란 카드에 보이는 문구(`연결확인 ○○`)를 [**복사**]하세요.
2. [**채널 채팅 열기 ↗**]를 누르거나 휴대폰의 채널 채팅방에서, 채팅방을 한 번 나갔다가 다시 들어간 뒤 그 문구를 **그대로** 보내세요.
3. 답장 말풍선에 나온 **숫자 4자리**를 화면에 넣고 [**확인**]을 누르세요.
4. "✓ 카톡 → CRM 연결을 확인했어요"가 뜨면 완료예요.

* 말풍선에 이름·번호를 여쭤보는 문구가 함께 보일 수 있어요. 처음 온 손님에게 어떻게 보이는지 미리 보여 주는 것이니 그대로 두세요.
* 숫자가 안 보이면 [**답장에 숫자가 안 보여요**]에서 **[고정 문구만 보였어요]** 또는 [**아무 답장도 없었어요**]를 누르면 확인할 곳을 순서대로 알려 줘요.
* 이미 손님 대화가 오가는 **운영 중인 채널**에서는 손님 대화와 섞이지 않도록 이 확인 코드 점검이 꺼져 있어요. 그때는 3단계를 건너뛰어도 돼요.

## 안 될 때 — 화면 문구별로 보세요

| 화면 문구 | 원인 | 해결 |
| --- | --- | --- |
| 아직 메시지가 오지 않았어요 | 카카오가 카카오 커넥터를 부르지 않음 | 아래 **체크리스트**를 위에서부터 |
| 스킬 테스트는 통과했어요. 실제 카카오톡으로… | 서버 연결은 됨. 실제 메시지가 없음 | 휴대폰에서 다시 보내기 |
| 연결 암호가 일치하지 않아요 | 스킬 헤더의 값이 다름 | [3단계 ②](03-openbuilder-bot.md)에서 헤더를 **지우고 다시 입력** → 저장 → 배포 |
| 다른 봇에서 신호가 왔어요 | 봇 ID가 다른 봇의 것 | [3단계 ①](03-openbuilder-bot.md)에서 이 봇의 봇 ID를 다시 복사 |
| 봇 ID를 먼저 저장해 주세요 | 봇 ID 칸이 비어 있음 | [3단계 ①](03-openbuilder-bot.md) 6번 |
| 숫자가 맞지 않아요 | 예전 말풍선의 숫자를 넣음 | **가장 마지막에** 받은 말풍선의 4자리 |
| 코드가 만료됐어요 | 시간이 지남 | [**확인 코드 받기**]를 다시 누르고 새 문구로 보내기 |
| "연결확인" 뒤의 단어까지 그대로 보냈는지… | 문구 일부만 보냄 | 화면에 나온 문구를 **그대로** 복사해 보내기 |

### "아직 메시지가 오지 않았어요" 체크리스트

위에서부터 하나씩 확인하고, 하나라도 고쳤으면 **배포를 다시** 누른 뒤 다시 보내세요.

1. **배포했나요?** 오픈빌더 [배포] → 배포 히스토리에 방금 시각이 있어야 해요. (열에 아홉)
2. **운영 채널이 연결됐나요?** [설정] → [챗봇 관리] → 운영 채널에 내 채널 이름이 보여야 해요. ([3단계 ①](03-openbuilder-bot.md))
3. **Callback이 켜져 있나요?** 폴백 블록 → [•••] → Callback 설정 ON. ([3단계 ③](03-openbuilder-bot.md))
4. **폴백 블록 봇 응답이 "스킬데이터 사용" 하나인가요?** ([3단계 ③](03-openbuilder-bot.md))
5. **채널의 '채팅' 스위치가 꺼져 있나요? 운영시간은 24시간인가요?** ([1-3](01-kakao-channel.md))
6. **손님 채팅방이 상담 모드가 아닌가요?** 채팅방 위쪽에 "챗봇 채팅중"이 보여야 해요. 상담 채팅으로 바뀌어 있으면 채팅방을 나갔다가 다시 들어와 보내세요.
7. **헤더에 공백이 섞였나요?** 스킬 헤더 줄을 지우고 다시 입력하세요. ([3단계 ②](03-openbuilder-bot.md))
8. **검색용 아이디를 채널 주소로 넣지 않았나요?** 채널 URL은 `pf.kakao.com/_`로 시작해요. ([1-4](01-kakao-channel.md))
9. **카카오 쪽 장애인가요?** 아래 스킬 테스트에서 `bot-proxy … timeout`이 뜨면 카카오 장애예요. 기다렸다가 다시 해 보세요. 복구되면 자동으로 다시 들어와요.

### 스킬 테스트로 서버 연결만 먼저 볼 수 있어요

오픈빌더 스킬 화면 맨 아래 **스킬 테스트 → [스킬서버로 전송]**(URL 모드)을 누르세요.

* **"올바른 스킬 서버 응답입니다"** → 카카오 → 카카오 커넥터 연결은 정상이에요. 남은 건 봇·채널 설정(체크리스트 1~6)이에요.
* **"올바르지 않은 스킬 서버 응답"** + 1초 만에 실패 → 헤더 문제예요(체크리스트 7).
* **`bot-proxy … timeout`** → 카카오 장애예요(체크리스트 9).

스킬 테스트로는 연락처가 만들어지지 않아요. 최종 확인은 언제나 실제 카카오톡이에요.
