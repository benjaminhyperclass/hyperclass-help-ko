## 자주 막히는 곳 12가지

1. **배포를 누르지 않았어요** — 오픈빌더는 저장과 배포가 별개예요. 바꿀 때마다 배포하세요.
2. **운영 채널을 연결하지 않았어요** — 봇을 만들고 배포해도 채널에 연결하지 않으면 메시지가 오지 않아요(3-6).
3. **폴백 블록의 Callback 설정이 꺼져 있어요** — 꺼져 있으면 고객 메시지가 연결되지 않아요(3-3).
4. **채널 채팅(상담)이 켜져 있어요** — 고객이 "상담 연결"을 누르면 챗봇이 호출되지 않아요. 운영시간 밖에도 호출되지 않아요(1-3).
5. **헤더 값에 공백이 섞였어요** — 붙여넣을 때 따라온 보이지 않는 문자 때문에 카카오가 조용히 실패해요. 헤더를 지우고 손으로 다시 입력하세요(3-2).
6. **스킬 테스트만 하고 실제 카카오톡으로 보내지 않았어요** — 스킬 테스트는 서버 연결만 봐요. 연결 확인은 실제 카카오톡에서 보내야 통과해요(4단계).
7. **비즈월렛을 연결하지 않았거나 잔액이 없어요** — 1분이 지난 답장은 건당 약 15원이에요(3-7).
8. **REST API 키를 넣지 않았어요** — 1분이 지난 답장은 키가 있어야 나가요. 답장 옆 ⚠️에 사유가 표시돼요(3-8).
9. **채널을 추가하지 않은 고객에게 늦게 답장했어요** — 채널을 추가하지 않은 고객에게는 1분이 지난 답장이 전달되지 않아요.
10. **알림톡 템플릿에 허용되지 않은 변수를 넣었어요** — `#{이름}`, `#{상담일시}`, `#{meeting_link}` 외에는 값이 채워지지 않아요.
11. **Wait의 If already passed가 종료로 되어 있거나, Webhook의 kind가 모두 같아요** — 내일 예약에서 리마인드가 모두 취소되거나, 리마인드 시각에 확정 문구가 나가요.
12. **대화가 두 개로 나뉘어 보여요** — 카카오톡 첫 문의는 임시 연락처로 잡혀요. 고객이 예약하거나 번호를 남기면 **그 이후 대화는 기존 고객 정보로** 들어가요. 자동으로 합쳐지지는 않아요. 이전 임시 연락처에는 `카카오병합대기` 태그가 붙고 그때까지의 대화는 그쪽에 남아요. 한곳에서 보고 싶으면 태그가 붙은 연락처를 찾아 직접 병합하세요.

## 자주 묻는 질문

### AI 답변이 오기까지 왜 15초쯤 걸리나요?

AI가 답을 만드는 시간이에요. 카카오톡과 **대화** 사이의 전달은 2~3초이고, 나머지는 AI 생성 시간이라 정상 범위예요. 사람이 직접 답하는 방식에서는 답장을 누르는 즉시 가요.

### AI 답변 비용은 누가 내나요?

AI는 내 하이퍼클래스 요금제에서 처리돼요. KAKA 앱 자체는 무료예요.

### 카카오 채널을 여러 개 연결할 수 있나요?

서브 계정 하나에 채널 하나예요. 채널이 여럿이면 서브 계정을 나눠 설치하세요.

### 고객에게 먼저 카카오톡을 보낼 수 있나요?

고객이 먼저 말을 건 대화에만 답할 수 있어요. 카카오 정책이에요. 먼저 연락해야 한다면 [알림톡(선택 B)](06-booking-alimtalk.md)을 쓰세요.

### 알림톡과 일반 답장은 뭐가 다른가요?

알림톡은 검수된 문구만, 정해진 상황에서 발송해요. 대신 채널을 추가하지 않은 고객에게도 도착해요. 일반 답장은 자유롭게 쓸 수 있지만, 고객이 먼저 말을 건 대화에서만 가능해요.

### 대화 내용은 어디에 남나요?

다른 채널과 똑같이 **대화**와 연락처 정보에 남아요.

### 챗봇 설정을 바꾸면 연결이 끊기나요?

스킬 주소나 봇 ID를 바꾸면 끊겨요. 바꾼 뒤 배포하고 연결 확인을 다시 하세요.

### 설정은 그대로인데 갑자기 메시지가 안 들어와요.

카카오 쪽 장애일 수 있어요. [4단계 체크리스트](04-verify-and-test.md#아직-메시지가-오지-않았어요-체크리스트) 7번으로 확인하세요. 카카오 장애라면 복구되면 자동으로 다시 들어와요.
