# 7단계 · 실제로 써 보기와 완료 화면

## 7-1. 휴대폰으로 5분 확인

1. 채널을 추가한 휴대폰 카카오톡에서 채널에 "**안녕하세요**"를 보내세요.
2. **대화** 메뉴에 왼쪽 말풍선으로 뜨는지 확인하세요.
3. 그 대화에 **4분 안에 답장**을 보내고 카카오톡에 도착하는지 확인하세요. (0원)
4. **4분 넘게 기다린 뒤 한 번 더 답장**을 보내고 도착하는지 확인하세요. (약 15원 · [6단계](06-late-reply.md)를 마쳤을 때)

다 되면 설치 완료예요. 🎉

### 안 될 때

* **대화에 안 뜬다** → [4단계 체크리스트](04-verify-and-test.md)
* **4분 안 답장이 안 간다** → [3단계 ③](03-openbuilder-bot.md) Callback 설정과 [④ 배포](03-openbuilder-bot.md) 확인
* **4분 지난 답장이 안 간다** → 대화에서 그 답장 옆 **⚠️**를 눌러 사유를 확인하세요.

| ⚠️ 사유 | 해결 |
| --- | --- |
| REST API 키가 설정되지 않아… | [6단계 ③](06-late-reply.md) |
| 비즈월렛 미연결 · 잔액 부족 | [6단계 ①](06-late-reply.md) |
| 손님에게 `카카오비친구` 태그가 있음 | 채널을 추가하지 않은 손님이에요. 메시지마다 첫 답장 1건만 전달되니 할 말은 한 답장에 모아 보내세요 ([운영 가이드](08-operations.md)) |
| 이벤트 이름 오타 | [6단계 ②](06-late-reply.md)의 `agent_reply` 확인 후 배포 |

## 7-2. 완료 화면 알아보기

설치를 마친 뒤 왼쪽 메뉴 **카톡채팅연결**을 열면 완료 화면이 나와요.

* **운영 상태 3줄** — 카톡 받기 · 상담원 답장 · 예약 알림톡 상태가 보여요. 예약 알림톡을 아직 안 했다면 옆 [**연결하기**]로 [선택 B](10-booking-alimtalk.md)를 시작할 수 있어요.
* **주황색 "확인 1분" 항목** — 한 번 더 확인할 일이 있다는 뜻이에요. 그 자리에서 확인하고 **[껐어요]** 등을 누르면 사라져요.
* **[대화창 열기]** — 대화 메뉴로 바로 가요.
* **[내 카톡으로 테스트]** — 연결 확인을 한 휴대폰으로 테스트를 보내요.
* **늦은 답장(4분 후)** — [6단계](06-late-reply.md)의 비즈월렛 · agent_reply 블록 · REST API 키
* **홈페이지에 카카오톡 문의 버튼 달기** — [선택 C](11-website-button.md)
* **[설정 바꾸기] → [바꾸기]** — 답변 방식 등 앞 단계 설정을 다시 바꿔요.
* **설치 점검 → 자세히** — 연결 상태와 기술 정보를 점검해요. "다른 자동응답이 무료 답장 창을 먼저 쓰고 있는지"도 여기서 확인해요.
* **연결 해제** — 계정 이름을 정확히 입력하고 [**연결 해제 실행**]을 누르면 카카오 연결이 해제돼요. 되돌리기 어려우니 정말 해제할 때만 쓰세요.

## 7-3. 봇이나 설정을 바꿀 때

* 오픈빌더에서 **스킬 주소나 봇 ID를 바꾸면 연결이 끊겨요.** 바꾼 뒤 배포하고 [연결 확인](04-verify-and-test.md)을 다시 하세요.
* 봇을 바꾸면 설정 화면에 "봇이 바뀌어 연결 확인을 다시 해야 해요"가 떠요. 3단계 연결 확인을 다시 하면 돼요.
* 오픈빌더 설정을 하나라도 바꿨다면 **배포**를 잊지 마세요.
