# 선택 A · 문의 접수 자동화

카카오톡으로 들어온 신규 문의에 **담당자 배정 + 파이프라인 기회 생성 + 내부 알림**을 자동으로 처리해요. 손님이 이름·번호를 알려 주면 연락처에 `카카오톡_유입` 태그가 붙는데, 이 태그를 신호로 워크플로우를 돌려요.

## A-1. 접수 워크플로우 만들기

1. **자동화 → 워크플로우**에서 새 워크플로우를 만드세요(이름 예: `카카오톡 문의 접수`).
2. 트리거 **Contact Tag Added**(태그가 붙었을 때)를 고르고 태그를 `카카오톡_유입`으로 정하세요.
3. 액션 세 개를 추가하세요.
   * **Assign to user** — 담당자 지정
   * **Create opportunity** — 파이프라인과 단계를 고르고, 이름은 예를 들어 `카카오 · {{contact.first_name}}`
   * **Internal Notification** — 받을 사람: 담당자
4. 저장한 뒤 **Publish**(게시)하세요.

{% hint style="warning" %}
이 워크플로우에 손님에게 **자동으로 답장하는 액션**(SMS 보내기 등)은 넣지 마세요. 무료 답장 창을 먼저 써 버려 상담원 답장이 유료가 돼요. ([운영 가이드](08-operations.md))
{% endhint %}

## A-2. AI 방식을 쓰면 하나 더

AI가 대화에서 번호를 받아 적을 때는 `카카오톡_유입` 태그가 자동으로 붙지 않아요. 번호가 바뀔 때 태그를 붙이는 워크플로우를 하나 더 만드세요.

1. 새 워크플로우를 만드세요(이름 예: `카카오 AI 수집 → 유입 태그`).
2. 트리거 **Contact Changed**를 고르고 필터를 `Phone` **Has changed**로 정하세요.
3. 조건(**If/Else**): 태그에 `카카오채널` 포함 **그리고** `카카오톡_유입` 미포함
4. 예(Yes) 분기에 **Add Tag → `카카오톡_유입`**을 넣으세요.
5. 설정에서 **Allow re-entry**를 켜고 **Publish**하세요.

## 함께 쓰는 태그

전체 태그 설명은 [운영 가이드 — 태그로 알아보는 카카오 손님](08-operations.md)에 있어요.

| 태그 | 언제 붙나요 |
| --- | --- |
| `카카오채널` | 카카오톡으로 들어온 손님 |
| `카카오톡_유입` | 이름·번호를 받음 (접수 트리거) |
| `카카오톡_이탈` | 이름·번호 없이 대화가 이어짐 |
| `카카오병합대기` | 대화가 기존 고객 정보로 옮겨간 뒤 이전 임시 연락처에 남는 표시 |
