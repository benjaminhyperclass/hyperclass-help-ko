# 선택 A · 문의 접수 자동화

카카오톡으로 들어온 신규 문의에 **담당자 배정 + 파이프라인 기회 생성 + 알림**을 자동으로 처리해요.

{% hint style="info" %}
워크플로우 편집 화면은 영어로 표시돼요. 아래 트리거·액션 이름은 화면에 보이는 영어 그대로 적었어요.
{% endhint %}

## 워크플로우 만들기

1. **자동화 > 워크플로우**에서 새 워크플로우를 만드세요(이름 예: `카카오톡 문의 접수`).
2. 트리거로 **Contact Tag Added**(태그가 추가됐을 때)를 고르고, 태그 `카카오톡_유입`을 선택하세요.
3. 액션 3개를 추가하세요.
   * **Assign to user**(담당자 지정) — 담당자를 고르세요.
   * **Create opportunity**(기회 만들기) — 파이프라인과 단계를 고르고, 이름은 예를 들어 `카카오 · {{contact.first_name}}`으로 하세요.
   * **Internal Notification**(내부 알림) — 받을 사람을 담당자로 정하세요.
4. 저장한 뒤 **Publish**(게시)하세요.

## AI 방식을 쓴다면 하나 더

AI가 고객 번호를 받아 적을 때는 태그가 자동으로 붙지 않아요. 아래 워크플로우를 하나 더 만드세요.

1. 새 워크플로우를 만드세요(이름 예: `카카오 AI 수집 → 유입 태그`).
2. 트리거 **Contact Changed**(연락처 변경)를 고르고, 필터를 `Phone` **Has changed**로 정하세요.
3. 조건(**If/Else**)을 추가하세요: 태그에 `카카오채널` 포함 **그리고** `카카오톡_유입` 미포함.
4. 예(Yes) 분기에 **Add Tag**(태그 추가) → `카카오톡_유입`을 넣으세요.
5. 워크플로우 설정에서 **Allow re-entry**(재진입 허용)를 켠 뒤 **Publish**하세요.

## KAKA가 붙이는 태그

| 태그 | 언제 붙나요 |
| --- | --- |
| `카카오채널` | 카카오톡으로 들어온 고객 |
| `kaka-mirror` | KAKA가 만든 대화 |
| `카카오톡_유입` | 이름·번호를 확보했을 때(접수 트리거) |
| `카카오톡_이탈` | 연락처 없이 이탈했을 때 |
| `카카오병합대기` | 예약·번호 입력으로 대화가 기존 고객 정보로 옮겨간 뒤, **이전 임시 정보**에 남는 표시(수동 정리 대상) |
| `알림톡미발송-번호없음` | 알림톡을 보내려 했지만 휴대폰 번호가 없어 건너뜀(노트도 함께 남아요) |
