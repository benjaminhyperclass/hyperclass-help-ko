# 선택 D · AI 챗봇 연결

AI가 먼저 답하고, 필요할 때 사람이 이어받아요.

## D-1. AI 에이전트 만들기

왼쪽 메뉴 **AI 에이전트**에서 새 에이전트를 만들고 이름을 정하세요. 안내 문구(프롬프트)에는 아래 D-5의 규칙이 반드시 들어가야 해요.

## D-2. 커스텀 값 등록

프롬프트에서 브랜드 정보 같은 공통 값을 쓰려면 **설정 > 커스텀 값**에서 먼저 만들어 두세요.

## D-3. 카카오톡 대화에도 AI가 답하게 켜기

1. **자동화 > 워크플로우**에서 새 워크플로우를 만드세요(이름 예: `AI 응답 켜기`).
2. 트리거 **Customer Replied**(고객이 답장했을 때)를 고르고 채널 조건을 **SMS**로 정하세요.
3. 액션 **Update Conversation AI Bot**을 추가해 만든 에이전트를 고르고, 상태를 **켜기**로 정하세요.
4. 저장한 뒤 **Publish**(게시)하세요.

{% hint style="info" %}
카카오톡 대화는 내부적으로 SMS 유형으로 처리돼요. 그래서 채널 조건을 SMS로 두는 게 맞아요.
{% endhint %}

## D-4. 응답대기 메시지 넣기

AI 답변은 고객 화면에 **10~20초** 뒤에 떠요. 그동안 아무 표시가 없으면 고객이 무시당했다고 느낄 수 있어요. [3-3](03-openbuilder-bot.md#3-3-폴백-블록에-스킬-연결)의 **Callback 설정 > 응답대기 메시지**에 짧은 문구를 넣고 배포하세요. 예: `확인 중이에요. 잠시만요.`

AI 답변은 대부분 1분 안에 나가므로 발송비가 들지 않아요. 상담원이 이어받아 늦게 답하면 [3-7 비즈월렛](03-openbuilder-bot.md#3-7-비즈월렛-연결)과 [3-8 REST API 키](03-openbuilder-bot.md#3-8-카카오-rest-api-키-저장)가 필요해요.

## D-5. 꼭 확인할 규칙

프롬프트에 아래 문장이 들어 있어야 해요.

```
예약 링크는 대화에서 받은 주소를 그대로 전달합니다.
주소를 바꾸거나 줄이거나 다시 만들지 않습니다.
주소 뒤에 붙은 값이 있으면 그대로 두고 전달합니다.
```

예약 링크 뒤에 붙는 값으로 카카오톡 고객과 기존 고객 정보를 자동으로 연결해요. AI가 주소를 다듬으면 그 연결이 끊어져 고객 정보가 두 개로 갈려요.
