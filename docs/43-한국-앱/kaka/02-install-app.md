# 2단계 · 앱 설치

## 2-1. 앱 설치하기

1. 왼쪽 메뉴에서 **앱 마켓플레이스**를 여세요.
2. **Kakao AI chatbot**을 검색해 **설치**(Install)를 누르세요.
3. 설치할 서브 계정을 선택하고 **권한 11개를 모두 허용**하세요.
4. 설치가 끝나면 왼쪽 메뉴에 **KAKA ai 설정**이 생겨요.

{% hint style="warning" %}
권한을 하나라도 빼면 메시지가 들어오거나 나가지 않아요.
이미 다른 카카오 봇이 연결된 서브 계정에 설치하면 그 연결이 바뀌어요. 새 채널은 새 서브 계정에 설치하세요.
{% endhint %}

**대화 > 새 대화** 화면의 채널 선택지에 **KakaoTalk**이 보이면 정상이에요. 아직 메시지는 오지 않아요. 3단계까지 마쳐야 연결됩니다.

## 2-2. 위저드 1단계 — 검색용 아이디 저장

1. 왼쪽 메뉴 **KAKA ai 설정**을 열고 **시작하기**를 누르세요.
2. **1단계 — 카카오톡 채널 연결**에 [1-4](01-kakao-channel.md#1-4-채널-주소-확인)에서 적어 둔 **검색용 아이디**를 입력하세요. `@`는 빼도 되고, 채널 주소 `pf.kakao.com/_abcdef`를 그대로 붙여넣어도 돼요.
3. **저장**을 누르면 **채널 열기 ↗** 버튼이 생겨요. 눌러서 내 채널이 맞는지 확인하세요.

{% hint style="info" %}
이 값이 있어야 [선택 C(홈페이지 버튼)](07-website-button.md)의 코드가 만들어져요. 저장하지 않고 넘어가면 그 카드가 열리지 않아요.
{% endhint %}
