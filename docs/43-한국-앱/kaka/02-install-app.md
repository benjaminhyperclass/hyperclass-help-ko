# 2단계 · 앱 설치와 설정 화면 둘러보기

## 2-1. 앱 설치

1. 왼쪽 메뉴 **앱 마켓플레이스**를 여세요.
2. **KAKAO Connector** (카톡채팅연결)을 검색하고 **설치**를 누르세요.
3. 설치할 워크스페이스(서브 계정)를 고르고 **요청하는 권한을 모두 허용**하세요.
4. 설치가 끝나면 왼쪽 메뉴에 **카톡채팅연결**이 생겨요.

{% hint style="warning" %}
* 권한을 하나라도 빼면 메시지가 들어오거나 나가지 않아요.
* **카카오 채널 하나 = 워크스페이스 하나**예요. 이미 다른 카카오 봇이 연결된 워크스페이스에 설치하면 그 연결이 바뀌어요. 새 채널은 새 워크스페이스에 설치하세요.
* 설정 화면은 **관리자 권한 계정**으로 열어야 해요. 일반 사용자 계정으로 열면 "이 설정은 계정 관리자만 열 수 있어요"가 떠요.
{% endhint %}

**대화** 메뉴에서 새 메시지를 쓸 때 채널 선택지에 **KakaoTalk**이 보이면 설치가 정상이에요. 아직 손님 메시지는 들어오지 않아요. [3단계](03-openbuilder-bot.md)를 마쳐야 연결돼요.

## 2-2. 설정 화면 둘러보기

왼쪽 메뉴 **카톡채팅연결**을 누르면 **카카오톡 상담 연결** 화면이 열려요. 위쪽에 5단계 칸이 있고, 단계를 마칠 때마다 ✓가 붙어요.

| 단계 | 하는 일 | 이 매뉴얼 |
| --- | --- | --- |
| 1 · 카카오 채널 | 채널 주소 저장 · 1:1 채팅 끄기 확인 | 아래 2-3 |
| 2 · 챗봇 연결 | 오픈빌더에서 봇·채널 연결 → 스킬 등록 → 폴백 블록 → 배포 | [3단계](03-openbuilder-bot.md) |
| 3 · 연결 확인 | "연결확인 ○○"를 카톡으로 보내고 답장 속 숫자 4자리 넣기 | [4단계](04-verify-and-test.md) |
| 4 · 답변 방식 | 상담원 또는 AI 고르기 · 다른 자동응답 끄기 | [5단계](05-reply-mode.md) |
| 5 · 예약 알림톡 (선택) | 솔라피 · 템플릿 · 예약 알림 워크플로우 | [선택 B](10-booking-alimtalk.md) |
| 완료 화면 | 운영 상태 · 늦은 답장 · 홈페이지 버튼 · 설치 점검 · 연결 해제 | [6단계](06-late-reply.md) · [7단계](07-first-test.md) |

화면에서 자주 쓰는 버튼

* **[복사]** — 스킬 주소, 헤더 이름, 연결 암호 같은 값을 복사해요. 복사 버튼 옆 **"→" 표시**는 그 값을 붙여넣을 칸을 알려 줘요.
* **[○○ 열기 ↗]** — 파트너센터, 오픈빌더, 워크플로우처럼 다음에 가야 할 화면을 새 탭으로 열어요.
* **[화면 보기]** — 그 단계의 실제 화면 그림을 보여 줘요.
* **[막히면 도움 요청]** — AI 도우미 파일 받기 · 지금 상태 복사 ([안내 보기](README.md))

2·3단계를 마치면 2초 뒤 저절로 다음 단계로 넘어가요. 그 자리에 머물고 싶으면 [**머무르기**]를 누르세요.

## 2-3. 설정 화면 1단계 — 채널 주소 저장과 1:1 채팅 끄기

1. **채널 주소** 칸에 [1-4](01-kakao-channel.md)에서 복사한 **채널 URL**을 붙여넣으세요(예: `pf.kakao.com/_abcdef`). 칸 옆 [**파트너센터 열기 ↗**]로 바로 찾아갈 수도 있어요.
2. [**확인**]을 누르면 "✓ 저장했어요"가 뜨고 **[채널 열기 ↗]** 버튼이 생겨요. 눌러서 내 채널이 맞는지 확인하세요.
3. [1-3](01-kakao-channel.md)처럼 '채팅' 스위치를 껐으면 같은 화면의 [**껐어요**]를 누르세요. [**설정 열기 ↗**]를 누르면 파트너센터 채팅 설정이 바로 열려요.

{% hint style="info" %}
* `_`로 시작하지 않는 값(검색용 아이디)을 넣으면 "채널 URL을 붙여 넣어 주세요" 안내가 떠요.
* 채널 주소가 있어야 [선택 C](11-website-button.md)(홈페이지 버튼)의 코드가 만들어져요.
{% endhint %}
