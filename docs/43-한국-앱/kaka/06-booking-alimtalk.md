# 선택 B · 예약 알림톡

예약 확정과 리마인드를 알림톡으로 자동 발송해요. **카카오 비즈니스 인증**([1-2](01-kakao-channel.md#1-2-비즈니스-인증-알림톡을-쓸-계획이면-필수))과 **문자 발송 서비스 계정**이 필요해요.

알림톡은 채널을 추가하지 않은 고객에게도 도착해요. 대신 **카카오가 미리 검수한 문구만** 보낼 수 있어요.

## 전체 흐름

```
1) 발송 서비스 가입          →  2) 발신프로필 등록 (채널 연결)
   ↓                             ↓
3) 템플릿 4종 등록·검수 신청  →  4) KAKA에 API 키 연결
   ↓                             ↓
5) 예약 알림 워크플로우 만들기 →  6) 테스트 예약으로 확인
```

## B-1. 발송 서비스 가입과 발신프로필

1. 문자 발송 서비스(예: 솔라피)에 가입하세요.
2. **카카오 > 발신프로필(채널) 등록**에서
   * 1단계에서 만든 채널의 **검색용 아이디**를 입력하고
   * 채널 관리자 휴대폰으로 오는 **인증번호**를 입력하세요.
3. 발신프로필이 등록되면 그 채널로 알림톡을 보낼 수 있어요.
4. **잔액을 충전**해 두세요. 잔액이 없으면 발송이 실패해요.

{% hint style="info" %}
발신프로필을 등록하려면 비즈니스 인증이 완료된 채널이 필요해요.
{% endhint %}

## B-2. 템플릿 등록 — 변수 규칙이 중요해요

**KAKA가 채워 보내는 변수는 아래 3개뿐이에요.**

| 변수 | 들어가는 값 | 예시 |
| --- | --- | --- |
| `#{이름}` | 고객 이름 | 홍길동 |
| `#{상담일시}` | 예약 일시(한국어로 자동 변환) | 2026년 9월 23일 (수) 오후 9:00 |
| `#{meeting_link}` | 화상 회의·장소 링크 | https://meet.google.com/abc-defg-hij |

{% hint style="warning" %}
**이 3개 외의 변수를 템플릿에 넣으면 발송이 실패해요.** 예를 들어 `#{상호}`, `#{금액}`, `#{담당자}` 같은 변수는 값이 채워지지 않아요. 브랜드명처럼 고정된 내용은 변수가 아니라 **그냥 글자로** 적으세요.
{% endhint %}

### 등록할 템플릿 4종

아래 문안은 검수 통과를 염두에 두고 쓴 거예요. `[내 브랜드명]` 부분만 바꿔서 그대로 등록하세요.

**① 예약 확정 알림**

```
[내 브랜드명] 예약이 확정되었습니다 ✅

#{이름}님, 아래 일정으로 예약이 확정되었습니다.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

입장 시 이름을 실명으로 설정해 주세요.
궁금하신 점은 채널로 문의해 주세요.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

**② 1일 전 알림**

```
[내 브랜드명] 예약 하루 전입니다 ⏰

#{이름}님, 내일 일정을 잊지 마세요.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

일정 변경이 필요하시면 채널로 알려주세요.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

**③ 4시간 전 알림**

```
[내 브랜드명] 예약 4시간 전입니다 ⏰

#{이름}님, 오늘 일정을 잊지 마세요.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

링크 접속 테스트를 미리 해두시면 좋습니다.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

**④ 30분 전 알림**

```
[내 브랜드명] 예약 30분 전입니다 🔔

#{이름}님, 잠시 후 시작됩니다.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

지금 접속 준비해 주세요.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

### 검수에서 반려되지 않으려면

* **광고 문구는 쓰지 마세요.** 할인, 이벤트, 특가, "지금 신청하세요" 같은 표현이 있으면 반려돼요.
* **수신 사유를 밝히세요.** 위 문안의 마지막 줄이 그 역할을 해요. 지우지 마세요.
* 정보 전달 목적만 담으세요. 알림톡은 "고객이 한 행동에 대한 안내"만 허용돼요.
* 반려되면 사유가 자세히 오니, 지적된 문장만 고쳐 다시 신청하면 돼요.

### 버튼 추가(선택)

템플릿에 **웹링크 버튼**을 달 수 있어요. 예: `채널로 문의하기` → [1-4](01-kakao-channel.md#1-4-채널-주소-확인)의 채팅 URL. 버튼은 최대 5개까지 가능해요.

## B-3. KAKA에 발송 계정 연결

**KAKA ai 설정 > 알림톡 연결** 카드에서 해요. 카드 맨 위에 **전체 준비 상태**(준비됨 / 주의 / 미설정)와 알림 4종의 연결 상태가 표시돼요.

### ① 발송 서비스 자격 — 입력 3개

1. 발송 서비스 콘솔에서 **API 키**와 **API 시크릿**을 복사해 넣으세요.
2. **자격 확인**을 누르면 키·시크릿을 확인하고 이 계정의 **발신프로필 목록**을 불러와요. 드롭다운에서 고르세요(목록을 못 받으면 **발신프로필 ID**를 직접 입력하면 돼요).
3. **검증하고 저장**을 누르세요. 저장 전에 **무료 조회**로 확인하고, 통과했을 때만 저장돼요. 실패하면 사유가 그대로 표시돼요.
   * "API 키 또는 시크릿이 맞지 않아요" → 콘솔에서 다시 복사하세요.
   * "발신프로필 ID가 이 계정에 없어요" → B-1의 발신프로필 등록을 확인하세요.
   * "발송 서비스에 연결하지 못했어요(네트워크)" → 잠시 후 다시 시도하세요.
4. 저장되면 **API 키는 앞 4자리만**, **시크릿은 ••••로** 표시되고 다시 볼 수 없어요. 바꾸려면 **수정**을 눌러 세 값을 다시 입력하세요.

### ② 템플릿 연결(4종)

1. 저장이 끝나면 승인된 템플릿 목록을 불러와 **예약 확정 / 1일 전 / 4시간 전 / 30분 전** 슬롯에 드롭다운으로 연결해요.
2. 템플릿 이름(확정·하루·4시간·30분)으로 **자동 추천**돼 있어요. 바꿔도 돼요.
3. 각 템플릿에 **승인 / 검수중 / 검수 대기 / 반려** 배지가 붙어요. **승인**된 것만 고를 수 있어요.
4. **변수 검사** — 템플릿 본문의 `#{...}`를 검사해 허용된 3종 외 변수가 있으면 그 슬롯에 경고가 떠요. 경고가 있어도 저장은 되지만 준비 상태가 **주의**로 표시되고, 그 알림은 실제로 발송되지 않아요.
5. **템플릿 연결 저장**을 누르고, 카드 위 준비 상태가 **준비됨**이면 끝이에요.

{% hint style="info" %}
**웹훅 주소**와 **연결 암호**는 선택 항목의 **예약 알림톡 보내기**를 펼치면 있어요. 암호는 **암호 발급** 버튼으로 만들고, 화면을 벗어나면 다시 볼 수 없으니 바로 B-4에 넣으세요.
{% endhint %}

## B-4. 예약 알림 워크플로우 만들기

**자동화 > 워크플로우**에서 새 워크플로우를 만드세요(이름 예: `예약 알림`). 워크플로우 편집 화면은 영어로 표시돼요.

### 트리거

**Appointment Status**(예약 상태)

| 조건 | 값 |
| --- | --- |
| Event Type | normal |
| In calendar | 알림을 보낼 캘린더 선택 |
| Appointment status is | confirmed |

### 구성(액션 7개)

```
① Webhook  (예약 확정)
② Wait     1일 전까지 대기
③ Webhook  (1일 전)
④ Wait     4시간 전까지 대기
⑤ Webhook  (4시간 전)
⑥ Wait     30분 전까지 대기
⑦ Webhook  (30분 전)
```

### Webhook 4개 공통 설정

| 항목 | 값 |
| --- | --- |
| Method | POST |
| URL | **KAKA ai 설정**의 **웹훅 주소(POST)** |
| 헤더 이름 | `x-webhook-secret` |
| 헤더 값 | **KAKA ai 설정**의 **연결 암호** |

**Custom Data**에는 8개를 모두 넣어요. `kind`만 웹훅마다 달라요.

| key | value |
| --- | --- |
| kind | `confirm` / `remind_1d` / `remind_4h` / `remind_30m` |
| tenant_id | 설정 화면에 표시된 값 |
| contactId | `{{contact.id}}` |
| phone | `{{contact.phone}}` |
| name | `{{contact.name}}` |
| slot | `{{appointment.start_time}}` |
| meetingLink | `{{appointment.meeting_location}}` |
| calendarName | `{{calendar.name}}` |

{% hint style="warning" %}
`kind`를 빠뜨리거나 네 개가 모두 `confirm`이면 리마인드 시각에 확정 문구가 나가요. 반드시 다르게 넣으세요.
{% endhint %}

### Wait 3개 설정

| Wait | 기준 |
| --- | --- |
| 1일 전 | 예약 시작 **1440분 전** |
| 4시간 전 | 예약 시작 **240분 전** |
| 30분 전 | 예약 시작 **30분 전** |

각 Wait의 **If already passed**(이미 지난 경우) 옵션을 **다음 단계로 건너뛰기**로 설정하세요. 기본값인 "종료"로 두면, 내일 잡힌 예약에서 1일 전 시점이 이미 지났다는 이유로 **4시간 전·30분 전 알림까지 모두 취소**돼요. 마지막 30분 전 Wait만 "종료"로 두면 돼요.

저장한 뒤 **Publish**(게시)하세요.

## B-5. 테스트

1. 캘린더에 **3일 뒤**로 본인 예약을 하나 잡으세요.
2. 1~2분 안에 **예약 확정 알림톡**이 오면 성공이에요.
3. 확인한 뒤 예약은 취소해도 돼요.

리마인드까지 빨리 확인하려면 **35분 뒤**로 예약을 잡으세요. 확정 알림은 바로, 30분 전 알림은 약 5분 뒤에 와요(비용 약 26원).

### 알림톡이 안 올 때

| 증상 | 원인 |
| --- | --- |
| 아무것도 안 옴 | 워크플로우가 Draft(임시 저장) 상태 / 캘린더 조건 불일치 / 예약 상태가 confirmed가 아님 |
| 실패 기록이 남음 | 템플릿 검수 미완료 / 발송 서비스 잔액 부족 / 전화번호 없음 |
| 확정만 오고 리마인드가 안 옴 | Wait의 If already passed 설정 확인 |
| 리마인드에 확정 문구가 옴 | `kind` 값이 모두 `confirm`으로 되어 있음 |
| 임박한 예약인데 안 옴 | 정상이에요. 예약이 임박하면 해당 리마인드는 자동으로 건너뛰어요 |

{% hint style="info" %}
자동 건너뛰기 기준: 1일 전 알림은 12시간 이내, 4시간 전 알림은 2시간 이내, 30분 전 알림은 10분 이내.
{% endhint %}
