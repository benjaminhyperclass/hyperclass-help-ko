# KAKA AI — 카카오톡을 대화창으로

KAKA AI는 카카오톡 채널로 들어온 고객 문의를 **대화** 메뉴에서 그대로 주고받게 해 주는 앱이에요. 인스타그램 DM이 대화에 들어오는 것과 똑같이 동작한다고 생각하시면 됩니다.

* 고객이 카카오톡 채널에 말을 걸면 → **대화**에 뜹니다
* **대화**에서 답장을 쓰면 → 고객 카카오톡으로 갑니다
* 원하면 AI가 먼저 답하게 할 수도 있어요
* 예약 확정·리마인드를 알림톡으로 자동 발송할 수도 있어요

## 준비물

1. **카카오 비즈니스 채널** — 없으면 1단계에서 만듭니다
2. **카카오 i 오픈빌더 계정** — 카카오 계정으로 바로 가입돼요(무료)
3. **카카오 비즈월렛** — 고객 메시지를 받은 지 1분이 지난 뒤 답장하려면 필요해요. 3단계에서 만듭니다(없어도 기본 연결은 돼요)

{% hint style="info" %}
오픈빌더가 낯설어도 괜찮아요. 3단계에서 화면 순서대로 짚어 드려요. 코드를 쓰거나 개발 지식이 필요한 부분은 없고, 복사·붙여넣기만 하면 됩니다.
{% endhint %}

## 비용

| 항목 | 비용 | 어디서 차감 |
| --- | --- | --- |
| KAKA 앱 | **무료** | — |
| 고객이 말을 건 뒤 **약 1분 안에** 보낸 답장 | **0원** | — |
| 1분이 지난 뒤 보낸 답장 | 약 15원/건 | 카카오 비즈월렛 |
| 예약 알림톡(선택 B) | 약 8~13원/건 | 문자 발송 서비스 |
| AI 자동 응답(선택 D) | 요금제에 포함/추가 | 내 하이퍼클래스 계정 |

고객이 말을 건 뒤 **1분 안에 답장하면 발송비가 들지 않아요.** 1분이 지난 답장은 카카오 비즈월렛과 카카오 REST API 키가 있어야 나갑니다.
