# 카카오 커넥터 — 카카오톡 채팅을 대화창으로

**카카오 커넥터**(앱 마켓플레이스 이름: **KAKAO Connector (카톡채팅연결)**)는 카카오톡 채널로 들어온 손님 메시지를 하이퍼클래스 **대화** 메뉴에서 받고, 거기서 바로 답장하게 해 주는 **무료 앱**이에요. 인스타그램 DM이 대화에 들어오는 것과 똑같이 동작한다고 생각하시면 돼요.

* 손님이 카카오톡 채널에 말을 걸면 → **대화**에 새 메시지로 떠요
* **대화**에서 답장을 쓰면 → 손님 카카오톡으로 가요
* 처음 말을 건 손님에게는 이름과 휴대폰 번호를 여쭤봐서 **기존 고객 기록과 자동으로 이어** 줘요
* 원하면 **AI 에이전트가 먼저 답하고** 사람이 이어받게 할 수 있어요
* 예약 확정·리마인드를 **알림톡**으로 자동 발송할 수 있어요

설치하면 왼쪽 메뉴에 **카톡채팅연결**이 생기고, 그 화면(카카오톡 상담 연결)이 단계별로 안내해 줘요. 이 매뉴얼은 그 화면 옆에 띄워 두고 함께 보시면 돼요.

## 어떻게 동작하나요?

```
손님 카카오톡 ──▶ 카카오 채널 ──▶ 카카오 챗봇(오픈빌더) ──▶ 카카오 커넥터 ──▶ 하이퍼클래스 [대화]
                                                                              │
손님 카카오톡 ◀── 카카오 채널 ◀──────────── 카카오 커넥터 ◀──────────── 상담원·AI 답장
```

* **카카오 챗봇**(오픈빌더)은 답을 만들지 않아요. 손님이 보낸 말을 카카오 커넥터로 **넘겨주는 통로**예요.
* 답장은 **상담원**이 대화에서 직접 쓰거나, 켜 두었다면 **AI 에이전트**가 써요.
* 카카오톡 대화는 하이퍼클래스 안에서 **SMS(문자) 유형**으로 처리돼요. 그래서 워크플로우나 AI 에이전트를 설정할 때 채널 조건을 **SMS**로 고르면 카카오톡에도 똑같이 반응해요.

## 꼭 알아 둘 규칙 — "4분 안 첫 답장은 무료"

카카오톡은 손님이 먼저 말을 건 대화에만 답할 수 있어요(카카오 정책). 답장은 두 종류로 나뉘어요.

| 답장 | 비용 | 누구에게 가나요 |
| --- | --- | --- |
| 손님 메시지 1건마다 **약 4분 안에** 보낸 **첫 답장 1건** | **0원** | 모든 손님 |
| 약 4분이 지난 답장 · 같은 메시지에 **두 번째부터** 보낸 답장 | 건당 약 15원 (카카오 비즈월렛에서 차감) | **채널을 추가(친구)한 손님에게만** |

그래서 할 말은 **4분 안에 한 답장으로 모아** 보내는 게 가장 좋아요. 4분이 지난 답장을 보내려면 [늦은 답장 설정](06-late-reply.md)(비즈월렛·REST API 키)이 꼭 필요해요.

## 비용

| 항목 | 비용 | 어디서 차감되나요 |
| --- | --- | --- |
| 카카오 커넥터 앱 | **무료** | — |
| 4분 안 첫 답장 | **0원** | — |
| 4분이 지난 답장 · 두 번째부터 답장 | 약 15원/건 | 카카오 비즈월렛 |
| 예약 알림톡 (선택 B) | 약 8~13원/건 | 문자 발송 서비스(예: 솔라피) |
| 예약 알림 자동화 (선택 B) | 워크플로우 Custom Webhook 실행 요금 | 하이퍼클래스 요금제 |
| AI 자동 응답 (선택 D) | 요금제에 포함 또는 추가 | 하이퍼클래스 요금제 |

## 준비물

1. **카카오톡 채널** — 없으면 1단계에서 만들어요
2. **카카오 비즈니스 인증 (필수)** — 사업자등록증으로 신청해요. **1~2영업일**이 걸리니 가장 먼저 신청하세요
3. **카카오 i 오픈빌더 계정** — 카카오 계정으로 바로 가입돼요(무료)
4. **카카오 비즈월렛 (필수)** — 4분이 지난 답장 비용을 내는 지갑이에요. 1만 원이면 600건 이상 보낼 수 있어요
5. **카카오 디벨로퍼스 앱의 REST API 키** — 4분이 지난 답장에 써요

{% hint style="info" %}
오픈빌더가 낯설어도 괜찮아요. 코드를 쓰거나 개발 지식이 필요한 부분은 없고, 카톡채팅연결 화면의 **[복사]** 버튼으로 값을 복사해 붙여넣기만 하면 돼요.
{% endhint %}
