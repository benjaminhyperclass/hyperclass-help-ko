# 선택 C · 홈페이지에 카카오톡 버튼 달기

홈페이지나 랜딩 페이지의 채팅 버튼 목록에 **카카오톡 문의**를 한 줄 더 넣어요. 채팅 위젯이 없는 페이지에서는 오른쪽 아래에 카카오톡 버튼만 따로 떠요.

코드 한 덩어리를 붙여넣는 게 전부예요. 5분이면 돼요.

{% hint style="info" %}
코드는 항상 **KAKA ai 설정** 화면에서 복사하세요. 그 화면의 코드가 늘 최신이에요.
{% endhint %}

## C-1. 코드 복사

1. **KAKA ai 설정 > 선택 항목 > 홈페이지에 카카오톡 문의 버튼 달기**를 펼치세요.
2. 버튼 위치(목록 맨 위 / 맨 아래)를 고르세요. 한국 고객에게는 **맨 위**를 권해요.
3. **복사** 버튼을 누르세요.

## C-2. 붙여넣을 위치 찾기

붙여넣는 곳은 **페이지별 설정 안의 Tracking Code > Footer** 칸이에요.

1. 왼쪽 메뉴 **사이트**에서 **퍼널** 또는 **웹사이트**를 고르세요.
2. 카카오톡 버튼을 넣을 **페이지**를 찾으세요.
3. 그 페이지 줄 오른쪽 끝의 **⚙️ 설정** 아이콘을 누르세요.
4. 설정 창에서 **Tracking Code** 탭을 고르세요.
5. 칸이 **Header / Body / Footer** 세 개로 나뉘어 있어요. **Footer** 칸을 쓰세요.

## C-3. 붙여넣고 저장

1. **Footer** 칸에 복사한 코드를 **통째로** 붙여넣으세요.
2. **저장**을 누르세요.
3. 페이지를 **다시 게시**하세요.

## C-4. 확인

1. **시크릿 창**(새 프라이빗 창)으로 해당 페이지를 여세요. 일반 창에는 이전 버전이 캐시로 남아 있을 수 있어요.
2. 오른쪽 아래 채팅 버튼을 누르세요.
3. 채널 목록에 **카카오톡으로 문의하기**가 보이면 성공이에요.
4. 눌러서 카카오톡 채팅방으로 연결되는지도 확인하세요. PC에서는 카카오 로그인 화면을 거치고, 휴대폰에서는 카카오톡 앱이 바로 열려요.

## 여러 페이지에 넣으려면

Tracking Code는 **페이지마다 따로** 설정해요. 모든 페이지에 넣으려면 페이지별로 C-2~C-3을 반복하거나, **퍼널 전체 설정**에 같은 코드를 넣으면 그 퍼널의 모든 페이지에 적용돼요.

## 안 보일 때

| 증상 | 확인할 것 |
| --- | --- |
| 버튼이 아예 안 보여요 | 저장한 뒤 **다시 게시**했는지 / 시크릿 창으로 열었는지 |
| 채팅 위젯은 뜨는데 카카오만 없어요 | 코드를 Header가 아닌 **Footer** 칸에 넣었는지 |
| 카카오 버튼만 따로 떠요 | 그 페이지에 채팅 위젯이 없는 경우예요. 정상 동작이에요 |
| 눌러도 아무 일이 없어요 | 코드 안의 카카오 주소가 비어 있을 수 있어요. [위저드 1단계](02-install-app.md#2-2-위저드-1단계-검색용-아이디-저장)에서 검색용 아이디를 저장했는지 확인하세요 |
