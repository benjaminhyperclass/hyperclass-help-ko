# 선택 B · 예약 알림톡

예약 확정과 리마인드를 **알림톡**으로 자동 발송해요. 알림톡은 채널을 추가하지 않은 손님에게도 도착하지만, **카카오가 미리 검수한 문구만** 보낼 수 있어요.

필요한 것: **카카오 비즈니스 인증 채널**([1-2](01-kakao-channel.md)) · **문자 발송 서비스 계정**(예: 솔라피)

## 전체 흐름

```
1) 발송 서비스 가입          →  2) 발신프로필 등록(채널 연결) · 충전
   ↓                              ↓
3) 템플릿 4종 등록·검수 신청  →  4) 카톡채팅연결 5단계에 솔라피·템플릿 연결
   ↓                              ↓
5) 예약 알림 워크플로우 만들기 →  6) 테스트 예약으로 확인
```

**매장마다 자기 발송 계정과 자기 템플릿을 써요.** 다른 매장과 공유하지 않아요. 템플릿 검수에 1~3영업일이 걸리니, **검수를 기다리는 동안 나머지 설치를 먼저** 끝내 두세요.

## B-1. 발송 서비스 가입과 발신프로필

1. 문자 발송 서비스(예: 솔라피)에 가입하세요.
2. **카카오 → 발신프로필(채널) 등록**에서
   * 1단계에서 만든 채널의 **검색용 아이디**를 넣고
   * 채널 관리자 휴대폰으로 오는 **인증번호**를 넣으세요.
3. 발신프로필이 등록되면 그 채널로 알림톡을 보낼 수 있어요.
4. **잔액을 충전**해 두세요. 잔액이 없으면 발송이 실패해요.

## B-2. 템플릿 등록 ⚠️ 변수 규칙이 중요해요

**카카오 커넥터가 채워 주는 변수는 아래 3개뿐이에요.**

| 변수 | 들어가는 값 | 예시 |
| --- | --- | --- |
| `#{이름}` | 손님 이름 | 홍길동 |
| `#{상담일시}` | 예약 일시(한글로 자동 변환) | 2026년 9월 23일 (수) 오후 9:00 |
| `#{meeting_link}` | 화상 회의·장소 링크 | https://meet.google.com/abc-defg-hij |

{% hint style="danger" %}
**이 3개 외의 변수를 템플릿에 넣으면 발송이 실패해요.** `#{상호}`, `#{금액}`, `#{담당자}` 같은 변수는 값이 채워지지 않아요. 브랜드명처럼 고정된 내용은 변수가 아니라 **그냥 글자로** 적으세요.
{% endhint %}

### 등록할 템플릿 4종

검수 통과를 염두에 두고 쓴 문안이에요. `[내 브랜드명]`만 본인 브랜드로 바꿔 그대로 등록하세요. 템플릿 이름에 **확정 · 하루 · 4시간 · 30분**을 넣어 두면 나중에 슬롯에 자동으로 추천돼요.

**① 예약 확정 알림**

```
[내 브랜드명] 예약이 확정되었습니다 ✅

#{이름}님, 아래 일정으로 예약이 확정되었습니다.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

입장 시 이름을 실명으로 설정해 주세요.
궁금하신 점은 채널로 문의해 주세요.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

**② 1일 전 알림**

```
[내 브랜드명] 예약 하루 전입니다 ⏰

#{이름}님, 내일 일정을 잊지 마세요.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

일정 변경이 필요하시면 채널로 알려주세요.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

**③ 4시간 전 알림**

```
[내 브랜드명] 예약 4시간 전입니다 ⏰

#{이름}님, 오늘 일정을 잊지 마세요.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

링크 접속 테스트를 미리 해두시면 좋습니다.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

**④ 30분 전 알림**

```
[내 브랜드명] 예약 30분 전입니다 🔔

#{이름}님, 잠시 후 시작됩니다.

📅 일시: #{상담일시}
📍 접속 링크: #{meeting_link}

지금 접속 준비해 주세요.

본 메시지는 예약 신청 시 남겨주신 연락처로 발송되었습니다.
```

### 검수에서 반려되지 않으려면

* **광고 문구 금지** — 할인, 이벤트, 특가, "지금 신청하세요" 같은 표현이 있으면 반려돼요.
* **수신 사유를 밝히세요** — 문안 마지막 줄이 그 역할을 해요. 지우지 마세요.
* 정보 전달 목적만 담으세요. 알림톡은 "손님이 한 행동에 대한 안내"만 허용돼요.
* 반려되면 사유가 자세히 오니, 지적된 문장만 고쳐 다시 신청하면 돼요.

**버튼(선택)** — 템플릿에 **웹링크 버튼**을 최대 5개까지 달 수 있어요. 예: `채널로 문의하기` → [1-4](01-kakao-channel.md)의 채팅 URL

## B-3. 카톡채팅연결 5단계에 연결하기

카톡채팅연결 설정 화면 **5단계**(예약 알림톡)에서 해요.

### ① 솔라피 API 키·시크릿

1. [**솔라피 콘솔 ↗**]에서 **API 키**와 **API 시크릿**을 복사해 두 칸에 넣으세요.
2. 저장 전에 **무료 조회**로 값을 확인하고, 통과했을 때만 저장돼요. 실패하면 사유가 그대로 보여요.
   * "API 키 또는 시크릿이 맞지 않아요" → 콘솔에서 다시 복사
   * "발신프로필 ID가 이 계정에 없어요" → B-1의 발신프로필 등록 확인
   * "발송 서비스에 연결하지 못했어요(네트워크)" → 잠시 뒤 다시
3. 저장되면 API 키는 **앞 4자리만**, 시크릿은 ••••로 가려져 보이고 다시 볼 수 없어요. 바꾸려면 [**수정**]을 눌러 다시 넣으세요.

### ② 발신프로필

[**불러오기**]를 누르면 이 계정의 발신프로필을 불러와요. 1개면 바로 저장되고, 여러 개면 고른 뒤 [**불러오기**]를 한 번 더 누르세요. 목록을 못 받으면 **발신프로필 ID를 직접 넣을게요**를 펼쳐 넣으면 돼요.

### ③ 템플릿 검수·연결

1. 승인된 템플릿을 불러와 **예약 확정 / 1일 전 / 4시간 전 / 30분 전** 슬롯에 연결해요. 템플릿 이름으로 **자동 추천**되고, 바꾸려면 **템플릿 바꾸기**를 펼치세요.
2. 각 템플릿에 **승인 / 검수중 / 검수 대기 / 반려** 배지가 붙어요. **승인**된 것만 고를 수 있어요. 검수 중이면 승인 뒤 [**불러오기**]를 한 번 더 누르세요.
3. ★ **변수 검사** — 허용된 3개 외의 변수가 있으면 그 슬롯에 "이 템플릿의 #{xxx}는 값이 채워지지 않아 발송이 실패해요" 경고가 떠요. 경고가 있어도 저장은 되지만 준비 상태가 **주의**로 표시되고, 그 알림은 실제로 발송되지 않아요.
4. [**템플릿 연결 저장**]을 누르고 **전체 준비 상태**가 **준비됨**인지 확인하세요.
5. **테스트(약 10원)** — 내 휴대폰 번호를 넣고 발송 동의에 체크한 뒤 **[테스트 알림톡 보내기]** → 카톡에 오면 [**받았어요**]를 누르세요.

### ④ 예약 알림 자동화 연결

워크플로우에 넣을 **웹훅 주소**와 **웹훅 암호**가 여기 있어요.

* **[웹훅 주소 복사]** · **[헤더 이름 복사]**(`x-webhook-secret`) · **[웹훅 암호 복사]**
* 암호가 없으면 [**암호 발급**]을 누르세요. [**암호 재발급**]을 하면 워크플로우에 넣은 값도 새 값으로 바꿔야 해요.
* 웹훅 암호는 2단계의 **연결 암호와 다른 값**이에요.
* 워크플로우를 만든 뒤 [**시험 보내기**]로 주소와 암호를 확인할 수 있어요(실제 발송 없음).

## B-4. 예약 알림 워크플로우 만들기

화면의 **[자동화 열기 ↗]** 또는 **자동화 → 워크플로우**에서 새 워크플로우를 만드세요(이름 예: `예약 알림`).

### 트리거 — Appointment Status

| 조건 | 값 |
| --- | --- |
| Event Type | normal |
| In calendar | 알림을 보낼 캘린더 |
| Appointment status is | confirmed |

### 구성 — 액션 7개

```
① Custom Webhook  (예약 확정)
② Wait            1일 전까지 대기
③ Custom Webhook  (1일 전)
④ Wait            4시간 전까지 대기
⑤ Custom Webhook  (4시간 전)
⑥ Wait            30분 전까지 대기
⑦ Custom Webhook  (30분 전)
```

### Custom Webhook 4개 공통 설정

| 항목 | 값 |
| --- | --- |
| Method | POST |
| URL | 카톡채팅연결의 **웹훅 주소** |
| 헤더 이름 | `x-webhook-secret` |
| 헤더 값 | 카톡채팅연결의 **웹훅 암호** |

**Custom Data** — 8개를 모두 넣어요. `kind`만 웹훅마다 달라요.

| key | value |
| --- | --- |
| kind | `confirm` / `remind_1d` / `remind_4h` / `remind_30m` |
| tenant_id | 설정 화면에 보이는 값 |
| contactId | `{{contact.id}}` |
| phone | `{{contact.phone}}` |
| name | `{{contact.name}}` |
| slot | `{{appointment.start_time}}` |
| meetingLink | `{{appointment.meeting_location}}` |
| calendarName | `{{calendar.name}}` |

{% hint style="warning" %}
`kind`를 빠뜨리거나 네 개가 전부 `confirm`이면 리마인드 시각에 확정 문구가 나가요. **웹훅마다 반드시 다르게** 넣으세요.
{% endhint %}

### Wait 3개 설정

| Wait | 기준 |
| --- | --- |
| 1일 전 | 예약 시작 **1440분 전** |
| 4시간 전 | 예약 시작 **240분 전** |
| 30분 전 | 예약 시작 **30분 전** |

각 Wait의 **"이미 지난 경우(If already passed)"** 옵션을 **다음 단계로 건너뛰기**로 바꾸세요. 기본값 "종료"로 두면 내일 잡힌 예약에서 1일 전 시점이 이미 지났다는 이유로 **4시간 전·30분 전 알림까지 전부 취소**돼요. 마지막 30분 전 Wait만 "종료"로 두면 돼요.

저장한 뒤 **Publish**하세요. Custom Webhook 실행에는 하이퍼클래스 요금제에 따른 워크플로우 실행 요금이 들어요.

### 예약 취소 시 리마인드 멈추기 ⚠️ 꼭 함께 만드세요

`예약 알림` 워크플로우는 예약이 **취소돼도 Wait에서 그대로 기다렸다가** 리마인드를 보내요. 취소한 손님에게 "예약 하루 전입니다"가 가지 않도록 워크플로우를 하나 더 만드세요(이름 예: `예약 취소 → 알림 중지`).

| 구성 | 값 |
| --- | --- |
| 트리거 | **Appointment Status** · In calendar = `예약 알림`과 같은 캘린더 · Appointment status is = **cancelled** |
| 액션 | **Remove from Workflow** → `예약 알림` |

저장한 뒤 **Publish**하세요. 예약은 지우지 말고 **상태를 취소(cancelled)로** 바꾸세요. 예약을 삭제했을 때 이 워크플로우가 실행되는지는 아직 확인되지 않았어요.

### 예약 시간을 바꿀 때 ⚠️ 자동 확정이 꺼진 캘린더

캘린더의 **자동 확정이 꺼져 있으면** 예약 시간을 바꾸는 순간 상태가 **미확정**으로 돌아가요. **바꾼 뒤 반드시 다시 확정**(confirmed)으로 저장하세요. 다시 확정해야 새 시간으로 확정 알림톡이 다시 나가고 리마인드가 새로 걸려요. 다시 확정하지 않은 예약에는 리마인드가 나가지 않아요(확정되지 않은 시간으로 안내하지 않도록 건너뛰어요).

설정 화면 5단계에 **예약 캘린더** 줄이 보이면 이 경우에 해당한다는 뜻이에요.

## B-5. 테스트

1. 캘린더에 **3일 뒤**로 본인 예약을 하나 잡으세요.
2. 1~2분 안에 **예약 확정 알림톡**이 오면 성공이에요.
3. 확인 뒤 예약을 취소할 때는 `예약 취소 → 알림 중지` 워크플로우가 켜져 있어야 리마인드가 나가지 않아요. 그 워크플로우가 없다면 `예약 알림` 워크플로우의 **Enrollment History**에서 본인을 빼세요.

리마인드까지 빨리 보려면 **35분 뒤**로 예약을 잡으세요. 확정 알림이 바로, 30분 전 알림이 약 5분 뒤에 와요(비용 약 26원). 캘린더에 최소 예약 간격이 있거나 자동 확정이 꺼져 있으면 예약 페이지로는 35분 뒤 예약이 안 되거나 확정 알림이 나가지 않아요. 이때는 **캘린더에서 직접 예약을 만들고 상태를 confirmed로** 저장하세요.

## 알림톡이 안 올 때

| 증상 | 원인 |
| --- | --- |
| 아무것도 안 와요 | 워크플로우가 Draft 상태 / 캘린더 조건 불일치 / 예약 상태가 confirmed가 아님 |
| 실패 기록이 남아요 | 템플릿 검수 미완료 / 발송 서비스 잔액 부족 / 전화번호 없음 |
| 확정만 오고 리마인드가 안 와요 | Wait의 "이미 지난 경우" 설정 |
| 리마인드에 확정 문구가 와요 | `kind`가 전부 `confirm` |
| 취소한 예약에 리마인드가 와요 | `예약 취소 → 알림 중지` 워크플로우가 없거나 Draft |
| 임박한 예약인데 안 와요 | 정상이에요. 1일 전은 12시간 이내, 4시간 전은 2시간 이내, 30분 전은 10분 이내면 그 리마인드는 자동으로 건너뛰어요 |
