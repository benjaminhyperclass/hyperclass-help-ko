## 자주 막히는 곳

**1. 배포를 안 눌렀어요**
오픈빌더는 저장과 배포가 따로예요. 바꿀 때마다 왼쪽 메뉴 [배포]에서 배포하세요. ([3단계 ④](03-openbuilder-bot.md))

**2. 운영 채널을 연결하지 않았어요**
봇을 만들고 배포해도 채널에 연결하지 않으면 메시지가 오지 않아요. ([3단계 ①](03-openbuilder-bot.md))

**3. 폴백 블록의 Callback 설정이 꺼져 있어요**
꺼져 있으면 손님 메시지가 연결되지 않아요. ([3단계 ③](03-openbuilder-bot.md))

**4. 폴백 블록이 스킬데이터가 아니에요**
봇 응답이 "스킬데이터 사용" 하나여야 해요. ([3단계 ③](03-openbuilder-bot.md))

**5. 채널 '채팅' 스위치가 켜져 있어요**
손님이 "상담 연결"을 누르거나 채팅방에 다시 들어오면 상담 모드가 되어 챗봇이 불리지 않아요. 운영시간 밖에도 불리지 않아요. ([1-3](01-kakao-channel.md))

**6. 헤더 값에 공백이 섞였어요**
붙여넣을 때 따라온 보이지 않는 문자 때문에 카카오가 조용히 실패해요. 헤더 줄을 지우고 다시 입력하세요. ([3단계 ②](03-openbuilder-bot.md))

**7. 휴대폰 카카오톡으로 보내지 않았어요**
스킬 테스트는 서버 연결만 봐요. 연결 확인은 실제 카카오톡에서 보내야 통과해요. ([4단계](04-verify-and-test.md))

**8. 채널 주소에 검색용 아이디를 넣었어요**
채널 URL은 `pf.kakao.com/_`로 시작해요. ([1-4](01-kakao-channel.md))

**9. 다른 자동응답이 먼저 답해요**
워크플로우나 대화 AI가 무료 답장 창을 먼저 써서 상담원 답장이 유료가 되거나 전달되지 않아요. ([5단계](05-reply-mode.md))

**10. 관리자 카카오 계정으로 시험했어요**
관리자 계정으로는 손님 화면을 볼 수 없어요. 채널을 관리하지 않는 다른 카카오 계정으로 시험하세요. ([4단계](04-verify-and-test.md))

**11. 비즈월렛·REST API 키가 없거나, 친구가 아닌 손님에게 늦게 답장했어요**
4분이 지난 답장과 두 번째부터 답장은 비즈월렛·REST API 키가 있어야 나가고, 채널을 추가한 손님에게만 전달돼요. 답장 옆 ⚠️에 사유가 보여요. ([6단계](06-late-reply.md))

**12. 알림톡 템플릿이 검수 중이거나, 워크플로우가 Draft이거나, kind가 전부 같아요**
템플릿에는 `#{이름}` `#{상담일시}` `#{meeting_link}` 외의 변수를 넣지 마세요. Wait의 "이미 지난 경우"는 다음 단계로 건너뛰기로 두세요. ([선택 B](10-booking-alimtalk.md))

## 자주 묻는 질문

**카카오 커넥터 앱은 유료인가요?**
앱은 무료예요. 손님 메시지마다 4분 안 첫 답장 1건도 무료예요. 늦은 답장(건당 약 15원)은 카카오 비즈월렛에서, 알림톡(건당 약 8~13원)은 문자 발송 서비스에서 차감돼요. ([비용](README.md))

**왜 손님에게 이름과 휴대폰 번호를 묻나요?**
카카오톡은 손님 전화번호를 알려 주지 않아요. 번호를 받아야 기존 고객 기록과 자동으로 이어지고, 예약 알림톡도 보낼 수 있어요. 대화당 최대 두 번만 여쭤보고, 답이 없어도 대화는 그대로 이어져요.

**AI 답변은 왜 15초쯤 걸리나요?**
AI가 답을 만드는 시간이에요. 카카오톡과 대화 사이 전달은 2~3초이고, 나머지는 AI 생성 시간이라 정상 범위예요. 사람이 직접 답하는 방식에서는 보내기를 누르면 바로 가요.

**AI 답변 비용은 누가 내나요?**
AI는 하이퍼클래스 요금제에서 처리돼요. 카카오 커넥터 앱 자체는 무료예요.

**카카오 채널 여러 개를 연결할 수 있나요?**
한 워크스페이스에 채널 하나예요. 채널이 여럿이면 워크스페이스를 나눠 설치하세요.

**손님에게 먼저 카카오톡을 보낼 수 있나요?**
손님이 먼저 말을 건 대화에만 답할 수 있어요(카카오 정책). 먼저 연락해야 한다면 알림톡([선택 B](10-booking-alimtalk.md))을 쓰세요.

**알림톡과 일반 답장은 뭐가 다른가요?**
알림톡은 검수된 문구만, 정해진 상황에서 보내요. 대신 채널을 추가하지 않은 손님에게도 도착해요. 일반 답장은 자유롭게 쓸 수 있지만 손님이 먼저 말을 건 대화에서만 가능해요.

**대화 내용은 어디에 남나요?**
**대화** 메뉴와 연락처 기록에 남아요. 다른 채널과 같아요.

**워크플로우에서 카카오톡 손님을 어떻게 골라내나요?**
카카오톡 대화는 SMS 유형으로 들어와요. 채널 조건을 SMS로 두고, 필요하면 `카카오채널` 태그로 한 번 더 걸러 주세요.

**챗봇 설정을 바꾸면 연결이 끊기나요?**
스킬 주소나 봇 ID를 바꾸면 끊겨요. 바꾼 뒤 배포하고 [연결 확인](04-verify-and-test.md)을 다시 하세요.

**갑자기 메시지가 안 들어와요. 설정은 안 건드렸는데요.**
카카오 쪽 장애일 수 있어요. [4단계 체크리스트](04-verify-and-test.md) 9번으로 확인하세요. 카카오 장애라면 복구되면 자동으로 다시 들어와요.

**연결을 끊고 싶어요.**
카톡채팅연결 완료 화면 맨 아래 **연결 해제**에서 계정 이름을 입력하고 [**연결 해제 실행**]을 누르세요. 앱 자체를 지우려면 앱 마켓플레이스에서 제거하면 돼요.
