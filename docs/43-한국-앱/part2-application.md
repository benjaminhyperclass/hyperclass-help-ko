# Part 2. 토스페이먼츠 신청 🟡

## 2-1. 전자계약 신청 (MID마다 반복)

1. **tosspayments.com** 접속 → 우측 상단 **[이용 신청하기]** (또는 [전자결제 신청하기])
2. 회원가입/로그인 → 대표자(또는 대리인) 휴대폰 본인인증
3. 홈페이지 구축 방식: **직접 구축** 선택 (하이퍼클래스가 기술 연동을 대행하므로 호스팅사 경로가 아닙니다. "직접 연동 = Y")
4. 패키지 선택:
   - 일반결제 MID → **기본결제 패키지**
   - 빌링 MID → **빌링(정기결제)**
   - PayPal MID → **해외결제/PayPal** (신청하는 경우만)
5. Part 1에서 준비한 정보 입력 + 서류 업로드 (사진 가능)
6. 결제 단계에서 **"나중에 결제"** 선택 → 가입비/연회비 면제 처리
7. 신청 완료 → 영문 상점아이디(MID) 발급 확인

> 💡 신청 직후 "미리 오픈"이 안내될 수 있습니다 — 계약 완료 전에도 신용/체크카드 결제가 선오픈되는 서비스입니다(최대 1개월 유지, 기간 내 계약을 완료해야 함). 활용하되, 카드사 심사 완료 전까지는 나머지 결제수단이 열리지 않는다는 점을 기억하세요.

## 2-2. ★ 온라인 강의 협약서 (강의·구독 업종 필수)

**강의, 교육 콘텐츠, 구독 서비스를 판매한다면 이 단계 없이는 심사가 끝나지 않습니다.** 실제 심사에서 "협약서 서명 요청" 회신을 받은 사례가 있습니다 — 미리 처리하면 심사 기간이 단축됩니다.

1. 신청 후 토스페이먼츠에서 **온라인 강의 업종 확약서(협약서)** 양식을 안내합니다 (신청 화면 다운로드 또는 담당자 메일)
2. 내용 확인 → 서명(전자서명 또는 날인) → 안내받은 방법으로 회신
3. 모두싸인 등 전자서명 요청 메일이 오는 경우도 있으니 **신청에 쓴 이메일 수신함을 매일 확인**하세요

> 이 협약서는 환불 분쟁이 잦은 교육 업종의 소비자 보호 약정입니다. 환불 규정(Part 0-3)과 내용이 일치해야 합니다.

## 2-3. 보증보험 (해당 시)

- **월 정산 한도 1,000만 원 미만 신규 가맹점은 보증보험이 면제**됩니다 — 대부분 처음엔 가입 불필요
- 정산 한도를 늘리거나 고액·장기 상품을 팔면 심사 후 토스페이먼츠가 담보금액을 안내합니다 (보험료는 담보금액의 약 1%, 1년 단위 갱신)
- 안내를 받으면 서울보증보험 제휴처(예: 인산아이비, 플러스)에서 가입 후 증권을 회신하면 됩니다

## 2-4. 계약 완료 확인

- 서류·홈페이지 심사(평균 5일) 통과 → **계약 완료** 메일 수신
- 계약이 완료돼도 **카드사 심사 전에는 운영(라이브) 결제가 열리지 않습니다.** 다음 단계(앱 연동 → 테스트 → 결제경로 제출)로 카드사 심사를 준비합니다
