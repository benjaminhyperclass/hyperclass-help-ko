# Part 0. 홈페이지 사전 점검 🟡

심사 반려의 대부분은 신청서가 아니라 **홈페이지**에서 나옵니다. 신청 전에 아래 4가지를 반드시 완료하세요.

## 0-1. 판매 상품이 홈페이지에 보이는가

- 실제 구매 가능한 상품/서비스 **1개 이상**이 페이지에 노출되어야 합니다
- 상품명, 이미지, 가격, 상세 설명이 있어야 하며 "준비 중", "0원", "가격 문의" 상품은 심사 불가입니다
- 무형 서비스(강의·컨설팅 등)는 **서비스 제공 기간을 상품 페이지에 명시**하세요 (예: "12주 과정")

> ⚠️ 가격 관련 제한: 결제 금액을 구매자가 임의 입력하는 방식, 500만 원 이상 고가 단일 상품은 카드사 등록 심사가 제한될 수 있습니다. 해당되면 신청 전에 문의하세요.
> ⚠️ 서비스 기간 제한: 무형 서비스는 제공 기간 6개월 초과 시 가상계좌 사용 불가, 12개월 초과 시 입점이 불가합니다. 연간 상품은 12개월 이내로 설계하세요. (선불 연간 플랜이 1년을 넘지 않도록 주의)

## 0-2. 하단(footer)에 사업자 정보 6종이 있는가

홈페이지 모든 페이지 하단에 아래 6가지가 **사업자등록증과 글자 하나까지 동일하게** 표기되어야 합니다.

1. 상호명
2. 대표자명
3. 사업자등록번호
4. 사업장 주소
5. 유선 전화번호 (070·0505·080·휴대폰 가능)
6. 통신판매업 신고번호

> ⚠️ 통신판매업 신고번호가 없으면 KB국민카드 심사가 제외됩니다 (간이과세자·비영리·공공기관은 면제).

## 0-3. 환불 규정이 명시되어 있는가

- 이용약관 또는 별도 환불정책 페이지에 환불 조건·기한·방법이 명시되어야 합니다
- **정기결제(구독) 상품을 팔 경우, 구독 해지·청약철회 규정을 반드시 포함**하세요 — 빌링 심사에서 확인하는 항목입니다
- 업종별 환불 규정 템플릿은 [부록 1] 참고

## 0-4. 결제까지의 경로가 실제로 동작하는가

- 상품 → 주문서 → 결제 버튼까지 클릭으로 도달 가능해야 합니다
- 회원 전용이라면 **심사용 테스트 계정(ID/PW)** 을 준비하세요 — 심사관이 로그인해서 확인합니다
- 비회원 구매가 가능하면 그 경로를 명시하세요

**✅ Part 0 체크리스트**

- [ ] 구매 가능한 상품 1개 이상 노출 (이미지·가격·설명 포함)
- [ ] footer 사업자 정보 6종, 사업자등록증과 동일
- [ ] 환불 규정 페이지 존재 (+ 구독 해지 규정)
- [ ] 상품 → 결제까지 클릭 도달 가능 / 테스트 계정 준비
- [ ] 무형 서비스 제공 기간 12개월 이내
