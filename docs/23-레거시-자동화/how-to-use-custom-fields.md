# 커스텀 필드 사용하기

커스텀 필드는 이름, 전화번호, 이메일 같은 기본 필드 외에 연락처나 기회에 대한 정보를 더 저장하는 기능이에요. 이 문서에서는 커스텀 필드의 개념, 연락처 필드와 기회 필드의 차이, 폴더 정리, 만드는 방법을 안내해요.

---

## 커스텀 필드란?

커스텀 필드에는 이름, 전화번호, 이메일 같은 기본 필드로 담기지 않는 정보를 저장할 수 있어요. 폼, 설문, 자동화 워크플로우, 파이프라인에서 우리 비즈니스에 맞는 핵심 데이터를 모으고 활용할 수 있어요.

---

## 커스텀 필드의 장점

커스텀 필드를 쓰면 데이터 수집, 세분화, 자동화를 유연하게 할 수 있어요.

- 맞춤 데이터 수집: 리드 유형, 예산 범위, 선호 연락 방법처럼 우리 비즈니스에 필요한 정보를 모을 수 있어요.
- 여러 도구에서 활용: 폼, 설문, 워크플로우, 파이프라인 어디에서나 커스텀 필드를 쓸 수 있어요.
- 자동화 개인화: 병합 필드로 필드 값을 문자, 이메일, 내부 알림에 넣어 맞춤 메시지를 보낼 수 있어요.
- 연락처 쉽게 세분화: 커스텀 필드 데이터를 기준으로 스마트 리스트를 만들거나 워크플로우를 필터링할 수 있어요.
- 체계적인 정리: 관련 있는 필드를 폴더로 묶으면 연락처와 기회 레코드를 깔끔하게 관리할 수 있어요.
- 핵심 정보 표시: 중요한 커스텀 필드 값을 기회 카드나 알림에 바로 보여 줄 수 있어요.

---

## 연락처 커스텀 필드와 기회 커스텀 필드의 차이

데이터를 정돈해서 잘 활용하려면 알맞은 유형의 커스텀 필드를 고르는 게 중요해요. 하이퍼클래스에서는 연락처 커스텀 필드와 기회 커스텀 필드, 두 가지 유형을 만들 수 있어요. 비슷해 보여도 쓰임새와 사용하는 위치가 달라요.

연락처 커스텀 필드는 개인 한 명에게 연결돼요. 리드 유형(예: 구매자 또는 판매자), 생일, 선호 연락 방법, 유입 경로 같은 개인 정보를 저장할 때 쓰세요. 이 필드는 연락처 레코드에 표시되고, 폼, 설문, 연락처 워크플로우, 스마트 리스트에서 쓸 수 있어요. 병합 필드로 메시지를 개인화할 때도 쓸 수 있어요.

기회 커스텀 필드는 특정 딜, 즉 영업 기회에 연결돼요. 예산 범위, 긴급도, 계약까지 걸리는 기간, 부동산 유형처럼 딜별 정보를 담을 때 쓰세요. 이 필드는 기회 레코드 안에서만 표시되고, 파이프라인 보기, 기회 워크플로우, 딜 단위 리포팅이나 자동화에서 쓰여요.

{% hint style="info" %}
연락처 필드나 기회 필드로 한 번 만들면 다른 유형으로 바꿀 수 없어요.
{% endhint %}

## 폴더로 커스텀 필드 정리하기

필드를 정리해 두면 레코드 안에서 데이터를 더 쉽게 찾아 쓸 수 있어요.

폴더는 레코드 레이아웃에서 하나의 섹션으로 표시돼요. 관련 있는 커스텀 필드를 폴더로 묶어 보세요.

폴더를 만드는 방법은 다음과 같아요.

1. **설정 > 커스텀 필드**로 이동하세요.
2. 페이지 위쪽의 객체 선택기에서 관리할 객체를 고르세요.
3. **폴더** 탭을 여세요.
4. **폴더 만들기**를 클릭하세요.
5. 폴더 이름을 입력하세요.
6. **만들기**를 클릭하세요.  
   폴더를 만든 뒤에는 커스텀 필드를 이 폴더에 넣어 정리할 수 있어요.

![폴더 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049900396/original/PCF0QM0G-of9ERI8GPRYhxJPesPmgYofaw.png?1752609459)

## AI에게 문의로 커스텀 필드 관리하기

**AI에게 문의**(Ask AI)로 일상 언어로 요청해서 커스텀 필드를 만들고, 수정하고, 관리할 수도 있어요.

**AI에게 문의**는 필드 이름으로 커스텀 필드를 찾기 때문에 Field ID를 알려 주지 않아도 돼요.

예: “Boat Size를 Large로 업데이트해 줘.”

**AI에게 문의**는 연락처, 기회, 사용자 지정 객체에 연결된 커스텀 필드를 지원해요. 선택 목록 같은 필드는 필요하면 새 값을 적용하기 전에 선택 가능한 옵션을 먼저 관리해요. 커스텀 필드나 필드 값을 바꾸기 전에 승인을 요청할 수도 있어요.

## 커스텀 필드 만드는 방법

다음 단계를 따라 서브 계정에서 커스텀 필드를 만들고 정리해 보세요.

### 1단계: **설정 > 커스텀 필드**로 이동

서브 계정에서 **설정**을 클릭한 다음 **커스텀 필드**를 클릭하세요.

![설정 > 커스텀 필드 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049899570/original/Yh9Qi_nPEsGdQ6sTnTPWqfsfYOoqiPMDKw.jpeg?1752607385)

### 2단계: 객체 선택

페이지 위쪽의 객체 선택기에서 관리할 객체를 고르세요.

### 3단계: **필드** 탭 열기

**필드** 탭에서 기존 필드를 확인하고 새 필드를 만들 수 있어요.

![필드 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069289224/original/FCj3FKJDzVDpKkC5YnjnnlwgJD-QxfL5Sw.png?1776338503)

### 4단계: **필드 만들기** 클릭

페이지 오른쪽 위에 있는 **필드 만들기**를 클릭하세요.

### 5단계: **필드 유형 선택**

만들려는 필드 유형을 고르세요.

![필드 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069290219/original/WlNtThFx6snR4gViN1jaJQJGxgatzCMoPQ.png?1776338844)

### 6단계: 필드 세부 정보 입력

필드 이름을 입력하고, 필요하면 폴더도 선택하세요.

![필드 세부 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069290765/original/6zaShf6HHJz7SAL7gro4_9WumqfukG6YWw.png?1776339089)

### 7단계: **실시간 미리보기** 확인

**실시간 미리보기** 패널에서 필드가 어떻게 보일지 확인하세요.

![실시간 미리보기 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069291322/original/EPYVFabzkOzqPJKnuMsnoK2DdkBzTkKCUA.png?1776339395)

### 8단계: 필드 만들기

**커스텀 필드 만들기**를 클릭하면 필드가 저장돼요.

![커스텀 필드 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069291497/original/LEN3EzAyraO2t3sfRVZy7T0pi0QgOfAHSQ.png?1776339485)

### 커스텀 필드 페이지 사용하기

커스텀 필드 페이지는 레이아웃이 새로 바뀌어서 필드를 더 효율적으로 관리할 수 있어요.

1. 페이지 위쪽의 객체 선택기에서 지원하는 객체 사이를 전환하세요.
2. **필드** 탭에서 커스텀 필드를 확인하고 관리하세요.
3. **폴더** 탭에서 폴더를 만들고 관리하세요.
4. 열 기준으로 표를 정렬하면 필드를 더 빨리 찾을 수 있어요.
5. 필드 목록의 아이콘으로 특별한 필드 상태를 확인하세요.

### 선택형 필드에서 옵션 삭제하기

오래됐거나 잘못된 필드 옵션을 삭제하면 사용자 지정 객체와 회사 데이터를 깔끔하게 유지할 수 있어요. 해당 옵션을 이미 쓰고 있는 레코드의 기존 값은 그대로 남아요. 이 기능은 **Dropdown**(드롭다운), **Multi-select**(다중 선택), **Radio**(라디오), **Checkbox**(체크박스) 필드에서 지원돼요.

1. 서브 계정에서 **설정 > 커스텀 필드**로 이동하세요.
2. 해당하는 **사용자 지정 객체** 또는 **회사**를 선택하세요.
3. 수정할 **Dropdown**, **Multi-select**, **Radio**, **Checkbox** 필드를 여세요.
4. 삭제할 옵션을 삭제하세요.
5. 이미 레코드에서 쓰고 있는 옵션이면, 삭제 전에 표시되는 영향받는 레코드 수를 확인하세요.
6. 삭제를 확인하세요.

옵션을 삭제하면 다음과 같이 동작해요.

- 이미 그 옵션을 쓰는 기존 레코드는 값을 그대로 유지하고 표시해요.
- 삭제한 옵션은 새 레코드에서 선택할 수 없어요.
- 삭제한 옵션은 새 필터나 워크플로우 조건을 만들 때 선택할 수 없어요.
- 삭제한 값을 이미 참조하는 기존 필터, 스마트 리스트, 워크플로우 조건은 계속 작동해요.

{% hint style="info" %}
연락처 필드와 기회 필드는 이미 옵션 삭제를 지원해요. 이번 개선으로 사용자 지정 객체와 회사에서도 같은 방식으로 쓸 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 연락처 필드를 기회 필드로(또는 그 반대로) 바꿀 수 있나요?
아니요. 올바른 객체 유형으로 필드를 다시 만들어야 해요. 필드는 만든 뒤에 객체를 바꿀 수 없어요.

### 어떤 유형의 필드를 만들 수 있나요?
**Short Text**(짧은 텍스트), **Long Text**(긴 텍스트), **Dropdown**, **Date Picker**(날짜 선택), **Phone**(전화번호), **Email**(이메일), **Radio Select**(라디오 선택), **Checkbox Group**(체크박스 그룹), **URL** 등을 만들 수 있어요.

### 폼이나 워크플로우에 필드가 보이지 않아요.
객체 유형이 사용하려는 곳과 맞는지 확인하세요. 폼과 연락처 워크플로우에는 연락처 필드만 표시돼요.

### Dropdown (multiple) 커스텀 필드에는 옵션을 몇 개까지 넣을 수 있나요?
**Dropdown (multiple)** 필드에는 옵션을 많이(50개 이상) 넣을 수 있어서 사실상 제한이 없어요.
