# "ZIP Code Check Failed for Your Card" 배너 해결하기

결제 수단을 추가할 때 **ZIP Code Check Failed for Your Card**(카드의 ZIP 코드 확인 실패) 배너가 나타나면 이 문서를 따라 해 보세요. 배너가 나타나는 이유와 ZIP 코드를 바로잡는 방법, 그래도 해결되지 않을 때 할 일을 안내해요.

## 배너가 나타나는 이유

결제 수단을 추가하면 하이퍼클래스는 결제 서비스 제공업체를 통해 ZIP 코드를 확인해요. 이 확인은 제공업체의 판단에 따라 이루어지고, 도난 카드 공격을 막기 위한 추가 보안 절차예요. 입력한 ZIP 코드가 카드에 등록된 ZIP 코드와 다르면 이 배너가 나타나요.

![ZIP 코드 확인 실패 배너 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042418723/original/_DH5EcNVzeFlBGCX1REFxZMYMHtlMHhy1w.png?1740739001)

## ZIP 코드를 수정해 문제 해결하기

기본 결제 수단에 입력한 ZIP 코드가 은행 명세서에 있는 ZIP 코드와 같은지 확인하세요. 다음 순서로 결제 정보를 수정해요.

1. 계정의 **청구/결제** 페이지로 이동하세요.

   ![청구/결제 페이지 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042418298/original/f8poN9D2AlAtxmej0ptNdacGZ_9gINAfwQ.png?1740738701)

2. **결제** 탭을 선택한 다음, 결제 수단의 편집 아이콘을 클릭하세요.

   ![결제 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042418271/original/WH62lr4CyD7T-W0L2iqB52wKszXcKNtOpA.png?1740738684)

   ![결제 수단 편집 아이콘 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042418227/original/IPKliuRZ-upUNkEgQlruc6TdoDFC6lYmGQ.png?1740738659)

3. **새 카드 추가**를 클릭하세요.

   ![새 카드 추가 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042418378/original/2AnI0l_WFqXLKipttnjMhq1j68-g4kxNsQ.png?1740738774)

4. 지금 쓰는 카드 번호와, 은행 명세서에 있는 올바른 ZIP 코드를 입력하세요.

   ![카드 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042418439/original/NeVDg6BLYO0wiYq4T6v5nnrSix3OrRaMXQ.png?1740738803)

   ![카드 정보 입력 완료 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042408639/original/iP9PCJ1hPGehj2WVnTAfcReTneQaQN8DLA.png?1740732146)

{% hint style="info" %}
카드 번호는 같고 ZIP 코드만 다르면, 새로 입력한 카드가 기존 카드를 대체해요.
{% endhint %}

```
참고: 수정해야 하는 ZIP 코드는 카드 정보에 등록된 ZIP 코드예요. 청구 주소의 ZIP 코드가 아니에요.
```

## 문제가 계속될 때

올바른 ZIP 코드를 입력했는데도 오류가 계속 나타나면 다음 순서로 진행하세요.

1. **지원 티켓 등록**: 하이퍼클래스 고객지원 팀에 문의하세요.
2. **은행 명세서 일부 제출**: 카드 번호 마지막 4자리와 해당 ZIP 코드가 보이는 문서를 요청할 수 있어요.

   {% hint style="info" %}
   은행 명세서 전체를 보낼 필요는 없어요. 필요한 정보가 보이는 부분만 보내 주세요.
   {% endhint %}

3. 하이퍼클래스가 결제 서비스 제공업체에 이 문제를 전달해 추가 확인을 거쳐 해결해요.
