# 계정 일시중지 기능 안내

하이퍼클래스를 잠시 쉬어야 할 때, 계정을 처음부터 다시 만들지 않아도 돼요. 일시중지 요금제를 쓰면 월 $27에 핵심 계정 데이터와 설정을 보관하고, 플랫폼 이용만 멈출 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 계정 일시중지 기능이란?

계정 일시중지는 에이전시 관리자를 위한 기능이에요. 하이퍼클래스 구독은 당분간 필요 없지만 핵심 계정 설정과 데이터는 남겨 두고 싶을 때 쓰세요.

계정이 일시중지된 동안에는 에이전시 사용자와 서브 계정이 플랫폼에 접속할 수 없어요. 지원되는 데이터, 설정, 구성은 그대로 보관되어 나중에 재활성화할 때 쓸 수 있어요. 일시중지 요금제는 월 $27이고, 필요할 때 재활성화하거나 변경하거나 해지할 수 있어요.

일시중지는 하이퍼클래스 구독 해지와 달라요. 해지한 계정은 90일 동안 데이터 보관 기간에 들어가요. 이 기간 안에 재활성화하지 않으면 에이전시 계정, 서브 계정, 관련 데이터가 영구 삭제돼요. 해지 후 데이터에 대한 자세한 내용은 [하이퍼클래스 구독을 해지하면 데이터는 어떻게 되나요?](what-happen-s-to-your-data-when-you-cancel-your-hyperclass-subscription.md)를 참고하세요. 일시중지 요금제는 잠시 쉬면서 지원되는 계정 데이터를 유지하고 싶은 분을 위한 요금제예요.

## 계정을 일시중지하면 어떻게 되나요?

일시중지 기간에는 다음과 같이 돼요.

- 본인과 서브 계정이 플랫폼에 접속할 수 없어요.
- 데이터, 설정, 구성이 안전하게 보관돼요.
- 요금제를 언제든 재활성화하거나 변경하거나 해지할 수 있어요.

재활성화하면 작업 내용이 모두 복원되어, 멈췄던 곳에서 바로 이어서 쓸 수 있어요.

## 일시중지해도 보관되는 항목

핵심 비즈니스 자산은 그대로 보관돼요.

| 분류 | 보관되는 항목 | 참고 |
| --- | --- | --- |
| CRM 자산 | 연락처, 대화, 커스텀 오브젝트, 작업, 기회, 회사, 사용자 | 핵심 CRM 데이터는 재활성화에 대비해 그대로 저장돼요 |
| **퍼널** | 퍼널 구성과 설정 | 게시된 퍼널 페이지는 초안으로 바뀌어요 |
| **자동화** | 워크플로우와 자동화 구성 | 게시된 워크플로우는 초안으로 바뀌어요 |
| **캘린더** | **캘린더 설정**과 구성 | 예약 링크는 초안으로 바뀌어요 |
| **클라이언트 포탈** | 포탈 구성 설정 | 일시중지 기간에는 클라이언트 접속이 막혀요 |
| **이메일 빌더** | 이메일 템플릿과 자산 | **예약된 캠페인**은 초안으로 바뀌어요 |
| **미디어 저장소** | 이미지, 동영상, PDF, 문서, 오디오 등 업로드한 파일 | 업로드한 미디어가 모두 저장돼요 |
| **스냅샷** | 저장한 스냅샷과 템플릿 | 전부 보관되어 다시 쓸 수 있어요 |
| **구독** (기록) | 하이퍼클래스 결제로 만든 구독 기록 | 외부에서 처리되는 구독 동작은 포함되지 않아요 |
| **거래 내역** | 결제 내역과 영수증 | 가져온 거래와 기본 거래를 모두 포함해요 |
| **상품** | 상품 카탈로그, 가격, 옵션 | 전부 보관돼요 |
| **주문** | 주문 기록과 관련 거래 데이터 | 리포팅과 이력 확인용으로 유지돼요 |
| **쿠폰** | 사용 중인 쿠폰과 만료된 쿠폰 구성 | 쿠폰 데이터가 모두 저장돼요 |
| **기프트 카드** | 기프트 카드 상품과 주문 내역 | 전부 보관돼요 |
| **결제 설정** | 세금, 영수증, 알림 등 관련 설정 | 설정 데이터가 그대로 유지돼요 |

## 일시중지 요금제에 포함되지 않는 항목

일부 하이퍼클래스 서비스는 활성 구독, 등록, 갱신, 외부 인프라에 의존해요. 그래서 핵심 계정 데이터처럼 보관되지 않아요. 일시중지하기 전에 아래 항목을 확인해 두면, 뜻하지 않게 서비스를 잃거나 재활성화 후 다시 설정하는 일을 줄일 수 있어요.

| 분류 | 일시중지 중에 일어나는 일 | 알아 둘 점 |
| --- | --- | --- |
| **전화번호** | 계정이 일시중지 상태가 되고 14일 뒤에 전화번호가 삭제돼요 | 삭제된 전화번호는 재활성화 후 다시 구하거나 설정해야 할 수 있어요 |
| **A2P 등록** | 계정이 일시중지 상태가 되고 14일 뒤에 A2P 등록이 삭제돼요 | 재활성화 후 메시징 등록을 다시 설정해야 할 수 있어요 |
| 재판매 구독 | 재판매 구독이 자동으로 해지돼요 | 에이전시 계정을 재활성화한 뒤 해당 서비스를 다시 구독해야 해요 |
| 마켓플레이스 구독 | 마켓플레이스 구독이 자동으로 해지돼요 | 해지된 구독은 재활성화해도 자동으로 다시 시작되지 않아요 |
| SaaS 구독 | SaaS 구독이 자동으로 해지돼요 | 에이전시 계정을 일시중지하는 것과 개별 SaaS 서브 계정을 일시중지하는 것은 서로 달라요 |
| **도메인** | 계정이 일시중지된 동안 예정된 내부 도메인 갱신이 실패해요 | 갱신하지 못한 도메인은 만료될 수 있고, 재활성화 후 복구해야 할 수 있어요 |

## 계정을 일시중지하는 방법

1. **에이전시 보기**에서 **설정 > 청구/결제**로 이동하세요.

   ![청구/결제 화면으로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078171921/original/Hb4F-5zqfj1ihyJ936S8ESGHkm4x3ULVzg.png?1786476516)
2. **Want to Modify/Cancel Your Subscription?**(구독을 변경하거나 해지하시겠어요?)을 클릭하세요.

   ![구독 변경/해지 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078171912/original/iWahRdOsB_fFFyI0YZ0lqPSXTXk7LZ0soA.png?1786476488)
3. 선택지가 나타나면 **Pause Account**(계정 일시중지) 옵션을 선택하세요.

   ![계정 일시중지 옵션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078171946/original/6U1lvMCX19DBZwCrmjpItSxMOT_eFWNPKQ.png?1786476560)

## 일시중지한 계정을 재활성화하는 방법

계정 재활성화는 간단해서 몇 분이면 끝나요.

1. 로그인 페이지에서 계정에 로그인하세요.
2. **Reactivate Account**(계정 재활성화) 화면이 나타나요.
3. 결제를 완료하세요.
4. 계정이 일시중지 상태에서 바로 활성 상태로 바뀌어요.

## 자주 묻는 질문

### 에이전시 계정이 일시중지된 동안 팀원이나 클라이언트가 하이퍼클래스에 접속할 수 있나요?

아니요. 계정이 일시중지된 동안에는 에이전시와 서브 계정 모두 플랫폼에 접속할 수 없어요. 이 기간에는 **클라이언트 포탈**에도 접속할 수 없어요.

### 에이전시 계정이 일시중지되면 워크플로우는 계속 실행되나요?

아니요. 계정을 일시중지하면 게시된 워크플로우와 자동화가 초안으로 바뀌어요. 구성은 그대로 보관되니, 재활성화한 뒤 내용을 확인하고 다시 게시하면 돼요.

### 해지된 마켓플레이스, 재판매, SaaS 구독은 재활성화하면 자동으로 다시 시작되나요?

아니요. 에이전시 계정을 일시중지하면 이 구독들은 자동으로 해지돼요. 재활성화한 뒤에 쓰고 싶은 서비스는 직접 다시 구독해야 해요.
