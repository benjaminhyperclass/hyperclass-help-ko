# 사용자 지정 리포트 만들기, 일정 설정, PDF로 내보내기

사용자 지정 리포트를 만들고, 정해진 일정에 맞춰 보내고, PDF로 내려받는 방법을 안내해요. 팀이나 고객과 데이터를 공유할 때 쓰면 좋아요. 처음부터 만들 수도 있고, 기존 대시보드를 리포트로 바꿀 수도 있어요. 리포트의 디자인, 내용, 발송 일정을 직접 정할 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

{% hint style="warning" %}
모든 요금제($97, $297, $497)의 서브 계정에서 이제 여러 개의 대시보드와 자유롭게 편집할 수 있는 리포트를 쓸 수 있어요.
{% endhint %}

{% hint style="info" %}
사용자 지정 리포트 빌더를 쓸 때는 시간대가 데이터에 어떤 영향을 주는지 알아 두세요.

- Report Builder Date Range: 빌더에 표시되는 데이터는 브라우저에 설정된 시간대를 따라요.
- **이메일 미리보기**: 예약 발송되는 이메일 미리보기는 서브 계정의 시간대를 따라요.
- Google 및 Facebook 광고 데이터: Google Ads, Facebook Ads 같은 외부 연동 데이터는 서브 계정이 아니라 각 광고 계정에 설정된 시간대를 기준으로 해요.
{% endhint %}

### 1단계. 사용자 지정 리포트 열기

1. 왼쪽 메뉴에서 **리포팅**(Reporting)으로 이동한 뒤 **사용자 지정 리포트**를 클릭하세요.
2. **New Report**(새 리포트)를 선택해 리포트 만들기를 시작하세요.

   ![리포팅 메뉴의 사용자 지정 리포트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035055490/original/XWop_yTg_BlD5QR9gtE0rOHuULkKgx62vQ.png?1729478541)

### 2단계. 처음부터 만들거나 기존 대시보드 사용하기

1. 리포트를 **처음부터 시작**하거나, 기존 대시보드를 리포트로 바꿀 수 있어요.

   ![리포트 생성 방식 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035055491/original/CN9NPXV5O74IZ5TAKE1b78VreNdJl28gtA.png?1729478560)

### 3단계. 리포트 빌더 사용하기

1. 처음부터 시작하면 **Report Builder**(리포트 빌더)로 이동해요.
2. 화면 맨 위에서 리포트 이름을 목적에 맞게 바꿀 수 있어요.

   ![리포트 이름을 바꾸는 화면 상단](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035055500/original/zmBtf-tN9LhiMM6vL9BqOZxeMPkAz9_AOQ.png?1729478592)

### 4단계. 표지 꾸미기

리포트의 첫 페이지는 표지예요. 오른쪽의 **Page Properties**(페이지 속성) 메뉴에서 표지를 꾸미거나 없앨 수 있어요.

![오른쪽 페이지 속성 메뉴에서 표지를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035055523/original/mGNh0S6YZcrDx7yCBMKItqWbD2dT4I7dKw.png?1729478640)

**Page Properties**에서 할 수 있는 설정은 다음과 같아요.

- 회사 로고 업로드
- 페이지별 머리글 설정
- 리포트 페이지의 배경 색상 조정

### 5단계. 위젯, 섹션, 테마 추가하기

1. 표지를 정했으면 왼쪽의 + 아이콘을 클릭해 위젯을 추가하세요.
2. 위젯 사이드바에서 리포트에 넣을 위젯을 업로드하거나 사용자 지정하세요.
3. **Elements Menu**(요소 메뉴)에서 제목을 추가하고 섹션으로 나누면 리포트를 읽기 쉽게 정리할 수 있어요.
4. **테마** 섹션으로 이동해 미리 만들어진 테마 중 하나를 적용하거나, 직접 만든 테마를 추가하세요.

### 6단계. 페이지 관리하기

1. 새 페이지를 추가하려면 기존 페이지의 위쪽이나 아래쪽에 있는 + 아이콘을 클릭하세요.

   ![페이지 위아래의 + 아이콘으로 새 페이지를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035055538/original/uaL0URUopHhC5wDig5wPB48i9pVXWzb73Q.png?1729478707)

2. 전체 페이지 목록을 보려면 **Page Icon**(페이지 아이콘)을 클릭하세요.
3. 페이지를 끌어다 놓아 순서를 바꾸고, 필요하면 이름도 바꿔 정리하세요.

   ![페이지 목록에서 순서를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035055540/original/zyglJDeH2oIk1fnjkCUcTp6ecOrC8uISQw.png?1729478725)

### 7단계. 리포트 내려받기

1. 리포트를 다 만들었으면 화면 위쪽의 **Download**(다운로드) 버튼을 클릭해 PDF로 내려받으세요.

{% hint style="info" %}
PDF 내보내기와 이메일의 미리보기 링크는 동작이 달라요. 표 위젯은 처음 100개 레코드까지만 표시되고, 드릴다운은 사용할 수 없어요.

- 미리보기 링크: 이미지와 iframe이 포함되어 수신자에게 보여요.
- PDF 다운로드: 보안 제한 때문에 이미지와 iframe이 제외돼요.

이미지를 넣을 때는 JPEG나 PNG 형식을 권장해요. 다른 형식은 브라우저와 인코딩에 따라 제대로 표시되지 않을 수 있어요.
{% endhint %}

### 8단계. 저장하고 보내기 또는 예약하기

1. 리포트를 다 만들었으면 **저장**을 클릭하세요.
2. **보내기** 또는 **일정**을 선택하세요.

### 9단계. 리포트 일정과 발송 설정하기

1. 아래 항목을 설정하세요.
   - **Frequency**(빈도): 리포트를 얼마나 자주 보낼지 정해요(매일, 매주 등).
   - **Time**(시간): 리포트가 발송될 정확한 시간을 선택해요.
   - **Date Range**(날짜 범위): 리포트에 포함할 데이터 기간을 선택해요.
   - **위젯 단위 날짜 설정**: 이 토글을 켜면 날짜 범위와 비교 기간을 따로 지정한 위젯은 이메일로 발송되는 리포트에서도 그 설정이 유지돼요.
   - **Compare With**(비교 대상): 이 토글을 켜면 추세와 비교 데이터를 추가할 수 있어요.
   - **발신자 이메일**: 리포트를 보낼 이메일 주소를 직접 정해요.
   - **Subject**(제목): 리포트 이메일의 제목을 입력해요.
   - **수신자**: 받는 사람의 이메일 주소를 입력해요.
   - **Optional Email Body**(이메일 본문, 선택): 필요하면 직접 쓴 메시지를 추가해요.

   ![리포트 일정과 발송 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035055549/original/lBoGoTRg-viTXQNBGh5jjtfyg7ujRHoNHw.png?1729478745)

#### 저장된 값, 비교 기간 동작, 이메일 스냅샷

사용자 지정 리포트는 대시보드와 같은 방식으로 값을 유지해요.

- 리포트 단위 날짜 범위와 저장된 필터 값은 리포트를 저장한 뒤에도 유지돼요.
- 리포트를 만든 사람이 **저장**을 클릭하면, 저장된 드롭다운 값이 그 리포트를 여는 사용자에게도 반영돼요.
- 일반 위젯에는 리포트 단위 비교 날짜 범위를 설정할 수 있어요.
- 위젯에 자체 비교 날짜 범위가 있으면, 그 위젯 설정이 리포트 단위 비교 설정보다 우선해요.

이메일로 공유하는 리포트는 이메일이 만들어진 시점의 리포트 값을 스냅샷으로 담아요.

- 발송된 이메일에는 이메일이 만들어질 때 적용되어 있던 값이 그대로 남아요.
- 이후에 리포트를 바꿔도 이미 발송된 이메일은 바뀌지 않아요.

{% hint style="info" %}
**위젯 단위 날짜 설정**은 리포트 단위 날짜 범위와 다를 수 있어요.
{% endhint %}

### 10단계. 테스트 이메일 보내기

1. 최종 설정 전에 테스트 이메일을 보내 수신자에게 리포트가 어떻게 보일지 확인하세요.

### 11단계. 마지막 단계: 저장하고 일정 예약하기

1. 모든 설정이 마음에 들면 **Save and Schedule**(저장 후 일정 예약)을 클릭하세요.
2. 설정한 일정에 따라 리포트가 자동으로 발송돼요.

# 자주 묻는 질문

### 하이퍼클래스 계정이 없는 사람에게도 예약 리포트를 보낼 수 있나요?

네, 보낼 수 있어요. **일정 설정**의 **수신자**에 유효한 이메일 주소를 추가하세요. 하이퍼클래스에 로그인하지 않아도 받은 편지함에서 바로 리포트를 받아요.

{% hint style="info" %}
이 경우에는 대시보드 공유 링크가 아니라 사용자 지정 리포트를 사용하세요. 대시보드 링크는 인증이 필요해요.
{% endhint %}

이메일과 PDF에 들어가는 표 위젯은 처음 100개 레코드만 보여 주고, 드릴다운 차트는 두 형식 모두에서 쓸 수 없어요. 전체 데이터를 보거나 드릴다운을 쓰려면, 수신자가 하이퍼클래스에 로그인해 리포트나 대시보드를 직접 열어야 해요.
