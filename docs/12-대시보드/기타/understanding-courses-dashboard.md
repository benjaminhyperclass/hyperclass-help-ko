# 코스 대시보드 살펴보기

코스 대시보드는 최근 30일 동안의 코스 성과를 한눈에 보여 줘요. 대시보드를 읽는 방법과 더 자세한 분석 화면으로 넘어가는 방법을 안내해요. 코스의 성과를 확인하고 개선할 부분을 찾을 때 활용하세요.

{% hint style="info" %}
데이터는 6시간마다 업데이트돼요.
{% endhint %}

## 새 코스 대시보드란?

새 코스 대시보드는 하이퍼클래스에서 코스를 운영하는 크리에이터에게 가장 먼저 보이는 기본 화면이에요. 기존 SQL 기반 화면을 대체하며, 등록·수익·참여 지표를 거의 실시간으로 보여 줘요. Highrise UI 디자인 시스템으로 만들어서 화면 크기에 맞게 자동으로 조정되고, 데이터는 6시간마다 새로 고쳐져요.

## 새 코스 대시보드의 주요 장점

- 최고 성과 코스와 성과가 낮은 코스를 30일 기준으로 바로 확인할 수 있어요.
- 총 수익, 총 체크아웃 수, AOV 등 수익 분석을 한 곳에서 볼 수 있어요.
- 수강생이 어느 단계에서 이탈하는지 퍼널로 확인할 수 있어요(가입 → 시작 → 완료).
- 처음 쓰는 크리에이터에게는 맞춤 빈 화면과 **시작하기** 카드가 보여요.
- 카드를 클릭하면 멤버 분석이나 수익 분석 화면으로 한 번에 이동해요.

## 최고 성과 코스와 성과가 가장 낮은 코스

이 카드에서는 등록·완료 데이터를 기준으로 성과가 가장 좋은 코스와 신경 써야 할 코스를 볼 수 있어요.

1. **최고 성과 코스**: 최근 30일 동안 참여도가 가장 높은 코스를 보여 줘요.
2. **성과가 가장 낮은 코스**: 참여도 또는 완료율이 가장 낮은 코스를 보여 줘요.
3. 표시되는 지표
   - **Completion Rate**(완료율): 등록한 수강생 중 코스를 완료한 비율이에요.
   - **등록**: 코스에 등록한 수강생의 전체 수예요.

![최고 성과 코스와 성과가 가장 낮은 코스 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056151085/original/Y8GjKLdMacSO-HewJIPcUuQCv84xDm4xtg.png?1760620587)

코스 이름을 클릭하면 **Course Details Page**(코스 상세 페이지)로 이동해요. 여기서 참여도, 콘텐츠, 완료 성과를 자세히 분석할 수 있어요.

## 발생한 수익

코스에서 번 전체 수익을 한눈에 보여 주는 카드예요.

- **발생한 수익**($): 최근 30일 동안 번 금액이에요.
- **vs Last Month**(지난달 대비): 이전 달과 비교한 변화율이에요.
- **총 체크아웃 수**: 완료된 구매의 전체 건수예요.
- **업셀 전환**: 코스 오퍼를 통해 성사된 업셀의 수예요.

![발생한 수익 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056150641/original/emEH0jvpZFmaG65zLDFU8I3nXzItbjhueg.png?1760620430)

**내비게이션**: **매출로 이동**을 클릭하면 상세 수익 분석, 거래별 내역, 수강생 구매 내역을 볼 수 있어요.

![매출로 이동 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056150822/original/1YyaSTJ4z3O15Qh0VxU1tIlYDLzx_2fPPA.jpeg?1760620472)

## 평균 주문 금액(AOV)

수강생 한 명당 평균 얼마의 수익이 나는지 보여 주는 카드예요.

- **사용자당 AOV**: 총 수익을 전체 수강생 수로 나눈 평균 주문 금액이에요.
- **최고 주문 금액**: 최근 30일 동안 기록된 단일 거래 중 가장 큰 금액이에요.
- **vs Last Month**(지난달 대비): 이전 기간과 비교한 변화율이에요.

![평균 주문 금액 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056150992/original/vlzOEs2RubxcIq7L2wQtqiT9RjoeTbYCCA.png?1760620520)

## 코스 진행 퍼널

수강생이 가입부터 코스 완료까지 어떻게 진행하는지 보여 주는 그래프예요.

- **가입함**: 코스에 가입한 수강생의 수예요.
- **시작됨**: 강의나 모듈을 보기 시작한 수강생이에요.
- **완료**: 코스를 끝까지 마친 수강생이에요.

![코스 진행 퍼널 그래프](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056150332/original/BX6Rwm-mlX4Vjz_uazL89WQgyB-QOjR1gQ.png?1760620347)

오른쪽의 **Cumulative %**(누적 비율)는 각 단계까지 진행한 수강생의 비율이에요.

**내비게이션**: **퍼널로 이동**을 클릭하면 코스 진행 상황을 자세히 분석하고, 수강생별 데이터를 보고, 리포트를 내보낼 수 있어요.

![퍼널로 이동 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056150262/original/qciu9_k3jNmLBjJ8LV9xgrSMRvlfhDKykw.png?1760620312)

## 대시보드 활용 팁

- **최고 성과 코스**와 **성과가 가장 낮은 코스** 데이터를 보고 어떤 코스를 개선할지 정해 보세요.
- 가격이나 프로모션을 바꾼 뒤에는 매달 수익과 AOV 추이를 확인해서 효과를 가늠해 보세요.
- **코스 진행 퍼널**을 자주 확인해서 수강생이 이탈하는 단계를 찾고 완료율을 높여 보세요.

## 새 코스 대시보드 찾는 방법

따로 설정하지 않아도 돼요. 하이퍼클래스 코스를 쓰는 모든 계정에서 대시보드가 자동으로 켜져 있어요. 아래 순서로 대시보드를 찾아서 화면을 활용해 보세요.

1. 하이퍼클래스 계정에 로그인해요.
2. **멤버십 > 코스**로 이동해요.
3. **대시보드**를 클릭해요. 크리에이터에게는 기본으로 열려요.

![멤버십 > 코스의 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056151808/original/HqiYuzYEXyoPlk1TiPX4yrrqXnbdjO3KBA.png?1760620783)

{% hint style="info" %}
**팁**

1. 대시보드를 사이드바에 고정하면 한 번의 클릭으로 열 수 있어요.
2. [선택] ••• > **Remove Sample Data**(샘플 데이터 제거)를 클릭하면 샘플 데이터를 숨길 수 있어요.
3. **매출로 이동**이나 **퍼널로 이동**으로 상세 분석 화면에 들어가 보세요.
4. 매일 또는 매주 확인해 보세요. 데이터는 6시간마다 새로 고쳐져요.
{% endhint %}

## 자주 묻는 질문

### 새 대시보드를 쓰려면 따로 이전 작업을 해야 하나요?

아니요. 기존 코스 데이터는 자동으로 업데이트돼요. 다음에 **코스**를 열면 대시보드가 보여요.

### 수익 데이터가 보이지 않아요.

수익 카드는 하이퍼클래스 결제 또는 Stripe로 유료 체크아웃이 한 건 이상 처리된 뒤에 채워져요.

### 대시보드 데이터를 내보낼 수 있나요?

네. 오른쪽 위의 **내보내기** > **CSV**를 클릭하면 30일 집계 데이터를 내려받을 수 있어요.

### 표시되는 지표를 바꾸려면 어떻게 하나요?

지표 타일은 지금은 고정이에요. 더 세부적인 사용자 지정 리포트는 Advanced Analytics의 일부로 곧 제공될 예정이에요.

### 월별 API 한도에 영향을 주나요?

아니요. 대시보드 쿼리는 서버에서 실행돼서 API 사용량에 포함되지 않아요.

### 모바일에서도 대시보드를 볼 수 있나요?

네. Highrise UI가 태블릿과 휴대폰 화면에 맞게 조정돼요.

### 여러 코스를 한꺼번에 관리하려면 어디서 하나요?

**Kollab Studio**를 사용하세요. 게시/게시 취소, 가격 수정 같은 코스 일괄 관리 작업을 할 수 있어요.
