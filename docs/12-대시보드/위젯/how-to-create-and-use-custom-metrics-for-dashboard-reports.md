# 대시보드 리포트용 맞춤 지표 만들고 사용하기

맞춤 지표를 쓰면 여러 출처의 데이터를 조합하고 직접 만든 수식을 적용해, 우리 비즈니스에 꼭 필요한 KPI를 대시보드와 리포트에서 바로 볼 수 있어요. 이 문서에서는 맞춤 지표가 무엇인지, 어떤 점이 좋은지, 어떻게 설정하는지 순서대로 알려 드려요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

{% hint style="info" %}
이 기능은 $497 이상 요금제에서 사용할 수 있어요.
{% endhint %}

## 맞춤 지표란?

**맞춤 지표**(Custom Metrics)는 우리 비즈니스에 중요한 KPI를 대시보드와 리포트 안에서 바로 만드는 기능이에요. 데이터를 스프레드시트로 내보내지 않아도 돼요. 여러 출처의 숫자를 합치고 직접 계산해서 전환율, ROI, 고객 획득 비용 같은 결과를 바로 확인할 수 있어요.

지표가 표시되는 형식(백분율, 통화, 정수 등)은 직접 정할 수 있어요. 만든 지표는 어떤 대시보드나 리포트에도 위젯으로 추가할 수 있어요. 스냅샷에도 쓸 수 있어서, 필요할 때 새 서브 계정에 함께 보낼 수 있어요.

{% hint style="info" %}
맞춤 지표에서 이제 지표 수준 필터와 추가 데이터 출처(Meta Ads, Google Analytics 포함)를 지원해요. 설정 방법과 예시는 "맞춤 지표 — 지표 수준 필터, Meta Ads 및 Google Analytics 지원" 문서를 참고하세요.
{% endhint %}

## 맞춤 지표의 장점

미리 정해진 지표만 쓰지 않고, 비즈니스 목표에 맞는 KPI를 직접 설계할 수 있어요. 주요 장점은 다음과 같아요.

- 나만의 KPI: 여러 출처의 데이터를 조합해 ROI, 전환율, 고객 획득 비용처럼 우리 비즈니스에 맞는 지표를 만들 수 있어요.
- 효율적인 설정: 새 지표를 처음부터 만들 수도 있고, 기존 지표를 복제해서 시간을 아끼고 리포트 간 일관성도 유지할 수 있어요.
- 스마트 수식 편집기: 여러 데이터 출처의 지표를 넣고, 연산자와 상수를 더할 수 있어요. 실시간 검증으로 계산 오류도 막아 줘요.
- 유연한 표시 옵션: 정수, 소수, 통화, 백분율 중에서 값이 보이는 방식을 골라 명확하게 보여 줄 수 있어요.
- 추세 방향 설정: 증가와 감소 중 어느 쪽을 긍정으로 볼지 정해서 비즈니스 기준에 맞게 데이터를 해석할 수 있어요.
- 차트 사용자 지정: 차트 이름을 바꾸고 테마를 적용하며, 서로 다른 기간의 결과를 비교해 더 깊이 있게 분석할 수 있어요.
- 어디서나 사용: 대시보드, 사용자 지정 리포트, 스냅샷에서 맞춤 지표를 쓸 수 있어요.

## 맞춤 지표 설정하기

### 1. 대시보드 열기

왼쪽 메뉴에서 **대시보드**를 클릭하세요. 위젯을 관리하고 새 맞춤 지표를 설정하는 화면이에요.

![대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052077843/original/1CNC_AyByvawx3vgUPFjncDNkZwrjhTmVw.png?1755775419)

### 2. 편집 모드로 전환하기

대시보드 오른쪽 위의 **Edit Dashboard**(대시보드 편집) 아이콘을 클릭하세요. 편집 모드가 켜지면 맞춤 지표를 비롯한 위젯을 추가하거나 설정할 수 있어요.

![대시보드 편집 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052077862/original/04haKbnQD85otqvcAlUOSbtSQc62R3BPZA.png?1755775439)

### 3. 위젯 추가하기

편집 모드에서 오른쪽 위의 **Add Widget**(위젯 추가) 버튼을 클릭하세요. 맞춤 지표를 포함해 대시보드에 넣을 수 있는 위젯 옵션이 열려요.

![위젯 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052077923/original/toOL6AHmXhhZVi4XTRaWP6iI0SDG7jdYOg.png?1755775462)

### 4. 맞춤 지표 탭 선택하기

위젯 옵션 패널에서 **맞춤 지표**(Custom Metrics) 탭을 클릭하세요. 대시보드용 KPI를 만드는 도구가 나타나요.

![맞춤 지표 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052077958/original/1P2zIuW1POB-j8x7yAMAHSYP3cyx8mUbpg.png?1755775486)

### 5. 맞춤 지표 만들기 시작하기

**+ Create Custom Metrics**(+ 맞춤 지표 만들기) 버튼을 클릭하세요. KPI를 정의하고 설정하는 화면이 열려요.

![맞춤 지표 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052077989/original/21l_RpWDueqqzQ2L8ppWRaTuDr2swDy7Yw.png?1755775510)

### 6. 시작 방식 고르기

**처음부터 시작**과 **기존 복제** 중에서 선택하세요. 새 지표를 처음부터 만들려면 **처음부터 시작**을, 이전에 만든 지표를 재사용하려면 **기존 복제**를 고르면 돼요. 기존 설정을 고쳐 쓰면 시간을 아낄 수 있어요.

![시작 방식 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052078252/original/gDr_Vqkaij6LDKOmCRXmiOVEgL83Y7GjNQ.png?1755775659)

### 7. 선택 확정하기

**처음부터 시작**이나 **기존 복제**를 고른 다음, 아래쪽의 **선택** 버튼을 클릭하세요. 선택이 확정되고 맞춤 지표를 만드는 설정 폼이 열려요.

![선택 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052078280/original/MVhaYaNf2y5VhRS2TFWt7h5CuQwazbHCew.png?1755775686)

### 8. 지표 기본 정보 입력하기

설정 폼에서 아래 항목을 입력하세요.

1. **Metric Name**(지표 이름): 지표를 쉽게 알아볼 수 있도록 분명한 이름을 입력하세요. 예: 매출 성장률
2. **Data Type**(데이터 유형): 값을 어떻게 표시할지 고르세요. **Integer**(정수), **Float**(소수), **Percentage**(백분율), **Currency**(통화) 중에서 선택할 수 있어요.
3. **설명**: 나와 팀원이 이 지표의 용도를 알 수 있도록 짧게 적어 주세요.

![지표 기본 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052078293/original/AjesB5ngRCF781lNgeuADOOwXLHBpFZ2jQ.png?1755775704)

### 9. 수식 추가하기

**수식** 필드에서 맞춤 지표를 어떻게 계산할지 정해요. 서로 다른 지표를 최대 4개까지 조합할 수 있고, 연산자(+, -, ×, ÷)와 상수도 넣을 수 있어요. 표준 지표에 얽매이지 않고 우리 비즈니스 논리에 맞는 KPI를 만들 수 있어요.

예를 들어 전환율은 고객전환성공 기회 수를 신규 리드 수로 나눈 뒤 100을 곱하면 백분율로 표시할 수 있어요.

![수식 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052078341/original/QSXSIu4IlgpgEsB9tbnULBFVm-EqM27D3A.gif?1755775750)

### 10. 고급 설정에서 날짜 속성 정하기

**고급 설정** 섹션에서는 수식에 쓴 각 지표에 적용할 날짜 속성을 정해요. 이렇게 하면 맞춤 지표가 올바른 시간 기준으로 일관되게 계산돼요.

- 예를 들어 수식에 **페이지 조회수**와 **예약**이 들어 있다면, 지표마다 날짜 속성이 따로 있을 수 있어요.
  - **페이지 조회수** → **Visited On**(방문일, 페이지를 조회한 날짜)
  - **예약** → **생성일**(예약이 만들어진 날짜)
- 여기에 나타나는 드롭다운 옵션은 수식 단계에서 고른 지표에 따라 달라져요. 지표마다 해당하는 날짜 필드만 표시돼요.

지표마다 알맞은 날짜 속성을 고르면 전환율이나 성장률 같은 계산이 올바른 시점의 이벤트에 맞춰져요. 예를 들어 **페이지 조회수**(**Visited On**)와 **예약**(**생성일**)을 짝지으면, 같은 기간에 방문이 실제 예약으로 이어진 비율을 측정할 수 있어요.

![고급 설정의 날짜 속성 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052078529/original/ggRdvVcP6fo0AHCg-GM_jeKHa7Ka0c47HA.png?1755775839)

### 11. 비교 값 정하기

**Comparison Value**(비교 값) 섹션에서는 맞춤 지표가 증가하는 것과 감소하는 것 중 어느 쪽을 긍정으로 볼지 정해요.

- **증가는 양수입니다**: 값이 높을수록 성장이나 성공을 뜻할 때 선택하세요. 예: 매출, 예약 수, 신규 리드
- **감소가 긍정적임**: 값이 낮을수록 개선을 뜻할 때 선택하세요. 예: 응답 시간, 이탈률, 고객 불만 건수

이 설정을 해 두면 대시보드와 리포트가 비즈니스 목표에 맞게 변화를 보여 줘요. 추세 방향을 정확히 정해 두면 팀이 성과 변화를 올바른 맥락에서 해석할 수 있어요.

![비교 값 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052078655/original/dCsEq0wdMIJ0VPb1ueXDrpvlUi0yJKbVwQ.png?1755775886)

### 12. 지표 완성하기

기본 정보, 수식, 설정을 모두 마쳤다면 **만들기**를 클릭해 맞춤 지표를 저장하세요. 새 지표를 대시보드나 사용자 지정 리포트에 위젯으로 추가할 수 있고, 정의한 로직에 따라 결과가 표시돼요.

![만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052078706/original/DlIryLgMbTbSHDD3WzZjYRza-R4eCBLtrw.png?1755775904)

## 자주 묻는 질문

### 날짜 속성이 서로 다른 출처의 지표도 조합할 수 있나요? (예: 연락처 생성일과 기회 종료일)

네, 조합할 수 있어요. 수식을 만들 때 지표마다 해당하는 날짜 옵션이 드롭다운에 표시돼요. 지표마다 알맞은 속성을 직접 골라야 해요. 예를 들어 연락처는 **생성일**, 기회는 **Closed Date**(종료일)를 선택해요. 이렇게 하면 수식이 일관되게 계산돼요. 다만 측정하려는 비즈니스 결과에 맞게 선택해야 해요. 그렇지 않으면 원하는 KPI와 다른 결과가 나올 수 있어요.

### 추세 방향 설정이 리포트 정확도에 어떤 영향을 주나요?

추세 방향은 지표가 증가하는 것을 긍정으로 볼지 부정으로 볼지 정해요. 대시보드와 리포트가 변화를 어떻게 강조해 보여 줄지에 영향을 줘요. 예를 들어 매출에 **증가는 양수입니다**를 설정하면 성장이 긍정적인 추세로 표시돼요. 그런데 응답 시간에 같은 설정을 잘못 적용하면 대기 시간이 길어지는 것이 '긍정'으로 표시돼서 해석이 왜곡돼요. 추세 방향이 지표의 의도와 맞는지 항상 확인하세요.

### 기존 맞춤 지표를 복제한 뒤 원본 데이터 출처가 바뀌면 어떻게 되나요?

복제한 지표는 만들 당시의 원본 데이터 출처와 필드에 계속 연결돼 있어요. 필드가 삭제되거나 이름이 바뀌거나 데이터 유형이 달라지면, 복제한 지표의 계산이 깨지거나 오류가 표시될 수 있어요. 이럴 때는 복제한 지표의 수식을 편집해서 영향을 받은 필드를 다시 연결하세요. 그러면 계산이 정상적으로 돌아와요.

### 맞춤 지표를 스냅샷으로 다른 서브 계정에 보낼 수 있나요? 수식도 그대로 유지되나요?

네, 맞춤 지표를 스냅샷에 포함해 다른 서브 계정에 보낼 수 있어요. 받는 계정에서 같은 데이터 출처와 필드를 쓸 수 있다면 수식도 그대로 유지돼요. 받는 서브 계정에 해당 출처가 없으면 지표는 표시되지만, 없는 필드를 설정하거나 올바르게 연결하기 전까지는 제대로 계산되지 않아요.
