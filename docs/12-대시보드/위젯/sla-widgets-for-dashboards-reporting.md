# 대시보드와 리포팅에서 SLA 위젯 사용하기

SLA 위젯을 쓰면 하이퍼클래스를 벗어나지 않고도 팀이 응답 약속(SLA)을 지키고 있는지 확인할 수 있어요. 서브 계정 **대시보드**와 **사용자 지정 리포트**에서 SLA 충족률, 위반 패턴, 평균 응답 시간, 사용자별·채널별 성과를 한눈에 볼 수 있어요. 에이전시와 고객사 모두 이 화면으로 현황을 파악할 수 있어요.

![SLA 위젯이 배치된 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073572823/original/PklU2K2KTOudq8kAtl_8LZBSnfHd6CM5PQ.png?1781286510)

## SLA 위젯이란?

SLA 위젯은 서비스 수준 협약(SLA) 데이터를 보여 주는 기본 제공 리포팅 블록이에요. 서브 계정 대시보드나 사용자 지정 리포트 어디에나 넣을 수 있어요. **대화** 위젯 섹션 안에 기존 대화량·배정·채널 위젯과 함께 들어 있어서, 대화 활동을 보던 화면에서 SLA 상태도 같이 확인할 수 있어요.

위젯은 모두 네 가지예요. SLA 충족 추세, SLA 위반 추세, 평균 응답 시간 추세, 사용자별 SLA 성과를 보여 줘요. 이 위젯으로 고객용 SLA 현황 화면을 몇 분 만에 만들고, 정해진 일정에 맞춰 공유할 수 있어요.

## SLA 위젯의 장점

1. SLA 상태를 한눈에 확인해요. **대화**를 일일이 뒤지지 않아도 SLA 충족률과 위반율을 숫자 KPI나 추세선으로 볼 수 있어요.
2. 위반 패턴을 일찍 찾아요. SLA 위반 추세에서 팀이 늦어진 기간을 확인할 수 있어요. 고객사 문제로 번지기 전에 관리자가 원인을 살펴볼 수 있어요.
3. 응답 속도의 변화를 추적해요. 평균 응답 시간 추세로 원하는 기간 동안 팀이 빨라지는지 느려지는지 일별·주별·월별로 볼 수 있어요.
4. 담당자별로 성과를 확인해요. SLA 성과 위젯은 사용자별 충족률과 위반율을 비교해 줘요. 관리자는 데이터를 근거로 개인별 성과를 볼 수 있어요.
5. 채널별 필터로 나눠 봐요. **메시지 채널**(통화, SMS, 이메일, 웹 채팅, Facebook, GMB, Instagram)별로 SLA 데이터를 나눠서, 어느 채널에서 응답 부담이 큰지 알 수 있어요.
6. **맞춤 지표**로 원하는 KPI를 만들어요. 수식 빌더에서 SLA 충족 건수와 SLA 위반 건수를 조합해 SLA 준수율 같은 지표를 만들 수 있어요.

## 사전 준비와 권한

- 대시보드·리포트 접근 권한: 사용자에게 대시보드를 보거나 편집할 권한, 사용자 지정 리포트를 만들거나 일정에 맞춰 보낼 권한이 있는지 확인하세요.
- SLA 위젯에 데이터가 보이려면 먼저 서브 계정에서 SLA를 켜야 해요. **대화 > 설정 > SLA**로 이동해서 SLA를 켜세요. SLA를 설정하지 않으면 모든 위젯이 0으로 표시되고 데이터가 나오지 않아요. 오류가 아니라 정상 동작이에요.

![SLA 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074908612/original/jq0wRk52ke4GECxTa0A9d0ctg_6QBTmddQ.png?1782891836)

{% hint style="info" %}
SLA 위젯은 최대 1년 범위까지만 조회할 수 있어요. SLA를 포함해 대시보드의 모든 위젯은 화면 상단의 **Dashboard Date Range**(대시보드 날짜 범위)를 기준으로 동작해요.
{% endhint %}

## 사용할 수 있는 SLA 위젯

SLA 위젯은 네 가지예요. 위젯마다 차트 유형, 조건, 테마를 설정할 수 있어요.

1. **SLA 충족 추세**: SLA 목표를 지킨 대화의 비율이 시간에 따라 어떻게 변하는지 보여 줘요. 일별·주별·월별로 볼 수 있고, **Inbound at**(수신 시각), **배정된 사용자**, **메시지 채널**별로 나눌 수 있어요.
2. **SLA 위반 추세**: SLA 기준을 넘긴 대화의 비율이 시간에 따라 어떻게 변하는지 보여 줘요. 문제가 생긴 기간을 찾거나, 개선 후 변화를 확인할 때 좋아요.
3. **평균 응답 시간 추세**: 선택한 기간 동안 평균 첫 응답 시간이 어떻게 변하는지 보여 줘요. 일별·주별·월별로 볼 수 있어요.
4. **SLA 성과**: 사용자와 메시지 채널별로 SLA 충족률과 위반율을 비교해 줘요. 팀원끼리 성과를 견주거나 지원이 필요한 곳을 찾을 때 쓰세요.

## 대시보드 위젯과 사용자 지정 리포트 위젯의 차이

두 곳 모두 같은 SLA 위젯 네 가지를 써요. 데이터를 어떻게 보고 공유할지에 따라 골라 쓰세요.

- **대시보드**: 상시 모니터링에 알맞아요. 위젯이 서브 계정 대시보드에 놓이고 자동으로 갱신돼요. 기존 **대화**, 이메일, SMS 위젯 옆에 SLA 위젯을 두면 커뮤니케이션 상태를 한 화면에서 볼 수 있어요.
- **사용자 지정 리포트**: 고객에게 정기적으로 보낼 때 알맞아요. 리포트 레이아웃에 SLA 위젯을 넣고, 매일·매주·매월 자동으로 이메일이 가도록 설정할 수 있어요.

## SLA 위젯 추가하기

### 1) 대시보드에 SLA 위젯 추가하기

1. 서브 계정에서 **대시보드**로 이동한 다음, 편집할 대시보드를 열어요. 새 대시보드를 만들어도 돼요.
2. 오른쪽 위의 **Edit Dashboard**(대시보드 편집)를 클릭하세요.
3. **+ Add Widget**(위젯 추가)을 클릭하세요. 오른쪽에 위젯 패널이 열려요.
4. 아래로 스크롤해서 **대화** 섹션을 찾으세요. SLA 위젯 네 가지가 맨 아래, **New Conversations started**(시작된 새 대화) 밑에 있어요.
5. 추가할 위젯을 클릭하세요. 대시보드 캔버스에 위젯이 놓여요.
6. **Configure**(구성) 탭과 **Conditions**(조건) 탭에서 위젯을 설정하세요. 자세한 내용은 아래에서 설명해요.

   ![대시보드 위젯 패널의 SLA 위젯 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073572817/original/iYAjO2MoYNpNkUBve9POFilJi-5T_wV5ug.png?1781286480)

7. **변경사항 저장**을 클릭하면 대시보드에 위젯이 게시돼요.

{% hint style="info" %}
SLA 충족 추세와 SLA 위반 추세를 나란히 놓으면 SLA 상태를 빠르게 볼 수 있어요. 대시보드 맨 위에 숫자형 SLA 충족, SLA 위반 위젯을 함께 두면 요약까지 한눈에 확인할 수 있어요.
{% endhint %}

### 2) 사용자 지정 리포트에 SLA 위젯 추가하기

1. 서브 계정에서 **리포팅 > 사용자 지정 리포트**로 이동해 기존 리포트를 열거나 **New Report**(새 리포트)를 클릭하세요.
2. 빈 캔버스에서 시작할지, 템플릿을 쓸지, 기존 대시보드 레이아웃을 가져올지 선택하세요.
3. 리포트 빌더 왼쪽 위의 **Add Widget / Element**(위젯/요소 추가)를 클릭하세요.
4. **대화** 섹션까지 스크롤한 다음, 추가할 SLA 위젯을 리포트 레이아웃으로 끌어다 놓으세요.
5. 각 위젯을 **Configure** 탭과 **Conditions** 탭에서 설정하세요.
6. **저장**을 클릭하세요.
7. **보내기** 또는 **일정**을 클릭해서 리포트를 이메일로 자동 발송하도록 설정하세요.

## SLA 위젯 설정하기

SLA 위젯마다 **Edit Widget**(위젯 편집) 패널에 **Configure** 탭과 **Conditions** 탭이 있어요.

### Configure 탭

**Configure** 탭에서는 위젯의 모양, 표시할 지표, 데이터를 묶는 방식을 정해요.

1. **Chart type**(차트 유형): **Numeric (#)**(숫자), **Donut**(도넛), **Line**(선), **Bar**(막대), **Horizontal Bar**(가로 막대), **Table**(표) 중에서 골라요. 위젯에 따라 고를 수 있는 유형이 달라요.
2. **Title**(제목): 대시보드나 고객 상황에 맞게 위젯 이름을 바꿔요.
3. **Metric**(지표): SLA 충족 %, SLA 위반 %, 평균 응답 시간, SLA 충족(건수), SLA 위반(건수) 중에서 골라요.
4. **View By**(보기 기준): 데이터를 묶는 기준을 정해요. **Inbound at**, **배정된 사용자**, **메시지 채널** 중에서 골라요.
5. **Breakdown**(세부 구분): 추세 위젯의 시간 단위를 정해요. **Daily**(일별), **Weekly**(주별), **Monthly**(월별) 중에서 골라요.
6. **Date range**(날짜 범위): 기본값은 **Dashboard Date Range**예요. 필요하면 직접 범위를 지정할 수 있고, 최대 범위는 1년이에요.

### Conditions 탭

필터를 추가하면 위젯에 표시할 대화 데이터를 정확히 좁힐 수 있어요. 조건으로 특정 사용자나 채널만 남길 수 있어요.

1. **배정된 사용자**: **Logged in user**(로그인한 사용자)나 서브 계정의 팀원 중 한 명을 고르세요. 그 팀원의 대화만 SLA 데이터로 보여 줘요.
2. **메시지 채널**: 통화, SMS, 이메일, 웹 채팅, Facebook, GMB, Instagram 중에서 고르세요. 대화가 들어온 채널별로 SLA 데이터를 걸러 볼 수 있어요.

![Conditions 탭 설정 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073572907/original/16GZv1VJQvvU3T4qWztYvuJnQxVXn-fupw.png?1781286698)

![Conditions 탭 설정 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073572911/original/ntR7U7hsudbrE2FmwMwPUhZojD21Ulo4FA.png?1781286708)

### 테마 탭

위젯 색상을 대시보드나 고객 브랜드에 맞춰 보세요. 제공되는 테마 프리셋 중에서 고르거나 색상을 직접 바꿀 수 있어요.

## 맞춤 지표에서 SLA 사용하기

**맞춤 지표**에서는 SLA 충족과 SLA 위반을 이미 기준 항목으로 쓸 수 있어요. **Formula builder**(수식 빌더)에서 이 둘을 조합하면 SLA 데이터를 숫자 하나로 보여 주는 KPI를 만들 수 있어요.

![맞춤 지표 수식 빌더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073572964/original/l285EZyxjKAJkGqTpbmT-Xy6bZ8qUCaV5g.png?1781286788)

### SLA 준수율 맞춤 지표 만들기

1. **대시보드 > 맞춤 지표**로 이동한 다음, **Create Custom Metric**(맞춤 지표 만들기)을 클릭하세요.
2. **Metric name**(지표 이름)에 SLA 준수율을 입력하고, **표시 형식**을 **Percentage**(백분율)로 설정하세요.
3. **Formula builder**에 다음 수식을 입력하세요: ( SLA 충족 / ( SLA 충족 + SLA 위반 ) ) × 100
4. 수식에서 SLA 충족을 클릭하면 오른쪽에 **Configuration**(구성) 패널이 열려요.
5. **필터** 아래에서 **날짜 속성**을 **Inbound at**으로 설정하고, 필요한 필터가 더 있으면 추가하세요.
6. 수식의 SLA 위반에도 같은 설정을 반복하세요.
7. **비교 값**을 **증가는 양수입니다**로 설정하세요. 준수율은 높을수록 좋기 때문이에요.
8. **만들기**를 클릭하세요.

### 만들 수 있는 KPI 예시

- SLA 준수율: ( SLA 충족 / ( SLA 충족 + SLA 위반 ) ) × 100
- SLA 위반 건수: SLA 위반 (해당 기간의 건수 그대로)
- SLA 충족 건수: SLA 충족 (해당 기간의 건수 그대로)

## 자주 묻는 질문

### SLA 위젯은 위젯 패널 어디에 있나요?
**대화** 섹션 맨 아래, **New Conversations started (This Week)**(이번 주 시작된 새 대화) 밑에 있어요.

### SLA 위젯의 최대 날짜 범위는 얼마인가요?
최대 1년까지 지원해요.

### SLA 위젯에서 어떤 지표를 쓸 수 있나요?
SLA 충족 %, SLA 위반 %, 평균 응답 시간, SLA 충족(건수), SLA 위반(건수)을 쓸 수 있어요.

### View By 옵션에는 어떤 것이 있나요?
**Inbound at**, **배정된 사용자**, **메시지 채널**이 있어요.

### 어떤 메시지 채널로 필터링할 수 있나요?
통화, SMS, 이메일, 웹 채팅, Facebook, GMB, Instagram이에요.

### 특정 팀원의 SLA 데이터만 볼 수 있나요?
네. **Conditions** 탭에서 **배정된 사용자** 조건을 쓰세요. 서브 계정의 팀원 중 한 명을 고르면 돼요. **Logged in user**를 고르면 현재 로그인한 사용자의 대화만 보여 줘요.

### 같은 대시보드에서 SLA 위젯과 다른 대화 위젯을 함께 쓸 수 있나요?
네. 대화량, 배정, 채널 분포, SLA 등 **대화** 위젯은 모두 같은 대시보드에 둘 수 있어서 한 화면에서 통합해 볼 수 있어요.

### 고객에게 SLA 리포트를 정기적으로 보낼 수 있나요?
네. **사용자 지정 리포트**에 SLA 위젯을 추가하고, 매일·매주·매월 자동으로 이메일이 발송되도록 일정을 설정하세요.

### 맞춤 지표에서도 SLA 데이터를 쓸 수 있나요?
네. SLA 충족과 SLA 위반을 **맞춤 지표**의 수식 빌더에서 쓸 수 있어요. 이 둘로 SLA 준수율 같은 KPI를 만들어 보세요.

### SLA 위젯에 데이터가 안 보여요.
가장 흔한 원인은 이 서브 계정에서 SLA가 꺼져 있는 경우예요. **대화 > 설정 > SLA**로 이동해서 먼저 SLA를 켜세요. 켠 뒤부터 발생한 데이터가 위젯에 채워지기 시작해요. 그 밖에 다음과 같은 원인도 있어요. 선택한 날짜 범위에 SLA 활동이 없거나, 날짜 범위가 1년을 넘었거나, 필터가 너무 좁은 경우예요.

### SLA 위젯은 어떤 요금제에서 쓸 수 있나요?
대시보드와 리포팅 기능이 포함된 모든 요금제에서 쓸 수 있어요.
