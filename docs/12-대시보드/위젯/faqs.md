# 대시보드 FAQ

커스텀 대시보드와 위젯의 요금제, 역할별 권한, 날짜 기준 등 자주 묻는 질문을 모았어요. 대시보드를 설정하다 막힐 때 참고하세요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 일반 질문

### 커스텀 대시보드 위젯은 어떤 요금제에서 쓸 수 있나요?

여러 개의 커스텀 대시보드, 위젯, 사용자 지정 리포트는 $297 요금제와 $497 이상 요금제에서 쓸 수 있어요.

### 위젯 데이터의 시간·날짜 형식이 다른 화면과 달라요. 왜 그런가요?

현재 대시보드 위젯은 일관성을 위해 시스템 시간대와 날짜 형식을 사용해요. 모든 사용자에게 맞지는 않을 수 있다는 점을 알고 있어요. 대시보드 위젯 안에서 시간과 날짜 형식을 바꿀 수 있는 기능을 준비하고 있어요.

### 커스텀 위젯은 어떤 역할이 쓸 수 있나요?

$497 이상 요금제에서는 **에이전시 관리자**와 **Agency User**(에이전시 사용자)가 커스텀 위젯으로 대시보드를 수정할 수 있어요. $497 이상 요금제 계정에서 대시보드 접근 권한은 역할에 따라 달라요.

- **에이전시 관리자** ➝ 편집 및 조회 권한 모두 있음
- **Agency User** ➝ 편집 및 조회 권한 모두 있음
- **계정 관리자** ➝ 조회 권한
- **계정 사용자** ➝ 조회 권한 (**사용자 권한** 설정에 따라 달라요)

### 대시보드 권한은 어떻게 설정하나요?

사용자의 대시보드 권한은 다음 순서로 바꿀 수 있어요.

1. **설정 > 스태프 관리**로 이동하세요.
2. 권한을 바꾸려는 사용자 옆의 **편집**을 클릭하세요.
3. **사용자 권한** 섹션에서 필요한 항목을 바꾸세요. 대시보드와 관련된 권한은 다음과 같아요.

|  |  |
| --- | --- |
| **Dashboard Stats**(대시보드 통계) | 대시보드 전체에 접근할 수 있어요. **계정 관리자**와 **계정 사용자**는 보기만 할 수 있어요. |
| **연락처** | 모든 연락처와 연락처 관련 위젯에 접근할 수 있어요. |
| **Opportunity**(기회) | 모든 기회와 기회 관련 위젯에 접근할 수 있어요. |
| **Appointment**(예약) | 모든 예약과 예약 관련 위젯에 접근할 수 있어요. |
| **Lead value**(리드 가치) | 대시보드에서 금액과 관련된 위젯에 접근할 수 있어요. |
| **Only Assigned data**(배정된 데이터만) | 켜면 커스텀 위젯에 데이터가 표시되지 않아요. |

### 대시보드를 보는 팀원 본인의 데이터만 위젯에 표시하려면 어떻게 하나요?

팀원이 대시보드 위젯에서 자신의 데이터만 보게 하려면, 각 위젯의 **Conditions**(조건) 탭에서 **USER**(사용자) > **LOGGED IN USER**(로그인한 사용자) 조건을 설정하세요. 이렇게 하면 팀원마다 자신의 데이터만 위젯에 표시돼요.

### 새 대시보드에서 기회 수가 맞지 않아요. 왜 그런가요?

기회의 날짜 기준이 이전의 **생성일**에서 **Last Status Change**(마지막 상태 변경일)로 바뀌었어요. 이전에 만든 기회가 업데이트되면 전체 차트 개수에 포함되기 때문에 새 대시보드의 기회 수가 달라 보일 수 있어요.

이럴 때는 위젯에서 사용하는 날짜 속성을 바꿀 수 있어요.

- 일반 위젯: 위젯의 필터 아이콘을 클릭하고 날짜 속성을 바꾸세요. 한 필터에서 바꾸면 나머지 일반 필터에도 자동으로 적용돼요.  
  ![위젯의 필터 아이콘 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155013893411/original/hGP9vr-CceskSunU0YQHHwivCCiKtNYf0w.png?1701245396)  
  ![날짜 속성 변경 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155013893429/original/hlFooSebrvx_XMUh3A4UCbS_Ptu5ABFgBg.png?1701245419)
- $497 이상 요금제 사용자: 커스텀 위젯을 추가하고 위젯 설정에서 날짜 속성을 직접 지정할 수 있어요. $497 이상 요금제에서만 쓸 수 있는 기능이에요.

### **그룹 기준**이나 **View By**(보기 기준)에서 **세션 소스**나 **Session Medium**(세션 매체)을 선택할 수 없어요.

위젯 설정에서 필터 그룹을 여러 개 사용하면 이런 일이 생겨요. **세션 소스**나 **Session Medium**을 그룹 기준으로 쓰려면 필터 그룹이 하나만 있어야 해요. 그 그룹에는 **Attribution Type**(어트리뷰션 유형) 필터가 들어 있어야 하고, 값은 **First Touch**(첫 접점)나 **Last Touch**(마지막 접점) 중 하나예요. 필터 그룹을 둘 이상 추가하면 정확성과 일관성을 위해 어트리뷰션 기반 그룹 기준을 쓸 수 없어요.
