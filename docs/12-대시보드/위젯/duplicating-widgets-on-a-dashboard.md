# 대시보드에서 위젯 복제하기

대시보드에 있는 위젯을 그대로 복사해서 새 위젯으로 만들 수 있어요. 설정이 비슷한 위젯을 여러 개 만들 때 처음부터 새로 만들지 않아도 돼서 시간이 절약돼요.

기존 위젯을 복제한 뒤 필요한 부분만 고쳐서 새 위젯으로 저장하면 돼요. 구성이 복잡하거나 같은 작업을 자주 반복하는 위젯이라면 특히 편해요.

## 1단계: 대시보드 편집 모드로 들어가기

1. 위젯을 복제할 대시보드로 이동하세요.
2. **편집**을 클릭해 대시보드를 편집 모드로 바꾸세요.

![대시보드 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039846910/original/tuzPpDm4C9rlw0Ea8R9JnCuclT-P6GdgFQ.png?1736925385)

## 2단계: 위젯 복제하기

1. 복제할 위젯을 찾으세요.
2. 위젯 카드 오른쪽 위에 있는 점 세 개 메뉴(⋮)를 클릭하세요.
3. 드롭다운 메뉴에서 **중복**을 선택하세요.
4. 대시보드에 위젯의 복제본이 나타나요.

![위젯 카드의 점 세 개 메뉴에서 중복 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039846971/original/m1gBvM8iKmtzvTgUXhQzj64pQJGfBGfEYg.png?1736925420)

## 3단계: 복제한 위젯을 수정하고 변경사항 저장하기

1. 복제된 위젯에서 바꾸고 싶은 부분을 수정하세요.
2. 수정을 마쳤으면 **저장**을 클릭해 위젯을 마무리하세요.
