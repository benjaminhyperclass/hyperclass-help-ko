# 퍼널 위젯과 Stages Distribution 위젯의 차이와 사용법

하이퍼클래스의 **퍼널** 위젯과 **Stages Distribution**(단계별 분포) 위젯은 기회 현황을 서로 다른 방식으로 보여 줘요. 퍼널은 기회가 파이프라인 단계를 순서대로 거치며 얼마나 진행했는지 보여 주고, **Stages Distribution**은 열린 기회가 지금 어느 단계에 있는지 보여 줘요. 목적에 맞는 위젯을 고르면 전환 분석과 일상적인 파이프라인 확인을 나눠서 볼 수 있어요.

이 문서에서는 두 위젯이 기회 데이터를 계산하는 방식, 퍼널의 전환율과 매출 계산, 단계 표시 설정, 대시보드에 위젯을 추가하는 방법을 알아봐요.

{% hint style="warning" %}
퍼널은 순차적인 진행 상황을 보기 위한 위젯이고, **Stages Distribution**은 현재 위치를 보기 위한 위젯이에요. 그래서 같은 기회라도 두 위젯에서 다르게 표시될 수 있어요.
{% endhint %}

## 퍼널 위젯과 Stages Distribution 위젯이란?

퍼널과 **Stages Distribution**은 하이퍼클래스 파이프라인의 기회 데이터를 시각화하는 **일반** 카테고리의 대시보드 위젯이에요.

- **퍼널** 위젯은 표시하도록 설정한 파이프라인 단계를 순서대로 따라가며 보여 줘요. 전환율과 이탈 지점을 확인할 때 써요.
- **Stages Distribution** 위젯은 열린 기회가 지금 어느 단계에 있는지 보여 줘요. 고객전환성공과 고객전환실패 기회는 따로 표시해요.

### 이럴 때 좋아요

목적에 맞는 위젯을 쓰면 기회의 진행 흐름이나 현재 파이프라인 상태를 더 분명하게 볼 수 있어요.

- 파이프라인 진행 상황 추적: 퍼널로 기회가 단계를 거치며 어떻게 나아가는지 확인해요.
- 전환 이탈 지점 파악: 퍼널의 각 구간을 비교해서 어느 구간부터 다음으로 넘어가는 기회가 줄어드는지 찾아요.
- 현재 파이프라인 분포 확인: **Stages Distribution**으로 열린 기회가 지금 어느 단계에 있는지 확인해요.
- 결과와 진행 중인 단계 분리: **Stages Distribution**에서 고객전환성공과 고객전환실패 기회를 따로 살펴봐요.
- 리포팅 표시 범위 조정: 퍼널과 **Stages Distribution** 리포팅에 표시할 파이프라인 단계를 직접 정해요.
- 파이프라인 전환: 위젯의 파이프라인 드롭다운으로 다른 파이프라인을 확인해요.

## 사전 준비와 제한 사항

파이프라인 구성, 표시 설정, 대시보드 접근 권한이 맞아야 두 위젯에 기대한 기회 데이터가 나와요.

- 기회 단계가 있는 파이프라인을 하나 이상 만드세요.
- 퍼널 또는 원형 차트 리포팅에 표시할 단계를 켜세요.
- 사용자에게 **Dashboard Stats**(대시보드 통계) 권한이 있는지 확인하세요.
- 사용자가 위젯이 들어 있는 대시보드에 접근할 수 있는지 확인하세요.
- 퍼널 단계는 기회가 진행될 것으로 예상하는 순서대로 배치하세요.

고객전환성공과 고객전환실패는 기회의 상태라서 파이프라인 단계로 따로 만들 필요가 없어요. 또 퍼널은 선택한 리포팅 기간을 계산할 때 기회의 **생성일**이 아니라 마지막 상태 변경일을 기준으로 해요.

## 퍼널과 Stages Distribution의 차이

핵심은 프로세스를 거친 진행 정도를 측정할 것인지, 파이프라인 안의 현재 위치를 볼 것인지예요.

| 위젯 | 알맞은 용도 | 기회가 표시되는 방식 |
| --- | --- | --- |
| **퍼널** | 순차적인 전환 분석 | 뒤쪽 단계에 있는 기회도 프로세스를 거쳐 왔기 때문에 앞쪽 퍼널 구간에 함께 집계돼요. |
| **Stages Distribution** | 현재 파이프라인 모니터링 | 열린 기회는 지금 있는 단계에만 표시돼요. 고객전환성공과 고객전환실패는 따로 표시돼요. |

예를 들어 열린 기회가 지금 '제안서 발송' 단계에 있다고 해 볼게요. **Stages Distribution**에는 이 기회가 '제안서 발송' 단계에 표시돼요. 퍼널에서는 이 기회가 앞쪽 단계도 거쳐 왔기 때문에, 표시 중인 앞쪽 구간에도 함께 집계될 수 있어요.

## 퍼널 위젯의 계산 방식

퍼널은 누적 방식으로 계산해요. 그래서 각 구간은 해당 지점에 도달했거나 그보다 더 나아간 기회를 나타내요.

기본 공식: 퍼널 구간의 기회 수 = 현재 표시 단계부터 마지막 표시 단계까지의 기회 수(해당하는 고객전환성공 기회 포함)

퍼널이 뒤로 진행될수록 다음과 같이 계산돼요.

- 아직 앞쪽 단계에 머물러 있는 기회는 뒤쪽 퍼널 구간에서 빠져요.
- 뒤쪽 단계까지 도달한 기회는 해당하는 앞쪽 구간에도 집계돼요.
- 고객전환성공은 마지막 성공 결과로 표시돼요.
- 고객전환성공 기회는 프로세스를 끝까지 마쳤기 때문에 앞쪽 퍼널 구간에도 집계돼요.

### 퍼널 전환율

퍼널은 전환율을 두 가지로 보여 줘요. 전체 진행 정도와 단계별 성과를 모두 확인할 수 있어요.

- 누적 전환율: 퍼널의 시작을 기준으로 얼마나 진행했는지 보여 줘요.
- 다음 단계 전환율: 바로 앞 퍼널 구간을 기준으로 얼마나 진행했는지 보여 줘요.

### 퍼널 매출

매출도 기회 수와 같은 순차 방식으로 계산해요. 뒤쪽 단계에 있는 기회와 고객전환성공 기회의 기회 가치는 해당하는 앞쪽 퍼널 구간에도 포함돼요.

## Stages Distribution 위젯의 계산 방식

**Stages Distribution**은 누적 방식을 쓰지 않고, 열린 기회가 지금 어느 단계에 있는지를 보여 줘요.

- 열린 기회는 현재 표시 중인 파이프라인 단계에 표시돼요.
- 고객전환성공 기회는 따로 표시돼요.
- 고객전환실패 기회도 따로 표시돼요.
- 위젯은 표시된 분포에 대한 전환 정보도 함께 보여 줘요.

## 파이프라인 표시 설정 방법

파이프라인 표시 설정으로 퍼널과 **Stages Distribution** 리포팅에 포함할 단계를 정해요.

1. **서브 계정 보기**에서 **기회 관리**(Opportunities)를 클릭하세요.
2. **파이프라인**을 선택하세요.
3. 설정할 파이프라인을 여세요.
4. 파이프라인 단계를 찾으세요.
5. **퍼널 아이콘**으로 퍼널 리포팅 표시 여부를 설정하세요.
6. **원형 차트 아이콘**으로 **Stages Distribution** 리포팅 표시 여부를 설정하세요.
7. 파이프라인 변경 사항을 저장하세요.

{% hint style="info" %}
고객전환성공과 고객전환실패는 기회 상태로 자동 생성되므로 파이프라인 단계로 추가할 필요가 없어요.
{% endhint %}

## 대시보드에 퍼널 또는 Stages Distribution 추가하기

두 위젯을 같은 대시보드에 추가하면 대시보드를 벗어나지 않고 순차 전환과 현재 파이프라인 위치를 나란히 비교할 수 있어요.

1. **서브 계정 보기**에서 **대시보드**를 여세요.
2. 수정할 대시보드를 여세요.
3. **Edit Dashboard**(대시보드 편집)를 클릭하세요.
4. **+ Add Widget**(위젯 추가)을 클릭하세요.
5. **일반** 위젯 카테고리를 찾으세요.
6. **퍼널** 또는 **Stages Distribution**을 선택하세요.
7. 위젯에서 설정할 수 있는 항목을 설정하세요.
8. 필요에 따라 위젯의 위치를 옮기거나 크기를 조절하세요.
9. **변경사항 저장**을 클릭하세요.

## 자주 묻는 질문

### 퍼널과 Stages Distribution은 무엇이 다른가요?

퍼널은 기회의 순차적인 진행 상황을 보여 줘요. **Stages Distribution**은 열린 기회가 지금 어느 단계에 있는지 보여 주고, 고객전환성공과 고객전환실패는 따로 표시해요.

### 퍼널에서는 기회가 지금 있지 않은 단계에도 집계되는 이유가 뭔가요?

퍼널은 누적 진행 방식으로 계산해요. 뒤쪽 단계에 도달한 기회는 그 앞의 단계들을 거쳐 왔기 때문에 해당하는 앞쪽 퍼널 구간에도 집계돼요.

### 고객전환성공과 고객전환실패 파이프라인 단계를 만들어야 하나요?

아니요. 하이퍼클래스에서는 고객전환성공과 고객전환실패를 기회 상태로 지원하기 때문에 파이프라인 단계로 따로 만들 필요가 없어요.

### 노쇼, 고객 답변 대기, 후속 조치 필요 같은 단계를 볼 때는 어떤 위젯이 더 좋은가요?

열린 기회가 지금 정확히 어느 단계에 있는지 봐야 할 때는 일반적으로 **Stages Distribution**이 더 유용해요.

### 퍼널이나 Stages Distribution에 파이프라인 단계가 보이지 않아요.

**기회 관리 > 파이프라인**에서 해당 파이프라인을 편집한 뒤, 그 단계의 퍼널 또는 원형 차트 표시 설정이 켜져 있는지 확인하세요.

### 퍼널은 리포팅에 어떤 날짜를 기준으로 쓰나요?

퍼널은 선택한 리포팅 기간을 계산할 때 기회의 마지막 상태 변경일을 기준으로 해요.

### 다른 기회 리포트와 합계가 다른 이유가 뭔가요?

위젯마다 계산 방식, 날짜 기준, 필터, 표시 설정, 리포팅 방식이 다를 수 있어요. 합계를 비교하기 전에 이런 설정부터 비교해 보세요.

### 더 세부적으로 설정할 수 있는 기회 위젯도 있나요?

네. 하이퍼클래스에는 차트 유형, 조건, 파이프라인 단계, 상태, 담당자, 어트리뷰션 데이터 등 여러 필터를 설정할 수 있는 전용 기회 위젯이 있어요.
