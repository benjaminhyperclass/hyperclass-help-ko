# 서브 계정 대시보드의 일반 위젯 설정과 필터

서브 계정 대시보드의 일반 위젯(General Widgets)은 직접 편집할 수 있어요. 고정 **조건**을 걸고, 위젯별 날짜 범위를 정하고, 이전 기간과 비교할 수 있어요. 제목 변경, 테마 적용, 위젯 **중복**과 **삭제**도 가능해요. 미리 만들어진 위젯을 커스텀 위젯으로 다시 만들지 않아도, 팀에 맞는 리포트 화면을 꾸밀 수 있어요.

## 편집할 수 있는 일반 위젯이란?

일반 위젯은 서브 계정에 기본으로 들어 있는 위젯이에요. 위젯을 처음부터 만들지 않아도 주요 비즈니스 지표를 볼 수 있어요. 이제 이 위젯을 편집할 수 있어서, 팀의 리포팅 목적에 맞는 데이터를 대시보드에 보여 줄 수 있어요.

일반 위젯에서는 제목, 리포팅 날짜, 비교 기간, 저장된 조건, 시각 테마를 바꿀 수 있어요. 위젯을 복제해 다른 버전의 리포트를 만들 수도 있고, 더 이상 필요 없으면 삭제할 수도 있어요.

위젯 화면에는 현재 적용된 날짜 속성과 날짜 범위도 함께 표시돼요. 그래서 보는 사람이 표시된 값이 어떤 기준으로 집계됐는지 바로 알 수 있어요.

---

## 편집 가능한 일반 위젯의 장점

미리 만들어진 위젯의 편리함은 그대로 두고, 기본 대시보드를 더 유연하게 쓸 수 있어요.

- 고정 데이터 필터: 배정된 사용자, 태그, 소스, 리드 금액, 커스텀 필드, 어트리뷰션 같은 필드를 기준으로 **조건**을 추가할 수 있어요.
- 위젯별 리포팅 기간: 대시보드 전체의 날짜 범위와 별개로, 위젯 하나에만 다른 날짜 범위를 정할 수 있어요.
- 기간 비교: 현재 리포팅 기간을 **지난해** 또는 **Last period**(직전 기간)와 비교할 수 있어요.
- 명확한 날짜 기준: 위젯에서 바로 현재 날짜 속성과 날짜 범위를 확인할 수 있어요.
- 맞춤 제목: 팀이나 고객사가 이해하기 쉬운 표현으로 위젯 이름을 바꿀 수 있어요.
- 시각 맞춤 설정: 위젯을 다시 만들지 않고도 테마를 적용할 수 있어요.
- 빠른 리포트 변형: 설정을 마친 위젯을 복제해서 조건이나 날짜 설정만 바꿔 쓸 수 있어요.
- 깔끔한 대시보드: 필요 없는 일반 위젯은 삭제할 수 있어요.

## 일반 위젯 편집하고 설정하기

일반 위젯을 편집하면 설정 창이 열려요. 여기서 리포팅 설정을 바꾸고, 조건을 추가하고, 테마를 고를 수 있어요.

1. **서브 계정** 화면에서 왼쪽 메뉴의 **대시보드**를 선택하세요.
2. 오른쪽 위의 **대시보드 수정**을 클릭하세요.
3. 설정하려는 일반 위젯을 찾으세요.
4. 위젯 위에 마우스를 올리고 점 세 개 메뉴(**⋮**)를 클릭하세요.
5. **편집**을 선택하세요.
6. 위젯 편집 창이 열리고 **구성**, **조건**, **테마** 탭이 보여요.
7. 필요한 내용을 바꾸세요.
8. **저장**을 클릭하세요.

---

## 위젯 제목과 리포팅 기간 설정하기

**구성** 탭에서는 위젯 제목과 날짜 설정을 관리해요. 이 설정으로 위젯이 무엇을 측정하는지, 어떤 기간을 기준으로 값을 계산하는지 보여 줄 수 있어요.

### 위젯 제목 바꾸기

1. **편집** 탭을 여세요.2. **제목** 필드를 찾으세요.
3. 위젯에 표시할 제목을 입력하세요.

팀이나 고객사가 더 쉽게 이해하는 표현으로 일반 위젯의 이름을 바꿀 수 있어요.

![위젯 제목 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082174510/original/sUYhnkVvBxdSUNPzi7wPNQRqrMWJi45jag.png?1790757521)

### 고급 설정 구성하기

1. **구성** 탭에서 **고급 설정**을 펼치세요.
2. **날짜 속성**에서 위젯 데이터를 계산할 때 기준으로 삼을 날짜 필드를 선택하세요.
3. **날짜 범위 재정의**에서 이 위젯에만 적용할 리포팅 기간을 정하세요.
4. **비교 날짜 범위**에서 선택한 기간과 비교할 기간을 고르세요.
5. **저장**을 클릭하세요.

![고급 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082174608/original/io1InCNxSRhvhhxWAkxNT-KBGirTbjdUXA.png?1790757580)

비교 기간으로는 **지난해**와 **Last period**를 선택할 수 있어요.

위젯의 날짜 범위 재정의는 대시보드 전체의 날짜 범위와 따로 적용돼요. 그래서 비슷한 위젯 두 개가 서로 다른 기간의 데이터를 보여 줄 수 있어요.

위젯 화면에는 현재 적용된 날짜 속성과 날짜 범위가 표시돼요. 보는 사람이 값이 어떤 기준으로 나왔는지 알 수 있어요.

## 조건으로 고정 데이터 필터 추가하기

**조건** 탭에서는 어떤 데이터가 일반 위젯에 집계될지 정해요. 여기서 만든 필터는 위젯에 계속 저장돼요. 그래서 늘 같은 기준으로 보는 리포팅 세그먼트에 쓰기 좋아요.

다음 일반 위젯에는 이제 **조건** 탭이 있어요.

| 위젯 | 사용할 수 있는 조건 | 참고 |
| --- | --- | --- |
| **기회 상태**, **Opportunity Value**(기회 금액), **전환율**, **퍼널**, **Stages Distribution**(단계별 분포), **Lead Source Report**(리드 소스 리포트) | **배정된 사용자**, **Followers**(팔로워), **태그**, **주 연락처 이름**, **Lead value**(리드 금액), **커스텀 필드**, **Source**(소스), **Attribution**(어트리뷰션) | 파이프라인은 조건이 아니라 위젯 설정에서 선택해요. |
| **Sales Efficiency**(영업 효율) | **Followers**, **태그**, **주 연락처 이름**, **Lead value**, **커스텀 필드**, **Source**, **Attribution** | 사용자별로 필터링하려면 위젯에 있는 사용자 드롭다운을 사용하세요. |
| **Google Analytics Count**(Google Analytics 카운트), **Google Analytics Chart**(Google Analytics 차트) | **Country**(국가), **기기 카테고리**, **세션 기본 채널 그룹**, **세션 소스**, **세션 매체**, **Session source/medium**(세션 소스/매체), **최초 사용자 소스**, **최초 사용자 매체**, **Page path**(페이지 경로), **Page title**(페이지 제목), **랜딩 페이지**, **Event name**(이벤트 이름), **User type**(사용자 유형), **커스텀 필드** | |
| **Facebook Ads Report**(Facebook 광고 리포트) | **Campaign**(캠페인), **Ad set**(광고 세트), **Ad name**(광고 이름), **Objective**(목표), **노출 0건**, **Frequency**(빈도) | 광고 계정은 **연동** 탭에서 선택해요. |
| **Google Ads Report**(Google 광고 리포트) | **Campaign**, **Ad group**(광고 그룹), **Ad name**, **캠페인 유형**, **Network**(네트워크), **캠페인 상태** | 광고 계정은 **연동** 탭에서 선택해요. |

다음 일반 위젯에는 현재 **조건** 탭이 없어요.

- **작업**: 제목과 대시보드 날짜 범위를 편집할 수 있어요. 날짜 속성은 마감일에 적용돼요.
- **수동 작업**: 제목과 대시보드 날짜 범위를 편집할 수 있어요. 날짜 속성은 생성일에 적용돼요.
- **Google 비즈니스 프로필**: 제목만 편집할 수 있어요.
- **Email Health Report**(이메일 상태 리포트): 제목과 대시보드 날짜 범위 재정의를 편집할 수 있어요.

조건에서 쓸 수 있는 필드는 위젯과 그 위젯의 원본 데이터에 따라 달라요.

![조건에서 선택할 수 있는 필드 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082174894/original/tqDfEdecQ7RDLGBGJLdPnuaJ14Xp-R_L9A.png?1790757681)

### 조건 추가하기

1. 위젯 편집 창에서 **조건**을 선택하세요.
2. 필터링할 필드를 선택하세요.
3. 알맞은 연산자를 선택하세요.
4. 값을 선택하거나 입력하세요.
5. 같은 필터 그룹 안에서 다른 조건도 함께 맞아야 하면 **+ 그리고**를 클릭하세요.
6. 다른 필터 그룹을 만들려면 **+ Add filter**(필터 추가)를 클릭하세요.
7. 위젯에 필요한 조건을 더 추가하세요.
8. **저장**을 클릭하세요.

같은 그룹 안의 조건은 **그리고** 방식으로 적용돼요. 서로 다른 필터 그룹은 **또는** 방식으로 적용돼요.

예를 들어 커스텀 필드로 필터링하려면 이렇게 설정할 수 있어요.

**커스텀 필드** → 부동산 유형 → **다음 중 하나** → 선택한 부동산 유형

소스와 태그처럼 지원되는 기준을 함께 써서 더 좁은 범위의 리포트를 만들 수도 있어요.

## 일반 위젯에 테마 적용하기

테마를 쓰면 커스텀 위젯으로 다시 만들지 않고도 일반 위젯의 모양을 바꿀 수 있어요. 리포팅 그룹을 구분하거나, 고객에게 보여 줄 대시보드 분위기에 맞출 때 도움이 돼요.

1. 위젯 편집 창에서 **테마**를 선택하세요.
2. 적용할 시각 테마를 선택하세요.
3. 바뀐 위젯 모양을 확인하세요.
4. **저장**을 클릭하세요.

![위젯 테마 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082175129/original/Rnyx8epnRGJuYEA83UGtAvZn_dB-FbSOyw.png?1790757801)

## 일반 위젯 중복하거나 삭제하기

설정을 마친 위젯을 복제하면, 같은 출발점에서 리포트 변형을 쉽게 만들 수 있어요. 필요 없어진 위젯은 대시보드가 편집 모드일 때 삭제할 수 있어요.

### 일반 위젯 중복하기

1. **서브 계정** 화면에서 **대시보드**를 선택하세요.
2. 점 세 개 메뉴(**⋮**)를 클릭하세요.
3. **중복**을 선택하세요.
4. 복제된 위젯을 필요에 맞게 편집하세요.

같은 기본 위젯으로 사용자, 소스, 태그, 커스텀 필드 값, 리포팅 기간을 서로 비교하고 싶을 때 유용해요.

![위젯 중복 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082175433/original/YACiGRsTfTzrHwtQP7LMz-V6vNZO40kaQw.png?1790757991)

### 일반 위젯 삭제하기

1. **서브 계정** 화면에서 **대시보드**를 선택하세요.
2. 점 세 개 메뉴(**⋮**)를 클릭하세요.
3. **삭제**를 선택하세요.

![위젯 삭제 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082175372/original/h2wQV1ynNkr9AG40QnwgLwHqql008N4O4A.png?1790757950)

## 자주 묻는 질문

### 일반 위젯에 건 조건은 계속 저장되나요?
네. 편집 모드에서 나와 대시보드로 돌아가도 조건이 위젯에 그대로 적용돼요.

### 일반 위젯에 대시보드와 다른 날짜 범위를 쓸 수 있나요?
네. **구성 > 고급 설정**의 **날짜 범위 재정의**에서 해당 위젯에만 적용할 리포팅 기간을 정할 수 있어요.

### 리포팅 기간을 다른 기간과 비교할 수 있나요?
네. **비교 날짜 범위**를 사용하면 현재 기간을 **지난해**나 **Last period** 같은 기간과 비교할 수 있어요.

### 조건을 여러 개 함께 쓸 수 있나요?
네. 같은 필터 그룹 안의 조건이 모두 맞아야 하면 **+ 그리고**를 사용하세요. 서로 다른 필터 그룹은 **또는** 방식으로 적용돼요.

### 같은 일반 위젯을 여러 버전으로 만들 수 있나요?
네. **중복**을 사용한 다음, 복제된 위젯의 제목, 조건, 날짜 설정, 테마를 바꾸세요.

### 필요 없어진 일반 위젯을 없앨 수 있나요?
네. **대시보드 수정**에 들어가 위젯의 점 세 개 메뉴를 열고 **삭제**를 선택하세요.

### 일반 위젯에도 대시보드의 빠른 필터가 적용되나요?
아니요. 일반 위젯의 대시보드 **빠른 필터** 지원은 현재 릴리스에 포함되어 있지 않아요.

### 퍼널 위젯과 수동 작업 위젯 안에 표시되는 내용을 설정할 수 있나요?
현재 일반 위젯 편집 릴리스에서는 할 수 없어요.
