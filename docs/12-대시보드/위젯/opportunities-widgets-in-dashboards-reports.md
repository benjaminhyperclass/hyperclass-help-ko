# 대시보드·리포트의 기회 위젯

기회 위젯을 쓰면 **대시보드**와 사용자 지정 리포트에서 파이프라인 현황을 바로 확인할 수 있어요. 이 문서에서는 위젯 종류, 그룹 기준, 날짜 기준, 조건 필터를 설명해요.

## 개요

기회 위젯으로 파이프라인을 대시보드와 사용자 지정 리포트 안에서 추적하고 분석할 수 있어요. 전체 기회 수와 매출 추이부터 고객전환실패 사유별 분포, 이번 달 고객전환성공 현황까지 볼 수 있어요. 하이퍼클래스를 벗어나지 않고 파이프라인 상태를 한눈에 파악할 수 있어요.

모든 기회 위젯은 여러 차트 유형을 지원해요. **조건**을 사용해 특정 **파이프라인**, **단계**, **상태**, **담당자**, 어트리뷰션 소스로 결과 범위를 좁힐 수도 있어요.

---

## 사용할 수 있는 기회 위젯

기회 위젯은 모두 **17개**예요. 위젯마다 기본 차트 유형이 정해져 있어요. 위젯 설정에서 지원되는 다른 차트 유형으로 바꿀 수 있어요.

| 번호 | 위젯 이름 | 기본 차트 | 측정값 | 보여 주는 내용 | 기본 필터 | 날짜 범위 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | **Opportunity Count**(기회 수) | 숫자 | 개수 | 전체 기회의 수 | 없음 | 대시보드 날짜 범위 |
| 2 | **Opened Opportunities**(진행 중인 기회 수) | 숫자 | 개수 | 현재 진행 중인 기회의 수 | 상태 = Open(진행 중) | 대시보드 날짜 범위 |
| 3 | **Opened Opportunity Value**(진행 중인 기회 금액) | 숫자 | 금액 합계 | 진행 중인 모든 기회의 금액 합계 | 상태 = Open | 대시보드 날짜 범위 |
| 4 | **Won Opportunities**(고객전환성공 기회 수) | 숫자 | 개수 | 고객전환성공 기회의 수 | 상태 = 고객전환성공 | 대시보드 날짜 범위 |
| 5 | **Won Opportunity Value**(고객전환성공 기회 금액) | 숫자 | 금액 합계 | 고객전환성공 기회의 금액 합계 | 상태 = 고객전환성공 | 대시보드 날짜 범위 |
| 6 | **Lost Opportunities**(고객전환실패 기회 수) | 숫자 | 개수 | 고객전환실패 기회의 수 | 상태 = 고객전환실패 | 대시보드 날짜 범위 |
| 7 | **Lost Opportunity Value**(고객전환실패 기회 금액) | 숫자 | 금액 합계 | 고객전환실패 기회의 금액 합계 | 상태 = 고객전환실패 | 대시보드 날짜 범위 |
| 8 | **Lost Opportunities By Reason**(사유별 고객전환실패 기회) | 도넛형 | 개수 | 고객전환실패 기회를 실패 사유별로 나눈 분포 | 상태 = 고객전환실패 | 대시보드 날짜 범위 |
| 9 | **Abandoned Opportunities**(포기된 기회 수) | 숫자 | 개수 | Abandoned(포기) 상태인 기회의 수 | 상태 = Abandoned | 대시보드 날짜 범위 |
| 10 | **Abandoned Opportunity Value**(포기된 기회 금액) | 숫자 | 금액 합계 | Abandoned 상태인 기회의 금액 합계 | 상태 = Abandoned | 대시보드 날짜 범위 |
| 11 | **Total Opportunity Value**(전체 기회 금액) | 숫자 | 금액 합계 | 상태와 상관없이 모든 기회의 금액 합계 | 없음 | 대시보드 날짜 범위 |
| 12 | **Opportunity Counts by Status**(상태별 기회 수) | 도넛형 | 개수 | 모든 상태에 걸친 기회의 분포 | 없음 | 대시보드 날짜 범위 |
| 13 | **Opportunity Counts Over Time**(기간별 기회 수 추이) | 줄 | 개수 | 기간에 따른 기회 생성 추이 | 없음 | 대시보드 날짜 범위 |
| 14 | **Opportunity Revenue Over Time**(기간별 기회 매출 추이) | 줄 | 금액 합계 | 기간에 따른 기회 매출 추이 | 없음 | 대시보드 날짜 범위 |
| 15 | **Won Opportunities This Month (For You)**(이번 달 고객전환성공 기회 수, 로그인한 사용자 기준) | 숫자 | 개수 | 로그인한 사용자에게 할당된 이번 달 고객전환성공 기회 | 상태 = 고객전환성공 + 할당된 사용자 = 로그인한 사용자 | 이번 달(고정) |
| 16 | **Won Opportunities Value This Month**(이번 달 고객전환성공 기회 금액) | 숫자 | 금액 합계 | 팀 전체의 이번 달 고객전환성공 매출 합계 | 상태 = 고객전환성공 | 이번 달(고정) |
| 17 | **Won Opportunities Value This Month (For You)**(이번 달 고객전환성공 기회 금액, 로그인한 사용자 기준) | 숫자 | 금액 합계 | 로그인한 사용자의 이번 달 고객전환성공 매출 합계 | 상태 = 고객전환성공 + 할당된 사용자 = 로그인한 사용자 | 이번 달(고정) |

{% hint style="info" %}
15, 16, 17번 위젯은 **고정 날짜 범위(이번 달)**를 사용해요. **Configure**(구성)에서 바꾸지 않으면 대시보드의 전체 날짜 범위 선택을 따르지 않아요.
{% endhint %}

{% hint style="info" %}
15번과 17번은 이름에 **추천**(For You)이 붙은 위젯이에요. 기본으로 들어 있는 **할당된 사용자** 필터 때문에 현재 로그인한 사용자 기준으로 집계돼요. 예약 발송 리포트에 넣으면 받는 사람이 아니라 리포트 소유자의 데이터가 표시돼요.
{% endhint %}

### 지원하는 차트 유형

17개 기회 위젯은 모두 위젯 설정에서 아래 차트 유형으로 바꿀 수 있어요.

| 차트 유형 | 적합한 용도 |
| --- | --- |
| **숫자** | 핵심 지표 하나, 간단한 개수나 금액 |
| **도넛형** | 카테고리별 분포(예: 상태별, 고객전환실패 사유별) |
| **바** | 카테고리 간 값 비교 |
| **줄** | 시간에 따른 추이 |
| **Horizontal Bar**(가로 바) | 레이블이 긴 카테고리를 많이 비교할 때 |
| **테이블** | 행 단위의 상세 내역 |

## 그룹 기준 옵션

세부 항목으로 나눠 볼 수 있는 위젯은 아래 필드로 묶어서 볼 수 있어요. 그룹 기준은 8, 12, 13, 14번 위젯에서 쓸 수 있어요.

| **그룹 기준** 옵션 | 묶는 기준 |
| --- | --- |
| **상태** | Open / 고객전환성공 / 고객전환실패 / Abandoned |
| **담당자** | 각 기회에 할당된 사용자 |
| **팔로워** | 기회를 팔로우하는 사용자 |
| **출처** | 기회 레코드의 출처 필드 |
| **파이프라인** | 기회가 속한 파이프라인 |
| **단계** | 파이프라인 안의 단계 |
| **고객전환실패 사유** | 기회를 고객전환실패로 표시할 때 기록한 사유 |
| **세션 소스** | 세션 단위의 유입 채널(예: 자연 검색, 유료 소셜) |
| **미디엄** | 어트리뷰션 매체(예: 폼, Facebook, 캘린더) |

{% hint style="info" %}
**그룹 기준**을 **상태** 조건과 함께 쓰면 더 깊이 분석할 수 있어요. 예를 들어 **상태**를 고객전환실패로 필터링한 뒤 **그룹 기준**을 **고객전환실패 사유**로 지정하면, 딜이 어디서 이탈하는지 정확히 볼 수 있어요.
{% endhint %}

## 날짜 속성

기회 위젯은 아래 날짜 필드를 기준으로 측정할 수 있어요. 날짜 속성은 대시보드 날짜 범위를 적용할 때 어떤 시각을 기준으로 삼을지 정해요.

| 날짜 속성 | 설명 |
| --- | --- |
| **생성일** | 기회가 만들어진 시점(대부분의 위젯에서 기본값) |
| **업데이트됨** | 기회 레코드가 마지막으로 수정된 시점 |
| **Status Change**(상태 변경일) | 기회의 상태가 마지막으로 바뀐 시점(예: 고객전환성공이나 고객전환실패로 표시한 시점) |

{% hint style="warning" %}
**Status Change 날짜 주의 사항:** **Status Change** 날짜는 기회가 특정 상태에 처음 들어간 시점이 아니라 *가장 최근* 상태가 바뀐 시점이에요. 고객전환실패로 표시했던 기회를 다시 열면 **Status Change** 날짜가 초기화돼요. 그래서 **Status Change**를 기준으로 한 과거 대시보드 수치는 시간이 지나면서 달라질 수 있어요. 과거 수치를 안정적으로 보려면 **생성일**을 쓰고 **상태**로 필터링하세요.
{% endhint %}

## 기회 위젯 필터링(조건)

모든 기회 위젯은 위젯 설정 패널의 **조건**으로 필터링할 수 있어요. 조건을 쓰면 위젯이 보여 줄 기회를 일부로 좁힐 수 있어요. 예를 들어 특정 파이프라인의 기회만, 또는 특정 사유로 고객전환실패가 된 기회만 볼 수 있어요.

조건 필드는 **24개**예요. 일반 필드와 어트리뷰션 필드로 나뉘어요.

---

| **팔로워** | 선택형 | **Is** / **Is not** / **Is one of** / **Is none of** / **Is empty** / 비어있지 않음 | 사용자/참조 검색 | |

| **리드 가치** | 숫자 | **Is** / **Is not** / 다음보다 큼 / 다음보다 크거나 같음 / 다음보다 작음 / 다음보다 작거나 같음 / **Is empty** / 비어있지 않음 | 숫자 입력 | |

### 어트리뷰션 필터

상위 필드인 **어트리뷰션**을 설정하면 추가 하위 필터를 쓸 수 있어요. 먼저 **첫 번째 어트리뷰션**이나 **최근 어트리뷰션** 중 하나를 선택하세요. 그러면 아래 하위 필드가 활성화돼요.

| 조건 필드 | 필요한 상위 필드 | 사용할 수 있는 연산자 | 값 입력 |
| --- | --- | --- | --- |
| **어트리뷰션** | — | **Is** | 첫 번째 어트리뷰션 / 최근 어트리뷰션 |
| **미디엄** | 어트리뷰션 | **Is** / **Is not** / **Is one of** / **Is none of** | 폼 / 설문 / 캘린더 / 채팅 위젯 / CSV 가져오기 / 수동 / API / 주문 폼 / 2단계 주문 폼 / Facebook / TikTok / 멤버십 / 대화 / Zapier / 기타 |
| **세션 소스** | 어트리뷰션 | **Is one of** / **Is none of** | Direct Traffic(직접 유입) / Organic Search(자연 검색) / Paid Search(유료 검색) / 소셜 미디어 / Paid Social(유료 소셜) / Referral(추천 유입) / Third Party(외부 서비스) / CRM UI(CRM 화면) / 이메일 마케팅 / 트리거 링크 / 기타 |
| **UTM 매체** | 어트리뷰션 | **Contains**(포함) | 텍스트 입력 |
| **UTM 소스** | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Campaign**(UTM 캠페인) | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Campaign ID**(UTM 캠페인 ID) | 어트리뷰션 | **Is** / **Is not** | 텍스트 입력 |
| **UTM 키워드** | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM 콘텐츠** | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Matchtype**(UTM 매치 유형) | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Ad ID**(UTM 광고 ID) | 어트리뷰션 | **Is** / **Is not** | 텍스트 입력 |
| **UTM Ad Group ID**(UTM 광고 그룹 ID) | 어트리뷰션 | **Is** / **Is not** | 텍스트 입력 |

{% hint style="info" %}
**어트리뷰션 필터가 동작하는 방식**

1. **조건** 패널에서 **어트리뷰션**을 **첫 번째 어트리뷰션** 또는 **최근 어트리뷰션**으로 설정해요.
2. 설정하고 나면 **미디엄**, **세션 소스**, 모든 UTM 필드를 쓸 수 있어요.
3. 모든 하위 필드는 선택한 접점(첫 번째 또는 최근)을 기준으로 적용돼요.
4. **그룹 기준**이나 **View By**(보기 기준) 드롭다운에서 **세션 소스**나 **미디엄**을 쓰면 복합 필터 그룹은 하나만 쓸 수 있어요. 그 그룹에는 어트리뷰션 유형이 들어 있어야 해요. 필터 그룹을 여러 개 추가하면 드롭다운에서 어트리뷰션 기반 필드를 쓸 수 없어요.
{% endhint %}

## 기회 위젯을 쓸 수 있는 곳

17개 기회 위젯은 모두 아래 두 곳에서 쓸 수 있어요.

- ✅ **대시보드** — 파이프라인을 상시 모니터링하고 매일 확인할 때
- ✅ 사용자 지정 리포트 — 예약 발송이나 고객에게 전달할 내보내기가 필요할 때

## 자주 묻는 질문

### **Won Opportunity Value**와 **Won Opportunities Value This Month**는 뭐가 다른가요?

**Won Opportunity Value**는 대시보드의 전체 날짜 범위를 따라요. 선택한 기간의 고객전환성공 매출을 보여 줘요. **Won Opportunities Value This Month**는 대시보드 날짜 범위 선택과 상관없이 항상 현재 캘린더 기준 이번 달을 보여 줘요.

### 지난달 기준으로 보면 고객전환성공/고객전환실패 숫자가 달라져요. 왜 그런가요?

날짜 속성으로 **Status Change**를 쓰고 있다면 정상적인 동작이에요. **Status Change**는 레코드의 *가장 최근* 상태 변경 시점이라서, 다시 열렸거나 다시 고객전환실패가 된 기회는 날짜가 소급해서 바뀌어요. 과거 수치를 안정적으로 보려면 날짜 속성을 **생성일**로 하고 **상태**로 필터링하세요.

### 기회를 파이프라인 단계별로 나눠 볼 수 있나요?

네, 볼 수 있어요. **Opportunity Counts by Status**나 **Opportunity Counts Over Time**을 쓰고 **그룹 기준 > 단계**로 설정하세요. 특정 파이프라인으로 먼저 범위를 좁히려면 **파이프라인** 조건 필터를 추가하세요.

### 고객전환실패 사유를 기록하지 않았다면 **Lost Opportunities By Reason**에는 무엇이 표시되나요?

사유 없이 고객전환실패로 표시한 기회는 도넛 차트에서 빈 값이나 **없음** 구간으로 나타나요. 이 위젯의 데이터를 깔끔하게 유지하려면 파이프라인 설정에서 **고객전환실패 사유**를 필수 필드로 설정하세요.

### 파이프라인이 서로 다른 팀원에게 **추천**(For You) 위젯은 어떻게 동작하나요?

**추천**(For You) 위젯은 로그인한 사용자의 **할당된 사용자** 값으로 필터링해요. 기본적으로 모든 파이프라인의 데이터를 합산해요. 범위를 더 좁히려면 **파이프라인** 조건을 추가하세요.

### 파이프라인을 먼저 선택하지 않고 특정 파이프라인 단계로 기회 위젯을 필터링할 수 있나요?

아니요, 할 수 없어요. **단계**는 종속 필드라서 **조건** 패널에서 **파이프라인**을 먼저 선택해야 해요. 파이프라인을 선택하면 그 파이프라인 안의 단계를 고를 수 있어요.

### 기회 위젯도 대시보드의 **빠른 필터**와 함께 동작하나요?

네, 동작해요. 대시보드 수준의 **빠른 필터**는 위젯 수준의 **조건** 위에 추가로 적용돼요. 위젯에 **상태** = 고객전환성공 조건이 걸려 있을 때 **담당자**에 대한 **빠른 필터**를 쓰면, 해당 담당자의 고객전환성공 기회로 한 번 더 좁혀져요.
