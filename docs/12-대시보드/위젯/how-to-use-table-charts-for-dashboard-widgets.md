# 대시보드 위젯에 표 차트 사용하기

대시보드 위젯을 표 형태로 보여 주는 방법을 안내해요. 위젯을 추가하고, 원하는 열을 고르고, 정렬 기준을 정하는 순서로 따라 하면 돼요.

---

## 1단계: 위젯 추가하기

1. **대시보드**로 이동해 **편집** 아이콘을 클릭하세요.
2. **Add widget**(위젯 추가)을 클릭하세요.

## 2단계: 표 차트 선택하기

1. 아래로 스크롤해 추가하려는 위젯을 찾으세요.
2. 차트 유형을 표로 바꾸세요.

![차트 유형을 표로 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155022885087/original/Tv-DNpkI8qeG5vXbj_anl0A3YGPmNnTQKg.png?1710421262)

## 3단계: 위젯 설정하기

1. **Select Columns**(열 선택)를 클릭해 위젯에 표시할 열을 고르세요.

   ![위젯에 표시할 열을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155022885097/original/EyMRUGmsd3nGgTZ5OvmnuAA5nQVsch5a9w.png?1710421277)

2. **고급 설정**에서 표를 정렬할 기준 열을 고르세요.

   ![고급 설정에서 정렬 기준 열을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155022885142/original/8rZzu6fO66Tq1o4iEUxrllJh7L3--ovZlQ.png?1710421311)

{% hint style="info" %}
**이메일 위젯: Source Action Name**(소스 액션 이름)

이메일 위젯의 표 차트에서 **Source Action Name**은 어떤 계기로 이메일이 발송되었는지 확인하는 데 도움이 돼요.
이메일이 워크플로우와 연결되어 있으면 **Source Action Name**에 워크플로우 단계 이름이 표시돼요. 그래서 대시보드와 리포트에서 발송 경로를 더 쉽게 추적할 수 있어요.
{% endhint %}

## 4단계: 변경사항 저장하기

1. **저장**을 클릭하면 위젯이 대시보드에 추가돼요.

![저장 버튼을 눌러 위젯을 대시보드에 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155022886687/original/cRu3tWKj6h2y424JHndURAxemS2w7hd57Q.png?1710422439)
