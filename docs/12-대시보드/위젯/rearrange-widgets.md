# 대시보드 위젯 위치 바꾸기

위젯을 끌어다 놓아 대시보드를 원하는 대로 꾸밀 수 있어요. 이 문서에서는 위젯 위치를 바꾸고 저장하는 방법을 안내해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

### 1단계: 편집 모드로 전환하기

1. 대시보드에서 **편집** 버튼을 클릭하세요.

![대시보드의 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010312385/original/eRQHCMA9WQGP_zrefsuo6VZgnjGGHNZQnQ.jpeg?1697544648)

### 2단계: 위젯을 원하는 위치로 끌어다 놓기

1. 옮기고 싶은 위젯을 끌어서 원하는 위치에 놓으세요.

![위젯을 끌어서 원하는 위치로 옮기는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010312384/original/DypaXzgiTP8lKSYQyr8xx5JGM0Q5E554_A.png?1697544649)

### 3단계: 변경사항 저장하기

1. **변경사항 저장**을 클릭하세요.

![변경사항 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010312383/original/BWdBR2cqs4rFkr6pJbvdSJ9L0Yi0Zi6eWA.jpeg?1697544648)

- 변경한 내용을 되돌리려면 **취소**를 클릭하세요. 위젯이 이전 상태로 돌아가요.

{% hint style="info" %}
맞춤 설정이 가능한 대시보드는 어떤 요금제에서 쓸 수 있는지 궁금하신가요?

현재 $497 요금제 이상에서만 쓸 수 있어요. $97 또는 $297 요금제를 사용 중이라면 요금제를 올려야 이 기능을 쓸 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 위젯 위치를 바꾸면 다른 사용자에게도 영향을 주나요?
보통은 내 대시보드 화면에만 적용돼요. 관리자라면 모든 사용자에게 적용되는 전체 레이아웃을 설정할 수도 있어요.

### 위젯을 엉뚱한 곳에 놓았어요. 어떻게 하나요?
위젯을 다시 끌어서 원하는 위치로 옮기면 돼요. 편집 모드에서는 위치를 자유롭게 바꿀 수 있고, 나가거나 저장하기 전까지는 변경 내용이 저장되지 않아요.
