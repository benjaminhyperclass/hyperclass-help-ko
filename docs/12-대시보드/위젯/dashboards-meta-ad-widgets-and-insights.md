# 대시보드의 Meta 광고 위젯과 인사이트

Meta 광고 위젯을 쓰면 클릭 수, 전환, 광고비, 성과가 좋은 캠페인을 하이퍼클래스 대시보드나 사용자 지정 리포트에서 바로 볼 수 있어요. 기본 제공되는 필터와 차트로 캠페인별 결과를 비교할 수 있어서, 스프레드시트를 만들거나 다른 도구로 옮겨 다닐 필요가 없어요.

## Meta 광고 위젯이란?

Meta 광고 위젯은 연결한 Meta(Facebook/Instagram) 광고 계정의 지표를 서브 계정 대시보드와 사용자 지정 리포트에 보여 주는 리포트용 블록이에요. 직접 내보내기를 하지 않아도 돼서, 퍼널·자동화·CRM 데이터를 관리하는 같은 공간에서 유료 트래픽 성과를 확인할 수 있어요.

광고 성과를 파이프라인과 매출 지표 옆에서 함께 보면, 여러 플랫폼을 오가지 않고도 데이터를 바탕으로 더 빠르게 판단할 수 있어요.

---

## Meta 광고 위젯의 장점

Meta 광고 위젯은 매일 하는 모니터링을 간단하게 하고 최적화를 앞당기도록 만들어졌어요. 아래 장점을 참고해 목표에 맞게 대시보드를 구성해 보세요. 광고비나 성과에 영향이 가기 전에 문제를 발견할 수 있어요.

- **한 화면에서 확인:** 광고비, 전환, 도달, CTR 등을 영업·CRM 핵심 지표와 함께 볼 수 있어요.
- **더 빠른 최적화:** CPC가 오르거나 효율이 떨어지는 흐름을 일찍 발견해 예산이나 소재를 조정할 수 있어요.
- **캠페인별 상세 분석:** 표 위젯이 광고비, 구매, 클릭, 노출 기준으로 캠페인 순위를 보여 줘서 잘된 캠페인과 아쉬운 캠페인을 빠르게 가릴 수 있어요.
- **추이 확인:** 선형·막대 차트로 전환당 비용, 도달 등 지표가 원하는 기간 동안 어떻게 변했는지 볼 수 있어요.
- **테마·필터 사용자 지정:** 브랜드 테마를 맞추고 캠페인, 광고 세트, 날짜별로 데이터를 나눠서 고객이나 보는 사람에 맞는 인사이트를 만들 수 있어요.

## 사용하기 전에 확인할 것

위젯을 추가하기 전에 이용 권한과 연결 상태를 확인해 두면 데이터가 제대로 표시돼요.

- **설정 > 연동 > Facebook**에서 **Meta 광고 계정이 연결되어 있어야 해요.** 연결 방법은 [Facebook과 광고 관리자 연결하기](../../10-마케팅/how-to-get-started-with-meta-campaigns-in-ad-manager.md)를 참고하세요.
- 리포트에 쓸 Business Manager, 광고 계정, 페이지에 하이퍼클래스 접근 권한이 허용되어 있는지 확인하세요.
- **대시보드·리포트 이용 권한:** 대시보드를 보거나 편집하고, 리포트를 만들고 예약 발송할 수 있는 권한이 사용자에게 있는지 확인하세요. 자세한 내용은 [대시보드 권한 관리하기](../how-to-manage-dashboard-permissions.md)를 참고하세요.

## Meta 광고 성과 지표

이 위젯들은 광고 성과를 가늠할 때 가장 많이 쓰는 핵심 지표를 보여 줘요. 광고비 관련 지표와 성과 지표를 함께 보면 효율을 놓치지 않을 수 있어요.

| 지표 | 정의 |
| --- | --- |
| 웹사이트 구매(Website Purchases) | 소셜 광고 트래픽으로 유입된 사용자가 웹사이트에서 완료한 구매예요. |
| 전환(Conversions) | Meta 설정에서 정의한 대로 광고로 발생한 행동이에요(예: 구매, 가입). |
| Meta 광고 클릭 수(Meta Ad Clicks) | Meta 광고의 전체 클릭 수예요. |
| 지출 금액(Amount Spent) | 선택한 기간의 전체 광고비예요. |
| 평균 CPC(Average CPC, 클릭당 비용) | 클릭 한 번당 지불한 평균 금액이에요. |
| 전환당 비용(Cost Per Conversion) | 전환 한 건을 만드는 데 든 평균 비용이에요. |
| 광고 노출 수(Ad Impressions) | 광고가 표시된 전체 횟수예요. |
| 도달(Reach) | 광고를 본 순 사용자 수예요. |
| 평균 CPM(Average CPM, 1,000회 노출당 비용) | 1,000회 노출당 평균 비용이에요. |
| CTR(클릭률) | 노출 중 클릭으로 이어진 비율이에요. |

직접 만든 지표를 대시보드 리포트에 쓰고 싶다면 [대시보드 리포트용 맞춤 지표 만들고 사용하기](how-to-create-and-use-custom-metrics-for-dashboard-reports.md)를 참고하세요.

## 상위 캠페인 위젯

표 형태의 위젯이 캠페인 순위를 자동으로 보여 줘서, 성과가 좋은 캠페인에 더 집중할 수 있어요.

| 위젯 | 정의 |
| --- | --- |
| 광고비 기준 상위 캠페인(Top Campaigns by Ad Spend) | 광고비를 가장 많이 쓴 순서로 정렬한 캠페인이에요. |
| 전환 기준 상위 캠페인(Top Campaigns by Conversions) | 전환을 가장 많이 만든 캠페인이에요. |
| 웹사이트 구매 기준 상위 캠페인(Top Campaigns by Website Purchases) | 웹사이트 구매가 가장 많았던 캠페인이에요. |
| 광고 클릭 기준 상위 캠페인(Top Campaigns by Ad Clicks) | 광고 클릭을 가장 많이 만든 캠페인이에요. |
| 노출 기준 상위 캠페인(Top Campaigns by Impressions) | 광고 노출 수가 가장 많은 캠페인이에요. |
| 도달 기준 상위 캠페인(Top Campaigns by Reach) | 가장 많은 순 사용자에게 도달한 캠페인이에요. |

## 대시보드 위젯과 사용자 지정 리포트 위젯 비교

두 곳 모두 같은 Meta 지표를 쓸 수 있어요. 인사이트를 어떻게 보고 공유할지에 따라 골라 쓰세요.

- **대시보드** — 하루 종일 한눈에 확인할 때 좋아요. 위젯은 서브 계정 대시보드에 있고 **자동으로 업데이트돼요**.
- **사용자 지정 리포트** — 이메일로 예약 발송하거나 인사이트를 묶어서 전달할 때 좋아요. Meta 광고 위젯으로 레이아웃을 만든 뒤 필요한 사람에게 예약 발송하세요.

{% hint style="info" %}
내보내기 형식과 이메일 미리보기는 콘텐츠 유형에 따라 다를 수 있어요.
{% endhint %}

## Meta 광고 위젯 설정하기

연결부터 성과 시각화까지 몇 분이면 끝나요. 대시보드에 위젯을 추가하는 방법과, 팀이나 고객이 정해진 주기로 받아 볼 수 있는 사용자 지정 리포트를 만드는 방법을 안내해 드릴게요.

### 1) 대시보드에 위젯 추가하기

대시보드 위젯을 만들고 추가하는 일반적인 방법은 [대시보드 위젯 만들고 추가하기](../how-to-create-add-dashboard-widgets.md)에서도 볼 수 있어요.

1. **서브 계정**에서 **대시보드**로 이동한 뒤, 왼쪽 위의 파란색 버튼을 눌러 원하는 대시보드를 열어요.

   ![서브 계정에서 대시보드를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055690090/original/8OpOVwXH-d5Sa8EqYDjXoPqLnPXmNVchXg.png?1760089468)
2. **Edit Dashboard**(대시보드 편집)를 클릭한 다음 **Add Widget**(위젯 추가)을 클릭해요.

   ![대시보드 편집 후 위젯 추가를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055690825/original/8sJbiHaBnc9zc67JBKcl8HPgiSmhOCfVcw.gif?1760089814)
3. 원하는 차트 유형(**Numeric**(숫자), **Donut**(도넛), **Line**(선), **Bar**(막대), **Table**(표))을 고르고, **Meta Ads** 카테고리까지 스크롤해서 보고 싶은 지표나 상위 캠페인 위젯을 선택해요.

   ![차트 유형과 Meta Ads 위젯을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055691630/original/mf9eHbaYs1_CrkgWpPvck5Ik06GdS2xQNg.png?1760090134)
4. 필터(캠페인, 지표, 기간)를 적용하거나 테마·색상을 바꿔요.

   ![위젯에 필터와 테마를 적용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055692547/original/NgAI0g9YvagwqasoKZi-27mhEjMsfU2m7A.png?1760090539)
5. **저장**을 클릭해요. 위젯에 광고 데이터가 표시되기 시작해요.

### 2) 사용자 지정 리포트에 위젯 추가하기

리포트를 만들고 예약하는 방법은 [사용자 지정 리포트 만들고 예약·PDF로 내보내기](../../18-리포팅/커스텀-리포트/how-to-create-a-custom-report-schedule-and-export-report-as-pdf.md)에서도 볼 수 있어요.

1. **서브 계정**에서 **리포팅 > 사용자 지정 리포트**로 이동해요. 기존 리포트를 열거나 **New Report**(새 리포트)를 클릭하세요.

   ![리포팅의 사용자 지정 리포트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055693768/original/pjo9zJv8sLVQXrXoGt0Em9dofL_DwFculg.png?1760090986)
2. 빈 캔버스에서 시작할지, 템플릿을 사용할지, 기존 대시보드 레이아웃을 가져올지 선택해요.

   ![리포트 시작 방식을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055693789/original/qSGUI9CyAez2mnuhw6aTYAh6TagYwM2xGg.png?1760091013)
3. 왼쪽 위의 **Add Widget/Element**(위젯/요소 추가)를 클릭해요. 위젯 목록에서 **메타** 위젯을 찾아 원하는 것을 레이아웃으로 끌어다 놓으세요.

   ![메타 위젯을 레이아웃으로 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055693921/original/V2rtATaG6sqwGZ8l59ZNszTDc8PltLhV_g.png?1760091116)
4. 위젯마다 차트 유형, 필터, 테마를 필요에 맞게 설정하고 **저장**을 클릭해요.

   ![위젯별 차트 유형과 필터, 테마를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055694027/original/PXaa35PBm69ylLC_AX1TRu91ClmJj8x0Sg.png?1760091185)
5. **Send or Schedule**(보내기 또는 예약)을 클릭해 이메일 일정을 설정하면 리포트를 자동으로 받을 수 있어요.

   ![리포트 이메일 발송 일정을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055694301/original/w2J4nHxYykP5wsyDPKnFTGFoRTeJqm_0HA.png?1760091375)

## 자주 묻는 질문

### 서브 계정마다 Meta를 따로 연결해야 하나요?
네. 각 서브 계정의 대시보드는 그 서브 계정 안에서 연결한 Meta 광고 계정의 데이터만 가져와요.

### Meta 광고 위젯은 얼마나 자주 새로고침되나요?
위젯은 **자동으로 업데이트돼요.** 직접 새로고침할 필요가 없어요.

### 위젯을 추가했는데 왜 비어 있나요?
기간이 너무 좁거나, 캠페인 필터가 너무 제한적이거나, 사용할 수 있는 광고 계정이 선택되지 않았거나, 하이퍼클래스 권한이 빠진 경우가 흔한 원인이에요. 필터를 제거하고(**필터 제거**), 기간을 넓히고, 연결 상태를 확인해 보세요.

### 어떤 역할이 Meta를 연결하고 위젯을 추가할 수 있나요?
**광고 관리자** 연결을 관리할 권한과, 대시보드를 **편집**하거나 리포트를 **만들** 권한이 필요해요. 보기 전용 사용자는 공유된 대시보드를 볼 수는 있지만 수정할 수는 없어요.

### Google Ads와 Meta Ads 지표를 한 대시보드에 함께 둘 수 있나요?
네. 두 라이브러리의 위젯을 함께 추가하면 채널을 나란히 비교할 수 있어요.

### 고객에게 Meta 전용 리포트를 예약 발송할 수 있나요?
네. Meta 위젯만으로 리포트를 만든 뒤 이메일 발송을 예약하세요. 내보내기와 레이아웃 옵션이 고객이 원하는 형태인지 확인해 보세요.

### Meta 연동을 끄면 기존 위젯이 망가지나요?
사용할 수 있는 광고 계정을 다시 연결할 때까지 위젯에 데이터가 표시되지 않아요. 하지만 레이아웃과 위젯 설정은 그대로 남아 있어요.
