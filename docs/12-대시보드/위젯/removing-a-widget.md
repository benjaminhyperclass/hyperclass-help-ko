# 대시보드에서 위젯 삭제하기

대시보드에 더 이상 필요 없는 위젯이 있다면 지울 수 있어요. 편집 모드로 전환한 뒤 위젯의 점 세 개 메뉴(...)에서 **삭제**를 선택하세요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

### 1단계: 편집 모드로 전환하기

1. 대시보드에서 **편집** 버튼을 클릭하세요.

   ![대시보드의 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010317802/original/8wf_eSsstb1zLWmOsvfiXKCeV-QZYYSINQ.jpeg?1697546741)

### 2단계: 위젯 삭제하기

1. 삭제하려는 위젯의 오른쪽 위 모서리에서 점 세 개 메뉴를 찾으세요.
2. 점 세 개 메뉴를 클릭하면 드롭다운 메뉴가 나타나요.
3. **삭제**를 선택하세요.

   ![위젯의 점 세 개 메뉴에서 삭제 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010317804/original/lcDofQwMAIbcnATj6T2ehRSmD0kC3W3CwQ.png?1697546746)

### 3단계: 변경사항 저장하기

1. 화면 오른쪽 위의 **변경사항 저장**을 클릭하세요. 위젯이 삭제된 상태로 대시보드가 저장돼요.

{% hint style="info" %}
맞춤 대시보드는 어느 요금제에서 쓸 수 있나요?

현재는 $497 이상 요금제에서만 쓸 수 있어요. $97 또는 $297 요금제를 사용 중이라면 요금제를 업그레이드해야 이 기능을 쓸 수 있어요.

$497 이상 요금제의 맞춤 대시보드는 에이전시 관리자와 에이전시 사용자가 사용할 수 있어요.

대시보드 권한 관리에 대한 자세한 내용은 별도의 권한 관리 문서를 참고하세요.
{% endhint %}
