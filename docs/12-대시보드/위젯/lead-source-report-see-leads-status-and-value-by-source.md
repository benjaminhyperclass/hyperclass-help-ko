# 리드 소스 리포트 — 소스별 리드 현황과 금액 보기

**Lead Source Report**(리드 소스 리포트)는 리드가 어디에서 들어오는지, 기회가 어떤 상태인지, 소스별 금액이 얼마인지 한눈에 보여 주는 대시보드 위젯이에요. 어떤 채널에서 기회가 많이 생기는지 파악할 때 사용하세요.

## 리드 소스 리포트란?

기록된 출처를 기준으로 기회를 묶어서 보여 주는 대시보드 위젯이에요. 리드 수, 기회 상태, 금액이 함께 표시되어 리드 확보 성과를 평가할 수 있어요.

## 이럴 때 유용해요

리드 성과를 이해하고, 확인이 필요한 기회를 찾는 데 도움이 돼요.

- 리드 소스 추적: 어떤 채널에서 기회가 생기는지 확인해요.
- 상태 모니터링: 진행 중(Open), 고객전환성공, 고객전환실패, 포기(Abandoned) 상태의 기회를 확인해요.
- 금액 비교: 소스별 기회 금액을 비교해요.
- 유연한 필터: 파이프라인, 사용자, 출처, 어트리뷰션 기준으로 걸러 볼 수 있어요.
- 기회 상세: 건수를 클릭해 개별 기회를 확인해요.

## 리포트 보는 법

출처마다 한 행씩 표시되고, 각 행 안에서 기회가 상태별로 나뉘어요.

| 열 | 설명 |
| --- | --- |
| **출처** | 기록된 기회의 출처예요. |
| **Total Leads**(전체 리드) | 해당 출처에서 들어온 전체 기회 수예요. |
| **Open**(진행 중) | 아직 진행 중인 기회예요. |
| **고객전환성공** | 고객전환성공으로 표시된 기회예요. |
| **고객전환실패** | 고객전환실패로 표시된 기회예요. |
| **Abandoned**(포기됨) | 포기됨으로 표시된 기회예요. |

{% hint style="info" %}
이 리포트는 고유 연락처가 아니라 기회 수를 집계해요. 금액을 보려면 해당 권한이 필요해요.
{% endhint %}

출처 필드가 어떻게 기록되는지 궁금하다면 [폼과 설문의 출처 필드](../../06-사이트/폼/source-field-in-forms-and-surveys.md) 문서를 참고하세요.

## 필터와 날짜 설정

필터로 특정 기회만 골라 볼 수 있고, 날짜 설정으로 집계 기간의 기준을 정할 수 있어요.

사용할 수 있는 필터는 다음과 같아요.

- **파이프라인**, **할당된 사용자**
- **출처**, **Attribution**(어트리뷰션)
- **태그**, **Followers**(팔로워)
- **Lead Value**(리드 금액), **커스텀 필드**

출처 필터에서는 **Is**(같음), **Is not**(같지 않음), **비어 있음**, **비어있지 않음** 중에서 골라 특정 출처를 포함하거나 제외할 수 있어요. 어트리뷰션 소스에 대한 자세한 내용은 [어트리뷰션 소스 이해하기](../../18-리포팅/understanding-attribution-source.md) 문서를 참고하세요.

날짜 기준은 두 가지예요.

- **생성일**: 기회가 만들어진 날짜예요.
- **Status Change Date**(상태 변경일): 기록된 상태가 마지막으로 바뀐 날짜예요.

## 리드 소스 리포트 설정하기

설정을 제대로 해 두면 원하는 기회와 기간이 리포트에 정확히 표시돼요.

1. 서브 계정에서 **대시보드**로 이동하세요.
2. **대시보드 수정**을 클릭한 다음 **위젯 추가**를 클릭하세요.

   ![대시보드 수정 후 위젯 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084599508/original/VFv6ItSJRMJ1L94grvpxWWVEhr7gelaPbQ.png?1793363207)
3. **Widget Gallery**(위젯 갤러리)에서 **Lead Source Report**를 검색하세요.

   ![위젯 갤러리에서 리드 소스 리포트 검색](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084599973/original/XjuhFGUT3iQPdy4su1FASJhZYy3AJ9K6og.png?1793363413)
4. 위젯을 선택하고 파이프라인을 고르세요.
5. **조건**에서 필터를 설정하세요.
6. 필요에 맞게 날짜 설정을 조정하세요.
7. **저장**을 클릭하세요.

위젯을 추가하고 꾸미는 방법은 [대시보드 위젯 만들기 및 추가하기](../how-to-create-add-dashboard-widgets.md), [대시보드 위젯 사용자 지정하기](../customizing-dashboard-widgets.md), [서브 계정 대시보드의 일반 위젯 설정 및 필터링](configure-and-filter-general-widgets-on-your-sub-account-dashboard.md) 문서에서 더 볼 수 있어요.

## 기회 확인하기와 출처가 없는 기회 찾기

리포트에서 개별 기회를 열어 보거나, 출처 정보가 없는 기록을 찾을 수 있어요.

- 기회 보기: 기회 건수를 클릭하면 해당하는 기록이 열려요.
- 출처가 없는 기회 찾기: N/A 행을 찾거나 **출처**에 **비어 있음**을 적용하세요.
- 출처가 없는 기회 제외하기: **출처**에 **비어있지 않음**을 적용하세요.

## 자주 묻는 질문

### 일부 기회가 보이지 않아요. 왜 그런가요?

선택한 파이프라인, 날짜 범위, 필터를 확인하세요. 출처가 없는 기회는 N/A 아래에 나타날 수 있어요.

### 기회 금액이 보이지 않아요.

리드 금액을 볼 수 있는 권한이 계정에 없을 수 있어요.

### 한 연락처가 여러 번 표시될 수 있나요?

네. 같은 연락처에 기회가 여러 개 있어도 기회마다 따로 집계해요.

### UTM 파라미터가 출처로 사용되나요?

아니요. 이 리포트는 **기회 소스**를 기준으로 기회를 묶어요. UTM 파라미터는 추가 어트리뷰션 필터로 쓸 수 있어요.

### 영업 담당자별로 리포트를 필터링할 수 있나요?

네. **할당된 사용자** 조건을 사용하면 특정 사용자와 연결된 기회만 볼 수 있어요.
