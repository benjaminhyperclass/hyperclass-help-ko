# 서브 계정 대시보드 테이블 위젯에 커스텀 필드 추가하기

**연락처**와 **기회 관리**(Opportunities) 테이블 위젯에 커스텀 필드를 열로 추가하는 방법을 안내해요. 비즈니스에 중요한 데이터를 대시보드와 리포트에 맞춰 보여 줄 수 있어요.

## 주요 기능

- 테이블에 커스텀 필드 추가: **연락처**와 **기회 관리** 위젯 모두에서 커스텀 필드를 열로 추가할 수 있어요.
- **Birthdate**(생년월일) 필드: **연락처** 위젯에서 **Birthdate** 필드를 열로 선택할 수 있어요.
- 대시보드와 리포트 지원: 이 필드는 **대시보드**와 **사용자 지정 리포트**에서 모두 쓸 수 있어요.

## 커스텀 필드를 추가하는 방법

1. 편집 모드로 들어가요.
    - 대시보드 또는 사용자 지정 리포트로 이동하세요.
    - **편집**을 클릭해 변경을 시작하세요.

2. 테이블 위젯을 추가해요.
    - **Add Widget**(위젯 추가)을 클릭하세요.
    - **연락처** 또는 **기회 관리** 테이블 위젯 중 하나를 선택하세요.

![테이블 위젯 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052520145/original/TdX8Yc_dFXFtW3Rp7yLhN-LJlyCJ8gy3GQ.png?1756311263)

3. 열을 선택해요.
    - 테이블 위젯의 열 선택기를 여세요.
    - 사용할 수 있는 커스텀 필드가 모두 표시돼요.
    - 보여 주고 싶은 필드를 체크하세요.

4. 저장하고 확인해요.
    - **저장**을 클릭해 변경 내용을 적용하세요.
    - 선택한 커스텀 필드가 테이블에 열로 표시돼요.

## 활용 이점

대시보드 테이블에서 커스텀 필드를 쓰면 다음과 같은 이점이 있어요.

- 비즈니스에 맞게 대시보드와 리포트를 꾸밀 수 있어요.
- 고유한 데이터 항목을 한 화면에서 바로 확인할 수 있어요.
- 데이터를 내보내거나 다른 도구로 옮겨 가지 않아도 한눈에 볼 수 있어요.

## 자주 묻는 질문

### 어떤 위젯에서 커스텀 필드를 쓸 수 있나요?

**연락처**와 **기회 관리** 테이블 위젯에 커스텀 필드를 추가할 수 있어요.

### 대시보드와 리포트 모두에서 이 필드를 쓸 수 있나요?

네, 쓸 수 있어요. 커스텀 필드는 **대시보드**와 **사용자 지정 리포트** 모두에서 사용할 수 있어요.

### 생년월일(Birthdate)을 열로 고를 수 있나요?

네, 고를 수 있어요. **Birthdate**는 **연락처** 위젯에서 선택할 수 있는 열이에요.

### 위젯에 커스텀 필드를 추가하려면 관리자 권한이 필요한가요?

대시보드나 리포트를 편집할 수 있는 권한만 있으면 돼요. 별도로 설정할 필요는 없어요.

### 위젯에 필드를 추가하면 원래 데이터가 바뀌나요?

아니요. 대시보드나 리포트에 데이터가 표시되는 방식만 바뀌어요.
