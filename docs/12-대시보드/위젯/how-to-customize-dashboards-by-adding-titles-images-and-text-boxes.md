# 대시보드에 제목, 텍스트 상자, 이미지 추가하기

커스텀 대시보드에 제목, 텍스트 상자, 이미지 요소를 추가해 대시보드를 꾸미고 정리하는 방법을 안내해요.

## 새로 추가된 요소

- **Titles**(제목): 대시보드에 제목이나 소제목을 넣을 수 있어요. 주제나 카테고리별로 위젯을 묶어 구역을 나눠 보세요.
- **Textboxes**(텍스트 상자): 팀원에게 필요한 정보나 할 일 목록을 대시보드에 바로 적어 둘 수 있어요. 위젯 데이터를 읽는 방법을 안내하거나 중요한 업무를 상기시킬 때 쓰면 소통이 한결 편해져요.
- **Images**(이미지): 이미지를 업로드해 대시보드에 넣을 수 있어요. 로고, 차트, 인포그래픽을 넣으면 내용을 이해하기 쉽고 대시보드도 보기 좋아져요.

## 사용 방법

1. 대시보드에서 편집 모드로 들어가세요.
2. **Add widget**(위젯 추가)을 클릭하세요.
3. **Elements**(요소) 탭으로 이동하세요.
4. **Titles**, **Textboxes**, **Images** 중에서 추가할 요소를 고르세요.
5. 필요에 맞게 요소를 설정하세요.
6. **변경사항 저장**을 클릭하세요.

## 이런 점이 좋아요

- 더 깔끔한 구성: 제목으로 대시보드에 뚜렷한 구역을 만들 수 있어요. 팀원이 화면 구성을 이해하고 원하는 곳을 찾기가 쉬워져요.
- 더 쉬운 소통: 텍스트 상자로 중요한 내용을 대시보드에 바로 전달할 수 있어요. 별도의 소통 채널을 쓸 필요가 줄고, 모두가 같은 내용을 확인할 수 있어요.
- 보기 좋은 화면: 이미지를 넣으면 대시보드가 더 눈에 띄고 인상적으로 보여요. 브랜드 요소나 데이터를 시각화한 이미지를 넣으면 정보를 더 효과적으로 전달할 수 있어요.

이 요소들을 활용하면 정보가 풍부하고 보기 좋은 대시보드를 만들 수 있어요. 팀의 협업과 생산성을 높이는 데도 도움이 돼요.
