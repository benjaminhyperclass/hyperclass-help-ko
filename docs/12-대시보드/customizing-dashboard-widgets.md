# 대시보드 위젯 맞춤 설정하기

대시보드 위젯은 차트, 그래프, 표 등으로 주요 비즈니스 지표를 한눈에 보여 줘요. 위젯을 맞춤 설정하면 필요한 정보만 골라 보고, 기간별 성과를 비교하고, 보고 목적에 맞게 데이터를 보여 줄 수 있어요. 이 문서에서는 위젯 구성, 차트 유형 변경, 추세 표시기 설정, 필터 적용, 변경사항 저장 방법을 안내해요.

---

## 대시보드 위젯이란?

대시보드 위젯은 차트, 그래프, 표 같은 시각 요소로 중요한 데이터를 보여 줘요. 위젯으로 지표를 확인하고, 성과를 평가하고, 비즈니스 흐름을 파악할 수 있어요. 위젯마다 표시할 지표, 필터, 차트 유형, 정보가 나타나는 방식을 바꿀 수 있어요.

---

## 위젯을 맞춤 설정하면 좋은 점

- 개인 맞춤 인사이트: 비즈니스 목표에 맞는 지표를 보여 줘요.
- 더 명확한 정보: 위젯 제목, 레이아웃, 필터를 조정해 데이터를 이해하기 쉽게 만들 수 있어요.
- 더 나은 비교: 서로 다른 기간의 지표를 비교해 성과를 평가할 수 있어요.
- 효율: 관련 없는 데이터를 거치지 않고 필요한 정보만 바로 확인할 수 있어요.

---

## 위젯 맞춤 설정 옵션 찾기

1. **대시보드**로 이동해요.
2. 맞춤 설정할 위젯을 찾아요.
3. 위젯 메뉴(⋮)를 열고 **위젯 편집**을 선택해요. 편집 모드로 들어가서 위젯을 선택해도 돼요.
4. 나타나는 구성 옵션으로 위젯을 맞춤 설정해요.

---

## 대시보드 위젯 맞춤 설정하기

### 1단계: 위젯 선택하기

맞춤 설정할 위젯을 선택해요. 위젯마다 기본 차트 유형이 정해져 있어요. 차트 선택 옵션에서 차트 유형을 바꾸면 보고 목적에 맞는 형식으로 데이터를 볼 수 있어요.

![위젯 차트 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084627759/original/EWTKaAemyBbalcj2_flkY8lX9gRL7N3oEg.png?1793376979)

### 2단계: 위젯 설정 구성하기

**구성** 탭을 열어 위젯 설정을 바꿔요. 위젯 유형에 따라 쓸 수 있는 옵션은 달라요. 사용할 수 있는 옵션은 다음과 같아요.

- **제목**: 위젯이 보여 주는 정보를 알 수 있게 위젯 이름을 바꿔요.
- **지표**: 위젯에 표시할 데이터 항목을 선택해요. 선, 막대, 가로 막대 차트는 지표를 여러 개 선택할 수 있어요.
- **그룹**: 도넛 차트처럼 지원하는 차트에서 데이터를 카테고리별로 묶어요.
- **View By**(보기 기준): 지원하는 시각화에서 보조 기준을 선택해요.
- **분석**: 시간 흐름에 따라 데이터를 나누는 주기를 조정해요.
- **Date Property**(날짜 속성): 데이터를 가져올 때 기준이 되는 날짜 필드를 선택해요. 예를 들어 **생성일**이나 **업데이트 날짜**가 있어요.
- **Date Range Override**(날짜 범위 재정의): 대시보드 전체 날짜 범위와 다른 날짜 범위를 이 위젯에만 지정해요.
- **주문**: 표시되는 결과를 오름차순이나 내림차순으로 정렬해요.
- **제한**: 표시할 결과의 최대 개수를 지정해요.
- **비교 날짜 범위**: 비교할 기간을 선택하면 기간 간 증감률을 보여 줘요.

**고급 설정**을 펼치면 추세 표시기 설정 같은 추가 옵션도 쓸 수 있어요.

---

## 긍정·부정 추세 표시기 설정하기

지표가 증가하는 것이 좋은 결과인지, 감소하는 것이 좋은 결과인지 지정할 수 있어요. 이 설정은 위젯의 추세 배지 색상을 정해요. 추세 배지는 선택한 기간과 비교한 증감률을 보여 줘요. 기본값은 증가하면 초록색, 감소하면 빨간색이에요. 하지만 이탈률, 구독 취소 이메일 수, 리드당 비용 같은 지표는 감소하는 쪽이 더 좋은 성과일 수 있어요.

추세 표시기를 설정하려면 다음과 같이 하세요.

1. 위젯이 있는 대시보드나 사용자 지정 리포트를 열어요.
2. 위젯 메뉴(⋮)를 열고 **위젯 편집**을 선택해요. 편집 모드로 들어가서 위젯을 선택해도 돼요.
3. **구성** 탭으로 이동해요.
4. **고급 설정**을 펼쳐요.

   ![고급 설정을 펼친 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084629070/original/2xbxmsPXPJcLBig0oj4PIVg71lwkwCqd4A.png?1793377918)
5. **비교 날짜 범위**를 설정해요. 예를 들어 **지난 7일**이나 **이전 기간**을 선택해요.
6. **Specify whether a metric's increase or decrease is positive**(지표의 증가 또는 감소가 긍정적인지 지정) 아래에서 다음 중 하나를 선택해요.

   - **증가는 양수입니다**(기본값): 지표가 증가하면 추세 배지가 초록색, 감소하면 빨간색으로 표시돼요.
   - **감소가 긍정적임**: 지표가 감소하면 추세 배지가 초록색, 증가하면 빨간색으로 표시돼요.
7. **변경사항 저장**을 클릭해 설정을 적용해요.

**예시**

이탈률을 추적하는 위젯이 있다고 해 볼게요.

- 이탈률이 증가하면 좋지 않은 결과예요.
- 이탈률이 감소하면 좋은 결과예요.

이때 **감소가 긍정적임**을 선택하면 이탈률이 감소할 때 초록색 추세 배지가, 증가할 때 빨간색 추세 배지가 표시돼요.

{% hint style="warning" %}
**중요 사항**

- 이 설정은 추세 배지 색상에만 영향을 줘요. 지표의 실제 값은 바뀌지 않아요.
- 증감률과 추세 배지를 표시하려면 **비교 날짜 범위**가 필요해요.
- 같은 위젯이라면 숫자, 선, 막대 차트 보기에서 설정이 똑같이 적용돼요.
- 기존 위젯은 따로 바꾸지 않으면 **증가는 양수입니다**가 기본 설정으로 유지돼요.
- **사용자 지정 지표**를 만드는 화면에도 비슷한 옵션이 있어요. **When the metric increases, show indicator as**(지표가 증가하면 표시기를 다음으로 표시) 옵션에서 **긍정적** 또는 **부정적**을 선택해요.
{% endhint %}

자세한 내용은 [트렌드 배지에서 증가와 감소 중 무엇을 '좋음'으로 볼지 선택하기](설정/choosing-whether-an-increase-or-a-decrease-is-good-for-the-trend-badge.md)를 참고하세요.

### 위젯 설정에서 차트 유형 고르기

위젯 설정 화면에서 바로 차트 유형을 바꿔 데이터를 가장 잘 보여 주는 시각화를 고를 수 있어요.

차트 유형을 선택하려면 다음과 같이 하세요.

1. 위젯 설정을 열고 **구성**으로 이동해요.
2. 원하는 차트 유형을 선택해요. 예를 들어 막대, 선, 원형 차트가 있어요.

   ![차트 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084629140/original/RP6YnS9Qc6dmVbR68rXWqq_DEqklZtjC4A.png?1793377966)
3. 미리보기에서 데이터가 어떻게 보이는지 확인해요.
4. 위젯 구성을 이어서 하거나 변경사항을 저장해요.

### 3단계: 조건 추가하기

조건을 쓰면 위젯에 표시할 데이터를 제어할 수 있어요. 필터를 적용하고 서로 조합하면 더 구체적인 데이터 보기를 만들 수 있어요.

조건을 추가하려면 다음과 같이 하세요.

1. 위젯의 **조건** 탭을 열어요.
2. **조건 추가**를 클릭해요.
3. 필드, 연산자, 필요한 값을 선택해요.
4. AND/OR 옵션으로 조건을 더 추가해요.
5. 필터를 확인하고 변경사항을 저장해요.

#### 중첩 필터 그룹 (OR 조건)

중첩 필터 그룹을 쓰면 AND와 OR 조건을 함께 조합할 수 있어요. 같은 그룹 안의 조건은 AND로 연결되고, 서로 다른 그룹은 OR로 연결할 수 있어요. 필터 그룹을 만들려면 다음과 같이 하세요.

1. 위젯의 **조건** 탭을 열어요.
2. **필터 추가**를 클릭해 첫 번째 그룹을 만들어요.

   ![필터 추가로 첫 번째 그룹을 만든 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084629187/original/ZZpqzrPpXCe3-eCOmJeCabqEDIWJWtfDmw.png?1793377993)
3. **+AND**(그룹 안에 조건 추가)를 사용해 그 그룹 안에 조건을 추가해요.
4. **+Add Filter**(+필터 추가)를 클릭해 OR 조건으로 연결되는 다른 그룹을 만들어요.
5. 필요한 조건을 추가하고 위젯을 저장해요.

{% hint style="info" %}
방문자 데이터 위젯은 필터 그룹을 하나만 지원해요.
{% endhint %}

#### 그룹으로 같은 필터 중복 사용하기

서로 다른 필터 그룹에 같은 필드를 써서 서로 다른 일치 조건을 만들 수 있어요. 예를 들어 두 소스의 데이터를 함께 표시하려면 이렇게 설정해요.

- 그룹 1: 소스 = Google
- 그룹 2: 소스 = Facebook

OR로 연결된 별도 그룹을 쓰면, 위젯에 두 소스 중 하나라도 일치하는 기록이 모두 포함돼요.

#### 연결된 필터 경고

일부 필터는 파이프라인과 단계처럼 서로 관련된 필드에 의존해요. 서로 맞지 않는 값을 선택하면 **조건** 탭에 경고가 바로 표시돼요. 경고를 해결하려면 다음과 같이 하세요.

1. 강조 표시된 필터를 확인해요.
2. 서로 맞지 않는 값을 조정해요.
3. 필터 조건이 올바른지 확인해요.
4. 위젯을 저장해요.

{% hint style="info" %}
선택한 조건에 맞는 데이터가 없으면 필터를 조정하거나 제거하기 전까지 위젯이 저장되지 않을 수 있어요.
{% endhint %}

### 4단계: 변경사항 저장하기

위젯 구성을 마친 뒤 다음과 같이 하세요.

1. 위젯 편집 화면에 따라 **저장** 또는 **변경사항 저장**을 클릭해요.
2. 필요하면 대시보드에서 위젯의 크기나 위치를 조정해요.
3. 대시보드 레이아웃을 저장해 변경을 마무리해요.

이제 위젯에 설정한 지표, 차트 유형, 필터, 추세 표시기 설정이 반영돼서 표시돼요.
