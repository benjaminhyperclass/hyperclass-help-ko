# 서브 계정 대시보드 복제하기

이미 만들어 둔 대시보드를 복제해서 다시 쓰면 시간을 아낄 수 있어요. 이 글에서는 대시보드를 복제하는 순서를 안내해요.

## 1단계: 대시보드 열기

1. 서브 계정의 왼쪽 메뉴에서 **대시보드**를 클릭하세요.
2. 대시보드 선택 메뉴를 클릭하세요.
3. 복제할 대시보드를 검색하거나 목록에서 찾아 선택하세요. 선택하면 대시보드가 열리고, 내용을 보거나 편집할 수 있어요.

![대시보드 선택 메뉴에서 대시보드를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044573427/original/SabBltMQD22qnDtAa81ooJp0HJUWRRLghQ.png?1743804171)

## 2단계: 대시보드 복제하기

1. 원본 대시보드 화면에서 작업 메뉴(점 3개 아이콘)를 클릭하세요.
2. **Clone**(복제) 버튼을 클릭하세요.

![작업 메뉴에서 Clone 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044573391/original/7QxGqD4lg8IgpiqZmBFyvs4K7HMBNSF2ew.png?1743803929)

## 3단계: 복제 설정하고 저장하기

1. **Clone Dashboard**(대시보드 복제) 창에서 복제본의 제목을 입력하세요.
2. 대시보드의 공개 범위와 접근 권한을 설정하세요.
3. **Clone**(복제) 버튼을 클릭하세요.

설정한 내용대로 복제된 새 대시보드가 만들어져요.

![Clone Dashboard 창에서 제목과 권한을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044573401/original/lzYJqJReqAwa75pXQ5EGJ9wnffGvqI7J1g.png?1743804027)
