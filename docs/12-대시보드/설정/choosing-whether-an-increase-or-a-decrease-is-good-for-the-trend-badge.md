# 추세 배지에서 증가와 감소 중 어느 쪽을 긍정으로 볼지 정하기

위젯의 숫자 옆에 나오는 추세 배지가 증가와 감소 중 어느 쪽을 긍정(초록)으로 표시할지 위젯마다 정하는 방법을 안내해요. 수치가 낮을수록 좋은 지표에서 배지 색이 실제 상황과 다르게 보일 때 설정하세요.

## 개요

위젯에 숫자 통계가 표시되면 그 옆에 작은 추세 배지가 함께 나와요. 위쪽 또는 아래쪽 화살표와 증감률이 보이는데, 예를 들면 ↓30% (지난 7일 대비) 같은 모양이에요. 기본값에서는 지표가 오르면 배지가 초록색, 내리면 빨간색이 돼요.

*발송 완료 이메일*처럼 많을수록 좋은 지표에서는 이 기본값이 잘 맞아요. 하지만 *구독 취소 이메일*, *반송률*, *리드당 비용*처럼 수치가 낮아야 좋은 지표는 달라요. 수치가 줄었는데 배지가 빨간색으로 나오면 오해하기 쉬워요.

이제 위젯마다 어느 방향을 긍정으로 볼지 지정할 수 있어요. 추세 배지가 실제 상황에 맞게 표시돼요.

![추세 배지가 표시된 위젯 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078186133/original/vWlbC4PR-cRhF-mV123oRIy91v3iAt-ZGA.png?1786512528)

## 설정 위치

1. 위젯이 있는 대시보드 또는 사용자 지정 리포트를 엽니다.
2. 위젯의 메뉴(**⋮**)를 클릭한 뒤 **Edit widget**(위젯 편집)을 선택해요. 또는 **Edit mode**(편집 모드)를 열고 위젯을 클릭해도 돼요.
3. **구성** 탭에서 **고급 설정**을 펼칩니다.
4. **비교 날짜 범위** 아래에 **Specify whether a metric's increase or decrease is positive**(지표의 증가 또는 감소 중 어느 쪽이 긍정적인지 지정)가 보여요.
   - **증가는 양수입니다** *(기본값)*: 값이 오르면 배지가 초록색, 내리면 빨간색이 돼요.
   - **감소가 긍정적임**: 값이 내리면 배지가 초록색, 오르면 빨간색이 돼요.
5. 지표를 읽는 방식에 맞는 옵션을 선택하고 **변경사항 저장**을 클릭합니다.

{% hint style="info" %}
이 설정은 추세 배지에만 적용돼요. **비교 날짜 범위**(예: **지난 7일**)가 설정되어 있어야 해요. 비교 범위가 없으면 색을 칠할 증감률 자체가 없기 때문이에요.
{% endhint %}

## 예시

| 위젯 | 지표 특성 | 권장 설정 | 결과 |
| --- | --- | --- | --- |
| 구독 취소 이메일 | 낮을수록 좋음 | **감소가 긍정적임** | 구독 취소가 줄면 초록색으로 표시돼요 |
| 발송 완료 이메일 | 높을수록 좋음 | **증가는 양수입니다** | 발송 완료 이메일이 줄면 빨간색으로 표시돼요 |
| 반송률 | 낮을수록 좋음 | **감소가 긍정적임** | 반송률이 줄면 초록색으로 표시돼요 |
| 리드당 비용 | 낮을수록 좋음 | **감소가 긍정적임** | 리드당 비용이 줄면 초록색으로 표시돼요 |
| 이탈률 | 낮을수록 좋음 | **감소가 긍정적임** | 이탈률이 줄면 초록색으로 표시돼요 |

## 모든 차트 유형에 적용되나요?

추세 배지와 이 설정은 위젯을 **숫자**, **줄**, **바** 차트 중 무엇으로 표시하든 똑같이 동작해요.

## 자주 묻는 질문

### 이 설정을 바꾸면 기존 위젯의 모양이 달라지나요?

아니요. 기존 위젯은 모두 기본값이 **증가는 양수입니다**예요. 이전의 유일한 동작과 같아요. 위젯 설정을 직접 바꾸지 않으면 달라지는 것은 없어요.

### 사용자 지정 지표에서도 쓸 수 있나요?

**사용자 지정 지표**에는 이미 비슷한 토글이 있어요. 사용자 지정 지표 빌더의 "When the metric increases, show indicator as"(지표가 증가하면 표시기를 다음으로 표시) 항목에서 **긍정적** 또는 **부정적**을 고를 수 있어요.

### 추세 배지가 아예 보이지 않아요

위젯에 **비교 날짜 범위**(예: **지난 7일**, **이전 기간**)가 설정되어 있는지 확인하세요. 비교 범위가 없으면 비교할 대상이 없어서 배지도 증감 값도 표시되지 않아요.

### 이 설정은 정확히 어디에 있나요?

위젯 편집 화면에서 **구성** 탭 > **고급 설정** > **비교 날짜 범위** 아래에 있어요.
