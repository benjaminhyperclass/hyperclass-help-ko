# 대시보드와 리포트에서 커스텀 값 사용하기

커스텀 값을 쓰면 대시보드나 리포트 하나를 여러 서브 계정에서 그대로 쓸 수 있어요. 위치나 사용자 정보를 매번 직접 고칠 필요가 없어요. 위치 이름, 주소, 전화번호, 저장해 둔 커스텀 값을 직접 입력하는 대신 자리표시자를 넣어 두면, 대시보드를 열 때 하이퍼클래스가 실제 값으로 바꿔 줘요. 덕분에 대시보드를 관리하기 쉬워지고, 에이전시는 고객마다 대시보드를 따로 만들지 않아도 돼요.

---

## 대시보드와 리포트의 커스텀 값이란?

커스텀 값은 대시보드나 리포트를 열 때 하이퍼클래스가 실제 정보로 바꿔 주는 자리표시자예요. 대시보드를 하나만 만들어도 서브 계정이나 로그인한 사용자에 맞는 정보가 자동으로 표시돼요.

예를 들어 위젯 조건에 위치 주소를 직접 입력하는 대신 아래처럼 넣을 수 있어요.

`{{ location.address }}`

대시보드를 열면 하이퍼클래스가 이 자리표시자를 현재 서브 계정의 실제 주소로 바꿔 줘요.

커스텀 값은 대시보드와 리포트의 다음 항목에서 쓸 수 있어요.

- 위젯 조건
- **임베드** URL
- **제목** 요소
- **텍스트 박스** 요소

값은 세 그룹에서 고를 수 있어요.

- **위치**: 현재 서브 계정의 정보
- **사용자**: 로그인한 사용자의 정보
- **커스텀 값**: **설정 > 커스텀 값**에서 만든 값

---

## 커스텀 값을 쓰면 좋은 점

같은 대시보드가 위치와 사용자에 따라 자동으로 바뀌므로, 대시보드를 반복해서 설정하지 않아도 돼요. 서브 계정을 많이 관리하는 에이전시에 특히 유용해요.

- 대시보드 하나로 여러 서브 계정에서 쓸 수 있어요.
- 위치 정보가 대시보드를 보는 서브 계정에 맞게 자동으로 바뀌어요.
- 사용자 값으로 지금 로그인한 사람의 정보를 보여 줄 수 있어요.
- **설정 > 커스텀 값**에서 만든 값을 지원하는 대시보드 필드에 바로 넣을 수 있어요.
- 원본 값을 한 번만 고치면 돼요. 대시보드를 하나씩 수정하지 않아도 돼요.`{}` 버튼으로 사용할 수 있는 값을 검색하거나 훑어볼 수 있어요.

---

## 사용할 수 있는 값의 종류

사용할 수 있는 값은 위치, 사용자, 커스텀 값 세 그룹으로 나뉘어요. 그룹별 차이를 알아 두면 대시보드나 리포트에 맞는 정보를 고르기 쉬워요.

### 위치 값

위치 값은 대시보드를 보는 서브 계정의 정보예요.

사용할 수 있는 필드는 다음과 같아요.

- 위치 ID
- 위치 이름
- 이메일
- 전화번호
- 웹사이트
- 주소
- 시
- 주(State)
- 국가
- 우편번호
- 시간대

예를 들어 `{{ location.address }}`는 현재 서브 계정의 주소를 보여 줘요.

### 사용자 값

사용자 값은 지금 로그인한 사용자의 정보예요.

사용할 수 있는 필드는 다음과 같아요.

- 사용자 ID
- 이메일
- 전화번호
- 역할
- 유형
- 이름(First Name)
- 성(Last Name)
- 이름(Name)
- 전체 이름(Full Name)

대시보드를 보는 사람에 따라 달라지는 정보를 보여 주고 싶을 때 유용해요.

### 커스텀 값

커스텀 값은 **설정 > 커스텀 값**에서 만들어 두고 다시 쓰는 값이에요.

예를 들면 이런 값이 있어요.

- 주간 코칭 주제
- 지원 전화번호
- 운영 시간
- 내부 링크
- 비즈니스별 문구

커스텀 값은 선택 창에서 폴더별로 정리되어 보여요.

---

## 커스텀 값 선택 창 사용하기

선택 창을 쓰면 자리표시자를 직접 입력하지 않고도 위치, 사용자, 저장해 둔 커스텀 값을 넣을 수 있어요. 지원하는 필드 옆에 `{}` 버튼이 보이면 선택 창을 열어 원하는 값을 고르세요.

1. 지원하는 필드 옆의 `{}` 버튼을 클릭하세요.
2. 값을 검색하거나 카테고리별로 둘러보세요.
3. **위치**, **사용자**, **커스텀 값** 중 하나를 선택하세요.
4. 원하는 필드를 선택하세요.
5. 하이퍼클래스가 자리표시자를 자동으로 넣어 줘요.

예를 들면 이런 자리표시자가 들어가요.

`{{ location.address }}`

편집하는 동안에는 자리표시자가 그대로 보여요. 대시보드를 열면 하이퍼클래스가 실제 값으로 바꿔 줘요.

![커스텀 값 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079820040/original/yVXs-22txncmBxUMSnqQJ9w_7SbRUHcRYQ.png?1788273277)

## 위젯 조건에서 커스텀 값 사용하기

위젯 조건 안의 텍스트 필드 중 지원하는 곳에는 커스텀 값을 넣을 수 있어요. 직접 입력한 정보에 의존하지 않고, 위젯이 알맞은 위치·사용자·저장된 값을 자동으로 쓰게 돼요.

예를 들어 위젯 필터에 특정 사업장 주소를 직접 입력하는 대신 아래 값을 넣을 수 있어요.

`{{ location.address }}`

그러면 위젯은 대시보드를 보는 서브 계정의 주소를 사용해요.

같은 대시보드를 여러 서브 계정이 함께 쓸 때 편리해요. 위치마다 대시보드를 따로 만들 필요가 없어요.

![위젯 조건에 커스텀 값을 넣은 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079820380/original/q9qSpnA6pxUJfg_AdDY2IVpH42pveCdeXQ.png?1788273463)

## 대시보드 요소에서 커스텀 값 사용하기

지원하는 대시보드 요소에서도 동적 값을 쓸 수 있어요. 제목, 텍스트, 링크가 자동으로 바뀌므로 대시보드를 복사하지 않고도 맞춤 대시보드를 만들 수 있어요.

커스텀 값은 다음 요소에서 지원해요.

- **임베드** URL
- **제목** 요소
- **텍스트 박스** 요소

예를 들어 **텍스트 박스**에는 저장해 둔 값을 이렇게 넣을 수 있어요.

`{{ custom_values.ai_coaching_calls__weekly_topic }}`

대시보드를 열면 하이퍼클래스가 자리표시자를 해당 서브 계정에 저장된 값으로 바꿔 줘요.

![텍스트 박스에 커스텀 값을 넣은 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079820294/original/0Vjg-E8B-K59-fxj5e9hGmJCQHMD0gcARA.jpeg?1788273432)

## 서브 계정이 여러 개여도 대시보드는 하나로

동적 값을 쓰면 에이전시는 고객마다 대시보드를 복사하지 않고 하나만 관리할 수 있어요. 각 서브 계정이 대시보드를 열 때 하이퍼클래스가 알맞은 정보를 자동으로 채워 줘요.

예를 들어 대시보드 하나에 다음 값을 넣을 수 있어요.
`{{ location.name }}``{{ location.address }}``{{ location.phone }}`

위치 A가 대시보드를 열면 위치 A의 정보가 보여요.

위치 B가 같은 대시보드를 열면 위치 B의 정보가 보여요.

서브 계정마다 대시보드를 복사하거나 고칠 필요가 없어요.

---

## 대시보드와 리포트에 커스텀 값 설정하기

동적 값을 넣는 데는 몇 단계면 충분해요. 위젯 조건에 넣을 때와 대시보드 요소에 넣을 때 방법이 조금 달라요.

### 위젯 조건에 커스텀 값 넣기

1. 대시보드를 **편집 모드**로 여세요.
2. 수정할 위젯을 선택하세요.
3. **조건** 탭을 여세요.
4. 지원하는 텍스트 필드가 있는 조건을 추가하거나 편집하세요.
5. 필드 옆의 `{}` 버튼을 클릭하세요.
6. **위치**, **사용자**, **커스텀 값** 중 하나를 선택하세요.
7. 원하는 값을 검색하거나 선택하세요.
8. 필드에 자리표시자가 들어갔는지 확인하세요.
9. **저장**을 클릭하세요.
10. 대시보드 변경 사항을 저장하세요.

![위젯 조건에 커스텀 값 추가하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079822791/original/0L3HOW3fMp4LhCVw4UgTggiHRMWpvv7pnA.jpeg?1788274372)

### 대시보드 요소에 커스텀 값 넣기

1. 대시보드를 **편집 모드**로 여세요.
2. 지원하는 요소를 추가하거나 편집하세요.
3. **임베드**, **제목**, **텍스트 박스** 요소 중 하나를 선택하세요.
4. `{}` 버튼이 보이면 클릭하세요.
5. **위치**, **사용자**, **커스텀 값** 중 하나를 선택하세요.
6. 원하는 값을 고르세요.
7. 요소에 자리표시자가 들어갔는지 확인하세요.
8. **저장**을 클릭하세요.
9. 대시보드 변경 사항을 저장하세요.

![대시보드 요소에 커스텀 값 추가하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079822972/original/uGajcU6Pya7qnmsqUGfPXN2gys27fiO_sQ.jpeg?1788274413)

### 커스텀 값을 먼저 만들기

필요한 값이 아직 없다면 대시보드에 넣기 전에 먼저 만드세요.

1. **설정 > 커스텀 값**으로 이동하세요.
2. 커스텀 값을 만드세요.
3. 필요하면 폴더에 추가하세요.
4. 값을 저장하세요.
5. 대시보드로 돌아가세요.
6. `{}` 선택 창을 여세요.
7. **커스텀 값**에서 새 값을 찾으세요.

## 문제 해결

문제는 대부분 필드가 동적 값을 지원하지 않거나, 저장된 커스텀 값이 비어 있거나, 값 종류를 잘못 골랐을 때 생겨요. 원본 값부터 확인하면 원인을 빨리 찾을 수 있어요.

### `{}` 버튼이 보이지 않아요

해당 필드가 동적 값을 지원하지 않을 수 있어요. 커스텀 값은 지원하는 대시보드·리포트 필드에서만 쓸 수 있어요.

### 커스텀 값이 보이지 않아요

**설정 > 커스텀 값**에서 값이 있는지, 저장되어 있는지 확인하세요.

### 대시보드에 값이 비어 있어요

해당 서브 계정에 저장된 값이 비어 있을 수 있어요. 원본 정보나 커스텀 값을 확인하세요.

### 다른 위치의 정보가 나와요

위치 값은 대시보드를 보는 서브 계정의 정보를 사용해요. 올바른 서브 계정이 열려 있는지 확인하세요.

### 다른 사용자의 정보가 나와요

사용자 값은 지금 로그인한 사용자를 기준으로 해요.

## 자주 묻는 질문

### 한 대시보드에서 위치, 사용자, 커스텀 값을 함께 쓸 수 있나요?
네. 동적 값을 지원하는 곳이라면 한 대시보드 안에서 여러 종류의 값을 섞어 쓸 수 있어요.

### 위치 값은 서브 계정마다 자동으로 바뀌나요?
네. 위치 값은 대시보드를 보는 서브 계정의 정보를 사용해요.

### 사용자 값은 어떤 사용자의 정보를 쓰나요?
지금 로그인한 사람의 정보를 사용해요.

### 모든 대시보드 필드에서 커스텀 값을 쓸 수 있나요?
아니요. 동적 값은 지원하는 필드에서만 쓸 수 있어요. 필드에 `{}` 버튼이 보이면 지원하는 필드예요.

### **텍스트 박스**에 커스텀 값을 두 개 이상 넣을 수 있나요?
네. 요소가 넣으려는 값을 지원하면 가능해요.

### 커스텀 값이 비어 있으면 어떻게 되나요?
그 값을 쓴 자리에 아무것도 표시되지 않을 수 있어요.

### **사용자 지정 리포트**에서도 커스텀 값을 쓸 수 있나요?
네. 대시보드와 **사용자 지정 리포트**에서 해당하는 영역에 동적 값을 쓸 수 있어요.

### 서브 계정마다 대시보드를 따로 만들어야 하나요?
동적 값으로 해결할 수 있는 차이라면 따로 만들 필요가 없어요. 대시보드 하나로 서브 계정마다 알맞은 위치 정보를 자동으로 보여 줄 수 있어요.
