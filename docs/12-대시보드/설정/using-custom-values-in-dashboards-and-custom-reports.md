# 대시보드와 사용자 지정 리포트에서 커스텀 값 사용하기

커스텀 값을 쓰면 위치(서브 계정)별 데이터를 대시보드에 자동으로 넣을 수 있어요. 대시보드 하나로 보는 서브 계정에 맞춰 내용이 바뀌어요.

사업체 이름이나 주소를 직접 입력하는 대신 `{{ location.name }}` 같은 토큰을 넣어요. 대시보드를 열면 토큰이 해당 위치의 실제 값으로 바뀌어 표시돼요.

## 누가 쓸 수 있나요?

대시보드나 사용자 지정 리포트의 편집 권한이 있는 사용자가 커스텀 값을 설정할 수 있어요. 보기 권한만 있는 사용자는 실제 값으로 바뀐 화면을 볼 수 있어요.

## 커스텀 값을 쓸 수 있는 곳

텍스트 입력란 옆에 **{}** 버튼이 보이면 커스텀 값을 쓸 수 있어요.

**위젯 조건**
위젯에 조건을 추가할 때, 값 입력란의 **{}** 를 클릭하면 고정된 값 대신 토큰을 넣을 수 있어요.

**대시보드 요소**

- **임베드**: URL 입력란에 토큰을 넣어요. (예: `https://myagency.crm.com/embed/{{ location.id }}/page/main`)
- **제목**: 제목 입력란에 토큰을 넣어요. (예: `{{ location.name }} — Performance Dashboard`)
- **텍스트 박스**: 서식 편집기 안에 토큰을 넣어요. 토큰은 다른 내용과 같은 줄에 일반 텍스트처럼 표시돼요.

## 선택할 수 있는 커스텀 값

**{}** 를 클릭하면 선택 창이 열리고, 세 가지 분류가 보여요. 창 위쪽의 검색창에서 세 분류를 한꺼번에 검색할 수 있어요.

**위치**
서브 계정에 따라 값이 정해지는 필드예요.

- **Location Id**(위치 ID)
- **위치 이름**
- **Email**(이메일)
- **Phone**(전화번호)
- **Website**(웹사이트)
- **Address**(주소)
- **City**(시)
- **State**(주/도)
- **Country**(국가)
- **Postal Code**(우편번호)
- **Timezone**(시간대)

**사용자**
로그인한 사용자에 따라 값이 정해지는 필드예요.

- **User Id**(사용자 ID)
- **Email**
- **Phone**
- **Role**(역할)
- **Type**(유형)
- **First Name**(이름)
- **Last Name**(성)
- **Name**(이름)
- **Full Name**(전체 이름)

**커스텀 값**
해당 위치의 **설정 > 커스텀 값**에서 만든 값이 모두 나와요. 폴더별로 정리되어 보여요.

## 커스텀 값 넣는 방법

### 위젯 조건에 넣기

1. 대시보드를 열고 **편집 모드**를 클릭하세요.
2. 위젯을 추가하거나 편집한 다음 **조건** 탭으로 이동하세요.
3. 필드(예: **Address**)와 연산자(예: **Is**(일치))를 설정하세요.
4. 값 입력란에서 **{}** 버튼을 클릭하세요.
5. **위치**, **사용자**, **커스텀 값** 중에서 찾아보거나 검색하세요.
6. **필드 선택**에서 넣을 필드를 선택하세요. 토큰(`{{  }}`)이 입력돼요.
7. **저장**을 클릭하세요.

### 대시보드 요소에 넣기

1. 대시보드를 열고 **편집 모드**를 클릭하세요.
2. **요소 추가**를 클릭하고 **임베드**, **제목**, **텍스트 박스** 중 하나를 선택하세요.
3. 해당 입력란 옆의 **{}** 버튼을 클릭하세요.
4. **위치**, **사용자**, **커스텀 값** 중에서 찾아보거나 검색하세요.
5. **필드 선택**에서 넣을 필드를 선택하세요. 토큰이 입력돼요.
6. **저장**을 클릭하세요.
7. **View mode**(보기 모드)로 바꾸세요. 토큰이 해당 위치의 실제 값으로 표시돼요.

## 토큰에 값이 없으면 어떻게 되나요?

토큰의 값을 찾을 수 없으면(예: 해당 위치에 그 필드 값이 비어 있는 경우) 보기 모드에서 **빈 칸**으로 표시돼요.

빈 칸을 피하려면 다음을 확인하세요.

- **위치**와 **사용자** 필드: **설정**에서 서브 계정 프로필이 모두 채워져 있는지 확인하세요.
- **커스텀 값**: 위치마다 **설정 > 커스텀 값**에서 값을 만들고 내용을 채웠는지 확인하세요.

## 나만의 커스텀 값 만들기

기본으로 제공되는 **위치**와 **사용자** 필드 외에 직접 만든 커스텀 값을 쓰려면 아래 순서로 만드세요.

1. **설정 > 커스텀 값**으로 이동하세요.
2. **+ 커스텀 값 추가**를 클릭하세요.
3. 이름과 값을 입력하세요. 원하면 폴더도 지정할 수 있어요.
4. **만들기**를 클릭하세요.

이제 대시보드를 편집할 때 **{}** 선택 창의 **커스텀 값**에 새로 만든 값이 나타나요.

## 자주 묻는 질문

### 한 입력란에 일반 텍스트와 토큰을 함께 쓸 수 있나요?
네, 쓸 수 있어요. 같은 입력란에 직접 입력한 텍스트와 토큰을 함께 넣을 수 있어요. 예: `Welcome to {{ location.name }}. Your address is {{ location.address }}.`

### 서브 계정을 바꾸면 대시보드 값도 바뀌나요?
네, 바뀌어요. 서브 계정이 바뀌면 모든 토큰이 지금 선택된 위치의 값으로 바뀌어요.

### 보기 권한만 있는 사용자도 커스텀 값을 넣을 수 있나요?
아니요. 커스텀 값은 편집 권한이 있는 사용자만 넣을 수 있어요. 보기 권한만 있는 사용자는 실제 값으로 바뀐 화면만 볼 수 있어요.

### 이미지 요소에서도 커스텀 값을 쓸 수 있나요?
아니요, **이미지** 요소에서는 쓸 수 없어요. 커스텀 값은 **임베드**에서 쓸 수 있어요. 이미지가 URL로 있다면 **임베드**로 표시할 수 있어요.
