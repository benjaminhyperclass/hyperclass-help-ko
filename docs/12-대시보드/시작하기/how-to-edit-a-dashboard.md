# 대시보드 편집하기

대시보드 소유자는 대시보드를 편집해 리포팅 기능을 더 잘 활용할 수 있어요. 대시보드 이름 변경, 권한 업데이트, 새 커스텀 위젯 추가, 기존 위젯 편집이 가능해요. 아래 단계를 따라 대시보드를 편집해 보세요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

{% hint style="info" %}
여러 개의 커스텀 대시보드를 쓸 수 있는 요금제가 궁금하신가요?
여러 개의 커스텀 대시보드, 위젯, 커스텀 리포트는 $297 요금제와 $497 이상 요금제에서 쓸 수 있어요.
{% endhint %}

## 1단계. 대시보드로 이동하기

1. 편집하려는 대시보드로 이동하세요.

![편집할 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014394504/original/cQPxedtzIl5veBjtZ0NZ0jIi0jjBi4TuuA.png?1701773142)

{% hint style="info" %}
대시보드는 소유자만 편집할 수 있어요.
{% endhint %}

## 2단계. 편집 모드로 들어가기

1. 오른쪽 위에 있는 연필 모양 편집 아이콘을 클릭하세요. 편집 모드로 전환돼요.

![오른쪽 위 연필 모양 편집 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014394681/original/bv-tzE3LS8lEAE8DiOkETyfSECw70HWQ1w.png?1701773220)

## 3단계. 대시보드 이름 바꾸기

1. 필요하면 리포팅 목적에 맞게 대시보드 이름을 바꾸세요.

![대시보드 이름 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014394750/original/9_9umKUhFSLapo_GjA65IU4TqVxX8iRO1w.png?1701773251)

## 4단계. 새 위젯 추가하기

1. **Add Widgets**(위젯 추가)를 클릭해 대시보드에 새 커스텀 위젯을 추가하세요.

![Add Widgets 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014394784/original/ZhoKJ6P6bREAc0e4j2FBI5pl8IBrNbkdVg.png?1701773273)

커스텀 위젯을 추가하는 자세한 방법은 '대시보드에 위젯 추가하기' 문서를 참고하세요.

## 5단계. 변경사항 저장하기

1. 편집을 마쳤으면 **변경사항 저장**을 클릭하세요. 수정한 내용이 적용돼요.

![변경사항 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014394842/original/btZlr2oGsHubw3rjLfN-mVLqpLlfDE1gvw.png?1701773303)
