# 대시보드에서 '할당된 데이터만' 설정 사용하기

역할 및 권한의 **할당된 데이터만** 설정을 쓰면 팀원에게 본인에게 할당된 데이터만 보여 줄 수 있어요. 데이터 보안을 높이고, 팀원이 불필요한 정보에 헷갈리지 않게 도와줘요.

## 이 설정을 쓰는 이유와 방법

### 활용 효과

- 보안 강화: 데이터가 보이는 범위를 제한해서 민감한 정보를 보호해요. 관련 있는 팀원만 해당 데이터를 볼 수 있어요.
- 업무 효율 향상: 대시보드 위젯이 자동으로 필터링되어 사용자와 관련된 데이터만 보여 줘요. 직접 필터를 설정하지 않아도 돼서 준비 시간이 줄고, 맡은 업무에 집중할 수 있어요.
- 더 간단한 사용 환경: 위젯 데이터가 자동으로 제한되므로, 자기 역할과 관계없는 정보는 보이지 않아요. 대시보드가 더 정돈되고 쓰기 편해져요.

### 활용 예시

- 영업팀: 영업 관리자는 영업 담당자가 본인의 리드와 기회만 보도록 설정할 수 있어요. 데이터가 겹치지 않아 각자 맡은 일에 더 집중할 수 있어요.
- 고객 성공팀: 팀원이 본인에게 할당된 고객, 통화, 예약만 보도록 제한할 수 있어요. 그만큼 응대도 빨라져요.

---

## 1단계. 설정 열기

1. **설정 > 스태프 관리**를 클릭하세요.
2. 데이터 공개 범위를 설정할 팀원을 검색하세요.
3. 그 팀원 이름 옆의 **편집**을 클릭하세요.

## 2단계. '할당된 데이터만' 선택하기

1. 프로필의 **Roles and Permissions**(역할 및 권한) 섹션에서 **Data Visibility Scope**(데이터 공개 범위) 옵션을 찾으세요.
2. 드롭다운 메뉴에서 **할당된 데이터만**을 선택하세요.

![데이터 공개 범위 드롭다운에서 할당된 데이터만 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031956605/original/eSljisXY05ZiWjuO5_CgHZ5_QCcjxdYxtw.png?1725016609)

이전 사용자 권한 화면에서는 아래처럼 보여요.

![이전 사용자 권한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031963492/original/KQkj7Ja4FkMYf7vSeXi6MIxDmLPTrpk_9g.png?1725021334)

## 3단계. 저장하기

**저장**을 클릭하세요.

{% hint style="info" %}
위젯에 다른 팀원 기준으로 고정된 필터가 설정되어 있으면, **할당된 데이터만**이 켜진 사용자에게는 권한이 필요하다는 메시지가 표시돼요.
