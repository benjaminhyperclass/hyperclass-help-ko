# 스냅샷에 커스텀 연락처 보기 추가하기

커스텀 연락처 보기를 스냅샷에 담으면 한 서브 계정에서 만든 연락처 상세 페이지 레이아웃을 다른 서브 계정으로 복사할 수 있어요. 서브 계정마다 같은 보기를 직접 다시 만들 필요가 없어요. 영업, 지원, 온보딩, 고객 관리처럼 연락처 화면을 통일하고 싶은 에이전시에 특히 유용해요. 에이전시 관리자만 쓸 수 있어요.

## 스냅샷의 커스텀 연락처 보기란?

커스텀 연락처 보기를 쓰면 관리자가 연락처 상세 페이지에 연락처 정보가 보이는 방식을 직접 꾸밀 수 있어요. 이 보기를 **계정 스냅샷**에 포함하면 다른 서브 계정으로 복사해 다시 쓸 수 있어요.

원본 서브 계정에서 만든 커스텀 연락처 보기는 스냅샷을 만들거나 업데이트할 때 **Contact Detail Views**(연락처 상세 보기)에서 고를 수 있어요. 스냅샷에 포함한 보기는 다른 서브 계정으로 푸시하거나 불러올 수 있어요. 같은 설정을 반복하지 않아도 팀이 일관된 연락처 레이아웃을 유지할 수 있어요.

## 스냅샷에 커스텀 연락처 보기를 넣으면 좋은 점

여러 서브 계정의 연락처 관리를 같은 기준으로 맞출 수 있어요. 검증된 레이아웃을 재사용하면 반복 설정이 줄고, 팀이 필요한 연락처 정보를 늘 같은 형태로 볼 수 있어요.

- 빠른 설정: 커스텀 연락처 보기를 직접 다시 만들지 않고 다른 서브 계정에 복사해요.
- 일관된 레이아웃: 여러 고객사 계정이나 지점의 연락처 페이지 레이아웃을 같게 유지해요.
- 확장하기 쉬운 커스터마이징: 에이전시가 커지고 서브 계정이 늘어나도 같은 연락처 보기를 계속 쓸 수 있어요.
- 수작업 감소: 반복되는 설정 작업이 없어져 관리자의 시간이 절약돼요.
- 팀 간 통일: 영업, 지원, 운영 팀이 계정이 달라도 익숙한 레이아웃으로 연락처 데이터를 볼 수 있어요.

## 스냅샷에서 연락처 상세 보기 선택하기

이제 스냅샷을 만들 때 **Contact Detail Views**를 자산 종류로 선택할 수 있어요. 어떤 커스텀 연락처 레이아웃을 스냅샷에 담아 여러 서브 계정에서 쓸지 직접 정할 수 있어요.

스냅샷을 만들 때 **Contact Detail Views**에서 커스텀 보기를 선택하면 그 보기가 스냅샷에 추가돼요. 추가된 보기는 연결된 서브 계정이나 대상 서브 계정으로 복사할 수 있어요.

이럴 때 쓰세요.

- 영업용 커스텀 연락처 레이아웃을 여러 서브 계정에서 같이 쓰고 싶을 때
- 팀별 지원 또는 온보딩 연락처 보기를 통일하고 싶을 때
- 에이전시가 승인한 연락처 레이아웃을 새 고객 계정이나 기존 고객 계정에 복사하고 싶을 때
- 새 서브 계정을 시작할 때 설정 시간을 줄이고 싶을 때

## 서브 계정 간 복사

스냅샷을 이용하면 한 서브 계정의 커스텀 연락처 보기를 다른 서브 계정으로 옮길 수 있어요. 보기를 일일이 다시 만들지 않아도 에이전시가 계정 간 일관성을 유지할 수 있어요.

커스텀 연락처 보기를 서브 계정 간에 복사하려면 다음 순서로 진행하세요.

1. 재사용할 보기가 이미 들어 있는 서브 계정에서 스냅샷을 만들어요.
2. **Contact Detail Views**에서 원하는 보기를 선택해요.
3. 스냅샷을 대상 서브 계정에 적용하거나 푸시해요.

같은 연락처 페이지 구조가 필요한 여러 계정을 운영하는 에이전시에 알맞은 방식이에요.

## 스냅샷에 커스텀 연락처 보기 추가하는 절차

올바른 보기를 스냅샷에 담아 알맞은 서브 계정으로 복사하려면 설정 순서를 지켜야 해요. 시작하기 전에 원본 서브 계정에 재사용할 커스텀 연락처 보기가 이미 있는지 확인하세요.

1. **Agency View**(에이전시 보기)로 이동한 뒤 **계정 스냅샷**을 클릭하세요.
2. **새 스냅샷 생성**을 클릭하세요.

   ![계정 스냅샷 화면에서 새 스냅샷 생성 버튼을 클릭하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072274145/original/JNxXwViLCAj-AdJk5Put-I6UTObFEyUk2w.png?1779859832)
3. 스냅샷 이름을 입력하고, 복사할 커스텀 연락처 보기가 들어 있는 원본 서브 계정을 선택하세요.

   ![스냅샷 이름을 입력하고 원본 서브 계정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072274206/original/Yi9PITCWvu8nzhOT2ZDLAx5N3f9zSv3VAA.png?1779859895)
4. 자산 선택 목록에서 **Contact Detail Views**를 찾으세요.

   ![자산 선택 목록에서 Contact Detail Views를 찾는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072274288/original/CcYHcOyR4Rbqu3jCbeMf3TbA5tmVFXbBPQ.png?1779860058)
5. 스냅샷에 포함할 커스텀 연락처 보기를 선택하세요.
6. **만들기**를 클릭하세요.

   ![선택을 마친 뒤 만들기 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072274362/original/24tDv8xwCDgvDYpt09Mlv2cOWBJJ2Ghsxw.png?1779860180)
7. 연결된 서브 계정으로 업데이트를 푸시하거나, 대상 서브 계정에 스냅샷을 적용하세요.

   ![연결된 서브 계정에 업데이트를 푸시하거나 스냅샷을 적용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072274437/original/cXxV7KUz9LrrIVHNdsrkeIdfwMVRDJaKiQ.png?1779860236)
8. 대상 서브 계정을 열어 연락처 상세 페이지에 커스텀 보기가 보이는지 확인하세요.

## 커스텀 연락처 보기를 잘 재사용하는 방법

보기 운영 기준이 분명하면 계정이 달라도 연락처 레이아웃을 깔끔하게 관리할 수 있어요. 이름 규칙을 정하고, 원본 계정을 하나로 유지하고, 복사 후 검토 단계를 두면 여러 서브 계정에 복사할 때 생기는 혼란을 막을 수 있어요.

```
커스텀 보기 이름은 영업 보기, 지원 보기, 고객 온보딩 보기처럼 알아보기 쉽게 지으세요.

커스텀 보기는 원본 서브 계정에서 먼저 만들고 테스트한 뒤 스냅샷에 추가하세요.

대상 서브 계정에서 필요한 보기만 선택하세요.

스냅샷 업데이트를 푸시한 뒤에는 대상 서브 계정을 확인하세요.
```

## 자주 묻는 질문

### 커스텀 연락처 보기를 한 서브 계정에서 다른 서브 계정으로 복사할 수 있나요?
네. 커스텀 연락처 보기를 스냅샷에 포함하면 다른 서브 계정으로 복사할 수 있어요.

### 스냅샷을 만들 때 커스텀 연락처 보기는 어디서 선택하나요?
스냅샷의 자산 선택 화면에서 **Contact Detail Views** 아래에 커스텀 보기가 나와요.

### 서브 계정마다 같은 연락처 보기를 다시 만들어야 하나요?
아니요. 보기를 스냅샷에 포함하면 다른 서브 계정에서 재사용할 수 있어요.

### 커스텀 연락처 보기를 연결된 서브 계정으로 푸시할 수 있나요?
네. 커스텀 보기를 스냅샷에 포함한 뒤 업데이트를 연결된 서브 계정으로 푸시할 수 있어요.

### 이미 있는 스냅샷에도 커스텀 연락처 보기를 추가할 수 있나요?
네. 원본 서브 계정에서 스냅샷을 새로 고치거나 업데이트하고, 원하는 **Contact Detail Views**를 선택한 뒤 업데이트를 푸시하세요.

### 이 기능으로 여러 계정의 연락처 레이아웃을 통일할 수 있나요?
네. 에이전시가 여러 서브 계정의 연락처 상세 페이지 레이아웃을 일관되게 유지하도록 만든 기능이에요.

### 스냅샷 업데이트를 푸시한 뒤에는 무엇을 확인해야 하나요?
대상 서브 계정을 열어 복사된 커스텀 연락처 보기가 연락처 상세 페이지에 보이는지 확인하세요.
