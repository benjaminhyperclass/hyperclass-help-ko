# 부동산 중개인 스냅샷

부동산 중개인용 서브 계정을 빠르게 만들 수 있는 기본 스냅샷이에요. 이 문서에서 스냅샷의 구성과 설치 방법을 확인하세요.

## 설정 가이드

**부동산 중개인** 스냅샷은 부동산 중개인에게 맞춘 서브 계정을 만들 때 기준이 되는 템플릿이에요. 리드를 모으고, 관리하고, 계약까지 이어 가는 데 필요한 도구가 한꺼번에 들어 있어요.

- 웹사이트
- 폼
- 캘린더
- 워크플로우
- 이메일 캠페인
- 온라인 광고
- 소셜 게시물

{% hint style="info" %}
설정 가이드 링크가 필요하면 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

## 스냅샷 설치하기

스냅샷을 계정에 설치하는 방법은 하이퍼클래스 고객지원에 문의하면 안내받을 수 있어요.
