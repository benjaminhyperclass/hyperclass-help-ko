# 여러 서브 계정에 스냅샷 한 번에 로드하기

에이전시는 고객사 계정 여러 개에 같은 스냅샷을 한 화면에서 적용할 수 있어요. 서브 계정을 하나씩 열 필요 없이 **계정 스냅샷** 화면에서 대상 계정을 고르고, 로드할 항목을 확인한 뒤 한 번에 마무리하세요. 대시보드가 포함돼 있으면 선택한 대시보드 하나를 대상 서브 계정 전체의 기본 대시보드로 지정할 수도 있어요.

이 문서에서는 다음 내용을 다뤄요.

- 스냅샷 로드 화면에서 서브 계정을 여러 개 선택하는 방법
- **전체**, **연결됨**, **사용 가능** 탭을 쓰는 방법
- 대시보드가 포함된 경우 기본 대시보드를 지정하는 방법
- 나머지 로드 단계를 마치는 방법

## 여러 서브 계정에 스냅샷을 로드한다는 건 무엇인가요?

기존 스냅샷 로드 화면에서는 서브 계정을 하나씩 열어 작업했어요. 이 기능은 계정 선택을 한곳으로 모아 줘요.

**계정 스냅샷**에서는 다음 일을 할 수 있어요.

- 스냅샷에 이미 연결된 서브 계정을 확인해요.
- 아직 연결되지 않은 계정을 찾아요.
- 대상 계정을 여러 개 선택해요.
- 서브 계정을 하나씩 열지 않고 바로 로드를 시작해요.

아직 연결되지 않은 계정에 스냅샷을 로드하면, 같은 과정에서 하이퍼클래스가 그 서브 계정을 스냅샷에 자동으로 연결해요.

### 이 기능의 장점

스냅샷을 한곳에서 로드하면 계정마다 같은 작업을 반복하지 않아도 돼요. 더 많은 고객사 계정에 일관된 설정을 쉽게 적용할 수 있어요.

- 빠른 온보딩: 같은 작업을 계정마다 반복하지 않고, 한 번에 여러 서브 계정에 스냅샷을 로드해요.
- 하나로 모은 워크플로우: **계정 스냅샷**에서 시작해 **Load**(스냅샷 로드 창) 한 곳에서 적용 여부를 정해요.
- 한눈에 보이는 현황: 어떤 서브 계정이 이미 스냅샷에 연결돼 있고, 어떤 계정에 아직 필요한지 바로 확인해요.
- 빠른 표준화: 수동 단계를 줄이면서 더 많은 고객사 계정에 에이전시의 기본 설정을 적용해요.
- 사용 가능한 계정은 자동 연결: 사용 가능한 서브 계정에 스냅샷을 로드하면 같은 작업에서 하이퍼클래스가 계정을 연결해요.
- 일관된 기본 대시보드: 스냅샷에 대시보드가 포함돼 있으면, 선택한 대시보드 하나를 계정마다 따로 바꾸지 않고 대상 서브 계정 전체의 기본 대시보드로 지정해요.

### 한 화면에서 계정 선택하기

**계정 스냅샷**에서 **Load** 창을 열면 다음 일을 할 수 있어요.

- 에이전시의 서브 계정을 한곳에서 확인해요.
- 이름으로 특정 서브 계정을 검색해요.
- 한 번에 계정을 하나, 여러 개, 또는 많이 선택해요.
- 서브 계정을 하나씩 열지 않고 바로 로드를 시작해요.

![스냅샷 선택에 사용할 수 있는 에이전시 서브 계정이 보이는 Load 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587395/original/aQ092GH-WvscNMVYpr3we1D_YZXUyGGz-Q.png?1787947852)

### 계정 탭으로 상태 구분하기

계정 탭을 쓰면 서브 계정이 선택한 스냅샷과 어떤 관계인지 알 수 있어요. 로드하기 전에 대상 계정을 고르기가 쉬워져요.

**Load** 창에는 탭이 세 개 있어요.

- **전체**: 에이전시의 모든 서브 계정을 보여 줘요.
- **연결됨**: 선택한 스냅샷에 이미 연결된 서브 계정을 보여 줘요.
- **사용 가능**: 선택한 스냅샷에 아직 연결되지 않은 서브 계정을 보여 줘요.

예를 들어 **사용 가능** 탭에서는 아직 스냅샷에 연결되지 않은 계정을 찾을 수 있어요.

![전체, 연결됨, 사용 가능 서브 계정 탭이 보이는 Load 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587413/original/3sCNG6xlzACE5RPpw5bv8Qss3JW247o44Q.png?1787947906)

## 여러 서브 계정에 스냅샷 로드하기

아래 순서대로 진행하면 대상 계정을 정확히 고르고, 스냅샷 항목과 충돌 여부를 확인한 뒤 여러 서브 계정에 같은 설정을 적용할 수 있어요.

1. **계정 스냅샷** 화면을 열어요.

   **에이전시 보기**에서 **계정 스냅샷**으로 이동해 사용할 스냅샷을 찾으세요. 그 스냅샷 옆의 **Load Updates to Sub-Account**(서브 계정에 업데이트 로드)를 클릭하세요.

   ![Load Updates to Sub-Account 작업이 보이는 계정 스냅샷 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587449/original/7XzB2TI-j6ZZPKLQOkevbgZgZQOhqKSogA.png?1787947999)

2. 알맞은 계정 탭을 선택해요.

   계정 탭으로 대상 목록을 좁힐 수 있어요.

   - **전체**: 모든 서브 계정을 봐요.
   - **연결됨**: 스냅샷에 이미 연결된 계정을 봐요.
   - **사용 가능**: 아직 연결되지 않은 계정을 봐요.

   ![전체, 연결됨, 사용 가능 계정 탭이 보이는 스냅샷 Load 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069033868/original/9k5WGTceT4yGpu8wr0_NRevaNvnQen90zQ.png?1776089943)

3. 대상 서브 계정을 선택해요.

   포함할 서브 계정 옆의 체크박스를 선택하세요. 특정 계정을 찾으려면 검색을 사용하세요. 그다음 **Load**(로드)를 클릭해 스냅샷 로드를 계속 진행하세요.

   ![대상 서브 계정을 여러 개 선택하고 스냅샷 로드를 계속하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587669/original/wfv7ISUj_YqJAtELI4KObENrPGyvpiFP5A.gif?1787948252)

4. 나머지 로드 단계를 마쳐요.

   안내가 나오면 로드할 스냅샷 항목을 확인하세요. 로드 과정에서 충돌 옵션이 나오면 충돌을 해결하세요.

   기본 대시보드: 로드할 항목에 대시보드가 포함돼 있으면, 선택한 대시보드 하나에서 **기본값으로 설정**을 클릭하세요. 그 대시보드가 대상 서브 계정의 기본 대시보드가 돼요. 한 번에 대시보드 하나만 표시할 수 있어요. 표시한 대시보드가 없으면 하이퍼클래스는 스냅샷에 원래 설정된 기본 대시보드를 사용해요.

   마지막으로 작업을 확인하면 선택한 계정에 스냅샷 로드가 시작돼요.

   ![선택한 서브 계정에 로드하기 전에 자산을 확인하는 스냅샷 로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587686/original/ZI_zl9-ZYCQQn2QJDihDn81mGCb88QgRdw.png?1787948269)
   ![선택한 서브 계정에 스냅샷을 적용하기 전 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587695/original/SuSp0GxbROrwRRdCyUefsplHTFlZcdpncg.png?1787948294)

스냅샷을 로드할 때 대시보드를 고르는 방법과 기본 대시보드가 적용되는 방식이 궁금하다면 [대시보드가 포함된 스냅샷 로드하기](../12-대시보드/시작하기/how-to-load-snapshots-with-dashboards.md) 문서를 참고하세요.

## 자주 묻는 질문

### 이 기능과 기존 스냅샷 로드 방식은 어떻게 다른가요?

기존 방식은 보통 서브 계정 하나에서 시작해요. 이 방식은 **계정 스냅샷**에서 시작하고, **Load** 창 한 곳에서 서브 계정을 여러 개 선택할 수 있어요.

### 사용 가능한 서브 계정에 스냅샷을 로드하면 어떻게 되나요?

하이퍼클래스가 스냅샷을 로드하고, 같은 과정에서 그 서브 계정을 스냅샷에 자동으로 연결해요.

### 서브 계정을 한 번에 여러 개 선택할 수 있나요?

네, 할 수 있어요. **Load** 창에서 한 번에 서브 계정 여러 개를 선택하도록 만들어져 있어요.

### 이 기능이 **Push Updates**(업데이트 푸시)를 대신하나요?

아니요. 이 기능은 서브 계정에 스냅샷을 로드하고 연결하는 방식을 개선한 거예요. **Push Updates**는 지속적인 업데이트 관리를 위한 별도의 스냅샷 작업으로 그대로 남아 있어요.

### 이 작업은 어디에서 시작하나요?

**에이전시 보기**의 **계정 스냅샷**에서 시작하세요. 적용할 스냅샷 옆의 **Load Updates to Sub-Account**를 클릭하면 돼요.

### 에이전시에 이 기능이 왜 유용한가요?

화면을 오가는 일이 줄고, 서브 계정별 현황이 한눈에 보여요. 여러 고객사 계정에 에이전시의 표준 설정을 적용하기도 쉬워져요.
