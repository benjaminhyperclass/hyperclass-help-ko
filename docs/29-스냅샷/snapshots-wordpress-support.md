# 스냅샷에 WordPress 사이트 포함하기

스냅샷의 WordPress 지원 기능을 쓰면 WordPress 사이트 전체(페이지, 테마, 플러그인, 설정)를 스냅샷에 담을 수 있어요. 이 문서에서는 WordPress를 스냅샷 자산으로 선택하는 방법과, 스냅샷을 다른 서브 계정에 배포할 때 어떻게 되는지 안내해요.

## 스냅샷의 WordPress 지원이란?

선택한 서브 계정에 있는 WordPress 사이트를 하나 또는 여러 개 스냅샷에 담을 수 있는 기능이에요. 이 스냅샷을 다른 서브 계정에 배포하면 하이퍼클래스가 선택한 다른 스냅샷 자산과 함께 WordPress 사이트도 자동으로 복원해요.

## WordPress 지원의 장점

- 고객사 계정을 더 빠르게 시작할 수 있어요. 처음부터 다시 만들지 않고 WordPress 환경 전체를 배포할 수 있어요.
- 계정마다 같은 테마, 플러그인, 구성을 재사용해서 일관되게 제공할 수 있어요.
- 표준 스냅샷에 사이트를 함께 복원하므로 빠뜨리는 설정 단계가 줄어요.
- 한 번 만들어 두면 새 서브 계정이나 기존 서브 계정에 같은 설정을 반복해서 적용할 수 있어요.

## 스냅샷에 WordPress 지원 설정하기

WordPress 자산을 올바르게 선택해야 스냅샷이 의도한 사이트를 복원하고, 서브 계정마다 같은 결과로 배포할 수 있어요. 이 기능은 에이전시 계정에서 설정해요.

### 옵션 A: WordPress를 포함해 새 스냅샷 만들기

1. 에이전시 계정에 로그인하세요.
2. **계정 스냅샷**으로 이동하세요.
3. **스냅샷 만들기**를 클릭하세요.

   ![스냅샷 만들기 버튼](https://jumpshare.com/share/LS1x1KWb7IgvoGuMisow+/Screen+Shot+2026-02-27+at+18.52.48.png)
4. **스냅샷 이름**을 입력하세요.
5. 데이터를 가져올 서브 계정을 선택하세요.
6. **다음**을 클릭하면 **Select Assets**(자산 선택) 창이 열려요.

   ![자산 선택 창](https://jumpshare.com/share/Wx1DZVAt8B71K2mKjsNt+/Screen+Shot+2026-02-27+at+19.01.52.png)
7. **WordPress** 체크박스를 켜세요.
8. **WordPress**를 펼쳐서 포함할 사이트를 선택하세요.
9. **만들기**를 클릭하세요.

   ![WordPress 사이트를 선택하고 만들기를 클릭하는 화면](https://jumpshare.com/share/mGhieh653e8wbCpvJWGS+/Screen+Shot+2026-02-27+at+19.05.53.png)

### 옵션 B: 기존 스냅샷에 WordPress 추가하기

1. 에이전시 계정에 로그인하세요.
2. **계정 스냅샷**으로 이동하세요.
3. 업데이트할 스냅샷을 찾으세요.
4. 스냅샷 옆의 **점 세 개(⋮)** 를 클릭한 다음 **설정**을 선택하세요.

   ![스냅샷 옆 점 세 개 메뉴에서 설정 선택](https://jumpshare.com/share/ci3g6pfJy3aONsBHuXAc+/Screen+Shot+2026-02-27+at+19.07.46.png)
5. **Linked Assets**(연결된 자산) 섹션까지 스크롤하세요.
6. **WordPress**를 켜고, 펼쳐서 포함할 사이트를 선택하세요.
7. **저장**을 클릭해 변경사항을 저장하세요.

   ![연결된 자산에서 WordPress 선택 후 저장](https://jumpshare.com/share/3RDmC8u3Xo3SaNfuMpKV+/Screen+Shot+2026-02-27+at+19.09.45.png)

## 자주 묻는 질문

### 스냅샷 하나에 WordPress 사이트를 여러 개 넣을 수 있나요?
WordPress 선택 목록에 사이트가 여러 개 있으면 함께 담을 사이트를 골라서 선택할 수 있어요.

### 스냅샷을 배포하면 WordPress 사이트는 어떻게 되나요?
스냅샷을 배포할 때 선택한 다른 자산과 함께 WordPress 사이트도 자동으로 복원돼요.

### 이 기능을 쓰면 고객마다 WordPress 페이지와 플러그인을 다시 만들지 않아도 되나요?
네. 스냅샷에 WordPress를 포함하면 처음부터 다시 시작하지 않고 서브 계정마다 같은 WordPress 환경을 재사용할 수 있어요.

### 스냅샷에는 WordPress의 어떤 요소가 들어가나요?
WordPress 스냅샷에는 페이지, 테마, 플러그인, 사이트, 설정이 들어갈 수 있어요. 그래서 다른 곳에 적용해도 사이트 구조와 구성이 그대로 유지돼요.

### 스냅샷에 플러그인과 테마 라이선스도 포함되나요?
아니요. WordPress 구성에 서드파티 라이선스나 외부 서비스가 쓰이면, 배포 후에 제공업체에 따라 다시 인증하거나 다시 활성화해야 할 수 있어요.

### 나중에 기존 스냅샷에 WordPress를 추가할 수 있나요?
네. **스냅샷 설정**에서 Linked Assets(연결된 자산)에 WordPress를 포함하도록 업데이트하면 돼요.
