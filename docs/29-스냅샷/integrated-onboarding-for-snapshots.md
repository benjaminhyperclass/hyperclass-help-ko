# 스냅샷 통합 온보딩 안내

스냅샷 화면 안에서 바로 쓸 수 있는 온보딩 안내예요. 짧은 팁과 영상, 도움말 문서 링크가 들어 있어서 앱을 벗어나지 않고 스냅샷을 만들고, 가져오고, 관리할 수 있어요. 처음 스냅샷을 쓰는 본인과 팀원이 더 빠르게 적응하도록 도와줘요.

---

# 스냅샷 통합 온보딩이란?

스냅샷 통합 온보딩은 스냅샷 화면 안에서 보여 주는 앱 내 학습 안내예요. 처음 쓰는 사용자가 스냅샷의 핵심 작업을 앱 안에서 바로 익힐 수 있어요. 핵심 작업은 만들기, 가져오기, 공유, 새로고침, **Push Updates**(업데이트 푸시)예요. 짧은 팁과 자세한 문서 링크를 함께 보여 주기 때문에, 처음 가치를 얻기까지 걸리는 시간이 줄고 빈 화면 앞에서 헤매는 일도 없어져요.

이 안내는 **에이전시 보기 > 계정 스냅샷**을 열었을 때, 아직 스냅샷을 만들거나 가져온 적이 없으면 나타나요. 간단한 설명과 학습 자료를 보면서 첫 스냅샷 작업을 끝낼 수 있고, 나중에 필요할 때 안내를 다시 볼 수도 있어요.

---

## 통합 온보딩의 주요 장점

앱 내 안내가 설정 시간을 줄이고, 스냅샷의 핵심 작업을 쉽게 찾게 해 주며, 팀의 온보딩 방식을 하나로 맞춰 줘요.

- **빠른 첫 성공:** 안내 문구와 도움말 링크를 따라가면 "스냅샷이 뭐지?" 단계에서 첫 스냅샷 완료까지 빠르게 갈 수 있어요.
- **화면 안에서 짧게 학습:** 스냅샷 화면에서 벗어나지 않고 짧은 영상을 보거나 도움말 문서로 이동할 수 있어요. 작업에 집중하기 좋아요.
- **팀 전체가 같은 방식으로 적응:** 새 팀원도 같은 순서로 스냅샷 기본기를 익힐 수 있어서 문의와 교육에 드는 시간이 줄어요.
- **작업을 방해하지 않는 안내:** 필요할 때 나타나고, 작업을 시작하면 방해하지 않아요.
- **필요할 때 다시 보기:** 나중에 안내를 다시 열어 단계를 확인하거나 관련 스냅샷 문서를 더 살펴볼 수 있어요.

---

## First-Interaction Helper(첫 사용 도움말)

스냅샷 목록이 비어 있으면 무엇을 해야 할지 막막할 수 있어요. **First-Interaction Helper**는 핵심 개념을 설명하고, 다음 단계인 스냅샷 만들기나 가져오기로 바로 안내해 줘요.

**빈 목록에서 볼 수 있는 내용:**

- "스냅샷이란?"을 짧게 설명한 안내
- 첫 스냅샷 작업을 시작하는 기본 버튼
- **만들기**, **가져오기**, **공유**, **새로고침**, **Push Updates**를 알아보는 바로가기 링크

![빈 스냅샷 목록에 나타난 첫 사용 도움말 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062321037/original/-0_6mhwqec8U-vGq3_n4Q4iP2weKjVpM7A.png?1767963027)

## On-Demand Learning Panel(필요할 때 여는 학습 패널)

스냅샷을 쓰기 시작한 뒤에도 작은 학습 영역이 남아 있어요. 작업 중에 필수 주제를 다시 보거나, 짧은 영상을 다시 재생하거나, 자세한 도움말 문서를 열 수 있어요.

**제공하는 내용:**

- **만들기**, **가져오기**, **공유**, **새로고침**, **Push Updates**에 대한 짧은 팁
- 모범 사례와 자세한 절차를 담은 추천 도움말 문서 링크
- 다른 탭으로 이동하지 않고 한곳에서 볼 수 있는 학습 영역

![필요할 때 여는 학습 패널 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062320843/original/Iac_YhubPwjxkjmq7mR6MexWCLNfycBHEg.png?1767962947)

## 통합 온보딩 사용하기

아래 순서대로 따라 하면 첫 스냅샷을 빠르게 끝내고, 나중에 도움말을 어디서 찾는지도 알 수 있어요.

1. **에이전시 보기 > 계정 스냅샷**으로 이동하세요.

   ![에이전시 보기의 계정 스냅샷 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062320629/original/O3Xw-eCC-mnHXkG_QjfInBP0dq0gixW5Dg.png?1767962830)
2. 스냅샷이 하나도 없으면 **First-Interaction Helper**가 자동으로 열려요.

   ![자동으로 열린 첫 사용 도움말](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062320730/original/T8Fc6_a7Oj1w8AFyQ33nHzCpnfgaBXyigg.png?1767962882)
3. **스냅샷 만들기**를 선택하세요. 이미 있는 스냅샷을 가져오려면 **가져오기**를 선택하세요. 그다음 기본 마법사 화면에 따라 진행하세요.

   ![스냅샷 만들기 또는 가져오기 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062321112/original/ZLIxPr2HtU1MF00fenCaTS6Jh8rlTVuE-w.png?1767963058)
4. 첫 스냅샷을 완료하면 **내 스냅샷**, **가져온 스냅샷**, **공유된 스냅샷** 섹션마다 **Help wizard**(도움말 마법사)가 생겨요. 여기서 학습 자료를 언제든 다시 열 수 있어요.

   ![스냅샷 하위 섹션의 도움말 마법사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062321409/original/IbV_Y-rRQBaXRVQu0hGfeCbAwUXABJASNw.png?1767963180)
   ![도움말 마법사를 다시 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062321440/original/dtQSOedtJpw6DQxMbbayejjlrmPPk01oiw.png?1767963202)
5. **공유**, **새로고침**, **Push Updates** 같은 주제가 필요할 때는 **On-Demand Learning Panel**에서 바로 이동하세요.

---

## 자주 묻는 질문

### 통합 온보딩은 누구에게 보이나요?
**에이전시 보기 > 계정 스냅샷**에 접근할 수 있는 사용자가 스냅샷이 하나도 없는 상태로 처음 들어가면 온보딩이 보여요. 보이지 않는다면 본인의 역할과 권한을 확인해 보세요.

### 스냅샷을 만든 뒤에 안내를 다시 볼 수 있나요?
네. 작은 접근 버튼이 남아 있어서 필요할 때 팁과 관련 문서를 다시 열 수 있어요.

### 온보딩 때문에 스냅샷을 만들고 관리하는 방식이 달라지나요?
아니요. 온보딩은 안내와 학습 링크만 제공해요. **만들기**, **가져오기**, **공유**, **새로고침**, **Push Updates** 같은 핵심 작업은 기존 스냅샷 화면에서 그대로 진행해요.
