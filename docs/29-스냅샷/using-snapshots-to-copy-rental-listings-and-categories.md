# 스냅샷으로 대여 리스팅과 카테고리 복사하기

이제 스냅샷에 대여 리스팅과 대여 카테고리를 담을 수 있어요. 대여 설정을 한 번 만들어 두면, 스냅샷을 만들거나 복원할 때 선택한 대여 자산을 다른 서브 계정으로 복사할 수 있어요. 에이전시와 여러 지점을 운영하는 비즈니스가 대여 설정을 반복해서 만드는 수고를 덜고, 설정을 일관되게 유지하는 데 도움이 돼요. 에이전시 관리자만 쓸 수 있는 기능이에요.

## 스냅샷에서 대여 리스팅과 카테고리를 지원한다는 건 무슨 뜻인가요?

에이전시는 스냅샷을 만들거나 불러올 때 대여 자산을 함께 담을 수 있어요. 리스팅과 카테고리를 서브 계정마다 일일이 다시 만들지 않아도, 대여 설정 구조를 빠르게 복제할 수 있어요.

대여 리스팅은 대여할 수 있는 개별 항목이에요. 부동산, 차량, 객실, 장비처럼 예약할 수 있는 자산이 여기에 해당해요. 대여 카테고리는 이런 리스팅을 논리적인 그룹으로 묶어 줘요. 고객과 내부 팀이 대여 옵션을 더 쉽게 찾아볼 수 있어요. 이제 이 자산들을 스냅샷 작업에서 선택해 다른 대상 서브 계정에 추가할 수 있어요.

---

## 대여 설정을 스냅샷으로 복사하면 좋은 점

스냅샷으로 대여 자산을 복제하면 에이전시와 여러 지점을 운영하는 팀이 일관된 대여 경험을 더 빠르게 만들 수 있어요. 서브 계정마다 리스팅과 카테고리를 새로 만드는 대신, 검증된 설정에서 시작해 필요한 곳에 적용하면 돼요.

- 빠른 온보딩: 미리 구성한 대여 리스팅과 카테고리를 새 서브 계정이나 기존 서브 계정에 복사해 설정 시간을 줄일 수 있어요.
- 일관된 대여 구성: 지점마다 카테고리 구조를 통일해 고객이 익숙한 예약 환경을 만나게 할 수 있어요.
- 반복 작업 감소: 비즈니스나 지점마다 같은 대여 자산을 직접 다시 만들지 않아도 돼요.
- 자산을 골라서 선택: 스냅샷을 만들거나 복원할 때 대여 리스팅과 대여 카테고리를 각각 따로 선택할 수 있어요.
- 확장 가능한 템플릿 배포: 여러 고객 계정이나 사업장에 적용할 수 있는 대여 템플릿을 만들어 둘 수 있어요.

---

## 스냅샷에 담기는 대여 리스팅

대여 리스팅은 대여 설정의 핵심 자산이에요. 스냅샷에 대여 리스팅을 포함하면 한 서브 계정에 구성해 둔 대여 항목을 다른 서브 계정으로 복사할 수 있어요.

리스팅은 보통 자동차, 부동산, 장비, 객실처럼 예약할 수 있는 항목 하나를 나타내요. 원본 서브 계정에서 리스팅을 어떻게 구성했는지에 따라 리스팅 정보, 가격, 예약 옵션, 재고, 변형, 게시 상태 같은 주요 설정 내용이 포함될 수 있어요.

```
스냅샷에서 대여 리스팅을 쓰면 좋은 경우:

표준 대여 항목 세트를 여러 지점에서 재사용하고 싶을 때

승인된 대여 구성을 담은 템플릿 서브 계정을 만들고 싶을 때

대상 서브 계정마다 리스팅을 일일이 다시 만들고 싶지 않을 때

비슷한 대여 비즈니스나 지점을 일관된 초기 설정으로 시작하고 싶을 때
```

대여 카테고리는 리스팅을 그룹으로 묶어서 대여 설정을 더 쉽게 관리하고 둘러볼 수 있게 해 줘요. 스냅샷에 대여 카테고리를 포함하면 대여 재고를 정리해 둔 구조를 여러 지점에서 그대로 유지할 수 있어요.

카테고리는 대여 항목 종류가 여러 가지일 때 유용해요. 예를 들어 차량 대여 비즈니스라면 승용차, 트럭, SUV, 특수 차량으로 리스팅을 나눌 수 있어요. 부동산 대여 비즈니스라면 캐빈, 아파트, 이벤트 공간, 객실로 나눌 수 있어요.

```
스냅샷에서 대여 카테고리를 쓰면 좋은 경우:

기존 대여 구성 구조를 다른 서브 계정에 복사하고 싶을 때

여러 지점에서 카테고리 이름을 일관되게 유지하고 싶을 때

에이전시나 프랜차이즈용 대여 템플릿을 만들어 재사용하고 싶을 때

정리 구조만 필요해서 리스팅과 따로 카테고리만 불러오고 싶을 때
```

## 대여 리스팅과 카테고리를 스냅샷으로 복사하는 방법

재사용하려는 대여 설정이 이미 들어 있는 원본 서브 계정에서 시작해요. 원본 설정이 깔끔할수록 대상 서브 계정에 올바른 대여 자산이 복사돼요.

1. 하이퍼클래스에서 **Agency View**(에이전시 화면)로 이동한 다음 **계정 스냅샷**으로 가요.

   ![계정 스냅샷 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071919934/original/229XO42iooYo3zAAjqvlqDkEjsoEauH29A.png?1779373617)
2. 대여 리스팅이나 대여 카테고리가 들어 있는 원본 서브 계정에서 새 스냅샷을 만들어요.

   ![원본 서브 계정에서 새 스냅샷 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071920279/original/bKW935md-17OX0o3RvsTNhVkazddBGYegQ.png?1779373847)
3. 자산 선택 단계에서 **Rental Listings**(대여 리스팅), **Rental Categories**(대여 카테고리) 중 하나 또는 둘 다 선택해요.

   ![자산 선택 단계에서 대여 리스팅과 대여 카테고리 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071920121/original/-XeL1JG9Ynd-xB7LxqYI8EzRx2CRcIkWQQ.png?1779373739)
4. 스냅샷을 저장해요.
5. 스냅샷을 다른 지점이나 대상 서브 계정에 불러와요.
6. 불러오는 과정에서 복사하려는 대여 자산이 선택되어 있는지 확인해요.
7. 스냅샷 불러오기를 마쳐요.
8. 대상 서브 계정을 열어 복사된 대여 리스팅과 카테고리를 확인해요.

{% hint style="info" %}
기존 서브 계정에 스냅샷을 불러올 때는 충돌 확인이나 자산 확인 화면이 나오면 내용을 살펴본 다음 진행하세요. 하이퍼클래스의 스냅샷 불러오기 과정에는 기존 서브 계정을 위한 자산 선택과 충돌 검토 안내가 포함되어 있어요.
{% endhint %}

## 자주 묻는 질문

### 대여 리스팅과 대여 카테고리를 따로 복사할 수 있나요?
네. 스냅샷을 만들거나 복원할 때 대여 리스팅과 대여 카테고리를 각각 따로 선택할 수 있어요.

### 대여 리스팅과 대여 카테고리를 꼭 같이 복사해야 하나요?
아니요. 둘 중 하나만 골라도 되고, 대여 설정을 더 완전하게 복제하고 싶다면 둘 다 선택해도 돼요.

### 여러 대여 고객을 온보딩하는 에이전시에 도움이 되나요?
네. 재사용할 대여 설정을 갖춘 원본 서브 계정을 만들고 스냅샷을 만든 다음, 선택한 대여 자산을 다른 서브 계정에 불러올 수 있어요.

### 여러 지점을 운영하는 대여 비즈니스에도 쓸 수 있나요?
네. 여러 지점을 운영하는 비즈니스는 스냅샷으로 지점마다 대여 리스팅과 카테고리를 일관되게 유지할 수 있어요.

### 대여 리스팅과 카테고리에 연결된 워크플로우, 폼, 캘린더, 결제 설정도 같이 복사되나요?
이번 업데이트에서 지원하는 대여 자산은 대여 리스팅과 대여 카테고리예요. 관련 자산이 필요하면 스냅샷 작업에서 선택할 수 있는 경우에 한해 따로 선택해 주세요.

### 예전에 만든 스냅샷으로도 대여 리스팅과 카테고리를 복사할 수 있나요?
대여 리스팅과 카테고리를 포함하려면, 해당 대여 자산이 있고 선택된 원본 서브 계정에서 스냅샷을 새로 만들거나 갱신해야 해요.

### 스냅샷을 불러온 뒤 복사된 대여 자산은 어디에서 확인하나요?
대상 서브 계정을 열고 **대여** 메뉴로 이동하면 복사된 대여 리스팅과 카테고리를 확인할 수 있어요.
