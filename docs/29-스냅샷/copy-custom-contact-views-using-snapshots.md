# 스냅샷으로 커스텀 연락처 상세 보기 복사하기

스냅샷에 커스텀 연락처 상세 보기를 담아 여러 서브 계정에 똑같이 적용하는 방법을 안내해요. 에이전시 관리자가 쓰는 기능이에요.

연락처 상세 페이지 보기를 직접 만들어 두면 업무 방식, 역할, 우선순위에 맞게 연락처 정보를 정리할 수 있어요. 이 보기를 스냅샷에 포함하면 서브 계정마다 다시 설정하지 않아도 돼요. 설정 시간이 줄고, 고객사 계정마다 연락처 레이아웃을 일관되게 유지할 수 있어요.

## 스냅샷으로 커스텀 연락처 보기를 복사한다는 건 무슨 뜻인가요?

커스텀 연락처 상세 페이지 보기에서는 서브 계정 안의 연락처 정보가 어떻게 보일지 정할 수 있어요. 레이아웃 구조, 패널, 필드, 모듈, 공개 설정이 모두 포함돼요. 스냅샷을 쓰면 한 서브 계정의 커스텀 보기를 **계정 스냅샷**으로 가져와 다른 서브 계정에서 다시 쓸 수 있어요.

서브 계정마다 같은 연락처 상세 페이지 보기를 직접 다시 만들 필요가 없어요. 스냅샷을 만들거나 업데이트하면서 담을 커스텀 보기를 선택하고, 연결된 서브 계정으로 푸시하면 돼요.

## 이럴 때 좋아요

여러 서브 계정에 같은 연락처 레이아웃을 맞추면서 수작업을 줄일 수 있어요. 여러 고객사 계정이 영업, 지원, 관리, 운영용 연락처 레이아웃을 똑같이 써야 할 때 특히 유용해요.

- 수작업 설정 감소: 커스텀 연락처 보기를 한 번 만들어 두면 여러 서브 계정에서 다시 만들지 않고 재사용할 수 있어요.
- 일관된 연락처 레이아웃: 계정이 달라도 팀이 연락처 정보를 같은 방식으로 보고 관리할 수 있어요.
- 더 빠른 서브 계정 설정: 스냅샷 기반으로 계정을 설정할 때 커스텀 보기도 함께 넣을 수 있어요.
- 확장하기 쉬운 맞춤 설정: 역할별, 업무 방식별 연락처 레이아웃을 여러 고객사 계정에 유지할 수 있어요.
- 관리자 업무 효율 향상: 에이전시 관리자가 연락처 페이지 설정을 하나의 원본 계정에서 관리할 수 있어요.

## 꼭 알아야 할 조건과 제한

복사하려는 커스텀 연락처 상세 페이지 보기가 이미 들어 있는 서브 계정을 원본으로 써야 해요. 스냅샷을 만들기 전에 보기 개수 제한과 권한을 확인하면 결과가 빠지거나 예상과 달라지는 일을 줄일 수 있어요.

```
서브 계정마다 기본 연락처 상세 보기가 1개 있어요.

관리자는 커스텀 연락처 상세 보기를 최대 4개까지 추가로 만들거나 가져올 수 있어요. 서브 계정당 보기는 모두 5개예요.

커스텀 연락처 상세 페이지 보기는 원본 서브 계정에 먼저 있어야 스냅샷에 추가할 수 있어요.
```

## 가져온 보기와 기본 보기

가져온 연락처 상세 보기는 대상 서브 계정에 커스텀 레이아웃으로 추가돼요. 기본으로 들어 있는 보기를 대체하지는 않아요. 서브 계정마다 자체 기본 연락처 상세 보기를 유지하기 때문에, 항상 기본 연락처 레이아웃을 쓸 수 있어요.

연락처 상세 보기는 퍼널이나 워크플로우 같은 다른 자산과 다르게 동작해요. 스냅샷은 레이아웃과 필드 구성을 가져오지만, 원본 서브 계정에서의 기본 보기 상태는 가져오지 않아요. 원본 서브 계정에서 기본이던 보기도 대상 서브 계정에는 커스텀 보기로 들어가요.

**Override**(덮어쓰기)를 선택해도 가져온 보기가 기본 보기가 되지는 않아요. **Override**는 충돌하는 가져온 설정을 어떻게 처리할지에만 영향을 줘요. 대상 서브 계정이 어떤 연락처 상세 보기를 기본으로 보는지는 바꾸지 않아요.

배포한 뒤에는 대상 서브 계정에서 **Contact Detail Views**(연락처 상세 보기)를 열고, 가져온 레이아웃을 사용할 사용자나 그룹에 지정하세요. 그러면 지정된 사람들이 연락처 정보를 볼 때 이 레이아웃이 보여요.

## 커스텀 필드와 가져온 연락처 보기

가져온 연락처 상세 보기는 대상 서브 계정에 있는 필드를 기준으로 동작해요. 원본 보기에서 쓰던 필드가 대상 서브 계정에 없으면, 하이퍼클래스는 가져오기를 막지 않고 매핑할 때 그 필드를 건너뛰어요.

그래서 대상 서브 계정이 원본과 완전히 같지 않아도 보기를 가져올 수 있어요. 가져온 뒤에는 복사된 레이아웃을 열어 필요한 필드가 모두 보이는지 확인하세요. 빠진 필드가 있으면 대상 서브 계정에서 필요한 커스텀 필드를 만들거나 매핑한 다음, 보기를 필요에 맞게 업데이트하세요.

## 스냅샷에 커스텀 연락처 보기 설정하기

아래 순서대로 설정하면 원본 서브 계정의 커스텀 보기가 스냅샷에 담기고, 대상 서브 계정에서 쓸 수 있어요. 에이전시 보기에서 스냅샷을 만들고, 보기를 선택하고, 업데이트를 푸시해요.

### 1단계: 계정 스냅샷으로 이동하기

1. **에이전시 보기로 전환**을 클릭해요.
2. **계정 스냅샷**을 클릭해요.
3. **새 스냅샷 생성**을 클릭해요.

![계정 스냅샷 화면에서 새 스냅샷 생성 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070782429/original/ZYMoX2O9SclymNrjAsXfUAi5Gdg_SS_XwQ.png?1778148831)

### 2단계: 스냅샷 이름 정하고 원본 서브 계정 선택하기

1. 알아보기 쉬운 스냅샷 이름을 입력해요.

   - 예: "영업용 연락처 보기 템플릿"
   - 예: "고객사 연락처 상세 레이아웃"
2. 복사할 커스텀 연락처 상세 페이지 보기가 들어 있는 서브 계정을 선택해요.

![스냅샷 이름 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070782488/original/guWR7hQK2cJQfDBiVNMzXy7fQjXXPVStrw.png?1778148891)

![원본 서브 계정 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070782563/original/McuHk2k80xy6gG0OYVQZnqX6rsXR9byIsg.png?1778148948)

### 3단계: 연락처 상세 보기 선택하기

1. 자산 선택 화면에서 **Contact Detail Views**를 찾아요.
2. 카테고리를 펼쳐 사용할 수 있는 커스텀 보기를 확인해요.
3. 스냅샷에 포함할 커스텀 보기를 선택해요.
4. **만들기**를 클릭해요.

![연락처 상세 보기 자산 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070782676/original/QU3RKvNEtO73_xL1pKBX2PntrbcFw7H7Yg.png?1778149015)

### 4단계: 연결된 서브 계정에 스냅샷 업데이트 푸시하기

1. 선택한 연락처 상세 보기가 들어 있는 스냅샷을 열어요.
2. 업데이트를 푸시하는 옵션을 선택해요.
3. 커스텀 보기를 받을 연결된 서브 계정을 하나 이상 선택해요.
4. 업데이트를 확인해요.

![연결된 서브 계정에 스냅샷 업데이트를 푸시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070783044/original/_dSgoaT2jtTMZ0TUuEIj5KyI3-rhBkXPxQ.gif?1778149258)

### 5단계: 대상 서브 계정에서 커스텀 보기 확인하기

1. 대상 서브 계정을 열어요.
2. **연락처**로 이동해요.
3. 연락처 상세 페이지를 설정하는 화면을 열어요.
4. 복사한 커스텀 보기가 있는지 확인해요.
5. 필드, 패널, 모듈, 보기 구조가 예상대로 나오는지 레이아웃을 살펴봐요.

## 자주 묻는 질문

### 커스텀 연락처 상세 페이지 보기를 다른 서브 계정으로 복사할 수 있나요?
네. 커스텀 연락처 상세 페이지 보기를 스냅샷에 포함하면 여러 서브 계정에서 다시 쓸 수 있어요.

### 서브 계정마다 커스텀 보기를 직접 다시 만들어야 하나요?
아니요. 원본 서브 계정에 보기가 있으면 스냅샷에 포함해서 연결된 서브 계정으로 푸시하면 돼요.

### 서브 계정 하나에 연락처 상세 보기를 몇 개까지 만들 수 있나요?
서브 계정마다 기본 연락처 상세 보기가 1개 있어요. 직접 만들거나 스냅샷으로 가져온 커스텀 보기를 최대 4개까지 추가할 수 있어서, 모두 5개예요.

### 가져온 보기가 대상 서브 계정의 기본 연락처 상세 보기가 되나요?
아니요. 원본 서브 계정에서 기본이던 보기도 가져온 뒤에는 대상 서브 계정의 기본 보기가 되지 않아요. 커스텀 보기로 가져와요.

### 커스텀 보기를 가져올 때 사용자도 같이 복사되나요?
아니요. 가져온 연락처 상세 보기에는 사용자가 함께 복사되지 않아요. 배포한 뒤 대상 서브 계정에서 가져온 보기를 사용할 사용자나 그룹에 지정하세요.

### 원본 보기에서 쓰던 커스텀 필드가 대상 서브 계정에 없으면 어떻게 되나요?
가져오기가 막히지는 않아요. 대상 서브 계정에 없는 필드는 매핑할 때 건너뛰어요. 가져온 뒤에 보기를 열어 필요한 필드가 제대로 나오는지 확인하세요.

### 복사한 보기가 예상대로 보이지 않으면 무엇을 확인하나요?
다음 내용을 확인해 보세요.
- **Contact Detail Views**에서 해당 보기를 선택했는지
- 스냅샷 업데이트를 올바른 서브 계정에 푸시했는지
- 가져온 보기에 사용자나 그룹을 지정했는지
- 필요한 커스텀 필드가 대상 서브 계정에 있는지
