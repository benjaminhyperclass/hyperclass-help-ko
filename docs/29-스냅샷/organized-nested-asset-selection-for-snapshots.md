# 스냅샷 에셋을 폴더 구조로 선택하기

스냅샷에 담을 에셋을 폴더 구조 그대로 펼쳐 보면서 고르는 기능이에요. **스냅샷 만들기**, **스냅샷 새로고침**, **Load Snapshot**(스냅샷 불러오기) 화면에서 쓸 수 있어요. 에이전시 관리자만 쓸 수 있어요.

기존에는 에셋이 하나의 평평한 목록으로 보였어요. 이제는 원본 서브 계정에서 쓰던 폴더 구조와 같은 모습으로 폴더와 에셋이 나와요. 스냅샷을 만들거나 새로고침하거나 불러올 때 관련 에셋을 빠뜨릴 가능성이 줄어들어요.

새 선택 화면은 **스냅샷 만들기**, **스냅샷 새로고침**, **Load Snapshot** 화면에 적용돼요. 스냅샷을 쓰면 다음과 같은 일을 할 수 있어요.

- 서브 계정 사이에서 재사용할 계정 설정을 복사해요.
- 재사용할 스냅샷 템플릿을 만들어요.
- 업데이트된 에셋을 새로고침해요.
- 선택한 에셋을 기존 서브 계정에 불러와요.

## 폴더 구조로 에셋 선택이란?

폴더, 하위 폴더, 에셋을 펼치고 접을 수 있는 계층 구조로 보여 주는 스냅샷 에셋 선택 화면이에요. 에셋을 스냅샷 작업에 넣기 전에 각 에셋이 어느 폴더에 속하는지 먼저 확인할 수 있어요. 폴더가 원래 구조대로 보이면 관련 에셋을 함께 묶어 두기 쉽고, 일부만 빠진 채로 선택하는 일도 줄어요.

이제 스냅샷 에셋은 평평한 목록에 흩어져 있지 않고 상위 폴더 아래에 모여 있어요. 폴더를 한 단계씩 펼쳐 볼 수 있어요. 폴더 전체를 선택하거나, 중첩된 폴더 안의 에셋을 하나씩 고를 수도 있어요.

![폴더 구조로 표시된 스냅샷 에셋 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072594001/original/krFWfS6jXR0jgy2pQLK5f-yfC3hczZiscw.png?1780310133)

## 폴더 구조로 에셋을 선택하면 좋은 점

폴더 기반 선택 화면에서는 스냅샷 에셋을 더 잘 보고 더 세밀하게 고를 수 있어요. 워크플로우, 폴더, 템플릿 등 에셋이 많고 함께 묶어 두어야 하는 서브 계정을 관리할 때 특히 도움이 돼요.

- 빠른 선택: 에셋을 하나씩 고르지 않고 폴더와 그 안의 내용을 한 번에 선택해요.
- 깔끔한 에셋 확인: 상위 폴더 구조대로 에셋이 보여서 항목이 어떻게 정리되어 있는지 바로 알 수 있어요.
- 정확도 향상: 스냅샷을 만들거나 새로고침하거나 불러올 때 중요한 에셋을 빠뜨릴 위험이 줄어요.
- 폴더 확인 용이: 여러 단계로 중첩된 폴더도 한 단계씩 펼쳐서 에셋을 살펴볼 수 있어요.
- 안심하고 작업: 스냅샷 작업을 준비할 때 관련 에셋과 하위 폴더를 함께 유지할 수 있어요.
- 수동 관리 감소: 어떤 에셋이 어느 폴더에 있는지 기억하려고 외부 스프레드시트나 메모를 쓰지 않아도 돼요.

## 폴더 구조 선택 화면이 나오는 곳

사용자가 스냅샷에 포함하거나 불러올 에셋을 고르는 주요 스냅샷 작업에서 이 선택 화면이 나와요. 새 스냅샷을 만들 때, 기존 스냅샷을 업데이트할 때, 스냅샷의 에셋을 서브 계정에 불러올 때 모두 같은 방식으로 선택할 수 있어요.

새 에셋 선택 화면이 적용되는 곳은 다음과 같아요.

- **스냅샷 만들기**: 새 스냅샷을 만들 때 원본 서브 계정에서 에셋을 선택해요.
- **스냅샷 새로고침**: 원본 서브 계정의 최신 변경 사항으로 기존 스냅샷을 업데이트할 에셋을 선택해요.
- **Load Snapshot**(스냅샷 불러오기): 스냅샷의 에셋 중 대상 서브 계정에 불러올 에셋을 선택해요.

스냅샷을 만들면 재사용할 서브 계정 설정을 복제할 수 있고, 새로고침하면 최신 에셋을 가져와요. 스냅샷을 불러올 때는 에셋을 선택하고 충돌을 해결한 뒤 기존 서브 계정에 적용해요.

## 폴더 구조는 어떻게 동작하나요?

에셋이 원래 폴더 아래에 묶여 있어서, 작업하기 전에 에셋끼리의 관계를 이해하기 쉬워요. 폴더 안에 에셋이 많거나 폴더가 여러 단계로 중첩되어 있을 때 유용해요.

폴더 구조 화면에서는 다음을 지원해요.

- 상위 폴더
- 하위 폴더
- 여러 단계로 중첩된 폴더
- 폴더 안의 개별 에셋
- 펼치기·접기 컨트롤
- 에셋 검색
- 상품 카테고리 레이블(해당하는 경우)

상위 폴더를 선택하면 그 안의 에셋과 하위 폴더가 함께 선택돼요. 폴더를 펼치면 그 항목이 어디에 속하는지 보면서 개별 항목을 확인하거나 선택할 수 있어요.

## 스마트 폴더 선택

스냅샷 작업에서 에셋을 선택할 때 관련 에셋이 함께 선택되도록 돕는 기능이에요. 폴더만 선택하고 그 안의 에셋은 빠뜨리는 일이 줄어들어요.

폴더를 선택하면 다음과 같이 돼요.

- 폴더 안의 에셋이 선택돼요.
- 폴더 안의 하위 폴더가 선택돼요.
- 중첩된 하위 폴더 안의 에셋도 포함돼요.
- 폴더를 펼쳐서 선택된 내용을 확인할 수 있어요.

특정 에셋만 필요하면 폴더를 펼친 뒤 포함할 항목만 하나씩 선택하세요.

## 중첩된 에셋 검색하기

에셋이 많은 스냅샷 목록에서 원하는 에셋이나 폴더를 빠르게 찾을 수 있어요. 서브 계정에 에셋이 수백, 수천 개 있으면 폴더를 하나씩 펼치는 데 시간이 너무 오래 걸리는데, 이때 검색이 도움이 돼요.

에셋 선택 화면 맨 위의 검색창에 에셋 이름을 입력해 찾으세요. 에셋을 찾았다면 선택하기 전에 어느 폴더에 있는지 확인하세요. 올바른 폴더 경로에서 올바른 에셋을 고르고 있는지 확인할 수 있어요.

## 스냅샷 만들기에서 폴더 구조로 선택하기

스냅샷을 만들 때는 먼저 원본 서브 계정의 에셋 중 포함할 항목을 골라요. 폴더 구조 선택 화면은 평평한 목록 대신 폴더와 에셋을 구조적으로 보여 줘서 이 과정을 쉽게 해 줘요.

스냅샷을 만들면서 폴더 구조로 에셋을 선택하는 방법은 다음과 같아요.

1. **스냅샷 만들기** 화면으로 이동하세요.
2. 원본 서브 계정을 선택하세요.
3. 에셋 선택 화면을 여세요.
4. 폴더를 펼쳐 안에 있는 에셋을 확인하세요.
5. 폴더, 하위 폴더, 그 안의 에셋을 모두 포함하려면 폴더 전체를 선택하세요.
6. 특정 항목만 필요하면 개별 에셋을 선택하세요.
7. 스냅샷 만들기를 계속 진행하세요.

![스냅샷 만들기에서 폴더를 펼쳐 에셋을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072595027/original/8MjTKP0fcdGMJxPRbEr9afcy7pnSguPo2w.png?1780310705)

## 스냅샷 새로고침에서 폴더 구조로 선택하기

스냅샷을 새로고침하면 원본 서브 계정의 변경 사항이 스냅샷에 반영돼요. 관련 에셋이 폴더 아래에 묶여 있어서 업데이트할 에셋을 더 정확하게 고를 수 있어요.

스냅샷을 새로고침하면서 폴더 구조로 에셋을 선택하는 방법은 다음과 같아요.

1. **스냅샷 새로고침** 화면으로 이동하세요.
2. 새로고침할 스냅샷의 에셋 선택 화면을 여세요.
3. 해당하는 상품 카테고리나 폴더를 펼치세요.
4. 폴더 안의 에셋을 모두 새로고침해야 하면 폴더를 선택하세요.
5. 특정 업데이트만 필요하면 개별 에셋을 선택하세요.
6. 새로고침하기 전에 선택한 에셋을 확인하세요.
7. **새로고침**을 클릭하세요.

![스냅샷 새로고침에서 에셋을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072595572/original/bvIr-haXYs1yoESmb8mHBNockXLczT3znQ.png?1780311022)

## Load Snapshot에서 폴더 구조로 선택하기

스냅샷을 불러오면 선택한 스냅샷 에셋을 기존 서브 계정에 적용할 수 있어요. 진행하기 전에 폴더 구조를 확인할 수 있어서, 특히 충돌 확인 전에 도움이 돼요.

스냅샷을 불러오면서 폴더 구조로 에셋을 선택하는 방법은 다음과 같아요.

1. 대상 서브 계정에서 **Load Snapshot** 화면을 여세요.
2. 사용할 수 있는 스냅샷 에셋을 확인하세요.
3. 폴더를 펼쳐 중첩된 에셋을 살펴보세요.
4. 불러올 폴더나 개별 에셋을 선택하세요.
5. 제한되었거나 사용할 수 없는 에셋이 보이면 내용을 확인하세요.
6. 해당하는 경우 충돌 확인 단계로 넘어가세요.
7. 스냅샷 불러오기를 계속 진행하세요.

{% hint style="info" %}
스냅샷, 계정 권한, 에셋의 동작 방식에 따라 일부 에셋은 제한되었거나 사용할 수 없는 것으로 표시될 수 있어요.
{% endhint %}

## 연결된 에셋과 폴더 선택

폴더 구조 선택은 에셋을 눈에 잘 띄게 묶어 주고 선택하기 쉽게 해 줄 뿐, 연결된 에셋 관리를 대신하지는 않아요. 어떤 에셋이 제대로 동작하려면 다른 에셋이 필요한 경우가 있어서, 연결된 에셋은 여전히 중요해요.

폴더 구조로는 에셋을 선택하고, 연결된 에셋 관리로는 선택한 에셋이 제대로 동작하는 데 필요한 의존 에셋이나 관련 에셋을 확인하세요. 연결된 에셋 관리와 선택적 스냅샷 만들기에 대한 안내는 하이퍼클래스 스냅샷 문서에 따로 있어요.

## 폴더 구조 선택 사용하기

폴더 구조 선택은 지원되는 스냅샷 작업 안에 기본으로 들어 있어요. 따로 설정할 필요가 없어요. 스냅샷 만들기, 새로고침, 불러오기에서 에셋 선택 화면을 열면 폴더 기반 화면이 자동으로 나와요.

새 선택 화면을 사용하는 방법은 다음과 같아요.

1. **에이전시 보기**로 이동하세요.
2. 사용할 스냅샷 작업을 여세요.

   - **스냅샷 만들기**
   - **스냅샷 새로고침**
   - **Load Snapshot**
3. 에셋 선택 화면을 여세요.
4. 폴더 옆 화살표를 눌러 펼치세요.
5. 안에 있는 에셋과 하위 폴더를 확인하세요.
6. 폴더 안의 에셋을 모두 포함하려면 상위 폴더를 선택하세요.
7. 특정 항목만 필요하면 개별 에셋을 선택하세요.
8. 스냅샷 작업을 계속 진행하세요.

## 자주 묻는 질문

### 폴더를 선택하면 그 안의 모든 항목이 선택되나요?
네. 폴더를 선택하면 그 폴더 안의 에셋과 하위 폴더가 함께 선택돼요.

### 개별 에셋만 선택할 수도 있나요?
네. 폴더를 펼친 뒤 포함할 에셋만 선택하세요.

### 이 업데이트로 스냅샷 동작 방식이 바뀌나요?
아니요. 에셋을 선택하는 화면이 개선된 거예요. 스냅샷 만들기, 새로고침, 불러오기는 기존과 같은 순서로 진행돼요.

### 스냅샷을 새로고침할 때도 폴더 구조 선택 화면을 쓸 수 있나요?
네. **스냅샷 새로고침**에도 적용돼요.

### 스냅샷을 불러올 때도 폴더 구조 선택 화면을 쓸 수 있나요?
네. **Load Snapshot**에도 적용되고, 계속 진행하기 전에 선택한 에셋을 확인하는 데 도움이 돼요.

### 에셋이 제한됨으로 표시되면 어떻게 해야 하나요?
해당 에셋을 확인하고, 지금 진행 중인 작업에서 선택하거나 불러올 수 있는지 살펴보세요. 제한된 에셋이 어떻게 동작하는지는 에셋 유형, 계정 권한, 스냅샷 구성에 따라 달라질 수 있어요.

### 폴더를 선택하면 연결된 에셋을 따로 확인하지 않아도 되나요?
아니요. 폴더 선택은 구조를 기준으로 에셋을 고르는 데 도움이 되고, 연결된 에셋 확인은 관련된 의존 에셋을 확인하는 데 도움이 돼요.

### 여러 단계로 중첩된 폴더도 펼칠 수 있나요?
네. 여러 단계의 폴더를 한 단계씩 펼쳐서 각 폴더 안의 에셋을 확인할 수 있어요.
