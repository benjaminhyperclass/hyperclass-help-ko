# 공유된 스냅샷 요약 — 일일 가져오기 활동 확인

공유된 스냅샷 요약을 쓰면 에이전시가 공유한 스냅샷이 하이퍼클래스에서 어떻게 가져오기되고 있는지 매일 확인할 수 있어요. 인앱 알림과 이메일 요약으로 어떤 스냅샷이 얼마나 자주, 어디에서 가져오기되는지 볼 수 있어서 스냅샷을 하나씩 열어 보지 않아도 돼요.

## 공유된 스냅샷 요약이란?

공유된 스냅샷 요약은 선택한 공유된 스냅샷의 가져오기 활동을 하루 단위로 보여 줘요. 스냅샷이 쓰이고 있는지 짐작할 필요 없이, 간단한 인앱 알림과 더 자세한 이메일 요약으로 가져오기 활동을 확인할 수 있어요.

## 주요 장점

스냅샷을 배포한 뒤 실제로 어떻게 쓰이는지 알 수 있어요. 고객, 파트너, 제휴 대상, 내부 팀에 스냅샷을 공유하면서 사용 현황을 간단히 확인하고 싶은 팀에 특히 도움이 돼요.

- 한곳에서 확인: 선택한 공유된 스냅샷의 일일 가져오기 활동을 한곳에서 볼 수 있어요.
- 사용 여부 파악: 공유한 뒤에 스냅샷이 실제로 쓰이는지 알 수 있어요.
- 스냅샷 관리 개선: 어떤 스냅샷이 활발하게 쓰이고, 유용하며, 자주 가져오기되는지 알 수 있어요.
- 간편한 모니터링: 매일 인앱 알림과 이메일 요약으로 가져오기 소식을 받아요.
- 필요한 것만 보기: 일일 요약에 포함할 공유된 스냅샷을 직접 고를 수 있어요.

## 공유된 스냅샷 알림 설정

알림 설정에서 어떤 공유된 스냅샷을 일일 요약에 넣을지 정해요. 모든 공유된 스냅샷의 활동을 받는 대신, 중요한 스냅샷만 골라서 볼 수 있어요. 공유된 스냅샷을 일일 요약에 넣으려면 해당 스냅샷의 설정 화면에서 **Include in daily summary**(일일 요약에 포함) 설정을 켜세요.

```
일일 요약에는 Include in daily summary 설정을 켠 공유된 스냅샷만 포함돼요.

팀에서 확인하고 싶은 내용에 맞게 포함할 공유된 스냅샷을 고를 수 있어요.

이 설정을 쓰면 불필요한 활동 정보 없이 핵심 스냅샷만 확인할 수 있어요.
```

## 인앱 알림 요약

인앱 알림은 하이퍼클래스 안에서 공유된 스냅샷의 일일 가져오기 활동을 빠르게 보여 줘요. 자세한 리포트를 열거나 이메일을 확인하지 않고 활동을 훑어보고 싶을 때 좋아요.

인앱 알림은 한눈에 확인하는 용도예요. 선택한 공유된 스냅샷에 가져오기 활동이 있었는지 확인할 수 있고, 팀이 일하면서 간단히 소식을 챙길 수 있어요.

## 공유된 스냅샷 가져오기 활동 이메일 요약

이메일 요약은 포함된 공유된 스냅샷별 가져오기 활동을 하루 단위로 더 자세히 정리해 줘요. 스냅샷 사용 기록을 검토하거나 내부에 공유하고, 시간이 지나면서 사용 추이를 살펴보는 데 쓸 수 있어요.

인앱 알림보다 더 많은 정보가 필요한 에이전시 대표, 운영팀, 스냅샷 관리자에게 도움이 돼요.

이메일 요약은 이럴 때 쓰세요.

- 포함된 공유된 스냅샷별 가져오기 활동 검토
- 가장 자주 쓰이는 스냅샷 확인
- 공유된 스냅샷 사용 내역을 매일 기록으로 보관
- 스냅샷 가져오기가 어디에서 이뤄지는지 파악

## 공유된 스냅샷 요약 설정하기

모니터링하려는 공유된 스냅샷만 일일 요약에 들어가도록 설정하세요. 이 기능은 먼저 **실험실**에서 켜야 하고, 그다음 공유된 스냅샷마다 설정에서 하나씩 포함해야 해요.

### 1단계: 공유된 스냅샷의 일일 요약 켜기

1. **스냅샷**으로 이동하세요.
2. **공유된 스냅샷**을 여세요.

   ![공유된 스냅샷 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071258352/original/2GK61TwyRKfh9OJItRBliPazdOi6vLACmQ.png?1778687626)
3. 모니터링할 공유된 스냅샷을 선택하세요.
4. 스냅샷의 **설정**을 여세요.

   ![스냅샷 설정 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071258495/original/y742E2R_URd6t6P0SUJIpXA9nPGza3J8XQ.png?1778687711)
5. **Include in daily summary**(일일 요약에 포함)를 켜세요.

   ![일일 요약에 포함 설정 켜기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071258412/original/F1xYimbpXGOaGwWLuJHAkLpFRvIt118UUg.png?1778687668)

### 2단계: 일일 활동 확인하기

설정을 켜면 하이퍼클래스가 매일 아래 두 가지로 활동을 알려 줘요.

- 인앱 알림: 공유된 스냅샷의 가져오기 활동을 간단히 요약해 줘요.
- 이메일 요약: 포함된 공유된 스냅샷별 가져오기 활동을 자세히 정리해 줘요.

## 자주 묻는 질문

### 모든 공유된 스냅샷이 일일 요약에 자동으로 들어가나요?
아니요. 공유된 스냅샷 설정에서 **Include in daily summary**(일일 요약에 포함)를 켠 스냅샷만 포함돼요.

### 인앱 알림과 이메일 요약은 뭐가 다른가요?
인앱 알림은 하이퍼클래스 안에서 하루 활동을 간단히 요약해 줘요. 이메일 요약은 포함된 공유된 스냅샷의 가져오기 활동을 하루 단위로 더 자세히 보여 줘요.

### 특정 공유된 스냅샷의 일일 요약을 나중에 끌 수 있나요?
네. 해당 공유된 스냅샷의 설정으로 돌아가 **Include in daily summary**(일일 요약에 포함)를 끄세요.

### 공유된 스냅샷 요약은 모든 사용자가 쓸 수 있나요?
릴리스 노트에 따르면 공유된 스냅샷 요약은 5월 2일부터 모든 사용자에게 **실험실**에서 제공돼요.

### 이 기능이 스냅샷 가져오기를 대신하나요?
아니요. 이 기능은 공유된 스냅샷의 가져오기 활동을 확인하는 용도예요. 스냅샷은 기존 스냅샷 작업 방식 그대로 가져오기하거나 불러와야 해요. 하이퍼클래스에는 스냅샷 가져오기와 기존 서브 계정으로 스냅샷 불러오기에 대한 별도 도움말이 있어요.

### 모든 공유된 스냅샷에 이 기능을 켜야 하나요?
가져오기 현황을 확인해야 하는 공유된 스냅샷에만 켜세요. 예를 들어 고객 온보딩용 스냅샷, 파트너용 스냅샷, 진행 중인 캠페인에 쓰는 스냅샷이 있어요.
