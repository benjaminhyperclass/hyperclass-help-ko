# 레스토랑용 하이퍼클래스 시작하기

레스토랑용 하이퍼클래스는 메뉴, 예약, 매장 식사(홀 서비스), 온라인 주문을 한 화면에서 관리하는 업종 전용 작업 공간이에요. 에이전시는 처음부터 직접 만들지 않아도 레스토랑에 맞는 서브 계정을 만들 수 있어요. 이 문서에서는 주요 기능과 설정 순서를 안내해요.

## 레스토랑용 하이퍼클래스란?

레스토랑용 하이퍼클래스는 식당의 일상 운영을 돕는 업종 전용 작업 공간이에요. 손님 정보는 하이퍼클래스 CRM과 계속 연결돼요. 에이전시 관리자는 서브 계정을 만들 때 **식당** 업종을 선택하면 아래 6개 모듈을 쓸 수 있어요.

| 모듈 | 용도 |
| --- | --- |
| **개요** | 운영 성과와 설정 진행 상황을 확인해요. |
| **메뉴** | 메뉴 항목, 가격, 판매 가능 여부를 관리해요. |
| **예약** | 예약, 테이블, 워크인(예약 없이 방문한 손님)을 관리해요. |
| **Restaurant Orders**(레스토랑 주문) | 매장 식사, 포장, 배달 주문을 추적해요. |
| **레스토랑 웹사이트** | 온라인 주문과 예약을 받아요. |
| **레스토랑 설정** | 영업시간, 결제, 배달, 알림을 설정해요. |

{% hint style="info" %}
레스토랑용 하이퍼클래스는 현재 비공개 베타에 참여 중인 에이전시에서만 사용할 수 있어요.
{% endhint %}

## 레스토랑용 하이퍼클래스의 장점

레스토랑 운영과 고객 관리를 연결해서, 매일 하는 일을 단순하게 하고 손님에게 일관된 경험을 드릴 수 있어요.

- 빠른 설정: **식당** 업종을 선택해서 레스토랑용 서브 계정을 바로 만들 수 있어요.
- 한곳에서 운영: 메뉴, 주문, 예약, 테이블을 한 작업 공간에서 관리해요.
- CRM 연결: 예약과 주문을 하이퍼클래스 연락처와 연결해서 후속 연락과 캠페인에 활용해요.
- 온라인 주문: 직접 꾸민 레스토랑 웹사이트에서 포장·배달 주문을 받아요.
- 비즈니스 인사이트: 매출, 주문, 예약, 인기 메뉴를 확인해요.
- 손님 커뮤니케이션: 지원되는 주문·예약 이벤트에 대해 이메일과 SMS 알림을 보내요.

## 레스토랑 주요 기능

### 개요

**개요** 대시보드에서 레스토랑 성과 지표와 설정 작업을 한눈에 볼 수 있어요. 사장님과 매니저는 영업 현황을 확인하고, 아직 끝내지 않은 설정 단계를 찾을 수 있어요.

### 메뉴

**메뉴**에서는 레스토랑이 지원하는 서비스 채널 전체에 적용할 메뉴를 하나로 만들고 관리해요. 메뉴를 한곳에서 관리하면 가격, 상품 정보, 판매 가능 여부를 정확하게 유지하기 쉬워요.

자세한 내용은 [레스토랑 메뉴 만들기](how-to-create-a-restaurant-menu-in-hyperclass.md)를 참고하세요.

### 예약

**예약**은 홀 직원이 예약, 테이블 현황, 워크인 손님을 관리할 때 쓰는 화면이에요. 시각적인 플로어 플랜으로 좌석 배치를 조율하고 손님 상황을 한눈에 볼 수 있어요.

**레스토랑 > 예약**으로 이동하세요.

세 가지 보기를 쓸 수 있어요.

- **Front of house**(홀): 테이블 상태, 도착하는 손님, 착석한 일행을 확인해요.
- **타임라인**: 시간대와 테이블별로 예약을 확인해요.
- **목록**: 예약을 검색하고, 필터링하고, 관리해요.

직원은 예약을 만들고, 워크인 손님을 안내하고, 테이블을 배정하고, 손님 정보를 확인할 수 있어요.

자세한 내용은 [레스토랑 예약: 예약, 테이블, 손님 관리](restaurant-reservations-manage-bookings-tables-and-guests.md)를 참고하세요.

### 매장 식사 서비스

매장 식사 서비스는 테이블 예약을 주방 주문과 결제에 연결해요. 직원은 손님의 예약에 여러 차례에 걸쳐 메뉴를 추가하고, 조리 진행 상황을 확인할 수 있어요.

매장 식사 주문은 이렇게 만들어요.

1. 착석 상태인 예약을 열고 **주문**을 선택하세요.
2. **Add round**(라운드 추가)를 클릭하세요.
3. 메뉴 항목을 선택하고 주방 메모를 입력하세요.
4. **Send to kitchen**(주방으로 보내기)을 클릭하세요.
5. 라운드의 진행 상황을 **수락됨 > 진행 중 > Ready to serve**(서빙 대기) **> Served**(서빙 완료) 순서로 확인하세요.

직원은 결제를 받고, 팁을 추가하고, 더치페이 계산서에 대해 수동 부분 결제를 기록할 수 있어요.

### 레스토랑 주문

**Restaurant Orders**(레스토랑 주문)는 매장 식사, 포장, 배달 주문을 한곳에서 관리하는 화면이에요. 직원은 주문 진행 상황을 추적하고, 확인이 필요한 주문을 찾을 수 있어요. **레스토랑 > Restaurant Orders**로 이동하세요.

주문은 다섯 개 탭으로 나뉘어요: **Active**(활성), **Scheduled**(예약됨), **Completed**(완료), **All**(전체), **Canceled**(취소됨).

이 밖에 이런 기능도 있어요.

- 새 온라인 주문이 들어오면 화면에서 울리는 알림
- 주문 수락과 상태 변경
- **Running late**(지연 중) 필터
- 주문 상세 정보와 결제 정보
- 매장 식사 주문의 주방 라운드 관리

자세한 내용은 [레스토랑 주문: 주문과 결제 관리](restaurant-orders-how-to-manage-orders-and-payments.md)를 참고하세요.

## 레스토랑용 하이퍼클래스 설정하기

손님이 이용하기 전에 메뉴, 주문, 예약, 결제를 미리 설정해 두는 과정이에요. 안내 체크리스트를 따라 하면 레스토랑을 매일 운영할 준비를 마칠 수 있어요.

1. 서브 계정을 만드세요. **서브 계정 > 서브 계정 만들기 > Start from an industry**(업종으로 시작) **> 식당**으로 이동해서 사업자 정보를 입력하고 서브 계정을 만들어요. 에이전시 관리자가 진행하는 단계예요.
2. 서브 계정 안에서 **레스토랑 > 개요**로 이동해 설정 체크리스트를 찾으세요.
3. 레스토랑 정보를 설정하세요. 레스토랑 이름, 브랜딩 로고, 색상을 추가해요.

   ![레스토랑 정보 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085047030/original/ncOgYWNS6g167wriVXfVKcTHjWQ3NVJtuQ.png?1793887147)
4. 결제를 연결하세요. **결제** 설정 작업을 열고 지원되는 결제 제공업체를 연결해요.

   ![결제 연결 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085047226/original/YNeACa7UjWPt81xWVWKRvyf2o2C285wYZw.png?1793887238)
5. 메뉴를 만드세요. 기존 메뉴를 가져오거나, 카테고리·항목·가격·옵션을 직접 추가해요.

   ![메뉴 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085047330/original/OO9e8U5w4exgG68CWjnktvLYU_9CfEF71w.png?1793887272)
6. 포장과 배달을 설정하세요. 준비 시간, 서비스 시간, 배달 지역, 적용되는 요금을 설정해요.

   ![포장 및 배달 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085047445/original/bE5Co9NB1ZQ5Ra_fsBhb9B5561-n-TEn_g.png?1793887314)
7. 테이블을 설정하세요. 플로어 레이아웃 편집기에서 식사 공간을 만들고, 테이블을 추가하고, 테이블별 수용 인원을 설정해요.

   ![테이블 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085047533/original/U7-qXxrVOU1Z4bxtX0u9ZT-oTIowUmDTJQ.png?1793887361)
8. 예약을 설정하세요. 예약 가능 시간, 예약 규칙, 예약 시간 길이, 필요하면 보증금을 설정해요.

   ![예약 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085047584/original/wVQbRkFivksU8coCS88anjHNDxHWF76yJA.png?1793887387)
9. 레스토랑 웹사이트를 게시하세요. 손님이 보는 페이지를 꾸미고, 결제 준비 상태를 확인하고, 필요하면 도메인을 연결한 뒤 게시해요.

{% hint style="warning" %}
설정 체크리스트를 모두 끝내도 웹사이트가 자동으로 게시되지는 않아요. 실제 결제를 받기 전에 필요에 따라 Checkout Live mode(결제 라이브 모드)도 설정해야 해요.
{% endhint %}

자세한 방법은 [레스토랑 설정 가이드: 주문과 예약 받을 준비하기](restaurant-setup-guide-get-ready-to-take-orders-and-reservations.md)를 참고하세요.

## 자주 묻는 질문

### 이미 있는 서브 계정에서 레스토랑 기능을 켤 수 있나요?
네. **No industry**(업종 없음)로 표시되는 기존 서브 계정 중 조건에 맞는 계정은, 에이전시의 **Features and Limits**(기능 및 한도) 설정에서 **식당**으로 지정할 수 있어요.

### 웹사이트를 게시하기 전에도 온라인 주문과 예약을 받을 수 있나요?
게시 전에도 직원은 일부 현장 운영 업무를 처리할 수 있어요. 하지만 손님이 온라인으로 주문하거나 예약하려면 레스토랑 웹사이트가 게시되어 있어야 해요.

### 포장과 배달 가격을 다르게 설정할 수 있나요?
네. 채널별 가격 인상분과, 해당하는 항목별 가격 조정을 설정할 수 있어요.

### 배달 대행 서비스 같은 외부 배달 서비스도 지원하나요?
아니요. 비공개 베타에서는 식당 직원이 직접 하는 배달만 지원해요. 배달 마켓플레이스나 배달 기사 서비스 연동은 지원하지 않아요.

### 레스토랑 손님도 하이퍼클래스 CRM에 추가되나요?
레스토랑 예약과 주문은 CRM 연락처와 연결돼요. 그래서 손님 정보를 활용해 연락하고 후속 응대를 할 수 있어요.
