# 에이전시 시스템 이메일 템플릿 바꾸기

에이전시 계정에서 웰컴, 비밀번호 재설정, 인증 이메일 템플릿을 브랜드에 맞게 바꾸는 방법을 안내해요. 시스템 이메일에 우리 브랜드의 로고와 버튼 색상을 넣고 싶을 때 보세요. 에이전시 관리자만 쓸 수 있어요.

브랜드 경험을 일관되게 유지할 수 있도록, 에이전시 계정에서 시스템 이메일 템플릿을 직접 바꾸는 기능이 있어요. 웰컴, 비밀번호 재설정, 인증 이메일을 브랜드 이미지에 맞게 꾸밀 수 있어요.

---

## 할 수 있는 일

- 템플릿 사용자 지정: 웰컴, 비밀번호 재설정, 인증 이메일의 문구를 브랜드 말투에 맞게 수정할 수 있어요.
- 로고와 CTA 색상 변경: 세 가지 이메일 템플릿 모두에서 로고를 바꾸고, CTA(콜투액션) 버튼 색상을 지정할 수 있어요.
- 간편한 접근과 관리: **에이전시 설정**에서 바로 이메일 템플릿을 관리할 수 있어요.

---

## 사용 방법

### 1단계: 시스템 이메일 설정 열기

1. 대시보드에서 **에이전시 설정**으로 이동해요.
2. **설정** 섹션 아래에서 **시스템 이메일**을 선택해요. 이곳에서 바꿀 수 있는 시스템 이메일 템플릿을 모두 볼 수 있어요.

   ![시스템 이메일 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040877282/original/or6WsiS6vwFHGWduGLD6nW8WWm9_zF6xog.png?1738563214)

### 2단계: 기존 템플릿 수정하기

1. 바꾸려는 이메일 템플릿을 찾아요. 예를 들면 **웰컴 이메일**, **Password Reset Email**(비밀번호 재설정 이메일), **인증 이메일**이 있어요.
2. 수정할 이메일 옆의 **템플릿 변경**을 클릭해요.
3. 변경 내용을 적용할 서브 계정을 선택해요.
4. **템플릿 경로**에서 템플릿이 저장된 폴더를 선택해요.
5. **템플릿 선택**에서 수정할 템플릿을 클릭한 다음, **변경**을 선택해 수정을 시작해요.

   ![템플릿 변경 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040877368/original/y2zAjg016h-LeVMx9S57nnu17CvCJ-IJgg.png?1738563300)

### 템플릿 검증과 자동 대체 발송

선택하거나 수정한 시스템 이메일 템플릿에 발송을 막는 오류가 있으면, 하이퍼클래스가 기본 시스템 템플릿으로 대신 이메일을 보내요.

이렇게 동작해요.

- 이메일은 그대로 발송돼요. 템플릿에 문제가 있어도 발송이 실패하지 않아요.
- 기본 시스템 템플릿은 선택한 템플릿에 발송을 막는 오류가 있을 때만 사용돼요.
- 이후 발송부터 수정한 내용이 다시 나가게 하려면, 선택한 템플릿의 오류를 고치세요.

{% hint style="info" %}
시스템 이메일에 브랜딩이나 병합 필드가 예상대로 나타나지 않으면, 선택한 템플릿에 잘못되었거나 지원하지 않는 필드가 있는지 확인해 보세요.
{% endhint %}

### 3단계: 새 템플릿 만들기 (선택 사항)

1. **이메일 마케팅 > 템플릿**으로 이동해요.
2. **새 템플릿 만들기**를 클릭하고 **이메일 마케팅 템플릿**을 선택한 다음, **system templates**(시스템 템플릿)를 클릭해요.
3. 목록에서 원하는 시스템 이메일을 찾아 **continue**(계속)를 클릭해요.

   ![시스템 이메일 템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040877350/original/9yyf0Uk4SQBu9WACcNFndcC3v_H0S_LtUA.png?1738563271)

4. 필요에 맞게 이메일을 디자인해요. 텍스트, 이미지, 브랜드 요소를 추가할 수 있어요.

### 4단계: 로고와 CTA 색상 바꾸기

1. 이메일 템플릿 편집기에서 **설정**을 클릭해요.
2. 브랜드 로고를 업로드하고, 콜투액션(CTA) 버튼 색상을 브랜드에 맞게 조정해요.
3. **변경사항 저장**을 클릭해 템플릿에 반영해요.

   ![로고와 CTA 버튼 색상 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040877378/original/O2BU_8rUCIrnEuclH4Qr44cx3iT5oLeXSg.png?1738563327)

## 자주 묻는 질문

### 변경한 내용이 마음에 들지 않으면 어떻게 되돌리나요?
템플릿 편집기로 돌아가서 이전 버전의 템플릿을 복원하거나, 수정한 내용을 직접 고치면 돼요.

### 이메일을 보내기 전에 변경 내용을 미리 볼 수 있나요?
네, 볼 수 있어요. 변경 내용을 적용하기 전에 테스트 이메일이나 이메일 빌더의 미리보기 기능으로 확인할 수 있어요.

### 직접 만든 템플릿에도 설정이 적용되나요?
빌더에서 제공하는 커스텀 값 옵션으로 로고나 버튼 색상을 넣었다면 설정이 적용돼요.

![커스텀 값으로 로고와 버튼 색상을 넣은 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040877490/original/pyVOC8mRh5Wf8gUKtfDNVKHGrFA9Ns1amQ.png?1738563440)
