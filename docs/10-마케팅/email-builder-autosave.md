# 이메일 빌더 자동 저장

**이메일 빌더**에서 이메일 템플릿과 캠페인을 편집하는 동안 작업 내용을 자동으로 저장해 주는 기능이에요. 자동 저장을 켜는 방법과 **버전 기록**으로 이전 상태를 되돌리는 방법을 안내해요.

자동 저장은 편집 중에 버전을 자동으로 남겨요. 실수로 에디터 바깥을 클릭하거나, 네트워크가 끊기거나, 페이지를 새로고침하거나, Mac의 왼쪽 스와이프 같은 이동 제스처를 써도 작업 내용을 지킬 수 있어요.

## 이메일 빌더 자동 저장이란?

하이퍼클래스에서 이메일 템플릿과 캠페인을 편집할 때, 변경할 때마다 직접 저장하지 않아도 편집 세션 중에 버전 스냅샷이 자동으로 만들어져요.

화면에 표시되는 자동 저장 표시에는 마지막으로 저장된 시각이 나와요. 표시 위로 마우스를 올리면 작업 내용이 정확히 언제 저장되었는지 볼 수 있어요. 필요하면 **버전 기록**에서 이전 상태로 되돌릴 수도 있어요.

## 주요 장점

- 자동 버전 관리 — 편집 세션 중의 모든 변경 사항이 직접 저장하지 않아도 버전으로 저장돼요.
- 데이터 손실 방지 — 실수로 새로고침하거나, 네트워크에 문제가 생기거나, 의도치 않게 다른 페이지로 이동해도 작업 내용을 지켜 줘요.
- 마지막 저장 시각 확인 — 자동 저장 표시 위로 마우스를 올리면 마지막으로 저장된 시각을 볼 수 있어요.
- 버전 기록 확인 — 템플릿과 캠페인의 이전 저장 상태를 살펴보고 복원할 수 있어요.
- 고객지원 담당자용 제어 — 고객지원 담당자는 필요할 때 자신의 세션에서 자동 저장을 끌 수 있어요.

## 자동 저장 켜는 방법

자동 저장은 현재 하이퍼클래스의 **Beta Labs**(베타 실험실)에서 사용할 수 있어요. 아래 순서로 기능을 켜고 사용해 보세요.

1. 하이퍼클래스 계정 설정에서 **Beta Labs**로 이동한 다음, 이메일 빌더의 자동 저장 기능을 찾으세요.
2. 이메일 빌더 자동 저장 토글을 켜세요.

   ![Beta Labs에서 자동 저장 토글을 켠 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080480401/original/kAEV_XkQSAS0bNLMlVyHTgLU91RgVeKFeg.png?1788953906)

3. 하이퍼클래스 계정에서 **이메일 마케팅**으로 이동하세요.
4. 기존 이메일 템플릿이나 캠페인을 열거나 새로 만든 다음, 내용을 편집하기 시작하세요.

   ![이메일 빌더에서 콘텐츠를 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080480590/original/VTH6A0rvMUBokdXBx-4cTvSyEVMN-1xX7A.png?1788953981)

5. 편집하는 동안 버전이 자동으로 만들어지는지 확인하세요. 자동 저장 표시 위로 마우스를 올리면 마지막 저장 시각이 나와요.

{% hint style="info" %}
이제 작업 내용이 자동 저장으로 보호돼요. 편집할 때마다 직접 저장하지 않아도 돼요.
{% endhint %}

## 버전 기록 사용하기

**버전 기록**에서는 이메일 템플릿과 캠페인의 이전 저장 상태를 살펴보고 복원할 수 있어요. 자동 저장이 이루어질 때마다 시각이 기록된 버전이 만들어져서, 나중에 다시 열어 볼 수 있어요.

**버전 기록**을 열려면 템플릿이나 캠페인의 **이메일 빌더**를 열고 **버전 기록** 옵션을 찾으세요. 저장된 모든 버전이 시각과 함께 나타나요. 변경 내용을 비교하고, 필요하면 이전 상태로 되돌릴 수 있어요.

{% hint style="info" %}
원치 않는 변경에서 복구하거나, 편집 중에 서로 다른 디자인을 비교할 때 **버전 기록**이 특히 유용해요.
{% endhint %}

## 자동 저장 끄기 (고객지원 사용자)

고객지원 담당자는 토글로 자신의 세션에서 자동 저장을 끌 수 있어요. 문제를 해결하거나, 자동으로 버전이 만들어지지 않는 상태에서 특정 동작을 시연할 때 유용해요.

자동 저장 토글은 고객지원 권한이 있는 사용자의 **이메일 빌더** 화면에 나타나요. 자동 저장을 꺼도 현재 세션에만 적용되고, 다른 사용자나 서브 계정의 자동 저장 설정에는 영향을 주지 않아요.

{% hint style="info" %}
자동 저장은 모든 서브 계정에서 기본으로 켜져요. 필요하면 **실험실** 설정에서 끌 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 자동 저장을 켠 뒤에도 작업 내용을 직접 저장해야 하나요?
아니요. 자동 저장을 켜면 편집 세션 중에 버전 스냅샷이 자동으로 만들어져요. 저장 버튼을 누르지 않고 계속 작업해도 돼요.

### 자동 저장은 얼마나 자주 버전을 만드나요?
자동 저장은 편집 세션 중에 버전을 자동으로 만들어요. 자동 저장 표시 위로 마우스를 올리면 마지막으로 저장된 버전의 시각을 볼 수 있어요.

### 이메일을 이전 버전으로 되돌릴 수 있나요?
네. **이메일 빌더**에서 **버전 기록**을 열면 저장된 모든 버전을 시각과 함께 볼 수 있어요. 템플릿이나 캠페인의 이전 상태를 살펴보고 복원할 수 있어요.

### 6월 1일 이후에는 자동 저장이 자동으로 켜지나요?
네. 6월 1일 이후에는 모든 서브 계정에서 자동 저장이 기본으로 켜져요. 끄려면 **실험실** 설정에서 끄면 돼요.

### 브라우저가 멈추거나 네트워크가 끊겨도 자동 저장이 작업 내용을 지켜 주나요?
네. 자동 저장은 실수로 인한 새로고침, 네트워크 문제, 브라우저 충돌, 의도치 않은 이동 제스처로 작업 내용이 사라지는 것을 막도록 만들어졌어요.

### 고객지원 담당자가 문제 해결을 위해 자동 저장을 끌 수 있나요?
네. 고객지원 담당자는 **이메일 빌더**의 토글로 자신의 세션에서만 자동 저장을 끌 수 있어요. 다른 사용자의 자동 저장 설정에는 영향을 주지 않아요.

### 자동 저장 설정은 지금 어디에서 찾나요?
자동 저장은 현재 **Beta Labs**에서 사용할 수 있어요. **실험실** 설정으로 이동해 이메일 빌더의 자동 저장 기능을 켜세요.

### 자동 저장은 이메일 템플릿과 캠페인 모두에서 작동하나요?
네. 하이퍼클래스 **이메일 빌더**에서 작업하는 이메일 템플릿과 이메일 캠페인 모두 자동 저장으로 보호돼요.
