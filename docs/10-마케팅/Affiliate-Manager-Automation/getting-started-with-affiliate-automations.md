# 제휴 자동화 시작하기

워크플로우를 사용하면 **제휴 관리자**(Affiliate Manager)에서 하던 반복 작업을 자동화할 수 있어요. 쉽게 설정할 수 있는 필수 자동화 네 가지를 소개해요.
## 1. Affiliate Created 워크플로우 트리거

### 트리거 설정

1. **Add New Workflow Trigger**(새 워크플로우 트리거 추가)를 클릭하세요.
2. **Affiliate Created**(제휴 생성됨)를 검색해서 선택하세요.
3. **Save Trigger**(트리거 저장)를 클릭하세요.

### 작동 방식

- 서브 계정에 새 제휴 파트너가 생성될 때마다 이 워크플로우가 실행돼요.

### 예시

- 마케팅 캠페인을 진행하다 보면 여러 제휴 파트너가 가입할 수 있어요. 이 트리거를 설정해 두면 각 파트너가 추가되는 즉시 직접 처리하지 않아도 워크플로우에 자동으로 포함돼요.

---

## 2. Add to Affiliate Manager

### 자동화 설정

- 연락처를 **제휴 관리자**의 **제휴 목록**에 자동으로 추가하고, 상태를 '활성'으로 설정해요.

### 작동 방식

- 워크플로우가 실행되는 즉시 연락처가 활성 상태의 제휴 파트너로 추가돼요.

### 예시

- 파트너가 될 만한 사람이 가입하면 바로 활성 제휴 파트너 목록에 추가돼요. 온보딩이 늦어지지 않아요.

## 3. Update Affiliate

### 자동화 설정

- 제휴 파트너의 상태를 '활성' 또는 '비활성'으로 바꿀 수 있어요.
- 선택할 수 있는 옵션:
  - **Mark as Active**(활성으로 표시)
  - **Mark as Inactive**(비활성으로 표시)

### 예시

- 일정 기간이 지난 뒤에도 제휴 파트너가 활동 요건을 채우지 못했다면, 이 자동화로 상태를 자동으로 비활성으로 바꿀 수 있어요.

  ![Update Affiliate 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033844790/original/cYmDOShWFpLExXBmjLj0hwNCzbEPL3bKNw.jpeg?1727763735)

## 4. Add to Affiliate Campaign

### 자동화 설정

- 제휴 파트너를 **제휴 관리자**의 **캠페인** 탭에 있는 특정 캠페인에 자동으로 추가해요. 드롭다운 메뉴에서 캠페인을 선택하세요.

### 예시

- 새 상품을 출시해서 활성 제휴 파트너 모두를 이 캠페인에 추가하고 싶다고 해 볼게요. 직접 하나씩 추가하지 않아도 이 자동화가 바로 처리해 줘요.

  ![Add to Affiliate Campaign 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033844789/original/_QzifFSd0AmdXr5SY0oUdrja-FQRSRXe7Q.jpeg?1727763735)

## 5. Remove from Affiliate Campaign

### 자동화 설정

- 제휴 파트너를 캠페인에서 제거하는 옵션이에요. 드롭다운 메뉴에서 제거할 캠페인을 선택하세요.

### 예시

- 제휴 파트너가 특정 캠페인의 조건을 더 이상 충족하지 않으면 시스템이 자동으로 캠페인에서 제거해 줘요. 관리 업무가 줄어들어요.
