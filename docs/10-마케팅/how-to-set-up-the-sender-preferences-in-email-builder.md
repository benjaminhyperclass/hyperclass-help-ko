# 이메일 빌더에서 Sender Preferences(발신자 환경설정) 설정하기

**Sender Preferences**(발신자 환경설정)에 기본 발신자 정보를 저장해 두면 새 이메일 캠페인과 테스트 발송에 자동으로 채워져요. 매번 같은 내용을 입력하지 않아도 되고, 캠페인마다 필요하면 따로 바꿀 수도 있어요. 이 문서에서는 설정 방법, 기본값이 적용되는 범위, 발신자 인증이 발송에 미치는 영향을 알려 드려요.

## Sender Preferences란?

**Sender Preferences**는 계정 전체에 적용되는 기본값이에요. 새 이메일 캠페인을 만들거나 테스트 메일을 보낼 때 **발신자 이름**, **발신자 이메일**, **Test Recipient(s)**(테스트 수신자), **Custom Reply**(사용자 지정 회신 주소)가 자동으로 채워져요. 캠페인 단위로 값을 바꾸는 것도 가능해요.

## Sender Preferences 입력란

입력란마다 발신자 정보나 테스트 발송의 다른 부분을 정해요. 새 캠페인을 만들거나 테스트를 보낼 때 하이퍼클래스가 미리 채워 주기를 원하는 항목만 설정하세요.

### 발신자 이름

받는 사람에게 보내는 사람으로 보이는 이름이에요. 알아보기 쉬운 비즈니스, 브랜드, 팀 이름을 쓰세요.

### 발신자 이메일

받는 사람에게 발신 주소로 보이는 이메일 주소예요. 유효한 발신 주소를 입력하고, 하이퍼클래스에서 요구하는 인증이 있으면 발송 전에 마치세요.

주소를 이메일 캠페인에서 쓰려면 먼저 하이퍼클래스의 이메일 인증이 필요할 수 있어요. 발신 도메인 요건은 공유 도메인, 하이퍼클래스 이메일 전용 도메인, 다른 이메일 제공업체 중 무엇을 쓰는지에 따라 달라질 수 있어요.

{% hint style="warning" %}
**발신자 이메일**을 저장해도 발신 도메인 검증이 생략되지는 않아요. 캠페인을 발송하거나 예약할 때 인증, 도메인, 전달률 관련 경고가 나오면 내용을 확인하세요.
{% endhint %}

### Test Recipient(s)

테스트 메일의 기본 수신자로 쓸 이메일 주소를 쉼표로 구분해 최대 5개까지 추가할 수 있어요. 캠페인을 보내기 전에 확인할 팀, QA 담당자, 이해관계자의 메일함을 넣어 두면 편해요.

### Custom Reply

회신을 **발신자 이메일**이 아닌 다른 주소로 받고 싶을 때 입력하세요. 비워 두면 해당 상황의 기본 회신 방식이 적용돼요.

{% hint style="info" %}
태그 아이콘이 보이는 입력란에서는 고정된 발신자 정보 대신 지원되는 커스텀 값을 쓸 수 있어요.
{% endhint %}

## Sender Preferences 설정하기

한 번만 설정해 두면 새 이메일 캠페인과 테스트 발송에 발신자 정보와 테스트 정보가 미리 채워져요.

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. **설정** 톱니바퀴 아이콘을 클릭하세요.

   ![설정 톱니바퀴 아이콘 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082342901/original/KXiscupmN2_gbKF89dYBFnUSlp7y3bb_SA.png?1790922379)
3. **Sender Preferences**를 선택하세요.
4. 기본 **발신자 이름**을 입력하세요.
5. 기본 **발신자 이메일**을 입력하세요.
6. 필요하면 **Test Recipient(s)**를 최대 5개까지 추가하세요.
7. 회신을 다른 주소로 받으려면 **Custom Reply** 주소를 입력하세요.
8. **저장**을 클릭하세요.

   ![저장 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082342961/original/npd-dbG5N4zsmwXYtwT0tWOqeMU_EWWKRA.png?1790922440)

## Sender Preferences가 적용되는 방식

**Sender Preferences**는 새 이메일 캠페인과 테스트 발송의 시작값이에요. 이미 만들어 둔 초안이나 예약된 캠페인에 저장된 발신자 정보를 자동으로 바꾸지는 않아요.

필요하면 캠페인마다 발신자 정보를 따로 바꿀 수 있어요.

캠페인을 복제하면 최근에 바꾼 **Sender Preferences**가 아니라 원본 캠페인에 저장된 발신자 값을 그대로 가져와요. 복제한 뒤에는 발신자 정보를 확인하세요.

## 자주 묻는 질문

### Sender Preferences를 바꾸면 기존 초안이나 예약된 캠페인도 바뀌나요?

아니요. 바꾼 **Sender Preferences**는 새 캠페인과 테스트 발송에만 적용돼요. 기존 초안과 예약된 캠페인은 직접 수정하지 않는 한 저장된 발신자 정보를 그대로 유지해요.

### 특정 캠페인에서만 Sender Preferences와 다르게 설정할 수 있나요?

네. **Sender Preferences**는 기본값일 뿐이라서, 필요하면 캠페인마다 발신자 정보를 바꿀 수 있어요.

### Custom Reply 주소를 발신자 이메일과 다르게 쓸 수 있나요?

네. 회신 주소는 발신 도메인과 별개라서 다른 유효한 이메일 주소를 쓸 수 있어요.

### 발신자 이메일도 인증해야 하나요?

이메일 캠페인에는 인증된 유효한 **발신자 주소**가 필요해요. 계정의 이메일 설정에서 아직 신뢰된 주소가 아니라면, 발송 전에 하이퍼클래스가 **이메일 인증**을 마치라고 안내할 수 있어요.
