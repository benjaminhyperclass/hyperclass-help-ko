# 제휴 관리자 공개 API: 개요, 엔드포인트, 스코프

제휴 관리자 공개 API를 쓰면 개발자와 마켓플레이스 앱 개발자가 로케이션(서브 계정)의 제휴 프로그램을 코드로 관리할 수 있어요. REST API 엔드포인트로 제휴 파트너, 캠페인, 추천 고객, 커미션, 지급, 지급 방법, 제휴 미디어를 다룰 수 있어서 **제휴 관리자** 화면에만 의존하지 않아도 돼요.

이 API는 새 엔드포인트 28개와, 더 엄격하게 조정한 기존 엔드포인트 4개를 합쳐 모두 32개예요. 하이퍼클래스 개발자 마켓플레이스의 v3 API 카탈로그에서 확인할 수 있어요.

---

## 주요 기능

- 화면 없이 제휴 파트너 관리: 내 앱에서 제휴 파트너를 등록, 수정, 활성화, 비활성화할 수 있어요.
- 커미션과 지급 리포트: 커미션과 지급 데이터를 외부 대시보드, 대조 작업, 재무 워크플로우로 가져올 수 있어요.
- 전환 귀속: 추천 ID를 검증하고 외부 랜딩 페이지와 결제 흐름에서 리드를 만들어, 전환 실적을 알맞은 제휴 파트너에게 연결할 수 있어요.
- 내 흐름에서 지급 정보 수집: 제휴 파트너의 지급 방법을 관리할 수 있어요. 국가별로 필요한 은행 필드를 조회하는 기능도 있어요.

---

## 사용 대상

**제휴 관리자**를 활용해 맞춤 대시보드, CRM 연동, 자동 리포트, 파트너 앱을 만드는 개발자와 에이전시를 위한 기능이에요.

### API 엔드포인트 그룹

모든 엔드포인트는 `/affiliate-manager` 아래에 있고, 7개 그룹으로 나뉘어요.

| 그룹 | 엔드포인트 수 | 할 수 있는 일 |
| --- | --- | --- |
| 제휴 파트너(Affiliates) | 10 | 제휴 파트너를 만들고, 조회하고, 수정하고, 목록으로 볼 수 있어요. 제휴 파트너를 활성화하거나 비활성화할 수 있어요. 제휴 파트너를 캠페인 사이에서 옮길 수 있어요. 추천 ID를 설정하고 검증할 수 있어요. 캠페인에서 제휴 파트너를 일시 중지할 수 있어요. 세금 양식을 업로드할 수 있어요. |
| 지급 방법(Payout Methods) | 6 | 제휴 파트너의 지급 방법을 만들고, 조회하고, 수정하고, 삭제할 수 있어요. 지급 방법을 기본으로 지정할 수 있어요. 국가별로 필요한 은행 필드를 조회할 수 있어요. |
| 커미션(Commissions) | 5 | 커미션을 만들고, 목록으로 보고, 삭제할 수 있어요. 커미션 상태를 바꾸거나 커미션을 거부할 수 있어요. |
| 고객(Customers) | 5 | 제휴 파트너가 추천한 고객 목록을 볼 수 있어요. 리드를 만들고 검증할 수 있어요. 고객의 상태를 바꾸거나 고객을 삭제할 수 있어요. |
| 제휴 미디어(Affiliate Media) | 3 | 로케이션의 제휴 미디어 파일과 폴더를 목록으로 보고, 수정하고, 삭제할 수 있어요. |
| 캠페인(Campaigns) | 2 | 캠페인 목록을 보고, 커미션 구조가 포함된 캠페인 정보를 가져올 수 있어요. |
| 지급(Payouts) | 1 | 로케이션의 지급 목록을 볼 수 있어요. |

## 꼭 알아 둘 API 동작

제휴 관리자 API를 쓰기 전에 엔드포인트별 동작을 먼저 확인하세요.

- 제휴 파트너 만들기: 같은 이메일 주소의 제휴 파트너가 로케이션에 이미 있으면 `Create Affiliate` 엔드포인트는 중복으로 만들지 않고 기존 제휴 파트너를 업데이트해요.
- 제휴 파트너 수정: `Update Affiliate` 엔드포인트는 제휴 파트너 레코드를 통째로 교체해요. 요청 본문에서 빠진 필드는 비워지므로, 유지하려는 필드는 모두 포함하세요.
- 추천 ID: 추천 ID는 제휴 파트너가 서로 다른 캠페인에 속해 있더라도 로케이션 안에서 고유해야 해요.
- 제휴 파트너 일시 중지: 캠페인에서 제휴 파트너를 일시 중지하면 보류 중이거나 거부된 지급, 커미션, 거래가 취소돼요. 제휴 파트너를 복구하면 취소된 항목이 다시 보류 상태로 돌아가요.
- 지급 방법: 제휴 파트너는 PayPal 지급 방법 1개와 은행 지급 방법 1개를 가질 수 있어요. 가장 먼저 추가한 방법이 기본 지급 방법이 돼요.
- 지급 방법 삭제: 제휴 파트너의 지급 방법이 2개 이상이면 기본 지급 방법은 삭제할 수 없어요.
- 지급 정보: `List Payout Methods` 엔드포인트는 은행 계좌 값의 마지막 4자리만 반환해요.

엔드포인트별 요구 사항은 개발자 마켓플레이스의 제휴 파트너(Affiliates)와 지급 방법(Payout Methods) API 문서를 확인하세요. 문서 주소가 필요하면 하이퍼클래스 고객지원에 문의하세요.

---

## 인증과 스코프

이 API는 Location-Access를 사용하는 표준 v3 OAuth 2.0 방식이에요. 앱이 할 수 있는 일은 스코프 2개로 정해져요.
`affiliate-manager.readonly`: 데이터를 읽는 엔드포인트 12개에 필요해요.`affiliate-manager.write`: 데이터를 만들거나 수정하거나 삭제하는 엔드포인트 20개에 필요해요.

---

## 시작하는 방법

1. 하이퍼클래스 개발자 마켓플레이스에서 제휴 관리자 API v3 문서를 여세요.
2. 개발자 마켓플레이스에서 앱을 만들거나 열고, 앱이 하는 일에 맞게 `affiliate-manager.readonly` 또는 `affiliate-manager.write` 스코프(또는 둘 다)를 활성화해요.
3. Location-Access를 사용하는 OAuth 2.0으로 로케이션에 앱을 승인해요.
   앱 등록, OAuth 설정, 로케이션에 앱 설치, 액세스 토큰 발급 방법은 하이퍼클래스 OAuth 2.0 문서를 참고하세요. 문서 주소가 필요하면 하이퍼클래스 고객지원에 문의하세요.
4. 필요한 그룹의 엔드포인트를 호출해요. 그룹마다 요청과 응답 내용을 담은 참조 페이지가 따로 있어요.
   - 제휴 파트너(Affiliates)
   - 지급 방법(Payout Methods)
   - 커미션(Commissions)
   - 고객(Customers)
   - 제휴 미디어(Affiliate Media)
   - 캠페인(Campaigns)
   - 지급(Payouts)

---

## 활용 사례

- 고객사를 위한 맞춤 제휴 대시보드를 만들 수 있어요.
- 제휴 파트너, 커미션, 지급 데이터를 CRM이나 재무 도구와 동기화할 수 있어요.
- 내 가입 흐름에서 제휴 파트너를 등록하면서 지급 정보도 함께 받을 수 있어요.
- 외부 랜딩 페이지와 결제 흐름에서 발생한 리드와 매출을 알맞은 제휴 파트너에게 연결할 수 있어요.

## 자주 묻는 질문

### 이 API를 쓰려면 개발자 마켓플레이스에 앱이 있어야 하나요?
이 API는 Location-Access를 사용하는 v3 OAuth 2.0 방식이에요. 그래서 연동에서 제휴 파트너 데이터를 가져오려는 로케이션에 대한 승인이 필요해요.

### 요청과 응답 예시는 어디서 볼 수 있나요?
하이퍼클래스 API 문서의 제휴 관리자 섹션에서 예시를 볼 수 있어요. 엔드포인트 그룹마다 참조 페이지가 따로 있어요. 문서 주소가 필요하면 하이퍼클래스 고객지원에 문의하세요.
