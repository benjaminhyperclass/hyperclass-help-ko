# WhatsApp·소셜 플래너에서 광고 관리자로 바로 광고 만들기

WhatsApp와 **소셜 플래너**에서 버튼 한 번으로 **광고 관리자**(Ad Manager)를 열 수 있어요. 대화나 소셜 게시물을 광고로 바로 이어서 만들고 싶을 때 쓰세요.

## 새 버튼(빠른 연결 링크)이란?

WhatsApp와 **소셜 플래너**에 **광고 관리자**를 바로 여는 버튼이 생겼어요. 광고를 만들 수 있는 상태로 **광고 관리자**가 열려요.

- WhatsApp의 **Create Engagement Ad**(참여 유도 광고 만들기)
- **소셜 플래너**의 **광고로 실행**

두 버튼은 지금 보고 있는 화면에 맞춰 **광고 관리자**로 연결돼요. 캠페인 목표와 게시물 내용이 미리 채워져서, 평소 광고를 만들 때 거치는 수동 단계를 줄여 줘요.

## 이 버튼을 쓰면 좋은 점

- 캠페인 설정이 빨라져요. 목표, 도착 위치, 미디어, 문구가 미리 선택돼 있어서 입력할 내용이 줄어요.
- **광고 관리자**를 쓰지 않던 사용자가 일하는 화면에 업그레이드 안내가 나타나서, **광고 관리자**를 시작하기 쉬워요.
- 작업이 끊기지 않아요. 일반 콘텐츠에서 유료 광고까지 한 번에 이어져요.
- 실수가 줄어요. 올바른 목표(Engagement)와 채널(WhatsApp/Facebook/Instagram)이 자동으로 적용돼요.

## WhatsApp에서 참여 유도 광고 만들기

WhatsApp 전화번호 하나를 바로 참여 유도(Engagement) 캠페인으로 만들 수 있어요.

- 버튼 위치: **설정 > WhatsApp > Numbers**(번호) 탭에서 **번호 추가** 옆
- **광고 관리자**에 자동으로 채워지는 항목:
  - **Objective**(목표): Engagement
  - **Destination**(도착 위치): WhatsApp
  - 예산, 타깃, 크리에이티브는 그대로 수정할 수 있어요.
- **광고 관리자**를 쓰지 않는 사용자에게는 구독 혜택 안내 창이 나타나고, 여기에 **Connect Ad Manager**(광고 관리자 연결) 버튼이 있어요.
- **광고 관리자**는 있지만 광고 계정이 연결되지 않은 사용자에게는 **Connect Account**(계정 연결) 버튼이 보여요.

## 소셜 플래너에서 광고로 실행하기

이미 게시했거나 예약해 둔 Facebook/Instagram 게시물을 파일을 다시 올리지 않고 바로 광고로 만들 수 있어요.

**광고로 실행** 버튼이 보이는 위치:

- **마케팅 > 소셜 플래너 > Planner**(플래너) 탭 > 목록 행의 점 3개 메뉴
- **마케팅 > 소셜 플래너 > Content**(콘텐츠) 탭 > **Approval**(승인) 탭 > 목록 행의 점 3개 메뉴
- **마케팅 > 소셜 플래너** > 게시물 상세 사이드바

지원하는 게시물 상태는 **Published**(게시됨), **Scheduled**(예약됨), **In Review**(검토 중)예요. **Draft**(임시 저장)와 **Recurring**(반복) 상태는 지원하지 않아요.

이동 순서는 다음과 같아요.

1. **광고로 실행**을 클릭해요.
2. 확인 창이 나타나면 확인해요.
3. **광고 관리자**가 열려요.
4. Google 또는 Meta를 선택해요.
5. 미디어와 캡션이 미리 채워진 캠페인이 나타나요. 텍스트만 있는 게시물은 계속 수정할 수 있어요.

## 자주 묻는 질문

### 이 기능을 쓰면 추가 비용이 드나요?
아니요. 기능 자체는 무료예요. 다만 서브 계정에 **광고 관리자** 구독이나 사용량에 따라 내는 요금제(pay-as-you-go)가 활성화되어 있어야 해요.

### TikTok이나 LinkedIn 게시물에도 광고로 실행을 쓸 수 있나요?
아직 안 돼요. 지금은 Facebook과 Instagram 게시물만 지원해요.

### 게시물을 광고로 만든 뒤에 게시물을 수정하면 어떻게 되나요?
**소셜 플래너**에서 바꾼 내용은 이미 실행 중인 광고에 반영되지 않아요. 광고 내용은 **광고 관리자**에서 직접 수정하세요.

### WhatsApp에서 Create Engagement Ad 버튼이 안 보여요.
**Numbers**(번호) 탭에 있는지, 서브 계정에서 WhatsApp이 켜져 있는지 확인하세요. 일반 사용자 권한도 적용돼요.

### 확인 창을 건너뛸 수 있나요?
아니요. 확인 창은 실수로 화면이 넘어가는 것을 막고, **광고 관리자** 흐름으로 들어간다는 점을 알려 줘요.
