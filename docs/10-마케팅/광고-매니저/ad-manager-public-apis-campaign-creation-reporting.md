# 광고 관리자 공개 API: 캠페인 생성과 리포팅

하이퍼클래스 화면을 열지 않고도 Facebook, Google, LinkedIn 광고를 만들고 관리하고 성과까지 확인할 수 있어요. 직접 만든 소프트웨어나 워크플로우에서 **광고 관리자**(Ad Manager) 공개 API를 호출하면 됩니다.

## 이 문서에서 알 수 있는 내용

개발자가 아니어도 이해할 수 있게 광고 관리자 공개 API가 무엇인지, 왜 쓰는지, 광고 운영을 어떻게 자동화할 수 있는지 설명해요. 기술 팀과 함께 자동 광고 워크플로우를 구축할 때 참고하세요.

- 이 API가 해결해 주는 문제
- 지원하는 광고 플랫폼
- 수동 캠페인 설정에서 코드로 하는 자동 광고 운영으로 넘어가는 방법

## 광고 관리자 공개 API란?

광고 관리자 공개 API는 직접 만든 소프트웨어가 하이퍼클래스의 **광고 관리자**와 바로 연결되도록 해 주는 개발자 도구예요. 화면을 클릭하며 광고를 하나씩 설정하는 대신, 개발팀이 코드로 다음 작업을 자동 처리할 수 있어요.

- 캠페인 만들기
- 예산 설정
- 잠재고객 선택
- 광고 게시
- Facebook, Google, LinkedIn 전체의 성과 리포트 가져오기

이 API는 광고 운영을 위한 컨트롤 패널과 비슷해요. 하이퍼클래스는 사람이 개입하지 않아도 인증하고, 광고 계정을 연결하고, 캠페인을 시작하고, 플랫폼 전체의 성과 데이터를 가져오는 표준화된 방법을 제공해요.

[스크린샷: 하이퍼클래스 API 2.0 문서. 왼쪽 탐색에서 "Ad Manager"가 강조되어 있고 Facebook, Google, LinkedIn 섹션이 보여요.]

## 광고 관리자 공개 API의 주요 장점

이 API를 쓰면 광고 운영 방식이 달라져요. 화면에서 클릭해 설정할 수 있는 범위에 묶이지 않고, 우리 비즈니스 방식에 딱 맞는 자동화를 직접 만들 수 있어요.

- 모든 플랫폼을 한 번에 관리: 규칙과 화면이 서로 다른 광고 대시보드 세 곳을 오가는 대신, 하나의 일관된 시스템에서 Facebook, Google, LinkedIn 광고를 관리해요.
- 대규모 캠페인 자동 생성: 코드로 캠페인, 광고 세트, 광고를 만들고 수정하고 일시중지·재개·복제할 수 있어요. 성과가 좋은 구조를 템플릿으로 만들어 수십, 수백 고객사에 바로 적용할 수 있어요.
- 코드로 계정 설정: 광고 계정을 코드로 연결하고 관리해요. 서브 계정이나 고객사를 새로 받을 때마다 직접 연동하지 않아도 돼요.
- 플랫폼 통합 리포팅: 노출수, 클릭수, 지출, 전환 같은 지표를 모든 플랫폼에서 같은 형식으로 가져와요. 이 데이터로 맞춤 대시보드, 데이터 웨어하우스, 고객 리포팅 도구를 만들 수 있어요.
- 빠른 출시: 여러 플랫폼에 걸친 복잡한 캠페인을 직접 만든 애플리케이션이나 스크립트로 한꺼번에 시작해요. 화면에서 변형을 하나씩 설정하느라 며칠씩 쓰지 않아도 돼요.
- 확장 가능한 자동화와 워크플로우: 광고 관리자 API를 내부 CRM, 결제 시스템, 온보딩 도구와 연결하세요. 새 지점, 상품, 업종이 생기면 사람 손 없이 캠페인이 자동으로 만들어져요.

## 광고 관리자 API 인증과 접근

광고 관리자 API는 하이퍼클래스 API 2.0에 포함돼 있어요. API 2.0은 보안 액세스 토큰으로 소프트웨어가 광고 계정을 제어할 권한이 있는지 확인해요. 토큰은 디지털 열쇠라고 생각하면 돼요. 개발자가 하이퍼클래스에서 열쇠를 받아 두면, 소프트웨어가 캠페인을 만들거나 리포트를 가져올 때마다 이 열쇠를 보여 주고 권한을 증명해요.

### 인증 방식

HTTP Bearer 인증

광고 관리자 API 요청은 모두 JWT 토큰을 쓰는 HTTP Bearer 인증을 사용해요. 토큰은 두 가지 종류로 만들 수 있어요.

- 에이전시 토큰: 여러 서브 계정에 걸친 에이전시 단위 접근
- 서브 계정 토큰: 특정 고객사 한 곳(로케이션)에 대한 접근

### 알맞은 토큰 종류 고르기

- 특정 고객사나 로케이션 한 곳의 광고만 관리하면 된다면 서브 계정 액세스 토큰(또는 비공개 연동 토큰)을 쓰세요.
- 에이전시 아래 여러 서브 계정의 캠페인을 한꺼번에 운영하는 도구를 만든다면 에이전시 액세스 토큰을 쓰세요.

### API 위치

하이퍼클래스 API 2.0 문서에는 광고 관리자 전용 모듈이 있어요. 모듈 안에는 소개(광고 관리자 API 개요)와 함께 다음 섹션이 따로 나뉘어 있어요.

- Facebook 연동 / 광고 / 리포팅
- Google 연동 / 광고 / 리포팅
- LinkedIn 연동 / 광고 / 리포팅

[스크린샷: API 2.0 인증 페이지. Bearer(JWT) 인증 상세 내용이 강조되어 있어요.]

## 캠페인·광고 생성 API

캠페인·광고 생성 API를 쓰면 소프트웨어가 코드만으로 광고 캠페인 전체를 만들 수 있어요. 최상위 캠페인 목표와 예산부터 이미지와 헤드라인이 들어간 개별 광고까지 모두 해당해요. 그래서 캠페인 템플릿 자동화, 업종별 플레이북, 대량 캠페인 관리처럼 수동으로 하면 며칠 걸릴 작업을 자동화할 수 있어요.

플랫폼별 주요 기능은 다음과 같아요.

### Facebook Ads: 캠페인 전체 수명 주기 관리

- 타겟팅 옵션 검색(지역, 관심사)으로 잠재고객 구성
- 캠페인, 광고 세트, 광고를 코드로 만들거나 수정
- 화면을 열지 않고 캠페인 일시중지, 재개, 복제, 삭제
- 전환 픽셀, 맞춤 잠재고객(잠재고객 구성원 일괄 업데이트 포함) 같은 관련 자산 관리

### Google Ads: 처음부터 끝까지 자동화

- Google Ads 캠페인을 코드로 게시
- 전환, 크리에이티브 자산, 캠페인, 광고 그룹, 광고 작업
- 타겟팅 지원: 지역 검색, 키워드 아이디어, 타겟 관심사(관심 분야 및 구매 의도)
- 잠재고객 관리: 오프라인 사용자 목록 작업, 잠재고객 세그먼트, 결합 잠재고객

### LinkedIn Ads: 캠페인 그룹 작업

- 광고 캠페인 그룹 작업: 캠페인과 광고가 포함된 캠페인 그룹을 만들거나 수정하고 게시
- 지역, 업종, 직책 같은 타겟팅 옵션 검색
- LinkedIn 리드 폼 처리(조회 또는 생성)
- 광고, 캠페인, 광고 그룹의 상태 변경(일시중지 또는 재개)

### 일반적인 작업 순서

코드로 캠페인을 만들 때는 다음 순서로 진행해요.

1. 연동 API로 플랫폼 계정이 연결되어 있는지 확인해요.
2. 플랫폼별 타겟팅 옵션 검색이나 키워드·관심사 도구로 잠재고객 정의를 만들어요.
3. 목표, 예산, 상태를 담은 캠페인 객체를 만들거나 수정해요.
4. 타겟팅, 게재 위치, 일정을 담은 광고 세트(광고 그룹)를 만들거나 수정해요.
5. 크리에이티브와 도착 URL을 담은 광고를 만들거나 수정해요.
6. 게시 전용 도구로 캠페인을 게시해요.

[스크린샷: API 흐름 예시 다이어그램. "Integration → Targeting → Campaign → Ad Set/Ad Group → Ad → Publish" 순서가 나와 있어요.]

## Facebook, Google, LinkedIn 연동 API

연동 API를 쓰면 광고 계정, 페이지, 관련 자산이 하이퍼클래스 서브 계정에 어떻게 연결되는지 코드로 제어할 수 있어요. 고객사가 많아 계정 설정을 표준화하거나 자동화하고 싶을 때 특히 유용해요. 고객에게 수동 단계를 하나하나 안내하는 대신, 소프트웨어가 새 고객사의 Facebook 페이지, Google Ads 계정, LinkedIn 프로필을 자동으로 연결해 줘요.

### Facebook 연동: 계정과 자산 관리

- 로케이션에 인증된 Facebook 사용자 조회
- Facebook 페이지, 페이지에 연결된 Instagram 계정, 광고 계정, 리드 폼, 대화 폼 목록 조회 및 관리
- 로케이션 단위의 Facebook 광고 연동 생성 및 관리: Facebook 연동 생성·조회·삭제, 기본 페이지 설정, 페이지 연결 해제
- 리드 폼 관리(ID로 리드 폼 상세 조회 포함)

### Google·LinkedIn 연동: 플랫폼 계정 연결

- Google 연동: 로케이션의 Google Ads 전환, 자산, 잠재고객, 캠페인을 조회하고 관리해요.
- LinkedIn 연동: 캠페인 그룹과 리드 폼으로 LinkedIn 광고 계정을 다루고, LinkedIn 타겟팅 패싯을 검색해 적용해요.

{% hint style="info" %}
Facebook, Google, Instagram용으로 하이퍼클래스에 이미 있는 화면 기반 연동과 함께 쓰면, 수동 설정과 코드 설정을 모두 선택할 수 있어요.
{% endhint %}

[스크린샷: 개발자 문서의 Facebook 연동 엔드포인트 목록(Get current Facebook user, Get pages, Get ad accounts, Create Facebook integration 등).]

## 리포팅 API

리포팅 API를 쓰면 각 광고 네트워크를 따로 호출하지 않고, 하이퍼클래스 **광고 관리자**를 통해 Facebook, Google, LinkedIn의 성과 지표를 표준화된 방식으로 가져올 수 있어요. 분석 데이터를 직접 쓰는 비즈니스 인텔리전스 도구, 고객 대시보드, 자동 최적화 루틴으로 모을 수 있어서 모든 광고 성과를 일관된 지표로 한곳에서 볼 수 있어요.

### 리포팅 API가 지원하는 지표

핵심 광고 지표는 다음과 같아요.

- 노출수
- 클릭수
- 지출
- 전환 및 전환 관련 지표
- 플랫폼에 따라 제공되는 추가 성과 지표(예: 클릭당 비용, 전환당 비용, 전환율, 투자수익률)

### 플랫폼 간 일관된 리포팅 구조

데이터는 광고 관리자가 플랫폼별로 제공하는 리포팅 엔드포인트로 가져와요(예: Google 리포팅의 `Get reporting data`, `Get reporting list`). 통합된 "캠페인 성과" 모델이 필요하면 애플리케이션에서 이 데이터를 직접 만든 스키마로 맞추면 돼요.

### 예시: Google 리포팅 엔드포인트

주요 리포팅 호출은 세 가지예요.
`Get reporting data`: 로케이션의 Google Ads 집계 지표`Get reporting list`: 요약 통계가 포함된 캠페인과 광고 그룹`Get campaign reporting`: 캠페인 하나의 상세 리포트

{% hint style="info" %}
정확한 필드는 플랫폼마다 달라요. 그래도 노출수, 클릭수, 지출, 전환 관련 지표 같은 핵심 성과 지표는 각 광고 플랫폼 자체 화면과 광고 관리자 리포팅에서 보는 값과 맞춰 볼 수 있어요. Facebook과 LinkedIn 리포팅 API도 Google과 비슷한 방식으로 동작해요.
{% endhint %}

[스크린샷: 광고 관리자 API 문서의 Google 리포팅 섹션. Get reporting data, Get reporting list, Get campaign reporting이 보여요.]

## 지원하는 광고 플랫폼과 객체

광고 관리자 API는 광고 네트워크마다 다른 복잡한 부분을 어느 정도 감춰 주면서도, 본격적인 미디어 구매에 필요한 핵심 요소는 그대로 다룰 수 있게 설계되어 있어요.

| 플랫폼 | 객체 | 작업 |
| --- | --- | --- |
| Facebook / Instagram | - 캠페인, 광고 세트, 광고<br>- 맞춤 잠재고객, 전환 픽셀<br>- 페이지, 리드 폼, 대화 폼 | - 타겟팅 옵션 검색<br>- 캠페인, 광고 세트, 광고 생성 또는 수정<br>- 일시중지, 재개, 복제, 삭제<br>- 잠재고객과 픽셀 관리<br>- 캠페인 게시 |
| Google Ads | - 캠페인, 광고 그룹, 광고<br>- 전환 및 전환 목표<br>- 자산(크리에이티브), 잠재고객 세그먼트, 결합 잠재고객 | - 광고와 캠페인 게시<br>- 지역 타겟 및 키워드 아이디어 검색<br>- 전환, 자산, 잠재고객 관리<br>- 리포팅 지표 조회 |
| LinkedIn Ads | - 광고 캠페인 그룹(캠페인과 광고 포함)<br>- 리드 폼 | - 캠페인 그룹 게시<br>- 타겟팅 패싯 검색(지역, 업종, 직책)<br>- 광고, 캠페인, 광고 그룹 일시중지 또는 재개<br>- 리드 폼 생성 또는 조회 |

## 광고 관리자 공개 API 설정하기

광고 자동화를 시작할 준비가 되었다면 아래 안내에 따라 개발 환경을 광고 관리자 공개 API에 연결하세요.

설정은 크게 세 단계예요. 해당 서브 계정에서 **광고 관리자**를 사용할 수 있는지 확인하고, 인증을 설정하고, 필요한 엔드포인트를 호출하도록 직접 만든 애플리케이션이나 연동을 연결해요. 아래 내용은 개발자가 기술 환경에 맞게 조정할 수 있는 개략적인 구현 가이드로 활용하세요.

### 1단계. 계정에서 광고 관리자가 켜져 있는지 확인하기

1. 에이전시 사용자로 하이퍼클래스에 로그인해요.
2. 해당 서브 계정에서 화면의 **광고 관리자**에 접근할 수 있는지 확인해요.
3. 많은 고객사 로케이션에 적용한다면, 코드로 관리할 로케이션과 화면으로만 관리할 로케이션을 미리 정해요.

[스크린샷: 하이퍼클래스 서브 계정 화면. 왼쪽 메뉴에 광고 관리자 모듈이 보여요.]

### 2단계. API 접근 설정하기 (하이퍼클래스 API 2.0)

1. 에이전시 계정에서 하이퍼클래스 API 2.0 가이드라인에 따라 API 토큰(또는 비공개 연동 토큰)을 만들어요.
2. 연동에서 서브 계정 토큰을 써서 한 번에 로케이션 한 곳 대신 작업할지, 여러 서브 계정을 아우르는 에이전시 토큰을 쓸지 정해요.
3. 토큰은 백엔드에 안전하게 보관해요(예: 환경 변수나 시크릿 매니저).
4. 개발자가 API 클라이언트에서 모든 요청에 `Authorization: Bearer token` 헤더를 설정하고, 광고 관리자 모듈 문서에 나와 있는 광고 관리자 엔드포인트를 사용하도록 구성해요.

[스크린샷: API 2.0 인증 페이지. Bearer(JWT) 인증 상세 내용이 강조되어 있어요.]

### 3단계. 연동 API 또는 화면으로 광고 계정 연결하기

서브 계정마다 Facebook, Google, LinkedIn 광고 계정이 연결되어 있는지 확인하세요.

- 한 번만 빠르게 설정하려면 화면에 이미 있는 연동을 써요(예: Facebook/Instagram 연동, Google Ads 연동).
- 연동 API를 쓸 수도 있어요.
- Facebook 연동: 연동 생성, 조회, 삭제, 페이지와 광고 계정 관리
- Google Ads와 LinkedIn Ads: 서브 계정에 플랫폼 계정과 권한이 갖춰져 있는지 확인
- API로 확인해요. 알맞은 조회 엔드포인트(예: Get Facebook pages, Get ad accounts, Get conversions)를 호출해 연동이 활성 상태인지 확인해요.

[스크린샷: 하이퍼클래스 Facebook 연동 설정 화면. 연결된 페이지와 광고 계정이 보여요.]

### 4단계. 첫 API 호출 만들고 테스트하기

1. 인증이 잘 되는지 확인하려면 간단한 조회 엔드포인트부터 시작해요(예: Get Facebook pages, Get Google conversions).
2. Postman, curl 또는 사용하는 프로그래밍 언어의 HTTP 클라이언트로 Bearer 토큰을 넣어 요청을 보내요.
3. 응답을 보고 예상한 데이터가 오는지 확인해요.
4. 기본 호출이 잘 되면 캠페인 생성이나 리포팅 데이터 조회 같은 더 복잡한 작업으로 넘어가요.

### 5단계. 자동화 워크플로우 구현하기

인증과 연동을 확인했다면, 개발자가 비즈니스에 필요한 워크플로우를 만들 수 있어요.

- 캠페인 생성 자동화(캠페인·광고 생성 API 사용)
- 예약된 리포트 수집(리포팅 API 사용)
- 대량 캠페인 관리(일시중지, 재개, 예산 업데이트)
- 광고 성과를 집계해서 보여 주는 맞춤 대시보드나 고객 포털

{% hint style="warning" %}
엔드포인트 상세 사양, 요청/응답 스키마, 호출 한도, 오류 처리 가이드라인은 공식 하이퍼클래스 API 2.0 문서를 참고하세요. 광고 관리자 모듈 문서에는 Facebook, Google, LinkedIn 연동에서 쓸 수 있는 모든 엔드포인트의 자세한 내용이 나와 있어요.
{% endhint %}
