# Google Ads에서 광고 그룹과 광고 여러 개 만들기

Google 검색 캠페인을 캠페인 → 광고 그룹 → 광고 구조로 만들고, 여러 키워드 주제와 광고 변형을 관리하는 방법을 안내해요. 단계별 성과도 확인할 수 있어요.

하이퍼클래스 **광고 관리자**(Ad Manager)에서는 Google 검색 캠페인 하나에 광고 그룹과 광고를 여러 개 넣을 수 있어요. 캠페인당 광고 그룹은 최대 10개, 광고 그룹당 광고는 최대 3개까지 만들 수 있어요. 키워드 정리, 광고 변형, 리포트를 더 세밀하게 관리할 수 있어요.

이 문서에서는 캠페인 계층 구조, 현재 한도, 키워드와 URL 요건, 캠페인 설정 방법, 관리 기능, 검토 과정, 상세 성과 확인 방법을 설명해요.

{% hint style="info" %}
이 문서는 하이퍼클래스 **광고 관리자**에서 만드는 Google 반응형 검색 캠페인의 여러 광고 그룹 설정 흐름을 다뤄요. Google Demand Gen과 Meta 캠페인 빌더는 설정 흐름이 따로 있어요.
{% endhint %}

## 여러 광고 그룹과 광고란?

여러 광고 그룹을 쓰면 Google 검색 캠페인 하나를 키워드와 메시지 주제별로 나눠 정리할 수 있어요. 광고 그룹마다 기본 웹사이트 URL, 키워드(긍정·제외), 키워드 일치 유형, 반응형 검색 광고 최대 3개를 따로 가져요.

하이퍼클래스는 이 구조를 캠페인 → 광고 그룹 → 광고로 보여 줘요. 캠페인 설정에서는 전체 예산과 타겟을, 광고 그룹 설정에서는 키워드 타겟팅과 공통 기본 URL을 정해요. 광고 설정에서는 제목, 설명, 최종 URL, 표시 경로를 정해요.

### 여러 광고 그룹과 광고의 장점

캠페인을 여러 단계로 나누면 키워드, 랜딩 페이지, 광고 메시지를 맞춰 두기 쉬워요. 상품, 서비스, 타겟 주제마다 캠페인을 따로 만들지 않아도 성과를 비교할 수 있어요.

- 유연한 캠페인 구조: 캠페인 하나를 오퍼, 서비스, 지역, 키워드 주제별 광고 그룹으로 나눌 수 있어요.
- 광고 변형: 광고 그룹마다 광고를 최대 3개까지 추가해 제목, 설명, 표시 경로를 비교할 수 있어요.
- 키워드 관리: 광고 그룹 단위로 긍정 키워드, 제외 키워드, 그리고 **넓게**, **문구**, **정확히** 일치 유형을 관리할 수 있어요.
- 일관된 랜딩 페이지 구조: 같은 광고 그룹의 광고에는 공통 기본 URL을 적용하고, 표시 경로는 광고마다 다르게 쓸 수 있어요.
- 빠른 캠페인 구성: 캠페인 계층 구조에서 광고 그룹이나 광고를 만들고, 복사하고, 삭제할 수 있어요.
- 게시 전 검토: Google에 보내기 전에 캠페인 설정과 전체 계층 구조를 확인할 수 있어요.
- 세분화된 리포트: 캠페인, 광고 그룹, 광고, 키워드 단위로 성과를 볼 수 있어요.

## 시작하기 전에

빌더에 들어가기 전에 계정 연결과 캠페인 자료를 준비해 두면 설정 중에 끊기지 않아요. 올바른 Google Ads 계정이 연결되어 있는지, 광고 그룹마다 쓸 랜딩 페이지, 키워드 주제, 광고 문구가 준비되어 있는지 확인하세요.

- 서브 계정에서 **광고 관리자**를 사용할 수 있고, 캠페인을 만드는 사용자도 쓸 수 있는지 확인하세요.
- **광고 관리자**에서 올바른 Google 계정과 사용할 수 있는 Google Ads 계정을 연결하세요.
- 연결한 Google Ads 계정에 광고비를 낼 결제 수단이 등록되어 있는지 확인하세요.
- 만들 광고 그룹마다 랜딩 페이지 기본 URL을 하나씩 준비하세요.
- 관련 있는 긍정 키워드와 제외 키워드를 상품, 서비스, 지역, 검색 의도별로 묶어 두세요.
- 선택한 키워드와 랜딩 페이지에 정확히 맞는 반응형 검색 광고 제목과 설명을 준비하세요.

계정 연결 방법은 [광고 관리자에 Google 연결하기](connect-google-with-ad-manager.md)를 참고하세요.

## 캠페인 구조와 현재 한도

캠페인 빌더는 단계마다 광고 노출의 다른 부분을 설정해요. 어떤 설정이 어느 단계에 속하는지 알아 두면 URL 불일치, 키워드 주제 중복, 미완성 캠페인을 막을 수 있어요.

| 단계 | 설정하는 내용 | 현재 한도 또는 요건 |
| --- | --- | --- |
| 캠페인 | 캠페인 이름, 입찰 전략, 일일 예산, 일정, 네트워크, 타겟 설정, 지원되는 캠페인 단계 에셋 | 광고 그룹이 최소 1개 필요해요. |
| 광고 그룹 | 광고 그룹 이름, 기본 웹사이트 URL, 긍정 키워드, 제외 키워드, 키워드 일치 유형 | 기존의 긍정 키워드 40개, 제외 키워드 40개 제한은 없어졌어요. 키워드 하나는 최대 80자까지 쓸 수 있어요. |
| 광고 | 최종 URL, 표시 경로, 제목, 설명, 반응형 검색 광고 미리보기 | 광고 그룹당 최대 3개이고, 각 그룹에 최소 1개가 필요해요. |

필수 캠페인 구조: 광고 그룹이 최소 1개 있고, 포함된 모든 광고 그룹 안에 광고가 최소 1개 있어야 캠페인을 게시할 수 있어요.

## 키워드, URL, 광고 소재

키워드는 어떤 검색이 광고 그룹과 연결될지 정하고, URL과 광고 소재는 검색한 사람이 무엇을 보고 어디로 이동할지 정해요. 이 요소들을 서로 관련 있게 유지하면 캠페인이 정리되고 리포트도 읽기 쉬워져요.

### 키워드 일치 유형

긍정 키워드와 제외 키워드마다 지원되는 일치 유형을 고를 수 있어요. 검색어가 키워드와 얼마나 가까워야 하는지에 맞춰 선택하세요.

| 일치 유형 | 표시 형태 |
| --- | --- |
| **넓게** | `keyword` |
| **문구** | `"keyword"` |
| **정확히** | `[keyword]` |

### 기본 URL과 표시 경로

기본 웹사이트 URL은 광고 그룹 단위로 정하고, 키워드 추천을 만드는 데 쓰여요. 같은 광고 그룹의 광고는 모두 같은 기본 URL을 써야 해요. 선택 사항인 표시 경로는 광고마다 다르게 쓸 수 있어요. 표시 경로는 2개 구간까지 지원하고, 구간마다 최대 15자까지 입력할 수 있어요.

### 반응형 검색 광고 입력 항목

광고 하나에 제목은 최대 15개(제목당 30자 이내), 설명은 최대 4개(설명당 90자 이내)까지 넣을 수 있어요. **검토 화면**을 열기 전에 빌더에서 필수로 표시된 항목을 모두 채우세요.

## 광고 그룹과 광고 여러 개 설정하기

가장 높은 단계부터 차례로 만들면 모든 광고 그룹이 올바른 캠페인 설정을 이어받고, 모든 광고가 알맞은 키워드 주제와 맞아요. 광고 그룹을 더 만들거나 게시하기 전에 단계마다 내용을 확인하세요.

### 1단계: Google 검색 캠페인 시작하기

**광고 관리자**에서 반응형 검색 광고를 지원하는 Google 캠페인 흐름을 선택해요. 빈 캠페인으로 시작해도 되고, 사용할 수 있는 광고 관리자 템플릿으로 시작해도 돼요. 템플릿 사용법은 [광고 관리자: 템플릿으로 광고 캠페인 만들기](../Ad-Campaign-Creation-and-Management/ad-manager-create-ad-campaigns-using-templates.md)에서 볼 수 있어요.

1. **마케팅 > 광고 관리자**로 이동하세요.
2. **캠페인 만들기**를 클릭하세요.
3. **Google**을 선택하고 **다음**을 클릭하세요.
4. **처음부터 시작**을 선택하거나 사용할 수 있는 광고 관리자 템플릿을 고르세요.

### 2단계: 캠페인 설정하기

캠페인 설정은 캠페인의 모든 광고 그룹이 함께 쓰는 예산, 노출 방식, 타겟을 정해요. 광고 그룹 키워드와 광고를 만들기 전에 이 값들을 확인하세요.

1. 알아보기 쉬운 캠페인 이름을 입력하세요.
2. **Maximize Clicks**(클릭수 최대화) 입찰 전략을 확인하고, 필요하면 최대 CPC 한도를 설정하세요.
3. 일일 예산과 캠페인 기간을 입력하세요.
4. 사용할 수 있는 네트워크 설정을 선택하세요.
5. 지역, 언어를 설정하고, 필요하면 연령이나 성별도 선택하세요.
6. 현재 빌더에 표시되는 다른 필수 캠페인 단계 선언이나 에셋을 모두 입력하세요. 캠페인 단계 에셋은 [광고 관리자: 캠페인 단계에서 Google Ads 추가 에셋 설정하기](ad-manager-configure-google-ads-additional-assets-at-campaign-level.md)에서 자세히 볼 수 있어요.

![캠페인 설정 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546716/original/90DfhStsLGk_SoZxN9FcVfmu4PH5ut-_Ig.png?1789012002)![캠페인 설정 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546725/original/I8yonR1E97JwkhuF0XL1yn6Gz40shDOnBw.png?1789012032)

### 3단계: 첫 번째 광고 그룹 설정하기

광고 그룹 하나는 서로 가까운 키워드와 랜딩 페이지 주제 하나를 나타내야 해요. 그룹에 알아보기 쉬운 이름을 붙이고, 기본 URL을 입력한 뒤, 그 주제와 연결할 키워드를 추가하세요.

1. 캠페인 계층 구조에서 광고 그룹을 선택하세요.
2. **Ad Group Name**(광고 그룹 이름)을 입력하세요.
3. **웹사이트 URL**에 랜딩 페이지를 입력하세요.
4. **Positive Keywords**(긍정 키워드)에 키워드를 여러 개 입력하거나 붙여 넣으세요. 쉼표나 줄 바꿈으로 구분해요. 표시되는 키워드 추천을 써도 돼요.
5. 필요한 일치 유형(**넓게**, **문구**, **정확히**)을 선택하고 **추가**를 클릭해 키워드를 한꺼번에 추가하세요.
6. 관련 없는 검색을 제외하려면 **Negative Keywords**(제외 키워드)에서 같은 과정을 반복하세요. 여러 개를 한꺼번에 입력하면 중복 키워드와 빈 항목은 자동으로 지워져요.

![광고 그룹 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083392651/original/r6eN33zVJnRre2rHcEqQlZoSvhFtz15g-A.png?1792059193)

### 4단계: 광고 만들기

광고는 광고 그룹이 나타내는 검색 의도에 맞아야 하고, 방문자를 같은 기본 URL의 페이지로 안내해야 해요. 정확한 제목과 설명을 여러 개 써서 반응형 검색 광고가 다양한 조합을 만들 수 있게 하세요.

1. 해당 광고 그룹 아래에서 광고를 선택하세요.
2. 광고 그룹의 공통 기본 URL을 사용해 최종 웹사이트 URL을 입력하세요.
3. 필요하면 표시 경로를 추가하세요.
4. 필수 제목 항목을 채우고, 필요하면 한도 안에서 제목을 더 추가하세요.
5. 필수 설명 항목을 채우고, 필요하면 한도 안에서 설명을 더 추가하세요.
6. 표시되는 광고 미리보기를 확인하세요.

![광고 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546741/original/MynyLQAwh60NJO0RkicKOXRetc-gFgk9Fg.png?1789012082)

## 광고 그룹과 광고 관리하기

캠페인 계층 구조에서는 캠페인, 광고 그룹, 광고 단계마다 빠른 관리 메뉴를 쓸 수 있어요. 이 메뉴로 캠페인을 확장하고, 기존 설정을 재사용하고, 초안 요소를 지울 수 있어요. 필요한 최소 구조는 그대로 유지돼요.

### 광고 그룹 추가하기

새 키워드, 랜딩 페이지, 메시지가 별개의 주제라면 광고 그룹을 추가하세요. 계층 구조에서 캠페인의 점 세 개(…) 메뉴를 열고 **Create Ad Group**(광고 그룹 만들기)을 선택하세요.

![광고 그룹 추가 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546750/original/5xyGp7F9mJNO8VtV8c50aY0_z33k8f2lZg.png?1789012098)

### 광고 그룹 관리하기

광고 그룹 메뉴에서는 새 광고를 만들 수 있어요. **중복**으로 선택한 광고 그룹을 복사하거나 **삭제**로 선택한 그룹을 지울 수도 있어요. 캠페인에는 광고 그룹이 최소 1개 필요하므로, 마지막 하나 남은 광고 그룹은 삭제할 수 없어요.

![광고 그룹 관리 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546759/original/X3LkvfDlxMlbM9Hdk7vsRfXkbn1vaJPoyA.png?1789012143)

### 개별 광고 관리하기

광고 메뉴에서는 선택한 광고를 **중복**하거나 **삭제**할 수 있어요. 모든 광고 그룹에 광고가 최소 1개 남아 있어야 하므로, 마지막 하나 남은 광고는 삭제할 수 없어요.

![광고 관리 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546762/original/oETqp3w15t1v65wTPSbHyfd7vTYVERer6g.png?1789012159)

## 캠페인 검토하고 게시하기

**검토 화면**에서는 게시 전에 캠페인 설정과 전체 광고 그룹 계층 구조를 마지막으로 확인할 수 있어요. 각 그룹에 의도한 키워드, 랜딩 페이지 기본 URL, 완성된 광고가 최소 1개 있는지 확인한 뒤 게시하세요.

1. 캠페인 빌더에서 **리뷰**를 클릭하세요.
2. 예산, 일정, 입찰 전략, 네트워크, 지역, 언어, 연령대, 성별 설정을 확인하세요.
3. 계층 구조에서 모든 광고 그룹과 광고를 살펴보세요.
4. 빠졌거나 잘못된 정보가 있으면 해당 단계로 돌아가 고치세요.
5. 캠페인이 완성되면 **게시**를 클릭하세요.

![검토 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546857/original/bbAV-S3911bq2vpXKQshK7icVG7hAA5wgg.png?1789012193)

{% hint style="warning" %}
결제 안내: 광고비는 연결된 Google Ads 계정에 등록된 결제 수단으로 청구돼요. 캠페인을 게시하면 Google의 검토 및 노출 시스템에도 캠페인이 제출돼요.
{% endhint %}

## 캠페인 단계별 성과 확인하기

세분화된 리포트를 보면 성과 차이가 캠페인 전체, 특정 광고 그룹, 개별 광고, 키워드 중 어디에서 나오는지 알 수 있어요. 결과를 비교할 때는 모든 단계를 같은 기간으로 맞추세요.

1. **마케팅 > 광고 관리자**로 이동하세요.
2. **통계**를 여세요.
3. **Google**을 선택하고 기간을 고르세요.
4. 해당 캠페인 이름을 클릭하세요.
5. **광고**, **Ad Groups**(광고 그룹), **키워드** 탭에서 확인할 수 있는 지표를 살펴보세요.

![캠페인 통계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080546858/original/cakjW5ov-HBsPv3w48hSVQpDn2mq9-qQPg.png?1789012205)

지표에 대한 자세한 설명은 [광고 관리자에서 Google 광고 캠페인 통계 보기](how-to-view-google-ad-campaign-statistics-in-ad-manager.md)를 참고하세요.

## 문제 해결

캠페인 빌더 문제는 대부분 계정 접근 권한, 빠진 필수 항목, 잘못된 계층 구조, 광고 그룹 기본 URL과 광고 최종 URL의 불일치 중 하나가 원인이에요. 캠페인을 다시 만들기 전에 해당 단계를 먼저 확인하세요.

| 문제 | 확인할 내용 |
| --- | --- |
| 캠페인을 만들 때 Google을 선택할 수 없어요 | **광고 관리자** 접근 권한, Google 연결, 필요한 권한, 사용할 수 있는 Google Ads 계정을 선택했는지 확인하세요. |
| 키워드 추천이 나타나지 않아요 | 광고 그룹에 접근 가능한 전체 웹사이트 URL을 입력했는지 확인하세요. 키워드는 직접 입력해도 돼요. |
| 광고 URL이 거부돼요 | 광고가 광고 그룹에 정한 기본 URL과 같은 URL을 쓰는지, 최종 랜딩 페이지가 올바른지 확인하세요. |
| **삭제**를 쓸 수 없거나 막혀 있어요 | 캠페인에는 광고 그룹이 최소 1개, 모든 광고 그룹에는 광고가 최소 1개 남아 있어야 해요. |
| **검토 화면**에 미완성 정보가 표시돼요 | 표시된 캠페인, 광고 그룹, 광고 단계를 열어 필수 항목을 모두 채운 뒤 게시하세요. |
| 게시 후 통계가 비어 있어요 | 캠페인과 기간을 확인하고, Google의 캠페인 노출과 리포트 데이터가 채워질 때까지 기다려 보세요. |

## 자주 묻는 질문

### 광고 그룹과 광고는 몇 개까지 만들 수 있나요?
Google 검색 캠페인 하나에는 광고 그룹을 최대 10개까지 만들 수 있고, 광고 그룹마다 광고를 최대 3개까지 만들 수 있어요.

### 키워드는 몇 개까지 추가할 수 있나요?
광고 그룹당 긍정 키워드 40개, 제외 키워드 40개라는 기존 제한은 없어졌어요. 키워드를 하나씩 입력해도 되고, 쉼표나 줄 바꿈으로 구분해 여러 개를 붙여 넣어도 돼요. 중복 키워드와 빈 항목은 자동으로 지워져요.

키워드 하나는 기존 도움말에 안내된 대로 최대 80자까지 쓸 수 있어요.

### 같은 광고 그룹의 키워드에 서로 다른 일치 유형을 쓸 수 있나요?
네. 키워드마다 **넓게**, **문구**, **정확히** 일치 유형을 고를 수 있어요. 해당하는 긍정 키워드와 제외 키워드에도 똑같이 적용돼요.

### 같은 광고 그룹의 광고마다 다른 웹사이트를 쓸 수 있나요?
같은 광고 그룹의 광고는 그 그룹의 공통 기본 URL을 함께 써야 해요. 선택 사항인 표시 경로는 광고마다 다르게 쓸 수 있어요.

### 마지막 광고 그룹이나 광고는 왜 삭제할 수 없나요?
캠페인에는 광고 그룹이 최소 1개 필요하고, 포함된 모든 광고 그룹에는 광고가 최소 1개 필요해요. 마지막 하나를 삭제하기 전에 대신 쓸 항목을 먼저 추가하세요.

### 광고 그룹이나 광고를 복사할 수 있나요?
네. 해당 단계의 점 세 개(…) 메뉴에서 **중복**을 선택한 뒤, 게시하기 전에 복사된 설정을 확인하세요.

### 광고 그룹, 광고, 키워드 성과는 어디에서 비교하나요?
**마케팅 > 광고 관리자 > 통계**를 열고 Google을 선택한 다음 캠페인 이름을 클릭하세요. **광고**, **Ad Groups**(광고 그룹), **키워드** 탭에서 단계별 내역을 볼 수 있어요.

### 광고 관리자 템플릿도 Google 캠페인에 쓸 수 있나요?
네. 사용할 수 있는 광고 관리자 템플릿으로 시작할 수 있어요. 미리 채워진 설정을 모두 확인하고, 게시 전에 계정별로 필요한 정보를 추가하세요. 자세한 내용은 [광고 관리자: 템플릿으로 광고 캠페인 만들기](../Ad-Campaign-Creation-and-Management/ad-manager-create-ad-campaigns-using-templates.md)를 참고하세요.

### Google 광고 캠페인을 스냅샷에 포함할 수 있나요?
네. 지원되는 스냅샷을 만들거나 불러올 때 Google 광고 캠페인 에셋을 선택할 수 있어요. 대상 서브 계정에서 계정별 연결이나 에셋은 다시 선택해야 할 수 있어요. 자세한 내용은 스냅샷에 광고 관리자 포함하기를 참고하세요.
