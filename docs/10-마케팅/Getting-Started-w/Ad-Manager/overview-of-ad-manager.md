# 광고 관리자 개요

하이퍼클래스의 **광고 관리자**(Ad Manager)는 여러 광고 플랫폼의 캠페인을 한곳에서 만들고, 관리하고, 성과까지 확인할 수 있는 도구예요. 에이전시와 서브 계정이 모두 쓸 수 있어요. 디지털 광고 작업을 한곳으로 모아 주고, 에이전시가 고객에게 눈에 보이는 성과를 전달하도록 도와줘요.

## 광고 관리자란?

광고 관리자는 Facebook, Instagram, Google, LinkedIn 광고를 하나의 대시보드에 모아 줘요.

광고 플랫폼을 일일이 오가지 않아도 돼요. 하이퍼클래스 안에서 바로 캠페인을 만들고, 성과를 확인하고, 결과를 개선할 수 있어요. 덕분에 시간이 줄고 작업이 단순해져서, 규모와 상관없이 어떤 비즈니스든 전문적인 광고를 운영하기 쉬워져요.

에이전시와 서브 계정 모두 하이퍼클래스를 벗어나지 않고 성과 좋은 캠페인을 운영하고 분석할 수 있어요.

---

## 지원하는 플랫폼과 캠페인 유형

광고 관리자는 여러 플랫폼과 광고 유형을 지원해요. 아래 표에서 플랫폼별로 쓸 수 있는 캠페인 목표와 광고 형식을 확인하세요.

| 플랫폼 | 캠페인 목표 | 지원하는 광고 형식 |
| --- | --- | --- |
| Meta (Facebook & Instagram) | 리드 생성, 웹사이트 트래픽, 참여, 매출 | 단일 이미지, 동영상, 캐러셀(최대 10개), 리드 폼, 대화 폼 |
| Google Ads | 검색 캠페인, 디맨드 제너레이션(Demand Generation) *(출시 예정)* | 검색 광고, 이미지, 동영상, 캐러셀(Demand Gen) |
| LinkedIn Ads | 리드 생성, 웹사이트 방문 | 단일 이미지, 동영상, 캐러셀, 리드 폼 |

## 광고 관리자로 할 수 있는 일

광고 관리자에서는 캠페인 제작, 관리, 리포팅 도구를 하이퍼클래스 안에서 쓸 수 있어요. 아래 표에서 주요 기능을 확인하세요.

| 기능 | 할 수 있는 일 |
| --- | --- |
| 멀티 플랫폼 광고 관리 | 하이퍼클래스 안에서 Meta(Facebook, Instagram), Google, LinkedIn의 지원되는 광고 캠페인을 만들고 관리해요. |
| 캠페인 만들기 | 지원되는 목표로 캠페인을 만들고, 타겟 오디언스·예산·일정·광고 소재 같은 캠페인 설정을 구성해요. |
| 오디언스 타기팅 | 선택한 광고 플랫폼과 캠페인 유형에서 지원하는 타기팅 옵션을 설정해서 알맞은 오디언스에게 도달해요. |
| 캠페인 템플릿 | 재사용할 수 있는 캠페인 템플릿으로 캠페인 제작을 빠르게 하고, 반복되는 설정을 줄여요. |
| 캠페인 관리 | 지원되는 캠페인을 하이퍼클래스에서 관리해요. 모든 작업을 각 광고 플랫폼에서 직접 처리하지 않아도 돼요. |
| 성과 리포팅 | 광고 관리자 대시보드에서 노출수, 클릭수, 전환수, 지출 같은 캠페인 지표를 확인해요. |
| 캠페인 검토 및 최적화 | 캠페인 성과를 검토하고, 제공되는 인사이트와 추천을 활용해 개선할 부분을 찾아요. |
| 광고 관리자용 AI에게 문의(Ask AI) | AI와 대화하며 캠페인 만들기, 관리, 성과 분석 같은 지원되는 광고 작업을 해요. |
| 광고 관리자 API | 제공되는 API로 캠페인 관리, 연동, 리포팅 작업을 자동화해요. |
| 에이전시 및 서브 계정 관리 | 에이전시와 서브 계정이 하이퍼클래스 안에서 광고 작업을 관리해요. 에이전시는 고객 계정 전반의 접근 권한을 관리해요. |

## 광고 관리자의 주요 장점

광고 관리자는 캠페인 실행을 단순하게 하고, 투명성을 높이고, 측정 가능한 결과를 내도록 도와줘요. 에이전시와 서브 계정 모두에게 도움이 돼요.

- 올인원 광고: Facebook, Instagram, Google, LinkedIn 캠페인을 하나의 대시보드에서 관리해요.
- 시간을 아끼는 워크플로우: 안내에 따라 설정하면 광고를 빠르고 효율적으로 시작할 수 있어요.
- 간편한 타기팅: 목표 중심의 캠페인 목표를 고르면 알맞은 오디언스에 도달할 수 있어요.
- 분명한 ROI: 광고 성과, 지출, 전환 지표를 바로 확인할 수 있어요.
- 성과 중심 운영: 리드 생성, 트래픽, 전환 캠페인을 운영해서 실제 비즈니스 성과로 이어가요.
- 에이전시의 운영 효율: 여러 고객의 캠페인을 매끄럽게 관리해요.
- 재판매 기회: 에이전시는 광고 관리자를 부가 서비스로 서브 계정에 제공하고 수익을 낼 수 있어요.

## 요금과 이용 권한

광고 관리자는 에이전시가 **무료**로 쓸 수 있어요. 서브 계정에 접근 권한을 재판매해서 새 수익원을 만들 수도 있어요.

### 주요 내용

- 에이전시: 광고 관리자 이용권이 추가 비용 없이 포함돼요.
- 서브 계정: 에이전시가 접근 권한을 재판매할지 정하고, 가격도 직접 정해요.
- 수익 관리: 에이전시가 정한 가격이 곧 에이전시의 수익이에요. 하이퍼클래스의 기본 비용은 항상 0달러예요.

에이전시 관리자는 아래 세 곳에서 광고 관리자의 제공 여부와 가격을 관리할 수 있어요.

- **에이전시 > 재판매** 탭: 모든 서브 계정에 적용되는 기본 가격을 정해요.

## 광고 관리자 설정하기

다음 단계를 따르세요. 광고 관리자를 설정하고 캠페인을 시작할 수 있어요.

1. 하이퍼클래스 대시보드에서 **마케팅 > 광고 관리자**로 이동하세요.

   ![마케팅 메뉴의 광고 관리자 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056046202/original/eEM9a6YJnB7QmmkWTKKstaj2q3xRvVPjWQ.png?1760528861)

2. **계정 연결**을 클릭하고, 안내에 따라 Facebook, Instagram, Google, LinkedIn Ads 계정을 연결하세요.
3. 캠페인을 만들고 관리하는 데 필요한 권한이 올바르게 부여되었는지 확인하세요.
4. 플랫폼(Facebook, Instagram, Google, LinkedIn)을 선택해 캠페인을 만드세요.
   - 캠페인 목표를 정하세요. 예를 들면 인지도, 트래픽, 전환, **리드 생성**이 있어요.
   - 타겟 오디언스, 예산, 일정을 설정하세요.
5. 광고 관리자 대시보드에서 노출수, 클릭수, 전환수, 지출 같은 성과 지표를 확인하세요.

### 광고 관리자 시작하기

광고 관리자를 쓸 준비가 되셨나요? 서브 계정에 광고 관리자를 활성화하는 방법, 접근 권한 설정, 재판매 옵션 설정은 단계별 가이드 광고 관리자 활성화 및 재판매 방법에서 확인하세요.

## Meta 비즈니스 포트폴리오 만들기

Facebook을 하이퍼클래스 광고 관리자에 연결하려면 Meta 비즈니스 포트폴리오(예전 이름은 Business Manager), Meta 광고 계정, Facebook 페이지가 필요해요.

Meta 비즈니스 포트폴리오가 없다면 Meta의 공식 가이드에 따라 만드세요. 비즈니스 포트폴리오 생성 과정은 Meta가 관리하고, 설정 화면은 시간이 지나며 바뀔 수 있어요. 최신 단계는 [Meta Business Suite에서 비즈니스 포트폴리오 만들기](https://business.facebook.com/business/help/1710077379203657?id=180505742745347)를 참고하세요.

포트폴리오를 만든 뒤에는 필요한 Facebook 페이지와 광고 계정이 추가되어 있는지, 그리고 알맞은 접근 권한이 있는지 확인하세요.

## 자주 묻는 질문

### 에이전시도 광고 관리자 비용을 내나요?

아니요. 에이전시는 광고 관리자를 무료로 쓸 수 있어요. 서브 계정에 재판매할 수도 있어요.

### 광고 관리자에서 어떤 플랫폼을 쓸 수 있나요?

현재 Facebook, Instagram, Google, LinkedIn Ads를 지원해요.

### 에이전시가 서브 계정 가격을 직접 정할 수 있나요?

네. 에이전시는 **재판매** 탭, 서브 계정의 **재판매** 탭, **SaaS 구성기**에서 가격을 정할 수 있어요.

### 서브 계정은 리포팅을 어디에서 확인하나요?

모든 성과 리포팅은 광고 관리자 대시보드에서 실시간으로 확인할 수 있어요.

### 서브 계정이 광고 예산을 직접 부담하나요?

네. 각 서브 계정이 자기 광고비 예산을 직접 부담해요.
