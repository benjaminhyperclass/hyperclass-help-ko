# 조건부 발송으로 커스텀 필드 기본값 설정하기

이름, 회사, 지역 같은 연락처 정보를 이메일에 넣으면 참여율을 높이는 데 도움이 돼요. **이름** 같은 커스텀 필드가 비어 있을 때 **조건부 발송**(Conditional Sending)을 쓰면 기본값을 대신 보여 줄 수 있어서, 이메일이 항상 깔끔하게 나가요.

## 조건부 발송이란?

**조건부 발송**은 연락처의 커스텀 필드 데이터에 따라 콘텐츠 블록을 보여 주거나 숨기는 기능이에요. 수신자마다 이메일 내용을 다르게 구성할 수 있고, **이름** 같은 필드가 비어 있으면 기본값을 대신 보여 줄 수 있어요.

## 장점

- 전문성: 인사말이나 본문에 빈칸이나 누락된 정보가 보이지 않아요.
- 개인화: 일부 데이터가 없어도 수신자마다 알맞고 친근한 인사말을 볼 수 있어요.
- 일관성: 데이터 상태와 관계없이 모든 이메일의 모양과 분위기를 똑같이 유지해요.
- 높은 참여율: 개인화된 이메일은 더 많이 열어 보고 읽어요.

## 설정 방법

**예시 목표:**
**이름**이 있으면 "{{contact.first_name}}님, 안녕하세요."를, 없으면 "고객님, 안녕하세요."를 보여 줍니다.

1. **조건부 발송**을 켜요.
   - 콘텐츠 블록의 사이드바에서 **조건부 발송** 토글을 켜세요.
2. 개인화된 인사말을 설정해요.
   - 텍스트 블록을 추가하고 아래 내용을 입력하세요.

     `{{contact.first_name}}님, 안녕하세요.`
   - **조건 설정** 아래에서 다음과 같이 선택하세요.
     - **커스텀 필드 선택**: "이름"
     - **Condition**(조건): "다음과 같지 않음"
     - **Value**(값): 비워 두세요.
   - 이 블록은 **이름**이 비어 있지 않을 때만 보여요.
3. 기본 인사말을 설정해요.
   - 텍스트 블록을 하나 더 추가하고 아래 내용을 입력하세요.

     `고객님, 안녕하세요.`
   - **조건 설정** 아래에서 다음과 같이 선택하세요.
     - **커스텀 필드 선택**: "이름"
     - **Condition**(조건): "다음과 같음"
     - **Value**(값): 비워 두세요.
   - 이 블록은 **이름**이 비어 있을 때만 보여요.
4. 미리 보고 테스트해요.
   - **미리보기**로 **이름**이 있는 연락처와 없는 연락처에게 이메일이 어떻게 보이는지 확인하세요.

## 제한 사항

- 콘텐츠 블록 하나에서 **조건부 발송**에 쓸 수 있는 커스텀 값은 하나뿐이에요.
- 한 블록이나 섹션 안에서 같은 필드에 조건을 여러 개 설정할 수 없어요.

## 팁

{% hint style="info" %}
- 조건이 제대로 동작하는지 항상 테스트용 연락처로 미리 확인하세요.
- 기본값은 친근하고 분명한 문구로 정하면 전문적인 느낌을 줄 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 이름 외의 다른 필드에도 조건부 발송을 쓸 수 있나요?
네, 추가한 모든 커스텀 필드에 같은 방법을 쓸 수 있어요.

### 한 블록에 커스텀 필드를 여러 개 쓸 수 있나요?
아니요, 콘텐츠 블록 하나에는 커스텀 값을 하나만 쓸 수 있어요.

### 값을 입력하세요 칸을 비워 두면 어떻게 되나요?
조건이 필드가 비어 있는지 아닌지를 확인해요. 이를 이용해 상황에 맞게 콘텐츠를 보여 주거나 숨길 수 있어요.

### 기본값을 원하는 문구로 정할 수 있나요?
네, 브랜드에 어울리도록 기본 메시지를 자유롭게 바꿀 수 있어요.
