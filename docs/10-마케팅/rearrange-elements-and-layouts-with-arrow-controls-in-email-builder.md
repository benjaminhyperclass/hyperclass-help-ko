# 이메일 빌더에서 화살표로 요소와 레이아웃 순서 바꾸기

**이메일 빌더**에서 화살표 컨트롤을 사용해 요소와 레이아웃의 순서를 빠르게 바꾸는 방법을 안내해요. 복잡한 드래그 앤 드롭 없이 클릭만으로 이메일을 편집할 수 있어요.

## 화살표 컨트롤 기능이란?

화살표 컨트롤은 요소나 레이아웃 섹션을 클릭 한 번으로 위나 아래로 옮기는 기능이에요. 정확한 위치에 맞춰 드래그하지 않아도 되므로, 이메일 캠페인과 템플릿을 더 수월하게 만들 수 있어요.

![이메일 빌더의 화살표 컨트롤](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049547347/original/aa_V0boJnVpOLw9NncPtzSWk4NaRjKh85A.png?1751999067)

## 화살표 컨트롤의 장점

이메일을 디자인할 때 더 부드럽고 편하게 작업할 수 있어요.

- 레이아웃 순서를 더 빠르게 바꿀 수 있어요.
- 드래그 앤 드롭에만 의존하지 않고 요소를 옮길 수 있어요.
- 블록을 잘못 놓아서 생기는 디자인 실수를 줄여 줘요.
- 처음 이메일을 만드는 사용자도 쉽게 쓸 수 있어요.
- 클릭 한 번으로 레이아웃을 정확하게 조정할 수 있어요.
- 개별 요소와 레이아웃 블록 전체에 모두 쓸 수 있어요.

## 화살표 컨트롤로 레이아웃 순서 바꾸기

화살표 컨트롤을 쓰면 이메일 안의 콘텐츠 블록 위치를 더 빠르고 정확하게 바꿀 수 있어요.

1. 왼쪽 메뉴에서 **이메일 마케팅**(Email Marketing)을 선택하세요.
2. 기존 템플릿을 열거나 새 캠페인을 만드세요.
3. 옮기려는 요소(예: 텍스트, 이미지)나 레이아웃 블록 위에 마우스를 올리세요.
4. 섹션 왼쪽 위 근처에 나타나는 위(↑) 또는 아래(↓) 화살표를 클릭하세요.
5. 요소나 레이아웃이 바로 새 위치로 이동해요.

![화살표로 레이아웃을 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082951784/original/Wo1LJUrH_EhSQ8NRsTyHvKIUyxycw7Sy0A.png?1791549884)

## 요소와 레이아웃의 화살표 컨트롤 차이

요소와 레이아웃이 어떻게 다른지 알면 화살표를 더 잘 쓸 수 있어요.

화살표 컨트롤은 아래 두 가지에 모두 나타나요.

- 요소: 텍스트 블록, 버튼, 이미지처럼 개별 구성 요소예요. 화살표를 누르면 현재 레이아웃 안에서 위치가 바뀌어요.
- 레이아웃: 머리글, 본문, 바닥글처럼 더 큰 섹션이에요. 화살표를 누르면 이메일 전체 디자인 안에서 섹션 전체가 위나 아래로 이동해요.

## 자주 묻는 질문

### 이동할 때마다 저장해야 하나요?
아니요. 변경 사항은 작업하는 대로 자동 저장돼요.

### 드래그 앤 드롭도 계속 쓸 수 있나요?
네. 화살표 컨트롤은 기존 방식을 대체하는 기능이 아니라 보완하는 기능이에요. 새 화살표와 함께 드래그 앤 드롭도 그대로 쓸 수 있어요.

### 모바일에서도 화살표 컨트롤을 쓸 수 있나요?
현재는 데스크톱에서 쓰기에 맞게 만들어져 있어요.

### 화살표가 나타나지 않아요. 어떻게 하나요?
마우스를 이동할 수 있는 요소나 레이아웃 바로 위에 올렸는지 확인하세요. 그래도 보이지 않으면 편집기를 새로고침하거나 브라우저를 최신 버전으로 업데이트했는지 확인해 보세요.

## 다음 단계

- 지금 템플릿을 편집하면서 화살표 컨트롤을 써 보세요.
- 화살표 이동과 드래그 앤 드롭을 함께 써 보면서 더 편한 방법을 찾아보세요.
- 레이아웃 블록이 어떻게 동작하는지 알아 두면 이메일 구조를 더 잘 계획할 수 있어요.
