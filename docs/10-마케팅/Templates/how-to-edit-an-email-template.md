# 이메일 템플릿 편집하기

이미 만들어 둔 이메일 템플릿의 문구, 이미지, 레이아웃을 수정하는 방법을 안내해요. 템플릿을 고치고 저장한 뒤, [미리보기와 테스트](../../09-이메일/기타/preview-and-test-your-email-campaign-templates.md)까지 하고 나서 사용하세요.

하이퍼클래스의 이메일 템플릿을 쓰면 매번 같은 디자인을 처음부터 만들지 않아도 돼요. 일관되고 전문적인 이메일을 보낼 수 있어요. 기존 템플릿을 편집해서 내용을 바꾸고, 이미지를 교체하고, 레이아웃을 조정하고, 브랜드의 모습을 유지하세요. 하이퍼클래스의 **이메일 빌더**는 캠페인과 대상에 맞게 템플릿을 수정하는 도구를 제공해요.

## 이메일 템플릿 편집이란?

이메일 템플릿 편집은 이미 있는 템플릿의 내용, 화면 스타일, 레이아웃을 처음부터 다시 만들지 않고 수정하는 작업이에요. 템플릿에는 머리글, 바닥글, 문자, 이미지, 버튼, 브랜딩처럼 다시 쓸 수 있는 요소를 넣을 수 있어요. 기존 템플릿을 수정하면 이메일의 일관성을 유지하면서 캠페인이나 비즈니스 상황에 맞게 내용을 바꿀 수 있어요.

하이퍼클래스의 **이메일 빌더**는 **디자인 에디터**로 시각적인 편집을 지원해요. 코드를 작성하지 않고도 요소를 하나씩 수정하고 이메일 레이아웃을 배치할 수 있어요.

---

## 이메일 템플릿을 편집하면 좋은 점

기존 템플릿을 편집하면 새 이메일을 만드는 시간을 줄이면서 브랜드의 일관성을 유지할 수 있어요. 템플릿을 재사용하고 업데이트하면 메시지를 최신 상태로 유지하기 쉽고, 받는 사람에게도 일관된 경험을 줄 수 있어요.

- 시간 절약: 새 이메일을 처음부터 디자인하지 않고 기존 이메일 템플릿을 업데이트해요.
- 브랜드 일관성 유지: 이메일 전반에서 로고, 색상, 글꼴, 레이아웃을 통일해요.
- 콘텐츠 맞춤 수정: 문구, 이미지, 버튼 등 요소를 캠페인이나 대상에 맞게 바꿔요.
- 이메일 디자인 개선: 간격, 정렬, 레이아웃을 조정해 보기 좋은 이메일을 만들어요.
- 기존 디자인 재사용: 이후 캠페인에도 맞춰 쓸 수 있는 이메일 레이아웃을 만들어 둬요.
- 오류 감소: 수정한 템플릿을 미리 보고 테스트해서 서식 문제, 잘못된 링크, 빠진 내용을 발송 전에 찾아내요.

## 이메일 템플릿 편집 옵션

**이메일 빌더**에는 이메일 템플릿을 수정하는 여러 도구가 있어요. 어떤 옵션이 있는지 알아 두면 내용, 화면 스타일, 구조를 바꿀 때 알맞은 도구를 고르기 쉬워요.

아래 옵션은 **디자인 에디터**로 템플릿을 편집할 때 쓸 수 있어요.

### 문구와 콘텐츠 편집

**문자** 요소로 제목, 설명, 프로모션 메시지, 행동 유도 문구 같은 글을 수정할 수 있어요.

할 수 있는 작업은 다음과 같아요.

- 이메일 레이아웃에서 기존 문구를 바로 편집해요.
- 글꼴 스타일, 문자 정렬, 서식을 조정해요.
- 내용이 더 필요하면 새 문자 요소를 추가해요.
- 지원되는 커스텀 값을 넣어 이메일 내용을 개인화해요.

### 이미지와 브랜딩 편집

**이미지** 요소와 로고 요소로 이메일마다 비즈니스의 시각적 정체성을 유지할 수 있어요.

할 수 있는 작업은 다음과 같아요.

- 기존 이미지를 새 이미지로 교체해요.
- 로고, 배너, 프로모션 이미지를 추가해요.
- 지원되는 이미지 설정과 정렬을 조정해요.
- 비즈니스의 현재 스타일에 맞게 브랜딩을 업데이트해요.

### 버튼과 링크 편집

**버튼**은 받는 사람이 예약하기, 웹사이트 방문, 오퍼 확인 같은 행동을 하도록 이끌어요.

할 수 있는 작업은 다음과 같아요.

- 버튼 레이블을 수정해요.
- 연결된 URL을 변경해요.
- 버튼의 모양과 정렬을 조정해요.
- 이메일의 다른 위치에 버튼을 추가해요.

### 레이아웃과 화면 스타일 편집

레이아웃과 화면 스타일 설정으로 이메일 내용을 정리하고 읽기 편한 이메일을 만들 수 있어요.

할 수 있는 작업은 다음과 같아요.

- 이메일 요소를 추가하거나 순서를 바꿔요.
- 콘텐츠 블록 사이의 간격을 조정해요.
- **Divider**(구분선)나 **Spacer**(여백)를 추가해요.
- 지원되는 레이아웃과 화면 스타일 설정을 수정해요.
- 화면 크기별로 이메일이 어떻게 보이는지 확인해요.

{% hint style="info" %}
쓸 수 있는 설정은 선택한 요소와, 이메일을 만들 때 사용한 에디터에 따라 달라요. 지원되는 요소를 자세히 알고 싶다면 [이메일 빌더의 다양한 요소](../Email-Builder-Capabilities/different-elements-in-email-builder.md)를 참고하세요.
{% endhint %}

## 이메일 템플릿 편집하는 방법

기존 이메일 템플릿을 편집하면 다시 쓸 수 있는 구조는 그대로 두고 내용과 디자인만 바꿀 수 있어요. 올바른 순서로 편집하고 저장해야 이후 이메일 캠페인에서 템플릿을 쓸 때 변경 사항이 반영돼요.

1. 왼쪽 메뉴에서 **마케팅**을 클릭한 다음 **이메일**로 이동하세요.
2. **템플릿** 탭을 선택하고 편집할 템플릿을 찾으세요.

   ![이메일 템플릿 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083531782/original/a6lVuLsr4rEWPs-qScaF-Zp5O9NEoX56YQ.png?1792162591)
3. 기존 템플릿을 둘러보거나 검색 기능으로 원하는 템플릿을 찾으세요.
4. 템플릿이 **이메일 빌더**에서 열리면 수정할 요소를 선택하세요.5. 템플릿을 클릭해서 **이메일 빌더**에서 여세요.

   ![이메일 빌더에서 열린 템플릿](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083532254/original/b3cbAgKOYXcN6J6ttjrQIAD8NT5u5cALMw.png?1792162799)
6. 기존 **문자** 요소를 클릭해서 내용과 서식을 편집하세요.
7. **이미지** 요소를 선택해서 이미지나 표시 설정을 수정하세요.
8. **버튼** 요소를 클릭해서 레이블, 링크, 모양을 수정하세요.
9. 이메일에 필요한 다른 내용도 수정하세요.

   ![이메일 내용을 수정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083532322/original/2xTAxzLO5yERtiVULEQabM_XElasVyPaYA.png?1792162838)
10. **요소 추가** 패널을 열어 쓸 수 있는 콘텐츠 요소를 확인하세요.
11. 원하는 요소를 이메일 캔버스로 끌어다 놓으세요.
12. 추가한 요소를 클릭해서 내용, 스타일, 설정을 수정하세요.
13. 기존 요소를 원하는 위치로 끌어서 순서를 바꾸세요.
14. 전체 스타일을 조정하려면 **화면 스타일** 설정을 사용하세요(해당하는 경우).

    ![화면 스타일 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083532625/original/2ISTN9VWUY_KdYzzVWudXbRVEjMXSlp3NQ.png?1792162989)
15. 템플릿에서 변경한 내용을 확인하세요.
16. 수동 저장 옵션이 있으면 **Save Template**(템플릿 저장)을 클릭해서 수정한 템플릿을 저장하세요.

## 자주 묻는 질문

### 변경하기 전에 이메일 템플릿을 복제할 수 있나요?

기존 디자인은 그대로 두고 다른 버전을 만들고 싶을 때 템플릿을 복제하면 편해요. 템플릿의 작업 메뉴에서 쓸 수 있는 옵션을 확인해 보세요. 복제 옵션이 있다면 편집하기 전에 사본을 만들어서 원본 템플릿을 남겨 두세요.

### 이메일 템플릿의 이전 버전을 복구할 수 있나요?

네. 하이퍼클래스의 **이메일 빌더**는 저장된 버전을 확인하고 복원할 수 있는 **버전 기록**을 지원해요(기능을 쓸 수 있는 경우). 이메일 에디터를 열고 **버전 기록**에서 쓸 수 있는 버전을 확인하세요.

### 여러 팀원이 같은 이메일 템플릿을 편집할 수 있나요?

필요한 계정 권한이 있는 **팀원**은 같은 템플릿에 접근할 수 있어요. 변경 사항을 덮어쓰는 일을 줄이려면 편집을 서로 조율하고, 크게 수정하기 전에 가장 최근에 저장된 버전을 확인하세요.

### 이메일 템플릿을 편집하면 연락처에게 이메일이 자동으로 발송되나요?

아니요. 템플릿을 편집하고 저장하는 것만으로는 이메일 캠페인이 발송되지 않아요. 발송하려면 별도의 캠페인이나 알맞게 설정된 워크플로우가 필요해요.

### 원본 버전은 그대로 두고 템플릿을 편집할 수 있나요?

복제나 다른 이름으로 저장 옵션이 있는 경우, 별도의 버전을 만들어 원본을 보존할 수 있어요. 워크플로우 안에서 템플릿을 편집할 때는 계속 동기화(continuous synchronization)를 꺼 두면, 워크플로우에서만 바꾼 내용이 원본 템플릿에 자동으로 반영되지 않아요. 자세한 내용은 [워크플로우 단계에서 이메일 템플릿 관리하기](../Workflow-Email-Action/managing-email-templates-in-workflow-steps.md)를 참고하세요.
