# 화이트라벨 이메일 템플릿 공유 가이드

에이전시 전용 브랜드 URL로 이메일 템플릿을 공유하는 방법을 안내해요. 받는 사람은 링크를 열어 템플릿을 자신의 서브 계정으로 가져오고, 디자인을 처음부터 다시 만들 필요가 없어요.

에이전시의 화이트라벨 도메인을 쓰면 고객이나 팀원에게 템플릿을 공유할 때도 일관된 브랜드 경험을 줄 수 있어요. 이 문서에서는 공유 링크를 만들고, 브랜드 URL로 바꾸고, 템플릿을 가져오는 과정을 차례로 설명해요.

## 화이트라벨 이메일 템플릿 공유란?

기존 이메일 템플릿의 공유 ID(Share ID)로 URL을 만들어, 에이전시에 설정된 화이트라벨 앱 도메인으로 열리게 하는 기능이에요. 이 URL을 열면 공유된 템플릿으로 연결되고, 사용할 수 있는 대상 서브 계정에 복사본을 추가할 수 있어요.

기본 이메일 템플릿 공유 링크는 다음과 같은 모습이에요.

`https://SHARE-DOMAIN/?fp_ref=xxxx&email_template_share=6438b5b145411d0ce4332f1b`

같은 템플릿을 아래와 같은 브랜드 URL로 공유할 수 있어요.

`https://app.yourdomain.com/emails/share/6438b5b145411d0ce4332f1b`

두 링크는 같은 이메일 템플릿을 가리켜요. 브랜드 URL은 에이전시의 앱 도메인을 사용한다는 점만 달라요.

## 화이트라벨 이메일 템플릿 공유의 장점

에이전시의 브랜드 도메인으로 이메일 템플릿을 공유하면 재사용할 수 있는 이메일 디자인을 쉽게 나눠 주면서 고객에게 보이는 화면도 일관되게 유지할 수 있어요. 캠페인을 일일이 다시 만들거나 HTML 파일을 전달하는 대신, 권한이 있는 사용자가 링크 하나로 편집 가능한 템플릿을 공유해요.

- 일관된 에이전시 브랜딩: 공유 링크에 에이전시의 화이트라벨 앱 도메인이 표시돼 브랜드 경험이 통일돼요.
- 간편한 템플릿 배포: 서브 계정마다 템플릿을 다시 만들 필요 없이, 대상 사용자에게 링크로 공유할 수 있어요.
- 빠른 템플릿 재사용: 받는 사람이 기존 이메일 디자인을 가져와 자신의 캠페인에 맞게 고칠 수 있어요.
- 편집 가능한 이메일 템플릿: 받는 사람은 고정된 HTML 파일이 아니라 하이퍼클래스 이메일 편집기에서 가져온 템플릿을 바로 편집할 수 있어요.
- 유연한 공유 권한: 제공되는 공유 접근 설정으로 공유 링크를 열 수 있는 사람을 정할 수 있어요.
- 수작업 감소: 사용할 수 있는 서브 계정 전반에서 기존 레이아웃, 디자인, 콘텐츠를 재사용해 반복 설정을 줄여요.

## 이메일 템플릿 공유 링크 이해하기

이메일 템플릿 공유 링크에는 공유 ID(Share ID)라는 고유 식별자가 들어 있어요. 이 ID가 받는 사람이 열어야 할 템플릿을 알려 줘요. 공유 ID가 브랜드 URL에서 어디에 들어가는지 알면 원본 템플릿을 건드리지 않고 정확한 링크를 만들 수 있어요.

### 기본 이메일 템플릿 공유 링크

생성된 기본 링크는 다음과 같아요.

`https://SHARE-DOMAIN/?fp_ref=xxxx&email_template_share=6438b5b145411d0ce4332f1b`

`email_template_share=` 파라미터가 공유된 이메일 템플릿을 가리켜요.

이 예시에서 공유 ID는 다음과 같아요.

`6438b5b145411d0ce4332f1b`

### 화이트라벨 이메일 템플릿 공유 링크

브랜드 링크는 아래 형식으로 만들어요.

`https://YOUR-WHITELABEL-DOMAIN/emails/share/SHAREID`

각 부분을 이렇게 바꿔 주세요.
`YOUR-WHITELABEL-DOMAIN`: 에이전시의 화이트라벨 데스크톱 앱에 설정된 전체 호스트 이름이에요. 예: `app.yourdomain.com``SHAREID`: 원래 템플릿 공유 링크에서 복사한 고유 식별자예요.

예시:

`https://app.yourdomain.com/emails/share/6438b5b145411d0ce4332f1b`

{% hint style="warning" %}
기본 공유 URL 전체가 아니라 공유 ID 값만 복사하세요. 브랜드 링크를 만들 때는 `/emails/share/` 경로를 그대로 유지해야 해요.
{% endhint %}

## 화이트라벨 이메일 템플릿 공유 설정하기

브랜드 이메일 템플릿 공유 링크는 원본 템플릿 링크를 만들고, 그 링크에서 공유 ID를 뽑아낸 뒤, 에이전시의 화이트라벨 앱 도메인과 합치는 순서로 만들어요. 순서대로 따라 하면 만들어진 URL이 원하는 이메일 템플릿을 정확히 가리켜요.

1. 하이퍼클래스에서 해당 서브 계정을 여세요.
2. **마케팅 > 이메일 > 템플릿**으로 이동하세요.
3. 공유할 이메일 템플릿을 찾으세요.
4. 템플릿 옆의 점 세 개(⋮) 메뉴를 클릭하세요.
5. **공유**를 선택하세요.

   ![템플릿의 점 세 개 메뉴에서 공유 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083527024/original/Ur2uIpgQ7Ol-eVrV9-jfW5ccfTFa6wTCTg.png?1792160351)
6. **템플릿 공유** 창에서 알맞은 공유 접근 옵션을 선택하세요.
7. 생성된 템플릿 공유 링크를 복사하세요.

   ![생성된 템플릿 공유 링크 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083527087/original/nio8xWiBEQeOADe_g1vh4zjvc2-rN8xa0g.png?1792160397)

사용할 수 있는 공유 옵션에 따라 에이전시 내부로 접근을 허용하거나, 링크가 있는 모든 사람에게 허용할 수 있어요.

### 공유 ID 추출하기

생성된 링크에는 공유할 이메일 템플릿을 구분하는 고유 공유 ID가 들어 있어요.

1. 복사한 URL을 텍스트 편집기 등 전체 링크를 확인할 수 있는 곳에 붙여넣으세요.
2. `email_template_share=` 파라미터를 찾아요.
3. 등호(=) 바로 뒤에 있는 식별자를 복사하세요.
4. 다른 URL 파라미터나 관련 없는 문자는 포함하지 않아요.

예를 들어 아래 링크가 있다고 해 볼게요.

`https://SHARE-DOMAIN/?fp_ref=xxxx&email_template_share=6438b5b145411d0ce4332f1b`

이 링크의 공유 ID는 `6438b5b145411d0ce4332f1b`예요.

### 화이트라벨 공유 링크 만들기

공유 ID를 구했다면 에이전시에 설정된 화이트라벨 앱 도메인과 합치세요.

1. 아래 URL 형식을 복사하세요.

   `https://YOUR-WHITELABEL-DOMAIN/emails/share/SHAREID`
2. `YOUR-WHITELABEL-DOMAIN`을 실제로 설정한 앱 호스트 이름으로 바꿔요.
3. `SHAREID`를 앞에서 추출한 공유 ID로 바꿔요.4. 최종 URL에 올바른 사용자 지정 도메인, `/emails/share/` 경로, 공유 ID가 모두 들어 있는지 확인해요.

예시:

`https://app.yourdomain.com/emails/share/6438b5b145411d0ce4332f1b`

{% hint style="warning" %}
호스트 이름은 에이전시의 화이트라벨 앱에 설정된 도메인과 같아야 해요. 설정한 호스트 이름에 이미 `app.`이 들어 있다면 `app.`을 한 번 더 붙이지 마세요.
{% endhint %}

### 브랜드 링크 공유하기

브랜드 URL을 만들었다면 이메일 템플릿을 가져와야 하는 사용자에게 전달하세요.

1. 완성된 화이트라벨 URL을 복사하세요.
2. 브라우저에서 링크를 열어 의도한 템플릿 공유 화면으로 연결되는지 확인하세요.
3. 원하는 소통 채널로 받는 사람에게 URL을 보내세요.
4. 받는 사람에게 링크를 열고 가져오기 단계를 따라 달라고 안내해요.

받는 사람은 해당 공유 권한을 충족해야 하고, 사용할 수 있는 대상 서브 계정에 접근할 수 있어야 해요.

### 공유된 이메일 템플릿 가져오기

링크를 열면 사용 자격이 있는 받는 사람이 공유된 템플릿을 대상 서브 계정에 추가할 수 있어요. 가져오면 받는 사람의 이메일 캠페인에 맞게 고칠 수 있는 편집 가능한 복사본이 만들어져요.

1. 공유된 이메일 템플릿 링크를 여세요.
2. **템플릿 추가**를 선택하세요.
3. 필요하면 템플릿 이름을 입력하거나 수정해요.
4. **대상 서브 계정 선택**에서 대상 서브 계정(또는 사용 가능한 위치)을 선택하세요.
5. **템플릿 복제**를 클릭하세요.
6. 대상 서브 계정을 여세요.
7. **마케팅 > 이메일 > 템플릿**으로 이동해 가져온 템플릿을 찾으세요.

에이전시 간 템플릿 공유 문서에는 복제할 때 최대 3개의 위치를 선택할 수 있다고 안내되어 있어요. 실제로 선택할 수 있는 대상은 사용자의 접근 권한과 적용되는 공유 방식에 따라 달라요.

자세한 내용은 [에이전시 간 이메일 템플릿 공유](share-email-template-across-agencies.md)를 참고하세요.

## 자주 묻는 질문

### 화이트라벨 앱 도메인을 설정하지 않고도 화이트라벨 공유 링크를 만들 수 있나요?

기본 템플릿 공유 링크는 쓸 수 있어요. 하지만 에이전시 도메인을 쓰는 브랜드 링크를 만들려면 정상적으로 동작하는 화이트라벨 앱 도메인이 필요해요. 브랜드 URL을 만들기 전에 도메인을 먼저 설정하고 인증하세요. 설정 방법은 [화이트라벨 데스크톱 웹 앱 도메인 설정](../../25-애드온-세일즈/Whitelabel-Desktop-App/how-to-set-up-a-whitelabel-domain-for-the-desktop-web-app.md)을 참고하세요.

### 이메일 템플릿 공유에 API/브랜드 링크 도메인을 써도 되나요?

문서에 안내된 URL 형식은 화이트라벨 데스크톱 앱 도메인을 사용해요. API/브랜드 링크 도메인은 용도가 달라서, 하이퍼클래스에서 해당 설정을 명시적으로 지원하지 않는 한 대신 쓰지 마세요. 도메인 유형별 차이는 [하이퍼클래스 도메인 유형 설정](../../06-사이트/일반-설정/how-to-set-up-different-domain-types-in-hyperclass-websites-email-wordpress-more.md)을 참고하세요.

### 브랜드 링크를 만들면 원본 이메일 템플릿이 바뀌나요?

아니요. 브랜드 URL을 만들어도 이미 공유된 템플릿에 접근하는 방식만 달라질 뿐, 원본은 바뀌지 않아요. 받는 사람은 공유 과정을 거쳐 복사본을 가져와요.

### 어떤 사용자에게는 공유 옵션이 보이고 다른 사용자에게는 안 보이는 이유가 뭔가요?

공유 기능을 쓸 수 있는지는 사용자 역할과 권한에 따라 달라요. 지정된 역할을 확인하고, 이메일 템플릿 공유 기능에 접근할 수 있는지 확인하세요.

### 같은 템플릿을 여러 사람에게 공유할 수 있나요?

공유 링크를 접근 설정에서 허용된 받는 사람들에게 배포할 수 있어요. 각 받는 사람은 사용할 수 있는 대상에 템플릿을 가져올 수 있는 적절한 접근 권한이 있어야 해요.

### 가져온 이메일 템플릿에 카운트다운 타이머가 작동하지 않아요.

공유된 이메일 템플릿을 다른 서브 계정으로 복사하면 카운트다운 타이머가 플레이스홀더로 바뀌어요. 가져온 템플릿을 쓰기 전에 대상 서브 계정에서 타이머를 선택하거나 새로 만드세요. 자세한 내용은 [카운트다운 타이머 플레이스홀더](../카운트다운-타이머/countdown-timer-placeholder.md)를 참고하세요.

### 가져온 템플릿을 수정할 수 있나요?

네. 템플릿을 복제한 뒤 대상 서브 계정의 이메일 편집기에서 가져온 복사본을 열어 내용이나 디자인을 수정할 수 있어요. 수정 방법은 [이메일 템플릿 편집하기](how-to-edit-an-email-template.md)를 참고하세요.

### 화이트라벨 이메일 템플릿 공유와 템플릿 라이브러리 배포는 같은 기능인가요?

아니요. 화이트라벨 공유는 브랜드 URL로 이메일 템플릿 하나를 배포하는 방식이에요. **템플릿 라이브러리** 배포는 별도의 게시 및 접근 방식을 사용해요.
