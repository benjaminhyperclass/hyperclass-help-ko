# Mailchimp 이메일 템플릿을 하이퍼클래스 디자인 에디터로 가져와 편집하기

기존에 만들어 둔 Mailchimp 이메일 템플릿을 하이퍼클래스 **디자인 에디터**로 가져와서, 코드 없이 눈으로 보며 편집하는 방법을 안내해요. 가져오기 과정과 Mailchimp 레이아웃이 편집 가능한 콘텐츠 블록으로 바뀌는 방식도 함께 설명해요.

## Mailchimp 이메일 템플릿 가져오기란

Mailchimp에서 이미 디자인해 둔 이메일 레이아웃을 하이퍼클래스 **디자인 에디터**로 가져오는 기능이에요. 처음부터 다시 만들 필요 없이, 기존 디자인을 하이퍼클래스의 드래그 앤 드롭 화면에서 그대로 편집할 수 있어요.

템플릿을 가져오면 하이퍼클래스가 Mailchimp 디자인의 구조(헤더, 이미지, 텍스트 블록 등)를 자동으로 인식해서 편집 가능한 요소로 바꿔 줘요. 코드를 쓰거나 고치지 않아도 내용과 레이아웃을 수정하고, 브랜드의 일관성도 유지할 수 있어요.

## 가져오기의 주요 장점

- 템플릿 재사용: 기존 Mailchimp 이메일 디자인을 다시 만들지 않고 하이퍼클래스로 가져올 수 있어요.
- 코드 없는 시각적 편집: 드래그 앤 드롭 방식의 **디자인 에디터**에서 코딩 없이 이메일을 수정하고 맞춤 설정할 수 있어요.
- 플랫폼이 달라도 같은 브랜드 느낌: Mailchimp 템플릿에서 쓰던 익숙한 레이아웃, 글꼴, 색상 구성을 그대로 이어서 쓸 수 있어요.
- 더 빠른 캠페인 제작: 이미 디자인된 템플릿을 편집 가능한 하이퍼클래스 버전으로 바꿔서 빠르게 수정하고 발송할 수 있어요.

## 가져와서 편집하는 방법

1. 왼쪽 메뉴에서 **마케팅 > 이메일 > 템플릿**으로 이동하세요. 이 화면에는 지금까지 만든 이메일 템플릿이 모두 보이고, 여러 방법으로 새 템플릿을 만들 수 있어요.

   ![이메일 템플릿 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056894975/original/OYe3DEtySJVLcWGjC7Gu9wK-Msk5VizXuQ.png?1761563083)

2. 오른쪽 위의 **신규** 버튼을 클릭하고, 드롭다운 메뉴에서 **이메일 가져오기**를 선택하세요. Mailchimp 같은 외부 서비스의 이메일 템플릿을 가져올 때 쓰는 메뉴예요.

   ![신규 버튼의 드롭다운 메뉴에서 이메일 가져오기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056895037/original/A2k50IEVFH5Y2q-sc0cJnfolgtI1Un3B7g.png?1761563100)

3. **Import Email Templates**(이메일 템플릿 가져오기) 팝업에서 **다음에서 가져오기** 드롭다운을 열고 Mailchimp를 선택하세요. 그러면 Mailchimp 계정의 캠페인 레이아웃을 가져올 준비를 해요.

   ![다음에서 가져오기 드롭다운에서 Mailchimp 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056895099/original/b_cJmap4szvRsDbQchnUGKjj-8QtICsIYA.png?1761563119)

4. Mailchimp 계정에서 캠페인 URL을 복사해서 **URL** 필드에 붙여 넣으세요. 하이퍼클래스는 이 URL로 Mailchimp 캠페인의 구조를 가져와 편집할 수 있게 다시 만들어요.

   ![URL 필드에 Mailchimp 캠페인 URL 붙여 넣기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056895207/original/Gt4XvZflpbNcACydm3BdiF4zxfFg_BZSWg.png?1761563140)

5. **템플릿 이름** 필드에 가져올 템플릿의 이름을 알아보기 쉽게 입력하세요. 나중에 템플릿 목록에서 찾아 편집하기 편해요.

   ![템플릿 이름 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056895266/original/mpD3jeZh7NBr7hb1ozeXqTWXcoH8Bsb26Q.png?1761563170)

6. **Open in Design Editor**(디자인 에디터에서 열기)를 선택한 다음 **템플릿 만들기**를 클릭하세요. Mailchimp 템플릿이 하이퍼클래스 **디자인 에디터**에서 열리고, 드래그 앤 드롭으로 바로 내용을 수정할 수 있어요.

   ![디자인 에디터에서 열기 선택 후 템플릿 만들기 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056895332/original/BirT1-2OtP4blMKq4t3nw5Hn8dBz-7dI5g.png?1761563193)

## 자주 묻는 질문

### 가져온 Mailchimp 템플릿이 디자인 에디터에서 제대로 보이지 않아요.

가져온 템플릿이 어긋나 보이거나 일부 영역이 빠져 있다면, 대부분 Mailchimp에서만 쓰는 HTML 구조가 **디자인 에디터**의 블록 기반 레이아웃과 완전히 호환되지 않기 때문이에요. 이럴 때는 **코드 편집기**로 전환해서 HTML을 확인하고 직접 수정할 수 있어요. 가져오기 전에 Mailchimp 캠페인이 표준 HTML과 인라인 CSS를 사용하는지 확인하면 더 좋은 결과를 얻을 수 있어요.

### 동적 콘텐츠, 머지 태그, 조건부 로직을 쓰는 Mailchimp 템플릿도 가져올 수 있나요?

Mailchimp 전용 머지 태그와 동적 콘텐츠 규칙은 가져오는 과정에서 하이퍼클래스의 기능으로 자동 변환되지 않아요. 템플릿의 구조는 가져오지만, 동적 로직은 템플릿이 **디자인 에디터**에 열린 뒤 하이퍼클래스의 **커스텀 값**이나 **Dynamic Fields**(동적 필드)로 직접 다시 설정해야 해요.

### 가져오기 기능이 Mailchimp 계정 정보를 저장하거나 접근하나요?

아니요. 가져오기 기능은 하이퍼클래스에 붙여 넣는 공개 캠페인 URL만 사용해요. Mailchimp 로그인 정보나 API 키를 요구하거나 저장하지 않아요. 입력한 URL의 HTML 레이아웃만 읽어서 **디자인 에디터** 안에 이메일 디자인을 다시 만들어요.

### Mailchimp의 '캠페인'을 가져오는 것과 '템플릿'을 가져오는 것은 어떻게 다른가요?

Mailchimp 캠페인은 캠페인 URL로 바로 가져올 수 있어요. 하지만 Mailchimp에 저장된 템플릿을 가져오려면, 먼저 Mailchimp에서 그 템플릿으로 캠페인을 만든 다음 해당 캠페인의 URL을 복사해야 해요. 하이퍼클래스 가져오기 기능이 처리할 수 있는 공유용 URL은 캠페인에만 있어요.
