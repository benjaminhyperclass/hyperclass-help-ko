# 이메일 발송 방식 — 지금 전송, 일정, 배치 일정, RSS 일정

하이퍼클래스에서는 이메일 캠페인을 보내는 방식을 네 가지 중에서 고를 수 있어요. 바로 보내거나, 날짜를 정해 보내거나, 나눠서 보내거나, RSS 피드와 연결해 자동으로 보낼 수 있어요. 캠페인 목표에 맞는 방식을 골라 보세요.

## 이메일 발송 방식이란?

발송 방식은 캠페인이 언제, 어떻게 수신자에게 도착할지를 정해요. 하이퍼클래스에는 **지금 전송**, **일정**, **배치 일정**, **RSS Schedule**(RSS 일정)의 네 가지 방식이 있어요. 급한 공지부터 블로그 소식 자동 발송까지, 필요에 맞게 쓸 수 있어요.

## 발송 방식별 장점

- **지금 전송**: 시간이 중요한 캠페인을 즉시 보낼 수 있어요.
- **일정**: 원하는 날짜와 시간에 맞춰 캠페인을 미리 준비할 수 있어요.
- **배치 일정**: 이메일을 작은 그룹으로 나눠 보내서 전달률을 높여요.
- **RSS Schedule**: 블로그, 피드, 콘텐츠 스트림의 새 소식을 자동으로 보내요.

## 지금 전송

**지금 전송**을 선택하면 로케이션 시간대 기준으로 선택한 수신자에게 캠페인을 바로 보내요. 깜짝 세일이나 중요한 공지처럼 급한 소식에 알맞아요.

**지금 전송을 쓰면 좋은 경우**

- 긴급 소식이나 긴급 오퍼
- 막판에 추가된 캠페인
- 바로 알려야 하는 상품 업데이트

**설정 방법**

1. 발송 방식에서 **지금 전송**을 선택해요.
2. **발신자 이메일**을 입력하고, 필요하면 **발신자 이름**도 입력해요.
3. **Subject Line**(제목)을 쓰고, 필요하면 **Preview Text**(미리보기 텍스트)도 써요.
4. **수신자 선택**에서 스마트 리스트, 태그, 세그먼트, 연락처 중 보낼 대상을 골라요.
5. **보내기**를 클릭하면 바로 발송돼요.

## 일정

**일정**을 선택하면 보낼 날짜와 시간을 직접 정할 수 있어요. 수신자가 메일을 확인할 가능성이 높은 때에 맞춰 보낼 수 있어요.

**일정을 쓰면 좋은 경우**

- 이벤트 알림
- 시즌 프로모션
- 미리 계획한 마케팅 캠페인

**설정 방법**

1. **일정**을 선택해요.
2. 날짜와 시간을 선택해요. 시스템은 로케이션 시간대를 기준으로 해요.
3. 발신자 정보, 제목, 미리보기 텍스트를 설정해요.
4. **수신자 선택**에서 보낼 대상을 골라요.
5. 일정을 확인해요.

## 배치 일정

**배치 일정**을 선택하면 규모가 큰 캠페인을 작은 그룹(배치)으로 나눠 보낼 수 있어요. 전달률 문제가 생길 위험이 줄고, 정한 기간에 걸쳐 발송이 분산돼요.

{% hint style="info" %}
**배치 일정 유효성 검사**

1. 종료 시간이 시작 시간보다 빠르면 **End time**(종료 시간) 아래에 "End time can't be before start time."(종료 시간은 시작 시간보다 빠를 수 없어요.)이라는 오류 문구가 나타나요.
2. 종료 시간이 시작 시간보다 앞서게 선택하면 **시작 날짜 시간** 아래에 "Please enter a valid start time."(올바른 시작 시간을 입력해 주세요.)이라는 안내 문구가 나타나요.
3. 오류를 고치기 전까지는 **보내기**와 **일정**이 비활성화된 상태로 남아 있어요.
4. **배치 수량**과 **반복 간격**을 설정해요.
5. 배치를 반복할 간격은 지원되는 것 중에서 골라요.
   - 참고: 초 단위 옵션은 지원하지 않아요.
   - 임시 저장 동작: 이전에 저장한 초안에서 초 단위를 선택했다면, 일정 오류를 막기 위해 그 값이 자동으로 지워져요.
6. 시작 시간을 수정하면 **OK**(확인) 버튼 하나로 확인해요.
7. 자정(오전 12:00) 경계도 잘못된 오류 없이 정상적으로 처리돼요.
{% endhint %}

**배치 일정을 쓰면 좋은 경우**

- 수신자 목록이 큰 경우(연락처 수천 명)
- 서버 제한(스로틀링)을 피하고 싶은 경우
- 전달률을 꾸준히 유지하고 싶은 경우

**예시:** 연락처가 1,000명이고 배치 수량을 100으로 설정하면, 이메일이 10번에 나뉘어 발송돼요.

**설정 방법**

1. **배치 일정**을 선택해요.
2. **시작 날짜 시간**을 정해요.
3. **배치 수량**과 **반복 간격**(시간 또는 일 단위)을 설정해요.
4. 발신자 정보, 제목, 수신자를 설정해요.
5. 저장하고 확인해요.

## RSS 일정

**RSS Schedule**(RSS 일정)은 RSS 피드와 연결해 자동으로 보내는 캠페인에 쓰는 방식이에요. 피드가 업데이트될 때마다 이메일이 만들어지고, 설정한 일정에 맞춰 발송돼요.

**RSS Schedule을 쓰면 좋은 경우**

- 블로그 업데이트
- 뉴스레터
- 콘텐츠 자동 발송

**설정 방법**

1. **RSS Schedule**을 선택해요.
2. **RSS 피드 URL**을 입력해요.
3. 보낼 주기(매일, 매주 등)와 보낼 시간대를 골라요.
4. 발신자 정보, 제목, 수신자를 설정해요.
5. 저장하고 확인해요.

## 이메일 캠페인 설정과 관리

설정과 관리를 제대로 해 두면 캠페인이 안정적으로 전달돼요. 처음 일정을 정한 뒤에도 하이퍼클래스에서 캠페인을 편집하거나, 일정을 바꾸거나, 취소할 수 있어요.

**주요 관리 기능**

- **일정 변경**: 발송 1시간 전까지 캠페인의 날짜와 시간을 바꿀 수 있어요.
- 콘텐츠 편집: 일정, 배치, RSS 캠페인은 실행되기 전에 이메일 내용을 수정할 수 있어요.
- 일시 중지 또는 취소: 캠페인이 발송되기 전에 멈출 수 있어요. 일정, 배치 일정, RSS 일정 캠페인에 적용돼요.
- **테스트 이메일**/**미리보기**: 발송을 확정하기 전에 나에게 테스트 메일을 보내 확인할 수 있어요.

## 자주 묻는 질문

### 일정을 정한 뒤에도 캠페인을 편집할 수 있나요?
네, 발송 1시간 전까지 날짜와 시간을 수정할 수 있어요. 배치 일정과 RSS 일정 캠페인은 일정이 진행되는 도중에도 이메일 내용을 수정할 수 있어요.

### RSS 피드에 새 콘텐츠가 없으면 어떻게 되나요?
피드에 새 콘텐츠가 올라올 때까지 이메일이 발송되지 않아요.

### 발송에는 어느 시간대가 쓰이나요?
계정에 설정된 로케이션 시간대를 사용해요.

### 예약한 캠페인을 취소할 수 있나요?
네, 일정, 배치 일정, RSS 일정 캠페인은 발송되기 전에 일시 중지하거나 취소할 수 있어요.

### 일정과 배치 일정은 무엇이 다른가요?
**일정**은 전체 목록에 한꺼번에 보내고, **배치 일정**은 목록을 작은 그룹으로 나눠 시간을 두고 보내요.
