# 이메일 캠페인을 배치 일정으로 나누어 보내기

배치 일정을 쓰면 마케팅 이메일을 한꺼번에 보내지 않고 정해 둔 간격에 맞춰 나누어 보낼 수 있어요. 웹사이트나 퍼널로 들어오는 트래픽을 조절하고 발송 서버의 부담도 줄일 수 있어요. 이 문서에서는 **이메일 빌더**의 **배치 일정** 옵션으로 배치 발송을 설정하는 방법을 안내해요.

## 이메일 캠페인의 배치 일정이란?

배치 일정(배치 발송 또는 드립 모드라고도 해요)은 정해 둔 간격에 따라 발송을 나누는 방식이에요. 전체 수신자에게 동시에 보내는 대신 배치 수량, 발송 시간, 발송 요일을 직접 정해서 천천히, 예측할 수 있게 보낼 수 있어요.

## 배치 일정의 장점

- 트래픽 관리: 시간 간격을 두고 나누어 보내므로 웹사이트나 퍼널에 갑자기 방문자가 몰리는 일을 막을 수 있어요.
- 서버 부하 조절: 발송 속도를 조절해서 서버에 걸리는 부담을 줄여요.
- 유연한 시간 설정: 배치 수량, 반복 주기, 요일, 시작·종료 시간을 직접 정할 수 있어요.

## 발송 전 확인 사항

시작하기 전에 아래 내용을 확인하세요.

- 이메일을 보내려면 캠페인에 쓸 이메일 템플릿을 미리 만들어 두어야 해요.
- 이메일을 보내려면 발송에 쓸 도메인을 인증해 두어야 해요.

## 이메일 캠페인 배치 일정 설정하기

**이메일 빌더**에서 캠페인을 만들고 배치 발송(드립 모드)을 설정하는 순서예요.

### 1단계: 이메일 캠페인 만들기

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. **신규** 캠페인을 만들거나 기존 캠페인을 **편집**하세요.

   ![이메일 캠페인 만들기 화면 녹화](https://jumpshare.com/share/4ksctHv7u96lC8oWPfe5+/GIF+Recording+2026-09-21+at+16+17+03.gif)

### 2단계: 이메일 디자인하기

{% hint style="info" %}
**이메일 빌더**와 인라인 편집기 사용법을 더 알고 싶다면 이메일 빌더 사용 문서를 읽어 보세요.
{% endhint %}

1. 템플릿을 **빌드**하거나 선택하세요.
2. 내용, 이미지, 링크를 추가하세요.
3. Preview and Test Email(미리보기 및 테스트 이메일)로 데스크톱과 모바일에서 레이아웃이 제대로 보이는지 확인하세요.

   ![이메일 미리보기 및 테스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063151522/original/Z3mVbgpb7EtTlR84G9ion3OMCK5N5OlO2g.jpeg?1768997743)

### 3단계: 전달 방식 선택하기 (배치 일정)

1. **보내기** 또는 **일정** 버튼을 클릭하세요.

   ![보내기 또는 일정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063151529/original/umIMMvfAC0puh_z5iDvDAUJtmwFDPnc49w.jpeg?1768997744)
2. **Sending Options**(발송 옵션)에서 **배치 일정**을 선택하고 아래 순서대로 설정하세요.

   1. 캠페인의 **Start date and time**(시작 날짜 및 시간)을 입력하세요.
   2. **배치 수량**을 입력하세요.

      {% hint style="info" %}
      **배치 수량**은 배치 한 번에 보내는 이메일 수예요. 배치의 개수가 아니에요. 예를 들어 수신자가 10,000명인데 **배치 수량**을 1,000으로 설정하면, 1,000통씩 10번에 나누어 보내요.
      {% endhint %}
   3. **반복 간격**에 주기에 맞는 숫자를 입력하고, 단위를 일, 시간, 분, 초 중에서 선택하세요.
      이전에 저장한 초안에서 초 단위를 썼다면, 일정 오류를 막기 위해 그 칸이 자동으로 비워져요.
   4. 배치 이메일 캠페인을 보내지 않을 요일은 체크를 해제하세요.
   5. 발송을 시작하고 끝낼 시간을 **시작 시간**과 **종료 시간**에 입력하세요.

      {% hint style="info" %}
      배치 일정 입력값 검증 규칙이에요.

      - **종료 시간**이 **시작 시간**보다 빠르면 **종료 시간** 아래에 **End time can't be before start time**(종료 시간은 시작 시간보다 빠를 수 없어요)이라는 오류가 나타나요.
      - **종료 시간**을 **시작 시간**보다 빠르게 선택하면 **시작 시간** 아래에 **Please enter a valid start time**(올바른 시작 시간을 입력하세요)이라는 안내가 나타나요.
      - 오류를 고치기 전까지 **보내기**와 **일정** 버튼은 비활성화된 상태로 유지돼요.
      - **시작 시간**을 편집하면 **확인** 버튼 하나로 확정해요.
      - 자정(오전 12:00) 경계는 잘못된 오류 없이 처리돼요.
      {% endhint %}

      ![시작 시간과 종료 시간 검증 오류 화면](https://jumpshare.com/share/nZlsGLmQmgQ0E5XV5aOq+/Screen+Shot+2026-01-21+at+5.58.09+PM.png)
   6. **발신자** 섹션의 **이름** 칸에 이름을 입력하세요. (선택 사항)
   7. **Sender Domain**(발신 도메인)을 선택하거나 설정하세요.
   8. **발신자 이메일** 칸에 이메일 주소를 입력하세요.
   9. **Subject Line**(제목)을 입력하세요.
   10. **미리보기** 섹션에 미리보기 텍스트를 입력하세요. (선택 사항)
   11. **받는사람** 칸에서 이메일 주소 또는 스마트 리스트를 선택해 수신자를 추가하세요.

       ![받는사람 입력 화면](https://jumpshare.com/share/lYpiAnM4jeiK0HjH8DLW+/Screen+Shot+2026-01-21+at+6.02.32+PM.png)

{% hint style="info" %}
일정을 확정하기 전에 실행 날짜, 시간, 시간대를 꼭 확인하세요.

이메일 캠페인은 삭제하거나 일정을 변경할 수 있어요. 일정을 바꾸려면 **reschedule**(일정 변경)을 클릭해서 캠페인의 날짜와 시간을 다시 설정하세요.

일정 변경은 이메일 캠페인을 보내기 1시간 전까지만 할 수 있어요. 예를 들어 발송 일정이 오전 11시(EST)라면 오전 10시(EST)까지 변경할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 배치 캠페인의 이메일 내용을 수정할 수 있나요? 통계에는 영향을 주고 싶지 않아요.
네, 진행 중인 배치 일정 캠페인의 이메일 내용은 **이메일 콘텐츠 업데이트**를 클릭해서 수정할 수 있어요. 실행 날짜 전에 내용을 수정한 뒤 **save edits**(편집 저장)를 클릭하세요.

{% hint style="info" %}
수정한 내용이 반드시 반영되는 것은 아니에요. 다만 서버에서 실행 대기열이 시작되기 전에 반영하려고 노력해요.
{% endhint %}

### RSS 이메일 캠페인 일정을 변경하려면 어떻게 하나요?
이메일 캠페인 일정 변경은 **Simple Schedule**(단순 일정), **배치 일정**, **RSS Schedule**(RSS 일정) 모두 실행 날짜 1시간(60분) 전까지 할 수 있어요.

**마케팅 > 이메일**로 이동한 뒤 **이메일 캠페인** 탭을 열어 보세요. Simple Schedule, RSS Schedule, 배치 일정으로 등록된 이메일 캠페인 목록이 나와요. 이 중 실행 날짜와 시간 1시간 전까지인 캠페인은 일정을 변경할 수 있어요.

작업 버튼에서 **Reschedule Campaign**(캠페인 일정 변경)을 선택하세요. 일정 세부 정보를 바꾸고 전달 방식도 변경할 수 있어요. 변경을 마치면 일정이 변경된 캠페인으로 표시해야 설정이 저장돼요.

### 시스템의 발송 속도 제한은 어떻게 되나요?
**드립 모드로 추가**:

- 발송 주기 30초~1분: 분당 1,000개 메시지
- 발송 주기 5분: 분당 4,999개 메시지
- 발송 주기 6분~10분: 분당 5,000개 메시지
- 발송 주기 10분 초과: 분당 10,000개 메시지

**모두 한 번에 추가** 및 **Add all at a scheduled time**(예약 시간에 모두 추가):

- 1만 명 미만: 시간당 연락처 15,000개 처리
- 1만 명 이상 5만 명 미만: 시간당 연락처 6,000개 처리
- 5만 명 이상 7만 명 미만: 시간당 연락처 3,000개 처리
- 7만 명 이상: 시간당 연락처 1,500개 처리

{% hint style="info" %}
**반복 간격** 드롭다운에는 초 단위가 없어요. 이전에 초 단위 간격을 썼다면 1분 이상을 선택하세요.
{% endhint %}
