# 예약된 이메일 캠페인 일시정지·다시 시작·취소하기

**이메일 캠페인** 페이지에서 예약된 이메일 캠페인을 일시정지하거나, 다시 시작하거나, 취소할 수 있어요. 발송을 잠깐 멈추고 싶을 때, 멈춘 캠페인을 다시 보내고 싶을 때, 예약된 발송을 완전히 중단하고 싶을 때 쓰세요. 이 문서에서는 캠페인을 다시 시작하면 어떻게 되는지, 언제 **일정 변경**을 써야 하는지도 함께 알려 드려요.

## 일시정지, 다시 시작, 취소가 뭔가요?

이 세 가지 기능은 아직 발송되지 않은 이메일 캠페인을 관리해요. **일시정지**는 캠페인을 잠시 멈추고, **다시 시작**은 멈춘 캠페인을 다시 보내고, **취소**는 예약된 캠페인을 완전히 중단해요.

### 일시정지

캠페인을 잠시 멈춰요. 나중에 다시 시작할 수 있어요.

### 다시 시작

일시정지한 캠페인을 다시 시작해요.
- 원래 예약된 시간 전에 다시 시작하면, 원래 일정대로 발송돼요.
- 예약된 시간이 지난 뒤에 다시 시작하면, 바로 발송돼요.

### 취소

예약된 캠페인이 더 이상 진행되지 않도록 완전히 중단해요. 취소한 캠페인은 다시 시작할 수 없어요.

{% hint style="info" %}
**일정**, **배치 일정**, **RSS Schedule**(RSS 일정) 캠페인에서 **일시정지**와 **취소**를 쓸 수 있어요.
{% endhint %}

## 예약된 캠페인 일시정지·다시 시작·취소하기

이미 예약했지만 아직 발송이 끝나지 않은 캠페인은 캠페인 작업 메뉴에서 관리해요.

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. 관리할 예약된 캠페인을 찾으세요.
3. 캠페인 옆의 **점 세 개 메뉴(⋮)**를 클릭하세요.
   ![예약된 캠페인과 점 세 개 작업 메뉴가 보이는 이메일 캠페인 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058743022/original/Srw-TLXKqrWiUfSJPi2_SmEEnYStHF_vIA.png?1763554622)
4. 캠페인의 현재 상태와 하려는 작업에 맞게 **일시정지**, **다시 시작**, **취소** 중 하나를 선택하세요.
   ![일시정지, 다시 시작, 취소 옵션이 보이는 캠페인 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058743335/original/c_rmhYzTXlJLOC2V5-NWgd-F9_JiWDlYRw.png?1763554739)

## 일시정지와 일정 변경, 어떻게 다른가요?

캠페인을 잠시 멈췄다가 나중에 다시 시작할 수도 있다면 **일시정지**를 쓰세요. 앞으로의 발송 날짜나 시간을 다른 때로 정하려면 **일정 변경**을 쓰세요.

{% hint style="warning" %}
지원되는 예약 캠페인은 실행 시간 60분 전까지 일정 변경을 마쳐야 해요.
{% endhint %}

## 자주 묻는 질문

### 원래 예약된 시간이 지난 뒤에 캠페인을 다시 시작하면 어떻게 되나요?
다시 시작하는 즉시 캠페인이 발송돼요.

### 일시정지한 캠페인을 다시 시작하지 않으면 어떻게 되나요?
**다시 시작**이나 **취소**를 선택할 때까지 캠페인은 일시정지 상태로 남아 있어요.

### 캠페인을 취소하면 캠페인이 삭제되나요?
아니요. 취소하면 예약된 발송만 중단돼요. 캠페인이 삭제되지는 않아요.

### 일시정지하지 않고 새 발송 시간을 정할 수 있나요?
네. 앞으로의 발송 시간을 다른 때로 바꾸려면 **일정 변경**을 쓰세요. 지원되는 예약 캠페인은 실행 시간 60분 전까지 일정 변경을 마쳐야 해요.

### 배치 일정이나 RSS Schedule 캠페인도 일시정지하거나 취소할 수 있나요?
네. **일정**, **배치 일정**, **RSS Schedule** 캠페인에서 **일시정지**와 **취소**를 쓸 수 있어요.
