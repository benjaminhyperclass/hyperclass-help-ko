# 이메일 빌더의 이미지 요소

**이메일 빌더**에서 이미지 요소를 쓰면 이메일 템플릿에 이미지를 넣고 크기와 정렬을 조정할 수 있어요. 이미지를 넣는 방법이 여러 가지라서, 보기 좋고 깔끔한 이메일을 만들 때 유용해요.

## 이미지 요소란?

이미지 요소는 **이메일 빌더**에서 끌어다 놓아 쓰는 블록이에요. 이메일 레이아웃에 이미지를 바로 넣을 수 있어요. 새 이미지를 업로드하거나 URL을 붙여 넣거나, 이미 저장해 둔 파일 라이브러리에서 불러올 수 있어요.

크기 조절, 정렬, 링크 연결 같은 설정도 지원해요. 브랜드 로고, 상품 소개, 시각적인 스토리텔링에 이미지를 활용해 보세요. 이미지는 주요 이메일 클라이언트와 기기에서 올바르게 표시돼요.

{% hint style="info" %}
로딩 시간을 줄이고 이메일 전달률을 유지하려면 JPG나 PNG 형식의 압축된 이미지(1MB 미만)를 사용하세요.
{% endhint %}

## 이미지 요소의 장점

이메일 디자인에 이미지 요소를 추가하면 다음과 같은 점이 좋아요.

- 끌어다 놓기만 하면 고화질 이미지를 빠르게 넣을 수 있어요.
- 너비, 높이, 정렬을 조정해 균형 잡힌 레이아웃을 만들 수 있어요.
- 데스크톱과 모바일 모두에서 이미지가 일관되게 표시돼요.
- 로고, 배너, 시각 자료로 브랜드의 완성도 있는 모습을 유지할 수 있어요.

## 이미지 요소 설정하기

이메일 템플릿에 이미지 요소를 추가하고 설정하는 방법이에요.

1. 서브 계정 대시보드에서 **마케팅 > 이메일 > 템플릿**으로 이동하세요.
   ![마케팅 > 이메일 > 템플릿 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057289337/original/XHI8TgNTaj5hIxqBDmQMq6ocYMQepyBdvA.png?1761904242)
2. 기존 템플릿을 열거나 **+ 신규** 버튼을 눌러 새 템플릿을 만드세요.
   ![기존 템플릿을 열거나 새 템플릿을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057289402/original/vXaGlsjMi1ZGKmKSokUfVNQxmj1sYnstTg.jpeg?1761904288)
3. **이메일 빌더**의 왼쪽 사이드바에서 **요소 추가(+)** 아이콘을 클릭하세요.
   ![이메일 빌더 왼쪽 사이드바의 요소 추가 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057289494/original/FJOmvw7ZFbokKI4kkmcYP8FYKElC9D1ZMw.png?1761904349)
4. **요소** 섹션에서 **이미지** 요소를 찾으세요.
5. 이미지 요소를 이메일 레이아웃에서 원하는 위치로 끌어다 놓으세요.
6. 이미지 요소를 클릭하면 왼쪽 패널에 **편집** 탭이 열려요. 여기서 다음 설정을 할 수 있어요.

   - **Upload an Image**(이미지 업로드): 내 컴퓨터에서 이미지를 선택해요.
   - **Use an Image URL**(이미지 URL 사용): 외부에 올려 둔 이미지의 직접 링크를 붙여 넣어요.
   - **Adjust Width & Height**(너비와 높이 조정): 원하는 크기를 직접 지정하거나 자동 크기 조절을 사용해요.
   - **Add a Link**(링크 추가): 이동할 URL을 넣어 이미지를 클릭할 수 있게 만들어요.
   - **Set Alignment**(정렬 설정): 이미지를 왼쪽, 가운데, 오른쪽으로 정렬해요.
   - **Add Padding**(패딩 추가): 이미지 주변 여백을 조절해 디자인 균형을 맞춰요.
     ![이미지 요소의 편집 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057289695/original/5ULMgMtX99lLYUsvgAXpihAZikng-Fv51g.png?1761904443)
7. (선택) **공개 범위** 탭을 클릭하면 **Device-Based Visibility**(기기별 표시 설정)나 **조건부 발송** 옵션을 설정할 수 있어요.
   ![공개 범위 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057289798/original/ad6WgCPPL4DGdz-JTuhgaSNG-_ao81_g3g.png?1761904510)
8. 데스크톱과 모바일 양쪽에서 이메일을 미리보기로 확인해, 이미지가 의도한 대로 표시되는지 살펴보세요.

## 자주 묻는 질문

### 어떤 이미지 파일 형식을 쓸 수 있나요?
JPG, PNG, GIF 같은 일반적인 형식을 업로드하거나 링크로 연결할 수 있어요.

### 이미지를 클릭할 수 있게 만들 수 있나요?
네, 가능해요. **Redirection Link**(리디렉션 링크) 필드에 하이퍼링크를 넣으면 이미지를 클릭할 수 있어요.

### 외부 이미지 URL을 쓸 수 있나요?
네, **Image URL**(이미지 URL) 필드에 올바른 이미지 URL을 붙여 넣으면 돼요. 이미지가 누구나 볼 수 있게 공개되어 있어야 해요.

### 스페이서가 이메일 전달률이나 로딩 속도에 영향을 주나요?
아니요, 스페이서는 가벼워서 전달률이나 로딩 시간에 영향을 주지 않아요.

### 이미지를 삭제하려면 어떻게 하나요?
이미지 요소를 클릭한 다음 삭제(휴지통) 아이콘을 누르면 레이아웃에서 제거돼요.
