# 이메일 빌더에서 항목 저장하고 다시 쓰기

이미 만든 요소와 레이아웃을 다시 쓰면 일관된 이메일 디자인을 더 쉽게 만들 수 있어요. 하이퍼클래스의 **Saved Items**(저장된 항목) 기능을 쓰면 자주 쓰는 콘텐츠를 저장해 두고, **디자인 에디터**에서 다른 이메일 템플릿에 바로 추가할 수 있어요. 이 문서에서는 항목을 저장하고, 찾고, 다시 쓰고, 이름을 바꾸고, 관리하는 방법을 안내해요.

## Saved Items(저장된 항목)란?

**Saved Items**는 하이퍼클래스 이메일 **디자인 에디터** 안에 저장해 두고 꺼내 쓸 수 있는 재사용 디자인 구성 요소예요. 브랜드 헤더, 푸터, 프로모션 섹션처럼 자주 쓰는 내용을 매번 새로 만들 필요 없이, 만들어 둔 디자인을 저장했다가 다른 이메일 템플릿에 넣을 수 있어요.

저장한 항목은 같은 서브 계정 안에서 **디자인 에디터**로 만든 이메일 템플릿이라면 어디서든 쓸 수 있어요. 브랜드 이미지를 통일하고 반복 작업을 줄이는 데 도움이 돼요.

**지원하는 에디터**

- **디자인 에디터**: 이메일 디자인 항목을 저장하고 다시 쓸 수 있어요.
- **AI Editor**(AI 에디터): 지금은 **Saved Items**를 지원하지 않아요.

이메일 구성 요소에 대한 자세한 내용은 [이메일 빌더의 다양한 요소](different-elements-in-email-builder.md)를 참고하세요.

## 이메일 빌더에서 항목 저장하고 다시 쓰기

자주 쓰는 디자인 구성 요소를 저장해 두면 새 이메일 템플릿을 더 빠르고 일관되게 만들 수 있어요. 아래 순서대로 기존 요소나 레이아웃을 저장하고, 저장한 항목을 다른 템플릿에서 다시 쓰고, 항목을 관리해 보세요.

{% hint style="info" %}
**Saved Items**는 **AI Editor**에서 쓸 수 없어요. 이 기능을 쓰려면 **디자인 에디터**로 전환하거나 **디자인 에디터**를 사용하세요.
{% endhint %}

### 1단계: 이메일 디자인 에디터 열기

1. 하이퍼클래스 계정에 로그인하세요.
2. **마케팅 > 이메일 > 템플릿**으로 이동하세요.
3. 새 이메일 템플릿을 만들거나 기존 템플릿을 여세요.
4. **디자인 에디터**를 사용 중인지 확인하세요.

![디자인 에디터 열기](https://jumpshare.com/share/sXEzQdcB3a2ae3BKzL7Q+/GIF+Recording+2026-10-08+at+21.55.15.gif)

### 2단계: 요소 또는 레이아웃 저장하기

1. 다시 쓰고 싶은 요소, 섹션, 레이아웃을 찾으세요.
2. 항목 위에 마우스를 올려 편집 도구 모음을 표시하세요.
3. 도구 모음에서 **저장** 아이콘을 클릭하세요.
4. 항목이 저장되면 확인 메시지가 나타나요.

{% hint style="info" %}
브랜드 푸터, 헤더, 프로모션 섹션처럼 자주 쓰는 구성 요소를 저장해 두면 반복해서 서식을 맞추는 일을 줄일 수 있어요.
{% endhint %}

![요소 또는 레이아웃 저장](https://jumpshare.com/share/8Y2EmcNdPhuzHjuZAIL5+/GIF+Recording+2026-10-08+at+22.04.30.gif)

### 3단계: 저장된 항목 찾아서 다시 쓰기

1. **디자인 에디터** 왼쪽 도구 모음에서 **Saved Items** 패널을 여세요.
2. 이전에 저장한 요소, 섹션, 레이아웃을 찾으세요.
3. 저장된 항목을 패널에서 이메일 템플릿의 원하는 위치로 끌어다 놓으세요.
4. 필요하면 넣은 항목의 내용이나 스타일을 수정하세요.

{% hint style="warning" %}
저장된 항목은 같은 서브 계정 안에서 **디자인 에디터**로 만든 이메일 템플릿이라면 다시 쓸 수 있어요.
{% endhint %}

![저장된 항목 끌어다 놓기](https://jumpshare.com/share/QaCYFX8yG32KJweHS8Dq+/GIF+Recording+2026-10-08+at+22.12.04.gif)

### 4단계: 저장된 항목 검색, 이름 변경, 삭제하기

비슷한 요소나 레이아웃이 여러 개 쌓여 있을 때는 알아보기 쉬운 이름을 붙여 두면 편해요.

1. **Saved Items** 패널을 여세요.
2. **검색** 창에 저장된 항목의 이름이나 관련 키워드를 입력하세요.
3. 해당 항목의 **점 세 개 메뉴(⋯)**를 클릭하세요.
4. **이름 변경** 또는 **삭제**를 선택하세요.

![저장된 항목 이름 변경 및 삭제](https://jumpshare.com/share/10yGJlR3KjKKCAk73mnw+/GIF+Recording+2026-10-08+at+22.15.36.gif)

## 자주 묻는 질문

### AI Editor에서도 저장된 항목을 쓸 수 있나요?

아니요. **Saved Items**는 현재 **디자인 에디터**에서만 지원돼요.

### 다른 서브 계정에서 저장한 항목을 쓸 수 있나요?

저장된 항목은 만든 서브 계정 안에서만 쓸 수 있어요. 다른 서브 계정과는 자동으로 공유되지 않아요.

### 디자인 일부만 다시 쓰려면 이메일 템플릿 전체를 저장해야 하나요?

아니요. 이메일 전체를 재사용 템플릿으로 저장하지 않아도, 지원되는 요소, 섹션, 레이아웃을 개별로 저장할 수 있어요.

### 저장한 항목을 여러 번 쓸 수 있나요?

네. 같은 서브 계정 안에서라면 같은 저장 항목을 여러 이메일 템플릿에 끌어다 놓을 수 있어요.

### 이전에 저장한 항목이 보이지 않아요.

**디자인 에디터**를 쓰고 있는지, 항목을 저장했던 서브 계정에 들어와 있는지 확인하세요. **Saved Items** 패널에서 항목 이름을 **검색**해 볼 수도 있어요.
