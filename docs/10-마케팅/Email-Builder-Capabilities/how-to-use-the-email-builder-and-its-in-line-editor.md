# 이메일 빌더와 인라인 편집기 사용하기

하이퍼클래스의 **이메일 빌더**(Email Builder)는 끌어다 놓기(드래그 앤 드롭) 방식으로 템플릿과 캠페인용 이메일을 만드는 편집 도구예요. 이 문서에서는 화면 구성, 이메일 요소별 설정, 발송 전 확인 방법을 안내해요.

텍스트, 이미지, 버튼 같은 콘텐츠 요소를 추가하고, 캔버스에서 바로 서식을 고칠 수 있어요. 연락처 정보를 활용해 메시지를 개인화할 수도 있어요.

레이아웃, 모바일 서식, 미리보기, 고급 편집 옵션도 함께 제공돼서 독자에게 보낼 이메일을 한곳에서 준비할 수 있어요.

## 이메일 빌더 인라인 편집기란?

**이메일 빌더**는 코드를 쓰지 않고 이메일 템플릿과 캠페인을 만드는 시각적 디자인 도구예요. 인라인 편집기는 보이는 그대로 편집되는 WYSIWYG(What You See Is What You Get) 방식이에요. 이메일 캔버스에서 바로 서식을 바꾸고 결과를 즉시 확인할 수 있어요.

예를 들어 텍스트를 선택해 글꼴이나 색상을 바꾸고, 버튼을 넣어 행동을 유도하고, 이미지를 넣어 메시지를 보완할 수 있어요.

**이메일 빌더**에서는 콘텐츠 편집, 레이아웃 조정, 개인화, 미리보기를 한 작업 공간에서 할 수 있어요.

![이메일 빌더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083970587/original/EISaqEpXL0i7iXYCbLORYhVeYvrkOTwbVQ.png?1792673994)

{% hint style="info" %}
이메일 구조를 일관되게 유지하기 위해 기본 여백이 업데이트되었어요. 이제 콘텐츠 주변 간격을 직접 관리할 수 있어요. 기본 여백 값은 다음과 같아요.

- 위쪽 여백: 12
- 아래쪽 여백: 12
- 왼쪽 여백: 24
- 오른쪽 여백: 24

이 기능으로 이메일 레이아웃과 모양을 더 세밀하게 조정할 수 있어요.
{% endhint %}

## 이메일 빌더 인라인 편집기의 장점

- 시각적 일관성: 모든 이메일에 기본 여백을 위 12, 아래 12, 왼쪽 24, 오른쪽 24로 맞추면 통일된 느낌을 유지할 수 있어요.
- 다양한 글꼴 지원: Arial, Georgia, Verdana 등 여러 글꼴을 쓸 수 있어서 브랜드 스타일에 맞출 수 있어요. 예를 들어 브랜드가 Helvetica를 쓴다면 이메일에서도 같은 글꼴을 쓸 수 있어요.
- 정교한 텍스트 스타일: 굵게, 기울임, 밑줄, 취소선으로 텍스트 모양을 다듬을 수 있어요. 중요한 내용을 굵게 또는 기울임으로 강조해 눈에 띄게 만들 수 있어요.
- 자유로운 색상 지정: 헥스 코드로 텍스트 색상과 강조 색상을 정확하게 지정할 수 있어요. 예를 들어 브랜드 색상이 #AFAFAF라면 이메일 텍스트나 강조 표시에 정확히 그 색을 쓸 수 있어요.
- 하이퍼링크 추가: 단어나 문구에 링크를 걸어 독자가 관련 콘텐츠로 바로 이동하게 할 수 있어요. 예를 들어 상품명에 웹사이트의 상품 페이지 링크를 걸 수 있어요.
- AI 콘텐츠 작성 지원: **콘텐츠 AI**로 콘텐츠를 더 빠르게 만들어 이메일 작성·편집 시간을 줄일 수 있어요. 처음 입력한 내용을 바탕으로 텍스트를 제안해 주기도 해요.
- 텍스트 서식 정리: 다른 곳에서 텍스트를 복사해 붙여 넣을 수 있고, **서식 지우기**를 누르면 기존 서식이 지워져요. 문서에서 가져온 텍스트에 이메일의 서식을 새로 적용하고 싶을 때 편해요.

## 이메일 빌더 열기

1. **마케팅 > 이메일 > 템플릿**으로 이동하세요.
2. 새 템플릿을 만들거나, 기존 템플릿을 편집하거나, AI로 이메일을 만들 수 있어요.

## 새 화면 둘러보기

**이메일 빌더**를 열면 위쪽에 여러 기능이 있는 도구 모음이 보여요.

**요소 추가** 버튼으로 텍스트와 이미지부터 더 복잡한 구조까지 이메일에 새 콘텐츠를 넣을 수 있어요.

![요소 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083971009/original/xIqgSPWsai3qkgkGlGLUGrEt857TEbWTXA.png?1792674172)

**Manage Elements**(요소 관리)에서는 이메일에 들어 있는 모든 요소를 한눈에 보고, 쉽게 선택해서 조정할 수 있어요.

![요소 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083971277/original/ZMtGs31uhu9wtTTG4RLmMGj7y5cV54WjjA.png?1792674267)

**화면 스타일** 설정에서는 이메일 전체 스타일을 조정해요. **배경 색상**, **구분선**, **사용자 지정 CSS**, **모바일 서식** 등을 여기서 설정해요.

![화면 스타일 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083971366/original/2N_-eVC165iyvhPs-990O4iDSqBK33BiEA.png?1792674303)

이 기능들로 개별 요소부터 이메일의 전체 분위기까지 디자인을 직접 조정할 수 있어요.

### 요소 추가하기

**요소 추가**를 누르면 이메일에 넣을 수 있는 콘텐츠 유형 목록이 나와요. 각 요소는 다음과 같아요.

#### 문자

제목, 본문, 캡션 등에 두루 쓰는 요소예요. 인라인 편집기로 글꼴 스타일과 색상부터 정렬까지 텍스트를 세밀하게 다듬을 수 있어요. 제목 텍스트(H1~H4)는 제목을 선택한 뒤 도구 모음의 **굵게**(B) 버튼으로 굵게 서식을 켜거나 끌 수 있어요. 제목 수준은 그대로 유지돼요.

#### 이미지

사진, 그래픽 등 시각 콘텐츠를 넣고 싶다면 **이미지** 요소를 쓰세요. 컴퓨터에서 직접 올리거나 외부 이미지를 링크할 수 있어요.

![이미지 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083971802/original/hPXdzHVEHB6HSwSoya7ctuJ-BtikcUQGFA.png?1792674449)

- **Image Upload**(이미지 업로드): 내 기기에서 이미지를 바로 올려요. 최대 업로드 크기는 10MB예요. 고해상도 사진도 올릴 수 있어요.
- **이미지 URL**: 외부 이미지나 CRM의 **미디어 라이브러리**에 있는 이미지를 링크할 수 있어요. 입력란에 이미지 URL을 붙여 넣으세요.
- **대체 텍스트**: 화면 낭독기를 쓰는 수신자나 이미지가 불러와지지 않을 때를 위해 접근성을 높여 줘요. 이 입력란에 이미지를 짧고 명확하게 설명하세요.
- **링크**(선택): 이미지를 클릭했을 때 특정 URL로 이동하게 하려면 **링크** 입력란에 원하는 링크를 넣으세요.
- **Width**(너비)와 **높이**: 이미지 크기를 조정해요. 픽셀 값을 직접 입력하거나, **높이와 너비를 자동으로 설정**을 체크하면 이미지 원래 비율에 맞춰 크기가 정해져요.
- **여백**: 이미지 주변 공간을 조정해요. 위, 아래, 왼쪽, 오른쪽 여백을 디자인에 맞게 설정하세요.
- **정렬**: 이미지 정렬을 설정해요. 예를 들어 **중앙**을 선택하면 이미지가 컨테이너 가운데에 놓여요. **왼쪽**, **오른쪽** 정렬도 선택할 수 있어요.

## 편집 패널 위치 바꾸기(왼쪽/오른쪽)

편집 패널을 오른쪽에 두거나 다시 왼쪽으로 옮길 수 있어요. 수동 편집과 **이메일 AI**를 나란히 쓸 때 특히 편해요.

패널을 오른쪽에 두면 작업 공간이 자연스럽게 나뉘어서 수정을 빠르게 반복할 수 있어요. 도구보다 결과물에 집중하기도 좋아요.

사전 조건: 편집기에서 **이메일 AI**와 패널 전환 기능을 보려면 에이전시 **실험실** 설정의 서브 계정 기능에서 **이메일 AI**를 켜야 해요. 에이전시 관리자만 설정할 수 있어요.

패널 위치를 바꾸는 방법은 다음과 같아요.

1. **마케팅 > 이메일**을 열고, **캠페인** 또는 **템플릿**을 편집 모드로 여세요.
2. AI와 나란히 쓸 계획이라면 **이메일 AI**를 켜세요.
3. 편집기의 패널 전환 컨트롤을 눌러 패널을 오른쪽에 두거나 왼쪽으로 옮기세요.
4. **이메일 AI**와 캔버스를 함께 보며 계속 편집하세요.

![편집 패널 위치 전환](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083971961/original/8UepJTsdbsJEhFSyCtz3SHJDmeEDpLYGkA.png?1792674553)

#### 버튼

**버튼** 요소로 독자의 반응을 이끌어 낼 수 있어요. 웹페이지로 연결하거나 파일 다운로드를 시작하는 등 클릭으로 실행되는 동작을 설정할 수 있어요.

![버튼 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000350397/original/6V5iTscJ-FxQ-PhxDD4BllEydRiK07y0fg.png?1685715704)

![버튼 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972172/original/r2BMhujPK3i4qyeZPOGwRYUv3oBkK9Snaw.png?1792674666)

- **버튼 텍스트**: 버튼에 표시할 텍스트를 입력해요. 예를 들어 독자를 소셜 미디어 페이지로 안내하려면 '팔로우하기'라고 쓸 수 있어요.
- **글꼴**과 **크기**: 이메일 분위기에 맞는 글꼴과 크기를 고르세요. 예를 들어 'Arial' 14 크기로 쓰면 읽기 편한 기본적인 모양이 돼요.
- **글꼴 색상**: 버튼 텍스트 색상을 선택해요. 색상은 16진수 코드로 지정해요. 예를 들어 흰색은 '#ffffff'예요.
- **작업**: 버튼을 눌렀을 때 실행할 동작을 고르세요.
  - **URL**: 가장 흔히 쓰는 동작이에요. 수신자를 특정 웹페이지로 보내요. 버튼을 연결할 페이지의 URL을 입력하세요.
  - **Mail**(메일): 수신자의 기본 이메일 앱이 열리고 새 메일 작성 화면이 나와요. 받는 사람 이메일 주소를 미리 정해 둘 수 있어요.
  - **File Download**(파일 다운로드): 버튼을 누르면 파일이 다운로드되게 하려면 이 동작을 고르세요. 파일의 직접 다운로드 URL을 입력해야 해요.
  - **Telephone**(전화): 모바일 사용자에게 유용해요. 수신자가 버튼을 누르면 입력한 번호로 전화가 걸려요.
  - **Other**(기타): 위 항목에 없는 동작이 필요하면 이 옵션을 고르세요.
- **정렬**: 버튼 정렬을 선택해요. **왼쪽**, **중앙**, **오른쪽**이 있어요.
- **Total Width**(전체 너비): 버튼을 컨테이너 너비 전체로 늘리려면 이 옵션을 켜세요.
- **배경 색상**: 버튼 배경 색상을 선택해요. 글꼴 색상처럼 16진수 코드로 지정해요. 예를 들어 '#000000'이면 버튼 배경이 검은색이 돼요.
- **모서리 둥글기**: 버튼 모서리가 얼마나 둥글지 조정해요. 숫자가 클수록 더 둥글어요. 예를 들어 '75'로 설정하면 알약 모양 버튼이 돼요.
- **여백**: 버튼 텍스트와 버튼 테두리 사이 간격을 위, 아래, 왼쪽, 오른쪽 값으로 조정해요.

이 설정으로 이메일 전체 분위기에 어울리면서 수신자의 행동을 이끄는 버튼을 만들 수 있어요.

##### 색상 필드에서 커스텀 값 사용하기(실시간 반영)

**배경 색상**, **본문 색상**, **버튼 색상** 같은 색상 입력란에도 **커스텀 값**을 쓸 수 있어요.

커스텀 값 토큰을 입력하면 빌더가 캔버스에 색상을 바로 적용해요. 색상이 바뀌었는지 확인하려고 **미리보기 모드**로 전환하지 않아도 돼요.

![색상 필드에 커스텀 값 입력](https://jumpshare.com/share/kYtmv6GLLOVU3mU1dAEF+/Screen+Shot+2026-02-09+at+10.20.52+PM.png)

#### 구분선

**구분선** 요소로 이메일의 섹션 사이를 확실하게 나눌 수 있어요. 색상, 너비, 스타일을 디자인에 맞게 조정하세요.

![구분선 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000352270/original/FoW90aoQ7s2aNo1N77LXlKdAAKRz92OyTg.png?1685717171)

![구분선 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972338/original/_7bpvE0iXY3DsoFPcMw_IZpINsq_mvCWhQ.png?1792674733)

- **높이**: 구분선의 두께를 정해요. 숫자가 클수록 선이 굵어요. 예를 들어 '2'로 설정하면 적당히 굵은 선이 돼요.
- **Width (%)**(너비(%)): 구분선이 컨테이너 안에서 가로로 차지하는 범위를 정해요. 컨테이너 너비에 대한 백분율로 입력해요. 예를 들어 '100'이면 구분선이 컨테이너 너비 전체를 채워요.
- **선 유형**: 구분선 스타일을 고르세요. 보통 **Solid**(실선), **파선**, **점선**이 있어요.
- **정렬**: 구분선 정렬을 선택해요. **왼쪽**, **중앙**, **오른쪽**이 있어요.
- **색상**: 구분선 색상을 16진수 코드로 지정해요. 예를 들어 '#FED7E2'는 연한 분홍색 구분선이 돼요.
- **여백**: 구분선과 다른 요소 사이 간격을 조정해요. 구분선의 위, 아래, 왼쪽, 오른쪽 여백을 각각 다르게 설정할 수 있어요.

#### 소셜

수신자가 내 소셜 미디어 프로필을 방문하게 하고 싶다면 **소셜** 요소로 여러 소셜 플랫폼으로 연결되는 아이콘을 쉽게 넣을 수 있어요.

![소셜 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000355754/original/OAqzqxv2N193IKidWKf7jJNKbEwI046now.png?1685719574)

![소셜 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972524/original/u2Ndt7sqZ75Il0GSQbYFSKV-3kD3seI2Ag.png?1792674797)

- **Social Items**(소셜 항목): 소셜 미디어 플랫폼을 추가해요. 보통 Facebook, Instagram, Twitter 아이콘을 추가할 수 있어요. 플랫폼을 클릭하고 계정 이름이나 프로필 URL을 입력하세요.
- **아이콘 스타일**: 소셜 아이콘의 모양을 정해요. 이메일 분위기에 맞는 스타일, 모양, 디자인을 고르세요.
- **표시**: 아이콘 표시 방식을 고르세요. **아이콘**, **문자**, **아이콘과 문자** 중에서 선택해요.
- **정렬**: 이메일 안에서 아이콘 정렬을 조정해요. **왼쪽**, **중앙**, **오른쪽**으로 맞출 수 있어요.
- **글꼴**: 아이콘과 함께 표시되는 플랫폼 이름의 글꼴을 설정해요. **표시**를 '아이콘과 문자'로 쓰면 이 글꼴이 텍스트에 적용돼요.
- **글꼴 색상**: 소셜 아이콘 색상을 16진수 코드로 지정해요. 예를 들어 '#00a4bd'는 청록색이에요.
- **크기**: 아이콘이 잘 보이되 지나치게 크지 않도록 크기를 조정해요.
- **스페이스**: 소셜 아이콘 사이 간격을 정해요.
- **여백**: 소셜 아이콘과 다른 요소 사이 간격을 조정해요. 소셜 아이콘 영역의 위, 아래, 왼쪽, 오른쪽 여백을 각각 다르게 설정할 수 있어요.

이 값들을 알맞게 설정하면 소셜 미디어 채널을 이메일에 자연스럽게 녹여서, 수신자가 해당 플랫폼에서 쉽게 나와 연결되도록 할 수 있어요.

#### 푸터

**푸터** 요소에는 연락처, 회사 주소, 수신거부 링크 같은 필수 정보를 넣어요.

![푸터 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000366980/original/I8-suzLj0ciFDn4J-wwsA8DnAea7yib-_Q.png?1685734315)

![푸터 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972720/original/0AV-1xrg0Whkpi2wF76GtELiAu9by2aUHQ.png?1792674862)

- 텍스트 편집: 푸터 텍스트를 클릭하면 인라인 편집기가 켜져요. 필요에 맞게 텍스트를 고치세요. 회사 주소, 개인정보 처리방침 링크, 수신거부 링크 등을 푸터에 바로 입력할 수 있어요.
- 글꼴과 스타일: 인라인 편집기로 푸터 텍스트의 글꼴, 크기, 색상을 바꿀 수 있어요. 바꾸려는 텍스트를 드래그해서 선택한 뒤 편집 도구 모음의 옵션을 고르세요. 굵게, 기울임, 밑줄, 취소선도 적용할 수 있어요.
- 링크: 인라인 편집기로 푸터에 하이퍼링크를 쉽게 넣을 수 있어요. 링크로 만들 텍스트를 선택하고, 도구 모음의 **링크** 아이콘을 누른 뒤 원하는 URL을 입력하세요. 회사 웹사이트나 서비스 이용약관, 개인정보 처리방침 같은 특정 페이지로 연결할 때 편해요.
- 정렬과 간격: 디자인에 맞게 텍스트를 왼쪽, 오른쪽, 가운데로 정렬하세요. 줄 간격도 조정해서 푸터 텍스트를 읽기 쉽고 깔끔하게 보이게 할 수 있어요.

#### 동영상

멀티미디어 콘텐츠로 수신자의 관심을 끌 수 있어요. **동영상** 요소를 넣고 호스팅된 동영상 콘텐츠에 연결하세요.

![동영상 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367283/original/p-LoL9bxbUTDuCFcYZBfUhLyq5Jo-Vd24Q.png?1685735283)

![동영상 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972848/original/GmKyhQlId1Xyg7HnXNnZfY9z_hTTtMCsZw.png?1792674901)

- **Video Type**(동영상 유형): 동영상이 호스팅된 플랫폼을 선택해요. YouTube, Vimeo, Wistia, HTML 5 video 중에서 고를 수 있어요.
- **동영상 URL**: 넣으려는 동영상의 URL을 붙여 넣어요. 선택한 플랫폼에 있는 동영상의 직접 링크여야 해요.
- **동영상 썸네일**: 재생하기 전에 보이는 이미지예요. 직접 만든 썸네일(최대 10MB)을 올리거나 이미지 URL을 쓸 수 있어요. 예를 들어 **미디어 라이브러리**에 있는 대체 이미지를 쓸 수 있어요.
- **Width**(너비)와 **높이**: 이메일 안에서 동영상 플레이어의 크기를 정해요. 높이와 너비를 '자동'으로 설정하면 동영상 화면 비율과 이메일의 남는 공간에 맞춰 크기가 조정돼요.
- **Play Button Size**(재생 버튼 크기): 동영상 썸네일에 표시되는 재생 버튼의 크기를 고르세요. 보통 작게, 중간, 크게 중에서 선택해요.
- **Play Button Opacity**(재생 버튼 불투명도): 재생 버튼이 얼마나 보일지 조정해요. 디자인에 맞게 더 투명하게 또는 더 진하게 만들 수 있어요.
- **여백**: 동영상 플레이어 주변 공간이에요. 위, 아래, 왼쪽, 오른쪽 여백을 조정해서 이메일 레이아웃에 동영상이 딱 맞게 들어가도록 하세요.

#### Shopping Cart(장바구니)

이커머스 사업을 한다면 **Shopping Cart** 요소로 상품 정보, 가격, 온라인 스토어 바로가기 링크를 넣을 수 있어요. 수신자가 관심 있던 상품을 다시 떠올리고 구매를 마무리하도록 유도하는 데 쓰여요.

![Shopping Cart 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367318/original/qXhlqMqV0wHc3GbUJrkKJCF_xEgcQMdQrQ.png?1685735372)

![Shopping Cart 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972957/original/gx7kkiSt2FNsVDw6kg61TeSk1XBLMjhG9w.png?1792674941)

이 영역은 다음과 같이 설정해요.

- **여백**: 장바구니 내용 주변 공간을 조정해서 이메일의 다른 섹션과 시각적으로 구분해요. 장바구니 영역의 위, 아래, 왼쪽, 오른쪽 여백을 각각 조정할 수 있어요.
- **글꼴**: 장바구니 텍스트의 글꼴을 고르세요. 시스템 기본 글꼴이나 이메일 디자인에 어울리는 다른 스타일을 쓸 수 있어요.
- **텍스트 색상**: 장바구니 텍스트 색상을 정해요. 검은색(#000)이나 이메일 디자인에 맞는 다른 색을 쓸 수 있어요.
- **배경 색상**: 장바구니 배경 색상을 선택해요. 흰색(#ffffff)이나 텍스트가 잘 읽히는 다른 색을 쓸 수 있어요.

**Shopping Cart** 요소 안에서는 보통 상품마다 다음 정보를 표시해요.

- **상품명**: 웹사이트나 온라인 스토어에 표시되는 상품 이름이에요.
- **가격**: 상품 한 개의 가격이에요.
- **수량**: 고객이 선택한 해당 상품의 개수예요.
- **Line Price**(품목별 금액): 해당 품목의 합계 금액이에요(가격 × 수량).

장바구니에 담긴 상품마다 같은 과정을 반복하세요. 이렇게 자세한 정보를 보여 주면 고객이 주문 내용을 투명하게 확인할 수 있고, 결제 단계로 넘어갈 가능성도 높아져요.

이렇게 장바구니 영역을 설정하면 사용자 경험이 좋아지고 이메일 전체 디자인과도 어울려요. 구매 전환에도 도움이 될 수 있어요.

#### RSS Header(RSS 헤더)

이메일 빌더의 **RSS Header** 블록은 RSS 피드의 `<channel>` 태그 정보를 이메일 캠페인에 자동으로 채워 넣어요.

![RSS Header 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367385/original/rRmv-SVDKBIg7IL4acN83y3pI5ggciO17w.png?1685735522)

![RSS Header 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083973043/original/Gpzoljdp-RjIIXK5xMuqG_1lCvV84Coccw.png?1792674978)

쓸 수 있는 태그와 각 태그에 해당하는 커스텀 값은 다음과 같아요.

| 태그 | 커스텀 값 |
| --- | --- |
| `<title>` | `{{rss_feed.title}}` |
| `<description>` | `{{rss_feed.description}}` |
| `<link>` | `{{rss_feed.url}}` |
| `<lastBuildDate>` | `{{rss_feed.date}}` |

**RSS Header** 블록에서는 **기본**과 **사용자 지정** 중에서 선택할 수 있어요.

**기본**을 고르면 텍스트 편집기에 다음과 같이 수정할 수 없는 텍스트가 들어가요.

```
<h1 class="h1">{{rss_feed.title}}</h1> {{rss_feed.description}}<br /> <br />
```

**사용자 지정**을 고르면 텍스트 편집기에 다음과 같이 수정할 수 있는 텍스트가 들어가요.

```
Updates from {{rss_feed.url}} <h1>{{rss_feed.title}}</h1> <strong>{{rss_feed.description}}</strong><br /> <br /> <strong>In the {{rss_feed.date}} edition:</strong><br />
```

이 RSS `<channel>` 변수는 이메일 캠페인의 제목 입력란에도 쓸 수 있어요.

#### RSS Items(RSS 항목)

RSS 피드를 쓸 때 **RSS Items** 요소는 RSS 피드의 콘텐츠를 이메일 캠페인에 자동으로 채워 넣는 자리표시자 역할을 해요. RSS 항목에는 블로그 게시글, 뉴스, 기사 등 RSS 피드로 볼 수 있는 모든 게시 콘텐츠가 해당돼요.

![RSS Items 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367932/original/KXeCwwcrr1bgCt_nLQJ3g50ATWIIHanFsw.png?1685736584)

![RSS Items 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083973129/original/figwCJPCWESF2EOjGrDIi6tF7BsTSPTb1g.png?1792675024)

RSS 편집 옵션은 다음과 같아요.

- **발췌문**: RSS 피드 항목의 원문에서 요약이나 일부만 표시해요. 구독자에게 미리보기를 보여 주고, 웹사이트에서 전체 내용을 읽도록 유도하고 싶을 때 유용해요.
- **Excerpts with Image**(이미지가 있는 발췌문): **발췌문**처럼 원문의 요약이나 일부를 표시하고, RSS 항목에 연결된 이미지도 함께 보여 줘요. 시각적 효과가 좋아서 참여율을 높이는 데 도움이 될 수 있어요.
- **제목**: 각 RSS 항목의 제목만 표시해요. 간결한 방식이에요. 제목만으로도 내용이 잘 전달되거나 독자의 호기심을 끌 수 있을 때 효과적이에요.
- **전체 콘텐츠**: 각 RSS 항목의 전체 내용을 이메일에 가져와요. RSS 항목이 짧거나 이메일 안에서 모든 정보를 제공하고 싶을 때 유용해요. 다만 항목이 길면 이메일도 길어질 수 있어요.
- **사용자 지정**: RSS 피드에서 어떤 정보를 이메일에 넣고 어떻게 표시할지 직접 정해요. 예를 들어 제목, 짧은 발췌문, 작성자 이름, 전체 글 링크를 넣을 수 있어요. 설정할 것이 더 많지만, 피드 항목을 보여 주는 방식을 가장 자유롭게 조정할 수 있어요.

이 요소는 RSS 항목의 다음 속성을 자동으로 가져와요.

- 게시글/항목 제목: `{{rss_item.title}}`
- 게시글/항목의 요약 또는 설명: `{{rss_item.content}}`
- 원본 게시글/항목의 직접 URL 링크: `{{rss_item.url}}`
- 게시글/항목의 게시 날짜: `{{rss_item.date}}`
- 게시글/항목의 작성자: `{{rss_item.author}}`

**RSS Items** 요소를 이메일에 넣으면 어떤 정보를 어떻게 보여 줄지 정할 수 있어요. 제목만 보여 주거나, 제목과 요약을 함께 보여 주거나, 전체 게시글로 가는 하이퍼링크까지 넣을 수도 있어요.

디자인 설정도 가능해요. 이메일 분위기에 맞게 요소 주변의 위, 아래, 왼쪽, 오른쪽 여백을 조정할 수 있어요. 각 게시글의 이미지를 이메일에 넣을지 말지도 선택할 수 있어요.

#### 레이아웃

**레이아웃**은 이메일 콘텐츠의 구조를 정해요. 단순한 1단 구성부터 더 복잡한 구조까지 여러 옵션이 있어요.

![레이아웃 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083973224/original/QLwjdXlPElwrmBpWJr22ojjC9-wbLh26aA.png?1792675053)

레이아웃별 설명은 다음과 같아요.

- **1**: 1단 구조예요. 모든 콘텐츠가 세로 한 줄로 배치돼요. 이메일에서 가장 기본적이고 흔한 레이아웃이에요. 특히 모바일 같은 작은 화면에서 읽기 좋아요.
- **2**: 2단 구조예요. 이메일 콘텐츠가 세로 2개 열로 나뉘어요. 이미지와 텍스트 블록, 또는 RSS 피드의 기사 2개처럼 콘텐츠 2개를 나란히 보여 줄 때 알맞아요.
- **1/3 : 2/3**, **2/3 : 1/3**: 콘텐츠가 서로 다른 너비의 2개 열로 나뉘어요. **1/3 : 2/3**는 한 열이 전체 너비의 1/3, 다른 열이 2/3를 차지해요. **2/3 : 1/3**은 그 반대예요. 이미지를 중심으로 두고 설명을 곁들이는 경우처럼 한쪽 콘텐츠를 더 돋보이게 할 때 좋아요.
- **1/4 : 3/4**, **3/4 : 1/4**: 위와 비슷하지만 한 열이 1/4, 다른 열이 3/4를 차지하고, 반대 구성도 있어요. 작은 내비게이션 메뉴와 넓은 콘텐츠 영역처럼 한쪽 콘텐츠가 훨씬 중요할 때 유용해요.
- **4**: 4단 구조예요. 이메일 콘텐츠가 같은 너비의 세로 4개 열로 나뉘어요. 이미지 그리드나 RSS 피드의 여러 기사처럼 같은 비중의 콘텐츠 여러 개를 나란히 보여 줄 때 유용해요.

이 레이아웃들을 쓰면 상황과 이메일 유형에 맞게 콘텐츠를 다양하게 구성할 수 있어요. 옵션을 이해해 두면 이메일에 가장 효과적인 레이아웃을 고를 수 있어요.

위 요소들을 이메일에 추가하려면 캔버스로 끌어다 놓으세요. 편집할 요소를 선택하면 인라인 편집기가 나타나고, 선택한 요소를 원하는 대로 바꿀 수 있는 여러 옵션이 표시돼요.

**이메일 빌더**의 인라인 편집기로 텍스트와 서식을 다루는 방법을 설명해요. 요소 관리, **화면 스타일**, **모바일 서식** 설정도 함께 다뤄요. 이 문서는 3부작 중 2부예요.

![링크 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034104204/original/OdoOabg73mZdyxjKfE1Vkpo6mopk_0p6EA.jpeg?1728042836)

**링크 편집**: 이메일에 새 하이퍼링크를 추가하거나, 이미 넣은 링크를 수정하는 옵션이에요.

**링크 URL**: 링크를 클릭했을 때 이동할 웹 주소(URL)예요. 웹페이지, 다운로드 파일, 그 밖의 온라인 자료를 연결할 수 있어요. URL이 정확하고 제대로 열리는지 꼭 확인하세요.

**표시할 텍스트**: 이메일에 보이고 클릭할 수 있는 글자예요. "더 알아보기", "지금 다운로드" 같은 행동 유도 문구나 연결할 웹페이지 이름을 쓰면 돼요. 연결된 내용을 알 수 있도록 짧고 분명하게 쓰는 것이 좋아요.

**제목**: 입력하지 않아도 되는 항목이에요. 링크에 대한 추가 정보를 담을 수 있어요. 수신자가 링크 위에 마우스를 올리면 툴팁으로 보이는 경우가 많아요. 링크의 배경 설명이나 이동할 곳을 알려 줄 수 있어요.

**링크 열기 위치**: 새 창을 선택하면 수신자가 링크를 클릭할 때 현재 창 대신 새 브라우저 창이나 탭에서 열려요. 수신자가 이메일이나 보던 웹페이지에서 벗어나지 않게 하고 싶을 때 유용해요.

**링크 목록**: 이전에 사용했거나 저장해 둔 링크가 담긴 드롭다운 메뉴일 수 있어요. 자주 쓰는 링크를 더 빠르고 쉽게 넣을 수 있어요.

텍스트 정렬과 줄 높이를 조정하거나 글머리 기호를 넣을 수도 있어요.

![텍스트 정렬 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108731/original/-sXSCSMBTBgBZnWCUxpSLfdLVTswZUk-tg.png?1728045588)

![줄 높이 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108773/original/l0Ion--7quZWh3nZ8I9DfCWNRi8pfzntKQ.png?1728045619)

![글머리 기호 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108788/original/SpHu5N_Z-BymA69QaftnYT24YJuiGGwvMw.png?1728045640)

글머리 기호 유형은 다음과 같아요.

**Disc**(채워진 원): 속이 채워진 동그라미예요. HTML에서 순서 없는 목록의 기본 스타일이에요.

**Circle**(빈 원): 속이 빈 동그라미(고리 모양)예요. 순서 없는 목록에서 두 번째, 세 번째 수준 항목에 주로 써요.

**정사각형**: 속이 채워진 네모예요. 변화를 주거나 강조하고 싶을 때 Disc나 Circle 대신 쓸 수 있어요.

**Decimal**(숫자): 1, 2, 3처럼 일반적인 숫자 기호예요. 순서가 중요한 목록에 주로 써요.

**Lower Alpha**(영문 소문자): a, b, c처럼 영문 소문자 기호예요. 순서 있는 목록 안의 하위 항목에 자주 써요.

**Lower Greek**(그리스 문자 소문자): 알파, 베타, 감마 같은 그리스 문자 소문자 기호예요. 자주 쓰지는 않지만 일반 기호 대신 색다르게 쓸 수 있어요.

**Lower Roman**(로마 숫자 소문자): i, ii, iii처럼 로마 숫자 소문자 기호예요. 법률 문서처럼 격식 있거나 전통적인 문서에 자주 써요.

**Upper Alpha**(영문 대문자): A, B, C처럼 영문 대문자 기호예요. 순서 있는 목록의 주요 항목에 자주 써요.

**Upper Roman**(로마 숫자 대문자): I, II, III처럼 로마 숫자 대문자 기호예요. 소문자 로마 숫자처럼 격식 있거나 전통적인 문서에 자주 써요.

## 고급 편집 옵션 사용하기

인라인 편집기에는 고급 편집 옵션도 있어요. **서식 지우기**를 쓰면 선택한 텍스트에서 기존 서식을 모두 없애요. 다른 곳에서 복사한 텍스트를 붙여 넣을 때 편리해요.

![서식 지우기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108820/original/-GVLMpeYCWrPTD6yUTRd5CEeWZFYB1UE3Q.png?1728045677)

**커스텀 값**: 수신자의 이름이나 지역 같은 정보를 이메일에 넣어 개인화해 줘요. 수신자마다 이메일 내용이 더 잘 맞아서 참여율을 높이는 데 도움이 돼요.

**서비스 및 렌탈 커스텀 값**: 이메일 내용을 만들거나 편집할 때 이메일 빌더의 커스텀 값 선택기에서 지원되는 **서비스**와 **렌탈** 커스텀 값을 바로 고를 수 있어요. 예약 관련 정보를 직접 입력하거나 외우지 않고도 쉽게 넣을 수 있어요.

선택기에서 필요한 서비스 또는 렌탈 커스텀 값을 선택하면 이메일 내용에 삽입돼요.

![커스텀 값 선택기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034109121/original/6oxFeaWK7INztLF5qu_X0HWB4nZkt41iIg.jpeg?1728045887)

**트리거 링크**: 수신자가 이메일에서 바로 구독 확인, 수신거부, 특별 오퍼 확인 같은 행동을 할 수 있게 해 줘요. 수신자의 행동이 간단해져서 참여와 전환을 높이는 데 도움이 돼요.

![트리거 링크](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108891/original/O64_8g_YlwM4Xt9Fn6LjDcAYUCOKw8t7lQ.png?1728045724)

**콘텐츠 AI** 기능은 인공지능으로 텍스트 콘텐츠 작성을 도와줘요. 콘텐츠 제목, 설명, 키워드를 입력하면 알맞은 텍스트를 자동으로 만들어 줘요. 자세한 내용은 아래를 참고하세요.
![콘텐츠 AI 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033414105/original/LWVq6Er5rHqRBNePkyPld-KudW2yjGPVXQ.png?1727156790)

**맥락**: AI가 만들 콘텐츠의 맥락을 입력해요. AI가 전체 주제를 이해하는 데 도움이 돼요. "디지털 마케팅"이나 "건강 레시피"처럼 무엇이든 쓸 수 있어요. 맥락을 구체적으로 쓸수록 결과가 더 정확해요.

**Content Title**(콘텐츠 제목): 만들고 싶은 콘텐츠의 핵심 주제나 아이디어를 입력해요. AI는 이 제목을 바탕으로 콘텐츠를 만들어요. 블로그 제목, 이메일 제목줄, 상품 설명 등을 쓸 수 있어요.

**간단한 콘텐츠 설명 제공**: 원하는 콘텐츠를 간단히 설명해요. AI가 콘텐츠를 만들 때 고려했으면 하는 세부 내용이나 관점을 넣을 수 있어요.

**키워드 추가**: 콘텐츠를 나타내는 단어나 구문이에요. AI가 이 표현을 자연스럽게 콘텐츠에 넣어요. 특히 SEO에 도움이 될 수 있어요.

**작성 톤**: 글의 어조를 정해요. 전문적, 친근함, 격식 없음, 권위 있음 등을 고를 수 있어요. AI가 선택한 톤에 맞춰 콘텐츠를 만들어요.

**Number of Variations**(변형 수): AI가 만들 콘텐츠 버전의 수를 정해요. 여러 결과 중에서 가장 알맞은 것을 고를 수 있어요. 최대 5개까지 만들 수 있어요.

## 요소 관리(Manage Elements)

**Manage Elements**(요소 관리)에서는 이메일 안의 각 요소를 관리해요. 이 영역에서 요소를 선택하면 데스크톱, 모바일, 또는 둘 다에서 보일지 정할 수 있어요.

![요소 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034101650/original/wKRH_G0nGBm-HhipPli_f5FPbOudnHGCTA.png?1728041285)

표시 설정으로 기기마다 요소가 어떻게 보일지 조절해요. 모바일 표시와 데스크톱 표시 설정을 쓰면 데스크톱이나 모바일에서 볼 때 이메일(또는 웹페이지)의 어떤 요소를 보여 줄지 고를 수 있어요.

모바일 표시는 스마트폰이나 태블릿 같은 모바일 기기에서 이메일이나 웹페이지 요소가 어떻게 보이는지를 말해요. 화면이 작아서, 잘 보이지 않는 요소는 숨기거나 내용을 단순하게 줄일 수 있어요. 모바일에 맞게 요소를 재배치하거나 크기를 바꿀 수도 있어요.

![모바일 표시 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000369146/original/Yvs3IeM4Iq-7TwRlttbuEuV97nsWvc3nLw.png?1685740278)

데스크톱 표시는 데스크톱 기기에서 이메일이나 웹페이지 요소가 어떻게 보이는지를 말해요. 데스크톱 화면은 더 넓어서 모바일 화면에는 맞지 않는 요소도 넣을 수 있어요. 모바일에서는 쓸 수 없는 마우스 오버 동작이 필요한 요소도 보여 줄 수 있어요.

![데스크톱 표시 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000369159/original/ojy184_ZOKzusnWIbQWdFFtXk_hRazXeXQ.png?1685740294)

각 요소를 따로 편집해서 속성을 바꿀 수도 있어요.

![요소 개별 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000369214/original/EBNo8muVmOtNWuazHcAJf1WPQDTdkHRcIg.png?1685740422)

이메일에 맞지 않는 요소는 **Manage Elements** 영역에서 삭제할 수 있어요.

**Manage Elements** 영역에서 섹션, 열, 요소 위에 마우스를 올리고 클릭하면 화면이 해당 섹션, 열, 요소 위치로 스크롤돼요.

## 화면 스타일 조정하기

**화면 스타일**에서는 템플릿의 전체적인 모습과 분위기를 조정해요.

![화면 스타일 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032210122/original/PdZexKgAxNWLj2gCZYgFBy_SboGv3yTqxQ.png?1725437066)

#### 템플릿

템플릿의 색상 구성을 고르고, 배경 이미지를 올리고, 이메일 콘텐츠의 너비도 정할 수 있어요.

![템플릿 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033414269/original/n7uy7xfXNKR0X1_dJrRw_t9Kt-Cz0acY_w.png?1727156995)

**배경 색상**: 이메일 콘텐츠 뒤에 보이는 색이에요. 메시지의 디자인과 분위기에 맞는 색을 고르세요. 배경 색상을 잘 고르면 이메일이 더 읽기 쉽고 보기 좋아져요.

#### 색상 필드에서 커스텀 값 사용하기(실시간 반영)

**배경 색상**, **본문 색상**, **버튼 색상** 같은 색상 입력란에 커스텀 값을 쓸 수 있어요.

커스텀 값 토큰을 입력하면 빌더가 캔버스에 바로 색상을 적용해요. 색상 변경을 확인하려고 **미리보기 모드**로 바꿀 필요가 없어요.

![색상 필드의 커스텀 값 예시](https://jumpshare.com/share/kYtmv6GLLOVU3mU1dAEF+/Screen+Shot+2026-02-09+at+10.20.52+PM.png)

**본문 색상**: 이메일의 주요 콘텐츠 영역, 즉 본문의 색이에요. 텍스트, 이미지 등 다른 요소가 이 영역 안에 들어가요. 읽기 쉽도록 본문 색상은 텍스트나 다른 요소와 대비가 잘 되는 색으로 정하세요.

**콘텐츠 너비**: 이메일 안 콘텐츠 영역의 너비예요. 기본값은 표준 너비인 600픽셀로 설정되어 있을 수 있어요. 디자인 필요와 넣을 콘텐츠에 맞게 조정할 수 있어요. 콘텐츠가 너무 넓으면 모든 화면, 특히 모바일 기기에서 잘 보이지 않을 수 있어요.

**배경 이미지**: 이메일 배경으로 보일 이미지를 올려요. 메시지에 시각적인 재미와 브랜드 이미지를 더하기 좋아요. 모든 이메일 클라이언트가 배경 이미지를 지원하는 것은 아니니, 대체 색상을 함께 설정해 두는 것이 좋아요.

최대 업로드 크기는 배경으로 올릴 수 있는 가장 큰 이미지 파일 크기를 말해요. 파일이 크면 불러오는 데 오래 걸리고 일부 이메일 클라이언트에서는 제대로 지원되지 않을 수 있어요. 보통은 웹용으로 최적화한 이미지를 쓰는 것이 좋아요.

**Background Image URL**(배경 이미지 URL): 컴퓨터에서 이미지를 올리는 대신 외부에 올려 둔 이미지나 CRM의 **미디어 라이브러리**에 있는 이미지의 URL을 입력할 수 있어요. 이메일을 열 때 이 URL에서 이미지를 불러와요. 모든 수신자에게 제대로 보이도록 이미지 URL은 보안(HTTPS) 주소이고 안정적으로 불러와지는지 확인하세요.

#### 버튼

**화면 스타일**의 **버튼** 섹션에서는 행동을 유도하는 버튼을 디자인하고 꾸밀 수 있어요. 이메일이 더 인터랙티브하고 눈에 띄게 만들 수 있어요.

**모서리 반경**: 버튼 모서리의 둥근 정도를 조정해요. 값이 9이면 모서리가 적당히 둥글어져요.

**버튼 색상**: 브랜드나 이메일 테마에 맞게 버튼 색을 정해요.

**글꼴**: 버튼 텍스트의 글꼴과 크기를 정해요. 예시 화면에서는 글꼴 Arial, 크기 16이 선택되어 있어요.

**Text Styling**(텍스트 스타일):

버튼 안의 굵은 텍스트, 기울임꼴 텍스트, 밑줄 텍스트에 각각 다른 색을 지정할 수 있어요. 핵심 단어나 문구를 강조해서 더 눈에 띄는 버튼을 만들 수 있어요.

#### 구분선

**화면 스타일**의 **구분선** 섹션에서는 이메일 콘텐츠를 구분하고 구조화하는 선을 꾸밀 수 있어요.

![구분선 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000377932/original/7Ic6nTQcF_9KMZ-rLjwANe3quP4WQIAIPQ.png?1685778380)

**높이**: 구분선의 두께를 정해요. 기본값은 2픽셀이고, 이메일의 분위기에 맞게 바꿀 수 있어요. 두꺼운 선은 눈에 더 잘 띄고, 얇은 선은 섹션을 은은하게 나눠요.

**색상**: 구분선의 색을 정해요. 이메일 전체 색상 구성과 어울리는 색을 쓰면 시각적으로 통일감이 생겨요.

**스타일**: 구분선의 모양을 고를 수 있어요.

#### 사용자 지정 CSS

**사용자 지정 CSS** 섹션에서는 CSS 스타일을 추가해 이메일 레이아웃을 더 세밀하게 꾸밀 수 있어요. 다만 CSS와 이메일 디자인에서의 영향을 잘 알고 있어야 해요. 이메일 클라이언트가 다양하고 렌더링 방식도 달라서, 이메일의 CSS는 웹 디자인과 조금 다르게 동작해요.

![사용자 지정 CSS 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000378079/original/aLNlE61zesfaDmaT33jLXS8pwzSvLnVQ-g.png?1685778956)

시작할 때 참고하면 좋은 자료예요.

1. [CSS Tricks](https://css-tricks.com/): CSS와 효과적인 활용법에 대한 정보가 풍부한 웹사이트예요. 이메일에서 CSS를 쓰는 방법을 다룬 글도 많아요.
2. [Litmus](https://litmus.com/blog/category/coding): 잘 알려진 이메일 테스트 도구예요. 블로그에 CSS를 포함한 이메일 코딩 관련 심층 글이 많아요.
3. [Smashing Magazine: An Introduction To Building And Sending HTML Email For Web Developers](https://www.smashingmagazine.com/2017/01/introduction-building-sending-html-email-for-web-developers/): 이메일의 HTML과 CSS를 종합적으로 설명하는 가이드예요.
4. [MDN Web Docs: Using CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties): Mozilla의 개발자 네트워크로, 웹 개발자가 믿고 보는 자료예요. 사용자 지정 CSS 블록에서 활용할 수 있는 CSS 사용자 지정 속성의 사용법을 설명해요.
5. [Email Design Workshop: CSS in Email](https://emaildesign.beefree.io/2016/08/css-in-email/): 이메일에서 CSS를 쓰는 기본 개념을 알기 쉽게 정리한 가이드예요.
6. [Can I email…](https://www.caniemail.com/): "Can I use…"의 이메일 버전이에요. 주요 이메일 클라이언트가 어떤 CSS 속성과 HTML 요소를 지원하는지 확인할 수 있는 유용한 자료예요.

## 모바일 서식

요즘은 이메일이 모든 기기에서 보기 좋아야 해요. 그래서 **이메일 빌더** 인라인 편집기에는 **모바일 서식** 섹션이 따로 있어요. 여기서 모바일 기기로 볼 때 어떤 제목, 단락, 버튼을 표시할지 정할 수 있어요. 데스크톱과 모바일 모두에 맞게 이메일을 최적화할 수 있어요.

![모바일 서식 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083973541/original/GI3PDiaZWMdRRCo6XJPiRkRRm2qKFCdVYQ.png?1792675222)

이 설정은 이메일 템플릿의 모바일 화면에만 적용되고, 미디어 쿼리를 지원하는 이메일 클라이언트에서 적용돼요.

#### H1

**글꼴 크기**: 모바일에서 주요 제목의 크기예요. 눈길을 끌 만큼 크되 화면을 가득 채우거나 스크롤이 길어질 만큼 크지는 않게 정하세요. 모바일은 화면이 작아서 데스크톱과 보는 경험이 많이 달라요. 균형을 맞추는 것이 중요해요.

**텍스트 정렬**: 모바일 화면에서는 정렬에 따라 콘텐츠가 읽히는 정도가 달라져요. 모바일은 세로로 긴 화면이라 균형이 잘 맞는 중앙 정렬을 많이 써요.

**줄 높이**: 모바일은 화면이 작아서 읽기 편하려면 줄 간격이 더 중요해요. 1.5로 설정하면 편안하게 읽을 수 있어요.

#### H2

**글꼴 크기**: 모바일 화면에서 보조 제목의 크기를 정해요. H1보다 작지만 정보의 위계를 구분할 수 있을 만큼은 눈에 띄어야 해요.

**텍스트 정렬**: H1처럼 모바일에서는 중앙 정렬이 잘 맞는 경우가 많지만, 콘텐츠와 디자인에 따라 가장 알맞은 정렬은 달라질 수 있어요.

**줄 높이**: H1과 같은 원칙이 적용돼요. 줄 높이는 독자가 한 줄에서 다음 줄로 얼마나 쉽게 넘어가는지를 좌우해요. 작은 모바일 화면에서는 특히 그래요.

#### H3

**글꼴 크기**: 세 번째 단계 제목은 구분은 되되 지나치게 튀지 않아야 해요. H1, H2보다 작은 글꼴 크기로 구분하되, 모바일 화면에서 읽을 수 있는 크기여야 해요.

**텍스트 정렬**: H3의 정렬은 디자인 필요와 콘텐츠에 따라 달라질 수 있어요. H1, H2와 같게 맞추면 보통 시각적으로 통일감이 생겨요.

**줄 높이**: 줄 높이를 알맞게 정하면 작은 화면에서도 콘텐츠를 쉽게 읽을 수 있어요.

#### 단락

**글꼴 크기**: 단락 텍스트는 모바일 화면에서 편하게 읽을 수 있어야 해요. 그래서 데스크톱에서 쓰는 것보다 글꼴을 조금 크게 하는 경우가 많아요.

**텍스트 정렬**: 왼쪽에서 오른쪽으로 읽는 언어에서는 모바일 단락을 보통 왼쪽 정렬로 해요. 다만 콘텐츠와 디자인 필요에 따라 달라질 수 있어요.

**줄 높이**: 긴 글에서는 단락의 줄 간격을 편안하게 유지하는 것이 특히 중요해요. 글이 덜 빽빽해 보이고 작은 화면에서도 따라 읽기 쉬워요.

#### 버튼

**글꼴 크기**: 버튼 텍스트는 모바일 기기에서 읽고 누르기 쉬워야 해요. 글꼴을 크게 하면 잘못 누르는 일을 줄이고 행동 유도 문구도 더 분명해져요.

이 값들은 모두 출발점일 뿐이에요. 콘텐츠, 독자, 전체 디자인에 따라 모바일에서 가장 보기 좋도록 설정을 조정하세요.

## 모바일 이메일 설정 모범 사례

모바일 이메일을 설정할 때는 이메일의 사용성과 효과에 영향을 주는 몇 가지 핵심 사항에 신경 써야 해요.

단일 열 레이아웃 사용하기: 모바일에는 단일 열 레이아웃이 가장 잘 맞아요. 작은 화면에 맞게 줄이기 쉬워요. 열이 여러 개이면 모바일 화면에서 복잡해 보이고 사용자가 보기 혼란스러울 수 있어요.

이미지 최적화하기: 이미지는 품질은 높게, 파일 크기는 작게 유지해서 빠르게 불러오게 하세요. 보는 화면에 맞춰 자동으로 크기가 조정되는 반응형 이미지를 쓰는 것도 고려하세요. 접근성을 위해 대체 텍스트도 꼭 넣으세요.

터치하기 쉬운 버튼 만들기: 모바일 기기에서는 행동 유도 버튼을 마우스로 클릭하기보다 손가락으로 누르는 경우가 대부분이에요. 버튼이 쉽게 눌릴 만큼 크도록 하세요. 최소 44px × 44px를 권장해요.

텍스트 양 줄이기: 모바일에서는 긴 글이 부담스러워요. 간결하게 쓰고, 글을 작게 나눠서 한눈에 들어오게 하세요. 글머리 기호와 소제목을 활용하면 읽기 쉬워요.

반응형 이메일 디자인 사용하기: 이메일이 어떤 기기에서 열리든 화면에 맞게 자동으로 조정돼요.

미리보기와 테스트하기: 이메일이 제대로 표시되는지 여러 기기와 이메일 클라이언트에서 항상 미리보고 테스트하세요.

여백 넣기: 여백은 낭비가 아니에요. 이메일이 더 깔끔해지고 작은 화면에서 읽기 쉬워져요.

글꼴 크기와 스타일: 글꼴 크기는 작은 화면에서도 읽을 수 있을 만큼 크게 유지하세요. 본문은 14, 제목은 22를 많이 권장해요. 읽기 어려울 수 있는 화려한 글꼴은 피하세요.

명확하고 간결한 행동 유도 문구: 행동 유도 문구는 분명하고 간결하며 찾기 쉬워야 해요. 행동 유도 버튼은 보통 화면 중간에 두는 것이 가장 좋아요.

제목줄과 프리헤더 텍스트 최적화하기: 제목줄은 짧고 눈길을 끌게 쓰고, 프리헤더 텍스트에는 이메일 내용의 요약이나 맛보기를 담으세요. 제목줄 버전을 여러 개 만들어 A/B 테스트해서 독자에게 가장 잘 맞는 것을 찾는 것도 좋아요.

이미지보다 일반 텍스트 우선하기: 일부 이메일 클라이언트는 이미지를 자동으로 표시하지 않아요. 메시지가 전달되도록 가능한 한 텍스트를 쓰고, 꼭 필요할 때만 이미지를 쓰세요.

수신거부 옵션: 수신자가 쉽게 이메일 수신을 거부할 수 있게 하세요. 법적 요구 사항일 뿐 아니라 사용자 경험도 좋아져요.

접근성: 누구나 이메일을 볼 수 있게 만드세요. 큰 글꼴을 쓰고, 텍스트와 배경의 대비를 충분히 주고, 이미지에 대체 텍스트를 넣는 것이 포함돼요.

## 이메일 빌더에서 브라우저에서 미리보기 링크 사용하기

### 

### 커뮤니티의 다른 튜토리얼

이제 새 캠페인과 기존 캠페인에 **브라우저에서 미리보기** 링크를 쉽게 넣어서 이메일 디자인을 정확하게 보여 줄 수 있어요.

### 추가하는 방법

기본 포함: 모든 빈 이메일 템플릿에는 맨 위에 **브라우저에서 미리보기** 링크가 기본으로 들어가요.

기존 캠페인이나 템플릿에 직접 추가하기:

1. **이메일 마케팅**으로 이동해서 캠페인이나 템플릿을 열어요.
2. **Preview URL**(미리보기 URL) 요소를 추가해요.

   ![Preview URL 요소 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034098899/original/pbqV1FA9BLB4z8M_I-Q5cThF9xflxHkPrg.png?1728039559)

3. 텍스트를 직접 편집하거나 링크 추가 옵션을 써서 텍스트 스타일과 서식을 바꿔요.

   ![텍스트 스타일 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034099578/original/eteVbdWVd15KAAyOCl-nZ3YoD0iqX3VQKQ.png?1728040004)

**이메일 빌더**로 만든 이메일을 발송 전에 미리보기와 테스트 발송으로 확인하는 방법을 안내해요. 업종별로 어떤 템플릿을 쓰면 좋은지 묻는 질문도 함께 정리했어요.

## 자주 묻는 질문

### 어떤 이메일 요소가 가장 효과적인지 테스트하고 싶어요. 이메일 빌더가 어떻게 도움이 되나요?

A/B 테스트 기능을 사용하면 돼요. 자세한 방법은 [A/B 테스트 가이드](../../09-이메일/기타/how-to-set-up-a-b-testing-for-your-email-campaigns.md)를 참고하세요.
제목, 콘텐츠, CTA(행동 유도 버튼) 같은 이메일 구성 요소를 각각 테스트해서 어떤 쪽이 고객에게 반응이 좋은지 확인할 수 있어요.

### 레스토랑을 운영하는데, 새 메뉴를 고객에게 알리려면 어떤 템플릿을 써야 하나요?

"Restaurant Generic" 템플릿을 사용하세요. 새 요리를 소개하기에 알맞은 다양한 레이아웃이 있어요.

### 법률 사무소를 운영하는데, 새 서비스를 알리려면 어떤 템플릿이 좋을까요?

"Legal Minds" 또는 "Justice Law Firm" 템플릿을 추천해요. 전문적인 느낌이라 서비스를 소개하기에 잘 맞아요.

### 자선 단체를 운영하는데, 기부를 요청하는 이메일은 어떻게 만들어야 하나요?

"Helping Hand Charity" 또는 "Giving Back Foundation" 템플릿을 사용하세요. 단체의 활동과 기부의 의미를 설득력 있게 전달하는 메시지를 만들 수 있어요.

### 물리치료 클리닉을 운영하는데, 고객에게 건강 팁과 운동법을 알리려면 어떤 템플릿을 써야 하나요?

"Physical Therapy" 템플릿을 사용하세요. 건강 팁과 운동 정보를 전달하도록 만들어진 템플릿이에요.

### 회계 법인을 운영하는데, 재무 관리 팁을 담은 뉴스레터를 보내려면 어떤 템플릿이 좋을까요?

"Accurate Accounting Agency" 또는 "Accounting Generic" 템플릿을 사용하세요. 재무 팁과 조언을 전달하기에 잘 맞아요.

### 부동산 중개업을 하는데, 새 매물을 소개하려면 어떻게 해야 하나요?

"Real Estate" 템플릿 중 아무거나 사용할 수 있어요. 각 템플릿마다 매물을 소개하기 좋은 전문적인 레이아웃이 있어요.

### 미용실을 운영하는데, 새 서비스와 프로모션을 알리려면 어떤 템플릿을 써야 하나요?

"Radiance Beauty" 또는 "Hair Salon Generic" 템플릿이 잘 맞아요. 뷰티 서비스와 혜택을 돋보이게 하도록 만들어진 템플릿이에요.

### 여행사를 운영하는데, 휴가 패키지를 홍보하려면 어떤 템플릿을 추천하나요?

"Pinnacle Travel" 또는 "Getaways Travel" 템플릿을 사용하세요. 여행 패키지를 소개하도록 만들어진 템플릿이에요.

### 치과를 운영하는데, 정기 검진 안내 이메일에는 어떤 템플릿이 가장 좋을까요?

"Dentist" 템플릿을 사용하세요. 치과에 맞게 만들어진 템플릿이에요.

### 요가 스튜디오를 운영하는데, 수업 일정과 건강 팁을 공유하려면 어떤 템플릿을 쓰면 좋을까요?

"Yoga Generic" 또는 번호가 붙은 "Yoga" 템플릿 중 아무거나 사용하세요. 수업 일정과 건강 팁을 공유하기에 잘 맞아요.

### 자동차 정비소를 운영하는데, 서비스와 프로모션을 알리려면 어떻게 해야 하나요?

"Auto Repair" 템플릿을 사용하면 서비스와 혜택을 홍보할 수 있어요.

### 헬스장을 운영하는데, 고객에게 운동 팁과 수업 일정을 공유하려면 어떤 템플릿을 추천하나요?

"Gym" 템플릿을 사용해 보세요. 운동과 관련된 콘텐츠를 위해 만들어진 템플릿이에요.

### 통합 웰니스 센터를 운영하는데, 고객에게 웰니스 팁을 공유하려면 어떤 템플릿을 써야 하나요?

"Holistic Wellness Image Layer Generic" 템플릿이 좋은 선택이에요. 웰니스 팁과 조언을 전하기에 잘 맞아요.

### 메드스파를 운영하는데, 새 시술과 프로모션을 알리려면 어떤 템플릿이 가장 좋을까요?

"MedSpa" 템플릿을 사용하세요. 메드스파의 시술과 혜택을 소개하도록 만들어진 템플릿이에요.

### 조경 서비스를 운영하는데, 작업 사례를 소개하려면 이메일 빌더를 어떻게 활용하나요?

"Landscaping Image Layer Generic 1" 템플릿을 사용하세요. 조경 작업과 서비스를 소개하기 좋은 전문적인 레이아웃이에요.

### 신용 점수 관련 회사를 운영하는데, 재무 조언을 공유하려면 어떤 템플릿이 가장 적합할까요?

"Credit Score" 템플릿을 사용하세요. 재무 조언과 팁을 전하도록 만들어진 템플릿이에요.

### 태양광 에너지 회사를 운영하는데, 새 제품과 서비스를 알리려면 어떤 템플릿을 써야 하나요?

"Solar Generic" 또는 번호가 붙은 "Solar" 템플릿이 알맞아요. 태양광 제품과 서비스를 소개하기에 좋아요.

### 법률 사무소를 운영하는데, 법률 조언을 담은 뉴스레터를 보내려면 어떤 템플릿이 좋을까요?

"Attorney Generic" 또는 "Legal Minds" 템플릿을 사용하면 법률 조언과 소식을 전할 수 있어요.

### 클라이밍 짐을 운영하는데, 트레이닝 수업을 홍보하려면 이메일 빌더를 어떻게 활용하나요?

"Peak Climbing" 템플릿을 사용하세요. 클라이밍 수업과 트레이닝 세션을 소개하기에 좋아요.

### 동물 보호소를 운영하는데, 입양 가능한 동물 소식을 보내려면 어떤 템플릿을 써야 하나요?

"Dog Shelter" 또는 "Cat's Cradle" 템플릿이 잘 맞아요. 입양 가능한 동물을 알리기에 알맞아요.
