# 레이아웃 마진과 텍스트 간격 설정

하이퍼클래스 [이메일 빌더](how-to-use-the-email-builder-and-its-in-line-editor.md)에서 섹션 바깥 간격과 텍스트 위아래 간격을 조절하는 방법을 안내해요. 섹션의 **마진**은 섹션 바깥의 세로 간격을, **타이포그래피 설정**은 지원하는 텍스트 스타일의 위아래 간격을 조절해요. 이 두 설정으로 이메일 레이아웃을 더 세밀하게 다듬을 수 있어요.

## 레이아웃 마진과 텍스트 간격이란?

레이아웃 마진과 텍스트 간격은 이메일 디자인의 간격을 조절하는 별도의 설정이에요.

**마진**은 지원하는 섹션 바깥의 세로 간격을 조절해요. 현재 섹션 편집기에서는 상단과 하단 마진 값을 픽셀 단위로 조절할 수 있어요.

**타이포그래피 설정**은 지원하는 단락과 제목 스타일의 위아래 간격을 조절해요. 지원하는 텍스트 스타일마다 따로 켜고, **상단 간격**과 **하단 간격** 값을 각각 설정할 수 있어요.

## 레이아웃 마진과 텍스트 간격의 장점

레이아웃마다 한 가지 방법만 쓰지 않고 상황에 맞게 간격을 조절할 수 있어요.

- 섹션 단위 간격: 지원하는 이메일 섹션의 상단·하단 마진 값을 조절해요.
- 텍스트 스타일별 간격: 단락과 제목 스타일의 위아래 간격을 설정해요.
- 다양한 입력 방식: 섹션 마진을 슬라이더, 픽셀 값 직접 입력, 사용할 수 있는 프리셋 중에서 골라 조절해요.
- 일관된 타이포그래피 설정: 지원하는 텍스트 스타일에 같은 픽셀 값을 반복해서 적용해요.
- 여러 가지 간격 방법: 필요한 레이아웃에 따라 **마진**, **여백**(Padding), **여백**(Spacer) 요소 중 알맞은 것을 써요.

## 레이아웃 마진 조절하기

레이아웃 마진은 선택한 이메일 섹션 바깥의 세로 간격을 조절해요.

1. 서브 계정에서 **마케팅 > 이메일**로 이동해요.
2. **캠페인** 또는 **템플릿**을 열어요.
3. 새 이메일을 만들거나 기존 이메일을 열어요.
4. **디자인 에디터**에서 이메일을 열어요.
5. 간격을 조절할 섹션을 선택해요.
6. **Edit section**(섹션 편집) 패널에서 **Margin and Padding**(마진 및 여백)을 찾아요.
7. 박스 모델에서 **상단** 또는 **하단** 마진 값을 선택해요.
8. 슬라이더로 마진을 조절하거나, **PX** 칸에 값을 직접 입력하거나, 사용할 수 있는 프리셋을 선택해요.
9. 마진 값을 되돌리려면 **재설정**을 선택해요.
10. **이메일 빌더** 화면에서 바뀐 간격을 바로 확인해요. 발송 전에는 [이메일 캠페인/템플릿 미리보기와 테스트](../../09-이메일/기타/preview-and-test-your-email-campaign-templates.md)로도 확인해 보세요.

현재 편집기에 표시되는 마진 프리셋은 다음과 같아요.

- 자동
- 0
- 10
- 20
- 40
- 60
- 80

## 텍스트 간격 조절하기

**타이포그래피 설정**에서 지원하는 단락과 제목 스타일의 위아래 간격을 조절할 수 있어요. 텍스트 요소에 대한 자세한 내용은 [이메일 빌더의 텍스트 요소](text-element-in-email-builder.md)에서 확인하세요.

1. **디자인 에디터**에서 이메일을 열어요.
2. 빌더의 스타일 설정 영역을 열어요.
3. **타이포그래피 설정**을 펼쳐요.
4. 설정할 텍스트 스타일을 켜요.
5. **상단 간격**에 값을 입력해 선택한 텍스트 스타일 위쪽 간격을 정해요.
6. **하단 간격**에 값을 입력해 선택한 텍스트 스타일 아래쪽 간격을 정해요.
7. **이메일 빌더** 화면에서 바뀐 모습을 바로 확인해요.

현재 **타이포그래피 설정** 패널에는 다음 스타일이 있어요.

- **단락**
- **제목 H1**
- **제목 H2**
- **제목 H3**
- **제목 H4**
- **제목 H5**

지원하는 스타일마다 다음 항목이 있어요.

- 켜고 끄는 토글
- **상단 간격**
- **하단 간격**
- **PX** 단위의 숫자 값

## 마진, 여백, 여백 요소의 차이

**마진**, **여백**(Padding), **여백**(Spacer) 요소는 모두 이메일 레이아웃에서 간격을 만들 수 있지만, 디자인에 영향을 주는 방식이 달라요. 이 문서에서는 구분하기 위해 Padding은 **여백**(Padding), Spacer는 **여백**(Spacer) 요소라고 적어요. Spacer 요소는 [이메일 빌더의 여백 요소](../../09-이메일/기타/spacer-element-in-email-builder.md)에서 자세히 볼 수 있어요.

| 설정 | 용도 |
| --- | --- |
| **마진** | 지원하는 섹션 바깥에 세로 간격을 더해요. |
| **여백**(Padding) | 지원하는 요소나 섹션 안쪽에 간격을 더해요. |
| **여백**(Spacer) | 이메일 레이아웃에 간격만 차지하는 별도 요소를 넣어요. |

현재 섹션 편집기의 **Margin and Padding** 영역에서는 박스 모델 바깥쪽에 마진이, 안쪽에 여백이 표시돼요.

바꾸려는 간격의 종류에 맞는 설정을 사용하세요.

## 자주 묻는 질문

### 이메일 빌더에서 마진 설정은 어디에 있나요?
섹션을 선택한 다음 **Edit section** 패널을 열고 **Margin and Padding**을 찾으세요.

### 어떤 마진 값을 조절할 수 있나요?
현재 섹션 편집기에서는 상단과 하단 마진 값을 조절할 수 있어요.

### 마진은 어떤 단위를 쓰나요?
마진 값은 픽셀 단위이고, 편집기에는 **PX**로 표시돼요.

### 마진 값은 어떻게 바꾸나요?
상단 또는 하단 마진 값을 선택한 다음, 슬라이더를 쓰거나 픽셀 값을 직접 입력하거나 사용할 수 있는 프리셋을 고르세요.

### 어떤 텍스트 스타일에서 상단 간격과 하단 간격을 설정할 수 있나요?
현재 **타이포그래피 설정** 패널에서는 **단락**과 **제목 H1**부터 **제목 H5**까지 지원해요.

### 텍스트 간격은 어떤 단위를 쓰나요?
**상단 간격**과 **하단 간격**은 **PX** 단위를 써요.

### 여백이나 여백 요소도 계속 쓸 수 있나요?
네. 이메일 빌더에서 필요에 따라 **여백**(Padding)과 **여백**(Spacer) 요소를 계속 쓸 수 있어요.

### 모바일 보기에서도 이 설정을 확인할 수 있나요?
네. 모바일 레이아웃을 확인하는 동안에도 마진과 타이포그래피 설정을 쓸 수 있어요. 모바일 서식은 [이메일 빌더에서 모바일 서식 사용자 지정하기](../how-to-customize-mobile-formatting-in-the-email-builder.md)에서 자세히 볼 수 있어요.
