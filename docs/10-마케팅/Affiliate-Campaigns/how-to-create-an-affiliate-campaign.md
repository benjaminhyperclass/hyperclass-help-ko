# 제휴 캠페인 만들기

제휴 캠페인에서는 제휴 파트너가 만든 판매나 리드를 추적하고, 커미션 규칙을 정하고, 제휴 파트너를 배정하고, 추천 추적 방식을 한곳에서 관리할 수 있어요. 캠페인 소스에 따라 상품 구매나 조건을 충족한 리드에 대해 보상할 수 있고, 커미션, 지급 조건, 쿠키 유지 기간, 다단계 구조(선택)도 함께 설정해요.

---

## 제휴 캠페인이란?

제휴 캠페인은 제휴 파트너가 무엇을 홍보하는지, 추천을 어떻게 추적하는지, 커미션을 어떻게 계산하는지를 정해 두는 단위예요. 캠페인마다 제휴 파트너를 특정 소스에 연결하고, 캠페인 전용 추천 링크를 만들어요. 하이퍼클래스는 이 링크로 조건에 맞는 판매나 리드를 제휴 파트너의 실적으로 인정해요.

캠페인 설정에서 정할 수 있는 항목은 다음과 같아요.

- 캠페인 소스
- 랜딩 대상
- 커미션 대상 상품
- 커미션 구조
- 다단계 커미션
- 배정된 제휴 파트너
- 쿠키 유지 기간
- 지급 조건
- 하위 제휴 파트너 옵션

---

## 제휴 캠페인의 장점

제휴 캠페인을 쓰면 파트너에게 보상하면서도 실적 인정, 커미션, 캠페인 참여 현황을 체계적으로 관리할 수 있어요.

- 유연한 추적: 캠페인 소스에 따라 제휴 파트너가 만든 상품 판매나 리드를 추적해요.
- 맞춤 커미션: 기본 커미션을 정하고, 필요하면 상품별 커미션도 따로 정해요.
- 다단계 보상: 조건에 맞는 제휴 파트너 구조에 최대 7단계까지 커미션을 설정해요.
- 제휴 파트너 배정: 캠페인을 만들 때 제휴 파트너를 추가하거나, 나중에 **제휴 관리자**와 워크플로우로 등록해요.
- 추천 실적 인정: 제휴 파트너마다 캠페인 전용 추천 링크를 제공해요.
- 지급 관리: 환불 및 결제 정책에 맞춰 지급 조건을 설정해요.

---

## 제휴 캠페인 만드는 순서

### 1단계: 추가 버튼 클릭

**제휴 관리자** 페이지로 이동해서 **+ 추가** 버튼을 클릭하면 캠페인 만들기가 시작돼요.

![제휴 관리자에서 추가 버튼을 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082851914/original/i3rdSl2PRrUy-hGEhcsNCc7T0zfjXc0KAw.png?1791464014)

### 2단계: 캠페인 소스 선택

캠페인 소스를 선택해요. 상품이 등록된 퍼널, 웹사이트, 스토어 중에서 고르면 돼요.

### 3단계: 소스 세부 정보 설정

잠재 고객이 처음 도착할 **랜딩 페이지**도 선택할 수 있어요. 선택하면 기본 캠페인 URL이 만들어져요. 이 URL에는 제휴 파트너 고유 링크가 들어 있어요. 자리표시자 `<<affiliate_id>>`는 제휴 파트너마다 고유한 ID로 자동으로 바뀌어요.

![캠페인 소스 설정 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781724/original/ZBtujVrvdHxcz9ToqznlorQhRDZ-crR4cQ.jpeg?1727691000)

![캠페인 소스 설정 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781716/original/RaKWk2FxX9qCPb7sXXYyiKqZPNXBhUwk5w.jpeg?1727691000)

{% hint style="info" %}
현재 제휴 캠페인에서 상품 판매를 지원하는 소스는 퍼널, 웹사이트, 스토어뿐이에요. 다만 폼, 설문, 캘린더를 통해 리드를 추적하고, 리드를 만든 제휴 파트너에게 비용을 지급할 수도 있어요. 자세한 내용은 문서 하단의 '다음 단계'에서 확인하세요.

**랜딩 페이지** 선택은 잠재 고객이 도착할 위치를 정하는 용도예요. 추적은 랜딩 페이지 하나가 아니라 소스 전체를 기준으로 이루어져요.
{% endhint %}

### 4단계: 상품 목록 확인

선택한 소스에 연결된 상품을 확인해요. 상품을 추가하거나 제거해서 커미션 대상 상품만 남겨 두세요.

![상품 목록 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781717/original/z6mS3KYOu-HsFjnHgpwVjYFBM-tmHmQ2hg.jpeg?1727691000)

### 5단계: 기본 커미션 설정

캠페인의 기본 커미션을 정해요. 정액 또는 상품 가격의 일정 비율 중에서 선택할 수 있어요.

![기본 커미션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781714/original/iaAewggi3qR-EpTaHYAeRoOgQ4sSrQF1jA.jpeg?1727691000)

### 6단계: 상품별 커미션 설정 (선택)

필요하면 상품별로 커미션을 따로 정할 수 있어요. 상품 가격에 맞춰 지급액을 조정할 때 써요.

![상품별 커미션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781723/original/ti7BKz8eGAdARlnMfV4lALQmDmfuf40o4g.jpeg?1727691000)

### 7단계: 다단계 커미션 켜기

**Advanced Commissions**(고급 커미션) 설정에서 다단계 커미션을 켜요. 더 복잡한 커미션 구조가 필요하면 최대 7단계까지 설정할 수 있어요. 자세한 내용은 [다단계 커미션 설정하기](how-to-set-up-multi-tier-commissions.md)를 참고하세요.

![다단계 커미션 켜기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781720/original/ksW7cgUS_iICkEz_CpNOnvZbnmMEGSEbCw.jpeg?1727691000)

### 8단계: 단계별 커미션 설정

각 단계에 커미션을 지정해요. 기본 비율을 그대로 적용해도 되고, 실적에 맞춰 단계마다 다르게 정해도 돼요.

![단계별 커미션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781713/original/LrUv3uJsLCNoPLCsgnevcXOA9UzwI8jr1g.jpeg?1727691000)

### 9단계: 캠페인 설명 추가 (선택)

캠페인의 목적을 설명하는 글을 추가해 보세요. 제휴 파트너가 캠페인에 더 관심을 가질 수 있어요.

![캠페인 설명 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781715/original/J0TTyCwIlA-LG3RseQd5HHQKtCEFv1fOiw.jpeg?1727691000)

### 10단계: 제휴 파트너 직접 배정

제휴 파트너의 가입일, 전체 제휴 파트너 수 같은 정보를 확인한 뒤 캠페인에 직접 배정해요.

![제휴 파트너 직접 배정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781722/original/GaGiOLmMrLJfqPJp7oTdtCj7uFCnC_0-zA.jpeg?1727691000)

### 11단계: 추가 설정 조정

**추가 설정**에서 캠페인을 더 세밀하게 조정할 수 있어요.

- **이메일 템플릿**: 제휴 파트너 온보딩용
- 제휴 파트너 활동을 추적하는 쿠키 유지 기간
- 지급 조건
- 커미션 계산에 설정 비용 포함 여부
- 하위 제휴 파트너 가입 허용
- 신규 고객을 하위 제휴 파트너로 자동 등록

![추가 설정 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781721/original/dCpccd0oPMEupNfRZrVinHbinh9DGmH0Ew.jpeg?1727691000)![추가 설정 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033781719/original/c3uDUHW_bHs03toyL6-XULcgZcdDAZoe4w.jpeg?1727691000)

### 12단계: 게시 또는 초안으로 저장

캠페인 설정이 끝나면 **게시**를 눌러 바로 시작하거나, **초안으로 저장**을 눌러 나중에 더 편집할 수 있어요.

## 기존 캠페인의 소스 변경하기

제휴 캠페인은 게시한 뒤에도 소스를 편집할 수 있어요. 예를 들어 연결해 둔 퍼널, 코스, 웹사이트가 삭제되었거나 바뀐 경우에 쓸 수 있어요.

캠페인 소스를 바꾸면 다음과 같이 돼요.

- 새 추천 URL이 만들어져요.
- 이전 캠페인 URL은 새 추천을 더 이상 추적하지 않아요.
- 기존 캠페인 설정은 그대로 유지돼요.
- 과거 캠페인 성과 데이터도 그대로 남아요.

소스를 바꾼 뒤에는 다음 순서로 진행하세요.

1. 참여 중인 모든 제휴 파트너에게 알려요.
2. 이전에 공유한 캠페인 링크를 바꾸도록 요청해요.
3. 홍보를 다시 시작하기 전에 새 추천 링크가 제대로 작동하는지 확인해요.

{% hint style="warning" %}
캠페인 소스를 바꾼 뒤에는 이전 캠페인 URL로 들어온 추천이 더 이상 제휴 파트너의 실적으로 인정되지 않아요.
{% endhint %}

제휴 파트너에게 변경 사항을 미리 알려 두면 링크가 작동하지 않는다는 혼란과 불필요한 문의를 줄일 수 있어요.
