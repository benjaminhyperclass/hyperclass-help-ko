# 이메일 캠페인·템플릿·시퀀스에 중첩 폴더 설정하기

중첩 폴더를 쓰면 캠페인, 템플릿, 시퀀스를 폴더 안의 폴더로 정리할 수 있어요. 이메일 자료가 많아져도 필요한 캠페인이나 템플릿을 금방 찾을 수 있도록 폴더 구조를 만드는 방법을 안내해요.

## 중첩 폴더란?

중첩 폴더는 **이메일 마케팅**(Email Marketing) 안에서 폴더 안에 폴더를 만들어 계층 구조로 정리하는 기능이에요. 항목을 긴 목록 하나에 모아 두는 대신, 고객사·브랜드·상품 라인·라이프사이클 단계 등 업무 방식에 맞는 기준으로 나눌 수 있어요.

이 기능으로 할 수 있는 일은 다음과 같아요.

- 큰 분류의 최상위 폴더 만들기 (예: "고객사 A", "뉴스레터")
- 더 구체적인 분류의 하위 폴더 추가하기 (예: "프로모션", "온보딩", "2026년 1분기")
- 기존 캠페인, 템플릿, 시퀀스를 알맞은 폴더로 옮기기
- 폴더 경로로 현재 위치 확인하기

이 폴더 기능은 **이메일 빌더**의 **캠페인**, **템플릿**, **Sequences**(시퀀스)에서 똑같이 쓸 수 있어요. 이메일 관련 항목을 같은 방식으로 정리할 수 있어요.

## 중첩 폴더의 장점

중첩 폴더로 정리하면 에이전시나 브랜드 규모가 커져도 구조를 그대로 유지할 수 있어요.

- 체계적인 정리: 관련 항목을 폴더 트리로 묶어서 평면 목록 속에 항목이 묻히지 않아요.
- 빠른 이동: 섞여 있는 긴 목록을 스크롤하지 않고 원하는 폴더로 바로 들어갈 수 있어요.
- 확장 가능한 구조: 여러 단계로 중첩해서 복잡한 구성도 지원해요.
- 일관된 작업 방식: 캠페인, 템플릿, 시퀀스에 같은 구조를 쓸 수 있어요.
- 수월한 협업: 항목이 있어야 할 위치를 분명히 정해 두면 중복과 혼란이 줄어요.
- 앞날을 고려한 정리: 간단하게 시작해서 필요할 때 구조를 넓혀 갈 수 있어요.

## 폴더 계층과 탐색

중첩 폴더는 파일 시스템과 비슷한 단순한 계층 구조를 따라요. 각 폴더에는 항목과 하위 폴더를 모두 넣을 수 있어서, 필요한 만큼 층을 쌓을 수 있어요.

### 최상위 수준(홈)

모든 최상위 폴더와 폴더에 넣지 않은 항목이 보이는 시작 지점이에요. 고객사, 브랜드, 라이프사이클 단계처럼 큰 분류를 두기에 좋아요.

### 하위 폴더

다른 폴더 안에 만든 폴더로, 더 구체적인 묶음을 나타내요. (예: 고객사 A → 캠페인 → 상품 출시 → 2026년 1분기)

### 폴더 경로

현재 위치를 보여 줘요. (예: 홈 / 고객사 A / 캠페인 / 2026) 경로의 상위 폴더를 클릭하면 바로 이동할 수 있어요.

## 캠페인의 중첩 폴더

캠페인에 중첩 폴더를 쓰면 일회성 발송, 정기 뉴스레터, 프로모션 캠페인을 구조적으로 정리할 수 있어요.

이런 경우에 많이 써요.

- 여러 고객사나 브랜드의 캠페인을 관리할 때
- 뉴스레터처럼 반복되는 이메일 시리즈를 정리할 때
- 리포팅과 규정 준수를 위해 기록을 깔끔하게 보관할 때

### 구조 예시

**고객사와 퍼널 단계별**

- 고객사 A / 뉴스레터
- 고객사 A / 프로모션 / 상품 라인 A
- 고객사 A / 라이프사이클 / 온보딩

**대상 고객군별**

- B2B / 잠재 고객
- B2B / 기존 고객 / 엔터프라이즈
- B2C / VIP

## 이메일 템플릿의 중첩 폴더

템플릿에 중첩 폴더를 쓰면 재사용하는 이메일 디자인과 레이아웃을 한곳에서 체계적으로 관리할 수 있어요.

### 정리 아이디어

- 용도별: 뉴스레터, 프로모션, 온보딩, 트랜잭션 메일
- 고객사나 브랜드별: 고객사 A / 뉴스레터 / 2026
- 기능별: 계약, 리뷰 요청, 알림

### 장점

- 이메일을 만들 때 알맞은 템플릿을 빠르게 찾을 수 있어요.
- 팀 전체에서 디자인 기준을 일관되게 유지할 수 있어요.
- 시스템 템플릿과 마케팅 템플릿을 따로 둘 수 있어요.

## 시퀀스의 중첩 폴더

시퀀스는 온보딩, 육성, 재참여처럼 여러 단계로 이어지는 이메일 여정이에요. 중첩 폴더를 쓰면 이런 여정을 구조적으로 정리하고 쉽게 관리할 수 있어요.

### 구조 예시

**라이프사이클 단계별**

- 라이프사이클 / 온보딩 / SaaS 체험
- 라이프사이클 / 구매 후 / 업셀
- 라이프사이클 / 재참여

**퍼널이나 오퍼별**

- 웨비나 퍼널 / 리마인더
- 리드 마그넷 / 후속 안내
- 코스 출시 / 장바구니 이탈

## 중첩 폴더 구조를 짜는 요령

처음에 구조를 잘 계획해 두면 항목이 늘어나도 깔끔하고 찾기 쉬워요.

- 간단하게 시작하세요. 1~2단계로 시작하고, 꼭 필요할 때만 늘리세요.
- 이름 규칙을 통일하세요. "고객사 / 라이프사이클 / 캠페인 이름"처럼 정해진 형식을 따르세요.
- 항목 종류가 달라도 구조를 맞추세요. 캠페인, 템플릿, 시퀀스에 비슷한 패턴을 쓰세요.
- 불필요하게 깊게 만들지 마세요. 항목이 거의 없는 폴더는 만들지 않는 편이 좋아요.
- 정기적으로 점검하세요. 오래된 항목은 보관하고, 폴더 구조도 시간이 지나면서 다듬으세요.

{% hint style="info" %}
중첩 폴더는 정리를 위한 기능이에요. 접근 권한은 따로 관리해요.
{% endhint %}

## 중첩 폴더 설정하기

### 1단계: 폴더 구조 계획하기

항목을 어떤 기준으로 정리할지 정해요.

- 고객사나 브랜드별
- 라이프사이클 단계별
- 상품이나 오퍼별

2~4단계의 간단한 구조로 시작하세요.

### 2단계: 최상위 폴더 만들기

1. **이메일 마케팅**을 열어요.
2. **캠페인**, **템플릿**, **Sequences**(시퀀스) 중 정리할 곳으로 이동해요.
3. 최상위 수준(**홈**)에서 **새 폴더**를 클릭해요.
4. 이름을 입력하고 **저장**을 클릭해요.

![최상위 폴더 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070214732/original/XBDhe4atNJrAXh9ZLkRhI3QinjlBiBPZew.gif?1777463791)

### 3단계: 하위 폴더 만들기

1. 이미 만든 폴더를 열어요.
2. **새 폴더**를 클릭해요.
3. 이름을 입력하고 **저장**을 클릭해요.
4. 필요한 만큼 반복해서 구조를 만들어요.

![하위 폴더 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070215374/original/ix_HqJoMxUxjMD1hqJnEXcPqVpiuUWu46w.gif?1777464183)

### 4단계: 기존 항목 정리하기

1. 옮길 항목(캠페인, 템플릿, 시퀀스)을 찾아요.
2. 작업 메뉴(점 세 개)를 열어요.
3. **폴더로 이동**을 선택해요.
4. 이동할 폴더를 고르고 확인해요.

![항목을 폴더로 이동하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070215481/original/rjO4-52suX93SOQ_MaXVF3qOwwYiYjr0Pw.png?1777464244)

### 5단계: 폴더 재정리하기

1. 폴더의 작업 메뉴를 열어요.
2. **폴더 이동**을 선택해요.
3. 새 상위 폴더를 골라요.
4. 이동을 확인하고 폴더 경로가 알맞은지 살펴봐요.

### 6단계: 폴더 경로 활용하기

1. 페이지 맨 위의 폴더 경로를 확인해요.
2. 경로의 각 단계를 클릭하면 폴더 사이를 오갈 수 있어요.
3. 항목이 알맞은 위치에 저장되어 있는지 확인할 때도 활용하세요.

## 자주 묻는 질문

### 중첩 폴더를 쓰면 이메일 발송 방식이 달라지나요?
아니요. 중첩 폴더는 항목을 정리하는 방식에만 영향을 줘요.

### 폴더는 몇 단계까지 만들 수 있나요?
5단계를 넘는 깊이도 지원해요. 다만 경로가 짧을수록 관리하기 쉬워요.

### 폴더로 권한을 관리할 수 있나요?
아니요. 접근 권한은 사용자 역할과 권한으로 관리해요.

### 여러 폴더를 한 번에 검색할 수 있나요?
네, 검색은 모든 폴더에 걸쳐 작동해요.

### 폴더를 삭제하면 어떻게 되나요?
폴더 안의 항목은 삭제되지 않아요. 상위 폴더나 최상위 수준으로 이동해요.

### 분석에 영향이 있나요?
아니요. 리포팅과 분석은 그대로예요.
