# 반복 카운트다운 타이머 만들기

반복 타이머는 정기적으로 열리는 이벤트, 세일, 활동을 알리고 홍보할 때 쓰는 기능이에요. 한 번의 이벤트까지만 카운트다운하는 고정 타이머와 달리, 반복 타이머는 한 주기가 끝나면 처음부터 다시 시작해요. 그래서 반복되는 이벤트나 마감일을 계속 알릴 수 있어요.

## 반복 타이머란?

반복 카운트다운 타이머는 정해진 기간(예: 7일) 동안 카운트다운하고, 0이 되면 설정한 횟수만큼 자동으로 다시 시작하는 타이머예요. 마감 시점이 모든 방문자에게 똑같으므로, 방문자는 매 주기마다 같은 긴박감을 느껴요.

한 번 끝나면 영구히 만료되는 일회성 타이머와 달리, 반복 타이머는 세 가지 상태를 오가요.

- **대기**: 활성 카운트다운이 시작되기 전이에요.
- **활성**: 카운트다운이 화면에 보이며 진행 중이에요.
- **만료됨**: 카운트다운이 끝나요. 다른 페이지로 이동하거나 콘텐츠가 숨겨져요.

## 반복 타이머의 장점

반복 타이머를 쓰면 따로 손보지 않아도 긴박감이 유지돼요. 프로모션이 매번 새롭고 믿음직하게 보여요.

- 자동화: 일정에 맞춰 스스로 초기화돼요. 타이머를 새로 만들거나 복제할 필요가 없어요.
- 일관된 긴박감: 방문자에게 항상 진행 중인 카운트다운이 보여서 행동을 유도해요.
- 여러 채널에서 재사용: 같은 타이머를 퍼널, 이메일, 외부 사이트에 넣을 수 있어요.
- 유연한 반복 횟수: 타이머가 몇 번 돌지 직접 정할 수 있어요.
- 브랜드에 맞는 스타일: 글꼴과 색상 등 디자인을 브랜드에 맞게 바꿀 수 있어요.

## 반복 타이머는 어디에 쓰나요?

### 주간 세일이나 프로모션

정기적으로 열리는 주간 세일이나 특별 오퍼를 강조할 때 써요. 웹사이트, 이메일, 소셜 미디어에 타이머를 보여 주면 고객이 반복되는 할인 기회를 기억해요.

### 월간 구독이나 갱신

구독형 서비스나 멤버십 갱신에서는 매달 다가오는 갱신일을 타이머로 알릴 수 있어요. 구독 관리 이메일이나 사용자 대시보드에 넣어 보세요.

### 정기 웨비나나 수업

매주 화요일처럼 정해진 일정으로 웨비나나 수업을 연다면, 다음 세션까지 남은 시간을 타이머로 보여 줄 수 있어요. 이벤트 등록 페이지나 홍보 이메일에 타이머를 넣어 보세요.

### 일일 특가나 반짝 세일

매일 또는 매주 반복되는 특가나 한정 시간 반짝 세일에 쓰면 긴박감을 만들 수 있어요. 고객에게 다음 혜택 기회도 알려 줄 수 있어요.

## Loop Events란?

**Loop Events**(루프 횟수)는 카운트다운이 끝난 뒤 타이머를 몇 번 다시 시작할지 정하는 설정이에요. 예를 들어 **Loop Events**를 3으로 정하면 타이머가 카운트다운하고 초기화되는 과정을 총 3번 거쳐요. 처음 카운트다운 1번에 반복 2번을 더한 횟수예요.

타이머를 매주 다시 시작하고 싶다면 이렇게 설정하세요.

- **시작일**을 원하는 다음 시작 시점(예: 월요일 오전 8시)으로 정해요.
- **Countdown Duration**(카운트다운 기간)을 7일로 정해요.
- **Loop Events**를 주간 주기를 반복할 횟수로 정해요(예: 4주 연속이면 4).

{% hint style="info" %}
이전 카운트다운이 끝나면 시간대 설정에 따라 다음 주기가 자동으로 시작돼요.

카운트다운 기간이 1일이 아니라면 매일 초기화되지 않아요. 전체 기간이 끝난 뒤에만 다시 시작해요.
{% endhint %}

## 반복 타이머 만들기

다음 단계를 따라 반복 타이머를 만들어 보세요.

### 1단계: 마케팅으로 이동하기

1. 왼쪽 메뉴에서 **마케팅**(Marketing)을 선택해요.
2. 상단 메뉴에서 **카운트다운 타이머**를 선택해요.

![마케팅 메뉴의 카운트다운 타이머 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050461464/original/e6lM1ZgRyR_J8zbdo3tDQOQDmIzmBy_aXA.png?1753473301)

### 2단계: 타이머 선택하기

- 새 타이머를 만들려면 파란색 **신규** 버튼을 클릭해요. 템플릿을 사용하면 디자인 시간을 줄일 수 있어요.
- 기존 타이머를 수정하려면 타이머 옆의 **편집**(연필) 아이콘을 클릭해요.

### 3단계: 타이머 유형 고르기

1. 설정 패널의 **일반** 탭에서 **Timer Type**(타이머 유형)을 찾아요.
2. **반복**을 선택해요.

### 4단계: 타이머 세부 설정하기

타이머 설정을 정해요.

- **시작 날짜 시간**: 첫 번째 주기가 시작되는 시점이에요.
- **Loop Events**(루프 횟수): 초기화되는 횟수, 즉 주기의 수예요.
- **Countdown Duration**(카운트다운 기간): 한 주기의 길이예요(예: 7일).
- **Countdown Timer Waits For**(카운트다운 타이머 대기 시간): 대기 상태가 활성 상태 뒤에 오면 사이트가 **만료됨** 페이지로 자동 이동하지 않아요. [이 설정에 대한 자세한 내용은 여기를 확인하세요](#반복-타이머의-대기-시간).
- **Hide Timer on Site in Wait State**(대기 상태에서 사이트의 타이머 숨기기): 이 설정을 끄면 사이트에서 대기 시간 동안 타이머가 0 상태로 보여요.

![타이머 세부 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050461875/original/ckHLglv14mBoy7tg_iNBd11QZ-2blN_qtw.png?1753474653)

### 5단계: 링크 추가하기

- **Active Link**(활성 링크): 타이머가 활성 상태일 때 사용자가 이동할 URL을 입력해요.
- **Expired Link**(만료 링크): 타이머가 만료된 뒤 사용자가 도착할 URL을 입력해요.

### 6단계: 꾸미고 저장하기

1. 색상, 글꼴, 만료 이미지, 시간 표시 형식 등 타이머의 모양을 조정해요.
2. 타이머를 알아보기 쉬운 이름으로 지어요.
3. 파란색 **저장** 버튼을 클릭해 카운트다운 타이머를 완성하고 활성화해요.

## 반복 타이머의 대기 시간

**Countdown Timer Waits For** 설정을 쓰면 타이머 주기 사이에 일정한 쉬는 시간을 둘 수 있어요. 캠페인 전략에 맞게 대기 시간을 정하면 반복 타이머를 더 유연하게 쓸 수 있고, 맞춤형 자동화 워크플로우도 지원해요. 이메일과 퍼널에서 대기 시간이 어떻게 동작하는지 살펴볼게요.

### 이메일

- 타이머가 0 상태로 표시돼요.
- 이메일 링크를 클릭하면 만료 페이지로 이동해요.

### 퍼널

- 대기 중에는 타이머를 숨길 수 있어요(설정을 켠 경우).
- 같은 세션에서 타이머가 활성에서 대기로 바뀌면 사용자는 현재 페이지에 그대로 머물러요(자동 이동 없음).
- 페이지를 새로고침했을 때 대기 상태이면 사용자가 만료 페이지로 이동해요.

## 자주 묻는 질문

### 대기 시간이 무엇이고, 왜 쓰나요?

대기 시간은 주기와 주기 사이에 두는 선택 사항인 간격이에요(예: 주간 세일 사이에 24시간). 타이머가 바로 다시 시작되지 않기 때문에, 팀이 오퍼나 재고를 업데이트할 시간을 벌 수 있어요.

### 타이머를 사용 중인데 대기 시간이나 Loop Events를 수정할 수 있나요?

네, 수정할 수 있어요. **마케팅 > 카운트다운 타이머**에서 타이머를 편집하세요. 변경 내용은 그 타이머가 삽입된 모든 곳에 적용돼요.

### 타이머가 방문자의 현지 시간대에 맞춰지나요?

아니요. 반복 타이머는 설정할 때 고른 시간대를 기준으로 동작해요. 모든 방문자에게 같은 기준 시계가 보여요.

### 활성화할 수 있는 반복 타이머 개수에 제한이 있나요?

하이퍼클래스는 개수를 제한하지 않아요. 다만 타이머마다 필요할 때 이미지 자산이 생성돼요. 최적의 성능을 위해 목록을 깔끔하게 관리하고, 쓰지 않는 타이머는 삭제하세요.
