# 이메일 캠페인 데이터 내보내기

**통계** 화면에서 이메일 성과 지표를 CSV 파일로 내려받을 수 있어요. 캠페인 성과를 분석하거나, 관계자에게 결과를 공유하거나, 플랫폼 밖에 리포트 기록을 보관할 때 쓰세요. 캠페인, 워크플로우, 일괄 이메일 작업의 통계를 내보낼 수 있고, 다운로드 링크는 이메일로 안전하게 전달돼요.

---

## 이메일 캠페인 데이터 내보내기란?

**통계** 화면의 이메일 성과 통계를 CSV 형식으로 내려받는 기능이에요. 캠페인 성과 지표를 뽑아서 스프레드시트나 외부 리포팅 도구에서 분석할 수 있어 리포트 작성이 편해져요.

---

## 이메일 데이터 내보내기 유형

내보내기 범위는 여러 가지예요. 리포트나 분석에 필요한 이메일 통계만 골라서 내려받을 수 있어요. 각 유형은 **통계** 화면에서 집계되는 이메일 활동에 대응해요.

| 내보내기 유형 | 해설 |
| --- | --- |
| **All Campaigns**(전체 캠페인) | **통계** 화면에 보이는 모든 이메일 활동의 통계를 내보내요. 캠페인, 워크플로우, 일괄 발송이 모두 포함돼요. |
| **Email Marketing Campaigns Only**(이메일 마케팅 캠페인만) | **마케팅 > 이메일 > 캠페인**에서 만든 이메일 캠페인의 성과 지표를 내보내요. |
| **Workflows Only (Individual Email Action Level)**(워크플로우만, 개별 이메일 액션 단위) | 워크플로우 안의 개별 이메일 액션별 성과 데이터를 내보내요. |
| **Bulk Actions Only**(일괄 작업만) | **연락처 > 일괄 작업**으로 보낸 이메일의 통계를 내보내요. |

## 최근 내보내기

**최근 내보내기**에서는 **통계** 화면에서 만든 내보내기 파일을 한곳에서 확인할 수 있어요. 내보내기가 잘 만들어졌는지 확인하고, 계정 안의 리포팅 활동도 살펴볼 수 있어요.

**최근 내보내기**에는 내보내기 기록이 최대 30일 동안 보관돼요. 최근 리포트 요청을 확인하고 팀이 리포팅 업무를 나누기도 쉬워요.

**최근 내보내기**에는 보통 다음 정보가 표시돼요.

- 내보내기 파일 이름 또는 설명
- 내보내기 유형(캠페인, 워크플로우, 일괄 작업 등)
- 내보내기를 요청한 사용자
- 내보내기를 만든 **날짜 및 시간**
- 내보내기 상태(예: 완료)

## 이메일 캠페인 데이터 내보내기 방법

계정에서 이메일 통계를 쓸 수 있다면 따로 설정할 필요가 없어요. **통계** 화면에서 바로 내보내기를 만들고, 다운로드 링크를 이메일로 받으세요.

1. **마케팅 > 이메일 > 통계**로 이동하세요.

   ![마케팅 이메일 통계 메뉴로 이동한 화면](https://jumpshare.com/share/ikg2XdGlMBGS9IZPpIxA+/Screen+Shot+2026-09-21+at+18.16.14.png)
2. **캠페인 유형**과 날짜 범위를 선택한 다음 **내보내기** 버튼을 클릭하세요.

   ![캠페인 유형과 날짜 범위를 선택하고 내보내기 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081456197/original/lB_uY3FcwfkcExU1ghljgrXgYqwFz7LK1A.png?1789996162)
3. 파일을 받을 이메일 주소를 입력하고 **내보내기**를 클릭하세요.

   ![받을 이메일 주소를 입력하는 화면](https://jumpshare.com/share/7QEmZCFRR428S03pWFcd+/Screen+Shot+2026-09-21+at+18.37.22.png)
4. 이메일 받은편지함에서 CSV 파일 다운로드 링크가 담긴 메일을 확인하세요.

   ![다운로드 링크가 담긴 이메일 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066764415/original/-p17Iyb7uDYRkUEodE4ja3QtN769cfxHfQ.png?1773308310)
5. 모든 내보내기 파일에는 발송 완료, 열람, 클릭 같은 주요 성과 지표가 들어 있어요.

   ![내보낸 CSV 파일에 주요 성과 지표가 담긴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066764456/original/UcaIiMcX_bweJhfuooXYqk6ndNo7VAx0Eg.png?1773308333)

## 자주 묻는 질문

### 내보내기 파일에는 어떤 지표가 들어 있나요?
**통계** 화면에서 볼 수 있는 주요 이메일 성과 지표가 들어 있어요. 예를 들면 발송 완료, 열람, 클릭이 있어요.

### 내보낸 파일은 어떻게 받나요?
내보내기를 요청할 때 입력한 이메일 주소로 CSV 다운로드 링크가 전송돼요.

### 내보내기 다운로드 링크는 얼마 동안 유효한가요?
다운로드 링크는 내보내기를 만든 날부터 30일 동안 유효해요.

### 워크플로우 이메일 성과도 내보낼 수 있나요?
네. 워크플로우 내보내기를 선택하면 워크플로우 안의 개별 이메일 액션 단위로 성과 데이터를 받을 수 있어요.

### 이메일 데이터를 내보내면 캠페인이나 연락처에 영향이 있나요?
아니요. 내보내기는 리포팅 작업일 뿐이에요. 캠페인, 워크플로우, 연락처, 통계는 바뀌지 않아요.
