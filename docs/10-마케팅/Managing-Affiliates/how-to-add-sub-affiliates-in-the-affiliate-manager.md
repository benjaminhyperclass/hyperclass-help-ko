# 제휴 관리자에서 서브 제휴 파트너 추가하기

서브 제휴 파트너를 쓰면 하이퍼클래스 **제휴 관리자**(Affiliate Manager)에서 멀티 티어 추천 구조를 만들 수 있어요. 상위 제휴 파트너 아래에 다른 제휴 파트너를 직접 모집하거나 배정할 수 있고, 커미션은 캠페인에 설정한 티어에 따라 나뉘어 지급돼요. 하이퍼클래스는 최대 7개 티어의 멀티 티어 제휴 캠페인을 지원해요.

예를 들어 서브 제휴 파트너가 판매를 만들면, 그 파트너는 1티어 커미션을 받고 상위 제휴 파트너는 해당하는 2티어 커미션을 받을 수 있어요.

{% hint style="warning" %}
서브 제휴 파트너를 쓰려면 제휴 캠페인에 티어가 2개 이상 설정되어 있어야 해요.
{% endhint %}

---

## 서브 제휴 파트너의 장점

서브 제휴 파트너를 쓰면 제휴 파트너가 추천 네트워크를 키울 수 있고, 그 관계를 캠페인 안에서 정리해서 볼 수 있어요.

- 멀티 티어 커미션: 판매를 만든 제휴 파트너와 해당하는 상위 제휴 파트너에게 모두 보상할 수 있어요.
- 유연한 등록 방식: 서브 제휴 파트너를 직접 추가하거나, 추천받은 고객을 자동으로 등록하거나, 제휴 파트너가 직접 모집하게 할 수 있어요.
- 제휴 파트너 주도 성장: 공유할 수 있는 가입 페이지로 제휴 파트너가 스스로 네트워크를 넓힐 수 있어요.
- 계층 구조 확인: 상위 제휴 파트너와 서브 제휴 파트너의 관계를 **제휴 관리자**와 **제휴 포털**에서 볼 수 있어요.

---

## 사전 준비

서브 제휴 파트너 기능은 캠페인의 티어 설정에 따라 달라져요. 캠페인과 가입 조건을 먼저 확인해 두면 옵션이 보이지 않거나 등록 오류가 나는 일을 막을 수 있어요.

서브 제휴 파트너를 추가하기 전에 아래를 준비하세요.

- **제휴 관리자** 캠페인을 만들거나 선택해요.
- 캠페인에 커미션 티어를 2개 이상 설정해요.
- 각 티어의 커미션 비율을 알맞게 설정해요.
- 제휴 파트너 직접 모집 기능을 쓰려면 아래 항목이 들어 있는 폼을 준비해요.

  - **이름**
  - **성**
  - **이메일**

하이퍼클래스는 최대 7개의 커미션 티어를 지원해요.

티어 설정 방법은 [멀티 티어 커미션 설정하기](../Affiliate-Campaigns/how-to-set-up-multi-tier-commissions.md)를 참고하세요.

## 제휴 페이지에서 서브 제휴 파트너 확인하기

**제휴** 페이지에서는 제휴 파트너 프로필을 열지 않고도 각 제휴 파트너에게 연결된 서브 제휴 파트너 수를 바로 볼 수 있어요. 메인 목록에서 제휴 관계를 한눈에 확인할 수 있어요.

1. **제휴** 페이지로 이동하세요.
2. 확인하려는 제휴 파트너를 찾으세요.
3. **Sub Affiliates**(서브 제휴 파트너) 열에서 연결된 서브 제휴 파트너 수를 확인하세요.
4. 숫자를 클릭하면 해당 서브 제휴 파트너의 이름과 이메일 주소를 볼 수 있어요.

![제휴 페이지의 서브 제휴 파트너 열](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081188461/original/o76j1erYVi8TeeODIhpx5ENu4owMSRvcUA.png?1789650374)

## 서브 제휴 파트너를 추가하는 방법 고르기

하이퍼클래스에서는 서브 제휴 파트너 계층을 만드는 방법이 세 가지 있어요. 등록 과정을 얼마나 직접 관리하고 싶은지, 제휴 파트너가 스스로 네트워크를 모집하게 할지에 따라 고르세요.

| 방식 | 이럴 때 좋아요 |
| --- | --- |
| 수동 지정 | 상위 제휴 파트너 아래에 둘 제휴 파트너를 이미 알고 있을 때 |
| 고객 자동 등록 | 추천받은 고객이 판매에 성공하면 자동으로 서브 제휴 파트너가 되게 하고 싶을 때 |
| 제휴 파트너 직접 모집 | 제휴 파트너가 공유용 가입 링크로 서브 제휴 파트너를 직접 모집하게 하고 싶을 때 |

---

## 서브 제휴 파트너 직접 추가하기

수동 지정을 쓰면 캠페인 계층 구조를 직접 관리할 수 있어요. 특정 상위 제휴 파트너 아래에 둘 제휴 파트너를 이미 알고 있을 때 쓰세요.

1. **제휴 관리자**로 이동하세요.

   ![제휴 관리자 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082965870/original/mSVpX_TJ9Eu3JH6B1dhkN0dLSos00htcbg.png?1791556768)
2. 상위 제휴 파트너로 쓸 제휴 파트너를 찾아 여세요.
3. **Sub-Affiliate**(서브 제휴 파트너) 탭을 여세요.
4. **Add Sub-Affiliate**(서브 제휴 파트너 추가)를 클릭하세요.

   ![서브 제휴 파트너 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082965916/original/YX-dAJJU4K_mC8759dHLk8Q8V0TOSmOl-g.png?1791556821)
5. 해당하는 멀티 티어 캠페인을 선택하세요.

   ![멀티 티어 캠페인 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082966002/original/s9xd7gLlXm34-kg_Wut8Qjh4950mu8h-9w.png?1791556895)
6. 상위 제휴 파트너 아래에 추가할 기존 제휴 파트너를 선택하세요.

   ![기존 제휴 파트너 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081159332/original/L3jXbz_2xwOK2tkHKqCpv5Tg7X6bm2HR4A.png?1789637676)

   아직 제휴 파트너가 아닌 사람이라면, 화면에 보이는 옵션으로 새 제휴 파트너 프로필을 만드세요.
7. 관계를 저장하세요.

저장한 뒤에는 상위 제휴 파트너 아래에 서브 제휴 파트너가 제대로 나타나는지 확인하세요.

{% hint style="info" %}
커미션 참고: 캠페인의 티어 설정이 기본 멀티 티어 커미션 구조를 정해요. 제휴 파트너에게 별도로 커스텀 커미션을 설정했다면, 그 제휴 파트너에게는 제휴 파트너 단위 비율이 캠페인 단위 비율보다 우선 적용될 수 있어요. 자세한 내용은 [제휴 파트너별 커스텀 커미션 설정하기](how-to-set-custom-affiliate-commissions.md)를 참고하세요.
{% endhint %}

## 추천받은 고객을 서브 제휴 파트너로 자동 등록하기

자동 등록을 켜면 판매에 성공한 고객이 직접 등록하지 않아도 제휴 네트워크의 일원이 될 수 있어요. 고객은 해당 추천을 만든 제휴 파트너 아래에 추가돼요.

자동 등록을 켜려면 다음과 같이 하세요.

1. 해당 제휴 캠페인을 여세요.
2. 캠페인의 **추가 설정**으로 이동하세요.
3. **Auto Enroll New Customers as Sub-Affiliates**(신규 고객을 서브 제휴 파트너로 자동 등록)를 켜세요.

   ![신규 고객 자동 등록 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081159419/original/FK2l29rC0f04yJiPVjpSajyNjqeaB9daWw.png?1789637709)
4. 캠페인을 저장하세요.

제휴 파트너가 고객을 추천하고 해당 판매가 성공하면, 그 고객은 추천한 제휴 파트너 아래 서브 제휴 파트너로 등록될 수 있어요.

{% hint style="warning" %}
자동 등록은 추천받은 판매가 성공했을 때를 기준으로 해요. 모든 리드나 폼 제출이 자동으로 서브 제휴 파트너가 되는 것은 아니에요.
{% endhint %}

## 제휴 파트너가 직접 서브 제휴 파트너 모집하게 하기

직접 모집 기능을 켜면 모집할 때마다 일일이 추가하지 않아도 기존 제휴 파트너가 스스로 네트워크를 키울 수 있어요. 하이퍼클래스는 제휴 파트너가 서브 제휴 파트너 후보에게 나눠 줄 수 있는 공유용 가입 폼을 제공해요.

이 옵션을 켜기 전에 선택할 폼에 아래 항목이 들어 있는지 확인하세요.

- **이름**
- **성**
- **이메일**

직접 모집을 켜려면 다음과 같이 하세요.

1. 해당 제휴 캠페인을 여세요.
2. **추가 설정**으로 이동하세요.
3. **Sub-Affiliate Sign-Up Page**(서브 제휴 파트너 가입 페이지)를 켜세요.

   ![서브 제휴 파트너 가입 페이지 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081159500/original/4Ve45xXAtHemoAFUavQ0qbmLaTY3ntTuWg.png?1789637750)
4. 모집 대상이 작성할 폼을 선택하세요.
5. 캠페인을 저장하세요.

설정이 끝나면 제휴 파트너가 **제휴 포털**에서 모집 URL을 확인하고, 서브 제휴 파트너 후보에게 공유할 수 있어요.

진행 흐름은 다음과 같아요.

제휴 파트너가 가입 URL 공유 → 모집 대상이 폼 작성 → 서브 제휴 파트너로 등록 → 제휴 계층 구조에 서브 제휴 파트너 표시

제휴 파트너는 **제휴 포털**에서 자신의 서브 제휴 파트너도 확인할 수 있어요.

{% hint style="info" %}
문제 해결: 가입 페이지에서 오류가 나면, 선택한 폼에 이름, 성, 이메일 항목이 모두 있는지 확인하세요.
{% endhint %}

## 커미션 티어 한도를 넘어서도 서브 제휴 파트너 모집하기

제휴 네트워크가 캠페인에 설정한 마지막 커미션 티어까지 커진 뒤에도, 제휴 파트너는 계속 서브 제휴 파트너를 모집할 수 있어요. 커미션 티어 수가 네트워크를 얼마나 깊게 키울 수 있는지를 제한하지는 않아요.

제휴 파트너가 판매를 만들면 **제휴 관리자**는 판매를 만든 제휴 파트너부터 거슬러 올라가며 커미션 대상인지 계산해요. 캠페인에 설정한 커미션 티어 한도 안에 있는 상위 제휴 파트너만 커미션을 받아요.

{% hint style="warning" %}
설정한 커미션 티어를 넘어 모집해도 커미션 지급이 그 티어 너머로 늘어나지는 않아요. 커미션 대상 범위 밖에 있는 제휴 파트너는 그 판매에서 커미션을 받지 못해요.
{% endhint %}

이 개선 사항은 멀티 티어 커미션을 쓰는 캠페인에 자동으로 적용돼요. 따로 설정하거나 바꿀 것은 없어요.

자세한 내용은 '제휴 관리자의 서브 제휴 파트너 모집 깊이 무제한 적용 방식' 문서를 참고하세요.

---

### 더 깊은 제휴 네트워크에서 커미션이 지급되는 방식

제휴 파트너가 판매를 만들면 **제휴 관리자**는 판매를 만든 제휴 파트너부터 시작해 제휴 계층을 거슬러 올라가며 커미션 대상인지 계산해요.

- 판매를 만든 제휴 파트너는 해당하는 1티어 커미션을 받아요.
- 대상이 되는 상위 제휴 파트너는 남은 설정 티어에 따라 커미션을 받아요.
- 설정된 커미션 티어 한도를 넘어선 제휴 파트너는 그 판매에서 커미션을 받지 못해요.

{% hint style="warning" %}
서브 제휴 파트너를 더 모집해도 커미션을 받을 수 있는 티어 수는 늘어나지 않아요.
{% endhint %}

## 캠페인 설정과 글로벌 설정의 차이

캠페인 설정과 글로벌 설정은 같은 종류의 서브 제휴 파트너 옵션을 서로 다른 범위에서 관리해요. 차이를 알아 두면 캠페인을 만들거나 수정할 때 예상과 다르게 동작하는 일을 막을 수 있어요.

- **Campaign Settings**(캠페인 설정): 지금 수정하는 개별 캠페인에 적용돼요.
- **글로벌 설정**: 앞으로 만드는 캠페인의 기본 서브 제휴 파트너 동작을 정해요.
- 기존 캠페인: 나중에 **글로벌 설정**을 바꿔도 이미 만든 캠페인에는 소급 적용되지 않아요.

**글로벌 설정**에서는 다음 항목을 설정할 수 있어요.

- **Auto Enroll New Customers as Sub-Affiliates**
- **Sub-Affiliate Sign-Up Page**

## 자주 묻는 질문

### 서브 제휴 파트너를 쓰려면 캠페인에 티어가 여러 개 있어야 하나요?

네. 서브 제휴 파트너 기능을 쓰기 전에 캠페인에 티어를 2개 이상 설정하세요.

### 제휴 티어는 몇 개까지 설정할 수 있나요?

하이퍼클래스는 멀티 티어 제휴 캠페인에서 최대 7개 티어를 지원해요.

### 추천받은 고객은 언제 서브 제휴 파트너가 되나요?

**Auto Enroll New Customers as Sub-Affiliates**를 켜 두면, 추천받은 판매가 성공한 뒤에 등록돼요.

### 서브 제휴 파트너 가입 폼에서 오류가 나요.

선택한 폼에 **이름**, **성**, **이메일** 항목이 모두 있는지 확인하세요. 서브 제휴 파트너 가입 과정에는 이 항목이 꼭 필요해요.

### 글로벌 설정을 바꾸면 기존 제휴 캠페인에도 적용되나요?

아니요. **글로벌 설정**에서 바꾼 내용은 앞으로 만드는 캠페인에 적용되고, 기존 캠페인은 바뀌지 않아요.

### 제휴 파트너마다 캠페인 기본값과 다른 커미션 비율을 줄 수 있나요?

네. 제휴 파트너 단위의 커스텀 커미션 설정이 그 제휴 파트너에게는 캠페인 단위 비율보다 우선 적용될 수 있어요. 전체 커미션 티어 수는 캠페인 단위로 정해져요.

### 서브 제휴 파트너를 제거하면 어떻게 되나요?

하이퍼클래스에는 서브 제휴 파트너 관계를 관리하는 기능이 있어요. 다만 현재 하이퍼클래스 도움말 문서에는 관계를 제거했을 때 과거 커미션 계산에 어떤 영향이 있는지 따로 나와 있지 않아요. 이미 만들어진 계층 구조를 바꾸기 전에 기존 커미션 기록을 먼저 확인하세요.

### 캠페인 설정을 바꿔야 하나요?

아니요. 서브 제휴 파트너 모집 깊이 무제한 기능은 멀티 티어 커미션을 쓰는 캠페인에 자동으로 적용돼요.

커미션 티어 수를 늘리거나 새 설정을 켤 필요는 없어요.

설정된 티어 한도 안의 제휴 파트너 체인에서는 커미션 지급 방식이 그대로예요.
