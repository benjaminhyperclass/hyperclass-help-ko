# 제휴 파트너에게 판매 실적 수동 등록하기

수동 판매 어트리뷰션(Manual Sale Attribution)을 쓰면 관리자가 판매 실적을 제휴 파트너에게 직접 연결할 수 있어요. 제휴 링크를 쓰지 않았거나 오프라인에서 이뤄진 판매도 제휴 파트너의 실적으로 인정할 수 있어요.

## 수동 판매 어트리뷰션이란?

관리자가 판매 실적을 제휴 파트너에게 직접 지정하는 기능이에요. 오프라인 판매, 제휴 링크를 쓰지 않은 판매, 수동으로 추적해야 하는 판매 모두 관리자가 직접 처리할 수 있어요. 제휴 파트너가 기여한 판매에 대해 빠짐없이 보상할 수 있어요.

## 이런 때 사용해요

1. 오프라인 판매: 제휴 파트너가 행사, 컨퍼런스, 오프라인 마케팅 캠페인으로 상품을 홍보한 경우
2. 추적되지 않은 판매: 제휴 링크는 쓰지 않았지만 제휴 파트너의 소개로 고객이 구매한 경우
3. 고객 추천: 제휴 링크를 클릭하지 않고 입소문 추천으로 판매가 이뤄진 경우

## 제휴 파트너에게 수동으로 판매 연결하기

판매와 커미션을 제휴 파트너에게 수동으로 연결하는 방법은 크게 세 가지예요.

### 1. 이미 있는 거래를 연결하기

시스템에 거래가 이미 있다면, 그 거래를 제휴 파트너에게 직접 연결할 수 있어요.

1. **제휴 관리자**(Affiliate Manager)를 여세요.
2. 제휴 프로필을 선택하고 **Commissions**(커미션) 탭으로 이동하세요.
3. **Add Sales Manually**(수동으로 판매 추가)를 클릭하고 **Import Existing Transaction**(기존 거래 가져오기)을 선택하세요.
   ![수동으로 판매 추가에서 기존 거래 가져오기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804699/original/1R29dX16p_xGCEhboo2w1sl265Y69X3Xsg.jpeg?1727703360)
4. 고객의 이메일을 입력하고 캠페인을 선택하세요.
   ![고객 이메일 입력과 캠페인 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804695/original/auA8qmeUoZATo6A_DGfna_KMVU1TMq7HvA.jpeg?1727703359)
5. 거래 내용을 확인하고 연결할 거래를 선택하세요.
   ![연결할 거래 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804694/original/Mit0KCxykL7xKA0Y2-SXkmARg8DAHXvt0Q.jpeg?1727703358)
6. 내용을 확인한 뒤 제출해요.

### 2. 거래가 없을 때 (오프라인 판매 또는 외부에서 처리한 판매)

현장 판매처럼 거래가 기록되지 않은 경우에는 이렇게 하세요.

1. 서브 계정의 **제휴 관리자**를 열고 제휴 프로필로 이동하세요.
2. **Commissions** 탭으로 스크롤해서 **Add Sales Manually**를 클릭하세요.
   ![커미션 탭에서 수동으로 판매 추가 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804700/original/1NeMJ0XWwgM5OEaEdAvE85Uk741lpene6Q.jpeg?1727703361)
3. 리드나 고객이 아직 없다면 새 리드로 추가하세요.
   ![새 리드 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804698/original/TvnpbKXzCzfzh17bVssXXjZi_x4XHpuAYQ.jpeg?1727703361)
4. 거래 금액을 입력하세요. 커미션은 캠페인의 기본 설정에 따라 자동으로 계산돼요.
   ![거래 금액 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804697/original/Kf2PIrEIaXLQbCz78FwE9q8tOW2PntRa0Q.jpeg?1727703360)
5. 필요하면 거래 날짜와 참조 번호를 추가하세요.
6. 제출하고 저장해요.

{% hint style="info" %}
수동 판매를 연결할 때는 판매 매출 금액만 입력하면 돼요. 커미션은 선택한 제휴 캠페인에 설정된 기본 커미션 비율로 자동 계산돼요.

예를 들어 매출 금액이 100달러인 수동 판매를 입력했고 해당 제휴 캠페인의 기본 커미션 비율이 20%라면, 제휴 파트너는 이 판매에 대해 20달러(100달러의 20%)를 커미션으로 자동으로 받아요.

커미션 계산은 시스템이 대신 처리하므로, 제휴 파트너는 캠페인에서 약속한 비율대로 커미션을 받아요.
{% endhint %}

### 3. 워크플로우와 자동화로 연결하기

반복되는 작업이나 한꺼번에 처리할 작업은 자동화를 사용하세요.

1. 워크플로우에 **Add Manual Sales For An Affiliate**(제휴 파트너에 수동 판매 추가) 액션을 추가하세요.
   ![워크플로우에 수동 판매 추가 액션 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804689/original/usiJrOiI83VpFERzhoy4xrwH4212GRXcuw.png?1727703358)
2. 최초 어트리뷰션과 최근 어트리뷰션 중 어느 쪽을 쓸지 선택하세요. 제휴 파트너의 활동을 기준으로 자동 추적하는 방식이에요.
   ![최초 또는 최근 어트리뷰션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033804696/original/DOnZrvjSHUBL0jEYTeN-6138rmUkVDPrdA.jpeg?1727703359)
3. 제휴 캠페인을 선택하고 매출 정보를 입력하세요.
4. 워크플로우를 저장하면 수동 판매 어트리뷰션이 자동으로 처리돼요.

## 수동 판매 어트리뷰션의 장점

- 유연성: 오프라인이나 일반적이지 않은 플랫폼에서 발생한 판매도 수동으로 연결할 수 있어요.
- 정확도: 제휴 파트너가 만든 모든 판매를 빠짐없이 추적하고 실적으로 인정할 수 있어요.
- 사용자 지정 추적: 링크 같은 기본 추적 수단을 쓰지 않았더라도 판매를 제휴 파트너에게 연결할 수 있어요.
