# 제휴에 속한 고객 관리하기

제휴에 속한 고객을 삭제하거나, 비활성화·활성화하거나, 다른 제휴로 옮기는 방법을 안내해요. 커미션 삭제 방법도 함께 다뤄요. 고객을 알맞게 관리하면 커미션이 정확하게 집계되고 제휴 프로그램도 원활하게 운영돼요.

## 제휴에서 고객 삭제하기

### 1단계. 제휴 프로필 열기

- **제휴** 페이지로 이동하세요.
- 삭제할 고객이 속한 제휴를 찾으세요.
- 제휴 이름을 클릭해 상세 정보를 여세요.

### 2단계. 고객 찾기

- **고객** 탭에서 삭제할 고객을 찾으세요.
- 검색창이나 필터를 쓰면 빠르게 찾을 수 있어요.

![고객 탭에서 고객 찾기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041694830/original/Rs28ZeQLTK7EYNKOTdjNimkI6ixmeeaq3w.png?1739776643)

### 3단계. 고객 삭제하기

- 고객 이름 옆의 **삭제** 버튼을 클릭하세요.
- 확인 창이 나타나면 삭제를 확인하세요.

![고객 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041694841/original/ze_KOIAsP6a9KNKaSC6XlRXbR8IRcmulDw.png?1739776653)

{% hint style="info" %}
**고객을 삭제하면 어떻게 되나요?**
- 해당 고객은 더 이상 이 제휴와 연결되지 않아요.
- 이 고객에게서 발생하는 커미션은 앞으로 생성되지 않아요.
{% endhint %}

## 고객 비활성화·활성화하기

### 1단계. 제휴 프로필 열기

- **제휴** 페이지로 이동하세요.
- 해당 고객이 속한 제휴를 찾으세요.
- 제휴 이름을 클릭해 상세 정보를 여세요.

### 2단계. 고객 찾기

- **고객** 탭에서 비활성화하거나 활성화할 고객을 찾으세요.
- 검색창이나 필터를 쓰면 빠르게 찾을 수 있어요.

### 3단계. 고객 비활성화하기

- 점 3개 메뉴를 클릭한 다음 **Disable Customer**(고객 비활성화)를 클릭하세요.
- 확인 창에서 작업을 확인하세요.
- 고객의 상태 태그가 **Disabled**(비활성화됨)로 바뀌어요.
- 다시 활성화하려면 같은 방법으로 **Enable Customer**(고객 활성화)를 클릭하세요. 비활성화된 고객만 다시 활성화할 수 있어요.

![고객 비활성화 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042193140/original/ENSjul7U4c4ZIhsSsXwqQGIA0wdanpeK4Q.png?1740479229)

{% hint style="info" %}
**고객은 언제 비활성화하나요?**
고객을 "비활성화됨" 상태로 두면 이후 판매가 추적되지 않고, 커미션도 더 이상 발생하지 않아요. 부정 가입을 처리하거나, 특정 경우에 커미션이 배정되지 않게 할 때 유용해요.
{% endhint %}

## 커미션 삭제하기

### 1단계. 제휴 프로필 열기

- **제휴** 페이지로 이동하세요.
- 삭제할 커미션이 있는 제휴를 찾으세요.
- 제휴 이름을 클릭해 상세 정보를 여세요.

### 2단계. 커미션 찾기

- **Commissions**(커미션) 탭에서 삭제할 커미션을 찾으세요.
- **Denied**(거절됨) 상태의 커미션만 삭제할 수 있어요. 필요하면 먼저 해당 커미션을 거절하세요.

![커미션 탭에서 커미션 찾기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042528246/original/amT3S38PlZzKiG-ZqtOnt0RKwKFXdfey8g.png?1740997766)

### 3단계. 커미션 삭제하기

- 거절한 뒤 점 3개 메뉴를 다시 클릭하고 **삭제**를 클릭하세요.

  ![커미션 삭제 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042528432/original/XPZJIdaJ1uJlL6micNsPyLcVytJSm5JhIg.png?1740997869)

- 확인 창에서 작업을 확인하세요.

  ![커미션 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042528452/original/LSqRLYM1JDSV_pSOxNcZURzlnosuJzbdNw.png?1740997879)

## 고객을 다른 제휴로 이동하기

{% hint style="warning" %}
**중요 안내**
- 고객은 같은 캠페인 안에서만 이동할 수 있어요.
- 커미션도 함께 이동하도록 선택하면 지급되지 않은 커미션만 옮겨져요. 이미 지급된 커미션은 원래 제휴에 남아요.
{% endhint %}

### 1단계. 제휴 관리자로 이동하기

- **제휴 관리자**에서 고객이 현재 배정된 제휴의 프로필로 이동하세요.

### 2단계. 고객 탭으로 스크롤하기

- 제휴 프로필 안에서 아래로 스크롤해 **고객** 섹션을 찾으세요.

### 3단계. 점 3개 메뉴(⋮) 클릭하기

- 이동할 고객 옆의 점 3개를 클릭해 작업 메뉴를 여세요.

### 4단계. 고객 이동 선택하기

- 드롭다운에서 **Move Customer**(고객 이동)를 선택하세요.

![고객 이동 메뉴 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044773814/original/-Kx6P7L6GA8Wf6CanKVN7wqjtiCCX_ikAw.png?1744181966)

### 5단계. 이동할 제휴 선택하기

- 팝업에서 고객을 옮길 제휴를 선택하세요.
- 지급되지 않은 커미션도 함께 옮기려면 **Also move all associated commissions of this Customer to destination Affiliate**(이 고객의 모든 관련 커미션을 대상 제휴로도 이동) 옵션을 켜세요.
- **이동**을 클릭하면 이동이 끝나요.

![이동할 제휴 선택 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044773868/original/zitPHCIS7LlmlG0TdOQCm55QuXWZ2PLjCA.png?1744182029)
