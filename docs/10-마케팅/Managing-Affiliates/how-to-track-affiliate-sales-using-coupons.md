# 쿠폰으로 제휴 판매 추적하기

추천 링크를 공유하기 어려울 때는 제휴 쿠폰으로 판매를 추적할 수 있어요. 제휴 파트너마다 고유한 쿠폰 코드를 하나씩 정해 주면, 고객이 결제할 때 그 코드를 입력해요. 쿠폰은 할인을 줄 수도 있고, 제휴 실적만 추적하고 싶을 때는 할인율을 0%로 설정할 수도 있어요.

## 쿠폰 코드 추적의 장점

- 제휴 파트너가 여러 채널에서 오퍼를 홍보할 때 더 유연하게 대응할 수 있어요.
- 추천 링크 없이도 판매를 추적할 수 있어요. 제휴 파트너가 추천 URL을 공유하기 어려울 때 쿠폰 코드를 쓰세요.
- 할인 방식을 유연하게 정할 수 있어요. 퍼센트 할인과 정액 할인을 모두 만들 수 있어요.
- 할인 없이 추적만 할 수 있어요. 0% 쿠폰을 쓰면 고객의 구매 금액은 그대로 두고 제휴 판매만 추적해요.

## 쿠폰 코드 설정하고 사용하기

1. **마케팅 > 제휴 관리자**로 이동해요. 그다음 **Affiliate/Promoter**(제휴/프로모터) 섹션을 열고, 설정할 제휴 파트너를 선택해요.
2. **Active Referral Links**(활성 추천 링크)로 스크롤해 해당 캠페인을 찾은 다음 **커스터마이징**을 클릭해요.
3. 캠페인을 커스터마이징해요.
   - **Active Referral Links** 섹션까지 아래로 스크롤하면 캠페인 목록과 제휴 파트너의 URL이 보여요.
   - 원하는 캠페인에서 **커스터마이징**을 클릭해요.

   ![캠페인의 커스터마이징 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033859110/original/CyUb1QDoCKo-vtVW0R2ewt6Isfs3HeGLyg.png?1727774580)
4. 쿠폰을 설정해요.
   - **Coupon**(쿠폰) 탭으로 이동해요.
   - 쿠폰 유형으로 **Percentage**(퍼센트) 또는 **Fixed**(정액)를 선택해요.
   - 알아보기 쉬운 쿠폰 이름을 입력해요.
   - **Generate Code**(코드 생성)를 클릭해 쿠폰 코드를 만들어요.

   ![쿠폰 탭에서 쿠폰 유형과 이름을 입력하고 코드를 생성하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033859199/original/oxSMxDkMOY0RrDIe5xZH7hAKLJSl1JvI1Q.png?1727774643)
5. 할인율을 설정해요.
   - 무료로 제공하려면 할인율을 `100%`로 설정해요.
   - 특정 할인을 주려면 `0%`부터 `100%` 사이에서 할인율을 정해요.

   {% hint style="info" %}
   할인율 `0%`는 추적 용도로만 쓰여요.
   {% endhint %}
6. 저장하고 관리해요.
   - **저장**을 클릭하면 쿠폰 코드가 확정돼요.
   - 같은 팝업 창에서 기존 쿠폰 코드를 편집하거나 관리할 수도 있어요.

## 알아 두세요

- 제휴 파트너가 자기 고객에게 쉽게 공유할 수 있도록 알아보기 쉬운 쿠폰 코드를 쓰세요.
- 프로모션 전략에 맞춰 쿠폰 코드를 주기적으로 검토하고 업데이트하세요.
