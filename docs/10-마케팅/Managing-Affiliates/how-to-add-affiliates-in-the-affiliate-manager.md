# 제휴 관리자에서 제휴 추가하기

**제휴 관리자**(Affiliate Manager)에서는 제휴 프로그램에 사람을 추가하는 방법이 여러 가지예요. 직접 한 명씩 추가하거나, CSV 파일로 한꺼번에 올리거나, 기존 연락처를 가져오거나, 워크플로우 액션을 쓸 수 있어요. 직접 추가와 가져오기는 **제휴 관리자**의 **제휴** 페이지에서 할 수 있어요. 이 문서에서는 방법별 요건과 워크플로우 자동화를 어디에 쓰는지 설명해요.

## 제휴 추가란

제휴는 내 상품이나 서비스를 홍보하고, 그 홍보로 발생한 판매나 리드에 따라 수수료를 받는 개인 또는 사업자예요. 제휴마다 고유한 제휴 링크가 있어서 홍보 성과를 추적할 수 있어요. 보통 "제휴 마케터"나 "퍼블리셔"라고도 불러요. 제휴를 추가하면 그 사람이 **제휴 관리자**에 등록되어, 내가 설정한 제휴 프로그램에 참여할 수 있어요.

하이퍼클래스에서는 **제휴** 페이지에서 바로 쓸 수 있는 방법이 세 가지 있어요.

- **New Affiliate**(새 제휴)
- **Upload Affiliate**(제휴 업로드)
- **Import from Contacts**(연락처에서 가져오기)

워크플로우 액션을 쓰면 제휴 생성, 캠페인 등록, 상태 변경, 캠페인에서 제거하는 작업도 자동으로 처리할 수 있어요.

## 제휴를 추가하면 좋은 점

제휴 정보가 하이퍼클래스에 이미 어떤 형태로 있는지에 맞춰 추가 방법을 고르세요.

- 유연한 추가 방식: 제휴를 한 명씩 직접 추가하거나, 여러 명을 함께 추가할 수 있어요.
- 기존 연락처 활용: 추가할 사람이 이미 하이퍼클래스에 있다면 CRM 연락처에서 시작할 수 있어요.
- 대량 가져오기: CSV 파일로 여러 제휴 정보를 한 번에 올릴 수 있어요.
- 캠페인 배정: 제휴를 알맞은 제휴 캠페인에 배정할 수 있어요.
- 워크플로우 자동화: 워크플로우 조건이 충족되면 제휴를 자동으로 추가하거나 업데이트할 수 있어요.

## 제휴 추가 방법

**제휴** 페이지에서 시작한 뒤, 원하는 추가 방법을 고르세요.

### 제휴 페이지 열기

제휴 목록은 서브 계정 메뉴에서 열어요.

1. 하이퍼클래스 **서브 계정** 화면에서 **마케팅**을 선택하세요.
2. **제휴 관리자**를 선택하세요.
3. **제휴**를 여세요.
4. **+ 추가**를 클릭하세요.

![제휴 페이지의 + 추가 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082619431/original/oTnWJ-sz7yIeL-JrifULReqIwAYTnaWhmQ.png?1791283045)

**+ 추가** 메뉴에는 세 가지 옵션이 있어요.

- **New Affiliate**
- **Upload Affiliate**
- **Import from Contacts**

### 제휴 한 명 직접 추가하기

**제휴 관리자**에서 제휴를 한 명씩 직접 추가할 때는 **New Affiliate**를 쓰세요.

1. 하이퍼클래스 **서브 계정** 화면에서 **마케팅**을 선택하세요.
2. **제휴 관리자**를 선택하세요.
3. **제휴**를 여세요.
4. **+ 추가**를 클릭하세요.
5. **New Affiliate**를 선택하세요.
6. 제휴의 **이메일**을 입력하세요.
7. 제휴의 **이름**을 입력하세요.
8. 제휴의 **성**을 입력하세요.
9. 해당하면 **회사명**을 입력하세요.
10. **Assign to Campaign**(캠페인에 배정)에서 제휴 캠페인을 선택하세요.

이 창에는 아래 항목도 있어요.

- **Save & Continue to Add More Details**(저장하고 상세 정보 계속 추가)
- **저장**
- **완료**
- **CSV 업로드** 바로가기

### CSV 파일로 제휴 대량 추가하기

CSV 파일로 여러 제휴를 한 번에 추가할 때는 **Upload Affiliate**를 쓰세요.

1. 하이퍼클래스 **서브 계정** 화면에서 **마케팅**을 선택하세요.
2. **제휴 관리자**를 선택하세요.
3. **제휴**를 여세요.
4. **+ 추가**를 클릭하세요.
5. **Upload Affiliate**를 선택하세요.

   ![제휴 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082623601/original/olHJtGeY36IcUcUALcecQVGLkmHpZXYagw.png?1791284672)

6. 가져오기 템플릿이 필요하면 **샘플 파일**을 선택하세요.
7. 가져올 제휴 정보가 담긴 `.csv` 파일을 준비하세요.
8. 제휴마다 **이름**, **성**, **이메일**을 넣으세요.
9. 파일 크기는 현재 업로드 한도인 **50 MB** 이내로 맞추세요.
10. CSV 파일을 업로드하거나 업로드 영역으로 끌어다 놓으세요.
11. **다음**을 클릭하세요.

이후 마법사는 아래 순서로 진행돼요.

**업로드 → 지도 → 상세 정보**

#### CSV 필드 매핑하기

**지도** 단계는 CSV 파일을 업로드한 뒤에 진행해요.

#### 가져오기 상세 정보 완료하기

**상세 정보** 단계에서는 대량 가져오기에 필요한 나머지 설정을 마무리해요.

업로드 화면에서 **Add Affiliate Manually**(제휴 직접 추가)를 선택하면 CSV 작업을 멈추고 직접 입력 방식으로 바꿀 수 있어요.

### 연락처에서 제휴 가져오기

추가할 사람이 서브 계정에 이미 CRM 연락처로 있다면 **Import from Contacts**를 쓰세요.

1. 하이퍼클래스 **서브 계정** 화면에서 **마케팅**을 선택하세요.
2. **제휴 관리자**를 선택하세요.
3. **제휴**를 여세요.
4. **+ 추가**를 클릭하세요.
5. **Import from Contacts**를 선택하세요.

{% hint style="warning" %}
이 방법은 CRM 연락처를 기존 제휴 아래 리드로 가져오는 것과는 달라요. 이 섹션에서는 **제휴 > + 추가 > Import from Contacts**로 연락처를 제휴로 추가하는 방법을 다뤄요.
{% endhint %}

### 워크플로우로 제휴 관리 자동화하기

하이퍼클래스 워크플로우에는 제휴 전용 트리거와 액션이 있어요. 이를 쓰면 제휴 등록, 캠페인 배정, 리드 귀속, 판매 기록, 제휴 상태 변경을 자동화할 수 있어요. 워크플로우 빌더는 영어 화면으로 표시돼서, 트리거와 액션 이름도 영어 그대로 적었어요.

### 제휴 워크플로우 트리거

- **Affiliate created**(제휴 생성됨): 새 제휴가 만들어지면 워크플로우가 시작돼요.
- **New affiliate sales**(새 제휴 판매): 새 제휴 판매가 기록되면 워크플로우가 시작돼요.
- **Affiliate enrolled in campaign**(제휴가 캠페인에 등록됨): 제휴가 제휴 캠페인에 등록되면 워크플로우가 시작돼요.
- **Lead created**(리드 생성됨): 새 제휴 리드가 만들어지면 워크플로우가 시작돼요.

![제휴 워크플로우 트리거 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082627703/original/JWQIPUxxAnhP_4f2qwf9R8SAJjwQLcFung.png?1791286044)

### 제휴 워크플로우 액션

현재 워크플로우 빌더에는 아래 제휴 액션이 있어요.

- **Add to affiliate manager**(제휴 관리자에 추가): 워크플로우의 연락처를 제휴로 **제휴 관리자**에 추가해요.
- **Update affiliate**(제휴 업데이트): 기존 제휴의 상태나 지원되는 제휴 정보를 업데이트해요.
- **Add to affiliate campaign**(제휴 캠페인에 추가): 워크플로우의 연락처를 선택한 제휴 캠페인에 등록해요.
- **Remove from affiliate campaign**(제휴 캠페인에서 제거): 선택한 제휴 캠페인에서 제휴를 제거해요.
- **Add leads under an affiliate**(제휴 아래 리드 추가): 선택한 제휴에 리드를 연결해요.
- **Add manual sales for an affiliate**(제휴 수동 판매 추가): 선택한 제휴의 판매를 수동으로 기록해요.

![제휴 워크플로우 액션 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082627585/original/yU2A39lsEWbxtWtrnZ23btrpZI_iwBOswg.png?1791286025)

## 자주 묻는 질문

### 하이퍼클래스에서 제휴를 추가하는 방법에는 어떤 것이 있나요?
제휴를 한 명씩 직접 추가하거나, CSV로 업로드하거나, 기존 연락처를 가져올 수 있어요. **제휴 관리자** 워크플로우 액션을 쓰는 방법도 있어요.

### 제휴를 한 명씩 직접 추가할 때 꼭 입력해야 하는 정보는 무엇인가요?
현재 **Add New Affiliate**(새 제휴 추가) 폼에서는 **이메일**, **이름**, **성**, **Assign to Campaign**이 필수 항목이에요.

### CSV로 제휴를 업로드할 때 필수 필드는 무엇인가요?
현재 업로드 화면에서는 제휴마다 **이름**, **성**, **이메일**이 필요해요.

### 제휴 CSV 파일은 최대 몇 MB까지 올릴 수 있나요?
현재 업로드 화면에서는 최대 **50 MB**까지의 `.csv` 파일을 지원해요.

### Add To Affiliate Manager 액션을 쓰면 연락처가 활성 상태가 되나요?
네. 현재 이 워크플로우 액션은 연락처를 활성(Active) 상태로 **제휴 관리자**에 추가해요.

### Add To Affiliate Campaign 전에 Add To Affiliate Manager를 먼저 써야 하나요?
그렇지는 않아요. **Add To Affiliate Campaign**은 워크플로우의 연락처를 활성 제휴로 바꾸면서, 선택한 캠페인에 바로 등록할 수 있어요.
