# 이메일 캠페인 통계 가이드

이메일 캠페인 통계에서는 이메일 성과와 수신자 반응을 확인하고, 캠페인이 전환과 매출에 얼마나 기여했는지 볼 수 있어요. 이 문서에서 각 지표의 의미와 통계 화면을 보는 방법을 안내해요.

이메일 캠페인 통계에서는 발송, 오픈, 클릭, 주문 같은 주요 지표를 확인할 수 있어요. 어떤 내용이 고객에게 반응을 얻는지 파악할 수 있고, 성과 추이와 상세 리포트를 바탕으로 이메일 마케팅 전략을 개선할 수 있어요.

## 이메일 캠페인 통계란?

이메일 캠페인 통계는 이메일 마케팅의 효과를 측정하는 리포팅 기능이에요. 이메일 활동, 수신자 반응, 해당되는 전환 지표를 보여 주기 때문에 캠페인 결과를 평가하고 개선할 부분을 찾을 수 있어요.

이메일 통계 대시보드에는 **이메일 캠페인**, 워크플로우의 이메일 액션, **일괄 작업**의 통계가 한데 모여 있어요. 통합 통계를 볼 수도 있고, 대시보드를 필터링해 **이메일 캠페인**만 볼 수도 있어요. 캠페인 하나를 더 자세히 분석하려면 해당 캠페인의 통계 페이지로 이동하세요.

---

## 이메일 캠페인 통계의 주요 이점

연락처가 이메일에 어떻게 반응하는지 알면 캠페인 효과를 평가하고 데이터에 근거해 개선할 수 있어요. 이메일 캠페인 통계는 고객 참여, 발송 성과, 전환 정보를 보여 줘서 성공한 캠페인을 찾고 다음 이메일을 최적화하는 데 도움이 돼요.

- 캠페인 성과 모니터링: 이메일 발송, 오픈, 클릭 같은 참여 지표를 추적해 캠페인 성과를 파악해요.
- 수신자 참여도 측정: 연락처가 이메일에 어떻게 반응하는지 보고, 콘텐츠와 콜투액션을 개선할 부분을 찾아요.
- 성과 추이 분석: 기간별 리포팅 데이터를 살펴 참여도 변화를 확인하고 캠페인 결과를 평가해요.
- 성과가 좋은 이메일 찾기: 반응이 좋은 이메일을 확인하고, 그 결과를 다음 캠페인에 활용해요.
- 전환과 매출 추적: 인정되는 주문, 귀속된 매출, 전환 지표를 보고 이메일 캠페인이 매출에 어떻게 기여하는지 파악해요.
- 이메일 소스 비교: **이메일 캠페인**, **워크플로우**, **일괄 작업** 기준으로 통계를 필터링해 이메일 활동을 비교해요.
- 성과 데이터 내보내기: 확인할 수 있는 리포팅 지표를 CSV 형식으로 내려받아 추가 분석에 쓰거나 공유해요.

## Conversion Summary(전환 요약)

**Conversion Summary**는 이메일 반응이 구매나 매출 같은 비즈니스 성과로 얼마나 이어졌는지 보여 줘요. 귀속된 전환과 참여 지표를 함께 보면 오픈과 클릭을 넘어 실제 성과를 낸 캠페인을 가려낼 수 있어요.

리포팅 화면과 전환 데이터에 따라 다음 지표가 표시될 수 있어요.

| 지표 | 설명 |
| --- | --- |
| **Orders / Conversions**(주문 / 전환) | 이메일 캠페인에 귀속된, 인정되는 구매 또는 전환의 수예요. |
| **Revenue**(매출) | 캠페인에 귀속된 총 매출이에요. |
| **Conversion / Order Rate**(전환율 / 주문율) | 해당 리포팅 계산 방식에 따라, 귀속된 전환과 연결된 수신자의 비율이에요. |
| **평균 주문 금액** | 귀속된 주문의 평균 금액이에요. |
| **Revenue per Recipient (RPR)**(수신자당 매출) | 이메일 수신자 1명당 발생한 귀속 매출의 평균이에요. |

하이퍼클래스는 이메일 어트리뷰션 기간(attribution window)을 기준으로, 어떤 이메일 반응에 구매 실적을 인정할지 정해요. 기본 어트리뷰션 기간은 5일이고, 변경할 수 있어요.

연락처가 인정 대상 캠페인 여러 개에 반응했다면, 어트리뷰션 기간 안에서 가장 최근에 일어난 인정 대상 이메일 반응에 구매 실적이 돌아가요.

{% hint style="warning" %}
중요: 귀속 매출은 투자수익률(ROI)과 같지 않아요. ROI를 구하려면 비용이나 지출 정보도 필요해요. 캠페인에 귀속된 인정 구매가 없으면 전환 데이터가 0으로 표시될 수 있어요.
{% endhint %}

어트리뷰션 설정, 인정 기준, 계산 방식은 [이메일 전환 및 매출 어트리뷰션 이해하기](../understanding-email-conversion-and-revenue-attribution.md)에서 자세히 확인하세요.

## Engagement Summary(참여 요약)

**Engagement Summary**는 수신자가 이메일에 어떻게 반응하는지 한눈에 보여 줘요. 발송, 오픈, 클릭을 비교하면 캠페인이 수신자에게 잘 닿고 있는지, 의미 있는 반응을 얻고 있는지 알 수 있어요.

리포팅 화면에 따라 다음 지표가 표시될 수 있어요.

| 지표 | 설명 |
| --- | --- |
| **Sent**(발송) | 선택한 리포팅 기간에 발송한 이메일 수예요. |
| **Delivered**(전달) | 확인된 전달 이벤트를 기준으로, 정상 전달된 이메일의 수 또는 비율이에요. |
| **Opened**(오픈) | 지원되는 추적 방식으로 기록된 이메일 오픈 활동이에요. |
| **Clicked**(클릭) | 지원되는 추적 방식으로 기록된 이메일 링크 클릭 활동이에요. |
| **Unsubscribed**(수신 해지) | 앞으로 이메일을 받지 않겠다고 선택한 수신자예요. |
| **Bounced**(반송) | 전달하지 못한 이메일이에요. 보고된 경우 일시적 실패와 영구적 실패를 모두 포함해요. |

### 고유 오픈과 고유 클릭

고유 지표는 같은 수신자의 반복 활동이 여러 번 집계되지 않도록 해 줘요.

- **Unique Opens**(고유 오픈): 한 수신자가 같은 이메일을 여러 번 열어도 1명으로 집계해요.
- **Unique Clicks**(고유 클릭): 해당되는 이메일 클릭 활동에서, 한 수신자가 여러 번 클릭해도 1명으로 집계해요.

반응한 수신자 수를 보고 싶을 때는 전체 반응 횟수보다 고유 지표가 더 유용해요.

{% hint style="info" %}
참고: 오픈과 클릭 추적은 설정된 발송 제공업체와 추적 설정에 따라 달라져요. 오픈은 추적 신호일 뿐, 수신자가 이메일을 실제로 읽었다는 것을 보장하지는 않아요.
{% endhint %}

## Performance Analysis(성과 분석)

**Performance Analysis**는 이메일 지표가 시간에 따라 어떻게 변하는지 보여 줘요. 추이를 살펴보면 참여 패턴을 파악하고, 기간별로 비교하고, 캠페인 성과를 개선해야 할 부분을 찾기 쉬워요.

제공되는 리포팅 컨트롤에 따라 다음 같은 지표를 분석할 수 있어요.

- 이메일 발송 및 전달 활동
- 이메일 오픈
- 이메일 클릭
- 수신 해지
- 그 밖에 지원되는 성과 이벤트

### 성과 추이 분석하기

1. 이메일 통계 대시보드를 열어요.
2. 확인할 리포팅 기간을 선택해요.
3. 캠페인별 결과를 보려면 이메일 소스 드롭다운에서 **이메일 캠페인**을 선택해요.
4. **Performance Analysis**까지 스크롤해요.
5. 분석할 지표를 선택해요.
6. 차트를 보고 증가, 감소, 반복되는 패턴을 확인해요.

예를 들어 이메일 발송량은 일정한데 고유 클릭이 줄고 있다면, 이메일 콘텐츠, 타깃 설정, 콜투액션을 점검해 보세요.

## Top Performing Emails(성과 상위 이메일)

**Top Performing Emails**는 수신자 반응이 좋은 이메일 콘텐츠를 찾는 데 도움이 돼요. 성과가 좋은 이메일을 비교하면 어떤 제목, 메시지 방식, 콜투액션이 고객에게 더 잘 통하는지 알 수 있어요.

현재의 통합 이메일 통계 대시보드에서는 오픈율, 클릭률 같은 참여 지표로 성과 상위 이메일을 평가할 수 있어요.

리포팅 소스에 따라 이메일을 나누는 단위가 달라요.

| 이메일 소스 | 리포팅 단위 |
| --- | --- |
| 이메일 캠페인 | 캠페인 이메일 발송 건별 |
| 워크플로우 캠페인 | 워크플로우 안의 이메일 액션별 |
| 일괄 작업 캠페인 | 일괄 이메일 발송 건별 |

캠페인을 비교할 때는 참여율과 함께 수신자 규모도 살펴보세요. 오픈율은 높지만 수신자가 적은 캠페인은, 오픈율이 조금 낮아도 수신자가 많은 캠페인과 다르게 해석해야 할 수 있어요.

{% hint style="info" %}
참고: 이전 이메일 캠페인 통계 가이드에는 매출 기준 상위 5개를 보여 준다는 설명이 있었어요. 이 예전 설명은 현재 통합 **Top Performing Emails** 리포트의 정의가 아니에요.
{% endhint %}

## Recent Email Analysis(최근 이메일 분석)

최근 발송한 이메일 캠페인을 살펴보면 과거 추이에만 의존하지 않고 새 활동을 평가할 수 있어요. 최근 캠페인 결과를 비교하면 이메일 콘텐츠, 타깃 설정, 발송 전략을 바꾼 효과가 기대한 참여도로 이어지는지 알 수 있어요.

예전 이메일 캠페인 통계에는 가장 최근에 발송한 이메일 10개를 보여 주는 **Recent Email Analysis** 영역이 있었어요. 현재 리포팅 화면에서는 각 캠페인의 통계 페이지에서 발송한 캠페인을 하나씩 확인할 수 있어요.

최근 캠페인을 분석하려면 전달 및 참여 지표, 확인 가능한 경우 전환 결과, 수신자별 상세 정보를 살펴보세요.

더 자세한 리포팅은 이메일 통계 – 요약 페이지 문서를 참고하세요.

## 이메일 캠페인 통계 확인하고 활용하기

원하는 캠페인과 기간을 정확히 평가하려면 알맞은 리포팅 화면에서 시작해야 해요. 하이퍼클래스에는 이메일 활동을 비교하는 통합 이메일 통계 대시보드와, 발송 건 하나를 살펴보는 캠페인별 통계 화면이 따로 있어요.

### 이메일 통계 대시보드 열기

1. 하이퍼클래스 서브 계정에서 **마케팅 > 이메일**로 이동하세요.
2. **통계** 탭을 선택하세요.
3. 대시보드 위쪽의 이메일 소스 드롭다운을 여세요.
4. 마케팅 캠페인만 보려면 **이메일 캠페인**을, 이메일 활동을 합쳐서 보려면 **All Campaigns**(전체 캠페인)를 선택하세요.
5. 리포팅 기간을 선택하세요.
6. **Engagement Summary**에서 전체 이메일 활동을 확인하세요.
7. **Performance Analysis**까지 스크롤해 성과 추이를 살펴보세요.
8. **Top Performing Emails**에서 성과가 좋은 이메일 발송 건을 확인하세요.

{% hint style="warning" %}
중요: 이제 문서화된 설정 절차에 별도의 베타 활성화 단계는 없어요. 서브 계정에서 이메일 통계를 사용할 수 있게 되면 바로 접근할 수 있어요.
{% endhint %}

캠페인별 통계에서는 전달 결과, 수신자 반응, 전환을 더 자세히 볼 수 있어요. 여러 발송 건을 비교하기보다 특정 캠페인을 살펴볼 때 특히 유용해요.

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. 확인할 발송 완료 캠페인을 찾으세요.

### 이메일 캠페인 통계 내보내기

이메일 통계를 내보내면 하이퍼클래스 밖에서 추가로 분석하거나 캠페인 성과 데이터를 공유할 수 있어요. 내보내기 파일은 CSV 형식이고, 선택한 리포팅 소스의 이메일 활동을 담을 수 있어요.

1. **마케팅 > 이메일 > 통계**로 이동하세요.
2. 리포팅 소스와 기간을 선택하세요.
3. **내보내기**를 클릭하세요.
4. 내보내기 파일을 받을 이메일 주소를 입력하세요. 여러 개를 입력해도 돼요.
5. **내보내기**를 클릭해 요청을 제출하세요.
6. CSV 다운로드 링크가 담긴 이메일을 여세요.

내보내기 다운로드 링크는 생성된 후 30일 동안 유효해요. 자세한 안내는 [이메일 캠페인 데이터 내보내기](../이메일-마케팅/exporting-email-campaign-data.md)를 참고하세요.

## 자주 묻는 질문

### 캠페인을 보냈는데 이메일 통계가 바로 안 보여요.

대부분의 이메일 통계는 거의 실시간으로 업데이트되지만, 일부 반응 이벤트는 표시되기까지 몇 분 걸릴 수 있어요. 캠페인이 발송되었는지, 리포팅 소스와 기간을 올바르게 선택했는지 확인하세요.

### 캠페인에 오픈은 있는데 클릭이 없어요.

수신자가 링크를 클릭하지 않고 이메일만 열었을 수 있어요. 클릭이 있어야 하는 상황이라면 클릭 추적이 켜져 있는지, 해당 링크가 추적 설정에서 지원되는지 확인하세요.

### 전달이나 반송 통계가 일부 보이지 않아요.

설정된 이메일 서비스 제공업체에 따라 확인할 수 있는 리포팅 이벤트가 달라요. 하이퍼클래스 이메일이나 Mailgun과 달리, 일부 제공업체는 오픈과 클릭 리포팅은 지원해도 같은 수준의 전달 또는 반송 정보는 제공하지 않아요.

### 연락처가 구매한 내역이 이메일 귀속 매출과 맞지 않아요.

매출 어트리뷰션에는 설정된 어트리뷰션 기간 안에서 인정되는 이메일 반응과 연결된 구매만 포함돼요. 어트리뷰션 기간이나 적용 범위를 벗어난 구매는 캠페인에 반영되지 않을 수 있어요.

### 워크플로우 하나가 **Top Performing Emails**에 여러 항목으로 나와요.

하이퍼클래스는 워크플로우의 이메일 액션을 하나씩 따로 평가해요. 워크플로우 전체를 하나의 결과로 합치지 않기 때문에, 어떤 이메일이 성과가 좋은지 구체적으로 확인할 수 있어요.

### 대시보드에 샘플 데이터가 표시된다는 건 무슨 뜻인가요?

샘플 데이터는 리포팅 화면을 미리 볼 수 있도록 보여 주는 데모 통계예요. 샘플 데이터 안내가 나타나면 실제 이메일 성과를 분석하기 전에 **샘플 데이터 지우기**를 사용하세요.

### 수신 해지했거나 스팸으로 신고한 연락처를 확인할 수 있나요?

네. 해당 캠페인의 통계를 열고 **상세 정보** 영역에서 수신자별 정보를 확인하세요. 확인할 수 있는 경우에 한해 표시돼요.

### 캠페인 통계를 내보내면 캠페인이나 연락처 정보가 바뀌나요?

아니요. 통계 내보내기는 리포팅 작업이에요. 이메일 캠페인, 워크플로우, 연락처 레코드, 기록된 통계는 바뀌지 않아요.
