# 캠페인 통계에서 연락처에 태그 지정하기

이메일 캠페인 통계에서 이메일을 열었거나 링크를 클릭한 연락처에 바로 태그를 지정할 수 있어요. 이미 반응한 연락처에는 직접 태그를 지정하고, 앞으로 반응할 연락처에는 자동 태그를 켜 두면 돼요. 이 문서에서 태그를 설정하는 방법, 여러 태그를 한꺼번에 지정하는 방법, 태그 지정 기록을 확인하는 방법을 알아보세요.

## 캠페인 통계에서 연락처에 태그를 지정한다는 건

캠페인 통계에서 태그를 지정하면 수신자가 이메일 캠페인에 반응한 방식에 따라 대상을 나눌 수 있어요. **연락처**에서 반응한 사람을 일일이 찾지 않아도 돼요. 캠페인 반응 데이터에서 수신자를 바로 골라 알맞은 태그를 붙이면 됩니다. 이렇게 나눈 그룹은 이후 마케팅에 활용할 수 있어요.

예를 들어 특정 캠페인에서 이메일을 연 연락처나 링크를 클릭한 연락처에 태그를 지정할 수 있어요. 자동 태그를 켜 두면, 앞으로 이 캠페인에 반응하는 연락처에도 직접 작업하지 않아도 태그가 붙어요. 이 기능은 발송을 마친 이메일 캠페인의 **통계** 화면에서 사용해요.

## 캠페인 통계에서 태그를 지정하면 좋은 점

캠페인 반응 데이터를 연락처 그룹으로 바꿀 수 있어요. 수신자를 행동별로 나누면 관심 있는 대상을 파악하고, 후속 연락을 간단하게 하고, 반복되는 연락처 관리 작업을 줄일 수 있어요.

- 발송 후 세분화: 미리 태그 조건을 설정하지 않아도, 캠페인을 보낸 뒤에 연락처에 태그를 지정할 수 있어요.
- 자동 태그: 선택한 반응 조건에 해당하는 연락처에 앞으로도 자동으로 태그를 붙여요.
- 반응 기반 타기팅: 캠페인 이메일을 열거나 클릭한 연락처를 찾아 더 알맞은 후속 메시지를 보낼 수 있어요.
- 여러 태그 지원: 연락처에 태그를 여러 개 지정해 대상을 더 세밀하게 나눌 수 있어요.
- 간편한 연락처 관리: 개별 연락처 기록을 열지 않고 캠페인 통계에서 바로 반응 기반 태그를 관리해요.
- 태그 지정 기록 확인: 직접 지정한 태그는 태그 및 **일괄 작업** 화면에서 확인할 수 있어요.

## 캠페인 반응에 따라 직접 태그 지정하기

직접 태그 지정은 이미 발송한 이메일 캠페인에 반응한 연락처를 골라 태그를 하나 이상 지정하는 방법이에요. 캠페인 성과를 살펴본 뒤 연락처를 정리하거나, 후속 연락 대상을 고를 때 유용해요.

예를 들어 프로모션 이메일 캠페인의 성과를 확인한 뒤, 이메일을 연 연락처에는 `가을 캠페인 - 열림`, 링크를 클릭한 연락처에는 `가을 캠페인 - 클릭` 태그를 지정할 수 있어요.

### 반응 유형별로 연락처 선택하기

캠페인 통계는 수신자를 이메일에 반응한 방식별로 나눠 보여 줘요. 반응 분류를 선택하면 태그를 지정할 연락처를 쉽게 찾을 수 있어요. 주요 반응 분류는 다음과 같아요.

- **열림**: 이메일을 연 연락처
- **클릭됨**: 이메일에서 추적되는 링크를 클릭한 연락처
- 그 외 반응 분류: 캠페인 **통계** 화면에 표시되는 다른 수신자 목록

분류를 연 다음 연락처를 하나씩 선택하거나, 화면의 선택 옵션으로 여러 연락처를 한 번에 선택해 태그를 지정할 수 있어요.

### 여러 태그 지정하기

태그를 여러 개 지정하면 연락처를 한 가지 이상의 특징으로 나눌 수 있어요. 예를 들어 프로모션 링크를 클릭한 연락처에 `제품 A 관심`과 `10월 프로모션`을 함께 지정할 수 있어요. 하이퍼클래스에서는 한 번의 태그 지정 작업으로 여러 태그를 지정할 수 있어요.

{% hint style="warning" %}
중요: 연락처에 이미 있는 태그를 다시 지정해도 중복 태그가 생기지 않아요. 기존 태그는 그대로 유지돼요.
{% endhint %}

## 이후 상호작용 자동 태그

**Auto-Tag Future Interactions**(이후 상호작용 자동 태그)를 켜면, 자동 태그를 켠 뒤에 캠페인에 반응하는 연락처에 선택한 태그가 자동으로 붙어요. 캠페인 통계로 돌아와 태그 지정을 반복하지 않아도 반응 기반 대상 그룹이 계속 최신 상태로 유지돼요.

예를 들어 **열림** 분류에 자동 태그를 설정할 수 있어요. 이후 다른 연락처가 캠페인 이메일을 열면, 하이퍼클래스가 설정한 태그를 해당 연락처에 자동으로 지정해요.

### 자동 태그가 작동하는 방식

자동 태그는 발송을 마친 캠페인의 반응 분류별로 설정해요. 순서는 다음과 같아요.

1. 해당 캠페인의 반응 분류를 엽니다.
2. **전체** 연락처를 선택합니다.
3. 지정할 태그를 고릅니다.
4. **Auto-Tag Future Interactions**를 켭니다.

켜고 나면, 설정한 반응 조건에 해당하는 연락처가 새로 생길 때마다 선택한 태그가 자동으로 지정돼요.

{% hint style="warning" %}
중요: 자동 태그는 앞으로 일어날 반응을 위한 기능이에요. 이미 캠페인에 반응한 연락처에 태그를 지정하려면 직접 태그 지정을 사용하세요.
{% endhint %}

## 직접 태그 지정과 자동 태그 비교

| 구분 | 직접 태그 지정 | 자동 태그 |
| --- | --- | --- |
| 주요 목적 | 이미 반응한 연락처에 태그 지정 | 앞으로 반응할 연락처에 태그 지정 |
| 연락처 선택 | 특정 연락처 또는 선택 가능한 그룹 선택 | 반응 분류 안에서 전체 선택 |
| 태그 지정 방식 | 직접 실행 | 이후 반응이 있을 때 자동 실행 |
| 일괄 작업 표시 여부 | 직접 지정한 작업이 기록됨 | 이후 자동 태그는 일괄 작업으로 기록되지 않음 |
| 주로 쓰는 경우 | 기존 캠페인 반응 정리 | 반응 기반 태그를 계속 유지 |

### 이메일 캠페인 발송 전 태그와 발송 후 태그

이메일 캠페인을 보내기 전에 **Send or Schedule**(보내기 또는 예약) 페이지에서도 태그 옵션을 설정할 수 있어요. 이는 캠페인 **통계** 화면에서 태그를 지정하는 방법과는 별개예요.

- 발송 전: 캠페인을 준비하면서 **Send or Schedule** 페이지에서 태그를 설정해요.
- 발송 후: 캠페인 통계에서 기록된 반응을 바탕으로 수신자에게 태그를 지정하거나, 이후 반응에 대한 자동 태그를 설정해요.

캠페인을 준비하면서 태그를 만드는 방법은 [이메일 빌더: 보내기 또는 예약 페이지에서 새 태그 만들기](../email-builder-create-new-tags-in-the-send-or-schedule-page.md)를 참고하세요.

## 태그 지정 기록 확인하기

태그 작업 기록을 확인하면 연락처에 태그가 지정됐는지 확인할 수 있고, 직접 태그를 지정한 내역도 살펴볼 수 있어요. 연락처 그룹이 크거나 태그 지정에 문제가 있을 때 특히 도움이 돼요. 하이퍼클래스가 태그 지정 작업을 어디에 기록하는지 알아 두세요.

### 직접 태그 지정 기록

캠페인 통계에서 직접 실행한 태그 지정 작업은 하이퍼클래스의 태그 및 **일괄 작업** 기능에 기록돼요. 이 기록에서 직접 태그를 지정한 내역과 지원되는 일괄 작업의 상태를 확인할 수 있어요.

더 자세한 내용은 [연락처 및 스마트 리스트 일괄 작업](email-statistics.md)을 참고하세요.
### 자동 태그 기록

**Auto-Tag Future Interactions**로 태그가 지정된 연락처는 **일괄 작업** 기록에 별도 작업으로 나타나지 않아요.

자동 태그가 잘 적용됐는지 확인하려면 해당 캠페인의 반응 정보를 살펴보고, 연락처 기록에서 지정된 태그를 확인하세요.

## 캠페인 통계 태그 지정의 제한 사항

캠페인 통계 태그 지정의 제한 사항을 알아 두면 상황에 맞는 연락처 관리 방법을 고르고, 지원하지 않는 기능을 기대하는 일을 피할 수 있어요. 일부 제한은 캠페인 통계의 모든 작업이 아니라 자동 태그에만 적용돼요.

- 유효하지 않은 연락처: **Invalid**(유효하지 않음) 분류의 연락처에는 자동 태그를 사용할 수 없어요.
- **주문 상세** 목록: **주문 상세** 목록에는 자동 태그가 지원되지 않아요.
- 태그 제거: 캠페인 통계의 태그 지정 기능은 태그 추가만 지원해요. 기존 태그는 제거할 수 없어요.
- 일괄 작업 기록: 이후 자동 태그는 **일괄 작업**으로 기록되지 않아요.

기존 태그를 제거하려면 캠페인 통계의 태그 지정 화면이 아니라 다른 연락처 관리 도구를 사용하세요. 연락처 태그 관리에 대한 자세한 내용은 [여러 연락처에 태그 추가하기](../../02-연락처/일괄-작업/adding-tags-to-multiple-contacts.md)를 참고하세요.

## 캠페인 통계에서 연락처에 태그를 지정하는 방법

캠페인, 반응 분류, 태그 지정 방법을 정확히 골라야 원하는 연락처에 태그가 지정돼요. **통계** 화면에서 이미 반응한 연락처에 태그를 지정하거나, 앞으로의 반응에 대한 자동 태그를 켤 수 있어요.

### 1단계: 이메일 캠페인 통계 열기

먼저 수신자에게 태그를 지정할 발송 완료 이메일 캠페인을 찾아요.

1. 하이퍼클래스에서 **마케팅 > 이메일 캠페인**으로 이동합니다.
2. 확인할 이메일 캠페인을 찾습니다.
3. 캠페인 옆의 점 세 개 메뉴를 클릭합니다.
4. **통계**를 선택합니다.

   ![이메일 캠페인의 점 세 개 메뉴에서 통계 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083292841/original/jIx24txUwTifkH87Pq6X_citDuGm4E0MYg.png?1791974763)

### 2단계: 캠페인 반응 데이터 불러오기

캠페인 통계에는 반응별 정보가 있어서, 이메일에 반응한 수신자를 구분할 수 있어요.

1. **통계** 화면에서 **더 보기**를 클릭해 수신자 반응 데이터를 더 불러옵니다.

   ![통계 화면에서 더 보기 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083292949/original/jLzDd20-s6QpjeKCyfi_4n5qA7662Uyo6w.png?1791974819)
2. **열림**, **클릭됨** 같은 반응 분류를 찾습니다.
3. 태그를 지정할 연락처에 해당하는 분류를 선택합니다.

### 3단계: 태그를 지정할 연락처 선택하기

수신자를 정확히 골라야 원하는 연락처에만 태그가 지정돼요.

1. 원하는 반응 분류를 엽니다.
2. 목록에 표시된 연락처를 확인합니다.
3. 태그를 지정할 연락처를 하나씩 선택하거나, 선택할 수 있는 그룹 전체를 선택하려면 **전체**를 사용합니다.
4. **태그 추가**를 클릭합니다.

   ![연락처를 선택한 뒤 태그 추가 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083293141/original/I3skanE6HMqZQDnTTRcMvRKYMZdHQgEVtw.png?1791974897)

### 4단계: 선택한 연락처에 태그 지정하기

태그를 쓰면 캠페인 반응에 따라 연락처를 구분할 수 있어요. 연락처 기록을 보거나 나중에 대상 그룹을 만들 때 팀원이 태그의 용도를 알 수 있도록, 태그 이름은 알아보기 쉽게 지어 주세요.

1. **태그 추가** 화면에서 지정할 태그를 입력하거나 선택합니다.
2. 필요하면 태그를 더 추가합니다.
3. 선택한 태그를 연락처에 적용합니다.

선택한 연락처 기록에 태그가 연결돼요.

### 5단계: 이후 상호작용 자동 태그 켜기 (선택)

자동 태그를 켜면, 이후 다른 연락처가 캠페인에 반응할 때 선택한 태그가 자동으로 지정돼서 반복 작업이 줄어요. 선택한 반응 분류를 기준으로 계속 태그를 지정하고 싶을 때 켜세요.

1. 자동 태그를 설정할 반응 분류를 엽니다.
2. **전체**를 선택합니다.
3. **태그 추가**를 클릭합니다.
4. 지정할 태그를 입력하거나 선택합니다.
5. **Auto-Tag Future Interactions** 토글을 켭니다.
6. 화면의 버튼으로 태그 지정을 마무리합니다.

이후 선택한 반응 조건에 해당하는 연락처에 하이퍼클래스가 설정한 태그를 자동으로 지정해요.

![Auto-Tag Future Interactions 토글을 켠 태그 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083293261/original/-aPhBrzGkfK0Qo7gIn2Vr_KSB3JT06BHfA.png?1791974951)

### 6단계: 태그 지정 결과 확인하기

태그가 정확히 지정됐는지 확인한 뒤에 다른 마케팅에 사용하세요.

1. **연락처**로 이동합니다.
2. 태그 지정 작업에 포함된 연락처를 엽니다.
3. 연락처에 지정된 태그를 확인합니다.
4. 직접 일괄 태그를 지정했다면, 해당하는 경우 **일괄 작업** 기록도 확인합니다.

자동 태그는 조건에 맞는 새 반응이 생긴 뒤에 연락처 기록을 확인하세요.

## 자주 묻는 질문

### 캠페인 통계에서 바로 태그를 제거할 수 있나요?
아니요. 캠페인 통계의 태그 지정 기능은 태그 추가만 지원해요. 태그를 제거하려면 하이퍼클래스의 다른 연락처 관리 도구를 사용하세요. 자세한 방법은 [여러 연락처에서 태그 제거하기](../../02-연락처/removing-contact-tags-from-multiple-contacts.md)를 참고하세요.

### 연락처가 이미 가지고 있는 태그를 지정하면 어떻게 되나요?
하이퍼클래스는 중복된 태그 지정을 무시해요. 같은 태그가 한 번 더 붙지 않아요.

### 캠페인 통계 태그 지정은 A/B 테스트 캠페인에서도 되나요?
네. A/B 테스트 캠페인에서도 태그 지정을 지원해요.

### 한 번에 여러 태그를 지정할 수 있나요?
네. **연락처**에서 태그를 지정할 때처럼, 선택한 연락처에 태그를 여러 개 지정할 수 있어요.

### 캠페인을 이미 보냈는데, 전에 반응한 연락처에도 태그를 지정할 수 있나요?
네. 캠페인 통계를 열고, 해당하는 반응 분류를 선택한 다음, 기존 연락처를 골라 원하는 태그를 직접 지정하세요.

### 자동으로 태그가 지정된 연락처도 일괄 작업에 나타나나요?
아니요. 이후 자동 태그는 **일괄 작업**으로 기록되지 않아요. 직접 태그를 지정한 작업은 일괄 태그 지정 기록에서 확인할 수 있어요.

### 캠페인을 보내기 전에 태그 조건을 만들어 두지 않았는데, 발송 후에 태그를 지정할 수 있나요?
네. 캠페인 통계에서는 이미 쌓인 반응 데이터를 바탕으로 태그를 지정할 수 있어요. 캠페인을 보내기 전에 태그 조건을 설정해 두지 않아도 돼요.

### 자동 태그를 사용할 수 없는 반응 분류가 있나요?
네. **Invalid** 연락처와 **주문 상세** 목록에는 자동 태그를 사용할 수 없어요.
