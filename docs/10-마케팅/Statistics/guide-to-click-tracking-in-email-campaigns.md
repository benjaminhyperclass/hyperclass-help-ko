# 이메일 캠페인 클릭 추적 가이드

이메일에 넣은 링크를 받는 사람이 클릭했는지 확인하는 클릭 추적의 기본 개념과 사용 방법을 안내해요. 클릭 추적이 작동하지 않는 경우도 함께 알아 두세요.

## 

## 클릭 추적이란?

클릭 추적은 받는 사람이 이메일 속 링크를 어떻게 이용하는지 보여 주는 기능이에요. 클릭 추적을 켜면 다음을 확인할 수 있어요.

- 이메일 안의 어떤 링크가 클릭되었는지
- 어떤 수신자가 내 콘텐츠에 반응하는지
- 링크별로 몇 번 클릭되었는지

## 기본 동작

기본적으로 클릭 추적은 꺼져 있어요. 이메일 캠페인에서 클릭 추적을 쓰려면 캠페인마다 직접 켜야 해요.

## 클릭 추적이 필요한 이유

1. 구독자 반응 파악: 구독자가 콘텐츠에 어떻게 반응하는지 알 수 있어요. 어떤 링크가 클릭되는지 보면 관심도를 가늠하고 콘텐츠를 그에 맞게 다듬을 수 있어요.
2. 링크 성과 분석: 구독자에게 가장 인기 있는 링크를 분석할 수 있어요. 이 결과로 이메일 레이아웃과 콘텐츠 전략을 반응이 좋은 요소 중심으로 개선할 수 있어요.

## 클릭 추적이 작동하지 않는 경우

다음 상황에서는 클릭 추적이 기대한 대로 작동하지 않을 수 있어요.

1. **클릭 성과** 추적을 켜지 않은 경우: 이메일을 보내거나 예약할 때 클릭 성과 추적을 켜지 않으면 클릭 추적 데이터가 수집되지 않아요.
2. 테스트 이메일: 테스트 이메일에는 클릭 추적이 적용되지 않아요. 클릭 추적이 제대로 되는지 확인하려면 선택한 연락처에게 테스트용 캠페인을 보내 보세요.
3. 트리거 링크: 현재 버전에서는 트리거 링크의 클릭 추적을 지원하지 않아요. 트리거 링크는 이미 중앙 시스템에서 리디렉션과 추적을 처리해요.
4. `http://` 또는 `https://`로 시작하지 않는 URL: 클릭 추적은 `http://` 또는 `https://`로 시작하는 URL에서만 작동해요. 이런 접두사가 없는 링크나 커스텀 값에 저장해 둔 링크는 추적할 수 없어요.5. 지원하지 않는 링크: 이메일 주소(`mailto:`) 클릭이나 앵커 링크는 추적하지 않아요. 추적하려면 캠페인의 모든 링크에 절대 경로를 사용하세요.
6. 시스템이 만든 링크: 미리보기 링크, 수신거부 링크, 시스템이 만든 제휴 링크는 추적하지 않아요.
7. 문법 오류나 오타가 있는 링크: 링크에 문법 오류나 오타가 있으면 링크가 깨져서 클릭을 정확히 추적할 수 없어요. 추적이 잘 되도록 모든 URL이 올바른지 미리 확인하세요.
8. 매직 링크: 링크에 커스텀 값이나 필드가 들어 있는 경우 링크가 작동하지 않을 수 있어요. 테스트용 이메일 캠페인을 보내 미리 확인하는 것이 좋아요.

## 자주 묻는 질문

### 모든 캠페인에서 클릭 추적을 쓸 수 있나요?

아니요. RSS 캠페인과 A/B 테스트 캠페인은 아직 클릭 추적을 지원하지 않아요. 현재 지원을 준비하고 있어요.

### 커스텀 값이나 트리거 링크도 추적되나요?

커스텀 값은 클릭 추적을 지원해요. 트리거 링크는 아직 지원하지 않아요.
### 워크플로우로 보낸 캠페인에도 이 지표가 나오나요?

아니요. 클릭 추적은 워크플로우로 실행하는 자동화 캠페인을 지원하지 않아요. 현재는 일반 이메일 마케팅 캠페인에서만 쓸 수 있어요.

### 모든 이메일에서 클릭 성과 결과를 볼 수 있나요?

아니요. 2024년 6월 13일 이전에 보낸 이메일이나 클릭 추적 옵션을 켜지 않고 보낸 이메일 캠페인은 **클릭 성과** 탭에 결과가 나타나지 않아요.
