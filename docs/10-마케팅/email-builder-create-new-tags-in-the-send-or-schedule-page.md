# 이메일 캠페인을 보내거나 예약할 때 새 태그 바로 만들기

이메일 캠페인의 자동화를 설정하는 중에 **Send or Schedule**(보내기 또는 예약) 화면에서 새 태그를 바로 만들 수 있어요. 태그를 미리 준비하지 않아도 그 자리에서 만들어 적용할 수 있어서 작업 시간이 줄어요.

## 이메일 캠페인에서 태그를 바로 만드는 기능이란?

태그는 연락처를 나누고, 특정 행동에 따라 자동화를 시작할 때 쓰는 도구예요. 이 기능을 쓰면 이메일 캠페인을 예약하거나 보내는 중에도 새 태그를 만들어 바로 적용할 수 있어요. 캠페인 작업을 멈추고 **태그** 화면으로 먼저 이동할 필요가 없어요.

![이메일 캠페인에서 새 태그를 바로 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049541545/original/iHaD1LU6lzAwk882smdaW7LwfpMK2W2OXQ.png?1751991006)

## 예약 중에 태그를 만들면 좋은 점

**Send or Schedule** 화면에서 바로 태그를 만들면 이메일 캠페인을 더 간편하게 관리할 수 있어요.

- 태그를 미리 만들어 둘 필요가 없어서 설정이 더 빠르고 쉬워요.
- 클릭 수와 화면 이동이 줄어서 캠페인을 더 간단하게 만들 수 있어요.
- 불필요한 단계가 없어서 예약 시간이 줄어요.
- 태그가 없어서 자동화를 시작하지 못할까 봐 걱정하지 않아도 돼요.
- 연락처를 더 정확하게 나눌 수 있어서 캠페인 타기팅과 후속 연락이 좋아져요.

## Send or Schedule 화면에서 태그 만들기

몇 단계만 거치면 예약 중에 태그를 만들 수 있어요.

1. 하이퍼클래스 계정에서 **이메일 마케팅**(Email Marketing)으로 이동하세요.
2. 새 이메일 캠페인을 만들거나, 보낼 준비 중인 기존 캠페인을 여세요.
3. **Send or Schedule** 화면으로 이동하세요.
4. **태그 추가**를 클릭하고 토글을 켜세요.
5. 이 태그로 자동화를 시작하려면 **Automate**(자동화)를 켜세요.
6. 태그 드롭다운에 새 태그 이름을 입력하세요.
7. **추가** 버튼을 클릭하세요. 새 태그가 만들어지고 캠페인에 바로 적용돼요.

![Send or Schedule 화면에서 태그를 추가하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049541544/original/wENA3BiWu008jJFC_4RLJe7YWhefgkSuwQ.png?1751991006)

## 알아두세요

{% hint style="info" %}
이 방법으로 만든 태그는 CRM의 전체 태그 목록에 자동으로 추가돼요. 이후 다른 캠페인과 자동화에서도 쓸 수 있어요.
{% endhint %}

{% hint style="warning" %}
철자와 이름 규칙이 일관되지 않으면 중복되거나 비슷한 이름의 태그가 의도치 않게 만들어질 수 있어요. 확정하기 전에 한 번 더 확인하세요.
{% endhint %}

## 자주 묻는 질문

### 캠페인을 예약한 뒤에도 태그를 편집하거나 제거할 수 있나요?
캠페인을 아직 보내지 않았다면 태그를 편집하거나 제거할 수 있어요. 캠페인을 보내고 나면 태그가 이미 적용된 상태라서 자동으로 제거할 수 없어요.

### 바로 만든 태그도 CRM 태그 목록에 표시되나요?
네. 예약 중에 만든 태그는 저장되어 CRM의 전체 태그 목록에 표시돼요. 나중에 다시 쓸 수 있어요.

### 항상 Automate를 켜야 하나요?
태그로 특정 자동화를 시작하려는 경우에만 켜면 돼요. 대상을 나누는 것이 목적이라면 **Automate**를 켜지 않고 태그만 추가해도 돼요.

### 새 태그를 한 번에 여러 개 추가할 수 있나요?
네. 캠페인 예약을 확정하기 전에 새 태그를 여러 개 만들어 적용할 수 있어요.

## 다음 단계

- 지금 진행 중인 캠페인을 살펴보고, 태그를 쓰면 연락처 분류와 후속 연락이 좋아질 부분을 찾아보세요.
- 다음 이메일 캠페인을 예약할 때 새 태그를 만들어 보세요.
- 새 태그를 쓰는 자동화를 설정하거나 수정해서 더 개인화된 소통과 참여를 이끌어 보세요.
