# 텍스트·이메일 스니펫 만들기와 사용하기

스니펫(Snippets)은 자주 쓰는 메시지를 저장해 두고 필요할 때마다 불러 쓰는 기능이에요. 텍스트 스니펫과 이메일 스니펫을 따로 만들고, 폴더로 정리하고, 연락처에게 메시지를 보낼 때 바로 넣을 수 있어요. 팀이 같은 내용으로 안내하면서 반복 작업도 줄일 수 있어요. 이 문서에서는 스니펫을 만들고, 정리하고, 사용하는 방법을 설명해요.

## 이 문서에서 배울 내용

- 텍스트 스니펫과 이메일 스니펫의 차이
- 현재 HiRise 스니펫 화면에서 재사용 콘텐츠를 만들고 정리하는 방법
- **대화**에서 스니펫을 사용하는 방법
- 워크플로우에서 SMS 재사용 콘텐츠가 동작하는 방식
- 메시지를 보내는 위치별 첨부파일 처리 방식

{% hint style="warning" %}
현재 **HiRise 스니펫** 화면은 서브 계정에 자동으로 켜져 있어요. **실험실**이나 베타 설정을 따로 켤 필요가 없어요. 기존 스니펫 목록 레이아웃은 더 이상 제공되지 않아요. **대화**를 통해 스니펫을 쓰는 사용자에게는 **대화 > View & manage conversation**(대화 보기 및 관리) 권한이 필요해요.
{% endhint %}

## 스니펫이란?

스니펫은 텍스트나 이메일 메시지에 쓰는 재사용 템플릿이에요. 같은 답변을 매번 입력하는 대신, 자주 쓰는 내용을 한 번 저장해 두고 같거나 비슷한 메시지가 필요할 때 넣으면 돼요.

스니펫은 텍스트 스니펫과 이메일 스니펫으로 나뉘어 있어요. **커스텀 값**이나 **트리거 링크** 같은 개인화 도구도 쓸 수 있어서, 재사용 메시지에 연락처나 상황에 맞는 정보를 담을 수 있어요.

스니펫은 보통 이런 곳에 써요.

- 예약 알림과 후속 안내
- 자주 묻는 질문에 대한 답변
- 고객 지원 답변
- 프로모션 메시지
- 운영시간과 연락처 정보
- 표준 안내 사항이나 다음 단계 안내
- 자주 다시 쓰는 이메일 내용

### 스니펫의 장점

스니펫을 쓰면 반복되는 커뮤니케이션이 빨라져요. 팀이 함께 보고, 정리하고, 업데이트할 수 있는 메시지 보관함도 생겨요.

- 시간 절약: 자주 보내는 내용을 다시 쓰거나 복사하지 않고 그대로 재사용해요.
- 일관성 향상: 팀원이 자주 생기는 상황마다 정해진 메시지를 쓸 수 있어요.
- 메시지 개인화: 지원되는 커스텀 값으로 연락처나 계정 정보를 자동으로 넣어요.
- 체계적인 관리: 폴더, 검색, 필터, 관리 기능으로 스니펫이 많아져도 정리할 수 있어요.
- 반복 작업 감소: 준비해 둔 내용을 지원되는 메시지 화면에 빠르게 넣어요.
- 최신 내용 유지: 비즈니스 정보나 메시지가 바뀌면 스니펫 화면에서 바로 수정해요.

## 사용 조건과 제한 사항

스니펫이 어디에 저장되는지, 어떤 권한이 필요한지, 채널마다 재사용 콘텐츠를 어떻게 처리하는지 알아 두면 만들고 보낼 때 헷갈리지 않아요.

시작하기 전에 확인하세요.

- 스니펫은 해당 서브 계정 안에서 관리해요.
- 현재 HiRise 스니펫 화면은 자동으로 제공돼요. **실험실** 설정은 필요 없어요.
- **대화**를 통해 스니펫을 쓰는 사용자에게는 **대화 > View & manage conversation**(대화 보기 및 관리) 권한이 필요해요.
- 재사용하려는 내용에 맞게 텍스트 스니펫과 이메일 스니펫 중 알맞은 유형을 고르세요.

다음 차이점도 기억해 두세요.

- 텍스트와 이메일: 텍스트 스니펫과 이메일 스니펫은 서로 다른 재사용 콘텐츠 유형이에요.
- 첨부파일: 이메일 템플릿, 캠페인, 워크플로우마다 첨부파일 처리 방식이 달라요.
- 워크플로우: 사용할 수 있는 재사용 콘텐츠 옵션은 설정하는 워크플로우 메시지 액션에 따라 달라요.
- RCS 스니펫: RCS는 형식과 리치 메시지 요건이 따로 있어요.
- WhatsApp 템플릿: WhatsApp 템플릿은 일반 스니펫과 달라요. 승인 절차와 사용 조건이 따로 있어요.

### 사용자에게 스니펫 접근 권한 주기

**대화** 안의 스니펫은 사용자의 대화 권한에 따라 보여요. **스니펫** 탭이나 메시지 작성창의 스니펫 옵션이 보이지 않으면 사용자의 역할을 확인해 보세요.

1. **서브 계정 보기**에서 **설정**을 클릭하세요.
2. **스태프 관리**를 선택하세요.
3. 권한을 바꿀 팀원을 선택하세요.
4. **Roles & Permissions**(역할 및 권한)를 여세요.
5. **대화**를 찾으세요.
6. **View & manage conversation**(대화 보기 및 관리)을 켜세요.
7. **저장**을 클릭하세요.

## 스니펫 만들기

스니펫을 만들어 두면 같은 종류의 메시지가 필요할 때마다 검색하고, 정리하고, 불러 쓸 수 있어요.

### 1단계: 스니펫 대시보드 열기

현재 HiRise 스니펫 대시보드는 **대화** 안에 있어요. 저장한 스니펫, 폴더, 검색, 필터, 만들기 기능을 여기서 쓸 수 있어요.

1. **서브 계정 보기**에서 **대화**를 클릭하세요.
2. **대화** 페이지 위쪽에서 **스니펫**을 선택하세요.

### 2단계: 스니펫 유형 고르기

텍스트 스니펫과 이메일 스니펫은 따로 만들어요. 사용할 채널에 맞게 콘텐츠를 구성할 수 있어요.

1. **+ New Snippet**(새 스니펫)을 클릭하세요.
2. **텍스트 스니펫 추가** 또는 **이메일 스니펫 추가**를 선택하세요.

![새 폴더와 새 스니펫 버튼, 텍스트 스니펫 추가·이메일 스니펫 추가 옵션이 보이는 HiRise 스니펫 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056243868/original/sK2i8lnlVoluWHqwbM9WF7TbQVsjM5sfhQ.png?1760702857=)

### 3단계: 스니펫 작성하고 개인화하기

이름을 알아보기 쉽게 짓고, 재사용할 내용과 지원되는 동적 값을 넣어 두면 다른 팀원도 스니펫을 이해하고 안전하게 쓸 수 있어요.

1. **설명이 되는 이름 입력** 칸에 스니펫 이름을 입력하세요.
2. 메시지 내용을 입력하세요.
3. 정보가 자동으로 채워지도록 하려면 지원되는 **커스텀 값**을 추가하세요.
4. 추적 가능한 링크가 필요하면 **트리거 링크**를 추가하세요.
5. 사용할 수 있는 미리보기를 확인하세요.
6. 필요하면 사용할 수 있는 테스트 옵션으로 확인하세요.
7. **저장**을 클릭하세요.

{% hint style="info" %}
이름 짓기 팁: 스니펫의 목적이 드러나게 이름을 지으세요. 예를 들어 *예약 알림*, *FAQ - 운영시간*, *신규 리드 소개*, *지원 - 비밀번호 재설정 안내*처럼요.
{% endhint %}

{% hint style="info" %}
SMS 비용 확인: SMS용 콘텐츠라면 보내기 전에 표시되는 글자 수, 세그먼트 수, 예상 비용을 확인하세요.
{% endhint %}

### 다른 경로로 스니펫 열기

**서브 계정 보기 > 마케팅 > 스니펫**에서도 스니펫을 열 수 있어요. **대화**의 스니펫 페이지는 현재 HiRise 레이아웃을 쓰고, 폴더·검색·필터·관리 기능에 가장 바로 접근할 수 있어요.

## 스니펫 정리하고 관리하기

스니펫 보관함을 정리해 두면 팀원이 승인된 내용을 빨리 찾을 수 있어요. 오래된 메시지나 중복된 메시지를 쓰는 일도 줄어요.

**대화 > 스니펫**에서 할 수 있는 일은 다음과 같아요.

- **검색**으로 이름이나 키워드로 스니펫 찾기
- 지원되는 유형별로 스니펫 필터링
- **새 폴더**를 클릭해 폴더 만들기
- 스니펫을 폴더로 옮기기
- 기존 스니펫 편집
- 스니펫을 복제해 변형본 만들기
- 더 이상 필요 없는 스니펫 삭제
- 같은 서브 계정의 다른 사용자와 화면을 공유할 때, 현재 페이지 URL로 지원되는 검색·페이지 이동 설정 유지

### 스니펫 하나씩 관리하기

점 세 개 메뉴에서는 스니펫 목록을 벗어나지 않고 자주 쓰는 관리 작업을 바로 할 수 있어요.

1. **대화 > 스니펫**으로 이동하세요.
2. 관리할 스니펫을 찾으세요.
3. 점 세 개 메뉴(⋮)를 클릭하세요.
4. 알맞은 옵션을 선택하세요.
   - **폴더로 이동**
   - **스니펫 편집**
   - **스니펫 복제**
   - **스니펫 삭제**

{% hint style="info" %}
정리 팁: 폴더는 영업, 지원, 예약, 결제, FAQ처럼 목적별로 스니펫을 묶을 때 편해요.
{% endhint %}

## 대화에서 스니펫 사용하기

**대화**에서 스니펫을 쓰면 준비된 메시지를 빠르게 불러올 수 있어요. 연락처에게 보내기 전에 내용을 확인하고 고칠 수도 있어요.

1. **서브 계정 보기**에서 **대화**를 클릭하세요.
2. 메시지를 보낼 연락처와의 대화를 여세요.
3. 알맞은 메시지 채널을 선택하세요.
4. 메시지 작성창에서 **스니펫** 아이콘을 클릭하세요.
5. 폴더를 둘러보거나 원하는 스니펫을 검색하세요.
6. 스니펫을 선택하세요.

   ![재사용 메시지 콘텐츠를 고르는 스니펫 선택 창이 보이는 대화 메시지 작성창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081372383/original/-u4VGvyjoGhCqJQXeRqtHysHub-KsrCjYg.png?1789854576)

7. 스니펫 내용이 메시지 작성창에 들어왔는지 확인하세요.
8. 메시지를 검토하고 필요한 부분을 고치세요.
9. 지원되는 동적 값이 제대로 표시되는지 확인하세요.
10. 메시지를 보내세요.

{% hint style="info" %}
보내기 전에: 스니펫을 선택해도 입력된 메시지는 잠기지 않아요. 연락처에게 보내기 전에 들어온 내용을 검토하고 수정할 수 있어요.
{% endhint %}

## 워크플로우에서 스니펫 사용하기

재사용 메시지는 자동 발송 메시지를 일관되게 유지하는 데도 도움이 돼요. 사용할 수 있는 템플릿 옵션은 설정하는 워크플로우 메시지 액션에 따라 달라요.

### Send SMS 액션에서 재사용 콘텐츠 사용하기

워크플로우의 **Send SMS**(SMS 전송) 액션에는 **Templates**(템플릿) 선택 기능이 있어요. 저장한 재사용 콘텐츠로 SMS 메시지를 채울 수 있어서, 같은 문구를 다시 입력하지 않고 자동 메시지를 통일할 수 있어요.

1. **서브 계정 보기**에서 **자동화**를 클릭하세요.
2. **워크플로우**를 선택하세요.
3. 기존 워크플로우를 열거나 새 워크플로우를 만드세요.
4. **Send SMS** 액션을 추가하거나 여세요.
5. Send SMS 설정에서 **Templates**를 찾으세요.
6. 사용할 저장된 재사용 메시지를 선택하세요.

   ![워크플로우 Send SMS 액션에서 Templates로 재사용 메시지 콘텐츠를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054024535/original/CrC7ZfU2-KCpi3hNdfuPUmKu_olJGbSDQA.gif?1758186871)

7. 메시지 필드에 들어온 내용을 검토하세요.
8. 필요하면 지원되는 **커스텀 값**을 추가하거나 수정하세요.
9. SMS 테스트 옵션으로 메시지를 확인하세요.
10. 워크플로우 액션을 저장하세요.
11. 게시하기 전에 워크플로우를 테스트하세요.

{% hint style="info" %}
이메일 보내기 워크플로우: **Send Email**(이메일 보내기) 액션에서도 재사용 이메일 템플릿을 쓸 수 있어요. 다만 워크플로우 이메일 템플릿은 편집, 복사, 동기화 방식이 달라요. 자동 이메일 내용을 설정할 때는 워크플로우 이메일 템플릿 전용 기능을 사용하세요.
{% endhint %}

## 스니펫과 첨부파일

스니펫 내용을 어디에 쓰느냐에 따라 첨부파일 처리 방식이 달라요. 차이를 알아 두면 받는 사람이 재사용 메시지 내용만이 아니라 의도한 파일까지 받게 할 수 있어요.

| 스니펫을 쓰는 곳 | 첨부파일 동작 |
| --- | --- |
| **이메일 템플릿** | 스니펫을 이메일 템플릿에 넣을 때 스니펫에 연결된 첨부파일은 자동으로 포함되지 않아요. 지원되는 메시지 내용만 들어가요. |
| 캠페인 이메일 | 스니펫을 캠페인 이메일에 넣으면 스니펫에 연결된 첨부파일이 함께 포함돼요. |
| **워크플로우** | 스니펫에 연결된 첨부파일은 워크플로우 이메일이나 SMS 메시지에 자동으로 추가되지 않아요. 필요한 파일은 워크플로우 액션에서 지원되는 기능으로 직접 추가하세요. |

{% hint style="info" %}
보내기 전에: 캠페인을 보내거나 자동 워크플로우를 게시하기 전에 최종 메시지와 첨부파일을 꼭 확인하세요.
{% endhint %}

## 자주 묻는 질문

### 텍스트 스니펫과 이메일 스니펫은 어떻게 다른가요?
텍스트 스니펫과 이메일 스니펫은 서로 다른 재사용 콘텐츠 유형이에요. 각각 텍스트 기반 커뮤니케이션과 이메일 커뮤니케이션용으로 만들어져 있어요. 재사용하려는 내용에 맞는 유형을 고르세요.

### 스니펫은 어디에서 만들고 관리하나요?
**서브 계정 보기 > 대화 > 스니펫**으로 이동하세요. **마케팅 > 스니펫**에서도 열 수 있어요.

### HiRise 스니펫 화면을 실험실에서 켜야 하나요?
아니요. HiRise 스니펫 페이지는 서브 계정에 자동으로 켜져 있어요. 기존 스니펫 레이아웃은 더 이상 제공되지 않아요.

### 스니펫을 폴더로 정리할 수 있나요?
네. 스니펫 페이지에서 **새 폴더**를 클릭한 다음, 관련 스니펫을 알맞은 폴더로 옮기세요.

### 기존 스니펫을 검색하거나 복제할 수 있나요?
네. **필드 검색**으로 이름이나 키워드로 스니펫을 찾을 수 있어요. 복제하려면 스니펫의 점 세 개 메뉴(⋮)를 열고 **스니펫 복제**를 선택하세요.

### 스니펫에 개인화 정보를 넣을 수 있나요?
네. 스니펫은 **커스텀 값**과 지원되는 다른 플레이스홀더를 쓸 수 있어서, 재사용 메시지에 동적 정보를 담을 수 있어요.

### 스니펫을 만들 수 있는 개수에 제한이 있나요?
하이퍼클래스 문서에는 현재 스니펫 개수에 정해진 제한이 없는 것으로 안내되어 있어요. 스니펫이 많아지면 폴더, 검색, 필터로 정리하세요.

### 대화에서 스니펫을 쓰려면 어떤 권한이 필요한가요?
**대화 > View & manage conversation**(대화 보기 및 관리) 권한이 필요해요.

### WhatsApp 템플릿은 일반 스니펫과 같은가요?
아니요. 일반 스니펫은 지원되는 대화에서 쓰는 재사용 콘텐츠예요. WhatsApp 템플릿은 WhatsApp 메시지용으로 승인 절차와 사용 조건이 따로 있어요.

### RCS 스니펫은 텍스트 스니펫과 같은가요?
아니요. RCS 스니펫은 RCS 전용 메시지 형식, 미디어, 액션, 대체 메시지를 지원해요. 만들고 보내는 과정도 따로 있어요.
