# 캠페인 설정 — 발신 주소(From Address)

캠페인 설정에서 발신 주소(From Address)를 구성하는 방법을 영상으로 안내하는 문서예요.

{% hint style="info" %}
이제 모든 계정에서 워크플로우를 쓸 수 있어요. 트리거와 캠페인으로 하던 일을 하나의 빌더에서 모두 할 수 있고, 그 외의 기능도 쓸 수 있어요. 워크플로우 빌더 개요 문서(워크플로우 빌더 개요)도 함께 확인해 보세요.
{% endhint %}
