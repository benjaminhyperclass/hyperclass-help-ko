# 퍼널과 웹사이트에서 브랜드 보드 사용하기

브랜드 보드를 쓰면 퍼널과 웹사이트 전반에 일관된 브랜드 가이드를 쉽게 적용할 수 있어요. 이 문서에서는 빌더 안에서 브랜드 보드의 색상을 불러와 적용하는 방법을 안내해요.

## 브랜드 보드 개요

브랜드 보드는 회사의 로고, 색상 팔레트, 타이포그래피를 하나로 묶어 둔 재사용 가능한 디자인 키트예요. 브랜드 보드를 만들어 두면 그 자산이 퍼널 빌더와 웹사이트 빌더 안에 나타나요. 원하는 스타일을 한 번의 클릭으로 적용할 수 있어서, 모든 웹사이트와 퍼널에서 브랜드를 일관되게 유지하기 쉬워요.

## 브랜드 보드를 사용하면 좋은 점

- 브랜드 일관성: 브랜드 보드 옵션을 사용하면 브랜드에 맞는 사이트를 쉽게 만들고 수정할 수 있어요.
- 시간 절약: 맞는 색상을 찾아다니거나 HEX 코드를 외울 필요가 없어요. 브랜드 보드가 워크플로우을 간소화해 줘요.
- 브랜드 팔레트 바로 사용: 승인된 브랜드 색상과 글꼴이 사이트 빌더 안에 나타나요. HEX 코드를 복사하거나 외부 브랜딩 가이드를 찾아볼 필요가 없어요.
- 한 곳에서 관리: 브랜드 보드를 한 번만 업데이트하면, 서브 계정 안 빌더의 모든 선택기에 업데이트된 색상, 글꼴, 로고가 반영돼요.

## 웹사이트와 퍼널에서 브랜드 보드 사용하기

{% hint style="info" %}
퍼널이나 웹사이트 빌더에서 사용하려면 브랜드 보드를 미리 만들어 두어야 해요. 만드는 방법은 '브랜드 보드 만들기' 문서를 참고하세요.
{% endhint %}

#### 1단계: 퍼널 또는 웹사이트 빌더로 이동하기

1. 메인 메뉴에서 **사이트**를 선택하세요.
2. 상단 메뉴에서 **퍼널** 탭 또는 **웹사이트** 탭을 클릭하세요.
3. 편집할 사이트를 선택하세요. 새 사이트를 만들려면 파란색 **+ New Funnel**(새 퍼널) 또는 **+ New Website**(새 웹사이트) 버튼을 클릭하세요.

![퍼널 또는 웹사이트 선택 화면](https://jumpshare.com/share/tSSj6eOn5gXpZDGDOHXT+/Screen+Shot+2026-09-24+at+19.40.12.png)

#### 2단계: 색상 팔레트 열기

1. 스타일을 바꿀 요소를 클릭하세요.
2. 오른쪽 사이드바에서 **Color Swatch**(색상 견본)를 클릭해 색상 선택기를 여세요.
3. 글자 색은 인라인 툴바에서도 색상 선택기를 열 수 있어요.

![오른쪽 사이드바의 색상 견본](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051653880/original/jJituTG-0f-3Y0r-fgrpKvqX0vIsElivoA.png?1755194558)

#### 3단계: 색상 선택기 사용하기

1. 색상 선택기 맨 윗줄에 브랜드 보드의 색상이 나타나요.
2. 적용할 브랜드 보드 색상을 클릭하세요.

{% hint style="info" %}
**기본**으로 설정된 브랜드 보드만 색상 선택기에 나타나요. 기본 브랜드 보드를 바꾸는 방법은 '기본 브랜드 보드 변경하기' 문서를 참고하세요.
{% endhint %}

![색상 선택기 윗줄에 표시된 브랜드 보드 색상](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051653940/original/O-ItumJSa-5wsyqdJ6_0ApazZRpjj3Bjaw.png?1755194693)

## 자주 묻는 질문

### 브랜드 보드를 업데이트하면 퍼널이나 웹사이트에 이미 적용된 색상도 자동으로 바뀌나요?
아니요. 브랜드 보드를 업데이트해도 이미 만든 퍼널이나 웹사이트 페이지에는 소급 적용되지 않아요.

### 새 프로젝트에 쓸 기본 브랜드 보드는 어떻게 설정하나요?
**마케팅 > 브랜드 보드**로 이동하세요. 사용할 보드 옆의 점 세 개 메뉴를 클릭하고 **기본값으로 설정**을 선택하세요. 그러면 선택한 브랜드 보드가 새 퍼널과 웹사이트에 기본으로 적용돼요. 이 주제에 대한 자세한 내용은 '기본 브랜드 보드 변경하기' 문서를 참고하세요.

### 브랜드 보드 색상이 색상 선택기에 안 보여요.
브랜드 보드 색상은 브랜드 보드가 실제로 선택되어 있을 때만 퍼널 또는 웹사이트 빌더에 나타나요. **Design**(디자인) 탭으로 가서 브랜드 보드가 적용되어 있는지 확인하세요.

### 한 서브 계정에 브랜드 보드를 여러 개 만들 수 있나요?
네. 원하는 만큼 만들 수 있어요. 다만 **기본**으로 설정할 수 있는 보드는 한 번에 하나뿐이에요.

### 브랜드 보드를 삭제하면 어떻게 되나요?
페이지에 이미 사용한 스타일이나 색상은 그대로 유지돼요. 다만 해당 브랜드 보드는 선택기에서 사라져요.
