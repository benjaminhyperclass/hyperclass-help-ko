# 제휴 지급 자주 묻는 질문

제휴 파트너에게 수수료를 지급할 때 자주 나오는 질문을 모았어요. 자동 지급 설정, 지급 방법, 지급 기한, 지급 상태를 확인할 때 참고하세요.

### 자동 지급 기능을 쓰려면 꼭 해야 할 설정이 뭔가요?

자동 지급 기능을 켜고 쓰려면 아래 두 가지가 꼭 필요해요.

1. PayPal 비즈니스 계정 연동
2. **Payout Methods**(지급 방법)에 제휴 파트너의 PayPal 계정 추가

PayPal 자동 지급을 쓰려면 다음 사항도 확인하세요.

1. PayPal 비즈니스 계정을 사용하세요.
2. 해당 계정에서 PayPal 지급(PayPal Payouts) 기능이 켜져 있는지 확인하세요.
3. 필요한 라이브 PayPal 자격 증명으로 PayPal 계정을 하이퍼클래스에 연결하세요.
4. PayPal로 지급하려는 제휴 파트너마다 유효한 PayPal 지급 방법이 추가되어 있는지 확인하세요.

### 제휴 파트너는 어떤 지급 방법을 쓸 수 있나요?

관리자가 켜 둔 방법에 따라 PayPal과 **계좌 이체**를 쓸 수 있어요.

사용할 수 있는 지급 방법을 설정하려면 다음 경로로 이동하세요.
**제휴 관리자 > 설정 > Affiliate Portal Settings**(제휴 포털 설정) **> Configure Payout Methods**(지급 방법 설정)

### 제휴 지급용으로 PayPal을 연동한 뒤 퍼널/웹사이트 주문 폼에서 PayPal 버튼을 숨기려면 어떻게 하나요?

주문 폼에서는 PayPal 버튼을 숨기고, 제휴 지급에는 계속 PayPal을 쓰려면 아래 순서대로 하세요.

1. PayPal 버튼을 숨기려는 퍼널 또는 웹사이트를 여세요.
2. **설정** 탭으로 이동하세요.
3. **Head 추적 코드** 섹션에 아래 코드를 붙여 넣으세요.

   ```
   <style>.paypal-content {
     display: none;
   }
   .order-form-v2 > div > .divider {
     display: none;
   }
   </style>
   ```
4. **저장**을 클릭하세요.

이렇게 하면 주문 폼에는 PayPal 옵션이 보이지 않아요. 제휴 지급용 PayPal 연동은 그대로 유지돼요.

### PayPal 자동 지급으로 제휴 파트너에게 지급할 수 있는 권한은 누구에게 있나요?

에이전시 관리자와 계정 관리자만 PayPal 자동 지급 방식으로 제휴 파트너에게 지급할 수 있어요.

### PayPal을 쓸 때 반복 결제 상품의 지급은 어떻게 처리되나요?

반복 결제 상품의 지급 건은 자동으로 만들어져요. 다만 PayPal로 결제를 마무리하려면 직접 **Pay Now**(지금 결제) 버튼을 클릭해야 해요. 보안과 인증 문제 때문에 하이퍼클래스가 지급을 자동으로 처리하지는 않아요.

### 제휴 지급은 언제 기한이 되나요?

기한은 캠페인 또는 **제휴 관리자** 설정에 지정한 지급 조건에 따라 달라져요.

지원하는 지급 조건은 다음과 같아요.

- NET-7
- NET-15
- NET-30
- NET-45
- NET-60
- NET-90

선택한 조건에 따라 월말로부터 며칠 뒤에 지급 기한이 되는지가 정해져요.

### PayPal 대신 은행으로 제휴 파트너에게 지급할 수 있나요?

네, 할 수 있어요. 지급 방법으로 **계좌 이체**를 켜 두면, 관리자가 원하는 은행이나 결제 업체로 제휴 파트너에게 지급한 뒤 하이퍼클래스에서 해당 지급 건을 지급 완료로 표시할 수 있어요.

### 판매가 환불되면 하이퍼클래스가 제휴 지급액을 자동으로 조정하나요?

아니요. 일회성 상품이나 구독의 환불은 수수료 지급 과정에서 자동으로 추적되지 않아요.

환불이나 차지백 가능 기간이 있다면 NET-30, NET-60처럼 그에 맞는 지급 조건을 쓰세요.

### 지급 상태는 각각 어떤 뜻인가요?

- **대기 중**: 지급 건이 만들어졌고 검토를 기다리는 상태예요.
- **Approved for Payout**(지급 승인): 지급이 승인되어 결제를 요청할 준비가 된 상태예요.
- **처리 중**: 지급을 요청했지만 결제 업체에서 아직 완료하지 않은 상태예요.
- **유료**: 제휴 파트너에게 지급이 끝나 지급 건이 확정된 상태예요.
- **Denied Payout**(지급 거부): 지급 건을 직접 거부한 상태예요.
- **실패**: 지급을 요청한 뒤 완료하지 못한 상태예요. 실패 사유가 있으면 함께 표시될 수 있어요.
- **실패**와 **Denied Payout**은 서로 다른 상태예요. **Denied Payout**은 지급 건을 직접 거부했을 때, **실패**는 요청한 지급 건을 완료하지 못했을 때 쓰여요.

### 일부 제휴 파트너는 PayPal로 지급 처리가 안 돼요.

PayPal 계정을 지급 방법으로 추가한 제휴 파트너에게만 지급을 처리할 수 있어요. 연결된 PayPal 계정이 없는 파트너는 오류 아이콘과 함께 **Add Account**(계정 추가) 옵션이 표시돼요.
