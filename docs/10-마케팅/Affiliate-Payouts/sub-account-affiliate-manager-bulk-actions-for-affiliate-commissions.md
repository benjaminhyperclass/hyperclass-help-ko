# 제휴 커미션 일괄 승인·거부·삭제하기

**제휴 관리자**(Affiliate Manager)의 **일괄 작업**을 쓰면 여러 제휴 커미션을 한 번에 승인하거나 거부하거나 삭제할 수 있어요. 일괄 작업은 제휴 프로필과 **제휴 관리자**의 대시보드, 두 곳에서 쓸 수 있어요.

## 커미션 일괄 작업이란?

커미션 일괄 작업을 쓰면 여러 커미션 기록을 한 번에 관리할 수 있어요. 제휴 프로필이나 전체 커미션 대시보드에서 바로 처리할 수 있어서, 커미션을 하나씩 승인하거나 삭제하는 반복 작업이 줄어들어요.

{% hint style="warning" %}
**거부됨** 상태의 커미션만 삭제할 수 있어요. 아직 거부되지 않은 커미션은 먼저 거부한 뒤에 삭제하세요.
{% endhint %}

## 커미션 일괄 작업의 장점

일괄 작업 도구를 쓰면 커미션을 더 빠르고 수월하게 관리할 수 있어요.

- 여러 커미션을 한 번에 승인하거나 거부할 수 있고, 삭제할 수 있는 거부됨 커미션은 한꺼번에 삭제할 수 있어요.
- 제휴 프로필과 메인 대시보드 모두에서 일괄 작업을 쓸 수 있어요.
- 커미션 검토나 지급 건수가 많을 때 시간을 아낄 수 있어요.
- 커미션을 상태(승인됨, 대기 중, 거부됨)나 캠페인별로 필터링할 수 있어요.
- 수작업과 반복 클릭이 줄어요.
- 팀과 에이전시가 제휴를 더 효율적으로 관리할 수 있어요.

## 제휴 프로필에서 일괄 작업 사용하기

일괄 작업을 쓰면 커미션 관리가 훨씬 간편해져요. 아래 순서대로 따라 해 보세요.

1. 서브 계정에서 **마케팅 > 제휴 관리자**로 이동하세요.

   ![제휴 관리자 메뉴로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048282254/original/y7jK-LFaCQjrM0JMz3kzCWCHbBESODU8hw.jpeg?1750051301)
2. **제휴** 섹션을 열고, 커미션을 관리할 제휴를 선택하세요.

   ![제휴 섹션에서 제휴 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048282479/original/lefMd1l8BaxsNIxEmyfOljQ7cc0gLozFyw.jpeg?1750051687)
3. 제휴 프로필에서 **Commissions**(커미션) 탭을 여세요.

   ![제휴 프로필의 커미션 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048282558/original/-tJ2_YKnljzI1Liq5yERcfYTdmty-m63_A.jpeg?1750051828)
4. 체크박스로 커미션을 하나 이상 선택하세요.
5. **일괄 작업** 버튼을 클릭하세요.
6. 원하는 작업을 선택하세요.

   - **승인**: 선택한 커미션 중 승인할 수 있는 커미션을 승인해요.
   - **거부**: 선택한 커미션 중 거부할 수 있는 커미션을 거부해요.
   - **삭제**: 선택한 **거부됨** 커미션을 영구 삭제해요.

{% hint style="warning" %}
커미션은 먼저 거부해야 삭제할 수 있어요.
{% endhint %}

## 대시보드에서 일괄 작업 사용하기

전체 커미션 대시보드에서도 같은 일괄 작업을 할 수 있어요. 모든 제휴의 최신 활동을 한꺼번에 검토할 때 편해요.

1. **제휴 관리자**의 **대시보드**로 이동하세요.

   ![제휴 관리자 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048282706/original/OBsDIovl82cp-1nmMq5wZlFzWKWOPRSfqQ.png?1750052130)
2. **Latest Updates**(최신 업데이트) 섹션까지 스크롤해서 최근 커미션 목록을 찾으세요.

   ![최신 업데이트 섹션의 최근 커미션 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048282715/original/_fMPs33uYQSXy-Cn9wustnduJ_eXhBQZJw.png?1750052162)
3. 체크박스로 커미션을 여러 개 선택하세요.
4. **일괄 작업**을 클릭하고, 선택한 커미션에 맞는 작업을 고르세요. 커미션을 삭제하려면 선택한 커미션이 모두 **거부됨** 상태인지 먼저 확인하세요.

## 상태와 캠페인으로 커미션 필터링하기

필터를 쓰면 커미션을 빠르게 좁혀서 바로 작업할 수 있어요. 제휴 프로그램 규모가 클 때 특히 유용해요.

- **상태** 필터로 커미션 상태(**대기 중**, **승인됨**, **거부됨** 등)에 따라 목록을 좁힐 수 있어요.

  ![상태 필터](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048280219/original/Hp-r148sUSBLVSII31cw6p6rllbsG83row.png?1750046696)
- **캠페인** 필터로 제휴 캠페인별 커미션만 모아 볼 수 있어요.

  ![캠페인 필터](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048280270/original/MWF-Q5J04IApwdedLmpotODMHKmVxOFMtg.png?1750046864)
- 필터를 함께 쓰면 더 정확하게 찾을 수 있어요.

## 자주 묻는 질문

### 일괄 작업을 되돌릴 수 있나요?
되돌릴 수 없어요. 일괄 작업을 실행하면 그대로 확정돼요. 확인하기 전에 선택한 항목을 꼭 다시 살펴보세요.

### 모든 사용자 권한에서 일괄 작업을 쓸 수 있나요?
제휴 커미션을 관리할 권한이 있는 사용자만 일괄 작업을 할 수 있어요.

### 서로 다른 제휴의 커미션에 한 번에 일괄 작업을 적용할 수 있나요?
네, 대시보드 화면에서는 여러 제휴의 커미션을 함께 선택할 수 있어요.

### 일괄 작업을 하면 제휴에게 이메일 알림이 가나요?
현재 일괄 작업은 제휴에게 알림을 자동으로 보내지 않아요.

### 한 번에 일괄 승인할 수 있는 커미션 수에 제한이 있나요?
정해진 제한은 없어요. 다만 건수가 많으면 처리하는 데 몇 초 걸릴 수 있어요.
