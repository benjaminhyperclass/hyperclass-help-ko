# WhatsApp 템플릿에 카운트다운 타이머 추가하기

WhatsApp 템플릿 버튼에 실시간 카운트다운 타이머를 붙이면 기간 한정 프로모션으로 바로 행동을 이끌어 낼 수 있어요. 이 문서에서는 타이머 유형(고정, 반복, 동적)을 고르는 방법과 템플릿에 타이머를 추가하는 방법을 안내해요.

## WhatsApp 템플릿의 카운트다운 타이머란?

이메일, 퍼널, 웹사이트에서 쓰던 하이퍼클래스 **카운트다운 타이머**(Countdown Timers)를 WhatsApp 템플릿 버튼에도 넣을 수 있어요. 수신자가 버튼을 누르면 타이머의 현재 상태에 따라 "활성" 링크나 "만료" 링크로 이동해요. 메시지마다 마감 시한이 생기므로 클릭률과 전환율을 높이는 데 도움이 돼요.

**고정** 타이머와 **반복** 타이머를 쓸 수 있어요. 연락처마다 WhatsApp 메시지가 발송되거나 전달되는 순간부터 시작하는 **동적** 타이머도 쓸 수 있어요.

## 카운트다운 타이머의 장점

- 긴급성과 전환율: 실시간으로 줄어드는 카운트다운이 즉각적인 행동과 구매를 유도해요.
- 다양한 타이머 유형: 프로모션 방식에 맞게 **고정**, **반복**, **동적** 타이머 중에서 고를 수 있어요.
- 활성/만료 링크 자동 연결: 만료 전에는 활성 페이지로, 만료 후에는 만료 페이지로 방문자를 자동으로 보내요.
- 워크플로우 분기: 타이머 버튼 클릭 여부에 따라 자동화를 나눌 수 있어요.

## 지원하는 카운트다운 타이머 유형

타이머 유형을 알맞게 고르면 시간대나 발송 시각이 달라도 메시지, 페이지, 자동화가 같은 기준으로 움직여요.

- **고정**: 특정 날짜와 시간에 끝나요. 블랙프라이데이처럼 마감이 정해진 일회성 캠페인에 알맞아요.
- **반복**: 일정에 따라 매일 또는 매주 반복돼요. 상시 진행하는 오퍼나 "주간 특가"에 잘 맞아요.
- **동적**: 연락처마다 개별 시간이 주어지고, 메시지가 **발송**되거나 **전달**되는 등 트리거 시점부터 시작해요. "이 메시지를 받은 후 12시간 안에 사용하세요"처럼 개인별 기간 한정 오퍼에 좋아요.

## WhatsApp 템플릿에 타이머 추가하기

아래 순서대로 템플릿에 타이머를 붙이고, 동적 타이머를 설정하고, 만료 전후 연결 링크까지 지정해 보세요.

### 1단계: WhatsApp 템플릿으로 이동하기

1. **설정 > WhatsApp**으로 이동하세요.
2. 상단 보조 메뉴에서 **템플릿** 탭을 선택하세요.

![WhatsApp 템플릿 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058115832/original/jIwBOvYmAxDtI2W5U-kvaMal1OwA1mAWow.png?1762876545)

### 2단계: 템플릿 열기

1. 파란색 **+ 템플릿 만들기** 버튼을 눌러 새 템플릿을 만들거나, 기존 템플릿을 선택해 편집하세요.
2. **상세 정보**에서 **Name**(이름), **카테고리**, **언어**, **머리글**, **Body**(본문), **Footer**(바닥글)를 입력하세요.

![템플릿 상세 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058115892/original/kmcJWIs2IlcWjDi5gRumBIEBIb_cgOKzwQ.png?1762876582)

### 3단계: 카운트다운 타이머 버튼 추가하기

**버튼** 섹션에서 **+ 버튼 추가**를 누르고, 드롭다운에서 **카운트다운 타이머**를 선택하세요.

![버튼 추가에서 카운트다운 타이머 선택](https://jumpshare.com/share/xPEOpHIhfYl7qKMFc5KM+/Screen+Shot+2026-09-24+at+17.08.45.png)

### 4단계: 타이머 선택 또는 만들기

**타이머** 드롭다운을 열어 기존 타이머를 고르거나 **+ Create New**(새로 만들기)를 누르세요.

![타이머 드롭다운 화면](https://jumpshare.com/share/Bc4RES4S1OekqbLUI72z+/Screenshot+2026-09-24+at+17.12.52.png)

### 5단계: 타이머 설정하기

타이머를 선택한 뒤 **타이머 URL** 아래의 **타이머 편집**을 누르세요. 타이머 설정 화면이 열리고, 아래 항목을 조정할 수 있어요.

- **Timer Type**(타이머 유형): **고정**, **반복**, **동적** 중에서 선택해요.
- **카운트다운 시간**: 지속 시간이나 정확한 종료 시각을 정해요.
- **타이머 시작 시점**: **동적** 타이머일 때 시작 기준이 되는 트리거를 골라요.
  - **WhatsApp message is sent**(WhatsApp 메시지가 발송될 때)
  - **WhatsApp message is delivered**(WhatsApp 메시지가 전달될 때)
- **Active link**(활성 링크): 만료 전에 연결할 오퍼, 결제, 예약 페이지예요.
- **Expired link**(만료 링크): 만료 후에 보여 줄 대체 페이지예요. 대기자 명단이나 다른 오퍼 페이지 등을 쓸 수 있어요.

![타이머 편집 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058116445/original/zo2vZ14tOHPQFd9BqIsVukBE5CsiWygyXA.png?1762876922)

### 6단계: 저장하고 미리보기 확인하기

1. **미리보기**에서 템플릿이 어떻게 보이는지 확인하세요.
2. 파란색 **만들기** 버튼을 눌러 WhatsApp 템플릿을 완성하세요.

![템플릿 미리보기와 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058116816/original/QbkiJ9cwRh1XV5Ued9gfvpHRIC3Td3A_Eg.png?1762877091)

## 자주 묻는 질문

### WhatsApp 메시지 하나에 타이머를 두 개 이상 쓸 수 있나요?
카운트다운 타이머 버튼은 최대 2개까지 추가할 수 있어요. **Visit Website**(웹사이트 방문)나 **Trackable Website**(추적 가능한 웹사이트) 버튼과 함께 쓸 수 있어요.

### 타이머가 만료되면 어떻게 되나요?
만료된 뒤에는 타이머 설정에 지정한 만료 오퍼 페이지로 이동해요.

### 타이머를 만든 뒤에도 수정할 수 있나요?
네, **타이머 편집**을 눌러 지속 시간, 스타일, 트리거를 언제든 바꿀 수 있어요.

### 동적 타이머는 사용자마다 다른 카운트다운이 표시되나요?
네, 연락처마다 트리거 시점(예: WhatsApp 메시지가 발송된 때)을 기준으로 각자 다른 카운트다운이 적용돼요.

### 타이머 URL 아래에 "No link found"(링크를 찾을 수 없음)가 표시돼요.
타이머에 아직 연결할 링크가 없다는 뜻이에요. **타이머 편집**을 누르고 동적 링크나 URL을 추가하세요.

### 활성 링크와 만료 링크는 무엇인가요?
활성 링크는 할인, 오퍼, 무료 등록 같은 내용이 담긴 오퍼 페이지의 링크예요. 만료 링크는 오퍼가 끝났을 때 사용자가 도착할 페이지의 링크예요. 오퍼 페이지에도 같은 타이머를 넣어 두세요. 그러면 타이머와 함께 자동으로 만료되고 만료 페이지로 이동해요.

### 카운트다운 타이머 버튼 클릭을 기준으로 워크플로우를 분기할 수 있나요?
네, **타이머 URL**에 **트리거 링크**를 쓰면 클릭이 추적돼요. 이 클릭 기록으로 워크플로우를 분기할 수 있어요.
