# 즐겨찾기로 자주 쓰는 템플릿 빠르게 찾기

**즐겨찾기** 기능을 쓰면 하이퍼클래스에서 자주 쓰는 템플릿을 빠르게 열 수 있어요. 템플릿을 즐겨찾기로 표시해 두면 작업 시간을 줄이고, 캠페인마다 같은 템플릿을 일관되게 쓸 수 있어요.

## 즐겨찾기 기능이란?

하이퍼클래스의 **템플릿 라이브러리**에서는 이메일, 퍼널, 웹사이트, 소셜 플래너 템플릿처럼 자주 쓰는 템플릿에 별 표시를 할 수 있어요. 그러면 매번 라이브러리 전체를 뒤지지 않아도 원하는 템플릿을 바로 찾아 다시 쓸 수 있어요.

## 즐겨찾기 기능의 장점

- 바로 접근: 가장 많이 쓰는 템플릿을 몇 번만 클릭해서 불러올 수 있어요.
- 간편한 탐색: 캠페인을 만들 때마다 큰 라이브러리를 훑어볼 필요가 없어요.
- 일관성: 효과가 좋았던 템플릿을 다시 써서 메시지를 통일할 수 있어요.
- 시간 절약: 찾는 시간이 줄어 작업 속도가 빨라져요.
- 나만의 작업 방식: 즐겨찾는 템플릿을 골라 나만의 템플릿 모음을 만들 수 있어요.
- 사용자별 즐겨찾기: 즐겨찾기는 내 사용자 프로필에 연결돼서 사람마다 따로 관리돼요.

## 템플릿을 즐겨찾기에 추가하기

1. **템플릿 라이브러리**에서 즐겨찾기에 추가할 템플릿 유형으로 이동해요. 예를 들면 이메일, 퍼널, 웹사이트, 소셜 플래너 템플릿이에요.
2. 목록을 스크롤하거나 검색해서 즐겨찾기에 추가할 템플릿을 찾아요.
3. 템플릿에 마우스를 올리고 오른쪽 위에 있는 별 아이콘을 클릭해요.
4. 별이 채워지면 즐겨찾기에 추가된 거예요.

이제 그 템플릿이 즐겨찾기 목록에 저장돼서 빠르게 찾을 수 있어요.

## 즐겨찾기한 템플릿 찾기

**즐겨찾기** 필터를 쓰면 별 표시한 템플릿만 모아 볼 수 있어요.

1. **템플릿 라이브러리**에서 해당 템플릿 섹션으로 돌아가요.
2. 템플릿 목록 위쪽 근처에서 **필터** 메뉴를 열어요.
3. **즐겨찾기** 필터를 클릭해요. 즐겨찾기한 템플릿만 바로 표시돼요.
4. 원하는 템플릿을 클릭하면 편집하거나 바로 적용할 수 있어요.

## 즐겨찾기 활용 팁

- 목록 최신 상태로 유지하기: 가장 자주 쓰는 템플릿이 목록에 있도록 주기적으로 확인하고 정리해요.
- 태그와 함께 쓰기: 태그와 카테고리를 함께 활용하면 템플릿을 더 체계적으로 정리할 수 있어요.
- 즐겨찾기 수 제한하기: 즐겨찾기를 너무 많이 추가하지 말고 간결하게 유지하면 더 빨리 찾을 수 있어요.
- 오래된 템플릿 정리하기: 더 이상 쓰지 않는 템플릿은 별 표시를 해제해서 목록을 깔끔하게 유지해요.

## 자주 묻는 질문

### 어떤 카테고리의 템플릿이든 즐겨찾기에 추가할 수 있나요?
네. 즐겨찾기 기능은 이메일, 퍼널, 웹사이트, 소셜 플래너 템플릿 등 여러 유형에서 쓸 수 있어요.

### 템플릿을 즐겨찾기에서 빼려면 어떻게 하나요?
템플릿에서 채워진 별 아이콘을 클릭하면 표시가 해제돼요. 별이 다시 테두리만 있는 모양으로 바뀌고, 즐겨찾기 목록에서도 빠져요.

### 팀원도 제 즐겨찾기를 볼 수 있나요?
아니요. 즐겨찾기는 사용자 프로필마다 따로 저장돼요. 팀이나 서브 계정끼리 공유되지 않아요.

### 즐겨찾기에 추가할 수 있는 템플릿 수에 제한이 있나요?
엄격한 제한은 없어요. 다만 빠르게 찾으려면 즐겨찾기 목록을 관리하기 쉬운 수준으로 유지하는 것이 좋아요.

### 즐겨찾기를 템플릿 유형별로 나눠서 볼 수 있나요?
네. 템플릿 섹션마다 따로 볼 수 있어요. 예를 들어 퍼널 템플릿처럼 유형을 선택한 다음 **즐겨찾기** 필터를 적용하면 돼요.
