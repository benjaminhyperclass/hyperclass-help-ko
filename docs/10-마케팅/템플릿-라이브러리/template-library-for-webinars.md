# 웨비나 템플릿으로 웨비나 빠르게 만들기

웨비나 템플릿을 쓰면 라이브 웨비나나 온디맨드 웨비나를 빠르게 설정할 수 있어요. 선택한 동영상과 폼이 미리 디자인된 웨비나 레이아웃에 자동으로 들어가서, 브랜드 일관성을 지키면서 설정 시간도 줄일 수 있어요.

## 웨비나 템플릿이란?

웨비나 템플릿은 웨비나용 레이아웃을 미리 디자인해 두고 다시 쓸 수 있게 한 기능이에요. 웨비나를 만들 때 선택한 동영상과 폼이 템플릿의 자리표시 영역을 자동으로 대체해요. 라이브든 온디맨드든 빠르게 설정하고, 웨비나마다 같은 브랜드 느낌을 유지할 수 있어요.

## 웨비나 템플릿의 주요 장점

웨비나 템플릿은 설정 시간을 줄이고, 여러 웨비나에서 통일된 모양과 느낌을 유지하도록 도와줘요. 참석자에게 전문적인 경험을 주면서 시간도 아낄 수 있어요.

- 빠른 웨비나 설정: 선택한 동영상과 폼이 템플릿에 자동으로 채워져서 몇 분 만에 웨비나를 열 수 있어요.
- 일관된 브랜딩: 다시 쓸 수 있고 수정도 가능한 템플릿으로 통일된 브랜드 경험을 유지해요.
- 유연한 템플릿 관리: 에이전시 관리자는 템플릿을 업로드하고 관리하며, 서브 계정별로 템플릿 공개 여부를 정할 수 있어요.
- 쉬운 맞춤 설정: 템플릿이나 빈 템플릿에서 시작해 필요에 맞게 내용을 바꿀 수 있어요.
- 수작업 감소: 자리표시 영역이 자동으로 바뀌어 반복 작업이 줄어요.

## 템플릿으로 웨비나 만들기

템플릿으로 웨비나를 만드는 방법은 간단해요. 직접 서식을 맞추지 않아도 일관된 디자인을 바로 적용할 수 있어서, 콘텐츠와 참석자 소통에 집중할 수 있어요.

1. **웨비나**(Webinars)로 이동해서 **Create Webinar**(웨비나 만들기)를 클릭하고, 라이브 또는 온디맨드를 선택하세요.

   ![웨비나 만들기 시작 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048215598/original/5hMpCrderWWYfBa9nANU_rtse6qHHnOV2Q.gif?1749816780)
2. **상세 정보**에서 웨비나 이름을 입력하세요.

   ![웨비나 상세 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048216064/original/5OL8okzFwpUOgDWfswgsgYxne_-AoqYwFA.png?1749817115)
3. **폼 선택** 단계에서 **웨비나 등록을 위한 폼을 선택하세요** 항목의 폼을 고르세요.

   ![웨비나 등록용 폼 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048216100/original/UnHpQnPb86H-4JJsPcAjZfxsPuyROgUSYA.png?1749817174)
4. **동영상 선택** 단계에서 **사전 녹화된 웨비나 선택** 항목의 동영상을 고르세요.

   ![사전 녹화된 웨비나 동영상 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048216171/original/0FjTZGZrVLKsTYV-ijGLY31Uh6wkBbM_Aw.png?1749817244)
5. 목록에서 웨비나 템플릿을 고르거나 빈 템플릿으로 시작하세요.
6. **계속하기**를 클릭하세요. 선택한 동영상과 폼이 템플릿의 자리표시 영역을 자동으로 대체해요.

   ![템플릿 선택 후 계속하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048216815/original/42CViOvIz-iLyIBOnH0w60f61fuxXxieqw.gif?1749817580)

## 웨비나 템플릿 관리하기 (에이전시 관리자 전용)

에이전시 관리자만 쓸 수 있어요. 에이전시 관리자는 웨비나 템플릿을 관리하는 추가 권한이 있어서, 서브 계정에 브랜딩과 요구 사항에 맞는 템플릿만 보이도록 할 수 있어요.

- **템플릿 라이브러리**로 이동한 뒤 **웨비나** 카테고리를 선택하세요.

  ![템플릿 라이브러리의 웨비나 카테고리 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048217050/original/x6qNAX_PsYIG1guX64_byUlT8jiLUF9_KA.gif?1749817727)
- 서브 계정에 템플릿을 숨기거나 표시하려면 각 템플릿 옆의 **공개 범위** 토글을 클릭하세요.

  ![템플릿별 공개 범위 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048217645/original/GInrAHGdHxZwp2IwVl6Gx--N6RxEK6vIxg.png?1749818174)
- 새 템플릿을 업로드하려면 **만들기**를 클릭한 뒤 새 웨비나 템플릿을 업로드하세요. 서브 계정별로 어떤 템플릿을 쓸 수 있는지 관리하면 사용 환경을 원하는 대로 꾸밀 수 있어요.

  ![새 웨비나 템플릿 업로드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048217355/original/zT0IuT_SwwzJZZc_OTSRNnwJQxc_y5lmgg.gif?1749818026)

{% hint style="info" %}
기본 템플릿과 빈 템플릿은 숨길 수 없어요.
{% endhint %}

## 웨비나 템플릿의 추가 장점

웨비나 템플릿이 어떻게 동작하는지 알면 더 잘 활용할 수 있어요. 이 기능은 비즈니스 전반에서 시간을 아끼고 웨비나 품질을 유지하도록 만들어졌어요.

- 자리표시 영역 자동 대체: 선택한 동영상과 폼이 선택한 템플릿의 자리표시 영역을 대체해요.
- 재사용 가능한 디자인: 여러 웨비나에 같은 템플릿을 써서 브랜딩과 레이아웃을 일관되게 유지할 수 있어요.
- 공개 범위 관리: 에이전시 관리자는 서브 계정이 접근하고 사용할 수 있는 템플릿을 관리할 수 있어요.
- 템플릿 라이브러리 통합: 웨비나 템플릿은 하나로 모인 **템플릿 라이브러리**에 있어서 찾고 관리하기 쉬워요.

## 자주 묻는 질문

### 웨비나 템플릿을 직접 만들 수 있나요?
네. 에이전시 관리자는 **템플릿 라이브러리**에서 새 웨비나 템플릿을 업로드할 수 있어요.

### 템플릿을 적용한 뒤에 동영상이나 폼을 바꿀 수 있나요?
네. 템플릿을 적용한 뒤에도 웨비나 설정에서 동영상이나 폼을 수정할 수 있어요.

### 기본 템플릿이나 빈 템플릿을 숨길 수 있나요?
아니요. 기본 템플릿과 빈 템플릿은 항상 보여요.

### 템플릿에 사용자 지정 스타일을 적용할 수 있나요?
네. 직접 만든 템플릿 디자인은 그대로 유지돼요. 동영상과 폼 자리표시 영역만 자동으로 바뀌어요.

### 서브 계정에서는 웨비나 템플릿을 기본으로 쓸 수 있나요?
네. 에이전시 관리자가 특정 템플릿을 서브 계정에 숨기지 않는 한 쓸 수 있어요.

### 템플릿을 쓰기 전에 미리 볼 수 있나요?
네. 템플릿을 선택하기 전에 **템플릿 라이브러리**에서 미리 볼 수 있어요.
