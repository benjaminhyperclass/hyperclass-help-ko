# 템플릿 라이브러리에서 유형과 태그 숨기기

관리자는 **템플릿 라이브러리**(Template Library)에서 서브 계정에 보여 줄 **유형**과 **태그**를 고를 수 있어요. 필요 없는 필터를 숨기면 서브 계정 사용자가 템플릿을 더 쉽게 찾을 수 있고, 라이브러리도 에이전시 브랜드에 맞게 깔끔하게 유지돼요. 에이전시 관리자만 쓸 수 있어요.

## 템플릿 라이브러리의 유형과 태그

**템플릿 라이브러리**에는 **유형**과 **태그**라는 필터가 있어요. 이 필터로 템플릿을 용도나 특징별로 나눌 수 있어요.

관리자는 이 필터의 공개 여부를 정할 수 있어요. 관련 없거나 내부용인 항목은 숨기고, 꼭 필요한 항목만 켜 두면 돼요.

필터를 숨기면 관리자 화면에는 그대로 보이고, 서브 계정 화면에서만 사라져요.

- 숨긴 항목은 서브 계정의 필터 목록에 나타나지 않아요.
- 숨긴 필터에 연결된 템플릿도 다른 필터나 이름으로 찾을 수 있어요.
- 관리자는 숨긴 항목을 참고나 점검용으로 표시된 상태로 계속 볼 수 있어요.

공개 여부를 조절하면 고객에게 간결한 템플릿 라이브러리를 보여 주고, 서브 계정 전체에서 브랜딩을 일관되게 유지할 수 있어요.

## 숨기기 기능의 장점

유형과 태그를 숨기면 템플릿 라이브러리를 정리하고, 고객에게 화이트라벨 환경을 제공할 수 있어요.

- 맞춤형 필터: 서브 계정마다 꼭 필요한 유형과 태그만 보여 줘서 라이브러리를 간단하게 관리할 수 있어요.
- 간편한 탐색: 필터 수를 줄이면 사용자가 템플릿을 더 빠르고 쉽게 찾을 수 있어요.
- 화이트라벨 지원: 하이퍼클래스 브랜드가 붙은 필터나 내부용 필터를 숨기면, 고객이 에이전시 브랜드로 일관된 환경을 쓸 수 있어요.
- 되돌릴 수 있는 설정: 숨긴 필터는 필요할 때 바로 다시 보이게 할 수 있어요. 데이터가 사라지거나 태그를 다시 지정할 필요도 없어요.
- 모든 요금제에서 사용 가능: 템플릿 라이브러리 권한이 있는 모든 관리자가 쓸 수 있어요.

## 필터 공개 여부 설정하기

관리자는 서브 계정의 **템플릿 라이브러리**에 보일 **유형**과 **태그**를 직접 정할 수 있어요. 아래 순서대로 설정 화면을 열고 공개 여부를 바꿔 보세요.

### 에이전시 보기로 전환

계정 전환 메뉴에서 서브 계정 대신 **에이전시 보기**를 선택하세요. 모든 서브 계정을 관리하는 관리자 수준 설정에 들어가려면 이 화면이 필요해요.

![에이전시 보기로 전환하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056571057/original/8Zsr2WWI6w_yihbldEswzGSTEbDsA572ug.png?1761132057)

### 템플릿 라이브러리 열기

1. **에이전시 대시보드**의 왼쪽 메뉴에서 **템플릿 라이브러리**를 선택하세요.

전체 템플릿 목록이 열리고, 템플릿 라이브러리 설정에도 들어갈 수 있어요.

![왼쪽 메뉴에서 템플릿 라이브러리를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056571122/original/rzTylLfnm7kgjNi1dy6yCxH9UX7vCNhemg.png?1761132089)

### 템플릿 라이브러리 설정 열기

1. **템플릿 라이브러리** 화면 오른쪽 위의 톱니바퀴 아이콘을 클릭하세요.

설정 패널이 열려요. 여기서 **카테고리**, **태그**, **유형**을 관리하고 서브 계정에 대한 공개 여부도 정할 수 있어요.

![톱니바퀴 아이콘으로 설정 패널을 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056571268/original/QaH2HQZvWHGpHVYM6GW354qGu2wjrzNabA.png?1761132119)

### 관리할 태그 또는 유형 선택

1. 설정 패널의 사이드바에서 편집하려는 항목에 따라 **태그** 또는 **유형**을 선택하세요.

태그는 템플릿을 설명하는 라벨이고, 유형은 템플릿을 용도나 형식별로 나누는 기준이에요. 이 화면에는 기존 필터가 모두 나오고, 각 필터의 생성일과 공개 여부 설정도 함께 보여요.

![사이드바에서 태그 또는 유형을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056571351/original/RT1FCTwsCeV3Zw9u2h_dZiE54x6XlXlwKA.png?1761132148)

### 공개 여부 바꾸기

1. 목록 오른쪽의 **숨기기** 열을 찾으세요.
2. 각 태그나 유형 옆의 전환 스위치로 공개 여부를 바꾸세요.
   - 스위치를 **끄면** 모든 서브 계정 화면에서 해당 필터가 숨겨져요.
   - 스위치를 **켜면** 해당 필터가 다시 보여요. 변경 내용은 바로 적용되고, 연결된 모든 서브 계정에 반영돼요.

{% hint style="info" %}
라이브러리 정리 팁: 내부용 필터, 하이퍼클래스 브랜드가 붙은 필터, 잘 쓰지 않는 필터부터 숨기면 서브 계정 사용자의 화면이 간단해져요. 숨긴 필터는 언제든 이 화면으로 돌아와 스위치를 다시 켜면 복원할 수 있어요.
{% endhint %}

![숨기기 열에서 필터 공개 여부를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056571519/original/BNzB4qvDgQl5QnQoLgPukbNLG9H5fGo99g.png?1761132191)

{% hint style="info" %}
작업 공간 설정에 따라 공개 여부 스위치의 이름이나 아이콘이 다르게 보일 수 있어요. 그래도 목록의 각 태그와 유형 옆에는 항상 표시돼요.
{% endhint %}

## 자주 묻는 질문

### 필터 공개 여부는 누가 관리할 수 있나요?
관리자 권한이나 템플릿 라이브러리 관리 권한이 있는 사용자라면 누구나 관리할 수 있어요.

### 필터를 숨기면 템플릿에서 필터가 삭제되나요?
아니요. 숨기기는 필터 패널에 보이는 여부만 바꿔요. 템플릿에 연결된 필터 정보는 그대로 남아 있어요.

### 숨긴 필터를 나중에 다시 보이게 할 수 있나요?
네. 언제든 다시 보이게 할 수 있어요.

### 검색 결과에도 영향이 있나요?
아니요. 템플릿은 이름과 카테고리로 계속 검색할 수 있어요.

### 모든 요금제에서 쓸 수 있나요?
네. 템플릿 라이브러리 기능을 제공하는 모든 요금제에 공개 여부 설정이 포함돼 있어요.
