# 확장된 템플릿 라이브러리 권한 (스타터·무제한 플랜 관리자용)

$97 **스타터** 플랜과 $297 **무제한** 플랜의 관리자도 이제 **템플릿 라이브러리**(Template Library)를 쓸 수 있어요. 이 문서에서는 새로 열린 권한과, 템플릿이나 카테고리를 숨겨 에이전시의 브랜드를 지키는 방법을 안내해요. 에이전시 관리자만 쓸 수 있는 기능이에요.

## 확장된 템플릿 라이브러리 관리자 권한이란?

그동안 **템플릿 라이브러리** 관리자 권한은 $497 플랜 사용자만 가질 수 있었어요. 이제 $97 **스타터** 플랜과 $297 **무제한** 플랜의 관리자도 **Agency View**(에이전시 보기)에서 **템플릿 라이브러리**에 들어갈 수 있어요. 여기서 바로 쓸 수 있는 자료를 둘러보고, 템플릿이나 카테고리를 통째로 숨길 수 있어요. 프리미엄 제작 도구는 미리 볼 수 있고, 업그레이드 안내가 함께 표시돼요.

## 확장된 권한으로 할 수 있는 일

- **템플릿 둘러보기**: $97, $297 플랜 관리자도 **템플릿 라이브러리**를 둘러볼 수 있어요.
- 템플릿 숨기기: 특정 템플릿이 서브 계정의 **템플릿 라이브러리**에 나타나지 않게 해요.
- 카테고리 숨기기: 카테고리 전체가 **템플릿 라이브러리**에 나타나지 않게 해요.

## 개별 템플릿 숨기기

템플릿을 숨기면 서브 계정 어디에서도 그 템플릿이 보이지 않아요. 에이전시의 브랜드나 전문 분야에 맞지 않는 템플릿을 정리할 때 쓰세요.

1. 에이전시 화면에서 **템플릿 라이브러리**로 이동해요.
2. 숨기려는 템플릿에 마우스를 올려요.
3. **숨기기**를 클릭해요.
4. 템플릿에 회색 **숨김** 배지가 표시되면 적용된 거예요.

```
숨긴 템플릿은 이후 관리를 위해 에이전시 관리자에게는 계속 보여요.
```

## 카테고리 전체 숨기기

폴더 안의 템플릿이 모두 에이전시 서비스와 맞지 않을 때는 카테고리 단위로 숨기는 편이 편해요.

1. **템플릿 라이브러리** 안에서 톱니바퀴 아이콘(**설정**)을 클릭해요.
2. 퍼널 같은 종류를 선택한 뒤 **카테고리**를 선택해요.
3. 숨기려는 카테고리 옆의 **숨기기** 토글을 켜요.
4. 그 카테고리 안의 모든 템플릿이 모든 서브 계정에서 보이지 않아요.

## 자주 묻는 질문

### $97, $297 플랜 관리자도 새 템플릿을 만들 수 있나요?
아직은 안 돼요. 템플릿을 만들려면 $497 Pro 플랜이 필요해요. 지금은 템플릿을 둘러보고 숨기는 것까지 할 수 있어요.

### 템플릿을 숨기면 기존 서브 계정에서도 사라지나요?
네. 템플릿이나 카테고리를 숨기면 현재 서브 계정과 앞으로 만들 서브 계정 모두에서 자동으로 사라져요.

### 카테고리를 숨기면 제가 수정한 템플릿도 같이 숨겨지나요?
수정한 템플릿이 숨긴 카테고리에만 들어 있다면 함께 숨겨져요. 보이는 카테고리에도 함께 배정된 템플릿은 계속 보여요.

### 숨긴 항목을 나중에 다시 보이게 할 수 있나요?
네. **설정 > 카테고리**로 돌아가 토글을 끄거나, 템플릿에 마우스를 올려 **Unhide**(숨김 해제)를 클릭하세요. 변경 내용은 바로 적용돼요.

### 숨기면 에이전시에서도 그 템플릿을 쓸 수 없나요?
아니요. 숨긴 항목도 에이전시 관리자에게는 계속 보여서, 내부에서 복제하거나 편집할 수 있어요.

### 한꺼번에 숨기는 방법이 있나요?
카테고리 숨기기가 가장 빠른 방법이에요. 카테고리 안에서 템플릿을 여러 개 선택한 뒤 **숨기기**를 켜는 방법도 있어요.

### 고객에게 하이퍼클래스가 아닌 다른 브랜드가 보이나요?
다른 브랜드의 자료가 담긴 템플릿을 숨기면 고객 화면에서 그런 자료가 보이지 않아요. 에이전시의 화이트라벨 환경을 지킬 수 있어요.

### 에이전시 사용자(관리자가 아닌 경우)도 라이브러리를 쓸 수 있나요?
$97, $297 플랜에서는 에이전시 관리자만 라이브러리 권한이 있어요. 일반 사용자와 서브 계정 역할은 템플릿을 보거나 편집할 수 없어요.
