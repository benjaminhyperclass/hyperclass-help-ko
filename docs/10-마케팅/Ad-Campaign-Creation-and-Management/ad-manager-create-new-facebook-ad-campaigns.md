# 광고 관리자에서 Facebook 광고 캠페인 만들기

하이퍼클래스 **광고 관리자**(Ad Manager)에서 Facebook과 Instagram 광고를 바로 시작할 수 있어요. 이 문서에서는 Meta 캠페인을 만드는 방법과 캠페인 → 광고 세트 → 광고 구조를 설명해요. 여러 변형을 관리하고 안심하고 게시하는 방법도 함께 안내해요.

## 하이퍼클래스 광고 관리자의 Facebook 캠페인 만들기란?

{% hint style="info" %}
시작하기 전에 Facebook 연동이 연결되어 있는지 확인하세요. 자세한 내용은 "광고 관리자와 Facebook 연결하기" 문서를 참고하세요.
{% endhint %}

하이퍼클래스에서 Facebook 캠페인을 만들면 CRM을 벗어나지 않고 Meta 광고를 만들어 시작할 수 있어요. 목표를 고르고, 오디언스와 예산을 정하고, 크리에이티브를 추가한 뒤 게시하면 돼요. 화면은 Meta의 구조를 그대로 따르면서 자주 하는 작업은 더 간단하게 만들었어요.

하이퍼클래스에서 만든 Meta 캠페인은 연결된 Meta 광고 계정으로 전송돼요. 게시와 검토는 Meta의 정책을 따라요.

---

## Facebook 캠페인 만들기의 장점

- 속도: 하이퍼클래스 한곳에서 캠페인, 광고 세트, 광고를 만들 수 있어요.
- 명확성: Meta의 계층 구조대로 정리해 테스트와 리포팅을 깔끔하게 관리할 수 있어요.
- 확장성: 광고 세트 10개, 광고 10개까지 추가해 처음부터 다시 만들지 않고 테스트를 늘릴 수 있어요.
- 일관성: 오디언스, 크리에이티브, 폼을 재사용해 브랜드와 데이터 품질을 유지할 수 있어요.
- 제어: 각 단계의 **⋮** 메뉴에서 게시, 일시중지, 복제, 편집을 간단히 할 수 있어요.

---

## Meta 비즈니스 포트폴리오 만들기

Facebook을 하이퍼클래스 광고 관리자에 연결하려면 Meta 비즈니스 포트폴리오(이전 이름: Business Manager), Meta 광고 계정, Facebook 페이지가 필요해요.

Meta 비즈니스 포트폴리오가 없다면 Meta 공식 안내에 따라 만들어 주세요. 비즈니스 포트폴리오 생성 과정은 Meta가 관리하고, 설정 화면은 바뀔 수 있어요. 최신 절차는 [Meta Business Suite에서 비즈니스 포트폴리오 만들기](https://business.facebook.com/business/help/1710077379203657?id=180505742745347&utm_source=chatgpt.com)를 참고하세요.

포트폴리오를 만든 뒤에는 필요한 Facebook 페이지와 광고 계정이 추가되어 있는지, 적절한 접근 권한이 있는지 확인하세요.

---

## 시작하기 전에 확인할 사항

1. 에이전시 화면의 **재판매**에서 요금 모델을 선택하는 것이 광고 관리자를 시작하는 첫 단계예요. 에이전시 관리자만 할 수 있어요. 다음 단계로 넘어가기 전에 서브 계정에 제공할 광고 관리자 재판매 오퍼를 먼저 설정해 두는 것이 좋아요.

2. 서브 계정마다 광고 관리자를 켜거나 끌 수 있어요. 켜 두면 서브 계정의 **마케팅** 아래에 **광고 관리자** 탭이 보여요. 모든 서브 계정에서 기본으로 켜져 있어요.

3. 에이전시가 서브 계정에서 광고 관리자를 켤 수 있어요. 사용자별로는 **직원**의 **Permissions**(권한)에서 광고 관리자 권한을 켜면 돼요.

4. 광고 관리자의 첫 단계는 Meta 광고 계정과 여러 Facebook 페이지를 연결하는 거예요. 하이퍼클래스 앱을 통해 Facebook 계정에 로그인해서 연결해요. 광고 관리자에서는 Facebook 페이지를 여러 개, 광고 계정을 1개 연결할 수 있어요.

![광고 관리자에 Meta 광고 계정과 Facebook 페이지를 연결하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037532285/original/5ivQOSgleO5reIeXFTHE5mSU7HxMF2EqfQ.jpeg?1733082217)

## 캠페인 구조 (Meta)

하이퍼클래스 광고 관리자의 Meta 캠페인은 **캠페인** → **Ad Set**(광고 세트) → **광고**의 3단계 구조예요.

캠페인을 만들면 시작하기 쉽도록 광고 세트 1개와 광고 1개가 자동으로 만들어져요.

한도:

- 캠페인당 광고 세트 최대 10개
- 광고 세트당 광고 최대 10개

## 광고 관리자에서 Meta 캠페인 만들기

아래 순서는 하이퍼클래스 화면의 입력 순서와 같아요. 단계별로 따라 한 뒤, 게시 전에 설정을 검토하면 정책에 맞는 깔끔한 상태로 제출할 수 있어요.

### 1단계: 캠페인 만들기

1. **마케팅** > **광고 관리자**로 이동하세요.
2. 광고 관리자 홈 화면에서 **캠페인 만들기** 버튼을 클릭하세요. 다음 화면에서 광고 캠페인을 게시할 플랫폼으로 **Facebook**을 선택하세요.
3. **다음**을 클릭하면 **처음부터 시작**하거나 **광고 관리자 템플릿**을 사용해 Facebook 광고 캠페인을 만들 수 있어요. 템플릿으로 캠페인을 만드는 방법은 "템플릿으로 광고 캠페인 만들기" 문서를 참고하세요.
4. **다음**을 클릭해 광고 캠페인 설정을 시작하세요.

![캠페인 만들기 시작 화면 녹화](https://jumpshare.com/share/EKGGmI81uFaxri6wDbIB+/GIF+Recording+2026-02-10+at+8.26.00+PM.gif)

### 2단계: 캠페인 목표와 특별 광고 카테고리 선택

1. **목표**: 캠페인 목표는 광고로 이루려는 결과예요. **리드 생성** 목표는 Facebook 폼 연동으로 이뤄져요. 새 폼을 만들거나 기존 폼을 사용할 수 있어요. 자세한 내용은 "광고 관리자에서 Facebook 폼 만들기" 문서를 참고하세요.
2. **Special Ad Category**(특별 광고 카테고리): 광고가 특별 카테고리에 해당하면 목록에서 알맞은 카테고리를 선택하세요. 그래야 현지 법규를 지키고 캠페인 검토가 원활해요. 해당하지 않으면 **NOT APPLICABLE**(해당 없음)을 선택하세요.

{% hint style="info" %}
Facebook의 특별 광고 카테고리는 타겟팅 옵션이 제한되어 있고, 아래 오디언스는 쓸 수 없어요.

- **유사 오디언스**: 특별 광고 카테고리 광고에서는 사용할 수 없어요. 대신 Facebook 밖에서 유사 오디언스를 만든 뒤 커스텀 오디언스로 업로드할 수 있어요.
- 저장된 오디언스: 특별 광고 카테고리 광고에서는 사용할 수 없어요.
- 우편번호: 특별 광고 카테고리 광고에서는 사용할 수 없어요. 특정 지역을 선택하면 최소 15마일 또는 25km 반경이 포함돼요.
- **상세 타겟팅**: 대부분의 인구통계, 행동, 관심사 옵션을 쓸 수 없어요.

그 밖의 제한 사항은 다음과 같아요.

- 연령은 18~65세 이상으로 고정되며 편집할 수 없어요.
- 성별은 모든 성별만 포함되며 편집할 수 없어요.
{% endhint %}

### 3단계: 광고 세트 설정

{% hint style="info" %}
캠페인당 광고 세트를 최대 10개까지 추가할 수 있어요.
{% endhint %}

1. **Ad Set**(광고 세트)의 **이름**을 입력하세요.

   ![광고 세트 이름 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064608054/original/CJI1QxUDe7-KerSpWdPZZaKeNykUJ_qGQw.png?1770738388)
2. **Facebook 페이지 선택**에서 페이지를 고르세요. 광고에서는 Facebook 페이지나 Instagram 계정이 내 비즈니스를 대표해요.
3. **Instagram 계정 선택**에서 광고에 사용할 Instagram 계정을 고르세요. 연결된 계정이 없으면 광고에 Facebook 페이지의 이름, 프로필 사진, 설명, 팔로워 수가 사용돼요.

   ![Instagram 계정 선택 화면](https://jumpshare.com/share/kH3NTAhO8l5SMid1MzXg+/Screen+Shot+2026-02-10+at+8.50.42+PM.png)
4. **Select Placement**(게재 위치 선택): 광고를 노출할 수 있는 위치를 게재 위치라고 해요. 자동 게재 위치를 쓰면 배정된 예산에 맞춰 기본 게재 위치 전체에서 가장 좋은 결과를 얻도록 자동으로 조정하고, 비용을 관리하는 데도 도움이 돼요. 수동 게재 위치를 쓰면 브랜드 안전과 최적화를 위해 광고를 보여 줄 위치를 직접 고를 수 있어요.

   수동 게재 위치 선택 옵션은 토글을 켜면 나타나요.

   {% hint style="info" %}
   선택할 수 있는 수동 게재 위치는 Meta가 현재 지원하는 위치에 따라 달라요. Instagram 탐색 탭 피드는 더 이상 게재 위치로 선택할 수 없어요. 이전에 Instagram 탐색 탭 피드를 포함했던 기존 초안 캠페인은 광고 세트를 저장할 때 해당 게재 위치가 자동으로 제거돼요. 따로 할 일은 없어요.
   {% endhint %}

   ![게재 위치 선택 화면 녹화](https://jumpshare.com/share/ju0gSrK3wu4Yiq4BhERA+/GIF+Recording+2026-02-10+at+8.52.59+PM.gif)
5. **Choose Budget**(예산 선택): 이 광고 캠페인에 쓰려는 평균 금액을 **daily**(일일 예산) 또는 **lifetime**(전체 기간 예산) 중에서 골라 정하세요. 비용은 Meta 광고 계정에 등록된 카드로 결제돼요. 전체 기간 예산은 캠페인을 일시중지하고 편집해서 늘리거나 줄일 수 있어요.

   전체 기간 예산은 날짜 선택기로 시작·종료 날짜와 시간을 정할 수 있어요.

   {% hint style="info" %}
   표시되는 통화는 연결된 광고 계정에 설정된 통화예요. 시작·종료 날짜의 시간대는 캠페인을 만드는 사용자가 있는 시간대예요.
   {% endhint %}

   ![예산 선택 화면 녹화](https://jumpshare.com/share/vsUHcoeZiYGHdahFLAfc+/GIF+Recording+2026-02-10+at+9.00.50+PM.gif)
6. **오디언스 제어**를 설정하세요.

   **Geographic Location**(지역): 특정 지역에서만 캠페인을 실행하도록 조정하거나, 특정 국가·주에서 일부 지역을 제외할 수 있어요.

   {% hint style="info" %}
   광고를 보여 줄 지역을 넓게 잡으면 결과가 좋아질 수 있어요. 예를 들어 도시 여러 곳 대신 국가를 추가하는 방식이에요.
   {% endhint %}

   ![지역 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064607095/original/pnY7aepWgtpomIJEbsS9JIEOPJjH53ebVQ.png?1770738055)

   **대상 오디언스**의 선택 설정으로 오디언스 범위를 좁힐 수 있어요. 각 옵션마다 더 구체적으로 설정할 수 있어요.

   {% hint style="info" %}
   **대상 오디언스** 섹션의 자세한 내용은 [광고 관리자 - 오디언스 제어](ad-manager-audience-controls.md) 문서를 참고하세요.
   {% endhint %}

   ![대상 오디언스 선택 설정 화면](https://jumpshare.com/share/llwMF0cD0prMdRX06f67+/Screen+Shot+2026-02-10+at+9.11.44+PM.png)

### 4단계: 광고 설정

{% hint style="info" %}
광고 세트당 광고를 최대 10개까지 추가할 수 있어요.
{% endhint %}

1. **광고**의 **이름**을 입력하세요.

   ![광고 이름 입력 화면](https://jumpshare.com/share/4z65Iv3k02pEUJc73Bgb+/Screen+Shot+2026-02-10+at+9.22.29+PM.png)
2. 캠페인 단계에서 고른 **목표**(**리드 생성**, **Website Traffic**(웹사이트 트래픽), **Engagement**(참여), **Sales**(판매))에 따라 **Website URL**(웹사이트 URL), **Facebook Lead Form**(Facebook 리드 폼), **Conversation Form**(대화 폼) 중에서 하나를 선택하라는 안내가 나와요.

   ![광고 유형 선택 화면](https://jumpshare.com/share/9dlalReminr9cNSxtxog+/Screen+Shot+2026-02-10+at+9.26.15+PM.png)
3. **Ad Text & Media**(광고 텍스트 및 미디어): **기본 텍스트**, **헤드라인**, **설명**을 입력하고, **단일** 또는 **캐러셀** 형식으로 **이미지**와 **동영상**을 추가할 수 있어요.

   - **기본 텍스트**는 선택 항목이에요. 권장 글자 수는 125자예요.
   - **버튼**을 선택하세요. 예: **Learn More**(더 알아보기), **Buy Now**(지금 구매), **Contact Us**(문의하기). **리드 생성** 광고에서는 **Get Offer**(혜택 받기) CTA를 쓸 수 있어요.
   - **다중 광고주 광고**: Meta의 광고 형식 중 하나로, 여러 광고주가 같은 광고 공간에서 제품이나 서비스를 보여 줄 수 있어요. 이 체크박스는 기본으로 선택되어 있고, 게시하는 사람이 끌 수 있어요.

     작동 방식: 잠재 구매자가 광고에 반응하면, 광고 아래에 다른 비즈니스의 상품을 보여 주는 다중 광고주 캐러셀이 나타날 수 있어요. 캐러셀의 상품은 보통 사용자가 반응한 광고와 관련된 상품이에요.

     이 기능을 쓰면 도달 범위 확대, 비용 효율, 상호 홍보 같은 이점을 얻을 수 있어요.

     {% hint style="info" %}
     다중 광고주 광고는 모든 캠페인에 맞지는 않아요. 특히 브랜드를 분명히 구분해야 하거나 비즈니스마다 고유한 메시지가 필요하면 맞지 않을 수 있어요.
     {% endhint %}
   - **이미지**를 **단일** 또는 **캐러셀**로 올리거나, **동영상**을 **단일**로 올리세요. 이미지는 최대 8MB, 동영상은 최대 1GB까지 올릴 수 있어요.
   - **헤드라인**은 광고 캠페인의 필수 항목이에요. 권장 글자 수는 40자예요.
   - **설명**은 선택 항목이에요. 권장 글자 수는 30자예요.

   ![광고 텍스트 및 미디어 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064610038/original/CmNg9pJt9l-MJASRMccKQUpuhWF4CrKPLw.jpeg?1770739539)

### 5단계: 검토 후 게시

1. **리뷰** 버튼을 클릭하세요. 캠페인을 시작하기 전에 디자인, 미디어, 콘텐츠, 예산, 그 밖의 옵션을 모두 확인하세요.

## 자주 묻는 질문

### 예산은 캠페인과 광고 세트 중 어디에서 설정하나요?
하이퍼클래스에서는 광고 세트의 예산 설정을 쓰세요. 오디언스 테스트와 지출의 관계를 가장 분명하게 볼 수 있어요.

### 광고 세트와 광고는 몇 개까지 만들 수 있나요?
캠페인당 광고 세트 최대 10개, 광고 세트당 광고 최대 10개까지 만들 수 있어요.

### 광고가 거절됐어요. 무엇부터 확인해야 하나요?
특별 광고 카테고리, 콘텐츠 정책 준수 여부, 연결되는 페이지의 품질을 확인하세요. 수정한 뒤 다시 제출하세요.

### 광고 세트와 광고를 복제할 수 있나요?
네, 복제할 수 있어요.

### 게시했거나 검토 중인 캠페인은 어떻게 편집하나요?
"게시했거나 검토 중인 Meta 광고 캠페인 편집하기" 문서를 확인하세요.
