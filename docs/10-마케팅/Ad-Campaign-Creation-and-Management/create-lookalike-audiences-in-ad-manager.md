# 광고 관리자에서 유사 오디언스 만들기

**광고 관리자**(Ad Manager)에서 캠페인을 만들 때 유사 오디언스를 만들고 사용하는 방법을 안내해요. 유사 오디언스의 상태 표시가 무엇을 뜻하는지도 함께 설명해요.

## 유사 오디언스 만들기 메뉴 위치

유사 오디언스는 캠페인 만들기 과정에서 만들 수 있어요.

1. 캠페인 만들기의 두 번째 단계인 **Budget and Audience**(예산 및 오디언스)로 이동해요.
2. **Audience Controls**(오디언스 컨트롤) 아래의 **Intended Audience**(타깃 오디언스) 섹션을 찾아요.

![캠페인 만들기 2단계의 오디언스 컨트롤 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081894232/original/IQt0Fdvgm4hN3EJ1WGGS7WMT3pR5vGUMOw.jpeg?1790355613)

3. **Lookalike Audience**(유사 오디언스) 탭에서 **유사 오디언스를 새로 만들거나 선택** 드롭다운을 클릭해요.
4. 목록의 첫 번째 항목인 **Create a Lookalike Audience**(유사 오디언스 만들기)를 선택해요.

![유사 오디언스 드롭다운 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081894237/original/IyxibFo8bPQwKVNzzWHM4BsERSB08f3D6A.jpeg?1790355622)

## 유사 오디언스 만드는 방법

유사 오디언스는 기존 고객과 취향이 비슷한 새로운 사람들의 그룹이에요. 선택한 기존 맞춤 오디언스를 소스 오디언스로 삼아요. 유사 오디언스를 사용하면 소스가 된 기존 고객과 비슷한 사람들에게 광고가 노출돼요.

유사 오디언스는 한 단계로 만들 수 있어요.

1. **Create a Lookalike Audience** 버튼을 클릭해요. 오디언스 정보를 입력하는 대화상자가 열려요.

   ![유사 오디언스 만들기 대화상자](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032032490/original/bgoCx9iwl0tA3tnPYKcb8YCNTXPR88ExkQ.png?1725228900)

2. **데이터 소스**에서 유사 오디언스를 만들 때 쓸 소스를 하나 선택해요. 선택할 수 있는 소스는 두 가지예요.
   - **Page**(페이지): 광고 관리자와 연동된 모든 페이지가 드롭다운에 표시돼요. 그중 하나를 선택해요.
   - **맞춤 오디언스**: 광고 관리자에 있는 모든 맞춤 오디언스가 드롭다운에 표시돼요. 그중 하나를 선택해요.

   ![데이터 소스 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032032549/original/XDanCkhpiOEb_CrS3suR1kMMLGdhkCuTrQ.png?1725229266)

3. **오디언스 이름**에 알아보기 쉬운 이름을 입력해요.
4. **지리적 위치**에서 **국가를 선택하세요**를 눌러 국가를 선택해요. 소스 오디언스와 비슷한 사람을 찾아 묶을 국가예요. 선택한 국가에 따라 유사 오디언스에 포함되는 사람들이 어느 지역에 사는지가 정해져요. 소스와 위치를 선택하면 Facebook이 해당 위치에서 소스와 비슷한 사람들을 찾아요.

   {% hint style="info" %}
   지금은 국가만 선택할 수 있어요. 도시, 동네, 시·도 같은 지역은 유사 오디언스 위치로 쓸 수 없어요.
   {% endhint %}

5. **Audience Size**(오디언스 크기)를 정해요. 0~10% 범위로 정할 수 있어요. 0~1%는 소스 오디언스와 가장 비슷한 사람들만 포함해요. 비율을 높이면 더 크고 일반적인 오디언스가 돼요.
6. 정보를 모두 입력한 뒤 **오디언스 만들기**를 클릭해요.

오디언스를 만들면 유사 오디언스 드롭다운에 표시돼요. 하지만 아직 바로 사용할 수는 없어요.

## 오디언스 상태

오디언스를 사용할 수 있는지는 아래 상태로 확인해요.

![오디언스 상태 표시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032032816/original/QmZAMvj3t7qvSslu3fTDJThajAzT7CILYw.png?1725231695)

1. **준비됨**: 오디언스가 만들어졌고 Facebook의 모든 사양을 충족한 상태예요. 어떤 캠페인에서든 오디언스로 사용할 수 있어요.
2. **채우는 중**: 유사 오디언스를 만드는 중인 상태예요. 채우는 데 6~24시간이 걸려요. 유사 오디언스가 만들어지면 **준비됨**으로 표시돼요. 해당 유사 오디언스로 광고를 타기팅하는 동안에는 3~7일마다 새로 고쳐져요.
3. **오디언스가 생성되지 않았습니다**: 유사 오디언스를 만들 때 사용한 소스 오디언스가 너무 작았을 수 있어요. 새 오디언스를 다시 만들어 보세요.

{% hint style="info" %}
유사 오디언스를 만들면 유사 오디언스 드롭다운 목록에 표시돼요. 새로 만든 오디언스의 상태가 **준비됨**이거나 **채우는 중**이면 캠페인을 만들 때 사용할 수 있어요.
{% endhint %}
