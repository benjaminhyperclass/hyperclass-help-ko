# 소셜 계정을 연결할 때 모든 페이지에 권한을 허용해야 하는 이유

Facebook 계정을 연결할 때 일부 페이지만 선택하면, 이미 연결해 둔 다른 페이지의 게시가 갑자기 실패할 수 있어요. 이 문서에서는 그 원인과 이를 막는 방법을 설명해요.

### 이런 문제를 막을 수 있어요

이전에 연결한 Facebook 페이지에 게시할 때 갑자기 토큰 또는 권한 오류가 난다면, 가장 흔한 원인은 같은 Facebook 계정을 다시 인증하면서 그 페이지를 선택하지 않은 경우예요.

Facebook은 앱 하나당 Facebook 사용자 한 명에게 인증을 하나만 발급해요. Facebook 계정을 연결하거나 다시 연결하면서 공유할 페이지를 고르면, 새로 고른 선택이 이전 선택을 대체해요. 체크하지 않은 페이지는 다른 서브 계정에 연결되어 있어도 인증이 해제돼요.

**예시**

1. Facebook 계정 하나로 페이지 A와 페이지 B를 관리하고 있어요.
2. 서브 계정 1에서 Facebook을 연결하면서 페이지 A만 허용했어요. 게시가 잘 돼요.
3. 나중에 서브 계정 2에서 같은 Facebook 계정을 연결하면서 페이지 B만 허용했어요.
4. 이제 페이지 A의 인증이 해제돼요. **소셜 플래너**(Social Planner)에는 페이지 B의 유효한 토큰만 남아 있어서, 서브 계정 1의 게시가 토큰 오류로 실패하기 시작해요.

### 권장 방법

Facebook 인증 화면에서 공유할 페이지를 물어보면, 계정에 연결된 모든 페이지를 선택하세요. 그러면 기존 연결이 끊기거나 나중에 다시 인증할 필요 없이, 연결할 수 있는 모든 서브 계정에서 각 페이지를 연결할 수 있어요.

{% hint style="info" %}
모든 페이지에 권한을 허용한다고 해서 모든 페이지가 모든 서브 계정에 연결되는 것은 아니에요. 각 서브 계정에서 사용할 페이지는 직접 선택해요.
{% endhint %}

#### 나중에 페이지 추가하기

계정을 다시 연결하면 언제든 다른 페이지에 권한을 추가로 허용할 수 있어요.

{% hint style="warning" %}
다시 인증할 때는 이전에 선택한 페이지를 모두 체크한 상태로 두고, 새 페이지를 추가로 체크하세요. 페이지 체크를 해제하면 그 페이지의 권한이 취소되고, 그 페이지가 연결된 모든 서브 계정에서 연결이 끊겨요.
{% endhint %}

#### 이미 토큰 오류가 나고 있다면

1. Facebook 계정을 다시 연결하고, 이번에는 모든 페이지를 선택하세요.
2. 게시가 실패하던 각 서브 계정에서 **소셜 플래너**의 페이지 연결 상태를 확인하세요. 여전히 오류가 표시되면 페이지를 다시 연결하세요.

## 자주 묻는 질문

### 모든 페이지에 자동으로 게시되나요?
아니요. 권한을 허용하면 페이지를 연결할 수 있는 상태가 될 뿐이에요. 각 서브 계정에서 연결할 페이지는 직접 선택해요.

### 나중에 다른 페이지에 권한을 추가할 수 있나요?
네, 할 수 있어요. 다만 소셜 계정을 다시 연결하고 인증 과정을 처음부터 다시 진행해야 해요. 그래야 새로 선택한 페이지와 기존에 추가한 페이지에 권한이 부여돼요. 이 과정을 거치지 않으려면 처음 연결할 때 모든 페이지에 권한을 허용하는 것을 권장해요.

### 다른 플랫폼에도 해당하나요?
이런 동작은 Facebook과 Instagram에만 해당해요. 이 두 곳은 가장 최근의 인증이 이전 인증을 대체해요. 다른 플랫폼도 선택 옵션이 있다면 사용 가능한 모든 프로필에 권한을 허용하는 것이 좋아요.
