# 소셜 플래너에서 소셜 그룹 만들고 관리하기

소셜 그룹을 만들어 두면 여러 소셜 미디어 계정을 한 번에 골라 게시물을 올릴 수 있어요. 이 문서에서는 소셜 그룹을 만들고, 게시물에 쓰고, 수정하고, 삭제하는 방법을 안내해요.

## 소셜 플래너의 소셜 그룹이란?

소셜 그룹은 연결된 여러 소셜 미디어 계정을 하나로 묶어 둔 것이에요. 게시물을 만들거나 콘텐츠를 필터링할 때 그룹을 선택할 수 있어서, 계정이 많아도 시간을 아낄 수 있어요.

### 소셜 그룹의 장점

소셜 그룹을 쓰면 여러 계정을 관리하기 쉽고 게시 과정도 간단해져요.

- 빠른 계정 선택: 그룹 하나로 여러 소셜 계정을 한 번에 선택할 수 있어요.
- 체계적인 정리: 연결된 프로필을 브랜드, 캠페인, 사업별로 나눠 둘 수 있어요.
- 간편한 그룹 관리: 계정을 추가하거나 빼고, 그룹 이름도 바꿀 수 있어요.
- 간단한 게시: 소셜 미디어 게시물을 만들 때 기존 그룹을 바로 선택할 수 있어요.

---

## 소셜 그룹 만들기

그룹을 만들어 두면 연결된 계정을 더 쉽게 고르고 콘텐츠를 관리할 수 있어요.

1. **마케팅 > 소셜 플래너 > 플래너**로 이동하세요.
2. **소셜 계정을 선택하세요** 드롭다운을 클릭하고 **새 그룹 만들기**를 선택하세요.

   ![소셜 계정 드롭다운에서 새 그룹 만들기를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084765064/original/y4IgJ8jzu7bdZcDvblsbzveXANVOeUHUTg.png?1793634127)
3. **그룹 이름 입력** 필드에 그룹 이름을 입력하세요.
4. **그룹에 계정 추가**에서 그룹에 넣을 소셜 프로필을 선택하세요.
5. **만들기**를 클릭해 그룹을 저장하세요.

![그룹 이름을 입력하고 계정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084765115/original/WVgpaHSDUtkSCOM7ZkLx76jVlqX3OUQsbQ.png?1793634163)

새 그룹은 소셜 계정 드롭다운의 **그룹** 아래에 표시돼요.

## 게시물을 만들 때 소셜 그룹 사용하기

소셜 그룹을 선택하면 프로필을 하나씩 고르지 않아도 새 게시물에 여러 소셜 계정을 한 번에 넣을 수 있어요.

1. **마케팅 > 소셜 플래너**로 이동하세요.
2. **+ New Post**(새 게시물)를 클릭한 다음 **새 게시물 만들기**를 선택하세요.
3. **게시 대상**에서 **소셜 계정을 선택하세요** 드롭다운을 여세요.
4. **그룹**에서 사용할 그룹 옆의 체크박스를 선택하세요.
5. 게시물 내용을 입력하고 게시하거나 예약하세요.

![게시 대상 드롭다운에서 그룹을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084765235/original/VWZvcgBkZQTJgh8h_jPFs_Za5UedNoD56A.png?1793634219)

## 소셜 그룹 수정하거나 삭제하기

그룹 이름을 바꾸거나 포함된 계정을 바꿔야 할 때 기존 그룹을 수정할 수 있어요.

1. **소셜 플래너 > 플래너**로 이동해 소셜 계정 드롭다운을 여세요.
2. **그룹**에서 수정할 그룹 옆의 연필 아이콘을 클릭하세요.
3. **그룹 수정** 창에서 그룹 이름을 바꾸거나 소셜 계정을 추가·제거하세요.
4. 변경 내용을 적용하려면 **변경사항 저장**을 클릭하세요. 그룹을 없애려면 **삭제**를 클릭하세요.

![그룹 옆의 연필 아이콘을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084765332/original/C2Gkpa9HJ28r4FUMmhqDfCzxcTFgwPngDQ.png?1793634294)

![그룹 수정 창에서 변경사항 저장과 삭제 버튼이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084765355/original/69GEiy_G7zsbMPEvOZNCOeDXEKpkI_I3gw.png?1793634315)

## 자주 묻는 질문

### 서로 다른 소셜 미디어 플랫폼의 계정을 한 그룹에 넣을 수 있나요?
네, 가능해요. 지원하는 플랫폼이라면 연결된 계정을 플랫폼과 관계없이 같은 소셜 그룹에 넣을 수 있어요.

### 게시물을 작성하는 중에도 소셜 그룹을 만들 수 있나요?
네, 가능해요. **새 소셜 게시물** 편집기에서 **게시 대상** 드롭다운을 열고 **새 그룹 만들기**를 선택하세요.

### 소셜 그룹을 선택하면 플랫폼마다 콘텐츠가 따로 맞춰지나요?
아니요. 소셜 그룹은 계정을 쉽게 고르기 위한 기능이에요. 플랫폼별로 문구와 미디어를 따로 만들려면 **Customize for Each Channel**(채널별 맞춤 설정)을 사용하세요. 자세한 방법은 [소셜 채널별로 게시물 맞춤 설정하기](how-to-customize-posts-for-each-social.md)를 참고하세요.

### 그룹에 있는 소셜 계정의 연결이 끊기면 어떻게 되나요?
해당 계정에 게시하려면 먼저 계정을 다시 연결해야 해요. 소셜 플래너에서 **재연결** 옵션을 확인하세요.
