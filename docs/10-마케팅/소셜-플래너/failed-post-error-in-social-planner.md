# 소셜 플래너 게시물 실패 오류 해결

**소셜 플래너**(Social Planner)에서 게시물이 실패하는 경우는 여러 가지예요. 플랫폼별 실패 메시지와 **오류 코드**에 맞는 해결 방법을 아래 표에 정리했어요.

|  | **실패 메시지와 해결 방법** | **오류 코드** |
| --- | --- | --- |
| Facebook | 소셜 계정 토큰이 만료됐어요. 소셜 계정을 다시 연결하세요. | OAuthException, 102, 109, 463, 467 |
| Facebook | Facebook에서 일시적인 오류가 발생했어요. 브라우저를 강제 새로고침해 캐시를 지운 뒤, 몇 분 후에 다시 시도하세요. | 1, 2, Unexpected Error |
| Facebook | 소셜 계정 토큰이 만료됐거나 연결된 계정에 게시 권한이 없어요. 게시 권한이 있는 계정으로 소셜 계정을 다시 연결하세요. | 3 |
| Facebook | 하이퍼클래스 앱이 없어요. 페이지나 그룹에 하이퍼클래스 앱을 추가하세요. | 10 |
| Facebook | 연결된 계정에 게시 권한이 없어요. 게시 권한이 있는 계정으로 소셜 계정을 다시 연결하세요. | 200-299 |
| Facebook | 게시물 내용이 커뮤니티 규정을 위반했어요. | 368 |
| Facebook | 중복된 게시물 내용이에요. 12시간 안에 같은 내용을 다시 게시할 수 없어요. | 506 |
| Facebook | 게시물에 잘못된 링크가 있어요. | 1609005 |
| Facebook | 사용자 체크포인트가 걸렸어요. Facebook에 로그인해 페이지나 그룹에 하이퍼클래스 앱이 추가되어 있는지 확인하세요. | 459 |
| Facebook | 비밀번호가 일치하지 않아요. Facebook에 로그인해 페이지나 그룹에 하이퍼클래스 앱이 추가되어 있는지 확인하세요. | 460 |
| Facebook | 확인되지 않은 사용자예요. Facebook에 로그인해 페이지나 그룹에 하이퍼클래스 앱이 추가되어 있는지 확인하세요. | 464 |
| Facebook | 게시 권한이 부족하거나 토큰이 만료됐어요. 계정을 다시 연결하고 권한을 확인하세요. | 492 |
| Facebook | Facebook에서 일시적인 오류가 발생했어요. 브라우저를 강제 새로고침해 캐시를 지운 뒤, 몇 분 후에 다시 시도하세요. | Unexpected Error |
| Facebook | 일시적으로 차단됐어요. Facebook이 일정 시간이 지난 뒤에야 프로필의 게시 기능을 복구해 줘요. | Temporary Block |
| Instagram | 파일 업로드 시간이 초과됐어요. 용량이 더 작은 파일을 첨부해 보세요. | 400 -2207003 |
| Instagram | 원인을 알 수 없는 Instagram 문제예요. 곧 저절로 해결될 거예요. | 400- 2207001, 2207053 |
| Instagram | 게시물 내용이 커뮤니티 규정을 위반했어요. | 400 - 2207051 |
| Instagram | 하루 게시 한도에 도달했어요. Facebook API는 하루에 올릴 수 있는 게시물 수가 정해져 있어요. | 400 - 2207042 |
| Instagram | Instagram용 소셜 계정 토큰이 만료됐거나, 취소됐거나, 유효하지 않아요. **소셜 플래너**에서 Instagram 비즈니스 계정을 다시 연결하세요. | 400 - 2207006 |
| Instagram | Instagram 계정이 제한됐어요. 계정이 비즈니스 계정인지 확인하세요. | 400 - 2207050 |
| Instagram | Instagram 비즈니스 계정의 캐러셀 게시물에는 이미지/동영상을 2개보다 많고 10개보다 적게 넣을 수 있어요. | 400 - 2207028 |
| Instagram | 태그 최대 개수를 초과했어요. 태그는 30개 이하로 사용하세요. | 400 - 2207040 |
| Instagram | 사용자 권한이 부족해요. 게시 권한이 있는 계정으로 이 소셜 계정을 다시 연결하세요. | 400 - 2207005 |
| LinkedIn | LinkedIn용 소셜 계정 토큰이 만료됐거나, 취소됐거나, 유효하지 않아요. LinkedIn을 다시 연결하세요. | 400 or 403 |
| LinkedIn | 원인을 알 수 없는 LinkedIn 문제예요. 곧 저절로 해결될 거예요. | 404, 500, 504 |
| LinkedIn | 중복된 게시물 내용이에요. 12시간 안에 같은 내용을 다시 게시할 수 없어요. | 422 |
| LinkedIn | 필수 항목이 없거나 게시물 문구가 너무 길어요. | 422 |
| LinkedIn | 연결된 계정에 게시 권한이 없어요. 게시 권한이 있는 계정으로 소셜 계정을 다시 연결하세요. | 400 |
| LinkedIn | LinkedIn에서 일시적인 오류가 발생했어요. 브라우저를 강제 새로고침해 캐시를 지운 뒤, 몇 분 후에 다시 시도하세요. | 409 |
| Google 비즈니스 프로필(GMB) | 값이 없어요. Google 비즈니스 프로필 설정을 완료한 뒤 **소셜 플래너**에서 다시 연결하세요. | `MISSING_VALUE`, `INVALID_VALUE` |
| Google 비즈니스 프로필(GMB) | 게시물 글자 수 제한을 넘었어요. 게시물 문구의 단어 수를 줄이세요. | `VALUE_OUTSIDE_ALLOWED_RANGE` |
| Google 비즈니스 프로필(GMB) | 소셜 계정 토큰이 만료됐어요. 소셜 계정을 다시 연결하세요. | `OPERATION_EXECUTION_ERROR`, `EXPIRED_VALUE` |
| Google 비즈니스 프로필(GMB) | 미디어 업로드에 실패했어요. | `PHOTO_FETCH_FAILED`, `PHOTO_UPLOAD_FAILED` |
| Google 비즈니스 프로필(GMB) | 계정 상태 때문에 소셜 계정 작업을 지원하지 않아요. | `OPERATION_UNSUPPORTED_UNDER_ACCOUNT_CONDITION` |
| Google 비즈니스 프로필(GMB) | 로컬 게시물 API가 비활성화됐어요. 보통 해당 위치가 체인점에 속해 있을 때 발생해요. | `LOCATION_DISABLED_FOR_LOCAL_POST_API` |
