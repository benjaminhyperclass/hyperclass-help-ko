# 소셜 플래너에서 게시물 승인 사용하기

**소셜 플래너**의 게시물 승인 기능을 쓰면 소셜 미디어 콘텐츠를 게시하기 전에 팀원이 검토할 수 있어요. 게시물을 만들어 예약하고 승인자를 지정하면, 콘텐츠가 게시 일정에 들어가기 전에 피드백을 받을 수 있어요.

승인자는 게시물을 검토하고 수정할 수 있어요. 콘텐츠를 승인하거나 반려할 수 있고, 게시 날짜와 시간도 조정할 수 있어요. 덕분에 팀이 콘텐츠 품질을 유지하며 더 원활하게 협업할 수 있어요.

이 문서에서는 내부 승인을 위해 게시물을 제출하는 방법, 승인 요청을 검토하는 방법, 반려된 게시물을 관리하는 방법, 승인 알림을 설정하는 방법, 대량 게시물을 승인 요청으로 제출하는 방법을 설명해요.

{% hint style="info" %}
하이퍼클래스에 접근할 수 없는 고객이나 외부 관계자에게 승인을 받아야 한다면 [소셜 플래너의 외부 링크 승인 흐름](../기타/post-approval-flow-in-social-planner.md)을 참고하세요.
{% endhint %}

## 게시물을 승인 요청으로 제출하기

소셜 미디어 게시물을 만들어 검토 요청으로 제출하는 방법이에요.

1. 하이퍼클래스 계정에서 **마케팅 > 소셜 플래너**로 이동하세요.
2. **새 게시물**을 클릭하고 소셜 미디어 게시물을 만드세요.
   ![새 게시물 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084928844/original/5Hmc6Joinojvt3WiLjDj0yHFCzNocpsJPw.png?1793790809)
3. 게시물 내용, 미디어, 해시태그 등 필요한 정보를 입력하세요.
4. 게시물을 승인용으로 예약하는 옵션을 선택하세요.
   ![승인용 예약 옵션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084928910/original/DtFDfU-YjNzGUgOpyopOAL6C70ExN6m9Og.png?1793790831)
5. 게시물을 게시할 날짜와 시간을 선택하세요.
   ![게시 날짜와 시간 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084929032/original/qLVQ0uN4E_GsKapFV1yCKhrmpRZesg0Gzg.png?1793790884)
6. 게시물을 승인할 팀원을 선택하세요.
   ![승인할 팀원 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084929085/original/D64s9qxnrpEuO0WoXMoOxrtF1-JLdTgQiw.png?1793790919)
7. 검토자에게 전달할 배경 설명이나 안내가 있으면 **내부 메모 추가**에 입력하세요.
8. 승인을 요청하며 게시물을 제출하세요.

제출하면 선택한 승인자가 게시물을 검토할 수 있어요.

## 승인 요청 알림

게시물을 승인 요청으로 제출하면 소셜 플래너가 선택한 승인자에게 이메일 알림을 보낼 수 있어요.

소셜 플래너 알림 설정에서 **Request for Post Approval**(게시물 승인 요청) 알림을 켜 두면 이메일이 발송돼요.

승인자는 소셜 플래너의 **콘텐츠 > 승인** 탭에서도 검토를 기다리는 게시물을 확인할 수 있어요.

승인 알림 관리 방법은 [소셜 플래너 이메일 알림 관리하기](how-to-manage-social-planner-email-notifications.md)를 참고하세요.

## 이메일 템플릿을 편집해 게시물 승인 이메일로 적용하기

승인 요청 이메일은 **소셜 플래너 설정**에서 지정할 수 있어요. 이메일 템플릿에 브랜딩을 적용하려면 **마케팅 > 이메일 > 템플릿 > 신규 > 이메일 마케팅 템플릿**으로 이동하세요.

![이메일 마케팅 템플릿 메뉴 경로](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48275003974/original/JbZqtJEP21bG7zSQEBIcw8lBCo-EpKoAbQ.png?1673541277)

그러면 **템플릿 라이브러리**로 이동해요. 여기서 **시스템 템플릿 > Social Planner : Post Approval**(소셜 플래너: 게시물 승인)로 가서 템플릿을 사용하세요. 원하는 대로 편집할 수 있어요.

![시스템 템플릿에서 게시물 승인 템플릿 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48275004276/original/H3HxcY2vYP0ctLVJWNR34FHNE9Jpp6A3Bg.png?1673541333)

편집한 템플릿은 소셜 플래너의 **설정 > 알림**에서 게시물 승인 이메일 흐름에 적용할 수 있어요.

![소셜 플래너 설정의 알림 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48275003279/original/tZg4MDksmtgmJqElCq8JhKJN18Ih6MRr3Q.png?1673541093)

**Setup Email template for Social Post Approval**(소셜 게시물 승인용 이메일 템플릿 설정) 아래에서 **이메일 템플릿 선택**을 클릭해 템플릿을 고르세요.

![이메일 템플릿 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48275003362/original/SuRrc78gn4HDJcewt5urj4Z61F4UAjOZzQ.png?1673541115)

## 승인이 필요한 대량 게시물을 CSV로 예약하려면 어떻게 하나요?

1. **새 게시물** 버튼을 클릭해 새 CSV를 만드세요.
2. CSV 파일을 추가하고 소셜 계정을 선택하면 **승인자 선택** 옵션이 나타나요.
   ![승인자 선택 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48274895622/original/llrQ2L893aD17J19tI91bIQ277mjhZXgUA.png?1673523102)
3. 게시물을 가져오면 선택한 승인자에게 검토 요청이 전달돼요. 승인되면 소셜 캘린더에 예약돼요.

## 대량 게시물을 승인 요청으로 제출하기

소셜 플래너에서는 대량 예약 과정에서 여러 게시물을 한꺼번에 승인 요청으로 제출할 수 있어요.

CSV 또는 XLSX 파일로 여러 소셜 미디어 게시물을 준비해 업로드하면 돼요.

### 대량 게시물 승인 요청 제출하기

1. **마케팅 > 소셜 플래너**로 이동하세요.
2. **새 게시물**을 클릭하고 **CSV에서 업로드**를 선택하세요.
3. 알맞은 CSV 형식을 선택하고, 작성을 마친 CSV 또는 XLSX 파일을 업로드하세요.
4. **다음**을 클릭하세요.
5. 게시물을 게시할 소셜 미디어 계정을 선택하세요.
6. **승인 요청 보내기**를 켜세요.
7. 게시물을 승인할 팀원을 선택하세요.
8. **만들기**를 클릭하세요.
9. 가져온 게시물 정보를 검토하고, 시스템이 알려 주는 오류를 수정하세요.
10. 남은 예약·가져오기 단계를 따라 대량 업로드를 마무리하세요.

파일 준비, 게시물 검증, 가져오기 완료 방법은 [소셜 플래너 – 대량 예약을 위한 고급 CSV](social-planner-advanced-csv-for-bulk-scheduling.md)를 참고하세요.

{% hint style="info" %}
승인 요청으로 제출한 게시물은 검토를 거쳐야 승인 후 게시 흐름으로 넘어가요.
{% endhint %}

## 자주 묻는 질문

### 승인을 기다리는 게시물은 어디서 확인하나요?

**마케팅 > 소셜 플래너 > 콘텐츠 > 승인**으로 이동하면 검토를 기다리는 게시물을 볼 수 있어요.

### 승인자가 게시물을 승인하기 전에 수정할 수 있나요?

네. 승인자는 게시물을 열고 **편집**을 선택해 승인 전에 내용을 고칠 수 있어요.

### 승인자가 예약된 게시 시간을 바꿀 수 있나요?

네. 승인자는 승인 검토 화면에서 날짜와 시간을 수정한 뒤 **승인**을 선택하면 돼요.

### 승인자가 승인 요청 이메일을 받지 못했어요.

**소셜 플래너 > 설정 > 알림**에서 **Request for Post Approval**(게시물 승인 요청) 알림이 켜져 있는지 확인하세요.

게시물을 제출할 때 원하는 승인자를 선택했는지도 확인하세요.

알림 설정 방법은 [소셜 플래너 이메일 알림 관리하기](how-to-manage-social-planner-email-notifications.md)를 참고하세요.

### 외부 고객이 소셜 미디어 게시물을 승인할 수 있나요?

네. 소셜 플래너는 보안 승인 링크를 사용하는 별도의 외부 승인 절차를 지원해요.

자세한 내용은 [소셜 플래너의 외부 링크 승인 흐름](../기타/post-approval-flow-in-social-planner.md)을 참고하세요.

### 여러 게시물을 한 번에 승인 요청으로 제출할 수 있나요?

네. 대량 CSV 예약 방법을 사용하고, 업로드를 설정할 때 **승인 요청 보내기**를 켜세요.

자세한 내용은 [소셜 플래너 – 대량 예약을 위한 고급 CSV](social-planner-advanced-csv-for-bulk-scheduling.md)를 참고하세요.
