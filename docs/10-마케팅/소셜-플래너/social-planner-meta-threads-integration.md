# 소셜 플래너 — Meta Threads 연동

하이퍼클래스 **소셜 플래너**에서 Meta의 Threads 게시물을 예약, 게시, 자동화할 수 있어요. 이 문서에서는 계정을 연결하는 방법과 미디어 제한을 안내하고, **Category Queues**(카테고리 대기열), **RSS Auto-Posting**(RSS 자동 게시), **Advanced CSV Upload**(고급 CSV 업로드) 같은 자동화 도구도 소개해요.

## 소셜 플래너의 Threads 연동이란?

Threads 연동을 켜면 Meta의 텍스트 중심 소셜 네트워크를 하이퍼클래스에서 관리하는 채널에 추가할 수 있어요. Instagram 계정 정보로 로그인하면 Facebook, Instagram, LinkedIn 같은 다른 채널과 함께 한 캘린더에서 Threads 게시물을 작성하고, 예약하고, 성과를 확인할 수 있어요. 팀이 하나의 워크플로우 안에서 일할 수 있어요.

## Threads 연동의 주요 장점

- **한 곳에서 게시:** 앱을 오가지 않고 하나의 **소셜 플래너** 캘린더에서 Threads, Facebook, Instagram, LinkedIn 등을 함께 관리해요.
- **시간을 아껴 주는 자동화:** **Review Flow**(검토 플로우), **RSS Auto-Posting**, **Category Queues**로 캘린더를 자동으로 채워서, 직접 게시하지 않아도 Threads 채널을 꾸준히 운영할 수 있어요.
- **짧은 시간에 콘텐츠 대량 등록:** **Advanced CSV Upload**로 게시물 수백 개를 한 번에 만들고 예약할 수 있어요. 해시태그, 카테고리, 첫 댓글 등도 매핑할 수 있어요.
- **게시 실패 줄이기:** API 기준에 맞는 한도(500자, 이미지 최대 20개 또는 5분 이내 동영상 1개) 안에서 작성하면 게시 실패와 재작업을 막을 수 있어요.
- **일관된 브랜드 노출:** 미리 예약하고 시기를 타지 않는 콘텐츠를 다시 활용하면, 팀이 바쁠 때도 Threads 채널을 꾸준히 운영할 수 있어요.

## Threads 게시 사양

| 구분 | 이미지 | 동영상 |
| --- | --- | --- |
| 파일 형식 | JPEG, PNG | MP4, MOV |
| 최대 파일 크기 | 8MB | 1GB |
| 게시물당 최대 업로드 수 | 이미지 최대 20개 | 동영상 20개 (이미지와 함께 사용 가능) |
| 치수 / 해상도 | 최소 320px, 최대 1440px | 너비 최대 1920px |
| 가로세로 비율 | 0.01:1 ~ 10:1 | 0.01:1 ~ 10:1 |
| 길이 | – | 최대 5분 |
| 프레임 속도 | – | 23~60 FPS |
| 코덱 | – | H.264 또는 HEVC(영상), AAC(오디오) |
| 기타 | – | 맞춤 썸네일은 지원하지 않아요 |

## 소셜 플래너에 Threads 연결하기

{% hint style="info" %}
Threads 접근 권한은 Instagram 계정 정보로 관리돼요. 그래서 Threads 계정이 Instagram 계정과 연결되어 있어야 해요.
{% endhint %}

다음 순서대로 Threads를 연결하세요.

1. 서브 계정에서 **마케팅**을 클릭하세요.
2. **소셜 플래너** 탭을 클릭하세요.
3. **+ Socials**(소셜 추가) 버튼을 클릭하세요.
4. **Connect Threads**(Threads 연결) 옵션을 클릭하세요.
5. Instagram 계정 정보로 로그인하고 접근 권한을 승인하세요.
6. 연결할 프로필 옆의 **추가** 버튼을 클릭하세요.
7. 연결이 끝나면 소셜 플래너의 **모든 계정** 드롭다운에 Threads 계정이 표시돼요.

{% hint style="info" %}
이제 소셜 플래너에서 Threads 댓글도 관리할 수 있어요. 지원 기능, 제한 사항, 자세한 사용법은 소셜 플래너 댓글 관리 문서를 참고하세요.
{% endhint %}

## 자주 묻는 질문

### Threads 계정이 공개 계정이어야 하나요?

네. 소셜 플래너로 게시하려면 Threads 계정이 공개 상태여야 해요.

### Threads 게시물에 위치를 추가할 수 없어요.

위치 태그는 지원되지 않아요. 현재 Threads API에서 제한하고 있는 기능이에요.

### 소셜 플래너에서 Threads 분석을 볼 수 있나요?

네. 게시물, 좋아요, 댓글, **참여율**을 확인할 수 있어요.

### Threads 로그인을 따로 만들어야 하나요?

아니요. Threads API 인증은 Instagram(OAuth 2.0)을 통해 이루어져요. Threads 프로필에 연결된 Instagram 계정을 연결하면 돼요.

### 한 게시물에 이미지와 동영상을 함께 넣을 수 있나요?

네. 캐러셀에 이미지와 동영상을 섞어서 최대 20개까지 넣을 수 있어요.

### Threads 게시물의 글자 수 제한은 얼마이고, 넘기면 어떻게 되나요?

Threads 게시물은 최대 500자까지 쓸 수 있어요. 제한을 넘는 텍스트는 잘려 나가고, 답글로 이어서 게시되지 않아요. 글을 더 넣고 싶다면 **Follow-up comment**(후속 댓글) 필드를 사용하세요. 입력한 내용은 Threads 게시물 바로 아래에 답글로 게시돼요.

### Threads와 다른 채널에 함께 게시하면 어떻게 되나요?

여러 채널에 보내는 게시물 하나는 캡션을 공유해요. 그래서 선택한 채널 중 글자 수 제한이 가장 작은 쪽에 맞춰져요. Threads를 선택하면 Instagram, Facebook, LinkedIn 캡션도 500자로 제한돼요. 채널별 글자 수 제한을 그대로 쓰려면 편집기에서 **채널별 사용자 지정**을 켜거나, Threads 게시물을 별도의 CSV로 가져오세요.

### Instagram/Threads 토큰이 만료되면 어떻게 하나요?

스케줄러에서 Threads 계정을 **Reconnect**(다시 연결)하라는 안내가 나타나요. 다시 인증하면 예약된 게시물이 이어서 게시돼요.

### 게시한 Threads 게시물을 소셜 플래너에서 편집하거나 삭제할 수 있나요?

Threads는 게시물 편집을 지원하지 않아요. 삭제는 Threads 앱에서 직접 할 수 있어요.

### 여러 계정에 Threads 게시물을 한 번에 예약할 수 있나요?

네. Threads 계정이 각각 연결되어 있고 공개 상태라면 여러 Threads 계정에 함께 예약할 수 있어요.
