# 클라이언트에게 소셜 계정 연결 초대하기

**Social Connect Invite**(소셜 연결 초대) 기능을 쓰면 클라이언트가 하이퍼클래스에 접근하지 않고도 자신의 소셜 미디어 계정을 내 서브 계정에 연결할 수 있어요. 비밀번호가 걸린 초대 링크를 만들어 클라이언트에게 전달하면, 클라이언트가 직접 소셜 계정 연결을 마칠 수 있어요. 연결이 끝나면 계정이 내 서브 계정에 자동으로 추가돼요.

## 소셜 연결 초대를 쓰면 좋은 점

클라이언트의 소셜 계정을 연결하려면 에이전시와 클라이언트가 서로 조율해야 할 때가 많아요. **Social Connect Invite**를 쓰면 클라이언트가 하이퍼클래스 계정에 접근하지 않고도 직접 권한을 승인할 수 있어요.

이런 점이 좋아요.

- 클라이언트를 더 빠르게 온보딩할 수 있어요.
- 클라이언트에게 내 서브 계정 접근 권한을 주지 않아도 돼요.
- 클라이언트에게 소셜 미디어 비밀번호를 받지 않아도 돼요.
- 계정을 연결하는 동안 주고받는 연락이 줄어요.
- 클라이언트가 자신의 소셜 계정을 직접 승인해요.
- 초대 하나로 여러 소셜 플랫폼을 연결할 수 있어요.
- 연결된 계정에 확인이 필요할 때 알림을 받을 수 있어요.

## 진행 방식

진행 과정은 간단해요.

1. **설정 > 실험실**에서 **Social Connect Invite**를 켜요.
2. **마케팅 > 소셜 플래너 > 설정 > Social Accounts**(소셜 계정)에서 보안 초대 링크를 만들어요.

   ![소셜 계정 설정에서 초대 링크를 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082100389/original/aWfLNSD2VA444APSbBjbINBydQUtHi8TlQ.png?1790683286)

3. 자동 생성 비밀번호를 쓰거나 직접 비밀번호를 만들어요.

   ![비밀번호를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082100549/original/BSkuQOlcZ_O28FYslyy6vRhoZnEI1oPw6g.png?1790683343)

4. 초대 링크와 비밀번호를 클라이언트에게 전달해요.

   ![초대 링크와 비밀번호를 공유하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082100891/original/fxYxMnvAYktBKpuAPbXKrEUe_hD-uxutFA.png?1790683458)

{% hint style="info" %}
초대 링크와 비밀번호는 평소 쓰는 소통 채널로 클라이언트에게 전달하면 돼요.
{% endhint %}

5. 클라이언트가 초대 링크를 열고 소셜 계정을 연결해요.

   ![클라이언트가 초대 링크로 소셜 계정을 연결하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082100960/original/CzJM5YhZAymcBttX-UUNkyzEkPGZRz3BZg.png?1790683495)

6. 클라이언트는 **Notification recipients**(알림 수신자)에 이메일 주소를 추가할 수도 있어요.

지정한 수신자는 연결된 계정이 다음과 같은 상태가 되면 알림을 받아요.

- 연결에 성공했을 때
- 연결이 끊겼을 때
- 확인이 필요할 때

![알림 수신자 이메일을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082101601/original/SyElJAEYxrCC7RYe26rkQq319yv5zpcOWg.png?1790683809)

7. 연결이 끝나면 소셜 계정이 내 서브 계정에 자동으로 표시돼요.

![서브 계정에 표시된 연결된 소셜 계정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082101717/original/Urmuo89ieZj5QVhrNE4mhxkAnuhq0DNmJw.png?1790683859)

## 소셜 연결 초대 만들기

1. **마케팅 > 소셜 플래너 > 설정 > Social Accounts**로 이동해요.
2. **Social Connect Invite**를 선택해요.
3. 초대 링크를 만들어요.
4. **auto-generated password**(자동 생성 비밀번호)를 쓸지, **custom password**(직접 만든 비밀번호)를 만들지 선택해요.
5. 초대 링크와 비밀번호를 복사하거나, 초대를 클라이언트에게 바로 보내요.

{% hint style="info" %}
초대 링크와 비밀번호는 평소 쓰는 소통 채널로 클라이언트에게 전달하면 돼요.
{% endhint %}

## 클라이언트가 소셜 계정을 연결하는 방법

클라이언트는 내 하이퍼클래스 서브 계정에 접근할 필요가 없어요.

클라이언트는 다음 순서로 진행하면 돼요.

1. 전달받은 초대 링크를 열어요.
2. 초대 비밀번호를 입력해요.
3. 연결할 소셜 플랫폼을 선택해요.
4. 해당 플랫폼의 권한 승인 절차를 마쳐요.
5. 연결을 완료해요.

연결에 성공하면 소셜 계정이 내 서브 계정에 자동으로 추가돼요.

## 소셜 연결 초대 관리하기

이미 만든 초대는 다음 위치에서 관리할 수 있어요.

**설정 > Manage Links**(링크 관리) **> Social Connect Link**(소셜 연결 링크)

여기에서 다음 작업을 할 수 있어요.

- 초대의 **유효기간 연장**
- 초대 **재생성**
- 초대 **해제**

![소셜 연결 링크 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082853539/original/M4lzm6lHGLaAdIagRqrAMkARxjqBZcK2Hg.png?1791464795)

## 초대 만료와 보안

- 초대 링크는 만든 날부터 30일 뒤에 만료돼요.
- 초대가 만료되기 전이나 만료된 뒤에 초대를 연장하거나 재생성할 수 있어요.
- 초대 링크와 비밀번호를 둘 다 아는 사람은 누구나 이 초대로 내 서브 계정에 소셜 계정을 연결할 수 있어요.
- 초대 정보는 신뢰할 수 있는 클라이언트에게만 공유하세요.
- 초대를 해제하면 해당 초대로는 즉시 접근할 수 없어요.

## 소셜 연결 초대가 편한 경우

여러 사업체나 브랜드의 소셜 미디어를 대신 관리한다면, Social Connect Invite로 클라이언트 온보딩이 더 쉬워져요.

이 기능으로 다음을 할 수 있어요.

- 클라이언트가 자신의 소셜 계정을 직접 연결하게 해요.
- 클라이언트에게 내 하이퍼클래스 서브 계정 접근 권한을 주지 않아도 돼요.
- 계정을 설정하는 동안 주고받는 연락을 줄여요.
- 클라이언트에게 소셜 계정 로그인 정보를 받지 않아도 돼요.
- 연결 초대를 한곳에서 관리해요.

## 자주 묻는 질문

### 클라이언트도 내 하이퍼클래스 서브 계정에 접근할 수 있어야 하나요?

아니요. 클라이언트는 보안이 적용된 외부 초대 페이지에서 소셜 계정을 연결해요.

### 연결된 계정은 내 서브 계정에 자동으로 추가되나요?

네. 클라이언트가 연결을 성공적으로 마치면 연결된 소셜 계정이 내 서브 계정에 자동으로 추가돼요.

### 초대 링크는 얼마나 오래 유효한가요?

초대 링크는 만든 날부터 30일 동안 유효해요.

### 초대를 더 이상 쓰지 못하게 하려면 어떻게 하나요?

**설정 > Manage Links > Social Connect Link**로 이동해서 초대를 **해제**하세요. 해제한 초대는 더 이상 쓸 수 없어요.

### 비밀번호를 직접 정할 수 있나요?

네. 초대를 만들 때 자동으로 생성된 비밀번호를 쓰거나 직접 비밀번호를 만들 수 있어요.

### 클라이언트에게 초대를 바로 보낼 수 있나요?

네. **소셜 플래너**에서 초대를 바로 보내거나, 초대 링크와 비밀번호를 복사해서 평소 쓰는 소통 채널로 전달할 수 있어요.
