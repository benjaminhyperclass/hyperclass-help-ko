# 소셜 채널별로 게시물 다르게 작성하기

하이퍼클래스 소셜 플래너에서는 게시물을 따로 만들지 않아도 채널마다 캡션과 미디어를 다르게 설정할 수 있어요. 이 문서에서는 채널별 맞춤 내용을 작성하고, 확인하고, 게시하는 방법을 안내해요.

## 채널별 맞춤 설정(Customize for Each Post) 기능이란?

**Customize for Each Channel**(채널별 맞춤 설정) 기능을 쓰면 게시물 하나 안에서 소셜 플랫폼마다 캡션과 미디어를 다르게 작성할 수 있어요. 플랫폼별 요건에 맞는 내용을 한곳에서 관리할 수 있어요.

이 기능의 특징은 다음과 같아요.

- 여러 플랫폼 지원: Facebook, LinkedIn 등 여러 소셜 미디어 플랫폼을 선택하고, 플랫폼마다 다른 글자 수 제한과 요건에 맞춰 내용을 작성할 수 있어요.
- 내용 맞춤 작성: 채널마다 글자 수 제한이 달라요. 한 화면에서 LinkedIn에는 짧은 글을, Facebook에는 긴 글을 각각 작성할 수 있어요.
- 토글 스위치: 토글로 채널별 맞춤 내용과, 선택한 모든 플랫폼에 똑같이 적용되는 내용 사이를 오갈 수 있어요.
- AI 연동: 콘텐츠 AI를 연동해 최대 900단어까지 내용을 만들 수 있어요. 소셜 미디어 종류에 따라 작은 분량, 중간 분량, 긴 분량으로 조정할 수도 있어요.
- 예약 기능: 맞춤 게시물을 나중에 게시되도록 예약할 수 있어요. 소셜 미디어 관리를 자동화하는 데 도움이 돼요.
- 시간과 비용 절약: 플랫폼마다 게시물을 따로 만들 필요가 없어 시간과 노력이 줄어요. 통일감은 유지하면서 채널에 맞는 마케팅을 할 수 있어요.

## 채널별로 게시물 맞춤 설정하기

하이퍼클래스에서는 게시하기 전에 연결된 여러 소셜 계정별로 내용을 다르게 설정할 수 있어요. 아래 순서대로 플랫폼별 게시물을 만들어 보세요. ▶ 영상 [8강 2부 23:35](https://www.youtube.com/watch?v=TNUzXx1UteQ&t=1415s)

1. **마케팅 > 소셜 플래너**로 이동해 **+ New Post**(새 게시물 추가)를 클릭한 다음 **새 게시물 만들기**를 선택하세요.

   ![새 게시물 만들기 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084757610/original/VcYR5C47WMQ0C20uH_BYsGRT76sDb0X9Lw.png?1793631280)

2. 소셜 미디어 채널을 여러 개 선택하세요. Facebook, Instagram, LinkedIn, GMB(Google My Business) 등을 선택할 수 있어요. 채널을 여러 개 선택해야 맞춤 설정 옵션이 나타나요.

   ![여러 소셜 채널 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084758035/original/e16_zUnOt-zA_A9H3SSqT1--LKg7I5hHQw.png?1793631435)

3. 채널을 선택하면 채널별 맞춤 설정을 켤 수 있는 토글이 나타나요. **Customize for Each Channel** 토글을 켜세요. 이 토글을 켜면 플랫폼마다 글자 수 제한과 이미지·동영상 형식을 고려해 서로 다른 내용을 만들 수 있어요.

   ![Customize for Each Channel 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084758335/original/iRLbvhr9A_A-NeEjHweT9zpfJuyKVEO7lg.png?1793631566)

4. 채널별로 내용을 작성하세요. 플랫폼별 글자 수 제한을 지켜야 해요. 예를 들어 Facebook은 5,000자, GMB는 1,500자예요.

### 소셜 미디어 채널별 글자 수 제한

채널별 맞춤 설정을 쓸 때 꼭 확인해야 하는 글자 수 제한이에요.

| 채널 | 글자 수 제한 |
| --- | --- |
| Facebook 페이지 및 그룹 | 5,000 |
| Instagram 프로필 | 2,200 |
| LinkedIn 페이지 및 프로필 | 3,000 |
| GMB(Google My Business) | 1,500 |

채널별 내용을 따로 보고 편집할 수 있어서, 각 게시물을 플랫폼의 글자 수 제한과 독자 성향에 맞출 수 있어요.

![채널별 내용 작성 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155005176906/original/Hc6I1UBbhapeFzgazVj1Cfl0zRTe5p6WFA.png?1692035608)

![채널별 내용 작성 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155005176960/original/5IbS881B_zhWOcA6jL9yt2K-K-aHE71Sxw.png?1692035717)

5. 미디어(이미지·동영상)를 추가하세요. 파일 크기 기준은 [게시 콘텐츠 가이드(이미지·동영상·텍스트)](../../26-산업-가이드/기타/posting-content-image-video-and-text-guidelines.md)에서 확인할 수 있어요. 소셜 미디어마다 맞는 이미지, 동영상 등 멀티미디어 요소를 추가해 게시물을 더 풍성하게 만들 수 있어요.

   ![미디어 추가 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048870075/original/_y71MZip2uZ8eWJwiiyGt4iy3jv8be7M4g.png?1750863597)

   ![미디어 추가 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048870095/original/6mW5SrJoH7NcON2qG_e4_d7NXVMXkPuPVw.png?1750863612)

{% hint style="info" %}
1. 미디어를 업로드하는 중에 소셜 계정을 바꾸면 진행 중이던 업로드가 취소될 수 있어요.
2. 미디어를 업로드하는 중에 **Customize for Each Post** 토글을 바꾸면 진행 중이던 업로드가 삭제될 수 있어요.
3. 동영상 썸네일을 처리하는 중에 소셜 계정이나 **Customize for Each Post** 토글을 바꾸면 썸네일 처리가 중단될 수 있어요. 이 경우 썸네일을 다시 적용해야 할 수 있어요.
{% endhint %}

6. (선택) 콘텐츠 AI를 활용하세요. 이 단계에서 AI로 새 문구를 만들거나, 소셜 미디어 종류에 맞게 내용 분량을 조정할 수 있어요.

   ![콘텐츠 AI 사용 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084760949/original/CSmXRERMlxWrnvLxSI4AUqis_5MBC4zAew.png?1793632557)

   ![콘텐츠 AI 사용 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084761035/original/M3ECpklbE5rAAB58ZkJLj0WkXDcJwlgizA.png?1793632577)

7. 채널별 내용을 모두 작성했으면 바로 게시하거나 나중에 게시되도록 예약하세요. 게시 전에 플랫폼마다 내용이 정확하고 일관된지 한 번 더 확인하세요.

{% hint style="info" %}
맞춤 설정 토글을 끄면 현재 선택된 채널의 내용이 선택한 모든 소셜 채널에 적용돼요. 이때 맞춤 작성한 내용이 사라진다는 경고가 표시돼요.

![맞춤 설정을 끌 때 표시되는 경고](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155005177120/original/-2ntwlxNMYpzQZYt2ekAmKg8YdNiz6tViQ.png?1692035967)
{% endhint %}

이 순서대로 하면 소셜 미디어 채널마다 플랫폼에 맞는 내용을 만들어 도달 범위와 반응을 높일 수 있어요. 여러 캠페인을 효율적으로 관리하면서 플랫폼마다 독자에게 맞는 메시지를 전달하기에 좋은 방법이에요.

## 알아 두면 좋은 점

소셜 플랫폼마다 콘텐츠 요건이 달라요. 게시하기 전에 아래 내용을 확인하면 형식 오류나 변경 내용 손실을 막을 수 있어요.

- 여러 계정 선택: 채널별 맞춤 설정을 쓰려면 소셜 계정을 두 개 이상 선택해야 해요.
- 맞춤 설정 끄기: 토글을 끄면 현재 선택된 채널의 내용이 선택한 모든 채널에 적용되고, 나머지 맞춤 버전은 사라져요.
- 미디어 업로드: 채널을 바꾸거나 맞춤 설정 토글을 바꾸기 전에 이미지, 동영상, 썸네일 처리가 끝날 때까지 기다리세요.
- 플랫폼 요건: 게시하기 전에 지원되는 글자 수 제한과 미디어 형식을 확인하세요.

자세한 요건은 [게시 콘텐츠 가이드(이미지·동영상·텍스트)](../../26-산업-가이드/기타/posting-content-image-video-and-text-guidelines.md)를 참고하세요.

## 자주 묻는 질문

### 채널별 맞춤 설정 옵션이 안 보여요.
게시물을 만들 때 소셜 계정을 여러 개 선택하면 맞춤 설정 옵션이 나타나요.

### 여러 채널의 내용을 편집한 뒤에 맞춤 설정을 끄면 어떻게 되나요?
현재 선택된 채널의 내용이 선택한 모든 채널에 적용되고, 다른 맞춤 버전은 사라져요.

### 콘텐츠 AI로 채널별 캡션을 만들 수 있나요?
네. 선택한 소셜 채널의 내용을 만들고 편집할 때 콘텐츠 AI의 도움을 받을 수 있어요.

### 내용이 플랫폼의 글자 수 제한을 넘으면 어떻게 되나요?
게시하기 전에 해당 플랫폼의 요건에 맞게 내용을 고쳐야 해요. 제한을 넘으면 소셜 플래너에 경고가 표시될 수 있어요.
