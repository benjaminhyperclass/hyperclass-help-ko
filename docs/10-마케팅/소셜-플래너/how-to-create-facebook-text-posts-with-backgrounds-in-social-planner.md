# 소셜 플래너에서 Facebook 배경 텍스트 게시물 만들기

**소셜 플래너**(Social Planner)에서 Facebook의 기본 배경 스타일을 쓴 텍스트 게시물을 만들고, 미리 보고, 예약할 수 있어요. 이 문서에서는 기능 설명과 설정 방법을 안내해요.

소셜 플래너는 Facebook의 컬러 배경 텍스트 게시물을 지원해요. 하이퍼클래스 밖으로 나가지 않고도 눈에 띄는 게시물을 올릴 수 있어요. 글만 있는 게시물도 피드에서 더 잘 보이고, 콘텐츠 작업을 한곳에서 끝낼 수 있어요.

## Facebook 배경 텍스트 게시물이란?

Facebook 배경 텍스트 게시물은 하이퍼클래스 게시물 작성 화면에서 Facebook 기본 배경 스타일을 적용해 텍스트만으로 만드는 게시물이에요. Facebook에 들어가 따로 디자인할 필요가 없어요. 배경을 고르고 글을 쓴 뒤, 다른 소셜 콘텐츠를 관리하던 소셜 플래너 캘린더에서 바로 게시하거나 예약하면 돼요.

주요 기능은 다음과 같아요.

- Facebook 기본 배경의 텍스트 게시물 — 소셜 플래너를 떠나지 않고 Facebook이 제공하는 배경 스타일로 게시물을 만들어요.
- 즉시 게시와 예약 게시 — 바로 올리는 게시물과 캘린더 예약 게시물 모두에 배경을 쓸 수 있어요.
- 실시간 미리보기 — 실제 피드에 보일 모습과 거의 같은 Facebook 스타일 목업을 확인해요.
- 자동 검증 — 미디어를 추가하면 배경이 자동으로 꺼져서, 배경을 쓸 수 있는 게시물에만 적용돼요.

## 이런 점이 좋아요

Facebook 텍스트 게시물에 배경을 넣으면 콘텐츠가 눈에 띄고 제작 시간도 줄어요. 작업은 소셜 플래너 안에서 하면서, 결과물은 Facebook에서 직접 올린 것과 비슷해요.

- 더 눈에 띄는 게시물 — 컬러 배경 덕분에 짧은 글도 바쁜 Facebook 피드에서 눈에 잘 띄어요. 짧은 소식이나 공지도 한눈에 읽혀요.
- 빠른 콘텐츠 제작 — 다른 소셜 채널과 같은 소셜 플래너 작성 화면에서 배경 게시물을 쓰고, 미리 보고, 예약해요. Facebook으로 옮겨 갈 필요가 없어요.
- 일관된 Facebook 기본 스타일 — Facebook의 기본 배경 스타일을 쓰기 때문에, 예약한 게시물도 Facebook에서 직접 만든 것처럼 보여요.
- 수동 게시 줄이기 — 에이전시와 비즈니스가 일상적인 게시 일정을 소셜 플래너에서 더 많이 관리할 수 있어요. 여러 탭과 앱을 오가는 시간이 줄어요.
- 더 안전한 게시 — 배경은 조건에 맞는 Facebook 텍스트 게시물에만 적용돼요. 잘못 설정된 게시물이나 게시 시점의 예상 밖 결과를 막아 줘요.

## Facebook 기본 배경 게시물

Facebook 기본 배경 게시물은 컬러 배경이나 패턴 배경 위에 짧은 글이 보이는 텍스트 전용 게시물이에요. 소셜 플래너가 이 형식을 직접 지원해서, 예약한 게시물도 Facebook 앱에서 만든 것과 똑같이 나와요.

- 배경이 있는 텍스트 전용 Facebook 게시물 — 텍스트(이모지, 해시태그, @멘션 포함 가능)로만 게시물을 쓰고 배경 스타일을 적용해요. 이미지와 동영상은 넣을 수 없어요.
- Facebook 기본 배경 스타일 — Facebook이 제공하는 스타일 계열을 그대로 써요. 직접 올리는 이미지가 아니라 플랫폼 기본 배경이라 호환성이 가장 좋아요.
- 즉시 게시와 예약 게시 모두 지원 — 빠른 소식이든 캠페인 계획이든, 소셜 플래너의 즉시 게시와 예약 게시에서 모두 배경 스타일을 쓸 수 있어요.

### 이럴 때 쓰면 좋아요

- 시각적으로 더 강조하고 싶은 짧은 공지, 알림, 혜택
- 명언, 질문, 재미있는 문구처럼 브랜드 개성을 보여 주는 게시물
- 소셜 피드에서 눈에 띄는 행동 유도 문구

## 게시물 작성 화면의 배경 선택기

배경 선택기는 소셜 플래너 게시물 작성 화면에 들어 있어요. 글을 쓰다가 자연스럽게 배경을 고를 수 있어요. 채널에서 Facebook을 선택하면 **Text Background**(텍스트 배경) 옵션이 나타나요. 여기서 미리 만들어 둔 디자인을 실시간으로 넘겨 가며 볼 수 있어요.

- 채널에 맞춰 나타남 — **Text Background**는 채널 목록에서 Facebook을 선택했을 때만 보여요. 이 기능을 지원하지 않는 플랫폼과 헷갈리지 않아요.
- 프리셋 선택 — 단색, 그라데이션, 패턴 등 Facebook 기본 옵션과 같은 여러 프리셋 중에서 골라요.
- 즉시 확인 — 프리셋을 바꿀 때마다 실시간 미리보기가 바로 바뀌어서, 글에 가장 잘 어울리는 조합을 고르기 쉬워요.

### 활용 팁

- 글을 먼저 쓰고 여러 배경을 적용해 보세요. 핵심 메시지가 가장 잘 보이는 배경을 찾을 수 있어요.
- 한 캠페인 안에서는 배경을 일관되게 유지하세요. 예를 들어 깜짝 세일은 한 가지 색, 유용한 정보는 다른 색으로 정하면 피드에서 알아보기 쉬워요.

## 게시물 실시간 미리보기

게시 전에 배경 게시물이 어떻게 보일지 Facebook 스타일 목업으로 정확하게 확인할 수 있어요. 게시 후에 달라 보여서 놀랄 일이 줄고, 글을 읽기 좋게 다듬기도 쉬워져요.

- Facebook 스타일 레이아웃 — 미리보기는 텍스트 위치와 카드 전체 레이아웃까지 Facebook이 배경 게시물을 보여 주는 방식에 맞춰져 있어요. 소셜 플래너 안에서 최종 모습을 볼 수 있어요.
- 글꼴 크기 자동 조절 — 입력한 글의 양에 따라 글꼴 크기가 바뀌어요. 짧은 글은 크고 눈에 띄게, 긴 글은 공간에 맞게 조금 작게 보여요.
- 배경 변경 즉시 반영 — **Text Background** 선택을 바꾸면 미리보기가 바로 새로고침돼요. 여러 모습을 빠르게 비교할 수 있어요.

### 읽기 쉽게 쓰는 방법

- 짧고 임팩트 있게 쓰세요. 배경 게시물에는 짧은 문구가 가장 잘 어울려요.
- 줄 바꿈을 신경 써서 글 덩어리의 균형을 맞추세요.
- 해시태그와 @멘션이 읽기 쉽고 브랜드 분위기에 맞게 보이는지 다시 확인하세요.

## 스마트 검증과 자동 처리

Facebook이 지원하는 경우에만 배경이 쓰이도록 시스템이 확인해요. 미디어 등 배경 게시물이 제대로 작동하지 않는 상황에서는 배경이 자동으로 비활성화되거나 제거돼요.

- 텍스트 전용 게시물만 가능 — 배경은 Facebook 게시물에 텍스트만 있고 이미지나 동영상이 첨부되지 않았을 때만 쓸 수 있어요. Facebook의 배경 게시물 규칙과 같아요.
- 미디어가 있으면 자동 처리 — Facebook 게시물에 이미지, 동영상, 캐러셀 등 미디어를 첨부하면 **Text Background** 옵션이 자동으로 비활성화돼요. 지원하지 않는 조합을 설정할 수 없어요.
- 예약 게시물 편집 시 — 배경을 쓰던 예약 Facebook 게시물을 편집하다가 미디어를 추가하면, 게시 시점에 문제가 없도록 기존 배경 스타일이 자동으로 제거돼요.

이 검증으로 다음과 같은 문제를 막을 수 있어요.

- 배경과 이미지처럼 맞지 않는 조합 때문에 게시가 실패하거나 결과가 달라지는 문제
- 편집 화면에는 배경이 보이는데 게시할 때 Facebook이 배경을 없애 버려서 생기는 혼란

## Facebook 배경 텍스트 게시물 설정하기

Facebook 배경 텍스트 게시물은 평소 쓰던 소셜 플래너 워크플로우에 포함돼 있어요. Facebook 계정이 소셜 플래너에 연결돼 있으면 별도 활성화 없이 새 게시물부터 바로 배경을 쓸 수 있어요.

1. **마케팅 > 소셜 플래너**로 이동하세요.

   ![소셜 플래너 메뉴로 이동한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077087558/original/l7D5G-IdiDOJDm25e2usFzj438Y0m6ajiw.png?1785297832)

2. **새 게시물**을 클릭해 게시물 작성 화면을 여세요. 아직 Facebook 프로필이나 페이지를 연결하지 않았다면 먼저 **설정 > 연동**에서 연결하세요.

   ![새 게시물 버튼을 클릭한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077087598/original/2LPa7yxLKh3nSpaBskA0dMdbXvaQckc2bA.png?1785297917)

3. 소셜 채널 선택에서 소셜 플래너가 지원하는 Facebook 대상을 하나 이상 선택하세요. Facebook을 선택하면 조건에 맞는 게시물에 **Text Background** 옵션이 나타나요.

   ![Facebook 채널을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077087611/original/1vRvoxGI6nm09whvUbSbFt4V4F4mdKDDGA.png?1785297952)

4. 편집기에 게시물 내용을 입력하세요. 배경을 쓰려면 텍스트만 입력하고, 이 게시물에는 이미지나 동영상을 추가하지 마세요. 이모지, 해시태그, @멘션은 넣어도 돼요. 참여를 높이는 데 도움이 돼요.

   ![편집기에 텍스트를 입력한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077087651/original/c8DDbj6Bwo0bwEqxNXsPJH39DtAZkRo0lQ.png?1785298037)

5. 작성 화면에서 **Text Background**를 클릭하세요. 배경 프리셋 패널이 열려요.

   ![Text Background 옵션을 클릭한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077087669/original/dF9tGFNR8I7RoGHZU5hoOVsNgQe1eH1k2A.png?1785298062)

6. 여러 스타일을 둘러보고 마음에 드는 것을 클릭해 적용하세요. **실시간 미리보기** 패널이 바뀌는 것을 보면서 디자인마다 글이 어떻게 보이는지 확인해요.

7. **실시간 미리보기**에서 메시지가 분명하고 읽기 쉬우며 보기 좋은지 확인하세요. 필요하면 글 길이나 줄 바꿈을 고쳐서 읽기 편하게 다듬어요.

   ![실시간 미리보기로 게시물을 확인한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077087708/original/KzejTQAtFOYvVBQLoFcyYVWSqQpmpszBuw.png?1785298093)

8. **게시 또는 예약**을 진행하세요. 바로 게시하려면 **Post Now**(지금 게시)를 선택하고, 예약하려면 소셜 플래너 캘린더에서 날짜와 시간을 설정하세요. 저장하면 설정한 배경이 적용된 게시물이 소셜 플래너 캘린더에 표시돼요.

   ![게시 또는 예약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077087717/original/xWQBFLf3JnCz1YoT6Hw_YoZHT-CKdw_LBA.png?1785298117)
