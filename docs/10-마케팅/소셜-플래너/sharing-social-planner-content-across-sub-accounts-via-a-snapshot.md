# 스냅샷으로 서브 계정 간 소셜 플래너 콘텐츠 공유하기

**스냅샷**을 사용하면 에이전시 설정에서 소셜 캘린더를 원하는 서브 계정에 공유할 수 있어요. 소셜 플래너 콘텐츠를 여러 서브 계정에서 재사용할 때 쓰세요.

앞으로 기능이 더 추가될 예정이에요. 아이디어나 제안이 있으면 소셜 플래너 안에서 피드백으로 알려 주세요.

## 부모 서브 계정에서는 어떻게 되나요?

```
부모 서브 계정은 스냅샷의 원본입니다. 스냅샷을 만들어 낸 서브 계정이에요.
```

1. **마케팅** 탭 > **소셜 플래너**로 이동해요.
2. **게시글 작성**을 클릭한 다음 **CSV에서 업로드**를 선택해요.
3. 소셜을 선택해요. CSV 가져오기를 만들려면 이 선택이 필요해요.
4. CSV 목록으로 이동해요. CSV에는 다음과 같은 상태가 표시돼요.
   - **진행 중**: 시스템이 CSV 데이터를 처리하고 있어요.
   - **Review and Schedule**(검토 및 예약): CSV 데이터 처리가 끝난 상태예요. 스냅샷에는 이 상태의 CSV가 표시돼요.

## 에이전시 설정 > 스냅샷에서는 어떻게 되나요?

에이전시 관리자만 쓸 수 있어요.

1. **에이전시 설정** > **스냅샷**으로 이동해요.
2. **Refresh the snapshot**(스냅샷 새로 고침)을 하거나 **upload the snapshot**(스냅샷 업로드)을 해요.
3. 선택을 마치면 소셜 플래너 CSV 중 **Review and Schedule** 상태인 CSV가 표시돼요.

## 자식 서브 계정에서는 어떻게 되나요?

```
자식 서브 계정은 스냅샷을 불러와서 사용할 계정입니다.
```

1. **마케팅** > **소셜 플래너** > **CSV**(목록 보기)로 이동해요.
2. 목록 보기에 부모 서브 계정의 소셜 플래너 CSV가 나타나요.
3. 해당 CSV로 이동한 다음 **Select Social for scheduling the posts**(게시글을 예약할 소셜 선택)를 클릭해요.
4. 선택한 모든 소셜에 대해 CSV가 처리돼요.
5. CSV 데이터 처리가 끝나면 CSV에 **Review and Schedule** 옵션이 나타나요. 게시글을 확인한 뒤 소셜 캘린더로 가져올 수 있어요.
