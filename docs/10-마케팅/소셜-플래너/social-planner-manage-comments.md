# 소셜 플래너에서 댓글 관리하기

**소셜 플래너**에서 소셜 미디어 게시물에 달린 댓글을 바로 확인하고 관리할 수 있어요. Facebook, Instagram, LinkedIn, TikTok, 커뮤니티, Bluesky, Threads의 댓글 관리를 지원해요. 이 문서에서는 댓글 관리 사용법과 이 기능으로 할 수 있는 일, 제한 사항을 안내해요.

---

## 댓글 관리란?

**소셜 플래너**의 댓글 관리를 쓰면 게시물에 달린 댓글을 한 화면에서 보고 답글을 달 수 있어요. 여러 소셜 미디어 플랫폼을 오가지 않아도 돼요. 콘텐츠를 예약하고 계획하는 곳에서 바로 대화를 관리할 수 있어요. ▶ 영상 [8강 2부 10:26](https://www.youtube.com/watch?v=TNUzXx1UteQ&t=626s)

{% hint style="info" %}
현재는 **소셜 플래너**로 게시한 글의 댓글만 지원해요. Facebook, Instagram, LinkedIn, TikTok, 커뮤니티 등에서 직접 게시한 글의 댓글은 여기에 나타나지 않아요. 다른 소셜 플랫폼 지원은 준비 중이에요.
{% endhint %}

---

## 댓글 관리의 장점

- 한곳에서 모아 보기: 예약한 게시물과 함께 모든 댓글을 볼 수 있어요.
- 실시간 소통: 댓글에 좋아요를 누르고 답글을 달며 꾸준히 소통할 수 있어요.
- 대화 맥락 유지: 스레드(중첩) 답글로 더 깊은 대화를 이어 갈 수 있어요.
- 시간 절약: **소셜 플래너**를 벗어나지 않고 바로 답글을 달 수 있어요.
- 빠른 받은 댓글 정리: 선택한 플랫폼과 필터 화면에 있는 읽지 않은 댓글을 하나씩 확인하지 않고 한 번에 읽음으로 표시할 수 있어요.

---

## 댓글 관리에서 할 수 있는 일

아래 기능으로 매일 하는 소통을 더 빠르게 처리할 수 있어요. 대화를 정리해 두고, 중요한 댓글을 하이퍼클래스를 벗어나지 않고 챙길 수 있어요.

### 댓글에 답글 달기

최상위 댓글에는 **소셜 플래너**에서 바로 답글을 달 수 있어요. 작성자 이름, 이모지, GIF가 그대로 유지돼서 플랫폼에서 직접 쓰는 것과 비슷하게 느껴져요. 빠르고 브랜드에 맞는 답글은 팔로워와의 관계를 단단하게 하고, 추가 소통이나 DM으로 이어질 수 있어요.

### 댓글에 좋아요 누르기

좋아요를 누르면 팔로워에게 의견을 확인했고 고맙게 생각한다는 뜻을 전할 수 있어요. 누른 좋아요는 모두 Facebook에 기록되고 게시물 참여 지표에 반영돼서 도달 범위를 높이는 데 도움이 돼요.

### 모든 댓글 읽음으로 표시하기

**Mark All as Read**(모두 읽음으로 표시)를 쓰면 선택한 플랫폼과 적용 중인 필터 안의 읽지 않은 댓글을 모두 읽음으로 바꿀 수 있어요.

이 작업은 현재 화면의 읽지 않은 댓글 수를 지워요. 댓글이 삭제되는 것은 아니에요. 읽음으로 표시한 뒤에도 댓글을 계속 보고 답글을 달 수 있어요.

### 스레드 댓글에 답하기

스레드 답글을 쓰면 여러 사람이 나누는 대화를 깔끔하게 정리할 수 있어요. 부모 댓글 옆의 화살표를 클릭하면 하위 스레드를 보고 답할 수 있어서, 대화가 이어지는 바로 그 자리에 답글이 달려요.

### 스마트 필터(최신 / 상단)

받은 댓글 위에 있는 드롭다운으로 보기 방식을 바꿀 수 있어요.

- **최신**: 가장 최근 활동을 보여 줘서 새 질문을 놓치지 않아요.
- **상단**: Facebook의 '관련성 높은 순'으로 정렬해서 참여도가 높은 댓글을 먼저 보여 줘요.

### 답글에서 멘션 사용하기

"@"와 최소 세 글자를 입력하면 Facebook 페이지나 공개 프로필을 태그할 수 있어요. 일치하는 공개 페이지 목록이 나타나서, 하이퍼클래스를 벗어나지 않고 파트너를 소개하거나 고객에게 감사를 전할 수 있어요.

## 소셜 플래너에서 댓글 관리하는 방법

### 1단계: 소셜 플래너에서 댓글 열기

**마케팅 > 소셜 플래너 > 댓글**로 이동하세요.

![소셜 플래너 댓글 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055031108/original/Gmtm-H64JrgQ-1S8-I9JgiFJiqDdo_1mvg.png?1759342240)

### 2단계: 댓글 확인하고 소통하기

여기서 다음을 할 수 있어요.

- **소셜 플래너**로 게시한 글의 댓글 읽기
- 사용자에게 바로 답글 달기
- 댓글에 좋아요 누르기
- 답글에 이모지와 이미지 넣기
- 스레드(중첩) 댓글에 답글을 달아 더 깊은 대화 나누기

댓글을 더 크게 보려면 **더 보기**를 클릭하세요.

![더 보기로 확장한 댓글 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055031164/original/2LJ67QwXJJWIXlYmQoJDd6RV9RV1gewc_g.png?1759342324)

### 3단계: 최신 댓글과 상단 댓글 필터링하기

드롭다운 필터로 댓글을 보는 방식을 고르세요.

- **최신**: 가장 최근 댓글을 먼저 보여 줘요.
- **상단**: 참여도가 높거나 관련성이 높은 댓글을 위쪽에 보여 줘요.

![최신과 상단 필터 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055031537/original/BHewoQSIhZ9bPICI0i0KcFBxOyG6ztyx8g.png?1759342834)

### 4단계: 모든 댓글 읽음으로 표시하기

1. 관리할 플랫폼을 선택하세요.
2. 업데이트할 댓글에 맞게 필터를 적용하세요.
3. **Mark All as Read**를 클릭하세요.

![모두 읽음으로 표시 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076279093/original/nze3C2rABJeVZhK_5gkuhTf57SapaG6UDg.png?1784311720)

선택한 플랫폼과 적용 중인 필터 안의 읽지 않은 댓글이 모두 읽음으로 표시돼요. 해당 화면의 읽지 않은 댓글 수도 바로 사라져요. 기존 댓글은 그대로 남아 있고, 계속 보고 답글을 달 수 있어요.

## 플랫폼별 지원 기능

**소셜 플래너**의 댓글 관리는 Facebook, Instagram, LinkedIn, TikTok, 커뮤니티, Bluesky, Threads를 지원해요.

### Facebook

- **소셜 플래너**로 게시한 글의 댓글 보기
- 텍스트, 이모지, 이미지(최대 10MB)로 답글 달기
- 스레드 답글 지원(여러 단계)
- 댓글 좋아요
- "@" + 최소 3자를 입력해 검색하는 멘션 지원
- **최신** 또는 **상단**으로 댓글 필터링
- 답글에 이모지 사용 가능
- 이미지 업로드 지원(Facebook 제한에 따라 최대 10MB)
- **댓글 검색**(최소 3자)
- 숨기기/삭제 미지원
- API 지원
- 댓글 속 미디어(GIF, 썸네일)는 보이지만 클릭할 수 없음
- **소셜 플래너**로 게시한 글의 댓글만 지원

**제한 사항**

- 중첩 댓글 수는 표시되지 않아요(최상위 댓글 수만 표시돼요).
- 댓글 속 썸네일, 이미지, 동영상, GIF는 클릭할 수 없어요.
- 답글에 GIF, 스티커, 아바타를 추가하는 기능은 지원하지 않아요.
- 10MB를 넘는 이미지는 업로드할 수 없어요(Facebook API 제한).
- 검색은 최소 3자 이상 입력해야 해요.
- Facebook에서 직접 게시한 글의 댓글은 나타나지 않아요.
- 숨기기/삭제는 지원하지 않아요.

### Instagram

- **소셜 플래너**로 게시한 글의 댓글 보기
- 텍스트, 이모지, 이미지(최대 10MB)로 답글 달기
- 스레드 답글 지원
- 댓글 좋아요
- 정확한 @사용자이름을 직접 입력할 때만 멘션 지원(검색 불가)
- **최신** 또는 **상단**으로 댓글 필터링
- 답글에 이모지 사용 가능
- 이미지 업로드 지원(Instagram 제한에 따라 최대 10MB)
- **댓글 검색**(최소 3자)
- 숨기기/삭제 미지원
- Instagram 댓글은 API 지원 없음
- 댓글 속 미디어는 보이지만 클릭할 수 없음
- **소셜 플래너**로 게시한 글의 댓글만 지원

**제한 사항**

- 멘션은 검색을 지원하지 않아요. 정확한 @사용자이름을 직접 입력해야 해요(Instagram API 제한).
- 댓글 속 썸네일, 이미지, 동영상, GIF는 클릭할 수 없어요.
- 10MB를 넘는 이미지는 업로드할 수 없어요.
- 검색은 최소 3자 이상 입력해야 해요.
- 숨기기/삭제는 지원하지 않아요.
- Instagram 댓글 관리의 API 지원이 제한적이라 고급 작업은 할 수 없어요.
- Instagram에서 직접 게시한 글의 댓글은 나타나지 않아요.

### LinkedIn

- **소셜 플래너**로 게시한 LinkedIn 페이지 게시물의 댓글 보기
- 텍스트와 이모지로 답글 달기
- 스레드 답글 1단계까지 지원
- 댓글 좋아요
- 사용자 이름을 검색해 다른 LinkedIn 사용자 멘션
- Facebook, Instagram과 비슷한 댓글 필터(**최신**, **상단**)
- **댓글 검색**(최소 3자)
- 통합 받은 댓글 화면에서 모든 댓글 보기
- **소셜 플래너**로 게시한 LinkedIn 페이지 게시물 지원

**제한 사항**

- LinkedIn 페이지만 지원해요. 개인 프로필은 연결할 수 없어요(API 제한).
- 스레드 답글은 1단계까지만 가능해요.
- 답글에 이미지를 업로드할 수 없어요.
- 댓글 속 썸네일, 이미지, GIF, 동영상은 클릭할 수 없어요.
- LinkedIn에서 직접 게시한 글의 댓글은 **소셜 플래너**에 나타나지 않아요.
- 댓글 숨기기/삭제는 지원하지 않아요.
- 검색은 최소 3자 이상 입력해야 해요.
- 답글은 LinkedIn의 3,000자 제한 안에서 작성해야 해요.

### TikTok

- **소셜 플래너**로 게시한 글의 댓글 보기
- 텍스트와 이모지로 답글 달기
- 스레드 답글 1단계까지 지원
- 통합 받은 댓글 화면에서 모든 댓글 보기

**제한 사항**

- 댓글 관리는 TikTok 비즈니스 프로필에서만 지원해요.
- 댓글은 최대 150자까지 쓸 수 있어요.
- 답글에 미디어를 첨부할 수 없어요.
- 스레드 댓글에는 1단계까지만 답글을 달 수 있어요.

### 커뮤니티

- 커뮤니티 게시물의 댓글을 **소셜 플래너**에서 바로 보기
- 텍스트로 답글 달기
- 스레드 답글 1단계까지 지원
- 통합 받은 댓글 화면에서 모든 댓글 보기
- 답글에서 "@"로 커뮤니티 멤버 멘션
- 기본 플랫폼과 실시간으로 동기화해 최신 내용 반영

**제한 사항**

- 답글에 첨부 파일을 추가할 수 없어요.
- 코스 멘션과 이벤트 멘션은 지원하지 않아요.
- **소셜 플래너**에서는 댓글을 수정할 수 없어요.
- 댓글은 최대 8,000자까지 쓸 수 있어요.
- 스레드 댓글에는 1단계까지만 답글을 달 수 있어요.

### Bluesky

- **소셜 플래너**로 게시한 Bluesky 글의 댓글 보기
- 텍스트와 이모지로 답글 달기
- 스레드 답글 지원(최대 3단계까지 표시)

**제한 사항**

- 답글은 300자까지 쓸 수 있어요.
- 텍스트와 이모지만 지원해요(미디어 첨부 불가).
- 프로필 태그는 지원하지 않아요.
- 답글은 최대 3단계 깊이까지 표시돼요(전체 스레드는 내부에 저장돼요).
- 댓글은 최근 게시물 15개만 동기화돼요.
- 동기화는 6시간마다(하루 4번) 실행돼요.

### Threads

{% hint style="info" %}
이미 연결한 Threads 계정은 댓글 관리에 필요한 권한을 부여하려면 한 번 다시 연결해야 해요.
{% endhint %}

- **소셜 플래너**로 게시한 Threads 글의 댓글 보기
- 다음을 사용해 답글 달기
  - 텍스트
  - 이미지
  - 이모지
  - 위치 첨부
- 스레드 답글 1단계까지 지원
- 통합 받은 댓글 화면에서 모든 댓글 보기
- 웹훅을 이용한 실시간 댓글 동기화
- Facebook, Instagram, LinkedIn, TikTok, 커뮤니티, Bluesky와 함께 Threads 대화 관리

**제한 사항**

- **소셜 플래너**로 게시한 Threads 글만 지원해요.
- 스레드 답글은 1단계까지만 가능해요.
- 댓글 관리는 Threads API가 지원하는 연결된 Threads 비즈니스/프로페셔널 계정에서만 쓸 수 있어요.
- 댓글 숨기기/삭제는 지원하지 않아요.
- 검색은 최소 3자 이상 입력해야 해요.
- 답글에는 Threads 플랫폼의 글자 수 제한과 API 제한이 적용돼요.
- **소셜 플래너**에서 쓸 수 있는 기능은 Threads API가 지원하는 기능에 따라 달라요.

## YouTube

YouTube 댓글 관리를 쓰면 YouTube 동영상에 달린 댓글을 **소셜 플래너**에서 바로 보고 답글을 달 수 있어요. YouTube Studio로 이동하지 않고도 시청자와 소통하고, 답글을 달고, 대화를 따라갈 수 있어요.

### 할 수 있는 일

- YouTube 댓글 보기: **소셜 플래너**로 게시한 동영상에 달린 댓글을 볼 수 있어요.
- 댓글에 답글 달기: **소셜 플래너**의 **댓글** 페이지에서 시청자 댓글에 바로 답글을 달 수 있어요.
- 이모지 지원: 답글에 이모지를 넣어 더 생동감 있게 소통할 수 있어요.
- 스레드 답글: 중첩 답글 1단계까지 보고 답할 수 있어요.
- 댓글 자동 동기화: 댓글을 6시간마다 YouTube에서 자동으로 가져와요.
- 과거 댓글 동기화: 지원하는 동영상은 첫 동기화 때 기존 댓글과 답글을 가져와요.
- 통합 댓글 관리: YouTube 댓글을 Facebook, Instagram, LinkedIn, TikTok, 커뮤니티, Bluesky, Threads 댓글과 함께 관리할 수 있어요.

### YouTube 댓글 동기화 방식

YouTube는 댓글 업데이트용 웹훅을 제공하지 않아서, YouTube 댓글 관리는 주기적으로 확인하는 방식으로 댓글을 가져와요.

동기화는 다음과 같이 이루어져요.

**1. 첫 동기화(과거 댓글)**

YouTube 계정을 연결하면 첫 동기화가 실행돼요.

- **소셜 플래너**는 대상 동영상마다 답글을 포함해 가져올 수 있는 전체 댓글 기록을 가져와요.
- 댓글은 페이지 단위로 가져오며, 한 페이지에 100개씩이에요.
- 대상 동영상에 대해 가져오는 페이지 수에는 제한이 없어요.
- 첫 동기화는 연결한 YouTube 계정별로 최근 게시한 동영상 15개만 대상으로 해요.

{% hint style="warning" %}
대상 동영상은 전체 댓글 기록을 가져오지만, 최근 게시한 15개보다 오래된 동영상의 댓글은 첫 동기화 때도 동기화되지 않아요.
{% endhint %}

**2. 댓글 자동 업데이트**

첫 동기화 이후에는 다음과 같이 동작해요.

- **소셜 플래너**가 6시간마다 YouTube에서 새 댓글을 자동으로 확인해요.
- 새 댓글과 답글은 이렇게 예약된 동기화 주기에 가져와요.
- 업데이트가 실시간이 아니어서, YouTube에 올린 댓글이 바로 나타나지 않을 수 있어요.

**3. 동기화된 댓글 보고 관리하기**

댓글이 동기화되면 다음 경로에서 댓글을 보고 답글을 달 수 있어요.

**마케팅 > 소셜 플래너 > 댓글 > YouTube**

연결한 YouTube 계정을 선택하면 대상 동영상에 달린 댓글을 볼 수 있어요.

### 제한 사항

- 댓글 관리는 **소셜 플래너**로 게시한 동영상만 지원해요.
- YouTube에서 직접 게시한 동영상의 댓글은 지원하지 않아요.
- 연결한 YouTube 계정별로 최근 게시한 동영상 15개만 동기화 대상이에요.
- 더 오래된 동영상의 댓글은 첫 과거 댓글 동기화 때도 동기화되지 않아요.
- 첫 댓글 동기화는 한 페이지에 100개씩 가져오며, 대상 동영상의 페이지 수에는 제한이 없어요.
- 댓글 자동 동기화는 6시간마다 실행되며, 실시간 동기화는 지원하지 않아요.
- 댓글과 답글에는 텍스트와 이모지만 쓸 수 있어요.
- 댓글과 답글에 이미지, 동영상을 첨부할 수 없어요.
- 스레드 답글은 중첩 답글 1단계까지만 가능해요.
- 댓글 관리 기능은 YouTube API 제한을 따라요.

## 자주 묻는 질문

### 다른 플랫폼의 댓글도 볼 수 있나요?

네. **소셜 플래너**에서 Facebook, Instagram, LinkedIn, TikTok, 커뮤니티, Bluesky, YouTube, Threads의 댓글을 관리할 수 있어요. 다만 **소셜 플래너**로 게시한 글의 댓글만 여기에 나타나요.

### 각 플랫폼에서 직접 게시한 글의 댓글도 보이나요?

아니요. **소셜 플래너**로 게시한 글의 댓글만 여기에 나타나요.

### 댓글을 삭제하거나 숨길 수 있나요?

아니요. 댓글 관리에서는 삭제와 숨기기를 지원하지 않아요.

### 이미지와 이모지로 답글을 달 수 있나요?

이모지로 답글을 다는 것은 지원해요. 이미지는 플랫폼에 따라 달라요.
