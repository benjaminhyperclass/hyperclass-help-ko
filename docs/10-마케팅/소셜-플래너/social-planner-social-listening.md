# 소셜 플래너의 소셜 리스닝으로 트렌드 찾기

**소셜 플래너**(Social Planner)의 **소셜 리스닝** 탭에서는 여러 데이터 소스의 실시간 트렌드를 볼 수 있어요. 지금 뜨는 주제와 바이럴 콘텐츠를 찾아 콘텐츠 계획에 활용하세요.

## 소셜 리스닝이란?

소셜 리스닝은 온라인 대화, 트렌드, 문화적 신호를 추적하는 일이에요. 사람들이 무슨 말을 하는지뿐 아니라 왜 그런 말을 하는지도 살펴봐요. 이미 올라간 게시물에 반응하는 분석과 달리, 소셜 리스닝은 다음에 어떤 콘텐츠가 호응을 얻을지 미리 가늠하게 도와줘요. ▶ 영상 [8강 2부 13:23](https://www.youtube.com/watch?v=TNUzXx1UteQ&t=803s)

**소셜 플래너**의 소셜 리스닝은 여러 소스의 트렌드를 실시간으로 보여 줘요. 뜨고 있는 주제와 바이럴 콘텐츠를 정점에 오르기 전에 찾을 수 있어요.

## 소셜 리스닝을 쓰면 좋은 점

소셜 리스닝으로 다음과 같은 일을 할 수 있어요.

- Google 검색부터 TikTok에서 뜨는 노래, YouTube 인기 영상까지 트렌드를 일찍 포착해요.
- 사람들이 지금 어떤 이야기를 하는지, 그 뒤에 어떤 감정이 있는지 파악해요.
- 사람들이 실제로 관심을 두는 주제에 맞춰 콘텐츠 전략을 세워요.
- 실시간 신호를 바탕으로 더 똑똑한 캠페인을 만들어요.
- 감에 의존하지 않고 데이터로 콘텐츠를 결정해요.

## 화면에서 볼 수 있는 것

**소셜 리스닝** 탭을 열면 여러 데이터 소스로 트렌드를 찾아볼 수 있어요.

| 데이터 소스 | 알 수 있는 것 |
| --- | --- |
| Google Trends | 사람들이 지금 무엇을 검색하는지 |
| Pinterest Keywords | 뜨고 있는 콘텐츠 아이디어와 검색 트렌드 |
| Wikipedia Pageviews | 전 세계에서 관심이 커지는 주제 |
| TikTok Trends | 인기 급상승 노래, 인기 해시태그, 바이럴 사운드 |

## 소셜 리스닝 사용하기

여기서 찾은 내용은 콘텐츠 캘린더, 캠페인 아이디어, 실시간 게시물에 활용하세요.

### 1단계: 소셜 리스닝 탭 열기

**소셜 플래너**를 열고 **소셜 리스닝** 탭을 클릭하세요.

![소셜 플래너에서 소셜 리스닝 탭을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054106667/original/UDzmM1McCJFMjjpS3QcIt1QbOkL3DARMoQ.png?1758267619)

### 2단계: 데이터 소스 선택하기

해시태그, 키워드, 노래, 채널 같은 데이터 소스를 선택하세요. 선택한 항목이 강조 표시돼요. 세부 정보가 담긴 전체 목록은 스크롤해서 볼 수 있어요.

![데이터 소스를 선택해 전체 목록을 보는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054106732/original/vNj6WFAuC2_Hr-8da4GFcACejqsvcw7Upg.png?1758267682)

### 3단계: 날짜 필터로 범위 좁히기

**날짜 필터**를 사용하면 결과를 좁혀서 선택한 날짜의 트렌드를 확인할 수 있어요. 필터를 바꾸면 실시간 트렌드 통계가 자동으로 새로고침돼요.

![날짜 필터로 트렌드를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054106840/original/xhSG_uI98DmGshSzn5HY8y9QsOC-zxm7OQ.png?1758267800)

## 활용 팁

- 매주 또는 매일 확인하세요. 트렌드는 빠르게 바뀌니, 소셜 리스닝에서 10~15분씩 시간을 쓰세요.
- 우리 오디언스에 맞는 트렌드를 고르세요. 전 세계에서 유행하는 트렌드가 모두 브랜드에 어울리는 것은 아니에요. 브랜드와 잘 맞는 주제에 집중하세요.
- 빠르게 행동하세요. 소셜 리스닝에서 트렌드를 찾았다면 바로 소셜 플래너에서 게시물을 예약하세요.
- 키워드 옆에 **신규** 태그가 있는지 살펴보세요. 인기가 막 오르기 시작한 새 콘텐츠라는 뜻이에요.

## 어떤 소스를 쓰면 좋을까요?

| 시나리오 | 추천 소스 |
| --- | --- |
| "사람들이 지금 무엇을 검색하고 있나요?" | Google Trends |
| "사람들이 어떤 콘텐츠를 계획하고 저장하고 있나요?" | Pinterest Keywords |
| "넓게 보아 어떤 주제가 관심을 얻고 있나요?" | Wikipedia Pageviews |
| "TikTok에서 무엇이 바이럴되고 있나요?" | TikTok Trends |
| "어떤 크리에이터, 키워드, 영상이 뜨고 있나요?" | YouTube Insights |

{% hint style="info" %}
소셜 리스닝에 감정·주제 분석, 워드 클라우드, 경쟁사 분석, 스마트 알림, 맞춤 대시보드 같은 기능을 추가할 예정이에요. 업데이트를 기다려 주세요.
{% endhint %}

## 자주 묻는 질문

### 트렌드가 너무 광범위해 보여요. 어떻게 하면 되나요?
**날짜 필터**로 특정 기간을 지정하세요. 선택한 기간 안에서 뜨는 트렌드만 볼 수 있어요.

### 이 인사이트를 다운로드할 수 있나요?
아니요, 지금은 안 돼요. 소셜 리스닝은 현재 대시보드 안에서 보기만 할 수 있어요.

### 소셜 리스닝을 쓰려면 소셜 계정을 연결해야 하나요?
아니요. 소셜 리스닝은 Google, Pinterest, Wikipedia, TikTok, YouTube 같은 소스의 공개 트렌드 데이터를 가져와요.

### 소셜 리스닝으로 잠재 리드를 찾는 데 도움을 받을 수 있나요?
예, 도움이 돼요. 리드를 직접 발굴하는 도구는 아니에요. 하지만 타깃 오디언스가 참여하고 있는 대화, 인기 주제, 키워드를 찾을 수 있어요. 이를 바탕으로 알맞은 대화에 참여하고, 잠재 리드를 끌어들일 콘텐츠를 만들 수 있어요.
