# 소셜 플래너 링크 축약기로 URL 줄이고 클릭 추적하기

하이퍼클래스 **소셜 플래너**(Social Planner)의 **링크 축약기**를 쓰면 긴 URL을 짧게 줄이고, 캠페인 추적 파라미터를 붙이고, 링크 클릭 수까지 확인할 수 있어요. 이 문서에서는 단축 링크를 만드는 방법과 성과를 확인하는 방법을 안내해요.

## 링크 축약기란?

**링크 축약기**는 게시하는 글 속의 긴 URL을 짧은 링크로 바꿔 주는 소셜 플래너 기본 기능이에요. UTM 파라미터와 링크 클릭 추적도 지원해서 소셜 미디어 캠페인의 성과를 확인할 수 있어요.

블로그, 랜딩 페이지, 외부 웹사이트의 URL을 공유할 때 게시물이 더 읽기 쉽고 깔끔해져요.

## 링크 축약기의 장점

단축 링크를 쓰면 게시물이 읽기 쉬워지고, 캠페인 성과도 함께 파악할 수 있어요.

- 깔끔한 게시물: 긴 URL을 줄여서 게시물이 지저분해지지 않아요.
- 더 나은 사용 경험: 짧고 읽기 쉬운 링크로 보는 사람이 편해져요.
- 자동 축약: 긴 URL이면 짧은 버전을 자동으로 만들어 줘요.
- 게시물 미리보기: 단축 링크가 들어간 최종 게시물이 어떻게 보일지 확인할 수 있어요.
- 플랫폼 구분 없이 사용: 소셜 플래너에 연결된 모든 소셜 플랫폼에서 쓸 수 있어요.

## 소셜 플래너에서 링크 축약기 사용하기

게시물을 작성하면서 링크 축약기를 쓰는 순서예요. ▶ 영상 [8강 2부 24:45](https://www.youtube.com/watch?v=TNUzXx1UteQ&t=1485s)

1. 왼쪽 메뉴에서 **마케팅 > 소셜 플래너**로 이동해 **+ 새 게시물 > + 새 게시물 만들기** 버튼을 클릭하세요.

   ![새 게시물 만들기 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084847402/original/3rpPZPoJWf-6khzk-JU2LOvxoB2xKbb-Sw.png?1793713128)
2. 게시물 작성 화면에서 게시물을 올릴 소셜 미디어 계정을 선택하세요.

   ![게시할 소셜 미디어 계정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084847445/original/Rf-gse8gQTvAsJNRE_csQkXRR_EbXoXnpg.png?1793713155)
3. **콘텐츠** 입력란에 내용을 입력하세요.
4. 편집기 옆에 있는 **URL Shortener**(URL 축약기) 아이콘을 클릭하세요.

   ![URL 축약기 아이콘을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084847496/original/Wg28Cc2_yf0d7xqZ89NwVUJkSCljiTPAKg.png?1793713207)
5. **링크 이름**과 **대상 URL**을 입력하세요.
6. **추적 세부 정보**를 설정하세요.

   - **UTM Campaign**(utm\_campaign): 캠페인을 선택하거나 새로 만드세요.
   - **Custom UTM Parameters**(커스텀 UTM 파라미터): source, campaign 같은 값을 직접 추가하세요.
7. **링크 생성 및 삽입** 버튼을 클릭하세요.

   ![링크 생성 및 삽입 과정을 보여 주는 화면 녹화](https://jumpshare.com/share/FwmggfzC0ZzUxkhb5QCH+/GIF+Recording+2025-12-02+at+9.18.40+PM.gif)
8. 링크가 삽입되면 다음처럼 표시돼요.

   - **게시물 미리보기** 영역에는 URL이 짧게 줄어든 모습으로 나와요.
   - 콘텐츠 입력란에는 원래의 긴 URL이 그대로 남아 있어요.
9. 게시물을 확인한 뒤 **게시 또는 예약**을 선택해 바로 게시하거나, 나중에 보내도록 예약하세요.

   ![게시 또는 예약을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084847847/original/2uhZ5TwoprJoLWYR6Apt4Wq471t1Gqm-IA.png?1793713375)

## 알아 두세요

단축 링크와 추적 파라미터가 어떻게 동작하는지 알아 두면 캠페인 리포트를 더 정확하게 볼 수 있어요.

- 지원 링크: 소셜 플래너에서 만든 단축 링크에는 기본 URL 추적 기능을 쓸 수 있어요.
- UTM 파라미터: UTM 태그는 호환되는 분석 도구에서 캠페인 트래픽을 구분하는 데 쓰여요. 소셜 플래너의 클릭 추적과는 별개예요.
- 자동 생성 단축 URL: 단축 URL은 자동으로 만들어지며, 현재는 직접 바꿀 수 없어요.
- 링크 미리보기: 편집기에는 원래 URL이 남아 있지만, 게시된 글에는 단축 링크가 나와요.
- 외부 축약 서비스: 다른 서비스에서 만든 단축 링크를 직접 붙여 넣을 수는 있지만, 소셜 플래너의 기본 URL 추적 대상은 아니에요.
- 전환 추적: 링크 클릭만으로는 리드, 구매 등 웹사이트 전환이 자동으로 측정되지 않아요.

## 통계에서 링크 추적 확인하기

소셜 플래너의 **통계** 페이지에서 링크별 성과 분석을 바로 볼 수 있어요. 게시물에 넣은 링크를 줄이는 데서 끝나지 않고, 게시한 뒤 링크 성과까지 확인할 수 있어요.

링크 축약기는 게시물 미리보기와 최종 게시물에서 긴 URL을 계속 짧게 보여 줘요. URL 추적을 쓰면 다음과 같이 할 수 있어요.

- 단축 링크와 긴 URL이 모두 성과 분석에 나타나요.
- 게시하는 모든 링크가 자동으로 추적돼요.
- 클릭 추적을 위해 따로 할 일은 없어요. 게시물이 올라가는 순간부터 시작돼요.
- **캠페인 이름**으로 같은 링크를 쓰는 여러 게시물을 묶어서 볼 수 있어요.

{% hint style="info" %}
소셜 플래너에서 만든 링크만 **통계** 페이지에 표시돼요.
{% endhint %}

### 링크 클릭 분석

소셜 플래너로 공유한 모든 URL의 성과를 측정할 수 있어요. 다음 항목을 확인할 수 있어요.

- 단축 URL 또는 원본 URL별 총 클릭 수
- 플랫폼별 성과(Facebook, Instagram, LinkedIn 등)
- 시간에 따른 추이

![링크 클릭 분석 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064027182/original/lYr6EJeFMIR9LndS7JUG-HORObUbEW2T3w.jpeg?1770059860)

### 캠페인 추적

게시물을 작성할 때 링크에 **캠페인 이름**을 지정할 수 있어요. 같은 링크와 같은 캠페인을 쓴 게시물은 분석에서 한데 묶여서, 게시물과 채널별 성과를 비교하고 파악하기 쉬워요.

![링크에 캠페인 이름을 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064027201/original/t5C3wqeoszEUkOxb9jxesYmINTVc4l04dQ.png?1770059904)

### 필터와 정렬

**마케팅 > 소셜 플래너 > 통계 > URL Tracking**(URL 추적)에서 **상위 성과**와 **Low performing**(하위 성과) 기준으로 필터링할 수 있어요.

### URL 빠른 미리보기

URL을 선택하면 미리보기 패널이 열려서, 지금 분석하는 링크가 어떤 링크인지 바로 확인할 수 있어요.

## 자주 묻는 질문

### 소셜 게시물에는 긴 링크와 짧은 링크 중 어느 쪽이 표시되나요?

게시된 글에는 단축 링크가 표시돼요. 긴 URL은 콘텐츠 편집기에서만 볼 수 있어요.

### 링크 축약기를 쓸 때 UTM이 왜 중요한가요?

UTM 없이 링크 축약기를 쓰면 이런 점이 아쉬워요.

- 분석 도구에서 트래픽이 "direct"나 일반 "referral"로만 보일 수 있어요.
- 다음과 같은 경우의 성과를 쉽게 구분할 수 없어요.

  - Facebook 광고와 Facebook 일반 게시물
  - 이메일 상단 링크와 하단 링크
  - 인플루언서 A와 인플루언서 B

UTM과 함께 링크 축약기를 쓰면 이런 점이 좋아요.

- 다음을 할 수 있어요.

  - GA 등 다른 도구에서 캠페인을 제대로 추적해요.
  - 채널과 크리에이티브별 성과를 비교해요.
  - 어떤 링크와 위치가 효과가 있는지 확인해요.

축약기는 UTM이 잔뜩 붙은 긴 URL을 깔끔하고 클릭하기 좋게 만들어 주고, 실제 리포팅은 UTM 태그가 맡아요.

### 단축 링크를 직접 바꾸거나 이름을 정할 수 있나요?

아직은 안 돼요. 단축 링크는 현재 자동으로 만들어지며 편집할 수 없어요.

### 링크 축약기는 모든 소셜 플랫폼에서 쓸 수 있나요?

네, 소셜 플래너에서 지원하는 Facebook, Instagram, LinkedIn 등 모든 소셜 플랫폼에 단축 링크가 표시돼요.

### Bitly 같은 외부 링크 축약 서비스를 계속 써도 되나요?

네, 원한다면 다른 서비스에서 만든 단축 링크를 직접 추가해서 쓸 수 있어요.
