# 소셜 플래너 — Facebook 게시물 동기화(Facebook Post Sync)

이미 올려 둔 Facebook 게시물을 **소셜 플래너**로 가져와, 지난 콘텐츠와 성과를 한곳에서 볼 수 있는 기능이에요. 이 문서에서는 기능의 역할, 동기화되는 항목, 설정 방법, 동기화된 게시물과 성과 데이터를 확인하는 위치를 안내해요.

{% hint style="info" %}
이 기능은 현재 **베타** 단계예요. 서브 계정에서 사용하려면 **설정 > 실험실**로 이동하세요. **Facebook Post Sync**(Facebook 게시물 동기화)를 검색한 뒤 서브 계정에서 기능을 켜세요.
{% endhint %}

## 소셜 플래너의 Facebook 게시물 동기화란?

Facebook 게시물 동기화를 켜면 하이퍼클래스가 Facebook 페이지에 이미 올라간 게시물을 **소셜 플래너**로 가져와요. 새로 예약했거나 게시한 글과 함께 지난 콘텐츠도 보고, 관리하고, 분석할 수 있어요. 덕분에 **소셜 플래너**가 소셜 게시와 분석의 기준이 되는 곳이 돼요. 이 기능을 쓰려면 Facebook 계정이 연결되어 있어야 해요.

## 이 기능의 장점

- 게시물을 한곳에서 관리해요: Facebook에서 지난 콘텐츠를 따로 관리하지 않고 **소셜 플래너** 안에서 볼 수 있어요.
- 다시 만들 필요가 없어요: 최근 게시물을 하나씩 새로 만들지 않아도 **소셜 플래너**로 가져올 수 있어요.
- 성과를 더 잘 볼 수 있어요: 동기화된 게시물의 인사이트를 **통계**에서 확인해 지난 콘텐츠의 성과를 파악할 수 있어요.
- 리포트가 더 정확해져요: Facebook 게시 이력이 하나의 리포트 흐름 안에 더 많이 모여요.
- 시작이 빨라져요: 새 로케이션이나 고객사를 설정할 때 계정을 연결하고 최근 게시 이력을 바로 가져올 수 있어요.

## 동기화 설정과 동작 방식

동기화를 켠 뒤 보이는 내용은 몇 가지 설정과 플랫폼 동작에 따라 달라져요. 특히 처음 가져올 때와 이후 새로고침 때 차이가 있어요.

- Facebook 게시물 동기화는 연결된 Facebook 페이지에서만 작동해요.
- 기본 동기화 범위는 최근 30일 동안의 게시물이에요.
- 첫 동기화에서는 가져올 수 있는 경우 그보다 오래된 게시물을 더 가져오기도 해요.
- 설정이 끝나면 동기화가 백그라운드에서 자동으로 계속돼요.
- 인사이트는 실시간이 아니라 24시간마다 새로고침돼요.
- 권한이 만료되면 Facebook 연결을 다시 해야 할 수 있어요.

## 동기화되는 항목

Facebook 게시물 동기화는 최근 Facebook 페이지 콘텐츠를 가져오고, 지원하는 미디어를 자동으로 처리해요. 그래서 기존 게시물을 **소셜 플래너**에서 볼 수 있어요.

- 최근 30일 동안의 게시물이 **소셜 플래너**로 동기화돼요.
- 게시물은 UTC 시간 기준으로 오늘까지 동기화돼요.
- 첫 동기화에서는 가져올 수 있는 경우 더 오래된 게시물도 가져와요.
- 텍스트, 이미지, 동영상을 지원해요.
- 미디어는 가져오는 중에 자동으로 처리돼요.
- 미디어 처리는 일괄 처리 방식이라 가져오기가 더 매끄럽게 진행돼요.
- 동영상 동기화는 플랫폼 한도 안에서 지원돼요.

## Facebook 게시물 동기화 켜기

Facebook 계정이 연결되어 있고 동기화가 제대로 켜져 있어야 지난 게시물을 끊김 없이 가져올 수 있어요.

### 방법 1: 소셜 계정을 연결하면서 동기화 켜기

Facebook 계정을 연결하는 중에 바로 게시물 동기화를 켤 수 있어요.

1. **마케팅 > 소셜 플래너**로 이동하세요.
2. **+ Socials**(소셜 추가)를 클릭하세요.

   ![+ Socials 버튼](https://jumpshare.com/share/aS1QNSBzd7cJbEF07JA2+/Screen+Shot+2026-04-21+at+18.43.03.png)
3. **Connect Socials**(소셜 연결) 팝업에서 **Sync Posts Automatically**(게시물 자동 동기화) 토글을 켜세요.
4. **Facebook 연결**을 클릭하고 계정 연결을 마치세요.
5. 켜고 나면 **소셜 플래너**가 Facebook 게시물을 자동으로 동기화하기 시작해요.

   ![게시물 자동 동기화 토글을 켠 화면](https://jumpshare.com/share/o8MPHuGY7b6deIXrNwGg+/Screen+Shot+2026-04-21+at+18.45.54.png)

### 방법 2: 소셜 플래너 설정에서 동기화 켜기

Facebook 계정이 이미 연결되어 있다면 나중에 게시물 동기화를 켤 수 있어요.

1. **마케팅 > 소셜 플래너**로 이동하세요.
2. **설정**을 클릭하세요.

   ![소셜 플래너의 설정 메뉴](https://jumpshare.com/share/Ce1hHjIktHaej7yOtI4t+/Screen+Shot+2026-04-21+at+19.18.59.png)
3. **소셜 계정 > Facebook**으로 이동하세요.
4. 동기화할 페이지의 **Sync Posts**(게시물 동기화) 토글을 켜세요.
5. 시스템이 백그라운드에서 게시물 동기화를 시작해요.

   ![페이지별 게시물 동기화 토글](https://jumpshare.com/share/83seeVdXPYGc55x8fyXd+/Screen+Shot+2026-04-21+at+19.21.48.png)
6. 동기화가 켜지면 **플래너**를 열어 동기화된 게시물을 확인하세요.

   ![플래너에서 동기화된 게시물 확인](https://jumpshare.com/share/GQQiZkl6Xaf3hfTrGWHp+/Screen+Shot+2026-04-21+at+18.47.47.png)
7. **통계**를 열어 동기화된 성과 데이터를 확인하세요.

   ![통계에서 동기화된 성과 데이터 확인](https://jumpshare.com/share/QYHEnVX545BjQTd6rHmD+/Screen+Shot+2026-04-21+at+18.50.09.png)
8. 연결 끊김이나 액세스 만료 메시지가 보이면 안내에 따라 다시 연결해서 동기화를 이어 가세요.

   ![연결 끊김 또는 액세스 만료 안내](https://jumpshare.com/share/IiUOWrWI9oXjXSiip4YM+/Screen+Shot+2026-04-21+at+18.51.09.png)

## 자주 묻는 질문

### Facebook 게시물은 얼마나 오래된 것까지 동기화되나요?
**소셜 플래너**는 최근 30일 동안의 Facebook 게시물을 자동으로 동기화해요. 플랫폼에서 지원하는 경우에는 첫 동기화 때 더 오래된 게시물까지 가져오기도 해요.

### 동기화된 게시물은 얼마나 자주 업데이트되나요?
게시물 인사이트와 분석 데이터는 24시간마다 새로고침돼요. Facebook API 한도를 지키면서 데이터를 최신 상태로 유지하기 위해서예요.

### Facebook 계정 연결이 끊기면 어떻게 되나요?
Facebook 연결이 만료되면 동기화가 일시 중지돼요. **소셜 플래너**에 다시 연결하라는 안내가 보이는데, 계정을 다시 연결하면 동기화가 이어져요.

### 나중에 게시물 동기화를 끌 수 있나요?
네. **소셜 플래너 설정**에서 **Sync Posts Automatically** 토글을 언제든 끌 수 있어요. 끄면 이후 동기화는 멈추지만, 이미 가져온 게시물은 삭제되지 않아요.
### 어떤 종류의 Facebook 콘텐츠를 지원하나요?
텍스트, 이미지, 동영상을 동기화할 수 있어요.
