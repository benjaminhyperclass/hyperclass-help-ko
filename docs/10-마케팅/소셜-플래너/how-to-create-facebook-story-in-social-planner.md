# 소셜 플래너에서 Facebook 스토리 만들기

**소셜 플래너**(Social Planner)에서 Facebook 스토리를 만들고 예약하는 방법과 파일 조건을 안내해요.

Facebook 스토리는 20초 길이의 짧은 동영상이나 5초 동안 보이는 사진으로, 24시간이 지나면 사라져요. 이제 소셜 플래너에서 피드, 스토리, 릴스 세 가지 형식으로 Facebook에 게시할 수 있어요.

## 소셜 플래너에서 Facebook 스토리 만드는 방법

1. **마케팅 > 소셜 플래너**로 이동하세요.
2. **Facebook 페이지 연결**을 눌러 Facebook 페이지를 연결하세요.
3. **New Post**(새 게시글)를 누르고, 게시글 작성 창에서 이미지나 동영상을 추가하세요.
   ![게시글 작성 창에서 이미지 또는 동영상 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046284119/original/3yNNd54DQHBSx7cNKVS8AombOzas0D6M-A.jpeg?1746652681)
4. 드롭다운에서 게시할 소셜 계정(Facebook 페이지)을 선택하고 게시글 내용을 입력하세요.
5. 소셜 플래너에서 Facebook 스토리가 올라갈 시간을 예약하세요.

![Facebook 스토리 예약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046284118/original/DOAB_Y482iusB-zeIyJOPEWUHkTmd31DEA.jpeg?1746652681)

## Facebook 스토리 파일 조건

1. Facebook 스토리에는 이미지 또는 동영상을 하나만 추가할 수 있어요.
2. 이미지는 JPEG, PNG, GIF 형식이어야 하고, 파일 크기는 최대 4MB예요.
3. 동영상은 모든 형식을 사용할 수 있어요. 파일 크기는 1GB까지, 길이는 3초 이상 90초 이하, 최소 해상도는 540\*960 px예요.
4. Facebook 스토리는 썸네일과 OG 메타 태그를 지원하지 않아요.
