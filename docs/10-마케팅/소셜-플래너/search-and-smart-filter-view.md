# 소셜 플래너에서 검색과 스마트 필터 뷰 사용하기

**소셜 플래너**(Social Planner)에서 검색과 스마트 필터 뷰를 사용해 게시물을 빠르게 찾는 방법을 알려 드려요. 자주 쓰는 필터 조합을 뷰로 저장해 두면 같은 작업을 반복할 때 편해요.

## 검색과 스마트 필터 뷰란?

검색과 스마트 필터 뷰는 **소셜 플래너**에서 소셜 미디어 콘텐츠를 정리하고 관리하는 데 쓰는 기능이에요. 키워드로 게시물 내용을 바로 검색할 수 있어요. 게시물 상태, 채널, 카테고리 같은 조건으로 필터를 만들어 뷰로 저장해 두고 다시 쓸 수도 있어요. 스크롤하며 찾는 시간을 줄이고, 중요한 콘텐츠를 바로 처리할 수 있어요.

## 검색과 스마트 필터 뷰의 장점

검색과 필터를 쓰면 게시물을 일일이 분류하지 않아도 돼요.

- 게시물 내용에 있는 키워드로 게시물을 빠르게 찾아요.
- 여러 필터를 조합해 원하는 조건의 게시물만 모아 봐요.
- 필터 조합을 뷰로 저장해 두고 바로 불러와요.
- 콘텐츠 전략이 바뀌면 저장한 뷰도 그에 맞게 수정해요.
- **임시 저장**, **게시됨**, **예약됨** 같은 게시물 유형별로 모아 봐요.
- 플랫폼, 카테고리 등 여러 기준으로 필터링해요. 저장 뷰는 최대 4개까지 지원해요.

## 소셜 플래너에서 검색과 필터 뷰 사용하기

아래 순서대로 따라 해 보세요.

1. 왼쪽 메뉴에서 **마케팅**(Marketing)을 클릭하세요.
2. **소셜 플래너**를 클릭하세요.
3. **목록 보기** 탭으로 전환하세요. **캘린더** 옆에 있어요.
4. 게시물 목록 위쪽의 **검색** 창을 사용하세요.
   - 게시물 내용에 들어 있는 키워드나 문구를 입력하세요.
   - 일치하는 결과가 바로 표시돼요.

   <!-- 스크린샷 추가: 목록 보기에서 검색 창에 키워드를 입력하고 아래에 필터링된 결과가 표시된 화면 -->

5. **필터** 버튼을 클릭해 필터 조건을 적용하세요.
   - 상태, 채널, 카테고리 등을 고를 수 있어요.
6. 필터 조합을 선택했으면 **Save as New View**(새 뷰로 저장)를 클릭하세요.
   - 뷰 이름을 입력하세요. 예: "임시 저장 Instagram 게시물"
   - 저장한 뷰는 필터 뷰 드롭다운에서 바로 선택할 수 있어요.

   <!-- 스크린샷 추가: 여러 필터를 선택한 필터 패널과 Save as New View 옵션이 보이는 화면 -->

7. 저장한 뷰를 사용하려면 다음과 같이 하세요.
   - **필터** 옆의 드롭다운을 클릭하세요.
   - 사용할 뷰를 선택하세요.
   - 선택한 필터가 적용되어 목록이 자동으로 바뀌어요.
8. 필요에 따라 저장한 뷰를 **편집**하거나 **이름 변경**, **삭제**할 수도 있어요.

{% hint style="info" %}
저장할 수 있는 필터 뷰는 계정당 최대 4개예요.
{% endhint %}

## 게시물 내용 검색

게시물 본문에 있는 키워드로 게시물을 빠르게 찾을 수 있어요.

게시물이 많을 때 특히 유용해요. 여러 페이지를 넘겨 보지 않아도 키워드만 입력하면 일치하는 게시물이 실시간으로 나타나요.

## 저장된 필터 뷰

저장된 필터 뷰는 반복되는 작업에 맞춰 콘텐츠를 정리해 줘요. 예를 들어 임시 저장 게시물을 검토하거나 특정 플랫폼의 예약된 게시물을 확인할 때 쓰면 좋아요.

카테고리, 상태, 플랫폼처럼 여러 필터 조건을 조합해 뷰를 만들어 두세요. **소셜 플래너**를 열 때마다 같은 필터를 다시 설정하지 않아도 돼요.

저장된 뷰로 할 수 있는 일은 다음과 같아요.

- 뷰를 최대 4개까지 만들 수 있어요.
- 필터 조합을 바꾸거나 저장한 뷰의 이름을 바꿀 수 있어요.
- 드롭다운으로 뷰를 빠르게 전환해 콘텐츠를 관리할 수 있어요.

## 자주 묻는 질문

### 소셜 플래너에서 필터 뷰를 몇 개까지 저장할 수 있나요?
계정당 최대 4개까지 저장할 수 있어요.

### 저장한 뷰를 편집하거나 이름을 바꿀 수 있나요?
네, 저장한 뷰는 수정할 수 있어요. 뷰를 클릭한 다음 **편집** 또는 **이름 변경** 옵션을 사용해 바꾸세요.

### 어떤 게시물 내용을 검색할 수 있나요?
캡션, 설명, 텍스트 필드 같은 게시물 내용을 검색해요.

### 저장한 필터 뷰를 삭제할 수 있나요?
네, 저장한 뷰를 선택하고 **삭제** 아이콘을 클릭하면 삭제돼요.

### 저장한 뷰가 팀원과 공유되나요?
아니요, 저장한 뷰는 현재 사용자별로 저장되며 다른 계정과 공유되지 않아요.
