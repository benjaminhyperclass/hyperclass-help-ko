# 소셜 플래너 이메일 알림 설정

소셜 플래너 알림은 계정 만료, 게시물 승인·반려, 게시 실패 소식을 팀에 알려 줘요. 이 문서에서는 알림을 켜고, 이메일 템플릿을 고르고, 받는 사람과 알림 빈도를 설정하는 방법을 안내해요.

---

## 소셜 플래너 알림이란?

소셜 플래너 알림은 계정과 게시에 관한 중요한 일이 생겼을 때 보내는 이메일이에요. 다음과 같은 경우에 해당하는 사용자에게 알려 줘요.

- 소셜 계정 토큰이 곧 만료되거나 이미 만료됐을 때
- 게시물에 승인이 필요할 때
- 예약된 게시물이 승인·반려되거나 게시에 실패했을 때

소셜 플래너에는 알림 유형이 6가지 있어요.

- **Account Pre-Expiry**(계정 만료 예정): 연결된 소셜 계정의 토큰이 만료되기 전에 선택한 사용자에게 알려 줘요.
- **Account Expired**(계정 만료됨): 연결된 소셜 계정의 토큰이 만료되면 선택한 사용자에게 알려 줘요.
- **Request for Post Approval**(게시물 승인 요청): 예약 게시물이 승인 요청으로 제출되면 승인자에게 알려 줘요.
- **Approved Post**(승인된 게시물): 예약 게시물이 승인되면 작성자에게 알려 줘요.
- **Rejected Post**(반려된 게시물): 예약 게시물이 반려되면 작성자에게 알려 줘요. 반려 코멘트도 함께 보내요.
- **Post Failed**(게시 실패): 예약 게시물의 게시에 실패하면 선택한 사용자에게 알려 줘요. 실패 사유도 함께 보내요.

알림 유형마다 설정할 수 있는 항목이 달라요. 어떤 항목을 설정할 수 있는지 알아 두면 알림마다 알맞은 사용자와 목적에 맞게 구성할 수 있어요.

| 알림 | 활성화/비활성화 | 이메일 템플릿 | 알림 받을 사용자 | 알림 빈도 |
| --- | --- | --- | --- | --- |
| **Account Pre-Expiry** | 예 | 예 | 예 | 예 |
| **Account Expired** | 예 | 예 | 예 | 예 |
| **Request for Post Approval** | 예 | 예 | 아니요 | 아니요 |
| **Approved Post** | 예 | 예 | 아니요 | 아니요 |
| **Rejected Post** | 예 | 예 | 아니요 | 아니요 |

## 알림 설정하기

알림을 알맞게 설정하면 꼭 확인해야 할 계정·게시 소식을 알맞은 사용자가 이메일로 받을 수 있어요. 알림 설정은 소셜 플래너에서 바로 관리해요. ▶ 영상 [8강 2부 14:32](https://www.youtube.com/watch?v=TNUzXx1UteQ&t=872s)

1. **마케팅 > 소셜 플래너**로 이동하세요.
2. 필요한 소셜 계정이 연결되어 있는지 확인하세요.

   ![소셜 플래너에서 연결된 소셜 계정 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085156566/original/MWPomN2YMPlMWlY9Pe6HsPf2rDlcsWqxyw.png?1793979839)
3. **설정**을 클릭하세요.

   ![소셜 플래너 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085156633/original/TJjKkb6N55nnnsnrM0YhrY9O3JmmILUFhw.png?1793979887)
4. 왼쪽 메뉴에서 **알림**을 선택하세요.
5. 설정하려는 알림을 찾으세요.
6. **상태** 토글을 눌러 알림을 켜거나 끄세요.
7. **Action**(작업) 열의 연필 아이콘을 클릭해 해당 알림에서 설정할 수 있는 항목을 여세요.
8. 항목을 설정하세요.
9. **변경사항 저장**을 클릭하세요.

   ![알림 설정 후 변경사항 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085156676/original/OwJ__Hg8MeFkPZQjU5st1e3zEQJktJHfQw.png?1793979927)

### Account Pre-Expiry 알림 설정

**Account Pre-Expiry** 알림에서는 미리 알림을 받을 사용자와 알림을 다시 보낼 빈도를 정할 수 있어요.

1. **Account Pre-Expiry**를 켜세요.
2. 연필 아이콘을 클릭해 설정 화면을 여세요.
3. **Users to Notify**(알림 받을 사용자) 옵션 아래의 **+** 버튼을 클릭하고, 이메일을 받을 사용자를 선택하세요.
4. 선택한 사용자에게 알림을 다시 보낼 빈도를 **알림 빈도**에서 선택하세요.
5. 사용할 **이메일 템플릿**을 선택하세요. 기본 템플릿이 자동으로 선택돼 있고, 이미 만들어 둔 사용자 지정 이메일 템플릿을 고를 수도 있어요.
6. **변경사항 저장**을 클릭하세요.

   ![Account Pre-Expiry 알림 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085156793/original/sy5V9Bxk5YHLKaZpUPLubAN9NhdJr0Jakw.png?1793979988)

### Account Expired 알림 설정

**Account Expired** 알림에서도 받는 사람과 알림 빈도를 정할 수 있어요. 그래서 연결이 만료된 뒤에도 알맞은 사용자가 계속 알림을 받을 수 있어요.

1. **Account Expired**를 켜세요.
2. 연필 아이콘을 클릭해 설정 화면을 여세요.
3. 알림을 받을 사용자를 선택하세요.
4. **알림 빈도**를 선택하세요.
5. **이메일 템플릿**을 선택하세요.
6. **변경사항 저장**을 클릭하세요.

   ![Account Expired 알림 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085156811/original/UphVOwOHG0u26FzO63qeiZcbG7SpvolkAA.png?1793980016)

### 게시물 승인 알림 설정

**Request for Post Approval**, **Approved Post**, **Rejected Post** 알림은 승인 흐름에 따라 받는 사람이 정해져 있어요. 그래서 받는 사람이나 알림 빈도를 직접 고르지 않고, 알림을 켜고 끄는 것과 이메일 템플릿만 설정해요.

각 알림마다 다음 순서로 설정하세요.

1. **상태** 토글로 알림을 켜세요.
2. 연필 아이콘을 클릭하세요.
3. 사용할 이메일 템플릿을 선택하세요.
4. **변경사항 저장**을 클릭하세요.

아래 알림에도 같은 순서를 반복하세요.

- Request for Post Approval
- Approved Post
- Rejected Post

![게시물 승인 알림 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085157033/original/GYC80ug6PWIzR0QX7sIZVHyWpMbXbtdW_w.png?1793980122)

### Post Failed 알림 설정

**Post Failed** 알림은 예약 게시물을 게시하지 못했을 때 선택한 사용자에게 보낼 수 있어요. 내용을 확인하고 조치할 수 있는 사용자를 받는 사람으로 정해 두면 게시 실패를 놓치지 않아요.

1. **Post Failed**를 켜세요.
2. 연필 아이콘을 클릭하세요.
3. 게시에 실패했을 때 이메일로 알림을 받을 사용자를 선택하세요.
4. **이메일 템플릿**을 선택하세요.
5. **변경사항 저장**을 클릭하세요.

![Post Failed 알림 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085157119/original/cUyjuvL37-NKnM1HXiMuUR0J4i9S1xKNWQ.png?1793980160)

## 자주 묻는 질문

### 게시물 승인 알림은 왜 받는 사람을 고를 수 없나요?
승인 알림의 받는 사람은 승인 흐름에 따라 자동으로 정해져요. 알림 설정에서는 알림을 켜고 끄는 것과 이메일 템플릿 선택만 할 수 있어요.

### 기본 이메일 템플릿 미리보기가 비어 있어요.
기본 알림 템플릿은 하이퍼클래스가 관리하고, 서브 계정의 **이메일 템플릿** 목록에는 저장되지 않아요. 그래서 미리보기가 비어 있는 것이 정상이에요. 기본 알림을 보내는 데는 문제가 없어요.

### 계정 만료 알림을 얼마나 자주 받을지 바꿀 수 있나요?
네, 바꿀 수 있어요. **Account Pre-Expiry**와 **Account Expired** 알림은 알림 빈도를 설정할 수 있어요. 다른 알림 유형에는 이 설정이 없어요.

### 승인자가 이메일 알림을 받지 못했어요.
**소셜 플래너 설정 > 알림**에서 **Request for Post Approval**이 켜져 있는지 확인하세요. 게시물을 제출할 때 알맞은 승인자를 지정했는지도 확인하세요.

### 게시 실패 알림을 받았어요. 어떻게 해야 하나요?
**소셜 플래너**를 열어 실패한 게시물을 찾고 실패 사유를 확인하세요. 다시 게시하기 전에 연결된 계정, 권한, 게시물 내용을 점검하세요.
