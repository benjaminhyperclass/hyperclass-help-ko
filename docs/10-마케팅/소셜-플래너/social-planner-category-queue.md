# 소셜 플래너 카테고리 대기열로 게시물 자동 반복 게시하기

카테고리 대기열을 쓰면 상시 활용할 수 있는 소셜 콘텐츠를 자동으로 반복 게시할 수 있어요. 게시물을 카테고리로 묶고 반복 게시 일정을 정해 두면, 대기열이 게시물을 계속 순환하며 올려 줘요. 이 문서에서는 카테고리 대기열의 작동 방식과 만들고 관리하는 방법, 앞으로 추가될 콘텐츠를 다루는 방법을 안내해요.

## 카테고리 대기열이란?

**Category Queue**(카테고리 대기열)는 소셜 게시물을 카테고리별로 묶어 반복 일정에 따라 게시하는 기능이에요. 대기열이 마지막 게시물까지 올리고 나면 처음부터 다시 시작해요. 그래서 시간이 지나도 쓸 수 있는 콘텐츠에 잘 맞아요. ▶ 영상 [8강 2부 13:59](https://www.youtube.com/watch?v=TNUzXx1UteQ&t=839s)

카테고리에 지정된 게시 완료 게시물로 대기열을 만들 수 있어요. 대기열을 설정하면서 새 게시물을 추가할 수도 있고, 같은 카테고리로 앞으로 만드는 게시물을 자동으로 포함할 수도 있어요.

## 카테고리 대기열의 장점

- 상시 콘텐츠 자동 예약: 게시물마다 일정을 다시 잡지 않아도 카테고리 콘텐츠가 계속 게시돼요.
- 콘텐츠 재활용: 이미 게시한 게시물을 다시 쓰고, 같은 카테고리로 만드는 앞으로의 게시물도 포함할 수 있어요.
- 우선순위 설정: 새 콘텐츠를 대기열의 맨 앞에 넣을지 맨 뒤에 넣을지 정할 수 있어요.
- 맞춤 일정: 대기열마다 게시 요일과 시간대를 따로 정할 수 있어요.
- 유연한 대기열 관리: 필요에 따라 대기열을 편집하고, 순서를 바꾸고, 일시중지·재개·일정 변경·삭제할 수 있어요.

## 시작하기 전에

{% hint style="info" %}
기존 콘텐츠로 대기열을 만들려면, 게시 완료된 게시물이 알맞은 소셜 카테고리에 지정되어 있는지 확인하세요. 대기열을 설정하면서 새 카테고리를 만들고 게시물을 추가할 수도 있어요.
{% endhint %}

## 카테고리 대기열 만들기

1. 서브 계정에 로그인하세요.
2. **마케팅 > 소셜 플래너**로 이동하세요.

   ![마케팅 메뉴에서 소셜 플래너로 이동하기](https://jumpshare.com/share/Pc9OwGeP0CQNwDqQGxDI+/Screen+Shot+2025-11-24+at+10.50.25+PM.png)
3. **+ 새 게시물**을 클릭한 다음 **Category Queue**(카테고리 대기열)를 선택하세요.

   ![새 게시물 메뉴에서 카테고리 대기열 선택하기](https://jumpshare.com/share/8c1m6djAWSQvyC42Ytl2+/Screen+Shot+2025-11-24+at+11.07.43+PM.png)
4. **카테고리 선택**에서 대기열에 쓸 카테고리를 고르세요.

   ![대기열에 사용할 기존 소셜 카테고리 선택하기](https://jumpshare.com/share/qbxG3xek8G9cvNa14qm6+/CN96DupK6jOf3xVoh6AdGV2sZqbOoSTBkQ.jpeg)
5. 새 카테고리를 만들려면 카테고리 이름을 입력하고 추가 옵션을 선택하세요.

   ![대기열을 설정하면서 새 소셜 카테고리 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060860653/original/VICQYWl3jqjF_J-r8Rp0z-lF_L85LMWg5Q.png?1765991958)
6. **Enable future posts queuing**(향후 게시물 대기열 추가)을 켜세요. 이 카테고리로 앞으로 만드는 게시물이 이 대기열에 자동으로 추가돼요.
7. **Prioritize new content**(새 콘텐츠 우선)를 켜면 새로 대기열에 들어온 콘텐츠가 맨 앞에 추가돼요. 끄면 새 콘텐츠는 맨 뒤에 추가돼요.
8. **계속**을 클릭하세요.

   ![카테고리와 대기열 환경설정을 고른 뒤 계속 클릭하기](https://jumpshare.com/share/NcCpZOrNCiOcoM56an2w+/Screen+Shot+2025-11-24+at+11.46.49+PM.png)
9. 대기열을 게시할 요일과 시간대를 선택하세요.
10. **게시물 대기열**을 클릭하면 일정이 적용되고 대기열 편집 화면으로 넘어가요.

    ![게시 일정을 정하고 대기열 편집 화면으로 이동하기](https://jumpshare.com/share/6p1qoeG3RInnMgludW8d+/Screen+Shot+2025-11-24+at+11.49.18+PM.png)
11. 대기열에 담긴 게시물을 확인하세요. 필요하면 게시물 내용이나 미디어를 수정하세요.
12. 게시물을 더 추가하려면 **새 게시물**을 클릭하세요. 추가한 게시물은 끌어서 대기열의 원하는 위치로 옮길 수 있어요.
13. 대기열에서 한 게시물의 여러 버전을 돌려 가며 올리고 싶다면 콘텐츠 변형을 여러 개 추가하세요.

    ![카테고리 대기열의 게시물에 콘텐츠 변형 추가하기](https://jumpshare.com/share/Z8q8ZI64iYqMe5h0QpxB+/GIF+Recording+2025-11-25+at+7.17.11+PM.gif)
14. 주의, 경고, 오류 메시지를 모두 확인하고 문제가 있으면 해결하세요.
15. 진행을 막는 오류가 없으면 **게시물 대기열**을 클릭해 대기열을 활성화하세요.

    ![대기열 오류를 해결하고 카테고리 대기열 활성화하기](https://jumpshare.com/share/J5Lsc81T3q8Al1fhDM9n+/Screen+Shot+2025-11-25+at+7.03.11+PM.png)
16. 대기열을 활성화하기 전에는 필요에 따라 **초안으로 저장**, **삭제**, **재설정**을 선택할 수 있어요.

    ![카테고리 대기열 저장, 삭제, 재설정하기](https://jumpshare.com/share/Llasxm2JW3kAaDJTeQTp+/Screen+Shot+2025-11-25+at+7.05.00+PM.png)
17. 나중에 카테고리 대기열을 일시중지하거나 다시 시작하려면 **콘텐츠** 탭으로 이동해 대기열 상태 토글을 사용하세요.

    ![콘텐츠 탭에서 카테고리 대기열 일시중지 또는 재개하기](https://jumpshare.com/share/5RTw8IW6FJ7agWsJNyDs+/2hAzCIIduz8i2sS6g_8TQKy0WWJV6xY6eA.jpeg)

## 카테고리 대기열 관리하기

**마케팅 > 소셜 플래너 > 콘텐츠 > Category Queue**로 이동하세요. 대기열을 찾아 **더 보기** 아이콘을 클릭하면 사용할 수 있는 관리 작업이 나와요.

![소셜 플래너의 카테고리 대기열 더 보기 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060861302/original/0_Bh0pGd3Mn6ZujZ9FiubHRzUCGT6W0R_g.png?1765992875)

### 1. 카테고리 대기열 편집하기

**Edit queue**(대기열 편집)를 선택하면 대기열을 삭제하고 다시 만들 필요 없이 바로 수정할 수 있어요. 다음 항목을 편집할 수 있어요.

- 게시물 상세정보, 캡션, 미디어, 변형
- 게시 빈도
- 대기열 시간대
- 항목을 끌어서 놓는 방식의 게시물 순서

### 2. 대기열 환경설정 바꾸기

**추가 옵션 메뉴**에서 **대기열 환경설정**을 선택하세요. 여기서 앞으로 만드는 게시물이 대기열에 어떻게 추가될지 정할 수 있어요.

| 설정 | 켰을 때 | 껐을 때 |
| --- | --- | --- |
| **Enable future posts queuing** | 카테고리로 새로 만든 게시물이 대기열에 자동으로 추가돼요. | 앞으로 만드는 게시물이 대기열에 자동으로 추가되지 않아요. |
| **Prioritize new content** | 새 콘텐츠가 대기열 맨 앞에 추가되어 가장 먼저 게시돼요. | 새 콘텐츠가 대기열 맨 뒤에 추가돼요. |

![카테고리 대기열 메뉴의 대기열 환경설정 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060861428/original/raCU9zXB_zDWhZXW26mheyXJqRNBqLpaaQ.png?1765993165)

![향후 게시물 대기열 추가와 새 콘텐츠 우선 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060861440/original/ME71MM_VsLUBQ32yGp-MItMmFsrGYroTag.png?1765993199)

### 3. 대기열 캘린더 보기

**View queue calendar**(대기열 캘린더 보기)를 선택하면 대기열을 주간 또는 월간 보기로 확인할 수 있어요. 캘린더에서 게시물이 어떻게 분포하는지, 비어 있는 날이나 콘텐츠가 몰린 날은 없는지 살펴보세요.

### 4. 대기열 전체 일정 변경하기

**Reschedule queue**(대기열 일정 변경)를 선택하면 대기열 전체를 새 시작일로 옮길 수 있어요. 하이퍼클래스가 대기열의 기존 게시 빈도와 시간대에 맞춰 게시물 날짜를 다시 계산해요.

![소셜 플래너의 대기열 일정 변경 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060861506/original/B-rKvVdwo3Ba2sjFuTy_MomIyZxXhekw3A.png?1765993274)

![카테고리 대기열의 새 시작일 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060861546/original/26ZksYwNAv7d-SEUJtty5NKelnd9UQtbDA.png?1765993329)

### 5. 게시물 작성 화면에서 게시물 추가하기

소셜 게시물을 만드는 중에 **대기열에 추가**를 선택하고 카테고리를 고르세요.

- 기존 카테고리를 선택하면 그 카테고리의 대기열에 게시물이 추가돼요.
- 새 카테고리를 만들면 그 게시물을 위한 카테고리 대기열이 새로 만들어져요.

![소셜 게시물을 기존 또는 새 카테고리 대기열에 추가하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063016594/original/FS8wPfJv0ra9CbjnufIbaucaLvlj_uz7eA.png?1768888475)

### 6. 대기열 일시중지, 재개, 삭제하기

- **Category Queue** 페이지의 상태 토글로 대기열을 일시중지하거나 다시 시작해요.
- 더 이상 필요 없는 대기열은 **추가 옵션 메뉴**에서 **삭제**를 선택해 지워요.
- 대기열을 편집하는 중에 **재설정**을 누르면 대기열 항목의 변경 사항이 취소되고 원래 내용으로 돌아가요.

## 알아 두세요

- 카테고리 대기열에는 카테고리에 지정된 이전 게시 완료 게시물을 포함할 수 있어요. 새 게시물을 만들어 대기열에 추가할 수도 있어요.
- 카테고리 대기열 안의 개별 게시물 일정 변경은 지원하지 않아요.
- 카테고리 대기열 캘린더에서 직접 게시물 일정을 바꾸거나 순서를 옮길 수는 없어요.
- **대기열 환경설정**에서 바꾼 내용은 다음 대기열 순환부터 적용돼요.
- **콘텐츠** 탭에서 카테고리 대기열을 일시중지, 재개, 삭제할 수 있어요.
- 카테고리와 대기열 상태를 확인하려면 **마케팅 > 소셜 플래너 > 설정 > 카테고리**로 이동하세요. **Status**(상태) 열에서 대기열이 활성, 일시중지, 초안 중 어떤 상태인지 볼 수 있어요.

## 카테고리 대기열 공개 API

사용자 지정 워크플로우나 연동, 자동화에서 카테고리 대기열을 코드로 만들고 관리하려면 **Category Queue Public API**(카테고리 대기열 공개 API)를 쓸 수 있어요.

API 참조 문서는 **Public API Docs**(공개 API 문서) → **Social Planner** → **Category Queue**에서 찾을 수 있어요.

연동 유형에 따라 Location API 키 또는 OAuth 토큰으로 인증하세요.

### 주요 지원 작업

| 작업 | 설명 |
| --- | --- |
| 카테고리 조회 | 사용할 수 있는 카테고리와 대기열 상태를 가져와요. |
| 카테고리 대기열 관리 | 카테고리 대기열을 만들고, 목록을 보고, 수정하고, 조회해요. |
| 대기열 항목 관리 | 대기열 항목을 추가, 수정, 재설정, 삭제해요. |
| 캘린더 데이터 보기 | 예약된 게시물을 캘린더 형식으로 확인해요. |
| 대기열 앞당기기 | 현재 활성 게시물을 삭제하고 다음 게시물을 예약해요. |

엔드포인트 상세 정보와 요청·응답 스키마, 예시는 공식 문서를 참고하세요.

## 자주 묻는 질문

### 앞으로 만드는 게시물을 카테고리 대기열에 자동으로 추가하려면 어떻게 하나요?

**대기열 환경설정**을 열고 **Enable future posts queuing**을 켜세요. 그러면 하이퍼클래스가 그 카테고리로 새로 만든 게시물을 대기열에 자동으로 추가해요.

### 새로 추가한 콘텐츠를 기존 대기열 항목보다 먼저 게시하려면 어떻게 하나요?

**대기열 환경설정**에서 **Prioritize new content**를 켜세요. 그러면 새 콘텐츠가 대기열 맨 앞에 추가돼요.

### 카테고리 대기열의 일정을 바꿀 수 있나요?

네, 바꿀 수 있어요. **Edit queue**에서 게시 빈도나 시간대를 바꾸고, **Reschedule queue**로 대기열 전체를 새 시작일로 옮기세요. 대기열 안의 개별 게시물 일정 변경은 지원하지 않아요.

### 기존 대기열에 새 게시물을 추가하려면 어떻게 하나요?

대기열을 열어 **새 게시물**을 선택하거나, 소셜 게시물 작성 화면에서 **대기열에 추가**를 선택한 뒤 카테고리를 고르세요. 대기열을 편집하면서 게시물을 끌어 원하는 위치로 옮길 수 있어요.

### 콘텐츠 변형을 여러 개 추가할 수 있나요?

네, 추가할 수 있어요. 변형을 추가하면 게시물의 콘텐츠와 미디어를 여러 버전으로 돌려 가며 올릴 수 있어요.

### 나중에 게시물 순서를 바꿀 수 있나요?

네, 바꿀 수 있어요. **Edit queue**를 선택한 뒤 게시물을 끌어서 원하는 순서로 놓으세요.
