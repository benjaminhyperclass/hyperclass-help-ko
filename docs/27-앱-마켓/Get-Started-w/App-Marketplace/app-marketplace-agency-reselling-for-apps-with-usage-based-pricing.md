# 사용량 기반 앱 에이전시 리셀링

에이전시는 사용량 기반 요금제의 마켓플레이스 앱을 리셀링할 수 있어요. 사용량 기반 서비스에 마크업(추가 금액)을 붙여 판매하면 새로운 수익을 만들면서 고객사에 가치를 전할 수 있어요. 이 문서에서는 설정부터 설치까지의 과정을 안내해요.

## 사용량 기반 앱의 에이전시 리셀링이란?

에이전시 관리자는 하이퍼클래스 마켓플레이스 앱이 제공하는 사용량 기반 서비스에 원하는 마크업을 적용할 수 있어요. 이 서비스를 고객사에 재판매하면서 사용량 기반 지출에서 추가 마진을 얻을 수 있어요. 이 기능은 마켓플레이스를 에이전시와 개발자 모두에게 수익 기회로 만드는 중요한 단계예요.

## 사용량 기반 앱 에이전시 리셀링의 장점

- **유연한 수익 창출:** 사용량 기반 마켓플레이스 앱에 원하는 마크업을 설정해 새로운 수익원을 만들 수 있어요.
- **간편한 관리:** 레이아웃을 단순하게 개편한 리셀링 페이지에서 리셀링 옵션을 더 쉽게 설정하고 관리할 수 있어요.
- **향상된 검색과 필터:** 개선된 검색·필터 도구로 앱을 빠르게 찾고 관리할 수 있어요.
- **관리자 전용 권한:** 에이전시 관리자만 리셀링 설정을 보고 조정할 수 있어서 통제와 보안이 유지돼요.
- **개발자 지원:** 개발자가 에이전시 리셀링으로 앱을 수익화할 수 있게 도와 마켓플레이스 생태계를 넓혀요.

## 사용량 기반 앱 에이전시 리셀링 설정하고 사용하기

설정을 제대로 해 두면 리셀링 수익을 높이고 상품을 효율적으로 관리할 수 있어요. 아래 단계를 따라 시작해 보세요.

{% hint style="info" %}
에이전시 관리자만 리셀링 마크업을 보고 설정할 수 있어요. 고객사에는 에이전시가 설정한 마크업에 따라 요금이 청구돼요.
{% endhint %}

### 1단계: 앱 리셀링 화면으로 이동하기

1. 에이전시 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **앱 마켓플레이스**(App Marketplace)를 클릭하세요.
3. **앱 리셀링** 탭을 클릭하세요.

![앱 리셀링 탭 화면](https://jumpshare.com/v/uUn5qW5MUFJevrOcVC4o+/Screen+Shot+2025-07-15+at+5.59.44+PM.png)

### 2단계: 사용량 기반 앱 찾기

1. **가격** 탭을 클릭하세요.
2. 가격 필터 드롭다운에서 **Usage-Based**(사용량 기반)를 선택하세요.
3. 앱을 직접 검색해서 찾을 수도 있어요.

![가격 필터에서 사용량 기반 선택](https://jumpshare.com/v/U09CJGhAiRcQvIPBpVJG+/Screen+Shot+2025-07-15+at+6.01.33+PM.png)

### 3단계: 가격과 마진 설정하기

1. 리셀링할 앱을 선택하세요.
2. 해당 앱의 **Set Usage-Based Pricing**(사용량 기반 가격 설정) 버튼을 클릭하세요.
3. 각 서비스나 액션에 책정된 개발자의 사용량 가격을 확인하세요.
4. **수익** 필드에 기본 가격에 더해 받고 싶은 추가 금액을 입력하세요.
5. 최종 리셀링 가격이 자동으로 계산되어 표시돼요.
6. 모든 가격을 설정했으면 **저장**을 클릭하세요.

![사용량 기반 가격과 수익 설정 과정](https://jumpshare.com/v/UsiddxCl2nsa04IQJDDM+/GIF+Recording+2025-07-15+at+6.17.53+PM.gif)

### 4단계: 에이전시 계정에서 서브 계정에 앱 설치하기

1. **앱 이름**을 클릭하면 새 탭에서 설치 창이 열려요.

   ![앱 이름을 클릭해 설치 창 열기](https://jumpshare.com/v/RT7aGdACs4Sp5LcfjkVI+/Screen+Shot+2025-07-15+at+6.26.43+PM.png)
2. **설치** 버튼을 클릭하세요.

   ![설치 버튼](https://jumpshare.com/v/XGPBhCFd4TP2zUda20En+/Screen+Shot+2025-07-15+at+6.28.09+PM.png)
3. 앱을 설치할 서브 계정을 하나 이상 선택하세요.
4. **계속**을 클릭하세요.

   ![서브 계정 선택 후 계속](https://jumpshare.com/v/7F3Go5S2escMLM3iEzjQ+/Screen+Shot+2025-07-15+at+6.30.03+PM.png)
5. **Allow and Install**(허용 및 설치)을 클릭하세요.
6. 선택한 서브 계정에 앱이 설치돼요. 이때 사용량 기반 가격이 적용되고, 설정한 마크업도 함께 반영돼요.

   ![서브 계정에 앱 설치 완료](https://jumpshare.com/v/a3UWZukJBNXVS3XQ4cCQ+/Screen+Shot+2025-07-15+at+6.33.10+PM.png)

### 5단계: 서브 계정에서 앱 설치하기

앱이 서브 계정 단위 설치를 지원하면 사용자와 관리자 모두 서브 계정 안에서 직접 설치할 수 있어요.

{% hint style="info" %}
에이전시 단계에서 설정한 사용량 기반 가격은 에이전시 화면과 서브 계정 화면 모두에서 볼 수 있어요.
{% endhint %}

1. 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **앱 마켓플레이스**를 클릭하세요.
3. 마켓플레이스에서 앱을 검색해 찾으세요.
4. **앱 이름**을 클릭해 설치 창을 여세요.
5. **설치** 버튼을 클릭하세요.
6. **Allow and Install**(허용 및 설치) 버튼을 클릭하세요.

![서브 계정에서 앱 설치하는 과정](https://jumpshare.com/v/NFR1HTAEX2MXpLrYQbGD+/GIF+Recording+2025-07-15+at+6.44.13+PM.gif)

## 자주 묻는 질문

### 사용량 기반 앱의 리셀링 마크업은 누가 설정하고 관리할 수 있나요?
에이전시 관리자만 마켓플레이스의 사용량 기반 앱에 대한 리셀링 마크업을 설정하고 관리할 수 있어요.

### 모든 마켓플레이스 앱을 에이전시 리셀링할 수 있나요?
현재는 사용량 기반 가격이 적용된 앱만 에이전시 리셀링을 지원해요.

### 고객사마다 다른 마크업을 설정할 수 있나요?
마크업은 앱 단위로 설정되어 모든 고객사에 똑같이 적용돼요. 고객사별 마크업은 아직 지원하지 않아요.

### 고객사에는 앱 원래 가격이 보이나요, 마크업을 붙인 가격이 보이나요?
고객사에는 마크업이 포함된, 내가 설정한 가격만 보여요.

### 마크업을 설정하지 않으면 어떻게 되나요?
마크업이 없으면 고객사에는 앱의 기본 사용 요금만 청구돼요.

### 마크업을 설정한 뒤 원래 앱 가격으로 되돌릴 수 있나요?
네, 앱 리셀링 설정 화면에서 언제든 마크업을 조정하거나 제거할 수 있어요.

### 설정할 수 있는 마크업 금액에 제한이 있나요?
현재는 제한이 없어요. 다만 경쟁력 있고 합리적인 수준으로 설정하는 것을 권장해요.

### 에이전시가 앱을 리셀링하면 개발자에게 알림이 가나요?
개발자는 앱 리셀링 활동을 확인할 수 있어요. 앞으로는 개발자가 리셀링 요율을 추천할 수 있게 될 예정이에요.
