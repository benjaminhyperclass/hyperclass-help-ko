# 앱 마켓플레이스 — 사용량 기반 앱의 일일 사용 한도 설정

하이퍼클래스 마켓플레이스에서 에이전시 소유자와 관리자가 사용량 기반 요금제 앱의 하루 사용 한도를 정할 수 있어요. 이 문서에서는 비용을 예측 가능하게 관리하는 방법과, 한 설정 페이지에서 모든 제어를 처리하는 방법을 안내해요.

## 에이전시 일일 사용 한도 제어란?

사용량 기반 요금제로 운영되는 앱에 하루 사용 한도를 정하는 기능이에요. 에이전시 소유자와 관리자가 쓸 수 있어요. 일일 한도를 한곳에서 관리하면 지출을 더 잘 파악할 수 있고, 외부 API 요금도 예산 안에서 예측할 수 있어요. 하이퍼클래스는 이 기능으로 에이전시의 신뢰와 운영 관리 수준을 높이려 해요.

## 일일 사용 한도 제어의 주요 장점

일일 사용 한도를 정하면 비용을 관리하고 운영을 안정적으로 이어 갈 수 있어요.

- **비용 관리 강화:** 하루 지출에 상한을 두어 예상치 못한 초과 비용을 막아요.
- **에이전시 신뢰 향상:** 청구 금액을 예측할 수 있고, 외부 요금 때문에 놀랄 일이 줄어요.
- **간편한 관리:** 마켓플레이스 제어를 설정 페이지 한곳에 모았어요. 에이전시 소유자와 관리자만 들어갈 수 있어요.
- **쓰기 편한 화면:** 에이전시에 맞춘 전용 화면에서 일일 관리를 간단히 할 수 있어요.

## 새롭게 바뀐 에이전시 제어 설정 페이지

새 설정 페이지는 에이전시 소유자와 관리자만 쓰는 전용 공간이에요. 마켓플레이스 제어를 한 화면에 모아 두어 일일 사용 한도와 앱 설정을 쉽게 관리할 수 있어요.

- 권한이 있는 에이전시 사용자 전용 제어 화면을 쓸 수 있어요.
- 모든 설정이 한곳에 정리되어 있어 보기 편해요.
- 사용 한도를 쉽게 확인하고 조정할 수 있어서 비용 관리에 도움이 돼요.

## 앱의 일일 사용 한도 설정하기

설정은 어렵지 않아요. 아래 순서대로 따라 하면 바로 사용 한도를 관리할 수 있어요.

1. **에이전시** 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **앱 마켓플레이스**를 클릭하세요.

   ![왼쪽 메뉴의 앱 마켓플레이스](https://jumpshare.com/share/GfcoMZUl7PnuWmdKCMzi+/Screen+Shot+2025-09-01+at+8.12.11+PM.png)
3. **설정** 버튼을 클릭하세요.

   ![설정 버튼](https://jumpshare.com/share/Akzp1baL0KFCQ4qelKKa+/Screen+Shot+2025-09-01+at+8.13.22+PM.png)
4. 설정에서 **앱 사용 한도**를 클릭하세요.

   ![앱 사용 한도 메뉴](https://jumpshare.com/share/S4Dr8AR7Uj5iJXqq7v38+/Screen+Shot+2025-09-01+at+8.14.58+PM.png)
5. 한도를 정할 앱을 찾아 **Set Usage Limit**(사용 한도 설정) 버튼을 클릭하세요.

   ![사용 한도 설정 버튼](https://jumpshare.com/share/JKA39F5kCPQ9FKd8dF9g+/Screen+Shot+2025-09-01+at+8.16.25+PM.png)
6. 숫자 입력란에 하루에 허용할 실행 횟수를 입력하세요.
7. **저장**을 클릭하세요.

   ![사용 한도 저장](https://jumpshare.com/share/OZwCNgU1i8buzKNdUmfe+/GIF+Recording+2025-09-01+at+8.18.14+PM.gif)

## 자주 묻는 질문

### 일일 사용 한도 기능은 누가 쓸 수 있나요?
에이전시 소유자와 관리자만 쓸 수 있어요.

### 일일 사용 한도가 왜 중요한가요?
사용량 기반 앱에서 하루 지출에 상한을 두어, 예상치 못한 비용이 생기는 것을 막아 줘요.

### 사용 한도를 정한 뒤에 바꿀 수 있나요?
네, 에이전시 관리자는 예산에 맞게 필요할 때 한도를 수정할 수 있어요.

### 설치한 앱에만 한도를 정할 수 있나요?
네, 가능해요. **앱 사용 한도**에서 **App Status**(앱 상태) → **설치된 앱**을 선택해 필터링하면, 이미 쓰고 있는 앱에만 한도를 정할 수 있어요.
