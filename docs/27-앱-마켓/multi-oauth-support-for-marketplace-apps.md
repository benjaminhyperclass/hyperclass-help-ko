# 마켓플레이스 앱의 멀티 OAuth 지원

마켓플레이스 앱 하나에 외부 계정을 여러 개 연결하고 관리하는 방법을 안내해요. Google, Facebook, SurveyMonkey, CRM 등 OAuth 기반 계정이 여러 개여도 앱을 중복 설치하거나 별도 연결 과정을 만들 필요가 없어요.

## 마켓플레이스 앱의 멀티 OAuth 지원이란?

멀티 OAuth 지원은 마켓플레이스 앱 하나에 OAuth 연결을 여러 개 둘 수 있는 기능이에요. 앱이 멀티 OAuth를 지원하면 외부 계정을 하나로 제한하지 않고, 같은 앱에 둘 이상 연결할 수 있어요.

연결한 계정은 계정 이름, 이메일, 계정 ID로 구분해요. 하이퍼클래스가 연결된 계정의 토큰을 안전하게 저장하고 갱신해 주기 때문에, 여러 외부 계정에서 워크플로우, 트리거, 액션을 더 안정적으로 쓸 수 있어요.

---

## 멀티 OAuth 지원의 장점

외부 계정을 여러 개 운영하는 에이전시나 SaaS 환경에서 마켓플레이스 앱을 더 유연하게 쓸 수 있어요.

- **여러 계정 연결:** 마켓플레이스 앱 하나에 외부 OAuth 계정을 둘 이상 연결할 수 있어요.
- **간편한 계정 관리:** 연결 패널 한곳에서 연결된 계정을 보고, 검색하고, 새로고침하고, 기본 계정으로 지정하거나 연결을 해제할 수 있어요.
- **수작업 감소:** 외부 계정마다 앱을 중복 설치하거나 OAuth 과정을 따로 만들지 않아도 돼요.
- **안전한 토큰 관리:** 하이퍼클래스가 플랫폼에서 OAuth 토큰을 저장하고 갱신해요.
- **확장 가능한 앱 워크플로우:** 연결된 여러 계정을 워크플로우, 트리거, 액션에 쓸 수 있어요.
- **에이전시 지원 강화:** 마켓플레이스 앱 하나로 여러 고객사, 브랜드, 플랫폼 계정을 관리할 수 있어요.

---

## 멀티 OAuth 작동 방식

멀티 OAuth는 마켓플레이스 앱의 연결 방식을 '하나만 연결'에서 '여러 개 연결'로 넓혀 줘요. 앱 하나를 설치해도 외부 계정 여러 개를 쓸 수 있고, 각 연결은 따로 구분돼요.

작동 순서는 다음과 같아요.

1. 멀티 OAuth를 지원하는 마켓플레이스 앱을 설치해요.
2. 외부 OAuth 계정을 하나 이상 연결해요.
3. 연결한 계정이 앱의 **외부 연결** 탭에 표시돼요.
4. 하이퍼클래스가 연결된 계정의 토큰을 안전하게 저장하고 갱신해요.
5. 앱이 지원하는 워크플로우, 트리거, 액션에서 이 연결을 쓸 수 있어요.

---

## 여러 외부 계정 관리하기

**외부 연결** 탭에서 마켓플레이스 앱에 연결된 OAuth 계정을 보고 관리할 수 있어요. 어떤 계정이 연결되어 있는지 확인하고, 계정을 새로고침하거나 제거하거나 기본 계정으로 지정할 수 있어요.

**외부 연결** 탭에서는 다음 작업을 할 수 있어요.

- 연결된 계정 보기
- 연결된 계정 검색
- **다른 계정 추가**
- 연결 새로고침
- 기본 계정 지정
- 계정 연결 해제

---

## 기본 연결 계정 지정하기

기본 연결 계정은 기본 선택이 필요할 때 하이퍼클래스가 앱에서 기본으로 쓰는 계정이에요. 같은 마켓플레이스 앱에 외부 계정이 여러 개 연결되어 있을 때 기본 계정을 정해 두면 헷갈리지 않아요.

기본 연결 계정을 지정하려면 다음 순서대로 하세요.

1. **앱 마켓플레이스**로 이동하세요.
2. 설치된 마켓플레이스 앱을 여세요.
3. **외부 연결** 탭을 클릭하세요.
4. 기본으로 쓸 계정을 찾으세요.
5. **기본** 열에서 해당 계정의 라디오 버튼을 선택하세요.
6. 기본 계정이 업데이트되었다는 성공 메시지를 확인하세요.

## 외부 계정 연결 해제하기

외부 계정 연결을 해제하면 마켓플레이스 앱에서 해당 OAuth 연결이 제거돼요. 더 이상 필요 없거나 그 앱에서 쓰지 않아야 하는 계정일 때만 해제하세요.

외부 계정 연결을 해제하려면 다음 순서대로 하세요.

1. **앱 마켓플레이스**로 이동하세요.
2. 설치된 마켓플레이스 앱을 여세요.
3. **외부 연결** 탭을 클릭하세요.
4. 제거할 연결된 계정을 찾으세요.
5. 해당 계정의 삭제 아이콘을 클릭하세요.
6. 확인 메시지를 읽어 보세요.
7. **삭제**를 클릭해 계정 연결을 해제하세요.

![연결된 계정의 삭제 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071950509/original/ufgDxJbv-YHP2eg04wJKPtbe-Qp5bMuBag.png?1779398893)

## 새 앱과 기존 앱에서의 사용 가능 여부

멀티 OAuth 지원은 OAuth 연결을 여러 개 지원하는 새 마켓플레이스 앱이나 새 앱 버전에서 쓸 수 있어요. 기존 앱은 지원하는 새 버전이 추가되기 전까지 멀티 OAuth를 자동으로 쓸 수 없어요.

즉, 다음과 같아요.

- 새 앱은 멀티 OAuth 지원을 포함해 만들 수 있어요.
- 기존 앱이 여러 OAuth 연결을 지원하려면 새 버전이 필요할 수 있어요.
- 개발자가 멀티 OAuth 지원 버전을 출시하면 앱 버전을 업데이트하거나 다시 설치해야 할 수 있어요.
- 멀티 OAuth를 지원하지 않는 앱은 OAuth 연결을 하나만 허용할 수 있어요.

---

## 멀티 OAuth 사용하기

멀티 OAuth를 쓰면 외부 계정을 각각 연결해 정리해 두고, 앱이 지원하는 액션에서 쓸 수 있어요. 마켓플레이스 앱을 어떻게 만들었는지에 따라 쓸 수 있는 옵션은 다를 수 있어요.

멀티 OAuth를 사용하려면 다음 순서대로 하세요.

1. 마켓플레이스 앱이 설치된 서브 계정을 여세요.
2. **앱 마켓플레이스**로 이동하세요.
3. 설치된 앱을 선택하세요.
4. **외부 연결** 탭을 여세요.
5. **계정 추가**를 클릭해 다른 외부 계정을 연결하세요.
6. OAuth 인증 과정을 완료하세요.
7. 새 계정이 연결된 계정 목록에 나타나는지 확인하세요.
8. 필요하면 기본 계정을 지정하세요.
9. 계정을 업데이트하거나 제거해야 할 때는 새로고침하거나 연결을 해제하세요.

## 자주 묻는 질문

### 멀티 OAuth 지원이 뭔가요?
마켓플레이스 앱 하나에 외부 OAuth 계정을 여러 개 연결하고 관리할 수 있는 기능이에요.

### 같은 앱에 외부 계정을 두 개 이상 연결할 수 있나요?
네. 마켓플레이스 앱이 멀티 OAuth를 지원하면, 앱의 **외부 연결** 탭에서 외부 계정을 여러 개 연결할 수 있어요.

### 기존 앱도 멀티 OAuth를 자동으로 지원하나요?
아니요. 멀티 OAuth 지원은 여러 OAuth 연결을 지원하는 새 앱이나 새 앱 버전에서 쓸 수 있어요.

### 연결된 계정은 어디에서 관리하나요?
설치된 앱의 **외부 연결** 탭에서 관리해요.

### 기본으로 쓸 계정을 고를 수 있나요?
네. 계정이 여러 개 연결되어 있으면 **기본** 열에서 기본 연결 계정을 선택할 수 있어요.

### 계정 연결을 해제하면 어떻게 되나요?
선택한 외부 계정이 앱의 연결된 계정에서 제거돼요. 다시 연결하기 전에는 그 앱에서 쓸 수 없어요.

### OAuth 토큰은 자동으로 갱신되나요?
네. 하이퍼클래스가 플랫폼에서 연결된 계정의 토큰을 안전하게 저장하고 갱신해요.

### 멀티 OAuth를 워크플로우, 트리거, 액션에도 쓸 수 있나요?
네. 앱을 어떻게 만들었는지에 따라 달라지지만, 앱은 연결된 OAuth 계정을 지원하는 워크플로우, 트리거, 액션에 쓸 수 있어요.
