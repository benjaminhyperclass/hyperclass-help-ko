# 마켓플레이스 앱 권한 관리: 서브 계정이 쓸 수 있는 앱 정하기

화이트라벨 에이전시가 서브 계정에 열어 줄 마켓플레이스 앱을 직접 정하는 방법을 안내해요. 서브 계정이 모든 마켓플레이스 앱을 쓰게 할 수도 있고, 에이전시가 승인한 앱만 쓰게 제한할 수도 있어요. 에이전시 관리자만 쓸 수 있어요.

## 서브 계정이 접근할 수 있는 마켓플레이스 앱 정하기

**Show only approved apps to sub-accounts**(서브 계정에 승인된 앱만 표시) 설정으로, 서브 계정이 모든 마켓플레이스 앱을 쓸지 에이전시가 승인한 앱만 쓸지 정해요.

| 설정 | 서브 계정의 앱 이용 범위 |
| --- | --- |
| **비활성화됨** | 서브 계정에서 모든 마켓플레이스 앱을 쓸 수 있어요. 기본 설정이에요. |
| **활성화됨** | 에이전시가 명시적으로 승인한 마켓플레이스 앱만 서브 계정에서 쓸 수 있어요. |

에이전시가 서브 계정에 열어 줄 앱을 직접 관리하고 싶다면 **Show only approved apps to sub-accounts** 를 켜세요.

{% hint style="info" %}
이 설정을 켜기 전에 앱 목록에서 현재 승인 상태를 확인하세요. 서브 계정이 써야 하는 앱이 모두 승인되어 있는지도 살펴보세요.
{% endhint %}

---

## 앱 액세스 관리

에이전시 관리자는 한 곳에서 서브 계정이 쓸 수 있는 마켓플레이스 앱을 관리할 수 있어요.

1. **앱 마켓플레이스**로 이동하세요.
2. **설정**을 클릭하세요.
3. **앱 액세스 관리**를 선택하세요.

### 서브 계정이 접근할 수 있는 앱 제어하기

마켓플레이스 앱 접근은 **Show only approved apps to sub-accounts** 설정으로 제어해요.

- **비활성화됨:** 서브 계정에서 모든 마켓플레이스 앱을 쓸 수 있어요.
- **활성화됨:** 에이전시가 명시적으로 승인한 앱만 서브 계정에서 쓸 수 있어요.

기본값은 비활성화됨이에요.

### AI에게 문의에서 마켓플레이스 앱 찾기 제어하기

서브 계정 관리자가 **AI에게 문의**로 마켓플레이스 앱을 찾을 수 있게 할지 에이전시 관리자가 정할 수 있어요.

{% hint style="info" %}
이 설정은 서브 계정 관리자에게만 적용돼요. 에이전시 관리자는 **AI에게 문의**에서 항상 마켓플레이스 앱을 찾을 수 있어요.
{% endhint %}

**Ask AI Discoverability**(AI에게 문의 검색 노출) 설정 순서는 다음과 같아요.

1. **앱 마켓플레이스**로 이동하세요.
2. **설정**을 클릭하세요.
3. **마켓플레이스 공개 여부**를 선택하세요.
4. **Ask AI Discoverability**를 찾으세요.
5. 설정을 **활성화**하거나 비활성화하세요.

설정을 켜면 서브 계정 관리자가 **AI에게 문의**에 앱이나 연동을 물어보고, 관련 있는 마켓플레이스 앱을 추천받을 수 있어요.

설정을 끄면 **AI에게 문의**가 서브 계정 관리자에게 마켓플레이스 앱을 추천하지 않아요.

에이전시 관리자는 계속 마켓플레이스 앱을 찾을 수 있어요.

기존 마켓플레이스 공개 여부와 앱 액세스 제어도 그대로 적용돼요.

## 마켓플레이스 앱 승인하기

**앱 액세스 관리**에서 바로 마켓플레이스 앱을 검토하고 승인할 수 있어요.

1. **앱 마켓플레이스 > 설정 > 앱 액세스 관리**로 이동하세요.
2. 관리할 앱을 찾으세요.
3. 앱의 현재 승인 상태를 확인하세요.
4. **승인**을 선택하세요.

검색과 필터를 쓰면 원하는 앱을 더 빨리 찾을 수 있어요.

**Show only approved apps to sub-accounts** 가 켜져 있으면 승인된 앱을 서브 계정에서 쓸 수 있어요.

![앱 목록에서 승인할 앱 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155009952241/original/crNm9hhSccga56_GnJLMP4ZjpRHd-9-TJg.png?1697115627)

- 팝업 창에서 **승인**을 클릭해 결정을 확정하세요.

![승인 확인 팝업 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155009952348/original/ZNidXSC_JcD_9Ewv_N4NSJRuCsE9GXPplA.png?1697115648)

- 승인된 앱은 서브 계정 사용자의 **앱 마켓플레이스**에 표시돼요. 서브 계정 사용자는 이 앱을 보고 설치할 수 있어요.

개별 앱에서 승인하려면 다음과 같이 해요.

- 앱을 클릭해 앱 상세 페이지로 이동하세요.

![앱 상세 페이지로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155009952447/original/kV2Q5zmlKngFwCeoRggiKvLyhdlx1uSxUw.png?1697115692)

- 오른쪽 위에서 **승인**을 클릭하세요.
- 팝업 창에서 **승인**을 선택해 확정하세요.

## 앱 승인 거부하기

- **App state**(앱 상태)에서 **승인된 앱**을 선택하세요.

![앱 상태에서 승인된 앱 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155009952542/original/OxMJRvLAfVqIwILE33GvCgpapUy_kPrilw.png?1697115717)

- 여러 앱을 한꺼번에 처리하려면 승인을 거부할 앱을 고르고, 오른쪽 위의 **승인 거부** 버튼을 클릭하세요.

![승인 거부할 앱을 선택하고 승인 거부 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155009952652/original/_V33Bgz4gIO6zAKLKD1rH5m-7Mg5OKaXoA.png?1697115754)

- 입력란에 CONFIRM 을 입력한 다음 **승인 거부**를 클릭해 결정을 확정하세요.

### 승인을 거부하면 달라지는 점

- 승인이 거부된 앱은 서브 계정에서 더 이상 보이지 않고 설치할 수도 없어요.
- 이미 설치된 앱이라면 연결된 모든 서브 계정에서 삭제돼요. 커스텀 대화 제공업체, 워크플로우 액션, 트리거 같은 부가 기능도 함께 삭제돼요.
- 승인이 거부된 앱도 나중에 다시 승인할 수 있어요. 다만 예전에 설치했던 서브 계정에 자동으로 다시 설치되지는 않아요. 직접 다시 설치해야 해요.

### 레벨별 설치된 앱 표시

**설치된 앱**은 이제 앱 표시를 **에이전시 앱**과 **서브 계정 앱**으로 나눠 보여 줄 수 있어요. 사용자는 자신의 접근 권한에 맞는 레벨에서 앱 설치를 관리할 수 있어요.

## 승인된 앱으로 마켓플레이스 접근 제한하기

서브 계정이 모든 마켓플레이스 앱을 쓰게 할지, 에이전시가 승인한 앱만 쓰게 할지 정할 수 있어요.

1. **앱 마켓플레이스 > 설정 > 앱 액세스 관리**로 이동하세요.

   ![앱 액세스 관리 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080371209/original/n03A_xLSva2K24d2nsoDCfj606iFrwLvJA.png?1788868877)
   ![앱 액세스 관리 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080371284/original/B7c-kgTOP5RpxYylzGU-9nvtogsH4AfjEQ.png?1788868920)
2. **Show only approved apps to sub-accounts** 를 찾으세요.

   ![서브 계정에 승인된 앱만 표시 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080371317/original/96zCarQl8syl15DFOKhKiXBsBLgZeyf3fg.png?1788868936)
3. 승인된 앱만 쓰도록 제한하려면 이 설정을 켜세요.
4. **마켓플레이스 앱** 목록을 확인하세요.

   ![마켓플레이스 앱 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080371387/original/D2gRqO3qKQv9LpYYd36Gyvnoa4-5lKb4SA.png?1788868983)
5. 앱별로 **승인** 또는 **승인 거부**를 눌러 접근을 관리하세요.
6. 검색과 필터로 원하는 앱을 찾으세요.

### 비활성화하면 달라지는 점

- 서브 계정에서 모든 마켓플레이스 앱을 보거나 설치할 수 있어요.
- 기본 설정이에요.

### 이 옵션 다시 켜기

- 왼쪽 메뉴에서 **앱 마켓플레이스**로 이동하세요. 보이지 않으면 **실험실**에서 켜세요.
- 오른쪽 위의 **앱 권한 관리**를 클릭하세요.
- 오른쪽 위의 설정 아이콘을 클릭하세요.
- **allow sub-accounts to view and install apps built by 3rd party developers**(서브 계정이 외부 개발자가 만든 앱을 보고 설치하도록 허용) 체크박스를 선택하세요.
- **저장**을 클릭하세요.

```
에이전시가 명시적으로 승인한 마켓플레이스 앱만 서브 계정에서 쓸 수 있어요.
```

### 다시 켜면 달라지는 점

- 새로 나오는 모든 공개 앱이 서브 계정에 자동으로 승인돼요.
- 이전에 승인된 앱은 모두 서브 계정에서 보이고 설치할 수 있게 돼요.
- 승인이 거부된 앱은 직접 승인하기 전까지 승인 거부 상태로 남아 있어요.
