# 기회 정보 편집하기

영업 진행 상황이 바뀌면 기회 정보도 함께 고쳐야 해요. 이 문서에서는 하이퍼클래스에서 기회를 찾아 정보, 예약, 메모, 작업, 파이프라인 단계, 상태를 수정하는 순서를 안내해요.

### 1단계. 기회 관리 화면 열기

1. 하이퍼클래스 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **기회 관리**(Opportunities)를 선택하세요.

![왼쪽 메뉴에서 기회 관리 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155020571440/original/0bJQM_rD91QZegROkFju68jT5S-0buDVeA.png?1707937165)

### 2단계. 편집할 기회 찾기

1. **기회 관리** 화면에서 수정할 기회를 찾으세요.
2. 필터와 검색을 쓰거나 기회 목록을 훑어보면서 원하는 기회를 찾을 수 있어요.
3. 기회의 이름을 클릭해 상세 페이지를 여세요.

### 3단계. 기회 상세 페이지에서 정보 수정하기

**기회 상세** 페이지에는 기회에 관한 정보가 항목별로 나와 있어요.

1. 연락처 이름, 연락처 정보, 기회 금액, 기회 출처 같은 정보를 필요에 맞게 고치세요.
2. 파이프라인 단계, 담당자, 태그, 기회에 연결된 **커스텀 필드** 등도 바꿀 수 있어요.

![기회 상세 페이지의 정보 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070884035/original/xUWKnUcuUdDJSS86vtE4SnOpSMi7fxZ2EA.png?1778242764)

### 4단계. 예약 잡기와 수정하기

**Edit Opportunity**(기회 편집) 창에서 바로 예약을 관리할 수 있어요.

1. **기회 관리**를 열고 기회를 선택하세요.
2. **예약 업데이트**를 여세요.
3. 예약이 없으면 **+ New Appointment**(새 예약)를 클릭한 다음 **미팅**, **서비스**, **대여** 중에서 고르세요.
4. 예약이 이미 있으면 점 세 개 아이콘을 클릭해 **편집**, **View**(보기), **삭제** 중에서 선택하세요.
5. **편집**을 선택하면 기존 내용이 미리 채워진 예약 화면이 열려서 더 빠르게 수정할 수 있어요.

{% hint style="info" %}
현재는 기회 하나에 예약을 하나만 연결할 수 있어요.
{% endhint %}

![기회 편집 창에서 예약을 잡고 수정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070884455/original/2IIKZ92zfZ6BxJVqjiZNdsRWGoiXDIUhCg.gif?1778243066)

### 5단계. 메모와 첨부파일 추가하기

1. 필요하면 왼쪽 사이드바에서 **Notes**(메모)를 클릭해 기회에 관한 메모나 추가 정보를 남기세요.
2. 여기에 추가한 메모는 해당 연락처의 메모에도 똑같이 표시돼요.

![기회 상세 페이지의 메모 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070884298/original/gP5MBmd21FXS8pZpeAEQNIDyXM2go6Q-rw.png?1778242944)

### 6단계. 작업과 리마인더 설정하기

1. 기회와 관련해 해야 할 일이나 후속 조치가 있으면 사이드바에서 **작업**을 여세요.
2. 필요한 작업을 만들고 나 자신이나 다른 팀원에게 배정하세요.
3. 마감일과 우선순위를 알맞게 설정하세요.

기회에서 만든 작업은 해당 연락처에도 연결돼요.

![기회 상세 페이지의 작업 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070884414/original/IpFzjVxMDwmX9CbNFfdEVeDWdXXZrYhGPw.png?1778243041)

### 7단계. 파이프라인 단계 관리하기

1. 영업 과정에서 기회가 지금 어디에 있는지 보이도록 파이프라인 단계를 조정하세요.
2. 기회가 성사를 향해 나아갈 때마다 다음 단계로 옮기면서 상태를 최신으로 유지하세요.

![파이프라인 단계를 조정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155020571804/original/mD9YjhGAcOuozHIm3ijS6b3XTmaBhrDKEg.png?1707937986)

### 8단계. 기회 상태 관리하기

1. 화면 아래쪽에 보이는 상태 중 하나로 기회를 끌어다 놓으면 **기회 상태**가 바뀌어요.
2. 기회 상태는 **진행 중**, **고객전환성공**, **고객전환실패**, **중단됨** 중 하나예요. 새 기회의 기본 상태는 **진행 중**이에요.
3. 기회를 **고객전환실패**로 바꿀 때는 고객전환실패 사유도 함께 남길 수 있어요.

![기회를 끌어다 놓아 상태를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155020572021/original/AM_l66aIe-slG3GutRY1UQSNIzDsaA47Bg.png?1707938303)
