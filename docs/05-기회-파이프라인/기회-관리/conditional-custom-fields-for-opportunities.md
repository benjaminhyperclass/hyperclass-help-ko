# 기회 커스텀 필드 조건부 설정

관리자는 기회의 파이프라인, 단계, 상태, 다른 필드 값에 따라 어떤 기회 필드를 보여 줄지, 어떤 필드를 꼭 입력하게 할지 정할 수 있어요. 기회 입력 화면이 간결해지고, 영업 과정의 알맞은 시점에 필요한 정보를 모을 수 있어요.

## 조건 규칙이 작동하는 방식

조건 규칙 하나는 다음 두 가지로 이루어져 있어요.

- **트리거**: 규칙을 작동시키는 조건이에요.
- **결과들**: 조건이 충족되었을 때 나타나거나 필수가 되는 필드 또는 폴더예요.

트리거로 쓸 수 있는 항목은 다음과 같아요.

- 파이프라인
- **파이프라인 단계**
- 상태
- 드롭다운 필드
- 라디오 필드
- 체크박스 필드
- 다중 선택 필드

결과로 쓸 수 있는 항목은 다음과 같아요.

- **필드 표시**: 기회 필드 하나를 보여 줘요.
- **폴더 표시**: 기회 필드가 담긴 폴더 전체를 보여 줘요.
- **필수로 설정**: 화면에 보이는 필드를 입력해야만 기회를 저장할 수 있게 해요.

예를 들어 기회가 고객전환성공 상태가 되면 온보딩 필드를 추가로 보여 주거나, 기회가 특정 파이프라인 단계에 도달하면 제안 내용을 필수로 입력하게 할 수 있어요.

## 조건부 커스텀 필드 켜기

이 기능이 아직 켜져 있지 않다면 다음 순서로 켜세요.

1. **설정 > 실험실**로 이동하세요.
2. **Show & Require Opportunity Fields Conditionally**(기회 필드를 조건부로 표시 및 필수 지정)를 찾으세요.
3. 서브 계정에서 이 기능을 켜세요.

![실험실에서 기능을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079850993/original/bkFIUXCeQiHhXz8Jb1QLwq2OZTaZGmxEOw.jpeg?1788296867)

기능을 켜도 기존 기회 입력 화면은 바뀌지 않아요. 관리자가 첫 번째 규칙을 만들어 저장하면 그때부터 조건에 따라 화면이 달라져요.

## 조건 규칙 만들기

1. **설정 > 커스텀 필드**로 이동하세요.
2. **기회**를 선택하세요.
3. **조건 규칙** 탭을 여세요.
4. **조건부 규칙 만들기**를 클릭하세요.
5. 규칙을 작동시킬 필드를 선택하세요.
6. 연산자와 트리거 값을 선택하세요.
7. 필요하면 **조건 더 추가**를 클릭해 조건을 늘리세요.
8. 조건이 여러 개이면 **그리고** 또는 **또는**으로 연결하세요.
9. 결과를 하나 이상 추가하세요.
10. 실시간 미리보기로 규칙이 의도대로 동작하는지 확인하세요.
11. **규칙 저장**을 클릭하세요.

규칙은 저장하면 바로 적용돼요.

![조건부 규칙을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078108369/original/a-nzBaJMTsWAZ5VJ_57D74yRto_cJdtzcg.png?1786441964)

## 그리고, 또는 조건 사용하기

모든 조건이 충족되어야 할 때는 **그리고**를 쓰세요.

예시:

- 파이프라인이 영업 파이프라인
- **그리고** 파이프라인 단계가 종료

조건 중 하나만 충족되어도 규칙이 작동하게 하려면 **또는**을 쓰세요.

예시:

- 파이프라인 단계가 제안서 발송
- **또는** 파이프라인 단계가 종료

규칙을 저장하기 전에 실시간 미리보기로 동작을 확인하세요.

## 필드와 폴더 표시하기

**필드 표시**나 **폴더 표시** 결과에 포함된 필드와 폴더는 기본적으로 숨겨져 있어요. 규칙의 트리거 조건이 충족될 때만 나타나요.

표시 규칙에 포함하지 않은 필드는 평소처럼 계속 보여요.

필드나 폴더를 조건부로 표시하려면 다음과 같이 하세요.

1. 규칙의 트리거 조건을 설정하세요.
2. **결과들**에서 **필드 표시** 또는 **폴더 표시**를 선택하세요.
3. 표시할 필드 또는 폴더를 선택하세요.
4. 실시간 미리보기를 확인하세요.
5. 규칙을 저장하세요.

![필드와 폴더를 조건부로 표시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078108413/original/gChKIX6Aggd7e0fIKiahglrVqqJmTUi4Rg.png?1786441986)

## 필드를 필수로 설정하기

**필수로 설정** 결과를 쓰면, 사용자는 화면에 보이는 필드를 입력해야 기회를 저장할 수 있어요.

예시:

- **트리거:** 파이프라인 단계가 종료
- **결과들:**
  - 제안 금액을 필수로 설정
  - **예상 종료일**을 필수로 설정
  - 의사결정자를 필수로 설정

사용자가 기회를 종료 단계로 옮기면, 해당하는 필드를 모두 입력해야 변경 내용을 저장할 수 있어요.

{% hint style="warning" %}
필수 설정 결과가 숨겨진 필드를 자동으로 보여 주지는 않아요. 표시 규칙으로 제어되는 필드라면, 필수여야 하는 시점에 필드가 나타나도록 표시 조건을 확인하세요.
{% endhint %}

![필드를 필수로 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078108425/original/mlBGLkrahY2sIwQdTq9ULkL6mSycTAwYSg.png?1786442004)

## 기존 규칙 관리하기

**설정 > 커스텀 필드 > 기회 > 조건 규칙**으로 이동하세요.

이 페이지에서 관리자는 다음 작업을 할 수 있어요.

- 규칙의 트리거와 결과 보기
- 기존 규칙 검색
- 규칙 편집
- 규칙 삭제
- 규칙 추가 생성

변경 내용은 규칙을 저장하는 즉시 적용돼요.

![기존 조건 규칙 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078108542/original/6ZsxjjUiirva03_UtEzQHfSB0siTLO9ebQ.png?1786442029)

## 파이프라인 페이지에서 규칙 관리하기

특정 파이프라인에만 해당하는 규칙은 파이프라인 페이지에서도 관리할 수 있어요.

1. **설정 > 기회 & 파이프라인**으로 이동하세요.
2. 원하는 파이프라인을 찾으세요.
3. 해당 파이프라인의 **작업** 메뉴를 여세요.
4. **조건 규칙 관리**를 선택하세요.
5. 규칙을 만들거나 수정하세요.
6. 실시간 미리보기를 확인하세요.
7. **규칙 저장**을 클릭하세요.

![파이프라인 페이지에서 조건 규칙을 관리하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079850903/original/XnpsJq-jz3mic6Pf9d7jiYu1LiXYZuZU4Q.jpeg?1788296745)

## 알아 둘 점과 제한 사항

- 조건 규칙은 관리자만 만들고, 편집하고, 삭제할 수 있어요.
- 규칙은 서브 계정마다 따로 설정해요.
- 웹과 모바일에서 사용자가 기회를 추가, 편집, 일괄 편집할 때 규칙이 적용돼요.
- **필드 표시**나 **폴더 표시** 결과에 포함된 필드와 폴더는 조건이 충족될 때까지 숨겨져 있어요.
- 표시 규칙에 포함하지 않은 필드는 계속 보여요.
- 숨겨진 필드는 기존 값을 그대로 유지해요.
- 숨겨진 필드는 필수 입력 검사에서 제외돼요.
- 여러 규칙이 적용되면 각 규칙의 필수 요건이 합쳐져요.
- 조건부 검사는 Public API나 워크플로우로 하는 업데이트에는 적용되지 않아요.

## 자주 묻는 질문

### 규칙 조건을 충족하지 않았는데 필드가 계속 보여요. 왜 그런가요?
**필드 표시** 또는 **폴더 표시** 결과에 포함된 필드만 기본적으로 숨겨져요. 표시 규칙에 포함하지 않은 필드는 계속 보여요.

### 필드가 숨겨지면 이미 입력된 값은 어떻게 되나요?
값은 그대로 유지돼요. 필드를 숨겨도 기존 데이터가 삭제되거나 바뀌지 않아요.

### 숨겨진 필드도 필수 입력 검사에 포함되나요?
아니요. 숨겨진 필드는 화면에 나타나기 전까지 필수 입력 검사에서 제외돼요.

### 기회에 여러 규칙이 적용되면 어떻게 되나요?
적용되는 결과가 합쳐져요. 사용자는 그 규칙들이 필수로 설정한 필드 중 화면에 보이는 필드를 모두 입력해야 해요.

### 조건부 필드가 나타나지 않아요. 무엇을 확인해야 하나요?
다음 항목을 확인하세요.

- 기능이 켜져 있는지
- 규칙이 저장되어 있는지
- 기회가 규칙의 트리거 조건과 일치하는지
- 올바른 파이프라인, 단계, 상태, 필드 값이 선택되어 있는지
- 해당 필드나 폴더가 표시 결과에 포함되어 있는지

### 조건 규칙이 API나 워크플로우 업데이트에도 적용되나요?
조건부 검사는 웹과 모바일에서 지원되는 저장 작업에 적용돼요. Public API나 워크플로우로 하는 업데이트에는 적용되지 않아요.
