# 같은 파이프라인에서 한 연락처에 기회를 여러 개 만들기

**Allow Multiple Opportunities per Contact**(연락처당 여러 기회 허용) 설정을 켜면, 같은 연락처의 기회를 같은 파이프라인에서 2개 이상 진행할 수 있어요. 갱신, 추가 판매, 여러 상품을 함께 제안하는 경우에도 기회를 정확하게 관리할 수 있고, 자동화와 리포트도 일관되게 유지돼요. 이 문서에서는 설정을 켜는 방법, 워크플로우가 충돌하지 않게 하는 방법, 활용 팁을 안내해요.

## Allow Multiple Opportunities per Contact란?

**Allow Multiple Opportunities per Contact**는 하이퍼클래스의 서브 계정 설정이에요. 이 설정을 켜면 같은 파이프라인에서 한 연락처에 기회를 2개 이상 둘 수 있어요. 갱신, 추가 상품(애드온), 상품군별 병행 판매, 여러 지점의 서비스 같은 경우에도 연락처 한 명당 기록을 깔끔하게 유지할 수 있어요.

## 이 설정을 켜면 좋은 점

이 기능을 켜면 연락처가 파이프라인과 자동화를 거치는 방식이 달라져요. 아래 내용을 보고 언제 쓸지, 중복 발송은 어떻게 줄일지 정해 보세요.

- 갱신·추가 판매: 같은 고객의 새 매출 건을 기존 기회를 덮어쓰지 않고 따로 관리할 수 있어요.
- 병행 제안: 서로 다른 상품이나 서비스의 기회를 동시에 진행할 수 있어요.
- 명확한 자동화 조건: 기회가 여러 개여도 워크플로우 액션으로 원하는 기회만 골라 처리할 수 있어요.
- 정확한 매출 예측: 고객에게 진행 중인 딜이 여러 개일 때 파이프라인 전체 금액을 확인할 수 있어요.
- 유연한 운영: 같은 연락처가 여러 번 문의하는 다지점·프랜차이즈 상황도 관리할 수 있어요.

## 설정 방법

설정을 올바르게 켜 두면 한 연락처에 기회 카드를 여러 개 만들 수 있고, 자동화도 예측한 대로 동작해요. 아래 순서대로 설정한 뒤 샘플 데이터로 꼭 테스트해 보세요.

1. **서브 계정 설정 > 오브젝트 > 기회 관리**로 이동하세요.
2. **Allow Multiple Opportunities per Contact** 토글을 켜세요.
3. **변경사항 저장**을 클릭하세요.

   ![설정 토글을 켜고 변경사항을 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052690324/original/VTTWy0o29_3ZX1Ffbpm53K21G8osCaIoSQ.gif?1756473412)

4. 같은 파이프라인에서 한 연락처에 기회를 2개 만들어 보세요. 두 기회가 모두 보이는지, 자동화가 예상대로 실행되는지 확인하세요.

   ![같은 연락처에 기회 2개를 만들어 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052691214/original/jyR-HEBDl3Si9wxxpwy7_jbDHnivNNHTGg.gif?1756473954)

## 자주 묻는 질문

### 이 설정을 켜면 기존 기회가 바뀌나요?
기존 기회 카드는 그대로 유지돼요. 설정을 켜면 같은 파이프라인을 포함해 같은 연락처에 기회 카드를 추가로 만들 수 있게 될 뿐이에요.

### 나중에 설정을 끄면 어떻게 되나요?
기존 기회 카드는 삭제되지 않아요. 대신 같은 파이프라인에서 같은 연락처의 중복 기회를 새로 만드는 것은 제한돼요. 기회 생성·업데이트 오류가 나지 않도록 자동화를 미리 점검하세요.

### 설정을 꺼 두면 다른 파이프라인에는 한 연락처의 기회를 여러 개 둘 수 있나요?
이 설정은 같은 파이프라인 안에서 같은 연락처의 중복 기회를 다루는 설정이에요. 파이프라인이 서로 다른 경우에는 파이프라인 구성과 생성 규칙에 따라 동작이 달라져요. 워크플로우를 직접 테스트해서 확인하세요.

### 자동화가 알맞은 기회 카드에서 실행되게 하려면 어떻게 하나요?
**Find Opportunity**(기회 찾기) 액션으로 가장 오래된 기회, 가장 최근 기회, 또는 조건에 맞는 기회를 고르세요. 의도하지 않은 재진입을 막으려면 진입 필터도 함께 설정하세요.

### 예측 금액이 중복 집계되나요?
예측과 파이프라인 합계에는 진행 중인 기회가 모두 반영돼요. 대시보드와 리포트도 이 점을 고려해서 구성하세요.

### 워크플로우 단계의 **Duplicate Opportunity**(기회 복제) 옵션과 같은 건가요?
아니요. 워크플로우의 복제 옵션은 해당 액션의 동작만 정해요. 이 설정은 연락처 한 명에 기회 카드를 여러 개 만드는 것을 허용할지 전체적으로 정해요.

### 사용자 권한도 바꿔야 하나요?
사용자가 파이프라인에 접근하고 기회를 만들고 업데이트할 수 있는지 확인하세요. 필요하면 역할을 조정하세요.

### 기회가 여러 개일 때 메시지가 중복 발송되지 않게 하려면 어떻게 하나요?
다음과 같이 안전장치를 추가하세요. **Find Opportunity**를 사용하고, 트리거 조건을 더 좁히고, 재진입 규칙이나 발송 제외 조건을 적용하세요.
