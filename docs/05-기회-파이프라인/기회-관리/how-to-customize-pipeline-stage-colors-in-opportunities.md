# 기회 관리에서 파이프라인 단계 색상 설정하기

파이프라인 단계마다 색상을 지정하면 기회를 한눈에 훑어보고 파이프라인을 더 빠르게 관리할 수 있어요. 이 문서에서는 **기회 관리**의 파이프라인 드롭다운에서 파이프라인을 만들고 편집하는 방법과, 단계 색상을 지정해 칸반·목록·상세 화면에 표시하는 방법을 안내해요.

## 파이프라인 단계 색상이란?

파이프라인 단계 색상은 하이퍼클래스 **기회 관리**(Opportunities)에서 쓸 수 있는 기능이에요. 파이프라인을 만들거나 편집할 때 **설정**으로 이동할 필요 없이, **기회 관리**의 파이프라인 드롭다운에서 바로 할 수 있어요. 각 단계에 색상을 지정하면 여러 화면에서 같은 색으로 표시돼요.

단계 색상은 파이프라인마다 설정해요. 작은 색상 점이나 배경 색조로 표시할 수 있어서, 각 기회가 프로세스의 어느 단계에 있는지 팀원이 빠르게 알아볼 수 있어요.

---

## 단계 색상의 장점

클릭 수는 줄이고 화면은 더 알아보기 쉽게 만들어 주는 기능이에요. 아래 장점을 참고해서 파이프라인을 어떻게 설정할지, 조직 안에서 색상 규칙을 어떻게 맞출지 정해 보세요.

- **기회 관리에서 바로 파이프라인 관리:** 파이프라인 드롭다운에서 파이프라인을 만들거나 편집할 수 있어요. **기회 관리** 화면을 떠나거나 **설정**으로 이동하지 않아도 돼요.
- **화면이 달라도 같은 색상 규칙:** 단계 색상이 칸반(보드) 보기, 목록 보기, 기회 카드, 상세 화면에 똑같이 표시돼요.
- **기회를 더 쉽게 훑어보기:** 색상 점이나 배경 색조 덕분에 열이나 목록을 빠르게 살펴보고, 우선순위를 찾고, 병목 구간을 파악할 수 있어요.
- **팀 전체가 같은 설정 사용:** 색상은 파이프라인 단위로 설정하므로 모두가 같은 색상을 봐요. CRM 화면이 일관되게 유지돼요.
- **다른 시각 도구와 함께 사용:** 단계 색상은 [스마트 태그](how-to-color-code-opportunity-pipelines-smart-tags.md), [기회 카드 레이아웃 사용자 지정](../customize-opportunity-cards-in-board-view.md) 같은 기능과 함께 쓸 수 있어요. 기회마다 더 풍부한 시각 정보를 볼 수 있어요.

---

## 파이프라인 드롭다운에서 바로 이동하기

평소 파이프라인을 전환할 때 쓰던 드롭다운에서 파이프라인을 만들고 편집할 수 있어요. 화면을 오가는 일이 줄어서, 관리자나 영업 리더가 그 자리에서 파이프라인을 조정하기 쉬워요.

**기회 관리**에서 작업할 때는 다음과 같아요.

- 화면 위쪽의 파이프라인 드롭다운에 아래 항목이 추가돼요.
  - 파이프라인을 바로 만드는 **+ Create Pipeline**(+ 파이프라인 만들기) 항목
  - 각 파이프라인 옆 점 세 개 메뉴 아래의 편집 항목. 파이프라인 설정을 수정할 수 있어요.
- 기회를 살펴보거나 관리하던 화면을 벗어나지 않고 파이프라인 구조를 다듬을 수 있어요.
- 파이프라인을 만들거나 편집할 수 있는지는 사용자 역할과 파이프라인 권한에 따라 달라요. 드롭다운은 보이지만 편집 항목은 보이지 않는 사용자도 있을 수 있어요.

---

## 단계 색상 지정

파이프라인의 단계마다 서로 다른 색상을 지정할 수 있어요. 예를 들어 신규 리드, 핫딜, 온보딩 같은 단계를 색으로 구분하면 팀이 같은 시각 규칙을 쓰게 돼요. 색상을 잘 골라 두면 파이프라인 검토가 더 빠르고 직관적이에요.

핵심 개념은 다음과 같아요.

- 색상은 파이프라인마다 지정해요. 파이프라인마다 목적에 맞는 단계 색상 조합을 따로 쓸 수 있어요.
- 모든 단계에 색상을 지정할 수 있어요. 기본 단계는 물론 직접 만든 단계도 영업이나 서비스 프로세스에 맞게 색을 고를 수 있어요.
- 색상 설정은 모두에게 공유돼요. 한 번 설정하면 그 파이프라인을 볼 수 있는 모든 사용자에게 같은 색상이 보여요.

---

## 단계 색상 표시 방식

표시 방식에 따라 선택한 색상이 화면에 나타나는 모습이 달라져요. 은은한 표시(점)와 강한 표시(배경 색조) 중에서 고를 수 있어요. 화면이 복잡해지지 않으면서 단계가 눈에 띄는 방식을 골라 보세요.

표시 방식은 세 가지예요.

- **기본값 (색상 없음)**
  - 단계 색상을 추가하지 않은 하이퍼클래스 기본 화면 그대로 보여요.
  - 화면을 단순하게 쓰고 싶거나 이제 막 파이프라인을 쓰기 시작했다면 알맞아요.
- **색상 점**
  - 단계 이름이나 기회 옆에 작은 색상 점이 표시돼요. 카드나 행 전체는 바뀌지 않아서 은은하게 구분할 수 있어요.
  - 색상 표시는 원하지만 배경은 깔끔하게 두고 싶을 때 좋아요.
- **배경 색조**
  - 카드나 행(또는 둘 다)의 배경에 단계 색상을 연하게 입혀요.
  - 단계를 더 뚜렷하게 구분하고 한눈에 알아보고 싶은 팀에 알맞아요.

이 표시 방식은 파이프라인의 단계 설정에서 언제든 바꿀 수 있어요.

## 단계 색상이 표시되는 위치

단계 색상은 CRM의 여러 화면에서 똑같이 보일 때 가장 효과적이에요. 한 번 지정한 색상은 기회를 어느 화면에서 보든 따라가므로, 팀이 어디서나 같은 의미로 읽을 수 있어요.

설정이 끝나면 단계 색상이 다음 위치에 표시돼요.

- 칸반(보드) 보기
  - 각 단계 열의 카드에 색상 점이나 배경 색조가 표시돼요. 파이프라인의 흐름을 바로 읽을 수 있어요.
- 기회 [목록 보기](../list-view-for-opportunities.md)
  - 표 형태의 목록에서 기회 옆에 단계 색상이 표시돼요. 한 화면에서 자세한 데이터와 단계 색상을 함께 볼 수 있어요.
- 기회 카드와 상세 화면
  - 개별 기회 화면과 연락처 상세 화면에도 단계 색상이 적용돼요. 메인 칸반 화면이 아니어도 기회가 파이프라인의 어느 위치에 있는지 알 수 있어요.

단계 색상은 파이프라인 단위 설정이라서, 그 파이프라인에 접근할 수 있는 모든 사용자가 같은 색상 구성을 봐요.

![단계 색상이 표시되는 화면 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069772874/original/9sm6E6tY3kXus9QC9hIXjSnkyCop2tQPSA.gif?1776936354)

## 기회 관리에서 파이프라인 단계 색상 설정하기

아래 순서대로 설정하면 팀이 **기회 관리**에서 파이프라인을 빠르게 조정하고, 실제 업무 흐름에 맞게 색상을 쓸 수 있어요. 파이프라인 하나 또는 여러 개에 단계 색상을 설정하는 과정을 차례로 안내해요.

### 기회 관리의 파이프라인 메뉴 열기

1. 서브 계정의 왼쪽 메뉴에서 **기회 관리**를 클릭해요.
2. 화면 위쪽의 **파이프라인** 탭을 클릭해요.
3. 새 파이프라인을 만들려면 오른쪽 위에 있는 **+ Create Pipeline** 버튼을 클릭해요.

이렇게 하면 **기회 관리** 화면을 떠나지 않고 파이프라인을 설정하고 관리할 수 있어요.

![기회 관리의 파이프라인 탭과 + Create Pipeline 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069764577/original/QkmhatvRoVBjHSbdK6B-fjX-hDwh8HvVtA.png?1776932257)

### 파이프라인 만들기

**+ Create Pipeline** 버튼을 클릭하면 **기회 관리** 화면에서 바로 새 파이프라인을 만들 수 있어요. 갱신이나 온보딩처럼 기회를 별도의 프로세스로 나누고 싶을 때 쓰면 워크플로우를 체계적으로 관리하기 좋아요.

![파이프라인 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069766741/original/3zp59v5gOHKTW3bdZbLTtzA3GWOD-qOEVg.png?1776933559)

### 기존 파이프라인 편집하기

새로 만들 필요가 없다면 기존 파이프라인을 수정할 수도 있어요.

1. 수정할 파이프라인 옆의 점 세 개(⋮) 메뉴를 클릭해요.
2. **편집**을 선택해요.

이미 있는 프로세스에서 단계를 다듬거나, 확률을 바꾸거나, 단계 색상을 적용할 때 편리해요.

### 파이프라인 이름 입력하기

**파이프라인 이름**에 파이프라인의 목적이 잘 드러나는 이름을 입력해요. 예를 들면 "영업 파이프라인"이나 "고객 온보딩"이에요. 이름이 분명하면 팀이 파이프라인을 쉽게 구분하고 전환할 수 있어요.

기회마다 확률을 따로 지정하고 싶다면 **Opportunity-level probability**(기회별 확률) 토글을 켜세요. 직접 예측을 세울 때 유용해요. 단계별 확률을 따르는 표준 방식을 쓰려면 토글을 꺼 두세요.

### 단계 색상 지정하기

**색상 옵션**으로 파이프라인에 색상 표시가 어떻게 나타날지 정할 수 있어요. 표시 방식을 잘 고르면 팀이 기회를 검토하고 관리하는 방식에 맞게 알아보기 쉬움과 단순함 사이의 균형을 맞출 수 있어요.

각 단계에 의미를 나타내는 색상을 지정하세요. 예를 들어 초록은 고객전환성공, 빨강은 위험, 노랑은 후속 조치로 정할 수 있어요.

#### 기본값 (색상 없음)

단계에 색상 표시를 적용하지 않아 파이프라인이 깔끔하게 유지돼요. 팀이 색상보다 필터, 태그, 상세 데이터를 주로 쓸 때 선택하세요. 색상 없이도 기회 진행 상황을 파악할 수 있는 단순한 워크플로우에 가장 잘 맞아요.

![기본값 (색상 없음) 표시 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069768465/original/yFfybM8Arcg1yQUhkmssp-mpoJw3ieVWkw.png?1776934333)

#### 색상 점

각 단계 옆에 작은 색상 점을 붙여 은은하게 구분해 줘요. 목록 위주로 작업하면서 화면을 복잡하게 만들지 않고 단계를 빠르게 확인하고 싶을 때 쓰세요. 레이아웃은 깔끔하게 유지하면서 시각 정보를 더할 수 있어요.

![색상 점 표시 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069773198/original/ugcDaSV4WmWmEaFLuROEgYWG2Ce4P7ZY9w.png?1776936506)

#### 배경 색조

단계의 행이나 카드 전체에 연한 색조를 입혀 단계가 눈에 확 띄어요. 파이프라인을 빠르게 훑어보거나, 우선순위를 찾거나, 기회가 많을 때 쓰면 좋아요. 파이프라인 검토 중에 빠르게 눈으로 알아보는 영업팀에 특히 유용해요.

![배경 색조 표시 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069773286/original/euJR9IAnDe0DzxebLFvIpiF7c1ANBIbaSg.png?1776936562)

### 권한 확인하고 팀에 공유하기 (선택이지만 권장)

- 관리자라면 **파이프라인 권한**을 확인하세요. 파이프라인 구조와 단계 색상은 필요한 사용자만 수정하게 하고, 나머지 사용자는 색상 표시를 그대로 볼 수 있어요. 자세한 내용은 [파이프라인 권한 관리](how-to-manage-pipeline-permissions.md)를 참고하세요.
- 색상 규칙(예: 각 색상이 무슨 뜻인지)을 팀에 알려 주세요. 모두가 같은 의미로 읽을 수 있어요.
- 팀이 색상을 어떻게 쓰는지 지켜보면서 필요에 따라 조정하세요.
- 새 단계나 프로세스가 생기면 색상도 함께 업데이트해서 시각 규칙이 흐트러지지 않게 하세요.

색상과 이동 방법 이외의 파이프라인 전반 설정은 [단계별 가이드: 파이프라인 만들기](../step-by-step-guide-creating-pipelines.md)를 참고하세요.

## 자주 묻는 질문

### 단계 색상은 사용자마다 다르게 보이나요, 아니면 모두 같나요?
단계 색상은 파이프라인 단위로 설정돼요. 그 파이프라인에 접근할 수 있는 모든 사용자에게 똑같이 적용돼요. 개별 사용자가 자기 화면에서만 색상을 바꿀 수는 없어요.

### 파이프라인마다 다른 색상 구성을 쓸 수 있나요?
네. 파이프라인마다 단계 색상과 표시 방식을 따로 지정할 수 있어요. 영업 파이프라인, 온보딩 파이프라인, 지원 파이프라인이 각각 다른 색상 구성을 쓸 수 있어요.

### 스마트 태그 같은 다른 색상 표시와는 뭐가 다른가요?
단계 색상은 기회가 파이프라인의 어느 단계에 있는지를 나타내요. [스마트 태그](how-to-color-code-opportunity-pipelines-smart-tags.md)는 금액, 경과 기간, 활동 같은 조건에 따라 기회에 색상을 입히는 규칙 기반 레이블이에요. 두 가지를 함께 쓰는 팀이 많아요. 프로세스 단계는 단계 색상으로, 긴급도나 상태는 스마트 태그로 표시하는 식이에요.

### 파이프라인에 색상을 아예 쓰고 싶지 않아요.
단계를 **기본값 (색상 없음)**으로 설정하면 돼요. 추가된 색상이 사라지고 파이프라인 구조는 그대로 유지돼요. 화면을 단순하게 쓰고 싶거나, 색상보다 태그와 필터를 주로 쓴다면 이 설정이 알맞아요.

### 모든 사용자가 기회 관리의 드롭다운에서 파이프라인을 만들거나 편집할 수 있나요?
아니요. 드롭다운에서든 **파이프라인** 페이지에서든, 파이프라인을 만들고 편집할 수 있는지는 사용자 역할과 파이프라인 권한에 따라 달라요. 관리자는 특정 파이프라인을 누가 보고 수정할 수 있는지 제한할 수 있어요.

### 단계 색상이 자동화나 리포팅에 영향을 주나요?
단계 색상은 화면 표시용일 뿐이에요. 자동화가 실행되는 방식이나 데이터가 계산되는 방식은 바뀌지 않아요. 다만 파이프라인 단계를 기준으로 한 대시보드와 리포팅 화면을 읽기는 더 쉬워질 수 있어요.

### 내보낸 데이터에도 단계 색상이 표시되나요?
내보내기에는 단계 이름만 포함되고 색상 표시는 포함되지 않아요. 색상은 하이퍼클래스 화면 안에서만 적용되고, CSV나 외부 파일에는 적용되지 않아요.

### 단계 이름을 바꾸거나 순서를 바꾸면 색상은 어떻게 되나요?
파이프라인 안에서 단계 이름이나 순서를 바꾸면 색상도 그 단계를 따라 이동해요. 색상 설정은 화면상의 위치가 아니라 단계 자체에 연결돼 있어요.
