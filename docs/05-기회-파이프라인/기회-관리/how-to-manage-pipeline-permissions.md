# 파이프라인 권한 관리

영업 파이프라인마다 누가 보고 누가 바꿀 수 있는지 정할 수 있어요. 민감한 딜은 비공개로 두고, 팀원에게는 역할에 맞는 화면만 보여 줄 수 있어요. 이 문서에서는 하이퍼클래스에서 파이프라인 권한을 관리하는 방법을 안내해요.

## 파이프라인 권한이란?

파이프라인 권한은 **기회 관리**(Opportunities) 안의 파이프라인별로 볼 수 있는 범위와 편집 권한을 정하는 기능이에요. 관리자는 모든 사용자에게 권한을 주거나, 특정 역할·사용자를 지정하거나, 일부 사용자를 직접 제외할 수 있어요. 서브 계정의 전체 역할은 바꾸지 않아도 돼요. 이렇게 세밀하게 공개 범위를 정하면 데이터를 안전하게 지키고, 영업팀은 자기에게 필요한 딜에만 집중할 수 있어요.

## 파이프라인 권한의 주요 장점

- 일관성: 단계 이름과 순서는 그대로 유지하면서, 담당자는 딜을 계속 처리할 수 있어요.
- 데이터 개인정보 보호: 외부 계약자나 신규 직원에게 매출·보드 데이터를 숨길 수 있어요.
- 세밀한 제어: 모든 사용자와 공유하거나, 특정 사용자와 공유하거나, 예외 사용자를 제외할 수 있어요.
- 감사 추적: 누가 파이프라인 설정을 바꿨는지 추적해서 컴플라이언스 요건에 대응할 수 있어요.
- 플랫폼 공통 적용: 웹과 하이퍼클래스 모바일 앱에 같은 권한이 적용돼요.
- 대시보드 일치: 대시보드의 위젯과 지표도 파이프라인 액세스와 **Assigned Data**(할당된 데이터)를 따라요.

## 파이프라인 권한 설정하기

아래 순서대로 따라 하면 파이프라인마다 누가 보고 편집할 수 있는지 설정할 수 있어요. 단계 구조와 민감한 매출 데이터도 함께 보호할 수 있어요.

1. **기회 관리 > 파이프라인**으로 이동하세요.

   ![기회 관리의 파이프라인 화면](https://jumpshare.com/share/Ios9ymH4r1c5gM8yvDxx+/Screen+Shot+2026-02-09+at+7.31.12+PM.png)

2. 파이프라인 이름 옆의 **키** 아이콘을 클릭하면 **권한 관리**가 열려요.

   ![파이프라인 이름 옆 키 아이콘](https://jumpshare.com/share/KIWixyBYGFKfP7dFSurB+/Screen+Shot+2026-02-09+at+7.34.08+PM.png)

3. **Sharing mode**(공유 방식)를 선택하세요. **모든 사용자와 공유**, **선택한 사용자와 공유**, **Exclude specific users**(특정 사용자 제외) 중에서 고를 수 있어요.

   ![공유 방식 선택 화면](https://jumpshare.com/share/uW4VpLaqpDTccl4woHI0+/Screen+Shot+2026-02-09+at+7.24.56+PM.png)

4. 포함된 사용자나 역할마다 **액세스 수준**을 설정하세요. **View Only**(보기 전용), **편집**, **No Access**(액세스 없음) 중에서 고를 수 있어요.

   ![액세스 수준 설정 화면](https://jumpshare.com/share/MefKbpikfyLgjuWSgt41+/Screenshot+2026-02-09+at+7.38.01%E2%80%AFPM.png)

5. (선택 사항) 이미 권한이 있는 팀원에게 파이프라인 바로가기를 공유하려면 **링크 복사**를 클릭하세요.

   ![링크 복사 버튼](https://jumpshare.com/share/PoctQ4SHFuobYR1mTpYa+/Screen+Shot+2026-02-09+at+7.40.13+PM.png)

6. **저장**을 클릭해서 적용하세요.

   ![저장 버튼](https://jumpshare.com/share/XGgwPAFOvDpeK3bm2UsL+/Screen+Shot+2026-02-09+at+7.41.54+PM.png)

## 파이프라인 권한의 공유 방식

파이프라인마다 세 가지 방식으로 공유할 수 있어서, 어떤 조직 구조에도 맞출 수 있어요.

- **모든 사용자와 공유**: 모든 사용자에게 **View Only**, **편집**, **No Access** 중 하나를 한 번에 적용해요.
- **선택한 사용자와 공유**: 사용자나 역할을 직접 골라 각각 **View Only**, **편집**, **No Access**를 설정해요.
- **Exclude specific users**: 파이프라인을 전체 공개로 두고, 일부 예외 사용자만 액세스를 제거해요.

![공유 방식 선택 화면](https://jumpshare.com/share/uW4VpLaqpDTccl4woHI0+/Screen+Shot+2026-02-09+at+7.24.56+PM.png)

## 파이프라인 권한의 액세스 수준

이름만 봐도 각 사용자가 무엇을 할 수 있는지 알 수 있어요.

{% hint style="info" %}
관리자 사용자는 항상 파이프라인에 대한 모든 권한을 가져요.
{% endhint %}

- **View Only**: 기회를 이동하고 업데이트할 수 있어요. 단계나 파이프라인을 추가·편집·삭제할 수는 없어요.
- **편집**: 파이프라인 단계를 추가·편집·삭제할 수 있고, 파이프라인 자체도 관리할 수 있어요.
- **No Access**: 웹, 모바일, API 응답에서 파이프라인이 완전히 숨겨져요.

![액세스 수준 설정 화면](https://jumpshare.com/share/MefKbpikfyLgjuWSgt41+/Screenshot+2026-02-09+at+7.38.01%E2%80%AFPM.png)

## 감사 로그와 안전장치

하이퍼클래스는 권한을 만들거나 수정하거나 회수할 때마다 사용자, 파이프라인, 작업, 시간을 자동으로 기록해요. 기록은 60일 동안 보관돼요. 이 감사 기록은 문제를 찾거나 컴플라이언스를 검토할 때 도움이 돼요.

1. **설정 > 감사 로그**로 이동하세요.

   ![감사 로그 메뉴로 이동하는 화면](https://jumpshare.com/share/OZguNUBFCClOrApXHjfL+/GIF+Recording+2026-02-09+at+7.58.37+PM.gif)

2. **사용자**, **모듈**(**파이프라인 권한**), **Actions**(작업), **Date Range**(기간)로 필터링하면 누가 언제 무엇을 바꿨는지 확인할 수 있어요.

   ![감사 로그 필터 화면](https://jumpshare.com/share/yBJXEproMLpU1nwCIQuF+/Screen+Shot+2026-02-09+at+8.03.57+PM.png)

3. 해당 파이프라인에서 기회를 담당하고 있는 사용자의 액세스는 회수할 수 없어요. 먼저 담당자를 다른 사용자로 바꾸라는 안내가 나타나요.

   ![담당자 재지정 안내 화면](https://jumpshare.com/share/yEBWJSWsfvOYhJoFDBjC+/sHUEjYNe0ST15mQhinHzyua2gUV8i1XCAA.jpeg)

## 자주 묻는 질문

### **View Only**와 **No Access**는 어떻게 다른가요?

**View Only** 사용자는 파이프라인 안에서 자신에게 배정된 기회를 이동하거나 업데이트할 수 있어요. **No Access**는 파이프라인을 완전히 숨겨요.

### 이미 기회를 담당하고 있는 사용자를 **No Access**로 설정하면 어떻게 되나요?

하이퍼클래스가 변경을 막아요. 먼저 해당 사용자의 기회를 다른 사용자에게 재배정하거나 삭제한 뒤 액세스를 제거하세요.

### 권한이 모바일 앱에도 똑같이 적용되나요?

네. 웹, iOS, Android, 모든 API 응답에 같은 규칙이 적용돼요.

### 사용자마다 설정하지 않고 역할 단위로 권한을 한 번에 줄 수 있나요?

네. 선택 목록에 역할도 나타나요. 해당 역할에 속한 모든 사용자가 선택한 수준을 그대로 적용받아요.

### 권한을 바꾸면 실행 중인 자동화나 웹훅이 멈추나요?

아니요. 자동화는 계속 실행돼요. 다만 액세스가 없는 사용자 토큰으로 API를 호출하면 빈 파이프라인 목록이 반환돼요.

### "소유자 전용" 옵션이 있나요?

따로 없어요. **선택한 사용자와 공유**를 선택한 뒤 소유자를 고르고, 나머지 사용자는 **No Access**로 설정하면 소유자만 쓰는 파이프라인이 돼요.

### 감사 로그는 얼마나 오래 보관되나요?

60일 동안의 기록을 내려받거나 확인할 수 있어요.
