# 기회 관리에서 파이프라인(Pipeline) 순서 변경하기

기회 관리(Opportunities)의 파이프라인 뷰에서 바로 파이프라인 순서를 원하는 대로 정리할 수 있어요. 드래그해서 순서를 바꾸거나, 원하는 위치로 정확하게 이동시킬 수도 있습니다. 변경한 순서는 자동으로 저장되며, 페이지를 새로고침해도 그대로 유지돼요.

목차

- [드래그 앤 드롭으로 순서 변경하기](#Reorder-by-drag-and-drop)
- [특정 위치로 파이프라인 이동하기](#Move-a-pipeline-to-a-specific-position)
- [알아두면 좋은 점](#Good-to-know)

## 드래그 앤 드롭으로 순서 변경하기

- 기회 관리(Opportunities)로 이동한 후 파이프라인(Pipelines) 탭을 엽니다.
- 각 파이프라인 행 왼쪽에 있는 드래그 핸들(점선 아이콘) 위에 마우스를 올려주세요.
- 원하는 위치로 파이프라인을 위아래로 드래그한 다음 놓으세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472806/original/Tqtv9kpzrPj2bm_NhWTCb__8RzjPP5th-w.png?1781185020)
드래그 핸들을 잡고 파이프라인 순서를 변경하는 모습입니다.

## 특정 위치로 파이프라인 이동하기

파이프라인을 정확한 위치에 배치하고 싶을 때 사용하는 방법이에요. 페이지 간에도 적용되기 때문에, 현재 보고 있는 페이지에 없는 파이프라인이라도 위치를 바꿀 수 있습니다.

- 파이프라인 행에서 ⋯ (점 3개) 액션 메뉴를 클릭하세요.
- 위치로 이동(Move to position)을 선택하세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472807/original/86l1JNPREH6Z_oKFRXp_a2dBRDnblAOyYQ.png?1781185020)
액션 메뉴를 열고 위치로 이동을 선택하세요.
- 파이프라인 순서 변경(Reorder Pipeline) 대화상자에서 원하는 위치 번호를 입력하세요.
- 적용(Apply)을 클릭하세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472805/original/ZJKnO2kbz68NbrraUQFV9vpX4eWGXsrRgw.png?1781185020)
원하는 위치를 입력하고 적용을 클릭하세요.
파이프라인이 해당 위치로 이동하고 목록 번호가 자동으로 재정렬돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472808/original/FQXvC1zo6VxUPQr2-2q84grr69VZxcraBw.png?1781185020)
변경된 순서가 목록에 바로 반영됩니다.

## 알아두면 좋은 점

- 변경한 순서는 자동으로 저장돼요 — 별도의 저장(Save) 버튼은 없습니다.
- 설정한 순서는 페이지를 새로고침해도 그대로 유지돼요.
- 위치로 이동(Move to position) 기능은 페이지 간 이동도 지원해서, 여러 파이프라인을 관리할 때 유용해요.
- 이 기능은 관리자(Admin)만 사용할 수 있으며, 설정한 순서는 해당 로케이션의 모든 사용자에게 동일하게 적용됩니다.
