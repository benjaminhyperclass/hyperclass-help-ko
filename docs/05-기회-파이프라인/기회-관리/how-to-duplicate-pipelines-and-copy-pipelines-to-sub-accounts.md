# 파이프라인 복제 및 서브 계정에 복사하기

이 문서에서는 기존 파이프라인을 같은 서브 계정 안에서 복제하거나, 다른 서브 계정으로 복사하는 방법을 안내해요. 파이프라인 구조를 처음부터 다시 만들지 않고 그대로 가져다 쓸 때 유용해요.

## 파이프라인 복제와 서브 계정에 복사란?

파이프라인 복제와 서브 계정에 복사 기능을 쓰면 기존 기회 파이프라인을 다시 만들지 않고 재사용할 수 있어요. 영업 프로세스를 표준화하고, 설정 시간을 줄이고, 계정마다 파이프라인 구조를 똑같이 유지하기 좋아요. 같은 서브 계정 안에 파이프라인 사본을 만들 때는 복제를, 파이프라인을 하나 이상의 서브 계정으로 보낼 때는 복사를 쓰세요.

비슷한 영업 파이프라인을 여러 서브 계정에서 운영하면 같은 설정을 계속 반복해야 해요. 이 기능을 쓰면 에이전시 관리자는 파이프라인을 다른 서브 계정으로 빠르게 복사할 수 있고, 권한이 있는 사용자는 같은 서브 계정 안에서 파이프라인을 복제할 수 있어요. 시간을 아끼면서 계정 간 일관성도 지킬 수 있어요.

## 이 기능을 쓰면 좋은 점

- **빠른 설정:** 단계를 하나씩 만들 필요 없이 기존 파이프라인을 재사용해요.
- **일관성 향상:** 서브 계정끼리 영업 프로세스를 같게 맞춰요.
- **간편한 온보딩:** 검증된 파이프라인 구조를 새 서브 계정에 더 빠르게 적용해요.
- **수작업 감소:** 여러 계정을 관리할 때 반복되는 설정 작업을 줄여요.
- **안전한 테스트:** 같은 서브 계정에서 파이프라인을 복제해 변경 사항을 먼저 시험해 볼 수 있어요.

## 중복과 서브 계정에 복사의 차이

두 기능의 차이를 알면 목적에 맞는 쪽을 고르기 쉬워요. 하나는 같은 서브 계정 안에서 재사용하는 용도이고, 다른 하나는 여러 서브 계정에 배포하는 용도예요.

- **중복:** 같은 서브 계정 안에 기존 파이프라인의 사본을 만들어요.
- **서브 계정에 복사:** 파이프라인의 사본을 다른 서브 계정 하나 이상에 보내요.
- **중복을 쓰면 좋은 경우:** 변형을 시험해 보고 싶을 때, 비슷한 파이프라인을 하나 더 만들고 싶을 때, 같은 계정에서 단계를 다시 만들기 번거로울 때예요.
- **서브 계정에 복사를 쓰면 좋은 경우:** 고객사 계정이나 지점 계정 전체에 파이프라인 구조를 표준화하고 싶을 때예요.

## 필요한 권한

파이프라인을 복제하거나 복사할 수 있는지는 사용자의 역할과 파이프라인 권한에 따라 달라요. 파이프라인 메뉴에서 두 기능 중 하나 또는 둘 다 보이지 않는다면 먼저 아래 권한을 확인해 보세요.

- **중복:** 해당 파이프라인에 편집 권한이 있는 사용자가 쓸 수 있어요.
- **서브 계정에 복사:** 에이전시 관리자만 쓸 수 있어요.

## 복사되는 항목과 복사되지 않는 항목

파이프라인과 함께 무엇이 옮겨지는지 미리 알아 두면 복제나 복사 전에 기대치를 맞출 수 있어요. 서브 계정 간에 복사할 때는 일부 설정이 함께 옮겨지지 않으니 특히 주의하세요.

**같은 서브 계정 안에서 파이프라인을 복제하면** 아래 항목이 복사돼요.

- 파이프라인 단계
- 파이프라인 권한
- 색상 스마트 태그
- 차트 표시 설정

**파이프라인을 다른 서브 계정으로 복사하면** 아래 항목이 복사돼요.

- 파이프라인 단계
- 차트 표시 설정

아래 항목은 **복사되지 않아요.**

- 레코드
- 자동화
- 리포트
- 커스텀 필드

다른 서브 계정으로 복사할 때는 아래 항목도 **복사되지 않아요.**

- 파이프라인 권한
- 색상 스마트 태그

## 같은 서브 계정에서 파이프라인 복제하기

파이프라인을 복제하면 같은 서브 계정 안에 사본이 만들어져요.

1. **기회 관리**(Opportunities) > **파이프라인**으로 이동하세요.
2. 복제할 파이프라인을 찾아 오른쪽의 점 세 개(⋮) 메뉴를 클릭하고 **중복**을 선택하세요.

   ![파이프라인 점 세 개 메뉴에서 중복 선택](https://jumpshare.com/share/mJPEKAEkS8TZRmLCvkzP+/Screen+Shot+2026-04-14+at+18.55.02.png)
3. **파이프라인 복제** 창이 열려요.
4. **파이프라인 이름**에 복제본의 새 이름을 입력하세요. 기본값으로 이름 뒤에 "(copy)"가 붙어서 나와요.
5. **파이프라인 표시 색상 설정**에서 파이프라인 보기마다 단계 색상을 어떻게 보여 줄지 선택하세요.
6. **파이프라인 단계**에서 단계를 재배치하거나 이름을 바꾸고, 추가하거나 삭제하세요.
7. **Choose show in report options**(리포트 표시 옵션 선택)에서 각 단계를 기본 대시보드에 표시할지 선택하세요. 모든 단계를 끄면 이 파이프라인이 대시보드에서 숨겨져요.

   ![리포트 표시 옵션을 선택하는 화면](https://jumpshare.com/share/UhgM6olratSUK2ZujeTr+/GIF+Recording+2026-04-14+at+19.42.09.gif)
8. 아래 항목은 자동으로 복사돼요.

   - 파이프라인 단계
   - 차트 표시 설정
   - 스마트 태그 색상
   - 파이프라인 권한
9. 아래 항목은 복사되지 않아요.

   - 기회 레코드
   - 자동화
   - 리포트
   - 커스텀 필드
10. **중복**을 클릭해 새 파이프라인을 만드세요.

    ![파이프라인 복제 창에서 중복 클릭](https://jumpshare.com/share/S6sxzNLbXJ4duiNxQZ4t+/Screen+Shot+2026-04-14+at+19.44.50.png)
11. 복제된 파이프라인이 파이프라인 목록에 나타나요. 바로 편집하거나 사용을 시작할 수 있어요.

    ![목록에 추가된 복제 파이프라인](https://jumpshare.com/share/VJgNxxngEUikwjjXjRyK+/Screen+Shot+2026-04-14+at+19.45.20.png)

## 파이프라인을 다른 서브 계정에 복사하기

에이전시 관리자는 파이프라인을 여러 서브 계정에 한 번에 복사할 수 있어요.

1. **기회 관리 > 파이프라인**으로 이동하세요.
2. 복사할 파이프라인을 찾아 점 세 개(⋮) 메뉴를 열고 **서브 계정에 복사**를 선택하세요.

   ![파이프라인 점 세 개 메뉴에서 서브 계정에 복사 선택](https://jumpshare.com/share/RQaSWpniymmX66xsJ20A+/Screen+Shot+2026-04-14+at+19.49.53.png)
3. **서브 계정에 복사** 창에서 아래 항목을 입력하세요.
4. **파이프라인 이름**: 같은 이름을 그대로 쓰거나 바꿀 수 있어요.
5. **서브 계정 선택**: 파이프라인을 만들 서브 계정을 하나 이상 선택하세요. 여러 개를 선택할 수 있어요.
6. **복사**를 클릭하면 선택한 서브 계정마다 파이프라인이 만들어져요.

   ![서브 계정을 선택하고 복사 클릭](https://jumpshare.com/share/bEYV4PLvhhUQS8HCGPeT+/Screen+Shot+2026-04-14+at+19.52.39.png)

## 활용 팁

몇 가지 습관만 들이면 파이프라인을 복제하고 배포하는 일이 훨씬 수월해져요. 헷갈림을 줄이고 정리가 잘 되며, 나중에 수정하기도 쉬워져요.

- 복제한 파이프라인은 바로 이름을 바꿔서 원본과 쉽게 구분하세요.
- 파이프라인을 널리 적용하기 전에 복제본으로 변형을 먼저 시험해 보세요.
- 다른 서브 계정에 복사하기 전에 표준으로 쓸 파이프라인 템플릿을 먼저 정리하세요.
- 어떤 설정이 복사되고 복사되지 않는지 확인해 두면 복사 후 필요한 설정을 빠뜨리지 않아요.

## 자주 묻는 질문

### 같은 서브 계정 안에서 파이프라인을 복제할 수 있나요?
네. 파이프라인 옆의 점 세 개(⋮) 메뉴에서 **중복**을 선택하세요.

### 파이프라인을 서브 계정 여러 개에 동시에 복사할 수 있나요?
네. 한 번 복사할 때 대상 서브 계정을 여러 개 선택할 수 있어요.

### 다른 서브 계정으로 파이프라인을 복사할 수 있는 사람은 누구인가요?
에이전시 관리자만 **서브 계정에 복사**를 쓸 수 있어요.

### 파이프라인은 누가 복제할 수 있나요?
해당 파이프라인에 편집 권한이 있는 사용자라면 누구나 복제할 수 있어요.

### 기회 레코드도 파이프라인과 함께 복사되나요?
아니요. 레코드는 복사되지 않아요.

### 자동화, 리포트, 커스텀 필드도 복사되나요?
아니요. 자동화, 리포트, 커스텀 필드는 복사되지 않아요.

### 스마트 태그도 파이프라인과 함께 복사되나요?
같은 서브 계정 안에서 복제할 때는 스마트 태그 색상이 복사돼요. 다른 서브 계정으로 복사할 때는 복사되지 않아요.

### 파이프라인 권한도 파이프라인과 함께 복사되나요?
같은 서브 계정 안에서 복제할 때는 파이프라인 권한이 복사돼요. 다른 서브 계정으로 복사할 때는 복사되지 않아요.

### **서브 계정에 복사** 옵션이 보이지 않아요.
이 옵션은 에이전시 관리자만 쓸 수 있어요.
