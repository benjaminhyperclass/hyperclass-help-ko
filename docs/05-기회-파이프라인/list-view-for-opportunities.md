# 기회 관리의 목록 보기

**기회 관리**(Opportunities)에서 **목록 보기**를 쓰면 기회를 표 형태로 한눈에 보고, 필요한 열만 골라 정리할 수 있어요. 이 문서에서는 목록 보기를 여는 방법과 주요 기능, 모든 파이프라인을 한 목록으로 보는 방법을 안내해요.

]()

## 목록 보기 여는 방법

![기회 관리에서 목록 보기로 전환하는 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155026297014/original/VSJ7NIwxHmnQhd44kGcwmvUVhEi-nFHQ8w.png?1716214908)

**기회 관리**로 이동한 뒤, 오른쪽 위에서 **목록 보기**로 전환하세요.

## 기능 목록

- 목록으로 보는 기회: 모든 기회를 알아보기 쉬운 표 형태로 볼 수 있어요. 훑어보면서 필요한 정보를 빠르게 찾을 수 있어요.
  
  ![표 형태로 정리된 기회 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155026290654/original/MLu63tyqF-FtWNjb00z9AKWd4WJNCAU_Uw.png?1716210484)
- 여러 필드 기준으로 정렬하기: 기본 필드와 지원되는 커스텀 필드로 기회를 정렬할 수 있어요. 우리 비즈니스에 맞는 데이터를 기준으로 우선순위를 정할 수 있어요.

    1. **기회 관리**로 이동해 **목록 보기**로 전환하세요.

    2. **정렬**을 클릭하세요.

    3. 정렬 기준으로 쓸 필드를 선택하세요. 기본 필드와 지원되는 커스텀 필드 중에서 고를 수 있어요.

    4. **Ascending**(오름차순) 또는 **Descending**(내림차순)을 선택하세요.

    정렬에 쓸 수 있는 커스텀 필드 유형은 다음과 같아요.

    - **Single Line**(한 줄 텍스트)

    - **Multi Line Text**(여러 줄 텍스트)

    - **Dropdown (Single Select)**(드롭다운, 단일 선택)

    - **라디오 선택**

    - **Number**(숫자)

    - **Monetary**(금액)

    - **Phone**(전화번호)

    - **Date**(날짜)

    ![정렬 기준 필드를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069582615/original/vqmzptN0JdaMyZl0hV-rtyFhR06qZR9JMA.png?1776762286)
- 필드 사용자 지정: 목록 보기에 표시할 필드를 직접 고를 수 있어요. 필드의 너비를 조절하고 순서를 바꿀 수도 있어요.

  ![목록 보기에 표시할 필드를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029367355/original/Jod4pR0zoOZlp2DOC1agDfpQ7ynOb2fbMQ.png?1721154112)
- 주 연락처 메모: **Primary Contact Notes**(주 연락처 메모) 열을 추가하면 기회의 주 연락처에 남긴 메모를 목록에서 바로 볼 수 있어요.

  **Customize Columns**(열 사용자 지정)를 열고 **Primary Contact Notes**를 켜면 열이 표시돼요.

  목록 보기의 다른 열처럼 **Primary Contact Notes** 열도 너비를 조절하고 정렬할 수 있으며, 저장된 보기에 포함할 수 있어요. 기회의 주 연락처에 새 메모가 추가되면 이 열도 함께 업데이트돼요.

  ![목록 보기의 Primary Contact Notes 열](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079549116/original/p3gRkDZbRIRZvRHfbj3sEDd3oRLpGShXqw.png?1787921168)
- **Board view**(보드 보기)와 같은 기능: 보드 보기에서 쓰던 기능을 목록 보기에서도 그대로 쓸 수 있어요. 검색 범위를 좁혀 주는 고급 **필터**와, 원하는 기회를 빠르게 찾아 주는 **검색**도 포함돼요.

  ![목록 보기에서 필터와 검색을 사용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155026290691/original/FFfoCZS8iogvc1vdSCrhptB6DDjdg0eljw.png?1716210492)

## 모든 파이프라인을 한 목록으로 보기

**파이프라인** 드롭다운에는 **All Pipelines**(모든 파이프라인) 옵션이 있어요. 이 옵션을 선택하면 모든 파이프라인의 기회가 하나의 목록에 모여서, 파이프라인을 하나씩 전환하지 않아도 돼요.

1. **기회 관리**를 열고 **목록 보기**로 전환하세요. **All Pipelines**는 목록 보기에서만 쓸 수 있어요.
2. 왼쪽 위의 **파이프라인** 드롭다운을 열고 **All Pipelines**를 선택하세요.
3. 목록에 모든 파이프라인의 기회가 표시돼요. 각 기회가 어느 파이프라인에 속하는지는 **파이프라인** 열에서 확인할 수 있어요.
4. (선택) 나중에 다시 보려면 현재 보기를 스마트 리스트로 저장하세요.

> ![파이프라인 드롭다운에서 All Pipelines를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073468550/original/D_0bUYh95TQVAGpbLqOWle2rI4uAQEwcng.png?1781183146)

> ![모든 파이프라인의 기회가 한 목록에 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073468556/original/7P8cM5uiTDx74fk4lgriHrKT6qlo1JWaYQ.png?1781183155)

알아 두세요.

- 목록 보기에서만 쓸 수 있어요. 칸반(보드) 보기는 한 파이프라인의 단계별로 구성되기 때문에 **All Pipelines**를 사용할 수 없어요. 이 옵션을 쓰려면 목록 보기로 전환하세요.
- 스마트 리스트는 목록 유형만 지원해요. **All Pipelines** 보기에서 저장한 스마트 리스트는 목록 유형 스마트 리스트가 되고, 칸반 보드 스마트 리스트는 이 보기에서 지원하지 않아요.
- 이 보기에서는 단계 기준 정렬을 지원하지 않아요. 단계 기준으로 정렬하면 **생성일** 기준으로 정렬돼요.

## 목록 보기의 장점

목록 보기를 쓰면 업무를 더 효율적으로 처리할 수 있어요.

- 한눈에 보기 쉬워요: 한 화면에 더 많은 기회가 표시되기 때문에, 화면을 오가지 않아도 파이프라인 전체를 살펴볼 수 있어요.
- 내게 맞게 바꿀 수 있어요: 가장 중요한 정보가 보이도록 열을 직접 구성할 수 있어요. 필요와 취향에 맞는 보기를 유지할 수 있어요.
- 작업이 빨라져요: 목록 보기에서 바로 정렬, 필터, 내보내기를 할 수 있어서, 반복되는 작업에 드는 시간과 수고를 줄일 수 있어요.
