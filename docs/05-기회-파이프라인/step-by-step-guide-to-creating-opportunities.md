# 기회 만들기 단계별 가이드

기회는 하이퍼클래스에서 잠재 매출을 관리하는 기본 단위예요. 이 문서에서는 기회를 만드는 순서를 안내해요. 첫 접촉부터 계약 성사까지 잠재 고객을 한곳에서 추적할 수 있어요.

## 기회란?

기회는 하이퍼클래스 안에서 추적하는 판매 건 하나를 뜻해요. 기회에는 연락처, 파이프라인, 단계, 예상 금액, 담당 소유자가 함께 묶여 있어요. 그래서 첫 대화부터 최종 결과까지 딜 하나를 이어서 볼 수 있어요.

## 기회를 만들면 좋은 점

- 한곳에서 추적: 진행 중인 딜을 기회 관리 화면에서 모두 볼 수 있어요.
- 매출 예측: 예상 매출을 기록해 두면 판매 전망을 더 정확하게 세울 수 있어요.
- 협업: 소유자를 지정하면 팀원이 누가 담당인지 바로 알 수 있어요.
- 맥락 보존: 대화 내용을 기회 카드에 바로 메모로 남길 수 있어요.

## 기회 만들기

### 1단계: 기회 관리 열기

1. 하이퍼클래스 서브 계정에 로그인하세요.
2. **기회 관리**(Opportunities) 탭을 클릭하세요.
3. 오른쪽 위의 **+ Add Opportunity**(기회 추가) 버튼을 클릭하세요.

![기회 관리 화면 오른쪽 위의 기회 추가 버튼](https://jumpshare.com/v/SDr5vZRXt5jg6EPOeNpw+/Screen+Shot+2025-07-17+at+7.09.44+PM.png)

### 2단계: 연락처와 기회 정보 입력

1. 저장된 연락처 목록에서 **주 연락처**를 선택하세요.
2. 이메일과 전화번호를 확인하세요. 저장된 정보가 없으면 직접 입력하세요.
![주 연락처 선택과 연락처 정보 입력 화면](https://jumpshare.com/v/Dyzm3UJ6zfnTM3KUNOZQ+/Screen+Shot+2025-07-17+at+7.11.55+PM.png)

### 3단계: 파이프라인, 단계, 상태 지정

1. 기본값인 연락처 이름을 그대로 쓰거나, 원하는 **기회명**을 입력하세요.
2. 기회를 추가할 **파이프라인**을 선택하세요.
3. 알맞은 **파이프라인 단계**를 선택하세요.
4. **기회 상태**를 지정하세요.

   - **Open**(진행 중)
   - **고객전환실패**
   - **고객전환성공**
   - **Abandon**(포기)

5. **Opportunity Value**(기회 금액)를 입력하세요.

![파이프라인, 단계, 상태, 금액 입력 화면](https://jumpshare.com/v/35WyDdsrRPyqa1yjynmu+/Screen+Shot+2025-07-17+at+7.23.09+PM.png)

### 4단계: 소유자, 팀원, 추가 세부정보 입력

1. 기회의 **소유자**를 지정하세요.
2. 기회에 **팔로워**를 추가하세요. 팔로워는 여러 명 추가할 수 있어요.
3. **추가 세부정보**의 필드를 필요에 따라 입력하세요.

   1. **사업자명**
   2. **기회 소스**
   3. **태그**
   4. **Task Type**(작업 유형)
   5. **Favorite Pet**(좋아하는 반려동물)
   6. **Efficiency Rating**(효율 평가)
   7. **Task Difficulty**(작업 난이도)
   8. **Time Tracked**(기록된 시간)

![소유자, 팔로워, 추가 세부정보 입력 화면](https://jumpshare.com/v/TZi1I05DbkbE0nFVUpea+/Screen+Shot+2025-07-17+at+7.33.44+PM.png)

### 5단계: 기회 저장

1. 커스텀 필드를 관리하려면 **필드 관리**를 클릭하세요.
2. **만들기** 버튼을 클릭해 기회를 저장하세요.
3. 파이프라인에서 새 기회가 보이는지 확인하세요.

![필드 관리와 만들기 버튼이 있는 화면](https://jumpshare.com/v/qY55sCPKUHccRa77t2F1+/Screen+Shot+2025-07-17+at+7.36.10+PM.png)

## 자주 묻는 질문

### 기회를 나중에 다른 사람에게 배정할 수 있나요?
네. 기회 카드를 열고 새 **소유자**를 선택한 다음 **저장**을 클릭하세요.

### 기회를 만든 뒤에 기회 금액을 바꿀 수 있나요?
네. **Edit Drawer**(편집 패널)에서 **Opportunity Value** 필드를 수정하고 저장하세요.

### 기존 기회를 복제할 수 있나요?
지금은 할 수 없어요. 새 기회를 만들고 필요한 내용을 직접 옮겨 입력하세요.

### 기회에 연결된 연락처를 삭제하면 어떻게 되나요?
기회는 그대로 남지만 연락처와의 연결이 끊어져요. 맥락을 유지하려면 새 연락처를 다시 연결하거나 원래 연락처를 복원하세요.

### 기회를 만든 뒤 다른 단계로 옮기려면 어떻게 하나요?
**기회 관리** 보드에서 기회 카드를 원하는 단계 열로 끌어다 놓으세요. 또는 **Edit Drawer**를 열고 **파이프라인 단계** 드롭다운에서 새 단계를 선택해도 돼요.

### 이미 만든 기회의 주 연락처를 바꿀 수 있나요?
네. **Edit Drawer**를 열고 현재 주 연락처를 제거하세요. 새 연락처를 추가한 다음 **주 연락처**로 지정하고 저장하세요.
