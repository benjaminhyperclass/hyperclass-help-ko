# 기회 커스텀 필드 사용하기

기회에 필요한 정보를 직접 만든 필드로 기록하고 정리하는 기능이에요. 기회 창 안에서 커스텀 필드를 만들고 폴더로 묶을 수 있어서, 데이터 관리와 진행 상황 추적이 편해져요. 연락처와 똑같이 쉽게 사용자 지정할 수 있어요.

{% hint style="info" %}
이 기능은 현재 **실험실**에서 사용할 수 있어요.
{% endhint %}

![실험실 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003923483/original/cjLoF2igsC2Qfr8s8sdBc17IoofwOaeQhQ.png?1690539467)

## 이 기능은 무엇인가요?

기회 커스텀 필드를 쓰면 영업 기회에 맞는 데이터 필드를 직접 추가하고, 꾸미고, 정리할 수 있어요.

잠재 매출이나 업무를 더 유연하고 정확하게 추적할 수 있어요. 우리 회사의 운영 방식이나 영업 과정에만 있는 정보도 담을 수 있어요. 프로젝트 마감일, 상품 사양, 고객 선호처럼 다양한 필드를 만들 수 있어요.

커스텀 필드를 여러 폴더로 나눠 두면 화면도 한결 깔끔하게 정리돼요. 값이 없는 필드를 숨기는 옵션도 있어서, 기회 카드를 간결하게 볼 수 있어요.

### 활용 사례

- 영업 마감일: 기회마다 판매 마감일 필드를 만들어 두면 팀 전체가 중요한 마감일을 알 수 있어요.
- 영업 단계: 최초 접촉, 요구 사항 파악, 협상, 최종 계약처럼 기회가 어느 단계에 있는지 구분할 수 있어요.
- 상품 상세 정보: 상품 모델, SKU, 서비스 유형처럼 기회와 관련된 상품이나 서비스 정보를 기록해요.
- 고객 선호: 연락하기 좋은 시간, 특별한 요구나 요청 사항 같은 고객의 선호와 필요를 기록해요.
- 리드 출처: 리드가 어디서 들어오는지 추적해요. 추천, 소셜 미디어, 우편 발송 등을 예로 들 수 있어요.
- 고객 예산: 고객의 예산이나 지출 여력을 적어 두면 제안을 더 정확하게 맞출 수 있어요.
- 전환 가능성: 기회가 실제 판매로 이어질 확률을 나타내는 필드예요. 자원을 어디에 먼저 쓸지 정하는 데 도움이 돼요. 숫자 필드로 만들고, **Math Operation**(수학 연산) 워크플로우 액션으로 값을 업데이트할 수 있어요.
- 다음 후속 연락일: 잠재 고객에게 언제 다시 연락해야 하는지 기록해 두면 대화를 이어 가고 판매 가능성을 높일 수 있어요.
- 연결된 캠페인: 기회가 특정 마케팅 캠페인과 연결되어 있다면, 어떤 캠페인에서 온 기회인지 필드로 추적할 수 있어요.
- 고객의 업종 또는 직업: 고객의 업종이나 직업을 알면 필요를 더 잘 이해하고 그에 맞게 소통할 수 있어요.

## 사용 방법

1. 서브 계정의 **설정**으로 이동해요. 커스텀 필드를 만드는 메뉴는 설정 페이지에 있어요.
2. **설정** 안의 **커스텀 필드**로 이동해서 **필드 추가** 또는 **필드 만들기**를 클릭해요.

![커스텀 필드 화면에서 필드 추가 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003926979/original/l5FROAGJ8IFlg3fyI27xzUWJiXYdCRSi-A.png?1690541104)

3. 오브젝트로 **기회**를 선택하고, 단일 행 텍스트, 숫자, 드롭다운 같은 필드 유형을 정해요. 필드 이름은 용도에 맞게 지어요. 예를 들면 '프로젝트 시작일'이나 '영업 단계'처럼요.

현재 기회에 추가할 수 있는 커스텀 필드 유형은 다음과 같아요.

![기회에 추가할 수 있는 커스텀 필드 유형 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003927631/original/s-ZgSCwM-EvvgQQDaE89KhGVZe6tcCH2dQ.png?1690541399)

- **Text Input**(텍스트 입력)
- **Single Line**(한 줄)
- **Multi-Line**(여러 줄)
- **텍스트 박스 목록**
- **Values**(값)
- **Number**(숫자)
- **Phone**(전화번호)
- **Monetary**(금액)
- **옵션 선택**
- **단일 드롭다운**
- **Dropdown (Multiple)**(다중 드롭다운)
- **라디오 선택**
- **Checkbox**(체크박스)
- **Date Picker**(날짜 선택기)
- **Signature**(서명)
- **Rich text**(서식 있는 텍스트)
- **URL**: 모든 도메인 허용, 특정 도메인만 허용, 특정 도메인 차단 중에서 고를 수 있어요.
- **날짜 및 시간**: 날짜, 시간, 또는 둘 다 받을 수 있어요. 미래 날짜만, 과거 날짜만, 또는 특정 범위로 제한할 수 있고, 선택 가능한 요일도 정할 수 있어요.
- **사용자**: **다중 사용자 허용**을 켜면 한 명 넘게 담당자로 지정할 수 있어요. 이 설정은 나중에 바꿀 수 없어요. 지정된 사용자는 팔로워 수준의 접근 권한을 가져요.

{% hint style="info" %}
**파일 업로드** 필드 유형은 보통 사용할 수 있지만, 기회에서도 쓸 수 있도록 현재 작업 중이에요. 완료되면 기회 영역의 커스텀 필드에 파일을 바로 업로드할 수 있어요.
{% endhint %}

4. 이제 **기회 관리**와 **연락처** 옵션이 보여요. 필요한 정보를 입력한 뒤 **기회 관리**를 선택하고 **저장**을 클릭해요.

![기회 관리 선택 후 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003927964/original/Dpk6HxzTu7ktlVvscbUdiiOrv1s4Vh_E0A.png?1690541537)

5. 기회용 커스텀 필드를 폴더로 묶으면 필드를 더 잘 분류하고 정리할 수 있어요. **커스텀 필드** 안의 **폴더**로 이동해 새 폴더를 만들고, 이름을 입력한 다음 오브젝트로 **기회**를 선택해요.

![커스텀 필드 폴더 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003928158/original/hqiCkHKiwMvZ4IjsBY5DV6ZMOpJ2Lbm04A.png?1690541617)

6. 기회를 만들거나 편집할 때 **기회 관리** 영역에 새 커스텀 필드가 보여요. 필요한 정보를 입력하면 돼요.

![기회 화면에서 커스텀 필드 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003928314/original/61fXXWE6LCSQzCWb2yXucfHQvYoVYfomYg.png?1690541722)

7. 커스텀 필드가 많아서 값이 없는 필드는 보고 싶지 않다면 **Hide Empty Fields**(빈 필드 숨기기)를 켜세요.

![Hide Empty Fields 켜기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003928544/original/fNguPFyCZ_-nW3ohktcraHSqkr35cvxy3A.png?1690541797)

## 자주 묻는 질문

### 기회에서 커스텀 필드는 어디서 볼 수 있나요?

**기회 관리**로 이동해 기회를 선택하거나 새로 만들면 커스텀 필드가 목록으로 보여요. 기회를 편집할 때는 이 필드에 값을 입력할 수 있어요. 필드를 폴더로 정리해 두었다면 폴더별로 차례대로 표시돼요.

### Hide Empty Fields 기능은 어떤 역할을 하나요?

이 기능을 켜면 지금 값이 없는 필드가 모두 숨겨져요. 나에게 필요하거나 꼭 입력해야 하는 필드에만 집중할 수 있어서, 기회 데이터를 더 깔끔하게 볼 수 있어요.
