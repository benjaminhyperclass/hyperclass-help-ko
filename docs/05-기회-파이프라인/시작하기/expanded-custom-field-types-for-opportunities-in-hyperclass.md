# 기회에서 쓰는 확장 커스텀 필드 유형

기회에서도 확장 커스텀 필드 유형을 쓸 수 있어요. 제안서 URL, 계약일, 서식을 넣은 딜 요약, 팀 배정, 이미지로 고르는 서비스 선택 같은 정보를 기회 레코드에 바로 저장할 수 있어요. 이 필드는 **기회 관리**(Opportunities)의 **목록 보기** 열과 **상세 필터**에도 쓸 수 있어서, 딜 정보를 정리하고 찾기가 쉬워져요.

{% hint style="info" %}
이 업데이트는 먼저 연락처에 적용되었고, 이제 기회에서도 쓸 수 있어요.
{% endhint %}

## 확장 커스텀 필드 유형이란?

확장 커스텀 필드는 정보를 모으고, 검증하고, 보여 주는 방식을 더 다양하게 고를 수 있는 필드예요. 연락처에서 먼저 제공되던 기능이 이제 기회로도 넓어졌어요. 그래서 중요한 딜 정보를 연락처 필드나 정리되지 않은 메모에 의존하지 않고 관리할 수 있어요.

확장 필드 유형에는 URL, **날짜 & 시간**, **리치 텍스트**, **사용자**, 그리고 이미지나 아이콘을 쓸 수 있는 **체크박스**와 **라디오 선택**이 있어요.

---

## 기회와 연락처에서 확장 커스텀 필드를 쓰면 좋은 점

확장 커스텀 필드를 쓰면 정확한 정보를 유지하고, 딜을 함께 관리하고, 중요한 기회 정보를 빠르게 찾을 수 있어요.

- 딜 정보를 한곳에 모아요: 제안서 링크, 계약일, 딜 요약을 기회에 바로 저장해요.
- 팀 협업이 쉬워져요: **사용자** 필드로 여러 팀원을 딜에 연결해요.
- 서식을 자유롭게 쓸 수 있어요: **리치 텍스트**로 자세한 딜 정보를 정리해요.
- 한눈에 구분할 수 있어요: 이미지와 아이콘으로 서비스, 우선순위, 카테고리를 나타내요.
- 파이프라인이 더 잘 보여요: 커스텀 필드를 **목록 보기**에 표시하고 **상세 필터**로 찾아요.
- URL을 더 체계적으로 모아요: 웹사이트 주소, 프로필 URL, 자료 링크 같은 URL을 도메인 제어 기능이 있는 전용 필드로 받아요.
- 날짜와 시간을 더 세밀하게 제어해요: 날짜와 시간, 날짜만, 시간만 중에서 고르고, 선택할 수 있는 날짜 범위도 정해요.
- 팀 협업이 더 편해져요: 사용자 필드로 한 명 또는 여러 팀원을 레코드에 연결하고, 선택한 사용자에게 팔로워 수준의 접근 권한을 줘요.
- 라디오 선택지를 더 알아보기 쉽게 만들어요: 하나만 골라야 할 때 선택지에 이미지나 아이콘을 넣어요.
- 모바일에서도 필드를 수정해요: 모바일 앱의 연락처와 기회 레코드에서 지원되는 커스텀 필드를 바로 보고 편집해요.

## 지원하는 커스텀 필드 유형과 설정 옵션

확장 필드 유형마다 설정 옵션이 달라서, 정보를 가장 알맞은 형식으로 받을 수 있어요. 필드 유형을 잘 고르면 입력 형식이 일정해지고 기회 정보를 검토하기도 쉬워져요.

| 필드 유형 | 설정 옵션 | 기회에서 쓰는 예 |
| --- | --- | --- |
| **URL** | **모든 도메인 허용**, 지정한 도메인만 허용, 지정한 도메인 차단 | 제안서·계약서 링크 |
| **날짜 & 시간** | 날짜만, 시간만, 또는 둘 다 / 과거·미래 날짜, 날짜 범위, 요일 | 계약 시작일, 프로젝트 마감일 |
| **리치 텍스트** | 텍스트 서식, 제목, 목록, 링크, 이모지 | 딜 요약, 업무 범위 메모 |
| **사용자** | 사용자 한 명 또는 여러 명 선택 | 영업팀, 구축 담당 팀 |
| **체크박스** | **이미지가 있는 텍스트** / 여러 개 선택 | 딜에 포함된 서비스 |
| **라디오 선택** | **이미지가 있는 텍스트** 또는 **아이콘이 있는 텍스트** / 하나만 선택 | 딜 우선순위, 서비스 패키지 |

주요 설정 안내

- URL 검증: 도메인 제한에 맞지 않는 URL은 "This URL isn't allowed. Use an allowed domain."(허용되지 않는 URL이에요. 허용된 도메인을 사용하세요.)라는 메시지와 함께 거부돼요.
- 날짜 제한: **Future Dates Only**(미래 날짜만)를 고르면 오늘 날짜는 제외돼요. 오늘 날짜도 선택할 수 있어야 하면 **Any Date**(모든 날짜)를 고르세요.
- 리치 텍스트: 굵게, 기울임, 밑줄, 취소선, 색상, 강조 표시, 목록, 링크, 이모지를 지원해요. 제목은 `#` 또는 `##`로 만들 수 있어요.
- 사용자 필드: 선택한 사용자는 기회 담당자가 되지 않고 팔로워 수준의 접근 권한을 받아요. **다중 사용자 허용** 설정은 필드를 만든 뒤에는 바꿀 수 없어요. 팔로워에 대한 자세한 내용은 [연락처 및 기회 팔로워](../../02-연락처/contact-and-opportunity-followers-in-hyperclass.md) 문서를 참고하세요.
- 시각 옵션: **체크박스** 필드는 이미지를, **라디오 선택** 필드는 이미지나 아이콘을 지원해요.

필드 설정, 모바일 편집, 스냅샷 지원에 대한 자세한 내용은 "Expanded Custom Field Types and Configuration Options" 문서를 참고하세요.

## 모바일·스냅샷 지원

확장 커스텀 필드는 모바일에서 레코드를 관리할 때도 쓸 수 있고, 여러 서브 계정에서 같은 설정을 다시 쓸 수도 있어요. 기기를 바꿔 가며 일하거나 새 서브 계정을 설정할 때도 정보를 일관되게 유지할 수 있어요.

- **모바일**: 지원되는 확장 필드는 모바일 앱의 연락처와 기회 레코드에서 보고 편집할 수 있어요. 설정해 둔 검증 규칙도 그대로 적용돼요.
- **스냅샷**: 지원되는 확장 커스텀 필드와 설정은 **스냅샷**에 포함할 수 있어요. URL 제한, 날짜 설정, 시각 옵션도 포함돼요.

## 기회용 확장 커스텀 필드 설정하기

기회 객체 아래에 커스텀 필드를 만들면 정보가 알맞은 딜에 연결돼요. 저장하기 전에 필드 제한과 선택 설정을 먼저 정하세요. 특히 **사용자** 필드는 여러 명 선택 설정을 나중에 바꿀 수 없어요. 기회 커스텀 필드를 활용하는 방법은 [기회용 커스텀 필드 사용하기](how-to-use-custom-fields-for-opportunities.md) 문서를 참고하세요.

1. **설정 > 커스텀 필드**로 이동하세요.
2. **기회**를 선택하고 **필드 만들기**를 클릭하세요.

   ![기회를 선택하고 필드 만들기를 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084503326/original/uC-8AasL-1B0XgjA72GL_LcVTQ8pwq8FDA.png?1793276726)
3. **URL**, **날짜 & 시간**, **리치 텍스트**, **사용자**, **체크박스**, **라디오 선택** 중에서 고르세요.

   ![필드 유형을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084503411/original/qQUlNxA8pjDQGoNd4io9lcXqkVG1KGEN1g.png?1793276777)
4. 필드 이름과 필요한 설정을 입력하세요. 시각 옵션을 쓰려면 **체크박스**는 **이미지가 있는 텍스트**를, **라디오 선택**은 **이미지가 있는 텍스트** 또는 **아이콘이 있는 텍스트**를 고르세요.
5. 폴더를 선택하고 **커스텀 필드 만들기**를 클릭하세요.
6. **기회 관리**로 이동해 딜을 열고, **필드** 영역에서 새 필드에 값을 입력하세요.

## 확장 커스텀 필드 설정 절차

필드 유형과 설정을 알맞게 정해 두면 업무 방식에 맞는 형식으로 정보를 받을 수 있어요. 커스텀 필드는 **커스텀 필드** 화면에서 관리해요. 이 화면에서 객체를 고르고, 쓰임새에 맞게 필드를 설정하세요.

1. **설정**으로 이동하세요.

   ![설정 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081484152/original/TyL4ws6CggZjlYGqtYUQOy67XSoJJ4KHSA.png?1790009348)
2. **커스텀 필드**를 선택하세요.
3. 커스텀 필드를 만들 객체를 선택하세요.
4. **필드 만들기** 또는 새 커스텀 필드를 만드는 옵션을 클릭하세요.

   ![필드 만들기 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081484202/original/i4wMxkwHMYvu4Z4k1SDKnFuD4IGsWMRVgA.png?1790009374)
5. 받으려는 정보에 맞는 필드 유형을 선택하세요.
6. 필드 이름과 나머지 설정을 입력하세요.
7. 선택한 필드 유형에 맞는 설정을 하세요.

   - **URL** 필드: 알맞은 도메인 제어를 설정하세요.
   - **날짜 및 시간** 필드: 필요한 날짜·시간 형식과 날짜 제한을 선택하세요.
   - **리치 텍스트** 필드: 지원되는 서식이 필요한 내용을 받는 용도로 만드세요.
   - **사용자** 필드: 레코드에 사용자 한 명 또는 여러 명을 연결할지에 맞게 설정하세요.
   - **체크박스** 필드: 시각적인 선택지가 필요하면 해당 옵션마다 이미지를 추가하세요.
   - **라디오 선택** 필드: 시각적인 맥락이 필요하면 해당 옵션마다 이미지나 아이콘을 추가하세요.

     ![필드 유형별 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081484231/original/CMWakaTHoW2e58fVY7AKmwSSMCUVUnEWBA.png?1790009397)
8. 필드 설정과 미리보기를 확인하세요.
9. 커스텀 필드를 저장하세요.

{% hint style="warning" %}
커스텀 필드를 쓸 수 있는지는 필드를 쓰는 객체나 영역에 따라 다를 수 있어요. 업무 프로세스를 만들기 전에, 선택한 필드 유형을 쓰려는 객체와 용도에서 쓸 수 있는지 먼저 확인하세요.
{% endhint %}

## 기회 목록 보기에서 커스텀 필드 표시하고 필터링하기

확장 커스텀 필드는 기회의 **목록 보기**에 열로 추가하고 **상세 필터**와 함께 쓸 수 있어요. 그러면 딜 정보를 한눈에 검토하고, 커스텀 필드 값으로 기회를 찾기 쉬워요. 자세한 내용은 [기회 목록 보기](../list-view-for-opportunities.md) 문서를 참고하세요.

커스텀 필드를 표시하려면 다음과 같이 하세요.

1. **기회 관리 > 목록 보기**로 이동하세요.
2. **필드 관리**를 여세요.
3. 열로 표시할 커스텀 필드를 선택하세요.

기회를 필터링하려면 다음과 같이 하세요. 필터 사용법은 [기회를 쉽고 빠르게 필터링하기](../how-to-filter-opportunities.md) 문서에서도 볼 수 있어요.

1. **기회 관리**에서 **상세 필터**를 여세요.
2. 알맞은 커스텀 필드를 선택하세요.
3. 사용할 수 있는 필터 조건과 값을 고르세요.
4. 필터를 적용해 조건에 맞는 기회를 확인하세요.

필터 연산자는 필드 유형에 따라 달라요. 그리고 열로 표시할 수 있다고 해서 반드시 정렬을 지원하는 것은 아니에요.

## 확장 커스텀 필드의 공개 API 지원

하이퍼클래스의 공개 API에서도 확장 커스텀 필드 유형을 지원해요. 개발자와 연동 파트너가 프로그래밍으로 커스텀 필드를 만들고, 조회하고, 업데이트할 수 있어요. 그래서 외부 애플리케이션, 연동, 자동화 프로세스에서도 커스텀 필드를 다루기 쉬워요.

지원하는 커스텀 필드 유형

공개 API는 다음 여섯 가지 커스텀 필드 개선 사항을 지원해요.

- URL 필드: URL 커스텀 필드를 만들고, 조회하고, 업데이트해요. 도메인 제한이 있는 설정도 포함돼요.
- 날짜 및 시간 필드: 날짜와 시간, 날짜만, 시간만 있는 커스텀 필드를 다뤄요.
- 리치 텍스트 필드: 공개 API로 리치 텍스트 커스텀 필드를 관리해요.
- 사용자 필드: 사용자 한 명 또는 여러 명을 선택하도록 설정한 커스텀 필드를 다뤄요.
- 이미지가 있는 체크박스 필드: 이미지 옵션이 있는 체크박스 커스텀 필드를 다뤄요.
- 이미지가 있는 라디오 버튼 필드: 이미지 옵션이 있는 라디오 버튼 커스텀 필드를 다뤄요.

API 문서

개발자는 다음 API 엔드포인트로 지원되는 커스텀 필드를 다룰 수 있어요.

- Create Custom Field
- Get Custom Fields
- Get Custom Field
- Update Custom Field

지원하는 요청 파라미터, 필드 설정, 응답 형식은 **API 문서**를 참고하세요. API 문서 링크는 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 기회에서 확장 커스텀 필드 유형이 보이지 않아요.

이 기능은 기회 우선(Opportunity-First) 비공개 베타에 포함돼 있어요. 서브 계정에 해당 기능이 켜져 있는지 확인하세요.

### 사용자 커스텀 필드를 만든 뒤에 여러 명을 선택할 수 있게 바꿀 수 있나요?

아니요. **다중 사용자 허용**은 필드를 만들기 전에 켜 두어야 해요.

### 사용자 커스텀 필드로 사용자를 추가하면 기회 담당자가 바뀌나요?

아니요. 선택한 사용자는 팔로워 수준의 접근 권한을 받지만, 담당자는 따로 유지돼요.

### 날짜 & 시간 필드에서 오늘 날짜를 선택할 수 없어요.

**Future Dates Only**(미래 날짜만)는 오늘을 제외해요. 오늘 날짜도 선택해야 한다면 **Any Date**(모든 날짜)나 알맞은 날짜 범위를 사용하세요.

### 이 필드들을 기회 목록 보기와 상세 필터에서 쓸 수 있나요?

네. 확장 필드 유형은 **목록 보기**의 열로 표시하고 **상세 필터**와 함께 쓸 수 있어요. 사용할 수 있는 필터 옵션은 필드 유형에 따라 달라요.

### 기존 연락처 커스텀 필드를 기회 커스텀 필드로 바꿀 수 있나요?

아니요. 커스텀 필드는 만들 때 선택한 객체에 연결돼요. 딜에 정보를 바로 저장하려면 **기회** 아래에 새 필드를 만드세요.
