하이퍼클래스의 확장된 커스텀 필드(Custom Field) 옵션을 사용하면 정보를 수집, 구성, 표시하는 방식을 더욱 유연하게 설정할 수 있어요. 새로운 필드 유형과 설정 옵션을 통해 도메인 규칙이 적용된 URL, 선택 제한이 가능한 날짜와 시간, 서식이 적용된 텍스트, 연관된 사용자 정보 등을 수집할 수 있습니다. 또한 체크박스와 라디오 버튼 선택지에 시각 요소를 추가해서 각 옵션을 더 쉽게 구분할 수도 있어요.

# 하이퍼클래스의 확장된 커스텀 필드 유형이란?

커스텀 필드(Custom Field)를 사용하면 비즈니스와 레코드에 특화된 정보를 수집할 수 있어요. 확장된 필드 옵션은 구조화된 정보를 수집하는 데 추가적인 제어 기능을 제공하면서, 사용자가 목적에 맞는 형식으로 데이터를 입력하도록 도와줍니다.

## **확장된 커스텀 필드의 주요 이점**

확장된 커스텀 필드를 사용하면 비즈니스 프로세스에 맞춰 정보를 더 다양하게 구조화할 수 있어요. 적절한 필드 유형을 선택하면 레코드를 더 쉽게 이해할 수 있고, 사용자가 입력하거나 선택할 수 있는 내용도 더 세밀하게 제어할 수 있습니다.

- **더 구조화된 URL 수집**: 도메인 제어 기능이 있는 전용 필드를 사용해 웹사이트 주소, 프로필 URL, 자료 링크 등 다양한 URL을 수집할 수 있어요.

- **날짜와 시간에 대한 더 세밀한 제어**: 필드가 날짜와 시간을 모두 수집할지, 날짜만 수집할지, 시간만 수집할지 선택하고, 선택 가능한 날짜 범위도 제어할 수 있어요.

- **상세 정보에 더 나은 서식 적용**: 제목, 목록, 굵은 글씨, 기울임꼴 같은 서식을 사용해 긴 정보를 정리할 수 있는 Rich Text(서식 있는 텍스트) 필드를 활용하세요.

- **향상된 팀 협업**: Users(사용자) 필드를 사용해 한 명 또는 여러 명의 팀원을 레코드에 연결하고, 선택된 사용자에게 팔로워 수준의 접근 권한을 부여할 수 있어요.

- **더 시각적인 체크박스 선택지**: 사용자가 여러 항목을 선택할 수 있는 체크박스 옵션에 이미지를 추가할 수 있어요.

- **더 알아보기 쉬운 라디오 버튼 선택지**: 사용자가 하나의 항목만 선택해야 하는 라디오 버튼 옵션에 이미지나 아이콘을 추가할 수 있어요.

## **URL 필드와 도메인 제어**

URL 커스텀 필드는 일반 텍스트 필드에 저장하는 대신, 웹 주소를 구조화된 방식으로 수집할 수 있게 해줘요. 도메인 제어 기능은 사용자가 입력할 수 있는 도메인을 지정함으로써, 제출된 URL이 비즈니스 요건에 맞도록 보장하는 데 도움을 줍니다.

URL 필드는 다음과 같은 정보에 유용해요:

- 회사 웹사이트
- 소셜 프로필 URL
- 포트폴리오 링크
- 자료 링크
- 프로젝트 URL
- 레코드와 관련된 기타 웹 주소

URL 필드를 설정할 때는 도메인 처리 방식을 다음 중에서 선택할 수 있어요:

- **모든 도메인 허용**: 사용자가 모든 도메인의 URL을 입력할 수 있어요.
- **특정 도메인만 허용**: 사용자가 허용된 도메인의 URL만 입력할 수 있어요.
- **특정 도메인 차단**: 차단된 도메인을 제외한 모든 URL을 사용자가 입력할 수 있어요.

## **유연한 날짜 및 시간 필드**

날짜 및 시간 필드는 시간 기반 정보를 목적에 맞는 형식으로 수집하는 데 도움을 줘요. 사용자가 어떤 유형의 날짜·시간 정보를 입력해야 하는지 결정할 수 있고, 비즈니스 프로세스에 추가 검증이 필요한 경우 선택 가능한 날짜를 제한할 수도 있어요.

다음 필드 형식 중에서 선택할 수 있어요:

- **날짜 & 시간**: 달력 날짜와 구체적인 시간을 모두 수집해요.
- **날짜만**: 시간 없이 달력 날짜만 수집해요.
- **시간만**: 날짜 없이 시간만 수집해요.

이러한 형식은 다음과 같은 사용 사례를 지원할 수 있어요:

- 중요 일정
- 선호하는 연락 시간
- 갱신일
- 예정된 이벤트
- 날짜 또는 시간이 중요한 기타 레코드 정보

날짜 기반 필드의 경우, 목적에 따라 선택 가능한 날짜도 제한할 수 있어요:

- **미래 날짜만 허용**: 사용자가 과거 날짜를 선택하지 못하도록 해요.
- **과거 날짜만 허용**: 사용자가 미래 날짜를 선택하지 못하도록 해요.
- **특정 날짜 범위**: 선택 가능한 범위를 지정된 범위로 제한해요.

예를 들어, 미래 날짜 제한 설정은 다가오는 갱신일을 실수로 과거 날짜로 입력하는 것을 방지하는 데 도움이 될 수 있어요.

## **서식 있는 텍스트(Rich Text) 필드**

Rich Text 커스텀 필드는 일반 텍스트만으로는 부족한, 더 많은 구조가 필요한 정보를 위해 설계됐어요. 긴 내용에 서식을 적용하면 사용자가 레코드를 검토할 때 중요한 세부 내용을 더 쉽게 훑어보고 이해할 수 있어요.

Rich Text 필드는 다음과 같은 서식 옵션을 지원해요:

- 굵은 글씨
- 기울임꼴
- 제목
- 목록
- 기타 지원되는 텍스트 서식

Rich Text 필드는 상세 메모, 구조화된 정보, 안내 사항, 요약 등 서식이 가독성을 높여주는 콘텐츠에 유용해요.

## **사용자(Users) 필드**

Users 커스텀 필드를 사용하면 관련된 하이퍼클래스 사용자를 레코드에 연결할 수 있어요. 책임이나 협업이 한 사람에게 국한되지 않고, 레코드와 관련된 추가 팀원을 식별해야 할 때 유용합니다.

Users 필드는 한 명 또는 여러 명의 사용자를 선택할 수 있도록 설정할 수 있어요. 이는 여러 팀원이 같은 레코드에서 협업하는 상황을 지원할 수 있어요.

이 필드를 통해 선택된 사용자는 팔로워 수준의 접근 권한도 함께 받아서, 관련 팀원이 해당 레코드와 계속 연결된 상태를 유지하는 데 도움이 돼요.

## **체크박스 옵션용 이미지**

체크박스 옵션에 이미지를 추가하면 사용자가 여러 항목을 선택할 수 있을 때 시각적인 맥락을 제공할 수 있어요. 텍스트와 이미지를 함께 사용하면 선택지가 제품, 디자인, 카테고리 등 시각적으로 구분되는 항목일 때 더 쉽게 식별할 수 있어요.

각 체크박스 옵션에는 해당 선택지와 함께 이미지를 포함할 수 있어요. 이는 텍스트만으로는 전달하기 어려운 선택지 간의 차이를 이미지가 더 빠르게 전달할 때 특히 유용해요.

가능한 사용 사례는 다음과 같아요:

- 제품 선택
- 디자인 선택
- 시각적 카테고리
- 스타일 선호도
- 시각적 맥락이 도움이 되는 기타 다중 선택 항목

## **라디오 버튼 옵션용 이미지 및 아이콘**

이미지와 아이콘은 사용자가 하나의 항목만 선택해야 할 때 라디오 버튼 옵션을 더 쉽게 구분할 수 있게 해줘요. 선택지가 디자인, 카테고리, 스타일 등 시각적으로 더 쉽게 인식되는 개념을 나타낼 때 시각적 맥락이 특히 도움이 됩니다.

여러 항목을 선택할 수 있는 체크박스와 달리, 라디오 버튼은 하나의 옵션만 선택하도록 설계되어 있어요. 이제 각 라디오 버튼 옵션에도 선택지와 함께 이미지나 아이콘을 포함할 수 있어요.

## **확장된 커스텀 필드 설정 방법**

필드 유형과 사용 가능한 설정을 올바르게 구성하면 사용자가 비즈니스 프로세스에서 요구하는 형식으로 정보를 입력하는 데 도움이 돼요. 하이퍼클래스 커스텀 필드는 Custom Fields(커스텀 필드) 영역에서 관리하며, 여기서 적절한 오브젝트를 선택하고 용도에 맞게 필드를 설정할 수 있어요.

- 하위 계정(Sub-account)에서 **Settings(설정)**으로 이동하세요.

- **Custom Fields(커스텀 필드)**를 선택하세요.

- 커스텀 필드를 만들고자 하는 오브젝트를 선택하세요.

- **Create Field(필드 생성)** 또는 새 커스텀 필드를 생성하는 옵션을 클릭하세요.

- 선택한 필드 유형에 맞는 세부 설정을 구성하세요:

**URL 필드**의 경우, 적절한 도메인 제어 옵션을 설정하세요.

- **Date and Time(날짜 및 시간) 필드**의 경우, 필요한 날짜/시간 형식과 해당되는 날짜 제한 옵션을 선택하세요.

- **Rich Text 필드**의 경우, 서식 적용이 필요한 콘텐츠를 위해 필드를 생성하세요.

- **Users 필드**의 경우, 레코드에 연결해야 할 사용자가 한 명인지 여러 명인지에 따라 설정하세요.

- **Checkbox(체크박스) 필드**의 경우, 시각적 선택이 필요한 각 옵션에 이미지를 추가하세요.

- **Radio(라디오) 필드**의 경우, 시각적 맥락이 필요한 각 옵션에 이미지나 아이콘을 추가하세요.

**중요**: 커스텀 필드 사용 가능 여부는 해당 필드가 사용되는 오브젝트나 하이퍼클래스 내 영역에 따라 다를 수 있어요. 프로세스를 구축하기 전에 선택한 필드 유형이 의도한 오브젝트와 사용 사례에서 지원되는지 먼저 확인하세요.

## **자주 묻는 질문**

**Q: 웹 주소를 입력받을 때 일반 텍스트 필드 대신 URL 필드를 사용해야 하나요?**
A: 수집하려는 값이 구체적으로 웹 주소라면 전용 URL 필드가 유용해요. 또한 추가적인 도메인 제어 기능을 통해 모든 도메인을 허용할지, 특정 도메인만 허용할지, 아니면 특정 차단된 도메인을 제외한 모든 도메인을 허용할지 결정할 수 있어요.

**Q: 사용자가 날짜를 선택하지 않고 시간만 입력하게 할 수 있나요?**
A: 네, 가능해요. 유연한 날짜 및 시간 필드 옵션에는 날짜만, 날짜와 시간 형식 외에도 시간만 입력하는 형식이 포함되어 있어요.

**Q: 사용자가 과거 날짜를 선택하지 못하게 할 수 있나요?**
A: 네, 가능해요. 날짜 제한을 미래 날짜만 선택 가능하도록 설정할 수 있어요. 사용 사례에 더 적합하다면 과거 날짜만 또는 특정 날짜 범위로도 제한할 수 있어요.

**Q: 일반 텍스트 필드 대신 Rich Text 필드는 언제 사용해야 하나요?**
A: 제목, 목록, 굵은 글씨, 기울임꼴 같은 서식이 긴 정보를 정리하는 데 도움이 될 때 Rich Text가 유용해요. 서식 없이 값만 필요하다면 일반 텍스트 필드로 충분할 수 있어요.

**Q: Users 커스텀 필드에서 누군가를 선택하면 그 사람이 레코드의 소유자가 되나요?**
A: 공개된 기능 설명에 따르면, 이 필드를 통해 선택된 사용자는 레코드에 대한 팔로워 수준의 접근 권한을 받게 돼요. 따라서 해당 하이퍼클래스 기능이 명시적으로 그러한 동작을 지원하지 않는 한, Users 필드를 소유권이나 담당자 지정 필드의 대체 수단으로 사용해서는 안 돼요.

**Q: 체크박스 옵션과 라디오 버튼 옵션은 언제 각각 사용해야 하나요?**
A: 사용자가 여러 항목을 선택할 수 있어야 할 때는 체크박스를 사용하세요. 하나의 항목만 선택해야 할 때는 라디오 버튼을 사용하세요.

**Q: 체크박스와 라디오 버튼 옵션 모두 시각적 선택을 지원하나요?**
A: 둘 다 시각적 맥락을 제공할 수 있지만, 지원하는 옵션은 달라요. 체크박스 옵션은 이미지를 포함할 수 있고, 라디오 버튼 옵션은 이미지 또는 아이콘을 포함할 수 있어요.

**Q: 확장된 커스텀 필드 유형은 하이퍼클래스 어디에서나 사용할 수 있나요?**
A: 커스텀 필드 사용 가능 여부는 해당 필드가 사용되는 오브젝트와 하이퍼클래스 내 영역에 따라 달라질 수 있어요. 필드를 설정하기 전에 의도한 오브젝트와 워크플로우에서 사용 가능한 필드 유형과 설정을 먼저 확인하세요.
