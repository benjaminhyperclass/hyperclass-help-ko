# CSV 파일로 기회 가져오기

CSV 파일을 사용하면 기회를 한꺼번에 새로 만들거나 이미 있는 기회를 일괄 업데이트할 수 있어요. 다른 시스템의 딜 데이터를 옮기거나, 기존 연락처에 기회를 추가하거나, 파이프라인·단계·상태·금액·커스텀 필드 같은 기회 정보를 고칠 때 쓰세요.

모든 기회는 연락처와 연결되어 있어야 해요. 연락처가 이미 하이퍼클래스에 있다면 연락처 ID(**연락처 ID**)로 기회만 가져올 수 있어요. 연락처까지 함께 만들거나 가져와야 한다면 **Contacts + Opportunities**(연락처 + 기회)로 가져오세요.

{% hint style="warning" %}
기회만 가져올 때는 모든 행에 올바른 **연락처 ID**, **기회명**, **파이프라인** 값이 있어야 해요.
{% endhint %}

---

## CSV 파일로 기회를 가져오면 좋은 점

CSV로 가져오면 기회를 하나씩 편집하지 않아도 여러 개를 빠르게 만들거나 업데이트할 수 있어요. 가져오기 전에 데이터를 제대로 준비해 두면 연락처, 파이프라인, 단계, 기회 정보 사이의 연결도 그대로 유지돼요.

- 기회 일괄 생성: CSV 파일 하나로 여러 기회를 만들 수 있어요.
- 기존 기회 업데이트: 기회 ID를 이용해 이미 있는 기록을 일괄 업데이트할 수 있어요.
- 연락처 연결: 가져온 기회를 해당하는 기존 연락처와 연결할 수 있어요.
- 파이프라인 정리: 하이퍼클래스에 있는 파이프라인과 해당 단계로 기회를 가져올 수 있어요.
- 커스텀 데이터 이전: 다른 CRM이나 데이터 소스의 기회 커스텀 필드를 매핑할 수 있어요.
- 가져오기 문제 확인: **일괄 작업**에서 가져오기 결과와 실패한 행을 확인할 수 있어요.

---

## 기회를 가져오기 전에 준비할 것

가져오기를 시작하기 전에 CSV 파일과 하이퍼클래스 계정을 미리 준비하면 매핑 오류와 의도하지 않은 중복 기회를 줄일 수 있어요. 파일을 올리기 전에 필요한 CRM 기록과 필드가 있는지 확인하세요.

가져오기 전에 다음을 확인하세요.

- 파일을 **CSV 형식**으로 저장하세요.
- CSV 파일 크기는 현재 안내된 한도인 **30MB** 이하여야 해요.
- 사용할 파이프라인을 하이퍼클래스에 미리 만들어 두세요.
- 단계 정보를 가져오려면 해당 파이프라인 단계를 미리 만들어 두세요.
- 매핑하려는 **기회 커스텀 필드**를 미리 만들어 두세요.
- 기회만 가져올 때는 모든 행에 올바른 **연락처 ID**가 있는지 확인하세요.
- 기존 기회를 업데이트할 때는 **기회 ID**를 포함하세요.
- 비어 있거나 잘못된 값이 없는지 데이터를 검토하세요.
- 데이터가 많다면 먼저 작은 샘플 파일로 시험해 보세요.

{% hint style="warning" %}
이미 완료된 가져오기는 한 번에 되돌릴 수 없어요. 매핑을 꼼꼼히 확인하고, 데이터가 많다면 먼저 소수의 기록으로 시험해 보세요.
{% endhint %}

### 파이프라인과 단계 값 준비하기

파이프라인 정보는 가져온 기회가 어디에 정리될지 정해요. 가져오기 전에 하이퍼클래스에서 이 값들을 준비해 두면 기회가 의도한 영업 프로세스에 들어가요.

CSV의 **파이프라인** 값은 하이퍼클래스에 있는 파이프라인과 일치해야 해요.

**파이프라인 단계**를 포함한다면, 해당 파이프라인 안에 그 단계가 이미 있는지 확인하세요.

---

## 기회만 가져오기 vs 연락처 + 기회 함께 가져오기

하이퍼클래스에서는 기회만 가져오거나, 연락처와 기회를 함께 가져올 수 있어요. 기회와 연결할 연락처가 이미 하이퍼클래스에 있는지에 따라 방법을 고르세요.

| 가져오기 유형 | 이럴 때 사용해요 |
| --- | --- |
| 기회만 가져오기 | 연락처가 이미 하이퍼클래스에 있고, 올바른 **연락처 ID**를 알고 있을 때 |
| 연락처 + 기회 함께 가져오기 | 같은 CSV 행에서 연락처를 가져오거나 만들면서 기회도 연결해야 할 때 |

기회만 가져올 때는 연락처가 이미 있고 **연락처 ID**로 연결하므로, 이름·이메일·전화번호 형식처럼 연락처 가져오기에 필요한 요건을 따로 맞출 필요가 없어요.

**Contacts + Opportunities**로 가져올 때는 하이퍼클래스가 연락처 기록도 만들거나 가져오므로, 연락처 가져오기 요건도 함께 적용돼요.

---

## 기회 필수 필드와 선택 필드

CSV에 어떤 필드를 넣느냐에 따라 각 기회에 만들거나 업데이트할 수 있는 정보가 달라져요. 필수 필드는 연락처 연결과 파이프라인 위치를 정하고, 선택 필드로는 그 밖의 딜 정보를 옮길 수 있어요.

| 필드 | 필수 여부 | 용도 |
| --- | --- | --- |
| **연락처 ID** | 기회만 가져올 때 필수 | 기회를 하이퍼클래스의 기존 연락처와 연결해요. |
| **기회명** | 필수 | 기회의 이름을 정해요. |
| **파이프라인** | 필수 | 기회를 기존 파이프라인에 배정해요. |
| **파이프라인 단계** | 단계를 지정하려면 권장 | 선택한 파이프라인의 해당 단계에 기회를 놓아요. |
| **기회 ID** | 기존 기회를 업데이트할 때 필수 | 하이퍼클래스가 업데이트할 기존 기회를 정확히 찾도록 식별해요. |
| **Opportunity Value**(기회 금액) | 선택 | 기회의 금액을 저장해요. |
| **상태** | 선택 | 기회 상태를 정해요. |
| **Custom Opportunity Fields**(기회 커스텀 필드) | 선택 | 기회에만 해당하는 추가 정보를 가져와요. |

### 기회 상태

하이퍼클래스에서 쓸 수 있는 기회 상태는 다음과 같아요.

- **진행 중**
- **고객전환성공**
- **고객전환실패**
- **중단됨**

기존에 쓰던 CRM의 상태 이름이 다르다면, 가져오기 전에 위 상태 중 알맞은 값으로 바꿔 주세요.

### 기회 커스텀 필드

기회 커스텀 필드는 연락처 커스텀 필드와 별개예요. 가져오기를 시작하기 전에 필요한 커스텀 필드를 **기회** 오브젝트에 만들어 두세요.

필드를 매핑할 때 각 CSV 열을 그에 해당하는 기회 커스텀 필드에 연결하세요.

## CSV 파일로 기회 가져오는 순서

가져오기는 레코드 유형을 고르고, CSV를 올리고, 각 열을 하이퍼클래스 필드에 매핑한 뒤, 가져오기 설정을 검토하는 순서로 진행해요. ID나 파이프라인 값이 잘못되면 의도하지 않은 기록이 만들어질 수 있으니 시작하기 전에 매핑을 꼼꼼히 확인하세요.

### 1단계: 가져오기 시작하기

1. 하이퍼클래스 서브 계정에서 **기회 관리**(Opportunities)로 이동하세요.
2. **가져오기**를 클릭하세요.

   ![기회 관리 화면에서 가져오기를 클릭하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081214710/original/zO2v3ZZzdPsIJHRDDmjQmCinbSGnsRov_w.png?1789661464)
3. 알맞은 가져오기 유형을 고르세요.

   - **기회 관리**
   - 두 가지 레코드를 모두 가져와야 하면 **Contacts + Opportunities**(연락처 + 기회)

   ![가져오기 유형을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081214763/original/iUFMcMb7dXfYR_9sbjZA-zLRCuLzFQl8_w.png?1789661494)

### 2단계: CSV 파일 올리기

1. CSV 파일을 선택하거나 가져오기 창으로 끌어다 놓으세요.
2. 파일이 정상적으로 올라갔는지 확인하세요.
3. 계속하기 전에 처음 나오는 파일 경고가 있으면 확인하세요.

### 3단계: 가져오기 방식 선택하기

새 기록을 만드는지, 기존 기록을 업데이트하는지에 맞게 가져오기 방식을 고르세요.

기존 기회를 업데이트할 때는 CSV에 올바른 **기회 ID** 값이 들어 있는지 확인하세요.

{% hint style="warning" %}
기존 기회를 업데이트하려는데 올바른 기회 ID를 넣지 않으면, 의도한 기록을 업데이트하는 대신 다른 기회가 새로 만들어질 수 있어요.
{% endhint %}

### 4단계: CSV 열을 하이퍼클래스 필드에 매핑하기

필드 매핑은 CSV의 각 열이 하이퍼클래스의 어느 필드에 해당하는지 알려 주는 과정이에요. 다음 단계로 넘어가기 전에 ID와 기회 필드를 꼼꼼히 확인하세요.

먼저 필수 필드를 매핑하세요.

- **연락처 ID**
- **기회명**
- **파이프라인**

그런 다음 해당하는 선택 필드를 매핑하세요.

- 파이프라인 단계
- 기회 ID
- **Opportunity Value**(기회 금액)
- 상태
- 기회 커스텀 필드

가져오지 않을 CSV 열은 매핑하지 않고 두세요. 안내 창이 나오면 **Don't import data for unmapped columns**(매핑하지 않은 열의 데이터는 가져오지 않음)를 확인하세요.

### 5단계: 빈 값 처리 방식 설정하기

기존 기회를 업데이트할 때는 CSV의 빈 셀이 하이퍼클래스에 있는 기존 데이터에 어떤 영향을 줄지 정하세요.

CSV의 빈 셀 때문에 기존 기회 값이 바뀌지 않게 하려면 **Don't update Empty Values**(빈 값은 업데이트하지 않음)를 켜세요.

예를 들어 기존 기회의 커스텀 필드에는 값이 있는데 CSV의 해당 셀이 비어 있다면, 이 옵션을 켜 두면 하이퍼클래스의 기존 값이 빈 값으로 바뀌지 않고 그대로 남아요.

### 6단계: 검토하고 가져오기 시작하기

제출하기 전에 다음을 확인하세요.

1. 매핑한 필드를 검토하세요.
2. 필수 필드가 모두 매핑되었는지 확인하세요.
3. 경고가 있으면 확인하세요.
4. 빈 값 설정을 다시 확인하세요.
5. 필요 없는 열이 제외되었는지 확인하세요.
6. 가져오기를 시작하세요.

## 기회 업데이트는 어떻게 동작하나요?

기회를 업데이트하려면 기존 기록을 믿을 수 있게 식별할 방법이 필요해요. 기회 ID가 그 역할을 해서, 하이퍼클래스가 그 행을 새 딜로 취급하지 않고 의도한 기회에 가져온 값을 적용해요.

### 새 기회 만들기

새 기회를 만들 때는 다음을 지키세요.

- 올바른 **연락처 ID**를 넣으세요.
- **기회명**을 넣으세요.
- **파이프라인**을 넣으세요.
- 필요하면 단계, 상태, 금액, 커스텀 필드를 추가하세요.
- 새 기회에는 **기회 ID**가 필요 없어요.

### 기존 기회 업데이트하기

기존 기회를 업데이트할 때는 다음 순서로 진행하세요.

1. CSV에 기존 **기회 ID**를 넣으세요.
2. 그 열을 **기회 ID** 필드에 매핑하세요.
3. 업데이트할 필드를 매핑하세요.
4. 빈 셀이 기존 값을 덮어쓸지 정하세요.
5. 기회를 많이 업데이트하기 전에 먼저 작은 테스트로 가져와 보세요.

{% hint style="warning" %}
기회 ID가 없거나 잘못되면, 의도한 기회를 업데이트하는 대신 가져오기 과정에서 다른 기회가 새로 만들어질 수 있어요.
{% endhint %}

CSV를 준비하기 전에 ID를 먼저 찾아야 한다면 [하이퍼클래스에서 파이프라인, 단계, 기회 ID 찾는 방법](../../23-레거시-자동화/how-to-find-pipeline-stage-and-opportunity-ids-in-hyperclass.md)을 참고하세요.

## 연락처와 기회를 함께 가져오기

기회와 연결할 연락처가 아직 하이퍼클래스에 없다면 함께 가져오기가 편해요. 연락처 정보와 기회 정보를 같은 CSV 행에 넣으면, 가져오는 동안 기록이 만들어지고 서로 연결돼요.

다음과 같은 데이터를 옮길 때 이 방법을 쓰세요.

| 연락처 데이터 | 기회 데이터 |
| --- | --- |
| **First Name**(이름) | **기회명** |
| **Last Name**(성) | **파이프라인** |
| **Email**(이메일) | **파이프라인 단계** |
| **Phone**(전화번호) | **Opportunity Value** |
| 연락처 커스텀 필드 | **기회 상태** |
|  | 기회 커스텀 필드 |

가져오는 동안 다음 순서로 진행하세요.

1. **Contacts + Opportunities**를 선택하세요.
2. 연락처와 기회가 함께 들어 있는 CSV를 올리세요.
3. 연락처 열을 연락처 필드에 매핑하세요.
4. 기회 열을 기회 필드에 매핑하세요.
5. 두 가지 매핑을 모두 검토하세요.
6. 가져오기를 완료하세요.

연락처 기록을 가져올 때는 식별 정보와 전화번호 형식 같은 연락처별 요건이 적용돼요.

연락처 가져오기에 필요한 준비 사항은 여기서 다시 설명하지 않아요. 자세한 내용은 [CSV 파일로 연락처 가져오기](../../02-연락처/importing-contacts-using-a-csv-file.md)를 참고하세요.

## 가져오기 결과 확인하고 오류 고치기

**일괄 작업**에서 CSV 가져오기의 진행 상태와 결과를 볼 수 있어요. 일부 행은 성공하고 다른 행은 ID 누락, 잘못된 값, 매핑 문제 때문에 실패할 수 있으니, 특히 대량 이전 뒤에는 결과를 꼭 확인하세요.

가져오기를 시작한 뒤 다음 순서로 확인하세요.

1. **일괄 작업**으로 이동하세요.
2. 해당 가져오기를 찾으세요.
3. 상태를 확인하세요.
4. **통계 보기**를 클릭해 가져오기 결과를 확인하세요.
5. 성공한 기록과 실패한 기록을 살펴보세요.
6. 실패한 기록이 있으면 **오류** 탭을 여세요.
7. 제공되는 오류 로그를 다운로드하세요.
8. 각 행이 실패한 이유를 확인하세요.
9. CSV에서 실패한 행을 고치세요.
10. 필요에 따라 고친 기록만 다시 가져오세요.

일부 행만 실패했다면 원래 파일 전체를 바로 다시 가져오지 마세요. 성공한 행이 이미 기회를 만들었을 수 있기 때문이에요.

## 자주 생기는 기회 가져오기 문제 해결

기회 가져오기 오류는 대부분 ID 누락, 파이프라인 불일치, 잘못된 업데이트 방식, 필드 매핑 문제에서 생겨요. 이 부분을 먼저 확인하면 가져오기 전체를 다시 만들지 않고도 실패한 행을 해결할 수 있어요.

### 기회가 올바른 연락처와 연결되지 않았어요

CSV에 올바른 **연락처 ID**가 들어 있고, 그 열이 **연락처 ID** 필드에 매핑되었는지 확인하세요.

기회만 가져올 때는 모든 기회가 기존 연락처와 연결되어야 해요.

### 기존 기회가 업데이트되지 않고 새 기회가 만들어졌어요

**기회 ID**를 확인하세요. 업데이트할 행에 올바른 기회 ID가 없으면 하이퍼클래스가 새 기회로 처리할 수 있어요.

### 파이프라인이 인식되지 않아요

**파이프라인** 값이 하이퍼클래스에 있는 파이프라인과 일치하는지 확인하세요. CSV 가져오기가 파이프라인을 자동으로 만들어 주지는 않으니, 가져오기 전에 필요한 파이프라인을 먼저 만드세요.

### 기회가 엉뚱한 단계에 들어갔어요

**파이프라인 단계** 값을 검토하고, 선택한 파이프라인 안에 의도한 단계가 있는지 확인하세요.

### 기존 데이터가 빈 값으로 바뀌었어요

업데이트용 가져오기에서 **Don't update Empty Values**를 켰는지 확인하세요. CSV의 빈 셀 때문에 하이퍼클래스의 기존 값이 바뀌지 않게 하려면 이 옵션을 켜세요.

### 매핑할 때 커스텀 필드가 보이지 않아요

다음을 확인하세요.

- 가져오기를 시작하기 전에 커스텀 필드를 만들었는지
- 연락처 오브젝트가 아니라 **기회** 오브젝트에 만들었는지
- CSV 열을 올바른 기회 필드에 매핑하고 있는지

### 일부 행은 실패하고 나머지는 가져와졌어요

**일괄 작업 > 통계 보기 > 오류**에서 해당 가져오기를 열고, 오류 로그를 다운로드해서 실패한 행을 고친 뒤 고친 데이터를 다시 가져오세요.

## 자주 묻는 질문

### 연락처를 가져오지 않고 기회만 가져올 수 있나요?

연락처가 이미 하이퍼클래스에 있다면 가능해요. 기회만 가져올 때는 각 기회에 올바른 **연락처 ID**가 있어야 하이퍼클래스가 알맞은 연락처와 연결할 수 있어요.

### 기회만 가져올 때 연락처 ID가 꼭 필요한가요?

네. 기회만 가져오는 CSV에는 현재 하이퍼클래스 도움말 기준으로 **연락처 ID**, **기회명**, **파이프라인**이 필요해요.

### 새로 만들지 않고 기존 기회를 업데이트하려면 어떻게 하나요?

CSV에 기존 **기회 ID**를 넣고 가져오기 중에 매핑하세요. 올바른 기회 ID가 없으면 하이퍼클래스가 의도한 기록을 업데이트하지 않고 다른 기회를 만들 수 있어요.

### 가져오기 전에 파이프라인과 단계가 먼저 있어야 하나요?

네, 가져오기 전에 필요한 파이프라인과 해당 단계를 만들어 두세요. 파이프라인 값은 하이퍼클래스에 있는 파이프라인과 일치해야 하고, 가져오는 단계는 의도한 파이프라인에 속해 있어야 해요.

### 업데이트용 CSV에 빈 셀이 있으면 기존 값은 어떻게 되나요?

CSV의 빈 셀 때문에 하이퍼클래스의 기존 기회 데이터가 바뀌지 않게 하려면 **Don't update Empty Values**를 켜세요.

### 기회 커스텀 필드도 가져올 수 있나요?

네. 가져오기를 시작하기 전에 기회 오브젝트에 커스텀 필드를 만들고, 필드 매핑 단계에서 해당하는 CSV 열을 매핑하세요.

### 기회 가져오기를 되돌릴 수 있나요?

아니요. 하이퍼클래스에는 완료된 가져오기를 한 번에 되돌리는 기능이 없어요. 데이터가 많다면 작은 샘플 파일로 먼저 시험하고 매핑을 꼼꼼히 확인한 뒤 가져오세요.

### 가져오기에 실패한 기회 행은 어디서 볼 수 있나요?

**일괄 작업**에서 해당 가져오기를 찾아 **통계 보기**를 선택한 뒤 **오류** 탭을 확인하세요. 오류 로그를 다운로드하면 실패한 행을 찾아 고칠 수 있어요.
