# 하이퍼클래스가 매출에서 수수료를 가져가나요?

**아니요, 하이퍼클래스는 판매(거래) 수수료를 받지 않습니다.** 네이버 스마트스토어·쿠팡·라이브클래스처럼 "매출의 몇 %"를 플랫폼이 떼가는 구조가 아니에요.

**왜 수수료가 없나요?**

- 하이퍼클래스는 **결제를 대행하지 않습니다.** **사장님 본인 명의의 토스페이먼츠(PG) 가맹 계약**을 연동해 드리는 방식이라, 고객이 결제한 돈은 중간 정산 없이 **토스페이먼츠에서 사장님 계좌로 직접** 들어갑니다.
- 결제 대행 플랫폼들이 수수료를 받는 이유는 "고객 결제를 자기들이 대신 받아서 정산해 주기 때문"인데, 하이퍼클래스는 그 중간에 서지 않으므로 수수료를 받을 이유 자체가 없어요.
- 하이퍼클래스에 내시는 비용은 **월 구독료 + 사용량 비용**이 전부입니다. 매출이 아무리 늘어도 하이퍼클래스 비용은 그대로예요. (→ [요금제 구성](pricing-plans.md), [사용량 비용](usage-costs.md))

**그럼 결제 수수료가 아예 0인가요?**

- 하이퍼클래스 몫은 0이지만, 어떤 결제 시스템을 쓰든 발생하는 **PG(전자결제) 수수료**는 토스페이먼츠에 냅니다. 공시 기준 신용·체크카드 약 3.4%, 계좌이체 약 2.0% 수준이에요(VAT 별도, 업종·계약·연매출 규모에 따라 다름).
- 연매출 규모에 따른 **영세·중소 가맹점 우대 수수료율은 자동 적용**됩니다. 정확한 요율은 토스페이먼츠 가맹 계약 시 확정되니 [토스페이먼츠 이용요금](https://www.tosspayments.com/about/fee) 페이지를 참고하세요.
- 이 수수료는 사장님과 토스페이먼츠 간의 직접 계약 조건이라, 하이퍼클래스를 거치지 않습니다.

**네이버페이·카카오페이 같은 간편결제도 받을 수 있나요?**

네. 토스페이먼츠 계약 하나로 **네이버페이·카카오페이·토스페이·페이코·애플페이·삼성페이** 등 간편결제를 각 간편결제사와 따로 계약하지 않고 신청해서 쓸 수 있어요. 신용·체크카드(국내/해외)·계좌이체·가상계좌도 물론 포함됩니다. 결제 링크·청구서·퍼널 결제 페이지 어디에서나 활성화하신 수단이 그대로 노출돼요. (→ [어떤 결제 수단을 지원하나요?](payment-methods.md))

**다른 플랫폼과 비교하면?**

| 구분 | 판매 수수료 | 결제 구조 |
| --- | --- | --- |
| **하이퍼클래스** | **0%** (구독료만) | 사장님 명의 토스페이먼츠 → 사장님 계좌 직접 정산 |
| 라이브클래스 | 매출의 5~10% (무료 플랜 10%, 유료 플랜 5%) + PG 수수료 별도 | 플랫폼이 결제 대행 후 정산 |
| 스마트스토어·쿠팡 등 오픈마켓 | 판매·매출연동 수수료 별도 부과 | 플랫폼이 결제 대행 후 정산 |

정리하면: **매출이 커질수록 유리한 구조**입니다. 플랫폼 수수료 없이 PG 수수료만 부담하고, 고객 데이터와 결제 흐름을 모두 사장님이 직접 소유하시게 돼요.
