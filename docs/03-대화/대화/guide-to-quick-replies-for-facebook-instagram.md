# Facebook·Instagram 빠른 답장 설정 가이드

빠른 답장(Quick Replies)은 Facebook과 Instagram 메시지에 미리 정해 둔 답변 선택지를 붙이는 기능이에요. 문의가 자주 들어오는 비즈니스에서 고객에게 빠르게 응대하고 대화를 이어 가고 싶을 때 쓰면 좋아요.

## 개요

빠른 답장을 쓰면 Facebook과 Instagram 메시지에 미리 정해 둔 답변 선택지를 보여 줄 수 있어요. 고객은 선택지를 눌러 간편하게 답할 수 있고, 비즈니스는 더 빠르고 효율적으로 소통할 수 있어요.

## 빠른 답장 설정하기

1. 왼쪽 메뉴에서 **자동화**로 이동해 상단의 **워크플로우**를 선택해요. 그런 다음 **Create Workflow**(워크플로우 만들기)를 선택하거나 기존 워크플로우를 편집해요.
   ![워크플로우 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036408900/original/lkPJOf5JrrO40XXLlS019ID_9ofuz2dQWw.png?1731410097)
2. 트리거를 설정해요. 예를 들어 고객이 Facebook이나 Instagram 게시물에 댓글을 남기는 경우를 트리거로 쓸 수 있어요. 필요하면 특정 게시물을 선택해요.
   ![트리거 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036409697/original/Fecr-YY7jrWWnlmRWHjA3oe-5ZdeIMoiUg.png?1731410629)
3. Facebook의 인터랙티브 메시지 옵션에서 **Reply to comment via DM**(DM으로 댓글에 답장) 또는 **Reply via DM**(DM으로 답장)을 선택해요. 템플릿이나 **스니펫**을 아직 만들지 않았다면 **마케팅** 메뉴에서 먼저 만들어 두세요.
   ![DM 답장 액션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036738833/original/fEukGTost3oTHosq5lmvzyVcE4_cMzQXhg.jpeg?1731932607)
4. 설정 영역에서 미리 정해 둔 선택지를 버튼으로 추가해요. 아래 화면에서는 "질문이 있어요" 버튼을 추가했고, 이 버튼을 누르면 전화번호로 전화를 걸 수 있도록 연결했어요.
   ![버튼 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036741552/original/A49x9sr3OoDBVOAwxSccGnuEp6f8r3THhw.png?1731934628)
5. 워크플로우 액션 **Facebook Interactive Messenger**(Facebook 인터랙티브 메신저)와 **Instagram Interactive Messenger**(Instagram 인터랙티브 메신저)로 Facebook이나 Instagram용 빠른 답장을 설정할 수 있어요. 빠른 답장은 최대 13개까지 만들 수 있고, 하나당 최대 20자까지 쓸 수 있어요.
   ![인터랙티브 메신저 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036745039/original/H2sel0kmpP7Fy82oxI34C6flRrornQ8NzA.png?1731936733)

![빠른 답장 설정 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035120341/original/LPxNSf31EvECrdzoH-cJ8vzNOBQTagXCLw.png?1729526980)

## 빠른 답장이 보이는 방식

- 빠른 답장은 고객 화면에 미리 정해 둔 선택지로 표시돼요. 고객은 한 번만 눌러 간편하게 답장을 보낼 수 있어요.
  ![고객 화면에 표시된 빠른 답장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035120368/original/ZuMrhNRz0zCZI41CDnyYrEZ3BMNpmUrStg.png?1729527006)
- **대화** 화면에서는 메시지 아래에 빠른 답장이 모두 표시돼요.
  ![대화 화면에 표시된 빠른 답장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035120429/original/CcpSxKVIu4_4BhnWMpPYuvPsuljuGw1zyA.png?1729527063)
- 고객이 선택한 빠른 답장은 수신 메시지로 전달돼요. **대화** 화면에서는 파란색으로 표시돼요.
  ![파란색으로 표시된 선택한 빠른 답장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035120461/original/_zxKvWe_9LDGIB2xfAD2Pop3phgf0kCp0Q.png?1729527105)

{% hint style="info" %}
- 빠른 답장은 가장 최근 메시지에만 표시되고, 한 번 누르면 바로 답장이 되는 방식으로 작동해요.
- 고객이 빠른 답장을 한 번 선택하면 선택을 바꿀 수 없어요. 덕분에 대화가 한 방향으로 이어져요.
{% endhint %}

### 채널별 조건

- Facebook: 버튼, 이미지와 함께 빠른 답장을 추가할 수 있어요. 고객이 고를 수 있는 선택지가 더 다양해져요.
- Instagram: 메시지에 버튼 또는 빠른 답장 중 하나를 추가할 수 있어요. 빠른 답장은 같은 메시지에 첨부파일이 없을 때만 추가할 수 있어요.
