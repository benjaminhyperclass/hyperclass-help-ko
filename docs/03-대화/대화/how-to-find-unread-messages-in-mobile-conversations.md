# 모바일 대화에서 읽지 않은 메시지 찾기

하이퍼클래스 모바일 앱의 **대화**에서 **신규** 구분선으로 읽지 않은 메시지를 바로 찾을 수 있어요. 읽지 않은 메시지가 있는 대화를 열면 채팅 맨 아래가 아니라 첫 번째 읽지 않은 메시지로 이동해요. 긴 대화에서도 스크롤이 더 부드러워졌어요. 이 문서에서는 읽지 않은 메시지를 찾는 방법과 구분선의 동작, 대화 사이를 더 편하게 오가는 방법을 안내해요.

## 모바일 대화의 읽지 않은 메시지 구분선이란?

**신규** 구분선은 대화에서 읽지 않은 메시지가 시작되는 위치를 보여 줘요. 읽지 않은 수신 메시지 중 가장 먼저 온 메시지 바로 위에 표시되기 때문에, 읽던 곳부터 이어서 볼 수 있어요.

읽지 않은 대화를 열면 앱이 이 구분선으로 자동 스크롤해요. 읽지 않은 메시지가 대화 기록 한참 위에 있어도 마찬가지예요.

이 기능은 자동으로 동작하며 별도 설정이 필요 없어요.

## 신규 구분선의 동작 방식

읽지 않은 활동이 있는 대화를 열면, 하이퍼클래스가 첫 번째 읽지 않은 수신 메시지 위에 **신규** 구분선을 표시해요.

위로 스크롤하면 이전 메시지를, 아래로 스크롤하면 최신 활동을 볼 수 있어요.

![읽지 않은 메시지 위에 표시된 신규 구분선](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083796254/original/qqcJu1LypSSU4sTI8sGLPmCYWUzF0hAhGA.png?1792516662)

{% hint style="info" %}
대화를 열어도 자동으로 읽음 처리되지 않아요. 구분선은 대화의 읽지 않음 상태가 해제될 때까지 그대로 남아 있어요.
{% endhint %}

## 신규 구분선이 사라지는 경우

대화가 읽음 상태가 되면 구분선은 자동으로 사라져요.

다음과 같은 경우에 읽음 상태가 돼요.

- 메시지 입력창에서 답장을 보낼 때
- AI가 제안한 답장을 보낼 때
- 대화를 직접 읽음으로 표시할 때
- 웹 앱이나 다른 기기에서 답장할 때

구분선을 직접 지울 필요는 없어요.

자세한 내용은 [대화를 읽음으로 표시하기](how-to-mark-a-conversation-as-read.md)를 참고하세요.

## 긴 대화에서 더 부드러워진 스크롤

대화 기록이 길어도 모바일 **대화**가 이전보다 부드럽게 스크롤돼요.

120Hz 디스플레이를 지원하는 기기에서는 스크롤 성능이 약 120 FPS까지 나올 수 있어요. 이전에는 약 90 FPS였어요.

실제 성능은 기기에 따라 달라질 수 있어요.

## 지원하는 모바일 앱

이번 릴리스는 다음 모바일 앱을 대상으로 해요.

- 하이퍼클래스 모바일 앱
- 화이트라벨 모바일 앱

{% hint style="info" %}
제공된 릴리스 노트에는 이 기능이 QA 중(In QA)으로 표시되어 있어요. 공식 출시일과 지원하는 앱 버전은 아직 확정되지 않았어요.
{% endhint %}

## 모바일 대화에서 읽지 않은 메시지 찾기

**신규** 구분선은 지원하는 모바일 앱 버전에서 자동으로 표시돼요. 특별한 설정이나 필터는 필요 없어요.

1. 모바일 앱을 열어요. 하이퍼클래스 모바일 앱 또는 지원하는 화이트라벨 앱에 로그인하세요.
2. **대화**로 이동해 대화 목록을 열어요.
3. 확인하려는 읽지 않은 대화를 탭하세요.
4. **신규** 구분선을 찾아요. 채팅이 첫 번째 읽지 않은 수신 메시지 위치에서 열리고, 그 바로 위에 구분선이 보여요.
5. 새 메시지를 읽은 뒤 답장하거나, 필요하면 대화를 읽음으로 표시하세요.

![모바일 대화 목록에서 읽지 않은 대화를 열어 신규 구분선을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083796287/original/KpNpz7mZruof0uWA7ERTQHxH2AqlQLNgmw.png?1792516719)

## 자주 묻는 질문

### **신규** 구분선을 따로 켜야 하나요?
아니요. 지원하는 앱 버전에서 대화에 읽지 않은 메시지가 있으면 자동으로 표시돼요.

### 대화가 채팅 중간에서 열려요. 왜 그런가요?
놓친 메시지를 바로 확인할 수 있도록 앱이 첫 번째 읽지 않은 메시지 위치에서 대화를 열어요.

### 대화를 열면 읽음 처리되나요?
아니요. 대화를 여는 것만으로는 읽지 않음 상태가 꼭 해제되지는 않아요.

### **신규** 구분선은 언제 사라지나요?
답장을 보내거나 읽음으로 표시하는 등 대화가 읽음 상태가 되면 사라져요.

### 다른 기기에서 답장하면 구분선이 사라지나요?
네. 웹이나 다른 기기에서 답장해서 읽지 않음 상태를 해제하는 것도 이번 릴리스에서 지원해요.

### 이전 메시지도 볼 수 있나요?
네. 위로 스크롤하면 이전 메시지를 볼 수 있어요.

### 긴 대화에서도 구분선이 동작하나요?
네. 읽지 않은 메시지가 대화 기록 한참 위에 있어도 앱이 그 위치에서 열려요.

### 모든 휴대폰에서 스크롤이 120 FPS까지 나오나요?
아니요. 실제 스크롤 성능은 기기와 디스플레이 성능에 따라 달라요.

### 이 기능은 언제부터 쓸 수 있나요?
출시일과 지원하는 앱 버전은 아직 확정되지 않았어요.
