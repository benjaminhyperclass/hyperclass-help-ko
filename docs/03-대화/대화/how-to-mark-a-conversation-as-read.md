# 대화를 읽음으로 표시하기

읽지 않은 대화는 팀이 아직 확인하지 못한 메시지를 찾는 데 도움이 돼요. 하이퍼클래스에서는 대화를 열어도 자동으로 읽음 처리되지 않아요. 답글을 보내거나 의도한 처리를 마치기 전에 리드나 고객의 메시지를 놓치지 않도록 하기 위해서예요. 이 문서에서는 대화를 직접 읽음으로 표시하는 방법과 워크플로우로 자동화하는 방법을 안내해요.

## 대화 읽음 상태란?

대화 읽음 상태를 보면 **대화** 메뉴에서 아직 확인이 필요한 메시지를 파악할 수 있어요. 대화는 사용자가 답글을 보내거나 직접 읽음으로 표시하기 전까지 읽지 않은 상태로 남아요. 그래서 메시지를 언제 처리된 것으로 볼지 팀이 직접 정할 수 있어요.

## 대화 읽음 상태의 장점

- 리드 누락 방지: 대화를 열어도 자동으로 읽음 처리되지 않아서, 메시지를 실수로 지나치는 일을 줄일 수 있어요.
- 정돈된 인박스: 읽지 않은 대화는 사용자가 답글을 보내거나 읽음으로 표시할 때까지 계속 보여요.
- 팀 책임 관리: 팀원이 아직 처리가 필요한 대화를 한눈에 알아볼 수 있어요.
- 자동화 지원: 필요할 때 워크플로우로 대화 읽음 상태를 자동으로 바꿀 수 있어요.

## 읽은 대화와 읽지 않은 대화의 동작 방식

읽지 않은 대화는 분명한 동작이 있을 때까지 읽지 않음 상태로 남아요. 메시지를 클릭해서 들어가거나 대화를 보기만 해서는 읽음 상태가 바뀌지 않아요.

읽지 않은 대화를 열어도 읽지 않음 상태가 유지돼요. 답변하기 전에 리드나 고객의 메시지가 처리된 것으로 잘못 표시되지 않게 하려는 의도적인 동작이에요.

다음과 같은 경우에 대화가 읽음으로 표시돼요.

- 대화에 직접 답글을 보낼 때
- 대화 화면에서 **읽음으로 표시** 아이콘을 클릭할 때
- 워크플로우가 **Edit Conversation**(대화 편집) 워크플로우 액션으로 대화 상태를 바꿀 때

## 대화를 직접 읽음으로 표시하기

대화를 읽음으로 정확하게 표시해 두면 읽지 않은 대화 목록이 정확하게 유지돼요. 그러면 팀이 아직 확인이 필요한 메시지에 집중할 수 있어요.

1. 하이퍼클래스 계정에서 **대화**를 클릭하세요.
2. **팀 인박스**를 여세요.
3. 읽지 않은 대화를 선택하세요.

   ![읽지 않은 대화를 선택한 팀 인박스 화면](https://jumpshare.com/share/b9j1AQDv1sb2fnpUo9gv+/Screen+Shot+2026-06-05+at+15.16.42.png)
4. 다음 중 한 가지를 하세요.

   - 대화에 **답글**을 보내세요.
   - 대화 화면 오른쪽 위에 있는 **읽음으로 표시** 아이콘을 클릭하세요.
5. 대화가 읽지 않은 대화 목록에서 사라졌는지 확인하세요.

   ![읽지 않은 대화 목록에서 대화가 사라진 화면](https://jumpshare.com/share/o0xewlaGRe6LaH2hJ5DP+/Screen+Shot+2026-06-05+at+15.18.26.png)

## 워크플로우로 읽음 표시 자동화하기

특정 상황이나 워크플로우 활동에 따라 대화를 읽음으로 표시해야 할 때 워크플로우 자동화가 유용해요. 대화를 하나씩 직접 바꾸는 대신, 워크플로우 액션이나 워크플로우 설정으로 인박스에 대화가 보이는 방식을 조절할 수 있어요.

이 동작을 자동화하려면 [워크플로우 액션 - Edit Conversation(대화 편집)](../../07-워크플로우/workflow-action-edit-conversation.md) 문서를 확인하세요. 이 액션으로 대화를 읽음 또는 읽지 않음으로 표시할 수 있고, 대화를 보관하거나 보관 해제할 수도 있어요.

## 자주 묻는 질문

### 대화를 열면 읽음으로 표시되나요?
아니요. 대화를 열거나 클릭해서 들어가는 것만으로는 자동으로 읽음 처리되지 않아요.

### 대화를 열었는데도 왜 계속 읽지 않음으로 남아 있나요?
팀이 답글을 보내거나 직접 읽음으로 표시하기 전에 메시지가 처리된 것으로 잘못 표시되는 일을 막기 위해서예요.

### 대화에 답글을 보내면 읽음으로 표시되나요?
네. 읽지 않은 대화에 답글을 보내면 자동으로 읽음으로 표시돼요.

### 답글을 보내지 않고도 대화를 읽음으로 표시할 수 있나요?
네. 대화를 열고 오른쪽 위에 있는 **읽음으로 표시** 아이콘을 클릭하세요.

### 대화를 읽음으로 표시하는 작업을 자동화할 수 있나요?
네. **Edit Conversation** 워크플로우 액션을 사용하면 대화 읽음 상태를 자동으로 바꿀 수 있어요.
