# 대화를 읽음으로 표시하는 방법

읽지 않음 상태의 대화는 팀이 아직 응대해야 할 메시지를 파악하는 데 도움을 줍니다. 하이퍼클래스에서는 대화(Conversation)를 열어도 자동으로 읽음 처리되지 않아요. 이렇게 하면 답장을 보내거나 의도적으로 처리하기 전에 리드나 고객 메시지를 놓치는 일을 방지할 수 있습니다. 이 가이드를 참고해서 대화를 수동으로 읽음 처리하거나 워크플로우(Workflow)로 자동화하는 방법을 알아보세요.

---

## 대화 읽음 상태란 무엇인가요?

대화 읽음 상태는 팀이 대화(Conversations) 영역에서 아직 처리해야 할 메시지를 추적하는 데 도움을 줍니다. 대화는 사용자가 답장을 보내거나 직접 읽음으로 표시하기 전까지는 계속 읽지 않음 상태로 남아있어요. 이를 통해 팀이 메시지 처리 완료 시점을 더 명확하게 관리할 수 있습니다.

## 대화 읽음 상태의 주요 이점

- **놓치는 리드 방지**: 대화를 열어도 자동으로 읽음 처리되지 않기 때문에, 팀이 실수로 메시지를 놓치는 것을 방지할 수 있어요.

- **깔끔한 인박스(수신함) 관리**: 사용자가 답장을 보내거나 직접 읽음 표시를 하기 전까지 읽지 않음 대화가 계속 표시됩니다.

- **팀 책임 관리 지원**: 팀원들이 아직 처리가 필요한 대화를 빠르게 파악할 수 있어요.

- **자동화 지원**: 필요에 따라 워크플로우를 사용해 대화 읽음 상태를 자동으로 업데이트할 수 있습니다.

## 읽음/읽지 않음 대화는 어떻게 작동하나요?

읽지 않음 대화는 명확한 조치가 취해지기 전까지 계속 읽지 않음 상태로 유지됩니다. 메시지를 클릭하거나 대화를 조회하는 것만으로는 읽음 상태가 변경되지 않아요.

읽지 않음 대화를 열어도 해당 대화는 계속 읽지 않음 상태로 남습니다. 이는 팀이 답장을 하기도 전에 실수로 리드나 고객 메시지를 처리 완료로 표시하지 않도록 의도적으로 설계된 기능이에요.

다음의 경우 대화가 읽음으로 표시됩니다:

- **대화에 직접 답장**하는 경우

- 대화 화면에서 **읽음으로 표시(Mark as Read)** 아이콘을 클릭하는 경우

- 워크플로우가 **대화 편집(Edit Conversation)** 워크플로우 액션(Action)을 사용해 대화 상태를 업데이트하는 경우

## 대화를 수동으로 읽음 처리하는 방법

대화를 올바르게 읽음 처리하면 읽지 않음 목록을 정확하게 유지할 수 있고, 팀이 아직 처리가 필요한 메시지에 집중하는 데 도움이 됩니다.

- 하이퍼클래스 계정에서 **대화(Conversations)** 메뉴를 클릭하세요.

- **팀 인박스(Team Inbox)**를 여세요.

- 읽지 않음 대화를 선택하세요.

- 해당 대화가 읽지 않음 목록에서 사라진 것을 확인하세요.

## 워크플로우로 읽음 처리 자동화하기

특정 시나리오나 워크플로우 활동에 따라 대화를 읽음으로 표시해야 하는 경우 워크플로우 자동화가 유용해요. 대화를 하나하나 수동으로 업데이트하는 대신, 워크플로우 액션이나 워크플로우 설정을 사용해 인박스에 대화가 어떻게 표시될지 제어할 수 있습니다.

이 동작을 자동화하려면 [**워크플로우 액션 - 대화 편집(Edit Conversation)**](https://help.gohighlevel.com/support/solutions/articles/48001214153-workflow-action-edit-conversation?utm_source=chatgpt.com) 문서를 참고하세요. 이 액션을 사용하면 대화를 읽음/읽지 않음으로 표시하거나, 보관/보관 해제할 수도 있습니다.

## 자주 묻는 질문

**Q: 대화를 열면 자동으로 읽음 처리되나요?**

아니요. 대화를 열거나 클릭하는 것만으로는 자동으로 읽음 처리되지 않아요.

**Q: 대화를 열었는데도 왜 계속 읽지 않음 상태인가요?**

이는 팀이 답장을 보내거나 의도적으로 읽음 처리하기 전에 메시지가 처리 완료로 표시되는 것을 방지하기 위한 기능입니다.

**Q: 대화에 답장하면 읽음으로 표시되나요?**

네. 읽지 않음 대화에 답장하면 자동으로 읽음 처리됩니다.

**Q: 답장하지 않고도 대화를 읽음으로 표시할 수 있나요?**

네. 대화를 열고 오른쪽 상단의 읽음으로 표시 아이콘을 클릭하면 됩니다.

**Q: 대화 읽음 처리를 자동화할 수 있나요?**

네. 대화 편집(Edit Conversation) 워크플로우 액션을 사용해 대화 읽음 상태를 자동화할 수 있어요.
