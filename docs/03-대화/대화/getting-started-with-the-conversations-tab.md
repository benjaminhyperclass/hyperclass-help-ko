# 새로워진 대화 화면 시작하기

새로워진 **대화** 화면은 패널 네 개, 태그와 그리고/또는 조건을 쓸 수 있는 향상된 필터, 새 이메일 작성창으로 구성되어 있어요. 더 빠르고 보기 쉬운 인박스에서 대화창을 벗어나지 않고 분류, 협업, 응대를 할 수 있어요. 이 문서에서 달라진 점과 활용법을 알아보세요.

## 새로워진 대화 화면이란?

**대화** 모듈 전체를 새로 설계해서 더 빠르고 직관적으로 쓸 수 있게 했어요. 화면의 모든 요소를 다듬어 보기 쉽고 반응이 빨라졌어요. 팀은 메시지를 처리하고, 협업하고, 필요한 맥락을 한곳에서 확인할 수 있어요. 성능이 크게 좋아졌고, 고급 필터와 새 이메일 작성창도 추가됐어요.

새 디자인은 4패널 레이아웃, 연락처 정보를 모아 보여 주는 통합 오른쪽 패널, 고급 필터(태그 + 그리고/또는), 그리고 전체 화면 작성과 인라인 답장을 모두 지원하는 이메일 작성창으로 이루어져 있어요.

{% hint style="info" %}
Google 리뷰 대화에는 연결된 Google Business Profile 페이지 이름이 함께 표시될 수 있어요. 여러 페이지를 연결해 리뷰를 관리할 때 어느 페이지에서 온 리뷰인지 쉽게 알 수 있어요.
{% endhint %}

## 새로워진 대화 화면의 장점

관리자와 상담 담당자는 이 장점을 참고해 새 화면을 켤 시점과 일상적인 활용법을 정하면 돼요. 더 빠르고 정확하게 일할 수 있어요.

- 성능 개선: 모듈 전반에서 수치로 확인되는 개선이 있어요.
- 더 빠른 반응: 동작 반응 속도가 약 70% 빨라졌어요. Google의 '양호' 웹 바이탈 기준을 충족해요.
- 더 빠른 이동: 페이지 이동이 약 35% 빨라졌어요.
- 메모리 사용량 감소: 메모리 사용량이 약 18% 줄어 모든 기기에서 성능이 좋아져요.
- 한 화면에서 맥락 확인: 연락처 세부정보, 문서, 결제, 활동이 대화창 옆에 있어서 클릭 수가 줄어요.
- 정밀한 필터링: 태그와 그리고/또는 조건을 조합해 원하는 대화만 모은 뒤, 저장된 뷰로 저장해 한 번에 열 수 있어요.
- 유연한 작성: 긴 이메일은 전체 화면으로, 빠른 답장은 인라인으로 쓸 수 있어요.
- 메모리 개선 수치: 전체 메모리 사용량이 약 1.7GB에서 약 0.45GB로 줄었어요. 연락처 약 50개를 오가도 메모리는 약 450MB 아래로 유지돼요.
- 타임라인 날짜 형식 통일: 날짜에 월 이름이 들어가는 일관된 형식(예: Jan 5)을 써요. mm/dd와 dd/mm처럼 숫자 형식 때문에 생기는 혼동을 줄이고, 대화 타임라인을 훑어보기 쉬워요.
- 내장 협업 기능: 내부 댓글과 @멘션으로 팀 논의를 비공개로 깔끔하게 정리할 수 있어요.

## 읽지 않은 메시지 빠르게 확인하기

대화가 길어지면 읽지 않은 메시지가 묻히기 쉬워요. 캠페인 로그, 활동 같은 타임라인 이벤트가 섞여 있으면 더 그래요. 읽지 않은 메시지 표시를 쓰면 새 메시지가 시작되는 지점을 정확히 찾아서 더 빨리 답하고 중요한 답장을 놓치지 않을 수 있어요.

읽지 않은 대화를 열면 하이퍼클래스가 자동으로 첫 번째 읽지 않은 메시지로 이동해요. 읽지 않은 메시지가 시작되는 곳에는 **신규** 구분선이 표시돼요.

작동 방식:

1. 읽지 않은 대화를 여세요.
2. 대화창이 첫 번째 읽지 않은 메시지로 자동 스크롤돼요.
3. 읽지 않은 메시지가 시작되는 곳에 **신규** 구분선이 나타나요.

알아둘 점:

- **신규** 구분선은 답장하거나 대화를 직접 **읽음으로 표시**할 때까지 계속 보여요.
- 대화를 나갔다가 다시 들어오거나 페이지를 새로고침해도 구분선이 계속 나타나요.
- **신규** 구분선은 2026년 4월 23일 이후에 받은 메시지에만 표시돼요.

활동이 많은 긴 대화에서도 스크롤을 오래 하지 않고 읽지 않은 답장을 확인할 수 있어요.

## 화면 구성과 이동

새 **대화** 모듈은 정리와 가독성을 높이려고 4패널 레이아웃을 써요. 패널은 접을 수 있어서 원하는 대로 작업 공간을 조절할 수 있어요.

- 인박스 패널을 접거나 펼치려면 왼쪽 패널 가운데에 있는 접기 아이콘을 클릭하세요.
- 오른쪽 패널을 접거나 펼치려면 화면 오른쪽 가장자리에 있는 탭 아이콘을 클릭하세요.

읽거나 답장할 공간이 더 필요할 때 이렇게 조절하면 돼요.

![대화 화면의 4패널 레이아웃](https://jumpshare.com/share/zo1pFU2Xulj4iVAX2B2s+/Screen+Shot+2026-02-03+at+6.01.20+PM.png)

### 대화 패널 크기 조절하기

1. **서브 계정** 화면에서 **대화**로 이동하세요.
2. 크기를 조절할 패널 사이의 구분선에서 크기 조절 아이콘을 찾으세요.
3. 구분선을 왼쪽이나 오른쪽으로 끌어서 패널을 넓히거나 좁히세요.
4. 원하는 너비가 되면 구분선을 놓으세요.

패널 크기 조절 방식:

- 자유로운 패널 너비: 대화 목록, 메시지 대화창, 연락처 세부정보 패널을 조절해서 필요한 정보에 공간을 더 줄 수 있어요.
- 자동 저장되는 레이아웃: 패널 너비는 자동으로 저장돼요. **대화**를 다시 열면 이전에 정한 레이아웃이 그대로 유지돼요.
- 최소·최대 너비: 가독성을 지키기 위해 패널마다 최소·최대 너비가 있어요. 허용 범위를 넘어서 끌 수는 없어요.

## 1. 인박스 패널

인박스 패널에서는 개인, 팀, 내부 채팅 중 어떤 대화 묶음을 볼지 정해요. 페이지를 옮기지 않고도 빠르게 전환할 수 있어요.

- **내 인박스**: 나에게 배정됐거나 내가 팔로우하는 대화예요.
- **팀 인박스**: 계정 안의 모든 대화예요(전체 데이터 접근 권한이 필요해요).
- **내부 채팅**: 고객 대화와 분리된, 팀원끼리만 나누는 비공개 논의예요.

접근 권한 안내:

- **Assigned Data Access**(배정된 데이터 접근) 권한이 있는 계정은 **내 인박스**와 **내부 채팅**을 볼 수 있어요(**팀 인박스**는 볼 수 없어요).
- 전체 접근 권한이 있는 사용자는 세 가지를 모두 보고 관리할 수 있어요.

## 2. 채팅 목록 패널

채팅 목록 패널은 **대화** 레이아웃의 두 번째 열이에요. 인박스 패널에서 선택한 인박스, 폴더, 필터에 맞는 모든 대화를 목록으로 보여 줘요. 현재 인박스, 폴더, 저장된 뷰에 맞는 대화를 훑어보고 선택해서 일괄 작업을 빠르게 할 수 있어요.

- 맨 위의 선택 체크박스를 체크하면 일괄 작업을 쓸 수 있어요: **읽음으로 표시**/**Mark as Unread**(읽지 않음으로 표시), **Star**/**Unstar**(별표 지정/해제), **삭제**
- **정렬**로 최신순이나 오래된순 활동으로 정렬할 수 있어요.
- **필터** 아이콘으로 채널, 태그, 담당자, 날짜 필터를 쓸 수 있어요. **그리고**/**또는** 조합도 지원해요.

![채팅 목록 패널](https://jumpshare.com/share/APFZFvGUSwra7DzTBKwq+/Screen+Shot+2026-02-03+at+6.06.54+PM.png)

이제 읽지 않은 대화 수가 실시간으로 갱신되고, 인박스의 모든 탭에서 계속 보여요.

- 새 메시지가 도착하면 수가 바로 갱신돼요.
- 대화를 읽음으로 표시하면 수가 바로 줄어요.
- **전체**나 **광산** 같은 탭을 보고 있어도 읽지 않음 배지가 계속 보여요.

새 메시지를 확인하려고 **Unread**(읽지 않음) 탭으로 옮겨 갈 필요가 없어서 팀이 더 빠르게 응대할 수 있어요.

필터 사용법은 [대화 필터 개요](../overview-of-conversation-filters.md)에서 자세히 볼 수 있어요.

## 3. 메시지 기록 패널

메시지 기록 패널은 읽고 답장하는 주 영역이에요. 여러 채널의 타임라인, 빠른 답장, 메시지 유형별 필터를 지원해서 필요한 맥락을 빠르게 찾을 수 있어요.

- **이메일, SMS, WhatsApp, Facebook/Instagram 메시지**와 **내부 댓글**까지 전체 기록을 읽을 수 있어요.
- 보이는 타임라인을 필터링해서 특정 항목만 볼 수 있어요(다음 섹션 참고).

{% hint style="info" %}
실시간 채널 업데이트: 오른쪽 패널에서 연락처의 이메일 주소를 추가하거나 수정하면 작성창에 바로 반영돼요. 페이지를 새로고침하지 않고도 이메일 채널로 전환할 수 있어요.
{% endhint %}

![메시지 기록 패널](https://jumpshare.com/share/uVrxwXvnC310lV8YGVsH+/Screen+Shot+2026-02-03+at+6.10.15+PM.png)

### 연락처 세부정보를 수정하면서 통화 녹취록 보기

통화 녹취록은 메시지 기록 패널에서 열려요. 오른쪽 패널은 그대로 쓸 수 있어서 녹취록을 보면서 연락처 세부정보를 수정할 수 있어요.

1. **대화**를 열고 녹음된 통화가 있는 대화를 선택하세요.
2. 통화 카드에서 **음성 인식 보기**를 클릭하세요.
3. 메시지 기록 패널에서 녹취록을 확인하세요.
4. 오른쪽 패널에서 이메일이나 전화번호 같은 연락처 필드를 수정하세요. 녹취록은 닫지 않아도 돼요.
5. 다 봤으면 **녹취록 숨기기**를 클릭하세요.

### 채널 전환하기

대화창을 벗어나지 않고 답장마다 가장 알맞은 채널을 고를 수 있어요. SMS로 시작한 대화를 이메일로 옮기거나 내부 메모를 남길 때 편해요.

- 작성창의 채널 선택기를 열어 사용할 수 있는 채널 사이를 전환하세요.
- 작성창을 접었다 펼쳐도 채널 선택이 유지돼요. 같은 대화에서 작성창을 접었다가 다시 열면, 마지막으로 선택한 채널을 기억해서 하던 곳에서 이어서 쓸 수 있어요.

  ![작성창의 채널 선택기](https://jumpshare.com/share/xIlZ5seZv71JVeIDDEBN+/OGzVi-Ns_g9vPzAJNLWHueH3gmLwZeCqpQ.png)

- **내부 댓글**을 선택하면 비공개 메모를 남길 수 있어요(고객에게 알림이 가지 않아요).
- 내부 댓글 임시저장은 채널 전환, 작성창 접기/펼치기, 대화 전환 후에도 유지돼요.

  ![내부 댓글 임시저장](https://jumpshare.com/share/pbcdoBpR2LH43DuuUaxe+/Screen+Shot+2026-02-03+at+6.19.13+PM.png)

내부 댓글과 멘션은 [대화에서 내부 댓글 추가 및 사용자 멘션하기](conversations-how-to-add-internal-comments-mention-users.md)에서, 임시저장은 [대화에서 임시저장 메시지 사용하기](how-to-save-draft-messages-in-conversations.md)에서 자세히 볼 수 있어요.

### 메시지 작성창

작성창에서는 대화창 맨 아래에서 글을 쓰고, 파일을 첨부하고, 알맞은 채널로 보낼 수 있어요.

- 텍스트 서식을 쓸 수 있어요.
- 인라인 답장 작성창은 활성 메시지 바로 아래에 열려서, 답장하는 동안 앞선 내용을 볼 수 있어요.
- 긴 답장은 전체 화면 모드로 쓸 수 있어요.
- 파일 첨부와 링크를 넣을 수 있어요.
- 클립보드에 있는 파일이나 이미지를 작성창에 바로 붙여 넣어 빠르게 첨부할 수 있어요(Windows는 Ctrl + V, Mac은 Cmd + V).
- 오른쪽의 보내기 아이콘으로 빠르게 보낼 수 있어요.
- 답장은 작성창에서 선택한 채널로 전송돼요.
- 작성창에서 **내부 댓글**을 클릭하면 대화를 벗어나지 않고 고객 답장과 내부 메모를 오갈 수 있어요.

### 대화 안에서 메시지 필터링하기

타임라인 필터를 쓰면 긴 대화에서 이메일만, 내부 메모만, 활동만 따로 골라 볼 수 있어서 필요한 맥락을 빠르게 찾을 수 있어요.

타임라인 오른쪽 위의 메시지 필터에서 다음 항목을 골라 볼 수 있어요.

- **전체** 메시지
- **대화**(연락처와 직접 주고받은 내용)
- **활동**(예약, 업데이트 등)
- **이메일** / **내부 댓글** / **연락처** / **기회 관리** / **결제** / **인보이스** / **AI 액션 로그**

필터 메뉴 안의 검색창에서 메시지나 활동 유형을 더 빨리 찾을 수 있어요. 활동 카드는 [대화의 활동 카드](conversations-activity-cards.md)에서 자세히 볼 수 있어요.

## 대화 보관하기

대화를 삭제하거나 메시지를 잃지 않고 **최근 대화** 탭에서 치울 수 있어요.

대화를 보관하면 이렇게 돼요.

- **최근 대화** 탭에서는 사라지지만 **전체** 탭에서는 그대로 볼 수 있어요.
- 삭제되는 것은 없어요. 대화 기록 전체가 보존돼요.
- 알림은 계속 켜져 있어요. 새 메시지가 오면 평소처럼 알림이 와요.
- 보관된 대화에 새 메시지가 오면 대화는 보관 상태로 남아요(**최근 대화**로 돌아가지 않아요). 대신 **Unread**(읽지 않음) 탭에 나타나서 놓치지 않을 수 있어요.
- **Unarchive**(보관 해제) 버튼을 클릭하면 언제든 보관을 해제할 수 있어요.

![보관된 대화](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076919583/original/lCOiuOHL_XTlkSKaow1v8kAUR7N0liMtyQ.jpeg?1785151726)

## 메시지 상세정보에서 메시지 출처 확인하기

메시지 상세 정보를 보면 메시지가 어디서 왔는지 알 수 있어요. 직접 보낸 메시지가 아니라 연동으로 발송된 메시지일 때 특히 유용해요.

**마켓플레이스 앱**이나 사용자 지정 제공업체로 보낸 메시지는 메시지 상세 정보 패널에 출처 앱 정보가 표시될 수 있어요. 어떤 연동이 메시지를 보냈는지 알 수 있어요.

메시지 출처를 확인하려면:

1. **대화**를 여세요.
2. 확인할 대화를 선택하세요.
3. 발송된 메시지의 메시지 상세 정보를 여세요.
4. **마켓플레이스 앱** 이름과 관련 앱 정보 같은 출처 정보를 확인하세요.

예상하지 못한 메시지의 원인을 파악하거나 어떤 연동이 발송했는지 확인하기 쉬워요.

![메시지 상세 정보의 출처 정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073369036/original/CXjGl6FR7P0j_b3NjG0akm7IxgqbIs2O3Q.png?1781097026)

## 4. 오른쪽 패널

오른쪽 패널에는 연락처 정보가 모여 있어서 대화를 벗어나지 않고 세부정보, 파일, 결제, 관련 기록을 보고 수정할 수 있어요. **연락처** 페이지에서 쓰던 기능은 커스텀 필드, 폴더, 작업까지 모두 이 패널에 들어와 있어요. 고객과 대화하면서 모든 정보를 보고 관리할 수 있어요.

오른쪽 패널에서 할 수 있는 일:

- 연락처 필드, 커스텀 필드, 폴더, 태그, 담당자를 보고 수정하기
- 기회, 예약, 인보이스, 결제를 만들고 보기
- **연락처**, **활동**, **연관**, **문서**, **결제** 같은 탭 전환하기

자세한 내용은 [대화의 오른쪽 패널 & 확장 사이드바](right-panel-expandable-sidebar-in-conversations.md)를 참고하세요.

## 그리고 / 또는 조건

새 필터링 시스템은 조건 연산자를 지원해서 여러 기준을 유연하게 조합할 수 있어요.

- **그리고**(AND)를 쓰면 선택한 조건을 모두 만족하는 대화만 보여 줘요.

  > 예시: *높은 우선순위* 태그가 붙어 있고 **그리고** 나에게 배정된 대화
- **또는**(OR)을 쓰면 선택한 조건 중 하나라도 만족하는 대화를 보여 줘요.

  > 예시: *이메일* **또는** *WhatsApp* 채널의 대화

이렇게 하면 긴급한 지원 요청만 골라내거나 여러 채널의 캠페인을 검토하는 등, 내 업무 흐름에 맞는 복합 필터를 쉽게 만들 수 있어요.

## 이메일 작성창 개선

새 **대화** 모듈의 이메일 작성창은 더 보기 편하고 부드럽고 유연하게 글을 쓸 수 있도록 개선됐어요.

### 전체 화면 작성창

작성창을 전체 화면 레이아웃으로 넓혀서 길거나 자세한 이메일도 편하게 쓸 수 있어요. 서식을 넣고, 파일을 첨부하고, 보내기 전에 내용을 검토할 공간이 더 넉넉해요.

![전체 화면 작성창](https://jumpshare.com/share/QIxlZv5dnIXd5rvitXDW+/GIF+Recording+2026-02-03+at+6.30.51+PM.gif)

### 인라인 답장

기존 이메일 대화에 답장하면 작성창이 자동으로 활성 이메일 바로 아래에 열려요. 입력하는 동안 앞선 내용이 계속 보여서 대화 기록에 집중할 수 있어요.

답장 작성창을 닫으려면 작성창 도구 모음 오른쪽의 삭제 아이콘을 클릭하세요.

참조(CC)와 숨은 참조(BCC)는 [이메일 작성창에서 참조(CC)와 숨은 참조(BCC) 사용하기](../how-to-cc-carbon-copy-and-bcc-blind-carbon-copy-for-email-composer.md)에서 자세히 볼 수 있어요.

## 키보드 단축키

키보드 단축키를 쓰면 이동과 답장이 빨라져요. 단축키 패널을 열면 언제든 사용할 수 있는 동작을 확인하고, 지원되는 경우 매핑을 직접 바꿀 수 있어요.

- ⌘/Ctrl + K — **전체 검색**
- ⌘/Ctrl + Enter — **메시지 전송**
- ⌘/Ctrl + Shift + E — 전체 화면 작성창 켜기/끄기
- **대화**에서 ?를 누르면 전체 단축키 목록이 열려요.

## 자주 묻는 질문

### 저장된 답장, 템플릿, 서명이 새 화면에서도 그대로 있나요?

네. 기존 저장된 답장, 템플릿, 서명은 새 작성창에서도 계속 사용할 수 있어요.

### 키보드 단축키를 바꿀 수 있나요?

?를 누르면 단축키 목록이 열려요. 단축키는 직접 바꿀 수 없어요.

### 모든 채널에서 필터를 쓸 수 있나요? 채널별로 필터링할 수도 있나요?

네. **필터** 아이콘으로 채널(이메일, SMS, WhatsApp 등)을 포함하거나 제외할 수 있어요. 태그, 담당자와 **그리고**/**또는**으로 조합해서 쓸 수도 있어요.

### 필터로 만든 저장된 뷰를 팀원과 공유할 수 있나요?

저장된 뷰를 만들어 두면 빠르게 열 수 있어요. 공유 여부와 공개 범위는 워크스페이스 설정과 권한에 따라 달라요.

### 새 화면을 쓰면 워크플로우 자동화나 트리거가 달라지나요?

아니요. **대화**와 연결된 워크플로우와 캠페인 트리거는 이전과 똑같이 작동해요.

### 내부 댓글과 멘션은 어디서 쓰나요?

채널 선택기에서 **내부 댓글**을 선택하면 비공개 메모를 남길 수 있어요. **@멘션**으로 팀원에게 알릴 수 있어요.

### 읽지 않은 대화 수가 예전과 다르게 보여요.

읽지 않은 대화 수는 이제 실시간으로 갱신되고 인박스의 모든 탭에서 계속 보여요. 예전에는 탭을 전환하거나 어떤 동작을 했을 때만 수가 갱신돼서 반영이 늦어질 수 있었어요.
