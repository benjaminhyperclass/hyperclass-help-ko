# SMS 그룹 채팅 사용하기 (데스크톱·모바일)

SMS 그룹 채팅을 쓰면 데스크톱과 모바일 모두에서 소규모 연락처 그룹에게 하나의 대화 스레드로 문자를 보낼 수 있어요. 여러 고객, 팀원, 이해관계자와 한 번에 대화를 시작하는 방법을 안내해요.

## SMS 그룹 채팅이란?

SMS 그룹 채팅은 그룹을 만들어 여러 연락처에게 하나의 대화로 SMS를 보내는 기능이에요. 1:1 대화를 여러 개 오가지 않고, 가족이나 사내 팀, 부서 전체 같은 여러 연락처와 한 스레드에서 소통할 수 있어요. 그래서 소통 과정이 간결해지고, 답변이 늦어지는 일이 줄고, 참여자 모두에게 대화 내용이 투명하게 공유돼요.

{% hint style="info" %}
1. 그룹 문자는 +1(미국·캐나다) 롱코드 번호에서만 지원돼요. 수신자 부담 번호와 단축 코드(short code)는 Twilio에서 그룹 문자를 주고받을 수 없어요.
2. 그룹 채팅에서도 첨부파일을 보내고 받을 수 있어요. 이미지는 대화 안에 바로 표시되고, 파일은 내려받을 수 있는 칩 형태로 표시돼요. 자세한 내용은 [SMS 첨부파일 크기 제한](../../15-전화-시스템/메시징/file-size-limits-for-attachments-in-sms-and-email.md)을 참고하세요.
{% endhint %}

## SMS 그룹 채팅의 장점

- 협업 대화: 여러 연락처를 하나의 스레드에 모아 대화를 간결하게 이어 갈 수 있어요.
- 간결한 소통: 여러 채팅에 같은 메시지를 반복해서 보내지 않아도 모두가 같은 내용을 볼 수 있어요.
- 고객 참여 향상: 가족, 부서, 팀처럼 관련된 연락처를 묶어 상황에 맞게 소통할 수 있어요.
- 모바일 편의성: 언제 어디서나 그룹 대화를 시작하고, 관리하고, 이어 갈 수 있어요.
- 빠른 응답: 모두가 실시간으로 메시지를 보고 답할 수 있어요.

## 그룹 채팅을 쓰기 위한 조건

SMS 그룹 채팅을 쓰려면 다음 조건이 필요해요.

- 전화번호: SMS/MMS가 켜져 있는 하이퍼클래스 번호를 써야 해요.
- 지역: 참여자 모두 미국 또는 캐나다 전화번호여야 해요.
- 액세스: **Only Assigned Data**(배정된 데이터만) 액세스 권한이 있는 사용자는 자신에게 배정된 연락처만 포함된 그룹을 만들고 볼 수 있어요. 그룹 채팅을 만들 때 쓴 전화번호에 대한 액세스 권한이 있어야 그룹에서 메시지를 보낼 수 있어요.

## 그룹 채팅의 동작 방식과 제한 사항

그룹 채팅을 만들기 전에 아래 내용을 확인하세요.

- 최대 그룹 크기: 그룹 채팅은 참여자 2~9명을 지원해요.
- 수신거부: 수신거부 상태인 연락처는 그룹에 추가할 수 없고 그룹에서 메시지를 받을 수도 없어요. 그룹을 만든 뒤에 참여자가 수신거부를 켜면 그 그룹 스레드는 더 이상 쓸 수 없어요. 그룹 메시지를 계속 보내려면 수신거부 상태인 참여자를 뺀 새 그룹을 만들어야 해요.
- 변경 불가: 그룹을 만든 뒤에는 참여자를 추가하거나 제거할 수 없고 **보낸 사람** 번호도 바꿀 수 없어요. 구성원을 바꿔야 하면 새 그룹을 만드세요.
- 참여자 연락처가 변경된 경우: 나중에 연락처가 삭제되거나 번호가 수정되어도, 메시지는 그룹을 만들 때 추가한 원래 번호로 계속 전달돼요. 영향을 받은 연락처 옆에는 수정됨/삭제됨 태그가 표시돼요.

## 그룹 채팅 만들기 (데스크톱)

1. 왼쪽 메뉴에서 **대화**(Conversations)를 열어요.

   ![왼쪽 메뉴의 대화 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063281934/original/8T0dprUYj-ury60q-6T7jy2SlerpByHfiQ.png?1769099659)
2. 파란색 **Create New Message**(새 메시지 만들기) 버튼을 클릭해요.

   ![새 메시지 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063281964/original/NoONxCc-LURAatRcIabMrpZAkgeVm6yoBg.png?1769099710)
3. **연락처에게 메시지**를 선택해요. 내부 그룹을 만들려면 **팀원에게 메시지**를 선택하세요.

   ![연락처에게 메시지 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063282304/original/818Q9gNk8Te7I7CwcMOS1O6HnfIKgLLLSw.png?1769100026)
4. **그룹 대화**를 선택하고, 메시지를 보낼 번호를 고른 뒤, 참여자를 2~9명 추가하고 **대화 만들기**를 클릭해요.

   ![그룹 대화 설정 후 대화 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063282692/original/8O7CDYYpAmCPx0sOzXT_LBJkhgGHjp1dyQ.png?1769100301)
5. **메시지를 입력하세요** 입력란에 메시지를 쓰고 **보내기**를 클릭해요.

   ![메시지 입력 후 보내기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063282799/original/jXCxzw12spVrCr7rJB2ECOPC3rRiTNlr9A.png?1769100378)

## 그룹 채팅 만들기 (모바일)

1. iOS 또는 Android 기기에서 하이퍼클래스 모바일 앱을 열고, 화면 아래쪽의 **대화** 탭을 탭해요.
2. 대화 유형으로 **Group Chat**(그룹 채팅)을 선택해요.
3. 전화번호를 선택하고, 연락처 목록에서 그룹 채팅에 추가할 연락처를 여러 명 골라요. 참여자는 최소 2명, 최대 9명까지 추가할 수 있어요.
4. 나중에 쉽게 찾을 수 있도록 그룹 채팅 이름을 지어요. 이 단계는 선택 사항이에요.
5. **채팅 시작**을 탭하면 바로 대화가 시작돼요.

## 그룹 채팅 관리하기

그룹 채팅이 시작되면 1:1 채팅처럼 소통할 수 있어요. 다음 작업을 할 수 있어요.

- 메시지 보내기와 받기
- 이미지나 파일 공유하기
- 채팅 참여자 전체 보기

그룹 채팅 창 맨 위에서 추가된 연락처를 모두 볼 수 있어요. **채팅 참여자** 아이콘을 클릭하면 이름이나 전화번호로 참여자를 검색할 수 있어요.

![채팅 참여자 아이콘으로 참여자 검색](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063292140/original/iAEvLl6weH6HNDNATYFjvcdTMAUXkEiE8w.png?1769114318)

## 자주 묻는 질문

### 그룹을 만든 뒤에 참여자나 업무용 번호를 바꿀 수 있나요?

아니요. 바꿀 수 없어요. 수신자를 새로 구성해서 새 그룹을 만드세요.

### 그룹 채팅에서도 첨부파일을 쓸 수 있나요?

네, 쓸 수 있어요. 다만 통신사의 파일 크기 제한을 지켜야 해요. 전송이 실패하면 파일을 압축해서 다시 보내 보세요. SMS 파일 제한에 대한 자세한 내용은 [SMS 첨부파일 크기 제한](../../15-전화-시스템/메시징/file-size-limits-for-attachments-in-sms-and-email.md)을 참고하세요.

### 그룹을 만든 뒤에 참여자가 수신거부를 켜면 어떻게 되나요?

그 스레드로는 그룹 메시지를 보낼 수 없어요. 수신거부 상태인 연락처를 뺀 새 그룹을 만들거나, 그 연락처가 다시 수신에 동의하면 같은 스레드를 계속 쓸 수 있어요.

### 모바일 앱에서도 그룹 채팅을 관리할 수 있나요?

네. 하이퍼클래스 모바일 앱에서 그룹 채팅을 만들고, 보고, 답장할 수 있어요.

### 그룹 채팅에서 알림은 어떻게 오나요?

1:1 채팅과 똑같이 와요. 그룹에 새 메시지가 올 때마다 모바일 푸시 알림이 전달돼요.

### 그룹 채팅 참여자는 모두 이전 메시지를 볼 수 있나요?

네. 그룹 구성원은 모두 전체 메시지 기록을 볼 수 있어요.
