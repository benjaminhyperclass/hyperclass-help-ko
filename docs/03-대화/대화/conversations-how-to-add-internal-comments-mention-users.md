# 대화에서 내부 댓글 남기고 팀원 멘션하기

하이퍼클래스 **대화**(Conversations)에서 내부 댓글과 @멘션을 쓰면, 연락처에게 노출되지 않게 대화 기록 안에서 팀원과 협업할 수 있어요. 이 문서에서는 내부 댓글과 @멘션이 무엇인지, 댓글을 남기고 검색하는 방법, 팀원에게 알림이 가는 방식을 안내해요.

## 내부 댓글이란?

내부 댓글은 대화 기록에 남기는 비공개 메모예요. 연락처에게는 전송되지 않고, 연락처가 볼 수도 없어요. @를 입력하고 팀원을 선택하면 그 팀원을 멘션할 수 있고, 멘션된 팀원은 알림을 받아 내용을 확인하거나 후속 작업을 할 수 있어요. 업무를 넘길 때 필요한 맥락을 한곳에 모아 둘 수 있어요.

**내부 댓글**과 **내부 채팅**은 달라요. **내부 채팅**은 별도의 팀 채팅 기능이에요.

{% hint style="info" %}
**대화**의 내부 댓글은 한 번 남기면 수정하거나 삭제할 수 없어요.
{% endhint %}

## 내부 댓글의 장점

메시지를 보낼지, 내부 댓글을 쓸지, 팀 채팅으로 전환할지 고민될 때 참고하세요.

- 비공개 협업: 민감한 메모와 결정 사항을 연락처에게 보이지 않게 남길 수 있어요.
- 맞춤 알림: 알맞은 팀원을 @멘션해서 대화를 바로 확인하게 할 수 있어요.
- 빠른 업무 인계: 대화 화면을 떠나지 않고 맥락과 다음 할 일을 전달할 수 있어요.
- 검색 가능한 맥락: 필터로 내부 메모를 찾아볼 수 있어서 품질 점검과 감사에 도움이 돼요.

## 내부 댓글 남기기

1. 서브 계정에 로그인해요.
2. **대화** 탭을 클릭해요.

   ![대화 탭](https://jumpshare.com/share/Oolsmxa8ThGG2ktK3Uwa+/Screen+Shot+2026-02-03+at+6.50.58+PM.png)
3. 내부 댓글을 남길 대화를 클릭해서 열어요.

   ![대화 열기](https://jumpshare.com/share/dEXBarVKvpU3MWbS093g+/Screen+Shot+2026-02-03+at+6.52.29+PM.png)
4. **Channel Switcher**(채널 전환) 버튼을 눌러 **내부 댓글**로 바꿔요.

   ![채널 전환 버튼으로 내부 댓글 선택하기](https://jumpshare.com/share/h6ilpcAieORSwP6UAVYt+/GIF+Recording+2026-02-03+at+6.55.00+PM.gif)
5. 댓글을 입력해요. 필요하면 @를 입력해서 팀원을 멘션하세요.
6. 내부 댓글 초안은 자동으로 저장돼요. 채널을 바꾸거나, 입력창을 접었다 펼치거나, 다른 대화로 이동해도 초안이 그대로 남아 있어요.
7. **보내기**를 클릭하면 댓글이 등록돼요. 내부 사용자에게만 보여요.

   ![보내기 버튼](https://jumpshare.com/share/ot2gHS6naeN1IzR8vSbw+/Screen+Shot+2026-02-03+at+6.58.09+PM.png)

## 내부 댓글 필터링하기

내가 멘션된 대화나 특정 사용자가 멘션된 대화를 보려면 다음 순서로 진행하세요.

1. **빠른 필터** 버튼을 클릭해요.

   ![빠른 필터 버튼](https://jumpshare.com/share/zzst31TVJX9ncRM5Fxtx+/Screen+Shot+2025-09-16+at+10.14.01+PM.png)
2. **Mentions**(멘션) 필터에서 **Mentions of Me**(나를 멘션한 대화)를 선택하고 **적용**을 클릭하면, 내가 멘션된 대화를 볼 수 있어요.

   ![나를 멘션한 대화 필터](https://jumpshare.com/share/7ZEh5vvYaUHzhwVst6Oo+/Screen+Shot+2025-09-16+at+10.19.48+PM.png)
3. 특정 사용자의 멘션을 보려면 **Mentions of a Specific User**(특정 사용자 멘션)를 선택하세요. 목록에서 사용자를 고르고 **적용**을 클릭하면, 그 사용자가 멘션된 대화를 볼 수 있어요.

   ![특정 사용자 멘션 필터](https://jumpshare.com/share/N1uHrIXOo9LPA5XeF37u+/Screen+Shot+2025-09-16+at+10.23.39+PM.png)
4. 한 대화 안의 내부 댓글을 모두 보려면 **필터** 버튼을 클릭하고 **내부 댓글** 필터를 적용하세요.

   ![내부 댓글 필터](https://jumpshare.com/share/LJ1JdMcW2SVx5jzjvaUq+/Screen+Shot+2025-09-16+at+10.26.03+PM.png)

## 알림 관리하기

- 내가 멘션되었을 때나 관련 대화에 새 메시지가 왔을 때 알림을 받으려면 알림 설정이 켜져 있어야 해요.
- **설정 > 내 프로필 > 알림**으로 이동해서 필요한 알림을 켜세요.

## 자주 묻는 질문

### 내부 댓글 초안은 자동으로 저장되나요?
네. 내부 댓글 초안은 자동으로 저장돼요. 채널을 바꾸거나, 입력창을 접었다 펼치거나, 다른 대화로 이동해도 초안이 그대로 남아 있어요.

### 연락처가 내부 댓글을 볼 수도 있나요?
아니요. 내부 댓글은 우리 팀에게만 보이고, 연락처에게는 전송되지 않아요.

### @멘션하면 이메일이 가나요, 앱 안 알림만 가나요?
알림은 사용자마다 설정한 알림 환경에 따라 달라요. 팀원에게 **설정 > 내 프로필 > 알림**을 확인해 달라고 요청하세요.

### 내부 댓글을 나중에 검색하거나 필터링할 수 있나요?
네. **필터 > 내부 댓글**을 사용하세요. 나에게 온 멘션을 찾으려면 **필터 > Mentions of Me**(나를 멘션한 대화)를 사용하세요.
### 내부 댓글은 누가 수정하거나 삭제할 수 있나요?
**대화**의 내부 댓글은 한 번 남기면 수정하거나 삭제할 수 없어요.

### 내부 댓글에 첨부파일을 넣을 수 있나요?
아니요. 내부 댓글에서는 첨부파일을 지원하지 않아요.
