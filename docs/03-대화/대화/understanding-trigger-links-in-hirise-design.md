# HiRise 디자인의 트리거 링크(Trigger Link) 이해하기

하이퍼클래스의 트리거 링크(Trigger Links) 페이지가 이제 깔끔한 HiRise 인터페이스를 갖추게 되었어요. 더 빠른 로딩 속도, 쉬운 탐색, 그리고 몇 초 만에 동적 링크를 만들 수 있는 원클릭 커스텀 값(Custom Value) 선택기를 제공합니다. 클릭을 추적하고 후속 작업을 자동화하는 더 편리한 방법을 만나보세요.

# 트리거 링크 HiRise 디자인 업그레이드란 무엇인가요?

HiRise는 하이퍼클래스 전반의 레이아웃, 타이포그래피, 성능을 통일하는 현대적인 디자인 언어예요. 트리거 링크 페이지를 HiRise로 다시 설계하면서, 오래된 표 형식과 수동 새로고침 방식을 없애고 세련된 목록 보기, 고정 필터, 실시간 작업 기능으로 대체했어요. 덕분에 에이전시는 막힘없이 링크를 만들고, 검색하고, 공유할 수 있습니다.

트리거 링크 자체의 작동 방식은 그대로예요. 각 클릭은 연락처 상세(레코드)에 기록되며, 워크플로우나 캠페인을 실행시킬 수 있어요.

---

## 트리거 링크 HiRise 업그레이드의 주요 이점

- 즉각적인 페이지 로딩—더 이상 로딩 스피너를 기다릴 필요가 없어요.

- 열 너비를 조절할 수 있고, 조밀하게/여유롭게 보기 밀도를 선택할 수 있는 더 깔끔한 목록 보기.

- 내장된 커스텀 값 선택기: 병합 코드를 외울 필요 없이 연락처, 회사, 로케이션 단위의 값을 바로 삽입할 수 있어요.

- 공유 가능 URL은 검색어, 페이지, 행 개수 설정을 그대로 유지해서, 동료가 지금 이야기하고 있는 바로 그 화면을 열어볼 수 있어요.

- 일관된 HiRise 스타일이 다른 리뉴얼 영역(연락처, 결제 등)과 통일되어, 신규 직원의 학습 곡선을 줄여줘요.

---

## HiRise 인터페이스 개요

이제 미니멀한 툴바에 전체 검색, 필터, "+ 새 트리거 링크(New Trigger Link)" 버튼이 모여 있어요. 열은 드래그 앤 드롭으로 크기를 조절할 수 있고, 점 세 개(⋮) 메뉴는 상황에 맞게 바뀌어서—관련이 있을 때만 편집(Edit), URL 복사(Copy URL), 분석(Analytics), 삭제(Delete)를 보여줘요. 이렇게 화면이 정돈되고 자주 쓰는 작업까지 걸리는 시간이 줄어듭니다.

---

## 커스텀 값 선택기 개선 사항

링크 생성 모달에는 {} 버튼이 있어서 클릭하면 전체 커스텀 값 패널이 열려요. 이름, 예약 ID, 로케이션 슬러그 등 원하는 동적 필드를 선택하면 하이퍼클래스가 자동으로 대상 URL에 병합 코드를 삽입해줘요. 이메일/SMS에서 커스텀 값을 사용하는 것과 비슷한 방식으로, 오타를 방지하고 발송 시점에 값이 정확히 표시되도록 보장합니다.

---

## 보기 설정이 포함된 공유 가능 URL

검색 키워드, 페이지 번호, 페이지당 행 개수 설정을 변경할 때마다 URL이 실시간으로 업데이트돼요. 이 URL을 Slack에 복사해서 공유하면, 동료가 정확히 동일하게 필터링된 목록을 열어볼 수 있어요—QA 검토나 클라이언트 승인 과정에 특히 유용합니다.

## 업그레이드된 트리거 링크 페이지 사용 방법

### 트리거 링크 열기

왼쪽 사이드바에서 **대화(Conversations)**로 이동한 뒤 상단의 **트리거 링크(Trigger Links)** 탭을 선택하세요. 이렇게 하면 대화(Conversations) 모듈 안에서 링크를 관리하고 있다는 것을 확인할 수 있어요. 여기서 클릭을 추적하고 자동화에 활용할 수 있습니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101896/original/63N-Io0pw5xDOPu2EA9FtPCgjXrTSifR8Q.png?1760585798)

### 새 링크 추가

오른쪽 상단의 **+ 링크 추가(Add Link)** 버튼을 클릭해서 새 트리거 링크를 만드세요. 생성 대화상자가 열리면 링크 이름을 짓고 대상 URL을 설정할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101901/original/bLS753_3d6IW2RROEYOQzCPHkEOKdH9mew.png?1760585818)

### 링크 세부 정보 입력

**트리거 링크 추가(Add Trigger Link)** 모달에서 알아보기 쉬운 **이름(Name)**을 입력하고 **링크 URL(Link URL)**을 붙여넣으세요. **저장(Save)**을 클릭하면 목록에 추가되며, 커스텀 값을 넣어야 한다면 {} 아이콘을 사용하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101906/original/K3PLtGeR0h3-igo91T4T7icuC1yFo7zWKg.png?1760585850)

### 링크 검색

오른쪽의 **검색(Search)** 필드를 사용해서 이름의 일부만 입력해도 원하는 링크를 빠르게 찾을 수 있어요. 결과는 즉시 필터링되므로, 목록이 길어도 더 빠르게 링크를 찾을 수 있습니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101910/original/Gxh0SvpXZpHyAgXoTmM3ixKJr6IjK-KrUw.png?1760585876)

### 편집 또는 삭제

행의 점 세 개(⋮) 메뉴를 열면 **편집(Edit)**과 **삭제(Delete)** 작업에 접근할 수 있어요. 페이지를 벗어나지 않고도 URL을 수정하거나, 링크 이름을 바꾸거나, 오래된 항목을 제거할 수 있습니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101920/original/retk_-FedEBqzmhsvcS2yeMXoR1ao1dJig.png?1760585900)

### 링크 키(Link Key) 복사

**링크 키(Link Key)** 옆의 **복사(copy)** 아이콘을 클릭하면 병합 코드가 클립보드에 저장돼요. 이 키를 이메일, SMS(문자), 왓츠앱 템플릿, 워크플로우 액션에 붙여넣으면 클릭을 안정적으로 추적할 수 있습니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101928/original/Ew9JgoGSGIzWmCmmPP1zurqPc1mj6aqyjQ.png?1760585954)

## 자주 묻는 질문

**Q: 업그레이드 후 기존 트리거 링크가 깨지나요?**

아니요. 이번 업그레이드는 순수하게 인터페이스 차원의 변경이며, 기존 링크 ID와 추적 기능은 그대로 유지됩니다.

**Q: 예전 디자인으로 되돌릴 수 있나요?**

클래식 보기는 더 이상 지원되지 않아요. 모든 사용자는 자동으로 HiRise 버전으로 이동됩니다.

**Q: 공유된 URL이 계정 단위의 데이터를 노출하나요?**

공유 URL은 사용자 권한을 그대로 따라요. 특정 하위 계정(Sub-account)에 접근 권한이 없는 동료는 권한 오류 메시지를 보게 됩니다.

**Q: 페이지네이션(페이지 넘김) 컨트롤이 어디로 이동했나요?**

페이지네이션은 이제 오른쪽 하단 모서리에 있으며, 동시에 행 개수 선택 기능도 겸하고 있어요.

**Q: 링크당 커스텀 값 개수에 제한이 있나요?**

기술적인 상한선은 없지만, 이메일 클라이언트 호환성을 위해 URL을 2KB 이하로 유지하는 것이 좋아요.

**Q: 특정 링크의 분석(Analytics) 데이터는 어떻게 확인하나요?**

점 세 개 메뉴 → 분석(Analytics)을 클릭하면 선택한 기간 동안의 순 클릭 수, 연락처, 상위 유입 경로를 확인할 수 있어요.

**Q: 트리거 링크가 왓츠앱(WhatsApp) 메시지에서도 작동하나요?**

네—복사한 링크를 왓츠앱 V2 템플릿 버튼이나 인라인 링크에 삽입하면 이메일/SMS와 똑같이 탭(클릭)을 추적할 수 있어요.
