# 트리거 링크 HiRise 디자인 살펴보기

**트리거 링크** 페이지가 새 HiRise 디자인으로 바뀌었어요. 페이지가 더 빨리 열리고, 화면 이동이 쉬워졌고, 커스텀 값을 한 번에 골라 동적 링크를 만들 수 있어요. 이 문서에서 달라진 화면과 사용법을 확인하세요.

## 트리거 링크 HiRise 디자인 업그레이드란?

HiRise는 하이퍼클래스의 새 디자인 체계예요. 앱 전체의 레이아웃, 글꼴, 성능을 하나로 맞춰 줘요. 이번에 **트리거 링크** 페이지도 HiRise로 다시 만들었어요. 예전의 표 형태와 수동 새로고침은 없어졌고, 깔끔한 목록 보기와 고정 필터, 실시간 작업 기능이 생겼어요. 에이전시와 서브 계정 사용자 모두 링크를 더 편하게 만들고, 찾고, 공유할 수 있어요.

트리거 링크의 동작 방식은 그대로예요. 링크를 클릭할 때마다 연락처 기록에 남고, 워크플로우나 캠페인을 시작할 수도 있어요.

## 업그레이드로 좋아진 점

- 페이지가 바로 열려요. 오래 기다릴 일이 없어요.
- 목록 보기가 더 깔끔해졌어요. 열 너비를 조절할 수 있고, 행 간격을 촘촘하게 또는 넉넉하게 바꿀 수 있어요.
- 커스텀 값 선택기가 내장되어 있어요. 병합 코드를 외우지 않아도 연락처, 회사, 로케이션 단계의 값을 넣을 수 있어요.
- 공유 URL에 검색어, 페이지, 페이지당 행 수 설정이 그대로 담겨요. 팀원이 내가 보고 있는 화면을 똑같이 열 수 있어요.
- 다른 개편 영역(**연락처**, **결제** 등)과 디자인이 같아서 새 직원도 쉽게 익힐 수 있어요.

## HiRise 화면 둘러보기

상단의 간단한 도구 모음에 전체 검색, 필터, **+ New Trigger Link**(새 트리거 링크) 버튼이 모여 있어요.열 너비는 끌어서 조절해요. 세 점 메뉴에는 상황에 맞는 항목만 나타나요. **편집**, **Copy URL**(URL 복사), **분석**, **삭제** 중 지금 쓸 수 있는 것만 보여 줘요. 그래서 화면이 덜 복잡하고 자주 쓰는 작업에 더 빨리 닿아요.

## 커스텀 값 선택기

링크를 만드는 창에 {} 버튼이 있어요. 이 버튼을 누르면 커스텀 값 전체 목록이 열려요. 이름, 예약 ID, 로케이션 슬러그 같은 동적 필드를 고르면 병합 코드가 도착 URL에 자동으로 들어가요. 오타를 막아 주고, 발송할 때 값이 제대로 표시되도록 해 줘요. 이메일이나 SMS에서 커스텀 값을 쓰는 것과 비슷해요.

## 보기 설정이 담긴 공유 URL

검색어, 페이지 번호, 페이지당 행 수를 바꿀 때마다 URL이 실시간으로 바뀌어요. 이 URL을 Slack으로 보내면 동료가 똑같이 필터링된 목록을 열어요. 검수나 고객 승인 때 편해요.

## 업그레이드된 트리거 링크 페이지 사용하기

### 트리거 링크 열기

왼쪽 메뉴에서 **대화**로 이동한 뒤 맨 위의 **트리거 링크** 탭을 선택하세요. 클릭을 추적하고 자동화에 활용할 수 있는 **대화** 메뉴 안에서 링크를 관리하게 돼요.

![트리거 링크 탭이 열린 대화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101896/original/63N-Io0pw5xDOPu2EA9FtPCgjXrTSifR8Q.png?1760585798)

### 새 링크 추가하기

오른쪽 위의 **+ Add Link**(링크 추가) 버튼을 누르세요. 링크 만들기 창이 열리면 링크 이름과 도착 URL을 입력할 수 있어요.

![오른쪽 위의 링크 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101901/original/bLS753_3d6IW2RROEYOQzCPHkEOKdH9mew.png?1760585818)

### 링크 정보 입력하기

**트리거 링크 추가** 창에서 알아보기 쉬운 **이름**을 입력하고 **링크 URL**을 붙여 넣으세요. 그런 다음 **저장**을 누르면 목록에 추가돼요. 커스텀 값을 넣어야 하면 {} 아이콘을 사용하세요.

![트리거 링크 추가 창에서 이름과 링크 URL 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101906/original/K3PLtGeR0h3-igo91T4T7icuC1yFo7zWKg.png?1760585850)

### 링크 검색하기

오른쪽의 **검색** 필드에 링크 이름 일부를 입력하면 원하는 링크를 빠르게 찾을 수 있어요. 결과가 바로 걸러져서 목록이 길어도 금방 찾을 수 있어요.

![검색 필드에서 링크 찾기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101910/original/Gxh0SvpXZpHyAgXoTmM3ixKJr6IjK-KrUw.png?1760585898)

### 편집 또는 삭제하기

해당 행의 세 점 메뉴(⋮)를 열면 **편집**과 **삭제**를 선택할 수 있어요. 페이지를 벗어나지 않고 URL을 고치거나, 이름을 바꾸거나, 오래된 링크를 지울 수 있어요.

![행의 세 점 메뉴에서 편집과 삭제 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101920/original/retk_-FedEBqzmhsvcS2yeMXoR1ao1dJig.png?1760585900)

### 링크 키 복사하기

**링크 키** 옆의 복사 아이콘을 누르면 병합 코드가 클립보드에 복사돼요. 이 키를 이메일, SMS, WhatsApp 템플릿, 워크플로우 액션에 붙여 넣으면 클릭을 정확하게 추적할 수 있어요.

![링크 키 옆의 복사 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056101928/original/Ew9JgoGSGIzWmCmmPP1zurqPc1mj6aqyjQ.png?1760585954)

## 자주 묻는 질문

### 업그레이드 후에 기존 트리거 링크가 작동하지 않게 되나요?

아니요. 이번 업그레이드는 화면만 바뀐 거예요. 링크 ID와 추적 기능은 그대로예요.

### 예전 디자인으로 되돌릴 수 있나요?

이전 화면은 더 이상 지원하지 않아요. 모든 사용자가 HiRise 버전으로 자동 연결돼요.

### 공유 URL로 계정 단위 데이터가 노출되나요?

공유 URL에도 사용자 권한이 그대로 적용돼요. 일부 서브 계정에 접근 권한이 없는 팀원은 권한 오류 화면을 보게 돼요.

### 페이지 이동 버튼은 어디로 옮겨졌나요?

페이지 이동 버튼은 이제 오른쪽 아래에 있어요. 페이지당 행 수를 고르는 기능도 같은 자리에 있어요.

### 링크 하나에 넣을 수 있는 커스텀 값 개수에 제한이 있나요?

기술적인 상한은 없어요. 다만 이메일 프로그램과 호환되도록 URL은 2KB 아래로 유지하세요.

### 특정 링크의 분석 정보는 어디서 보나요?

해당 링크의 세 점 메뉴에서 **분석**을 선택하세요. 원하는 기간을 골라 고유 클릭 수, 연락처, 주요 유입 경로를 볼 수 있어요.

### 트리거 링크를 WhatsApp 메시지에서도 쓸 수 있나요?

네. 복사한 링크를 WhatsApp V2 템플릿 버튼이나 본문 링크에 넣으면 돼요. 이메일이나 SMS처럼 탭 횟수를 추적할 수 있어요.
