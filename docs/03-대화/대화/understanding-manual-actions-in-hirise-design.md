# HiRise 디자인의 수동 작업 페이지 알아보기

하이퍼클래스의 **수동 작업**(Manual Actions) 페이지가 새 HiRise 인터페이스로 바뀌었어요. 통화·SMS 작업을 더 빠르고 깔끔하게 처리할 수 있어요. 필터가 URL에 자동으로 저장되기 때문에, 작업 대기열을 팀원과 공유하기도 쉬워요.

## 수동 작업 페이지(HiRise 디자인)란?

**수동 작업** 페이지는 워크플로우, 캠페인, 파워 다이얼러 대기열에서 만들어진 통화·SMS 작업을 처리하는 곳이에요. HiRise 디자인으로 바뀌면서 레이아웃이 새로워졌어요. 페이지가 더 빨리 열리고, 작업의 핵심 정보를 한눈에 볼 수 있어요. 필터도 기억하기 때문에 링크만 보내면 같은 화면을 함께 볼 수 있어요.

## HiRise 수동 작업 페이지의 장점

- 작업 대기열이 많아도 빠르게 불러와요. 기다리는 시간은 줄고 통화하는 시간은 늘어요.
- 2단 레이아웃에 연락처 패널이 보여서, 작업을 오갈 때 맥락을 바로 파악할 수 있어요.
- URL 기반 필터가 상태, 사용자, 날짜 필터를 유지해요. 링크를 공유해도 같은 화면이 열려요.
- 키보드 이동이 좋아져서, 통화나 SMS를 많이 처리할 때 더 빨라요.
- 하이퍼클래스 전체에 같은 HiRise 스타일이 적용되어 일관된 작업 환경을 쓸 수 있어요.

## 수동 작업 페이지 찾기

### 수동 작업 열기

왼쪽 메뉴에서 **대화 > 수동 작업**을 클릭하세요.

![수동 작업 페이지로 들어가는 왼쪽 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056121295/original/y0i4AK73Q6ZPqyCV6FyzaAIPBSvk8Jyr7w.png?1760605569)

### 시작하기

파란색 **시작하기** 버튼을 클릭하면 작업을 차례로 처리할 수 있어요. 옆 패널에 통화 결과나 SMS 답장을 기록한 다음, 작업을 **완료**, **건너뛰기**, **Re-queue**(다시 대기열에 넣기) 중 하나로 처리하세요.

현재 보고 있는 화면을 공유하려면 브라우저 주소(URL)를 복사하세요. 선택한 필터가 그대로 유지돼요.

![시작하기 버튼과 작업 처리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056121607/original/9EbAYYtJX7gojA9-jHMz9WxJ6U1UsTpCiA.png?1760605750)

### 더 깔끔해진 HiRise 레이아웃

왼쪽에는 접을 수 있는 필터 사이드바가 있고, 오른쪽에는 더 넓은 작업 표가 있어요. 연락처 이름, 전화번호, 작업 유형, 추가한 날짜 같은 핵심 정보가 바로 보여요. 색상, 글꼴, 아이콘은 HiRise 표준을 따라서 플랫폼 전체와 모양이 같아요.

### URL에 저장되는 필터

작업 상태, 담당 사용자, 날짜 같은 필터 설정은 페이지 URL에 자동으로 붙어요. 이 링크를 공유하거나 즐겨찾기에 추가하면, 링크를 여는 사람은 같은 화면을 보게 돼요. 팀이나 캠페인 성과를 확인하는 관리자에게 특히 편해요.

### 작업 필터와 상태 사용하기

필터를 쓰면 중요한 작업부터 처리하고 대기열을 정돈할 수 있어요. 다음 기준으로 필터링할 수 있어요.

- 워크플로우 소스
- 작업 유형(통화 또는 SMS)
- 상태(**Yet to Call**(통화 전), **완료**, **건너뜀**)
- 담당자

### 수동 작업 대기열 공유하기

필터 선택이 URL에 저장되므로, 브라우저 주소창에서 페이지 링크를 복사해 팀원과 필터가 적용된 대기열을 공유할 수 있어요. 채팅이나 이메일로 팀원이나 관리자에게 보내세요. 링크를 열면 같은 필터가 적용된 대기열이 보여요.

## 자주 묻는 질문

### 수동 작업 페이지는 어디에 있나요?
**대화 > 수동 작업**으로 들어가세요. 웹과 모바일 모두에서 쓸 수 있어요.

### 어떤 작업 상태가 있나요?
**Yet to Call**, **완료**, **건너뜀**이 있어요.

### 작업을 다른 사용자에게 한꺼번에 다시 배정할 수 있나요?
네. 체크박스로 작업을 선택하고 **일괄 작업**을 클릭한 다음 **Assign User**(사용자 배정)를 선택하세요.

### URL 기반 필터가 모바일에서도 되나요?
하이퍼클래스 모바일 앱은 앱 내부 링크(딥링크)로 열려요. 지원되지 않는 경우에는 공유한 링크가 모바일 브라우저에서 대기열로 열려요.

### HiRise로 바뀌면 기존 워크플로우에서 만들어진 작업이 달라지나요?
아니요. 작업, 메모, 기록은 그대로예요. 인터페이스만 새로워졌어요.

### 필터를 한 번에 모두 지우려면 어떻게 하나요?
사이드바에서 **필터 초기화**를 클릭하세요. URL에서 쿼리 매개변수를 지우고 페이지를 새로고침해도 돼요.

### 다음 작업을 시작하는 키보드 단축키가 있나요?
작업을 선택한 상태에서 Enter(또는 Return) 키를 누르면 대기열의 다음 작업이 시작돼요.

### 필터가 기기 간에 동기화되나요?
필터는 URL에 저장돼요. 같은 링크를 열면 어느 기기에서든 똑같은 대기열이 보여요.
