# HiRise 디자인의 수동 작업(Manual Actions) 이해하기

하이퍼클래스의 **수동 작업(Manual Actions)** 페이지가 최신 **HiRise 인터페이스**로 새롭게 단장되어, 전화 및 SMS 작업을 더 빠르고 깔끔한 작업 공간에서 관리할 수 있게 되었어요. 보기 설정을 자동으로 저장하는 URL 기반 필터 덕분에, 팀원과 작업 큐를 공유하는 것도 훨씬 간편하고 수월해졌습니다.

# **수동 작업 페이지(HiRise 디자인)란 무엇인가요?**

**수동 작업(Manual Actions)** 페이지는 워크플로우(Workflow), 캠페인, 또는 파워 다이얼러 큐에서 생성된 전화나 SMS 작업을 사용자가 직접 처리하는 공간이에요. HiRise 디자인 개편을 통해 더 빠르게 로딩되고, 주요 작업 정보를 한눈에 확인할 수 있으며, 필터 설정을 기억하는 업데이트된 레이아웃이 적용되었습니다. 이제 링크 하나만 공유하면 협업이 훨씬 간단해져요.

---

## **HiRise 수동 작업 페이지의 주요 장점**

- 대량 작업 큐의 로딩 속도 향상—대기 시간은 줄이고 통화에 집중하는 시간은 늘려보세요.
- 연락처 패널이 보이는 깔끔한 2단 레이아웃으로 빠른 상황 전환이 가능해요.
- URL 기반 필터가 상태, 사용자, 날짜 필터를 유지한 채로 링크를 공유할 수 있어요.
- 개선된 키보드 탐색으로 대량 전화/SMS 작업 세션 속도가 빨라져요.
- 하이퍼클래스 전체에 통일된 HiRise 스타일이 적용되어 일관된 작업 환경을 제공해요.

---

## 수동 작업 페이지 찾는 방법

### **수동 작업 페이지 접근하기**

왼쪽 네비게이션 메뉴에서 **대화(Conversations) → 수동 작업(Manual Actions)**을 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056121295/original/y0i4AK73Q6ZPqyCV6FyzaAIPBSvk8Jyr7w.png?1760605569)

### **시작하기(Let's Start)**

**시작하기(Let's Start)**(파란색 버튼)를 클릭해서 작업을 시작하세요. 사이드 패널에서 통화 결과나 SMS 답변을 기록한 다음, 작업을 **완료(Complete)**, **건너뛰기(Skip)**, 또는 **다시 대기열에 넣기(Re-queue)**로 표시하면 됩니다.

현재 보기를 공유하려면 브라우저 주소창의 URL을 그대로 복사하면 돼요—선택한 필터 값이 그대로 유지됩니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056121607/original/9EbAYYtJX7gojA9-jHMz9WxJ6U1UsTpCiA.png?1760605750)

### **더 깔끔해진 HiRise 레이아웃**

이제 왼쪽에 접고 펼칠 수 있는 필터 사이드바가 생기고, 오른쪽에는 더 넓은 작업 테이블이 배치되어 **연락처 이름**, **전화번호**, **작업 유형**, **추가된 날짜** 같은 중요한 정보를 바로 확인할 수 있어요. 색상, 글꼴, 아이콘 모두 HiRise 표준을 따라, 플랫폼 전반에서 일관된 디자인을 경험할 수 있습니다.

### **지속되는 URL 필터**

**작업 상태**, **담당 사용자**, **날짜** 같은 필터 설정은 자동으로 페이지 URL에 추가돼요. 이 링크를 공유하거나 북마크하면, 링크를 여는 사람 누구나 똑같은 화면을 보게 되므로 팀이나 캠페인 성과를 추적하는 관리자에게 특히 유용합니다.

### **작업 필터 및 상태 활용하기**

필터를 활용하면 가장 중요한 작업을 우선순위에 두고 큐를 정리된 상태로 유지할 수 있어요. **워크플로우 출처**, **작업 유형**(전화 또는 SMS), **상태**(통화 전, 완료, 건너뜀), 또는 **담당자**별로 필터링할 수 있습니다.

### **수동 작업 큐 공유하기**

필터 선택값은 URL에 저장되므로, 브라우저 주소창의 페이지 링크만 복사하면 필터링된 큐를 팀원과 손쉽게 공유할 수 있어요. 채팅이나 이메일로 동료나 상급자에게 전달해보세요. 링크를 여는 순간 동일하게 필터링된 큐를 확인할 수 있습니다.

## **자주 묻는 질문**

**Q: 수동 작업 페이지는 어디에 있나요?**

**대화(Conversations) → 수동 작업(Manual Actions)** 메뉴로 이동하세요. 웹과 모바일 모두에서 이용할 수 있어요.

**Q: 어떤 작업 상태를 사용할 수 있나요?**

**통화 전(Yet to Call)**, **완료(Completed)**, **건너뜀(Skipped)** 상태가 있어요.

**Q: 작업을 다른 사용자에게 일괄 재배정할 수 있나요?**

네, 가능해요—체크박스로 작업을 선택한 뒤 **일괄 작업(Bulk Actions)**을 클릭하고 **사용자 배정(Assign User)**을 선택하세요.

**Q: URL 기반 필터가 모바일에서도 작동하나요?**

모바일 앱은 내부 딥링크를 여는 방식이에요. 지원되지 않는 경우, 공유된 링크는 모바일 브라우저에서 큐를 엽니다.

**Q: HiRise 업데이트로 기존 워크플로우에서 생성된 작업이 변경되나요?**

아니요—작업, 메모, 이력은 그대로 유지되며, 인터페이스만 업그레이드된 거예요.

**Q: 모든 필터를 빠르게 초기화하려면 어떻게 하나요?**

사이드바에서 **필터 초기화(Reset Filters)**를 클릭하세요(또는 URL에서 쿼리 파라미터를 제거하고 새로고침하세요).

**Q: 다음 작업을 시작하는 키보드 단축키가 있나요?**

작업이 선택된 상태에서 **Enter**(또는 **Return**) 키를 누르면 큐에서 다음 작업이 시작돼요.

**Q: 필터가 기기 간에 동기화되나요?**

필터는 URL에 저장되므로, 동일한 링크를 열기만 하면 어떤 기기에서든 동일한 큐를 확인할 수 있어요.
