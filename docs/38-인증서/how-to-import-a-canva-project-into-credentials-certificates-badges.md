# Canva 디자인을 자격 증명(수료증·배지)에 가져오기

Canva에서 만든 수료증이나 배지 디자인을 **자격 증명**(Credentials) 편집 화면으로 바로 가져올 수 있어요. 이 문서에서는 Canva 계정을 연결하고, 디자인을 수료증·배지 캔버스에 넣는 방법을 안내해요.

## 1단계: 자격 증명 편집 화면 열기

1. **멤버십 > 자격 증명**으로 이동하세요.
2. **만들기**를 클릭한 다음, 디자인할 종류에 맞게 **수료증** 또는 **배지**를 선택하세요.

빈 캔버스가 있는 편집 화면이 열려요.

## 2단계: 미디어 라이브러리 열기

1. 편집 화면 왼쪽 사이드바에서 **이미지**를 클릭하세요.
2. **Import from Media Library**(미디어 라이브러리에서 가져오기)를 클릭하세요.

**미디어 저장소** 창이 열리고, 현재 미디어 라이브러리에 있는 파일이 보여요.

## 3단계: Canva 계정 연결하기

1. **미디어 저장소** 창 오른쪽 위에서 **Canva 연결**을 클릭하세요.
2. 화면의 안내에 따라 Canva와 하이퍼클래스 계정의 연결을 승인하세요.

연결은 한 번만 하면 돼요. 이후에도 Canva 계정이 계속 연결되어 있어서 다시 가져올 때 이 과정을 반복하지 않아도 돼요.

## 4단계: Canva 프로젝트 찾아보기

1. 연결이 끝나면 왼쪽의 소스 드롭다운을 여세요. 기본값은 **내 미디어**예요.
2. 목록에서 **Canva**를 선택하세요.

**미디어 저장소** 창에 Canva 프로젝트가 모두 표시돼요.

## 5단계: 프로젝트를 미디어 라이브러리로 가져오기

1. 사용할 Canva 프로젝트를 찾으세요.
2. 프로젝트 썸네일의 점 세 개 메뉴(⋮)를 클릭하세요.
3. **미디어 라이브러리로 가져오기**를 선택하세요.

프로젝트가 미디어 라이브러리에 복사되어, 편집 화면에서 쓸 수 있게 돼요.

## 6단계: 수료증 또는 배지에 디자인 넣기

1. 가져오기가 끝나면 미디어 라이브러리에서 해당 프로젝트를 선택하세요.
2. **미디어 삽입**을 클릭하세요.

Canva 디자인이 수료증 또는 배지 캔버스에 추가돼요. 크기와 위치를 바꾸거나, 그 위에 다른 요소를 더할 수 있어요.

{% hint style="info" %}
- Canva에서 원본 디자인을 수정해도 자동으로 반영되지 않아요. 변경 내용을 가져오려면 다시 가져오세요.
- Canva에서 가져온 디자인은 이미지로 들어와요. 그래서 디자인 안의 텍스트는 자격 증명 편집 화면에서 수정할 수 없어요. 텍스트를 바꾸려면 가져오기 전에 Canva에서 수정하세요.
{% endhint %}
