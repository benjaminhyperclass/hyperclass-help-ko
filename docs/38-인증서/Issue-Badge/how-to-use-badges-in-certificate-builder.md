# Certificate Builder(인증서 빌더)에서 배지 사용하기

**Certificate Builder**의 배지 기능으로 수강생의 성취를 눈에 보이게 인정하고 동기를 높일 수 있어요. 코스 수료, 역량 달성 같은 성과를 배지로 만들어 발송하는 방법을 안내해요.

## 배지란?

배지는 역량 달성, 코스 수료, 직접 정한 성과 등에 대해 수여하는 디지털 아이콘이에요. 직접 디자인할 수 있고 쉽게 공유할 수 있어요. 수강생의 진행 상황을 브랜드 안에서 인정하고 축하하는 동기 부여 수단으로 쓰여요. 코스와 커뮤니티에서 참여도를 높이고 전문성을 보여 주는 데도 도움이 돼요.

## 배지의 주요 장점

배지는 만드는 사람과 받는 수강생 모두에게 도움이 돼요.

- 동기 부여: 수강생이 강의를 끝까지 듣고 목표를 달성하도록 북돋워요.
- 참여도 향상: 진행 상황이 눈에 보이고 보상이 되므로 참여가 늘어요.
- 브랜드 맞춤: 배지의 모양을 브랜드에 맞게 자유롭게 바꿀 수 있어요.
- 전문성 인정: 코스의 신뢰도와 전문성을 높여요.
- 간편한 공유: 배지를 내려받거나 소셜 미디어에 공유할 수 있어서 브랜드 홍보 효과도 있어요.
- 유연한 디자인: 템플릿과 요소 라이브러리로 빠르고 창의적으로 배지를 만들 수 있어요.
- 대량 발급: 다양한 성과에 대해 많은 수의 배지를 발급할 수 있어요.

## 배지 만들고 꾸미기

배지를 만들어 두면 수강생의 성취를 보기 좋고 브랜드에 맞는 방식으로 인정할 수 있어요. 아래 순서대로 배지를 만들고 발급하세요.

### 1단계: Certificate Builder 열기

1. 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **멤버십**을 클릭하세요.
3. **자격 증명** 탭을 클릭하세요.
4. 오른쪽 위에서 **+ 만들기** 버튼을 클릭하세요.
5. 드롭다운에서 **배지 만들기**를 선택하세요.

### 2단계: 템플릿 선택 또는 처음부터 시작

다음 중 하나를 선택하는 화면이 나와요.

- **처음부터 시작**: 빈 캔버스에서 시작해요.
- **템플릿 사용**: 기본 제공 라이브러리의 템플릿을 사용해요.
- 템플릿을 선택한 다음 **만들기**를 클릭하세요.

![템플릿 선택 화면](https://jumpshare.com/v/Uw4tazMmWiu3lg9Ur5r0+/GIF+Recording+2025-07-09+at+12.01.26+AM.gif)

### 3단계: 배지 디자인 커스터마이징

#### 편집 환경 개선 사항

- 요소를 옮기거나 회전하는 동안 편집 툴바가 자동으로 숨겨져서 캔버스를 가리지 않아요.
- 아주 작거나 빽빽하게 모여 있는 요소는 이동 아이콘을 사용하면 위치를 더 쉽게 바꿀 수 있어요.
- 요소 위에 마우스를 올리면 선택하기 전에 강조 표시돼요. 선택한 요소의 크기를 바꾸려면 가장자리나 모서리를 원하는 크기만큼 끌어 주세요.
- 선과 도형의 크기 조절이 더 안정적이고, 캔버스에 표시되는 모서리 표시가 줄어서 화면이 더 깔끔해요.

#### 텍스트 편집

1. 왼쪽 패널에서 **문자** 탭을 클릭하세요.
2. **+ Add Text Box**(텍스트 상자 추가)를 클릭해서 디자인에 텍스트를 넣으세요.
3. **제목**, **Subheading**(부제목), **Normal Text**(일반 텍스트) 중에서 고르세요.
4. 캔버스에서 바로 텍스트를 편집하세요.

![텍스트 상자 추가](https://jumpshare.com/v/xgQosD5WyzUuehmo9HhZ+/GIF+Recording+2025-07-09+at+12.08.56+AM.gif)

#### 텍스트 스타일 지정

텍스트 요소를 선택하면 다음을 바꿀 수 있어요.

- 글꼴 패밀리, 크기, 두께
- **텍스트 색상 변경**
- **굵게**, **Italic**(기울임꼴) 적용
- 필요하면 줄 간격 조정
- 정렬: 왼쪽, 가운데, 오른쪽

![텍스트 스타일 지정](https://jumpshare.com/v/llestcU4kbKydrk0b8Ht+/GIF+Recording+2025-07-09+at+12.20.17+AM.gif)

#### 커스텀 값 추가

텍스트 상자를 클릭하거나 새로 추가한 뒤 **커스텀 값 추가**를 사용하면 다음과 같은 값이 자동으로 채워져요.

- 연락처의 **이름**(Full Name), **이름**(First Name), **성**
- **이메일**, **전화번호**, **회사명**
- **주소**, **도시**, **주/도**, **국가** 등 목록에서 고를 수 있는 여러 항목

{% hint style="info" %}
연락처 수준의 커스텀 값만 채워져요(값이 있는 경우). 일부 커스텀 값은 비어 있을 수 있어요. 보내기 전에 템플릿을 다시 확인하세요.
{% endhint %}

![커스텀 값 추가](https://jumpshare.com/v/CcRz23kJxjhkzKsf0OhA+/GIF+Recording+2025-07-09+at+12.25.15+AM.gif)

#### 디자인 요소 추가 및 커스터마이징

- **요소** 탭을 클릭하면 다음을 추가할 수 있어요.
  - **선**
  - **도형**
  - **리본**
  - **아이콘**
  - **바탕 도형**

- 도형이나 요소를 선택하면 다음을 바꿀 수 있어요.
  - **채우기 색상**
  - **선 색상**
  - **Change Border Type and Width**(테두리 유형 및 두께 변경)
  - **모서리 둥글기**
  - **Element Opacity**(요소 불투명도)

![디자인 요소 커스터마이징](https://jumpshare.com/v/ZdrRhghBnAqG2VG0dow4+/GIF+Recording+2025-07-09+at+12.37.33+AM.gif)

#### 이미지 넣기

- **Upload Media from Library**(라이브러리에서 미디어 업로드)를 클릭하면 저장해 둔 자산을 쓸 수 있어요.
- 외부 이미지를 가져오려면 **이미지 URL**을 붙여 넣으세요.

#### 키보드 단축키

익숙한 단축키를 쓰면 메뉴를 거치지 않고 디자인에 집중할 수 있어요.
`Ctrl + X`: 선택한 요소 잘라내기`Ctrl + C`: 선택한 요소 복사`Ctrl + V`: 요소 붙여넣기`Ctrl/Cmd + B`: 선택한 텍스트 굵게`Ctrl/Cmd + I`: 선택한 텍스트 기울임꼴`Ctrl/Cmd + U`: 선택한 텍스트 밑줄

#### 방향키로 이동

방향키로 요소를 조금씩 움직여서 위치를 정밀하게 맞출 수 있어요.
`← ↑ → ↓`: 선택한 요소를 1px 이동`Shift + 방향키`: 10px씩 이동해서 더 빠르게 위치 변경

#### 레이어 조정

겹쳐 있는 그래픽과 텍스트를 쉽게 정리해서 여러 겹으로 된 디자인을 만들 수 있어요.

- **앞으로 가져오기**: 요소를 한 단계 앞으로 이동해요.
- **Send to Back**(뒤로 보내기): 요소를 한 단계 뒤로 이동해요.

![레이어 조정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050815864/original/8aqKKcn3XnX2G66Nu7HdvmMbSK9XY5E7Xw.png?1754068482)

### 4단계: 배지 미리보기 및 저장

1. **미리보기**(눈 모양 아이콘)를 클릭해서 배지가 어떻게 보이는지 확인하세요.
2. **저장**을 클릭해서 배지를 저장하세요.

![배지 미리보기 화면](https://jumpshare.com/v/PbLhdvsBecGL3gKrwoCH+/Screen+Shot+2025-07-09+at+12.56.41+AM.png)

{% hint style="info" %}
이제 배지 템플릿의 테두리가 최종 미리보기와 더 정확하게 일치해요. 배지를 저장하기 전에 **미리보기**로 최종 모습을 확인하세요.
{% endhint %}

### 5단계: 이메일로 배지 보내기

1. **보내기** 버튼을 클릭하세요.
2. **강사 이름**을 입력하세요.
3. 다음 중 하나로 받는 사람을 고르세요.
   - 이전에 저장해 둔 **Recipients**(수신자)에서 선택
   - **새로 추가**를 클릭해서 새 연락처 입력
4. 이메일 템플릿을 정하세요.
   - **기본 템플릿**을 그대로 쓰거나
   - 눈 모양 아이콘 옆의 **편집** 버튼을 클릭해서 저장해 둔 이메일 템플릿을 선택하세요.
5. 눈 모양 아이콘으로 이메일을 **미리보기**하세요.
6. 필요하면 이메일 제목을 원하는 대로 수정하세요.
7. **확인**을 클릭한 다음 **이메일 보내기**를 클릭하면 배지가 발송돼요.

![이메일로 배지 보내기](https://jumpshare.com/v/D6zv0KU5ZgvvZGp1XmH2+/GIF+Recording+2025-07-09+at+1.21.26+AM.gif)

## 배지 내려받기와 공유

받는 사람은 받은 이메일에서 바로 배지를 내려받고 공유할 수 있어요.

- 고해상도 PNG 형식으로 내보낼 수 있어요.
- 인증서 링크를 공유할 수 있어요.
- 소셜 미디어 플랫폼에 바로 공유할 수 있어요.
- 수강생이 성취를 널리 알리면 브랜드 노출도 함께 늘어요.

![배지 내려받기와 공유 화면](https://jumpshare.com/v/CqETTrTBiFtfDJKmP1h8+/Screen+Shot+2025-07-09+at+1.16.01+AM.png)

## 자동 저장

배지의 **자동 저장** 기능은 작업 중인 배지를 실시간으로 계속 저장해 줘요. 디자인 진행 상황이 직접 저장하지 않아도 60초마다 저장되므로, 인터넷 연결이 끊겨도 안심하고 작업할 수 있어요.

저장하지 않은 변경 사항이 있으면 파란 점이 나타나요. **저장**을 클릭해서 직접 저장하거나, 파란 점이 사라질 때까지 기다리면 자동 저장이 된 것을 알 수 있어요.

![자동 저장을 알리는 파란 점](https://jumpshare.com/v/wJVzB5gvxXUHTKrWM32D+/Screen+Shot+2025-07-09+at+1.29.27+AM.png)

## 자주 묻는 질문

### 배지 디자인을 처음부터 직접 만들 수 있나요?

네, 빈 캔버스에서 시작해서 배지의 모든 부분을 직접 꾸밀 수 있어요.

### 배지는 코스 수료에만 쓸 수 있나요?

아니요, 역량 달성, 강의 완료, 직접 정한 기준 등 어떤 성과에도 배지를 발급할 수 있어요.

### 수강생이 배지를 소셜 미디어에 공유할 수 있나요?

네, 배지를 내려받거나 소셜 미디어 플랫폼에 바로 공유할 수 있어요.

### 만들 수 있는 배지 수에 제한이 있나요?

제한이 없어요. 코스와 성과에 필요한 만큼 배지를 만들 수 있어요.

### 배지 디자인에 직접 만든 그래픽이나 아이콘을 쓸 수 있나요?

네, 직접 만든 그래픽을 업로드하거나 기본 제공되는 요소 라이브러리를 쓸 수 있어요.

### 배지가 인증서에도 표시되나요?

배지는 **Certificate Builder** 안에서 관리하며, 인증서와 연결하거나 따로 발급할 수 있어요.

### 코스 수료 여부에 따라 배지를 자동으로 줄 수 있나요?

네, 강의 완료나 퀴즈 결과 같은 기준에 따라 자동화 워크플로우로 배지를 수여하도록 설정할 수 있어요.

### 이미 발급한 배지를 수정하려면 어떻게 하나요?

배지 디자인은 언제든 편집할 수 있어요. 다만 이미 발급한 배지는 다시 발급하지 않는 한 원래 모습 그대로 유지돼요.

### 방향키로 텍스트 상자와 이미지를 모두 움직일 수 있나요?

방향키로 조금씩 옮기는 기능은 텍스트, 이미지, 도형, 아이콘을 포함한 모든 요소에 적용돼요.
