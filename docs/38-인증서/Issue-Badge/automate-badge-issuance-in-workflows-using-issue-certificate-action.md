# 워크플로우에서 배지 자동 발급하기 (Issue Certificate 액션 사용)

워크플로우의 **Issue Certificate**(수료증 발급) 액션으로 고객에게 배지를 자동으로 보내는 방법을 안내해요.

## 개요

**배지**는 학습 진행이나 참여 같은 작은 성과를 눈에 보이게 인정하는 가벼운 방법이에요. 전용 **Issue Badge**(배지 발급) 액션은 현재 준비 중이에요. 하지만 지금도 기존 **Issue Certificate** 액션으로 배지를 바로 발급할 수 있어요.

배지는 수료증과 같은 액션으로 발급해요.

---

## 작동 방식

워크플로우 트리거 중 원하는 것을 **Issue Certificate** 액션과 함께 쓰면 고객에게 배지를 자동으로 보낼 수 있어요.

{% hint style="info" %}
**Issue Certificate** 액션을 설정할 때 수료증 템플릿 대신 배지 템플릿을 선택하세요.
{% endhint %}

---

## 자주 쓰는 트리거와 활용 예시

| 워크플로우 트리거 | 배지 활용 예시 |
| --- | --- |
| **Lesson Completed**(강의 완료) | "강의 1 완료" 배지 |
| **Category Completed**(카테고리 완료) | "모듈 마스터" 배지 |
| **Product Completed**(상품 완료) | "인증 프로" 배지 |
| **Quiz Submitted**(퀴즈 제출) | "퀴즈 에이스" 배지 |
| **Survey Submitted**(설문 제출) | "우수 응답자" 배지 |
| **Form Submitted**(폼 제출) | "빠른 실행가" 배지 |
| **Task Completed**(작업 완료) | "마일스톤 달성" 배지 |

이 트리거는 워크플로우 트리거 메뉴의 **Courses**(코스), **Contact**(연락처), **Form Activities**(폼 활동) 아래에서 찾을 수 있어요.

---

## 설정 방법

1. **자동화 > 워크플로우**로 이동하세요.
2. **Create from Scratch**(처음부터 만들기)를 눌러 새 워크플로우를 만들거나, 기존 워크플로우를 여세요.
3. 위 목록에서 원하는 트리거를 추가하세요.
4. 액션을 추가하고 **Issue Certificate**를 선택하세요.
5. 수료증 템플릿 대신 배지 템플릿을 선택하세요.
6. **Save**(저장)한 뒤 **Publish**(게시)하세요.

{% hint style="info" %}
배지는 시각적이고 가벼워서 작은 성과를 인정할 때 알맞아요. 고객에게는 다운로드할 수 있는 이미지로 전송돼요.
{% endhint %}

---

## 출시 예정

더 쉽게 쓸 수 있도록 전용 **Issue Badge** 액션을 준비하고 있어요. 그 전까지는 **Issue Certificate** 액션으로 배지와 수료증을 모두 발급할 수 있어요.

## 배지 빌더로 이동하기

1. **멤버십**으로 이동하세요.
2. **자격 증명** 탭을 선택하세요.
3. 오른쪽 위의 **만들기**를 클릭하세요.
4. 드롭다운에서 **배지 만들기**를 선택하세요.
