# 수동 수료증 이메일 템플릿 선택하기

수료증을 직접 보낼 때 이메일 템플릿을 고르고 이메일 제목을 바꾸는 방법을 안내해요. 받는 사람에게 맞춰 수료증 메일을 더 세심하게 보내고 싶을 때 쓰세요.

## 수동 수료증 이메일 템플릿 기능이란?

수료증을 직접 보낼 때 이미 만들어 둔 이메일 템플릿 중에서 하나를 고를 수 있는 기능이에요. 보내기 전에 이메일 제목도 바꿀 수 있어요. 행사, 받는 사람, 브랜딩 기준에 맞는 메일을 보낼 수 있어요.

템플릿을 고르지 않으면 **클라이언트 포탈**의 이메일 설정에 지정된 템플릿이 자동으로 쓰여요.

## 수동 수료증 이메일 템플릿의 장점

수동 수료증 메일에 원하는 템플릿을 고르면 내용이 더 분명해지고 브랜딩도 일관되게 유지돼요.

- 원하는 템플릿으로 수료증 메일을 맞춤 구성할 수 있어요.
- 내용이나 행사에 맞게 이메일 제목을 바꿀 수 있어요.
- 모든 메일에 일관된 브랜딩을 유지할 수 있어요.
- 템플릿을 다시 쓰면 직접 고치는 시간을 줄일 수 있어요.
- 템플릿을 고르지 않아도 기본 템플릿이 적용되어 실수를 막아 줘요.

## 이메일 템플릿을 골라 수동으로 수료증 보내기

미리 만들어 둔 이메일 템플릿을 고르면 메일 내용이 알맞고 깔끔하게 정리된 상태로 나가요. 아래 순서대로 따라 하세요.

1. 하이퍼클래스 계정에서 **수료증**으로 이동하세요.
2. 수료증을 보낼 연락처를 선택하세요.
3. **Send Certificate**(수료증 보내기)를 클릭하세요.
4. 이메일 창에서 **이메일 템플릿** 드롭다운을 찾으세요.
5. 목록에서 원하는 이메일 템플릿을 선택하세요.
6. 필요하면 **이메일 제목** 필드를 수정하세요.
7. 미리보기를 확인한 뒤 **보내기**를 클릭하세요.

## 템플릿을 고르지 않았을 때

템플릿을 직접 고르지 않아도 메일이 정상적으로 나가도록, 기본 동작을 알아 두면 좋아요.

수료증을 수동으로 보낼 때 템플릿을 고르지 않으면 다음과 같이 처리돼요.

- 기본 이메일 템플릿이 자동으로 적용돼요.
- 이 기본 템플릿은 **클라이언트 포털 설정 > 이메일 설정**에서 지정해요.

## 자주 묻는 질문

### 수료증 이메일 전용 템플릿을 직접 만들 수 있나요?
네. **이메일 템플릿** 설정으로 이동해 새 템플릿을 만드세요. 만든 템플릿은 수동으로 보낼 때 선택할 수 있어요.

### 템플릿을 선택하면 이메일 제목도 자동으로 바뀌나요?
아니요. 이메일 제목은 직접 수정할 수 있고, 바꾸고 싶다면 직접 입력해야 해요.

### 수료증을 보내기 전에 템플릿을 미리 볼 수 있나요?
네. 템플릿을 선택하면 보내기 창 안에 미리보기가 나타나요.

### 템플릿을 고르지 않거나 이메일 제목을 수정하지 않고 보내면 어떻게 되나요?
**클라이언트 포털 설정**에 지정된 기본 템플릿과 이메일 제목이 쓰여요.

### 수료증 종류별로 기본 템플릿을 다르게 지정할 수 있나요?
아직은 할 수 없어요. **클라이언트 포털 설정**에서는 계정당 기본 템플릿을 하나만 지정할 수 있어요.
