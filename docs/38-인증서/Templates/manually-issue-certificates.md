# 수료증 수동 발급하기

하이퍼클래스에서 **수료증**을 연락처에게 직접 보내는 방법을 안내해요. 테스트용으로 수료증을 발급하거나, 하이퍼클래스에서 운영하지 않는 코스의 수료증을 발급할 때 쓸 수 있어요.

### 커뮤니티의 다른 튜토리얼

새로 추가된 **오프라인 수료증** 기능을 쓰면 원하는 연락처에게 수료증을 직접 보낼 수 있어요. 오프라인 교육을 진행하거나 외부 코스의 수료증을 발급할 때도 편리하게 수강생의 성과를 인정해 줄 수 있어요.

## 수료증 수동·오프라인 발급하기

### 1단계: 수료증 화면으로 이동하기

1. 하이퍼클래스 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **멤버십**을 선택하세요.
3. **수료증**을 클릭하면 수료증을 관리하는 화면이 열려요.

### 2단계: 수료증 템플릿 고르거나 만들기

1. 기존 수료증 템플릿을 선택하거나, 처음부터 새로 만드세요.

### 3단계: 수료증 보내기

1. 수료증 템플릿을 고르거나 만들었다면 **보내기** 버튼을 클릭하세요.
2. 강사 이름, 받는 사람의 이메일 같은 정보를 입력하세요. 받는 사람이 아직 연락처에 없으면 **새로 추가**를 선택해 추가할 수 있어요.
3. 필요한 정보를 모두 입력한 뒤 **보내기**를 클릭하세요.

![수료증 보내기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155023522926/original/OaKaCNbB9BdHuZilrzCrUtlzS7SZ06LlRA.png?1711458643)

### 4단계: 수료증 전달 확인하기

- 수강생에게 이메일이 발송돼요. 이메일에는 PDF 형식의 수료증을 내려받을 수 있는 링크가 들어 있어요.

### 5단계: 발급한 수료증 확인하기

1. 지금까지 보낸 수료증 기록을 보려면 **멤버십 > 수료증**으로 돌아가세요.
2. **발급된 수료증**을 선택하세요.

이 화면에서 발급한 수료증 전체 목록을 확인하고 관리할 수 있어요.
