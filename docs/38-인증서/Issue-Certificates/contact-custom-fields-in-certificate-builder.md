# 수료증 빌더에서 연락처 커스텀 필드 사용하기

수료증 빌더에서 연락처 단위의 **커스텀 필드** 값을 쓸 수 있어요. 이 문서에서는 이 기능이 무엇인지 간단히 소개해요.

## 이 기능으로 할 수 있는 일

- 수료증 빌더에서 연락처 수준의 **커스텀 필드** 값을 사용할 수 있어요.
- 기본으로 제공되는 커스텀 값 외에, 연락처에 따로 저장해 둔 비표준 데이터도 수료증에 넣을 수 있어요.
