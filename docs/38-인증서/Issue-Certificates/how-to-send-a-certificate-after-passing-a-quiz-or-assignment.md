# 퀴즈·과제를 통과하면 수료증 자동 발급하기

코스에서 학습자가 퀴즈나 과제를 완료(통과)하면 수료증을 자동으로 발급할 수 있어요. **워크플로우 빌더**에서 설정하는 방법을 안내해 드려요.

## 개요

코스의 특정 퀴즈나 과제를 완료한 학습자에게 수료증을 발급하는 자동화를 만들어요. **Lesson Completed**(강의 완료) 트리거에 필터를 설정하고, **Issue Certificate**(수료증 발급) 액션을 추가해요.

## 설정 순서

### 1. 트리거 추가하기

1. 워크플로우에서 **Add Trigger**(트리거 추가)를 클릭하세요.
2. **Lesson Completed**를 선택하세요.

### 2. 필터 설정하기

의도한 퀴즈나 과제에만 수료증이 발급되도록 아래 필터를 설정하세요.

- **Product**(상품) → *수료증을 발급할 코스를 선택하세요.*
- **Category**(카테고리) → *퀴즈가 들어 있는 모듈 또는 섹션을 선택하세요.*
- **Lesson**(강의) → *대상 퀴즈나 과제를 선택하세요.*

### 3. 수료증 액션 추가하기

1. 트리거 아래의 **+** 아이콘을 클릭하세요.
2. 액션 목록에서 **Issue Certificate**를 선택하세요.
3. 사용할 수료증 템플릿을 선택하세요.

설정이 끝났어요. 이제 선택한 퀴즈나 과제를 완료하면 수료증이 자동으로 발송돼요.
