# 수료증: 스냅샷 및 복제 지원

스냅샷에 수료증 템플릿을 포함해 다른 계정으로 옮기거나, 수료증 템플릿을 다른 서브 계정으로 복제하는 방법을 안내해요.

## 스냅샷의 수료증 기능이란?

스냅샷에 수료증 템플릿을 넣을 수 있는 기능이에요. 스냅샷을 불러오면 수료증 템플릿과 연결된 모든 미디어 파일이 함께 이동해요. 스냅샷에 포함된 수료증에는 IP 보호도 적용되어 보안이 한층 강화돼요.

## 스냅샷에 수료증을 넣을 때의 장점

- 간편한 이전: 스냅샷으로 계정 간에 수료증 템플릿을 쉽게 옮길 수 있어요.
- 미디어 파일 자동 이전: 템플릿에 연결된 모든 미디어 파일이 함께 이전돼요.
- 시간 절약: 데이터를 옮길 때 수료증을 처음부터 다시 만들지 않아도 돼요.
- 일관된 설정: 이전하는 동안 수료증의 모든 설정이 그대로 유지돼요.
- 보안 강화: 스냅샷에 포함된 수료증에 IP 보호가 적용돼요.

## 스냅샷에 수료증 넣는 방법

다음 순서로 수료증 템플릿을 스냅샷에 넣어요.

1. **설정 > 스냅샷**으로 이동해요.
2. 새 스냅샷을 만들어요.

   ![스냅샷 화면에서 스냅샷 만들기를 누르는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043454805/original/7DDtIJQHQKW5sm9OJ7ymMwapDpMLUWCzZQ.png?1742243674)

   - **스냅샷 만들기**를 클릭해요.
   - 스냅샷의 이름과 설명을 입력해요.
3. 수료증 템플릿을 추가해요.

   ![스냅샷에 포함할 수료증 템플릿을 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043454823/original/L79flSXtaZ68oiffLVMacdG-dAiF53Tu6g.png?1742243739)

   - 포함할 수료증 템플릿을 선택해요.
   - 필요한 미디어 파일이 자동으로 포함되는지 확인해요.
4. 스냅샷을 저장하고 내보내요.

   - 설정을 마쳤다면 스냅샷을 저장해요.
   - 필요에 따라 다른 서브 계정으로 내보내요.
5. 새 서브 계정에서 스냅샷을 불러와요.

   - 옮기려는 계정 또는 서브 계정으로 스냅샷을 가져와요.
   - 모든 수료증과 미디어 파일이 잘 이전되었는지 확인해요.

## 수료증 템플릿 복제하기

### 수료증 템플릿 복제란?

수료증 템플릿을 한 서브 계정에서 다른 서브 계정으로 복사하는 기능이에요. 한 번에 최대 3개의 서브 계정까지 복제할 수 있어서 유연하고 효율적으로 쓸 수 있어요.

## 수료증 템플릿 복제의 장점

- 여러 서브 계정 지원: 한 번에 최대 3개의 서브 계정으로 템플릿을 복제할 수 있어요.
- 미디어 파일 유지: 템플릿에 연결된 모든 미디어 파일이 자동으로 함께 이전돼요.
- 설정 유지: 수료증의 기존 설정과 구성이 그대로 유지돼요.
- 버전 기록 유지: 복제한 뒤에도 템플릿의 전체 버전 기록이 그대로 남아 있어요.

## 수료증 템플릿 복제하는 방법

1. 수료증 템플릿으로 이동해요.

   - 대시보드에서 **수료증** 섹션으로 이동해요.
2. 복제할 수료증 템플릿을 선택해요.

   - 복제하려는 템플릿을 골라요.
3. 복제를 시작해요.

   - **템플릿 복제**를 클릭해요.
   - 복제할 대상 서브 계정을 최대 3개까지 선택해요.
4. 확인하고 복제해요.

   - 복제될 미디어 파일과 설정을 확인해요.
   - **Clone**(복제)을 클릭해 마무리해요.
5. 복제된 템플릿을 확인해요.

   - 대상 서브 계정에서 템플릿이 잘 복제되었는지 확인해요.

## 자주 묻는 질문

### 스냅샷에 수료증 템플릿이 여러 개 있으면 어떻게 되나요?

스냅샷을 불러올 때 모든 수료증 템플릿과 미디어 파일이 함께 이전돼요.

### 스냅샷으로 수료증 템플릿을 옮길 때 미디어 파일을 빼고 옮길 수 있나요?

아니요. 빠짐없이 옮기기 위해 연결된 모든 미디어 파일이 자동으로 포함돼요.

### 수료증 템플릿을 한 번에 몇 개까지 복제할 수 있나요?

한 번에 최대 3개의 서브 계정까지 복제할 수 있어요. 더 많은 서브 계정에 복제하려면 같은 과정을 반복하세요.

### 수료증을 복제하거나 이전해도 IP 보호 설정이 유지되나요?

네. 스냅샷에 포함된 수료증과 복제한 템플릿 모두 IP 보호가 그대로 유지돼요.
