# 코스 수료 시 수료증 발급하기

코스를 수료한 학습자에게 맞춤 수료증을 자동으로 보내는 기능이에요. 학습자는 이메일로 수료증을 확인하고 내려받을 수 있는 링크를 받아요.

## 수료증 발급 설정하기

코스를 수료하면 수료증이 발급되도록 설정해 보세요.

1. 수료증을 발급할 코스 상품을 선택하세요. (**멤버십 > 코스 > 상품**)
2. **수료증** 탭으로 이동하세요.
3. **Attach**(연결)를 클릭하세요.
4. **템플릿을 선택하세요**에서 연결할 템플릿을 고르세요.
5. **카테고리**는 기본으로 **Course Completion**(코스 수료)이 선택돼요.
6. **저장**을 클릭하세요.

저장하고 나면 이 코스를 수료하는 모든 새 학습자에게 수료할 때마다 수료증이 이메일로 자동 발송돼요.

발급된 수료증의 상세 내용은 **수료증** 탭에서 확인할 수 있어요. (**멤버십 > 수료증**)

코스 수료용 수료증은 한 번에 하나만 연결할 수 있어요. 다른 템플릿으로 바꾸려면 **편집**에서 새 템플릿을 선택하거나, 연결된 템플릿을 **삭제**한 뒤 새 템플릿을 추가하세요.
{% endhint %}

## 자주 묻는 질문

### 특정 코스의 수료증을 비활성 상태로 바꾸면 어떻게 되나요?
코스를 수료해도 학습자에게 수료증이 자동으로 발송되지 않아요. **Active**(활성)로 다시 바꾸면 발송돼요.

### 특정 학습자에게 코스 수료 수료증이 발송되지 않게 하려면 어떻게 하나요?
**사이트 > 멤버십 > 수료증 > 발급된 수료증**으로 이동하세요. 해당 학습자 옆의 점 세 개 아이콘을 클릭한 다음 **접근 권한 취소**를 클릭하면 돼요. 접근 권한을 취소하면 그 학습자는 이미 받은 수료증에도 접근할 수 없어요.

### 학습자가 수료증을 공개적으로 공유할 수 있나요?
네, 모든 학습자가 수료증 링크를 복사해서 공유할 수 있어요.
