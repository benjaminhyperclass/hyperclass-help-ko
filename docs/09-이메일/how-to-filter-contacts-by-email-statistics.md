# 이메일 통계로 연락처 필터링하기

**Email Analytics**(이메일 분석)에서 열림, 클릭됨, 반송됨 같은 실제 반응을 기준으로 연락처를 골라낼 수 있어요. 지표를 클릭하면 그 결과에 해당하는 연락처를 바로 확인할 수 있습니다.

{% hint style="warning" %}
연락처 단위의 이메일 통계 필터링은 하이퍼클래스 이메일을 쓰는 서브 계정에서만 쓸 수 있어요. 다른 이메일 제공업체를 쓰는 계정은 지원하지 않습니다.
{% endhint %}

## 이메일 통계로 연락처를 필터링한다는 건?

이메일 통계 필터링은 하이퍼클래스에서 연락처 단위로 이메일 성과를 보는 기능이에요. 서브 계정에서 **열림**, **클릭됨**, **반송됨** 같은 지표로 연락처를 걸러 낼 수 있어요. 그래서 연락처 한 명 한 명의 반응을 보고 바로 조치할 수 있습니다.

캠페인 요약을 일일이 들여다볼 필요 없이, 이메일을 열었거나 클릭했거나 반송됐거나 불만을 제기한 연락처로 바로 갈 수 있어요. 세그먼트를 만들거나 재참여를 유도하거나 목록을 정리할 때 훨씬 빨라집니다.

## 이메일 통계로 연락처를 필터링하면 좋은 점

- 맞춤 참여 유도: 열림·클릭 같은 실제 지표로 세그먼트를 만들어 후속 메시지를 맞추고 전환율을 높일 수 있어요.
- 목록 관리: **반송됨**, **불만 제기됨**, **실패** 연락처를 빠르게 찾아 발신자 평판을 지킬 수 있어요.
- 유연한 기간 설정: 날짜 필터로 특정 캠페인이나 테스트 기간의 성과를 볼 수 있어요.
- 발송 유형별 구분: **대량**, **캠페인**, **워크플로우**로 필터링해서 결과가 어디서 나왔는지 따로 볼 수 있어요.

## 이메일 통계로 연락처 필터링하기

아래 순서대로 따라 하면 필터 결과를 정확하게 얻고, 연락처 단위 반응을 안심하고 분석할 수 있어요.

1. 연락처 단위 이메일 성과를 분석할 서브 계정에 로그인하세요.

2. **설정 > 이메일 서비스 > Email Analytics**(이메일 분석)로 이동하세요.

   ![Email Analytics로 이동하는 화면](https://jumpshare.com/share/bprRykWzXSKjURMczcWU+/GIF+Recording+2025-12-31+at+3.48.16+PM.gif)

3. 페이지 상단의 **Email Metrics**(이메일 지표)를 확인하세요. 아래 지표가 있어요.

   - **Sent**(발송됨)
   - **전달됨**
   - **열림**
   - **클릭됨**
   - **불만 제기됨**
   - **반송됨**
   - **Unsubscribed**(구독 취소)
   - **실패**

   {% hint style="info" %}
   이메일 분석은 하이퍼클래스 이메일의 데이터만 가져와요.
   {% endhint %}

   ![이메일 지표 개요 화면](https://jumpshare.com/share/nHDHMg85jOYSP0K4QDUc+/Screen+Shot+2025-12-31+at+3.49.35+PM.png)

4. **날짜 범위**에서 분석할 기간을 정하세요. 원하는 기간의 지표만 볼 수 있어요.

   ![날짜 범위 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061665817/original/Rzk851hBFRZOzOnatjfGFu63drYiHRCRlw.png?1767176543)

5. **필터**를 클릭하고 **Email Source**(이메일 소스)를 선택한 뒤, 아래 발송 유형 중 하나를 고르세요.

   - **캠페인**: 캠페인에서 발송한 마케팅 이메일
   - **워크플로우**: 워크플로우 단계에서 자동으로 발송된 이메일
   - **대량 요청**: 연락처 목록에 한 번만 보내는 대량 발송

   ![이메일 소스 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061666100/original/o2zxBJeoftfqcYM1eNwgz6SsMwtkX-eliA.png?1767176684)

6. **Email Source Name**(이메일 소스 이름)을 선택하세요. 분석하려는 캠페인, 워크플로우, 대량 발송 중 하나를 고르면 돼요.

   {% hint style="warning" %}
   **소스 이름**은 필수예요. 이 단계를 건너뛰면 이메일 소스 유형을 선택해도 결과가 나오지 않아요.
   {% endhint %}

   ![이메일 소스 이름 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061666434/original/RUKyExutxMBhhxyfWRx1Lc8a7MsueP480w.png?1767176780)

7. 지표 상자(예: **전달됨**)를 클릭하세요. 선택한 소스와 날짜 범위에서 그 지표에 해당하는 연락처 목록이 열려요.

   ![지표 상자를 클릭해 연 연락처 목록](https://jumpshare.com/share/TsMIT4JD3O0Y3A2wy2wA+/Screen+Shot+2025-12-31+at+3.57.42+PM.png)

8. **페이지네이션**에서 페이지당 20개, 50개, 100개 중 하나를 선택하세요. **날짜 범위**를 바꾼 뒤 **새로고침**을 클릭하면 목록을 다시 불러와요. 필터를 바꿀 때마다 **새로고침**을 클릭하세요.

   ![페이지네이션과 새로고침 화면](https://jumpshare.com/share/4qkAMKpXvHhoNlZiKkJG+/Screen+Shot+2025-12-31+at+3.59.04+PM.png)

9. 목록에서 연락처를 클릭하면 연락처 상세 화면이 열려요. 메모를 확인하거나 후속 조치를 할 때 쓰세요.

   ![연락처 상세 화면 열기](https://jumpshare.com/share/50TaqXT09ew0YhONKegH+/Screen+Shot+2025-12-31+at+4.03.41+PM.png)

## 자주 묻는 질문

### 필터에서 캠페인을 선택했는데 결과가 안 나와요.
**소스 이름**(해당 캠페인)도 함께 선택해야 해요. 그리고 그 캠페인이 실제로 실행되었는지도 확인하세요. 소스 이름이 없으면 필터 결과가 나오지 않습니다.

### 여러 캠페인이나 워크플로우를 한꺼번에 필터링할 수 있나요?
소스 유형은 전체 또는 하나를 선택할 수 있어요. 선택한 유형 안에서는 여러 **소스 이름**도 지원돼요.

### 열림과 클릭을 확인하려면 추적이 필요한가요?
네. 링크 추적이나 열림 추적이 꺼져 있으면 **열림**과 **클릭됨** 지표가 일부만 보이거나 보이지 않을 수 있어요.

### 반송됨, 실패, 불만 제기됨은 어떻게 달라요?
- **반송됨**: 수신자의 메일 서버가 이메일을 거부한 경우예요.
- **실패**: 전달을 시도하기 전에 발송 오류가 난 경우예요.
- **불만 제기됨**: 수신자가 이메일을 스팸으로 신고한 경우예요.

### 날짜 범위는 어디서 바꾸나요?
**Email Analytics** 상단의 **날짜 범위**에서 바꾸세요. 그다음 **새로고침**을 클릭하면 바뀐 기간이 적용돼요.

### 하이퍼클래스 이메일이 아닌 다른 제공업체에서도 연락처 단위 이메일 분석 필터링을 쓸 수 있나요?
아니요. 연락처 단위 이메일 분석 필터링은 하이퍼클래스 이메일을 쓰는 서브 계정에서만 쓸 수 있어요.
