# 이메일 캠페인·템플릿 미리보기와 테스트 전송

이메일을 보내기 전에 레이아웃, 링크, 개인화 값이 제대로 표시되는지 확인하는 방법을 안내해요. 미리보기 모드와 테스트 이메일 전송을 활용하면 캠페인과 템플릿을 처음부터 정확하게 만들 수 있어요.

## 이메일 미리보기·테스트란?

하이퍼클래스의 **이메일 빌더**에서는 실제 발송 전에 내용을 눈으로 확인하고, 테스트용 이메일을 안전하게 받아 볼 수 있어요. 이 기능을 쓰면 실제 연락처나 캠페인 지표에 영향을 주지 않고 개인화, 레이아웃, 링크를 점검할 수 있어요. **미리보기**로는 빌더 안에서 이메일이 어떻게 보이는지 확인하고, **테스트 전송**으로는 내 받은편지함에 샘플을 보내 최종 점검을 해요.

{% hint style="info" %}
이메일 템플릿은 다시 쓸 수 있는 이메일 디자인이고, 이메일 캠페인은 연락처에게 실제로 보내거나 예약하는 이메일이에요.
{% endhint %}

## 미리보기·테스트의 장점

- 정확도: 병합 필드, 커스텀 값, 조건부 콘텐츠가 의도한 대로 표시되는지 확인해요.
- 컴플라이언스: 수신거부 영역 같은 필수 요소가 발송 전에 들어 있는지 확인해요.
- 품질 점검: 레이아웃, 이미지, 링크 문제를 미리 찾아낼 수 있어요. HTML을 가져왔다면 특히 유용해요.
- 속도: 실제 목록에 보내지 않고, 분석 데이터도 왜곡하지 않으면서 빠르게 수정할 수 있어요.

## 이메일 캠페인·템플릿 미리보기와 테스트 전송 방법

{% hint style="info" %}
이메일 템플릿과 캠페인을 만들고, 편집하고, 보내는 방법은 시작하기 - 이메일 캠페인 시작, 이메일 빌더와 인라인 편집기 사용 방법 가이드에서 자세히 볼 수 있어요.
{% endhint %}

{% hint style="info" %}
테스트 이메일에서는 수신거부 링크가 작동하지 않아요.
{% endhint %}

1. **마케팅 > 이메일 > 캠페인** 또는 **마케팅 > 이메일 > 템플릿**으로 이동하세요.

   ![마케팅 > 이메일 화면](https://jumpshare.com/share/9rnIvA446cGtavryFP3D+/Screen+Shot+2026-09-21+at+15.19.54.png)
2. 캠페인 또는 템플릿을 클릭해 연 다음, **디자인 에디터**로 전환하세요.
3. 오른쪽 위의 **미리보기** 버튼을 클릭하고 **데스크톱**/**태블릿**/**모바일** 보기를 각각 확인하세요.

   ![데스크톱, 태블릿, 모바일 미리보기 화면 녹화](https://jumpshare.com/share/Y5b13ld78bAUgsM2kBdI+/GIF+Recording+2026-09-21+at+15.30.18.gif)
4. 테스트 이메일을 보내려면 **미리보기** 버튼 옆의 점 세 개 아이콘을 클릭한 다음 **테스트 이메일** 버튼을 클릭하세요.

   ![점 세 개 메뉴에서 테스트 이메일 선택](https://jumpshare.com/share/3eLrIVZNbrjvcmUiyeQx+/Screen+Shot+2026-09-21+at+15.33.41.png)
5. **발신자 이메일**을 선택하고, **발신자 이름**을 입력하세요. 이어서 **Receiver Email**(수신자 이메일)을 선택하고, **Preview Text**(미리보기 텍스트)와 **이메일 제목**을 입력하세요.
6. **테스트 이메일 전송** 버튼을 클릭하세요.

   ![테스트 이메일 전송 화면](https://jumpshare.com/share/5qcVCMDIx7akEwjGBWvJ+/Screen+Shot+2026-09-21+at+15.42.03.png)

## 자주 묻는 질문

### 테스트 이메일에서 수신거부 링크가 작동하지 않는 이유는 무엇인가요?

목록을 보호하기 위해 테스트에서는 수신거부 기능을 일부러 꺼 두었어요. 실제 발송에서는 설정한 흐름에 따라 정상적으로 작동해요.

### 테스트 이메일의 열람이나 클릭이 분석 데이터에 영향을 주나요?

아니요. 테스트는 확인용이에요. 성과 지표는 실제 발송에서만 쌓여요.

### 테스트 이메일이 도착하지 않아요. 무엇부터 확인해야 하나요?

스팸함이나 정크 메일함을 먼저 확인하세요. 그다음 발신자(From)와 서비스 설정이 맞는지 확인하고, 수신자가 발송 제외 상태가 아닌지 살펴보세요. 그래도 안 오면 다른 이메일 주소로 다시 시도해 보세요.

### 사용자 지정 수신거부 링크도 테스트에서 작동하나요?

테스트 이메일에는 링크가 표시되지만, 수신거부 처리는 완료되지 않아요. 실제 발송에서는 설정한 대로 작동해요.
