# 이메일 유형별로 전용 발송 도메인 지정하기

이메일 유형마다 다른 발송용 서브도메인을 지정하고, 도메인별 발송량 비율을 정하고, 따로 지정하지 않은 발송에 쓸 기본 도메인을 정하는 방법을 안내해요. 이메일 전달률(Deliverability)을 관리할 때 쓰는 기능이에요.

## 개요

**워크플로우**, **이메일 캠페인**, 일괄 작업 이메일, 수동 1:1 이메일마다 서로 다른 발송용 서브도메인을 쓰고 싶다면 **Domain Configuration**(도메인 구성)에서 설정하세요. 같은 화면에서 도메인별 발송 비율을 나누고, 따로 지정하지 않은 발송에 쓸 기본 발송 도메인도 정할 수 있어요.

## Domain Configuration 찾는 위치

이메일 유형별 도메인 지정, 발송 비율 설정, 기본 발송 도메인 설정은 모두 한 화면에서 할 수 있어요.

**서브 계정 설정 > 이메일 서비스 > SMTP 서비스 > Dedicated Domain and IP**(전용 도메인 및 IP) **> Domain Configuration**

![Dedicated Domain and IP 설정 안의 Domain Configuration 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155024423997/original/MwbK5FXsS2k4OyYNDobeWxAyYCq8QC3sfw.png?1713046276)

**Domain Configuration** 화면에서 이메일 유형별로 도메인을 지정하고, 발송 비율을 설정하고, 기본 도메인을 고를 수 있어요.

## 빈도 설정

{% hint style="info" %}
발송량이 많은 계정에 권장해요.
{% endhint %}

**빈도 설정**을 쓰면 예약된 이메일 중 몇 퍼센트를 추가해 둔 각 도메인으로 보낼지 정할 수 있어요. 모든 이메일을 도메인 하나로 보내지 않고, 정해 둔 비율대로 나눠서 보내요.

도메인마다 다른 비율을 주면 전달률이 높은 도메인에 더 많이 보낼 수 있어요. 도메인별 성과에 따라 발송량을 조정할 수도 있어요. 이렇게 하면 이메일이 수신자의 받은편지함에 안정적으로 도착하도록 도울 수 있어요.

![여러 도메인에 퍼센트로 발송 비율을 나눈 빈도 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155024424011/original/iknMDP50VIX3j6kLdDJR3a4pbbVHEoCpxg.png?1713046362)

도메인마다 발송 비율을 퍼센트로 지정해요. 전체 합계는 100%가 되어야 해요.

## 기본 전용 발송 도메인

기본 전용 발송 도메인은 다른 도메인이 따로 지정되지 않은 모든 이메일 발송에 쓰이는 도메인이에요. 도메인을 지정하지 않은 발송은 모두 이 도메인으로 나가요.

{% hint style="info" %}
기본 도메인을 설정해 두면, 설정 중에 특정 지정을 빠뜨리더라도 인증된 전용 도메인 없이 이메일이 발송되는 일이 없어요. 캠페인을 시작하기 전에 기본 도메인을 꼭 지정하세요.
{% endhint %}

![Domain Configuration의 기본 전용 발송 도메인 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039361093/original/Vz0rz1u4xGjJYxZX2DCGyBuSoKJqz0d96Q.png?1736200367)

지정되지 않은 모든 이메일 발송의 기본값으로 쓸 인증된 도메인을 선택해요.

## 자주 묻는 질문

### 이메일 유형(워크플로우, 캠페인, 일괄 작업, 1:1)마다 다른 도메인을 지정할 수 있나요?
네, 할 수 있어요. **Domain Configuration**에서 **워크플로우**, **이메일 캠페인**, 일괄 작업 이메일, 수동 1:1 이메일마다 인증된 발송 도메인을 따로 지정할 수 있어요. 지정하지 않은 유형은 기본 도메인으로 발송돼요.

### 발송 비율의 합계가 꼭 100%여야 하나요?
네. **빈도 설정**에서 모든 도메인에 지정한 비율의 합은 100%가 되어야 해요. 예를 들어 도메인이 두 개라면 하나는 70%, 다른 하나는 30%로 정할 수 있어요. 플랫폼은 이 값에 비례해서 발송량을 나눠요.

### 기본 도메인을 설정하지 않으면 어떻게 되나요?
기본 도메인이 없으면 도메인을 따로 지정하지 않은 이메일은 전용 도메인으로 나가지 않을 수 있어요. 공유 발송 인프라로 발송될 수도 있어요. 모든 발송에 인증된 전용 도메인을 쓰려면 꼭 기본 도메인을 설정하세요.

### 전용 도메인이 하나뿐이에요. 그래도 Domain Configuration을 설정해야 하나요?
도메인이 하나라면 그 도메인을 기본 도메인으로 지정하는 것이 가장 중요해요. **빈도 설정**은 도메인이 여러 개일 때 가장 유용해요. 도메인이 하나라면 기본 도메인으로 지정하는 것만으로 전체 발송의 100%를 그 도메인이 처리해요.

### 기본 도메인이나 발송 비율을 언제든 바꿀 수 있나요?
네. **Domain Configuration**에서 기본 도메인이나 발송 비율을 언제든 수정할 수 있어요. 변경한 내용은 이후 새로 발송하는 이메일부터 적용돼요. 이미 대기열에 있거나 발송 중인 이메일은 트리거된 시점에 지정되어 있던 도메인으로 발송돼요.

### 발송 비율을 나누면 전달률에 어떤 영향이 있나요?
발송 비율을 나누면 평판이 좋은 도메인으로 더 많이 보내고, 새 도메인이나 성과가 낮은 도메인은 노출을 줄일 수 있어요. 평판이 높은 도메인을 과도하게 쓰지 않도록 보호할 수 있어요. 한 도메인의 성과가 떨어지면 발송을 완전히 멈추지 않고 비율만 낮출 수도 있어요.

### Domain Configuration은 기본 헤더 설정과 같은 건가요?
아니요, 서로 다른 기능이에요. **Domain Configuration**은 이메일 유형별로 어떤 도메인을 쓸지, 발송량을 어떻게 나눌지 정해요. 기본 헤더는 특정 도메인에서 DMARC 정렬에 실패했을 때 대신 쓰는 **From Name**(보낸 사람 이름)과 **From Email**(보낸 사람 이메일)을 정해요. 두 기능은 각각 따로 설정할 수 있어요.
