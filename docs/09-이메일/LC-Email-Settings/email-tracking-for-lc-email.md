# 하이퍼클래스 이메일 열람·클릭 추적 설정

전용 발송 도메인에서 이메일 열람 추적과 클릭 추적을 켜거나 끄는 방법을 안내해요. 추적을 켜면 어떤 참여 데이터를 볼 수 있는지도 함께 설명해요.

{% hint style="warning" %}
이메일 추적은 하이퍼클래스 이메일을 사용할 때만 쓸 수 있어요. Mailgun, Gmail 등 다른 이메일 제공업체에서는 이 기능을 쓸 수 없어요.
{% endhint %}

## 이메일 추적이란?

이메일 추적은 수신자가 이메일로 하는 행동을 확인하고 기록하는 기능이에요. 이메일을 열었는지(열람 추적), 이메일 안의 링크를 클릭했는지(클릭 추적)를 알 수 있어요.

이 기능을 켜면 이메일 캠페인의 효과를 확인할 수 있어요. 수신자가 어떻게 반응하는지 실시간 데이터로 파악하고, 그 결과로 마케팅 전략을 개선할 수 있어요.

## 이메일 추적을 쓰면 좋은 이유

이메일 추적을 쓰면 받는 사람들이 이메일에 어떻게 반응하는지 알 수 있어요. 열람과 클릭 데이터를 보면 어떤 콘텐츠가 반응이 좋은지 확인하고, 메시지를 다듬어 전환율을 높일 수 있어요.

### 실제 사례

신제품 출시를 알리는 이메일 캠페인을 보낸다고 가정해 볼게요.

이메일 추적을 켜 두면 누가 이메일을 열었고, 누가 상품 링크를 클릭했는지 볼 수 있어요. 링크를 클릭한 사람은 많은데 구매까지 이어지지 않았다면, 맞춤 이메일로 후속 안내를 보내 볼 수 있어요. 기간 한정 할인이나 추가 정보를 보내면 매출을 높이는 데 도움이 돼요.

이메일 추적을 켜 두지 않으면 수신자가 어떻게 행동했는지 알 수 없어요. 그러면 캠페인을 개선할 기회를 놓치게 돼요.

## 이메일 추적 메뉴 위치

1. 서브 계정에 로그인해요.
2. 서브 계정 대시보드로 이동해요.
3. **설정**을 클릭해요.

   ![서브 계정의 설정 내비게이션](https://jumpshare.com/share/Qkoo3Kve68ZSWEuN1Fe6+/Screen+Shot+2025-09-17+at+6.50.26+PM.png)

4. **이메일 서비스** 탭을 클릭해요.

   ![설정의 이메일 서비스 탭](https://jumpshare.com/share/tICDA3zJEutya9XRVaYS+/Screen+Shot+2025-09-17+at+6.51.07+PM.png)

## 이메일 추적 설정하기

몇 번만 클릭하면 하이퍼클래스 이메일 전용 발송 도메인의 열람 추적과 클릭 추적을 켜거나 끌 수 있어요.

{% hint style="info" %}
이메일 추적을 설정하려면 하이퍼클래스 이메일 전용 발송 도메인을 먼저 설정해 두어야 해요. 전용 발송 도메인 설정 방법은 별도 도움말을 참고하세요.
{% endhint %}

1. **설정 > 이메일 서비스**로 이동해요.
2. 하이퍼클래스 이메일이 선택되어 있는지 확인해요.
3. **Dedicated Domain and IP**(전용 도메인 및 IP) 버튼을 클릭해요.

   ![이메일 서비스 설정의 Dedicated Domain and IP 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031768466/original/aKaW4hSM6jlbYQ8YsuFx7f13KLU99ns07g.jpg?1724785936)

4. 하이퍼클래스 이메일 전용 발송 도메인 카드 오른쪽 위의 점 세 개 메뉴(⋯)를 클릭해요.
5. 드롭다운에서 **Domain Settings**(도메인 설정)를 선택해요.

   ![도메인 카드의 점 세 개 메뉴와 Domain Settings 옵션](https://jumpshare.com/share/D5ThPjATnIaBXxUOZXPQ+/Screen+Shot+2025-09-17+at+6.57.31+PM.png)

6. 팝업에서 **Click Tracking**(클릭 추적)과 **Open Tracking**(열람 추적) 토글을 원하는 대로 켜거나 꺼요. 변경 내용은 해당 도메인으로 보내는 이메일에 바로 적용돼요.

   ![Click Tracking과 Open Tracking 토글이 있는 Domain Settings 팝업](https://jumpshare.com/share/NGK1EfwbzY1gcNWdgcCq+/Screen+Shot+2025-09-17+at+7.02.07+PM.png)

## 자주 묻는 질문

### 이메일 활동을 추적하면 어떤 데이터가 수집되나요?

참여 데이터가 수집되어 서브 계정의 연락처 기록에 연결돼요. 이메일 추적 분석에서는 연락처별로 다음 이벤트 유형을 볼 수 있어요.

- 이메일 발송
- 이메일 전달
- 이메일 열람
- 이메일 링크 클릭(이메일 안의 링크)
- 이메일 반송
- 스팸 신고(스팸으로 표시)
- 구독 취소
- **이메일 발송 실패**

### Mailgun으로 이메일을 보내는데 이메일 활동을 추적할 수 있나요?

아니요. 이메일 추적 분석은 하이퍼클래스 이메일이 SMTP 제공업체일 때만 쓸 수 있어요. 서브 계정이 Mailgun, Gmail 같은 외부 제공업체로 발송하도록 설정되어 있으면 추적 데이터를 볼 수 없어요.

### Gmail 주소로 보낸 이메일도 추적할 수 있나요?

아니요. 이메일 활동과 참여를 추적하려면 하이퍼클래스 이메일 전용 발송 도메인으로 이메일을 보내야 해요. 이메일을 보낼 때 Gmail 주소를 **보내는 사람**으로 쓸 수는 있어요. 하지만 Google이 SMTP 제공업체이면 추적은 지원되지 않아요.

### 이메일 추적을 끄면 어떻게 되나요?

이메일 추적을 끄면 열람, 클릭, 반송 같은 참여 데이터를 더 이상 볼 수 없어요. 어떤 연락처가 이메일 캠페인에 반응하는지 계속 확인할 수 있도록 이메일 추적을 켜 두기를 권장해요.

### 발송 도메인마다 추적 설정을 다르게 할 수 있나요?

네. 추적 설정은 **Domain Settings** 에서 도메인별로 설정해요. 전용 발송 도메인이 여러 개라면 도메인마다 열람 추적과 클릭 추적을 따로 켜거나 끌 수 있어요.

### 클릭 추적을 켜면 이메일 속 링크가 바뀌나요?

네. 클릭 추적을 켜면 이메일 속 링크가 추적용 리디렉션을 거치도록 바뀌어요. 그래야 클릭을 기록할 수 있어요. 이메일 마케팅 분석에서 일반적으로 쓰는 방식이고, 수신자가 링크를 클릭했을 때 이동하는 최종 주소에는 영향을 주지 않아요.
