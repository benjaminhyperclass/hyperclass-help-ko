# 하이퍼클래스 이메일 전용 발송 도메인 삭제하기

서브 계정에 연결된 하이퍼클래스 이메일 전용 발송 도메인을 삭제해야 하는 경우와 삭제 위치, 삭제 방법을 안내해요.

## 개요

하이퍼클래스 이메일 전용 발송 도메인은 서브 계정에 연결해 이메일을 보내고 받는 데 쓰는 이메일 도메인이에요. 서브 계정 하나에 도메인과 서브 도메인을 여러 개 연결할 수 있어요. 그래서 도메인을 추가하고 삭제하는 방법을 알아 두면 좋아요.

하이퍼클래스 이메일 전용 발송 도메인에 대해 더 알아보기

## 도메인을 삭제해야 하는 이유

서브 계정에서 전용 발송 도메인을 삭제해야 하는 경우는 대체로 아래와 같아요.

### 이유 1. 잘못된 도메인을 추가했어요

도메인을 잘못 추가하면 DNS 레코드가 제대로 연결되지 않아 이메일이 동작하지 않아요. 이럴 때는 잘못 추가한 도메인을 삭제하고 올바른 도메인을 추가하세요.

### 이유 2. 비즈니스에서 사용하는 도메인이 바뀌었어요

리브랜딩을 하거나 새 도메인으로 옮기면 발송 도메인도 그에 맞춰 바꾸는 것이 좋아요. 이메일 평판에도 중요해요. Google 같은 이메일 서비스는 이메일이 믿을 만한지 판단할 때 발송 도메인과 비즈니스 정체성이 일치하는지 살펴봐요.

### 이유 3. 도메인이 스팸으로 분류되어 전송 성공률이 낮아졌어요

대량 마케팅 발송을 하면 스팸 신고가 쌓여 도메인의 평판 점수가 떨어질 수 있어요. 전송 성공률이 크게 떨어지면 새 도메인으로 바꿔야 하는 경우가 많아요. 문제가 된 도메인으로는 더 이상 보내지 않기로 했다면 서브 계정에 계속 연결해 둘 이유가 없어요.

{% hint style="info" %}
위 내용은 가장 흔한 이유예요. 사용 목적과 비즈니스 상황에 따라 다른 이유가 있을 수도 있어요.
{% endhint %}

## 전용 발송 도메인은 어디에서 확인하나요

모든 이메일 발송 도메인은 서브 계정 설정의 **이메일 서비스** 화면에서 관리해요.

이동 경로: **설정 > 이메일 서비스**

![서브 계정에서 설정 메뉴로 이동하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032625907/original/2_-VQ3O57oJG2a_uIc8nPUD56YmP2YHiJg.jpg?1725993012)
![서브 계정 설정의 이메일 서비스 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032625911/original/n8zdGiX9Wc_BUq9aRnPIfJ-DplDEDh16nw.jpg?1725993021)

**설정 > 이메일 서비스**에서 전용 발송 도메인을 관리해요.

## 전용 발송 도메인 삭제하기

**이메일 서비스** 화면에서 아래 순서대로 따라 하면 전용 발송 도메인을 삭제할 수 있어요.

1. 화면 오른쪽에 있는 **Dedicated Domain and IP**(전용 도메인 및 IP) 버튼을 클릭하세요. 이 서브 계정에 연결된 발송 도메인이 모두 보여요.

   ![이메일 서비스의 Dedicated Domain and IP 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032625704/original/cbPXDzi8WwYJbMJ17V6rRb9yE6k1zvPhkw.jpg?1725992653)

   **Dedicated Domain and IP**를 클릭하면 이 서브 계정에 연결된 발송 도메인을 모두 볼 수 있어요.

2. 삭제할 도메인 카드의 왼쪽 위에 있는 점 세 개 메뉴를 클릭해 작업 메뉴를 여세요.

   ![도메인 카드의 점 세 개 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032625837/original/JlFhET4WPCO06FGgWFn5zSM4zBi37wcfhw.jpg?1725992863)

   도메인 카드의 점 세 개 메뉴를 클릭하세요.

3. 메뉴에서 **도메인 삭제**를 선택하세요.

   ![작업 메뉴의 도메인 삭제 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032625843/original/86FJLae4GVP0SsYg0uwhOaSXsdJyJB9h2w.jpg?1725992876)

   작업 메뉴에서 **도메인 삭제**를 선택하세요.

4. 확인 팝업이 나타나면 삭제를 확인하세요. 서브 계정에서 도메인이 영구적으로 삭제돼요.

   ![도메인 삭제를 확인하는 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032625847/original/Kt2ypyv0iB2fllZW2Pplzpklok_ZRGBAIQ.jpg?1725992888)

   팝업에서 삭제를 확인하세요. 이 작업은 되돌릴 수 없어요.

{% hint style="warning" %}
서브 계정에서 도메인을 삭제하면 되돌릴 수 없어요. 이 서브 계정과 도메인의 DNS 연결이 바로 끊어지고, 이 계정에서 해당 도메인으로 보내던 이메일 발송도 모두 멈춰요. 도메인은 언제든 다시 추가할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 서브 계정에서 이메일 도메인을 삭제하면 어떻게 되나요?

삭제하면 해당 도메인과 서브 계정 사이의 DNS 연결이 끊어져요. 도메인 자체에는 영향이 없고, 도메인 등록 업체에 있는 DNS 레코드도 그대로 남아 있어요. 그래서 필요하면 그 도메인을 바로 다른 이메일 서비스에 연결하거나 다른 서브 계정에 다시 추가할 수 있어요.

### 삭제한 발송 도메인을 같은 서브 계정에 다시 연결할 수 있나요?

네, 가능해요. **설정 > 이메일 서비스 > Dedicated Domain**(전용 도메인) **> + 도메인 추가**로 이동해 같은 도메인을 다시 입력하면 언제든 다시 추가할 수 있어요. 도메인 호스팅 업체에 따라 DNS 변경 사항이 반영되기까지 시간이 걸릴 수 있어요.

### 발송 도메인을 삭제하면 이메일 전송 성공률이 나빠지나요?

상황에 따라 달라요. 삭제하는 도메인의 평판이 좋았다면 새 도메인으로 바꾸는 순간 처음부터 다시 시작하는 셈이에요. 새 도메인은 긍정적인 평판 점수를 쌓을 시간이 필요해서 전송 성공률이 일시적으로 떨어질 수 있어요.

반대로 삭제하는 도메인이 스팸 신고 때문에 이미 평판이 나쁘다면, 새 도메인으로 바꾸는 것이 시간이 지나면서 전송 성공률을 높여 줄 수도 있어요.

### 도메인을 삭제할 때 등록 업체의 DNS 레코드도 지워야 하나요?

꼭 그렇지는 않아요. 하이퍼클래스에서 도메인을 삭제하면 서브 계정에서만 제거되고, 등록 업체에 있는 DNS 레코드는 건드리지 않아요. 나중에 이 서브 계정이나 다른 서브 계정에 도메인을 다시 추가할 계획이라면 DNS 레코드를 그대로 두어도 돼요. 완전히 다른 이메일 서비스로 옮긴다면 해당 레코드를 수정하거나 바꿔야 할 수 있어요.

### 도메인을 삭제하면 이미 예약되었거나 발송 대기 중인 이메일은 어떻게 되나요?

삭제한 도메인을 사용하도록 설정된 예약 이메일과 실행 중인 워크플로우는 도메인이 삭제된 뒤 전송에 실패할 가능성이 높아요. 삭제하기 전에 해당 발송 도메인과 연결된 실행 중인 캠페인과 워크플로우를 일시중지하고, 다른 도메인으로 바꿔 두는 것이 좋아요.

### 서브 계정 하나에 전용 발송 도메인을 몇 개까지 연결할 수 있나요?

서브 계정 하나에 도메인과 서브 도메인을 여러 개 연결할 수 있어요. 서브 계정당 전용 발송 도메인 수에는 정해진 제한이 없어요. 그래서 팀, 브랜드, 사용 목적에 맞게 발송 도메인을 나누어 쓸 수 있어요.
