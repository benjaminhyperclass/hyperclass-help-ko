# 캠페인 보내는 이메일 주소 인증하기

이메일 캠페인을 보내기 전에 **보내는 이메일 주소**를 한 번 인증해야 해요. 일회용 비밀번호(OTP)로 확인하는 간단한 절차이고, 발신자 평판을 지키고 다른 사람이 내 이메일 주소를 도용하지 못하게 막아 줘요.

## 달라진 점

예전에는 캠페인의 보내는 이메일 주소를 따로 인증하지 않았어요. 그래서 발신자를 사칭할 수 있었고, 발신자 평판이 나빠질 위험도 있었어요.

보안을 강화하기 위해 이제 이메일 캠페인을 보내기 전에 **보내는 이메일 주소**를 인증해야 해요. 유효하게 인증된 주소만 사용할 수 있어서 발신자 사칭을 막을 수 있어요.

## 인증이 필요 없는 경우

아래 두 경우에는 OTP 인증 단계를 건너뛰어요.

- **하이퍼클래스 이메일에서 제공한 커스텀 도메인을 쓰는 경우**: 발송 도메인이 하이퍼클래스 이메일에서 발급한 커스텀 도메인이면 소유권이 이미 확인된 상태예요. 이 경우 발신자 주소는 자동으로 신뢰돼요.
- **설정에 저장된 Location admin email(서브 계정 관리자 이메일)과 같은 경우**: 발신자 주소가 설정에 이미 저장된 **Location admin email**과 같으면 인증된 주소로 처리돼요. OTP는 필요 없어요.

## 이메일 인증하는 방법

1. **이메일 마케팅**(Email Marketing)으로 이동해 새 캠페인을 만드세요.
2. **발신자 이메일** 필드에 보내는 이메일 주소로 쓰려는 주소를 입력하세요.
3. 인증되지 않은 주소 옆에 **지금 인증하기** 버튼이 나타나요. 버튼을 누르면 OTP가 담긴 이메일이 발송돼요.

   ![발신자 이메일 필드와 지금 인증하기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031199950/original/kaNwiSY0fmopj5MlBf7bYD_wdR0NYuUzDA.png?1723866095)

4. 입력한 주소의 받은편지함에서 이메일을 열어 6자리 OTP를 복사한 다음, 인증 창에 붙여넣으세요.

   ![이메일 인증 OTP 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031199951/original/ckUZs8FxIzpfRLvjOS8JZmn-TUUZvrIAsQ.png?1723866095)

5. OTP가 확인되면 인증이 끝나요. 이후 모든 캠페인에서 이 주소를 보내는 이메일 주소로 쓸 수 있어요.

{% hint style="info" %}
인증한 주소는 모든 캠페인에서 그대로 유지돼요. 주소마다 한 번만 인증하면 돼요.
{% endhint %}

## 설정에서 미리 인증하기

캠페인을 만들기 전에 미리 인증할 수도 있어요. **설정** 페이지에서 **이메일 인증하기**를 누르세요. OTP 인증 절차는 캠페인에서 인증할 때와 똑같아요.

![설정 페이지에서 이메일 인증하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031199952/original/8plDBApPogd_CPPjESiBP3Bmm06Kyd2WRQ.jpeg?1723866095)

## 자주 묻는 질문

### 이메일 인증이 왜 필요해졌나요?
인증이 없으면 누구나 발신자 주소에 아무 이메일 주소나 입력할 수 있었어요. 자신이 소유하지 않은 도메인도 가능했죠. 그러면 발신자를 사칭할 수 있고 발신자 평판도 나빠져요. 발신자 주소의 소유권을 확인하면 이런 허점을 막을 수 있어요.

### OTP는 얼마 동안 유효한가요?
보안을 위해 OTP는 짧은 시간이 지나면 만료돼요. 만료됐다면 **지금 인증하기**를 다시 눌러 새 코드를 받으세요.

### OTP 이메일이 오지 않아요. 무엇을 확인해야 하나요?
스팸 메일함을 확인하고, 이메일 주소를 정확히 입력했는지 살펴보세요. 받은편지함이 발신 전용(no-reply) 주소에서 온 메일을 걸러내고 있지는 않은지도 확인해 보세요. 1분이 지나도 오지 않으면 새 OTP를 요청하세요.

### 같은 이메일을 여러 번 인증해야 하나요?
아니요. 한 번 인증한 주소는 내 계정에서 인증된 주소로 표시돼요. 이후 캠페인에서는 OTP 인증 없이 그대로 쓸 수 있어요.

### 보내는 이메일 주소를 여러 개 인증할 수 있나요?
네. 쓰려는 주소마다 인증 절차를 반복하세요. 인증한 주소는 다음에 캠페인을 만들 때 **발신자 이메일** 드롭다운에 모두 표시돼요.

### 워크플로우의 Send Email 액션에도 인증이 적용되나요?
이 인증 요구 사항은 이메일 캠페인에 적용돼요. 워크플로우로 보내는 이메일은 워크플로우에 설정한 발신자 주소를 따라요. 워크플로우 이메일에도 같은 보호를 적용하고 싶다면, 워크플로우의 **Send Email**(이메일 보내기) 액션에서 쓰는 보내는 주소도 인증하세요.

### 캠페인이 발송되지 않고 주소가 인증되지 않았다고 나와요. 어떻게 하나요?
캠페인을 열고 **발신자 주소** 옆의 **지금 인증하기**를 누르세요. OTP 인증을 마친 뒤 다시 보내면 돼요. **설정 > 이메일 인증하기**에서 미리 인증해 둘 수도 있어요.
