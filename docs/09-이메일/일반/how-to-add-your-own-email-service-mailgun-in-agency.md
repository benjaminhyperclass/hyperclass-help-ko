# 에이전시에 내 이메일 서비스(Mailgun) 연결하기

내 Mailgun 계정을 하이퍼클래스에 연결하면 에이전시가 내 인프라로 이메일을 보낼 수 있어요. 발신 평판, 도메인, 발송량 한도도 내 Mailgun 계정 기준으로 적용돼요. 이 기능은 에이전시 관리자만 쓸 수 있어요.

## 개요

에이전시는 기본적으로 하이퍼클래스에 내장된 하이퍼클래스 이메일 시스템으로 이메일을 보내요. 이미 쌓아 둔 발신 평판이 있거나, 발송량이 많거나, 전용 도메인이 필요하다면 에이전시 단위에서 Mailgun 계정을 직접 연결할 수 있어요.

이 문서에서는 이메일 서비스 설정 위치, 기본 서비스와 사용자 설정 서비스의 차이, Mailgun을 추가하고 활성화하는 전체 과정을 안내해요.

## 이메일 서비스 설정 위치

**이메일 서비스** 설정은 개별 서브 계정이 아니라 에이전시 계정 안에 있어요. 설정을 바꾸기 전에 아래 순서로 이동하세요.

1. 에이전시 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **설정**을 클릭하세요.
3. **이메일 서비스**를 선택하세요.
4. **SMTP 서비스** 탭을 여세요. 버전에 따라 **고급 설정**이라고 표시될 수도 있어요.

{% hint style="info" %}
화면에 따라 탭 이름이 **SMTP 서비스** 또는 **고급 설정**으로 보일 수 있어요. 둘 다 같은 설정 화면으로 연결돼요.
{% endhint %}

## 기본 서비스와 사용자 설정 서비스 비교

에이전시는 처음에 공용 하이퍼클래스 이메일 시스템을 사용해요. Mailgun을 연결하면 이 시스템 대신 내 발송 인프라를 쓰게 돼요. 두 방식의 차이는 다음과 같아요.

| 항목 | 기본 (하이퍼클래스) | 사용자 설정 (내 Mailgun) |
| --- | --- | --- |
| 발신 도메인 | 플랫폼 공용 도메인 | 인증을 마친 내 도메인 |
| 발신자 평판 | 다른 발신자와 공유 | 전적으로 내가 관리 |
| 발송량 한도 | 플랫폼에서 관리 | 내 Mailgun 요금제 기준 |
| 필요한 설정 | 없음 — 바로 사용 가능 | API 키 + 도메인 설정 |
| 이런 경우에 추천 | 처음 시작하는 에이전시 | 발송 이력이 있거나 발송량이 많은 에이전시 |

{% hint style="warning" %}
사용자 설정 이메일 서비스로 바꾸면 에이전시에서 나가는 모든 이메일에 영향이 있어요. 활성화하기 전에 Mailgun 도메인 인증이 끝났는지, API 키에 발송 권한이 있는지 확인하세요.
{% endhint %}

## 설정 방법: 내 이메일 서비스(Mailgun) 추가하기

아래 다섯 단계를 따라 Mailgun 계정을 에이전시에 연결하세요.

1. **이메일 서비스 열기**

   에이전시 계정에서 **설정 > 이메일 서비스 > SMTP 서비스** 탭으로 이동하세요.

2. **+ Add Service 클릭하기**

   페이지 오른쪽 위에서 **+ Add Service**(서비스 추가) 버튼을 클릭하세요. **Add your own email service**(내 이메일 서비스 추가) 팝업이 열려요.

3. **SMTP 제공업체로 Mailgun 선택하기**

   팝업에 나오는 제공업체 목록에서 **Mailgun**을 선택하세요.

   ![SMTP 제공업체 선택 화면에서 Mailgun 옵션을 보여 주는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073953045/original/qyEWS4o0kk1ZySrPNiltmgA0ALWON6bDTA.jpeg?1781774144)

   서비스 추가 팝업의 제공업체 목록에서 Mailgun을 선택하세요.

4. **Mailgun 인증 정보 입력하기**

   Mailgun 계정 대시보드의 정보를 보고 필수 항목을 입력하세요.

   - **API 키**: Mailgun API 키예요. Mailgun 계정의 **Settings > API Keys**(설정 > API 키)에서 확인할 수 있어요.
   - **도메인**: 사용하려는 인증된 발신 도메인을 드롭다운에서 선택하세요.

   ![API 키와 도메인 입력란이 있는 Mailgun 인증 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073953029/original/kDOiN0NIZRnIA9bvyWE-Axu7FCz1MIMU3Q.png?1781774130)

   Mailgun API 키를 입력하고 발신 도메인을 선택하세요.

5. **저장하고 활성으로 설정하기**

   저장하면 Mailgun 서비스가 목록에 나타나지만, 활성화하기 전까지는 사용되지 않아요. 사용을 시작하려면 아래 순서로 진행하세요.

   1. 목록에서 방금 추가한 서비스를 찾으세요.
   2. **Set as Active**(활성으로 설정)를 클릭하세요.
   3. 나타나는 확인 창에서 선택을 확인하세요.

{% hint style="info" %}
설정이 끝났어요. 이제 에이전시의 모든 발신 이메일이 내 Mailgun 계정을 통해 나가요. **설정 > 이메일 서비스**로 돌아가면 언제든 서비스를 바꾸거나 제공업체를 더 추가할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 이 설정이 에이전시 아래 모든 서브 계정에 적용되나요?
네. **설정 > 이메일 서비스**에서 활성으로 지정한 사용자 설정 이메일 서비스는 에이전시 단위로 적용돼요. 자체 서비스를 설정하지 않은 서브 계정의 기본 발송 서비스가 돼요. 필요하면 각 서브 계정이 자체 서비스로 바꿔 쓸 수도 있어요.

### Mailgun API 키는 어디서 찾나요?
Mailgun 계정에 로그인한 뒤 **Settings > API Keys**(설정 > API 키)로 이동하세요. 그곳에 Private API key가 표시돼요. 아직 키를 만들지 않았다면 **Add new key**(새 키 추가)를 클릭하세요. 사용하려는 도메인에 대한 발송 권한이 키에 있는지 꼭 확인하세요.

### 도메인 드롭다운에 내 도메인이 보이지 않아요.
드롭다운에는 인증을 마친 Mailgun 도메인만 나타나요. 도메인이 보이지 않으면 Mailgun 계정에서 도메인이 완전히 인증됐는지 확인하세요. SPF, DKIM, MX 등 DNS 레코드가 모두 설정되어 있어야 해요. Mailgun에서 인증을 마친 뒤 이 화면으로 돌아와 다시 시도하세요.

### Mailgun 서비스를 여러 개 추가할 수 있나요?
네. 서비스를 여러 개 추가할 수 있어요. 예를 들어 Mailgun 도메인이나 계정별로 따로 등록할 수 있어요. 다만 한 번에 하나의 서비스만 **활성**으로 지정할 수 있어요. 에이전시 단위의 모든 발신 이메일은 활성 서비스를 통해 나가요.

### Mailgun을 활성화한 뒤 기본 서비스로 되돌릴 수 있나요?
네. **설정 > 이메일 서비스**로 돌아가 하이퍼클래스 이메일 시스템을 **활성**으로 설정하세요. 그러면 에이전시 단위의 모든 발신 이메일이 즉시 플랫폼 기본 발송 인프라로 돌아가요.

### 서비스를 바꾸면 이미 예약됐거나 워크플로우 진행 중인 이메일에도 영향이 있나요?
이미 대기열에 있거나 워크플로우 진행 중인 이메일은 처리되는 시점에 새로 활성화된 서비스를 사용해요. 이미 발송된 이메일은 되돌릴 수 없어요. 전환 중 위험을 줄이고 싶다면 발송이 적은 시간대에 Mailgun 설정을 테스트해 보세요.

### 내 Mailgun 계정을 쓰면 추가 비용이 드나요?
플랫폼에서는 Mailgun 연결에 추가 요금을 받지 않아요. 사용자 설정 SMTP 서비스를 써도 별도 비용이 없어요. 다만 Mailgun 계정으로 보내는 이메일 양에 따라 Mailgun 자체 요금이 적용돼요. 자세한 내용은 Mailgun 웹사이트에서 요금 안내를 확인하세요.
