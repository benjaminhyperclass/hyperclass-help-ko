# SMTP 설정 도움말 링크 숨기기

짧은 사용자 지정 CSS 코드를 넣어, 고객 화면에 보이는 SMTP 설정 도움말 링크를 숨기는 방법을 안내해요. 에이전시 관리자만 쓸 수 있어요.

## 숨길 링크 확인하기

아래와 같은 SMTP 설정 도움말 링크를 고객에게 보여 주고 싶지 않다면, 다음 순서대로 숨겨 보세요.

![기본으로 표시되는 SMTP 설정 도움말 링크](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032853011/original/eP8muhxmKz6vk0vz9iAKhy17sMVPvCBtdA.jpg?1726245732)

## 사용자 지정 CSS로 링크 숨기기

1. 에이전시 설정을 열어요. 로그인한 뒤 **설정 > 에이전시 설정**으로 이동하고, 아래로 스크롤해 **사용자 지정 CSS** 필드를 찾으세요.
2. 아래 코드를 **사용자 지정 CSS** 필드에 붙여 넣으세요.

   ```
   .hl__smtp-help-doc {
     display: none;
   }
   ```

3. 변경사항을 저장하세요. 저장하면 SMTP 설정 도움말 링크가 화면에서 사라져요.

{% hint style="info" %}
나중에 SMTP 설정 도움말 링크를 다시 보이게 하려면 **사용자 지정 CSS** 필드에서 이 코드를 지우세요.
{% endhint %}

## 자주 묻는 질문

### 링크를 숨기면 고객이 SMTP를 설정하는 데 문제가 생기나요?
아니요. 화면에 보이는 도움말 링크만 숨겨질 뿐이에요. 이메일 서비스 설정이나 기능은 바뀌거나 제한되지 않아요.

### 사용자 지정 CSS는 어디에 붙여 넣나요?
**설정 > 에이전시 설정**에서 아래로 스크롤해 **사용자 지정 CSS** 필드를 찾고, 그 안에 코드를 붙여 넣으세요.

### 서브 계정 하나에만 적용되나요, 에이전시 전체에 적용되나요?
에이전시 수준에서 설정한 사용자 지정 CSS는 에이전시의 고객 화면 전체에 적용돼요. 더 좁은 범위에만 적용하고 싶다면 해당 설정 위치를 따로 확인해 보세요.

### 숨긴 링크를 다시 보이게 하려면 어떻게 하나요?
**사용자 지정 CSS** 필드에서 `.hl__smtp-help-doc` 코드를 지우고 저장하세요. 링크가 다시 나타나요.

### 다른 요소도 같은 방법으로 숨길 수 있나요?
네. 바뀌지 않는 CSS 클래스가 있는 요소라면 같은 방법으로 숨길 수 있어요. **사용자 지정 CSS** 필드에서 해당 클래스에 `display: none;`을 지정하세요.

### 나중에 업데이트되면 이 코드가 작동하지 않을 수도 있나요?
이후 릴리스에서 클래스 이름이 바뀌면 그럴 수 있어요. 업데이트 후 링크가 갑자기 다시 보이면 클래스 이름이 바뀌었는지 확인해 보세요.
