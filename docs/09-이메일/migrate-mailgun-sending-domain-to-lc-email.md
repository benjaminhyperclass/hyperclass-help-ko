# Mailgun 전송 도메인을 하이퍼클래스 이메일로 옮기기

Mailgun에 만들어 둔 전송 도메인을 하이퍼클래스 이메일로 옮기는 방법을 안내해요. Mailgun에서 도메인을 삭제한 뒤 같은 도메인을 하이퍼클래스에 추가하면, 이후 모든 이메일이 하이퍼클래스를 통해 전송돼요.

## 이 문서에서 다루는 내용

Mailgun에 전송 도메인을 설정해 두었다면, 다음 순서로 하이퍼클래스 이메일로 옮길 수 있어요. 먼저 Mailgun에서 도메인을 삭제하고, 같은 도메인을 하이퍼클래스에 추가해요.

기존 DNS 레코드(TXT, MX, CNAME)는 그대로 두어도 돼요. 이 레코드들은 Mailgun 인프라를 가리키는데, 하이퍼클래스 이메일도 내부적으로 같은 인프라를 쓰기 때문이에요.

## Mailgun에서 도메인 삭제하기

1. Mailgun 계정에 로그인한 뒤 **Sending**(전송) **> Domain Settings**(도메인 설정)로 이동하세요.
2. 오른쪽 위 드롭다운에서 옮기려는 도메인이 선택되어 있는지 확인하세요.

   ![Mailgun Sending > Domain Settings 화면에서 오른쪽 위 드롭다운에 도메인이 선택된 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48280266614/original/jhvqfR085Lovd-qZJ6jhxAiNkHrOPcvx4g.png?1675802157)

3. **Domain Settings** 페이지 맨 아래로 스크롤해서 **Delete**(삭제)를 클릭하세요.
4. 확인 창이 나타나면 삭제를 확인하세요.

   ![Mailgun Domain Settings 맨 아래에 있는 Delete 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48280266633/original/v58M1hzv9FXxvGVERJ2ZR4_EFX0qCl162A.png?1675802167)

{% hint style="warning" %}
Mailgun에서 도메인을 삭제하면 되돌릴 수 없어요. 이 도메인에만 연결된 API 키와 SMTP 자격 증명도 작동하지 않게 돼요. 삭제하기 전에 더 이상 Mailgun으로 이메일을 보내지 않는지 꼭 확인하세요.
{% endhint %}

## 하이퍼클래스에 도메인 추가하기

Mailgun에서 도메인을 삭제했다면, 같은 도메인을 전용 전송 도메인으로 하이퍼클래스에 추가해요. 일반적인 전용 도메인 설정 방법과 같아요.

1. 서브 계정에서 **설정 > 이메일 서비스 > 전용 도메인**으로 이동하세요.
2. **도메인 추가**를 클릭하세요.
3. 방금 Mailgun에서 삭제한 도메인 이름을 똑같이 입력하세요.
4. **Add & Verify**(추가 및 인증)를 클릭하세요. 확인해야 할 DNS 레코드가 화면에 표시돼요.
5. **Verify DNS Settings**(DNS 설정 인증)를 클릭하세요.

{% hint style="info" %}
하이퍼클래스 이메일도 Mailgun 인프라를 쓰기 때문에, 기존 DNS 레코드(SPF TXT, DKIM TXT, MX, CNAME)는 바꾸지 않아도 될 수 있어요. **Verify DNS Settings**를 클릭하면 이미 올바른 레코드에 초록색 체크 표시가 나타나요.
{% endhint %}

## 마무리

모든 DNS 레코드에 초록색 체크 표시가 나타나면 도메인 이전이 끝난 거예요. **대화**에서 테스트 이메일을 보내 정상적으로 전송되는지 확인해 보세요.

## 자주 묻는 질문

### 하이퍼클래스로 도메인을 옮긴 뒤에 DNS 레코드를 수정해야 하나요?
대부분 수정하지 않아도 돼요. 하이퍼클래스 이메일은 같은 Mailgun 인프라를 쓰기 때문에, Mailgun용으로 추가해 둔 SPF, DKIM, MX, CNAME 레코드를 그대로 쓸 수 있어요. 하이퍼클래스에 도메인을 추가하고 **Verify DNS Settings**를 클릭하면, 이미 올바른 레코드에는 바로 초록색 체크 표시가 나타나요.

### Mailgun에서 도메인을 삭제하면 이메일 기록이나 발송 평판이 사라지나요?
Mailgun 대시보드에 저장된 이메일 로그는 도메인을 삭제하면 더 이상 볼 수 없어요. 하지만 수신 메일 서버가 보는 도메인의 외부 발송 평판은 Mailgun 계정이 아니라 DNS 레코드와 IP 주소에 연결되어 있어요. 그래서 하이퍼클래스 이메일로 바꿔도 전송 성공률(deliverability) 평가가 초기화되지는 않아요.

### 도메인을 삭제할 때 Mailgun에서 대기 중이거나 전송 중이던 이메일은 어떻게 되나요?
삭제하기 전에 Mailgun이 이미 접수해서 대기열에 넣은 이메일은 그대로 전달될 거예요. 그래도 만약을 위해 Mailgun에서 보내던 이메일을 모두 마무리하고, 대기열이 비어 있는지 확인한 뒤에 도메인을 삭제하세요.

### 옮긴 뒤에 같은 도메인을 여러 서브 계정에서 쓸 수 있나요?
전용 전송 도메인은 서브 계정마다 따로 설정해요. 필요하다면 같은 도메인을 두 개 이상의 서브 계정에 추가할 수 있어요. 다만 이렇게 하면 계정별로 발송 평판이 관리되는 방식에 영향을 줄 수 있으니 유의하세요.

### 마음이 바뀌면 도메인을 다시 Mailgun으로 옮길 수 있나요?
네, 가능해요. 과정을 거꾸로 하면 돼요. 하이퍼클래스의 전용 도메인 설정에서 도메인을 제거하고, Mailgun에서 다시 추가하세요. DNS 레코드는 그대로 남아 있을 테니 Mailgun에서 다시 인증하면 돼요. 그동안 하이퍼클래스로 보낸 이메일은 Mailgun 로그에 나타나지 않아요.

### 도메인을 옮기는 동안 이메일 전송이 중단되나요?
Mailgun에서 도메인을 삭제하고 나서 하이퍼클래스에서 인증을 마칠 때까지 잠깐 동안은 이 도메인으로 보내는 이메일이 전송되지 않을 수 있어요. 이 시간을 줄이려면 Mailgun에서 삭제하자마자 바로 하이퍼클래스의 전용 도메인 설정을 이어서 할 수 있게 준비해 두세요. 전체 과정은 보통 몇 분이면 끝나요.

### 하이퍼클래스 이메일로 옮긴 뒤에도 Mailgun 계정이 필요한가요?
아니요. 모든 전송 도메인을 하이퍼클래스 이메일로 옮기고 인증까지 마쳤다면, 하이퍼클래스를 통한 이메일 전송을 위해 Mailgun 계정을 따로 유지할 필요가 없어요. 이메일 인프라는 하이퍼클래스 이메일이 직접 처리해요.
