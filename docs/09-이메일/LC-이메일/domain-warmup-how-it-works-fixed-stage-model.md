# 도메인 워밍업: 고정 단계 모델의 작동 방식

하이퍼클래스의 고정 단계 워밍업 모델이 발신자 평판을 쌓고 이메일 전달률을 높이는 과정을 설명해요. 새 도메인과 기존 도메인 모두에 해당하며, 워밍업을 안전하게 진행하고 싶을 때 참고하세요.

## 도메인 워밍업이란?

도메인 워밍업은 하루 이메일 발송량을 조금씩 늘려 가며, Gmail·Outlook·Yahoo 같은 메일 서비스에서 신뢰받는 발신자 평판을 쌓는 과정이에요.

워밍업 없이 새 도메인을 쓰면 이런 일이 생기기 쉬워요.

- 스팸으로 분류돼요.
- 반송률이나 스팸 신고율이 높아져요.
- 이메일 발송이 차단되거나 지연돼요.

하이퍼클래스는 이 과정을 자동으로 진행해서 신뢰를 쌓고 전달률을 높여 줘요.

## 워밍업 모델은 이렇게 작동해요

이 시스템은 고정 단계로 조금씩 발송량을 늘리는 방식이에요.

- 단계마다 하루 발송 한도가 정해져 있어요.
- 현재 단계의 하루 한도를 모두 채워야 다음 단계로 넘어가요.
- 하루 한도를 채우지 못하면 도메인은 같은 단계에 머물러요.
- 시간당 발송 한도는 없어요.
- 진행 상황이 기록되려면 워밍업 중인 도메인으로 이메일을 보내야 해요.

단계별 한도는 다음과 같아요.

| 단계 | 일일 한도 |
| --- | --- |
| 1 | 1,000 |
| 2 | 2,500 |
| 3 | 5,000 |
| 4 | 6,500 |
| 5 | 8,000 |
| 6 | 10,000 |
| 7 | 14,000 |
| 8 | 20,000 |
| 9 | 25,000 |
| 10 | 35,000 |
| 11 | 50,000 |
| 12 | 80,000 |
| 13 | 125,000 |
| 14 | 175,000 |
| 15 | 250,000 |

{% hint style="info" %}
현재 단계의 하루 한도에 도달해도 발송이 막히지는 않아요. 이메일은 계속 나가요. 한도를 모두 채우면 다음 단계로 넘어갈 뿐이에요.
{% endhint %}

## 워밍업은 언제 시작되나요?

- 새로 만든 도메인: 도메인을 만들고 인증하면 워밍업이 자동으로 켜져요. 따로 할 일은 없어요.
- 기존 도메인: 워밍업을 직접 켜야 해요. 켜면 시스템이 과거 이메일 발송 기록과 Google Postmaster 평판 데이터(연동한 경우)를 자동으로 분석해요.

분석 결과를 바탕으로 가장 알맞은 시작 단계를 추천해 줘요. 덕분에 워밍업을 무리 없이 진행할 수 있어요.

## 누가 이메일 워밍업을 쓸 수 있고, 어떻게 켜나요?

전용 도메인을 쓰는 에이전시와 서브 계정 모두 이메일 워밍업을 쓸 수 있어요.

### 에이전시 도메인

에이전시 도메인의 워밍업을 켜려면 다음과 같이 하세요. 에이전시 관리자만 할 수 있어요.

1. **에이전시 설정**으로 이동하세요.
2. **이메일 서비스**를 클릭한 다음 **SMTP 서비스**를 선택하세요.
3. **Dedicated Domain and IP**(전용 도메인 및 IP) 탭으로 이동하세요.
4. 도메인을 선택하고 **Start Warmup**(워밍업 시작)을 클릭하세요.

### 서브 계정 도메인

서브 계정 도메인의 워밍업을 켜려면 다음과 같이 하세요.

1. **서브 계정 설정**으로 이동하세요.
2. **이메일 서비스**를 클릭한 다음 **SMTP 서비스**를 선택하세요.
3. **Dedicated Domain and IP** 탭으로 이동하세요.
4. 도메인을 선택하고 **Start Warmup**을 클릭하세요.

## Google Postmaster 연동 (권장)

도메인을 Google Postmaster Tools와 연동하면 이메일 전달과 관련된 주요 데이터를 볼 수 있어요.

- 도메인 평판(High, Medium, Low, Bad)
- 스팸 신고율
- 인증 상태
- 발송 및 오류 지표

Google Postmaster가 아직 연결되지 않았거나 데이터가 없으면, 도메인 대시보드에서 알려 주고 설정 방법을 안내해 줘요.

## 워밍업을 성공적으로 마치는 방법

- 매일 꾸준히 이메일을 보내세요.
- 인증된 수신 동의 연락처 목록을 쓰세요.
- 발송량이 갑자기 늘어나지 않게 하세요.
- 캠페인 중간에 발신 도메인을 바꾸지 마세요.
- 이후 발송 제한을 피하려면 하루 워밍업 한도를 지키세요.

## 워밍업은 언제 끝나나요?

도메인이 15단계(하루 250,000통)에 도달하면 워밍업이 끝나요. 이때 도메인 대시보드에 "Warmup Complete" 라벨이 표시되고, 본격적인 대량 발송이 가능해져요.

## 자주 묻는 질문

### 도메인 워밍업은 꼭 해야 하나요? 건너뛸 수 있나요?

새로 만든 도메인은 워밍업이 자동으로 진행되고, 기존 도메인도 워밍업을 강력히 권장해요. 워밍업을 건너뛰고 처음부터 최대 발송량으로 보내면 스팸 분류, 차단, 발송 지연 위험이 크게 높아져요.

### 워밍업 중에 매일 이메일을 보내지 않으면 어떻게 되나요?

도메인이 현재 단계에 그대로 머물러요. 하루 한도를 모두 채워야 다음 단계로 넘어가기 때문에, 발송하지 않은 날은 진행이 멈출 뿐이에요. 단계가 초기화되거나 불이익을 받지는 않아요.

### 더 높은 워밍업 단계로 직접 건너뛸 수 있나요?

아니요. 단계는 하루 발송량에 따라 자동으로 올라가요. 예외는 기존 도메인에서 워밍업을 켤 때예요. 이때는 과거 발송 기록과 Google Postmaster 데이터에 따라 더 높은 단계에서 시작할 수 있어요.

### 워밍업은 공유 도메인에도 적용되나요, 전용 도메인에만 적용되나요?

에이전시와 서브 계정 모두 전용 도메인에만 적용돼요. 공유 발신 도메인은 이미 평판이 쌓여 있어서 고정 단계 모델을 거치지 않아요.

### 워밍업을 시작한 뒤에 Google Postmaster를 연동하면 어떻게 되나요?

연동한 시점부터 도메인 대시보드에 평판, 스팸 신고율, 인증, 발송 데이터가 들어오기 시작해요. 현재 단계가 소급해서 바뀌지는 않지만, 남은 워밍업 기간 동안 상태를 더 잘 파악할 수 있어요.

### 도메인을 워밍업하는 동안 연락처가 달라진 점을 느끼나요?

아니요. 워밍업은 다음 단계로 넘어가기 전까지 도메인이 보낼 수 있는 하루 발송량 기준에만 영향을 줘요. 이메일이 어떻게 보이는지, 개별 수신자에게 어떻게 전달되는지는 달라지지 않아요.
