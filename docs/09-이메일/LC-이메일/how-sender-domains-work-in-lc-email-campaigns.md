# 하이퍼클래스 이메일 캠페인의 발신 도메인 설정 이해하기

캠페인마다 알맞은 발신 도메인을 고르고, 발신자 이메일이 규정에 맞는지 확인해 발신자 평판을 지키는 방법을 설명해요. 이메일 캠페인을 보내거나 예약 발송하기 전에 발신 도메인이 어떻게 동작하는지 알고 싶을 때 읽어 보세요.

## 개요

발신 도메인은 이메일 캠페인을 어떤 도메인으로 보낼지 정하고, 발신자 이메일 주소가 유효하고 규정에 맞는지도 확인해요. 발신 도메인을 알맞게 고르면 캠페인 발송 실패를 막고, 도메인 평판을 지키고, 받은편지함 도달률을 높일 수 있어요.

{% hint style="info" %}
발신 도메인 동작은 하이퍼클래스 이메일을 사용하는 서브 계정에만 적용돼요. SMTP로 이메일을 보내는 경우에는 기존 방식 그대로 동작해요.
{% endhint %}

## 발신 도메인 설정이란?

발신 도메인 설정은 **마케팅 > 이메일 > 캠페인**에서 이메일 캠페인을 보내거나 예약 발송할 때 쓸 수 있어요. 캠페인을 어떤 도메인으로 보낼지 정하고, 발신자 이메일이 그 도메인과 일치하는지 확인해 줘요.

이메일 서비스 제공업체는 메시지를 올바르게 인증하기 위해 이 일치 여부를 확인해요. 발송 도메인과 발신자 이메일이 맞지 않으면 캠페인이 발송되지 않거나 스팸으로 분류될 수 있어요. 발신 도메인 설정을 쓰면 캠페인마다 알맞은 발송 도메인을 고르고, 발신자 이메일을 실시간으로 확인할 수 있어요. 도메인 규정을 충족하지 못하면 캠페인이 발송되지 않도록 막아 주기도 해요.

이렇게 캠페인별로 직접 정하면 전송 문제를 줄이고 발송 안정성을 높일 수 있어요. 캠페인을 보내거나 예약 발송하고 나면, 선택한 발신 도메인은 그 캠페인에 고정돼요.

## 발신 도메인 설정의 주요 장점

- 발송 실패 감소: 발신 도메인이 맞지 않거나 규정에 어긋난 채로 캠페인이 발송되는 것을 막아, 발송 시점에 생기는 오류를 줄여요.
- 도달률 향상: 도메인이 올바르게 일치해서 이메일 서비스 제공업체가 메시지를 인증하기 쉽고, 받은편지함 도달률도 높아져요.
- 캠페인별 설정: 기본 도메인 하나에만 의존하지 않고, 캠페인마다 가장 알맞은 발송 도메인을 고를 수 있어요.
- 자동 안전장치: 지원되는 발신자 이메일은 자동으로 조정하고, 직접 조치가 필요하면 경고를 분명하게 보여 줘요.
- 한눈에 확인: 실시간으로 검증하고 도메인 설정 화면으로 바로 이동할 수 있어서, 문제를 쉽게 찾아 해결할 수 있어요.

## 상황별 발신 도메인 동작

### 공유 도메인(에이전시 또는 플랫폼)

캠페인에 공유 발송 도메인을 쓰면 Gmail, Yahoo 같은 공개 이메일 주소도 사용할 수 있어요. 하이퍼클래스가 규정에 맞게 발신자 이메일을 내부적으로 자동 조정하기 때문에, 별도 조치 없이 캠페인이 정상 발송돼요.

### 전용 도메인이 하나인 경우

서브 계정에 인증된 전용 도메인이 하나 있으면, 보내기 또는 예약 단계에서 그 도메인이 자동으로 선택돼요. 발신자 이메일은 이 도메인과 일치해야 해요. 발송 전에 실시간 검증으로 규정에 맞는지 확인해 줘요.

### 전용 도메인이 여러 개인 경우

인증된 도메인이 여러 개면 캠페인에 쓸 도메인을 직접 고르거나 **모든 도메인**을 선택할 수 있어요. **모든 도메인**을 선택하면 하이퍼클래스가 내부 규칙에 따라 발송 가능한 도메인을 돌아가며 사용해요. 대량 발송에서도 도달률을 관리하는 데 도움이 돼요.

아래 표에서 자주 있는 상황별 동작을 한눈에 볼 수 있어요.

| 상황 | 사용자가 입력하는 값 | 동작 |
| --- | --- | --- |
| 공유 도메인 + 공개 이메일 | name@gmail.com | 규정에 맞게 이메일이 자동 변환돼요 |
| 전용 도메인 1개 | 일치하는 도메인의 이메일 | 도메인이 자동 선택되고 검증돼요 |
| 도메인 여러 개(하나 선택) | 도메인 하나 선택 | 선택한 도메인만 사용해요 |
| 도메인 여러 개(**모든 도메인**) | marketing 입력 | 도메인이 자동으로 순환해요 |
| 전용 도메인 불일치 | 도메인 ≠ 발신자 이메일 | 발송이 차단돼요 |
| 도메인 미인증 | DNS 설정 미완료 | 경고와 함께 해결 링크가 표시돼요 |

## 캠페인의 발신 도메인 설정하기

발신 도메인은 이메일 캠페인을 보내거나 예약 발송하는 과정에서 자연스럽게 선택해요. 미리 켜거나 따로 설정할 항목은 없어요.

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.

   ![마케팅, 이메일, 캠페인으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062541657/original/ze0sRG7VX2OdNL3Lnn58GbebG9a5f9CBlA.png?1768304730)

2. 새 캠페인을 열거나 기존 초안을 여세요.

   ![새 캠페인 또는 기존 초안을 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062541708/original/uvGDXxJ6OmcIoJVp0Fm0hEi5H3TaIKdGhg.png?1768304758)

3. 이메일 캠페인 빌더에서 **보내기** 또는 **일정**을 클릭해 **캠페인 상세 정보**를 확인하세요.

   ![발송 또는 예약 전에 캠페인 상세 정보를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062541742/original/cVjtJTns0eY4IIlmYzVj8Nl-4ScM1SJPFg.png?1768304799)

4. **Sender Details**(발신자 정보) 섹션에서 **발신자 이름**과 **발신자 이메일**이 맞는지 확인하세요.

   ![발신자 이름과 발신자 이메일이 보이는 Sender Details 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062542511/original/yUhh4H19Wi1FRvcYcSN93HpXGeQJx8F8Iw.png?1768305076)

5. **발신 도메인** 드롭다운을 열어 서브 계정에서 쓸 수 있는 발송 옵션을 확인하세요. 이메일 도메인을 어떻게 설정했는지에 따라 보이는 옵션이 달라요.
   - 공유 도메인을 쓰면 공개 이메일 주소를 사용할 수 있고, 규정에 맞게 자동으로 조정돼요.
   - 전용 도메인이 하나 있으면 그 도메인이 미리 선택되어 있고, 발신자 이메일이 이 도메인과 일치해야 해요.
   - 전용 도메인이 여러 개면 도메인 하나를 고르거나 **모든 도메인**을 선택해요. **모든 도메인**을 선택하면 하이퍼클래스가 발송 가능한 도메인을 돌아가며 사용해서 도달률을 관리해요.

   ![사용 가능한 발송 옵션이 보이는 발신 도메인 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062544375/original/xpDMY7KgIttDxgOURKmFGCDmFjfgTAx-uQ.png?1768305964)

6. 경고나 오류가 나타나면 **Review Domain Configuration**(도메인 설정 검토) 링크를 눌러 도메인 인증, 워밍업 상태, IP 할당 등을 확인하세요.

   ![Review Domain Configuration 링크](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062543611/original/BSUw9vRW7fKWi1HL_x50G8SVAKLSoIprtA.png?1768305582)

### 경고와 오류의 차이

**경고**는 발생할 수 있는 문제를 알려 줘요. 예를 들어 발신자 이메일과 발신 도메인이 맞지 않을 때 나타나요. 이때도 캠페인은 보낼 수 있지만, 스팸으로 분류될 위험을 줄이려면 도메인을 맞추는 것이 좋아요. **오류**는 캠페인 발송을 막는 문제예요. 문제를 해결해야 캠페인을 보낼 수 있어요.

![발신 도메인 설정의 경고와 오류 메시지 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062565977/original/7dUXgMQxCCQeFiv1rW-g-rt7g95y4W-0ZQ.png?1768316471)

### 마무리

모든 항목에 문제가 없으면 캠페인 발송이나 예약을 마무리하세요. 선택한 발신 도메인은 캠페인을 보내거나 예약하는 시점에 그 캠페인에 고정돼요.

## 자주 묻는 질문

### 캠페인을 보낼 수 있는데 왜 경고가 표시되나요?
발신자 이메일과 도메인이 맞지 않는 등 도달률에 문제가 생길 수 있을 때 경고가 나타나요. 캠페인은 보낼 수 있지만, 스팸으로 분류되는 것을 피하려면 도메인을 맞추는 것이 좋아요.

### 발신 도메인이 인증되지 않았거나 워밍업이 안 됐다면 어떻게 되나요?
도메인이 인증되고 준비 요건을 충족해야 캠페인을 보낼 수 있어요. 필요한 설정을 마칠 수 있도록 경고나 오류 메시지가 안내해 줘요.

### 발신 도메인과 다른 회신 주소를 쓸 수 있나요?
네. 회신 주소는 발신 도메인과 상관없이 정할 수 있고, 유효한 이메일 주소라면 어떤 주소든 쓸 수 있어요.

### "모든 도메인"을 선택하면 이메일 도달률에 영향이 있나요?
아니요. 이 옵션을 선택하면 인증되고 워밍업을 마친 도메인에서만 이메일을 보내요. 내부 규칙에 따라 도메인을 돌아가며 사용해서 평판을 관리하고 도달률을 유지하는 데 도움이 돼요.

### 발신 도메인 동작이 SMTP 발송에도 적용되나요?
아니요. 발신 도메인 설정은 하이퍼클래스 이메일을 사용하는 서브 계정에만 적용돼요. 사용자 지정 SMTP 연결로 보내는 경우에는 기존 SMTP 방식과 도메인 규칙이 그대로 적용돼요.

### 캠페인을 예약한 뒤에 발신 도메인을 바꿀 수 있나요?
아니요. 캠페인을 보내거나 예약하면 발신 도메인이 그 캠페인에 고정돼요. 다른 도메인을 쓰려면 예약하기 전에 초안을 수정하거나, 캠페인을 복제해서 새 도메인을 선택하세요.
