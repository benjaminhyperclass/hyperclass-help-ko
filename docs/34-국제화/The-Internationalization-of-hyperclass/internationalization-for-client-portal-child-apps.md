# 클라이언트 포탈·차일드 앱 표시 언어 바꾸기

클라이언트 포탈과 차일드 앱(Child App)에서 화면 언어를 바꾸는 방법을 안내해요. 웹과 모바일 모두 여러 언어를 지원하므로, 사용자가 원하는 언어로 쓸 수 있어요.

## 언어 국제화란?

언어 국제화를 쓰면 사용자가 원하는 언어로 클라이언트 포탈과 차일드 앱을 이용할 수 있어요. 영어를 쓰지 않는 사용자도 더 편하게 쓸 수 있고, 지역에 맞는 화면을 볼 수 있어요.

클라이언트 포탈 관리자는 모든 포탈 사용자에게 적용되는 기본 언어를 정할 수 있어요. 사용자는 웹과 모바일 모두에서 자기 계정 설정으로 기본 언어를 바꿀 수 있어요. 관리자와 사용자 모두 언어를 선택하지 않으면 포탈은 영어로 표시돼요.

## 언어 국제화의 장점

언어를 선택할 수 있으면 전 세계 사용자가 더 쉽게 쓸 수 있어요.

- 클라이언트 포탈과 차일드 앱의 웹·모바일 버전에서 모두 쓸 수 있어요.
- 여러 지역의 12개 언어를 지원해요.
- 관리자가 모든 클라이언트 포탈 사용자의 기본 언어를 정할 수 있어요.
- 영어를 쓰지 않는 사용자도 더 쉽게 쓸 수 있어요.
- 언어는 빠르게 바꿀 수 있고, 사용자별로 적용돼요.
- 클라이언트가 모국어로 설정을 관리할 수 있어요.
- 언어를 선택하지 않으면 영어로 표시돼요.

## 기본 언어 설정하기(관리자)

모든 클라이언트 포탈 사용자에게 로그인 페이지와 포탈 화면을 같은 언어로 보여 주고 싶을 때 사용하세요.

1. **멤버십 > 클라이언트 포탈 > 설정 > 언어 설정**으로 이동하세요.

## 웹에서 언어 바꾸기(사용자·클라이언트)

클라이언트 포탈에 로그인한 뒤 언어를 바꿀 수 있어요. **멤버십 > 클라이언트 포탈**로 이동해 포탈에 로그인하거나, **클라이언트 포탈 URL**로 바로 로그인하세요.

![클라이언트 포탈에 로그인하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046796710/original/kG2AXbYNNnknefEyR0HqZ4ELcIXgx1kvqg.gif?1747483477)

**언어를 바꾸는 순서**

1. 오른쪽 위에 있는 로고를 클릭한 뒤 **Manage your Account**(내 계정 관리)를 클릭하세요.

   ![로고 메뉴에서 계정 관리 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046796853/original/tfJGTmozjpQ4SGxhxOQfSfIbWfQTX_PuiQ.png?1747483819)
2. **Manage Account**(계정 관리) 화면에서 **언어 설정**을 선택하고, 드롭다운 메뉴에서 원하는 언어를 고르세요.

   ![언어 설정에서 언어 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046796976/original/gRSlkZmvSH6aD1Gnd8W8KvIufLTYJVFPIQ.gif?1747484034)

## 모바일 앱에서 언어 바꾸기

모바일 기기로 앱에 접속한 사용자도 몇 번만 탭하면 언어를 바꿀 수 있어요.

**모바일에서 언어를 바꾸는 순서**

1. 하단 내비게이션 바에서 **프로필**을 탭하세요.
2. **설정**으로 이동하세요.
3. **언어 설정**을 탭하세요.
4. 목록에서 원하는 언어를 선택하세요.
5. **저장**을 탭하면 변경한 언어가 적용돼요.

## 지원 언어

현재 웹과 모바일에서 아래 언어를 지원해요.

| 언어 | 지역 |
| --- | --- |
| 독일어 | DE |
| 스페인어 | ES |
| 프랑스어(캐나다) | CA |
| 프랑스어(프랑스) | FR |
| 네덜란드어 | NL |
| 포르투갈어(포르투갈) | PT |
| 포르투갈어(브라질) | BR |
| 이탈리아어 | IT |
| 스웨덴어 | SE |
| 핀란드어 | FI |
| 노르웨이어 | NO |

{% hint style="info" %}
영어가 기본 언어예요. 다른 언어를 선택하지 않으면 영어로 표시돼요.
{% endhint %}

## 자주 묻는 질문

### 언어를 바꾸면 바로 적용되나요?
네, 저장하면 새 언어가 바로 적용돼요.

### 언어를 여러 번 바꿀 수 있나요?
네, 언제든 언어 설정을 바꿀 수 있어요.

### 일부 기능이 번역되지 않았다면 어떻게 표시되나요?
번역이 없는 부분은 영어로 표시돼요.

### 새 사용자 모두에게 적용할 기본 언어를 정할 수 있나요?
네, **멤버십 > 클라이언트 포탈 > 설정 > 언어 설정**으로 이동해 언어를 선택한 뒤 **저장**을 클릭하세요. 이 기본 언어는 모든 사용자의 /login 페이지와 클라이언트 포탈 웹 화면에 적용돼요.
