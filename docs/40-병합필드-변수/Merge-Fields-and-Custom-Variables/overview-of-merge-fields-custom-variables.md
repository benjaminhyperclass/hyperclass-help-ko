# 병합 필드와 커스텀 변수 한눈에 보기

병합 필드(Merge Fields)와 커스텀 변수가 무엇인지 설명하는 문서예요. 커스텀 필드, 커스텀 값, 사용자 지정 개체, 커스텀 링크(트리거 링크, 결제 링크)의 종류와 쓰임새를 알아보고, 이를 활용해 메시지를 개인화하고 워크플로우를 자동화하는 방법을 소개해요.

## 병합 필드와 커스텀 변수란?

병합 필드와 커스텀 변수는 개인화된 정보를 자동으로 넣어 주는 자리 표시자예요. 병합 필드는 `{{something.here}}`처럼 생겼어요. CRM이나 다른 모듈의 데이터를 가져와 병합 필드 자리에 채워 주기 때문에, 메시지를 자동으로 개인화할 수 있어요.

연락처 기반 워크플로우를 만들 때는 변수 선택기에서 연락처 필드와 함께 회사 필드도 고를 수 있어요. 연락처가 회사 레코드와 연결되어 있으면 워크플로우 단계와 조건에서 회사 정보(예: 회사명, 전화번호, 이메일, 웹사이트, 주소)를 가져올 수 있어요. 연락처가 회사와 연결되어 있지 않으면 회사 값은 비어 있는 상태로 표시돼요.

병합 필드와 커스텀 변수는 다음과 같이 나뉘어요.

- **표준 필드**: 연락처 이름, 예약 시간, 사용자 정보처럼 기본으로 제공되며 바꿀 수 없는 필드예요.
- **커스텀 필드**: 연락처와 기회에 직접 만들어 쓰는 필드예요.
- **커스텀 값**: 템플릿과 워크플로우에서 반복해서 쓸 수 있는 값이에요.
- **사용자 지정 개체**: 더 복잡한 데이터를 관리하기 위해 직접 만드는 데이터 구조예요.
- **트리거 링크**: 클릭하면 워크플로우와 캠페인에서 자동화 작업을 실행시키는 특별한 링크예요.
- **결제 링크**: 고객이 상품이나 서비스를 바로 결제할 수 있게 해 주는 링크예요.

## 병합 필드와 커스텀 변수를 쓰면 좋은 점

- 메시지 개인화: 이메일과 SMS에 연락처 이름, 날짜 같은 정보를 자동으로 넣어요.
- 업무 자동화: 워크플로우에서 병합 필드를 쓰면 시간을 아끼고 수작업을 줄일 수 있어요.
- 데이터 일관성 유지: 메시지마다 정확하고 최신인 정보를 쓸 수 있어요.
- 반복 작업 간소화: 커스텀 값과 트리거 링크를 재사용해 효율을 높여요.

## 비어 있는 필드의 기본값(대체값)

지금은 변수가 비어 있을 때 대신 채워 넣을 기본값(대체값)을 지원하지 않아요. 값이 없으면 병합 필드가 빈 칸으로 바뀌어요.

대안으로 콘텐츠 블록을 보이거나 숨기는 방법이 있어요.

예를 들어 **이메일 빌더**에서는 **Conditional Send**(조건부 발송)를 써서 특정 조건일 때만 콘텐츠 블록이 보이게 할 수 있어요. `first_name` 병합 필드가 들어간 블록(`Hi {{contact.first_name}},`)은 `first_name`이 비어 있지 않을 때 발송되게 설정해요. 병합 필드가 없는 블록(기본값 역할을 하는 "Hi Friend," 같은 문구)은 `first_name`이 비어 있을 때 발송되게 설정해요. 이렇게 하면 기본값을 넣은 것과 비슷한 효과를 낼 수 있어요.

## 표준 필드

표준 필드는 모든 계정에 기본으로 들어 있는 병합 필드예요. 연락처 이름, 이메일 주소, 전화번호, 예약 정보(예: 날짜와 시간) 같은 기본 데이터를 담고 있어요. **커스텀 필드**와 달리 기본으로 내장되어 있어서 수정하거나 삭제할 수 없어요. 표준 필드는 이렇게 활용할 수 있어요.

- 연락처 이름(First Name): 연락처의 이름이에요.
- 연락처 이메일: 연락처의 이메일 주소예요.
- 예약 날짜 및 시간: 예약된 날짜와 시간이에요.
- 사용자 전체 이름(User Full Name): 담당 사용자의 전체 이름이에요.
- 회사명: 내 사업체나 조직의 이름이에요.

![표준 필드를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038180066/original/1U_pnxGaeBpxPQ0iwghG44A_fA39DpxSSQ.gif?1733951039)

{% hint style="warning" %}
표준 병합 필드 목록을 확인할 수 있어요. 다만 목록에 일부 필드가 빠져 있을 수 있으니 참고하세요.
{% endhint %}

## 커스텀 필드

연락처나 기회마다 다르게 저장하는, 사용자가 직접 정의하는 데이터예요. 생일이나 선호도 같은 개인화 정보를 저장해 두면 더 세밀하게 분류하고 소통할 수 있어요. 커스텀 필드는 이렇게 활용할 수 있어요.

- 고객 선호도: 선호하는 연락 방법(이메일, SMS, 전화) 등 고객의 관심사를 기록해요.
- 멤버십 정보: 골드, 실버, 플래티넘 같은 멤버십 등급을 저장해 등급별 프로모션에 활용해요.
- 관심 상품: 고객이 관심 있는 상품이나 서비스를 기록해 맞춤 후속 연락에 활용해요.
- 이벤트 참석 정보: 이벤트 등록·참석 내역을 남겨 초대장이나 후속 메시지를 개인화해요.
- 담당 매니저 배정: 해당 연락처를 맡은 담당 매니저 이름을 저장해요.
- 계약 갱신일: 계약 만료일이나 갱신일을 기록해 알맞은 때에 알림을 보내요.
- 리드 출처: 리드가 어디서 왔는지(예: Facebook, Google Ads, 추천) 기록해 마케팅 성과를 추적해요.

## 변수 선택기의 추가 워크플로우 필드

워크플로우의 병합 필드와 커스텀 값에는 저장해 둔 커스텀 값 외에 시스템에 내장된 필드도 포함될 수 있어요. 이제 병합 필드와 **If/Else**(조건 분기) 조건의 변수 선택기에서 워크플로우에 쓸 수 있는 필드가 더 늘었어요.

추가된 필드는 다음과 같아요.

- **Contact Engagement Score**(연락처 참여 점수)
- **Contact → Attribution Medium ID**(연락처 > 어트리뷰션 매체 ID)
- **Note created by (Name)**(메모 작성자 이름)
- **Task ID**(작업 ID)

이 필드들을 활용하면 참여도, 어트리뷰션, 메모 활동, 작업 상황에 따라 더 구체적인 자동화를 만들 수 있어요.

{% hint style="warning" %}
**중요**

일부 필드는 워크플로우에 해당 맥락이 있을 때만 나타나요. 예를 들어 **Task ID**는 작업과 관련된 워크플로우에서, **Note created by** (Name)은 메모와 관련된 워크플로우에서 나타나요. **Contact Engagement Score**는 서브 계정에서 참여 점수 기능(Engagement Scoring)을 켰을 때 쓸 수 있어요.
{% endhint %}

## 커스텀 값

회사 정보처럼 바뀌지 않는 정보를 자리 표시자로 저장해 두고 재사용하는 기능이에요. 이메일 템플릿, 웹사이트, 퍼널, 워크플로우 등 CRM 곳곳에서 같은 정보를 일관되게 쓸 수 있고, 한 번만 고치면 모든 곳에 반영돼요. 커스텀 값은 이렇게 활용할 수 있어요.

- 회사 연락처 정보: 이메일 하단에 회사 전화번호, 이메일, 주소를 넣을 때 써요.
- 표준 맺음말: "Best Regards, [회사명]" 같은 마무리 인사를 추가해요.
- 웹사이트 링크: 웹사이트나 고객지원 페이지처럼 자주 쓰는 URL을 저장해 써요.
- 규정 준수 문구: 법적 고지나 규정 준수 문구를 모든 템플릿에 똑같이 넣어요.
- 브랜드 슬로건: 마케팅 자료와 캠페인에 회사 슬로건이나 태그라인을 넣어요.
- 시즌 인사말: 뉴스레터나 프로모션 메시지에 넣을 시즌 인사말을 만들어 두고 재사용해요.

## 사용자 지정 개체

사용자 지정 개체를 쓰면 기본 필드로는 담기 어려운 나만의 데이터 구조를 만들 수 있어요. 이렇게 활용할 수 있어요.

- 구독 플랜: 플랜 종류, 갱신일, 결제 주기 같은 구독 정보를 관리해요.
- 재고 관리: SKU 번호, 수량, 공급업체 정보 등 상품 재고를 관리하는 개체를 만들어요.
- 부동산 매물: 부동산 업체라면 위치, 가격, 특징 같은 매물 정보를 저장해요.
- 거래처 정보: 계약, 담당자, 결제 조건 등 거래처 정보를 관리해요.
- 예약 세부사항: 서비스 유형, 장소, 담당 직원처럼 더 자세한 예약 정보를 기록해요.

## 트리거 링크

트리거 링크는 클릭하면 워크플로우와 캠페인에서 특정 작업을 실행시키는 특별한 링크예요. 이렇게 활용할 수 있어요.

- 웨비나 등록: 웨비나 등록 링크를 보내고, 클릭하면 확인 이메일이 발송되게 해요.
- 설문 후속 조치: 설문 링크를 누른 사람을 추적해 감사 메시지를 자동으로 보내요.
- 콘텐츠 다운로드: 전자책이나 백서 같은 자료 다운로드 링크를 보내고 참여도를 추적해요.
- 업셀 기회: 상위 서비스 링크를 보내고, 클릭한 사람에게 후속 이메일을 보내요.
- 이벤트 초대: 초대 링크로 참석 여부를 확인하고, 클릭 여부에 따라 후속 조치를 자동화해요.
- 특별 혜택: 기간 한정 혜택 링크를 보내고, 클릭하지 않은 사람에게는 리마인더 이메일을 보내요.

## 결제 링크

결제 링크는 고객이 결제할 수 있는 링크를 만들어 상품이나 서비스를 판매하는 기능이에요. 이렇게 활용할 수 있어요.

- 이벤트 티켓: 워크숍이나 컨퍼런스 같은 이벤트 티켓 결제를 받아요.
- 구독 플랜: 정기 구독이나 멤버십용 링크를 만들어요.
- 상품 판매: 도서, 코스 같은 실물·디지털 상품의 결제 링크를 만들어요.
- 예약금 수령: 예약이나 예매의 예약금을 받아요.
- 기부: 기부나 모금 캠페인용 결제 링크를 만들어요.

## 자주 묻는 질문

### 커스텀 필드와 커스텀 값은 어떻게 다른가요?
커스텀 필드는 연락처나 기회마다 따로 저장하는 데이터예요. 생일이나 선호도처럼 사람마다 다른 정보를 담아요. 커스텀 값은 회사 정보나 표준 문구처럼 여러 메시지에서 똑같이 쓰는 정보를 저장해 두고 재사용하는 자리 표시자예요.

### 병합 필드가 작동하지 않거나 이상하게 표시돼요.
병합 필드 형식이 빠졌거나 잘못되었을 수 있어요. `{{contact.email}}`처럼 올바른 형식으로 입력했는지 확인하세요. 또 연락처나 사용자 레코드에 해당 필드의 데이터가 있는지도 확인하세요.

### 병합 필드는 대소문자를 구분하나요?
네, 구분해요. 예를 들어 `{{contact.name}}`은 작동하지만 `{{Contact.Name}}`은 작동하지 않아요.

### 병합 필드가 제대로 작동하는지 어떻게 테스트하나요?
나에게 테스트 이메일이나 SMS를 보내 보거나, 템플릿 편집기에서 미리보기로 확인해 보세요. 병합 필드가 올바른 데이터를 불러오는지 확인할 수 있어요.

### 병합 필드에 데이터가 없으면 어떻게 되나요?
해당하는 데이터가 없으면 병합 필드가 빈 칸으로 표시될 수 있어요. 결과가 좋으려면 연락처나 사용자 데이터를 항상 빠짐없이 채워 두세요.

### 커스텀 값을 수정하면 모든 템플릿에 반영되나요?
네, 설정에서 커스텀 값을 수정하면 그 값을 쓰는 모든 템플릿과 워크플로우에 자동으로 반영돼요. 그래서 정보를 일관되게 유지할 수 있어요.

### 표준 필드와 커스텀 필드는 어떻게 다른가요?
표준 필드는 CRM에 기본으로 내장된 필드예요. 커스텀 필드는 사용자가 직접 만들어서 연락처와 기회에 고유한 데이터를 저장하는 필드예요.

### 사용자 지정 개체는 커스텀 필드, 커스텀 값과 어떻게 다른가요?
사용자 지정 개체는 더 복잡한 관계와 데이터 관리를 지원하는 고급 데이터 구조예요. 커스텀 필드와 커스텀 값으로는 하기 어려운 일을 할 수 있어요.

### 커스텀 필드나 커스텀 값을 만들 수 있는 개수에 제한이 있나요?
엄격한 제한은 없어요. 다만 계정을 알아보기 쉽고 체계적으로 유지하려면 잘 관리하는 것이 좋아요.

### 웹사이트와 퍼널에서도 커스텀 값을 쓸 수 있나요?
네, 커스텀 값을 쓰면 웹사이트와 퍼널 전체에 일관된 정보를 동적으로 보여 줄 수 있고, 개인화도 더 잘할 수 있어요.

### 커스텀 값을 더 편하게 관리하려면 어떻게 정리하나요?
폴더로 나눠서 정리할 수 있어요. 목록이 길어져도 관리하고 찾기가 쉬워져요.

### 커스텀 필드나 커스텀 값을 한꺼번에 만들거나 업로드할 수 있나요?
현재는 일괄 생성이나 업로드를 지원하지 않아요. 하나씩 추가해야 해요.

### 표준 필드를 수정하거나 삭제할 수 있나요?
아니요, 표준 필드는 내장되어 있어서 수정하거나 삭제할 수 없어요. 대신 템플릿과 워크플로우에서 쓸지 말지는 직접 정할 수 있어요.
