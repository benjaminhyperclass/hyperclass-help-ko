# 모바일 앱에서 문서와 계약 사용하기

미리 만들어 둔 템플릿으로 모바일 앱에서 문서와 계약을 만들고 보낼 수 있어요. 이 문서에서는 모바일 앱에서 문서를 보내는 순서를 안내해요.

{% hint style="info" %}
모바일에서 문서와 계약을 쓰려면 먼저 하이퍼클래스 웹 플랫폼에서 템플릿을 저장해 두세요. 아직은 모바일 앱에서 문서를 처음부터 만들 수 없어요.
{% endhint %}

## 진행 순서

1. 모바일 앱을 열고 사용할 서브 계정을 선택하세요.
2. 왼쪽 메뉴에서 **문서 & 계약**을 누르세요.
3. **All documents**(전체 문서) 섹션에서 작성 중인 문서와 보낸 문서를 모두 볼 수 있어요. 저장해 둔 문서 템플릿을 보려면 **템플릿** 탭으로 전환하세요.
4. 화면 오른쪽 아래에 떠 있는 **+** 버튼을 눌러 새 연락처를 만드세요.5. 이 문서에 필요한 연락처를 추가하세요.
6. 보낼 문서 템플릿을 선택하세요.
7. 상품 카탈로그에서 상품을 추가하세요. 견적서가 필요 없다면 이 단계는 건너뛰어도 돼요.
8. 문서 내용을 확인하세요. 확인이 끝나면 이메일로 보내거나 고유 링크를 만들어 전달할 수 있어요.
