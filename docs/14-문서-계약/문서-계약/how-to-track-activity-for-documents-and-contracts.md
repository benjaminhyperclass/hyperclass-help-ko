# 문서·계약 활동 내역 확인하기

보낸 문서가 지금 어떤 상태인지, 문서를 열지 않고도 확인할 수 있어요. 문서 하나에서 일어난 전송, 편집, 열람, 서명 기록도 한곳에서 볼 수 있어요.

## 새로운 기능

- 문서를 보낸 뒤 옵션 메뉴에서 **히스토리 보기**를 클릭하면 전송, 편집, 열람, 서명까지 문서의 전체 히스토리를 볼 수 있어요.
- 연락처 아이콘 위에 마우스를 올리면 마지막으로 열람한 시간과 해당 사용자가 해야 할 작업을 볼 수 있어요.

## 사용 방법

1. **문서 & 계약**을 열어요.
2. 대시보드에서 상태를 확인하려는 문서의 줄로 이동해요.
3. 연락처 아이콘 위에 마우스를 올려요.
4. 문서에 참여한 모든 사용자의 마지막 작업 시간, 태그, 상태를 확인해요.
5. 자세한 로그를 보려면 점 3개 아이콘을 클릭한 다음 **히스토리 보기**를 클릭해요.
6. 오른쪽 패널에서 해당 문서에서 일어난 모든 작업을 확인해요.

## 이 기능을 만든 이유

- 문서를 매번 열지 않아도 지금 문서가 어떤 상태인지 바로 알 수 있어요.
- 필요한 정보를 바로 확인해서 문서를 마무리하는 데 도움이 돼요.

{% hint style="info" %}
마우스를 올렸을 때 나오는 창의 마지막 작업 시간은 지금부터 보내는 문서에만 표시돼요. 이전에 보낸 문서는 시간이 표시되지 않아요.
{% endhint %}
