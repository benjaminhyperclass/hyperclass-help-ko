# GDPR 준수와 데이터 개인정보 보호

하이퍼클래스가 GDPR(EU 일반 데이터 보호 규정)에 어떻게 대응하는지, 하이퍼클래스를 쓰는 고객은 어떤 책임을 지는지 설명하는 문서예요. 연락처의 개인정보를 하이퍼클래스에 저장하거나 처리하기 전에 읽어 보세요.

하이퍼클래스는 고객의 개인정보를 보호하기 위해 최선을 다하고 있어요. 하이퍼클래스는 EU Data Privacy Framework 인증을 받았어요. 플랫폼을 쓰는 동안 개인 데이터의 보안과 개인정보를 지키겠다는 약속을 이어 가는 일이에요.

## 소개

하이퍼클래스는 사용자와 사용자 고객의 개인정보를 보호하기 위해 노력해요. 데이터 보호 관련 법이 어떻게 바뀌는지 계속 살펴보고 있어서, 플랫폼을 안심하고 쓰실 수 있어요.

이 문서는 어떤 규칙이 있는지, 그 규칙이 하이퍼클래스 사용에 어떻게 적용되는지, 하이퍼클래스가 규정을 지키려고 어떤 조치를 했는지 설명해요.

이 문서는 **개인정보처리방침**과 함께 읽어 보세요. 더 자세한 정보나 조언이 필요하면 법률 전문가에게 문의하세요.

## EU 일반 데이터 보호 규정(GDPR)

Regulation (EU) 2016/679, 흔히 GDPR(General Data Protection Regulation)이라고 부르는 규정은 EU 전역의 데이터 보호법과 개인정보 보호법을 조화시키기 위한 EU 규정이에요. EU 정보주체의 개인 데이터가 관련된 곳이라면 어디든 GDPR 조항이 적용돼요.

GDPR은 기업이 개인의 데이터를 어떻게 쓰는지를 개인이 더 잘 통제하게 하고, 데이터의 수집과 처리를 더 투명하게 만드는 데 초점을 두고 있어요.

영국은 브렉시트 전환 기간이 끝난 뒤 GDPR을 영국 법에 그대로 편입했어요. 그래서 영국 기업도 'UK GDPR'을 통해 GDPR 조항을 계속 지켜야 해요.

## 기본 GDPR 개념

### 컨트롤러와 프로세서

GDPR은 개인 데이터의 컨트롤러(controller)인지 프로세서(processor)인지에 따라 서로 다른 의무를 부과해요.

컨트롤러는 개인 데이터를 처리하기로 결정하고, 처리의 근거와 방법을 정하는 주체예요. 컨트롤러에게는 개인 데이터와 관련한 의무가 있어요. 고객에게서 개인 데이터를 수집하기 전에 이 의무를 먼저 확인해 두세요.

프로세서는 컨트롤러를 대신해 컨트롤러를 위해 데이터를 처리하는 주체예요. 프로세서는 데이터나 처리 방식을 독자적으로 결정하지 않아요. 컨트롤러를 대신해서만 처리하고, 컨트롤러의 모든 지시를 따라야 해요.

하이퍼클래스를 사용할 때 고객은 컨트롤러예요. 하이퍼클래스에 올리는 데이터, 그 데이터로 하는 일, 그 이유를 고객이 정하기 때문이에요. 따라서 데이터를 처리할 법적 근거가 있는지, 필요한 기간보다 오래 데이터를 보관하지 않는지는 고객이 책임지고 확인해야 해요.

컨트롤러로서 어떤 의무가 있는지 이해하고, 개인 데이터를 하이퍼클래스로 적법하게 전송할 수 있도록 고객의 시스템과 정책을 업데이트하세요.

하이퍼클래스는 데이터 프로세서예요. 하이퍼클래스 플랫폼을 통해 고객이 수집한 데이터를 고객의 지시에 따라 저장하고 관리해요. 고객이 하이퍼클래스에 올린 개인 데이터는 하이퍼클래스 자체 목적으로, 또는 고객의 지시 없이는 절대 사용하지 않아요.

### 처리를 위한 법적 근거

개인 데이터는 법적 근거가 있을 때만 수집하고 처리할 수 있어요. 허용되는 법적 근거는 GDPR에 정해져 있어요.

프로세서인 하이퍼클래스는 고객이 개인 데이터를 수집하고 처리할 올바른 근거를 직접 고르고, 알맞은 고지와 동의 절차를 마련했다고 믿고 서비스를 제공해요. 하이퍼클래스를 쓰기 전에 어떤 법적 근거를 쓸 수 있는지 살펴보세요. 그리고 그 근거를 이행하는 데 필요한 범위에서만 개인 데이터를 수집하고 보관하세요. 개인 데이터를 수집한 근거는 정말 타당한 이유 없이 바꾸지 않는 게 좋아요. 그러니 근거마다 요건이 어떻게 다른지 이해하고, 처음부터 알맞은 근거를 고르는 것이 중요해요.

### 데이터 주체 접근 권한

GDPR은 데이터 주체(고객의 고객)에게 자신의 개인 데이터에 대한 여러 권리를 줘요. 자신과 관련된 데이터에 접근하고, 수정하고, 삭제를 요청할 권리 등이에요.

데이터 주체에게서 이런 요청을 받으면 고객이 하이퍼클래스에 알리고, 하이퍼클래스가 요청을 받으면 고객에게 알리는 간단한 절차를 마련해 두었어요. 하이퍼클래스는 고객의 지시에 따라 이런 요청을 신속하게 처리해요. 고객 자신의 시스템이나 하이퍼클래스가 아닌 다른 서비스에 보관한 개인 데이터까지 포함해서, 고객에게 부과되는 의무를 미리 확인해 두세요.

### 미국으로의 데이터 전송

개인 데이터는 특정한 경우가 아니면 EEA(유럽 경제 지역) 밖으로 전송할 수 없어요. 하이퍼클래스는 모든 고객과 체결하는 **데이터 처리 계약**에 표준계약조항(Standard Contractual Clauses)을 포함해 사용해요.

### 데이터 보안

하이퍼클래스가 보유한 개인 데이터는 안전하게 저장되도록 강력한 보안 장치와 조치를 마련해 두었어요. 제품의 버그와 취약점도 정기적으로 점검해요.

정기 백업 시스템을 갖추고 있고, 개인 데이터가 손상되거나 손실될 위험을 줄이기 위해 데이터 복구와 무결성 유지 시스템 및 절차도 운영해요.

## GDPR 준수를 위해 하이퍼클래스가 한 조치

하이퍼클래스는 프로세서로서의 의무를 매우 중요하게 생각해요. GDPR을 계속 준수하고, 고객이 수집한 개인 데이터를 하이퍼클래스로 적법하게 보낼 수 있도록 여러 절차를 마련하고 조치를 취했어요. 예를 들면 다음과 같아요.

- **데이터 처리 계약**에 표준계약조항을 적용해, 고객이 미국에 있는 하이퍼클래스로 개인 데이터를 적법하게 보낼 수 있게 했어요.
- 개인정보 침해를 감지하고 고객에게 최대한 빨리 알릴 수 있어요.
- 정보주체 접근 요청과 삭제권 요청을 처리할 수 있어요. 데이터 주체가 하이퍼클래스에 이런 요청을 하면 고객에게 알려요.
- 하이퍼클래스가 고객을 대신해 처리하는 개인 데이터를 평가하고 문서로 정리했어요.
- 데이터 유출과 관련해 하이퍼클래스가 마주한 위험 수준에 알맞은지 보안을 평가하고, 필요한 곳은 업그레이드했어요.
