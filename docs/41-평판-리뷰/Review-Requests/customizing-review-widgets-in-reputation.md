# 평판 관리에서 리뷰 위젯 설정하고 웹사이트에 넣기

리뷰 위젯을 만들고, 꾸미고, 웹사이트에 넣는 방법을 안내해요. 고객이 남긴 실제 리뷰를 내 사이트에 바로 보여 주면 신뢰도가 높아지고 전환율 개선과 브랜드 이미지 향상에 도움이 돼요.

## 리뷰 위젯이란?

리뷰 위젯은 고객이 남긴 실제 후기를 내 웹사이트에 바로 보여 주는 기능이에요. 방문자에게 곧바로 신뢰감과 사회적 증거를 줄 수 있어요. Google, Facebook 같은 플랫폼의 리뷰를 불러와 하나의 브랜드 디자인으로 묶어 보여 줘요. ▶ 영상 [1강 1:01:39](https://www.youtube.com/watch?v=yok-ipmJoDI&t=3699s)

레이아웃, 스타일, 내용을 웹사이트 디자인에 맞게 간단히 바꿀 수 있어요. 한 번 넣어 두면 새 리뷰가 자동으로 반영돼서, 따로 손대지 않아도 방문자에게 최신 후기를 보여 줄 수 있어요.

## 리뷰 위젯의 장점

리뷰 위젯은 단순한 디자인 요소가 아니라 전략적인 선택이에요. 리뷰를 보여 주면 신뢰가 쌓이고, 잠재 고객이 안심하고 구매를 결정하는 데 도움이 돼요.

- 사회적 증거: 실제 고객 리뷰를 보여 주면 신뢰가 쌓이고 전환율이 올라가요.
- 리뷰 모으기와 필터링: Google, Facebook 같은 플랫폼의 리뷰를 한곳에 모아 보여 줄 수 있어요. 플랫폼이나 평점으로 필터를 적용해 좋은 리뷰만 보여 줄 수도 있어요.
- 브랜드 일관성: 위젯의 레이아웃, 글꼴, 색상을 웹사이트 브랜딩에 맞게 바꿀 수 있어요.
- 자동 업데이트: 새 리뷰가 위젯에 자동으로 들어와서 별도 관리 없이 최신 상태가 유지돼요.
- **템플릿**: 코드 없이 쓸 수 있는 기성 템플릿으로 빠르게 설정하고, 전문적이고 일관된 디자인을 만들 수 있어요.
- 간편한 연동: 코딩 지식 없이도 웹사이트 어느 페이지에든 쉽게 넣을 수 있어요.
- **AI 요약**: 자동으로 만들어진 요약으로 전체 리뷰 분위기를 한눈에 보여 줘서 신뢰를 높여요.

## 리뷰 위젯 빌더 열고 사용하기

아래 순서로 리뷰 위젯을 만들고 꾸며 보세요.

### 1단계: 위젯 탭 열기

1. 서브 계정 대시보드의 왼쪽 메뉴에서 **평판 관리**(Reputation)를 선택하세요.
2. 위쪽 탐색 메뉴에서 **위젯** 탭을 클릭하세요.

![평판 관리의 위젯 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048742832/original/XKzNYgLBwwdl_3dbuSDyCyJBJqiDgn2gUA.png?1750707612)

### 2단계: 위젯 선택하거나 새로 만들기

- 새 위젯을 만들려면 **+ 위젯 만들기** 버튼을 클릭하세요.
- 기존 위젯을 편집하려면 원하는 위젯을 클릭한 다음, 오른쪽 아래의 파란색 **위젯 편집** 버튼을 클릭하세요.
- 처음부터 만든다면 미리 만들어진 템플릿을 골라 전문적인 레이아웃과 스타일을 바로 적용할 수도 있어요. 자세한 내용은 아래 템플릿 항목을 참고하세요.

![위젯 만들기와 위젯 편집 버튼이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048742915/original/EMYU2h6RqZch8DvSRA6qPapyfDlE-PFAew.png?1750707936)

### 3단계: 위젯 설정하기

위젯 빌더에는 여러 탭이 있어서 리뷰 위젯의 구조, 내용, 모양을 자유롭게 바꿀 수 있어요. 레이아웃부터 리뷰 출처, 테마까지 모두 설정할 수 있어요.

각 탭은 위젯의 서로 다른 부분을 다뤄요.

- **레이아웃** 탭: 위젯 유형, 리뷰 출처, 요약 옵션, 평점 필터, "Powered by" 표시 여부를 설정해요. 자세한 내용은 아래 '레이아웃 탭' 항목을 참고하세요.
- **Content**(콘텐츠) 탭: 위젯의 제목, 설명, 위치, 머리글 요소를 관리해요. 자세한 내용은 아래 'Content 탭' 항목을 참고하세요.
- **모양** 탭: 테마를 고르고 브랜드 글꼴을 적용해요. 테마를 사용자 지정으로 고르면 색상을 하나씩 설정할 수 있어요. 자세한 내용은 아래 '모양 탭' 항목을 참고하세요.
- **설정** 탭: 리뷰에 표시할 요소를 켜거나 끄고, 사이트에 넣을 임베드 코드를 만들어요. 자세한 내용은 아래 '설정 탭' 항목을 참고하세요.

{% hint style="info" %}
탭별 세부 설정 옵션은 아래에서 자세히 설명해요.
{% endhint %}

### 4단계: 저장하고 웹사이트에 넣기

1. 필요한 변경을 모두 마쳤으면 오른쪽 아래의 파란색 **저장** 버튼을 클릭하세요.
2. 하이퍼클래스 웹사이트나 퍼널에 위젯을 넣으려면 **리뷰** 요소를 사이트 페이지로 끌어다 놓으세요.
3. 코드로 위젯을 넣으려면 **코드** 아이콘을 클릭한 다음 **코드 복사**를 클릭하세요. 복사한 코드는 웹사이트나 퍼널의 커스텀 HTML 블록에 붙여넣으세요.

![코드 아이콘과 코드 복사 버튼이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048743288/original/R85gbS6-qStRCI6W82PAHVy3A4Wjy8MUCQ.png?1750708645)

## 리뷰 위젯 설정하기

위젯 빌더의 각 탭에서는 구조와 레이아웃, 내용, 디자인, 동작을 각각 설정할 수 있어요.

{% hint style="info" %}
선택한 **위젯 유형**에 따라 설정할 수 있는 항목이 달라져요.
{% endhint %}

### 레이아웃 탭: 위젯 구조 설정

리뷰를 보여 주는 기본 구조와 출처를 정해요.

- **요약 유형**: 리뷰를 바탕으로 AI가 만든 전체 분위기 요약이에요. 요약 유형(Short, Detailed, Action-Oriented) 중에서 고르고, 필요에 따라 켜거나 끌 수 있어요.
- **요약 위치**: AI 요약을 위젯 상단에 보여 줄지, 리뷰와 같은 줄(인라인)에 보여 줄지 정해요. 기본적으로는 선택한 위젯 레이아웃에 따라 위치가 정해져요. 요약을 항상 위쪽에 보이게 하려면 **요약 위치**를 상단(Top)으로 설정하세요.
- **리뷰 출처**: 리뷰를 가져올 플랫폼을 선택해요.
- **위젯 유형**: 리뷰를 보여 주는 형식을 골라요. 목록(List), Grid, Masonry, Carousel, Slider, Flash, Legacy 중에서 선택할 수 있어요.
- **Max Number of Reviews**(최대 리뷰 수): 위젯에 보여 줄 리뷰의 전체 개수를 정해요.
- **최소 평점**: 지정한 별점 이상의 리뷰만 보여 줄 수 있어요.
- **Powered by**: 위젯 아래쪽의 "Powered by" 문구를 보이거나 숨겨요.

![레이아웃 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048743501/original/VsRXMjHsQTnNBoXWiqY11wnS4TcAQhqG0Q.png?1750709276)

### Content 탭: 위젯 머리글과 설명 편집

위젯이 리뷰를 어떻게 소개할지 정해요.

- **Title**(제목 토글): 위젯 맨 위에 사용자 지정 제목을 보여 줄지 켜거나 꺼요.
- **제목**: 위젯 제목으로 보여 줄 문구를 입력해요. 브랜드 분위기나 콘텐츠 방향에 맞게 쓰면 돼요(예: "고객 여러분의 이야기").
- **설명**: 제목 아래에 짧은 보조 문구를 넣어 맥락을 알려 주거나 방문자에게 한마디 건넬 수 있어요.
- **머리글**(토글): 머리글 요약 영역을 보여 줄지 정해요. 이 영역에는 평점 정보, 리뷰 수, 리뷰 작성 버튼이 들어가요.
- **평점**: 전체 리뷰의 평균 별점을 보여 줘요.
- **총 리뷰 수**: 지금까지 남겨진 리뷰의 총 개수를 보여 줘요.
- **리뷰 작성 버튼**: 클릭하면 리뷰를 남기는 곳으로 이동하는 버튼을 추가해요.
- **위젯 위치**: 화면에서 위젯이 표시될 위치를 정해요.
- **슬라이더 간격**: 리뷰 하나가 몇 초 동안 보인 뒤 다음 리뷰로 넘어갈지 정해요. Carousel이나 Slider 레이아웃일 때 사용할 수 있어요.

![Content 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048743648/original/x2gWp6YEwpHiNRDZzW4AAbIgst118-J2WA.png?1750709673)

### 모양 탭: 테마와 색상 선택

웹사이트 브랜딩에 맞게 위젯의 전체적인 시각 스타일을 정해요.

- **테마**: 라이트, 다크, 또는 자유롭게 바꿀 수 있는 사용자 지정 중에서 골라요. 테마마다 기본 모양이 달라요.
- **글꼴**: 위젯에 쓰는 글꼴 패밀리를 브랜드 타이포그래피에 맞게 바꿔요.
- **색상**: 테마를 사용자 지정으로 선택하면 배경, 테두리, 별점, 리뷰 텍스트, 버튼 등 다양한 색상 요소를 하나씩 바꿀 수 있어요.

![모양 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048743710/original/Jo9j_aUcvymr-Emyx643P3BkMDpsrmwvTQ.png?1750709827)

### 설정 탭: 위젯 동작 세부 조정

위젯의 동작과 리뷰마다 보여 줄 정보를 더 세밀하게 정해요.

- **표시 날짜**: 켜면 각 리뷰가 작성된 날짜를 보여 줘요.
- **리뷰어 아이콘 표시**: 켜면 각 리뷰 옆에 리뷰어의 아바타나 이니셜을 보여 줘요.
- **Exclude Reviews Containing No Description**(내용 없는 리뷰 제외): 별점만 있고 작성한 글이 없는 리뷰를 제외해요.
- **Embed Code to Website**(웹사이트에 임베드 코드 넣기): **코드 복사**를 클릭하면 자동으로 만들어진 임베드 스크립트를 복사할 수 있어요. 이 코드를 웹사이트나 퍼널의 HTML 블록에 붙여넣으면 위젯이 표시돼요.

![설정 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048743770/original/Vonk7q9JWxpuSOgsI3gPM59s5TcGIWgA4w.png?1750709979)

## 위젯 저장하고 이름 정하고 관리하기

위젯에 알아보기 쉬운 이름을 붙여 두세요. 저장한 위젯은 모두 저장된 위젯 탭에서 볼 수 있어요. 나중에 쓰려고 저장만 해 둘 수도 있고, 바로 게시할 수도 있어요.

![저장된 위젯 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155007981528/original/i5hDyYsrlVq8APk28m-HSSzxC0Wv5sFNqw.png?1695106902)

더 이상 필요 없는 위젯은 위젯 오른쪽 위 모서리의 점 세 개 메뉴를 클릭한 다음 **삭제**를 클릭해서 지울 수 있어요.

![위젯 삭제 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155007981577/original/_aghciJL9owpFIKVaccyIr0Ze3WrxNEH4Q.png?1695106947)

## 템플릿

**템플릿**을 쓰면 멋지게 꾸며진 리뷰 위젯을 몇 초 만에 시작할 수 있어요. 요소를 하나하나 설정하지 않고도 전문적인 레이아웃을 쓰고 싶을 때 특히 편해요. 적용 방법도 간단해요.

1. 위젯 패널 오른쪽 위의 **템플릿** 탭을 클릭하세요.
2. 사용할 수 있는 디자인 목록을 둘러보고, 원하는 템플릿을 클릭하면 리뷰 위젯에 바로 적용돼요.

적용한 뒤에도 다른 위젯과 똑같이 계속 편집할 수 있어요. 레이아웃, 색상, 글꼴, 내용을 바꿔서 나만의 위젯으로 만들어 보세요. 파란색 **위젯 편집** 버튼을 클릭하면 돼요.

![템플릿 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048745241/original/MkvFXEafZrEa26Llwtbliuoy3iLRiXTU1A.png?1750714297)

## 자주 묻는 질문

### 한 웹사이트에 서로 다른 리뷰 위젯을 여러 개 넣을 수 있나요?
네, 넣을 수 있어요. 다만 빌더의 "리뷰" 블록으로는 할 수 없어요. 이 블록은 항상 기본 위젯만 보여 줘요. 같은 사이트에 위젯을 여러 개 넣으려면 **임베드 코드** 옵션으로 원하는 위젯의 코드를 복사하세요. 그런 다음 "코드" 블록을 이용해 웹사이트에 위젯 코드를 추가하세요. 코드를 복사할 때는 드롭다운에서 올바른 위젯을 선택했는지 꼭 확인하세요. 넣고 싶은 위젯마다 같은 방법을 반복하면 돼요.

### 새 리뷰가 들어오면 위젯도 자동으로 업데이트되나요?
네. 위젯은 Google, Facebook 같은 연결된 플랫폼과 동기화돼요. 새 리뷰는 설정해 둔 필터와 표시 설정에 따라 위젯에 자동으로 나타나요.

### 하이퍼클래스로 만들지 않은 웹사이트에서도 리뷰 위젯을 쓸 수 있나요?
네. 리뷰 위젯은 거의 모든 웹사이트 플랫폼에 넣을 수 있어요. 위젯의 **임베드 코드**를 복사해서 외부 사이트의 커스텀 코드 블록에 붙여넣으면 돼요.

### 위젯을 사이트에 넣은 뒤에도 계속 편집할 수 있나요?
네. 사이트에 넣은 뒤에도 위젯은 언제든 편집할 수 있어요. 위젯 빌더에서 레이아웃, 내용, 스타일 등을 바꾸고 위젯을 저장하면 사이트에도 자동으로 반영돼요.

### 리뷰 위젯은 모바일 화면에도 맞게 보이나요?
네. 모든 리뷰 위젯 템플릿과 레이아웃은 반응형이어서, 모바일, 태블릿, 데스크톱 화면에 맞게 자동으로 최적화돼요.
