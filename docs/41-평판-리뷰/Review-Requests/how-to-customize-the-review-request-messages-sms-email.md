# 리뷰 요청 메시지(SMS·이메일) 사용자 지정하기

고객이 리뷰를 쉽게 남기도록 SMS와 이메일 리뷰 요청을 직접 꾸밀 수 있어요. 이 문서에서는 리뷰 요청을 켜고, 메시지 템플릿을 고치고, 발송 주기와 재시도를 정하고, 리뷰 링크를 설정하는 방법을 안내해요.

## 리뷰 요청 메시지란?

리뷰 요청 메시지는 고객에게 공개 리뷰를 부탁하는 일을 자동으로 처리해 주는 기능이에요. 하이퍼클래스는 체크인 후 개인화된 **SMS**와 **이메일**을 보내고, 고객이 리뷰 링크를 클릭할 때까지 정해 둔 주기로 반복해서 보내요. 고객은 **리뷰 링크**에 설정한 리뷰 페이지로 이동해요.

---

## 리뷰 요청 메시지의 장점

장점을 알아 두면 비즈니스 목표에 맞게 설정하기 쉬워요.

- 브랜드 일관성: SMS와 이메일 모두 말투와 브랜딩이 일관된 템플릿을 만들 수 있어요.
- 자동화: 첫 요청을 언제 보낼지, 고객이 클릭할 때까지 얼마나 자주 다시 보낼지 정할 수 있어요.
- 개인화: 연락처와 계정 정보 변수 같은 머지 필드를 넣어 고객마다 맞는 메시지를 보낼 수 있어요.
- 유연성: 고객을 Google 비즈니스 프로필이나 원하는 페이지로 안내할 수 있고, 이메일에는 링크를 여러 개 넣을 수도 있어요.
- 제어: 어떤 템플릿을 **라이브**로 쓰고, 어떤 템플릿을 각 **재시도**에 쓸지 직접 고를 수 있어요.

---

## 리뷰 요청을 보낼 수 있는 곳

템플릿과 발송 주기를 설정해 두면 하이퍼클래스 여러 곳에서 리뷰를 요청할 수 있어요. 팀의 업무 방식에 맞는 방법을 쓰세요.

- **평판 관리**(Reputation) **> 요청**: 요청을 한꺼번에 또는 하나씩 보내고 현황을 확인해요.
- 연락처: 연락처를 열고 **리뷰 요청 보내기**를 선택해요.
- 워크플로우: **Review Request**(리뷰 요청) 액션을 사용하면 트리거에 맞춰 자동으로 보낼 수 있어요. 예를 들어 예약 상태가 바뀐 뒤에 보낼 수 있어요.
- 채널: 이 문서에서는 SMS와 이메일을 다뤄요. **WhatsApp Requests**(WhatsApp 요청)는 **평판 관리 > 설정 > WhatsApp Requests**에서 따로 설정할 수 있어요.

---

## 리뷰 링크(리뷰 밸런싱 vs. 사용자 지정 링크)

리뷰 링크는 리뷰 요청 메시지에 들어가는 URL이에요. 하이퍼클래스가 지원하는 플랫폼(예: Google)에 리뷰를 나눠서 받게 할 수도 있고, 사용자 지정 URL 한 곳으로 모을 수도 있어요.

메뉴 경로: **평판 관리 > 설정 > 리뷰 링크**

![리뷰 링크 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063513870/original/ZkcZchgDLioGh9YTmNgacq7SrE6--_izSQ.jpeg?1769449800)

#### 설정 항목

- **리뷰 밸런싱**: 토글을 켜면 설정한 플랫폼에 리뷰 트래픽이 자동으로 나뉘어요.
- **Google에서 리뷰 받기**: Google 비즈니스 프로필(GBP)을 연결하면 고객을 Google 리스팅으로 안내해요.
- **사용자 지정 링크**: 모든 고객을 한 페이지로 보내고 싶을 때 선택해요. 원하는 URL을 붙여 넣으세요.

{% hint style="info" %}
**사용자 지정 링크**를 쓴다면 리뷰 작성 폼이 바로 열리는지 확인하세요. **리뷰 밸런싱**을 쓴다면 연동이 연결되어 있는지 확인하세요.
{% endhint %}

## SMS 요청

SMS 요청은 빠르고 개인적인 느낌을 줘요. 토글을 켜서 발송을 시작하고, 첫 문자를 보낼 시점과 재시도 주기를 정한 뒤, 리뷰 링크와 이미지(선택)를 넣은 템플릿을 만드세요.

메뉴 경로: **평판 관리 > 설정 > SMS 요청**

![SMS 요청 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063513905/original/Vo_pjWaiHFSBuHwx-TJSn7UrR6sQIURIbA.jpeg?1769449870)

#### 활성화 및 발송 주기 설정

- **SMS 리뷰 요청**: 오른쪽 위의 토글을 켜세요.
- **발송 시점**: 체크인 후 첫 문자를 언제 보낼지 선택해요(예: 즉시).
- **클릭할 때까지 다음 주기로 반복**: 반복 간격을 골라요. **사용자 지정**을 선택하면 숫자와 **일** 단위로 직접 정할 수 있어요.
- **최대 재시도 횟수**: 리뷰 링크를 클릭하지 않았을 때 후속 문자를 최대 몇 번 보낼지 정해요.

![SMS 발송 주기 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063513935/original/PYFMHD87MYkdGS3KPqcFuASbYRmCJQmEjg.png?1769449949)

### SMS 템플릿 만들기 또는 편집하기

1. **새로 만들기**를 클릭해요. 기존 템플릿을 고치려면 해당 템플릿의 **편집**을 클릭하세요.
2. **처음부터 새로 만들기** 또는 **사전 제작 템플릿에서 선택**을 선택해요.

   빌더에서 **템플릿 이름**을 입력하세요. 필요하면 **이미지로 요청**을 켜거나 이미지 URL을 추가할 수 있어요.
3. 메시지를 작성하고 리뷰 링크 토큰 `{{reputation.review_link}}`를 넣어요.
4. **저장**을 클릭해요.

{% hint style="info" %}
비용 안내: **이미지로 요청**을 켜면 메시지가 MMS로 발송될 수 있고, 이 경우 통신사 요금이 달라질 수 있어요. 사용 중인 제공업체에 확인하세요.
{% endhint %}

### 기본 발신 번호 선택하기

기본 발신 설정에서 SMS 리뷰 요청을 보낼 전화번호를 고를 수 있어요.

1. **평판 관리 > 설정 > SMS 요청**으로 이동해요.
2. 기본 발신 번호로 쓸 전화번호를 선택해요.
3. 나머지 발송 시점, 재시도, 템플릿 설정을 마쳐요.

선택한 번호가 SMS 리뷰 요청의 기본 발신 번호로 쓰여요.

![기본 발신 번호 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079287866/original/jnwY9adqBqlsJREieaBWWhidNXaKXNxxnw.png?1787693912)

## 이메일 요청

이메일 요청에서는 브랜딩을 더 풍부하게 꾸미고, 이미지를 넣고, 리뷰 페이지를 여러 곳 안내할 수 있어요. 기능을 켜고 발송 시점과 재시도를 정한 다음, 끌어다 놓는 편집기에서 템플릿을 만들거나 가져오세요.

메뉴 경로: **평판 관리 > 설정 > 이메일 요청**

![이메일 요청 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063516219/original/Ilaq69B44toxPAWJoghbVhS0eXlcVYCaCA.png?1769452221)

#### 활성화 및 발송 주기 설정

- **이메일 리뷰 요청**: 오른쪽 위의 토글을 켜세요.
- **발송 시점**: 첫 이메일을 보낼 때까지의 대기 시간을 골라요(예: 1시간).
- **클릭할 때까지 다음 주기로 반복**: 반복 간격을 정해요. **사용자 지정**을 선택하면 숫자와 **일** 단위로 직접 정할 수 있어요.
- **최대 재시도 횟수**: 후속 이메일을 최대 몇 번 보낼지 정해요.

{% hint style="info" %}
"체크인 후"는 **리뷰 요청 보내기** 액션이 실행되는 시점을 뜻해요. 연락처 화면이나 **평판 관리 > 요청**에서 직접 실행할 수도 있고, 워크플로우의 **Review Request**(리뷰 요청) 액션으로 자동 실행할 수도 있어요. 여기서 고른 시간은 그 실행 시점으로부터 SMS가 나가기까지의 대기 시간이에요.
{% endhint %}

![이메일 발송 주기 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063516230/original/g0tDB4bGh7YTD8ZUKizpWFQ-EQhsIWTDyA.png?1769452263)

### 이메일 템플릿 만들기 또는 가져오기

1. **새로 만들기**를 클릭한 뒤 **새 템플릿 만들기** 또는 **템플릿 라이브러리에서 가져오기**를 선택해요.
2. 이메일 빌더에서 브랜딩과 내용을 채워요.
3. **리뷰 링크** 요소를 이메일에 끌어다 놓아요. 또는 대표 CTA 버튼이 리뷰 링크를 쓰도록 설정해도 돼요.
4. 템플릿을 저장해요.

### 기본 발신자 이메일 선택하기

**기본 발신자 이메일**에서 이메일 리뷰 요청을 보낼 이메일 주소를 고를 수 있어요.

1. **평판 관리 > 설정 > 이메일 요청**으로 이동해요.
2. **기본 발신자 이메일**에서 주소를 선택해요.
3. 나머지 발송 시점, 재시도, 템플릿 설정을 마쳐요.

선택한 주소가 이메일 리뷰 요청의 기본 발신자로 쓰여요.

![기본 발신자 이메일 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079287916/original/JivKtPT0IEp_32i53Ewr_SdtlfI6yaia6Q.png?1787694055)

## 라이브·재시도 템플릿 선택하기(발송 순서)

SMS나 이메일 요청을 켜는 것만으로는 충분하지 않아요. 처음 보낼 때와 재시도마다 어떤 템플릿을 쓸지도 하이퍼클래스에 알려 줘야 해요. 여기서 고른 템플릿이 단계마다 고객에게 그대로 전달돼요.

- 이메일: **이메일 템플릿 설정**을 클릭해요. **라이브** 템플릿을 고르고 각 **재시도** 슬롯에 템플릿을 지정한 뒤 **저장**하세요.
- SMS: **SMS 템플릿 설정**을 클릭해요. 라이브와 재시도 템플릿을 고르고 저장하세요.

## 리뷰 요청 메시지 설정하기(단계별)

#### 1단계: 리뷰 링크 설정

왼쪽 메뉴에서 **평판 관리**를 클릭하고 위쪽의 **설정** 탭을 열어요. **리뷰 링크**에서 **리뷰 밸런싱** 토글을 켜거나, **사용자 지정 링크**를 선택하고 **맞춤 링크 설정**에 URL을 붙여 넣어요.

![리뷰 링크 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058933873/original/QB3j9NV406CrZGGrHw_hZ5PhNhneE107XQ.jpeg?1763723464)

#### 2단계: SMS 요청 켜기

**평판 관리 > 설정 > SMS 요청**을 열고 오른쪽 위의 토글을 켜서 자동 리뷰 문자를 활성화해요.

**발송 시점**을 정하고, 반복 간격(**클릭할 때까지 다음 주기로 반복**)과 **최대 재시도 횟수**를 선택하세요. 그런 다음 **새로 만들기** 또는 **SMS 템플릿 설정**으로 아래 화면에 보이는 메시지를 관리해요.

![SMS 요청 켜기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058933920/original/gxWefKkRxYWGp630dnmpJmEt2GauEUvFPw.jpeg?1763723498)

#### 3단계: SMS 템플릿 추가

**새로 만들기**를 클릭하면 새 SMS 리뷰 요청을 만들 수 있어요. 선택한 템플릿을 고치려면 연필(편집) 아이콘을 클릭하세요. 여기서 만들거나 고친 템플릿은 목록에 표시되고, 나중에 라이브 또는 재시도 순서에 지정할 수 있어요.

![SMS 템플릿 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058937902/original/JkADEj50izgPa70Pve3V3O8pGUFYEZ-B_Q.png?1763725571)

#### 4단계: 템플릿 유형 선택

**새로 만들기**를 클릭한 뒤 시작 방식을 골라요. **처음부터 새로 만들기**와 **사전 제작 템플릿에서 선택** 중에서 원하는 쪽의 **선택**을 클릭하세요. 빈 템플릿에서 시작하면 자유롭게 만들 수 있고, 검증된 템플릿을 쓰면 더 빠르게 만들 수 있어요.

![템플릿 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058938037/original/6ufdGZ9VGsp7Sd_gom24_CQn2vBlfoyEPg.png?1763725586)

#### 5단계: 사전 제작 템플릿 선택

**SMS 템플릿 라이브러리**에서 **Request a Review**(리뷰 요청하기) 같은 사전 제작 템플릿을 선택해요. 화면에 글자 수가 표시되니 참고하세요. **템플릿 수정**을 클릭해 문구를 바꿀 수 있어요. 이때 `{{reputation.review_link}}` 토큰은 그대로 두세요.

![사전 제작 템플릿 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058938158/original/2p9Gcm_rwylwfHoQt5GN06fRSC6AMuOFQg.png?1763725602)

#### 6단계: SMS 템플릿 사용자 지정

**템플릿 이름**을 입력해요. 이미지를 올리거나 링크로 넣으려면 **이미지로 요청**을 켜세요. 메시지는 `{{reputation.review_link}}`를 넣어 작성해요. 오른쪽의 실시간 휴대폰 미리보기를 확인한 뒤 **저장**을 클릭해 템플릿을 저장하세요.

![SMS 템플릿 사용자 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058938272/original/0QeAG2m0_i5c6CJNuN-LoK2y27GC4heRVA.png?1763725619)

#### 7단계: 이메일 요청 켜기

**평판 관리 > 설정 > 이메일 요청**을 열고 오른쪽 위의 토글을 켜서 자동 리뷰 이메일을 활성화해요. **발송 시점**, 클릭할 때까지의 반복 간격, **최대 재시도 횟수**를 설정한 뒤 **이메일 템플릿 설정** 또는 **새로 만들기**로 템플릿을 관리하세요.

![이메일 요청 켜기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058938389/original/wwV6X0pG3zkFFBmww9-QoknrHLcSDpY3xQ.png?1763725650)

#### 8단계: 이메일 발송 순서 지정

**이메일 템플릿 설정**을 클릭하면 왼쪽 드롭다운에서 처음 보낼 템플릿(**라이브**)과 각 **재시도** 슬롯에 쓸 템플릿을 고를 수 있어요. 필요하면 오른쪽의 제목을 확인하거나 고친 뒤 **저장**을 클릭해 순서를 적용하세요.

#### 8단계: 이메일 만들기·가져오기

**새로 만들기** 드롭다운에서 **새 템플릿 만들기** 또는 **템플릿 라이브러리에서 가져오기**를 선택해 이메일 요청 템플릿을 준비해요. 기존 디자인을 고치려면 템플릿 카드의 **⋯** 메뉴를 클릭하고 **템플릿 수정**을 선택하세요. 이렇게 준비한 템플릿은 나중에 **이메일 템플릿 설정**에서 지정해요.

## 자주 묻는 질문

### 고객이 리뷰 링크를 클릭하면 어떻게 되나요?
클릭이 확인되면 해당 채널의 반복 발송이 멈춰요. 그 연락처에는 추가 재시도가 나가지 않아요.

### 리뷰 밸런싱과 사용자 지정 링크는 어떻게 다른가요?
**리뷰 밸런싱**은 연결된 리뷰 사이트(예: Google)에 트래픽을 나눠서 보내요. **사용자 지정 링크**는 모든 고객을 직접 정한 한 곳으로 보내요.

### SMS에서 리뷰 URL을 넣으려면 어떤 토큰을 써야 하나요?
`{{reputation.review_link}}`를 쓰세요. **평판 관리 > 설정 > 리뷰 링크**에서 설정한 리뷰 링크가 자동으로 들어가요.

### 이메일에 리뷰 사이트를 둘 이상 넣을 수 있나요?
네. 이메일 빌더에서 **리뷰 링크** 요소를 쓸 수 있어요. 디자인이 지원하는 일부 템플릿에서는 리뷰 버튼을 여러 개 설정할 수도 있어요.

### 재시도는 몇 번으로 설정하는 게 좋나요?
대부분 2~3회로 시작해요. 알맞은 횟수는 고객 반응, 업종 관행, 규정 준수 요건에 따라 달라요.

### SMS에 이미지를 넣으면 비용이 달라지나요?
MMS로 발송될 수 있고, 이 경우 통신사 요금이 달라질 수 있어요. 사용 중인 메시지 제공업체의 요금을 확인하세요.

### Google 비즈니스 프로필을 꼭 연결해야 하나요?
**리뷰 밸런싱**으로 Google에 리뷰를 보내려는 경우에만 연결하면 돼요. 다른 사이트나 직접 만든 페이지를 쓰려면 **사용자 지정 링크**를 설정하세요.

### 직접 보내지 않고 요청을 자동화할 수 있나요?
네. 워크플로우에 **Review Request**(리뷰 요청) 액션을 추가하면 발송이 자동으로 실행돼요. 예를 들어 체크인 뒤에 보내도록 설정할 수 있어요.
