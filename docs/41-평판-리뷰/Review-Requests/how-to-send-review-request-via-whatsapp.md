# WhatsApp으로 리뷰 요청 보내기

WhatsApp으로 리뷰 요청을 보내면 고객과 가깝게 소통하면서 후기를 모을 수 있어요. 이 문서에서는 WhatsApp 연동부터 리뷰 요청 메시지 설정, 단건·일괄·워크플로우 발송 방법까지 안내해요.

## 1단계: WhatsApp 연동하기

리뷰 요청을 보내려면 먼저 계정에 WhatsApp이 연동되어 있어야 해요.

1. **설정 > WhatsApp**으로 이동하세요.
2. 아직 구독하지 않았다면 **구독하기**를 눌러 WhatsApp을 구독하세요.
3. 화면의 안내에 따라 인증하고 WhatsApp Business 번호를 연결하세요.
4. 연결이 끝나면 메시지가 정상적으로 발송되는지 테스트하세요.

## 2단계: 기본 WhatsApp 발신 번호 선택하기

WhatsApp을 연결한 뒤에는 리뷰 요청을 보낼 때 사용할 번호를 정해요.

1. **평판 관리 > 설정 > WhatsApp Requests**(WhatsApp 요청)로 이동하세요.
2. **기본 WhatsApp 발신 번호**에서 사용할 WhatsApp 번호를 선택하세요.
3. **저장**을 클릭하세요.

선택한 번호가 WhatsApp 리뷰 요청의 기본 발신 번호가 돼요.

## 3단계: 리뷰 요청 메시지 만들기

1. 대시보드의 **WhatsApp** **리뷰 요청** 섹션으로 이동하세요.
2. 메시지를 작성하세요.
   - 비즈니스 이름을 넣어요.
   - 친근한 행동 유도 문구를 넣어요. (예: "소중한 의견을 들려주세요!")
   - 후기를 받을 플랫폼(예: Google, Facebook)의 리뷰 링크를 첨부해요.
3. 템플릿을 저장해 두면 다음에도 다시 쓸 수 있어요.

## 4단계: 리뷰 요청 보내기

### 단건 리뷰 요청

1. 대시보드의 **리뷰** 섹션으로 이동하세요.
2. **리뷰 요청 보내기**를 클릭하고 채널로 **WhatsApp**을 선택하세요.
3. 요청을 보낼 고객을 선택하세요.
4. 만들어 둔 템플릿을 선택하고 내용을 확인한 뒤 **보내기**를 클릭하세요.

### 일괄 리뷰 요청

1. **리뷰** 섹션에서 고객 정보(이름과 WhatsApp 번호)가 담긴 CSV 파일을 업로드하세요.
2. 필드를 알맞게 연결하세요. (예: 이름 → **고객 이름**, 전화번호 → **WhatsApp Number**(WhatsApp 번호))
3. **Send Bulk Review Requests**(리뷰 요청 일괄 보내기)를 선택하고 채널로 **WhatsApp**을 선택하세요.
4. 미리보기를 확인하고 메시지를 최종 확인하세요.

### 워크플로우로 리뷰 요청 보내기

단건이나 일괄 발송 외에, 워크플로우로 발송을 자동화할 수도 있어요. 구매 완료처럼 특정 이벤트나 행동이 일어났을 때 리뷰 요청을 보내려는 경우에 알맞아요.

1. 워크플로우를 준비해요. 대시보드의 **워크플로우** 섹션으로 이동해 새 워크플로우를 만들거나 기존 워크플로우를 편집하세요.
2. 트리거를 추가해요. 리뷰 요청을 보낼 이벤트를 정하세요. 예를 들어 구매를 완료한 뒤로 설정할 수 있어요.
3. 액션을 추가해요. 워크플로우에 **Send Review Request via WhatsApp**(WhatsApp으로 리뷰 요청 보내기) 액션을 추가하세요.
4. 템플릿을 선택하거나 만들어요. 사전 승인된 WhatsApp 템플릿을 고르고, `{Customer Name}`, `{Order ID}` 같은 동적 변수로 내용을 개인화하세요.
5. 워크플로우를 활성화해요. 워크플로우를 저장하고 활성화하세요. 이제 트리거 조건이 충족될 때마다 리뷰 요청이 자동으로 보내져요.

## WhatsApp 리뷰 요청 활용 팁

- 메시지 개인화: 고객 이름을 넣어 부르면 응답률이 높아져요.
- 발송 시점: 긍정적인 경험을 한 직후에 요청을 보내세요.
- 규정 준수: WhatsApp 메시지를 보내기 전에 고객 동의를 받았는지 확인하세요.
