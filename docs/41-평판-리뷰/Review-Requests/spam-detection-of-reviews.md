# 리뷰 스팸 감지

스팸 리뷰를 쉽게 찾아 관리하는 기능이에요. 서브 계정에서 가짜이거나 관련 없는 리뷰를 걸러 내면 온라인 평판을 더 잘 지킬 수 있고, 실제 고객 리뷰에 집중할 수 있어요.

## 스팸 감지 기능 살펴보기

- **리뷰** 화면에서 스팸으로 표시된 리뷰를 한눈에 알아볼 수 있어요.
- 각 리뷰의 액션 메뉴에 **Mark as Spam**(스팸으로 표시) 옵션이 추가되었어요.
- 스팸 리뷰만 골라 보는 필터가 추가되었어요.
- 스팸으로 잘못 분류했다면 **Undo Spam**(스팸 취소)으로 바로잡을 수 있어요.

## 리뷰 스팸 감지를 써야 하는 이유

- 스팸을 쉽게 걸러 내서 실제 고객 의견에 집중할 수 있고, 리뷰의 품질도 좋아져요.
- 스팸을 자동으로 감지하므로 리뷰를 직접 확인하는 시간이 줄어요.
- AI가 스팸 리뷰에 답하지 않아서, 평판에 손해가 생길 수 있는 상황을 막아 줘요.
- 리뷰를 직접 스팸으로 표시하거나 표시를 해제할 수 있어서 정확하게 관리할 수 있어요.

## 자주 묻는 질문

### 새로 생긴 "스팸으로 표시" 기능은 어떤 기능인가요?
**Mark as Spam**(스팸으로 표시)을 쓰면 가짜이거나 관련 없어 보이는 리뷰에 표시를 해 둘 수 있어요. 표시한 리뷰는 스팸으로 눈에 띄게 보이고 따로 걸러 낼 수 있어서, 실제 고객 의견에 집중하기 좋아요.

### 스팸으로 표시된 리뷰는 어떻게 알아볼 수 있나요?
스팸으로 표시된 리뷰는 **리뷰** 화면에서 눈에 띄는 표시가 붙어 있어서 한눈에 구분할 수 있어요.

### 스팸 리뷰만 모아서 볼 수 있나요?
네. 스팸으로 표시된 리뷰만 보여 주는 필터가 추가되었어요. 표시된 리뷰를 빠르게 확인하고 관리할 수 있어요.

### 리뷰를 실수로 스팸으로 표시했어요. 어떻게 하나요?
**Undo Spam**(스팸 취소)을 선택하세요. 스팸 표시가 없어지고 리뷰가 원래 상태로 돌아가요.

### 스팸으로 표시된 리뷰에도 AI가 답하나요?
아니요. AI는 스팸으로 표시된 리뷰에 답하지 않아요. 관련 없거나 가짜인 리뷰가 자동 답변이나 평판 관리에 영향을 주지 않도록 하기 위해서예요.

### 이 기능이 왜 중요한가요?
스팸을 걸러 내서 리뷰의 품질을 높여 주고, 리뷰를 관리하는 시간과 수고를 줄여 줘요. 또 AI가 관련 없거나 해로운 리뷰에 답하지 않게 해서 평판을 지키는 데도 도움이 돼요.
