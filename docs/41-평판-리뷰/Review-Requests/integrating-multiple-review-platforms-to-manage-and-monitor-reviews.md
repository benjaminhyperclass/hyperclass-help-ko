# 여러 리뷰 플랫폼을 연동해 리뷰 한곳에서 관리하기

여러 플랫폼에 흩어진 리뷰를 관리하는 일은 온라인 평판을 지키는 데 중요해요. 하이퍼클래스에서 리뷰 플랫폼을 여러 개 연동하면 리뷰를 한곳에서 확인하고, 관리하고, 답글까지 달 수 있어요. 이 문서에서는 지원하는 리뷰 플랫폼을 계정에 연결하는 방법을 안내해요.

## 리뷰 플랫폼을 연동하면 좋은 점

여러 페이지 연동은 여러 리스팅의 리뷰를 관리하는 에이전시나 다점포 비즈니스에 특히 유용해요. 플랫폼 하나에 페이지를 여러 개 연결하면 수작업으로 확인하는 일이 줄고, 온보딩이 간단해지고, 평판 활동을 큰 규모로 지켜볼 수 있어요.

- 플랫폼당 여러 페이지: 같은 리뷰 플랫폼 안에서 비즈니스 페이지, 리스팅, 프로필을 둘 이상 연결할 수 있어요.
- 페이지 연결 개수 제한 없음: 비즈니스, 지점, 고객사가 늘어나는 만큼 플랫폼마다 필요한 페이지를 추가할 수 있어요.
- 리뷰 통합 관리: 리스팅을 하나씩 따로 챙기지 않고, **평판 관리**의 연동 화면 한곳에서 연결된 페이지를 관리해요.
- 페이지별 확인: 페이지 정보, 연결 상태, 리뷰 수, 마지막 동기화 정보를 볼 수 있어요.
- 에이전시 확장성: 서브 계정 하나로 여러 고객사, 브랜드, 지점, 프랜차이즈 매장을 지원할 수 있어요.
- 폭넓은 플랫폼 지원: 일반 리뷰 플랫폼과 업종별 플랫폼을 포함해 52개 리뷰 플랫폼에 페이지를 연결할 수 있어요.
## 플랫폼별 여러 페이지 연결

여러 페이지 연결을 쓰면 리뷰 플랫폼 하나에서 리스팅을 둘 이상 관리할 수 있어요. 비즈니스에 지점이 여러 개이거나, 에이전시가 같은 고객사의 리스팅을 여러 개 맡고 있을 때 편해요.

여러 페이지 연동으로 다음을 할 수 있어요.

- 지원하는 플랫폼 하나에 비즈니스 페이지를 여러 개 연결해요.
- 서브 계정 하나 안에서 여러 지점의 리뷰 리스팅을 추가해요.
- 프랜차이즈, 지점, 숙소, 서비스 지역별 리뷰 페이지를 관리해요.
- 새 지점이나 고객사가 생기면 페이지 연결을 늘려요.
- 불필요하게 설정을 중복해서 만들지 않고, 리뷰 플랫폼 관리를 한곳에 모아 둬요.

## 리뷰 플랫폼 연동하기

### 1단계: 연동 화면으로 이동하기

1. 왼쪽 메뉴에서 **평판 관리**로 이동하세요.
2. 상단 메뉴에서 **설정**을 클릭하세요.
3. **연동** 탭을 선택하세요.

이 화면에서 연동할 수 있는 리뷰 플랫폼을 모두 볼 수 있어요.

### 2단계: 연동 설정하기

1. 연결할 플랫폼에서 **계정 연결**을 클릭하세요.
2. 비즈니스 리뷰 페이지 URL을 입력하세요.
3. **연결**을 클릭하세요.

### 예시: 플랫폼 연동 창

![플랫폼 연동 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073735062/original/-0nT1vHIRmxfzGgD7SlTp6yw7g3zLf3EDg.png?1781593034)

URL은 Yelp, Google Business Profile처럼 외부에 공개된 리뷰 페이지를 바로 가리켜야 해요.

연결하고 나면 리뷰가 대시보드로 자동 동기화돼요.

## 페이지별 확인과 리뷰 필터링

페이지별 확인 기능으로 리뷰가 올바른 연결 페이지에서 오는지 확인할 수 있어요. 같은 플랫폼이든 다른 플랫폼이든 페이지를 여러 개 연결했다면, **리뷰** 탭에서 출처 하나로 필터링하거나 출처를 여러 개 골라 여러 페이지의 피드백을 한 번에 볼 수 있어요.

**리뷰** 탭에서 할 수 있는 일은 다음과 같아요.

- **출처** 드롭다운을 열어 연결된 리뷰 페이지를 확인해요.
- 연결된 페이지를 하나 선택해 그 리스팅의 피드백만 봐요.
- 연결된 페이지를 둘 이상 선택해 여러 리스팅의 리뷰를 같은 리뷰 화면에서 봐요.
- 선택한 출처 필터로 지점, 숙소, 브랜드, 페이지별 리뷰 활동을 비교해요.

선택한 페이지는 리뷰 목록 위에 출처 필터 칩으로 표시돼요. 지금 어떤 페이지의 리뷰를 보고 있는지 한눈에 알 수 있어요. 특정 리스팅의 피드백을 확인하려고 메인 **리뷰** 탭을 벗어나지 않아도 돼서, 에이전시와 다점포 비즈니스에 특히 유용해요.

## 문제 해결

리뷰 플랫폼을 연동하다가 문제가 생겼다면 다음을 확인해 보세요.

- URL 확인: 공개된 리뷰 페이지를 가리키는 URL인지 확인하세요.
- 접근 권한 확인: 내 계정이 해당 페이지에 접근할 권한이 있는지 확인하세요.
- 캐시 지우기: 브라우저 캐시를 지워 보세요.
- 고객지원 문의: 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.

## 요약

리뷰 플랫폼을 여러 개 연동하면 리뷰 관리를 한곳에 모으고, 응답 시간을 줄이고, 모든 채널에서 좋은 온라인 평판을 유지할 수 있어요.

## 자주 묻는 질문

### 플랫폼마다 페이지를 여러 개 연결해야 하나요?
아니요. 그 플랫폼에서 리스팅을 하나만 쓴다면 페이지 하나만 연결해 두어도 돼요. 같은 플랫폼에서 페이지, 지점, 리스팅을 여러 개 관리해야 할 때 여러 페이지 연동이 유용해요.

### 플랫폼 하나에 연결할 수 있는 페이지 수에 제한이 있나요?
아니요. 이번 업데이트에서는 페이지 연결 개수 제한 없이 플랫폼마다 페이지를 여러 개 추가할 수 있어요.

### 여러 플랫폼을 연결하고, 각 플랫폼마다 페이지도 여러 개 연결할 수 있나요?
네. 지원하는 리뷰 플랫폼을 여러 개 연결하고, 해당하는 경우 플랫폼마다 페이지를 여러 개 추가할 수 있어요.

### 플랫폼에 연결된 페이지는 어디에서 볼 수 있나요?
**평판 관리 > 설정 > 연동**으로 이동해 플랫폼을 선택하고 **관리**를 열어 보세요. 연결된 페이지와 페이지별 상세 정보를 확인할 수 있어요.

### 연결된 페이지 여러 개의 리뷰를 동시에 볼 수 있나요?
네. **리뷰** 탭에서 **출처** 드롭다운을 열고 연결된 페이지를 둘 이상 선택하세요. 선택한 출처의 피드백이 리뷰 화면에 함께 표시돼서 여러 리스팅을 한꺼번에 살펴볼 수 있어요.

### 새 페이지를 추가했는데 리뷰가 바로 보이지 않아요.
새로 연결한 페이지는 리뷰 데이터를 동기화하는 데 시간이 걸릴 수 있어요. **관리** 화면에서 페이지 상태, 리뷰 수, 마지막 동기화 정보를 확인하면 데이터가 언제 업데이트됐는지 알 수 있어요.

### 여러 페이지 연동을 쓰면 리뷰 요청 메시지가 바뀌나요?
아니요. 여러 페이지 연동은 주로 모니터링과 관리를 위해 어떤 리뷰 페이지를 연결할지에 영향을 줘요. 리뷰 요청 메시지, **리뷰 링크**, 분배 설정은 고객이 올바르게 안내되는지 따로 확인해 주세요.

### 에이전시도 여러 고객사에 쓸 수 있나요?
네. 에이전시는 여러 페이지 연동으로 여러 페이지, 브랜드, 지점, 고객사 리스팅을 더 한곳에 모아 관리할 수 있어요.
