# 리뷰 요청에 사진 첨부하기

시공 전후 사진 같은 실제 작업 사진을 하이퍼클래스 리뷰 요청에 함께 보낼 수 있어요. 사진을 보면 고객이 결과를 떠올리기 쉬워서 응답률이 올라가고, 실제 후기로서 신뢰도도 높아져요.

## 개요

**평판 관리**(Reputation)의 **리뷰 요청 보내기** 창에서 리뷰 요청에 사진을 첨부할 수 있어요. 요청 하나에 최대 5장까지 올릴 수 있어서, 시공 전후 사진처럼 작업 결과를 보여 주는 사진을 곁들일 수 있어요.

사진은 메시지와 함께 전송돼요. 연락처의 **대화** 스레드에도 표시되어서 팀원이 확인할 수 있어요. 고객도 이 사진을 리뷰에 활용할 수 있어서 리뷰의 품질과 신뢰도가 높아져요.

## 사진을 첨부하면 좋은 점

- 개인화: 작업별 사진을 넣으면 요청마다 개성이 생겨요.
- 참여율 향상: 사진을 보면 고객이 작업을 떠올리기 쉬워서 리뷰 링크를 누를 가능성이 높아져요.
- 신뢰도: 실제 사진이 품질을 보여 주고, 후기의 신뢰도를 높여요.
- 채널 유연성: 한 번 보낼 때 같은 사진을 이메일과 SMS에 함께 쓸 수 있어요.
- 간편한 사용: 리뷰 요청 창에서 바로 사진을 최대 5장까지 올릴 수 있어요.

## 지원되는 채널

아래에서 사진 첨부를 지원하는 채널을 확인하세요. 어떤 채널로 보낼지 정할 때와 팀원과 기준을 맞출 때 도움이 돼요.

- 이메일(지원): 사진이 이메일 본문 아래에 첨부파일로 표시돼요.
- SMS(지원): 사진이 메시지 첨부파일로 전송돼요.
- WhatsApp(지원되지 않음): WhatsApp 리뷰 요청에는 사진을 첨부할 수 없어요.

{% hint style="warning" %}
모바일 앱에서는 아직 리뷰 요청에 사진을 첨부할 수 없어요.
{% endhint %}

## 지원하는 파일 형식과 제한

아래 형식과 크기를 지키면 사진이 문제없이 업로드되고, 받는 사람에게도 깔끔하게 보여요.

- 요청당 최대 사진 수: 최대 5장
- 지원 형식: JPG, PNG, JPEG
- 최대 파일 크기: 5MB

## 사진과 함께 리뷰 요청 보내기

사진 업로드는 몇 번만 클릭하면 끝나요. 아래 순서대로 따라 해 보세요.

#### 1단계: 리뷰 요청 보내기 화면 열기

서브 계정의 왼쪽 메뉴에서 **평판 관리**를 선택하세요. 그다음 화면 오른쪽 위에 있는 파란색 **리뷰 요청 보내기** 버튼을 클릭하세요.

![평판 관리 화면의 리뷰 요청 보내기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058026972/original/XZTmLDqWrA8l8VnvDKxQZgtE-F71Xk1Jhw.png?1762797490)

#### 2단계: 연락처 선택하기

**연락처 이름**으로 검색해서 알맞은 연락처를 선택하세요. 보낼 채널에 맞게 **연락처 전화번호**나 **연락처 이메일**이 입력되어 있는지 확인하세요.

![연락처를 검색해 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058027290/original/Po8Sa-sKD15yP3IFuK_KWSNofVnwc6GVgA.png?1762797813)

#### 3단계: 발송 채널과 템플릿 고르기

**모드 선택** 체크박스에서 발송 채널을 선택하세요. 사진은 이메일과 SMS에서만 지원하고, WhatsApp는 지원하지 않아요.

**이메일 템플릿 선택**이나 **SMS 템플릿 선택** 드롭다운에서 사용할 리뷰 요청 템플릿을 고르세요.

![발송 채널과 템플릿을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058027696/original/GiaLNMkmCK46Mh4esFIGv7Pnp6PSmA8nKQ.png?1762798121)

#### 4단계: 사진 업로드하기

**사진 업로드** 버튼을 클릭하고, 리뷰 요청에 첨부할 사진을 최대 5장까지 선택하세요. 선택한 사진의 미리보기가 **사진 업로드** 버튼 바로 아래에 표시돼요.

![사진을 업로드하고 미리보기를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058027797/original/GiLusMFbkBup-IZzegmqftmMQwSmAvQ4oA.png?1762798290)

#### 5단계: 리뷰 요청 보내기

파란색 **리뷰 요청 보내기** 버튼을 클릭하면 요청이 발송돼요.

![리뷰 요청을 발송하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058028027/original/8XE4jW1CmuWFwGMAb6t9SmGNTp1bWuwg1A.png?1762798401)

## 자주 묻는 질문

### 이메일과 SMS로 리뷰 요청을 함께 보내면 같은 사진이 쓰이나요?
네. 두 채널을 모두 선택하면 업로드한 사진이 두 채널에 똑같이 포함돼요.

### 사진이 템플릿이나 미디어 라이브러리에 저장되나요?
아니요. 사진은 발송할 때 추가되고, **대화**에서 보낸 메시지와 함께 표시돼요. 이 기능으로 올린 사진은 템플릿이나 미디어 라이브러리에 저장되지 않아요.

### 하이퍼클래스 모바일 앱에서도 쓸 수 있나요?
아직은 쓸 수 없어요. 지금은 웹 앱에서만 쓸 수 있고, 모바일 지원은 계획 중이에요.

### 워크플로우로 사진이 포함된 리뷰 요청을 자동화할 수 있나요?
지금은 안 돼요. 사진 첨부는 **리뷰 요청 보내기** 창에서 직접 추가해야 해요.
