# 이메일 템플릿에 여러 리뷰 링크 넣기

**평판 관리**(Reputation)에서 이메일 템플릿 하나에 여러 리뷰 플랫폼 링크를 넣는 방법을 안내해요. 링크가 올바른지 자동으로 확인해 주기 때문에, 잘못된 URL 걱정 없이 여러 플랫폼에서 리뷰를 받을 수 있어요.

## 여러 리뷰 링크 기능이란?

이메일 템플릿에 Google, Facebook 등 여러 리뷰 링크를 바로 넣을 수 있는 **평판 관리** 기능이에요. 연결된 리뷰 플랫폼을 모두 자동으로 불러오고, 링크마다 텍스트, 순서, 표시 여부를 바꿀 수 있어요.

이메일 한 통에 리뷰 남길 곳을 여러 개 보여 주면 고객이 편한 플랫폼을 골라 리뷰를 남길 수 있어요. 그만큼 리뷰를 받을 가능성도 높아져요.

## 여러 리뷰 링크 기능의 장점

수작업은 줄이고, 브랜드 메시지는 그대로 유지하면서 완성되는 리뷰를 늘리는 데 도움이 돼요.

- 플랫폼 선택권: 고객이 평소 쓰는 플랫폼을 골라 리뷰를 남길 수 있어요.
- 높은 전환율: 고객이 쓰지 않는 플랫폼으로 안내되어 중간에 이탈하는 일을 줄여요.
- 자유로운 문구: 브랜드 말투와 행동 유도 문구에 맞게 링크 텍스트를 바꿀 수 있어요.
- 실수 방지: 발송 전에 형식이 잘못되었거나 올바르지 않은 URL을 자동 검증으로 걸러 내요.
- 간편한 관리: 연동을 건드리지 않고도 링크 순서를 바꾸거나, 숨기거나 다시 표시하거나, 삭제할 수 있어요.

## 이메일 템플릿에 여러 리뷰 링크 넣는 방법

다음 순서로 리뷰 요청 이메일 한 통에 여러 플랫폼을 추가하세요.

1. **평판 관리 > 설정 > 이메일 요청**으로 이동하세요.

   ![평판 관리 설정의 이메일 요청 화면](https://jumpshare.com/share/HQC4Y61D9ftxhkfkrbch+/Screen+Shot+2025-08-27+at+8.27.02+PM.png)

2. + **새로 만들기**를 클릭하거나 기존 템플릿을 **편집**하세요.

   ![새 템플릿을 만들거나 기존 템플릿을 편집하는 화면](https://jumpshare.com/share/pDuqjBNn8aSVZIO5Mh8k+/GIF+Recording+2025-08-27+at+8.29.00+PM.gif)

3. **리뷰 링크** 요소를 빌더로 **드래그**해서 놓으세요. 연결된 리뷰 플랫폼이 있으면 자동으로 선택되어 있어요.

   ![리뷰 링크 요소를 빌더에 끌어다 놓는 화면](https://jumpshare.com/share/RC29HzssyZnZWMb4rUvX+/GIF+Recording+2025-08-27+at+8.32.09+PM.gif)

4. 필요에 따라 플랫폼 URL을 **추가**, **편집**하거나 **선택 해제**하세요.

   ![플랫폼 URL을 추가, 편집, 선택 해제하는 화면](https://jumpshare.com/share/HfjSNyAAk9MJC7UhJ3IT+/GIF+Recording+2025-08-27+at+8.34.52+PM.gif)

5. 링크 텍스트를 **커스터마이징**하세요. 예를 들어 "Google에 리뷰 남기기"처럼 쓸 수 있어요.
6. Google 비즈니스 프로필(GBP)이 여러 개 연결되어 있다면 원하는 GBP 위치를 선택하세요.
7. 링크를 끌어서 순서를 바꾸세요.

   ![링크를 끌어서 순서를 바꾸는 화면](https://jumpshare.com/share/SXQtvWeVlwAG1RN5EUCk+/GIF+Recording+2025-08-27+at+8.39.04+PM.gif)

8. 검증 오류가 없는지 확인하세요.
9. 템플릿을 **저장**하고 **미리보기**로 확인한 뒤 **보내기**를 클릭하세요. 반복 이메일이나 워크플로우 기반 리뷰 요청에서 이 템플릿을 사용할 수도 있어요.

   ![템플릿을 저장하고 미리보기 후 보내는 화면](https://jumpshare.com/share/sqpVeTreV0fyqNerUKSo+/GIF+Recording+2025-08-27+at+8.40.30+PM.gif)

## 자주 묻는 질문

### 리뷰 링크를 보려면 따로 켜야 하는 설정이 있나요?
아니요. 리뷰 플랫폼을 연결하면 **리뷰 링크** 구성 요소에 자동으로 나타나요.

### 플랫폼이 하나도 보이지 않아요.
**평판 관리 > 설정 > 연동**에서 리뷰 플랫폼을 연결하세요. 그런 다음 **이메일 빌더**로 돌아가 **리뷰 링크**를 열어 보세요.

### 링크마다 행동 유도(CTA) 문구를 따로 바꿀 수 있나요?
네. 플랫폼마다 텍스트를 편집해서 브랜드 말투에 맞출 수 있어요.

### 추가한 리뷰 링크의 순서를 바꾸거나 지울 수 있나요?
네. 이메일 빌더에서 각 링크의 순서를 바꾸거나, 선택·선택 해제하거나, 삭제할 수 있어요.

### 추가할 수 있는 링크 수에 제한이 있나요?
한 이메일에 링크를 여러 개 추가할 수 있어요. 읽기 편하도록 목록은 간결하게 유지하는 것이 좋아요.

### 리뷰 링크 자동 검증은 어떻게 작동하나요?
구성 요소가 각 링크를 자동으로 확인해서, 깨졌거나 잘못된 URL이 들어갈 가능성을 줄여 줘요.

### 이메일에서 플랫폼을 숨기려면 연동을 해제해야 하나요?
아니요. 템플릿에서 해당 플랫폼을 선택 해제하면 연동은 그대로 두고 이메일에서만 숨길 수 있어요.

### 이 템플릿을 자동화나 반복 발송에도 쓸 수 있나요?
네. 템플릿을 저장한 뒤 **반복 이메일**이나 워크플로우의 **Review Request**(리뷰 요청) 액션에서 사용하세요.
