# 수동 리뷰 — 오프라인 리뷰 추가하고 관리하기

종이 설문지, 이메일, 전화처럼 연동된 플랫폼 밖에서 받은 고객 후기를 하이퍼클래스에 직접 넣을 수 있어요. 리뷰를 하나씩 추가하거나 CSV로 한꺼번에 가져올 수 있고, Google 등 연동된 리뷰와 함께 보여 줄 수 있어요. 웹사이트용 리뷰 위젯에도 넣을 수 있어요. 이 문서에서 설정 방법, 입력 방법, 표시 방법을 안내해요.

## 수동 리뷰란?

수동 리뷰는 오프라인이나 지원되지 않는 플랫폼에서 받은 후기를 기록하는 기능이에요. 연동으로 가져온 리뷰만 보이는 게 아니라, 평판 데이터와 요약, 웹사이트 위젯에 전체 후기가 반영돼요. 이렇게 추가한 리뷰는 **평판 관리 > 리뷰**에 모여요. 기존 리뷰와 같은 방식으로 관리하고 필터링하고 보여 줄 수 있어요.

## 수동 리뷰의 장점

수동 리뷰는 예전 후기를 옮겨 올 때, 오프라인 채널의 빈틈을 채울 때, 흩어진 출처를 하나로 모을 때 쓰면 좋아요.

- 빠짐없이 모으기: 오프라인이나 지원되지 않는 플랫폼의 리뷰를 추가해서, 공개하는 후기가 연동된 플랫폼에만 머물지 않아요.
- 한곳에서 관리하기: 하나의 리뷰 목록에서 같은 카드 모양, 필터, 라벨로 관리해요.
- 대량 가져오기: 과거 데이터를 CSV로 빠르게 가져와요. 입력값 검증도 함께 이루어져요.
- 위젯에 바로 사용: 수동 리뷰를 여러 위젯 레이아웃에 게시하고, 출처별로 필터링해서 원하는 리뷰만 골라 보여 줄 수 있어요.
- 이전하기 쉬움: 예전 후기를 하이퍼클래스로 옮겨 지난 성과를 계속 보여 줄 수 있어요.
- AI 요약과 호환: AI 요약이 모든 후기를 분석해요.

## 수동 리뷰 설정하기

**실험실**에서 수동 리뷰를 켜면 계정에서 이 기능을 쓸 수 있어요. 켠 뒤에는 **리뷰** 탭에서 리뷰를 하나씩 추가하거나 CSV로 가져오고, 필요하면 위젯으로 게시하세요.

### 리뷰 하나씩 직접 추가하기

1. **평판 관리**를 열고 **리뷰** 탭에서 **리뷰 추가**를 클릭하세요.

   ![리뷰 탭에서 리뷰 추가 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065394120/original/SoAnyGJdiaHFvcVyHfBmEyMulT1I1v1tpg.png?1771622745)

2. **수동으로 추가** 탭을 선택하세요.

   ![수동으로 추가 탭 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065394037/original/LEziFl1yca2pkBbkhWQBY_SqhtX0uJ4lOA.png?1771622705)

3. **Rating**(평점), **Testimonials**(후기), **Date**(날짜), **Platform**(플랫폼), **프로필 사진**, **고객 이름** 같은 항목을 필요에 맞게 입력하세요.

   ![리뷰 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065394146/original/zvF9ITNFOESJRRp56nesng1Nja7U7xqFzA.png?1771622887)

   ![리뷰 제출 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065394147/original/8VP3VPU7aWpLICUVd26QSLG0YQ7BuVLiNQ.png?1771622909)

## 위젯에 수동 리뷰 표시하기

수동 리뷰를 웹사이트에 보여 주면, 잠재 고객이 업체를 살펴보는 곳 어디서든 오프라인에서 받은 좋은 후기를 볼 수 있어요. 모든 위젯 레이아웃과 필터에서 사용할 수 있어요.

1. **평판 관리 > 위젯**으로 이동해서 위젯을 선택하거나 새로 만드세요.

   ![평판 관리 위젯 화면에서 위젯 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065394218/original/hwZsYJGMQxwCiRiNZuY1Fq_ueQBV8hztDA.png?1771623161)

2. **리뷰 출처**에서 **수동**을 선택하세요.

   ![리뷰 출처에서 수동 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065394238/original/8U033SDG6faRQlWdliFvNOEJwL13nfW5lw.png?1771623232)

3. 레이아웃을 고르고 표시 설정(예: 최대 표시 개수, 최소 평점)을 조정한 뒤, 필요한 곳(사이트, 퍼널, WordPress 등)에 위젯을 삽입하세요.

   ![레이아웃과 표시 설정 조정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065394251/original/4T0cdma1xaTLTno4E7q4-7CN2jVfsIzGOw.png?1771623284)

## 자주 묻는 질문

### 수동 리뷰가 AI 요약에 영향을 주나요?
네. 수동 리뷰는 AI 요약과 호환돼요. 그래서 요약에 연동으로 가져온 후기와 직접 추가한 후기가 모두 반영돼요.

### 기본으로 지원하지 않는 플랫폼이나 출처도 추가할 수 있나요?
네. 수동 리뷰를 추가할 때 기존 플랫폼을 선택하거나, 직접 플랫폼/출처를 만들거나(예: Checkatrade), **No Platform**(플랫폼 없음)을 선택할 수 있어요.

### 수동 리뷰는 추가하거나 가져온 뒤 어디에 나타나나요?
**평판 관리 > 리뷰**에 **Manual Pages**(수동 페이지) 라벨이 붙어서 나타나요. **출처**로 필터링할 수도 있어요.

### 수동 리뷰를 위젯에 표시할 수 있나요?
네. 수동 리뷰는 리뷰 위젯에 표시할 수 있어요. 여러 레이아웃에서 출처를 조합하거나 필터링할 수도 있어요.

### 한꺼번에 가져오는 방법이 있나요?
네. CSV 업로드 기능과 내려받을 수 있는 템플릿을 사용하면 여러 리뷰를 한 번에 가져올 수 있어요. 입력값 검증이 있어서 잘못된 데이터를 막는 데 도움이 돼요.

### 수동 리뷰에는 어떤 항목을 입력할 수 있나요?
**고객 이름**, **Rating**, **Review Text**(리뷰 내용), **Date**, **Platform**/**출처**, **프로필 사진**, **Photo Attachments**(사진 첨부)를 입력할 수 있어요. 항목의 사용 가능 여부와 필수 여부는 화면의 입력 폼과 템플릿을 따라요.

### 위젯의 **리뷰 작성** 링크를 바꿀 수 있나요?
네. 위젯에서 **리뷰 작성** 링크를 바꿀 수 있어서, 고객을 원하는 주소로 보낼 수 있어요.

### 수동 리뷰만 골라서 보려면 어떻게 하나요?
**리뷰** 탭의 **출처** 필터에서 **수동**(**Manual Pages**)을 선택하세요. 직접 만든 플랫폼 이름을 선택해도 돼요.
