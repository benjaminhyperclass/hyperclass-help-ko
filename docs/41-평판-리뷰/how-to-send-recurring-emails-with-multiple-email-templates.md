# 반복 이메일에 여러 이메일 템플릿 사용하기

**평판 관리**(Reputation Management)에서 반복 리뷰 요청 이메일마다 다른 이메일 템플릿을 지정할 수 있어요. 후속 이메일을 보낼 때마다 내용을 바꿔서 받는 사람에게 더 알맞게 보내고 싶을 때 쓰세요.

## 1단계: 이메일 리뷰 요청 화면으로 이동하기

1. 대시보드에서 **평판 관리**를 엽니다.
2. **이메일 리뷰 요청** 섹션으로 이동합니다.

![이메일 리뷰 요청 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042198552/original/sYqXq78eHw9yMbjjj8d-o6Ku4mo_J_ZVPw.png?1740482435)

## 2단계: 반복 리뷰 요청 켜기

1. **Maximum Retries**(최대 재시도 횟수) 옵션을 찾습니다.
2. **Recurring Review Requests**(반복 리뷰 요청)를 켭니다. 이렇게 하면 후속 이메일을 여러 번 보낼 수 있어요.

## 3단계: 이메일 템플릿 선택하고 이메일 제목 설정하기

1. 후속 이메일마다 사용할 **이메일 템플릿**을 각각 고릅니다.
2. 미리 만들어진 템플릿 중에서 고르거나 직접 만들 수 있어요.
3. 각 반복 이메일의 **이메일 제목**을 설정합니다.

![이메일 템플릿 선택과 이메일 제목 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042198698/original/YV3pGU4Vgtn7A5JCSwGB1k1UB8gbESSh_w.png?1740482467)

## 4단계: 이메일 콘텐츠 꾸미기

1. **이메일 빌더**에서 브랜드 분위기와 받는 사람에 맞게 내용을 수정합니다.
2. 개인화 요소를 추가해 참여를 높여 보세요.

![이메일 빌더에서 콘텐츠 수정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042198782/original/okQojkoSsYGzB6fkfoOvIC1OTKPKR7v8sA.png?1740482477)

## 5단계: 저장하고 반복 이메일 활성화하기

1. 모든 이메일 순서에 템플릿이 알맞게 지정되었는지 설정을 확인합니다.
2. **Save & Activate**(저장 및 활성화)를 클릭합니다. 이제 선택한 템플릿으로 이메일이 자동으로 발송돼요.

반복 리뷰 요청에 여러 이메일 템플릿을 쓰면 받는 사람의 관심을 유지하고 응답률을 높이며, 브랜드 평판을 쉽게 관리할 수 있어요. 지금 템플릿을 설정해 보세요.
