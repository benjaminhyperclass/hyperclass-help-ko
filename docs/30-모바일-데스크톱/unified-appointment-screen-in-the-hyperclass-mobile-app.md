# 모바일 앱의 통합 예약 화면

하이퍼클래스 모바일 앱에서 예약 하나를 한 화면의 탭으로 관리하는 방법을 안내해요. 통합 예약 화면에서는 예약 상세 정보, 참석자, 폼 제출, 메모, 활동 기록, 결제를 모두 볼 수 있어요. **캘린더**, **연락처**, **폼**, **결제** 메뉴를 오가지 않고 예약을 관리할 수 있어요.

이 문서에서는 통합 예약 화면을 여는 방법, 탭별 용도, 모바일 앱에서 예약 정보를 관리하는 방법을 설명해요.

## 통합 예약 화면이란?

통합 예약 화면은 하이퍼클래스 모바일 앱 안에서 예약 하나를 한곳에서 보여 주는 화면이에요. 예약 상세 정보, 참석자, 폼 제출, 내부 메모, 활동 기록을 볼 수 있어요. 결제 설정이 되어 있으면 결제도 함께 볼 수 있어요.

예약 하나를 파악하려고 여러 메뉴를 열 필요가 없어요. **캘린더**에서 예약을 열면 중요한 정보를 탭별로 정리해서 볼 수 있어요.

## 통합 예약 화면의 장점

예약 화면이 한곳에 모여 있으면 팀이 더 빠르게 일하고 놓치는 내용도 줄일 수 있어요. 예약과 관련된 작업을 해당 예약에 연결해서 처리할 수 있어요. 하루 종일 모바일 기기로 예약을 관리하는 팀에 특히 유용해요.

- 시간 절약: 예약 상세 정보, 메모, 참석자, 폼, 활동, 결제를 예약 화면 하나에서 관리해요.
- 메뉴 이동 감소: **캘린더**, **연락처**, **폼**, **결제** 사이를 오가지 않고 예약 관련 정보를 확인해요.
- 더 빠른 결제 수금: 결제가 설정되어 있으면 예약 화면에서 **카드로 청구**하거나 수동 결제를 기록하고 결제 내역을 확인해요.
- 체계적인 관리: 내부 메모, 폼 제출, 활동 업데이트를 예약에 붙여서 보관해요.
- 팀 협업 개선: 어시스턴트, 영업 담당자, 직원이 예약을 정확하게 관리하는 데 필요한 맥락을 얻어요.
- 실수 감소: 예약 정보를 한곳에 모아 두어 여러 메뉴를 뒤지는 시간을 줄여요.

## 통합 예약 화면의 탭

탭마다 예약 업무의 한 부분을 다뤄요. 예약 유형, 예약 설정, 폼 설정, 결제 설정에 따라 보이는 탭이 다를 수 있어요.

### 상세 정보

**상세 정보** 탭에는 예약을 확인하고, 수정하고, 검토하는 데 필요한 핵심 정보가 나와요. **캘린더**를 벗어나지 않고도 예약을 빠르게 변경할 수 있어요.

### 참석자

**참석자** 탭에서는 예약에 연결된 사람들을 확인하고 관리해요. **Class Booking**(클래스 예약)에서는 참석자별로 설정을 바꿀 수 있어서, 수업 전체에 영향을 주지 않고 한 사람의 예약만 수정할 수 있어요.

하이퍼클래스 모바일 앱 버전 **4.20.0 이상**에서는 **Class Booking** 참석자 옆의 점 세 개 메뉴를 눌러 다음 작업을 할 수 있어요.

- **Change Status**(상태 변경): 참석자의 상태를 **확정**, **참석**, **노쇼**, **취소됨** 중에서 선택해요.
- **일정 변경**: 해당 참석자 예약의 예약 편집 화면을 열어요.
- **View Contact**(연락처 보기): 참석자의 연락처 레코드를 열어요.
- **취소**: 수업의 다른 예약은 그대로 두고 해당 참석자의 예약만 취소해요.

{% hint style="info" %}
**일정 변경**을 누르면 선택한 참석자 예약의 편집 화면이 열려요. 추가 일정 변경 항목과 완료 절차는 확인된 릴리스 자료가 없어서 이 문서에서 다루지 않아요.
{% endhint %}

### 폼 제출

**폼 제출** 탭에서는 예약과 연결된 예약 폼 응답을 확인해요. 제출된 사전 정보를 예약 가까이에 두면 미팅, 서비스, 상담, 통화를 준비하기 편해요.

모바일 통합 예약 화면의 **폼 제출** 탭은 현재 기본 폼을 지원해요. 커스텀 폼 지원은 이후 업데이트에서 제공할 예정이에요.

### Notes

**Notes**(메모) 탭에서는 팀원이 예약에 관한 내부 메모를 추가하고 확인해요. 메모를 남겨 두면 맥락과 변경 내용이 보존되고, 직원 간 인수인계도 수월해져요.

예약 메모는 내부 팀용이에요. 예약 업무 전반에서 중요한 맥락을 볼 수 있게 도와줘요.

### Activity Log

**Activity Log**(활동 기록) 탭에는 예약 업데이트가 시간순으로 나와요. 읽기 전용이라서 무엇이 언제 바뀌었는지, 예약이 어떻게 진행됐는지 확인할 수 있어요.

**Activity Log**는 읽기 전용이라 타임라인을 수정하지 않고 예약 이력을 점검할 수 있어요.

### 결제

**결제** 탭은 해당 예약에 결제가 설정되어 있을 때 나타나요. 별도의 결제 화면으로 이동하지 않고 예약 화면에서 결제 내역을 확인하고 결제를 받을 수 있어요.

**결제** 탭이 보이지 않으면 해당 예약이나 캘린더에 결제 설정이 되어 있지 않을 수 있어요.

## 일정 변경 링크 생성하고 공유하기

모바일 앱에서 예약별 일정 변경 링크를 공유하면 고객이 직접 새 예약 시간을 고를 수 있어요.

이 기능은 지원되는 미팅 예약과 서비스 예약에서 쓸 수 있어요.

일정 변경 링크를 공유하려면 다음과 같이 하세요.

1. **연락처**, **대화**, **예약**, **기회 관리**(Opportunities) 중 한 곳에서 예약을 열어요.
2. 오른쪽 위의 점 세 개 메뉴를 눌러요.
3. **일정 변경 링크 생성**을 눌러요.

   ![일정 변경 링크 생성 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082329159/original/pPAFeybzNBp6Iqr2IVQqvrFb_IV-r6ungQ.jpeg?1790883933)

4. **일정 변경 링크 공유** 시트에 해당 예약의 일정 변경 링크가 나와요. **Share**(공유)를 눌러요.

   ![일정 변경 링크 공유 시트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082329164/original/EQI3lIxob3KIx6qP8bxQIo4dAuOBwzvZ0g.png?1790883948)

5. 기기의 공유 시트에서 앱을 선택해 고객에게 링크를 보내요.

   ![기기 공유 시트에서 앱 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082329170/original/lmAupevVYfPhb-YoZuHNvlmiNWgAmQadGQ.png?1790883966)

{% hint style="warning" %}
링크가 있는 모든 사람은 예약 시간을 바꿀 수 있어요. 링크는 해당 고객에게만 공유하세요.
{% endhint %}

## 통합 예약 화면 사용하기

모바일 앱에서 예약 상세 정보, 결제, 폼, 메모, 활동 정보를 보려면 지원되는 앱 버전을 쓰고 있어야 하고 **캘린더** 메뉴에 접근할 수 있어야 해요. 사용 전에 팀이 이 조건을 갖췄는지 확인하세요.

통합 예약 화면을 열고 사용하려면 다음과 같이 하세요.

1. 하이퍼클래스 모바일 앱을 열어요.
2. **캘린더** 메뉴로 이동해요.

   ![모바일 앱의 캘린더 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071413345/original/tEbZ2crEV-QzIEw7mJ4AvftJE45UXR4bSQ.png?1778846896)

3. 기존 예약이나 Service (v2) 예약을 열어요.
4. 사용할 수 있는 탭을 확인해요.
   - **상세 정보**
   - **참석자**
   - **폼 제출**
   - **Notes**
   - **Activity Log**
   - **결제** (설정된 경우)

   ![통합 예약 화면의 탭 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071413481/original/cjM9_TS9czwlGe4j9OP6Pa4QuG8KyEmEWA.png?1778846972)

   ![통합 예약 화면의 탭 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071413592/original/k3srkFoWQUV8L3UYURpnPf_qTVfx3GfYRA.png?1778847031)

5. 예약 정보를 확인하거나 관리할 탭을 선택해요.
6. 사용할 수 있는 옵션에 따라 예약 상세 정보를 수정하고, 참석자를 확인하고, 폼 제출을 보고, 메모를 추가하고, 활동을 확인하고, 결제를 받아요.

   **Class Booking 참석자 한 명씩 관리하기**

   참석자를 한 명씩 관리하면 수업의 다른 예약은 그대로 두고 상태 변경, 취소, 일정 변경 요청에 대응할 수 있어요.

   1. 하이퍼클래스 모바일 앱을 열어요.
   2. **캘린더** 메뉴를 선택해요.
   3. 관리할 **Class Booking** 예약을 눌러요. **Class Booking** 예약은 **2/5 Class Booking**처럼 좌석 수가 표시된 캘린더 타일 하나로 보여요.
   4. **참석자** 탭을 선택해요.
   5. 관리할 참석자 옆의 점 세 개 메뉴를 눌러요.
   6. 필요한 작업을 선택해요.
      - **Change Status**
      - **일정 변경**
      - **View Contact**
      - **취소**
   7. **Change Status**를 선택했다면 해당 참석자의 상태를 **확정**, **참석**, **노쇼**, **취소됨** 중에서 골라요.

## 자주 묻는 질문

### 통합 예약 화면은 어디에서 열 수 있나요?
하이퍼클래스 모바일 앱에서 **캘린더** 메뉴로 이동한 다음 기존 예약을 열면 돼요.

### 통합 예약 화면은 하이퍼클래스 모바일 앱에서 쓸 수 있나요?
네. 하이퍼클래스 모바일 앱에서 쓸 수 있어요.

### 어떤 앱 버전이 필요한가요?
통합 예약 화면은 4.12.0 (816) 버전 이상에서 쓸 수 있어요.

### **결제** 탭이 안 보여요.
**결제** 탭은 해당 예약이나 캘린더에 결제가 설정되어 있을 때만 나타나요.

### 예약 화면에서 결제를 받을 수 있나요?
네. 결제가 설정되어 있으면 **결제** 탭에서 결제를 받고, **카드로 청구**하고, 수동 결제를 기록하고, 거래 내역을 확인할 수 있어요.

### 모바일 통합 예약 화면에서 커스텀 폼 제출을 볼 수 있나요?
커스텀 폼 지원은 이후 업데이트에서 제공할 예정이에요. 현재 모바일 버전의 **폼 제출** 탭은 기본 폼을 지원해요.

### 예약 메모가 고객에게도 보이나요?
**Notes** 탭에서 추가한 메모는 내부 팀용이에요.

### Class Booking 참석자를 한 명씩 관리할 수 있나요?
네. 하이퍼클래스 모바일 앱 버전 4.20.0 이상에서 **캘린더**의 **Class Booking** 예약을 열고 **참석자** 탭을 선택한 다음, 참석자 옆의 점 세 개 메뉴를 누르세요. 해당 참석자의 상태 변경, 예약 일정 변경, 연락처 보기, 예약 취소를 개별로 할 수 있어요.

### 미팅 예약에 **일정 변경 링크 생성** 옵션이 안 보여요.
**일정 변경 링크 생성** 옵션은 미팅 예약을 편집할 수 있고 연락처가 연결되어 있을 때 나타나요. 다음 경우에는 나타나지 않아요.
- Calendly에서 가져온 미팅 예약
- 사용자 지정 반복 미팅 예약
- 아직 불러오는 중이거나 오류 상태인 예약
- 예약을 관리할 권한이 없는 사용자

### 서비스 예약에서는 **일정 변경 링크 생성** 옵션을 언제 쓸 수 있나요?
서비스 예약은 예약을 불러온 뒤 필요한 예약 권한이 있을 때 예약 작업 메뉴가 나타나요.

### 취소됨이나 노쇼 상태의 예약도 일정 변경 링크를 만들 수 있나요?
네. **취소됨**과 **노쇼** 상태의 예약도 일정 변경 링크를 만들 수 있어요.

### 일정 변경 링크를 만들 수 없으면 어떻게 되나요?
앱에서 일정 변경 링크를 만들지 못하면 **일정 변경 링크 공유** 시트에 N/A가 표시되고 **Share** 버튼이 비활성화돼요.
