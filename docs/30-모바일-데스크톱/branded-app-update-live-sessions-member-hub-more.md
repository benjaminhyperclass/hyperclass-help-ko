# 브랜드 모바일 앱 업데이트: 라이브 세션, Member Hub 등

브랜드 모바일 앱이 새롭게 바뀌었어요. 멤버는 커뮤니티에서 바로 라이브 세션과 룸에 참여할 수 있고, 콘텐츠와 계정 영역을 더 쉽게 오갈 수 있어요. 또 **Member Hub**(멤버 허브)에서 중요한 자료를 한곳에서 관리할 수 있어요. 새 앱에는 새로워진 브랜딩, 간소해진 인증, 개선된 미디어 성능, 앞으로의 개선을 뒷받침하는 최신 인터페이스도 담겼어요.

## 업데이트된 브랜드 모바일 앱이란?

업데이트된 브랜드 모바일 앱은 하이퍼클래스의 멤버용 기능을 더 현대적인 모바일 환경에 모았어요. 커뮤니티, 코스, 계정 자료, 라이브 기능 같은 멤버 도구를 서로 떨어진 화면을 오가지 않고 쉽게 찾아 쓸 수 있어요.

브랜드 모바일 앱은 이전처럼 비즈니스 브랜딩을 입힌 iOS와 Android 네이티브 앱으로 제공돼요. 새 디자인에서는 탐색이 편해지고, 성능이 좋아지고, 로그인이 간단해지고, 계정에 연결된 자료에 더 쉽게 접근할 수 있어요.

기존 멤버는 지금 쓰는 **클라이언트 포탈** 로그인 방식을 그대로 쓸 수 있어요. 하이퍼클래스의 통합 클라이언트 포탈 구조는 코스, 커뮤니티, 멤버십, 청구/결제 같은 자료를 로그인 하나로 묶어서 보여 주도록 만들어졌어요.

- 통합 클라이언트 포탈에 대해 더 알아보려면 [통합 클라이언트 포탈 경험](../39-클라이언트-포털/unified-client-portal-experience.md)을 참고하세요.
- 앱 브랜딩 설정 방법은 [클라이언트 포탈 브랜드 모바일 앱: 앱 브랜딩 설정하기](../39-클라이언트-포털/Client-Portal/client-portal-branded-mobile-app-setting-up-branding-of-your-app.md)를 참고하세요.

## 업데이트된 브랜드 모바일 앱의 장점

새 브랜드 모바일 앱은 중요한 콘텐츠와 계정 자료를 하나의 모바일 환경에서 쉽게 찾게 해 줘요. 성능과 탐색이 좋아져서 멤버가 콘텐츠를 찾는 시간은 줄고, 비즈니스를 이용하는 시간은 늘어나요.

- 라이브 세션과 룸: 멤버가 커뮤니티에서 지원되는 라이브 오디오·영상 세션에 바로 참여할 수 있어요.
- 빠른 성능: 앱 로딩, 탐색, 미디어 성능이 좋아져서 더 부드럽게 쓸 수 있어요.
- 간편한 멤버 접근: 로그인과 가입 화면이 새로워져서 자료에 더 쉽게 들어갈 수 있어요.
- 새로워진 탐색: 커뮤니티, 코스, 계정 등 사용할 수 있는 영역 사이를 더 쉽게 이동할 수 있어요.
- 한곳에 모은 Member Hub: 청구/결제, 구독, 수료증, 문서, 계약, 공유된 파일을 한 영역에서 찾을 수 있어요.
- 일관된 브랜딩: 새 환영 화면과 멤버 화면 전반에서 비즈니스 브랜딩이 계속 보여요.
- 안정성 향상: 새 앱 구조 덕분에 더 안정적이고, 앞으로의 개선도 더 쉽게 전달할 수 있어요.

## 라이브 세션과 룸

**라이브 세션**과 룸을 쓰면 멤버가 브랜드 모바일 앱을 벗어나지 않고도 실시간 커뮤니티 활동에 참여할 수 있어요. 진행자가 세션을 어떻게 설정했는지에 따라 영상, 오디오, 채팅, 리액션, 화면 공유 같은 기능을 쓸 수 있어요.

멤버는 커뮤니티 이벤트 화면에서 지원되는 라이브 룸 이벤트에 바로 들어갈 수 있어요. 하이퍼클래스의 라이브 룸 기능은 커뮤니티에 내장되어 있어서, 기본 라이브 룸 이벤트에 참여할 때 별도의 미팅 앱이 필요 없어요.

하이퍼클래스는 커뮤니티의 **Go Live**(라이브 시작) 세션도 지원해요. **Go Live**는 상호작용형 미팅룸이나 방송에 쓸 수 있고, 멤버는 지원되는 웹과 모바일 환경에서 참여할 수 있어요.

라이브 경험을 만들고 진행하는 방법은 [커뮤니티 이벤트의 라이브 룸](../17-멤버십-커뮤니티/커뮤니티/live-rooms-in-communities-events.md)과 [커뮤니티 - Go Live로 미팅과 방송 진행하기](../17-멤버십-커뮤니티/커뮤니티/communities-use-go-live-to-host-meetings-broadcasts.md)를 참고하세요.

## 새로워진 로그인과 환영 화면

로그인 과정이 간단해져서 멤버가 불필요한 단계 없이 콘텐츠에 들어갈 수 있어요. 새 환영 화면은 비즈니스 브랜딩, 멤버 인증, 로그인 후 보이는 자료 사이의 흐름도 더 자연스럽게 이어 줘요.

하이퍼클래스의 통합 클라이언트 포탈은 접근 방식을 하나로 합쳤어요. 멤버는 로그인 하나로 클라이언트 포탈 ID에 연결된 코스, 커뮤니티, 멤버십, 청구/결제 자료를 볼 수 있어요. 통합 경험을 켰다는 이유만으로 멤버를 다시 초대할 필요는 없어요.

예전에 같은 클라이언트 포탈 ID로 중복 연락처가 있던 멤버는, 해당되는 자료가 하나의 로그인 아래에 함께 표시될 수 있어요. CRM의 연락처 레코드가 자동으로 병합되지는 않아요.

## 새로워진 홈과 탐색

새 **홈** 화면은 멤버가 브랜드 모바일 앱을 열었을 때 어디서 시작하면 되는지 더 분명하게 보여 줘요. 탐색이 개선되어 따로 떨어진 화면을 뒤질 필요가 줄고, 필요한 코스, 커뮤니티, 계정 자료 등을 더 빨리 찾을 수 있어요.

멤버가 쓸 수 있는 자료에 따라, 탐색에서 다음과 같은 영역으로 들어갈 수 있어요.

- 커뮤니티
- 코스
- **Account**(계정)
- 청구/결제 관련 자료
- 공유된 파일
- 앱에서 쓸 수 있는 그 밖의 멤버 도구

하이퍼클래스의 통합 클라이언트 포탈 구조는 고객에게 보이는 모든 자료에 하나의 탐색 체계를 제공하고, 콘텐츠 찾기와 모바일 반응 속도도 개선하도록 설계되었어요.

## Member Hub

**Member Hub**(멤버 허브)는 계정과 관련된 자료를 여러 영역에서 찾아다니지 않고 한곳에서 볼 수 있게 해 줘요. 멤버마다 보이는 항목은 계정에 연결된 자료와 기능에 따라 달라요.

**Member Hub**에서는 지원되는 다음 자료에 접근할 수 있어요.

- 청구/결제 정보
- **구독**
- **Documents**(문서)
- **문서 & 계약**
- **수료증**
- **공유된 파일**

공유된 파일과 연락처 레코드의 문서는 하이퍼클래스의 **문서 & 계약**과 별개예요. 공유 문서는 연락처 레코드에 연결되어 클라이언트 포탈로 제공되는 파일이에요. **문서 & 계약**은 제안서, 계약서, 견적서, 서명 같은 문서 처리 작업을 지원해요.

공유 문서 기능을 쓸 수 있는 멤버는 클라이언트 포탈에서 지원되는 파일을 업로드할 수도 있어요. 업로드한 파일은 하이퍼클래스의 해당 멤버 연락처 레코드에 연결돼요.

수료증이 발급된 멤버는 발급된 수료증을 미리 보거나 다운로드하거나 공유할 수 있어요.

- 문서 공유와 관리 방법은 [클라이언트 포탈과 CRM으로 문서 공유하고 관리하기](../02-연락처/how-to-share-and-manage-documents-via-client-portal-and-crm.md)를 참고하세요.
- 멤버의 파일 업로드는 [클라이언트 포탈에서 문서 업로드하기](../39-클라이언트-포털/upload-documents-through-the-client-portal.md)를 참고하세요.

## 성능과 안정성 개선

로딩이 빨라지고 탐색 반응이 좋아져서 멤버가 기다림 없이 콘텐츠를 이용할 수 있어요. 새 구조는 하이퍼클래스에서 고객에게 보이는 화면 전반에 앞으로의 개선을 전달하기 위한 더 탄탄한 기반이 되기도 해요.

업데이트된 브랜드 모바일 앱에는 다음과 같은 개선이 포함돼요.

- 앱 실행 속도 향상
- 더 부드러운 탐색
- 이미지 성능 개선
- 오디오 성능 개선
- 영상 성능 개선
- 안정성 향상
- 앞으로의 업데이트를 더 빠르게 전달할 수 있는 최신 기반

하이퍼클래스의 통합 클라이언트 포탈은 공통의 최신 구조 위에 만들어졌어요. 데스크톱과 모바일 모두에서 성능을 높이고, 앞으로의 개발도 더 빠르게 할 수 있도록 설계되었어요.

## 업데이트된 브랜드 모바일 앱으로 자동 전환

이번 브랜드 모바일 앱 업데이트는 기존 멤버에게 불편이 생기지 않도록 설계되었어요. 대상이 되는 브랜드 모바일 앱은 자동으로 업데이트되므로, 멤버가 콘텐츠를 직접 옮기거나 새 디자인 때문에 별도의 멤버 환경을 만들 필요가 없어요.

브랜드 모바일 앱 출시 기준으로 다음과 같이 진행돼요.

1. 앱을 직접 전환할 필요가 없어요.
2. 업데이트된 브랜드 모바일 앱은 대상 앱에 자동으로 배포돼요.
3. 기존 멤버는 브랜드 모바일 앱에서 제공하던 멤버 접근 방식을 계속 사용해요.
4. 해당 브랜드 모바일 앱 업데이트가 끝나면 이메일로 알려 드려요.

브랜드 모바일 앱 배포는 하이퍼클래스 안에 있을 수 있는 클라이언트 포탈의 별도 활성화나 미리보기 설정과는 다릅니다. 통합 클라이언트 포탈은 계정 환경에 따라 자체 활성화·전환 과정이 있을 수 있어요.

## 자주 묻는 질문

### 기존 멤버가 새 계정을 만들어야 하나요?
기존 멤버는 지금 쓰던 클라이언트 포탈 접근 방식을 계속 사용하면 돼요. 하이퍼클래스의 통합 환경은 인터페이스가 업그레이드되었다는 이유만으로 멤버를 다시 초대하지 않아도 접근이 유지되도록 설계되었어요.

### 멤버를 전환할 때 중복된 CRM 연락처가 병합되나요?
아니요. 하이퍼클래스의 통합 클라이언트 포탈은 같은 클라이언트 포탈 ID에 연결된 자료를 하나의 멤버 로그인 아래에 모아 보여 줄 수 있지만, 중복된 CRM 연락처 레코드가 자동으로 병합되지는 않아요.

### 멤버가 라이브 세션을 보기만 하지 않고 직접 참여할 수도 있나요?
라이브 룸 설정과 진행자가 정한 권한에 따라, 멤버가 오디오, 영상, 채팅, 리액션, **Raise Hand**(손들기) 같은 지원되는 상호작용 기능을 쓸 수 있어요.

### 공유된 파일과 문서 & 계약은 같은 건가요?
아니요. 연락처 레코드의 문서와 공유된 파일은 하이퍼클래스의 **문서 & 계약**과 별개예요. **문서 & 계약**은 제안서, 계약서, 견적서, 서명 같은 문서 처리 작업을 지원해요.

### 업데이트된 멤버 화면에서 멤버가 파일을 업로드할 수 있나요?
지원되는 클라이언트 포탈 환경에서는 멤버가 허용된 문서 및 이미지 파일 형식을 업로드할 수 있어요. 업로드한 파일은 해당 멤버의 연락처 레코드에 연결돼요.

### Member Hub에서 모든 멤버에게 같은 옵션이 보이나요?
꼭 그렇지는 않아요. 청구/결제 정보, 수료증, 문서, 구독, 공유된 파일처럼 멤버에게 설정되거나 지정된 자료에 따라 보이는 항목이 달라요.

### 브랜드 모바일 앱 업데이트로 기존 워크플로우와 자동화가 바뀌나요?
새로워진 통합 클라이언트 포탈은 멤버에게 보이는 화면만 바꿔요. 기존의 백엔드 라우팅, 워크플로우, 자동화, 연동은 바뀌지 않아요.
