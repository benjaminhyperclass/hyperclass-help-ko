# Windows, macOS, Linux용 하이퍼클래스 데스크톱 앱 설치하기

하이퍼클래스 데스크톱 앱은 **macOS, Windows, Linux**에서 쓸 수 있어요. 방해 요소 없이 빠르게 쓸 수 있고, 운영체제 기본 알림도 받을 수 있어요. 하이퍼클래스를 하루 종일 켜 두는 팀에 잘 맞아요. 이 문서에서는 앱을 컴퓨터에 설치하고 처음 로그인하는 방법을 안내해요.

## 데스크톱 앱 설치하기 (macOS, Windows, Linux)

사용하는 운영체제에 맞는 안내를 따라 하세요. 어느 운영체제든 네 단계로 끝나요.

### macOS

1. 설치 파일을 내려받아요. 위 표에서 macOS용 `.dmg` 링크를 누르세요.

   ![macOS 설치 파일 내려받기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061959620/original/aKSZgs_a0R1EUTGZjZInzLj9LIPAxajuMQ.gif?1767666117)
2. 설치해요. `.dmg` 파일을 열고 하이퍼클래스 아이콘을 응용 프로그램(Applications) 폴더로 끌어다 놓으세요.

   ![하이퍼클래스를 응용 프로그램 폴더로 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061959840/original/kaDik86DRGPYgBxrulUxatN4JLTwI3L8Uw.gif?1767666746)
3. 하이퍼클래스를 실행해요. 응용 프로그램 폴더, **런치패드**, Spotlight 중 편한 곳에서 열면 돼요.
4. **로그인**을 눌러요. 데스크톱 앱에서 **로그인**을 누르면 기본 브라우저가 열려요.
   - 그 브라우저에서 이미 하이퍼클래스 웹 앱에 로그인해 있다면 데스크톱 앱으로 자동으로 돌아와요.
   - 로그인하지 않은 상태라면 브라우저에서 로그인을 마치세요. 화이트라벨 도메인을 쓰고 있다면 그 도메인에서 로그인해요. 로그인이 끝나면 앱으로 돌아와요.

   ![데스크톱 앱에서 로그인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061960526/original/AC9XbfFHvob-n3S1MOHcZtu2HLqMMUREbQ.gif?1767669339)

### Windows

1. 설치 파일을 내려받아요. 위 표에서 Windows용 `.exe` 링크를 누르세요.

   ![Windows 설치 파일 내려받기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061959970/original/iuvZ8-UIbTH7DUtiONX6Lso-Gw73xBGAsw.gif?1767667253)
2. 설치해요. `.exe` 파일을 열고 설치 마법사를 끝까지 진행하세요.

   ![Windows 설치 마법사 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061960682/original/NfEem5BRad__9Ro3V_FL_WVd8ojbjCvo7A.gif?1767670217)
3. 하이퍼클래스를 실행해요. 시작 메뉴에서 열면 돼요.
4. **로그인**을 눌러요. 데스크톱 앱에서 **로그인**을 누르면 기본 브라우저가 열려요.
   - 그 브라우저에서 이미 하이퍼클래스 웹 앱에 로그인해 있다면 데스크톱 앱으로 자동으로 돌아와요.
   - 로그인하지 않은 상태라면 브라우저에서 계정 정보를 입력하세요. 화이트라벨 도메인을 쓰고 있다면 그 도메인에서 입력해요. 로그인이 끝나면 앱으로 돌아와요.

   ![데스크톱 앱에서 로그인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061960415/original/pBaH-trhaoOaSG4d4u-vPFN-6eRkaz57IA.gif?1767668890)

### Linux

1. 위 표에서 사용하는 배포판과 아키텍처에 맞는 Linux 설치 파일을 내려받으세요.
2. 시스템의 기본 설치 방법으로 설치하세요.
3. 애플리케이션 메뉴에서 데스크톱 앱을 열어요.

   ![애플리케이션 메뉴에서 데스크톱 앱을 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068381151/original/kc-_bCYFbw_cmfGo-mMBYBCz8TAdb-BZ7A.png?1775147156)
4. **로그인**을 누르세요. 기본 브라우저가 열리면 로그인을 마치세요. 그러면 데스크톱 앱으로 돌아와요.

   ![Linux 데스크톱 앱 로그인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068381154/original/ihE3t3mCqZLagYJspRJa9WfQ8RqBwnVyYQ.png?1775147173)

## 자주 묻는 질문

### 데스크톱 앱은 웹 앱과 달라요?
화면과 데이터는 웹 앱과 같아요. 데스크톱 앱은 하이퍼클래스를 전용 창에 담아 더 쾌적하게 쓰게 해 주고, 운영체제 기본 알림도 받을 수 있어요.

### 여러 계정이나 서브 계정을 쓸 수 있어요?
네, 평소처럼 로그인한 뒤 여러 서브 계정에 접근할 수 있다면 계정 메뉴에서 전환하면 돼요.

### 화이트라벨 도메인을 쓰면 로그인에 영향이 있나요?
네, 화이트라벨 도메인이 활성화되어 있으면 로그인할 때 브랜드 로그인 화면을 거친 뒤 앱으로 돌아와요.

### 알림이 안 와요
운영체제에서 하이퍼클래스의 알림을 켠 다음, 앱 안의 환경설정을 확인해 보세요.
