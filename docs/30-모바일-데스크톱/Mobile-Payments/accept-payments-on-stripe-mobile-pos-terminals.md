# Stripe 모바일 POS 단말기로 결제 받기

Stripe에서 판매하는 결제 단말기를 모바일 앱에 연결하면, 고객이 단말기에 카드를 대거나 꽂거나 긁어서 결제할 수 있어요. 하이퍼클래스 모바일 앱과 화이트라벨 앱에서 사용할 수 있어요.

{% hint style="info" %}
지원하는 단말기는 Stripe M2 reader와 BBPOS WisePad 3예요.
{% endhint %}

## 단말기로 결제 받는 방법

기기에 쓰려는 모바일 앱(하이퍼클래스 모바일 앱 또는 화이트라벨 앱)을 설치한 뒤 아래 순서대로 진행하세요.

1. **메뉴**를 열고 **설정**(톱니바퀴 아이콘)을 누르세요.
2. **Payment Devices**(결제 기기)를 누르세요.
   - 이전에 연결한 결제 기기가 있으면 **My devices**(내 기기) 섹션에 기록이 보여요.
   - 기기를 처음 연결하는 경우에는 화면이 자동으로 페어링 모드로 열려요. 결제 단말기의 전원이 켜져 있고 배터리가 25% 이상인지 확인하세요.
3. 페어링 화면에 단말기가 나타나면 **Connect**(연결)를 누르세요. 앱이 단말기 상태와 함께 업데이트가 있는지 확인해요.
4. 페어링이 끝나고 업데이트가 모두 설치되면 단말기로 결제를 받을 수 있어요.
5. 사용 목적에 따라 **POS** 탭 또는 **인보이스**로 이동하세요.
6. 결제 수단 화면에서 **Pay with Hardware**(단말기로 결제) 타일을 누르세요. 단말기가 결제를 받을 수 있는 상태로 바뀌어요.
7. 고객이 카드를 단말기에 대거나 꽂거나 긁으면 결제가 완료돼요.
