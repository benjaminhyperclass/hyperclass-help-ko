# 모바일 POS에서 BBPOS WisePOS E·Stripe S700 인터넷 리더기 사용하기

Stripe의 Wi-Fi 결제 단말기인 **WisePOS E**와 **S700**을 하이퍼클래스 모바일 앱이나 직접 만든 화이트라벨 모바일 앱과 연결하는 방법을 안내해요. 연결하고 나면 동글, 케이블, 브라우저 창 없이 POS 안에서 바로 카드 대면 결제를 받을 수 있어요.

## Stripe 인터넷 리더기란?

Stripe 인터넷 리더기는 같은 Wi-Fi에서 휴대폰이나 태블릿과 연결해 쓰는 독립형 결제 단말기예요. 인터넷에 연결된 기기라서 카드를 대거나 꽂거나 긁으면 결제 정보가 Stripe의 PCI 인증 인프라를 거쳐 처음부터 끝까지 암호화돼요. 하이퍼클래스와 연결하면 iOS나 Android 기기를 계산대 겸 이동식 결제 단말기로 쓸 수 있어요.

## 모바일 POS에서 WisePOS E·S700을 쓰면 좋은 점

- 올인원 하드웨어: 별도 장비 없이 IC칩, 비접촉(태그), 마그네틱 스트라이프 결제를 모두 받을 수 있어요.
- 빠른 계산: 고객 화면에 안내가 표시되어 계산 시간이 줄어요.
- 매장당 리더기 수 제한 없음: 필요한 만큼 등록할 수 있고, 등록한 기기는 모두 **Payment Instruments**(결제 수단) 목록에 표시돼요.
- 통합 리포팅: 대면 결제와 온라인 결제가 같은 하이퍼클래스 **결제** 대시보드에 모여요.
- 자동 규정 준수: 펌웨어가 업데이트되면서 새 카드사 요건이 별도 작업 없이 반영돼요.

## 시작하기 전에 확인하세요

페어링 오류나 결제 실패를 막으려면 아래 항목을 먼저 확인하세요.

- **결제 > 연동**에서 Stripe 계정이 연결되어 있어야 해요. (라이브 계정)
- 모바일 기기와 리더기가 같은 2.4GHz 또는 5GHz Wi-Fi 네트워크에 연결되어 있어야 해요.
- App Store 또는 Google Play의 하이퍼클래스 모바일 앱 공개 베타에 참여한 기기여야 해요.
- 모바일 앱이 3.103.4 버전 이상이어야 해요.

## WisePOS E 또는 S700 리더기 등록하기

페어링하면 실제 단말기가 서브 계정에 연결되어 결제할 때 선택할 수 있게 돼요.

#### 1단계: 리더기에서 페어링 코드 받기

1. 리더기 전원을 켜세요.
2. 대기 화면에서 **Generate Pairing Code**(페어링 코드 생성)를 누르면 6자리 코드가 표시돼요.

#### 2단계: 인터넷 리더기 설정 화면으로 이동하기

1. 모바일 앱을 열고 사용할 서브 계정을 선택하세요.
2. **설정** > **Stripe Payment Hardware**(Stripe 결제 하드웨어) > **Pair New Devices**(새 기기 페어링) > **Internet Readers**(인터넷 리더기)로 이동하세요.

![인터넷 리더기 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053906031/original/GGg16hSwyUPy3RiltXf_b0z9tloUU5SiGw.png?1758054983)

#### 3단계: 기기 페어링하기

1. 결제할 때 알아보기 쉬운 리더기 이름을 입력하세요. (예: FrontCounter\_WisePOS1)
2. 리더기에 표시된 페어링 코드를 입력하세요.
3. **Pair**(페어링)를 누르세요. "FrontCounter\_WisePOS1 registered successfully." 메시지가 나타나면 등록이 끝난 거예요.

![리더기 이름과 페어링 코드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053906064/original/WGuq0-NGLB8w4lbzuYLcUUdfTJExIHQDng.png?1758055049)

#### 4단계: 다른 기기도 같은 방법으로 등록하기

같은 네트워크에 있는 다른 리더기도 위 과정을 반복해서 등록하세요.

## 등록한 리더기로 결제 받기

페어링을 마치면 저장된 카드를 고르듯이 리더기를 선택할 수 있어요.

1. POS에서 판매를 시작하고 장바구니에 상품을 담으세요.
2. **Payment Instruments**(결제 수단)에서 사용할 리더기를 선택하세요.
3. 리더기를 고객에게 건네세요. 고객은 카드를 대거나 꽂거나 긁을 수 있어요. 모바일 화면에서 5분 타이머가 줄어들어요.
4. 승인을 기다리세요. 리더기에 "Approved"가 표시되면 **Transaction History**(거래 내역)에 판매 내역이 바로 나타나요.

## 문제 해결과 사용 팁

아래 해결 방법으로 대부분의 문제를 빠르게 풀 수 있어요.

|  |  |
| --- | --- |
| 증상 | 해결 방법 |
| 리더기를 찾을 수 없어요 | 두 기기가 같은 SSID에 연결되어 있는지 확인하세요. 리더기를 다시 시작하세요. 443번과 4070번 포트가 열려 있는지 확인하세요. |
| 페어링 코드가 만료됐어요 | 코드는 60초 동안만 유효해요. 리더기에서 새 코드를 생성해 다시 시도하세요. |
| 결제 타이머가 만료됐어요 | 판매를 다시 시작하세요. 고객에게 신호음이 울릴 때까지 카드를 그대로 두라고 안내하세요. |
| 리더기를 다른 매장으로 옮겨야 해요 | **Payment Devices**(결제 기기)에서 페어링을 해제한 뒤, 새 Wi-Fi 네트워크에서 페어링 과정을 다시 진행하세요. |

## 자주 묻는 질문

### 서브 계정 하나에 인터넷 리더기를 몇 대까지 등록할 수 있나요?
제한이 없어요. 등록한 리더기는 **Payment Instruments**(결제 수단)에 하나씩 표시돼요.

### Bluetooth가 필요한가요?
아니요. WisePOS E와 S700은 로컬 Wi-Fi로 페어링해요.

### 고객이 리더기에서 팁을 추가할 수 있나요?
네. **POS Settings**(POS 설정) > **Gratuity**(팁)에서 **Prompt for Tip**(팁 입력 요청)을 켜세요.

### 웹 앱에서 이 결제를 환불할 수 있나요?
네. 환불 과정은 온라인 Stripe 결제와 같아요.

### 리더기를 오프라인에서도 쓸 수 있나요?
결제하려면 인터넷 연결이 필요해요. Wi-Fi가 끊기면 현금이나 저장된 카드로 결제를 받으세요.
