# 모바일 앱의 통합 결제 허브

모바일 앱의 POS(Point-of-Sale, 현장 결제) 모듈 하나로 POS 결제, 인보이스, 견적서를 모두 처리할 수 있어요. POS 결제에는 **Tap to Pay**(탭 결제), **Cash**(현금), **Cards**(카드), **Manual Entry**(수동 입력)가 있어요.

- 기본 결제 수단
  - **Tap to Pay**, **Cash**, **Cards**, **Manual Entry** 중에서 사용할 수 있는 결제 수단을 고를 수 있어요.
- **Convert to Invoice**(인보이스로 전환)
  - POS 거래를 인보이스로 전환해요. 고객이 자세한 인보이스를 받고 온라인으로 결제하거나 나중에 결제하려 할 때 쓰세요.
- **Convert to Estimate**(견적서로 전환)
  - POS 거래로 견적서를 만들어 고객에게 보내요. 고객은 받은 견적서를 수락하거나 거절할 수 있어요.

현장에서 결제를 받는 일이 훨씬 간단해져요. 결제에 필요한 일을 모듈 하나에서 처리하고, 나머지는 하이퍼클래스에 맡긴 채 사업에 집중하세요.

# 결제 허브 사용 방법

|  |  |
| --- | --- |
| 앱 하단 바에서 "$" 아이콘을 탭해 POS를 열어요. **Keypad**(키패드) 또는 **Catalog**(카탈로그)로 주문을 만드세요. |  |
| 항목을 모두 담았으면 **Review**(검토) 페이지로 이동해요. 연락처를 연결하고, 할인을 추가하고, 거래 내용을 확인하세요. |  |
| 내용에 문제가 없으면 **Choose payment instruments**(결제 수단 선택)를 탭해요. 지금 결제할지, 인보이스를 보낼지, 견적서를 보낼지 상황에 맞게 고르세요. 고객이 직접 결제하려면 **Tap to Pay**, **Cash**, **Cards**, **Manual Entry** 중에서 선택하세요. |  |
| **Tap to Pay**로 결제 |  |
| 현금으로 결제 (**Manual Entry**로 기록할 수도 있어요) |  |
| 신용카드로 결제 |  |
| 디지털 방식이 아니거나 모바일 앱으로 처리하지 않는 결제 수단은 **Manual Entry**로 기록해요. |  |
| 고객이 자세한 인보이스를 받고 온라인으로 결제하려면 **Convert to Invoice**를 선택하세요. 대부분의 내용이 미리 채워진 인보이스 편집기가 열려요. 결제 기한과 인보이스 번호(필요한 경우)를 설정하고, 최종 인보이스를 확인하면 돼요. |  |
| 고객이 거래를 바로 진행하지 않고 견적을 받으려면 **Convert to Estimate**를 선택하세요. 대부분의 내용이 미리 채워진 견적서 편집기가 열려요. 기한과 견적서 번호(필요한 경우)를 설정하고, 최종 견적서를 확인하면 돼요. |  |
