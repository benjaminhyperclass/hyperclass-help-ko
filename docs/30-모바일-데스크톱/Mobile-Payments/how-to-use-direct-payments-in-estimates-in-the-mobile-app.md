# 모바일 앱에서 견적서에 직접 결제 사용하기

하이퍼클래스 모바일 앱에서 견적서에 직접 결제를 켜고 사용하는 방법을 안내해요. 이 기능을 쓰면 고객이 견적서를 수락하자마자 바로 결제할 수 있어서, 인보이스 발행과 결제 과정이 한결 간단해져요.

## 모바일 견적서 결제란?

모바일 견적서 결제는 서브 계정 사용자가 견적서에 직접 결제 옵션을 넣을 수 있는 기능이에요. 고객이 견적서를 수락하면 자동으로 인보이스로 이동하고, 거기서 온라인으로 결제를 마칠 수 있어요. 하이퍼클래스 모바일 앱과 화이트라벨 앱의 3.91 버전 이상에서 사용할 수 있어요.

## 모바일 견적서 결제의 장점

견적서에 결제 기능을 더하면 고객은 더 편하게 결제하고, 매출은 더 빨리 들어와요.

- 견적서가 승인되면 바로 인보이스로 이동해요.
- 모바일 결제와 매끄럽게 이어져요.
- 결제 때문에 주고받는 연락이 줄어요.
- 앱 안에서 바로 결제할 수 있어 더 전문적인 인상을 줘요.
- 오프라인·수동 결제를 대체 수단으로 쓸 수 있어요.
- 여러 브랜드의 모바일 앱에서 사용할 수 있어요.

## 견적서에 직접 결제 켜기

모바일 앱에서 바로 결제가 가능한 견적서를 만들어 보내 보세요.

1. 하이퍼클래스 모바일 앱(또는 화이트라벨 앱)을 열고 사용할 서브 계정을 선택하세요.
2. **navigation drawer**(탐색 메뉴)를 탭한 뒤 **견적서**를 선택하세요.
3. 새 견적서를 만들거나 작성 중인 초안을 여세요.
4. 필요한 내용을 모두 입력하세요.

   - 견적서 이름과 번호
   - 발행일과 만료일
   - 연락처
   - 상품/서비스 항목별 내역
5. **리뷰** 화면으로 이동하세요.
6. 맨 아래로 스크롤해서 **결제 설정** 섹션을 찾으세요.
7. **직접 결제 켜기**를 켜세요.
8. 견적서를 SMS, 이메일 또는 둘 다로 보내세요.

## 견적서 수락 후 인보이스로 이동

고객이 자신의 기기에서 견적서를 수락하면 해당 인보이스 페이지로 자동 이동해요. 고객은 그 페이지에서 바로 결제를 마칠 수 있어요.

## 결제가 실패했을 때

고객이 결제에 문제를 겪으면 **인보이스** 화면에서 직접 처리할 수 있어요.

1. 모바일 앱에서 **인보이스** 탭으로 이동하세요.
2. 해당 견적서와 연결된 인보이스를 찾으세요.
3. 인보이스를 탭하거나 왼쪽으로 밀어 **결제 기록**을 표시하세요.
4. 사용할 수 있는 결제 방법 중에서 선택하세요.

   - **Tap to Pay**(탭하여 결제)
   - **Cash**(현금)
   - **Card**(카드)
   - **Manual entry**(직접 입력)

## 자주 묻는 질문

### 어떤 앱 버전에서 이 기능을 쓸 수 있나요?

하이퍼클래스 모바일 앱과 화이트라벨 앱의 3.91 버전 이상에서 사용할 수 있어요.

### 견적서를 SMS와 이메일로 보낼 수 있나요?

네. 견적서를 보낼 때 SMS, 이메일 또는 둘 다 중에서 고를 수 있어요.

### 고객이 결제를 끝내지 않으면 어떻게 되나요?

인보이스를 열어 다시 보내거나, 여러 방법으로 결제를 직접 기록할 수 있어요.

### 데스크톱에서도 사용할 수 있나요?

현재 견적서의 직접 결제는 모바일 앱에서만 지원돼요.

## 다음 단계

- 모바일 앱을 3.91 버전 이상으로 업데이트하세요.
- **Tap to Pay**와 수동 기록 옵션을 살펴보고 결제를 편하게 관리해 보세요.
- 고객이 자신의 기기에서 바로 견적서를 수락하고 결제하도록 안내하면 처리가 더 빨라져요.
