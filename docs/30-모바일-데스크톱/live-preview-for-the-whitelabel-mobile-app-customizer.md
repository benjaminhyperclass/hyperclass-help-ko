# 화이트라벨 모바일 앱 커스터마이저의 실시간 미리보기

커스터마이저에서 앱을 꾸미는 동안 내 휴대폰으로 결과를 바로 확인할 수 있어요. 색상, 로고, 앱 드로어를 바꾸면 휴대폰 화면이 즉시 바뀌고, 최종 사용자에게는 아무것도 전달되지 않아요.

한마디로 **실시간 미리보기**를 켜고, 휴대폰으로 QR 코드를 스캔한 뒤, 무언가를 바꿔 보세요. 바꾼 내용이 바로 휴대폰에 나타나요. 게시하기 전까지는 최종 사용자에게 아무것도 전달되지 않아요.

## 실시간 미리보기란?

실시간 미리보기는 컴퓨터의 화이트라벨 모바일 앱 커스터마이저와 내 휴대폰을 QR 코드로 연결하는 기능이에요. 연결된 동안 커스터마이저에서 바꾼 내용이 휴대폰에 실시간으로 나타나요.

- 초안만 보여 줘요. 게시하기 전까지는 최종 사용자에게 아무것도 게시되지 않아요.
- 세션 하나에 기기 한 대만 연결할 수 있어요.
- 커스터마이저나 휴대폰에서 언제든 세션을 끝낼 수 있어요.

## 시작하기 전에

- 컴퓨터(데스크톱 브라우저)에서 커스터마이저를 열어 주세요.
- 미리보기를 할 휴대폰에 화이트라벨 모바일 앱(WLMA)을 설치하고, 에이전시 관리자로 로그인해 주세요.
- 휴대폰이 인터넷에 연결되어 있는지 확인해 주세요.

## 실시간 미리보기 세션 시작하기

### 1단계: 컴퓨터에서

1. **모바일 앱**으로 이동해서 **Customise App**(앱 커스터마이즈)을 클릭하면 커스터마이저(Agency App Manager)가 열려요.
2. 상단 바에서 **실시간 미리보기** 토글을 켜세요.

![상단 바에 실시간 미리보기 토글이 있는 커스터마이저 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082890712/original/mjS8VEf5VFv5t-cFRWZe3UBbqvGz8HHJ9g.jpg?1791487663)

3. QR 코드가 있는 **Preview on a real phone**(실제 휴대폰에서 미리보기) 창이 열려요. 창을 닫지 말고 그대로 두세요.

![QR 코드가 표시된 실제 휴대폰에서 미리보기 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082890719/original/P2wMk_nGq0vj-3fyYC5hQO2V3osZXsicyw.jpg?1791487675)

### 2단계: 휴대폰에서

1. 모바일 앱을 열고 **설정**으로 이동하세요.
2. **Additional resources**(추가 리소스) 아래에서 **Scan Live Preview QR**(실시간 미리보기 QR 스캔)을 탭하세요.
3. 컴퓨터 화면의 QR 코드가 프레임 안에 들어오도록 카메라를 맞춰 주세요.
4. **Live preview connected**(실시간 미리보기 연결됨) 메시지와 함께, **정지** 버튼이 있는 **Changes sync in real time**(변경 사항이 실시간으로 동기화됨) 배너가 보여요.

|  |  |
| --- | --- |
| Scan Live Preview QR이 있는 휴대폰 설정 화면 설정 > Additional resources > Scan Live Preview QR | Live preview connected와 정지 배너가 표시된 휴대폰 연결됨: 변경 사항이 실시간으로 동기화돼요 |

{% hint style="info" %}
한 번에 기기 한 대만 연결할 수 있어요. **Live preview already running**(실시간 미리보기가 이미 실행 중)이 보이면 **Stop live preview**(실시간 미리보기 중지)를 탭한 다음, 새 QR 코드를 스캔하세요.
{% endhint %}

## 변경하고 미리 보기

세션이 연결된 상태에서 커스터마이저의 무엇이든 바꿔 보세요. 예를 들어 **기본 색상**을 바꾸면 휴대폰에 바로 반영돼요.

{% hint style="info" %}
실시간 미리보기는 초안만 보여 줘요. 게시하기 전까지 커스터마이저에는 **Not published yet**(아직 게시되지 않음)이 표시돼요.
{% endhint %}

## 실시간 미리보기 세션 끝내기

- **커스터마이저에서:** **실시간 미리보기** 토글을 끄세요. 툴팁에 휴대폰의 세션도 함께 끝난다는 안내가 나와요.
- **휴대폰에서:** 배너의 **정지**를 탭하세요. 커스터마이저에 **Live preview closed from your phone**(휴대폰에서 실시간 미리보기가 닫힘)이 표시돼요.

## 커스터마이징을 프리셋으로 저장하기

저장한 커스터마이징은 모두 프리셋으로 보관돼요. 프리셋은 앱 설정을 이름 붙여 저장해 둔 버전이에요. 프리셋은 최대 20개까지 만들 수 있어요.

![20개 중 2개를 사용 중인 커스터마이징 프리셋 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082890761/original/4XPeuHdE1v1lOkUiv1WgA14LuM_xCrylpA.jpg?1791487728)

1. **저장 후 다음**을 클릭해 **Save customization**(커스터마이징 저장) 창을 여세요.
2. **Preset name**(프리셋 이름)을 입력하세요. 필수 항목이며 30자까지 쓸 수 있어요. 필요하면 **설명 추가**에서 설명도 적어 주세요.
3. 나만 보게 두려면 **초안으로 저장**을, 바로 적용하려면 **저장 및 게시**를 선택하세요.

## 커스터마이징 게시하기

게시하면 내 커스터마이징이 최종 사용자에게 적용돼요.

1. **게시** 창을 여세요. 휴대폰 두 대 화면으로 **라이브 중**과 **New Updated**(새로 업데이트됨)를 비교해 볼 수 있어요.
2. **Publishing instantly**(즉시 게시) 아래에서, 서브 계정 전체의 모든 최종 사용자에게 바로 적용되는 변경 사항을 확인하세요.
3. **Few changes require a new app build**(일부 변경 사항은 새 앱 빌드가 필요해요)라는 상자가 보이면, 해당 항목이 그 안에 나열돼요. 이 항목들은 새 빌드가 배포되기 전까지 사용자에게 적용되지 않아요.
4. 변경 사항을 확인했다는 체크박스를 선택하세요. 선택하기 전까지 **게시** 버튼은 비활성 상태예요.
5. **게시**를 클릭하세요.

![새 빌드가 필요한 변경 사항 목록이 있는 게시 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082890772/original/IXiR4k0hP8x_qC28VmGnDyT1BdT3JMysiw.jpg?1791487742)

게시에 성공하면 프리셋이 **is live**(라이브 상태예요)라는 메시지가 나와요. 변경 사항은 즉시 적용되고, App Store나 Google Play 심사는 필요하지 않아요.

### 즉시 적용되는 변경과 새 빌드가 필요한 변경

| 즉시 적용되는 변경 | 새 앱 빌드가 필요한 변경 |
| --- | --- |
| 브랜드 색상, 앱 드로어 모듈 등(**Publishing instantly** 아래에 표시돼요) | 앱 아이콘, 스플래시 화면 아이콘(라이트·다크), 로그인 로고(라이트·다크) |

## 앱 빌드하기

게시한 내용에 빌드가 필요한 변경이 있으면, 성공 창에 **Start app build**(앱 빌드 시작) 버튼이 나타나요. **Distribution**(배포) > **채널**에서도 빌드를 시작할 수 있어요.

1. **Start app build**를 클릭하세요.
2. **Distribution** > **채널**로 이동해서 진행 상황을 확인하세요. 이 페이지에는 빌드 상태 업데이트가 표시되고, 스토어별로 앱 상태, 앱 버전, 마지막 성공 빌드도 볼 수 있어요.

Google Play: Google Play는 앱 이름과 로고를 자동으로 업데이트하지 않아요. 스토어 정보가 서로 어긋나지 않도록 Google Play Console에서 직접 바꿔 주세요.

## 프리셋 관리하기

커스터마이저 왼쪽에서 **Customisation presets**(커스터마이징 프리셋)를 여세요.

- 목록에 프리셋별 이름, 상태(예: **활성**, **임시 저장**), 마지막 업데이트 시점이 표시돼요. 상단 바에서는 프리셋 20개 중 몇 개를 사용했는지 볼 수 있어요.
- **Preview on device**(기기에서 미리보기)는 선택한 프리셋을 연결된 휴대폰으로 보내 줘요. 게시하지 않고도 확인할 수 있어요.
- **게시**를 누르면 선택한 프리셋이 라이브 버전이 돼요. 이전 버전으로 돌아가려면 그 프리셋을 선택하고 **게시**를 클릭하세요.
- 휴지통 아이콘을 누르면 프리셋이 삭제돼요.
- **Create new preset**(새 프리셋 만들기)에서 새 프리셋을 만들 수도 있어요.

## 자주 묻는 질문

### 실시간 미리보기를 쓰는 동안 최종 사용자에게도 보이나요?

아니요. 실시간 미리보기는 내 휴대폰에 초안만 보여 줘요. 게시하기 전까지 라이브 앱은 바뀌지 않아요.

### 게시한 변경 사항은 사용자에게 얼마나 빨리 적용되나요?

위에서 설명한 빌드가 필요한 항목을 제외한 모든 변경 사항이 즉시 적용돼요.

### "Live preview already running"이 보여요. 어떻게 하나요?

휴대폰에 이미 세션이 열려 있다는 뜻이에요. **Stop live preview**를 탭한 다음, 새 QR 코드를 스캔하세요.

### 휴대폰을 두 대 이상 연결할 수 있나요?

아니요. 세션 하나에 기기 한 대만 연결할 수 있어요.

### "초안으로 저장"과 "저장 및 게시"는 뭐가 다른가요?

**초안으로 저장**은 프리셋을 나만 볼 수 있게 보관하고, 최종 사용자에게는 아무 변화도 없어요. **저장 및 게시**는 **게시** 창으로 이동해요.

### 이전 버전으로 돌아가려면 어떻게 하나요?

**Customisation presets**를 열어 이전 프리셋을 선택하고 **게시**를 클릭하세요. **라이브 중**과 **New Updated** 화면을 확인한 뒤 동의하고 게시하면 돼요.

### 프리셋 20개를 모두 썼어요. 어떻게 하나요?

더 이상 필요 없는 프리셋을 삭제해서 새 프리셋을 만들 자리를 확보하세요.
