# 이커머스 스토어 모바일 화면 개선 사항

하이퍼클래스가 **이커머스 스토어**(E-commerce Stores) 페이지의 모바일 화면을 개선했어요. 레이아웃을 통일하고 사용성과 반응성을 높여서, 모바일에서도 더 편하게 쇼핑할 수 있어요.

## 개요

이번 개선 사항은 이커머스 스토어에 자동으로 적용돼요. 상품 둘러보기, 리뷰, 장바구니, 결제, 구매 후 페이지처럼 고객이 자주 거치는 화면을 중심으로 다듬었어요.

따로 설정할 것은 없어요.

## 상품 및 둘러보기 개선

### 상품 평점 표시

모바일에서는 상품 평점 표시를 단순하게 바꿨어요. 상품 이미지 위에 별 아이콘 하나와 평점 수만 보여서, 화면은 덜 복잡하고 정보는 그대로 확인할 수 있어요.

### 정렬 및 필터 화면 개선

모바일에 맞게 정렬과 필터 화면을 새로 디자인했어요.

- 더 깔끔하고 직관적인 레이아웃
- 작은 화면에서도 가격 필터가 알맞게 들어맞음
- 이전에 화면 밖으로 넘치던 문제 해결

## 리뷰 화면 개선

### 리뷰 작성 모달

모바일에서 리뷰를 남길 때 더 알아보기 쉽고 쓰기 편하도록 **리뷰 작성**(Write a Review) 화면을 업데이트했어요.

### 드롭다운 표시 오류 수정

"Create Review" 섹션에서 드롭다운 목록이 화면 밖으로 넘치던 문제를 고쳤어요. 이제 모든 옵션이 보이고 선택할 수 있어요.

## 장바구니 및 결제 개선

### 장바구니 드로어와 장바구니 페이지

장바구니 레이아웃을 다듬어 아래 내용이 더 잘 보여요.

- 상품 상세 정보
- 구독 정보
- 오류 메시지

### 결제 페이지 개선

**결제 페이지**에서 달라진 점이에요.

- 장바구니 요약이 아코디언 형태로 바뀌어서, 주문 상세 내용을 펼치거나 접을 수 있어요.
- 쿠폰 입력란의 위치를 옮겨서, 소계·배송비·세금·합계 내역과 함께 더 잘 보여요.

## 구매 후 화면 개선

### 감사 페이지 업데이트

**감사 페이지** 레이아웃을 새로 정리했어요. 구매 후에 중요한 주문 정보를 더 쉽게 찾을 수 있어요.

## 참고 사항

{% hint style="info" %}
- 이번 업데이트는 모든 이커머스 스토어에 자동으로 적용돼요.
- 변경 사항은 모바일 기기에만 해당해요.
- 사용자가 따로 할 일은 없어요.
{% endhint %}
