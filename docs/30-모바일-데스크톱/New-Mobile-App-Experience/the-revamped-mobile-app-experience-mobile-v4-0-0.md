# 새로워진 모바일 앱 경험 (Mobile v4.0.0)

하이퍼클래스 모바일 앱이 속도, 똑똑한 기능, 사용성에 맞춰 새롭게 바뀌었어요. 이 문서에서는 새 모바일 경험을 켜는 방법과 홈 화면, 통합 검색, 앱 서랍, **AI에게 문의** 등 달라진 점을 안내해요.

## 개요

이번 업데이트로 모바일 앱의 디자인이 웹 앱과 비슷해졌어요. 이동 중에도 비즈니스를 더 쉽게 관리할 수 있어요.

새로운 UI와 다크 모드부터 통합 검색(Universal Search), **AI에게 문의**까지, 하이퍼클래스의 기능을 휴대폰에서 그대로 쓸 수 있어요. 익숙한 모습에 더 빠르고 똑똑해졌어요.

---

## 더 빨라진 앱 실행 속도

앱이 더 빨리 열려서 리드에 바로 응대하고, 기회를 확인하고, 하던 일을 기다림 없이 이어갈 수 있어요. 앱 사용 방법은 그대로예요.

이제 앱 아이콘을 누른 뒤 홈 화면까지 더 빨리 도착해요. 지원되는 최신 버전으로 업데이트하면 자동으로 적용돼요.

{% hint style="warning" %}
- 별도 설정은 필요 없어요.
- 앱을 실행한 뒤에도 백그라운드에서 계속 준비 작업을 해요.
- 속도 개선 정도는 기기 모델, 운영체제 버전, 네트워크 상태에 따라 달라질 수 있어요.
- 이 개선은 하이퍼클래스 모바일 앱과 셀프서브 화이트라벨 모바일 앱에 모두 적용돼요.
{% endhint %}

지원되는 버전으로 업데이트하면 더 빠른 실행 속도를 자동으로 쓸 수 있어요.

---

{% hint style="info" %}
**참고**

- 이 새 경험은 2025년 12월 31일까지 **실험실** 기능으로 제공되며, 직접 켜야 해요.
- 새 디자인은 단계적으로 적용 중이에요. 일부 모듈은 다음 업데이트에서 새 디자인으로 바뀌어요.
- 위젯과 모듈을 쓸 수 있는지는 사용자 역할과 **SaaS 구성기** 권한에 따라 달라져요.
{% endhint %}

## 1. 새 모바일 앱에서 달라진 점

새 앱은 현대적인 디자인, 역할에 맞춰 보이는 홈 화면, 더 똑똑한 탐색을 갖췄어요. 주요 내용은 다음과 같아요.

- 위젯, 고정 앱, **빠른 액션**이 있는 동적인 홈 화면
- 대화, 연락처, 기회 전체에서 원하는 정보를 찾는 통합 검색(Universal Search)
- 업무 분야별로 정리된 새 앱 서랍(App Drawer)
- 글 초안 작성, 만들기, 실행까지 휴대폰에서 도와주는 개인 비서 **AI에게 문의**
- 사용성을 높이고 배터리도 아껴 주는 완전한 블랙 다크 모드

## 2. 새 모바일 경험 켜는 방법

새 디자인을 쓰려면 먼저 **실험실**에서 켜야 해요.

1. App Store 또는 Google Play에서 앱을 업데이트하세요.
2. **에이전시 설정 > 실험실 > 서브 계정**으로 이동하세요.
3. **A New Mobile App Experience**(새 모바일 앱 경험) 토글을 켜세요.
4. 새 경험을 켤 서브 계정을 선택하세요.

{% hint style="info" %}
**팁**

새 레이아웃과 탐색에 먼저 익숙해질 수 있도록, 에이전시 내부용 서브 계정에 먼저 켜 보세요. 그 다음에 고객사 계정에 적용하는 것을 권해요.
{% endhint %}

켠 뒤 앱을 열면 새 홈 화면, 앱 서랍, **AI에게 문의** 등을 바로 써 볼 수 있어요.

## 3. 홈 화면 살펴보기

새 홈 화면은 로그인하자마자 가장 중요한 정보를 보여 주는 상황판 역할을 해요.

### 고정 위젯 (상단)

핵심 데이터 위젯 네 가지가 보여요.

- **Tasks Due**(마감 예정 작업)
- **기회 파이프라인** 금액(Opportunity Pipeline Value)
- **Unread Messages**(읽지 않은 메시지)
- **Today's Appointments**(오늘의 예약)

> 이 위젯들은 현재 고정되어 있어요. 2025년 4분기에는 홈 화면에 표시할 위젯을 직접 고를 수 있게 바뀔 예정이에요.

### 고정 앱 위젯

- 자주 쓰는 모듈을 최대 4개까지 고정해 빠르게 열 수 있어요.
- 고정 앱을 바꾸려면 **편집** 아이콘을 누르세요.
- 햄버거 아이콘을 끌어서 고정한 모듈의 순서를 바꿀 수 있어요.

### 빠른 액션 위젯

- 자주 하는 작업 8가지를 **빠른 액션**으로 바로 실행할 수 있어요. 모듈 사이를 오갈 필요가 없어요.

### 매출 차트

- 최근 6개월 동안의 매출을 보여 주는 그래프예요.

> 홈 화면의 모든 요소는 역할에 맞춰 보여요. 사용자가 접근할 수 없는 모듈의 위젯은 나타나지 않아요.

## 4. 통합 검색

새 통합 검색(Universal Search)으로 필요한 정보를 더 빠르게 찾을 수 있어요.

- 현재는 대화, 연락처, 기회에서 검색해요.
- 나머지 모듈은 2025년 4분기에 지원될 예정이에요.
- 모듈이나 **빠른 액션**도 바로 검색할 수 있어요.
- 최근 검색어 5개를 기억해서 다시 찾기 쉬워요.
- 맥락을 이해하도록 만들어져서, 키워드만으로 몇 달 전 메시지도 찾을 수 있어요.

> 예: "meeting notes"를 검색하면 3개월 전 대화라도 그 문구가 들어 있는 대화를 바로 보여 줘요.

## 5. 앱 서랍

기존의 왼쪽 탐색 메뉴 대신 새 앱 서랍(App Drawer)이 생겼어요. 원하는 기능을 훨씬 쉽게 찾을 수 있어요.

- 모듈이 4열 격자 보기로 표시돼요.
- 모듈은 다음 분류로 나뉘어요.

  - **Insights & Productivity**(인사이트 및 생산성)
  - **커뮤니케이션**
  - **Sales & Operations**(영업 및 운영)
  - **Marketing & Growth**(마케팅 및 성장)
- 웹 앱과 같은 구조라서 일관되게 쓸 수 있어요.

> **설정**과 **알림** 같은 항목은 이제 앱 오른쪽 위에 전용 아이콘으로 있어요.

## 6. AI에게 문의

**AI에게 문의**는 일상적인 작업을 자연스러운 말로 요청하면 도와주는 내장 비서예요.

**AI에게 문의**로 할 수 있는 일은 다음과 같아요.

- 소셜 미디어 콘텐츠 초안 쓰기
- 연락처 만들기·편집하기
- 이미지 생성·편집하기
- 지원되는 MCP(Multi-Channel Platform) 액션 실행하기

모바일에서 지원하지 않는 모듈(예: 블로그, 퍼널)과 관련된 것을 뺀 모든 MCP 액션을 쓸 수 있어요.

**채팅 기록**에서 전체 대화 기록을 볼 수 있어요. 하던 대화를 이어가거나 이전 결과물을 다시 확인할 수 있어요.

```
사용 대상: 모바일의 AI에게 문의는 현재 에이전시 관리자(Agency Admin)가 사용할 수 있어요.
```

## 7. 핵심 개선 사항

### 다크 모드와 새로운 UI

깔끔하게 다듬은 화면과 완전한 블랙 다크 모드를 쓸 수 있어요. 글이 더 잘 읽히고 에너지도 절약돼요.

### 성능과 안정성

로딩이 빨라지고 화면 전환이 부드러워졌어요. 데이터 캐싱도 최적화해서 이동 중에도 안정적으로 쓸 수 있어요.

### 더 간단해진 탐색

- **설정**과 **알림**이 오른쪽 위 아이콘으로 옮겨졌어요.
- **알림**에는 읽지 않은 알림 표시가 있어서 쉽게 확인할 수 있어요.

### SaaS 구성기 준수

새 모바일 앱은 **SaaS 구성기**를 완전히 따라요. 모바일에서의 접근 권한이 웹의 구독 설정과 같아져요.

이전에는 요금제와 상관없이 모든 사용자가 모바일의 모든 기능을 쓸 수 있었어요. 이번 업데이트부터는 다음과 같이 바뀌어요.

- 기능과 모듈 접근이 SaaS 요금제 제한을 따라요.
- 하위 요금제를 쓰는 사용자는 요금제에 포함되지 않은 모듈을 볼 수도, 쓸 수도 없어요.

이렇게 해서 모바일과 웹의 권한이 같아지고, 재판매 업체와 고객 모두 일관되게 쓸 수 있어요.

## 8. 자주 묻는 질문

### 기존에 쓰던 앱이 새 경험으로 자동 업데이트되나요?

아직은 아니에요. 새 경험은 **실험실**에서 직접 켜야 해요.

### 홈 화면 위젯을 직접 설정할 수 있나요?

출시 시점에는 안 돼요. 완전한 맞춤 설정은 2025년 4분기에 제공될 예정이에요.

### AI에게 문의는 모든 모듈을 지원하나요?

블로그, 퍼널처럼 아직 모바일에서 쓸 수 없는 모듈을 뺀 모든 MCP 기능을 지원해요.

### SaaS 구성기 변경은 우리 고객에게 어떤 영향을 주나요?

고객의 모듈 접근 권한이 SaaS 요금제에 포함된 기능과 같아져요. 웹과 모바일에서 똑같이 적용돼요.

### 통합 검색은 언제 모든 모듈에서 되나요?

모든 모듈 지원은 2025년 4분기에 제공될 예정이에요.

### 화이트라벨 모바일 앱을 쓰고 있어요. 새 경험을 쓸 수 있나요?

네, 모든 모바일 앱에서 새 경험을 쓸 수 있어요. 다만 새 디자인은 구조가 바뀌어서, 기존 앱에 적용해 둔 커스터마이징이 깨질 수 있어요. 그래서 에이전시 내부용 서브 계정에 먼저 켜 보시길 권해요. 이전에 없던 방식으로 모바일 앱을 꾸밀 수 있는 새 화이트라벨 모바일 앱 커스터마이저도 준비 중이에요.

## 요약

하이퍼클래스 모바일 앱의 새 경험은 현대적인 디자인과 똑똑한 업무 흐름을 갖췄고, 웹과도 일관성 있게 맞춰졌어요. **AI에게 문의**, 동적인 홈 화면, 간결해진 탐색으로 모바일에서의 비즈니스 관리가 더 빠르고 똑똑하고 편해졌어요.
