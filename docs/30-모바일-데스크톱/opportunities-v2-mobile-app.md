# 모바일 앱의 기회 관리 V2

모바일 앱에서 기회 카드를 내 업무에 맞게 꾸미고, 빠른 액션을 실행하고, 파이프라인 전체를 한 화면에서 관리하는 방법을 안내해요.

이 문서에서는 새로 바뀐 **기회 관리**(Opportunities) 모바일 화면의 카드 레이아웃, 빠른 액션, 통합 상세 화면을 설명해요. 파이프라인을 내게 맞게 설정하고, 기회에 바로 조치하고, 리드 정보를 한 화면에서 확인할 수 있어요. 클릭 수가 줄어 딜을 더 빨리 마무리하는 데 도움이 돼요.

## 기회 관리 V2 모바일 앱이란?

기회 관리 V2는 하이퍼클래스가 새로 디자인한 모바일 리드 관리 화면이에요. 이동 중에도 영업 업무를 할 수 있도록 카드 레이아웃을 내 방식대로 바꿀 수 있어요. 기회 상세 정보, 빠른 액션, 관련 정보가 한 작업 공간에 모여 있어서 여러 화면이나 탭을 오갈 필요가 줄어요.

모바일에서는 기회 카드에 표시할 필드를 직접 고를 수 있어요. 통화나 메시지 같은 액션을 바로 실행하고, 리드 정보도 한 화면에서 모두 볼 수 있어요.

![기회 관리 V2 모바일 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077935891/original/nKkwbsQOxv3mwyJA79EhbJm50clYBPBJSA.png?1786170368)

## 주요 장점

화면 이동을 줄이고 꼭 필요한 액션을 한 화면에 모아서 영업 업무가 한결 편해져요.

- 시간 절약: 클릭 수는 줄고 파이프라인 이동은 빨라져서 중요한 기회 정보를 빠르게 확인할 수 있어요.
- 매출 증대: 기회 카드에서 바로 후속 액션을 실행해 딜 성사 속도를 높일 수 있어요.
- 팀 역량 강화: 팀에 필요한 정보만 카드에 표시해서 한눈에 보고 관리할 수 있어요.
- 고객 만족: 메모, 작업, 예약을 한 화면에서 처리해 더 빠르게 응답할 수 있어요.

## 사용자 지정 기회 카드

기회 카드에는 업무에 꼭 필요한 필드와 빠른 액션만 표시할 수 있어요. 사용할 수 있는 필드는 40개가 넘고, 카드마다 최대 7개의 사용자 지정 필드를 설정할 수 있어요.그래서 파이프라인에서 필요한 정보를 한눈에 볼 수 있어요.

### 기본 필드

각 기회 카드의 첫 줄에는 기본으로 **이름**, **금액**, **담당자**가 표시돼요. 여기에 **소스**, **비즈니스**, **고객전환실패 사유** 등 37개 이상의 필드 중에서 사용자 지정 필드를 최대 4개까지 더 고를 수 있어요.

### 빠른 액션

기본 빠른 액션은 **메시지**, **태그 추가**, **작업 추가**, **기회 이동**이에요. 팀이 자주 쓰는 업무에 맞게 카드에 표시할 액션을 바꿀 수 있어요.

![기회 카드의 빠른 액션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077935908/original/58C57d2YZJoke6A11nsyxru4kfmBpzUtPQ.png?1786170435)

{% hint style="info" %}
팀이 가장 자주 확인하는 필드가 카드에 먼저 보이도록 설정해 보세요. 자주 보는 정보를 보려고 상세 화면을 여는 시간이 줄어요.
{% endhint %}

## 새로워진 파이프라인

새 **파이프라인** 화면에서는 기회 단계를 한눈에 볼 수 있어요. 카드에서 바로 액션을 실행할 수 있어서 파이프라인 화면을 벗어나지 않고도 리드 관리에 필요한 기능을 대부분 쓸 수 있어요.

### 인터랙티브 카드

상세 화면을 열지 않고 카드에서 바로 통화하거나, 메모를 추가하거나, 작업을 만들거나, 태그를 적용하거나, 단계를 바꿀 수 있어요.

### 활동 배지

각 기회 카드에 대화, 메모, 작업, 태그의 개수가 배지로 표시돼요. 전체 기록을 열지 않아도 리드의 활동 상황을 바로 알 수 있어요.

![기회 카드의 활동 배지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077935912/original/wI3RJV4GUGxuvTSN9OutdLwBelFonI4H3A.png?1786170447)

## 올인원 기회 상세 화면

기회 상세 화면에서는 리드 정보를 한 화면에 모아 탭으로 나눠 볼 수 있어요. 통화 기록, 메시지, 작업, 예약, 거래 내역을 보려고 화면을 따로 오갈 필요가 없어요.

### 빠른 액션 바

기회 상세 화면 위쪽에서 통화, 메시지, 태그 같은 주요 빠른 액션을 바로 쓸 수 있어요. 화면을 벗어나지 않고 리드와 바로 소통할 수 있어요.

### 통합 탭

**상세 정보**, **작업**, **메모**, **예약**, **거래 내역** 탭을 오가며 기회의 모든 정보를 한 화면에서 확인하고 관리하세요. 화면을 바꾸지 않고 정보를 수정하고, 업데이트를 추가하고, 활동을 추적할 수 있어요.

![기회 상세 화면의 통합 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077935914/original/0oPxIlJbj0gcwqLxs9UpKt96QoAGeta54A.png?1786170456)

{% hint style="info" %}
탭 바에 표시되는 대화, 메모, 작업, 태그의 개수를 확인해 보세요. 탭을 하나씩 열어 보지 않아도 어느 항목에 확인이 필요한지 알 수 있어요.
{% endhint %}

## 기회 관리 V2 설정하기

기회 카드 레이아웃을 설정하고 새 파이프라인 화면에 익숙해지면 준비가 끝나요. 아래 순서대로 따라 해 보세요.

### 기회 카드 사용자 지정하기

1. 모바일 앱을 열고 **기회 관리 > 설정 > 카드 사용자 지정**으로 이동하세요.
2. 40개 이상의 필드 중에서 기회 카드에 표시할 필드를 고르고, 표시할 빠른 액션도 선택하세요.

   ![카드 필드와 빠른 액션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077935916/original/SCHY9E06oFi8TyenOxOCP0wg9RSxH8JBUg.png?1786170469)

3. 기본 필드 3개(**이름**, **금액**, **담당자**)를 포함해 최대 7개까지 필드를 선택하고, 원하는 빠른 액션을 고르세요.
4. **저장**을 누르세요. 파이프라인 화면의 기회 카드가 바로 새로고침돼요.

   ![저장 후 새로고침된 기회 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077935921/original/l2Zb6_tldj2M8lKHJ4f_F44RJpRRrxNifg.png?1786170479)

### 새 파이프라인 사용하기

1. 모바일 앱에서 **기회 관리 > 파이프라인**으로 이동해 바뀐 단계를 확인하세요.
2. 단계를 둘러보고 사용자 지정한 카드를 사용해 보세요. 각 카드에서 바로 통화하거나, 메모나 작업을 추가하거나, 태그를 지정하거나, 단계를 바꿀 수 있어요.

### 올인원 상세 화면 사용하기

1. 파이프라인에서 기회 카드를 누르면 **기회 상세** 화면이 열려요.
2. 화면 위쪽의 빠른 액션으로 통화, 메시지, 태그 기능을 바로 사용하세요.
3. **상세 정보**, **작업**, **메모**, **예약**, **거래 내역** 탭을 오가며 기회의 모든 정보를 한 화면에서 관리하세요. 상세 화면을 벗어나지 않고 정보를 수정하고, 업데이트를 추가하고, 활동을 추적할 수 있어요.

{% hint style="info" %}
이번 업데이트를 적용하면 현재 모바일 카드 레이아웃과 필드가 기본 설정으로 초기화돼요. 앱을 업데이트한 뒤에 사용자 지정 설정에서 다시 설정해야 해요.
{% endhint %}

## 자주 묻는 질문

### 이 업데이트는 언제부터 쓸 수 있나요?
기회 관리 V2 모바일 앱 업데이트는 이미 출시됐어요. 하이퍼클래스 모바일 앱을 업데이트하면 새 기능을 쓸 수 있어요.

### 업데이트하면 지금 쓰는 모바일 카드 레이아웃이 초기화되나요?
네, 현재 모바일 카드 레이아웃과 필드가 기본 설정으로 초기화돼요. 사용자 지정 필드와 빠른 액션은 사용자 지정 설정에서 다시 설정해야 해요.

### 기회 카드의 기본 필드는 무엇인가요?
기본 필드는 **이름**, **금액**, **담당자**, **소스**, **비즈니스**, **고객전환실패 사유**예요.**이름**, **금액**, **담당자**는 선택하면 항상 각 카드의 첫 줄에 표시돼요.

### 기회 카드마다 사용자 지정 필드를 몇 개까지 표시할 수 있나요?
카드마다 사용자 지정 필드를 최대 4개까지 표시할 수 있어요. 여기에 **이름**, **금액**, **담당자** 3개 필드가 선택하면 기본으로 항상 첫 줄에 추가로 표시돼요.

### 카드에서 쓸 수 있는 기본 빠른 액션은 무엇인가요?
기본 빠른 액션은 **메시지**, **태그 추가**, **작업 추가**, **기회 이동**이에요. 설정에서 카드에 표시할 액션을 바꿀 수 있어요.

### 이 사용자 지정 설정이 데스크톱 화면에도 적용되나요?
아니요, 이 사용자 지정은 모바일 앱에만 적용돼요. 데스크톱 화면은 그대로예요.

### 모바일에서 바꾼 설정이 웹 레이아웃에도 영향을 주나요?
아니요, 모바일 앱에서 바꾼 내용은 모바일 레이아웃에만 적용돼요. 웹 레이아웃은 기존 웹 설정 그대로 동작해요. 사용자 지정은 플랫폼별로 따로 적용돼요.

### 기회 관리 V2는 모바일에서만 쓸 수 있나요?
네, 이 문서에서 설명한 사용자 지정과 레이아웃 개선은 모바일 앱에만 적용돼요. 비슷한 기능이 웹에서는 이미 제공되고 있고, 기존 웹 설정에 따라 계속 동작해요.
