# 클라이언트 포털 코스 알림 설정

클라이언트 포털 소유자는 코스와 관련된 이벤트 알림을 켜고 끄고, 알림 이메일의 내용을 직접 꾸밀 수 있어요. 이 문서에서는 코스 알림을 설정하는 방법을 안내해요.

## 코스 알림 설정이란?

클라이언트 포털 소유자는 코스 관련 이벤트의 알림을 활성화하거나 비활성화하고, 내용을 사용자에 맞게 바꿀 수 있어요. 중요한 소식을 사용자에게 어떤 방식으로 알릴지 세밀하게 정할 수 있어서, 필요한 내용을 알맞은 때에 전달할 수 있어요.

## 코스 알림 설정의 장점

- 알림 켜기/끄기: 코스 이벤트별로 알림을 관리할 수 있어요. 사용자가 어떤 소식을 받을지도 조절할 수 있어요.
- 이메일 템플릿 편집: **이메일 빌더**로 코스 관련 이메일 알림을 사용자에게 맞게 꾸밀 수 있어요. 읽는 사람이 바로 행동할 수 있는 내용으로 만들 수 있어요.
- 알림 관리 통합: **클라이언트 포탈**에서 모든 하위 앱의 알림을 한곳에서 관리해요. 알림 설정을 한 번에 다룰 수 있어서 더 편리하게 쓸 수 있어요.

## 클라이언트 포털에서 코스 알림 설정하기

1. 서브 계정에 로그인하세요.
2. **사이트 > 클라이언트 포탈 > 설정**으로 이동하세요.

   ![사이트 메뉴에서 클라이언트 포탈 설정으로 이동하는 화면](https://jumpshare.com/share/Pp2DK36DSR7ZLwyLcFnX+/Screenshot+2025-12-08+at+6.56.13%E2%80%AFPM.png)
3. 또는 **멤버십 > 클라이언트 포탈 > 설정**으로 이동하세요.

   ![멤버십 메뉴에서 클라이언트 포탈 설정으로 이동하는 화면](https://jumpshare.com/share/yKi1TkFmH0LSMkI4WCwX+/Screenshot+2025-12-08+at+6.56.42%E2%80%AFPM.png)
4. **이메일 설정 > 코스**로 이동하세요.

   ![이메일 설정에서 코스 탭을 여는 화면](https://jumpshare.com/share/7D1SOIBrgF0atNhnB3TK+/GIF+Recording+2025-12-08+at+7.00.39+PM.gif)
5. 체크박스로 코스 이메일 알림의 종류별로 활성화하거나 비활성화하세요.
6. **Eye Icon**(눈 모양 아이콘)을 클릭하면 선택한 이메일 템플릿을 미리 볼 수 있어요.
7. **기본 템플릿** 버튼을 클릭해 새 템플릿을 고르거나 기본 템플릿을 편집하세요. 자세한 내용은 "클라이언트 포털 - 기본 이메일 템플릿 편집" 문서를 참고하세요.

   ![기본 템플릿 버튼으로 템플릿을 선택하거나 편집하는 화면](https://jumpshare.com/share/ypxsTJyF3bXs41xP4TNM+/GIF+Recording+2025-12-08+at+7.05.26+PM.gif)

## 이 기능이 필요한 이유

- 사용자 참여도 향상: 코스 이벤트에 맞춘 알림을 받으면 사용자가 중요한 소식이나 기회를 놓치지 않고 꾸준히 참여할 수 있어요.
- 효율적인 커뮤니케이션: 코스별 알림 설정을 켜 두면 사용자는 필요한 정보만 알맞은 때에 받아요. 불필요한 메시지로 부담을 느끼지 않아요.
- 사용자 경험 개선: 이메일 템플릿을 직접 꾸미면 받는 사람이 자신을 소중히 여긴다고 느끼고, 플랫폼 이용도 늘어나요.
- 클라이언트 포털 활용 확대: 모든 하위 앱의 알림 관리를 **클라이언트 포탈**에 모으면 작업 과정이 단순해져요. 클라이언트 포털을 알림 관리의 종합 도구로 더 많이 쓰게 돼요.
