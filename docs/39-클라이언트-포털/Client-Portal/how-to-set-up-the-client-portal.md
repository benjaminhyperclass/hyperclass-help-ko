# 클라이언트 포탈 설정

클라이언트 포탈은 고객과 각 서브 계정을 하나로 이어 주는 플랫폼이에요. 이 문서에서는 클라이언트 포탈이 무엇인지 알아보고, 도메인 연결, 브랜딩, 기본 언어, 고객 초대, Google 로그인까지 설정하는 방법을 안내해요.

클라이언트 포탈에서 고객은 제휴 수수료를 확인하고, 커뮤니티(출시 예정) 그룹에 참여하고, 멤버십 코스에 등록할 수 있어요. 기업은 고객 유지율을 높이고 더 나은 서비스를 제공할 수 있고, 고객은 필요한 일을 스스로 처리할 수 있어요.

## 클라이언트 포탈이란?

클라이언트 포탈은 서브도메인 clientclub.net 에 있는 고객용 화면이에요. 고객과 리드가 각자의 서브 계정과 편하게 소통할 수 있도록 만든 통합 플랫폼이에요.

![클라이언트 포탈 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001303871/original/rp92ZFYpGylrXy4YqM0xx7AiGLjp2gjPxw.png?1687171974)

- 통합 플랫폼: 고객이 한 곳에서 제휴 수수료를 확인하고, 커뮤니티(출시 예정) 그룹에 참여하고, 멤버십 코스에 등록할 수 있어요. 여러 기능을 한곳에 모아 두어서 고객이 비즈니스와의 활동을 쉽게 관리할 수 있어요.
- 사용자 지정 도메인: 서브 계정마다 사용자 지정 도메인을 설정해 더 개성 있게 꾸밀 수 있어요. 고객이 내 서비스라는 느낌을 더 갖게 되고, 참여도도 높아질 수 있어요.
- 브랜딩 가능한 화면: 서브 계정의 브랜드에 맞게 포탈을 꾸밀 수 있어요. 로고, 파비콘, 색상 등을 설정하면 리드와 고객에게 일관되고 익숙한 경험을 줄 수 있어요.
- 소통 개선과 고객 자율성: 나와 고객이 안전하고 쉽게 소통할 수 있어요. 고객이 필요한 일을 직접 처리할 수 있어서 만족도와 유지율도 높아질 수 있어요.
- 간편한 초대: 개별 앱에서 초대하거나 포탈 URL을 직접 공유해서 고객을 쉽게 초대할 수 있어요.

### 이런 경우에 활용하면 좋아요

1. 온라인 교육 사업(이러닝 플랫폼): 여러 주제의 온라인 코스를 운영한다면, 수강생(고객)이 포탈에서 코스를 듣고, 진도를 확인하고, 커뮤니티(출시 예정) 그룹에서 다른 수강생과 소통할 수 있어요. 학습 과정이 단순해지고 수강생 사이의 유대감도 생겨요.
2. SaaS 기업: 제휴 마케팅 프로그램을 운영한다면, 제휴 파트너가 하나의 플랫폼에서 추천 실적과 수수료를 확인할 수 있어요. 투명하게 공개되면 제휴 파트너가 소프트웨어를 더 적극적으로 홍보하게 될 수 있어요.
3. 피트니스 업계(온라인 트레이닝 프로그램): 여러 온라인 트레이닝 프로그램을 운영한다면, 회원이 자신의 운동 계획을 확인하고, 피트니스 커뮤니티에 참여하고, 시간에 따른 진행 상황을 볼 수 있어요.
4. 마케팅 에이전시: 여러 고객사(각각 서브 계정)를 관리하는 에이전시라면, 고객사마다 클라이언트 포탈에 자체 도메인을 쓸 수 있어요. 고객사는 자신의 데이터와 캠페인에 대한 주인 의식을 더 느끼고, 에이전시와의 소통도 간결해져요.
5. 리테일 이커머스 사업: 단골 고객을 VIP 프로그램에 초대할 수 있어요. 고객은 로그인해서 전용 혜택을 보고, 포인트나 리워드를 확인하고, 특별한 커뮤니티(출시 예정) 이벤트에 참여할 수 있어요.
6. 이벤트 기획사: 이벤트마다 브랜딩에 맞춰 포탈을 꾸밀 수 있어요. 고객은 이벤트 관련 문서와 소식을 확인하고, 기획자와 직접 소통할 수 있어요.

### 이런 점이 좋아요

1. 정보에 쉽게 접근: 제휴 수수료, 커뮤니티(출시 예정) 그룹, 멤버십 코스 같은 핵심 기능과 데이터가 한곳에 모여 있어요. 고객이 여러 플랫폼을 오가지 않고도 필요한 정보를 쉽게 찾을 수 있어요.
2. 고객 자율성 향상: 고객이 스스로 필요한 조치를 할 수 있어요. 지원팀에 문의하지 않고도 문제를 해결하거나 궁금한 점을 확인할 수 있어서 만족도가 높아질 수 있어요.
3. 고객 참여 강화: 커뮤니티(출시 예정) 그룹을 둘러보면 고객이 서비스와 더 가깝다고 느끼게 돼요. 이런 소속감은 고객 충성도와 유지율을 높일 수 있어요.
4. 일관된 브랜드 경험: 브랜딩 기능으로 모든 고객 접점에서 일관된 브랜드 경험을 줄 수 있어요. 일관성은 탄탄한 브랜드 정체성의 핵심이고, 고객의 신뢰와 충성도를 더 높여 줘요.
5. 쉬운 고객 온보딩: 이메일을 여러 번 보내거나 여러 플랫폼을 쓰는 대신, 고객을 포탈로 초대하면 필요한 것을 모두 찾을 수 있어요.
6. 사용자 지정 도메인으로 신뢰도 향상: 사용자 지정 도메인은 고객에게 친숙함과 소속감을 줄 뿐 아니라, 고객 눈에 비치는 서브 계정의 신뢰도도 높여 줘요.
7. 효율적인 소통: 한곳에서 모든 고객에게 연락할 수 있고, 고객도 편한 시간에 확인하고 답할 수 있어요.

## 사용자 지정 도메인 설정

하이퍼클래스는 서브 계정마다 전용 서브도메인 clientclub.net 에 클라이언트 포탈을 제공해요. 이 포탈에서 고객과 서브 계정이 소통할 수 있어요. 설정 과정에서 서브 계정별로 고유한 사용자 지정 도메인을 골라 포탈을 꾸밀 수도 있어요. 브랜드를 더 돋보이게 하고, 고객이 플랫폼에 더 익숙해지도록 도와줘요.

클라이언트 포탈에 사용자 지정 도메인을 설정하려면 다음 단계를 따라 하세요.

1. 왼쪽 메뉴에서 **멤버십**으로 이동해요.
2. 위쪽에서 **클라이언트 포탈**을 열고 **설정**을 선택해요.
3. **도메인 설정** 영역으로 이동해요.

   ![도메인 설정 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062739609/original/abS2G3u9bU8x1jbioBIFheo1JVkP05Ly2Q.png?1768483661)
4. **사용자 지정 도메인** 옵션을 클릭하고 사용할 도메인 이름을 입력해요.

   ![사용자 지정 도메인 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062740344/original/MPaxvmdkkjNsXs0QogGSZ0ngXM5GXj9GAQ.png?1768483832)

![사용자 지정 도메인 설정 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062740495/original/RT1GQguoVYLYKVHNMYOYyziItKbKiqEFhg.gif?1768483921)

A 레코드나 CNAME 레코드를 제대로 설정하려면, 먼저 도메인 등록 업체(레지스트라)가 안내받은 IP 주소나 서버를 가리키도록 설정해 두어야 해요. 이 과정은 도메인이 내 서버를 정확히 가리켜서 제대로 작동하게 하는 데 꼭 필요한 단계예요.

A 레코드(Address Record)는 도메인을 하나의 서버 IP 주소에 연결해요. CNAME 레코드(Canonical Name Record)는 도메인(또는 서브도메인)을 다른 도메인 이름에 연결해요.

A 레코드와 CNAME 레코드를 추가하는 순서는 다음과 같아요.

1. 도메인 등록 업체의 대시보드에 로그인해요.
2. DNS 설정으로 이동해요.
3. 새 레코드를 추가하는 옵션을 찾아요.
4. 추가할 레코드 유형(A 또는 CNAME)을 선택해요.
5. 정보를 입력해요. A 레코드에는 IP 주소 `162.159.140.166` 을, CNAME 레코드에는 대상 도메인 [preview.clientclub.net](//preview.clientclub.net) 을 입력해요.
6. 변경 내용을 저장해요.

등록 업체마다 절차가 조금씩 달라요. 자주 쓰는 업체별 안내는 다음과 같아요.

- [GoDaddy](https://www.godaddy.com/help/add-an-a-record-19238)
- [NameCheap](https://www.namecheap.com/support/knowledgebase/article.aspx/319/2237/how-can-i-set-up-an-a-address-record-for-my-domain/)
- [Bluehost](https://www.bluehost.com/help/article/dns-management-adding-an-a-record)
- [HostGator](https://www.hostgator.com/help/article/how-to-manage-dns-records)
- [Google Domains](https://support.google.com/domains/answer/3290350)

{% hint style="info" %}
레코드에 "designated IP address or server"라는 자리 표시 문구가 있으면, 실제 IP 주소나 서버 정보로 바꿔 넣어야 해요. 도메인 설정이 제대로 되려면 이 항목을 정확히 입력해야 해요.
{% endhint %}

도메인 등록 업체에 DNS 레코드를 입력한 뒤에는, 레코드가 적용될 때까지 충분히 기다린 다음(등록 업체에 따라 다름) **도메인 업데이트**를 클릭하세요.

클라이언트 포탈의 서브도메인이나 사용자 지정 도메인을 업데이트하면, 이전 도메인으로 접속한 방문자에게 새 도메인 링크가 담긴 도메인 변경 안내가 표시돼요. 하이퍼클래스는 30초 뒤에 방문자를 새 도메인으로 자동 이동시켜요.

![도메인 변경 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155002194359/original/U4mvBT_4NGPmvVWz7o4MuO9Ngqxz9gW3bQ.png?1688403918)

{% hint style="info" %}
아래 자료는 DNS 전파에 대한 전반적인 내용을 이해하는 데 도움이 돼요. 다만 DNS 레코드에 설정된 TTL, 인터넷 서비스 제공업체의 업데이트 주기, 지역 등 여러 요인에 따라 실제 전파 시간은 달라질 수 있어요. 보통 DNS 전파에는 24~48시간 정도 걸린다고 생각하면 돼요.

### 코스 설정에서 마이그레이션 시작하기

기존 멤버십에서 클라이언트 포탈로 마이그레이션하면 코스와 멤버십을 더 통합된 환경에서 설정할 수 있어요. 업데이트된 설정 화면에서는 마이그레이션 안내도 더 쉽게 찾고 따라 할 수 있어요.

마이그레이션을 시작하려면 다음 단계를 따라 하세요.

1. **멤버십**으로 이동해요.
2. **코스**를 열어요.
3. 사이트의 설정 영역으로 이동해요.
4. 설정 화면에 표시된 마이그레이션 안내 메시지를 확인해요.
5. 화면 안내에 따라 클라이언트 포탈 설정으로 이동해요.

![코스 설정의 마이그레이션 안내](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071114382/original/D3uWvZ2W3EAINr4yUle-PXK3rAysTXgweg.png?1778579784)

{% hint style="info" %}
마이그레이션이 끝나면 브랜딩, 도메인, 이메일 설정, 앱 설정이 현재 사용 중인 설정과 같은지 확인하세요.
{% endhint %}

## 클라이언트 포탈 브랜딩

1. 클라이언트 포탈 영역으로 이동해요. 서브 계정에 로그인한 상태에서 보통 왼쪽 메뉴로 열 수 있어요.
2. 클라이언트 포탈 영역에서 **브랜딩** 옵션을 찾아 선택하면 포탈 꾸미기를 시작할 수 있어요.

   ![브랜딩 옵션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062741113/original/z0hKBwpmucrVqnU1S3HqqDB8fWS9zx_xOg.png?1768484111)
3. **브랜딩** 화면에서 클라이언트 포탈의 모양과 느낌을 자유롭게 바꿀 수 있어요. 사용할 수 있는 항목은 다음과 같아요.

![브랜딩 설정 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062742112/original/oQ0XbPtoseJNZhH239y3TNb-LnqN_HAqOw.gif?1768484453)

| 설정 | 설명 |
| --- | --- |
| **Portal Name**(포털 이름) | 포탈 이름을 입력해요. 포탈에 눈에 띄게 표시되는 이름이에요. |
| **포털 설명** | 포탈 설명을 입력해요. 고객에게 보이는 설명이므로 포탈이나 서비스를 간단히 소개하는 내용이 좋아요. |
| **브랜드 색상 1** | 포탈에서 브랜드를 대표할 주 색상을 골라요. 버튼, 제목, 강조 표시에 자주 쓰여요. |
| **브랜드 색상 2** | 주 색상과 어울리는 보조 색상을 골라요. 포탈 색 구성에 깊이와 다양함을 더해 줘요. |
| **Favicon**(파비콘) | 포탈의 파비콘을 업로드해요. 파비콘은 웹사이트가 열려 있을 때 브라우저 탭에 나타나는 작은 아이콘이에요. 1:1 비율의 SVG, PNG, JPG 형식이 좋고, 크기는 최대 16x16 픽셀이에요. |
| **포털 이미지** | 클라이언트 포탈에서 브랜드의 정사각형(1:1 비율) 이미지를 SVG, PNG, JPG 형식으로 업로드해요. 이미지 크기는 720x720 픽셀을 넘지 않아야 해요. 이 이미지는 클라이언트 포탈의 대표 브랜딩 이미지로 쓰여요. |
| **Logo**(로고) | 포탈에 표시할 브랜드 로고를 업로드해요. 파비콘처럼 1:1 비율의 SVG, PNG, JPG 형식이어야 하고, 크기는 최대 200x200 픽셀이에요. |
| **지원 이메일** | 포탈과 관련된 지원이나 문의를 위해 고객이 연락할 수 있는 이메일 주소를 입력해요. |
| **Copy Right**(저작권) | 저작권 정보를 입력해요. 보통 "© 2023 회사명"처럼 써요. 콘텐츠를 보호하고 회사의 권리를 밝히는 데 도움이 돼요. |
| **설정 저장** | 원하는 변경을 모두 마친 뒤 **설정 저장**을 클릭해야 클라이언트 포탈에 적용돼요. 마음이 바뀌어 이전 설정으로 되돌리고 싶으면, 저장하기 전에 **취소**를 클릭하세요. |

## 고객 초대

고객을 클라이언트 포탈에 초대하면 서비스 이용 경험이 좋아지고, 커뮤니티(출시 예정)에 대한 소속감도 생겨요. 클라이언트 포탈은 고객이 이용 중인 서비스와 관련된 중요한 정보, 소식, 자료를 한곳에서 볼 수 있는 공간이에요. 고객을 포탈에 초대하는 방법은 크게 두 가지예요.

### 개별 앱에서 직접 초대하기

포탈에는 멤버십 코스, 커뮤니티(출시 예정) 플랫폼, 제휴 프로그램 같은 여러 개별 앱(서비스)이 있어요. 이런 앱에서 직접 초대할 수 있어요.

- 멤버십 코스: 기존 멤버십 사용자는 두 가지 방법으로 접근할 수 있어요. 기존 방식으로 코스에 들어갈 수도 있고, 로그인해서 클라이언트 포탈로 들어갈 수도 있어요. 현재 사용자 이름과 비밀번호는 두 곳 모두에서 쓸 수 있어요. 기존 코스가 없는 서브 계정은 클라이언트 포탈에서 직접 설정해야 해요.
- 커뮤니티 플랫폼: 출시 예정이에요.
- 제휴 프로그램: 제휴 관리 시스템에서 제휴 파트너를 초대할 수 있어요. **마케팅 > 제휴 관리자 > 캠페인 > 캠페인 수정**으로 이동하세요.

  ![캠페인 수정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001318387/original/upkSYyrFfH_LRVUXMfqyPhguj0HIri-VZw.png?1687180644)

  초대하려는 사람들에게 공유할 가입 링크를 복사하세요.

  ![가입 링크 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001318314/original/XgGvnTUxW2C63w34b-1nkipEtNj4qimPww.png?1687180613)

  이 링크로 제휴 파트너로 가입하면, 클라이언트 포탈에서 추천 링크, 수수료율, 수익 같은 제휴 관련 정보를 모두 확인할 수 있어요.

### 클라이언트 포탈 URL 공유하기

더 직접적으로 초대하고 싶거나 많은 고객을 한꺼번에 초대하려면 클라이언트 포탈의 URL을 공유하면 돼요. 이 URL은 클라이언트 포탈 설정의 도메인 설정 영역에서 쉽게 복사할 수 있어요.

![포탈 URL 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001319106/original/_99A6KgauydPRZ4sAlQsshsFoatrEZ3VVg.png?1687181017)

복사한 URL은 이메일, 문자 메시지 등 고객과 소통하는 어떤 채널로도 공유할 수 있어요.

신규 고객에게 보내는 환영 이메일이나 뉴스레터에 URL을 넣거나, 메인 웹사이트나 소셜 미디어의 공지에 올리는 방법도 있어요.

클라이언트 포탈은 모든 서비스를 모아 둔 허브예요. URL을 공유할 때는 포탈에 들어오면 고객이 얻을 수 있는 혜택과 자료를 함께 알려 주세요. 전용 콘텐츠, 직접 문의 채널, 커뮤니티(출시 예정) 토론 참여 등을 예로 들 수 있어요.

## Google 로그인 설정

서브 계정 관리자는 클라이언트 포탈의 가입 페이지와 로그인 페이지에 **Google로 로그인** 옵션을 표시할지 정할 수 있어요.

설정 방법은 다음과 같아요.

1. 해당 서브 계정에서 **클라이언트 포탈 > 설정**으로 이동해요.

   ![클라이언트 포탈 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077252276/original/hTGW8HpqVPk_kl7a5BEN-3ZJH47ix0mcKQ.png?1785419157)
2. **앱 권한**을 열어요.

   ![앱 권한 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077252377/original/zrgp7yPeFOMVgTdHVxzxcaNfqSF2RAMPIQ.gif?1785419187)
3. **Google Sign-In**(Google 로그인)을 켜거나 꺼요.

   ![Google 로그인 켜기·끄기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077252390/original/fdboWxsMmbqb4-lgXxwK1D06S0F8HDRceg.png?1785419201)
4. 변경 내용을 저장해요.

Google 로그인을 끄더라도 연락처는 이메일과 비밀번호 또는 보안 코드로 계속 클라이언트 포탈에 접속할 수 있어요.

이 설정은 서브 계정마다 따로 적용되고, 클라이언트 포탈 웹 플랫폼에서 사용할 수 있어요.

{% hint style="info" %}
Google 로그인을 제거하면 내부 개인정보 보호, 데이터 처리 또는 지역별 요건에 맞게 인증 방식을 조정하는 데 도움이 될 수 있어요. 다만 이 설정만으로 규정 준수가 보장되는 것은 아니에요.
{% endhint %}

## 자주 묻는 질문

### 클라이언트 포탈에 브랜딩을 설정했는데 변경 사항이 보이지 않아요. 왜 그럴까요?

캐시 문제일 수 있어요. 브라우저 캐시를 삭제하거나 시크릿 창에서 포탈을 열어 보세요. 그래도 해결되지 않으면 하이퍼클래스 고객지원에 문의하세요.

### 클라이언트 포탈에서 서브 계정마다 다른 브랜딩을 설정할 수 있나요?

서브 계정마다 따로 브랜딩을 설정할 수 있어요. 로고나 색상 같은 시각 요소를 서브 계정별로 설정해서 각 브랜드의 정체성을 가장 잘 보여 줄 수 있어요. 해당 서브 계정으로 이동해 **브랜딩** 옵션에서 원하는 대로 설정하세요.

### 제휴 파트너가 클라이언트 포탈에서 자신의 통계를 보지 못해요. 어떻게 하나요?

제휴 파트너가 올바른 로그인 정보를 쓰고 있는지 확인하세요. 통계를 볼 수 있는 권한을 제대로 부여했는지도 확인하세요. 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.

### 클라이언트 포탈의 DNS 레코드를 제대로 설정했는데 접속이 안 돼요. 왜 그럴까요?

DNS 변경 사항이 인터넷 전체에 전파되려면 최대 48시간이 걸릴 수 있어요. 방금 변경했다면 바로 반영되지 않을 수 있어요. 48시간이 지나도 접속되지 않으면 도메인 등록 업체에 문의하세요.

### 클라이언트 포탈의 파비콘을 바꾸고 싶은데 업로드가 안 돼요. 권장 형식과 크기는 어떻게 되나요?

파비콘은 1:1 비율을 권장해요. 형식은 SVG, PNG, JPG이고 크기는 16x16 픽셀을 넘지 않아야 해요. 이 조건을 모두 맞췄는데도 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.
