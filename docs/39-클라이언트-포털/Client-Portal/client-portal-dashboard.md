# 클라이언트 포탈 대시보드 살펴보기

클라이언트 포탈 대시보드에서는 포탈에 초대한 사용자와 가입한 사용자 현황을 한눈에 볼 수 있어요. 매직 링크 생성, 클라이언트 포탈 초대, 로그인 이메일 발송도 여기서 할 수 있어요.

## 클라이언트 포탈 URL

**클라이언트 포탈 URL**을 복사해서 고객에게 보낼 수 있어요. 이 URL은 선택한 사용자 지정 도메인에 맞춰 바뀌어요.

## 초대한 사용자와 가입한 사용자

- 초대한 사용자: 작업 메뉴에서 초대를 선택해 클라이언트 포탈에 초대한 사용자의 수예요.
- 가입한 사용자: 실제로 클라이언트 포탈에 가입한 사용자의 수예요.

![클라이언트 포탈 대시보드의 초대한 사용자·가입한 사용자 현황](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010292573/original/KHXwkkC02Mk2EehPylnHCT5tvgU7VTIirg.png?1697537631)

## 작업 1. 매직 링크

매직 링크(**Magic Link**)를 쓰면 연락처가 따로 로그인하지 않고 바로 클라이언트 포탈에 들어올 수 있어요. 이메일이나 메시지로 링크를 보낼 때 편해요.

{% hint style="info" %}
클라이언트 포탈 대시보드에서 만든 매직 링크는 15분 뒤에 만료돼요. 링크를 만들면 남은 시간이 카운트다운 타이머로 표시돼요. 링크가 만료되면 **매직 링크 생성** 버튼이 다시 활성화되어, 새 링크를 만들 수 있어요.
{% endhint %}

![매직 링크 생성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010295415/original/u_iu3EOTE-g0MEYFZAESg4GoNEWrqcaQRQ.png?1697538706)

{% hint style="info" %}
매직 링크는 연락처마다 따로 만들어져요. 워크플로우 트리거로 매직 링크를 이메일에 넣어 보내려면, 필요한 데이터를 자동으로 가져와 매직 링크를 만들어 주는 커스텀 값을 사용하세요. 대시보드에서 만든 매직 링크는 유효 시간이 짧고 자동으로 만료돼요. 고객이 링크가 더 이상 유효하지 않다고 하면 새 매직 링크를 만들어 다시 보내 주세요.
{% endhint %}

## 작업 2. 클라이언트 포탈에 초대하기

작업 메뉴의 **Invite**(초대)를 선택하면 새 사용자를 클라이언트 포탈에 초대할 수 있어요. 이미 있는 연락처를 초대해도 되고, 이메일 주소를 직접 입력해도 돼요. 초대 이메일은 기본 도메인으로 발송돼요.

![클라이언트 포탈 초대 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010295329/original/DUG2QqLn3r8PLV6IfoXzV5t0Z6Dd3CH2Xg.png?1697538679)

## 작업 3. 로그인 이메일 보내기

**Login Email**(로그인 이메일)을 선택하면 연락처에게 빠른 로그인 버튼이 담긴 이메일이 자동으로 발송돼요. 고객은 이메일의 로그인 버튼을 눌러 비밀번호를 입력하지 않고도 클라이언트 포탈에 로그인할 수 있어요.

![로그인 이메일 발송 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010295799/original/MhNJZKg4lMyzxt_90RBibWwm3LeTgf8Enw.png?1697538833)

{% hint style="info" %}
연락처를 여러 명 선택해서 로그인 이메일을 한꺼번에 보낼 수 있어요.
{% endhint %}
