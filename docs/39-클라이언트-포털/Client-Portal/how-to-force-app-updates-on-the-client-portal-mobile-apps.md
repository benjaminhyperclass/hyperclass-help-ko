# 클라이언트 포탈 모바일 앱 강제 업데이트 설정

클라이언트 포탈 모바일 앱에서 필수 업데이트를 켜는 방법을 안내해요. 이 기능을 켜면 사용자가 항상 앱의 최신 버전을 쓰게 돼요. 보안, 성능, 사용 경험을 지키는 데 중요한 설정이에요.

## 강제 앱 업데이트란?

강제 앱 업데이트(Force App Update)는 사용자가 모바일 앱을 최신 버전으로 업데이트해야만 계속 쓸 수 있게 하는 기능이에요. 새 버전이 나오면 사용자에게 안내 창이 나타나고, 해당 앱 스토어로 이동해 업데이트할 수 있어요. 그래서 모든 사용자가 최신 기능과 강화된 보안을 이용할 수 있어요.

## 강제 앱 업데이트의 주요 장점

필수 업데이트를 적용하면 사용 경험과 앱의 안정성을 함께 높일 수 있어요.

- 보안 강화: 모든 사용자가 최신 보안 패치가 적용된 버전을 사용해요.
- 성능 개선: 최신 버전에 포함된 성능 최적화를 모든 사용자가 누려요.
- 기능 일관성: 모든 사용자가 가장 새로운 기능과 개선 사항을 쓸 수 있어요.
- 지원 문의 감소: 오래된 앱 버전 때문에 생기는 문제가 줄어, 지원 요청도 줄어들어요.
- 일관된 사용 경험: 모든 기기와 사용자에게 같은 경험을 제공해요.

## 강제 앱 업데이트 켜기

강제 앱 업데이트를 켜면 사용자가 중요한 업데이트를 건너뛸 수 없어요. 앱의 안정성과 사용자의 신뢰를 지키는 데 도움이 돼요.

1. 클라이언트 포털 설정을 여세요.
   1. 하이퍼클래스 대시보드에서 **사이트** 메뉴로 이동하세요.
   2. **클라이언트 포탈**을 선택하세요.
   3. **설정**을 클릭하세요.
2. 강제 업데이트를 켜세요.
   1. 설정 화면에서 **Force App Update**(앱 강제 업데이트) 옵션을 찾으세요.
   2. 스위치를 **활성화**로 바꾸세요.
3. 버전 정보를 입력하세요.
   1. 앱의 최신 버전 번호를 입력하세요.
   2. Apple App Store와 Google Play Store의 직접 다운로드 링크를 각각 입력하세요.
4. **변경사항 저장**
   1. **저장**을 클릭하면 새 설정이 적용돼요.

## 강제 앱 업데이트를 켠 뒤 사용자 화면

사용자가 어떤 과정을 거치는지 알아 두면 문의에 미리 대비하고 전환을 매끄럽게 진행할 수 있어요.

- 업데이트 안내: 앱을 실행하면 새 버전이 있다는 안내가 나타나요.
- 앱 스토어로 이동: 업데이트를 선택하면 해당 앱 스토어로 이동해 최신 버전을 내려받을 수 있어요.
- 이용 제한: 업데이트를 마칠 때까지 앱의 기능을 쓸 수 없어요.
- 원활한 전환: 업데이트를 마치면 향상된 기능과 보안이 적용된 앱을 평소처럼 쓸 수 있어요.

## 자주 묻는 질문

### 사용자가 업데이트 안내를 건너뛰고 앱을 계속 쓸 수 있나요?
아니요. 강제 앱 업데이트를 켜면 사용자는 앱을 최신 버전으로 업데이트해야 다시 이용할 수 있어요.

### 강제 업데이트는 얼마나 자주 적용하는 게 좋나요?
중요한 수정 사항이나 큰 기능 개선이 포함된 주요 릴리스에 강제 업데이트를 켜는 것을 권장해요.

### 이미 최신 버전을 쓰는 사용자도 영향을 받나요?
아니요. 최신 버전을 쓰는 사용자에게는 업데이트 안내가 나타나지 않아요. 앱도 끊김 없이 계속 쓸 수 있어요.

### 예정된 필수 업데이트를 사용자에게 미리 알릴 방법이 있나요?
네. 앱의 알림 기능으로 예정된 업데이트를 알리고, 미리 업데이트하도록 안내할 수 있어요.

## 다음 단계

- 소프트 앱 업데이트 적용: 꼭 필요하지 않은 개선 사항에는 소프트 업데이트를 켜서 사용자가 선택할 수 있게 해 보세요.
- 앱 성능 확인: 앱 성능 지표를 정기적으로 살펴보고 개선할 부분을 찾아보세요.
- 푸시 알림 활용: 푸시 알림으로 업데이트와 새 기능을 사용자에게 효과적으로 알려 보세요.
