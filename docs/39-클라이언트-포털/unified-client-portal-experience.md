# 통합 클라이언트 포털 경험

하이퍼클래스 전체에 통합 클라이언트 포털 경험이 순차적으로 적용되고 있어요. 이 문서에서는 달라지는 점과 활성화 방법, 새로 생긴 클라이언트 포털 이메일 필드를 안내해요.

## 개요

멤버에게 두 가지가 달라져요.

- **로그인 한 번으로 모든 리소스 확인**: 같은 서브 계정 안에 중복 연락처가 있는 최종 사용자도 이제 하나의 로그인으로 모든 리소스를 볼 수 있어요. 프로필을 바꿔 가며 로그인할 필요가 없어요.
- **더 안전해진 로그인**: 클라이언트 포털 로그인이 더 안전하고 안정적으로 바뀌었어요. 하이퍼클래스의 다른 화면과도 같은 방식으로 맞춰졌어요.

## 새로워진 점

1. **모든 것을 한 번에 로그인**: 멤버는 한 번만 로그인하면 코스, 커뮤니티, 멤버십, 결제 내역 같은 모든 리소스를 한곳에서 볼 수 있어요. 같은 이메일로 중복 계정이 여러 개 있었더라도 마찬가지예요. 여러 로그인을 오가거나 프로필마다 찾아 헤맬 필요가 없어요.
2. **리소스별로 하나로 합쳐진 공간**: 중복 프로필에 흩어져 있던 콘텐츠와 이용 내역이 하나의 계정으로 모여요. 멤버가 원하는 내용을 늘 기대한 자리에서 찾을 수 있어요.
3. **더 안전하고 표준화된 로그인**: 로그인이 더 안전해지고 플랫폼의 다른 화면과 일관되게 바뀌었어요. 최종 사용자는 더 매끄럽고 안정적으로 로그인할 수 있어요.
4. **새로운 디자인, Compass 앱**: 통합 경험에는 새롭게 디자인한 Compass 인터페이스가 함께 제공돼요. 멤버는 더 깔끔하고 현대적인 포털을 쓰게 돼요.
5. **연락처와 포털 계정의 안정적인 연결**: CRM에서 연락처의 기본 이메일을 바꿔도 클라이언트 포털 로그인이 의도치 않게 바뀌거나 끊기지 않아요. 클라이언트 포털 전용 이메일 필드가 각 연락처를 알맞은 포털 계정에 안정적으로 연결해 주고, 관련된 모든 연락처에 변경 내용이 동기화돼요.

![새 브랜드 로그인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078548681/original/M0VqtIcRoO7XK1PTlvw9f3rmcS--ai3f7Q.png?1786942959)

새 브랜드 로그인 화면이에요. 이전에 중복 연락처가 있던 멤버에게는 프로필 확인이 한 번 표시돼요.

![멤버 화면에서 하나로 합쳐진 리소스](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078548679/original/w3pqAw3f7TlsoUPUoIqir04cVTUDc30kBA.png?1786942958)

멤버 화면이에요. 한 멤버의 모든 연락처에 배정된 리소스가 하나의 로그인 아래에 함께 표시돼요.

## 통합 경험 활성화하기

시작은 간단해요. 서브 계정의 빌더에서 클라이언트 포탈 대시보드를 열기만 하면 돼요.

이렇게 한 번 열면 해당 서브 계정이 업그레이드 대기열에 들어가요. 그다음부터는 백그라운드에서 자동으로 진행되고, 준비가 끝나면 멤버에게 새 Compass 경험이 켜져요. 따로 설정할 것도 없고, 누구도 로그아웃시킬 필요가 없어요.

### 1단계. 클라이언트 포탈 대시보드 열기

서브 계정에서 **멤버십 > 클라이언트 포탈 > 대시보드**로 이동하세요. 새로 디자인한 포털 안내가 보여요. 멤버에게 적용하기 전에 내 계정에서 새 디자인을 미리 볼 수 있어요.

![새 클라이언트 포털 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078548683/original/IUObkuDUgHohxox-PGSxXk22xklNuHdAHg.png?1786942960)

새 클라이언트 포털 안내 화면이에요. 먼저 비공개로 미리 본 뒤 모든 멤버에게 활성화하세요.

- **미리보기 열기**: 비공개 미리보기 토큰으로 새 탭에서 포털을 열어요. 멤버에게는 계속 현재 버전이 보여요.
- **모두에게 활성화**: 모든 멤버가 바로 새 디자인으로 로그인해요. 언제든 기존 포털로 되돌릴 수 있어요.
- 사용자 지정 CSS나 JS를 쓰고 있나요? 먼저 새 디자인을 미리 보고 사용자 지정 코드를 업데이트한 다음, 모두에게 활성화하세요.

{% hint style="info" %}
활성화한 뒤 업데이트된 화면이 모든 사용자에게 표시되기까지 최대 5분 걸릴 수 있어요.
{% endhint %}

### 2단계. 이전이 끝날 때까지 기다리기

서브 계정이 대기열에 들어가면 포털이 백그라운드에서 새 경험으로 이전돼요. 보통 몇 분 정도 걸려요. 대화 상자를 닫고 나중에 다시 확인해도 이전은 알아서 계속 진행돼요.

![이전 진행 중 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078548682/original/JBBH29LUYStniCotNaTNAZaJrrFgy-vKGw.png?1786942959)

**이전 진행 중** 화면이에요. 업그레이드는 백그라운드에서 계속 진행되고, 따로 할 일은 없어요.

### 3단계. 멤버는 평소처럼 로그인

멤버에게 따로 안내하거나 다시 가입시킬 필요가 없어요. 멤버는 늘 하던 대로 로그인하면 모든 리소스를 한곳에서 볼 수 있어요.

## 새로 생긴 클라이언트 포털 이메일 필드

이번 업데이트로 CRM의 연락처 레코드에 클라이언트 포털 전용 이메일 필드가 생겼어요. 이 필드 덕분에 클라이언트 포털 로그인 정보가 연락처의 기본 이메일과 분리되고, 기본 이메일이 바뀌어도 영향을 받지 않아요.

연락처 레코드에서 **Actions**(작업) > **클라이언트 포털**에서 확인할 수 있어요. 클라이언트 포털 사용자는 이 이메일 주소로 로그인하고, 코스·커뮤니티 같은 모든 클라이언트 포털 앱의 알림도 이 주소로 받아요. 같은 패널에서 멤버의 비밀번호를 변경하거나 재설정 링크를 보낼 수도 있어요.

![연락처 레코드의 클라이언트 포털 이메일 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078548680/original/Q5kmNWoxuf-FBbP0r5OY_sf7h7qWc0jKvg.png?1786942959)

연락처 레코드 화면이에요. 클라이언트 포털 전용 이메일 필드와 함께 비밀번호 변경, 재설정 링크 보내기 기능이 있어요.

{% hint style="warning" %}
**중복 CRM 연락처는 자동으로 병합되지 않아요.**

CRM에 중복된 연락처가 있어도 이번 업데이트에서 연락처 레코드가 병합되지는 않아요. 통합 경험은 멤버의 리소스를 하나의 로그인으로 모아 줄 뿐, CRM의 연락처는 그대로 유지돼요.

중복된 CRM 연락처를 병합하는 일은 직접 해야 하며, 에이전시 또는 서브 계정 소유자가 진행해야 해요.
{% endhint %}

## 자주 묻는 질문

### 멤버를 로그아웃시키거나 다시 초대해야 하나요?

아니요. 로그아웃시킬 필요도, 다시 초대할 필요도 없어요. 멤버는 이전과 똑같이 로그인하면 돼요.

### 같은 이메일로 중복 계정이 여러 개 있던 멤버는 어떻게 되나요?

이제 한 번만 로그인하면 코스, 커뮤니티, 멤버십, 결제 내역 같은 모든 리소스를 하나의 로그인으로 볼 수 있어요. 중복 프로필에 있던 콘텐츠와 이용 내역도 하나의 계정으로 모여요.

### CRM의 중복 연락처도 병합되나요?

아니요. 중복된 CRM 연락처를 병합하는 일은 에이전시 또는 서브 계정 소유자가 직접 진행해야 해요.

### 연락처의 기본 이메일을 바꾸면 포털 로그인이 안 되나요?

아니요. 클라이언트 포털 전용 이메일 필드가 포털 로그인 정보를 기본 이메일과 분리해 주고, 관련된 모든 연락처에 변경 내용이 동기화돼요.

### 새 디자인을 켠 뒤에 기존 포털로 되돌릴 수 있나요?

네, 언제든 기존 포털로 되돌릴 수 있어요.

### 변경 사항이 적용되기까지 얼마나 걸리나요?

이전 작업은 백그라운드에서 진행되고, 보통 몇 분 걸려요. 모두에게 새 디자인을 활성화한 뒤에는 모든 멤버에게 업데이트된 화면이 표시되기까지 최대 5분 걸릴 수 있어요.

### 포털에 사용자 지정 CSS나 JS를 쓰고 있어요. 어떻게 해야 하나요?

먼저 비공개 미리보기 링크로 새 디자인을 확인하세요. 새 디자인에 맞게 사용자 지정 코드를 업데이트한 다음, 모두에게 새 경험을 활성화하세요.

## 지원팀 참고 사항

- 빌더에서 누군가 클라이언트 포탈 대시보드를 처음 열면 해당 서브 계정이 이전 대기열에 들어가요. 서브 계정에서 아직 새 경험이 적용되지 않았다고 문의하면 대시보드를 한 번이라도 열었는지 확인하세요.
- 업그레이드 후 멤버가 리소스가 보이지 않는다고 하면, 해당 멤버의 연락처들이 같은 클라이언트 포털 이메일을 쓰는지 확인하세요. 리소스는 CRM 연락처 레코드가 아니라 포털 로그인 정보를 기준으로 합쳐져요.
- CRM 이메일을 바꾼 뒤 로그인이 안 된다는 문의는 연락처의 클라이언트 포털 이메일 필드를 확인하세요. 이제 포털 로그인의 기준은 이 필드예요.
- 새 디자인을 켠 직후에 스타일이 깨진다는 문의는 대부분 Compass 인터페이스에 맞게 업데이트하지 않은 사용자 지정 CSS나 JS 때문이에요.
