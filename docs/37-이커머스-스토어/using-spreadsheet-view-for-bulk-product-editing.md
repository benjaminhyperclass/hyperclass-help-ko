# 스프레드시트 보기로 상품 대량 편집하기

스프레드시트 보기에서는 여러 상품을 표 형태로 한 화면에서 고칠 수 있어요. 상품이 많은 스토어에서 카탈로그를 빠르게 정리할 때 쓰면 좋아요. 이 문서에서는 대량 편집이 무엇인지, 어떤 점이 좋은지, 설정하고 사용하는 방법을 안내해요.

## 상품 대량 편집이란?

상품 대량 편집은 스프레드시트 같은 편집기로 여러 상품을 한 번에 수정하는 기능이에요. 상품을 하나씩 열지 않아도 한 화면에서 여러 필드를 바꿀 수 있어요.

상품이 많은 스토어일수록 손이 덜 가고, 정보를 일관되게 맞추기 쉬워요.

## 스프레드시트 보기에서 대량 편집할 때의 장점

대량 편집을 쓰면 상품 카탈로그를 더 빠르고 정확하게 관리할 수 있어요.

- 효율성: 여러 상품 속성을 동시에 편집할 수 있어서 수작업 시간이 줄어요.
- 폭넓은 관리: 제목, 설명, 미디어, 세금 코드, 컬렉션, 재고, 배송, SEO 같은 정보를 한곳에서 수정할 수 있어요.
- 익숙한 작업 방식: 스프레드시트처럼 표에서 바로 편집하므로 쉽게 쓸 수 있어요.
- 오류 방지: 내장된 검증 기능이 잘못된 입력을 표시하고, 잘못된 데이터는 저장되지 않게 막아 줘요.

## 스프레드시트 보기에서 상품 대량 편집하기

아래 순서대로 따라 하면 상품을 대량으로 편집할 수 있어요.

### 결제 열기

왼쪽 메뉴에서 **결제**(Payments)를 클릭하세요. 상품과 관련된 모든 작업은 여기서 시작해요.

{% hint style="info" %}
사용자 권한이 올바르게 설정되어 있는지 확인하세요. 권한이 없으면 편집 기능을 쓸 수 없을 수 있어요.
{% endhint %}

![왼쪽 메뉴에서 결제 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233048/original/otfxgD2MUezcH197l0w4YMU8TeeuKPwhkw.png?1756027024)

### 상품으로 이동

**결제** 화면 위쪽 메뉴에서 **상품** 탭을 클릭하세요. 전체 상품 목록이 열려요.

![상단 메뉴의 상품 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233053/original/GIDmqpcEpj0Cc8uoAtMGyWhFA-CLGO1GAQ.png?1756027045)

### 상품 선택

편집할 상품 옆의 체크박스를 선택하세요. 여러 상품을 한꺼번에 선택해서 대량으로 바꿀 수 있어요.

![편집할 상품 체크박스 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233060/original/wzbwqer08wxBnVBo8VnctVqITxyZrwgeIA.png?1756027061)

### 대량 편집 클릭

작업 표시줄의 **대량 편집** 버튼을 클릭하세요. 스프레드시트 형태의 편집기가 열리고, 선택한 상품이 모두 표에 나타나요.

![대량 편집 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233065/original/RnbFxn-TEwRvAOyRplyw6X52BG4TGfipHw.png?1756027086)

### 상품 필드 편집

상품 이름, 설명, 가격, 컬렉션 같은 정보를 스프레드시트 셀에서 바로 수정하세요.

![스프레드시트 셀에서 상품 정보 수정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233218/original/MRzxgTbSfWi3re-33n6N39tgS-s1GU1KXA.png?1756027945)

{% hint style="info" %}
검증: 잘못 입력한 셀은 빨간색으로 표시돼요. 저장하기 전에 반드시 고쳐야 해요.

요금제 안내: 사용 중인 요금제에서 제공하지 않는 필드는 (—)로 표시돼요.

요금제(에이전시 또는 SaaS)에 따라 일부 필드는 편집할 수 없는 (—) 상태로 보일 수 있어요.
{% endhint %}

![잘못된 입력이 빨간색으로 표시되는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233105/original/nCGLmHwTpdZ2rKIyemNukBoZaZQkW4o-3g.gif?1756027278)

### 필드 관리

**필드 관리**를 클릭하면 스프레드시트 보기에 표시할 상품 속성을 고를 수 있어요.

![필드 관리 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233082/original/_bVv41eiAl_5krD4vVvJiRECTgP5mPW1lg.png?1756027188)

### 열 사용자 지정

**필드 관리** 패널에서 **설명**, **컬렉션**, **미디어**, **Pricing**(가격), **재고**, **SEO** 같은 속성을 선택하거나 선택 해제하세요. 선택한 열 설정은 다음에 열 때도 유지되어, 반복 편집이 편해져요.

{% hint style="info" %}
**제목**, **Price**(가격), **상품 유형** 같은 핵심 필드는 계속 표시해 두세요. 필수 정보를 놓치지 않을 수 있어요.
{% endhint %}

![필드 관리 패널에서 열 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233092/original/-7FF3ufHfd1StwbT80LYm9YkzDCj-OHgsQ.png?1756027228)

### 변경사항 저장

편집을 마쳤으면 오른쪽 위의 **저장**을 클릭해 변경 내용을 적용하세요.

![오른쪽 위 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052233085/original/sgLOeggYqGEDTBIr8QgipmDwX9UOUDJDOQ.png?1756027207)

## 자주 묻는 질문

### 상품을 많이 선택했더니 일부 행의 필드에 대시(—)가 보여요. 편집 가능한 필드만 저장할 수 있나요? 편집할 수 없는 필드는 어떻게 되나요?

네, 저장할 수 있어요. 스프레드시트에서 편집 가능한 셀은 모두 수정할 수 있어요. (—)로 표시된 셀은 사용 중인 요금제나 상품 유형에서 편집할 수 없고, 값이 그대로 유지돼요. 저장하면 올바르게 편집한 내용만 적용돼요. 다만 편집 가능한 행에서 필수 필드(예: **제목** 또는 **Price**/**금액**)가 잘못되었거나 비어 있으면, 그 오류를 해결할 때까지 저장할 수 없어요. 에이전시 플랜 상품은 모든 필드를 편집할 수 없어요.

### 상품 하나에 잘못된 값(빨간 셀)이나 빈 필수 필드가 있으면 대량 편집 전체가 저장되지 않나요?

네, 그래요. 스프레드시트 보기는 표 전체를 검증해요. 잘못된 셀이 하나라도 있거나 필수 필드가 비어 있으면 **저장**을 할 수 없어요. 잘못된 셀은 **빨간색**으로 표시되고, 모든 검증 문제를 해결할 때까지 **저장되지 않은 변경사항** 표시가 계속 보여요. 표시된 셀을 고치거나, **필드 관리**에서 필요한 열을 다시 표시한 뒤 저장하세요.

### **필드 관리**에서 일부 열을 숨겼어요. 필수 필드가 숨겨져 있어도 저장할 수 있나요? 숨긴 필드가 일부 행에서 비어 있으면요?

열을 숨겨도 검증은 건너뛰지 않아요. 편집한 모든 상품에서 필수 필드가 올바른 값이어야 해요. 숨겨진 필수 필드가 어느 행에서든 비어 있거나 잘못되었다면 저장할 수 없어요. **필드 관리**를 다시 열어 필수 열(예: **제목**, **금액**, **상품 유형**)을 선택하고, 값을 고친 뒤 저장하세요.
