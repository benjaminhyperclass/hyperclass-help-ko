# 스토어에서 바로 상품 페이지 미리보기·링크 공유하기

**스토어 > 상품**에서 라이브 상품 상세 페이지(PDP)를 바로 미리 보고 링크를 복사할 수 있어요. 상품을 공유할 때마다 **Store Builder**(스토어 빌더)를 열지 않아도 돼요.

이 문서에서는 **미리보기**와 **링크 복사**를 쓰는 방법, 하이퍼클래스가 커스텀 도메인과 SEO 핸들로 상품 URL을 만드는 방식, 상품을 커스텀 PDP에 연결했을 때 어떻게 동작하는지를 설명해요.

## 상품 페이지 공유란?

상품 페이지 공유는 **스토어 > 상품**에서 라이브 상품 상세 페이지(PDP) 링크를 바로 미리 보고 복사하는 기능이에요. 상품 페이지를 공유하거나 확인할 때마다 **Store Builder**를 열지 않아도 돼요.

**포함됨** 탭의 상품마다 두 가지 작업을 쓸 수 있어요.

- **미리보기**: 라이브 상품 페이지를 새 브라우저 탭에서 열어요.
- **링크 복사**: 완성된 URL을 클립보드에 복사하고, 확인 메시지를 보여 줘요.

하이퍼클래스는 커스텀 PDP 연결을 자동으로 반영해요. 스토어의 커스텀 도메인이나 미리보기 도메인으로 URL을 만들기 때문에, 공유하는 링크가 정확해요.

## 이런 점이 좋아요

- 작업이 빨라져요: **상품** 화면을 떠나거나 **Store Builder**를 열지 않고도 상품 링크를 미리 보고 공유할 수 있어요.
- URL이 정확해요: 커스텀 PDP 연결과 SEO 핸들을 자동으로 반영해서 올바른 상품 페이지 링크를 만들어요.
- 도메인이 자동으로 정해져요: 커스텀 도메인을 먼저 쓰고, 연결된 커스텀 도메인이 없으면 미리보기 도메인을 써요.
- 복사 여부를 바로 알 수 있어요: **링크 복사**를 누르면 "상품 링크가 복사되었습니다" 메시지가 나타나서 URL을 바로 붙여 넣을 수 있다는 걸 알 수 있어요.
- 빌더 미리보기가 정확해졌어요: 커스텀 PDP에 연결한 상품은 빌더 미리보기에서 상품 목록 페이지가 아니라 해당 PDP가 열려요.

## 상품 URL이 만들어지는 방식

하이퍼클래스는 아래 기준으로 상품 URL을 만들어요. 그래서 링크에 스토어의 도메인과 페이지 설정이 정확히 반영돼요.

1. 커스텀 PDP 연결: 상품을 커스텀 상품 상세 페이지에 연결했다면, URL을 만들 때 기본 PDP 템플릿 대신 그 페이지를 자동으로 써요.
2. SEO 핸들: 상품의 SEO 핸들이 URL 슬러그가 돼요. 상품 이름에 맞는, 검색 엔진 친화적인 깔끔한 URL이 만들어져요.
3. 도메인 우선순위: 커스텀 도메인을 가장 먼저 써요. 스토어에 연결된 커스텀 도메인이 없으면 미리보기 도메인을 자동으로 써요.

{% hint style="info" %}
상품 링크에 내 브랜드 도메인을 쓰려면, 고객에게 상품 페이지를 공유하거나 마케팅 캠페인에 넣기 전에 스토어에 커스텀 도메인을 연결하세요.
{% endhint %}

## 상품 링크 미리보기·복사하기

**상품** 화면에서 라이브 상품 페이지 링크를 미리 보거나 공유하는 방법이에요.

1. 하이퍼클래스 계정에서 **스토어 > 상품**으로 이동하세요. 기본으로 **포함됨** 탭이 열리고, 현재 스토어에 포함된 상품이 모두 보여요.
2. 미리 보거나 공유할 상품을 목록에서 찾으세요. **미리보기**와 **링크 복사**는 **포함됨** 탭의 상품에만 보여요.
3. 상품마다 있는 두 가지 작업 중 하나를 선택하세요.
   - **미리보기**: 라이브 상품 상세 페이지를 새 브라우저 탭에서 열어요. 공유하기 전에 페이지를 확인할 수 있어요.
   - **링크 복사**: 완성된 상품 URL을 클립보드에 복사하고 "상품 링크가 복사되었습니다" 확인 메시지를 보여 줘요.

     ![상품 목록에서 미리보기와 링크 복사 작업을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080617319/original/t7q_zuiqztAT2Ol9xGx4lncdtJPmd8fT3A.png?1789049954)

4. 링크를 복사했다면 마케팅 캠페인, 이메일 시퀀스, 소셜 미디어 게시물에 붙여 넣으세요. **미리보기**를 썼다면, 고객에게 공유하기 전에 라이브 페이지가 제대로 보이는지 확인하세요.

{% hint style="info" %}
**미리보기**와 **링크 복사**는 **포함됨** 탭의 상품에서만 쓸 수 있어요. **제외됨** 탭이나 **전체** 탭의 상품에는 이 작업이 보이지 않아요.
{% endhint %}

## 달라진 상품 탭과 미리보기 동작

상품 관리와 미리보기가 더 편해지도록 **상품** 화면이 아래와 같이 바뀌었어요.

### 기본 탭 순서

**상품** 화면은 기본으로 **포함됨** 탭이 열리고, 그다음에 **제외됨**, **전체** 순서로 나와요. 라이브 상태라서 미리 보거나 공유할 수 있는 상품이 먼저 보여요.

### 포함됨 탭의 상품만 가능

**미리보기**와 **링크 복사**는 **포함됨** 탭의 상품에서만 쓸 수 있어요. 지금 스토어에서 활성 상태인 상품만 공유하거나 미리 보게 하기 위해서예요.

### 빌더 미리보기 개선

**Store Builder**에서 상품을 미리 볼 때, 커스텀 PDP에 연결한 상품은 이제 상품 목록 페이지가 아니라 해당 상품 상세 페이지가 열려요.

### 결과

라이브 상품이 화면 앞쪽에 먼저 보이고, 미리보기에는 항상 올바른 상품 페이지 설정이 반영돼요. 그래서 워크플로우이 더 자연스러워져요.

## 자주 묻는 질문

### 제외된 상품도 미리보기하거나 링크를 복사할 수 있나요?

아니요. **미리보기**와 **링크 복사**는 **포함됨** 탭의 상품에서만 쓸 수 있어요. 제외된 상품은 지금 스토어에서 라이브 상태가 아니라서 이 작업이 보이지 않아요.

### 스토어에 커스텀 도메인이 연결돼 있지 않으면 어떻게 되나요?

커스텀 도메인이 없으면 하이퍼클래스가 사용할 수 있는 미리보기 도메인으로 상품 URL을 자동으로 만들어요. 링크는 그대로 작동하지만, 내 브랜드 도메인이 아니라 하이퍼클래스 기본 미리보기 도메인이 쓰여요.

### 하이퍼클래스는 어떤 상품 상세 페이지를 쓸지 어떻게 정하나요?

상품이 커스텀 PDP에 연결돼 있으면, 상품 URL을 만들 때 그 커스텀 페이지를 자동으로 써요. 연결된 커스텀 PDP가 없으면 스토어의 기본 PDP 템플릿을 써요.

### "상품 링크가 복사되었습니다" 메시지는 무슨 뜻인가요?

**링크 복사**를 눌렀을 때 나타나는 메시지예요. 상품 URL이 클립보드에 복사됐다는 뜻이에요. 이제 마케팅 자료에 붙여 넣거나 고객에게 공유하면 돼요.

### **Store Builder**에서도 상품을 미리 볼 수 있나요?

네. **Store Builder**에서 상품을 미리 보면, 상품의 커스텀 PDP 연결에 맞는 상품 상세 페이지가 열려요. 고객이 실제로 보게 될 페이지를 확인할 수 있어요.

### SEO 핸들이 뭐고, 상품 URL에 어떤 영향을 주나요?

SEO 핸들은 상품 이름을 URL에 쓰기 좋게 바꾼 값이에요. 하이퍼클래스는 이 SEO 핸들을 상품별 URL 슬러그로 써서 깔끔하고 읽기 쉬운 URL을 만들어요. 검색 엔진 최적화에 도움이 되고, 고객이 상품 링크를 공유하기도 쉬워져요.

### 상품 링크를 공유하려면 꼭 **Store Builder**를 열어야 하나요?

아니요. **스토어 > 상품**에서 바로 상품 링크를 미리 보고 복사할 수 있어요. **Store Builder**를 열지 않아도 되기 때문에, 여러 상품을 공유할 때 시간을 아낄 수 있어요.

### 아직 스토어에 올라가지 않은 상품도 미리볼 수 있나요?

아니요. **미리보기**와 **링크 복사**는 **포함됨** 탭의 상품에서만 쓸 수 있어요. 상품을 미리 보려면 먼저 **상품** 화면에서 스토어에 포함해야 해요.
