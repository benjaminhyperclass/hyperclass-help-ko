# 스토어 주문의 배송 라벨·패킹 슬립 인쇄하기

이커머스 스토어 주문에 대해 배송 라벨과 패킹 슬립(포장 명세서)을 만들 수 있어요. 주문 전체나 일부 상품만 골라 인쇄할 수 있어서 주문 처리가 한결 편해져요.

## 소개

만든 배송 라벨과 패킹 슬립에는 아래 정보가 들어가요.

1. **주문 ID**
2. **주문일**
3. 스토어 이름
4. **배송 주소**와 **청구지 주소**
5. 상품 목록 (아래 정보 포함)
   1. **배리언트 이름**
   2. **상품 이미지**
   3. 수량
6. 보내는 사람 주소(스토어 주소)

## 사용 방법

1. **결제 > 주문**으로 이동해요.
2. 스토어 주문 중 하나를 선택해요.
3. **Print Shipping Label**(배송 라벨 인쇄)을 클릭해요.

배송 라벨은 세 곳에서 만들 수 있어요.

1. 주문 상세 페이지: **Print Shipping Label** 버튼을 클릭하면 미처리 주문과 처리 완료 주문이 각각 별도 페이지에 담긴 PDF를 내려받아요.

   ![주문 상세 페이지의 배송 라벨 인쇄 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030203469/original/NCGmvEDm2w9a4npuDX5YxR6cjZWVxqjwlw.png?1722412012)
2. 주문 처리(풀필먼트) 화면: 주문을 처리할 때 선택한 상품과 수량이 목록으로 나타나요. **Print Shipping Label** 버튼을 클릭하면 해당 상품의 배송 라벨이 만들어져요.

   ![주문 처리 화면에서 선택한 상품과 수량 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030203560/original/eWb54GdVuIO5k6vfXX4vjMubraVXBK2Byg.png?1722412127)
   ![주문 처리 화면의 배송 라벨 인쇄 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030203496/original/nUmAXc2aHcvewMpXq_OuDPqtNx-F7b6wBg.png?1722412034)
3. 부분 처리된 주문: 부분 처리된 주문 옆의 점 3개를 클릭하면 해당 주문의 패킹 슬립이나 배송 라벨을 내려받는 옵션이 나타나요.

   ![부분 처리된 주문 옆 점 3개 메뉴의 패킹 슬립·배송 라벨 내려받기 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030203753/original/Zd-qJRIsdHpXDl0If7G8D4hmlyqHDVb4Pw.png?1722412283)

{% hint style="info" %}
- 배송 라벨과 패킹 슬립은 이커머스 스토어 주문에 대해서만 만들 수 있어요.
- 여러 번에 나눠 부분 처리한 주문은 배송 라벨을 만들 때 처리 건마다 상품이 별도 페이지에 나열돼요.
- 현재 배송 라벨에는 청구지 주소와 배송 주소가 같게 표시돼요. 결제 페이지에 청구지 주소 필드가 추가되면 수정할 수 있게 될 예정이에요.
{% endhint %}
