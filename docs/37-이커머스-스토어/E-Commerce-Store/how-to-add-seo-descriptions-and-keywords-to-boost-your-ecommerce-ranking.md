# 상품에 SEO 제목·설명 추가하기

스토어 운영자는 상품마다 SEO 정보를 넣을 수 있어요. 검색 결과에서 고객이 상품을 더 쉽게 찾도록 도와줘요. 이 문서에서는 SEO 정보를 입력하는 위치와 알아 둘 점을 안내해요.

## 사용 방법

상품 SEO는 **결제 > 상품**의 상품 만들기/편집 페이지에서 추가해요. 이 페이지에서 SEO 제목, 설명, 사용자 지정 슬러그를 설정할 수 있어요.

{% hint style="info" %}
- SEO 미리보기 이미지로는 대표 이미지가 사용돼요.
- SEO는 상품을 온라인 스토어에 노출하는 토글을 켠 경우에만 수정할 수 있어요.- 같은 슬러그를 여러 상품에 쓸 수 없어요.
{% endhint %}
