# 온라인 스토어 재고 관리 기능 사용하기

**재고** 페이지에서 상품 수량을 수정하고, 재고가 없어도 판매할지 정할 수 있어요. 검색 기능으로 원하는 상품을 빠르게 찾을 수도 있어요.

## 소개

스토어 운영자는 새로 생긴 재고 관리 페이지에서 재고를 한곳에서 편하게 관리할 수 있어요. 이 페이지에서는 상품 수량을 수정하고 **재고 소진 시에도 판매 계속** 옵션을 켤 수 있어요. 검색 기능도 더 좋아졌어요.

## 사용 방법

1. **결제 > 상품** 드롭다운 > **재고**로 이동해 재고 관리 페이지를 엽니다.
2. 재고 관리 페이지에서 모든 옵션(변형)의 상품 수량을 수정할 수 있어요. 재고가 없어도 계속 판매하려면 **재고 소진 시에도 판매 계속**을 켜세요.
3. 재고를 수정한 뒤 **저장**을 클릭하면 변경 사항이 적용돼요. 변경 사항을 버리려면 **취소**를 클릭하세요.
4. 특정 상품을 찾으려면 **상품 검색**에서 SKU나 상품·옵션 이름으로 검색하세요.

## 참고 사항

- 페이지를 벗어나기 전에 변경 사항을 저장하거나 취소해야 해요. 저장하지 않은 변경 사항이 있으면 다른 페이지로 이동할 수 없어요.
- SKU를 입력하지 않은 상품은 **SKU 없음**으로 표시돼요.
- **재고** 페이지에서 상품 옵션을 클릭하면 해당 옵션의 상세 페이지로 이동해요.
