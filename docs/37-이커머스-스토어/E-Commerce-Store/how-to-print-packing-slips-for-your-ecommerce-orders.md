# 이커머스 주문 포장 명세서 인쇄

스토어 주문의 포장 명세서를 만들어 주문 처리 과정을 더 간편하게 할 수 있어요. 주문 전체나 일부 상품만 골라 라벨을 인쇄할 수 있어서, 상품을 처리할 때 쓰기 좋아요.

만들어진 라벨에는 다음 정보가 들어가요.

- 주문 ID
- 주문 날짜
- 스토어 이름
- **배송 주소**와 **청구지 주소**
- 주문 메모 (고객이 결제 중에 메모를 남긴 경우)
- 상품 목록
  - 상품명 또는 옵션명
  - **상품 이미지**
  - 수량
  - SKU
- 발송인 주소 (스토어 주소)

## 사용 방법

스토어 운영자는 **결제 > 주문**(Orders)에서 스토어 주문을 선택한 뒤 **Print Shipping Label**(배송 라벨 인쇄)을 눌러 포장 명세서를 만들 수 있어요.

포장 명세서는 두 곳에서 만들 수 있어요.

1. 주문 상세 페이지: **Print Shipping Label** 버튼을 누르면 PDF가 내려받아져요. 이 PDF에는 미처리 항목과 처리 완료 항목이 각각 별도 페이지로 담겨 있어요.
2. 주문 처리 화면: 주문을 처리할 때 선택한 상품과 수량이 목록에 표시돼요. 여기서 **Print Shipping Label** 버튼을 누르면 해당 상품의 배송 라벨이 만들어져요.

## 참고 사항

- 포장 명세서는 이커머스 스토어 주문에서만 만들 수 있어요.
- 부분 처리를 여러 번 한 주문은, 포장 명세서를 만들 때 처리 건마다 상품 목록이 별도 페이지에 나와요.
- 현재 포장 명세서에는 청구지 주소와 배송 주소가 같게 표시돼요. 결제 페이지에 청구지 주소 필드가 출시되면 따로 수정할 수 있게 될 예정이에요.
- 주문 메모 섹션은 고객이 결제 중에 메모를 남긴 경우에만 상품 목록 위에 나타나요.
- 상품 SKU는 상품 또는 옵션 설정에서 가져와 상품 목록 표에 표시돼요.
