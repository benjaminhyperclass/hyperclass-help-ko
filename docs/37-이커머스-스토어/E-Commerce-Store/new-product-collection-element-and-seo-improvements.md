# 컬렉션 목록 요소 추가와 SEO 개선

스토어가 켜져 있는 페이지라면 어디든 컬렉션 목록 요소를 넣고, 보여 줄 컬렉션을 골라 배치할 수 있어요. 컬렉션에 이미지와 SEO 정보도 넣을 수 있어서 컬렉션을 더 알차게 꾸밀 수 있어요.

## 사용 방법

1. **결제 > 상품 > 컬렉션**으로 이동해 컬렉션을 설정하세요. 이미지는 넣어도 되고 넣지 않아도 돼요. 여기에서 이름, 이미지, **SEO title**(SEO 제목), **SEO 설명**, **Handle**(핸들)을 수정할 수 있어요.
2. 스토어의 페이지 빌더로 이동해 **Collection List**(컬렉션 목록) 요소를 추가하세요. 요소 목록의 **스토어** 섹션에 있어요.
3. 이름과 이미지가 임시로 채워진 기본 컬렉션 3개가 나타나요. 요소를 클릭하면 오른쪽에 설정이 열려요. 필요한 항목을 설정하세요.
   - 제목, 여백(마진·패딩), 색상, 테두리, 글꼴 같은 항목은 다른 요소와 똑같이 설정할 수 있어요.
   - 한 줄에 보이는 컬렉션 수는 기본 3개예요. **레이아웃** 탭의 **Number of columns**(열 개수)에서 데스크톱과 모바일 값을 각각 바꿀 수 있어요. 최대 열 수는 데스크톱 5개, 모바일 2개예요.
   - 제목이 필요 없으면 **Text options**(텍스트 옵션)의 **Headline**(제목) 필드를 비워 두세요. 제목이 사라져요.
4. 보여 줄 컬렉션을 정하려면 **컬렉션** 그룹에 나열된 컬렉션 중 하나를 클릭하세요. 컬렉션을 고를 수 있는 영역이 나타나요. 컬렉션을 선택하면 빌더에 해당 컬렉션의 이름과 이미지가 표시돼요.

   {% hint style="info" %}
   실제 컬렉션을 보여 주려면 이 단계를 꼭 해야 해요. 임시로 채워진 기본 컬렉션은 라이브 사이트에서 아무 역할을 하지 못해요.
   {% endhint %}

   ```
   캔버스에서 바로 컬렉션 선택하고 연결하기

   설정을 더 빠르게 할 수 있도록, 이제 컬렉션 목록 요소 안의 항목을 캔버스에서 바로 선택할 수 있어요.

   컬렉션 목록 요소의 항목을 더블 클릭하세요.

   항목이 실제 컬렉션에 연결되어 있지 않으면 선택 창이 자동으로 열려요. 여기에서 컬렉션을 지정하세요. (확인 필요: 선택 창의 이름·위치)

   항목이 이미 연결되어 있으면 선택된 컬렉션이 캔버스에서 강조 표시돼요.

   양방향 동기화: 선택 창에서 바꾼 내용은 캔버스에 바로 반영되고, 캔버스에서 선택한 내용은 선택 창에도 반영돼요.

   일정한 순서 유지: 요소에 항목을 추가하거나 삭제해도 선택 순서가 그대로 유지돼요.
   ```

5. **저장** 또는 **게시**를 클릭하면 사이트에서 변경 내용을 확인할 수 있어요.

## 알아 두면 좋은 점

- 컬렉션에 이미지가 있으면 해당 컬렉션에 그 이미지가 표시돼요. 이미지가 없으면 컬렉션 이름이 배경 위 가운데에 표시돼요.
- 업로드한 이미지와 SEO 정보는 컬렉션 필터가 적용된 상품 목록 페이지의 SEO 태그를 만드는 데 쓰여요.
