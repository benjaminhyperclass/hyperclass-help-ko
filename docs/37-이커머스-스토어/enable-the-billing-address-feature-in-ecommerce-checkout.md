# 이커머스 결제 페이지에서 청구지 주소 켜고 사용하기

이커머스 결제 페이지에서 청구지 주소를 따로 받는 기능을 켜고 쓰는 방법을 안내해요. 청구지 주소를 배송 정보와 나눠서 받으면 주문 정보가 더 정확해지고, 규정 준수와 온라인 스토어 맞춤 설정에도 도움이 돼요.

## 청구지 주소 기능이란?

청구지 주소 기능을 켜면 고객이 결제할 때 배송지와는 별도로 청구지 주소를 입력할 수 있어요. 이때 **결제 페이지**에 새 섹션이 추가돼요. 입력한 청구지 주소는 배송 정보와 함께 **연락처**, **Customer Access Center**(고객 액세스 센터, CAS), 주문 확인 이메일 등 여러 곳에 저장돼요.

## 청구지 주소 기능을 쓰면 좋은 점

스토어 운영자가 이 기능을 켜면 좋은 이유예요.

- 규정 준수나 인보이스 발행에 필요한 청구 정보를 배송 정보와 따로 받을 수 있어요.
- 주문 데이터가 더 명확하고 정확해져요.
- **연락처** 탭에 주소가 두 개(배송지, 청구지)로 저장되어 고객 기록을 더 잘 관리할 수 있어요.
- CAS와 포장 명세서에 청구지 주소가 표시되어 주문 후 처리가 간편해져요.
- 안내 문구를 스토어 분위기와 고객이 쓰는 말에 맞게 바꿀 수 있어요.
- 서브 계정(로케이션)별로 기능을 켜거나 끌 수 있어서 스토어마다 필요에 맞게 쓸 수 있어요.

## 청구지 주소 기능 켜기

청구지 주소 기능을 켜고 결제 과정을 설정하는 방법이에요.

1. **Store Builder**(스토어 빌더)를 열고 **결제 페이지**로 이동하세요.
2. **Checkout Element**(결제 요소)를 클릭해 설정을 여세요.
3. 아래로 스크롤해서 **고급 설정** 섹션의 **Form Options**(폼 옵션)를 찾으세요.
4. **Enable Billing Address**(청구지 주소 활성화) 토글을 켜세요.
5. **General**(일반) 섹션으로 이동해 다음 문구를 원하는 대로 바꾸세요.

   - **Billing Address Headline Text**(청구지 주소 제목 텍스트): 예) “결제 정보”
   - **Billing Address Checkbox Text**(청구지 주소 체크박스 텍스트): 예) “배송 주소와 동일”
6. **저장**을 클릭한 뒤 **게시**를 클릭해 변경 사항을 반영하세요.

## 결제 페이지 구성 변경

청구지 주소가 새 결제 페이지 레이아웃에서 어디에 들어가는지 알아 두면 고객 경험을 계획하기 쉬워요.

기능을 켜면 결제 폼은 다음 순서로 구성돼요.

1. **연락처 세부정보**
2. **Shipping Details**(배송 정보)
3. **Billing Details**(청구 정보) (새 섹션)
4. **Notes**(메모)
5. **Shipping Options**(배송 옵션)
6. **결제 방법**

고객 화면에는 “배송 주소와 동일” 체크박스가 나타나고, 기본으로 선택되어 있어요. 그래서 청구지 주소가 다를 때만 따로 입력하면 돼요.

## 플랫폼에서 청구지 주소가 표시되는 곳

고객이 주문을 제출하면 청구지 주소가 플랫폼 여러 곳에 표시돼요.

- **주문 상세** 페이지: **Customer Info**(고객 정보) 섹션에 배송 주소와 따로 청구지 주소가 표시돼요.
- **Customer Access Center**(CAS): 고객의 **주문 상세** 화면에 청구지 주소가 포함돼요.
- **연락처**: 이커머스 스토어 연락처 레코드에 배송 주소와 청구지 주소가 모두 저장돼요.
- 포장 명세서 및 감사 페이지: 주문 처리와 고객 확인을 위해 두 주소가 모두 표시돼요.
- 주문 확인 이메일: 청구지 주소가 입력되어 있으면 자동으로 포함돼요.

## 중요 사항

청구지 주소 기능을 켜거나 관리할 때 꼭 알아 둘 내용이에요.

- 새 스토어: 스토어를 만들 때 청구지 주소가 기본으로 켜져 있어요. 관련 커스텀 필드도 자동으로 만들어져요.
- 기존 스토어: 청구지 주소가 기본으로 꺼져 있어서 직접 켜야 해요.
- 기능을 켜면 커스텀 필드는 다음과 같이 처리돼요.

  - 자동으로 만들어져요.
  - 삭제하거나 편집할 수 없어요.
  - 고유 키가 지정돼요. 같은 키가 이미 있으면 그 키를 다시 사용해요.
- 청구지 주소 데이터는 고객이 결제할 때 해당 필드를 입력한 경우에만 시스템에 표시돼요.
- 청구지 주소는 현재 세금 계산에 쓰이지 않아요. 세금은 계속 배송 주소를 기준으로 계산돼요.

## 자주 묻는 질문

### 스토어에서 청구지 주소를 받고 싶지 않으면 어떻게 하나요?
결제 설정 패널에서 **Enable Billing Address**(청구지 주소 활성화) 토글을 꺼 두면 돼요.

### 고객이 청구지와 배송지에 같은 주소를 쓸 수 있나요?
네, 쓸 수 있어요. “배송 주소와 동일” 체크박스가 있고 기본으로 선택되어 있어요.

### 내보낸 주문이나 리포트에서도 청구지 주소를 볼 수 있나요?
네, 결제할 때 청구지 주소를 입력했다면 주문 내보내기와 데이터 화면에 반영돼요.

### 청구지 주소 커스텀 필드를 삭제하거나 바꿀 수 있나요?
아니요. 청구지 주소용으로 만들어진 커스텀 필드는 시스템에서 보호되어 있어서 편집하거나 삭제할 수 없어요.

### 청구지 주소가 배송비나 세금에 영향을 주나요?
아니요. 현재는 배송 주소만 배송비와 세금 계산에 쓰여요.
