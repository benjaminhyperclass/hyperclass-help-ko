# 이커머스 스토어의 매장 픽업

매장 픽업을 켜면 고객이 실물 상품 주문을 배송받는 대신 사용 설정된 매장에서 직접 받아 갈 수 있어요. 스토어 운영자는 픽업 주소, 안내 사항, 준비 시간, 요금, 적용 세금을 설정할 수 있어요. 이 문서에서는 픽업 장소를 설정하는 방법, 매장 픽업이 결제 화면을 어떻게 바꾸는지, 픽업 요금과 세금 처리, 주문 후 픽업 정보를 확인하는 위치를 안내해요.

## 매장 픽업이란?

매장 픽업은 고객이 이커머스 스토어의 실물 상품 주문을 사용 설정된 픽업 장소에서 받아 가는 수령 방식이에요.

픽업 장소마다 주소, 픽업 안내, 준비 시간, 픽업 비용, 적용 세금을 설정할 수 있어요. 사용 설정된 픽업 장소가 여러 곳이면 고객이 결제 중에 원하는 장소를 고를 수 있어요.

고객이 **Pickup in Store**(매장 픽업)를 선택하면 하이퍼클래스는 선택한 픽업 장소를 배송 주소로 사용하고, 결제 화면에서 **Shipping Details**(배송 상세 정보) 섹션을 숨겨요.

## 매장 픽업의 장점

매장 픽업은 실물 상품 주문을 처리하는 또 하나의 방법이에요. 고객이 주문하는 과정 내내 픽업 정보와 결제 정보가 주문에 연결되어 있어요.

- 유연한 수령 방식: 주문을 꼭 배송하지 않아도 고객이 직접 받아 갈 수 있어요.
- 여러 픽업 장소: 사용 설정된 매장 중에서 고객이 장소를 고를 수 있어요.
- 명확한 픽업 안내: 구매 전에 장소 주소, 안내 사항, 준비 시간을 보여 줘요.
- 픽업 요금: 필요하면 장소별로 픽업 비용을 추가할 수 있어요.
- 적용 세금: 설정한 세금이 주문 합계에 더해져요.
- 간단한 결제: 고객이 픽업을 선택하면 배송 상세 정보 입력란이 자동으로 사라져요.
- 연결된 주문 데이터: 지원되는 주문, 거래 내역, 영수증, 고객 주문 화면, 워크플로우에서 픽업 정보를 확인할 수 있어요.

## 사용 조건과 제한 사항

필요한 장소와 수령 방식 설정을 마쳐야만 매장 픽업이 나타나요. 결제 화면을 테스트하기 전에 아래 내용을 확인하세요.

- 픽업 장소를 하나 이상 만들고 사용 설정해야 결제 화면에 매장 픽업이 나타나요.
- 사용 설정된 픽업 장소만 고객에게 보여요.
- 픽업 장소마다 올바른 주소가 있어야 해요.
- 선택한 픽업 장소의 주소가 주문의 배송 주소로 사용돼요.
- 매장 픽업은 실물 상품 주문의 수령에만 적용돼요.
- **Pickup in Store**를 선택하면 **Shipping Details** 섹션 전체가 숨겨져요.
- 매장 픽업을 선택해도 **청구지 주소** 섹션은 계속 표시돼요. **Checkout Builder**(체크아웃 빌더) 설정과는 상관없어요.
- 설정한 픽업 요금과 적용 세금은 주문 합계에 더해져요.

## 매장 픽업 설정하기

고객 화면을 테스트하기 전에 픽업 장소를 하나 이상 설정하고 사용 설정하세요. 장소 정보를 정확하게 입력해야 고객이 결제할 때 올바른 픽업 안내, 요금, 세금 정보를 볼 수 있어요.

1. 서브 계정 화면에서 **결제**를 선택하세요.
2. **설정**을 선택하세요.
3. **배송**을 여세요.
4. **Pickup & Store**(픽업 및 스토어)를 선택하세요.
5. 픽업 장소를 만드세요.
6. 올바른 픽업 주소를 입력하세요.
7. 고객이 주문을 받으러 올 때 따라야 할 픽업 안내를 입력하세요.
8. 준비 시간을 설정하세요.
9. 요금을 받아야 하면 픽업 비용을 입력하세요.
10. 적용할 픽업 세금을 설정하세요.
11. 픽업 장소를 사용 설정하세요.
12. 픽업 장소 설정을 저장하거나 완료하세요.

![매장 픽업 설정 화면의 픽업 장소 구성](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930315/original/T_HX8TinfLt67gmYJp0579mtGAsXOT-PSA.png?1790463083)

설정을 마친 뒤에는 이커머스 스토어의 결제 화면을 미리 보고 **Pickup in Store**가 나타나는지 확인하세요. 사용 설정된 픽업 장소가 하나도 없으면 매장 픽업이 나타나지 않아요.

## 결제 화면에서 매장 픽업이 동작하는 방식

사용 설정된 픽업 장소가 있으면 고객은 수령 방식으로 픽업을 고를 수 있어요. 고객은 장소 정보와 최종 주문 합계를 확인한 뒤 결제를 마쳐요.

1. 고객이 실물 상품을 담고 결제 화면으로 이동해요.
2. 두 가지 수령 방식을 모두 쓸 수 있으면 고객이 **Ship**(배송)과 **Pickup in Store** 중에서 선택해요.
3. 고객이 **Pickup in Store**를 선택해요.
4. **Shipping Details** 섹션이 숨겨져요.
5. 고객이 사용할 수 있는 픽업 장소를 선택해요.
6. 픽업 주소, 준비 시간, 안내 사항, 적용되는 요금이 표시돼요.
7. **청구지 주소**는 계속 표시돼요.
8. 선택한 픽업 장소가 주문의 배송 주소가 돼요.
9. 고객이 최종 합계를 확인하고 구매를 완료해요.

![매장 픽업이 수령 방식으로 선택된 이커머스 결제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930353/original/yEMgWLnhoAjKnH47QzvCOS7qQFpndBwEjQ.png?1790463177)

### 픽업 요금과 세금

픽업 요금과 적용 세금은 주문 합계에 포함돼요. 그래서 고객은 주문하기 전에 전체 비용을 볼 수 있어요.

- 설정한 픽업 요금은 상품 소계에 더해져요.
- 적용되는 픽업 세금은 설정한 세금 설정에 따라 더해져요.
- 픽업 요금과 세금은 결제 중에 표시돼요.
- 이 금액은 구매 후에도 지원되는 주문 요약과 영수증 화면에서 확인할 수 있어요.

## 주문 후 픽업 상세 정보

결제가 끝난 뒤에도 픽업 정보는 주문에 연결되어 있어요. 스토어 운영자와 고객은 선택한 장소, 요금, 세금, 수령 정보를 이곳에서 다시 확인할 수 있어요.

- **주문 상세**: **결제 > 주문**에서 선택한 픽업 장소, 주소, 픽업 요금, 적용 세금을 볼 수 있어요.
- **거래 내역**: 지원되는 거래 상세 정보에 매장 픽업 정보가 남아 있어요.
- **Customer Access Center**(고객 액세스 센터): 고객이 주문 상세 정보와 함께 지원되는 픽업 정보를 확인할 수 있어요.
- **영수증**: 지원되는 영수증 화면과 내려받는 영수증에 픽업 정보, 요금, 적용 세금이 들어가요.
- **워크플로우**: 지원되는 워크플로우에서는 픽업 정보를 커스텀 값으로 쓸 수 있어요.

![구매 후 매장 픽업 정보가 표시된 주문 상세 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930368/original/XTOSXK9j1yEkmTooLkXVNeb7mVjV-_llQg.png?1790463317)

### 매장 픽업과 업셀

업셀 구매에는 추가하는 상품 유형에 맞는 주소가 사용돼요. 그래서 수령 정보가 구매 내용과 일치해요.

- **실물 상품** 업셀: 선택한 픽업 주소가 그대로 이어져요.
- **디지털 상품** 업셀: 청구지 주소가 사용돼요.

## 자주 묻는 질문

### 결제 화면에 매장 픽업이 나타나지 않아요.
픽업 장소를 하나 이상 만들고 사용 설정해야 해요. 사용 설정하지 않은 장소는 고객에게 보이지 않아요.

### 고객이 원하는 픽업 장소를 고를 수 있나요?
네. 고객은 결제 중에 선택할 수 있는, 사용 설정된 픽업 장소 중에서 고를 수 있어요.

### 픽업 주문이면 고객이 배송 상세 정보를 입력해야 하나요?
아니요. **Pickup in Store**를 선택하면 **Shipping Details**가 숨겨지고, 선택한 픽업 장소가 배송 주소로 사용돼요.

### 매장 픽업을 선택했는데 청구지 주소가 계속 보이는 이유가 뭔가요?
매장 픽업 주문에는 **Checkout Builder** 설정과 상관없이 **청구지 주소**가 항상 표시돼요.

### 매장 픽업에 요금을 받을 수 있나요?
네. 픽업 장소마다 픽업 비용과 적용 세금을 설정할 수 있어요.

### 결제 후에 픽업 정보는 어디에서 볼 수 있나요?
지원되는 **주문 상세**, **거래 내역**, **Customer Access Center** 주문 화면, **영수증**, 워크플로우의 커스텀 값에서 픽업 정보를 확인할 수 있어요.
