# 하이퍼클래스에서 Printful 연동 사용하기

Printful 계정을 하이퍼클래스에 연결하면 주문형 인쇄(print-on-demand) 상품을 내 스토어에서 바로 판매하고, 주문 처리까지 자동으로 맡길 수 있어요. 이 문서에서는 Printful 앱 설치, 상품 동기화, 주문 처리 방식까지 차례대로 안내해요.

이 문서에서 다루는 내용은 다음과 같아요.

- Printful 앱 설치
- 상품 템플릿 가져오기
- 옵션(variant)과 가격 관리
- 고객 데이터와 주문 동기화

## Printful 연동이란?

Printful 연동을 쓰면 Printful의 주문형 인쇄 계정을 하이퍼클래스의 이커머스 기능과 연결할 수 있어요. Printful은 직접 만든 디자인이나 로고가 들어간 의류, 액세서리 등을 인쇄하고 배송까지 처리해 주는 드롭쉬핑 업체예요.

이 연동을 쓰면 재고 관리, 주문 처리, 배송을 직접 챙기지 않고도 하이퍼클래스 웹사이트나 퍼널에서 Printful 상품을 판매할 수 있어요. 고객이 하이퍼클래스 스토어에서 상품을 구매하면 주문이 자동으로 Printful에 전달되어 처리돼요.

이 연동은 하이퍼클래스의 **연동** 메뉴에서 사용할 수 있어요. **하이퍼클래스 마켓플레이스**에서도 찾을 수 있고, 거기서 외부 개발자나 민간 기업이 만든 앱도 둘러볼 수 있어요.

## Printful 연동의 주요 장점

- 상품 자동 동기화: Printful에서 만들거나 가져온 상품이 제목, 이미지, 옵션, 가격 그대로 하이퍼클래스 스토어에 나타나요.
- 주문 처리 연동: 고객이 하이퍼클래스 스토어에서 상품을 구매하면 주문이 Printful로 바로 전달되고, Printful 구독 설정에 따라 자동으로 처리돼요.
- 고객 데이터 연동: 배송 주소, 이메일 알림, 고객 정보가 하이퍼클래스 CRM으로 들어와서 한 곳에서 관리할 수 있어요.
- 기존 상품 템플릿 활용: 기존 Printful 스토어의 상품 템플릿을 가져오면 디자인이나 옵션을 처음부터 다시 만들지 않아도 돼요.
- 워크플로우 자동화 지원: 주문이 접수되면 워크플로우를 실행해서 리뷰 요청, 배송 안내, 팀 알림 등을 보낼 수 있어요.
- 기회 파이프라인 연동: "주문 접수", "주문 처리 완료" 같은 단계가 있는 맞춤 파이프라인으로 주문 진행 상황을 추적하고, 팀과 함께 후속 조치를 챙길 수 있어요.

## Printful 연동 설치하기

Printful 계정을 하이퍼클래스 서브 계정에 연결하는 방법이에요.

1. 하이퍼클래스 서브 계정에서 **설정 > 연동**으로 이동해요.
2. 아래로 스크롤하거나 검색해서 **Printful**을 찾아요.

   ![연동 목록에서 Printful 찾기](https://jumpshare.com/share/CdBw3F193rGaKC6WBtvg+/GIF+Recording+2026-08-03+at+19.46.21.gif)

3. **관리**를 클릭한 뒤 **설치**를 클릭해요.
4. 앱이 서브 계정에 요청하는 권한을 확인하고 **Allow and Install**(허용 및 설치)을 클릭해요.

   ![앱 권한 확인 후 설치하기](https://jumpshare.com/share/PEdTmeGn8gxCWsy20e3Q+/GIF+Recording+2026-08-03+at+19.47.18.gif)

5. printful.com으로 이동하면 Printful 계정에 **로그인**해요. 계정이 없으면 새 계정을 만들어요.

   ![Printful 로그인 또는 가입 화면](https://jumpshare.com/share/KnC6xST4tR4XbchKKPAl+/Screen+Shot+2026-08-03+at+19.52.45.png)

6. 새 Printful 스토어를 만들지, 기존 스토어를 연결할지 선택한 다음 **수락**을 클릭해요.

   ![Printful 스토어 만들기 또는 연결하기](https://jumpshare.com/share/OUKUXllswSr6SoTf5Kf4+/Screen+Shot+2026-08-03+at+19.57.41.png)

이제 하이퍼클래스 계정이 Printful에 접근할 수 있어요. Printful에는 **기본 제공 서비스**라는 이름의 새 스토어가 만들어져요.

## 하이퍼클래스 스토어에 상품 추가하기

연동이 활성화되면 Printful 상품을 추가해서 하이퍼클래스 상품 목록에 자동으로 동기화할 수 있어요.

1. Printful 왼쪽 사이드바에서 **스토어**로 이동해요. 새로 만들어진 **기본 제공 서비스** 스토어가 보여요.
2. 하이퍼클래스 연동용 스토어에서 점 세 개 아이콘을 클릭하고 **상품 보기**를 클릭해요.

   ![Printful에서 기본 제공 서비스 스토어의 상품 보기](https://jumpshare.com/share/QWlYQTmPAHCtkE02k45w+/GIF+Recording+2026-08-03+at+20.03.36.gif)

3. **상품 추가**를 클릭한 뒤 **Create New Products**(새 상품 만들기)를 선택해요. Printful 카탈로그에 있는 의류, 액세서리, 생활용품 등으로 상품을 처음부터 디자인할 수 있어요.

   ![새 상품 만들기 선택](https://jumpshare.com/share/P5XeRZ3sgFJ0zf6XHVQb+/GIF+Recording+2026-08-03+at+20.07.52.gif)

4. 상품이나 템플릿을 선택한 뒤 Printful의 상품 설정 과정을 따라가요. 목업 이미지를 만들고 옵션(사이즈, 색상 등)을 설정해요.
5. 설정이 끝나면 **Save Template**(템플릿 저장)을 클릭해요.

   ![목업과 상품 정보 설정 후 템플릿 저장](https://jumpshare.com/share/LtA6mOZ6parC18qc1nIn+/GIF+Recording+2026-08-03+at+20.39.35.gif)

6. 표시할 목업 이미지, 가격, 상품 이름을 정한 뒤 **게시**를 클릭해요.

   ![목업 이미지와 가격을 정하고 상품 게시하기](https://jumpshare.com/share/D2p1OwhuIJtNpNdNp4b8+/GIF+Recording+2026-08-03+at+20.46.04.gif)

{% hint style="info" %}
상품이 Printful과 하이퍼클래스 사이에 동기화되었어요. Printful에서 제목, 가격, 옵션을 바꾸면 하이퍼클래스에도 자동으로 반영돼요.
{% endhint %}

## 상품 동기화와 가격 관리

Printful에 상품을 추가하면 대부분의 정보가 그대로 하이퍼클래스 상품 목록에 나타나요.

### 동기화된 상품 확인하기

하이퍼클래스에서 **결제 > 상품**으로 이동하세요. Printful에서 설정한 이름, 이미지, 옵션, 가격이 그대로 적용된 Printful 상품이 목록에 보여요.

![결제 > 상품에서 동기화된 Printful 상품 확인](https://jumpshare.com/share/W0bgLRrhl0GpBii9NVWL+/GIF+Recording+2026-08-03+at+21.06.10.gif)

### 하이퍼클래스에서 상품 수정하기

1. 수정할 상품 옆의 점 세 개 아이콘을 클릭하고 **편집**을 선택해요.
2. 다른 하이퍼클래스 상품처럼 상세 정보를 수정해요. 상품 설명은 현재 Printful에서 동기화되지 않으니 하이퍼클래스에서 직접 입력해야 해요.
3. 하이퍼클래스 이커머스 사이트에 상품을 보이려면 상품 설정에서 **Include in Online Store**(온라인 스토어에 포함)를 켜요. 이렇게 하면 상품이 실제 스토어 화면에 나타나요.

![상품 설정에서 온라인 스토어 포함 켜기](https://jumpshare.com/share/O1ElAPIg2ZXKsEXt1W4g+/GIF+Recording+2026-08-03+at+21.12.35.gif)

{% hint style="warning" %}
상품 설명은 Printful에서 동기화되지 않아요. 스토어에 게시하기 전에 하이퍼클래스 상품 편집 화면에서 설명을 직접 입력해야 해요.
{% endhint %}

Printful에서 하이퍼클래스로 자동 동기화되는 상품 데이터는 다음과 같아요.

- 상품 제목
- 상품 이미지와 목업
- 옵션(사이즈, 색상 등)
- 옵션별 가격

{% hint style="info" %}
재고 없이 맞춤 상품을 판매하세요. Printful 연동이 제작, 배송, 주문 처리를 맡아 주니 마케팅과 고객 관계에 집중할 수 있어요.
{% endhint %}

## 주문 처리와 고객 데이터 동기화

이 연동의 가장 큰 장점은 주문 처리와 고객 데이터 동기화가 자동으로 이루어진다는 점이에요.

### 주문 자동 동기화

고객이 하이퍼클래스 스토어에서 Printful 상품을 구매하면 주문이 Printful 계정으로 자동 전달돼요. Printful 구독 설정에 따라 주문이 자동으로 처리되기도 하고, 제작을 시작하기 전에 직접 승인해야 할 수도 있어요.

### 고객 데이터 가져오기

배송 주소, 이메일 주소 같은 고객 정보가 하이퍼클래스 CRM으로 들어와요. 덕분에 하이퍼클래스 안에서 고객 관계를 관리하고, 후속 안내를 보내고, 주문 내역을 확인할 수 있어요.

### Printful에서 주문 확인하기

동기화된 모든 주문은 Printful 대시보드의 **기본 제공 서비스** 스토어 아래에 나타나요. Printful에서 주문 상세 정보, 처리 상태, 배송 추적 정보를 볼 수 있어요.

{% hint style="info" %}
Printful 구독 플랜을 확인해서 주문이 자동으로 처리되는지, 수동 확인이 필요한지 알아 두세요. 그래야 품질과 진행 시점을 직접 관리할 수 있어요.
{% endhint %}

## 배송 프로필과 결제 시 실시간 배송비

Printful 상품에 결제 시 실시간 배송비를 적용하기 위해, 시스템이 Printful 전용 배송 프로필을 자동으로 관리해요.

알아 둘 내용은 다음과 같아요.

- 시스템이 Printful 배송 프로필을 자동으로 만들고 설정해요.
- 기존에 설치한 계정은 Printful 상품을 동기화하거나 업데이트하면 배송 프로필이 활성화되어 결제 시 실시간 배송비가 표시되기 시작할 수 있어요.
- 상품은 Printful 배송 프로필에 계속 지정되어 있어야 해요. 지정에서 빼면 해당 상품의 실시간 배송비 계산이 꺼져요.
- Printful 배송 프로필을 삭제하면 자동으로 다시 만들어지지 않아요. 복원하려면 Printful 연동을 다시 설치하세요.

![Printful 배송 프로필 화면](https://jumpshare.com/share/VrBbN5UhtUgZMm1SR90g+/Screen+Shot+2026-08-03+at+21.15.35.png)

{% hint style="info" %}
실시간 배송비는 고객 위치와 상품 사양에 따라 계산돼요. 결제 금액이 정확하게 나오도록 Printful 상품이 올바른 배송 프로필에 계속 지정되어 있는지 확인하세요.
{% endhint %}

## 자주 묻는 질문

### Printful 연동을 쓰려면 기존 Printful 계정이 꼭 있어야 하나요?

네, Printful 계정이 필요해요. 계정이 없다면 하이퍼클래스에서 연동을 설치하기 전에 printful.com에서 무료 계정을 만들 수 있어요.

### 하나의 하이퍼클래스 계정에서 여러 Printful 스토어의 상품을 쓸 수 있나요?

이 연동은 Printful에 **기본 제공 서비스**라는 전용 스토어를 만들고, 이 스토어를 하이퍼클래스 서브 계정과 동기화해요. 다른 Printful 스토어의 템플릿은 가져올 수 있지만, 실제 동기화는 **기본 제공 서비스** 스토어와 하이퍼클래스 사이에서만 이루어져요.

### Printful에서 하이퍼클래스로 어떤 상품 정보가 동기화되나요?

상품 제목, 이미지, 옵션(사이즈, 색상), 가격이 자동으로 동기화돼요. 상품 설명은 동기화되지 않으니 하이퍼클래스 상품 편집 화면에서 직접 입력해야 해요.

### Printful이 주문을 자동으로 처리해 주나요?

Printful 구독과 계정 설정에 따라 달라요. 자동 처리를 지원하는 플랜도 있고, 제작을 시작하기 전에 수동 승인이 필요한 플랜도 있어요. Printful 설정에서 주문 처리 방식을 확인하세요.

### 하이퍼클래스로 동기화된 뒤에도 상품 정보를 수정할 수 있나요?

네, 하이퍼클래스에서 다른 상품처럼 수정할 수 있어요. 다만 Printful에서 바꾼 내용(제목, 가격, 옵션)이 하이퍼클래스로 다시 동기화되면서 수정한 내용을 덮어쓸 수 있어요. 제목과 가격은 Printful에서 관리하고, 설명과 스토어별 설정은 하이퍼클래스에서 관리하는 것이 좋아요.
