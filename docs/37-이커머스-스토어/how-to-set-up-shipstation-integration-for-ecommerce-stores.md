# 이커머스 스토어에 ShipStation 연동 설정하기

하이퍼클래스 이커머스 스토어에 ShipStation 연동을 설치하고 설정하는 방법을 안내해요. 이 연동을 쓰면 주문이 ShipStation으로 자동 동기화되고, 결제 페이지에서 실시간 배송사 요금을 보여 주고, 스토어에서 바로 배송 라벨을 만들 수 있어요.

## ShipStation 연동이란?

ShipStation 연동은 스토어와 ShipStation을 이어 주는 다리 역할을 해요. 스토어에 들어온 새 주문이 ShipStation으로 자동 동기화돼요. ShipStation에서는 배송 라벨을 만들고, 실시간 배송사 요금을 비교하고, 모든 배송을 한 대시보드에서 관리할 수 있어요.

50개 이상의 배송사를 이용할 수 있어서 고객에게 결제 페이지에서 정확한 배송 옵션을 보여 줄 수 있어요. 자동 동기화로 오류가 줄고, 주문 처리도 한곳에서 관리할 수 있어요. ShipStation은 스토어 브랜드로 된 배송 추적 알림도 고객에게 보내 줘요. 그래서 결제부터 배송 완료까지 고객 경험이 매끄럽게 이어져요.

## ShipStation 연동의 주요 장점

- 자동 동기화: 스토어에서 접수된 주문이 ShipStation으로 자동 동기화돼요.
- 실시간 배송사 요금: 고객이 결제 페이지에서 설정한 배송사의 실시간 배송 옵션을 볼 수 있어요.
- 할인된 배송비: ShipStation에서 제공하는 배송사의 할인 요금을 이용할 수 있어요.
- 한곳에서 주문 처리: 한 대시보드에서 배송을 관리하고, 라벨을 만들고, 주문을 추적할 수 있어요.
- 브랜드 알림: 배송 추적 정보가 스토어 브랜드로 된 안내를 통해 고객에게 자동으로 전달돼요.

## 자동 주문 처리

주문을 자동으로 동기화하고 배송 상태를 알아서 업데이트해 주기 때문에 수작업이 줄어요. 그만큼 사업을 키우는 일에 집중하면서도 모든 주문을 정확하게 처리할 수 있어요.

- 여러 플랫폼 사이에서 주문이 자동으로 동기화돼요.
- 배송 상태가 자동으로 업데이트돼서 나와 고객 모두 진행 상황을 알 수 있어요.
- 수작업으로 생기는 실수가 줄어 운영 효율이 높아져요.

## 실시간 배송사 요금

결제 페이지에서 고객에게 실시간 배송 정보를 바로 보여 줘요. 50개가 넘는 배송사의 최신 요금을 가져오기 때문에, 고객은 배송비를 투명하게 확인하고 판단할 수 있어요.

- 최신 배송 요금을 확인할 수 있어요.
- 50개 이상의 배송사 가격을 실시간으로 비교할 수 있어요.
- 정확한 배송비를 안내해서 고객 신뢰를 높일 수 있어요.

## 할인된 배송비

ShipStation이 미리 협상해 둔 할인 요금을 이용하거나, 내 배송사 계정을 직접 연결해서 비용을 아낄 수 있어요. 경쟁력 있는 가격으로 스토어의 매력도 높일 수 있어요.

- 미리 협상된 배송 할인을 이용할 수 있어요.
- 내 배송사 계정을 직접 연동할 수도 있어요.
- 전체 배송 비용이 줄어 마진이 좋아져요.

## ShipStation 연동 설정 방법

설정은 어렵지 않아요. 결제 페이지에 실시간 배송 요금이 나타나도록 아래 순서대로 진행하세요.

### 1단계: ShipStation Integration 설치

1. 서브 계정에서 **앱 마켓플레이스** 또는 **설정 > 연동**으로 이동하세요.
2. **ShipStation Integration**을 검색하세요.
3. **앱 보기** → **설치**를 클릭하세요.
4. **허용 및 설치** 버튼을 클릭해 설치를 마무리하세요.

![ShipStation Integration 설치 과정 화면 녹화](https://jumpshare.com/share/U3RKvLKV5Je6kzqTbWNj+/GIF+Recording+2025-08-28+at+9.09.18+PM.gif)

### 2단계: ShipStation 계정 연결

1. 하이퍼클래스 안에서 **ShipStation** 앱을 여세요.
2. **설정** 탭으로 이동하세요.
3. **ShipStation Live API Key**(ShipStation 라이브 API 키)와 **API Secret**(API 시크릿)을 입력하세요.

   - 이 값은 ShipStation 계정의 **Settings > Account > API Settings**(설정 > 계정 > API 설정)에서 만들 수 있어요.
4. **연결**을 클릭하세요.

{% hint style="warning" %}
라이브 토큰만 사용하세요. 테스트 토큰은 지원되지 않아요.
{% endhint %}

![ShipStation 계정 연결 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052179819/original/AUL3lNcMP-LS5KmMCv_l9-UbhGBJCg_-Vw.jpeg?1755872179)

### 3단계: 설정 체크리스트 완료

연동을 마무리하기 전에 ShipStation에서 먼저 설정해 둘 항목이 있어요. 그래야 요금 계산과 주문 처리가 제대로 동작해요.

1. 발송지(**Ship From** 위치)를 하나 이상 만드세요.

   - ShipStation에서 **Settings > Shipping > Ship From Locations**(설정 > 배송 > 발송지 위치)로 이동하세요.
2. 사용 중인 모든 배송사에서 패키지 옵션을 켜세요.

   - ShipStation에서 **Settings > Shipping > Packages**(설정 > 배송 > 패키지)로 이동하세요.
3. ShipStation 계정의 통화가 하이퍼클래스 스토어의 통화와 같은지 확인하세요.
4. 모두 마쳤으면 연동 설정 화면에서 체크박스를 선택하고 **연결**을 클릭하세요.

![설정 체크리스트 화면](https://jumpshare.com/share/dQDsMwUv5XRYLJ3WN2Gb+/image+%283%29.png)

### 4단계: 배송 옵션 추가

배송 옵션은 고객이 결제 페이지에서 보게 될 내용을 정해요. 실시간 배송 서비스와 대체 요금을 함께 설정해 두면 배송 요금이 항상 표시돼요.

1. **+ Add Shipping Option**(배송 옵션 추가)을 클릭하세요.

   ![배송 옵션 추가 버튼](https://jumpshare.com/share/ycA3yx8kMuOiEkGmTPoI+/image+%285%29.png)
2. **Shipping Option Name**(배송 옵션 이름)을 입력하세요. 이 이름이 결제 페이지에 표시돼요.
3. 배송 서비스를 하나 이상 선택하세요(예: USPS Priority Mail, UPS Ground, FedEx 2Day).
4. **Fallback Value**(대체 값)를 설정하세요. 실시간 요금을 사용할 수 없을 때 적용되는 고정 요금이에요.

   ![배송 옵션 이름과 배송 서비스, 대체 값 입력 화면](https://jumpshare.com/share/DrnLXqpcRvvb1U98AoLS+/image+%284%29.png)
5. **만들기**를 클릭하세요.

   ![배송 옵션 만들기 화면](https://jumpshare.com/share/cGXWzsYZisar99qJ9yDg+/image+%286%29.png)

### 5단계: 결제 과정 테스트

실제로 운영하기 전에 테스트해 보면 고객에게 올바른 배송 옵션과 대체 요금이 보이는지 확인할 수 있어요.

1. 이커머스 스토어에서 상품을 장바구니에 담으세요.
2. **결제 페이지**로 이동하세요.
3. **배송** 단계를 확인하세요.

   - ShipStation에서 가져온 실시간 요금이 표시돼요.
   - 실시간 요금을 사용할 수 없으면 대체 요금이 적용돼요.

![결제 페이지의 배송 단계 화면](https://jumpshare.com/share/3orn2NeaWOaVnFAqJuWD+/image+%287%29.png)

### 6단계: 주문 처리와 배송 추적

연동이 끝나면 ShipStation이 주문 처리, 라벨, 배송 추적을 관리하는 중심이 돼요.

- 주문이 **ShipStation Dashboard**(ShipStation 대시보드)로 자동 동기화돼요.
- ShipStation 안에서 라벨을 만들어 인쇄하고, 주문을 배송 완료로 표시하고, 주문 처리를 관리할 수 있어요.
- 운송장 번호가 하이퍼클래스로 다시 동기화되고, 고객에게 자동으로 전달돼요.

![ShipStation 대시보드의 주문 처리 화면](https://jumpshare.com/share/eAEdSub4tWIqcJJP3xgk+/image+%288%29.png)

## 자주 묻는 질문

### 결제 페이지에 실시간 요금이 표시되지 않아요.

고객이 올바른 배송 주소를 입력했는지, 그리고 ShipStation 계정에서 배송사가 활성 상태인지 확인하세요.

### 결제할 때 실시간 요금을 사용할 수 없으면 어떻게 되나요?

설정할 때 입력해 둔 대체 고정 요금이 자동으로 적용돼요.

### 스토어와 ShipStation의 통화가 다르면 어떻게 되나요?

스토어 통화와 ShipStation 계정 통화가 같아야 요금이 제대로 계산돼요. 필요하면 두 곳의 설정을 모두 업데이트하세요.

### 설정할 때 테스트 API 토큰을 써도 되나요?

아니요. 이 연동은 유효한 라이브 API 토큰이 있어야 하며, 테스트 토큰은 작동하지 않아요.

### ShipStation 연동으로 몇 개의 배송사를 이용할 수 있나요?

50개 이상의 배송사에서 실시간 배송 요금을 비교할 수 있어요.

### ShipStation 계정에는 어떤 항목을 설정해 두어야 하나요?

ShipStation에서 배송사 계정, 발송인·수신인 정보, 배송 규칙이 모두 올바르게 설정되어 있어야 해요.

### 주문이 자동으로 동기화되나요?

네. 주문이 자동으로 동기화되고, 배송 상태도 플랫폼 사이에서 업데이트돼요.

### 운송장 번호는 고객에게 어떻게 전달되나요?

ShipStation에서 주문을 배송 완료로 표시하면 운송장 정보가 하이퍼클래스로 다시 동기화돼요. 그러면 스토어 브랜드로 된 알림으로 고객에게 전달돼요.

### 배송 옵션을 여러 단계로 만들 수 있나요?

네. 배송 서비스를 다르게 선택해서 표준, 특급, 우선 배송 같은 여러 옵션을 만들 수 있어요.
