# 이커머스 스토어 상품 위시리스트 사용하기

로그인한 고객이 마음에 드는 상품을 저장해 두고, 전용 위시리스트에서 다시 확인하고 관리할 수 있게 해 주는 기능이에요. 이 문서에서는 설정 방법, 고객이 보는 화면, 문제 해결 방법을 안내해요.

## 이 문서에서 알아볼 내용

하이퍼클래스 이커머스 스토어의 상품 위시리스트를 쓰면, 로그인한 고객이 스토어 화면에서 상품을 저장해 두었다가 **Customer Access Center**(고객 액세스 센터)에서 다시 찾아볼 수 있어요. 스토어 운영자는 지원되는 상품 요소에서 위시리스트를 켜고, 위시리스트 버튼의 모양을 바꾸고, 고객 메뉴에 위시리스트 항목을 추가할 수 있어요.

제대로 쓰려면 **Customer Login**(고객 로그인)과 연결된 스토어 도메인이 필요해요. 이 문서에서는 스토어 화면과 **Customer Access Center**에서 어떻게 동작하는지, 설정 단계, 문제 해결 방법, 고객이 상품을 저장하고 관리하는 위치를 다뤄요.

스토어를 처음 만든다면 [이커머스 온라인 스토어 설정하기](E-Commerce-Store/how-to-set-up-an-e-commerce-online-store-websites.md)를, 상품을 만들고 판매하는 방법은 [시작하기 - 상품 만들고 판매하기](../01-시작하기/커머스/getting-started-create-sell-products.md)를 먼저 참고하세요.

{% hint style="warning" %}
중요: 고객은 로그인해야 위시리스트를 쓸 수 있어요. 또 유효한 스토어 도메인이 연결되어 있고, 그 도메인의 기본 페이지가 스토어에 연결되어 있어야 **Customer Login**과 위시리스트 접근이 제대로 작동해요. 도메인 설정은 [루트 도메인 또는 서브도메인 설정하기](../06-사이트/트러블슈팅/how-to-set-up-root-domain-subdomain-for-funnels-websites.md)를 참고하세요.
{% endhint %}

## 이커머스 스토어의 위시리스트란?

위시리스트는 로그인한 고객이 관심 있는 상품을 장바구니에 담지 않고 저장해 두는 기능이에요. 저장한 상품은 **Customer Access Center**와 연결된 전용 위시리스트 페이지에서 확인할 수 있어요.

스토어 운영자는 지원되는 스토어 요소에서 위시리스트 버튼을 켜고 모양을 바꿀 수 있어요. 고객은 쇼핑 흐름이 끊기지 않으면서도 상품을 기억해 두었다가 나중에 다시 찾을 수 있어요.

### 위시리스트의 장점

위시리스트를 쓰면 고객은 둘러보는 동안 마음에 드는 상품을 가볍게 저장해 둘 수 있어요. 스토어 운영자 입장에서는 고객이 바로 장바구니에 담지 않아도 되는 편의 기능을 더하는 셈이에요.

- 나중에 볼 상품 저장: 고객이 다시 보고 싶은 상품을 장바구니에 담지 않고 보관할 수 있어요.
- 더 쉬운 상품 찾기: 저장한 상품이 전용 위시리스트에 정리되어 있어서 다시 찾을 필요가 없어요.
- 고객별 맞춤 경험: 위시리스트는 **Customer Access Center**에 로그인한 고객별로 연결돼요.
- 여러 곳에서 저장 가능: **Product List**(상품 목록), **상품 상세정보**, **Featured Product**(추천 상품) 요소에서 위시리스트를 켤 수 있어요.
- 모양 변경 가능: 활성 상태 위시리스트 아이콘 색상과 위시리스트 버튼 배경 색상을 바꿀 수 있어요.
- 편리한 이동: 로그인한 고객용 메뉴에 **My Wishlist**(내 위시리스트)를 추가하면 저장한 상품으로 쉽게 이동할 수 있어요.

## 스토어에서 위시리스트가 보이는 곳

지원되는 상품 요소가 표시되는 곳이면 어디든 위시리스트 버튼이 나타날 수 있어요. **Store Builder**(스토어 빌더)에서 해당 요소의 위시리스트를 켜면, 고객이 상품을 둘러보거나 개별 상품을 살펴보는 중에 바로 저장할 수 있어요.

| 스토어 요소 | 위시리스트 사용 방식 |
| --- | --- |
| **Product List** | 고객이 상품 목록을 둘러볼 때, 지원되는 상품 카드에 위시리스트 버튼이 표시돼요. |
| **상품 상세정보** | 고객이 상품 상세정보 페이지에서 바로 상품을 저장할 수 있어요. |
| **Featured Product** | **Featured Product** 요소로 표시된 상품을 고객이 저장할 수 있어요. |

### Product List에서의 사용

**Product List**에서는 상품 상세정보 페이지를 열지 않고도 빠르게 상품을 저장할 수 있어요. 같은 목록에서 여러 상품을 비교할 때 특히 편해요.

![Product List의 위시리스트 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080659322/original/htXV9LHcbZbBBu0ryhPa4mwbzFmMNkNkXw.png?1789097251)

### 상품 상세정보에서의 사용

상품 상세정보 페이지에서도 구매 정보 옆에 같은 위시리스트 버튼을 표시할 수 있어요. 고객은 상품 정보를 살펴보면서 바로 저장할 수 있어요. 상품 상세정보 페이지를 직접 꾸미려면 [이커머스 스토어 맞춤 상품 상세정보 페이지](../06-사이트/custom-product-details-page-for-e-commerce-stores.md)를 참고하세요.

![상품 상세정보 페이지의 위시리스트 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080659346/original/4xk0sqkOppvC-ko0Gqd6ns_5j_aP2QlB3A.png?1789097326)

## 고객 로그인과 위시리스트 이용

위시리스트는 로그인한 고객을 기준으로 동작해서, 저장한 상품이 해당 고객에게 연결돼요. 그래서 **Customer Login**과 **Customer Access Center**가 위시리스트 사용의 중요한 부분이에요. 로그인 방법은 [이커머스 스토어 고객 로그인](customer-login-for-ecommerce-stores.md)을, **Customer Access Center**에서 주문 내역을 보는 방법은 [Customer Access Center - 현재 및 지난 주문 내역 보기](customer-access-center-to-view-current-and-past-order-details.md)를 참고하세요.

- 고객은 로그인한 뒤에 위시리스트를 쓸 수 있어요.
- 로그인하지 않은 고객이 위시리스트를 쓰려고 하면 **Customer Access Center** 로그인 화면이 나타나요.
- 로그인한 뒤에는 설정해 둔 스토어 내비게이션에서 **My Wishlist**로 들어갈 수 있어요.
- 전용 위시리스트 페이지에는 저장한 상품이 표시되고, 상품을 제거하는 버튼도 있어요.
- **Customer Login**이 제대로 작동하려면 유효한 스토어 도메인이 설정되어 있어야 해요.

### 고객 내비게이션의 위시리스트

고객 메뉴에 **My Wishlist**를 추가하면 게시된 스토어에서 고객이 저장한 상품으로 바로 이동할 수 있어요. 로그인한 고객은 같은 내비게이션 영역에서 주문, 위시리스트, 계정 관련 기능을 오갈 수 있어요.

![고객 내비게이션에 표시된 My Wishlist 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080659334/original/BBOg95W11IbIxTA9TA3OAIG1bi5kPICphg.png?1789097285)

## 이커머스 스토어에 위시리스트 설정하기

상품 요소에서 위시리스트를 켜고 고객 내비게이션에 링크를 추가하면, 고객이 상품을 저장하고 다시 찾아올 수 있어요. 실제 스토어에서 테스트하기 전에 스토어 화면, 로그인, 도메인 설정을 먼저 마쳐 주세요.

### 1단계: Store Builder 열기

고객이 상품을 둘러보고 살펴보는 상품 요소에 위시리스트 버튼을 설정하려면 먼저 수정할 스토어를 열어요.

1. **사이트 > 스토어**로 이동해요.
2. 해당 **이커머스 스토어**를 열어요.
3. **Store Builder**를 열고, 설정할 상품 요소가 있는 **페이지**로 이동해요.

### 2단계: 위시리스트 켜고 꾸미기

위시리스트 설정은 지원되는 상품 요소에서 해요. 고객이 상품을 저장할 수 있게 하려는 곳마다 기능을 켜고, 스토어 디자인에 맞게 색상을 조정하세요.

1. **Product List**, **상품 상세정보**, **Featured Product** 중 하나를 선택해요.
2. **일반 설정**을 열어요.
3. **Wishlist Products**(위시리스트 상품)를 펼쳐요.
4. **Enable wishlist for products**(상품에 위시리스트 사용)를 켜요.
5. **Wishlist Icon Active Color**(위시리스트 아이콘 활성 색상)를 선택해요.
6. **Wishlist Button Background Color**(위시리스트 버튼 배경 색상)를 선택해요.

![위시리스트 활성화와 색상 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080659351/original/5XA93TgDIflYs3cCOrr6NHVCg5EW1OscPQ.png?1789097349)

### 3단계: 고객 내비게이션에 My Wishlist 추가하기

**My Wishlist** 메뉴 항목이 있으면 로그인한 고객이 스토어에서 저장한 상품 목록으로 쉽게 들어갈 수 있어요. 이 메뉴 항목이 **Customer Access Center**의 위시리스트 페이지로 바로 이동하도록 설정해요.

1. 스토어의 **Navigation Menu**(내비게이션 메뉴)를 선택해요.
2. **일반 > Customer Login**을 열어요.
3. **Enable Customer Login**(고객 로그인 활성화)이 꺼져 있으면 켜요.
4. 이름이 **My Wishlist**인 메뉴 항목을 추가하거나 설정해요.
5. **Go To**(이동 위치)를 **Go to Customer Access Center**(Customer Access Center로 이동)로 설정해요.
6. **페이지**를 **Wishlist**(위시리스트)로 설정해요.
7. 메뉴 설정을 제출해요.

![My Wishlist 메뉴 항목 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080659336/original/prqIr49zcfbsfjJd_c1leDrHuxwuEpr8tA.png?1789097301)

### 4단계: 스토어 도메인 확인하기

**Customer Login**은 게시된 스토어의 도메인에 따라 동작해요. 고객 입장에서 위시리스트를 테스트하기 전에 도메인이 연결되어 있는지, 도메인의 기본 페이지가 이커머스 스토어 안의 페이지를 가리키는지 확인하세요.

1. 스토어에 유효하고 인증된 도메인이 연결되어 있는지 확인해요.
2. 도메인의 기본 페이지가 스토어 안의 페이지에 연결되어 있는지 확인해요.
3. 둘 중 하나라도 빠져 있으면 **Customer Login**을 테스트하기 전에 도메인 설정을 고쳐요.

### 5단계: 저장, 게시, 테스트하기

게시된 스토어에서 테스트해 보면 위시리스트 버튼, 로그인, 고객 내비게이션, 저장한 상품 확인이 모두 잘 맞물려 동작하는지 알 수 있어요.

1. **Store Builder**의 변경 내용을 **저장**해요.
2. 업데이트한 스토어를 **게시**해요.
3. 게시된 스토어를 열어요.
4. 로그아웃한 상태에서 위시리스트를 눌러 보고, 로그인 화면이 나타나는지 확인해요.
5. 고객으로 로그인한 뒤 상품을 저장해요.
6. **My Wishlist**를 열어 저장한 상품이 보이는지 확인해요.

## 위시리스트에서 저장한 상품 관리하기

전용 위시리스트 페이지에서는 로그인한 고객이 저장해 둔 상품을 한곳에서 확인할 수 있어요. 고객은 상품 정보를 다시 보러 가거나, 더 이상 보관하고 싶지 않은 상품을 목록에서 뺄 수 있어요.

1. 스토어의 **Customer Login**으로 로그인해요.
2. 설정해 둔 고객 메뉴에서 **My Wishlist**를 열어요.
3. 저장한 상품을 확인해요.
4. 상품으로 돌아가려면 **View Product**(상품 보기)를 선택해요.
5. 제거 버튼을 눌러 위시리스트에서 상품을 삭제해요.

![위시리스트 페이지에서 저장한 상품을 관리하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080659366/original/L98-MS5VQdpVP5rDb2AvsVvF1hXmZccsWw.png?1789097377)

## 위시리스트 문제 해결

위시리스트 문제는 대부분 상품 요소의 켜짐 설정, **Customer Login** 설정, 내비게이션 연결, 게시 여부, 스토어 도메인 설정 중 하나와 관련돼요. 항목을 하나씩 확인하면 고객 흐름에서 빠진 부분을 찾을 수 있어요.

| 문제 | 확인할 내용 |
| --- | --- |
| 위시리스트 버튼이 보이지 않아요 | 해당 **Product List**, **상품 상세정보**, **Featured Product** 요소에서 **Enable wishlist for products**가 켜져 있는지 확인한 뒤, 페이지를 저장하고 게시하세요. |
| 로그아웃한 고객이 상품을 저장할 수 없어요 | 위시리스트는 고객 로그인이 필요해요. **Customer Login**이 켜져 있는지, 로그인 화면이 정상적으로 열리는지 확인하세요. |
| 고객 메뉴에 My Wishlist가 없어요 | **Navigation Menu** 설정을 열어, 메뉴 항목이 **Customer Access Center** > **Wishlist**로 연결되어 있는지 확인하세요. |
| Customer Login 버튼이 작동하지 않아요 | 유효한 도메인이 연결되어 있는지, 도메인의 기본 페이지가 스토어 페이지에 연결되어 있는지 확인하세요. |
| 저장한 상품이 위시리스트에 보이지 않아요 | 고객이 로그인한 상태인지, 상품이 실제로 저장되었는지 확인하고, 위시리스트 페이지를 새로고침한 뒤 다시 테스트하세요. |

## 자주 묻는 질문

### 고객이 위시리스트를 쓰려면 먼저 로그인해야 하나요?

네. 위시리스트는 고객 로그인이 필요해요. 로그아웃한 고객이 위시리스트를 쓰려고 하면 **Customer Access Center** 로그인 화면이 나타나요.

### 어떤 스토어 요소에서 위시리스트를 쓸 수 있나요?

**Product List**, **상품 상세정보**, **Featured Product** 요소에서 위시리스트를 켤 수 있어요.

### 고객이 위시리스트에서 상품을 뺄 수 있나요?

네. 고객은 전용 위시리스트 페이지를 열어 더 이상 저장하고 싶지 않은 상품을 제거할 수 있어요.

### 위시리스트 버튼의 모양을 바꿀 수 있나요?

네. 활성 상태 위시리스트 아이콘 색상과 위시리스트 버튼 배경 색상을 설정할 수 있어요.

### 위시리스트를 쓰려면 왜 스토어 도메인이 필요한가요?

**Customer Login**은 스토어의 실제 도메인을 기반으로 동작해요. 로그인한 고객 화면이 제대로 작동하려면 유효한 도메인이 연결되어 있고, 그 도메인의 기본 페이지가 스토어에 연결되어 있어야 해요.

### 내비게이션 메뉴에 My Wishlist를 꼭 추가해야 하나요?

**My Wishlist**를 추가하면 고객이 스토어 화면에서 전용 위시리스트 페이지로 바로 이동할 수 있어요. **Customer Login**을 켠 경우에는 이렇게 설정하는 것을 권장해요.

### 위시리스트에 상품을 저장하면 장바구니에도 담기나요?

아니요. 위시리스트는 나중에 참고할 상품을 저장해 두는 기능이에요. 구매할 준비가 되면 고객이 상품을 선택하고 일반 구매 절차를 따르면 돼요.
