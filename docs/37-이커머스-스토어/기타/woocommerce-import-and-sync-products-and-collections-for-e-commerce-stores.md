# WooCommerce 상품·컬렉션 가져오기 및 동기화

WooCommerce 스토어의 상품과 컬렉션을 하이퍼클래스로 가져오고 계속 동기화하는 기능이에요. 이 문서에서는 연동 방법, 가져오기 기준, 연결 오류가 났을 때의 동작을 안내해요.

## WooCommerce 가져오기 및 동기화란?

WooCommerce 스토어 운영자는 상품과 컬렉션을 하이퍼클래스로 가져와 동기화할 수 있어요. 예전에는 주문, 연락처, 거래 내역만 가져올 수 있었어요. 이제는 상품과 컬렉션까지 옮길 수 있어서, WooCommerce 스토어를 하이퍼클래스에서 더 편하게 관리할 수 있어요.

## 주요 장점

WooCommerce 스토어를 하이퍼클래스와 연결해 데이터를 쉽게 동기화할 수 있어요.

- 스토어 전체 가져오기: 모든 상품, 컬렉션, 연락처, 주문, 거래 내역을 가져와 동기화해요.
- 자동 동기화: 상품과 컬렉션 데이터를 실시간으로 최신 상태로 유지해요.
- 스토어 데이터 통합 관리: 스토어와 관련된 데이터를 하이퍼클래스에서 바로 관리해요.
- 데이터 정확성 향상: WooCommerce를 기준 데이터(source of truth)로 삼아 정확하고 일관된 데이터를 유지해요.
- 오류 대응: 인증 오류가 나면 다시 연결할 수 있도록 자동으로 안내해요.

## WooCommerce 가져오기 및 동기화 사용하기

다음 단계를 따라 WooCommerce 스토어를 연결하고 데이터 동기화를 시작하세요.

1. 연동 설정 화면으로 이동해요.
   - 하이퍼클래스 서브 계정에서 **설정 > 연동 > WooCommerce**로 이동하세요.
2. WooCommerce 스토어를 연결해요.
   - **Connect**(연결)를 클릭하고 WooCommerce 스토어 URL을 입력하세요. (예: https://yourstore.com, 끝에 슬래시 없이 입력)
   - 화면 안내에 따라 설정을 마무리하세요.
3. 가져올 데이터를 선택해요.
   - 가져올 항목을 고르세요.
     - **연락처**
     - **주문**
     - **거래 내역**
     - **상품**
     - **컬렉션**
4. **동기화 설정**을 구성해요.
   - 계속 동기화할 항목을 설정하세요.
     - **연락처**
     - **주문**
     - **거래 내역**
     - **Order Submitted Trigger**(주문 제출 트리거)
     - **결제 완료 트리거**
     - **상품**
     - **컬렉션**
5. 설정을 완료하고 관리해요.
   - **저장**을 클릭하면 가져오기와 동기화가 시작돼요.
   - 연동 설정에서 동기화 옵션을 언제든 켜거나 끌 수 있어요.
6. 데이터를 다시 가져오려면 연동을 해제했다가 다시 연결하세요.
   - 그러면 최신 데이터를 새로 가져와요.

## 상품·카테고리 가져오기 기준

상품과 카테고리는 아래 기준에 맞는 것만 가져와요.

- Simple(단순)과 Variable(변형) 상품만 가져와요. 다른 유형의 상품은 가져오지 않아요.
- 가격이 $0이거나 옵션(variant)이 없는 상품은 가져오지 않아요.
- **Include in Online Store**(온라인 스토어에 포함) 토글은 게시된 상품에서만 켜져요.
- 상품 정보는 WooCommerce가 기준 데이터예요.
- 상품에 연결된 카테고리만 가져와요. 상품과 연결되지 않은 카테고리는 무시해요.
- 상품이나 카테고리를 삭제해도 하이퍼클래스에는 반영되지 않아요.

## 추가 개선 사항: 더 강력하고 안정적으로

연동을 더 매끄럽고 효율적으로 쓸 수 있도록 개선했어요.

- 주문 가져오기 완성도 향상: 상품과 이미지가 연결된 주문을 이제 모두 가져와요.
- 오류 처리와 재연결 지원 개선
  - 401(Unauthorized), 403(Forbidden), 404(Not Found) 같은 인증 오류가 생기면 연동이 재연결 모드로 바뀌어요.
  - 서브 계정 관리자에게 연결을 복구하는 방법이 담긴 이메일이 발송돼요.
- 동기화 효율 개선: 데이터를 더 빠르고 안정적으로 가져오고 동기화해요.
- 데이터 정확성 강화: WooCommerce를 유일한 기준 데이터로 유지해 데이터 불일치를 줄여요.

## 자주 묻는 질문

### WooCommerce 상품을 유형 상관없이 모두 가져올 수 있나요?
아니요. Simple(단순)과 Variable(변형) 상품만 가져와요. 다른 유형의 상품은 지원하지 않아요.

### WooCommerce에서 상품을 삭제하면 하이퍼클래스에도 반영되나요?
아니요. WooCommerce에서 상품이나 카테고리를 삭제해도 하이퍼클래스에는 반영되지 않아요.

### WooCommerce와 하이퍼클래스 사이의 데이터는 얼마나 자주 동기화되나요?
연동 설정 화면에서 정한 내용에 따라 동기화가 계속 진행돼요.

### WooCommerce 연결이 끊어졌어요. 어떻게 해야 하나요?
인증 오류가 나면 연동이 재연결 모드로 바뀌고, 관리자에게 연결을 복구하는 방법이 담긴 이메일이 발송돼요. 이메일 안내에 따라 연결을 복구하세요.
