# 이커머스 스토어의 고객 로그인

하이퍼클래스 이커머스 스토어에서 쓸 수 있는 고객 로그인 기능을 소개해요. 방문자가 스토어 화면을 벗어나지 않고 바로 로그인해서 지난 주문과 계정 전용 콘텐츠를 볼 수 있어요. 고객의 신뢰를 높이고 재구매를 이끌며, 스토어를 더 전문적으로 보이게 해 줘요.

## 고객 로그인이란?

고객 로그인은 이커머스 스토어에 전용 로그인 창구를 만드는 기능이에요. 기능을 켜면 스토어 내비게이션 메뉴에 로그인 버튼이 나타나요. 고객이 로그인하면 주문 내역과 로그아웃 메뉴가 들어 있는 드롭다운 메뉴를 쓸 수 있어요. 이 메뉴는 스토어 화면 안에 자연스럽게 들어가 있어요.

## 고객 로그인의 장점

고객 로그인을 쓰면 스토어가 더 편리하고 전문적으로 보여요. 고객은 브랜드를 더 안심하고 이용하면서 자신의 주문 정보도 그대로 확인할 수 있어요.

- 스토어 화면에서 바로 로그인해요. 다른 페이지로 이동하지 않아도 돼요.
- 로그인 후 드롭다운 메뉴에서 고객 전용 기능을 빠르게 쓸 수 있어요.
- 로그인 아이콘 색상과 내비게이션 이름을 원하는 대로 바꿀 수 있어요.
- 로그인 창을 새 탭에서 열지, 현재 탭에서 열지 선택할 수 있어요.
- 이동 주소를 지정해서 내비게이션 메뉴 항목을 직접 추가할 수 있어요.
- 안전한 로그인을 위해 인증된 도메인이 필요해요.

## 고객 로그인을 켜는 방법

다음 단계를 따라 스토어에서 고객 로그인을 켜고 설정해 보세요.

1. **대시보드**에서 **Store Builder**(스토어 빌더)를 열어요.
2. 스토어 페이지로 이동해서 **Navigation Menu**(내비게이션 메뉴)를 클릭해요.
3. 다음 위치로 이동해요.

   - **일반 설정 > Customer Login**(고객 로그인)
   - **Enable Customer Login**(고객 로그인 활성화) 토글을 켜요.
4. 같은 설정 화면에서 **Menu Items Dropdown**(메뉴 항목 드롭다운) 섹션까지 스크롤해서 다음을 설정해요.

   - 새 메뉴 항목을 추가해요.
   - 각 항목의 이동 주소(redirect URL)를 지정해요.
   - 링크를 새 탭에서 열지, 같은 창에서 열지 선택해요.
5. 스토어 도메인이 추가되어 있고 인증도 끝났는지 확인해요.

   - 도메인이 기존 스토어 페이지에 연결되어 있어야 해요. 연결되어 있지 않으면 로그인 버튼이 제대로 작동하지 않아요.

{% hint style="warning" %}
토글이 꺼져 있으면 스토어 내비게이션에 로그인 버튼이 나타나지 않아요. 로그인 기능이 작동하려면 유효한 도메인이 연결되고 인증되어 있어야 해요.
{% endhint %}

스토어를 아직 만들지 않았다면 [이커머스 온라인 스토어 설정 방법](E-Commerce-Store/how-to-set-up-an-e-commerce-online-store-websites.md)을 먼저 확인해 보세요.

## 스토어 내비게이션의 로그인 버튼

로그인 버튼은 스토어 상단 내비게이션에 새로 들어간 기능이에요. 원하는 대로 꾸밀 수 있어요. 고객은 스토어를 벗어나지 않고 바로 자기 계정에 들어갈 수 있어요.

### 로그인 버튼 기능

- 켜기/끄기 토글: 로그인 버튼을 표시하거나 숨겨요.
- 아이콘 색상 설정: 브랜드 테마에 맞춰 색상을 바꿔요.
- 메뉴 항목 추가: 자주 찾는 다른 페이지로 바로 갈 수 있게 해요.
- **새 탭에서 열기**: 방문자가 링크를 열 방식을 고를 수 있어요.

## 로그인 후 고객 드롭다운 메뉴

고객이 로그인하면 프로필 아이콘을 눌러 드롭다운 메뉴를 열 수 있어요. 이 메뉴에는 꼭 필요한 기능이 들어 있어요.

### 드롭다운 메뉴 항목

- **주문**: 지난 주문 내역을 전체 목록으로 볼 수 있어요.
- **Logout**(로그아웃): 고객 계정에서 로그아웃해요.

이 간단한 화면 덕분에 고객은 쇼핑 내역을 손쉽게 직접 관리할 수 있어요.

## 자주 묻는 질문

### 고객 로그인 토글을 끄면 어떻게 되나요?
스토어 내비게이션 메뉴에 로그인 버튼이 나타나지 않고, 고객도 로그인할 수 없어요.

### 도메인 없이 로그인 기능을 테스트할 수 있나요?
아니요. 로그인 기능이 활성화되려면 스토어 페이지 중 하나에 인증된 라이브 도메인이 연결되어 있어야 해요.

### 고객 드롭다운 메뉴에 원하는 링크를 추가할 수 있나요?
네, 이동 주소를 지정한 메뉴 항목을 여러 개 추가할 수 있어요. 각 항목을 새 탭에서 열지 현재 탭에서 열지도 정할 수 있어요.

### 로그인하면 고객 데이터가 CRM과 동기화되나요?
현재 로그인으로는 지난 주문 확인과 로그아웃만 할 수 있어요. CRM 동기화는 아직 지원하지 않아요.

### 도메인이 인증되지 않았거나 스토어 페이지에 연결되지 않으면 어떻게 되나요?
로그인 버튼이 작동하지 않고, 고객 로그인 기능도 제대로 동작하지 않아요.
