# 이커머스 스토어의 문구 바꾸기 — Text Customization

스토어의 여러 요소에 들어가는 문구를 한곳에서 직접 바꾸는 기능이에요. 스토어를 우리말에 맞게 다듬거나 브랜드만의 표현을 넣고 싶을 때 쓰세요.

## 새로 달라진 점

- 스토어 운영자가 이커머스 스토어의 여러 구성 요소(예: **Product List**(상품 목록), **상품 상세**, **Upsell**(업셀))에 들어가는 문구를 직접 바꿀 수 있어요. 스토어를 지역 언어에 맞게 현지화하거나 브랜드만의 표현을 넣을 수 있어요.
- 이전에는 문구 설정이 **일반 설정**과 **고급 설정**에 나뉘어 있었고, 바꿀 수 없는 항목도 많았어요. 이제 모든 문구 설정이 **일반 설정** 안의 **Text Customization**(문구 사용자 지정) 섹션 한곳에 모여 있어요.

## 사용 방법

1. **Store Builder**(스토어 빌더)를 열고, 문구를 바꾸고 싶은 요소를 선택하세요. 예를 들면 **Product List**, **상품 상세**, **Upsell** 같은 요소예요.
2. 오른쪽 **설정** 탭의 **일반 설정** 섹션으로 이동하세요. 맨 아래까지 스크롤하면 **Text Customization** 섹션이 나와요.
3. **Text Customization** 섹션에는 구성 요소의 부분별로 문구 옵션이 하위 섹션으로 나뉘어 있어요. 예를 들면 **Shipping Details**(배송 정보), **Payment Section**(결제 섹션) 같은 하위 섹션이 있어요.
4. 각 하위 섹션에서 바꾸고 싶은 문구, 레이블, 제목을 편집하세요.
5. 편집을 마치면 변경 내용을 저장하고 **게시**를 클릭하세요.

## 참고할 점

- 오류 메시지나 검색 결과가 없을 때 보이는 화면 문구처럼, 빌더 미리보기에 나타나지 않는 문구도 있어요. 이런 문구도 바꿀 수 있어요.
- 기존 **Button Options**(버튼 옵션), **Form Options**(폼 옵션) 같은 설정은 **Text Customization** 섹션으로 옮겨졌어요. 이전 옵션은 더 이상 제공되지 않고, 쓸 필요도 없어요.
- 이미 운영 중인 스토어는 문구 설정을 바꾸지 않아도 지금처럼 그대로 동작해요.
