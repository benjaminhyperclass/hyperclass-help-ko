# AI에게 문의 컴퓨터 사용하기

AI에게 문의 컴퓨터(Ask AI Computer)는 AI에게 문의 어시스턴트에게 전용 클라우드 컴퓨터를 주는 기능이에요. 어시스턴트가 웹사이트를 열고, 명령어를 실행하고, 파일을 다루면서 여러 단계로 이루어진 작업을 처리해요. 진행 상황은 화면에서 바로 볼 수 있고, 필요하면 직접 컴퓨터를 조작한 뒤 다시 어시스턴트에게 넘길 수 있어요. 이 문서에서는 주요 기능과 시작 방법을 안내해요.

## AI에게 문의 컴퓨터란?

AI에게 문의 컴퓨터는 하이퍼클래스의 [AI에게 문의 어시스턴트](../13-AI-Employee/introduction-to-ask-ai-assistant.md)가 웹사이트를 이용하고, 데스크톱 도구를 쓰고, 사용자 대신 작업을 끝내도록 해 주는 개인용 클라우드 컴퓨터예요.

사용자마다 클라우드 컴퓨터가 하나씩 주어지고, 작업하는 서브 계정마다 데스크톱이 따로 있어요. 컴퓨터에는 Chrome 브라우저, 터미널, 파일 관리자가 들어 있어서 웹사이트, 명령어, 문서를 다룰 수 있어요.

**컴퓨터** 채팅에 원하는 작업을 적으면 어시스턴트가 필요한 동작을 수행하고, 진행 상황을 보여 주고, 결과를 대화로 알려 줘요.

[AI 브라우저 제어 확장 프로그램](../13-AI-Employee/Ask-AI/ai-browser-control-extension.md)은 내 기기의 브라우저를 제어하지만, AI에게 문의 컴퓨터는 자체 클라우드 데스크톱에서 작동해요.

---

## AI에게 문의 컴퓨터의 장점

AI에게 문의 컴퓨터는 대화형 도움에 실제 데스크톱 작업을 더했어요. 웹사이트, 파일, 컴퓨터 도구가 필요한 작업을 진행 상황을 확인하면서 직접 제어할 수 있어요.

- 대화로 작업 완료: 필요한 내용을 평소 말투로 적으면 어시스턴트가 컴퓨터로 작업을 수행해요.
- 웹사이트 직접 이용: 페이지를 열고, 사이트를 이동하고, 온라인 도구를 사용해요. 직접 연동되지 않는 서비스도 쓸 수 있어요.
- 실시간으로 작업 확인: 대화와 실시간 컴퓨터 미리보기로 어시스턴트의 진행 상황을 따라가요.
- 필요할 때 직접 제어: AI 제어에서 수동 조작으로 바꿨다가, 다시 컴퓨터를 넘겨 작업을 이어가요.
- 파일과 문서 작업: 컴퓨터의 파일 관리자, 브라우저, 터미널로 정보를 처리하고 내려받을 수 있는 파일을 만들어요.
- 안전한 로그인: 비공개 로그인 폼과 암호화된 **보안 저장소** 로그인 정보로 인증 정보가 채팅에 남지 않게 해요.
- 작업 공간 분리: 사용자의 컴퓨터에는 서브 계정별로 데스크톱이 따로 있어요.

## 사용 조건과 제한 사항

AI에게 문의 컴퓨터는 사용할 수 있는 서브 계정에서만 쓸 수 있고, 저장 공간·보안·접근 범위에 제한이 있어요. 작업을 시작하기 전에 아래 내용을 확인하세요.

- 가용성: Ask AI Level Up이 있는 서브 계정에서 사용할 수 있어요.
- 접근 제어: 에이전시는 에이전시, 서브 계정, 개별 사용자 단위로 컴퓨터 사용 여부를 관리할 수 있어요. 에이전시 관리자는 계속 사용할 수 있어요.
- 파일 크기: 업로드하거나 내려받는 파일은 하나당 최대 25MB예요.
- 저장 공간: 사용자마다 모든 서브 계정을 합쳐 15GB를 쓸 수 있어요.
- 네트워크 접근: 컴퓨터는 공용 인터넷에는 접근할 수 있지만 사설 네트워크나 내부 클라우드 서비스에는 접근할 수 없어요.
- 승인: 민감한 작업이나 도구 설치는 컴퓨터가 진행하기 전에 승인이 필요할 수 있어요.

## AI에게 문의 컴퓨터 시작하기

시작은 AI에게 문의 화면에서 해요. **컴퓨터** 채팅을 열고, 클라우드 컴퓨터를 켠 다음, 시킬 작업을 적으면 돼요.

### 1단계: AI에게 문의 컴퓨터 열기

1. 서브 계정 화면의 왼쪽 메뉴에서 **AI에게 문의**(Ask AI)를 선택하세요.
2. **AI에게 문의** 사이드바에서 **컴퓨터**를 선택하세요.

![AI에게 문의 사이드바에서 컴퓨터 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084304078/original/HDAVL-X2TkUrDeVV2vkBISL6ooeEci3SLA.png?1793103190)

### 2단계: 컴퓨터 켜기

1. **컴퓨터** 채팅이 데스크톱 미리보기와 함께 열려요.
2. 미리보기에 **컴퓨터가 꺼져 있습니다**라고 나오면 **켜기**를 클릭해 컴퓨터를 시작하세요.

![컴퓨터가 꺼져 있어요 화면에서 켜기 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084304147/original/mKGyBK05doWeje_kYO6xyT0GjHigKIgDDA.png?1793103219)

### 3단계: 작업 입력하기

1. **컴퓨터** 채팅에서 **Ask anything**(무엇이든 물어보세요) 입력란을 클릭하세요.
2. AI에게 문의 컴퓨터가 해 줬으면 하는 일을 적으세요.
3. 전송 화살표를 클릭해 작업을 보내세요.

입력 예시는 다음과 같아요.

> Google을 열고 뉴욕시에서 가볼 만한 곳을 검색해 주세요. 웹사이트를 몇 군데 방문한 다음, 인기 명소 5곳을 간단한 설명과 웹사이트 링크와 함께 목록으로 알려 주세요.

![컴퓨터 채팅에 작업 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084304526/original/RPo4pfGtyAv33nsS2nBm8SNFyzwKnyQA0A.png?1793103387)

### 4단계: 컴퓨터가 일하는 모습 확인하기

1. AI에게 문의 컴퓨터가 작업을 시작해요.
2. 실시간 미리보기에서 브라우저가 움직이는 모습을 보면서 대화로 진행 상황을 확인하세요.
3. 작업이 끝나면 답변과 함께 제공된 링크나 파일을 확인하세요.

![작업 진행 중인 컴퓨터 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084306994/original/rCatXo5Wh0eG1AqSwdstmJFSxJL6HZKy3g.png?1793104435)

![작업 완료 후 결과 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084307041/original/MHjXLbVcLiypouwLmpAXOk6tpUUlmtv2Ig.png?1793104462)

## AI에게 문의 컴퓨터의 작동 방식

AI에게 문의 컴퓨터는 클라우드 데스크톱에서 사용자의 지시에 따라 작업을 수행해요. 실시간 미리보기, 데스크톱 도구, 제어 옵션으로 어시스턴트의 활동을 확인하고, 필요할 때 직접 컴퓨터를 조작할 수 있어요.

### 실시간 컴퓨터 미리보기

어시스턴트가 작업하는 동안 컴퓨터 미리보기에 데스크톱이 표시돼요. 웹사이트가 열리는 모습, 브라우저의 움직임, 컴퓨터가 도구를 쓰는 모습을 볼 수 있어요.

제어 상태를 보면 지금 누가 컴퓨터를 조작하고 있는지 알 수 있어요.

- **Computer has control**(컴퓨터가 제어 중): 어시스턴트가 데스크톱을 제어하고 있어요.
- **직접 제어 중**: 내가 데스크톱의 제어권을 가져온 상태예요.
- **Computer is idle**(컴퓨터 대기 중): 컴퓨터가 지금 작업을 수행하고 있지 않아요.

![제어 상태가 표시된 컴퓨터 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084306043/original/I-XUjoH3krpOVw-sMr0BLVPZFlSOnX1xyA.png?1793104031)

### 제어권 가져오기와 반환하기

직접 해야 할 작업이 있으면 컴퓨터를 직접 조작할 수 있어요.

1. 서브 계정 화면의 왼쪽 메뉴에서 **AI에게 문의**를 선택하세요.
2. **AI에게 문의** 사이드바에서 **컴퓨터**를 선택하세요.
3. 실시간 컴퓨터 미리보기에서 **제어권 가져오기**를 클릭하세요.
4. 상태가 **직접 제어 중**으로 바뀌어요.
5. 필요한 대로 브라우저나 다른 데스크톱 도구를 사용하세요.
6. 어시스턴트에게 다시 넘기려면 **제어권 반환**을 클릭하세요.

제어권을 반환하면 어시스턴트가 멈춘 지점부터 작업을 이어갈 수 있어요.

![제어권 가져오기와 제어권 반환 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084306663/original/REy42_QFzfqS5AqULBW3w5CcXach5kdRwg.png?1793104311)

### 브라우저, 터미널, 파일

미리보기 아래쪽 도구 모음에서 컴퓨터 데스크톱의 도구 세 가지를 쓸 수 있어요.

- **브라우저**: Chrome으로 웹사이트를 열고 이용해요.

  ![브라우저 도구 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084306513/original/yWKqHVWwkWE_m6lHVRsoNsHJcGvBlg82Hg.png?1793104229)
- **터미널**: 명령어를 실행하고 스크립트나 명령줄 도구를 다뤄요.

  ![터미널 도구 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084306338/original/CnVEf1Enj8-MoyYO9BlaIJqSJDndWr4bJg.png?1793104137)
- **파일**: 파일 관리자를 열어 **다운로드**, **uploads**(업로드), **workspace**(작업 공간) 폴더에 접근해요.

  ![파일 관리자 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084306537/original/fibeBD-s8mD1_SwhFpve5gIqaNzlWyqkIQ.png?1793104247)

이 도구들 덕분에 컴퓨터는 웹사이트 탐색 이상의 작업도 처리할 수 있어요.

## 자주 묻는 질문

### AI에게 문의 컴퓨터를 한동안 쓰지 않으면 어떻게 되나요?

15분 동안 활동이 없으면 컴퓨터가 절전 상태가 되고, 필요할 때 다시 깨어나요.

### AI에게 문의 컴퓨터에서 PDF나 로컬 파일을 열 수 있나요?

네. 컴퓨터의 브라우저에서 PDF 문서와 로컬 파일을 열 수 있어요.

### AI에게 문의 컴퓨터에 도구를 추가로 설치할 수 있나요?

네. 컴퓨터는 Python 패키지, Node 도구, 명령줄 유틸리티를 지원해요. 설치할 때마다 사용자의 승인이 필요하고, 설치한 도구는 이후 작업에서도 계속 쓸 수 있어요.

### 웹사이트에서 일회용 인증 코드를 요구하면 어떻게 하나요?

컴퓨터의 제어권을 가져와 웹사이트에 인증 코드를 직접 입력한 다음, 제어권을 반환하면 어시스턴트가 작업을 이어갈 수 있어요.
