# 서브 계정 대시보드의 평판 관리 위젯

**평판 관리** 위젯을 쓰면 리뷰 요청, 고객 피드백, 응답 현황을 서브 계정 **대시보드**에서 바로 확인할 수 있어요. 이 문서에서는 위젯의 종류와 대시보드에 추가하는 방법을 안내해요.

평판 관리 위젯은 꼭 필요한 평판 지표를 한곳에 모아 줘요. 리뷰 활동을 지켜보고, 추세를 파악하고, 고객 피드백에 얼마나 잘 응답하는지 확인하기 쉬워요. 차트, 날짜 범위, 필터를 조합해서 보고 싶은 대로 대시보드를 꾸밀 수 있어요.

## 서브 계정 대시보드의 평판 관리 위젯이란?

평판 관리 위젯은 리뷰 요청, 고객 리뷰, 리뷰 응답과 관련된 핵심 지표를 보여 주는 대시보드 구성 요소예요. 여러 리포트 페이지를 오가지 않아도, 기업과 에이전시가 서브 계정 대시보드에서 다른 비즈니스 지표와 함께 평판 성과를 볼 수 있어요.

하이퍼클래스는 평판 관리 위젯 16개를 제공해요. 이 위젯으로 리뷰 요청 활동, 리뷰 수, 평점, 감성, 응답 성과를 추적할 수 있어요. 기존 대시보드에 추가해도 되고, 평판 전용 대시보드를 새로 만들어도 돼요.

대시보드 레이아웃을 바꾸고, 조회 기간을 고르고, 지원되는 필터를 적용해서 우리 비즈니스에 필요한 정보만 볼 수 있어요.

## 평판 관리 위젯의 장점

평판 관리 위젯을 쓰면 하이퍼클래스의 여러 화면을 오가지 않고도 고객 피드백을 파악하고 리뷰 관리 현황을 확인할 수 있어요. 중요한 평판 데이터를 맞춤 설정한 대시보드에 모아 두면 추세를 찾고, 성과를 확인하고, 팀과 의미 있는 인사이트를 공유하기 좋아요.

- 평판을 한곳에서 확인해요: 리뷰 요청, 고객 리뷰, 응답 성과를 다른 비즈니스 지표와 함께 한 대시보드에서 볼 수 있어요.
- 리뷰 요청 현황을 파악해요: 리뷰 요청이 몇 건 발송됐는지, 어떤 채널을 썼는지, 요청 상태가 어떤지 추적할 수 있어요.
- 고객 피드백을 이해해요: 리뷰 수, 별점, 감성, 리뷰 출처를 확인하면서 고객 경험을 더 잘 이해할 수 있어요.
- 응답 성과를 추적해요: 고객 리뷰에 얼마나 꾸준히, 얼마나 빨리 답하는지 볼 수 있어요. AI 응답과 수동 응답도 구분해서 확인해요.
- 원하는 대로 리포트를 만들어요: 위젯을 추가하고, 크기를 바꾸고, 순서를 옮겨서 우선순위에 맞는 대시보드를 만들 수 있어요.
- 데이터를 유연하게 필터링해요: 날짜 범위와 지원되는 **빠른 필터**로 특정 평점, 출처, 응답 상태에 집중할 수 있어요.
- 고객 리포트가 더 명확해져요: 에이전시와 사업주에게 다른 운영 지표와 함께 평판 성과를 한눈에 보여 줄 수 있어요.

## 리뷰 요청 위젯

리뷰 요청 위젯은 고객 피드백을 얼마나 적극적으로 요청하고 있는지, 요청이 채널별로 어떻게 진행되는지 보여 줘요. 요청 수, 전달 상태, 추이를 살펴보면 리뷰 요청 방식을 개선할 부분을 찾는 데 도움이 돼요.

다음 위젯으로 리뷰 요청 활동을 확인해요.

| 위젯 | 설명 |
| --- | --- |
| **전송된 요청** | 선택한 조회 기간에 발송된 리뷰 요청 수를 보여 줘요. |
| **채널별 요청** | 리뷰 요청을 SMS, 이메일, WhatsApp 등 커뮤니케이션 채널별로 나누어 보여 줘요. 해당하는 경우에만 표시돼요. |
| **상태별 요청** | 리뷰 요청을 **대기 중**, **발송됨**, **전달됨**, **열림**, **실패** 같은 상태별로 묶어 보여 줘요. |
| **요청 추이** | 시간에 따른 리뷰 요청 수의 변화를 그래프로 보여 줘요. |

**리뷰 요청 상태 이해하기**

요청 상태를 보면 리뷰 요청이 정상적으로 처리됐는지, 확인이 필요한지 알 수 있어요.

- **대기 중**: 리뷰 요청이 발송을 기다리고 있어요.
- **발송됨**: 선택한 채널로 리뷰 요청을 보냈어요.
- **전달됨**: 메시지 제공업체가 지원하는 경우, 전달이 확인됐어요.
- **열림**: 열림 상태가 기록된 요청이에요.
- **실패**: 요청을 정상적으로 전달하지 못했어요.

전달 확인과 상태 표시 여부는 채널과 제공업체에 따라 다를 수 있어요.

리뷰 요청을 보내고 상태를 관리하는 방법은 [리뷰 요청 보내는 방법](../41-평판-리뷰/Review-Requests/how-to-send-review-requests.md)을 참고하세요.

## 고객 리뷰 위젯

고객 리뷰 위젯은 지원되는 리뷰 플랫폼 전반에서 받은 피드백을 보여 줘요. 리뷰 수, 고객 평점, 리뷰 출처, 감성을 추적하면 고객 만족도의 변화를 찾고 전반적인 평판을 확인할 수 있어요.

사용할 수 있는 리뷰 지표는 다음과 같아요.

| 위젯 | 설명 |
| --- | --- |
| **총 리뷰 수** | 위젯의 조회 기간과 해당 데이터 범위에 포함된 전체 리뷰 수를 보여 줘요. |
| **평점별 리뷰** | 고객 리뷰를 별점별로 묶어 보여 줘요. |
| **출처별 리뷰** | 리뷰를 출처 또는 연결된 리뷰 플랫폼별로 나누어 보여 줘요. |
| **감성별 리뷰** | 리뷰를 **긍정적**, **중립**, **부정적**으로 분류해 보여 줘요. |
| **리뷰 추이** | 시간에 따른 리뷰 수의 변화를 보여 줘요. |
| **평균 평점** | 지표에 포함된 리뷰의 평균 별점을 보여 줘요. |
| **평점 추이** | 시간에 따른 평균 별점의 변화를 추적해요. |

**리뷰 감성 이해하기**

리뷰 감성을 보면 고객이 경험을 어떻게 느꼈는지 가늠할 수 있어요.

- **긍정적**: 고객이 호의적인 피드백을 남긴 리뷰예요.
- **중립**: 엇갈리거나 중립적인 피드백을 남긴 리뷰예요.
- **부정적**: 고객이 불만스러운 피드백을 남긴 리뷰예요.

하이퍼클래스는 감성 분석으로 작성된 리뷰를 분류해요. 작성된 내용이 없는 리뷰는 별점으로 감성을 판단할 수 있어요.

감성은 별점만으로는 알기 어려운 맥락을 보여 줘요. 고객 만족도 추세와 개선이 필요한 부분을 알아보기 쉬워요.

![고객 리뷰 위젯 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083395268/original/i8k7KE-QtWEe4PzwIXaZ8MU1B-Z6fgdzmQ.png?1792060650)

리뷰 분석에 대한 자세한 내용은 [평판 관리 개요 대시보드 살펴보기](../41-평판-리뷰/Review-Requests/reputation-breaking-down-the-reputation-overview-dashboard.md)를 참고하세요.

## 리뷰 응답 위젯

리뷰 응답 위젯은 고객 피드백에 얼마나 꾸준하고 효율적으로 응답하는지 보여 줘요. 응답 활동을 추적하면 답하지 않은 리뷰를 찾고, 응답 성과의 변화를 파악하고, 고객과의 소통을 개선하는 데 도움이 돼요.

사용할 수 있는 응답 지표는 다음과 같아요.

| 위젯 또는 지표 | 설명 |
| --- | --- |
| **응답률** | 위젯의 조회 기준에 따라, 응답을 받은 리뷰의 비율을 보여 줘요. |
| **평균 응답 시간** | 고객 리뷰에 응답하기까지 걸린 평균 시간을 측정해요. |
| **응답률 추이** | 시간에 따른 리뷰 응답률의 변화를 보여 줘요. |
| **평균 응답 시간 추세** | 시간에 따른 평균 리뷰 응답 시간의 변화를 추적해요. |
| **AI vs. manual responses**(AI 응답 대 수동 응답) | AI로 생성한 리뷰 응답과 직접 작성해서 제출한 응답을 비교해 보여 줘요. |

**응답 분류 이해하기**

리뷰 응답은 처리 방식에 따라 다음과 같이 나눠요.

- **AI**: AI 기반 응답 기능으로 답한 리뷰예요.
- **수동**: 직접 답한 리뷰예요.
- **Not Responded**(미응답): 기록된 응답이 없는 리뷰예요.

이 분류를 보면 리뷰 응답이 어떻게 처리되고 있는지 알 수 있어요.

![리뷰 응답 위젯 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083395889/original/frO2p9eGXdYdAULDJPFZEcabcc56m1VmnQ.png?1792060955)

{% hint style="info" %}
응답 관련 지표와 수치는 위젯의 조회 범위에 포함된 리뷰에 따라 달라져요. AI 응답 데이터를 볼 수 있는지는 해당 서브 계정에 설정된 리뷰 응답 기능에 따라 달라질 수 있어요.
{% endhint %}

## 대시보드 필터와 맞춤 설정

대시보드를 맞춤 설정하면 필요한 평판 지표에 집중하면서 리포트를 깔끔하게 정리할 수 있어요.

날짜 범위를 바꾸고, 지원되는 **빠른 필터**를 쓰고, 평판 관리 위젯의 위치를 조정해서 비즈니스 목표별 리포트 화면을 만들어 보세요.

**날짜 범위 필터**

**대시보드** 위쪽의 날짜 범위 선택기로 원하는 조회 기간의 지표를 볼 수 있어요.

예를 들어 월간, 분기, 연간 기간을 선택해서 평판 활동의 변화를 확인할 수 있어요.

1. 평판 관리 위젯이 있는 서브 계정 대시보드를 여세요.
2. 오른쪽 위에 있는 날짜 범위 선택기를 클릭하세요.
3. 원하는 조회 기간을 선택하세요.
4. 대시보드 날짜 범위를 따르는 위젯의 지표가 어떻게 바뀌었는지 확인하세요.

**빠른 필터**

평판 관리 대시보드에서는 지원되는 **빠른 필터**로 표시되는 정보를 좁힐 수 있어요.

평판 관리 대시보드 화면에 나오는 필터 예시는 다음과 같아요.

| 필터 | 용도 |
| --- | --- |
| **Rating**(평점) | 특정 별점의 리뷰에 집중해요. |
| **소스 또는 페이지** | 리뷰 데이터를 선택한 소스나 페이지로 좁혀요. |
| **응답 상태** | 리뷰에 답했는지, 어떻게 답했는지에 따라 리뷰에 집중해요. |

기존 **빠른 필터**를 적용하는 방법은 다음과 같아요.

1. 평판 관리 위젯이 있는 대시보드를 여세요.
2. **빠른 필터** 바를 찾으세요.
3. **Rating**, **소스 또는 페이지**, **응답 상태** 중 하나를 선택하세요.
4. 원하는 필터 값을 선택하세요.
5. 선택한 필터의 영향을 받는 위젯을 확인하세요.

{% hint style="warning" %}
**빠른 필터**는 호환되는 위젯과 데이터 소스에만 적용돼요. 대시보드의 모든 위젯에 자동으로 적용되지는 않아요. **빠른 필터**는 위젯 단위 조건과 함께 작동하기 때문에, 조건이 서로 충돌하면 일치하는 데이터가 없을 수 있어요.
{% endhint %}

자세한 방법은 [대시보드의 빠른 필터](../12-대시보드/시작하기/quick-filters-on-dashboards.md)를 참고하세요.

![빠른 필터가 적용된 평판 관리 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083396475/original/Qrgghd4OOd9GoIxtKsY0QjQQWR8bsvxbWA.png?1792061208)

**위젯 레이아웃과 맞춤 설정**

평판 관리 위젯을 다른 대시보드 지표와 나란히 배치하면 팀에 맞는 리포트 레이아웃을 만들 수 있어요.

대시보드에서 쓸 수 있는 맞춤 설정 옵션은 다음과 같아요.

- 위젯 재배치: 위젯을 끌어서 대시보드에서의 위치를 바꿔요.
- 위젯 크기 조정: 위젯 크기를 조절해서 더 읽기 쉽게 만들어요.
- 위젯 설정: 지원되는 설정, 차트 유형, 조건을 바꿔요.
- 지표 조합: 평판 관리 위젯을 다른 비즈니스 성과 위젯과 함께 표시해요.
- 모양 설정: 사용할 수 있는 대시보드 테마와 레이아웃 요소를 활용해요.
- **맞춤 지표** 추가: 계산이 필요한 비즈니스 지표가 더 있고 지원되는 경우, 별도의 **맞춤 지표** 기능을 사용해요.

고급 위젯 설정은 [대시보드 위젯 맞춤 설정](../12-대시보드/customizing-dashboard-widgets.md)을 참고하세요.

## 서브 계정 대시보드에 평판 관리 위젯 설정하기

서브 계정 대시보드에 평판 관리 위젯을 추가하면 **평판 관리** 메뉴를 계속 오가지 않아도 중요한 평판 지표를 볼 수 있어요. 위젯을 설정하고 잘 배치해 두면 우리 비즈니스나 고객에게 유용한 정보를 대시보드에 보여 줄 수 있어요.

### 1단계: 서브 계정 대시보드로 이동하기

1. 하이퍼클래스 계정에 로그인해요.
2. 원하는 서브 계정을 여세요.
3. 왼쪽 메뉴에서 **대시보드**를 선택하세요.
4. 대시보드 선택기에서 기존 대시보드를 여세요.

평판 관리 지표 전용 리포트 화면이 필요하면 새 대시보드를 만들어도 돼요.

![서브 계정의 대시보드 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083425146/original/XkRymqPvwgSM3ZYGSH54HQFrtpeOMM_Xuw.png?1792073374)

### 2단계: 대시보드 편집 모드로 들어가기

1. 맞춤 설정할 대시보드를 여세요.
2. 오른쪽 위에서 **대시보드 수정**을 클릭하세요.
3. 대시보드 편집기가 열릴 때까지 기다려요.

편집 모드에서는 필요한 권한이 있는 사용자가 대시보드 위젯을 추가, 배치, 설정할 수 있어요.

![대시보드 수정 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083425192/original/EOOcn8GhGscejkV_v9-e0pI-uqWV38dATQ.png?1792073405)

### 3단계: 위젯 라이브러리 열기

1. 편집 모드에서 **위젯 추가**를 클릭하세요.
2. 화면 오른쪽에 **새 위젯 추가** 패널이 열리세요.
3. **위젯** 탭이 선택되어 있지 않다면 클릭하세요.
4. **평판 관리** 위젯 카테고리를 찾으세요.

위젯 검색란에서 특정 평판 관리 지표를 검색할 수도 있어요.

![새 위젯 추가 패널 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083425698/original/FiW713163Wz0pITSuroGrkG6cWKmYmzXTw.png?1792073556)

### 4단계: 평판 관리 위젯 선택하기

1. **평판 관리** 카테고리를 둘러보세요.
2. 추가할 위젯을 선택하세요. 예를 들면 다음과 같아요.

   - **전송된 요청**
   - **채널별 요청**
   - **총 리뷰 수**
   - **평점별 리뷰**
   - **감성별 리뷰**
   - **응답률**
3. 선택한 위젯에 표시되는 설정 옵션을 확인하세요.
4. 필요에 따라 사용할 수 있는 차트 유형과 다른 설정을 선택하세요.
5. 위젯 설정을 저장하면 대시보드에 추가돼요.

위젯마다 지원하는 차트 유형이나 설정 옵션이 다를 수 있어요.

![평판 관리 위젯 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083427237/original/9QakhAo0mTCkZonlh2oA8JxNGsmRXGatRg.png?1792074142)

### 5단계: 다른 평판 관리 위젯 추가하기

같은 방법으로 위젯을 선택해서 다른 평판 관리 지표도 추가하세요.

예를 들어 평판 관리 전 과정을 모니터링하려는 비즈니스라면 다음 위젯을 포함해 볼 수 있어요.

1. **전송된 요청**: 요청 활동을 추적해요.
2. **상태별 요청**: 전달 문제를 찾아내요.
3. **총 리뷰 수**: 리뷰 수를 확인해요.
4. **감성별 리뷰**: 고객 피드백을 평가해요.
5. **응답률**: 리뷰 응답 활동을 확인해요.

기존 대시보드 위젯과 함께 배치하면 더 폭넓은 비즈니스 성과 개요를 만들 수 있어요.

### 6단계: 위젯 배치하고 크기 조정하기

원하는 위젯을 모두 추가한 뒤에 다음 순서로 진행하세요.

1. 대시보드 편집 모드를 그대로 유지해요.
2. 위젯을 끌어서 위치를 바꾸세요.
3. 크기 조절 컨트롤로 위젯 크기를 바꾸세요.
4. 관련 있는 위젯끼리 모아 두면 읽기 편해요.

예를 들어 리뷰 요청 위젯을 먼저 모으고, 그다음에 고객 리뷰 위젯과 리뷰 응답 위젯을 배치할 수 있어요.

![위젯을 끌어서 배치하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083428052/original/cA0vYPGt-PXVYfF9JELmPVRSK7kwyJ4ZTQ.gif?1792074520)

### 7단계: 대시보드 변경사항 저장하기

1. 위젯 배치와 설정을 확인하세요.
2. 대시보드 위쪽에서 **변경사항 저장**을 클릭하세요.
3. 대시보드 보기 화면으로 돌아가요.
4. 선택한 평판 관리 위젯이 의도대로 표시되는지 확인하세요.

### 8단계: 날짜 범위와 필터 적용하기

대시보드를 저장한 뒤에 다음 순서로 진행하세요.

1. 대시보드 상단에서 원하는 날짜 범위를 선택하세요.
2. 사용할 수 있는 **빠른 필터**로 표시되는 정보를 좁힙니다.
3. 호환되는 평판 관리 위젯이 선택한 조건에 따라 어떻게 바뀌는지 확인하세요.
4. 필요에 따라 필터를 조정하면서 평판 성과의 여러 영역을 비교해요.

![날짜 범위와 빠른 필터를 적용한 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083428155/original/qciSesp0xrJ99OWhqIyZwaPk7slXhHBK2Q.png?1792074575)

{% hint style="info" %}
위젯에 데이터가 표시되지 않으면 선택한 날짜 범위, 적용된 필터, 연결된 리뷰 소스를 확인하세요. 해당 서브 계정에 관련 리뷰나 요청 활동이 있는지도 확인해 보세요.
{% endhint %}

## 자주 묻는 질문

### 기존 서브 계정 대시보드에 평판 관리 위젯을 추가할 수 있나요?

네, 추가할 수 있어요. 대시보드를 열고 편집 모드로 들어간 다음 **위젯 추가**를 선택하면 **평판 관리** 카테고리가 나와요. 평판 관리 위젯은 다른 비즈니스 지표와 함께 추가할 수 있어요.

### 평판 관리 위젯을 쓰면 기존 평판 관리 개요 페이지는 없어지나요?

아니요. 평판 관리 위젯은 서브 계정 대시보드 안에서 평판 지표를 확인하는 또 하나의 방법이에요. 평판 관리 개요 페이지는 별도의 리포트 영역으로 그대로 있어요.

### 평판 관리 위젯마다 리뷰 총계가 다르게 나와요.

조회 기간, 필터, 사용할 수 있는 소스 데이터, 지표마다 측정하는 대상이 달라서 총계가 다를 수 있어요. 결과를 비교할 때는 위젯의 설정과 조회 범위를 확인하세요.

### 평판 관리 위젯에 데이터가 표시되지 않아요.

선택한 기간이나 필터에 일치하는 활동이 없을 수 있어요. 날짜 범위, 위젯 단위 조건, **빠른 필터**, 관련 리뷰 소스 연결을 확인하세요.

### 편집 권한 없이도 평판 관리 위젯을 사용할 수 있나요?

대시보드 보기 권한이 있는 사용자는 자신에게 허용된 위젯을 볼 수 있어요. 위젯을 추가하거나 재배치하거나 설정하려면 대시보드 편집 권한이 필요해요.

### 빠른 필터가 모든 평판 관리 위젯에 적용되나요?

꼭 그렇지는 않아요. **빠른 필터**는 해당 데이터 소스를 쓰는 호환되는 위젯에만 적용돼요. 특정 필터를 적용해도 일부 위젯은 그대로일 수 있어요.

### AI가 작성한 리뷰 응답과 직접 쓴 리뷰 응답을 따로 확인할 수 있나요?

지원되는 경우, 응답 리포트에 AI, 수동, Not Responded(미응답) 분류가 표시돼요. 이 분류로 고객 리뷰가 어떻게 처리되고 있는지 확인할 수 있어요.

### 평판 관리 대시보드 위젯은 웹사이트 리뷰 위젯과 같은 건가요?

아니요. 평판 관리 대시보드 위젯은 내부 분석과 성과 모니터링용이에요. 웹사이트 리뷰 위젯은 웹사이트와 퍼널에서 고객 리뷰를 공개적으로 보여 주기 위한 위젯이에요.
