# 상품 상세 페이지 레이아웃 사용자 지정하기

상품 상세 페이지를 요소별로 나누어 배치하고 꾸미는 방법을 안내해요. 기존 스토어를 새 레이아웃으로 바꾸는 방법과, 저장해 둔 스토어 템플릿에 새 레이아웃을 반영하는 방법도 함께 다뤄요.

## 상품 상세 페이지 레이아웃 사용자 지정하기

이제 하이퍼클래스에서는 상품 상세 페이지를 고정된 블록 하나가 아니라 상품 요소 여러 개로 구성할 수 있어요. 각 상품 정보가 페이지의 어디에 나올지, 어떤 모양으로 보일지 요소마다 직접 정할 수 있어요.

상품 이미지, 제목, 리뷰, 가격, 옵션, 수량, **Add to Cart**(장바구니 담기), **Buy Now**(바로 구매), 설명, 관련 상품, 리뷰 같은 요소를 스토어에 맞게 자유롭게 옮길 수 있어요. 예를 들어 제목을 상품 이미지 위에 두거나, 리뷰를 페이지 위쪽으로 올리거나, 상품 상세 정보를 나란히 배치할 수 있어요.

요소마다 설정이 따로 있어서 글꼴, 색상, 간격, 정렬, 배경, 테두리, 모서리 둥글기, 그림자, 기기별 표시 여부도 요소별로 지정할 수 있어요.

기존 스토어는 업그레이드하기 전까지 기존(클래식) 상품 상세 레이아웃을 계속 쓸 수 있어요. 새 레이아웃(요소별 레이아웃)으로 바꾸면 기존에 적용해 둔 스타일 중 지원되는 것은 그대로 가져와요.

## 기존 스토어를 새 레이아웃으로 바꾸기

업그레이드는 되돌릴 수 없어요. 업그레이드 버튼으로는 이전 레이아웃으로 돌아갈 수 없고, 필요하면 **버전 기록**에서 이전에 저장한 버전으로 페이지를 복원할 수 있어요.

1. 빌더에서 스토어의 상품 상세정보 페이지를 엽니다.
2. **상품 상세** 요소를 선택합니다.
3. 오른쪽 패널에서 **Switch to new layout**(새 레이아웃으로 전환)을 클릭합니다.

기존 레이아웃에서 쓰던 커스텀 CSS 클래스는 업그레이드할 때 가져오지 않아요. 레이아웃을 바꾼 뒤에 각 요소에 커스텀 클래스를 다시 추가하세요.

## 저장된 스토어 템플릿 업데이트하기

저장해 둔 템플릿으로 새로 만드는 스토어에도 새 레이아웃을 쓰고 싶다면, 먼저 그 템플릿을 만든 스토어의 상품 상세정보 페이지를 업그레이드하세요.

페이지를 업그레이드한 뒤에는 **템플릿 라이브러리**에서 저장된 템플릿을 새로 고쳐서 업데이트된 레이아웃이 들어가게 하세요.

새로 고친 템플릿으로 만드는 새 스토어에는 새 상품 상세정보 페이지 레이아웃이 적용돼요. 이미 그 템플릿으로 만들어 둔 스토어는 자동으로 업데이트되지 않아요. 스토어마다 따로 업그레이드해야 해요.
