# 미팅룸 개요

미팅룸(Meeting Room)은 하이퍼클래스에 들어 있는 화상 회의 기능이에요. 고객 상담, 팀 미팅, 교육 세션 등에 쓸 수 있어요. 다시 쓸 수 있는 미팅 링크를 만들고, 바로 화상 통화를 시작하고, 녹화본·대화 기록·AI 미팅 요약을 한곳에서 볼 수 있어요.

{% hint style="warning" %}
미팅룸 기능은 Founder Plan($497)을 구독 중인 에이전시만 쓸 수 있어요. $97 또는 $297 플랜 사용자는 쓸 수 없어요.
{% endhint %}

## 미팅룸이란?

미팅룸을 쓰면 별도의 화상 회의 서비스 없이 하이퍼클래스 안에서 바로 화상 미팅을 열 수 있어요. 서브 계정의 **미팅룸** 메뉴에는 세 가지 영역이 있어요.

- **내 방**: 영구적으로 쓸 수 있는 링크가 있는 나만의 미팅룸을 만들고 관리해요.
- **팀 룸**: 팀원들의 미팅룸을 찾아 들어가요.
- **연동**: 미팅룸을 하이퍼클래스의 다른 기능과 연결해요.

캘린더 예약마다 고유한 미팅룸 링크를 만들 수도 있어요.

## 미팅룸의 주요 기능

### 화상 미팅과 협업

- **즉석 미팅**: 예약을 잡지 않고 바로 화상 통화를 시작해요.
- **게스트 입장**: 게스트 입장을 허용해 두면, 하이퍼클래스 계정이 없는 참가자도 미팅 링크로 초대할 수 있어요.
- **화면 공유와 채팅**: 미팅 중에 화면을 공유하고 대화를 나눠요.
- **상호작용 도구**: 반응 표시, 손 들기, 여러 가지 미팅 레이아웃을 쓸 수 있어요.
- **화면 속 화면(Picture-in-Picture)**: 브라우저 탭을 옮겨 다녀도 미팅 화면을 계속 볼 수 있어요.

### 미팅 관리와 보안

- **호스트·공동 호스트 제어**: 참가자, 미팅 권한, 호스트 역할을 관리해요.
- **대기실과 비밀번호**: 미팅에 들어올 수 있는 사람을 제어해요.
- **영상·음성 설정**: 카메라, 마이크, 배경, 조명, 소음 제거를 설정해요.

### 녹화, 대화 기록, AI

- **미팅 녹화**: 미팅을 녹화하고, 끝난 뒤 사용할 수 있는 녹화본을 확인해요.
- **발언자별 대화 기록**: 발언자 이름과 시간이 표시된 대화 기록을 볼 수 있어요.
- **AI 미팅 지원**: 미팅 중에 질문하고, 대화 기록을 바탕으로 요약, 주요 결정 사항, 실행 항목을 만들어요.

### 다국어 실시간 대화 기록

미팅룸은 다국어 실시간 대화 기록을 지원해서, 참가자들이 서로 다른 언어로 이야기해도 돼요. 실시간 대화 기록은 Deepgram Nova-3를 사용해요. 개별 언어 9개와 **Mixed Languages**(혼합 언어) 모드를 선택할 수 있어요.

#### Mixed Languages 모드

Mixed Languages 모드는 실시간 대화 기록 중에 지원되는 언어를 자동으로 감지해요. 대화 도중 참가자가 언어를 바꿔도 감지해요. Mixed Languages는 10개 언어를 지원하며, 이번에 새로 추가된 언어는 다음과 같아요.
- 네덜란드어
- 힌디어
- 러시아어
- 일본어

#### Mixed Languages 켜기

1. 미팅룸에서 미팅을 시작하세요.
2. 실시간 대화 기록을 시작할 때 대화 기록 언어로 **Mixed Languages**를 선택하세요.
3. 대화 기록을 시작하세요.

그러면 미팅룸이 대화 중에 지원되는 언어를 자동으로 인식해요.

{% hint style="info" %}
기존 실시간 대화 기록 방식은 그대로예요. 대화 기록을 시작할 때 원하는 언어를 계속 직접 선택할 수 있어요.
{% endhint %}

## 미팅룸 연동

미팅룸은 하이퍼클래스의 여러 기능과 함께 쓸 수 있어요.

| 연동 | 할 수 있는 일 |
| --- | --- |
| **캘린더** | 영구 미팅룸 링크를 쓰거나, 예약마다 고유한 링크를 만들어요. |
| **커뮤니티** | 라이브 토론과 커뮤니티 이벤트를 열어요. |
| **코스** | 코스에 라이브 미팅 세션을 추가해요. |
| **이벤트** | 미팅룸을 온라인 이벤트 장소로 써요. |
| **웨비나** | 라이브 웨비나를 미팅룸에 연결해요. |

이 옵션들은 **미팅룸 > 연동**에서 확인할 수 있어요.

## 내 미팅룸 만들기

다시 쓸 수 있는 영구 링크가 있는 개인 미팅룸을 만들어요.

1. 하이퍼클래스 서브 계정에서 **미팅룸 > 내 방**으로 이동하세요.
2. **Create room**(룸 만들기)을 클릭하세요.

   ![내 방 화면에서 룸 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084883287/original/vGTzE3d8CI6Twhu0a9_iHpnNdx5_C_FtxA.png?1793737540)
3. **Room details**(룸 상세 정보)에서 **이름**과 **Room link**(룸 링크)를 입력하세요.
4. **보안**에서 비밀번호, 대기실, 게스트 입장, 룸 이용 가능 시간을 필요에 맞게 설정하세요.

   ![보안 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084883288/original/yVYvBKELc9Earli4Va7C-6457dNZFroEbg.png?1793737540)
5. 필요하면 **Co-hosts**(공동 호스트)에서 공동 호스트를 추가하세요.
6. **변경사항 저장**을 클릭하세요. 이제 내 미팅룸을 쓸 수 있어요.

   ![저장 후 완성된 내 미팅룸](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083276195/original/4cwBPTKGlRSyKPK5B1ghFlyfPGmQ6WYq4g.png?1791968635)

## 즉석 미팅 시작하기

예약을 잡지 않고 언제든 미팅을 시작할 수 있어요.

1. **미팅룸 > 내 방**으로 이동하세요.
2. **Start room**(룸 시작)을 클릭하세요.
3. 마이크, 스피커, 카메라 설정을 확인하세요.
4. **Start now**(지금 시작)를 클릭해 미팅을 시작하세요.

참가자를 초대하려면 **내 방**에서 **Room link**를 복사해 공유하세요.

![내 방에서 즉석 미팅을 시작하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083275729/original/heMEMnRXs81PDdXSP2Khay843PmyJcLDMA.png?1791968421)

## 중요 참고 사항

- **Allow guest users**(게스트 사용자 허용)를 켜면 하이퍼클래스 계정이 없는 게스트도 미팅에 참가할 수 있어요.
- 사용자 지정 배경 업로드는 로그인한 사용자만 쓸 수 있어요.
- 미팅을 녹화해도 대화 기록이 자동으로 만들어지지는 않아요. 대화 기록을 바탕으로 하는 AI 기능을 쓰려면 미팅 중에 대화 기록을 켜야 해요.
