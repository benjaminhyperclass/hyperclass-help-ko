# 새 주문 폼 설정하고 꾸미기

새로 바뀐 **주문 폼**은 퍼널과 웹사이트에서 브랜드에 맞는 결제 화면을 유연하게 만들 수 있는 요소예요. 주문 폼 요소 하나로 한 단계, 두 단계, 분할 레이아웃을 오갈 수 있고, 연락처 커스텀 필드와 상품, 오더 범프, 디자인까지 한곳에서 설정해요. 이 문서에서는 새 주문 폼을 설정하고 꾸미는 방법과, 기존 주문 폼을 새 주문 폼으로 옮기는 방법을 알려 드려요.

## 새 주문 폼이란?

새 주문 폼은 고객 정보를 받고, 상품을 보여 주고, 결제까지 처리하는 통합 결제 요소예요. 예전에는 One-Step 요소와 Two-Step 요소를 따로 썼지만, 이제는 하나의 요소 안에서 레이아웃 세 가지 중 하나를 고르고 필요할 때 바꿀 수 있어요.

새 주문 폼에는 설정을 한곳에 모은 작업 공간이 있어요. 연락처 필드, 상품, 오더 범프, 결제 동작, 고객에게 보이는 문구, 디자인을 이 공간에서 함께 다뤄요. 설정 옆에 실시간 미리보기가 나타나서 패널을 계속 오가지 않고도 결제 폼을 꾸밀 수 있어요.

지원되는 CRM 커스텀 필드로 고객 정보를 더 받을 수 있고, 주문 폼과 오더 범프 각각에 전용 스타일 옵션을 적용할 수 있어요.

## 새 주문 폼의 장점

레이아웃, 필드 관리, 상품 설정, 디자인을 한 작업 공간에 모았어요. 그래서 폼을 처음부터 다시 만들지 않고도 결제 방식과 브랜드 느낌을 자유롭게 바꿀 수 있어요.

- 세 가지 결제 레이아웃: One-step, Two-step, Split 레이아웃을 오가도 기존 필드, 상품, 콘텐츠, 스타일 설정이 그대로 유지돼요.
- 통합 설정: 결제 설정, 고객에게 보이는 문구, 상품, 스타일을 실시간 미리보기와 함께 한곳에서 관리해요.
- CRM 커스텀 필드: 지원되는 CRM 커스텀 필드 유형으로 결제 단계에서 고객 정보를 더 받을 수 있어요.
- 다양한 스타일 옵션: 디자인 프리셋 6가지 중에서 고르고, 80개 이상의 스타일 속성을 브랜드에 맞게 조정할 수 있어요.
- 오더 범프 따로 꾸미기: 오더 범프 전용 프리셋과 세부 모양 설정으로 따로 디자인할 수 있어요.
- 유연한 상품 관리: 상품을 추가·관리하고, 수량 옵션을 조정하고, 상품 정보 표시와 쿠폰 사용 여부를 정할 수 있어요.
- 고객 화면 문구 수정: 필드 레이블, 플레이스홀더, 유효성 검사 메시지, 결제 버튼 등 고객에게 보이는 문구를 고칠 수 있어요.
- 선택형 기존 폼 이전: 조건이 맞는 기존 주문 폼을 새 주문 폼으로 바꿀 수 있어요. 다른 폼은 자동으로 바뀌지 않아요.

## 새 주문 폼 설정하기

설정을 제대로 해 두면 의도한 레이아웃으로 필요한 고객 정보를 받고, 알맞은 상품을 보여 주고, 일관된 결제 경험을 줄 수 있어요. 게시하기 전에 기능을 켜고, 주문 폼을 설정하고, 게시된 결제 화면을 직접 테스트하세요.

### 1. 새 주문 폼 기능 켜기

새 주문 폼은 실험실 기능 설정에서 켤 수 있어요. 에이전시 설정에서 진행하므로 에이전시 관리자가 해야 해요.

1. **에이전시 설정**으로 이동하세요.
2. **실험실**을 여세요.
3. **Brand New Order Forms with New Layouts and Custom Fields**(새로운 레이아웃과 커스텀 필드를 갖춘 새 주문 폼)를 검색하세요.
4. **기능 활성화**를 선택하세요.

   ![실험실에서 새 주문 폼 기능 활성화](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082952229/original/rmKlVwScHOZLNWWqIr91UkNxU2dOw5fNvQ.png?1791550150)

### 2. 페이지에 주문 폼 추가하기

1. 해당 서브 계정을 여세요.
2. **사이트 > 퍼널** 또는 웹사이트 빌더로 이동하세요.
3. 결제 페이지가 들어 있는 퍼널이나 웹사이트를 여세요.
4. 편집할 페이지를 선택하세요.

   ![편집할 페이지 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082952090/original/kzxPDAKeB1QCSTgHNNgrywjl7Eib6lJmgA.png?1791550076)
5. 페이지 빌더를 여세요.
6. **요소 추가**를 클릭하세요.
7. **주문 폼** 요소를 찾아 추가하세요.

   ![주문 폼 요소 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082952425/original/GOqWMRjHFtVjNnkl5wuK7lPp_udKn3hdow.png?1791550244)
8. 요소를 선택하고 **Customize order form**(주문 폼 사용자 지정)을 클릭하세요.

주문 폼 설정 작업 공간이 열려요. 여기서 결제 화면을 설정해요.

### 3. 결제 레이아웃 고르기

1. 주문 폼 설정 작업 공간에서 **단계**를 여세요.
2. 다음 레이아웃 중 하나를 선택하세요.

   - **One-step**(한 단계)
   - **Two-step**(두 단계)
   - **Split**(분할)
3. 실시간 미리보기에서 레이아웃을 확인하세요.
4. 결제 화면에 가장 잘 맞는 구성을 찾을 때까지 레이아웃을 바꿔 가며 확인하세요.

레이아웃을 바꿔도 설정해 둔 필드, 상품, 오더 범프, 콘텐츠, 스타일은 주문 폼에 그대로 유지돼요.

![결제 레이아웃 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082953823/original/z1_DYNBt6Hbw1roeGodDbEJ4FcyW-ONcNw.png?1791550940)

### 4. 연락처 필드 설정하기

1. **연락처 필드**를 여세요.
2. 표준 연락처 필드를 확인하세요.
3. 지원되는 필드는 필요에 따라 표시하거나 숨기세요.
4. 설정할 수 있는 필드는 필수 입력 여부를 정하세요.
5. 필드를 끌어서 순서를 바꾸세요.
6. 전체 너비 또는 절반 너비로 배치하세요.
7. 커스텀 필드 선택기에서 지원되는 CRM 커스텀 필드를 추가하세요.
8. 미리보기에서 바뀐 폼을 확인하세요.

전체 이름과 이메일은 항상 필수예요. 필요한 커스텀 필드가 CRM에 아직 없다면, 주문 폼에서 고르기 전에 **커스텀 필드** 설정에서 먼저 만드세요.

![연락처 필드 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082953579/original/tCP1sCZM-feO_FtRpqxi8wURJeMbeJr3Uw.png?1791550820)

### 5. 상품 설정하기

1. **상품**을 여세요.
2. 판매할 상품과 가격을 검색하세요.
3. 해당하는 상품을 추가하세요.
4. 상품 행을 확인하세요.
5. 필요하면 행을 편집하거나 복제하고, 순서를 바꾸거나 제거하세요.
6. 필요한 경우 여러 수량 선택을 켜세요.
7. 최대 수량 한도를 설정하세요.
8. 상품 이미지와 설명을 표시할지 정하세요.
9. 필요하면 여러 상품 선택을 설정하세요.
10. 고객이 사용할 수 있는 할인을 적용하게 하려면 쿠폰 입력을 켜세요.

![상품 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082953616/original/r27H_guB1JGwi3tQsNDJR-nhlMBXgixX7Q.png?1791550837)

{% hint style="warning" %}
**중요:** 퍼널 단계의 상품을 바꾸면 같은 단계에 있는 다른 주문 폼에도 영향을 줄 수 있어요. 변경하기 전에 기존 상품을 먼저 확인하세요.
{% endhint %}

### 6. 오더 범프 설정하기

오더 범프는 결제 중에 보여 주는 추가 구매 제안이에요.

1. **Order bump**(오더 범프)를 여세요.
2. 추가 구매로 제안할 상품을 설정하세요.
3. 오더 범프 헤드라인을 입력하세요.
4. **보조 텍스트 추가**에서 보조 문구를 입력하세요.
5. 필요하면 이미지를 따로 지정하세요.
6. 처음 선택된 상태로 둘지 정하세요.
7. 제공되는 범프 스타일 프리셋 중 하나를 고르세요.
8. 오더 범프 전용 스타일 설정으로 모양을 조정하세요.
9. 결제 미리보기에서 오더 범프를 확인하세요.

![오더 범프 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082953643/original/AHmFeeG-nv3ECdn2KcN-CyS056qZyO7fGw.png?1791550853)

### 7. 결제 옵션 설정하기

1. **Checkout options**(결제 옵션)를 여세요.
2. 제공되는 결제 동작 설정을 확인하세요.
3. 쿠폰, 이용약관 등 필요한 옵션을 설정하세요.
4. 설정이 만들려는 상품과 구매 경험에 맞는지 확인하세요.

게시하기 전에 설정을 꼼꼼히 살펴보세요. 특히 결제에 구독, 할인, 세금, 추가 구매 옵션이 들어 있다면 더 신경 써서 확인하세요.

![결제 옵션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082953713/original/Kqkf4IbGdFptVxiXzk_9ZH7pgBuc_LTlEA.png?1791550873)

### 8. 결제 화면 콘텐츠 꾸미기

1. **콘텐츠**를 여세요.
2. 단계별 헤드라인과 보조 텍스트를 편집하세요.
3. 필드 레이블과 플레이스홀더를 고치세요.
4. 유효성 검사 메시지를 수정하세요.
5. 상품 요약 레이블과 결제 관련 문구를 바꾸세요.
6. 결제 버튼 텍스트를 수정하세요.
7. Two-step을 쓴다면 단계 이동 레이블도 바꾸세요.
8. 미리보기에서 문구를 확인하세요.

고객이 결제의 각 단계를 이해할 수 있도록 짧고 분명한 문구를 쓰세요.

![결제 화면 콘텐츠 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082953739/original/hH3MESOrvSvHxN37GB82h2HxAK2rJTPFSA.png?1791550891)

### 9. 테마 적용하고 스타일 꾸미기

1. **Theme & style**(테마 및 스타일)을 여세요.
2. 테마 프리셋을 선택하세요.
3. 원하는 브랜드 색상을 설정하세요.
4. 타이포그래피와 입력창 스타일을 조정하세요.
5. 버튼, 상품 표시 방식, 단계 표시기를 꾸미세요.
6. 가능한 경우 기기별 크기, 간격, 정렬을 조정하세요.
7. 실시간 미리보기에서 모양을 확인하세요.
8. 오더 범프만 따로 조정하고 싶다면 오더 범프 스타일 설정으로 돌아가세요.

![테마와 스타일 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082953793/original/PmnbuPgGHOf4TkiudClEPYR2CdjKUfjADA.png?1791550914)

### 10. 저장, 게시, 테스트하기

1. **저장**을 클릭해 주문 폼 설정을 저장하세요.
2. **저장 및 게시**를 클릭해 결제 페이지를 게시하세요.
3. 게시된 페이지를 여세요.
4. 올바른 레이아웃이 표시되는지 확인하세요.
5. 표준 필드와 커스텀 필드가 의도한 대로 나타나는지 확인하세요.
6. 상품 선택, 가격, 수량 조절을 확인하세요.
7. 쿠폰과 오더 범프가 제대로 동작하는지 확인하세요.
8. 필수 필드 유효성 검사와 결제 단계 이동을 확인하세요.
9. 사용 중인 결제 제공업체가 지원하는 테스트 방식으로 결제를 테스트하세요.
10. 데스크톱과 모바일에서 결제 화면을 확인하세요.

{% hint style="warning" %}
**중요:** 빌더 미리보기는 결제 필드 대신 자리표시자를 쓰고 합계도 빌더 안에서 계산해요. 미리보기 금액만 믿지 말고, 반드시 게시된 결제 화면을 직접 확인하세요.
{% endhint %}

## 주문 폼 레이아웃

새 주문 폼에는 결제 경험에 맞춰 고를 수 있는 레이아웃이 세 가지 있어요. 고객이 구매를 마치는 흐름에 맞춰 연락처 정보, 결제 정보, 상품 요약을 어떻게 배치할지 정하면 돼요.

### One-step 레이아웃

One-step 레이아웃은 결제 과정을 한 화면에 보여 줘요. 고객은 단계를 넘어가지 않고 연락처 입력, 상품 확인, 결제를 모두 마칠 수 있어요.

구매 과정을 단순하게 유지하고 필요한 결제 정보를 한꺼번에 보여 주고 싶을 때 쓰기 좋아요.

### Two-step 레이아웃

Two-step 레이아웃은 결제를 두 단계로 나눠요.

- **1단계:** 고객의 연락처 정보를 받고 검증해요.
- **2단계:** 결제 단계를 보여 줘서 고객이 구매를 마칠 수 있어요.

첫 번째 단계에서 받은 연락처 정보는 결제 단계로 이어져요. 고객이 결제 전에 연락처부터 입력하게 하고 싶을 때 쓰기 좋아요.

### Split 레이아웃

Split 레이아웃은 결제 폼과 주문 요약을 좌우 두 열로 나란히 보여 줘요. 고객이 상품 정보를 보면서 폼을 작성할 수 있어요.

요소의 너비가 너무 좁아지면 열이 자동으로 위아래로 쌓여요.

{% hint style="warning" %}
**중요:** 주문 폼을 다시 만들지 않고 레이아웃을 바꿀 수 있어요. 레이아웃을 바꿔도 기존 필드, 상품, 오더 범프, 고객에게 보이는 콘텐츠, 스타일 설정이 그대로 이어져요.
{% endhint %}

## 연락처 필드와 CRM 커스텀 필드

연락처 필드는 결제 중에 어떤 고객 정보를 받을지 정해요. 새 주문 폼에서는 표준 연락처 필드를 원하는 대로 바꾸고, 지원되는 CRM 커스텀 필드를 추가해서 우리 비즈니스나 상품에 맞는 정보를 받을 수 있어요.

### 표준 연락처 필드

주문 폼은 표준 필드 9개를 지원해요.

- 전체 이름
- 이메일
- 전화번호
- 회사
- 주소
- 시/구/군
- 시/도
- 우편번호
- 국가

지원되는 표준 필드는 다음 옵션으로 배치와 표시 방식을 바꿀 수 있어요.

- 필드 표시 여부: 받고 싶은 정보에 맞게 필드를 표시하거나 숨겨요.
- 필수 필드: 지원되는 필드를 결제 시 필수 입력으로 만들어요.
- 필드 순서: 필드를 끌어서 폼에서의 위치를 정해요.
- 필드 너비: 폼 구성에 맞게 필드를 전체 너비나 절반 너비로 표시해요.

{% hint style="warning" %}
**중요:** 전체 이름과 이메일은 결제를 제출하는 데 꼭 필요해서 항상 필수예요.

주소 관련 필드는 스마트 주소 그룹으로 관리돼요. 사용할 수 있는 너비에 따라 배치가 자동으로 바뀌어요.
{% endhint %}

### CRM 커스텀 필드

CRM 커스텀 필드를 쓰면 표준 결제 필드로는 받을 수 없는 정보를 받을 수 있어요. 예를 들어 고객이 원하는 서비스 날짜, 추가 요청 사항, 구매하는 상품이나 서비스에 관한 정보를 받을 수 있어요.

주문 폼은 다음 유형의 CRM 커스텀 필드를 지원해요.

- 텍스트
- 숫자
- 전화번호
- 금액
- 긴 텍스트
- 날짜
- 선택형 필드(드롭다운 선택 등)- 파일 업로드
- 서명

커스텀 필드는 주문 폼 설정 작업 공간의 필드 선택기에서 추가해요. 미리 정해 둔 드롭다운 선택지 같은 커스텀 필드 설정은 계속 CRM에서 관리해요. 주문 폼은 그 설정을 가져와 고객에게 필드를 보여 줘요.

커스텀 필드를 만들거나 관리하는 방법은 [데이터 정리를 위한 커스텀 필드 만들기와 관리하기](../40-병합필드-변수/creating-and-managing-custom-fields-for-better-data-organization-008030.md) 문서를 참고하세요.

## 상품과 결제 옵션

상품 설정은 고객이 무엇을 살 수 있는지, 결제 중에 상품 정보를 어떻게 보여 줄지 정해요. 새 주문 폼은 기존 결제 기능을 그대로 유지하면서 상품 선택, 수량, 표시 옵션, 할인 입력을 설정할 수 있어요.

### 상품 관리

**상품** 설정에서 결제와 연결된 상품과 가격을 관리해요. 다음과 같은 설정을 쓸 수 있어요.

- 상품과 가격 검색 및 추가
- 기존 상품 행 편집
- 상품 행 복제
- 상품 순서 변경
- 상품 제거
- 고객이 여러 수량을 선택하도록 허용
- 허용되는 최대 수량 설정
- 상품 이미지 표시 또는 숨기기
- 상품 설명 표시 또는 숨기기
- 여러 상품 선택 켜기 또는 끄기

{% hint style="warning" %}
**중요:** 상품은 개별 주문 폼이 아니라 퍼널 단계와 연결돼요. 퍼널 단계에 연결된 상품을 바꾸면 그 단계에 있는 모든 주문 폼에 영향을 줄 수 있어요.
{% endhint %}

### 결제 옵션

결제 옵션은 고객이 폼을 사용하고 구매를 마치는 방식을 정해요. 새 주문 폼은 다음과 같은 결제 기능을 그대로 지원해요.

- **쿠폰 코드**
- 세금
- 기프트 카드
- 반복 가격
- **Sticky Contact**(고정 연락처)
- **이용약관**
- 구매 후 리디렉션

결제 설정에서 쿠폰 입력을 켜거나 끌 수도 있어요. 고객이 할인을 적용하게 하려면 하이퍼클래스에서 해당 쿠폰을 만들고 사용 조건을 설정하세요.

자세한 내용은 [쿠폰 시작하기](../08-결제/상품-세금-쿠폰/getting-started-with-coupons.md) 문서를 참고하세요.

## 오더 범프

오더 범프를 쓰면 결제 중에 추가 상품을 제안할 수 있어요. 새 주문 폼에는 오더 범프 전용 스타일 설정이 있어서, 기본 결제 폼의 스타일은 그대로 두고 오더 범프의 모양만 따로 바꿀 수 있어요.

자세한 내용은 [오더 범프 설정 방법](../06-사이트/폼/forms-how-to-setup-and-use-order-bumps.md) 문서를 참고하세요.

## 테마와 스타일

테마는 색상, 타이포그래피, 버튼, 입력창, 간격, 상품 표시 방식 등 주문 폼의 모양을 정해요. 새 스타일 시스템에서는 미리 만들어진 테마에서 출발해 결제 디자인을 더 세밀하게 조정할 수 있어요.

{% hint style="warning" %}
**중요:** 빌더 미리보기는 시각적으로 설정을 확인하는 용도예요. 결제 필드는 자리표시자로 표시되고 미리보기 합계는 빌더 안에서 계산돼요. 그래서 빌더 미리보기의 금액이 게시된 결제 화면의 금액과 다를 수 있어요.
{% endhint %}

## 주문 폼 콘텐츠 꾸미기

결제 화면 콘텐츠는 고객이 어떤 정보를 입력해야 하는지, 무엇을 구매하는지, 주문을 어떻게 마치는지 이해하도록 도와요. **콘텐츠** 설정에서는 별도의 코드 없이 고객에게 보이는 문구를 바꿀 수 있어요. 고객이 주문을 제출하기 전에 무엇이 필요한지 알 수 있도록 분명한 레이블과 짧은 안내 문구를 쓰세요.

## 기존 주문 폼 이전하기

기존 주문 폼은 이전하지 않아도 계속 동작해요. 새 주문 폼에는 조건에 맞는 기존 요소를 옮기는 선택형 이전 기능이 있어요. 기존 결제 설정을 유지하면서 요소를 하나씩 새 경험으로 바꿀 수 있어요.

### 이전 취소하기

이전은 한 번에 되돌릴 수 있는 작업이에요. 이전한 버전을 쓰지 않기로 했다면 빌더의 **Undo**(되돌리기)로 원래 요소를 복원할 수 있어요.

**커스텀 CSS 관련 유의사항**

커스텀 클래스와 커스텀 CSS는 이전할 때 그대로 유지돼요. 하지만 새 주문 폼은 내부 마크업이 달라요. 기존 폼 구조에 맞춰 작성한 커스텀 CSS 선택자는 이전한 요소와 맞지 않을 수 있어요. 이전한 뒤에는 커스텀 CSS를 확인하고 테스트해서 게시된 결제 화면이 제대로 보이는지 확인하세요.

{% hint style="warning" %}
**중요:** 이전은 선택 사항이며, 조건에 맞는 요소를 한 번에 하나씩 진행해요. 정해진 기한도 없어요. 이전하지 않은 주문 폼은 기존 설정 그대로 계속 동작해요.
{% endhint %}

## 자주 묻는 질문

### 새 주문 폼을 쓰려면 기존 주문 폼을 모두 이전해야 하나요?

아니요. 기존 주문 폼은 꼭 이전하지 않아도 계속 동작해요. 기존 요소는 그대로 두고 새 주문 폼을 만들 수 있어요.

### 일부 주문 폼만 이전하고 나머지는 그대로 둘 수 있나요?

네. 이전은 조건에 맞는 요소마다 따로 진행해요. 주문 폼 하나만 이전하고 나머지는 기존 설정 그대로 둘 수 있어요.

### 이전한 뒤 커스텀 CSS가 다르게 보여요. 어떻게 하나요?

새 주문 폼은 기존 요소와 마크업이 달라요. 커스텀 CSS와 커스텀 클래스가 이어지긴 하지만, 기존 마크업을 대상으로 한 선택자는 수정해야 할 수 있어요. 이전한 뒤 게시된 결제 화면을 확인하세요.

### 빌더 미리보기의 합계가 게시된 결제 화면과 달라요. 왜 그런가요?

빌더는 미리보기 합계를 빌더 안에서 계산하며, 실제 결제의 모든 계산을 그대로 재현하지는 않아요. 세금과 할인을 포함한 실제 가격은 게시된 결제 화면에서 확인하세요.

### 커스텀 드롭다운 필드의 선택지는 어디서 수정하나요?

CRM의 커스텀 필드 설정에서 선택지를 수정하세요. 주문 폼은 별도의 선택지를 두지 않고 CRM에서 옵션을 읽어 와요.

### 상품을 바꿨더니 같은 퍼널 단계의 다른 주문 폼에도 영향을 줬어요. 왜 그런가요?

상품은 특정 주문 폼 요소가 아니라 퍼널 단계와 연결돼 있어요. 그 단계의 상품을 바꾸면 연결된 모든 주문 폼에 영향을 줄 수 있어요.

### 오더 범프만 결제 화면의 나머지와 다르게 꾸밀 수 있나요?

네. 오더 범프에는 전용 스타일 설정과 프리셋이 있어서 메인 주문 폼과 따로 꾸밀 수 있어요.

### 빌더에서 새 주문 폼이 보이지 않아요.

**Brand New Order Forms with New Layouts and Custom Fields** 기능이 해당 서브 계정에 대해 **에이전시 설정 > 실험실**에서 활성화되어 있는지 확인하세요.

### Two-step에서 Split으로 바꾸면 설정해 둔 정보가 사라지나요?

아니요. 레이아웃을 바꿔도 주문 폼에 설정한 필드, 상품, 오더 범프, 고객에게 보이는 콘텐츠, 스타일이 그대로 유지돼요. 바꾼 뒤에는 새 레이아웃이 의도에 맞게 보이는지 확인하세요.
