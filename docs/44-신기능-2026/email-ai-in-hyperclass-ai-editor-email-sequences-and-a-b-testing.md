# 이메일 AI: AI 에디터, 이메일 시퀀스, A/B 테스트

하이퍼클래스는 이메일 AI 기능 세 가지를 제공해요. 이메일 AI 에디터(Email AI Editor), AI 이메일 시퀀스 만들기, AI 기반 A/B 테스트예요. 브랜드에 맞는 이메일을 만들고, 여러 단계의 이메일 흐름을 구성하고, 캠페인 성과를 높이는 일을 손이 덜 가게 도와줘요.

## 이메일 AI란?

이메일 AI는 이메일 마케팅에서 콘텐츠 생성, 편집, 시퀀스 구성, 성과 개선을 AI로 도와주는 기능이에요. 일상 언어로 지시하면 이메일을 만들고 다듬을 수 있어요. 이어지는 후속 이메일도 만들 수 있고, 여러 버전을 실험해 고객 반응을 높일 수도 있어요.

| 기능 | 설명 |
| --- | --- |
| 이메일 AI 에디터 | 대화하듯 AI에게 요청해서 이메일 콘텐츠와 디자인을 만들고 다듬어요. |
| AI로 이메일 시퀀스 만들기 | 프롬프트 하나와 커뮤니케이션 목표를 바탕으로 서로 이어지는 이메일 여러 통을 만들어요. |
| AI 기반 A/B 테스트 | 이메일 변형을 만들고 성과를 비교해서 더 효과적인 메시지를 찾아요. |

## 이메일 AI 에디터

이메일 AI 에디터에서는 대화하듯 요청하면서 이메일을 만들고 다듬을 수 있어요. 입력한 지시와 **브랜드 보드** 정보를 바탕으로 메시지와 시각적 아이덴티티에 맞는 이메일을 만들어 줘요. 요소를 하나하나 직접 고치지 않아도 내용과 디자인을 개선할 수 있어요.

| 기능 | 설명 |
| --- | --- |
| 대화형 이메일 편집 | 일상 언어로 요청해서 이메일 콘텐츠를 만들고 수정해요. |
| 브랜드 반영 콘텐츠 | 브랜드 보드의 색상, 글꼴, 스타일을 활용해 일관된 이메일 디자인을 만들어요. |
| AI 디자인 제안 | 레이아웃, 메시지, 시각 요소를 만들고 다듬어요. |
| 콘텐츠 다듬기 | 이어지는 요청으로 이메일 제목, 헤드라인, 본문, 콜투액션을 조정해요. |
| 빠른 반복 작업 | 이메일을 처음부터 다시 만들지 않고도 콘텐츠와 디자인을 여러 번 바꿀 수 있어요. |

예를 들어 이메일 AI에게 프로모션 이메일을 만들어 달라고 하거나, 내용을 줄이고, 말투를 바꾸고, 특정 혜택을 강조해 달라고 요청할 수 있어요. 만들어진 이메일은 계속 편집할 수 있어서 최종 디자인을 직접 다듬을 수 있어요.

자세한 사용법은 [Email AI(베타 2.0) — 브랜드에 맞는 이메일을 더 빠르게 만들기](../09-이메일/일반/email-ai-beta-2-0-create-on-brand-emails-faster.md)와 [이메일 캠페인/템플릿에서 브랜드 보드 사용하기](../10-마케팅/브랜드-보드/how-to-use-brand-boards-in-email-campaign-templates.md)를 참고하세요.

## AI로 이메일 시퀀스 만들기

AI 이메일 시퀀스는 커뮤니케이션 목표를 설명하는 프롬프트 하나로, 서로 이어지는 이메일 여러 통을 만드는 기능이에요. AI가 시퀀스 전체의 맥락을 살려 메시지를 만들어서, 리드 육성, 온보딩, 고객 참여를 위한 후속 이메일 흐름을 일관되게 만들기 쉬워요.

| 기능 | 설명 |
| --- | --- |
| AI 이메일 시퀀스 생성 | 목표를 설명하는 프롬프트 하나로 서로 관련된 이메일 여러 통을 만들어요. |
| 맥락을 살린 메시지 | 시퀀스 전체에서 주제를 일관되게 유지하고 메시지가 자연스럽게 이어지게 해요. |
| AI 콘텐츠 작성 지원 | 후속 이메일을 하나씩 직접 쓰는 수고를 줄여요. |
| 이메일 다듬기 | 생성된 이메일 내용을 검토하고 캠페인 목표에 맞게 수정해요. |
| 맞춤형 커뮤니케이션 | 대상, 커뮤니케이션 목표, 고객 여정에 맞는 시퀀스를 만들어요. |

시퀀스 기능의 전반적인 내용은 [하이퍼클래스 이메일 시퀀스](../10-마케팅/email-sequences-in-hyperclass.md)를 참고하세요.

### AI 이메일 시퀀스를 활용하는 대표적인 경우

AI가 만든 시퀀스는 첫 접점부터 지속적인 소통까지 고객 커뮤니케이션의 여러 단계에 쓸 수 있어요.

| 활용 사례 | 예시 |
| --- | --- |
| 리드 육성 | 서비스를 소개하고, 관련 정보를 공유하고, 잠재 고객이 행동하도록 유도해요. |
| 고객 온보딩 | 신규 고객을 환영하고, 중요한 기능이나 자료를 여러 통의 이메일로 나눠 소개해요. |
| 영업 후속 연락 | 문의나 첫 대화 이후에 이어지는 후속 메시지를 만들어요. |
| 고객 참여 | 교육 콘텐츠, 소식, 추천 정보를 공유해서 꾸준히 소통해요. |

예를 들어 이메일 4통짜리 온보딩 여정을 요청하는 프롬프트 하나로 환영 이메일, 기능 소개, 유용한 팁, 고객이 다음 단계로 넘어가도록 안내하는 마지막 메시지를 만들 수 있어요.

## AI 기반 A/B 테스트

AI 기반 A/B 테스트는 이메일의 다른 버전을 만들고, 대상 일부에게 보내 성과를 비교하는 기능이에요. AI가 만든 콘텐츠와 성과 기반 테스트를 함께 쓰면 수신자에게 더 잘 맞는 메시지를 찾을 수 있어요. 테스트용 버전을 여러 개 만드는 수고도 줄어요.

| 기능 | 설명 |
| --- | --- |
| AI 변형 생성 | 이메일 제목이나 이메일 콘텐츠의 대안을 여러 개 만들어요. |
| 제목 테스트 | 여러 제목을 비교해서 어느 쪽이 더 높은 반응을 얻는지 확인해요. |
| 이메일 콘텐츠 테스트 | 이메일 메시지, 레이아웃, 콜투액션을 비교해요. |
| 대상 분할 테스트 | 변형을 일부 대상에게 나눠 보내 성과를 측정해요. |
| 우승안 자동 선택 | 설정한 반응 지표에 따라 우승 변형을 선택해요. |

### A/B 테스트 옵션

하이퍼클래스의 이메일 캠페인 A/B 테스트에서는 변형 수, 대상 배분, 테스트 기간, 우승안 선택 방식을 설정할 수 있어요. 이 설정에 따라 변형을 어떻게 비교할지, 어떤 버전을 나머지 대상에게 보낼지가 정해져요.

| 설정 | 선택할 수 있는 옵션 |
| --- | --- |
| **테스트 유형** | **이메일 제목** 또는 **이메일 콘텐츠** |
| **Number of Variations**(변형 수) | 최대 6개 |
| **Test Duration**(테스트 기간) | 30분~24시간 |
| **Audience Distribution**(대상 배분) | 테스트 대상 비율 조정 가능 |
| **Winning Criteria**(우승 기준) | Unique Open Rate(고유 오픈율) 또는 Unique Click Rate(고유 클릭률) |
| **배송 옵션** | **Send Now**(지금 보내기) 또는 **일정** |

AI는 긴박감, 호기심, 특정 혜택 강조처럼 접근 방식이 다른 대안을 만들 수 있어요. 만들어진 변형은 선택한 A/B 테스트 기준으로 평가해요.

설정 방법은 [이메일 캠페인 A/B 테스트 설정하기](../09-이메일/기타/how-to-set-up-a-b-testing-for-your-email-campaigns.md)를 참고하세요.

{% hint style="warning" %}
일반 이메일 캠페인 A/B 테스트에는 전체 연락처가 최소 40명, 변형당 연락처가 최소 10명 필요해요. 이메일 제목과 이메일 콘텐츠는 따로 테스트해요. 선택한 우승 지표에서 반응이 기록되지 않으면 하이퍼클래스는 첫 번째 변형을 기본 우승안으로 선택해요.
{% endhint %}

## 자주 묻는 질문

### 이미 만든 이메일도 이메일 AI로 수정할 수 있나요?

네. 이메일 AI 편집을 지원하는 화면에서는 이미 만든 이메일도 대화하듯 요청해서 다듬을 수 있어요. 메시지와 디자인 모두 바꿀 수 있어요.

### 브랜드 보드를 바꾸면 이전에 만든 이메일도 자동으로 바뀌나요?

아니요. 이전에 만든 이메일은 직접 수정하지 않는 한 기존 스타일을 그대로 유지해요. 업데이트한 브랜드 보드 정보는 새 콘텐츠를 만들 때 사용할 수 있어요.

### 프롬프트 하나로 이메일 시퀀스 전체를 만들 수 있나요?

네. 목표, 대상, 원하는 커뮤니케이션 흐름을 설명한 프롬프트 하나로 서로 이어지는 이메일 여러 통을 만들 수 있어요.

### AI 이메일 시퀀스와 워크플로우 자동화는 같은 건가요?

아니요. 이메일 시퀀스는 이어지는 이메일 후속 연락에 초점을 두고 있어요. 워크플로우는 트리거, 액션, 여러 커뮤니케이션 채널을 아우르는 더 넓은 자동화를 지원해요.

### 한 번의 A/B 테스트로 이메일 제목과 이메일 콘텐츠를 함께 테스트할 수 있나요?

아니요. 문서에 안내된 이메일 캠페인 A/B 테스트는 한 번에 이메일 제목 테스트나 이메일 콘텐츠 테스트 중 하나만 지원해요.

### AI 기반 A/B 테스트를 쓰면 오픈율이나 클릭률이 반드시 올라가나요?

아니요. AI는 변형을 만들고 실험을 쉽게 도와줄 뿐이에요. 캠페인 성과는 대상과의 관련성, 이메일 콘텐츠, 전달률, 수신자 반응 같은 요소에 따라 달라져요.
