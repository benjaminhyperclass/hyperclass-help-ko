# App Studio로 AI와 함께 앱 만들고 테스트하고 게시하기

App Studio는 코딩 없이 하이퍼클래스 마켓플레이스 앱을 만들 수 있는 AI 앱 빌더예요. 만들고 싶은 앱을 말로 설명하면 프런트엔드, 백엔드, 데이터베이스, 호스팅, 연동까지 자동으로 만들어 줘요. 이 문서에서는 앱을 만들고, 서브 계정 데이터로 테스트하고, 설치 링크로 공유하는 방법을 안내해요.

채팅으로 앱을 고치고, 하이퍼클래스 서브 계정 데이터로 테스트한 뒤, 공유할 수 있는 설치 링크와 함께 게시할 수 있어요.

---

## App Studio란?

App Studio는 하이퍼클래스 **Developer Portal**(개발자 포털) 안에 있는 AI 앱 빌더예요. 일상적인 말로 쓴 요청을 실제로 동작하는 마켓플레이스 앱으로 바꿔 줘요. PostgreSQL 데이터베이스, OAuth, API 연동, 웹훅 같은 앱 인프라를 자동으로 처리하기 때문에 직접 개발해야 하는 작업이 많이 줄어요.

앱은 별도 로그인 없이 하이퍼클래스 서브 계정 안에서 바로 실행돼요. 처음부터 앱을 만들 수도 있고, 제안된 시작 프롬프트로 만들 수도 있어요. 대화로 앱을 다듬고, 변경 사항을 미리 보고, 지원되는 앱을 게시할 수 있어요.

![App Studio 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084143040/original/BEyhSZxVSZgFoWh2sj9dyNrhPs_nZaZK6g.png?1792936098)

## App Studio의 장점

App Studio에서는 앱 제작, 인프라 관리, 테스트, 게시를 한곳에서 AI와 함께 할 수 있어요. 맞춤 개발이 더 빠르고 쉬워져요.

- 코딩 없이 앱 만들기: 직접 코드를 쓰지 않고, 말로 설명해서 동작하는 앱을 만들어요.
- 빠른 개발: 프런트엔드 구성 요소, 백엔드 로직, 데이터베이스, 연동을 자동으로 만들어 줘요.
- 하이퍼클래스 기본 연동: 관리형 OAuth, 권한 범위(스코프), 웹훅으로 앱을 연락처, 기회, 예약 등 지원되는 CRM 데이터에 연결해요.
- 관리형 인프라: 기본 제공 호스팅, PostgreSQL 데이터베이스, 백엔드 서비스, 보안이 적용된 외부 API 연동을 쓸 수 있어요.
- 대화로 수정: AI 채팅으로 기능을 바꾸고, 목업 이미지를 첨부하고, 빌드 오류를 자동으로 찾아 고치게 할 수 있어요.
- 실시간 미리보기와 테스트: 변경 사항을 미리 보고, 하이퍼클래스 서브 계정에서 바로 앱을 테스트해요.
- 버전 관리와 개발자 도구: 저장된 빌드를 복원하고, 소스 코드를 내려받고, 데이터베이스 테이블과 환경 변수를 확인해요.
- 간편한 게시: 검증을 통과한 앱 버전을 게시하고, 하이퍼클래스 또는 그레이라벨 설치 링크로 배포해요.

## AI로 앱 만들기

App Studio는 글로 쓴 설명을 동작하는 앱으로 바꿔 줘요. 구성 요소를 하나하나 직접 설정하지 않아도 업무에 맞는 앱을 만들 수 있어요.

### 프롬프트로 앱 만들기

앱의 목적, 기능, 사용자, 필요한 하이퍼클래스 연동을 설명하세요. 제안된 시작 프롬프트를 골라도 돼요.

예를 들면 이렇게 입력할 수 있어요.

> 커스텀 필드 값에 따라 새 연락처를 영업 담당자에게 배정하는 리드 배정 앱을 만들어 줘. 라우팅 규칙, 배정된 사용자, 배정 기록을 보여 주는 대시보드도 넣어 줘.

그러면 App Studio가 필요한 화면, 데이터 모델, 연동, 백엔드 기능을 만들어 줘요.

활용 예시:

- 태양광 제안서: CRM 연락처, 부지 지도, 패널 수량, 시스템 가격으로 태양광 제안서를 만들어요.
- 리드 배정: 사용자 지정 규칙으로 리드를 배정하고 배정 결과를 확인해요.
- 견적 및 배차: 고객 요청, 견적, 작업 배정을 관리해요.
- 예약 및 접수: CRM 예약과 연결된 맞춤 접수 폼을 만들어요.
- 부동산: 부동산 리드를 수집하고 기회를 만들어요.
- 수업 예약: 등록, 예약, 멤버십 정보를 관리해요.

### 대화로 앱 수정하기

앱이 만들어지면 채팅창에서 변경을 요청하거나, 기능을 추가하거나, 문제를 해결할 수 있어요.

예를 들면 이렇게 입력할 수 있어요.

> 대시보드의 라우팅 로그에 일치한 커스텀 필드 값을 열로 보여 줘.

App Studio가 관련 구성 요소를 수정하고 바뀐 미리보기를 보여 줘요. 이미지나 목업을 첨부해서 디자인 방향을 알려 줄 수도 있어요. AI가 빌드 오류를 찾아 고쳐 보려고 시도하기도 해요.

## 하이퍼클래스 기본 연동

App Studio는 만들어진 앱을 하이퍼클래스 CRM 리소스에 연결해 줘요. 별도 시스템을 따로 운영하지 않아도 비즈니스 데이터를 활용한 맞춤 워크플로우를 만들 수 있어요.

지원하는 기능은 다음과 같아요.

- CRM 연결: 지원되는 연락처, 기회, 예약 등 CRM 리소스에 접근해요.
- OAuth 자동 구성: 앱 기능에 맞춰 지원되는 인증 방식, 필요한 권한 범위, 웹훅을 구성해요.
- 관리형 인프라: 자동 생성된 프런트엔드와 백엔드 구성 요소, PostgreSQL 데이터베이스, 기본 제공 호스팅을 사용해요.
- 외부 서비스 연동: 지원되는 외부 API를 연결하고, 환경 변수로 앱 설정을 관리해요.
- 서브 계정 안에서 바로 사용: 별도 앱 로그인 없이 하이퍼클래스 안에서 앱을 실행해요.

예를 들어 태양광 제안서 앱은 기존 연락처를 불러오고, 부지 위치를 지도에 표시하고, 제안서 내용을 계산할 수 있어요. 원하면 제안서를 파이프라인의 기회와 연결할 수도 있어요.

![하이퍼클래스 연동이 적용된 앱 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084143028/original/LZGG0PHmmb8Civ8dldXMy8VGDMyFY9nYIw.png?1792936033)

{% hint style="warning" %}
**중요:** App Studio가 지원되는 OAuth 연동을 자동으로 구성해 주지만, 앱을 설치할 때 요청되는 권한은 사용자가 직접 검토하고 승인해야 해요.
자세한 내용은 [API 보안 – 마켓플레이스 앱의 OAuth 동의](../27-앱-마켓/Get-Started-w/App-Marketplace/api-security-oauth-consent-for-marketplace-apps.md)를 참고하세요.
{% endhint %}

## 실시간 미리보기, 버전 기록, 개발자 도구

App Studio에는 만들어진 앱을 미리 보고, 테스트하고, 살펴보는 도구가 있어요. 게시 전에 기능을 확인하고, 필요하면 이전 빌드로 되돌릴 수 있어요.

**실시간 미리보기**와 테스트

- 앱 페이지, 대시보드, 폼, 동작을 미리 봐요.
- AI가 수정한 내용을 바로 확인해요.
- **Try it in Hyperclass**(하이퍼클래스에서 사용해 보기)로 선택한 서브 계정에서 테스트해요.
- 실제 CRM 데이터로 연동과 워크플로우를 확인해요.

**버전 기록**과 개발자 도구

- 앱 빌드가 자동으로 저장돼요.
- 필요할 때 이전 버전을 복원해요.
- 생성된 소스 코드를 확인하고 내려받아요.
- 데이터베이스 테이블과 환경 변수를 확인해요.

{% hint style="warning" %}
**중요:** 테스트에는 실제 하이퍼클래스 CRM 데이터가 사용돼요. 가능하면 테스트 전용 서브 계정을 쓰세요. 특히 레코드를 만들거나 수정하거나 삭제하는 앱을 테스트할 때 더 그래요.
{% endhint %}

## 앱 게시와 배포

App Studio는 버전 만들기, 검증, 설치 링크 공유까지 안내해 줘서 마켓플레이스 게시가 간단해요. 지원되는 마켓플레이스 설정, 권한 범위, 웹훅은 앱이 바뀔 때마다 함께 동기화돼요.

게시 기능은 다음과 같아요.

- 릴리스 노트와 함께 앱 버전을 게시해요.
- 게시 전에 검증 검사를 실행해요.
- 게시되지 않은 변경 사항과 게시된 버전을 관리해요.
- 하이퍼클래스 설치 링크와 그레이라벨 설치 링크를 만들어요.
- 대상이 되는 하이퍼클래스 서브 계정에 앱을 공유해요.

{% hint style="warning" %}
**중요:** App Studio 초기 버전은 비공개 서브 계정 앱만 지원해요. 에이전시 단위 앱은 이후 버전에서 지원할 예정이에요.
자세한 내용은 [마켓플레이스 앱 배분 유형](../35-개발자/Developer-Resources/marketplace-app-distribution-type.md)을 참고하세요.
{% endhint %}

## App Studio 제공 범위와 사용 제한

App Studio는 먼저 자격이 되는 개발자에게 [실험실](../19-에이전시-뷰/Agency-Settings/labs-features-complete-overview.md)을 통해 제공돼요. 현재 제한을 알아 두면 앱을 만들거나 테스트할 때 작업이 끊기지 않도록 계획할 수 있어요.

| 항목 | 현재 제공 범위 또는 제한 |
| --- | --- |
| 이용 방법 | 실험실을 통한 얼리 액세스 |
| 앱 유형 | 비공개 서브 계정 앱 |
| 사용량 집계 | 5시간 롤링 윈도우 기준, 팀 단위 사용량 |
| 사용량 확인 | 사용량과 초기화 정보 확인 가능 |
| 동시 빌드 | 한 번에 1개 |
| 메시지 길이 | 최대 16,000자 |
| 이미지 첨부 | 메시지당 최대 5장, 장당 5MB |
| 실행 방식 | 요청 및 웹훅 기반 |
| 예약 작업/백그라운드 작업 | 아직 지원하지 않음 |

곧 출시 예정인 기능이에요.

- 에이전시 단위 앱
- 클라이언트 리포팅 시작 앱
- 예약 작업 및 백그라운드 작업

## App Studio 설정하고 사용하기

App Studio를 켜고, 프롬프트로 앱을 만들고, 기능을 다듬고, 하이퍼클래스 안에서 테스트한 뒤 버전을 게시하는 순서로 진행해요. 이 순서를 따르면 설치 링크를 공유하기 전에 앱이 제대로 동작하는지 확인할 수 있어요.

### 1단계: App Studio 켜고 열기

1. 하이퍼클래스 **Developer Portal**(개발자 포털)을 열어요.
2. App Studio가 보이지 않으면 **Profile Menu**(프로필 메뉴) > **실험실**로 이동해서 App Studio를 켜세요. 자격이 되는 경우에만 켤 수 있어요.
3. **My Apps**(내 앱) > **Create App**(앱 만들기)으로 이동해요.
4. **Build with App Studio**(App Studio로 빌드)를 선택해요.

![App Studio로 빌드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084143080/original/TLYJwN-0KwKpV22wf_SKSY9lPJphcaJCsQ.png?1792936237)

### 2단계: 앱 설명하고 빌드하기

1. 앱의 목적, 필요한 기능, 하이퍼클래스 연동을 설명하는 프롬프트를 입력하세요. 시작 아이디어를 골라도 돼요.
2. 필요하면 목업이나 참고 이미지를 첨부해요.
3. **빌드**를 클릭해요.
4. 만들어진 앱을 실시간 미리보기에서 확인해요.

프롬프트 예시:

> 하이퍼클래스 연락처를 불러오고, 부지 위치를 지도에 표시하고, 패널 수량과 시스템 가격을 입력받아 고객 제안서를 저장하는 태양광 제안서 앱을 만들어 줘. 원하면 파이프라인 기회도 만들 수 있게 해 줘.

### 3단계: 앱 수정하기

1. 채팅 패널에 추가 요청을 입력해요.
2. 기능 추가, 디자인 변경, 버그 수정을 요청해요.
3. AI가 수정한 내용을 확인해요.
4. 변경 사항을 테스트하고 앱을 계속 다듬어요.

예를 들면 이렇게 입력할 수 있어요.

> 저장된 제안서, 고객 이름, 시스템 가격, 제안서 상태를 보여 주는 대시보드를 추가해 줘.

### 4단계: 하이퍼클래스에서 앱 테스트하기

1. 앱 미리보기를 확인해요.
2. **Try it in Hyperclass**를 클릭해요.
3. 테스트에 사용할 **서브 계정 선택** 화면에서 서브 계정을 골라요.
4. 필요한 승인 절차를 완료해요.
5. 폼, 화면 이동, CRM 연동, 레코드 생성·수정을 테스트해요.
6. 수정이 필요하면 App Studio로 돌아가서 고쳐요.

{% hint style="warning" %}
**중요:** 실제 운영 중인 CRM 레코드가 의도치 않게 바뀌지 않도록 테스트 전용 서브 계정을 사용하세요.
{% endhint %}

### 5단계: 앱 게시하고 공유하기

1. 앱이 제대로 동작하는지 확인해요.
2. **게시**를 클릭해요.
3. 검증 결과를 확인하고, 문제가 있으면 해결해요.
4. 요청이 나오면 릴리스 노트를 추가해요.
5. 앱 버전을 게시해요.
6. **공유**를 클릭하고 하이퍼클래스 설치 링크 또는 그레이라벨 설치 링크를 선택해요.
7. 링크를 복사해서 대상 사용자에게 공유해요.

링크를 받은 사용자는 설치 링크를 열고 필요한 승인 절차를 마치면 돼요.

## 자주 묻는 질문

### App Studio를 쓰려면 코딩 경험이 필요한가요?

아니요. App Studio는 말로 쓴 지시를 바탕으로 앱을 만들어 줘요. 필요하면 개발자가 소스 코드를 확인하거나 내려받을 수도 있어요.

### App Studio와 AI 스튜디오는 같은 건가요?

아니요. App Studio는 Developer Portal에서 마켓플레이스와 연동되는 앱을 만드는 도구예요. [AI 스튜디오](../13-AI-Employee/ai-studio-in-hyperclass.md)는 하이퍼클래스의 별도 제품으로, 만들기와 게시 과정이 따로 있어요.

### 에이전시 단위 앱이나 공개 마켓플레이스 앱도 만들 수 있나요?

초기 버전은 비공개 서브 계정 앱만 지원해요. 에이전시 단위 앱은 이후 버전에서 지원할 예정이에요.

### 사용 한도에 도달하면 어떻게 되나요?

App Studio에는 5시간 롤링 윈도우 기준의 팀 단위 사용량과 초기화 정보가 표시돼요. 표시된 초기화 정보를 확인하면 추가 사용이 가능해지는 시점을 알 수 있어요.

### 빌드를 동시에 여러 개 실행할 수 있나요?

아니요. 초기 버전은 한 번에 1개의 빌드만 지원해요.

### App Studio에서 예약 작업이나 백그라운드 작업을 실행할 수 있나요?

아직은 안 돼요. 초기 버전은 요청 및 웹훅 기반 실행만 지원해요.

### 이전 버전으로 복원하거나 앱 코드를 내려받을 수 있나요?

네. App Studio는 빌드를 자동으로 저장하고, 이전 버전 복원과 소스 코드 다운로드를 지원해요.

### 테스트할 때 실제 하이퍼클래스 CRM 데이터가 사용되나요?

네. 테스트에는 선택한 서브 계정의 데이터가 사용돼요. 테스트 전용 서브 계정을 쓰는 것을 권장해요.

### Developer Portal에 App Studio가 보이지 않아요.

App Studio는 먼저 자격이 되는 개발자에게 실험실을 통해 제공돼요. 사용 자격이 되는지, 그리고 실험실 설정이 맞게 되어 있는지 확인하세요.
