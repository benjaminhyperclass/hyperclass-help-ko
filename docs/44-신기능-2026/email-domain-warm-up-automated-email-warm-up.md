# 이메일 도메인 워밍업 — 자동 이메일 워밍업 (베타)

전용 발송 도메인의 발신자 평판을 자동으로 쌓아서, 받은편지함에 안전하게 도착하는 비율을 높여 주는 기능이에요. 하이퍼클래스의 자동 도메인 워밍업이 어떻게 작동하는지, 베타 사용 신청부터 워밍업 설정, 리포트 보는 법, 일시정지·정지 방법까지 설명해요.

도메인 워밍업은 하루 이메일 발송량을 조금씩 늘려서 Gmail, Outlook, Yahoo 같은 메일 서비스에 신뢰할 수 있는 발신자로 인정받는 과정이에요.

{% hint style="info" %}
이메일 도메인 워밍업은 지금 승인된 베타 사용자에게 무료로 제공돼요. 베타 기간이 끝난 뒤의 요금은 아직 정해지지 않았어요.
{% endhint %}

## 도메인 워밍업이 필요한 이유

메일 서비스는 갑자기 많은 양을 보내기 시작하는 도메인을 경계해요. 워밍업 없이 새 도메인으로 대량 발송하면 이런 문제가 생길 가능성이 높아요.

- 스팸으로 분류돼요.
- 반송률이나 스팸 신고율이 높아져요.
- 이메일 전달이 막히거나 늦어져요.

{% hint style="info" %}
하이퍼클래스가 이 과정을 자동으로 처리해요. 발송량을 직접 조절하지 않아도 메일 서비스의 신뢰를 쌓고 전달률을 높일 수 있어요.
{% endhint %}

## 자동 이메일 워밍업은 이렇게 작동해요

이메일 도메인 워밍업은 완전 자동이에요. 직접 메일을 보내면서 발송량을 늘리는 대신, 하이퍼클래스가 내 도메인에 워밍업 전용 메일함을 만들어 다음 작업을 해요.

- 하루 발송량을 조금씩 늘려요. 선택한 일일 목표를 향해 단계적으로 올라가요.
- 자연스러운 대화를 주고받아요. 이메일이 실제 주고받는 메일처럼 보이고 동작해요.
- 같은 스레드 안에서 답장을 보내요. 실제와 같은 주고받기 흐름을 만들어요.
- 이메일을 중요 표시해요. 메일 서비스에 긍정적인 신호를 보내요.
- 스팸함에 들어간 메일을 꺼내요. 스팸함에 들어간 워밍업 메일을 되살려요("Saved from spam").
- 꾸준히 반응을 유지해요. 시간이 지나도 평판이 좋은 상태로 유지돼요.

이런 신호가 쌓이면 Gmail, Outlook, Yahoo 등에서 발신자 평판이 높아지고, 시간이 지나면서 받은편지함 도착률도 좋아져요.

## 누가 쓸 수 있고, 워밍업은 언제 시작되나요?

### 사용 대상

에이전시와 서브 계정 모두 전용 발송 도메인에서 이메일 워밍업을 쓸 수 있어요.

### 기존 도메인

기존 도메인은 워밍업을 직접 켜야 해요. 기존 도메인에서 워밍업을 켜면, 시스템이 과거 이메일 발송 기록과 Google Postmaster 평판 데이터(연동한 경우)를 자동으로 분석해서 워밍업 계획을 세워요.

### 사전 조건

워밍업을 시작하려면 도메인이 인증되어 있어야 하고, SSL 인증서도 발급되어 있어야 해요. 인증되지 않은 도메인에는 **Start warm-up**(워밍업 시작) 버튼 대신 "Verify the domain and wait for its SSL certificate before starting warm-up"(도메인을 인증하고 SSL 인증서가 발급될 때까지 기다린 뒤 워밍업을 시작하세요)이라는 안내가 보여요.

## 이메일 워밍업 사용 신청하기 (베타)

이메일 워밍업은 지금 베타 단계예요. 사용하려면 아래 폼으로 신청하세요. 신청이 승인되고 내 계정에서 기능이 켜지면, 전용 도메인 카드에 **Start warm-up** 옵션이 나타나요.

[이메일 워밍업 사용 신청하기 →](https://api.leadconnectorhq.com/widget/form/IXjYTSgn4H9KZzPFwstY?notrack=true)

{% hint style="info" %}
계정에서 이메일 워밍업이 켜지면, 지금 전용 도메인에 표시되는 일일 발송 한도 단계 상향이 사라져요. 그 대신 자동 워밍업이 발신자 평판을 쌓아 줘요.
{% endhint %}

## 도메인 워밍업 켜기

클릭 몇 번이면 워밍업을 시작할 수 있어요. 일일 목표만 고르면 메일함 생성, 발송량 증가, 반응 유지는 하이퍼클래스가 알아서 처리해요.

1. 전용 도메인 설정을 열어요. **에이전시 설정** 또는 **서브 계정 설정** > **이메일 서비스** > **SMTP 서비스**로 이동한 뒤 **Dedicated Domain and IP**(전용 도메인 및 IP) 탭을 열어요. 먼저 내 계정에서 이메일 워밍업이 켜져 있어야 해요. 위의 '이메일 워밍업 사용 신청하기 (베타)'를 참고하세요.
2. 도메인 카드를 찾아 **Domain Warm-Up**(도메인 워밍업) 아래의 **Start warm-up**을 클릭해요. 도메인 이름이 붙은 **Warm up** 팝업이 열려요.

   ![워밍업 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083160527/original/LVU4JZIsPaxp298YykTonGcUUhOo1GtD8Q.png?1791874404)

3. 일일 목표를 골라요. **Daily goal**(일일 목표) 아래에서 **변경**을 클릭하고, **Daily warm-up limit**(일일 워밍업 한도) 드롭다운에서 발송량을 선택해요(예: 하루 10,000통 또는 25,000통). 그다음 **완료**를 클릭해요. 발송량은 이 수치까지 조금씩 늘어나요. 매일 이 양을 보내 준다는 뜻은 아니에요.

   {% hint style="info" %}
   일일 워밍업 목표는 자동 워밍업 이메일의 최대 목표 발송량이에요. 평소 캠페인 이메일의 발송 한도가 아니에요. 워밍업 발송량은 선택한 목표를 향해 조금씩 늘어나며, 매일 그 양에 도달하는 것은 아니에요.

   워밍업이 진행되는 동안에도 캠페인과 워크플로우 이메일을 계속 보낼 수 있어요. 단, 적용되는 발송 한도는 그대로 따라요.
   {% endhint %}

   ![일일 목표 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083160579/original/wkCf7cBmCfu9OX-rQYsi17IiMU49g6pdOQ.png?1791874438)

4. 워밍업 메일함을 확인해요. 선택한 발송량에 맞춰 하이퍼클래스가 필요한 수만큼 워밍업 메일함을 만들어요. 예를 들어 하루 25,000통을 목표로 하면 메일함 5개를 만들고, 메일함마다 하루 5,000통까지 보낼 수 있어요. 이 메일함은 워밍업용으로 하이퍼클래스가 만들고 관리해요. 고객의 받은편지함이 아니에요.
5. **Start warm-up**을 클릭해서 확정해요. 도메인 카드의 **Domain Warm-Up** 배지가 **Warming up**(워밍업 중)으로 바뀌어요.

{% hint style="info" %}
워밍업이 진행되는 동안에도 평소처럼 이메일을 보낼 수 있어요. 워밍업은 일시정지하거나 정지할 때까지 함께 계속돼요.
{% endhint %}

{% hint style="info" %}
이미 등록된 도메인이면 **"Warm-Up is already set up"**(워밍업이 이미 설정되어 있어요)이라는 메시지가 보여요. **완료**를 클릭하고, 도메인 카드에서 해당 도메인의 리포트를 열어 보세요.
{% endhint %}

## 도메인 워밍업 리포트

### 도메인 카드 요약

워밍업을 켜면 도메인 카드마다 워밍업 성과가 한눈에 보여요. **Health score**(상태 점수, 0~100), **전달률**(받은편지함 도착률), 일일 목표 대비 **Sent today**(오늘 발송량)가 표시돼요.

![도메인 카드 요약](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083160641/original/r2bqfn1pqIwR_bHyd4jPg03L5rMxG1wzDQ.png?1791874501)

### 상세 리포트

도메인 카드에서 **View report**(리포트 보기)를 클릭하면 전체 **Domain warm-up** 페이지가 열려요.

| 리포트 항목 | 보여 주는 내용 |
| --- | --- |
| **Domain health score**(도메인 상태 점수) | 이 도메인의 전반적인 상태를 0~100 점수로 보여 줘요. |
| **전달률** | 워밍업 이메일의 받은편지함 도착률이에요. |
| **Sent today** | 오늘 보낸 워밍업 이메일 수와 일일 목표까지의 진행 상황이에요. |
| **DNS 레코드** | SPF, DKIM, DMARC, MX 레코드의 상태예요(초록 = 설정됨, 빨강 = 없거나 올바르지 않음). |
| **Warm-Up performance**(워밍업 성과) | "Landed in inbox"(받은편지함에 도착) 차트예요. **인박스**로 전달된 메일과 **Saved from spam**(스팸함에서 구조됨)을 비교해서 보여 주고, 기간별(예: Week)로 필터링할 수 있어요. |
| **Warm-Up mailboxes**(워밍업 메일함) | 워밍업 메일함별 발신자 이름, 상태, 전달률, 오늘 발송량과 일일 발송 한도를 보여 줘요. |

![상세 리포트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083160622/original/wIs-TFonm4OmqOHS2_6oWJ-ulzsTUmlWDw.png?1791874476)

### 메일함 리포트

워밍업 메일함 하나만 자세히 볼 수 있어요. 워밍업 메일함의 발신자 이름을 바꾸려면 메일함 옆의 **View report**를 클릭한 뒤 **Update mailbox**(메일함 업데이트)를 선택하세요. 지금은 발신자 이름만 편집할 수 있어요. 그 밖의 메일함 설정 옵션은 이후 업데이트에서 추가될 예정이에요.

![메일함 리포트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083160674/original/ZJwmgBBufwUObVoldz6K634cObqc3zdfrA.png?1791874529)

## 워밍업 성과 읽는 법

워밍업 리포트로 전용 도메인의 상태를 확인하고, 이메일 전달에 영향을 줄 수 있는 문제를 찾아낼 수 있어요. 지표를 자주 살펴보면 워밍업이 받은편지함 도착률을 높이고 있는지, 도메인 인증이 제대로 설정되어 있는지 파악할 수 있어요.

- **Domain Health Score**: 전달률, 발신자 평판, DNS 설정을 바탕으로 한 0~100점의 점수예요.
- **전달률**: 수신자의 받은편지함에 도착한 워밍업 이메일의 비율이에요.
- **Sent Today**: 오늘 보낸 워밍업 이메일 수를 선택한 일일 워밍업 목표와 비교해서 보여 줘요.
- **Saved from Spam**: 자동 반응 작업의 하나로 스팸함에서 꺼낸 워밍업 이메일이에요.
- **DNS 레코드**: SPF, DKIM, DMARC, MX 레코드의 설정 상태예요. 레코드가 없거나 올바르지 않으면 도메인 상태와 전달률에 나쁜 영향을 줄 수 있어요.

{% hint style="info" %}
워밍업을 켠 뒤 결과가 나타나기까지 하루나 이틀 걸릴 수 있어요. 새로 활성화한 도메인에 발송 수가 0이거나 전달률 데이터가 없다고 해서 꼭 문제가 있는 것은 아니에요.
{% endhint %}

## 도메인 워밍업 일시정지·정지하기

1. 도메인 카드의 점 세 개(…)를 클릭해요.
2. **Pause warm-up**(워밍업 일시정지) 또는 **Stop warm-up**(워밍업 정지)을 선택해요.

![워밍업 일시정지·정지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083160695/original/cPOrMHXP5VG6wH216HZ7QSn-jMxA5Dny9Q.png?1791874556)

{% hint style="info" %}
잠시 쉬고 싶을 때는 **일시정지**를, 해당 도메인의 워밍업을 끝내고 싶을 때는 **정지**를 쓰세요. 중간에 정지하면 특히 새 도메인에서 평판이 쌓이는 속도가 느려질 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 도메인 워밍업 중에도 캠페인 이메일을 보낼 수 있나요?
네. 캠페인, 워크플로우 등 다른 이메일을 평소처럼 계속 보낼 수 있어요. 워밍업은 일시정지하거나 정지할 때까지 함께 진행돼요.

### 워밍업 메일함은 고객의 받은편지함인가요?
아니요. 워밍업 메일함(예: team1@yourdomain.com)은 하이퍼클래스가 워밍업만을 위해 만들고 관리하는 가상의 계정이에요. 내 연락처는 워밍업 이메일을 받지 않아요.

### 도메인 워밍업은 누가 쓸 수 있나요?
에이전시와 서브 계정 모두 **설정 > 이메일 서비스 > SMTP 서비스 > Dedicated Domain and IP**에서 **전용 발송 도메인**의 워밍업을 켤 수 있어요.

### 이메일 워밍업을 쓰려면 어떻게 해야 하나요?
이메일 워밍업은 베타 단계예요. [이메일 워밍업 사용 신청 폼](https://api.leadconnectorhq.com/widget/form/IXjYTSgn4H9KZzPFwstY?notrack=true)으로 신청하세요. 기능이 켜지면 전용 도메인 카드에 **Start warm-up**이 보여요.

### 지금 쓰는 일일 발송 한도 단계 상향은 어떻게 되나요?
계정에서 이메일 워밍업이 켜지면, 전용 도메인에 표시되던 일일 발송 한도 단계 상향이 사라져요.

### 도메인에 Start warm-up 버튼이 안 보여요.
먼저 도메인이 인증되어 있고 SSL 인증서가 발급되어 있어야 해요. 도메인 카드의 **지금 인증하기**(또는 점 세 개 메뉴의 **도메인 인증**)를 사용하고, SSL 상태가 **SSL Issued**(SSL 발급됨)로 바뀔 때까지 기다린 뒤 워밍업을 시작하세요.

### 첫날부터 일일 목표만큼 보내나요?
아니요. 적은 양으로 시작해서 선택한 일일 목표까지 조금씩 늘려 가요. 목표는 상한선이고, 매일 보장되는 발송량이 아니에요.

### 워밍업 메일함은 몇 개 만들어지나요?
선택한 일일 목표에 따라 달라요. 확정하기 전에 팝업에서 메일함 수를 보여 줘요. 예를 들어 하루 25,000통 목표면 메일함 5개를 만들고, 메일함마다 하루 5,000통까지 보낼 수 있어요.

### 리포트에 전달률 0%, 오늘 발송 0건으로 나와요. 문제가 있는 건가요?
꼭 그렇지는 않아요. 워밍업을 막 시작했거나 하루 중 이른 시간이면 지표가 아직 0일 수 있어요. 워밍업 이메일이 발송되고 반응이 기록되면서 데이터가 채워져요. 하루나 이틀 뒤에 다시 확인해 보세요.

### "Warm-Up is already set up"은 무슨 뜻인가요?
해당 도메인이 이미 워밍업에 등록되어 있다는 뜻이에요. **완료**를 클릭한 뒤, 도메인 카드의 **View report**로 리포트를 열어 보세요.

### 리포트에서 DNS 레코드 일부가 빨간색이에요. 어떻게 해야 하나요?
빨간색 레코드(예: DMARC 또는 MX)는 없거나 올바르게 설정되지 않았다는 뜻이에요. DNS 제공업체에서 추가하거나 고치세요. SPF, DKIM, DMARC, MX 설정을 모두 마치면 도메인 상태 점수와 전달률이 좋아져요.

### 워밍업 메일함의 발신자 이름을 바꿀 수 있나요?
네. 도메인 워밍업 리포트에서 **View report**로 메일함을 열고, **Update mailbox**를 클릭해서 정보를 편집하세요.

### 워밍업을 쓰려면 Google Postmaster Tools가 꼭 필요한가요?
아니요, 필수는 아니지만 연동하면 좋아요. 연동하면 기존 도메인에서 워밍업을 켤 때 Postmaster 평판 데이터를 활용하고, 스팸률·인증·전달 오류도 더 자세히 볼 수 있어요.
