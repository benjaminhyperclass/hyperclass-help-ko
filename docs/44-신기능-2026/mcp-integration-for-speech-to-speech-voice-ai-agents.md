# S2S 음성 AI 에이전트의 MCP 연동

MCP(Model Context Protocol)를 쓰면 음성 AI 에이전트가 통화 중에 연결된 앱의 도구를 사용할 수 있어요. 음성 대 음성(Speech-to-Speech, S2S) 에이전트는 Google Calendar, Notion 같은 MCP 앱에서 정보를 가져오거나 작업을 실행해요. 이미 연결해 둔 앱을 다시 쓰거나, MCP 카탈로그에서 앱을 고르거나, 직접 만든 서버를 연결할 수 있어요. 이 문서에서는 음성 AI에서 MCP 서버를 설정하고, 테스트하고, 관리하는 방법을 안내해요.

# MCP 서버란 무엇인가요?

MCP 서버는 S2S 음성 AI 에이전트를 외부 앱과 이어 줘요. 에이전트가 통화 중에 정보를 가져오거나 지원되는 작업을 실행할 수 있어요.

예를 들어 병원의 음성 AI 상담원이 Google Calendar에서 예약 가능한 시간을 확인하고, 통화 중에 그 결과를 알려 줄 수 있어요.

에이전트는 회원님이 선택한 도구와, 연결된 앱에 허용된 권한 범위 안에서만 동작해요.

---

## 음성 AI의 MCP 연결 이해하기

S2S 음성 AI 빌더에서 **작업**, **지식 베이스**와 나란히 **MCP Servers**(MCP 서버) 패널이 보여요.

MCP 앱은 세 가지 방법으로 연결할 수 있어요.

- 기존 연결: 하이퍼클래스에 이미 연결된 MCP 앱 중 사용할 수 있는 앱을 다시 써요.
- 카탈로그 앱: 목록에서 앱을 고르고 계정을 승인해요.
- 사용자 지정 MCP: 호환되는 MCP 서버의 이름과 URL을 입력해요.

연결된 서버마다 연결 상태, 도구 수, **When to use**(사용 시점) 입력란이 표시돼요.

*![MCP 서버 패널에 표시된 연결 상태, 도구 수, 사용 시점 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083764180/original/zRBY4u9qm7aUCcXG2eGA-UdhRsMD-0nB3A.png?1792501391)*

## 카탈로그 서버와 사용자 지정 MCP 서버 연결하기

카탈로그 앱은 안내에 따라 차례대로 연결해요. 사용자 지정 MCP 서버를 쓰면 카탈로그에 없는 호환 서비스도 연결할 수 있어요.

카탈로그 앱을 연결하는 경우:

MCP 카탈로그에서 앱을 고르고, 필요하면 로그인한 다음 에이전트가 쓸 도구를 선택해요.

사용자 지정 MCP 서버를 연결하는 경우:

**Add custom MCP**(사용자 지정 MCP 추가)를 선택하고 아래 항목을 입력해요.

- **이름**: 서버를 알아보기 쉬운 이름
- **MCP server URL**(MCP 서버 URL): 서버의 연결 주소
- **고급**: 추가 인증 설정이에요. 필요하면 OAuth **Client ID**(클라이언트 ID)와 **클라이언트 시크릿**을 입력해요.

서버에 연결하면 하이퍼클래스가 사용할 수 있는 도구를 자동으로 찾아 와요.

*![사용자 지정 MCP 서버의 이름, URL, 고급 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083766615/original/HbG2IuMJKUG1OIpl-1Ok_-SGI2L1_r1B6w.png?1792502521)*

{% hint style="warning" %}
보안: 신뢰할 수 있는 MCP 서버만 연결하세요. 꼭 필요한 도구만 선택하고, 외부 계정이나 데이터에 불필요한 접근 권한을 주지 마세요. OAuth 자격 증명은 다른 사람에게 알려 주지 마세요.
{% endhint %}

## MCP 도구 선택과 사용 시점 안내문

도구를 선택하면 음성 AI 에이전트가 할 수 있는 작업이 정해져요. **When to use**에 적은 안내문은 에이전트가 대화 중에 알맞은 서버를 고르는 데 도움이 돼요.

MCP 서버를 연결한 뒤에는 이렇게 해요.

1. 사용할 수 있는 도구를 확인해요.
2. 에이전트에 필요한 도구만 선택해요.
3. 선택한 내용을 저장해요.
4. **When to use**에 분명한 안내문을 입력해요.

예를 들면 이렇게 쓸 수 있어요.

"전화한 사람이 예약 가능 여부를 확인하거나 예약을 관리하려고 하면 Google Calendar MCP를 사용하세요."

![도구 선택과 사용 시점 안내문 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083765978/original/qTGFYcvLHAiNxNYm2F6fgsvIZG9ASQ2TOA.png?1792502241)

## 통화 중 MCP 도구 사용

S2S 에이전트는 통화 중에 상대방의 요청이 안내문과 맞으면 MCP 도구를 사용해요.

예를 들면 이런 순서로 진행돼요.

1. 전화한 사람이 예약 가능한 시간을 물어봐요.
2. 에이전트가 연결된 캘린더 도구를 호출해요.
3. 도구가 가능한 시간을 돌려줘요.
4. 에이전트가 그 결과를 상대방에게 알려 줘요.

선택한 도구와 계정 권한이 허용하면 에이전트가 예약 만들기 같은 지원되는 작업도 실행할 수 있어요.

테스트 통화에서는 MCP 도구 호출이 상태와 소요 시간과 함께 대화 기록(트랜스크립트)에 표시돼요.

## MCP 연결 상태 관리

연결 상태를 보면 MCP 연동을 그대로 쓸 수 있는지, 확인이 필요한지 알 수 있어요.

| 상태 | 의미 | 조치 |
| --- | --- | --- |
| **Connected**(연결됨) | 연결을 사용할 수 있어요 | 할 일 없음 |
| **재연결** | 연결이 만료되었거나 취소되었어요 | 계정을 다시 연결해요 |
| **App removed**(앱 제거됨) | 다른 곳에서 앱이 삭제되었어요 | 연결을 복원해요 |

도구가 작동하지 않으면 연결 상태, 선택한 도구, **When to use** 안내문을 차례로 확인하세요. 그다음 테스트 통화 대화 기록을 열어 에이전트가 도구를 호출하려고 했는지 살펴보세요.

## S2S 음성 AI에 MCP 서버 설정하기

MCP 서버는 S2S 음성 AI 빌더에서 바로 설정해요. 알맞은 도구를 고르고 분명한 안내문을 적어 두면 에이전트가 통화 중에 연결된 앱을 제대로 사용해요.

### 1단계: S2S 음성 AI 에이전트 열기

1. **AI 에이전트 > 음성 AI**로 이동해요.
2. 음성 대 음성 에이전트를 열거나 새로 만들어요.
3. 에이전트의 **빌드** 화면을 열어요.

### 2단계: MCP 서버 열기

1. 오른쪽 패널에서 **MCP Servers**를 펼쳐요.
2. **+ Add MCP**(MCP 추가)를 클릭해요.

***![MCP 서버 패널의 MCP 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083766207/original/tkNPQoXAiDT6DzJtZQW94yhcKOkjurrujA.png?1792502342)***

### 3단계: MCP 앱 연결하기

둘 중 하나를 선택해요.

카탈로그 앱을 연결하는 경우:

1. 원하는 앱을 검색하거나 선택해요.
2. 필요하면 로그인하거나 계정을 승인해요.

사용자 지정 MCP를 연결하는 경우:

1. **Add custom MCP**를 클릭해요.
2. 서버의 **이름**과 **MCP server URL**을 입력해요.
3. 추가 인증 정보가 필요하면 **고급**을 열어요.
4. 연결을 완료해요.

사용할 수 있는 기존 연결은 다시 승인하지 않고 그대로 쓸 수 있어요.

### 4단계: 도구 선택하기

1. 연결된 서버가 제공하는 도구를 확인해요.
2. 음성 AI 에이전트에 필요한 도구를 선택해요.
3. 선택한 내용을 저장해요.

예를 들어 예약을 처리하는 에이전트라면 캘린더 가용 시간 확인 도구와 예약 관리 도구를 켜 두세요.

### 5단계: 사용 시점 설정하기

1. 연결한 서버의 카드로 돌아가요.
2. **When to use**를 찾아요.
3. 에이전트가 이 서버를 언제 호출해야 하는지 짧게 입력해요.

예시: "전화한 사람이 예약 가능 여부나 일정 잡기를 물어보면 이 서버를 사용하세요."

**![서버 카드의 사용 시점 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083766367/original/DjKLzjAj-i4r-YNeNUTXAWSJUUqsnh1imw.png?1792502418)**

### 6단계: 저장하고 게시하기

1. 서버 연결, 선택한 도구, 안내문을 한 번 더 확인해요.
2. 저장하지 않은 변경 사항이 있으면 저장해요.
3. 화면에 있는 버튼으로 에이전트를 게시하거나 배포해요.

### 7단계: 연동 테스트하기

1. 음성 AI 에이전트로 테스트 통화를 시작해요.
2. MCP 도구를 써야 하는 질문을 해요. 예: "내일 가능한 예약 시간이 언제예요?"
3. 에이전트의 답변을 확인해요.
4. 대화 기록에서 MCP 도구 호출, 상태, 소요 시간을 확인해요.
5. 필요하면 도구나 안내문을 고쳐요.

*![테스트 통화 대화 기록에 표시된 MCP 도구 호출](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083766864/original/Vie_SraVe-lYy5GNZkFv6LCSclOIuQuM-g.png?1792502623)*

{% hint style="warning" %}
중요: 테스트 중에도 MCP 도구는 실제로 작업을 실행할 수 있어요. 정보를 만들거나 바꾸거나 삭제하는 도구를 확인할 때는 테스트 계정이나 안전한 테스트 데이터를 사용하세요.
{% endhint %}

자세한 내용은 [음성 AI 에이전트 테스트하기](../13-AI-Employee/Voice-AI/how-to-test-voice-ai-agents.md)를 참고하세요.

## 자주 묻는 질문

### 하이퍼클래스에 이미 연결한 MCP 앱을 쓸 수 있나요?

네. **관리형 에이전트**, **AI에게 문의**, **대화 AI**에서 연결한 앱 중 사용할 수 있는 연결은 음성 AI에서도 다시 쓸 수 있어요.

### 카탈로그에 없는 MCP 서버도 연결할 수 있나요?

네. **Add custom MCP**를 선택하고 서버의 이름과 URL을 입력하세요.

### 사용자 지정 MCP 서버에 OAuth가 필요하면 어떻게 하나요?

**고급**을 열고 필요한 Client ID와 클라이언트 시크릿을 입력하세요.

### 에이전트가 쓰는 MCP 도구를 고를 수 있나요?

네. 에이전트가 하는 일에 필요한 도구만 선택하세요.

### 연결된 앱은 모든 S2S 모델에서 작동하나요?

MCP를 쓸 수 있는지는 지원되는 S2S 모델과 기능 사용 권한에 따라 달라요. 에이전트를 설정하기 전에 호환되는지 확인하세요.

### MCP 연결이 만료되면 어떻게 되나요?

서버에 **재연결**이 표시돼요. 계정을 다시 승인하면 접근 권한이 복구돼요.

### **App removed**는 무슨 뜻인가요?

앱이 다른 곳에서 삭제되었다는 뜻이에요. 연결을 복원해야 해요.

### 에이전트가 MCP 도구를 사용했는지 어떻게 알 수 있나요?

테스트 통화를 실행하고 대화 기록에서 도구 호출 상세 정보를 확인하세요.
