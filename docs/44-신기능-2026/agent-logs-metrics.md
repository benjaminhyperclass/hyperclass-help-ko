# 에이전트 로그 지표로 AI 에이전트 활동 확인하기

**에이전트 로그**(Agent Logs) 안의 **지표** 탭은 위젯, 필터, 저장된 레이아웃으로 AI 에이전트 활동을 한눈에 보여 주는 대시보드예요. 대화를 하나씩 열어 보지 않아도 성과, 효율, 활동 흐름을 넓게 살펴볼 수 있어요. 추세를 찾고, 업무량을 확인하고, 개선이 필요한 부분을 가려내기 좋아요.

## 에이전트 로그 지표란?

에이전트 로그 지표는 하이퍼클래스 안에서 AI 에이전트의 성과를 시간 흐름에 따라 보여 주는 유연한 대시보드예요. 대화량, 메시지 활동, 응답 속도, 운영 추세를 상호작용마다 따로 확인하지 않고도 볼 수 있어요. 위젯, 필터, 자동 새로고침을 원하는 대로 설정하면 에이전트 성과를 파악하고 개선점을 찾기가 더 쉬워요.

세션 로그나 실행 로그보다 한 단계 높은 관점으로 보고 싶을 때 쓰면 좋아요. 상세 로그는 개별 상호작용과 실행 단계를 살펴볼 때 쓰고, **지표** 탭은 여러 에이전트, 채널, AI 활동의 전체 성과를 한 대시보드에서 추적할 때 써요.

## 에이전트 로그 지표의 주요 이점

에이전트 로그 지표를 쓰면 개별 로그를 하나씩 보던 방식에서 벗어나 규모 있게 성과를 모니터링할 수 있어요. 추세를 빠르게 찾고, 활동을 비교하고, 가장 중요한 곳에 개선 노력을 집중할 수 있어요.

- 한곳에서 확인: 대화를 하나씩 보지 않고 한 대시보드에서 AI 활동을 추적해요.
- 맞춤 모니터링 화면: 팀이나 업무에 가장 중요한 지표를 중심으로 레이아웃을 만들어요.
- 빠른 문제 발견: 성과·활동 위젯으로 평소와 다른 추세, 지연 문제, 도구 사용이 많은 구간을 더 빨리 찾아요.
- 더 나은 개선 판단: 시간에 따른 추세를 비교하고, 더 깊은 조사가 필요한 지표는 상세 로그로 확인해요.
- 실시간 파악: 자동 새로고침 간격을 설정해 모니터링 중에도 대시보드를 최신 상태로 유지해요.

## 대시보드 레이아웃과 위젯

**지표** 페이지에는 AI 에이전트 활동을 추적할 수 있는 기본 레이아웃과 사용자 지정 레이아웃이 있어요. 미리 구성된 지표를 보거나, 보고 싶은 정보 중심으로 레이아웃을 직접 만들 수 있어요.

### 기본 레이아웃

레이아웃 드롭다운에는 기본 레이아웃 3개가 있어요.

- 대화 AI: 채팅량, 사람 상담으로의 전환, 후속 메시지, 가장 바쁜 시간대를 볼 수 있어요.
- 음성 AI: 통화량, 통화 결과, 감정, 통화가 끝난 이유를 모니터링해요.
- 관리형 에이전트: 처리된 대화, 연락 닿은 연락처, 에이전트 응답 시간을 확인해요.

이 레이아웃에는 **기본** 표시가 붙어 있어요. 볼 수만 있고 편집하거나 삭제할 수는 없어요.

대시보드를 원하는 대로 바꾸려면 템플릿이나 빈 캔버스로 별도의 레이아웃을 만드세요.

![기본 레이아웃 3개를 보여 주는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083770046/original/rv3zEsrOwxngP-ID1zMmHXbOgDITbCstPg.gif?1792504001)

### 템플릿과 사용자 지정 레이아웃

사용자 지정 레이아웃을 쓰면 보고 싶은 항목에 맞춰 위젯을 구성할 수 있어요. 기본 레이아웃과 달리, 직접 만든 레이아웃은 편집, 이름 변경, 재배치, 삭제가 가능해요.

레이아웃을 만들 때는 다음 중 하나를 선택해요.

- **템플릿으로 시작**: 미리 구성된 위젯 모음으로 시작해요. 저장하기 전에 위젯을 지우거나 재배치하거나 더 추가할 수 있어요.
- **처음부터 시작**: 빈 캔버스에서 시작해 필요한 위젯만 추가해요.

![템플릿 또는 빈 캔버스로 레이아웃을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083771568/original/PcnorL3ZVOn9SRo38zu8prUcqHWq07XDFg.gif?1792504553)

### 기본 제공 위젯과 사용자 지정 위젯

사용자 지정 레이아웃에 위젯을 추가하려면 **Add Widget**(위젯 추가)을 사용해요.

기본 제공 위젯은 이미 만들어진 지표와 시각화예요. 카테고리를 둘러보거나, 위젯을 검색하거나, 숫자·차트·표 같은 위젯 유형으로 필터링할 수 있어요.

**사용자 지정 지표**를 쓰면 에이전트 로그에 있는 지표로 나만의 시각화를 만들 수 있어요.

사용자 지정 지표로 할 수 있는 일은 다음과 같아요.

- 지표에 제목을 붙여요.
- 선, 막대, 파이, 도넛, 히트맵, 표 중에서 시각화 형태를 골라요.
- 추적할 지표를 선택해요.
- 에이전트, 채널, AI 제품, 도구별로 데이터를 필터링해요.
- 지원되는 차트 세부 구분과 시간 간격을 설정해요.
- 레이아웃에 추가하기 전에 시각화를 미리 봐요.

사용자 지정 레이아웃에 위젯을 추가한 뒤에는 위치를 옮기고 변경 사항을 저장할 수 있어요.

![위젯을 추가하고 사용자 지정 지표를 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083771673/original/w2I7HbpXTZHohABo3DtHAkZe0_zHWpQTlA.gif?1792504609)

## 주요 지표와 운영 인사이트

**지표** 탭의 위젯으로 활동량과 운영 성과를 함께 파악할 수 있어요. 패턴을 찾고, 추세를 비교하고, 어디에 집중할지 정하기 쉬워져요.

이 위젯들은 추세를 빠르게 확인하는 데 맞춰져 있어요. 더 깊이 분석해야 할 때는 상세 로그와 디버깅 도구로 개별 대화, 액션, 실행 경로를 조사하세요.

| 지표 | 설명 |
| --- | --- |
| **처리된 대화**(Conversations Handled) | 선택한 기간 동안 처리된 AI 대화의 총수예요. |
| **AI Messages**(AI 메시지) | AI 에이전트가 만든 메시지의 총수예요. |
| **대화당 평균 메시지 수**(Average Messages per Conversation) | 대화 하나에서 오간 메시지의 평균 수예요. |
| **평균 응답 시간**(Avg Response Time) | AI 에이전트가 응답하는 데 걸리는 평균 시간이에요. |
| **Top Agents**(상위 에이전트) | 선택한 기간에 활동이 가장 많은 에이전트를 보여 줘요. |
| **Top Actions**(상위 액션) | 가장 자주 쓰인 액션과 평균 실행 지연 시간을 요약해서 보여 줘요. |
| **가장 바쁜 시간대**(Busiest Hours) | 하루 중 대화 활동이 가장 많은 시간대를 보여 줘요. |
| **Channel Activity**(채널별 활동) | 지원되는 소통 채널별로 활동이 시간에 따라 어떻게 달라지는지 보여 줘요. |

![지표 탭의 주요 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069689627/original/fCe7-G56GyFy-pKI7VtYgOesUop2Dsuc6A.gif?1776854053)

## 에이전트 로그 지표 설정하기

설정을 제대로 해 두면 대시보드에 팀에 맞는 데이터, 지표, 모니터링 우선순위가 반영돼요. 레이아웃과 필터를 한 번 설정해 두면 매일 하는 리포팅, 실시간 모니터링, 개선 작업에 다시 활용할 수 있어요.

1. 에이전트 로그를 열고 **지표** 탭을 선택해요.

   하이퍼클래스에서 **AI 에이전트 > 에이전트 로그**로 이동한 다음 **지표** 탭을 선택하면 대시보드가 열려요.

   ![에이전트 로그의 지표 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069687895/original/VEaubx_1ycm2WazNhf2PZ8geNsjEFTFt4Q.png?1776852944)
2. 필터 범위를 정해요.

   분석할 데이터에 맞게 필터를 설정해요. **Time Range**(기간), **Agents**(에이전트), **AI Products**(AI 제품), **Channels**(채널), **연락처**로 대시보드를 좁힐 수 있어요.

   ![필터를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069687947/original/eutltFnMtBl-wfVzBGq__v1UZMRVsAKG4Q.gif?1776852979)
3. 사용자 지정 레이아웃을 만들거나 선택해요.

   레이아웃 드롭다운을 열고 **Add Layout**(레이아웃 추가)을 선택해 레이아웃을 만들어요.

   템플릿을 골라 미리 구성된 위젯으로 시작하거나, **처음부터 시작**을 선택해 빈 캔버스에서 시작해요.

   기본 레이아웃 3개(대화 AI, 음성 AI, 관리형 에이전트)는 읽기 전용이에요. 변경하려면 사용자 지정 레이아웃을 만드세요.

   ![레이아웃을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083772464/original/hjWV3Tyv6-HOmPYIfV6jbeG4qBjIW3Ef7g.gif?1792504970)
4. 레이아웃을 꾸미고 저장해요.

   직접 만든 레이아웃은 **Edit Layout**(레이아웃 편집)으로 꾸밀 수 있어요.

   - **Add Widget**을 선택해 기본 제공 위젯이나 **사용자 지정 지표**를 추가해요.
   - 필요 없는 위젯은 지워요.
   - 위젯을 끌어다 놓아 위치를 바꿔요.
   - 위젯 크기를 조절해 대시보드를 정리해요.

   꾸미기를 마치면 **Save changes**(변경 사항 저장)를 선택해요.

   ![레이아웃을 편집하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083774344/original/f9SJr7zSMVywPHvsF6o_0EWU-sIBeuJ_Xg.gif?1792505570)
5. 실시간 활동을 볼 때는 자동 새로고침을 설정해요.

   대시보드를 얼마나 자주 확인해야 하는지에 따라 자동 새로고침 간격을 30초, 1분, 5분, 15분 중에서 선택해요. 새로고침 아이콘을 클릭하면 바로 업데이트돼요.

   ![자동 새로고침 간격을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069688481/original/oQMRlaiu2cthbnnIOUg_BE8kxV6-TbGCoA.png?1776853359)
6. 더 깊이 조사할 때는 **세션**을 사용해요.

   대시보드에서 본 추세를 더 자세히 확인하고 싶다면 **에이전트 로그 > 세션**을 열어 해당 지표 뒤에 있는 대화를 살펴보세요. AI 에이전트가 어떤 대화를 처리했는지, 상호작용이 어떻게 진행됐는지, 더 조사할 부분이 어디인지 맥락을 파악할 수 있어요. 자세한 내용은 [에이전트 로그 개요](agent-logs-overview.md)를 참고하세요.

   ![세션에서 대화를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069689467/original/5esSGh6SmqTPbdOqTqXITFxcFvxvotmWmg.png?1776853967)

## 자주 묻는 질문

### 에이전트 로그 지표와 에이전트 로그 세션은 어떻게 다른가요?
에이전트 로그 지표는 성과와 활동을 종합해서 보여 주는 대시보드예요. 세션 로그와 실행 로그는 개별 상호작용이나 실행 단계를 더 자세히 살펴볼 때 써요.

### 에이전트 로그 지표에서 어떤 필터를 쓸 수 있나요?
**Time Range**(기간), **Agents**(에이전트), **AI Products**(AI 제품), **Channels**(채널), **연락처**로 필터링할 수 있어요.

### 대시보드 레이아웃을 바꿀 수 있나요?
네. 템플릿이나 빈 캔버스로 사용자 지정 레이아웃을 만들 수 있어요. 직접 만든 레이아웃에서는 **Edit Layout**(레이아웃 편집)으로 위젯을 추가, 삭제, 재배치하고 크기를 조절할 수 있어요. 기본 레이아웃 3개는 읽기 전용이에요.

### 여러 가지 대시보드 화면을 저장할 수 있나요?
네. 사용자 지정 레이아웃을 여러 개 저장하고 레이아웃 드롭다운에서 전환해 쓸 수 있어요. 직접 만든 레이아웃은 이름을 바꾸거나 삭제할 수도 있어요.

### 기본 레이아웃인 대화 AI, 음성 AI, 관리형 에이전트를 편집하거나 삭제할 수 있나요?
아니요. 이 3개 레이아웃은 기본으로 제공되며 편집하거나 삭제할 수 없어요. 지표 대시보드를 원하는 대로 바꾸려면 별도의 레이아웃을 만드세요.

### 기본 제공 위젯에 없는 지표로 차트를 만들 수 있나요?
네. **Add Widget**(위젯 추가)을 선택한 다음 **사용자 지정 지표**에서 **새 지표 만들기**를 선택하세요. 사용할 수 있는 측정값을 고르고 차트 유형을 선택한 뒤, 지원되는 필터와 세부 구분을 설정해요. 레이아웃에 추가하기 전에 결과를 미리 볼 수 있어요.

### 에이전트 로그 지표는 자동으로 새로고침되나요?
네. 자동 새로고침 간격은 30초, 1분, 5분, 15분 중에서 선택할 수 있어요.

### 지표에서 성능 문제를 발견하면 어떻게 하나요?
먼저 대시보드에서 추세를 확인한 다음, 관련 로그나 디버깅 도구를 열어 더 자세히 분석하세요.

### 기본 제공 위젯에 없는 지표도 만들 수 있나요?
