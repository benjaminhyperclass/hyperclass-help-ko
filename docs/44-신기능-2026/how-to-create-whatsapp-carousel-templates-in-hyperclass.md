# WhatsApp 캐러셀 템플릿 만들기

WhatsApp 캐러셀 템플릿을 쓰면 상품, 서비스, 프로모션 여러 개를 WhatsApp 메시지 하나에 담아 보여 줄 수 있어요. 캐러셀 하나에는 이미지나 동영상, 설명, 버튼이 들어 있는 카드가 2~10개 들어가고, 고객은 옆으로 넘겨 볼 수 있어요. 이 문서에서는 하이퍼클래스에서 캐러셀 템플릿을 만들고, 설정하고, 승인받고, 보내는 방법을 안내해요.

## WhatsApp 캐러셀 템플릿이란?

WhatsApp 캐러셀 템플릿은 대화 하나 안에서 옆으로 넘겨 볼 수 있는 카드 여러 개를 보여 주는 마케팅 메시지예요. 고객은 채팅을 벗어나지 않고 여러 오퍼를 둘러보고, 카드별로 버튼을 누를 수 있어요.

캐러셀 하나는 메시지 본문과 카드 2~10개로 이루어져요. 템플릿은 Meta의 승인을 받아야 보낼 수 있어요.

## WhatsApp 캐러셀 템플릿의 장점

캐러셀 템플릿으로 여러 상품이나 서비스를 메시지 하나에 담으면 마케팅 캠페인의 반응을 높이고 비용도 줄일 수 있어요.

- 여러 오퍼 소개: 상품, 서비스, 프로모션을 메시지 하나에 최대 10개까지 보여 줄 수 있어요.
- 메시지 비용 절감: 오퍼마다 따로 보내지 않고 마케팅 메시지 1건 요금만 내요.
- 참여도 향상: 고객이 이미지, 동영상, 오퍼를 넘겨 가며 볼 수 있어요.
- 맞춤형 콘텐츠: 카드 설명에 지원되는 변수를 쓸 수 있어요.
- 고객 행동 유도: 카드마다 인터랙티브 버튼을 넣을 수 있어요.
- 보내기 전 미리보기: 템플릿을 만드는 동안 실시간 미리보기로 캐러셀을 확인할 수 있어요.

## WhatsApp 캐러셀 템플릿 설정하기

템플릿 유형을 고르고, 카드를 추가해 내용을 채운 다음, 완성한 템플릿을 승인 요청하는 순서로 진행해요.

### 1단계: 템플릿 만들기

1. **설정 > WhatsApp > 템플릿**으로 이동하세요.
2. **템플릿 만들기**를 클릭하세요.

   ![템플릿 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084178071/original/CIRk4Hodd1lKm1reIORvwMRLH1lwZ6fxAA.png?1793007074)
3. 템플릿 이름을 입력하고 **언어**를 선택하세요.
4. **카테고리**는 **마케팅**을 선택하세요.
5. **Media Carousel**(미디어 캐러셀)을 선택하세요.

   ![미디어 캐러셀 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084177908/original/2Wc4ZG3HdOinUkoC6hy80-kidAXRuE2KOw.png?1793007020)

### 2단계: 메시지 내용과 카드 추가

1. 메시지 본문을 입력하세요.
2. 캐러셀 카드를 2~10개 추가하세요.
3. 카드마다 이미지나 동영상을 업로드하세요.
4. 카드마다 160자 이내로 설명을 추가하세요.
5. 카드마다 버튼을 최대 2개까지 설정하세요.
6. 카드를 드래그해서 순서를 바꾸세요.

모든 카드의 버튼 구성이 같아야 해요.

![카드 내용 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084178264/original/gw-m-2Oh-4GBQGFemZJiFmuQQE0EAiZ4WQ.png?1793007152)

### 3단계: 미리보기 후 승인 요청하기

1. 실시간 미리보기 패널에서 캐러셀을 확인하세요.
2. 미디어, 설명, 버튼, 카드 순서를 살펴보세요.
3. 카드 수와 구성 요소가 맞는지 확인하세요.
4. **승인**을 받기 위해 템플릿을 제출하세요.

   ![승인을 위해 템플릿 제출](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084178664/original/WVqGXrJEAYHpcg94O31GuW50Q_hkHltnAw.png?1793007288)

승인된 뒤에는 카드 수를 바꿀 수 없어요.

### 4단계: 승인된 캐러셀 보내기

승인된 템플릿은 하이퍼클래스의 다음 기능에서 보낼 수 있어요.

- **대화**: 연락처와의 대화를 열고 WhatsApp 템플릿 옵션을 선택한 다음, 승인된 캐러셀을 골라 보내요.
- **워크플로우**: WhatsApp 액션을 추가하고, 승인된 캐러셀 템플릿을 선택한 다음, 발송 조건을 설정해요.
- **일괄 작업**: 연락처를 선택하고 **WhatsApp 보내기**를 누른 다음, 승인된 캐러셀 템플릿을 선택해 발송을 설정해요.

WhatsApp 메시지 정책, 연락처 발송 가능 조건, 적용되는 발송 한도는 그대로 적용돼요.

## WhatsApp 캐러셀 카드 구성 요소

카드마다 시각 콘텐츠, 설명 텍스트, 선택 사항인 버튼이 들어가요. 카드 형식을 통일해야 고객이 캐러셀을 넘겨 볼 때 일관된 경험을 얻을 수 있어요.

| 구성 요소 | 요건 |
| --- | --- |
| 캐러셀 카드 | 2~10개 |
| 미디어 | 카드마다 이미지 또는 동영상 |
| 카드 본문 | 필수, 최대 160자 |
| 변수 | 카드 본문 텍스트에서 지원 |
| 버튼 | 카드당 최대 2개 |
| 버튼 레이블 | 최대 25자 |
| 카드 순서 | 드래그 앤 드롭으로 조정 가능 |

## 미디어 및 콘텐츠 요건

캐러셀 카드마다 이미지 또는 동영상과 짧은 설명이 필요해요. 하이퍼클래스 **미디어 저장소**에서 미디어를 고르거나, 파일을 업로드하거나, 미디어 URL을 입력할 수 있어요. 카드 설명은 160자를 넘으면 안 되고, 지원되는 변수를 넣을 수 있어요.

미디어에 대한 자세한 안내는 WhatsApp 미디어 템플릿을 참고하세요.

## 캐러셀 버튼과 상호작용

캐러셀 버튼을 쓰면 고객이 WhatsApp 안에서 특정 상품이나 오퍼에 바로 반응할 수 있어요. 카드마다 버튼을 최대 2개까지 넣을 수 있고, 버튼 레이블은 25자까지 쓸 수 있어요. 버튼 동작은 캐러셀 템플릿 편집 화면에서 제공하는 옵션 중에서 골라야 해요. 사용할 수 있는 추적 기능은 지원되는 버튼 구성에 따라 달라요.

{% hint style="warning" %}
모든 카드의 버튼 수와 구성이 같아야 해요.
{% endhint %}

## WhatsApp 캐러셀 템플릿 제한 사항

캐러셀 템플릿은 형식을 일정하게 유지하고 Meta의 승인 절차를 따르기 위해 몇 가지 요건이 있어요.

- 카드 수 고정: 카드 5개로 승인받은 템플릿은 항상 카드 5개를 보내야 해요. 카드 수를 바꾸려면 새 템플릿을 만들어야 해요.
- 구성 요소 일치: 모든 카드에 본문 텍스트가 있어야 하고, 버튼 수와 구성 요소 구조가 같아야 해요.
- 지원 미디어: 캐러셀 카드에는 이미지나 동영상을 써요.
- 승인: 보내기 전에 템플릿이 승인되어야 해요.

## 자주 묻는 질문

### 승인된 뒤에 카드를 더 추가할 수 있나요?

아니요. 카드 수를 바꾸려면 새 템플릿을 만들어 다시 승인받아야 해요.

### 카드마다 버튼 수를 다르게 할 수 있나요?

아니요. 모든 카드가 같은 수와 같은 구조의 버튼을 써야 해요.

### 캐러셀 하나에 이미지와 동영상을 함께 쓸 수 있나요?

캐러셀 템플릿은 이미지와 동영상을 지원해요. 다만 한 캐러셀에 두 형식을 섞어 쓸 수 있는지는 템플릿 편집 화면에서 확인하세요.

### 카드 10개짜리 캐러셀은 카드 2개짜리보다 비용이 더 드나요?

둘 다 마케팅 메시지 1건으로 계산돼요. 해당하는 WhatsApp 마케팅 메시지 요금은 그대로 적용돼요.

### 워크플로우에서 캐러셀 템플릿을 쓸 수 있나요?

네. 승인된 캐러셀 템플릿은 지원되는 WhatsApp 워크플로우 액션에서 선택할 수 있어요.

### 고객이 어떤 카드를 선택했는지 추적할 수 있나요?

카드별 버튼으로 고객의 관심을 가늠할 수 있어요. 사용할 수 있는 추적 및 자동화 기능은 지원되는 버튼 동작에 따라 달라요.
