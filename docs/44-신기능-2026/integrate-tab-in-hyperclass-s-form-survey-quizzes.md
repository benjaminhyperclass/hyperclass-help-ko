# 폼·설문·퀴즈의 Integrate(연동) 탭 사용 안내

**Integrate**(연동) 탭에서 폼, 설문, 퀴즈를 임베드하고, 공유하고, 이메일과 워크플로우에 연결할 수 있어요. 임베드 미리보기와 기본 QR 코드도 이 탭에서 바로 볼 수 있어서, 여러 메뉴를 오가지 않고 콘텐츠를 설정하고 배포할 수 있어요.

---

## 폼·설문·퀴즈의 Integrate 탭이란?

**Integrate** 탭은 폼, 설문, 퀴즈를 만드는 빌더 화면 안에서 배포와 연동 옵션을 한곳에 모아 둔 탭이에요. 기존 **Integrate** 버튼을 대신하며, 네 가지 연동 옵션이 있어요.

| 연동 옵션 | 설명 |
| --- | --- |
| **임베드** | 임베드 레이아웃을 설정하고, 변경 내용을 미리 보고, 임베드 코드를 복사해요. |
| **공유** | 직접 링크를 공유하거나 소셜 공유 옵션을 쓰고, QR 코드를 사용자 지정해요. |
| **이메일** | 기존 이메일이나 새 이메일에 폼, 설문, 퀴즈를 넣어요. |
| **연결** | 연결된 워크플로우를 확인하고 새 워크플로우를 시작해요. |

---

## 임베드

**임베드** 옵션에서는 폼, 설문, 퀴즈가 웹페이지에 어떻게 보일지 설정해요. 지원하는 설정을 바꾸면 미리보기에 바로 반영되니, 임베드 코드를 복사하기 전에 알맞은 레이아웃을 고를 수 있어요.

임베드 유형은 다음과 같아요.

| 유형 | 설명 | 이럴 때 좋아요 |
| --- | --- | --- |
| **Standard**(표준) | 웹페이지 안에 바로 표시돼요. | 문의·등록 폼 |
| **Popup**(팝업) | 화면 위에 겹쳐서 열려요. | 프로모션, 리드 확보 |
| **Popover**(팝오버) | 떠 있는 버튼을 누르면 열려요. | 간단한 문의 |
| **Sidebar**(사이드바) | 옆쪽 패널로 열려요. | 피드백·지원 폼 |

![임베드 유형별 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084078853/original/jC7sp28gz2KMFNJtH13siYJ4H3LavWCOXA.gif?1792766937)

### 설정으로 레이아웃 조정하기

| 설정 | 설명 |
| --- | --- |
| **Choose Type**(유형 선택) | Standard, Popup, Popover, Sidebar 중에서 골라요. |
| **Position**(위치) | 지원하는 표시 위치나 버튼 위치를 조정해요. |
| **Width and Height**(너비와 높이) | 설정할 수 있는 폼 크기를 지정해요. |
| **Button Settings**(버튼 설정) | 버튼의 레이블, 색상, 유형, 크기를 바꿔요. |
| **Appearance**(모양) | 지원하는 모서리 둥글기와 글꼴 설정을 조정해요. |

선택한 임베드 유형에 따라 설정 항목이 달라져요. **Advanced**(고급) 탭에서 추가 설정을 쓸 수 있는 경우도 있어요.

![임베드 설정을 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084078890/original/3t1hZbgzOrPbozHsCHWpksqo1ZR14QHrxA.gif?1792766962)

## 공유

**공유** 옵션에서는 폼, 설문, 퀴즈를 여러 방법으로 배포할 수 있어요. 항목마다 직접 링크와 기본 QR 코드가 준비되어 있어서, 온라인과 인쇄물 어디에서든 쉽게 공유할 수 있어요.

| 공유 옵션 | 설명 |
| --- | --- |
| **Direct Link**(직접 링크) | URL을 복사해 메시지, 이메일 등 원하는 채널로 공유해요. |
| **Social Sharing**(소셜 공유) | 지원하는 소셜 플랫폼으로 공유해요. |
| **QR 코드** | 자동으로 만들어진 QR 코드를 사용자 지정하고 다운로드해요. |

기본 QR 코드가 있으니, 폼·설문·퀴즈마다 QR 코드를 따로 만들 필요가 없어요.

QR 코드를 더 자세히 꾸미고 관리하는 방법은 [QR 코드 생성 및 다운로드 가이드](../06-사이트/QR코드/qr-code-generation-and-download-guide.md)를 참고하세요.

![공유 옵션과 QR 코드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084078936/original/sFmlnxIg0ofz0DK4kh6nATdQzLyDDSDDQQ.gif?1792767008)

## 이메일

**이메일** 옵션을 쓰면 **Integrate** 탭에서 바로 폼, 설문, 퀴즈를 이메일에 넣을 수 있어요. 기존 이메일 연동 기능은 그대로예요.

| 옵션 | 설명 |
| --- | --- |
| **Use Existing Template**(기존 템플릿 사용) | 기존 이메일 템플릿을 골라 폼, 설문, 퀴즈를 넣어요. |
| **Create New Email**(새 이메일 만들기) | 새 이메일을 시작하고 폼, 설문, 퀴즈를 추가해요. |

![이메일 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084100293/original/ikpRxaTxHl0bNori3or7fEbIdc4TuFQ9Fw.gif?1792785869)

## 연결

**연결** 옵션에서는 폼, 설문, 퀴즈와 연결된 워크플로우를 확인할 수 있어요. **자동화** 메뉴에서 일일이 찾지 않아도 기존 연결을 살펴보거나 새 워크플로우를 시작할 수 있어요.

| 옵션 | 설명 |
| --- | --- |
| **Connected Workflows**(연결된 워크플로우) | 선택한 폼, 설문, 퀴즈와 연결된 워크플로우를 봐요. |
| **Create Workflow**(워크플로우 만들기) | 새 워크플로우 만들기를 시작해요. |

워크플로우를 만들 때는 게시하기 전에 제출 트리거, 필터, 액션을 알맞게 설정하세요.

![연결된 워크플로우 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084079191/original/wSMOlxAwSY1yLKfbwuaUBV6iz4JPgvqPWA.gif?1792767143)

{% hint style="info" %}
연결된 **퍼널 단계**와 **웹사이트 페이지**를 확인하는 기능은 앞으로 추가될 예정이며, 첫 출시에는 포함되지 않아요.
{% endhint %}

## Integrate 탭 설정하고 사용하기

**Integrate** 탭에서는 한곳에서 폼, 설문, 퀴즈를 임베드하고, 공유하고, 이메일로 보내고, 워크플로우에 연결할 수 있어요. 목적에 맞는 연동 옵션을 골라 아래 순서대로 진행하세요.

1. **사이트 > 폼**, **사이트 > 설문**, **사이트 > 퀴즈** 중 연동할 항목이 있는 곳으로 가서 해당 항목을 열어요.
2. 빌더에서 **Integrate** 탭을 선택해요.

   ![빌더에서 Integrate 탭을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084079300/original/9da8AyyHnhDlsvTau8YRwZLsRCiUwyuFBw.png?1792767201)
3. 원하는 연동 옵션을 선택해요.

   - **임베드**: 임베드 유형(**Sidebar**, **Popover**, **Popup**, **Standard**)을 고르고, **General**(일반) 또는 **Advanced** 탭에서 설정을 바꾼 뒤 미리보기를 확인해요. **Embed code**(임베드 코드) > **코드 복사**를 클릭하고, 복사한 코드를 웹사이트 편집기에 붙여 넣어 게시해요.
   - **공유**: 직접 링크를 복사하거나, 소셜 공유 옵션을 고르거나, 기본 QR 코드를 사용자 지정해 다운로드해요.
   - **이메일**: 기존 이메일 템플릿을 고르거나 새 이메일을 만들어 폼, 설문, 퀴즈를 넣어요.
   - **연결**: 연결된 워크플로우를 확인하거나 **Create Workflow**를 클릭해 새 자동화를 설정해요.

     ![연동 옵션을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084079443/original/a-4K93JVd_XPHPh6LHtsik7goMPTHY72fA.png?1792767309)
4. **저장**을 클릭해 폼, 설문, 퀴즈를 저장해요. 저장 후 나타나는 창에서 **공유**, **임베드**, **Create a Workflow**(워크플로우 만들기) 중 하나를 고를 수 있어요.

## 자주 묻는 질문

### 임베드하기 전에 폼, 설문, 퀴즈를 미리 볼 수 있나요?
네. **임베드** 탭에서 기존 임베드 옵션을 모두 실시간으로 미리 볼 수 있어요. 지원하는 설정을 바꾸면 변경 내용이 바로 보여요.

### 폼, 설문, 퀴즈마다 QR 코드를 직접 만들어야 하나요?
아니요. 하이퍼클래스는 폼, 설문, 퀴즈마다 기본 QR 코드를 자동으로 제공해요. **공유** 탭에서 바로 사용자 지정하고 다운로드할 수 있어요.

### 이메일 연동 기능이 바뀌었나요?
아니요. 기존 이메일 연동 기능은 그대로예요. 이제 **Integrate** 탭에서 쓸 수 있어요.

### 내 폼, 설문, 퀴즈에 어떤 워크플로우가 연결되어 있는지 볼 수 있나요?
네. **연결** 탭에서 연결된 워크플로우를 확인할 수 있고, 빌더에서 바로 새 워크플로우 만들기를 시작할 수도 있어요.
