# 에이전트 로그 개요

**에이전트 로그**(Agent Logs)에서는 하이퍼클래스의 여러 기능에서 AI 에이전트가 어떻게 동작했는지 한곳에서 확인할 수 있어요. 실행 기록, 대화 맥락, 단계별 상세 정보를 함께 보여 주기 때문에 무슨 일이 있었는지 파악하고, 문제를 빨리 찾고, 에이전트 성능을 꾸준히 개선하기 좋아요.

## 에이전트 로그란?

에이전트 로그는 AI 에이전트의 로그와 추적 기록을 한곳에서 볼 수 있는 하이퍼클래스의 기능이에요. 하이퍼클래스에서 지원하는 에이전트 기반 애플리케이션의 로그와 추적 기록을 모아서 보여 주기 때문에, 각 상호작용 뒤에서 어떤 일이 일어났는지 확인할 수 있어요. 짐작에 의존하지 않고 에이전트가 어떻게 판단했는지 더 분명하게 보고, 자신 있게 문제를 해결하고 에이전트의 동작을 개선할 수 있어요. 현재 에이전트 로그는 에이전트 스튜디오(Agent Studio)와 음성 AI에서 사용할 수 있고, 다른 AI 상품도 곧 지원될 예정이에요.

에이전트 로그는 3단계로 살펴보도록 구성되어 있어요.

- 에이전트 활동을 한눈에 보는 화면
- 선택한 상호작용의 대화와 실행 타임라인을 자세히 보는 화면
- 디버깅에 필요한 기술 정보까지 단계별로 보는 화면

---

## 에이전트 로그의 장점

- 한곳에서 확인해요: 따로 떨어진 테스트 화면에만 의존하지 않고, 지원되는 AI 에이전트의 활동을 한곳에서 볼 수 있어요.
- 문제를 더 빨리 찾아요: 전체 활동에서 특정 대화로, 다시 개별 실행 단계로 좁혀 가며 어디에서 문제가 생겼는지 찾을 수 있어요.
- 디버깅할 때 맥락을 알 수 있어요: 에이전트의 응답과 실행 타임라인을 비교해 최종 답변이 어떻게 만들어졌는지 이해할 수 있어요.
- 성능을 파악해요: 단계별 실행 시간을 보고 느린 부분을 찾아낼 수 있어요.
- 더 자세히 점검해요: 프롬프트, 로직, 변수, 도구 동작을 점검할 때 기술 정보를 꼼꼼히 확인할 수 있어요.

## 전체 활동 개요

전체 활동 개요에서는 최근 에이전트 활동을 폭넓게 볼 수 있어서, 어디를 살펴봐야 할지 빠르게 정할 수 있어요. 많은 활동을 모니터링하거나, 문제의 범위를 좁히거나, 자세히 보고 싶은 상호작용을 찾을 때 유용해요.

전체 활동 개요는 에이전트 로그의 1단계 화면이에요. 여기서 최근 실행 내역을 확인하고 조사 범위를 좁혀 갈 수 있어요.

이 화면은 다음과 같은 경우에 유용해요.

- 지원되는 에이전트 전반의 최근 활동을 모니터링할 때
- 조사할 실행 건을 좁힐 때
- 특정 상호작용을 더 빨리 찾을 때
- 활동량이 많은 환경에서 대화를 효율적으로 검토할 때

이 화면에 표시되는 주요 항목과 기능은 다음과 같아요.

| 항목 또는 기능 | 설명 |
| --- | --- |
| **Timestamp**(타임스탬프) | 상호작용이 일어난 시각을 보여 줘요. 활동을 시간 흐름 속에서 확인할 수 있어요. |
| **에이전트 이름** | 상호작용을 처리한 에이전트를 알려 줘요. |
| **Agent ID**(에이전트 ID) | 상호작용에 연결된 에이전트의 고유 ID를 보여 줘요. |
| **AI 상품** | 활동이 어떤 AI 상품에 속하는지 보여 줘요. |
| **채널** | 상호작용이 이루어진 채널을 보여 줘요. |
| **상태** | 상호작용의 현재 결과나 상태를 보여 줘요. |
| **Filter by product**(상품별 필터) | 결과를 특정 AI 상품으로 좁혀요. |
| **에이전트별 필터** | 특정 에이전트의 활동만 모아 봐요. |
| **Search by contact**(연락처로 검색) | 특정 연락처와 관련된 상호작용을 찾아요. |
| **Sort results**(결과 정렬) | 결과 순서를 바꿔서 필요한 상호작용을 더 빨리 찾아요. |

![에이전트 로그 전체 활동 개요 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083765032/original/qfMU8l0dmPwdFxhzVLK3mY3CXnCbcsVWdg.gif?1792501702)

## 대화 맥락과 타임라인

대화와 실행 기록을 함께 보면 사용자가 겪은 경험과 그 뒤의 로직을 모두 이해할 수 있어요. 에이전트가 왜 그렇게 응답했는지, 어디에서 판단이 바뀌었는지, 도구가 언제 쓰였는지 알고 싶을 때 도움이 돼요.

대화 맥락과 타임라인은 에이전트 로그의 2단계 화면이에요. 특정 상호작용을 선택하면 대화 내용과 **실행 타임라인**을 나란히 볼 수 있어요.

이 화면에서는 다음을 할 수 있어요.

- 익숙한 대화 형식으로 상호작용을 읽어요.
- 에이전트의 응답과 그 응답에 이르기까지의 단계를 비교해요.
- 사용자의 첫 메시지부터 최종 응답까지 흐름을 따라가요.

**실행 타임라인**은 상호작용 중에 에이전트가 거친 경로를 순서대로 보여 줘요. 대화가 뒤에서 어떻게 진행됐는지 더 분명하게 알 수 있어요.

{% hint style="info" %}
실행 타임라인의 작업 체크리스트

에이전트 스튜디오 실행 중에는 **실행 타임라인**에 여러 단계로 된 작업을 추적하는 작업 체크리스트가 표시되기도 해요.

- 작업은 숫자 순번 대신 설명이 담긴 이름으로 표시돼요.
- 어떤 작업이 진행 중이고 어떤 작업이 끝났는지 화면에 나타나요.
- 에이전트가 실행 도중 작업을 추가하거나 계획을 바꿔도 진행 상황을 알아보기 쉬워요.
{% endhint %}

![대화와 실행 타임라인을 함께 보여 주는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069200261/original/A2DwB7mIRdz7Tx3ZW09iemKoFSrA2Nhq_g.png?1776252894)

### 로그 안에서 이동하고 검색하기

에이전트 로그 상세 페이지에서는 에이전트 대화, **실행 타임라인**, 단계별 점검 정보를 한 화면에서 볼 수 있어요. 헤더의 컨트롤을 사용하면 AI 상품을 확인하고, 완료된 비즈니스 액션을 열고, 세션을 오가고, 원하는 정보를 검색할 수 있어요.

#### 1. AI 상품 확인하기

로그 헤더에는 해당 상호작용과 연결된 AI 상품이 표시돼요. 예를 들어 대화 AI나 음성 AI가 표시돼요. 실행 상세를 보기 전에 어떤 상품이 상호작용을 처리했는지 알 수 있어요.

#### 2. 비즈니스 액션으로 바로 이동하기

완료된 비즈니스 액션은 로그 헤더에 표시돼요. 예약 잡기, SMS 발송, 연락처 업데이트 등이 있어요.

1. **AI 에이전트 > 에이전트 로그**에서 로그를 여세요.
2. 헤더에서 완료된 비즈니스 액션을 찾으세요.
3. 살펴보고 싶은 액션을 선택하세요.
4. 대화에서 해당 부분으로 이동하고, 연결된 실행 단계가 열려요.

이 바로가기를 쓰면 **실행 타임라인** 전체를 일일이 뒤지지 않고도 특정 액션을 점검할 수 있어요.

#### 3. 세션 사이 이동하기

로그 상세 페이지에서 바로 다른 세션으로 이동할 수 있어요.

1. 로그를 여세요.
2. 헤더에서 세션 이동 컨트롤을 선택하세요.
3. 사이드 패널에서 사용할 수 있는 세션을 확인하세요.
4. 다른 세션을 선택하면 그 세션의 로그가 열려요.

이렇게 하면 **에이전트 로그** 목록으로 돌아가지 않고도 여러 세션을 검토할 수 있어요.

#### 4. 로그 안에서 검색하기

로그 헤더의 검색 컨트롤을 사용하면 로그 상세 페이지 전체에서 정보를 찾을 수 있어요.

검색 범위는 다음과 같아요.

- 에이전트 대화 메시지
- **실행 타임라인** 단계
- **Inspect View**(검사 보기)의 상세 정보(입력, 출력, 메타데이터 포함)

검색하는 방법은 다음과 같아요.

1. 로그를 열고 헤더의 검색 아이콘을 선택하세요.
2. 키워드, 도구 이름 등 관련 용어를 입력하세요.
3. 일치하는 결과를 확인하세요.
4. 결과를 선택하면 일치하는 메시지나 실행 단계로 이동해요.

**실행 타임라인**이나 **Inspect View**에서 일치하는 내용이 나오면 해당 단계가 열려서 바로 확인할 수 있어요.

## 단계별 상세 실행 정보

단계별 상세 정보를 보면 문제를 훨씬 정확하게 찾을 수 있어요. 대화가 잘못되었거나 끝까지 이어지지 않았을 때, 개별 실행 단계를 점검하면 원인이 로직, 타이밍, 데이터 처리, 도구 관련 액션 중 어디에 있는지 알 수 있어요.

단계에 따라 출력을 여러 형식으로 볼 수도 있어요. 원본 JSON 형식으로 보거나, 읽기 쉽게 가공한 형식으로 볼 수 있어요. 더 깊이 분석하거나 공유할 때는 단계 출력을 JSON으로 복사할 수도 있어요.

단계별 상세 실행 정보는 에이전트 로그의 3단계 화면이에요. **실행 타임라인**에서 단계를 선택하면 상호작용의 해당 부분에 대한 더 자세한 정보를 볼 수 있어요.

이 화면에서는 다음 내용을 확인할 수 있어요.

- 해당 단계에서 사용한 모델
- 지연 시간과 실행 시간
- 타임스탬프 상세 정보
- 선택한 단계의 입력과 출력
- 프롬프트 상세 정보(해당하는 경우)
- 디버깅에 도움이 되는 추가 기술 메타데이터

{% hint style="info" %}
여러 단계로 실행되는 작업의 경우 구조화된 작업 상세 정보(예: 이름이 붙은 작업, 명시적인 전환)가 표시될 수도 있어요. 이 정보로 작업 순서, 완료 상태, 진행 상황이 바뀐 지점을 확인하세요.
{% endhint %}

## 에이전트 로그 사용하기

에이전트 로그는 따로 설치할 필요가 없어요. 설정에서 가장 중요한 점은 검토할 에이전트 활동이 있는지 확인하고, 전체 화면에서 상세 실행 화면으로 이동하는 방법을 아는 거예요. 순서를 알아 두면 에이전트 로그를 더 빨리 활용할 수 있고, 문제 해결도 일정한 방식으로 할 수 있어요.

다음 순서로 에이전트 로그를 사용해 보세요.

1. 하이퍼클래스 계정에서 **AI 에이전트 > 에이전트 로그**를 여세요.

   ![AI 에이전트 메뉴에서 에이전트 로그를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069201692/original/atgl-Ik238obZFbpC_vWIyM2QlQ4zNTBvw.png?1776253622)
2. 활동 목록을 보고 살펴볼 상호작용을 고르세요. **에이전트 이름**, **AI 상품**, **채널**, **상태** 같은 필터로 결과를 좁힐 수 있어요.

   ![필터로 활동 목록을 좁히는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069201519/original/01VKkFM3lphTt8ikmS0wd8Bxxms9GW3wkw.gif?1776253536)
3. 상호작용을 열어 대화와 **실행 타임라인**을 확인하세요.

   ![대화와 실행 타임라인을 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069201787/original/pMcceTo2Qwh4sLGPJlDlJsHXJMzR0Vv7gw.png?1776253680)
4. 메시지나 단계를 선택해 더 자세한 실행 정보를 보세요. 이 정보를 에이전트를 개선하는 데 활용하세요.

   ![메시지나 단계를 선택해 상세 정보를 보는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069202637/original/4K2PCAtzFsh4M6n69RYGAraqShWwMw2Ofg.gif?1776254124)
5. 메시지나 실행 단계를 선택해 입력, 출력, 실행 시간 등 확인할 수 있는 정보를 점검해요.
6. 완료된 비즈니스 액션을 조사하려면 로그 헤더에서 해당 액션을 선택하세요. 연결된 실행 단계가 열려요.
7. 특정 정보를 찾으려면 헤더의 검색 아이콘으로 대화, 실행 단계, 입력, 출력, 메타데이터를 검색하세요.
8. 다른 세션을 보려면 헤더에서 세션 사이드 패널을 열고 점검할 세션을 선택하세요.
9. 실행 상세 정보를 검토한 뒤 필요한 부분을 에이전트에서 수정하고, 다시 테스트한 다음 에이전트 로그에서 업데이트된 활동을 확인하세요.

## 자주 묻는 질문

### 에이전트 로그는 주로 어떤 용도로 쓰나요?
에이전트 로그는 대화 맥락과 실행 상세 정보를 한곳에 모아 보여 줘서, AI 에이전트가 상호작용을 어떻게 처리했는지 이해하는 데 도움이 돼요.

### 에이전트 로그는 에이전트 스튜디오의 Message Execution Timeline과 같은 건가요?
아니요. 에이전트 로그는 로그와 추적 기록을 한곳에서 보는 기능이고, **Message Execution Timeline**(메시지 실행 타임라인)은 에이전트 스튜디오의 테스트와 디버깅 기능의 일부예요.

### 에이전트 로그는 언제 사용하면 되나요?
에이전트가 어떻게 응답했는지 조사하거나, 상호작용의 경로를 검토하거나, 실행 흐름의 특정 단계에서 생긴 문제를 해결하고 싶을 때 사용하세요.

### 느리거나 복잡한 상호작용을 디버깅할 때도 에이전트 로그가 도움이 되나요?
네. 단계별 화면에서 실행 시간과 기술 정보 등 더 자세한 실행 정보를 볼 수 있어서 문제를 해결하는 데 도움이 돼요.

### 에이전트 로그가 앞으로 다른 AI 상품도 지원하나요?
네.에이전트 로그는 출시 시점에 에이전트 스튜디오에서 사용할 수 있고, 다른 AI 상품 지원도 곧 추가될 예정이에요.
