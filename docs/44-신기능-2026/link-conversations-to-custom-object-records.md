# 대화를 사용자 지정 객체 레코드에 연결하기

메시지를 속성, 보험 계약 같은 **사용자 지정 객체** 레코드에 연결하면, 소통 내용을 관련 레코드와 함께 볼 수 있어요. 메시지는 연락처의 대화에 그대로 남고, 연결된 각 레코드에도 표시돼요.

예를 들어 속성 문의는 속성 레코드에, 프로젝트 진행 안내는 프로젝트 레코드에, 갱신 논의는 보험 계약 레코드에 연결할 수 있어요.

{% hint style="info" %}
이 기능은 비공개 베타로만 제공되며, 기능이 활성화된 서브 계정에서만 쓸 수 있어요.
{% endhint %}

---

## 사용자 지정 객체와 회사에 대화 연결하고 확인하기

메시지를 **사용자 지정 객체** 레코드와 회사에 연결하면, 소통 내용을 관련 레코드와 함께 관리할 수 있어요. 레코드마다 **대화** 피드가 있어서 연결된 메시지를 확인하고, 답장하고, 새 대화를 시작할 수 있어요. 메시지는 연락처의 원래 대화에 그대로 남으면서 연결된 각 레코드에도 표시돼요.

예를 들어 속성 문의는 속성 레코드에, 갱신 논의는 보험 계약 레코드에, 계정 관련 대화는 회사 레코드에 모아 둘 수 있어요.

{% hint style="info" %}
이 기능은 현재 비공개 베타로 제공되며, 기능이 활성화된 서브 계정에서만 쓸 수 있어요. 베타 이용 신청 폼을 통해 서브 계정을 추가할 수 있어요.
{% endhint %}

---

## 레코드를 소통의 중심으로 쓰기

**대화** 탭에서는 레코드의 소통 기록을 보고, 같은 곳에서 바로 대응할 수 있어요.

- 맥락 파악: 레코드에 연결된 메시지를 **연락처**나 **채널**별로 걸러서 읽어요.
- **조치 취하기**: 답장하거나, 해당 레코드가 이미 연결된 새 대화를 시작해요.
- 소통의 중심으로 활용: 속성 문의와 보험 계약 갱신 논의를 각 레코드에 모아 두면, 레코드를 여는 사람 누구나 대화 내용을 볼 수 있어요.

---

## 레코드의 대화 확인하기

1. 왼쪽 메뉴에서 **사용자 지정 객체**를 선택하고 레코드를 열어요.
2. 사이드 패널에서 **대화**를 선택해요.
3. **필터 전환 > 필터**를 사용해 **연락처**나 **채널**로 피드를 좁혀요.

피드에는 선택한 레코드에 연결된 메시지만 표시돼요. 피드가 비어 있어도 해당 연락처에게 다른 대화가 없다는 뜻은 아니에요.

1단계: 레코드를 열고 오른쪽에서 **대화**를 선택하세요. 각 메시지의 배지에 연결된 레코드 수가 표시돼요.

2단계: 필터 아이콘을 눌러 **연락처**나 **채널**로 피드를 좁혀요.

## 레코드에서 대화 시작하기

1. 레코드의 **대화** 탭에서 **대화 만들기** 또는 **새 대화 만들기**를 선택해요.
2. 현재 레코드가 **연결됨**으로 표시되는지 확인해요.
3. **연락처 선택**에서 소통할 연락처를 골라요.
4. **대화 만들기**를 선택해 계속 진행해요.

연락처는 대화에 참여하는 사람을 나타내고, 사용자 지정 객체 레코드는 그 대화의 레코드 맥락을 담아요.

3단계: **대화 만들기**를 클릭하세요. 현재 레코드는 이미 **연결됨** 상태예요. 연락처를 고르고 계속 진행하세요.

![3단계: 대화 만들기를 클릭하고 연락처 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084168601/original/OuZwfPPDlGfPDQtXju8EwaRLMVMBoaTeXA.png?1793002886)

## 대화 화면에서 메시지 연결하기

**대화**를 열고 연락처의 스레드를 선택하세요. 메시지를 작성하는 중에, 이미 있는 메시지에, 또는 여러 메시지를 한꺼번에 연결할 수 있어요.

---

### 메시지를 작성하는 중에 연결하기

작성 창의 연결 아이콘을 선택해요. 사용자 지정 객체 유형을 고르고, 레코드를 찾아 선택한 뒤, 선택한 레코드를 확인하고 **저장**을 선택해요. 메시지를 보내기 전에 메시지 내용과 수신자를 다시 확인하세요.

4단계: **대화**의 작성 창에서 연결 버튼을 보면 메시지가 연결될 레코드 수를 알 수 있어요.

![4단계: 작성 창의 연결 버튼에 표시된 연결 레코드 수](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084168604/original/JGewpofpojiFcJlH2wOZnHq03xzcm3j_EA.png?1793002886)

5단계: 보내기 전에 레코드를 확인하거나 바꿔요. 여기서는 메시지가 속성 레코드에 연결되어 있어요.

![5단계: 보내기 전 연결된 레코드 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084168599/original/0hxdRGw-1uYjkKJXDwSG54xYYDjFDg-Tvg.png?1793002886)

---

### 이미 있는 메시지에 연결하기

1. 메시지의 점 세 개 메뉴를 열고 **연결 추가**를 선택해요. 이메일은 이메일 머리글의 점 세 개 메뉴를 사용해요.
2. **속성** 같은 해당 사용자 지정 객체 유형을 선택해요.
3. 레코드를 검색해서 선택해요.
4. **저장**을 선택해요.

메시지의 연결 배지에 연결된 레코드 수가 표시돼요. 배지를 선택하면 연결된 레코드를 확인하거나 수정할 수 있어요.

6단계: 이미 있는 이메일은 이메일 머리글의 점 세 개 메뉴를 열고 **연결 추가**를 선택하세요.

![6단계: 이메일 머리글의 점 세 개 메뉴에서 연결 추가 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084168605/original/RlKeMTfSBfW-SiiD3Bu0Dy4AazPGoPzb5w.png?1793002886)

7단계: **속성** 같은 사용자 지정 객체 유형을 고르고, 검색해서 레코드를 선택한 뒤 **저장**을 클릭하세요.

![7단계: 객체 유형 선택 후 레코드 검색, 선택, 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084168600/original/2A3NudJwPsSYTxcfugfM68bB-al6p3wxrA.png?1793002886)

---

### 여러 메시지를 한꺼번에 연결하기

1. 대화 상단에서 **메시지 일괄 연결**을 선택해요.
2. 연결할 메시지를 선택해요.
3. **연결 추가**를 선택하고 레코드를 골라요.
4. **저장**을 선택해요.

8단계: 여러 메시지를 연결하려면 **메시지 일괄 연결**을 클릭하고, 메시지를 선택한 뒤 **연결 추가**를 선택하세요.

![8단계: 메시지 일괄 연결 후 연결 추가 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084168607/original/xoq3Gl2xEQ8fskH3eLKUMXJXo8Y_rKg0Kg.png?1793002886)

## 자주 묻는 질문

### 메시지를 레코드에 연결하면 연락처의 대화에서 사라지나요?
아니요. 메시지는 연락처의 대화에 그대로 남고, 연결된 각 레코드에도 표시돼요.

### 같은 메시지를 여러 레코드에 연결할 수 있나요?
네. 하나의 메시지를 여러 사용자 지정 객체 레코드, 회사, 그 밖에 지원되는 레코드 유형에 연결할 수 있어요.

### 회사 레코드 하나에서 여러 연락처의 대화를 볼 수 있나요?
네. 회사의 **대화** 피드에는 그 회사에 연결된 메시지가 표시되고, 서로 다른 연락처가 주고받은 메시지도 함께 보여요. **연락처** 필터를 사용하면 피드를 좁힐 수 있어요.

### 회사나 사용자 지정 객체 레코드에서 바로 대화를 시작할 수 있나요?
네. 레코드의 **대화** 탭을 열고 **대화 만들기**를 선택한 뒤 연락처를 고르고 계속 진행하세요. 현재 레코드는 이미 연결된 상태예요.

### 레코드에 연결할 수 없는 메시지는 무엇인가요?
그룹 SMS와 내부 채팅 메시지는 레코드에 연결할 수 없어요.

### 이 기능은 모든 서브 계정에서 쓸 수 있나요?
아니요. 현재 비공개 베타로 제공되며, 기능이 활성화된 서브 계정에서만 쓸 수 있어요.
