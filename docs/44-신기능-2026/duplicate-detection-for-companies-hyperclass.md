# 회사 추가할 때 중복 회사 미리 확인하기

회사를 새로 추가할 때 회사명이나 도메인을 입력하면, 하이퍼클래스가 이미 있는 비슷한 회사를 바로 찾아서 보여 줘요. 실수로 같은 회사를 두 번 만드는 일을 막고, 관련 정보를 한곳에 모아 둘 수 있어요.

회사 기록을 잘 정리해 두면 연락처, 기회, 계정 정보를 더 쉽게 관리할 수 있어요.

## 회사 중복 감지란?

**Preemptive Duplicate Detection for Companies**(회사 중복 사전 감지)는 **실험실** 기능이에요. 회사를 직접 만드는 중에 중복일 수 있는 회사를 찾아 줘요.

**회사 추가** 패널에서 회사명이나 도메인을 입력하면, 하이퍼클래스가 비슷한 정보를 가진 기존 회사가 있는지 확인해요. 일치할 만한 회사가 있으면 **"This company may already exist"**(이 회사가 이미 있을 수 있어요)라는 메시지와 함께 추천 회사가 나타나요.

추천된 회사를 열어 볼 수도 있고, 추천을 닫고 새 회사를 계속 만들 수도 있어요.

---

## 회사 중복 감지의 장점

회사를 만들기 전에 중복 가능성을 확인하면 CRM 데이터를 정확하게 유지할 수 있어요. 한 회사의 정보가 여러 기록으로 흩어지는 일도 막을 수 있어요.

- 조기 발견: 새 회사를 저장하기 전에 중복일 수 있는 회사를 확인해요.
- 유연한 이름 일치: 이름의 일부만 입력했거나, 문장 부호가 다르거나, 흔한 오타가 있어도 찾아 줘요.
- 도메인 일치: 이름을 입력하지 않아도 도메인만으로 기존 회사를 찾을 수 있어요.
- 더 나은 데이터 정리: 관련 연락처, 기회, 계정 정보를 한곳에 모아 둘 수 있어요.
- 유연한 기록 생성: 추천을 확인해 보고, 다른 회사라면 그대로 새로 만들 수 있어요.

---

## 회사 중복 감지 켜고 사용하기

이 실험실 기능을 켜 두면 팀원들이 회사를 만들 때 중복 가능성을 바로 확인할 수 있어요. 그만큼 계정 정보가 여러 기록으로 나뉠 위험도 줄어요.

### 1단계: 실험실에서 기능 켜기

1. 해당 서브 계정을 여세요.
2. **설정 > 실험실**로 이동하세요.
3. **Preemptive Duplicate Detection for Companies**(회사 중복 사전 감지)를 찾으세요.
4. 기능을 켜세요.

### 2단계: 회사 추가하기

1. **연락처 > 회사**로 이동하세요.
2. **회사 추가**를 클릭하세요.

   ![회사 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084292024/original/tX09WhX5Qtnwy1gnvzJMTmKdU9suE-aM3Q.png?1793097185)
3. **회사명** 또는 **도메인 이름**에 두 글자 이상 입력하세요.

   ![회사명 입력 시 나타나는 중복 추천](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084292154/original/dVB8Yammc7bTlXytZwpVuVNifgmwJhWCbQ.png?1793097257)

   ![도메인 이름 입력 시 나타나는 중복 추천](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084292178/original/d_gcdH1B44VqTqu4H4DEysMfPCMQuGFBdg.png?1793097288)
4. 나타난 중복 추천을 확인하세요.

### 3단계: 추천 확인하기

1. 일치하는 회사를 선택하면 기존 회사 기록이 열려요.
2. 회사 상세 정보를 보고 같은 사업체가 맞는지 확인하세요.
3. 추천된 회사가 다른 회사라면 추천을 닫으세요.
4. 필수 항목을 입력하고 **저장**을 클릭하면 별개의 회사가 만들어져요. 단, 적용 중인 다른 검증 규칙을 통과해야 해요.

## 회사 중복 감지는 어떻게 동작하나요?

입력하는 동안 하이퍼클래스가 회사명과 도메인을 확인해요. 그래서 회사 목록에서 직접 검색하지 않아도 기존 회사를 찾을 수 있어요.

**회사명** 또는 **도메인 이름** 필드에 **두 글자 이상** 입력하면 중복 추천이 나타날 수 있어요.

예를 들면 다음과 같아요.

| 입력한 정보 | 기존 회사 |
| --- | --- |
| Tesla Inc | Tesla, Inc. |
| Logitec | Logitech |
| logitech.com | 같은 도메인을 쓰는 회사 |

일치하는 회사를 찾으면 하이퍼클래스가 **"This company may already exist"** 메시지와 함께 추천 회사를 보여 줘요.

{% hint style="info" %}
추천이 나타나도 기록이 자동으로 병합되지는 않아요. 또한 모든 중복이 감지된다고 보장하지도 않아요.
{% endhint %}

---

## 중복일 수 있는 회사 확인하기

이름이나 도메인이 비슷해도 같은 사업체가 아닐 수 있어요. 추천된 회사를 확인하면 불필요한 중복은 피하고, 서로 다른 회사는 따로 관리할 수 있어요.

- 이미 있는 회사라면: 추천된 회사를 선택해 기록을 열고 확인하세요.
- 다른 회사라면: 추천을 닫고 새 회사를 계속 만드세요.
- 추천이 나타나지 않는다면: 회사명이나 도메인을 더 정확하게 입력해 보거나, 회사 목록에서 직접 검색해 보세요.

{% hint style="warning" %}
추천을 닫아도 회사에 적용되는 다른 제한이 사라지지는 않아요. **Automatically prevent duplicate companies**(중복 회사 자동 방지)가 켜져 있으면, 도메인 고유성 규칙 때문에 저장이 막힐 수 있어요.
{% endhint %}

자세한 내용은 [회사 도메인 이름 필드와 중복 방지](../02-연락처/company-domain-name-field-and-duplicate-prevention.md)를 참고하세요.

## 자주 묻는 질문

### 중복된 회사를 자동으로 병합해 주나요?
아니요. 회사를 만드는 중에 일치할 수 있는 회사를 추천해 주기만 해요. 기존 기록은 병합되지 않아요.

### 중복 추천이 나와도 회사를 만들 수 있나요?
네. 추천을 닫고 계속 진행할 수 있어요. 다만 다른 회사 검증 규칙에서 저장을 허용해야 해요.

### 기존 회사가 추천에 나타나지 않는 이유는 뭔가요?
입력한 글자가 너무 짧거나 철자가 많이 다르면 일치하지 않을 수 있어요. 회사명이나 도메인을 더 자세히 입력해 보세요.

### 예전에 만들어진 중복 회사도 찾아 주나요?
새 회사를 입력할 때 기존 회사 기록을 추천해 줄 수는 있어요. 하지만 이미 생긴 중복을 검색하거나 정리해 주지는 않아요.

### 연락처, 기회, 커스텀 오브젝트에서도 중복 감지가 되나요?
아니요. 이번 기능은 **회사 추가** 패널에서 회사를 직접 만들 때만 적용돼요.

### 회사 CSV 가져오기에서도 이 기능이 동작하나요?
아니요. CSV 가져오기에는 별도의 중복 처리 규칙이 있어요. [회사 일괄 가져오기](../02-연락처/bulk-import-companies-008400.md)를 참고하세요.

### 실험실에서 이 기능이 보이지 않아요.
올바른 서브 계정에 있는지, 필요한 권한이 있는지 확인하세요. 에이전시 관리자가 접근 권한을 켜 줘야 할 수도 있어요.
