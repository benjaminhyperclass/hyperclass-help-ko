# 브랜드 보드의 디자인 키트 편집하기

로고, 색상, 글꼴, 타이포그래피 스타일을 한곳에서 관리하면 브랜드의 모습을 일관되게 유지할 수 있어요. 이 문서에서는 **브랜드 보드**(Brand Boards)의 디자인 키트(Design Kit)를 편집하고, 타이포그래피 스타일을 설정하고, 변경 내용을 저장하는 방법을 안내해요.

## 디자인 키트란?

디자인 키트는 하이퍼클래스의 브랜드 보드 안에 저장되는 브랜딩 요소 모음이에요. 로고, 브랜드 색상, 글꼴, 미리 정해진 타이포그래피 스타일이 들어 있어서 브랜드의 모습을 한 곳에서 관리할 수 있어요.

저장해 둔 브랜드 색상과 글꼴은 하이퍼클래스에서 지원하는 빌더에서 쓸 수 있어요. 그래서 브랜드 가이드에 맞춰 콘텐츠를 만들기가 쉬워져요.

타이포그래피 스타일 기능으로는 글꼴, 무게, 크기, 줄 높이처럼 텍스트 종류별 서식을 따로 정할 수 있어요.

{% hint style="info" %}
디자인 키트를 수정해도 이미 만들어 둔 페이지나 이메일의 모습은 자동으로 바뀌지 않아요. 미리 정해진 타이포그래피 스타일은 브랜드 보드에서 설정할 수 있지만, 빌더에서 이 스타일을 바로 선택하는 기능은 이후 업데이트에서 제공될 예정이에요.
{% endhint %}

## 타이포그래피 스타일 이해하기

타이포그래피 스타일은 텍스트 종류마다 어떻게 보일지 정해서, 글의 위계를 일관되게 만들어 줘요. 스타일마다 글꼴, 무게, 크기, 줄 높이 설정이 따로 있어서 브랜드에 맞게 바꿀 수 있어요.

디자인 키트에는 미리 정해진 타이포그래피 스타일이 8가지 들어 있어요.

| 타이포그래피 스타일 | 용도 |
| --- | --- |
| **제목** | 주 제목과 눈에 띄어야 하는 텍스트 |
| **자막** | 제목 아래에 들어가는 보조 텍스트 |
| **제목 1** | 가장 큰 단위의 제목 |
| **제목 2** | 그다음 단위의 제목 |
| **Section header**(섹션 제목) | 콘텐츠 섹션을 시작하는 제목 |
| **Quote**(인용문) | 인용구나 강조하고 싶은 문장 |
| **본문** | 문단과 일반 텍스트 |
| **캡션** | 짧은 설명과 보충 정보 |

스타일마다 기본값이 미리 채워져 있고, 각각 따로 바꿀 수 있어요.

설정할 수 있는 서식 옵션은 다음과 같아요.

- **글꼴**: 스타일에 쓸 글꼴을 골라요.
- **무게**: 글자가 얼마나 굵거나 가늘게 보일지 정해요.
- **크기**: 글자 크기를 조절해요.
- **줄 높이**: 줄과 줄 사이 간격을 정해요.

{% hint style="info" %}
미리 정해진 이 스타일들은 디자인 키트 안에서 브랜드의 타이포그래피 설정을 잡아 주는 용도예요. 스타일을 설정해도 이미 만든 콘텐츠에는 자동으로 적용되지 않아요.
{% endhint %}

## 디자인 키트 편집하기

### 1단계: 브랜드 보드 열기

1. 서브 계정 왼쪽 메뉴에서 **마케팅 > 브랜드 보드**로 이동해요.
2. 수정할 브랜드 보드를 찾아요.

### 2단계: 로고 바꾸기

**로고** 탭에서 기존 브랜드 이미지를 교체할 수 있어요. 디자인 키트에 최신 로고를 담아 두세요.

1. 디자인 키트에서 **로고** 탭을 선택해요.
2. 바꾸려는 로고를 찾아요.
3. **Logo 1**(로고 1) 또는 **Logo 2**(로고 2) 옆의 **편집**(연필) 아이콘을 클릭해요.
4. 교체할 로고를 선택하거나 업로드해요.

{% hint style="info" %}
디자인 키트에서 로고를 교체해도 **미디어 라이브러리**에 있는 원본 파일은 삭제되지 않아요. 이전 로고 파일을 완전히 없애려면 **미디어 라이브러리**에서 직접 삭제하세요.
{% endhint %}

### 3단계: 브랜드 색상 관리하기

**색상** 탭에서는 저장해 둔 브랜드 색상 팔레트를 관리할 수 있어요. 색상을 추가하거나 바꾸고, 이름을 변경하거나 제거해서 디자인 키트를 현재 브랜딩에 맞춰 두세요.

1. 디자인 키트에서 **색상** 탭을 선택해요.
2. 하려는 작업을 골라요.

   - 색상 추가: **+ 추가**를 클릭해 브랜드 색상을 하나 더 만들어요.
   - 색상 변경: 기존 색상 옆의 색상 사각형을 클릭하고 바꿀 색을 선택해요.
   - 색상 이름 변경: 색상 이름 입력란을 클릭하고 새 이름을 입력해요.
   - 색상 제거: 지우려는 색상 옆의 휴지통 아이콘을 클릭해요.

{% hint style="info" %}
일반 브랜드 보드 색상을 수정해도 이미 만든 페이지나 이메일에 적용된 색상은 자동으로 바뀌지 않아요. **전역 사용자 지정 색상**은 동기화 방식이 따로 있어요.
{% endhint %}

### 4단계: 글꼴 추가하거나 바꾸기

**타이포그래피** 탭에서는 브랜드 보드에 연결된 글꼴을 관리할 수 있어요. 자주 쓰는 글꼴을 저장해 두면 지원하는 빌더에서 콘텐츠를 만들 때 바로 꺼내 쓸 수 있어요.

1. 디자인 키트에서 **타이포그래피** 탭을 선택해요.
2. 하려는 작업을 골라요.

   - 글꼴 추가: **+ 추가**를 클릭하고 글꼴을 선택해요.
   - 글꼴 변경: 글꼴 드롭다운에서 다른 글꼴을 선택해요.
   - 글꼴 제거: 지우려는 글꼴 옆의 휴지통 아이콘을 클릭해요.

디자인 키트에는 글꼴을 최대 5개까지 저장할 수 있고, 최소 1개는 남아 있어야 해요.

### 5단계: 타이포그래피 스타일 설정하기

**타이포그래피** 탭의 **스타일** 영역에서 텍스트 종류별 모양을 설정할 수 있어요. 스타일마다 따로 편집할 수 있어서, 모든 텍스트에 같은 서식을 쓰지 않고도 일관된 위계를 만들 수 있어요.

1. **타이포그래피** 탭에서 **스타일** 영역을 찾아요.
2. 미리 정해진 타이포그래피 스타일 8가지를 확인해요.
3. 설정하려는 스타일을 찾아요.
4. 해당 스타일 옆의 **편집** 아이콘을 클릭해요.

   <!-- 스크린샷 자리: 미리 정해진 스타일 옆의 편집 아이콘이 표시된 타이포그래피 스타일 영역 -->
5. 서식 설정을 조정해요.

   - **글꼴**: 원하는 글꼴을 선택해요.
   - **무게**: 글꼴 무게를 골라요.
   - **크기**: 텍스트 크기를 정해요.
   - **줄 높이**: 줄 사이 간격을 조절해요.
   - <!-- 스크린샷 자리: 글꼴, 무게, 크기, 줄 높이 설정이 보이는 타이포그래피 스타일 편집 화면 -->
6. 바꾸고 싶은 다른 스타일도 같은 방법으로 반복해요.

{% hint style="warning" %}
미리 정해진 타이포그래피 스타일은 브랜드 보드에서 설정할 수 있어요. 빌더에서 이 스타일을 바로 선택해 적용하는 기능은 이후 업데이트에서 제공될 예정이에요.
{% endhint %}

### 6단계: 변경 내용 저장하기

브랜드 보드를 저장하면 로고, 색상, 글꼴, 타이포그래피 스타일에 한 변경 내용이 보관돼요.

1. 수정한 디자인 키트 설정을 확인해요.
2. 오른쪽 위의 **Save Board**(보드 저장)를 클릭해요.

수정한 브랜딩 설정이 브랜드 보드에 저장돼요.

## 자주 묻는 질문

### 디자인 키트를 수정하면 기존 페이지나 이메일도 자동으로 바뀌나요?

아니요. 디자인 키트를 수정해도 기존 페이지나 이메일은 자동으로 바뀌지 않아요. 앞으로 지원하는 빌더에서 편집할 때 수정한 브랜드 자산을 쓸 수 있어요.

### 타이포그래피 스타일을 하나씩 따로 설정할 수 있나요?

네. 미리 정해진 8가지 스타일마다 글꼴, 무게, 크기, 줄 높이 설정이 따로 있어서 텍스트 종류별로 각각 설정할 수 있어요.

### 미리 정해진 타이포그래피 스타일을 이메일 빌더, 퍼널 빌더, 웹사이트 빌더에서 바로 적용할 수 있나요?

미리 정해진 8가지 타이포그래피 스타일을 빌더에서 바로 선택하는 기능은 이후 업데이트에서 제공될 예정이에요. 브랜드 보드에 저장한 글꼴과 색상은 지원하는 빌더에서 쓸 수 있지만, 이것은 타이포그래피 스타일을 적용하는 것과는 별개예요.

### 브랜드 보드 색상이 지원하는 빌더에 나타나지 않아요.

기본 브랜드 보드만 해당 빌더의 브랜드 색상 선택기에 표시돼요. 올바른 브랜드 보드가 기본으로 설정되어 있는지, 변경 내용을 저장했는지 확인해 보세요. 자세한 방법은 [하이퍼클래스에서 기본 브랜드 보드 변경하기](../10-마케팅/how-to-change-default-brand-boards.md)를 참고하세요.

### 디자인 키트에 글꼴을 5개보다 많이 저장할 수 있나요?

아니요. 디자인 키트에는 글꼴을 최대 5개까지 저장할 수 있고, 최소 1개는 있어야 해요.

### 디자인 키트에서 로고를 교체하면 미디어 라이브러리의 원본 이미지도 삭제되나요?

아니요. 디자인 키트에서 로고를 교체해도 **미디어 라이브러리**의 원본 파일은 삭제되지 않아요. 더 이상 필요 없다면 파일을 따로 삭제해야 해요.

### 브랜드 보드를 수정하면 결제 링크에도 영향이 있나요?

**결제 링크**에 브랜드 보드 테마를 쓰고 있다면, 해당 브랜드 색상을 수정한 내용이 링크에 반영될 수 있어요.
