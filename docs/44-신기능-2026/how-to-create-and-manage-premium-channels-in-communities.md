# 커뮤니티 프리미엄 채널 만들고 관리하기

하이퍼클래스의 프리미엄 채널을 쓰면 공개 범위와 유료 가입 방식을 직접 정하는 비공개 커뮤니티 채널을 만들 수 있어요. 채널을 숨길 수도 있고, 내용은 보여 주지 않은 채 채널 존재만 알릴 수도 있고, 가입비를 받을 수도 있어요.

## 비공개 채널 옵션 이해하기

### 채널 공개 여부

접근 권한이 없는 멤버에게 비공개 채널이 어떻게 보일지 정해요.

| 옵션 | 설명 |
| --- | --- |
| **표시됨** | 채널이 사이드바에 보여요. 멤버가 아닌 사람도 채널 정보는 볼 수 있지만, 게시글과 콘텐츠는 잠겨 있어요. |
| **숨김** | 접근 권한이 없는 멤버의 사이드바에는 채널이 나타나지 않아요. |

![비공개 채널 공개 여부 설정 화면](https://jumpshare.com/share/Vbp3PTkIfN0Cu5rQz1AS+/Screen+Shot+2026-10-15+at+22.04.43.png)

### 채널 가격

| 옵션 | 설명 |
| --- | --- |
| **무료** | 멤버가 관리자나 채널 매니저에게 연락해 접근을 요청해요. |
| **반복** | 멤버가 월간 또는 연간 구독료를 내고 가입해요. |
| **1회 결제** | 멤버가 한 번만 결제하고 가입해요. |

![채널 가격 옵션 화면](https://jumpshare.com/share/qxf0Sjz2SeQS5SWoi9pI+/Screen+Shot+2026-10-15+at+22.08.30.png)

## 프리미엄 채널 만들기

{% hint style="info" %}
유료 채널을 설정할 때 **Test Mode**(테스트 모드)를 사용하면 결제 설정이 제대로 되었는지 테스트해 볼 수 있어요.
{% endhint %}

1. **멤버십 > 커뮤니티 > 그룹**으로 이동한 뒤 커뮤니티 그룹에 접속하세요.

   ![커뮤니티 그룹 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083445833/original/Xgw_7mpBbxO_TaNcNf_2OPqETRDXTpFO9w.png?1792082941)
2. **채널** 아래의 **+** 아이콘을 클릭하세요.
3. **Create a channel for conversations and updates**(대화와 소식을 나누는 채널 만들기)를 선택하세요.
4. **채널 이름**을 입력하고 **아이콘**을 선택하세요. 필요하면 **설명**도 입력하세요.
5. **Private channel**(비공개 채널)을 켠 뒤 **표시됨** 또는 **숨김**을 선택하세요.
6. **계속**을 클릭하세요.
7. **가격 옵션**을 선택하세요.

   - **무료**: 결제 없이 접근할 수 있어요. 관리자나 채널 매니저의 승인이 필요해요.
   - **반복**: 통화를 선택하고, 월간 또는 연간 결제를 켠 뒤 각각의 가격을 입력하세요.
   - **1회 결제**: 한 번에 결제할 금액을 설정하세요.
8. **Create Channel**(채널 만들기)을 클릭하세요.

![프리미엄 채널 만들기 과정 녹화 화면](https://jumpshare.com/share/uBISgMHcTwguqqfCX56s+/GIF+Recording+2026-10-15+at+22.20.09.gif)

## 공개 여부와 가격 관리하기

채널을 만든 뒤에도 비공개 채널 설정을 바꿀 수 있어요.

1. 커뮤니티 그룹을 열고 사이드바에서 채널을 찾으세요.
2. 채널의 **설정**을 여세요.
3. **소개**에서 **편집**을 눌러 채널 상세 정보와 공개 여부 설정을 관리하세요.
4. **가격** 탭을 열어 채널의 결제 옵션을 관리하세요.

![채널 공개 여부와 가격 관리 과정 녹화 화면](https://jumpshare.com/share/n9bF9sxVZo0kMZsuHF9l+/GIF+Recording+2026-10-15+at+22.12.14.gif)

## 중요 사항

- 프리미엄 채널의 공개 여부와 가격 설정은 비공개 채널에서만 쓸 수 있어요. 공개 채널은 달라지지 않아요.
- **표시됨**으로 설정한 비공개 채널도 게시글과 토론은 접근 권한이 있는 멤버에게만 열려 있어요.
- 채널을 만들 때 **Read Only Channel**(읽기 전용 채널)을 켜면, 관리자만 글을 올릴 수 있어요.
