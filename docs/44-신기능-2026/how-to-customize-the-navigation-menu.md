# 내비게이션 메뉴 사용자 지정

자주 쓰는 상품을 쉽게 찾을 수 있도록 하이퍼클래스 내비게이션 메뉴를 바꿀 수 있어요. 그룹 이름 변경, 아이콘 변경, 순서 변경, 상품 숨기기, 새 그룹 만들기를 할 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

내비게이션 사용자 지정은 모든 에이전시 플랜에서 쓸 수 있지만, 구독 수준에 따라 할 수 있는 범위가 달라요. 모든 플랜에서 새로 바뀐 내비게이션 화면을 쓸 수 있고, 상위 플랜에서는 사용자 지정 옵션이 더 많아요. 이 문서에서는 **새로운 하이퍼클래스 화면**에서 내비게이션 사용자 지정이 어떻게 동작하는지, 공유 레이아웃이 서브 계정에 어떤 영향을 주는지, 내비게이션을 꾸미고 저장하는 방법을 안내해요.

---

## 내비게이션 메뉴 사용자 지정이란?

내비게이션 메뉴 사용자 지정은 왼쪽 사이드바에 그룹과 상품이 보이는 방식을 바꾸는 기능이에요. 내비게이션 편집기에서 메뉴의 구성과 표시 여부를 조정할 수 있어요. 상품 기능이나 접근 권한은 달라지지 않아요.

바꾼 내용은 개별 사용자의 개인 설정이 아니라 서브 계정의 내비게이션 레이아웃에 저장돼요.

---

## 내비게이션 메뉴 사용자 지정의 장점

팀이 일하는 방식에 맞춰 메뉴를 정리하면 자주 쓰는 상품을 더 쉽게 찾을 수 있어요. 상품 기능은 그대로예요.

- 익숙한 구성: 그룹 이름을 바꾸고, 팀의 업무 흐름에 맞게 상품을 배치해요.
- 깔끔한 메뉴: 눈에 띄게 둘 필요가 없는 그룹이나 상품은 숨겨요.
- 빠른 접근: 자주 쓰는 그룹과 상품을 앞쪽으로 옮겨요.
- 보기 쉬운 구분: 내비게이션 아이콘을 바꿔 항목을 더 쉽게 알아봐요.
- 일관된 내비게이션: 같은 서브 계정의 사용자에게 같은 레이아웃을 보여 줘요. 단, 각 사용자의 상품 권한에 따라 보이는 항목은 달라질 수 있어요.

---

## 사용 가능 여부와 공유 내비게이션

내비게이션 사용자 지정을 쓰려면 사용 가능한 에이전시 플랜이어야 하고, 내비게이션 편집기에 접근할 수 있어야 해요. 플랜에 따라 사용자 지정할 수 있는 서브 계정 수가 달라요.

| 에이전시 플랜 | 내비게이션 사용자 지정 |
| --- | --- |
| 월 $97 | 기본 내비게이션만 사용할 수 있어요. 사용자 지정은 포함되지 않아요. |
| 월 $297 | 서브 계정 1개를 사용자 지정할 수 있어요. 재사용 가능한 레이아웃과 여러 서브 계정에 적용하는 기능은 포함되지 않아요. |
| 월 $497 | 모든 서브 계정을 사용자 지정하고, 재사용 가능한 레이아웃을 만들고, 여러 서브 계정에 레이아웃을 적용할 수 있어요. |

적용한 뒤에는 그룹 이름, 순서, 숨긴 항목, 상품 구성이 서브 계정의 공유 내비게이션 레이아웃에 반영돼요.

{% hint style="info" %}
**최근 대화**와 **고정됨**은 사용자마다 따로 유지되며, 공유 레이아웃을 편집해도 바뀌지 않아요. 각 사용자가 접근할 수 있는 항목은 계속 상품 권한에 따라 정해져요.
{% endhint %}

## 내비게이션 단계와 사용자 지정 옵션

내비게이션 단계에 따라 쓸 수 있는 사용자 지정 작업이 달라요.

- L1: 최상위 내비게이션 그룹이에요.
- L2: L1 그룹 안에 있는 상품 또는 항목이에요.
- L3: L2 항목 아래에 중첩된 항목이에요.

| 작업 | L1: 내비게이션 그룹 | L2: 상품 또는 항목 | L3: 중첩 항목 |
| --- | --- | --- | --- |
| 이름 변경 | 가능 | 불가 | 불가 |
| 아이콘 변경 | 가능 | 가능 | 가능 |
| 순서 변경 | 최상위 그룹끼리 | 현재 속한 L1 그룹 안에서 | 현재 속한 L2 상위 항목 안에서 |
| 개별 숨기기/표시 | 가능 | 가능 | 불가 |
| 편집기에서 만들기 | 가능 | 불가 | 불가 |
| 다른 L1 그룹으로 이동 | 해당 없음 | 가능 | 가능 (그룹 메뉴로 바로 이동) |

{% hint style="warning" %}
순서 변경은 항목이 속한 상위 항목 안에서 위치만 바꾸는 작업이에요. 이동은 항목이 들어 있는 그룹을 바꾸는 작업이에요. 내비게이션 그룹을 만들어도 새로운 하이퍼클래스 상품이 생기지는 않아요.
{% endhint %}

---

## 이름 규칙과 고정 내비게이션 항목

그룹 이름은 알아보기 쉽게 정하세요. 꼭 필요한 이동 경로를 위해 일부 항목은 보호돼 있어요.

- 그룹 이름은 비워 둘 수 없고, 공백만으로 만들 수도 없어요.
- 같은 내비게이션 안에서 다른 L1 그룹 이름과 같은 이름은 쓸 수 없어요.
- 이름 앞뒤의 공백은 자동으로 지워져요.
- **최근 대화**와 **고정됨**은 예약된 이름이에요.
- 긴 이름은 말줄임표(…)로 표시될 수 있어요. 줄여서 보이는 이름에 마우스를 올리면 전체 이름이 보여요.
- **설정**은 고정된 위치에 그대로 있어요.
- **최근 대화**와 **고정됨**은 숨길 수 없어요.
- **사용자 정의 메뉴 링크**와 사용자 지정 페이지는 내비게이션 편집기에서 이름을 바꿀 수 없어요. 처음 만든 곳에서 이름을 수정하세요.

---

## 내비게이션 표시 여부와 상품 접근 권한의 차이

내비게이션 표시 여부는 항목이 사이드바에 보이는지를 정해요. 사용자가 상품에 접근할 수 있는지는 권한이 정해요.

상품을 숨겨도 상품이 비활성화되거나 접근이 제한되지 않아요. 필요한 권한이 있는 사용자는 숨긴 상품도 직접 URL이나 **전체 상품**에서 열 수 있어요.

반대로 내비게이션 레이아웃에서 상품을 표시하더라도 사용자 권한이나 **SaaS 구성기**의 제한이 풀리지 않아요.

{% hint style="warning" %}
상품 접근을 제한하려면 기능 권한이나 사용자 권한을 사용하세요. 내비게이션 사용자 지정은 사이드바에서 상품을 어떻게 정리해서 보여 줄지 정할 때 사용하세요.
{% endhint %}

## 내비게이션 메뉴 사용자 지정하기

바꾸려는 내비게이션이 있는 서브 계정에서 시작하세요. 내비게이션 편집기로 메뉴를 정리한 뒤, 저장하기 전에 레이아웃과 적용 범위를 확인하세요.

### 1단계: 내비게이션 편집기 찾기

편집기로 들어가는 버튼은 사이드바 맨 아래에 있어요. 지금 보고 있는 페이지를 편집하는 컨트롤과는 별개예요.

1. **새로운 하이퍼클래스 화면**에서 서브 계정을 여세요.
2. 왼쪽 내비게이션 맨 아래에서 **편집**을 찾으세요.

**![사이드바 맨 아래의 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084247746/original/vwdp8cdADFozwHW4WwQzSA8jGU_RAt7F4A.png?1793042218)**

{% hint style="info" %}
사이드바의 **편집**을 선택하세요. 대시보드 도구 모음에 있는 **대시보드 수정**을 선택하면 안 돼요.
{% endhint %}

### 2단계: 편집 모드 열기

편집 모드에서는 내비게이션 항목 옆에 사용자 지정 컨트롤이 나타나요. 상품을 하나씩 열지 않고도 메뉴를 정리할 수 있어요.

1. 사이드바 맨 아래의 **편집**을 클릭하세요.
2. 편집 모드에서 내비게이션을 살펴보세요.

메인 페이지는 어둡게 표시돼요. 사이드바에는 드래그 핸들, 점 3개 메뉴, **Add a category or product**(카테고리 또는 상품 추가), 맨 아래의 **편집 중** 패널 같은 컨트롤이 나타나요.

**![편집 모드의 사이드바](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084247866/original/mOIP0tBPsgRSEv5fp1Xa-7C8lkK6diE5Ng.png?1793042522)**

### 3단계: 내비게이션 그룹과 항목 순서 바꾸기

순서 변경은 항목이 속한 내비게이션 단계 안에서 위치를 바꾸는 작업이에요.

1. 그룹이나 항목 옆의 드래그 핸들을 길게 누르세요.
2. 원하는 위치로 끌어다 놓습니다.
3. 가로 배치 표시선을 보고 항목이 놓일 위치를 확인하세요.
4. 마우스를 놓아 그 위치에 배치해요.

**![드래그해서 순서를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084249807/original/jNAPjRK-NRh79m-cUeQB73XplScUPG-GiA.png?1793044610)**

최상위 그룹은 그룹의 점 3개 메뉴에서 **위로 이동** 또는 **아래로 이동**을 선택해도 순서를 바꿀 수 있어요.

- L2 항목은 현재 속한 L1 그룹 안에서 순서를 바꿀 수 있어요.
- L3 항목은 현재 속한 L2 상위 항목 안에서 순서를 바꿀 수 있어요.
- 항목을 다른 그룹으로 옮기는 것은 별도의 작업이에요.
- **설정**은 순서를 바꿀 수 없어요.

### 4단계: 그룹 이름 바꾸기, 아이콘 변경하기

그룹 이름과 아이콘을 보면 팀원이 상품이 어디에 속하는지 알아보기 쉬워요. 이름 변경은 L1 그룹만 할 수 있고, 지원되는 내비게이션 아이콘은 세 단계 모두에서 바꿀 수 있어요.

1. 사용자 지정할 그룹이나 항목 옆의 **점 3개 메뉴(⋮)**를 클릭하세요.

그룹 이름을 바꾸려면:

2. **이름 변경**을 선택하세요.
3. 위의 이름 규칙에 맞게 짧고 알아보기 쉬운 그룹 이름을 입력하세요.
4. 화면에 나온 확인 버튼으로 변경을 마치세요.

![그룹 이름을 변경하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084250710/original/crv3QW537s6dqdkbdYMlXC7kBsStVSNDwQ.png?1793046238)

아이콘을 바꾸려면:

1. 항목의 **점 3개 메뉴(⋮)**를 여세요.
2. **아이콘 변경**을 선택하세요.
3. 사용할 내비게이션 아이콘을 고르세요.
4. 화면에 나온 버튼으로 변경을 마치세요.

{% hint style="info" %}
내비게이션 아이콘을 바꾸면 해당 내비게이션 항목 옆의 아이콘만 바뀌어요. 계정 아바타나 로고는 바뀌지 않아요.
{% endhint %}

### 5단계: 사용 가능한 내비게이션 레이아웃 확인하기

**Navigation Layouts**(내비게이션 레이아웃) 선택기에서 지금 편집 중인 레이아웃을 확인하고, 저장된 다른 레이아웃이 어떻게 쓰이고 있는지 살펴볼 수 있어요.

선택기에는 **Search layouts**(레이아웃 검색) 필드가 있어요. 선택한 레이아웃에는 체크 표시가 나타나요. 사용 현황 레이블로 다른 레이아웃이 사용 중이 아닌지, 서브 계정에 적용돼 있는지를 알 수 있어요.

**![내비게이션 레이아웃 선택기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084248845/original/GclxQoHtwugckCnxRBlC1h-aUeqoj7P87w.png?1793043346)**

{% hint style="info" %}
**Navigation Layouts** 선택기는 레이아웃 선택 현황과 사용 현황을 보여 줘요. 저장 확인 화면은 아니에요.
{% endhint %}

### 6단계: 표시 여부 관리하고 그룹 정리하기

숨기기 기능으로 사이드바를 단순하게 만들 수 있고, 그룹 정리 기능으로 팀의 업무에 맞게 상품을 배치할 수 있어요.

그룹의 **점 3개 메뉴(⋮)**를 열면 **숨기기**, **Add a product**(상품 추가) 같은 작업을 쓸 수 있어요.

**![그룹의 점 3개 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084249655/original/1bzQa-QxBe9L1G2nAZxOVI4YdTwG9ww0EQ.png?1793044384)**

### 그룹이나 상품 숨기기·표시하기

상품 접근 권한은 그대로 두고 사이드바에서만 항목을 없애고 싶을 때 쓰세요.

- L1 그룹은 숨기거나 다시 표시할 수 있어요.
- L2 상품은 하나씩 숨기거나 다시 표시할 수 있어요.
- L3 항목은 개별로 숨길 수 없어요.

숨길 수 있는 그룹이나 상품은 메뉴에서 **숨기기**를 선택하면 숨겨져요. 숨긴 항목은 내비게이션 편집기에서 표시 여부를 조절하는 컨트롤로 다시 보이게 할 수 있어요.

### 내비게이션 그룹 만들기

관련 있는 상품을 한곳에 모으고 싶을 때 새 내비게이션 그룹을 만드세요. 편집기에서는 내비게이션 그룹을 카테고리라고 부르기도 해요.

1. **Add a category or product**(카테고리 또는 상품 추가)를 선택하세요.
2. 카테고리를 만드는 옵션을 고르세요.
3. 새 그룹의 이름을 입력하세요.
4. 화면에 나온 버튼으로 만들기를 마치세요.

![새 내비게이션 그룹 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084250696/original/2C5z1wZD5ozUPfQwJFHPFuiDk3Evt4EXqg.png?1793046214)

새 그룹도 이름을 바꾸고, 아이콘을 지정하고, 기존 그룹들 사이에서 순서를 바꿀 수 있어요.

### 그룹에 상품 추가하기

1. 그룹의 **점 3개 메뉴(⋮)**를 여세요.
2. **Add a product**(상품 추가)를 선택하세요.
3. 화면에 나온 상품 선택 컨트롤로 그룹 안의 상품을 정리해요.

![그룹에 상품 추가하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084249478/original/XjBWlqQbiXE_blsxblRuA76hH6zgB_5m8Q.png?1793044101)

### 그룹 사이에서 상품 이동하기

이동은 항목이 들어 있는 내비게이션 그룹을 바꾸는 작업이에요. 현재 그룹 안에서 순서를 바꾸는 것과는 달라요.

- L2 상품은 다른 L1 그룹으로 옮길 수 있어요. 이름을 바꾼 그룹이나 새로 만든 그룹도 가능해요.
- L3 항목은 L2 상위 항목에서 빼서 L1 그룹 메뉴에 바로 넣을 수 있어요.

L3 항목을 L1 그룹으로 옮겨도 새로운 최상위 내비게이션 그룹은 만들어지지 않아요.

### 7단계: 레이아웃 확인하고 저장하기

저장하기 전에 내비게이션을 꼭 살펴보세요. 이미 다른 서브 계정에서 쓰는 레이아웃이라면 더 그래요.

1. 그룹 이름, 아이콘, 순서, 표시 여부, 상품 배치를 확인하세요.
2. 이 레이아웃을 이미 다른 서브 계정에서 사용하고 있는지 확인하세요.
3. 맨 아래 **편집 중** 패널에서 **Save layout**(레이아웃 저장)을 클릭하세요.

**![편집 중 패널의 레이아웃 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084249330/original/yP5AAvwT1x63B9eqiJFmmmXmCNtVHqIQnA.png?1793043843)**

4. 적용 범위를 묻는 창이 나타나면 변경 내용이 어디에 적용되는지 확인하세요.
5. 저장을 완료하세요.
6. 결과로 나온 내비게이션을 살펴보고 레이아웃이 의도한 대로 보이는지 확인하세요.

저장하면 설정이 기록되고, 기본적으로 지금 편집 중인 서브 계정에 적용돼요. 저장한 레이아웃을 다른 서브 계정에 적용하는 것은 별도의 작업이에요.

{% hint style="warning" %}
이미 여러 서브 계정에서 쓰고 있는 저장된 레이아웃을 업데이트하면 해당 서브 계정들에 영향을 줄 수 있어요. 월 $497 플랜에서는 한 번만 하는 편집을 공유 레이아웃에 업데이트하거나, 현재 서브 계정용으로 따로 저장할 수 있어요. 저장하기 전에 레이아웃 사용 현황을 확인하세요.
{% endhint %}

## 자주 묻는 질문

### 내비게이션 그룹 이름이 낯설 때 상품을 어떻게 찾나요?
**최근 대화** 옆의 **전체 보기**를 선택하면 **전체 상품**이 열려요. 그룹 이름을 바꿔도 이 목록에는 상품이 원래 하이퍼클래스 이름으로 표시돼요.

### 상품을 숨기면 접근도 막히나요?
아니요. 상품을 숨기면 내비게이션에서 보이는 여부만 바뀌어요. 필요한 권한이 있는 사용자는 **전체 상품**이나 직접 URL로 계속 접근할 수 있어요.

### 내비게이션 레이아웃도 스냅샷에 포함되나요?
아니요. 이번 릴리스에서는 내비게이션 레이아웃과 스냅샷이 서로 따로 동작해요. 스냅샷을 적용해도 기존 내비게이션 레이아웃이 바뀌지 않고, 내비게이션 사용자 지정으로 숨긴 항목이 복원되지도 않아요.

### 새로 만든 서브 계정에 에이전시의 사용자 지정 내비게이션 레이아웃이 자동으로 적용되나요?
아니요. 레이아웃은 에이전시가 선택한 서브 계정에만 적용돼요. 새로 만든 서브 계정은 에이전시의 사용자 지정 기본 내비게이션을 자동으로 물려받지 않아요.

### 에이전시가 월 $497 플랜에서 월 $297 플랜으로 내리면 기존 레이아웃은 어떻게 되나요?
기존 사용자 지정은 서브 계정에 그대로 남아 있어요. 이후 편집은 서브 계정 1개로 제한돼요. 플랜을 내린 뒤 처음 편집하는 서브 계정이 편집 가능한 서브 계정이 돼요. 다른 서브 계정은 기존 레이아웃을 유지하지만, 월 $297 플랜에서는 수정할 수 없어요.

### 새 내비게이션을 끄면 사용자 지정한 내용이 유지되나요?
아니요. 새 내비게이션을 끄면 사용자 지정한 내용이 사라져요. 다시 켜면 이전에 꾸며 둔 레이아웃이 복원되지 않고 기본 내비게이션부터 시작해요.

### 최근 대화와 고정됨도 같은 내비게이션 레이아웃을 쓰는 모든 사람에게 공유되나요?
아니요. **최근 대화**와 **고정됨**은 사용자마다 따로 유지돼요. 공유 내비게이션 레이아웃을 편집해도 바뀌지 않아요.
