# Agent Health와 자가 복구로 AI 에이전트 상태 관리하기

**Agent Health**(에이전트 상태)는 음성 AI와 대화 AI 에이전트의 성능을 확인하고, 문제가 생기면 테스트를 거친 프롬프트 개선안을 **Self Healing**(자가 복구)으로 받아 보는 기능이에요. 이 문서에서는 모니터링을 켜는 방법, 정기 점검을 설정하는 방법, 에이전트 성능을 확인하는 방법, 추천 개선안을 적용하는 방법을 설명해요.

---

## Agent Health와 자가 복구란?

Agent Health는 한 화면에서 AI 에이전트의 성능을 확인하는 모니터링 기능이에요.

**Monitoring**(모니터링)은 최근에 끝난 통화나 채팅으로 에이전트를 주기적으로 평가해요. 그리고 상태를 기록하고, 시간에 따른 정확도 변화를 추적해요.

**Self Healing**(자가 복구)은 모니터링에서 문제가 발견되면 **프롬프트 최적화 도구**로 개선된 프롬프트를 자동으로 만들고 테스트해요. 결과를 비교하고 제안된 변경 내용을 검토한 뒤에 실제 운영 중인 에이전트에 적용할 수 있어요. 프롬프트 최적화 도구에 대한 자세한 내용은 [음성 AI - 프롬프트 최적화 도구](../13-AI-Employee/Voice-AI/voice-ai-prompt-optimizer.md)를 참고하세요.

{% hint style="warning" %}
**중요:** 자가 복구는 운영 중인 에이전트를 자동으로 바꾸지 않아요. 추천된 프롬프트 변경은 모두 직접 승인해야 적용돼요.
{% endhint %}

---

## Agent Health 열고 켜기

모니터링과 자가 복구는 지원하는 에이전트마다 따로 켤 수 있어요.

1. **AI 에이전트 > Agent Health**로 이동해요.
2. 에이전트 목록, 검색창, 필터로 모니터링할 에이전트를 찾아요.
3. **자동화** 아래에서 **Monitoring**을 켜요.
4. 에이전트에 주의가 필요할 때 **프롬프트 최적화 도구**가 테스트를 마친 개선안을 자동으로 준비해 주길 원하면 **Self Healing**도 켜요.

{% hint style="info" %}
**참고:**

- 현재 Agent Health는 음성 AI와 대화 AI 에이전트를 지원해요.
- 자가 복구가 작동하려면 모니터링이 켜져 있어야 해요. 모니터링을 끄려면 먼저 자가 복구를 꺼야 해요.
- 에이전트를 관리할 권한이 있는 사용자만 해당 에이전트의 모니터링과 자가 복구 설정을 바꿀 수 있어요.
{% endhint %}

## Agent Health 설정하기

Agent Health는 공통 설정으로 에이전트를 언제 점검할지, 어떤 대화를 평가할지, 사용량을 어떻게 관리할지 정해요. 이 설정은 서브 계정에서 모니터링이 켜진 모든 에이전트에 적용돼요.

{% hint style="warning" %}
**중요:** 공통 설정을 저장해도 개별 에이전트의 모니터링이나 자가 복구가 자동으로 켜지지는 않아요.
{% endhint %}

1. **AI 에이전트 > Agent Health**를 열어요.
2. **Edit Agent Health settings**(Agent Health 설정 편집)를 클릭해요.
3. 아래 항목을 설정해요.

   - **확인 주기**: 에이전트를 얼마나 자주 모니터링할지 1일에서 30일 사이로 선택해요.
   - **Preferred run hour**(선호 실행 시간): 정기 점검을 시작할 UTC 시간을 선택해요. 가장 많이 쓰는 에이전트부터 먼저 점검해요.
   - **Conversations to use**(사용할 대화): 평가 샘플에 포함할, 끝난 대화를 선택해요.
   - **Number of conversations**(대화 수): 평가 한 번에 사용할 대화를 2개에서 10개 사이로 선택해요. 사용할 수 있는 대화 기록(트랜스크립트)이 최소 2개 필요하고, 기록이 없는 대화는 건너뛰어요.
   - **Monthly Agent Health budget**(월간 Agent Health 예산): 설정 패널에서 월간 예산, 사용량, 예약된 금액, 남은 금액을 확인해요.
4. **Save for all agents**(모든 에이전트에 저장)를 클릭해요.

![Agent Health 공통 설정 패널](https://jumpshare.com/share/r5DyZ1iaeCsrwputqvaF+/Screenshot+2026-10-15+at+7.09.58%E2%80%AFPM.png)

{% hint style="info" %}
**참고:** Agent Health 실행에도 기존 유료 AI [사용 제한](../13-AI-Employee/AI-Employee/ai-usage-limits.md)이 적용돼요. 플랜에 포함된 실행에는 **Covered by plan**(플랜에 포함)이라는 표시가 붙어요. 적용되는 AI 사용 제한 때문에 새 실행을 할 수 없으면 실행이 시작되지 않아요.
{% endhint %}

## 에이전트 상태 확인하기

Agent Health 대시보드에서는 대화량, 상태, 정확도 추이, 추천 사항, 예정된 점검을 한눈에 볼 수 있어요.

### 상태 확인하기

모니터링 결과에 따라 에이전트마다 아래 상태 중 하나가 표시돼요.

- **좋음**: 가장 최근 평가에서 성능이 괜찮은 것으로 나왔어요.
- **주의 필요**: 모니터링에서 성능 문제가 발견됐어요.
- **알 수 없음**: 상태를 판단할 수 없어요.
- **아직 확인되지 않음**: 에이전트가 아직 상태 평가를 마치지 않았어요.

대시보드에서 에이전트의 정확도 추이, 가장 최근 점검, 다음 예정 점검도 바로 볼 수 있어요.

![대시보드에서 에이전트별 상태와 정확도 추이 확인하기](https://jumpshare.com/share/eSm6gV36zWDghrtQCxHb+/Screenshot+2026-10-15+at+7.04.11%E2%80%AFPM+%281%29.png)

### 상세 결과 보기와 수동 점검 실행

1. **AI 에이전트 > Agent Health**를 열어요.
2. 에이전트 이름을 클릭해 상세 화면을 열어요.
3. **프롬프트 최적화 도구** 패널에서 최신 정확도 점수, 목표 정확도, 정확도 추이, 최근 평가를 확인해요.
4. **Run monitoring now**(지금 모니터링 실행)를 클릭하면 에이전트의 정기 모니터링 주기는 그대로 두고 평가를 한 번만 실행해요.

![에이전트 상세 화면의 프롬프트 최적화 도구 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083746411/original/WtFmp6Y1vCrUTYWcW4Lptg-4uoIrHUAc1Q.png?1792493807)

에이전트 로그에 대해서는 [에이전트 로그 개요](agent-logs-overview.md)를 참고하세요.

## 자가 복구 추천 검토하고 적용하기

에이전트에 주의가 필요하고 자가 복구가 켜져 있으면, **프롬프트 최적화 도구**가 개선된 프롬프트를 자동으로 만들고 테스트해요. 추천이 준비되면 에이전트 편집자에게 앱 내 알림과 이메일이 와요.

### 추천 검토하기

1. **AI 에이전트 > Agent Health**를 열어요.
2. **주의 필요**로 표시된 에이전트를 찾아요.
3. 대시보드에서 **Review & apply**(검토 및 적용)를 클릭하거나, 에이전트를 열고 **Review recommendation**(추천 검토)을 선택해요.

   ![대시보드에서 검토 및 적용 선택하기](https://jumpshare.com/share/ex9UCiLMeGuajsuJdKvb+/Screenshot+2026-10-15+at+7.04.11%E2%80%AFPM+%282%29.png)
4. **프롬프트 최적화 도구**의 추천 내용을 살펴봐요. 아래 내용이 포함돼 있어요.

   - 이전 정확도 점수와 추천 프롬프트의 정확도 점수
   - 테스트한 통화 수, 통과한 수, 실패한 수
   - 사용할 수 있는 최적화 변형과 가장 성능이 좋은 변형
5. **프롬프트 비교**에서 현재 프롬프트와 추천 프롬프트의 차이를 확인해요.
6. **AI 추론**을 선택해 어떤 점이 왜 개선안으로 제안됐는지 확인해요.
7. **View full prompt**(전체 프롬프트 보기)를 선택해 적용하기 전에 추천 프롬프트 전체를 확인해요.

   ![추천 프롬프트 검토 화면](https://jumpshare.com/share/codKjfmTsdNy8JcXZhT2+/Screenshot+2026-10-15+at+7.11.39%E2%80%AFPM.png)

### 추천 프롬프트 적용하기

{% hint style="warning" %}
**중요:** 테스트로 확인된 개선 효과는 그 평가에 포함된 대화를 기준으로 한 결과예요. 테스트 정확도 점수가 높다고 해서 실제 고객 응대에서도 모든 경우에 같은 결과가 나온다고 보장할 수는 없어요.
{% endhint %}

추천 내용을 검토한 뒤에 아래 순서로 진행하세요.

1. 제안된 지침이 에이전트가 의도한 동작과 맞는지 확인해요.
2. **Apply to live agent**(운영 중인 에이전트에 적용)를 클릭해 테스트를 마친 프롬프트를 적용해요.
3. 다음 모니터링 점검에서 업데이트 이후 에이전트 성능을 확인해요.

   ![운영 중인 에이전트에 추천 프롬프트 적용하기](https://jumpshare.com/share/dmBEmGVwTkfgkEg5pB5U+/Screenshot+2026-10-15+at+7.11.39%E2%80%AFPM+%281%29.png)
4. 개별 에이전트 페이지에서 **Run Self Healing now**(지금 자가 복구 실행)를 클릭하면 자가 복구를 한 번만 실행할 수도 있어요.

   ![에이전트 페이지에서 지금 자가 복구 실행하기](https://jumpshare.com/share/BMpoAPv32VdmtfCLwl60+/Screenshot+2026-10-15+at+7.08.25%E2%80%AFPM.png)

## 자주 묻는 질문

### 에이전트 상태가 알 수 없는 상태로 나와요. 왜 그런가요?

**알 수 없는 상태**는 상태를 판단할 수 없다는 뜻이에요. 다시 점검하기 전에 가장 최근 실행 상태에서 오류나 실패한 평가가 있는지 확인하세요.

### 에이전트의 다음 점검이 예약되지 않음으로 표시돼요. 왜 그런가요?

모니터링이 꺼져 있거나 막혀 있을 수 있어요. **Monitoring** 토글과 **Last check**(마지막 확인) 열에서 자세한 내용을 확인하세요.

### 대화 기록이 충분하지 않으면 어떻게 되나요?

Agent Health가 평가하려면 사용할 수 있는 대화 기록이 최소 2개 필요해요. 기록이 없는 대화는 건너뛰기 때문에, 데이터가 부족하면 점검을 끝내지 못할 수 있어요.

### AI 사용 제한 때문에 점검이 안 되면 어떻게 되나요?

실행이 시작되지 않아요. Agent Health에 표시된 사용량 정보와 서브 계정의 [AI 사용 제한](../13-AI-Employee/AI-Employee/ai-usage-limits.md)을 확인해 어떤 제한에 걸렸는지 살펴보세요.
