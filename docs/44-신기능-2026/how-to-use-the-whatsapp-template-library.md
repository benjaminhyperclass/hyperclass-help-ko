# WhatsApp 템플릿 라이브러리 사용하기

메시지를 처음부터 쓰지 않고, 미리 만들어진 내용으로 WhatsApp 메시지 템플릿을 만들 수 있어요. 템플릿 라이브러리에서 템플릿을 찾아 미리 보고, 내용을 수정한 다음 Meta에 제출하면 돼요.

{% hint style="warning" %}
미리 만들어진 템플릿은 내 계정에서 승인된 상태가 아니에요. 템플릿을 선택하면 내 서브 계정에 새 템플릿이 만들어지고, 이 템플릿은 보내기 전에 Meta의 승인을 따로 받아야 해요.
{% endhint %}

## WhatsApp 템플릿 라이브러리란?

WhatsApp 템플릿 라이브러리는 Meta의 승인을 받은 적이 있는 템플릿에서 가져온 내용을 모아 둔 곳이에요. 이 내용을 출발점으로 삼아 우리 비즈니스에 맞게 고친 다음, 일반적인 WhatsApp 템플릿 만들기 절차로 제출하면 돼요.

템플릿을 만들 때는 세 가지 방법 중에서 고를 수 있어요.

| 만드는 방법 | 설명 |
|---|---|
| **빈 템플릿** | 빈 폼에서 직접 메시지를 써요. |
| **AI 템플릿** | AI의 도움으로 템플릿 내용을 만들고, 검토하고 수정해요. |
| **Use Prebuilt Template**(기존 템플릿 사용) | 템플릿 라이브러리에 있는 내용을 골라 수정한 뒤 제출해요. |

자주 쓰는 메시지의 초안을 쓰는 시간은 줄어들고, 최종 내용은 직접 정할 수 있어요. 다만 Meta의 검토를 건너뛰는 것은 아니고, 승인을 보장하지도 않아요.

---

## 시작하기 전에

- 서브 계정에 활성 상태의 WhatsApp 구독이 있고, WhatsApp 온보딩을 마쳤어요.
- 메시지에 쓸 비즈니스 정보, 미디어, 링크, 샘플 값을 준비했어요.
- WhatsApp 템플릿을 만들고 편집할 권한이 있어요. 관리자는 해당 사용자의 **Roles & Permissions**(역할 및 권한) 설정에서 **Create/edit WhatsApp templates**(WhatsApp 템플릿 만들기/편집) 권한을 확인할 수 있어요.

{% hint style="info" %}
아래 단계는 서브 계정에서 **Use Prebuilt Template**을 쓸 수 있을 때 적용돼요.
{% endhint %}

---

## 라이브러리에서 WhatsApp 템플릿 만들기

### 1. WhatsApp 템플릿 열기

1. 해당 서브 계정에서 **설정 > WhatsApp > 템플릿**으로 이동해요.
2. **템플릿 만들기**를 클릭해요.
3. **Use Prebuilt Template**을 선택해요. WhatsApp 템플릿 만들기 화면을 벗어나지 않고, 팝업 창으로 템플릿 라이브러리가 열려요.

### 2. 템플릿 찾아보기와 필터링

라이브러리의 검색과 정렬 기능으로 알맞은 내용을 찾아보세요. 왼쪽 필터 패널로 결과를 좁힐 수 있어요.

| 필터 | 용도 |
|---|---|
| **카테고리** | 사용할 수 있는 카테고리별로 템플릿을 찾아요. |
| **Industry**(산업) | 내 비즈니스나 업종에 맞는 내용을 찾아요. |
| **언어** | 필요한 언어로 된 템플릿을 찾아요. |

나중에 쉽게 찾을 수 있도록 템플릿을 즐겨찾기에 추가할 수도 있어요. 검색 결과에 알맞은 템플릿이 없으면 검색어를 넓히거나 필터를 일부 풀어 보세요.

![템플릿 라이브러리의 검색과 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083091073/original/hRYLTTjmIWPTGXc8bRENq303pJutnsWMlw.png?1791803668)

### 3. 메시지 미리 보기

템플릿을 선택하면 WhatsApp 메시지 미리보기가 나와요. 머리글, 본문, 바닥글, 버튼이 있다면 함께 보여요. 계속하기 전에 내용, 언어, 고객이 취할 행동이 내 목적에 맞는지 확인하세요.

{% hint style="info" %}
미리보기는 메시지를 살펴보는 용도예요. 이 템플릿이 내 서브 계정에서 승인되었다는 뜻은 아니에요.
{% endhint %}

![WhatsApp 메시지 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083091436/original/DAuRD4MJUQqNojv5LLzwSMmySu8pxGJGkg.png?1791803755)

### 4. 템플릿 수정하기

라이브러리 템플릿을 선택하면 만들기 폼에 내용이 미리 채워져요. 폼은 그대로 편집할 수 있으니, 제출하기 전에 내용을 알맞게 고치세요. 아래 항목을 확인해 보세요.

| 항목 | 확인할 내용 |
|---|---|
| **Name**(이름) | 팀에서 알아보기 쉬운 이름을 써요. |
| **카테고리** | 메시지의 목적과 카테고리가 맞는지 확인해요. |
| **언어** | 선택한 언어가 메시지 내용과 같은지 확인해요. |
| **머리글** | 머리글 유형과 내용을 확인해요. 텍스트, 이미지, 동영상, 문서, 위치 중 하나일 수 있어요. |
| **Body**(본문) | 비즈니스에 맞게 세부 내용을 바꾸고, 개인화 자리 표시자를 확인해요. |
| **Footer**(바닥글) | 내 비즈니스에 맞지 않는 문구는 수정하거나 지워요. 지울 수 있는 경우에만 해당해요. |
| **Buttons**(버튼) | 버튼 이름과 연결되는 목적지나 동작을 확인해요. |

필수 항목을 모두 채우고, 변수에는 실제와 비슷한 샘플 값을 넣어요. 제출하기 전에 빌더에 표시된 검증 오류도 모두 고치세요.

{% hint style="warning" %}
수정하는 것은 내가 새로 만든 템플릿이에요. 라이브러리에 있는 원본이나 다른 비즈니스가 만든 템플릿은 바뀌지 않아요.
{% endhint %}

![라이브러리 템플릿으로 미리 채워진 만들기 폼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083091489/original/tL0ajE6P14AW4ACY9zcT1qcfw2WJ9QVc0Q.png?1791803813)

### 5. Meta에 제출하기

완성한 템플릿을 확인한 뒤, 일반적인 템플릿 만들기 절차로 제출해요. Meta는 제출한 버전의 내용, 카테고리, 형식, 정책 준수 여부를 검토해요. 라이브러리 원본 내용이 예전에 승인되었더라도, 내가 제출한 템플릿의 승인이 보장되지는 않아요.

상태를 확인하려면 **설정 > WhatsApp > 템플릿**으로 돌아가세요. **검토 중**으로 표시된 템플릿은 아직 검토가 진행 중이에요. 거부되었다면 Meta가 알려 준 사유를 먼저 확인하고, 고쳐서 다시 제출하세요.

### 6. 승인된 템플릿 사용하기

승인되어 활성 상태가 되면, 라이브러리로 만든 템플릿도 서브 계정의 다른 WhatsApp 템플릿과 똑같이 쓸 수 있어요.

- **워크플로우**: 자동 메시지 발송에 사용해요.
- **일괄 작업**: 선택한 대상에게 보낼 때 사용해요.
- **대화**: 1:1로 소통할 때 사용해요.

{% hint style="info" %}
템플릿을 만들거나 제출했다고 해서 고객에게 자동으로 발송되지는 않아요.
{% endhint %}

## WhatsApp 템플릿을 템플릿 라이브러리에 저장하기

에이전시 관리자만 쓸 수 있어요. 에이전시 관리자는 WhatsApp에서 **Save Template**(템플릿 저장)으로 기존 템플릿 라이브러리 저장 과정에 들어갈 수 있어요.

1. **설정 > WhatsApp > 템플릿**을 열어요.
2. 내가 만든 템플릿을 찾아요.
3. 해당 템플릿의 **점 세 개 메뉴**를 열고 **Save Template**을 선택해요.
4. 템플릿 라이브러리 저장 과정에서 필요한 정보를 입력해요.

{% hint style="warning" %}
라이브러리에 저장하는 것과 Meta 승인을 받는 것은 별개예요. 재사용하려고 내용을 저장해도 승인이 다른 서브 계정으로 넘어가지 않아요. 그 내용으로 새 WhatsApp 템플릿을 만들 때는 여전히 승인을 받아야 해요.
{% endhint %}

## 접근 권한

WhatsApp 라이브러리로 템플릿을 만들 때는 기존 WhatsApp 템플릿 관리 권한을 그대로 써요. 라이브러리용 권한이 따로 있지 않으니, 따로 켤 것도 없어요.

- 가능: **에이전시 소유자, 에이전시 관리자, 서브 계정 관리자**는 각자 접근이 허용된 계정 범위 안에서 쓸 수 있어요.
- 권한 필요: **에이전시 사용자와 서브 계정 사용자**는 해당 WhatsApp 템플릿 관리 권한이 있어야 해요.
- 불가능: 템플릿 편집기에 접근할 수 없는 사용자는 이 만들기 과정으로 라이브러리를 쓸 수 없어요.

{% hint style="info" %}
기존 WhatsApp 템플릿을 볼 수 있다고 해서 만들거나 편집할 수 있는 것은 아니에요. 만들기 동작이 보이지 않으면 사용자의 **Create/edit WhatsApp templates** 권한을 확인하세요.

중앙에서 관리하는 라이브러리 내용은 읽기 전용이에요. 권한이 있는 사용자는 만드는 중인 내 템플릿은 수정할 수 있지만, 라이브러리의 원본은 직접 수정할 수 없어요.
{% endhint %}

## 문제 해결

| 문제 | 확인할 내용 |
|---|---|
| **Use Prebuilt Template**이 보이지 않아요 | 서브 계정에서 이 기능을 쓸 수 있는지, 그리고 내 사용자 계정이 WhatsApp 템플릿을 만들고 편집할 수 있는지 확인하세요. |
| 검색해도 맞는 템플릿이 없어요 | **카테고리**, **Industry**, **언어** 필터를 일부 풀거나, 더 넓은 검색어로 찾아보세요. |
| 원하는 언어가 없어요 | 사용할 수 있는 언어 옵션을 확인하세요. **빈 템플릿**이나 **AI 템플릿**으로 알맞은 내용을 준비할 수도 있어요. |
| 템플릿을 저장하거나 제출할 수 없어요 | 필수 항목을 채우고, 빌더에 표시된 검증 오류를 고치세요. |
| Meta가 라이브러리 기반 템플릿을 거부했어요 | 거부 사유를 확인하고, 제출한 버전을 고치세요. 원본 내용이 승인되었더라도 내 계정에서의 승인이 보장되지는 않아요. |
| 템플릿을 발송에 쓸 수 없어요 | 현재 상태를 확인하세요. 검토 중이거나 거부, 일시중지, 비활성화된 템플릿은 일반 발송에 쓸 수 없어요. |
| **Save Template**이 보이지 않아요 | 해당 템플릿 라이브러리 접근 권한이 있는 에이전시 관리자 계정인지, 그리고 WhatsApp 진입 경로가 활성화되어 있는지 확인하세요. |

{% hint style="info" %}
빌더의 검증 오류와 Meta의 거부 사유는 서로 다른 검사예요. 먼저 만들기 폼에 표시된 오류를 고치세요. 제출한 뒤에는 Meta가 알려 주는 상태와 거부 상세 내용을 보고 다음 조치를 정하세요.

하이퍼클래스 고객지원에 문의할 때는 Location ID(로케이션 ID), 템플릿 이름, 문제가 생긴 사용자의 역할, 정확한 오류 메시지, 문제 상황이 담긴 스크린샷이나 녹화 영상을 함께 보내 주세요.
{% endhint %}

## 자주 묻는 질문

### 라이브러리 템플릿은 내 계정에서 이미 승인된 상태인가요?
아니요. 원본 내용은 예전에 Meta 검토를 통과했지만, 라이브러리 템플릿을 선택하면 내 서브 계정에 새 템플릿이 만들어져요. 문구를 하나도 바꾸지 않더라도 내가 만든 템플릿은 따로 승인을 받아야 해요.

### 라이브러리를 사용하면 Meta 승인이 더 빨라지나요?
아니요. 라이브러리는 메시지를 준비하는 수고를 줄여 줄 뿐이에요. 별도의 승인 절차가 있지도 않고, 검토 기간을 보장해 주지도 않아요.

### 제출하기 전에 내용을 바꿀 수 있나요?
네. 선택한 템플릿으로 편집 가능한 폼이 미리 채워져요. 제출하기 전에 내용, 비즈니스 정보, 변수, 버튼을 검토하고 수정하세요.

### 내가 수정하면 라이브러리의 원본 템플릿도 바뀌나요?
아니요. 만드는 중에 바꾼 내용은 내 새 템플릿에만 적용돼요. 중앙에서 관리하는 라이브러리 원본은 바뀌지 않아요.

### 알맞은 템플릿을 찾지 못하면 어떻게 하나요?
**빈 템플릿**으로 직접 메시지를 쓰거나, **AI 템플릿**으로 초안 작성을 도움받으세요. 라이브러리는 기존 두 가지 방법을 대신하는 것이 아니라 추가로 쓸 수 있는 방법이에요.

### WhatsApp 답장을 보낼 때마다 승인된 템플릿이 필요한가요?
아니요. 고객이 메시지를 보낸 뒤 24시간 동안 열려 있는 고객 서비스 창 안에서는 자유 형식 메시지를 보낼 수 있어요. 그 창이 지난 뒤에 메시지를 보내려면 승인된 템플릿이 필요해요. 라이브러리는 템플릿을 준비하는 방법만 바꾸고, 이 메시지 규칙은 바꾸지 않아요.
