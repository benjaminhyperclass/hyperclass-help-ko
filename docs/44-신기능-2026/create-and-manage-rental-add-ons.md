# 대여 애드온 만들기와 관리

대여 예약에 반려동물 요금, 장비 대여, 보험 같은 선택 옵션을 붙여 판매할 수 있어요. 관리자는 재사용할 수 있는 애드온을 만들어 가격과 세금을 설정하고, 여러 리스팅에 연결할 수 있어요. 고객은 예약하면서 옵션을 고르고 바뀐 합계를 바로 볼 수 있어요. 관리자는 이미 만든 예약에서도 애드온을 관리할 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

---

## 대여 애드온이란?

대여 애드온은 고객이 대여 예약에 함께 담을 수 있는 선택 상품이나 서비스예요. 글로벌 카탈로그에서 한곳에 모아 관리하고, 여러 대여 리스팅에 다시 쓸 수 있어요. 그래서 리스팅을 따로 만들거나 요금을 수동으로 추가할 필요가 없어요.

예를 들어 휴가용 숙소에서는 바비큐 스테이션이나 온수 수영장을, 차량 대여에서는 GPS 내비게이션이나 장비 보험을 애드온으로 제공할 수 있어요.

{% hint style="info" %}
애드온은 항상 선택 사항이에요. 꼭 내야 하는 요금은 **Additional fees**(추가 요금)를 사용하세요.
{% endhint %}

---

## 대여 애드온의 장점

대여 애드온을 쓰면 선택 서비스를 더 간단하게 제공하고 관리할 수 있어요. 고객은 예약하면서 더 유연하게 고르고, 요금도 투명하게 확인할 수 있어요.

- 중앙 관리: 재사용할 수 있는 애드온을 만들어 여러 리스팅에 연결해요.
- 유연한 가격 설정: 정액이나 비율로 요금을 정하고, 수량 한도도 둘 수 있어요.
- 추가 매출: 대여와 함께 선택 장비와 서비스를 판매할 수 있어요.
- 투명한 예약 경험: 선택 가능한 옵션을 보여 주고, 합계를 실시간으로 갱신해요. 인보이스에는 항목별 요금이 표시돼요.

---

## 가격과 설정

애드온은 가격 방식, 수량, 공개 여부를 다양하게 설정할 수 있어요. 설정을 알맞게 해 두면 고객에게 정확한 금액이 청구되고, 고객은 해당 예약에 의도한 옵션만 고를 수 있어요.

### 가격 방식

| 가격 유형 | 설명 | 예시 |
| --- | --- | --- |
| **Flat – Per booking**(정액 – 예약당) | 선택한 애드온 수량마다 부과하는 고정 요금이에요. 대여 기간과 관계없어요. | 바비큐 스테이션: 예약당 $150 |
| **Flat – Per booking unit**(정액 – 예약 단위당) | 리스팅의 예약 단위(시간, 일, 주, 월)마다 부과해요. | 온수 수영장: 월 $299 |
| **Percentage**(비율) | 세금을 더하기 전 기본 대여 소계에 대한 비율이에요. | 보험: $1,000의 10% = $100 |

{% hint style="warning" %}
비율 요금은 다른 애드온이나 요금과 중복 계산(복리)되지 않아요. **최대 수량**은 대여 단위 수와 관계없이 예약당 적용되는 고정 한도예요.
{% endhint %}

### 애드온 설정

| 설정 | 설명 |
| --- | --- |
| **Name**(이름) | 필수 항목이에요. 고객에게 보이고 인보이스에도 표시돼요. |
| **설명** / **이미지** | 선택 항목이에요. 예약 페이지에 표시돼요. |
| **Status**(상태) | **Active**(활성) 또는 **Inactive**(비활성)로 설정해요. |
| **Price**(가격) | **Flat amount**(정액) 또는 **Percentage**(비율)를 고르고 값을 입력해요. |
| **Pricing unit**(가격 단위) | 정액 요금일 때 **Per booking**(예약당) 또는 **Per booking unit**(예약 단위당)을 골라요. |
| **최대 수량** | 예약 한 건에서 고를 수 있는 최대 개수예요. 재고를 관리하지는 않아요. |
| **Hide from booking page**(예약 페이지에서 숨기기) | 관리자는 애드온을 쓸 수 있지만 고객에게는 보이지 않아요. |
| **Tax**(세금) | 애드온을 저장한 뒤 적용할 세금을 설정해요. |

{% hint style="info" %}
애드온의 상태와 공개 설정에 따라 고객이나 관리자가 새 예약에서 애드온을 고를 수 있는지가 정해져요. 이미 기록된 선택에는 영향이 없어요.

- **Active**: 고객용 예약 페이지에서 숨기지 않은 한, 새 예약에서 선택할 수 있어요.
- 숨김: 고객에게는 보이지 않지만, 관리자가 예약을 만들거나 편집할 때는 선택할 수 있어요.
- **Inactive**: 새 예약에서는 선택할 수 없어요. 기존 리스팅에는 계속 연결되어 있고, 이미 선택된 애드온은 기존 예약에 그대로 남아요.
{% endhint %}

## 대여 애드온 만들고 관리하기

글로벌 카탈로그에서는 관리자가 대여 옵션을 한곳에서 만들고, 검색하고, 편집하고, 정리할 수 있어요. 애드온을 여러 리스팅에 연결하고 한 번에 수정할 수 있어서 반복 설정이 줄어요.

### 글로벌 애드온 만들기

1. **캘린더 > 캘린더 설정 > 대여 > 애드온**(Add-ons)으로 이동하세요.
2. **+ New add-on**(새 애드온 추가)을 클릭하세요.
3. **Name**(이름)을 입력하고, 필요하면 **설명**과 **이미지**도 입력하세요.
4. **Active** 또는 **Inactive**를 선택하세요.
5. **Price type**(가격 유형)을 고르고 금액을 입력하세요. 해당하면 **Pricing unit**(가격 단위)도 설정하세요.
6. **최대 수량**을 정하고, 고객에게 보일지 설정하세요.
7. 필요하면 애드온에 연결할 리스팅을 선택하세요.
8. **부가 기능 만들기**를 클릭하세요.

   ![애드온 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083908594/original/6LbFuueJHl4DYgkc8TxGdV9YnXi61xa6QQ.png?1792617709)

{% hint style="info" %}
이미지 업로더는 SVG, PNG, JPG, GIF 형식을 지원해요. 권장 이미지 크기는 66 × 46 픽셀이에요.
{% endhint %}

### 만든 애드온 관리하기

만든 애드온은 카탈로그에 이름, 가격, 가격 단위, 연결된 리스팅, 상태, 사용 가능한 작업과 함께 표시돼요.

![애드온 카탈로그 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083908638/original/WRmJL5YvoBJY4G3M3Sz8IbB1ipSF3u16vw.png?1792617803)

**검색** 창에서 이름으로 애드온을 찾을 수 있어요. **필터**로 연결된 리스팅별로 결과를 좁힐 수도 있어요. 기존 항목은 **편집**과 **삭제**로 관리하세요.

리스팅 필터를 적용했는데 결과가 없으면, 필터를 지우거나 조정해서 카탈로그의 다른 애드온을 확인해 보세요.

{% hint style="warning" %}
글로벌 애드온을 편집하면 연결된 모든 리스팅에 변경 내용이 적용돼요. 애드온을 삭제하면 해당 리스팅에서 빠지지만, 이미 만든 예약에는 기록된 애드온 정보가 그대로 남아요.
{% endhint %}

## 리스팅에 애드온 연결하기

글로벌 카탈로그에서 연결하거나, 개별 리스팅에서 직접 연결할 수 있어요. 두 방법 모두 같은 글로벌 애드온 정보를 쓰기 때문에 설정을 일관되게 유지할 수 있어요.

| 방법 | 순서 |
| --- | --- |
| 글로벌 카탈로그 | **대여 > 애드온**을 열고 애드온을 만들거나 편집한 다음, 리스팅을 하나 이상 선택하고 저장하세요. |
| 개별 리스팅 | **대여 > 리스팅**을 열고 리스팅을 편집하세요. **애드온** 탭에서 **+ Add-on**(애드온 추가)을 클릭하고, 기존 애드온이나 **+ New Add-on**(새 애드온 추가)을 선택하세요. |

한 리스팅에 애드온을 여러 개 연결할 수 있어요.

- **편집**: 리스팅의 **애드온** 탭에서 애드온 설정을 바꾸고 저장하세요. 변경 내용은 모든 곳에 적용돼요.
- **제거**: 글로벌 카탈로그에서 삭제하지 않고, 현재 리스팅에서만 애드온을 뗍니다.

{% hint style="warning" %}
리스팅마다 애드온 가격이나 설정이 달라야 한다면 글로벌 카탈로그에 항목을 따로 만드세요.
자세한 내용은 [대여 – 리스팅 만들기·편집](../04-캘린더-예약/렌탈/rentals-create-edit-listings.md)을 참고하세요.
{% endhint %}

## 예약 과정의 애드온

고객은 대여를 예약하면서 선택 옵션을 고를 수 있어요. 관리자는 예약을 관리할 때 옵션을 추가하거나 바꿀 수 있어요. 선택한 애드온은 예약 합계에 반영되고, 연결된 인보이스에 개별 요금으로 표시돼요.

### 고객 예약 페이지

고객이 대여 날짜와 수량을 선택하면 **애드온** 영역이 나타나요. 여기에는 리스팅에 연결된 애드온 중 활성 상태이고 숨기지 않은 항목이 보여요.

각 카드에는 애드온의 이미지, 이름, 설명, 가격과 **추가**/**제거** 버튼이 표시될 수 있어요.

- 애드온을 선택하거나 제거하면 합계가 실시간으로 바뀌어요.
- 수량 선택기는 **최대 수량**이 1보다 클 때만 나타나요.
- 숨김 또는 비활성 애드온은 고객 예약 페이지에 나타나지 않아요.

![고객 예약 페이지의 애드온 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083908713/original/jbgSJel-5FZj714_TeW-psIA8QG4YDPeOg.png?1792618022)

### 수동 예약에서 애드온 추가하기

관리자는 대여 예약을 만들 때 선택 옵션을 붙일 수 있어요. 고객에게 숨겨진 애드온도 선택할 수 있어요.

1. 대여 예약 생성 화면을 열고 **Add new listing**(새 리스팅 추가)을 클릭하세요.
2. 리스팅, 대여 날짜, 시간, 수량을 선택하세요.
3. **부가 기능 선택**을 펼치세요.
4. 옵션을 선택하고 수량을 조정하세요.
5. 요금을 확인한 다음 **Add listing**(리스팅 추가)을 클릭하세요.

![수동 예약에서 부가 기능 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083908722/original/MAMxL67V-0aIe4GXXjo_rRxNekWv-ISzew.png?1792618075)

### 기존 예약의 애드온 확인하고 편집하기

관리자는 **예약 세부 정보 > 대여 상세 정보**에서 선택된 옵션을 확인할 수 있어요. 애드온은 해당 대여 리스팅 아래에 표시돼요.

기존 예약을 수정하려면 다음 순서로 하세요.

1. 예약을 열고 **Edit Booking**(예약 편집)을 선택하세요.
2. 애드온을 추가하거나 제거하고, 수량을 조정하세요.
3. 바뀐 합계를 확인하세요.
4. 변경 내용을 적용하려면 **저장**을, 되돌리려면 **Discard**(변경 내용 버리기)를 클릭하세요.

{% hint style="warning" %}
변경 내용을 저장하거나 버리기 전까지는 **저장되지 않은 변경사항** 배너가 표시돼요. 애드온을 바꾸면 예약 합계가 달라지고, 결제가 끝난 예약이라면 결제 금액을 조정해야 할 수 있어요.
자세한 내용은 대여 – 예약 편집 문서를 참고하세요.
{% endhint %}

## 애드온 세금

애드온 세금은 기본 대여 세금과 따로 설정할 수 있어요. 또 상태와 공개 설정으로 고객이나 관리자가 옵션을 고를 수 있는지 정할 수 있어요. 이 설정을 이용하면 이미 기록된 예약은 그대로 두고 애드온 제공 여부만 조절할 수 있어요.

### 애드온 세금 설정하기

1. **대여 > 애드온**으로 이동하세요.
2. 기존 애드온을 편집하고 **Configure tax**(세금 구성)를 선택하세요.
3. 적용할 세율을 지정하고 저장하세요.

세금은 선택한 수량과 가격 단위를 반영한 애드온의 해당 항목 합계에 대해 계산돼요. 인보이스에서는 세금 금액이 애드온 요금과 따로 표시되고, 해당하는 경우 고객에게 보이는 합계에 포함돼요.

더 자세한 안내는 [대여 – 세금](../04-캘린더-예약/렌탈/rentals-taxes.md)을 참고하세요.

## 자주 묻는 질문

### 같은 애드온을 리스팅마다 다른 가격으로 쓸 수 있나요?

공유하는 애드온 하나로는 안 돼요. 가격이나 설정이 다르면 글로벌 애드온 항목을 따로 만드세요.

### 최대 수량은 대여 단위 수를 기준으로 하나요?

아니요. 한도는 예약 전체에 적용돼요. 예를 들어 최대 수량이 2이면 대여 단위를 몇 개 예약하든 해당 애드온을 최대 2개까지 고를 수 있어요.

### 결제가 끝난 예약에서도 관리자가 애드온을 수정할 수 있나요?

네, 기존 예약 결제 제한 범위 안에서 가능해요. 변경하면 결제 금액을 조정해야 할 수 있고, 바뀐 합계는 이미 결제한 금액보다 낮을 수 없어요.

### 애드온 요금이 인보이스에 포함되나요?

네. 선택한 애드온은 인보이스에 별도 항목으로 표시되고, 해당 세금은 세금 내역에 포함돼요. 예약을 만들 때 인보이스가 항상 자동으로 이메일 발송되는 것은 아니에요.
