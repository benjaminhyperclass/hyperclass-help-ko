# 관리형 에이전트 안내에 커스텀 값 사용하기

커스텀 값과 비즈니스 프로필 정보를 쓰면 관리형 에이전트가 예약 링크, 이메일 주소, 전화번호 같은 최신 비즈니스 정보를 자동으로 사용해요. 그래서 에이전트를 관리하기 쉽고, 서브 계정·템플릿·스냅샷에서 다시 쓰기도 편해요.

관리형 에이전트는 에이전시 계정과 서브 계정 모두에서 만들고 편집할 수 있어요. 다만 비즈니스별 커스텀 값과 비즈니스 프로필 정보는 해당 서브 계정에서 관리해요.

{% hint style="info" %}
**Custom navigation UI**(사용자 지정 내비게이션 UI)를 사용 중이라면 **CRM** 탭 > **커스텀 값**으로 이동하세요.
{% endhint %}

## 커스텀 값 삽입하기

1. 에이전시 계정 또는 서브 계정에서 **AI 에이전트 > 에이전트 스튜디오**로 이동해 **관리형 에이전트**를 열어요.
2. **안내**에서 **값 삽입**을 클릭해요.
3. **커스텀 값** 또는 **비즈니스 프로필**을 선택해요.
4. 이미 만들어 둔 값을 고르거나, **새 커스텀 값…**을 클릭해 새로 만들어요. 커스텀 값과 비즈니스 프로필 정보는 해당 서브 계정에 저장되고 그곳에서 관리해요.
5. **게시**를 클릭해요.

## 값이 없을 때 처리하기

해당 서브 계정에 값이 없으면 **이 서브 계정에 설정되지 않음**이라고 표시돼요. 게시하기 전에 그 서브 계정에서 빠진 값을 설정해야 해요.

1. **게시**를 클릭해요.
2. **게시하려면 커스텀 값을 설정하세요**에서 해당 서브 계정에 빠진 정보를 입력해요.
3. **저장 및 게시**를 클릭해요.

## 커스텀 값 수정하기

관리형 에이전트는 다음번에 실행될 때 수정된 커스텀 값을 자동으로 사용해요.

커스텀 값이 저장된 서브 계정으로 전환한 뒤 **설정 > 커스텀 값**으로 이동해 값을 수정하고 저장하세요. 다시 게시하지 않아도 돼요.

비즈니스 프로필 정보를 바꾸려면 해당 서브 계정으로 전환한 뒤 **설정 > 비즈니스 프로필**에서 수정하세요.

## 자주 묻는 질문

### 관리형 에이전트를 여러 서브 계정에서 재사용할 수 있나요?

네, 할 수 있어요. 각 에이전트는 현재 서브 계정에 저장된 커스텀 값을 사용해요.

### 값을 바꾼 뒤에 다시 게시해야 하나요?

아니요. 바뀐 내용은 다음번 실행 때 자동으로 적용돼요.

### 값이 없으면 어떻게 되나요?

게시하기 전에 값을 입력하라는 안내가 나와요.
