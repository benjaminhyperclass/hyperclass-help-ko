# 이메일 빌더 색상 선택기에서 브랜드 보드 만들기

이메일을 작성하다가 **이메일 빌더**를 벗어나지 않고 바로 브랜드 보드를 만들 수 있어요. 이 문서에서는 이 기능이 무엇인지 알아보고, 첫 브랜드 보드를 만들어 그 색상을 바로 적용하는 방법을 안내해요.

## 색상 선택기에서 브랜드 보드를 만든다는 건?

**브랜드 보드 만들기** 기능을 쓰면 이메일 빌더의 색상 선택기에서 바로 브랜드 색상, 글꼴, 로고를 설정할 수 있어요.

새 탭을 열 필요 없이, 이메일을 작업하던 화면에서 팝업 창으로 브랜드 보드를 만들 수 있어요.

브랜드 보드는 다음 방법으로 만들 수 있어요.

- **URL에서 가져오기:** 내 웹사이트의 브랜드 색상, 글꼴, 로고를 가져와요.
- 프리셋 선택: 미리 만들어진 브랜드 스타일로 시작해요.
- **빈 상태로 시작:** 처음부터 직접 브랜드 보드를 만들어요.

꼭 필요한 항목은 브랜드 색상뿐이에요. 글꼴과 로고는 선택 사항이에요. 저장하면 브랜드 색상을 색상 선택기에서 바로 쓸 수 있어요.

## 이메일 빌더에서 브랜드 보드 만들기

{% hint style="info" %}
**브랜드 보드 만들기** 옵션은 브랜드 보드가 아직 없을 때만 나타나요. 이미 브랜드 보드가 있다면 색상 선택기에서 저장된 색상을 바로 쓸 수 있어요.
{% endhint %}

1. **마케팅 > 이메일 > 템플릿**으로 이동해 새 템플릿을 만들거나 기존 템플릿을 편집해요.
2. **이메일 빌더**에서 아무 색상 선택기나 열고 **브랜드 보드 만들기**를 클릭해요.
3. **URL에서 가져오기**, 프리셋 스타일 선택, **빈 상태로 시작** 중 하나를 골라요.
4. **브랜드 색상**을 추가하거나 확인해요. 필요하면 **글꼴** 탭과 **로고** 탭에서 글꼴과 로고도 추가해요.
5. **저장**을 클릭해 브랜드 보드를 만들어요.
6. 색상 선택기로 돌아가 **브랜드 색상**에서 저장한 색상을 선택해요.
