# 그래픽 라이브러리 소개

그래픽 라이브러리(Graphic Library)는 퍼널, 웹사이트, 스토어, 웨비나 페이지에 아이콘, 이모지, 일러스트를 바로 넣을 수 있는 기능이에요. 이 문서에서는 그래픽 라이브러리를 여는 방법, 주요 기능, 페이지에 그래픽을 추가하는 방법을 안내해요.

## 그래픽 라이브러리란?

하이퍼클래스의 그래픽 라이브러리를 쓰면 퍼널, 웹사이트, 스토어, 웨비나 페이지에 아이콘, 이모지, 일러스트를 바로 추가할 수 있어요. 11,000개 이상의 아이콘과 이모지를 검색하거나 카테고리별로 둘러볼 수 있고, 빌더를 벗어나지 않고 아이콘 색상도 바꿀 수 있어요. AI로 나만의 일러스트를 만들거나 직접 만든 그래픽을 업로드해서 디자인을 꾸밀 수도 있어요. 외부 디자인 도구를 쓸 일이 줄어들어요.

그래픽 라이브러리는 지원되는 하이퍼클래스 빌더의 **Icons & Graphics**(아이콘 및 그래픽) 패널에서 쓸 수 있는 기본 제공 시각 자료 모음이에요. 외부 사이트에서 그래픽을 찾지 않고, 필요한 요소를 페이지에 바로 넣을 수 있어요.

그래픽 라이브러리에는 세 가지 종류가 있어요.

- 아이콘: 기능을 강조하거나 아이디어를 전달하거나 페이지 내용을 보완하는 시각 기호예요.
- 이모지: 제목, 메시지 등의 내용을 익숙한 그림 문자로 더 생동감 있게 표현해 줘요.
- 일러스트: 기본 제공 일러스트, AI로 만든 일러스트, 내 기기에서 업로드한 그래픽으로 디자인을 꾸밀 수 있어요.

그래픽은 캔버스에 바로 추가할 수 있고, 아이콘은 지원되는 텍스트와 버튼 요소 안에도 쓸 수 있어요.

## 그래픽 라이브러리의 주요 장점

그래픽 라이브러리를 쓰면 워크플로우이 끊기지 않으면서 페이지를 더 보기 좋게 꾸밀 수 있어요. 기본 제공 그래픽과 사용자 지정 기능 덕분에 콘텐츠에 맞는 그래픽을 쉽게 찾고, 페이지마다 일관된 디자인을 유지할 수 있어요.

- 수천 개의 그래픽 사용: 하이퍼클래스 안에서 11,000개 이상의 아이콘과 이모지 중에서 고를 수 있어요.
- 페이지 디자인 시간 절약: 외부 사이트를 찾아다니거나 그래픽을 하나하나 가져오지 않아도 바로 찾아 넣을 수 있어요.
- 브랜드 일관성 유지: 웹사이트나 퍼널 디자인에 어울리도록 아이콘 색상을 바꿀 수 있어요.
- 그래픽을 더 빠르게 찾기: 아이콘과 이모지를 검색하거나 정리된 카테고리에서 둘러볼 수 있어요.
- AI로 맞춤 일러스트 만들기: 기본 일러스트가 필요에 맞지 않을 때 직접 생성할 수 있어요.
- 내 그래픽 사용: 직접 만든 일러스트를 업로드해서 페이지를 나만의 스타일로 꾸밀 수 있어요.
- 텍스트와 버튼 꾸미기: 제목, 문단, 지원되는 버튼 안에 아이콘을 넣어 내용을 더 쉽게 알아보고 따라갈 수 있게 해요.

## 그래픽 라이브러리의 아이콘

아이콘은 정보를 빠르게 전달하고, 중요한 내용을 강조하고, 방문자가 페이지를 따라가도록 안내하는 시각 기호예요. 그래픽 라이브러리에서는 검색 가능한 아이콘 모음을 제공하며, 페이지 디자인에 추가하고 브랜드에 맞게 색상을 바꿀 수 있어요.

### 아이콘 둘러보기와 검색

카테고리별로 아이콘을 둘러보거나 키워드로 원하는 그래픽을 검색할 수 있어요.

1. 빌더(사이트, 퍼널, 이메일 등)의 왼쪽 사이드바에서 **Icons & Graphics** 패널을 열어요.
2. **아이콘** 탭을 선택해요.
3. 아이콘 카테고리를 둘러봐요.
4. **필드 검색**에 키워드를 입력해서 원하는 아이콘을 찾아요.
5. 아이콘을 선택해 페이지에 추가하거나, 캔버스로 바로 끌어다 놓아요.

![아이콘 탭에서 아이콘 검색하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083546972/original/-Z4P7AfXMV4BCnWmOq-qEN70u7S48JL19g.png?1792173018)

### 아이콘 색상 바꾸기

페이지 디자인에 어울리도록 아이콘 색상을 조정할 수 있어요. 아이콘을 브랜드 색상, 버튼, 다른 페이지 요소와 맞추고 싶을 때 특히 유용해요.

아이콘 색상을 고르는 방법은 다음과 같아요.

1. 그래픽 라이브러리에서 **아이콘** 탭을 열어요.
2. **아이콘 색상** 옵션을 찾아요.
3. 색상 선택기에서 원하는 색상을 골라요.
4. 페이지에 추가할 아이콘을 선택해요.

![아이콘 색상 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083547051/original/_Bbq8hHwLI4bIaQ00aRc-4rpRdxTGwVj-g.png?1792173092)

## 그래픽 라이브러리의 이모지

이모지를 쓰면 페이지 내용이 더 생동감 있어지고, 메시지, 제목 등 중요한 정보를 강조할 수 있어요. 그래픽 라이브러리 안에서 바로 이모지를 고를 수 있어서 다른 앱으로 옮겨 갈 필요가 없어요.

이모지를 추가하는 방법은 다음과 같아요.

1. 빌더의 왼쪽 사이드바에서 **Icons & Graphics**를 열어요.
2. **이모지** 탭을 선택해요.
3. 이모지를 둘러보거나 **필드 검색**으로 원하는 이모지를 찾아요.
4. 선택한 이모지를 클릭하거나 캔버스로 끌어다 놓아요.

이모지는 공지를 강조하거나, 오퍼에 시선을 모으거나, 페이지 내용에 개성을 더할 때 쓰기 좋아요.

## 그래픽 라이브러리의 일러스트

일러스트는 개념을 전달하고, 페이지의 메시지를 뒷받침하고, 디자인에 시각적 재미를 더해 줘요. 그래픽 라이브러리에는 기본 일러스트가 들어 있고, 더 구체적인 그림이 필요하면 AI로 새로 생성하거나 내 일러스트를 업로드할 수 있어요.

### 기본 제공 일러스트 사용하기

기본 제공 일러스트는 처음부터 그래픽을 만들지 않고 바로 페이지에 넣을 수 있는 이미지예요.

1. **Icons & Graphics** 패널을 열어요.
2. **Illustrations**(일러스트) 탭을 선택해요.
3. 기본 일러스트를 둘러봐요.
4. 페이지 내용에 어울리는 일러스트를 골라요.
5. 클릭하거나 캔버스로 끌어다 놓아요.

### AI로 일러스트 생성하기

라이브러리에 필요한 그림이 없을 때 AI로 일러스트를 만들 수 있어요. 제공되는 AI 생성 기능으로 디자인에 맞는 일러스트를 만들어 보세요.

시작하는 방법은 다음과 같아요.

1. 그래픽 라이브러리를 열어요.
2. **생성**을 눌러 일러스트 생성 옵션을 열어요.
3. 화면에 나오는 AI 생성 안내에 따라 일러스트를 만들어요.
4. 생성된 이미지를 확인하고 사용할 일러스트를 선택해요.
5. 일러스트를 페이지에 추가해요.

![AI로 일러스트 생성하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083547249/original/zjoiSYQXmHHV0LqVVtUAu0trGaWQ7tgKqQ.png?1792173390)

### 내 일러스트 업로드하기

내 비즈니스, 브랜드, 캠페인을 위해 만든 그래픽을 업로드해서 쓸 수 있어요. 이미 가지고 있는 이미지를 페이지에 넣고 싶을 때 유용해요.

일러스트를 업로드하는 방법은 다음과 같아요.

1. **Icons & Graphics**를 열어요.
2. 일러스트 또는 사용자 그래픽 업로드 옵션이 있는 곳으로 이동해요.
3. **업로드** 버튼을 선택해요.
4. 내 기기에서 그래픽을 골라요.
5. 업로드가 끝나면 해당 그래픽을 선택해서 페이지에 사용해요.

![내 일러스트 업로드하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083547362/original/ENfCWutNnVQESCOOF5OPSpNvNC5iTNrOEg.png?1792173491)

## 버튼과 텍스트 요소에서 아이콘 사용하기

아이콘은 캔버스 위의 독립된 그래픽으로만 쓰는 것이 아니에요. 하이퍼클래스에서는 텍스트와 버튼 안에도 아이콘을 넣어 글과 시각 기호를 함께 쓸 수 있어요. 콜투액션을 더 눈에 띄게 하고 제목과 문단도 보기 좋게 꾸밀 수 있어요.

### 버튼에 아이콘 넣기

지원되는 빌더에서는 버튼 텍스트의 앞이나 뒤에 아이콘을 넣을 수 있어요.

예를 들어 "시작하기" 뒤에 화살표 아이콘을, "가이드 다운로드" 앞에 다운로드 아이콘을 넣으면 방문자가 해야 할 행동을 더 분명하게 보여 줄 수 있어요.

### 텍스트 안에 아이콘 넣기

지원되는 다음 텍스트 요소 안에도 아이콘을 글과 나란히 넣을 수 있어요.

- H1 제목
- H2 제목
- 문단
- 그 밖에 지원되는 텍스트 콘텐츠

시각 기호마다 별도의 그래픽 요소를 만들지 않고 단어 옆에 바로 아이콘을 둘 수 있어요.

예를 들어 기능을 소개하는 제목 앞에 체크 표시 아이콘을 넣거나, 문단 안에 아이콘을 넣어 특정 내용을 강조할 수 있어요.

### 새 이메일 빌더에서 아이콘 사용하기

새 **이메일 빌더**에도 글 안에 아이콘을 넣는 기능이 추가되었어요. 처음 출시된 퍼널, 웹사이트, 스토어, 웨비나 빌더에서 이메일 쪽으로 아이콘 활용 범위가 넓어진 거예요.

덕분에 하이퍼클래스의 여러 디자인 화면에서 시각 콘텐츠를 더 일관되게 만들 수 있어요.

이메일 편집에 대한 자세한 내용은 [이메일 빌더와 인라인 편집기 사용 방법](../10-마케팅/Email-Builder-Capabilities/how-to-use-the-email-builder-and-its-in-line-editor.md)을 참고하세요.

## 자주 묻는 질문

### 아이콘과 이모지를 찾으려면 외부 사이트를 써야 하나요?
아니요. 그래픽 라이브러리에는 11,000개 이상의 아이콘과 이모지가 있어서, 지원되는 하이퍼클래스 빌더 안에서 바로 쓸 수 있어요.

### 기본 제공 그림에 없는 일러스트도 그래픽 라이브러리로 만들 수 있나요?
네. 그래픽 라이브러리에는 AI 일러스트 생성 기능이 있어서, 기본 일러스트가 필요에 맞지 않을 때 직접 만들 수 있어요.

### 버튼 안에서 텍스트 앞이나 뒤에 아이콘을 넣을 수 있나요?
네. 지원되는 빌더에서는 버튼 내용의 앞이나 뒤에 아이콘을 넣을 수 있어요.

### 제목이나 문단의 단어 사이에 아이콘을 넣을 수 있나요?
네. 제목, 문단 등 지원되는 텍스트 콘텐츠 안에 아이콘을 넣을 수 있어요.

### 이메일 빌더에서도 그래픽 라이브러리를 쓸 수 있나요?
새 이메일 빌더에는 글 안에 아이콘을 넣는 기능이 추가되었어요. 다만 일러스트와 AI 생성 기능을 포함한 그래픽 라이브러리 전체 기능을 쓸 수 있는지는 처음 지원된 페이지 빌더와 다를 수 있어요.

### 하이퍼클래스 밖에서 만든 그래픽을 업로드할 수 있나요?
네. 그래픽 라이브러리에서 내 일러스트를 업로드해서 디자인에 쓸 수 있어요.

### 그래픽 라이브러리는 **Social Icons**(소셜 아이콘) 요소와 같은 건가요?
아니요. 그래픽 라이브러리는 페이지 디자인에 쓰는 범용 아이콘, 이모지, 일러스트를 제공해요. **Social Icons** 요소는 소셜 미디어 프로필로 연결되는 아이콘을 보여 주는 용도예요.

### 모든 계정에서 그래픽 라이브러리 기능을 바로 쓸 수 있나요?
기능 제공 여부는 제품 출시 일정과 계정 접근 권한에 따라 달라요. **Icons & Graphics**가 보이지 않으면 아직 내 계정에서 그래픽 라이브러리가 활성화되지 않았을 수 있어요.
