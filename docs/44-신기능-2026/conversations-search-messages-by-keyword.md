# 대화에서 키워드로 메시지 검색하기

키워드 검색을 쓰면 **대화** 인박스 전체나 한 대화 안에서 원하는 메시지를 바로 찾을 수 있어요. 메시지 기록을 일일이 스크롤하지 않아도 됩니다. 이 문서에서는 키워드 검색의 동작 방식, 메시지를 찾고 필터로 좁히는 방법, 검색 결과 사이를 이동하는 방법을 안내해요.

## 키워드 검색이란?

키워드 검색은 특정 단어, 문구, 숫자가 들어 있는 메시지를 **대화** 인박스에서 바로 찾는 기능이에요. 안내한 가격, 고객 불만, 상품 이름, 약속한 날짜 등 이전 대화에 나온 내용을 무엇이든 검색할 수 있어요.

검색 방법은 두 가지예요.

| 검색 유형 | 위치 | 기능 |
| --- | --- | --- |
| 전체 대화 검색 | **대화** 목록 맨 위의 **검색 아이콘** | 키워드가 들어 있는 대화를 찾고, 일치하는 메시지 미리보기를 보여 줘요. |
| 대화 내 검색 | 열린 대화 상단의 **검색 아이콘** | 한 대화 안에서 일치하는 메시지를 찾아 강조하고, 일치 항목 사이를 이동할 수 있어요. |

같은 검색창에서 **이름, 이메일 주소, 전화번호**로 연락처를 찾을 수도 있어요.

---

## 대화에서 키워드 검색 사용하기

받은 대화 전체에서 검색하거나, 특정 연락처의 대화 안에서만 검색할 수 있어요.

### 모든 대화에서 검색하기

무슨 말이 오갔는지는 기억나는데 어느 연락처였는지 모를 때 사용하세요.

{% hint style="warning" %}
- 같은 연락처의 메시지가 여러 개 일치하면 대화는 한 번만 표시되고, 미리보기에는 가장 최근에 일치한 메시지가 나와요.
- 검색은 내가 볼 수 있는 권한이 있는 모든 대화를 대상으로 해요. 배정된 대화만 볼 수 있도록 접근이 제한되어 있다면 결과에도 그 대화만 나와요.
{% endhint %}

1. 왼쪽 메뉴에서 **대화**를 클릭하세요.
2. 대화 목록 맨 위의 **검색 아이콘**을 클릭하세요. **키워드, 이름, 이메일 또는 전화번호로 검색**이라는 안내 문구가 있는 검색창이 나타나요.
3. 키워드나 문구를 입력하세요. 입력하는 동안 결과가 나타나고, 맨 위에 일치하는 전체 건수가 표시돼요. 각 결과에는 **연락처 이름**, 채널 아이콘, 날짜, 그리고 일치한 키워드가 노란색으로 강조된 메시지 미리보기가 나와요.
4. 결과를 클릭하면 해당 대화가 열려요. Enter 키를 누르면 전체 결과 목록을 볼 수 있어요. 대화가 열리면 대화 내 검색창에 키워드가 자동으로 입력되어 있어요.
5. 결과 건수 옆의 **정렬 아이콘**을 클릭해 최신순 또는 오래된순으로 정렬하세요.
6. 검색창 옆의 **뒤로 화살표**를 클릭하면 원래의 인박스로 돌아가요.

### 한 대화 안에서 검색하기

연락처는 이미 아는데 안내한 가격이나 상대가 확인해 준 날짜 같은 특정 메시지를 찾을 때 사용하세요.

{% hint style="info" %}
대화 내 검색은 지금 화면에 보이지 않는 이전 메시지까지 연락처의 전체 메시지 기록을 대상으로 해요. 일치하는 이전 메시지는 해당 위치로 이동할 때 자동으로 불러와져요.
{% endhint %}

1. **대화**에서 연락처의 대화를 여세요.
2. 대화 상단의 **검색 아이콘**을 클릭하세요. 메시지 영역 오른쪽 위에 검색창이 나타나요. 전체 대화 검색 결과에서 대화를 열었다면 키워드가 이미 입력되어 있어요.
3. 찾을 단어나 문구를 입력하세요. 일치하는 메시지가 노란색으로 강조되고, 일치 항목 중 현재 위치가 **4/4**처럼 표시돼요.
4. 카운터 옆의 **위쪽 화살표**와 **아래쪽 화살표**로 일치하는 메시지 사이를 이동하세요. 메시지 영역이 각 일치 항목으로 자동 스크롤되고, 해당 메시지는 계속 강조돼요.
5. **X**를 클릭하면 검색창이 닫혀요. 대화는 현재 위치에 그대로 남아 있어요.

### 필터로 검색 결과 좁히기

키워드로 검색한 결과가 너무 많으면 필터를 적용해 필요한 대화를 더 빨리 찾을 수 있어요.

1. 키워드를 검색한 뒤, 결과 목록 오른쪽 위의 **필터 아이콘**을 클릭하세요.
2. 적용할 필터를 선택하세요. 검색 결과 위에 필터 칩이 나타나고, 필터를 적용할 때마다 전체 결과 건수가 바뀌어요.
3. 필터링된 대화를 확인하고 원하는 결과를 선택하세요.
4. 필터 줄 맨 끝의 **지우기**를 클릭하면 적용한 검색 필터가 모두 해제돼요.

#### 사용할 수 있는 검색 필터

| 필터 | 기능 |
| --- | --- |
| **날짜 범위** | 선택한 기간에 보내거나 받은 메시지로 결과를 제한해요. 날짜를 직접 고르거나 **Today**(오늘), **Last 7 Days**(최근 7일), **최근 30일**, **최근 90일** 중에서 선택한 뒤 **확인**을 클릭하세요. |
| **채널** | 하나 이상의 채널로 필터링해요. 이메일, SMS, Facebook, WhatsApp, Instagram, 라이브 채팅, GBP, 통화를 선택할 수 있어요. |
| **Has Attachments**(첨부파일 있음) | 일치한 메시지에 첨부파일이 있는 대화만 보여 줘요. |
| **방향** | 수신 또는 발신 메시지로 필터링해요. **더 많은 필터**에서 선택할 수 있어요. |
| **소유자** | 대화에 배정된 소유자를 기준으로 결과를 좁혀요. **더 많은 필터**에서 선택할 수 있어요. |
| **팔로워** | 대화의 팔로워를 기준으로 필터링해요. **더 많은 필터**에서 선택할 수 있어요. |

## 더 잘 찾는 팁

메시지를 검색할 때 참고하세요.

- 최소 글자 수: 3자 이상 입력해야 검색이 시작돼요.
- 대소문자 구분 없음: "Refund", "refund", "REFUND"를 검색하면 결과가 모두 같아요.
- 부분 일치: "invoic"을 검색하면 "invoice"나 "invoicing"이 들어 있는 메시지를 찾을 수 있어요.
- 여러 단어: 단어를 여러 개 입력하면 순서와 관계없이 그 단어가 모두 들어 있는 메시지를 찾아요.
- 정확한 문구: 큰따옴표로 묶으면 정확히 일치하는 문구를 검색해요. 예: `"not interested"`
- 숫자: 숫자도 단어처럼 검색할 수 있어요. 예를 들어 "299"를 검색하면 안내한 가격 299달러가 들어 있는 메시지를 찾는 데 도움이 돼요.
- 필터 조합: 날짜 범위, 채널, 첨부파일, 방향, 소유자, 팔로워 필터를 함께 사용하면 전체 대화 검색 결과를 더 좁힐 수 있어요.

## 자주 묻는 질문

### 키워드 검색이 기존 연락처 검색을 대신하나요?

네. 같은 검색창에서 연락처 이름, 이메일 주소, 전화번호, 메시지 내용을 모두 찾을 수 있어요. 연락처 이름이 일치하는 결과가 먼저 나와요.

### 현재 적용된 인박스 필터가 키워드 검색 결과에 영향을 주나요?

아니요. 키워드 검색은 현재 인박스 필터와 관계없이 내가 접근 권한이 있는 모든 대화를 대상으로 시작해요. 검색 결과 안에서 필터를 적용해 결과를 좁힐 수 있어요.

### 에이전시 사용자가 여러 서브 계정의 대화를 한꺼번에 검색할 수 있나요?

아니요. 키워드 검색은 현재 작업 중인 서브 계정 안에서만 가능해요.

### 보관된 대화도 키워드 검색에 포함되나요?

네. 보관된 대화는 검색 결과에 나타나요. 삭제된 대화는 나타나지 않아요.

### 누가 키워드 검색을 사용할 수 있나요?

서브 계정에서 **대화**에 접근할 수 있는 사용자라면 누구나 키워드 검색을 쓸 수 있어요. 키워드 검색을 위한 별도 권한은 필요하지 않아요.

검색 결과에는 기존 접근 권한이 그대로 적용돼요. 예를 들어 배정된 대화만 볼 수 있는 사용자는 그 대화 안의 메시지만 찾을 수 있어요.

### 입력해도 아무 반응이 없어요.

키워드 검색은 **3자 이상** 입력해야 결과를 보여 줘요. 그 전에는 검색창에 몇 글자를 더 입력해야 하는지 표시돼요.

### 검색 결과에 대화가 나타나지 않아요.

다음과 같은 경우일 수 있어요.

- 검색 필터가 아직 적용되어 있어요.
- 대화가 삭제되었어요.
- 해당 대화를 볼 권한이 없어요.

**지우기**를 클릭해 필터를 해제해 보세요. 그래도 대화가 보이지 않으면 관리자에게 대화 배정 상태와 내 접근 권한을 확인해 달라고 요청하세요.

### 대화 내 검색에서 일부 메시지가 검색되지 않아요.

대화 내 검색에는 해당 대화에 적용된 메시지 유형 필터가 그대로 반영돼요.

예를 들어 대화가 WhatsApp 메시지만 보이도록 필터링되어 있다면, 일치하는 WhatsApp 메시지만 검색돼요.

그 대화의 모든 채널에서 검색하려면 메시지 유형 필터를 해제하세요.
