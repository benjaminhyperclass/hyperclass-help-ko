# 서비스 예약에 소매 상품 추가하기

서비스 예약에 소매 상품을 바로 추가하면 고객이 같은 방문에서 서비스와 상품을 함께 구매할 수 있어요. 상품 목록에서 상품을 고르고, 수량과 가격을 조정하고, 예약 전체 금액을 확인할 수 있어요. 재고 추적을 켜 둔 상품은 재고도 자동으로 바뀌어요. 이 문서에서는 소매 상품을 추가하는 방법과 결제·재고 처리 방식을 안내해요.

## 서비스 예약의 소매 상품이란?

서비스 예약의 소매 상품 기능을 쓰면 카탈로그에 등록한 상품을 대상 서비스 예약에 함께 넣을 수 있어요.

예를 들어 미용실에서 케라틴 트리트먼트 예약에 샴푸 2개를 추가할 수 있어요. 서비스와 상품은 예약 세부 내용과 결제 요약에 함께 표시돼요.

대상 예약을 만들 때나 편집할 때 상품을 추가할 수 있어요.

{% hint style="warning" %}
소매 상품은 **서비스**가 아니라 **결제 > 상품**에서 관리해요. 고객이 사용하는 예약 페이지에서는 소매 상품을 추가할 수 없어요.
{% endhint %}

## 예약에 소매 상품 추가하기

대상 서비스 예약을 만들거나 편집할 때 하이퍼클래스 카탈로그에서 소매 상품을 고를 수 있어요.

예약 창을 열고 **Product(s)**(상품) 아래의 **상품 추가**를 클릭하세요. 넣고 싶은 상품이나 옵션(변형 상품)을 검색해서 선택하세요.

![예약 창에서 상품 추가를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083950551/original/rXf1GFtqQoZNAEobH3v3qu0uUSY_nGH_WA.png?1792664887)

## 수량과 가격 조정하기

상품을 고른 뒤 예약에 추가하기 전에 수량과 단가를 조정할 수 있어요.

**Add retail product**(소매 상품 추가) 창에는 다음 항목이 있어요.

- **상품**: 선택한 상품 또는 옵션이에요.
- **수량**: 상품 개수예요.
- **단가**: 상품 1개당 청구하는 가격이에요.
- **금액**: 선택한 상품의 소매 청구 총액이에요.

예를 들어 19달러짜리 상품 2개를 추가하면 예약에 38달러가 더해져요.

단가를 바꿔도 해당 예약에만 적용돼요. 카탈로그의 상품 가격은 바뀌지 않아요.

![수량과 단가를 입력하는 소매 상품 추가 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083950655/original/vNvIw08qPEmv18oTN4wAz8w1WUZgjzWOeg.png?1792664946)

## 예약 결제 내역 확인하기

소매 상품 금액은 예약의 결제 요약에 서비스 금액과 함께 표시돼요.

| 항목 | 금액 |
| --- | --- |
| 케라틴 트리트먼트 | $249 |
| 샴푸 — 2 × $19 | $38 |
| 소계 | $287 |

적용되는 세금이나 수수료에 따라 최종 금액은 달라질 수 있어요.

![서비스와 소매 상품 금액이 함께 표시된 결제 요약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083950798/original/T9OJk1WrYjiaXC1T9fnaxXF0Md8rH3BKPw.png?1792665012)

이미 결제가 있는 예약에서 소매 상품을 바꾸면 결제 상태에 추가로 받을 금액이나 환불할 금액이 반영돼요.

{% hint style="warning" %}
잔액이 바뀐다고 해서 추가 결제가 자동으로 수납되거나 환불이 자동으로 처리되지는 않아요. **결제** 탭에서 거래를 확인하고 직접 처리하세요.
{% endhint %}

자세한 내용은 [캘린더의 결제 탭](../04-캘린더-예약/예약-관리/payments-tab-in-calendars.md)을 참고하세요.

## 소매 상품이 재고에 미치는 영향

재고 추적을 켜 둔 상품을 예약에 추가하거나 예약에서 빼면 하이퍼클래스가 재고를 자동으로 조정해요.

- **상품을 추가하면**: 재고 수량이 줄어요.
- **상품을 제거하면**: 해당하는 재고가 다시 늘어요.
- **수량을 줄이면**: 줄어든 만큼 재고로 돌아가요.
- **재고가 부족하면**: 오류가 표시돼요. 단, 해당 상품에서 재고가 없어도 판매를 계속하도록 설정했다면 표시되지 않아요.

재고 추적을 켜지 않은 상품은 영향을 받지 않아요.

{% hint style="info" %}
예약을 취소할 때 재고가 어떻게 처리되는지는 게시 전에 확인이 필요해요.
{% endhint %}

## 예약 세부 정보에서 소매 상품 확인하기

저장한 예약은 **예약 세부 정보**에서 연결된 소매 상품을 보여 줘요.

**Product details**(상품 상세 정보) 영역에는 상품 이름과 수량이 표시돼요. 직원이 예약에 무엇이 포함됐는지 바로 확인할 수 있어요.

나중에 카탈로그 정보가 바뀌어도 예약 기록에는 당시의 상품 정보가 그대로 남아요.

![예약 세부 정보의 상품 상세 정보 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083951054/original/_6AOlrWcyoDGFEoUlJNKzwLLitKQPQbzfQ.png?1792665101)

## 서비스 예약에 소매 상품 추가하는 순서

대상 서비스 예약을 만들거나 편집할 때 소매 상품을 추가할 수 있어요. 시작하기 전에 **결제 > 상품**에 상품이 등록되어 있는지 확인하세요.

### 1단계: 서비스 예약 열기

1. **캘린더 > 캘린더 보기 > 서비스**로 이동하세요.
2. 새 서비스 예약을 만들거나, 대상 예약을 열어요.
3. 기존 예약을 수정하려면 **편집**(연필) 아이콘을 클릭하세요.

### 2단계: 소매 상품 선택하기

1. 예약 창에서 **Product(s)**(상품)를 찾으세요.
2. **상품 추가**를 클릭하세요.
3. 상품이나 옵션을 검색하세요.
4. 추가할 상품을 선택하세요.

![검색한 상품을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083951399/original/h3rLuOmWODuNH8Do6y0nkoohR21nE79icQ.png?1792665241)

### 3단계: 수량과 가격 설정하기

1. **수량**을 입력하세요.
2. 필요하면 **단가**를 조정하세요.
3. 계산된 **금액**을 확인하세요.
4. **상품 추가**를 클릭하세요.

![수량과 단가를 설정하고 상품 추가를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083951833/original/_XWa4_CfpOsb4lF4ggbgxtmDuuVbavxHXw.png?1792665438)

### 4단계: 예약 확인하고 저장하기

1. 서비스와 소매 상품 내용을 확인하세요.
2. 수량, 가격, 업데이트된 결제 요약을 확인하세요.
3. 새 예약이면 **예약하기**를 클릭하세요. 기존 예약이면 변경 사항을 저장하세요.

![서비스와 소매 상품을 확인하고 예약하기를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083951738/original/gXsAFkBk9Wzz5UbazkaUgfejZxJGZSsznQ.png?1792665382)

{% hint style="warning" %}
소매 상품은 앱 안에서 진행하는 대상 서비스 예약에서만 쓸 수 있어요. 고객이 사용하는 예약 페이지에서는 지원하지 않아요.
{% endhint %}

### 5단계: 예약과 결제 내용 확인하기

1. 저장한 예약을 여세요.
2. **예약 세부 정보**에서 **Product details**(상품 상세 정보)를 확인하세요.
3. **결제** 탭을 열어 총액, 결제한 금액, 남은 잔액을 확인하세요.

![저장한 예약의 상품 상세 정보와 결제 탭 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083951688/original/3dnl8_mI_ttxkt9ruA_mq0PPlnXcdVSPpg.png?1792665352)

이미 결제가 있는 예약이라면 추가 결제 작업을 하기 전에 남은 잔액이나 환불할 금액을 먼저 확인하세요.

## 자주 묻는 질문

### 이미 만든 예약에도 소매 상품을 추가할 수 있나요?
네. 대상 서비스 예약을 편집할 때 상품을 추가할 수 있어요. 예약을 다시 만들 필요는 없어요.

### 고객이 예약 페이지에서 소매 상품을 직접 추가할 수 있나요?
아니요. 소매 상품은 앱 안에서 진행하는 지원되는 서비스 예약에서만 추가할 수 있어요.

### 소매 상품은 어디에서 만드나요?
**결제 > 상품**에서 카탈로그 상품을 만들고 관리해요.

### 상품을 여러 개 추가하거나 상품 가격을 바꿀 수 있나요?
네. 카탈로그 가격은 그대로 두고, 해당 예약의 수량과 단가만 조정할 수 있어요.

### 상품 재고가 없으면 어떻게 되나요?
하이퍼클래스에서 오류가 표시돼요. 단, 해당 상품에 **재고 소진 시에도 판매 계속**을 켜 두었다면 표시되지 않아요.

### 소매 상품을 제거하면 어떻게 되나요?
예약에서 상품이 빠지고, 해당하는 추적 재고가 복원돼요.

### 추가 요금이나 환불이 자동으로 처리되나요?
결제 상태에는 받을 금액이나 환불할 금액이 반영돼요. 실제 결제 수납과 환불은 해당 결제 절차에 따라 직접 처리해야 해요.

### 결제가 모두 끝난 예약에도 상품을 추가할 수 있나요?
이번 출시 버전은 이미 결제가 있는 예약의 변경을 지원해요. 다만 결제가 모두 끝난 예약을 편집하는 정확한 규칙은 확인이 필요해요.
