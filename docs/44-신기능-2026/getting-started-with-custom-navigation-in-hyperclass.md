# 커스텀 내비게이션 시작하기

커스텀 내비게이션(Custom Navigation)은 하이퍼클래스의 새 인터페이스예요. 기능을 더 쉽게 찾고, 상품 사이를 빠르게 오가고, 작업 공간을 정리할 수 있어요. 이 문서에서는 커스텀 내비게이션이 어떻게 동작하는지, **실험실**에서 미리보기·활성화·비활성화하는 방법, 요금제별로 쓸 수 있는 사용자 지정 옵션을 안내해요.

## 커스텀 내비게이션 알아보기

메뉴가 그룹으로 묶이고, 검색이 좋아지고, 레이아웃을 바꿀 수 있어서 에이전시가 비즈니스와 서브 계정에 맞는 내비게이션을 만들 수 있어요. 긴 메뉴 목록을 스크롤하지 않아도 돼요. 관련된 상품이 왼쪽 사이드바에 그룹으로 정리되어 더 깔끔하고 직관적으로 쓸 수 있어요.

자주 쓰는 기능은 **최근 대화**와 **고정됨**에서 바로 열 수 있어요. **전체 검색**과 이동 경로(breadcrumb)를 쓰면 사이드바로 되돌아가지 않고도 상품을 찾고 이동할 수 있어요. 내비게이션 그룹을 바꾼 뒤에도 **전체 상품**에서 원하는 기능을 찾을 수 있어요.

{% hint style="info" %}
커스텀 내비게이션은 상품이 정리되고 접근하는 방식만 바꿔요. 상품의 기능이나 사용자 권한은 그대로예요.
{% endhint %}

## 요금제별 사용 범위

커스텀 내비게이션은 하이퍼클래스의 모든 에이전시 요금제에서 쓸 수 있어요. 다만 사용자 지정 범위는 요금제에 따라 달라요. 모든 요금제에서 새 내비게이션을 쓸 수 있고, 상위 요금제에서는 내비게이션을 정리하고 서브 계정 전체의 레이아웃을 관리하는 옵션이 더해져요.

| 에이전시 요금제 | 사용할 수 있는 기능 |
| --- | --- |
| **월 $97** | 기본 레이아웃의 새 내비게이션을 사용할 수 있어요. 내비게이션 사용자 지정은 할 수 없어요. |
| **월 $297** | 새 내비게이션을 쓰고, 서브 계정 1개의 내비게이션 메뉴를 사용자 지정할 수 있어요. 재사용 가능한 레이아웃을 여러 서브 계정에 적용할 수는 없어요. |
| **월 $497** | 모든 서브 계정의 내비게이션을 사용자 지정하고, 재사용 가능한 레이아웃을 만들고 관리하며, 레이아웃 변경을 여러 서브 계정에 적용할 수 있어요. |

{% hint style="info" %}
사이드바, 검색, 이동 경로 같은 내비게이션 개선 사항은 모든 요금제에 적용돼요. 사용자 지정 기능은 해당 요금제에서만 쓸 수 있어요.
{% endhint %}

## 커스텀 내비게이션 켜기

**에이전시 보기**나 **서브 계정 보기**에서 **설정 > 실험실**로 들어가 커스텀 내비게이션을 켤 수 있어요. 에이전시 보기에 켜거나, 특정 서브 계정을 골라서 켜거나, 서브 계정 하나에서 바로 켤 수 있어요.

{% hint style="warning" %}
에이전시 보기에서 커스텀 내비게이션을 켜도 서브 계정에는 자동으로 켜지지 않아요. 반대로 에이전시 단계에서 끄면, 이를 사용 중인 모든 서브 계정에서도 꺼져요.
{% endhint %}

### 에이전시 보기에서 켜기

에이전시 보기에서는 한곳에서 에이전시 보기와 선택한 서브 계정에 커스텀 내비게이션을 켤 수 있어요. 두 옵션은 따로 관리되기 때문에 새 내비게이션을 쓸 위치를 직접 정할 수 있어요.

1. **에이전시 보기**에서 **설정 > 실험실**로 이동하세요.
2. **에이전시** 탭이나 **서브 계정** 탭을 선택하고, 아래로 스크롤해 **A New Design Experience, Starting with Navigation**(새로운 디자인 경험, 내비게이션부터 시작)을 찾으세요.
3. **에이전시** 탭: 켜기 전에 **미리보기**를 눌러 새 인터페이스를 먼저 살펴볼 수 있어요. 그다음 **A New Design Experience, Starting with Navigation**의 토글을 켜면 에이전시 보기에 커스텀 내비게이션이 활성화돼요.
4. **서브 계정** 탭: 켜기 전에 **미리보기**를 눌러 인터페이스를 살펴볼 수 있어요. 그다음 **기능 활성화**를 클릭하고, 커스텀 내비게이션을 켤 서브 계정을 선택한 뒤 저장하세요.

   ![서브 계정 탭에서 기능 활성화하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084251015/original/0mxgXLfvKJz8TKEZg3waAv4pONMEgAPAfA.png?1793046458)

### 서브 계정 보기에서 켜기

에이전시 관리자는 서브 계정 하나에서 바로 커스텀 내비게이션을 켤 수도 있어요. 이렇게 하면 그 서브 계정에만 새 인터페이스가 적용되고, 다른 서브 계정이나 에이전시 보기는 달라지지 않아요.

1. 원하는 서브 계정을 열고 **설정 > 실험실**로 이동하세요.
2. 아래로 스크롤해 **A New Design Experience, Starting with Navigation**을 찾으세요.
3. 켜기 전에 **미리보기**를 눌러 새 인터페이스를 먼저 살펴볼 수 있어요. 그다음 토글을 켜면 현재 서브 계정에 커스텀 내비게이션이 활성화돼요.

### 켜기 전에 미리보기

**미리보기 모드**에서는 커스텀 내비게이션을 켜기 전에 새 인터페이스를 먼저 써 볼 수 있어요. 새 내비게이션이 별도의 브라우저 탭에서 열리고 현재 계정 설정은 바뀌지 않아요. 켤지 말지 정하기 전에 부담 없이 둘러볼 수 있어요.

**실험실**의 **A New Design Experience, Starting with Navigation**에서 **미리보기**를 클릭하면 새 인터페이스가 열려요.

미리보기 화면 위쪽의 **사용자 지정 CSS** 토글로 기존 사용자 지정 스타일을 켜거나 끈 상태를 비교해 볼 수 있어요. 다 둘러봤으면 **Exit Preview**(미리보기 종료)를 클릭하거나 브라우저 탭을 닫으세요.

{% hint style="info" %}
**미리보기 모드**는 커스텀 내비게이션을 켜지 않고, 기존 내비게이션 설정도 바꾸지 않아요. 미리보기에서는 이전 내비게이션용 사용자 지정 CSS와 JavaScript가 기본적으로 꺼져 있어요.
{% endhint %}

![미리보기 모드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084251313/original/V9TQnaOG9APZLV_nYRGgtIq-2wdS8qBKkg.png?1793046945)

### 끄고 이전 내비게이션으로 되돌리기

켤 때 썼던 것과 같은 **설정 > 실험실** 메뉴에서 언제든 커스텀 내비게이션을 끌 수 있어요. 끄면 해당 계정은 이전 내비게이션으로 돌아가요.

끄는 위치에 따라 적용 범위가 달라요.

- **에이전시 보기:** 에이전시 단계에서 끄면, 이를 사용 중인 모든 서브 계정에서도 꺼져요.
- **서브 계정 단계:** 서브 계정 하나에서 끄면 그 서브 계정에만 적용돼요. 에이전시 보기와 다른 서브 계정은 그대로예요.

{% hint style="warning" %}
커스텀 내비게이션을 끄면 내비게이션 사용자 지정 내용이 초기화돼요. 나중에 다시 켜도 이전 사용자 지정 내용은 자동으로 복원되지 않아요.
{% endhint %}

## 내비게이션 사용자 지정

**월 $297, 월 $497 요금제**의 에이전시는 상품과 기능이 사이드바에 나타나는 방식을 직접 바꿀 수 있어요. 내비게이션 편집기에서 팀의 업무 흐름에 맞게 그룹과 상품을 정리하면, 자주 쓰는 도구를 쉽게 찾고 불필요한 항목은 줄일 수 있어요. 사용자 지정 내용은 개별 사용자가 아니라 서브 계정의 공유 레이아웃에 적용돼요.

내비게이션 사이드바 아래쪽의 **편집**을 선택하면 다음과 같은 사용자 지정 옵션을 쓸 수 있어요.

- 그룹 이름 변경: 최상위 내비게이션 그룹의 이름을 비즈니스에서 쓰는 용어로 바꿔요.
- 아이콘 변경: 지원되는 내비게이션 그룹과 항목의 아이콘을 바꿔요.
- 내비게이션 항목 순서 변경: 자주 쓰는 도구가 먼저 보이도록 그룹과 상품 순서를 바꿔요.
- 항목 숨기기 또는 표시: 사이드바에 나타낼 그룹과 상품을 정해요.
- 내비게이션 그룹 만들기: 관련 상품을 묶을 새 그룹을 추가해요.
- 그룹 간 상품 이동: 상품을 다른 내비게이션 그룹으로 옮겨요.

예를 들어 자주 쓰는 마케팅 도구를 모은 그룹을 만들고, 관련 상품을 그 그룹으로 옮긴 뒤, 덜 쓰는 항목은 사이드바에서 숨길 수 있어요.

**요금제별 사용 범위:** 월 $97 요금제에서는 내비게이션 사용자 지정을 할 수 없어요. 월 $297 요금제는 서브 계정 1개, 월 $497 요금제는 모든 서브 계정의 사용자 지정을 지원해요.

자세한 내용과 단계별 방법은 「내비게이션 메뉴 사용자 지정 방법」 문서를 참고하세요.

{% hint style="warning" %}
상품을 숨겨도 그 상품이 비활성화되거나, 필요한 권한이 있는 사용자의 접근이 막히지는 않아요.
{% endhint %}

## 내비게이션 레이아웃 저장 및 관리

저장된 레이아웃(Saved Layouts)을 쓰면 사용자 지정한 내비게이션 구성을 저장해 두고 여러 서브 계정에서 재사용할 수 있어요. 고객마다 같은 내비게이션 구조를 처음부터 다시 만들 필요 없이, 레이아웃을 한 번 만들어 필요한 곳에 적용하면 돼요.

요금제에 따라 다음과 같은 레이아웃 관리 기능을 쓸 수 있어요.

- 사용자 지정한 내비게이션 구성 저장
- 이미 저장된 레이아웃 선택
- 레이아웃 이름 변경 또는 복제
- 여러 서브 계정에 레이아웃 적용
- 레이아웃을 쓰는 서브 계정 전체에 공유 레이아웃 변경 사항 반영

예를 들어 같은 업종의 여러 비즈니스를 관리하는 에이전시라면, 해당 업종에 꼭 필요한 상품을 강조한 내비게이션 레이아웃을 한 번 만들어 두고 그 비즈니스들에 적용할 수 있어요. 서브 계정마다 일일이 사용자 지정하지 않아도 돼요.

**요금제별 사용 범위:** 서브 계정 1개의 내비게이션 사용자 지정은 월 $297 요금제에서 쓸 수 있어요. 여러 서브 계정에서 재사용할 레이아웃을 만들고 관리하려면 월 $497 요금제가 필요해요.

자세한 방법은 「내비게이션 레이아웃 만들기 및 관리 방법」 문서를 참고하세요.

{% hint style="info" %}
내비게이션 레이아웃은 스냅샷에 포함되지 않고, 새로 만든 서브 계정에도 자동으로 적용되지 않아요.
{% endhint %}

## 사용자 지정 CSS와 JavaScript

커스텀 내비게이션은 새 인터페이스를 쓰기 때문에, 이전 내비게이션용으로 만든 사용자 지정 CSS와 JavaScript에 영향을 줄 수 있어요. 스타일이 충돌하지 않도록, 커스텀 내비게이션을 켜면 하이퍼클래스가 이전 사용자 지정 코드를 기본적으로 비활성화해요. 기존 코드를 삭제하지는 않아요.

에이전시는 **White Label settings**(화이트라벨 설정)에서 기존 사용자 지정 CSS와 JavaScript를 다시 사용하도록 선택할 수 있어요. 다만 다크 모드, 사이드바 수정, 사용자 정의 메뉴 링크 같은 일부 사용자 지정 스타일은 새 인터페이스에서 제대로 표시되지 않을 수 있어요.

에이전시 보기에서 커스텀 내비게이션을 미리 볼 때 **사용자 지정 CSS** 토글을 쓰면, 기능을 켜기 전에 기존 사용자 지정 스타일을 켠 모습과 끈 모습을 비교해 볼 수 있어요.

이전 코드를 다시 쓰는 방법과 호환 한계는 「커스텀 내비게이션에서 사용자 지정 CSS와 JavaScript 사용하기」 문서를 참고하세요.

{% hint style="info" %}
이전 내비게이션을 쓰는 서브 계정에서는 기존 사용자 지정 CSS와 JavaScript가 계속 적용돼요. 커스텀 내비게이션을 켜도 저장해 둔 사용자 지정 코드가 삭제되거나 수정되지는 않아요.
{% endhint %}

## 자주 묻는 질문

### 내비게이션이 바뀌면 하이퍼클래스 기능이 작동하는 방식도 달라지나요?
아니요. 커스텀 내비게이션은 상품과 기능이 정리되고 접근하는 방식만 바꿔요. 기존 상품의 기능은 그대로예요.

### 아무것도 사용자 지정하지 않고 커스텀 내비게이션을 쓸 수 있나요?
네. 모든 요금제에서 기본 내비게이션 레이아웃으로 새 인터페이스를 쓸 수 있어요.

### 서브 계정 하나에만 커스텀 내비게이션을 켤 수 있나요?
네. 모든 서브 계정에 켜지 않고도 개별 서브 계정에만 켤 수 있어요.

### 이전 내비게이션으로 되돌릴 수 있나요?
네. **실험실**에서 커스텀 내비게이션을 끄면 돼요. 다만 끄면 내비게이션 사용자 지정 내용이 초기화돼요.

### 상품을 숨기면 사용자가 그 상품에 접근할 수 없게 되나요?
아니요. 상품을 숨기면 내비게이션 메뉴에서만 사라지고 접근 권한은 바뀌지 않아요. 적절한 권한이 있는 사용자는 직접 URL이나 **전체 상품**을 통해 계속 접근할 수 있어요.

### 내비게이션 레이아웃이 스냅샷에 포함되나요?
아니요. 내비게이션 레이아웃과 스냅샷은 따로 관리돼요. 스냅샷을 적용해도 기존 내비게이션 레이아웃은 바뀌지 않아요.
