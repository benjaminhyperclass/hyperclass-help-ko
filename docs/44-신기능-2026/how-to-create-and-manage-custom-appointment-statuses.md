# 사용자 지정 예약 상태 만들기와 관리

하이퍼클래스 캘린더에서는 예약 상태를 우리 비즈니스에 맞는 이름으로 직접 만들 수 있어요. '체크인', '의사 대기 중', '픽업 준비 완료'처럼 실제 업무 흐름에 맞는 이름을 쓸 수 있어요. 사용자 지정 상태는 모두 6가지 정해진 상태(state) 중 하나에 속하고, 이 상태가 일정 확보, 연결된 캘린더, 알림 동작을 정해요. 이 문서에서는 사용자 지정 예약 상태를 켜고, 만들고, 관리하고, 캘린더와 워크플로우 자동화에서 사용하는 방법을 안내해요.

## 사용자 지정 예약 상태란?

사용자 지정 예약 상태를 쓰면 예약의 각 단계를 원하는 말로 이름 붙일 수 있어요. 예를 들면 '체크인', '의사 대기 중', '픽업 준비 완료' 같은 이름이에요. 모든 예약 상태는 6가지 고정된 **상태(state)** 중 하나에 속해요. 예약 시간, 연결된 캘린더, 알림이 어떻게 처리될지는 상태(state)가 정해요. 예약 상태(status)는 팀원이 화면에서 보고 고르는 이름표예요.

```
이 기능을 쓰려면 해당 로케이션의 실험실에서 Custom Appointment Statuses(사용자 지정 예약 상태)를 켜세요.
```

---

## 사용자 지정 예약 상태의 장점

- 우리 용어 그대로 쓸 수 있어요. 정해진 이름 대신 비즈니스 방식에 맞게 예약을 관리하세요.
- 예상치 못한 변화가 없어요. 일정 확보, 캘린더 동기화, 알림은 이름이 아니라 상태(state)를 기준으로 동작하기 때문에 계속 똑같이 작동해요.
- 자동화가 더 깔끔해져요. 체크인처럼 원하는 단계에서 정확히 워크플로우를 실행할 수 있어요.
- 안심하고 정리할 수 있어요. 더 이상 쓰지 않는 예약 상태를 보관해도 기록은 그대로 남아요.

### 상태(state)와 동작

| 상태(state) | 예약 시간 | 연결된 캘린더(Google, Outlook) | 기본 예약 상태 |
| --- | --- | --- | --- |
| Pending(대기) | 시간이 확보돼요. 다른 사람은 예약할 수 없어요 | 아직 추가되지 않아요 | Unconfirmed(미확정) |
| Active(활성) | 시간이 확보돼요. 다른 사람은 예약할 수 없어요 | 캘린더가 미팅 링크를 쓰면 링크와 함께 추가돼요 | Confirmed(확정) |
| Completed(완료) | 새 예약을 받을 수 있게 시간이 풀려요 | 기록으로 남아요 | Showed(방문함) |
| No show(노쇼) | 새 예약을 받을 수 있게 시간이 풀려요 | 기록으로 남아요 | No Show(노쇼) |
| Cancelled(취소) | 새 예약을 받을 수 있게 시간이 풀려요 | 삭제돼요 | Cancelled(취소됨) |
| Invalid(유효하지 않음) | 새 예약을 받을 수 있게 시간이 풀려요 | 삭제돼요 | Invalid(유효하지 않음) |

상태(state)는 추가하거나 이름을 바꾸거나 삭제할 수 없어요. 각 상태(state)에는 사용 중인 예약 상태가 항상 1개 이상 있어요.

### 기존 예약은 어떻게 되나요?

사용자 지정 예약 상태를 켜면 지금 쓰고 있는 6가지 예약 상태가 위 표의 기본 예약 상태가 돼요. 기존 예약, 워크플로우, 캘린더 설정은 바꾸지 않아도 그대로 작동해요.

## 예약 상태 관리하기

**설정 > 캘린더 > 환경설정 > 예약 상태**로 이동하세요. 예약 상태는 상태(state)별로 묶여 있어요. 페이지 맨 위의 **자세히 보기**를 클릭하면 각 상태(state)에 대한 요약을 볼 수 있어요.

![예약 상태 설정 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084285245/original/wE0Jj6sXLybbEL7XnjcRhSsTKyPRPr6MiQ.png?1793093646)

**예약 상태 추가하기**

1. 원하는 상태(state)를 열어요. 예를 들어 Active를 열어요.
2. **새 상태**를 클릭하고 이름을 입력한 뒤 Enter를 누르세요.
3. 해당 상태(state)의 맨 아래에 예약 상태가 추가되고 바로 쓸 수 있어요.

이름은 40자까지 입력할 수 있고, 대소문자와 불필요한 공백을 무시해도 다른 이름과 겹치면 안 돼요. 한 상태(state)에는 예약 상태를 25개까지 둘 수 있어요.

![새 예약 상태 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084285479/original/49grRMMGIfOPSjx6glezZhIjme42MgckXw.png?1793093771)

**예약 상태 이름 바꾸기**

예약 상태 위에 마우스를 올리고 연필 아이콘을 클릭한 다음, 이름을 고치고 확인하세요. 이 상태를 쓰는 모든 예약과 워크플로우에 새 이름이 표시되고, 다른 것은 바뀌지 않아요. 이름만 바꾸는 게 아니라 다른 단계가 필요하다면 새 예약 상태를 추가하세요.

![예약 상태 이름 변경](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084285685/original/EjoU-mcI3tY8ZWOXlKb9kx_-WJv3FQlOeA.png?1793093846)

**예약 상태 순서 바꾸기**

예약 상태의 핸들을 드래그해 같은 상태(state) 안에서 위아래로 옮기세요. 상태 선택 목록에도 이 순서대로 표시돼요. 예약 상태를 다른 상태(state)로 옮길 수는 없어요. 대신 원하는 상태(state)에 새 예약 상태를 추가하세요.

![예약 상태 순서 변경](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084288200/original/PbAgrII5AWlOwsR2ymqhZlZAWpRs9g_efw.gif?1793094951)

**예약 상태 보관하기**

예약 상태 위에 마우스를 올리고 보관 아이콘을 클릭하세요. 영향 내용을 확인하고 체크박스를 선택한 다음 **보관**을 클릭하세요.

- 새 예약은 보관된 상태로 설정할 수 없어요. 이미 이 상태인 예약은 그대로 유지돼요.
- 예약을 이 상태로 바꾸는 워크플로우는 다른 상태를 고르기 전까지 해당 단계에서 실패해요.
- 한 상태(state)에서 사용 중인 마지막 예약 상태는 보관할 수 없어요.

![예약 상태 보관 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084288030/original/nAYh6_Zd0VwaPeXuJf9dokwCaRsd6JSgCg.png?1793094871)

**예약 상태 복원하기**

상태(state)를 열고 **보관됨**을 펼친 다음 복원 아이콘을 클릭하세요. 예약 상태가 원래 위치로 돌아오고 다시 쓸 수 있어요.

## 예약에서 예약 상태 사용하기

예약을 만들거나 수정하는 곳이면 어디서든 예약 상태를 고를 수 있어요. **새 예약** 창, **예약 목록 보기**의 **상태** 드롭다운, 예약 상세 정보 패널에서 고르세요. 예약 상태는 상태(state)별로 묶여 보이고, 이름으로 검색할 수도 있어요.

- **같은 상태(state)** 안에서 바꾸면 이름표만 바뀌어요. 예를 들어 **Confirmed**에서 체크인으로 바꾸는 경우예요. 예약 시간, 연결된 캘린더, 알림은 그대로예요.
- **다른 상태(state)**의 예약 상태로 바꾸면 그 상태(state)의 동작이 바로 적용돼요. 예를 들어 체크인에서 **Showed**로 바꾸는 경우예요.
- 예약 상태로 예약을 찾으려면 **예약 목록 보기**에서 **상세 필터 > 상태**를 사용하세요.

### 자동 확정과 새 예약

**Auto-confirm new calendar meetings**(새 캘린더 미팅 자동 확정)를 켜면 새 예약이 Active 상태(state)로 시작해요. 끄면 Pending 상태(state)로 시작해요. 두 경우 모두 예약 시간은 확보돼요.

### 워크플로우와 알림

- **워크플로우:** **Appointment Status**(예약 상태) 트리거, **If/Else**(조건 분기)의 예약 필터, **Update Appointment Status**(예약 상태 업데이트) 액션에 예약 상태 목록이 표시돼요. 이름을 바꾼 예약 상태는 자동으로 반영돼요.
- **캘린더 알림**은 상태(state)를 기준으로 동작해요. **예약 완료**(Pending), **예약 완료**(Active), **Cancellation**(취소 알림)은 예약이 해당 상태(state)로 들어갈 때만 발송돼요. 같은 상태(state) 안에서 예약 상태만 바뀔 때는 발송되지 않아요.
- 예약이 특정 예약 상태가 됐을 때 고객에게 메시지를 보내려면, **Appointment Status** 트리거로 워크플로우를 만들고 그 예약 상태로 필터링하세요.

```
공개 API 지원은 곧 확대될 예정이에요.
```

## 자주 묻는 질문

### 이 기능을 켜면 기존 워크플로우가 작동하지 않게 되나요?

아니요. 현재 쓰고 있는 예약 상태가 기본 예약 상태가 되기 때문에 기존 워크플로우는 계속 작동해요.

### 예약 상태를 삭제할 수 있나요?

아니요. 삭제하는 대신 보관하세요. 그러면 지난 예약과 리포트의 기록이 그대로 남아요.

### 예약 상태가 보관되지 않아요.

각 상태(state)에는 사용 중인 예약 상태가 1개 이상 있어야 해요. 먼저 해당 상태(state)에 다른 예약 상태를 추가하세요.

### 전에 쓴 이름으로는 예약 상태를 만들 수 없는 이유가 뭔가요?

이름은 보관된 예약 상태를 포함해 모든 상태(state)에서 고유해야 해요. 보관된 예약 상태를 복원하거나 이름을 바꾸세요.

### 고객에게도 이 예약 상태가 보이나요?

예약 상세 정보를 넣은 메시지처럼 직접 보여 주도록 설정한 곳에서만 보여요. 상태(state) 이름은 고객에게 표시되지 않아요.

### 예약 상태에 색상을 지정할 수 있나요?

아직은 안 돼요. 각 예약 상태는 소속된 상태(state)의 색상을 써요.

### 서비스나 대여에서도 쓸 수 있나요?

아직은 안 돼요. 사용자 지정 예약 상태는 캘린더(미팅 캘린더)에서만 쓸 수 있어요.
