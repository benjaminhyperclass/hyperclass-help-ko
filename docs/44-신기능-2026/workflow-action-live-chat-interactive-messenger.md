# 워크플로우 액션 — Live chat interactive messenger(라이브 채팅 인터랙티브 메신저)

라이브 채팅 대화 안에 버튼을 보여 주고, 방문자가 고른 버튼에 따라 워크플로우를 이어 가는 액션이에요. 방문자는 긴 메시지를 입력하지 않고도 자주 묻는 요청을 해결할 수 있어요. 이 문서에서는 인터랙티브 버튼을 설정하는 방법, 워크플로우 분기를 만드는 방법, 방문자가 고른 버튼을 하이퍼클래스 **대화**에서 확인하는 방법을 안내해요.

## Live chat interactive messenger란?

**Live chat interactive messenger**(라이브 채팅 인터랙티브 메신저)는 방문자가 메시지를 보낸 뒤 라이브 채팅 대화에 인터랙티브 카드를 보내는 워크플로우 액션이에요.

카드에는 메시지, 이미지(선택), 인터랙티브 버튼을 최대 5개까지 넣을 수 있어요. 방문자는 "주문 조회", "반품/환불", "고객지원 연결" 같은 항목을 입력 없이 선택할 수 있어요.

버튼마다 특정 워크플로우 분기를 시작하거나 HTTPS 링크를 열도록 정할 수 있어요. 이 액션에는 **Timeout**(시간 초과) 분기도 있어요. 정해 둔 대기 시간 안에 방문자가 워크플로우 옵션을 고르지 않았을 때 이 분기로 이어져요.

방문자의 선택에 따라 후속 메시지를 보내거나, 태그를 추가하거나, 연락처를 사용자에게 배정하는 등 워크플로우에서 지원하는 다른 액션을 실행할 수 있어요.

## 이 액션을 쓰면 좋은 점

인터랙티브 버튼을 쓰면 반복되는 방문자 요청을 정해진 흐름으로 처리할 수 있어요. 들어오는 메시지를 일일이 분류하지 않고, 방문자가 고른 옵션에 맞춰 워크플로우가 응답하도록 설정하면 돼요.

- 한 번의 탭으로 응답: 방문자가 요청을 길게 설명하지 않아도 미리 정해 둔 옵션 중에서 고를 수 있어요.
- 대화 자동 분기: 액션 버튼마다 워크플로우 분기를 따로 만들어, 방문자를 알맞은 후속 절차로 안내해요.
- 다양한 워크플로우 액션: 선택한 옵션에 따라 라이브 채팅 메시지를 보내거나, 연락처에 태그를 추가하거나, 사용자를 배정할 수 있어요.
- 셀프서비스 링크: 도움말 센터나 주문 정보 페이지처럼 HTTPS 페이지를 여는 버튼을 넣을 수 있어요.
- 시간 초과 처리: 방문자가 정해 둔 대기 시간 안에 선택하지 않으면 전용 **Timeout** 분기로 이어 가요.
- 선택 내용 확인: 방문자가 고른 버튼이 **대화**에 표시돼서 팀원이 답변하기 전에 선택 내용을 볼 수 있어요.
- 빠른 워크플로우 설정: 채팅 위젯 빌더에서 연결된 워크플로우나 빠른 워크플로우로 바로 시작할 수 있어요.

## 사전 준비 사항과 제한 사항

Interactive Messenger를 설정하기 전에 라이브 채팅 환경과 워크플로우가 올바르게 구성되어 있는지 확인하세요. 지원하는 버튼 동작과 제한 사항을 미리 알아 두면 예상치 못한 결과를 줄일 수 있어요.

#### 사전 준비 사항

- 라이브 채팅용으로 설정한 **라이브 채팅** 또는 **All-in-One Chat**(올인원 채팅) 위젯을 사용하세요. 올인원 채팅 위젯은 [올인원 채팅 위젯 사용 방법](../06-사이트/채팅-위젯/how-to-use-the-all-in-one-chat-widget.md) 문서를 참고하세요.
- 방문자가 채팅을 사용할 웹사이트에 채팅 위젯을 설정하고 설치하세요.
- 서브 계정의 채팅 위젯 설정 화면과 워크플로우 빌더 설정 화면에 접근할 수 있어야 해요.
- 해당 라이브 채팅 위젯용으로 **Customer Replied**(고객 답장) 워크플로우 트리거를 설정하세요. 자세한 내용은 [워크플로우 트리거 — Customer Replied](../07-워크플로우/Events-Workflow-Triggers/workflow-trigger-customer-replied.md) 문서를 참고하세요.
- 웹사이트를 여는 버튼이 있다면 이동할 HTTPS 주소를 준비하세요.

#### 지원 기능과 제한 사항

- 최대 버튼 수: 인터랙티브 카드 하나에 버튼을 최대 5개까지 넣을 수 있어요.
- 이미지(선택): JPG, PNG, WEBP 형식을 지원해요.
- 이미지 출처: 이미지를 시스템에서 업로드하거나 **Media library**(미디어 라이브러리)에서 선택할 수 있어요.
- 버튼 동작: 버튼은 워크플로우 액션을 수행하거나 HTTPS 링크를 열 수 있어요.
- 워크플로우 분기: 액션 버튼마다 워크플로우 캔버스에 대응하는 분기가 생겨요.
- 시간 초과: 정해 둔 대기 시간이 지나도 유효한 선택이 없으면 별도의 **Timeout** 분기가 실행돼요.
- 액션 선택은 한 번만: 워크플로우 분기 버튼은 처음 선택한 하나만 인정돼요. 그 뒤에는 다른 워크플로우 분기 버튼을 선택할 수 없어요.
- 링크 버튼: 웹사이트 링크 버튼은 워크플로우 분기 버튼을 선택한 뒤에도 계속 클릭할 수 있어요.
- 메시지 트리거: 방문자가 설정한 워크플로우를 실행시키는 메시지를 보내면 인터랙티브 워크플로우 카드가 나타나요.

{% hint style="warning" %}
버튼 선택 대기 시간은 채팅 위젯의 일반 비활성 설정이나 채팅 종료 설정과 달라요.
{% endhint %}

## Live chat interactive messenger 설정하기

채팅 위젯 빌더에서 설정하거나 워크플로우 빌더에서 직접 설정할 수 있어요. 어느 방법으로 하든 인터랙티브 카드를 보내고 방문자의 선택에 응답하는 워크플로우가 만들어져요.

채팅 위젯 빌더에서는 선택한 위젯에 연결된 워크플로우로 바로 이동할 수 있어요. 직접 설정하는 방법에서는 워크플로우 빌더에서 트리거와 액션을 구성해요.

### 채팅 위젯 빌더에서 설정하기

특정 위젯에서 인터랙티브 워크플로우까지 가장 빠르게 가는 방법이에요. 이미 쓰고 있는 라이브 채팅에 자동 응답을 설정할 때 편해요.

1. 서브 계정 화면의 왼쪽 메뉴에서 **사이트**를 선택하세요.
2. **채팅 위젯**을 선택하세요.
3. 설정하려는 **라이브 채팅** 또는 **All-in-One Chat** 위젯을 여세요.
4. 위젯 빌더에서 **채팅 창** 탭을 선택하세요.
5. **인터랙티브 버튼** 섹션을 펼치세요.
6. **인터랙티브 버튼 설정**을 클릭하세요.

   ![인터랙티브 버튼 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083893893/original/yOiMOfkaM4n2JXQiGSItR64dgaD61sYLkA.png?1792600984)

7. **Automate your chat widgets**(채팅 위젯 자동화) 창에서 시작 방식을 고르세요.
   - **Support Triage**(지원 문의 분류): 자주 들어오는 지원 요청에 맞춰 만든 워크플로우로 시작해요.
   - **Lead Qualification Menu**(리드 자격 검증 메뉴): 방문자의 응답에 따라 분기하도록 만든 워크플로우로 시작해요.
   - **Create your own workflow**(직접 워크플로우 만들기): 선택한 위젯에 연결된 워크플로우가 열려요. **Customer Replied** 트리거와 **Live chat interactive messenger** 액션이 이미 추가되어 있어요.
8. 나만의 인터랙티브 카드를 만들려면 **Create your own workflow**를 선택하세요.

   ![Create your own workflow 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083894043/original/EF_oqq_8-fG-QknxVzngcFhosOWNwAwCaA.png?1792601113)

9. 워크플로우 빌더에서 이미 추가된 **Customer Replied** 트리거와 **Live chat interactive messenger** 액션을 찾으세요.
10. **Live chat interactive messenger** 액션을 열고 메시지, 이미지, 버튼을 설정하세요.

    ![Live chat interactive messenger 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083894295/original/6tH9M64olJXaxKYM8203KJdAwmFo-JNmkQ.png?1792601258)

{% hint style="info" %}
채팅 위젯 빌더에서 **Create your own workflow**를 선택하면 트리거와 인터랙티브 액션이 이미 추가되어 있어요. 직접 다시 만들 필요가 없어요.
{% endhint %}

### 워크플로우 빌더에서 설정하기

새 워크플로우나 기존 워크플로우에 인터랙티브 버튼을 추가할 수 있어요. 채팅 위젯 빌더를 거치지 않아도 돼요.

1. 서브 계정 화면에서 **자동화 > 워크플로우**로 이동하세요.
2. **Create Workflow**(워크플로우 만들기)를 클릭해 새 워크플로우를 시작하거나, 기존 워크플로우를 여세요. 새로 만드는 경우에는 안내에 따라 빌더 화면으로 들어가세요.
3. **+ Add New Trigger**(새 트리거 추가)를 클릭하고 **Customer Replied**를 선택하세요.
4. 알아보기 쉬운 이름을 트리거에 붙이세요.
5. **+ Add Filters**(필터 추가)를 클릭해 워크플로우를 실행할 라이브 채팅 대화를 지정하세요.
6. 위젯 유형에 맞게 필터를 설정하세요.
   - 라이브 채팅 위젯: **Reply Channel**(답장 채널)을 **Live chat**(라이브 채팅)으로 설정한 다음, **Live chat is**(라이브 채팅 조건)에서 특정 위젯을 선택하세요.
   - 올인원 채팅 위젯: **Reply Channel**을 **All-in-One Chat**으로 설정하세요. **Chat Type is**(채팅 유형 조건)에서 **Chat Widget**(채팅 위젯) 또는 **Live Chat**을 고른 뒤, **Chat Widget is**(채팅 위젯 조건) 또는 **Live Chat is**에서 위젯을 선택하세요.
7. 트리거 설정이 끝나면 **Save Trigger**(트리거 저장)를 클릭하세요.
8. 워크플로우 캔버스에서 다음 액션을 추가할 위치의 **+** 아이콘을 클릭하고 **Live chat interactive messenger**를 선택하세요.
9. 액션을 열어 메시지, 이미지(선택), 인터랙티브 버튼을 설정하세요.

### 메시지, 이미지, 버튼 설정하기

**Live chat interactive messenger** 액션에서는 방문자에게 보이는 메시지를 정하고, 이미지를 넣고, 다음 단계를 안내하는 클릭 버튼을 만들 수 있어요.

1. 서브 계정 화면에서 **자동화 > 워크플로우**로 이동해 설정할 워크플로우를 여세요.
2. 워크플로우 캔버스에서 **Live chat interactive messenger** 액션을 클릭해 설정 창을 여세요.
3. 필요하면 **ACTION NAME**(액션 이름)을 바꿔서 액션을 쉽게 구분할 수 있게 하세요.
4. **MESSAGE**(메시지) 필드에 질문이나 인사말을 입력하세요. 예: "안녕하세요, 오늘 주문과 관련해 무엇을 도와드릴까요?"
5. 이미지를 넣으려면 **IMAGE**(이미지)에서 **System upload**(시스템에서 업로드)를 선택해 JPG, PNG, WEBP 파일을 추가하거나, **Media library**를 선택해 이미 올려 둔 이미지를 사용하세요.
6. **Buttons**(버튼) 섹션으로 스크롤하세요.
7. **BUTTON LABEL**(버튼 레이블)에 방문자에게 보여 줄 문구를 입력하세요. 예: "주문 조회"
8. **ON CLICK**(클릭 시 동작)에서 버튼을 눌렀을 때 일어날 일을 선택하세요.
   - **Perform actions**(액션 수행): 방문자를 해당 워크플로우 분기로 안내해요. 그 분기에서 후속 액션을 설정할 수 있어요.
   - **Open website URL**(웹사이트 URL 열기): **WEBSITE URL**(웹사이트 URL) 필드에 입력한 HTTPS 링크를 열어요. 예: `https://example.com/help`
9. 선택지를 더 추가하려면 **+ Add button**(버튼 추가)을 클릭하고, 추가한 버튼도 같은 방식으로 설정하세요. 인터랙티브 카드 하나에는 최대 5개의 버튼을 넣을 수 있어요.
10. 설정이 끝나면 **Save action**(액션 저장)을 클릭하세요.

![메시지, 이미지, 버튼 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083894559/original/nlwSOnhJY1GcrSABBy7pQJSlEEsNTe6TWA.png?1792601445)

#### 인터랙티브 카드 예시

메시지: "안녕하세요, 오늘 주문과 관련해 무엇을 도와드릴까요?"

| 버튼 레이블 | 클릭 시 동작 | 의도한 결과 |
| --- | --- | --- |
| 주문 조회 | Perform actions | 주문 조회 워크플로우 분기 시작 |
| 주문 변경 | Perform actions | 주문 변경 워크플로우 분기 시작 |
| 반품/환불 | Perform actions | 반품 또는 환불 워크플로우 분기 시작 |
| 고객지원 연결 | Perform actions | 지원 담당자 연결 분기 시작 |
| 도움말 센터 보기 | Open website URL | HTTPS 도움말 페이지 열기 |

위 버튼 레이블은 예시예요. 실제 워크플로우 단계와 연결할 웹사이트 주소는 비즈니스에 맞게 설정하세요.

### 버튼 분기와 Timeout 설정하기

액션을 수행하도록 설정한 버튼마다 워크플로우 분기가 하나씩 생겨요. 방문자가 고른 버튼에 따라 이어질 동작을 자동화할 수 있어요. 방문자가 정해 둔 대기 시간 안에 응답하지 않으면 **Timeout** 분기가 대신 실행돼요.

1. 서브 계정 화면에서 **자동화 > 워크플로우**로 이동해 워크플로우를 여세요.
2. **Live chat interactive messenger** 액션을 선택하세요.
3. 방문자의 응답을 얼마 동안 기다릴지 설정하고 **Save action**을 클릭하세요.
4. 워크플로우 캔버스에서 액션 버튼별 분기와 **Timeout** 분기를 확인하세요.
5. 버튼 분기 아래의 **+** 아이콘을 클릭해, 그 옵션을 선택했을 때 실행할 액션을 추가하세요. 예를 들어 다음과 같은 액션을 쓸 수 있어요.
   - **Send live chat message**(라이브 채팅 메시지 보내기): 방문자의 선택에 맞는 후속 메시지를 보내요.
   - **Add Tag**(태그 추가): 방문자의 요청을 분류하는 태그를 추가해요.
   - **Assign to User**(사용자에게 배정): 연락처를 팀원에게 배정해 도움을 받게 해요.
6. 각 액션을 설정하고 저장한 뒤, 나머지 버튼 분기도 같은 방식으로 설정하세요.
7. **Timeout** 분기에서 **+** 를 클릭하고, 정해 둔 시간 안에 방문자가 옵션을 선택하지 않았을 때 실행할 액션을 추가하세요. 예를 들어 라이브 채팅 후속 메시지를 보내거나 연락처를 팀원에게 배정할 수 있어요.
8. 모든 분기를 설정했다면 각 워크플로우 경로를 살펴보고, 게시하기 전에 방문자가 알맞은 다음 단계로 이어지는지 확인하세요.

{% hint style="info" %}
버튼 레이블과 워크플로우 액션 이름을 알아보기 쉽게 지으면 팀원이 각 분기 경로를 쉽게 파악할 수 있어요.
{% endhint %}

### 워크플로우 게시하고 테스트하기

방문자에게 공개하기 전에 버튼이 올바르게 표시되는지, 각 선택이 의도한 액션을 실행하는지 테스트하세요. 방문자의 선택은 **대화**에서도 확인할 수 있어요.

1. 서브 계정 화면에서 **자동화 > 워크플로우**로 이동해 설정한 워크플로우를 여세요.
2. **Customer Replied** 트리거, **Live chat interactive messenger** 액션, 버튼별 분기가 올바르게 설정되어 있는지 확인하세요.
3. 준비가 끝나면 워크플로우를 **Publish**(게시) 상태로 설정하세요.
4. 채팅 위젯이 설치된 웹사이트에 접속해서 채팅을 여세요.
5. "안녕하세요," 같은 테스트 메시지를 보내 워크플로우를 실행하세요. 설정한 메시지, 이미지(선택), 버튼이 담긴 인터랙티브 카드가 나타나야 해요.
6. 버튼 동작별로 테스트하세요.
   - **Perform actions**: 버튼을 선택하면 그 버튼이 강조 표시되고 다른 워크플로우 분기 버튼은 선택할 수 없게 되는지 확인하세요. 해당 워크플로우 분기가 의도한 액션을 실행하는지도 확인하세요.
   - **Open website URL**: 링크 버튼을 클릭해 설정한 HTTPS 주소가 열리는지 확인하세요.
   - **Timeout**: 옵션을 선택하지 않고 테스트를 한 번 더 시작하세요. 정해 둔 대기 시간이 지나면 워크플로우가 **Timeout** 분기로 이어지는지 확인하세요.
7. 서브 계정 화면으로 돌아와 왼쪽 메뉴에서 **대화**를 선택하세요.
8. **대화** 탭을 열고 **팀 인박스**에서 테스트 대화를 찾아 선택하세요. 방문자가 선택한 버튼이 기록되어 있는지 확인하세요.

## 라이브 채팅과 대화에서 보이는 버튼 선택 내용

Interactive Messenger는 방문자의 선택을 채팅 화면과 하이퍼클래스 **대화**에 모두 보여 줘요. 선택 상태가 표시되기 때문에 여러 워크플로우 분기가 동시에 실행되지 않고, 팀원이 대화를 넘겨받을 때도 맥락을 알 수 있어요.

#### 방문자에게 보이는 화면

- 선택하기 전에는 설정한 버튼이 카드에 표시돼요.
- 방문자가 워크플로우 분기 버튼을 선택하면 선택한 버튼이 강조 표시돼요.
- 그 카드의 다른 워크플로우 분기 버튼은 비활성화돼요.
- 웹사이트 링크 버튼은 계속 클릭할 수 있어요.
- 같은 카드에서 두 번째 워크플로우 분기를 실행할 수는 없어요.

#### 팀원에게 보이는 화면

- **대화**에서 인터랙티브 카드에 선택된 버튼이 표시돼요.
- 팀원은 대화에 답하면서 기록된 선택 내용을 확인할 수 있어요.
- 선택한 옵션을 보면 방문자의 처음 요청이 무엇이었는지 알 수 있어요.

## 자주 묻는 질문

### 라이브 채팅 인터랙티브 메신저를 쓰려면 대화 AI가 꼭 필요한가요?
아니요. **Live chat interactive messenger**는 워크플로우 빌더에서 설정하는 워크플로우 액션이에요. 대화 AI의 **Rich Elements Support**(리치 요소 지원)는 별도 기능이고, 자체 설정이 따로 있어요. 자세한 내용은 [대화 AI 고급 설정 개요](../13-AI-Employee/Getting-Started-w/Conversation-AI/advanced-settings-overview-conversation-ai.md) 문서를 참고하세요.

### 한 카드에 워크플로우 버튼과 웹사이트 링크 버튼을 함께 넣을 수 있나요?
네. 버튼마다 워크플로우 액션을 수행할지 HTTPS 링크를 열지 따로 정할 수 있어요. 액션 버튼은 각각 설정한 워크플로우 분기를 사용해요.

### 빠른 워크플로우를 쓰지 않고도 Interactive Messenger 워크플로우를 만들 수 있나요?
네. 채팅 위젯 빌더에서 **Create your own workflow**를 선택하거나, **자동화 > 워크플로우**에서 트리거와 액션을 직접 설정하면 돼요.

### 방문자가 지원 옵션을 선택하면 팀원에게 연결할 수 있나요?
네. 해당 버튼 분기에 **Assign to User** 같은 배정 액션을 설정하면 연락처를 알맞은 팀원에게 배정할 수 있어요.
