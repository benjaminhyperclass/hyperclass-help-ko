# 기회 추가 사이드 패널 사용과 설정

하이퍼클래스의 기회 추가 사이드 패널을 쓰면 연락처가 없어도 기회를 만들 수 있어요. 한 화면에서 딜을 만들고, 연락처 정보를 입력하고, 관련 레코드를 연결할 수 있어요. 관리자는 필드 선택, 필수 여부, 연결 항목을 설정해 이 폼을 원하는 대로 바꿀 수 있어요.

{% hint style="info" %}
이 기능은 현재 Opportunity-First 비공개 베타에 포함되어 있어요. 베타 접근 신청 폼을 통해 서브 계정을 등록해야 사용할 수 있어요.
{% endhint %}

## 기회 추가 사이드 패널이란?

기회 추가 사이드 패널은 설정을 바꿀 수 있는 폼이에요. 필수 항목은 **기회명**, **파이프라인**, **단계** 세 가지뿐이에요. 연락처는 선택 사항이라서 연락처 정보가 없을 때도 딜을 먼저 등록할 수 있어요. 이 패널에서는 폼 안에서 바로 연락처 만들기, 커스텀 필드, 레코드 연결, 여러 가지 저장 방식도 쓸 수 있어요.

## 사이드 패널의 장점

새 패널은 기회를 만드는 과정을 단순하게 하면서, 어떤 정보를 받을지는 관리자가 정할 수 있게 해 줘요.

- 빠른 딜 생성: 꼭 필요한 정보만 입력해서 기회를 만들 수 있어요.
- 선택 사항인 연락처: 연락처를 고르지 않고도 기회를 저장할 수 있어요.
- 패널 안에서 연락처 관리: 패널을 벗어나지 않고 연락처를 선택하거나 새로 만들 수 있어요.
- 필드 사용자 지정: 필드를 추가하고, 제거하고, 순서를 바꾸고, 필수로 지정할 수 있어요.
- 유연한 연결: 기회를 만드는 중에 연락처, 회사, 사용자 지정 개체를 연결할 수 있어요.
- 연속 입력: **저장 후 추가**로 딜을 연달아 만들 수 있어요.
- 저장되지 않은 변경사항 보호: 저장하지 않은 내용이 있는 채로 패널을 닫으려 하면 확인 창이 나타나요.

## Opportunity-First 생성

Opportunity-First 생성은 연락처 정보가 없어도 딜을 먼저 등록할 수 있게 해 줘요. 초기 단계의 기회, 문의로 들어온 건, 회사 단위 딜을 등록할 때 유용해요. 기본으로 필수인 항목은 세 가지예요.

- **기회명**: 딜을 구분하는 이름이에요.
- **파이프라인**: 기회가 속할 위치를 정해요.
- **단계**: 기회가 현재 어디까지 진행됐는지 나타내요.

관리자는 다른 필드를 추가로 필수로 지정할 수 있어요. 하지만 이 세 가지 필드는 고정되어 있어서 제거할 수 없어요.

## 연락처 선택과 폼 안에서 연락처 만들기

기회 추가 패널에서 연락처를 바로 선택하거나 만들 수 있어요. 화면을 오가지 않아도 돼요.

- 기존 연락처 선택: 이미 있는 연락처를 검색해서 선택해요.
- 연락처 만들기: 이름을 입력하고 **Create Contact**(연락처 생성)를 선택해요.
- **연락처 세부정보**: 연락처를 선택하면 **기본 이메일**, **기본 전화번호**, **사업자명**, **태그**를 입력할 수 있어요.
- **기회명**: 연락처를 선택하면 자동으로 채워져요.

{% hint style="warning" %}
**Create Contact**를 선택하면 기회를 저장하지 않아도 연락처가 바로 만들어져요.
{% endhint %}

## 기회 필드 설정

관리자는 기회 추가 폼을 비즈니스 절차에 맞게 바꿔서, 팀이 같은 기준으로 정보를 받도록 할 수 있어요.

**설정 > 오브젝트 > 기회 관리**(Opportunities)**> Customize fields for add Opportunity**(기회 추가용 필드 사용자 지정)로 이동하세요.

설정할 수 있는 항목은 다음과 같아요.

- 필드 순서 바꾸기: 필드를 끌어서 원하는 순서로 옮겨요.
- 필수 필드 지정: 다른 필드를 필수로 표시해요.
- 필드 제거: 필요 없는 필드를 폼에서 숨겨요.
- **필드 관리**: 기본 기회 필드, **커스텀 필드**, 주 연락처 필드를 폴더별로 정리된 목록에서 골라 추가해요.

**기회명**, **파이프라인**, **단계**는 제거할 수 없어요. 자세한 내용은 [기회에서 커스텀 필드 사용하기](../05-기회-파이프라인/how-to-use-custom-fields-for-opportunities.md)를 참고하세요.

## 기회 연결

연결은 기회를 관련 CRM 레코드와 이어 주는 기능이에요. 관리자는 **연결 추가**로 기회를 만들 때 사용자가 어떤 관계를 지정할 수 있는지 고를 수 있어요.

지원하는 연결은 다음과 같아요.

- **주 연락처**와 **추가 연락처**
- 사용자 지정 연락처 라벨
- **회사**와 **주 회사**
- **사용자 지정 개체**

자세한 내용은 [기회, 회사, 사용자 지정 개체 간의 연결](../36-기타/리커버리/associations-between-opportunities-companies-custom-objects.md)을 참고하세요.

## 저장 옵션과 저장되지 않은 변경사항 보호

사이드 패널은 기회를 하나씩 만들 때와 연달아 만들 때 모두 쓸 수 있도록 저장 방식을 나눠 두었어요.

- **저장**: 지금 입력한 기회를 만들어요.
- **저장 후 추가**: 기회를 저장한 뒤 바로 다른 기회를 만들 수 있게 해요.
- **저장되지 않은 변경사항**: 저장하지 않은 내용이 있는 채로 패널을 닫으려 하면 **Discard**(버리기), **계속 편집**, **저장** 중에서 고르는 창이 나타나요.

## 사이드 패널로 기회 만들기

기회는 몇 단계만 거치면 만들 수 있어요. 필요하면 연락처와 추가 필드도 함께 입력하세요.

1. **기회 관리**로 이동해 **기회 추가**를 클릭하세요.

   ![기회 추가 사이드 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084021347/original/MLtA1-BJPmdCnN9S45ENYKHdLwv9yflyaA.png?1792737336)
2. **기회명**을 입력하세요.
3. **파이프라인**과 **단계**를 선택하세요.
4. 필요하면 기존 **주 연락처**를 선택하거나 **Create Contact**를 선택하세요.
5. 연락처 세부정보, 필수로 지정된 추가 필드, 연결 항목을 입력하세요.

   ![연락처 세부정보와 추가 필드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084021405/original/hGQKF_TumQE-gFiwRbeGP27tk2TApLgjqw.png?1792737394)
6. **저장** 또는 **저장 후 추가**를 클릭하세요.

## 기회 추가 폼 설정하기

관리자는 폼을 설정해서 필요한 기회 정보만 받고 불필요한 필드는 빼 둘 수 있어요.

1. **설정 > 오브젝트 > 기회 관리 > Customize fields for add Opportunity**를 여세요.
2. 필드를 끌어서 순서를 바꾸세요.
3. 필드를 **필수**로 표시하거나, 필요 없는 필드는 제거하세요.
4. **필드 관리**를 선택해 기회 필드, 커스텀 필드, 주 연락처 필드를 추가하세요.
5. **연결 추가**를 클릭해 연락처, 회사, 사용자 지정 개체와의 관계를 넣으세요.
6. **미리보기**를 클릭해 폼을 확인하세요.
7. **저장**을 클릭해 설정을 적용하세요.

## 자주 묻는 질문

### 연락처 없이 기회를 만들 수 있나요?
네. 기본으로 필수인 항목은 **기회명**, **파이프라인**, **단계**뿐이에요.

### 연락처를 만들었는데 기회를 저장하지 않으면 어떻게 되나요?
**Create Contact**를 선택하는 순간 연락처가 바로 만들어져요. 기회를 저장했는지와는 상관없어요.

### 기본 필수 필드를 제거할 수 있나요?
아니요. **기회명**, **파이프라인**, **단계**는 고정되어 있어요.

### 폼에 커스텀 필드를 추가할 수 있나요?
네. 관리자는 **필드 관리**에서 기회 커스텀 필드를 추가할 수 있어요.

### 폼을 설정하면 기회 카드나 목록 보기도 바뀌나요?
이 설정은 기회 추가 폼에만 적용돼요. 기회 카드와 **목록 보기**는 따로 설정해야 해요.

### 새 사이드 패널이 보이지 않아요.
이 기능은 현재 Opportunity-First 비공개 베타에 포함되어 있어요. 서브 계정에 베타 접근 권한이 있어야 해요.
