# Voice AI 에이전트 버전 관리: 임시 저장 버전 만들기, 테스트, 비교, 게시

Voice AI 에이전트 버전 관리를 쓰면 임시 저장 버전을 만들어 설정 변경을 테스트하고, 버전을 비교한 뒤, 진행 중인 라이브 통화를 방해하지 않고 업데이트를 게시할 수 있어요.

**버전 기록**에서는 이전 설정을 확인하고, 무엇이 바뀌었는지 살펴보고, 필요하면 이전 버전으로 되돌릴 수 있어요. 임시 저장 버전과 라이브 버전이 따로 있어서, 발신자에게는 일관된 경험을 주면서 Voice AI 에이전트를 개선할 수 있어요.

---

## Voice AI 에이전트 버전 관리란?

Voice AI 에이전트 버전 관리는 에이전트의 변경 사항을 관리하는 버전 관리 기능이에요. 라이브 통화에 쓰이는 설정에 바로 영향을 주지 않고 변경할 수 있어요. 사용 중인 버전을 직접 수정하는 대신 임시 저장 버전을 만들어 수정하고, 게시하기 전에 테스트해 볼 수 있어요.

저장된 각 버전은 에이전트 설정 하나를 나타내요. 프롬프트, 음성, 모델, 액션, MCP 연동, **지식 베이스** 연결, 통화 후 설정이 들어갈 수 있어요.

버전 기록에서는 설정을 비교하고, 이전 변경 내용을 살펴보고, 필요할 때 이전 버전으로 되돌릴 수도 있어요.

예를 들어 에이전트의 인사말을 바꾸거나 고객 질문에 답하는 방식을 수정하고 싶다면, 임시 저장 버전에서 변경하고 새 동작을 테스트한 다음 결과가 마음에 들 때만 게시하면 돼요.

{% hint style="warning" %}
에이전트 버전 관리는 **실험실 > Agent Versioning**(에이전트 버전 관리)에서 사용할 수 있어요. 프롬프트 기반의 Standard 및 Realtime Voice AI 에이전트를 지원해요. **Flow-Based Builder**(플로우 기반 빌더)로 만든 에이전트는 지원하지 않아요.
{% endhint %}

## 에이전트 버전 기록 이해하기

버전 기록에서는 에이전트 설정이 시간에 따라 어떻게 달라졌는지 확인할 수 있어요. 저장된 버전마다 식별 정보가 있어서 이전 설정을 살펴보고, 지금 라이브인 버전이 무엇인지 알아보고, 비교하거나 되돌릴 이전 버전을 고를 수 있어요.

**버전 기록** 패널에는 에이전트의 저장된 버전과 현재 임시 저장 버전이 표시돼요.

각 항목에는 다음 정보가 들어갈 수 있어요.

- **Version Number**(버전 번호): v0, v1, v2, v3처럼 번호로 된 식별자예요.
- **작성자**: 해당 버전과 연관된 사용자예요.
- **타임스탬프**: 해당 버전과 연관된 날짜와 시간이에요.
- **Change Tags**(변경 태그): 프롬프트 업데이트처럼 어떤 부분이 바뀌었는지 알려 주는 레이블이에요.
- **라이브** 배지: 지금 라이브 통화를 처리하는 버전을 나타내요.
- **Draft Status**(임시 저장 상태): 아직 게시하지 않은, 편집 가능한 설정을 나타내요.

예를 들어 v1에 라이브 배지가 붙어 있고 v3이 가장 최근에 저장된 버전일 수 있어요. 이때는 더 새로운 번호의 버전이 있어도 v1이 계속 사용 중인 설정이에요.

라이브 버전은 읽기 전용이에요. 수정하려면 임시 저장 버전을 만들어야 해요.

버전 한도: Voice AI 에이전트 하나에 최대 20개까지 버전을 둘 수 있어요. 오래된 버전은 삭제해서 여유 공간을 확보할 수 있어요.

## 임시 저장 버전 만들고 관리하기

임시 저장 버전은 사용 중인 설정을 건드리지 않고 에이전트를 수정할 수 있는 별도 작업 공간이에요. 발신자는 계속 라이브 버전과 통화하는 동안, 프롬프트·음성 설정·액션 등 지원되는 설정을 조정할 수 있어요.

임시 저장 버전은 다음 두 가지에서 만들 수 있어요.

- 라이브 버전: 지금 라이브 통화에 쓰이는 에이전트 설정에서 시작해요.
- 이전 버전: 이전에 저장한 설정을 새 변경의 출발점으로 써요.

Voice AI 에이전트 하나에는 임시 저장 버전을 한 번에 하나만 둘 수 있어요.

임시 저장 버전이 있으면 버전 기록에 따로 표시돼요. 그래서 편집 가능한 설정과 저장된 버전을 구분할 수 있어요.

### 임시 저장 버전과 라이브 버전

두 버전의 차이를 알면 진행 중인 고객 대화에 의도치 않은 변경이 생기는 일을 막을 수 있어요.

| 항목 | 임시 저장 버전 | 라이브 버전 |
| --- | --- | --- |
| 목적 | 변경 사항을 준비하고 테스트 | 라이브 통화 처리 |
| 편집 가능 | 예 | 아니요 |
| 테스트 | 게시 전에 테스트할 수 있어요 | 사용 중인 버전으로 테스트할 수 있어요 |
| 고객 통화 | 라이브 설정을 대체하지 않아요 | 라이브 통화를 처리해요 |
| 게시 | 새 버전으로 게시할 수 있어요 | 변경하려면 새 임시 저장 버전이 필요해요 |

{% hint style="warning" %}
임시 저장 버전을 만든다고 해서 자동으로 라이브가 되지는 않아요. 다른 버전을 게시하거나 라이브로 전환하기 전까지는 기존 라이브 버전이 계속 사용돼요.
{% endhint %}

## 임시 저장 버전과 라이브 버전 테스트하기

테스트를 하면 변경 사항이 고객에게 공개되기 전에 에이전트가 의도대로 동작하는지 확인할 수 있어요. Voice AI 에이전트 버전 관리에서는 지금 라이브 통화를 처리하는 버전과 별개로 임시 저장 설정을 테스트할 수 있어요.

테스트할 때는 선택한 버전과 **Test Audio**(테스트 오디오) 패널에 표시되는 정보를 확인하세요.

- 임시 저장 버전 테스트: 테스트 통화에 임시 저장 설정이 사용돼요. 게시하기 전에 변경 사항을 확인할 수 있어요.
- 라이브 버전 테스트: 테스트 통화에 가장 최근에 저장된 버전이 자동으로 쓰이지 않고 라이브 버전이 사용돼요.

예를 들어 v1이 라이브이고 v3이 가장 최근에 저장된 버전이면, **Test Audio** 패널에 테스트 통화가 v3이 아니라 v1로 실행된다고 표시될 수 있어요.

이 점을 알아 두면 엉뚱한 설정을 테스트하는 실수를 피할 수 있어요.

### 사용할 수 있는 테스트 방법

하이퍼클래스에서는 Voice AI 에이전트를 테스트하는 방법을 두 가지 제공해요.

**웹 통화**

**웹 통화**에서는 브라우저의 마이크로 에이전트와 직접 대화해 볼 수 있어요.

**웹 통화**로 다음을 확인해 보세요.

- 환영 메시지와 인사말
- 프롬프트 지침
- 대화 흐름
- **지식 베이스** 응답
- 지원되는 에이전트 액션

**웹 통화**에서는 **통화 전환**을 테스트할 수 없어요.

**전화 통화**

**전화 통화** 테스트에서는 실제 전화 연결로 에이전트를 확인할 수 있어요.

다음을 검증해야 할 때 **전화 통화**를 쓰세요.

- 전화 기반 대화
- 전화 연결에서의 발신자 경험
- 통화 전환 동작
- 통신 환경에 따라 달라지는 설정

![전화 통화 테스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083777327/original/BjazPgOhEoT8KRdfJRu4GJzJX6tsccu4GQ.png?1792506578)

테스트 요건과 통화 로그가 궁금하다면 [Voice AI 에이전트 테스트 방법](../13-AI-Employee/Voice-AI/how-to-test-voice-ai-agents.md)을 참고하세요.

## 에이전트 버전 비교하기

버전을 비교하면 게시하거나 되돌리기 전에 두 설정 사이에서 무엇이 바뀌었는지 알 수 있어요. 설정을 하나씩 직접 확인하지 않아도, 강조 표시된 차이를 보거나 선택한 버전의 전체 설정을 볼 수 있어요.

**Compare versions**(버전 비교) 화면에는 두 가지 보기가 있어요.

### 변경사항

**변경사항** 보기에서는 선택한 두 에이전트 버전의 차이가 강조 표시돼요.

버전 드롭다운 메뉴에서 비교할 버전을 선택하세요.

시스템 프롬프트가 바뀐 경우에는 이렇게 표시돼요.

- 빨간색 강조: 비교 대상 설정에서 제거된 내용이에요.
- 초록색 강조: 비교 대상 설정에 추가된 내용이에요.
- 변경 횟수: 비교에서 발견된 변경 건수가 표시돼요.

예를 들어 에이전트 시스템 프롬프트의 문장 하나가 수정되면, 제거된 텍스트와 추가된 텍스트가 각각 강조 표시돼요.

이렇게 하면 버전을 라이브로 전환하기 전에 의도하지 않은 프롬프트 변경을 쉽게 찾을 수 있어요.

![변경사항 비교 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083777441/original/mThkM7J98uk5xM0sI8Iotlpnz0XXbRBs4A.png?1792506633)

### Full configuration

**Full configuration**(전체 구성) 보기에서는 선택한 버전에 저장된 설정을 볼 수 있어요.

에이전트 설정에 따라 다음 정보가 포함될 수 있어요.

- 에이전트 이름
- 음성
- AI 모델
- 청구/결제 설정
- 언어
- 시간대
- 시스템 프롬프트
- 지원되는 그 밖의 에이전트 설정과 연동

두 버전의 차이만 보는 게 아니라 이전 버전의 전체 설정을 살펴보고 싶을 때 이 보기를 쓰세요.

![전체 구성 보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083777559/original/oIl-rLtVETX8t0VQPxyHQE_b90VzUw4OyQ.png?1792506673)

## 에이전트 버전 게시하고 복원하기

게시와 복원으로 어떤 설정이 라이브 대화를 처리할지 정할 수 있어요. 게시하면 임시 저장 버전에서 새 설정이 만들어지고, 복원하면 이전에 저장한 버전을 다시 활성화해요.

### 1. 임시 저장 버전 게시하기

수정한 임시 저장 버전을 게시하면 하이퍼클래스가 새 저장 버전을 만들고 그 설정을 라이브로 전환해요.

변경 사항 테스트를 마치고 에이전트가 라이브 통화에서 업데이트된 설정을 쓰게 하고 싶을 때 게시하세요.

게시하기 전에 변경 내용을 검토하고, 테스트 통화에서 임시 저장 버전이 기대한 대로 동작하는지 확인하세요.

### 2. 이전 버전으로 복원하기

복원하면 설정을 일일이 다시 만들지 않고도 지원되는 이전 설정으로 돌아갈 수 있어요.

선택한 버전을 활성화하려면 **라이브로 전환**을 사용하세요. 지원되는 버전만 활성화할 수 있어요.

예를 들어 최근에 게시한 설정이 기대한 결과를 내지 못하면, 버전 기록에서 이전 버전을 선택해 다시 라이브로 전환할 수 있어요.

이전 버전을 라이브로 전환하면 그 버전은 읽기 전용이 돼요. 추가로 변경하려면 그 버전에서 임시 저장 버전을 만드세요.

{% hint style="warning" %}
번호가 가장 높은 버전이 라이브 버전이라는 보장은 없어요. 지금 어떤 설정이 사용 중인지는 **라이브** 배지로 확인하세요.
{% endhint %}

## 버전 한도와 지원 종료 모델 관리하기

버전 한도와 모델 제공 여부에 따라 보관하고 다시 쓸 수 있는 설정이 달라져요. 이런 제한을 알아 두면 버전 기록을 관리하고, 필요할 때 이전 설정을 계속 쓸 수 있어요.

### 1. 버전 한도

Voice AI 에이전트 하나에 최대 **20개 버전**을 보관할 수 있어요.

한도에 도달하면 오래된 버전을 삭제해서 새로 저장할 공간을 만들 수 있어요.

오래된 버전을 주기적으로 검토하고, 비교나 복원에 쓸 만한 설정은 남겨 두세요.

### 2. 지원이 종료된 AI 모델

이전에 저장한 에이전트 버전이 더 이상 지원되지 않는 모델을 쓰고 있을 수 있어요.

모델 지원이 종료되었다면 다음과 같이 처리돼요.

- 원래 저장된 버전은 그대로 유지돼요.
- 지원되는 대체 모델은 편집할 수 있는 임시 저장 버전에서 선택해야 해요.
- 모델은 알림 없이 바뀌지 않아요.
- 대체하려면 사용자의 동의와 게시가 필요해요.

이렇게 해서 기반 AI 모델의 변경이 항상 의도한 변경이 되도록 해요.

{% hint style="info" %}
모델마다 같은 지침에도 다르게 응답할 수 있으니, 게시하기 전에 대체 모델을 테스트해 보세요.
{% endhint %}

## 자주 묻는 질문

### 같은 Voice AI 에이전트에 임시 저장 버전을 여러 개 만들 수 있나요?
아니요. Voice AI 에이전트 하나에는 임시 저장 버전을 한 번에 하나만 둘 수 있어요.

### 라이브 버전을 직접 수정할 수 있나요?
