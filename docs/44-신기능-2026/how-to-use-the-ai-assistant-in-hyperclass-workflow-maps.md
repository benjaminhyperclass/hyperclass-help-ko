# Workflow Maps에서 AI 어시스턴트 사용하기

Workflow Maps(워크플로우 맵)의 AI 어시스턴트에게 말하듯이 요청하면 하이퍼클래스 자동화를 이해하고 정리하고 관리할 수 있어요. 워크플로우에 대해 질문하고, 문제를 조사하고, 연결된 자산을 찾을 수 있어요. 맵 화면에서 바로 워크플로우 생성이나 수정을 요청할 수도 있어요. 어시스턴트는 워크플로우와 맵의 정보를 참고해 답하고, 사용자의 접근 권한을 지켜요.

## AI 어시스턴트의 장점

여러 워크플로우를 일일이 열어 보지 않아도 정보를 찾고 변경을 요청할 수 있어요.

- 워크플로우를 빠르게 이해해요: 워크플로우 하나의 설명이나 폴더 전체의 요약을 받을 수 있어요.
- 문제를 쉽게 파악해요: 워크플로우 문제를 조사하고 연결된 자산을 확인할 수 있어요.
- 워크플로우를 빠르게 찾아요: 말로 요청해서 워크플로우를 찾고, 필터링하고, 강조 표시할 수 있어요.
- 정리가 간편해요: 폴더 만들기, 워크플로우 이동, 이름 변경, 메모 추가를 할 수 있어요.
- AI가 자동화를 도와줘요: 새 워크플로우를 만들거나 기존 워크플로우를 수정해 달라고 요청할 수 있어요.
- 변경 내용을 직접 통제해요: 제안된 작업을 검토하고, 승인이 필요할 때 승인할 수 있어요.

## 워크플로우 이해하고 조사하기

어시스턴트는 워크플로우와 맵의 정보를 바탕으로 자동화에 관한 질문에 답해요. 처음 보는 워크플로우를 파악하거나, 문제를 조사하거나, 연결된 자산을 찾을 때 편리해요.

이런 질문을 할 수 있어요.

- "이 워크플로우가 하는 일을 설명해 줘."
- "영업 폴더에 있는 워크플로우를 요약해 줘."
- "이 워크플로우에 연결된 자산이 뭐야?"
- "이 자동화에서 생긴 문제를 조사하도록 도와줘."

어시스턴트는 확인할 수 있는 정보를 바탕으로 관련 내용을 알려 줘요.

{% hint style="info" %}
문제를 조사한다고 해서 문제가 자동으로 해결되는 것은 아니에요. 워크플로우를 직접 확인하고, 수정한 내용이 맞는지 검증하세요.
{% endhint %}

## 워크플로우 찾고 필터링하기

필터를 여러 번 적용하지 않아도 어시스턴트가 필요한 워크플로우를 찾아 주고 맵에서 그 부분만 보여 줘요. 찾거나 강조하고 싶은 내용을 말로 설명하면 돼요.

요청 예시예요.

- "영업 폴더에서 초안만 보여 줘."
- "환영 이메일 워크플로우를 찾아 줘."
- "온보딩 폴더에 있는 워크플로우를 강조해 줘."
- "게시된 워크플로우를 보여 줘."

{% hint style="warning" %}
저장된 보기에는 필터가 저장되지만, 맵의 확대/축소 상태, 위치, 레이아웃은 저장되지 않아요.
{% endhint %}

## 워크플로우와 폴더 정리하기

대화하듯 요청해서 워크플로우를 정리할 수 있어요. 폴더 만들기, 워크플로우 이동, 이름 변경, 메모 추가를 요청해 자동화 환경을 깔끔하게 유지하세요.

요청 예시예요.

- "온보딩이라는 폴더를 만들어 줘."
- "이 워크플로우들을 온보딩 폴더로 옮겨 줘."
- "이 워크플로우 이름을 '신규 리드 후속 안내'로 바꿔 줘."
- "이 워크플로우를 설명하는 메모를 추가해 줘."

승인이 필요한 경우에는 정리 작업을 적용하기 전에 제안된 변경 내용을 검토하세요.

## 워크플로우 만들고 수정하기

원하는 자동화나 기존 워크플로우에서 바꾸고 싶은 내용을 말로 설명하면 어시스턴트가 워크플로우를 만들거나 수정해 줘요.

요청 예시예요.

- "환영 이메일과 SMS를 보내는 워크플로우를 만들어 줘."
- "신규 리드 후속 안내 자동화를 만들어 줘."
- "이 워크플로우에 SMS 후속 안내를 추가해 줘."

지원되는 워크플로우 생성과 수정은 백그라운드 작업으로 실행돼요. 제안된 변경 내용을 검토하고, 완성된 워크플로우가 의도한 자동화와 맞는지 확인하세요.

{% hint style="info" %}
어시스턴트가 모든 워크플로우 수정을 지원하는 것은 아니에요. 사용할 수 있는 작업은 어시스턴트가 지원하는 기능에 따라 달라요.
{% endhint %}

## 어시스턴트 작업 검토하고 승인하기

승인 기능으로 어시스턴트를 통해 요청한 변경을 관리할 수 있어요. 제안된 작업을 검토하면 의도한 워크플로우, 폴더, 설정에 변경이 적용되는지 확인할 수 있어요.

어시스턴트는 조건에 맞는 작업에 대해 자동 승인을 지원해요. 하지만 자동 승인을 켜 두어도 항상 확인을 거쳐야 하는 변경이 있어요.

- 항목 삭제
- 워크플로우 맵 전체 재배치

어시스턴트는 기존 계정 권한도 그대로 따르기 때문에, 제한된 작업을 우회할 수 없어요.

## 사용 방법

어시스턴트는 Workflow Maps 안에서 바로 쓸 수 있어요. 다음 순서로 질문하거나, 자동화를 조사하거나, 지원되는 변경을 요청하세요.

1. **자동화 > 워크플로우 > Workflow Maps**(워크플로우 맵)로 이동해요.

   ![자동화 > 워크플로우 > Workflow Maps 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084395896/original/lVhYIfYqhWxzxdY_zAYHIwEm5D62d4xC6A.png?1793185390)
2. Workflow Maps 화면에서 **어시스턴트**를 클릭해요.

   ![어시스턴트 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084400785/original/hpaVzI_7xpdDQwZEKst1Tp_eVZRW7lSD_g.png?1793187643)
3. 질문을 입력하거나 원하는 작업을 설명해요. 예를 들어 "이 워크플로우가 하는 일을 설명해 줘" 또는 "환영 이메일과 SMS를 보내는 워크플로우를 만들어 줘"라고 입력해요.

   ![어시스턴트에 요청 입력하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084400957/original/_uGAcv2MKN4QNXKZTSJbvdDuhx648ft2BQ.png?1793187734)
4. 응답을 확인해요. 어시스턴트가 워크플로우를 설명하거나, 관련 자동화를 찾거나, 맵을 필터링하거나, 변경을 제안할 수 있어요.

   ![어시스턴트 응답 확인하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084401091/original/fj8PWCZxTihrFPZB8B-oFbF6m3hR9r5ZdA.png?1793187779)
5. 승인이 필요하면 제안된 작업을 검토하고, 변경을 적용하기 전에 화면에 나온 승인 버튼을 사용해요.
6. 변경된 워크플로우나 맵을 확인해서 요청한 내용과 맞는지 검증해요.

   ![변경 결과 확인하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084401236/original/zcWtUyTRtvmbKxO1RdeslyXy-K8UsbD4NQ.png?1793187841)

## 자주 묻는 질문

### 어시스턴트는 모든 서브 계정에서 작동하나요?
어시스턴트는 지금 작업 중인 서브 계정 안에서 확인할 수 있는 워크플로우와 맵 정보를 사용해요.

### 어시스턴트가 내 계정 권한을 우회할 수 있나요?
아니요. 어시스턴트는 기존 접근 권한 안에서만 작동해요.

### 어시스턴트가 워크플로우 오류를 자동으로 고쳐 주나요?
어시스턴트는 문제를 조사하고 지원되는 수정을 요청하는 데 도움을 줄 수 있어요. 하지만 문제 해결이 자동으로 이루어진다고 보장하지는 않아요.

### 자동 승인은 모든 작업에 적용되나요?
아니요. 삭제와 맵 전체 재배치는 항상 확인을 거쳐야 해요.

### 워크플로우를 직접 관리할 수도 있나요?
네. 기존 Workflow Maps의 이동, 필터링, 워크플로우 관리 기능을 그대로 쓸 수 있어요.

### 워크플로우 생성과 수정이 바로 완료되나요?
지원되는 생성과 수정은 백그라운드 작업으로 실행돼요. 작업이 끝나면 만들어진 자동화를 확인하세요.
