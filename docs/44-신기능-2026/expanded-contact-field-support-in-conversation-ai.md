# 대화 AI에서 더 많은 연락처 필드 유형 지원

하이퍼클래스 **대화 AI**(Conversation AI)의 **연락처 정보 추가** 액션이 이제 **라디오 선택**, **Checkbox**(체크박스), 단일 선택·다중 선택 **Dropdown**(드롭다운), **Phone**(전화) 같은 커스텀 필드 유형을 지원해요. 표준 필드인 **연락처 출처**와 **연락처 유형**도 업데이트할 수 있어요. 고객이 선택지와 똑같이 말하지 않아도 대화 AI가 의미를 알아듣고, 여러 개를 고른 경우에도 맞는 값을 찾아 연락처 레코드에 저장해요. 고객의 선호 사항이나 리드 확인에 필요한 정보를 자동으로 모을 때 쓰세요.

## 연락처 필드 지원 확대란?

Auto-Pilot 모드로 운영하는 프롬프트 기반 대화 AI 에이전트가 기존 **연락처 정보 추가** 액션으로 더 다양한 유형의 필드에 고객 정보를 모을 수 있게 됐어요. 자세한 내용은 [대화 AI의 Auto-Pilot 모드](../13-AI-Employee/auto-pilot-mode-in-conversation-ai-for-efficient-communication.md)를 참고하세요.

미리 정해 둔 선택지가 있는 필드에서는 에이전트가 고객의 답을 해석해 맞는 값을 저장해요. 고객은 선택지 이름을 그대로 말하지 않고 자연스럽게 답하면 돼요.

## 지원하는 연락처 필드 유형

연락처 필드는 유형에 따라 고객 정보를 모으고 정리하는 방식이 달라요. 단일 선택 필드는 하나만 저장하고, 다중 선택 필드는 여러 개를 저장할 수 있어요. 대화 AI는 텍스트, 숫자, 날짜, 시간, 전화번호 필드도 지원해요. 커스텀 필드에 대한 자세한 내용은 [커스텀 필드 만들고 사용하기](../23-레거시-자동화/Logic-and-Fulfillment/how-to-use-custom-fields.md)를 참고하세요.

### 지원하는 커스텀 필드 유형

| 필드 유형 | 설명 | 예시 |
| --- | --- | --- |
| **라디오 선택** | 미리 정해 둔 목록에서 맞는 선택지 하나를 저장해요. | 여행 등급: 비즈니스 |
| **Checkbox**(체크박스) | 맞는 선택지를 하나 또는 여러 개 저장해요. | 식단 선호: 채식, 글루텐프리 |
| **Dropdown (single)**(드롭다운 단일 선택) | 드롭다운 목록에서 맞는 선택지 하나를 저장해요. | 선호 색상: 파란색 |
| **Dropdown (multiple)**(드롭다운 다중 선택) | 드롭다운 목록에서 맞는 선택지를 여러 개 저장해요. | 관심 서비스: 컨설팅, 교육 |
| **Phone**(전화) | 지원하는 커스텀 전화 필드에 전화번호 정보를 저장해요. | 보조 연락처 번호 |

### 지원하는 표준 연락처 필드

대화 AI는 **연락처 정보 추가** 액션으로 아래 표준 연락처 필드도 업데이트할 수 있어요.

- **연락처 출처**: 연락처가 어디에서 들어왔는지 기록해요.
- **연락처 유형**: 연락처의 유형이나 분류를 기록해요.

## 대화 AI가 고객 답변을 필드 선택지에 맞추는 방법

대화 AI는 고객의 답변을 알아보고 연락처 필드의 선택지와 맞춰 봐요. 고객이 선택지와 똑같은 표현을 쓰지 않아도 돼요. 필드 유형에 따라 에이전트가 값을 하나만 저장하기도 하고 여러 개 저장하기도 해요.

| 필드 유형 | 동작 방식 | 고객 답변 예시 | 저장되는 값 |
| --- | --- | --- | --- |
| **라디오 선택** | 답변을 선택지 하나와 맞춰요. | "비즈니스 클래스로 부탁해요" | 비즈니스 |
| **Checkbox** | 맞는 선택지를 여러 개 알아보고 저장해요. | "저는 채식하고 글루텐도 못 먹어요" | 채식, 글루텐프리 |
| **Dropdown (single)** | 답변을 드롭다운 목록의 선택지 하나와 맞춰요. | "파란색으로 할게요" | 파란색 |
| **Dropdown (multiple)** | 맞는 드롭다운 선택지를 여러 개 알아보고 저장해요. | "컨설팅이랑 교육에 관심 있어요" | 컨설팅, 교육 |
| **Phone** | 고객의 전화번호를 커스텀 전화 필드에 저장해요. | "보조 번호는 415-555-0123이에요" | 415-555-0123 |

{% hint style="info" %}
대화 AI는 미리 정해 둔 선택지가 있는 필드에서만 일치하는 값을 저장해요. 사용자 지정 값을 허용하도록 설정한 필드는 추가 입력도 받을 수 있어요. **설정 > 커스텀 필드**에서 선택지를 바꾸면, 바로 다음 고객 메시지부터 바뀐 목록이 적용돼요.
{% endhint %}

## 연락처 정보 추가 액션 설정하기

**연락처 정보 추가** 액션을 설정하면 대화 AI가 고객 정보를 모아 알맞은 연락처 필드에 저장해요. 필드를 정확히 고르고 프롬프트에 지시를 분명하게 적어 두면 에이전트가 고객 답변을 더 정확하게 저장해요.

1. **AI 에이전트 > 대화 AI > Agents List**(에이전트 목록)로 이동해 프롬프트 기반 에이전트를 열어요.
2. **Bot Goals**(봇 목표) > **액션 설정**에서 **연락처 정보**를 선택해요.

   ![액션 설정에서 연락처 정보 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083907279/original/1TTLGzsa60XJDKT3G5dieMp0hN1GLm5ctw.png?1792614552)
3. **Action name**(액션 이름)을 입력하고 **업데이트할 연락처 필드**를 선택해요.
4. 미리 정해 둔 선택지가 있는 필드라면 **Values the Conversation AI can update**(대화 AI가 업데이트할 수 있는 값)에서 선택지를 확인해요.

   ![대화 AI가 업데이트할 수 있는 값 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083907200/original/bPViVCkrow2uXnunniFZYNLzf9SfL7YBUQ.png?1792614361)
5. 다른 정보도 모으려면 **새 필드 추가**를 선택해 필드를 더 설정한 뒤 **저장**을 클릭해요.
6. 모으려는 정보를 고객에게 물어보도록 에이전트의 프롬프트에 지시를 추가해요.
7. 에이전트를 테스트해서 고객 답변이 연락처 레코드의 알맞은 필드에 저장되는지 확인해요.

   ![연락처 레코드에 저장된 답변 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083907220/original/BUNHfEqBL0rHUtAYLg-wQl2bJSccgQ6CXg.png?1792614417)

{% hint style="warning" %}
**연락처 정보** 액션을 추가해도 에이전트가 해당 질문을 자동으로 하지는 않아요. 필요한 정보를 모으도록 에이전트의 프롬프트에 분명한 지시를 넣어 주세요.
더 자세한 안내는 [대화 AI에서 봇 목표 설정하기](../13-AI-Employee/how-to-configure-bot-goals-in-conversation-ai.md)를 참고하세요.
{% endhint %}

## 자주 묻는 질문

### 고객이 한 번 답한 내용에서 값을 여러 개 저장할 수 있나요?
네. **Checkbox**와 다중 선택 **Dropdown** 필드는 여러 개를 선택할 수 있어요. 예를 들어 고객이 "저는 채식하고 글루텐도 못 먹어요"라고 답했을 때 두 선택지가 모두 있으면, 대화 AI가 채식과 글루텐프리를 함께 저장해요.

### 고객의 답변이 선택지와 맞지 않으면 어떻게 되나요?
미리 정해 둔 선택지만 허용하는 필드라면, 어느 선택지와도 맞지 않는 값은 저장하지 않아요. 사용자 지정 선택지를 허용하는 필드라면 에이전트가 추가 값을 저장할 수 있어요.

### 연락처 필드에 이미 저장된 정보를 대화 AI가 바꿀 수 있나요?
아니요. **연락처 정보 추가** 액션은 비어 있는 필드만 업데이트해요. 기존 연락처 정보를 덮어쓰지 않아요.

### 고객의 답변이 연락처 레코드에 저장되지 않았어요. 왜 그런가요?
다음과 같은 경우에 답변이 저장되지 않을 수 있어요.

- 필드에 이미 값이 들어 있어요.
- 답변이 선택지와 맞지 않아요.
- 액션에서 잘못된 필드를 골랐어요.

또한 에이전트의 프롬프트에 해당 정보를 모으라는 지시가 들어 있는지, 그리고 Auto-Pilot 모드의 프롬프트 기반 에이전트를 쓰고 있는지도 확인해 보세요.
