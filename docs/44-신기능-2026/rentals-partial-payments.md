# 대여 부분 결제

대여 예약 때 예치금만 먼저 받고, 나머지 잔금은 대여 시작일 전에 받을 수 있어요. 차량, 휴양 숙소, 장비처럼 금액이 큰 대여에 특히 유용해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 부분 결제란?

부분 결제를 켜면 고객은 대여 요금을 두 번에 나눠 내요. 예약할 때 예치금을 내고, 대여가 시작되기 전에 잔금을 내요. 잔금은 자동으로 결제되게 할 수도 있어요. 예약 시점에 내야 할 금액이 줄어들기 때문에, 금액이 커서 결제 단계에서 포기하던 고객도 예약으로 이어질 수 있어요.

부분 결제를 켜면 예약마다 두 번에 나눠 내는 결제 일정이 담긴 인보이스가 만들어져요. 예치금은 바로 결제돼요. 자동 결제를 켜 두면 하이퍼클래스가 설정한 마감일에, 예약할 때 저장된 카드로 잔금 결제를 시도해요.

{% hint style="info" %}
부분 결제를 쓰려면 **예약 시 결제 필수**가 켜져 있어야 해요. 이 설정이 꺼져 있으면 분할 결제 일정을 만들 수 없어요. 결제 없이 예약이 확정되고, 결제는 직접 받아야 해요.
{% endhint %}

---

## 부분 결제의 장점

결제 일정을 나눌 수 있으면 금액이 큰 예약도 쉽게 잡을 수 있어요. 결제 시점과 남은 금액도 한눈에 파악할 수 있어요.

- 선결제 부담 감소: 고객이 대여 전체 금액 대신 정해진 예치금만 내고 대여를 확보할 수 있어요.
- 명확한 결제 금액: 고객은 오늘 낼 금액과 나머지 결제일을 확인할 수 있어요.
- 선택형 자동 결제: 잔금을 마감일에 자동으로 결제하도록 설정할 수 있어요.
- 결제 현황 확인: 예약 세부 정보에서 결제 일정별 금액, 마감일, 상태를 볼 수 있어요.
- 보증금 시점 선택: 조건이 맞으면 보증금을 예약 예치금과 함께 받을지, 잔금과 함께 받을지 고를 수 있어요.

## 작동 방식

결제 일정은 예약 예치금과 남은 대여 잔금으로 나뉘어요. 각 결제가 언제 만들어지고 언제 마감되는지 알아 두면 고객이 낼 금액을 쉽게 예상할 수 있어요.

### 결제 일정

부분 결제가 켜진 상태에서 고객이 예약하면 결제 일정이 2개인 인보이스가 만들어져요.

- 일정 1 — 예치금: 결제할 때 바로 내요. 금액은 예치금 비율 × 대여 총액이에요.
- 일정 2 — 잔금: 설정한 마감일에 내요. 금액은 남은 대여 총액이에요.

{% hint style="info" %}
보증금은 설정에 따라 예치금과 함께 내거나 잔금과 함께 낼 수 있어요.
{% endhint %}

### 마감 임박 예약은 한 번에 결제

설정한 기준 기간 안에 예약하면 두 번으로 나누지 않고, 결제 시점에 전체 금액을 한 번에 내요.

예약 시점에 이미 잔금 마감일이 지났을 때도 마찬가지로 한 번에 결제해요.

**예시**

잔금을 대여 시작일 7일 전에 받도록 설정했는데 대여 시작일 2일 전에 예약했다면, 결제가 두 번으로 나뉘지 않아요.

### 결제 수단

마감일 자동 결제를 쓰려면 예약할 때 카드가 저장되어 있어야 해요. 현금과 오프라인 결제는 자동 결제할 수 없어요. 아래 [카드 외 결제](#카드-외-결제)를 참고하세요.

{% hint style="info" %}
ACH 계좌이체는 곧 지원될 예정이에요.
{% endhint %}

## 사전 준비

분할 결제 일정을 만들려면 먼저 결제 수집 설정이 되어 있어야 해요. 부분 결제를 켜기 전에 예약 시 결제 설정과 사용 가능한 결제 수단을 확인하세요.

부분 결제를 켜기 전에 다음을 확인하세요.

- **예약 시 결제 필수**가 켜져 있어요. 이 설정이 꺼져 있으면 부분 결제를 쓸 수 없어요. 토글도 나타나지 않아요.
- 카드 또는 ACH 결제 수단을 쓸 수 있어요.마감일 자동 결제는 고객이 결제할 때 카드를 저장한 경우에만 작동해요. 현금만 받는 위치라면 부분 결제를 켜도 잔금이 자동으로 결제되지 않아요.

{% hint style="info" %}
부분 결제를 켜면 자동 결제가 불가능하므로 결제 화면에서 다른 결제 수단은 쓸 수 없어요.
{% endhint %}

## 설정하기

글로벌 결제 설정에서 예치금 비율과 잔금 마감일(대여 며칠 전인지)을 정해요. 이 값은 모든 리스팅의 새 예약에 적용되므로 신중하게 확인하세요.

부분 결제 설정은 모두 **캘린더 > 캘린더 설정 > 대여 > 글로벌 설정 > 결제 설정**에 있어요.

### 1단계 — 부분 결제 켜기

1. **글로벌 설정 > 결제 설정**으로 이동하세요.
2. **예약 시 결제 필수**가 켜져 있는지 확인하세요.
3. **Partial payments**(부분 결제) 토글을 켜세요.

![대여 글로벌 설정의 결제 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084318881/original/dXJchNu_y7mSxlTSgIGOkH75QKToFuQAOg.png?1793109603)

### 2단계 — 결제 일정 설정하기

| 설정 | 기능 |
| --- | --- |
| 예치금 | 예약할 때 결제하는 금액이에요. 예약 총액(해당하는 세금과 수수료 포함, 환불 가능한 보증금 제외)의 1~99%로 정해요. |
| **Balance due**(잔금 마감일) | 남은 잔금을 언제까지 내야 하는지 정해요. |
| **Auto-collect balance on due date**(마감일에 잔금 자동 결제) | 잔금 마감일에 저장된 카드로 자동 결제해요. 켜져 있으면 결제 화면에 카드 결제 수단만 나타나요. |

{% hint style="info" %}
자동 결제 시간: 예약된 분할 결제는 마감일 오전 11:00(ET) / 오전 10:00(CT) / 오전 9:00(MT) / 오전 8:00(PT)에 결제돼요.
{% endhint %}

### 3단계 — 보증금 결제 시점 정하기(해당하는 경우)

이 옵션은 **예약 시 결제 필수**가 켜져 있고, **보증금**이 켜져 있고, **선결제 수금**이 선택되어 있고, 부분 결제도 켜져 있을 때만 나타나요.

- **With the booking deposit**(예약 예치금과 함께): 보증금을 예약할 때 예치금과 함께 받아요. 고가 자산을 일찍 확실하게 보호하고 싶을 때 선택하세요.
- **With the balance payment**(잔금과 함께): 보증금을 잔금과 함께 받아요. 예약할 때 낼 금액을 최소로 줄일 수 있어요.

{% hint style="info" %}
새 예약에만 적용돼요. 글로벌 결제 플랜을 저장하거나 바꿔도 기존 예약은 다시 계산되지 않아요. 기존 예약은 만들어질 때 정해진 일정을 그대로 유지해요.
{% endhint %}

## 보증금과 부분 결제

환불 가능한 보증금은 대여 예치금 비율과 별개예요. 보증금을 언제 받을지에 따라 고객이 오늘 낼 금액과 나중에 낼 금액이 달라져요.

**보증금**이 **선결제 수금**으로 설정되어 있고 부분 결제가 켜져 있으면, 보증금은 항상 전체 금액을 한 번에 받아요. 결제 일정에 맞춰 나누어 받지 않아요.

### 보증금 결제 시점 옵션

| 옵션 | 보증금을 받는 시점 | **오늘 마감** (예: 대여료 $1,200, 보증금 $300, 예치금 25%) |
| --- | --- | --- |
| **With the balance payment** | 대여 시작 전, 잔금과 함께 | $300 *(예치금만)* |
| **With the booking deposit** | 예약할 때, 첫 번째 결제와 함께 | $600 *(예치금 + 보증금)* |

### Card on File 모드

보증금을 **Card on File**(카드 저장)로 설정하면, 나중에 따로 결제하기 전까지 보증금은 결제 금액에 포함되지 않아요. 이때 부분 결제는 대여 총액에만 정상적으로 적용돼요. 예약할 때 저장된 카드는 잔금 자동 결제에도 쓰이고, 보증금용 저장 카드로도 쓰여요.

## 고객에게 보이는 결제 화면

주문 요약에는 고객이 대여를 확정하기 전에 앞으로 결제할 금액이 표시돼요. 표시되는 금액에는 선택한 예약 예치금, 잔금 마감일, 보증금 결제 시점이 반영돼요.

예약 페이지의 결제 요약은 설정에 따라 자동으로 바뀌어요. 고객에게는 항상 다음이 보여요.

- **오늘 마감**: 예약하면서 바로 내는 예치금
- **Upcoming payment**(예정된 결제): 잔금 금액과 마감일

![고객 주문 요약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084319012/original/qOm32yPg1dRJ0SFM49ceDpLox64iM8nBzg.png?1793109652)

### 마감 임박 예약일 때

분할 결제 일정 대신 전체 금액을 한 번에 결제해요.

### 예약 시 결제 필수가 꺼져 있을 때

결제가 수집되지 않아요.

## 결제 내역 확인하고 관리하기

예약의 결제 요약에는 결제 일정이 나뉘어 표시돼요. 이미 결제된 금액과 아직 처리해야 하는 금액을 구분해서 볼 수 있어요. 직접 결제를 받기 전에 예약 화면에서 마감일과 상태를 확인하세요.

1. **캘린더 > 예약 목록 보기**를 열고 **대여**를 선택한 다음, 예약을 여세요.
2. 결제 요약에서 결제 일정별 **금액**, **마감일**, **상태**를 확인하세요. 예를 들어 **Payment 1 of 2 · Paid**, **Payment 2 of 2 · Pending**으로 표시돼요.
3. 남은 결제를 미리 받거나 자동 결제할 카드가 없을 때는 예약 사이드바에서 **작업 > 결제 수집**을 선택하세요.
4. 예정된 결제 하나, 또는 남은 결제 여러 개를 골라 함께 받을 수 있어요. 예정된 결제는 예정 금액 전체가 수집돼요.
5. 결제 요약으로 돌아가 바뀐 상태를 확인하세요.

![예약의 결제 요약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084319122/original/o6Vzzp807osz_fC236qjGY7gYAE99QaujQ.png?1793109710)

## 결제 실패

예약은 성공했어도 예정된 결제가 실패하면 잔금이 남을 수 있어요. 결제 상태와 인보이스 알림 설정을 확인해서 적절히 후속 조치를 하세요.

예정된 분할 결제의 실패 처리는 인보이스에서 기본으로 관리해요. 추가 설정은 필요 없어요.

### 잔금 결제가 실패하면

1. 마감일에 저장된 카드로 결제를 시도해요.
2. 실패하면 24시간 간격으로 최대 3번까지 자동으로 다시 시도해요.
3. 모든 재시도가 실패하면 직접 결제를 받아야 해요.

{% hint style="info" %}
미리 알림 이메일과 결제 실패 이메일 템플릿은 인보이스 설정(**결제 > 인보이스 & 견적서 > 설정 > 알림**)에서 설정하세요. 이 템플릿으로 각 분할 결제 전에 보내는 미리 알림과 결제 실패 후 보내는 이메일을 관리해요. 예약 시스템이 이 템플릿을 덮어쓰지 않아요.
{% endhint %}

{% hint style="info" %}
결제가 실패해도 예약은 자동으로 취소되지 않아요. 취소는 항상 운영자가 직접 해야 해요.
{% endhint %}

## 예약 변경과 추가 요금

날짜나 가격을 바꾸면 앞으로 낼 금액이 달라질 수 있어요. 변경할 때마다 결제 일정을 확인해서 요금과 마감일이 대여 내용과 맞는지 점검하세요.

예약을 수정하면 수정한 시점을 기준으로 결제 일정이 다시 계산돼요.

대여 날짜 변경: 대여 시작일을 바꾸면 남은 잔금의 마감일도 새 시작일에 맞춰 이동해요. 설정한 '대여 며칠 전' 기준이 그대로 적용돼요.

{% hint style="info" %}
자동 결제가 켜져 있었다면, 예약을 수정할 때 해당 예약의 자동 결제는 꺼져요.
{% endhint %}

### 예치금 결제 전

새 총액으로 인보이스가 업데이트되고, 설정된 비율에 따라 결제 일정이 새로 계산돼요.

### 예치금 결제 후, 잔금 마감 전

- 총액이 늘어나면 두 번째 결제의 잔금이 늘어나요.
- 총액이 줄어들면 잔금이 줄어들어요. (잔금은 이미 결제된 금액보다 낮아질 수 없어요.)

### 모든 결제가 끝난 후

- 총액이 늘어나면 예약에 **Additional charges**(추가 요금) 행이 추가돼요. 인보이스에서는 내부적으로 결제 일정 행이 하나 더 만들어져요.
- 전액 결제 후에 리스팅을 더 추가하거나 예약을 계속 수정하면, **Additional charges** 행은 새 총액에 맞춰 업데이트돼요. 인보이스에는 그때마다 새 결제 일정 행이 추가돼요.

![전액 결제 후 금액이 늘어 추가 요금 행과 대기 상태가 생긴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084319276/original/S6pd0SOBoBc9GW27dCLaOBwdbLz-HP0gLQ.png?1793109771)

{% hint style="info" %}
인보이스가 전액 결제된 후 예약 총액이 바뀌어도 자동으로 환불되지 않아요. 환불은 운영자가 **예약 세부 정보**에서 직접 진행해야 해요.
{% endhint %}

## 카드 외 결제

나중에 자동으로 결제하려면, 고객에게 나중에 결제할 수 있는 결제 수단이 필요해요. 예약된 자동 결제에 의존하기 전에 결제 화면의 결제 옵션을 확인하세요.

마감일 자동 결제는 연락처에 저장된 카드가 있어야 해요. 현금과 기타 오프라인 결제 수단은 나중의 자동 결제용으로 저장할 수 없어요.

부분 결제를 켜면 다른 결제 수단은 모두 비활성화돼요.

{% hint style="info" %}
**예약 시 결제 필수**가 꺼져 있으면 결제 수단과 관계없이 모든 결제를 직접 받아요. 이 모드에서는 부분 결제를 쓸 수 없어요.
{% endhint %}

## 자주 묻는 질문

### 리스팅마다 다른 결제 플랜을 설정할 수 있나요?

아니요. **글로벌 설정**에서 정한 값이 모든 리스팅의 기본값으로 적용돼요.

### 고객이 예치금을 낸 뒤 잔금 마감일 전에 예약을 취소하면 어떻게 되나요?

결제되지 않은 잔금 행은 즉시 무효 처리되고 결제되지 않아요. 예치금 환불은 취소 정책에 따라요. 보증금을 선결제로 받았다면, 대여 시작 전 취소 시 취소 정책과 관계없이 항상 전액 환불돼요.

### 고객이 잔금을 미리 낼 수 있나요?

네. 고객이 인보이스에서 **Pay Now**(지금 결제)를 눌러 마감일 전에 언제든 잔금을 낼 수 있어요. 사용자나 관리자가 예약 화면에서 미리 결제를 받을 수도 있어요.

### 예약이 이미 들어온 뒤에 예치금 비율을 바꾸면 어떻게 되나요?

**글로벌 설정**의 변경 내용은 새 예약에만 적용돼요. 기존 예약은 예약할 때 만들어진 일정을 그대로 유지해요.

### 고객이 전액 결제한 뒤 추가 요금을 붙이면 어떻게 되나요?

추가 금액에 해당하는 행이 예약과 인보이스에 새로 만들어져요. 원래 결제 일정은 바뀌지 않아요. 추가 요금을 받으려면 **예약 세부 정보**에서 결제 요청을 보내세요.

### 마감일 자동 결제는 몇 시에 실행되나요?

설정한 마감일 오전 11:00(ET) / 오전 10:00(CT) / 오전 9:00(MT) / 오전 8:00(PT)에 실행돼요.

### 부분 결제를 켜면 원하는 금액만큼 결제를 받을 수 있나요?

아니요. 부분 결제가 켜져 있으면 설정된 일정 금액만 전액으로 받을 수 있어요. 예를 들어 25%, 75%, 또는 두 일정을 합친 금액이에요.

### 대여 시작일을 바꾸면 잔금 마감일도 바뀌나요?

네. 설정한 '대여 며칠 전' 기준에 따라 새 시작일에 맞춰 잔금 마감일이 조정돼요.
