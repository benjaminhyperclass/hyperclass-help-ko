# 폼·설문·퀴즈의 오류 수정과 추천 사항 사용 가이드

폼, 설문, 퀴즈를 저장할 때 설정 실수가 어디에 있는지 찾기 어려울 때가 있어요. 하이퍼클래스의 추천 사항 및 오류 감지(Recommendations & Error Detection) 기능은 기존 유효성 검사 오류를 찾아 해당 요소로 바로 안내해 줘요. 자주 놓치는 설정을 알려 주는 선택형 추천과, 주요 설정을 한눈에 보여 주는 **인사이트**도 함께 제공해요. 이 문서를 보고 오류를 고치고, 추천 내용을 살펴보고, 공유하기 전에 설정을 점검해 보세요.

## 추천 사항 및 오류 감지란?

추천 사항 및 오류 감지는 빌더에서 설정 오류를 찾고, 개선 제안을 확인하고, 폼·설문·퀴즈가 어떻게 설정되어 있는지 파악하도록 돕는 기능이에요.

이 기능은 세 가지로 구성돼요.

- **오류 감지(Error Detection):** 저장하려고 할 때 기존 유효성 검사 오류를 찾아 줘요. 오류마다 문제가 있는 요소와, 그 요소를 찾아 해결할 수 있는 이동 링크가 함께 나와요.
- **추천 사항:** 선택적으로 개선할 만한 부분을 알려 줘요. 예를 들면 자리 표시용 URL 교체, 기본 필드 이름 변경, 결제 테스트 모드 확인, 봇 방지 켜기 같은 것들이에요.
- **인사이트:** 조건부 로직, 커스텀 필드, 결제 모드, 이메일 알림, 자동 응답 상태 같은 주요 설정을 보여 줘요.

유효성 검사 오류를 고치면 하이퍼클래스가 오류 목록에서 자동으로 해결 처리해요. 남은 문제를 하나하나 직접 확인하지 않아도 돼요.

## 이 기능을 쓰면 좋은 점

폼, 설문, 퀴즈를 공유하기 전에 설정 문제를 미리 찾으면, 필드 이름을 명확하게 유지하고 중요한 설정을 점검할 수 있어요. 모든 요소를 일일이 뒤져 보지 않아도 되고요.

- **오류를 빠르게 찾아요:** 빌더 전체를 뒤지지 않아도 어떤 필드나 요소에 오류가 있는지 바로 볼 수 있어요.
- **문제 해결이 쉬워요:** 오류를 선택하면 해당 요소로 바로 이동해서 무엇을 고쳐야 하는지 확인할 수 있어요.
- **해결 여부가 자동으로 표시돼요:** 해결한 오류는 목록에서 줄이 그어져 보여요.
- **설정 제안을 받을 수 있어요:** 놓치기 쉬운 설정, 자리 표시용 내용 같은 흔한 설정 문제를 알려 줘요.
- **설정을 한눈에 볼 수 있어요:** 항목마다 따로 열어 보지 않아도 **인사이트**에서 주요 설정을 확인할 수 있어요.

## 사용 전 알아 둘 점

추천 사항 및 오류 감지는 새로 만든 폼·설문·퀴즈와 기존 폼·설문·퀴즈 모두에서 쓸 수 있어요. 유효성 검사 오류와 선택형 추천의 차이를 알아 두면 저장 전에 꼭 고쳐야 할 문제를 구분하기 쉬워요.

- **지원 대상:** 폼, 설문, 퀴즈
- **기존·신규 자산:** 이전에 만든 폼·설문·퀴즈와 새로 만든 폼·설문·퀴즈 모두에서 작동해요.
- **오류 감지 시점:** 저장하려고 할 때 기존 유효성 검사 오류를 찾아요.
- **검사 범위:** 커스텀 필드 생성, 중복된 커스텀 필드, 폼·설문·퀴즈 요소와 관련된 기존 오류를 대상으로 해요.
- **새 검사 규칙은 없어요:** 이번 업데이트는 기존 유효성 검사 오류를 보여 주고 해결하는 방식을 개선한 거예요. 새로운 제한을 추가하지는 않아요.
- **저장을 막는 오류:** 기존 유효성 검사 오류는 고쳐야 해당 폼·설문·퀴즈를 저장할 수 있어요.
- **선택형 추천:** 추천 사항은 설정을 개선하기 위한 제안이에요. 저장을 막는 유효성 검사 오류와는 별개예요.
- **추천 사항 켜기/끄기:** 릴리스 안내에 따르면 추천 사항은 **설정**에서 켜거나 끌 수 있어요.

## 추천 사항 및 오류 감지 사용하기

폼, 설문, 퀴즈를 만들거나 편집하는 중에 이 기능을 쓸 수 있어요. 아래에서 빌더 열기, 저장 오류 해결, 추천 사항 확인, 설정 인사이트 확인 순서로 안내해요.

### 폼·설문·퀴즈 빌더 열기

**서브 계정** 화면에서 확인하려는 항목을 찾아 열어요. 세 가지 모두 이동 방법은 비슷하지만, 목록과 편집 화면의 세부 기능은 조금 다를 수 있어요.

1. **서브 계정** 화면의 왼쪽 메뉴에서 **사이트**를 선택하세요.
2. **폼**, **설문**, **퀴즈** 중 하나를 선택하세요.
3. **빌더**를 선택하면 목록이 나와요.
4. 편집하려는 폼, 설문, 퀴즈를 찾으세요.
5. 항목 옆의 **점 세 개 메뉴(⋮)**를 클릭하세요.
6. **편집**을 선택해 빌더를 여세요.
7. 다른 빌더 탭이 열려 있다면 **편집** 탭을 선택하세요.

아래 절차는 이미 만들어 둔 항목을 기준으로 해요. 새로 만든 폼·설문·퀴즈에서도 똑같이 쓸 수 있어요.

### 저장 오류 찾아 고치기

오류 감지는 저장을 막는 설정 문제를 찾아 줘요. 필드를 직접 뒤지지 않아도, 오류 목록에서 문제가 있는 요소를 찾아 바로 고칠 수 있어요.

**유효성 검사 오류를 찾아 해결하려면:**

1. **서브 계정** 화면의 왼쪽 메뉴에서 **사이트**를 선택하세요.
2. **폼**, **설문**, **퀴즈** 중 하나를 선택하세요.
3. **빌더**를 선택하세요.
4. 항목 옆의 **점 세 개 메뉴(⋮)**를 클릭하고 **편집**을 선택하세요.
5. 빌더에서 **편집** 탭을 선택하세요.
6. 오른쪽 위의 **저장**을 클릭하세요.
7. 유효성 검사 오류가 있으면 **조치 필요** 오류 목록을 확인하세요.
8. 오류나 오류 옆의 이동 링크를 선택해 문제가 있는 요소로 이동하세요.
9. 요소 옆에 표시된 오류 메시지를 확인하세요.
10. 해당 필드나 요소의 설정에서 문제를 고치세요.
11. 오류 목록을 확인하세요. 문제가 해결된 것을 감지하면 하이퍼클래스가 해당 항목에 자동으로 줄을 그어 줘요.
12. 남은 오류도 같은 방법으로 고치세요.
13. 저장을 막는 오류를 모두 해결했으면 **저장**을 다시 클릭하세요.

**나타날 수 있는 오류 예시**

- **커스텀 필드 이름 중복:** 같은 이름을 쓰는 필드가 이미 있어요. 오류 목록에 **Rename the field**(필드 이름 바꾸기) 링크가 나와요.
- **필드 이름 누락:** 커스텀 필드는 이름이 있어야 저장할 수 있어요. 오류 목록에 **Name the field**(필드 이름 짓기) 링크가 나와요.
- **상품 누락:** 상품 요소에 상품이나 범프 상품이 지정되어 있지 않아요. 오류 목록에 **상품 추가** 링크가 나와요.
- **이미지 누락:** 이미지 요소에 이미지가 들어 있지 않아요. 오류 목록에 **이미지 추가** 링크가 나와요.

오류 메시지는 문제가 있는 요소 근처에도 표시돼요. 예를 들어 빌더에 **이미 사용 중인 이름입니다**, **이름이 필요합니다**, **No image added**(추가된 이미지가 없음) 같은 메시지가 나올 수 있어요.

**해결한 오류 확인하기**

오류를 하나씩 해결할 때마다 오류 목록이 자동으로 업데이트돼요. 해결한 항목에는 체크 표시와 취소선이 나타나서, 고친 오류와 남은 오류를 쉽게 구분할 수 있어요.

### 추천 사항 확인하기

추천 사항은 저장을 막지는 않지만 놓치기 쉬운 설정을 알려 줘요. 각 추천에는 설명이 있고, 가능한 경우 해당 설정으로 이동하는 링크가 함께 나와요.

**추천 사항을 확인하려면:**

1. **서브 계정** 화면의 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. **폼**, **설문**, **퀴즈** 중 하나를 선택하세요.
3. **빌더**를 선택하세요.
4. 항목 옆의 **점 세 개 메뉴(⋮)**를 클릭하고 **편집**을 선택하세요.
5. 빌더에서 **편집** 탭을 선택하세요.
6. 오른쪽 위 도구 모음에서 **추천 사항**을 클릭하세요.
7. 패널에서 **추천 사항** 탭을 선택하세요.
8. **필드**, **결제**, **설정** 같은 카테고리를 펼치세요.
9. 추천 내용과 제안된 조치를 확인하세요.
10. 이동 링크를 선택해 해당 설정으로 이동하세요.
11. 화면에 나온 설정에서 필요한 내용을 바꾸세요.
12. **저장**을 클릭해 변경 내용을 저장하세요.

![추천 사항 패널에서 카테고리별 추천 내용을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084320852/original/YHDEugb8v34VykFdeNGS6E9oImOnYeP8Tw.png?1793110523)

**자주 나오는 추천 유형**

- **자리 표시용 URL:** `example.com` 같은 예시 URL이 그대로 들어 있는 링크를 찾아 줘요. 실제로 연결할 URL로 바꾸세요.
- **기본 커스텀 필드 이름:** 기본 이름이나 자리 표시용 이름이 그대로인 새 커스텀 필드를 찾아 줘요. 알아보기 쉬운 이름으로 바꾸세요.
- **답변 레이블 누락:** 레이블이 없는 선택 항목을 찾아 줘요. 빠진 텍스트를 추가하세요.
- **결제 테스트 모드:** 결제 요소가 **Test Mode**(테스트 모드)로 남아 있는지 알려 줘요. 이 모드에서는 실제로 결제 금액이 수금되지 않는다는 경고가 함께 나와요.
- **봇 방지:** 원치 않는 스팸 제출을 줄이도록 봇 방지를 켜라고 추천해 줘요.

추천 사항은 선택 사항이에요. 패널에는 추천이 항목을 개선하기 위한 팁이라는 안내와 함께 **Save anytime**(언제든 저장 가능)이라는 메시지가 표시돼요.

릴리스 안내에 따르면 추천 사항은 **설정**에서 켜거나 끌 수 있어요.

### 인사이트 확인하기

**인사이트**에서는 현재 폼, 설문, 퀴즈가 어떻게 설정되어 있는지 한눈에 볼 수 있어요. 기능을 하나씩 열어 보지 않아도 주요 설정을 점검할 수 있어요.

**인사이트를 열려면:**

1. **서브 계정** 화면의 왼쪽 메뉴에서 **사이트**를 선택하세요.
2. **폼**, **설문**, **퀴즈** 중 하나를 선택하세요.
3. **빌더**를 선택하세요.
4. 항목 옆의 **점 세 개 메뉴(⋮)**를 클릭하고 **편집**을 선택하세요.
5. 빌더에서 **편집** 탭을 선택하세요.
6. 오른쪽 위 도구 모음에서 **추천 사항**을 클릭하세요.
7. **인사이트** 탭을 선택하세요.
8. 해당 항목의 설정 정보를 확인하세요.

![인사이트 탭에서 폼의 주요 설정을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084320911/original/dw1QDP1ajx5usmWAOFuKcC-hx2x20Bt_gg.png?1793110569)

**인사이트에서 볼 수 있는 정보**

| 항목 | 보여 주는 내용 |
| --- | --- |
| 조건부 로직 | 설정된 조건부 로직 규칙의 수 |
| **On-submit action**(제출 후 동작) | 제출 후에 실행되도록 설정한 동작 |
| 커스텀 필드 | 사용 중인 커스텀 필드의 수 |
| 결제 모드 | 결제 설정이 **Test Mode**(테스트 모드)인지 **Live Mode**(라이브 모드)인지 |
| **Email notification**(이메일 알림) | 이메일 알림이 켜져 있는지 꺼져 있는지 |
| **Auto responder**(자동 응답) | 자동 응답이 켜져 있는지 꺼져 있는지 |

표시되는 값은 지금 확인 중인 항목의 설정을 그대로 반영해요. 예를 들어 위 화면 예시에서는 조건부 로직 규칙이 1개, 커스텀 필드가 10개이고 결제 모드가 테스트로 설정되어 있어요.

추가로 수정하기 전에 **인사이트**의 설정 정보를 추천 사항과 함께 살펴보세요.

## 자주 묻는 질문

### 추천 사항이 남아 있어도 폼·설문·퀴즈를 저장할 수 있나요?

네, 저장할 수 있어요. 추천 사항은 선택 사항인 개선 제안이고, 패널에도 **Save anytime**이라고 표시돼요. 다만 저장을 막는 기존 유효성 검사 오류는 저장하기 전에 반드시 해결해야 해요.

### 오류 감지가 게시된 폼에 방문자가 입력한 답변도 검사하나요?

아니요. 새 오류 감지는 빌더에서 저장할 때 나타나는 설정 오류를 다뤄요. 제출할 때 누락되거나 잘못된 입력을 알려 주는 응답자용 유효성 검사는 하이퍼클래스 문서에 별도로 안내되어 있어요.

### 인사이트에서 결제 모드가 Test로 나와요. 왜 그런가요?

인사이트는 현재 결제 설정을 그대로 보여 줘요. 결제 모드가 **Test Mode**이면 추천 사항 패널에서 이 모드로는 실제로 결제 금액이 수금되지 않는다는 경고가 나올 수 있어요. 실제 결제를 받기 전에 설정을 확인하세요.

### 오류 하나를 고쳤는데 다른 오류가 남아 있으면 어떻게 되나요?

해결한 오류는 오류 목록에서 자동으로 줄이 그어져요. 남은 오류는 목록에 그대로 있고, 해당 항목을 저장하려면 모두 고쳐야 해요.
