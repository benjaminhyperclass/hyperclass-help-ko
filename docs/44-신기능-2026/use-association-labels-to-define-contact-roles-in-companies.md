# 연결 라벨로 회사 안 연락처의 역할 정하기

연결 라벨은 회사 안에서 연락처가 맡은 역할을 나타내요. 예를 들어 직원, 청구 담당자, 의사결정자 같은 역할이 있어요. 필요한 역할을 직접 만들어 연락처와 회사의 관계에 적용하면, 담당자를 한눈에 알아보거나 회사 이메일을 보낼 연락처를 고를 때 쓸 수 있어요.

## 연락처 연결 라벨이란

연결 라벨은 연락처와 회사의 관계를 정의해요. 팀원이 각 사람의 담당 업무를 알아보고, 레코드가 어떻게 이어져 있는지 이해하는 데 도움이 돼요.

연결 라벨은 다음과 같이 구성할 수 있어요.

- **단일 라벨**: 어느 쪽 레코드에서 보든 같은 라벨을 써요.
- **라벨 한 쌍**: 양쪽에 각각 다른 이름을 붙여요. 예를 들어 회사에는 '고용주', 연락처에는 '직원'이라고 쓸 수 있어요.
- 여러 역할: 한 사람이 여러 업무를 맡고 있다면 같은 연락처와 회사에 라벨을 두 개 이상 적용할 수 있어요.
- **주 회사**: 연락처의 주된 회사를 나타내는 기본 제공 관계예요. 사용자 지정 연결 라벨과 함께 쓸 수 있어요.

예를 들어 결제 관련 연락을 맡은 사람에게는 '청구 담당자' 라벨을, 제안서나 계정 검토에 참여하는 사람에게는 '의사결정자' 라벨을 만들 수 있어요. 한 연락처가 두 업무를 모두 맡고 있다면 같은 관계에 두 라벨을 모두 지정할 수 있어요.

---

## 연결 라벨 만들기

연결 라벨을 만들어 연락처와 회사가 어떤 관계인지 정해 보세요. 양쪽 레코드에 같은 이름으로 표시할지, 쪽마다 다른 이름을 쓸지 선택할 수 있어요.

1. **설정 > 오브젝트**로 이동해 **회사** 또는 **연락처**를 열고 **연관**을 선택하세요.
2. **연결 만들기**를 클릭하세요. 회사에서 시작했다면 상대 오브젝트로 **연락처**를, 연락처에서 시작했다면 **회사**를 선택하세요.

   ![연결 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256558/original/TSpGnPFs6tnRo--84sl22uF6Ntoco4qw5w.png?1793058577)
3. **단일 라벨** 또는 **라벨 한 쌍**을 선택하고 라벨 이름을 입력하세요.
4. 양쪽 방향의 연결 한도를 설정하고 미리보기를 확인하세요.
5. **저장**을 클릭하세요.

   ![연결 라벨 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256557/original/pOEivTU3G8MHE6i-kcqSsIq3bNCbEJlNMQ.png?1793058556)

연결 한도는 하나의 연결에 레코드를 몇 개까지 이을 수 있는지 정하는 값이에요. 설정한 한도에 도달하면 그 이상은 연결할 수 없어요.

시스템에서 정의한 **주 회사** 관계는 사용자 지정 라벨로 바꿀 수 없어요. 대신 **주 회사** 옆에 사용자 지정 라벨을 새로 만드세요.

## 연락처에 연결 라벨 지정하기

연결 라벨을 만들었다면 연락처를 회사에 연결할 때 라벨을 지정할 수 있어요. 이렇게 하면 연결된 레코드에서 바로 각 연락처의 역할을 알아볼 수 있어요.

1. **회사** 레코드를 열고 **연관**을 선택하세요.
2. **연락처** 옆의 **추가**를 클릭하세요.

   ![연락처 옆 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256597/original/kfDmZTAuidB6b2z0NeRLpuv7zWwGNZ7-YQ.png?1793058868)
3. 연결할 연락처를 검색해서 선택하세요.
4. 알맞은 연결 라벨을 고르고 **저장**을 클릭하세요.

   ![연결 라벨 선택 후 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256605/original/Se4jrF7h08ah2A4fo8IPsNXIaqWyh9t3AQ.png?1793058897)

연락처 레코드에서도 **연관** 탭에 회사를 추가해 같은 방식으로 연결할 수 있어요.

---

## 연락처 역할 수정하거나 추가하기

연락처의 담당 업무는 시간이 지나면서 바뀔 수 있고, 한 사람이 같은 회사에서 여러 역할을 맡을 수도 있어요. 연락처 레코드를 중복으로 만들지 않고도 기존 라벨을 수정하거나 라벨을 추가로 지정할 수 있어요.

1. 회사의 **연관** 탭을 여세요.
2. 해당 연락처의 연결 카드에서 점 세 개 메뉴를 클릭하세요.
3. **레이블 편집**을 선택하세요.

   ![레이블 편집 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256612/original/g_qSctSBC9qgLlzBalLnszK2y9h1MsKCmQ.png?1793058920)
4. 지정된 라벨을 바꾸거나 다른 라벨을 추가해 연락처에 여러 역할을 주세요.
5. **저장**을 클릭하세요.

   ![수정한 라벨 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256615/original/UuOTjBtbxe9CH6F3BjRpw_FdLosBWX07Jw.png?1793058937)

{% hint style="info" %}
시스템 기본 라벨인 **주 회사**는 레이블 편집 화면에서 제거할 수 없도록 보호돼요.
{% endhint %}

## 회사에서 연락처 역할 확인하기

연결 라벨을 쓰면 회사의 영역별 담당자를 쉽게 파악할 수 있어요. 회사 레코드 하나씩 열어서 볼 수도 있고, **회사** 목록에 바로 표시할 수도 있어요.

### 회사 레코드에서 역할 보기

회사의 **연관** 탭을 열면 연결된 연락처와 지정된 역할을 볼 수 있어요.

예를 들어 Sarah Thompson의 역할은 '매니저', Robert Chen의 역할은 '소유자'로 표시될 수 있어요. 사용자 지정 연결 라벨은 기본 제공 연락처 관계와 함께 표시돼요.

![회사의 연관 탭에서 연락처 역할 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256631/original/vLLA8XwhmW77NGFwiGuwI6Nn3212VJiIqA.png?1793058993)

### 회사 목록에서 역할 보기

레코드를 하나씩 열지 않고 여러 회사의 연락처 역할을 한 번에 보려면 다음과 같이 하세요.

1. **회사** 목록을 여세요.
2. **필드 관리**를 클릭하세요.
3. 표시하려는 역할의 연락처 연결 열을 추가하세요.

열 이름은 내 계정에 설정된 연결 라벨 이름을 따라가요.

![필드 관리에서 연락처 연결 열 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256638/original/1QbFemWS6fqdUAq-iI7_njd-A5LI1GBB7w.png?1793059030)

## 역할에 따라 연락처에 이메일 보내기

연결 라벨을 쓰면 선택한 회사 안에서 담당 업무에 따라 대상을 좁혀 이메일을 보낼 수 있어요. 예를 들어 청구 담당자에게는 계정 관련 소식을, 의사결정자에게는 예정된 검토 일정을 안내할 수 있어요.

1. **회사**를 열고 이메일을 보낼 연락처가 속한 회사를 선택하세요.
2. **이메일 보내기**를 클릭하고, 선택한 회사를 확인한 다음 이메일 작성 화면으로 넘어가세요.

   ![이메일 보내기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256649/original/OlalMdPq4tQM_2WBUvB8jzu-Krq6n3pAjQ.png?1793059084)
3. **연결 라벨**에서 포함할 역할을 선택하세요. 청구 담당자, 소유자, 매니저 같은 역할을 고를 수 있어요.

   ![연결 라벨 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084256653/original/aEMfzarZ7VkMzegRjma4nYQHt3oQWfKDVg.png?1793059098)
4. **이메일 수신자**에서 이메일을 받을 대상을 선택하세요.

   - **연결된 모든 연락처**: 조건에 맞는 연락처를 모두 포함해요.
   - **가장 최근에 연결된 연락처**: 조건에 맞는 연락처 중 가장 최근에 연결된 연락처를 포함해요.
   - **가장 먼저 연결된 연락처**: 조건에 맞는 연락처 중 가장 먼저 연결된 연락처를 포함해요.
5. 이메일을 작성한 뒤 보내기 전에 대상과 설정을 확인하세요.

{% hint style="warning" %}
**중요 사항**

- 여러 라벨을 선택한 경우: 조건에 맞는 연락처가 중복 없이 하나의 대상 목록으로 합쳐져요. 같은 연락처가 두 번 포함되지 않아요.
- **주 회사**를 포함한 경우: 연락처 쪽 라벨은 '연락처'로 표시되고 **주 회사**와 한 쌍을 이뤄요. 이 관계를 포함하면 **이메일 수신자**가 **모든 연락처**로 유지돼요.
- 수신자 선택: **이메일 수신자**의 세 가지 옵션은 사용자 지정 연결 라벨만 선택했을 때 쓸 수 있어요.
- 최종 수신자 수: 대상은 일괄 작업이 실행될 때 확정돼요. 최종 인원수는 일괄 작업 통계에서 확인할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 주 회사를 사용자 지정 라벨로 바꿀 수 있나요?
아니요. **주 회사**는 연락처의 주된 회사를 나타내는 기본 제공 시스템 관계라서, 레이블 편집 화면에서 제거할 수 없도록 보호돼요. 대신 **주 회사** 옆에 사용자 지정 역할을 새로 만드세요.

### 한 연락처가 같은 회사에서 역할을 두 개 이상 가질 수 있나요?
네, 가질 수 있어요. 같은 연락처와 회사를 소유자와 의사결정자처럼 여러 라벨로 연결할 수 있어요. **레이블 편집**에서 기존 라벨 옆에 새 라벨을 추가한 뒤 **저장**을 클릭하세요.

### 단일 라벨과 라벨 한 쌍은 어떻게 다른가요?
**단일 라벨**은 어느 쪽 레코드에서 보든 같은 이름을 써요. **라벨 한 쌍**은 양쪽에 각각 다른 이름을 붙여요. 예를 들어 회사에는 '고용주', 연락처에는 '직원'이라고 쓸 수 있어요.

### 각 연락처의 역할은 어디서 볼 수 있나요?
회사의 **연관** 탭을 열면 각 연락처 카드에서 역할을 볼 수 있어요. **회사** 목록에서 **필드 관리**를 열고 필요한 역할의 연락처 연결 열을 추가해도 확인할 수 있어요.

### 연락처에 이메일을 보낼 때 라벨을 여러 개 선택하면 어떻게 되나요?
조건에 맞는 연락처가 중복 없이 하나의 대상 목록으로 합쳐지기 때문에, 각 연락처는 한 번만 포함돼요.
