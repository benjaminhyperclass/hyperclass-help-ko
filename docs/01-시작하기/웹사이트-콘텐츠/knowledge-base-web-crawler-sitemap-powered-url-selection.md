# 지식 베이스 웹 크롤러: 사이트맵으로 학습할 페이지 고르기

**지식 베이스**(Knowledge Base)에 학습시킬 웹사이트 페이지를 사이트맵 미리보기에서 직접 골라 쓰는 방법을 안내해요. 발견된 URL을 미리 보고, 학습할 페이지만 골라서, 진행 상황을 확인하고, 실패한 URL만 다시 시도할 수 있어요.

## 사이트맵 기반 URL 선택이란?

**웹 크롤러**에서 웹사이트 페이지를 지식 베이스에 학습시키기 전에 미리 보고 고를 수 있는 방식이에요. 하이퍼클래스가 웹사이트의 사이트맵 URL을 찾으면 **페이지 선택** 창에 사용할 수 있는 페이지가 나와요. 그중 지식 베이스 콘텐츠로 쓸 URL만 고르면 돼요.

웹사이트에 페이지가 많은데 AI 답변에 필요한 페이지는 일부일 때 유용해요. 한 창에서 다음 작업을 모두 할 수 있어요.

- URL 검색
- 페이지 넘기기
- URL 개별 선택
- 사용 가능한 페이지 할당량 확인
- 선택한 페이지 학습

필요한 페이지가 사이트맵 결과에 없으면 **Discover by Crawling**(크롤링으로 찾기)을 대체 수단으로 쓸 수 있어요. 웹사이트의 링크를 따라가며 페이지를 찾아 줘요.

![사이트맵 기반 페이지 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078015126/original/dZeAViOdCQZcQQlTHrIgbb4TNf-soWz-2g.png?1786360429)

## 이럴 때 좋아요

학습할 페이지를 직접 고르면 지식 베이스가 무엇을 학습하는지 더 잘 관리할 수 있어요. 관련 없는 콘텐츠가 줄고, 불필요한 페이지 사용을 피하며, 웹사이트 학습 상황을 확인하기도 쉬워져요.

- 정확한 페이지 선택: 학습할 웹사이트 URL을 직접 골라요. 무작정 학습시키지 않아도 돼요.
- 빠른 설정: 사이트맵 결과, 검색, 페이지 넘기기, 행 수 조절로 필요한 페이지를 빠르게 찾아요.
- 할당량 확인: 학습 전에 선택한 페이지 수와 사용 가능한 페이지 수를 확인해요.
- 대체 탐색: 사이트맵 결과에 빠진 페이지가 있으면 **Discover by Crawling**을 써요.
- 진행 상황 확인: 작업 카드(operation card)에서 크롤링과 학습 진행 상황을 확인해요.
- 수동 재시도: 학습이 끝까지 되지 않은 URL을 다시 시도해요.

## 웹 크롤러는 어디에 있나요?

**웹 크롤러**는 지식 베이스 안에 있고, 웹사이트 콘텐츠를 학습시키는 데 써요. 웹사이트 소스를 추가하면 AI 도구가 선택한 공개 웹사이트 페이지를 바탕으로 질문에 답할 수 있어요.

1. 하이퍼클래스에서 **AI 에이전트**로 이동해요.
2. **지식 베이스**를 열어요.
3. 업데이트할 지식 베이스를 선택해요.
4. **웹 크롤러** 탭을 클릭해요.
5. 새 웹사이트 소스를 추가하려면 **웹사이트 추가**를 클릭해요.

**웹 크롤러** 탭에는 웹사이트 소스, 학습된 페이지 상태, 업데이트 시각, 페이지별 작업이 나와요.

## URL 선택 모드

URL 선택 모드는 입력한 URL과 관련된 페이지를 하이퍼클래스가 어떤 범위로 찾을지 정해요. 알맞은 모드를 고르면 학습할 URL을 선택하기 전에 페이지 목록을 좁힐 수 있어요.

| 모드 | 방식 | 설명 |
|---|---|---|
| **Exact URL**(정확한 URL) | 단일 페이지 학습 | 특정 페이지 URL 하나를 사용해요. 긴 목록을 훑지 않고 페이지 하나만 학습시킬 때 좋아요. |
| **All URLs with this Path**(이 경로의 모든 URL) | 경로 기준 탐색 | 웹사이트의 특정 경로(예: /help, /docs, /support) 아래 페이지를 찾아요. 특정 영역만 지식 베이스 학습에 쓰고 싶을 때 유용해요. |
| **All URLs in this Domain**(이 도메인의 모든 URL) | 도메인 전체 탐색 | 선택한 도메인 전체에서 페이지를 찾아요. 문서 사이트나 작은 마케팅 웹사이트처럼 대부분의 페이지가 필요할 때 좋아요. 사이트맵 창에서 관련 없는 하위 영역은 선택을 해제할 수 있어요. |

![URL 선택 모드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078015306/original/W6fT1aG_c-97NewgeO6eoGOAtnBHSFOYZw.png?1786360499)

## 페이지 선택 창

**페이지 선택** 창은 사이트맵 기반 URL 선택의 중심 화면이에요. 발견된 URL을 표로 보여 줘서, 학습을 시작하기 전에 어떤 페이지를 지식 베이스에 넣을지 살펴보고 걸러서 고를 수 있어요.

"전부 학습"에서 벗어나 필요한 URL만 골라 학습시킬 수 있어요. 고객에게 필요한 페이지가 일부뿐인 크거나 복잡한 웹사이트일수록 도움이 돼요.

### 창에서 볼 수 있는 항목

- 사이트맵에서 발견된 페이지 수 (예: "사이트맵에서 426페이지 발견")
- **선택된 페이지** 카운터 (예: "3,995개 중 0개 선택")
- 키워드나 경로로 URL을 걸러내는 **필드 검색**
- URL별 선택 체크박스
- 목록의 모든 URL을 한 번에 고르는 **전체 선택**
- **페이지당 행 수** 선택 (예: 10, 25, 50)
- 긴 목록을 넘겨 보는 페이지 이동 버튼
- 더 깊이 찾아보는 **Discover by Crawling** 버튼
- 선택한 URL의 학습을 시작하는 **Train Selected**(선택 항목 학습) 버튼

### 화면 반응 속도

페이지 번호를 바꾸거나 페이지당 행 수를 조절하거나 검색어를 바꾸면 URL 목록만 새로 고쳐져요. 창은 계속 열려 있고, URL이 수천 개인 긴 목록도 몇 초 만에 다룰 수 있어요.

![페이지 선택 창 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078015416/original/LBvHnYb9kzJ7reO3lRqKj4_-KN1vsC2WSg.png?1786360556)

## 페이지 할당량 카운터

학습을 시작하기 전에 할당량을 미리 확인할 수 있어요. 선택한 페이지 수와, 지식 베이스 한도를 기준으로 학습에 쓸 수 있는 페이지 수가 나와요.

지식 베이스를 안정적으로 운영하려면 URL 할당량을 관리하는 게 중요해요. 하이퍼클래스에서는 지식 베이스 하나당 정해진 수까지(예: 4,000개) 웹 URL을 학습시킬 수 있고, 이미 학습 데이터에 포함된 URL도 함께 집계해요. 실시간 할당량 카운터를 보면 한도를 넘기지 않고 선택할 수 있어요.

### 카운터가 동작하는 방식

카운터에는 "3,995개 중 120개"처럼 현재까지의 집계가 나와요. 다음 작업을 할 때마다 바로 바뀌어요.

- 창에서 URL을 선택하거나 선택 해제할 때
- 이미 학습된 URL을 포함하거나 제외할 때

지식 베이스에 이미 들어 있는 URL은 자동으로 반영돼요. 그래서 새 페이지에 쓸 수 있는 여유 공간이 얼마인지 알 수 있어요.

### 이런 점이 좋아요

- URL 한도를 넘겨서 학습 도중 오류가 나는 일을 막아 줘요.
- 도메인 전체를 학습시키는 대신, 가치 높은 URL만 골라 학습시키게 돼요.
- 새 상품 페이지나 문서를 위해 할당량을 남겨 두는 등 이후 추가 계획을 세우기 쉬워요.

## Discover by Crawling(크롤링으로 찾기)

**Discover by Crawling**은 사이트맵 결과에 페이지가 빠졌거나, 사이트맵에 필요한 내용이 다 들어 있지 않을 때 쓰는 대체 수단이에요. 사이트맵 결과에만 의존하지 않고 웹사이트의 링크를 따라가며 추가 페이지를 찾아요.

이 기능은 고도화된 웹 크롤러의 링크 탐색 기능과 함께 쓰여요. 이 탐색 기능은 사이트맵 재귀 크롤링, 압축된 사이트맵 파일, 동적 링크 감지를 지원해요.

### 이럴 때 사용하세요

- 필요한 페이지가 사이트맵 목록에 없을 때
- 웹사이트에 사이트맵이 없거나 사이트맵이 불완전할 때
- 주요 페이지가 탐색 메뉴, 아코디언 같은 인터랙티브 요소로만 접근될 때
- 새로 추가한 섹션이 아직 사이트맵에 반영되지 않았을 때
- URL 한도 안에서 최대한 많은 페이지를 찾고 싶을 때

### 동작 방식

- 입력한 도메인이나 경로에서 시작해, 허용된 범위 안의 내부 링크를 따라가요.
- 크롤러가 범위를 벗어나지 않도록 탐색 경계와 루트 도메인 규칙을 지켜요.
- 추가 페이지가 발견될 때마다 창의 URL 목록이 업데이트돼요.
- 작업 카드에 "크롤링 중 — 지금까지 42페이지 발견"과 같이 진행 상황이 나와요.
- 링크를 직접 따라가며 탐색하므로, 사이트맵 기반 선택보다 시간이 더 걸릴 수 있어요.

## 크롤링·학습 진행 상황 확인하기

작업 카드에서 웹 크롤러가 무엇을 하는지, 학습이 어디까지 진행됐는지 실시간으로 볼 수 있어요. 규모가 큰 웹사이트나 깊이 있는 탐색 크롤링일 때 특히 유용해요.

상태 메시지와 수치는 페이지를 새로고침하거나 탭을 바꿔도 그대로 유지돼요.

### 작업 카드에 나오는 내용

- 상태 메시지와 함께 보이는 크롤링 진행 상황
- 학습 진행 상황 (예: "5개 중 5개 학습 중")
- 크롤링 중 발견된 페이지 수
- 학습에 성공한 페이지 수
- 현재 작업 상태 (진행 중, 완료, 실패)
- 완료율을 보여 주는 진행 표시

### 이런 점이 좋아요

- 페이지를 벗어나거나 탭을 바꿔도 크롤링이 중단되지 않고, 진행 상황도 계속 볼 수 있어요.
- 문제가 생겼을 때 탐색 단계, 학습 단계, 또는 둘 다 중 어디에서 생겼는지 바로 알 수 있어요.
- 기술에 익숙하지 않은 팀원도 지식 베이스 학습이 지금 어떻게 되고 있는지 쉽게 볼 수 있어요.

## 실패한 URL 다시 시도하기

처음 시도에서 모든 URL이 성공적으로 학습되는 것은 아니에요. 페이지가 시간 초과되거나 응답이 느리거나, 외부 상황 때문에 일시적으로 실패할 수 있어요. 수동 재시도를 쓰면 크롤링 전체를 다시 하지 않고 실패한 URL만 복구할 수 있어요.

작업 결과를 보면 문제가 있는 페이지를 찾아서 골라 다시 시도할 수 있어요.

### 수동 재시도 방법

크롤링이나 학습 중 페이지가 실패했다면 다음과 같이 해요.

1. 지식 베이스를 열고 **웹 크롤러** 탭으로 이동해요.
2. 웹사이트 소스나 페이지 목록에서 실패한 URL을 확인해요.
3. 페이지별 재시도 또는 새로고침 작업이 있으면 사용해요.
4. 재시도가 끝날 때까지 작업 카드를 확인해요.

### 실패에 대처하는 요령

- URL부터 확인하세요. 브라우저에서 페이지가 제대로 열리는지 확인해요(404 오류, 리디렉션 반복, 로그인 필요 페이지가 아닌지).
- 적은 수로 나눠 다시 시도하세요. 여러 URL이 실패했다면 일부만 다시 학습시켜 보고 공통된 패턴을 찾아보세요.
- Auto Refresh(자동 새로고침)와 함께 쓰세요. URL이 성공적으로 학습된 뒤에는 Auto Refresh를 켜서 자동으로 최신 상태를 유지할 수 있어요.

## 사이트맵으로 웹사이트 페이지 학습시키기

설정을 제대로 해 두면 지식 베이스에 AI 답변에 도움이 되는 페이지만 학습시킬 수 있어요. 먼저 웹사이트 소스를 선택하고, 알맞은 URL 모드를 고른 다음, 학습 전에 사이트맵 기반 페이지 목록을 확인하세요.

### 1단계. 지식 베이스 열기

1. 서브 계정에서 **AI 에이전트 > 지식 베이스**로 이동해요.
2. 기존 지식 베이스를 열거나 새로 만들어요.
3. **웹 크롤러** 탭을 선택해요.

### 2단계. 웹사이트 소스 추가하기

1. **웹사이트 추가**를 클릭해요.
2. URL 선택 모드를 골라요.
   - **Exact URL**: 페이지 하나만 학습할 때
   - **All URLs with this Path**: 경로 기준으로 학습할 때
   - **All URLs in this Domain**: 도메인 전체를 학습할 때
3. 시작할 URL을 입력해요. https://를 포함해서 입력하세요.
4. **페이지 선택**을 클릭해요.

### 3단계. 사이트맵 미리보기 창 확인하기

1. 하이퍼클래스가 사이트맵을 불러와 발견된 URL을 보여 줘요.
2. 창 위쪽에 사이트맵에서 발견된 페이지 수가 나와요(예: "사이트맵에서 426페이지 발견").
3. URL 목록을 보고 어떤 페이지를 사용할 수 있는지 확인해요.

### 4단계. URL 검색하고 고르기

1. **필드 검색**에서 키워드나 경로로 URL을 찾아요.
2. 규모가 큰 웹사이트라면 **페이지당 행 수**를 조절해요.
3. 페이지 이동 버튼으로 전체 목록을 넘겨 봐요.
4. 학습할 URL 옆 체크박스를 선택해요.
5. 한 번에 고르는 게 알맞다면 **전체 선택** 체크박스를 사용해요.
6. 관련 없는 URL은 선택을 해제해요.
7. 할당량 카운터(예: "3,995개 중 120개")를 보면서 한도를 넘지 않게 선택해요.

### 5단계(선택). Discover by Crawling 실행하기

필요한 페이지가 사이트맵에 없거나 사이트맵이 불완전하다면 다음과 같이 해요.

1. **Discover by Crawling**을 클릭해요.
2. 크롤러가 내부 링크를 탐색할 때까지 기다려요.
3. 표에 새 URL이 나타나면 **필드 검색**과 체크박스로 선택을 다시 정리해요.
4. 작업 카드에서 크롤링 진행 메시지를 확인해요.

### 6단계. 선택한 URL 학습시키기

1. 선택한 URL과 할당량 카운터를 마지막으로 확인해요.
2. **Train Selected**를 클릭해요.
3. 학습 진행 상황을 보여 주는 작업 카드가 나타나요.
4. 다른 탭으로 이동해도 돼요. 작업은 백그라운드에서 계속 진행돼요.

### 7단계. 결과 확인하고 실패한 URL 다시 시도하기

1. 학습이 끝나면 학습된 URL 목록을 확인해요.
2. 실패한 URL이 있는지 살펴봐요.
3. 실패한 URL이 있다면 페이지별 재시도/새로고침 작업이 있을 때 사용해요.
4. 검색 테스트 도구(retrieval tester)로 지식 베이스를 테스트해서 콘텐츠가 제대로 검색되는지 확인해요.

## 자주 묻는 질문

### 사이트맵 기반 URL 선택이 뭔가요?
**웹 크롤러**에서 사이트맵에 있는 웹사이트 URL을 보여 주고, 지식 베이스에 학습시킬 페이지를 직접 고르게 해 주는 방식이에요.

### 사이트맵 기반 URL 선택을 쓰면 지식 베이스당 URL 한도가 바뀌나요?
아니요. 지식 베이스당 전체 URL 한도는 그대로예요(예: 웹 URL 최대 4,000개). 새 방식은 남은 URL이 몇 개인지 쉽게 보여 줘서, 페이지를 고를 때 한도를 넘기지 않게 도와줄 뿐이에요.

### 사이트맵 미리보기와 Discover by Crawling 중 어느 걸 써야 하나요?
웹사이트의 사이트맵이 정확하고 필요한 섹션을 모두 담고 있다면 사이트맵 미리보기를 쓰세요. 보통 더 빠르고 부담도 적어요. 사이트맵에 섹션이 빠졌다고 의심되거나, 웹사이트가 동적으로 구성되어 있거나, 중요한 콘텐츠가 탐색 메뉴나 인터랙티브 요소로만 접근된다면 **Discover by Crawling**을 쓰세요.

### 학습 전에 페이지 목록을 검색할 수 있나요?
네. **페이지 선택** 창의 **필드 검색**에서 특정 페이지나 URL 경로를 찾을 수 있어요.

### 모든 페이지를 한 번에 선택할 수 있나요?
네. 창에서 **전체 선택** 체크박스를 사용하세요. 모든 페이지를 학습시키기 전에 사용 가능한 할당량을 먼저 확인하세요.
