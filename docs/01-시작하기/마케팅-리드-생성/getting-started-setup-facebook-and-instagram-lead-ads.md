# Facebook·Instagram 리드 광고 설정하기

Facebook과 Instagram 채널을 연결해서 리드 생성 광고를 관리하는 방법을 안내해요. Meta 광고로 잠재 고객 정보를 받고, 캠페인 설정까지 하이퍼클래스 안에서 처리할 수 있어요.

## Facebook·Instagram 리드 광고란?

리드 생성 캠페인에서는 Facebook 리드 폼으로 이름, 이메일 주소, 전화번호, 직접 만든 질문에 대한 답변 같은 정보를 모을 수 있어요.

**마케팅 > 광고 관리자**(Ad Manager)에서 Meta 리드 생성 캠페인을 만들고 관리할 수 있어요. 폼 필드를 하이퍼클래스의 연락처 필드에 알맞게 매핑해 두면, 제출된 리드 정보를 CRM에 정리해서 후속 조치와 자동화에 활용할 수 있어요.

---

## Facebook·Instagram 리드 광고 설정 방법

### 1단계. 광고 관리자 열고 활성화하기

Meta 자산을 연결하고 캠페인을 만들려면 서브 계정에서 **광고 관리자**를 먼저 활성화해야 해요.

1. 하이퍼클래스 서브 계정에서 **마케팅 > 광고 관리자**로 이동하세요.
2. **광고 관리자**가 아직 활성화되지 않았다면 **광고 관리자 활성화**를 클릭하세요.

![광고 관리자 활성화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078477956/original/os-WfwWeGuPqqUT2BXo-rUJ8jvS9dCIriA.png?1786726217)

### 2단계. Facebook 연결하기

1. **광고 관리자** 시작 화면에서 **Facebook 연결**을 클릭하세요.
2. Facebook 로그인 또는 권한 승인 절차를 마치고, 요청하는 권한을 하이퍼클래스에 허용하세요.

![Facebook 연결 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078478030/original/MM6zYytVDK-6souUuz8yukJ0octEcRIt9w.png?1786726295)

### 3단계. Meta 광고 계정 선택하기

1. **Meta 광고 계정 선택** 드롭다운이나 검색란에서 사용할 광고 계정을 찾아 선택하세요.
2. Facebook 페이지 선택 영역에서 사용할 페이지를 검색해 선택한 뒤 **연결**을 클릭하세요.
3. 페이지가 연결되면 **시작하기** 버튼을 클릭하세요.

![Meta 광고 계정과 Facebook 페이지 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078478284/original/FRrZ6nzG6F9CmytUvtYpb6wcwlwouuWGAg.png?1786726486)

### 4단계. 캠페인 만들기

1. **캠페인 만들기**를 클릭하세요.
2. 플랫폼으로 **메타**를 선택하세요.
3. **다음**을 클릭하세요.
4. 처음부터 시작하거나, 사용할 수 있는 광고 관리자 템플릿 중에서 골라 시작하세요.

![캠페인 만들기 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078478808/original/3wuI73yvsr9iNfV_RCq1XNdF6CI5lHQJuw.gif?1786726707)

### 5단계. 리드 생성 목표 선택하기

1. 캠페인 목표로 **리드 생성**을 선택하세요.
2. 해당하는 경우 알맞은 **Special Ad Category**(특별 광고 카테고리)를 선택하세요. 캠페인이 특별 카테고리에 해당하지 않으면 '해당 없음'에 해당하는 옵션을 선택하세요.
3. 광고 세트 설정 단계로 넘어가세요.

![리드 생성 목표 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078479094/original/3wwOmLf_wZPrUlmes-oYFUwyn1tjkr55zw.png?1786726987)

### 6단계. 광고 세트 설정하기

화면에 나오는 광고 세트 설정을 차례로 채워요.

- **Ad Set Name**(광고 세트 이름)을 입력하세요.
- **Facebook Page**(Facebook 페이지)를 선택하세요.
- 해당하는 경우 **Instagram Account**(Instagram 계정)를 선택하세요.
- **게재 위치**를 선택하세요.
- **예산**과 일정을 설정하세요.
- **오디언스**와 지역 설정을 구성하세요.

Meta 광고비는 선택한 Meta 광고 계정에 연결된 결제 수단으로 청구돼요.

![광고 세트 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078479251/original/SrlKEzkLNLZ_sCxblXNHYT23Na0IRzuY8w.png?1786727074)

### 7단계. Facebook 리드 폼 만들기 또는 선택하기

1. 광고 단계에서 리드 수집 방식을 고르라는 안내가 나오면 **Facebook Lead Form**(Facebook 리드 폼)을 선택하세요.
2. 리드 폼 드롭다운을 여세요.
3. 기존 폼을 선택하거나 **Facebook 폼 만들기**를 클릭하세요.

기존 폼을 선택했다면 다음 단계로 넘어가기 전에 매핑을 확인하세요. 폼 필드가 매핑되지 않았다고 하이퍼클래스가 안내하면, 안내에 따라 폼 필드를 알맞은 CRM 필드에 연결하세요.

새 폼을 만들려면 **Facebook 폼 만들기**를 클릭한 뒤 필수 정보를 모두 입력하세요.

![Facebook 리드 폼 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078479387/original/2kCd5pWR_5wg2oRt7JOxaH0qLXkm58lOwA.png?1786727209)

### 8단계. 광고 소재 설정하기

1. **광고명**을 입력하세요.
2. **Primary Text**(기본 텍스트)를 입력하세요.
3. **헤드라인**을 입력하세요.
4. 필요하면 **설명 추가**로 설명을 입력하세요.
5. 원하는 **행동 유도**를 선택하세요.
6. 사용할 이미지, 캐러셀, 동영상을 업로드하세요.

캠페인 준비가 끝나면 **리뷰**를 클릭해 캠페인 내용을 확인한 다음 **Publish Campaign Now**(캠페인 바로 게시)를 클릭하세요.

![광고 소재 설정과 게시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078479525/original/NfQp9H276rjUdLDUsCsxeSPWwtc8ork92A.png?1786727335)

## 기존 광고 게시하기

광고가 이미 **광고 관리자**에 있지만 아직 검토하거나 게시하지 않았을 때 쓰는 방법이에요. 새 캠페인을 처음부터 만들지 않고, 기존 캠페인 설정으로 돌아가서 이어서 작업할 수 있어요.

1. **마케팅 > 광고 관리자**로 이동하세요.
2. 해당 광고나 캠페인을 찾으세요.
3. 점 세 개(⋮) 메뉴를 클릭하세요.
4. **편집**을 클릭하세요.
5. 캠페인, 광고 세트, 광고 설정을 확인하세요.
6. 최종 검토와 게시 단계로 넘어가세요.
7. **게시**를 클릭하고 게시를 확인하세요.

![기존 광고 편집 및 게시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078479670/original/aCM80odNOJxd1NifeJsyn5E-esLMyTPYng.png?1786727535)

## 자주 묻는 질문

### Facebook·Instagram 광고에 광고 관리자를 쓰려면 Meta 광고 계정이 꼭 필요한가요?
네. 광고 관리자를 설정할 때 Meta 광고 계정을 선택해야 시작 절차를 끝낼 수 있어요.

### 시작하기 버튼이 비활성화되어 있어요.
필요한 광고 관리자 연결 단계를 모두 마치기 전까지는 버튼을 쓸 수 없어요. Meta 광고 계정을 선택했는지, Facebook 페이지가 연결된 상태로 표시되는지 확인하세요.

### 필드 매핑은 왜 중요한가요?
필드 매핑은 Facebook 폼 응답을 하이퍼클래스 CRM의 해당 필드와 연결해 줘요. 매핑을 제대로 해 두면 이름, 이메일, 전화번호, 직접 만든 질문의 답변 같은 정보가 알맞은 연락처 필드에 저장돼요.

### 캠페인에 Instagram 계정을 사용할 수 있나요?
네. 사용할 수 있는 Instagram 계정이 있으면 광고 세트 단계에서 선택할 수 있어요. Instagram 계정이 연결되어 있지 않으면, 캠페인 동작은 사용할 수 있는 Meta 설정과 선택한 게재 위치에 따라 달라질 수 있어요.

### Facebook 리드 광고 제출로 워크플로우를 실행할 수 있나요?
네. Facebook 연동과 리드 동기화를 설정해 두면, Facebook 리드 광고 제출 내용을 하이퍼클래스 자동화에 쓸 수 있어요. 워크플로우 트리거 **Facebook Lead Form Submitted**(Facebook 리드 폼 제출)도 그중 하나예요.
