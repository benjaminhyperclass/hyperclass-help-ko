# 시작하기 - 개인 이메일 연결

여러 받은편지함을 오가며 고객 대화를 챙기기 번거로울 때, Gmail이나 Outlook 받은편지함을 하이퍼클래스에 연결해 보세요. 고객과 주고받은 이메일을 한곳에서 볼 수 있어서 중요한 후속 연락을 놓치지 않아요.

## Gmail 또는 Outlook 연결하기

받은편지함은 아래 순서로 연결해요.

1. **설정 > 내 프로필 > 이메일 (양방향 동기화)** 로 이동하세요.
2. **Gmail** 또는 **Outlook**을 선택하고 **연결**을 클릭하세요.

   ![이메일 서비스를 선택하고 연결을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046886503/original/wlIzt4ohhqao3OMU4ruXMtXaEn8TD4dRXg.png?1747694876)
3. 안내에 따라 권한을 허용하세요. 안전하게 연결돼요.

   ![권한 허용 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046886508/original/QeM2ih-tIpDggV2SEmCbDnF2TXxV7IVVlA.png?1747694925)

### 함께 보면 좋은 문서

- Gmail 양방향 이메일 동기화 설정하기
- Outlook 양방향 이메일 동기화

다음으로 하이퍼클래스 안에서 바로 메시지를 보내 보세요. 작업이 한결 편해져요.

연결 중 문제가 생겼다면 'Email Failure: Insufficient Permission for 2-Way Sync' 문서를 참고하세요.

## 연결한 이메일 사용하기

받은편지함을 연결했다면 하이퍼클래스에서 바로 이메일을 보낼 수 있어요. 아래 순서로 보내 보세요.

1. **대화**로 이동하세요.
2. 연필과 종이 모양 아이콘인 **Create New Message**(새 메시지 만들기)를 클릭하세요.
3. **Direct Message**(다이렉트 메시지)를 선택하세요.

   ![다이렉트 메시지를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046886699/original/2RmZnJEROfqY_iXzlGMbjIQTtVQXtu-zaQ.png?1747695680)
4. 연락처를 선택하고 **계속**을 클릭하세요.

   ![연락처를 선택하고 계속을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046886724/original/skyZC4rN3t9yD9qwALmBqjA6UVIh0R5GcQ.png?1747695777)
5. **보낸 사람** 필드에 연결한 이메일 주소가 자동으로 입력돼요.

   ![보낸 사람 필드에 연결한 이메일 주소가 입력된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046886742/original/LACGHPQyZi4BUtuW-86xpEQdzqOK_Y6xtw.png?1747695895)

이메일은 하이퍼클래스에서 개인 받은편지함으로, 개인 받은편지함에서 하이퍼클래스로 양방향으로 동기화돼요. 두 곳의 내용이 항상 같게 유지돼요.

다음으로 응답과 워크플로우를 자동화하는 방법도 살펴보세요. 고객과 더 쉽게 소통할 수 있어요.
