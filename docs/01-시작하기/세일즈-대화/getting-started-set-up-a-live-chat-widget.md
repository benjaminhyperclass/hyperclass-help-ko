# 시작하기 - 라이브 채팅 위젯(Live Chat Widget) 설정하기

하이퍼클래스의 채팅 위젯(Chat Widget)을 사용하면 웹사이트에 다양한 채팅 경험을 추가할 수 있어요. 이 가이드에서는 웹사이트 방문자가 팀원 또는 대화 AI(Conversation AI)와 실시간으로 대화를 시작할 수 있는 라이브 채팅 위젯을 만드는 방법을 안내해 드려요. 또한 위젯을 커스터마이징하고 하이퍼클래스 웹사이트(Website)나 퍼널(Funnel)에 추가하는 방법도 함께 알아볼게요.

## 라이브 채팅 위젯 만들기

웹사이트에 라이브 채팅을 추가하려면 **채팅 위젯** 섹션에서 새 위젯을 만들고 채팅 유형으로 **Live Chat(라이브 채팅)**을 선택하세요.

- **Sites(사이트) > Chat Widget(채팅 위젯)** 메뉴로 이동합니다.

- **New(신규)**를 클릭하면 다음 중 하나를 선택할 수 있어요: All-in-one chat(올인원 채팅), SMS / Email chat(SMS/이메일 채팅), Live chat(라이브 채팅), WhatsApp(왓츠앱)

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078737592/original/A_CPwrjS-U_f-QoywQ3FE3AxrC4r98FzuQ.png?1787081674)

- **Live Chat**을 선택합니다.

- 브랜드에 맞게 위젯을 커스터마이징합니다.

- **Save(저장)**를 클릭합니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960759/original/SRZNNj26lxreHm5VbkHahfNcCrcphc350g.png?1747784131)

- **Get Code(코드 가져오기) > Copy(복사)**를 클릭합니다.

- 제공된 임베드 코드를 복사합니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960766/original/VoU2x6UeSm_BfBCXsNEwBdH-IvD1n80R3Q.png?1747784179)

더 알아보기

- [라이브 채팅(Live Chat)](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000001320) - 라이브 채팅 대화가 하이퍼클래스 대화(Conversations) 메뉴로 어떻게 전달되고 관리되는지 알아보세요.
- [채팅 위젯 커스터마이징 개요](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000002960) - 채팅 위젯의 외관과 동작을 커스터마이징하는 추가 옵션을 살펴보세요.
- [채팅 위젯 시작하기](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000004102) - 사용 가능한 모든 채팅 위젯 유형, 설정 옵션, 커스터마이징 설정에 대해 알아보세요.

**다음으로**, 새로 만든 위젯을 어떻게 배포할지 결정할 차례예요! 어떤 방법들이 있는지 살펴볼게요.

## 임베드 코드로 라이브 채팅 위젯 배포하기

이미 웹사이트나 퍼널에 스크립트를 직접 추가하는 방법에 익숙하신가요? 좋아요! 사이트 편집기에 채팅 위젯을 직접 임베드하는 방법은 아주 간단해요. 아래 단계를 따라해 보세요.

- **Sites(사이트) > Websites(웹사이트)** 또는 **Sites(사이트) > Funnels(퍼널)** 메뉴로 이동합니다.

- 원하는 웹사이트나 퍼널을 찾아 편집 화면을 엽니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960787/original/gl7U7-ugo-EDySww14EHX-4Gj2WR2rk96w.png?1747784281)

- 편집기에서 **Tracking Code(추적 코드)** 아이콘(</>)을 클릭합니다.

- 복사해둔 채팅 위젯 코드를 붙여넣습니다.

- **Save(저장)**를 클릭합니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960800/original/7j7RzpFPTEufQWAwRrPbk8r82cQKIsBZpg.png?1747784365)

**더 알아보기**

- [추가 설치 방법과 문제 해결은 하이퍼클래스 채팅 위젯 설치 방법 문서를 참고하세요](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/48000984860).

잘하셨어요! **다음으로**, 위젯이 원활하게 작동하는지 테스트해 보시는 걸 추천드려요.

## 설정 메뉴로 라이브 채팅 위젯 배포하기

좀 더 간단한 방법을 선호하시나요? 코드를 직접 다루는 게 부담스럽다면 웹사이트 설정을 통해 위젯을 배포하는 방법이 훨씬 편리해요. 함께 살펴볼게요.

- **Sites(사이트) > Websites(웹사이트)** 또는 **Sites(사이트) > Funnels(퍼널)** 메뉴로 이동합니다.

- 원하는 웹사이트나 퍼널을 찾아 설정 화면을 엽니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960805/original/qO6x3foY4mdlFGpt9mJMtShG_K95UyCF2A.png?1747784390)

- **Chat Widget(채팅 위젯)** 섹션에서 만들어둔 **라이브** 채팅 위젯을 선택합니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960820/original/w-Ubwt6xqJS_-CIIhHTfhfcnFa96K3PU5g.png?1747784475)

- **Save(저장)**를 클릭합니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960834/original/1BsYAyKDH_J3qdvsMEAcrssP0JqZCeQLFA.png?1747784529)

축하드려요! 이제 설정이 모두 끝났어요. 다음으로는 고급 커스터마이징 옵션을 살펴보면서 브랜드만의 독특한 채팅 경험을 만들어보는 건 어떨까요?
