# 새 코스 편집기로 멤버십 코스 편집하기

**멤버십**의 새 코스 편집기는 코스를 만들고 관리할 수 있는 더 넓고 집중하기 좋은 작업 공간이에요. 큰 편집 창이 열리고 코스 전체 구조가 계속 보여서, 화면을 오갈 일이 줄어요.

## 새 코스 편집기란?

새 코스 편집기는 **멤버십**의 코스 편집 화면을 새로 바꾼 버전이에요. 다음과 같이 구성돼 있어요.

- 화면 대부분을 차지하는 큰 편집 창
- 코스의 전체 구조를 보여 주는 왼쪽 코스 맵
- 코스 안에서 내 위치를 알려 주는 맨 위의 경로 표시줄(브레드크럼)

## 새 코스 편집기의 장점

- 방해 요소가 적어요: 다른 화면 요소를 가려서 콘텐츠에 집중할 수 있어요.
- 이동이 빨라요: 코스 맵에서 원하는 강의나 퀴즈로 바로 이동할 수 있어요.
- 정리하기 쉬워요: 개별 항목을 편집하는 동안에도 코스 개요가 계속 보여요.
- 현재 위치를 알 수 있어요: 경로 표시줄에 코스 안에서 지금 어디에 있는지 나와요.
- 구조를 빠르게 바꿀 수 있어요: 끌어서 놓기로 콘텐츠 순서를 바꾸고, 섹션을 접거나 펼 수 있어요.

## 새 코스 편집기로 멤버십 코스 편집하기

#### 1단계. 코스 편집기 열기

1. **멤버십**으로 이동해 **코스**를 여세요.
2. 편집할 코스를 선택하세요.
3. 편집기를 여세요. 편집기가 큰 작업 공간으로 열려요.

#### 2단계. 화면 구성 이해하기

편집기가 열리면 다음 두 영역이 보여요.

- 왼쪽 패널(**Course Map**, 코스 맵): 코스 구조가 목차처럼 보여요.
- 메인 편집 영역: 선택한 항목이 이곳에 열려서 편집할 수 있어요.

#### 3단계. 코스 콘텐츠 순서 바꾸기 (끌어서 놓기)

1. **Course Map**에서 항목을 클릭한 채로 새 위치로 끌어요.
2. 원하는 위치에 놓으세요.

#### 4단계. 섹션 접기와 펼치기

- 모듈이나 하위 섹션을 접으면 한 영역에 집중할 수 있어요.
- 전체를 보고 싶을 때는 다시 펼치세요.

![코스 맵에서 섹션을 접고 펼치는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068700685/original/b38UskLFsBEejjWMn0UQfafRhwwg1wIbKg.gif?1775653066)

#### 5단계. 상태 표시와 빠른 작업 사용하기

**Course Map**에는 콘텐츠 상태가 표시될 수 있어요. 예를 들면 게시됨, 초안, 잠김 같은 상태예요. 빠른 작업도 쓸 수 있어요. 예를 들면 **편집**, **삭제**, **공개 범위** 변경이에요.

## 자주 묻는 질문

### 새 편집기가 예전처럼 여러 페이지를 오가며 편집하던 방식을 대체하나요?

새 편집기는 코스 맵과 편집 영역을 한 화면에 함께 보여 줘서, 페이지를 오가는 일을 줄이도록 만들어졌어요.

### 코스를 만드는 중에 단계 사이를 자유롭게 이동할 수 있나요?

업데이트된 코스 만들기 과정에는 진행 표시줄이 있고, 단계를 클릭해서 이동할 수 있어요. 뒤로 가거나, 단계를 건너뛰거나, 완료한 단계로 바로 이동할 수 있어요.

### 모듈과 강의 순서를 바꿀 수 있나요?

네. 코스 맵에서 끌어서 놓기로 순서를 바꿀 수 있어요.

### 코스 맵에 나오는 "locked"(잠김)는 무슨 뜻인가요?

코스 맵에는 "locked"(잠김) 콘텐츠가 상태로 표시될 수 있어요.

### 속도가 빨라지나요?

릴리스 노트에 따르면 로딩, 캐싱, 상태 처리가 개선되어 주요 페이지와 편집기 동작이 훨씬 빨라졌어요.
