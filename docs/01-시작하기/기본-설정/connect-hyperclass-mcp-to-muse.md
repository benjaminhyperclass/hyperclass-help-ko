# 하이퍼클래스 MCP를 Muse에 연결하기

하이퍼클래스 MCP는 이제 Muse의 공식 앱으로 제공돼요. Muse가 Model Context Protocol(MCP)을 통해 승인된 하이퍼클래스 CRM 기능을 사용할 수 있게 해 줘요. 이 문서에서는 연결 방식과 OAuth 권한, 설정 순서를 안내해요.

## 하이퍼클래스 MCP for Muse란?

하이퍼클래스 MCP for Muse는 Muse와 하이퍼클래스 사이에 안전한 연결을 만들어요. 이 연결로 Muse는 MCP를 통해 지원되는 CRM 서비스를 사용할 수 있어요.

MCP는 호환되는 AI 클라이언트가 사용 가능한 기능을 찾고, 정보를 가져오고, 승인된 작업을 실행하는 표준 방식이에요. 그래서 CRM 기능마다 따로 연동을 만들 필요가 없어요. 하이퍼클래스 MCP 서버는 연락처, 대화, 캘린더, 기회, 결제, 로케이션(Locations), 커스텀 필드 같은 CRM 서비스를 지원해요.

Muse 연동은 전용 하이퍼클래스 MCP 엔드포인트에서 OAuth로 인증해요.

`https://services.leadconnectorhq.com/mcp/muse/v2/`

인증하는 중에 Muse가 연결할 수 있는 CRM 서브 계정을 고르고, 요청된 스코프를 승인해요. 이 스코프에 따라 Muse가 접근할 수 있는 하이퍼클래스 데이터와 기능이 정해져요.

Muse가 연결하는 방식은 일반 MCP 서버 설정과 달라요. 일반 설정은 [하이퍼클래스 MCP 서버 설정 및 사용 방법](../../13-AI-Employee/MCP-Server/how-to-setup-and-use-the-hyperclass-mcp-server.md)에서 확인할 수 있어요.

## 하이퍼클래스 MCP for Muse의 장점

하이퍼클래스를 Muse에 연결하면 지원되는 CRM 기능을 Muse에서 쓰게 하면서도 요청되는 권한을 직접 확인할 수 있어요. OAuth 스코프는 설정할 때 승인한 하이퍼클래스 리소스와 작업으로만 접근을 제한해 줘요.

- OAuth 기반 연결: Muse 연결용 자격 증명을 직접 설정하지 않고 하이퍼클래스를 통해 인증해요.
- 서브 계정 선택: 인증하는 중에 연결할 CRM 서브 계정을 고를 수 있어요.
- 세분화된 접근 제어: Muse가 접근할 수 있는 하이퍼클래스 리소스와 작업을 OAuth 스코프로 승인해요.
- 폭넓은 CRM 지원: 38개 CRM 도메인에서 600개 이상의 지원 작업을 사용할 수 있어요.
- 통합된 MCP 접근: 지원되는 작업이 네 가지 통합 MCP 도구로 제공돼서 Muse가 하이퍼클래스를 더 간단하게 다룰 수 있어요.
- 권한 확인: 하이퍼클래스의 OAuth 화면에 요청된 스코프가 표시돼요. 외부 애플리케이션이 요청하는 권한을 승인하기 전에 검토할 수 있어요.

## Muse에서 OAuth 권한이 작동하는 방식

OAuth를 쓰면 외부 애플리케이션에 계정 자격 증명을 직접 알려 주지 않고도 특정 하이퍼클래스 리소스에 대한 접근을 요청받을 수 있어요. 승인하기 전에 요청된 스코프를 살펴보면 Muse가 하이퍼클래스의 어떤 영역을 쓰게 되고, 어떤 작업이 가능한지 알 수 있어요.

하이퍼클래스를 Muse에 연결하면 OAuth 인증 과정에서 요청된 권한, 즉 OAuth 스코프가 표시돼요. 하이퍼클래스의 OAuth 동의 화면은 요청된 권한과 그 권한으로 할 수 있는 일을 접근 권한을 부여하기 전에 보여 줘요. 자세한 내용은 [API 보안 - 마켓플레이스 앱의 OAuth 동의](../../27-앱-마켓/Get-Started-w/App-Marketplace/api-security-oauth-consent-for-marketplace-apps.md)를 참고하세요.

OAuth 스코프와 하이퍼클래스 사용자 권한은 서로 달라요.

- OAuth 스코프는 Muse 연결이 접근할 수 있는 범위를 정해요.
- 사용자 역할과 권한은 개별 하이퍼클래스 사용자가 서브 계정 안에서 접근할 수 있는 범위를 정해요.
- 할당된 데이터 제한은 하이퍼클래스 사용자가 보거나 관리할 수 있는 레코드를 더 좁힐 수 있어요. 하이퍼클래스는 관리자(Admin)와 사용자(User) 역할, 세분화된 모듈 권한, 할당된 데이터 제한을 지원해요.

사용자 역할과 권한은 [서브 계정: 사용자 역할, 권한 및 할당된 데이터](../../11-설정/사용자-설정/user-roles-permissions-and-assigned-data-subaccount.md)에서 자세히 볼 수 있어요.

연결을 승인하기 전에 항상 요청된 OAuth 스코프를 확인하세요.

## 지원되는 하이퍼클래스 작업

MCP를 쓰면 호환되는 AI 클라이언트가 CRM 기능마다 따로 연동하지 않고도 표준 연결로 하이퍼클래스 서비스를 다룰 수 있어요. Muse 연동은 네 가지 통합 MCP 도구로 38개 CRM 도메인의 600개 이상 지원 작업을 제공해요. 실제로 쓸 수 있는 범위는 승인한 OAuth 스코프에 따라 정해져요.

하이퍼클래스의 일반 MCP 서버가 지원하는 서비스는 다음과 같아요.

- 연락처
- 대화
- 캘린더
- 기회
- 결제
- 로케이션(Locations)
- 커스텀 필드

하이퍼클래스 MCP 문서에 따르면, 적절한 접근 권한이 있을 때 MCP 호환 클라이언트는 레코드 조회, 데이터 업데이트, 메시지 보내기, 기회 검색, 캘린더 정보 확인 같은 지원 작업을 할 수 있어요.

Muse에서 쓸 수 있는 작업은 연결에 부여한 권한에 따라 달라요. 필요한 스코프만 승인하면 사용 목적에 맞는 범위로 접근을 유지할 수 있어요.

## 하이퍼클래스 MCP를 Muse에 설정하기

설정을 마치려면 하이퍼클래스 OAuth 인증 과정을 끝까지 진행하고, 올바른 CRM 서브 계정을 고르고, Muse가 요청한 스코프를 확인해야 해요. 설정 중에 이 내용을 확인하면 Muse가 의도한 수준으로만 CRM에 접근해요.

1. Muse를 열고 앱 또는 MCP 서비스를 연결하는 옵션을 찾으세요.
2. 연결할 앱으로 **하이퍼클래스**를 선택하세요.
3. 하이퍼클래스 MCP 연결 정보를 입력하라는 안내가 나오면 Muse 전용 엔드포인트를 입력하세요.

   `https://services.leadconnectorhq.com/mcp/muse/v2/`
4. 하이퍼클래스 인증을 시작하세요.
5. 로그인하라는 안내가 나오면 하이퍼클래스에 로그인하세요.
6. 하이퍼클래스 OAuth 인증 화면을 확인하세요.

   하이퍼클래스의 OAuth 동의 화면에는 애플리케이션이 요청한 스코프가 표시돼요. 접근을 승인하기 전에 요청된 권한을 확인할 수 있어요.
7. Muse에 연결할 CRM 서브 계정을 선택하세요.
8. 요청된 OAuth 스코프를 검토하고, Muse에 주려는 접근 범위와 맞는지 확인하세요.
9. 인증 요청을 승인하세요.
10. Muse로 돌아가서 하이퍼클래스가 연결됨으로 표시되는지 확인하세요.

이제 Muse는 승인한 스코프에서 제공하는 하이퍼클래스 작업을 쓸 수 있어요.

## 자주 묻는 질문

### 하이퍼클래스를 Muse에 연결하려면 비공개 연동 토큰이 필요한가요?
이 문서에서 설명하는 Muse 연결은 전용 하이퍼클래스 MCP 엔드포인트와 OAuth 인증 과정을 사용해요. 다른 하이퍼클래스 MCP 클라이언트 설정에 나오는 일반적인 토큰 방식 대신 Muse에서 안내하는 OAuth 과정을 따르세요. 토큰 방식은 [하이퍼클래스 MCP 서버 설정 및 사용 방법](../../13-AI-Employee/MCP-Server/how-to-setup-and-use-the-hyperclass-mcp-server.md)에서 확인할 수 있어요.

### Muse가 쓸 수 있는 하이퍼클래스 작업은 무엇으로 정해지나요?
인증할 때 승인한 OAuth 스코프에 따라 쓸 수 있는 작업이 정해져요. 스코프는 외부 애플리케이션이 접근할 수 있는 하이퍼클래스 리소스와 작업을 정의해요.

### Muse가 하이퍼클래스의 데이터를 변경할 수도 있나요?
하이퍼클래스 MCP 서버는 필요한 접근 권한이 있을 때 정보 조회와 데이터 업데이트를 포함한 지원 작업 실행을 모두 지원해요. Muse에서 특정 작업을 쓸 수 있는지는 승인한 스코프와 지원되는 작업인지에 따라 달라요.

### 연결하기 전에 OAuth 스코프를 왜 확인해야 하나요?
OAuth 스코프는 외부 애플리케이션이 요청하는 하이퍼클래스 리소스와 작업을 보여 줘요. 인증을 마치기 전에 스코프를 확인하면 어떤 접근 권한을 부여하는지 알 수 있어요.

### 연결하려는 하이퍼클래스 서브 계정이 보이지 않아요.
먼저 인증을 진행하는 하이퍼클래스 사용자가 해당 서브 계정에 접근할 수 있는지 확인하세요. 개별 서브 계정에서 사용자가 접근할 수 있는 범위는 하이퍼클래스 사용자 역할과 권한으로 정해져요.

### OAuth 스코프와 하이퍼클래스 사용자 권한은 같은 건가요?
아니에요. OAuth 스코프는 외부 애플리케이션에 부여되는 권한을 정하고, 하이퍼클래스 사용자 역할과 권한은 개별 사용자가 서브 계정 안에서 접근할 수 있는 범위를 정해요.

### 나중에 Muse의 접근 권한을 취소할 수 있나요?
하이퍼클래스는 연결된 애플리케이션을 정기적으로 검토하고, 더 이상 필요 없는 애플리케이션의 접근 권한은 취소하길 권해요. 연결된 애플리케이션의 접근 권한은 하이퍼클래스의 **설정 > Connected Apps**(연결된 앱)에서 확인할 수 있어요.

### Muse 연결은 600개 이상의 하이퍼클래스 작업을 모두 자동으로 받나요?
아니에요. 이 연동은 38개 CRM 도메인에서 600개 이상의 작업을 지원하지만, 연결에서 쓸 수 있는 작업은 인증할 때 승인한 스코프에 따라 달라요.
