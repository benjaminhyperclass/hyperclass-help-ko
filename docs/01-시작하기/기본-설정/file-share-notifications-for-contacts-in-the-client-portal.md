# 클라이언트 포털 연락처를 위한 파일 공유 알림

하이퍼클래스는 클라이언트 포털(Client Portal)을 통해 새 파일이 공유되면 연락처(Contacts)에게 자동으로 알려드려요. 이 알림 덕분에 연락처는 비즈니스로부터 별도의 메시지를 받지 않아도 중요한 문서, 계약서, 인보이스, 그리고 기타 공유 파일을 쉽게 찾을 수 있어요. 연락처는 지원되는 클라이언트 포털 환경 전반에서 알림을 확인하고, 원하는 방식으로 업데이트를 받을 수 있도록 알림 환경설정을 관리할 수 있어요.

## 파일 공유 알림이란?

파일 공유 알림은 하이퍼클래스 사용자가 클라이언트 포털을 통해 파일을 제공할 때 연락처에게 전달되는 알림이에요. 이를 통해 비즈니스는 고객에게 정보를 계속 알릴 수 있고, 연락처는 새로 공유된 문서를 바로 확인하고 접근할 수 있어요.

사용자가 연락처 상세(레코드)에서 파일을 공유하면서 클라이언트 포털에 업로드/공유하는 옵션을 활성화하면, 하이퍼클래스는 해당 연락처를 위한 알림을 생성해요.

연락처의 알림 환경설정에 따라, 연락처는 다음을 받을 수 있어요:

- 클라이언트 포털 내 인앱 알림
- 지원되는 화이트라벨 모바일 앱을 통한 푸시 알림

표준 파일 공유 알림을 생성하기 위해 별도의 워크플로우(Workflow)가 필요하지는 않아요.

## 파일 공유 알림의 주요 장점

파일 공유 알림은 중요한 파일이 준비되는 즉시 연락처에게 알려줌으로써 커뮤니케이션을 개선해줘요. 이를 통해 수동으로 후속 조치를 할 필요가 줄어들고, 연락처가 공유된 정보에 더 빠르게 대응할 수 있어요.

- **자동 고객 업데이트:** 클라이언트 포털을 통해 파일이 공유되면 연락처에게 알림이 전달돼요.
- **파일 가시성 향상:** 업로드 후 중요한 문서를 놓칠 가능성이 줄어들어요.
- **수동 리마인더 감소:** 파일을 공유할 때마다 비즈니스가 별도의 메시지를 보낼 필요가 없어요.
- **크로스 플랫폼 접근:** 클라이언트 포털 웹 환경과 화이트라벨 모바일 앱 모두에서 알림이 지원돼요.
- **연락처가 직접 설정하는 환경설정:** 연락처는 인앱 알림과 푸시 알림 수신 여부를 직접 선택할 수 있어요.
- **더 나은 고객 경험:** 시기적절한 알림으로 문서 공유가 더 체계적이고 신뢰할 수 있게 느껴져요.

## 파일 공유 알림 작동 방식

알림 흐름을 이해하면 어떤 작업이 알림을 생성하는지, 파일이 공유된 후 연락처가 무엇을 기대할 수 있는지 파악하는 데 도움이 돼요.

파일 공유 알림은 하이퍼클래스 사용자가 다음 작업을 수행할 때 트리거(Trigger)돼요:

- 연락처 상세(레코드)를 엽니다.
- 새 파일을 업로드하거나 기존 파일을 선택합니다.
- 클라이언트 포털에 파일을 공유하거나 업로드하는 옵션을 활성화합니다.
- 파일을 저장합니다.

파일이 공유된 후:

- 연락처는 인앱 알림을 받아요.
- 푸시 알림이 활성화되어 있다면 연락처는 푸시 알림도 받을 수 있어요.
- 공유된 파일은 연락처의 클라이언트 포털 환경에서 확인할 수 있게 돼요.

파일 공유 알림은 지원되는 파일 공유 프로세스를 통해 자동으로 생성돼요. 이는 Smart Push Notifications 같은 워크플로우 액션(Action)으로 만드는 커스텀 알림과는 별개예요.

## 지원되는 알림 채널

알림 채널은 연락처가 새로 공유된 파일에 대한 알림을 어디서 확인하는지를 결정해요. 각 채널을 이해하면 비즈니스가 웹 사용자와 모바일 사용자 모두에게 정확한 기대치를 설정하는 데 도움이 돼요.

파일 공유 알림은 다음 채널을 지원해요:

- **인앱 알림:** 클라이언트 포털 알림 환경 내에 표시돼요.
- **푸시 알림:** 연락처가 푸시 알림을 활성화한 경우, 지원되는 화이트라벨 모바일 앱을 통해 전달돼요.

푸시 알림 전달은 연락처의 모바일 기기 권한 설정에도 영향을 받을 수 있어요. 기기 수준에서 푸시 알림이 비활성화되어 있어도, 연락처가 클라이언트 포털을 열면 알림을 확인할 수 있어요.

## 연락처와 파일을 공유하는 방법

지원되는 클라이언트 포털 흐름을 통해 파일을 공유하면 연락처가 문서에 접근할 수 있고 관련 알림도 받을 수 있어요.

- 하이퍼클래스에서 연락처(Contacts) 메뉴로 이동합니다.
- 파일을 받을 연락처를 엽니다.
- 오른쪽 네비게이션 패널에서 Files 영역을 엽니다.
- 새 파일을 업로드하거나 기존 파일을 선택합니다.
- Upload to Client Portal 옵션을 활성화합니다.
- 파일을 저장합니다.

![파일 업로드 및 클라이언트 포털 공유 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076586315/original/IaY1hY1XZ0SqagMvSu0-y4BrjOOeCF0WzA.png?1784722031)

파일이 저장되고 공유되면, 하이퍼클래스는 연락처에게 인앱 알림을 보내고, 활성화되어 있다면 푸시 알림도 함께 보내요.

**중요:** 하이퍼클래스는 업로드된 파일과 Documents & Contracts 레코드에 대해 서로 다른 라벨을 사용할 수 있어요. 여기서 설명하는 파일 공유 알림은 지원되는 연락처 및 클라이언트 포털 파일 공유 프로세스를 통해 공유된 파일에 적용돼요.

## 연락처가 알림 환경설정을 관리하는 방법

알림 환경설정을 통해 연락처는 파일 관련 업데이트를 받는 방식을 직접 제어할 수 있어요. 이 설정을 최신 상태로 유지하면 연락처가 원치 않는 알림은 피하면서도 원하는 채널로 중요한 알림은 계속 받을 수 있어요.

- 클라이언트 포털에 로그인합니다.
- Settings(설정)로 이동합니다.
- Notification Preferences를 엽니다.
- In-app Notifications와 Push Notifications를 활성화하거나 비활성화합니다.
- 변경 사항을 저장합니다.

![클라이언트 포털 알림 환경설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076577249/original/QkWaxu198LQMLrMP9-T6Y6FrEJCfunUh4A.png?1784717483)

알림을 비활성화해도 이미 공유된 파일에 대한 연락처의 접근 권한은 그대로 유지돼요. 이 설정은 지원되는 활동에 대한 알림 방식만 변경할 뿐이에요.

## 파일 공유 알림 문제 해결

알림 전달 여부는 파일이 올바른 클라이언트 포털 프로세스를 통해 공유되었는지, 그리고 연락처의 알림 설정에 따라 달라져요. 하이퍼클래스 레코드와 연락처의 접근 권한을 모두 확인하면 알림 누락의 일반적인 원인을 파악하는 데 도움이 돼요.

연락처가 알림을 받지 못한 경우, 다음을 확인해 보세요:

- 파일을 저장하기 전에 Upload to Client Portal이 활성화되어 있었는지 확인합니다.
- 연락처 상세(레코드)에서 파일이 공유됨으로 표시되는지 확인합니다.
- 연락처가 클라이언트 포털에 접근 권한이 있는지 확인합니다.
- 연락처에게 클라이언트 포털 알림 환경설정을 확인해 달라고 요청합니다.
- 화이트라벨 모바일 앱에서 푸시 알림이 활성화되어 있는지 확인합니다.
- 모바일 기기에서 해당 앱의 알림을 허용하고 있는지 확인합니다.
- 연락처가 올바른 클라이언트 포털 계정에 로그인되어 있는지 확인합니다.
- 연락처에게 클라이언트 포털 내 알림 벨을 확인해 달라고 요청합니다.

기기에서 푸시 알림을 차단하고 있어도 인앱 알림은 여전히 확인할 수 있어요.

## 자주 묻는 질문

**Q: 파일 공유 알림을 위해 워크플로우를 따로 만들어야 하나요?**

A: 아니요. 지원되는 클라이언트 포털 파일 공유 프로세스를 통해 파일이 공유되면 하이퍼클래스가 자동으로 알림을 생성해요.

**Q: 어떤 알림 채널이 지원되나요?**

A: 파일 공유 알림은 인앱 알림과 푸시 알림을 지원해요. 푸시 알림은 연락처가 직접 활성화해야 해요.

**Q: 파일이 공유되면 이메일이나 SMS(문자) 알림도 발송되나요?**

A: 공개된 정보에 따르면 지원되는 채널은 인앱 알림과 푸시 알림이에요. 이메일이나 SMS는 이 기능에 포함되지 않아요.

**Q: 연락처가 파일 공유 알림을 비활성화할 수 있나요?**

A: 네. 연락처는 클라이언트 포털 알림 환경설정에서 인앱 알림과 푸시 알림 설정을 직접 관리할 수 있어요.

**Q: 알림을 비활성화하면 공유된 파일 접근 권한도 사라지나요?**

A: 아니요. 알림 환경설정은 알림 여부만 제어할 뿐, 이미 공유된 파일에 대한 접근 권한에는 영향을 주지 않아요.

**Q: 연락처가 인앱 알림은 받았는데 푸시 알림은 왜 받지 못했나요?**

A: 클라이언트 포털 환경설정, 모바일 앱, 또는 연락처의 기기 설정에서 푸시 알림이 비활성화되어 있을 수 있어요.
