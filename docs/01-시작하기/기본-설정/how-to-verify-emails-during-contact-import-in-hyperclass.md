# 연락처 가져오기 중 이메일 검증하기

연락처를 가져오는 과정에서 이메일 주소를 함께 검증하면, 이메일을 보내기 전에 잘못된 주소를 미리 찾을 수 있어요. 가져오기와 검증을 한 번에 시작할 수 있고, 진행 상황은 **일괄 작업**에서 확인할 수 있어요.

## 연락처 가져오기 중 이메일 검증이란?

연락처 가져오기 중 이메일 검증은 연락처를 하이퍼클래스로 가져올 때 이메일 검증을 함께 시작하는 기능이에요. 가져오는 중에 이메일 주소를 확인하므로, 이메일 캠페인 등에 연락처 목록을 쓰기 전에 잘못됐을 가능성이 있는 주소를 찾을 수 있어요.

이 기능은 기존 연락처 가져오기의 마지막 단계에 선택용 체크박스를 추가해요. 연락처 가져오기와 이메일 검증을 따로 하지 않고 한 번에 설정할 수 있어요.

가져오기를 시작하고 나면 **일괄 작업**에서 진행 상황을 볼 수 있어요. 상태는 **처리 중**과 **완료**로 표시돼요.

{% hint style="warning" %}
이메일 검증은 잘못된 주소를 찾는 데 도움이 되지만, 모든 이메일이 받는 사람의 받은편지함에 도착한다는 뜻은 아니에요.
{% endhint %}

## 연락처 가져오기 중 이메일 검증의 장점

연락처가 들어오는 시점에 이메일 주소를 검증하면 데이터 품질이 좋아지고, 이메일 발송용 목록을 준비하는 수고도 줄어요. 문제를 더 일찍 찾아 더 믿을 수 있는 연락처 정보를 유지할 수 있어요.

- 이메일 전달률 개선: 이메일을 보내기 전에 잘못된 주소를 찾아, 발송 실패와 반송률을 줄이는 데 도움이 돼요.
- 더 깨끗한 연락처 목록: 가져오는 중에 문제가 있는 주소를 찾아 연락처 데이터 품질을 높일 수 있어요.
- 간단해진 가져오기 과정: 연락처 가져오기와 이메일 검증을 따로 관리하지 않고 한 흐름에서 시작해요.
- 수작업 감소: 연락처를 가져온 뒤 검증을 따로 시작하지 않아도 돼요.
- 발신자 평판 보호: 잘못된 주소로 이메일을 보내 발신자 평판이 나빠질 위험을 줄여요.
- 쉬운 진행 상황 확인: **일괄 작업**에서 **처리 중**과 **완료** 상태로 검증 진행 상황을 볼 수 있어요.

## 연락처 가져오기 중 이메일 검증이 동작하는 방식

이 기능은 기존 CSV 가져오기 과정에 선택 단계 하나를 더해요. 가져오기는 평소와 똑같이 진행되고, 시작하기 전에 검증 옵션만 추가로 나타나요.

### 이메일 검증 체크박스

연락처 가져오기의 마지막 단계에는 이메일 검증을 켜는 새 체크박스(**이메일 인증**)가 있어요. 이 체크박스를 선택하면 가져오기와 함께 이메일 검증이 시작돼요.

- 검증 옵션은 연락처 가져오기의 마지막 단계에 나타나요.
- 가져오기를 시작하기 전에 검증을 켤지 정할 수 있어요.
- 이메일 검증은 같은 흐름 안에서 시작돼요.
- 검증 진행 상황은 **일괄 작업**에서 확인할 수 있어요.

### 이메일 검증과 연락처 가져오기

이메일 검증은 이메일 주소가 이메일 발송에 쓸 수 있는 주소처럼 보이는지 확인해요.

예를 들어 주소 형식은 맞아도 사용하지 않거나 존재하지 않는 메일함일 수 있어요. 이메일 검증은 기본적인 CSV 형식 확인보다 한 단계 더 나아간 확인이에요.

연락처 데이터를 준비하는 방법은 [CSV 파일로 연락처 가져오기](../../02-연락처/importing-contacts-using-a-csv-file.md)를 참고하세요.

## 일괄 작업에서 이메일 검증 진행 상황 확인하기

**일괄 작업**은 연락처 가져오기 같은 작업과 진행 상황을 한곳에서 볼 수 있는 화면이에요. 가져오는 중에 이메일 검증을 켰다면 이곳에서 검증이 진행되는 모습과 끝난 시점을 확인할 수 있어요.

### 일괄 작업 열기

이메일 검증을 켜고 연락처 가져오기를 시작한 뒤, 아래 경로로 이동하세요.

**연락처 > 일괄 작업**

목록에서 확인하려는 작업을 찾아 상태를 살펴보세요.

검증 작업에는 다음 상태가 표시돼요.

| 상태 | 설명 |
| --- | --- |
| **처리 중** | 이메일 검증이 진행되고 있어요. |
| **완료** | 검증 처리가 끝났어요. |

### 일괄 작업 상세 내용 확인하기

**일괄 작업** 화면에서는 연락처 가져오기 작업을 추적하는 일반 리포팅 도구도 쓸 수 있어요. 작업 유형에 따라 다음과 같은 일을 할 수 있어요.

- 일괄 작업의 상태 확인
- 상태, 유형, 사용자, 날짜로 작업 필터링
- **통계 보기**를 선택해 제공되는 작업 통계 확인
- 문제 해결을 위해 제공되는 가져오기 오류 로그 다운로드

{% hint style="info" %}
검증 결과가 제공되는지와 그 형식은 일반 연락처 가져오기 통계와 다를 수 있어요. **완료** 상태는 처리가 끝났다는 뜻이고, 모든 이메일 주소가 검증을 통과했다는 뜻은 아니에요.
{% endhint %}

자세한 내용은 [연락처 & 스마트 리스트 일괄 작업](../../02-연락처/bulk-actions-for-contacts-smartlists.md)을 참고하세요.

## 연락처 가져오기 중 이메일 검증 켜기

가져오기 중에 이메일 검증을 켜면 연락처 정보를 하이퍼클래스에 올리면서 검증도 함께 시작할 수 있어요. CSV 파일을 올바르게 준비하고, 필드를 알맞게 연결하고, 검증 옵션을 선택하면 의도한 대로 가져오기가 설정돼요.

### 1단계: 연락처 화면으로 이동하기

1. 하이퍼클래스 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **연락처**를 선택하세요.
3. **가져오기**를 클릭해 가져오기 화면을 여세요.

   ![연락처 화면에서 가져오기 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083664092/original/QDuwDPlsFqMfFdcoics0VuGWO7hBK8PNfA.png?1792416406)

### 2단계: 가져올 연락처 선택하기

1. 연락처 정보가 들어 있는 CSV 파일을 업로드하세요.
2. 새 연락처 만들기나 기존 연락처 업데이트처럼, 알맞은 가져오기 옵션을 선택하세요.
3. 필드 연결 단계로 넘어가세요.

{% hint style="info" %}
연락처 가져오기는 CSV 파일을 지원해요. 가져오려는 연락처 정보가 파일에 모두 들어 있는지, **이메일** 열에 올바른 이메일 주소가 들어 있는지 확인하세요.

CSV 준비 방법은 [CSV로 연락처와 기회 가져오기](../../02-연락처/importing-contacts-and-opportunities-via-csv.md)를 참고하세요.
{% endhint %}

![CSV 파일 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083664285/original/Q06UgYWwhl1L4Mr2P3CkVYdonR7LICyQEg.png?1792416468)

![가져오기 옵션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083664531/original/iKUEOAeAht5_AyFIykWfODWYwVJUDMDvLQ.png?1792416518)

### 3단계: 연락처 필드 연결하기

1. CSV 파일에서 인식된 열을 확인하세요.
2. 각 열을 알맞은 하이퍼클래스 연락처 필드에 연결하세요.
3. 이메일 주소가 들어 있는 열이 **이메일**에 연결됐는지 확인하세요.
4. 나머지 필드 연결도 확인하세요.
5. 마지막 가져오기 단계로 넘어가세요.

필드를 올바르게 연결하면 가져온 정보가 알맞은 연락처 필드에 들어가요.

![CSV 열을 연락처 필드에 연결하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083665023/original/ohM1PSy6xuYgFPsoeTQVXlyhaPEwkU_8IA.png?1792416764)

![연결된 필드 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083664971/original/klbJCzjNa6QUZEFyzjAw89bz7KQEle89wA.png?1792416727)

### 4단계: 이메일 검증 켜기

1. 연락처 가져오기의 마지막 단계에서 가져오기 설정을 확인하세요.
2. 새로 생긴 **이메일 인증** 체크박스를 찾으세요.
3. 체크박스를 선택해 가져오는 중에 이메일 검증을 켜세요.
4. 나머지 가져오기 설정과 필요한 확인 항목을 살펴보세요.

이 옵션을 선택하면 연락처 가져오기와 함께 이메일 검증이 시작돼요.

![마지막 단계에서 이메일 인증 체크박스 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083665227/original/UaP7q14XklyIb3zl8fsVRCdUuXTEBp3sig.png?1792416854)

### 5단계: 연락처 가져오기 시작하기

1. 가져오기 설정이 맞는지 확인하세요.
2. 대량 가져오기를 시작하는 버튼을 클릭하세요.
3. 가져오기와 검증이 진행될 때까지 기다리세요.

옵션을 켜 두면 가져오기 흐름 안에서 이메일 검증이 시작돼요.

### 6단계: 검증 진행 상황 확인하기

1. **연락처 > 일괄 작업**으로 이동하세요.
2. 가져오기와 관련된 검증 작업을 찾으세요.
3. 작업 상태를 확인하세요.
4. 상태가 **처리 중**에서 **완료**로 바뀔 때까지 지켜보세요.
5. 확인할 수 있는 액션 상세 정보나 결과가 있으면 살펴보세요.

{% hint style="warning" %}
검증을 마쳤다고 해서 검증된 모든 주소가 이메일을 받아 준다는 뜻은 아니에요. 가져온 연락처에 이메일을 보내기 전에 적절한 수신 동의를 받는 등, 이메일 전달률을 지키는 모범 사례를 계속 따르세요.
{% endhint %}

## 자주 묻는 질문

### 이메일 검증을 하면 이메일이 받는 사람의 받은편지함에 꼭 도착하나요?

아니요. 이메일 검증은 잘못됐을 가능성이 있는 주소를 찾는 데 도움을 줄 뿐이에요. 실제 전달 여부는 발신자 평판, 받는 쪽 메일 서버 설정, 스팸 필터, 메일함 상태 같은 여러 요인에도 달려 있어요.

### 연락처 가져오기 중 이메일 검증은 이메일을 보내기 전에 자동으로 하는 검증과 같은 건가요?

아니요. 가져오기 중 검증은 연락처 가져오기 흐름에서 시작해요. 하이퍼클래스는 이메일을 보내기 전에 하는 검증과 워크플로우 액션을 통한 검증도 지원해요. 모두 이메일 주소를 확인하는 방법이지만 시작하는 곳이 달라요. 자세한 내용은 하이퍼클래스 이메일 인증 켜기와 재청구와 [워크플로우 액션 - 이메일 검증](../../07-워크플로우/액션/workflow-action-email-verification.md)을 참고하세요.

### 가져오는 중에 이메일 검증을 켜면 잘못된 연락처가 자동으로 삭제되나요?

이번 업데이트에서는 잘못된 이메일 주소가 있는 연락처를 가져오기에서 제외하는지, 아니면 검증 결과와 함께 그대로 두는지 밝히지 않았어요. 검증을 켜면 잘못된 연락처가 자동으로 삭제된다고 생각하지 마세요.

### 검증이 끝난 뒤 유효한 이메일 주소와 잘못된 이메일 주소를 정리한 리포트를 내려받을 수 있나요?

**일괄 작업**은 지원되는 작업에 대해 통계와 내려받을 수 있는 오류 로그를 제공해요. 가져오기 중 이메일 검증을 위한 별도 리포트가 제공되는지는 아직 확인되지 않았어요.

### 연락처와 기회를 함께 가져올 때도 이메일 검증을 쓸 수 있나요?

하이퍼클래스에서는 연락처와 기회를 함께 가져올 수 있어요. 하지만 이번 업데이트에서 확인된 내용은 연락처 가져오기에 새 검증 옵션이 생겼다는 것뿐이고, 함께 가져오는 경우에도 쓸 수 있는지는 따로 밝히지 않았어요.
