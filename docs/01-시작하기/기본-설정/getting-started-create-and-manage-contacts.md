# 시작하기 - 연락처 만들기와 관리하기

하이퍼클래스에서 연락처를 만들고, 편집하고, 더 이상 필요 없는 연락처를 삭제하는 방법을 안내해요. 연락처 기록이 어디에 쓰이는지와 자주 묻는 질문도 함께 정리했어요.

## 하이퍼클래스 연락처 관리란?

연락처를 만들고 관리하는 일은 CRM을 깔끔하고 쓸모 있게 유지하는 데 가장 중요한 부분이에요. 정확한 연락처 정보를 입력하고, 정보가 바뀌면 기록을 수정하고, 필요 없는 연락처를 지우면 팀이 믿을 수 있는 데이터로 일할 수 있어요.

{% hint style="info" %}
연락처 상세 페이지를 원하는 대로 바꾸는 방법은 '연락처 상세 페이지 사용자 지정' 문서를 참고하세요.
{% endhint %}

- 연락처 만들기: 새 사람이나 리드를 CRM에 추가해서 한곳에서 추적하고 관리해요.
- 연락처 정보 편집하기: 이름, 전화번호, 이메일 주소 같은 정보를 최신 상태로 유지해요.
- 오래된 기록 삭제하기: 더 이상 필요 없는 연락처를 지워서 데이터베이스를 정리해요.
- 더 나은 워크플로우 지원하기: 정확한 연락처 기록은 커뮤니케이션, 자동화, 리포팅을 개선하는 데 도움이 돼요.

---

## 새 연락처 만들기

새 연락처를 만들면 하이퍼클래스에서 리드나 고객을 바로 추적할 수 있어요. 처음부터 정보를 빠짐없이 정확하게 입력해 두면 대화 관리와 후속 연락, CRM 정리가 쉬워져요.

{% hint style="info" %}
폼이나 설문을 새 리드가 작성하면 연락처가 자동으로 만들어져요.
{% endhint %}

{% hint style="info" %}
연락처를 만들 때 보이는 필드는 계정 설정에 따라 다를 수 있어요. 필드가 더 필요하면 계정에 설정된 커스텀 필드를 사용하세요.
{% endhint %}

1. 왼쪽 메뉴에서 **연락처 > 스마트 리스트**로 이동하세요.
2. + **연락처 추가**를 클릭하세요.

   ![연락처 추가 버튼](https://jumpshare.com/share/4oC6X6thrMSY3rbKFCNg+/Screen+Shot+2026-07-02+at+19.19.57.png)
3. 연락처 정보를 입력하세요. 예를 들면 다음과 같아요.

   1. **First name**(이름)
   2. **Last name**(성)
   3. **이메일 주소**
   4. **전화번호**
   5. 필요한 경우 그 밖에 사용할 수 있는 필드
4. 새 연락처를 추가할 때 어떤 필드가 보일지 정하려면 **Customise Form**(폼 사용자 지정) 버튼을 클릭하세요.

   ![Customise Form 버튼](https://jumpshare.com/share/yzJcua2kJA7ieSVMwS0f+/Screen+Shot+2026-07-02+at+19.26.59.png)
5. 입력한 정보가 정확한지 확인하세요.
6. **저장**을 클릭하면 연락처가 만들어져요.

   ![연락처 저장 화면](https://jumpshare.com/share/TuoaWMki9y4HwVXnGmtg+/GIF+Recording+2026-07-02+at+19.25.01.gif)

## 기존 연락처 편집하기

고객 정보는 시간이 지나면서 바뀌어요. 연락처를 편집해서 기록을 정확하게 유지하면 커뮤니케이션이 좋아지고 실수가 줄어들며, 팀이 가장 최신 정보로 일할 수 있어요.

{% hint style="info" %}
연락처 정보가 바뀐 걸 알게 되면 바로 업데이트하세요. CRM을 정확하고 쓸모 있게 유지하는 데 도움이 돼요.
{% endhint %}

1. **연락처 > 스마트 리스트**로 이동하세요.
2. **검색**으로 수정할 연락처를 찾거나 목록에서 선택하세요.

   ![수정할 연락처 검색 화면](https://jumpshare.com/share/MTFN3CVlxb8AXOYJQcgX+/Screen+Shot+2026-07-02+at+19.31.13.png)
3. **연락처 이름**을 클릭해 연락처 기록을 여세요.
4. 필요한 연락처 정보를 수정하세요.
5. 변경사항을 저장하세요.

   ![연락처 편집 후 저장하는 화면](https://jumpshare.com/share/57qhxLaJkno3Xhjti4qp+/GIF+Recording+2026-07-02+at+20.10.59.gif)

## 기존 연락처 삭제하기

더 이상 필요 없는 기록을 삭제하면 CRM이 깔끔해지고 관리하기 쉬워져요. 삭제하기 전에 그 기록이 정말 필요 없는지 꼭 확인하세요. 연락처를 삭제하면 연결된 활동과 후속 처리 과정에 영향을 줄 수 있어요.

{% hint style="info" %}
삭제한 연락처는 2개월 이내에 복원할 수 있어요.

연락처를 삭제하면 해당 연락처의 대화, 메모, 기회, 작업, 예약, 수동 작업, 커뮤니티 그룹 소유자 정보도 함께 삭제돼요. 해당 연락처에 진행 중인 캠페인과 워크플로우도 중지돼요.
{% endhint %}

연락처를 삭제하려면 다음 단계를 따르세요.

1. **연락처 > 스마트 리스트**로 이동하세요.

   ![스마트 리스트 화면](https://jumpshare.com/share/7K1v5UZnBOpqW8fi5BQL+/Screen+Shot+2026-07-02+at+20.20.55.png)
2. 삭제할 연락처 이름 왼쪽의 체크박스를 선택한 다음 **삭제** 버튼을 클릭하세요.

   ![연락처를 선택하고 삭제 버튼을 누르는 화면](https://jumpshare.com/share/PR52XjMp20Ywy5VXdqUw+/Screen+Shot+2026-07-02+at+20.23.25.png)
3. 팝업 창에 `DELETE`를 입력해 확인한 다음 **삭제** 버튼을 클릭하세요.

   ![삭제 확인 팝업 창](https://jumpshare.com/share/6kMSylQYqUP4qWoCNZkg+/Screen+Shot+2026-07-02+at+20.25.55.png)

## 연락처를 관리하는 다른 방법

연락처를 하나씩 만들고 편집하는 것은 연락처 관리의 일부일 뿐이에요. 연락처가 늘어나면 하이퍼클래스의 다른 도구를 써서 연락처를 효율적으로 추가하고, 수집한 정보를 정리하고, 여러 기록을 한 번에 관리하고, 연락처 데이터베이스를 깔끔하게 유지할 수 있어요.

| 기능 | 할 수 있는 일 |
| --- | --- |
| 연락처 가져오기 | 연락처를 하나씩 만들지 않고 CSV 파일을 가져와서 여러 연락처를 한 번에 추가해요. 가져오는 중에 파일의 열을 알맞은 연락처 필드와 연결할 수 있어요. 자세한 방법은 [시작하기 - 기존 연락처 가져오기](getting-started-import-existing-contacts.md)를 참고하세요. |
| 커스텀 필드 사용하기 | 리드 유형, 예산, 선호 사항처럼 기본 연락처 필드에 없는 비즈니스 맞춤 정보를 담을 수 있어요. 자세한 내용은 커스텀 필드 사용하기를 참고하세요. |
| 연락처 일괄 관리하기 | 여러 연락처를 선택해서 기록마다 하나씩 수정하는 대신 한꺼번에 처리해요. 태그 추가·제거, 메시지 보내기, 연락처 삭제 같은 작업에 쓸 수 있어요. 사용할 수 있는 작업은 [연락처 및 스마트 리스트 일괄 작업](../../02-연락처/bulk-actions-for-contacts-smartlists.md)에서 확인하세요. |
| 중복 연락처 관리하기 | 같은 사람의 기록을 찾아내고, 필요하면 중복된 연락처를 병합해서 데이터베이스를 정리해요. 자세한 내용은 [중복 연락처 관리 및 병합하기](../../02-연락처/스마트-리스트/how-to-manage-and-merge-duplicate-contacts.md)를 참고하세요. |
| 삭제한 연락처 복원하기 | 실수로 삭제한 연락처 중 아직 복원할 수 있는 연락처를 되살려요. 일괄 삭제로 지워진 연락처를 되돌릴 때도 쓸 수 있어요. 복원 방법은 [삭제한 연락처 복원하기 또는 일괄 삭제 되돌리기](../../02-연락처/연락처-기본/restore-deleted-contacts-or-undo-bulk-deletes.md)를 참고하세요. |

이 기능들을 활용하면 데이터베이스가 커져도 연락처를 더 효율적으로 관리할 수 있어요. 특정 작업을 자세히 알아보고 싶다면 위의 링크된 문서를 이용하세요.

## 자주 묻는 질문

### 한 번에 여러 연락처를 만들 수 있나요?
여러 연락처를 추가할 때는 하나씩 직접 만드는 것보다 연락처를 가져오는 방법이 더 좋아요.

### 연락처를 만들 때 보이는 필드가 다른 이유는 뭔가요?
**연락처 추가** 폼에 보이는 필드는 계정 설정에 따라 달라요. 추가해 둔 커스텀 필드도 여기에 포함돼요.

### 연락처를 삭제하면 어떻게 되나요?
연락처를 삭제하면 CRM에서 그 기록이 사라져요. 그 연락처와 연결된 기록, 캠페인, 워크플로우에도 영향을 줄 수 있어요.

### 삭제한 연락처를 복원할 수 있나요?
삭제한 연락처는 2개월 이내에 복원할 수 있어요.
