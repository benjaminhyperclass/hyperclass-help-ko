# 퍼널 만들고 공개하기: 템플릿, 폼, 도메인 연결까지

퍼널을 만들고, 폼을 붙이고, 내 도메인에 연결해서 공개하는 전체 과정을 안내해요. 웹사이트 방문자를 리드로 모으고 싶을 때 처음부터 차례대로 따라 해 보세요.

## 시작하기 전에

- 하이퍼클래스 서브 계정에 접근할 수 있어야 해요.
- 연결된 커스텀 도메인이 있거나, 연결할 도메인을 준비해 두세요.
- 퍼널의 목표를 정해 두세요. 예를 들어 리드 확보, 예약, 판매가 있어요.

## 퍼널 만드는 방법 고르기

퍼널은 아래 세 가지 방법 중 하나로 만들 수 있어요. 상황에 맞게 골라 보세요.

| 옵션 | 이럴 때 좋아요 |
| --- | --- |
| **From Blank**(처음부터 만들기) | 완전히 직접 꾸미고 싶을 때 |
| **템플릿으로 만들기** | 가장 빠르게 설정하고 싶을 때 |
| **퍼널 AI** | AI의 도움을 받아 만들고 싶을 때 |

## 퍼널 만들기

퍼널을 만드는 것이 첫걸음이에요. 바로 시작해 볼게요.

1. **사이트 > 퍼널**로 이동하세요.

   ![사이트 > 퍼널 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046286661/original/oaqTtT2iATnBeJzT1P4pgEkikblRY19hRA.png?1746659443)
2. **New Funnel**(새 퍼널)을 클릭한 뒤 다음 중 하나를 선택하세요.
   - **From Blank** (직접 처음부터 만들기)
   - **퍼널 AI** (AI로 만들기)
   - **템플릿으로 만들기** (미리 디자인된 퍼널 사용)

   ![새 퍼널 만들기 옵션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046286677/original/ihaI9Sktk5ddHWokV6s6Pcx6SSCf3jObjA.png?1746659509)

다음 단계: 이어서 브랜드 분위기에 맞게 퍼널 디자인을 꾸며 보세요.

## 템플릿으로 퍼널 만들기

템플릿은 전환율이 검증된 전문가 수준의 디자인을 제공해요. 처음부터 만들 필요 없이 세부 내용만 다듬으면 되니 시간을 아낄 수 있어요.

1. **사이트 > 퍼널**로 이동하세요.
2. **New Funnel** > **템플릿으로 만들기** > **계속**을 클릭하세요.
3. **템플릿 라이브러리**를 여세요.
4. 템플릿을 검색, 필터, 정렬해서 살펴보세요.

   ![템플릿 라이브러리에서 템플릿 검색하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046286718/original/-XbsRbDJrdRD17C7-_CijO-r7NwFDUVg7Q.png?1746659739)
5. 마음에 드는 퍼널 템플릿을 **미리보기**로 확인하세요.
6. **계속**을 클릭하세요.

   ![템플릿 미리보기 후 계속 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287136/original/s0pOLga6ZQFtch9OXdsYnGkKFMm1sXQwuw.png?1746661966)
7. **Funnel Editor**(퍼널 편집기)에서 내용을 수정하세요.

   ![퍼널 편집기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287138/original/t8eLvI2eb51pyq_YdWoy7U__zHhH-M9mJQ.png?1746662023)
8. **저장**을 클릭하세요.

```
더 알아보기: 템플릿 라이브러리 개요 및 설정
```

다음 단계: 맞춤 폼을 연결해서 방문자 정보를 모아 보세요.

## 폼 만들기

폼은 리드 확보의 핵심이에요. 방문자가 부담 없이 쉽게 작성할 수 있고, 필요한 정보를 잘 받을 수 있게 만들어 보세요.

1. **폼 빌더**로 이동하세요. 퍼널 편집기의 **Form Picker**(폼 선택기)에서 들어가도 되고, 폼 빌더로 바로 가도 돼요.
2. **폼 추가**를 클릭하세요.

   ![폼 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287496/original/zPR6ibp2083EYcYVARWLEGGyr4pMRsRtoA.png?1746664220)
3. **Form Editor**(폼 편집기)에서 필드와 브랜딩을 원하는 대로 꾸미세요.
4. **저장**을 클릭하세요.

```
더 알아보기: 연락처 폼 만드는 방법
```

다음 단계: 자동화를 연결해서 폼을 제출한 방문자에게 바로 후속 메시지를 보내 보세요.

## 기존 퍼널 수정하기

퍼널은 계속 최신 상태로 관리하는 것이 좋아요. 시장 상황이나 전략이 바뀌면 기존 퍼널을 빠르게 수정할 수 있어요.

1. **사이트 > 퍼널**로 이동하세요.
2. **Funnel List**(퍼널 목록)에서 수정할 퍼널을 선택해 클릭하세요.

   ![퍼널 목록에서 퍼널 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287538/original/xF3s5zqU3XWLooebQXr_LcMRi4CrnHmKgA.png?1746664480)
3. **Funnel Editor**에서 내용을 수정하세요.
4. **저장**을 클릭하세요.

다음 단계: 분석 지표를 확인해서 수정한 내용이 잘 반영되고 있는지 살펴보세요.

## 퍼널에 도메인 연결하기

기억하기 쉬운 도메인이 있으면 퍼널의 신뢰도와 전문성이 높아져요. 내 도메인을 퍼널에 연결해 보세요.

1. **설정 > 도메인**으로 이동하세요.
2. **Connect a Domain**(도메인 연결)을 클릭하세요.

   ![도메인 연결 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287715/original/3Dj-bDoO1hqBolTo1hseNR56D5itlNIPzw.png?1746665329)
3. 도메인을 입력하고 **계속**을 클릭하세요.

   ![도메인 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287722/original/jOVySWHvD_lw4o4xOGPQ51I4KyThuclFJQ.png?1746665376)
4. 화면에 나오는 안내에 따라 **DNS 레코드**를 설정하세요. 설정 방법은 도메인을 등록한 업체마다 달라요.
5. **Verify Records**(레코드 인증)를 클릭하세요.

   ![레코드 인증 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287763/original/P9fjINy3IbSe7rQw0d25b_VsakCjwrSkBA.png?1746665613)
6. 도메인과 퍼널을 연결하세요.

   ![도메인과 퍼널 연결 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046287774/original/NdBJzKUSG7fUw7L9Z8zPA-BR2p7XQGxL5w.png?1746665668)
7. **Proceed to Finish**(완료 진행)를 클릭하세요.

다음 단계: 이제 공개할 준비가 끝났어요. 퍼널을 공유하고 리드가 들어오는 모습을 확인해 보세요.

## 자주 겪는 문제

### 퍼널이 열리지 않아요

- 커스텀 도메인이 인증되었는지 확인하세요.
- DNS 전파 상태를 확인하세요.
- 퍼널이 해당 도메인에 연결되어 있는지 확인하세요.

### 폼으로 리드가 들어오지 않아요

- 페이지에 폼이 추가되어 있는지 확인하세요.
- 테스트로 직접 제출해 보세요.
- 해당하는 경우 워크플로우나 자동화 설정을 확인하세요.
