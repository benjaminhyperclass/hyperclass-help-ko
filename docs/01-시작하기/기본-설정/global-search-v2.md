# 글로벌 검색 V2

키보드 단축키, 음성 명령, 그리고 빠른 백엔드 성능을 갖춘 단일 통합 인터페이스에서 하이퍼클래스의 모든 제품, 페이지, 레코드를 검색해보세요.

무엇을 배우게 되나요

글로벌 검색 V2(Global Search V2)는 하이퍼클래스 전반에 걸친 통합 검색 경험을 제공하며, 530개 이상의 플랫폼 경로와 연락처, 기회 관리, 캘린더, 워크플로우 등 8개 핵심 제품을 인덱싱합니다. 백엔드 기반 검색, 키보드 중심 내비게이션, 음성 명령 지원 덕분에 여러 단계의 메뉴를 뒤질 필요 없이 몇 초 만에 원하는 레코드나 페이지를 찾을 수 있어요.

이 아티클에서는 글로벌 검색 V2의 주요 기능, 검색 인터페이스를 활성화하고 사용하는 방법, 사용 가능한 검색 모드와 단축키, 그리고 제품 지원 범위 및 성능에 관한 자주 묻는 질문을 다룹니다.

Labs 기능

글로벌 검색 V2는 하이퍼클래스 Labs에서 제공됩니다. **Labs > Subaccounts > "Global Search V2"** 에서 활성화하면 이 기능을 사용할 수 있어요. Labs 기능은 사용자 피드백에 따라 업데이트될 수 있는 얼리 액세스(선공개) 기능입니다.

## 글로벌 검색 V2란 무엇인가요?

글로벌 검색 V2는 단일 진입점에서 하이퍼클래스 내 모든 레코드, 페이지, 경로를 찾을 수 있는 통합 검색 인터페이스입니다. 에이전시(Agency)와 로케이션(Location) 레벨 모두에서 530개 이상의 플랫폼 경로를 인덱싱하며, 연락처, 기회 관리, 상품, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 대화 등 8개 핵심 제품을 검색합니다.

이 검색은 백엔드에서 병렬로 제품 쿼리를 실행하며, 사용자 역할, 본인 데이터만 보기 권한, 기능 플래그(feature flag), 지원 종료된 기능 등을 기준으로 접근 제어를 적용합니다. 이를 통해 클라이언트 측 지연을 없애고 Mac Spotlight나 Windows 검색과 유사한 빠른 검색 경험을 제공해요.

글로벌 검색 V2를 사용하면 여러 단계의 메뉴를 뒤지거나 특정 기능의 위치를 기억할 필요가 없습니다. 좌측 사이드바의 검색창을 클릭하거나 하이퍼클래스 어디서든 **Cmd/Ctrl + K**를 눌러 바로 검색을 시작할 수 있어요.

## 주요 이점

글로벌 검색 V2는 플랫폼 내비게이션을 시간이 오래 걸리는 작업에서 즉각적인 행동으로 바꿔줍니다. 통합 검색 인터페이스는 불편함을 줄이고, 기능 위치에 대한 혼란을 없애며, 제품 카탈로그가 늘어나도 성능이 저하되지 않도록 확장됩니다.

**전체 플랫폼 커버리지** — 530개 이상의 경로와 8개 제품을 하나의 인터페이스에서 검색할 수 있으며, 완전한 플랫폼 커버리지를 위해 더 많은 제품이 지속적으로 추가되고 있어요.

**백엔드 기반 속도** — 서버 측 검색이 여러 제품 쿼리를 병렬로 실행하여 클라이언트 측 지연이 누적되지 않으며, 검색하는 제품 수와 관계없이 한 번의 왕복(round trip)으로 결과를 제공합니다.

**스마트 퍼지 매칭(Fuzzy Matching)** — 철자 오류를 자동으로 처리하며, 섹션 이름을 입력하면 정확한 텍스트 일치 없이도 해당 섹션의 모든 하위 페이지를 보여줍니다.

**권한 기반 결과** — 검색 결과는 사용자 역할, 본인 데이터만 보기 권한, 기능 플래그, 지원 종료된 기능에 따라 자동으로 필터링되어, 접근 권한이 있는 항목만 표시됩니다.

**키보드 중심 내비게이션** — 방향키와 Enter로 완전한 탐색이 가능하고, Cmd/Ctrl+K로 열고, Cmd/Ctrl+1..9로 검색 범위를 전환하는 빠르고 손을 키보드에서 떼지 않는 워크플로우를 제공합니다.

**음성 명령 지원** — "open", "tab" 같은 명령과 단축키를 음성으로 사용하여 손을 사용하지 않는 내비게이션과 접근성을 지원합니다.

## 검색 인터페이스

글로벌 검색 V2 인터페이스는 깔끔하고 집중도 높은 디자인의 중앙 정렬 모달 오버레이로 열립니다. 상단에 4개의 액션 아이콘과 함께 검색창이 표시되고, 그 아래에 제품 필터 필(pill)과 그룹화된 결과가 나타납니다.

구성 요소 1

검색창 및 액션 아이콘

검색창은 선택한 필터에 따라 "Search", "Search for Conversations...", "Search apps..." 등의 동적 안내 문구를 표시합니다. 검색 입력창 오른쪽에는 4개의 액션 아이콘이 있어요: 음성 명령용 마이크 아이콘, 일반 검색용 돋보기 아이콘, 내비게이션/경로 아이콘, 도움말 아이콘입니다.

구성 요소 2

제품 필터 필(Pill)

검색창 아래에는 알약 모양의 필터가 한 줄로 표시되어 검색 범위 옵션을 보여줍니다. "All" 필은 모든 제품과 경로를 검색하며, 개별 제품 필(연락처, 기회 관리, 상품, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 대화)은 결과를 특정 제품 유형으로 좁혀줍니다. 활성화된 필터는 파란색으로 강조 표시됩니다.

구성 요소 3

그룹화된 검색 결과

결과는 PAGES, CONTACTS, PRODUCTS, FUNNELS 등의 그룹화된 섹션으로 표시되며, 각 섹션 제목 옆에 결과 개수가 표시됩니다(예: "PAGES 3", "FUNNELS 5"). 각 결과는 레코드 또는 페이지 이름, 브레드크럼(breadcrumb) 내비게이션 경로, 관련 메타데이터를 보여줍니다. 표시된 것보다 결과가 많은 섹션에는 "See all" 링크가 나타납니다.

구성 요소 4

Search Apps 뷰

검색창을 클릭했지만 아무것도 입력하지 않은 경우, "Search apps..." 뷰가 나타나며 8개 제품 아이콘이 그리드 형태로 표시됩니다: 연락처, 기회 관리, 상품, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 대화. 아이콘을 클릭하면 해당 제품으로 검색이 필터링됩니다.

구성 요소 5

키보드 단축키 안내

검색 모달 하단에는 사용 가능한 명령어를 안내하는 키보드 단축키 정보가 표시됩니다: Navigate(방향키), Tab, Switch tab(Cmd/Ctrl+숫자), Open(Enter), ESC to Dismiss. 우측 하단에는 "Global Search" 라벨이 표시됩니다.

접근 지점

글로벌 검색 V2는 하이퍼클래스 좌측 사이드바에 있는 검색창에서 실행되며, 그 옆에 키보드 단축키 "⌘K"가 표시됩니다. 검색창을 클릭하거나 플랫폼 어디서든 Cmd/Ctrl+K를 눌러 바로 검색 인터페이스를 열 수 있어요.

## 검색 모드와 필터

글로벌 검색 V2는 다양한 워크플로우에 맞춰 여러 검색 모드를 제공합니다. 모든 제품과 경로를 대상으로 글로벌 검색을 실행하거나, 검색 범위를 단일 제품으로 좁히거나, 내비게이션 전용 검색에 집중할 수 있어요.

모드 1

전체(All) 범위

기본값인 "All" 모드는 활성화된 모든 제품과 모든 플랫폼 경로를 동시에 검색합니다. 이는 하이퍼클래스 전반을 포괄적으로 훑어보며, 검색어와 일치하는 레코드(연락처, 기회 관리, 퍼널 등)와 내비게이션 페이지를 함께 반환합니다. 결과는 카테고리별로 그룹화되어 개수와 함께 표시됩니다.

모드 2

제품별 필터

8개의 제품 필터 필(연락처, 기회 관리, 상품, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 대화) 중 하나를 클릭하면 검색 범위가 해당 제품으로 좁혀집니다. 검색창의 안내 문구가 선택 내용에 맞게 업데이트됩니다. 예를 들어 대화 필터가 활성화되면 "Search for Conversations..."로 표시됩니다. 이 모드는 제품 유형은 알지만 구체적인 레코드를 모를 때 유용합니다.

모드 3

Search Apps 뷰

글로벌 검색을 처음 열거나 검색어를 지우면, 인터페이스에 8개 제품 아이콘이 그리드로 배치된 "Search apps..." 뷰가 표시됩니다. 아이콘을 클릭하면 바로 해당 제품 카테고리로 검색이 필터링되어, 구체적인 검색어를 입력하기 전에 제품별로 둘러보기 편리합니다.

모드 전환하기

검색 인터페이스를 벗어나지 않고 빠르게 검색 범위를 전환하려면 Cmd/Ctrl+1부터 Cmd/Ctrl+9까지의 키보드 단축키를 사용하세요. 활성화된 필터 필은 파란색으로 강조 표시되며, 검색창의 안내 문구도 선택 내용에 맞게 업데이트됩니다.

## 키보드 단축키와 음성 명령

글로벌 검색 V2는 방향키와 Enter를 완전히 지원하는 키보드 중심 내비게이션을 위해 설계되었으며, 접근성과 손을 사용하지 않는 워크플로우를 위한 음성 명령 기능도 갖추고 있습니다. 검색 인터페이스 하단에는 빠른 참조를 위한 키보드 단축키 안내가 표시됩니다.

키보드 단축키

단축키기능Cmd/Ctrl + K하이퍼클래스 어디서든 글로벌 검색 열기방향키검색 결과 위아래로 이동Enter강조 표시된 결과를 선택하여 해당 페이지 또는 레코드로 이동Tab검색 인터페이스 요소 간 이동Cmd/Ctrl + 1..9검색 범위 전환(전체, 특정 앱, 내비게이션)Esc글로벌 검색 인터페이스 닫기

음성 명령

글로벌 검색 V2는 손을 사용하지 않는 내비게이션을 위한 명령 단축키와 음성 받아쓰기를 지원합니다. 검색창의 마이크 아이콘을 클릭하면 음성 명령을 활성화할 수 있어요:

**"open [페이지 이름]"** — 음성으로 플랫폼 페이지에 바로 이동

**"tab [제품 이름]"** — 음성으로 특정 제품 필터로 전환

**명령 단축키** — 음성으로 키보드 단축키를 실행하여 더 빠르게 이동

접근성

글로벌 검색 V2는 상태 변경 및 명령 실행 시 스크린 리더 안내를 제공하여, 보조 기술을 사용하는 사용자도 완전히 접근할 수 있도록 지원합니다. 키보드 단축키 안내는 항상 화면 하단에 표시되어 사용 가능한 명령어를 참고할 수 있습니다.

속도와 확장성

백엔드 기반 성능

글로벌 검색 V2는 병렬 백엔드 쿼리, 디바운스(debounce) 처리된 입력, 취소 가능한 요청을 통해 클라이언트 측 지연을 없애며, 검색하는 제품 수와 관계없이 한 번의 왕복으로 결과를 제공합니다.

## 글로벌 검색 V2 활성화 및 사용 방법

글로벌 검색 V2는 하이퍼클래스 Labs에서 제공됩니다. 활성화하고 나면 키보드 단축키를 사용하거나, 좌측 사이드바의 검색창을 클릭하거나, 음성 명령을 통해 검색 인터페이스를 실행할 수 있습니다.

글로벌 검색 V2 활성화하기

Labs 설정으로 이동하여 글로벌 검색 V2 활성화하기

하이퍼클래스 계정에서 **Labs > Subaccounts**로 이동해 Labs 기능 설정에 접근하세요. Labs 기능 목록에서 **"Global Search V2"**를 찾아 토글을 활성화 위치로 전환합니다. 변경 사항은 즉시 적용됩니다.

결과 확인 및 이동하기

결과는 유형별(PAGES, CONTACTS, PRODUCTS, FUNNELS 등)로 그룹화되어 개수와 함께 표시됩니다. 방향키로 결과를 탐색하고 **Enter**를 눌러 선택한 항목을 엽니다. 결과는 사용자의 권한과 접근 수준에 따라 자동으로 필터링됩니다.

## 자주 묻는 질문

Q: 글로벌 검색 V2에는 현재 어떤 제품이 포함되어 있나요?

글로벌 검색 V2는 현재 연락처, 기회 관리, 상품, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 대화 등 8개 핵심 제품을 검색합니다. 완전한 플랫폼 커버리지를 위해 추가 제품이 지속적으로 도입되고 있어요.

Q: 글로벌 검색 V2는 어떻게 활성화하나요?

**Labs > Subaccounts**로 이동하여 **"Global Search V2"** 기능을 활성화하세요. 활성화한 후에는 좌측 사이드바의 검색창(⌘K 라벨 옆)을 클릭하거나, 하위 계정 레벨에서 어디서든 **Cmd/Ctrl + K**를 눌러 검색 인터페이스에 접근할 수 있습니다.

Q: 글로벌 검색 V2는 사용자 권한과 역할 기반 접근 제어를 준수하나요?

네. 글로벌 검색은 백엔드에서 접근 제어를 적용하여, 사용자 역할, 본인 데이터만 보기 권한, 기능 플래그, 지원 종료된 기능에 따라 결과를 필터링합니다. 접근 권한이 있는 레코드와 페이지만 표시됩니다.

Q: 데이터 레코드뿐만 아니라 플랫폼 페이지도 검색할 수 있나요?

네. 글로벌 검색 V2는 에이전시와 로케이션 레벨을 모두 포괄하는 530개 이상의 사이드바 경로와 8개 제품의 데이터 레코드를 인덱싱합니다. 하이퍼클래스 내 이동 가능한 모든 페이지를 검색할 수 있으며, 결과는 전체 메뉴 계층을 보여주는 브레드크럼 내비게이션 경로와 함께 표시됩니다.

Q: 글로벌 검색 V2에서 사용할 수 있는 키보드 단축키는 무엇인가요?

**Cmd/Ctrl + K**를 눌러 글로벌 검색을 엽니다. 방향키로 결과를 탐색하고 **Enter**로 선택하세요. **Cmd/Ctrl + 1..9**로 검색 범위를 전환하고, **Tab**으로 요소 간 이동, **Esc**로 검색 인터페이스를 닫을 수 있습니다. 검색 모달 하단에 키보드 단축키 안내가 표시됩니다.

Q: 글로벌 검색 V2는 철자 오류를 처리하나요?

네. 글로벌 검색은 퍼지 매칭을 사용하여 철자 오류를 자동으로 처리합니다. 정확한 이름이나 경로를 입력할 필요 없이, 대략적인 텍스트만으로도 관련 결과를 찾아줍니다.

Q: 검색 결과를 단일 제품으로 필터링할 수 있나요?

네. 제품 필터 필(연락처, 기회 관리, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 상품, 대화) 중 하나를 클릭하면 해당 제품으로 결과가 좁혀집니다. 검색창을 클릭해 모든 제품 아이콘을 그리드로 볼 수도 있고, **Cmd/Ctrl + 숫자** 단축키로 빠르게 필터를 전환할 수도 있어요.

Q: 글로벌 검색 V2에서 음성 명령이 지원되나요?

네. 글로벌 검색 V2는 "open [페이지 이름]", "tab [제품 이름]" 같은 명령을 통한 음성 받아쓰기를 지원하여 손을 사용하지 않는 내비게이션이 가능합니다. 검색창의 마이크 아이콘을 클릭하면 음성 명령을 활성화할 수 있어요. 접근성을 위한 스크린 리더 안내도 포함되어 있습니다.

Q: 글로벌 검색 실행 버튼은 어디에 있나요?

글로벌 검색 실행 버튼은 하이퍼클래스 좌측 사이드바에 있으며, 검색창 형태로 그 옆에 키보드 단축키 "⌘K"가 표시됩니다. 검색창을 클릭하거나 플랫폼 어디서든 Cmd/Ctrl + K를 눌러 바로 검색 인터페이스를 열 수 있습니다.
