# 전체 검색 V2 사용하기

하이퍼클래스의 상품, 페이지, 기록을 검색창 하나로 찾아요. 키보드 단축키와 음성 명령을 쓸 수 있고, 검색은 서버에서 처리돼서 빨라요.

## 이 문서에서 배우는 내용

**전체 검색 V2**는 하이퍼클래스 전체를 한 번에 검색하는 기능이에요. 530개 이상의 플랫폼 경로와 연락처, 기회, 캘린더, 워크플로우 등 8개 핵심 상품을 색인해요. 서버 기반 검색, 키보드 중심 이동, 음성 명령을 지원해서 중첩된 메뉴를 뒤지지 않고도 원하는 기록이나 페이지를 몇 초 만에 찾을 수 있어요.

이 문서에서는 전체 검색 V2의 주요 기능, 켜는 방법과 사용 방법, 검색 모드와 단축키를 설명해요. 지원하는 상품 범위와 성능에 관한 자주 묻는 질문도 함께 정리했어요.

{% hint style="info" %}
**실험실** 기능이에요. 전체 검색 V2는 하이퍼클래스 **실험실**에서 제공해요. **실험실 > 서브 계정**에서 **전체 검색 V2**를 켜면 쓸 수 있어요. **실험실** 기능은 먼저 만나 보는 기능이라서 사용자 의견에 따라 업데이트될 수 있어요.
{% endhint %}

## 전체 검색 V2란?

전체 검색 V2는 하이퍼클래스의 기록, 페이지, 경로를 한 곳에서 찾는 통합 검색 화면이에요. 에이전시 수준과 서브 계정 수준의 530개 이상 플랫폼 경로를 색인하고, 연락처, 기회, 상품, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 대화 등 8개 핵심 상품을 검색해요.

검색은 서버에서 처리해요. 여러 상품을 동시에 조회하면서 사용자 역할, 배정된 데이터만 볼 수 있는 권한, 기능 플래그, 지원이 중단된 기능을 기준으로 접근을 제한해요. 그래서 화면에서 지연이 쌓이지 않고, Mac의 Spotlight나 Windows 검색처럼 빠르게 결과가 나와요.

중첩된 메뉴를 뒤지거나 기능 위치를 외우지 않아도 돼요. 왼쪽 사이드바의 검색창을 클릭하거나, 하이퍼클래스 어디서든 **Cmd/Ctrl + K**를 누르면 바로 검색을 시작할 수 있어요.

**전체 검색**에서 일치하는 결과를 찾지 못했을 때, **'AI에게 문의' 액세스**가 있는 사용자는 같은 검색어를 처음부터 다시 입력하지 않고 **AI에게 문의**로 보낼 수 있어요. 첫 번째 답변은 **전체 검색** 안에 표시돼요. 더 자세히 대화하고 싶으면 **AI에게 문의**에서 이어 갈 수 있어요.

## 주요 장점

- 플랫폼 전체 검색: 하나의 화면에서 530개 이상의 경로와 8개 상품을 검색해요. 검색 대상 상품은 계속 늘어나고 있어요.
- 서버 기반의 빠른 속도: 서버에서 여러 상품을 동시에 조회해요. 검색하는 상품이 많아도 한 번의 요청으로 결과를 받아요.
- 오타를 알아서 보정: 철자가 틀려도 자동으로 처리해요. 섹션 이름만 입력해도 그 아래의 모든 하위 페이지가 나타나서, 정확한 이름을 입력하지 않아도 돼요.
- 권한에 맞는 결과: 사용자 역할, 배정된 데이터만 볼 수 있는 권한, 기능 플래그, 지원이 중단된 기능에 따라 결과가 자동으로 걸러져요. 접근 권한이 있는 항목만 보여요.
- 키보드 중심 이동: 방향키와 Enter로 이동하고, Cmd/Ctrl+K로 열고, Cmd/Ctrl+1..9로 검색 범위를 바꿔요. 손을 키보드에서 떼지 않고 작업할 수 있어요.
- 음성 명령 지원: "open", "tab" 같은 명령과 단축키를 음성으로 입력해서 손을 쓰지 않고도 이동할 수 있어요.

## 검색 화면 구성

전체 검색 V2는 화면 가운데에 모달 창으로 열려요. 맨 위에 검색창과 작업 아이콘 4개가 있고, 그 아래에 상품 필터, 그 아래에 그룹별 검색 결과가 표시돼요.

### 1. 검색창과 작업 아이콘

검색창의 안내 문구는 선택한 필터에 따라 바뀌어요. 예를 들면 **검색**, **Search for Conversations...**(대화 검색), **Search apps...**(앱 검색)처럼 표시돼요. 검색창 오른쪽에는 아이콘 4개가 있어요.

- 마이크 아이콘: 음성 명령
- 돋보기 아이콘: 일반 검색
- 이동/경로 아이콘
- 도움말 아이콘

### 2. 상품 필터

검색창 아래에는 검색 범위를 고르는 알약 모양의 필터가 있어요. **전체** 필터는 모든 상품과 경로를 검색해요. 개별 상품 필터(**연락처**, **기회 관리**, **상품**, **캘린더**, **퍼널**, **워크플로우**, **소셜 플래너**, **대화**)를 선택하면 해당 상품의 결과만 보여요. 선택한 필터는 파란색으로 강조돼요.

### 3. 검색 결과

결과는 **PAGES**(페이지), **CONTACTS**(연락처), **PRODUCTS**(상품), **FUNNELS**(퍼널)처럼 그룹별로 나뉘어 표시돼요. 각 그룹 제목 옆에 결과 수가 보여요(예: "PAGES 3", "FUNNELS 5"). 결과마다 기록이나 페이지 이름, 이동 경로(브레드크럼), 관련 정보가 함께 나와요. 표시된 개수보다 결과가 많은 그룹에는 **전체 보기** 링크가 나타나요.

### 4. 앱 검색 화면

검색창을 클릭하고 아무것도 입력하지 않으면 **Search apps...**(앱 검색) 화면이 나타나요. 이 화면에는 8개 상품 아이콘이 격자로 표시돼요. 아이콘은 **연락처**, **기회 관리**, **상품**, **캘린더**, **퍼널**, **워크플로우**, **소셜 플래너**, **대화**예요. 아이콘을 클릭하면 해당 상품으로 검색 범위가 좁혀져요.

### 5. 키보드 단축키 안내

검색 모달 맨 아래에는 **키보드 단축키** 안내가 표시돼요. 이동(방향키), **탭**, 탭 전환(Cmd/Ctrl+숫자), 열기(Enter), **Esc 키로 닫기**를 확인할 수 있어요. 오른쪽 아래에는 **전체 검색**이라는 이름이 보여요.

### 6. 'AI에게 문의' 결과 없음 화면

**전체 검색**에서 일치하는 결과를 찾지 못하면, **'AI에게 문의' 액세스**가 있는 사용자는 입력한 검색어를 바로 **AI에게 문의**로 보낼 수 있어요. 검색 결과로 정보를 찾지 못했을 때 다음 방법이 되어 줘요.

**AI에게 문의** 옵션을 선택하면 현재 검색어가 **AI에게 문의**로 전달돼요. 첫 번째 답변은 **전체 검색** 모달 안에 표시되므로, 검색 화면을 떠나지 않고 답변을 확인할 수 있어요.

대화를 이어 가려면 **Continue in Ask AI**(AI에게 문의에서 계속하기)를 선택하세요. 검색어와 대화 내용이 전체 **AI에게 문의** 화면으로 넘어가서 처음부터 다시 시작하지 않아도 돼요.

### 열기

전체 검색 V2는 하이퍼클래스 왼쪽 사이드바의 검색창에서 열어요. 검색창 옆에는 단축키 "⌘K"가 표시돼요. 검색창을 클릭하거나 플랫폼 어디서든 Cmd/Ctrl+K를 누르면 바로 열려요.

## 검색 모드와 필터

전체 검색 V2에는 작업 방식에 맞게 고를 수 있는 검색 모드가 여러 개 있어요. 모든 상품과 경로를 한 번에 검색할 수도 있고, 상품 하나로 범위를 좁히거나 이동용 검색에만 집중할 수도 있어요.

### 모드 1. 전체 범위

기본 모드인 **전체**는 사용 중인 모든 상품과 모든 플랫폼 경로를 한꺼번에 검색해요. 검색어와 일치하는 기록(연락처, 기회, 퍼널 등)과 이동할 수 있는 페이지가 함께 나와요. 결과는 카테고리별로 묶여 개수와 함께 표시돼요.

### 모드 2. 상품별 필터

8개 상품 필터(**연락처**, **기회 관리**, **상품**, **캘린더**, **퍼널**, **워크플로우**, **소셜 플래너**, **대화**) 중 하나를 클릭하면 그 상품으로만 검색해요. 검색창 안내 문구도 선택에 맞게 바뀌어요. 예를 들어 **대화** 필터를 선택하면 **Search for Conversations**...로 표시돼요. 상품 종류는 알지만 정확한 기록을 모를 때 유용해요.

### 모드 3. 앱 검색 화면

전체 검색을 처음 열거나 검색어를 지우면 **Search apps...**(앱 검색) 화면이 나타나요. 8개 상품 아이콘이 격자로 배열돼 있어요. 아이콘을 클릭하면 바로 그 상품 범위로 검색이 좁혀져요. 검색어를 입력하기 전에 상품별로 둘러볼 때 편해요.

### 모드 바꾸기

검색 화면을 벗어나지 않고 Cmd/Ctrl+1부터 Cmd/Ctrl+9까지 눌러 검색 범위를 빠르게 바꿀 수 있어요. 선택한 필터는 파란색으로 강조되고, 검색창 안내 문구도 선택에 맞게 바뀌어요.

## 키보드 단축키와 음성 명령

전체 검색 V2는 방향키와 Enter로 모든 작업을 할 수 있게 만들어졌어요. 접근성과 손을 쓰지 않는 작업을 위해 음성 명령도 지원해요. 검색 화면 맨 아래에 **키보드 단축키** 안내가 표시되어 바로 확인할 수 있어요.

### 키보드 단축키

| 단축키 | 동작 |
| --- | --- |
| Cmd/Ctrl + K | 하이퍼클래스 어디서든 전체 검색 열기 |
| 방향키 | 검색 결과를 위아래로 이동 |
| Enter | 강조된 결과를 선택하고 해당 페이지나 기록으로 이동 |
| 탭 | 검색 화면의 요소 사이를 이동 |
| Cmd/Ctrl + 1..9 | 검색 범위 전환(전체, 개별 앱, 내비게이션) |
| Esc | 전체 검색 닫기 |

### 음성 명령

전체 검색 V2는 음성 받아쓰기와 명령 단축키를 지원해서 손을 쓰지 않고 이동할 수 있어요. 검색창의 마이크 아이콘을 클릭하면 **음성 명령**이 켜져요.

- "open [page name]": 말한 이름의 플랫폼 페이지로 바로 이동해요.
- "tab [product name]": 말한 이름의 상품 필터로 전환해요.
- 명령 단축키: 키보드 단축키를 음성으로 실행해서 더 빠르게 이동해요.

### 접근성

전체 검색 V2는 상태가 바뀌거나 명령이 실행될 때 스크린 리더로 안내를 읽어 줘요. 보조 기술을 사용하는 분도 모든 기능을 쓸 수 있어요. 화면 아래의 **키보드 단축키** 안내에서 사용할 수 있는 명령을 언제나 눈으로 확인할 수 있어요.

### 속도와 확장성

전체 검색 V2는 서버에서 여러 조회를 동시에 처리하고, 입력이 멈춘 뒤에 검색하고, 이전 요청을 취소할 수 있어요. 그래서 화면에서 지연이 쌓이지 않아요. 검색하는 상품이 아무리 많아도 한 번의 요청으로 결과를 받아요.

## 전체 검색 V2 켜고 사용하기

전체 검색 V2는 하이퍼클래스 **실험실**에서 제공해요. 켜고 나면 단축키, 왼쪽 사이드바의 검색창 클릭, 음성 명령으로 검색 화면을 열 수 있어요.

### 전체 검색 V2 켜기

1. 하이퍼클래스 계정에서 **실험실 > 서브 계정**으로 이동해요.
2. 실험실 기능 목록에서 **전체 검색 V2**를 찾아 토글을 켜요. 변경 사항은 바로 적용돼요.

   ![실험실의 서브 계정 설정에서 전체 검색 V2를 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077348979/original/DxdifN9pOtd1kHs1pZFnusGZar9SEC-q3g.png?1785504987)

3. 왼쪽 사이드바의 검색창(⌘K 표시 옆)을 클릭하거나, 서브 계정 수준의 하이퍼클래스 어디서든 **Cmd/Ctrl + K**를 눌러 전체 검색을 열어요.

   ![왼쪽 사이드바의 검색창과 전체 검색 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077349407/original/xtdqDDgsUbqN1B5tQUXBd0kZEY1Jzy_ubw.png?1785505175)

### 전체 검색 V2 사용하기

4. 찾고 싶은 연락처, 기회, 페이지, 기능의 이름을 입력해요. 전체 검색은 오타를 자동으로 보정해요. 마이크 아이콘을 클릭해서 음성 명령으로 검색해도 돼요.
5. 결과를 확인하고 이동해요. 결과는 **PAGES**(페이지), **CONTACTS**(연락처), **PRODUCTS**(상품), **FUNNELS**(퍼널) 같은 유형별로 묶여 개수와 함께 표시돼요. 방향키로 결과를 이동하고 **Enter**를 눌러 선택한 항목을 열어요. 결과는 권한과 접근 수준에 따라 자동으로 걸러져요.

   ![유형별로 묶인 검색 결과 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077349532/original/8BZXenuDkuRTJihHEtsCyg2dAOcmuhXwGw.png?1785505243)

6. 상품 필터를 클릭하면 연락처, 기회 관리, 캘린더 등 상품 하나로 결과가 좁혀져요. 검색어를 입력하지 않고 검색창을 클릭하면 8개 상품 아이콘이 있는 **Search apps...**(앱 검색) 격자를 볼 수 있어요. **Cmd/Ctrl + 1..9**를 누르면 키보드로 범위를 빠르게 바꿀 수 있어요.

{% hint style="info" %}
**팁:** "설정" 같은 섹션 이름을 입력하면 그 섹션 아래의 모든 하위 페이지가 자동으로 나타나요. 메뉴를 여러 단계 거치지 않고도 숨어 있는 기능을 찾을 수 있어요. 각 결과에는 전체 메뉴 경로가 표시돼요.
{% endhint %}

## 자주 묻는 질문

### 전체 검색 V2에서는 어떤 상품을 검색할 수 있나요?

현재 8개 핵심 상품(연락처, 기회, 상품, 캘린더, 퍼널, 워크플로우, 소셜 플래너, 대화)을 검색해요. 플랫폼 전체를 검색할 수 있도록 하이퍼클래스의 다른 상품도 계속 추가하고 있어요.

### 전체 검색 V2는 어떻게 켜나요?

**실험실 > 서브 계정**으로 이동해서 **전체 검색 V2** 기능을 켜세요. 켠 뒤에는 왼쪽 사이드바의 검색창(⌘K 표시 옆)을 클릭하거나, 서브 계정 수준 어디서든 **Cmd/Ctrl + K**를 누르면 검색 화면이 열려요.

### 전체 검색 V2에서도 사용자 권한과 역할별 접근 제한이 적용되나요?

네. 전체 검색은 서버에서 접근을 제어해요. 사용자 역할, 배정된 데이터만 볼 수 있는 권한, 기능 플래그, 지원이 중단된 기능을 기준으로 결과를 걸러요. 접근 권한이 있는 기록과 페이지만 보여요.

### 데이터 기록뿐 아니라 플랫폼 페이지도 검색할 수 있나요?

네. 전체 검색 V2는 에이전시와 서브 계정 수준을 모두 포함한 530개 이상의 사이드바 경로와 8개 상품의 데이터 기록을 색인해요. 하이퍼클래스에서 이동할 수 있는 모든 페이지를 검색할 수 있고, 결과에는 전체 메뉴 경로가 함께 표시돼요.

### 전체 검색 V2에서는 어떤 키보드 단축키를 쓸 수 있나요?

**Cmd/Ctrl + K**로 전체 검색을 열어요. 방향키로 결과를 이동하고 **Enter**로 선택해요. **Cmd/Ctrl + 1..9**로 검색 범위를 바꾸고, **탭** 키로 요소 사이를 이동하며, **Esc**로 검색 화면을 닫아요. 검색 모달 아래에 **키보드 단축키** 안내가 표시돼요.

### 전체 검색 V2는 오타도 알아서 처리하나요?

네. 전체 검색은 오타를 자동으로 보정해요. 정확한 이름이나 경로를 입력하지 않아도 비슷한 텍스트만으로 관련 결과를 찾아 줘요.

### 검색 결과를 상품 하나로 좁힐 수 있나요?

네. 상품 필터(**연락처**, **기회 관리**, **캘린더**, **퍼널**, **워크플로우**, **소셜 플래너**, **상품**, **대화**) 중 하나를 클릭하면 해당 상품의 결과만 볼 수 있어요. 검색창을 클릭해서 상품 아이콘을 격자로 볼 수도 있고, **Cmd/Ctrl + 숫자** 단축키로 필터를 빠르게 바꿀 수도 있어요.

### 전체 검색 V2에서 음성 명령을 쓸 수 있나요?

네. "open [page name]", "tab [product name]" 같은 명령으로 손을 쓰지 않고 이동할 수 있어요. 검색창의 마이크 아이콘을 클릭하면 **음성 명령**이 켜져요. 접근성을 위한 스크린 리더 안내도 지원해요.

### 전체 검색은 어디서 여나요?

하이퍼클래스 왼쪽 사이드바에 있는 검색창에서 열어요. 검색창 옆에 단축키 "⌘K"가 표시돼 있어요. 검색창을 클릭하거나 플랫폼 어디서든 **Cmd/Ctrl + K**를 누르면 바로 열려요.
