# SaaS 플랜에 애드온 포함하기

**SaaS 구성기**(SaaS Configurator)에서 WordPress, WhatsApp, Yext, 광고 관리자, AI 직원 같은 유료 애드온을 SaaS 플랜에 포함하는 방법을 안내해요. 에이전시 관리자만 쓸 수 있는 기능이에요. 청구 방식과 비용 계산 방법, 플랜이 적자가 나지 않게 가격을 정할 때 알아 둘 점도 함께 다뤄요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 시작하기 전에: 애드온 청구 방식

하이퍼클래스에서 애드온을 제공하는 방식은 두 가지예요.

### 1. 재판매 (SaaS 플랜 안에서는 쓰지 않아요)

- 에이전시가 하이퍼클래스에 비용을 내요.
- 서브 계정은 에이전시에 마진이 붙은 가격을 내요.

### 2. 직접 배포 (SaaS 플랜에서 쓰는 방식)

SaaS 플랜에 애드온을 포함하면 다음과 같이 청구돼요.

- 서브 계정에는 해당 애드온 비용이 청구되지 **않아요**.
- 에이전시에 하이퍼클래스가 비용을 청구해요.
- 이 비용을 SaaS 플랜 가격에 **반드시** 포함해야 해요.

에이전시가 가장 자주 놓치는 부분이고, 예상하지 못한 애드온 요금이 나오는 원인이 돼요. 이 문서를 따라 하면 이런 일을 피할 수 있어요.

## 1. SaaS 구성기에서 애드온 탭 열기

1. **에이전시 보기 > SaaS 구성기**로 이동하세요.
2. 새 플랜을 만들거나 기존 플랜을 편집하세요.
3. **애드온** 탭으로 이동하세요.
4. 애드온 비용은 서브 계정이 아니라 에이전시에 청구된다는 안내 배너가 보여요.
   - 이 배너는 플랜 가격을 정할 때 애드온 비용을 꼭 반영하라고 알려 줘요.

```
중요: SaaS 플랜에 포함한 애드온 비용은 항상 에이전시에 청구됩니다.
서브 계정에는 개별로 청구되지 않습니다.
```

## 2. 플랜에 포함할 애드온 고르기

유료 애드온 목록과 월 도매가(에이전시에 청구되는 금액)가 보여요.

예시:

- **WordPress**
- **WhatsApp**
- **광고 관리자**
- **리스팅**

플랜에 묶어 제공할 애드온을 클릭해 선택하세요.

## 3. 애드온 총비용 확인하기 (실시간 계산기)

애드온을 선택하면 바로 다음과 같이 동작해요.

- 비용 계산기가 자동으로 업데이트돼요.
- 에이전시에 청구되는 구독자당 월 총비용이 표시돼요.
- 애드온을 선택하거나 해제할 때마다 금액이 즉시 바뀌어요.

그래서 SaaS 플랜 가격을 정하기 전에 실제 도매 비용을 정확히 알 수 있어요.

예시: WordPress($10) + WhatsApp($10) + 광고 관리자($97)를 선택하면 구독자당 월 $117이 들어요.

## 4. 비용에 맞게 SaaS 플랜 가격 정하기

애드온 비용은 에이전시가 내므로 플랜 가격은 다음 조건을 만족해야 해요.

**플랜 가격 ≥ 애드온 비용 + 목표 이익**

애드온 선택 예시:

| 애드온 | 에이전시 비용 |
| --- | --- |
| AI 직원 | $97/월 |
| 브랜드 모바일 앱 | $49/월 |
| WordPress | $10/월 |
| **애드온 총비용** | **$156/월** |

이익률 40%를 목표로 한다면 플랜 가격을 최소 $220~$250/월 올려야 해요.

## 5. 서브 계정이 구독하면 일어나는 일

누군가 SaaS 플랜을 구매하면 다음과 같이 처리돼요.

- 애드온이 자동으로 설치돼요.
- 선택한 모든 애드온 비용이 에이전시에 청구돼요.
- 서브 계정에는 개별로 청구되지 않아요.
- 고객이 구독을 취소해도 애드온은 자동으로 삭제되지 않아요. 직접 확인해서 제거해야 해요.

## 6. 애드온을 포함할 때 권장 사항

- 플랜을 저장하기 전에 항상 계산기를 확인하세요. 총비용을 정확히 알고 저장할 수 있어요.
- 할인이나 프로모션을 제공하기 전에 플랜 가격부터 조정하세요. 애드온 비용이 이익률을 빠르게 깎을 수 있어요.
- 가격이 낮은 플랜에 비싼 애드온을 많이 넣지 마세요. 비용을 에이전시가 부담하는 것이 전략이라면 예외예요.
- 고객에게 어떤 애드온이 패키지에 포함되어 있는지 분명하게 알려 주세요.

## 7. 요약

SaaS 플랜에 애드온을 포함하면 제공하는 상품의 가치를 높일 수 있어요. 다만 플랜 가격을 제대로 정하는 것이 중요해요.

기억할 점:

- 애드온 비용은 서브 계정이 아니라 에이전시에 청구돼요.
- 비용 계산기로 가격을 근거 있게 정할 수 있어요.
- 경고 배너를 보면서 플랜이 수익을 낼 수 있는 가격인지 다시 확인하세요.
