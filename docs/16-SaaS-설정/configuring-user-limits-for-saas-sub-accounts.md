# SaaS 서브 계정 사용자 제한 설정

사용자 제한을 쓰면 SaaS 서브 계정에 추가할 수 있는 서브 계정 수준 사용자 수를 에이전시가 정할 수 있어요. SaaS 플랜별로 허용 인원을 정하고, 필요하면 개별 고객에게만 다른 제한을 적용할 수 있어요. 사용자 제한은 SaaS V1과 SaaS V2 플랜에서 모두 쓸 수 있어요. 이 문서에서는 사용자 제한이 어떻게 동작하는지, **SaaS 구성기**에서 어떻게 설정하는지 안내해요.

## 이 문서에서 배울 내용

사용자 제한이 서브 계정 수준 사용자를 어떻게 제한하는지, 플랜별 허용 인원은 어떻게 설정하는지, 어떤 사용자가 제한에 포함되는지, 고객별 예외 설정은 어떻게 동작하는지 알아봐요.

{% hint style="warning" %}
사용자 제한을 켜지 않으면 SaaS 플랜은 기본적으로 사용자 수를 제한하지 않아요. 설정한 제한은 서브 계정 수준 사용자에게만 적용돼요. 서브 계정에 배정된 에이전시 수준 사용자는 제한에 포함되지 않아요.
{% endhint %}

## SaaS 서브 계정의 사용자 제한이란?

사용자 제한은 SaaS 서브 계정에 추가할 수 있는 서브 계정 수준 사용자의 최대 인원을 정하는 기능이에요. 이 기능으로 SaaS 상품을 구성할 때 플랜마다 다른 사용자 허용 수를 포함할 수 있어요.

사용자 제한을 설정하지 않으면 SaaS 플랜은 기본적으로 사용자 수를 제한하지 않아요. 제한은 서브 계정 수준 사용자에게만 적용돼요. 서브 계정에 배정된 에이전시 수준 사용자는 설정한 제한에 포함되지 않아요.

사용자 제한은 SaaS V1과 SaaS V2 플랜 모두에서 지원돼요.

## 사용자 제한을 쓰면 좋은 점

사용자 제한을 쓰면 SaaS 플랜에 사용자 허용 수를 포함해 구성하면서도, 다른 인원이 필요한 고객에게는 유연하게 대응할 수 있어요.

- 플랜별 사용자 허용 수: SaaS 플랜에서 쓸 수 있는 서브 계정 수준 사용자의 최대 인원을 정해요.
- 유연한 SaaS 상품 구성: 서비스 등급에 맞게 플랜마다 다른 사용자 허용 수를 둘 수 있어요.
- 고객별 예외 설정: 플랜은 그대로 두고, 개별 SaaS 서브 계정에만 다른 사용자 제한을 적용할 수 있어요.
- 플랜 자동 맞춤: 조건에 맞는 플랜 변경으로 새 플랜의 제한이 적용되면, 서브 계정은 그 플랜에 설정된 사용자 제한을 이어받을 수 있어요.

## 사전 확인 사항 및 제한 사항

어떤 사용자가 제한에 포함되는지 알아 두면 플랜별 허용 인원을 알맞게 정할 수 있어요. 에이전시 사용자가 서브 계정 사용자 수에 포함되는 일도 막을 수 있어요.

- 이 기능은 SaaS 플랜을 쓰는 서브 계정에 적용돼요.
- 사용자 제한은 SaaS V1과 SaaS V2 플랜에서 지원돼요.
- 설정한 제한은 서브 계정 수준 사용자에게만 적용돼요.
- 서브 계정에 배정된 에이전시 수준 사용자는 제한에 포함되지 않아요.
- 사용자 제한을 켜기 전까지 SaaS 플랜은 기본적으로 사용자 수를 제한하지 않아요.
- 사용자 제한은 SaaS 서브 계정에 추가할 수 있는 서브 계정 수준 사용자 수를 정해요.

## SaaS 플랜에 사용자 제한 설정하기

플랜에 사용자 제한을 설정하면, 그 SaaS 플랜을 쓰는 서브 계정에서 사용할 수 있는 서브 계정 수준 사용자의 최대 인원이 정해져요.

1. **에이전시 보기**에서 **SaaS 구성기**를 선택하세요.
2. **플랜 & 가격**을 선택하세요.
3. 수정할 SaaS 플랜을 찾으세요.
4. **세부 정보 수정**을 선택하세요.
5. **가격** 탭을 선택하세요.
6. **사용자 제한**을 찾아 토글을 켜세요.
7. 서브 계정에서 허용할 최대 사용자 수를 입력하세요.
8. **변경사항 저장**을 선택하세요.

플랜 적용 방식: 조건에 맞는 서브 계정이 이 플랜을 구독하거나 이 플랜으로 옮겨 오면, 이 플랜에 설정된 사용자 제한이 서브 계정에 적용돼요.

## 특정 서브 계정의 사용자 제한 따로 설정하기

개별 서브 계정에 사용자 제한을 따로 설정하면, 같은 SaaS 플랜을 쓰는 모든 서브 계정의 기본 제한은 그대로 두고 특정 SaaS 고객에게만 다른 사용자 허용 수를 줄 수 있어요.

{% hint style="info" %}
개별 서브 계정의 사용자 제한으로 가는 현재 메뉴 경로는 확인 중이에요. 확인되는 대로 단계별 안내를 추가할 예정이에요.
{% endhint %}

개별 서브 계정에 설정한 제한은 해당 SaaS 플랜에 설정된 사용자 제한보다 우선해요.

기존 사용자 제한 문서에 따르면, 다른 SaaS 플랜으로 업그레이드하면 개별 설정이 초기화되고 새 플랜에 설정된 사용자 제한이 적용돼요.

## 자주 묻는 질문

### SaaS 플랜에는 반드시 사용자 제한을 설정해야 하나요?
아니요. 사용자 제한을 켜고 설정하지 않으면 SaaS 플랜은 기본적으로 사용자 수를 제한하지 않아요.

### 에이전시 수준 사용자도 사용자 제한에 포함되나요?
아니요. 제한은 서브 계정 수준 사용자에게만 적용돼요. 서브 계정에 배정된 에이전시 수준 사용자는 제한에 포함되지 않아요.

### SaaS V1과 SaaS V2 플랜 모두에서 사용자 제한을 쓸 수 있나요?
네. 사용자 제한은 SaaS V1과 SaaS V2 플랜 모두에서 지원돼요.

### SaaS 서브 계정 하나만 플랜과 다른 사용자 제한을 적용할 수 있나요?
네. 사용자 제한은 개별 서브 계정에 따로 설정할 수 있어서, 고객별로 SaaS 플랜의 기본 허용 수와 다른 제한을 둘 수 있어요.
