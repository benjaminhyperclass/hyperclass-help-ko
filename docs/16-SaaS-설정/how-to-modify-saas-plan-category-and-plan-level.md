# SaaS 플랜의 카테고리와 플랜 레벨 변경하기

SaaS 플랜의 **카테고리**나 **플랜 레벨**을 바꿔 플랜 구성을 다시 정리하는 방법을 안내해요.

## 1단계: 플랜 편집 화면 열기

1. **SaaS 구성기 > Plans**(플랜)로 이동하세요.
2. 수정할 플랜을 선택하세요.

![플랜 목록에서 수정할 플랜을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054539634/original/28BbbHO9pAff0ZpJDGn4CVO8z_pqkRXpYg.png?1758779866)

## 2단계: 카테고리와 플랜 레벨 수정하기

1. **Category Settings**(카테고리 설정)에서 **편집**을 클릭하세요.
2. 다른 카테고리로 옮기려면 다음과 같이 하세요.
   - **카테고리 선택** 드롭다운에서 카테고리를 고르세요. 같은 통화의 카테고리만 표시돼요.
3. 플랜 레벨을 바꾸려면 다음과 같이 하세요.
   - 카테고리 안에서 플랜의 계층 위치를 조정하세요.
4. 선택한 내용을 확인하세요.

![카테고리와 플랜 레벨을 수정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054539637/original/zwWKfXLJcQnTSRNxRfzWWYClsLJE2heSAg.png?1758779879)

## 3단계: 저장하고 영향 확인하기

1. **변경사항 저장**을 클릭하세요.
2. 새 카테고리에서 영향을 받는 플랜을 확인하세요. 이동한 플랜의 기능은 상위 플랜으로 이어지고, 이동한 플랜은 아래 레벨 플랜의 기능을 이어받아요.

## 중요 사항

- 기존 고객의 플랜은 소급해서 바뀌지 않아요. 플랜은 그대로 유지되지만, 업그레이드·다운그레이드 경로는 업데이트돼요.
- 기능에 미치는 영향은 다음과 같아요.
  - 위 레벨의 플랜은 이동한 플랜의 기능을 이어받아요.
  - 이동한 플랜은 아래 레벨 플랜의 기능을 이어받아요.

```
