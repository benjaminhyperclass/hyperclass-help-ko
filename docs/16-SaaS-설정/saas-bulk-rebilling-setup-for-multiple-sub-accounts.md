# 여러 서브 계정에 재청구 마크업 한 번에 설정하기

여러 서브 계정의 재청구 마크업을 한 번에 설정하는 방법을 안내해요. 에이전시 관리자는 이 기능으로 시간을 아끼고, 가격을 일정하게 유지하며, 계정이 많아도 효율적으로 운영할 수 있어요.

## 재청구 마크업 일괄 설정이란?

재청구 마크업 일괄 설정은 여러 서브 계정에 재청구 마크업을 동시에 적용하는 기능이에요. 예전에는 계정마다 따로 설정해야 해서 시간이 오래 걸리고 실수하기도 쉬웠어요. 이제는 수십~수백 개의 서브 계정에 같은 마크업 기준을 바로 적용할 수 있어요. 서비스 수익화를 더 일관되고 효율적으로 관리할 수 있어요.

## 재청구 마크업 일괄 설정의 장점

마크업을 일괄 적용하면 청구 업무가 간소해지고, 모든 고객에게 같은 가격 정책을 적용할 수 있어요.

- 시간 절약: 계정마다 반복해서 수정하지 않아도 되므로 매달 몇 시간을 아낄 수 있어요.
- 일관된 수익: 모든 고객에게 같은 마크업 기준을 적용하므로 마진을 예측하기 쉬워요.
- 운영 확장성: 새 서비스나 가격 변경을 수백 개 계정에 한 번에 적용할 수 있어요.
- 오류 감소: 설정을 한곳에서 관리하므로 마크업이 서로 다르거나 빠지는 위험이 줄어요.
- 빠른 온보딩: SaaS 온보딩 자동화와 함께 쓰면 새 고객을 더 빨리 시작하게 할 수 있어요.

## 일괄 작업 기록

일괄 작업은 모두 **Bulk Action History**(일괄 작업 기록)에 남아요. 여기서 작업 상태를 확인하고, 지난 작업의 상세 내용을 볼 수 있어요. 지원되는 경우에는 작업을 되돌리거나 다시 실행할 수도 있어요. 이 기록 덕분에 팀은 변경 내용을 검증하고, 어떤 계정이 업데이트되었는지 추측하지 않고 문제를 확인할 수 있어요.

**Bulk Action History**를 열려면 **서브 계정** 페이지에서 **일괄 작업** 옆에 있는 **Clock Icon**(시계 아이콘)을 클릭하세요.

**Bulk Action History**에 대한 자세한 내용은 「SaaS 서브 계정을 한 번에 쉽게 관리하는 방법」 문서를 참고하세요.

## 재청구 마크업을 일괄 설정하는 방법

계정이 많아도 쉽고 빠르게 설정할 수 있어요.

#### 1단계: 서브 계정 선택

1. **에이전시 대시보드**에서 **서브 계정**을 클릭하세요.
2. 업데이트할 서브 계정마다 옆의 체크박스를 선택하세요. 계정이 많으면 **필터**를 쓰거나 **전체 선택**을 클릭하세요.

![서브 계정 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050453495/original/HVJvoPlPNRJ8o9CtQjEJiZzd2kCv7P_iTA.png?1753457897)

#### 2단계: 일괄 작업

1. 오른쪽 위의 **일괄 작업**을 클릭하세요.
2. 드롭다운 메뉴에서 **재청구 활성화**를 선택하세요.

![일괄 작업 메뉴에서 재청구 활성화 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050453557/original/F6Xw9BNcotobxuIsZVR9XkvuXGRudgjzBg.png?1753457934)

#### 3단계: 결제 제공업체 선택

1. 팝업에서 연결된 **결제 제공업체**(예: Stripe)를 선택하고 **계속**을 클릭하세요.
2. 연결된 **결제 제공업체**가 없으면 먼저 연결해야 해요. 설정 방법은 「시작하기 - Stripe 연결」 문서를 참고하세요.

![결제 제공업체 선택 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050453624/original/V_gRwEifJTHTeaXw5b0e2SwXDJkWTxRwlw.png?1753457977)

#### 4단계: 마크업 설정

1. **Configure Rebilling Services**(재청구 서비스 설정) 창에는 사용량 기반 서비스(전화, 이메일, AI 등)가 목록으로 나와요.
2. 전체 슬라이더 **Enable rebilling on all services and apply same markup**(모든 서비스에 재청구를 활성화하고 같은 마크업 적용)을 끌어서 모든 서비스에 같은 배수를 설정하세요.
3. 서비스별로 세밀하게 조정하려면 각 서비스의 슬라이더를 따로 조정하세요.
4. 서비스별 요율 상세 내역을 보려면 각 서비스 옆의 **화살표** 아이콘을 클릭하세요.

![재청구 서비스별 마크업 설정 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050453681/original/2SrOyRvoQae2FsAvc4uq9VfrEE3U_7sD0w.png?1753458037)

#### 5단계: 작업 확인

1. 요약 창에 선택한 서브 계정 수가 표시돼요.
2. 내용을 확인한 뒤 **재청구 활성화**를 클릭해 확정하세요.

![작업 확인 요약 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050453722/original/DzwvRgUGBAj1KZNRnJP0MqLabjA_JQUqEw.png?1753458077)

#### 6단계: 재청구 활성화 확인

- 서브 계정에 등록된 카드가 이미 있으면 새 마크업 설정으로 재청구가 바로 활성화돼요.
- 서브 계정에 결제 수단이 아직 없으면 선택한 결제 제공업체에 고객 프로필이 만들어져요. 서브 계정 관리자가 카드를 추가하면 미리 정해 둔 마크업으로 재청구가 자동으로 활성화돼요.

## 중요 사항 및 권장 사항

아래 내용을 알아 두면 문제를 피하고 이 기능을 더 효율적으로 쓸 수 있어요.

- 결제 수단이 없는 서브 계정은 카드가 추가될 때까지 재청구가 시작되지 않아요. 다만 마크업 설정은 저장되어 준비된 상태로 남아요.
- 마크업 비율이 에이전시의 전체 가격 정책과 수익 목표에 맞는지 다시 확인하세요.
- 모든 서브 계정이 현재 정책과 일치하도록 마크업 설정을 주기적으로 점검하세요.
- 새 서브 계정의 표준 온보딩 절차와 이 기능을 함께 쓰도록 내부 업무 매뉴얼(SOP)을 만들어 보세요.

## 자주 묻는 질문

### 일괄 설정을 한 뒤에 마크업을 개별로 수정할 수 있나요?
네. 나중에 필요하면 서브 계정별로 마크업을 언제든 조정하거나 덮어쓸 수 있어요.

### 이미 사용자 지정 마크업이 설정된 서브 계정은 어떻게 되나요?
일괄 설정을 하면 기존 마크업이 새로 지정한 일괄 설정으로 덮어써져요.

### 재청구를 일괄로 비활성화할 수도 있나요?
이 기능은 마크업을 일괄로 활성화하고 설정하기 위한 기능이에요. 비활성화는 서브 계정마다 개별로 해야 해요.

### 등록된 카드가 없는 계정도 재청구가 자동으로 활성화되나요?
서브 계정 관리자가 프로필에 카드를 추가하면 재청구가 자동으로 활성화돼요.
