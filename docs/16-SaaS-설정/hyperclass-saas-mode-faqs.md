# 하이퍼클래스 SaaS 모드 자주 묻는 질문

청구/결제, SaaS 구성, 서브 계정, 결제, 인증과 관련해 자주 나오는 질문을 모았어요. SaaS 모드를 쓰다가 막혔을 때 먼저 확인해 보세요.

---

## 청구/결제와 지갑

### 서브 계정 청구/결제 페이지에서 마지막 카드를 삭제하려면 어떻게 하나요?

카드가 하나만 있으면 서브 계정의 **청구/결제** 페이지에서는 삭제할 수 없어요.

대신 이렇게 해 보세요.

- Stripe에서 해당 고객에 접근할 수 있다면 Stripe에서 카드를 직접 삭제하세요.
- SaaS V2에서는 카드 관리가 에이전시 수준에서만 가능할 수 있어요.

### 카드를 바꿨는데 여러 서브 계정에 함께 반영돼요

여러 서브 계정이 같은 Stripe Customer ID를 쓰고 있을 때 생기는 현상이에요.

해결 방법: 서브 계정마다 서로 다른 Stripe 고객을 지정하세요.

- 해당 서브 계정에서 **SaaS 비활성화**를 실행하세요.
- 다음 방법 중 하나로 다시 활성화하세요.
  - 공유 링크
  - **SMS로 요청** 또는 이메일 요청

### 고객이 결제 정보를 추가할 수 없어요

**자주 나오는 오류**
`No such customer``stripe.confirmPayment()...`

**가능한 원인**

- Stripe 고객이 삭제되었어요.
- Stripe 계정이 바뀌었어요.
- 서브 계정이 에이전시 간에 이전되었어요.

**해결 방법**

- **SaaS 비활성화**를 실행한 뒤 다시 활성화해서 연결 정보를 새로 만드세요.

### 인도 고객이 결제 정보를 추가할 수 없어요

RBI(인도 중앙은행) 규정에 따라 청구 주소가 필요해요.

**해결 방법**: Stripe 대시보드에서 청구 주소를 추가하세요.

### 자동 충전이 계속 실패해요

자동 충전은 3DS 전용 카드를 지원하지 않아요.

**해결 방법**

- 3DS를 지원하되 3DS 전용은 아닌 카드를 사용하세요.
- 또는 수동으로 충전하세요.

### SaaS를 비활성화하면 어떻게 되나요?

- 구독이 취소돼요.
- 지갑이 영구 삭제돼요.
- 환불은 에이전시가 직접 처리해야 해요.

비활성화한 뒤에는 이렇게 돼요.

- 에이전시가 지갑 잔액을 이메일로 받아요.
- 환불하거나 크레딧을 수동으로 추가할 수 있어요.

### 청구/결제 페이지에서 마지막 카드를 삭제하려면 어떻게 하나요?

마지막으로 남은 카드는 삭제할 수 없어요. 현재 기본 카드로 설정된 카드도 삭제할 수 없어요. 카드를 삭제하려면 계정에 다른 결제 수단이 남아 있어야 하고, 삭제할 카드가 기본 카드로 설정되어 있지 않아야 해요.

## 웰컴 이메일

### 커스텀 값이 채워지지 않아요

커스텀 값은 **SaaS 구성기 > 고급 설정**에서 설정해야 해요. 서브 계정에서 직접 수정하는 방식은 지원되지 않아요.

### 웰컴 이메일의 기본 제목은 무엇인가요?

"Activate your account"예요.

### 내가 만든 이메일 대신 기본 이메일이 발송돼요

**[Do Not Edit] SaaS Configurator Templates**에 템플릿이 없을 때 이런 일이 생겨요.

**해결 방법**

- 하이퍼클래스 고객지원에 요청해서 에이전시 **웰컴 이메일**을 초기화하세요.

### 웰컴 이메일은 누가 받나요?

서브 계정에 새로 만들어진 모든 사용자가 받아요.

### 웰컴 이메일이 엉뚱한 서브 계정으로 연결돼요

하이퍼클래스 고객지원에 요청해서 에이전시 **웰컴 이메일**을 초기화하세요.

## 서브 계정과 구독

### 서브 계정이 중복으로 만들어져요

다음 경로로 구매가 이루어지면 새 서브 계정이 자동으로 만들어져요.

- Stripe
- 퍼널
- 판매 링크

중복을 피하려면 기존 계정은 **고객 관리** 페이지에서 처리하세요.

### 퍼널로 구매했는데 서브 계정이 만들어지지 않아요

상품이 **Agency Plan**(에이전시 플랜)으로 지정되어 있는지 확인하세요.

{% hint style="info" %}
테스트 모드로 구매하면 서브 계정이 만들어지지 않아요.
{% endhint %}

### 구독을 다른 서브 계정으로 옮기려면 어떻게 하나요?

1. 두 서브 계정이 같은 Stripe 고객을 쓰는지 확인하세요.
2. 원래 계정에서 **SaaS 비활성화**를 실행하세요. 이때 구독은 취소하지 마세요.
3. 대상 계정을 새로고침하세요. 구독이 자동으로 연결돼요.

### 플랜을 업그레이드할 수 없어요

서브 계정이 이미 해당 카테고리에서 가장 높은 플랜일 수 있어요.

### 월간 플랜과 연간 SaaS 플랜 사이를 바꿀 수 없어요

SaaS V2 구독은 기존 구독의 결제 주기를 바꾸는 기능을 아직 지원하지 않아요.

SaaS V2에서 지원하는 플랜 변경은 다음과 같아요.

- **매월** → **매월**
- **매년** → **매년**

SaaS V2에서 지원하지 않는 변경은 다음과 같아요.

- **매월** → **매년**
- **매년** → **매월**

잘못된 청구를 막기 위해 업그레이드 과정에서 이 옵션들은 숨겨져 있어요. 이 제한은 SaaS V2 구독에만 적용돼요. SaaS V1 구독은 Stripe가 결제 주기 변경을 자체적으로 처리하기 때문에 영향을 받지 않아요.

### SaaS 계정을 다른 에이전시로 이전하려면 어떻게 하나요?

1. 모든 서브 계정에서 **SaaS 비활성화**를 실행하세요.
2. 서브 계정을 이전하세요.
3. 지갑 잔액은 직접 처리하세요.

## SaaS 구성기와 요금제

### "Invalid price currency" 오류가 표시돼요

**Invalid price currency**(가격 통화가 올바르지 않음) 오류는 가격의 통화와 카테고리의 통화가 다를 때 나타나요.

**해결 방법**

- **SaaS 구성기**에서 가격을 수정하세요.
- 그다음 Stripe에서 통화를 수정하세요.

{% hint style="info" %}
다음 경우에는 통화를 바꿀 수 없어요.

- 판매 링크가 있는 경우
- 활성 구독이 있는 경우
{% endhint %}

### Stripe Connect 연결을 해제하려면 어떻게 하나요?

활성 SaaS 청구가 Stripe에 의존하고 있으면 Stripe 연결을 해제할 수 없어요.

**진행 순서**

1. **에이전시 설정 > Stripe Connect**(Stripe 계정 연결)로 이동하세요.
2. 해제를 막고 있는 서브 계정을 확인하세요.
3. 해당 계정에서 **SaaS 비활성화**를 실행하세요.
4. 연결 해제를 다시 시도하세요.

### Stripe 연결을 해제할 수 없고 활성 고객 관련 오류가 나와요

해당 Stripe 계정을 쓰는 서브 계정에서 SaaS가 아직 켜져 있기 때문이에요.

**해결 방법**: 해당하는 모든 서브 계정에서 먼저 **SaaS 비활성화**를 실행하세요.

### SaaS V1 또는 V2 플랜이 보이지 않아요

SaaS를 설정할 때 선택한 항목에 따라 달라져요.

- Stripe를 선택하면 SaaS V1이에요.
- **에이전시 서브 계정**을 선택하면 SaaS V2예요.

**해결 방법**

- **SaaS 비활성화**를 실행하세요.
- 올바른 옵션을 선택해서 다시 활성화하세요.

### SaaS V1과 V2는 무엇이 다른가요?

**SaaS V1**

- Stripe만 지원해요.
- 에이전시 수준에서 설정해요.

**SaaS V2**

- 여러 결제 제공업체(Stripe, NMI, Authorize.net, Square)를 지원해요.
- 서브 계정별로 설정해요.

### SaaS V1과 V2를 함께 쓸 수 있나요?

아니요. 서브 계정은 한 번에 한 가지 모드만 쓸 수 있어요.

### 월간 플랜과 연간 플랜 사이를 바꿀 수 없어요

- SaaS V1: 변경할 수 있어요.
- SaaS V2: 같은 결제 주기 안에서만 변경할 수 있어요.

## 보안과 인증

### 2단계 인증(2FA)을 꺼 뒀는데도 요구해요

- **이메일 인증**은 필수예요.
- 전화 인증만 끌 수 있어요.

### 리빌링이 켜지지 않거나 하이퍼클래스로 이전되지 않아요

계정이 **인증 대기 중** 상태이기 때문이에요.

**해결 방법**

- 이메일과 전화 **인증 완료**를 진행하세요.
- 또는 **고객 관리**에서 수동으로 인증하세요.

### 서브 계정에 "Manual Verification Pending"이 표시돼요

**Manual Verification Pending**(수동 인증 대기 중)은 이메일 또는 전화 인증이 아직 끝나지 않았기 때문에 표시돼요. 일시정지 설정 때문이 아니에요.

{% hint style="warning" %}
- 계정 접근을 막지는 않아요.
- 처음 전화번호를 구매할 때는 인증이 필요해요.
{% endhint %}

### 서브 계정이 "Paused due to pending approval" 상태예요

**Paused due to pending approval**(승인 대기로 일시정지됨)은 **SaaS 구성기 > 보안 > 새 서브 계정 일시정지** 설정으로 정해져요.

**해결 방법**

- 다음 위치에서 승인하거나 거절하세요.
  - **고객 관리** 페이지
  - **요청** 섹션

## 대시보드와 공개 범위

### 에이전시 대시보드가 보이지 않아요

공개 범위 설정에 따라 보이는 사람이 달라져요.

- **Only Me**(나만): 소유자만 볼 수 있어요.
- **All Admins**(모든 관리자): 모든 관리자가 볼 수 있어요.

**해결 방법**

- **에이전시 설정 > Stripe**에서 변경하세요.

---

해결되지 않는 문제가 있다면 하이퍼클래스 고객지원에 문의하세요.
