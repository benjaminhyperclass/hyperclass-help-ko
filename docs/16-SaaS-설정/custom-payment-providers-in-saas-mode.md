# SaaS 모드의 커스텀 결제 제공업체

SaaS 모드에서는 **앱 마켓플레이스**의 결제 제공업체 앱을 연결해 쓸 수 있어요. Stripe나 Square 같은 기본 연동을 쓰기 어려운 지역에서도 SaaS 가입과 결제를 운영할 수 있습니다. 에이전시 관리자가 설정하는 기능이에요.

## SaaS 모드의 커스텀 결제 제공업체란?

에이전시는 자신의 시장에 가장 잘 맞는 결제 제공업체를 골라 연결할 수 있어요. 이 기능을 쓰면 다음 작업을 할 수 있습니다.

- 결제 과정에서 서브 계정을 자동으로 만들어요.
- SaaS 요금제를 서브 계정에 연결해요.
- 반복 결제와 지갑 충전을 관리해요.

다양한 해외 결제 서비스를 활용할 수 있다는 점도 장점이에요.

---

## 주요 장점

SaaS 사업에 맞는 결제 환경을 만들 수 있어요.

- **앱 마켓플레이스**에 있는 50개 이상의 결제 제공업체 중에서 고를 수 있어요.
- 기본 결제 연동이 잘 지원되지 않는 지역에서도 쓸 수 있어요.
- 결제할 때 서브 계정 생성과 SaaS 요금제 연결이 자동으로 이루어져요.
- 반복 구독 결제를 지원해서 안정적인 매출을 유지할 수 있어요.
- 애드온을 재판매할 수 있어 마켓플레이스 생태계가 더 넓어져요.

---

## 커스텀 결제 제공업체로 SaaS 모드 설정하기

아래 순서대로 설정하면 커스텀 결제 연동을 바로 쓸 수 있어요.

### 1단계: 에이전시 서브 계정 지정하기

1. **에이전시 보기**에서 **서브 계정**으로 이동하세요.
2. 에이전시의 결제용 계정으로 쓸 서브 계정을 찾으세요.
3. 점 세 개 메뉴를 클릭한 뒤 **Add as agency sub-account**(에이전시 서브 계정으로 추가)를 선택하세요.
4. 이 서브 계정이 에이전시 서브 계정이 돼요. 여기에서 결제 제공업체를 설치하고, SaaS 상품을 만들고, 결제를 처리합니다.

![에이전시 서브 계정으로 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056921337/original/LWLQQPbkMalmRdgDJ39NCmpIFLh0TzYkxg.png?1761575862)

### 2단계: 결제 제공업체 앱 설치하기

1. 에이전시 보기에서 **앱 마켓플레이스**로 이동하세요.
2. 사용할 결제 제공업체 앱을 검색해서 선택하세요. **카테고리**에서도 결제 제공업체를 찾을 수 있어요.
3. **설치**를 클릭하고 에이전시 서브 계정에 추가하세요.

![앱 마켓플레이스에서 결제 제공업체 앱을 설치하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056921626/original/HaOjaK-tIxCyJ_Bel4ZZ_ikT6rQyMDxhhQ.png?1761576036)

### 3단계: 연동 설정하기

1. 설치가 끝나면 해당 결제 제공업체의 설정으로 이동하세요.
2. 필요한 정보를 입력하세요. 보통 다음 항목이 필요해요.
   - **Account ID**(계정 ID)
   - **Authorization / API token**(인증 / API 토큰)
3. 설정을 저장하세요.

![결제 제공업체 연동 정보를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053365365/original/0M65QOepAKgw76Q7RwQaCZojvzksg_cIAw.png?1757412905)

{% hint style="info" %}
결제 제공업체마다 필요한 항목이 조금씩 달라요. 정확한 입력 항목은 해당 앱의 문서를 확인하세요.
{% endhint %}

### 4단계: SaaS 상품 만들고 판매하기

1. 에이전시 서브 계정에서 SaaS 상품을 만드세요.
2. 결제 링크를 공유하거나, 퍼널에 체크아웃을 삽입하세요.
3. 결제가 완료되면 다음 작업이 자동으로 이루어져요.
   - 새 서브 계정이 만들어져요.
   - 선택한 SaaS 요금제가 그 계정에 연결돼요.

자세한 내용은 **SaaS 구성기**의 **시작하기** 문서를 참고하세요.

### 5단계: 기존 서브 계정을 SaaS로 전환하기

1. 에이전시 보기에서 **서브 계정 > 고객 관리**로 이동하세요.
2. **SaaS > Add SaaS Subscription**(SaaS 구독 추가)으로 이동하세요.
3. 연동한 결제 제공업체를 선택하세요.
4. 적용할 SaaS 요금제를 선택한 뒤 확인하세요.

자세한 내용은 [기존 서브 계정을 SaaS 모드 구독 요금제로 전환하기](Saas-Mode/convert-existing-sub-account-to-saas-mode-subscription-plan.md) 문서를 참고하세요.

{% hint style="info" %}
결제가 완료되지 않아 SaaS 요금제가 **On Hold**(보류) 상태로 남아 있으면, 에이전시 관리자가 SaaS 모드를 끄지 않고도 보류 중인 요금제를 분리할 수 있어요. **에이전시 보기 > 서브 계정 > 고객 관리 > SaaS**에서 분리하세요. 보류 중인 요금제를 분리하면 서브 계정에 다시 접근할 수 있고, 기존 고객 프로필은 그대로 연결돼 있어요.
{% endhint %}

### 6단계: 지갑과 애드온 관리하기

- **지갑 충전**: 자동 충전과 수동 충전을 모두 지원해요.
- **애드온 재판매**:
  - AI 직원, WordPress, 마켓플레이스 앱 같은 애드온을 판매할 수 있어요.
  - 애드온 결제 금액은 서브 계정의 지갑에서 차감돼요. 카드로 바로 청구되지 않아요.

자세한 내용은 [SaaS 지갑 크레딧 관리 - 서브 계정 단위](Saas-Mode/saas-wallet-credit-management-sub-account-level.md) 문서를 참고하세요.

## 자주 묻는 질문

### SaaS 모드의 커스텀 결제 제공업체는 무엇이고, 왜 중요한가요?
에이전시가 원하는 결제 제공업체를 연결해서 계정 생성, 반복 결제, 지갑 관리 같은 작업을 자동화할 수 있는 기능이에요. 해외 SaaS를 운영할 때 더 유연하게 대응할 수 있어요.

### 어떤 결제 제공업체를 쓸 수 있나요?
반복 결제와 오프세션 결제(고객이 결제 화면에 없을 때 자동으로 결제하는 방식)를 지원하는 제공업체만 쓸 수 있어요. Razorpay처럼 이 기능을 지원하지 않는 제공업체는 쓸 수 없어요.

### 커스텀 결제 제공업체에서 반복 구독 결제는 어떻게 이루어지나요?
설정을 마치면 시스템이 고객의 결제 수단을 안전하게 저장하고, SaaS 요금제의 반복 결제를 자동으로 처리해요. 그래서 서비스와 매출이 끊기지 않아요.

### 기존 서브 계정을 커스텀 결제 제공업체를 쓰도록 전환할 수 있나요?
네, 할 수 있어요. **에이전시 보기 > 서브 계정 > 고객 관리 > SaaS > Add SaaS Subscription**(SaaS 구독 추가)으로 이동하세요. 그런 다음 연동한 결제 제공업체와 원하는 요금제를 선택하면 돼요.

### 더 자세한 설정 안내는 어디에서 볼 수 있나요?
하이퍼클래스 고객지원 문서에서 커스텀 결제 제공업체 관련 안내를 확인하세요.
