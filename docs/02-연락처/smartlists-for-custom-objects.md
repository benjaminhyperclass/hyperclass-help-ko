# 사용자 지정 객체용 스마트 리스트 사용하기

**사용자 지정 객체**의 데이터를 원하는 조건으로 걸러 저장해 두고, 팀 전체와 함께 쓸 수 있는 스마트 리스트 기능을 소개해요. 목록을 만들고, 관리하고, 공유하는 방법을 순서대로 안내해요.

## 새로 생긴 기능

- 스마트 리스트 만들기: **사용자 지정 객체**에 맞춘 보기를 만들 수 있어요.
- 스마트 리스트 검색: **스마트 리스트 관리**로 들어가 원하는 스마트 리스트를 바로 검색할 수 있어요.
- 간편한 전환: 여러 스마트 리스트 사이를 자연스럽게 오갈 수 있어요.
- 열 너비 조절: 열 너비를 조절하고 설정을 저장할 수 있어요.
- 간편한 공유
  - 목록 공유: 스마트 리스트를 팀 전체 또는 선택한 멤버와 공유할 수 있어요.
  - **권한**: 사용자별로 보기 전용 또는 편집 권한을 지정할 수 있어요.
  - 직접 링크: 링크로 목록을 공유해 팀 모두가 같은 화면을 볼 수 있어요.
- 체계적인 관리
  - 목록 복제: 기존 스마트 리스트를 빠르게 복제해 변형본을 만들 수 있어요.
  - 이름 변경, 내보내기, 삭제: 필요에 따라 스마트 리스트의 이름을 바꾸거나 내보내거나 삭제할 수 있어요.
  - 관리자 기능: 관리자는 모든 스마트 리스트를 관리하고 확인할 수 있어요.

## 사용 방법

### 1. 스마트 리스트 만들고 보기

1. 스마트 리스트를 만들 **사용자 지정 객체**로 이동해요. 예: **작업**

   ![사용자 지정 객체 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607627/original/UjYr3rXU7qfGlRjkeWbW5etZnpSKyvqtBg.png?1745503204)

### 2. 필터와 열 설정하기

스마트 리스트는 상세 필터, 정렬, 표시할 열을 조합해 저장하는 목록이에요. 이 조합 덕분에 데이터를 목적에 맞게 정리해 볼 수 있어요.

새 목록을 만들려면 먼저 다음과 같이 설정해요.

1. **상세 필터**를 클릭하고 필터 조건을 선택해요.
2. 표시할 열을 선택하고 정렬 순서를 설정해요.

![상세 필터와 열 설정 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045606731/original/LoHD0N6tsB3RYssAl1_-ME2dd9VjGCxmxg.png?1745502572)![상세 필터와 열 설정 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045606732/original/If4arwqvvFM9deXsgThTAZJDDCEkQ2OsEg.png?1745502572)

### 3. 스마트 리스트 저장하기

1. **+ List**(목록 추가) 아이콘을 클릭해요.
2. 목록 이름을 입력하고, 필터·열·정렬을 확인한 뒤 **만들기**를 클릭해요.

### 4. 스마트 리스트 관리하기

1. 편집: **목록 사용자 지정**을 클릭해 필터, 정렬 순서, 열을 조정해요.

   ![목록 사용자 지정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607892/original/yusWObNPbovAuNvRiuCRXsXQ0vtr303UTg.png?1745503419)

2. 복제: **중복**을 선택하고 새 이름을 입력한 뒤 **만들기**를 클릭해요.

   ![스마트 리스트 복제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045604846/original/N6VQvpGeD1WPdHC2py765NPNyXehttOFjA.png?1745501203)

3. 내보내기: **내보내기**를 클릭하면 목록 데이터를 내려받을 수 있어요.
4. 삭제: 필요 없는 목록은 **옵션 삭제**를 사용해 지워요.

### 5. 공유와 권한 설정하기

1. 기본적으로 서브 계정의 관리자와 사용자에게 공개돼요.
2. 접근 권한을 바꾸려면 **Share**(공유)를 클릭하고, 선택한 사용자에게 **View**(보기) 또는 **편집** 권한을 지정해요.

   ![공유와 권한 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045604845/original/FDDKQ_qeAfD6Rljc2qrRu2Ah7YxSooTkJQ.png?1745501203)

### 6. 스마트 리스트 빠르게 만들기

1. 원하는 **상세 필터**를 적용한 뒤 unsaved changes(저장하지 않은 변경 사항)를 클릭해요.

   ![저장하지 않은 변경 사항 클릭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607918/original/Yw2C_lGgO4jStwMFX0HnT957Aw_baHyPRQ.png?1745503442)

2. 오른쪽 위의 **Unsave Changes**를 클릭한 다음 **Save as New SmartList**(새 스마트 리스트로 저장)를 클릭해요.

   ![새 스마트 리스트로 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045604844/original/0MMzTQVFsB5CMrzr9wzEm5WXz8-PSjMU3g.png?1745501203)

### 7. 스마트 리스트 검색하기

검색 기능으로 여러 스마트 리스트 중에서 원하는 목록을 찾을 수 있어요.

1. 점 세 개(•••) 메뉴 > **스마트 리스트 관리**를 클릭해요.
2. **검색** 입력란에 키워드를 입력해요.

   ![스마트 리스트 관리 검색 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045608172/original/-Lmc4ClVA-t-aNdKy06b1Dwlcdq-x2fqww.png?1745503658)![스마트 리스트 관리 검색 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045607976/original/36io1Rg12jUIAkmWJ8y5JEdgX1cKA5ez6w.png?1745503498)

## 활용 팁

- 스마트 리스트 이름은 한눈에 알아볼 수 있게 분명하게 지으세요.
- 공유 권한은 주기적으로 확인하고 업데이트하세요.
