# 회사 일괄 가져오기

CSV 파일을 올려 회사 레코드를 한꺼번에 만들거나 업데이트하는 방법을 안내해요. 안내에 따라 단계별로 진행하는 가져오기 마법사를 사용해요.

이 문서에서는 **실험실**에서 기능을 켜는 방법, 4단계 가져오기 마법사의 흐름, 필드 매핑, 중복 처리, 가져오기 진행 상황과 통계 확인 방법을 설명해요.

{% hint style="info" %}
이 기능은 현재 **실험실**에서 제공해요. 일괄 가져오기를 쓰려면 먼저 서브 계정의 **실험실** 설정에서 **Company and Custom Object Import**(회사 및 사용자 지정 객체 가져오기)를 켜야 해요.
{% endhint %}

## 회사 일괄 가져오기란?

회사 일괄 가져오기는 CSV 파일로 CRM의 회사 레코드를 한꺼번에 만들고 업데이트하는 도구예요. 4단계 마법사가 파일 업로드, 필드 매핑, 중복 처리, 데이터 확인까지 차례로 안내해요.

가져오기 방식은 세 가지예요. 새 회사 만들기, 기존 회사 업데이트하기, 만들기와 업데이트를 한 번에 하기 중에서 고를 수 있어요. 중복은 **회사 ID** 필드로 찾아요. 그래서 이미 있는 레코드는 새로 만들어지지 않고 업데이트돼요.

가져오기가 끝나면 성공, 오류, 경고 건수별 통계가 나와요. 점검이나 문제 해결에 쓸 수 있는 보고서도 내려받을 수 있어요.

## 이럴 때 편해요

회사 일괄 가져오기를 쓰면 레코드를 하나씩 입력하는 수고를 크게 줄일 수 있어요. 고객사 데이터를 옮기는 에이전시나 여러 곳에 흩어진 회사 정보를 모으려는 중소기업에 특히 유용해요.

- 빠른 CRM 이전: 회사 레코드 수백~수천 건을 하나씩 입력하지 않고 몇 분 만에 가져와요.
- 똑똑한 중복 관리: **회사 ID**를 기준으로 기존 회사를 자동으로 찾아 업데이트하므로 중복이 생기지 않아요.
- 필드 단위 보호: **Don't update to empty value**(빈 값으로 업데이트하지 않기) 옵션을 켜면 기존 레코드를 업데이트할 때 데이터가 실수로 덮어써지는 걸 막을 수 있어요.
- 상세한 가져오기 통계: 가져오기를 마칠 때마다 성공, 오류, 경고 건수를 확인하고 문제를 빠르게 해결할 수 있어요.
- 감사 기록: 가져오기 보고서를 내려받아 규정 준수 확인, 문제 해결, 기록 보관에 활용할 수 있어요.

## 회사 및 사용자 지정 객체 가져오기 켜기

회사 일괄 가져오기를 쓰려면 먼저 **실험실**에서 기능을 켜야 해요. 실험실 기능은 실험적이거나 先행 공개된 기능이라서 서브 계정마다 직접 켜야 해요.

1. 서브 계정으로 이동한 뒤 설정 메뉴에서 **실험실**을 선택해요.
2. **Company and Custom Object Import** 토글을 찾아 켜요.
3. CRM의 **회사** 화면으로 이동해서 **가져오기** 버튼이 보이는지 확인해요.

## 회사 가져오기

아래 순서대로 회사 레코드 일괄 가져오기를 시작해요. 시작하기 전에 CSV 파일 형식이 올바른지, 가져올 데이터가 들어 있는지 확인하세요.

1. CRM에서 **회사**로 이동한 뒤 **가져오기** 버튼을 클릭해요.

   ![회사 화면의 가져오기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077955661/original/c8GQRG6z8wRZTctfPVw3AFyJEg6p_lQkLQ.png?1786246895)

2. 객체 선택 화면에서 가져올 유형으로 **회사**를 선택해요.
3. **클릭하여 업로드**를 눌러 CSV 파일을 선택하거나, 파일을 업로드 영역으로 끌어다 놓아요.

   ![CSV 파일 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077955663/original/Z_nEWh5sDVvpHa7zCRX5fMq7MvHkhsmJ_w.png?1786246910)

4. 가져오기 방식을 세 가지 중 하나로 선택해요: **Create companies**(회사 만들기), **Update companies**(회사 업데이트), **Create & update companies**(회사 만들기 및 업데이트).
5. 중복 확인 기준으로 **회사 ID**를 선택해요. 이렇게 하면 기존 레코드가 중복 생성되지 않고 업데이트돼요.
6. CSV의 각 열을 하이퍼클래스의 해당 회사 필드와 연결해요. 미리보기 데이터를 보면서 연결이 맞는지 확인할 수 있어요.

   ![CSV 열과 회사 필드 매핑 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077955675/original/2FuQNg_DWW7G5I2n68cZ58J7EY4u7YrSNQ.png?1786246960)

7. 확인 화면에서 모든 설정과 매핑이 맞는지 검토해요. 기존 레코드를 업데이트한다면 **Don't update to empty value**를 켜는 것을 고려하세요. 빈 칸이 기존 데이터를 덮어쓰는 일을 막아 줘요.
8. **Start Bulk Import**(일괄 가져오기 시작)를 클릭해 파일 처리를 시작해요.

{% hint style="info" %}
팁: 가져오기 전에 필드 매핑을 꼭 다시 확인하세요. CSV의 각 열이 알맞은 회사 필드에 연결되어 있어야 데이터가 어긋나거나 오류가 나는 일을 막을 수 있어요.
{% endhint %}

## 가져오기 흐름 이해하기

회사 일괄 가져오기는 네 단계로 나뉘어요. 각 단계에서 데이터를 검증하고 준비한 뒤 다음 단계로 넘어가요.

1. **Start**(시작): 객체 유형(회사)을 고르고 가져오기 방식(만들기, 업데이트, 둘 다)을 선택해요.
2. **Upload**(업로드): CSV 파일을 올리고 중복 확인 기준을 설정해요. 보통 **회사 ID**를 써요.
3. **Map**(매핑): CSV 열을 하이퍼클래스의 회사 필드와 연결해요. 미리보기 데이터가 표시돼서 매핑이 맞는지 확인할 수 있어요.
4. **Verify**(확인): 제출하기 전에 모든 설정, 매핑, 가져오기 옵션을 검토해요. 빈 값이 기존 데이터를 덮어쓰지 않게 하려면 필드 단위 보호를 켜세요.

{% hint style="info" %}
매핑 단계에서는 미리보기 데이터가 표시돼요. 가져오기를 마무리하기 전에 각 열에 예상한 정보가 들어 있는지 확인해 보세요.
{% endhint %}

## 가져오기 진행 상황 확인

가져오기를 시작하면 가져오기 작업의 상태와 상세 통계를 볼 수 있는 전용 페이지가 열려요.

**일괄 작업 – 회사**로 이동하면 진행 중인 가져오기와 끝난 가져오기를 모두 볼 수 있어요. 각 가져오기에는 진행률이 표시되고, 끝나면 성공, 오류, 경고 건수가 나와요.

- 성공 건수: 성공적으로 만들어졌거나 업데이트된 회사 레코드 수예요.
- 오류 건수: 유효성 문제나 시스템 오류로 가져오지 못한 레코드 수예요.
- 경고 건수: 치명적이지 않은 문제(예: 선택 필드 누락)가 있었지만 가져온 레코드 수예요.
- 내려받을 수 있는 보고서: 오류 메시지와 해당 레코드를 포함해 모든 가져오기 결과를 담은 CSV 보고서예요.

{% hint style="info" %}
가져오기가 끝나면 항상 보고서를 내려받아 점검과 문제 해결에 활용하세요. 보고서에는 상세한 오류 메시지가 들어 있어서, 다시 가져오기 전에 CSV의 문제를 고치는 데 도움이 돼요.
{% endhint %}

## CSV 준비 체크리스트

업로드하기 전에 CSV 파일 형식을 제대로 맞추면 오류가 줄고 가져오기가 매끄럽게 진행돼요. 아래 기준에 맞춰 데이터를 준비하세요.

- UTF-8 인코딩 사용: 글자가 깨지지 않도록 CSV 파일을 UTF-8 인코딩으로 저장해요.
- 머리글 행 포함: 첫 행에는 각 필드를 알아볼 수 있는 열 이름을 넣어요.
- 업데이트할 때는 회사 ID 포함: 기존 회사를 업데이트한다면 CSV의 각 레코드에 하이퍼클래스 회사 ID가 들어 있어야 해요.
- 불필요한 열 삭제: 가져올 열만 남기면 필드 매핑이 간단해져요.
- 데이터 형식 확인: 숫자 필드에는 숫자만 넣고, 날짜 필드는 형식을 통일하고, 텍스트 필드는 글자 수 제한을 넘기지 않게 해요.
- 작은 파일로 먼저 테스트: 전체 데이터를 올리기 전에 10~20건 정도의 샘플로 먼저 가져와서 필드 매핑과 설정을 확인해요.

{% hint style="warning" %}
기존 레코드를 업데이트할 때는 **Don't update to empty value**를 켜는 것을 권장해요. 이 옵션을 켜지 않으면 CSV의 빈 칸이 하이퍼클래스의 기존 데이터를 덮어써서 데이터가 사라질 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 한 번에 가져올 수 있는 회사 수에 제한이 있나요?
릴리스 문서에는 정해진 한도가 나와 있지 않아요. 다만 성능이 좋고 문제를 찾기 쉽도록 1,000~5,000건 단위로 나눠서 가져오는 것을 권장해요. 아주 큰 파일은 처리하는 데 시간이 더 걸릴 수 있어요.

### 가져오기를 처리한 뒤에 되돌릴 수 있나요?
기본으로 제공되는 되돌리기(롤백) 기능은 없어요. 가져오기가 끝나면 변경 내용은 그대로 반영돼요. 가져온 레코드를 지우려면 하나씩 삭제하거나, 일괄 삭제 기능이 있으면 그 기능을 써야 해요. 먼저 작은 샘플로 테스트해 보세요.

### 기존 레코드의 회사 ID는 어디서 확인하나요?
하이퍼클래스에서 기존 회사를 내보내기하면 **회사 ID** 필드가 들어 있는 CSV 파일을 받을 수 있어요. 이 파일을 업데이트용 템플릿으로 쓰면 각 행에 올바른 ID가 들어가요.

### CSV에 이미 있는 회사가 들어 있으면 어떻게 되나요?
가져오기 방식을 **Update companies** 또는 **Create & update companies**로 선택했다면, 회사 ID가 일치하는 경우 중복 레코드를 만들지 않고 기존 레코드를 업데이트해요. **Create companies**만 선택하면 중복이 생길 수 있어요.

### Don't update to empty value 옵션은 무슨 역할을 하나요?
이 옵션을 켜면 CSV의 빈 칸이 하이퍼클래스의 기존 데이터를 덮어쓰지 않아요. 예를 들어 회사 레코드에 전화번호가 이미 있는데 CSV의 해당 칸이 비어 있으면, 기존 전화번호는 지워지지 않고 그대로 남아요.

### 회사 일괄 가져오기에서 커스텀 필드도 가져올 수 있나요?
네, 필드 매핑 단계에서 CSV 열을 회사 커스텀 필드와 연결할 수 있어요. 가져오기를 시작하기 전에 커스텀 필드를 하이퍼클래스에 미리 만들어 두세요.

### 가져오기가 끝난 뒤 보고서는 어디서 내려받나요?
**일괄 작업 – 회사**로 이동해서 완료된 가져오기 작업을 찾으세요. 다운로드 아이콘이나 링크를 클릭하면 레코드별 성공, 오류, 경고 내용이 담긴 상세 보고서를 받을 수 있어요.

### 가져오기에 필요한 파일 형식은 무엇인가요?
CSV(쉼표로 구분된 값) 파일을 쓸 수 있어요. 파일은 UTF-8 인코딩으로 저장하고, 열 이름을 알아볼 수 있게 적은 머리글 행을 포함해야 해요.
