# 팀을 위한 내부 작업 관리

**Tasks List**(작업 목록) 페이지에서 팀 내부용 작업을 만들고 관리할 수 있어요. 연락처와 연결하지 않고도 작업을 만들 수 있어서, 팀의 업무 분담이나 운영 업무를 정리하기 편해요.

### 

## 연락처 없는 작업 만들기

**Tasks List** 페이지에서 특정 연락처와 연결하지 않고 작업을 만들 수 있어요. 이렇게 만든 작업은 팀원에게 배정해서 내부 업무와 담당 업무를 관리하는 데 쓸 수 있어요.

![작업 목록 페이지에서 연락처 없는 작업을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078814306/original/w-SbUPC28U4YQ3Yb3b75FVUs3VafjMAiHg.png?1787147700)

## 내부 작업 필터링하기

**연락처** 필터에서 **미배정** 옵션을 선택하면 연락처가 없는 내부 작업만 볼 수 있어요. 특정 연락처와 연결된 작업과 구분해서, 팀 내부 활동용 작업을 쉽게 찾을 수 있어요.

![연락처 필터에서 미배정 옵션을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078814387/original/7PIaSIoC2QigKCvJqs9HwmcVdqhW7SnBBg.png?1787147751)

## 작업에 연락처 지정·제거·변경하기

연락처 없는 작업을 만든 뒤에 나중에 연락처를 추가할 수 있어요. 필요하면 연결된 연락처를 제거하거나 다른 연락처로 바꿀 수도 있어요. 작업 요건이 바뀌어도 유연하게 관리할 수 있어요.

## 워크플로우로 연락처 없는 작업 자동화하기

**Add Task**(작업 추가) 워크플로우 액션은 연락처가 없는 워크플로우에서도 연락처 없는 작업을 만들 수 있어요. 예를 들어 시스템에서 들어오는 이벤트로 워크플로우가 시작되는 경우가 그래요. 워크플로우에 연락처가 있으면 작업은 자동으로 그 연락처와 연결돼요.

---

## 자주 묻는 질문

### 동적 날짜로 작업을 예약하거나, 트리거에 따라 작업을 자동으로 만들 수 있나요?

네, 할 수 있어요. **작업** 섹션에서는 팀 작업을 직접 만들 수 있어요. "지금부터 2일 후 오후 5시"처럼 동적 마감일을 정하는 고급 작업 예약과 자동화는 워크플로우에서 설정해요.

**자동화 > 워크플로우**로 이동해서 **Add Task** 액션을 사용하세요. 폼 제출, 기회 업데이트 같은 워크플로우 트리거와 지원되는 다른 이벤트에 맞춰 작업 생성, 작업 배정, 동적 마감일 설정을 자동화할 수 있어요.
