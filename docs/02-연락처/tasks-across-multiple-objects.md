# 하나의 작업을 여러 객체에 연결하기

작업 하나를 연락처, 기회, 회사, 사용자 지정 객체에 함께 연결할 수 있어요. 객체 유형마다 최대 10개 레코드까지 연결할 수 있어서, 후속 작업을 실제 업무가 이뤄지는 곳에서 관리할 수 있어요.

## 다중 객체 작업 연결이란?

다중 객체 작업 연결(Multi-Object Task Associations)은 하이퍼클래스 **작업** 기능을 확장한 기능이에요. 이전에는 작업을 연락처에만 연결할 수 있었지만, 이제는 작업 하나를 연락처, 기회, 회사, 사용자 지정 객체에 함께 연결할 수 있어요. 관련된 모든 담당자가 같은 할 일을 바로 확인할 수 있고, 작업을 알맞은 레코드에 붙일 수 있어 데이터도 더 깔끔해져요.

```
작업 하나에 객체 유형별로 최대 10개까지 연결할 수 있어요. 예를 들어 작업 하나를 연락처 10개와 기회 10개에 동시에 연결할 수 있어요.
```

---

## 다중 객체 작업 연결의 장점

팀이 일을 체계적으로 관리하고 책임을 분명히 하는 데 도움이 돼요.

- 처음부터 끝까지 한눈에 확인: 같은 작업이 연결된 각 레코드의 **Associated Objects**(연결된 객체) 패널에 표시돼요.
- 팀 간 협업: 영업, 고객 성공, 운영 팀이 서로 다른 모듈에서 일해도 같은 할 일을 함께 볼 수 있어요.
- 중복 감소: 레코드마다 복제 작업을 따로 만들 필요 없이 작업 하나로 처리해요.
- 유연한 한도: 작업 하나에 연락처 10개, 기회 10개, 회사 10개, 사용자 지정 객체 10개까지 연결할 수 있어요.
- 편리한 목록 필터: 담당자, 상태, 연결된 연락처나 기회를 기준으로 작업 목록을 빠르게 좁힐 수 있어요.

---

## 기본 연결 방식

하이퍼클래스는 클릭 수를 줄이도록 기본 연결을 미리 지정해 줘요. 연결은 직접 바꿀 수 있어요.

- **작업** 페이지에서 만들 때: 연결이 하나도 없는 상태로 시작해요. 필요한 레코드를 직접 고르세요.
- **연락처**에서 만들 때: 해당 연락처와 그 연락처의 주 회사(있는 경우)가 미리 연결돼요.
- **기회**에서 만들 때: 해당 기회, 주 연락처, 그 연락처의 주 회사가 미리 연결돼요.
- **회사**에서 만들 때: 해당 회사가 미리 연결돼요.

**Associate To**(연결 대상) 드롭다운에서 연결을 언제든 수정, 추가, 제거할 수 있어요.

---

## 연결된 객체 확인하기

**연락처**, **기회**, **회사**, **사용자 지정 객체** 레코드에는 모두 **Associated Objects**(연결된 객체) 섹션이 있어요. 작업 행의 체인 링크 아이콘에 마우스를 올리면 연결된 레코드를 바로 미리 볼 수 있어요. 레코드 이름을 클릭하면 새 탭에서 열려요.

---

## 연결 기준으로 작업 필터링하기

**작업** 페이지나 레코드 안의 작업 패널에서 필터 아이콘을 사용하면 다음과 같이 작업을 좁혀 볼 수 있어요.

- 특정 연락처나 기회에 연결된 작업만 보기
- 상태(**Open**(진행 중), **Completed**(완료), **Overdue**(기한 지남))와 담당자 필터를 함께 적용해 원하는 작업만 보기

이 필터는 새 기능에서 쓰는 연결 데이터를 그대로 활용해요. 그래서 업무 방식에 맞게 작업을 다양한 기준으로 나눠 볼 수 있어요.

---

## 다중 객체 작업 연결 설정하기

작업을 연결해 두면 팀원이 기대하는 모든 곳에서 작업을 확인할 수 있어요.

1. **연락처**, **기회**, **회사**, **사용자 지정 객체** 중 원하는 레코드로 이동하거나 **작업** 페이지를 열어요.
2. **+ Add Task**(작업 추가)를 클릭해요.
3. **Associate To** 필드에서 기본 연결을 확인하거나 수정해요.
4. (선택) **+ Add Association**(연결 추가)을 클릭해 레코드를 더 연결해요. 객체 유형마다 최대 10개까지 연결할 수 있어요.
5. 제목, 담당자, 기한 등 나머지 항목을 입력해요.
6. **저장**을 클릭해요.
7. 나중에 연결을 바꾸려면 작업을 열고 **Associated Objects** 옆의 연필 아이콘을 클릭해요. 연결을 조정한 뒤 **저장**을 클릭하세요.

## 자주 묻는 질문

### 기존에 만든 작업에도 영향이 있나요?
아니요. 이 기능이 나오기 전에 만든 작업은 처음 연결한 연락처에만 그대로 연결돼 있어요. 기존 작업을 수정해서 연결을 더 추가할 수 있어요.

### 객체 유형당 10개 한도를 넘길 수 있나요?
이 한도는 데이터를 관리하기 쉽게 유지하려고 플랫폼 전체에 적용돼요. 규모가 큰 프로젝트라면 작업을 여러 개로 나눠 보세요.

### 워크플로우에서 연결을 자동화할 수 있나요?
아직은 할 수 없어요. 현재는 화면에서만 연결을 관리할 수 있어요. 작업용 워크플로우 액션은 제품 로드맵에 있어요.

### 반복 작업도 같은 연결을 유지하나요?
네. 반복 작업이 새로 생성되면 원래 작업의 연결을 모두 그대로 이어받아요.

### 권한은 객체 소유자를 따라가나요?
연결된 레코드 중 하나라도 접근 권한이 있으면 그 작업을 볼 수 있어요.
