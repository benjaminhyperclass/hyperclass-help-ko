# 연락처 – 완전히 새로워진 연락처 상세 페이지

완전히 새로워진 하이퍼클래스 연락처 상세(Contact Detail) 페이지는 모든 고객 상호작용을 한곳에서 확인할 수 있는 더 빠르고, 더 깔끔하고, 더 스마트한 방법을 제공해요. 이 아티클에서는 무엇이 바뀌었는지, 왜 중요한지, 그리고 자동 저장(Auto-Save), 접이식 패널, 즉각적인 키보드 탐색 같은 생산성 향상 기능을 어떻게 사용하기 시작하는지 설명해 드릴게요.

## **완전히 새로워진 연락처 상세 페이지란?**

처음부터 다시 설계된 연락처 상세(Contact Record) 페이지는 연락처 정보를 확인하고, 대화를 추적하고, 활동을 기록하고, 각종 액션을 실행할 수 있는 핵심 작업 공간이에요. 이제 속도와 사용성에 최적화되었습니다. 이번 리디자인을 통해 끝없이 스크롤하던 방식 대신 3단 패널 레이아웃을 적용했고, 중요한 데이터를 한눈에 확인할 수 있으며, 사용자가 설정한 개인 화면 구성을 기억해서 진정으로 간소화된 CRM 경험을 제공해요.

## **한눈에 보는 주요 개선 사항**

- 모던 디자인: 더 빠르고 일관되며 시각적으로 정돈된 레이아웃

- 자동 저장(Auto-Save): 필드에서 벗어나는 순간 변경 사항이 자동으로 저장되며, 별도 클릭이 필요 없어요.

- 스마트 탐색: 키보드 단축키로 연락처 간 이동이 가능해요.

- 접이식 패널: 중요한 부분에 집중할 수 있고, 시스템이 사용자의 레이아웃을 기억해요.

- 인라인 연결 관계: 회사(Companies), 기회 관리(Opportunities), 커스텀 객체(Custom Objects)를 연락처 페이지에서 바로 보고 편집할 수 있어요.

- 더 깔끔해진 오른쪽 패널: 할 일(Tasks), 노트(Notes), 문서(Documents), 결제(Payments), 예약(Appointments)을 위한 통합된 경험

- 빈 필드 숨기기: 불필요한 정보를 줄이고 입력된 항목만 볼 수 있어요.

- 필드 내 검색: 데이터나 폴더를 빠르게 찾을 수 있어요.

- **간소화된 연결 레코드:** 오른쪽 패널의 전용 탭에서 기회 관리(Opportunities)에 접근하고, 회사(Companies)와 커스텀 객체(Custom Objects)는 연결 관계(Associations) 아래에서 확인할 수 있어요.

### 연락처 태그 편집 (Apply/Cancel 확인)

연락처의 태그를 업데이트할 때, 하이퍼클래스는 사용자가 확인(Apply)을 눌러야만 변경 사항을 저장해요.

1. 연락처에서 Tags(태그) 드롭다운을 엽니다.

2. 추가할 태그를 선택하고, 제거할 태그는 선택 해제합니다.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073242888/original/GQK_ZIGiJ9r-sT-VpP7FBSKlnaZetBE-kg.png?1781000801)

3. Apply(적용)를 클릭해서 변경 사항을 저장합니다.

4. Cancel(취소)을 클릭하면 대기 중인 변경 사항이 취소됩니다.

## **자동 저장: 작동 방식**

자동 저장(Auto-Save)은 이번 업데이트에서 가장 강력한 신규 기능 중 하나예요. 활성화하면, 필드에서 벗어나는 순간 편집 내용이 자동으로 저장돼요 — 별도로 "저장" 버튼을 누를 필요가 없어요.

**단계**: 아무 연락처 상세 레코드를 엽니다. 내용을 편집하면 화면 하단에 Save 바가 나타나요. 케밥(점 3개) 메뉴에서 "Enable Auto-Save(자동 저장 활성화)"를 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056157667/original/v1gsiG7FiFft22yhfQgr2e5GKTXSEVrOAQ.png?1760623346)

안내 창이 뜨면 "Enable Auto-Save"를 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055793497/original/sd_dilWAx91RpPK6y4HHqZGFe5eMxpzrEw.png?1760264176)

팝업 창에서 확인을 눌러주세요 — 이렇게 하면 해당 하위 계정에 이 설정이 적용돼요. 관리자(Admin)는 다음 경로에서도 자동 저장을 켜거나 끌 수 있어요: **Settings(설정) → Contacts(연락처) → Details Tab(세부 정보 탭) → Auto-Save 토글**

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055793499/original/lBmu2nddaOpGl69KHwW1vRwhs4U7yn-WCg.png?1760264183)

활성화되면, 해당 하위 계정의 모든 사용자가 작업하는 동안 편집 내용이 자동으로 저장돼요.

## **키보드 단축키**

새로운 단축키로 시간을 절약해 보세요:

- → / ← — 목록에서 연락처 간 이동

- ESC — 오른쪽 패널 접기

- CTRL + S (또는 CMD + S) — 수동 저장 (자동 저장이 꺼져 있는 경우)

## **사용성 개선 사항**

- 패널과 탭이 이제 마지막 상태를 기억해서, 매번 다시 펼치거나 접을 필요가 없어요.

- 일관된 여백, 타이포그래피, 컴포넌트 동작으로 전문적이고 깔끔한 화면을 제공해요.

- 할 일(Tasks), 문서(Documents), 노트(Notes), 결제(Payments) 등 모든 모듈에서 통일된 디자인 언어와 빈 상태(empty state) 화면을 제공해요.

## **자주 묻는 질문**

**Q: 자동 저장(Auto-Save)이 계정의 모든 사용자에게 적용되나요?**
네. 관리자가 활성화하면, 해당 하위 계정의 모든 사용자에게 자동 저장이 적용돼요.

**Q: 자동 저장으로 저장된 변경 사항을 되돌릴 수 있나요?**
필드는 언제든 다시 편집할 수 있어요 — 자동 저장은 레코드를 즉시 업데이트하며, 전체 활동 로그를 계속 유지해요.

**Q: "Enable Auto-Save" 버튼이 보이지 않아요. 왜 그런가요?**
이미 활성화되어 있을 수 있어요. Settings(설정) → Contacts(연락처) → Details Tab(세부 정보 탭)에서 확인해 보세요.
