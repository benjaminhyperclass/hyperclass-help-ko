# 새 연락처 상세 페이지 살펴보기

새 연락처 상세 페이지에서는 연락처와 주고받은 모든 내용을 한 화면에서 더 빠르고 깔끔하게 볼 수 있어요. 달라진 점과, **자동 저장**·접이식 패널·키보드 이동 같은 기능을 쓰는 방법을 안내해요.

## 새 연락처 상세 페이지란?

연락처 상세 페이지는 연락처 정보를 확인하고, 대화를 따라가고, 활동을 기록하고, 여러 작업을 시작하는 중심 화면이에요. 이번에 처음부터 다시 만들어서 속도와 사용성이 좋아졌어요.

길게 스크롤하던 화면은 3단 패널 구성으로 바뀌었어요. 중요한 정보는 한눈에 보이고, 내가 설정한 보기 방식도 기억해요.

## 달라진 점 한눈에 보기

- 새로운 디자인: 더 빠르고 일관되며 깔끔한 레이아웃이에요.
- **자동 저장**: 필드에서 벗어나면 변경 내용이 자동으로 저장돼요. 따로 클릭할 필요가 없어요.
- 간편한 이동: 키보드 단축키로 연락처 사이를 이동할 수 있어요.
- 접이식 패널: 필요한 부분에 집중할 수 있고, 시스템이 내 레이아웃을 기억해요.
- 인라인 연관 정보: 연락처 페이지에서 바로 회사, 기회, 커스텀 오브젝트를 보고 편집할 수 있어요.
- 더 깔끔해진 오른쪽 패널: 작업, 메모, 문서, 결제, 예약을 같은 방식으로 쓸 수 있어요.
- **빈 필드 숨기기**: 복잡함을 줄이고 값이 입력된 필드만 볼 수 있어요.
- 필드 안 검색: 필요한 데이터나 폴더를 빠르게 찾을 수 있어요.
- 연결된 레코드 정리: 오른쪽 패널의 **기회 관리**(Opportunities) 탭에서 기회를 볼 수 있어요. 회사와 커스텀 오브젝트는 **연관** 탭에서 확인해요.

### 연락처 태그 편집하기 (적용/취소 확인)

연락처의 태그를 바꾸면, 변경 내용을 확인한 뒤에야 저장돼요.

1. 연락처에서 **태그** 드롭다운을 열어요.
2. 추가할 태그는 선택하고, 제거할 태그는 선택을 해제해요.

   ![태그 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073242888/original/GQK_ZIGiJ9r-sT-VpP7FBSKlnaZetBE-kg.png?1781000801)

3. **적용**을 클릭하면 변경 내용이 저장돼요.
4. **취소**를 클릭하면 아직 저장되지 않은 변경 내용이 취소돼요.

## 가운데 패널: 대화 및 활동

이 영역에는 연락처와 주고받은 모든 내용이 시간순으로 보여요. 이런 일을 할 수 있어요.

- 메시지, 통화, 메모를 한곳에서 확인해요.
- 예약, 기회, 활동 로그를 따라가 볼 수 있어요.
- 새 메모를 만들거나, 메시지를 보내거나, 통화를 기록할 수 있어요.

## 자동 저장 사용하기

**자동 저장**은 새로 추가된 기능 중 하나예요. 켜 두면 필드에서 벗어나는 순간 수정한 내용이 자동으로 저장돼요. **저장**을 따로 누를 필요가 없어요.

**자동 저장 켜는 방법**

1. 연락처 레코드를 열어요.
2. 값을 수정해요. 화면 아래쪽에 저장 바가 나타나요.
3. 점 3개(⋮) 메뉴에서 **자동 저장 활성화**를 클릭해요.

   ![점 3개 메뉴의 자동 저장 활성화](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056157667/original/v1gsiG7FiFft22yhfQgr2e5GKTXSEVrOAQ.png?1760623346)

4. 안내 창이 나타나면 **자동 저장 활성화**를 클릭해요.

   ![자동 저장 활성화 안내 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055793497/original/sd_dilWAx91RpPK6y4HHqZGFe5eMxpzrEw.png?1760264176)

5. 확인 창에서 설정을 확인해요. 이 설정은 현재 서브 계정에 적용돼요.

관리자는 **설정 > 연락처 > 상세 정보**에서 **자동 저장** 토글로도 켜거나 끌 수 있어요.

![설정의 자동 저장 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055793499/original/lBmu2nddaOpGl69KHwW1vRwhs4U7yn-WCg.png?1760264183)

> 한 번 켜면 서브 계정의 모든 사용자가 작업하는 대로 수정 내용이 자동 저장돼요.

## 키보드 단축키

새 단축키로 시간을 아낄 수 있어요.

- **→ / ←**: 목록에서 이전·다음 연락처로 이동해요.
- **ESC**: 오른쪽 패널을 접어요.
- **CTRL + S (Mac은 CMD + S)**: **자동 저장**이 꺼져 있을 때 직접 저장해요.

## 사용하기 편해진 점

- 패널과 탭이 마지막 상태를 기억해요. 매번 다시 펼치거나 접을 필요가 없어요.
- 간격, 글꼴, 구성 요소의 동작이 일관돼서 깔끔하고 정돈된 화면으로 보여요.
- 모든 모듈(작업, 문서, 메모, 결제)에서 디자인이 통일되었고, 데이터가 없을 때 보이는 빈 화면(empty state)도 같은 모양이에요.

## 자주 묻는 질문

### 자동 저장은 계정의 모든 사용자에게 적용되나요?
네. 관리자가 한 번 켜면 해당 서브 계정의 모든 사용자에게 **자동 저장**이 적용돼요.

### 자동 저장으로 저장된 변경을 되돌릴 수 있나요?
필드를 언제든 다시 편집할 수 있어요. **자동 저장**은 레코드를 바로 업데이트하고, 활동 로그를 빠짐없이 남겨요.

### 자동 저장 활성화 버튼이 안 보여요
이미 켜져 있을 수 있어요. **설정 > 연락처 > 상세 정보**에서 확인해 보세요.
