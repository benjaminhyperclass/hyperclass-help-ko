# 하이퍼클래스에서 연락처 오버레이 사용하기

하이퍼클래스의 연락처 오버레이(Contact Overlay)를 사용하면 기회 관리(Opportunities)나 예약(Appointments) 화면에서 작업하면서 연락처 정보와 대화 내역을 더 쉽게 확인할 수 있어요. 현재 작업 중인 페이지를 벗어나지 않고도 연락처를 확인할 수 있어서, 하던 작업의 맥락을 그대로 유지할 수 있답니다. 불필요한 화면 이동을 줄이고 필요한 정보에 더 빠르게 접근할 수 있어요.

---

## 연락처 오버레이란 무엇인가요?

연락처 오버레이는 하이퍼클래스에서 지원되는 화면에서 연락처(Contacts)를 맥락(context) 안에서 바로 볼 수 있게 해주는 기능이에요. 현재 작업 중인 기회 관리 또는 예약 페이지를 벗어나지 않고도 연락처 상세 정보와 대화 내역을 확인할 수 있도록 도와줘요.

기회 관리나 예약 화면에서 연락처를 선택하면, 현재 페이지 위에 연락처 오버레이가 열려요. 더 간결하게 보고 싶다면 1단 보기(Single-column view)를, 대화 내역을 더 자세히 보고 싶다면 2단 보기(Two-column view)를 사용할 수 있어요. 필요할 때는 언제든 전체 연락처 상세(Contact Detail Page) 페이지를 열 수도 있어요.

## **연락처 오버레이의 주요 장점**

예약과 기회 관리를 처리하면서도 연락처 맥락을 계속 유지할 수 있어서, 불필요한 화면 이동을 줄이고 더 효율적으로 작업할 수 있어요.

- **맥락 유지**: 기회 관리나 예약 페이지를 바로 벗어나지 않고도 연락처를 확인할 수 있어요.
- **빠른 대화 확인**: 추가 맥락이 필요할 때 연락처 정보와 함께 대화 기록을 바로 볼 수 있어요.
- **원하는 보기 방식 선택**: 표시하고 싶은 정보량에 따라 1단 보기와 2단 보기를 자유롭게 전환할 수 있어요.
- **전체 연락처 상세 접근**: 완전한 연락처 정보가 필요할 때는 언제든 연락처 상세 페이지를 열 수 있어요.
- **일관된 작업 환경 유지**: 기존에 설정해둔 연락처 상세 페이지의 커스터마이징이 오버레이에도 그대로 반영돼요.
- **불필요한 화면 이동 감소**: 필요한 정보만 확인하고, 페이지 전환을 최소화한 채 기존 작업으로 바로 돌아갈 수 있어요.

## **연락처 오버레이를 사용할 수 있는 위치**

연락처 오버레이는 기회 관리와 예약 화면에서 사용할 수 있어요. 현재 작업 중인 페이지를 벗어나지 않고도 관련 연락처에 바로 접근할 수 있어요.

### **예약(Appointments)**

예약 목록 보기(Appointment List View)에서 예약과 연결된 연락처를 선택하면 해당 연락처가 오버레이로 열려요. 예정된 예약을 검토하면서 연락처 정보나 대화 내역을 확인해야 할 때 유용해요.

![예약 목록 보기에서 연락처를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080122492/original/axMxr2E1Xb7Dk4ZYIJ_6Qz61dY2qWWvBBQ.png?1788531302)

### **기회 관리(Opportunities)**

기회 관리 화면에서 기회와 연결된 연락처를 선택하면 연락처 오버레이가 열려요. 기회와 파이프라인(Pipeline)의 맥락을 유지하면서 연락처 정보를 검토할 수 있어요.

![기회 관리 화면에서 연락처를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080122566/original/iamP1boPbICxrdETlBTHYti-rOn1aRWErw.png?1788531321)

## **1단 보기와 2단 보기**

연락처 오버레이는 두 가지 표시 모드를 제공해서, 한 번에 보고 싶은 연락처 및 대화 정보의 양을 직접 선택할 수 있어요. 이 표시 모드는 오버레이에만 적용되며, 연락처 상세 페이지를 커스터마이징할 때 사용하는 레이아웃 옵션과는 별개예요.

- **1단 보기(Single-column view)**: 연락처 정보와 관련된 오른쪽 패널 기능에 접근할 수 있도록 더 간결한 연락처 화면을 제공해요.

![1단 보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080123004/original/wq2SzOxebULNmKEOj6BZfJVAnmGBkQiaNg.png?1788531411)

- **2단 보기(Two-column view)**: 오버레이를 확장해서 연락처 상세 정보와 넓어진 대화(Conversations) 영역을 함께 보여줘요. 현재 페이지를 벗어나지 않고도 더 풍부한 맥락을 확인할 수 있어요.

![2단 보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080123028/original/13Xmd1TM7pr6jC5S_0ZpEGAKHe2kZm6Hzg.png?1788531430)

오버레이 상단의 레이아웃 컨트롤을 사용해서 이 두 보기 방식을 서로 전환할 수 있어요.

**참고:** 1단 보기와 2단 보기는 연락처 오버레이의 표시 옵션이에요. [연락처 상세 페이지 커스터마이징 방법](https://hyperclass.gitbook.io/hyperclass-docs/support/solutions/articles/155000007588?utm_source=chatgpt.com)에서 설명하는 연락처 상세 페이지의 레이아웃 설정과는 다른 기능이니 참고해주세요.

## **연락처 오버레이 사용 방법**

연락처 오버레이를 사용하면 기회 관리나 예약 작업의 맥락을 유지하면서도 연락처 정보에 빠르게 접근할 수 있어요. 오버레이를 연 후에는 원하는 만큼의 연락처 및 대화 정보를 확인하거나, 필요할 때 전체 연락처 상세 페이지로 이동할 수 있어요.

- 기회 관리(Opportunities) 메뉴 또는 캘린더(Calendars) > 예약 목록 보기(Appointment list view)로 이동하세요.
- 확인하려는 기회 또는 예약을 찾으세요.
- 해당 레코드와 연결된 연락처 이름 또는 연락처 아이콘을 클릭하세요.

![연락처 이름 또는 아이콘 클릭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080121176/original/d2Ez3blvrXSCKO1swlQ2kEyssH2PDw06BQ.png?1788530775)

- 현재 작업 중인 기회 관리 또는 예약 페이지를 유지한 채로 연락처 오버레이가 열려요.

![연락처 오버레이가 열리는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080121582/original/1Cm_GnLLchjR0RvZPAZzIfBeb8QI7NZ9ag.gif?1788530985)

- 연락처 상세 정보, 대화 내역, 기타 이용 가능한 정보를 확인하세요.
- 오버레이 상단의 레이아웃 컨트롤을 사용해서 1단 보기, 2단 보기, 또는 **연락처 페이지로 이동(Go to Contacts Page)** 중 필요한 방식으로 전환하세요.

![레이아웃 컨트롤 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080121823/original/IEIjlcHcqG7ikG_892UncGrg8z7Cv6EGww.png?1788531079)

- 전체 연락처 상세 정보를 보려면 새 탭에서 연락처 열기(Open contact in new tab) 아이콘을 사용하세요.

![새 탭에서 연락처 열기 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080122102/original/8pD3-wDj-o-zasTS01JNAmB-7vchtXVHog.png?1788531150)

- X 버튼을 클릭하면 오버레이가 닫히고, 기회 관리 또는 예약 페이지에서 하던 작업을 계속 이어갈 수 있어요.

![오버레이 닫기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080122409/original/ZgZCvXstTnRi82_LAMeR8Biy8M0UatlE3g.gif?1788531270)

## **자주 묻는 질문**

**Q: 연락처 오버레이는 현재 어디에서 사용할 수 있나요?**
현재는 기회 관리와 예약 화면에서 연락처에 접근할 때 연락처 오버레이를 사용할 수 있어요.

**Q: 1단 보기와 2단 보기는 연락처 상세 페이지의 레이아웃 설정과 같은 건가요?**
아니요. 1단 보기와 2단 보기는 연락처 오버레이가 표시되는 방식을 제어하는 옵션이에요. 연락처 상세 페이지의 레이아웃은 별도의 커스터마이징 옵션을 통해 설정돼요.

**Q: 연락처를 확인할 때마다 연락처 오버레이를 꼭 사용해야 하나요?**
아니요. 전체 연락처 상세 페이지를 보고 싶다면 하이퍼클래스에서 해당 페이지를 바로 열 수 있는 옵션을 제공해요.

**Q: 제가 커스터마이징한 연락처 상세 페이지가 오버레이에서는 다르게 보이나요?**
아니요. 오버레이는 사용자가 설정한 연락처 상세 페이지의 커스터마이징을 그대로 반영해서, 오버레이와 전체 페이지 사이에 일관된 연락처 경험을 유지해줘요.

**Q: 연락처를 연 뒤에도 오버레이 보기 방식을 바꿀 수 있나요?**
네. 오버레이 상단의 레이아웃 컨트롤을 사용해서 1단 보기와 2단 보기를 자유롭게 전환할 수 있어요.

**Q: 전체 연락처 상세 페이지를 연 뒤에 원래 작업하던 페이지로 돌아갈 수 있나요?**
네. 오버레이에서 전체 연락처 상세 페이지로 이동한 뒤에도, 이전에 작업하던 페이지로 다시 돌아갈 수 있어요.

**Q: 연락처 이름이 표시되는 모든 화면에서 연락처 오버레이를 사용할 수 있나요?**
현재 버전에서는 기회 관리와 예약 화면에서만 연락처 오버레이가 제공돼요. 다른 화면에서도 사용 가능하다고 가정하지 않는 것이 좋아요.
