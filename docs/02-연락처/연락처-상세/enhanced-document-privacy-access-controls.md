# 문서 개인정보 보호 및 이용 권한 설정 강화

연락처 기록의 **문서** 패널에서 파일을 공유할 때 링크 유형, 만료일, 다운로드 권한을 직접 정할 수 있어요. 이 문서에서는 네 가지 링크 유형과 이용 권한 설정, 보안 정책에 맞게 문서를 안전하게 공유하는 방법을 안내해요.

{% hint style="info" %}
이 기능은 **실험실**에서 제공하며 앞으로 달라질 수 있어요. 계정에 보이지 않으면 에이전시 관리자 또는 서브 계정 관리자에게 **설정 > 실험실**을 확인하고, 사용 중인 서브 계정에서 기능을 켜 달라고 요청하세요.
{% endhint %}

## 문서 개인정보 보호 및 이용 권한 설정이란?

연락처 상세 페이지의 **문서** 패널에 저장된 문서를 공유하는 방식이 바뀌어요. 예전에는 모든 파일이 공개 URL처럼 동작했지만, 이제는 보안 수준, 만료일, 다운로드 권한을 정해서 공유 링크를 만들 수 있어요. 누가 언제 어떤 문서를 열었는지도 확인할 수 있어요.

예전에는 URL만 알면 누구나 연락처 문서를 열 수 있었기 때문에 민감한 정보는 더 조심해서 다뤄야 했어요. 이 기능을 켜면 새 링크는 기본적으로 비공개(내부 전용)로 만들어져요. 링크를 공개, 이메일 인증, 비밀번호 보호 중 어떤 방식으로 공유할지는 직접 선택해요.

메모 첨부파일로 새로 올린 문서는 기본적으로 비공개예요. 이 파일은 **문서** 아래 **Notes attachments**(메모 첨부파일) 폴더에 저장돼요.

이 변경은 이번 업데이트 이후에 메모로 올린 첨부파일에만 적용돼요. 이전에 메모로 올린 문서는 그대로 공개 상태예요.

![문서 패널의 메모 첨부파일 폴더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078239273/original/wxd_yXuIMvMUTkB82E-bQ-OWe7i88ZIjDw.png?1786538316)

{% hint style="warning" %}
이 기능은 **실험실**로 제공되며 의견에 따라 달라질 수 있어요. 제품팀이 사용 경험을 다듬는 과정에서 동작과 화면이 바뀔 수 있어요.
{% endhint %}

## 주요 장점

문서 관리가 탄탄해지면 고객과 팀을 보호하면서도 일상 업무는 간단하게 유지할 수 있어요.

- 고객 파일 보안 강화: 문서의 민감도에 따라 비공개, 일회용 비밀번호, 비밀번호 보호, 공개 링크 중에서 고를 수 있어요.
- 정책·규정에 맞는 공유: 항상 공개되는 링크 하나에 의존하지 않고, 내부 데이터 취급 규칙과 업계 요건에 맞춰 공유 방식을 정할 수 있어요.
- 명확한 감사 및 책임 추적: 문서 상세 정보와 접근 기록을 보고 "누가 언제 열었는지" 바로 확인할 수 있어요.
- 과도한 공유 위험 감소: 링크가 기본적으로 비공개라서, URL을 채팅·이메일·티켓에 복사해 붙여 넣어도 뜻밖에 노출될 가능성이 줄어요.
- 유연한 고객 경험: 내부 팀은 비공개 링크를 쓰고, 고객과 외부 파트너는 하이퍼클래스 로그인 없이 열 수 있는 일회용 비밀번호(OTP) 링크나 비밀번호 보호 링크를 쓸 수 있어요.

## 링크 만료 및 다운로드 제어

만료일과 다운로드 권한을 쓰면 링크를 얼마나 오래 열어 둘지, 받는 사람이 파일로 무엇을 할 수 있는지 세밀하게 정할 수 있어요. 두 가지를 함께 쓰면 문서가 받은편지함에 오래 남거나 부적절하게 다운로드되는 위험을 크게 줄일 수 있어요.

### 링크 만료

링크가 더 이상 작동하지 않을 날짜를 정해요. 기간이 정해진 오퍼, 민감한 리포트, 규정에 따른 데이터 보관 정책에 알맞아요.

### 다운로드 권한

받는 사람이 기록용으로 파일을 내려받을 수 있게 할지, 보기만 가능하게 할지 정해요(지원되는 경우). 사본을 더 엄격하게 관리할 수 있어요.

{% hint style="info" %}
유출됐을 때 위험이 큰 문서는 만료 기간을 짧게 하고 다운로드도 제한하세요.
{% endhint %}

## 문서 상세 정보 및 접근 기록

문서 상세 정보와 접근 기록에서 각 파일이 어떻게 공유되고 열렸는지 확인할 수 있어요. 감사, 내부 검토, "고객이 아직 안 열어 봤나?" 같은 문의를 확인할 때 특히 유용해요.

문서 상세 화면에서는 다음을 할 수 있어요.

- 링크 유형(공개, 비공개, OTP, 비밀번호 보호)과 다운로드 허용 여부를 확인해요.
- 만료 설정과 파일이 마지막으로 업데이트된 시점을 확인해요.
- 링크가 언제, 누구에 의해 열렸는지 등 접근 기록을 확인해요(확인 가능한 경우). 문서별 감사 기록을 한눈에 볼 수 있어요.

활동 추적, 메시지 기록과 함께 보면 핵심 문서를 둘러싼 연락처의 참여 상황을 더 폭넓게 파악할 수 있어요.

## 문서 개인정보 보호 및 이용 권한 설정 방법

설정은 두 단계로 나뉘어요. 먼저 **실험실**에서 기능을 켜고(사용 가능한 경우), 그다음 연락처 기록에서 문서를 공유할 때 새 제어 기능을 사용해요. 꼼꼼히 설정해 두면 링크가 알맞은 보안 수준으로 만들어지고, 팀도 상황별로 어떤 옵션을 골라야 할지 알 수 있어요.

아래 단계를 따라 기능을 켜고, 연락처 문서에 공유 링크를 만들어 보세요.

### 1단계. 실험실에서 기능 켜기

1. **설정**과 **실험실**에 접근할 수 있는 에이전시 관리자 또는 서브 계정 관리자 계정으로 로그인해요.
2. 해당하는 작업 공간(에이전시 또는 서브 계정)에서 **설정 > 실험실**로 이동해요.
3. "Enhanced document privacy & access controls"와 비슷한 이름이거나 연락처의 문서 링크 제어를 설명하는 기능 카드를 찾아요.
4. 기능을 **켜짐**으로 바꿔요. 카드에서 대상 지정을 지원하면, 접근 권한을 줄 서브 계정(로케이션)을 선택하고 저장해요.
5. 연락처 상세 페이지를 새로 고침한 뒤, **문서** 패널에서 문서를 공유할 때 새 공유 옵션이 나타나는지 확인해요.

### 2단계. 연락처의 문서 패널 열기

1. **연락처**로 이동해 연락처 기록을 하나 열어요.
2. 오른쪽 패널에서 **문서** 탭(모듈)을 클릭해요. 해당 연락처와 연결된 파일(내부 문서, 동기화된 첨부파일, 그 외 저장된 파일)이 보여요.

메모로 올린 문서는 **문서** 아래 **Notes attachments**(메모 첨부파일) 폴더에 저장돼요. 새 메모 첨부파일은 기본적으로 비공개예요.

![연락처 오른쪽 패널의 문서 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078019036/original/NCfRhsmUj4Qx0SxqkwyOGtiUWYHkgGkrOQ.png?1786362472)

### 3단계. 공유할 문서 고르기

1. 연락처의 문서 목록에서 공유할 파일을 찾아요.
2. 파일 이름 옆의 더보기 메뉴(점 세 개 아이콘)를 클릭하고 **링크 공유**를 선택해요.

![파일 옆 더보기 메뉴에서 링크 공유 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078019100/original/Kr2-vFO62zO-p37yBMWhGMbLtgKXAjO--g.png?1786362510)

### 4단계. 링크 유형 설정하기

공유 창에서 다음 접근 유형 중 하나를 선택해요.

- **Public link**(공개 링크): URL을 아는 사람은 누구나 볼 수 있어요(다운로드 및 만료 설정은 그대로 적용돼요).
- **Private link**(비공개 링크): 권한이 있는 하이퍼클래스 사용자만 열 수 있어요.
- **One-time passcode link**(일회용 비밀번호 링크): 받는 사람이 연락처의 기본 이메일로 전송된 코드를 입력해 접근을 확인해야 해요.
- **Password-protected link**(비밀번호 보호 링크): 직접 정한 비밀번호를 입력해야 열 수 있어요.

접근 유형이 문서의 민감도와 내부 정책에 맞는지 확인하세요.

![공유 창에서 링크 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078019219/original/dVcISOmPmUMisBsC0A0TEqGnbWpogek9hw.png?1786362575)

### 5단계. 만료일과 다운로드 옵션 정하기

1. 만료일을 설정해요(선택 사항이지만 권장해요). 이 링크로 더 이상 접근할 수 없게 될 날짜를 골라요.
2. 다운로드 권한을 정해요. 받는 사람이 사본을 저장할 수 있게 하려면 **Allow downloads**(다운로드 허용)를 켜요. 끄면 보기만 가능하도록 유지해요(지원되는 경우).
3. 마무리하기 전에 선택한 설정 요약을 확인해요.

![만료일과 다운로드 허용 옵션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078019380/original/TOkzih12hYHyQbVQQU32LpxARw0FaB4SIA.png?1786362665)

### 6단계. 링크 복사해서 보내기

1. **만들기** 또는 **링크 생성**을 클릭해요(화면에 따라 표현이 다를 수 있어요).
2. **링크 복사** 버튼을 눌러 URL을 클립보드에 복사해요.
3. 원하는 채널(이메일, SMS, WhatsApp, 클라이언트 포털 메시지 등)에 붙여 넣어 보내요. 이때 보안 수칙을 지켜 주세요. 예를 들어 비밀번호나 민감한 정보는 다른 채널로 따로 전달하세요.

![링크 복사 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078019461/original/_7884cWU5GKiGuQx_NKEPTX_ZDztQLQPug.png?1786362724)

### 7단계. 문서 상세 정보와 접근 기록 확인하기 (선택 사항)

1. 연락처의 **문서** 패널로 돌아가요.
2. 공유한 파일의 **Document details**(문서 상세 정보)를 열어요(예: 상세 정보 아이콘이나 더보기 메뉴).
3. 링크 유형과 만료일, 다운로드 설정, 접근 기록(마지막 접근 시각 등, 확인 가능한 경우)을 살펴봐요.
4. 이 화면에서 설정이 올바른지 확인하고, 내부 검토나 고객 문의에 활용해요.
