# 사용자 지정 객체에서 메모 사용하기

사용자 지정 객체 레코드에도 **연락처**에서 쓰던 것과 같은 메모를 남길 수 있어요. 이 문서에서는 메모를 추가하고 찾는 방법, 연락처나 기회의 메모를 사용자 지정 객체 레코드에 연결하는 방법, 워크플로우로 메모를 자동으로 남기는 방법을 안내해요.

## 개요

메모를 쓰면 업데이트, 후속 조치, 내부 정보 같은 중요한 내용을 CRM 레코드에 바로 남길 수 있어요. 이제 **연락처**에서 쓰던 메모 기능을 **사용자 지정 객체** 레코드에서도 똑같이 쓸 수 있어요. **검색**과 **필터**/**정렬**도 지원해서 필요한 메모를 더 빠르게 찾을 수 있어요.

또 **연락처**나 **기회**에 있는 기존 메모나 새 메모를 연관된 **사용자 지정 객체** 레코드에 연결할 수 있어요. 같은 메모 내용을 필요한 곳 어디에서든 볼 수 있어요.

## 기능 이름

사용자 지정 객체 메모(Notes for Custom Objects)

## 기능 설명

사용자 지정 객체 메모로 다음 작업을 할 수 있어요.

- 사용자 지정 객체 레코드에 직접 메모를 추가해요. (예: 매물, 자동차, 보험 계약, 구독)
- 키워드로 메모를 검색해서 필요한 내용을 빠르게 찾아요.
- 필터와 정렬로 메모가 많이 쌓여도 쉽게 관리해요.
- **연락처**나 **기회**에 있는 기존 메모나 새 메모를 연관된 **사용자 지정 객체** 레코드에 연결해요. 해당 연락처나 기회와 연관된 사용자 지정 객체 레코드일 때만 연결할 수 있어요.

## 사용 방법

### A) 사용자 지정 객체 레코드에 메모 추가하기

1. **사용자 지정 객체**로 이동해서 원하는 객체를 열어요. (예: 매물)
2. 레코드를 열어 상세 화면을 확인해요.
3. 오른쪽 패널에서 **메모**를 열어요.
4. **메모 추가**를 클릭하고 메모를 입력한 뒤 **저장**을 클릭해요.
5. **메모 검색**에 키워드를 입력해서 메모를 찾아요.
6. 메모가 많아지면 **필터**와 **정렬**로 목록을 좁혀요.
7. 필요하면 메모를 연결된 연락처나 기회에 연관시켜요.

![사용자 지정 객체 레코드의 메모 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066507669/original/F8OHlNfQ_fpxvTZiSehoZQwZVI6CHIZ9bQ.png?1773062135)

### B) 연락처/기회의 메모를 사용자 지정 객체 레코드에 연결하기

1. **연락처** 또는 **기회** 레코드를 열어요.
2. **메모**로 이동해서 새 메모를 만들거나 기존 메모를 열어요.
3. 메모의 **연관**에서 연결할 **사용자 지정 객체** 레코드를 선택해요.
4. **저장**을 클릭해요. 이제 이 메모가 사용자 지정 객체 레코드의 **메모**에도 표시돼요. 원래 있던 연락처나 기회에도 그대로 남아 있어요.

같은 연락처나 기회와 이미 연관된 사용자 지정 객체 레코드에만 메모를 연결할 수 있어요.
{% endhint %}

### C) 워크플로우로 메모 자동화하기

워크플로우를 쓰면 사용자 지정 객체 레코드에 메모를 자동으로 추가할 수 있어요.

1. 사용자 지정 객체용 워크플로우를 열어요.
2. **Add to Note**(메모에 추가) 액션을 추가해요.
3. 메모 내용을 입력하고 **Save**(저장)한 뒤 **Publish**(게시)해요.

{% hint style="info" %}
사용자 지정 객체 워크플로우 메모에서는 메모 제목과 메모 색상을 아직 지원하지 않아요.
{% endhint %}

## 활용 예시

**예시 1: 부동산 (매물 사용자 지정 객체)**
현장 방문이 끝날 때마다 매물 레코드에 메모를 남겨요. 예를 들면 "고객은 동향 선호, 예산 변경됨" 같은 내용이에요. 그러면 담당자 모두가 최신 상황을 볼 수 있어요.

**예시 2: 자동차 (자동차 사용자 지정 객체)**
점검 내용을 자동차 레코드에 기록해요. 예를 들면 "브레이크 패드 교체, 다음 점검은 5,000km 후" 같은 내용이에요. 정비 이력을 깔끔하게 관리할 수 있어요.

**예시 3: 보험 (보험 계약 사용자 지정 객체)**
갱신 상담 내용을 보험 계약 레코드에 기록해요. 예를 들면 "갱신 제안 완료, 서류 대기 중" 같은 내용이에요. 팀 전체가 진행 상태를 한눈에 알 수 있어요.

**예시 4: 기회 → 사용자 지정 객체 (공유 메모)**
영업 담당자가 기회에 협상 메모를 남기고, 같은 메모를 연관된 "매물" 레코드에 연결해요. 메모를 복사하지 않아도 매물 레코드를 보는 사람이 같은 내용을 볼 수 있어요.
