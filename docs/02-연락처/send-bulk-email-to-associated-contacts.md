# 연결된 연락처에게 일괄 이메일 보내기

회사나 사용자 지정 객체 레코드를 선택해서, 그 레코드와 연결된 연락처에게 일괄 이메일을 보내는 방법을 안내해요. **연락처**에서 같은 대상 목록을 다시 만들 필요가 없어요. 하이퍼클래스가 레코드의 연결 정보를 바탕으로 받을 연락처를 정해요. 회사나 사용자 지정 객체의 데이터를 이메일에 넣어 개인화할 수 있고, 기존 일괄 이메일의 작성·발송·리포트 기능을 그대로 써요.

이 문서에서는 회사나 사용자 지정 객체의 연결 정보로 수신 대상을 만들고, 수신자를 고르고, 메시지를 개인화하고, 발송 방식을 정하고, 결과를 확인하는 방법을 알아봐요.

## 연결된 연락처에게 일괄 이메일 보내기란?

회사나 사용자 지정 객체 레코드를 선택하면, 그 레코드와 연결된 연락처에게 이메일을 보낼 수 있어요.

사용자 지정 객체는 **연결 라벨**을 하나 이상 고를 수 있어요. 수신자는 가장 최근에 연결된 연락처, 가장 먼저 연결된 연락처, 연결된 모든 연락처 중에서 정해요. 회사는 하이퍼클래스가 연락처 연결을 자동으로 사용해요.

지원하는 회사·사용자 지정 객체 필드는 병합 필드로도 쓸 수 있어요. 그러면 이메일마다 원본 레코드의 정보를 넣을 수 있어요.

## 주요 장점

연결 정보를 기준으로 일괄 이메일을 보내면, 이미 CRM에 있는 관계를 바로 발송 대상으로 쓸 수 있어요. **연락처**에서 같은 세그먼트를 다시 만들지 않아도 돼요.

- 기존 레코드에서 바로 발송: 선택한 회사나 지원되는 사용자 지정 객체 레코드에서 시작해요.
- 특정 관계만 대상으로 지정: 사용자 지정 객체의 연결 라벨로 어떤 연락처를 포함할지 정해요.
- 수신자 선택 방식 조정: 가장 먼저 연결된 연락처, 가장 최근에 연결된 연락처, 연결된 모든 연락처 중에서 골라요.
- 원본 데이터로 개인화: 지원되는 회사·사용자 지정 객체 필드를 메시지에 넣어요.
- 중복 발송 방지: 선택한 여러 연결 라벨에 모두 해당하는 연락처는 중복을 제거해요.
- 기존 일괄 이메일 도구 사용: 작성, 테스트, 예약, 일괄 발송, 결과 추적을 기존 일괄 이메일 화면에서 그대로 해요.

## 사전 조건과 제한 사항

일괄 이메일은 기존 연락처 연결 정보와 일반적인 이메일 발송 조건을 따라요. 발송하기 전에 필요한 레코드와 연결 관계를 미리 준비해 두세요.

- 선택한 회사나 사용자 지정 객체 레코드에 연결된 연락처가 있어야 해요.
- 사용자 지정 객체에 연락처와의 연결이 있어야 **이메일 보내기**를 쓸 수 있어요.
- 회사는 하이퍼클래스가 연락처 연결을 자동으로 선택해요.
- 사용자 지정 객체는 해당하는 연결 라벨을 하나 이상 선택할 수 있어요.
- 최종 수신자 목록은 일괄 작업이 실행될 때 확정돼요.
- 선택한 여러 연결 라벨에 모두 해당하는 연락처에게는 이메일이 한 번만 가요.
- 사용할 수 있는 이메일 주소가 없거나 이메일 설정으로 제한된 연락처는 건너뛸 수 있어요.
- 기존 권한, 수신 동의 요건, 전달률 보호, 발송 제한 등 일괄 이메일의 다른 제한도 그대로 적용돼요.

## 설정 방법

수신 대상을 정하는 회사나 사용자 지정 객체 레코드에서 시작해요. 레코드의 연결 정보로 수신자가 정해지면, 이메일을 작성해서 보내요.

### 1단계: 원본 레코드 선택하기

수신 대상에 연락처를 넣을 레코드만 선택하세요.

1. 회사는 **연락처 > 회사**로 이동해요. 사용자 지정 객체는 서브 계정 왼쪽 메뉴에서 해당 객체를 열어요.
2. 레코드를 좁혀야 하면 필터나 스마트 리스트를 사용해요.
3. 연결된 연락처에게 이메일을 보낼 레코드를 선택해요.

![여러 레코드가 선택되고 이메일 보내기 일괄 작업이 보이는 사용자 지정 객체 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081929953/original/NNAoibr9W-TjpcuYVp9u3XuUlY-NtPN4AQ.png?1790460391)

### 2단계: 일괄 이메일 시작하기

확인 단계에서는 하이퍼클래스가 연결된 연락처를 찾기 전에 선택한 원본 레코드를 한 번 더 확인해요.

1. 일괄 작업 바에서 **이메일 보내기**를 클릭해요.
2. 선택한 레코드 수를 확인해요.
3. **확인 후 진행**을 클릭해요.

{% hint style="info" %}
수신자 수: 정확한 수신자 목록은 일괄 작업이 실행될 때 확정돼요. 최종 숫자는 일괄 작업의 통계에서 확인할 수 있어요.
{% endhint %}

### 3단계: 연결 라벨과 수신자 선택하기

연결 라벨은 사용자 지정 객체에서 어떤 관계를 대상으로 할지 정해요. 수신자 설정은 각 원본 레코드에서 연결된 연락처를 몇 명 선택할지 정해요.

1. **액션 이름**을 입력해요.
2. 사용자 지정 객체는 **연결 라벨**을 하나 이상 선택해요. 회사는 연락처 연결이 자동으로 선택돼요.
3. **이메일 수신자**에서 **가장 최근에 연결된 연락처**, **가장 먼저 연결된 연락처**, **연결된 모든 연락처** 중 하나를 선택해요.

![연결 라벨과 연결된 연락처 수신자 옵션이 보이는 일괄 이메일 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081929994/original/dcU4ht-UHMNsrfsPuIQkfh9sDpmNPXrw5w.png?1790460669)

### 4단계: 이메일 작성하고 보내기

기본 **Bulk Email Builder**(일괄 이메일 빌더)에서 메시지를 만들어요. 원본 레코드 필드로 개인화하고, 테스트 발송을 한 뒤, 발송 시점을 정해요.

1. 필수 발신자 정보, 제목, 필요하면 프리헤더를 입력해요.
2. **Quick Compose**(빠른 작성), **스마트 빌더에서**, **기존 템플릿 선택** 중 하나를 선택해요.
3. 이메일을 만들고, 필요하면 연락처, 회사, 사용자 지정 객체 병합 필드를 넣어요.
4. 필요하면 **첨부 파일 추가**를 하고 테스트 이메일을 보내요.
5. 클릭 추적이나 UTM 추적 같은 옵션이 필요하면 **추가 설정**을 열어요.
6. **모두 한 번에 발송**, **예약된 시간에 모두 보내기**, **일괄 모드로 보내기** 중 하나를 선택해요.
7. 설정을 검토하고, 필요한 수신 동의 확인을 마친 뒤 **이메일 보내기**를 클릭해요.

![이메일 작성 옵션, 메시지 내용, 발송 방식, 테스트 이메일 버튼이 보이는 일괄 이메일 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930014/original/kdLaPVB6rb5UBI1-cA-fv73rnmAmJ-hjcA.png?1790460820)

### 5단계: 결과 확인하기

일괄 이메일 통계에서 어떤 수신자가 정상 처리됐는지, 발송이나 반응에 어떤 문제가 있었는지 확인할 수 있어요.

**연락처 > 일괄 작업**에서 해당 발송 건을 열면 **Accepted**(수락), **Delivered**(전달됨), **Opened**(열람), **Clicked**(클릭), **Replied**(회신), **Unsubscribed**(수신 해지), **Complained**(스팸 신고), **Bounced**(반송), **Failed**(실패), **Skipped**(건너뜀) 같은 지표를 볼 수 있어요.

![연결된 연락처의 발송·반응 결과가 보이는 일괄 이메일 통계](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930018/original/OmpjYKICiuSsLo0S39kK-owzjyjVgsZGtA.png?1790460844)

더 넓은 범위의 리포트가 필요하면 일괄 작업에서 **Load More Stats**(통계 더 보기)를 사용하거나 **마케팅 > 이메일 > 통계**로 이동해요. 그다음 소스 필터에서 **Bulk Action Campaigns**(일괄 작업 캠페인)를 선택하세요.

## 활용 사례

대상이 회사나 업종별 사용자 지정 객체 레코드를 중심으로 나뉘어 있을 때 특히 유용해요.

- 부동산: 매물 레코드를 선택하고, 잠재 구매자로 연결된 연락처에게 이메일을 보내요.
- 보험: 갱신 시기가 다가오는 보험 증권을 선택하고, 연결된 보험 계약자에게 이메일을 보내요.
- B2B: 조건에 맞는 회사를 필터링하고, 연결된 연락처에게 이메일을 보내요.
- 반려동물·동물병원: 반려동물 레코드를 선택하고, 연결된 보호자에게 알림이나 소식을 보내요.
- 스마트 리스트 세그먼트: 회사나 사용자 지정 객체 스마트 리스트를 만들어 레코드를 선택하고, 연결된 연락처에게 바로 이메일을 보내요.

## 자주 묻는 질문

### 사용자 지정 객체에 이메일 보내기가 보이지 않아요.
사용자 지정 객체에 연락처와의 연결이 있어야 **이메일 보내기** 일괄 작업을 쓸 수 있어요.

### 여러 연결 라벨에 해당하는 연락처에게 이메일이 중복으로 가나요?
아니요. 선택한 여러 연결 라벨에 해당하는 연락처는 발송 전에 중복이 제거돼요.

### 연락처가 건너뛰어지는 이유는 무엇인가요?
사용할 수 있는 이메일 주소가 없거나, 기존 이메일 권한·수신 동의 설정·기타 발송 보호 때문에 전달이 막히면 건너뛸 수 있어요.

### 기존 이메일 템플릿을 사용할 수 있나요?
네. **Bulk Email Builder**에서 **기존 템플릿 선택**을 선택하면 저장해 둔 템플릿을 쓸 수 있어요.

### 클릭 추적이나 UTM 추적을 추가할 수 있나요?
네. **Bulk Email Builder**에서 **추가 설정**을 열면 **Track Clicks**(클릭 추적), **UTM 트래킹** 같은 추적 옵션을 쓸 수 있어요.

### 일괄 이메일의 전체 성과는 어디에서 확인하나요?
**연락처 > 일괄 작업**에서 해당 발송 건을 확인하세요. 또는 **마케팅 > 이메일 > 통계**를 열고 대시보드를 **Bulk Action Campaigns**로 필터링하세요.
