# 커스텀 오브젝트 감사 로그 확인하기

커스텀 오브젝트, 커스텀 오브젝트 레코드, 오브젝트 간 연관 관계에서 일어난 생성·수정·삭제 같은 주요 활동을 **감사 로그**에서 확인할 수 있어요. 이 기능은 처음에는 베타 사용자에게 제공돼요. 커스텀 오브젝트 전반에 걸친 변경 내용을 자세히 볼 수 있어요.

## 주요 기능: 오브젝트, 연관 관계, 오브젝트 레코드 활동 추적

- 새 커스텀 오브젝트를 만들거나 수정하면 감사 로그에 기록돼요.
- 커스텀 오브젝트 레코드를 하나씩 만들거나 수정하거나 삭제하는 작업도 기록돼요.
- 커스텀 오브젝트끼리, 또는 커스텀 오브젝트와 연락처 사이에서 연관 관계를 새로 만들거나 수정하거나 삭제하면 모두 추적돼요.
- 오른쪽의 점 세 개 메뉴를 클릭하고 **상세 보기**를 선택하면, 각 작업에서 무엇이 추가되거나 수정됐는지 더 자세히 확인할 수 있어요.

```
감사 로그는 해당 활동이 일어난 뒤 60일까지만 보관돼요.
```

## 감사 로그 확인하는 순서

1. **서브 계정 > 설정 > 감사 로그**로 이동하세요.

   ![감사 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034694929/original/wHJh-R4K6GAOOxch-lrWp1EAIvtAE9uxXQ.png?1728976110)

2. 변경 내용을 자세히 보고 싶은 항목의 오른쪽에 있는 점 세 개 메뉴를 클릭하세요.

   ![점 세 개 메뉴로 상세 정보 보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034695035/original/TuJoDwOyfyPHFUL2f4LVKS71i6onxZtdIw.png?1728976197)

3. 모듈 드롭다운에서 **오브젝트**, **Custom Objects**(커스텀 오브젝트), **Associations**(연관 관계) 중 하나를 선택하면 원하는 로그만 걸러서 볼 수 있어요.

   ![모듈 드롭다운으로 필터링하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034695052/original/WfG_pttCn3Ak2YjKC4dY6Vtl1S067PGvrA.png?1728976216)
