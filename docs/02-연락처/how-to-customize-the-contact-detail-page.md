# 연락처 상세 페이지 사용자 지정하기

하이퍼클래스에서는 관리자가 연락처 상세 페이지를 업무 방식에 맞게 바꿀 수 있어요. 이 문서에서는 보기를 만들고, 패널과 모듈을 정리하고, 표시할 항목을 정하고, 사용자에게 보기를 지정하는 방법을 안내해요.

## 연락처 상세 페이지 사용자 지정이란?

관리자는 연락처 기록이 하이퍼클래스 안에서 어떻게 보일지 직접 정할 수 있어요. 보기를 만들어 패널을 정리하고, 표시할 모듈과 필드를 고르고, 보기를 사용자별로 지정해요. 이렇게 하면 영업, 지원, 관리자 같은 역할마다 알맞은 화면을 만들 수 있어요.

{% hint style="info" %}
보기는 관리자만 만들고 관리할 수 있어요.
{% endhint %}

---

## 사용자 지정의 장점

- 역할별 보기: 사용자마다 다른 연락처 레이아웃을 만들 수 있어요.
- 더 쉬운 정리: 업무 우선순위에 따라 모듈, 폴더, 필드를 배치할 수 있어요.
- 덜 복잡한 화면: 필요 없는 필드와 모듈을 숨겨서 페이지를 단순하게 만들 수 있어요.
- 더 빠른 작업: 자주 쓰는 도구를 **Center Panel**(가운데 패널)이나 **Dynamic Tab**(동적 탭)에 둘 수 있어요.
- 더 세밀한 관리: 삭제 권한을 제한하고, 알맞은 보기를 알맞은 사용자에게 지정할 수 있어요.

---

## 보기와 접근 관리

보기를 쓰면 관리는 한곳에서 하면서도 사용자마다 다른 레이아웃을 보여 줄 수 있어요. 관리자는 어떤 사용자가 어떤 레이아웃을 볼지 정하고, 계정의 기본 화면도 정할 수 있어요.

- 계정당 보기를 최대 5개까지 만들 수 있어요.
- 보기는 관리자만 만들고 관리할 수 있어요.
- **기본 보기**는 미리 설정되어 있어서 바꿀 수 없어요.
- 보기는 **사용자 관리**에서 사용자에게 지정해요.
- 각 보기에 어떤 사용자가 연결되어 있는지 확인하고, 필요하면 다시 지정할 수 있어요.

## 연락처 상세 페이지 레이아웃 구조

연락처 상세 페이지는 여러 영역으로 나뉘어 있어서, 사용자의 업무 방식에 맞게 정보를 정리할 수 있어요. 각 영역을 알아 두면 탐색하기 쉽고 관리하기 편한 레이아웃을 만들 수 있어요.

패널 크기도 조절할 수 있어서 사용자가 업무에 맞게 페이지를 바꿀 수 있어요. 필드, 폴더, 모듈이 들어갈 공간이 더 필요하면 **Left Panel**(왼쪽 패널)을 넓혀 보세요.

![패널 크기를 조절하는 화면](https://jumpshare.com/share/ac38qsvKBiDpQ2TThtGQ+/GIF+Recording+2026-06-25+at+19.31.39.gif)

각 보기는 네 가지 영역으로 구성돼요.

{% hint style="warning" %}
**대화** 모듈은 고정되어 있어서 항상 **Center Panel**에 표시돼요.
{% endhint %}

1. **Contact Card**(연락처 카드): 주요 연락처 정보를 보여 주는 맨 위 영역이에요.
2. **Left Panel**: 커스텀 필드, 기본 필드, 폴더를 두는 영역이에요.
3. **Center Panel**: 주요 모듈을 두는 기본 작업 공간이에요.
4. **Right Panel**(오른쪽 패널): 추가 모듈을 두는 영역이에요.

![연락처 상세 페이지의 네 가지 영역](https://jumpshare.com/share/f8e4SgmKsxc5a9OQFglB+/Screen+Shot+2026-03-27+at+16.14.50.png)

## 연락처 상세 페이지 사용자 지정 방법

잘 설정해 두면 연락처 상세 페이지가 쓰기 편해지고, 사용자마다 필요한 정보를 알맞은 자리에서 볼 수 있어요. 아래 단계를 따라 사용자 지정 보기를 만들고 지정해 보세요.

#### 1단계: 사용자 지정 탭 열기

1. **연락처** 탭을 클릭하세요.
2. **스마트 리스트**로 이동하세요.
3. 점 세 개 아이콘을 클릭하세요.
4. **설정**을 클릭하세요.

   ![설정 메뉴](https://jumpshare.com/share/vQSG6BokMXzMoCgnCXAH+/Screen+Shot+2026-03-27+at+16.44.34.png)
5. **Customize Contact detail view**(연락처 상세 보기 사용자 지정) 탭을 클릭하세요.

   ![연락처 상세 보기 사용자 지정 탭](https://jumpshare.com/share/TZbd82upGM8qEuli7qN8+/Screen+Shot+2026-03-27+at+16.49.58.png)

#### 2단계: 보기 만들고 관리하기

필요하면 새 보기를 만들어요. 보기를 쓸 사용자나 업무에 맞게 이름을 정하세요.

{% hint style="info" %}
계정당 보기는 최대 5개까지 만들 수 있고, 보기는 관리자만 만들고 관리할 수 있어요.
{% endhint %}

1. **+ Add View**(보기 추가) 버튼을 클릭하세요.

   ![보기 추가 버튼](https://jumpshare.com/share/BWmH13Y26MiiLWHSoDBg+/Screen+Shot+2026-03-27+at+17.28.06.png)
2. **이름 보기**에 보기 이름을 입력하세요.
3. **Assign User(s)**(사용자 지정)에서 이 보기를 쓸 사용자를 고르세요. 한 사용자는 보기 하나에만 속할 수 있어요. 보기에서 빠지면 **기본 보기**로 돌아가요.
4. **만들기**를 클릭하세요.

   ![보기 만들기](https://jumpshare.com/share/mWx2CiKeHGOc6vfsRgdX+/Screen+Shot+2026-03-27+at+17.31.03.png)
5. 보기를 만들고 나면 보기 오른쪽 위의 점 세 개 아이콘을 클릭해 다음 작업을 할 수 있어요.

   - **Rename View**(보기 이름 변경)
   - **사용자 관리**
   - **Duplicate View**(보기 복제)
   - **보기 삭제**

   ![보기 옵션 메뉴](https://jumpshare.com/share/li5pKONNqpfiFBOv6lS2+/Screen+Shot+2026-03-27+at+17.33.34.png)
6. **사용자 관리**에서 알맞은 사용자에게 보기를 지정하세요.
7. **모든 사용자 관리**를 클릭하면 사용자 지정 현황을 한눈에 볼 수 있어요.
8. 각 보기에 어떤 사용자가 연결되어 있는지 확인하고, 필요하면 다시 지정하세요.

   ![모든 사용자 관리 화면](https://jumpshare.com/share/1vac4a3cvk8RsKvsHdA7+/Screen+Shot+2026-03-27+at+17.38.34.png)

#### 3단계: 상세 페이지 사용자 지정하기

레이아웃 편집기에서 연락처 상세 페이지를 정리해요.

**1. Contact Card 사용자 지정**

**Contact Card**는 중요한 연락처 정보를 기록 맨 위에 계속 보여 줘요.

다음 항목을 추가하고 배치할 수 있어요.

- **전화번호**
- **이메일 주소**
- **Contact address**(연락처 주소)
- **소유자**
- **팔로워**
- **태그**
- 커스텀 필드 최대 2개

자세한 내용은 다음과 같아요.

- **소유자**와 **팔로워**는 따로 관리할 수 있어요.
- 소유자만, 팔로워만, 둘 다, 또는 둘 다 표시하지 않을 수 있어요.
- 빠르게 확인할 수 있도록 **Contact Card**에 커스텀 필드를 최대 2개까지 추가할 수 있어요.
- **Contact Card**에 표시된 커스텀 필드는 읽기 전용이에요.
- 커스텀 필드 값을 수정하려면 **모든 필드** 탭을 사용하세요.
- **태그**를 꼭 **Contact Card**에 둘 필요는 없어요. 레이아웃에 따라 **Left Panel**이나 **Center Panel**에 둘 수 있어요.
- 기본 전화번호만 표시할 수 있어요.
- 기본 이메일 주소만 표시할 수 있어요.
- **Contact Card** 안에서 사용할 수 있는 항목의 순서를 바꿀 수 있어요.
- 필요 없는 필드는 숨길 수 있어요.
- **삭제** 버튼을 비활성화하면 연락처를 실수로 삭제하는 일을 막을 수 있어요.

![Contact Card 사용자 지정](https://jumpshare.com/share/1TThZA4LjEUMpTqzbFRU+/GIF+Recording+2026-06-25+at+19.23.54.gif)

**2. Left Panel 사용자 지정**

**Left Panel**은 필드 데이터를 정리해서 연락처 정보를 빠르게 확인하고 수정할 수 있게 해 줘요.

**Left Panel**에서 할 수 있는 일은 다음과 같아요.

- 커스텀 폴더와 필드 순서 바꾸기
- 폴더 이름을 알아보기 쉽게 바꾸기
- 관련 없는 필드 숨기기
- 제거한 필드를 **추가** 버튼으로 다시 추가하기
- 현재 표시된 필드 수 확인하기

![Left Panel 사용자 지정](https://jumpshare.com/share/Ih5yKoVC5ZwmSY5TLrmj+/GIF+Recording+2026-03-27+at+18.46.09.gif)

**3. Dynamic Tab 사용하기**

**Dynamic Tab**을 쓰면 우선순위가 높은 모듈 하나를 전용 탭에 두고 빠르게 열 수 있어요.

- **Dynamic Tab**은 **모든 필드** 탭과 **작업** 탭 사이에 표시될 수 있어요.
- 이 탭에 지원되는 모듈을 하나 지정할 수 있어요.
- 모듈을 **Dynamic Tab**에 두면 원래 있던 탭에서는 빠져요.
- **Dynamic Tab**에 둔 모듈은 탭을 열 때 기본으로 펼쳐진 상태로 열려요.
- **기회 관리**나 **클라이언트 포탈**처럼 빠르게 접근해야 하는 항목에 쓰면 좋아요.
- 사용자의 업무 흐름에 맞게 탭 이름을 바꾸고 순서를 바꿀 수도 있어요.

![Dynamic Tab 사용하기](https://jumpshare.com/share/j33MJwGwkTIOaxK8hxcl+/GIF+Recording+2026-06-25+at+19.36.18.gif)

**4. Center Panel 사용자 지정**

**작업** 탭이나 **Right Panel**에서 모듈을 끌어다 놓아 레이아웃을 꾸며요. **대화** 모듈은 항상 가운데에 고정되어 있어서 제거할 수 없어요.

{% hint style="info" %}
- **작업** 모듈은 **Center Panel**로 옮기거나 **Left Panel**에 그대로 둘 수 있어요.
- **작업** 모듈은 **Right Panel**로 옮길 수 없어요.
- **Right Panel** 모듈은 **Right Panel**에 그대로 두거나 **Center Panel**로 옮길 수 있어요.
{% endhint %}

표시 방식은 다음 중에서 고를 수 있어요.

- **Tabs View**(탭 보기): 모듈이 스마트 리스트처럼 탭으로 표시돼요.
- **Dropdown View**(드롭다운 보기): 모듈이 드롭다운 메뉴 안에 묶여서 화면이 덜 복잡해 보여요.

{% hint style="info" %}
**태그**는 공간이 더 필요하거나 **Contact Card**를 더 깔끔하게 유지하고 싶을 때 **Center Panel**에 둘 수 있어요.
{% endhint %}

업무 방식에 가장 잘 맞는 표시 방식을 고르세요.

![Center Panel 사용자 지정](https://jumpshare.com/share/dGoP40fVMImankvdVXem+/GIF+Recording+2026-03-27+at+18.53.00.gif)

**5. Right Panel 사용자 지정**

빠르게 접근할 수 있도록 모듈 순서를 바꾸세요.

![Right Panel 사용자 지정](https://jumpshare.com/share/djBdfqcELGTGXwVGH9oh+/GIF+Recording+2026-03-27+at+19.02.57.gif)

**6. 패널 레이아웃 고르기**

한 번에 봐야 하는 정보의 양에 맞는 레이아웃을 고르세요.

선택할 수 있는 레이아웃은 다음과 같아요.

- **Three-Panel View (Default)**(3패널 보기, 기본): 왼쪽, 가운데, 오른쪽 패널을 모두 보여 줘요.
- **Two-Panel View**(2패널 보기): **Right Panel** 모듈을 **Center Panel**에 합쳐서 더 간결하게 보여 줘요.

자세한 내용은 다음과 같아요.

- **Two-Panel View**에서는 **Right Panel** 항목이 **Center Panel**에 합쳐져요.
- 다시 바꾸면 이전 배치로 돌아가요.

![패널 레이아웃 선택](https://jumpshare.com/share/FPbwQouJ61dg8uJLm7nQ+/GIF+Recording+2026-03-27+at+19.07.05.gif)

#### 4단계: 레이아웃 확인하고 저장하기

실시간 미리보기로 레이아웃을 확인한 다음 **저장**을 클릭해 보기를 저장하세요.

![보기 저장](https://jumpshare.com/share/qZJzJyyKXRWnYMj0tXgm+/Screen+Shot+2026-03-27+at+19.14.06.png)

## 사용자 지정 활용 팁

몇 가지만 지켜도 보기를 더 유용하고 관리하기 쉽게 만들 수 있어요.

- 마케팅, 영업, 지원, 관리자 등 역할별로 보기를 따로 만드세요.
- 우선순위가 높은 모듈은 **Center Panel**에 두세요.
- 쓰지 않는 필드는 숨겨서 화면을 덜 복잡하게 만드세요.
- 가장 자주 쓰는 작업이나 모듈은 **Dynamic Tab**에 두세요.
- 연락처 데이터 보호가 중요하다면 **삭제** 버튼을 비활성화하세요.

## 자주 묻는 질문

### 연락처 상세 페이지 보기는 누가 만들고 관리할 수 있나요?
관리자만 보기를 만들고, 편집하고, 관리할 수 있어요.

### 계정당 보기를 몇 개까지 만들 수 있나요?
계정당 보기를 최대 5개까지 만들 수 있어요.

### Contact Card에 커스텀 필드를 추가할 수 있나요?
네. **Contact Card**에 커스텀 필드를 최대 2개까지 추가할 수 있어요. 카드에서는 읽기 전용이에요. 값을 수정하려면 **모든 필드** 탭을 사용하세요.

### 기본 보기를 여러 개 설정할 수 있나요?
아니요. 한 번에 하나의 기본 보기만 활성화할 수 있어요.

### 사용자마다 다른 보기를 지정할 수 있나요?
네. 관리자가 **사용자 관리**에서 보기를 지정하거나 다시 지정할 수 있어요.

### 대화 모듈을 다른 패널로 옮길 수 있나요?
아니요. **대화** 모듈은 **Center Panel**에 고정되어 있어요.

### 작업 모듈을 Right Panel로 옮길 수 있나요?
아니요. **작업** 모듈은 **Left Panel**에 그대로 두거나 **Center Panel**로 옮길 수 있지만, **Right Panel**로는 옮길 수 없어요.

### 2패널과 3패널 레이아웃을 바꿔 가며 쓸 수 있나요?
네. 관리자는 필요에 따라 두 레이아웃 중에서 바꿀 수 있어요.

### 숨긴 모듈이나 필드를 나중에 다시 표시할 수 있나요?
네. 제거한 모듈과 숨긴 필드는 **추가** 버튼으로 다시 추가할 수 있어요.
