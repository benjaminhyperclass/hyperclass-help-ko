# 사용자 지정 객체 목록 보기: 레코드 정렬하고 표시 필드 관리하기

사용자 지정 객체의 **목록 보기**에서는 레코드를 표 형태로 한눈에 확인하고, 정렬하고, 관리할 수 있어요. 필드 표시와 열 배치를 조정해 팀에 맞는 화면을 만들 수 있고, 실제 데이터는 바뀌지 않아요.

## 기능 개요

**목록 보기**로 할 수 있는 일은 다음과 같아요.

- **표 형태 레이아웃:** 레코드를 구조화된 표로 보여 주어 빠르게 훑어볼 수 있어요.
- **정렬 옵션:** 지원되는 필드를 기준으로 정렬해 중요한 레코드를 먼저 볼 수 있어요.
- **열 사용자 설정:** 필드를 표시하거나 숨기고, 업무 방식에 맞게 열 배치를 조정할 수 있어요. 연결된 필드도 포함돼요.

## 사용자 지정 객체 레코드를 목록으로 보기

여러 레코드를 한꺼번에 비교하거나, 레코드를 하나씩 열지 않고 세부 정보를 찾을 때 목록 보기가 편해요.

1. 하이퍼클래스에서 **사용자 지정 객체**로 이동하세요.
2. 확인할 사용자 지정 객체의 **목록 보기**를 여세요.
3. 표에서 레코드를 훑어보며 필요한 정보를 찾으세요.

## 필드 기준으로 레코드 정렬하기

최근에 수정된 레코드를 확인하거나, 중요한 필드 기준으로 우선순위를 정하거나, 비슷한 데이터를 모아 볼 때 정렬을 쓰면 편해요.

하이퍼클래스에서는 사용자 지정 객체 목록 보기를 **생성일**, **수정일** 필드뿐 아니라 커스텀 필드 기준으로도 정렬할 수 있어요.

### 방법 1: 정렬 메뉴 사용하기

1. **사용자 지정 객체**로 이동해 **목록 보기**를 여세요.
2. **정렬**을 클릭하세요.
3. 정렬 기준으로 쓸 필드를 선택하세요.
4. **오름차순** 또는 **내림차순**을 선택하세요.
5. **적용**을 클릭하세요.

### 방법 2: 열 머리글 클릭하기

1. 표에서 정렬 기준으로 쓸 필드의 열 머리글을 클릭하세요.
2. 같은 머리글을 다시 클릭하면 **오름차순**과 **내림차순**이 번갈아 바뀌어요.

## 정렬을 지원하지 않는 필드 유형

다음 커스텀 필드 유형은 정렬이 **지원되지 않음** 상태예요.

- **Dropdown (Multiple)**(다중 선택 드롭다운)
- **Checkbox**(체크박스)
- **Textbox List**(텍스트박스 목록)

## 표시 필드와 레이아웃 설정하기

꼭 필요한 필드만 열로 보여 주면 팀이 중요한 정보에 집중할 수 있고, 화면도 깔끔해져요. 매일 쓰는 업무 화면을 팀원 모두 같은 모양으로 맞추기에도 좋아요.

표시되는 필드와 배치는 이렇게 조정할 수 있어요.

- **표시 필드 선택:** 열로 보여 줄 필드를 고르세요. 해당하는 경우 연결된 필드도 고를 수 있어요.
- **열 너비 조정:** 열 가장자리를 끌어서 너비를 바꾸세요.
- **열 순서 변경:** 업무 흐름에 맞게 열 순서를 바꾸세요.

## 자주 묻는 질문

### 사용자 지정 객체 목록 보기에서 커스텀 필드로 정렬할 수 있나요?
네. 지원되는 커스텀 필드와 **생성일**, **수정일** 필드로 정렬할 수 있어요.

### 레코드를 가장 빠르게 정렬하는 방법은 무엇인가요?
정렬 기준으로 쓸 필드의 열 머리글을 클릭하세요. 한 번 더 클릭하면 **오름차순**과 **내림차순**이 번갈아 바뀌어요.

### Checkbox나 다중 선택 드롭다운 필드로는 왜 정렬이 안 되나요?
목록 보기에서는 해당 필드 유형의 정렬을 지원하지 않기 때문이에요. **Checkbox**, **Dropdown (Multiple)**, **Textbox List** 유형이 여기에 해당해요.

### 목록 보기에 표시되는 열을 바꿀 수 있나요?
네. 열로 보여 줄 필드를 직접 고를 수 있고, 연결된 필드가 있으면 그것도 고를 수 있어요.

### 열 순서를 바꾸거나 너비를 조절할 수 있나요?
네. 원하는 레이아웃에 맞게 열 순서를 바꾸고 너비를 조절할 수 있어요.
