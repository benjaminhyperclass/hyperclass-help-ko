# 회사 스마트 리스트

회사 스마트 리스트는 자주 쓰는 회사 목록 설정을 저장해 두고 다시 불러오는 기능이에요. 같은 설정을 매번 새로 만들 필요 없이, 필터·정렬·표시 필드를 스마트 리스트로 저장해 두었다가 필요할 때 열면 돼요.

## 개요

회사 스마트 리스트를 쓰면 설정해 둔 목록을 저장해 두고 **회사** 데이터를 더 빠르게 볼 수 있어요.

스마트 리스트에는 다음 설정을 담을 수 있어요.

- **상세 필터**
- 정렬 순서
- 화면에 표시할 **선택된 필드**

같은 조건으로 거래처 목록을 반복해서 보는 팀에 특히 유용해요. 예를 들어 갱신 대상을 확인하는 계정 매니저, 이탈 위험 고객사를 추적하는 CS 팀, 핵심 고객사를 관리하는 영업 리더가 쓰기 좋아요.

## 회사 스마트 리스트란?

회사 스마트 리스트는 저장해 둔 회사 보기예요.

회사 레코드를 보는 방식을 한 번 설정해 두면 계속 재사용할 수 있어요. 예를 들어 다음과 같은 스마트 리스트를 만들 수 있어요.

- 최근에 업데이트되지 않은 회사
- 매출이 큰 고객사(예: MRR이 기준 금액 이상)
- 특정 업종이나 등급의 고객사
- 특정 담당자나 팀에 배정된 회사
- 갱신 시기가 다가온 엔터프라이즈 고객사

스마트 리스트는 나중에 다시 열 때 필터, 정렬, 필드 선택을 처음부터 다시 설정하지 않아도 돼요.

## 이럴 때 좋아요

- 자주 쓰는 회사 목록을 재사용해서 시간을 아낄 수 있어요.
- 고객사 목록 설정을 체계적으로 관리할 수 있어요.
- 사용자마다 같은 기준으로 고객사 목록을 볼 수 있어요.
- 유용한 스마트 리스트를 필요한 팀원에게 공유할 수 있어요.
- 필터링된 회사 레코드를 필요할 때 내보낼 수 있어요.

## 스마트 리스트 만들기

1. **연락처 > 회사**로 이동하세요.
2. **+List**(리스트 추가)를 클릭하세요.
3. 원하는 설정을 적용하세요. 예를 들면 다음과 같아요.
   - **상세 필터**
   - 정렬 설정
   - 표시 필드(관리 필드)
4. 스마트 리스트 이름을 입력하세요.
5. **저장**을 클릭하세요.

새 스마트 리스트가 목록에 나타나요.

## 스마트 리스트에 저장되는 내용

스마트 리스트에는 만들 때 설정한 목록 구성이 저장돼요.

- **상세 필터**
- 정렬 순서
- 보기에 표시되는 **선택된 필드**

설정이 그대로 저장되기 때문에 나중에 열면 같은 보기가 나타나고, 회사 데이터는 최신 상태로 보여요.

## 기존 스마트 리스트 편집하기

기존 스마트 리스트는 언제든 수정할 수 있어요.

1. 스마트 리스트를 여세요.
2. 필터, 정렬, 표시 필드를 변경하세요.
3. 변경하면 **저장되지 않은 변경사항**이 표시돼요.

- **저장** – 현재 스마트 리스트를 업데이트해요.
- **새 스마트 리스트로 저장** – 변경한 설정으로 새 스마트 리스트를 만들어요.
- **변경사항 취소** – 저장하지 않은 수정 내용을 없애요.

현재 설정을 덮어쓰려면 **저장**을 사용하세요.

원래 설정은 그대로 두고 새 버전을 만들려면 **새 스마트 리스트로 저장**을 사용하세요.

## 스마트 리스트 복제하기

복제하면 처음부터 다시 만들지 않고도 비슷한 스마트 리스트를 빠르게 만들 수 있어요.

1. 스마트 리스트를 여세요.
2. **목록 사용자 지정**을 클릭하세요.
3. **중복**을 선택하세요.
4. 복제한 스마트 리스트의 새 이름을 입력하세요.
5. **저장**을 클릭하세요.

팀이나 용도에 따라 조금씩 다른 버전이 필요할 때 유용해요. 예를 들어 필드 구성만 조금 다른 "상위 고객사 – 영업" 목록과 "상위 고객사 – CS" 목록을 만들 수 있어요.

## 스마트 리스트 내보내기

스마트 리스트에 표시되는 회사 레코드를 내보낼 수 있어요.

1. 스마트 리스트를 여세요.
2. **목록 사용자 지정**을 클릭하세요.
3. **내보내기**를 선택하세요.

내보낸 파일에는 해당 스마트 리스트의 현재 설정에 따라 조회되는 회사가 담겨요.

![스마트 리스트 내보내기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072048486/original/NTE3UOHRt0_giF7fs0Kc5rYo2dIlb-Y_2Q.png?1779526380)

## 모든 스마트 리스트 관리하기

**스마트 리스트 관리**에서 모든 스마트 리스트를 한곳에서 확인할 수 있어요.

1. **회사**로 이동하세요.
2. 오른쪽 위의 점 3개 메뉴를 클릭하세요.
3. **스마트 리스트 관리**를 선택하세요.

이 페이지에서 다음 정보를 볼 수 있어요.

- 스마트 리스트 이름
- 공유된 사용자
- 만든 사람
- 마지막 업데이트 시점

중복된 보기를 정리하거나, 공유 상태를 점검하거나, 스마트 리스트를 정돈할 때 유용해요.

![스마트 리스트 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072048504/original/1-0VyoFajI_ayGidxloMDHu7h33urgiYZw.png?1779526426)

## 스마트 리스트 공유하기

스마트 리스트는 서브 계정의 사용자와 공유할 수 있어요.

1. 스마트 리스트를 여세요.
2. **목록 사용자 지정**을 클릭하세요.
3. **Sharing & Permissions**(공유 및 권한)를 선택하세요.
4. 공유 대상을 선택하세요.
   - **모든 사용자**
   - **Selected users**(선택한 사용자)
5. 접근 수준을 지정하세요.
   - **조회 가능**
   - **편집 가능**
6. 공유 설정을 저장하세요.

스마트 리스트의 직접 링크를 복사해서 공유할 수도 있어요.

### 권한 종류

**조회 가능**

사용자가 스마트 리스트를 열어서 사용할 수 있어요.

**편집 가능**

사용자가 스마트 리스트 설정을 바꿀 수 있어요.

편집 권한을 줄 때는 주의하세요. 편집 권한이 있는 사용자는 스마트 리스트 설정과 공유 설정을 변경할 수 있어요.

## 스마트 리스트 삭제하기

스마트 리스트를 삭제하려면 다음 순서대로 하세요.

1. 스마트 리스트를 여세요.
2. **목록 사용자 지정**을 클릭하세요.
3. **리스트 삭제**를 선택하세요.
4. **삭제 확인**을 클릭하세요.

더 이상 필요하지 않을 때만 삭제하세요. 다른 사용자와 공유 중인 스마트 리스트라면 특히 신중하게 결정하세요.

## 자주 묻는 질문

### 이 기능을 먼저 켜야 하나요?

네. 회사 스마트 리스트를 사용하려면 먼저 **Subaccount Labs**(서브 계정 실험실)에서 기능을 활성화해야 해요.

### 스마트 리스트에는 어떤 설정이 저장되나요?

필터, 정렬 설정, 표시 필드 구성이 저장돼요.

### 스마트 리스트를 다른 사용자와 공유할 수 있나요?

네. 모든 사용자 또는 선택한 사용자와 공유할 수 있어요.

### 조회 가능과 편집 가능은 어떻게 다른가요?

**조회 가능**은 사용자가 스마트 리스트를 열 수 있는 권한이에요. **편집 가능**은 스마트 리스트를 변경할 수 있는 권한이에요.

### 스마트 리스트를 처음부터 다시 만들지 않고 복제할 수 있나요?

네. **목록 사용자 지정**에서 **중복**을 사용하세요.

### 스마트 리스트에 있는 회사를 내보낼 수 있나요?

네. **내보내기**를 사용하세요.

### 회사 스마트 리스트는 실시간으로 업데이트되나요?

네. 회사의 필드 값이 바뀌면 해당 회사가 스마트 리스트에 자동으로 추가되거나 제외돼요. 직접 새로고침할 필요가 없어요.

### 모든 스마트 리스트를 한곳에서 보려면 어떻게 하나요?

**회사** 화면에서 **스마트 리스트 관리**를 사용하세요.
