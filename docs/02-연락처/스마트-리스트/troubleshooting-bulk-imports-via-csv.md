# CSV 일괄 가져오기 오류 해결하기

이 아티클은 하이퍼클래스에서 CSV 파일로 연락처(Contacts)를 가져올 때 발생할 수 있는 오류를 해결하는 데 도움을 드립니다. 각 오류 코드에는 구체적인 원인과 해결 방법이 함께 제공됩니다. 이를 이해하면 일괄 가져오기(Bulk Import)를 깔끔하고 원활하게, 성공적으로 완료할 수 있어요.

## 일괄 가져오기란 무엇인가요?

일괄 가져오기(Bulk Importing)를 사용하면 CSV 파일을 이용해 대량의 연락처 데이터를 한 번에 빠르게 업로드할 수 있어요. 온보딩(Onboarding), 리드(Lead) 마이그레이션, 리스트 동기화 등에 매우 유용한 기능이지만, 형식(포맷) 오류가 있으면 진행이 막힐 수 있습니다. 이 가이드는 그런 오류를 해결하는 데 도움을 드려요.

아래 영상에서는 특정 연락처 가져오기 일괄 작업(Bulk Action)과 연결된 오류 로그를 확인하는 방법과, 오류를 하나씩 해결하는 과정을 안내합니다.

---

## 성공적인 CSV 가져오기의 주요 장점

일괄 가져오기 문제 해결법을 익혀두면 시간을 아끼고 답답한 장애물을 피할 수 있어요. 이유는 다음과 같습니다.

- 재작업을 줄여 시간 절약
- 중복되거나 충돌하는 연락처 레코드 생성 방지
- 깔끔하고 검증된 연락처 데이터 유지
- 워크플로우(Workflow) 자동화를 막는 가져오기 실패 방지
- 정확한 담당자(Owner/User) 배정 보장
- 캠페인 개인화 및 태그(Tag) 정보 유지

## CSV 가져오기 문제 해결 체크리스트

일반적인 CSV 오류를 예방하려면 가져오기 전에 아래 체크리스트를 활용하세요.

- 파일에 시트(Sheet)가 하나만 있는지 확인
- 필수 필드가 모두 채워져 있고 올바르게 형식화되어 있는지 확인
- 이메일, 전화번호, 날짜 형식을 올바르게 지정
- 각 행마다 고유한 연락처 ID(Contact ID) 사용
- 열거형/드롭다운 값이 정확히 일치하는지 확인
- Owner(담당자) 열에는 유효한 하이퍼클래스 사용자 이메일 사용
- 신뢰할 수 있는 기본 열(Primary Column)(예: 이메일 또는 연락처 ID) 선택

## 전체 일괄 가져오기 오류 코드 목록

**스프레드시트에 값을 입력할 때 발생하는 형식 오류**

**1001 - 알 수 없는 오류**

알 수 없는 오류로 인해 하이퍼클래스가 파일을 처리하지 못했습니다.

데이터가 가져와지지 않았어요.

파일이 모든 요구 사항을 충족하는지 확인하세요. 브라우저 캐시를 삭제하거나 다른 브라우저를 사용하여 다시 가져오기를 시도해보세요.

**1002 - HL에 여러 명의 담당자(Owner)가 발견됨**

가져오기 파일에 있는 Owner 값이 계정 내 두 명 이상의 사용자와 일치합니다. 보통 이름이 겹칠 때 발생합니다(예: 하이퍼클래스 계정에 "John Doe"라는 사용자가 두 명 있고, 가져오기 파일에 "John Doe"라는 이름이 포함된 경우). 해당 레코드는 가져와졌지만 Owner 속성에는 값이 없습니다.

가져오기 파일에서 담당자 이름을 이메일 주소로 바꾼 후 다시 가져오세요. 또는 해당 레코드에서 Owner 속성 값을 직접 수정할 수도 있습니다.

**1003 - 잘못된 시트 개수**

가져오기 파일에 시트가 하나 이상 포함되어 있습니다. 데이터가 가져와지지 않았어요.

가져오기 파일에서 추가 시트를 삭제한 후 다시 가져오세요. 하이퍼클래스로 가져오기 위한 추가 파일 요구 사항을 확인해보세요.

**1004 - 잘못된 필수 속성**

가져오기 파일의 필수 속성에 유효하지 않은 값이 포함되어 있습니다. 해당 행의 데이터는 가져와지지 않았어요.

해당 속성 또는 속성 유형의 형식 요구 사항을 확인한 후, 파일을 올바른 형식에 맞게 수정하고 다시 가져오세요.

**1005 - 잘못된 열거형(Enumeration) 옵션**

가져오기 파일에 열거형 속성의 기존 옵션과 일치하지 않는 값이 포함되어 있습니다. 이는 다중 선택, 드롭다운 선택, 라디오 선택, 체크박스 유형 속성에 적용됩니다.

해당 레코드는 가져와졌지만 열거형 속성에는 값이 없습니다.

가져오기 파일과 하이퍼클래스의 속성을 비교하여 잘못된 값을 확인하세요. 가져오기 파일의 값을 기존 옵션에 맞게 수정하거나, 해당 값을 속성에 커스텀 옵션으로 추가할 수 있습니다. 완료 후 파일을 다시 가져오거나 해당 레코드의 속성 값을 직접 수정하세요.

**1006 - 잘못된 연락처 ID**

가져오는 동안 연락처 ID(Contact ID)를 이용해 기존 레코드를 업데이트하는 체크박스가 선택되었습니다. 그러나 파일에 있는 연락처 ID가 하이퍼클래스의 기존 ID와 일치하지 않았습니다.

해당 레코드는 가져와지지 않았어요.

[object] ID가 올바른지 확인하세요. 정확한 object ID를 얻기 위해 기존 레코드를 내보내야 할 수도 있습니다. 하이퍼클래스의 기존 object를 업데이트하거나 연결하지 않는 경우, 가져오기 과정에서 해당 체크박스를 선택하지 마세요.

**1007 - 파일을 찾을 수 없음**

선택한 파일을 찾을 수 없습니다. 데이터가 가져와지지 않았어요.

파일이 컴퓨터에 저장되어 있는지, 올바른 파일 형식인지 확인하세요. 확인 후 파일을 다시 업로드하세요.

**HL/파일 내 중복 항목**

**1008 - 이메일 유효성 검사 실패**

가져오기 파일에 일반적인 이메일 주소 형식(예: name@domain.com)에 맞지 않는 이메일 주소가 포함되어 있습니다.

가져오기는 레코드를 생성하거나 업데이트하지 않았어요.

연락처의 경우, 가져오기 파일의 이메일을 올바른 형식('@', '.com' 포함)으로 수정한 후 다시 가져오세요.

**1009 - 파일 내 고유 속성 값이 비어 있음**

가져오기 파일에 고유 식별자(기본 열)에 대한 값이 없는 데이터가 포함된 행이 있어 처리할 수 없습니다.

가져오려는 속성에 맞는 올바른 형식으로 데이터 값을 확인한 후 다시 가져오세요. 또는 해당 레코드의 속성 값을 직접 수정할 수도 있습니다.

**1010 - HL 내 고유 속성 값 중복**

기본 열의 동일한 값이 여러 레코드에 존재합니다. 데이터는 모든 HL 레코드에 대해 가져와졌지만, 하이퍼클래스 내에 동일한 레코드가 중복될 수 있습니다.

기본 열로 사용할 다른 열 헤더를 선택하거나 오류를 수정한 후 파일을 다시 가져오세요.

**1011 - 파일 내 고유 속성 값 중복**

파일 내에서 동일한 고유 값이 여러 번 사용되었습니다. 데이터는 가져와졌지만, 하이퍼클래스 내에 동일한 레코드가 중복될 수 있습니다. 연결(Association)을 시도한 경우 레코드가 연결되지 않았어요.

고유 값으로 사용할 다른 열 헤더를 선택하거나 오류를 수정한 후 파일을 다시 가져오세요.

**1012 - 파일 내 연락처 ID 중복**

파일 내에서 동일한 연락처 ID가 여러 번 사용되었습니다.

해당 레코드는 하이퍼클래스에서 업데이트되거나 연결되지 않았어요.

해당 연락처 ID를 가진 행이 하나만 남도록 가져오기 파일을 수정하세요. 하이퍼클래스에 반영하고 싶은 가장 최신 정보가 담긴 행만 남기세요. 중복을 제거한 후 파일을 다시 가져오세요.

**기타**

**1013 - 전화번호를 처리할 수 없음**

가져오기 파일에 숫자가 아닌 문자가 포함되거나 E.164 형식에 맞지 않는 번호 속성 값이 포함되어 있습니다.

해당 레코드는 가져와졌지만 번호 속성에는 값이 없습니다.

가져오기 파일의 값을 올바른 숫자 값으로 수정하고 다시 가져오거나, 해당 레코드의 속성 값을 직접 수정하세요.

레코드가 숫자 필드와 일치해야 하는 경우, 여러 체크박스 속성에 데이터를 올바르게 가져오도록 파일을 형식화하는 방법을 확인해보세요 - [자세히 알아보기](troubleshooting-bulk-imports-via-csv.md/preview#:~:text=yes%20or%20no%20)-,Phone%20Number,-For%20the%20vast)

**1014 - 날짜를 처리할 수 없음**

가져오기 파일에 가져오기 과정에서 선택한 형식과 일치하지 않는 날짜 값이 포함되어 있습니다.

해당 레코드는 가져와졌지만 날짜 속성에는 값이 없습니다.

가져오기 파일의 값을 올바르게 수정하고 다시 가져오거나, 해당 레코드의 속성 값을 직접 수정하세요.

레코드가 날짜 필드와 일치해야 하는 경우, 여러 체크박스 속성에 데이터를 올바르게 가져오도록 파일을 형식화하는 방법을 확인해보세요 - [자세히 알아보기](troubleshooting-bulk-imports-via-csv.md/preview#:~:text=the%20following%20columns%3A-,Date%20Picker,-Acceptable%20formats%2D)

**1015 - 담당자(Owner)를 찾을 수 없음**

가져오기 파일에 하이퍼클래스의 사용자와 일치하지 않는 레코드 담당자가 포함되어 있습니다.

해당 레코드는 가져와졌지만 Owner 필드에는 값이 없습니다.

가져오기 파일의 Owner 열에 계정 내 사용자의 이름(First/Last name) 또는 이메일을 정확히 입력하세요. 배정하려는 사람이 아직 계정의 사용자가 아니라면, 먼저 사용자로 추가한 후 계정에 표시된 이름 또는 이메일로 다시 가져오세요.

레코드가 연락처 담당자와 일치해야 하는 경우, 여러 체크박스 속성에 데이터를 올바르게 가져오도록 파일을 형식화하는 방법을 확인해보세요 - [자세히 알아보기](troubleshooting-bulk-imports-via-csv.md/preview#:~:text=Not%20Supported-,Contact%20Owner,-To%20assign%20an)

**1016 - HL 내 모호한 열거형 옵션**

동일한 레코드가 열거형 속성에 정의된 기존 옵션 중 하나 이상과 일치합니다. 이는 다중 선택, 드롭다운 선택, 단일 선택, 체크박스 유형 속성에 적용됩니다.

해당 레코드는 가져와졌지만 열거형 속성에는 값이 없습니다.

가져오기 파일과 하이퍼클래스의 속성을 비교하여 잘못된 값을 확인하세요. 가져오기 파일의 값을 기존 옵션 중 하나에만 일치하도록 수정한 후 다시 가져오세요. 또는 해당 레코드의 속성 값을 직접 수정할 수도 있습니다.

레코드가 여러 옵션과 일치해야 하는 경우, 여러 체크박스 속성에 데이터를 올바르게 가져오도록 파일을 형식화하는 방법을 확인해보세요 - [자세히 알아보기](troubleshooting-bulk-imports-via-csv.md/preview#:~:text=Multiple%20Options%2C%20Checkbox%2C%20Textbox%20List)

**1017** - 로케이션(Location)이 중복 연락처를 허용하지 않음 - 1010 및 1011 참고

**1018** - CustomField(커스텀 필드)가 지원되지 않음 -> 매핑 시점에 유효성 검사 - 파일 및 서명

**1019** - 잘못된 커스텀 필드 값 -> 1005 참고

**1020** - 연락처 생성 실패

**1021** - 이메일, 전화번호, First name, Last name, type이 생성되지 않음

**1022** - 연락처를 찾을 수 없음

**1023** - 연락처 업데이트 실패

**1024** - 캠페인/워크플로우 추가 실패

## 자주 묻는 질문

**Q: 어떤 파일 형식을 업로드해야 하나요?**

.csv 파일만 지원됩니다. Excel이나 Google Sheets에서 작업 중이라면 먼저 CSV 파일로 내보내기(Export) 하세요.

**Q: 일괄 가져오기를 취소(undo)할 수 있나요?**

직접적인 "취소" 기능은 없지만, 업로드 시 가져온 연락처에 태그를 붙여둘 수 있어요. 필요하면 그 태그로 필터링해서 삭제할 수 있습니다.

**Q: 가져오기 최대 파일 크기는 얼마인가요?**

20MB 또는 10,000행 중 먼저 도달하는 쪽이 한도입니다.

**Q: 업로드 전에 전화번호 형식을 어떻게 검증할 수 있나요?**

스프레드시트 수식이나 온라인 도구를 사용해서 E.164 형식을 따르는지 확인하세요.

**Q: 기본 열(Primary Column)로는 무엇을 선택해야 하나요?**

여러 연락처에서 중복되지 않는 고유 식별자, 예를 들어 이메일이나 연락처 ID를 사용하세요.

**Q. CSV 리스트가 섞여 있어요. 일부 연락처는 이메일 또는 전화번호만 있고, 일부는 둘 다 있어요. 어떻게 해야 하나요?**

혼합된 CSV의 경우 '2차 우선순위(secondary preference)' 옵션을 사용하세요. 시스템이 먼저 1차 우선순위 필드를 검색하고, 없으면 2차 필드를 검색합니다. 위 예시에서는 1차 우선순위가 '이메일', 2차가 '전화번호'입니다.

이제 2차 필드를 기준으로 기존 연락처를 찾을 수 있어서, 연락처 레코드에 전화번호만 있어도 업로드할 수 있어요!

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045601330/original/4zlCOqVjoq6LY8PnLxg6pZjqPyAfvDWsNg.png?1745499014)

**Q. 일부 연락처에 이메일이나 전화번호가 여러 개 있어요. 어떻게 해야 하나요?**

한 연락처에 여러 개의 전화번호나 이메일이 있는 경우, 업로드가 가능하도록 연락처를 여러 개로 분리하세요. 예시:

**전화번호 열이 두 개인 원본:**

Josephine

810-292 9388

810-374-9840

josephine_darakjy@darakjy.org

**업로드용으로 정리된 버전:**

Josephine

810-292-9388

josephine_darakjy@darakjy.org

Josephine

810-374-9840

두 번째 리드(다른 전화번호를 가진)는 이메일을 비워두세요. 전화번호를 고유 필드로 사용하여 연락처를 업로드할 때 이메일까지 채우면 중복이 생성됩니다.

**Q. Keap을 사용하는 분들을 위한 중요 참고사항:**

Keap에서 내보낸 CSV의 전화번호 필드는 하이퍼클래스와 호환되지 않습니다. 괄호 '()'와 하이픈 '-' 때문에 호환되지 않아요. CSV 파일에서 해당 열 전체를 선택하고 숫자로만 구성되도록 하여, 괄호와 하이픈을 제거해야 CRM의 데이터가 손상되지 않고 가져올 수 있습니다.

**Q. 전화번호를 가져올 때 1007 '잘못된 필수 속성' 오류가 발생해요:**

하위 계정(Sub-account)의 국가 밖에 있는 번호를 가져올 때는 국가 코드를 추가해야 합니다. 하위 계정의 국가가 미국(US)으로 설정된 경우, 가져오는 전화번호에 +1(미국 국가 코드)을 추가할 필요가 없어요. 하지만 미국 이외의 번호를 가져오는 경우에는 [국가 코드](https://countrycode.org/)를 추가해야 합니다. 예를 들어, 비즈니스 위치를 미국으로 설정한 하위 계정이 영국으로 전화를 걸려면 '+44'를 추가해야 합니다. 반대로 하위 계정의 국가가 미국이 아닌 다른 국가(예: 영국, 호주 등)로 설정된 경우, 미국 번호로 전화/SMS를 보내려면 CSV 파일 내 국가의 지역 번호 앞에 '+1'을 추가해야 합니다.

**Q. DND 열이 있는 CSV를 가져오려는데, 모든 연락처가 전체 채널에 대해 DND로 설정돼요.**

CSV 내에 DND 열이 있는 연락처를 가져올 경우, 해당 연락처는 **모든** 채널에 대해 DND로 설정된다는 점을 참고하세요. 특정 채널만 DND로 설정하려면, 먼저 워크플로우를 만들고 각 채널별 태그를 사용하세요.

예를 들어, John을 SMS만 DND로 설정하고 싶다면, 'DND SMS' 태그가 추가되면 연락처를 DND로 설정하는 워크플로우를 만드세요. 그런 다음 CSV에서 John의 이름 옆에 'DND SMS' 태그를 추가하면, 가져오는 과정에서 자동화가 실행되어 John을 SMS만 DND로 설정하게 됩니다.

**Q. 노트(Notes)가 포함된 CSV를 가져오려는데, 연락처 레코드당 노트를 하나 이상 생성할 수 없어요.**

연락처 노트를 가져올 때는 연락처 레코드당 노트 하나만 가능하며, 최대 5,000자로 제한됩니다. 노트가 여러 개 필요하거나 허용된 글자 수보다 많은 경우 [대용량 텍스트 커스텀 필드(large text custom field)](https://hyperclass.gitbook.io/hyperclass-docs)를 사용하세요.

**Q. 노트가 포함된 CSV를 내보내려고 해요.**

현재 노트에 대한 CSV 가져오기 제한은 없으며, 현재 내보내기 방식에 따라 마지막 노트에 대해 최대 255자까지 지원됩니다.
