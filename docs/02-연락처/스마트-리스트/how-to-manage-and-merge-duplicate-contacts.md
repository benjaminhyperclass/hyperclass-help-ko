# 중복 연락처 관리하고 병합하기

중복 연락처가 있으면 CRM이 지저분해지고, 대화 기록이 나뉘고, 리포트도 부정확해져요. 하이퍼클래스에서는 병합할 연락처를 직접 선택하거나, **중복 관리**로 이메일·전화번호·이름이 같은 후보를 찾아서 병합할 수 있어요. 이 문서에서는 중복 레코드를 검토하고, 마스터 연락처를 고르고, 안전하게 병합하는 방법을 안내해요.

## 중복 연락처 관리와 병합이란?

중복 연락처를 관리하고 병합하면, 한 사람당 정확한 연락처 프로필을 하나만 유지할 수 있어요. 중복 레코드가 있으면 하나의 마스터 레코드로 합칠 수 있어요. 합치기 전에 이메일, 전화번호, 회사명, 태그, 대화 같은 주요 정보를 검토해요.

마스터 레코드는 병합 후에 남는 연락처 프로필이에요. 중복 레코드의 일부 정보는 유지되거나 합쳐질 수 있어요. 값이 서로 다른 필드는 검토 단계에서 다른 값을 고르지 않으면 선택한 마스터 레코드의 값이 기본으로 적용돼요.

## 이럴 때 좋아요

- 깔끔한 CRM 데이터: 연락처마다 정확한 프로필 하나만 남길 수 있어요.
- 더 나은 커뮤니케이션 기록: 관련된 대화, 메모, 작업, 기회, 태그를 하나의 연락처 레코드로 모아요.
- 더 정확한 리포팅: 연락처 수, 캠페인 결과, 파이프라인 현황이 왜곡될 수 있는 중복 레코드를 줄여요.
- 빠른 연락처 관리: 검색이나 **중복 관리**로 중복 의심 레코드를 빠르게 찾아 검토할 수 있어요.
- 팀 협업 개선: 팀원들이 중복 레코드로 나뉘지 않고 같은 연락처 프로필에서 작업할 수 있어요.

## 권장 사항

- 주기적으로 중복 검사를 실행해 CRM을 깨끗하게 유지하세요.
- 병합하기 전에 값이 충돌하는 필드를 꼭 검토하세요.
- **거절**은 중복이 아니라고 확신할 때만 사용하세요.
- 앞으로 중복이 생기지 않도록 팀에서 데이터 입력 방식을 통일하세요.

## 병합하면 어떤 정보가 남나요?

병합할 때 연락처 정보 종류마다 처리 방식이 달라요. 마스터 연락처를 선택하고 병합을 확정하기 전에, 하이퍼클래스가 정보를 어떻게 유지하거나 합치는지 확인하세요.

| 정보 또는 동작 | 병합할 때 일어나는 일 |
| --- | --- |
| 마스터 연락처 | 마스터로 선택한 연락처가 병합 후에 남아요. 해당하는 경우 마스터 연락처에 있던 값은 기본으로 유지돼요. |
| 예약, 결제, 주문, 인보이스 | 마스터 연락처의 값이 기본으로 적용돼요. |
| 커스텀 필드 | 마스터 연락처의 해당 커스텀 필드가 비어 있을 때만 선택한 다른 연락처의 값이 추가돼요. 마스터 연락처에 이미 있는 커스텀 필드 값은 덮어쓰지 않아요. |
| 워크플로우 | 진행 중인 워크플로우 실행이 마스터 연락처로 넘어갈 수 있어요. 마스터 연락처가 이미 같은 워크플로우를 실행 중이면 기존 실행은 유지되고 추가 실행은 종료될 수 있어요. 대기 단계, 목표, 재진입 설정, 원래 연락처에 연결된 액션도 병합 후 동작에 영향을 줄 수 있어요. |
| 병합 되돌리기 | 완료된 연락처 병합은 되돌릴 수 없어요. |

{% hint style="warning" %}
연락처 병합은 영구적이에요. 병합을 확정하기 전에 마스터 연락처를 제대로 선택했는지 확인하세요. 영향을 받는 커스텀 필드, 예약, 결제, 주문, 인보이스, 진행 중인 워크플로우 동작도 함께 검토하세요.
{% endhint %}

## 연락처 목록에서 직접 병합하기

어떤 연락처가 중복인지 이미 알고 있을 때 쓰기 좋은 방법이에요. 연락처를 검색해서 목록에서 선택한 뒤 하나의 프로필로 병합해요.

1. **연락처 > 스마트 리스트**로 이동하세요.

   ![연락처 스마트 리스트 화면](https://jumpshare.com/share/9Yl5yALsVeYENd0iWjiA+/Screen+Shot+2026-06-04+at+19.22.16.png)
2. **연락처 검색** 입력란에서 중복 가능성이 있는 연락처를 찾으세요.
3. 다음과 같은 연락처 정보로 검색할 수 있어요.

   - 이름
   - 이메일
   - 회사명
   - 태그
   - 전화번호
4. 스마트 리스트에서 직접 찾아봐도 돼요.

   ![스마트 리스트에서 연락처 찾기](https://jumpshare.com/share/tODLhMrag9LgoSpqhYF9+/Screenshot+2026-06-04+at+19.23.26.png)
5. 병합할 연락처를 선택하세요.
6. 상단 작업 바에서 **더보기**를 클릭하세요.
7. **병합**을 선택하세요.

   ![더보기 메뉴에서 병합 선택](https://jumpshare.com/share/ieBHCmiG09LqDpSyuLwz+/Screen+Shot+2026-06-04+at+19.26.04.png)
8. **연락처 병합** 창에서 **마스터** 레코드로 남길 연락처를 선택하세요.
9. 값이 서로 다른 필드를 검토하세요.

   ![값이 다른 필드 검토 화면](https://jumpshare.com/share/HQw3aT0cqhH1Q8BwtBme+/Screen+Shot+2026-06-04+at+19.28.53.png)
10. 전체 필드를 검토하고, 대표 이메일·전화번호·회사명 등 남길 값을 선택하세요.
11. **연락처 병합**을 클릭하세요.

    ![연락처 병합 진행 과정](https://jumpshare.com/share/v5IFn7l6LNf0aki3FxAM+/GIF+Recording+2026-06-04+at+19.30.42.gif)

## 중복 관리로 연락처 병합하기

### 권한과 제한

| 역할 | 권한 |
| --- | --- |
| **에이전시 관리자** / 서브 계정 관리자 | ✅ 중복 찾기와 병합을 모두 사용할 수 있어요 |
| 팀원 / **사용자** | ❌ 사용할 수 없어요 |

### 1단계: 중복 관리 도구 열기

{% hint style="info" %}
관리자만 이 기능을 쓸 수 있어요. 기존 연락처 목록 보기와 새 연락처 목록 보기 모두에서 사용할 수 있어요.
{% endhint %}

1. 서브 계정에서 **연락처**를 클릭하세요.
2. **⋮**(점 세 개 메뉴)를 클릭하세요.
3. **중복 관리** 옵션을 클릭하세요.

   ![중복 관리 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924115/original/09VnSPThTKB8T5UIENbe-DCOOGSy93Zlaw.jpeg?1780583351)

### 2단계: 중복 찾기

1. **Find By**(검색 기준)에서 기준을 선택하세요.

   - **이메일** (기본값으로 권장해요)
   - **전화번호**
   - **이름**
2. **Find Duplicates**(중복 찾기)를 클릭하세요.
3. 연락처 데이터베이스 검사가 시작되고, 선택한 기준에 맞는 중복이 표시돼요.

   ![중복 검사 결과 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924133/original/lWhEHNVgJFHO8saa0wUK0lUKXPnnwHzbCA.jpeg?1780583353)

### 3단계: 중복 레코드 확인하기

- 중복이 발견되면 중복 후보 그룹 목록이 표시돼요.

  ![중복 후보 그룹 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924140/original/fRsRVkLVdZDNOPGuA27_o7CU-pq3v7YnXg.jpeg?1780583355)
- 그룹 옆의 **아래쪽 화살표**를 클릭하면 그룹이 펼쳐져요.

  ![그룹 옆 아래쪽 화살표](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924145/original/ZNvyKcjHWNoDkDN-etQ1aT7qF6p0s0e0cA.jpeg?1780583355)
- 그룹을 펼치면 감지된 연락처를 모두 볼 수 있어요.

  ![펼쳐진 중복 그룹](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924396/original/GXlp2-A1ZwsTHn6SyfnmeRQgrX4DwsTaug.jpeg?1780583453)

### 4단계: 충돌 검토하고 해결하기

1. **리뷰**를 클릭하면 변경 내용을 더 자세히 검토할 수 있어요.
2. 전화번호, 태그, 국가처럼 값이 충돌하는 필드가 나란히 표시돼요.
3. 다음과 같이 할 수 있어요.

   - 필드마다 남길 값을 선택해요.
   - 여러 태그나 추가 정보를 합쳐요.
   - 대표 이메일이나 전화번호를 선택해요.
   - 중복된 기회가 생기지 않도록 확인해요.
4. 검토가 끝나면 **연락처 병합**을 클릭해 진행하세요.

![충돌 검토 후 병합하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924748/original/BC34BVV-xVWFuXbbLE8EyeR2QdP4tG0xXw.gif?1780583667)

### 5단계: 중복 거절하기

병합하면 안 되는 중복이 있다면 다음과 같이 하세요.

1. **거절**을 클릭하세요.
2. 팝업에서 거절을 확인하세요.

   - “이 이메일 주소는 앞으로 중복 검색에 사용되지 않습니다.”
   - 이 작업은 되돌릴 수 없어요.

{% hint style="info" %}
거절한 이메일, 전화번호, 이름은 이후 중복 검사에서 제외돼요.
{% endhint %}

![중복 거절 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924830/original/aUku3g082b9T4p_4K1uZBLLgL8GzIMOUeg.gif?1780583706)

### 6단계: 병합할 레코드 선택하기

{% hint style="info" %}
병합한 뒤에는 되돌릴 수 없어요. 확정하기 전에 꼼꼼히 검토하세요.
{% endhint %}

1. 한 번에 최대 10개의 레코드를 선택해 병합할 수 있어요.

   - 한도에 도달하면 **한도 도달** 10/10 안내가 표시돼요.
2. 레코드 하나를 **마스터**로 선택하세요. 이 레코드가 이름, 대표 이메일, 대표 전화번호 같은 주요 정보를 유지해요.
3. 나머지 레코드의 관련 데이터(작업, 기회, 메모, 상품 등)는 모두 이 마스터 레코드로 합쳐져요.
4. **병합**을 클릭하세요. 병합하기 전에 확인 창이 나타나요.

   확인 창에는 다음 내용이 표시돼요.

   - 이 작업은 되돌릴 수 없다는 안내
   - 선택한 모든 레코드의 이메일, 전화번호, 메모, 기회, 작업이 하나로 합쳐진다는 안내
   - 확인 체크박스를 선택해 내용을 이해했음을 알리는 옵션
5. **Merge Duplicates**(중복 병합)를 클릭해 마무리하세요.

![병합 확정 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072925029/original/HWZzeX5fbkOqjnGmjRoDVIck8-Vi1M-NOw.gif?1780583774)

## 연락처 중복 방지 설정

처음부터 중복 연락처를 막으면 나중에 드는 시간과 혼란을 크게 줄일 수 있어요. 연락처 중복 방지 설정에서는 새 연락처가 들어올 때 시스템이 어떻게 처리할지 정할 수 있어요. 중복이 생기기 전에 미리 막을 수 있어요.

1. **설정 > 비즈니스 프로필 > Contact Preferences**(연락처 환경설정)로 이동하세요.
2. **Allow Duplicate Contacts**(중복 연락처 허용)를 켜거나 끄세요.
3. 1차·2차 중복 확인 필드(**이메일** 또는 **전화번호**)를 선택하세요.

![연락처 중복 방지 설정 화면](https://jumpshare.com/share/SlH89EX2ym68axA4XQS6+/pref.png)

## 문제 해결

| 증상 | 가능한 원인 | 해결 방법 |
| --- | --- | --- |
| “중복 항목 없음” | 검색 기준이 한정적이에요 | 다른 기준(전화번호 또는 이름)으로 바꿔 보세요. |
| “한도 도달 (10/10)” | 선택한 레코드가 너무 많아요 | 먼저 10개를 병합한 뒤 돌아와서 다음 묶음을 병합하세요. |
| 병합 버튼이 비활성화돼요 | 확인 체크박스를 선택하지 않았어요 | “I understand this cannot be undone”(되돌릴 수 없음을 이해해요) 체크박스를 선택하세요. |
| 병합 옵션이 보이지 않아요 | 관리자 역할이 아니에요 | 관리자에게 권한을 요청하세요. |

## 자주 묻는 질문

### 연락처 병합을 되돌릴 수 있나요?
아니요. 연락처 병합은 되돌릴 수 없어요. 확정하기 전에 선택한 연락처, 마스터 레코드, 필드 값을 꼼꼼히 검토하세요.

### 한 번에 몇 개까지 병합할 수 있나요?
한 번에 최대 10개까지 병합할 수 있어요.

### 직접 병합과 중복 관리는 뭐가 다른가요?
직접 병합은 어떤 연락처를 병합할지 이미 알 때 써요. **중복 관리**는 이메일, 전화번호, 이름을 기준으로 중복 가능성이 있는 레코드를 찾아 줘요.

### **연락처 병합** 버튼이 안 보여요.
**연락처 병합** 옵션은 유효한 연락처를 2개 이상, 최대 10개까지 선택해야 나타나요. 다음 사항을 확인해 보세요.

- 연락처를 관리할 수 있는 권한이 있는지
- 선택한 연락처가 같은 서브 계정에 있는지
- 선택한 연락처가 현재 목록 보기에 표시되어 있는지

### 하이퍼클래스에서 중복 연락처는 왜 생기나요?
직접 입력, CSV 가져오기, 폼, 캘린더 제출, Zapier 같은 외부 도구를 통해 중복이 생길 수 있어요.

### 어떤 연락처를 마스터 레코드로 선택해야 하나요?
가장 정확하고 최신 정보를 가진 연락처를 선택하세요. 마스터 레코드는 병합 후에도 남으므로, 가장 신뢰하는 정보가 들어 있어야 해요.

### 병합하면 필드 데이터는 어떻게 되나요?
선택한 마스터 레코드는 기존 정보를 유지해요. 다른 레코드에만 있는 정보는 추가되거나 합쳐질 수 있어요. 값이 충돌하는 필드는 사용자가 선택한 값이나 마스터 레코드의 값이 적용돼요.

### 병합할 때 커스텀 필드도 영향을 받나요?
다른 연락처의 커스텀 필드 값은 마스터 레코드의 같은 필드가 비어 있을 때만 추가돼요. 마스터 레코드에 이미 있는 커스텀 필드 값은 덮어쓰지 않아요.

### 병합하면 메모, 대화, 태그, 예약, 결제, 주문, 인보이스, 코스, 커뮤니티 그룹, 상품은 어떻게 되나요?
선택한 정보가 마스터 연락처로 합쳐져요. 예약, 결제, 주문, 인보이스를 포함해 나머지 필드는 마스터 레코드의 값이 기본으로 적용돼요. 코스, 커뮤니티 그룹, 상품은 선택한 모든 레코드의 정보가 합쳐져요.

### 중복 후보를 거절하면 어떻게 되나요?
거절한 후보는 해당 중복 매칭 규칙에서 다시 나타나지 않아요. 이 작업은 되돌릴 수 없어요.

### 폼이나 캘린더 제출로 중복이 생기지 않게 하려면 어떻게 하나요?
연락처 중복 방지 설정을 확인하세요. 일치하는 제출로 중복 연락처가 만들어지는 것을 원하지 않는다면 **Allow Duplicate Contacts**를 꺼 두세요.

### 중복을 병합하면 연락처의 워크플로우는 어떻게 되나요?
병합 중에 중복 연락처가 삭제되면, 하이퍼클래스가 워크플로우 실행을 마스터 연락처로 넘겨서 자동화가 계속 이어지게 해요. 마스터 연락처가 이미 같은 워크플로우에 등록되어 있으면, 추가 실행은 중단하고 이미 진행 중인 워크플로우 실행을 유지해요.

### 중복 연락처를 자동으로 병합할 수 있나요?
네. 워크플로우 안에서 중복 연락처를 병합하고 싶다면 **Merge Contact**(연락처 병합) 액션을 사용하세요.
