# 중복 연락처 관리 및 합치기 방법

중복 연락처는 CRM을 지저분하게 만들고, 대화 기록을 분산시키며, 리포트의 정확도를 떨어뜨릴 수 있어요. 하이퍼클래스는 중복 연락처를 관리하는 두 가지 방법을 제공합니다: 합칠 연락처를 직접 선택하는 방법과, 이메일·전화번호·이름으로 잠재적 중복 항목을 찾아주는 중복 관리(Manage Duplicates) 도구를 사용하는 방법이에요. 이 아티클에서는 중복 레코드를 검토하고, 올바른 마스터 연락처를 선택하며, 안전하게 레코드를 합치는 방법을 안내해 드려요.

# 중복 연락처 관리 및 합치기란?

중복 연락처 관리 및 합치기는 CRM 안에서 한 사람당 정확한 연락처 프로필 하나만 유지할 수 있도록 도와주는 기능이에요. 중복 레코드가 존재하는 경우, 이메일, 전화번호, 회사명, 태그, 대화 내역 등 주요 정보를 검토하면서 이를 하나의 마스터 레코드로 합칠 수 있어요.

마스터 레코드란 합치기(병합) 이후에 남게 되는 연락처 프로필을 말해요. 중복 레코드의 일부 정보는 유지되거나 통합될 수 있고, 검토 과정에서 다른 값을 선택하지 않는 한 충돌하는 항목은 선택한 마스터 레코드의 값을 기본값으로 사용해요.

## 중복 연락처 관리 및 합치기의 주요 이점

- **더 깔끔한 CRM 데이터**: 여러 개의 중복 레코드 대신 각 연락처마다 정확한 프로필 하나만 유지할 수 있어요.

- **더 나은 대화 기록**: 관련된 대화, 노트, 할 일, 기회, 태그를 하나의 연락처 상세(레코드)로 통합해요.

- **더 정확한 리포팅**: 연락처 수, 캠페인 결과, 파이프라인 현황을 왜곡시킬 수 있는 중복 레코드를 줄여줘요.

- **더 빠른 연락처 관리**: 검색 또는 중복 관리 도구를 사용해 중복 가능성이 있는 레코드를 빠르게 찾고 검토할 수 있어요.

- **팀 가시성 향상**: 팀원들이 중복된 연락처마다 따로 업데이트하지 않고, 같은 연락처 프로필을 기준으로 작업할 수 있도록 도와줘요.

## 모범 사례

- CRM을 깔끔하게 유지하려면 주기적으로 중복 검사를 실행하세요.
- 합치기 전에는 항상 필드 충돌을 검토하세요.
- 거부(Reject) 옵션은 해당 레코드가 중복이 아니라고 확신할 때만 사용하세요.
- 향후 중복 발생을 방지하기 위해 팀 내에서 데이터 입력 방식을 표준화하도록 권장하세요.

## 연락처 목록에서 수동으로 합치는 방법

수동 합치기는 어떤 연락처 레코드가 중복인지 이미 알고 있을 때 유용해요. 해당 레코드를 검색해서 연락처(Contacts) 테이블에서 선택한 뒤, 하나의 프로필로 합칠 수 있어요.

- 연락처(Contacts) → 스마트 리스트(Smart Lists)로 이동하세요.

![](https://jumpshare.com/share/9Yl5yALsVeYENd0iWjiA+/Screen+Shot+2026-06-04+at+19.22.16.png)

- 연락처 검색(Search Contacts) 박스를 사용해 중복 가능성이 있는 연락처를 찾으세요.
- 다음과 같은 사용 가능한 연락처 정보로 검색할 수 있어요:

이름
- 이메일
- 회사명
- 태그
- 전화번호

- 스마트 리스트에서 직접 수동으로 검색할 수도 있어요.

![](https://jumpshare.com/share/tODLhMrag9LgoSpqhYF9+/Screenshot+2026-06-04+at+19.23.26.png)

- 합치려는 **연락처**를 선택하세요.
- 상단 액션 바에서 더보기(More)를 클릭하세요.
- 합치기(Merge)를 선택하세요.

![](https://jumpshare.com/share/ieBHCmiG09LqDpSyuLwz+/Screen+Shot+2026-06-04+at+19.26.04.png)

- 연락처 합치기(Merge Contacts) 창에서 마스터 레코드로 남을 연락처를 선택하세요.
- 서로 다른 **값**을 가진 **필드**를 검토하세요.

![](https://jumpshare.com/share/HQw3aT0cqhH1Q8BwtBme+/Screen+Shot+2026-06-04+at+19.28.53.png)

- 전체 필드(All Fields)를 검토하고, 대표 이메일, 전화번호, 회사명 등 유지하고 싶은 값을 선택하세요.
- 연락처 합치기(Merge Contacts)를 클릭하세요.

![](https://jumpshare.com/share/v5IFn7l6LNf0aki3FxAM+/GIF+Recording+2026-06-04+at+19.30.42.gif)

## 중복 관리 도구를 사용해 연락처 합치는 방법

### 권한 및 제한 사항

| 역할 | 접근 권한 |
|---|---|
| 에이전시 관리자 / 하위 계정 관리자 | ✅ 중복 찾기 및 합치기 전체 접근 가능 |
| 팀원 / 일반 사용자 | ❌ 접근 불가 |

### 1단계: 중복 관리 도구 접근하기

참고: 이 기능은 **관리자(Admin)**만 사용할 수 있으며, **클래식 뷰**와 **새로운 연락처 목록 보기(Contacts List View)** 모두에서 작동해요.

- 하위 계정에서 연락처(Contacts)를 클릭하세요.
- ⋮ (점 세 개 메뉴)를 클릭하세요.
- 중복 관리(Manage Duplicates) 옵션을 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924115/original/09VnSPThTKB8T5UIENbe-DCOOGSy93Zlaw.jpeg?1780583351)

### 2단계: 중복 항목 찾기

- 검색 기준(Find By)을 선택하세요:

이메일 (기본 권장)
- 전화번호
- 이름

- 중복 찾기(Find Duplicates)를 클릭하세요.
- 시스템이 연락처 데이터베이스를 스캔하기 시작하며, 선택한 항목 기준으로 일치하는 중복 항목을 표시해요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924133/original/lWhEHNVgJFHO8saa0wUK0lUKXPnnwHzbCA.jpeg?1780583353)

### 3단계: 중복 레코드 확인하기

- 중복 항목이 발견되면, 잠재적 중복 그룹 목록이 표시돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924140/original/fRsRVkLVdZDNOPGuA27_o7CU-pq3v7YnXg.jpeg?1780583355)

- 그룹 옆의 아래쪽 화살표를 클릭해 펼치세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924145/original/ZNvyKcjHWNoDkDN-etQ1aT7qF6p0s0e0cA.jpeg?1780583355)

- 그룹을 펼쳐서 감지된 모든 연락처를 확인할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924396/original/GXlp2-A1ZwsTHn6SyfnmeRQgrX4DwsTaug.jpeg?1780583453)

### 4단계: 충돌 검토 및 해결하기

- 검토(Review)를 클릭하면 변경 사항을 더 자세히 확인할 수도 있어요.
- 전화번호, 태그, 국가 등 충돌하는 필드는 나란히 표시돼요.
- 다음과 같은 작업이 가능해요:

각 필드마다 유지할 값을 선택할 수 있어요.
- 여러 태그나 추가 정보를 결합할 수 있어요.
- 대표 이메일 또는 전화번호를 선택할 수 있어요.
- 중복 기회(Opportunity)가 생성되지 않도록 확인할 수 있어요.

- 검토가 끝나면 연락처 합치기(Merge Contacts)를 클릭해 진행하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924748/original/BC34BVV-xVWFuXbbLE8EyeR2QdP4tG0xXw.gif?1780583667)

### 5단계: 중복 항목 거부하기

특정 중복 항목을 합치면 안 된다고 판단되는 경우:

- 거부(Reject)를 클릭하세요.
- 팝업에서 거부를 확인하세요:

"이 이메일 주소는 이후 중복 검색에서 다시 사용되지 않습니다."

- 이 작업은 되돌릴 수 없어요.

참고: 거부된 이메일, 전화번호, 이름은 이후의 중복 검색에서 제외돼요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072924830/original/aUku3g082b9T4p_4K1uZBLLgL8GzIMOUeg.gif?1780583706)

### 6단계: 합칠 레코드 선택하기

참고: 한 번 합치면 되돌릴 수 없어요. 확정하기 전에 신중하게 검토하세요.

- 한 번에 최대 10개의 레코드까지 선택해서 합칠 수 있어요.
- 제한에 도달하면 도구에서 알림을 표시해요 (Limit reached 10/10).
- 마스터로 지정할 레코드 하나를 선택하세요 — 이 레코드가 이름, 대표 이메일, 대표 전화번호 등 주요 정보를 유지하게 돼요.
- 다른 레코드의 관련 데이터(할 일, 기회, 노트, 상품 등)는 모두 이 마스터 레코드로 통합돼요.
- 합치기(Merge)를 클릭하세요. 합치기 전에 확인 대화상자가 표시돼요:

다음과 같은 내용을 확인하게 돼요:

이 작업은 되돌릴 수 없다는 안내.
- 선택한 모든 레코드의 이메일, 전화번호, 노트, 기회, 할 일이 하나로 합쳐진다는 안내.
- 확인 체크박스를 체크하여 내용을 이해했음을 확인하는 옵션.

- 중복 합치기(Merge Duplicates)를 클릭해 마무리하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072925029/original/HWZzeX5fbkOqjnGmjRoDVIck8-Vi1M-NOw.gif?1780583774)

## 연락처 중복 제거 환경설정

애초에 중복 연락처가 생기지 않도록 방지하면, 이후 발생할 수 있는 시간 낭비와 혼란을 크게 줄일 수 있어요. 연락처 중복 제거 설정(Contact Deduplication Settings)을 사용하면 새로운 연락처가 등록될 때 시스템이 어떻게 처리할지 제어할 수 있어, 중복이 발생하기 전에 미리 막을 수 있어요.

- 설정(Settings) → 비즈니스 프로필(Business Profile) → 연락처 환경설정(Contact Preferences)으로 이동하세요.
- 중복 연락처 허용(Allow Duplicate Contacts)을 활성화하거나 비활성화하세요.
- 주요 및 보조 중복 제거 필드(이메일 또는 전화번호)를 선택하세요.

![](https://jumpshare.com/share/SlH89EX2ym68axA4XQS6+/pref.png)

## 문제 해결

| 문제 | 발생 가능한 원인 | 해결 방법 |
|---|---|---|
| "중복 항목을 찾을 수 없음" | 검색 기준이 제한적임 | 다른 검색 기준(전화번호 또는 이름)으로 전환해 보세요. |
| "제한 도달 (10/10)" | 너무 많은 레코드를 선택함 | 먼저 10개를 합친 뒤, 돌아와서 다음 세트를 합치세요. |
| "합치기 버튼 비활성화됨" | 확인 체크박스 미체크 | "이 작업은 되돌릴 수 없음을 이해합니다" 체크박스를 체크하세요. |
| 합치기 옵션이 안 보임 | 관리자 역할이 아님 | 관리자에게 접근 권한을 요청하세요. |

## 자주 묻는 질문

**Q: 연락처 합치기를 취소할 수 있나요?**
아니요. 연락처 합치기는 취소할 수 없어요. 확정하기 전에 선택한 연락처, 마스터 레코드, 필드 값을 신중하게 검토해 주세요.

**Q: 한 번에 몇 개의 연락처를 합칠 수 있나요?**
한 번에 최대 10개의 연락처까지 합칠 수 있어요.

**Q: 수동 합치기와 중복 관리(Manage Duplicates)의 차이는 무엇인가요?**
수동 합치기는 어떤 연락처를 합쳐야 할지 이미 알고 있을 때 사용해요. 중복 관리는 이메일, 전화번호, 이름 기준으로 중복 가능성이 있는 레코드를 찾아주는 기능이에요.

**Q: 연락처 합치기 버튼이 안 보이는 이유는 무엇인가요?**
연락처 합치기 옵션은 유효한 연락처를 2개 이상, 최대 10개까지 선택했을 때 나타나요. 연락처 관리 권한이 있는지, 선택한 연락처가 동일한 하위 계정에 속해 있는지, 그리고 현재 목록 보기에서 연락처가 표시되고 있는지 확인해 주세요.

**Q: 하이퍼클래스에서 중복 연락처가 생기는 원인은 무엇인가요?**
수동 입력, CSV 가져오기, 폼, 캘린더 제출, 또는 Zapier 같은 서드파티 도구를 통해 중복이 발생할 수 있어요.

**Q: 어떤 연락처를 마스터 레코드로 선택해야 하나요?**
가장 정확하고 최신 정보를 담고 있는 연락처를 선택하세요. 마스터 레코드는 합치기 후에도 남게 되므로, 가장 신뢰할 수 있는 정보를 담고 있어야 해요.

**Q: 합치기 중 필드 데이터는 어떻게 되나요?**
선택한 마스터 레코드는 자신의 정보를 유지해요. 다른 선택된 레코드의 고유한 정보는 추가되거나 통합될 수 있으며, 충돌하는 필드는 선택한 값 또는 마스터 레코드의 값을 사용해요.

**Q: 합치기 중 커스텀 필드에는 영향이 있나요?**
다른 연락처의 커스텀 필드 값은 마스터 레코드의 해당 필드가 비어 있을 때만 추가돼요. 마스터 레코드에 이미 값이 있는 커스텀 필드는 덮어쓰지 않아요.

**Q: 합치기 후 노트, 대화, 태그, 예약, 결제, 주문, 인보이스, 강의, 커뮤니티 그룹, 상품은 어떻게 되나요?**
선택된 정보는 마스터 연락처로 합쳐져요. 예약, 결제, 주문, 인보이스를 포함한 나머지 필드는 마스터 레코드의 값을 기본으로 사용해요. 강의, 커뮤니티 그룹, 상품은 선택된 모든 레코드의 정보를 통합해요.

**Q: 중복 제안을 거부하면 어떻게 되나요?**
거부된 제안은 해당 중복 매칭 규칙에서 다시 나타나지 않아요. 이 작업은 되돌릴 수 없어요.

**Q: 폼이나 캘린더 제출로 인한 중복을 방지하려면 어떻게 하나요?**
연락처 중복 제거 환경설정을 검토하고, 일치하는 제출로 인해 중복 연락처가 생성되는 것을 원하지 않는다면 중복 연락처 허용(Allow Duplicate Contacts)을 꺼주세요.

**Q: 중복 연락처를 합칠 때 워크플로우는 어떻게 되나요?**
합치기 과정에서 중복 연락처가 삭제되면, 하이퍼클래스는 워크플로우 실행을 마스터 연락처로 이전하여 자동화가 계속 진행될 수 있도록 해요. 만약 마스터 연락처가 이미 동일한 워크플로우에 등록되어 있다면, 하이퍼클래스는 추가 실행을 중단하고 이미 실행 중인 워크플로우를 유지해요.

**Q: 중복 연락처를 자동으로 합칠 수 있나요?**
네. 워크플로우 안에서 중복 연락처 합치기를 자동으로 실행하고 싶다면 워크플로우 액션 – 연락처 합치기(Merge Contact)를 사용하세요.
