# 연락처 프로필 사진

연락처에 프로필 사진을 등록하는 방법과, 등록한 사진이 어디에 보이는지 알려 드려요. 프로필 사진을 등록하면 **연락처** 목록과 **대화** 화면에서 누구인지 한눈에 알아보기 쉬워요.

## 프로필 사진 기능이란?

프로필 사진 기능을 쓰면 연락처에 사진이나 로고를 넣을 수 있어요. 등록한 이미지는 그 연락처가 나타나는 곳곳에 표시돼요. 주로 **연락처** 스마트 리스트와 **대화** 인박스에서 볼 수 있어요.

프로필 사진은 현재 **연락처를 새로 만들 때만** 넣을 수 있고, 만든 뒤에는 **바꿀 수 없어요**. 한 번 등록한 이미지는 여러 화면에 표시되어, 팀이 누구와 대화하고 있는지 바로 알아볼 수 있어요.

## 프로필 사진을 쓰면 좋은 점

프로필 사진은 보기 좋게 꾸미는 데서 끝나지 않고, 실제 업무에도 도움이 돼요.

- **연락처**와 **대화** 화면에서 연락처를 빠르게 알아볼 수 있어요.
- 고객과 주고받는 대화에 개인적인 느낌을 더할 수 있어요.
- 중복된 리드를 관리할 때 덜 헷갈려요.
- 팀원이 보는 화면이 더 깔끔하고 전문적으로 보여요.
- 한눈에 알아볼 수 있어서 화면을 오가며 찾기가 쉬워요.
- 상황 파악이 빨라져 팀의 업무 속도가 올라가요.

## 현재 제한 사항

도움이 되는 기능이지만 아직 개선 중이라 다음과 같은 제한이 있어요.

- 연락처를 만든 뒤에는 프로필 사진을 **추가, 변경, 수정할 수 없어요**.
- 연락처 상세 프로필 화면(탭) 안에는 프로필 사진이 **표시되지 않아요**.
- 업로드할 이미지에는 드래그 앤 드롭이나 자르기 도구를 쓸 수 없어요.
- API로는 **아직 지원하지 않아요**.

## 프로필 사진 추가하기

프로필 사진은 **새 연락처를 만들 때만** 추가할 수 있어요. 연락처를 저장한 뒤에는 사진을 바꿀 방법이 아직 없어요.

{% hint style="warning" %}
이미 있는 연락처에 프로필 사진을 넣고 싶다면, 새 연락처를 만들면서 프로필 사진을 추가한 다음 그 새 연락처를 기존 연락처와 병합해야 해요.
{% endhint %}

1. 왼쪽 메뉴에서 **연락처**를 클릭해요.
2. 더하기(➕) 버튼을 클릭해 새 연락처를 추가해요.
3. 연락처 만들기 창에서 **개인 로고**라고 적힌 이미지 영역을 클릭해요.
4. 이미지 파일을 업로드해요. 파일은 2.5MB 이하, 512x512px 크기를 권장해요.
5. 연락처 정보를 입력하고 **저장**을 클릭해요.

![연락처를 만들면서 프로필 사진을 업로드하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045078808/original/97GqJ3UH1TxnPmOimUqQPBq33ZuzlzfoHw.gif?1744660212)

저장하면 업로드한 이미지가 플랫폼 여러 곳에 표시돼요.

{% hint style="warning" %}
프로필 사진은 나중에 수정할 수 없어요. 연락처를 만들 때 이미지를 꼭 함께 업로드하세요.
{% endhint %}

{% hint style="info" %}
원하는 프로필 사진을 넣어 새 연락처를 만든 뒤에는 두 연락처를 병합할 수 있어요. 자세한 방법은 '여러 연락처 병합하기' 문서를 참고하세요.
{% endhint %}

## 연락처 화면에서 프로필 사진 보기

프로필 사진을 넣어 연락처를 만든 뒤 **연락처** 스마트 리스트로 돌아가 보세요. 연락처 이름 옆에 업로드한 이미지가 표시돼요. 로고나 프로필 사진만 보고도 리드를 쉽게 찾을 수 있어요.

![연락처 목록에서 이름 옆에 표시된 프로필 사진](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045077917/original/3FqyJ_Y100x8ArUuFA5MbrBZP8e_bsDI8A.png?1744657915)

## 대화 화면에서 프로필 사진 보기

이미지를 등록한 연락처가 메시지를 보내거나 대화에 나타나면, 이미지가 **왼쪽 대화 목록**의 이름 옆과 **오른쪽 연락처 패널**에 표시돼요. 가운데 대화 패널에는 표시되지 않아요.

![대화 화면의 왼쪽 목록과 오른쪽 패널에 표시된 프로필 사진](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045077842/original/yaVhJDzRTjoDAuqmwagDoqNVlaQ7GQqKhw.png?1744657700)

## 자주 묻는 질문

### 프로필 사진을 나중에 수정하거나 바꿀 수 있나요?
아니요, 지금은 할 수 없어요. 프로필 사진은 새 연락처를 만들 때만 추가할 수 있어요.

### 업로드한 이미지는 어디에 표시되나요?
**연락처** 스마트 리스트, **대화** 인박스, 오른쪽 연락처 패널에 표시돼요.

### 이미 있는 연락처에 사진을 추가할 수 있나요?
아니요. 이미 만들어진 연락처의 프로필 사진을 수정하는 기능은 현재 없어요.

### 이미지 크기와 형식은 어떻게 해야 하나요?
**512x512 픽셀**, **2.5MB 미만**의 JPG 또는 PNG 파일을 권장해요.

### 앞으로 프로필 사진을 수정할 수 있게 되나요?
하이퍼클래스는 연락처 기능을 계속 개선하고 있어요. 이후 업데이트에서 이미지 수정을 지원할 수도 있어요.
