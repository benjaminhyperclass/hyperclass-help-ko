# 연락처와 연락처 데이터 삭제하기

오래된 연락처를 정리하거나 개인정보 삭제 요청을 처리할 때 연락처와 연관 데이터를 삭제하는 방법을 안내해요. 삭제 기능의 동작 방식, 삭제 전에 알아 둘 점, 데이터를 깔끔하게 관리하는 방법, 자주 겪는 문제의 해결법을 함께 다뤄요.

## 삭제 전에 알아 둘 점

- 데이터를 안전하게 지키고 실수로 지우는 일을 막기 위해, 관리자만 연락처를 삭제할 수 있어요.
- 삭제한 연락처는 2개월(60일) 안에 복원할 수 있어요.
- 대화, 메모, 작업 같은 연관 데이터도 함께 삭제될 수 있어요(시스템 설정에 따라 달라져요).

## 권장 사항

- 삭제 전에 다시 확인하기: 실수로 데이터를 잃지 않도록 올바른 연락처를 선택했는지 확인하세요.
- 중요한 데이터 백업하기: 삭제하기 전에 연락처를 CSV 파일로 내보내서 기록으로 보관하세요.
- 정기적으로 정리하기: 연락처 목록을 주기적으로 검토하고 정리해서 데이터를 깔끔하게 유지하세요.
- 권한은 신중하게 부여하기: 삭제 권한은 관리자나 신뢰할 수 있는 팀원에게만 주세요.

{% hint style="warning" %}
연락처를 삭제하기 전에 확인하세요. 연락처를 삭제하면 대화, 메모, 작업, 활동 기록 같은 연관 데이터가 모두 영구적으로 사라져요. 삭제한 연락처를 복원해도 이 연관 데이터는 복구되지 않아요. 삭제하기 전에 중요한 정보를 백업해 두세요.

- 삭제 전에 다시 확인하기: 실수로 데이터를 잃지 않도록 올바른 연락처를 선택했는지 확인하세요.
- 중요한 데이터 백업하기: 삭제하기 전에 연락처를 CSV 파일로 내보내서 기록으로 보관하세요.
{% endhint %}

## 연락처 직접 삭제하기

**1단계**: 연락처 페이지 열기

**연락처** 메뉴로 이동하세요.

**2단계**: 연락처 선택

연락처를 선택하는 방법은 두 가지예요.

- 연락처 목록 머리글의 체크박스를 클릭하면 한 페이지의 연락처 전체(또는 CRM의 모든 연락처)를 선택할 수 있어요.
- 이름 옆의 체크박스를 클릭하면 연락처를 하나씩 선택할 수 있어요.

이름 옆의 체크박스를 눌러 연락처를 하나 이상 선택하세요.

**3단계**: 연락처 삭제

연락처 목록 위쪽의 **삭제** 버튼을 클릭하세요.

{% hint style="info" %}
스마트 리스트 보기를 쓰는데 휴지통(**삭제**) 아이콘이 보이지 않으면, 먼저 연락처를 하나 이상 선택했는지 확인하세요. 삭제 아이콘은 연락처를 선택한 뒤에만 나타나요. 그래도 보이지 않으면 필요한 **관리자 권한**이 없을 수 있어요. 계정 관리자에게 확인하세요.
{% endhint %}

![연락처 목록에서 삭제 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039831887/original/HuDe5zEU0tm6DykpMCq7Drkpq0HOBUquYQ.jpeg?1736883910)

**5단계**: 삭제 확인

확인 입력란에 DELETE를 입력해서 삭제를 확정하세요.

{% hint style="warning" %}
연락처를 삭제하기 전에 확인하세요. 연락처를 삭제하면 대화, 메모, 작업, 활동 기록 같은 연관 데이터가 모두 영구적으로 사라져요. 삭제한 연락처를 복원해도 이 연관 데이터는 복구되지 않아요. 삭제하기 전에 중요한 정보를 백업해 두세요.

- 삭제 전에 다시 확인하기: 실수로 데이터를 잃지 않도록 올바른 연락처를 선택했는지 확인하세요.
- 중요한 데이터 백업하기: 삭제하기 전에 연락처를 CSV 파일로 내보내서 기록으로 보관하세요.
{% endhint %}

## 삭제한 연락처 복원하기

연락처를 실수로 삭제했더라도 2개월(60일) 안에는 복원할 수 있어요.

{% hint style="warning" %}
삭제한 연락처를 복원해도 대화, 메모, 작업 같은 연관 데이터는 복원되지 않아요. 삭제하기 전에 중요한 정보를 백업해 두세요.
{% endhint %}

1. **연락처 > 복원**으로 이동하세요.
2. 복원할 연락처를 선택하세요.
3. **복원**을 클릭하면 연락처가 다시 활성 목록으로 돌아와요.
4. 선택한 내용을 확인해 삭제된 연락처를 **복원**하세요.

![삭제된 연락처를 복원하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039832113/original/_2GdAT-hU_VyiZm1GbybknD992oS05MTlw.png?1736884527)

복원 방법을 더 자세히 알고 싶다면 [삭제된 연락처 복원 단계별 가이드](../연락처-기본/restore-deleted-contacts-or-undo-bulk-deletes.md)를 참고하세요.

## 워크플로우로 연락처 삭제 자동화하기

하이퍼클래스에서는 워크플로우로 연락처 삭제를 자동화할 수 있어요. 구독을 취소했거나 활동이 없거나 유효하지 않은 연락처를 정리할 때 유용해요.

1. **자동화 > 워크플로우**로 이동해 새 워크플로우를 만드세요.
2. 워크플로우에 **Delete Contact**(연락처 삭제) 액션을 추가하면 삭제 과정이 자동으로 진행돼요.
3. 트리거를 설정하세요. **Contact Tag**(연락처 태그) 트리거를 쓰거나, 삭제할 연락처용 새 태그(예: "구독취소")를 만들어 쓸 수 있어요.
4. 워크플로우를 테스트한 뒤 활성화하세요.

![워크플로우에서 연락처 삭제를 자동화하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039832645/original/Hs_TOjSoBvdOxQMKuz2lUyfgHtYzFf16Hw.png?1736885822)

액션 설명은 [워크플로우 액션 — 연락처 삭제(Delete Contact)](../../07-워크플로우/Contact-Workflow-Actions/workflow-actions-delete-contact.md)에서 볼 수 있어요.

## 자주 묻는 질문

### 연락처를 삭제하면 모든 캠페인에서도 빠지나요?
네. 삭제한 연락처는 모든 캠페인, 워크플로우, 목록에서 제거돼요.

### 연락처를 삭제하면 리포팅에 영향이 있나요?
연락처를 삭제하면 과거 캠페인 지표나 이메일 전달률 통계에 영향을 줄 수 있어요.

### 여러 연락처를 한 번에 삭제할 수 있나요?
네. 연락처 목록에서 여러 항목을 선택하면 한꺼번에 삭제할 수 있어요.

### 관리자만 연락처를 삭제하게 하려면 어떻게 하나요?
**설정 > 스태프 관리**에서 사용자 역할과 권한을 검토하고 수정하세요.

### 연락처를 삭제할 수 없어요. 왜 그런가요?

- **관리자 권한**이 없을 수 있어요. 계정 관리자에게 권한을 요청하세요.
- 연락처가 진행 중인 캠페인이나 워크플로우에 포함되어 있을 수 있어요. 캠페인이나 워크플로우에서 먼저 제거한 뒤 삭제하세요.

### 연관 데이터는 어떻게 되나요?
메모, 대화, 작업 같은 연관 데이터도 별도로 지정하지 않는 한 함께 삭제돼요. 자세한 상태는 **일괄 작업** 페이지에서 확인하세요.

### 삭제한 연락처를 복구할 수 있나요?
네, 2개월 안에는 복구할 수 있어요. 그 기간이 지나면 데이터가 영구적으로 삭제돼요.
