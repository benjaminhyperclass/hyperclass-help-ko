# 카테고리와 색상으로 연락처 태그 정리하기

관련 있는 태그를 카테고리로 묶고 태그마다 색상을 지정하면, 연락처 태그를 더 깔끔하게 관리할 수 있어요. 이 문서에서는 카테고리를 만들고, 태그 색상을 지정하고, 기존 태그를 정리하는 방법을 안내해요.

## 이 문서에서 배우는 내용

하이퍼클래스에서는 **태그 카테고리**와 **태그 색상 지정**으로 연락처 태그를 더 쉽게 정리하고 알아볼 수 있어요. 카테고리는 관련 태그를 체계적으로 묶어 주고, 색상은 지원되는 연락처 화면에서 태그를 눈에 띄게 해 줘요.

기존 태그는 별도 설정 없이 그대로 작동해요. 처음에는 회색으로 표시되고 자동으로 **카테고리 없음**에 들어가요. 그래서 천천히 나눠서 정리할 수 있어요.

## 실험실에서 사용할 수 있어요

태그 카테고리와 색상은 현재 **실험실**(Labs)에서 사용할 수 있어요. 실험실 기능은 더 많은 사용자에게 제공되는 과정에서 바뀔 수 있어요.

## 태그 카테고리와 색상이란?

태그 카테고리와 색상은 기존 연락처 태그 기능을 바꾸지 않고 보완하는 기능이에요. 태그의 용도는 그대로이고, 카테고리는 관련 태그를 묶는 정리 단계를, 색상은 태그를 쉽게 알아보게 하는 시각적 단계를 더해 줘요.

- 태그 카테고리: 관련 있는 연락처 태그를 이름 붙인 카테고리로 묶어요.
- 태그 색상: 태그마다 기본 색상이나 사용자 지정 색상을 적용해요.

기존 연락처 태그는 그대로 사용할 수 있어요. 처음에는 회색으로 표시되고 자동으로 **카테고리 없음**에 들어가요.

## 태그 카테고리와 색상의 장점

태그를 체계적으로 관리하면 연락처가 많아도 유지하기 쉽고, 비슷한 태그가 길게 늘어선 목록에서 찾는 시간도 줄어요.

- 정리가 쉬워져요: 업무 방식에 맞게 관련 태그를 카테고리로 묶을 수 있어요.
- 더 빨리 알아볼 수 있어요: 색상으로 중요한 태그 종류를 한눈에 구분해요.
- 원하는 대로 꾸밀 수 있어요: 기본 색상을 고르거나 사용자 지정 색상을 선택할 수 있어요.
- 기존 태그도 안전해요: 기존 태그는 그대로 작동하고, 회색 상태로 **카테고리 없음**에서 시작해요.
- 일괄 관리를 할 수 있어요: 여러 태그를 한 번에 다른 카테고리로 옮기거나, 선택한 태그 최대 100개에 같은 색상을 한 번에 적용해요. 태그가 많아도 반복 작업이 줄어요.
- 연락처 관리가 깔끔해져요: 카테고리별로 묶여 있어 연락처에서 태그를 찾기 쉬워요.
- 화면마다 일관돼요: 태그 색상은 지원되는 연락처 화면과 스마트 리스트에 표시돼요.

## 태그 관리 페이지 살펴보기

태그 관리 페이지에서는 연락처 태그를 한곳에서 확인하고, 만들고, 정리하고, 수정할 수 있어요. 카테고리, 설명, 색상, 태그 정보가 함께 보여서 태그가 늘어나도 일관되게 관리할 수 있어요.

태그를 한 번에 최대 100개까지 선택해서 선택한 태그 전체에 같은 색상을 적용할 수도 있어요. 태그를 하나씩 수정하지 않고도 색상 체계를 만들거나 바꿀 수 있어요.

**태그** 탭에는 다음 정보가 표시돼요.

- **태그 이름**
- **설명**
- **카테고리**
- **생성일**
- **Updated date**(수정일)
- **편집**, **삭제** 작업

![태그 관리 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662249/original/hkqhWLdcPiFFHLXVRH0ZnJZby80W4zYiAA.png?1789103635)

## 카테고리로 태그 정리하기

카테고리는 관련 있는 연락처 태그를 담는 그릇이에요. 태그를 한 줄로 길게 관리하는 대신, 팀이 태그를 쓰는 방식에 따라 묶을 수 있어요. 예를 들어 라이프사이클 단계, 관심 상품, 지역, 유입 경로, 고객 상태로 나눌 수 있어요.

### 카테고리 만들기

카테고리 구조가 명확하면 태그를 찾기 쉽고, 태그를 많이 쓰는 팀도 같은 기준으로 정리할 수 있어요.

1. **태그** 관리 페이지를 열어요.
2. **카테고리 만들기**를 클릭해요.
3. 알아보기 쉬운 **카테고리 이름**을 입력해요.
4. 필요하면 **카테고리 설명**에 설명을 입력해요.
5. **카테고리 만들기**를 클릭해요.

![카테고리 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662317/original/MxP37jZ-Dv2aLS9MEBrA08m6OhgFvKsIcw.png?1789103661)

### 카테고리 없음이란?

**카테고리 없음**은 사용자 지정 카테고리에 속하지 않은 태그가 들어가는 기본 위치예요. 모든 태그가 항상 어딘가에 속해 있도록 해 줘요.

다음 경우에 태그가 **카테고리 없음**에 들어가요.

- 태그 카테고리가 생기기 전부터 있던 태그예요.
- 사용자 지정 카테고리를 지정하지 않았어요.
- 태그가 들어 있던 카테고리를 삭제했어요.

{% hint style="warning" %}
카테고리를 삭제해도 그 안의 태그는 삭제되지 않아요. 태그는 자동으로 **카테고리 없음**으로 이동해요.
{% endhint %}

## 카테고리와 색상을 지정해서 태그 만들기

태그를 만들 때 카테고리와 색상을 함께 지정하면 나중에 정리할 일이 줄고, 다른 사용자도 태그가 무엇을 뜻하는지 쉽게 알 수 있어요.

태그를 만들 때 다음 항목을 설정할 수 있어요.

- 태그 이름
- 카테고리
- 설명
- 태그 색상

1. **+ 새 태그**를 클릭해요.
2. **태그 이름**을 입력해요.
3. 알맞은 **카테고리**를 선택해요. 필요한 카테고리가 없으면 카테고리 선택 창에서 바로 새 카테고리를 만들 수 있어요. 현재 화면에서 벗어나지 않고 태그 만들기를 이어서 할 수 있어요.
4. 필요하면 **설명 추가**를 클릭해 설명을 입력해요.
5. **태그 색상**에서 색상을 선택해요.
6. **미리보기**를 확인해요.
7. **태그 만들기**를 클릭해요.

![태그 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662393/original/4s_6EFeVfqPXRmAOV6-0HQuNQQHfKBnpXw.png?1789103682)

## 색상으로 태그 꾸미기

태그 색상은 태그 종류를 더 빨리 구분하게 해 주는 시각적 단서예요. 연락처 한 명에게 태그가 여러 개 붙어 있을 때 일관된 색상 체계가 특히 도움이 돼요.

### 기본 색상 사용하기

기본 색상을 쓰면 색상 값을 직접 고르지 않고도 빠르게 통일감을 줄 수 있어요. 색상을 선택하지 않으면 태그는 기본값인 회색으로 표시돼요.

### 사용자 지정 색상 사용하기

기본 색상이 원하는 색 규칙이나 브랜드 색상과 맞지 않을 때는 색상 선택기로 직접 고를 수 있어요.

1. 태그의 **편집**을 클릭해요.
2. **태그 색상**을 찾아요.
3. **사용자 지정 색상**을 선택해요.
4. 색상 선택기에서 원하는 색상을 골라요.
5. **미리보기**를 확인해요.
6. 변경 내용을 저장해요.

![사용자 지정 색상 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662403/original/luFUzqEqFfdJO2rxjuIz8RG513aWbLvOxg.png?1789103707)

{% hint style="info" %}
색상을 무작정 지정하지 말고 반복해서 쓸 수 있는 규칙을 정해 보세요. 예를 들어 라이프사이클 태그는 한 계열의 색, 유입 경로 태그는 다른 계열의 색, 운영용 태그는 또 다른 계열의 색으로 정해요.
{% endhint %}

## 태그를 다른 카테고리로 옮기기

태그를 옮기면 태그를 다시 만들지 않고도 기존 태그를 새 구조로 정리할 수 있어요. 기존 태그가 **카테고리 없음**에서 시작해 새 구조로 정리가 필요할 때 특히 편리해요.

### 태그 일괄 이동하기

같은 카테고리에 속할 태그가 여러 개라면 일괄 이동이 가장 빨라요.

1. **태그** 탭을 열어요.
2. 정리할 태그를 선택해요.
3. **카테고리로 이동**을 클릭해요.
4. 옮길 카테고리를 선택해요.
5. 이동을 확인해요.

![태그를 카테고리로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662408/original/RaVUSWOjphfQVPCSd44OXVAtMeiWHl_hXA.png?1789103732)

## 연락처에서 카테고리와 색상 활용하기

카테고리가 있으면 연락처에서 태그를 고를 때 찾기 쉽고, 색상이 있으면 붙어 있는 태그를 구분하기 쉬워요. 연락처 상세 페이지에 대한 자세한 내용은 [새로운 연락처 상세 페이지](../연락처-상세/contacts-all-new-contact-detail-page.md)를 참고하세요.

### 카테고리별 태그 선택하기

태그 선택기에서는 태그나 카테고리로 검색할 수 있고, 사용할 수 있는 태그가 카테고리별로 묶여 보여요. 원하는 태그를 더 빨리 찾을 수 있어요.

1. 연락처 상세 화면을 열어요.
2. **태그**를 찾아요.
3. 태그를 추가하거나 편집하는 버튼을 클릭해요.
4. 태그나 카테고리를 검색해요.
5. 해당 카테고리를 펼쳐요.
6. 필요한 태그를 선택하거나 선택 해제해요.
7. **적용**을 클릭해요.

![카테고리별 태그 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662421/original/znYnrH1ygper2nW8UmWqivBBaQf3Yc7msQ.png?1789103758)

여러 연락처에 태그를 한 번에 추가하는 방법은 [여러 연락처에 태그 추가하기](../일괄-작업/adding-tags-to-multiple-contacts.md)를 참고하세요.

### 연락처에서 색상 태그 확인하기

태그를 적용하면 지정한 색상이 연락처 상세 화면에 표시돼요. 태그 선택기를 열지 않아도 태그 분류를 바로 알아볼 수 있어요.

![연락처에 표시된 색상 태그](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662429/original/L10cbrA0MdXK0brSuqgPxep8f_NVE1wCyg.png?1789103777)

태그 색상은 지원되는 스마트 리스트 열에도 표시돼요. 태그가 붙은 연락처를 더 빨리 훑어볼 수 있어요.

## 기존 태그와 자동화에 미치는 영향

카테고리와 색상은 기존 연락처 태그 기능을 대체하지 않고 보완해요. 그래서 태그를 새로 만들거나 연락처 분류와 워크플로우에서 태그의 기본 역할을 바꾸지 않고도 기존 태그를 정리할 수 있어요.

기존 태그는 다음과 같아요.

- 계속 사용할 수 있어요.
- 처음에는 회색으로 표시돼요.
- **카테고리 없음**에서 시작해요.
- 나중에 사용자 지정 카테고리로 옮길 수 있어요.
- 언제든 색상을 지정할 수 있어요.

{% hint style="warning" %}
카테고리와 색상은 연락처 태그를 정리하고 눈에 띄게 해 주는 기능이에요. 별도의 태그가 아니며, 카테고리나 색상에 따른 새 워크플로우 트리거도 만들어지지 않아요.
{% endhint %}

태그가 워크플로우와 연결되는 방식은 [워크플로우 트리거 — 연락처 태그](../../07-워크플로우/workflow-trigger-contact-tag.md)와 [워크플로우 액션 — 연락처 태그 추가](../../07-워크플로우/Contact-Workflow-Actions/workflow-action-add-contact-tag.md)를 참고하세요. 태그 외에 연락처 유형으로 연락처를 나누고 싶다면 [연락처 유형으로 연락처 정리하고 분류하기](how-to-use-contact-types-to-organize-and-segment-contacts.md)를 참고하세요.

### 연락처 태그와 기회 스마트 태그 비교

연락처 태그 색상과 기회의 스마트 태그(Opportunity Smart Tags)는 둘 다 색이 있는 라벨을 쓰지만 해결하는 문제가 달라요. 연락처 태그 색상을 규칙에 따라 붙는 파이프라인 라벨로 오해하지 않도록 구분해서 알아 두세요. 기회의 스마트 태그에 대한 자세한 내용은 [기회 파이프라인 색상으로 구분하기(스마트 태그)](../../05-기회-파이프라인/기회-관리/how-to-color-code-opportunity-pipelines-smart-tags.md)를 참고하세요.

| 기능 | 연락처 태그 | 기회 스마트 태그 |
| --- | --- | --- |
| 기본 대상 | 연락처 | 기회 |
| 용도 | 연락처에 라벨을 붙이고 분류 | 파이프라인의 기회를 시각적으로 우선순위화 |
| 카테고리 | 지원 | 다른 구성 방식 사용 |
| 색상 | 태그에 지정 | 스마트 태그 규칙에 지정 |
| 동작 | 기존 연락처 태그 동작 | 규칙 기반 기회 평가 |

## 태그 카테고리와 색상 설정하기

미리 계획한 태그 구조는 일관된 기준 없이 태그를 하나씩 정리하는 것보다 유지하기 쉬워요. 먼저 큰 카테고리로 시작해서 기존 태그를 정리하고, 시각적으로 구분하는 게 가장 도움이 되는 곳에 색상을 추가하세요.

### 1단계: 기존 태그 살펴보기

현재 태그를 먼저 살펴보면 이름이 겹치는 패턴, 자주 쓰는 태그, 자연스러운 묶음을 파악할 수 있어요. 카테고리를 만들기 전에 확인하세요.

- 유입 경로
- 라이프사이클 단계
- 상품 또는 서비스
- 지역
- 캠페인 또는 이벤트
- 내부 운영용 라벨

### 2단계: 카테고리 만들기

태그가 한두 개뿐인 아주 구체적인 카테고리보다, 여러 곳에 쓸 수 있는 폭넓은 카테고리가 팀이 이해하기 쉬워요.

1. **카테고리 만들기**를 클릭해요.
2. 알아보기 쉬운 카테고리 이름을 입력해요.
3. 맥락을 더 설명하고 싶으면 **카테고리 설명**에 설명을 입력해요.
4. **카테고리 만들기**를 클릭해 카테고리를 만들어요.

### 3단계: 기존 태그 정리하기

기존 태그는 **카테고리 없음**에서 시작해요. 지금 쓰는 태그 체계를 방해하지 않고 천천히 정리할 수 있어요.

1. 관련 있는 태그를 선택해요.
2. **카테고리로 이동**을 클릭해요.
3. 옮길 카테고리를 선택해요.
4. 다른 묶음도 같은 방식으로 반복해요.

### 4단계: 중요한 태그에 색상 추가하기

모든 태그를 장식용으로 꾸미지 말고, 눈에 잘 띄면 시간을 아낄 수 있는 태그에만 색상을 지정하세요.

- 우선순위가 높은 태그
- 고객 상태 태그
- 리드 적격 여부 태그
- 관심 상품 태그
- 운영 알림 태그

기존 태그 여러 개에 같은 색상을 쓰려면, 태그를 최대 100개까지 선택해서 한 번에 색상을 적용하세요. 태그가 많을 때 정리가 빨라지고 색상 규칙도 일관되게 유지할 수 있어요.

### 5단계: 연락처에서 확인하기

연락처에서 직접 확인해 보면 카테고리 구조가 탐색하기 쉬운지, 고른 색상이 실제로 쓰기에 알아보기 쉬운지 알 수 있어요.

- 카테고리 덕분에 필요한 태그를 찾기 쉬운가요?
- 선택한 색상이 서로 쉽게 구분되나요?
- 사용자가 색상 규칙을 이해하나요?
- 태그 추가와 제거가 예상대로 작동하나요?

### 6단계: 기존 자동화 점검하기

카테고리와 색상은 정리를 돕는 기능이에요. 하지만 워크플로우, 스마트 리스트, 필터, 연동은 여전히 개별 태그 이름에 의존할 수 있어요. 기존 태그의 이름을 바꾸거나 삭제하기 전에 연결된 곳을 확인하세요.

1. 해당 태그를 사용하는 워크플로우를 찾아요.
2. 해당 태그를 참조하는 스마트 리스트와 필터를 확인해요.
3. 해당 태그에 의존하는 캠페인이나 연동이 있는지 확인해요.
4. 구조를 바꿀 때는 신중하게 진행해요.

## 확장 가능한 태그 체계를 위한 모범 사례

사용자가 일관되게 기억하기 어려울 만큼 세분화된 체계보다, 의도가 분명한 소수의 카테고리와 반복해서 쓸 수 있는 색상 규칙이 유지하기 쉬워요.

- 카테고리는 용도별로 나누세요: 개별 연락처가 아니라, 반복되는 업무 용도에 따라 태그를 묶어요.
- 이름 규칙을 통일하세요: 태그가 많다면 정리하기 전에 대소문자와 이름 짓는 규칙을 먼저 정해요.
- 색상의 의미를 문서로 남기세요: 중요한 색상이 무엇을 뜻하는지 사용자가 알 수 있게 해요.
- 색상을 너무 다양하게 쓰지 마세요: 색상은 반복해서 같은 의미를 전달할 때 가장 유용해요.
- 설명으로 맥락을 더하세요: 태그 이름만으로 용도를 알기 어려우면 설명을 추가해요.
- **카테고리 없음**을 주기적으로 점검하세요: 분류되지 않은 태그가 또 다른 긴 목록이 되지 않게 해요.
- 삭제하기 전에 확인하세요: 카테고리를 삭제하면 그 안의 태그가 **카테고리 없음**으로 이동해요. 태그 자체를 삭제하는 건 별개의 작업이에요.

## 자주 묻는 질문

### 태그 카테고리와 색상은 모든 사용자가 쓸 수 있나요?
현재 **실험실**에서 사용할 수 있어요. 실험실에 있는 동안에는 제공 범위와 화면 구성이 바뀔 수 있어요.

### 기존 태그는 어떻게 되나요?
기존 태그는 그대로 사용할 수 있어요. 처음에는 회색으로 표시되고 **카테고리 없음**에 들어가요. 바로 다시 설정할 필요는 없어요.

### 모든 태그에 카테고리가 있어야 하나요?
네. 사용자 지정 카테고리가 없는 태그는 기본 제공되는 **카테고리 없음** 그룹에 속해요.

### 여러 태그를 한 번에 다른 카테고리로 옮길 수 있나요?
네. 여러 태그를 선택하고 **카테고리로 이동**을 사용하면 한꺼번에 정리할 수 있어요.

### 태그가 들어 있는 카테고리를 삭제하면 어떻게 되나요?
태그는 카테고리와 함께 삭제되지 않고 자동으로 **카테고리 없음**으로 이동해요.

### 태그 색상을 직접 지정할 수 있나요?
네. 기본 색상 중에서 고르거나 색상 선택기로 사용자 지정 색상을 선택할 수 있어요.

### 색상을 선택하지 않으면 어떤 색이 쓰이나요?
기본값인 회색이 쓰여요.

### 태그 색상은 어디에서 볼 수 있나요?
연락처 상세 화면에서 태그를 다룰 때와, 지원되는 스마트 리스트 열에 태그가 표시될 때 볼 수 있어요.

### 카테고리와 색상이 새로운 워크플로우 트리거를 만드나요?
아니요. 이번 출시에는 카테고리나 색상에 따른 새로운 워크플로우 동작이 포함되어 있지 않아요. 기존 태그 자동화는 계속 기존 연락처 태그를 기준으로 작동해요.

### 기회 스마트 태그와 같은 건가요?
아니요. 연락처 태그는 연락처에 라벨을 붙이는 기능이고, 기회 스마트 태그는 파이프라인에서 규칙에 따라 색이 붙는 라벨이에요.
