# 카테고리와 색상으로 태그 정리하고 개인화하기

연락처 • Labs

카테고리와 색상으로 태그 정리하고 개인화하기

관련 태그를 카테고리로 묶고, 중요한 라벨을 쉽게 알아볼 수 있도록 색상을 지정해서 더 깔끔한 연락처 태그 시스템을 만들어보세요.

배우게 될 내용

하이퍼클래스는 이제 **태그 카테고리(Tag Categories)**와 **커스터마이징 가능한 태그 색상(Tag Colors)**으로 연락처 태그를 더 쉽게 정리하고 식별할 수 있게 했어요. 카테고리는 관련 태그를 체계적인 구조로 그룹화하고, 색상은 지원되는 연락처 화면에서 태그가 표시될 때 시각적인 단서를 제공해요.

기존 태그는 추가 설정 없이 계속 사용할 수 있어요. 처음에는 회색으로 표시되며 자동으로 **카테고리 없음(No category)**에 배치되므로 점진적으로 정리해나갈 수 있어요.

Labs 제공 안내

태그 카테고리 및 색상 기능은 현재 **Labs**를 통해 제공되고 있어요. Labs 기능은 정식 출시로 가는 과정에서 계속 변경될 수 있어요.

# **태그 카테고리와 색상이란?**

태그 카테고리와 색상은 태그의 기본적인 목적은 그대로 유지하면서 하이퍼클래스의 기존 연락처 태그 시스템을 더 강화해줘요. 카테고리는 관련 태그를 그룹화하는 조직적인 레이어를 제공하고, 색상은 태그를 더 쉽게 식별할 수 있는 시각적인 레이어를 제공해요.

- **태그 카테고리:** 관련된 연락처 태그를 이름이 붙은 카테고리로 그룹화해요.
- **태그 색상:** 개별 태그에 미리 정의된 색상이나 커스텀 색상을 적용해요.

**기존 태그:** 기존 연락처 태그는 계속 사용할 수 있고, 처음에는 회색으로 표시되며, 자동으로 **카테고리 없음**에 배치돼요.


## **태그 카테고리와 색상의 주요 장점**

체계적인 태깅 시스템은 대규모 연락처 데이터베이스를 더 쉽게 관리할 수 있게 해주고, 사용자가 비슷한 태그들로 가득한 긴 목록을 뒤지는 시간을 줄여줘요.

- 향상된 정리: 비즈니스 프로세스에 맞춰 관련 태그를 카테고리로 그룹화해요.
- 더 빠른 식별: 색상을 활용해서 중요한 태그 유형을 한눈에 알아볼 수 있어요.
- 유연한 커스터마이징: 미리 정의된 색상을 선택하거나 커스텀 색상을 직접 고를 수 있어요.
- 안전한 기존 태그 처리: 기존 태그는 계속 작동하며 카테고리 없음 상태에서 회색 스타일로 시작해요.
- 일괄 관리: 여러 태그를 카테고리 간에 한번에 이동하거나, 최대 100개까지 선택한 태그에 하나의 색상을 한 번의 작업으로 적용할 수 있어서 대규모 태그 라이브러리에서 반복적인 업데이트 작업을 줄여줘요.
- 더 깔끔한 연락처 관리: 카테고리 그룹화로 연락처 상세(레코드)에서 태그를 더 쉽게 찾을 수 있어요.
- 시각적 일관성: 태그 색상은 지원되는 연락처 및 스마트 리스트(Smart List) 화면 전반에 걸쳐 표시돼요.


## **태그 관리 페이지 이해하기**

태그 관리 페이지는 연락처 태그를 검토, 생성, 정리, 업데이트할 수 있는 중앙 집중식 작업 공간이에요. 카테고리, 설명, 색상, 태그 정보를 하나로 모아 보여주기 때문에 점점 커지는 태그 라이브러리를 더 일관되게 관리할 수 있어요.

또한 최대 100개까지 태그를 한번에 선택해서 선택한 전체 항목에 동일한 색상을 적용할 수도 있어요. 일괄 색상 업데이트를 사용하면 태그를 하나씩 수정하지 않고도 일관된 색상 체계를 도입하거나 재정리하기가 더 쉬워져요.


태그 탭에는 다음과 같은 정보가 포함돼 있어요:

- 태그 이름
- 설명
- 카테고리
- 생성일
- 수정일
- 편집 및 삭제 액션

## **카테고리로 태그 정리하기**

카테고리는 관련된 연락처 태그를 담는 컨테이너 역할을 해요. 하나의 거대하고 평면적인 태그 목록을 유지하는 대신, 생애주기 단계, 상품 관심사, 지역, 유입 경로, 고객 상태 등 팀이 태그를 사용하는 방식에 맞춰 태그를 그룹화할 수 있어요.

### **카테고리 만들기**

명확한 카테고리 구조는 개별 태그를 더 쉽게 찾을 수 있게 해주고, 많은 태그를 사용하는 팀을 위한 재사용 가능한 조직 모델을 만들어줘요.

- **태그(Tags)** 관리 페이지를 엽니다.
- **카테고리 생성(Create category)**을 클릭하세요.
- 명확한 **카테고리 이름(Category name)**을 입력하세요.
- 선택적으로 설명을 추가하세요.
- **카테고리 생성(Create category)**을 클릭하세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662317/original/MxP37jZ-Dv2aLS9MEBrA08m6OhgFvKsIcw.png?1789103661)


### **카테고리 없음 이해하기**

카테고리 없음(No category)은 커스텀 카테고리에 배정되지 않은 태그를 위한 기본 위치로, 모든 태그가 항상 조직적인 위치를 가질 수 있도록 보장해줘요.

하이퍼클래스는 다음과 같은 경우에 태그를 **카테고리 없음**에 배치해요:

- 태그 카테고리 기능이 도입되기 전에 이미 존재했던 태그
- 커스텀 카테고리가 배정되지 않은 태그
- 해당 태그가 속해있던 카테고리가 삭제된 경우

**중요:** 카테고리를 삭제해도 그 안의 태그는 삭제되지 않아요. 해당 태그들은 자동으로 **카테고리 없음**으로 이동해요.


## **카테고리와 색상으로 태그 만들기**

태그를 만들 때 조직 정보와 시각적 스타일을 함께 지정하면 나중에 정리할 작업이 줄어들고, 다른 사용자가 해당 태그가 무엇을 의미하는지 더 쉽게 이해할 수 있어요.

태그를 만들 때 다음을 설정할 수 있어요:

- 태그 이름
- 카테고리
- 설명
- 태그 색상

- **새 태그(New tag)**를 클릭하세요.
- **태그 이름(Tag name)**을 입력하세요.
- 알맞은 **카테고리(Category)**를 선택하세요. 필요한 카테고리가 없다면, 현재 작업 흐름을 벗어나지 않고 카테고리 선택기에서 바로 새 카테고리를 만들어 태그 생성을 이어갈 수 있어요.
- 선택적으로 설명을 추가하세요.
- 태그 색상을 선택하세요.
- **미리보기(Preview)**를 확인하세요.
- **태그 생성(Create tag)**을 클릭하세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662393/original/4s_6EFeVfqPXRmAOV6-0HQuNQQHfKBnpXw.png?1789103682)


## **색상으로 태그 개인화하기**

태그 색상은 사용자가 태그 유형을 더 빠르게 구분할 수 있도록 시각적인 단서를 제공해요. 하나의 연락처에 여러 태그가 동시에 적용된 경우 일관된 색상 체계가 특히 유용해요.

### **미리 정의된 색상 사용하기**

미리 정의된 색상은 특정 색상값을 직접 선택하지 않고도 시각적 일관성을 빠르게 만드는 방법이에요. 색상을 선택하지 않으면 태그는 기본적으로 회색으로 표시돼요.

### **커스텀 색상 사용하기**

커스텀 색상 선택 도구는 미리 정의된 옵션이 원하는 시각적 규칙이나 브랜드 팔레트와 맞지 않을 때 더 세밀한 제어를 가능하게 해줘요.

- 태그의 편집 액션을 여세요.
- **태그 색상(Tag color)**을 찾으세요.
- 커스텀 색상 옵션을 선택하세요.
- 색상 선택기에서 원하는 색상을 고르세요.
- **미리보기(Preview)**를 확인하세요.
- 업데이트 내용을 저장하세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662403/original/luFUzqEqFfdJO2rxjuIz8RG513aWbLvOxg.png?1789103707)


**모범 사례:** 무작위로 색상을 지정하지 말고 반복 가능한 색상 규칙을 사용하세요. 예를 들어, 생애주기 태그에는 하나의 색상 계열을, 리드 유입 경로 태그에는 다른 색상 계열을, 운영 관련 태그에는 또 다른 색상 계열을 사용해보세요.


## **카테고리 간 태그 이동하기**

태그를 이동하면 태그를 다시 만들지 않고도 기존 태그 라이브러리를 재정리할 수 있어요. 이 기능은 기존 태그가 카테고리 없음 상태로 시작해서 새로운 구조로 정리해야 할 때 특히 유용해요.

### **태그 일괄 이동하기**

여러 태그가 같은 카테고리에 속해야 할 때, 일괄 이동은 이미 구축된 태그 라이브러리를 정리하는 가장 빠른 방법이에요.

- **태그(Tags)** 탭을 여세요.
- 재정리하고 싶은 태그를 선택하세요.
- **카테고리로 이동(Move to category)**을 클릭하세요.
- 이동할 대상 카테고리를 선택하세요.
- 이동을 확인하세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662408/original/RaVUSWOjphfQVPCSd44OXVAtMeiWHl_hXA.png?1789103732)


## **연락처 상세 페이지에서 카테고리와 색상 사용하기**

카테고리는 개별 연락처 상세(레코드)에서 태그 선택기를 더 쉽게 탐색할 수 있게 해주고, 색상은 적용된 태그를 더 쉽게 구분할 수 있게 해줘요.

### **카테고리화된 태그 선택하기**

태그 선택기는 태그나 카테고리로 검색하는 것을 지원하고, 사용 가능한 태그를 카테고리별로 그룹화해서 사용자가 알맞은 라벨을 더 빠르게 찾을 수 있도록 도와줘요.

- 연락처 상세(레코드)를 여세요.
- **태그(Tags)**를 찾으세요.
- 태그 추가/편집 컨트롤을 클릭하세요.
- 태그나 카테고리를 검색하세요.
- 알맞은 카테고리를 펼치세요.
- 원하는 태그를 선택하거나 선택 해제하세요.
- **적용(Apply)**을 클릭하세요.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662421/original/znYnrH1ygper2nW8UmWqivBBaQf3Yc7msQ.png?1789103758)


### **연락처에서 색상이 적용된 태그 보기**

태그가 적용되면 할당된 색상이 연락처 상세(레코드)에 표시되어, 태그 선택기를 열지 않고도 서로 다른 분류를 더 쉽게 알아볼 수 있어요.


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080662429/original/L10cbrA0MdXK0brSuqgPxep8f_NVE1wCyg.png?1789103777)


태그 색상은 지원되는 **스마트 리스트(Smart List) 컬럼**에도 표시되어, 사용자가 태그가 지정된 연락처를 더 빠르게 훑어볼 수 있게 도와줘요.


## **기존 태그와 자동화에 미치는 영향**

카테고리와 색상은 기존 연락처 태그 시스템을 대체하는 것이 아니라 강화하는 기능이에요. 즉, 태그 자체를 다시 만들거나 연락처 세분화 및 워크플로우(Workflow) 내에서의 기본적인 역할을 바꾸지 않고도 기존 태그를 정리할 수 있다는 뜻이에요.

기존 태그는:

- 계속 사용할 수 있어요.
- 처음에는 회색으로 표시돼요.
- **카테고리 없음**에서 시작해요.
- 나중에 커스텀 카테고리로 이동할 수 있어요.
- 언제든지 색상을 지정할 수 있어요.

**중요:** 카테고리와 색상은 연락처 태그를 정리하고 시각적으로 식별하기 위한 기능이에요. 이는 별도의 태그가 아니며, 카테고리나 색상에 특화된 새로운 워크플로우 트리거(Trigger)를 만들어내지 않아요.


### **연락처 태그 vs. 기회 스마트 태그**

연락처 태그 색상과 기회(Opportunities) 스마트 태그는 둘 다 색상 라벨을 사용할 수 있지만, 서로 다른 문제를 해결하기 위한 기능이에요. 두 개념을 분리해서 이해하면 사용자가 연락처 태그 색상을 규칙 기반의 파이프라인(Pipeline) 라벨로 오해하는 것을 방지할 수 있어요.

| 기능 | 연락처 태그 | 기회 스마트 태그 |
|---|---|---|
| **주요 대상** | 연락처 | 기회 |
| **목적** | 연락처에 라벨을 붙이고 세분화 | 파이프라인 기회를 시각적으로 우선순위화 |
| **카테고리** | 지원됨 | 다른 설정 모델 사용 |
| **색상** | 태그에 지정됨 | 스마트 태그 규칙에 지정됨 |
| **동작 방식** | 기존 연락처 태그 동작 방식 | 규칙 기반 기회 평가 |


## **태그 카테고리와 색상 설정 방법**

계획된 태그 구조는 일관된 규칙 없이 태그를 하나씩 재정리하는 것보다 유지 관리하기가 더 쉬워요. 넓은 범위의 카테고리부터 시작해서 기존 태그를 정리한 다음, 시각적 식별이 가장 큰 가치를 제공할 곳에 색상을 추가하세요.

### **1단계: 기존 태그 검토하기**

카테고리를 도입하기 전에 현재 태그 라이브러리를 먼저 검토하면 중복된 명명 패턴, 많이 사용되는 태그, 논리적인 그룹을 파악할 수 있어요.

- 리드 유입 경로
- 생애주기 단계
- 상품 또는 서비스
- 지역
- 캠페인 또는 이벤트
- 내부 운영 라벨

### **2단계: 카테고리 만들기**

하나 또는 두 개의 태그만 포함하는 매우 구체적인 카테고리보다, 넓고 재사용 가능한 카테고리가 팀이 이해하기 더 쉬워요.

- **카테고리 생성(Create category)**을 클릭하세요.
- 명확한 카테고리 이름을 입력하세요.
- 추가 맥락이 필요하면 설명을 추가하세요.
- 카테고리를 생성하세요.

### **3단계: 기존 태그 정리하기**

기존 태그는 카테고리 없음 상태로 시작하기 때문에, 현재의 태깅 시스템을 방해하지 않고 점진적으로 재정리할 수 있어요.

- 관련된 태그를 선택하세요.
- **카테고리로 이동(Move to category)**을 클릭하세요.
- 이동할 대상 카테고리를 선택하세요.
- 다른 그룹에 대해서도 반복하세요.

### **4단계: 중요한 태그에 색상 추가하기**

모든 태그를 단순히 장식 목적으로 색칠하는 대신, 시각적 식별이 사용자의 시간을 절약해줄 곳에 색상을 적용하세요.

- 우선순위가 높은 태그
- 고객 상태 태그
- 리드 자격 태그
- 상품 관심사 태그
- 운영 알림 태그

여러 기존 태그에 동일한 색상을 사용해야 하는 경우, 최대 100개까지 선택해서 한 번의 일괄 작업으로 색상을 적용하세요. 이렇게 하면 대규모 태그 라이브러리를 재정리하는 작업이 더 빨라지고, 일관된 색상 규칙을 유지하는 데 도움이 돼요.

### **5단계: 연락처 화면에서 확인하기**

연락처에서 결과를 테스트해보면 카테고리 구조가 탐색하기 쉽고, 선택한 색상이 일상적인 사용에서 이해하기 쉬운지 확인할 수 있어요.

- 카테고리가 원하는 태그를 더 쉽게 찾게 해주는지 확인하세요.
- 선택한 색상이 쉽게 구분되는지 확인하세요.
- 사용자가 색상 규칙을 이해하고 있는지 확인하세요.
- 태그를 추가하고 제거하는 작업이 예상대로 동작하는지 확인하세요.

### **6단계: 기존 자동화 검토하기**

카테고리와 색상은 조직화 기능을 추가해주지만, 워크플로우, 스마트 리스트, 필터, 연동(Integration) 기능은 여전히 개별 태그 이름에 의존할 수 있어요. 기존 태그의 이름을 바꾸거나 삭제하기 전에 이러한 의존 관계를 검토하세요.

- 해당 태그를 사용하는 워크플로우를 확인하세요.
- 그 태그를 참조하는 스마트 리스트와 필터를 검토하세요.
- 그 태그에 의존하는 캠페인이나 연동을 확인하세요.
- 구조적인 변경은 신중하게 진행하세요.


## **확장 가능한 태그 시스템을 위한 모범 사례**

의도적으로 설계된 소수의 카테고리와 반복 가능한 색상 규칙이, 사용자가 일관되게 기억할 수 없을 만큼 지나치게 세분화된 시스템보다 유지 관리하기 더 쉬워요.

- **목적에 맞게 카테고리 사용하기:** 개별 연락처가 아니라 반복되는 비즈니스 용도에 맞춰 태그를 그룹화하세요.
- **이름을 일관되게 유지하기:** 대규모 라이브러리를 재정리하기 전에 대소문자 표기와 명명 규칙을 미리 정해두세요.
- **색상의 의미를 문서화하기:** 사용자가 중요한 색상이 무엇을 의미하는지 이해하도록 하세요.
- **지나친 색상 변형 피하기:** 색상은 반복 가능한 의미를 전달할 때 가장 유용해요.
- **맥락을 위해 설명 사용하기:** 태그의 목적이 이름만으로 명확하지 않을 때 설명을 추가하세요.
- **카테고리 없음을 주기적으로 검토하기:** 카테고리가 없는 태그가 또 다른 거대한 평면 목록이 되지 않도록 관리하세요.
- **삭제 전에 검토하기:** 카테고리를 삭제하면 그 안의 태그는 카테고리 없음으로 이동하며, 태그 자체를 삭제하는 것은 별개의 작업이에요.


## **자주 묻는 질문**

Q: 태그 카테고리와 색상 기능은 모든 사용자가 사용할 수 있나요?

현재 이 기능은 Labs를 통해 제공되고 있어요. 기능이 Labs 상태로 남아있는 동안 제공 범위와 인터페이스 세부 사항이 변경될 수 있어요.

Q: 기존 태그는 어떻게 되나요?

기존 태그는 계속 사용할 수 있어요. 처음에는 회색으로 표시되고 카테고리 없음에 배치되기 때문에 즉시 추가 설정을 할 필요는 없어요.

Q: 모든 태그가 카테고리를 가져야 하나요?

네. 커스텀 카테고리가 없는 태그는 기본 제공되는 카테고리 없음 그룹에 속하게 돼요.

Q: 여러 태그를 한 번에 다른 카테고리로 옮길 수 있나요?

네. 여러 태그를 선택하고 카테고리로 이동 기능을 사용하면 한꺼번에 재정리할 수 있어요.

Q: 태그가 들어있는 카테고리를 삭제하면 어떻게 되나요?

태그는 카테고리와 함께 삭제되지 않고 자동으로 카테고리 없음으로 이동해요.

Q: 커스텀 태그 색상을 사용할 수 있나요?

네. 미리 정의된 색상 중 하나를 선택하거나 커스텀 색상 선택 도구를 사용할 수 있어요.

Q: 색상을 선택하지 않으면 어떤 색이 적용되나요?

기본적으로 회색이 적용돼요.

Q: 사용자는 태그 색상을 어디서 볼 수 있나요?

태그 색상은 연락처 상세 화면에서 태그를 작업할 때와, 지원되는 스마트 리스트 컬럼에 태그가 표시될 때 나타나요.

Q: 카테고리와 색상이 새로운 워크플로우 트리거를 만드나요?

아니요. 이번 업데이트에는 카테고리나 색상에 특화된 새로운 워크플로우 동작이 포함되어 있지 않아요. 기존 태그 자동화는 그대로 기반 연락처 태그를 계속 사용해요.

Q: 이 기능이 기회 스마트 태그와 같은 건가요?

아니요. 연락처 태그는 연락처에 라벨을 붙이는 기능이고, 기회 스마트 태그는 파이프라인 안에서 사용되는 규칙 기반의 색상 라벨이에요.
