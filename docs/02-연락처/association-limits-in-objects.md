# 오브젝트의 연관 한도 설정

연관 한도를 설정하면 오브젝트 사이에 연결할 수 있는 레코드 수를 제한할 수 있어요. 관계 데이터를 더 깔끔하고 정확하게 관리할 수 있어요. 이 문서에서는 지원하는 관계 유형, 한도를 설정하는 방법, 한도에 도달했을 때 사용자에게 보이는 화면을 안내해요.

## 연관 한도란?

연관 한도는 오브젝트 사이에 서로 연결할 수 있는 레코드 수를 정하는 규칙이에요. 데이터를 체계적으로 유지하고, 필요 이상으로 많이 연결되는 것을 막아 줘요. 이제 이 한도는 화면에서도 바로 적용되어 확인할 수 있어요.

- 레코드끼리 과도하게 연결되는 것을 막아요.
- 데이터 구조를 깔끔하게 유지해요.
- 한도에 도달하면 화면에 안내가 표시되어 사용자가 헷갈리지 않아요.

## 지원하는 관계 유형

{% hint style="info" %}
한도는 레이블 단위로 적용되고, 화면에도 그대로 반영돼요.
{% endhint %}

### 레이블이 여러 개인 연관

- One-to-One (1:1)
- One-to-N (N은 1,000 이하)
- One-to-Many
- N-to-Many (N은 1,000 이하)
- Many-to-Many

### 레이블이 하나인 연락처 간 연관

- One-to-One (1:1)
- Many-to-Many
- Custom N-to-N(사용자 지정 N:N)

## 연관 한도 설정하기

1. 서브 계정에서 **설정 > 오브젝트**로 이동하세요.
2. **사용자 지정 객체** 또는 **연락처**를 선택한 뒤, 점 세 개 아이콘 > **편집**을 클릭하세요.
3. **연관** 탭으로 이동하세요.

   ![연관 탭으로 이동하는 화면](https://jumpshare.com/share/7GVfIHfungV6UIeTZFbd+/GIF+Recording+2026-09-01+at+16.49.02.gif)
4. **연결 만들기**를 클릭하거나, 기존 연관을 편집하세요.

   ![연관 만들기 화면](https://jumpshare.com/share/IUPEThTYYavmnw8mFx7w+/Screen+Shot+2026-09-01+at+16.51.55.png)
5. 레이블 한 개 또는 레이블 한 쌍을 선택하세요.
6. **Configure Relationship**(관계 구성)에서 관계 유형(예: 1:1, 1:N)을 선택하세요. 한도가 필요하면 함께 설정하세요.
7. 저장하기 전에 **미리보기** 섹션에서 제한 조건을 확인하세요.
8. 설정한 연관은 **연관** 탭에서도 확인할 수 있어요.

   ![설정한 연관이 연관 탭에 표시된 화면](https://jumpshare.com/share/IA3QvW6bQnhekYOhefFk+/GIF+Recording+2026-09-01+at+17.19.41.gif)

## 활용 예시: 부동산 관리

한 부동산 에이전시에서 중개인 한 명이 맡는 매물을 최대 50개로 제한하려고 해요.

- 중개인에서 매물로 가는 One-to-N 관계를 만드세요.
- 한도를 N = 50으로 설정하세요.
- 중개인이 이 한도에 도달하면 화면에 경고가 표시되고, 매물을 더 배정할 수 없어요. 덕분에 업무량이 고르게 유지돼요.

## 연관 한도는 어떻게 작동하나요?

허용된 개수를 넘겨 연결하려고 하면 오류 메시지가 바로 표시돼요. 이를 통해 데이터 구조를 명확하고 효율적으로 관리할 수 있어요.
