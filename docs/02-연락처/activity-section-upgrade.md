# 연락처 활동 섹션 업그레이드

새롭게 바뀐 **연락처 > 활동** 섹션을 보는 방법과 달라진 점을 안내해요. 새 아이콘, 날짜별 그룹, 클릭할 수 있는 이벤트 카드, 빨라진 속도를 한 번에 확인할 수 있어요.

{% hint style="info" %}
이 기능을 켜려면 연락처 상세 페이지 > **Activity Section Upgrade**(활동 섹션 업그레이드)에서 토글을 켜세요.
{% endhint %}

## 달라진 점

1. UI 개편: 연락처와 관련된 모든 활동을 더 명확하고 직관적으로 볼 수 있도록 레이아웃을 새로 만들었어요. 새 아이콘도 추가했어요.
2. 날짜별 그룹: 활동이 **오늘**, **어제** 같은 제목 아래로 묶여 시간 순서대로 보기 쉬워요.
3. 클릭할 수 있는 이벤트 카드: 카드마다 제목, 시간, 캠페인/소스 레이블, 링크가 표시돼요.
4. 성능 개선: 백엔드를 개선해서 로딩이 빨라지고 화면이 더 부드럽게 움직여요.
5. 반응형 디자인: 데스크톱과 태블릿 화면에서 사용감과 레이아웃이 더 일관돼요.

## 활동 섹션의 기능

1. 실시간 추적: 연락처의 활동을 실시간으로 확인할 수 있어요.
2. 이벤트 상세 보기: 시간, 이벤트 유형, 링크 등 각 활동의 자세한 내용을 볼 수 있어요.
3. 이벤트 기록: 모든 활동이 기록되고, **활동** 섹션에서 확인할 수 있어요.

## 활동 섹션 확인하기

1. **연락처**로 이동한 뒤 연락처를 클릭해서 **활동**을 확인하세요.

   ![연락처 상세 화면의 활동 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045751424/original/Mfjay_JCMXcMSDntMCMCyYAK1MJaxIS6Kw.png?1745833352)

2. 자세한 내용을 보려면 이벤트 카드를 클릭하세요.
3. 외부 URL로 바로 이동하려면 이벤트의 링크 아이콘을 클릭하세요.

## 활동 섹션에서 추적하는 이벤트

**활동** 섹션에서는 연락처와 기회에 관련된 다양한 이벤트를 추적할 수 있어요. 현재 추적할 수 있는 이벤트 유형은 다음과 같아요.

### 연락처 이벤트 유형

1. 연락처 생성: 시스템에 새 연락처가 만들어졌을 때 기록해요.
2. 예약: 연락처가 예약을 잡았을 때 기록해요.
3. 통화: 연락처에게 건 전화와 연락처에게 받은 전화를 기록해요.
4. 페이지 방문: 연락처가 웹사이트의 페이지를 방문했을 때 기록해요.
5. **트리거 링크**: 연락처가 트리거 링크를 클릭했을 때의 활동을 기록해요.
6. 원스텝·투스텝 연락처 폼: 원스텝 연락처 폼과 투스텝 연락처 폼의 제출을 기록해요.
7. 원스텝·투스텝 결제: 원스텝 결제 폼과 투스텝 결제 폼의 제출을 기록해요.
8. 폼 제출: 연락처가 폼을 제출했을 때 기록해요.
9. 설문: 연락처가 설문에 응답한 활동을 기록해요.
10. 퀴즈: 연락처가 퀴즈에 참여했을 때의 데이터를 기록해요.
11. Facebook 리드 폼: 연락처가 Facebook을 통해 리드 폼을 제출했을 때 기록해요.
12. 채팅 위젯 폼: 연락처가 채팅 위젯 폼으로 제출한 내용을 기록해요.
13. LinkedIn 리드 폼: LinkedIn 리드 폼으로 들어온 제출 내용을 기록해요.
