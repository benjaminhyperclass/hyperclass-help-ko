# 연락처 추가 폼 업그레이드와 사용자 지정

업그레이드된 **연락처 추가** 사이드바로 연락처를 더 빠르게 만들고 CRM 데이터를 일정하게 관리할 수 있어요. 관리자는 폼에 표시할 필드(커스텀 필드 포함)를 고르고, 필수 필드를 정하고, 팀의 업무 순서에 맞게 필드 순서를 바꿀 수 있어요. 데이터 입력이 빨라지고 데이터 품질이 좋아지며, 데스크톱과 모바일에서 같은 방식으로 쓸 수 있어요.

{% hint style="warning" %}
**Add Contact Modal — Upgrade & Customization**(연락처 추가 모달 업그레이드 및 사용자 지정)은 현재 **실험실**에서 제공하는 기능이에요. 보이지 않으면 관리자에게 **에이전시 설정 > 실험실**에서 켜 달라고 요청하세요. 자세한 내용은 실험실 기능 전체 개요 문서를 참고하세요.
{% endhint %}

## 연락처 추가 폼 업그레이드와 사용자 지정이란?

기존의 팝업 창이 사이드바 형태로 바뀌었어요. 관리자는 어떤 필드를 어떤 순서로 보여 줄지 정할 수 있어요. 폼을 팀의 업무 방식에 맞추고, 꼭 필요한 정보는 필수 필드로 지정하면 입력 단계에서 오류를 줄이고 팀 전체의 입력 방식을 통일할 수 있어요.

이 사이드바에서 쓸 수 있는 기능은 다음과 같아요.

- 기본 필드와 커스텀 필드 지원
- 드래그 앤 드롭으로 필드 순서 변경
- 필드별 **필수** 설정
- **미리보기**
- 저장하지 않은 변경 사항 보호

관리자가 레이아웃을 한 번 정해 두면, 모든 사용자가 같은 화면에서 연락처를 만들 수 있어요. 저장 방법은 **저장**과 **Save & Add Another**(저장 후 다른 연락처 추가) 두 가지예요.

---

## 주요 이점

속도, 데이터 정확도, 관리 측면에서 처음부터 제대로 된 데이터를 받을 수 있어요.

- 빠른 입력: 사이드바 방식이라 연락처를 만드는 동안 현재 페이지에 그대로 머물 수 있어요.
- 깔끔한 데이터: 팀에 꼭 필요한 필드만 보여 주고 나머지는 숨길 수 있어요.
- 높은 데이터 품질: **연락처 유형** 같은 핵심 필드를 필수로 지정하면 정보가 빠진 연락처가 만들어지는 것을 막을 수 있어요.
- 커스텀 필드 지원: 연락처 단위 커스텀 필드를 넣으면 우리 비즈니스만의 데이터도 연락처를 만들 때 바로 받을 수 있어요.
- 관리자 제어: 관리자가 레이아웃을 관리하니 입력 기준이 일정하게 유지되고, 다른 사용자는 영업에 집중할 수 있어요.

---

## 관리자 권한과 접근

레이아웃 변경을 관리자에게만 허용하면 데이터 구조를 보호할 수 있어요. 일반 사용자는 영업과 지원 업무에 집중할 수 있고요.

- 레이아웃을 사용자 지정할 수 있는 사람: 서브 계정의 관리자 권한 사용자예요(**Roles & Permissions**(역할 및 권한) 기준).
- 연락처를 만들 수 있는 사람: **연락처** 영역에 접근할 수 있는 모든 사용자가 **연락처 추가**를 열어 설정된 폼을 쓸 수 있어요.

---

## 중복 방지와 데이터 품질 팁

연락처 데이터의 품질은 중복을 어떻게 처리하느냐에 달려 있어요. 새 연락처가 원하는 방식으로 처리되도록 중복 확인 기준을 미리 설정하세요.

- **설정 > 비즈니스 프로필 > Contact Deduplication Preferences**(연락처 중복 확인 환경설정)에서 일치 확인 방식을 정해요. **이메일**이나 **전화번호**를 기본·보조 일치 필드로 고를 수 있어요.
- CSV 가져오기는 항상 이메일과 전화번호를 확인해서 일치하는 연락처를 병합해요. CSV로는 중복 연락처가 만들어지지 않아요.
- 폼이나 연동으로 중복 연락처가 들어왔다면, 최대 10개까지 연락처를 병합하고 기준이 되는 마스터 레코드를 고를 수 있어요.

## 연락처 추가 폼 사용자 지정 설정

순서대로 설정하면 다시 작업할 일이 줄고, 팀이 일정한 상태로 시작할 수 있어요.

### 1단계: 연락처 추가 사이드바 열기

서브 계정에서 **연락처 > 스마트 리스트 > + 연락처 추가**로 이동해 사이드바를 열어요.

![연락처 추가 사이드바를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055509615/original/eKKyA8Sama6VPdu9ZXNBmHq7E52JzZBhuQ.gif?1759921782)

### 2단계: 폼 사용자 지정하기 (관리자)

**Customize Form**(폼 사용자 지정)을 클릭해요. 기본 필드와 연락처 단위 커스텀 필드를 추가하거나 제거하고, 드래그해서 순서를 바꿔요.

![폼 사용자 지정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055510030/original/O0uF5kQeH1kzsyx-IyLi-xkhZCwT98H2Sg.png?1759921995)

![필드를 추가하고 순서를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055510437/original/M4jdFf6S0tGS_tuhtsrUfqTXfNnaFgpeRw.gif?1759922166)

### 3단계: 필수 필드 지정하기

연락처 폼을 저장하기 전에 반드시 입력해야 하는 필드는 **필수**를 켜세요.

![필수 설정을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055510628/original/Vfe0w0j5_ZdyXEmbzalWmYyrAlqLjCazGA.png?1759922233)

### 4단계: 미리보기 후 저장하기

**미리보기**로 확인한 다음 팀이 쓸 레이아웃을 저장하세요.

![미리보기 후 레이아웃을 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055510842/original/yXDkoYAcXB6rLa0JKj9XdWD-5yNXBUOWmw.gif?1759922354)

**워크플로우**에서 **Contact Created**(연락처 생성) 트리거를 쓰면 새 연락처에 환영 메시지를 보내거나, 담당자를 지정하거나, 태그를 붙이는 일을 자동으로 처리할 수 있어요.

## 스마트 리스트 작업 메뉴 변경

**스마트 리스트 관리**와 **복원** 옵션이 페이지 상단에서 **연락처 추가** 버튼 옆의 작업 메뉴로 옮겨졌어요.

이 옵션을 쓰려면 다음과 같이 하세요.

1. **연락처 > 스마트 리스트**로 이동해요.
2. **연락처 추가** 버튼 옆의 점 세 개(⋮) 작업 메뉴를 클릭해요.
3. 다음 중 하나를 선택해요.
   - **스마트 리스트 관리**
   - **복원**

스마트 리스트 관리 기능이 한곳에 모이고 상단 화면은 더 단순해졌어요.

## 연락처 추가 사이드바 사용하기

팀원 모두 같은 위치에서 연락처를 만들 수 있어서 누구나 같은 방식으로 쓸 수 있어요.

1. **연락처 > 스마트 리스트 > + 연락처 추가**로 이동해 사이드바를 열어요.
2. 필수 필드를 입력한 다음 아래 중 하나를 선택해요.
   - **저장**: 연락처를 만들어요.
   - **Save & Add Another**: 연속해서 빠르게 여러 연락처를 입력해요.
   - **취소**: 저장하지 않고 나가요.

{% hint style="info" %}
변경 사항을 저장하지 않고 사이드바를 닫으려 하면, 저장하지 않은 변경 사항이 있다는 확인 창이 나타나요.
{% endhint %}

## 자주 묻는 질문

### 연락처 추가 폼의 레이아웃은 누가 사용자 지정할 수 있나요?
서브 계정의 관리자 권한 사용자만 할 수 있어요(**Roles & Permissions** 기준). 일반 사용자는 설정된 폼을 그대로 사용해요.

### 연락처 추가 폼에 커스텀 필드를 넣을 수 있나요?
네. 연락처 단위 커스텀 필드는 모두 폼에 추가하고, 순서를 바꾸고, 필수로 지정할 수 있어요. 필드는 **설정 > 커스텀 필드**에서 관리하세요.

### 연락처를 입력할 때 중복을 막으려면 어떻게 하나요?
**Contact Deduplication Preferences**에서 이메일·전화번호 일치 기준을 설정하세요. CSV 가져오기는 이메일·전화번호를 기준으로 자동 병합되기 때문에 중복 연락처가 만들어지지 않아요.

### 이 기능과 함께 쓰면 좋은 자동화는 무엇인가요?
**Contact Created** 워크플로우로 시작해 보세요. 담당자를 지정하고, 유입 경로별로 태그를 붙이고, 환영 메시지를 보낼 수 있어요. 필요하면 **Create Contact**(연락처 생성)와 **Update Contact Field**(연락처 필드 업데이트) 액션도 함께 쓰세요.

### "Save & Add Another"를 누르면 이전에 입력한 값이 그대로 남나요?
연락처를 만든 뒤 다음 입력을 위해 빈 폼을 다시 열어요. 일정하게 적용하고 싶은 태그나 담당자가 있다면 워크플로우로 자동 적용하세요.

### 사이드바의 필수 필드 설정이 CSV 가져오기나 API 생성에도 적용되나요?
아니요. 연락처 추가 사이드바의 필수 규칙은 직접 입력할 때만 적용돼요. CSV 가져오기와 API 요청에는 별도의 검증 규칙이 있어요.

### 레이아웃을 바꾸면 사용자에게 바로 반영되나요?
새로 접속하는 세션에는 바로 반영돼요. 이미 접속 중인 사용자는 **연락처** 페이지를 새로고침해야 최신 설정을 불러올 수 있어요.

### 스마트 리스트 관리 옵션은 어디로 옮겨졌나요?
**연락처 추가** 버튼 옆의 작업 메뉴(⋮) 안에 있어요.

### 삭제한 연락처는 얼마 동안 복원할 수 있나요?
삭제 후 최대 60일 동안 복원할 수 있어요.

### 스마트 리스트 권한도 바뀌었나요?
아니요. 메뉴 옵션의 위치만 바뀌었어요.
