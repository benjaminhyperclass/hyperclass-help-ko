# 회사·사용자 지정 객체 레코드에 자동화 일괄 실행하기

**회사**와 **사용자 지정 객체** 레코드를 목록 화면에서 여러 개 골라 한 번에 워크플로우로 보낼 수 있어요. 워크플로우 트리거 조건을 충족하기를 기다리거나 레코드를 하나씩 처리하지 않아도 돼요.

## 개요

일괄 작업 메뉴의 **Trigger Automation**(자동화 실행)을 쓰면 회사 또는 사용자 지정 객체 레코드 여러 개를 한 번에 워크플로우로 보낼 수 있어요.

이미 있는 특정 레코드 그룹에 자동화를 실행하고 싶을 때 쓰면 좋아요. 각 레코드가 워크플로우 트리거 조건을 충족하기를 기다릴 필요가 없어요.

스마트 리스트와 필터를 함께 쓰면 원하는 그룹을 만들 수 있어요. 그 그룹의 레코드를 선택해 전체에 자동화를 실행하세요.

## 사전 조건 및 제한 사항

일괄 작업을 쓰기 전에 아래 내용을 확인하세요.

- 선택한 객체에 사용할 워크플로우가 이미 있어야 해요.
- 워크플로우가 게시된 상태여야 해요.
- 일괄 작업은 현재 **회사**와 **사용자 지정 객체**에서 쓸 수 있어요.
- 선택한 객체에 해당하는 워크플로우만 실행할 수 있어요.

## 회사·사용자 지정 객체에 자동화 일괄 실행하기

1. 레코드를 선택해요.
   1. **회사** 또는 사용할 **사용자 지정 객체**를 열어요.
   2. 처리할 레코드를 선택해요.
   3. 먼저 필터를 적용하거나 스마트 리스트를 쓰면 특정 그룹으로 목록을 좁힐 수 있어요.
2. 일괄 작업 메뉴에서 **Trigger Automation**을 클릭해요.
3. 선택한 레코드를 보낼 워크플로우를 골라요.

   ![워크플로우 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079338378/original/YDhbo5nS6Q2wSPX5fOovjX7ByOMdAoQHBQ.png?1787743923)

4. 선택한 내용을 확인하고 작업을 확정해요. 선택한 레코드가 고른 워크플로우로 전달되어 처리돼요.
5. **일괄 작업**으로 이동해 진행 상황과 레코드별 상태를 확인해요.

   ![일괄 작업 진행 상황 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079338447/original/QpqdVpC8FAvS-nsbr5zeA-l5gsIvDnGsXw.png?1787743953)

## 사용 사례

### 1. 스마트 리스트 그룹에 워크플로우 실행하기

업종, 상태, 갱신일, 담당자 등 원하는 필드로 필터를 걸어 스마트 리스트를 만들어요. 그룹에 속한 레코드를 선택하고, 필요한 워크플로우를 한 번에 실행하세요.

### 2. 갱신 워크플로우 실행하기

갱신 시기가 다가온 정책, 구독, 계약, 멤버십 레코드를 필터로 찾아 갱신 워크플로우로 보내요.

### 3. 가져온 레코드 처리하기

회사나 사용자 지정 객체 레코드를 가져온 뒤, 해당 레코드를 선택해 온보딩, 연결, 정보 보강, 후속 조치 워크플로우를 실행해요.

### 4. 기존 레코드 다시 참여시키기

필터로 활동이 없는 회사나 다른 레코드를 찾아, 선택한 그룹에 재참여 유도 워크플로우를 실행해요.

### 5. 레코드 다시 처리하기

이전 자동화를 놓쳤거나 추가 처리가 필요한 레코드를 필터로 찾아, 워크플로우를 일괄로 다시 실행해요.

### 6. 일회성 운영 자동화 실행하기

필드 업데이트, 연결 만들기, 담당자 지정, 내부 팀 알림 같은 일회성 작업에 쓸 수 있어요. 워크플로우의 기존 트리거는 바꾸지 않아도 돼요.

## 자주 묻는 질문

### 자동화 일괄 실행을 하면 기존 워크플로우 트리거가 대체되나요?
아니요. 선택한 기존 레코드를 워크플로우에 수동으로 등록하는 방법이에요. 워크플로우의 기존 트리거 설정은 그대로 따로 작동할 수 있어요.

### 사용하려는 워크플로우가 보이지 않아요.
일괄 작업으로는 선택한 객체에 해당하는 워크플로우만 실행할 수 있어요. 워크플로우가 이미 만들어져 있고 게시된 상태여야 해요.

### 레코드별로 처리가 잘 됐는지 어디에서 확인하나요?
**일괄 작업**을 열어 해당 일괄 작업의 워크플로우 통계를 확인하세요. 결과에서 레코드별 상태를 볼 수 있어요.
