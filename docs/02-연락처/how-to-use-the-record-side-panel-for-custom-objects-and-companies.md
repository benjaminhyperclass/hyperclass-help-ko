# 회사·사용자 지정 객체의 레코드 사이드 패널 사용하기

레코드 사이드 패널은 회사나 사용자 지정 객체 레코드의 상세 정보, 연결된 항목, 활동 내역을 한 화면에 모아 보여 줘요. 레코드 목록을 벗어나지 않고 필드와 연결된 레코드를 확인하고, 대화를 시작하고, 예약을 만들거나 연결하고, 작업이나 메모를 추가할 수 있어요.

{% hint style="info" %}
비공개 베타: 새로 바뀐 사이드 패널은 비공개 베타에 포함된 서브 계정에서만 쓸 수 있어요. 서브 계정은 베타 신청 폼으로 추가돼요.
{% endhint %}

{% hint style="info" %}
요약: 회사 또는 사용자 지정 객체 레코드를 열고, 오른쪽 아이콘으로 **상세 정보**, **예약**, **연관**, **작업**, **메모**, **대화** 탭을 오가세요. 다음 작업은 해당 탭에서 시작하면 돼요. 패널 위쪽 화살표를 쓰면 패널을 닫지 않고 다른 레코드로 넘어갈 수 있어요.
{% endhint %}

---

## 레코드 사이드 패널이란?

레코드 사이드 패널은 회사 또는 사용자 지정 객체 레코드를 선택하면 목록 옆에 열리는 작업 공간이에요. 목록을 계속 보면서 선택한 레코드의 정보와 관련 활동을 확인할 수 있어요.

회사는 비즈니스 단위의 정보를 정리하는 레코드예요. 사용자 지정 객체는 부동산 매물, 보험 계약, 차량처럼 비즈니스에서 관리하는 다른 대상을 나타내려고 직접 만드는 객체예요. 둘 다 새 패널에서 레코드 상세 정보와 관련 작업을 함께 볼 수 있어요.

사용 예를 들어 볼게요.

- 계정 매니저는 회사 레코드를 열어 연결된 연락처를 확인하고 리뷰 미팅을 잡을 수 있어요.
- 부동산 중개인은 부동산 매물 레코드를 열어 구매 희망자를 확인하고, 문의에 답하고, 방문 일정을 예약할 수 있어요.
- 보험 설계사는 보험 계약 레코드를 열어 갱신 관련 대화를 확인하고 후속 작업을 만들 수 있어요.

## 레코드 사이드 패널의 장점

사이드 패널을 쓰면 한 레코드 안에서 정보를 확인하고 바로 다음 작업을 할 수 있어요.

- 맥락을 한곳에서 확인해요. 필드, 연결된 항목, 대화, 예약, 작업, 메모를 패널 하나에서 볼 수 있어요.
- 레코드를 떠나지 않고 작업해요. 대화를 시작하고, 예약을 만들거나 연결하고, 작업이나 메모를 추가하고, 기존 레코드를 연결할 수 있어요.
- 정보를 더 빨리 찾아요. 필드와 폴더를 검색하고, 빈 필드를 숨기고, 연결된 레코드를 상세 정보와 나란히 볼 수 있어요.
- 목록을 효율적으로 훑어요. 이전·다음 화살표로 같은 레이아웃에서 레코드 사이를 이동할 수 있어요.

## 레코드 사이드 패널 탭

패널 오른쪽에 세로로 놓인 아이콘을 눌러 탭을 전환해요.

| 탭 | 아이콘 | 할 수 있는 일 |
| --- | --- | --- |
| **상세 정보** | 객체별 아이콘(예: 건물, 집) | 레코드 필드를 확인하고, 연관을 간단히 보거나 추가해요. |
| **예약** | 캘린더 | 예정된 예약과 지난 예약을 확인하고, 미팅이나 서비스를 예약하고, 기존 예약을 연결해요. |
| **연관** | 서로 연결된 노드 | 객체 유형별로 묶인 관련 레코드를 확인하고, 연결을 추가하고, 연관 관리 화면으로 이동해요. |
| **작업** | 체크 표시가 있는 클립보드 | 작업을 확인하고 후속 작업을 만들어요. |
| **메모** | 연필 | 레코드에 대한 메모를 확인하고 추가해요. |
| **대화** | 말풍선 | 레코드와 연결된 메시지를 확인하고, 선택한 연락처와 대화를 시작해요. |

## 레코드 사이드 패널 여는 방법

작업할 레코드 목록에서 시작해요.

1. 열어 볼 레코드 목록으로 이동해요.

   - 회사: **CRM > 회사**로 이동해요.
   - 사용자 지정 객체: **CRM**에서 직접 만든 사용자 지정 객체 이름(예: 부동산 매물, 보험 계약)을 선택해요.
2. 레코드 이름을 클릭하면 사이드 패널이 열려요.

선택한 레코드가 오른쪽에 열리고, 뒤쪽에는 목록이 그대로 보여요.

![목록 옆에 레코드가 열린 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254300/original/uHHwtAWT1neUDdRmRfCnksSBkUnTFUJotg.png?1793051447)

## 필드 확인과 연결 관리

**상세 정보** 탭에서는 레코드 정보와 연관을 빠르게 다루는 기능을 함께 볼 수 있어요. 특정 필드를 찾고, 관련 레코드를 확인하고, 기존 연결을 추가할 때 쓰세요.

### 필드와 폴더 찾기

**필드 검색**으로 필요한 정보를 찾아요. 폴더를 펼치면 그 안의 필드를 볼 수 있고, 폴더 이름 옆에는 필드 개수가 표시돼요.

값이 들어 있는 필드만 보고 싶다면 **빈 필드 숨기기**를 켜세요. 아직 채우지 않은 필드까지 확인해야 할 때는 꺼 두세요.

### 상세 정보에서 연관 추가하기

**상세 정보** 탭의 연관 영역에는 연결된 레코드가 관계 레이블별로 표시돼요.

1. **연관** 영역에서 해당 관계 레이블을 찾아요.
2. 레이블 옆의 **+** 를 클릭해요.
3. 연결할 기존 레코드를 검색해서 선택해요.

이 영역에서 연결된 레코드를 바로 열 수도 있어요. **전체 보기**를 선택하면 전체 **연관** 탭이 열려요.

{% hint style="warning" %}
이 빠른 추가는 이미 있는 레코드를 연결하는 기능이에요. 회사나 사용자 지정 객체 레코드를 새로 만드는 기능과는 달라요.
{% endhint %}

### 전체 연관 목록 확인하기

오른쪽 아이콘에서 **연관**을 열면 관련 레코드가 객체 유형별로 묶여 있고, 그룹마다 개수가 표시돼요. 예를 들어 회사에는 연락처, 기회, 부동산 매물 그룹이 있을 수 있어요.

그룹 옆의 **추가**를 클릭하면 다른 기존 레코드를 연결할 수 있어요. 연관 관리 화면으로 가려면 **연결 관리**를 사용하세요.

객체 유형 사이의 관계와 레이블을 설정하는 방법은 '기회, 회사, 사용자 지정 객체 간 연관' 문서를 참고하세요.

## 대화 확인과 시작

**대화** 탭에는 현재 레코드와 연결된 메시지가 표시돼요. 회사, 부동산 매물, 보험 계약 같은 사용자 지정 객체 레코드를 보면서 관련 커뮤니케이션을 바로 확인할 수 있어요.

### 기존 메시지 확인하기

오른쪽 아이콘에서 **대화**를 열면 레코드와 연결된 메시지를 볼 수 있어요. 메시지에 답하려면 해당 메시지의 **답글**을 사용하세요.

### 대화 시작하기

1. **대화** 탭을 열어요.
2. 더하기 표시가 있는 파란색 메시지 버튼인 **대화 만들기**를 클릭해요.
3. 대화할 **연락처**를 선택해요.
4. 현재 레코드가 이미 연결된 상태로 메시지를 작성하고 보내요.

{% hint style="warning" %}
메시지를 받는 사람은 연락처예요. 회사나 사용자 지정 객체 레코드는 대화에 연결되는 맥락 역할을 해요.
{% endhint %}

예를 들어 부동산 매물 레코드에서 대화를 시작하면 연락할 구매 희망자를 선택해요. 매물은 이미 연결되어 있으므로, 대화가 논의 중인 매물과 이어져요.

## 예약 만들기와 연결하기

**예약** 탭에서는 예약 내역을 확인하고, 레코드에서 바로 다음 미팅이나 서비스를 잡을 수 있어요.

### 예약 확인하기

**예약**을 열고 **예정** 또는 **지난 이벤트**를 선택하면 해당 예약을 볼 수 있어요. 목록을 좁히려면 **캘린더 이름**으로 검색하세요.

### 예약 추가하기

**추가**를 클릭하고 작업에 맞는 옵션을 선택해요.

| 옵션 | 사용하는 경우 |
| --- | --- |
| **미팅** | 레코드에서 미팅을 예약할 때 |
| **서비스** | 레코드에서 서비스 예약을 잡을 때 |
| **기존 항목 연결** | 이미 잡힌 예약을 레코드에 연결할 때 |

선택한 옵션의 예약 또는 연결 과정을 끝까지 진행하세요.

{% hint style="info" %}
이미 있는 예약이라면 새로 예약을 만들지 말고 **기존 항목 연결**을 사용하세요. 같은 예약이 두 번 생기지 않아요.
{% endhint %}

## 작업과 메모 추가

끝내야 할 일은 **작업**에, 팀이 레코드를 이해하는 데 도움이 되는 정보는 **메모**에 남기세요.

### 작업 추가하기

**작업** 탭을 열고 **작업 추가**를 클릭해요. 제목, 담당자, 마감일 같은 작업 정보를 입력해요. **Associate To**(연결 대상) 필드에서 연결된 레코드가 맞는지 확인하고 **저장**을 클릭하세요.

작업은 회사, 사용자 지정 객체, 연락처, 기회와 연결할 수 있어요. 그래서 같은 후속 작업이 관련 레코드마다 이어져 있어요.

예를 들어 보험 계약 갱신을 챙기는 작업이나 회사의 다음 계정 리뷰를 준비하는 작업을 추가할 수 있어요.

### 메모 추가하기

**메모** 탭을 열고 **메모 추가**를 클릭해요. 남겨 둘 내용을 입력하고 **저장**을 클릭하세요. 메모에는 레코드와 관련된 변경 사항이나 팀에 필요한 맥락을 기록해 둘 수 있어요.

예를 들어 매물 방문 후 구매 희망자의 의견을 적거나, 갱신 논의 결과를 기록할 수 있어요.

## 레코드 이동과 레코드 작업 메뉴

패널 위쪽의 버튼으로 목록의 다른 레코드로 넘어가거나 레코드 단위 작업을 할 수 있어요.

### 레코드 사이 이동하기

패널 왼쪽 위의 이전·다음 화살표를 쓰면 사이드 패널을 닫았다 다시 열지 않고도 레코드를 차례로 넘길 수 있어요.

### 레코드 작업 메뉴 열기

패널 오른쪽 위의 점 세 개 메뉴를 클릭하면 다음 항목이 나와요.

- **레코드 ID 복사**: 선택한 레코드의 식별자를 복사해요.
- **감사 로그 보기**: 레코드의 변경 이력을 열어요.
- **삭제**: 선택한 레코드를 삭제해요.

{% hint style="warning" %}
**삭제**는 레코드 자체를 지우는 작업이에요. 레코드 사이의 연결만 바꾸려는 경우에는 사용하지 마세요.
{% endhint %}

## 자주 묻는 질문

### 새로 바뀐 사이드 패널이 안 보여요.

새 화면은 비공개 베타로 제공돼요. 이 문서에서 설명한 화면을 쓰려면 서브 계정이 베타에 포함되어 있어야 해요. 서브 계정은 베타 신청 폼으로 추가돼요.

### 회사나 사용자 지정 객체에 직접 메시지를 보내나요?

아니요. 패널에서 대화를 시작할 때는 받는 사람으로 연락처를 선택해요. 현재 회사 또는 사용자 지정 객체 레코드는 맥락을 알려 주려고 이미 연결되어 있어요.

### 대화 탭에는 어떤 메시지가 표시되나요?

현재 레코드와 연결된 메시지가 표시돼요. 해당 회사, 부동산 매물, 보험 계약 같은 사용자 지정 객체 레코드와 이어진 커뮤니케이션을 확인할 때 쓰세요.

### 전에 잡아 둔 예약을 연결할 수 있나요?

네, 가능해요. **예약 > 추가 > 기존 항목 연결**을 열고 연결 과정을 진행하세요. 예약을 새로 만들 필요는 없어요.

### 상세 정보에서 필드를 못 찾겠어요.

검색어를 확인하고, 해당 폴더를 펼치고, **빈 필드 숨기기**가 켜져 있는지 살펴보세요. 이 토글이 켜져 있으면 값이 없는 필드는 숨겨질 수 있어요.

### 빠른 연관 영역과 연관 탭은 어떻게 달라요?

빠른 연관 영역은 **상세 정보** 탭 안에 있어요. 연결된 레코드를 관계 레이블별로 보여 주고, 필드를 확인하면서 기존 레코드를 바로 추가할 수 있어요.

**연관** 탭에서는 객체 유형별로 묶인 전체 목록과 개수를 볼 수 있어요. **추가**와 **연결 관리** 버튼도 여기에 있어요.
