# 사용자 지정 객체 사이드 패널 사용하기

새로 바뀐 사이드 패널에서는 부동산 매물이나 보험 증권 같은 사용자 지정 객체 레코드를 열어 바로 작업할 수 있어요. 레코드의 필드, 연관 항목, 예약, 작업, 메모, 대화를 한곳에서 확인할 수 있어요. 패널을 닫지 않고도 대화를 시작하고, 예약을 잡거나 기존 예약을 연결하고, 연결된 레코드를 관리할 수 있어요. 레코드 목록은 뒤쪽에 그대로 열려 있어요.

{% hint style="info" %}
이 기능은 비공개 베타로만 제공돼요. 기능이 활성화된 서브 계정에서만 사용할 수 있어요.
{% endhint %}

## 레코드를 작업 허브로 쓰기

각 탭에서 내용을 확인하는 것은 물론 바로 작업까지 할 수 있어서, 레코드가 팀의 작업 공간이 돼요.

- 부동산 매물: 매물의 잠재 구매자, 방문 예약, 문의를 해당 매물 레코드에 모아 두세요.
- 보험 증권: 계약자, 갱신 관련 대화, 작업, 메모를 해당 증권에 함께 보관하세요.
- 그 밖의 모든 사용자 지정 객체: 호실, 반려동물, 차량처럼 객체가 관리하는 대상이 무엇이든 같은 탭을 그대로 쓸 수 있어요.

---

## 레코드 열기

1. 왼쪽 사이드바에서 사용자 지정 객체를 선택한 다음, 목록에서 레코드를 클릭하세요.

레코드가 사이드 패널에서 열려요. 패널 위쪽의 화살표를 누르면 현재 목록에서 이전 또는 다음 레코드로 이동해요. **닫기**를 클릭하면 목록으로 돌아가요.

---

## 레코드 상세 정보 확인하기

**상세 정보** 탭에는 레코드 이름, **소유자**와 **팔로워**, 연관 항목, 필드가 표시돼요.

- **연관**: 연결된 레코드를 관계별로 묶어서 볼 수 있어요. 관계 옆의 추가 아이콘을 클릭하면 연관 항목 선택 창이 열려요. **전체 보기**가 보이면 클릭해서 더 많은 연관 항목을 확인하세요.
- **필드 검색**: 전체 레코드를 스크롤하지 않고도 필드나 폴더를 바로 찾을 수 있어요.
- **빈 필드 숨기기**: 값이 있는 필드만 모아서 볼 수 있어요.
- 폴더와 개수: 폴더를 펼치면 그 안의 필드와 필드 개수를 확인할 수 있어요.
- **필드 편집**: 필드 값을 클릭하면 편집 창이 열려요.

1단계: 부동산 매물 같은 사용자 지정 객체를 열고 레코드를 클릭하세요.

## 탭 전환하기

패널 오른쪽 가장자리의 아이콘으로 탭을 전환해요.

| **탭** | **용도** |
| --- | --- |
| **상세 정보** | 레코드의 필드와 연관 항목을 확인해요 |
| **예약** | 레코드에 연결된 예약을 확인하고, 예약을 잡거나 기존 예약을 연결해요 |
| **연관** | 레코드의 연관 섹션을 열어요 |
| **작업** | 레코드의 작업 섹션을 열어요 |
| **메모** | 레코드의 메모 섹션을 열어요 |
| **대화** | 레코드와 연결된 대화를 확인하거나 새로 만들어요 |

---

## 대화 사용하기

1. 레코드를 열고 **대화**를 선택하세요.
2. 대화 목록을 확인하세요. 연결된 대화가 없으면 빈 화면이 표시돼요.
3. **대화 만들기** 또는 **새 대화 만들기**를 클릭하세요.
4. **연락처**를 선택하세요. 현재 레코드는 이미 **연결됨**으로 표시돼 있어요.
5. **대화 만들기**를 클릭해 계속 진행하세요.

연락처는 대화에 참여하는 사람이에요. 연결된 레코드는 그 대화가 어떤 사용자 지정 객체와 관련된 것인지 알려 줘요.

6단계: **대화**에서 **대화 만들기**를 클릭하세요. 레코드는 이미 **연결됨** 상태예요. **연락처**를 선택하고 계속 진행하세요.

![6단계: 대화 탭에서 대화 만들기 후 연락처 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084158141/original/mAqDqMBJU5TkVP-Q57_4ZHD6jlzi0e0BSw.png?1792994204)

## 예약 사용하기

1. 레코드를 열고 **예약**을 선택하세요.
2. **예정**과 **지난 이벤트** 사이를 전환하세요.
3. **캘린더 이름**으로 검색해서 예약을 찾으세요.
4. **추가**를 클릭한 뒤 **미팅**, **서비스**, **기존 항목 연결** 중에서 선택하세요.

7단계: **예약**에서 **추가**를 클릭한 다음 **미팅**, **서비스**, **기존 항목 연결** 중 하나를 선택하세요.

![7단계: 예약 탭에서 추가 메뉴 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084158139/original/NuGq7vPnJxJrU0JmhGyvwkJxPMgC1KTLmw.png?1792994205)

---

### 미팅 예약하기

1. **추가 > 미팅**을 선택하세요.
2. 캘린더, 예약 상세 정보, 날짜, 시간, **연락처**를 선택하세요.
3. **연결된 객체**를 확인하세요. 현재 레코드가 미리 선택돼 있어요.
4. 나머지 예약 정보를 확인한 다음 **예약하기**를 선택하세요.

8단계: 미팅을 예약할 때 **연결된 객체**를 열어 현재 레코드가 미리 선택돼 있는지 확인하세요.

![8단계: 연결된 객체에서 현재 레코드가 미리 선택됐는지 확인하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084158145/original/tCL7lLTmuDiygCRyHenDXaX66kwgi4AC4w.png?1792994204)

---

### 기존 예약 연결하기

1. **추가 > 기존 항목 연결**을 선택하세요.
2. 현재 서브 계정에 있는 예약을 검색하세요.
3. 이 레코드에 연결하려는 예약 옆의 **링크**를 선택하세요.

9단계: 이미 만들어 둔 예약을 쓰려면 **기존 항목 연결**을 선택하고 검색한 다음 **링크**를 클릭하세요.

![9단계: 기존 항목 연결에서 예약 검색 후 링크 클릭하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084158140/original/sd6Rff5eu74-9JZaGFbvFoNsiLAMILrZjA.png?1792994204)

## 레코드 작업

패널 위쪽의 점 3개 메뉴를 열면 **레코드 ID 복사**, **감사 로그 보기**, **삭제**를 선택할 수 있어요.

## 자주 묻는 질문

### 대화 탭이 비어 있는 이유가 뭔가요?

선택한 레코드의 대화 목록에 대화가 없기 때문이에요. **대화 만들기**를 클릭하고 **연락처**를 선택하면 바로 대화를 시작할 수 있어요.

### 이미 만들어 둔 예약을 연결할 수 있나요?

네, 할 수 있어요. **예약 > 추가 > 기존 항목 연결**을 선택하고 예약을 검색한 다음, 해당 예약 옆의 **링크**를 선택하세요.

### 왜 연락처를 꼭 선택해야 하나요?

대화를 만들려면 **연락처**를 선택해야 해요. 현재 레코드는 대화의 맥락을 알려 주려고 따로 연결돼요. 미팅 예약 폼에서도 **연락처**를 선택해야 해요.

### 이 패널에 기회 파이프라인 컨트롤이나 결제 탭도 있나요?

사용자 지정 객체 패널의 탭은 **상세 정보**, **예약**, **연관**, **작업**, **메모**, **대화**, 이렇게 6개예요. 기회 관련 파이프라인 컨트롤과 **결제** 탭은 이 패널에 없어요.
