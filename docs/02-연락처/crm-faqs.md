# CRM 자주 묻는 질문

새 서브 계정에 들어 있는 CRM 샘플 데이터에 대한 질문과 답을 모았어요. 샘플 데이터를 지울 수 있는지, 어떤 서브 계정에 들어가는지, 어떻게 알아볼 수 있는지 확인해 보세요.

## CRM 샘플 데이터

### 새 서브 계정에 들어 있는 샘플 데이터를 삭제하거나 수정할 수 있나요?

네, 샘플 데이터는 언제든 쉽게 수정하거나 삭제할 수 있어요.

### 서브 계정에 기본 파이프라인이 설정되어 있지 않으면 어떻게 되나요?

서브 계정에 기본 파이프라인이 없으면 샘플 기회와 파이프라인은 만들어지지 않아요. 다만 연락처, 작업, 메모, 회사, 태그의 샘플 데이터는 그대로 받을 수 있어요.

### 이미 만들어 둔 서브 계정에도 샘플 데이터가 들어오나요?

아니요, 기존 서브 계정은 그대로 유지돼요. 이 기능은 새로 만든 서브 계정에만 적용돼요.

### CRM에서 샘플 데이터는 어떻게 구분하나요?

모든 샘플 데이터 레코드 앞에는 "(Example)"(예시)이 붙어 있어요. 이 표시로 직접 입력한 실제 데이터와 구분할 수 있어요.
