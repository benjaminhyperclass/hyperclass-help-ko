# 사용자 지정 객체 레코드를 연관과 함께 가져오기

CSV 파일로 사용자 지정 객체 레코드를 가져오면서, 기존 연락처·회사·기회·다른 사용자 지정 객체와 자동으로 연결하는 방법을 설명해요. 워크플로우 액션 **Associate Records**(레코드 연결)를 사용해요.

## 개요

**Custom Object Bulk Import**(사용자 지정 객체 대량 가져오기)와 워크플로우 액션 **Associate Records**를 함께 쓰면, 사용자 지정 객체 레코드를 가져오는 동시에 연관을 자동으로 만들 수 있어요.

예를 들어 Pet(반려동물) 레코드를 가져올 때 CSV에 주인의 이메일 주소를 넣어 두세요. Pet 레코드가 만들어지면 워크플로우가 이 이메일 주소로 일치하는 연락처를 찾아, Pet과 주인을 연결해 줘요.

다른 시스템에서 데이터를 옮길 때 특히 편해요. 레코드를 가져온 뒤에 하나씩 직접 연결하지 않아도 CRM 연관이 만들어지거든요.

{% hint style="warning" %}
가져오기를 시작하기 전에 워크플로우를 먼저 만들고 게시하세요.
{% endhint %}

---

## 시작 전 확인할 점과 제한 사항

가져오기를 시작하기 전에 아래 내용을 확인하세요.

- 사용자 지정 객체와 필요한 필드가 만들어져 있어야 해요.
- 사용자 지정 객체와 연결할 대상 오브젝트 사이에 연관이 있어야 해요.
- CSV에 일치하는 레코드를 찾는 데 쓸 값이 들어 있어야 해요.
- 가져오기를 시작하기 전에 워크플로우를 만들고 게시해야 해요.

### 믿을 수 있는 매칭 필드 고르기

가져오는 사용자 지정 객체에는 대상 레코드의 필드와 비교할 수 있는 필드가 있어야 해요.

추천하는 매칭 필드는 다음과 같아요.

- 이메일
- 전화번호
- 고객 ID
- 계좌 번호
- 외부 시스템 ID

가능하면 고유하고 바뀌지 않는 식별 값을 쓰세요. 같은 이름의 레코드가 여러 개일 수 있으니, 이름만으로 일치 조건을 만드는 건 피하세요.

### 연관 한도는 그대로 적용돼요

**Associate Records** 액션은 두 오브젝트 사이에 설정된 연관 한도를 따라요.

일치하는 레코드를 모두 연결하려면, 설정된 연관 한도가 예상하는 연관 개수를 감당할 수 있는지 확인하세요.

## 연관과 함께 가져오는 방식

가져오기와 워크플로우 기능을 함께 사용해요. 순서는 다음과 같아요.

1. CSV를 가져오면 사용자 지정 객체 레코드가 만들어져요.
2. 새 레코드가 해당 사용자 지정 객체의 워크플로우에 들어가요.
3. **Associate Records** 액션이 가져온 값으로 일치하는 레코드를 검색해요.
4. 워크플로우가 선택한 연관 레이블로 연관을 만들어요.

### 예시

Pet CSV에 아래 값이 들어 있어요.

- **Pet Name**(반려동물 이름): Milo
- **Species**(종): Dog
- **Owner Email**(주인 이메일): [alex@example.com](mailto:alex@example.com)

워크플로우는 아래 조건에 맞는 연락처를 찾도록 설정해요.

- **연락처 이메일**이 **Pet Owner Email**과 같은 연락처

결과는 다음과 같아요.

**Milo → Pet Owner → Alex**

## 가져오기와 연관 만들기 순서

### 1단계: 필요한 연관 만들기

워크플로우를 만들기 전에 사용자 지정 객체와 대상 오브젝트 사이의 연관을 먼저 설정하세요.

다음 경로로 이동하세요.

**설정 > 오브젝트** 에서 해당 사용자 지정 객체를 선택한 다음 **연관**

예를 들면 이렇게 설정해요.

- **오브젝트**: Pet
- **연결된 오브젝트**: **연락처**
- **Association Label**(연관 레이블): Pet Owner

---

### 2단계: CSV 준비하기

CSV에는 다음 두 가지를 넣으세요.

1. 사용자 지정 객체 레코드를 만드는 데 필요한 데이터
2. 워크플로우가 연결할 레코드를 찾는 데 쓸 값

Pet 가져오기라면 CSV에 이런 열을 넣을 수 있어요.

- Pet Name
- Species
- Breed(품종)
- **생년월일**
- Owner Email

레코드 예시는 다음과 같아요.

- **Pet Name**: Milo
- **Species**: Dog
- **Owner Email**: [alex@example.com](mailto:alex@example.com)

Pet 사용자 지정 객체에 **Owner Email** 필드를 만들고, 가져올 때 CSV의 해당 열을 이 필드에 매핑하세요. 그러면 워크플로우가 가져온 값으로 일치하는 연락처를 찾을 수 있어요.

![Owner Email이 포함된 Pet CSV 샘플](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082099923/original/r-xp_t9zUy3bBaV3ReUqDAD3AJ_T0KDQtA.png?1790683004)

---

### 3단계: 워크플로우 만들기

**자동화 > 워크플로우**로 이동해, 가져올 사용자 지정 객체용 워크플로우를 만드세요.

Pet 예시라면 이렇게 해요.

1. Pet 워크플로우를 만들어요.
2. **Pet Record Created**(Pet 레코드 생성됨) 트리거를 추가해요.
3. **Associate Records**(레코드 연결) 액션을 추가해요.
4. **Create Association With**(연결할 대상)에서 **Contact**(연락처)를 선택해요.
5. 일치 조건이 되는 필터를 추가해요.
6. 일치하는 레코드가 여러 개일 때 어떻게 처리할지 선택해요.
7. 연관 레이블을 선택해요.
8. 워크플로우를 게시해요.

#### 설정 예시

- 워크플로우 오브젝트: Pet
- **Trigger**(트리거): Pet Record Created
- **Create Association With**: Contact
- 필터: **연락처 이메일**이 Pet Owner Email과 같음
- **Association Label**: Pet Owner

![Pet 워크플로우 설정 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082100076/original/ZP5TgTO_fal2bV4z7RS2UrzW4SNcGwk-Qw.png?1790683095)

#### 필터 여러 개 사용하기

값 하나만으로는 믿기 어렵다면 필터를 두 개 이상 쓸 수 있어요.

예를 들면 이런 조건이에요.

- **연락처 이메일**이 Pet Owner Email과 같음
- **연락처 전화번호**가 Pet Owner Phone과 같음

필터를 여러 개 설정하면 대상 레코드가 모든 조건을 충족해야 해요.

---

### 4단계: 사용자 지정 객체 레코드 가져오기

워크플로우를 게시한 뒤 아래 순서로 진행하세요.

1. 해당 사용자 지정 객체를 열어요.
2. **가져오기**를 클릭해요.
3. **CSV 파일 업로드**로 CSV 파일을 올려요.
4. CSV 열을 알맞은 사용자 지정 객체 필드에 매핑해요.
5. 매핑이 맞는지 확인해요.
6. 가져오기를 시작해요.
7. **일괄 작업**에서 가져오기 진행 상황을 확인해요.

사용자 지정 객체 레코드가 하나씩 만들어질 때마다 워크플로우에 들어가요. 그러면 워크플로우가 일치하는 레코드를 검색해 연관을 만들어요.

![사용자 지정 객체 가져오기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082100658/original/gJ_IDKtH-mVUoZ76sUsWsQdTyjeekUveog.png?1790683384)

---

### 5단계: 연관 확인하기

가져오기가 끝나면 다음과 같이 확인하세요.

1. 가져온 사용자 지정 객체 레코드 몇 개를 열어요.
2. 연결된 레코드를 확인해요.
3. 예상한 연관 레이블이 적용됐는지 확인해요.
4. 연관이 만들어지지 않은 레코드는 **Workflow Execution Logs**(워크플로우 실행 로그)에서 확인해요.

![워크플로우 실행 로그 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082100676/original/6ceqr2_Z9j8EncyVIWimwYKzhqtBBqackw.png?1790683403)

### 예시: Pet을 가져와 주인과 연결하기

동물병원에서 다른 시스템의 Pet 데이터를 옮기는 상황이에요.

주인 연락처는 이미 CRM에 있어요.

Pet CSV에는 이런 정보가 들어 있어요.

- Pet Name
- Species
- Owner Email

예를 들면 이래요.

- **Milo**
- **Dog**
- **[alex@example.com](mailto:alex@example.com)**

Milo를 가져오면 아래 순서로 처리돼요.

1. **Milo**라는 Pet 레코드가 만들어져요.
2. 워크플로우가 **Owner Email** 필드를 읽어요.
3. 이메일 주소가 같은 연락처를 찾아요.
4. **Pet Owner** 연관 레이블로 Milo와 그 연락처를 연결해요.

가져온 Pet 레코드마다 직접 연결하지 않아도 돼요.

## 활용 사례

### 보험 증권과 계약자

계약자 이메일이나 고객 ID가 들어 있는 Policy(보험 증권) 레코드를 가져온 뒤, 각 Policy를 알맞은 연락처에 연결해요.

예시:

**계약자 이메일 → 연락처 이메일**

---

### 부동산과 소유자

소유자 이메일이나 계좌 번호가 들어 있는 Property(부동산) 레코드를 가져온 뒤, 각 Property를 일치하는 연락처나 회사에 연결해요.

예시:

**소유자 계좌 번호 → 회사 계좌 번호**

---

### 차량과 고객

고객 ID가 들어 있는 Vehicle(차량) 레코드를 가져온 뒤, 각 Vehicle을 일치하는 연락처에 연결해요.

---

### 이벤트 등록과 참석자

참석자 이메일이 들어 있는 Registration(등록) 레코드를 가져온 뒤, 각 Registration을 일치하는 연락처에 연결해요.

---

### 자산과 회사

회사 계좌 번호가 들어 있는 Asset(자산) 레코드를 가져온 뒤, 각 Asset을 알맞은 회사에 연결해요.

---

### 거래와 연락처

고객 이메일, 전화번호, 고객 ID가 들어 있는 Transaction(거래) 레코드를 가져온 뒤, 각 Transaction을 알맞은 연락처에 연결해요.

---

## 모범 사례

- 작은 CSV로 먼저 테스트하세요. 워크플로우가 예상한 연관을 만드는지 확인한 뒤에 전체 데이터를 가져오세요.
- 바뀌지 않는 식별 값을 쓰세요. 이름보다 이메일, 전화번호, 고객 ID, 계좌 번호, 외부 ID가 좋아요.
- 필요하면 필터를 여러 개 쓰세요. 필드 하나가 고유하지 않을 때 잘못 연결되는 일을 줄일 수 있어요.
- 연관 한도를 확인하세요. 만들려는 연관 개수를 두 오브젝트의 관계가 지원하는지 살펴보세요.
- 가져오기 결과와 워크플로우 결과를 모두 확인하세요. CSV 가져오기와 연관 워크플로우는 서로 별개의 과정이에요.

{% hint style="warning" %}
워크플로우가 일치하는 레코드를 찾지 못해도 가져오기 자체는 성공으로 끝날 수 있어요.
{% endhint %}
