# 여러 연락처에 태그 한 번에 추가하기

이 아티클에서는 "태그 추가(Add Tags)" 기능을 사용해서 여러 연락처에 빠르게 태그를 적용하는 방법을 알려드릴게요. 라이프사이클 단계별로 리드를 정리하든, 캠페인을 위해 사용자를 세그먼트하든, 자동화를 위해 연락처를 표시하든, 일괄 태그 추가(Bulk Tagging) 기능을 사용하면 수작업으로 할 때보다 몇 시간을 절약할 수 있어요. 태그가 무엇인지, 왜 중요한지, 그리고 몇 번의 클릭만으로 어떻게 사용하는지 차근차근 설명해 드릴게요.

# 여러 연락처에 태그 추가란 무엇인가요

태그를 일괄로 추가하면 대량의 연락처를 효율적으로 라벨링하고 정리할 수 있어요. 태그(Tag)는 공통된 특성, 행동, 또는 고객 여정 단계를 기준으로 연락처를 분류하는 데 도움을 줍니다. 이 기능은 대상을 세그먼트하고, 자동화를 트리거(Trigger)하고, CRM 워크플로우(Workflow)를 대규모로 관리하는 데 필수적이에요.

## 여러 연락처에 태그를 추가하는 방법

이 섹션에서는 연락처(Contacts) 페이지에서 여러 연락처에 태그를 적용하는 정확한 방법을 단계별로 안내해 드릴게요.

- 좌측 네비게이션 메뉴에서 연락처 메뉴로 이동하세요.

- 왼쪽에 있는 체크박스를 사용해서 태그를 추가하고 싶은 연락처를 선택하세요. 원하는 만큼 레코드를 선택할 수 있어요.

- 연락처를 선택한 후, 화면 상단 작업 바에서 태그 추가(Add Tag) 아이콘을 클릭하세요.

- "태그 추가(Add Tags)" 팝업 창이 뜨면, Action Name(작업 이름) 필드에 이 작업의 이름을 입력하세요. 그 다음, 태그(Tags) 필드의 드롭다운을 클릭해서 목록에서 하나 이상의 태그를 선택하세요.

- 태그를 선택한 후, **Add Tags** 버튼을 클릭하면 작업이 시작돼요. 확인 메시지가 표시됩니다.

- Add Tags를 클릭한 직후 이 확인 팝업이 나타나요. 선택한 연락처에 대한 태그 지정 작업이 진행 중이라는 것을 알려줍니다. 작업 진행 상황을 확인하려면 Check Progress 버튼을 클릭하면 **일괄 작업(Bulk Actions)** 탭으로 이동해서 작업의 성공/실패 여부를 실시간으로 추적할 수 있어요.

- 강조 표시된 영역은 일괄 태그 작업이 성공적으로 완료되었음을 보여줘요. 작업 이름, 수행한 사람, 생성 시점, 그리고 결과를 확인할 수 있는 "Show Stats" 링크를 볼 수 있어요. 이를 통해 모든 작업이 예상대로 적용됐는지 확인할 수 있습니다.

## **자주 묻는 질문**

**Q: 한 연락처에 여러 개의 태그를 한 번에 적용할 수 있나요?**

네, 하나의 일괄 작업에서 여러 태그를 동시에 선택하고 적용할 수 있어요. 작업을 제출하기 전에 태그(Tags) 필드에 원하는 태그를 모두 추가하기만 하면 됩니다.

**Q: 이 작업이 연락처에 있던 기존 태그를 덮어쓰나요?**

아니요, 태그를 일괄로 추가하면 선택한 태그가 연락처의 기존 태그 목록에 추가될 뿐이에요. 기존에 있던 태그를 삭제하지는 않습니다.

**Q: 태그를 자동화의 트리거로 사용할 수 있나요?**

물론이에요. 태그는 하이퍼클래스 자동화에서 워크플로우 트리거로 자주 사용되며, 태그가 추가되거나 제거될 때 시퀀스를 실행할 수 있어요.

**Q: 일괄로 적용한 태그를 취소하거나 제거하려면 어떻게 하나요?**

연락처에서 태그를 제거하려면 "태그 제거(Remove Tag)" 일괄 작업을 사용하세요. 특정 태그만 제거하거나 선택한 연락처의 모든 태그를 지울 수 있어요. 이 내용은 별도의 아티클에서 다룰 예정이에요.

**Q: 어떤 연락처에 태그가 성공적으로 추가됐는지 확인할 수 있나요?**

네. 일괄 작업(Bulk Actions) 탭으로 이동해서 해당 작업 옆의 "Show Stats"를 클릭하세요. 이 화면에서 각 태그 지정 건의 성공 여부, 연락처 식별 정보, 타임스탬프를 확인할 수 있어요.
