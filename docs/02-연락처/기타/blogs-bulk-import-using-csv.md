# CSV로 블로그 게시물 한 번에 가져오기

CSV 블로그 가져오기 도구로 여러 개의 블로그 게시물을 한 번에 가져오는 방법을 안내해요. 스프레드시트 파일을 끌어다 놓고, 게시물마다 미리 본 뒤 게시·예약·임시 저장 중에서 고를 수 있어요. Blogger, Wix, WordPress 등 CSV 내보내기를 지원하는 플랫폼에서 옮겨 오는 에이전시에도 잘 맞아요.

---

## CSV 블로그 가져오기란?

CSV 블로그 가져오기는 하이퍼클래스 **블로그**(Blogs) 안에 있는 대량 업로드 도구예요. 형식에 맞게 작성한 CSV 또는 Excel 파일을 바로 게시할 수 있는 블로그 게시물로 바꿔 줘요.

파일의 헤더를 검증하고, 작성자와 카테고리를 자동으로 맞춰 줘요. 3단계 검토 과정도 안내해 줘서 복사해 붙여 넣는 수작업이 거의 필요 없어요.

---

## 이럴 때 좋아요

- 간편한 이전: 다른 플랫폼의 콘텐츠를 직접 복사해 옮기는 번거로움이 없어요.
- 대량 가져오기: 파일 하나에 게시물을 최대 60개까지 담아 올릴 수 있어서 초기 세팅이 빨라져요.
- 자동 정리: 작성자와 카테고리를 자동으로 만들거나 기존 항목과 맞춰 줘서 따로 정리할 일이 줄어요.
- 유연한 예약: 업로드한 파일의 `Publish Date`(게시일) 값을 하이퍼클래스가 자동으로 읽어 게시 상태를 정해요.
- SEO 미리보기: 게시하기 전에 제목, 메타 설명, 소셜 이미지를 확인할 수 있어요.
- 오류 없는 준비: 샘플 CSV를 내려받아 쓰면 헤더나 형식 실수를 막을 수 있어요.
- 즉시 검증: 누락되거나 잘못된 데이터를 오류 메시지로 바로 알려 줘요.

---

## 알아 두세요

- 자동 검증: 파일을 올리면 CSV 헤더를 확인해서 빠졌거나 철자가 틀린 항목을 알려 줘요. 바로 고칠 수 있어요.
- 필수 항목: 필수 헤더는 모두 있어야 해요. 다만 각 칸의 값은 비워 둘 수 있어요.
- 오류 표시: 이미지 누락, 잘못된 날짜, 너무 긴 메타 설명 같은 문제는 해당 위치에 오류 표시로 나타나요.
- 스마트 스케줄링: 과거 날짜는 **게시됨**, 미래 날짜는 **예약됨**, 날짜가 비어 있으면 **임시 저장**으로 가져와요.
- 파일 크기: 브라우저 시간 초과를 피하려면 파일을 25MB 미만으로 유지하세요. 더 큰 파일은 여러 개로 나눠 올리세요.
- CSV 서식: 형식이 맞지 않는 파일은 고칠 때까지 오류 메시지가 표시돼요.
- 시간대 처리: 서브 계정의 시간대를 기준으로 처리하므로 게시물이 현지 시간에 맞게 게시돼요.

## CSV 블로그 가져오기 사용 방법

### 1단계: 블로그 열고 대상 블로그 선택하기

1. 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **사이트 > 블로그**를 클릭하세요.

   ![사이트 메뉴에서 블로그 선택](https://jumpshare.com/share/ZinFPo1RVnGZCTMRniu4+/Screen+Shot+2025-10-06+at+5.31.49+PM.png)
3. 새 블로그 사이트를 만들려면 **Create Blog**(블로그 만들기) 드롭다운을 클릭한 뒤 **Create a blog**(블로그 만들기) 또는 **Create a Blog from Templates**(템플릿으로 블로그 만들기)를 선택하세요.
4. 기존 블로그를 쓰려면 블로그 사이트 이름을 클릭해 여세요.

   ![블로그 사이트 열기](https://jumpshare.com/share/9REccb1888mfPVeLhq1g+/GIF+Recording+2025-10-06+at+5.51.05+PM.gif)

### 2단계: CSV 가져오기 시작하기

1. **새 게시물** 드롭다운을 클릭하세요.
2. **Import Blog Post from CSV**(CSV에서 블로그 게시물 가져오기)를 선택하세요.

   ![CSV에서 블로그 게시물 가져오기 선택](https://jumpshare.com/share/rFQDvrSv5q52S7owU4L3+/Screen+Shot+2025-10-06+at+6.17.22+PM.png)

### 3단계: 파일 준비하고 업로드하기

1. **샘플 다운로드**를 클릭하세요. 내려받은 CSV 또는 XLSX 템플릿에 내용을 채우면 헤더가 맞지 않는 문제를 피할 수 있어요.

   ![샘플 다운로드 버튼](https://jumpshare.com/share/JBpiBZHh2eesb3OXfpWx+/Screen+Shot+2025-10-06+at+6.22.04+PM.png)
2. **클릭하여 업로드**를 누르거나 파일을 **Drag & Drop**(끌어다 놓기) 영역에 끌어다 놓아 준비한 파일을 선택하세요.

   ![파일 업로드](https://jumpshare.com/share/o4bLxrXRbgwCKkYPrKCA+/GIF+Recording+2025-10-06+at+6.33.56+PM.gif)
3. **파일 요약**(파일 이름, 전체 게시물 수)을 확인하세요.
4. **서식 지정 팁**을 읽어 보세요.
5. **계속**을 클릭하세요.

   ![파일 요약과 계속 버튼](https://jumpshare.com/share/duunvK3U2jGc4718cuLQ+/Screen+Shot+2025-10-06+at+6.40.11+PM.png)

### 4단계: 게시물 미리보기, 편집, 예약하기

1. 블로그 카드를 클릭하면 **미리보기**가 열려요. 데스크톱 화면과 모바일 화면을 모두 확인하세요.
2. 연필 아이콘을 클릭해 필요한 내용을 편집하세요.
3. 날짜 선택기로 **Publish/Schedule date**(게시/예약 날짜)를 정하세요.

   - 과거 날짜 → **게시됨**으로 가져와요.
   - 미래 날짜 → **예약됨**으로 가져와요.
   - 날짜 비어 있음 → **임시 저장**으로 가져와요.

{% hint style="info" %}
잘못된 날짜는 실수로 게시되는 일이 없도록 **임시 저장**으로 바뀌어요.
{% endhint %}

![게시물 미리보기, 편집, 날짜 설정](https://jumpshare.com/share/D1YqRuPC3Xvd1EenQ23Q+/GIF+Recording+2025-10-06+at+6.59.47+PM.gif)

### 5단계: 가져오기 실행하고 확인하기

1. **가져오기**를 클릭하세요.

   ![가져오기 버튼](https://jumpshare.com/share/JyaHfuT5HGJimwAS2kvW+/Screen+Shot+2025-10-06+at+7.08.03+PM.png)
2. 확인 창에서 요약을 확인하세요. 예를 들어 게시됨 1개, 임시 저장 1개처럼 상태별 개수가 표시돼요.
3. **가져오기**를 한 번 더 클릭해 확정하세요.

   ![가져오기 확인 창](https://jumpshare.com/share/foSNSJ3iTWv9CsEiwXeP+/Screen+Shot+2025-10-06+at+7.10.23+PM.png)

{% hint style="info" %}
**오류가 있는 게시물 (행별 리포트)**

검토 중 검증에 실패한 행이 있으면 **오류가 있는 게시물**을 열어 무엇이 왜 실패했는지 행별 리포트를 확인하세요.

실패한 행마다 다음 정보가 표시돼요.

- 게시물 제목(또는 행 식별자)
- 검증에 실패한 필드
- 무엇을 고쳐야 하는지 알려 주는 검증 메시지
{% endhint %}

## 자주 묻는 질문

### 한 번에 가져올 수 있는 게시물은 최대 몇 개인가요?
CSV/XLSX 파일 하나당 최대 60개예요.

### 이미지도 자동으로 내려받아 저장해 주나요?
네. 인터넷에서 누구나 접근할 수 있는 전체 이미지 URL이나 상대 경로를 넣어 주세요. 하이퍼클래스가 이미지를 가져와 저장해요.

### 가져온 뒤에도 게시물을 편집할 수 있나요?
네, 가능해요. 가져온 게시물은 다른 블로그 게시물과 똑같아요. 편집기를 열어 내용을 수정한 뒤 다시 게시하면 돼요.

### 제목이 같은 게시물을 다시 가져오면 어떻게 되나요?
**임시 저장** 상태의 새 게시물이 만들어져요. 중복 게시물은 자동으로 합쳐지지 않아요.

### 파일 크기에 제한이 있나요?
브라우저 시간 초과를 피하려면 파일을 25MB 미만으로 유지하세요. 더 큰 파일은 여러 개로 나눠 올리면 가장 잘 처리돼요.

### 임시 저장 게시물도 60개 제한에 포함되나요?
네. 최종 상태와 관계없이 CSV의 모든 행이 60행 제한에 포함돼요.

### 가져오기를 되돌릴 수 있나요?
한 번에 되돌리는 기능은 없어요. 가져온 게시물을 직접 삭제하거나 블로그 게시물 목록에서 일괄 삭제를 사용하세요.

### CSV에 없는 작성자나 카테고리는 어떻게 되나요?
가져오는 과정에서 시스템이 자동으로 만들어요.

### 게시일을 비워 두면 어떻게 되나요?
게시물이 **임시 저장** 상태로 가져와져요.

### 오류가 있으면 CSV를 다시 올릴 수 있나요?
네. 파일의 오류를 고친 뒤 언제든 다시 올릴 수 있어요.

### 어떤 플랫폼에서 옮겨 올 수 있나요?
구조화된 콘텐츠를 CSV나 Excel로 내보낼 수 있는 플랫폼이면 모두 가능해요. 예를 들면 Blogger, Wix, WordPress 등이 있어요.

### 실패한 오류를 해결하고 다시 시도하려면 어떻게 하나요?
**오류가 있는 게시물**을 여세요. 실패한 행을 선택해 메시지를 확인하세요. 행을 바로 수정할 수 있으면 수정하고, 그렇지 않으면 원본 CSV/XLSX 파일을 고친 뒤 다시 올리세요. 오류를 해결한 다음 가져오기를 다시 시도하세요.
