# 사용자 지정 객체의 고유 필드 지원

고유 필드 기능을 쓰면 사용자 지정 객체의 모든 레코드에서 특정 필드 값이 겹치지 않게 관리할 수 있어요. 데이터가 꼬이거나 중복되는 일을 막고, ID나 참조 번호가 실수로 다시 쓰이지 않게 해 줘요. 이 문서에서는 사용자 지정 객체에서 고유 필드를 쓰는 방법을 안내해요.

## 사용자 지정 객체의 고유 필드란?

고유 필드는 사용자 지정 객체의 일부 필드에 켤 수 있는 데이터 무결성 설정이에요. 필드를 고유로 지정하면 하이퍼클래스가 새 레코드나 수정된 레코드를 모두 확인해요. 같은 서브 계정 안에 이미 있는 값은 입력할 수 없게 막아요. 그래서 사용자 지정 객체의 레코드가 항상 겹치지 않게 유지되고, 나중에 번거로운 중복 정리 작업을 하지 않아도 돼요.

## 고유 필드의 장점

- 중복 방지: 레코드를 만들거나 수정할 때 고유 필드를 검사해요. 화면(UI), 폼, 워크플로우, 가져오기, API 어디에서 입력하든 같은 값은 막혀요.
- 정확한 리포팅: 레코드가 일대일로 정확하게 대응되어서 대시보드, 어트리뷰션, 각종 지표를 믿고 볼 수 있어요.
- 안전한 자동화: 대량 가져오기나 워크플로우 액션에서 실수로 같은 레코드가 두 번 만들어지는 일을 사전 검사로 막아요.
- 앞으로를 위한 준비: 이후에 나올 고급 중복 제거·병합 도구의 기반이 돼요.

## 규칙, 제한, 지원하는 필드

- 커스텀 필드를 만들 때 고유 필드로 지정해요.
- 오브젝트당 고유 필드는 최대 10개예요. 이 제한은 서브 계정 전체에 적용돼요.
- 레코드를 만드는 모든 방법(UI, 워크플로우, 폼, API)에서 적용돼요.
- 지원하는 필드 유형은 다음과 같아요.
  - **Single Line Text**(한 줄 텍스트)
  - **Multi Line Text**(여러 줄 텍스트)
  - **Number**(숫자)
  - **Phone**(전화번호)
- 고유 필드를 고유가 아닌 필드로 바꿀 수 있어요. 단, 이 작업은 되돌릴 수 없어요.

## 사용자 지정 객체에서 필드를 고유로 지정하기

{% hint style="info" %}
한 번 저장하면 이 설정은 서브 계정의 모든 레코드에 적용돼요. 한 번 끄고 나면 다시 켤 수 없어요.
{% endhint %}

### 옵션 1: 새 커스텀 필드를 만들 때

1. **설정**으로 이동해요.

   ![설정 메뉴 화면](https://jumpshare.com/share/DJ6UwhUJbbYconMeQoVu+/Screen+Shot+2025-10-15+at+8.08.46+PM.png)
2. **커스텀 필드**를 클릭해요.
3. **필드 추가**를 클릭해요.

   ![필드 추가 버튼 화면](https://jumpshare.com/share/dxDG7i3qZfniSBYsEBGf+/Screen+Shot+2025-10-15+at+8.09.55+PM.png)
4. 지원하는 필드 유형(**Single Line Text**, **Multi Line Text**, **Number**, **Phone**) 중 하나를 선택해요.
5. 필드 이름, 소속 오브젝트, 그룹을 입력해요.
6. **Mark Field as Unique**(필드를 고유로 표시) 체크박스를 선택해요.
7. **저장**을 클릭해요.

   ![고유 필드로 지정하고 저장하는 과정](https://jumpshare.com/share/BUuYNKbiZTXKsVUBEwpf+/GIF+Recording+2025-10-15+at+8.12.45+PM.gif)

### 옵션 2: 사용자 지정 객체를 만들면서 기본 필드를 고유로 지정하기

1. **설정**으로 이동해요.

   ![설정 메뉴 화면](https://jumpshare.com/share/DJ6UwhUJbbYconMeQoVu+/Screen+Shot+2025-10-15+at+8.08.46+PM.png)
2. **오브젝트**를 클릭해요.
3. **+ Add Custom Object**(사용자 지정 객체 추가)를 클릭해요.

   ![사용자 지정 객체 추가 버튼 화면](https://jumpshare.com/share/hK6LRe3RPJWb1Y6dR78A+/Screen+Shot+2025-10-15+at+8.23.59+PM.png)
4. 사용자 지정 객체 이름과 **Primary Display Field**(기본 표시 필드)를 입력해요.
5. **Mark Primary Field as Unique**(기본 필드를 고유로 표시)를 선택해요.
6. **Create Custom Object**(사용자 지정 객체 만들기)를 클릭해요.
7. 이렇게 하면 기본 필드(예: 사건 번호나 차량 식별번호(VIN))에 같은 값이 들어갈 수 없어요.

   ![기본 필드를 고유로 지정한 화면](https://jumpshare.com/share/W3HjgnXybCax9NDyZjnw+/Screen+Shot+2025-10-15+at+9.06.03+PM.png)

## 고유 필드 수정하기

{% hint style="info" %}
고유 필드를 고유가 아닌 필드로 바꾸면 다시 고유 필드로 만들 수 없어요.
{% endhint %}

1. **설정** > **커스텀 필드**로 이동해요.
2. **검색**을 쓰거나 목록에서 직접 고유 커스텀 필드를 찾아요.
3. 해당 필드를 선택해요.
4. **일괄 작업** > **편집**을 클릭해요.
5. **Mark Field as Unique** 옵션을 **선택 해제**해요.

![고유 필드 설정을 해제하는 과정](https://jumpshare.com/share/HsyIwTp1umfOumoWWyB8+/GIF+Recording+2025-10-15+at+9.37.09+PM.gif)

## 예시 상황

| 상황 | 동작 | 결과 |
| --- | --- | --- |
| 기본 필드에 같은 값을 가진 레코드가 두 개 있음 | 사용자가 저장 | 오류: “A record with the same value already exists.”(같은 값의 레코드가 이미 있다는 메시지) |
| 기본 필드가 아닌 고유 필드에 같은 값을 가진 레코드가 두 개 있음 | 사용자가 저장 | 부분 성공 – 중복된 행은 경고와 함께 건너뜀 |
| 고유로 지정한 필드를 삭제하려고 함 | 삭제 | 경고 – 필드를 삭제할 수 없음 |
| 고유 필드를 고유가 아닌 필드로 변경 | 사용자가 저장 | 허용되지만 되돌릴 수 없음 |
| API로 중복된 값을 넣어 업데이트 | 업데이트 호출 | API가 유효성 검사 오류를 반환함 |

## 활용 팁

- 환자 ID, 사건 번호, 직원 코드처럼 식별자나 키 역할을 하는 값에 고유 필드를 쓰세요.
- 자주 바뀌는 텍스트 필드는 고유로 지정하지 않는 게 좋아요.
- 가져오기 전에 외부에서 데이터의 중복을 먼저 정리하세요. 그래야 가져오기 중 경고가 뜨거나 행이 건너뛰어지는 일을 막을 수 있어요.
- 필드를 고유로 쓸지는 미리 정해 두세요. 나중에 고유 설정을 다시 켤 수는 없어요.

## 자주 묻는 질문

### 고유 규칙은 계정 전체에 적용되나요?
네. 고유 규칙은 서브 계정 전체에 적용돼요.

### 레코드를 만들 때만 확인하나요, 수정할 때도 확인하나요?
수정할 때도 확인해요. 이미 있는 고유 값이면 레코드를 만들 때도, 수정할 때도 막혀요.

### 중복된 값을 입력하면 어떤 오류가 보이나요?
“A record with the same value for <fieldName> already exists.” 같은 메시지가 보여요. 같은 필드에 이미 같은 값의 레코드가 있다는 뜻이에요.

### 고유 규칙은 어디에서 적용되나요?
수동으로 레코드를 만들 때, 워크플로우·자동화, 폼 등 모든 입력 경로에서 적용돼요.

### 드롭다운이나 이메일 필드도 고유로 지정할 수 있나요?
이번 릴리스에서는 **Single Line Text**, **Multi Line Text**, **Number**, **Phone** 필드만 지원해요.

### CSV로 가져올 때 중복된 값이 있으면 어떻게 되나요?
가져오기는 끝까지 진행되지만, 고유 필드 값이 중복된 행은 실패해요.

### 고유 검사 때문에 API 대량 입력이 느려지나요?
아니요. 데이터베이스 단계에서 검증이 최적화되어 있어서 대량으로 보내도 성능에 미치는 영향은 거의 없어요.

### 서브 계정이 다르면 고유 필드에 같은 값을 쓸 수 있나요?
네. 고유 규칙은 서브 계정별로 적용돼요. 에이전시 전체에 걸쳐 적용되지는 않아요.
