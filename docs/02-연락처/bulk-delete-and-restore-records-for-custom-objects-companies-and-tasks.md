# 사용자 지정 객체·회사·작업 레코드 일괄 삭제 및 복원

사용자 지정 객체, 회사, 작업 레코드를 하나씩 지우지 않고 한 번에 삭제할 수 있어요. 가져오기 이후 정리, 중복 제거, 데이터 초기화처럼 레코드를 많이 정리할 때 편리해요. 지원되는 일괄 삭제 작업으로 지운 레코드는 **일괄 작업** 페이지에서 60일 안에 복원할 수 있어서, 실수로 데이터를 잃을 위험도 줄어요.

## 일괄 삭제와 복원이란?

목록 보기에서 레코드를 여러 개 선택해 한 번에 삭제하는 기능이에요.

- **사용자 지정 객체**: 사용자 지정 객체 목록 보기에서 바로 여러 레코드를 선택해 삭제할 수 있어요.
- **회사, 작업**: 이전에는 일괄 삭제가 100개까지만 가능했지만 이제 그 제한이 없어졌어요. 큰 정리 작업도 나눠서 하지 않고 한 번에 할 수 있어요.

레코드를 삭제하면 해당 레코드의 관계(relations), 연관(associations), 연관 레이블(association labels)이 함께 제거돼요. 관련된 다른 레코드 자체는 삭제되지 않아요. 일괄 삭제한 레코드는 **일괄 작업** 페이지에서 확인하고 60일 안에 복원할 수 있어요.

## 일괄 삭제와 복원의 장점

레코드가 많아도 효율적으로 관리할 수 있고, 지원되는 삭제 작업은 복구 방법도 남아 있어요. 오래된 레코드, 중복 레코드, 잘못 가져온 레코드를 반복 작업 없이 정리할 수 있어요.

- 빠른 정리: 사용자 지정 객체, 회사, 작업 레코드를 하나씩 지우지 않고 한 번에 삭제해요.
- 사용자 지정 객체 관리 개선: 목록 보기에서 여러 레코드를 선택해 바로 일괄 삭제해요.
- 회사·작업의 100개 제한 해제: 100개씩 나눠서 삭제하지 않고 더 많은 레코드를 한 번에 삭제해요.
- 더 안전한 대량 삭제: 복원 대상이 되는 일괄 삭제 레코드를 **일괄 작업** 페이지에서 60일 안에 복원해요.
- 작업 현황 확인: **일괄 작업** 페이지에서 삭제 진행률, 상태, 통계를 확인해요.
- 깔끔한 레코드 관계: 삭제한 레코드의 관계, 연관, 연관 레이블은 제거되고, 관련된 다른 레코드는 그대로 남아요.

## 지원하는 레코드 유형

일괄 삭제는 목록 보기에서 선택하고 삭제할 수 있는 레코드 유형에서 쓸 수 있어요.

- 사용자 지정 객체 레코드
- 회사 레코드
- 작업 레코드

사용자 지정 객체는 목록 보기의 체크박스로 여러 레코드를 선택해 일괄 삭제해요. 회사와 작업은 기존 100개 제한이 없어져서 더 큰 삭제 작업도 할 수 있어요.

## 일괄 삭제하면 어떻게 되나요?

일괄 삭제하면 선택한 레코드가 해당 메뉴에서 삭제되고, 그 레코드와 연결된 관계 데이터도 함께 정리돼요. 그래서 삭제한 레코드가 관련 레코드의 연관이나 레이블에 계속 남아 보이지 않아요.

레코드를 삭제하면 다음과 같이 처리돼요.

- 선택한 레코드가 삭제돼요.
- 삭제한 레코드와 연결된 관계가 제거돼요.
- 삭제한 레코드와 연결된 연관이 제거돼요.
- 삭제한 레코드와 연결된 연관 레이블이 제거돼요.
- 관련된 다른 레코드 자체는 삭제되지 않아요.

예를 들어 회사 레코드를 삭제해도 그 회사와 관련된 연락처, 기회 등 다른 레코드는 삭제되지 않아요. 다만 삭제한 회사와 그 레코드들 사이의 연관은 제거돼요.

{% hint style="warning" %}
중요: 복원한 레코드가 이전의 관계, 연관, 연관 레이블을 다시 갖게 되는지 먼저 확인하세요. 확인하기 전에는 관계를 되살리는 용도로 복원 기능에만 의존하지 마세요.
{% endhint %}

{% hint style="info" %}
일괄 삭제를 확정하기 전에 확인하세요.

- 목록 보기에 적용된 필터를 확인해요.
- 선택한 레코드가 삭제하려는 레코드가 맞는지 확인해요.
- 큰 정리 작업 전에는 필요에 따라 중요한 데이터를 내보내 두세요.
- 레코드를 삭제하면 관계, 연관, 연관 레이블이 제거된다는 점을 팀원들이 알고 있는지 확인해요.
- 삭제한 뒤에는 **일괄 작업** 페이지에서 작업 진행 상황과 완료 여부를 확인해요.
- 실수로 삭제했다면 복원할 수 있는 삭제 작업을 60일 안에 복원해요.
{% endhint %}

## 레코드 일괄 삭제하기

일괄 삭제는 따로 설정할 것이 없어요. 목록 보기에서 레코드를 여러 개 선택하고 삭제를 확정한 다음, **일괄 작업** 페이지에서 삭제 작업을 확인하면 돼요.

1. 하이퍼클래스에서 **사용자 지정 객체**, **회사**, **작업** 중 삭제할 레코드가 있는 메뉴를 열어요.

   ![사용자 지정 객체, 회사, 작업 메뉴 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071158602/original/6nLncX04MovZsJQYSukA1hi0-fRansin3A.png?1778598383)
2. 삭제할 레코드가 있는 목록 보기로 이동해요.

   ![삭제할 레코드의 목록 보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071158825/original/BP6WNhCrxf2_j83-fvxSD3RjcgTY74cOJQ.png?1778598480)
3. 체크박스로 삭제할 레코드를 선택해요.

   ![체크박스로 레코드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071159056/original/LxMUYDAZZXjxqKwXs3xeN81ZCvBjYLFhhg.png?1778598539)
4. **삭제**를 클릭해요.
5. 확인 메시지를 꼼꼼히 읽어요.
6. 삭제를 확정해요.

   ![삭제 확인 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071159164/original/BOz0049RBYD-HbrwV4d0sbLflRgy9Q1Iqw.png?1778598580)
7. 서브 계정의 **일괄 작업** 페이지로 이동해요.
8. 삭제 작업에서 진행 상황, 완료 상태, 통계를 확인해요.

   ![일괄 작업 페이지에서 삭제 작업 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071159238/original/Qendp-8mCaip9FWsDqrORR5Ht70Z_0CWaQ.png?1778598617)

## 일괄 삭제한 레코드 복원하기

**일괄 작업** 페이지에는 지원되는 일괄 삭제 작업이 기록으로 남아 있어요. 처음 삭제했던 작업에서 복원하면, 실수로 삭제했거나 되돌려야 하는 정리 작업의 레코드를 복구할 수 있어요.

삭제한 레코드를 60일 안에 복원하려면 다음과 같이 해요.

1. 서브 계정의 **일괄 작업**으로 이동해요.
2. 복원할 레코드의 삭제 작업을 찾아요.
3. 해당 삭제 작업의 점 3개 메뉴를 클릭해요.

   ![삭제 작업의 점 3개 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071159901/original/MmLJBFu-pxjTYUaALvM7AoJn4VF_Bad-7Q.png?1778598902)
4. **복원**을 클릭해요.

   ![복원 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071159765/original/bNHpCakY41B-NBYzXSpahwmx8M4c2D6ONw.png?1778598840)
5. 확인 메시지를 읽어요.
6. 복원을 확정해요.
7. **일괄 작업** 페이지에서 복원 진행 상황을 확인해요.

## 자주 묻는 질문

### 이제 사용자 지정 객체 레코드도 일괄 삭제할 수 있나요?
네, 할 수 있어요. 목록 보기에서 체크박스로 사용자 지정 객체 레코드를 선택해 한 번에 삭제할 수 있어요.

### 회사와 작업을 일괄 삭제할 때 아직도 100개 제한이 있나요?
아니요. 회사와 작업의 일괄 삭제에 있던 100개 제한은 없어졌어요.

### 일괄 삭제 진행 상황은 어디서 확인하나요?
서브 계정의 **일괄 작업** 페이지에서 진행 상황, 통계, 완료 상태를 확인할 수 있어요.

### 일괄 삭제한 레코드를 복원할 수 있나요?
네, 지원되는 일괄 삭제 레코드는 **일괄 작업** 페이지에서 60일 안에 복원할 수 있어요.

### 레코드를 삭제하면 관련된 레코드도 같이 삭제되나요?
아니요. 관련된 다른 레코드 자체는 삭제되지 않아요. 다만 삭제한 레코드의 관계, 연관, 연관 레이블은 제거돼요.

### 60일이 지나면 어떻게 되나요?
복원은 **일괄 작업** 페이지에서 60일 안에 해야 해요. 그 기간이 지나면 **일괄 작업**의 복원 기능으로는 삭제한 레코드를 되살리지 못할 수 있어요.
