# 기본 활동 연결 설정하기

기본 활동 연결은 새 메시지, 전화, 예약, 메모, 작업을 어떤 연락처·기회·회사·사용자 지정 객체 기록에 함께 연결할지 정하는 기능이에요. 관리자가 활동이 시작된 위치별로 규칙을 설정하고, 미리 확인하고, 초기화할 수 있어요. 지원하는 활동과 제한 사항도 함께 정리했어요.

## 기본 활동 연결이란?

기본 활동 연결은 새 활동을 어떤 관련 CRM 기록에 함께 연결할지 정해요. 어떤 규칙이 적용되는지는 활동이 시작된 오브젝트에 따라 달라요.

- **연락처**: 연락처에서 시작한 활동은 연락처 규칙을 따라요.
- **기회**: 기회 기록에서 시작한 활동은 기회 규칙을 따라요.
- **회사**: 회사 기록에서 시작한 활동은 회사 규칙을 따라요.
- **사용자 지정 객체**: 사용자 지정 객체 기록에서 시작한 활동은 해당 오브젝트의 규칙을 따라요.

예를 들어 연락처에서 보낸 이메일은 그 연락처의 주 회사와, 가장 최근에 연결된 진행 중인 기회에도 함께 표시될 수 있어요. 기회에서 만든 작업은 그 기회의 주 회사와 주 연락처에도 표시될 수 있어요.

회사에서 보낸 이메일은 받는 사람이 연락처여도 연락처 규칙이 아니라 회사 규칙을 따라요.

---

## 기본 활동 연결의 장점

활동을 자동으로 연결해 두면 관련 커뮤니케이션과 업무 기록을 사용하는 CRM 기록에 모아 볼 수 있어요.

- **이어지는 활동 기록**: 연결된 기록에서 관련 메시지, 예약, 메모, 작업을 볼 수 있어요.
- **수동 연결 감소**: 지원하는 활동을 만들 때 연결 대상이 되는 관련 기록이 자동으로 선택돼요.
- **일관된 연결**: 저장한 규칙이 지원하는 수동 활동, 수신 활동, 자동화 활동에 똑같이 적용돼요.
- **유연한 설정**: 활동 유형과 시작 오브젝트마다 다른 규칙을 설정할 수 있어요.
- **연결 미리보기**: 저장하기 전에 **활동** 패널에서 예상되는 연결을 확인할 수 있어요.

## 사용 조건과 제한 사항

활동 연결을 설정하기 전에 서브 계정에서 이 기능을 쓸 수 있는지, 내 사용자 역할로 설정을 관리할 수 있는지 확인하세요.

{% hint style="info" %}
비공개 베타 제공 안내: 이 기능은 비공개 베타가 켜진 서브 계정에서만 쓸 수 있어요.
{% endhint %}

- **관리자 권한**: 서브 계정 관리자만 **Default activity associations**(기본 활동 연결)를 열고 바꿀 수 있어요.
- **사용자 권한**: **사용자** 역할이면 설정 버튼이 보이지 않아요. 지원하는 개별 활동에서는 제안된 기록을 직접 조정할 수 있어요.
- **기존 연결 관계**: 규칙이 기록을 선택하려면 관련 기록이 시작 기록에 미리 연결되어 있어야 해요. 연결 관계는 [기회, 회사, 사용자 지정 객체 간 연결](../36-기타/리커버리/associations-between-opportunities-companies-custom-objects.md)에서 확인하세요.
- **새 활동에만 적용**: 규칙을 바꿔도 이미 만든 활동의 연결은 바뀌지 않아요.
- **대상 기회**: 자동으로 연결되는 기회는 진행 중인 기회뿐이에요.
- **필수 참여자**: 메시지 수신자와 예약 참석자는 해당 활동에 계속 연결돼 있어요.

오브젝트에 설정된 연결이 없으면 **{Object} has no associations yet**({오브젝트}에 아직 연결이 없다는 안내)이 표시돼요. 이때는 **연결 관리**를 선택해 필요한 연결을 만든 다음, 활동 설정으로 돌아오세요.

## 기본 활동 연결 설정 방법

관리자는 서브 계정의 오브젝트 설정에서 활동 연결을 설정해요. 활동 유형과 시작 오브젝트를 고르고, 적용할 규칙을 선택한 뒤, 결과를 미리 확인하고 저장하세요.

### 연결 규칙 설정하기

1. 하이퍼클래스에서 **서브 계정** 화면을 여세요.
2. 왼쪽 메뉴에서 **설정**을 선택하세요.
3. **오브젝트**를 선택하세요.
4. 오른쪽 위에 있는 **Default activity associations**를 클릭하세요.

![설정 > 오브젝트 페이지의 기본 활동 연결 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084261525/original/CUfa4cKE_4EoATTgj-IIBHq2XNRJAksmLQ.png?1793076564)

5. **활동 연결** 페이지에서 설정할 활동 유형을 선택하세요.

   선택할 수 있는 탭은 **이메일**, **SMS**, **전화**, **WhatsApp**, **Facebook**, **Instagram**, **TikTok**, **채팅 위젯**, **예약**, **메모**, **작업**이에요.

![활동 유형 탭이 보이는 활동 연결 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084259926/original/4ZpJuvKgWbuQHAK59HHJP-2AVik_EyxuSQ.png?1793072170)

6. **Select an object**(오브젝트 선택)에서 활동이 시작되는 위치를 고르세요. **연락처**, **기회**, **회사**, 또는 사용할 수 있는 사용자 지정 객체 중에서 선택하세요.

![시작 오브젝트 목록이 보이는 Select an object 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084183090/original/-rldpPM1IrEC74bDUsYX-rb6vQYwI69dqA.png?1793009222)

7. 수정할 수 있는 관련 오브젝트 행마다 규칙을 선택하세요. 예를 들면 **Associated companies**(연결된 회사), **Associated opportunities**(연결된 기회) 행이 있어요.

![선택할 수 있는 규칙이 보이는 연결 규칙 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084183099/original/9L5WdRywe6ZBmHryVVxO_WYK_7PIhbdQSA.png?1793009224)

8. 오른쪽의 **활동** 패널에서 새 활동이 연결될 기록을 미리 확인하세요.

![연결 결과를 보여 주는 활동 패널 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084261640/original/uD1G2hin1MXdASmKyyL8igsDMr4uit8z7A.png?1793076588)

9. **저장**을 클릭해 변경 사항을 적용하세요.

![변경된 활동 연결 규칙과 활성화된 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084261022/original/KL-pI5mb-UHtFOEb-qgubbebOSOfKzKI2g.png?1793075665)

**기본** 표시가 붙은 행은 원래 설정이 그대로 유지된 행이에요. 행을 바꾸면 이 표시가 사라지고 **저장** 버튼이 활성화돼요. 오브젝트 이름을 바꿨다면 설정 화면에는 바뀐 이름이 표시돼요.

{% hint style="info" %}
규칙은 따로 저장돼요. 연락처의 이메일 규칙을 바꿔도 회사의 이메일 규칙이나 연락처의 SMS 규칙은 바뀌지 않아요. 활동 유형과 시작 오브젝트마다 설정이 따로 있어요.
{% endhint %}

### 연결 규칙을 기본값으로 초기화하기

**Reset all changes**(모든 변경 사항 초기화)를 쓰면 선택한 활동 유형과 오브젝트의 규칙이 원래대로 돌아가요. 다른 활동 유형과 오브젝트에 저장된 설정은 그대로 유지돼요.

1. 하이퍼클래스에서 **서브 계정** 화면을 여세요.
2. 왼쪽 메뉴에서 **설정**을 선택하세요.
3. **오브젝트**를 선택한 다음 **Default activity associations**를 선택하세요.
4. 활동 유형과 시작 오브젝트를 선택하세요.
5. **Reset all changes**를 클릭하세요.
6. **Reset to default?** 확인 창에서 **기본값으로 초기화**를 선택하세요.
7. **저장**을 클릭해 초기화를 적용하세요.

**Reset all changes**는 선택한 활동 유형과 오브젝트에서 변경 사항을 저장하기 전까지 비활성화되어 있어요. 확인 창에서 초기화를 확정해도 **저장**을 누르기 전에는 적용되지 않아요.

![기본값으로 초기화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084261725/original/V8MNwxJvMCph9ktI_5yTHJgNZLzoOXNR7Q.png?1793076770)

{% hint style="info" %}
채팅 위젯 설정: 웹 채팅과 실시간 채팅은 **채팅 위젯** 설정을 함께 써요. **채팅 위젯**을 초기화하면 두 곳의 규칙이 모두 원래대로 돌아가요.
{% endhint %}

## 연결 규칙과 기본 동작

관련 오브젝트 행마다 기록을 어떻게 선택할지 정해요. 선택할 수 있는 규칙은 활동 유형과 시작 오브젝트에 설정된 연결 관계에 따라 달라요.

### 선택할 수 있는 연결 규칙

| 규칙 | 동작 |
| --- | --- |
| **없음** | 해당 유형의 기록을 추가하지 않아요. 필수 수신자와 참석자는 계속 연결돼 있어요. |
| **Associate with primary {object}**(기본 {오브젝트}와 연결) | **기본** 연결 라벨이 붙은 관련 기록을 선택해요. 이 옵션은 기본 연결을 지원하는 관계에서만 나타나요. |
| **Associate to 1 most recently associated**(가장 최근에 연결된 1개에 연결) | 해당 유형에서 가장 최근에 연결된 대상 기록 1개를 선택해요. |
| **Associate to all**(모두에 연결) | 해당 유형에서 가장 최근에 연결된 대상 기록을 최대 10개까지 선택해요. |

화면에는 **기본만**, **1 most recent**(가장 최근 1개)처럼 줄여 쓴 이름으로 보일 수 있어요. 기본 옵션은 연락처의 회사, 기회의 주 연락처나 주 회사처럼 기본 연결을 지원하는 관계에서 쓸 수 있어요.

연락처에 연결된 회사는 있지만 **기본** 라벨이 붙은 회사가 없으면, 문서에 안내된 대체 규칙에 따라 가장 최근에 연결된 회사를 선택해요.

![기본 옵션이 보이는 연결 규칙 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084183237/original/Y81ohYVNN_efTk1wfHMggUFas2L1XWngAA.png?1793009265)

기본을 지원하지 않는 행도 있어요. 예를 들어 **Associated opportunities**에서는 최근 연결 기준 선택지만 나오고, 종료된 기회는 제외돼요.

![기본 선택지가 없는 Associated opportunities 규칙 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084183243/original/7K8tDYhsuQ8ANgJCGs8Pc_s8vPXgNyaFJA.png?1793009268)

### 활동별 제한 사항

자동으로 연결되거나 제한이 더 엄격한 경우가 있어요. 그래서 선택할 수 있는 옵션도 그에 맞게 달라져요.

- **메시지와 지원되는 전화**: **연결된 연락처**가 **Recipient only (automatic)**(수신자만, 자동)로 고정돼요.
- **예약**: **연결된 연락처**가 **Attendee only (automatic)**(참석자만, 자동)로 고정돼요.
- **메모**: 메모는 관련 오브젝트 유형마다 기록 1개에만 연결할 수 있어서 **Associate to all**을 선택할 수 없어요.
- **기회**: 자동 규칙에는 진행 중인 기회만 포함돼요. 고객전환성공, 고객전환실패, 포기 상태의 기회는 제외돼요.

### 기본 연결 설정

하이퍼클래스는 자주 쓰는 CRM 관계에 시작 규칙을 미리 설정해 두었어요. 관리자는 지원하는 활동 유형과 시작 오브젝트별로 이 규칙을 바꿀 수 있어요.

| 활동이 시작되는 곳 | 기본 연결 |
| --- | --- |
| **연락처** | 주 회사와, 가장 최근에 연결된 진행 중인 기회 1개예요. 해당하는 경우 수신자와 참석자는 계속 연결돼 있어요. |
| **기회** | 주 회사예요. 메모와 작업은 주 연락처를, 메시지와 예약은 수신자 또는 참석자를 사용해요. |
| **회사** | 가장 최근에 연결된 진행 중인 기회 1개예요. 메시지와 예약은 수신자나 참석자를 유지해요. 메모와 작업은 기본적으로 연락처를 자동 추가하지 않아요. |
| **사용자 지정 객체** | 기본적으로 추가되는 관련 오브젝트가 없어요. 메시지와 예약은 수신자나 참석자를 유지해요. |

![기회에서 만든 작업의 기본 연결: 주 회사와 주 연락처](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084261661/original/5cv7JvFJteBmzZeajr9LZ3jvhIshaACboQ.png?1793076609)

행을 한 번 바꾸면, 저장한 규칙이 선택한 활동 유형과 시작 오브젝트의 기본값을 대신해요.

## 규칙이 활동에 적용되는 방식

활동이 시작된 오브젝트에 따라 적용되는 규칙이 정해져요. 새 활동이 만들어질 때 저장된 설정에 따라 조건에 맞는 관련 기록이 선택돼요.

### 활동별로 쓰는 규칙

직접 만든 활동은 보통 활동이 시작된 기록의 오브젝트 규칙을 써요. 수신 메시지, 워크플로우, 일괄 작업, 고객이 직접 예약한 예약은 각 활동 출처에 맞는 규칙을 따라요.

| 활동이 만들어진 방식 | 적용되는 규칙 |
| --- | --- |
| CRM 기록에서 시작한 메시지, 메모, 작업, 예약 | 시작한 기록의 오브젝트 규칙 |
| 수신 이메일, SMS, 전화, 지원되는 소셜 또는 채팅 메시지 | 연락처 규칙 |
| 지원되는 채널로 고객이 직접 예약한 경우 (예약 위젯, 지원되는 Google 예약 옵션, Calendly, WhatsApp 플로우, 클라이언트 포탈 포함) | 연락처 규칙 |
| 지원되는 AI 생성 답변 또는 예약 | 연락처 규칙 |
| 연락처 워크플로우 (기회 트리거로 시작한 연락처 워크플로우 포함) | 연락처 규칙 |
| 회사 워크플로우 | 회사 규칙 |
| 사용자 지정 객체 워크플로우 | 해당 사용자 지정 객체의 규칙 |
| 워크플로우가 만든 메모, 작업, 예약 | 활동을 받는 기록의 규칙 |
| 이메일 또는 SMS 일괄 발송 | 발송을 시작한 오브젝트(연락처, 회사, 사용자 지정 객체 등)의 규칙 |

워크플로우에서 기록을 연결하는 방법은 [Associate Records(레코드 연결) 워크플로우 액션](../07-워크플로우/CRM-Workflow-Actions/workflow-action-associate-records.md)에서 확인할 수 있어요.

지원되는 연락처 활동 흐름으로 가져온 이메일과 지원되는 이메일·SMS 제공업체로 보낸 메시지는 해당하는 이메일 또는 SMS 규칙을 따라요.

### 직접 만드는 활동과 백그라운드 활동

지원되는 활동을 직접 만들 때는 작성 창이나 폼에 설정된 규칙으로 선택된 기록이 표시돼요. 저장된 기본값은 그대로 두고, 해당 활동 하나에 대해서만 연결을 조정할 수 있어요.

- **직접 만드는 활동**: 저장하거나 보내기 전에 선택된 기록을 확인하고, 추가하거나 제거할 수 있어요.
- **백그라운드 활동**: 수신 메시지, 워크플로우 활동, 고객이 직접 예약한 예약은 만들어진 뒤에 추가 연결이 이루어져요.
- **처리 시간**: 백그라운드 활동에서는 추가 연결이 표시되기까지 몇 초가 걸릴 수 있어요.
- **개별 조정**: 활동 하나의 연결을 바꿔도 설정된 규칙은 바뀌지 않아요.

### 관련 기록이 선택되는 방식

규칙은 활동이 만들어지는 시점에 존재하는 연결 관계를 사용해요. 나중에 다른 기록을 연결해도 이전 활동은 자동으로 업데이트되지 않아요.

- **기본**: 활동을 만든 시점에 **기본**으로 표시된 기록을 선택해요. **기본** 라벨을 바꾸면 이후에 만드는 활동부터 영향을 받아요.
- **최신순**: 가장 최근에 **연결된** 대상 기록을 선택해요. 가장 최근에 만든 CRM 기록과는 다를 수 있어요.
- **Associate to all**: 가장 최근에 연결된 대상 기록을 최대 10개까지 선택해요.
- **이미 기회가 연결된 경우**: 이미 기회가 연결된 활동에는 이 규칙으로 다른 기회가 추가되지 않아요.
- **이미 메모 연결이 있는 경우**: 오브젝트 유형 하나에 이미 기록 1개가 연결된 메모에는 같은 유형의 기록이 추가되지 않아요.
- **기존 연결**: 기본 규칙은 조건에 맞는 기록을 추가할 뿐, 활동에 이미 있는 기록을 제거하지는 않아요.

## 활동 제한과 예외

활동 유형마다 연결 제한이 달라요. 일부 생성 방식은 자동 연결 규칙을 거치지 않아요.

### 연결 제한

| 활동 또는 규칙 | 제한 |
| --- | --- |
| **메모** | 관련 오브젝트 유형마다 기록 1개예요. 메모 관리는 [하이퍼클래스 메모로 연락처, 기회, 회사 기록 관리하기](hyperclass-notes-for-managing-contacts-opportunities-and-company-records.md)에서 확인하세요. |
| **작업** | 오브젝트 유형마다 최대 10개예요. 작업에 이미 연결된 기록도 포함해요. 자세한 내용은 [여러 오브젝트에서 작업 사용하기](tasks-across-multiple-objects.md)를 참고하세요. |
| **직접 만든 예약** | 연락처를 제외하고 총 10개까지 연결할 수 있어요. |
| **Associate to all** | 선택한 유형에서 가장 최근에 연결된 대상 기록을 최대 10개까지 선택해요. |

### 자동 규칙이 적용되지 않는 활동

다음 활동이나 생성 방식에는 기본 연결 규칙으로 기록이 추가되지 않아요.

- **기존 활동**: 규칙을 바꾸거나 초기화해도 이전 활동에는 소급 적용되지 않아요.
- **가져오기나 일괄 작업으로 만든 메모와 작업**: 가져오기나 일괄 작업에서 선택한 연결이 그대로 유지돼요.
- **공개 API로 만든 메모, 작업, 예약**: 이 규칙으로는 추가 연결이 붙지 않아요.
- **지원되지 않는 타사 예약 연동**: 이런 연동으로 만든 예약은 자동 연결에서 제외돼요.

API로 받은 수신 메시지에는 여전히 연락처 규칙이 적용돼요. 이메일과 SMS 일괄 발송에도 해당하는 연결 규칙이 적용돼요.

## 자주 묻는 질문

### 새 활동에 회사가 연결되지 않았어요. 왜 그런가요?
활동을 만든 시점에 그 회사가 시작 기록에 이미 연결되어 있었는지 확인하세요. 설정된 규칙을 확인하고, 해당하는 경우 **기본** 라벨도 확인하세요.

### 회사 워크플로우로 보낸 이메일이 연락처의 기회에 표시되지 않아요. 왜 그런가요?
회사 워크플로우는 연락처 규칙이 아니라 회사 규칙을 사용해요. **Default activity associations**를 열고 **이메일**과 **회사**를 선택한 다음, **Associated opportunities** 설정을 확인하세요.

### 기회 트리거로 연락처 워크플로우가 시작되면 어떤 규칙이 적용되나요?
연락처 규칙이 적용돼요. 트리거가 기회를 가리키더라도 워크플로우가 연락처 기반이기 때문이에요.

### 메모에서 Associate to all을 선택할 수 없어요. 왜 그런가요?
메모는 관련 오브젝트 유형마다 기록 1개에만 연결할 수 있어요. 그래서 메모에서는 **Associate to all** 옵션을 쓸 수 없어요.

### 활동 하나의 연결된 기록만 바꿀 수 있나요?
네. 지원되는 수동 활동은 저장하거나 보내기 전에 선택된 기록을 조정할 수 있어요. 이 변경은 해당 활동에만 적용되고 기본 설정은 바뀌지 않아요.

### Reset all changes를 하면 이전 활동도 업데이트되나요?
아니요. 초기화는 저장한 뒤에 선택한 활동 유형과 오브젝트의 설정을 원래대로 되돌려요. 기존 활동의 연결은 바뀌지 않아요.

### Default activity associations 버튼이 보이지 않아요. 왜 그런가요?
서브 계정 관리자만 이 설정을 열 수 있어요. 또한 비공개 베타를 통해 내 서브 계정에서 이 기능이 켜져 있어야 해요.
