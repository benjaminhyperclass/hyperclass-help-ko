# 예약 위젯에 시간대별 남은 좌석 수 표시하기

클래스 예약 캘린더에서 **Show seats per slot**(슬롯별 좌석 수 표시) 설정을 켜면, 예약 위젯의 각 시간대에 남은 좌석 수가 표시돼요. 슬롯 수용 인원 계산 방식이 개선되어, 예약이 여러 슬롯에 걸쳐 겹치는 경우에도 실제 남은 인원이 정확하게 표시돼요.

## 개요

클래스 예약 캘린더에서는 여러 참석자가 같은 시간대를 예약할 수 있어요. **Show seats per slot** 옵션을 켜면 시간대별로 남은 좌석 수를 예약 위젯에서 바로 보여 줄 수 있어요.

이 설정을 쓰면 다음과 같은 점이 좋아요.

- 남은 인원을 한눈에 확인할 수 있어요.
- 고객에게 예약 현황을 투명하게 보여 줄 수 있어요.
- 인원이 많은 이벤트의 일정을 더 효율적으로 운영할 수 있어요.

## Show seats per slot 켜기

예약 위젯에 좌석 수를 표시하려면 다음과 같이 하세요.

1. 클래스 예약 캘린더를 엽니다.
2. **편집**을 클릭합니다.
3. **사용자 지정**으로 이동합니다.
4. **Calendar Widget Style**(캘린더 위젯 스타일) 아래에서 **Show seats per slot** 토글을 켭니다.
5. **저장**을 클릭합니다.

이 토글을 켜면 공개 예약 위젯에 좌석 수가 표시돼요.

## 남은 좌석 수 계산 방식 (개선된 로직)

남은 좌석 수는 캘린더 설정의 **클래스당 좌석 수** 값을 기준으로 계산해요.

개선된 일정 로직은 다음과 같이 동작해요.

- 확정된 예약 1건당 남은 좌석이 1개씩 줄어요.
- 예약이 여러 슬롯에 걸쳐 겹치면, 영향을 받는 슬롯마다 좌석이 1개씩만 줄어요.
- 슬롯의 전체 수용 인원이 모두 차야 해당 슬롯이 막혀요.
- 겹치는 예약 때문에 영향을 받는 슬롯이 모두 먼저 막히는 일이 더는 없어요.

이렇게 하면 남은 인원이 더 정확하게 반영되고, 인원이 많은 캘린더를 더 효율적으로 운영할 수 있어요.

## 예약 위젯에 좌석 수가 표시되는 모습

설정을 켜면 시간대별 남은 좌석 수가 예약 위젯에 바로 표시돼요.

고객은 시간대를 선택하기 전에 남은 좌석 수를 확인할 수 있어요.

## 중요 안내

{% hint style="warning" %}
- 이 기능은 클래스 예약 캘린더에서만 쓸 수 있어요.
- **클래스당 좌석 수** 설정이 1보다 커야 해요.
- Neo 위젯에서 사용할 수 있어요.
- 개선된 수용 인원 로직은 다음 항목에 모두 적용돼요.

  - 공개 예약 위젯
  - 앱 안의 예약 모달
  - 개인 캘린더
  - 라운드 로빈 캘린더
  - 이벤트 캘린더

슬롯은 정해진 수용 인원에 도달할 때까지 예약할 수 있는 상태로 유지돼요.
{% endhint %}

## 자주 묻는 질문

### Show seats per slot은 어떤 기능인가요?
클래스 예약 캘린더에서 각 시간대의 남은 좌석 수를 표시해 주는 기능이에요.

### 남은 좌석 수는 어떻게 계산하나요?
확정된 예약 1건당 슬롯의 수용 인원이 1씩 줄어요. 정해진 수용 인원에 도달해야 해당 슬롯이 막혀요.

### 겹치는 예약이 있으면 슬롯 전체가 막히나요?
아니요. 겹치는 예약은 슬롯을 완전히 막지 않고, 영향을 받는 슬롯마다 수용 인원을 1씩만 줄여요.

### 반복 클래스 예약에서도 쓸 수 있나요?
네, 쓸 수 있어요.
