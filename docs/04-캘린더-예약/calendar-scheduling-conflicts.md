# 캘린더 일정 충돌 확인

팀/그룹 캘린더에서 외부 캘린더의 일정을 읽어 와 겹치는 시간에 예약이 잡히지 않게 하는 방법을 설명해요. 외부 캘린더 연동 설정은 **설정 > 내 프로필**에서 할 수 있어요.

팀/그룹 캘린더(Round Robin, Service, Class, Collective 캘린더)에서는 특정 사용자에게 배정된 예약을 외부 캘린더(Google / Outlook / iCloud)로 동기화할 수 있어요. 반대로 외부 캘린더의 일정을 읽어 와 하이퍼클래스로 동기화할 수도 있어요.

**설정 > 내 프로필**에서 캘린더를 설정하세요. 주요 설정은 두 가지예요. **Primary Calendar**(기본 캘린더)와 **Check for Conflicts**(충돌 확인)입니다. 사용자가 연동한 외부 캘린더는 모두 이곳에 표시돼요.

## 일정 충돌 확인하기

**Check for Conflicts** 섹션에는 사용자가 연동한 Google/Outlook/iCloud 캘린더가 모두 표시돼요.

선택한 캘린더의 일정을 모두 읽어 와서, 사용자가 예약을 받을 수 없는 시간을 막아 두는 기능이에요. Google/Outlook/iCloud에서 가져온 일정은 모두 차단되므로 그 시간에는 예약이 잡히지 않아요.

**Check for Conflicts** 섹션에서는 예약을 만들지 않아요. 이 섹션에서 비활성화된 캘린더가 있다면, 그 캘린더는 이미 **Primary Calendar**로 선택되어 있다는 뜻이에요.
