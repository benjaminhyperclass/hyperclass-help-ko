# 하이퍼클래스 모바일 앱에서 맞춤 동영상 만들어 보내기

하이퍼클래스 모바일 앱에 있는 동영상 메시지 기능으로 맞춤 동영상을 보내는 방법을 안내해요. 내 얼굴과 목소리를 담으면 신뢰를 쌓고, 답장을 늘리고, 노쇼를 줄이는 데 도움이 돼요. 몇 번만 탭하면 끝나요.

# 맞춤 동영상이란?

맞춤 동영상은 하이퍼클래스 모바일 앱에 기본으로 들어 있는 기능이에요. 연락처에게 SMS나 이메일로 1:1 동영상 메시지를 직접 녹화해서 보낼 수 있어요. 자기소개, 예약 확인, 후속 연락처럼 더 사람 냄새 나는 메시지를 보낼 때 좋아요.

외부 앱이나 연동은 필요 없어요. 모든 기능이 하이퍼클래스 모바일 앱 안에 들어 있어요.

## 맞춤 동영상의 장점

짧은 동영상 메시지는 눈에 띄고, 사람 사이의 진짜 연결을 만들어 줘요. 맞춤 동영상이 연락 성과에 도움이 되는 점은 다음과 같아요.

- 이메일과 문자의 열람률·답장률이 올라가요.
- 개인적인 느낌을 더해 바로 신뢰를 쌓을 수 있어요.
- 친근한 예약 확인으로 노쇼를 줄일 수 있어요.
- 반응이 없던 리드와 다시 소통하기에 텍스트만 보낼 때보다 효과적이에요.
- 온보딩이 더 따뜻하고 맞춤형으로 느껴져요.
- 전문적인 소통으로 에이전시나 비즈니스를 돋보이게 할 수 있어요.

## 하이퍼클래스 모바일 앱에서 맞춤 동영상 보내기

하이퍼클래스 모바일 앱에서는 몇 번만 탭하면 맞춤 동영상을 녹화해 바로 보낼 수 있어요.

1. 연락처와의 대화를 열어요. SMS, Instagram, Facebook DM 모두 가능해요.
2. 더하기(+) 아이콘을 탭해요.
3. **동영상**을 선택하면 카메라가 켜져요. 메시지를 녹화하세요.
4. **Use Video**(동영상 사용)를 누르고 바로 보내요.
5. 앱이 동영상마다 고유한 브랜드 링크를 만들어 줘요. 받는 사람은 앱 설치 없이 휴대폰에서 바로 영상을 볼 수 있어요.

{% hint style="info" %}
동영상은 미리보기 이미지가 붙은 링크로 전달돼요. 연락처는 아무것도 내려받지 않아도 영상을 볼 수 있어요.
{% endhint %}

## 효과적인 동영상 메시지 팁

동영상 메시지가 더 잘 전달되도록 다음 팁을 참고해 보세요.

- 영상 길이는 30~60초로 맞춰요.
- 연락처의 이름을 부르고, 그 사람과 관련된 구체적인 내용을 언급해요.
- 웃는 얼굴로 카메라를 바라보며 말해요.
- 편안하고 명확하고 간결하게 말해요.
- "좋으시면 답장 주세요!", "편하신 시간을 알려 주세요."처럼 간단한 행동 유도 문구로 마무리해요.

## 자주 묻는 질문

### 데스크톱에서도 맞춤 동영상을 보낼 수 있나요?

아니요. 맞춤 동영상 기능은 현재 하이퍼클래스 모바일 앱에서만 쓸 수 있어요.

### 연락처가 내 동영상을 봤는지 확인할 수 있나요?

현재는 확인할 수 없어요. 동영상은 링크로 전달돼요. SMS나 이메일에서는 클릭 추적을 쓸 수 있을 수 있지만, 이 기능에는 동영상 시청 분석이 아직 들어 있지 않아요.

### 보낼 수 있는 동영상 개수에 제한이 있나요?

알려진 제한은 없어요. 다만 긴 영상은 업로드에 시간이 더 걸릴 수 있어요. 가장 좋은 성능을 위해 영상은 2분 이내로 유지하세요.

### 동영상이 삽입되어 전송되나요, 링크로 전송되나요?

동영상은 썸네일이 붙은 링크 미리보기로 전송돼요. 연락처가 링크를 탭하면 브라우저에서 영상을 볼 수 있어요.

### 동영상에 콜투액션이나 링크를 추가할 수 있나요?

동영상 링크와 함께 짧은 메시지를 넣을 수는 있어요. 하지만 이 기본 기능 안에서는 별도의 랜딩 페이지나 콜투액션을 쓸 수 없어요.

## 다음 단계

- 하이퍼클래스 모바일 앱을 열어 나 자신이나 팀원에게 테스트 동영상을 보내 보세요.
- 예약 확인, 후속 연락, 온보딩에 맞춤 동영상을 활용해 보세요.
- 영업팀이 리드에게 연락할 때 동영상을 활용하도록 권해 보세요.
- 받은 반응과 연락처의 참여도를 보면서 메시지를 계속 다듬어 보세요.
