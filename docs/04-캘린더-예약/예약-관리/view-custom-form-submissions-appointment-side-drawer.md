# 예약 창에서 커스텀 폼 제출 내용 보기

예약 창을 열면 고객이 예약할 때 작성한 커스텀 폼 응답을 바로 확인할 수 있어요. **폼** 메뉴나 **연락처**로 이동하지 않아도 되니, 미팅 전에 내용을 빠르게 살펴볼 때 편해요.

## 개요

폼 제출 보기 기능을 쓰면 커스텀 예약 폼의 응답을 **Appointment Modal**(예약 상세 창)에서 바로 볼 수 있어요. **폼** 메뉴나 **연락처**로 이동해 확인하던 번거로움이 줄어들어 일정 관리가 더 빨라져요.

## 새로 달라진 점

- **폼** 탭이 생겨요.
  예약에 커스텀 폼 제출 내용이 연결되어 있으면 **Appointment Modal**에 **폼** 탭이 나타나요.
- 제출 내용이 정리된 형태로 보여요.
  제출된 응답이 **폼** 메뉴의 **폼 제출** 화면과 비슷한 구성으로 표시돼요.
- 어디서든 확인할 수 있어요.
  **캘린더**, **연락처**, **대화** 어디에서든 예약을 클릭하면, 해당하는 경우 **폼** 탭이 보여요.

![예약 상세 창의 폼 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044766865/original/s1j5QPZ1mmmtGyLQYsm-XCXVNBcx7V3vNA.png?1744171665)

## 사용 방법

1. **캘린더**로 이동해 최근 예약을 클릭하세요.
2. 예약 카드를 클릭해 **Appointment Modal**을 여세요.
3. 예약 과정에서 커스텀 폼이 제출되었다면 **Appointment Modal**에 **폼** 탭이 보여요.
4. **폼** 탭을 클릭하면 제출 내용을 항목별로 자세히 볼 수 있어요.

## 중요 사항

{% hint style="warning" %}
- 이 기능은 예약 과정에 추가한 커스텀 폼만 지원해요.
- 폼 제출 내용은 2025년 4월 9일 이후에 만들어진 예약에만 표시돼요.
- 기본 예약 폼(이름, 이메일, 전화번호)의 제출 내용은 현재 **폼** 탭에 표시되지 않아요. 이 정보는 이미 **연락처** 섹션에 나와 있기 때문이에요.
- 기본 폼 제출 내용을 **폼** 탭에서 보는 기능은 곧 지원될 예정이에요.
{% endhint %}

## 활용 예시

- 미팅 전에 사전 질문과 입력 데이터를 빠르게 확인할 수 있어요.
- 여러 메뉴를 오가는 번거로움이 줄어요.
- 미리 파악한 내용을 바탕으로 대화하면 고객 경험이 좋아져요.
