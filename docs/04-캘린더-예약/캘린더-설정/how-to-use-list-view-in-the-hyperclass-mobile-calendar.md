# 하이퍼클래스 모바일 앱 캘린더에서 목록 보기 사용하기

하이퍼클래스 모바일 앱의 **캘린더**(Calendars)에 새로 추가된 **목록 보기**를 사용하는 방법을 안내해요. 다가오는 예약을 스크롤 목록으로 보여 줘서 한눈에 훑어보고 깔끔하게 확인할 수 있어요.

## 모바일 캘린더의 목록 보기란?

**목록 보기**는 하이퍼클래스 모바일 앱에서 쓸 수 있는 새 캘린더 보기 방식이에요. 격자 형태의 기존 보기(**매월**, **매주**)와 달리, 캘린더 이벤트를 시간순으로 정렬해 스크롤 목록으로 보여 줘요. 화면이 복잡하지 않아서 다가오는 이벤트를 하나씩 확인하기 좋고, 작은 화면에서 특히 편해요.

### 목록 보기의 장점

목록 보기는 작은 화면에서도 보기 쉽고 빠르게 쓸 수 있도록 만들어졌어요.

- 순서대로 일정 확인: 캘린더 격자 없이 위에서 아래로 이어지는 목록으로 이벤트를 볼 수 있어요.
- 모바일에 맞는 화면: 제한된 화면 공간을 최대한 활용하고, 눈에 거슬리는 요소를 줄였어요.
- 스크롤로 이동: 날짜마다 탭하지 않아도 스크롤만으로 전체 캘린더를 넘겨 볼 수 있어요.
- 집중하기 좋음: 오늘 일정에 집중하거나, 앞으로의 이벤트를 미리 스크롤해서 준비할 수 있어요.
- 간편한 전환: 한 번의 탭으로 목록 보기와 다른 보기를 오갈 수 있어요.

## 모바일 캘린더에서 목록 보기로 전환하기

몇 번만 탭하면 전체 캘린더를 보기 쉬운 목록으로 확인할 수 있어요.

1. 하이퍼클래스 모바일 앱을 열고 **캘린더**로 이동하세요.

   *화면 예시: 하단 내비게이션에서 캘린더 아이콘이 선택된 모습*
2. 캘린더 화면 오른쪽 위에 있는 **View Toggle**(보기 전환, 격자 아이콘)을 탭하세요.

   *화면 예시: 격자 아이콘에 동그라미 표시를 한 캘린더 화면*
3. 드롭다운 메뉴에서 **목록 보기**를 선택하세요.

   *화면 예시: **매월**, **매주**, **목록 보기**가 표시되고 **목록 보기**가 선택된 드롭다운 메뉴*
4. 캘린더가 날짜와 시간순으로 세로로 쌓인 이벤트 목록으로 바뀌어요.

   *화면 예시: 날짜와 시간 순으로 정렬된 이벤트 목록. 이벤트마다 카드 또는 행으로 표시돼요.*
5. 아래로 스크롤하면 다가오는 이벤트를, 위로 스크롤하면 최근 활동을 볼 수 있어요.
6. 격자 형태의 보기로 돌아가려면 같은 순서로 진행한 뒤 **매월** 또는 **매주**를 선택하세요.

## 모바일에서 일정 계획하기 좋은 이유

목록 보기는 모바일 사용자가 깔끔한 화면에서 일정을 효율적으로 확인하고 관리할 수 있도록 만들어졌어요.

작은 화면에서는 격자 보기가 빽빽해서 읽기 어려울 수 있어요. 목록 보기에서는 이벤트마다 자기 공간이 있어서 일정을 자연스럽게 넘겨 볼 수 있어요. 오늘 다음 일정을 확인할 때도, 다음 주 계획을 세울 때도 과정이 단순해져요.

## 자주 묻는 질문

### 목록 보기는 데스크톱에서도 쓸 수 있나요, 모바일에서만 쓸 수 있나요?
현재는 모바일 버전(하이퍼클래스 모바일 앱)에서만 쓸 수 있어요. 데스크톱 지원은 이후 업데이트에서 검토될 수 있어요.

### 월간 캘린더 보기로 다시 돌아갈 수 있나요?
네. 같은 보기 전환 버튼을 탭하고 **매월** 또는 **매주**를 선택하면 격자 보기로 돌아가요.

### 목록 보기에는 어떤 이벤트가 표시되나요?
작업, 부킹(booking), 예약 등 모든 종류의 이벤트가 목록에 표시돼요.

### 목록 보기에서 필터나 검색을 쓸 수 있나요?
아직 목록 보기에서는 필터를 지원하지 않아요. 대신 스크롤해서 이벤트를 찾거나 캘린더의 검색 기능을 사용하세요.
