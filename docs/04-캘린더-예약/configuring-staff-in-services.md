# 서비스에서 직원 설정하기

**서비스**에서 직원을 설정하면 누구를 예약할 수 있는지, 각 직원이 어떤 서비스를 맡는지, 언제 예약받을 수 있는지 정할 수 있어요. 수석 테라피스트, 시니어 컨설턴트처럼 여러 직원에게 쓸 수 있는 역할 배지를 만들어 두면, 고객이 예약 전에 담당자를 더 쉽게 알아볼 수 있어요.

이 문서에서는 직원 추가, 서비스 배정, 반복 일정과 특정 날짜 일정 설정, 서비스별 옵션 설정, 직원 역할 배지 만들기를 다뤄요.

{% hint style="warning" %}
고객이 직원을 예약하려면 그 직원이 활성 상태인 서비스와 위치에 배정되어 있어야 해요. 해당 서비스에 대한 가능 시간도 있어야 해요.
{% endhint %}

# 서비스의 직원 설정이란?

직원 설정은 어떤 팀원이 서비스를 제공하는지, 어디서 일하는지, 언제 예약받을 수 있는지, 고객 예약 화면에 어떻게 보이는지를 정하는 일이에요.

직원 프로필에는 다음 내용을 넣을 수 있어요.

- 연락처와 프로필 정보
- 배정된 서비스와 위치
- 기본 가능 시간과 반복 가능 시간
- 특정 날짜의 일정 변경
- 서비스별 가격과 예약 건수 제한
- 고객에게 보이는 직원 역할 배지

## 직원 설정을 하면 좋은 점

직원 설정을 한곳에서 관리하면 서비스 배정, 일정, 가격, 고객에게 보이는 정보를 예약 화면과 맞춰 둘 수 있어요.

- 직원 노출: 직원이 제공할 수 있는 서비스에만 그 직원을 보여 줘요.
- 가능 시간 통합 관리: 직원 프로필에서 반복 일정과 일회성 예외 일정을 함께 관리해요.
- 유연한 근무 시간: 시간대를 여러 개 추가해 휴식 시간이나 분할 근무를 반영할 수 있어요.
- 서비스별 설정: 서비스마다 가격과 예약 건수 제한을 따로 정할 수 있어요.
- 명확한 직원 역할: 고객이 바로 이해할 수 있는 짧은 역할 배지를 달 수 있어요.
- 재사용 가능한 레이블: 배지를 한 번 만들어 두면 여러 직원에게 배정할 수 있어요.

## 사전 조건과 제한 사항

고객 예약을 테스트하기 전에 직원 프로필, 서비스 배정, 가능 시간, 배지 제한을 확인하세요.

- 직원은 **캘린더 > 캘린더 설정 > 서비스 > 직원**에서 관리해요.
- 직원마다 이메일 주소가 달라야 해요.
- 직원은 서비스와 위치에 각각 1개 이상 배정되어 있어야 해요.
- 배정한 서비스에 가능 시간이 있어야 해요.
- 직원 한 명당 역할 배지는 1개까지 가질 수 있어요.
- 배지 텍스트는 최대 30자까지 입력할 수 있어요.
- 재사용 배지마다 색상을 따로 지정할 수 있어요.
- 배지가 없는 직원은 빈 자리 없이 평소처럼 표시돼요.

## 직원 추가하고 설정하기

먼저 직원 프로필을 만들어요. 그다음 서비스를 배정하고, 직원을 예약받을 수 있는 시간을 정하는 반복 일정 또는 일회성 일정을 설정해요.

### 1단계: 직원 추가 또는 편집하기

1. **캘린더 > 캘린더 설정 > 서비스 > 직원**으로 이동해요.
2. 직원을 추가하거나, 이미 있는 직원 옆의 **연필 아이콘**을 클릭해요.
3. 이름, 이메일, 전화번호, 시간대, 프로필 사진, 맞춤 예약 URL을 입력하거나 수정해요.
4. 직원 프로필을 저장해요.

![직원 프로필 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081817096/original/Lk7y26zFEle9TgvzE9PZvh3sqfKZd6rY5w.png?1790307554)

{% hint style="info" %}
서비스에 직원을 추가하면 오전 9시~오후 5시 일정이 기본으로 적용돼요. 예약 페이지를 게시하기 전에 이 시간을 확인하고 필요하면 조정하세요.
{% endhint %}

### 2단계: 서비스 배정하기

서비스를 배정하면 그 직원이 받을 수 있는 예약이 정해져요. 직원별 가격과 예약 건수 제한 옵션도 이때 나타나요.

1. **배정된 서비스** 탭을 열어요.
2. 서비스를 하나 이상 선택해요.
3. 필요하면 서비스별 가격을 조정해요.
4. 필요하면 일별, 주별, 월별 예약 건수 제한을 설정해요.
5. 변경 내용을 저장해요.

![직원의 서비스 배정 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052231637/original/4a92J7kcpeNS0M9wSRCNvrACKvwksnVlnA.png?1756023697)

### 3단계: 주간 근무 시간 설정하기

주간 근무 시간은 직원이 평소에 예약받을 수 있는 반복 일정을 정해요.

1. **Weekly Working Hours**(주간 근무 시간)를 열어요.
2. 근무하는 요일을 선택해요.
3. 요일마다 시간대를 하나 이상 추가해요.
4. 해당하는 서비스와 위치를 배정해요.
5. 일정을 저장해요.

휴식 시간을 만들려면 시간대를 나눠서 추가하세요. 예를 들어 오전 9:00~낮 12:00와 오후 1:00~5:00로 나눌 수 있어요.

![직원의 주간 근무 시간 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052231628/original/holv7nLlfPi2awAbGjW21uRcdQhWT9VvXA.png?1756023650)

### 4단계: 특정 날짜 근무 시간 추가하기

특정 날짜 근무 시간은 공휴일, 휴가, 연장 근무처럼 일회성으로 바뀌는 일정에 쓰며, 반복되는 주간 일정보다 우선해요.

1. **Date-Specific Hours**(특정 날짜 근무 시간)를 열어요.
2. 날짜를 하나 또는 여러 개 선택해요.
3. 직원을 예약 가능 또는 불가능으로 지정해요.
4. 해당하는 시간대, 서비스, 위치를 설정해요.
5. 변경 내용을 저장해요.

![직원의 특정 날짜 근무 시간 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052231616/original/E6ilYY0gDQRDi70Gte0Pci8y4vU4YdFOYg.png?1756023515)

{% hint style="info" %}
선택한 날짜에는 **Date-Specific Hours**가 **Weekly Working Hours**보다 우선해요.
{% endhint %}

## 직원 역할 배지 추가하거나 배정하기

직원 역할 배지는 고객이 담당자를 고를 때 수석 테라피스트, 시니어 컨설턴트 같은 짧은 설명을 보여 줘요. 배지는 다시 쓸 수 있고, 직원의 **기본 세부 정보**에서 배정해요.

1. **캘린더 > 캘린더 설정 > 서비스 > 직원**으로 이동해요.
2. 직원 옆의 **연필 아이콘**을 클릭해요.
3. **기본 세부 정보**를 열어요.
4. **Staff badge**(직원 배지) 드롭다운을 열어요.

![직원 배지 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081817832/original/BMx26M-WpA_0E6zphLG2dO4uC92THLZVZQ.png?1790309090)

이미 만든 배지를 쓰려면 드롭다운에서 선택한 뒤 직원 프로필을 저장하세요.

재사용할 배지를 새로 만들려면 다음 순서로 진행하세요.

1. **관리**를 선택해요.
2. **New badge**(새 배지)에 배지 이름을 입력해요.
3. 이름은 30자 이내로 입력해요.
4. 색상을 선택해요.
5. **+ 추가**를 클릭해요.
6. **변경사항 저장**을 클릭해요.
7. **Staff badge** 드롭다운에서 새로 만든 배지를 선택해요.
8. 직원 프로필을 저장해요.

![새 직원 배지 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081817518/original/Awj6wJFJoDF61oam5Z3mwcVwZShKbt1k4A.png?1790308682)

## 예약 화면에서 직원 역할 배지가 보이는 방식

고객이 직원을 선택하는 단계에서 직원 카드에 배정한 역할 배지가 나타나요. 고객은 예약할 직원을 고르기 전에 담당자를 구분할 수 있어요.

- 배지는 직원의 예약 카드에 표시돼요.
- 고객에게 보이는 배지는 예약 위젯의 기본 색상보다 밝은 색조를 써요.
- 배지가 없는 직원은 빈 자리 없이 평소처럼 표시돼요.
- 변경 내용은 예약 위젯을 다음에 불러올 때 반영돼요.
- 배지는 데스크톱과 모바일 예약 레이아웃 모두에 표시돼요.

{% hint style="info" %}
고객이 직원을 선택하는 단계를 쓰려면 **글로벌 설정 > Booking Page**(예약 페이지)에서 **Allow customers to pick who they book with**(고객이 직접 예약할 직원을 선택하도록 허용)를 켜세요.
{% endhint %}

![예약 화면의 직원 카드와 역할 배지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081817270/original/uhA-vRLCRSwNxu6qZGOKlByxm0LUIp11dg.png?1790308420)

## 자주 묻는 질문

### 예약 페이지에 직원이 보이지 않아요.
직원이 해당 서비스와 위치에 배정되어 있는지, 그 서비스에 대한 가능 시간이 있는지 확인하세요.

### 점심시간처럼 중간에 쉬는 시간은 어떻게 만드나요?
**Weekly Working Hours**에서 시간대를 나눠서 추가하세요. 예를 들어 오전 9:00~낮 12:00와 오후 1:00~5:00로 나누면 돼요.

### 어떤 일정이 우선하나요?
선택한 날짜에는 **Date-Specific Hours**가 **Weekly Working Hours**보다 우선해요.

### 직원 한 명에게 역할 배지를 몇 개까지 배정할 수 있나요?
직원 한 명당 역할 배지는 1개까지 가질 수 있어요.

### 직원마다 새 배지를 만들어야 하나요?
아니요. 이미 만든 배지는 다시 쓸 수 있고, **Staff badge** 드롭다운에 표시돼요.

### 배지를 배정하지 않으면 어떻게 되나요?
직원 카드는 배지나 빈 자리 없이 평소처럼 표시돼요.

### 배지를 바꾸면 언제 반영되나요?
수정하거나 제거한 배지는 예약 위젯을 다음에 불러올 때 반영돼요.
