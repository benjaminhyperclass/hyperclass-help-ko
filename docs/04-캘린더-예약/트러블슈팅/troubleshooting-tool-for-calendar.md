# 캘린더 문제 해결 도구

캘린더 문제 해결 도구(Troubleshooting Tool for Calendar)는 하이퍼클래스에서 예약 충돌이나 가용 시간 누락 같은 캘린더 문제를 빠르게 찾아 고치도록 돕는 도구예요. 흔한 설정 문제를 한눈에 보여 주므로 바로 조치할 수 있어요.

## 캘린더 문제 해결 도구란?

이 도구는 캘린더 예약이 정상적으로 잡히지 않게 만드는 설정 문제를 찾아 주는 진단 기능이에요. 캘린더 설정이 잘못되면 예약을 놓치고, 고객이 불편을 겪고, 매출도 줄어들 수 있어요. 이 도구는 가용 시간 누락, 사용자 동기화 오류, 잘못된 팀 설정처럼 무엇이 문제인지 정확히 짚어 줘요. 고객지원에 문의하지 않고도 바로 고칠 수 있어요.

## 이 도구의 장점

설정 문제를 바로 알려 주므로 원인을 추측하거나 지원 답변을 기다리는 시간이 줄어요. 예약을 막는 흔한 원인을 직접 찾아 해결할 수 있어요.

- 즉시 확인: 가용 시간 공백, 배정되지 않은 사용자, Google/Outlook 동기화 실패 같은 흔한 설정 문제를 실시간으로 찾아요.
- 직접 진단: 고객지원에 문의하지 않고도 문제를 확인할 수 있어요.
- 빠른 예약 복구: 예약 실패의 근본 원인을 빨리 찾아 캘린더를 정상으로 돌려놓을 수 있어요.
- 여러 캘린더 지원: 팀 캘린더와 라운드 로빈 캘린더에서도 쓸 수 있어요.
- 사용자 동기화 정보: 특정 사용자나 연결된 계정과 관련된 동기화 문제를 보여 줘요.

## 문제 해결 도구 사용하기

이 도구는 따로 설정할 필요가 없어요. 최신 화면에서 어디로 들어가는지만 알면 예약 문제를 빠르고 정확하게 진단할 수 있어요.

### 문제 해결 도구 열기

1. 하이퍼클래스에서 **설정 > 캘린더**로 이동해요. 페이지 상단에서 **캘린더 설정**을 클릭하세요.

   ![캘린더 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044569840/original/jRV5fRSzdppYjBCX-YmeOMFAH8TdiIEy6A.png?1743793447)

2. 문제를 확인할 캘린더를 찾아요. 그 캘린더 옆의 **Wrench Icon**(렌치 아이콘)을 클릭하면 도구가 열려요.

   ![캘린더 옆 렌치 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044569618/original/XfgdG81VrV3K9eF7vEsYeDfLzx9cP5yPzA.png?1743792864)

### 캘린더 상단에서 바로 열기

편집 중인 캘린더에서 바로 진단을 시작하면 클릭 수가 줄고 더 빨리 고칠 수 있어요.

1. **설정 > 캘린더 > [내 캘린더]**를 열어요. 오른쪽 상단 헤더에서 **Troubleshoot Calendar**(캘린더 문제 해결)를 클릭하세요.

   ![오른쪽 상단 헤더의 캘린더 문제 해결 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064114658/original/x0y8DwUOBUMa422acn4u3rLWTnsF-8LU9w.png?1770137263)

**Troubleshoot Calendar**를 클릭하면 편집기를 벗어나지 않고 진단 화면을 열 수 있어요.

## 문제 진단하기

1. 캘린더 격자에서 **날짜 선택**으로 날짜를 선택하세요.
2. 예약할 수 없는 시간대 위에 마우스를 올리면 툴팁에 이유가 표시돼요.

   ![예약 불가 시간대 위에 표시된 툴팁](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044569828/original/C7zoyuad_5Oc8Uq1bTLdkWUNoyRT9DDI6A.png?1743793431)

## 상황별 문제 해결

기본 사용법 외에도 예약 문제가 자주 생기는 상황이 있어요. 아래 내용을 알아 두면 예약이 끊기는 일을 미리 막고 일정 관리를 더 안정적으로 할 수 있어요.

### 캘린더 연동 상태 확인하기

캘린더가 제대로 연동되어 있어야 동기화와 가용 시간이 정확해요. 연동이 잘못되면 예약이 보이지 않거나 잘못 동기화될 수 있어요.

1. **캘린더 설정 > 연결**로 이동해요.
2. Google 또는 Outlook이 **연결됨**으로 표시되는지 확인해요.
3. 필요하면 다시 연결하고 올바른 캘린더를 선택해요.

### "삭제된 캘린더" 연결 오류 해결하기

연결해 둔 Google/Outlook 캘린더가 해당 서비스에서 삭제되면 하이퍼클래스에 오류 배너가 표시될 수 있어요. 하이퍼클래스 고객지원에 문의하지 않고 직접 정리할 수 있어요.

1. 계정의 **설정**에서 **캘린더** 섹션으로 이동한 뒤 **연결** 탭을 클릭해요.
2. **Fix This**(수정하기)를 클릭해요.

   ![연결 탭의 수정하기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064653011/original/AnEe_xd9nqPt4K4v0blr-j-CTDg-vU9plg.jpeg?1770799201)

3. 팝업에 나온 삭제된 캘린더 목록을 확인해요.

   - 각 항목에는 삭제된 캘린더와 하이퍼클래스에서 연결된 위치가 표시돼요.

4. **Remove Deleted Calendars**(삭제된 캘린더 제거)를 클릭하면 끊어진 캘린더 연결을 한 번에 제거할 수 있어요.

   ![삭제된 캘린더 제거 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064653223/original/NPvEVYdolJaLe1D31tv2IoIXQDIvI8wCug.png?1770799321)

5. 필요하면 유효한 캘린더를 다시 연결하거나 다시 선택해요.

### 사용자 가용성 설정 확인하기

캘린더를 연동했더라도 가용 시간이 없거나 잘못 설정되어 있으면 예약이 막혀요. 문제 해결 도구는 근무 시간이 정해지지 않은 사용자를 표시해 줘요. 가용 시간을 확인하고 수정하려면 다음과 같이 해요.

1. **캘린더 > 캘린더 설정**으로 이동해요.
2. 해당 사용자에게 배정된 캘린더를 찾아 **편집**을 클릭해요.
3. 캘린더 안에서 **가용성** 탭을 클릭해요.
4. 필요한 요일의 예약 가능 시간대를 추가하거나 수정해요.

![가용성 탭에서 시간대 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044573166/original/ribvANLujbwTUN1HVdKbI25UrcsxsLnGkA.png?1743802784)

### 예약 불가 상태 코드의 의미

문제 해결 도구의 툴팁에 표시되는 상태 코드는 해당 시간대를 예약할 수 없는 이유를 알려 줘요.

- **사용자**: 이 시간에 예약받을 수 있는 사용자가 없어요.
- **컬렉티브**: 한 명 이상의 사용자가 예약할 수 없는 상태예요.
- **충돌**: 외부 캘린더의 일정과 겹쳐요.
- **예약됨**: 시스템에서 이미 예약된 시간이에요.
- **차단됨**: 직접 차단한 시간이에요.
- **공지사항**: 최소 예약 사전 공지 시간을 지키지 않아요.
- **TOOFAR**: 허용된 날짜 범위를 벗어났어요.
- **DAYLIMIT**: 그날의 예약 한도에 도달했어요.
- **SLOTMAX**: 해당 시간대의 최대 예약 수에 도달했어요.
- **버퍼**: 버퍼 시간 때문에 이 시간대를 예약할 수 없어요.
- **지속 시간**: 빈 시간이 예약 시간보다 짧아요.
- **지난**: 이미 지난 시간입니다.
- **LOOKBUSY**: **Look Busy**(바쁘게 보이기) 설정으로 숨겨졌어요.
- **좌석 없음**: 최대 좌석 수에 도달했어요.
- **리소스**: 필요한 리소스를 사용할 수 없어요.

### 중복 예약 원인 찾기

여러 사용자가 같은 캘린더에 동기화되어 있거나 가용 시간이 겹치면 중복 예약이 생길 수 있어요.

- 문제 해결 도구로 어떤 사용자끼리 충돌하는지 확인하세요.
- 사용자 캘린더를 조정하거나 사용자마다 캘린더를 따로 두어 겹치지 않게 하세요.

### 권한 관련 오류 이해하기

Google/Outlook에서 권한이 취소되었거나 접근 범위가 부족해서 예약 문제가 생기기도 해요.

- **설정 > 스태프 관리**로 이동해요.
- 해당 스태프를 찾아 **편집 > 캘린더 구성**을 선택해요.
- 왼쪽 메뉴에서 **캘린더**를 클릭한 뒤 필요한 권한 범위가 모두 허용되어 있는지 확인해요.

## 자주 묻는 질문

### 문제 해결 도구를 따로 켜야 하나요?
아니요. 문제 해결 도구는 플랫폼에 기본으로 들어 있어서 **캘린더 설정**에서 바로 쓸 수 있어요.

### 시간대가 "UNAVAILABLE"로 표시되는 이유는 무엇인가요?
**UNAVAILABLE**(이용 불가)은 사용자가 가용 시간 밖에 있거나, 다른 일정·동기화 문제·예약 제한 같은 충돌 때문에 해당 시간이 막혀 있다는 뜻이에요.

### 캘린더에 예약 가능한 시간이 하나도 안 보여요.
보통 배정된 사용자가 없거나, 가용 시간이 설정되지 않았거나, 캘린더 동기화가 끊긴 경우에 이런 일이 생겨요.

### 그룹 캘린더나 라운드 로빈 캘린더도 이 도구로 확인할 수 있나요?
네. 그룹 캘린더를 지원하며, 어떤 사용자 때문에 예약이 실패하는지 보여 줘요.

### 문제 해결 도구에서 자동화나 워크플로우 오류도 볼 수 있나요?
아니요. 캘린더 설정 문제만 보여 주고 자동화 로직은 보여 주지 않아요.

### 이 도구에서 연락처의 시간대 기준으로 가용 시간을 볼 수 있나요?
아니요. 로그인한 사용자의 시간대를 기준으로 보여 줘요.
