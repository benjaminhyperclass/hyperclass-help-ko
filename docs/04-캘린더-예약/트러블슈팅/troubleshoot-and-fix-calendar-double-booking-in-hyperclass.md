# 캘린더 중복 예약 문제 해결하기

캘린더에서 같은 시간대에 예약이 겹쳐 들어올 때 원인을 찾고 해결하는 방법을 영상으로 안내해요.

## 함께 확인하면 좋은 내용

- 여러 Google 캘린더에서 일정 충돌을 확인하도록 그룹 캘린더를 설정하는 방법
- 캘린더 동기화 옵션별 의미

위 내용이 더 필요하면 하이퍼클래스 고객지원에 문의하세요.
