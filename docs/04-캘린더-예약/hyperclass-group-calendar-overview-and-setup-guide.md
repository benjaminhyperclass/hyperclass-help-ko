# 그룹 캘린더 개요와 설정 가이드

여러 캘린더를 링크 하나로 묶어 예약을 받는 그룹 캘린더의 개념과 만드는 방법을 안내해요. 담당자나 서비스를 고르게 하는 등 유연한 예약 방식이 필요할 때 사용하세요.

{% hint style="info" %}
그룹 캘린더를 만들어도 개별 캘린더가 자동으로 생기지 않아요. 그룹에 넣을 개별 캘린더를 먼저 만들어 두세요.
{% endhint %}

## 그룹 캘린더란?

그룹 캘린더는 여러 개별 캘린더를 링크 하나로 묶어 주는 상자 같은 기능이에요. 이 링크 하나로 다음과 같은 예약 방식을 만들 수 있어요.

- 여러 담당자 중에서 선택하기
- 예약 분배하기
- 특정 팀원과 연결된 서비스 중에서 선택하기

## 그룹 캘린더의 장점

그룹 캘린더를 쓰면 예약 과정을 이렇게 간단하게 만들 수 있어요.

- 여러 캘린더를 예약 링크 하나로 합칠 수 있어요.
- 고객이 팀원이나 서비스를 직접 고를 수 있어요.
- 부서, 가능 시간, 서비스별로 캘린더 링크를 정리할 수 있어요.
- 개별 캘린더 링크를 따로 여러 개 두지 않아도 돼서 깔끔해요.

## 그룹 캘린더 만들기

### 1단계: 캘린더 설정으로 이동하기

1. 서브 계정의 **설정**으로 이동하세요.

   ![서브 계정 설정 화면](https://jumpshare.com/v/9drFWZMZUKzK9Yz5Q6QP+/Screen+Shot+2025-05-30+at+6.54.15+PM.png)
2. **비즈니스 서비스** 아래에서 **캘린더**를 선택하세요.
3. **그룹 생성** 버튼을 클릭하세요.

   ![그룹 생성 버튼](https://jumpshare.com/v/nOoenAOqpMgwEMImXQtH+/Screen+Shot+2025-05-30+at+7.06.34+PM.png)

### 2단계: 새 캘린더 그룹 추가하기

1. **그룹 이름**을 입력하세요. 짧은 **설명**도 적을 수 있어요(선택 사항).
2. 그룹 보기에 쓸 템플릿으로 **클래식**이나 **Neo**(네오) 중 하나를 선택하세요.
3. **그룹 URL**에 알맞은 슬러그(주소 끝에 붙는 이름)를 입력하세요.
4. **만들기**를 클릭하세요.

   ![그룹 이름과 URL을 입력하는 화면](https://jumpshare.com/v/eq4sOBnJdw1wU4ihydX7+/Screen+Shot+2025-05-30+at+7.11.38+PM.png)

### 3단계: 그룹에 캘린더 추가하기

그룹 캘린더를 만들면 팝업 창이 나타나고, 선택지가 두 가지 있어요.

1. **Choose Calendars**(캘린더 선택): 팝업에서 바로 그룹에 넣을 캘린더를 고를 수 있어요.
2. **I'll Do It Later**(나중에 할게요): 지금은 건너뛰고 나중에 그룹에 캘린더를 추가할 수 있어요.

   ![캘린더 선택 팝업](https://jumpshare.com/v/ALemq7ZutFibgGANpTs9+/Screen+Shot+2025-05-30+at+7.15.17+PM.png)
3. **Choose Calendars**를 클릭한 뒤, 그룹에 추가할 캘린더를 선택하세요.
4. **확인**을 클릭하세요.

   ![그룹에 추가할 캘린더를 선택하는 화면](https://jumpshare.com/v/umTpXTkUYetmOiZg88Ug+/Screen+Shot+2025-05-30+at+7.19.12+PM.png)

{% hint style="info" %}
캘린더가 하나도 보이지 않으면 개별 캘린더를 먼저 만들었는지 확인하세요.
{% endhint %}

{% hint style="info" %}
**변경사항 저장**을 클릭했을 때 필수 항목이 비어 있으면 하이퍼클래스가 해당 항목으로 자동 이동해 줘요. 오류가 현재 탭에 있으면 그 위치로 스크롤하고, 다른 탭에 있으면 해당 탭을 열어 줘요.
{% endhint %}

## 외부 캘린더와 동기화하기

팀원마다 캘린더 설정에서 **Primary Calendar**(기본 캘린더)를 지정해 두세요. 예약을 Google, Outlook 같은 외부 캘린더에 동기화하려면 이 설정이 필요해요.

자세한 내용은 "Assigning a Primary Calendar"(기본 캘린더 지정하기) 문서를 참고하세요.

## 자주 묻는 질문

### 그룹 캘린더 설정 화면에서 바로 캘린더를 만들 수 있나요?

아니요. 먼저 **캘린더** 탭에서 개별 캘린더를 만들어야 해요. 개별 캘린더를 만든 뒤에 그룹 캘린더에 넣을 수 있어요. 그룹 캘린더는 캘린더를 담는 상자일 뿐이라서, 개별 캘린더를 직접 만들거나 설정하지는 않아요.

### Class 캘린더나 Collective 캘린더도 그룹으로 묶을 수 있나요?

아니요. 그룹 캘린더는 **Class**(클래스)나 **Collective**(단체) 캘린더 유형과는 별개예요. 유형마다 구조와 동작이 달라요. 이 유형들은 사용 목적에 맞게 별도의 예약 흐름으로 운영하세요.

### 그룹 안에 있는 캘린더를 삭제하면 어떻게 되나요?

그룹 캘린더는 그대로 남지만, 삭제한 캘린더는 더 이상 예약 옵션으로 보이지 않아요. 캘린더를 편집하거나 삭제한 뒤에는 항상 그룹 구성을 확인하세요.

### 그룹 캘린더를 공유하거나 임베드하려면 어떻게 하나요?

하이퍼클래스 캘린더 임베드 가이드를 확인하세요.

### 그룹 캘린더 없이 여러 캘린더를 보여 줄 수 있나요?

네, 가능해요. 자세한 내용은 다중 캘린더 안내 문서를 참고하세요.
