# 캘린더 그룹 비활성화하기

캘린더 그룹 하나를 골라 그 안의 캘린더를 한 번에 비활성화하는 방법을 안내해요.

비활성화하려는 그룹 옆의 **ellipses**(점 세 개 아이콘)를 클릭하면 그룹 하나를 비활성화할 수 있어요.

1. **ellipses**를 클릭하면 **options**(옵션) 창이 열려요.
2. 옵션 창에서 **Deactivate all calendars in group**(그룹 내 모든 캘린더 비활성화) 항목을 확인하세요.
3. 이 항목을 클릭하면 확인을 요청하는 팝업이 나타나요.
