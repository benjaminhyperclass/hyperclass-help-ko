# 캘린더 예약 직접 등록하기

리드, 고객, 팀원을 대신해 캘린더 예약을 직접 등록하는 방법을 안내해요. 하이퍼클래스 안에서 예약을 여는 방법과, 예약하기 창에서 일정을 완성하는 순서를 알려 드려요.

---

## 직접 예약하기

하이퍼클래스에서는 여러 화면에서 예약을 직접 등록할 수 있어요. 연락처를 대신해 예약을 만들 때 유용하고, 시간대나 캘린더가 서로 다를 때 특히 편해요. 연락처와 대화하는 중이든, 캘린더를 관리하는 중이든, 연락처 프로필을 보는 중이든 몇 번의 클릭으로 일정을 잡을 수 있어요. 연락처가 오프라인이거나 답이 없거나 도움이 필요할 때도 직접 일정을 정할 수 있어요.

---

## 직접 예약의 장점

직접 예약을 쓰면 고객이 아무것도 하지 않아도 플랫폼 안에서 바로 예약을 잡을 수 있어요. 담당자가 직접 챙겨야 하는 업무, 급한 상황, 내부 일정 조율에 특히 잘 맞아요.

- 리드나 고객이 직접 예약하지 못하거나 하지 않을 때 대신 예약해요.
- 통화 중에 바로 예약해서 시간을 확보해요.
- SMS나 이메일로 받은 확인 답변에 맞춰 내 쪽에서 예약을 확정해요.
- 팀원과의 내부 미팅을 시스템 안에서 바로 잡아요.
- 워크플로우, 알림, 캘린더 로직을 점검할 테스트 예약을 만들어요.
- 정확한 날짜, 시간, 캘린더를 직접 골라요.
- 시간대를 자동으로 감지해 여러 시간대에 걸친 일정을 다뤄요.
- 반복 일정을 추가하고 시간을 차단해서 예약 가능 시간을 관리해요.

---

## 예약하기 기능을 여는 방법

**대화**, **연락처**, **캘린더**, **기회 관리**(Opportunities)에서 예약을 등록할 수 있어요. 작업 방식에 맞는 곳에서 시작하세요.

{% hint style="warning" %}
어디서 시작해도 예약을 등록할 수 있지만, 화면 모양은 조금씩 달라요. 예를 들어 **기회 관리**에서는 **Edit Opportunity**(기회 편집) 화면 안에서 예약 창으로 예약을 등록해요.
{% endhint %}

### 1. 대화에서 예약하기

연락처와 메시지를 주고받다가 바로 예약을 잡고 싶다면 **대화**가 가장 빨라요. **대화 > 연락처 선택 > 캘린더 아이콘**으로 이동하세요. 사이드바에 있는 **캘린더 아이콘**을 누르면 **예약하기** 버튼이 나타나요.

![대화에서 캘린더 아이콘을 눌러 예약하기 버튼이 나타난 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044741877/original/9dNnZQm8aHR5zThvvGtEgHAtntnvJqCRSQ.png?1744123045)

### 2. 연락처에서 예약하기

연락처 프로필에서 바로 예약을 등록할 수도 있어요. **연락처**에서 연락처를 열고, 오른쪽 영역의 **예약** 탭에서 **+ 추가**를 누르세요.

![연락처 프로필의 예약 탭에서 추가를 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044742474/original/0rQhMHQiBk1n0_O1iWU5-nyrPNYMII_Qzw.png?1744123387)

### 3. 캘린더에서 예약하기

눈으로 보면서 일정을 잡고 싶다면 캘린더 보기에서 시간 칸을 직접 누르세요. **캘린더 > 캘린더 보기**로 이동한 다음, **신규**를 누르거나 원하는 시간 칸을 눌러 예약을 등록해요.

![캘린더 보기에서 시간 칸을 눌러 예약을 등록하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044743458/original/vu_l_cdpp7twyMkT9bHib-sD8PYZG1wo-A.gif?1744123971)

### 4. 기회 관리에서 예약하기

기회에서 바로 예약을 등록하거나 수정할 수 있어요.

1. **기회 관리**로 이동해 예약을 업데이트할 기회를 열어요.
2. **Book/Update Appointment**(예약 등록/업데이트) 섹션을 열어요.
3. **+ New Appointment**(+ 새 예약)를 누른 뒤 **미팅**, **서비스**, **대여** 중 하나를 선택해요.
4. 예약 창에서 예약 세부 내용을 입력하고 저장해요.

![기회 관리에서 새 예약을 등록하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070882915/original/6IcsA9ejUNwXacsj-pzj_H1udFajJnWqLQ.gif?1778242143)

## 예약 등록하기 (예약하기 창을 연 뒤)

위 네 가지 방법 중 어느 쪽으로든 **예약하기** 창을 열었다면, 이후 순서는 모두 같아요. 캘린더와 연락처를 고르고, 세부 내용을 입력해서 예약을 마무리해요.

### 1단계: 캘린더와 연락처 선택

예약을 만들 캘린더와 예약을 연결할 연락처를 선택하세요.

![예약을 만들 캘린더와 연락처를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044890048/original/P6V4V2T1Emng7wYiM34jEG6oJ5BIW7hF8w.png?1744295033)

### 2단계: 예약 세부사항 입력

이 단계에서 예약의 핵심 정보인 제목, 시간, 장소, 반복 옵션을 입력해요. 하이퍼클래스가 시간대를 자동으로 감지하고, 사용자 지정 예약을 위한 입력 옵션도 제공해요.

- **예약 제목**: 예약 내용에 맞는 제목을 입력해요(예: "사라 님 상담"). 제목 아래에 설명도 추가할 수 있어요.
- **날짜 & 시간**: 시작 시간과 종료 시간을 선택해요. 화면에는 사용자의 시간대가 표시되고, **사용자 지정** 날짜 및 시간으로 전환할 수 있어요.
- **사용자 지정**:

  1. 사용자 지정 미팅 링크(예: Zoom, Teams, 실제 주소)를 직접 입력해요.
  2. 시작 시간과 종료 시간을 직접 선택해요.
  3. **반복 사용**으로 원하는 주기와 기간을 정해 반복 예약으로 만들 수도 있어요.
- **미팅 장소**: 기본, 사용자 지정, 연동된 화상 미팅 옵션 중에서 선택해요. 사용자 지정을 선택하면 미팅 링크를 직접 입력해야 해요.

![예약 세부사항을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044891461/original/6dY8kNO5UvXa6VpAAD5QXrd0_DrH6n_gjQ.png?1744295800)

---

### 3단계: 시간 차단하기 (선택)

**차단된 시간** 탭을 쓰면 특정 기간에 새 예약이 잡히지 않도록 막을 수 있어요. 휴식 시간, 개인 시간, 팀 교육, 휴가에 알맞아요. 특정 사용자 또는 캘린더 전체의 시간을 차단할 수 있고, **시작 시간**과 **종료 시간**도 지정해요.

![차단된 시간 탭에서 시간을 차단하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044891349/original/kwx00yjYRkjCV7SDVno6aiAytP9_RDBfSQ.png?1744295732)

{% hint style="warning" %}
**차단된 시간** 옵션은 특정 날짜와 시간에 예약 가능한 시간을 없앨 때 사용해요. 기존 예약은 삭제되지 않아요. 차단된 시간은 새 예약이 가능한 시간에만 영향을 줘요.
{% endhint %}

{% hint style="info" %}
**팁**

1. 캘린더를 내가 볼 수 있는 팀원이라면 누구의 예약이든 대신 등록할 수 있어요.
2. 시간대는 자동으로 처리되고, 예약 창에서 확인할 수 있어요.
3. 정기 세션이나 주기적인 점검에는 반복 예약을 사용하세요.
4. **차단된 시간** 탭을 활용하면 예약 가능 시간을 깔끔하게 관리할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 다른 팀원의 예약을 대신 등록할 수 있나요?
네, 예약 창의 드롭다운에서 해당 팀원의 캘린더를 선택하세요.

### 캘린더에 예약이 보이지 않아요.
올바른 캘린더와 연락처를 선택했는지 확인하세요. 캘린더 보기에 필터가 적용되어 있는지도 확인해 보세요.

### 기존 예약을 지우지 않고 시간만 차단할 수 있나요?
네, 차단된 시간은 새 예약만 막고 기존 예약은 그대로 둬요.

### 예약 시간이 연락처의 시간대에 맞춰 자동으로 바뀌나요?
네, 하이퍼클래스는 기본적으로 연락처의 시간대를 기준으로 예약 가능한 시간을 보여 줘요.
