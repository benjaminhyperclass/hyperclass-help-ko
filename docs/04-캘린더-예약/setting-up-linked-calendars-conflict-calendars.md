# 연결됨 캘린더와 충돌 캘린더 설정하기

Google, Office 365, Outlook.com 같은 외부 캘린더를 하이퍼클래스와 동기화하면 내 일정이 항상 최신으로 유지되고 중복 예약을 막을 수 있어요. **Connected Calendars**(연결된 캘린더)로 하이퍼클래스의 접근 권한을 허용하고, **연결됨 캘린더**로 외부 일정을 가져와 실제 가능한 시간을 보여 주세요. **충돌 캘린더**를 쓰면 다른 일정이 있는 시간에는 하이퍼클래스 예약 슬롯이 자동으로 막혀요.

## 연결된 캘린더, 연결됨 캘린더, 충돌 캘린더는 언제 쓰나요?

- **Connected Calendars**(연결된 캘린더): 외부 캘린더 계정의 일정을 하이퍼클래스가 읽을 수 있도록(필요하면 쓸 수도 있도록) 권한을 허용해요.
- **연결됨 캘린더**: 외부 캘린더의 일정과 가능한 시간을 하이퍼클래스로 가져와서, 실제로 바쁜 시간이 표시돼요.
- **충돌 캘린더**: 연결한 캘린더 중 일부를 '막는 용도'로 지정해요. 이 캘린더의 일정과 겹치는 하이퍼클래스 예약 슬롯은 자동으로 **불가** 상태가 돼요.

## 시작하기 전에

- **사용자 역할**: 서브 계정의 Admin(관리자) 또는 Manager(매니저) 권한이 필요해요.
- **외부 캘린더 계정**: 사용자마다 사용 중인 Google Calendar, Office 365 또는 Outlook.com 로그인 정보가 필요해요.

## 연결됨 캘린더 설정하기

### 1단계: 연결 탭으로 이동하기

하이퍼클래스 서브 계정의 왼쪽 메뉴에서 **설정 > 캘린더**로 이동한 다음, 위쪽의 **연결** 탭을 클릭하세요. 그러면 **캘린더**와 **Connected Calendars** 화면이 열려요.

![연결 탭으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047943546/original/6nBdgykHgbRT_uGAU8fK9U-OP5Rk7y2HhA.gif?1749472656)

### 2단계: 캘린더 추가하기

1. **Connected Calendars** 아래에서 **새로 추가 +** 를 클릭하세요.
2. 사용할 캘린더 서비스를 선택하세요. **Google**, **Outlook**, **iCloud**, **Calendly** 캘린더 중에서 고를 수 있어요.
3. 로그인한 뒤 하이퍼클래스가 일정을 **읽을 수 있도록** 권한을 허용하세요. 예약을 외부 캘린더에 다시 기록하려면 **쓰기** 권한도 허용하세요.
4. 연결에 성공하면 이메일 주소와 서비스 아이콘이 목록에 표시돼요.

![캘린더 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047943978/original/stEFOtKQ5zhCQXbs8zNrUfu19JMVsdKWIg.gif?1749473168)

{% hint style="warning" %}
**끊어진 연동은 다시 연결하세요**

**연동 다시 연결**이라는 빨간색 배너가 보이거나 캘린더 타일 테두리가 빨간색이면, 인증 토큰(OAuth token)이 만료됐거나 취소됐을 수 있어요. **재연결**을 클릭하고 하이퍼클래스에 다시 권한을 허용하면 접근이 복구돼요.

외부 서비스에서 캘린더가 삭제된 경우에는 배너에 **Fix This**(문제 해결하기) 옵션이 함께 표시될 수 있어요. **Fix This**를 클릭하면 삭제된 캘린더 목록을 모두 확인할 수 있고, **Remove Deleted Calendars**(삭제된 캘린더 제거)로 끊어진 연결을 정리할 수 있어요.

재연결하거나 변경한 뒤에는 자동으로 다시 동기화돼요. 이전에 끊어졌던 캘린더를 재연결하면, 동기화되지 않은 예정된 예약을 하이퍼클래스가 외부 캘린더로 자동 전송해요. 새 캘린더를 연결하거나 같은 연동 안에서 선택한 캘린더를 바꾸면, 앞으로의 예약이 새로 선택한 캘린더로 자동 재동기화돼요.
{% endhint %}

### 3단계: 연결됨 캘린더 구성하기

1. **캘린더 구성** 섹션의 **연결됨 캘린더** 아래에서 **추가**를 클릭하세요.
2. 하이퍼클래스로 일정을 가져올 캘린더를 **Connected Calendars** 중에서 선택하세요.
3. **저장**을 클릭하세요.

![연결됨 캘린더 구성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047944165/original/cmcw_3LVwMag0rf2j0gu5C_Lz6RqRe47IA.gif?1749473383)

{% hint style="warning" %}
**중요**

1. 캘린더를 연결됨 캘린더로 선택하려면 해당 사용자에게 쓰기 권한이 있어야 해요.
2. 연결됨 캘린더는 기본적으로 충돌 캘린더에도 추가돼요. 외부 연결됨 캘린더에서 만든 일정은 시스템으로 가져오고, 시스템에서 만든 일정은 외부 연결됨 캘린더로 전송해요.
3. 동기화 방식은 **고급 설정**의 **Sync Preferences**(동기화 설정)에서 정할 수 있어요.
{% endhint %}

## 서비스 예약을 연결된 외부 캘린더와 동기화하기

연결됨 캘린더를 쓰면 직원에게 배정된 **서비스 예약**이 다른 일정과 함께 캘린더에 표시돼요. 하루 일정을 확인하기 쉬워지고, Google, Outlook, iCloud 같은 여러 플랫폼에서 예약을 관리하기도 편해져요.

이제 서비스 예약을 **캘린더 설정 > 연결**에서 선택한 외부 연결됨 캘린더와 동기화할 수 있어요.

지원하는 연결됨 캘린더는 다음과 같아요.

- Google
- Outlook
- iCloud

{% hint style="warning" %}
**중요**

- 나에게 배정된 예약만 내가 선택한 연결됨 캘린더로 동기화돼요.
- 한 예약에 서로 다른 직원이 맡은 서비스가 여러 개 있으면, 각 직원은 자신의 연결됨 캘린더에서 자신에게 배정된 예약만 볼 수 있어요.
{% endhint %}

이렇게 하면 팀 전체의 서비스 일정이 더 정확하게 관리되고, 다른 사용자에게 배정된 예약이 불필요하게 노출되지 않아요.

## 동기화 방식 정하기 (고급 설정)

### 1. 기본 동기화 (단방향 동기화)

- 시스템에서 만든 일정은 연결됨 캘린더(예: Google)로 동기화돼요.
- 연결됨 캘린더(예: Google)에서 만든 일정은 시스템으로 동기화돼요.
  1. 이 일정들은 '막힌 시간(blocked slot)'으로 동기화돼요.
  2. 연결됨 캘린더(예: Google) 일정에 들어 있는 게스트는 연락처로 생성되지 않아요.
  3. 자동화·워크플로우가 실행되지 않아요.

![기본 동기화 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047945204/original/jZsOK6uuUHRASpqHvscqcdsB6DadEbS_fg.png?1749474582)

### 2. 양방향 동기화

- 시스템에서 만든 일정은 연결됨 캘린더(예: Google)로 동기화돼요.
- 연결됨 캘린더(예: Google)에서 만든 일정은 시스템으로 동기화돼요.
  1. 이 일정들은 예약으로 동기화돼요.
  2. 연결됨 캘린더(예: Google) 일정에 들어 있는 게스트가 연락처로 생성돼요.
  3. 시스템에서 만든 다른 예약과 똑같이 자동화·워크플로우를 실행할 수 있어요.

```
예시: 존이 Google 캘린더에 오후 1시부터 2시까지 '마크 선생님 진료 예약' 일정을 만들고, 마크 선생님을 게스트로 추가했어요.

기본 동기화(단방향 동기화): 오후 1시부터 2시까지 막힌 시간만 시스템에 추가돼요. 그래서 그 시간에는 아무도 예약할 수 없어요.

양방향 동기화: 오후 1시부터 2시까지 예약이 시스템에 만들어져요. 그래서 그 시간에는 아무도 예약할 수 없어요. 마크 선생님이 새 연락처로 생성되고, 워크플로우가 있다면 마크 선생님을 대상으로 실행돼요.
```

## 충돌 캘린더

충돌 캘린더로 추가한 외부 캘린더의 일정은 시스템으로 동기화되고, 그 일정이 진행되는 시간 동안 내 예약 가능 시간이 막혀요. 선택한 캘린더의 모든 일정을 읽어서, 사용자가 예약을 받을 수 없는 시간대를 막는 방식이에요. 외부 캘린더에서 'BUSY'(바쁨)로 표시된 일정만 가능 시간을 막아요. 'FREE'(한가함)로 표시된 일정은 시스템으로 가져오지만 가능 시간은 그대로 열려 있어요.

![충돌 캘린더 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047945538/original/sckXVuIxwCrhketzFQDkdTzL8lhoedKrbg.gif?1749474918)

덕분에 가능 시간이 정확하게 유지되고 중복 예약을 피할 수 있어요. 중복 예약을 막기 위해 확인할 캘린더를 여러 개 추가할 수도 있어요. 충돌 캘린더는 예약을 만들지 않아요. 외부 캘린더에 이미 잡혀 있는 일정의 시간만 막아요.

## 캘린더들은 이렇게 동작해요

1. **예약 요청**
   - 고객이 예약을 요청하면 하이퍼클래스가 **연결됨 캘린더**와 **충돌 캘린더**를 모두 확인해요. 일정이 겹치는 슬롯은 **불가** 상태가 돼요.
2. **양방향 동기화**
   - **Write Back Appointments**(예약을 외부 캘린더에 다시 기록)를 켜면 하이퍼클래스가 새 예약을 외부 캘린더에 기록해요.
   - 하이퍼클래스에서 예약을 취소하거나 일정을 변경하면 외부 캘린더에도 반영돼요.
   - **상태만 바꾸는 경우**: 예약을 참석(Showed) 또는 노쇼(No Show)로 표시해도 외부 캘린더는 업데이트되지 않아요. 외부 서비스에서 '일정이 변경되었습니다' 같은 이메일이 가지 않으면서, 상태 관리는 하이퍼클래스 안에서 계속할 수 있어요.
   - **변경 후 안정성**: 연동을 재연결하거나 업데이트하거나 다른 캘린더로 바꾸면, 하이퍼클래스가 예정된 예약을 자동으로 동기화해요. 직접 수정하지 않아도 외부 캘린더가 정확하게 유지돼요.
3. **캘린더 보기**
   - **캘린더** 탭에서 외부 일정은 음영 처리된 블록으로, 하이퍼클래스 예약은 색이 있는 일정으로, 막힌 슬롯은 **불가** 표시로 보여요.

## 활용 팁과 유의 사항

- **쓰기 연동은 한 곳만**: 중복 일정을 막으려면 주로 쓰는 업무용 캘린더 한 곳에서만 Write Back을 켜세요.
- **개인 일정도 막기**: 개인 캘린더를 **충돌 캘린더**로 연결하면 가족 일정이나 개인 일정 시간에 예약 슬롯이 자동으로 막혀요.
- **시간대 맞추기**: 외부 캘린더의 시간대를 하이퍼클래스 프로필의 시간대와 똑같이 맞추세요. 그래야 시간이 어긋나지 않아요.
- **주기적으로 다시 인증하기**: 외부 계정의 비밀번호나 보안 설정을 바꿨다면 하이퍼클래스에 다시 권한을 허용하세요. 그러면 연동이 끊어지는 일을 막을 수 있어요.

## 자주 겪는 문제

| 문제 | 원인 | 해결 방법 |
| --- | --- | --- |
| **연동이 끊어졌다고 표시돼요 (빨간 배너)** | 인증 토큰이 만료되었거나 취소됨 | **설정 > 캘린더 > 연결**에서 **재연결**을 클릭하고 다시 권한을 허용하세요. |
| **하이퍼클래스에 일정이 안 보여요** | 연결됨 캘린더가 선택되지 않았거나 동기화가 꺼져 있음 | **캘린더 구성 > 연결됨 캘린더**에서 **편집**을 클릭하고 **Sync Events**(일정 동기화)가 켜져 있는지 확인하세요. |
| **외부 일정이 있는 시간에도 예약할 수 있어요** | 충돌 캘린더가 켜져 있지 않음 | **충돌 캘린더**에서 **편집**을 클릭하고 **Use as Conflict Calendar**(충돌 캘린더로 사용)를 켠 다음 **저장**하세요. |
| **하이퍼클래스 예약이 외부 캘린더에 기록되지 않아요** | Write-Back 토글이 꺼져 있음 | 연결됨 캘린더 설정을 편집해서 **Write Back Appointments**를 켠 다음 **저장**하세요. |
| **외부 캘린더에 일정이 중복돼요** | 여러 캘린더에서 Write-Back이 켜져 있음 | 보조 캘린더의 Write-Back을 끄거나, 필요 없는 캘린더는 연결을 해제하세요. |
