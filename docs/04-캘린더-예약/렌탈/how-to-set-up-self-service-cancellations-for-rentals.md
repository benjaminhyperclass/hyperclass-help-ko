# 렌탈 셀프서비스 취소 설정 방법

고객이 환불, 결제, 보증금 관련 결정은 사업자가 직접 통제하면서도, 취소 링크를 통해 예정된 렌탈 예약(Appointment)을 스스로 취소할 수 있도록 설정하는 방법을 안내해 드려요.

## 이 문서에서 배울 내용

하이퍼클래스 렌탈(Rentals)은 고객에게 셀프서비스 취소 링크를 제공해서, 고객이 먼저 사업자 팀에 연락하지 않고도 예정된 예약을 스스로 취소할 수 있게 해줘요. 또한 예약 시작 시간으로부터 얼마나 가까운 시점까지 고객이 이 링크를 사용할 수 있는지도 제한할 수 있어요.

이 문서에서는 셀프서비스 취소가 어떻게 작동하는지, 취소 링크 만료 시점(선택 사항)을 어떻게 설정하는지, 고객이 취소를 어떻게 완료하는지, 여러 리스팅이 포함된 예약은 어떻게 처리되는지, 그리고 예약이 취소된 후 결제와 보증금은 어떻게 되는지 설명해 드려요.

## 1. 셀프서비스 취소 작동 방식

셀프서비스 취소를 이용하면 고객이 예약과 연결된 취소 링크를 통해 예정된 렌탈 예약을 직접 취소할 수 있어요. 전화를 걸거나 이메일을 보내거나 사업자 팀의 처리를 기다릴 필요 없이, 고객은 링크를 열어 예약 내용을 확인하고 바로 취소할 수 있어요.

고객은 별도의 승인 단계를 기다릴 필요가 없어요. 취소가 성공적으로 처리되면 예약이 즉시 취소되고 예약됐던 가능 시간(Availability)이 다시 풀려요. 이를 통해 고객 입장에서는 취소 절차가 더 빨라지고, 사업자 팀 입장에서는 수동으로 처리해야 하는 일상적인 취소 요청 건수가 줄어들어요.

> **핵심 취소 플로우에는 추가 설정이 필요 없어요**
>
> 셀프서비스 취소는 취소 가능한 예정 렌탈 예약에 기본으로 제공돼요. 취소 링크의 만료 시점을 직접 제어하거나, 링크를 별도의 맞춤 커뮤니케이션에 넣고 싶을 때만 추가 설정이 필요해요.

> **취소한다고 자동으로 환불이 처리되는 건 아니에요**
>
> 셀프서비스 취소는 예약(Appointment) 자체만 변경해요. 환불 여부 결정, 결제 처리, 보증금 처리는 여전히 사업자가 직접 관리해요.

## 2. 취소 가능 기간 설정

기본적으로 고객은 예약이 시작되기 전까지 언제든 취소 링크를 사용할 수 있어요. 만약 셀프서비스 취소를 더 일찍 마감하고 싶다면, 선택 사항인 취소 마감 기준을 설정할 수 있어요. 이렇게 하면 임박한 취소에 대해서는 사업자 팀이 더 많은 통제권을 가지면서도, 그 이전 요청은 고객이 스스로 처리하도록 할 수 있어요.

**1단계: 렌탈 전역 설정(Global settings) 열기**

`Calendars(캘린더) → Rentals(렌탈) → Global settings(전역 설정)`로 이동한 후 **Booking settings(예약 설정)**를 열어주세요.

**2단계: 취소 링크 만료 설정 활성화**

**Set cancellation link expiry(취소 링크 만료 설정)**를 켜면 고객이 예약 시작 시간에 너무 임박해서 셀프서비스 취소 링크를 사용하지 못하도록 할 수 있어요.

**3단계: 마감 기준 설정**

예약 시작 몇 시간/며칠 전에 링크가 만료되어야 하는지 입력하세요. 마감 기준은 **분, 시간, 일** 단위로 설정할 수 있어요. 예를 들어 만료 시점을 3시간으로 설정하면, 고객은 예약 시작 3시간 전까지 셀프 취소를 할 수 있어요.

**4단계: 변경 사항 저장**

**Save changes(변경 사항 저장)**를 선택하면 설정한 취소 링크 만료 시점이 렌탈 예약 경험에 적용돼요.

![취소 링크 만료 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080994737/original/NacceeTaC4UugxQb4WXU3IbpVXj9NqJfrA.png?1789485724)

> **이 설정을 꺼두면 어떻게 되나요?**
>
> 고객은 예약이 시작될 때까지 계속 셀프서비스 취소 링크를 사용할 수 있어요. 예약이 시작된 이후에는 셀프서비스 취소를 더 이상 이용할 수 없어요.

## 3. 고객 커뮤니케이션에 취소 링크 추가

취소 링크는 각 고객에게 본인 예약에 대한 셀프서비스 취소 페이지로 바로 연결되는 접근 경로를 제공해요. 지원되는 고객 알림(Notification)이나 예약 확인 경험을 커스터마이징할 때, 고객이 접근할 위치에 렌탈 취소 링크용 커스텀 값(Custom Value)을 삽입할 수 있어요.

**취소 링크 커스텀 값**

렌탈 취소 링크를 사용하려면 다음을 입력하세요:

```
{{rentalBooking.cancellation_link}}
```

이 커스텀 값을 예약 확인 메시지나 리마인더 메시지 등 고객이 취소 플로우로 바로 이동할 수 있는 링크를 받아야 할 위치에 넣어주세요. 특정 예약에 대한 커뮤니케이션이 발송될 때, 하이퍼클래스가 이 커스텀 값을 해당 예약의 취소 링크로 자동 치환해 줘요.

> **링크의 목적을 명확히 알려주세요**
>
> 직접 작성하는 고객 메시지에 링크를 추가할 때는 "예약 취소하기"처럼 명확한 문구를 사용해서, 고객이 이 링크가 일반 예약 관리 페이지가 아니라 예약 취소를 실행하는 링크라는 것을 알 수 있도록 해주세요.

> **고객 셀프서비스**
>
> **재정 관련 결정을 자동화하지 않고도 고객이 직접 취소하게 할 수 있어요**
>
> 고객은 직접 예약 취소를 처리할 수 있고, 사업자 팀은 환불, 결제 조정, 보증금 처리에 대한 통제권을 계속 유지할 수 있어요.

## 4. 취소 시 고객에게 표시되는 화면

고객이 유효한 취소 링크를 열면 고객용 취소 페이지로 이동해요. 이 페이지에는 예약 정보가 표시되므로, 고객은 진행하기 전에 자신이 올바른 예약을 취소하고 있는지 확인할 수 있어요.

**1단계: 예약 내용 확인**

고객은 페이지에 표시된 리스팅 정보, 예약 날짜, 기타 예약 세부사항을 확인해요.

**2단계: 취소 사유 입력 (선택 사항)**

**Cancellation reason(취소 사유)** 필드는 고객이 취소 이유를 설명할 수 있는 공간이에요. 이 필드는 선택 사항이라서 고객이 사유를 입력하지 않아도 계속 진행할 수 있어요.

**3단계: Cancel booking(예약 취소) 선택**

고객이 **Cancel booking(예약 취소)**을 선택하면 셀프서비스 취소가 완료돼요.

![취소 페이지 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080994936/original/tYRlkDrWaUbbsJo0QevpPe3Wn35sFcFVKw.png?1789485839)

> **취소 사유를 수집하는 이유는 무엇인가요?**
>
> 사유 입력은 필수는 아니지만, 고객과 별도로 추가 대화를 나누지 않아도 사업자 팀이 취소에 대한 유용한 맥락을 파악할 수 있게 해줘요.

## 5. 여러 리스팅이 포함된 예약 처리 방식

하나의 렌탈 예약에는 두 개 이상의 리스팅이 포함될 수 있어요. 고객이 여러 리스팅이 포함된 예약의 취소 페이지를 열면, **Booking details(예약 상세)** 영역에 해당 예약에 속한 리스팅들과 각 항목의 관련 날짜가 표시돼요.

셀프서비스 취소는 예약 전체에 적용돼요. 고객이 리스팅 하나만 선택해서 제외하고 나머지는 유지하는 방식은 지원되지 않아요. **Cancel booking(예약 취소)**을 선택하면 예약 전체가 함께 취소돼요.

> **여러 리스팅 취소는 전부 취소되거나 전부 유지되는 방식이에요**
>
> 셀프서비스 취소는 선택한 리스팅 하나가 아니라 예약 전체에 적용되기 때문에, 고객은 진행하기 전에 Booking details에 표시된 모든 리스팅을 확인해야 해요.

## 6. 취소 후 발생하는 일

고객이 취소를 완료하면 예약이 취소되고 고객에게 확인 페이지가 표시돼요. 이를 통해 고객은 예약이 아직 유효한지 불확실해하지 않고, 요청이 성공적으로 처리되었다는 즉각적인 확인을 받을 수 있어요.

![취소 완료 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080995195/original/HBRlM0CByYe_BPVtXrg03CfvQMktul9nzw.png?1789485928)

취소된 예약은 더 이상 렌탈 가능 시간을 점유하지 않아요. 이후 사업자 팀은 예약을 검토하고, 자사의 비즈니스 및 취소 정책에 맞는 별도의 재정적 조치를 취할 수 있어요.

> **예약 취소와 재정적 조치는 별개예요**
>
> 예약을 취소한다고 해서 환불 여부가 자동으로 결정되지는 않아요. 이를 통해 환불 금액, 결제 변경, 보증금 처리 결정은 계속 사업자가 통제할 수 있어요.
>
> 예를 들어, 사업자마다 예약을 얼마나 일찍 취소했는지에 따라 다른 취소 정책을 적용할 수 있어요. 셀프서비스 취소는 고객이 예약을 해제할 수 있게 해주지만, 환불 관련 조치를 취하기 전에 사업자 팀이 자체 재정 정책을 적용할 수 있어요.

## 7. 만료되거나 이미 사용된 링크

취소 링크는 예약이 셀프서비스 취소 대상일 때만 유효해요. 예약이 이미 취소됐거나, 설정된 취소 가능 기간이 지났거나, 예약이 이미 시작됐거나 완료된 경우에는 고객이 해당 링크로 더 이상 취소를 진행할 수 없어요.

고객이 더 이상 취소에 사용할 수 없는 링크를 열면, 하이퍼클래스는 기술적인 오류 메시지 대신 고객이 이해하기 쉬운 안내 메시지를 보여줘요. 이를 통해 고객은 해당 링크로는 취소가 완료될 수 없다는 것을 이해할 수 있어요.

> **셀프서비스 취소는 취소 가능한 예정 예약에만 해당돼요**
>
> 예약이 이미 시작되었거나 완료된 경우, 또는 설정된 취소 마감 기준이 지난 경우에는 고객이 추가 도움이 필요할 때 사업자에게 직접 문의해야 해요.

## 8. 자주 묻는 질문

**Q: 고객이 취소하려면 Set cancellation link expiry를 꼭 활성화해야 하나요?**

아니요. 만료 설정은 선택 사항이에요. 비활성화 상태로 두면, 취소 가능한 고객은 예약이 시작되기 전까지 취소 링크를 사용할 수 있어요.

**Q: 예약 직전에 고객이 취소하지 못하도록 막을 수 있나요?**

네. 렌탈 전역 설정(Global settings)에서 **Set cancellation link expiry**를 활성화하고, 예약 시작 전 몇 분/몇 시간/며칠 전으로 마감 기준을 설정하면 돼요.

**Q: 취소 사유는 필수 입력 항목인가요?**

아니요. 고객은 선택적으로 취소 사유를 입력할 수 있지만, 입력하지 않고도 취소를 완료할 수 있어요.

**Q: 취소하면 자동으로 환불이 되나요?**

아니요. 셀프서비스 플로우는 예약만 취소하며, 환불 및 결제 결정은 별도로 사업자의 업무 프로세스에 따라 처리해야 해요.

**Q: 고객이 취소하면 보증금은 어떻게 되나요?**

셀프서비스 취소는 보증금 처리 방식을 자동으로 결정하지 않아요. 적절한 보증금 처리는 사업자가 계속 책임져요.

**Q: 여러 리스팅이 포함된 예약에서 고객이 리스팅 하나만 취소할 수 있나요?**

아니요. 셀프서비스 취소는 예약 전체에 적용돼요. 해당 예약에 포함된 모든 리스팅이 함께 처리돼요.

**Q: 예약이 시작된 후에도 고객이 취소할 수 있나요?**

아니요. 셀프서비스 취소는 예약이 시작되기 전에만 가능해요. 예약이 진행 중이거나 완료된 후에는 취소 링크로 더 이상 취소할 수 없어요.

**Q: 렌탈 취소 링크에는 어떤 커스텀 값을 사용하나요?**

지원되는 고객 커뮤니케이션에 예약별 취소 링크를 추가할 때는 `{{rentalBooking.cancellation_link}}`를 사용하세요.
