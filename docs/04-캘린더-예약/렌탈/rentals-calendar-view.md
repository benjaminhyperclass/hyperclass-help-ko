# 대여 캘린더 보기

**대여**(Rentals)의 **캘린더 보기**에서는 모든 예약, 차단된 슬롯, 리스팅의 예약 가능 여부를 한 화면에서 관리할 수 있어요. 이 문서에서는 캘린더 이동 방법, 필터로 보기 정리하는 방법, 이 화면에서 바로 새 예약을 만드는 방법을 안내해요.

## 대여 캘린더 보기란?

**캘린더 보기**는 모든 예약과 리스팅의 예약 가능 여부를 시간순으로 보여 줘요. 이미 찬 슬롯, 비어 있는 기간, 겹치는 예약을 리스팅이나 변형별로 쉽게 확인할 수 있어요. 새로 바뀐 레이아웃은 화면 공간이 더 넓고 필터가 간결해서, 예약이 많아도 보기 편해요.

**캘린더 보기**에서는 다음 작업을 할 수 있어요.

- 모든 리스팅의 예약을 일 단위나 주 단위로 한눈에 확인해요.
- 카테고리, 상태, 결제 상태로 리스팅과 예약을 걸러 봐요.
- 캘린더에서 바로 새 예약을 만들어요.
- 기존 예약을 빠르게 열어서 편집해요.

---

## 캘린더 보기의 장점

- 한눈에 보는 일정 관리: 일, 주, 월 단위로 예약을 보면서 빈 구간과 겹치는 구간을 빠르게 찾아요.
- 집중된 화면 구성: 리스팅, 변형, 대여 상태를 **미팅**/**서비스**와 분리해서 볼 수 있어요.
- 똑똑한 필터: 리스팅, 카테고리, 예약 상태, 결제 상태로 범위를 좁혀 업무를 분류해요.
- 빠른 예약 등록: 캘린더에서 바로 새 예약을 만들고, 기존 예약은 한 번 클릭으로 열어요.
- 도구 간 일관성: 여기서 만든 예약은 **예약 목록 보기**에도 바로 나타나서 운영 정보가 항상 맞아요.

---

## 캘린더 보기의 스케줄링 유형

**캘린더 보기**는 플랫폼의 여러 스케줄링 유형을 지원해서, 서로 다른 캘린더 환경이 겹치지 않고 함께 쓰여요. 그중 **대여**는 **미팅**, **서비스**와 구분되는 전용 스케줄링 유형이에요.

#### 스케줄링 유형 한눈에 보기

1. **미팅**

   - 영업 캘린더, 수업, 개인 또는 공동 일정에 알맞아요.
   - 개인, 라운드 로빈, 단체, 클래스 캘린더 등 기존 캘린더 유형이 포함돼요.
   - 팀이나 개인이 고객 미팅이나 내부 세션을 관리할 때 쓰도록 만들었어요.
2. **서비스**

   - 서비스업을 위해 만든 유형이에요.
   - 변형 옵션, 애드온, 복수 서비스, 직원별 가격 같은 고급 옵션을 지원해요.
   - 직원, 여러 서비스 유형, 여러 지점이 얽힌 예약을 관리하는 데 도움이 돼요.
3. **대여**

   - 대여업을 위해 만든 별도의 스케줄링 유형이에요.
   - 여러 날에 걸친 예약, 예약 가능 여부 추적, 자원 기반 일정 관리에 초점을 맞췄어요.
   - 리스팅 변형, 재고, 기간에 따른 가격 조정 같은 고급 기능을 지원해요.
   - **서비스**와 별개로, **대여**에는 자체 예약 흐름, 인보이스 로직, 전역 설정이 있어요.

#### 스케줄링 유형 켜기·끄기

- 스케줄링 유형은 **에이전시 설정**에서 관리해요(에이전시 관리자만 쓸 수 있어요).
- **대여** 같은 유형 하나만 켜져 있으면 **캘린더 보기**가 자동으로 그 유형으로 열리고, 스케줄링 유형 선택 메뉴는 보이지 않아요.
- **미팅**과 **대여**처럼 여러 유형이 켜져 있으면 **캘린더 보기** 상단에 드롭다운이 나타나서 유형을 바꿀 수 있어요.

#### 유형을 바꾸면 화면이 달라져요

드롭다운으로 스케줄링 유형을 바꾸면 다음과 같이 바뀌어요.

- 레이아웃과 필터 옵션이 선택한 유형에 맞게 달라져요.
- 유형이 섞여 헷갈리지 않도록, 각 유형에는 그 유형의 예약, 차단된 슬롯, 필터만 표시돼요.
- 예를 들어 **대여**에서는 리스팅, 변형, 대여 예약이 보이고, **미팅**에서는 예약(appointment)이 보여요.

{% hint style="info" %}
**Calendar View Enhancements**(캘린더 보기 개선, 실험실 플래그)는 **대여**가 활성화되면 자동으로 켜져요.
{% endhint %}

## 캘린더 보기 화면 구성

**캘린더 보기**는 세 영역으로 나뉘어요.

#### 1. 리스팅 (왼쪽)

- 모든 리스팅과 변형을 접었다 펼 수 있는 목록으로 보여 줘요.
- 리스팅 이름을 펼치면 변형이 있는 경우 변형이 나타나요.
- 이 패널에서 리스팅과 해당 리스팅의 진행 중인 예약을 눈으로 맞춰 볼 수 있어요.

![왼쪽 리스팅 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056624276/original/PdaI80JH3u9WWYSQsRnlfOnjeN6BKAanqQ.png?1761155999)

#### 2. 캘린더 그리드 (가운데)

- 선택한 기간의 예약을 보여 줘요.
- 예약 블록 하나는 예약된 기간 하나를 뜻해요.
- 예약 위에 마우스를 올리면 고객 이름, 리스팅, 기간, 예약 상태가 담긴 툴팁이 나타나요.
- 블록 색상은 예약 상태를 나타내요.

  - 연한 파란색: 예약됨
  - 파란색: 진행 중
  - 녹색: 완료
  - 빨강: 취소됨
  - 채워지지 않은 회색: 미확정
- 예약 블록을 클릭하면 **예약 상세정보**가 열려요.

![예약이 표시된 캘린더 그리드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056624295/original/SD40G9wvQKT_NDhnlc5efD5TFZSisDqWzA.png?1761156028)

#### 3. **Manage View**(보기 관리) 패널 (접었다 펼 수 있어요)

- 필터와 표시 설정을 조절해요.
- 여러 필터 카테고리로 캘린더에 표시할 내용을 좁힐 수 있어요.

![보기 관리 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056624314/original/2s7Il0c3vUI7cJ5v92I97E90b1mE3QNxrg.png?1761156066)

## 탐색 컨트롤

상단 탐색 바에서 예약을 보고 관리하는 방식을 빠르게 조절할 수 있어요.

| 컨트롤 | 설명 |
| --- | --- |
| **오늘** | 현재 날짜로 바로 이동해요. |
| **날짜 선택** / 화살표 | 시간을 앞뒤로 이동해요. |
| **일** / **주** / **개월** 보기 | 세부 보기와 넓은 보기 사이를 전환해요. |
| **대여** 드롭다운 | **서비스**, **대여** 같은 모듈 사이를 전환해요. |
| **Manage View** | 캘린더의 필터와 사용자 지정 옵션을 열어요. |
| **+ 신규** | 캘린더에서 바로 새 예약을 만들어요. |

{% hint style="info" %}
**일**과 **주** 보기는 운영 계획을 짜기에 좋고, **개월** 보기는 예약 가능 여부와 점유 추세를 크게 훑어볼 때 좋아요.
{% endhint %}

## Manage View 사용하기

**Manage View** 패널에서 예약과 리스팅을 걸러서 필요한 정보에 집중할 수 있어요.

#### View by Type(유형별 보기)

- **전체**: 예약과 차단된 슬롯을 모두 표시해요.
- **예약**: 대여 예약만 표시해요.
- **차단된 슬롯**: 직접 차단한 예약 불가 슬롯과 외부 서비스에서 가져온 차단을 표시해요.

#### 사용할 수 있는 필터

- **리스팅** – 캘린더에 표시할 특정 리스팅이나 변형을 선택해요.
- **카테고리** – 아파트, 차량, 장비 같은 카테고리별로 예약을 걸러요.
- **상태** – 예약 상태(미확정, 예약됨, 진행 중, 완료, 취소됨)로 걸러요.
- **결제 상태** – 결제 진행 정도(대기 중, 부분 결제됨, 결제 완료)로 예약을 걸러요.

**검색**으로 리스팅, 카테고리, 상태를 빠르게 찾고, **모두 지우기**로 필터를 초기화하세요.

## 예약 표시와 사용 방법

- 각 예약은 그리드에 색이 있는 블록으로 표시돼요.
- 블록 위에 마우스를 올리면 고객 이름, 예약 ID, 날짜, 상태가 담긴 요약 툴팁을 볼 수 있어요.- 예약을 클릭하면 상세 화면이 열려요.
- 같은 리스팅이나 변형에 예약이 둘 이상 있으면 캘린더 보기의 크기가 자동으로 늘어나요.

{% hint style="info" %}
여기에 표시되는 시간대는 **내 프로필**에서 **View Appointments In**(예약을 볼 시간대)에 설정한 사용자 시간대와 같아요.
{% endhint %}

## 캘린더 보기에서 예약 만들기

관리자는 **+ 신규** 버튼을 누르거나, 캘린더 그리드에서 예약 가능한 날짜를 끌어서 새 예약을 만들 수 있어요.

### 방법 1: + 신규 버튼 사용하기

1. 오른쪽 상단의 **+ 신규** 버튼을 클릭하세요.
2. 고객, 리스팅, 기간 등 예약 정보를 입력하세요.
3. **저장**을 클릭하세요.

새 예약은 바로 캘린더에 나타나고 **예약 목록 보기**와 동기화돼요.

{% hint style="info" %}
**캘린더 보기**에서 바로 예약을 만들면 리스팅의 예약 가능 여부와 맞게 등록하기 쉬워요.
{% endhint %}

![새 예약 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056624383/original/Don0KNnrWSttqXpzdVMoX8gCjxaAwwpbUQ.png?1761156199)

### 방법 2: 끌어서 만들기

캘린더 그리드 안에서 날짜나 시간 범위를 선택해 바로 예약을 만들 수 있어요.

1. **리스팅** 행에서 미래 날짜나 시간 슬롯 위를 클릭한 채로 끄세요.
2. 마우스를 놓으면 예약 생성 패널이 열려요. 선택한 시작·종료 날짜와 시간이 자동으로 채워져 있어요.
3. 예약 정보를 입력한 뒤 **예약 생성**을 클릭하세요.

{% hint style="warning" %}
끌어서 만들기는 미래 날짜에만 쓸 수 있어요. 과거 날짜와 오늘 날짜에는 지원하지 않아요. 오늘 날짜의 예약은 **+ 신규** 버튼으로 만드세요.
{% endhint %}

![끌어서 예약을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070745965/original/8KrlIYVm6nxWy0PD0tFoVgIwk5HHXEEavw.png?1778098112)

## 차단된 슬롯

차단된 슬롯을 쓰면 고객 예약이나 주문을 만들지 않고도 리스팅을 판매 대상에서 뺄 수 있어요. 차단된 슬롯을 만들면 선택한 기간 동안 리스팅을 예약할 수 없고, 모든 예약 흐름에 예약 가능 여부가 반영돼요.

차단된 슬롯을 만들려면 예약을 만들 때 **이벤트 유형**을 **차단된 슬롯**으로 설정하세요.

자세한 내용은 '대여 리스팅의 차단된 슬롯' 문서를 참고하세요.

{% hint style="info" %}
예시: 차량이 정비 중이라면 차단된 슬롯을 만들어서 그 기간에 예약이 겹치지 않게 할 수 있어요.
{% endhint %}

![차단된 슬롯을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071251873/original/9cPjJxBOSCK9JCwclVu4e_EmUSCZxzwqVA.png?1778684168)

## 활용 팁

- 리스팅이 여러 개라면 **주** 보기를 쓰면 운영 상황을 파악하기 좋아요.
- 예약 위에 마우스를 올리면 캘린더를 벗어나지 않고 상세 내용을 미리 볼 수 있어요.
- 성수기에는 **Manage View > 카테고리** 또는 **상태** 필터로 화면을 단순하게 만드세요.

## 자주 묻는 질문

### 캘린더에서 바로 예약을 편집하거나 끌어서 옮길 수 있나요?
현재는 예약 블록을 클릭해서 **Edit Booking**(예약 편집) 페이지를 열어야만 편집할 수 있어요.

### 색상은 각각 무슨 뜻인가요?
색상은 예약 상태를 나타내요. 연한 파란색은 예약됨, 파란색은 진행 중, 녹색은 완료, 빨강은 취소됨, 회색(채워지지 않음)은 미확정이에요.

### 차단된 슬롯을 숨길 수 있나요?
네. **Manage View > View by Type > 예약**을 선택하면 확정된 예약만 표시돼요.
### 캘린더 변경 사항이 실시간으로 반영되나요?
네. 접속 중인 모든 사용자의 캘린더가 자동으로 새로고침돼요.

### 리스팅이 보이지 않아요.
**Manage View** 필터를 확인해 보세요. 특정 리스팅, 상태, 결제 상태 필터가 적용되어 있을 수 있어요.

### 외부 플랫폼에서 새 예약이 들어왔는데 캘린더 보기에 안 보여요.
외부 플랫폼의 예약은 몇 시간마다 자동으로 동기화돼요. 직접 다시 동기화해서 예약을 가져오려면 해당 리스팅 > **편집** > Calendar Sync(캘린더 동기화) 탭으로 이동한 뒤, 가져온 캘린더 옆의 **새로고침** 아이콘을 클릭하세요.
