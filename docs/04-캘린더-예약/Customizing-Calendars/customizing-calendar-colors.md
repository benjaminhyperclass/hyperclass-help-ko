# 캘린더 색상 바꾸기

예약 캘린더의 색상을 브랜드 색상에 맞춰 바꾸는 방법을 알려 드려요. 로고와 캘린더 색이 달라 어색할 때 활용해 보세요.

## 캘린더 색상을 맞춰야 하는 이유

브랜드의 일관성을 지키려면 모든 자료에 같은 색상 체계를 쓰는 것이 중요해요.

예약 캘린더처럼 고객이 보는 자료의 색상을 바꾸면 고객에게 더 눈에 띄고, 깔끔하고 단정한 인상을 줄 수 있어요.

아래 이미지를 보면 회사 로고는 분명한 빨간색인데, 캘린더 요소는 모두 파란색이에요. 브랜드의 일관성을 지키려면 캘린더도 로고에 맞춰 빨간색으로 바꿔야 해요.

![로고는 빨간색인데 캘린더는 파란색인 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030366782/original/zfs8Tv7KlDog4CVixn6B3pKcRfID4rMr9g.jpg?1722612913)

## 캘린더 색상 바꾸는 방법

아래 인터랙티브 가이드를 따라 하면 캘린더 색상을 바꿀 수 있어요. 더 자세한 설명이 필요하면 가이드 아래의 안내를 이어서 읽어 보세요.

{% hint style="warning" %}
NEO 캘린더 스타일을 쓸 때만 캘린더 색상을 바꿀 수 있어요.

![NEO 캘린더 스타일 안내 이미지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030367091/original/FO4uAkBUun_dQk5VOTVHWUorGLwy9O8tHg.png?1722613320)
{% endhint %}

### 1단계: 캘린더 설정으로 이동하기

캘린더 색상을 바꾸려면 먼저 캘린더 설정 화면으로 가야 해요.

1. 왼쪽 메뉴에서 **캘린더**를 클릭하세요.
2. 화면 위쪽 메뉴에서 **캘린더 설정**을 클릭하세요.

![캘린더 설정으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030254627/original/3PH8h4gMtf1YqWNdk6Hvs6BFBQEhotNoHQ.gif?1722449472)

### 2단계: 캘린더 편집하기

**캘린더 설정** 화면에서 새 캘린더를 만들거나, 이미 있는 캘린더를 열어야 색상을 바꿀 수 있어요.

1. 캘린더 표의 맨 오른쪽 **ACTION DROPDOWN**(작업 드롭다운) 열에 있는 점 3개 아이콘을 클릭하세요.
2. 작은 팝업이 나타나면 **편집** 버튼을 클릭하세요. 선택한 캘린더의 편집 화면이 열려요.

![캘린더 표에서 점 3개 아이콘을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030256790/original/VlHMl5JGZSD6qclnqKkzbpOMUZYqqE3hxQ.gif?1722453959)

![편집 버튼이 보이는 팝업 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030254272/original/-cAdV9q31OkJgkeCBUd26VIINr-_wvxZCA.jpg?1722448977)

### 3단계: 사용자 지정 탭 열기

캘린더 편집 화면에 들어가면 왼쪽에 작은 메뉴가 보여요. 이 메뉴의 맨 아래 항목이 **사용자 지정**이에요.

**사용자 지정** 탭을 클릭하면 캘린더 색상을 조정할 수 있어요.

![왼쪽 메뉴의 사용자 지정 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030254082/original/bTve_bpyk7hnSoOIhCmZhh7FrOWqk1Kwpw.jpg?1722448622)

### 4단계: 색상 바꾸기

**사용자 지정** 탭에서 아래로 스크롤하면 색상 선택기가 보여요. 캘린더 색상은 **기본 색상**과 **배경 색상**, 두 가지를 바꿀 수 있어요. 두 항목 모두 HEXA 코드를 입력하거나, 색상 선택기 안에서 포인터를 움직여 색을 고를 수 있어요.

![기본 색상과 배경 색상 색상 선택기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030254115/original/64mGCoCHWcwVzjkkpGvjKCjlzSRS5Eknpg.jpg?1722448670)

- HEXA 코드: #으로 시작하는 코드예요. 여러 비즈니스가 다양한 자료에서 브랜드 색상을 똑같이 맞추려고 많이 써요.
- 색상 슬라이더: 색상 선택기의 작은 원을 클릭한 채 움직여서, 브랜드나 스타일에 맞는 색을 직접 고를 수 있어요.

![HEXA 코드와 색상 슬라이더로 색상을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030367415/original/YEjSjZRqDoKXqgYMZAyyhURnNwk1WYs9gQ.jpg?1722613740)

### 완성된 모습

아래 이미지를 보면 캘린더 색상을 바꾼 뒤 브랜드 색상이 일관되게 맞춰졌어요.

![색상을 바꾼 뒤 로고와 색이 맞춰진 캘린더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030367302/original/T34kHZPDOf8hEhIGwX6esj-qPreAg694ng.jpg?1722613546)

## 자주 묻는 질문

### 캘린더 색상을 바꾸면 어떤 부분이 달라지나요?

아래 영상처럼 색상을 바꾸면 캘린더의 여러 부분이 달라져요. **기본 색상**과 **배경 색상**이 각각 캘린더의 분위기를 어떻게 바꾸는지 보여 드리려고 예시를 두 개 준비했어요.

**기본 색상**을 바꾸면 달라지는 부분:

![기본 색상을 바꿨을 때 달라지는 부분](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030369132/original/-goqbzdqN7QiE9V854FIHDWUjiSPYzSm6w.gif?1722615470)

**배경 색상**을 바꾸면 달라지는 부분:

![배경 색상을 바꿨을 때 달라지는 부분](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030369268/original/HG228S4k6nK2K60XK7kPe2-EIHkJOQPznQ.gif?1722615686)
