# 리치 텍스트 편집기로 캘린더 설명 꾸미기

캘린더 설명에 리치 텍스트 편집기를 쓰면 글자 서식, 목록, 링크, 색상 등을 적용할 수 있어요. 예약하는 사람이 읽기 쉽고 브랜드 분위기에 맞는 설명을 만들고 싶을 때 사용하세요.

## 새로 생긴 기능

리치 텍스트 편집기에서는 다음 서식을 쓸 수 있어요.

- 텍스트 서식: 굵게, 기울임꼴, 밑줄, 취소선
- 목록: 글머리 기호 목록과 번호 목록
- 하이퍼링크: 예약 위젯에서 다른 페이지로 이동할 수 있는 클릭 가능한 링크
- 텍스트 색상과 **배경 색상**: 테마에 맞게 글자색과 배경색 지정
- 단락과 제목: 단락과 여러 단계의 제목으로 내용 정리
- **텍스트 정렬**: 왼쪽, 가운데, 오른쪽 중 원하는 방향으로 정렬

이 서식을 활용하면 중요한 정보를 눈에 띄게 하고, 읽기 쉽게 만들고, 브랜딩에 맞는 캘린더 설명을 꾸밀 수 있어요.

## 사용 방법

1. **캘린더 설정**으로 이동한 다음, 편집할 캘린더를 선택하세요.
2. **Meeting Details**(미팅 상세) 섹션으로 이동하세요.
3. 캘린더 설명 입력란 아래에 리치 텍스트 편집기 옵션이 보여요.
4. 원하는 서식 옵션을 사용해 설명을 작성하세요.
5. **저장**을 클릭해 변경 내용을 적용하세요.
