# 현장 서비스의 방문 상태

방문 상태를 쓰면 각 방문이 지금 어느 단계인지 팀 모두가 같은 정보를 볼 수 있어요. **현장 서비스**(Field Services)는 방문 상태를 고정된 여섯 가지 상태 그룹으로 나누고, 각 그룹 안에서 팀이 쓰는 말에 맞게 레이블을 직접 만들 수 있어요.

{% hint style="info" %}
현장 서비스는 현재 비공개 베타 기능이며, 선택된 계정에서만 쓸 수 있어요. 기능과 화면은 개선 과정에서 바뀔 수 있어요.
{% endhint %}

## 방문 상태란?

모든 방문에는 **시작 안 함**, **On my way**(이동 중), **체크인 완료**, **완료** 같은 상태 레이블이 있어요. 각 레이블은 여섯 가지 상태 그룹 중 하나에 속해요. 상태 그룹은 현장 서비스와 다른 도구가 리포팅과 로직에 쓰는 기준이에요. 레이블은 팀원에게 보이는 이름이에요.

## 여섯 가지 방문 상태 그룹

상태 그룹은 고정되어 있어서 바꿀 수 없어요.

| 상태 그룹 | 의미 | 기본 레이블 |
| --- | --- | --- |
| **대기 중** | 예약은 됐지만 아직 시작하지 않았어요. | 시작 안 함 |
| **활성** | 직원이 이동 중이거나 작업 중이에요. | On my way, 체크인 완료 |
| **완료** | 작업이 끝났어요. | 완료 |
| **노쇼** | 고객이 현장에 없었어요. | 노쇼 |
| **취소됨** | 방문이 진행되지 않아요. | 취소됨 |
| **무효** | 실수로 만들어졌어요. 리포팅에서 제외돼요. | 무효 |

---

## 방문 상태 변경하기

1. 캘린더, 방문 목록, 작업 중 한 곳에서 방문을 열어요.
2. 방문 패널 아래쪽의 **상태** 드롭다운을 사용해요. 방문 목록에서는 **상태** 열을 사용해도 돼요.
3. 새 상태를 선택해요. 목록은 상태 그룹별로 묶여 있어요.

---

## 상태 레이블 관리하기

1. **현장 서비스 > Field Services Settings**(현장 서비스 설정) **> 글로벌 설정**으로 이동해요.
2. **Operations**(운영)에서 **Jobs, visits and requests**(작업, 방문, 요청)를 열고 **Visit statuses**(방문 상태)를 클릭해요.
3. 상태 그룹을 클릭해 펼치면 그 그룹의 레이블이 보여요.
4. 그 그룹에 레이블을 추가하려면 **새 상태**를 클릭해요. 순서를 바꾸려면 레이블 옆의 핸들을 끌어서 옮겨요.
5. **변경사항 저장**을 클릭해요.

![방문 상태 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162856/original/E5XpzKXbI-MXrP19p5HAePxf-1wmzpVkuw.jpg?1792999558)

예를 들어 배관 업체라면 **대기 중**과 **활성** 그룹에 *기사 배정됨*, *이동 중*, *작업 시작*, *작업 완료* 같은 레이블을 추가할 수 있어요.

## 방문 상태가 작업에 미치는 영향

작업의 상태는 그 작업에 속한 방문들을 바탕으로 정해져요. 예를 들면 이래요.

- 예약된 방문이 없는 작업은 **Unscheduled**(미예약)예요.
- 예약된 방문이 있는 작업은 **예약됨**이에요.
- 진행 중인 방문이 있는 작업은 **진행 중**이에요.

직접 만든 레이블은 소속된 상태 그룹을 따라가요. 그래서 레이블 이름을 바꿔도 작업이 동작하는 방식은 달라지지 않아요. **무효**로 설정한 방문은 리포팅에서 제외돼요. 자세한 내용은 [현장 서비스의 작업](jobs-in-field-services.md)을 참고하세요.

## 자주 묻는 질문

### 여섯 가지 상태 그룹을 바꿀 수 있나요?
아니요. 상태 그룹은 고정되어 있어요. 각 그룹 안에서 레이블을 추가하거나, 이름을 바꾸거나, 순서를 바꿀 수 있어요.

### 직접 만든 레이블이 고객에게도 보이나요?
상태 레이블은 팀원용이에요. 고객에게는 설정해 둔 알림이 전달돼요. 예를 들면 **Staff en route**(직원 이동 중), **Visit completed**(방문 완료) 알림이 있어요. 자세한 내용은 [현장 서비스의 알림](notifications-in-field-services.md)을 참고하세요.

### 타이머가 켜져 있는데 방문을 완료 처리하면 어떻게 되나요?
**타임시트**가 켜져 있으면 타이머가 아직 작동 중이라는 경고가 나타나요. 이때 타이머를 멈출 수 있어요. 자세한 내용은 [현장 서비스의 타임시트](timesheets-in-field-services.md)를 참고하세요.
