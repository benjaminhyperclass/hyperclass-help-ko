# 현장 서비스의 체크리스트, 메모, 폼 사용하기

체크리스트를 쓰면 직원이 방문마다 같은 순서로 작업을 마칠 수 있어요. 메모와 폼으로는 고객이 요청한 내용과 현장에서 있었던 일을 함께 확인할 수 있어요.

{% hint style="info" %}
**현장 서비스**(Field Services)는 현재 비공개 베타예요. 선택된 계정에서만 쓸 수 있고, 기능과 화면은 개선되면서 바뀔 수 있어요.
{% endhint %}

## 체크리스트란?

체크리스트는 직원이 방문 중에 차례로 마치는 단계 모음이에요. 안전 점검이나 마무리 확인이 대표적이에요. 체크리스트 템플릿은 한 번만 만들어 두면 계속 다시 쓸 수 있어요. 템플릿은 모든 작업에 자동으로 적용할 수도 있고, 선택한 서비스에만 적용할 수도 있어요.

## 체크리스트 템플릿 만들기

1. **현장 서비스 > Field Services Settings**(현장 서비스 설정) **> 글로벌 설정**으로 이동하세요.
2. **Operations**(운영) 아래에서 **Jobs, visits and requests**(작업, 방문, 요청)를 열고 **Checklists**(체크리스트)를 클릭하세요.
3. **+ Checklist**(+ 체크리스트)를 클릭하세요.
4. 체크리스트 이름을 입력하고 항목을 추가하세요. 항목마다 입력 유형을 다르게 고를 수 있어요(아래 표 참고). 꼭 채워야 하는 항목은 **required**(필수)로 표시하세요.
5. **적용 대상**을 선택하세요. 모든 작업에 적용하거나 특정 서비스에만 적용할 수 있어요.
6. 체크리스트를 저장하세요.

목록에는 체크리스트별 이름, 항목 수, 적용 대상이 표시돼요. 체크리스트를 편집하려면 연필 아이콘을 클릭하세요. 더 많은 옵션은 점 세 개 아이콘에서 볼 수 있어요.

| 항목 유형 | 이럴 때 쓰세요 |
| --- | --- |
| **Single line of text**(한 줄 텍스트) | 부품 번호처럼 짧은 답을 적을 때 |
| **Checkboxes**(체크박스) | 완료 여부를 체크할 작업 |
| **Radio buttons**(라디오 버튼) | 여러 선택지 중 하나를 고를 때 |
| **Date picker**(날짜 선택) | 보증 만료일처럼 날짜를 기록할 때 |

---

## 작업에 체크리스트 추가하기

1. 작업을 여세요.
2. **Checklists**(체크리스트) 섹션에서 **체크리스트 추가**를 클릭하세요.
3. 사용할 템플릿을 선택하세요.

모든 작업에 적용되는 체크리스트와, 작업에 포함된 서비스에 적용되는 체크리스트는 자동으로 추가돼요. 자세한 내용은 [현장 서비스의 작업](jobs-in-field-services.md)을 참고하세요.

## 방문에서 체크리스트, 메모, 폼 사용하기

방문을 열면 방문 패널이 나와요. 오른쪽의 아이콘을 눌러 섹션을 바꿀 수 있어요.

| 섹션 | 표시되는 내용 |
| --- | --- |
| **상세 정보** | 방문 시간, **연락처**, 서비스 주소, 배정된 직원(출발 시간과 이동 시간 포함), 방문에 포함된 서비스와 상품이 보여요. 방문을 업데이트하려면 맨 아래의 **상태** 드롭다운을 사용하세요. |
| **Notes**(메모) | 작업 메모는 작업 전체에서 공유돼요. 방문 메모는 해당 방문에만 속해요. 메모를 쓰려면 **메모 추가**를 클릭하세요. |
| **Checklist**(체크리스트) | 체크리스트와 완료한 항목 수가 "0 of 4 items done"처럼 표시돼요. 직원은 작업하면서 항목을 하나씩 채워요. |
| **Job form**(작업 폼) | 고객이 예약할 때 제출한 폼이 있으면 그 내용이 보여요. 없으면 *제출된 폼이 없습니다*라고 표시돼요. |

![상세 정보, 메모, 체크리스트가 있는 방문 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162943/original/_fRWhf2K7iqKw1ZJ1clKGAwBDIlFFD3fZA.jpg?1792999589)

## 자주 묻는 질문

### 같은 체크리스트를 여러 서비스에 쓸 수 있나요?
네. 템플릿을 하나 만든 다음 적용할 서비스를 선택하거나, 모든 작업에 적용하세요.

### 메모는 누가 볼 수 있나요?
메모는 내부용이에요. 직원만 볼 수 있고 고객에게는 표시되지 않아요.

### 요청에 쓴 메모가 방문에도 이어지나요?
네. 요청에 추가한 메모는 그 요청에서 예약한 방문에도 표시돼요.
