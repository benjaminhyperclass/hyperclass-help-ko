# Field Services의 작업(Job)

작업(Job)은 Field Services의 핵심입니다. 한 고객의 한 주소지에서 진행되는 작업에 대한 모든 것, 즉 작업 범위, 방문, 체크리스트, 인보이스, 결제 내역을 담고 있어요. 이 글에서는 작업을 생성하는 방법, 작업 페이지를 읽는 방법, 작업을 처음부터 끝까지 관리하는 방법을 설명합니다.

참고: Field Services는 현재 비공개 베타 버전으로 선택된 계정에만 제공되고 있어요. 기능과 화면은 개선 과정에서 변경될 수 있습니다.

## 작업이란 무엇인가요?

작업(Job)은 한 고객의 한 서비스 주소지에서 진행되는 업무를 나타냅니다. 하나의 작업에는 방문(Visit)이 하나만 있을 수도 있고 여러 개가 있을 수도 있어요. 예를 들어 온수기 교체 작업이라면 첫 번째 방문에서는 점검을, 두 번째 방문에서는 설치를 진행해야 할 수 있습니다. 이 두 번의 방문 모두 같은 작업에 속하는 방문이에요.

작업을 만들 때는 고객, 서비스 주소, 제목만 입력해서 생성한 다음, 작업 범위(Scope of Work)는 나중에 추가할 수도 있습니다.

## 작업 찾는 방법

- 왼쪽 네비게이션 메뉴에서 **Field Services**로 이동하세요.
- **Jobs**를 클릭하세요.

목록에는 연락처(Contact), 작업 제목과 번호, 서비스 주소, 방문 횟수, 작업 총액, 상태가 표시됩니다. **Status** 필터를 사용하면 목록을 좁혀서 볼 수 있어요.

---

## 작업 생성 방법

- Jobs 페이지에서 **New job**을 클릭하세요. 캘린더 화면에서 **New > Create job**을 클릭하거나, 요청(Request)에서 **Convert to job**을 사용할 수도 있습니다.
- **Contact**(연락처)와 **Service address**(서비스 주소)를 선택하세요.
- **Job title**(작업 제목)을 입력하세요. 기본적으로 연락처의 전체 이름이 사용됩니다.
- 작업에 들어갈 **Services**(서비스)와 **Products**(상품)를 수량 및 단가와 함께 추가하세요.
- 작업을 저장하세요. 저장 즉시 방문을 예약할 수도 있고, 나중에 작업 페이지에서 예약할 수도 있어요.

참고: 작업을 생성하는 데 서비스가 꼭 필요하지는 않지만, 방문을 예약하려면 최소 하나의 서비스가 있어야 Field Services가 소요 시간과 작업 가능한 담당자를 계산할 수 있어요.

## 작업 페이지 이해하기

작업을 클릭하면 상세 페이지가 열립니다. 페이지는 다음과 같은 카드 형태로 구성되어 있어요:

| 섹션 | 표시되는 내용 |
|---|---|
| **Header(헤더)** | 작업 제목, 작업 ID, 상태, 시간대. **Schedule visit**으로 방문을 추가하고, **Save changes**로 수정 사항을 저장하며, 점 세 개 메뉴에서 추가 작업을 할 수 있어요. |
| **Contact details(연락처 정보)** | 연락처, 이메일, 서비스 주소. **Directions**를 클릭하면 지도에서 주소를 열 수 있어요. 주소가 서비스 가능 지역을 벗어나면 해당 작업이 검토 대상으로 표시된다는 경고가 나타납니다. **Servicing from**에는 어느 서비스 지역이 이 작업을 담당하는지 표시돼요. |
| **Job scope(작업 범위)** | 작업에 포함된 서비스와 상품의 수량, 단가, 합계. 예상 소요 시간은 추가한 서비스를 기준으로 계산됩니다. **Edit**를 클릭하면 범위를 수정할 수 있어요. |
| **Visits(방문)** | 해당 작업의 모든 방문 내역. 자세한 내용은 아래 '작업의 방문'을 참고하세요. |
| **Checklists(체크리스트)** | 직원이 방문 중 완료해야 할 체크리스트. [Field Services의 체크리스트, 노트, 폼](https://hyperclass.gitbook.io/hyperclass-docs/support/solutions/articles/155000009382) 문서를 참고하세요. |
| **Job details(작업 상세)** | 작업 제목을 수정할 수 있어요. 작업 ID, 상태, 생성일, 생성자가 여기에 표시됩니다. |
| **Billing, Invoices, Transactions and Job notes(결제, 인보이스, 거래 내역, 작업 노트)** | 아래 '작업의 결제'를 참고하세요. |

## 작업의 방문

작업에 포함된 각 방문에는 날짜, 시간, 상태, 배정된 담당자가 표시됩니다. 방문 항목 끝에 있는 아이콘을 사용해 보기, 수정, 삭제를 할 수 있어요. 방문을 추가하려면 **Schedule visit**을 클릭하세요. 자세한 내용은 [Field Services에서 방문 예약 및 가능 시간 찾기](https://hyperclass.gitbook.io/hyperclass-docs/support/solutions/articles/155000009377) 문서를 참고하세요.

방문에 사용 중인 서비스를 작업에서 제거하려고 하면, 먼저 확인 메시지가 표시됩니다.

## 작업의 결제

**Billing** 카드에는 현재 작업 총액, 인보이스 청구된 금액, 결제된 금액, 미수금이 표시됩니다.

- **Show job total breakdown**을 클릭하면 총액의 구성 내역을 확인할 수 있어요.
- **Create invoice**를 클릭하면 고객에게 인보이스를 발행할 수 있어요.
- 해당 작업의 인보이스와 결제 거래 내역은 **Invoices**와 **Transactions**에 나열됩니다.
- 내부용 메모는 **Job notes**에 작성하세요.

자세한 내용은 [Field Services의 견적서와 인보이스](https://hyperclass.gitbook.io/hyperclass-docs/support/solutions/articles/155000009381) 문서를 참고하세요.

## 작업 종료, 취소, 삭제

작업 페이지 오른쪽 상단의 점 세 개 메뉴를 클릭하세요:

| 작업 | 결과 |
|---|---|
| **Close job(작업 종료)** | 더 이상 진행할 작업이 없을 때 사용하세요. 예정되었거나 완료되지 않은 방문이 남아 있다면 먼저 처리해야 해요. 종료된 작업은 전체 이력이 그대로 유지됩니다. |
| **Cancel job(작업 취소)** | 작업의 향후 방문을 취소하고, 완료된 방문 이력은 그대로 유지하며, 이후 추가 방문 등록을 막습니다. |
| **Delete job(작업 삭제)** | 작업을 영구적으로 삭제합니다. |

## 작업 상태

작업 상태는 방문과 결제 내역을 기준으로 Field Services가 자동으로 설정합니다. 직접 수동으로 설정할 수는 없어요. Jobs 페이지의 **Status** 필터를 사용해 원하는 작업을 찾을 수 있습니다.

| 상태 | 의미 |
|---|---|
| **Ready to invoice(인보이스 발행 준비 완료)** | 작업이 완료되어 인보이스를 발행할 준비가 된 상태입니다. |
| **Unscheduled(미예약)** | 아직 예약된 방문이 없는 상태입니다. |
| **Scheduled(예약됨)** | 최소 한 건의 방문이 예약된 상태입니다. |
| **In progress(진행 중)** | 작업이 시작된 상태입니다. |
| **Action required(조치 필요)** | 팀의 확인이 필요한 작업입니다. |
| **Closed(종료됨)** | 더 이상 진행할 작업이 없는 상태입니다. |
| **Cancelled(취소됨)** | 작업이 취소된 상태입니다. |

## 모바일 앱에서 사용하기

직원은 모바일 앱에서도 작업을 관리할 수 있어서, 사무실과 현장이 동일한 작업 정보를 공유하며 일할 수 있어요. 모바일에서 팀원은 다음을 할 수 있습니다:

- 새 작업 생성
- 방문 예약 및 일정 변경
- 작업 진행 상황에 따른 방문 상태 변경
- 작업 및 방문에서 체크리스트와 노트 사용
- Timesheets(근무시간 기록) 기능이 켜져 있을 때 타이머 시작/중지

모바일 앱과 웹은 서로 동기화되므로, 현장에서 변경한 내용이 사무실에 반영되고, 반대의 경우도 마찬가지입니다.

## 자주 묻는 질문

**방문 없이 작업을 생성할 수 있나요?**
네. 작업은 처음에 **Unscheduled**(미예약) 상태로 생성되며, 캘린더의 **Jobs to schedule** 패널에 표시되어 그곳에서 방문을 예약할 수 있어요.

**방문을 예약하려면 서비스가 꼭 있어야 하나요?**
네. 방문을 예약하려면 최소 하나의 서비스가 있어야 Field Services가 소요 시간과 담당 가능한 직원을 계산할 수 있어요. 먼저 작업에 서비스를 추가해주세요.

**작업 상태를 수동으로 변경할 수 있나요?**
아니요. 상태는 방문을 예약, 완료, 청구하는 과정에 따라 자동으로 업데이트됩니다.

**작업과 방문의 차이가 무엇인가요?**
작업(Job)은 업무 자체를 의미하고, 방문(Visit)은 그 업무의 일부를 수행하기 위해 예약된 출동을 의미합니다.

**작업을 종료할 수 없는 이유는 무엇인가요?**
예정되었거나 완료되지 않은 방문이 남아 있으면 작업을 종료할 수 없어요. 해당 방문을 먼저 완료하거나 취소해주세요.
