# 현장 서비스에서 작업 만들고 관리하기

작업은 **현장 서비스**의 중심이 되는 단위예요. 한 고객의 한 주소에서 하는 일에 대한 범위, 방문, 체크리스트, 인보이스, 결제를 모두 작업 한곳에 모아 둬요. 이 문서에서는 작업을 만드는 방법, 작업 페이지 보는 법, 작업을 시작부터 끝까지 관리하는 방법을 안내해요.

{% hint style="info" %}
현장 서비스는 현재 비공개 베타 상태이며, 선정된 계정에서만 쓸 수 있어요. 기능과 화면은 개선되면서 바뀔 수 있어요.
{% endhint %}

## 작업이란?

작업은 한 고객의 한 서비스 주소에서 하는 일을 나타내요. 작업 하나에 방문이 한 번일 수도 있고 여러 번일 수도 있어요. 예를 들어 온수기 교체는 첫 방문에서 상태를 살피고, 두 번째 방문에서 설치할 수 있어요. 이 두 방문은 모두 같은 작업에 속해요.

고객, 서비스 주소, 제목만 있어도 작업을 만들 수 있어요. 작업 범위는 나중에 추가하면 돼요.

## 작업 찾기

1. 왼쪽 메뉴에서 **현장 서비스**(Field Services)를 클릭하세요.
2. **작업**을 클릭하세요.

목록에는 연락처, 작업 제목과 번호, 서비스 주소, **방문 수**, 작업 합계, 상태가 표시돼요. 목록을 좁히려면 **상태** 필터를 사용하세요.

## 작업 만들기

1. **작업** 페이지에서 **New job**(새 작업)을 클릭하세요. 캘린더 보기에서 **신규 > Create job**(작업 만들기)을 클릭하거나, 요청에서 **Convert to job**(작업으로 전환)을 사용해도 돼요.
2. **연락처**와 **Service address**(서비스 주소)를 선택하세요.
3. **직책**을 입력하세요. 기본값은 연락처의 전체 이름이에요.
4. 작업에 들어갈 **서비스**와 **상품**을 수량, 단가와 함께 추가하세요.
5. 작업을 저장하세요. 방문은 바로 예약해도 되고, 나중에 작업 페이지에서 예약해도 돼요.

{% hint style="info" %}
작업을 만들 때 서비스는 필수가 아니에요. 다만 방문을 예약하려면 서비스가 하나 이상 있어야 해요. 그래야 현장 서비스가 소요 시간과 작업할 수 있는 직원을 계산할 수 있어요.
{% endhint %}

## 작업 페이지 살펴보기

작업을 클릭하면 작업 페이지가 열려요. 페이지는 여러 카드로 나뉘어 있어요.

| 섹션 | 표시되는 내용 |
| --- | --- |
| **머리글** | 작업 제목, 작업 ID, 상태, 시간대가 표시돼요. 방문을 추가하려면 **Schedule visit**(방문 예약)을, 수정한 내용을 저장하려면 **변경사항 저장**을 사용하세요. 점 세 개 메뉴에서는 더 많은 작업을 할 수 있어요. |
| **연락처 세부정보** | 연락처, 이메일, 서비스 주소가 표시돼요. **길찾기**를 클릭하면 지도에서 주소가 열려요. 주소가 서비스 지역 밖이면, 작업이 검토 대상으로 표시된다는 경고가 나타나요. **Servicing from**(서비스 지역)에서는 어느 서비스 지역이 이 작업을 맡고 있는지 확인할 수 있어요. |
| **Job scope**(작업 범위) | 작업에 포함된 서비스와 상품이 수량, 단가, 합계와 함께 표시돼요. 예상 소요 시간은 추가한 서비스를 기준으로 계산돼요. 범위를 바꾸려면 **편집**을 클릭하세요. |
| **방문 수** | 작업의 모든 방문이 표시돼요. 아래 '작업의 방문'을 참고하세요. |
| **Checklists**(체크리스트) | 직원이 방문 중에 완료하는 체크리스트예요. [현장 서비스의 체크리스트, 메모, 폼](checklists-notes-and-forms-in-field-services.md)을 참고하세요. |
| **Job details**(작업 상세 정보) | 여기서 **직책**을 편집할 수 있어요. 작업 ID, 상태, 생성일, 생성한 사람도 함께 표시돼요. |
| **청구/결제**, **인보이스**, **거래 내역**, **Job notes**(작업 메모) | 아래 '작업의 청구/결제'를 참고하세요. |

## 작업의 방문

작업의 방문마다 날짜, 시간, 상태, 배정된 직원이 표시돼요. 방문 끝에 있는 아이콘으로 방문을 보거나 편집하거나 삭제할 수 있어요. 방문을 추가하려면 **Schedule visit**(방문 예약)을 클릭하세요. 자세한 내용은 [현장 서비스에서 방문 예약하고 가능한 시간 찾기](scheduling-visits-and-finding-availability-in-field-services.md)를 참고하세요.

방문에 사용된 서비스를 작업에서 제거하려고 하면, 먼저 확인을 요청해요.

## 작업의 청구/결제

**청구/결제** 카드에는 현재 작업 합계, 청구된 금액, 결제된 금액, 남은 금액이 표시돼요.

- **Show job total breakdown**(작업 합계 내역 보기)을 클릭하면 합계가 어떻게 구성되는지 볼 수 있어요.
- 고객에게 청구하려면 **인보이스 만들기**를 클릭하세요.
- 작업의 인보이스와 결제 내역은 각각 **인보이스**와 **거래 내역**에 표시돼요.
- 내부 메모는 **Job notes**(작업 메모)에 남겨요.

자세한 내용은 [현장 서비스의 견적서와 인보이스](estimates-and-invoices-in-field-services.md)를 참고하세요.

## 작업 종료, 취소, 삭제

작업 페이지 오른쪽 위의 점 세 개를 클릭하세요.

| 작업 | 동작 |
| --- | --- |
| **Close job**(작업 종료) | 더 이상 할 일이 없을 때 사용해요. 예정되었거나 완료되지 않은 방문이 남아 있으면 먼저 처리해야 해요. 종료한 작업에도 전체 기록이 그대로 남아요. |
| **Cancel job**(작업 취소) | 작업의 앞으로 남은 방문을 취소해요. 이미 완료한 방문의 기록은 남고, 방문을 더 추가할 수 없게 돼요. |
| **Delete job**(작업 삭제) | 작업을 영구적으로 삭제해요. |

## 작업 상태

작업 상태는 작업의 방문과 청구 내역을 바탕으로 현장 서비스가 정해요. 직접 바꿀 수는 없어요. 작업을 찾으려면 **작업** 페이지의 **상태** 필터를 사용하세요.

| 상태 | 의미 |
| --- | --- |
| **Ready to invoice**(인보이스 발행 대기) | 작업이 끝나서 인보이스를 발행할 수 있는 상태예요. |
| **Unscheduled**(미예약) | 예약된 방문이 아직 없어요. |
| **예약됨** | 예약된 방문이 하나 이상 있어요. |
| **진행 중** | 작업이 시작되었어요. |
| **조치 필요** | 팀의 확인이 필요한 작업이에요. |
| **종료됨** | 더 이상 할 일이 없어요. |
| **취소됨** | 작업이 취소되었어요. |

## 모바일 앱에서 사용하기

직원은 모바일 앱에서도 작업을 관리할 수 있어요. 그래서 사무실과 현장이 같은 작업을 보며 일할 수 있어요. 모바일에서는 팀이 다음과 같은 일을 할 수 있어요.

- 새 작업 만들기
- 방문 예약과 일정 변경
- 작업이 진행되는 동안 방문 상태 변경
- 작업과 방문에서 체크리스트와 메모 사용
- **타임시트**를 켜 둔 경우 타이머 시작과 중지

변경 내용은 모바일 앱과 웹에 동기화돼요. 현장에서 바꾼 내용은 사무실에서 바로 보이고, 반대도 마찬가지예요.

## 자주 묻는 질문

### 방문 없이 작업을 만들 수 있나요?
네, 만들 수 있어요. 방문이 없는 작업은 **Unscheduled**(미예약) 상태로 시작하고, 캘린더의 **Jobs to schedule**(예약할 작업) 패널에 표시돼요. 여기서 방문을 예약하면 돼요.

### 방문을 예약하려면 서비스가 꼭 필요한가요?
네, 방문에는 서비스가 하나 이상 있어야 해요. 그래야 현장 서비스가 소요 시간과 작업할 수 있는 직원을 계산할 수 있어요. 먼저 작업에 서비스를 추가하세요.

### 작업 상태를 직접 바꿀 수 있나요?
아니요. 방문을 예약하고, 완료하고, 청구하는 과정에 따라 상태가 자동으로 바뀌어요.

### 작업과 방문은 어떻게 다른가요?
작업은 해야 할 일 전체이고, 방문은 그 일의 일부를 하러 가는 예약된 일정이에요.

### 작업을 종료할 수 없어요. 왜 그런가요?
예정되었거나 완료되지 않은 방문이 남아 있으면 작업을 종료할 수 없어요. 해당 방문을 먼저 완료하거나 취소하세요.
