# 현장 서비스 타임시트

타임시트를 쓰면 직원이 방문마다 근무 시간을 기록할 수 있어요. 방문별, 직원별로 작업 시간을 확인할 수 있고, 변경 내역도 모두 남아요. 이 문서에서는 타이머와 시간 기록이 어떻게 작동하는지, 누가 시간 기록을 편집할 수 있는지 안내해요.

{% hint style="info" %}
**현장 서비스**는 현재 비공개 베타 상태이며, 선택된 계정에서만 사용할 수 있어요.
{% endhint %}

## 타임시트란?

타임시트는 직원이 각 방문에서 일한 시간을 기록해요. 직원이 타이머를 시작하고 멈출 때마다 **현장 서비스**(Field Services)가 시간 기록을 하나씩 저장해요. 기록은 방문별, 직원별로 합산되어 작업에 실제로 걸린 시간을 확인할 수 있어요.

![타임시트 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084171902/original/jvNDs4b_gfL6v__shr-g3Warj2rGlaYqoQ.jpg)

## 타임시트 켜기

1. **현장 서비스 > Field Services Settings > 글로벌 설정**으로 이동하세요. (**Field Services Settings**는 현장 서비스 설정 메뉴예요.)
2. **Operations**(운영) 아래에서 **Preferences and features**(환경설정 및 기능)를 클릭하세요.
3. **타임시트**(직원이 작업과 방문에 시간을 기록할 수 있어요)를 켜세요.
4. **변경사항 저장**을 클릭하세요.

![환경설정 및 기능 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162911/original/mK2qkMHJbWGd3l0DRaflvF55lPVgVXGA9w.jpg?1792999584)

이 페이지의 다른 설정은 [현장 서비스 설정: 작업, 방문, 환경설정](field-services-settings-jobs-visits-and-preferences.md)에서 확인하세요.

## 타이머가 작동하는 방식

- 직원은 방문에서 타이머를 시작할 수 있어요. 시작하고 멈출 때마다 시간 기록이 따로 만들어지므로, 방문 하나에 기록이 여러 개 생길 수 있어요.
- 한 직원이 타이머를 동시에 여러 개 실행할 수 있어요. 예를 들어 서로 다른 두 방문에서 동시에 실행할 수 있어요.
- 직원이 여러 명인 방문에서는 사람마다 자기 타이머가 따로 있어요. 내 타이머를 시작해도 다른 사람의 타이머는 시작되지 않아요.
- 방문 상태를 바꿔도(예: 체크인에서 부품 대기 중으로) 타이머는 직접 멈출 때까지 계속 실행돼요.
- 타이머가 실행 중일 때 방문을 **완료**, **취소됨**, **노쇼**로 바꾸면 경고가 표시돼요. 타이머가 그냥 사라지지 않게 하기 위해서예요.
- 웹과 모바일에서 같은 타이머가 보여요. 한쪽에서 타이머를 시작하고 다른 쪽에서 방문을 열어도, 타이머가 실행 중인 상태로 정확한 시간이 표시돼요.

방문 상태는 [현장 서비스 방문 상태](visit-statuses-in-field-services.md)에서 확인하세요.

## 시간 기록 추가, 편집, 삭제

기록을 지우지 않고도 시간을 바로잡을 수 있어요.

| 작업 | 작동 방식 |
| --- | --- |
| **수동으로 추가** | 방문, 직원, 시작 시간과 종료 시간을 선택해요. 소요 시간은 자동으로 계산돼요. 종료 시간은 시작 시간보다 늦어야 해요. |
| **편집** | 기록의 시작 시간이나 종료 시간을 바꿔요. 방문과 타임시트의 합계가 바로 업데이트돼요. |
| **삭제** | 기록을 지워요. 합계는 다시 계산돼요. |
| 자정을 넘기는 기록 | 오후 11시 30분부터 오전 12시 30분처럼 자정을 넘기는 기록은 1시간으로 계산돼요. |

직접 바꾼 내용은 모두 감사 이력에 남아요. 감사 이력에서 이전 값과 변경된 값, 변경한 사람을 확인할 수 있어요.

## 시간 기록은 누가 편집할 수 있나요?

- 직원은 권한이 있으면 자기 기록을 추가, 편집, 삭제할 수 있어요.
- 직원은 다른 사람의 기록을 편집할 수 없어요.
- 관리자는 모든 직원의 기록을 추가, 편집, 삭제할 수 있어요.

직원에 대한 자세한 내용은 [현장 서비스 직원](staff-in-field-services.md)을 참고하세요.

## 자주 묻는 질문

### 방문의 총 시간은 어디에서 볼 수 있나요?
방문에서 직원별 시간과 전체 직원의 총 작업 시간을 확인할 수 있어요.

### 완료된 방문의 시간도 편집할 수 있나요?
완료된 방문의 과거 시간은 계속 표시되고, 각자의 권한에 따라 편집할 수 있어요.

### 이미 지나간 날짜의 방문에서도 타이머를 쓸 수 있나요?
이미 지나간 방문에서는 타이머를 사용할 수 없어요. 대신 **수동으로 추가**로 시간 기록을 추가할 수 있어요.

일정을 잡는 방법은 [현장 서비스에서 방문 일정 잡고 가능한 시간 찾기](scheduling-visits-and-finding-availability-in-field-services.md)에서 확인하세요.
