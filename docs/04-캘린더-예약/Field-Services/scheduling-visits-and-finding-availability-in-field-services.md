# Field Services에서 방문 예약하고 예약 가능 시간 찾기

예약(Scheduling)은 작업(Job)이 실제 달력 위의 하루 일정으로 바뀌는 과정이에요. Find availability(예약 가능 시간 찾기)는 가장 번거로운 부분을 대신 처리해줘요. 직원의 일정, 서비스 지역, 그리고 작업 사이의 이동 시간까지 고려해서 딱 맞는 시간을 추천해주기 때문에, 이것저것 조율하는 시간은 줄이고 예약하는 데 더 집중할 수 있어요.

참고: Field Services는 현재 비공개 베타(private beta) 중이며, 선택된 계정에서만 이용하실 수 있어요. 기능과 화면은 개선 과정에서 변경될 수 있습니다.

## 방문(Visit)이란 무엇인가요?

방문(Visit)에는 날짜와 시간, 한 명 이상의 배정된 직원, 상태(Status), 그리고 처리할 서비스와 상품이 포함돼요. 하나의 작업(Job)에는 여러 개의 방문이 있을 수 있어요. 요청(Request)에는 **현장 방문(Site Visit)**도 포함될 수 있는데, 이는 작업을 확정하기 전에 현장을 간단히 둘러보는 짧은 방문을 의미해요.

---

## 방문 예약하는 방법

- 작업(Job)을 열고 **Schedule visit(방문 예약)**을 클릭하세요. 캘린더의 **Jobs to schedule(예약 대기 작업)** 패널에서 시작할 수도 있는데, 여기에는 아직 방문이 등록되지 않은 작업들이 표시돼요.
- **Visit title(방문 제목)**을 확인하세요. 기본값으로는 연락처(Contact)의 전체 이름이 사용돼요.
- **Schedule(일정)** 항목에서 **Date(날짜)**, **Start time(시작 시간)**, **End time(종료 시간)**을 선택하세요. 소요 시간은 작업에 포함된 서비스를 기준으로 자동 설정돼요. 섹션 오른쪽 상단에 시간대가 표시되며, **Edit(편집)**을 눌러 변경할 수 있어요.
- 방문 시간이 정해져 있지 않다면 **Anytime(언제든지)**을 체크하세요. 그러면 해당 방문은 캘린더의 Anytime 행에 표시돼요.
- **Arrival window(도착 예정 시간)** 옆의 **Edit(편집)**을 클릭하면 고객에게 보여지는 방문 시간을 정확한 시간으로 할지, 아니면 시간대(window)로 표시할지 변경할 수 있어요.
- **Staff(직원)** 항목에서 **Assigned staff(배정된 직원)**를 선택하세요. 여러 명을 배정할 수도 있어요.
- 내부 메모를 남기고 싶다면 **Add visit note(방문 메모 추가)**를 클릭하세요.
- 방문의 **Status(상태)**를 선택하세요. 새로 생성된 방문은 기본적으로 **Not started(시작 전)** 상태로 시작돼요.
- **Schedule visit(방문 예약)**을 클릭하세요.

## Find availability 사용 방법

- **Schedule(일정)** 옆의 **Find availability(예약 가능 시간 찾기)**를 클릭하면 **Find available time(예약 가능 시간 찾기)** 창이 열려요.
- **When(언제)** 항목에서 검색할 주(week)를 선택하세요. **Preferred time(선호 시간대)** 항목에서는 하루 중 특정 시간대나 **Any time(언제든지)**을 선택할 수 있어요.
- **Duration(소요 시간)**을 확인하세요. 작업에 포함된 서비스를 기준으로 자동 설정되며, 시간과 분 단위로 직접 변경할 수도 있어요.
- 직원 필터(예: **All staff(전체 직원)**)를 사용해서 전체 직원 또는 특정 한 명을 기준으로 검색할 수 있어요.
- **Suggested times(추천 시간)**를 확인하세요. 상단에 표시되는 추천 항목에는 **Best match(최적 매칭)**(가장 짧은 이동 거리) 또는 **Earliest(가장 빠른 시간)** 태그가 붙으며, 담당 직원과 이전 위치로부터의 이동 시간도 함께 표시돼요.
- 또는 **Select date(날짜 선택)**에서 날짜를 직접 고르고, **All open times(전체 가능 시간)**에서 시간을 선택할 수도 있어요.
- **Use this time(이 시간 사용)**을 클릭하면 방문 일정에 자동으로 입력돼요.

## Find availability가 확인하는 항목

Find availability는 실제로 가능한 시간만 추천해줘요. 다음과 같은 조건들을 확인해요.

| 확인 항목 | 중요한 이유 |
|---|---|
| 고객의 서비스 지역을 담당하는 직원 | 적합한 직원을 적합한 지역에 배정해요. |
| 선택한 서비스에 배정된 직원 | 자격을 갖춘 직원만 추천돼요. |
| 근무 시간, 휴가, 차단된 시간 | 각 직원의 실제 가능 시간을 반영해요. |
| 이미 예약된 방문 | 중복 예약을 방지해요. |
| 방문 소요 시간과 슬롯 간격 | 작업이 깔끔하게 시간대에 들어맞도록 해요. |
| 서비스 지역에 설정된 이동 시간 및 방문 전 여유 시간 | 이동할 시간을 확보해줘요. |
| 직원별 일일 방문 건수 제한 | 특정 직원에게 일이 과도하게 몰리지 않도록 해요. |
| 선택된 모든 직원이 동시에 가능한지 여부 | 여러 명이 함께하는 방문에도 적용돼요. |

참고: 온라인 예약 페이지와 달리, 앱 안의 Find availability는 최소 예약 안내 시간(minimum notice)이나 예약 가능 기간(booking window) 같은 고객용 규칙을 적용하지 않아요. 덕분에 팀에서는 고객이 예약할 수 있는 범위보다 더 빠르게, 또는 더 멀리 미래로도 일정을 잡을 수 있어요.

## 수동으로 예약하기

꼭 추천된 시간을 사용할 필요는 없어요. 날짜와 시간을 직접 입력하고, 서비스 지역 밖에 있거나 해당 서비스에 배정되지 않은 직원이라도 원하는 대로 직접 선택할 수 있어요. 긴급한 작업처럼 일반적인 규칙을 무시해야 할 때 이 방법을 사용하세요. 가능한 시간이 없다면 Find availability가 이를 알려주며, 이 경우에도 수동으로 예약을 진행할 수 있어요.

## 방문 조회, 편집, 삭제하기

작업(Job) 화면에서 방문 옆의 아이콘을 사용해 조회, 편집, 삭제할 수 있어요. 캘린더에서 방문을 클릭하거나 방문 목록을 열어 세부 정보를 확인하고, 상태를 변경하고, 메모를 추가하고, 체크리스트를 작성할 수도 있어요. 자세한 내용은 [Field Services의 방문 상태(Visit Statuses)](https://hyperclass.gitbook.io/hyperclass-docs/support/solutions/articles/155000009378)와 [Field Services의 체크리스트, 메모, 양식(Checklists, Notes and Forms)](https://hyperclass.gitbook.io/hyperclass-docs/support/solutions/articles/155000009382) 문서를 참고하세요.

## 모바일 앱에서 사용하기

팀원들은 현장에서도 예약을 처리할 수 있어요. 모바일 앱에서 직원은 새 방문을 예약하거나 기존 방문의 일정을 변경할 수 있고, 작업이 진행됨에 따라 방문 상태도 변경할 수 있어요. 변경 사항은 모바일 앱과 웹 사이에 동기화되므로, 사무실과 현장 모두 동일한 일정을 확인할 수 있어요.

## 자주 묻는 질문

**추천 시간이 하나도 안 보여요. 왜 그런가요?**
방문에 포함된 서비스에 최소 한 명 이상의 직원이 배정되어 있는지, 해당 직원이 고객의 서비스 지역을 담당하는지, 그리고 선택한 주(week)에 근무 시간이 등록되어 있는지 확인해보세요.

**과거 날짜로 방문을 예약할 수 있나요?**
이미 완료된 작업을 기록해야 할 때는 과거 날짜를 수동으로 입력할 수 있어요. 다만 Find availability는 미래 시간만 추천해요.

**고객이 선호하는 직원을 선택할 수 있나요?**
현재 비공개 베타에서는 고객이 선호하는 직원을 선택하는 기능이 지원되지 않아요. 원하는 직원을 수동으로 배정할 수는 있어요.

**추천 결과에 표시되는 이동 시간은 무엇을 의미하나요?**
직원의 이전 방문 장소, 또는 경로 시작 지점에서 해당 고객 주소까지의 예상 이동 시간이에요.
