# 일정(Schedules)으로 캘린더 가용성을 한곳에서 관리하기

일정은 하이퍼클래스의 모든 사용자가 쓰는 캘린더 가용성을 한곳에서 관리하고, 여러 캘린더에 다시 쓸 수 있게 해 주는 기능이에요. 근무 시간을 한 번만 설정해 두면 어느 캘린더에든 적용할 수 있어서, 시간을 아끼고 실수를 줄이며 예약 환경도 일관되게 유지할 수 있어요.

---

## 일정이란?

일정은 **주간 근무 시간**, 날짜별 예외 설정, 직원별 시간대 설정을 하나로 묶어 여러 곳에서 다시 쓸 수 있는 가용성 템플릿이에요. 캘린더를 하나씩 편집하는 대신, 같은 근무 시간을 따라야 하는 캘린더에 일정을 연결하면 돼요. 그러면 가용성을 한곳에서 관리할 수 있어요.

{% hint style="info" %}
이 기능은 현재 **실험실**에서 켜서 사용할 수 있어요. **에이전시 설정 > 실험실 > Sub-Account**(서브 계정)로 이동해 **Calendars - Schedules**(캘린더 - 일정)를 켜세요.

일정과 사용자 지정 일정은 서로 달라요. 일정은 한곳에서 중앙 관리해요. 사용자 지정 일정은 한 캘린더 안에서 일정을 수정한 것으로, 그 캘린더에서만 관리해요.
{% endhint %}

---

## 일정을 쓰면 좋은 점

- 모든 사용자의 근무 시간을 한곳에서 관리해요. 캘린더마다 따로 고치지 않아도 돼요.
- 같은 일정을 여러 캘린더나 서비스에 다시 사용할 수 있어요.
- 새 사용자에게 기본 일정이 자동으로 주어져서 바로 예약을 받을 수 있어요.
- 특정 캘린더에 별도 시간이 필요하면 일회성 사용자 지정 일정을 만들 수 있어요.
- 기존 가용성은 자동으로 옮겨지므로 중단되거나 다시 설정할 필요가 없어요.

{% hint style="info" %}
사용자 한 명이 여러 개의 일정을 가질 수 있어요.
캘린더 하나에는 사용자별로 한 번에 일정 하나만 연결할 수 있어요.
{% endhint %}

---

## 일정 열기

**전체 일정**을 보려면 **캘린더 > 캘린더 설정 > 가용성**으로 이동하세요. **설정 > 캘린더 > 가용성**으로도 들어갈 수 있어요.

![캘린더 설정의 가용성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003084/original/Tr3M_p69Qidf5zhYx1GP2QViCmxEguCSuQ.png?1760488059)

**사용자 본인**의 일정은 **설정 > 내 프로필**로 이동한 뒤, 아래로 스크롤해 **Schedules**(일정) 섹션에서 관리할 수 있어요.

![내 프로필의 일정 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003103/original/QnRDaMU1mL5SsLW7wwWWYSdm9qhHlCVBBw.png?1760488178)

관리자는 **다른 사용자의 일정**도 관리할 수 있어요. **설정 > 스태프 관리**로 이동해 해당 사용자 옆의 편집(연필) 아이콘을 클릭한 뒤 **사용자 가용성**을 선택하세요.

![스태프 관리에서 사용자 편집 아이콘 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003128/original/abVXmTA9oiKtiqeNWUccWCIHTEb3VsiNCQ.png?1760488353)

## 사용자 선택

**사용자 선택** 드롭다운에서 가용성을 관리할 직원을 고르세요.

![사용자 선택 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003153/original/rgYJzIrZQuRvAqITQXZ9xfcKIkDXxDWVAw.png?1760488526)

## 새 일정 만들기

1. **새 일정**을 클릭하세요.
2. **이름**을 입력하세요.
3. **만들기**를 클릭하세요.

   ![새 일정 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003272/original/1Ae3mER3dxJUoQCh0Kx_lPu2kKSbafYXAw.png?1760489002)
4. 일정을 설정하세요.
   - **주간 근무 시간**: 근무 요일과 시간을 정해요. 이 시간에 맞춰 캘린더에 예약 가능 시간이 표시돼요.
   - **시간대**: 일정의 가용성이 저장되고 계산되는 기준 시간대를 정해요.
   - **Date-Specific Overrides**(날짜별 예외 설정): 특정 날짜를 가능 또는 불가능으로 표시해서 주간 근무 시간을 덮어써요.
5. **Active On**(적용 대상) 드롭다운에서, 선택한 직원에게 이 일정을 적용할 캘린더를 고르세요.
6. **저장**을 클릭하세요.

{% hint style="info" %}
상담, 데모, 현장 방문처럼 일정을 여러 개 만들어서 캘린더마다 다르게 지정할 수 있어요.
{% endhint %}

## 일정 편집

일정 목록에서는 기존 일정에 다음 작업을 할 수 있어요.

- **기본값으로 설정**(핀 아이콘): 직원이 새 캘린더에 추가될 때마다 기본 일정이 자동으로 적용돼요. 그래서 직접 지정하지 않아도 바로 가용성이 설정돼요. 기본으로 쓸 일정에서 **기본값으로 설정** 아이콘을 클릭하세요.

  ![기본값으로 설정 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003301/original/oLcX7x8ZnIFrha0S5J-ppEMZtGNq1Hel6w.png?1760489129)
- **이름 변경**(연필 아이콘): 알아보기 쉽게 일정 이름을 바꿔요.
- **중복**(종이 아이콘): 기존 일정을 복사해서 처음부터 만들지 않고 변형본을 빠르게 만들어요.
- **삭제**(휴지통 아이콘): 일정을 지워요. 어느 캘린더에서도 사용 중이지 않은 일정만 지울 수 있어요.

---

## 일정 편집 - 캘린더 링크

특정 캘린더의 일정도 따로 관리할 수 있어요. **캘린더 > 캘린더 설정**으로 이동해 캘린더 목록에서 해당 캘린더의 **편집**을 클릭한 뒤 **가용성** 탭을 여세요.

- 캘린더가 다른 일정을 쓰도록 바꿀 수 있어요.
- 그 캘린더에서만 쓰는 사용자 지정 일정을 만들어 사용할 수 있어요.

{% hint style="info" %}
일정을 수정하면, 특정 캘린더에서 수정을 시작했더라도 그 일정에 연결된 모든 캘린더에 반영돼요.
{% endhint %}

![캘린더 편집의 가용성 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003338/original/UK1mBqG1le9aPPbm5hBzXqysP409c_24cw.png?1760489454)

## 사용자 지정 일정 (캘린더별 가용성)

- 사용자 지정 일정은 다음과 같아요.
  - 해당 캘린더에만 적용돼요.
  - 자체 주간 근무 시간, 시간대, 날짜별 예외 설정을 가져요.
- 사용자 지정 일정은 캘린더의 **가용성** 탭에서 바로 만들 수 있어요.
- 사용자 지정 일정을 만들려면 **가용성** 탭에서 직원을 선택한 뒤 **편집**을 클릭하고, **Customize schedule for this calendar only**(이 캘린더에만 일정 사용자 지정)를 선택하세요.

![이 캘린더에만 일정 사용자 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056003386/original/7zDnebAEvD0iuiHH3oewN2zn2bRSN5BMKA.png?1760489784)

{% hint style="info" %}
사용자 지정 일정은 일정 목록에 나타나지 않아요. 만든 캘린더 안에서만 관리할 수 있어요.
{% endhint %}

---

## 기존 캘린더의 전환 (사용자 지정 일정)

원활하게 전환되도록, 기존 캘린더마다 설정해 둔 가용성에 맞춰 사용자 지정 일정이 하나씩 만들어져요.

- 이 일정은 해당 캘린더의 **가용성** 탭에만 나타나요.
- 언제든 편집하거나, 다시 쓸 수 있는 일정으로 바꿔 사용할 수 있어요.

---

## 자주 묻는 질문

### 기존 가용성 설정은 어떻게 되나요?
하이퍼클래스가 자동으로 사용자 지정 일정으로 옮겨 두었기 때문에 문제없이 그대로 동작해요.

### 같은 일정을 라운드 로빈 캘린더에도 연결할 수 있나요?
네. 라운드 로빈 그룹 안에서 사용자별로 일정을 선택하면 돼요.

### 날짜별 예외 설정은 그 일정을 쓰는 모든 캘린더에 적용되나요?
네. 한 캘린더에만 예외가 필요하면 그 캘린더 안에서 사용자 지정 일정을 만드세요.

### 일정은 몇 개까지 만들 수 있나요?
정해진 한도는 없어요. 필요한 만큼 만들 수 있어요.

### 사용자가 여러 캘린더에 있어도 중복 예약을 막을 수 있나요?
각 캘린더가 같은 일정을 참조하기 때문에 이미 찬 시간은 가용성에서 자동으로 빠져요. 그래서 시간이 겹치지 않아요.

### 일정을 수정하면 이미 잡힌 예약이 취소되나요?
아니요. 기존 이벤트는 그대로 유지되고, 앞으로 비어 있는 시간대만 바뀌어요.

### 직원별 시간대는 캘린더의 시간대와 어떻게 연동되나요?
일정은 직원의 시간대를 기준으로 해요. 예약 위젯은 예약 가능한 시간을 방문자의 브라우저 시간대로 자동 변환해서 보여 줘요.

### API로 일정을 가져올 수 있나요?
아직은 안 돼요. 현재는 앱 안에서만 일정을 관리할 수 있고, API 엔드포인트는 이후 업데이트에서 안내될 예정이에요.
