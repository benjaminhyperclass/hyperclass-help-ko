# 서비스 애드온 만들기와 관리

애드온은 서비스에 붙일 수 있는 선택 옵션이에요. 고객은 예약할 때 애드온을 골라 원하는 대로 예약을 구성할 수 있어요. 애드온은 추가 서비스나 관련 상품일 수 있고, 전체 소요 시간과 가격에 영향을 줄 수 있어요. 이 문서에서는 애드온이 무엇인지, 어떻게 만들고, 편집하고, 서비스에 연결하는지 안내해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 애드온이란?

애드온을 쓰면 서비스에 추가 기능이나 업셀 상품을 붙일 수 있어요. 고객은 예약하면서 원하는 옵션을 골라 자신에게 맞게 예약을 구성해요. 애드온은 메인 서비스와 관련된 추가 서비스나 상품이에요. 예를 들면 다음과 같아요.

- 스파에서 마사지에 '아로마테라피 업그레이드'를 추가 옵션으로 제공해요.
- 퍼스널 트레이너가 운동 플랜에 '영양 상담'을 추가 옵션으로 제공해요.
- 사진작가가 촬영 패키지에 '보정 사진 추가'를 애드온으로 제공해요.

예약 과정에서 고객에게 더 다양한 선택지를 주면 매출을 늘리고 고객 만족도도 높일 수 있어요.

## 애드온의 주요 장점

- 추가 매출: 예약하는 순간 업그레이드를 제안하므로 별도 후속 연락 없이도 매출을 더 올릴 수 있어요.
- 맞춤형 예약: 고객이 필요한 옵션을 직접 골라서 기대에 맞는 서비스를 받을 수 있어요.
- 결제 시 투명한 가격: 수량 기준 가격 계산으로, 고객이 선택한 항목에 맞는 정확한 금액이 계산돼요.
- 서비스별 관련성: 애드온은 연결한 서비스에만 표시되어 선택지가 간결해요.
- 빠른 설정: 애드온을 한 번 만들어 두고 필요한 곳마다 연결하면 되므로 중복 작업이 없어요.

## 애드온을 만들 수 있는 위치

애드온은 두 곳에서 만들 수 있어요.

- **애드온** 탭에서 만들기: 모든 서비스의 애드온을 한곳에서 볼 수 있어요.

  ![애드온 탭의 전체 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053324490/original/QyW3Yb7fawtbyDUfmRg-CbgAedmMdz2TLA.png?1757355248)
- 서비스에서 바로 만들기: 여기서 만든 애드온은 해당 서비스에 자동으로 추가돼요.

  ![서비스 화면에서 애드온 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053324451/original/ElUQ-tHtaG6IlQJdHUEWOuZmeGrKqqlyWA.png?1757355200)

## 서비스에 애드온 연결하기

애드온을 만들었다고 해서 모든 서비스에 자동으로 표시되는 것은 아니에요. 애드온을 보여 주고 싶은 서비스마다 연결해 주세요. 그러면 고객이 예약할 때 관련 옵션만 볼 수 있어요.

- 애드온은 서비스 하나 또는 여러 개에 연결할 수 있어요.
- 애드온은 연결된 서비스의 예약 페이지에만 표시돼요.
- 고객은 예약할 때 애드온을 선택 옵션으로 보게 돼요.

### 1단계: 서비스 편집 화면 열기

1. **캘린더 > 캘린더 설정 > 서비스**로 이동해 서비스 화면을 열어요.
2. 애드온을 연결할 서비스에서 점 3개(⋮) > **편집**을 클릭해 서비스 편집 화면을 열어요.

![서비스 편집 화면 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053202643/original/UDojRNWxBqbHh2N5XGY9EIGMcX4OJ5QzPQ.png?1757105975)

### 2단계: + 애드온으로 이동

1. 왼쪽 보조 내비게이션 바에서 **애드온** 탭을 클릭해요.
2. **+ 애드온** 버튼을 클릭해요.

![+ 애드온 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053202629/original/UTD41ireMWs_2sXD5IW3xMZXryCsybaMcw.png?1757105881)

### 3단계: 애드온 선택

1. 이 서비스에 연결할 애드온을 선택해요. 필요하면 새 애드온을 만들 수도 있어요.
2. **저장** 버튼을 클릭해 변경사항을 저장해요.

![애드온 선택 후 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053202657/original/8NcYv3vIzziUyzueGyigFplBTBTNTSiNbQ.png?1757106059)

## 애드온 편집 또는 삭제하기

이름, 가격, 옵션을 업데이트하거나, 더 이상 제공하지 않는 항목을 삭제해서 애드온을 최신 상태로 유지하세요. 기존 애드온을 편집하거나 삭제하는 순서는 다음과 같아요.

### 1단계: 애드온 페이지 열기

1. **캘린더 > 캘린더 설정 > 서비스**로 이동해 서비스 화면을 열어요.
2. 보조 내비게이션 메뉴에서 **애드온** 탭을 클릭해요.

![애드온 탭 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053202755/original/LNPt2HslZJT7zOp5im13FFUTPuZ7_t_CRQ.png?1757106396)

### 2단계: 편집 또는 삭제

기존 애드온 목록이 표시돼요.

- 애드온 옆의 연필 아이콘 **편집** 버튼을 클릭하면 편집 화면이 열려요.
- 휴지통 아이콘 **삭제**를 클릭하면 애드온이 삭제돼요.

![애드온 편집 및 삭제 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053201942/original/L7uVqcTHb2NO2tBQLjHHXaNwcpw5ukBotw.png?1757104051)

### 3단계: 정보 업데이트

1. 편집하는 경우 필요한 정보를 수정해요.
2. 파란색 **변경사항 저장** 버튼을 클릭해 애드온 변경 내용을 저장해요.

![애드온 변경사항 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053202805/original/VhfBuPWJIKz7v9Yr7EwjxiVJjnEpAOAE_Q.png?1757106559)

## 애드온 만들기

설정을 정확히 해 두면 애드온이 올바른 시간, 가격, 공개 범위로 표시돼요. 새 애드온을 만드는 순서는 다음과 같아요.

### 1단계: + New Add-on(새 애드온 추가)으로 이동

1. **캘린더 > 캘린더 설정 > 서비스**로 이동해 서비스 화면을 열어요.
2. 위쪽 보조 내비게이션 메뉴에서 **애드온** 탭을 열어요.
3. 오른쪽 위의 **+ New Add-on**(새 애드온 추가) 버튼을 클릭해요.

![+ New Add-on 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053202073/original/f2kcOphbYDDXyc48UieKmKcgOp2HOPzBWw.png?1757104691)

### 2단계: 애드온 정보 입력

1. 애드온 정보를 입력해요. 입력 항목은 다음과 같아요.
   - **Add-on Image**(애드온 이미지): 애드온을 보여 줄 이미지를 올려요. 컴퓨터에서 올리거나 **미디어 라이브러리**에서 고를 수 있어요.
   - **이름**: 알아보기 쉬운 이름을 입력해요(예: *라벤더 마사지 오일*).
   - **가격**: 애드온 가격을 설정해요.
   - **소요 시간**: 애드온에 자체 소요 시간이 있으면 체크박스를 선택해요. 켜 두면 이 시간이 고객에게 보이는 전체 서비스 시간에 포함돼요.
   - **Maximum Quantity**(최대 수량): 예약 한 건당 선택할 수 있는 수량을 정해요.
   - **Multiple Price with Quantity**(수량에 따라 가격 곱하기): 켜 두면 선택한 수량만큼 가격이 곱해져요(예: $20 × 2개 = $40).
   - **설명**: 애드온의 장점을 설명하는 내용을 입력해요.
   - **Hide from Booking Page**(예약 페이지에서 숨기기): 애드온을 내부용으로만 두고 직원만 적용할 수 있게 해요.
2. 정보를 모두 입력했으면 **Create Add-on**(애드온 만들기) 버튼을 클릭해 저장해요.

![애드온 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064241718/original/lOtxyaSHrW2UP6D7qdGPXZItWwyRgKKlug.png?1770283081)

## 활용 팁

- 이름과 이미지를 명확하게 써서 고객이 애드온을 바로 이해할 수 있게 하세요.
- 상품, 소모품처럼 실물 재고와 연결된 경우에는 최대 수량을 제한하세요.
- 인기 있는 애드온을 서비스와 묶어서 제공하면 추가 판매 기회가 늘어요.
- 직원만 쓰는 내부 조정용 항목은 숨김 애드온으로 만드세요.

## 자주 묻는 질문

### 애드온이 모든 서비스에 자동으로 표시되나요?
아니요. 애드온을 표시하고 싶은 서비스마다 직접 연결해야 해요.

### 애드온의 소요 시간이 전체 서비스 시간에 영향을 주나요?
네. 애드온에 **소요 시간**을 켜면 그 시간이 서비스 소요 시간에 더해져 전체 서비스 시간이 계산돼요.
