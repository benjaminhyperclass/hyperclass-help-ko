# 모바일 앱에서 서비스 캘린더 사용하기

모바일 앱에서 서비스 캘린더의 예약을 확인하고, 연락처와 새 서비스 예약을 만드는 방법을 안내해요.

모바일 앱에 서비스 캘린더가 추가됐어요. 서브 계정 관리자와 사용자는 이제 **캘린더** 화면에서 서비스 예약을 모두 볼 수 있고, 어떤 연락처와도 새 서비스 예약을 만들 수 있어요. 이 업데이트는 하이퍼클래스 모바일 앱과 화이트라벨 모바일 앱에서 쓸 수 있어요. 화이트라벨 앱은 업데이트를 요청해야 해요.

## 새로 추가된 기능

1. 서비스 캘린더 예약 보기
2. 서비스 캘린더 예약 새로 만들기

## 사용 방법

1. 사용할 서브 계정을 선택한 상태로 모바일 앱을 열어요.
2. **캘린더** 화면으로 이동해요. 서비스 예약이 날짜별로 표시돼요.
3. 새 서비스 예약을 만들려면 "+" 버튼을 누른 뒤 **약속 일정 예약**을 눌러요.
4. 캘린더 드롭다운에서 웹에서 미리 만들어 둔 서비스 캘린더를 선택해요.
5. 해당 서비스에 맞는 룸을 선택해요. 룸을 선택하면 사용 가능 여부에 따라 장비가 자동으로 배정돼요.
6. 나머지 필요한 정보를 입력하고 **저장**을 누르면 예약이 완료돼요.

### 이 업데이트가 중요한 이유

이제 모바일 앱에서 서비스 예약을 보고 만들 수 있어요.

## 사용 가능한 앱 버전

- 하이퍼클래스 모바일 앱 (iOS, Android) - v3.74 이상
- 화이트라벨 모바일 앱 (iOS, Android) - v3.74 이상

## 모바일 서비스 예약의 위치 관련 기능

모바일 예약 화면에서 위치 관련 기능을 쓰면 앱을 바꿔 가며 쓰거나 미팅 정보를 직접 찾지 않고도 현장에서 일할 수 있어요. 방문 예약은 더 빨리 길을 찾아가고, 온라인 예약은 더 적은 단계로 참여할 수 있어요.

Service v2 예약에서는 모바일 앱이 위치 정보를 더 자세히 보여 주고, 다음과 같은 빠른 작업을 제공해요.

- 표시된 위치 값 복사하기
- 실제 주소는 **View Location**(위치 보기) 열기
- 온라인 링크는 **Join Meeting**(미팅 참여) 열기

Service v2 예약이 어떻게 동작하는지 자세히 알고 싶다면 "모바일 앱에서 Service v2 예약 관리하기" 문서를 참고하세요.
