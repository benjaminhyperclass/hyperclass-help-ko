# 미팅룸 화면 공유 개선 기능

하이퍼클래스 **미팅룸**에서 공유 화면을 더 선명하고 편하게 볼 수 있어요. 전체 화면 모드, 확대·축소, 시스템 오디오 공유, 개선된 스트리밍 화질을 쓰는 방법을 안내해요.

화면 공유는 지원 세션, 발표, 교육, 고객 미팅에서 꼭 필요한 기능이에요. 하이퍼클래스 **미팅룸**에는 공유 화면을 더 선명하게 보고 편하게 다룰 수 있는 개선 기능이 들어 있어요.

## 화면 공유 개선 기능이란?

화면 공유 개선 기능은 참가자가 실시간 미팅에서 공유 화면을 보고 다루는 방식을 좋게 만들어 줘요. 전체 화면 보기, 확대·축소, 시스템 오디오 공유, 최대 1080p·30 FPS의 스트리밍 화질이 포함돼요.

덕분에 발표, 교육, 지원 통화, 리포트 검토, 문제 해결, 고객·팀원과의 실시간 협업이 더 수월해져요.

## 주요 기능

하이퍼클래스 **미팅룸**에는 협업과 화면 가독성을 높이는 다음 기능이 있어요.

- 전체 화면 모드: 공유 화면을 전체 화면으로 키워서 화면 공간을 최대한 활용하며 집중해서 볼 수 있어요.
- 확대·축소: 공유 화면을 확대하거나 축소해서 세부 인터페이스, 스프레드시트, 대시보드를 읽기 쉽게 볼 수 있어요.
- 시스템 오디오 공유: 화면과 함께 시스템 소리도 공유해서 소리가 있는 영상, 애플리케이션 시연, 교육을 진행할 수 있어요.
- 1080p·30 FPS 화질: 더 선명한 화면과 더 부드러운 움직임으로 보기 편한 환경을 제공해요.

## 공유 화면 전체 화면 모드

전체 화면 모드를 쓰면 공유 화면을 내 디스플레이 전체로 키워서 볼 수 있어요. 방해 요소가 사라지고 화면 공간을 최대한 쓸 수 있어서, 발표 자료, 시연, 문서, 대시보드처럼 세부 내용이 많은 화면을 볼 때 좋아요.

참가자는 언제든 전체 화면 모드로 들어가거나 나올 수 있어요. 발표자의 화면이나 다른 참석자의 화면에는 영향이 없어요.

## 확대·축소 기능

공유 화면에는 확대·축소 기능이 기본으로 들어 있어요. 글이 많은 화면은 더 읽기 쉽고, 스프레드시트나 리포트, 세부 인터페이스와 워크플로우도 더 잘 보여요.

보는 배율을 바꿔도 발표자의 화면에는 영향이 없어요. 확대·축소 수준은 참석자마다 따로 조절해요.

{% hint style="info" %}
대시보드, 스프레드시트, 복잡한 워크플로우를 볼 때 확대·축소를 쓰면 작은 글씨와 인터페이스 요소를 더 쉽게 읽을 수 있어요.
{% endhint %}

## 시스템 오디오와 함께 화면 공유하기

참석자는 미팅 중에 화면과 시스템 오디오를 함께 공유할 수 있어요. 별도의 오디오 소스 없이도 소리가 나는 영상 발표, 교육·시연, 오디오가 있는 애플리케이션 시연, 멀티미디어 콘텐츠 공유를 할 수 있어요.

참가자는 발표자가 의도한 대로 화면과 소리를 함께 접해요. 시스템 오디오 공유는 하이퍼클래스 **미팅룸**에서 화면 공유를 시작할 때 선택할 수 있어요.

## 개선된 화면 공유 화질

하이퍼클래스 **미팅룸**의 화면 공유는 개선된 스트리밍 화질을 지원해요. 발표, 시연, 교육, 협업 미팅에서 더 선명한 화면과 더 부드러운 움직임을 볼 수 있어요.

공유 화면 스트리밍 화질 사양은 다음과 같아요.

| 항목 | 지원 값 |
| --- | --- |
| 해상도 | 최대 1080p |
| 프레임 속도 | 30 FPS |

리포트 검토, 문제 해결, 슬라이드 발표, 영상 공유, 실시간 협업 등 어떤 미팅이든 공유 화면을 이전보다 편하게 보고, 듣고, 다룰 수 있어요.

## 화면 공유 개선 기능 사용하기

하이퍼클래스 **미팅룸**에서 화면 공유 개선 기능을 쓰려면 다음 단계를 따르세요.

1. 화면 공유를 시작해요.
   1. 하이퍼클래스 **미팅룸**에 참여해요.
   2. 화면 공유 버튼을 눌러요.
   3. 공유할 화면, 창, 탭을 선택해요.
2. 시스템 오디오를 켜요. (선택 사항)
   1. 화면 공유를 시작할 때 시스템 오디오 공유 옵션을 선택해요. 참가자가 공유 화면과 함께 내 컴퓨터의 소리도 듣게 하고 싶을 때 선택하세요.

   ![시스템 오디오 공유 옵션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079462899/original/VgEZXlKmM7EMHzwP67y-0ZPNpbosLNAEqg.png?1787839207)

3. 전체 화면 모드를 사용해요.
   1. 공유 화면을 보는 참가자는 전체 화면 버튼을 눌러 공유 화면을 디스플레이 전체로 키워요.
   2. 전체 화면 모드에서 나오려면 Escape 키를 누르거나 나가기 버튼을 눌러요.

   ![전체 화면 모드 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079462852/original/Lhsm0CocNEOM00c3bSij2mHlOcN_C8Bewg.png?1787839189)

4. 확대·축소 수준을 조절해요.
   1. 확대·축소 컨트롤로 공유 화면의 보기 배율을 조절해요. 발표자의 화면이나 다른 참가자의 화면에는 영향 없이 세부 내용을 더 선명하게 볼 수 있어요.

## 자주 묻는 질문

### 전체 화면 모드와 확대·축소를 동시에 쓸 수 있나요?
네. 전체 화면 모드로 들어간 뒤 확대·축소로 보기 배율을 조절할 수 있어요. 두 기능을 함께 쓰면 가장 보기 좋은 환경을 만들 수 있어요.

### 공유 화면을 확대하면 다른 참가자에게도 영향이 있나요?
아니요. 확대·축소 수준은 참가자마다 따로 조절해요. 내 배율을 바꿔도 발표자의 화면이나 다른 참석자가 공유 화면을 보는 방식에는 영향이 없어요.

### 화면을 공유할 때 시스템 오디오는 어떻게 켜나요?
하이퍼클래스 **미팅룸**에서 화면 공유를 시작할 때, 공유 설정 과정에서 시스템 오디오 공유 옵션을 선택하세요. 이 옵션은 공유할 화면, 창, 탭을 고르는 단계에서 볼 수 있어요.

### 화면 공유는 어느 해상도까지 지원하나요?
하이퍼클래스 **미팅룸**의 화면 공유는 최대 1080p 해상도, 30 FPS를 지원해요. 발표, 시연, 협업 세션에서 더 선명한 화면과 부드러운 움직임을 볼 수 있어요.

### 특정 애플리케이션 창을 공유할 때도 시스템 오디오를 공유할 수 있나요?
네. 전체 화면, 특정 창, 브라우저 탭을 공유할 때 시스템 오디오를 공유할 수 있어요. 화면 공유 설정 과정에서 시스템 오디오 옵션을 선택하세요.

### 이 기능을 쓰려면 계정에서 따로 설정해야 하나요?
아니요. 화면 공유 개선 기능은 하이퍼클래스 **미팅룸**에서 기본으로 사용할 수 있어요. 모든 참가자가 추가 설정 없이 전체 화면 모드, 확대·축소, 시스템 오디오 공유, 개선된 스트리밍 화질을 쓸 수 있어요.

### 어떤 콘텐츠를 공유할 때 이 기능이 가장 좋나요?
발표 자료, 대시보드, 스프레드시트, 리포트, 교육 자료, 영상 시연, 애플리케이션 시연, 복잡한 워크플로우 등 모든 종류의 공유 콘텐츠를 더 편하게 볼 수 있어요.

### 공유 화면을 보다가 전체 화면 모드에서 나올 수 있나요?
네. 언제든 키보드의 Escape 키를 누르거나, 공유 화면에 마우스를 올리면 나타나는 전체 화면 나가기 버튼을 눌러 나올 수 있어요.
