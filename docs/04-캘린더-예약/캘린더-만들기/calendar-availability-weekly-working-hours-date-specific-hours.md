# 캘린더 가용성: 주간 근무 시간과 특정 날짜 시간 설정

하이퍼클래스 캘린더에서 예약을 받을 수 있는 시간을 정하는 방법을 안내해요. 평소 일정은 **주간 근무 시간**으로, 공휴일이나 특별 행사처럼 하루만 달라지는 일정은 **특정 날짜 시간**으로 설정해요.

---

## 캘린더 가용성이란?

캘린더 가용성은 캘린더가 예약을 받을 수 있는 시간을 정하는 설정이에요. **주간 근무 시간**은 매주 반복되는 기본 일정이에요. **특정 날짜 시간**은 공휴일이나 특별 행사처럼 개별 날짜에 한해 기본 일정을 덮어써요. 이 두 설정에 따라 캘린더 예약 페이지에 표시되는 시간대가 정해져요.

두 설정의 차이를 알아 두면 캘린더를 실제 일정에 맞게 관리하기 쉬워요.

{% hint style="warning" %}
**특정 날짜 시간**은 항상 **주간 근무 시간**보다 우선해요. 특정 날짜에 시간을 따로 설정하면, 그날은 기본 주간 근무 시간 대신 그 시간이 적용돼요.
{% endhint %}

---

## 주간 근무 시간

**주간 근무 시간**(이전 이름: Standard Availability)은 매주 반복되는 평소 근무 일정이에요. 매주 똑같이 반복되는 기본 일정을 설정할 때 쓰면 편해요.

예를 들어 매주 월요일, 화요일, 목요일 오전 8시부터 오후 10시까지 일할 수 있다면, 이 시간을 주간 근무 시간으로 설정하세요. 그러면 해당 요일과 시간에 매주 자동으로 적용돼요.

{% hint style="info" %}
여러 팀원의 가용성을 한 번에 바꾸려면 캘린더의 **가용성** 탭에서 **Bulk edit**(일괄 편집)를 사용하세요.
참고: How to Bulk Edit Calendar Availability for Multiple Team Member
{% endhint %}

### 주간 근무 시간 설정하기

1. **캘린더 > 캘린더 설정**으로 이동한 다음 **Edit Calendar**(캘린더 편집)를 클릭하세요.

   ![캘린더 설정에서 캘린더 편집을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063381466/original/1IsYwx3nVmjdY4ZC7zhtyjMPtKK_U4qhCw.png?1769199652)
2. 왼쪽 메뉴에서 **가용성**을 선택하세요. **Booking Availability**(예약 가용성) 아래에서 사용자 이름을 클릭하면 옆에 패널이 열려요.

   ![가용성 메뉴에서 사용자 이름을 클릭해 사이드 패널을 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063381580/original/a3brAjglqejecXiTd_b2mxxSA8RwLfTs0Q.png?1769199836)
3. **주간 근무 시간**에서 **편집**을 클릭하고 요일별로 근무 가능한 시간을 설정하세요.

   ![주간 근무 시간에서 요일별 시간을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063381637/original/q0gm9Vjn8ffVqJAL-0U-h5DxTv8Fk4lFlA.png?1769199937)
4. (선택) 같은 시간을 다른 요일에도 적용하려면 **복사**를 클릭하세요.

   ![복사 버튼으로 다른 요일에 같은 시간을 적용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063381663/original/EDq6a6JQR0SZTlef5vw-mzCTebnJbMR-jA.png?1769200013)
5. 파란색 **저장** 버튼을 클릭해 변경 내용을 적용하세요.

## 특정 날짜 시간

**특정 날짜 시간**(이전 이름: Custom Availability)에서는 특정 날짜에만 근무 가능 또는 불가능한 시간을 따로 정할 수 있어요. 날짜를 추가하고, 그 날짜에만 적용할 시간을 지정하세요.

평소 일정과 다른 예외 상황, 공휴일, 개인 일정을 처리할 때 특히 유용해요. 활용 예시는 다음과 같아요.

- 공휴일: 부활절, 크리스마스, 공휴일 같은 날을 근무 불가로 설정할 수 있어요. 해당 날짜에는 캘린더에 근무 불가로 표시돼서 일정이 정확하게 관리돼요.
- 개인 일정: 평소 일정과 겹치는 개인 약속이 있으면 그 날짜의 가용성만 쉽게 조정할 수 있어요. 예를 들어 2024년 2월 10일 낮 12시부터 오후 3시까지 병원 예약이 있다면, 차단 시간대를 따로 만들지 않고도 그 시간만 근무 불가로 설정할 수 있어요.
- 연장 근무: 연휴 주말처럼 잠깐 근무 시간을 늘리고 싶을 때, **특정 날짜 시간**으로 해당 날짜의 가용성만 바꿀 수 있어요.

**특정 날짜 시간**은 해당 날짜의 **주간 근무 시간**을 덮어써요. **특정 날짜 시간**이 있는 날짜에는 주간 근무 시간이 전혀 적용되지 않아요.

예시(하루 연장하기): **주간 근무 시간**이 오전 9시~오후 5시인데 3월 10일 화요일만 오전 9시~오후 8시까지 예약을 받고 싶다면, 그 날짜에 오전 9시~오후 8시를 **특정 날짜 시간**으로 설정해야 해요.
오후 5시~8시만 **특정 날짜 시간**으로 설정하면, 그 화요일은 오후 5시~8시만 예약 가능한 날로 처리돼요. 오전 9시~오후 5시는 예약할 수 없는 시간으로 표시돼요.

---

### 특정 날짜 시간 설정하기

1. 캘린더 가용성 설정으로 이동하세요. **설정 > 캘린더**로 이동해 **캘린더 선택**에서 원하는 캘린더를 고른 뒤 **가용성**을 클릭하세요.
2. **특정 날짜 시간** 섹션에서 **+ Add Date-Specific Hours**(특정 날짜 시간 추가)를 클릭하세요.

   ![특정 날짜 시간 섹션에서 추가 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067030845/original/WOAl5x3tXwtd2eKZKYYWCk0jZDI-zMee4A.png?1773669406)
3. 날짜 선택 창에서 기본 일정을 바꾸고 싶은 날짜를 하나 이상 선택하세요.

   ![날짜 선택 창에서 날짜를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067030908/original/5-e72I4fUtIURqa9DY_CPcYFhCCNnlkDiw.png?1773669449)
4. **Start time**(시작 시간)과 **End time**(종료 시간)을 설정하세요.
5. **저장**을 클릭하면 선택한 모든 날짜에 같은 시간이 적용돼요.

{% hint style="info" %}
이 기능은 순차적으로 제공되고 있어서, 일부 계정에서만 사용할 수 있을 수 있어요.
{% endhint %}

### 날짜가 묶여서 표시되는 방식

여러 날짜에 대한 특정 날짜 시간을 저장하면, 하이퍼클래스가 목록이 깔끔하게 보이도록 선택한 날짜를 묶어서 보여 줘요.

- 연속된 날짜는 하나의 기간으로 묶여서 표시돼요.
- 연속되지 않은 날짜는 각각 별도의 기간으로 표시돼요.

예시: 1월 2일, 3일, 4일, 5일, 8일, 9일을 선택했다면

- 1월 2일~5일이 하나의 항목으로 표시돼요.
- 1월 8일~9일이 또 다른 항목으로 표시돼요.

나중에 묶인 항목마다 따로 편집하거나 삭제할 수 있어요.

## 자주 묻는 질문

### 2주마다 반복되는 가용성 일정을 설정할 수 있나요?

지금은 캘린더 설정에서 매주 반복되는 일정만 지원해요. 2주 간격으로 근무한다면 해당하는 날짜마다 **특정 날짜 시간**으로 가용성을 설정하는 방법이 가장 좋아요. 직접 설정해야 해서 번거롭지만, 실제 근무 패턴이 캘린더에 정확하게 반영돼요.

2주마다 캘린더를 업데이트하도록 알림을 만들어 두거나, 앞으로 몇 달 치 **특정 날짜 시간**을 미리 한꺼번에 설정해 두는 방법을 추천해요.

### 특정 날짜 시간을 추가하면 주간 근무 시간이 사라져요. 왜 그런가요?

**특정 날짜 시간**이 우선 적용되어 해당 날짜의 주간 근무 시간을 대체하기 때문이에요. 하루를 "연장"하려면 추가할 시간(예: 오후 5시~8시)만 입력하지 말고, 예약을 받고 싶은 전체 시간(예: 오전 9시~오후 8시)을 입력하세요.
