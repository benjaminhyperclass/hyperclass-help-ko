# 모바일 앱에서 원하는 시간대로 예약 보기

예약 시간대 환경설정을 쓰면 하이퍼클래스 모바일 앱에 표시되는 예약 시간을 내가 원하는 시간대로 바꿔 볼 수 있어요. 사용자 시간대, 비즈니스 시간대, 사용자가 직접 고른 시간대 중에서 선택할 수 있고, 예약 가능 시간이나 고객이 예약하는 방식은 바뀌지 않아요. 여러 지역에서 일하는 팀이 모바일에서도 시간대 때문에 헷갈리지 않고 예약을 관리할 수 있어요.

## 모바일 앱의 예약 시간대 설정이란?

**예약 보기**는 사용자별 캘린더 환경설정이에요. 하이퍼클래스 모바일 앱에서 예약 시간이 어떤 시간대로 표시될지 정해요. 예약 규칙, 예약 가능 시간, 고객이 예약하는 방식은 그대로 두고, 사용자마다 자기 업무에 맞는 시간대로 예약을 볼 수 있어요.

예약 시간은 다음 중 하나로 표시할 수 있어요.

- **사용자 시간대**: 내 계정에 설정된 시간대로 예약을 보여 줘요.
- **비즈니스 시간대**: 서브 계정에 설정된 시간대로 예약을 보여 줘요.
- **커스텀 시간대**: 내가 고른 시간대로 예약을 보여 줘요.

이 환경설정은 로그인한 본인에게만 적용돼요. 다른 팀원은 각자 원하는 시간대를 따로 고를 수 있어요.

설정을 저장한 뒤 모바일 앱에서 아래 순서로 확인해 보세요.

1. 하이퍼클래스 모바일 앱을 열고 하단 메뉴에서 **캘린더**를 탭하세요.

   ![모바일 앱 하단 메뉴에서 캘린더 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077112534/original/tR8XAfFni8KrHtn5yxn-JiHzIXwuIvmqIA.png?1785316962)

2. **캘린더 보기**에서 예약을 확인하세요. 예약이 선택한 시간대로 표시되고, 각 예약 시간 옆에 시간대 약어가 함께 나와요.

   ![선택한 시간대로 표시된 캘린더 보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077108429/original/uMEwQAmTSnnu3ZIyHk7kKg3v5DzUfCGAJA.png?1785315053)

3. 예약을 열어 **예약 상세 정보**의 **Appointment Time**(예약 시간)이 같은 시간대로 표시되는지 확인하세요.

## 이 설정을 쓰면 좋은 점

여러 지역의 고객, 팀, 캘린더와 일한다면 예약 시간을 직접 계산하지 않아도 돼요. 사용자마다 하루를 계획하는 기준에 맞는 시간대를 고르면 됩니다.

- 시간대를 자유롭게 선택: 사용자 시간대, 비즈니스 시간대, 커스텀 시간대 중에서 골라 예약을 볼 수 있어요.
- 일정 혼동 감소: 지역이 다른 예약 시간을 직접 환산하지 않아도 돼요.
- 사용자별 설정: 팀원마다 자신이 원하는 시간대를 고를 수 있어요.
- 일관된 모바일 환경: 지원되는 모바일 예약 화면에서 모두 내가 고른 시간대로 표시돼요.
- 예약에 영향 없음: 이 설정을 바꿔도 예약 가능 시간, 예약 링크, 고객의 예약 과정, 예약 처리 방식은 바뀌지 않아요.
- 기기 간 동기화: 설정은 내 계정에 저장되어, 지원되는 다른 기기에서도 그대로 적용돼요.

## 모바일 앱에서 시간대가 적용되는 화면

선택한 시간대는 모바일 앱의 지원되는 예약 화면 전반에 적용돼요. 캘린더, 예약 상세 정보, 연락처 기록 사이를 오가도 예약 시간이 같은 시간대로 보여요.

시간대 설정이 적용되는 화면은 다음과 같아요.

- 주간·월간 보기를 포함한 캘린더 격자 보기
- 예약 목록 보기
- 예약 상세 정보
- 예약 편집 화면
- 연락처의 예약 기록
- **Message Activity**(메시지 활동) 스케줄러 (제공되는 경우)

## 알아 두어야 할 시간대 동작

이 설정은 나에게 예약 시간이 어떻게 보이는지만 바꿔요. 예약이 잡히는 방식은 바뀌지 않아요. 하이퍼클래스는 일정 관리의 다른 부분에서 비즈니스 시간대, 사용자 시간대, 연락처 시간대에 따른 동작도 지원하기 때문에 이 차이를 알아 두는 게 좋아요.

**예약 보기** 설정을 바꿔도 아래 항목은 바뀌지 않아요.

- 고객이 예약할 수 있는 시간
- 캘린더의 예약 가능 시간
- **일정 규칙**
- 예약 확인 처리 방식
- 고객에게 보이는 예약 페이지의 동작
- 다른 사용자의 예약 시간대 보기

예를 들어 비즈니스는 뉴욕에 있는데 내가 로스앤젤레스에서 출장 중이라면, 예약을 태평양 시간으로 볼 수 있어요. 이때 비즈니스 캘린더의 시간대나 고객이 예약할 때 보는 시간은 바뀌지 않아요.

## 원하는 시간대로 예약 보기 설정하기

예약을 볼 시간대를 정해 두면 예약 시간이 내 업무 방식에 맞는 시간대로 표시돼요. 저장하면 앱의 지원되는 예약 화면에 모두 적용되고, 실제 예약 가능 시간이나 고객의 예약 경험은 바뀌지 않아요.

1. 왼쪽 메뉴에서 **캘린더**를 클릭하세요.

   ![왼쪽 메뉴에서 캘린더 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077112015/original/3eICCAMr71Tn6j4GR5IP3SUbWAmjm2fAAQ.png?1785316684)

2. 캘린더 페이지 위쪽에서 **캘린더 설정**(톱니바퀴 아이콘)을 클릭하세요. 캘린더 설정 화면이 열려요.

3. **캘린더 설정**에서 **환경설정** 탭을 클릭하세요.

   ![캘린더 설정의 환경설정 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077112449/original/CCDESoq9CHuTU2Hc2r6wKGKWrRB2qbUsUw.png?1785316894)

4. **환경설정**에서 **My preference**(내 환경설정) 탭을 선택하세요. **Account preference**(계정 환경설정) 탭이 아니에요. 아래로 스크롤해서 **예약 보기**를 찾으세요. 내 예약 시간 표시 방식을 정하는 설정이에요.

   ![환경설정의 My preference 탭에서 예약 보기 찾기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077112475/original/jhEKtMaK_bNRJ6xBq67YqfxGA2E6aH4bKA.png?1785316912)

   {% hint style="info" %}
   **예약 보기**가 보이지 않나요? 이 항목은 새로운 캘린더 환경을 쓰는 서브 계정의 **My preference** 탭에 나와요. **환경설정** 페이지에 **Account preference** 탭만 있고 **My preference** 탭이 없다면 이 항목이 표시되지 않아요. 아래 "설정이 없을 때"를 참고하세요.   {% endhint %}

5. **예약 보기** 아래의 **시간대** 드롭다운을 열고 **사용자 시간대**, **비즈니스 시간대**, **사용자 지정** 중에서 선택하세요. **사용자 지정**을 선택했다면 원하는 시간대를 검색해서 고르세요.

6. **환경설정 저장**을 클릭하세요.

   ![시간대를 고르고 환경설정 저장하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077112516/original/X82E4vgvXfzkTK10o1VLJZR-kaTR4KtOWw.png?1785316937)

   {% hint style="info" %}
   다음 단계에서 모바일 앱의 변화를 분명하게 보려면, **사용자 지정**에서 내 시간대와 확실히 다른 시간대를 골라 보세요.
   {% endhint %}

7. 모바일 앱을 열고 **캘린더**로 이동해서 **캘린더 보기**, **예약 목록 보기**, **예약 상세 정보**에서 예약을 확인하세요.

## 모바일 앱 지원 현황

설정한 예약 시간대는 모바일 앱에서 지원돼요. 컴퓨터를 쓰지 않을 때도 예약 시간을 같은 기준으로 볼 수 있어요. 최신 표시 방식을 쓰려면 모바일 앱을 최신 버전으로 유지하세요.

지원 현황은 다음과 같아요.

- 하이퍼클래스 모바일 앱: 지원
- 화이트라벨 모바일 앱: 호환되는 버전으로 업데이트하면 지원
- 지원 버전: 모바일 앱 버전 4.10.0 (810) 이상

설정이 보이지 않거나 예약 시간이 예상과 다르게 표시되면 모바일 앱을 업데이트하세요. 올바른 서브 계정과 사용자 프로필로 로그인했는지도 확인하세요.

## 이전 실험실 토글에서 넘어온 설정

이전에 있던 **실험실** 시간대 토글은 사용자별 **예약 보기** 설정으로 바뀌었어요. 기존 설정은 자동으로 옮겨져서, 업데이트한 뒤 시간대를 다시 설정하지 않아도 돼요.

기존 설정은 이렇게 옮겨져요.

- 예전 **실험실** 시간대 설정이 켜져 있었다면 **사용자 시간대**로 옮겨져요.
- 예전 **실험실** 시간대 설정이 꺼져 있었다면 기본값인 **비즈니스 시간대**로 설정돼요.

저장된 시간대가 올바르지 않거나 인식되지 않으면, 하이퍼클래스는 서브 계정 시간대 또는 비즈니스 시간대로 되돌려요.

## 시간대 표시가 이상할 때

시간대 표시 문제는 대개 앱 버전, 로그인한 계정, 저장하지 않은 설정 중 하나가 원인이에요. 아래 순서대로 확인해 보세요.

1. **예약 보기**가 올바른 시간대로 설정되어 있는지 확인하세요.
2. 설정을 다시 저장하세요.
3. 모바일 앱 버전이 4.10.0 (810) 이상인지 확인하세요.
4. 올바른 서브 계정에 로그인했는지 확인하세요.
5. 모바일 앱을 새로 고치거나 다시 실행하세요.
6. 화이트라벨 앱이라면 지원되는 버전으로 업데이트했는지 확인하세요.

## 자주 묻는 질문

### 이 설정을 바꾸면 고객이 예약하는 방식도 달라지나요?
아니요. 표시 방식만 바꾸는 설정이에요. 예약 가능 시간, 예약 슬롯, **일정 규칙**, 고객에게 보이는 예약 페이지는 바뀌지 않아요.

### 이 설정이 팀 전체에 똑같이 적용되나요?
아니요. 사용자별 설정이에요. 팀원마다 자신이 원하는 예약 시간대를 고를 수 있어요.

### 내 사용자 시간대나 비즈니스 시간대가 아닌 다른 시간대를 쓸 수 있나요?
네. **사용자 지정**을 선택하고 예약 시간을 볼 때 쓸 시간대를 고르세요.

### 하이퍼클래스 모바일 앱에서도 쓸 수 있나요?
네. 하이퍼클래스 모바일 앱의 지원되는 버전에서 쓸 수 있어요.

### 화이트라벨 모바일 앱에서도 쓸 수 있나요?
네. 화이트라벨 앱을 지원되는 버전으로 업데이트했다면 쓸 수 있어요.

### 어떤 앱 버전이 필요한가요?
모바일 앱 버전 4.10.0 (810) 이상을 쓰세요.

### 예전 실험실 시간대 토글은 어떻게 되었나요?
**실험실** 토글은 **예약 보기** 설정으로 바뀌었어요. 기존 설정은 자동으로 옮겨져요.

### 예약 시간이 여전히 이상하게 보여요
선택한 시간대 설정을 확인하고 다시 저장하세요. 그리고 모바일 앱이 최신 버전인지, 올바른 서브 계정을 보고 있는지도 확인하세요.

### 예약 알림 이메일에도 영향을 주나요?
아니요. 이 설정은 로그인한 사용자에게 지원되는 앱 화면에서 예약 시간이 어떻게 보이는지만 정해요. 예약 알림이나 예약 처리 방식은 바뀌지 않아요.
