# 날짜 범위에서 예약 가능한 날만 세기

**Count available days only**(가용 일수만 계산) 토글은 **날짜 범위**를 계산하는 방식을 바꿔요. 주말이나 근무하지 않는 날까지 모든 날짜를 세는 대신, 가용 일정에 있는 날만 세요. 예약하는 사람에게는 **최소 예약 안내 기간**이 끝난 다음 날부터 설정한 일수만큼이 항상 모두 보여요.

## Count available days only 토글이란?

**날짜 범위**는 예약 위젯을 미래 며칠까지 열어 둘지 정하는 설정이에요. 기본값은 주말이나 근무하지 않는 날을 포함해 모든 날짜를 세요. 그래서 월요일부터 금요일까지만 운영하는 사업장이 날짜 범위를 2일로 설정하면, 금요일에 방문한 고객에게는 예약 가능한 날이 없는 것처럼 보일 수 있어요. 월요일이 되기 전에 토요일과 일요일이 범위를 다 써 버리기 때문이에요.

**Count available days only** 토글을 켜면 이 문제가 해결돼요. 날짜 범위를 셀 때 가용 일정에 없는 날은 건너뛰고, **최소 예약 안내 기간**이 끝난 다음 날부터 세기 시작해요. 예약하는 사람은 빈 캘린더 대신, 설정한 일수만큼의 근무일을 그대로 볼 수 있어요.

{% hint style="warning" %}
이 토글은 **가용성** 설정을 그대로 읽어요. 가용 일정을 설정하지 않은 상태에서 토글을 켜면 예약 위젯에 예약 가능한 날짜가 하나도 표시되지 않아요.
{% endhint %}

## 켜는 방법

1. **캘린더 > 캘린더 설정**으로 이동한 다음, 수정할 캘린더에서 **편집**을 클릭하세요.
2. 왼쪽 메뉴에서 **Booking Rules**(예약 규칙)를 선택하세요.
3. **날짜 범위** 필드를 찾으세요.
4. **날짜 범위** 입력란 바로 아래에서 **Count available days only** 토글을 켜세요.

![Count available days only 토글 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079413774/original/fymcAWJnf2N_kffcaYdqrW15CNLv46ckmg.png?1787817830)

기존 캘린더에서는 이 토글이 모두 꺼져 있어요. 토글을 켜도 **날짜 범위** 숫자는 바뀌지 않아요. 그 숫자를 세는 방식만 바뀌어요.

## 작동 방식

### 토글 꺼짐 — 기본 동작

오늘부터 주말과 가용 일정이 없는 날을 포함해 모든 날짜를 세요. 일정과 관계없이 예약 가능 기간은 오늘부터 정확히 X일 뒤에 끝나요.

예시

- 오늘: 8월 15일(금)
- **날짜 범위**: 2일
- 가용 일정: 월~금요일
- **Count available days only**: 꺼짐

토요일(8월 16일)과 일요일(8월 17일)은 가용 일정이 없지만 둘 다 일수에 포함돼요. 위젯에는 예약 가능한 날이 표시되지 않아요.

---

### 토글 켜짐 — 가용한 날만 세기

가용 일정에 있는 날만 세요. 가용 일정이 없는 날은 건너뛰면서, 설정한 일수만큼 가용한 날을 찾을 때까지 앞으로 나아가요. 일주일에 근무일이 적은 사업장일수록 캘린더의 마지막 날짜는 캘린더상 더 먼 날로 잡혀요. 이는 정상적인 동작이에요.

예시

- 오늘: 8월 15일(금)
- **날짜 범위**: 2일
- 가용 일정: 월~금요일
- **Count available days only**: 켜짐

토요일과 일요일은 건너뛰고, 월요일(1)과 화요일(2)을 세요.

위젯에는 8월 18일(월)과 8월 19일(화)이 표시돼요.

예시 — 근무일이 듬성듬성한 일정

- 오늘: 8월 11일(월)
- **날짜 범위**: 5일
- 가용 일정: 월요일, 수요일, 금요일만
- **Count available days only**: 켜짐

| 날짜 | 일정 상태 | 계산 여부 |
| --- | --- | --- |
| 8월 11일(월) | 일정에 있음 | 1 |
| 8월 12일(화) | 일정에 없음 | 건너뜀 |
| 8월 13일(수) | 일정에 있음 | 2 |
| 8월 14일(목) | 일정에 없음 | 건너뜀 |
| 8월 15일(금) | 일정에 있음 | 3 |
| 8월 16일(토) | 일정에 없음 | 건너뜀 |
| 8월 17일(일) | 일정에 없음 | 건너뜀 |
| 8월 18일(월) | 일정에 있음 | 4 |
| 8월 19일(화) | 일정에 없음 | 건너뜀 |
| 8월 20일(수) | 일정에 있음 | 5 |

위젯에는 8월 11일, 13일, 15일, 18일, 20일이 표시돼요.

## 최소 예약 안내 기간과 함께 쓸 때

**최소 예약 안내 기간**과 **날짜 범위**는 서로 독립된 설정이에요. 안내 기간은 예약 가능 기간이 언제 시작되는지를 정하고, 날짜 범위는 그 시점부터 가용한 날을 며칠 보여 줄지를 정해요.

**Count available days only**를 켜면 먼저 안내 기간을 적용하고, 안내 기간이 끝난 다음 날부터 가용한 날을 세요. 예약하는 사람에게는 **날짜 범위**에 설정한 일수가 항상 모두 보여요.

예시

- 오늘: 8월 12일(수)
- **최소 예약 안내 기간**: 2일
- 가용 일정: 월~금요일
- **날짜 범위**: 5일
- **Count available days only**: 켜짐

안내 기간을 먼저 적용해요. 그다음 안내 기간이 끝난 뒤 첫 번째 가용한 날부터 가용한 날 5일을 세요.

| 날짜 | 일정 상태 | 계산 여부 |
| --- | --- | --- |
| 8월 15일(목) | 일정에 있음 | 1 |
| 8월 16일(금) | 일정에 있음 | 2 |
| 8월 17일(토) | 일정에 없음 | 건너뜀 |
| 8월 18일(일) | 일정에 없음 | 건너뜀 |
| 8월 19일(월) | 일정에 있음 | 3 |
| 8월 20일(화) | 일정에 있음 | 4 |
| 8월 21일(수) | 일정에 있음 | 5 |

위젯에는 8월 15일, 16일, 19일, 20일, 21일이 표시돼요. 가용한 5일이 모두 보여요.

예시 — 안내 기간이 근무하지 않는 날에 걸칠 때

- 오늘: 8월 14일(목)
- **최소 예약 안내 기간**: 2일
- 가용 일정: 월~금요일
- **날짜 범위**: 3일
- **Count available days only**: 켜짐

안내 기간은 토요일에 끝나요. 안내 기간 뒤 첫 번째 가용한 날은 월요일이에요.

| 날짜 | 일정 상태 | 계산 여부 |
| --- | --- | --- |
| 8월 18일(월) | 일정에 있음 | 1 |
| 8월 19일(화) | 일정에 있음 | 2 |
| 8월 20일(수) | 일정에 있음 | 3 |

위젯에는 8월 18일, 19일, 20일이 표시돼요.

{% hint style="info" %}
**최소 예약 안내 기간**은 항상 근무일이 아니라 캘린더상의 날짜로 세요. 사업장이 쉬는 토요일과 일요일도 안내 기간에 포함돼요. 안내 기간은 예약을 준비하는 데 필요한 실제 경과 시간을 뜻하며, 사업장이 일하는 날만 뜻하지 않기 때문이에요.
{% endhint %}

## 특정 날짜 시간과 함께 쓸 때

**특정 날짜 시간**은 개별 날짜에 한해 주간 **근무 시간**을 덮어써요. **Count available days only** 토글은 어떤 날을 셀지 정할 때 이 설정을 그대로 반영해요.

**주간 일정**에는 없지만 **특정 날짜 시간**을 추가한 날 → 가용한 날로 계산해요.

- **주간 일정**: 월~금요일
- 8월 16일(토)에 **특정 날짜 시간** 추가(예: 특별 행사)
- **Count available days only**: 켜짐
- 8월 16일(토)은 그 날짜에 한해 가용한 날로 계산돼요.

**주간 일정**에는 있지만 **특정 날짜 시간**에서 불가능으로 설정한 날 → 계산하지 않아요.

- **주간 일정**: 월~금요일
- 8월 18일(월)의 **특정 날짜 시간**을 불가능으로 설정(예: 공휴일)
- **Count available days only**: 켜짐
- 8월 18일(월)은 계산에서 건너뛰어요.

예시

- 오늘: 8월 15일(금)
- 가용 일정: 화요일, 수요일, 목요일(주간)
- **특정 날짜 시간**: 8월 18일(월)을 가능한 날로 추가
- **날짜 범위**: 4일
- **Count available days only**: 켜짐

| 날짜 | 일정 상태 | 출처 | 계산 여부 |
| --- | --- | --- | --- |
| 8월 16일(토) | 가용 시간 없음 | 주간 | 건너뜀 |
| 8월 17일(일) | 가용 시간 없음 | 주간 | 건너뜀 |
| 8월 18일(월) | 가능 | 특정 날짜 | 1 |
| 8월 19일(화) | 가능 | 주간 | 2 |
| 8월 20일(수) | 가능 | 주간 | 3 |
| 8월 21일(목) | 가능 | 주간 | 4 |

위젯에는 8월 18일, 19일, 20일, 21일이 표시돼요.

## 라운드 로빈 캘린더와 함께 쓸 때

라운드 로빈과 컬렉티브 캘린더에서는 배정된 팀원 중 한 명이라도 그날 가용 일정을 설정해 두었다면 가용한 날로 계산해요.

예시

- **날짜 범위**: 4일
- **Count available days only**: 켜짐
- 팀원 A: 월요일과 수요일 가능
- 팀원 B: 화요일과 목요일 가능

| 날짜 | 가능한 팀원 | 계산 여부 |
| --- | --- | --- |
| 월 | 팀원 A | 1 |
| 화 | 팀원 B | 2 |
| 수 | 팀원 A | 3 |
| 목 | 팀원 B | 4 |

위젯에는 4일이 모두 표시돼요. 각 날짜에는 그날 가능한 팀원의 시간대만 보여요.

어느 팀원도 가용 일정이 없는 날은 개인 캘린더와 마찬가지로 계산에서 건너뛰어요.

## 알아 두면 좋은 예외 상황

### 예약이 모두 찬 날도 범위에 포함돼요

이 토글은 시간대가 예약되었는지가 아니라 가용 일정을 기준으로 읽어요. 일정에는 있지만 시간대가 모두 예약된 날도 가용한 날 하나로 계산해요. 그런 날은 위젯에 표시되지만 예약할 수 있는 시간대는 없어요.

### 가용 일정을 설정하지 않았을 때

**가용성** 섹션에 설정된 요일이 하나도 없는데 토글을 켜면, 예약 위젯에 예약 가능한 날짜가 표시되지 않아요. 토글이 제대로 작동하려면 먼저 가용 일정을 설정하세요.

## 자주 묻는 질문

### 이 토글을 켜면 기존에 설정한 날짜 범위 숫자가 바뀌나요?

아니요. 토글은 숫자를 세는 방식만 바꿔요. 5일로 설정했다면 그대로 5일이에요. 다만 캘린더상의 날짜가 아니라 가용 일정을 기준으로 세요.

### 토글을 켠 뒤에 가용 일정을 수정하면 어떻게 되나요?

토글은 가용 일정을 실시간으로 읽어요. 가용 일정을 바꾸면 따로 할 일 없이 예약 위젯에 바로 반영돼요.

### 최소 예약 안내 기간은 가용한 날을 세나요, 캘린더상의 날을 세나요?

항상 캘린더상의 날짜로 세요. 안내 기간은 사업장이 문을 여는 날이 아니라 실제로 경과하는 시간을 뜻해요.
