# 페이스북 리드 광고에 하이퍼클래스 캘린더 임베드 예약 기능 사용하기

임베드 예약(Embedded Appointment Booking) 기능은 리드가 즉시 양식(Instant Form)을 제출한 직후 바로 예약 일정을 잡을 수 있게 해줘서, 페이스북 리드 광고(Facebook Lead Ads)의 양식 제출을 실제 예약으로 전환하는 데 도움을 줘요. Meta에서 지원하는 경우, 양식의 감사 페이지(Thank You Page)에 하이퍼클래스 캘린더(Calendars) 예약 화면이 바로 나타나서, 리드가 별도 페이지를 열거나 정보를 다시 입력할 필요가 줄어들어요. 상담, 데모, 견적, 서비스 예약처럼 예약 기반 캠페인을 운영하는 비즈니스에 유용한 기능이에요.

# 하이퍼클래스 캘린더 임베드 예약이란?

임베드 예약 기능을 사용하면 리드가 정보를 제출한 후, 페이스북 리드 광고 즉시 양식의 감사 페이지에서 바로 예약을 잡을 수 있어요. 리드를 별도의 예약 페이지로 이동시키는 대신, Meta가 지원하는 캘린더 예약 화면을 페이스북 모바일 앱 흐름 안에서 바로 표시할 수 있어요.

하이퍼클래스 캘린더 지원 기능을 사용하면, 광고주는 Meta의 즉시 양식 편집기에서 예약 시간 잡기(Book time) CTA(행동 유도 버튼)의 목적지로 하이퍼클래스 캘린더 예약 링크를 사용할 수 있어요. 임베드 화면이 가능한 경우, 리드는 감사 페이지에서 시간을 선택할 수 있고, 제출한 양식에 입력된 이름, 이메일, 전화번호 같은 리드 정보가 예약 화면으로 그대로 이어질 수 있어요.

## 하이퍼클래스 캘린더 임베드 예약의 주요 장점

- **단계 축소**: 리드가 별도 예약 페이지로 이동하지 않고 감사 페이지에서 바로 예약할 수 있어요.

- **예약 전환율 향상**: 리다이렉트와 반복 정보 입력을 줄이면 리드가 예약 과정을 끝까지 완료할 가능성이 높아져요.

- **하이퍼클래스 캘린더 예약 가능 시간 반영**: 예약 화면에 표시되는 시간은 하이퍼클래스 캘린더 링크와 그에 설정된 예약 가능 시간(Availability)을 기준으로 해요.

- **간편한 캠페인 설정**: 광고주는 즉시 양식 편집기에 지원되는 예약 링크를 붙여넣고 예약 시간 잡기 CTA를 사용하면 돼요.

- **더 나은 리드 후속 관리**: 페이스북 리드 광고는 리드 정보를 하이퍼클래스로 동기화할 수 있어서, 팀에서 CRM 레코드, 워크플로우, 육성(nurture) 캠페인을 활용해 후속 조치를 할 수 있어요.

- **예약 기반 자동화**: 예약이 완료되면 하이퍼클래스 워크플로우가 실행되어 확인 메시지, 리마인더, 내부 알림, 예약 후 후속 조치를 자동으로 처리할 수 있어요.

## 페이스북 리드 광고 즉시 양식과 하이퍼클래스 캘린더 링크

페이스북 리드 광고 즉시 양식은 Meta 광고 화면 안에서 리드 정보를 수집해요. 하이퍼클래스는 페이스북 리드 광고를 CRM으로 동기화하여 리드 확보 및 후속 관리를 지원하고, 하이퍼클래스 캘린더 링크는 예약 일정 잡기를 지원해요.

임베드 예약 기능을 사용하려면, 먼저 리드가 예약할 하이퍼클래스 캘린더를 새로 만들거나 기존 캘린더를 선택한 뒤, 해당 캘린더의 공개 예약 링크를 복사하세요. 캘린더 링크는 광고 캠페인에서 사용하려는 특정 캘린더, 서비스, 또는 예약 화면을 가리켜야 해요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074424875/original/aJgQRDOPxqUUGh178OGPK6BKZUN8Ilh3iw.gif?1782316110)

**중요**: Meta는 즉시 양식, CTA, 감사 페이지, 제공업체 감지, 미리보기, 노출 위치(placement) 동작을 제어해요. 하이퍼클래스는 캘린더 링크, 예약 가능 시간, 예약 규칙, 캘린더 알림, 예약 기록을 제어해요.

## 하이퍼클래스 캘린더 임베드 예약 설정 방법

올바르게 설정하면 페이스북 즉시 양식이 리드 정보를 수집하고, 예약 시간 잡기 액션을 표시하며, 리드를 올바른 하이퍼클래스 캘린더로 연결해줘요. 먼저 하이퍼클래스 캘린더를 만들거나 확인한 다음, 해당 예약 링크를 Meta의 즉시 양식 편집기에서 사용하세요.

- 
하이퍼클래스 하위 계정(Sub-account)에서 다음 두 경로 중 하나로 캘린더 페이지를 여세요:
왼쪽 네비게이션 메뉴에서 Calendars(캘린더) → Calendar Settings(캘린더 설정)로 이동
왼쪽 네비게이션 메뉴에서 Settings(설정) → Calendars(캘린더)로 이동

기존 예약 캘린더를 사용하거나 캠페인용 새 캘린더 예약을 만드세요. 캘린더를 먼저 만드는 방법이 필요하다면 [하이퍼클래스로 개인 예약 캘린더 설정하기](https://help.gohighlevel.com/support/solutions/articles/155000005061-getting-started-setup-a-booking-calendar) 문서를 참고하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074422420/original/D790ErYr-dS5-HdMsBTzYJVfc36qYrhXGg.png?1782315153)

- 
페이스북 리드가 예약할 하이퍼클래스 캘린더의 예약 링크를 복사하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074422722/original/BNg7zrx5tZ3qf3YPA5Y3bhPPwreRuEJkww.gif?1782315248)

- 페이스북에 로그인해서 광고 관리자(Ads Manager)로 이동한 후 + 만들기(+ Create)를 클릭하세요. 캠페인 목표로 Leads(리드)를 선택하고 계속(Continue)을 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074423120/original/joON6S5rBIZFbwWKt371DRTwjV5mdE5Apw.png?1782315420)

- 광고 만들기 단계를 완료하고, 광고 세트 단계에서 전환 위치(conversion location)로 Instant forms(즉시 양식)을 선택하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074423428/original/CQbtsYOjoHb0XgDy2PUn1iCMS5Y7DBzwgg.png?1782315510)

- 
즉시 양식을 만들고 필수 양식 설정 단계를 완료하세요. Ending(마무리) 섹션에서 Additional actions(추가 작업) 아래 Book time(예약 시간 잡기)을 선택하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074423859/original/ZwTL8cCixJLcXzVn5YWYrxLcuwWkQNBj_Q.png?1782315697)

- 
Scheduling link(예약 링크) 항목에 하이퍼클래스 캘린더 URL을 붙여넣으세요. Meta가 캘린더 제공업체를 자동으로 감지하며, 지원되는 경우 광고 관리자에서 임베드 캘린더 위젯의 실시간 미리보기를 보여줘요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074424018/original/_M8ShhQJRl54Gn5xQC6BNue3z2nL2uhYrA.png?1782315758)

- 즉시 양식의 나머지 항목을 완료하고, 광고가 준비되면 Publish(발행)를 클릭하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074424082/original/8gPJcZwLuhedf8NbHgWYYDEpupcVpRboow.png?1782315830)

- 양식 제출 이후 상황에 맞춰 하이퍼클래스에서 후속 워크플로우를 만드는 것도 고려해보세요. 예를 들어 즉시 양식을 제출한 리드를 후속 관리하려면 Facebook Lead Form Submitted(페이스북 리드 양식 제출됨) 트리거를 사용하고, 예약을 완료한 연락처에는 Customer Booked Appointment(고객 예약 완료) 트리거를 사용하며, 노쇼를 줄이고 팀에 알리기 위해 예약 리마인더나 내부 알림을 추가하세요.

**중요**: 임베드 예약 기능은 현재 페이스북 모바일 앱에서 노출되는 광고에서만 사용할 수 있어요. 인스타그램 등 다른 노출 위치에서 표시되는 광고는 예약 시간 잡기 CTA가 표시되더라도, 캘린더가 감사 페이지에 임베드되는 대신 별도의 인앱 브라우저로 예약 페이지가 열릴 수 있어요.

**참고**: 임베드 예약에는 LeadConnector 도메인의 하이퍼클래스 캘린더 링크를 사용하세요. 브랜드 도메인(커스텀 도메인) 캘린더 링크는 광고 관리자에서 임베드 미리보기가 나타나지 않을 수 있고, 실제 광고에서 임베드 화면 대신 브라우저로 예약 페이지가 열릴 수 있어요.

## 자주 묻는 질문

**Q: 인스타그램 노출 위치에서도 작동하나요?**
임베드 예약 화면은 페이스북 모바일 앱에 최적화되어 있어요. 인스타그램을 포함해 지원되지 않는 노출 위치에서는, 예약 링크가 감사 페이지에 바로 임베드되는 대신 기존의 인앱 브라우저 방식으로 열릴 수 있어요.

**Q: 예약된 일정은 어디서 확인하나요?**
캠페인에 사용한 것과 동일한 하위 계정을 열고 Calendars(캘린더) 메뉴로 이동하세요. 즉시 양식에 추가한 예약 링크와 연결된 특정 캘린더의 캘린더 뷰나 예약 뷰를 확인하세요. 날짜 범위, 캘린더, 팀원 필터를 사용하면 해당 캠페인에서 예약된 일정을 찾을 수 있어요.

**Q: 예약 화면에 리드 정보가 자동으로 채워지나요?**
지원되는 경우, 이름, 이메일, 전화번호 같은 리드 정보가 즉시 양식에서 예약 화면으로 전달되어 중복 입력을 줄여줘요.

**Q: 광고마다 다른 하이퍼클래스 캘린더를 사용할 수 있나요?**
네. 각 캠페인에 맞는 특정 하이퍼클래스 캘린더, 서비스, 또는 예약 흐름의 예약 링크를 사용하면 돼요.

**Q: 임베드 캘린더는 로드되는데 예약 가능한 시간이 안 보여요. 무엇을 확인해야 하나요?**
하이퍼클래스 캘린더의 예약 가능 시간, 배정된 팀원, 충돌 캘린더, 버퍼(buffer) 시간, 날짜별 운영 시간, 예약 규칙을 확인하세요. 또한 Meta 밖에서 하이퍼클래스 캘린더 링크를 직접 테스트해서 정상적으로 작동하는지 확인하세요.

**Q: 예약 확인은 Meta가 보내나요, 하이퍼클래스가 보내나요?**
예약 확인 및 리마인더는 예약 링크에 연결된 하이퍼클래스 캘린더와 알림 설정에서 관리해요.

**Q: 이 기능을 사용하려면 코딩이 필요한가요?**
표준 설정에는 코딩이 필요하지 않아요. 옵션이 제공될 때 즉시 양식 편집기의 예약 시간 잡기 CTA에 하이퍼클래스 캘린더 예약 링크를 추가하기만 하면 돼요.

**Q: 리드가 예약을 완료하기 전에 예약 위젯을 닫으면 어떻게 되나요?**
리드가 예약 위젯을 닫으면, 감사 페이지에서 예약 시간 잡기 버튼을 다시 눌러 위젯을 재오픈할 수 있어요. 메시징 기능이 켜져 있다면, 리드가 메신저(Messenger)로 예약 완료를 안내하는 리마인더를 받을 수도 있어요.

**Q: 광고 관리자에서 예약 건수를 확인할 수 있나요?**
이 임베드 예약 화면의 예약 건수는 광고 관리자에서 표시되지 않아요. 즉시 양식에서 사용한 예약 링크와 연결된 하이퍼클래스 캘린더에서 확정된 예약을 확인하세요.

**Q: 페이스북에 표시되는 임베드 캘린더를 커스터마이징할 수 있나요?**
캘린더의 표시 방식은 하이퍼클래스 캘린더 설정에 따라 결정돼요. Meta는 즉시 양식 화면 안의 임베드 캘린더에 대해 별도의 커스터마이징 옵션을 제공하지 않아요.
