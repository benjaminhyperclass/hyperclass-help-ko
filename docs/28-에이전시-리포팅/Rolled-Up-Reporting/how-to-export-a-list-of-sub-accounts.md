# 서브 계정 목록 CSV로 내보내기

하이퍼클래스의 **서브 계정** 목록을 CSV 파일로 내보내 리포트를 만들거나 팀과 공유할 수 있어요. 이 문서에서는 CSV에 담기는 항목, 이메일로 파일을 받는 방식, 내보내는 순서를 설명해요.

## 개요

서브 계정 목록 내보내기는 에이전시 팀이 모든 서브 계정의 주요 정보를 CSV 리포트로 빠르게 만드는 기능이에요. 서브 계정 데이터를 하나하나 모으려면 시간이 많이 드는데, 이 기능을 쓰면 한 번에 받아 볼 수 있어요.

**서브 계정** 목록에 적용한 필터가 그대로 반영돼요. 파일은 화면 밖(백그라운드)에서 만들어지고, 완성되면 선택한 사용자에게 이메일로 전달돼요. 브라우저를 계속 열어 둘 필요가 없고, 필터링한 목록 전체를 한 번에 받을 수 있어요. 많은 계정을 다루거나 팀 전체에 공유할 때 알맞아요.

## 주요 장점

- 필터 반영 내보내기: 내보내기 전에 **서브 계정** 목록에서 필터링한 결과가 CSV에 그대로 담겨요.
- 풍부한 상세 정보: 계정 단위의 다양한 데이터를 파일 하나에 모아서 받아요.
- 백그라운드 처리: 파일을 만드는 동안 다른 화면으로 이동해도 괜찮아요.
- 지정한 사람에게 이메일 전달: 다운로드 링크가 선택한 팀원에게 바로 가서, 따로 전달할 필요가 없어요.
- 대량 데이터 처리: 복잡한 SaaS 구성에서도 수천 건의 데이터를 효율적으로 처리해요.

## 포함되는 데이터 항목

내보낸 서브 계정 목록에는 각 서브 계정의 상태와 활동이 요약 정보와 상세 정보로 담겨요. 팀 안에서 분석하고, 대조하고, 공유하기 쉬워요. 파일에 포함되는 항목을 묶음별로 정리했어요.

- 식별 정보 및 기본 정보: ID, 이름, SaaS 활성화됨, 추가한 날짜
- 사용자 및 연락처 데이터: 활성 사용자, 연락처, 예약 완료 수
- 이메일 활동: 전체 이메일, 수신 이메일, 발신 이메일
- 문자 메시지 활동: 전체 문자 메시지, 수신 문자 메시지, 발신 문자 메시지
- 통화 활동: 전체 통화, 수신 통화, 발신 통화, 수신 통화 시간(시간 단위), 발신 통화 시간(시간 단위)
- 폼 및 설문 참여: 폼 제출, 설문 제출, Facebook 리드 폼 제출
- Google 비즈니스 프로필 메시지: GBP 메시지, 수신 GBP 메시지, 발신 GBP 메시지
- Instagram 메시지: 전체 Instagram 메시지, 수신 Instagram 메시지, 발신 Instagram 메시지
- Facebook 메시지: 전체 Facebook 메시지, 수신 Facebook 메시지, 발신 Facebook 메시지
- 리뷰: 리뷰, Google 리뷰, Facebook 리뷰, 긍정적인 리뷰, 부정적인 리뷰
- 생성한 사이트 및 퍼널: 생성된 사이트 - 퍼널, 생성된 사이트 - 활성 퍼널, 생성된 사이트 - 웹사이트, 생성된 사이트 - 활성 웹사이트, 생성된 사이트 - 폼, 생성된 사이트 - 활성 폼, 생성된 사이트 - 설문, 생성된 사이트 - 활성 설문

## 내보내기에 반영되는 필터

필터를 쓰면 필요한 계정만 골라서 내보낼 수 있어요. 불필요한 데이터가 빠지고, 지금 보고 있는 목록과 CSV가 같아져요. 내보내기를 시작할 때 적용해 둔 필터(예: **SaaS mode**(SaaS 모드), **구독 상태**, **Assigned Snapshot**(할당된 스냅샷))가 최종 파일에 그대로 반영돼요.

![서브 계정 목록에 적용한 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051477598/original/1-PbcMtIVOan4LPJlwFq01152kCkw5vg0w.png?1755029785)

```
필터 사용법과 조합 방법은 "$97·$297 에이전시 요금제용 새 서브 계정 목록 UI" 문서를 참고하세요.
```

## 서브 계정 목록 내보내기

아래 순서대로 따라 하면 서브 계정 정보가 담긴 CSV 파일을 만들 수 있어요.

#### 1단계: 서브 계정으로 이동하기

- **에이전시 대시보드**에서 왼쪽 메뉴의 **서브 계정**을 선택하세요.
- 내보내려는 데이터에 맞게 필터를 적용하세요.

![서브 계정 메뉴에서 필터를 적용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078853608/original/-h0ac9_Hu1BaUZh1wcT9Be62PHPpIAF2mA.png?1787182698)

#### 2단계: 리포트 내보내기 선택하기

오른쪽 위에 있는 **리포트 내보내기** 버튼을 클릭하세요.

![오른쪽 위의 리포트 내보내기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078853613/original/UkxFrdvLwj_LPZut7reGYV163QeXvRB40g.png?1787182728)

#### 3단계: 수신자 선택하기

- 팝업의 드롭다운에서 CSV를 받을 팀원(수신자)을 선택하세요.
- 수신자를 선택했으면 파란색 **내보내기** 버튼을 클릭하세요.

![수신자를 선택하고 내보내기를 클릭하는 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051477865/original/BUGV_Izs41U321Um_XCQGz8Gdwp6CT3Z0w.png?1755030517)

#### 4단계: 시작 확인하기

- **"Your export has started!"**(내보내기가 시작되었어요!)라는 확인 창이 나타나요.
- 탭을 닫거나 다른 작업을 계속해도 돼요. 내보내기는 백그라운드에서 처리되고, 처리가 끝나면 선택한 수신자에게 파일이 이메일로 전달돼요.

![내보내기 시작 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051477901/original/EE1mVKjV358jPm-Gk-WmuUrJ6xudlgETsA.png?1755030627)

#### 5단계: 파일 다운로드하기

- 이메일이 도착하면 파란색 **Download Sub-Accounts List-YYYY-MM-DD.csv**(서브 계정 목록 다운로드) 버튼을 클릭해 파일을 받으세요.
- 링크가 만료되었다면(7일), 같은 필터로 내보내기를 다시 실행하세요.
- 받은 파일은 아무 스프레드시트 프로그램으로 열면 돼요.

![이메일에서 CSV 파일을 다운로드하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051477950/original/6Lkw6znStPuZfSZCGI67CjPOva-STAZbOw.png?1755030740)

## 사용 사례

- 고객사 리포트: 내보낸 데이터로 고객사에 보낼 종합 리포트를 만들어 전략의 성과를 보여 줄 수 있어요. 예약 완료 수, 폼 제출 수, 수신·발신 커뮤니케이션 같은 지표를 담을 수 있어요.
- 고객사 캠페인 전략 수립: 소셜 미디어 참여와 고객 응대 정보를 보면 고객사의 마케팅 활동에 대한 반응을 더 잘 파악할 수 있어요. 이를 바탕으로 캠페인 전략을 개선하고 조정해 보세요.
- 리소스 관리: 세부 지표를 보면 어떤 고객사나 캠페인에 커뮤니케이션이나 예약 같은 리소스가 더 필요한지 알 수 있어요. 팀의 시간과 노력을 배분하는 데 도움이 돼요.
- 성과 분석: 설문 제출, 폼 제출, 활성 사용자 수 같은 지표를 추적해 고객사별 마케팅 전략의 효과를 확인하고 필요하면 조정할 수 있어요.
- 고객사 기회 발굴: 기존 고객사에 서비스를 추가로 제안하거나 확장할 기회를 찾는 데 쓸 수 있어요. 예를 들어 Facebook 참여는 활발한데 Instagram은 적은 고객사라면, 소셜 미디어 마케팅 서비스를 추가로 제안해 볼 수 있어요.
- 온라인 평판 모니터링: Google과 Facebook 리뷰로 고객사의 온라인 평판을 살펴볼 수 있어요. 리뷰 관리 전략을 세우고 고객사의 온라인 입지를 개선하는 데 참고하세요.
- 리드 생성 및 전환: 리드가 들어오는 경로(Facebook, Messenger, Instagram)를 분석하면 성과가 좋은 곳에 마케팅 노력을 집중할 수 있어요. 고객사의 리드 생성과 전환을 최적화해 보세요.
- 팀 회의 및 고객사 리뷰: 팀 회의나 고객사 리뷰에서 마케팅 현황을 데이터로 분명하게 보여 줄 수 있어요. 현실적인 기대치를 설정하고 앞으로의 전략을 세우는 데 도움이 돼요.

## 자주 묻는 질문

### 필터링한 서브 계정만 내보내지나요?

네. CSV에는 내보내기를 시작한 시점에 **서브 계정** 목록에 적용한 모든 필터가 반영돼요.

### 내보내기는 얼마나 걸리나요?

보통 7~10분 정도 걸려요. 서브 계정이 수천 개처럼 많으면 더 오래 걸릴 수 있어요. 파일이 준비되면 이메일로 알려 드려요.

### 이메일 링크가 만료되면 어떻게 하나요?

링크는 7일 후에 만료돼요. 내보내기를 다시 실행해서 새 링크를 받으세요.

### 브라우저에서 바로 파일을 다운로드할 수 있나요?

아니요. 내보내기는 비동기로 처리되고, 선택한 수신자에게 이메일로 전달돼요.

### 연락처 내보내기와는 어떻게 다른가요?

연락처 내보내기는 서브 계정 하나를 기준으로 앱 안에서 바로 다운로드하는 방식이에요. 서브 계정 목록 내보내기는 에이전시 단위의 CSV 파일을 이메일로 받는 방식이고, 여러 서브 계정의 정보가 한 파일에 담겨요.
