# 에이전시 통합 리포팅

서브 계정의 주요 데이터를 에이전시 계정으로 모아 한곳에서 볼 수 있어요. 에이전시에 속한 모든 서브 계정의 성과를 한눈에 확인할 때 쓰세요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 서브 계정 통합 리포트

에이전시 계정에서 **서브 계정**으로 이동한 다음 **컬럼** 버튼을 클릭하세요.

![컬럼 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048428356/original/xJb4MWFinihNceExFvq0ogtqWRjLDM4YEQ.png?1750186878)

모든 서브 계정 요약 카드에 표시할 컬럼을 최대 8개까지 선택할 수 있어요.

- **활성 사용자**
  - 선택한 기간에 웹이나 모바일 앱(iOS, Android)으로 한 번 이상 로그인한 사용자예요.
  - 79/100 같은 형식으로 보여 줘요. 79는 활성 사용자 수이고, 100은 선택한 기간에 만들어진 서브 계정의 전체 사용자 수예요.
  - 서브 계정 관리자(admin)와 에이전트(agent) 모두 해당돼요.
- **예약**: 선택한 기간에 만들어진 예약의 수예요. 예약 상태와 상관없이 모두 세어요.
- **연락처**: 선택한 기간에 해당 서브 계정에서 만들어진 연락처의 수예요.
- **이메일**
  - 수신 이메일: 선택한 기간에 연락처가 서브 계정 관리자·사용자에게 보낸 이메일의 수예요.
  - 발신 이메일: 서브 계정 관리자·사용자가 연락처에게 보낸 SMS의 수예요. 자동화로 보낸 이메일은 포함되지 않아요.- **문자 메시지**
  - 수신 SMS: 선택한 기간에 연락처가 서브 계정 관리자·사용자에게 보낸 SMS의 수예요.
  - 발신 SMS: 서브 계정 관리자·사용자가 연락처에게 보낸 SMS의 수예요. 자동화로 보낸 SMS는 포함되지 않아요.
- **전화**
  - 수신 통화: 선택한 기간에 연락처가 서브 계정 관리자·사용자에게 건 통화의 수예요.
  - 발신 통화: 서브 계정 관리자·사용자가 연락처에게 건 통화의 수예요. 자동화로 건 통화는 포함되지 않아요.
  - 통화 시간: 사용자와 연락처 사이에 이뤄진 통화 시간의 합계예요.
- **제출**
  - 폼: 제출된 폼의 총 수
  - 설문: 제출된 설문의 총 수
  - Facebook 폼: 제출된 Facebook 폼의 총 수
- **WhatsApp**
  - 수신: 선택한 기간에 서브 계정·사용자에게 온 WhatsApp 메시지의 수
  - 발신: 보낸 WhatsApp 메시지의 수
- **GBP (Google 비즈니스 프로필)**
  - 수신 메시지: 선택한 기간에 연락처가 GMB를 통해 서브 계정 관리자·사용자에게 보낸 메시지의 수
  - 발신 메시지: 서브 계정 관리자·사용자가 연락처에게 보낸 메시지의 수
  - 자동화로 보낸 메시지는 포함되지 않아요.
- **Instagram**
  - 수신 메시지: 선택한 기간에 연락처가 IG를 통해 서브 계정 관리자·사용자에게 보낸 메시지의 수
  - 발신 메시지: 서브 계정 관리자·사용자가 연락처에게 보낸 메시지의 수
  - 자동화로 보낸 메시지는 포함되지 않아요.
- **Facebook**
  - 수신 메시지: 선택한 기간에 연락처가 Facebook을 통해 서브 계정 관리자·사용자에게 보낸 메시지의 수
  - 발신 메시지: 서브 계정 관리자·사용자가 연락처에게 보낸 메시지의 수
  - 자동화로 보낸 메시지는 포함되지 않아요.
- **리뷰**
  - 전체: 해당 서브 계정이 받은 리뷰의 수
  - 긍정: 받은 긍정 리뷰의 수
  - 부정: 받은 부정 리뷰의 수
- **Sites Created**(생성된 사이트)
  - 퍼널: 만든 퍼널의 수
  - 웹사이트: 만든 웹사이트의 수
  - 폼: 만든 폼의 수
  - 설문: 만든 설문의 수

## 서브 계정 예약 리포트 관리

**에이전시 보기**에서는 모든 서브 계정의 예약 리포트를 한 화면에서 관리할 수 있어요. 리포트를 일시정지하거나 다시 시작하고, 상태별로 걸러 보고, 새 서브 계정에 적용할 동작도 설정할 수 있어요.

### 예약 리포트 표

**에이전시 보기 > 서브 계정 > View Scheduled Reports**(예약 리포트 보기)로 이동하세요.

- 모든 서브 계정의 예약 리포트 목록을 볼 수 있어요.

  ![예약 리포트 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049079548/original/mUtZIGCYBWMbLYXYiSNLxh1opUv-CXLCuQ.png?1751283692)
- 체크박스로 리포트를 하나 이상 선택해요.
- **일괄 작업**으로 선택한 리포트를 **일시정지**하거나 **다시 시작**할 수 있어요.

  ![일괄 작업으로 리포트 일시정지·다시 시작](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049079568/original/8lC4urkJJXVvpEA4-OlByVM0OZfz8FH6Jw.png?1751283703)

## 상태별 필터

목록을 활성 또는 일시 중지 상태의 일정으로만 좁혀서 발송 현황을 빠르게 점검할 수 있어요.

- **상태** 필터를 선택하고 **활성** 또는 **일시 중지**를 고르세요.
- **일시 중지**를 선택하면 다시 시작하기 전까지 발송되지 않는 일정을 찾을 수 있어요.

## 설정 패널

신규 서브 계정 온보딩, 휴일, 템플릿 변경 때 의도하지 않은 발송을 막으려면 전체 동작을 설정하세요.

- 예약 리포트 화면에서 **설정** 아이콘(톱니바퀴)을 클릭하세요.
- **Pause All Scheduled Reports**(모든 예약 리포트 일시 정지): 에이전시 수준에서 목록에 있는 모든 예약 리포트를 바로 일시정지해요. 템플릿이나 수신자를 대대적으로 바꾸기 전에 사용하세요.
- **Auto-create scheduled reports for new sub-accounts**(신규 서브 계정에 예약 리포트 자동 생성) 토글:
  - **켬**: 새 서브 계정이 추가되면 기본 예약 리포트가 자동으로 만들어져요.
  - **끔**: 새 서브 계정에 리포트가 자동으로 만들어지지 않아요. 온보딩 중에 실수로 발송되는 일을 막을 수 있어요.

모범 사례

- 모든 신규 고객에게 수동 설정 없이 기본 리포트를 보내려면 **Auto-create**(자동 생성)를 켜세요.
- 리포트를 보내기 전에 템플릿, 수신자, 발송 시간을 먼저 검토하고 싶다면 **Auto-create**(자동 생성)를 끄세요.

### 사용 방법

1. **에이전시 계정 > 서브 계정 > View Scheduled Reports**로 이동하세요.
2. 체크박스로 관리할 리포트를 선택하세요.
3. 일괄 작업 바에서 **일시정지** 또는 **다시 시작**을 선택하세요.
4. 모든 리포트를 일시정지하거나 자동 생성 동작을 설정하려면 **설정** 아이콘을 클릭하세요.

## 자주 묻는 질문

### 에이전시 통합 리포팅 설정은 누가 사용할 수 있나요?
월 $497 이상 플랜에서 **에이전시 보기** 권한이 있는 사용자가 사용할 수 있어요.

### 여러 리포트를 한 번에 다시 시작할 수 있나요?
네. 체크박스로 여러 행을 선택한 다음 **일괄 작업** 바에서 **다시 시작**을 선택하세요.

### Pause All(모든 예약 리포트 일시 정지)을 켜면 나중에 자동으로 만들어지는 리포트도 멈추나요?
**Pause All Scheduled Reports**는 현재 있는 일정만 일시정지해요. 새 서브 계정에 일정을 자동으로 만들지는 **Auto-create**(자동 생성) 토글이 정해요. 필요하면 두 가지를 함께 사용하세요.

### 발송되지 않는 리포트를 빠르게 찾으려면 어떻게 하나요?
**상태** 필터에서 **일시 중지**를 선택하세요.
