# 하이퍼클래스 코스 드립 설정 관리

Kajabi에서 하이퍼클래스로 옮기는 전체 과정을 안내하는 문서예요. 온라인 코스, 자동화, 오퍼, 그 밖의 디지털 자산을 옮기는 단계를 다루고, 하이퍼클래스의 마케팅 자동화와 CRM 기능을 충분히 쓸 수 있도록 도와줘요. 마지막의 자주 묻는 질문에서는 코스 드립 설정도 설명해요.

## 마이그레이션 준비

### 1단계: 현재 Kajabi 설정 검토

- 핵심 자산 파악: Kajabi에 있는 모든 코스, 오퍼, 자동화, 그 밖의 디지털 자산을 목록으로 정리하세요.
- 워크플로우 기록: 운영에 꼭 필요한 Kajabi 자동화, 이메일 캠페인, 연동의 세부 내용을 기록하세요.
- 데이터 규모 확인: 옮길 콘텐츠(예: 동영상, 첨부파일)와 데이터(예: 연락처, 주문)가 얼마나 되는지 확인하세요.

### 2단계: 마이그레이션 목표 정하기

- 명확한 목표 설정: CRM 기능 강화, 통합 마케팅 자동화, 비용 절감 등 하이퍼클래스로 옮겨서 얻고 싶은 것을 정하세요.
- 기능 우선순위 정하기: 어떤 콘텐츠와 워크플로우를 먼저 옮길지 정하세요.

### 3단계: 백업 준비

- 데이터 백업: 마이그레이션을 시작하기 전에 모든 데이터가 안전하게 백업됐는지 확인하세요.

## Kajabi 가져오기 안정성 개선

하이퍼클래스는 규모가 크고 구조가 중첩된 코스도 잘 가져올 수 있도록 Kajabi 코스 가져오기를 개선했어요.

개선된 가져오기 과정은 이제 다음과 같이 동작해요.

- “Show More”(더 보기) 영역을 자동으로 찾아 펼쳐요.
- 중첩된 카테고리와 하위 카테고리 안의 강의도 가져와요.
- 규모가 큰 코스를 더 안정적으로 가져와요.

이 개선 덕분에 Kajabi에 있는 강의와 모듈을 더 일관되게 가져올 수 있어요.

## 코스 옮기기

하이퍼클래스의 Kajabi 가져오기 도구를 쓰면 동영상, 텍스트, 이미지를 포함한 코스를 쉽게 옮길 수 있어요. 단, 과제와 퀴즈는 자동으로 옮겨지지 않아요. 하이퍼클래스에서 직접 다시 만들어야 해요.

![Kajabi 코스 가져오기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042993816/original/qqQQl4sHcx6Vw4KR2Aq9tBdLgE8N-avogw.png?1741632257)

### 1단계: 준비하기

- 백업 만들기: 시작하기 전에 Kajabi 테마와 코스 콘텐츠를 백업해 사본을 보관하세요.
- 마이그레이션 계획 세우기: 수강생에게 불편이 가지 않도록 사용량이 적은 시간대에 시작하세요. 그러면 과정도 더 매끄러워요.

### 2단계: 코스를 하이퍼클래스로 옮기기

1. 하이퍼클래스에서 **사이트 > 멤버십**으로 이동한 뒤 **Kajabi 에서 가져오기**를 선택하세요.
2. 화면의 안내에 따라 Kajabi 계정을 안전하게 연결하세요.
3. 가져올 코스를 선택하세요. 게시된 강의만 가져오므로, 모든 콘텐츠가 게시된 상태인지 확인하세요.
4. **Import Course**(코스 가져오기)를 클릭하고 작업이 끝날 때까지 기다리세요. 코스 크기에 따라 몇 분 걸릴 수 있어요.

### 3단계: 과제와 퀴즈를 하이퍼클래스에서 다시 만들기

1. 상품 선택

   - 하이퍼클래스에서 **사이트 > 멤버십 > 상품**으로 이동하세요.
   - 평가를 추가할 상품을 선택하세요.
   - 섹션 제목 옆의 "+" 아이콘을 클릭하고 **Add Assessment**(평가 추가)를 선택하세요.

2. 평가 만들기

   - 평가의 **제목**을 입력하고 **저장**을 클릭하세요.

3. **합격 점수** 설정(선택 사항)

   - 평가에 합격 점수가 필요한지 정하세요.
   - 필요하다면 합격에 필요한 최소 점수를 설정하세요.

4. 맞춤 메시지

   - 수강생 점수에 따라 합격/불합격 메시지를 만드세요.

5. 질문 추가

   - **단일 선택**(정답 1개) 또는 **복수 선택**(정답 여러 개) 중 하나를 고르세요.
   - 질문을 입력하고 **Add choice**(선택지 추가)로 선택지를 입력하세요.
   - **정답** 체크박스로 정답 선택지를 표시하세요.

6. 평가 저장 및 게시

   - 저장한 뒤 상품 편집 페이지로 돌아가세요.
   - 공개할 준비가 되면 평가 옆의 **게시**를 클릭하세요.
   - 게시하면 평가가 모든 코스 멤버에게 표시되고 접근할 수 있어요.

![평가 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042993811/original/FZVUXBVpW5ldMeSItuwd7X_XoXkknMT1cQ.png?1741632255)

## 연락처 옮기기

### 1단계: Kajabi에서 연락처 목록 내보내기

- Kajabi의 **Contacts**(연락처) 탭으로 이동하세요.
- 모든 연락처를 선택하고 일괄 작업 드롭다운에서 CSV 파일로 내보내세요.
- CSV 파일은 Kajabi 계정에 연결된 이메일 주소로 전송돼요. 링크는 3일 후에 만료되니 빨리 파일을 내려받으세요.

### 2단계: 하이퍼클래스 가져오기용 CSV 준비

- 날짜 형식 확인: CSV의 모든 날짜 필드를 YYYY-MM-DD 형식으로 맞추세요. 하이퍼클래스와 호환되려면 꼭 필요해요.
- 특수 문자 인코딩: 특수 문자와 악센트 문자를 제대로 처리하려면 CSV 파일의 문자 인코딩을 UTF-8로 지정하세요.
- 데이터 정리: 파일에서 줄 바꿈, 이모지, 불필요한 특수 문자를 지우세요. 가져오기 오류를 막는 데 도움이 돼요.
- 커스텀 필드 다시 만들기: 하이퍼클래스에 로그인한 뒤 **연락처 > 설정 > 커스텀 필드**로 이동하세요. Kajabi에서 저장하던 방식과 비슷하게 연락처 데이터를 저장할 커스텀 필드를 추가하세요.

### 3단계: 연락처를 하이퍼클래스로 가져오기

1. 하이퍼클래스에 로그인한 뒤 왼쪽 메뉴에서 **연락처**로 이동하세요.
2. **Import Contacts**(연락처 가져오기) 버튼을 클릭하세요.
3. 준비한 CSV 파일을 선택해 업로드하세요. (**CSV 파일 업로드**)
4. **필드 매핑** 화면에서 CSV 파일의 필드를 하이퍼클래스의 해당 필드와 연결하세요. 예를 들어 CSV의 “First Name” 열은 하이퍼클래스의 **이름** 필드에 매핑해요.

   {% hint style="info" %}
   필드 매핑 팁: 필수 필드가 모두 올바르게 매핑됐는지 확인하세요. CSV의 필드에 대응하는 하이퍼클래스 필드가 없다면, 계속하기 전에 하이퍼클래스에서 커스텀 필드를 만들어야 할 수 있어요.
   {% endhint %}

5. 가져오는 중에 연락처를 특정 리스트에 넣고 태그를 지정할 수 있어요. 연락처의 출처를 나타내는 태그를 적용해 보세요. 예를 들면 "코스 A - 수강 중"이나 "Kajabi에서 가져옴" 같은 태그예요.
6. 모든 필드 매핑과 태그/리스트 설정을 마쳤으면 **가져오기**를 클릭하세요. 하이퍼클래스가 가져오기를 처리하고 연락처를 계정에 추가해요.

```
CSV로 일괄 가져오기 문제 해결에 대한 자세한 정보를 보려면 여기를 클릭하세요.
```

## 캘린더 옮기기

Kajabi의 예약은 하이퍼클래스처럼 일회성 이벤트와 반복 이벤트를 모두 지원해요. 하이퍼클래스 캘린더에서 이중 예약이 생기지 않도록 Google Calendar나 Microsoft Outlook 같은 외부 캘린더도 함께 옮기세요.

```
Kajabi 캘린더와 예약에 Calendly를 쓰고 있다면 이 안내서를 확인해 보세요!
```

![캘린더 옮기기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042993817/original/_7KO_3NlvTJnVZEQHfwHxKmwUgr4b6_OAg.png?1741632257)

### 1단계: Kajabi에 연결된 캘린더 검토

- 캘린더 연동 확인: Kajabi의 **Products > Coaching > Settings**에서 연결된 Google 캘린더와 Outlook 캘린더를 확인하세요.
- 캘린더 세부 정보 기록: 각 캘린더의 용도와 쓰이는 곳(예: 웹사이트, Zoom 미팅)을 적어 두세요. 유료 세션이 있는 캘린더인지도 함께 기록하세요.

### 2단계: Kajabi 캘린더를 하이퍼클래스에서 다시 만들기

- 하이퍼클래스 캘린더 만들기: 서브 계정의 **설정 > 캘린더**로 이동하세요. Kajabi의 캘린더와 같아지도록 캘린더를 하나씩 설정하세요. 알림, 담당 사용자, 미팅 장소 같은 설정도 맞춰 주세요.
- 캘린더 연동 추가: 서브 계정의 **설정 > 캘린더 > 연결**로 이동해 Google 또는 Outlook 캘린더를 하이퍼클래스와 동기화하세요.
- 반복 예약 설정: 반복되는 이벤트는 하이퍼클래스 캘린더 설정에서 반복 규칙을 직접 설정하세요.
- 확인 및 테스트: 새 캘린더를 기존 Kajabi 설정과 비교해 가며 제대로 작동하는지 확인하세요.

### 3단계: 하이퍼클래스 캘린더 사용자 지정

- 하이퍼클래스는 다양한 캘린더 스타일과 설정을 제공해요. 자주 쓰는 구성은 이렇게 시작해 보세요.

  - 라운드 로빈 캘린더 만들기: 여러 팀원에게 예약을 나눠 배정하고 싶을 때 쓰는 설정이에요.
  - 수업 일정 설정: 그룹 세션이나 수업용 캘린더를 구성하세요.
  - 반복 예약: 계속되는 미팅이나 수업을 반복 세션으로 설정하세요.
  - 세부 사용자 지정: 색상, 가용 시간, 사용자 권한을 필요에 맞게 조정하세요.

- 이런 캘린더 유형을 더 자세히 알고 싶다면 하이퍼클래스 도움말 센터에서 “캘린더 설정”을 검색해 보세요.

## 오퍼와 자동화 옮기기

![오퍼와 자동화 옮기기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042993812/original/3ItRz8S-GVvhG8n6dC0VHa2L_084ug-5oQ.png?1741632256)

### 1단계: 기존 Kajabi 오퍼와 자동화 검토

- 활성 오퍼 목록 작성: Kajabi 계정의 무료·유료 오퍼를 모두 찾아, 연결된 상품, 가격, 결제 설정을 정리하세요.
- 자동화 기록: 이메일 시퀀스, 태그, 코스 접근 권한이나 다른 동작을 제어하는 트리거 등 Kajabi의 모든 자동화를 적어 두세요.

### 2단계: Kajabi에서 이메일 템플릿 가져오기

1. 하이퍼클래스에서 새 이메일 템플릿을 만드세요.

   - 하이퍼클래스 계정에서 **이메일 마케팅 > 템플릿**으로 이동하세요.
   - **신규**를 클릭하고 **Import Templates**(템플릿 가져오기)를 선택하세요.
   - 드롭다운 메뉴에서 **Kajabi**를 선택하세요.

2. 화면에 표시된 이메일 ID를 복사하세요. 템플릿을 보낼 때 이 주소를 써요.
3. Kajabi로 이동해 가져오려는 템플릿을 테스트 이메일 또는 캠페인으로 복사한 이메일 ID에 보내세요.
4. 하이퍼클래스로 돌아와 **계속**을 클릭하고, 템플릿 이름을 입력한 뒤 **템플릿 만들기**를 선택하세요.

```
자세한 내용은 하이퍼클래스 Kajabi 이메일 템플릿 가져오기 안내서를 확인하세요.
```

### 3단계: 오퍼를 하이퍼클래스에서 다시 만들기

1. 하이퍼클래스에서 **멤버십** 탭으로 이동해 드롭다운 메뉴를 클릭하고 **오퍼**를 선택하세요.
2. 오퍼 만들기: **제목**을 입력하고 **상품**(코스)을 고른 뒤 **가격**을 설정하고 **만들기**를 클릭하세요.

   - 오퍼를 게시하기 전까지는 **DRAFT**(초안) 탭에 표시돼요.

3. 멤버십 오퍼를 상품에 연결하세요.

   - **결제** 탭을 클릭한 뒤 **상품** 탭으로 이동하세요.
   - **+ 상품 만들기**를 클릭하고 상품 정보를 입력하세요.
   - **Pricing name**(가격 이름), **type**(유형), **amount**(금액)을 입력하세요.
   - **추가 옵션**으로 이동해 **멤버십**을 켜고, 알맞은 멤버십 오퍼를 선택하세요.

{% hint style="info" %}
오퍼를 게시해야 드롭다운 메뉴에 표시돼요. 자세한 내용은 하이퍼클래스 오퍼 설정 안내서를 참고하세요.
{% endhint %}

### 4단계: 자동화를 하이퍼클래스에서 다시 만들기

- 새 워크플로우 만들기: 하이퍼클래스의 **워크플로우**로 Kajabi 자동화를 똑같이 구성하세요. Kajabi 워크플로우와 맞는 트리거, 액션, 조건을 설정하세요.
- 사용할 수 있는 액션: 워크플로우 빌더는 영어 화면이에요. 다음 같은 액션을 쓸 수 있어요.

  - **Grant Course Access**(코스 액세스 부여): 수강생에게 특정 코스의 접근 권한을 줄 때 써요.
  - **Send Email**(이메일 보내기): 이메일 시퀀스를 똑같이 만들 때 써요.
  - **If/Else**(조건 분기): 태그와 사용자 여정을 관리할 때 써요.

```
전체 개요는 워크플로우와 자동화 소개 및 코스 액세스 액션 안내서를 참고하세요.
```

### 5단계: 워크플로우 테스트

- 각 워크플로우가 의도대로 작동하는지 테스트하세요. 트리거, 이메일 시퀀스, 코스 접근 권한 설정을 확인하고 필요하면 수정하세요.

## 웹사이트와 퍼널 옮기기

하이퍼클래스의 **웹사이트 빌더**로 홈페이지, 상품 페이지, 문의 페이지 등 Kajabi 사이트의 페이지를 다시 만들 수 있어요. 하이퍼클래스의 템플릿과 블록을 활용해 브랜드에 맞게 디자인을 꾸며 보세요.

![웹사이트 빌더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042993818/original/cSMywtXZgOfxm3YOyqXyqzTMpt6ABNB9SA.png?1741632258)

### 1단계: 웹사이트 페이지와 퍼널을 하이퍼클래스에서 다시 만들기

- 사이트 빌더 열기: 하이퍼클래스에서 **사이트 > 퍼널 및 웹사이트**로 이동해 시작하세요.
- 템플릿 라이브러리 사용: Kajabi 페이지와 가장 비슷한 템플릿을 찾아 고르세요. 설정이 빨라지고 디자인도 일관되게 유지돼요. [템플릿 라이브러리에 대해 더 알아보기](../10-마케팅/template-library-overview-setup.md)
- 페이지별로 만들기: 홈페이지, 상품 페이지, 랜딩 페이지, 문의 페이지 등 Kajabi의 주요 페이지를 다시 만드세요. 미리 만들어진 블록을 활용하면 히어로 배너, 후기, 문의 폼 같은 섹션을 쉽게 구성할 수 있어요.

### 2단계: 페이지 저장, 초안 관리, 게시

- 페이지나 퍼널을 만드는 동안 **저장**으로 작업을 저장하고, **미리보기**로 변경 내용을 확인하세요. 준비가 되면 **게시**하세요. 그러면 원하는 때에 변경 사항이 반영돼요. 자세한 내용은 [페이지 저장 및 게시](../06-사이트/기타/save-draft-and-publish-funnels-and-websites.md)를 참고하세요.

### 3단계: DNS 레코드 설정

- A 레코드 추가: 루트 도메인이나 서브도메인에는 `162.159.140.166`을 사용하세요.

  - 예시: yoursitename.com

    {% hint style="info" %}
    Cloudflare를 쓴다면 **Proxy Status**를 **DNS Only**로 설정하세요. 하이퍼클래스는 Cloudflare 프록시를 지원하지 않아요.
    {% endhint %}

- CNAME 레코드 추가: 서브도메인에는 도메인 등록 업체(예: GoDaddy, Cloudflare)에서 `sites.ludicrous.cloud`를 사용하세요.

  - 예시: sometext.yoursitename.com

### 4단계: 도메인을 하이퍼클래스에 추가

1. **설정 > 도메인**으로 이동한 뒤 **+ 도메인 추가**를 클릭하세요.
2. 도메인(예: `mydomain.com`) 또는 서브도메인(예: `offer.mydomain.com`)을 입력하고 **수동으로 기록**을 선택하세요.
3. 루트 도메인이라면 **www redirect**(www 리디렉션)를 켜서 트래픽이 메인 도메인으로 가도록 하세요.

### 5단계: 도메인을 퍼널 또는 웹사이트에 연결

1. DNS 인증이 끝나면 도메인에 연결할 퍼널이나 웹사이트를 선택하세요.
2. 도메인의 기본 랜딩 페이지(예: 홈페이지)를 고르세요.
3. **Link Domain**(도메인 연결)을 클릭하세요. 시스템이 SSL 인증서를 자동으로 추가하는데, 처리에 몇 분 걸릴 수 있어요.

```
도메인 연결에 대한 자세한 내용은 하이퍼클래스 도메인 설정 안내서를 참고하세요.
```

- 하이퍼클래스 교육: 팀원에게 하이퍼클래스의 CRM, 코스 관리, 자동화 도구 사용법을 교육하세요.
- 지원 자료 활용: 팀원들이 꾸준히 배울 수 있도록 하이퍼클래스의 지원 자료를 활용하라고 권하세요.

- 지속적인 개선: 비즈니스 목표에 맞는지 하이퍼클래스 설정을 주기적으로 검토하고 다듬으세요.

## Kajabi 구독 해지

### 1단계: 전환 기간

- 병행 운영: 전환 기간에는 Kajabi와 하이퍼클래스를 함께 운영해 보세요. 중요한 업무를 놓치지 않을 수 있어요.
- 단계적 축소: 하이퍼클래스가 완전히 운영 상태가 되면 Kajabi 의존도를 점차 줄이세요.

### 2단계: Kajabi 구독 해지

- 최종 데이터 백업: Kajabi 구독을 해지하기 전에 모든 데이터가 안전하게 백업됐는지 확인하세요.
- 공식 해지: Kajabi의 절차에 따라 구독을 해지하고 서비스를 종료하세요.

### 3단계: 마이그레이션 후 검토

- 성과 검토: 마이그레이션이 잘 됐는지 평가하고, 배운 점이 있다면 기록해 두세요.
- 지속적인 모니터링: 마이그레이션 후에도 문제가 없는지 계속 살펴보세요.

## 자주 묻는 질문

### 하이퍼클래스 코스의 드립 설정이 무엇인가요?
드립 설정을 쓰면 강의나 코스 콘텐츠가 멤버에게 공개되는 시점을 시간에 따라 예약할 수 있어요.

### 드립 값을 0으로 설정할 수 있나요?
아니요. `0`처럼 올바르지 않은 드립 값은 일정 문제를 막기 위해 이제 차단돼요.

### 드립 설정이 저장되지 않는 이유가 뭔가요?
하이퍼클래스는 이제 저장하기 전에 드립 값을 검증해요. 올바르지 않은 일정 값은 자동으로 거부돼요.

### 이번 업데이트가 기존 드립 일정에도 영향을 주나요?
아니요. 이미 설정된 올바른 드립 일정은 그대로 정상 작동해요.

### 멤버십과 코스 모두에서 드립 일정을 쓸 수 있나요?
네. 하이퍼클래스의 코스와 멤버십 상품에서 드립 일정을 지원해요.
