# Squarespace에서 하이퍼클래스로 옮기기 (마이그레이션 가이드)

Squarespace의 웹사이트, 콘텐츠, 고객 데이터를 하이퍼클래스로 옮기는 과정을 단계별로 안내해요. 하이퍼클래스의 CRM, 마케팅 자동화, 웹사이트 빌더 기능을 충분히 활용하면서 무리 없이 전환하고 싶을 때 참고하세요.

---

## 마이그레이션 준비

### 1단계: 현재 Squarespace 구성 검토하기

- 기존 콘텐츠 목록 만들기: 페이지, 블로그 게시글, 이미지, 동영상, 상품, 폼 등 Squarespace 사이트의 모든 콘텐츠를 정리해요.
- 사용 중인 기능 분석하기: 이커머스, 일정 예약, SEO 설정 등 실제로 쓰고 있는 Squarespace 기능을 파악해요. 그리고 하이퍼클래스에서 어떤 기능으로 대체할지 계획해요.

### 2단계: 마이그레이션 목표 정하기

- 분명한 목표 세우기: 마케팅 자동화 개선, 고급 CRM 기능, 고객 관리 통합 등 하이퍼클래스로 옮기려는 이유를 정해요.
- 우선순위 정하기: 웹사이트 기능, 이메일 캠페인, 고객 세분화처럼 하이퍼클래스에서 그대로 구현하거나 더 낫게 만들어야 할 핵심 기능을 골라요.

### 3단계: 데이터 백업 및 내보내기

- Squarespace에서 콘텐츠 내보내기: Squarespace의 내보내기 기능으로 웹사이트 콘텐츠, 페이지, 게시글, 이미지 등 필요한 데이터를 모두 저장해요.
- 이커머스 데이터: 상품 정보, 주문, 고객 정보를 내보내요.
- 연락처와 구독자: 연락처 목록과 이메일 구독자 목록을 내보내요.
- 백업 문서 보관하기: 내보낸 파일은 마이그레이션 중 데이터가 사라지지 않도록 안전하게 보관해요.

## 웹사이트 콘텐츠 옮기기

### 1단계: 웹사이트 콘텐츠 내보내고 가져오기

- Squarespace에서 웹사이트 데이터 내보내기: Squarespace 관리 화면에서 내보내기 도구를 사용해 사이트 콘텐츠를 내려받아요.
- 하이퍼클래스에서 웹사이트 다시 만들기: 하이퍼클래스의 웹사이트 빌더로 새 사이트를 만들고 콘텐츠를 가져오거나 업로드해요. 드래그 앤 드롭으로 텍스트, 이미지, 동영상을 원하는 레이아웃에 배치할 수 있어요.
- 템플릿: Squarespace 디자인과 가장 비슷한 템플릿을 고르거나 직접 수정해요.
- 콘텐츠 블록: 텍스트, 이미지, 임베드 동영상 등 하이퍼클래스의 콘텐츠 블록으로 페이지와 블로그 게시글을 다시 만들어요. 관련 문서: [링크](../../06-사이트/기타/how-to-use-prebuilt-elements-in-your-funnels-and-websites.md)

### 2단계: 이커머스 설정 다시 만들기

- Squarespace에서 상품·주문 데이터 내보내기: 내보내기 기능으로 상품 카탈로그와 주문 내역을 CSV 형식으로 내려받아요.
- 하이퍼클래스에서 이커머스 설정하기: 하이퍼클래스의 **E-commerce**(이커머스) 섹션으로 이동해 이미지, 설명, 가격을 포함한 상품 데이터를 직접 입력하거나 가져와요.
  [하이퍼클래스에서 이커머스 스토어를 설정하는 방법 자세히 보기](../../37-이커머스-스토어/E-Commerce-Store/how-to-set-up-an-e-commerce-online-store-websites.md)
- 결제 연동: Squarespace에서 쓰던 것과 마찬가지로 Stripe, PayPal 같은 결제 게이트웨이를 연결해요.
- 배송 및 **세금 설정**: 이전 Squarespace 설정을 기준으로 배송 옵션과 세금 계산을 구성해요.

### 3단계: 연락처와 구독자 목록 가져오기

- Squarespace에서 연락처 내보내기: Squarespace의 연락처 패널에서 모든 연락처와 구독자를 CSV 파일로 내보내요.
- 하이퍼클래스로 연락처 가져오기: 하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동해 CSV 파일을 업로드해요. 가져오는 중에 이름, 이메일, 태그 같은 필드가 올바르게 매핑되었는지 확인하세요.
  CSV 파일로 연락처를 일괄 가져오는 방법도 함께 확인해 보세요.

## 기능 다시 만들고 개선하기

### 1단계: 웹사이트 디자인 및 사용자 지정

- 페이지 다시 만들기: 하이퍼클래스에서 각 페이지에 필요한 섹션, 콘텐츠 블록, 폼을 추가해 다시 만들어요. 하이퍼클래스의 디자인 옵션으로 겉모습을 꾸며서 기존 Squarespace 디자인과 같거나 더 낫게 맞춰요.
- SEO 최적화: Squarespace에 있던 페이지 제목, 설명 등 **SEO 메타데이터**를 하이퍼클래스에 추가해요. 하이퍼클래스의 SEO 도구로 검색 엔진에 맞게 콘텐츠를 최적화할 수도 있어요.

### 2단계: 이메일 캠페인 다시 만들고 자동화하기

- Squarespace에서 이메일 캠페인 데이터 내보내기: Squarespace에서 내려받을 수 있는 템플릿, 목록, 캠페인 리포트를 모두 내려받아요.
- 하이퍼클래스에서 이메일 캠페인 만들기: 하이퍼클래스에서 **마케팅 > 이메일 캠페인**으로 이동해 새 이메일 캠페인을 만들어요. 템플릿을 업로드하고, 이메일 트리거와 후속 이메일을 포함한 자동 워크플로우를 설정해요.

### 3단계: 일정 예약과 캘린더 연동 설정하기

- 일정 데이터 옮기기: Squarespace의 일정 예약 기능을 썼다면 예약 데이터와 고객 일정을 내보내 두세요.
- 하이퍼클래스에서 일정 예약 설정하기: 하이퍼클래스의 캘린더 연동으로 예약 유형과 예약 페이지를 설정해요. 후속 안내와 리마인더는 하이퍼클래스 워크플로우로 자동화해요.

## 테스트 및 검증

### 1단계: 웹사이트 기능 확인하기

- 웹사이트 페이지 테스트하기: 새 하이퍼클래스 사이트를 둘러보며 각 페이지의 콘텐츠 배치, 링크 작동 여부, 반응형 디자인을 확인해요.
- SEO 설정 확인하기: Google Search Console 같은 도구로 새 사이트가 제대로 색인되는지, SEO 메타데이터가 올바르게 옮겨졌는지 확인해요.

### 2단계: 이커머스와 **결제 처리** 확인하기

- 상품 목록과 구매 테스트하기: 테스트 구매를 해 보며 상품이 올바르게 표시되는지, 결제 과정에 문제가 없는지 확인해요.
- 결제 게이트웨이 확인하기: 결제 에이전시가 올바르게 설정되었는지 확인하고, 테스트 결제가 정상적으로 처리되는지 점검해요.

### 3단계: 이메일 캠페인과 자동화 테스트하기

- 테스트 이메일 보내기: 테스트 캠페인을 실행해 이메일이 의도한 대로 도착하는지, 서식과 내용이 올바른지 확인해요.
- 자동화 트리거 확인하기: 환영 이메일, 장바구니 이탈 알림 같은 자동 워크플로우가 의도한 대로 작동하는지 확인해요.

## 팀 교육 및 전환

### 1단계: 팀 교육하기

- 하이퍼클래스 교육 진행하기: 팀원에게 하이퍼클래스 화면 사용법을 교육해요. 웹사이트 관리, 이메일 캠페인, CRM 기능을 중심으로 진행해요.
- 문서 배포하기: 하이퍼클래스에서 쓰는 업무 방식에 맞춘 사용 가이드와 SOP를 팀원에게 나눠 줘요.

### 2단계: 모니터링하고 개선하기

- 지속적으로 모니터링하기: 새 시스템의 성능을 주기적으로 살펴봐요. 특히 마이그레이션 직후 몇 주 동안은 문제를 일찍 발견할 수 있도록 꼼꼼히 확인해요.
- 워크플로우 최적화하기: 팀원 의견과 운영상 필요에 따라 워크플로우와 웹사이트 설정을 조정해요.

## Squarespace 종료하기

### 1단계: 전환 기간 두기

- 두 시스템 함께 운영하기: 모든 데이터가 올바르게 옮겨졌는지, 사용자들이 새 플랫폼에 익숙해졌는지 확인할 수 있도록 Squarespace와 하이퍼클래스를 잠시 함께 켜 두는 방법도 고려해 보세요.
- 단계적으로 줄여 가기: Squarespace에 대한 의존도를 점차 줄이고, 모든 사용자와 고객이 하이퍼클래스로 자연스럽게 넘어오도록 해요.

### 2단계: 최종 백업 및 해지

- 최종 백업: Squarespace 계정을 해지하기 전에 필요한 데이터를 모두 백업했는지, 안전하게 보관되어 있는지 확인해요.
- Squarespace 구독 해지: Squarespace의 계정 해지 및 서비스 종료 절차를 따라요.

### 3단계: 마이그레이션 후 점검

- 점검 진행하기: 마이그레이션이 얼마나 잘 되었는지 평가해요. 겪은 어려움과 해결 방법은 나중에 참고할 수 있도록 기록해 두세요.
- 지속적으로 모니터링하기: 하이퍼클래스를 계속 살펴보면서 필요한 부분을 조정하고 개선해요.
