# Typeform에서 하이퍼클래스로 옮기기 (마이그레이션 가이드)

Typeform에서 쓰던 폼, 설문, 관련 데이터를 하이퍼클래스로 옮기는 순서를 안내해요. CRM 연동, 마케팅 자동화, 고급 분석 같은 하이퍼클래스 기능을 충분히 활용하면서 자연스럽게 넘어올 수 있어요.

{% hint style="warning" %}
Typeform에서 하이퍼클래스로 옮길 때는 아래 항목을 모두 옮겼는지 꼭 확인하세요.

1. 폼
2. 연락처
3. 자동화
4. 도메인 & QR 코드
5. 리포트
{% endhint %}

---

## 폼 옮기기

Typeform에서는 폼, 설문, 투표로 정보를 모을 수 있고, 모든 응답을 CSV 파일로 내려받을 수 있어요.

### 1단계: Typeform의 폼 확인하기

1. Typeform에 로그인해서 워크스페이스에 들어간 뒤, 모든 폼과 설문을 확인하세요.
2. 각 폼을 클릭하면 폼 미리보기 화면 왼쪽에서 폼의 질문을 볼 수 있어요.
3. Typeform에 설정된 자동화 순서를 기록해 두세요. 폼 로직, 계산, 이메일 검증, 알림이 모두 해당돼요.

### 2단계: 하이퍼클래스에서 질문 다시 만들기

1. 하이퍼클래스에 로그인한 뒤 **연락처 > 설정 > 커스텀 필드**로 이동하세요.
2. 모든 폼 질문에 맞는 커스텀 값 폴더를 추가하세요. 질문은 커스텀 필드로 직접 추가하고, 데이터 유형을 원래 질문과 맞춰 주세요.

### 3단계: 하이퍼클래스에서 폼과 설문 다시 만들기

1. 폼과 설문을 하나씩 만들고, 각각에 해당하는 질문을 추가하세요.
2. 하이퍼클래스의 사용자 지정 옵션으로 원래 Typeform의 디자인과 브랜딩을 맞춰 주세요.
3. Typeform에 있던 자동화 순서(로직, 계산, 이메일/전화번호 검증, 알림)를 똑같이 만들어 주세요. 일부 설정은 **폼 빌더** 안에서 만들 수 있어요. 나머지 자동화는 자동화 단계에서 만들어요.
4. 폼을 직접 테스트해서 제대로 작동하는지 확인하세요.

## 연락처 옮기기

하이퍼클래스와 달리 Typeform은 폼을 제출할 때 이메일이나 전화번호를 꼭 받지 않아요. 그래서 전화번호와 이메일 필드가 있는 응답만 내보내서 하이퍼클래스 연락처로 옮겨야 해요.

### 1단계: Typeform에서 폼 응답 내보내기

1. Typeform의 **My Workspace**(내 워크스페이스)에서 폼을 열고 **Results**(결과)로 이동한 뒤 **Responses**(응답)를 선택하세요.
2. 체크박스로 응답을 모두 선택하세요.
3. 오른쪽 위의 다운로드 아이콘을 클릭하면 모든 폼 응답을 CSV 형식으로 내려받을 수 있어요. 백업용으로도 보관하세요.

![Typeform에서 응답을 CSV로 내려받는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032429251/original/zreXLrvclihicln5nBGH93xAF--3X3LFcQ.png?1725645847)

### 2단계: 하이퍼클래스로 가져올 CSV 준비하기

1. CSV의 모든 날짜 필드를 YYYY-MM-DD 형식으로 맞추세요. 하이퍼클래스와 호환되려면 꼭 필요해요.
2. 특수 문자와 악센트 문자가 깨지지 않도록 CSV 파일을 UTF-8 인코딩으로 저장하세요.
3. 파일에서 줄바꿈, 이모지, 불필요한 특수 문자를 지우세요. 가져오기 오류를 막는 데 도움이 돼요.
4. 하이퍼클래스에 로그인한 뒤 **연락처 > 설정 > 커스텀 필드**로 이동하세요. Typeform에 저장했던 방식과 비슷하게 연락처 데이터를 저장할 커스텀 필드를 추가하세요.

### 3단계: 하이퍼클래스로 연락처 가져오기

1. 하이퍼클래스에 로그인한 뒤 왼쪽 메뉴에서 **연락처**로 이동하세요.
2. **연락처 가져오기** 버튼을 클릭하세요.
3. **CSV 파일 업로드**에서 준비한 CSV 파일을 선택해 업로드하세요.
4. **필드 매핑** 화면이 나오면 CSV 파일의 필드를 하이퍼클래스의 해당 필드에 연결하세요. 예를 들어 CSV의 "First Name" 열은 하이퍼클래스의 **이름** 필드에 연결해요.
   - 필드 매핑 팁: 필수 필드가 모두 올바르게 연결됐는지 확인하세요. CSV의 필드에 맞는 하이퍼클래스 필드가 없다면, 진행하기 전에 하이퍼클래스에서 커스텀 필드를 먼저 만들어야 할 수 있어요.
5. 가져오는 중에 연락처를 특정 목록에 넣고 태그를 지정할 수 있어요. "Typeform Import"처럼 연락처의 출처를 알려 주는 태그를 붙여 두면 좋아요.
6. 모든 필드를 연결하고 태그와 목록을 설정했다면 **가져오기 시작**을 클릭하세요. 하이퍼클래스가 가져오기를 처리하고 연락처를 계정에 추가해요.

### 4단계: 가져온 데이터 검토하기

1. 연락처와 폼 제출 데이터를 포함해 하이퍼클래스로 가져온 모든 데이터가 정확하고 빠짐없는지 확인하세요.
2. 하이퍼클래스의 데이터를 원래 Typeform 데이터와 비교해서 차이가 없는지 확인하세요.

## 자동화와 후속 조치 옮기기

Typeform에서는 앱 안에서 자동화를 만들 수도 있고, Slack, Zapier, 웹훅을 써서 만들 수도 있어요.

### 1단계: Typeform에 있는 자동화 확인하기

1. Typeform에서 톱니바퀴 아이콘을 클릭해 설정에 들어간 뒤, 아직 옮기지 않은 자동화 순서를 확인하세요. **폼 빌더**에서 만들 수 없는 것은 하이퍼클래스 워크플로우에서 만들 수 있어요. 후속 메시지, 연동, 웹훅이 여기에 해당해요.

### 2단계: 하이퍼클래스에서 자동화 다시 만들기

1. 하이퍼클래스 자동화 워크플로우로, **폼 빌더** 안에서 만들 수 없는 비슷한 순서를 설정하세요. 후속 이메일을 보내거나 폼 응답에 따라 CRM 작업을 실행하는 것이 예예요.
2. 폼을 제출했을 때 각 자동화가 제대로 실행되고 기대한 대로 작동하는지 테스트하세요.

## 폼 도메인과 QR 코드 옮기기

고객이 하이퍼클래스 폼에서도 같은 도메인을 계속 쓰고, 리드가 이전의 맞춤 링크로 접속할 수 있게 하려면 도메인을 옮겨야 해요. 폼은 맞춤 QR 코드로도 공유할 수 있어요. Typeform에서 쓰던 폼 QR 코드는 하이퍼클래스에서 다시 만들어 주세요.

### 1단계: Typeform 도메인 기록하고 삭제하기

1. 왼쪽 위의 조직 아바타를 클릭하고 **Admin settings**(관리자 설정)로 이동해서 Typeform의 사용자 지정 도메인을 기록해 두세요.
2. **Admin settings** 페이지에서 **Change URL**(URL 변경)을 클릭하세요.
3. **Custom domain**(사용자 지정 도메인) 라디오 버튼을 선택하고 **Confirm**(확인)을 클릭해서 Typeform의 사용자 지정 도메인을 삭제하세요.

### 2단계: 하이퍼클래스에서 301 리다이렉트 추가하기

1. **사이트 > URL 리다이렉트**로 이동해 리다이렉트를 설정하세요.
2. 여러 플랫폼과 기기에서 각 폼에 잘 접속되는지 테스트하세요. 공유와 접근이 매끄러워야 사용자 경험이 좋아요.

### 3단계: 하이퍼클래스에서 API 도메인 추가하기

1. **설정 > 비즈니스 프로필**로 이동해 도메인으로 폼의 브랜딩을 바꾸세요.

### 4단계: Typeform에서 QR 코드를 쓰는 폼 기록하기

1. Typeform에 로그인하세요.
2. 폼을 열고 **Share**(공유)를 클릭하면 공유 패널이 열려요. 마지막 아이콘이 QR 코드이고, 이 QR 코드로도 폼을 공유할 수 있어요.

### 5단계: 하이퍼클래스에서 QR 코드 추가하기

1. **사이트 > QR 코드 > QR 코드 생성**으로 이동하세요.
2. **이름**을 입력하고 **QR 유형**을 **웹사이트**로 선택한 뒤 **다음**을 클릭하세요.
3. 하이퍼클래스 폼 URL을 입력하세요. 사용자를 새 링크로 보내고 싶다면 이 웹사이트 URL은 나중에 바꿀 수 있어요.
4. 테스트하고 공유하세요. QR 코드 분석은 **QR 코드 > 분석**에서 확인할 수 있어요.

## 데이터 내보내고 새로 만들기

유료 Typeform 구독을 해지한 사용자는 해지가 적용된 뒤에는 리포트를 보거나 만들 수 없어요. 이 리포트는 집계된 폼 응답만 지원해요. **Contact Info**(연락처 정보)와 주소 질문 유형은 현재 지원하지 않아요.

### 1단계: Typeform에서 리포트 내보내기

1. 워크스페이스에서 폼을 열고 **Results**(결과) 패널을 클릭한 뒤 **Summary**(요약)를 클릭하세요.
2. **Generate a report**(리포트 생성)를 클릭하세요.
   - 새 화면이 열리고, 여기서 리포트를 보고 공유할 수 있어요.
   - 왼쪽의 토글을 클릭하면 주관식 질문의 답변을 리포트에 보여 줄 수 있어요.
   - 주관식 질문을 모두 표시하면 리포트에 포함돼요.

![Typeform 리포트 생성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032429288/original/mJmq5RKto93YpnrqyyaPXuF_-eNXKrtaqA.png?1725645930)

### 2단계: 리포트를 PDF로 저장하기

1. **Print**(인쇄) 버튼을 클릭해 리포트를 인쇄하세요. 브라우저에 새 탭이 열리고 **Save as PDF**(PDF로 저장) 옵션이 나타나요.
2. 저장한 PDF는 클라우드 스토리지에 올려 안전하게 보관하세요.

### 3단계: 폼 제출과 대시보드 위젯 리포팅

- 폼 응답은 어디에서 볼 수 있나요?
- 커스텀 위젯 (Pro 플랜 사용자만 사용할 수 있어요)
