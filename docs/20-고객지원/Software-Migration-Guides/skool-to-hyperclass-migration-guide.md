# Skool에서 하이퍼클래스로 이전하기 (마이그레이션 가이드)

온라인 커뮤니티, 코스, 관련 콘텐츠를 Skool에서 하이퍼클래스로 옮기는 전체 과정을 안내해요. 하이퍼클래스의 CRM, 마케팅 자동화, 커뮤니티 도구를 활용해 멤버 참여를 높이고 운영을 간소화하면서 끊김 없이 옮겨 가는 것이 목표예요.

## Skool에서 하이퍼클래스로 이전한다는 것

이전은 커뮤니티 멤버, 코스, 콘텐츠, 이벤트와 관련 운영 방식을 하이퍼클래스로 옮기는 작업이에요. 잘 마치면 중요한 멤버·코스 데이터를 그대로 지키면서, CRM, 자동화, 커뮤니티, 마케팅 도구를 한 플랫폼에서 쓸 수 있어요.

계획, 이전, 테스트, 검증을 꼼꼼히 하면 팀과 커뮤니티 멤버가 겪는 불편을 줄일 수 있어요.

---

## 이전 준비

### 1단계: 현재 Skool 설정 검토하기

- 핵심 자산 파악: Skool에서 쓰고 있는 커뮤니티 멤버, 코스, 콘텐츠, 이벤트, 자동화 워크플로우를 모두 목록으로 정리하세요.
- 데이터 규모 확인: 코스, 멤버, 커뮤니티 게시글의 수 등 옮길 데이터의 크기와 복잡도를 파악하세요.

### 2단계: 이전 목표 정하기

- 목표 구체화: 하이퍼클래스로 옮기려는 주된 이유를 정하세요. 예를 들어 더 나은 CRM 연동, 고급 마케팅 자동화, 하나로 통합된 플랫폼 등이 있어요.
- 우선순위 정하기: 커뮤니티 참여, 코스 콘텐츠, 멤버 관리를 중심으로 꼭 옮겨야 하는 요소를 정하세요.

### 3단계: 백업 준비하기

- Skool 데이터 내보내기: 멤버 목록, 코스, 커뮤니티 콘텐츠 등 필요한 데이터를 CSV 파일이나 다른 가능한 형식으로 Skool에서 내보내세요.
- 백업 자료 보관: 이전을 시작하기 전에 내보낸 파일과 관련 문서를 안전하게 보관해 데이터를 지키세요.

## Skool Importer로 더 간편하게 이전하기

Skool에서 옮겨 온다면 하이퍼클래스가 제공하는 전용 도구인 **Skool Importer**(Skool 가져오기 도구)를 쓸 수 있어요. 커뮤니티 멤버와 콘텐츠를 더 효율적으로 가져올 수 있어요.

이 도구는 이제 여러 그룹을 한꺼번에 옮기는 과정이 더 매끄럽고, 가져온 콘텐츠의 순서도 더 정확하게 유지해요.

---

## 데이터 이전

### 1단계: Skool에서 데이터 내보내기

- 멤버 내보내기: Skool의 **Members** 섹션으로 이동해 내보내기 기능으로 멤버 목록을 CSV 파일로 내려받으세요. 이름, 이메일, 커스텀 필드가 포함돼요.
- 코스 내보내기: 영상 링크, 설명, 자료를 포함한 코스 콘텐츠를 내려받으세요. 하이퍼클래스에 다시 올릴 수 있도록 모든 코스 자료를 저장해 두세요.
- 커뮤니티 콘텐츠 내보내기: 하이퍼클래스에서 다시 만들어야 할 중요한 커뮤니티 게시글, 토론, 고정 콘텐츠를 직접 복사하거나 내보내세요.

### 2단계: 하이퍼클래스로 데이터 가져오기

- 멤버 가져오기: 하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동해 Skool에서 내보낸 CSV 파일을 올리세요. 가져오는 동안 모든 필드가 올바르게 매핑되었는지 확인하세요.
- 코스 다시 만들기: 하이퍼클래스의 **코스** 섹션으로 이동해, 앞서 내보낸 영상·설명·자료를 올려 새 코스를 만드세요.
- 커뮤니티 콘텐츠 다시 만들기: 하이퍼클래스의 커뮤니티 도구로 중요한 토론, 게시글 등의 콘텐츠를 다시 만드세요. 꼭 알려야 할 게시글이나 공지는 **Featured Posts**(주요 게시글) 기능으로 고정하세요.

## 커뮤니티와 코스 다시 만들기

### 1단계: 하이퍼클래스에서 커뮤니티 채널 설정하기

- 채널 만들기: Skool에 있던 커뮤니티나 토론 그룹마다 하이퍼클래스에서 새 채널을 만드세요. 공개 범위, 접근 수준 등 채널 설정을 상황에 맞게 조정하세요.
- 멤버 초대하기: 이메일이나 고유 초대 링크로 모든 커뮤니티 멤버에게 초대장을 보내세요. 하이퍼클래스의 **연락처 > Send Email**(이메일 보내기) 기능을 쓰면 더 편해요.

### 2단계: 코스 다시 만들고 정리하기

- 코스 구조 구성: 하이퍼클래스의 코스 만들기 도구로, Skool에서 정리했던 방식과 비슷하게 코스를 구성하세요. 필요하면 섹션과 모듈을 만들고 관련 콘텐츠를 모두 올리세요.
- 코스 액세스 지정: 코스마다 접근 권한을 설정하세요. Skool에서 설정했던 접근 제어와 같이, 해당 멤버만 특정 콘텐츠를 볼 수 있게 해요.

### 3단계: 멤버 역할과 권한 관리하기

- 역할 지정: 하이퍼클래스에서 멤버에게 관리자, 모더레이터, 기여자 같은 역할을 지정해 커뮤니티의 위계와 권한을 그대로 유지하세요.
- 멤버 권한 설정: 지정한 역할에 따라 특정 채널, 코스, 커뮤니티 기능에 접근할 수 있도록 멤버 권한을 설정하세요.

## 이벤트와 자동화 다시 만들기

### 1단계: 하이퍼클래스에서 이벤트 다시 만들기

- 이벤트 캘린더 설정: 하이퍼클래스의 캘린더 기능으로 Skool에 잡아 둔 이벤트를 다시 만드세요. 반복 이벤트도 설정하고, 해당 멤버가 모두 초대되었는지 확인하세요.
- 이벤트 알림 설정: 하이퍼클래스의 커뮤니케이션 도구를 활용해 이벤트 이메일·SMS 리마인더를 자동으로 보내도록 설정하세요. 멤버 참여율을 높이는 데 도움이 돼요.

### 2단계: 자동화 워크플로우 다시 만들기

- 자동화 흐름 만들기: 하이퍼클래스의 **자동화 > 워크플로우**로 이동해 Skool에서 쓰던 자동화 과정을 다시 만드세요. 환영 메시지, 코스 수료 알림, 이벤트 리마인더 등이 있어요.
- 자동화 테스트: 새로 만든 자동화 워크플로우를 실행해 보고 제대로 작동하는지 확인하세요. 필요하면 수정하세요.

## 테스트와 검증

### 1단계: 커뮤니티와 코스 기능 테스트하기

- 전체 흐름 테스트: 채널 참여, 코스 접근, 토론 참여 같은 멤버의 행동을 직접 해 보면서 모든 기능이 의도대로 작동하는지 확인하세요.
- 데이터 정합성 검증: 멤버 목록, 코스 콘텐츠, 커뮤니티 게시글 등 가져온 데이터를 원본과 대조해 정확하고 접근 가능한지 확인하세요.

### 2단계: 이벤트와 자동화 설정 검증하기

- 테스트 시나리오 실행: 이벤트와 자동화 워크플로우를 하나씩 테스트해 트리거와 액션이 제대로 작동하는지 확인하세요. 모든 멤버가 불편 없이 이용할 수 있어야 해요.
- 커뮤니케이션 채널 확인: 이메일과 SMS를 포함한 모든 커뮤니케이션 액션이 워크플로우 안에서 제대로 실행되는지 확인하세요.

## 팀 교육과 전환

### 1단계: 팀원 교육하기

- 하이퍼클래스 교육: 팀원이 하이퍼클래스 화면에 익숙해지도록 교육 세션을 진행하세요. 커뮤니티 관리, 코스 설정, 자동화 도구를 중점적으로 다루세요.
- 문서 제공: 전환 기간에 팀원이 참고할 수 있도록 하이퍼클래스 기능에 맞춘 사용자 가이드와 SOP를 나눠 주세요.

### 2단계: 모니터링하고 최적화하기

- 시스템 성능 모니터링: 이전 후 커뮤니티 참여도, 코스 수료율, 자동화 효과를 정기적으로 점검하세요.
- 워크플로우 최적화: 팀의 피드백과 운영 요구에 맞춰 워크플로우와 커뮤니티 구조를 조정하세요.

## Skool 종료하기

### 1단계: 전환 기간 운영하기

- 두 시스템 병행 운영: 멤버와 관리자가 무리 없이 옮겨 갈 수 있도록 짧은 기간 동안 Skool과 하이퍼클래스를 함께 운영해 보세요.
- Skool 단계적 축소: 하이퍼클래스에 대한 확신이 커지고 모든 멤버가 옮겨 오면 Skool에 대한 의존을 차츰 줄이세요.

### 2단계: Skool 구독 해지하기

- 최종 백업: Skool 구독을 해지하기 전에 필요한 데이터를 모두 백업했는지 확인하세요.
- 공식 해지: Skool의 해지 절차에 따라 구독과 관련 서비스를 종료하세요.

### 3단계: 이전 후 검토하기

- 성과 검토: 이전이 성공적이었는지 평가하세요. 겪었던 어려움과 해결 방법은 나중에 참고할 수 있게 기록해 두세요.
- 지속적인 모니터링: 하이퍼클래스의 성능을 계속 살펴보면서 커뮤니티와 코스 관리를 최적화하도록 필요한 부분을 조정하세요.
