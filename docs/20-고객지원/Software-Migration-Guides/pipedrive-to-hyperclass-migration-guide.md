# Pipedrive에서 하이퍼클래스로 옮기기 (마이그레이션 가이드)

Pipedrive의 CRM 데이터, 자동화 워크플로우, 마케팅 활동을 하이퍼클래스로 옮기는 단계별 가이드예요. 기존 업무 방식과 데이터를 그대로 유지하면서 하이퍼클래스의 기능을 활용할 수 있도록 이전 과정을 안내해요.

## 이전 준비

### 1단계: Pipedrive 현재 설정 검토

- 핵심 자산 파악: Pipedrive에서 쓰고 있는 영업 파이프라인, 딜, 연락처, 자동화 시퀀스를 모두 문서로 정리해요.
- 데이터 규모 확인: 옮겨야 할 데이터(연락처 수, 딜 수, 커스텀 필드 수 등)의 크기와 복잡도를 살펴봐요.

### 2단계: 이전 목표 정하기

- 명확한 목표 설정: 하이퍼클래스로 옮기려는 주된 이유를 정해요. 예를 들면 고급 자동화, 통합 CRM, 비용 효율이 있어요.
- 기능 우선순위 정하기: CRM 데이터, 영업 파이프라인, 꼭 필요한 자동화처럼 중요한 요소부터 먼저 옮겨요.

### 3단계: 백업 준비

- Pipedrive 데이터 내보내기: CRM 데이터(연락처, 딜, 커스텀 필드 등)를 모두 CSV 또는 Excel 파일로 내보냈는지 확인해요.
- 백업 자료 보관: 이전을 시작하기 전에 내보낸 데이터 파일과 관련 문서를 안전하게 보관해요.

## 데이터 이전

### 1단계: Pipedrive에서 데이터 내보내기

- 연락처 내보내기:
  - Pipedrive에서 **Contacts > People**로 이동해요.
  - 내보내기 기능으로 연락처를 CSV 또는 Excel 파일로 내려받아요. 이름, 이메일 주소, 전화번호, 커스텀 필드 등 필요한 필드를 모두 포함해요.
- 딜 내보내기: **Deals**로 이동해 진행 중인 딜과 종료된 딜을 모두 내보내요. 딜 단계, 금액, 연결된 연락처가 포함되어 있는지 확인해요.
- 활동과 메모 내보내기: 연락처와 딜에 연결된 예정 활동, 메모, 파일을 모두 내보내요.

### 2단계: 하이퍼클래스로 데이터 가져오기

- 연락처 가져오기:
  - 하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동해 Pipedrive에서 내보낸 CSV 파일을 올려요.
  - 데이터가 정확히 들어오도록 필드를 알맞게 매핑해요.
- 딜 가져오기(기회):
  - **기회 관리**(Opportunities) **> 파이프라인**으로 이동해 하이퍼클래스에서 영업 파이프라인을 다시 만들어요.
  - CSV 파일에서 딜을 가져오고, 딜 단계와 금액을 새 파이프라인 구조에 맞게 매핑해요.
- 활동 다시 만들기: 예정된 활동을 직접 다시 만들거나 가져와요. 작업, 미팅, 후속 조치가 빠짐없이 옮겨졌는지 확인해요.

## 영업 파이프라인과 자동화 이전

### 1단계: 하이퍼클래스에서 영업 파이프라인 다시 만들기

- 파이프라인 설정: 하이퍼클래스에서 Pipedrive에서 쓰던 단계와 똑같은 영업 파이프라인을 만들어요. 모든 단계가 빠짐없이 들어갔는지 확인해요.
- 딜 옮기기: 새 하이퍼클래스 파이프라인에서 각 딜을 알맞은 단계에 배치해요. 그러면 영업 현황을 끊김 없이 이어서 추적할 수 있어요.

### 2단계: 하이퍼클래스에서 자동화 다시 만들기

- 트리거와 액션 설정:
  - **자동화 > 워크플로우**로 이동해 자동화 워크플로우를 다시 만들어요.
  - Pipedrive에서 쓰던 것과 비슷하게 트리거(예: 새 딜 생성, 단계 변경)와 그에 따른 액션(예: 이메일 보내기, 상태 업데이트)을 다시 설정해요.
- 커뮤니케이션 채널 연결: 하이퍼클래스에 통합된 커뮤니케이션 도구를 활용해 이메일과 SMS 자동화가 제대로 설정되었는지 확인해요.

## 문서와 계약 이전

### 1단계: 문서 템플릿 옮기기

- Pipedrive에서 템플릿 내보내기: Pipedrive의 SmartDocs 기능에서 쓰던 문서나 계약 템플릿을 내려받아요.
- 하이퍼클래스에서 가져와 다시 만들기: **문서 & 계약**으로 이동해 템플릿 편집기로 계약서, 제안서, 견적서 템플릿을 다시 만들어요.

### 2단계: 전자서명과 문서 추적 설정

- 전자서명 활성화: 하이퍼클래스의 문서 기능에서 계약서와 합의서에 전자서명을 쓸 수 있도록 설정해요.
- 문서 열람 추적: 문서를 열었는지, 확인했는지, 서명했는지 알 수 있도록 추적 기능을 설정해요. Pipedrive의 SmartDocs 기능과 비슷하게 쓸 수 있어요.

## 테스트와 검증

### 1단계: 영업 파이프라인 테스트

- 전체 과정 테스트: 하이퍼클래스에서 딜을 각 단계로 옮겨 가며 영업 과정을 직접 따라 해 보고, 모든 기능이 예상대로 동작하는지 확인해요.
- 데이터 정합성 검증: 가져온 데이터를 서로 대조해 연락처, 딜, 활동이 정확하게 옮겨졌는지 확인해요.

### 2단계: 자동화 워크플로우 검증

- 테스트 시나리오 실행: 하이퍼클래스의 각 자동화 워크플로우를 테스트해 트리거와 액션이 의도대로 동작하는지 확인해요.
- 커뮤니케이션 채널 확인: 워크플로우 안에서 이메일, SMS 등 커뮤니케이션 액션이 제대로 실행되는지 확인해요.

## 팀 교육과 전환

### 1단계: 팀원 교육

- 하이퍼클래스 교육: 팀원들이 하이퍼클래스의 화면과 기능에 익숙해지도록 교육 세션을 열어요.
- 문서 제공: 하이퍼클래스 기능에 맞춘 사용자 가이드와 SOP(표준 운영 절차)를 나눠 줘서 전환 기간 동안 팀원들을 도와요.

### 2단계: 모니터링과 최적화

- 시스템 성능 모니터링: 이전 후에도 영업 파이프라인과 자동화가 잘 동작하는지 정기적으로 확인해요.
- 워크플로우 최적화: 팀원들의 의견을 바탕으로 필요한 부분을 조정해 워크플로우를 개선하고 효율을 높여요.

## Pipedrive 사용 종료

### 1단계: 전환 기간

- 두 시스템 병행 운영: 원활하게 전환할 수 있도록 Pipedrive와 하이퍼클래스를 짧은 기간 동안 함께 운영하는 방법을 고려해 보세요.
- Pipedrive 단계적 축소: 하이퍼클래스에 대한 확신이 커질수록 Pipedrive에 대한 의존도를 조금씩 줄여요.

### 2단계: Pipedrive 구독 해지

- 최종 백업: Pipedrive 구독을 해지하기 전에 필요한 데이터를 모두 백업했는지 확인해요.
- 공식 해지: Pipedrive의 절차에 따라 구독을 해지하고 관련 서비스도 종료해요.

### 3단계: 이전 후 검토

- 성과 검토: 이전이 잘 되었는지 평가하고, 겪은 어려움과 해결 방법을 문서로 남겨요.
- 지속적인 모니터링: 하이퍼클래스의 성능을 계속 살펴보면서 필요할 때 조정해요.
