# HubSpot에서 하이퍼클래스로 옮기기: 마이그레이션 가이드

HubSpot에서 쓰던 업무 프로세스, 데이터, 워크플로우를 하이퍼클래스로 옮기는 전체 과정을 안내해요. 업무 중단은 줄이고 하이퍼클래스의 기능은 충분히 활용할 수 있도록 단계별로 따라 해 보세요.

## 이전 준비

### 1단계: 현재 HubSpot 설정 검토하기

- 주요 기능 파악: HubSpot에서 쓰는 기능을 모두 적어 보세요. 예를 들어 CRM, 자동화 워크플로우, 마케팅 캠페인, 통화, SMS 메시지, 이커머스 도구가 있어요.
- 기존 워크플로우 기록: 하이퍼클래스에 똑같이 만들어야 할 워크플로우, 파이프라인, 캠페인의 내용을 기록해 두세요.
- 데이터 양 확인: 옮길 데이터(연락처, 딜, 이메일 등)의 양을 가늠해 보고, 하이퍼클래스에 저장 공간과 자원이 충분한지 확인하세요.

### 2단계: 이전 목표 정하기

- 분명한 목표 설정: 이전으로 무엇을 얻고 싶은지 정하세요. 예를 들어 자동화 개선, CRM 연동 개선, 비용 절감이 있어요.
- 기능 우선순위 정하기: 먼저 옮겨야 할 기능과 데이터를 가장 중요한 순서대로 정하세요.

### 3단계: 백업 준비하기

- HubSpot 데이터 내보내기: 연락처, 회사, 딜, 티켓, 워크플로우 등 꼭 필요한 데이터를 모두 HubSpot에서 내보내세요.
- 데이터 백업: 이전을 시작하기 전에 모든 데이터를 안전하게 백업해 두세요.

## CRM 데이터 이전

### 1단계: HubSpot에서 데이터 내보내기

- 연락처와 회사: HubSpot에서 **Contacts > Contacts**와 **CRM > Companies**로 이동해 데이터를 CSV 파일로 내보내세요.
- 딜과 파이프라인: **Sales > Deals**로 이동해 파이프라인과 딜을 내보내세요.
- 마케팅 자산: 이메일, 랜딩 페이지, 폼, 워크플로우를 내보내세요.
- 상품과 인보이스: 상품 카탈로그와 HubSpot 결제 도구로 만든 인보이스를 내보내세요.

![HubSpot에서 데이터를 내보내는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033899440/original/m3IUOgQ8yxWgxcoJgIAdk0Edl4lQ5Sgb0A.png?1727808789)

### 2단계: 하이퍼클래스로 데이터 가져오기

- 연락처와 회사 가져오기:
  - 하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동하세요.
  - HubSpot에서 내보낸 CSV 파일을 올리고, 필드를 알맞게 연결하세요(예: 이름, 성, 이메일).
- 딜과 파이프라인 다시 만들기:
  - **기회 관리 > 파이프라인**에서 새 파이프라인을 만드세요.
  - 딜은 직접 다시 만들거나, 필요하면 가져오세요.
- 상품과 인보이스 옮기기:
  - **결제 > 상품**에서 상품 목록을 다시 만드세요.
  - 하이퍼클래스의 인보이스 도구로 인보이스와 결제 링크를 설정하세요.

![하이퍼클래스에서 데이터를 가져오는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033899495/original/0Sgz-rtXZ7Qi4ZLEbwUpJoOKGunTP5wWHg.jpg?1727808933)

## 워크플로우와 자동화 이전

### 1단계: 기존 HubSpot 워크플로우 검토하기

- 활성 워크플로우 목록 작성: HubSpot에서 사용 중인 워크플로우를 모두 찾아 트리거, 액션, 대기 시간까지 기록하세요.
- 워크플로우 복잡도 평가: 워크플로우마다 복잡한 정도를 살펴보고, 하이퍼클래스에서 어떻게 다시 만들지 정하세요.

### 2단계: 하이퍼클래스에서 워크플로우 다시 만들기

- 자동화 트리거 만들기:
  - 하이퍼클래스에서 **자동화 > 워크플로우**로 이동하세요.
  - HubSpot과 같은 역할의 트리거를 설정하세요(예: 폼 제출, 연락처 업데이트).
- 액션과 대기 시간 다시 만들기: 이메일 보내기, SMS 보내기, 연락처에 태그 지정하기, 딜 단계 업데이트하기 같은 액션을 다시 만드세요. 필요한 대기 시간과 조건 분기도 워크플로우 안에서 설정하세요.

### 3단계: 워크플로우 테스트하기

- 테스트 실행: 워크플로우를 활성화하기 전에 테스트를 돌려 의도한 대로 작동하는지 확인하세요.
- 설정 조정: 테스트 결과에 따라 필요한 부분을 고쳐 매끄럽게 작동하도록 하세요.

![워크플로우를 다시 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033899910/original/DGy6M7SKsTWy5vdlHzfKk2VU8WHd5Jt3IQ.png?1727809821)

## 마케팅 캠페인 이전

### 1단계: 이메일 캠페인 내보내고 다시 만들기

- 이메일 템플릿 내보내기: HubSpot 이메일 템플릿을 HTML 파일로 저장하세요.
- 하이퍼클래스에서 가져오거나 새로 만들기:
  - 하이퍼클래스에서 **마케팅 > 이메일 캠페인**으로 이동하세요.
  - 이메일 템플릿을 다시 만들거나 가져온 다음, 기존 디자인과 같아지도록 설정하세요.

### 2단계: 랜딩 페이지와 폼 다시 만들기

- 랜딩 페이지 내보내기: HubSpot 랜딩 페이지의 HTML을 내려받으세요.
- 하이퍼클래스에서 다시 만들기:
  - **사이트 > Landing Pages**(랜딩 페이지) 빌더로 랜딩 페이지를 다시 만드세요.
  - 모든 폼과 CTA 버튼이 하이퍼클래스 워크플로우에 연결되었는지 확인하세요.

### 3단계: 캠페인 설정하기

- 캠페인 구성: 하이퍼클래스에서 캠페인을 설정하고, 이메일, 랜딩 페이지, 폼 등 모든 자산이 연결되었는지 확인하세요. 필요하면 목표, 예산, 트래킹 설정도 지정하세요.

![마케팅 캠페인을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033899902/original/cCTdBmm3xtFftmGYrbFBd4_QSv4_bjPa8A.png?1727809808)

## 커뮤니케이션 도구 이전

### 1단계: 통화와 SMS 옮기기

- Twilio 연동: HubSpot에서 Twilio를 쓰고 있다면 하이퍼클래스에 연동해 통화와 SMS를 사용하세요. 하이퍼클래스에서 **설정 > 전화번호**로 이동해 Twilio 계정을 설정하면 돼요.
- 커뮤니케이션 워크플로우 설정: 하이퍼클래스의 **자동화 > 워크플로우**에서 SMS와 통화 자동화 워크플로우를 설정하세요. 고객과 주고받은 모든 소통이 제대로 기록되고 추적되는지 확인하세요.

### 2단계: 대화 인박스 설정하기

- 인박스 구성: 하이퍼클래스에서 **대화 > 인박스**로 이동하세요. 기본 인박스를 설정하고, 이메일, SMS, Facebook Messenger 같은 커뮤니케이션 채널을 연결하세요.
- 커뮤니케이션 채널 테스트: 모든 채널이 제대로 작동하는지, 메시지가 알맞은 인박스로 전달되는지 확인하세요.

![대화 인박스를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033899888/original/lpE6n1QaQ52WLVj6o3vZg2znRz4p1IfbCw.png?1727809774)

## 최종 점검과 교육

### 1단계: 데이터 최종 검증하기

- 데이터 교차 확인: 모든 데이터가 잘 옮겨졌는지, HubSpot과 하이퍼클래스의 기록이 서로 다르지 않은지 확인하세요.
- 워크플로우와 캠페인 검증: 모든 워크플로우, 자동화, 캠페인이 제대로 작동하는지 확인하세요.

### 2단계: 팀원 교육하기

- 하이퍼클래스 교육: 팀원에게 하이퍼클래스 사용법을 교육하세요. HubSpot과 달라진 점을 중심으로 알려 주세요.
- 하이퍼클래스 고객지원 활용: 팀원이 계속 배울 수 있도록 하이퍼클래스의 고객지원 자료와 커뮤니티 포럼을 활용하도록 권해 보세요.

### 3단계: 모니터링하고 개선하기

- 성과 모니터링: 하이퍼클래스에서 새로 구성한 환경의 성과를 지켜보고, 필요하면 조정하세요.
- 지속적인 개선: 워크플로우, 자동화, 캠페인이 비즈니스 목표에 맞는지 정기적으로 점검하고 다듬으세요.

## HubSpot 사용 종료

### 1단계: 전환 기간 두기

- 병행 운영: 전환하는 동안 HubSpot과 하이퍼클래스를 함께 운영해 보세요. 중요한 업무가 빠지지 않았는지 확인할 수 있어요.
- 단계적 축소: 하이퍼클래스가 완전히 자리 잡으면 HubSpot에 대한 의존도를 조금씩 줄이세요.

### 2단계: HubSpot 구독 해지하기

- 최종 데이터 백업: HubSpot 구독을 해지하기 전에 모든 데이터가 안전하게 백업되었는지 확인하세요.
- 공식 해지: HubSpot의 절차에 따라 구독을 해지하고 서비스를 종료하세요.

### 3단계: 이전 후 검토하기

- 성과 검토: 이전이 얼마나 성공적이었는지 평가하고, 배운 점을 기록해 두세요.
- 지속적인 모니터링: 이전한 뒤에도 문제가 생기지 않는지 시스템을 계속 살펴보세요.

## 자주 묻는 질문

### HubSpot에서 하이퍼클래스로 옮기려면 어떻게 준비하나요?
먼저 현재 HubSpot 설정을 검토하세요. 쓰고 있는 주요 기능(CRM, 자동화 워크플로우, 마케팅 캠페인, 통화, SMS 메시지, 이커머스 도구)을 파악하고, 기존 워크플로우와 파이프라인을 기록하고, 데이터 양을 확인해요. 그다음 분명한 이전 목표를 정하고, 먼저 옮길 기능의 우선순위를 정하세요. 이전을 시작하기 전에 필요한 데이터를 모두 HubSpot에서 내보내 안전하게 백업해 두세요.

### HubSpot 데이터는 어떻게 내보내나요?
연락처와 회사는 **Contacts > Contacts**와 **CRM > Companies**로 이동해 CSV 파일로 내보내세요. 딜과 파이프라인은 **Sales > Deals**로 이동해 파이프라인과 관련 딜을 내보내세요. 이메일, 랜딩 페이지, 폼, 워크플로우 같은 마케팅 자산도 내보내세요. 상품과 인보이스는 상품 카탈로그와 HubSpot 결제 도구로 만든 인보이스를 내보내면 돼요.

### 연락처와 회사를 하이퍼클래스로 가져오려면 어떻게 하나요?
하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동해 HubSpot에서 내보낸 CSV 파일을 올리고, 필드를 알맞게 연결하세요(예: 이름, 성, 이메일). 가져온 뒤에는 모든 연락처와 회사 데이터가 제대로 옮겨졌는지, 레코드 사이의 관계가 유지되는지 확인하세요.

### HubSpot 딜과 파이프라인을 하이퍼클래스에 다시 만들려면 어떻게 하나요?
**기회 관리 > 파이프라인**에서 HubSpot 파이프라인 구조와 같은 새 파이프라인을 만드세요. 그다음 딜을 직접 다시 만들거나, 가능하면 가져오세요. 영업 프로세스가 그대로 유지되도록 모든 딜 단계, 속성, 관련 데이터를 정확하게 설정하세요.

### HubSpot 이메일 캠페인을 하이퍼클래스로 옮기려면 어떻게 하나요?
HubSpot 이메일 템플릿을 HTML 파일로 저장하세요. 그다음 하이퍼클래스에서 **마케팅 > 이메일 캠페인**으로 이동해 이메일 템플릿을 다시 만들거나 가져오고, 기존 디자인과 같아지도록 설정하세요. 연락처 목록에 보내기 전에 이메일을 테스트해서 형식과 기능이 제대로인지 확인하세요.

### HubSpot 랜딩 페이지와 폼을 하이퍼클래스에서 다시 만들려면 어떻게 하나요?
HubSpot 랜딩 페이지의 HTML을 내려받은 다음, **사이트 > Landing Pages**(랜딩 페이지) 빌더로 다시 만드세요. 모든 폼과 CTA 버튼이 하이퍼클래스 워크플로우에 연결되었는지 확인하세요. 랜딩 페이지와 폼을 하나씩 테스트해서 기능과 데이터 수집이 제대로 되는지 확인하세요.

### HubSpot 워크플로우를 하이퍼클래스에서 다시 만들려면 어떻게 하나요?
HubSpot에서 활성 워크플로우를 모두 찾아 트리거, 액션, 대기 시간을 기록하세요. 하이퍼클래스에서 **자동화 > 워크플로우**로 이동해 같은 역할의 트리거(예: 폼 제출, 연락처 업데이트)를 설정하세요. 이어서 액션(이메일 보내기, SMS 보내기, 연락처에 태그 지정하기, 딜 단계 업데이트하기)을 다시 만들고, 필요한 대기 시간과 조건 분기를 설정하세요. 워크플로우를 활성화하기 전에 테스트를 돌려 의도한 대로 작동하는지 확인하세요.

### HubSpot의 통화와 SMS 기능을 하이퍼클래스로 옮기려면 어떻게 하나요?
HubSpot에서 Twilio를 쓰고 있다면 **설정 > 전화번호**로 이동해 Twilio 계정을 설정하고, 하이퍼클래스에 연동해 통화와 SMS를 사용하세요. 그다음 **자동화 > 워크플로우**에서 SMS와 통화 자동화 워크플로우를 설정하고, 고객과 주고받은 모든 소통이 제대로 기록되고 추적되는지 확인하세요. 모든 커뮤니케이션 채널을 관리하려면 하이퍼클래스에서 대화 인박스도 설정하세요.

### HubSpot에서 하이퍼클래스로 옮긴 뒤에는 어떤 최종 점검을 해야 하나요?
모든 데이터가 잘 옮겨졌는지, HubSpot과 하이퍼클래스의 기록이 서로 다르지 않은지 교차 확인하세요. 모든 워크플로우, 자동화, 캠페인이 제대로 작동하는지 확인하세요. 커뮤니케이션 채널도 테스트해서 기능을 확인하세요. 팀원에게 하이퍼클래스 사용법을 교육하되, HubSpot과 달라진 점을 중심으로 알려 주세요. 성과를 모니터링하면서 필요하면 조정하세요.

### 옮기자마자 바로 HubSpot 구독을 해지해야 하나요?
아니요. 전환하는 동안 HubSpot과 하이퍼클래스를 함께 운영해 보세요. 중요한 업무가 빠지지 않았는지 확인할 수 있어요. 하이퍼클래스가 완전히 자리 잡으면 HubSpot에 대한 의존도를 조금씩 줄이세요. HubSpot 구독을 해지하기 전에는 모든 데이터가 안전하게 백업되었는지 확인하세요. 해지한 뒤에도 문제가 생기지 않는지 시스템을 계속 살펴보고, 이전 과정에서 배운 점을 기록해 두세요.
