# 미국 전화번호를 Twilio에서 하이퍼클래스 전화로 옮기기

Twilio 계정에 있는 미국 전화번호를 하이퍼클래스 전화로 옮기면 통화, SMS, 메시지 등록을 한 플랫폼에서 관리할 수 있어요. 이 문서에서는 미국 로컬 번호와 수신자 부담(Toll-Free) 번호를 옮기는 방법을 안내해요.

이전 전에 준비할 정보, 이전 요청을 보내는 방법, 번호와 함께 옮겨지는 항목, 이전 후 통화·SMS·메시지 등록을 확인하는 방법을 차례로 설명해요.

## 전화번호 이전이란?

전화번호 이전은 미국 로컬 번호나 수신자 부담 번호를 관리하는 전화 시스템 제공업체를 바꾸는 일이에요. Twilio 계정의 번호를 하이퍼클래스 전화로 옮기면, 이후 그 번호의 통화, SMS, 메시지 기능은 모두 하이퍼클래스 전화에서 관리해요.

이전하면 번호를 관리하는 플랫폼만 바뀌어요. Twilio 계정의 과거 데이터, 통화 녹음, 메시지 등록은 자동으로 옮겨지지 않아요.

필요한 계정 정보와 전화번호 정보를 보내 주시면, 하이퍼클래스 고객지원이 이전 과정을 처음부터 끝까지 진행해요.

## 이전하면 좋은 점

Twilio의 미국 전화번호를 하이퍼클래스 전화로 옮기면 전화 관리를 하이퍼클래스 안에 모을 수 있고, 하이퍼클래스 전화의 기본 기능을 쓸 수 있어요.

- 통합 전화 관리: 다른 플랫폼으로 전환하지 않고 하이퍼클래스 안에서 통화와 메시지를 관리해요.
- 하이퍼클래스 기본 기능: 통화 추적, 워크플로우, 메시지 자동화 같은 하이퍼클래스 전화 기능을 써요.
- 간편한 결제 관리: 전화 사용량과 번호 요금을 하이퍼클래스에서 관리해요.
- 간소화된 지원: 하이퍼클래스 전화 문제를 하이퍼클래스 고객지원에서 해결해요.

## 번호와 함께 옮겨지는 항목

번호를 옮기면 번호를 관리하는 전화 시스템만 바뀌어요. 기존 Twilio 계정의 과거 전화 시스템 데이터는 자동으로 옮겨지지 않아요.

| 항목 | 이전 시 동작 |
| --- | --- |
| 전화번호 | 하이퍼클래스 전화로 이동 |
| 이후 통화와 SMS | 전환 후 하이퍼클래스 전화로 연결 |
| Twilio 과거 녹음 | 자동으로 옮겨지지 않음 |
| 과거 음성 사서함 | 자동으로 옮겨지지 않음 |
| 연락처와 대화 | 전화번호 이전과 함께 옮겨지지 않음 |
| A2P / Toll-Free 등록 | 이전 후 확인이 필요하며 다시 등록해야 할 수 있음 |

{% hint style="warning" %}
본인의 Twilio 계정에서 하이퍼클래스 전화로 옮기면 A2P 등록을 다시 해야 할 수 있어요. Twilio에 있던 A2P 등록은 하이퍼클래스 전화로 자동으로 옮겨지지 않아요. 이전 후 하이퍼클래스에서 A2P 등록을 완료하거나 확인하세요. 그리고 A2P 메시지를 다시 보내기 전에, 해당하는 미국 로컬 번호마다 승인된 올바른 캠페인에 연결되어 있는지 확인하세요.
{% endhint %}

{% hint style="info" %}
수신자 부담(Toll-Free) 번호는 이전 후 메시지를 다시 보내기 전에 Toll-Free Verification 상태를 확인하세요. 인증 상태가 자동으로 옮겨진다고 생각하면 안 돼요.
{% endhint %}

## 이전 전에 준비할 것

번호를 받을 위치를 미리 정해 두고, 나중에 필요할 정보를 보관해 두면 전환할 때 불편이 줄어요.

- 도착할 **서브 계정 ID** 확인하기: 이전 후 전화번호가 있게 될 하이퍼클래스 서브 계정의 **서브 계정 ID**(Location ID)를 확인하세요.

  ![서브 계정 ID 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080012211/original/pPDXz1VZqFxEPZgeOfM1L_pGevfoEioNtQ.png?1788439872)

- 번호를 내보내는 Twilio Account SID 확인하기: 지금 번호를 가지고 있는 Twilio Account SID를 찾으세요. 이전 요청에 꼭 필요한 정보예요.
- 이전할 번호 목록 만들기: 가능하면 전화번호를 E.164 형식(예: +1XXXXXXXXXX)으로 적으세요.
- 보관해야 할 Twilio 녹음과 음성 사서함 내려받기: 과거 녹음과 음성 사서함은 하이퍼클래스 전화로 자동으로 옮겨지지 않아요. 중요한 자료는 이전 전에 Twilio 계정에서 내보내 저장해 두세요.
- 번호의 A2P 또는 Toll-Free 등록 상태 확인하기: Twilio에서 해당 번호에 A2P 10DLC나 Toll-Free Verification이 활성 상태인지 확인하세요. 이전 후 하이퍼클래스에서 다시 등록하거나 인증해야 할 수 있어요.
- 기존 착신 전환·라우팅 설정 메모하기: 번호가 지금 통화와 SMS를 어떻게 연결하는지 기록해 두세요. 하이퍼클래스 전화에서 같은 설정을 만들 때 필요해요.
- 번호를 사용하는 워크플로우와 연동 찾기: 이 번호를 쓰는 하이퍼클래스 워크플로우, 외부 서비스 연동, 자동화를 확인하세요. 이전 후 필요하면 설정을 업데이트하세요.
- 통화·메시지가 적은 시간대로 전환 시간 정하기: 통화와 메시지에 주는 영향을 줄이려면, 하이퍼클래스 고객지원 요청에 원하는 이전 시간을 함께 적으세요.

{% hint style="info" %}
미국 외 번호는 국제 번호 이전 가이드를 참고하세요.
{% endhint %}

## Twilio의 미국 번호를 하이퍼클래스 전화로 옮기는 방법

필요한 정보와 전환 희망 시간을 보내 주시면, 하이퍼클래스 고객지원이 이전 과정을 처음부터 끝까지 진행해요.

1. 번호를 가지고 있는 Twilio Account SID를 찾으세요.
   Twilio 콘솔에서 번호를 내보내는 Twilio Account SID를 확인하세요. 이전을 시작하려면 이 정보가 필요해요.
2. 도착할 하이퍼클래스 **서브 계정 ID**(Location ID)를 찾으세요.
   이전 후 전화번호가 있게 될 하이퍼클래스 서브 계정의 **서브 계정 ID**를 확인하세요.
3. 하이퍼클래스 고객지원에 요청을 보내세요.
   하이퍼클래스 고객지원 센터에서 요청을 접수하고, 아래 정보를 함께 적으세요.
   - 이전할 전화번호(가능하면 E.164 형식, 예: +1XXXXXXXXXX)
   - 번호를 내보내는 Twilio Account SID
   - 도착할 하이퍼클래스 **서브 계정 ID**(Location ID)
   - 희망하는 전환 시간(날짜와 시간)

   ![고객지원 요청 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080012571/original/9msPvePhifZRdTEUw-p_1ZB6VnKoUNMq7g.gif?1788439990)

   ![고객지원 요청 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080012762/original/IaQIz83Oq1zjqTRdKU2P-S11rwKujtRWYg.png?1788440069)
4. 하이퍼클래스 고객지원이 이전을 진행하고, 번호가 활성화되면 알려 드려요.
   하이퍼클래스 고객지원이 요청을 처리하고, 전화번호가 하이퍼클래스 전화로 옮겨지면 알려 드려요.
5. 이전이 끝나면 수신·발신 통화와 SMS를 테스트하세요.
   통화와 메시지를 직접 테스트해서 하이퍼클래스 전화에서 번호가 제대로 작동하는지 확인하세요.

{% hint style="info" %}
이전 시점은 필요한 정보를 모두 받았는지와 정해진 전환 일정에 따라 달라져요. 요청을 처리할 준비가 되면 하이퍼클래스 고객지원이 이전 시간을 알려 드려요.
{% endhint %}

## 이전 후 번호 확인하기

전환 직후에 번호를 테스트하면 음성, SMS, 라우팅, 메시지 등록이 하이퍼클래스 전화에서 제대로 작동하는지 확인할 수 있어요.

- 올바른 하이퍼클래스 서브 계정에 번호가 보이는지 확인하기: 도착한 서브 계정의 **전화번호** 목록에서 번호가 추가되었는지 확인하세요.
- 발신 통화 걸어 보기: 이전한 번호로 테스트 전화를 걸어 발신 통화가 되는지 확인하세요.
- 수신 통화 받아 보기: 외부 전화기에서 이전한 번호로 전화를 걸어 수신 통화가 올바르게 연결되는지 확인하세요.
- 발신 SMS 보내 보기: 이전한 번호로 테스트 메시지를 보내 발신 SMS가 되는지 확인하세요.
- 수신 SMS 받아 보기: 외부 전화기에서 이전한 번호로 메시지를 보내 수신 SMS가 올바르게 연결되는지 확인하세요.
- 착신 전환과 라우팅 확인하기: 착신 전환과 라우팅 규칙이 원래 의도한 설정과 같은지 확인하세요.
- 번호가 올바른 사용자나 팀에 배정되었는지 확인하기: 하이퍼클래스에서 번호가 알맞은 사용자나 팀에 배정되어 있는지 확인하세요.
- 해당하는 로컬 번호의 A2P 캠페인 연결 확인하기: 미국 로컬 번호는 A2P 메시지를 다시 보내기 전에 하이퍼클래스 **신뢰 센터**에서 승인된 A2P 캠페인에 연결되어 있는지 확인하세요.
- 해당하는 수신자 부담 번호의 Toll-Free Verification 확인하기: 수신자 부담 번호는 메시지를 다시 보내기 전에 Toll-Free Verification 상태를 확인하세요. 인증 상태가 자동으로 옮겨진다고 생각하면 안 돼요.
- 번호를 사용하는 워크플로우와 연동 점검하기: 하이퍼클래스 워크플로우와 외부 서비스 연동이 이전 후에도 올바른 전화번호를 가리키는지 확인하세요.

{% hint style="info" %}
확인 단계를 모두 마치면 하이퍼클래스 전화에서 번호를 실제 업무에 쓸 수 있어요.
{% endhint %}
