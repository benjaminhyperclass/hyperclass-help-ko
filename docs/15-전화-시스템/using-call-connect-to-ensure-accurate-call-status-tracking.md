# 통화 연결로 통화 상태를 정확하게 추적하기

**통화 연결**(Call Connect)을 켜면 음성사서함, 응답, 부재중 같은 통화 결과가 정확하게 기록돼요. 시도만 한 통화가 아니라 실제로 연결된 통화가 무엇인지 분명하게 확인할 수 있어요.

## 통화 연결이란?

**통화 연결**은 사람이 실제로 통화에 참여한 뒤에만 통화를 '연결됨'으로 처리하는 통화 라우팅 기능이에요.

연락처가 전화를 받으면 시스템이 지정된 상담원에게 전화를 걸어요. 그리고 상담원이 키(예: "1")를 누를 때까지 기다린 뒤 두 사람을 연결해요. 이 키패드 확인 덕분에 상담원이 직접 받은 통화인지 알 수 있어요. 음성사서함으로 넘어갔거나 받지 못한 통화는 걸러져요. 리포트와 자동화를 어지럽히는 잘못된 **완료** 상태도 줄일 수 있어요.

## 통화 연결로 통화 상태를 추적하면 좋은 점

- **추적 정확도 향상**: 상담원이 직접 입력해야 응답으로 처리되므로 통화가 잘못 분류되는 일이 줄어요.
- **믿을 수 있는 통화 리포트**: 부재중 통화나 음성사서함이 아니라 실제 대화만 집계돼요.
- **정확한 워크플로우 트리거**: 상담원과 실제로 연결된 통화에서만 자동화가 실행돼요.
- **음성사서함 구분**: 실제로 받은 통화와 음성사서함으로 넘어간 통화를 나눌 수 있어요.
- **책임감 강화**: 상담원이 통화에 응했는지 놓쳤는지 쉽게 알 수 있어요.
- **더 나은 리드 후속 관리**: 통화 시도가 아니라 실제 사람 간의 대화를 기준으로 후속 조치를 할 수 있어요.

## **완료** 통화 상태가 오해를 부를 수 있는 이유

Twilio는 통화 라우팅이 끝나면 아무도 받지 않았더라도 모든 통화를 **완료**로 표시해요. 그래서 음성사서함으로 넘어간 통화, 상담원이 받지 못한 통화, 시간이 초과된 통화도 정상적으로 연결된 것처럼 보일 수 있어요.

**통화 연결**을 켜면 이 문제가 해결돼요.

- 상담원에게 귓속말 메시지가 재생되고, 통화를 받으려면 아무 버튼이나 누르라고 안내해요.
- 상담원이 받지 않거나 키를 누르지 않으면 통화가 연결되지 않아요. 응답한 통화로 잘못 표시되지도 않아요.

이 간단한 확인 단계 덕분에 실제 대화만 성공한 연결로 집계돼요.

## 통화 연결 켜는 방법

**전화번호** 설정에서 바로 **통화 연결**을 켤 수 있어요. 지정된 사용자나 팀으로 연결되는 수신 통화에 특히 알맞아요.

1. **설정 > 전화 시스템**으로 이동하세요.
2. 설정할 전화번호 옆의 **점 세 개** 아이콘을 클릭한 다음 **구성 편집**을 선택하세요.

   ![전화번호 옆 점 세 개 메뉴에서 구성 편집을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079844284/original/kZq1r4odwMLBqQU58ueVqjm9ipKopl6ORQ.png?1788287584)
3. **고급 설정**으로 이동하세요.
4. **통화 연결**을 켜세요.
5. **Play Whisper Message**(귓속말 메시지 재생)를 켜세요.
6. **귓속말 메시지**에 상담원이 통화를 연결하도록 안내하는 문구를 입력하세요. 예를 들면 "새 전화가 왔습니다. 연결하려면 아무 키나 누르세요."처럼 쓸 수 있어요.
7. **저장**을 클릭해 변경 내용을 적용하세요.

   ![고급 설정에서 통화 연결과 귓속말 메시지를 설정하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079844391/original/YaK07xD4ky3Qd5TMEM45363voh-cPaKTww.png?1788287661)

## 자주 묻는 질문

### 아무도 받지 않았는데 통화가 왜 완료로 표시되나요?
Twilio의 기본 동작은 통화를 받지 않았거나 음성사서함으로 넘어간 경우에도 모든 통화 시도를 **완료**로 표시하는 거예요.

### 통화 연결을 쓰면 무엇이 좋아지나요?
사람이 직접 키를 눌러 확인해야 해서, 통화가 실제로 연결됐는지 시스템이 알 수 있어요.

### 발신 통화와 수신 통화 모두에 적용되나요?
네, 양방향 모두 작동해요. 특히 수신 통화 라우팅과 빠른 리드 응대에 유용해요.

### 상담원이 키를 누르지 않으면 어떻게 되나요?
통화가 연결된 것으로 처리되지 않아서 더 정확하게 추적되고 리포트도 깔끔해져요.

### 자동화에도 영향이 있나요?
네, 좋은 방향으로 달라져요. 실제로 연결된 통화에서만 자동화를 실행할 수 있어요.

### 하이퍼클래스 웹 앱에서 받은 통화에도 통화 연결이 적용되나요?
웹 앱에서 바로 통화를 받을 수 있어요. 다만 이런 통화에는 보통 **통화 연결**이 필요하지 않아요. 하이퍼클래스가 앱 안에서 사람이 받았다는 것을 이미 확인할 수 있기 때문이에요. **통화 연결**은 주로 통화를 외부 전화번호로 연결할 때 유용해요.

### 하이퍼클래스 모바일 앱에서 받은 통화에도 통화 연결이 적용되나요?
하이퍼클래스 모바일 앱에서도 통화를 받을 수 있어요. 웹 앱과 마찬가지로 앱 안에서 받을 때는 보통 **통화 연결**이 필요하지 않아요. 하이퍼클래스가 사람이 받았다는 것을 알 수 있기 때문이에요.

### 하이퍼클래스 번호를 개인 번호나 외부 번호로 착신 전환해도 통화 연결을 쓸 수 있나요?
네. 이 경우가 **통화 연결**의 대표적인 사용 사례예요. 통화가 외부 번호나 개인 번호로 넘어가면 받는 사람이 키를 눌러야 연결돼요. 덕분에 하이퍼클래스가 실제 사람이 받은 통화와 음성사서함이나 자동응답기를 구분할 수 있어요.
