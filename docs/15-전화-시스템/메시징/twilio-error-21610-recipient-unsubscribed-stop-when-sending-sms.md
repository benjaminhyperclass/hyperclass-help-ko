# SMS 발송 시 Twilio 오류 21610 "Recipient unsubscribed (STOP)" 해결하기

SMS를 보냈는데 "Recipient unsubscribed (STOP)" 오류(21610)가 뜨면, 받는 사람이 수신을 거부했거나 수신거부(DND) 상태라서 메시지가 전달되지 않은 거예요. 이 문서에서 원인과 해결 방법을 확인하세요.

## 개요

Twilio(또는 Twilio와 연동된 플랫폼)로 SMS/MMS를 보낼 때, 받는 사람이 수신을 거부했거나 방해 금지(Do Not Disturb, DND)를 켜 두면 메시지를 보낼 수 없어요. 사용자의 선택을 존중하고 메시지 관련 규정을 지키기 위해 이렇게 막아 두었어요.

## 오류 설명

메시지를 받을 사람이 아래 중 하나에서 수신을 거부한 상태예요.

- 내 전화번호
- 내 Twilio Channels 발신자
- 내 메시징 서비스

또는 연락처 프로필에 수신거부(DND) 상태가 켜져 있을 수도 있어요.

받는 사람이 이전에 내 메시지에 `STOP`이라고 답장한 적이 있다면, 그 사람이 `START`라고 답장하기 전까지는 다시 메시지를 보낼 수 없어요.

## 원인

1. 받는 사람이 `STOP` 또는 다른 수신거부 키워드로 답장했어요.
2. 번호가 수신 동의를 한 적 없는 새 사용자에게 재할당되었을 수 있어요.
3. 연락처가 SMS, 통화 또는 모든 연락 유형에 대해 수신거부(DND)를 켰어요.
4. 규정과 컴플라이언스 요건을 지키기 위해 플랫폼이 발송 메시지를 막고 있어요.

## 해결 방법

- 수신을 거부한 번호를 연락처 목록에서 제거하세요.
- 받는 사람에게 내 번호로 `START`(또는 다른 수신 동의 키워드)를 문자로 보내 다시 수신하도록 요청하세요.
- 메시지를 보내기 전에 동의 여부를 확인하세요. 받는 사람이 메시지 수신에 명확히 동의했는지 꼭 살펴보세요.

## Twilio의 수신거부 처리 방식

수신을 거부한 사람에게 메시지를 보내려고 하면 Twilio API가 오류를 반환하고 메시지는 발송되지 않아요. 이때 발송 시도에 대한 요금은 청구되지 않아요.

### 수신거부 키워드

받는 사람이 아래 키워드 중 하나로 답장하면 메시지가 차단돼요.

`STOP` `STOPALL` `UNSUBSCRIBE` `CANCEL` `END` `QUIT`

### 수신 동의(재구독) 키워드

메시지를 다시 받으려면 받는 사람이 아래 키워드로 답장해야 해요.

`START` `YES`

{% hint style="warning" %}
**중요 공지**

메시징 서비스 번호에서 수신을 거부하면, 그 수신거부는 해당 서비스에서 보낸 모든 메시지에 적용돼요.

이렇게 해서 구독자가 원하지 않는 메시지를 받지 않도록 보호해요.
{% endhint %}

## 핵심 정리

항상 정확한 수신 동의를 받고, 수신거부 요청을 존중하세요. 수신을 거부한 사람은 직접 다시 수신 동의를 해야만 메시지를 다시 보낼 수 있어요.

## 자주 묻는 질문

### 수신거부로 차단된 메시지에도 요금이 부과되나요?
아니요. 받는 사람이 수신을 거부했다면 Twilio API가 오류를 반환하고 메시지는 발송되지 않아요. 그래서 발송 시도에 대한 요금은 청구되지 않아요.

### 수신을 거부한 연락처를 제가 직접 다시 등록할 수 있나요?
아니요. 수신거부 상태는 받는 사람이 직접 풀어야 해요. 내 번호로 `START` 또는 `YES`라고 문자를 보내야 하고, 대신 해제해 줄 수는 없어요.

### 번호 하나에서 수신을 거부하면 제 번호 전체가 차단되나요?
범위에 따라 달라요. 번호 하나에서 수신을 거부하면 그 번호만 차단돼요. 하지만 메시징 서비스에서 수신을 거부하면 그 서비스에 연결된 모든 번호가 차단돼요.

### 수신거부와 수신거부(DND)는 어떻게 다른가요?
수신거부는 받는 사람이 `STOP` 같은 키워드로 답장했을 때 적용돼요. 수신거부(DND)는 연락처 프로필에서 직접 켜는 상태예요. SMS, 통화 또는 모든 연락 유형을 막으며, 키워드 답장과는 관계가 없어요.

### 수신을 거부한 적 없는 번호인데 왜 차단되나요?
통신사가 번호를 새 가입자에게 재할당했는데, 그 사람은 수신 동의를 한 적이 없을 수 있어요. 또는 키워드 답장이 아니라 연락처 프로필에서 직접 수신거부(DND)가 켜졌을 수도 있어요.

### 수신거부 차단을 처음부터 피하려면 어떻게 해야 하나요?
수신 동의를 명확히 한 연락처에게만 메시지를 보내세요. 수신을 거부한 번호는 목록에서 정기적으로 정리하고, `STOP` 요청은 바로 처리하세요. 그러면 규정을 지키면서 전달률 문제도 피할 수 있어요.
