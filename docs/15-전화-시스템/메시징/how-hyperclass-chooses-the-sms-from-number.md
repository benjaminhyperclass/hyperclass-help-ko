# SMS 발신 번호가 정해지는 순서

서브 계정에 전화번호가 여러 개일 때, 하이퍼클래스는 정해진 우선순위에 따라 SMS를 보낼 번호를 고릅니다. 이 순서를 알면 연락처에게 어떤 번호가 보일지 미리 알 수 있어요. 대화를 같은 번호로 이어 가거나, 필요할 때 발신 번호를 직접 바꾸는 데도 도움이 됩니다.

## 개요

리드나 연락처에게 SMS를 보내면, 계정에 있는 전화번호 중 하나로 발송돼요. 번호가 둘 이상이면 연락처에게 어떤 번호로 문자가 가는지 궁금할 수 있어요.

SMS를 보낼 때 시스템은 정해진 규칙에 따라 발신 번호로 쓸 Twilio 전화번호를 고릅니다. 가장 알맞은 번호로 보내서 일관성을 지키고 규정도 따르기 위해서예요. 이 문서에서는 발신 번호(From)가 어떻게 정해지는지 설명해요. 이를 알면 발신 번호를 예측하고 직접 조절할 수 있어요.

## 한눈에 보기

시스템은 아래 우선순위를 위에서부터 확인하고, 가장 먼저 해당되는 번호를 사용해요.

1. 직접 지정한 번호: 해당 메시지에 대해 직접 고른 번호
2. 사용자에게 배정된 번호: 메시지를 보내는 사용자에게 배정된 번호
3. 마지막으로 사용한 번호: 해당 대화에서 이미 쓰고 있는 번호
4. 기본 번호: 계정의 기본 발신 번호

## 우선순위별 설명

### 우선순위 1: 메시지에 직접 지정한 번호

사용자나 자동화가 발신 번호(From)를 직접 지정하면 그 번호가 항상 사용돼요. 예를 들어 워크플로우의 SMS 액션에서 특정 번호를 고르거나, API로 번호를 지정하는 경우예요.

이 방법을 쓰면 발신 번호를 완전히 직접 정할 수 있어요. 메시지를 특정 번호로 보내고 싶다면 직접 지정하세요. 다른 모든 규칙보다 우선합니다.

{% hint style="info" %}
선택한 발신 번호는 해당 서브 계정에 속해 있어야 하고, SMS를 지원해야 하며, 필요한 메시징 등록과 규정 준수 요건을 충족해야 해요.
{% endhint %}

{% hint style="warning" %}
선택하는 번호는 내 계정에 속한 번호여야 해요.
{% endhint %}

### 우선순위 2: 메시지를 보내는 사용자에게 배정된 번호

직접 지정한 번호가 없으면, 시스템은 메시지를 보내는 사용자를 확인해요. 그 사용자에게 이 로케이션용 전용 번호가 배정되어 있으면 그 번호로 발송돼요. 팀원마다 자기 번호가 있으면 답장도 담당자에게 바로 돌아오기 때문에 더 개인적인 느낌을 줄 수 있어요.

SMS를 보내는 스태프가 서브 계정의 **스태프 관리** 탭에 있고, 전용 Twilio 번호가 배정되어 있으면 리드는 그 Twilio 번호로 SMS를 받아요. 이 번호는 직접 바꿀 수 있어요.

예외: 배정된 Twilio 번호가 SMS와 호환되지 않으면 시스템은 기본 발신 번호로 대신 보내요.

### 우선순위 3: 해당 대화에서 이미 쓰고 있는 번호

사용자에게 배정된 번호가 없으면, 시스템은 그 연락처의 대화가 이미 내 번호 중 하나와 연결되어 있는지 확인해요. 연결되어 있으면 같은 번호로 계속 보내요.

그러면 대화가 일관되게 유지돼요. 연락처는 지금까지 대화하던 번호로 계속 메시지를 받습니다.

### 우선순위 4: 계정의 기본 번호

위 조건에 모두 해당하지 않으면 계정의 기본 발신 번호로 보내요. 다른 번호가 지정되지 않은 대부분의 자동 메시지와 시스템 메시지는 이 번호로 나가요.

{% hint style="info" %}
기본 발신 번호는 아무것도 지정하지 않았을 때 연락처에게 가장 보이고 싶은 번호로 설정해 두세요.
{% endhint %}

## 사용자에게 전화번호 배정하기

1. **서브 계정 설정 > 스태프 관리**로 이동하세요.
2. 사용자 옆에서 **편집**을 클릭하세요.

   ![스태프 관리 탭에서 사용자 편집하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053959012/original/47E8wtytoJnuER0WSD4SpA2bNZ_p10Zfsw.png?1758115345)

3. **통화 및 음성메일 설정**을 펼치세요.
4. 사용자에게 배정할 Twilio 전화번호를 선택하세요.

   ![통화 및 음성메일 설정에서 Twilio 전화번호 배정하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053959210/original/ep5Tz931DpRQ7_j_Y5rXUwa9HDFnMJE8Bw.png?1758115465)

사용자에게 전화번호를 배정하는 방법은 별도 문서에서 더 자세히 볼 수 있어요.

## 워크플로우에서 번호 직접 지정하기

**Workflow builder**(워크플로우 빌더)에서도 SMS를 보낼 번호를 직접 고를 수 있어요. **Send SMS**(SMS 보내기) 스텝을 설정하면 **From Number**(발신 번호) 드롭다운이 보여요.

스태프 배정이나 채널 번호와 관계없이 워크플로우가 항상 특정 번호로 보내게 하고 싶을 때 유용해요.

![워크플로우 Send SMS 스텝의 From Number 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053959845/original/qlUVFLyfTCV5zYbFAhz3SS187jq-AOvDzg.png?1758115796)

## 대체 규칙 (사용자 번호가 없을 때)

메시지를 보내는 사용자에게 사용할 수 있는 전화번호가 배정되어 있지 않으면, 하이퍼클래스는 그 연락처의 SMS 대화에 연결된 번호를 확인해요. 그 번호를 더 이상 쓸 수 없으면 서브 계정의 기본 발신 번호를 사용해요.

### 대체 1: 채널 번호

해당 연락처와 처음 사용한 번호예요. 이 번호로 대화의 연속성을 유지해요.
### 대체 2: 기본 발신 번호

채널 번호가 삭제된 경우, 계정 차원에서 설정한 기본 Twilio 번호를 사용해요.

## 사용된 번호 확인하기

대화에서 실제로 사용된 Twilio 번호를 확인하려면 다음과 같이 하세요.

1. 대화 화면에서 확인할 SMS 메시지 위에 마우스를 올리세요.
2. 점 세 개(…)를 클릭한 다음 **상세 정보**를 클릭하세요.
3. 그 SMS를 보낼 때 사용한 Twilio 번호가 표시돼요.

![메시지 상세 정보 메뉴에서 사용된 Twilio 번호 확인하기](https://i.ibb.co/YjHc479/chrome-capture-2023-1-20.gif)

## 연락처에게 보이는 번호 조절하기

- 항상 특정 번호로 보내고 싶다면, 메시지나 자동화에 번호를 직접 지정하세요. 이 설정이 항상 우선해요.
- 팀원마다 개인적인 느낌으로 보내고 싶다면, 사용자마다 각자의 번호를 배정하세요.
- 대화를 같은 번호로 이어 가고 싶다면, 따로 할 일은 없어요. 대화가 시작되면 자동으로 같은 번호가 유지돼요.
- 그 외의 경우에는 계정의 기본 발신 번호를 믿을 수 있는 번호로 설정해 두세요.

## 자주 묻는 질문

### 새 번호를 받았는데도 SMS가 계속 예전 번호로 나가요. 왜 그런가요?

대부분 마지막으로 사용한 번호 규칙 때문이에요. 대화가 한 번 어떤 번호로 시작되면, 시스템은 연속성을 위해 그 번호를 계속 사용해요. 번호를 바꾸려면 메시지나 자동화에 원하는 번호를 직접 지정하거나, 사용자에게 배정된 번호를 변경하세요.

### 워크플로우의 모든 메시지를 특정 번호 하나로 보내게 할 수 있나요?

네, 가능해요. **Workflow builder**에서 **Send SMS** 스텝을 설정하고 **From Number** 드롭다운에서 번호를 선택하세요. 이렇게 지정한 번호는 스태프 배정과 채널 번호보다 우선해요.

### 사용자에게 배정된 번호로 SMS를 보낼 수 없으면 어떻게 되나요?

배정된 Twilio 번호가 SMS와 호환되지 않으면, 시스템이 자동으로 기본 발신 번호로 대신 보내요. 그래서 메시지는 그대로 발송돼요.

### 아무 전화번호나 발신 번호로 쓸 수 있나요?

아니요. 선택하는 번호는 내 계정에 속한 번호여야 해요. 서브 계정에 등록되지 않은 번호로는 보낼 수 없어요.

### 특정 SMS가 실제로 어떤 번호로 발송됐는지 어떻게 확인하나요?

대화 화면에서 해당 SMS 위에 마우스를 올리고, 점 세 개(…)를 클릭한 다음 **상세 정보**를 클릭하세요. 사용된 Twilio 번호가 정확히 표시돼요.

### 자동 메시지나 시스템 메시지는 어떤 번호로 나가나요?

특정 번호가 지정되지 않았고 사용자 번호나 대화 번호도 해당하지 않으면, 계정의 기본 발신 번호로 나가요. 연락처에게 가장 보이고 싶은 번호를 기본 발신 번호로 설정해 두세요.
