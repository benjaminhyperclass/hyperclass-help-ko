# SMS 발송 오류 코드 이해하고 해결하기

SMS나 MMS 발송에 실패했을 때 오류 코드로 원인을 파악하고, 알맞게 조치하고, 반복되는 문제를 모니터링하는 방법을 안내해요. 오류 코드가 보이는데 무엇부터 확인해야 할지 모를 때 참고하세요.

## 개요

SMS나 MMS가 실패하면 보통 전달이 어디에서 멈췄는지 알려 주는 오류 코드가 함께 표시돼요. 원인은 받는 사람 번호, 수신 동의 상태, 통신사 필터링, 메시지 등록, 발신 설정, 계정 상태, 지원하지 않는 미디어 파일 등 다양해요.

이 문서는 빠르게 찾아보는 참고용이에요. **대화**에서 실패한 메시지를 찾아 오류 코드를 확인하고, 아래에서 해당 코드를 찾아 원인을 해결한 다음, 필요한 경우에만 다시 테스트하세요.

오류 코드만으로 원인을 알 수 없다면 [SMS 발송 문제 해결](../troubleshooting-sms-delivery.md) 문서에서 처음부터 끝까지 진단하는 방법을 확인하세요.

{% hint style="warning" %}
원인을 확인하지 않고 실패한 메시지를 반복해서 다시 보내지 마세요. 옵트아웃했거나, 유효하지 않거나, 필터링되었거나, 등록되지 않았거나, 제한된 대상에게 반복 발송하면 실패가 더 늘고 메시지 발송 상태에도 나쁜 영향을 줄 수 있어요.

실패한 SMS가 나중에 자동으로 재시도된다고 보장되지 않아요. 먼저 원인을 해결한 다음, 필요할 때만 다시 보내거나 영향받은 연락처를 복구하세요.
{% endhint %}

## SMS 발송 오류란?

SMS 발송 오류는 메시지가 목적지에 도착하지 못했을 때 돌아오는 상태 코드예요. 이 코드로 문제가 받는 사람, 발신 번호, 통신사 경로, 메시지 등록, 계정 설정, 수신 동의 상태, 메시지 내용 중 어디에서 시작됐는지 알 수 있어요.

어떤 실패는 수신자 한 명에게만 영향을 주지만, 어떤 실패는 한 번호나 서브 계정의 모든 발신 메시지에 영향을 줘요. 다시 보내기 전에 영향 범위를 먼저 확인하면 불필요한 발송을 줄이고 더 빨리 해결할 수 있어요.

## 오류 코드를 이해하면 좋은 점

오류 코드를 알면 메시지를 수정해야 할지, 잠시 미뤄야 할지, 발송을 완전히 중단해야 할지, 하이퍼클래스 고객지원에 문의해야 할지 판단할 수 있어요. 발송 성공률과 수신자 경험을 함께 지킬 수 있어요.

- 빠른 진단: 추측하지 않고 실패한 메시지의 원인을 짐작할 수 있어요.
- 안전한 재시도: 다시 보내도 되는 경우와 발송을 멈춰야 하는 경우를 구분할 수 있어요.
- 발송 성공률 개선: 잘못된 번호, 필터링, 등록 누락, 지원하지 않는 경로를 반복되기 전에 바로잡을 수 있어요.
- 규정 준수: 옵트아웃, 수신거부 설정, 발신자 등록 요건, 통신사 제한을 지킬 수 있어요.
- 사전 모니터링: 워크플로우 트리거로 특정 메시지 오류에 자동으로 대응할 수 있어요.

## SMS 오류 확인하고 해석하기

SMS나 MMS 발송에 실패하면 **대화**에 오류 설명이 표시돼요. **자세히 보기**를 선택하면 관련 도움말 문서에서 자세한 내용과 해결 방법을 볼 수 있어요.

### 1단계: 실패한 대화 열기

1. **대화**로 이동하세요.
2. SMS나 MMS가 실패한 연락처를 검색하세요.
3. 해당 대화를 여세요.
4. **실패**로 표시된 메시지를 찾으세요.

![대화에서 실패한 SMS 메시지가 표시된 화면](https://jumpshare.com/v/3y1TTEGBoYVOYYkLuXR0+/Screen+Shot+2025-05-29+at+6.59.38+PM.png)

**대화**를 열고 실패한 발신 메시지를 찾으세요.

### 2단계: 오류 세부정보 열기

실패한 메시지 옆의 빨간색 경고 표시에 마우스를 올리거나 선택하세요.

**오류 세부정보**에 발송 문제에 대한 설명과 관련 도움말 문서로 연결되는 **자세히 보기** 링크가 표시돼요.

![대화에서 실패한 SMS 옆에 표시된 빨간색 오류 표시](https://jumpshare.com/v/GQuCGpZiPfibXmvZGEOw+/Screen+Shot+2025-05-29+at+7.06.05+PM.png)

경고 표시를 눌러 발송 오류의 세부정보를 여세요.

### 3단계: 오류 코드 기록하기

1. 오류 설명을 읽고 메시지가 실패한 이유를 파악하세요.
2. **자세히 보기**를 눌러 관련 도움말 문서를 여세요.
3. 원인과 권장 해결 방법을 확인하세요.
4. 메시지를 다시 보내기 전에 근본 원인을 먼저 해결하세요.

30034, 30007, 21610 같은 숫자 코드를 적어 두세요. 그런 다음 아래 표에서 코드의 의미와 조치 방법을 확인하세요.

![오류 코드와 간단한 설명이 표시된 실패 세부정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084425556/original/ptSkoLRztBJI9DhP7qyEJd9lfL_f5b5PEQ.png?1793199020)

실패 세부정보에는 오류 코드와 문제에 대한 간단한 설명이 나와요.

아래 "자주 발생하는 SMS 오류 코드와 해결 방법"에서도 특정 오류 코드와 권장 해결 방법을 확인할 수 있어요.

| 30033 | A2P 10DLC 캠페인이 정지됨 | **캠페인 상태**와 캠페인에 연결된 규정 준수 또는 등록 문제를 확인하세요. | 하이퍼클래스 고객지원에 문의해 정지 사유와 복구에 필요한 절차를 확인하세요. |
| 30034 | A2P 메시지용으로 번호가 완전히 등록되지 않음 | 승인된 캠페인, 번호와 캠페인의 연결, 통신사 활성화 기간, **개인 사업자** 제한을 확인하세요. | 번호가 승인된 캠페인에 연결되어 있는지 확인하세요. 승인 후 통신사 활성화에 최대 24시간이 걸릴 수 있어요. **개인 사업자** 등록은 캠페인당 로컬 번호 1개만 지원해요. [30034 가이드](../A2P-등록/error-30034-linking-a-phone-number-to-an-approved-a2p-campaign.md) |
| 30037 | 발신 메시지가 비활성화됨 | 계정 단위로 발신 메시지가 비활성화되어 있는지 확인하세요. | 발신 메시지가 활성화되어 있어야 한다면 하이퍼클래스 고객지원에 문의하세요. |

여기에 없는 코드가 필요하다면 [하이퍼클래스 전화 시스템 - 오류 코드 및 경고 사전](../LC-Phone/lc-phone-system-error-code-and-warning-dictionary.md)에서 최신 전체 목록을 확인하세요.

## 미디어 및 첨부파일 오류

MMS 실패는 첨부파일 크기, 지원하지 않는 미디어, 수신 대상의 기능, 호스팅된 미디어를 불러오지 못하는 문제 등으로 생길 수 있어요. 메시지와 관련은 있지만, 일반적인 통신사 SMS 발송 실패와는 따로 진단해야 해요.

### 오류 11751

미디어 메시지 크기 **한도 초과**

첨부한 미디어가 메시지 제공업체나 통신사의 한도보다 커요.

권장 조치: 첨부파일을 압축하거나 호스팅된 링크로 보내세요. 일부 발신자 유형과 통신사는 더 큰 파일을 지원하지만, 통신사 전반에서 호환되려면 MMS 첨부파일을 약 500KB 이하로 유지하길 권장해요.

[현재 SMS·이메일 첨부파일 용량 한도 확인하기 →](file-size-limits-for-attachments-in-sms-and-email.md)

### 관련 문제: 오류 11200

HTTP 불러오기 실패

오류 11200은 일반적인 통신사 SMS 발송 오류가 아니라 HTTP/미디어 불러오기 문제예요. 하이퍼클래스가 메시지에 사용된 호스팅 이미지나 다른 리소스를 불러오지 못할 때 생길 수 있어요.

브랜드가 적용된 시스템 생성 링크나 미디어 도메인과 관련된 실패라면, **비즈니스 프로필**에서 브랜드 도메인 설정을 확인하고 [시스템 생성 링크 브랜딩(API 도메인)](../../11-설정/branding-system-generated-links-api-domain.md)을 참고하세요.

## SMS 오류 자동 모니터링 설정하기

**Messaging Error - SMS**(메시징 오류 - SMS) 워크플로우 트리거를 쓰면, 선택한 오류 코드로 SMS가 전달되지 않았을 때 자동으로 대응할 수 있어요. 직원에게 알리거나, 연락처에 태그를 붙이거나, 자동화를 분기하거나, 성공 가능성이 낮은 대상에게 반복 발송되지 않게 막을 때 유용해요. 트리거에 대한 자세한 내용은 [워크플로우 트리거 - 메시징 오류 코드 - SMS](../../07-워크플로우/트리거/workflow-trigger-messaging-error-code-sms.md) 문서를 참고하세요.

1. **자동화 > 워크플로우**로 이동하세요.
2. 새 워크플로우를 만들거나 기존 워크플로우를 여세요.
3. 트리거 **Messaging Error - SMS**(메시징 오류 - SMS)를 추가하세요.
4. 특정 오류에만 반응하게 하려면 **Error Code**(오류 코드) 필터를 추가하세요.
5. 30007, 30034, 30032, 21610 등 해당하는 오류를 선택하세요.
6. 내부 알림, 태그, 기회 업데이트, 분기 로직 등 원하는 액션을 추가하세요.
7. 워크플로우를 저장하고 게시하세요.

{% hint style="warning" %}
오류 처리 워크플로우는 실패를 감지하고 대응할 수는 있지만, 실패한 SMS를 모두 무조건 다시 보내게 해서는 안 돼요. 특정 오류와 수신자가 여전히 메시지를 받을 수 있는 상태인지에 맞춰 복구 로직을 만드세요.
{% endhint %}

## 추가 문제 해결 팁

설정을 바꾸기 전에 실패의 범위를 먼저 살펴보면, 수신자 개별 문제와 계정 전체, 등록, 통신사 문제를 구분하는 데 도움이 돼요.

| 상황 | 먼저 확인할 내용 |
| --- | --- |
| 연락처 한 명만 실패해요 | 받는 사람 번호, SMS 수신거부/옵트아웃 상태, 번호 유형, 정확한 오류 코드를 확인하세요. |
| 한 통신사의 여러 연락처가 실패해요 | 필터링, 수신 통신사 문제, 30003/30007이 반복되는 패턴을 확인하세요. |
| 로컬 번호 SMS가 갑자기 모두 실패해요 | A2P **캠페인 상태**, 번호 연결 상태, 계정 제한, 30033/30034/30037 같은 오류를 확인하세요. |
| Toll-Free SMS가 모두 실패해요 | Toll-Free 인증 상태와 오류 30032를 확인하세요. |
| MMS만 실패해요 | 첨부파일 크기/유형, 수신 대상의 MMS 지원 여부, 오류 11751 또는 30011을 확인하세요. |
| 워크플로우 SMS는 실패하는데 수동 SMS는 잘 가요 | 액션이 실행된 시점의 워크플로우 실행 내역, 발신 번호, 연락처의 수신거부 상태, 메시지 내용을 확인하세요. |

### 올바르게 등록된 발신자 사용하기

해당하는 미국 로컬 번호는 승인된 올바른 A2P 캠페인에 연결해야 해요. Toll-Free 번호는 미국과 캐나다 수신자에게 메시지를 보내기 전에 Toll-Free 인증을 승인받아야 해요.

### 수신 동의와 목록 품질 지키기

유효한 수신 동의를 받은 사람에게만 메시지를 보내세요. 옵트아웃을 지키고, 잘못된 번호는 바로잡고, 계속 실패하는 대상에게 반복 발송하지 마세요.

### 문의할 때 근거 자료 함께 전달하기

하이퍼클래스 고객지원의 조사가 필요하면 오류 코드, 영향받은 발신 번호와 수신 번호, 메시지 시각, 관련 메시지 ID, Location ID(서브 계정 ID)를 알려 주세요. 요청하면 최근 사례도 여러 건 함께 전달하세요.

## 자주 묻는 질문

### 한 연락처만 SMS가 실패하고 다른 연락처는 잘 받아요. 왜 그런가요?

보통 수신자 개별 문제예요. 실패한 대화에서 전화번호, SMS 수신거부 또는 옵트아웃 상태, 휴대폰 기능, 통신사 상태, 정확한 오류 코드를 확인하세요.

### 발신 SMS가 갑자기 전부 안 가요. 무엇을 확인해야 하나요?

실패한 메시지들의 오류 코드가 같은지 확인하세요. 개별 연락처가 아니라 메시지 제한, 계정 정지, 발신 메시지 비활성화, A2P 캠페인 상태, 발신자 등록 같은 계정 전체 문제일 수 있어요.

### 오류 30007로 실패한 메시지는 바로 다시 보내도 되나요?

아니요. 먼저 내용, 발신자 식별, 수신 동의, URL, 해당 메시지 정책을 검토하세요. 필터링된 같은 내용을 반복해서 보내면 실패가 더 늘 수 있어요. 규정을 지킨 메시지가 계속 30007을 받으면 영향받은 사례를 3건 이상 모아 하이퍼클래스 고객지원에 문의하세요.

### A2P 캠페인이 승인됐는데 왜 오류 30034가 나오나요?

발신 번호가 아직 승인된 캠페인에 연결되지 않았거나, 통신사 활성화가 아직 진행 중일 수 있어요. 승인 후 최대 24시간을 기다리고, 번호와 캠페인의 연결 상태를 확인하세요. **개인 사업자** 등록은 캠페인당 로컬 번호 1개만 지원해요.

### 문제를 해결하면 실패한 SMS가 자동으로 다시 발송되나요?

그렇게 생각하지 마세요. 실패한 SMS 액션이 나중에 자동으로 재시도된다고 보장되지 않아요. 실패 내용을 검토하고, 원래 원인이 해결됐고 수신자가 여전히 메시지를 받을 수 있는 상태인지 확인한 뒤에만 다시 보내거나 해당 연락처를 복구하세요.

### SMS가 실패하면 하이퍼클래스가 팀에 자동으로 알려 줄 수 있나요?

네. **Messaging Error - SMS**(메시징 오류 - SMS) 워크플로우 트리거를 사용하고 해당 오류 코드로 필터링하세요. 그런 다음 내부 알림, 태그, 분기 로직 같은 액션을 추가할 수 있어요.

### SMS 발송 문제를 문의할 때 어떤 정보를 전달해야 하나요?

Location ID(서브 계정 ID), 발신 번호, 수신 번호, 오류 코드, 메시지 시각, 관련 메시지 ID, 스크린샷을 알려 주세요. 오류별 안내에서 요청하면 최근 실패 사례도 여러 건 함께 전달하세요.
