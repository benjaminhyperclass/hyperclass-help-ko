# 미국·캐나다 문자 발송 규정: A2P 등록과 Persona 인증

미국과 캐나다에서 문자를 보낼 때 필요한 A2P 등록과 Persona 인증 규정을 정리한 문서예요. 국내 발송과 해외 발송의 조건, 오류 코드별 해결 방법을 확인할 수 있어요.

미국과 캐나다의 A2P 요건은 문자 발송이 더 일관되고 안정적이며 규정에 맞게 이루어지도록 간소화되었어요.

## 개요

이 문서는 **A2P(Application-to-Person)** 등록과 **Persona 인증**에 관한 발송 요건과 오류 코드를 설명해요. 국내 발송과 해외 발송 모두 다룹니다. 규칙을 미리 알아 두면 메시지를 정상적으로 전달하고 규정 문제를 피할 수 있어요.

## 국내 발송 (미국·캐나다 내)

미국, 캐나다, 푸에르토리코 안에서 문자를 보낼 때는 A2P 등록이 필수예요.

### 이 규정이 뜻하는 것

국내 번호끼리 주고받는 메시지는 등록된 A2P 번호에서 보내야 해요. 예를 들어 미국 → 미국, 미국 → 캐나다, 캐나다 → 미국/푸에르토리코가 여기에 해당해요. 스팸과 허가되지 않은 메시지를 막으려는 통신사 규정을 지키기 위한 요건이에요.

A2P 등록이 없으면 메시지가 실패하고 아래 오류가 표시돼요.

오류 30034

```
Number not A2P compliant. Please register for A2P.
```

### 예시

- 미국 사업자 번호에서 미국 고객에게 보내는 메시지 → A2P 등록 필요
- 미국 번호에서 캐나다 번호로(또는 그 반대로) 보내는 메시지 → A2P 등록 필요

### 캐나다 → 캐나다 발송 규칙

2025년 3월 26일 이전에 구매한 번호

- A2P 등록이 필요하지 않아요.
- 기존처럼 문자를 보낼 수 있어요.

2025년 3월 26일 이후(당일 포함)에 구매한 번호

- A2P 등록이 있어도, 없어도 문자를 보낼 수 있어요.
- A2P 등록을 마치지 않았다면 Persona 인증만 완료하면 돼요.

### 정리

국내 발송은 모두 승인된 A2P 등록이 있어야 정상적으로 전달돼요. 단, 캐나다 → 캐나다는 예외예요. 오래된 번호는 등록이 필요 없고, 새 번호는 A2P 등록이나 Persona 인증 중 하나가 필요해요.

## 해외 발송 (미국·캐나다 → 다른 나라)

미국이나 캐나다에서 해외로 보내는 메시지에는 A2P 등록이 필요하지 않아요. 메시지가 정상적으로 전달되려면 Persona 인증만 있으면 돼요.

### 이 규정이 뜻하는 것

해외 발송은 A2P 등록 대신 발신자의 인증된 신원을 기준으로 해요. Persona 인증은 발신자 정보가 확인되고 승인되었다는 것을 보여 줘요.

### 메시지가 처리되는 방식

- 발신자의 Persona 인증이 완료되어 있으면 메시지가 정상적으로 전달돼요. 이 경우 A2P 인증은 필요하지 않아요.
- A2P 등록도, Persona 인증도 없으면 시스템이 메시지를 차단하고 오류를 표시해요.

오류 1002

```
Message blocked. A2P or persona verification needed.
```

### 오류 1002가 나올 때 해결 방법

전화번호를 구매할 때 Persona 인증이 시작되지 않았다면, 아래 순서로 직접 시작할 수 있어요.

1. **AI 에이전트**로 이동하세요.
2. **음성 AI**를 선택하세요.
3. **발신 통화 켜기**를 클릭하세요.
4. **Persona**(신원 인증) 체크박스를 선택해 인증을 시작하세요.

Persona 인증이 승인되면 메시지가 다시 정상적으로 발송돼요.

### 예시

- 미국 번호에서 프랑스 고객에게 발송 → 가능 (Persona 인증만 필요)
- 캐나다 번호에서 호주 고객에게 발송 → 가능 (Persona 인증만 필요)
- Persona 인증 없이 발송 → 오류 1002와 함께 차단

미국·캐나다 번호에서 보내는 해외 메시지에는 A2P가 아니라 Persona 인증만 필요해요.

## 예외: 영국으로 보내는 메시지

해외 발송 규칙에서 영국은 예외예요.

- 미국에서 영국으로 보내는 메시지는 허용되지 않고, 자동으로 실패해요.
- 영국 → 영국 발송은 가능해요.

오류 21612

```
Message cannot be sent with the current combination of "To" and/or "From" parameters.
```

받는 번호와 보내는 번호의 조합으로는 메시지를 보낼 수 없다는 뜻이에요.

## 한눈에 보기

| 발송 경로 | 필요 조건 |
| --- | --- |
| 국내 (미국 / 캐나다 / 푸에르토리코) | 항상 A2P 등록 필요 |
| 해외 (미국 / 캐나다 → 다른 나라) | Persona 인증만 필요 |
| A2P도 Persona도 없음 | 오류 1002와 함께 메시지 차단 |
| 미국 → 영국 | 지원되지 않음. 오류 21612 표시 |

## 자주 묻는 질문

### A2P 등록과 Persona 인증은 어떻게 다른가요?
A2P 등록은 통신사에 앱 대 개인(Application-to-Person) 메시지 캠페인을 승인받는 절차로, 국내(미국/캐나다/푸에르토리코) 발송에 필요해요. Persona 인증은 발신자의 신원을 확인하는 절차로, 미국·캐나다 번호에서 해외로 메시지를 보낼 수 있게 해 줘요.

### 오류 30034가 나와요. 어떻게 해야 하나요?
오류 30034는 번호가 A2P 규정을 충족하지 않는다는 뜻이에요. 국내 발송 전에 해당 번호의 A2P 등록을 완료하세요. 등록이 승인되면 메시지가 다시 전달돼요.

### 번호를 구매할 때 Persona 인증을 하지 않았어요. 어떻게 시작하나요?
**AI 에이전트 > 음성 AI**로 이동해 **발신 통화 켜기**를 클릭한 다음 **Persona** 체크박스를 선택하면 인증이 시작돼요. 승인되면 메시지가 다시 정상적으로 발송돼요.

### 해외 고객에게 문자를 보내려면 A2P 등록이 필요한가요?
아니요. 미국이나 캐나다 번호에서 보내는 해외 메시지에는 Persona 인증만 필요하고 A2P 등록은 필요하지 않아요. Persona 인증이 완료되어 있으면 메시지가 정상적으로 전달돼요.

### 미국 번호에서 영국으로 문자를 보낼 수 없는 이유가 뭔가요?
미국 → 영국 발송은 지원되지 않아서 오류 21612와 함께 자동으로 실패해요. 이 경로에서는 영국 → 영국 발송만 가능해요.

### 캐나다 번호는 A2P 등록이 면제되나요?
캐나다 → 캐나다 발송에서, 2025년 3월 26일 이전에 구매한 번호만 면제돼요. 그날 이후에 구매한 번호는 A2P 등록으로 보낼 수 있고, A2P를 완료하지 않았다면 Persona 인증으로 보낼 수 있어요.

### A2P 등록도 Persona 인증도 없으면 어떻게 되나요?
메시지가 차단되고 오류 1002가 표시돼요. 국내 발송은 A2P 등록을, 해외 발송은 Persona 인증을 완료하면 다시 발송할 수 있어요.
