# 음성 메시지 설정하기

하이퍼클래스에서는 회사 음성 메시지, 사용자별 음성 메시지, 워크플로우의 음성 메시지 드롭에 직접 녹음한 오디오 파일을 쓸 수 있어요. 재생 오류를 줄이려면 지원되는 형식으로 녹음 파일을 준비하고, 업로드한 뒤 꼭 테스트해 보세요.

## 오디오 파일 요구 사항

음성 메시지 파일을 업로드하기 전에 아래 권장 설정을 확인하세요.

| 요구 사항 | 권장 설정 |
| --- | --- |
| 파일 형식 | MP3 또는 WAV |
| 오디오 품질 | 64 kbps |
| 콘텐츠 | 미리 녹음한 또렷한 음성 메시지 |

{% hint style="warning" %}
음질이 높다고 해서 음성 메시지 전달에 항상 좋은 것은 아니에요. 녹음이 제대로 재생되지 않으면 64 kbps로 변환하거나 다시 내보낸 뒤 업로드하고 다시 테스트하세요.
{% endhint %}

## 회사 음성 메시지 설정하기

서브 계정 전체에 기본 음성 메시지를 쓰고 싶을 때 설정해요.

1. **서브 계정 > 설정 > 전화 시스템**으로 이동하세요.
2. **통화 및 음성메일 설정**까지 스크롤하세요.
3. MP3 또는 WAV 음성 메시지 파일을 업로드하세요.
4. **변경사항 저장**을 클릭하세요.
5. 다른 전화기로 하이퍼클래스 전화번호에 전화를 걸고, 음성 메시지가 나올 때까지 기다리세요.

![회사 음성 메시지 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082701498/original/vaVrcVOLC2Z69nRAY4UF33joNFVSyPiPfg.png?1791355312)

## 사용자 음성 메시지 설정하기

사용자마다 다른 음성 메시지를 설정할 수 있어요.

1. **서브 계정 > 설정 > 사용자**로 이동하세요.
2. 설정할 사용자를 여세요.
3. 해당 사용자의 통화 및 음성 메시지 설정을 여세요.
4. MP3 또는 WAV 음성 메시지 파일을 업로드하세요.
5. 사용자 설정을 저장하고 통화를 테스트하세요.

**사용자**에서 새 사용자를 만들 때 착신 전환 기본값과 음성 메시지 설정 같은 옵션이 나올 수 있어요.

연락처나 전화번호가 해당 사용자에게 배정된 경우에는 그 사용자의 음성 메시지가 우선 적용될 수 있어요.

## 워크플로우에 음성 메시지 드롭 추가하기

자동화로 미리 녹음한 음성 메시지를 보내고 싶을 때 **Voicemail**(음성 메시지) 워크플로우 액션을 써요. 자세한 내용은 [워크플로우 액션 - Voicemail](../../07-워크플로우/IVR-Workflow-Actions/workflow-action-record-voicemail.md)과 [음성 메시지 드롭 설정 가이드](../통화/ringless-voicemail-and-voicemail-drops-in-hyperclass-setup-guide.md)에서 확인할 수 있어요.

1. 해당 **워크플로우**를 여세요.
2. **+** 버튼을 클릭해 액션을 추가하세요.
3. **Voicemail**을 검색해 선택하세요.

   ![워크플로우에서 Voicemail 액션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082701531/original/zsGjQF-dvEgc4xilkupskQuSw__fINJ6Uw.png?1791355340)
4. 미리 녹음한 MP3 또는 WAV 파일을 업로드하세요. 호환성을 높이려면 64 kbps를 사용하세요.

   ![Voicemail 액션에 녹음 파일 업로드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078594921/original/eqhXXr-UlF3Mvr-kqDF9haxfz7fiBypahQ.png?1786969104)
5. **Save Action**(액션 저장)을 클릭하세요.

   ![Save Action 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082701546/original/G0ytCnyvaAtxD1bzZSySWxVXZiLH_Fa9mw.png?1791355360)
6. 상황에 맞게 워크플로우를 저장하거나 게시하세요.

실제 대상에게 음성 메시지 드롭을 보내기 전에, 테스트용 연락처로 워크플로우를 먼저 실행해 보세요.

## 녹음 파일 준비하기

호환되는 파일로 내보낼 수 있다면 어떤 녹음 도구나 오디오 편집 도구든 쓸 수 있어요.

- 조용한 곳에서 녹음하세요.
- 또렷하게, 일정한 크기로 말하세요.
- 배경 소음을 최소한으로 줄이세요.
- 녹음 파일을 MP3 또는 WAV로 내보내세요.
- 음성 메시지 호환을 위해 64 kbps를 사용하세요.

이미 가진 녹음 파일이 있다면 다시 녹음하지 않아도 돼요. 필요하면 기존 파일을 권장 형식과 품질로 변환하거나 다시 내보내세요.

녹음이나 변환에는 외부 오디오 도구를 쓸 수 있어요. 하이퍼클래스는 특정 외부 도구를 요구하지 않아요.

## 음성 메시지 테스트와 문제 해결

### 회사 또는 사용자 음성 메시지 테스트하기

1. 다른 전화기로 하이퍼클래스 전화번호에 전화를 거세요.
2. 음성 메시지가 나올 때까지 기다리세요.
3. 올바른 녹음이 재생되는지 확인하세요.
4. 소리가 깨지거나, 유난히 작거나, 재생에 문제가 없는지 들어 보세요.

### 워크플로우 음성 메시지 드롭 테스트하기

테스트용 연락처로 워크플로우를 실행하고, 의도한 녹음이 전달되는지 확인하세요.

### 오디오가 제대로 재생되지 않을 때

1. 파일이 MP3 또는 WAV인지 확인하세요.
2. 녹음 파일을 64 kbps로 변환하거나 다시 내보내세요.
3. 새 파일을 업로드하세요.
4. **변경사항 저장**을 클릭하세요.
5. 통화나 워크플로우를 다시 테스트하세요.

회사 또는 사용자 음성 메시지라면 **수신 통화 시간 초과**도 확인하세요. 시간 초과가 너무 길면 착신 전환 번호의 통신사 음성메일이 먼저 응답해서, 업로드한 음성 메시지가 재생되지 않을 수 있어요. 자세한 설정은 [전화번호 구성 편집: 수신 통화 설정](../전화번호/phone-number-edit-configuration-incoming-calls-settings.md)과 [전화번호 구성 옵션 개요](../overview-of-phone-number-configuration-options.md)에서 확인하세요.

## 자주 묻는 질문

### 음성 메시지에는 어떤 파일 형식을 써야 하나요?

MP3 또는 WAV 파일을 사용하세요. 안정적으로 재생하려면 64 kbps를 권장해요.

### 음성 메시지 파일은 업로드됐는데 제대로 재생되지 않아요.

오디오 인코딩이나 품질이 통신사 환경에서 안정적으로 재생되는 조건과 맞지 않을 수 있어요. 녹음 파일을 64 kbps로 다시 내보내 업로드한 뒤 다시 테스트하세요.

### 사용자 음성 메시지가 회사 음성 메시지보다 우선할 수 있나요?

네. 연락처나 전화번호가 해당 사용자에게 배정된 경우에는 그 사용자의 음성 메시지가 우선 적용될 수 있어요.

### 사용자별 음성 메시지는 어디에서 설정하나요?

**서브 계정 > 설정 > 사용자**로 이동해 해당 사용자를 열고, 통화 및 음성 메시지 설정에서 설정하세요.

### 음성 메시지 인사말과 워크플로우 음성 메시지 드롭에 같은 녹음 파일을 써도 되나요?

네. 파일이 사용 목적에 맞는 지원 형식과 오디오 품질 요구 사항을 충족한다면 같은 파일을 쓸 수 있어요.
