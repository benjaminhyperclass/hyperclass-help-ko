# Free Caller Registry로 발신번호의 'Spam Likely' 표시 해제하기

미국 발신번호에 'spam likely', 'potential spam', 'scam likely' 같은 표시가 붙었을 때 이를 해제해서 전화 응답률을 높이는 방법을 안내해요. 미국 번호에만 해당해요.

'Spam Likely'로 표시된 번호가 비교적 새 번호이거나 비즈니스에 꼭 필요한 번호가 아니라면, 그 번호는 쓰지 않고 새 번호를 받는 것을 권해요. 이 표시를 해제하는 것보다 빠르고 간편해요. FTC 신고가 접수된 번호도 마찬가지예요.

EIN이 있는데 번호에 'Spam Likely' 표시가 붙었다면, 하이퍼클래스에서 제공하는 **음성 정합성**(Voice Integrity)으로 등록하는 것을 권해요. 전체 단계는 [내 통화가 스팸으로 표시되는 이유와 피하는 방법](why-are-my-calls-marked-as-spam-and-how-can-i-avoid-it.md) 문서를 참고하세요.

EIN이 없다면 Free Caller Registry에 번호를 등록하세요.

---

## 음성 정합성이란?

**음성 정합성**은 비즈니스 통화가 'Spam Likely'로 표시되지 않도록 도와주는 기능이에요. 미국 전화번호를 주요 발신자 ID 분석 업체인 First Orion, Hiya, TNS에 등록해서 통화 응답률을 높이고 브랜드 신뢰도를 지킬 수 있어요.

## 음성 정합성을 켜면 좋은 점

비즈니스 번호가 스팸으로 표시되거나 차단된 경우 **음성 정합성**을 쓰면 다음과 같은 도움을 받을 수 있어요.

- 나빠진 평판을 바로잡고, 정상 통화에 붙은 'Spam Likely' 표시를 없애요.
- 발신자 ID에 인증된 이름이 표시되어 수신자가 전화를 받을 가능성이 높아져요.
- 통화가 의심스럽지 않고 진짜라는 점을 보여 줘요.
- 인증된 발신자 ID로 통화 응답률을 높여요.
- 번호가 차단되거나 무시되는 일을 줄여요.
- 발신자 평판을 오래 좋게 유지해요.
- 수신자에게 신뢰와 믿음을 줘요.
- 정확한 발신자 ID 표시로 브랜딩을 일관되게 유지해요.

## 시작하기 전에 필요한 것

**음성 정합성**을 켜기 전에 다음 조건을 확인하세요.

- SHAKEN/STIR 인증 (필수): 통화가 위조되지 않은 정상 통화임을 확인해 줘요.
- **CNAM 등록** (권장): 발신자 ID에 비즈니스 이름이 표시되어 신뢰도가 높아져요.
- 미국 전화번호만 가능: 현재 **음성 정합성**은 미국 번호에만 적용돼요. 해외 통화는 지원하지 않아요.

{% hint style="info" %}
SHAKEN/STIR 등록을 완료하려면 EIN(고용주 식별 번호)이 필요해요. EIN이 없다면 Free Caller Registry에 번호를 등록하세요.
{% endhint %}

## Free Caller Registry란?

AT&T, T-Mobile, Verizon 같은 통신사는 분석 엔진으로 발신자 ID의 스팸 점수를 만들고 관리해요. 이 3개 통신사는 각각 다른 분석 엔진을 써요. 세 분석 엔진이 함께 만든 것이 Free Caller Registry예요. 여기에 요청을 한 번만 제출하면 세 곳 모두 발신자 ID에 붙은 'Spam Likely' 표시를 다시 검토해요.

## Free Caller Registry에 요청을 제출하려면

1. [Free Caller Registry](https://freecallerregistry.com/fcr/#submitform)에 접속하세요.
2. **Register Here**(여기에서 등록)를 클릭하세요.
3. 아는 범위에서 정보를 입력하세요.
   ![Free Caller Registry 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051103416/original/1URWi00VyQx8kC4-px-3okhaPltNCX3_Zg.jpeg?1754561775)
4. 일부 항목의 권장값은 위 화면에 표시되어 있어요. 아래에도 정리했어요.
   1. **표시 이름**(**전화번호** 옆): 비워 두세요.
   2. **I believe my calls are**(내 통화는 다음에 해당한다고 생각해요): Other(기타)
   3. **Service Providers**(서비스 제공업체): Twilio
   4. **Please provide further information if you have received specific feedback ...**(구체적인 피드백을 받았다면 추가 정보를 알려 주세요): 비워 두세요.
5. **제출**을 클릭하세요.

영업일 기준 4일 안에 스팸 표시가 해제돼요. 해제되지 않으면 Free Caller Registry에 다시 제출하거나, 3개 분석 엔진에 직접 제출할 수 있어요. 각 링크는 다음과 같아요.

1. Hiya (AT&T): <https://hiyahelp.zendesk.com/hc/en-us/requests/new?ticket_form_id=824667>
2. First Orion (T-Mobile): <https://firstorion.com/register-your-number/>
3. Transaction Network Services (Verizon): <https://reportarobocall.com/trf/>

## 자주 묻는 질문

### 처리하는 데 얼마나 걸리나요?
3개 분석 엔진 모두 보통 영업일 기준 4일 정도 걸려요.

### 몇 번까지 제출할 수 있나요?
원하는 만큼 제출할 수 있어요. 횟수 제한은 없어요.

### 제출하면 비용이 드나요?
무료예요.
