# 워크플로우에서 링리스 보이스메일(보이스메일 드롭) 설정하기

링리스 보이스메일(Ringless Voicemail)은 워크플로우를 통해 미리 녹음한 음성 메시지를 연락처의 보이스메일로 보내는 기능이에요. 실시간 통화 없이 후속 안내, 예약 알림, 리드 육성, 재접촉에 쓸 수 있어요. 이 문서에서는 사전 준비, 설정 방법, 전송 방식, 테스트 방법, 문제 해결 방법을 안내해요.

## 링리스 보이스메일이란?

링리스 보이스메일은 미리 녹음한 음성 메시지를 일반 전화 걸기 없이 연락처의 보이스메일로 바로 보내는 워크플로우 액션이에요. 연락처의 휴대폰은 울리지 않고, 실시간 통화도 필요 없어요. 필요한 수신 동의를 받은 연락처에게 자동 후속 안내, 예약 알림, 리드 육성 캠페인, 재접촉 워크플로우를 보낼 때 유용해요.

이 기능은 보이스메일 드롭(Voicemail Drop)이라고도 부르며, 하이퍼클래스 워크플로우 안에서 하나의 액션으로 설정해요.

{% hint style="info" %}
링리스 보이스메일과 일반 보이스메일은 달라요. 링리스 보이스메일은 연락처에게 미리 녹음한 메시지를 보내는 발신용 워크플로우 액션이에요. 회사 보이스메일과 사용자 보이스메일은 상대방이 하이퍼클래스 번호로 전화를 걸었을 때 보이스메일로 연결해 주는 수신용 통화 라우팅 기능이에요.
{% endhint %}

## 링리스 보이스메일이 동작하는 방식

링리스 보이스메일은 실시간 통화 없이 미리 녹음한 메시지를 수신자의 보이스메일로 보내도록 만든 자동 발신 순서를 사용해요. 이 방식을 알아 두면 통신사, 기기, 보이스메일 설정에 따라 전송 결과가 달라지는 이유를 이해하기 쉬워요.

- 발신 순서: 시스템이 수신자 번호로 먼저 한 번 전화를 걸고, 곧바로 두 번째 전화를 걸어요. 두 번째 전화가 보이스메일로 연결되면 미리 녹음한 메시지가 남겨져요.
- 통신사에 따른 전송 결과: 전송 성공 여부는 수신자의 통신사, 네트워크 설정, 보이스메일 시스템에 따라 달라요. 모든 통신사와 기기가 이 발신 순서를 똑같이 처리하는 것은 아니에요.
- 전송 보장 불가: 전송이 통신사와 기기의 동작에 달려 있어서, 링리스 보이스메일이 모든 수신자에게 도착한다고 보장할 수는 없어요. 더 많은 대상에게 쓰기 전에 항상 워크플로우를 먼저 테스트하세요.

기술적인 설명이 더 필요하면 "Voicemail Drop: How It Works and Why It Matters" 문서를 참고하세요.

{% hint style="warning" %}
링리스 보이스메일은 전송이 보장되지 않아요. 수신자의 통신사, 기기, 보이스메일 설정, 네트워크 상태, 그 밖의 제공업체 요인에 따라 전송 결과가 달라질 수 있어요. 더 많은 대상에게 쓰기 전에 항상 워크플로우를 먼저 테스트하세요.
{% endhint %}

## 주요 장점

적절한 수신 동의와 규정 준수 조치를 갖추고 쓰면, 링리스 보이스메일은 자동 커뮤니케이션 워크플로우에서 다음과 같은 장점이 있어요.

- 방해가 적은 전달: 연락처의 휴대폰이 울리지 않아서 방해를 줄이면서도 메시지를 전달할 수 있어요.
- 확장 가능한 자동화: 워크플로우 하나로 여러 연락처에게 직접 전화를 걸지 않고 보이스메일 드롭을 보낼 수 있어요.
- 일관된 메시지: 미리 녹음한 음성이라서 모든 연락처가 같은 어조와 같은 내용의 메시지를 받아요.
- 후속 안내 시간 절약: 실시간 통화가 필요 없는 예약 알림, 리드 육성, 재접촉 캠페인에 유용해요.

| 사용 사례 | 예시 |
| --- | --- |
| 예약 알림 | 예약 24시간 전에 미리 녹음한 알림을 보내요. |
| 리드 육성 | 정보를 요청한 리드에게 후속 메시지를 보내요. |
| 이벤트 안내 | 등록한 참석자에게 다가오는 웨비나나 이벤트를 알려요. |
| 동의받은 리드 재접촉 | 사전 녹음 또는 자동 발신 전화에 대한 필요한 동의를 받은 연락처에게 다시 연락해요. |

## 사전 준비

링리스 보이스메일 워크플로우를 설정하기 전에 다음을 준비하세요.

- 서브 계정에서 사용 중인 하이퍼클래스 전화 번호 또는 연결된 Twilio 번호
- 64 kbps로 준비한 MP3 또는 WAV 형식의 사전 녹음 파일
- 사전 녹음 또는 자동 발신 전화에 필요한 수신 동의
- 보이스메일을 보낼 시점을 정하는 워크플로우 트리거
- 연락처 정보에 입력된 유효한 전화번호
- 게시하기 전에 워크플로우를 확인할 테스트용 연락처

오디오 파일을 만들고 형식을 맞추는 방법은 "Create an Audio File for Voicemail and Voicemail Drops" 문서를 참고하세요.

{% hint style="warning" %}
링리스 보이스메일은 사전 녹음 또는 자동 발신 전화에 관한 연방, 주, 지방, 통신사, 업종별 규정의 적용을 받을 수 있어요. 보내기 전에 필요한 수신 동의를 받고, 사용 사례가 관련 규정에 맞는지 확인하세요.
{% endhint %}

## 링리스 보이스메일 설정 방법

워크플로우에 링리스 보이스메일 액션을 추가하는 방법이에요. 워크플로우를 이미 만들어 두었고, 이제 보이스메일 액션을 추가하는 단계라고 가정해요.

1. **자동화 > 워크플로우**로 이동해 보이스메일 액션을 추가할 워크플로우를 열어요.

   ![워크플로우 목록에서 워크플로우 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080039422/original/Oh2pHu51FqxrTVqwTu7Xn2edzjrAgOQ-NQ.jpeg?1788451372)

2. 액션을 넣을 위치의 **+** 버튼을 클릭해요.
3. 액션 목록에서 **Voicemail**(보이스메일)을 선택하고 **완료**를 클릭해요.

   ![액션 목록에서 Voicemail 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080039489/original/a4yL3r3gJTb9MPNKefJ-DWYPZ1Y4EGxF5w.png?1788451417)

4. (선택) **액션 이름** 필드에 내부에서 알아볼 수 있는 이름을 입력해요. 이 이름은 워크플로우 빌더에 표시되어, 액션의 용도를 구분하는 데 도움이 돼요.
5. 새 파일을 올리려면 **첨부파일 추가**를 클릭하고, 이미 올린 녹음을 쓰려면 드롭다운 메뉴에서 선택해요.
6. 파일이 MP3 또는 WAV 형식이고 64 kbps로 내보낸 파일인지 확인해요.

   ![보이스메일 액션 패널에서 오디오 파일 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080041180/original/ADDz0X8hp0NQS8prgIfQOMaY_VvGslIexQ.png?1788452221)

7. (선택) 연락처를 사용자에게 배정해요. 보이스메일을 보내기 전에 연락처를 특정 팀원과 연결해 두는 용도이고, 연락처 담당자가 워크플로우 로직에 포함될 때만 사용하세요. 사용자 배정이 필요 없으면 이 필드를 비워 두세요.
8. **저장**을 클릭해 워크플로우에 보이스메일 액션을 추가해요.

## 보이스메일 드롭 워크플로우 테스트하기

실제 연락처에게 워크플로우를 게시하기 전에 테스트용 연락처로 실행해 보고, 다음 내용이 예상대로 동작하는지 확인하세요.

- 올바른 보이스메일 파일이 사용돼요.
- 오디오가 또렷하게 재생돼요.
- 워크플로우가 예상한 시점에 시작돼요.
- 메시지가 예상대로 보이스메일에 도착해요.

테스트가 성공하지 않으면 아래 문제 해결 섹션을 확인하세요.

## 링리스 보이스메일 문제 해결

전송 문제는 오디오 파일, 연락처 전화번호, 워크플로우 설정, 통신사 동작, 보이스메일 사용 가능 여부 등 여러 곳에서 생길 수 있어요. 워크플로우를 바꾸거나 고객지원에 문의하기 전에 기본 사항부터 확인하세요.

- 연락처에 유효한 전화번호가 있는지 확인해요.
- 워크플로우에 연락처가 실제로 등록되었는지 확인해요.
- 워크플로우가 Voicemail 액션까지 진행되었는지 확인해요.
- 업로드한 파일이 64 kbps의 MP3 또는 WAV인지 확인해요.
- 재생이 안 되면 오디오를 다시 업로드하거나 다시 내보내요.
- 다른 연락처나 다른 전화번호로 워크플로우를 테스트해요.
- 받는 쪽 번호에 보이스메일이 켜져 있는지 확인해요.
- 계정이 보이스메일 드롭 한도에 도달했는지 확인해요.

## 보이스메일 전송 한도 이해하기

계정의 사용 이력이 쌓이면 보이스메일 드롭 전송 한도가 늘어날 수 있어요. 현재 한도에 도달했거나 추가 용량이 필요하면 하이퍼클래스 고객지원에 문의하세요.

이 한도는 변경될 수 있고, 계정 활동과 통신사 요건에 따라 달라질 수 있어요.
