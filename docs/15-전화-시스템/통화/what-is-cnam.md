# CNAM(발신자 이름 표시)이란?

CNAM(Caller Name Presentation)은 미국 공중 전화망에서 내 전화번호와 비즈니스 이름 또는 개인 이름을 연결해 주는 기능이에요. 발신 전화를 걸면 받는 사람의 기기에 이 이름이 표시될 수 있어요. 이 문서에서는 CNAM 등록 요건과 등록 순서, 그리고 이름 표시나 스팸 표시 해제가 보장되지 않는 이유를 안내해요.

## CNAM이란?

CNAM은 미국 공중 전화망에서 전화번호를 등록된 비즈니스 이름 또는 개인 이름과 연결하는 기능이에요. 발신 통화에 신원 확인 단계를 더해, 받는 사람이 전화번호만 보는 대신 누가 거는 전화인지 볼 수 있게 해 줘요.

발신 전화를 걸면 수신 통신사가 내 번호에 연결된 CNAM 정보를 가져와, 등록된 이름을 받는 사람의 기기에 표시할 수 있어요.

{% hint style="warning" %}
CNAM 이름 표시는 보장되지 않아요. 수신자의 통신사, 기기, 발신자 정보 서비스, 그 밖의 통신사 정책에 따라 등록한 이름이 표시되지 않을 수 있어요.
{% endhint %}

## CNAM의 주요 장점

- 발신자 인지도 향상: 받는 사람이 발신 번호와 연결된 비즈니스를 알아보는 데 도움이 돼요.
- 신뢰도 향상: 알아볼 수 있는 비즈니스 이름이 보이면 정상적인 전화인지 쉽게 알 수 있어요.
- 응답률 향상: 발신자가 분명하게 표시되면 연락처가 전화를 받을 가능성이 높아질 수 있어요.
- 일관된 비즈니스 신원: 발신 번호를 등록할 때 제출한 비즈니스 이름과 연결해 줘요.

## CNAM, A2P, SHAKEN/STIR, 음성 정합성의 차이

CNAM은 하이퍼클래스가 제공하는 통화 신뢰·규정 준수 도구 중 하나예요. 각 등록의 차이를 알아 두면 목적에 맞는 절차를 고를 수 있어요.

- **A2P 등록**: 규정에 맞는 비즈니스 메시지 발송을 지원해요. 아래에서 설명하는 CNAM 등록을 시작하기 전에 먼저 완료해야 해요.
- CNAM: 미국 전화번호를 등록된 비즈니스 이름 또는 개인 이름과 연결해요.
- [SHAKEN/STIR](what-is-shaken-stir.md): 발신자 번호 정보를 인증하고, 통신사가 발신자에게 해당 번호를 쓸 권한이 있는지 확인하도록 도와요.
- **음성 정합성**: 대상이 되는 미국 전화번호의 평판 문제와 스팸 표시 문제를 발신자 정보 분석 업체에 해결하도록 도와요.

CNAM은 별도의 등록이며 A2P, SHAKEN/STIR, 음성 정합성을 대신하지 않아요.

{% hint style="info" %}
이 통화 도구들이 함께 어떻게 쓰이는지 더 넓게 알고 싶다면 [브랜드 콜링: 전화번호 평판 개선하기](../기타/improve-your-phone-number.md)를 참고하세요.
{% endhint %}

## CNAM 등록 요건

정확한 비즈니스 정보를 입력해야 통신사와 인증 시스템이 CNAM 등록을 확인할 수 있어요. 가능하면 공식 사업자 기록과 똑같이 입력하세요.

CNAM 등록을 시작하기 전에 아래 정보를 준비하세요.

- 유효한 고용주 식별 번호(EIN)
- 정확한 법인 비즈니스명
- 비즈니스 유형
- 비즈니스 산업
- 비즈니스 이메일 주소
- 비즈니스 웹사이트 URL
- 비즈니스 운영 지역
- 등록된 사업장 주소
- 공식 대표자의 연락처 정보
- CNAM 표시 이름으로 쓸 비즈니스 이름

등록할 때 IRS CP575 문서를 PDF로 올릴 수도 있어요. 하이퍼클래스는 이 문서를 이용해 비즈니스 이름, EIN, 주소 같은 정보를 자동으로 채울 수 있어요.

등록할 때 지켜야 할 사항이에요.

- 법인 비즈니스명은 LLC, Inc. 같은 접미사까지 포함해서 세금 서류에 적힌 그대로 입력하세요.
- **사업자 등록 번호**(EIN)는 9자리여야 해요.
- 발급받은 지 15일이 지나지 않은 EIN은 인증 과정에서 거부될 수 있어요.
- 가능하면 비즈니스 도메인의 이메일 주소를 쓰세요. Gmail, Yahoo 같은 개인 이메일 주소를 쓰면 승인에 시간이 더 걸릴 수 있어요.
- 상세 주소에 사서함(P.O. Box)을 쓰지 마세요.
- 미국 기업은 제출하는 주소가 CP575 문서에 적힌 주소와 같아야 해요.

## CNAM 등록 절차

등록 항목을 하나씩 정확히 입력하면 인증 문제를 줄이고, CNAM 기록에 올바른 비즈니스가 반영돼요. **신뢰 센터**의 등록 절차를 차근차근 따라가고, 비즈니스 정보가 공식 서류와 일치하는지 확인하세요.

### 1단계: 신뢰 센터에서 CNAM Voice 열기

1. 서브 계정에 로그인하세요.
2. **설정**으로 이동하세요.

   ![설정 메뉴](https://jumpshare.com/share/0eXtBos4kGkEW9DXMuTm+/Screen+Shot+2026-09-07+at+22.31.29.png)
3. **전화 시스템**을 여세요.
4. **신뢰 센터**로 이동하세요.

   ![신뢰 센터 메뉴](https://jumpshare.com/share/2FG1DREf2uBLDKSV4sXZ+/Screen+Shot+2026-09-07+at+22.33.40.png)
5. **A2P 등록**이 완료되었는지 확인하세요.
6. **CNAM Voice**(CNAM 음성 통화)를 찾으세요.
7. **등록 시작**을 클릭하세요.

   ![CNAM Voice의 등록 시작 버튼](https://jumpshare.com/share/m5NMlRorLLZgYhVJWIuF+/Screen+Shot+2026-09-07+at+22.37.44.png)

### 2단계: 비즈니스 세부 정보 입력하기

1. 가지고 있다면 **CP575 PDF**(IRS CP575 문서 PDF 파일)를 올리세요. 지원되는 비즈니스 정보가 자동으로 채워져요.

   직접 입력해도 돼요.
2. **법인 비즈니스명**을 세금 서류에 적힌 그대로 입력하세요.
3. **비즈니스 유형**을 선택하세요. 예를 들면 다음과 같아요.

   - 법인(Corporation)
   - 유한책임회사(Limited Liability Company)
   - 개인 사업자(Sole Proprietorship)
   - 비영리 법인(Nonprofit Corporation)
   - 파트너십(Partnership)
   - 협동조합(Cooperative)
4. **비즈니스 산업**을 선택하세요.
5. 9자리 **사업자 등록 번호**(EIN)를 입력하세요.
6. **비즈니스 이메일**을 입력하세요.
7. **웹사이트 URL**을 입력하세요.
8. **사업 운영 지역**을 선택하세요.
9. **계속**을 클릭하세요.

   ![비즈니스 세부 정보 입력 화면](https://jumpshare.com/share/tf5LDzO45Xzp95d2Gkeq+/Screen+Shot+2026-09-07+at+22.39.11.png)

### 3단계: 사업장 주소 입력하기

1. **국가**를 선택하세요.
2. **State or Province**(주 또는 지방)를 선택하세요.
3. **상세 주소**를 입력하세요.
4. **도시**를 입력하세요.
5. **Postal or ZIP Code**(우편번호)를 입력하세요.
6. **계속**을 클릭하세요.

{% hint style="info" %}
상세 주소에 사서함(P.O. Box)을 입력하지 마세요. 미국 기업은 CP575 문서에 적힌 주소와 같은 주소를 입력해야 해요.
{% endhint %}

![사업장 주소 입력 화면](https://jumpshare.com/share/DyhNB674Oq2PTPUUMLtw+/Screen+Shot+2026-09-07+at+22.46.27.png)

### 4단계: 공식 대표자 추가하기

1. 대표자의 **이름**을 입력하세요.
2. **성**을 입력하세요.
3. **이메일 주소**를 입력하세요. 이메일 주소를 확인하려면 OTP 인증을 완료해야 해요.
4. **전화번호**를 입력하세요.
5. 대표자의 **직책**을 입력하세요.
6. **계속**을 클릭하세요.

![공식 대표자 정보 입력 화면](https://jumpshare.com/share/Btc77yxSbLKiEK0FCBE6+/Screen+Shot+2026-09-07+at+22.47.41.png)

### 5단계: CNAM 세부 정보 입력하기

CNAM 등록에 연결되는 전화번호는 등록 과정에서 자동으로 연결돼요.

1. 발신 전화에 연결할 **CNAM 표시 이름**을 입력하세요.
2. 인증 문구를 읽어 보세요.
3. 인증 체크박스를 선택해 아래 내용을 확인하세요.

   - 연결된 비즈니스 프로필이 전화를 거는 주체예요.
   - 제출한 표시 이름이 내 비즈니스를 나타내요.
4. **제출**을 클릭하세요.

![CNAM 세부 정보 입력 화면](https://jumpshare.com/share/3zqCBCleGvwjUbz6tsga+/Screen+Shot+2026-09-07+at+22.49.42.png)

### 6단계: 인증 기다리기

제출하면 CNAM 등록이 인증 절차로 넘어가요. 승인되면 발신 전화를 걸 때 등록한 비즈니스 이름이 표시될 수 있어요.

통신사와 기기에 따라 동작이 다를 수 있어서, 승인되었다고 해서 모든 수신자에게 비즈니스 이름이 보이는 것은 아니에요.

## 자주 묻는 질문

### CNAM을 등록하면 고객에게 내 비즈니스 이름이 꼭 보이나요?

아니요. CNAM은 등록한 이름을 내 전화번호와 연결해 줄 뿐이에요. 그 이름이 실제로 표시되는지는 수신 통신사, 기기, 서비스, 발신자 정보 제공 업체에 따라 정해져요.

### CNAM을 등록하면 "Spam Likely" 표시가 없어지나요?

아니요. CNAM은 발신자 이름을 알려 주는 용도라서 스팸 표시를 직접 없애 주지는 않아요. 번호에 평판 문제가 있다면 [음성 정합성 안내](../전화번호/improve-your-phone-number-s-reputation-with-voice-integrity.md)를 확인하세요.

### CNAM과 SHAKEN/STIR는 같은 건가요?

아니요. CNAM은 전화번호에 이름을 연결하고, SHAKEN/STIR는 발신자 번호 정보를 인증해 통신사가 발신자에게 해당 번호를 쓸 권한이 있는지 확인하도록 도와요.

### CNAM을 등록하려면 EIN이 꼭 있어야 하나요?

네. 하이퍼클래스 문서에 안내된 CNAM 등록 절차에서는 EIN이 필요해요.

### 개인 사업자도 CNAM을 등록할 수 있나요?

네. EIN을 포함해 필요한 사업자 등록 정보가 있으면 개인 사업자도 등록할 수 있어요.

### EIN을 발급받은 지 얼마 안 됐는데 등록할 수 있나요?

발급받은 지 15일이 지나지 않은 EIN은 등록 과정에서 거부될 수 있어요. 인증 시스템이 새 정보를 아직 인식하지 못할 수 있기 때문이에요.

### Gmail이나 Yahoo 이메일 주소로 등록해도 되나요?

요청하는 비즈니스 이메일 정보에 입력은 할 수 있지만, 비즈니스 도메인의 이메일 주소를 쓰는 것을 권장해요. 개인 이메일 도메인을 쓰면 승인에 시간이 더 걸릴 수 있어요.

### CNAM이 승인됐는데 비즈니스 이름이 계속 안 보여요.

CNAM 정보는 수신 통신사가 가져와서 표시하는데, 통신사나 기기마다 CNAM 데이터를 처리하는 방식이 달라요. 그래서 승인되었더라도 모든 통화에서 등록한 이름이 표시되는 것은 아니에요.

### 이미 SHAKEN/STIR를 쓰고 있는데 CNAM도 등록해야 하나요?

네, 두 기능은 역할이 달라요. SHAKEN/STIR는 발신자 정보를 인증하고, CNAM은 발신자 이름을 알려 줘요.
