# 하이퍼클래스 전화 시스템의 지역 번호 발신 사용하기

지역 번호 발신은 연락처의 지역에 가장 잘 맞는 발신자 번호를 자동으로 골라 전화를 거는 기능이에요. 이 문서에서는 기능의 동작 방식, 설정 방법, 번호 예약 방법을 안내해요.

새로 만든 지역 번호 발신 기능은 미국, 캐나다, 영국, 호주에서 위치 기반 매칭을 지원해요. 웹 다이얼러, 모바일 앱, 데스크폰 등 지원되는 발신 경로에서 모두 쓸 수 있어요. 지역에 맞는 번호가 없거나 필요한 연락처 정보가 없으면 계정 기본 번호로 발신해서 통화가 끊기지 않게 해요.

## 지역 번호 발신이란?

지역 번호 발신은 연락처의 위치를 기준으로, 발신 통화에 쓸 수 있는 가장 알맞은 발신자 번호를 자동으로 골라 줘요. 위치 기반 매칭과 정해진 대체 순서에 따라 사용할 번호를 찾고, 지역에 맞는 번호가 없으면 계정 기본 번호를 사용해요.

### 꼭 알아 두세요

- 한 지역의 모든 지역번호를 지원해요. 예를 들어 Dallas에 사는 지역번호 241 연락처에게 전화한다면 이렇게 동작해요.
  - 지역번호 241 전화번호가 있으면 그 번호로 발신해요.
  - 241 번호는 없지만 지역번호 972인 Dallas 번호가 있으면 972 번호로 발신해요.
  - Dallas에 속한 지역번호의 번호가 하나도 없으면 서브 계정의 기본 전화번호로 발신해요.
- 지역에 맞는 번호가 하나도 없을 때를 대비해 서브 계정의 기본 전화번호를 대체 번호로 사용해요.
- 미국/캐나다만 지원해요.- 지역 번호 발신은 미국, 캐나다, 영국, 호주에서 위치 기반 매칭을 지원해요.
- 같은 연락처에게 다시 전화하면 이전에 매칭된 번호를 그대로 써요.
- 웹 다이얼러, 모바일 앱, 데스크폰에서 걸 수 있는 발신 통화에서 지역 번호 발신이 작동해요.
- 서브 계정마다 최대 50개의 번호를 예약해 두면, 지역 번호 발신에서 자동으로 선택되지 않아요.
- 예약한 번호도 직접 전화를 걸 때는 계속 쓸 수 있어요.
- 지역에 맞는 번호가 없거나 연락처의 위치 정보가 없으면 계정 기본 번호로 발신해요.

## 지역 번호 발신의 장점

지역 번호 발신을 쓰면 연락처의 응답률을 높이고 신뢰를 쌓는 데 도움이 돼요.

- 응답률 상승: 지역 번호는 낯설지 않아서 모르는 번호라도 받아 볼 가능성이 높아져요.
- 브랜드 신뢰도 향상: 일관된 지역 번호로 신뢰를 쌓고, 스팸으로 보는 인식을 줄여요. 스팸 표시가 걱정된다면 [내 통화가 스팸으로 표시되는 이유와 피하는 방법](why-are-my-calls-marked-as-spam-and-how-can-i-avoid-it.md)도 참고하세요.
- 자동 번호 선택: 번호를 직접 바꿀 필요 없이, 일치하거나 같은 지역의 번호로 자동 발신해요.
- 같은 지역 대체 번호: 지역번호가 정확히 일치하는 번호가 없으면 같은 지역의 다른 번호를 사용해요.
- 유연한 설정: 서브 계정 단위로 켜고 끌 수 있어서 사용 여부를 비즈니스에서 직접 정할 수 있어요.
- 일관된 발신자 ID: 같은 연락처에게 다시 전화하면 이전에 매칭된 번호를 그대로 써요.
- 예약 번호 관리: 서브 계정마다 최대 50개의 번호를 예약해 자동 선택에서 빼 두고, 직접 전화할 때는 계속 쓸 수 있어요.

---

## 지역 번호 발신의 동작 방식

번호가 어떻게 선택되는지 알아 두면 발신 통화에서 이 기능을 더 잘 활용할 수 있어요.

- 발신 통화를 시작하면, 연락처 전화번호의 지역번호를 보유한 번호 목록과 비교해요.
- 지역번호가 정확히 일치하는 번호가 있으면 그 번호를 발신자 번호로 사용해요.
- 일치하는 번호가 없으면 같은 지리적 지역의 번호(예: Dallas의 다른 지역번호)를 사용해요.
- 같은 지역의 번호도 없으면 서브 계정의 기본 발신자 ID를 사용해요.
- 번호 선택은 실시간으로 이루어지며 따로 조작할 필요가 없어요.

## 지역 번호 발신 설정하기

아래 순서대로 설정하면 발신 통화에 지역 번호가 자동으로 적용돼요.

1. 설정할 서브 계정을 열어요.
2. **설정 > 전화 시스템 > 음성 > 기타 설정**으로 이동해요.
3. **발신 통화**를 선택해요.
4. **Default number preference for outbound calls**(발신 통화 기본 번호 설정)까지 스크롤해요.
5. **지역 번호 발신**을 선택해요.

![발신 통화 설정에서 지역 번호 발신 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082014503/original/-VUJBDaP626eksCd1uErtwnNndDngKIYnQ.png?1790603959)

### 지역 번호 발신에서 번호 예약하기

예약한 번호는 지역 번호 발신에서 자동으로 선택되지 않지만, 직접 전화를 걸 때는 계속 쓸 수 있어요.

서브 계정마다 최대 50개의 번호를 예약할 수 있어요.

1. **설정 > 전화 시스템 > 음성 > 기타 설정 > 발신 통화**로 이동해요.
2. **지역 번호 발신** 섹션을 찾아요.
3. **Reserved numbers**(예약된 번호) 아래에서 **+ Reserve a number**(번호 예약)를 클릭해요.
4. 예약할 번호를 선택해요.

## 자주 묻는 질문

### 연락처의 지역번호와 일치하는 구매 번호가 없으면 어떻게 되나요?

하이퍼클래스가 지역 번호 발신의 매칭 순서를 차례로 확인해요. 오버레이 지역번호, 가장 가까운 거리의 사용 가능한 번호, 같은 지역의 번호를 확인한 다음 계정 기본 번호를 사용해요.

### 특정 통화에서는 자동 선택 대신 번호를 직접 고를 수 있나요?

네, 가능해요. 통화 전에 다이얼러 상단 바의 **변경**을 클릭한 다음 보유한 전화번호 중에서 고르세요. 통화가 끝나면 다시 지역 번호 발신으로 돌아가요. 내가 고른 발신 번호를 계속 쓰고 싶다면 지역 번호 발신을 비활성화하면 돼요.

### 추가할 수 있는 번호 수에 제한이 있나요?

서브 계정에 있는 모든 전화번호와 [인증된 발신자 ID](../LC-Phone/how-to-set-up-verified-caller-id-use-your-number-for-voice-calls.md)를 지원해요. 별도의 제한은 없어요.

### 인증된 발신자 ID도 지원하나요?

네, 지원해요. 어떤 발신자 ID로 전화할지 정할 때 인증된 발신자 ID의 지역번호도 함께 고려해요.

### 제 Twilio 계정을 쓰고 있어도 작동하나요?

네, 지역 번호 발신은 내 Twilio 계정에서도 작동해요.

### 특정 서브 계정이나 사용자에게만 지역 번호 발신을 끌 수 있나요?

서브 계정 단위로는 끌 수 있지만, 개별 사용자 단위로는 끌 수 없어요.

### 해외에서도 쓸 수 있나요?

위치 기반 지역 번호 발신은 미국, 캐나다, 영국, 호주에서 지원돼요.

### 지역 번호 발신을 쓰면 통화 응답률이 자동으로 올라가나요?

익숙한 지역 번호가 표시되면 상대방이 전화를 받을 가능성이 높아져요. 하지만 응답률이 오른다고 보장하지는 않아요.
