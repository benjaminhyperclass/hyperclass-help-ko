# 다이얼러 자동 최소화·고정·이동 기능

통화 중에도 하이퍼클래스 안에서 다른 작업을 계속할 수 있도록, 웹 다이얼러에 자동 최소화, 고정, 이동 기능이 추가됐어요. 다이얼러가 연락처나 파이프라인 정보를 가리지 않게 하면서도 통화 컨트롤은 가까이에 둘 수 있어요.

## 다이얼러 자동 최소화·고정·이동이란?

하이퍼클래스 웹 다이얼러가 화면에서 어떻게 동작하고 어디에 나타날지 직접 정할 수 있는 기능이에요. 다이얼러에는 세 가지 동작이 있어요.

- 다이얼러 바깥을 클릭하면 자동으로 최소화돼요.
- 고정하면 계속 화면에 남아 있어요.
- 원하는 위치로 옮길 수 있어요.

기록을 확인하거나 정보를 수정하거나 하이퍼클래스의 다른 메뉴로 이동하면서도 통화를 편하게 관리할 수 있어요.

## 이 기능의 장점

- 화면이 덜 복잡해요. 통화 중에 하이퍼클래스의 다른 영역을 클릭하면 자동 최소화가 공간을 비워 줘요.
- 직접 제어할 수 있어요. 통화 컨트롤이 항상 필요할 때는 다이얼러를 고정해 두면 돼요.
- 위치를 자유롭게 정할 수 있어요. 작업 방식에 맞는 화면 위치로 다이얼러를 끌어다 놓을 수 있어요.
- 화면 구성이 일정해요. 다이얼러를 고정해 두면 마지막으로 놓은 위치에서 다시 열릴 수 있어요.
- 여러 작업을 편하게 할 수 있어요. 다이얼러를 매번 닫거나 옮기지 않고도 연락처 정보나 파이프라인 정보를 볼 수 있어요.

## 자동 최소화

통화 중에 하이퍼클래스의 다른 곳에서 작업할 때 다이얼러가 방해되지 않게 해 주는 기능이에요. 다이얼러가 페이지 위에 크게 펼쳐져 있지 않아서 기록을 보거나 정보를 수정하기 편해요.

- 다이얼러가 열려 있고 고정되지 않은 상태에서 다이얼러 바깥을 클릭하면 최소화돼요.
- 최소화는 다이얼러가 화면에 보이는 방식만 바꿀 뿐, 통화를 끊지 않아요.
- 통화 컨트롤이 다시 필요하면 최소화된 상태에서 다이얼러를 다시 열 수 있어요.
- 최소화된 다이얼러를 복원하려면 상단 내비게이션의 전화 아이콘을 클릭하세요.

## 다이얼러 고정

다이얼러를 고정하면 다른 메뉴로 이동하는 동안에도 다이얼러가 화면에 계속 보여요. 기록을 확인하거나 스크립트를 따라 말하거나 통화 중에 메모를 수정할 때 통화 컨트롤을 화면에 두고 싶다면 유용해요.

- 핀 아이콘을 클릭하면 다이얼러가 열린 상태로 유지돼요.
- 고정하면 다른 곳을 클릭해도 다이얼러가 최소화되지 않고 계속 보여요.
- 원래 동작으로 돌아가려면 다이얼러의 고정을 해제하거나 직접 최소화하세요.

## 다이얼러 이동과 위치 기억

화면에서 가장 편한 곳에 다이얼러를 놓을 수 있어요. 꼭 봐야 할 정보를 가리지 않으면서 다이얼러를 가까이에 둘 수 있어요. 다이얼러가 열려 있는 동안에는 원하는 위치로 끌어서 옮길 수 있어요.

1. 다이얼러 머리글 또는 끌기 영역을 클릭한 채로 누르고 있어요.
2. 원하는 화면 위치로 옮겨요.
3. 마우스 버튼을 놓으면 그 자리에 다이얼러가 놓여요.

다이얼러를 고정해 둔 경우에는 저장된 그 위치에서 다시 열릴 수 있어요.

## 사용 방법

이 기능은 하이퍼클래스 웹 다이얼러에 기본으로 들어 있어서 따로 설정할 필요가 없어요.

1. 하이퍼클래스 상단 내비게이션 바에서 초록색 전화 아이콘을 클릭해 웹 다이얼러를 열어요.

## 자주 묻는 질문

### 자동 최소화하면 통화가 끊기나요?

아니요. 자동 최소화는 다이얼러가 화면에 보이는 방식만 바꿔요. 통화는 계속 연결돼 있어요.

### 다이얼러가 제가 놓은 위치를 기억하나요?

네, 다이얼러를 고정해 두면 마지막으로 놓은 같은 위치에서 다시 열릴 수 있어요.

### 하이퍼클래스의 다른 곳에서 작업하는 동안 다이얼러를 계속 열어 두려면 어떻게 하나요?

핀 아이콘을 클릭하세요. 고정하면 고정을 해제하거나 직접 최소화하기 전까지 다이얼러가 열린 상태로 유지돼요.

### 다이얼러를 화면의 다른 위치로 옮길 수 있나요?

네. 다이얼러를 화면의 원하는 위치로 끌어서 옮길 수 있어요.

### 하이퍼클래스에서 다이얼러는 어디서 여나요?

웹 앱 상단 내비게이션 바의 전화 아이콘을 클릭하면 다이얼러를 열 수 있어요.
