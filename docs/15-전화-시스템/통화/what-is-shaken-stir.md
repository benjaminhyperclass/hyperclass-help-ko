# SHAKEN/STIR란? 발신자 인증 이해하기

SHAKEN/STIR는 통신사가 발신 전화의 번호를 보낸 사람이 실제로 쓸 수 있는 번호인지 확인하도록 돕는 발신자 인증 체계예요. 이 문서에서는 SHAKEN/STIR의 개념, CNAM·**음성 정합성**과의 차이, 등록 방법을 설명해요.

SHAKEN/STIR는 발신자에 대한 신뢰를 높여 통화 연결률과 응답률에 도움이 될 수 있어요. 하지만 “Spam Likely” 같은 스팸 표시를 직접 없애 주지는 않아요.

## SHAKEN/STIR란?

SHAKEN/STIR는 발신자 번호(Caller ID) 정보를 인증하는 프로토콜 모음이에요. 통신사는 이 인증 정보를 보고 발신자가 화면에 표시된 번호를 쓸 권한이 있는지 판단해요.

- STIR는 Secure Telephone Identity Revisited의 약자예요.
- SHAKEN은 Signature-based Handling of Asserted information using toKENs의 약자예요.

발신 전화를 걸면 SHAKEN/STIR가 디지털 인증서로 발신자 번호 정보를 인증해요. 수신 통신사는 통화를 평가할 때 이 인증 정보를 활용할 수 있어요.

수신 통신사와 단말기에 따라, 인증된 통화에는 신뢰됨 또는 인증됨 표시가 붙을 가능성이 더 높아질 수 있어요.

SHAKEN/STIR를 쓰면 상대방의 전화가 울릴 때 회원님의 번호가 그대로 표시돼요. 그만큼 신뢰도가 높아지고 스팸으로 분류되는 일을 줄이는 데 도움이 돼요.

{% hint style="warning" %}
SHAKEN/STIR는 발신자 번호 정보를 인증해 줄 뿐이에요. 통화에 “Trusted”나 “Verified” 표시가 뜬다고 보장하지 않으며, “Spam Likely” 같은 스팸 표시를 직접 없애 주지도 않아요.
{% endhint %}

## SHAKEN/STIR의 주요 장점

SHAKEN/STIR는 정상적인 발신 전화의 진위를 확인해 주고, 발신자 평판을 관리하는 다른 도구가 쓰는 인증 기반이 돼요.

- 발신자 번호 인증: 통신사가 회원님의 비즈니스에 발신 전화에 표시된 번호를 쓸 권한이 있는지 확인할 수 있어요.
- 발신자 번호 도용 감소: 권한 없는 발신자가 회원님의 번호를 사칭하기 어려워져요.
- 통신사 신뢰도 향상: 수신 통신사가 정상 통화를 평가할 때 참고할 인증 정보를 받게 돼요.
- 통화 응답률 지원: 수신 통신사에 따라, 인증된 통화에 신뢰됨 또는 인증됨 표시가 붙을 가능성이 더 높아질 수 있어요.
- **음성 정합성** 사용 가능: 대상 미국 번호를 **음성 정합성**으로 제출하려면 먼저 SHAKEN/STIR 등록이 되어 있어야 해요.

## SHAKEN/STIR, CNAM, 음성 정합성의 차이

SHAKEN/STIR, CNAM, **음성 정합성**은 함께 쓰면 발신자 인증, 식별, 평판을 개선하는 데 도움이 돼요. 다만 각각 하는 일이 달라요.

| 기능 | 하는 일 | 알아둘 한계 |
| --- | --- | --- |
| SHAKEN/STIR | 발신자 번호 정보를 인증하고, 통신사가 발신자의 번호 사용 권한을 확인하도록 도와요 | 스팸 표시나 불편 표시를 없애지 않아요 |
| CNAM | 미국 전화번호를 등록된 비즈니스 이름이나 개인 이름과 연결해요 | 이름 표시는 보장되지 않으며 스팸 표시도 없애지 않아요 |
| **음성 정합성** | 대상 미국 번호를 주요 발신자 번호 분석 업체에 등록해 평판 검토를 받게 해요 | 업체별 검토는 따로 진행되고, 표시가 바뀌기까지 시간이 걸릴 수 있어요 |

세 기능을 함께 쓰면 발신자 진위 확인, 발신자 이름 표시, 전화번호 평판 개선에 도움이 돼요.

## SHAKEN/STIR 등록 요건

하이퍼클래스에서 SHAKEN/STIR를 등록하기 전에 비즈니스가 등록 요건을 충족하는지 확인하세요.

하이퍼클래스에 안내된 SHAKEN/STIR 등록 절차에는 유효한 고용주 식별 번호(EIN, Employer Identification Number)가 필요해요.

{% hint style="info" %}
EIN이 없는 비즈니스는 안내된 SHAKEN/STIR 등록 절차를 이용할 수 없어요. EIN이 없는데 대상 미국 전화번호의 평판이나 스팸 표시 문제를 해결해야 한다면, 번호를 평판 검토용으로 제출할 수 있는 다른 방법인 Free Caller Registry를 확인해 보세요.
{% endhint %}

## SHAKEN/STIR 활성화 방법

계정 설정에 따라 대상 전화번호가 조건을 갖춘 A2P 등록을 통해 자동으로 등록될 수도 있고, **신뢰 센터**에서 SHAKEN/STIR를 직접 설정할 수도 있어요.

### A2P 등록으로 자동 등록되는 경우

조건을 갖춘 A2P SMS 등록을 완료했다면, 대상 전화번호가 SHAKEN/STIR에 자동으로 등록될 수 있어요.

SHAKEN/STIR 등록 상태는 **신뢰 센터**에서 확인할 수 있어요.

![신뢰 센터에서 SHAKEN/STIR 등록 상태를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080506419/original/xL2QPb5F1aGcJg4fw_IgqDelx1-soArajA.png?1788963143)

2025년 4월 23일 이후 제출한 모든 신규 A2P 신청에 적용돼요. 이전에 만든 서브 계정도 자동으로 업데이트되고 있어요.

{% hint style="info" %}
자동 등록 여부는 등록 자격과 계정 설정에 따라 달라요. 계정에 SHAKEN/STIR가 설정되어 있지 않다면 아래의 직접 등록 방법을 이용하세요.
{% endhint %}

### SHAKEN/STIR 직접 등록

A2P 등록으로 자동 등록되지 않았다면 **신뢰 센터**에서 SHAKEN/STIR를 직접 설정할 수 있어요.

1. 하이퍼클래스 서브 계정으로 이동하세요.
2. **설정 > 전화번호 > 신뢰 센터**로 이동하세요.
3. **SHAKEN/STIR**(발신자 인증) 등록 옵션을 찾으세요.
4. 요청하는 비즈니스 정보를 입력하세요.
5. 입력한 정보가 정확한지 확인하세요.
6. 등록을 제출하세요.

![신뢰 센터에서 SHAKEN/STIR 등록 정보를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080506639/original/5lK9UeM0tTZbTfD8wm5KLozL7A-TWR_TVQ.png?1788963246)

SHAKEN/STIR 등록이 설정되면, 대상 번호는 발신 전화에서 이 인증 체계를 사용할 수 있어요.

## 알아둘 점

SHAKEN/STIR를 사용할 때 다음 사항을 기억하세요.

1. SHAKEN/STIR는 스팸 표시를 없애지 않아요. 번호가 인증에 성공해도 “Spam Likely”, “Potential Spam” 같은 불편 표시가 뜰 수 있어요. 스팸 분류는 통화 패턴, 수신자 신고, 분석 업체 데이터, 번호의 이전 사용 이력 등에 영향을 받아요.

2. 평판 문제에는 **음성 정합성**을 사용하세요. 대상 미국 전화번호가 잘못 스팸이나 불편 표시를 받고 있다면, **음성 정합성**으로 지원되는 발신자 번호 분석 업체에 번호를 제출해 평판 검토를 받을 수 있어요.

3. CNAM은 하는 일이 달라요. CNAM은 미국 전화번호에 비즈니스 이름이나 개인 이름을 연결해요. SHAKEN/STIR 인증을 대신하지 않으며, 등록한 이름이 모든 수신자의 단말기에 표시된다고 보장하지도 않아요.

4. 발신자 표시는 수신 네트워크가 정해요. SHAKEN/STIR로 인증해도 수신자에게 “Trusted”, “Verified” 같은 표시가 보인다고 보장하지 않아요. 표시 방식은 수신 통신사와 단말기에 따라 달라요.

5. **음성 정합성**에는 SHAKEN/STIR가 필요해요. 하이퍼클래스의 **음성 정합성** 등록 절차로 대상 미국 번호를 제출하려면, 비즈니스에 SHAKEN/STIR가 먼저 설정되어 있어야 해요.

## 자주 묻는 질문

### SHAKEN/STIR로 “Spam Likely” 표시를 없앨 수 있나요?
아니요. SHAKEN/STIR는 발신자 번호 정보를 인증할 뿐, 전화번호 평판을 직접 관리하거나 불편 표시를 없애지 않아요. 평판 문제가 있는 대상 미국 번호는 **음성 정합성**으로 평판 검토를 받으세요.

### SHAKEN/STIR를 등록하려면 EIN이 필요한가요?
네. 하이퍼클래스에 안내된 SHAKEN/STIR 등록 절차에는 유효한 고용주 식별 번호(EIN)가 필요해요.

### EIN이 없으면 어떻게 하나요?
EIN이 없는 비즈니스는 안내된 SHAKEN/STIR 등록 절차를 이용할 수 없어요. 대상 미국 번호의 스팸이나 평판 문제를 해결하려는 경우, 대체 방법으로 Free Caller Registry를 확인해 보세요.

### SHAKEN/STIR와 CNAM은 같은 건가요?
아니요. SHAKEN/STIR는 발신자 번호 정보를 인증해 통신사가 발신자의 번호 사용 권한을 확인하도록 도와요. CNAM은 미국 전화번호에 비즈니스 이름이나 개인 이름을 연결해요.

### **음성 정합성**을 등록하기 전에 SHAKEN/STIR가 필요한가요?
네. 대상 미국 전화번호를 **음성 정합성**으로 등록하려면 먼저 SHAKEN/STIR가 설정되어 있어야 해요.

### SHAKEN/STIR를 등록하면 내 전화에 “Trusted”나 “Verified”가 표시되나요?
아니요. SHAKEN/STIR는 수신 통신사에 인증 정보를 전달해 줄 뿐이에요. 신뢰됨이나 인증됨 표시를 보여 줄지, 어떻게 보여 줄지는 수신 통신사와 단말기가 최종적으로 정해요.

### SHAKEN/STIR를 등록했는데 왜 아직도 “Spam Likely”로 표시되나요?
SHAKEN/STIR는 발신자를 인증하지만 전화번호의 평판을 정하지는 않아요. 스팸 표시는 통화량, 수신자 신고, 발신 패턴, 분석 업체 데이터, 번호의 이전 사용 이력 같은 요인에 따라 달라질 수 있어요. 대상 미국 번호라면 평판 개선을 위해 **음성 정합성**을 확인해 보세요.

### A2P 등록을 완료하면 SHAKEN/STIR가 자동으로 활성화되나요?
조건을 갖춘 A2P 등록과 연결된 대상 전화번호는 SHAKEN/STIR에 자동으로 등록될 수 있어요. 현재 등록 상태는 **신뢰 센터**에서 확인할 수 있어요.
