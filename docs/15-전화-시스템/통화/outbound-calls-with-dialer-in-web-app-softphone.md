# 웹 다이얼러(소프트폰)로 발신 통화하기

브라우저에서 바로 발신 통화를 걸고, **발신 번호**를 고르고, 통화 중 기능을 쓰고, 통화를 전환하는 방법을 설명해요. 웹 다이얼러에서 자주 생기는 문제의 해결 방법도 함께 안내해요.

## 개요

웹 다이얼러(소프트폰)를 쓰면 지원되는 브라우저에서 바로 전화를 걸고 관리할 수 있어요. 전화번호를 직접 입력하거나, 연락처를 검색하거나, 최근 통화 번호를 고를 수 있어요. 사용 가능한 **발신 번호**를 선택하고, 하이퍼클래스를 벗어나지 않고 통화 중 기능도 쓸 수 있어요.

통화 품질은 번호 할당, 권한, 마이크와 오디오 장치 접근, 브라우저 설정, 네트워크 연결, 발신 통화 시간 제한에 따라 달라져요.

이 문서에서는 다음 내용을 다뤄요.

- 웹 다이얼러가 파워 다이얼러, 모바일 통화와 어떻게 다른지
- 발신 통화를 걸고 전환하는 방법
- **발신 번호**가 정해지는 방식
- 오디오, 발신자 번호 표시, 연결 문제를 해결하는 방법

{% hint style="warning" %}
웹 다이얼러가 내 목소리를 전달하려면 브라우저에서 마이크 사용을 허용해야 해요. 헤드셋, 스피커, VPN, 브라우저 확장 프로그램, 방화벽 규칙, 보안 프로그램도 통화 음질이나 연결에 영향을 줄 수 있어요.

통화를 녹음할 때는 녹음 안내 멘트를 바꾸거나 없애기 전에, 발신자·수신자·관련 지역에 적용되는 동의 및 고지 요건을 먼저 확인하세요.
{% endhint %}

## 웹 다이얼러(소프트폰)란?

웹 다이얼러는 하이퍼클래스의 브라우저 기반 통화 화면이에요. 별도의 유선 전화기나 하이퍼클래스 모바일 앱 없이 발신 통화를 걸고 관리할 수 있어요.

대부분의 페이지 상단 메뉴에 있는 초록색 전화 아이콘으로 다이얼러를 열 수 있어요. 다이얼러를 열면 다음 작업을 할 수 있어요.

- 번호를 직접 입력해요.
- 기존 연락처를 검색해요.
- 최근 통화를 확인해요.
- 통화 중에 다이얼패드를 써요.
- 설정해 둔 통화 스크립트를 열어요.
- 통화를 전환해요.
- 후속 정보를 기록해요.

웹 다이얼러는 데스크톱 브라우저나 지원되는 모바일 브라우저에서 쓸 수 있어요. 모바일에서 전용 환경으로 통화하려면 하이퍼클래스 모바일 앱을 사용하세요.

### 웹 다이얼러의 장점

웹 다이얼러는 통화 도구를 연락처 기록 가까이에 두어서, 앱을 오가는 시간을 줄이고 고객과의 대화에 더 집중할 수 있게 해 줘요.

- 브라우저로 통화: 별도의 전화기나 모바일 앱 없이 전화를 걸 수 있어요.
- 빠른 연락처 접근: 연락처를 검색하거나, 번호를 직접 입력하거나, **최근 대화**에서 바로 다시 전화할 수 있어요.
- 유연한 발신자 번호: 할당된 번호를 쓰거나, 권한이 있으면 허용된 다른 **발신 번호**를 고를 수 있어요.
- 통화 중 제어: 연결된 통화에서 음소거, 대기, 키패드, 전환을 쓸 수 있어요.
- 일관된 통화 처리: 통화 중이나 통화 후에 통화 스크립트, 메모, 태그, 연락처 정보를 볼 수 있어요.
- 통화 기록 한곳에서 관리: 발신 통화 이력과 관련 연락처 활동을 하이퍼클래스 안에 모아 둘 수 있어요.

### 웹 다이얼러, 파워 다이얼러, 모바일 통화 비교

세 가지 통화 방식은 같은 전화 시스템을 쓸 수 있지만, 쓰는 상황이 달라요. 알맞은 방식을 고르면 통화를 어디서 시작하고 연락처가 통화 대기열에 어떻게 들어오는지 이해하기 쉬워요.

| 통화 방식 | 작동 방식 | 이럴 때 좋아요 |
| --- | --- | --- |
| 웹 다이얼러 / 소프트폰 | 브라우저에서 다이얼러를 열고 연락처를 고르거나 전화번호를 직접 입력해요. | 개별 통화, 회신 전화, 특정 연락처 대상 연락 |
| **수동 작업** / **파워 다이얼러** | 워크플로우가 수동 통화 작업을 만들고, 이 작업이 **대화 > 수동 작업**에 나타나요. 사용자는 다이얼러로 할당된 대기열을 차례로 처리해요. | 체계적인 영업, 지원, 후속 통화 대기열 |
| 하이퍼클래스 모바일 앱 | 전용 모바일 앱에서 전화를 걸어요. | 데스크톱이나 브라우저 작업 환경에서 떨어져 있을 때 |

## 발신 통화 전에 준비할 것

통화 전에 짧게 확인해 두면 소리가 안 들리거나, 발신자 번호가 잘못 표시되거나, 상대가 받기 전에 통화가 끊기는 문제를 줄일 수 있어요.

- 사용 가능한 발신 번호: 할당된 번호가 있거나 사용할 수 있는 **발신 번호**에 접근 권한이 있는지 확인하세요.
- 올바른 사용자 권한: 사용자의 역할, 데이터 접근 범위, 연락처 접근 권한, 전화번호 할당을 확인하세요.
- 마이크 권한: 브라우저에서 마이크 사용을 허용하세요.
- 오디오 장치: 사용할 마이크, 스피커, 헤드셋을 선택하고 통화 전에 테스트하세요.
- 안정적인 네트워크: 안정적인 인터넷 연결을 쓰고, 불필요한 VPN이나 보안 라우팅은 피하세요.
- 발신 시간 제한: 전화번호의 **발신 통화 시간 제한**을 20초 이상으로 설정하세요.
- 녹음 규정 준수: 통화 녹음과 안내 멘트 설정이 관련 법률과 비즈니스 요건에 맞는지 확인하세요.

## 발신 번호 선택하기

**발신 번호**는 발신자 번호로 표시될 하이퍼클래스 번호를 정해요. 번호가 자동으로 선택될지, 다이얼러에서 직접 바꿀 수 있을지는 사용자 역할, 데이터 접근 범위, 번호 할당, 계정 접근 권한에 따라 달라요.

| 사용자 구성 | 발신 번호 동작 |
| --- | --- |
| **할당된 데이터만** 권한이 있는 사용자 역할 | 해당 할당이 있으면 발신 통화에 사용자에게 할당된 전화번호가 자동으로 쓰여요. |
| All Records(모든 레코드) 접근 권한이 있는 사용자 | **발신 번호** 드롭다운을 열어, 본인 계정과 권한으로 쓸 수 있는 전화번호 중에서 고를 수 있어요. |

### 사용자 역할과 데이터 접근 범위 확인하기

데이터 접근 범위에 따라 사용자가 할당된 데이터만 볼 수 있는지, 모든 레코드에 접근할 수 있는지가 정해져요. 다른 **발신 번호**를 고를 수 없거나 통화가 할당된 번호로 자동 발신된다면 이 설정을 확인하세요.

![사용자 역할과 권한 화면에서 사용자 역할과 할당된 데이터만 설정을 보여 주는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045947128/original/OPsybV0rDD4Ru3ln9VuYh1fn1O8j9RFLWg.png?1746053604=)

사용자 역할에 **할당된 데이터만** 권한이 설정된 사용자는 보통 본인에게 할당된 전화번호만 쓸 수 있어요.

### 발신 번호 드롭다운에서 번호 선택하기

적절한 권한이 있으면 **발신 번호** 드롭다운을 열어, 발신자 번호로 표시할 번호를 선택하세요.

![웹 다이얼러의 발신 번호 드롭다운 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045947177/original/5ljIoO6AWgEYanhVAj8Dk62VdyeWA3SsWg.png?1746053805=)

통화를 걸기 전에 **발신 번호**에서 알맞은 발신 번호를 선택하세요.

## 웹 다이얼러로 발신 통화 걸기

다이얼러에서는 직접 입력한 번호, 기존 연락처, 최근에 쓴 번호로 통화를 시작할 수 있어요. 의도한 비즈니스 번호로 걸리도록, 전화를 걸기 전에 **발신 번호**를 꼭 확인하세요.

1. 상단 메뉴에서 초록색 전화 아이콘을 클릭하세요.
2. **발신 번호**를 확인하고, 권한이 있으면 필요에 맞게 바꾸세요.
3. 다음 중 하나를 선택하세요.
   - **키패드**: 전화번호를 직접 입력해요.
   - **연락처**: 기존 연락처를 검색해서 선택해요.
   - **최근 대화**: 이전에 걸었거나 받은 번호를 선택해요.
4. 전화번호를 입력하거나 선택하세요.
5. 통화 버튼을 클릭해 전화를 거세요.
6. 통화가 연결된 뒤 IVR(자동 응답 전화 메뉴)에 키 입력을 보내야 하면 다이얼패드를 쓰세요.

![초록색 전화 아이콘으로 연 웹 다이얼러 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045946208/original/dIIfwMvTRPPPEuL6Zl10oKECU0mPgfgDtg.png?1746050609=)

초록색 전화 아이콘으로 웹 다이얼러를 열고, **발신 번호**를 선택한 뒤 **키패드**, **연락처**, **최근 대화** 중 하나를 고르세요.

다이얼러 작업 공간: 웹 다이얼러는 다른 곳을 클릭하면 자동으로 최소화될 수 있어요. 계속 보이게 하려면 고정하세요. 하이퍼클래스에서 작업하는 동안 화면의 다른 위치로 끌어 옮길 수도 있어요.

## 통화 중 기능 사용하기

통화가 연결되면 다이얼러에서 소리 차단, 통화 처리, 자동 응답 메뉴 조작, 다른 사용자나 전화번호로 통화 전환을 할 수 있어요.

| 기능 | 하는 일 |
| --- | --- |
| **음소거** | 내 마이크를 꺼서 상대방이 내 목소리를 듣지 못하게 해요. |
| **대기** | 통화를 대기 상태로 두어, 통화를 다시 이어 갈 때까지 양쪽 모두 상대방의 소리를 듣지 못해요. |
| **키패드** | IVR, 내선 번호, 컨퍼런스 코드, 자동 응답 메뉴에 쓰는 DTMF 키패드 신호를 보내요. |
| **통화 스크립트** | 사용할 수 있는 스크립트가 있으면 통화 중에 설정해 둔 통화 스크립트를 보여 줘요. |
| **전환** | 웜 트랜스퍼나 즉시 전환 방식으로 통화 중인 상대를 다른 사용자나 전화번호로 넘겨요. |

### 웜 트랜스퍼

**웜 트랜스퍼**를 쓰면 원래 통화 상대를 연결하기 전에 전환 받을 사람과 먼저 이야기할 수 있어요. 다음 담당자가 대화를 넘겨받기 전에 상황을 알아야 할 때 유용해요.

1. 통화가 연결된 상태에서 전환 관련 컨트롤을 여세요.
2. 다른 사용자를 검색하거나 전화번호를 직접 입력하세요.
3. **Call & Hold**(통화 & 대기)를 선택하면 원래 통화 상대가 대기 상태가 되고 전환 받을 사람에게 전화가 걸려요.
4. 전환 받을 사람과 이야기하며 필요한 상황을 전달하세요.
5. 다이얼러에 표시되는 최종 연결(패치) 또는 전환 옵션을 선택하면 두 사람이 연결되고 나는 통화에서 빠져요.

![웹 다이얼러의 웜 트랜스퍼 화면에서 Call & Hold 버튼이 보이는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045946585/original/9r03TLzUsFl7kYcgLvlhCpcmuTxkK2EyDA.png?1746051274=)

**Call & Hold**를 선택하면 전환 받을 사람과 이야기하는 동안 원래 통화 상대는 대기 상태로 있어요.

### 즉시 전환

**즉시 전환**은 전환 받을 사람과 먼저 이야기하지 않고 통화 상대를 바로 다른 사용자나 전화번호로 보내는 방식이에요. 전환이 끝나면 나는 통화에서 빠져요.

1. 통화가 연결된 상태에서 전환 관련 컨트롤을 여세요.
2. 사용자를 검색하거나 전환할 번호를 입력하세요.
3. **전달 & 종료**를 클릭하면 통화 상대가 해당 번호로 전달되고 내 통화는 종료돼요.

![웹 다이얼러의 즉시 전환 화면에서 전달 & 종료 버튼이 보이는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010495830/original/kkJck-tqalFEHANzgUMyCBsUrUBUwUAoXA.png?1697670632=)

**전달 & 종료**는 사전 통화 없이 통화 상대를 선택한 번호로 보내요.

## 발신 통화를 위한 웹 다이얼러 설정하기

브라우저와 전화번호 설정을 제대로 해 두면 다이얼러에서 가장 흔한 문제를 막을 수 있어요. 실제 고객 통화에 웹 다이얼러를 쓰기 전에 아래 단계를 모두 마치세요.

### 1단계: 브라우저에서 마이크 허용하기

하이퍼클래스 사이트에서 마이크를 허용해야 해요. Chrome에서는 주소창 왼쪽의 사이트 정보 아이콘을 클릭하고 **마이크**가 켜져 있는지 확인하세요.

![Chrome 사이트 정보 메뉴에서 하이퍼클래스의 마이크 권한이 허용된 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045947374/original/GHKokaA_r5Jo-VnwcM6lqShTa_14auVT9g.png?1746054454=)

브라우저의 사이트 정보 메뉴에서 마이크 접근을 허용하세요.

주소창에서 권한을 바꿀 수 없다면 브라우저의 사이트 권한 설정을 열어, **마이크**를 **차단**이나 **Ask**(묻기)에서 **허용**으로 바꾸세요.

![Chrome 사이트 설정에서 마이크 권한 옵션이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045947375/original/bY1_yjTWeOXmY7Li13V3_734_AUG90V5uw.jpeg?1746054454=)

브라우저 사이트 설정에서 마이크 접근을 초기화하거나 허용할 수 있어요.

### 2단계: 오디오 장치 선택하고 테스트하기

다이얼러의 **Audio Device Settings**(오디오 장치 설정)를 열고 사용할 마이크와 메인 스피커를 선택하세요. 테스트 기능과 마이크 입력 수준 표시가 있으면 실제 통화 전에 활용하세요.

[웹 다이얼러의 오디오 장치 설정 자세히 보기 →](../일반/audio-device-settings-in-the-web-dialer.md)

### 3단계: VPN과 브라우저 확장 프로그램 없이 테스트하기

VPN, 개인정보 보호 확장 프로그램, 광고 차단기, 보안 도구, 트래픽 라우팅 앱은 웹 다이얼러의 오디오나 연결 요청을 방해할 수 있어요. 확장 프로그램이 꺼진 시크릿 또는 게스트 브라우저 세션에서 잠시 테스트해 보세요.

![웹 다이얼러에 영향을 줄 수 있는 VPN과 보안 확장 프로그램이 보이는 Chrome 브라우저](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045947381/original/inaZmrkekmNgr6ZCyjHL6j4u6WHJe01wHw.png?1746054592=)

테스트할 때는 VPN이나 보안 확장 프로그램을 잠시 끄거나, 시크릿 또는 게스트 세션을 사용하세요.

### 4단계: 발신 통화 시간 제한 설정하기

전화번호의 **발신 통화 시간 제한**을 20초 이상으로 설정하세요. 시간 제한이 너무 짧으면 수신자의 통신사와 기기에서 벨이 울리기 전에 통화가 끊길 수 있어요.

1. **설정 > 전화 시스템 > 전화번호**로 이동하세요.
2. 해당 번호의 **구성 편집**을 여세요.
3. **발신 통화 시간 제한**을 켜세요.
4. **값을 입력하세요** 입력란에 20초 이상의 값을 입력하고 **저장**을 클릭하세요.

![수신 및 발신 통화 타임아웃 설정이 보이는 전화번호 구성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045947501/original/YAtV96DxqG5nYp8mx3fvRcSrRiaNm6GflQ.png?1746054859=)

스크린샷은 **통화 타임아웃** 항목이 있는 위치를 보여 줘요. 통화 방식에 맞는 값을 고르되, 발신 시간 제한은 20초 이상으로 유지하세요.

### 5단계: 테스트 통화 걸어 보기

직접 확인할 수 있는 전화기로 걸어 보세요. 다음 사항을 확인하세요.

- 수신자 기기에서 벨이 울려요.
- 의도한 발신자 번호가 표시돼요.
- 양쪽 모두 상대방의 소리가 들려요.
- 키패드가 작동해요.
- 필요할 때 통화를 대기로 두거나 전환할 수 있어요.

## 연결음과 링백톤 이해하기

전화를 시작한 직후 들리는 소리는 통신사 연결 단계에 따라 달라요. 소리의 차이를 알면 정상적인 연결 시간과, 목적지 통신망에 닿지 못한 통화를 구분하기 쉬워요.

1. 연결음: 하이퍼클래스가 수신자의 통신사에 연결을 시도하는 동안 짧은 연결음을 들려줘요.
2. 링백톤: 목적지 통신사가 수신자 기기에서 벨이 울리고 있다고 확인하면 링백톤이 시작돼요.
3. 지역별 링백톤: 지원되는 국가에서는 통화에 관련된 전화번호의 국가에 맞는 링백톤이 나올 수 있어요.
4. 통신사에 닿지 못한 경우: 목적지 통신사에 연결할 수 없으면, 실제로 울리지 않는 기기에 링백톤을 들려주는 대신 연결음 뒤에 통화가 끊길 수 있어요.

## 발신자 번호, 통화 녹음, 번호 평판

**발신 번호**는 발신 회선을 나타내요. CNAM, SHAKEN/STIR, **음성 정합성**은 통신사와 수신자가 그 번호의 신원과 평판을 판단하도록 도와요. 이 기능들은 목적이 서로 다르니 같은 것으로 보지 마세요.

| 기능 | 목적 | 알아 둘 한계 |
| --- | --- | --- |
| **발신 번호** | 발신 통화에 쓸 하이퍼클래스 전화번호를 선택해요. | 선택할 수 있는 번호는 번호 할당, 사용자 권한, 계정 구성에 따라 달라요. |
| CNAM | 미국 전화번호에 비즈니스 이름이나 개인 이름을 연결해요. | 표시는 보장되지 않고, CNAM으로 스팸 표시가 사라지지는 않아요. |
| SHAKEN/STIR | 발신자 번호 정보를 인증하고, 통신사가 정상 통화인지 판단하도록 도와요. | 인증이 되었다고 해서 스팸 표시가 반드시 사라지는 것은 아니에요. |
| **음성 정합성** | 조건에 맞는 미국 번호를 주요 발신자 번호 분석 업체에 등록해서 번호 평판을 높이고 스팸 표시에 대응해요. | 업체별 검토는 따로 진행되고, 표시가 바뀌어 각 통신망에 반영되기까지 시간이 걸릴 수 있어요. |

### 통화 녹음 안내

“This call will be recorded for quality purposes”(품질 관리를 위해 통화가 녹음돼요)라는 안내 멘트는 해당 전화번호의 **통화 녹음** 설정에서 관리해요. 확인하려면 **설정 > 전화 시스템 > 전화번호 > 구성 편집**으로 이동하세요.

화면에서 허용하면 이 안내 멘트를 수정하거나 끌 수 있어요. 하지만 녹음 절차가 모든 관련 동의 및 고지 요건을 충족하는지 확인하기 전에는 없애지 않는 것이 좋아요.

[전화번호 구성 옵션 자세히 보기 →](../overview-of-phone-number-configuration-options.md)

### 부재중 통화 후 나오는 음성 정합성 안내

웹 다이얼러에서 건 발신 통화를 상대가 받지 않으면, 하이퍼클래스가 **음성 정합성**을 추천하는 안내를 보여 줄 수 있어요. 이 안내에는 조건에 맞는 미국 전화번호의 평판과 응답률을 높이는 등록 도구로 바로 가는 바로가기가 있어요.

## 발신 통화 문제 해결

문제 해결은 사용자의 번호 접근 권한, 브라우저 권한, 오디오 장치, 네트워크 경로, 시간 제한 설정 순서로 점검하세요. 한 번에 한 가지씩 테스트하면 문제가 계정 설정, 브라우저, 목적지 통신사 중 어디에서 생기는지 알아내기 쉬워요.

### 다이얼러가 열리지 않거나 통화 버튼을 쓸 수 없어요

페이지를 새로 고치고, 해당 서브 계정에 대한 접근 권한이 있는지 확인하세요. 발신 통화에 쓸 수 있는 전화번호가 할당되어 있는지도 확인하세요. 사용자의 역할과 데이터 접근 범위도 살펴보세요.

### 상대방이 내 목소리를 듣지 못해요

브라우저에서 마이크 사용이 허용되어 있는지 확인하세요. **Audio Device Settings**에서 올바른 마이크가 선택되어 있는지, 마이크가 음소거되어 있지 않은지, 다른 앱이 마이크를 독점하고 있지 않은지도 확인하세요.

### 상대방의 소리가 들리지 않아요

올바른 메인 스피커나 헤드셋이 선택되어 있는지 확인하고 기기 볼륨을 점검하세요. 다른 출력 장치로도 테스트해 보세요. 브라우저가 이전에 쓰던 오디오 경로나 연결이 끊긴 경로를 쓰고 있다면 블루투스 기기를 다시 연결하세요.

### 상대방 벨이 울리기 전에 통화가 끊겨요

수신 번호가 올바른지 확인하세요. **발신 통화 시간 제한**을 20초 이상으로 설정하고, VPN, 개인정보 보호 확장 프로그램, 보안 프로그램 없이 테스트해 보세요. 연결음 직후 통화가 끊긴다면 목적지 통신사에 닿지 못했을 수 있어요.

### 엉뚱한 발신 번호로 전화가 걸려요

사용자에게 할당된 번호, 역할, **Data Visibility Scope**(데이터 가시성 범위), **발신 번호** 드롭다운을 확인하세요. **할당된 데이터만** 접근할 수 있는 사용자는 할당된 번호로 자동 발신될 수 있어요.

### 통화 소리가 지연되거나 끊기거나 불안정해요

안정적인 네트워크를 쓰고, 다른 곳에서 쓰는 대역폭을 줄이고, VPN 없이 테스트해 보세요. 가능하면 신뢰할 수 있는 헤드셋이나 유선 연결을 쓰세요. 지원되는 다른 브라우저나 기기에서도 결과를 비교해 보세요.

### 수신자에게 “Spam Likely”가 표시되거나 비즈니스 이름이 보이지 않아요

**신뢰 센터**에서 SHAKEN/STIR, CNAM, **음성 정합성**을 확인하세요. CNAM은 번호에 비즈니스 이름을 연결할 수 있지만, 이름이 표시된다고 보장하지는 않고 스팸 표시를 없애 주지도 않아요. 조건에 맞는 미국 번호의 평판을 등록하려면 **음성 정합성**을 이용하세요.

### 통화 전환이 완료되지 않아요

전환 대상 사용자나 전화번호가 올바른지 확인하세요. **웜 트랜스퍼**에서는 사전 통화가 연결될 때까지 기다린 뒤에 두 사람을 연결하세요. **즉시 전환**에서는 의도한 대상이 맞는지 확인한 뒤에만 **전달 & 종료**를 사용하세요.

## 자주 묻는 질문

### 모바일 브라우저에서도 웹 다이얼러를 쓸 수 있나요?

네. 브라우저 다이얼러는 지원되는 데스크톱 및 모바일 브라우저에서 작동할 수 있어요. 모바일에서 전용 통화 환경을 쓰려면 하이퍼클래스 모바일 앱을 사용하세요.

### 다른 발신 번호를 선택할 수 없어요. 왜 그런가요?

선택할 수 있는 **발신 번호**는 사용자의 역할, **Data Visibility Scope**(데이터 가시성 범위), 번호 할당, 계정 권한에 따라 달라요. **할당된 데이터만** 접근할 수 있는 사용자는 보통 할당된 번호로 자동 발신돼요.

### 웹 다이얼러와 파워 다이얼러는 같은 건가요?

아니요. 웹 다이얼러는 브라우저 통화 화면이에요. **파워 다이얼러**는 워크플로우가 만든 수동 통화 작업이 **대화 > 수동 작업**에 나타나고, 사용자가 대기열을 처리할 때 다이얼러가 열리는 방식이에요.

### 정상적인 벨소리 전에 연결음이 들리는 이유는 뭔가요?

연결음은 하이퍼클래스가 수신자의 통신사에 연결하는 동안 나와요. 통신사가 목적지 기기에서 벨이 울리고 있다고 확인하면 링백톤이 시작돼요.

### 부재중 통화 후에 음성 정합성 안내가 보이는 이유는 뭔가요?

웹 다이얼러에서 건 통화를 상대가 받지 않으면 하이퍼클래스가 **음성 정합성**을 추천할 수 있어요. 이 안내는 조건에 맞는 미국 번호의 스팸 표시에 대응하고 이후 응답률을 높이는 데 도움이 되는 평판 도구로 가는 바로가기예요.

### 통화 녹음 안내 멘트를 없애거나 바꿀 수 있나요?

녹음 안내 멘트는 전화번호의 **구성 편집** 화면에서 확인할 수 있어요. 녹음 절차가 관련 동의 및 고지 요건을 모두 충족하는지 확인하기 전에는 끄거나 바꾸지 마세요.

### 다이얼패드로 자동 응답 전화 메뉴를 조작할 수 있나요?

네. 통화가 연결된 상태에서 **키패드**를 열면 메뉴 선택, 내선 번호, 컨퍼런스 코드용 DTMF 신호를 보낼 수 있어요.

### 웹 다이얼러를 최소화하면 통화가 끊기나요?

아니요. 최소화하거나 자동으로 최소화되는 것은 다이얼러가 화면에 보이는 방식만 바꿀 뿐이에요. 통화는 끝내거나 연결이 끊어질 때까지 계속 유지돼요.
