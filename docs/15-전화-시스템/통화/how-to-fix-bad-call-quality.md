# 하이퍼클래스 통화 품질 문제 해결하기

소리가 끊기거나, 한쪽에만 들리거나, 통화가 끊기는 등 통화 품질 문제의 원인을 찾아 해결하는 방법을 안내해요.

통화 품질이 나쁘면 소리가 끊기거나 로봇 소리처럼 들려요. 한쪽에만 소리가 들리거나, 에코가 생기거나, 통화가 끊기거나, 말이 오가는 데 지연이 길어지기도 해요. 이런 증상은 대개 네트워크 불안정, 기기 설정 문제, 로컬 환경 문제에서 생겨요.

이 문서는 하이퍼클래스에서 통화 품질 문제를 찾아 해결하는 과정을 단계별로 안내해요.

{% hint style="info" %}
이 문서는 통화는 연결되지만 음질이 나쁘거나 불안정한 경우를 다뤄요. 통화가 계속 연결되지 않거나, 연결 즉시 끊기거나, 특정 오류 코드가 나타난다면 해당 통화 오류 해결 문서를 참고하세요.
{% endhint %}

## 통화 품질 문제란?

통화 품질 문제는 통화가 연결된 상태에서 생기는 음성 문제를 말해요. 대표적인 증상은 다음과 같아요.

- 소리가 끊기거나, 로봇 소리처럼 들리거나, 뭉개져 들려요.
- 한쪽에만 소리가 들려요. 내 쪽에서는 상대 소리가 들리는데 상대는 내 소리를 못 듣거나, 그 반대예요.
- 에코나 하울링이 생겨요.
- 말하는 사이에 지연이 길어요.
- 통화가 간헐적으로 끊기거나 갑자기 종료돼요.

하이퍼클래스 통화는 인터넷 연결을 사용해요. 그래서 네트워크 불안정, 기기 문제, 로컬 설정 문제가 통화 품질에 영향을 줄 수 있어요.

## 통화 품질 문제를 해결하면 좋은 점

통화 품질 문제를 해결하면 통화가 더 안정적이고, 고객과 팀 모두 더 나은 경험을 할 수 있어요.

- 통화 안정성 향상: 끊기는 통화가 줄고 대화가 더 매끄러워져요.
- 고객 경험 개선: 상담원의 말이 또렷하게 들리고, 대화가 반복해서 끊기지 않아요.
- 팀 생산성 향상: 통화 품질 문제를 점검하는 데 쓰는 시간이 줄어요.
- 놓치는 기회 감소: 중요한 고객 대화에서 소통이 더 안정적이에요.
- 전문적인 브랜드 이미지: 깨끗한 음질이 더 전문적인 통화 경험을 만들어요.

## 통화 품질 문제 해결 단계

아래 순서대로 점검하면서 통화 품질이 나빠진 원인을 찾아 해결해 보세요.

### 1단계. 문제 범위 확인하기

문제가 사용자 한 명, 기기 하나, 네트워크 하나에서만 생기는지, 아니면 계정의 모든 사용자에게 생기는지 확인하세요. 그러면 기기 문제인지, 네트워크 문제인지, 더 넓은 문제인지 좁히는 데 도움이 돼요.

### 2단계. 현재 네트워크 점검하기

가능하다면 Wi-Fi와 유선 연결, 또는 다른 안정적인 네트워크를 비교해 보세요. Wi-Fi에서 통화 품질이 나쁘다면, 가능할 때 유선 이더넷으로 같은 통화를 테스트해 보세요. 유선에서 문제없이 통화된다면 Wi-Fi 네트워크가 원인일 수 있어요.

### 3단계. 대역폭을 많이 쓰는 앱 끄기

스트리밍, 백업, 다운로드, VPN을 많이 쓰는 앱처럼 통화와 대역폭을 나눠 쓰는 작업을 잠시 멈추세요. 화상 회의, 클라우드 동기화, 대용량 파일 전송은 대역폭을 많이 차지해서 통화 품질을 떨어뜨릴 수 있어요.

### 4단계. 마이크와 헤드셋 확인하기

기기 설정이나 하이퍼클래스 통화 화면에서 올바른 마이크와 스피커가 선택되어 있는지 확인하세요. 다른 헤드셋이나 마이크가 있다면 바꿔서 테스트해 보세요. 하드웨어 상태가 좋지 않거나 입력/출력 장치를 잘못 선택하면 한쪽에만 소리가 들리거나 에코가 생길 수 있어요.

### 5단계. 통화 환경 새로고침하고 다시 시작하기

하이퍼클래스 웹 앱을 새로고침하고, 브라우저나 모바일 앱을 다시 시작하세요. 사용 중인 앱이 최신 버전인지도 확인하세요. 브라우저나 앱 버전이 오래되면 실시간 음성과 호환 문제가 생길 수 있어요.

### 6단계. 필요하면 네트워크 장비 다시 시작하기

장비의 전원을 껐다 켜면 일시적인 네트워크 문제가 해결될 수 있어요. 해당 네트워크 장비(공유기나 모뎀)의 전원을 뽑고 약 30초 기다린 뒤 다시 연결하세요. 연결이 완전히 복구된 후에 통화를 다시 테스트하세요.

### 7단계. 통화 품질 경고 확인하기

통화 중이나 통화 후에 **high-rtt**, **high-jitter**, **high-packet-loss**, **low-mos** 경고가 표시되는지 확인하세요. 이 경고는 어떤 네트워크·연결 문제가 있는지 알려 줘요. 자세한 내용은 아래 "통화 품질 경고 이해하기" 섹션을 참고하세요.

### 8단계. 연결 상태 테스트하기

인터넷 속도만으로는 통화 품질을 알 수 없어요. 업로드·다운로드 속도뿐 아니라 지연 시간(latency), 지터(jitter), 패킷 손실(packet loss), 연결 안정성도 함께 테스트하세요. 대역폭만이 아니라 네트워크 품질을 측정하는 도구를 쓰면 더 정확하게 진단할 수 있어요.

### 9단계. 문제가 계속되면 네트워크와 방화벽 설정 검토하기

회사 방화벽, VPN, 보안 소프트웨어, 제한적인 네트워크 정책이 실시간 음성을 방해할 수 있어요. 특정 관리형 네트워크에서만 통화 품질 문제가 생긴다면, IT 담당 팀에 하이퍼클래스의 음성 네트워크 요건을 검토해 달라고 요청하세요. 브라우저 확장 프로그램, VPN, 보안 도구, 커뮤니케이션 앱, 백그라운드 소프트웨어도 마이크 접근이나 네트워크 성능을 방해할 수 있어요. 충돌할 만한 것을 잠시 끄고 통화를 다시 테스트해 보세요.

### 10단계. 하이퍼클래스 고객지원에 문의하기

위 단계를 모두 해 봐도 문제가 계속되면, 문제가 생긴 통화 예시와 시각을 함께 하이퍼클래스 고객지원에 문의하세요. 필요한 정보는 아래 "하이퍼클래스 고객지원에 문의할 때" 섹션을 참고하세요.

## 통화 품질 경고 이해하기

하이퍼클래스는 네트워크 상태가 또렷한 음성을 유지할 수 있는 기준 아래로 떨어지면 통화 품질 경고를 보여 줘요. 이 경고로 통화 품질이 나빠진 원인을 파악할 수 있어요.

### 웹 앱 통화 품질 경고

웹 앱에서는 통화 중이나 통화 후에 다음 경고가 표시될 수 있어요.

![웹 앱 통화 품질 경고 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079995260/original/ql0KG04hQxAkVf9vUvtUrsbaVqGjYYT14A.jpeg?1788431600)

- **high-rtt**(높은 왕복 시간): 지연 시간(latency)이 높다는 뜻이에요. 음성이 오가는 경로의 지연을 측정한 값이고, 지연 시간이 높으면 대화 중에 눈에 띄는 지연이 생길 수 있어요.
- **high-jitter**(높은 지터): 패킷이 일정하지 않게 도착한다는 뜻이에요. 지터는 패킷 도착 시간의 편차를 말해요. 값이 낮을수록 대체로 음성이 안정적이고, 높은 지터가 계속되면 지직거리거나 로봇 소리처럼 들릴 수 있어요.
- **high-packet-loss**(높은 패킷 손실): 음성 패킷이 전송 중에 손실되고 있다는 뜻이에요. 패킷 손실은 목적지에 도착하지 못한 음성 패킷을 말해요. 이상적으로는 손실이 거의 없어야 하고, 손실이 계속되면 소리가 빠지거나 끊길 수 있어요.

### 모바일 앱 통화 품질 경고

모바일 앱에서는 통화 중이나 통화 후에 다음 경고가 표시될 수 있어요.

- **high-rtt**(높은 왕복 시간): 지연 시간(latency)이 높다는 뜻이에요. 음성이 오가는 경로의 지연을 측정한 값이고, 지연 시간이 높으면 대화 중에 눈에 띄는 지연이 생길 수 있어요.
- **high-jitter**(높은 지터): 패킷이 일정하지 않게 도착한다는 뜻이에요. 지터는 패킷 도착 시간의 편차를 말해요. 값이 낮을수록 대체로 음성이 안정적이고, 높은 지터가 계속되면 지직거리거나 로봇 소리처럼 들릴 수 있어요.
- **high-packet-loss**(높은 패킷 손실): 음성 패킷이 전송 중에 손실되고 있다는 뜻이에요. 패킷 손실은 목적지에 도착하지 못한 음성 패킷을 말해요. 이상적으로는 손실이 거의 없어야 하고, 손실이 계속되면 소리가 빠지거나 끊길 수 있어요.
- **low-mos**(낮은 MOS): 전체 통화 품질 점수가 기대 범위보다 낮다는 뜻이에요. MOS(Mean Opinion Score)는 통화 품질을 종합해 나타낸 점수예요. MOS가 낮으면 하나 이상의 요인 때문에 음질이 떨어졌다는 뜻이에요.

## 증상별로 확인할 곳

아래 표에서 겪고 있는 증상에 맞는 점검 영역을 찾아보세요.

| 증상 | 주로 확인할 곳 |
| --- | --- |
| 로봇 소리처럼 들리거나 소리가 끊겨요 | 지터, 패킷 손실, Wi-Fi 또는 네트워크 혼잡 |
| 말하는 사이에 지연이 길어요 | 지연 시간(latency) / RTT |
| 한쪽에만 소리가 들려요 | 마이크 권한, 기기 선택, 네트워크 또는 방화벽 |
| 에코가 생겨요 | 스피커/마이크 설정 또는 헤드셋 구성 |
| 통화가 간헐적으로 끊겨요 | 네트워크 불안정 또는 패킷 손실 |
| 한 명의 사용자만 문제가 있어요 | 기기, 브라우저/앱, 헤드셋 또는 로컬 네트워크 |
| 여러 사용자에게 문제가 있어요 | 공유 네트워크, 공유기/방화벽 또는 더 넓은 서비스 문제 |

## 하이퍼클래스 고객지원에 문의할 때

위 점검 단계를 모두 해 봐도 문제가 계속되면, 다음 정보를 정리해 하이퍼클래스 고객지원에 문의하세요.

- Location ID(서브 계정 ID)
- 문제를 겪는 사용자
- 예시 연락처 또는 전화번호
- 통화한 정확한 날짜와 시각
- 수신 통화인지 발신 통화인지
- 웹 앱인지 모바일 앱인지
- 당시 사용한 네트워크(Wi-Fi, 이더넷, 모바일 데이터)
- 표시된 **high-rtt**, **high-jitter**, **high-packet-loss**, **low-mos** 경고
- 문제를 다시 재현할 수 있는지

이 정보를 함께 보내 주시면 고객지원이 문제를 더 빠르고 정확하게 진단할 수 있어요.
