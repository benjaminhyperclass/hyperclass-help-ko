# 전화번호의 A2P 상태 태그 확인하기

미국에서 문자를 보내는 전화번호는 A2P 10DLC 규정에 따라 통신사에 등록해야 해요. 이제 계정의 각 전화번호 옆에 등록 상태를 알려 주는 태그가 표시돼요. 이 문서에서는 태그별 의미와 조치가 필요한지 설명해요.

## A2P 태그는 어디서 볼 수 있나요?

**설정 > 전화번호**로 이동하세요. 각 번호 옆에 A2P 태그가 표시되고, 현재 등록 상태를 보여 줘요.

- 번호 하나에는 A2P 태그가 한 번에 최대 하나만 붙어요.
- 상태가 바뀌면 태그도 자동으로 바뀌어요. 따로 새로 고침하지 않아도 돼요.

{% hint style="info" %}
번호에 태그가 아예 없다면, 아직 어떤 A2P 캠페인에도 등록되지 않은 번호예요. 아래 **태그 없음** 항목을 참고하세요.
{% endhint %}

## 상태 태그 한눈에 보기

빠르게 확인할 때는 이 표를 보세요. 태그별 자세한 내용은 다음 항목에서 설명해요.

| 태그 | 의미 | 필요한 조치 |
| --- | --- | --- |
| **A2P 인증됨** | 승인된 캠페인에 등록되어 문자를 보낼 수 있어요 | 없음 |
| **A2P In Progress**(진행 중) | 캠페인에 추가되어 통신사가 검토하고 있어요 | 없음 |
| **A2P Rejected**(거부됨) | 통신사가 문자 발송용으로 승인하지 않았어요 | 하이퍼클래스 고객지원에 문의 |
| **A2P Unlinking**(연결 해제 중) | 번호를 캠페인에서 제거했고, 통신사가 변경을 처리하고 있어요 | 없음 |
| **A2P Unlink Failed**(연결 해제 실패) | 통신사가 제거를 완료하지 못해서 번호가 여전히 등록된 상태예요 | 연결 해제를 다시 시도하고, 두 번 실패하면 하이퍼클래스 고객지원에 문의 |
| 태그 없음 | 어떤 A2P 캠페인에도 등록되지 않았어요 | **신뢰 센터**에서 승인된 캠페인에 연결 |

## 태그별 의미

각 상태가 어떤 뜻인지, 문자를 보낼 수 있는지, 무엇을 해야 하는지 알려 드려요.

### **A2P 인증됨**

번호가 승인된 캠페인에 등록되어 있어서 문자를 보낼 수 있어요.

조치는 필요 없어요.

### **A2P In Progress**

번호가 캠페인에 추가되었고, 통신사가 검토하고 있어요. 보통 24시간 안에 끝나지만, 통신사에 요청이 몰리는 시기에는 더 걸릴 수 있어요.

{% hint style="info" %}
검토가 끝나기 전에는 이 번호로 문자를 보낼 수 없어요. 따로 하실 일은 없어요.
{% endhint %}

### **A2P Rejected**

통신사가 이 번호를 문자 발송용으로 승인하지 않았어요. 번호가 캠페인의 사용 목적과 맞지 않거나, 캠페인 자체에 문제가 있을 때 주로 이런 일이 생겨요.

{% hint style="warning" %}
조치 필요: 하이퍼클래스 고객지원에 전화번호와 캠페인 세부 정보를 함께 보내 주세요. 팀에서 검토한 뒤 다시 제출해 드려요.
{% endhint %}

### **A2P Unlinking**

이 번호를 캠페인에서 제거했고, 통신사가 변경을 처리하고 있어요. 보통 24시간 안에 끝나요. 처리가 끝나면 태그가 사라지고, 번호에는 A2P 상태가 표시되지 않아요.

{% hint style="warning" %}
이 기간에는 번호로 문자를 보낼 수 없어요.
{% endhint %}

### **A2P Unlink Failed**

통신사가 제거를 완료하지 못했어요. 그래서 번호는 여전히 캠페인에 등록되어 있고, 문자도 계속 보낼 수 있어요.

해야 할 일: 번호 설정에서 연결 해제를 다시 시도하세요. 두 번째도 실패하면 하이퍼클래스 고객지원에 문의하세요.

### 태그 없음

번호가 어떤 A2P 캠페인에도 등록되지 않은 상태예요.

다음 단계: 이 번호로 문자를 보내려면 **신뢰 센터**에서 승인된 캠페인에 연결하세요.

## 자주 묻는 질문

### 한 번호에 A2P 태그가 여러 개 붙을 수 있나요?
아니요. 번호 하나에는 A2P 태그가 한 번에 최대 하나만 붙고, 항상 현재 상태를 보여 줘요.

### 태그를 직접 새로 고치거나 업데이트해야 하나요?
아니요. 상태가 바뀌면 태그가 자동으로 바뀌어요. **설정 > 전화번호**에서 언제든 확인할 수 있어요.

### A2P In Progress 상태는 얼마나 오래 가나요?
보통 24시간 안에 끝나지만, 통신사에 요청이 몰리는 시기에는 더 걸릴 수 있어요. 검토가 끝나기 전에는 이 번호로 문자를 보낼 수 없어요.

### A2P Rejected로 표시되면 고객지원에 무엇을 보내야 하나요?
전화번호와 캠페인 세부 정보를 보내 주세요. 팀에서 번호를 검토한 뒤 다시 제출해 드려요.

### A2P Unlinking 상태일 때도 문자를 보낼 수 있나요?
아니요. 통신사가 제거를 처리하는 동안에는 문자를 보낼 수 없어요. 보통 최대 24시간이 걸려요.

### A2P Unlink Failed로 표시돼요. 그래도 문자를 보낼 수 있나요?
네, 보낼 수 있어요. 제거가 완료되지 않아서 번호가 여전히 캠페인에 등록되어 있기 때문이에요. 번호 설정에서 연결 해제를 다시 시도하고, 두 번째도 실패하면 하이퍼클래스 고객지원에 문의하세요.

### 번호 연결을 해제했더니 태그가 사라졌어요. 정상인가요?
네, 정상이에요. 통신사가 제거 처리를 마치면 태그가 사라지고, 번호에는 A2P 상태가 표시되지 않아요. 이 번호로 다시 문자를 보내려면 **신뢰 센터**에서 승인된 캠페인에 연결하세요.
