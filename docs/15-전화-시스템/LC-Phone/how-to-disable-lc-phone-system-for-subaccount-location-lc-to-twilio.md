# 서브 계정의 하이퍼클래스 전화 시스템 비활성화하고 Twilio로 전환하기

서브 계정에서 하이퍼클래스 전화 시스템을 끄고 Twilio로 옮기는 절차를 안내해요. 전환하는 동안 전화번호를 잃지 않도록 순서대로 진행하세요.

## 비활성화 전에 확인할 것

### 1. 기존 전화번호를 계속 쓰려면 먼저 해제하세요

서브 계정의 하이퍼클래스 전화를 비활성화하기 전에, 계속 쓰려는 전화번호는 **Twilio 고객지원**에 문의해 하이퍼클래스 전화에서 해제해야 해요.

- 기존 전화번호를 계속 쓰려면, 하이퍼클래스 전화에서 Twilio로 바꾸기 전에 이 문서의 안내를 따라야 해요.
- 기존 전화번호를 유지할 필요가 없다면 2단계로 바로 가서 비활성화 요청 폼을 제출하면 돼요.

{% hint style="warning" %}
하이퍼클래스 전화를 비활성화하기 전에 전화번호를 해제하지 않으면, 그 번호는 영구적으로 사라져요.
{% endhint %}

### 2. Twilio 계정을 준비하세요

전환을 시작하기 전에 사용 중인 Twilio 계정이 있어야 해요. 하이퍼클래스와 연결하는 데 필요한 정보인 계정 SID와 Auth Token(인증 토큰)도 확인해 두세요.

## 하이퍼클래스 전화 시스템이란?

하이퍼클래스 전화 시스템은 플랫폼 안에서 바로 통화와 메시지를 쓸 수 있게 해 주는 내장 전화 서비스예요. 편리하지만, 전화 서비스를 직접 관리하려고 자체 Twilio 계정으로 바꾸려는 에이전시도 있어요.

자세한 내용은 [하이퍼클래스 전화 시스템이란?](../기타/what-is-lc-phone-system.md)을 참고하세요.

## 하이퍼클래스 전화 비활성화 시작하기

서브 계정에서 하이퍼클래스 전화 시스템을 비활성화하면 Twilio로 전화 서비스를 관리할 수 있어요. 전화번호를 잃지 않으려면 준비를 꼼꼼히 해야 해요. 기존 전화번호를 유지하려면 먼저 Twilio 고객지원에 문의해 번호를 해제하세요. 유지할 필요가 없다면 바로 비활성화 요청 폼을 제출하면 돼요.

### 1단계: 전화번호 해제하기 (필요한 경우)

유지하려는 기존 전화번호가 있다면, 비활성화하기 전에 하이퍼클래스 전화에서 해제해야 해요. 번호를 계속 쓰려면 반드시 거쳐야 하는 단계예요. 해제하지 않으면 번호가 영구적으로 사라져요.

1. Twilio 고객지원에 문의해 하이퍼클래스 전화에서 전화번호를 해제해 달라고 요청하세요.
2. [이 안내](../moving-us-numbers-from-twilio-to-hyperclass-lc.md)에 따라 번호 해제 절차를 마치세요.
3. 번호가 정상적으로 해제됐는지 확인한 뒤 다음 단계로 넘어가세요.

{% hint style="warning" %}
기존 번호를 유지할 필요가 없다면 이 단계를 건너뛰고 2단계로 바로 가세요.
{% endhint %}

### 2단계: 서브 계정의 위치 ID 확인하기

하이퍼클래스 전화를 비활성화할 서브 계정의 **위치 ID**를 먼저 확인해야 해요.

1. **설정 > 비즈니스 프로필**로 이동하세요.
2. **위치 ID**를 찾아 복사해 두세요. 나중에 폼에 입력해요.

![비즈니스 프로필 화면에서 위치 ID 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043047417/original/JXVARFyN3dAGT8mPq6TtipqbDehtF6bxvA.png?1741697994)

### 3단계: Twilio 인증 정보 확인하기

하이퍼클래스 전화를 비활성화하면 Twilio가 기본 전화 제공업체가 돼요. 그래서 Twilio의 **계정 SID**와 **Auth Token**(인증 토큰)이 필요해요.

1. Twilio 계정(Twilio Console)에 로그인하세요.
2. Twilio 대시보드 첫 화면의 Account Info에서 **계정 SID**와 **Auth Token**을 찾으세요.

![Twilio 대시보드의 계정 SID와 Auth Token](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043047852/original/dG7VuQOylrHPS2m5NEO8s-iG-mxIPKjuWA.png?1741698310)

### 4단계: 하이퍼클래스 전화 비활성화 요청 폼 제출하기

**위치 ID**, Twilio **계정 SID**, **Auth Token**을 모두 확인했다면 비활성화를 요청할 수 있어요. 요청 폼 링크는 하이퍼클래스 고객지원에 문의하세요.

1. 하이퍼클래스 전화 비활성화 요청 폼을 여세요.
2. 다음 항목을 입력하세요.
   - **Sub-Account ID**(서브 계정 ID, 위치 ID)
   - Twilio **계정 SID**
   - Twilio **Auth Token**(인증 토큰)
3. 폼을 제출하세요.

![하이퍼클래스 전화 비활성화 요청 폼 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043048303/original/FZGwYgkOf7QQ4A_mc2hJsg5Y0Y6SUM4zFQ.png?1741698536)

## 제출 후에는 어떻게 되나요?

폼을 제출하면 하이퍼클래스 고객지원팀이 요청을 검토하고, 하이퍼클래스 전화를 비활성화하는 데 필요한 절차를 진행해요. 추가 정보가 필요하거나 진행 상황에 변동이 있으면 폼에 입력한 이메일 주소로 연락드려요.

진행 중에 궁금한 점이 있거나 도움이 필요하면 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 하이퍼클래스 전화를 비활성화하기 전에 전화번호를 해제하지 않으면 어떻게 되나요?

번호가 영구적으로 사라져요. 진행하기 전에 [하이퍼클래스 전화 서브 계정으로 번호 옮기기](../moving-us-numbers-from-twilio-to-hyperclass-lc.md) 문서를 따라 하고, Twilio 고객지원에도 꼭 문의하세요.

### 여러 서브 계정의 하이퍼클래스 전화를 한 번에 비활성화할 수 있나요?

아니요. 서브 계정마다 따로 요청을 제출해야 하고, 요청은 각각 처리돼요.

### 비활성화가 처리되는 데 얼마나 걸리나요?

처리 시간은 경우에 따라 달라요. 처리가 끝나면 완료됐다는 안내를 받아요.

### Twilio로 바꾼 뒤에 다시 하이퍼클래스 전화로 돌아갈 수 있나요?

네, 돌아갈 수 있어요. 해당 서브 계정의 하이퍼클래스 전화를 다시 활성화해 달라고 하이퍼클래스 고객지원에 요청해야 해요.
