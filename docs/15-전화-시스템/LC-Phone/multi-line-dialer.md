# 멀티라인 다이얼러로 최대 3명에게 동시에 전화하기

멀티라인 다이얼러는 연락처 최대 3명에게 동시에 전화를 걸고, 가장 먼저 받은 사람과 바로 연결해 줘요. 신호음만 듣는 시간을 줄이고 싶을 때 쓰세요.

## 개요

발신 통화는 대부분 상대방이 받지 않아서, 팀이 하루 종일 신호음만 듣게 되곤 해요. 멀티라인 다이얼러는 최대 3명에게 동시에 전화를 걸고, 가장 먼저 받은 사람과 연결해 줘요.

통화 목록을 한 번 만들어 두고 시작 버튼만 누르면, 통화에만 집중할 수 있어요.

{% hint style="info" %}
**비공개 베타**
멀티라인 다이얼러는 비공개 베타 기능이에요. 계정에 보이지 않으면 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

## 작동 방식

- 동시에 전화를 걸 연락처 수를 **1명, 2명, 3명** 중에서 정해요.
- 다이얼러가 정한 수만큼 동시에 전화를 걸고, **가장 먼저 받은 사람**과 연결해 줘요.
- 누군가 전화를 받으면 나머지 통화는 바로 끊겨요.

{% hint style="info" %}
**예외 상황: 두 사람이 동시에 받은 경우**
두 번째로 받은 사람에게는 콜백 메시지가 나가요. 이 사람은 통화 목록 맨 위로 올라가서 다음에 전화할 상대가 돼요.
{% endhint %}

{% hint style="info" %}
**예외 상황: 전화벨이 울리다 끊긴 경우**
해당 연락처는 15분 동안 기다린 뒤에 다시 시도해요. 같은 연락처에서 이런 일이 두 번 생기면, 다음번에는 그 연락처에만 단독으로 전화를 걸어요. 그래서 부재중 전화가 계속 남지 않아요.
{% endhint %}

## 시작하기 전에

- 관리자가 켜 두어야 해요. 관리자가 계정에서 멀티라인 다이얼링을 켜기 전에는 꺼져 있어요.
- 콜백 메시지를 미리 준비해 두세요. 팀이 전화를 걸기 시작하기 전에 설정해야 해요. 한발 늦게 전화를 받은 두 번째 사람이 듣게 되는 메시지예요.
- 전화번호는 하이퍼클래스 전화번호로 발신되고, 평소의 발신 번호 설정을 그대로 따라요.
- 연락처에 전화번호가 있어야 해요. 전화번호가 없는 연락처는 건너뛰어요.

## 설정 가이드

기능을 켜고, 콜백 메시지를 녹음하고, 통화 목록을 만든 뒤 시작 버튼을 누르는 4단계로 끝나요.

### 멀티라인 다이얼링 켜기

1. **설정 > 전화 시스템**으로 이동하세요.
2. **음성** 탭을 선택하세요.
3. **기타 설정**에서 **발신 통화**를 선택하세요.
4. **Multi-line dialing**(멀티라인 다이얼링) 스위치를 켜세요.

![발신 통화 설정의 멀티라인 다이얼링 스위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254990/original/JgLOtw12KaKVrjDVCozXvNIc65QbSfeo3g.png?1793053277)

{% hint style="info" %}
**알아 두세요**
켜 두면 팀원마다 자기 다이얼러에서 사용할 회선 수를 직접 골라요. 이 스위치를 끄면 모든 팀원이 한 번에 한 통씩만 전화하는 방식으로 돌아가요.
{% endhint %}

### 콜백 메시지 설정하기

이미 다른 사람과 통화 중일 때 전화를 받은 사람에게 들려주는 메시지예요. 나중에 다시 전화하겠다고 알려 주고, 다이얼러가 그 약속대로 다음에 그 사람에게 전화를 걸어요.

**Callback message**(콜백 메시지)에서 두 가지 방법 중에 고를 수 있어요.

| 옵션 | 설명 |
| --- | --- |
| **문자** | 상대방에게 들려줄 내용을 500자까지 적고 **음성**을 고르세요. 전화 시스템이 통화에서 그 내용을 읽어 줘요. 지금은 영어만 지원해요. |
| **Upload audio**(오디오 업로드) | 직접 녹음한 파일을 올려요. |

설정을 마치면 **변경사항 저장**을 선택하세요. 메시지를 바꿔도 이미 신호음이 울리고 있는 통화에는 적용되지 않아요.

{% hint style="info" %}
**팁**
짧게 쓰고, 누구인지 밝히세요. 예를 들면 이렇게 쓸 수 있어요. *"Hi, this is Acme Marketing. Sorry we missed you just now. We'll call you back shortly, or you can reach us anytime at (205) 555-0147. Thank you!"*
{% endhint %}

{% hint style="warning" %}
**중요**
연락처가 있는 지역의 통화 관련 법규를 지킬 책임은 비즈니스에 있어요.
{% endhint %}

### 통화 목록에 연락처 추가하기

통화 목록은 **연락처** 또는 **기회 관리**(Opportunities)에서 만들 수 있어요. 어느 쪽이든 목록에 보이는 순서대로 연락처가 추가돼요. 다이얼링 중에도 언제든 더 추가할 수 있어요.

**방법 A: 연락처에서 추가하기**

1. **연락처**로 이동하세요.
2. 전화할 연락처를 선택하세요. 특정 그룹만 고르고 싶으면 먼저 필터나 검색을 사용하세요.
3. **더보기 > 통화**를 선택하세요.

**방법 B: 기회 관리에서 추가하기**

1. **기회 관리**로 이동하세요.
2. 오른쪽 위의 목록 아이콘을 눌러 목록 보기로 바꾸세요. 보드 보기에는 **통화** 작업이 없어요.
3. 전화할 기회를 선택하세요.
4. 나타나는 바에서 **통화**를 선택하세요.

{% hint style="info" %}
**참고**
기회는 주 연락처의 전화번호로 전화해요. 연락처에 전화번호가 없는 기회는 건너뛰어요.
{% endhint %}

### 다이얼링 시작하기

1. 상단 바의 전화 아이콘을 눌러 다이얼러를 여세요.
2. **통화 목록** 탭을 선택하세요. 탭의 배지에 대기 중인 연락처 수가 표시돼요.
3. **동시 발신**에서 **연락처 1명**, **연락처 2명**, **연락처 3명** 중에서 고르세요.
4. **다이얼링 시작**을 선택하세요.

![동시 발신 선택과 다이얼링 시작 버튼이 있는 다이얼러의 통화 목록 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084255021/original/mwVYaROWD0anhuRy7xABJau8carfXNQ78A.png?1793053361)

{% hint style="info" %}
**준비 끝!**
통화가 끝나면 통화 결과(disposition)를 선택하세요. 그러면 다이얼러가 알아서 다음 연락처로 넘어가요. 라운드 사이에는 동시에 전화할 연락처 수를 바꿀 수 있어요.
{% endhint %}

## 통화 목록에 표시되는 항목

| 항목 | 의미 |
| --- | --- |
| **다음** | 다이얼러가 순서대로 전화할 연락처예요. 맨 위의 행이 항상 다음에 걸 전화예요. |
| **Waiting**(대기 중) | 지금은 전화할 수 없는 연락처예요. 각 행에 이유와 전화할 수 있게 되는 시점이 표시돼요. 예: "Quiet hours, opens in 4h 15m". 이 연락처들은 시간이 되면 자동으로 **다음** 목록의 맨 끝에 다시 들어가요. |
| 연락처에 마우스를 올렸을 때 | 그 사람에게 바로 단독으로 전화하거나 목록에서 뺄 수 있어요. |
| **Clear**(비우기) | 목록 전체를 비워요. 연락처 자체는 바뀌지 않아요. |

{% hint style="info" %}
**알아 두세요**
세션 도중에 다이얼러를 닫으면 목록이 일시 중지되고, 그 사실이 화면에 안내돼요. **다이얼링 시작**을 선택하면 멈춘 곳부터 이어서 진행해요.
{% endhint %}

## 자주 묻는 질문

### 누군가 전화를 받으면 나머지 통화는 어떻게 되나요?
바로 끊겨요. 그래서 다른 사람이 전화기를 든 채 기다리는 일은 없어요. 이미 벨이 울리기 시작한 연락처는 15분을 기다린 뒤에 다시 시도해요.

### 두 사람이 동시에 전화를 받으면 어떻게 되나요?
먼저 받은 사람과 연결돼요. 두 번째 사람에게는 콜백 메시지가 나가고, 이 사람은 통화 목록 맨 위로 올라가요. 그래서 다음에 전화할 상대가 돼요.

### 연락처가 왜 Waiting 목록에 있나요?
그 연락처가 있는 지역이 통화를 걸 수 없는 시간대(Quiet hours)이거나, 최근에 벨이 울렸다 끊겨서 15분 대기 중이라서 그래요. 둘 중 어느 쪽인지, 언제 전화할 수 있게 되는지는 해당 행에 표시돼요. 필요하면 그 행에서 바로 전화를 걸 수도 있어요.

### 팀원마다 다른 회선 수를 쓸 수 있나요?
네. 멀티라인 다이얼링을 쓸 수 있는지는 관리자 설정으로 정해져요. 그다음에 팀원이 각자 다이얼러에서 1, 2, 3 중에 고르고, 라운드 사이에 바꿀 수도 있어요.

### 꼭 3개 회선을 써야 하나요?
아니요. 처음이라면 1개나 2개로 시작해 보세요. 회선이 많을수록 한 시간에 더 많은 사람에게 연락할 수 있지만, 그만큼 내가 아닌 콜백 메시지를 듣는 연락처도 늘어나요.

### 다이얼링 중에도 연락처를 추가할 수 있나요?
네. **연락처**나 **기회 관리**에서 언제든 더 추가할 수 있어요. 선택한 순서대로 통화 목록에 들어가요.

### 세션 도중에 다이얼러를 닫으면 어떻게 되나요?
통화 목록이 일시 중지되고, 그 사실이 화면에 안내돼요. **다이얼링 시작**을 다시 선택하면 멈춘 곳부터 이어서 진행해요.
