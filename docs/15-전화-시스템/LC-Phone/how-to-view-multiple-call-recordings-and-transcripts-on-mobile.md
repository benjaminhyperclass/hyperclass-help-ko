# 모바일에서 여러 통화 녹음과 대화 내용 기록 보기

하이퍼클래스 모바일 앱에서는 통화 하나에 연결된 녹음을 각각 확인할 수 있어요. 통화가 전환되었거나 여러 구간으로 나뉘어 녹음이 여러 개 생긴 경우에 특히 유용해요. 녹음을 하나씩 재생할 수 있고, 대화 기록이 있으면 **대화**에서 함께 볼 수 있어요.

## 모바일의 여러 통화 녹음이란?

통화가 전환되거나 여러 단계로 이어지면 녹음이 둘 이상 생길 수 있어요. 이전에는 첫 번째 녹음만 보였지만, 이제 하이퍼클래스 모바일 앱은 통화에 연결된 녹음을 모두 보여 줘요. 녹음은 **최근 대화**, 연락처의 **통화 상세정보**, **대화**에서 확인할 수 있어요.

## 주요 이점

- **전체 통화 기록 확인:** 통화에 연결된 모든 녹음을 볼 수 있어요. 전환 후에 생긴 녹음도 포함돼요.
- **녹음별 재생:** 녹음을 하나씩 재생하면서 통화의 각 부분을 따로 들어 볼 수 있어요.
- **녹음 위치 표시:** "1 of 3"처럼 지금 선택한 녹음이 몇 번째인지 표시돼요.
- **녹음별 대화 기록:** 대화 기록이 있으면 **대화**에서 녹음마다 따로 볼 수 있어요.

## 모바일에서 여러 통화 녹음 확인하기

1. 하이퍼클래스 모바일 앱을 엽니다.
2. 아래 위치 중 한 곳으로 이동합니다.
   - **최근 대화:** 최근 통화 기록에서 해당 통화를 찾아요.
   - 연락처의 **통화 상세정보**: 연락처에 연결된 통화 상세정보를 열어요.
   - **대화:** 녹음된 통화가 있는 대화를 열어요.
3. 녹음이 여러 개 있는 통화를 찾습니다.

   ![여러 녹음이 있는 통화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084850947/original/e6sYLOo7t0ThHKIYZHgNP33LFEJ8c7iyfg.png?1793714621)
4. 확인하려는 녹음을 선택합니다.
5. 녹음을 재생합니다.

통화에 녹음이 여러 개 있으면 앱에 "1 of 3"처럼 위치 표시가 나타나 선택한 녹음이 어느 것인지 알려 줘요.

## 녹음별 대화 기록 보기

**대화**에서는 백엔드에서 대화 기록을 제공하는 경우 녹음마다 각자의 대화 기록을 볼 수 있어요.

1. 모바일 앱에서 **대화**를 엽니다.
2. 녹음된 통화가 있는 대화를 찾습니다.
3. 통화를 열고 확인하려는 녹음을 선택합니다.
4. 선택한 녹음의 대화 기록이 있으면 확인합니다.

{% hint style="info" %}
선택한 녹음에 대화 기록이 있을 때만 표시돼요.
{% endhint %}

## 자주 묻는 질문

### 통화가 전환된 뒤에 생긴 녹음도 볼 수 있나요?

네. 모바일 앱은 통화에 연결된 모든 녹음을 보여 줘요. 이어진 통화 구간의 녹음도 포함돼요.

### 여러 녹음은 어디에서 볼 수 있나요?

**최근 대화**, 연락처의 **통화 상세정보**, **대화**에서 볼 수 있어요.

### 녹음마다 대화 기록이 따로 있나요?

**대화**에서는 녹음마다 대화 기록이 있을 수 있어요. 단, 백엔드에서 해당 기록을 제공하는 경우에 한해요.

### "1 of 3"은 무슨 뜻인가요?

선택한 녹음이 통화에 연결된 녹음 세 개 중 첫 번째라는 뜻이에요.

### 통화에 녹음이 하나뿐이면 어떻게 보이나요?

이번 개선 이전과 똑같이 표시돼요.
