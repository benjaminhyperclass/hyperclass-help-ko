# 전화 시스템 API 키는 변경하거나 삭제하지 마세요 (Non ISV/BYOT)

**전화 시스템** 계정에 자동으로 만들어지는 **API 키**는 통화와 메시지가 끊기지 않게 해 주는 키예요. 이 키를 수정하면 팀 전체의 서비스가 중단될 수 있어요.

## 누구를 위한 안내인가요?

하이퍼클래스에 기본으로 들어 있는 전화 시스템을 쓰는 서브 계정 사용자를 위한 안내예요. 전화번호와 통화 기능을 하이퍼클래스를 통해 관리하고 있다면 이 안내가 해당돼요.

## 한눈에 보기

계정에는 보안 API 키가 여러 개 들어 있어요. 이 키는 수정, 재생성, 교체(로테이션), 삭제를 하지 마세요. 그렇게 하면 하이퍼클래스가 키를 복구해 줄 때까지 통화와 메시지 기능이 중단될 수 있어요. 키를 바꿔야 한다고 생각되면 먼저 하이퍼클래스 고객지원에 문의하세요.

## API 키란 무엇인가요?

하이퍼클래스 시스템이 전화 서비스에 연결될 때 쓰는 보안 신분증 같은 거예요. 전화를 걸거나 받을 때, 사진 메시지를 보낼 때마다 이 신분증이 보이지 않는 곳에서 쓰여요. 요청이 실제로 내 계정에서 온 것인지 확인하는 용도예요.

이 키는 직접 관리하지 않아도 돼요. 하이퍼클래스가 설정하고 뒤에서 계속 유지하기 때문에 전화 기능을 그대로 쓸 수 있어요.

## 키를 바꾸면 왜 문제가 생기나요?

이 키가 있어야 계정이 전화 서비스에 연결돼요. 키가 바뀌거나 삭제되면 시스템이 그 연결을 더 이상 확인할 수 없어요. 그러면 이 연결에 의존하는 모든 기능이 새 키가 만들어져 동기화될 때까지 작동하지 않아요.

{% hint style="warning" %}
같은 키를 계정 전체가 함께 쓰기 때문에 서비스 중단은 한 명이 아니라 팀 전체에 영향을 줄 수 있어요.
{% endhint %}

## 키가 바뀌면 어떤 기능이 멈추나요?

키를 수정, 재생성, 삭제하면 아래 서비스가 영향을 받아요. 아래 목록 외의 서비스도 영향을 받을 수 있어요.

| 서비스 | 이렇게 보여요 |
| --- | --- |
| 앱 내 다이얼러 / 소프트폰 | 다이얼러가 연결되지 않아서 다이얼러로 전화를 걸거나 받을 수 없어요. |
| 발신 통화 | 웹 앱과 모바일 앱에서 거는 전화가 연결되지 않아요. |
| 수신 통화 | 수신 전화가 앱으로 울리지 않을 수 있어요. |
| 사진 / MMS 메시지 | 이미지를 보내지 못하거나 대화에서 이미지가 불러와지지 않을 수 있어요. |
| 모바일 앱 통화 | 모바일 앱의 통화 기능이 중단돼요. |
| 전체 전화 시스템 | 키가 복구되어 다시 동기화될 때까지 전화 시스템에 일반적인 오류가 보일 수 있어요. |

## 이렇게 하세요

### 해야 할 것

- 키를 그대로 두세요. 키를 계속 작동하게 하려고 따로 할 일은 없어요.
- 보안이나 규정 준수 때문에 키를 변경, 교체, 제거해야 한다고 생각되면 먼저 하이퍼클래스 고객지원에 문의하세요. 서비스가 끊기지 않게 안전하게 처리해 드려요.

### 하지 말아야 할 것

- 자동으로 만들어진 키를 직접 재생성, 교체, 수정, 삭제하지 마세요.

## 이미 키를 바꿨다면

키를 바꾼 뒤 통화나 메시지가 되지 않는다면 하이퍼클래스 고객지원에 문의하세요. 대부분은 키를 다시 만들어 동기화해서 서비스를 빠르게 복구할 수 있어요.

{% hint style="info" %}
변경해도 안전한지 확실하지 않다면 변경하기 전에 먼저 문의하세요. 서비스 중단을 고치는 것보다 미리 막는 편이 훨씬 나아요.
{% endhint %}

## 자주 묻는 질문

### 이 키를 직접 설정하거나 관리해야 하나요?

아니요. 하이퍼클래스가 자동으로 만들고 관리해요. 전화 기능을 계속 쓰려고 설정하거나 교체하거나 갱신할 일은 없어요.

### 실수로 키를 재생성하거나 삭제하면 어떻게 되나요?

키가 복구되어 다시 동기화될 때까지 통화와 사진 메시지 기능이 작동하지 않아요. 하이퍼클래스 고객지원에 문의하면 키를 다시 만들어 드려요.

### 키를 바꾸면 저 한 명에게만 영향이 있나요, 팀 전체에 있나요?

계정 전체에 영향이 있어요. 같은 키를 모든 통화와 메시지가 함께 쓰기 때문에, 키를 바꾼 사람뿐 아니라 계정의 모든 사용자의 서비스가 중단될 수 있어요.

### 보안이나 규정 준수 때문에 키를 교체해야 해요. 어떻게 하나요?

먼저 하이퍼클래스 고객지원에 필요한 내용을 알려 주세요. 서비스가 끊기지 않게 키를 안전하게 교체하고 모든 설정을 다시 동기화해 드려요.

### 연결된 전화 계정을 닫거나 연결을 끊으면 키도 사라지나요?

네. 연결된 전화 계정을 삭제하거나 닫으면 키도 함께 사라져서 통화와 메시지가 중단돼요. 그렇게 하려는 중이라면 먼저 고객지원에 확인하세요.

### 키를 고친 뒤 서비스가 얼마나 빨리 복구되나요?

대부분 빠르게 복구돼요. 고객지원에서 키를 다시 만들어 동기화하면 다이얼러, 통화, 사진 메시지가 다시 작동해요.
