# 전화 시스템 요금 및 청구 안내

하이퍼클래스 전화 시스템의 전체 요금 구조를 정리한 문서예요. 전화번호 임대, SMS/MMS 메시징, 음성 통화, 통신사 전달 요금, A2P 등록 요금을 다뤄요. 요금은 Twilio 요금과 같아요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

모든 금액은 미국 달러(USD) 기준이에요.

전화번호를 구매하려면 'How to Purchase a Phone Number' 문서를 참고하세요. 수신자 부담 번호(Toll-Free)를 구매하려면 'How to buy a toll free number' 문서를 참고하세요.

## 전화번호

모든 전화번호는 매달 요금이 청구돼요. 미국/캐나다 요금은 아래와 같아요.

| 번호 유형 | 월 요금 |
| --- | --- |
| 지역 번호 | 월 $1.15 |
| 수신자 부담 번호 | 월 $2.15 |

{% hint style="info" %}
그 외 국가의 요금은 이 문서 하단에 첨부된 국가별 요금 파일을 참고하세요.
{% endhint %}

## A2P 요금

저볼륨(Low Volume), 고볼륨(High Volume) 캠페인의 A2P 브랜드 및 캠페인 등록 요금이에요.

| 유형 | 일일 세그먼트 한도 | 월 캠페인 요금 | 1회성 등록 요금 |
| --- | --- | --- | --- |
| 개인 사업자 | 하루 3,000세그먼트 | 캠페인당 최대 $2.10 | $22.50 ($3 패스트트랙 포함) |
| 저볼륨(LV) | 하루 6,000세그먼트 | 캠페인당 $1.50 ~ $10.50 | $22.50 ($3 패스트트랙 포함) |
| 고볼륨(HV) | 하루 600,000세그먼트 | 캠페인당 $10.50 | $64.00 ($3 패스트트랙 포함) |

{% hint style="warning" %}
- 캠페인을 제출하면 검토 결과와 상관없이 1회성 등록 요금과 월 캠페인 요금이 모두 부과되기 시작해요.
- 계속 진행하고 싶지 않다면 캠페인을 삭제하세요. 이후 월 요금이 청구되지 않아요.
- $3 패스트트랙 요금은 환불되지 않으며, 캠페인 검토 속도를 높여 줘요.
- 2026년 2월 1일부터 A2P 캠페인 재제출은 무료예요. 기존 $15 재제출 요금은 없어졌어요.
{% endhint %}

## 통신사 전달 요금과 재청구

일부 통신 상품은 통신사 전달 요금(pass-through charges)으로 분류돼요. 이 요금에는 서브 계정(location) 단위로 고정 5%가 가산돼요. 재청구가 활성화된 경우에만 적용돼요.

### 5% 가산이 붙는 요금은 무엇인가요?

| 분류 | 설명 |
| --- | --- |
| A2P 등록 요금 | 1회성 브랜드 등록, 캠페인 등록, 매월 반복되는 캠페인 요금 |
| SMS 통신사 수수료 | 수신·발신 SMS에 이동통신사가 부과하는 추가 요금 |
| MMS 통신사 수수료 | 수신·발신 MMS에 이동통신사가 부과하는 추가 요금 |
| 인증된 발신자 번호(Verified Caller ID) | 인증된 발신자 번호 서비스와 관련된 요금 |
| RCS 메시징 통신사 수수료 | RCS(Rich Communication Services) 메시징과 관련된 통신사 수수료 |

### 재청구는 어떻게 적용되나요?

에이전시에서 재청구를 활성화했다면 위 분류에 5% 가산이 적용돼요.

- 재청구 활성화: 기본 요금 → 서브 계정 +5% 가산
- 재청구 비활성화: 재청구 가산이 붙지 않아요.

예시 (기본 SMS 통신사 수수료 $10.00, 에이전시 재판매 배수 2배)

| 항목 | 재청구 활성화 | 재청구 비활성화 |
| --- | --- | --- |
| 기본 통신사 수수료 | $10.00 | $10.00 |
| 서브 계정 5% 가산 ($10.00 × 1.05) | $10.50 | $10.00 |
| 에이전시 재청구 ($10.50 × 2) | $21.00 | — |
| 서브 계정에 청구되는 최종 금액 | $21.00 | $10.00 |

### 재청구는 어디서 설정하나요?

에이전시 관리자는 **에이전시 보기 > 재판매 > 핵심 서비스**에서 재청구를 설정해요. 이 화면에서 할 수 있는 일은 다음과 같아요.

- 지원되는 서비스의 **재판매 금액**(재청구 배수)을 설정해요.
- **마켓플레이스 앱**의 사용자 지정 요금을 설정해요.
- 서브 계정이 지원되는 상품에 내는 요금을 관리해요.

### 핵심 정리

- 재청구가 활성화되어 있으면 위 분류에는 서브 계정 단위로 항상 5% 가산이 적용돼요.

## 번호 인텔리전스

번호 인텔리전스는 세 가지 기능을 묶은 것으로, 한꺼번에 켜고 꺼요. 자세한 내용은 'Number Intelligence — Number Validation, Spam Detection, and Unknown Caller' 문서를 참고하세요.

![번호 인텔리전스 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074921397/original/BjtQ36oYFNcmxgwnzeDrTp947lm9jNgt5A.png)

- **Number Validation**(번호 유효성 검사) — 통화당 $0.005: SMS를 보내기 전에 번호가 유효한지 확인해요. 유효하지 않으면 SMS를 보내지 않아요.
- **Spam Detection**(스팸 감지) — 검사당 $0.005: 미국 수신 전화를 받으면 스팸인지 검사해요. 통과하지 못하면 "스팸 의심"으로 표시해요.
- **Name Lookup**(이름 조회) — 조회당 $0.01: 미국 수신 전화를 받았을 때 번호가 연락처에 연결되어 있지 않거나 연락처 이름이 비어 있으면 발신자 이름을 조회해요.
- **Number Format Lookups**(번호 형식 조회): 통화를 지원하기 위한 번호 형식 조회는 모두 무료예요.

## 자주 묻는 질문

### 수신 SMS에도 요금이 부과되는 이유가 뭔가요?
전화 시스템은 수신 SMS와 발신 SMS에 같은 요금을 부과해요.

### 서브 계정을 전화 시스템으로 옮겨도 SaaS 재청구가 되나요?
네, 전화 시스템에서도 SaaS 재청구가 계속 적용돼요.

### 10% 할인이 적용되는 항목은 무엇인가요?
- 전화번호: 미국과 캐나다만 해당하고, 모든 번호 유형에 적용돼요.
- SMS: 미국/캐나다에서 미국/캐나다로 보내는 경우만 해당하고, 수신과 발신 모두 적용돼요.
- 음성 통화: 미국/캐나다에서 미국/캐나다로 거는 경우만 해당하고, 수신과 발신 모두 적용돼요. 음성 통화 추가 요금에 나온 항목은 제외돼요.

### 통화를 하지 않았는데 바로 $20가 청구됐어요. 정상인가요?
네, 정상이에요. 지갑 잔액이 지갑 구성기(wallet configurator)에서 정한 기준 금액 아래로 떨어지자마자 자동으로 충전됐어요.

![지갑 구성기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074921482/original/fRdWrXrG4mZyZYHUrBkJuFzpnuX9Y_1eMg.png)

### SMS를 보내다 오류가 나도 요금이 청구되나요?
메시지가 전화 제공업체로 넘어가기 전에 내부 오류가 나면 요금이 청구되지 않아요. 하지만 전달을 시도한 메시지는 최종 전달 상태와 상관없이 모두 요금이 청구돼요. 수신자 부담 번호, A2P 번호, 국가 제한 때문에 전달할 수 없는 메시지도 마찬가지예요. 전달되지 않은 SMS는 환불되지 않아요.

### 최근에 통화를 녹음하지 않았는데 통화 녹음 저장 요금이 청구돼요. 왜 그런가요?
이전에 녹음한 파일을 포함해 저장된 통화 녹음이 있으면 저장 요금이 계속 발생해요. 이 요금은 서브 계정별로 매일 청구돼요. 요금을 막으려면 **설정 > 전화번호 > 고급 설정 > 음성 통화 > 통화 녹음**에서 오래된 녹음이 자동으로 삭제되게 설정하세요. 또는 삭제 기간을 1일로 설정하고 앞으로의 통화는 녹음하지 않도록 끄세요.

![통화 녹음 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074920889/original/3QRuC0klOSV2enbNRc8_wM_gz53n8JTg3g.png)

### 통화를 전환하지 않았는데 모든 발신 통화에 컨퍼런스 콜 요금이 부과되는 이유가 뭔가요?
발신 통화 흐름이 지연 없이 매끄럽게 전환되도록 설계되어 있기 때문이에요. 기본 통화 흐름에 따라 모든 발신 통화에서 컨퍼런스 콜이 시작돼요.
