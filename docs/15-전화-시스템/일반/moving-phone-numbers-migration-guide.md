# 전화번호 이동 가이드 — 마이그레이션과 포팅 중 알맞은 방법 고르기

전화번호 한 개 또는 VoIP 번호 전체를 하이퍼클래스 전화, Twilio, 하이퍼클래스 서브 계정, 외부 통신사 사이에서 옮길 때 어떤 방법을 쓸지 정하는 가이드예요. 먼저 내 상황을 표에서 찾고, 안내된 상세 문서를 따라 진행하세요.

## 개요

업무용 전화번호를 옮기는 방법은 두 가지예요. 지원되는 전화 환경 사이에서 옮기는 **마이그레이션**과 외부 통신사에서 가져오는 **포팅**이에요. 방법마다 필요한 계정 조건, 서류, 소요 기간, 규정 준수 사항이 달라서 처음에 올바른 방법을 고르는 것이 중요해요.

이 가이드는 하이퍼클래스 전화 → Twilio, Twilio → 하이퍼클래스 전화, 하이퍼클래스 전화 → 하이퍼클래스 전화, 같은 에이전시 안에서 번호 이동, 외부 통신사·VoIP에서 하이퍼클래스로 포팅하는 경우를 한곳에서 안내해요. 여러 개 또는 대량의 VoIP 번호를 옮기는 경우도 함께 다뤄요.

{% hint style="warning" %}
마이그레이션이나 포팅이 완료되었다고 확인되기 전에는 기존 제공업체에서 전화번호를 삭제, 해제, 비활성화, 연결 해제, 해지하지 마세요. 서비스가 끊기거나 번호 이동이 실패할 수 있어요.
{% endhint %}

하이퍼클래스 고객지원이 진행하는 계정 간 이동(하이퍼클래스 전화 → Twilio, Twilio → 하이퍼클래스 전화, 서로 다른 에이전시 간 하이퍼클래스 전화 → 하이퍼클래스 전화)에는 Twilio 지원 티켓을 따로 만들 필요가 **없어요**. 다만 이 가이드의 모든 경우가 같은 절차를 따르는 것은 아니에요.

## 전화번호 마이그레이션·포팅 가이드란?

이 가이드는 현재 제공업체, 이동할 곳, 계정 관계, 국가, 번호 유형에 따라 기존 전화번호를 어떻게 옮겨야 하는지 판단하도록 도와줘요. 모든 이동을 하나의 절차로 처리하지 않고, 내 상황에 맞는 방법으로 안내해 줘요.

하이퍼클래스 전화와 Twilio 사이의 마이그레이션, 같은 에이전시와 다른 에이전시 간 이동, 외부 통신사나 VoIP 제공업체에서 하이퍼클래스로 하는 포팅을 다뤄요. 여러 번호를 한꺼번에 옮길 때 요청 전에 준비할 정보도 정리해 두었어요.

### 알맞은 방법을 고르면 좋은 점

요청을 보내기 전에 이동 유형을 파악하면 불필요한 통신사 조율, 서류 누락, 잘못된 이동 대상 정보, 피할 수 있었던 지연을 막을 수 있어요. 번호가 옮겨진 뒤 무엇을 다시 설정해야 하는지도 알 수 있어요.

- **정확한 이동 경로:** 시작하기 전에 전화 시스템 간 마이그레이션인지 통신사 포팅인지 구분해요.
- **지연 감소:** Account SID, **위치 ID**, 통신사 기록, 청구 서류, 규제 정보를 미리 모아 두세요.
- **대량 이동 계획:** 여러 VoIP 번호를 실제로 적용되는 절차에 맞게 나눠 정리해요.
- **전환 준비:** 기존 서비스를 유지한 채, 실제 통화·메시지 트래픽을 바꾸기 전에 확인 계획을 세워요.
- **규정 준수 준비:** 이동한 뒤 A2P 10DLC, 수신자 부담(Toll-Free) 번호 인증, 해당 국가의 국제 규제 요건을 확인해요.

### 마이그레이션과 포팅은 뭐가 다른가요?

마이그레이션과 포팅은 둘 다 기존 전화번호를 그대로 유지하지만, 이동 유형이 달라요. 어느 쪽인지에 따라 앱 안의 도구, 하이퍼클래스 고객지원, 통신사 포팅 절차 중 무엇을 쓸지가 정해져요.

| 이동 유형 | 의미 | 예시 |
| --- | --- | --- |
| **마이그레이션** | 호환되는 전화 환경 또는 계정 구조 사이에서 지원되는 번호를 옮겨요. | 하이퍼클래스 전화 → Twilio, Twilio → 하이퍼클래스 전화, 하이퍼클래스 전화 → 하이퍼클래스 전화 |
| **포팅** | 통신사 간에 번호를 옮겨요. 통신사 명의 정보나 승인이 필요해요. | 외부 VoIP 통신사, 유선 통신사, 무선 통신사 또는 Twilio가 아닌 다른 제공업체 → 하이퍼클래스 |

## 내 상황에 맞는 이동 방법 찾기

번호가 지금 어디에 있고 어디로 가야 하는지부터 확인하세요. 서류를 모으거나 고객지원에 문의하기 전에, 아래 표에서 어떤 절차가 맞는지 확인할 수 있어요.

| 상황 | 이동 유형 | 기본 절차 |
| --- | --- | --- |
| **경우 1: 하이퍼클래스 전화 → Twilio** | 마이그레이션 | 하이퍼클래스 고객지원이 계정 간 이동을 진행해요. |
| **경우 2: Twilio → 하이퍼클래스 전화** | 마이그레이션 | 하이퍼클래스 고객지원이 계정 간 이동을 진행해요. |
| **경우 3: 하이퍼클래스 전화 → 하이퍼클래스 전화 (서로 다른 에이전시)** | 마이그레이션 | 하이퍼클래스 고객지원이 에이전시 간 이동을 진행해요. |
| **경우 4: 하이퍼클래스 전화 → 하이퍼클래스 전화 (같은 에이전시)** | 앱 내 이동 | 이동 가능한 미국·캐나다 번호는 **번호 이동**을 사용해요. |
| **Twilio → Twilio (같은 마스터 Twilio 계정)** | 앱 내 이동 | 다른 조건을 충족하면 **번호 이동**을 사용해요. |
| **외부 통신사 / VoIP 제공업체 → 하이퍼클래스** | 포팅 | 가능하면 미국 포트인 절차를 쓰고, 그렇지 않으면 해당하는 수동·국제 포팅 절차를 따라요. |

## 이동 전에 준비할 것

필요한 정보는 지원되는 전화 환경 사이에서 옮기는지, 다른 통신사에서 포팅하는지에 따라 달라요. 시작하기 전에 올바른 식별 정보를 준비하면 불필요한 문의가 줄고, 포트 요청이 반려될 가능성도 낮아져요.

| 상황 | 준비할 것 |
| --- | --- |
| **하이퍼클래스 전화 → Twilio** | 받는 쪽 Twilio Account SID, 현재 번호가 있는 하이퍼클래스 **위치 ID**, 전화번호, 희망하는 전환 시간대 |
| **Twilio → 하이퍼클래스 전화** | 보내는 쪽 Twilio Account SID, 이동할 하이퍼클래스 **위치 ID**, 전화번호, 희망하는 전환 시간대 |
| **하이퍼클래스 전화 → 하이퍼클래스 전화 (서로 다른 에이전시)** | 이동할 곳의 **위치 ID**, 가능하면 현재 번호가 있는 **위치 ID**, 전화번호, 희망하는 전환 시간대. 하이퍼클래스 전화 간 이동에는 보통 Twilio Account SID가 필요하지 않아요. |
| **같은 에이전시 안에서 번호 이동** | 관리자 권한, 이동 전·이동 후 서브 계정, 호환되는 전화 제공업체, 이동 가능한 미국·캐나다 번호 |
| **국제 마이그레이션** | 전화번호, 국가, 번호 유형, 해당 **위치 ID**, 국가와 번호 유형에 따라 필요한 경우 규정 번들 SID / Address SID |
| **외부 통신사 / VoIP 포팅** | 통신사 계정 정보, 서비스 주소, 승인 담당자, 청구 서류, 번호 목록, 이동할 **위치 ID**, 해당하는 경우 무선 PIN/패스코드 |

{% hint style="info" %}
전화번호는 가능하면 **E.164 형식**으로 입력하세요. 예를 들어 미국 번호는 **+1XXXXXXXXXX** 형태로 써요.
{% endhint %}

## 여러 개 또는 대량의 VoIP 번호 옮기기

VoIP 번호 전체를 옮길 때는 먼저 그 번호들이 이미 하이퍼클래스 전화나 Twilio에 있는지, 다른 VoIP 통신사에 있는지 확인하세요. 이에 따라 마이그레이션인지 포팅인지, 필요한 서류·한도·소요 기간이 정해져요.

| 대량 이동 상황 | 현재 안내 |
| --- | --- |
| **같은 에이전시의 이동 가능한 번호** | **번호 이동**은 한 번에 최대 **10개**까지 옮길 수 있어요. 남은 번호는 이동을 추가로 진행하세요. |
| **계정 간 하이퍼클래스 전화 / Twilio 마이그레이션** | 이동 가능한 번호 여러 개를 하이퍼클래스 고객지원 요청 하나에 담을 수 있어요. 이동 전·이동 후 계정과 전체 번호 목록을 분명히 적어 주세요. |
| **이동 가능한 미국 앱 내 포트인** | 유선 번호는 여러 개를 함께 입력할 수 있고, 무선 번호도 여러 개를 요청에 추가할 수 있어요. |
| **수동 / 외부 VoIP 포팅** | 전체 번호 목록을 E.164 형식으로 보내고, 통신사 명의 서류와 계정 정보도 함께 제출하세요. |

### 대량 VoIP 포팅 준비 체크리스트

정보를 깔끔하게 정리해 두면 계정 정보 하나가 틀려서 전체 포팅이 늦어지는 일을 막을 수 있어요. 외부 VoIP 제공업체의 번호를 제출하기 전에 아래 내용을 정리하세요.

- 모든 번호를 E.164 형식으로 적으세요.
- 각 번호가 유선, 무선, 로컬 VoIP, 수신자 부담(Toll-Free) 중 무엇인지 구분하세요.
- 현재 통신사 또는 VoIP 제공업체를 확인하세요.
- 통신사 계정 번호를 확인하세요.
- 통신사에 등록된 그대로 법적 고객명/사업자명과 서비스 주소를 확인하세요.
- 필요한 무선 PIN 또는 패스코드를 모으세요.
- 이동할 하이퍼클래스 **위치 ID**를 확인하세요.
- 최신 청구서 또는 인정되는 다른 통신사 명의 서류를 준비하세요.
- 포팅이 완료되었다고 확인될 때까지 기존 계정과 번호를 그대로 유지하세요.

### 수동 포팅 서류

표준 앱 내 절차로 처리할 수 없는 미국 번호는 수동 포팅 때 추가 서류가 필요할 수 있어요. 기존 통신사가 자기 기록과 대조해 요청을 검증하기 때문에 통신사 정보를 정확하게 쓰는 것이 특히 중요해요.

- **서명된 위임장(Letter of Authorization, LOA)**
- 발행일로부터 90일이 지나지 않은 **최신 청구서**
- E.164 형식의 **전화번호 목록**
- 이동할 **위치 ID**
- **통신사 계정 번호**
- 해당하는 경우 **무선 PIN / 패스코드**

**포팅이 끝나기 전에는 기존 통신사를 해지하지 마세요.** 통신사 포팅이 끝나고 하이퍼클래스에서 수신·발신 통화를 확인할 때까지 전화번호를 활성 상태로 유지하세요.

## 상황별 이동 절차

이동 전·이동 후 환경을 확인했다면, 해당하는 절차만 따르세요. 외부 통신사 포팅에 마이그레이션 절차를 쓰거나, 하이퍼클래스 전화 계정 이동에 포팅 절차를 쓰면 불필요하게 지연될 수 있어요.

### 경우 1: 하이퍼클래스 전화 → Twilio

하이퍼클래스 전화에서 관리하는 번호를 고객 본인의 Twilio 계정으로 옮길 때 쓰는 방법이에요. 지원되는 계정 간 마이그레이션을 하이퍼클래스 고객지원이 진행해요.

1. 받는 쪽 **Twilio Account SID**를 확인하세요.
2. 번호가 현재 있는 하이퍼클래스 **위치 ID**를 확인하세요.
3. 모든 전화번호를 E.164 형식으로 준비하세요.
4. 국제 번호라면 국가와 번호 유형에 따라 필요한 규제 정보를 준비하세요.
5. 전체 마이그레이션 요청을 하이퍼클래스 고객지원에 보내세요.

[전화번호 계정 간 이동 문서 보기 →](../moving-phone-numbers-across-accounts-us-and-international.md)

### 경우 2: Twilio → 하이퍼클래스 전화

번호가 현재 고객의 Twilio 계정에 있고, 이를 하이퍼클래스 전화를 쓰는 서브 계정으로 옮길 때 쓰는 방법이에요.

1. 보내는 쪽 **Twilio Account SID**를 확인하세요.
2. 이동할 하이퍼클래스 **위치 ID**를 확인하세요.
3. 모든 전화번호를 E.164 형식으로 준비하세요.
4. 필요한 경우 해당하는 국제 규제 정보를 준비하세요.
5. 마이그레이션 요청을 하이퍼클래스 고객지원에 보내세요.

[전화번호 계정 간 이동 문서 보기 →](../moving-phone-numbers-across-accounts-us-and-international.md)

### 경우 3: 서로 다른 에이전시 간 하이퍼클래스 전화 → 하이퍼클래스 전화

한 하이퍼클래스 에이전시의 서브 계정에 있는 하이퍼클래스 전화 번호를 다른 에이전시의 하이퍼클래스 전화 서브 계정으로 옮길 때 쓰는 방법이에요. 하이퍼클래스 고객지원이 진행하는 계정 간 마이그레이션이에요.

1. 이동할 곳의 **위치 ID**를 확인하세요.
2. 가능하면 현재 번호가 있는 **위치 ID**도 확인하세요.
3. 전화번호 목록을 준비하세요.
4. 필요한 경우 해당하는 국제 규제 정보를 준비하세요.
5. 마이그레이션 요청을 하이퍼클래스 고객지원에 보내세요.

**서로 다른 에이전시 간 하이퍼클래스 전화 → 하이퍼클래스 전화 이동에는 보통 Twilio Account SID가 필요하지 않아요.**

[전화번호 계정 간 이동 문서 보기 →](../moving-phone-numbers-across-accounts-us-and-international.md)

### 경우 4: 같은 에이전시의 서브 계정 간 번호 이동

같은 에이전시 안에서 이동할 수 있는 번호는 계정 간 이동용 고객지원 절차를 거치지 않아요. **번호 이동** 도구는 같은 에이전시 안의 하이퍼클래스 전화 → 하이퍼클래스 전화, 그리고 같은 마스터 Twilio 계정 아래의 Twilio → Twilio 이동을 위한 도구예요.

1. **에이전시 설정 > 전화 연동 > 서브 계정 설정**으로 이동하세요.
2. **번호 이동**을 클릭하세요.
3. 이동 전 서브 계정과 이동 후 서브 계정을 선택하세요.
4. 한 번에 이동 가능한 전화번호를 **최대 선택** 10개까지 고르세요.
5. 이동할 곳을 확인하고 이동을 완료하세요.

[서브 계정 간 번호 이동 문서 보기 →](../moving-numbers-across-sub-accounts-same-agency.md)

### 경우 5: 외부 통신사 또는 VoIP 제공업체에서 번호 포팅

번호가 지원되는 하이퍼클래스 전화/Twilio 마이그레이션 경로 밖의 통신 제공업체에 있을 때는 포팅을 사용해요. 미국 번호는 앱 안의 **번호 이동(포트인) 번호** 절차를 쓸 수 있어요. 지원되지 않는 미국 상황과 국제 번호는 별도의 포팅 절차를 따라요.

#### 이동 가능한 미국 앱 내 포트인

현재 앱 내 절차는 에이전시 소유자와 에이전시 관리자가 **실험실**을 통해 사용할 수 있어요. 이동 가능한 미국 포트 요청을 제출하고 진행 상황을 추적할 수 있어요.

1. **실험실**에서 해당 기능을 켜세요.
2. **전화 시스템 > 전화번호**로 이동하세요.
3. **번호 추가 > 번호 이동(포트인) 번호**를 클릭하세요.
4. 통신사, 번호, 승인 담당자, 서비스 주소 정보를 입력하세요.
5. 청구서를 업로드하세요.
6. 요청을 제출하고 Request SID를 저장하세요.
7. 승인 담당자가 자동 생성된 LOA에 서명하도록 하고, **번호 이동(포트인) 번호**에서 진행 상황을 확인하세요.

[포트인 번호 요청 제출 및 추적 문서 보기 →](../전화번호/how-to-submit-and-track-port-in-number-requests.md)

[포팅 옵션: 미국 앱 내 방식과 국제 수동 방식 문서 보기 →](../전화번호/porting-options-us-in-app-vs-international-manual-process.md)

## 이동 중과 이동 후에 알아둘 것

소요 시간과 통신사 조율은 계정 마이그레이션과 통신사 포팅이 크게 달라요. 모든 경우에 같은 소요 시간이나 보장된 전환 시점이 있다고 생각하고 계획하지 마세요. 이동 후 도착지에서 확인이 끝날 때까지 기존 서비스를 유지하세요.

| 절차 | 현재 안내 |
| --- | --- |
| **계정 간 마이그레이션** | 하이퍼클래스 고객지원이 필요한 정보를 모두 받은 뒤 영업일 기준 약 **1~2일**이 걸려요. 국제 이동이나 규제 확인이 필요한 이동은 더 걸릴 수 있어요. |
| **같은 에이전시 번호 이동** | 앱 내 **번호 이동** 절차로 완료돼요. 완료 즉시 이동한 곳을 확인하세요. |
| **외부 통신사 포팅 — 번호 50개 미만** | 필요한 서류를 제출한 뒤 약 **2~4주**가 걸려요. |
| **대규모 / 복잡한 포팅** | 통신사와 복잡도에 따라 약 **6~8주**가 걸려요. |
| **수동 포팅 전환** | 승인 후 통신사가 Firm Order Commitment(FOC) 기간을 알려 줘요. 정확한 시각이나 당일 일정은 보장되지 않아요. |

## 마이그레이션·포팅 후 확인 체크리스트

번호가 이동한 곳에 보인다고 해서 통화 연결, 메시지 등록, 규정 준수, 자동화 설정이 모두 준비된 것은 아니에요. 마이그레이션을 마무리하거나 이전 제공업체를 해지하기 전에 이동한 번호를 테스트하세요.

1. 모든 번호가 올바른 이동 후 계정에 표시되는지 확인하세요.
2. 관련 없는 다른 전화번호로 수신 테스트 통화를 걸어 보세요.
3. 대표 번호 또는 번호 그룹별로 발신 테스트 통화를 걸어 보세요.
4. 메시지가 켜져 있다면 SMS 수신과 발신을 테스트하세요.
5. 담당자, 음성사서함, 링 그룹, 워크플로우를 포함해 통화 연결과 착신 전환 설정을 검토하세요.
6. 이전 번호 배정을 참조하는 워크플로우와 자동화를 검토하세요.
7. SMS에 의존하기 전에 해당하는 미국 10자리 로컬 번호의 A2P 10DLC를 확인하세요. ([A2P 캠페인 등록 단계별 가이드](../A2P-등록/a2p-campaign-registration-step-by-step-guide-and-faqs.md))
8. 해당하는 수신자 부담(Toll-Free) 번호에서 미국 또는 캐나다 수신자에게 SMS/MMS를 보내기 전에 수신자 부담 번호 인증을 확인하세요. ([수신자 부담 번호 인증 가이드](../전화번호/toll-free-number-verification-guide-for-lc-phone-us-canada.md))
9. 국가와 번호 유형별로 해당하는 국제 규제 요건을 확인하세요.
10. 포팅이 완전히 끝나고 번호가 정상 작동하는 것을 확인한 뒤에만 이전 통신사를 해지하세요.

**과거 데이터:** 전화번호를 이동하거나 포팅해도 연락처, 대화 기록, 분석 데이터, 과거 녹음, 음성사서함 자료가 새 계정이나 새 전화 환경으로 자동 이동하지 않아요. 보관해야 할 자료는 기존 계정 접근이 사라지기 전에 내보내거나 다운로드하세요.

## 전화번호 이동 문제 해결

이동 문제는 대부분 잘못된 절차 선택, 통신사 기록 불일치, 지원되지 않는 계정 관계, 누락된 규제 요건, 이동 후 메시지 설정 문제에서 생겨요. 요청을 다시 제출하기 전에 아래에서 증상에 맞는 원인을 확인하세요.

### 번호 이동을 사용할 수 없어요

두 서브 계정이 같은 에이전시에 속해 있는지, 전화 환경이 호환되는지, 번호가 이동 가능한 미국·캐나다 번호인지 확인하세요. 앱 내 이동에서 Twilio 번호는 같은 마스터 Twilio 계정 아래에 있어야 해요.

### 포트 요청이 반려됐어요

서비스 주소 불일치, 잘못된 계정 번호, 유효하지 않은 무선 PIN, 서명되지 않은 LOA, 정지된 통신사 계정, 현재 요건을 충족하지 못하는 청구 서류가 흔한 원인이에요. 다시 제출하기 전에 기존 통신사에서 정보를 확인하세요.

### 국제 번호를 이동할 수 없어요

국제 번호는 국가와 번호 유형에 따라 이용 가능 여부와 필요한 서류가 달라요. 계속 진행하기 전에 이동할 곳의 규제 요건, Address 정보, 해당하는 **규정 번들**을 확인하세요.

### 번호는 이동했는데 SMS가 안 돼요

이동한 곳의 A2P 10DLC 등록, 수신자 부담(Toll-Free) 번호 인증, SMS 권한, 국가별 메시지 요건을 검토하세요. 번호 이동이 성공해도 메시지 규정 준수가 자동으로 완료되지는 않아요.

### 번호는 이동했는데 통화가 엉뚱하게 연결돼요

이동한 곳에서 착신 전환, 담당자, 음성사서함, 수신 통화 연결, IVR/워크플로우 참조, 그 밖의 번호별 설정을 검토하세요.

## 자주 묻는 질문

### VoIP 번호를 마이그레이션해야 하는지 포팅해야 하는지 어떻게 알 수 있나요?

번호가 이미 하이퍼클래스 전화나 지원되는 Twilio 환경에 있다면 보통 마이그레이션 경로를 따라요. 다른 외부 VoIP 또는 통신 사업자에 있다면 포팅 절차를 사용하세요.

### VoIP 번호를 한꺼번에 모두 옮길 수 있나요?

이동 유형에 따라 달라요. 같은 에이전시의 **번호 이동**은 한 번에 이동 가능한 번호를 최대 10개까지 지원해요. 계정 간 마이그레이션은 이동 가능한 번호 여러 개를 고객지원 요청 하나에 담을 수 있어요. 이동 가능한 미국 포트인 요청도 유선과 무선 번호를 여러 개 포함할 수 있어요.

### 계정 간 마이그레이션은 보통 얼마나 걸리나요?

지원되는 일반적인 계정 간 마이그레이션은 하이퍼클래스 고객지원이 필요한 정보를 모두 받은 뒤 영업일 기준 약 1~2일이 걸려요. 국제 이동이나 규제 확인이 필요한 이동은 더 걸릴 수 있어요.

### 외부 통신사 포팅은 얼마나 걸리나요?

현재 안내로는 번호 50개 미만의 포트 요청은 약 2~4주, 규모가 크거나 복잡한 포팅은 약 6~8주가 걸려요. 통신사 검토와 서류 상태에 따라 일정이 달라질 수 있어요.

### 포트 요청을 제출한 뒤 기존 전화 제공업체를 해지해도 되나요?

아니요. 포팅이 완료되었다고 확인되고, 이동한 곳에서 통화와 메시지를 테스트할 때까지 전화번호와 기존 통신사 계정을 유지하세요.

### A2P 10DLC 등록도 전화번호와 함께 자동으로 이동하나요?

자동으로 이동한다고 가정하지 마세요. 이동한 곳의 **A2P 등록**을 확인하고, 해당하는 미국 로컬 번호가 승인된 올바른 캠페인에 연결되어 있는지 SMS를 보내기 전에 확인하세요.

### 수신자 부담(Toll-Free) 번호 인증도 자동으로 이동하나요?

인증이 자동으로 이전된다고 가정하지 마세요. 미국 또는 캐나다 수신자에게 SMS나 MMS를 보내기 전에 수신자 부담 번호의 인증 상태를 확인하세요.

### 연락처, 대화, 녹음, 음성사서함도 번호와 함께 이동하나요?

아니요. 번호를 이동해도 연락처, 대화, 분석 데이터, 과거 통화 녹음, 음성사서함 자료는 다른 계정이나 전화 환경으로 자동 이동하지 않아요.

### 국제 전화번호도 이동하거나 포팅할 수 있나요?

국제 마이그레이션과 포팅은 국가, 번호 유형, 통신사에 따라 가능 여부가 달라요. **규제 번들**, Address 정보, 증빙 서류 또는 국가별 요건이 필요할 수 있어요. 국제 포팅은 하이퍼클래스 고객지원에 문의하세요.
