# 웹·앱 다이얼러에서 통화 스크립트 만들고 사용하기

통화 스크립트는 상담원이 통화 중에 바로 열어 볼 수 있는 말하기 가이드예요. 이 문서에서는 서브 계정에서 통화 스크립트를 만들고 관리하는 방법과, 상담원이 웹 다이얼러나 하이퍼클래스 모바일 앱에서 스크립트를 열어 따라 하는 방법을 안내해요.

{% hint style="info" %}
이 기능은 웹 다이얼러, 앱 다이얼러, 하이퍼클래스 모바일 앱에서 사용할 수 있어요.
{% endhint %}

## 통화 스크립트란?

통화 스크립트는 연락처와 통화하는 동안 필요할 때 바로 볼 수 있는 대화 가이드예요. 승인된 화법, 탐색 질문, 적격 판단 기준, 이의 제기 대응 방법, 규정 준수 문구 등을 담을 수 있어요. 상담원은 탭을 옮기거나 별도 메모를 찾지 않고도 일관되게 통화할 수 있어요.

## 통화 스크립트의 장점

통화 스크립트는 반복해서 쓸 수 있는 화법을 제공해 팀의 소통 품질을 높이고, 신규 팀원이 더 빨리 적응하도록 도와요.

- 메시지를 일관되게 유지해요: 자주 나오는 상황마다 반복해서 쓸 수 있는 화법을 상담원에게 제공해요.
- 온보딩이 빨라져요: 신규 팀원이 승인된 탐색·적격 판단 절차를 따라 할 수 있어요.
- 화면 전환이 줄어요: 외부 메모나 문서를 열지 않고 다이얼러 안에서 가이드를 볼 수 있어요.
- 통화 구성이 좋아져요: 상담원이 중요한 질문, 이의 제기 대응, 다음 단계를 빠짐없이 다루도록 도와요.
- 규정 준수에 도움이 돼요: 해당 통화에서 참고할 수 있는 승인된 문구를 제공해요.

## 통화 스크립트 만들기

통화 스크립트는 기존 업무 흐름에 맞춰 쉽게 만들 수 있어요. 아래 순서대로 따라 하면 상담원이 필요한 때에 맞는 스크립트를 열 수 있어요.

1. 서브 계정에 로그인한 뒤 **설정**을 클릭하세요.

   ![설정 메뉴](https://jumpshare.com/share/rCL4O7JdW3kUkHJbD0QY+/Screen+Shot+2025-07-31+at+9.06.14+PM.png)

2. **전화 시스템**으로 이동해 **음성**을 클릭하세요.

   ![전화 시스템의 음성 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062377171/original/S3hbiAE9QBep9UgxIogosdpjCvCVVzl7XQ.png?1768060143)

3. **통화 스크립트**를 클릭한 다음 **스크립트 추가** 버튼을 클릭하세요.

   ![통화 스크립트 화면의 스크립트 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062377191/original/WGeW8B1xLQEkKvgN2S4VtmujknPdjIEUoA.png?1768060204)

4. 원하는 내용을 입력해 새 통화 스크립트를 만들고 **저장**을 클릭하세요.

   ![통화 스크립트 내용 입력 화면](https://jumpshare.com/share/fyR4YRDPZWX2vnVHGsKZ+/Screen+Shot+2025-07-31+at+9.18.54+PM.png)

## 통화 스크립트에 넣을 수 있는 내용

통화 스크립트는 현재 일반 텍스트만 지원해요. 아래와 같은 내용을 넣어 보세요.

- 첫인사 멘트
- 탐색 질문
- 적격 판단 기준
- 이의 제기 대응 답변
- 필수 고지 사항
- 마무리 멘트 또는 다음 단계 안내

{% hint style="info" %}
서식이 있는 텍스트(리치 텍스트)와 클릭할 수 있는 하이퍼링크는 현재 지원하지 않아요.
{% endhint %}

## 웹·앱 다이얼러에서 통화 스크립트 사용하기

상담원은 다이얼러 안에서 통화 중에 바로 통화 스크립트를 열 수 있어요. 새 탭을 열거나 외부 문서를 찾을 필요 없이 한 화면에서 통화에 집중할 수 있어요.

사용할 수 있는 통화 스크립트가 있다면, 지원되는 다이얼러에서 통화 중에 바로 열 수 있어요.

1. 웹 다이얼러나 하이퍼클래스 모바일 앱으로 통화를 걸거나 받으세요.
2. 통화 중에 **스크립트**를 클릭하거나 탭하세요.

   - 웹 다이얼러

     ![웹 다이얼러의 스크립트 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050750989/original/Y-4kiVD1s3tbvZo69MMCtcjnSXIDR_UARg.png?1753978033)
   - 앱 다이얼러

3. 사용할 통화 스크립트를 선택하세요.

   - 웹 다이얼러

4. 연락처와 통화하면서 스크립트를 보고 따라가세요. 대화에 더 맞는 스크립트가 있다면 다른 스크립트로 바꿔도 돼요.

{% hint style="info" %}
통화 스크립트를 열거나 바꿔도 진행 중인 통화에는 영향이 없어요.
{% endhint %}

## 자주 묻는 질문

### 모바일 앱에 통화 스크립트가 보이지 않아요.
하이퍼클래스 모바일 앱을 최신 버전으로 쓰고 있는지 확인하세요. 그래도 옵션이 보이지 않으면 스크립트를 만들어 두었는지, 그 스크립트를 내 사용자가 쓸 수 있는지 확인하세요.

### 통화 스크립트는 만든 뒤에도 수정할 수 있나요?
네, 웹에서 언제든 수정해 대화 가이드를 다듬을 수 있어요.

### 화이트라벨 앱에서도 통화 스크립트 기능을 쓸 수 있나요?
네, 쓸 수 있어요. 다만 화이트라벨 앱의 업데이트는 별도로 요청해야 해요.

### 누가 통화 스크립트를 볼 수 있나요?
통화 스크립트는 서브 계정 단위로 설정할 수 있고, 지원되는 경우 특정 사용자나 팀에 지정할 수도 있어요. 사용자는 지원되는 통화 중에 자신에게 허용된 스크립트만 볼 수 있어요.

### 통화 스크립트에 글자 서식을 넣거나 링크를 추가할 수 있나요?
현재 통화 스크립트는 일반 텍스트만 지원해요. 서식과 하이퍼링크는 지원하지 않아요.

### 통화 스크립트를 수정하면 언제부터 반영되나요?
저장한 내용은 사용자가 지원되는 다이얼러에서 스크립트를 다음에 열거나 새로고침할 때 반영돼요.

### 통화 스크립트와 Manual Call 액션은 같은 건가요?
아니요. 통화 스크립트는 실시간 통화 중에 보는 가이드예요. 워크플로우의 **Manual Call**(수동 통화) 액션은 사용자에게 통화 작업을 만들어 주고, 그 작업은 **대화 > 수동 작업**에서 확인해요. 두 가지를 함께 쓸 수도 있어요. 예를 들어 워크플로우가 통화 작업을 만들고, 상담원이 그 작업을 처리하면서 통화 스크립트를 참고할 수 있어요.
