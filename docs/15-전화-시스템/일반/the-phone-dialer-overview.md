# 전화 다이얼러 개요

하이퍼클래스의 웹 다이얼러를 쓰면 플랫폼을 벗어나지 않고 발신 전화를 걸고, 진행 중인 통화를 관리하고, 통화를 전환하고, 오디오 장치를 설정할 수 있어요.

이 문서에서는 웹 다이얼러의 작동 방식을 설명해요. 전화 걸기, 발신 번호 선택, 통화 중 기능, 오디오 장치 설정, 자주 생기는 문제의 해결 방법을 차례로 다뤄요. 다이얼러 화면 사용법, 통화 전환, IVR(자동 응답 메뉴) 탐색, 음성 메시지 확인 방법도 함께 알아봐요.

## 전화 다이얼러란?

전화 다이얼러는 브라우저에서 쓰는 통화 화면이에요. 별도의 전화기나 앱 없이 하이퍼클래스에서 바로 전화를 걸고 받을 수 있어요. 연락처 검색, 번호 직접 입력, 진행 중인 통화 관리, 통화 기록 확인을 한 화면에서 할 수 있어요.

다이얼러는 하이퍼클래스의 연락처, 워크플로우, 전화번호와 연결돼 있어요. 그래서 연락처 기록, 메모, 활동 내역을 보면서 바로 통화할 수 있어요. 통화는 자동으로 기록돼요. 플랫폼을 벗어나지 않고 오디오 장치 설정, 통화 전환, IVR 메뉴 탐색, 음성 메시지 남기기도 할 수 있어요.

웹 다이얼러는 상단 내비게이션 바의 전화 아이콘으로 열어요. 마이크 권한을 허용한 최신 브라우저에서 사용할 수 있어요.

## 주요 장점

전화 다이얼러는 통화 기능을 하이퍼클래스 안에 모아 줘요. 외부 전화 시스템을 쓰거나 통화를 직접 기록할 필요가 없어요.

- 통합 통화: 하이퍼클래스를 벗어나거나 앱을 바꾸지 않고 전화를 걸고 받아요.
- 자동 통화 기록: 모든 통화가 시각, 통화 시간, 통화 상태와 함께 연락처 기록에 남아요.
- 연락처 검색과 빠른 발신: 이름이나 전화번호로 연락처를 검색하고 한 번의 클릭으로 전화를 걸어요.
- 오디오 장치 제어: 마이크, 스피커, 추가 벨소리 장치를 골라 통화 환경을 맞춰요.
- 통화 전환과 IVR 탐색: 팀원이나 외부 번호로 통화를 전환하고, 다이얼패드로 자동 응답 메뉴를 탐색해요.
- 음성 메시지 확인: 다이얼러 화면에서 음성 메시지를 듣고 확인해요.
- 통화 스크립트: 통화 중에 미리 만들어 둔 스크립트를 보면서 대화를 이끌고 안내 문구를 일관되게 유지해요.

## 다이얼러의 핵심 기능

웹 다이얼러에는 효율적인 통화 관리와 워크플로우 연동을 돕는 기능이 있어요.

### 즉시 발신

전화번호를 직접 입력하거나 이름 또는 전화번호로 연락처를 검색할 수 있어요. 연락처나 번호를 클릭하면 추가 단계 없이 바로 전화가 걸려요.

### 연락처 검색

다이얼러에는 입력하는 즉시 연락처를 걸러 주는 검색 필드가 있어요. 검색 결과에 연락처 이름, 전화번호, 최근 활동이 표시돼서 원하는 연락처를 쉽게 찾아 전화할 수 있어요.

### 최근 통화

**Recent Calls**(최근 통화) 탭에는 수신·발신 통화 목록이 시각, 통화 시간, 통화 상태와 함께 표시돼요. 최근 통화를 클릭하면 해당 연락처 기록을 보거나 같은 번호로 다시 걸 수 있어요.

### IVR 탐색

자동 응답 메뉴가 있는 번호에 전화했다면 다이얼패드를 열어 DTMF 신호음을 보낼 수 있어요. 별도 장비 없이 IVR 메뉴를 탐색할 수 있어요.

## 발신 번호 선택하기

받는 사람에게 표시되는 발신 번호는 사용자에게 지정된 전화번호, 권한, 서브 계정에서 쓸 수 있는 번호에 따라 달라져요. **발신 번호** 선택 방식을 알아 두면 전화를 걸기 전에 어느 비즈니스 번호가 쓰이는지 확인할 수 있어요.

지정된 번호가 있는 사용자는 접근 설정에 따라 그 번호로 자동 발신될 수 있어요. 더 넓은 범위의 기록에 접근할 수 있는 사용자에게는 **발신 번호** 드롭다운이 보일 수 있고, 쓸 수 있는 번호 중에서 고를 수 있어요. 쓸 수 있는 번호가 여러 개라면 전화를 걸기 전에 선택된 번호를 확인하세요.

발신 통화용으로 설정해 두었다면 인증된 발신자 ID도 표시될 수 있어요. 발신 번호가 선택되는 기준을 자세히 알고 싶다면 「웹 앱 다이얼러(소프트폰)로 발신 통화하기」 문서를 참고하세요.

{% hint style="info" %}
받는 사람에게 올바른 비즈니스 번호가 표시되도록, 전화를 걸기 전에 항상 **발신 번호**를 확인하세요.
{% endhint %}

## 오디오 장치 설정

오디오 설정에서 웹 다이얼러가 통화에 쓸 마이크와 스피커를 정해요. 수신 전화가 올 때 함께 울릴 추가 장치도 설정할 수 있어요. 헤드셋, 외부 스피커, 여러 오디오 장치를 쓸 때 유용해요.

오디오 장치를 설정하려면 다음 단계를 따르세요.

1. 다이얼러를 열고 톱니바퀴(설정) 아이콘을 클릭해 **오디오 설정**을 열어요.
2. 드롭다운 목록에서 메인 스피커 장치를 선택해요.
3. (선택) 수신 전화가 올 때 함께 울릴 추가 장치를 선택해요.
4. 사용할 마이크를 선택해요.
5. 내장된 테스트 도구로 스피커와 마이크를 테스트해요. 목소리를 낼 때 마이크 레벨 표시가 움직이는지 확인하세요.
6. **설정 저장**을 클릭해요. 이 설정은 브라우저와 기기에 저장돼요.

{% hint style="info" %}
오디오 설정은 브라우저와 기기마다 따로 저장돼요. 사용하는 브라우저나 컴퓨터마다 각각 설정해야 해요. 자세한 내용은 「웹 다이얼러의 오디오 장치 설정」 문서를 참고하세요.
{% endhint %}

## 화면에서 다이얼러 관리하기

하이퍼클래스의 다른 곳에서 작업하는 동안에도 웹 다이얼러를 열어 둘 수 있어요. 통화 컨트롤이 계속 보이도록 고정하거나, 화면의 다른 위치로 드래그하거나, 고정하지 않고 두어 다른 곳에서 작업할 때 자동으로 최소화되게 할 수 있어요.

- **Unpinned**(고정 해제): 다이얼러 바깥을 클릭하면 자동으로 최소화돼요.
- **고정됨**: 하이퍼클래스의 다른 페이지로 이동해도 다이얼러가 계속 보이고 사용할 수 있어요.
- **드래그**: 헤더를 클릭한 채 끌어서 다이얼러를 화면의 편한 위치로 옮겨요.

{% hint style="info" %}
다이얼러를 최소화해도 진행 중인 통화는 끊기지 않아요. 통화는 백그라운드에서 계속되고, 전화 아이콘을 클릭하면 다이얼러 화면을 다시 열 수 있어요. 자세한 내용은 「하이퍼클래스 다이얼러 자동 최소화, 고정, 드래그」 문서를 참고하세요.
{% endhint %}

## 진행 중인 통화 관리하기

통화가 연결되면 하이퍼클래스를 벗어나지 않고 다이얼러의 컨트롤로 통화를 관리할 수 있어요. 소리를 끄거나, 상대방을 대기 상태로 두거나, 통화를 전환하거나, IVR 메뉴를 탐색할 수 있어요.

- **음소거**: 내 마이크를 잠시 꺼요. 상대방은 내 목소리를 들을 수 없지만 나는 상대방의 목소리를 들을 수 있어요.
- **대기**: 양쪽 사이의 오디오를 일시 중지해요. 대기 중에는 서로의 목소리가 들리지 않아요.
- **웜 트랜스퍼**: 원래 통화를 연결하기 전에 두 번째 전화를 걸어 받을 사용자나 번호와 먼저 통화해요. 전환하기 전에 상황을 미리 설명할 수 있어요.
- **즉시 전환**: 상담 통화 없이 선택한 대상으로 통화를 바로 전환하고, 나는 통화에서 빠져요.
- **Dialpad**(다이얼패드): 통화 중에 DTMF 신호음을 보내 IVR 메뉴를 탐색하거나 내선 번호, 계좌 번호를 입력해요.

### 웜 트랜스퍼와 즉시 전환의 차이

- **웜 트랜스퍼**: 두 번째 전화를 걸어, 원래 통화를 연결하기 전에 받는 사람과 먼저 이야기해요. 상황을 미리 설명하거나 통화 가능 여부를 확인해야 할 때 사용하세요.
- **즉시 전환**: 상담 통화 없이 선택한 대상으로 바로 전환해요. 전환할 대상이 정해져 있고 따로 소개할 필요가 없을 때 사용하세요.

## 통화 스크립트

통화 스크립트는 통화 중에 필요할 때 바로 볼 수 있는 안내문이에요. 다이얼러를 벗어나지 않고도 승인된 안내 문구, 자격 확인 질문, 이의 제기 응대 문구, 규정 준수 문구를 따라갈 수 있어요. 스크립트는 웹 다이얼러, 앱 다이얼러, 하이퍼클래스 모바일 앱에서 볼 수 있어요.

스크립트는 서브 계정 수준에서 만들고 수정할 수 있고, 특정 사용자나 팀에 지정할 수 있어요. 스크립트가 활성화되어 있으면 통화 중에 볼 수 있어서 안내 문구를 일관되게 유지하고 교육 시간을 줄일 수 있어요.

통화 스크립트를 만들고 사용하는 방법은 「웹·앱 다이얼러에서 통화 스크립트 만들고 사용하기」 문서를 참고하세요.

## 음성 메시지

웹 다이얼러에서 발신자가 남긴 음성 메시지를 확인할 수 있어요. 음성 메시지 녹음을 재생하고, 음성 인식(전사)이 켜져 있다면 전사 내용을 보고, 음성 메시지 활동 내역을 다이얼러 화면에서 살펴볼 수 있어요.

음성 메시지는 사용자 권한에 따라 볼 수 있는 범위가 달라요. 개인 음성 메시지 접근 권한이 있는 사용자는 자신에게 지정된 번호로 온 메시지를 볼 수 있어요. 더 넓은 권한이 있는 사용자는 팀 또는 서브 계정의 음성 메시지 대기열을 볼 수도 있어요.

음성 메시지는 해당 연락처 기록에 자동으로 남고, 다른 통화 활동과 함께 음성 메시지 내역을 확인할 수 있어요. 전사 내용을 볼 수 있는지는 서브 계정의 전사 설정에 따라 달라요.

{% hint style="info" %}
음성 메시지 삭제, 다운로드 같은 고급 관리 옵션은 사용자 권한에 따라 쓸 수 있어요. 음성 메시지 관리 방법은 음성 메시지 전용 문서를 참고하세요.
{% endhint %}

## 전화 다이얼러 설정하기

웹 다이얼러를 쓰려면 사전 조건을 확인하고, 브라우저 권한을 허용하고, 오디오 장치를 설정해야 해요. 다음 순서로 다이얼러를 사용할 준비를 하세요.

시작하기 전에 확인하세요.

- 서브 계정에 활성화된 전화번호나 설정된 발신자 ID가 있어야 해요.
- 사용자에게 통화 기능을 사용할 권한이 있어야 해요.
- 브라우저에서 요청이 나오면 마이크 접근을 허용하세요.
- 사용할 스피커, 헤드셋, 마이크를 연결하고 선택하세요.
- 브라우저 확장 프로그램, VPN, 제한적인 네트워크 설정을 쓰고 있다면, 다이얼러가 제대로 연결되지 않을 때 그것들 없이 테스트해 보세요.

1. 상단 내비게이션 바의 전화 아이콘을 클릭해 웹 다이얼러를 열어요.

   ![웹 다이얼러를 여는 상단 내비게이션 바의 전화 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080043870/original/lEk4QZ6yALN-WgYNL2seJ2ejeV1RKblKPg.png?1788454343)

2. 요청이 나오면 브라우저의 마이크 접근을 허용해요. 전화를 걸고 받으려면 꼭 필요해요.
3. 다이얼러의 톱니바퀴 아이콘을 클릭해 **오디오 설정**을 열어요. 메인 스피커, 마이크, 추가 벨소리 장치(선택)를 고르고, 저장하기 전에 스피커와 마이크를 테스트해요.
4. **발신 번호** 필드를 확인해 받는 사람에게 표시될 비즈니스 번호를 확인해요. 쓸 수 있는 번호가 여러 개라면 드롭다운에서 알맞은 번호를 선택하세요.

   ![다이얼러에서 발신 번호를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080044446/original/N40wsGU2YZ102c_y07ne01bA3v03CKlfaA.png?1788454687)

5. **연락처 검색** 필드에서 이름이나 전화번호로 연락처를 찾거나, 다이얼패드에 전화번호를 직접 입력해요.
6. 테스트 전화를 걸어 오디오, 마이크, 통화 기능이 제대로 작동하는지 확인해요.

여기까지 마치면 웹 다이얼러를 쓸 준비가 끝나요. 이제 다이얼러 화면에서 전화를 걸고 받고, 통화를 전환하고, 음성 메시지를 확인할 수 있어요.

## 전화 다이얼러 문제 해결

다이얼러 문제는 대부분 브라우저 권한, 오디오 장치 설정, 확장 프로그램, 네트워크 간섭, 발신 전화 설정 때문에 생겨요. 문제를 해결하기 어렵다면 먼저 아래 항목을 확인해 보세요.

| 문제 | 해결 방법 |
| --- | --- |
| 마이크나 소리가 안 나요 | 브라우저 권한과 **오디오 설정**을 확인하세요. 브라우저에 마이크 접근 권한이 있는지, 올바른 장치가 선택되어 있는지 확인하세요. |
| 마이크나 스피커가 잘못 선택돼요 | 다이얼러의 톱니바퀴 아이콘으로 장치를 고르고 테스트하세요. 오디오 설정은 브라우저에 저장돼요. |
| 다이얼러에서 발신 전화를 걸 수 없어요 | 쓸 수 있는 발신 번호가 있는지 확인하고 **발신 번호** 설정을 살펴보세요. 사용자 권한으로 발신 통화가 허용되는지도 확인하세요. |
| 통화가 실패하거나 끊겨요 | 브라우저 확장 프로그램과 VPN을 잠시 꺼서 테스트하세요. 발신 통화 시간 초과와 관련 설정이 올바른지 확인하세요. |
| 특정 브라우저나 기기에서만 문제가 생겨요 | 해당 브라우저에서 오디오 권한과 장치 설정을 다시 하세요. 오디오 설정은 브라우저나 기기 간에 동기화되지 않아요. |
| 그래도 해결되지 않아요 | 발신 다이얼러 문제 해결 전용 문서에서 고급 진단과 네트워크 설정 안내를 확인하세요. |

{% hint style="info" %}
위 항목을 확인한 뒤에도 다이얼러가 연결되지 않으면 다른 브라우저나 다른 네트워크에서 테스트해 원인을 좁혀 보세요. 자세한 문제 해결 방법은 「웹 앱 다이얼러(소프트폰)로 발신 통화하기」 문서를 참고하세요.
{% endhint %}
