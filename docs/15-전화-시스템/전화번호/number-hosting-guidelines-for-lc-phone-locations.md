# 번호 호스팅 가이드 (하이퍼클래스 전화)

기존 통신사의 음성 서비스는 그대로 두고, 사용 가능한 전화번호에서 하이퍼클래스 전화를 통해 SMS와 MMS를 쓸 수 있어요. 이 문서에서는 번호 호스팅의 대상 번호, 설정 방법, 메시징 규정 준수, 소요 기간, 문제 해결 방법을 안내해요.

## 개요

번호 호스팅(Number Hosting)은 호스팅 SMS 또는 호스팅 메시징이라고도 불러요. 다른 통신사에서 이미 보유한 전화번호를 하이퍼클래스에서 SMS/MMS용으로 쓸 수 있게 해 줘요. 음성 통화는 기존 통신사가 계속 처리하고, 문자 메시지만 하이퍼클래스 전화를 통해 연결돼요.

번호의 소유권과 음성 서비스가 기존 통신사에 남아 있으므로, 번호 호스팅은 번호 이동(포팅)이나 번호 마이그레이션과 달라요. 호스팅 메시징을 켜려면 먼저 인증과 승인 절차를 거쳐야 해요.

이 문서에서는 대상 번호 조건, 실험실 셀프서비스 방식과 고객지원을 통한 설정 방식, 메시징 규정 준수, 소요 기간, 활성화 후 확인 사항, 자주 생기는 문제를 설명해요.

{% hint style="warning" %}
호스팅 승인이 메시징 규정 준수를 대신하지는 않아요. 해당하는 10DLC 번호는 A2P 등록 요건을 충족해야 해요. 미국 또는 캐나다 수신자에게 SMS/MMS를 보내는 수신자 부담 번호는 수신자 부담 번호 인증(Toll-Free Verification)을 마쳐야 해요. 모든 메시지는 수신 동의, 발신자 식별, 수신거부, 콘텐츠 요건을 지켜야 해요.
{% endhint %}

## 번호 호스팅이란? (호스팅 SMS / 호스팅 메시징)

번호 호스팅을 쓰면, 다른 통신사에 소유권과 음성 서비스가 남아 있는 번호에서도 SMS/MMS를 쓸 수 있어요. 번호 자체를 옮기지 않고, 지원되는 문자 메시지의 전송 경로만 바꿔요.

원래 통신사는 계속 음성 통화를 처리하고 번호도 소유해요. 호스팅 요청이 승인되면 지원되는 SMS/MMS 트래픽을 하이퍼클래스 전화가 처리해서, 하이퍼클래스 안에서 그 번호로 메시지를 보낼 수 있어요.

### 번호 호스팅의 장점

현재 음성 제공업체와 익숙한 전화번호는 그대로 두고, 하이퍼클래스에서 SMS/MMS 기능을 추가하고 싶을 때 유용해요.

- 기존 번호 유지: 고객이 이미 알고 있는 전화번호를 계속 쓸 수 있어요.
- 기존 음성 서비스 유지: 음성 통화는 하이퍼클래스 전화로 옮겨지지 않고 현재 통신사에 남아 있어요.
- 번호 이동 불필요: 번호 소유권을 넘기지 않고 지원되는 메시징만 추가해요.
- 하이퍼클래스 메시징 사용: 활성화 후 하이퍼클래스 메시징 화면에서 지원되는 SMS/MMS를 주고받을 수 있어요.
- 음성과 메시징 제공업체 분리: 기존 음성 설정을 유지한 채 메시징만 하이퍼클래스 전화로 쓸 수 있어요.

### 번호 호스팅과 번호 이동(포팅) 비교

호스팅과 포팅은 둘 다 기존 전화번호를 계속 쓸 수 있게 해 주지만, 바뀌는 부분이 달라요. 음성은 기존 통신사에 두고 싶다면 호스팅을, 번호 자체를 다른 통신사로 옮겨야 한다면 포팅을 선택하세요.

| 항목 | 번호 호스팅 | 포팅 |
| --- | --- | --- |
| 번호 소유권 | 현재 통신사에 남아요. | 이전받는 통신사로 넘어가요. |
| 음성 서비스 | 현재 통신사에 남아요. | 번호와 함께 이전받는 제공업체로 옮겨져요. |
| SMS/MMS | 승인 후 하이퍼클래스 전화를 통해 호스팅돼요. | 포팅 후 이전받는 통신사가 처리해요. |
| 통신사 이전 | 아니요. | 네. |
| 이럴 때 선택하세요 | 음성은 기존 통신사를 유지하고 메시징만 하이퍼클래스로 쓰고 싶을 때 | 이전받는 제공업체가 번호 전체를 관리하게 하고 싶을 때 |

번호 전체를 옮겨야 하나요? [포팅 옵션: 미국 앱 내 포팅 vs 해외 수동 절차](porting-options-us-in-app-vs-international-manual-process.md) 가이드를 참고하세요.

### 지원하는 번호와 지원하지 않는 번호

호스팅 가능 여부는 설정 방법에 따라 달라요. 처음 공개된 실험실 셀프서비스는 SMS만 지원하며, 대상은 미국 지역 번호와 수신자 부담 번호예요. 고객지원을 통한 기존 안내는 미국과 캐나다 번호, 지원되는 SMS/MMS를 대상으로 해요. 진행하기 전에 번호와 메시징 기능을 꼭 확인하세요.

| 번호 유형 / 상황 | 가능 여부 | 안내 |
| --- | --- | --- |
| 미국/캐나다 지역 유선 번호 | 대체로 가능 | 대부분의 유선 번호는 인증과 승인 후 호스팅 메시징을 쓸 수 있어요. |
| 미국/캐나다 수신자 부담 번호 | 대체로 가능 | 설정 방법에 따라 가능 여부가 달라요. 미국·캐나다 수신자에게 보내는 메시지에는 수신자 부담 번호 인증이 필요해요. |
| SMS 서비스를 쓰고 있지 않은 번호 | 다른 조건을 충족하면 가능 | 나머지 호스팅 요건을 모두 충족해야 해요. |
| 다른 제공업체에서 이미 SMS를 쓰는 번호 | 현재 구성으로는 불가 | 고객지원이 다음 단계를 안내하기 전까지 기존 메시징 서비스를 변경하지 마세요. |
| 휴대전화(모바일) 번호 | 불가 | 이 방식으로는 휴대전화 번호를 호스팅할 수 없어요. |
| 다른 Twilio 계정에 있는 Twilio 음성 번호 | 불가 | 이미 Twilio 계정이 음성용으로 보유한 번호는 다른 Twilio 계정의 메시징용으로 호스팅할 수 없어요. |
| 미국/캐나다 외 지역 번호 | 불가 | 실험실 셀프서비스는 미국 번호만 지원해요. 고객지원을 통한 안내는 미국과 캐나다 번호를 대상으로 해요. |

## 번호 호스팅을 요청하기 전에 준비할 것

호스팅을 요청하기 전에 소유권 정보와 규정 준수 정보를 준비하세요. 고객지원을 통해 진행할 때는 대상 위치 ID와 요청할 번호 목록도 필요해요.

- **위치 ID**: 호스팅 메시징을 활성화할 하이퍼클래스 서브 계정의 ID예요.
- 전화번호: 요청할 번호를 E.164 형식으로 입력하세요. 예: `+1XXXXXXXXXX`
- 번호 소유자 액세스: 번호를 소유한 권한자나 대리인이 소유권 인증과 승인을 직접 진행할 수 있어야 해요.
- 현재 통신사 정보: 인증 과정에서 요청하면 통신사나 소유권 관련 정보를 확인해 줄 수 있어야 해요.
- 메시징 규정 준수 정보: A2P 10DLC나 수신자 부담 번호 인증이 필요한 경우를 대비해 비즈니스, 수신 동의, 사용 목적, 수신 동의 방식 정보를 준비하세요.

## 번호 호스팅 진행 과정

번호 호스팅은 소유권 인증과 승인 절차로, 요청한 사람에게 해당 번호의 메시징을 연결할 권한이 있는지 확인해요. 필요한 인증과 통신사 검토가 모두 끝나야 호스팅이 활성화돼요.

| 단계 | 진행 내용 |
| --- | --- |
| 1. 요청 | 실험실 셀프서비스에서 번호를 제출하거나, 고객지원을 통해 진행할 때는 위치 ID와 대상 전화번호를 하이퍼클래스 고객지원에 전달해요. |
| 2. 소유권 인증 | 번호의 권한 있는 소유자가 요청한 번호를 직접 관리하고 있음을 확인해요. |
| 3. 승인서(LOA) | 번호 소유자가 호스팅 메시징을 승인하는 승인서(Letter of Authorization, LOA)에 서명해요. |
| 4. 통신사 검토 | Twilio와 관련 통신사 시스템이 호스팅 요청을 검토하며, 추가 확인을 요청할 수 있어요. |
| 5. 활성화 | 승인된 SMS/MMS 연결이 하이퍼클래스 전화를 통해 활성화돼요. |
| 6. 메시징 등록 | 호스팅된 번호로 발신 메시지를 보내기 전에 A2P 10DLC 또는 수신자 부담 번호 인증 요건을 완료하거나 확인하세요. |

![번호 호스팅 요청 화면: 호스팅 번호 입력과 미국 메시징 규정 준수 요건](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061748220/original/pGXKSlb9E2FOtPnMKfcLnTf81bqbWSWOHQ.png?1767340421)

호스팅 메시징 요청에는 번호 인증이 필요해요. 해당하는 10DLC 번호와 수신자 부담 번호는 미국 메시징 등록 요건도 충족해야 해요.

## 번호 호스팅 설정하기

사용 중인 계정에서 가능한 설정 방법을 선택하세요. 실험실 셀프서비스는 미국 지역 번호와 수신자 부담 번호를 지원해요. 고객지원을 통한 방식은 대상 조건과 제출 안내가 따로 있어요.

### 방법 1: 셀프서비스 번호 호스팅(실험실)

에이전시 소유자와 관리자는 하이퍼클래스에서 직접 호스팅 SMS를 요청할 수 있어요. 대상은 이미 보유한 미국 지역 번호 또는 수신자 부담 번호이고, 하이퍼클래스에서 관리하는 서브 계정에서 쓸 수 있어요. 이번 실험실 버전은 요청 한 번에 번호 하나만 지원해요. 음성 서비스는 현재 통신사에 그대로 남아요.

1. 기능 켜기: 에이전시 소유자 또는 관리자로 로그인해요. **설정 > 실험실**로 이동해 **호스팅 번호**를 켜세요. 사용할 수 있는 경우에만 보여요.
2. 요청 시작: **설정 > 전화 시스템 > 번호 관리**로 이동해요. **번호 추가 > Host a Number**(번호 호스팅)를 선택하고 미국 번호를 입력한 뒤 **다음**을 선택해 대상 여부를 확인하세요.
3. 소유권 인증: 화면에 표시된 인증 코드를 확인해요. 기존 번호로 걸려 오는 인증 전화를 받고 전화기 키패드로 코드를 입력한 다음, 하이퍼클래스에서 **인증**을 선택하세요.
4. 서비스 주소 추가: 저장된 미국 서비스 주소를 선택하거나 실제 미국 주소를 새로 추가하세요.
5. 호스팅 승인: 서명 권한자의 정보를 입력하고 전자 서명용 승인서를 보내세요. 에이전시 신원 인증 안내가 나오면 마쳐 주세요.
6. 진행 상황 확인: **호스팅 번호** 탭을 열어요. 요청 상태가 **Hosted**(호스팅 완료)가 될 때까지 진행 상황을 확인하세요. 그다음 남은 신원 인증, 메시징 등록, 발신자 설정을 마치세요. 메시지를 보내기 전에 **SMS Ready**(SMS 사용 준비 완료) 상태인지 확인하세요.

권한: 에이전시 소유자와 관리자만 호스팅 요청을 시작하고 관리할 수 있어요. 서브 계정 사용자는 자기 서브 계정의 요청을 볼 수 있고, 허용된 신원 인증이나 A2P 작업을 완료할 수 있지만 호스팅 요청을 시작할 수는 없어요.

요청이 지연되거나 실패한 경우: 화면에 표시된 가능한 작업을 확인하세요. 지원되는 경우 요청을 취소하고 다시 시작할 수 있어요. 추가 도움이 필요하면 **Request ID**(요청 ID)를 복사해 하이퍼클래스 고객지원에 문의하세요.

{% hint style="info" %}
실험실 버전은 미국 전용이며 SMS 호스팅만 해당해요. 이 방법으로 캐나다 번호와 MMS가 지원된다고 생각하면 안 돼요. 실험실 방식의 완료 소요 기간은 확정된 바가 없어요.
{% endhint %}

### 방법 2: 고객지원을 통한 번호 호스팅

하이퍼클래스 고객지원을 통해 요청할 때는 대상 위치 ID와 호스팅 가능한 번호를 전달한 뒤, 필요한 인증과 승인을 완료하세요.

### 1단계: 전화번호가 대상인지 확인하기

선택한 방법의 요건을 번호가 충족하는지 확인하세요. 처음 공개된 실험실 셀프서비스는 미국 지역 번호와 수신자 부담 번호만 대상으로 해요.

### 2단계: 하이퍼클래스 위치 ID 찾기

**위치 ID**는 호스팅 메시징을 켤 서브 계정을 구분하는 ID예요. 하이퍼클래스에 로그인한 상태에서 서브 계정 URL에서 확인할 수 있어요.

위치 ID는 서브 계정 URL에 표시되며, 대상 서브 계정을 고유하게 구분해요.

### 3단계: 전화번호 목록 준비하기

호스팅할 번호를 각각 E.164 형식으로 준비하세요. 예: `+15551234567`. 대상 번호가 여러 개라면 각 번호를 분명하게 나열해서 고객지원이 올바른 위치 ID와 연결할 수 있게 해 주세요.

### 4단계: 하이퍼클래스 고객지원에 문의하기

하이퍼클래스 고객지원(24시간 실시간 채팅)에 문의하고 아래 정보를 알려 주세요.

- 대상 위치 ID
- 호스팅할 전화번호
- 요청받은 소유권 또는 통신사 정보

### 5단계: 소유권 인증과 승인서(LOA) 완료하기

하이퍼클래스가 호스팅 메시징 인증 절차를 제공해요. 번호의 권한 있는 소유자가 소유권 인증을 마치고 승인서(Letter of Authorization, LOA)에 서명해야 해요. 통신사 확인이 추가로 필요할 수도 있어요.

### 6단계: 승인을 기다린 뒤 메시징 활성화하기

요청이 인증과 검토를 통과하면 호스팅 SMS/MMS 연결이 활성화돼요. 실제 운영 메시지를 보내기 전에 아래 메시징 등록과 확인 단계를 마치세요.

## 호스팅 번호의 메시징 규정 준수

번호 호스팅은 지원되는 메시징 트래픽의 연결을 승인하는 절차예요. 통신사 등록과 메시징 정책 요건은 여전히 적용돼요. 번호 호스팅 승인을 제한 없이 SMS나 MMS를 보내도 된다는 뜻으로 받아들이면 안 돼요.

| 요건 | 알아 둘 내용 |
| --- | --- |
| A2P 10DLC | 미국 비즈니스 메시징에 쓰는 10자리 지역 번호는 메시지를 보내기 전에 승인된 브랜드와 캠페인에 연결돼 있어야 해요. |
| 수신자 부담 번호 인증 | 미국·캐나다 수신자에게 SMS/MMS를 보내는 수신자 부담 번호는 메시지를 보내기 전에 인증을 통과해야 해요. |
| 수신 동의 | 해당 비즈니스와 메시징 사용 목적에 맞게 유효한 동의를 준 연락처에게만 메시지를 보내세요. |
| 발신자 식별 | 처음 보내는 메시지에는 메시지를 보내는 비즈니스를 분명하게 밝혀야 해요. |
| 수신거부 처리 | 필요한 수신거부 안내 문구를 넣고, STOP 같은 수신거부 요청을 지켜야 해요. |
| 콘텐츠 규칙 | 호스팅 메시징도 하이퍼클래스 메시징 정책과, 금지·제한 콘텐츠에 대한 통신사 제한을 받아요. |

호스팅 요청이 승인됨으로 표시된다는 이유만으로 운영 메시지를 보내기 시작하지 마세요. 해당 번호에 필요한 메시징 등록도 끝났는지 확인하세요.

## 호스팅 메시징을 활성화한 뒤 확인할 것

활성화 후에도 음성과 메시징은 각각 다른 경로로 동작해요. 간단히 확인해서, 호스팅 SMS/MMS가 올바른 서브 계정에서 동작하는지, 기존 통신사가 음성 통화를 정상 처리하는지 점검하세요.

- 의도한 하이퍼클래스 서브 계정에서 호스팅 메시징이 활성화됐는지 확인하세요.
- 다른 전화번호로 테스트 SMS를 보내 보세요.
- 테스트 SMS에 답장하고, 받은 메시지가 **대화**에 표시되는지 확인하세요.
- 번호와 메시징 사용 목적이 MMS를 지원하면 MMS도 테스트하세요.
- 기존 음성 설정으로 수신 통화와 발신 통화를 테스트해, 음성 통화가 원래 통신사에 그대로 남아 있는지 확인하세요.
- 해당하는 경우 A2P 10DLC 또는 수신자 부담 번호 인증 상태를 확인하세요.
- 호스팅 번호를 쓸 워크플로우와 자동화를 운영 트래픽에 적용하기 전에 점검하세요.

## 예상 소요 기간

호스팅 메시징은 외부 인증과 통신사 검토가 필요해서 바로 활성화되지 않아요. 소유권 인증과 승인을 빠르게 마치면 불필요한 지연을 줄일 수 있어요.

고객지원을 통한 방법의 예상 소요 기간: 영업일 기준 3~10일

이 예상 기간은 고객지원을 통한 기존 안내에 해당해요. 실험실 셀프서비스는 확정된 소요 기간이 없어요. 통신사 처리, 승인, 인증 상황에 따라 완료 시점이 달라질 수 있어요.

## 문제 해결

호스팅 지연이나 메시지 전송 실패는 대부분 번호 조건, 승인 미완료, 기존 SMS 서비스, 메시징 등록 누락 때문에 생겨요. 요청을 다시 제출하기 전에 아래에서 원인을 먼저 확인하세요.

### 휴대전화(모바일) 번호예요

휴대전화 번호는 이 번호 호스팅 방식의 대상이 아니에요. 지원되는 다른 메시징 방법이나 번호 이동 방법을 이용하세요.

### 다른 제공업체에서 이미 SMS를 쓰고 있어요

이미 SMS 서비스가 있는 번호는 그 상태로는 대상이 아니에요. 기존 메시징 설정을 바꾸거나 끄기 전에 고객지원에 문의해서 올바른 마이그레이션 또는 호스팅 방법을 확인하세요.

### 호스팅 요청이 계속 대기 중이에요

소유권 인증과 승인서(LOA)를 마쳤는지 확인하세요. 통신사의 추가 확인이나 인증이 필요하면 일반 검토 기간보다 길어질 수 있어요.

### 호스팅은 승인됐는데 SMS가 발송되지 않아요

해당 번호와 메시징 경로에 필요한 A2P 10DLC 또는 수신자 부담 번호 인증이 끝났는지 확인하세요. **SMS 규정 준수** 설정, 연락처의 수신 동의, **대화**나 워크플로우 실행 상세에 표시된 메시지 오류도 함께 확인하세요.

### 받은 SMS가 하이퍼클래스에 표시되지 않아요

의도한 위치 ID에서 호스팅 요청이 완전히 활성화됐는지 확인하고, 관련 없는 다른 전화번호로 다시 테스트하세요. 활성화가 끝났는데도 받은 메시지가 표시되지 않으면, 위치 ID와 해당 번호를 하이퍼클래스 고객지원에 알려 주세요.

### 음성 통화가 예상치 않게 바뀌었어요

번호 호스팅은 메시징 연결만 바꾸도록 되어 있어요. 음성 통화가 예상치 않게 바뀌었다면 원래 음성 통신사에서 번호 설정을 확인하세요. 호스팅 활성화 중에 문제가 시작됐다면 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 번호 호스팅을 하면 전화번호 소유권도 넘어가나요?

아니요. 번호는 계속 원래 통신사가 소유하고 관리해요. 지원되는 SMS/MMS 연결만 하이퍼클래스 전화를 통해 호스팅돼요.

### 음성 서비스도 하이퍼클래스로 옮겨지나요?

아니요. 음성 서비스는 기존 통신사에 그대로 남아요. 번호 호스팅은 지원되는 메시징만을 위한 기능이에요.

### 휴대전화(모바일) 번호도 호스팅할 수 있나요?

아니요. 이 번호 호스팅 방식은 휴대전화 번호를 지원하지 않아요.

### 다른 곳에서 이미 SMS를 쓰는 번호도 호스팅할 수 있나요?

현재 구성으로는 할 수 없어요. 기존 메시징 서비스를 바꾸기 전에 하이퍼클래스 고객지원에 문의해서 올바른 방법을 확인하세요.

### 번호 여러 개를 한 번에 호스팅 요청할 수 있나요?

네. 다만 실험실 셀프서비스에서는 요청 한 번에 전화번호 하나씩 제출해야 해요. 고객지원을 통한 호스팅에서는 대상 번호를 여러 개 전달할 수 있으며, 대상 여부는 확인을 거쳐요.

### 호스팅이 승인되면 바로 SMS를 보낼 수 있나요?

꼭 그렇지는 않아요. 운영 메시지를 보내기 전에 해당하는 A2P 10DLC 또는 수신자 부담 번호 인증 요건이 모두 승인됐는지 확인하세요.

### 번호 호스팅에는 보통 얼마나 걸리나요?

고객지원을 통한 기존 안내에서는 영업일 기준 약 3~10일로 예상해요. 실험실 셀프서비스는 구체적인 완료 기간이 확정되지 않았어요.

### 미국과 캐나다 밖의 번호도 호스팅 메시징을 쓸 수 있나요?

처음 공개된 실험실 셀프서비스는 대상 미국 번호만 지원해요. 고객지원을 통한 기존 안내는 대상 캐나다 번호도 포함하니, 가능 여부는 고객지원에 확인하세요.

### 실험실에서 호스팅 요청은 누가 시작할 수 있나요?

에이전시 소유자와 관리자만 할 수 있어요. 서브 계정 사용자는 요청을 보고, 허용된 신원 인증이나 A2P 작업을 완료할 수 있어요.

### 번호에 Hosted는 표시되는데 SMS Ready는 표시되지 않는 이유가 뭔가요?

호스팅 자체는 끝났지만, 신원 인증, A2P 10DLC 또는 수신자 부담 번호 인증, 발신자 설정이 아직 남아 있을 수 있어요.

### 기존 A2P 등록을 다시 쓸 수 있나요?

하이퍼클래스는 해당하는 승인된 서브 계정 수준 A2P 등록이 있으면 그것을 다시 사용해요.
