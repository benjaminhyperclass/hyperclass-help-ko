# 음성 정합성으로 전화번호 평판 높이기

미국 전화번호를 하이퍼클래스의 음성 정합성 기능으로 등록하면, 발신자 번호 분석 업체에 평판 검토를 요청할 수 있어요. 스팸 표시를 정리하고 발신자 번호 평판을 되살려 응답률을 높이고 싶을 때 사용하세요.

## 하이퍼클래스의 음성 정합성

음성 정합성은 대상이 되는 미국 전화번호를 First Orion, Hiya, TNS에 보내 평판 검토를 요청하는 기능이에요. 이 업체들은 발신 활동을 살펴보고 번호의 분류를 바꿀 수 있어요. 잘못 붙은 스팸 표시를 바로잡는 데 도움이 되지만, 최종 평판 판단은 업체와 통신사가 각각 내려요.

## 음성 정합성을 켜면 좋은 이유

- 나빠진 평판 회복: 이미 붙은 스팸 표시를 정리하고 발신자 번호에 대한 신뢰를 되찾을 수 있어요.
- 더 높은 응답률: 알려진 브랜드 이름이 표시되는 전화는 훨씬 더 많이 받는다는 연구 결과가 있어요.
- 더 나은 도달률: 정상적으로 발신하는 번호가 불필요하게 차단되는 일을 줄여서, 영업 전화와 고객 지원 전화가 더 많은 고객에게 닿아요.

{% hint style="info" %}
웹 다이얼러에서 건 발신 전화를 상대방이 받지 않으면 하이퍼클래스가 음성 정합성 등록을 안내할 수 있어요. 이 안내는 앞으로 응답률을 높이도록 돕는 바로가기예요.
{% endhint %}

## 등록하기 전에 확인할 것

음성 정합성을 켜기 전에 아래 조건을 확인하세요.

1. SHAKEN/STIR 등록: 음성 정합성 신청서를 제출하려면 먼저 SHAKEN/STIR를 설정해야 해요. SHAKEN/STIR는 발신자 번호 정보를 인증해서, 표시된 전화번호를 사용할 권한이 회원님의 비즈니스에 있다는 것을 통신사가 확인하게 도와줘요.
2. EIN 필요: 하이퍼클래스의 SHAKEN/STIR 등록 절차를 진행하려면 유효한 고용주 식별 번호(EIN)가 있어야 해요.
3. CNAM(발신자 이름) (권장): 번호와 함께 브랜드 이름을 제출하면 분석 업체의 신뢰도를 더 높일 수 있어요.
4. 미국 전화번호만 가능: 음성 정합성은 현재 미국 내 통화에만 적용돼요. 해외 번호는 지원하지 않아요.

## 음성 정합성 켜기

몇 분이면 신청을 마칠 수 있어요. SHAKEN/STIR 등록을 마쳐야 음성 정합성 폼을 끝까지 작성할 수 있으니, 아직 등록하지 않았다면 먼저 등록하세요.

### 1단계: 신뢰 센터에서 음성 정합성 탭 열기

**신뢰 센터**(Trust Center)에서 **음성 정합성** 탭으로 이동하세요.

![신뢰 센터에서 음성 정합성 탭으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048790618/original/XLqtPNtNwF3LhY9xfg72UOOKgClYvrn_LQ.gif?1750770991)

### 2단계: 등록 폼 작성하기

**신뢰 센터**의 **음성 정합성** 탭에서 아래 항목을 입력하세요.

- **사용 사례**: 앞으로 걸 전화의 종류를 선택하세요. 예를 들어 영업 전화나 고객 지원 전화가 있어요.
- **직원 수**: 회사의 규모를 입력하세요.
- **영업일 평균 통화량**: 하루에 예상되는 통화 횟수를 입력하세요.
- **CNAM Details**(CNAM 상세 정보): (선택) 표시할 브랜드 발신자 이름을 입력하세요.

![음성 정합성 등록 폼 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048791059/original/QdCinpeqBhKjgAALyKcZDuTLief7Wse0uA.png?1750771315)

{% hint style="info" %}
**제출**을 누르면 음성 정합성 신청서는 보통 영업일 기준 2일 안에 처리돼요. 진행 상황은 **신뢰 센터**의 **제출된 신청서** 탭에서 언제든 확인할 수 있어요.
{% endhint %}

## 등록하고 나면 어떻게 되나요?

정보를 제출하면 분석 업체인 Hiya, TNS, First Orion이 각자 등록 내용을 검토해요.

- 빠른 처리: 대부분의 신청서는 영업일 기준 2일 안에 처리돼요.
- 실시간 알림: 번호가 승인되면 알림을 받아요.
- 스팸 표시 제거가 모든 통신망에 반영되기까지는 시간이 걸릴 수 있어요.

{% hint style="info" %}
음성 정합성을 시작하려면 먼저 SHAKEN/STIR 등록을 마쳐야 하고, 이 등록에는 유효한 EIN이 필요해요. 개인사업자이거나 아직 EIN이 없다면 Free Caller Registry로 전화번호 평판을 개선할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 음성 정합성을 켜면 번호가 SHAKEN/STIR에 자동으로 등록되나요?
아니요. 음성 정합성을 등록하려면 계정에 SHAKEN/STIR가 먼저 완전히 설정되어 있어야 해요.

### 해외 번호도 등록할 수 있나요?
현재는 미국 번호만 지원해요. 다른 지역으로 넓히는 것을 검토하고 있어요.

### CNAM은 왜 선택 사항인가요?
CNAM은 발신자 이름을 표시해 주고, SHAKEN/STIR는 발신자를 인증해 주고, 음성 정합성은 평판 검토를 맡아요. 음성 정합성에 CNAM은 필수가 아니지만, 정확한 발신자 이름이 있으면 번호를 알아보는 데 도움이 되는 신호가 하나 더 생겨요.

### 음성 정합성을 쓰면 스팸 표시가 꼭 없어지나요?
아니요. 음성 정합성은 대상이 되는 전화번호를 발신자 번호 분석 업체에 보내 평판 검토를 요청하는 기능이에요. 업체와 통신사가 각자 평판을 판단하기 때문에 표시가 제거된다고 보장할 수 없고, 시간이 걸릴 수도 있어요.

### 사업체에 EIN이 없으면 어떻게 하나요?
EIN이 없으면 음성 정합성에 필요한 하이퍼클래스의 SHAKEN/STIR 등록 절차를 진행할 수 없어요. 대상이 되는 미국 번호라면 대안으로 Free Caller Registry를 이용해 평판을 개선할 수 있어요.

### 음성 정합성을 등록한 뒤에도 번호에 스팸 표시가 다시 붙을 수 있나요?
네. 통신사와 분석 업체는 통화량, 수신자 신고, 반응, 발신 패턴 등 여러 평판 신호를 계속 살펴봐요. 음성 정합성 등록이 앞으로의 스팸 표시를 영구적으로 막아 주는 것은 아니에요.
