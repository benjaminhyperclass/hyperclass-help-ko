# 방문자 활동 추적용 번호 풀 관리 기능

번호 풀을 직접 이동·제거·삭제하고 일반 번호 목록에서 추가하는 방법을 안내해요. 방문자 추적 캠페인에서 전화번호를 지원팀 도움 없이 관리하고 싶을 때 쓰세요.

## 번호 풀 관리 기능이란?

방문자 추적 시스템에서 전화번호를 다루는 새 도구예요. 이 기능으로 번호 풀과 일반 번호 목록 사이에서 전화번호를 이동하거나 제거하고, 삭제하고, 추가할 수 있어요. 캠페인에 맞게 번호를 더 유연하게 관리할 수 있어요.

{% hint style="info" %}
이 변경 사항은 방문자 활동 추적용으로 만든 번호 풀(보통 4~8개 번호)에만 적용돼요.
{% endhint %}

## 주요 이점

- 추가 절차나 지원 요청 없이 번호 풀 사이에서 번호를 이동할 수 있어요.
- 번호 풀 전체를 삭제하지 않고, 번호만 풀에서 빼서 일반 목록으로 돌려보낼 수 있어요.
- 풀에 있는 번호 하나만 삭제하고 나머지는 그대로 둘 수 있어요.
- 일반 목록의 번호를 원하는 추적 풀에 바로 추가할 수 있어요.
- 모든 작업이 감사 로그에 기록돼서 누가 무엇을 했는지 확인할 수 있어요.
- 번호 관리 같은 일상 업무를 위해 지원팀에 문의하는 일이 줄어들어요.
- 동적 방문자 추적 캠페인을 더 효율적으로 운영할 수 있어요.

## 새로 생긴 번호 풀 관리 기능

**번호 풀 정보** 창을 열면 다음 관리 옵션을 쓸 수 있어요.

### 1. 다른 번호 풀로 이동하기

1. 다른 풀로 옮길 번호를 찾으세요.
2. **Transfer to a Different Number Pool**(다른 번호 풀로 전환) 버튼을 클릭하세요.

   ![다른 번호 풀로 전환 버튼](https://jumpshare.com/v/xuJ9PxKIhH7xyc7F9GdS+/Screen+Shot+2025-06-24+at+11.37.31+PM.png)
3. **대상 선택** 드롭다운에서 번호를 옮길 풀을 선택하세요.
4. **이동**을 클릭하세요.

   ![대상 선택 및 이동 버튼](https://jumpshare.com/v/lnfFvfGmDq8jGYLK3wfQ+/Screen+Shot+2025-06-24+at+11.40.04+PM.png)

### 2. 일반 번호 목록으로 돌려보내기

1. 해당 풀에서 번호를 찾으세요.
2. **Move to Phone Numbers**(전화번호로 이동) 버튼을 클릭하세요.
3. 번호가 삭제되지 않고 일반 번호 목록으로 돌아가요.

   ![전화번호로 이동 버튼](https://jumpshare.com/v/hY5nQ3IP9Crlb4Jx82Ug+/Screen+Shot+2025-06-24+at+11.50.31+PM.png)

### 3. 번호를 풀에서 제거하고 삭제하기

1. 삭제할 번호를 선택하세요.
2. **Remove and Delete Number**(번호 제거 및 삭제) 버튼을 클릭하세요.
3. 선택한 번호만 풀에서 제거되고 삭제돼요.

   ![번호 제거 및 삭제 버튼](https://jumpshare.com/v/Odxh1maQuqelyd80sbqg+/Screen+Shot+2025-06-25+at+12.16.10+AM.png)

### 4. 일반 번호 목록에서 풀에 번호 추가하기

1. **번호 관리** 아래의 **전화번호**로 이동하세요.

   ![번호 관리 아래의 전화번호](https://jumpshare.com/v/zTHFkASZ0LCCwd6A7kXM+/Screen+Shot+2025-06-25+at+12.20.39+AM.png)
2. 풀에 추가할 번호 옆의 점 세 개 아이콘을 클릭하세요.
3. **기존 번호 풀에 추가** 버튼을 클릭하세요.

   ![기존 번호 풀에 추가 버튼](https://jumpshare.com/v/aU9I6sg0FAAGKZEdv4nd+/Screen+Shot+2025-06-25+at+12.31.40+AM.png)

5. **Add to Number Pool**(번호 풀에 추가) 버튼을 클릭하세요.

   ![번호 풀에 추가 버튼](https://jumpshare.com/v/2e1BcOQBHpqm9xOL1Dpi+/Screen+Shot+2025-06-25+at+12.35.34+AM.png)

## 감사 로그

번호 풀에서 이루어진 모든 작업이 감사 로그에 기록돼요. 규정을 지키고 문제를 확인할 때 작업 이력을 투명하게 볼 수 있어요.

- 누가 번호를 이동하거나 제거하거나 삭제했는지 확인할 수 있어요.
- 각 작업의 시간과 세부 내용을 볼 수 있어요.
- 분쟁을 해결하거나 문제를 조사할 때 로그를 활용할 수 있어요.

## 번호 풀을 잘 정리하는 방법

번호 풀을 잘 정리해 두면 방문자 추적과 캠페인 분석이 더 정확해져요.

- 캠페인, 지역, 용도별로 번호를 묶어 두면 한눈에 알아보기 쉬워요.
- 쓰지 않는 번호를 정기적으로 살펴보고 정리하세요.
- 풀 이름을 알아보기 쉽게 지으세요.

## 자주 묻는 질문

### 삭제한 번호를 다시 풀에 복원할 수 있나요?

번호를 삭제하면 복원할 수 없어요. 삭제하지 않고 제거만 한 번호만 다시 배정할 수 있어요.

### 번호를 번호 풀 사이에서 옮길 수 있는 횟수에 제한이 있나요?

아니요. 필요한 만큼 얼마든지 옮길 수 있어요.

### 풀에서 번호를 제거하면 추적 데이터에 영향이 있나요?

번호를 제거해도 풀 배정만 바뀌고, 기존 추적 데이터는 삭제되지 않아요.

### 누가 번호 풀을 변경했는지 어떻게 알 수 있나요?

모든 작업이 사용자, 작업 내용, 시간과 함께 감사 로그에 기록돼요.

### 번호 풀을 삭제하면 어떻게 되나요?

풀을 삭제하면 그 안의 번호도 모두 삭제돼요. 번호를 남기려면 풀을 삭제하기 전에 번호를 이동하거나 제거하세요.
