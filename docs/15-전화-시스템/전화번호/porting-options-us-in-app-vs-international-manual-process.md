# 번호 이동(포팅) 옵션 — 미국 앱 내 신청 vs 해외 수동 처리

다른 통신사에서 쓰던 전화번호를 하이퍼클래스 서브 계정으로 옮기는 방법을 안내해요. 필요한 서류, 번호 이동 요청 제출 방법, 이동이 진행되는 과정을 확인할 수 있어요.

이 문서에서 안내하는 정보를 준비한 뒤 번호 이동 신청 양식을 작성해 주세요. 양식 링크는 하이퍼클래스 고객지원에 문의하세요.

## 전화번호 번호 이동이란?

번호 이동(포팅)은 전화번호를 한 통신사에서 다른 통신사로 옮기는 일이에요. 번호의 소유자임을 증명하는 서류를 내면, 기존 통신사와 새 통신사 사이에서 이동이 진행돼요.

번호를 옮길 준비가 되면 서명한 위임장(LOA, Letter of Authorization)을 보내 주세요. 위임장에는 현재 통신사에 등록된 서비스 정보와 같은 내용이 들어 있어야 해요. 위임장을 제출하면 기존 통신사와의 조율은 저희가 맡아서 이동을 마무리해요.

필요한 서류를 제출한 뒤 번호 이동이 끝나기까지는 번호가 50개 미만이면 2~4주, 규모가 크고 복잡하면 6~8주가 걸려요. 번호 이동으로 인한 중단 시간은 없어서, 이동하는 동안에도 번호를 그대로 쓸 수 있어요.

{% hint style="warning" %}
**꼭 읽어 주세요**

1. 모든 무선 번호는 번호 이동 요청에 PIN이 필요해요. 잘못된 PIN이나 가짜 PIN을 입력하면 통신사가 요청을 거절해요.
2. 번호 이동이 늦어지지 않도록, 무선 번호에 PIN이 있는지와 PIN이 맞는지 통신사에 미리 확인하세요.
3. 번호 여러 개를 옮긴다면 번호마다 PIN이 따로 있는지 확인하세요. 통신사가 번호 여러 개에 PIN 하나를 쓰게 한다면, 양식의 무선 번호 PIN 입력란에 그렇게 적어 주세요.
4. 유선 전화와 수신자 부담(Toll-Free) 번호는 PIN이 필요 없을 수 있어요.
{% endhint %}

{% hint style="info" %}
이름과 주소는 통신사에 등록된 정보와 정확히 같아야 해요. 사서함(PO Box)은 서비스 주소로 인정되지 않아요.
{% endhint %}

## 미국 번호 이동: 앱 내 신청

미국 번호는 하이퍼클래스의 전용 포트인 절차를 이용해요. 미국 번호의 전체 절차를 한 문서에 모아 두었기 때문에, 오래된 중복 안내 없이 최신 요건과 제출 방법, 요청 추적 정보를 확인할 수 있어요.

전체 안내는 「포트인 번호 요청 제출 및 추적 방법」 문서를 참고하세요.

이 전용 문서에서 다루는 내용은 다음과 같아요.

- 포트인 가능 조건과 사전 준비 사항
- 요청을 제출하는 데 필요한 정보와 서류
- 하이퍼클래스에서 포트인 요청 제출하기
- 위임장(LOA) 요건
- 번호 이동 요청 상태 확인하기
- 거절된 번호 이동 요청 해결하기
- 번호 이동이 처리되는 동안의 진행 과정

{% hint style="warning" %}
미국 번호를 앱 내 절차로 옮길 때는 수동 번호 이동 양식 대신 전용 포트인 문서의 요건을 따르세요.

현재 이 절차로는 미국 번호만 가져올 수 있어요. 해외 번호는 고객지원에 문의해 주세요. Twilio의 해외 번호 이동 양식(International Porting Form)을 대신 제출해 드려요.
{% endhint %}

## 미국 번호 이동: 수동 요청

앱 내 절차로 처리할 수 없는 일부 미국 번호나 번호 이동 상황에서는 수동 요청이 필요할 수 있어요. 수동으로 번호를 옮길 때는 통신사 정보가 정확해야 해요. 거절이나 처리 지연을 줄이려면, 제출하는 정보가 현재 통신사에 등록된 기록과 대체로 일치해야 해요.

{% hint style="warning" %}
현재 미국 번호만 가져올 수 있어요. 해외 번호는 고객지원에 문의해 주세요. Twilio의 해외 번호 이동 양식(International Porting Form)을 대신 제출해 드려요.
{% endhint %}

### 1단계: 서류 준비

- LOA(위임장): 권한이 있는 사람이 서명해야 해요. 스크린샷에 보이는 **회사 이름** 입력란은 **비워 두어도** 돼요.

  ![위임장 예시 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079925262/original/_zRU3E9Y0PI2CVy1AKOZzsI2vJNw9ANuBQ.png?1788358831)
  ![위임장 예시 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058842655/original/V_oYDFgRxSYGkU7SwhxqzMDOuQTepdCtLw.png?1763638695)
- 최신 통신 요금 청구서: 통신사에서 받은, 내용이 선명하게 보이는 PDF 파일이어야 해요.
  - 청구서는 발행일로부터 90일이 지나지 않아야 해요.
  - 청구서에 전화번호, 계정 소유자 이름, 통신사 이름이 분명하게 보여야 해요.
  - Google Voice 번호는 전화번호와 연결된 이메일 주소가 보이는 스크린샷을 준비하세요.
  - 유선 전화나 VoIP 번호는 가능하면 최신 월별 청구서를 준비하세요.
  - 청구서가 없으면, 번호와 소유자가 보이는 영수증이나 계정 포털 스크린샷으로 대신할 수 있어요.
- 이동할 번호 목록: E.164 형식으로 적어요(예: `+15551234567`).
- **위치 ID**: 번호를 받을 서브 계정의 ID예요. 해당 서브 계정의 **설정 > 비즈니스 프로필**에서 확인할 수 있어요.
- 통신사 계정 정보: 무선 번호가 있으면 계정 번호와 PIN/비밀번호가 필요해요.

  ![통신사 계정 정보 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054088147/original/x_YH0z1VALLLlkJeQKy9xQErsE4uQaYjwA.png?1758222300)

### 2단계: 번호 이동 양식 작성(미국 번호)

수동 번호 이동 요청 양식을 작성하세요. 양식 링크는 하이퍼클래스 고객지원에 문의하세요. 다음 정보를 입력해요.

- 에이전시 **관계 번호**
- **연락처 이름**과 이메일: 진행 상황 안내가 이 이메일로 전달돼요.
- **위치 ID**(번호를 받을 서브 계정)
- **고객** 또는 사업체의 법적 이름과 서비스 주소: 통신사에 등록된 정보와 정확히 같아야 해요.
- **유선 전화** 번호와 수신자 부담(Toll-Free) 번호(있는 경우)
- **무선 번호**(있는 경우)와 계정 번호, PIN 또는 주민번호 뒤 4자리(Last 4 SSN)
- 필수 PDF 업로드: 위임장(LOA)과 청구서

필수 정보를 모두 입력했으면 동의 체크박스를 선택하고 양식을 제출하세요. 번호 이동이 진행되는 시간대에는 서비스가 잠시 영향을 받을 수 있어요. 이동이 끝날 때까지 기존 통신사 계정은 유지하세요.

{% hint style="info" %}
위임장과 청구서는 PDF 파일이어야 하고, 4MB를 넘을 수 없어요.
{% endhint %}

![번호 이동 양식 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054088581/original/RaM3J1q1AfqHnQ-1Jd-KLOz6H_vDkdDgDQ.png?1758222739)

### 3단계: 승인 및 FOC(Firm Order Commitment)

- 양식을 제출하면 진행 상황을 이메일로 알려 드려요.
- 요청이 승인되면 통신사가 FOC 날짜와 시간대를 알려 줘요. 당일 이동이나 특정 날짜 이동은 보장되지 않아요.

## 해외 번호 이동

해외 전화번호 이동은 현재 표준 포트인 절차로는 할 수 없어요. 표준 절차에서는 미국 번호만 가져올 수 있어요.

해외 번호를 옮기려면 하이퍼클래스 고객지원에 문의하세요. 고객지원팀이 Twilio의 [해외 번호 이동 양식(International Porting Form)](https://twlo.my.salesforce-sites.com/InternationalPorting)을 대신 제출하고, 필요한 정보와 서류도 안내해 드려요.

해외 번호 이동이 가능한지와 필요한 요건은 국가, 번호 유형, 통신사에 따라 달라요. 번호를 옮기기 전에 추가 서류나 규제 관련 정보가 필요할 수도 있어요.

## 번호 이동이 끝난 뒤

번호 이동이 끝났다고 해서 그 번호에 필요한 메시지 발송 요건과 규정 준수 절차가 모두 끝나는 것은 아니에요. 새로 옮긴 번호로 고객과 연락하기 전에, 번호 유형과 사용 지역에 맞는 요건을 확인하세요.

해당하는 번호는 다음 내용을 확인하세요.

- 미국 로컬 번호: A2P 10DLC 요건을 확인하세요. SMS/MMS를 보내기 전에, 해당 번호가 승인된 캠페인에 연결되어 있는지 확인해야 해요.
- 미국·캐나다 수신자 부담(Toll-Free) 메시지: 이 번호로 미국과 캐나다 수신자에게 SMS/MMS를 보내려면, 필요에 따라 수신자 부담 번호 인증(Toll-Free Verification)을 완료하세요.
- 해외 번호: 해당 국가의 규제 요건, 주소 등 국가별 서류를 모두 갖췄는지 확인하세요.

번호 이동이 완료된 것을 확인하고 번호가 정상적으로 작동하는지 확인할 때까지는, 이전 통신사 계정을 유지하세요.

## 자주 묻는 질문

### 앱 내 포트인과 수동 양식은 어떻게 다른가요?

앱 내 방식은 **실험실**이 켜진 에이전시 소유자와 관리자가 쓸 수 있어요. 미국 번호만 지원하고, 위임장(LOA)은 자동으로 만들어 줘요. 수동 양식은 하이퍼클래스 전화와 Twilio 중 어느 쪽으로든 옮길 수 있지만, 서명한 위임장을 직접 업로드해야 해요. 두 방식 모두 결과는 같아요. 번호가 하이퍼클래스로 이동돼요.

### 번호 이동 양식은 어디에서 찾나요?

하이퍼클래스 고객지원에 문의하세요. 양식 링크를 안내해 드려요.

### 원하는 날짜와 시간에 번호를 옮길 수 있나요?

통신사는 정확한 날짜와 시간을 보장하지 않아요. 가능한 경우 희망 일정을 요청하고, 통신사가 FOC를 발급하면 번호 이동 시간대를 확인해 드려요.

### 번호를 옮기면 SMS 기록도 같이 옮겨지나요?

아니요. 번호 이동으로는 번호만 옮겨져요. 이전 로그나 대화 기록은 옮겨지지 않아요. 꼭 필요한 기록은 이전 통신사에서 미리 내보내 두세요.

### 요청을 제출한 뒤에 옮길 곳(하이퍼클래스 전화 ↔ Twilio)을 바꿀 수 있나요?

아니요. 제출한 요청은 변경할 수 없어요. 도움이 필요하면 하이퍼클래스 고객지원에 문의하세요.

### 기존 통신사는 해지해야 하나요?

번호 이동이 끝나고, 하이퍼클래스에서 통화와 메시지가 정상적으로 작동하는지 확인한 뒤에만 해지하세요.

### 번호 이동 요청이 거절됐어요. 어떻게 해야 하나요?

앱 내에서 신청했다면 **번호 이동(포트인) 번호** 탭에 표시된 설명을, 수동으로 신청했다면 이메일 알림을 확인해 거절 사유를 확인하세요. 흔한 사유는 주소 오류, 계정 번호 불일치, PIN 오류, 정지된 계정, 90일이 지난 청구서예요.

{% hint style="warning" %}
거절된 요청은 편집할 수 없어요. 요청을 **삭제**하고, 수정한 정보로 새 요청을 만들어야 해요. 다시 제출하기 전에 현재 통신사에 정확한 정보를 확인하세요.
{% endhint %}
