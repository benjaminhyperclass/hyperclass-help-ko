# 전화번호 구매 시 신원 확인 (미국·캐나다·푸에르토리코·이스라엘)

Persona 신원 확인을 거치면 +1, +972 전화번호를 규정에 맞게 유지하고 스팸·악용을 줄일 수 있어요. 이 문서에서는 하이퍼클래스 전화가 관리하는 서브 계정에서 언제 신원 확인이 필요한지, 진행 과정은 어떤지 안내해요.

하이퍼클래스는 미국, 캐나다, 푸에르토리코, 이스라엘 번호를 구매하는 과정에 Persona 신원 확인을 도입했어요.

## 신원 확인이란?

하이퍼클래스 전화가 관리하는 전화 서비스에서 미국·캐나다·푸에르토리코(+1), 이스라엘(+972) 번호를 새로 구매할 때, 하이퍼클래스는 Persona로 서브 계정 사용자의 신원을 확인해요. 서브 계정마다 Persona를 한 번 완료하면, 이후 해당 계정에서 하는 전화번호 구매와 관련 규정 준수 작업에 그 신원 확인이 적용돼요.

Persona가 A2P 10DLC 등록, Toll-Free 번호 인증, CNAM 설정, SHAKEN/STIR 인증을 대신하거나 완료해 주지는 않아요. 해당하는 경우 이 절차들은 따로 완료해야 해요.

- 하이퍼클래스 전화가 관리하는 서브 계정에서 +1, +972 번호를 구매할 때 적용돼요.
- 서브 계정이 아직 Persona를 완료하지 않았다면 구매 과정에서 신원 확인이 시작돼요.
- 인증에 성공하면 그 서브 계정은 이후 +1, +972 번호를 구매할 때 인증된 계정으로 처리돼요.

---

## 신원 확인의 장점

- 규정 준수와 플랫폼 안전: 법적·운영상 규정 준수를 돕고 사기와 스팸을 줄여요.
- 이후 승인 절차 지원: A2P 10DLC 브랜드·캠페인 등록과 Toll-Free 번호 인증을 준비하는 데 도움이 돼요.
- 통화·SMS 전달률 개선: CNAM, SHAKEN/STIR와 함께 쓰면 발신 번호의 평판을 높이는 데 도움이 돼요.
- 서브 계정당 한 번: 한 번 완료하면 그 서브 계정의 +1, +972 번호 구매와 번호 풀 관련 작업이 더 간단해져요.

---

## Persona 신원 확인이 필요한 경우

아래 조건을 모두 만족할 때만 Persona 신원 확인이 필요해요.

- +1 번호(미국, 캐나다, 푸에르토리코) 또는 +972 번호(이스라엘)를 구매하는 경우
- 서브 계정이 하이퍼클래스 전화가 관리하는 계정인 경우(외부 제공업체가 아닌 경우)
- 서브 계정이 이전에 Persona를 완료한 적이 없는 경우

서브 계정에서 Persona 인증에 한 번 성공하면, 이후 해당 조건의 전화번호 구매나 관련 규정 준수 작업에서 Persona를 다시 요구하지 않아요. 인증된 신원은 아래 절차에서 다시 쓰일 수 있지만, 필요한 등록이나 인증은 각각 따로 완료해야 해요.

- 전화번호 구매(**번호 풀** 구매·보충 포함)
- A2P 10DLC 브랜드 등록
- Toll-Free 번호 인증
- CNAM 설정
- SHAKEN/STIR 인증

## 신원 확인 진행 방법

{% hint style="info" %}
Persona는 서브 계정당 한 번만 진행하는 절차예요. 한 번 인증하면 이후 규정 준수 작업이나 번호 구매 때 다시 요청하지 않아요.
{% endhint %}

1. 서브 계정에 로그인한 뒤 **설정**을 클릭하세요.

   ![설정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060627337/original/q1IAbp51gcZGMQekP-rHs66RkfsSL9ypNQ.png?1765803515)
2. **전화 시스템** > **+ Add Number**(번호 추가)를 클릭하세요.

   ![전화 시스템에서 번호 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060627470/original/1FvkTGU-6g7N9AnfCFd9hHl7V1OJSH07_A.png?1765803552)
3. +1 또는 +972 번호를 선택하고 **구매 진행**을 클릭하세요.

   ![번호 선택 후 구매 진행](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060627541/original/ClPPQEB8PmZ8tSzPcvN6mAw_6qxdizzwwA.png?1765803593)
4. 미국·캐나다·푸에르토리코·이스라엘 번호를 구매하려는데 그 서브 계정이 아직 Persona를 완료하지 않았다면, 아래와 같은 신원 확인 창이 나타나요.

   ![신원 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060627664/original/L6xSNVa7vqJ1JpMA_QkSxxKBgXyveW5E3Q.png?1765803655)
5. 국가와 신분증 종류에 맞는 유효한 정부 발급 신분증(예: 여권, 운전면허증)을 업로드하세요.

   ![신분증 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060627702/original/cPEQRL8EzFFmGP_FPlPjT0zsNCVoSYeQPw.png?1765803696)
6. 신분증 업로드가 끝나면 웹캠이나 휴대폰으로 실시간 셀카 인증을 진행해요.

   ![실시간 셀카 인증 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060627822/original/G-T_cvjJdO4ePYlHytXkneJuHve4czr2UQ.png?1765803746)

## 전화번호 구매 오류 해결하기

전화번호 구매를 완료하지 못했다면 아래 내용을 확인하세요.

- Persona 안내가 나타나지 않아요: 페이지를 새로고침하고 구매를 다시 시도하세요. 그래도 나타나지 않으면 하이퍼클래스 고객지원에 문의하세요.
- Persona 인증 창이 이미 열려 있어요: 페이지를 새로고침하거나 벗어나지 마세요. 세션이 24시간 넘게 멈춰 있으면 고객지원에 문의하세요.
- **사용할 수 없는 번호입니다**: 사용 가능한 번호 목록을 새로고침하거나 다른 지역 번호, 지역, 번호 유형으로 다시 찾아보세요.
- 지역 또는 재고 제한: 제공업체의 재고나 위치에 따라 일부 번호는 구매할 수 없을 수 있어요.
- 규정 요건: 일부 지역은 번호를 구매하기 전에 승인된 **규정 번들**이나 주소가 필요해요.

{% hint style="info" %}
새로고침 후 다시 시도해도 Persona 안내가 나타나지 않을 때, Persona 세션이 24시간 넘게 멈춰 있을 때, 검색 조건을 바꿔도 알맞은 하이퍼클래스 전화 번호가 없을 때는 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

## 자주 묻는 질문

### Persona 셀카 인증은 고객 본인의 컴퓨터에서 해야 하나요?
서브 계정을 소유하거나 관리하는 본인이 직접 셀카와 신분증 촬영을 해야 해요. 다만 기기는 웹캠이 있는 데스크톱이든 휴대폰이든 편한 쪽을 쓰면 돼요. 해당 서브 계정의 Persona 진행 화면에 접속할 수 있으면 됩니다.

### Persona를 완료하면 A2P 등록은 안 해도 되나요?
아니요. Persona는 A2P 10DLC 등록을 대신하지 않아요. 규정에 맞게 미국 롱코드 SMS를 보내려면 A2P 브랜드 등록과 캠페인 등록을 따로 완료해야 해요.

### 번호를 구매할 때마다 인증해야 하나요?
아니요. Persona는 보통 서브 계정당 한 번만 진행해요. 인증에 성공하면 Persona를 다시 하지 않고도 +1, +972 번호를 구매할 수 있어요. 번호 풀로 구매하는 경우도 마찬가지예요.

### 인증에 비용이 드나요?
Persona 인증 자체에는 추가 요금이 없어요. 번호 구매 요금과 사용 요금은 기존대로 적용돼요.

### 번호를 번호 풀로 구매하는데, 자동 구매할 때도 다시 인증해야 하나요?
아니요. 서브 계정이 인증된 후에는 번호 풀에서 직접 구매하는 경우와 자동 구매·보충하는 경우 모두 그대로 진행할 수 있어요.

### +1 번호를 구매하려는데 Persona 인증 안내가 나타나지 않아요. 어떻게 해야 하나요?
페이지를 새로고침한 뒤 구매를 다시 시도하세요. 새로고침해야 업데이트된 인증 화면이 나타나는 경우가 있어요. 그래도 해결되지 않으면 하이퍼클래스 고객지원에 문의하세요.
