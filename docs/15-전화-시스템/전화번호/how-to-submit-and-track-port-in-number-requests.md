# 번호 이동(포트인) 요청 제출하고 진행 상황 확인하기

사용 중인 미국 전화번호를 다른 통신사에서 하이퍼클래스로 옮기려면 번호 이동(포트인) 요청을 제출해야 해요. 이 문서에서는 요청을 제출하는 방법과 **번호 이동(포트인) 번호** 화면에서 진행 상황을 확인하는 방법을 안내해요.

번호 이동(포트인)은 다른 통신사에서 쓰던 미국 전화번호를 하이퍼클래스로 옮겨, 통화와 문자 메시지를 한곳에서 관리하게 해 주는 기능이에요.

에이전시 소유자와 에이전시 관리자는 대상이 되는 번호 이동 요청을 하이퍼클래스에서 바로 제출할 수 있어요. 필요한 서류를 올리고, 요청별 진행 상황도 확인할 수 있어요.

{% hint style="warning" %}
중요: 이 기능은 **실험실**(Labs)을 통해 에이전시 소유자와 에이전시 관리자만 쓸 수 있어요.
{% endhint %}

## 번호 이동(포트인) 번호란?

**번호 이동(포트인) 번호**는 대상이 되는 에이전시가 외부 통신사에서 쓰던 미국 전화번호를 하이퍼클래스로 옮기도록 요청하는 기능이에요. 요청을 제출하면 **전화번호** 화면에서 진행 상황을 볼 수 있어요. 통신사 검토, 진행, 완료, 거절 여부를 에이전시 팀이 한곳에서 확인할 수 있어요.

기존 전화번호를 그대로 쓰면서 통화, SMS 등 전화 관련 활동을 하이퍼클래스의 **전화 시스템**으로 관리하고 싶을 때 번호 이동을 해요. 요청 정보를 하이퍼클래스 안에서 입력하면 위임장(LOA)이 자동으로 만들어지고 상태도 바로 보여 줘요. 그래서 수작업 단계가 줄고 플랫폼을 벗어날 필요도 없어요.

## 번호 이동(포트인) 번호의 장점

앱 안의 요청 과정은 기존의 수동 양식 제출을 안내형 절차로 바꿨어요. 요청 내용을 더 정확하게 준비할 수 있고, 주고받는 연락이 줄고, 통신사가 번호를 옮기는 동안 진행 상황도 확인할 수 있어요.

- 앱 안에서 제출: **전화 시스템 > 전화번호**에서 대상이 되는 미국 번호 이동 요청을 바로 제출해요.
- 안내형 요청 절차: 4단계에 걸쳐 확인 사항, 번호 정보, 연락처 정보, 서류를 차례로 입력해요.
- 위임장 자동 생성: 요청 정보로 위임장(Letter of Authorization, LOA)을 만들고, 권한이 있는 담당자에게 보내 전자 서명을 받아요.
- 간단해진 서류 요건: 청구서만 올리면 돼요. PDF 또는 이미지 파일이며 10MB 이하여야 해요.
- 여러 번호 한 번에 입력: 유선 번호는 쉼표로 구분해 여러 개를 입력하고, 무선 번호는 **+ Add New Number**(새 번호 추가)로 여러 개를 추가해요.
- 화면에서 상태 확인: **번호 이동(포트인) 번호** 탭에서 상태, **Request SID**(요청 SID), 생성일, 통신사 처리 내용을 요청별로 확인해요.
- 지원 문의 감소: 대상이 되는 에이전시는 별도 양식 없이 미국 번호 이동 요청을 제출하고 진행 상황을 확인할 수 있어요.

## 시작하기 전에

통신사 정보와 계정 정보를 미리 정확하게 준비하면 지연이나 거절을 줄일 수 있어요. 통신사는 보관 중인 계정 정보와 요청 내용을 대조해 검토해요. 그래서 정보가 맞지 않으면 요청이 거절될 수 있어요.

번호 이동 요청을 제출하기 전에 다음을 준비하세요.

- 현재 통신사의 계정 번호
- 옮길 유선 번호 (여러 개라면 쉼표로 구분해 입력)
- 옮길 무선 번호
- 무선 PIN 또는 주민번호(SSN) 뒤 4자리 (필요한 경우)
- 권한이 있는 담당자의 이름
- 권한이 있는 담당자의 이메일 주소
- 주 및 우편번호를 포함한 전체 서비스 주소
- PDF 또는 이미지 파일 형태의 청구서
- 10MB 이하의 청구서 파일

번호 이동이 완전히 끝날 때까지는 현재 통신사에서 번호를 계속 사용 중인 상태로 두세요. 서비스를 너무 일찍 해지하면 이동이 중단되거나 요청이 실패할 수 있어요.

## 자동으로 만들어지는 위임장(LOA)

위임장(LOA)은 권한이 있는 담당자가 전화번호 이동을 승인했다는 것을 확인하는 문서예요. 이제 하이퍼클래스가 요청 정보로 위임장을 자동으로 만들어요. 문서를 직접 준비하는 수고가 줄고, 잘못된 위임장을 올리는 실수도 막을 수 있어요.

요청을 제출하면 다음 순서로 진행돼요.

1. 하이퍼클래스가 요청 정보로 위임장을 만들어요.
2. 위임장이 권한이 있는 담당자에게 이메일로 전송돼요.
3. 권한이 있는 담당자가 위임장에 전자 서명을 해요.
4. 통신사의 검토와 승인에 따라 번호 이동이 계속 진행돼요.

요청에 입력한 이메일 주소를 담당자가 확인할 수 있는지 꼭 점검하세요. 위임장에 서명하지 않으면 번호 이동 요청이 진행되지 않을 수 있어요.

{% hint style="info" %}
하이퍼클래스는 자동으로 만든 위임장을 해당 담당자의 이메일로 보내 전자 서명을 받아요. 그래서 권한이 있는 담당자의 이메일 주소가 중요해요.
{% endhint %}

## 번호 이동(포트인) 요청 제출하기

통신사 정보, 유효한 청구서, 올바른 담당자를 모두 갖춰 제출해야 요청이 순조롭게 진행돼요. 제출하기 전에 각 단계를 한 번씩 확인하면 지연을 줄이고 번호 이동에 성공할 가능성을 높일 수 있어요.

번호 이동 요청은 다음 순서로 제출하세요.

1. 에이전시 소유자 또는 에이전시 관리자로 로그인하세요.
2. **실험실**에서 이 기능이 켜져 있는지 확인하세요.

   ![실험실에서 기능 활성화 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073461895/original/dAXDniOb1hUSi_fvI6rfoUeTubaT45HE_A.png?1781179829)
3. **전화 시스템 > 전화번호**로 이동하세요.

   ![전화 시스템의 전화번호 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073462036/original/IYW_1qoRXQK876IOrFhP279-pDw3V8JUPQ.png?1781179944)
4. **Add Number**(번호 추가)를 클릭해 시스템에 번호를 추가하세요.

   ![번호 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073462156/original/XORNAEB-9trzfthEAPgDnH-7gQf9x0yZ8g.png?1781180034)
5. **번호 이동(포트인) 번호**를 선택하세요.

   ![번호 이동(포트인) 번호 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073462436/original/zXgu09tdwwbYMm9I06GWuDPJR9SGolTCTA.png?1781180210)
6. **Agreement Checklist**(동의 체크리스트)를 읽고 모두 완료하세요.

   ![동의 체크리스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073462637/original/FKrxhZqa6nM0RiLDiTAWH10_osYdyzmIBQ.png?1781180289)
7. 통신사 계정 번호를 입력하세요. **유선 전화번호**, **무선 번호**, 또는 둘 다 추가하세요. 필요한 경우 무선 PIN 또는 주민번호(SSN) 뒤 4자리를 입력하세요.

   ![통신사 계정 번호와 번호 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073462808/original/9eFIzI3R0fMVW90yioAsekGNpm6QHKXpmw.png?1781180387)
8. 필요하면 번호 이동 요청 이름을 입력하세요. **Residential**(주거용) 또는 **Business**(사업자)를 선택하세요. 권한이 있는 담당자의 이름과 이메일 주소를 입력하세요. 전체 서비스 주소, 주, 우편번호를 입력하세요.

   ![담당자 정보와 서비스 주소 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073463317/original/hdquQ0y_LSEWPWOVVH1kLD_u5gHIMTgm8w.jpeg?1781180658)
9. 청구서를 PDF 또는 이미지 파일(10MB 이하)로 올리세요. 요청 내용을 검토한 뒤 요청을 제출하세요.

   ![청구서 업로드와 요청 제출 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073463479/original/e-KGDTv6MFuRqUInNN-xJFzPGWf2VRCLng.png?1781180715)
10. 확인 창에 표시된 **Request SID**(요청 SID)를 복사하거나 저장하세요.

    ![요청 SID가 표시된 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073463637/original/JnyqR-bp8G5yHWkXUYCViwoGN9JZi_2Sfw.png?1781180776)
11. 권한이 있는 담당자에게 이메일을 확인하고 위임장에 서명해 달라고 요청하세요.
12. **전화번호 > 번호 이동(포트인) 번호**에서 요청 진행 상황을 확인하세요.

제출하면 하이퍼클래스가 **Request SID**가 담긴 확인 창을 보여 줘요. 요청은 **번호 이동(포트인) 번호** 탭에도 나타나요. 통신사가 요청을 처리하는 동안 이 탭에서 상태 변경을 확인할 수 있어요.

## 자주 묻는 질문

### 서브 계정 사용자도 번호 이동 요청을 제출할 수 있나요?
아니요. 앱 안의 **번호 이동(포트인) 번호** 기능은 현재 에이전시 소유자와 에이전시 관리자만 쓸 수 있어요.

### 한 번의 요청으로 여러 번호를 옮길 수 있나요?
네. 유선 번호는 쉼표로 구분해 여러 개를 입력할 수 있어요. 무선 번호는 **+ Add New Number**(새 번호 추가)로 여러 개를 추가할 수 있어요.

### 어떤 서류를 올려야 하나요?
청구서만 올리면 돼요. PDF 또는 이미지 파일이며 10MB 이하여야 해요.

### 요청을 제출한 뒤 현재 통신사 서비스를 해지해야 하나요?
아니요. 번호 이동이 완전히 끝날 때까지는 현재 통신사에서 번호를 계속 사용 중인 상태로 두세요.

### 번호 이동 요청은 어디에서 확인하나요?
**전화 시스템 > 전화번호 > 번호 이동(포트인) 번호**로 이동하세요. 요청 내역, 상태, **Request SID**, 생성일, 통신사 처리 내용을 볼 수 있어요.

### 'Rejected'는 무슨 뜻인가요?
**Rejected**(거절됨)는 요청이 번호 이동 과정을 더 진행하지 못했다는 뜻이에요. 흔한 원인은 다음과 같아요.

- 서비스 주소가 현재 통신사 기록과 맞지 않아요.
- 계정 번호가 잘못됐어요.
- 무선 PIN이 올바르지 않아요.
- 위임장(LOA)에 서명하지 않았어요.
- 통신사 계정이 정지됐어요.
- 청구서가 유효하지 않아요.

거절된 요청은 수정할 수 없어요. **번호 이동(포트인) 번호** 탭에서 거절 사유를 확인하고, 현재 통신사에 올바른 정보를 확인하세요. 그런 다음 거절된 요청을 삭제하고, 바로잡은 정보로 새 요청을 제출하세요.

### 번호 이동이 끝난 뒤에는 무엇을 해야 하나요?
번호가 올바른 서브 계정에 표시되는지 확인하고, 수신 통화와 발신 통화를 테스트해 보세요. SMS나 MMS를 쓸 계획이라면 메시지도 테스트하고, 필요한 메시지 등록이 모두 끝났는지 확인하세요.

미국 지역 번호는 해당 A2P 10DLC 등록이 필요할 수 있고, 수신자 부담(toll-free) 번호는 메시지를 보내기 전에 Toll-Free Verification이 필요할 수 있어요. 번호 이동이 끝난 것을 확인하고 번호가 정상 작동하는 것을 확인할 때까지는 이전 통신사 서비스를 유지하세요.

### 번호 이동 요청은 보통 얼마나 걸리나요?
소요 기간은 통신사와 요청의 복잡도에 따라 달라요. 현재 하이퍼클래스 안내 기준으로, 번호가 50개 미만인 외부 통신사 번호 이동은 필요한 서류를 제출한 뒤 보통 약 2~4주가 걸려요. 규모가 크거나 복잡한 번호 이동은 약 6~8주가 걸릴 수 있어요.

통신사 처리 시간은 달라질 수 있어요. 번호 이동이 끝난 것을 확인하기 전에는 기존 통신사 서비스를 해지하지 마세요.
