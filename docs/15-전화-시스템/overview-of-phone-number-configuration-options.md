# 전화번호 구성 옵션 한눈에 보기

서브 계정 안의 전화번호 하나하나를 설정하는 방법을 안내해요. 통화 착신 전환, 시간 초과 동작, 귓속말 메시지, 통화 녹음 같은 옵션을 다뤄요. 구성을 제대로 해 두면 통화가 알맞게 연결되고, 리드 응대와 자동화도 정확하게 동작해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

---

## 전화번호 구성이란?

전화번호 구성을 쓰면 번호마다 수신 통화와 발신 통화가 어떻게 동작할지 정할 수 있어요.

발신번호를 직접 정해서 보여 주거나, 통화를 사용자에게 연결하거나, 음성 사서함을 켜는 등 전화로 고객을 자주 만나는 팀에게 꼭 필요한 설정이에요.

## 전화번호 구성 옵션 한눈에 보기

| 옵션 | 용도 | 활용 예시 |
| --- | --- | --- |
| **Name Your Number**(번호 이름 지정) | 내부에서 알아보기 쉽게 번호에 이름 붙이기 | "대표 영업 번호", "고객 지원 데스크" |
| **Forwarding Calls To**(통화 착신 전환 대상) | 외부 번호나 휴대폰으로 통화 연결하기 | 팀원의 개인 휴대폰으로 통화 보내기 |
| **Use Verified Number as Caller ID**(인증된 번호를 발신번호로 사용) | 발신 통화에서 인증된 번호 보여 주기 | 발신 통화의 전문성 높이기 |
| **통화 연결** | 통화가 연결되기 전에 안내를 들려줘서 사람이 받았는지 확인하기 | 부재중 통화 자동화를 쓸 때 적합 |
| **귓속말 메시지** | 통화가 연결되기 전에 들려주는 커스텀 메시지 | "XYZ 에이전시에서 온 전화입니다. 연결하려면 1번을 누르세요." |
| **통화 녹음** | 규정 준수나 교육을 위해 통화를 자동으로 녹음하기 | 품질 관리, 팀 모니터링 |
| **통화 녹음 안내 메시지 재생** | 법적 기준에 맞게 녹음 사실 알리기 | "이 통화는 녹음될 수 있습니다..." |
| **수신 통화 시간 초과** | 음성 사서함으로 넘어가기 전까지 전화가 울리는 시간 정하기 | CRM 음성 사서함 또는 개인 음성 사서함으로 연결 |
| **발신 통화 시간 제한** | 발신 통화가 울리는 시간 제한하기 | 상대방 음성 사서함으로 넘어가는 것 방지 |
| **Ring Incoming Calls to Users**(수신 통화를 사용자에게 울리기) | 여러 사용자에게 동시에 전화 울리기 | 통화를 빠르게 받을 수 있게 하기 |

## 전화번호 구성 편집하기

#### 1단계: 전화번호 메뉴로 이동하기

서브 계정에서 **설정 > 전화 시스템 > 전화번호**로 이동하세요.

![설정 > 전화 시스템 > 전화번호 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078175121/original/2_7746jY1JbETbwa_AKn4M6xLxQDzuZ-ZQ.png?1786482930)

#### 2단계: 구성 편집 열기

구성할 번호 옆의 **Three Dots**(점 세 개) 아이콘을 클릭하고, 팝업에서 **구성 편집**을 선택하세요.

![점 세 개 아이콘을 눌러 구성 편집을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078265714/original/QYLwBsJHVBI2OpYubnD1DdRVraz-CMfTFA.png?1786550188)

#### 3단계: 번호 이름 지정하기

**Name Your Number**에서 번호에 내부용 이름을 붙일 수 있어요.

예: 대표 영업 번호, 고객 지원 번호, 상담원 John의 번호

![번호 이름을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078261222/original/AjIPxtxxoxpVuihRi9zd2WlFUR0WQczFKg.png?1786547987)

#### 4단계: 통화를 받을 번호 정하기

**Calls Go To**(통화 수신 번호)에서 수신 통화를 연결할 번호를 정해요. 휴대폰, 외부 회선, 다른 부서로 통화를 넘길 때 유용해요.

발신자가 A번호(구성 중인 번호)로 전화하면, 통화가 즉시 B번호(도착 번호)로 넘어가요.

![통화를 받을 번호를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078262129/original/hNzHFsPcHsWKye8yCG06lKl8ij68XzmYpw.png?1786548521)

#### 5단계: 통화 녹음 설정하기

**통화 녹음**을 켜면 교육, 품질 관리, 규정 준수를 위해 통화가 자동으로 녹음돼요.

**통화 녹음 안내 메시지 재생**을 켜면 녹음이 시작되기 전에 귓속말 메시지를 들려줄 수 있어요. 예를 들어 "품질 관리를 위해 이 통화는 녹음됩니다."라고 상대방에게 미리 알려요.

{% hint style="warning" %}
통화 녹음 요금은 분당 $0.0025예요. 녹음 파일을 보관하는 비용은 분당 월 $0.0005예요.
{% endhint %}

{% hint style="info" %}
미국의 많은 주에서는 녹음 안내 메시지를 들려주는 것이 법으로 정해져 있어요.
{% endhint %}

![통화 녹음 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078261663/original/xwZ-KU27fVakXHruyFmplSVNIXh-s5uF1A.png?1786548244)

#### 6단계: 통화 착신 전환 설정하기

더 자세하게 착신 전환을 설정하려면 **Call Forwarding**(통화 착신 전환) 탭을 클릭하세요. 다음 옵션이 있어요.

- **외부 전화번호**: 통화를 외부 전화번호로 연결해요.
- **비즈니스 전화번호**: **비즈니스 프로필**에 등록한 비즈니스 전화번호로 통화를 연결해요.
- **음성 AI**: 24시간 전화를 받고, 질문에 답하고, 통화를 전환하는 AI 에이전트에게 통화를 연결해요.
- **Ring Multiple Team members**(여러 팀원에게 동시에 울리기): 서브 계정의 여러 사용자(**팀원**)에게 수신 통화를 연결해요. 전화가 오면 선택한 모든 사용자의 전화기가 동시에 울리고, 누군가 받거나 시간이 초과될 때까지 계속 울려요. 최대 6명까지 지정할 수 있어요.
  자세한 내용은 "Ring Incoming Calls to Multiple Users" 문서를 참고하세요.

![통화 착신 전환 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078261752/original/kBo7JmWCtgvGRm5qpviD2K3n5jdnG2F1uw.png?1786548326)

#### 7단계: 시간 초과와 백업 설정하기

- **수신 통화 시간 초과**: 수신 통화가 울리다가 끊기거나 음성 사서함(개인 음성 사서함 또는 CRM에 녹음해 둔 음성 사서함)으로 넘어가기까지 기다리는 시간(초)이에요.

  **비즈니스 정보** 탭이나 지정한 사용자의 프로필 설정에 음성 사서함 녹음 파일(MP3 또는 WAV 형식)을 미리 올려 두세요.

  - 상황 1 - 개인 음성 사서함으로 연결하기: 부재중 통화를 내 휴대폰 음성 사서함으로 넘기고 싶다면 **수신 통화 시간 초과**를 비워 두거나 60초로 설정하세요. 통화가 개인 음성 사서함에 도달할 시간이 충분해요.
  - 상황 2 - 잠시 울린 뒤 CRM 음성 사서함으로 연결하기: 잠시 울리게 한 뒤 CRM에 녹음해 둔 음성 사서함으로 리드를 연결하고 싶다면 **수신 통화 시간 초과**를 20초 정도로 설정하세요. 통화가 개인 음성 사서함까지 가지 않고 CRM 설정으로 처리돼요.
  - 상황 3 - 바로 CRM 음성 사서함으로 연결하기: 전화를 울리지 않고 CRM에 녹음해 둔 음성 사서함으로 바로 보내려면 **수신 통화 시간 초과**를 1~4초로 설정하세요.
- **발신 통화 시간 제한**: 발신 통화가 울리다가 끊기기까지 기다리는 시간(초)이에요. 고객의 음성 사서함으로 넘어가지 않도록 30초처럼 짧게 설정하세요. 음성 사서함 드롭 캠페인이나 리드 이탈 줄이기 캠페인에 알맞아요.
- **Set the Backup**(백업 설정): 백업으로 **Voicemail**(음성 사서함)과 **음성 AI** 중에서 고를 수 있어요. 수신 통화를 받지 못할 때 고객이 듣게 되는 내용이에요.

#### 8단계: 고급 설정 살펴보기

**고급 설정** 탭으로 이동하세요. 이 탭에는 다음 옵션이 있어요.

- **통화 연결**: 켜면 받는 사람에게 귓속말 메시지가 나오고, 키를 눌러야 통화를 수락할 수 있어요. 사람이 받은 통화만 연결된 것으로 처리돼요.

  부재중 문자 회신(Missed-Call Text-Back) 자동화를 쓸 때 좋고, 음성 사서함이 연결된 통화가 성공으로 잘못 기록되는 것도 막아 줘요.
- **귓속말 메시지**: **통화 연결**을 켰을 때 통화가 연결되기 전에 재생할 메시지를 정해요. 통화 녹음 안내와 귓속말 메시지는 음성 합성(TTS)을 사용하고, TTS 요금은 100자당 $0.00084예요.

  예: "하이퍼클래스에서 걸려 온 전화입니다. 연결하려면 아무 키나 누르세요." 또는 "XYZ 에이전시에서 걸려 온 전화입니다. 연결하려면 아무 키나 누르세요."
- **내 번호 가져오기**: 발신 통화를 걸 때 받는 사람의 발신번호 표시창에 내가 인증한 전화번호를 보여 줘요. 인증된 전화번호에만 쓸 수 있어요.

  자세한 내용은 "인증된 발신번호 설정하기(내 번호로 음성 통화하기)" 문서를 참고하세요.
- **Phone number I see when receiving the call**(통화를 받을 때 보이는 전화번호): 기본적으로 발신번호 표시창에는 전화를 건 사람의 번호가 보여요. 대신 발신자가 걸었던 번호를 보고 싶다면 이 기능을 켜세요. 발신자가 A번호로 걸었고 통화가 B번호(내 번호)로 넘어온 경우에 가장 쓸모 있어요.
- **통화 착신 전환 우선 대상**: 전화번호로 수신 통화가 오면 연락처 담당자나 전화번호 소유자에게 연결할 수 있어요.
- **Connect me to the contact (Outbound calls)**(연락처와 연결하기(발신 통화)): 아래 두 가지 중에서 고르세요.

  - **응답 직후**: 연락처가 전화를 받는 즉시 연결해요. 연락처에게 전화를 걸 때 가짜 소리가 아닌 실제 연결음, 통화 중 신호음이 들려요. 통화 녹음 안내 메시지도 함께 들려요(켜 둔 경우).
  - **After the call recording message finishes**(통화 녹음 안내 메시지가 끝난 후): 대화가 통화 녹음 안내 메시지와 겹치지 않아요. 대신 전화를 걸 때 가짜 연결음이 들려요.

## 자주 묻는 질문

### 수신·발신 시간 초과 필드를 비워 두면 어떻게 되나요?
수신 통화와 발신 통화 모두 기본값인 60초로 적용돼요.

### 수신자 부담(Toll-Free) 번호를 인증할 때 어떤 URL을 입력해야 하나요?
고객이 찾아서 확인할 수 있는 공식 비즈니스 웹사이트 URL을 입력하세요.

더 자세한 내용은 "하이퍼클래스 전화(미국/캐나다) 수신자 부담 번호 인증 가이드" 문서를 참고하세요.

### 같은 번호를 여러 사용자에게 지정할 수 있나요?
네. **Ring Incoming Calls to Selected Users**(선택한 사용자에게 수신 통화 울리기)에서 번호 하나에 최대 7명까지 지정할 수 있어요.
### 착신 전환된 통화가 내 개인 음성 사서함으로 넘어가지 않게 하려면 어떻게 하나요?
**수신 통화 시간 초과**를 20초 정도로 짧게 설정하세요. 통화가 개인 음성 사서함에 도달하기 전에 CRM 음성 사서함으로 연결돼요.

### 발신 통화에 올바른 발신번호가 표시되지 않아요.
번호가 인증되었고 발신 통화용으로 승인되었는지 확인하세요. 그리고 **Use Verified Number as Caller ID**를 선택했는지도 확인하세요.

### 수신자 부담 번호를 SMS와 음성 통화에 모두 쓸 수 있나요?
네. 다만 SMS 규정 준수를 위해 등록과 인증을 마쳐야 해요. 통신사 지원 여부에 따라 발신 통화의 발신번호 표시에 제한이 있을 수 있어요.

### IVR 워크플로우로 통화를 연결할 때 귓속말 메시지가 재생되지 않아요.
귓속말 메시지는 외부 전화번호로 착신 전환된 통화에서만 재생돼요. 하이퍼클래스 웹 앱, 모바일 앱, 데스크톱 앱에서 통화를 받으면 귓속말 메시지가 재생되지 않아요. 이는 정상 동작이에요.
