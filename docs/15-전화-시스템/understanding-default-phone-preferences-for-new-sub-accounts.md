# 새 서브 계정의 기본 전화 환경설정

서브 계정을 새로 만들 때 일부 전화 설정은 미리 적용돼요. 덕분에 처음부터 알맞게 설정된 상태로 시작할 수 있고, 직접 바꿔야 하는 부분이 줄어들어요. 이 설정은 언제든 운영 방식에 맞게 바꿀 수 있어요.

## 새 서브 계정의 기본 전화 환경설정이란?

기본 전화 환경설정은 새 서브 계정을 만들 때 하이퍼클래스 전화 기능을 어떻게 설정할지 정하는 에이전시 수준의 설정이에요. 미리 정해 두면 새 서브 계정이 일관된 설정으로 시작해요. 계정을 만든 뒤 같은 전화 설정을 하나씩 다시 하지 않아도 돼요.

에이전시 관리자는 **에이전시 설정 > 전화 연동**의 **계정 생성** 영역에서 이 설정을 관리할 수 있어요.

## 기본 전화 환경설정의 장점

- 일관된 온보딩: 새 서브 계정을 만들 때마다 같은 기본값을 반복해서 설정하지 않고, 표준 전화 환경설정을 한 번에 적용해요.
- 전화 시스템 준비: 새로 만든 서브 계정에 하이퍼클래스 전화 시스템을 자동으로 연결할지 정해요.
- A2P 등록 권한: 전화 재청구(Re-Billing)가 꺼져 있을 때도 서브 계정 사용자가 A2P 등록을 제출할 수 있게 할지 정해요.
- 번호 인텔리전스 기본값: 새 서브 계정에 **번호 인텔리전스**를 자동으로 켤지 정해요.
- 메시지 설정: 에이전시에서 사용할 수 있는 메시지 구성에 맞춰, 새 서브 계정이 처음 쓸 메시지 방식을 정해요.

## 기본 전화 환경설정 변경하기

필요에 따라 이 환경설정을 언제든 조정할 수 있어요.

1. 에이전시 계정에 로그인한 뒤 **설정**을 클릭하세요.
2. **전화 연동**을 클릭하세요.
3. **계정 생성** 탭을 클릭하세요.
4. 필요에 맞게 설정을 바꾸세요.

## 기본 환경설정 항목

### 1. **전화 시스템 자동 연결**

기본으로 켜져 있어요.

이 설정을 켜 두면 새 서브 계정이 전화 시스템에 자동으로 연결돼요. 메시지와 음성 서비스를 바로 쓸 수 있어서 따로 설정하지 않아도 돼요.

### 2. **Allow Sub-Account Users to Submit A2P Registration if Re-Billing is Disabled**(재청구가 꺼져 있어도 서브 계정 사용자의 A2P 등록 제출 허용)

기본적으로 서브 계정은 재청구가 켜져 있을 때만 A2P(Application-to-Person) 등록을 제출할 수 있어요. 이 옵션을 켜면 재청구가 꺼져 있어도 사용자가 A2P 등록을 제출할 수 있어요. 선택 설정이에요.

### 3. **번호 인텔리전스 자동 활성화**

이 설정을 켜면 전화번호 정보를 더 풍부하게 활용할 수 있어요.

- 첫 SMS를 보내기 전에 번호가 유효한지 확인해요.
- 걸려 오는 스팸 전화를 감지해요.
- 전화를 받기 전에 모르는 발신자의 이름을 조회해요.

이 설정을 켜면 전화 소통이 더 효율적이고 안정적이에요. 선택 설정이에요.

### 4. **메시지 한도**

**메시지 한도**는 새로 만드는 모든 서브 계정에 적용돼요. 선택한 한도에 따라 새 서브 계정의 메시지 발송 용량이 정해지며, 이용 정책을 지키는 데 도움이 돼요.

- **현재 한도**: **메시징 램프**(기본 설정)
- 필요하면 이 설정을 바꿀 수 있어요.

## 자주 묻는 질문

### 기본 전화 환경설정을 바꾸면 이미 있는 서브 계정에도 적용되나요?
아니요. 이 환경설정은 새 서브 계정을 만들 때 적용할 기본값을 정하는 설정이에요.

### A2P 등록 권한을 켜면 서브 계정이 자동으로 A2P 등록되나요?
아니요. 제출을 허용하면 해당하는 서브 계정 사용자가 등록 절차를 시작할 수 있게 될 뿐이에요. A2P 등록을 마치려면 비즈니스, 브랜드, 캠페인 정보가 필요하고, 정해진 등록 절차도 끝까지 완료해야 해요.
