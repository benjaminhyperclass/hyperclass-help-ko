# 채팅 위젯으로 A2P 캠페인 등록하기 (사전 구성형)

하이퍼클래스의 안내형 질문지와 자동 생성되는 동의 수집용 채팅 위젯으로 A2P 캠페인 등록을 마치는 방법을 설명해요. 마케팅, 정보성, 혼합 메시지 프로그램을 모두 지원해요.

하이퍼클래스의 사전 구성형 A2P 캠페인(위젯 우선) 방식은 안내형 질문지와 자동 생성 채팅 위젯을 사용해요. 규정 준수 안전장치가 기본으로 들어 있어서 캠페인 등록을 더 수월하게 마칠 수 있어요.

이 문서에서는 위젯 우선 방식, 마케팅·정보성·혼합 사용 사례, 자동으로 만들어지는 동의 화면, 캠페인 등록 절차를 차례로 안내해요.

## 사전 구성형 A2P 캠페인(위젯 우선)이란?

사전 구성형 A2P 캠페인(위젯 우선) 방식은 하이퍼클래스가 만든 채팅 위젯과 안내형 캠페인 설정으로 SMS 수신 동의 설정을 간단하게 만들어 줘요. 캠페인 등록을 시작하면 기본으로 **Chat Widget Setup**(채팅 위젯 설정) 화면이 열려요. 이미 승인된 다른 방법으로 SMS 수신 동의를 받고 있다면 **Manual Setup**(수동 설정)으로 바꿀 수 있어요.

**Chat Widget Setup**은 세 가지 메시지 프로그램을 지원해요. **마케팅 / 홍보용**, **Informational / Non-Marketing**(정보성 / 비마케팅), **혼합**이에요. 혼합은 홍보성 메시지와 정보성 메시지를 함께 보내는 하나의 메시지 프로그램을 위한 유형이에요.

## 주요 장점

위젯 우선 등록 방식에는 안전장치가 들어 있어요. 수신 동의 설정이 쉬워지고, 캠페인 정보가 실제 수신 동의 화면과 맞춰지며, 완전 수동으로 제출할 때보다 피할 수 있는 규정 준수 문제가 줄어들어요.

- 안내형 설정: 통신사 기준에 맞는 고지 문구가 자동으로 채워져요. 규정 준수 문구를 직접 쓸 필요가 없어요.
- 혼합 메시지 지원: 홍보성 메시지와 정보성 메시지를 모두 보내는 비즈니스도 안내형 채팅 위젯을 쓸 수 있어요. 두 가지 동의는 각각 따로 받아요.
- 피할 수 있는 문제 감소: 금융 관련 내용과 마케팅이 충돌하면 제출 전에 알려 줘요. 캠페인이 반려되는 흔한 원인을 줄이기 위한 기능이에요.
- 자동 연령 확인: 캠페인 내용상 필요하면 필수 **생년월일** 필드가 위젯에 자동으로 추가돼요. CTIA 규정을 지키는 데 도움이 돼요.
- 직접 쓰는 안내 문구 없음: STOP/HELP 문구, 발송 빈도 안내, 데이터 요금 안내는 시스템이 만들어 주며 편집하거나 삭제할 수 없어요.
- 일관된 규정 준수 필드: 규정과 관련된 필드는 잠겨 있어요. 통신사가 검토하는 내용과 웹사이트에 실제로 게시되는 내용이 같게 유지돼요.

## 사전 구성형 캠페인 흐름 이해하기

위젯 우선 방식에는 자동 안전장치와 미리 구성된 요소가 들어 있어요. 이 덕분에 캠페인 정보, 수신 동의 화면, 메시지 목적이 통신사 요구 사항에 맞게 유지돼요.

### 기능 1. 메시지 사용 사례 간편 선택

등록을 시작할 때 프로그램에 맞는 메시지 유형을 선택해요.

- **마케팅 / 홍보용**: 홍보성 메시지를 보낼 때 선택해요.
- **Informational / Non-Marketing**: 거래성 또는 정보성 메시지를 보낼 때 선택해요.
- **혼합**: 같은 메시지 프로그램에서 두 유형을 모두 보낼 때 선택해요.

마케팅 또는 정보성을 선택하면 **캠페인 사용 사례** 옵션이 선택한 메시지 유형에 맞게 걸러져요. **혼합**을 선택하면 **캠페인 사용 사례**가 자동으로 **Low Volume Mixed**(소량 혼합)로 설정돼요.

### 기능 2. 금융 + 마케팅 충돌 확인

**마케팅 / 홍보용**을 선택했는데 캠페인이 금융 서비스나 대출 관련 내용도 다룬다고 답하면, 계속하기 전에 **Informational**(정보성)로 바꾸라는 안내가 나와요. 통신사가 흔히 반려하는 고위험 조합을 막기 위한 기능이에요.

### 기능 3. 자동 연령 확인

캠페인이 연령 제한 콘텐츠나 금융 서비스·대출 관련 내용을 다룬다고 답하면, 위젯에 필수 **생년월일** 필드가 자동으로 추가돼요. 연락처는 최소 연령 요건을 충족한다고 확인해야만 폼을 제출할 수 있어요. 제한 대상 카테고리에 적용되는 CTIA 규정을 지키는 데 도움이 돼요.

### 기능 4. 자동 생성 채팅 위젯

하이퍼클래스가 비즈니스에 맞는 위젯을 자동으로 만들어요. 위젯에는 비즈니스 이름, 발송 빈도 안내, "Msg & data rates may apply" 문구, STOP/HELP 안내가 들어가요. 웹사이트에 붙일 JavaScript 임베드 코드도 함께 만들어져요.

**혼합**을 선택하면 생성된 위젯에 독립적인 동의 체크박스가 두 개 들어가요. 하나는 정보성/거래성 메시지용, 다른 하나는 마케팅/홍보성 메시지용이에요. 두 체크박스 모두 미리 선택되어 있지 않고, 동의 항목마다 시스템이 관리하는 고지 내용이 따로 표시돼요.

색상과 헤더 텍스트만 바꿀 수 있어요. 고지 문구, 필수 필드, 동의 체크박스는 편집하거나 삭제할 수 없어요. 그래서 실제 위젯이 검토용으로 제출한 내용과 같게 유지돼요.

![규정 준수 고지가 포함된 자동 생성 채팅 위젯 코드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077193544/original/ie0gyNyv1d5xlJxllpiaVTFzICQO-LmGvg.png?1785387958)

### 기능 5. 잠긴 동의 검토 화면

제출하기 전에 읽기 전용 요약 화면에서 내용을 확인해요. 동의 필드, 시스템이 만든 샘플 메시지, 수신 동의 방법이 표시돼요. 이 필드들은 편집할 수 없어서 등록 내용이 실제 위젯과 일치하는 상태로 유지돼요.

## 사전 구성형 A2P 캠페인 설정 방법

### 시작하기 전에

다음 사항을 먼저 확인하세요.

- A2P 브랜드 등록이 승인되었거나 계속 진행할 수 있는 상태예요.
- 비즈니스에 누구나 접속할 수 있는 운영 중인 웹사이트가 있어요.
- 웹사이트가 브랜드 등록 때 제출한 비즈니스와 같은 비즈니스를 나타내요.
- 웹사이트에 **개인정보처리방침**과 이용약관(Terms & Conditions)이 있어요.
- 메시지 프로그램이 마케팅/홍보용인지, 정보성/비마케팅인지, 혼합인지 알고 있어요.

아래 단계에 따라 위젯 우선 방식으로 캠페인을 등록하세요. 메시지 유형에 따라 선택할 수 있는 캠페인 사용 사례와 위젯에 만들어지는 동의 구조가 달라지므로, 올바른 유형을 선택하는 것이 중요해요.

### 1단계. 캠페인 등록 화면 열기

서브 계정에서 **설정 > 전화 시스템 > 신뢰 센터**로 이동하세요. **A2P 메시징 (SMS)** 아래에서 캠페인 등록을 이어서 진행해요. 캠페인을 추가로 만들 때는 **브랜드 및 캠페인 > 캠페인 > 캠페인 만들기**로 이동하세요.

### 2단계. Chat Widget Setup 진행하기

브랜드 등록이 끝나면 캠페인 등록이 기본으로 **Chat Widget Setup**에서 열려요. **Chat Widget Setup** 항목을 입력해서 캠페인의 수신 동의 화면을 구성하세요.

이미 승인된 다른 방법으로 SMS 수신 동의를 받고 있다면 **Manual Setup**을 사용하세요. 예를 들어 기존 웹사이트 폼, 종이 양식, 리드 폼, QR 코드, 키오스크, 구두 동의 등이 있어요. 첫 번째 **Chat Widget Setup** 화면 아래의 **Switch to Manual Setup**(수동 설정으로 전환)을 선택하세요.

{% hint style="info" %}
**Manual Setup**으로 전환했다가 채팅 위젯을 쓰기로 마음을 바꿨다면, **캠페인 상세 정보** 단계 패널에서 **Chat Widget Setup — recommended**(채팅 위젯 설정 — 권장)를 선택하세요.
{% endhint %}

![사전 구성형 캠페인 옵션이 강조된 등록 방식 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077192716/original/gejxJhX9MYE3MM4aA0E1jlnBsrmJWoKl1w.png?1785385543)

### 3단계. 메시지 사용 사례 선택하기

메시지 프로그램에 맞는 옵션을 선택하세요.

- **마케팅 / 홍보용**: 캠페인에서 프로모션 제안, 광고, 할인, 뉴스레터 등 마케팅 콘텐츠를 보낼 때 선택해요.
- **Informational / Non-Marketing**: 캠페인에서 알림, 확인, 서비스 업데이트 같은 거래성 또는 정보성 메시지를 보낼 때 선택해요.
- **혼합**: 같은 메시지 프로그램에서 홍보성 메시지와 정보성 메시지를 실제로 모두 보낼 때 선택해요.

**혼합**을 선택하면 하이퍼클래스가 **캠페인 사용 사례**를 **Low Volume Mixed**로 자동 설정해요.

![혼합 메시지 사용 사례를 선택하면 캠페인 사용 사례가 Low Volume Mixed로 자동 지정된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080734379/original/dOFPBjxJHMgPsl4iMkGeakQvOcv2LlND3w.png?1789140163)

### 4단계. 안내형 질문에 답하기

캠페인 콘텐츠에 관한 질문에 답하세요. 금융 서비스, 대출 관련 내용, 연령 제한 자료를 다루는지 묻는 질문이 포함돼요. 마케팅과 금융을 함께 선택하는 것처럼 허용되지 않는 조합을 고르면, 계속하기 전에 선택을 조정하라는 안내가 나와요.

### 5단계. 위젯 검토 및 사용자 지정하기

자동 생성된 채팅 위젯을 미리 확인하세요. 색상과 헤더 텍스트는 바꿀 수 있어요. 하지만 고지 문구, 필수 필드(필수 **생년월일** 필드 포함), 동의 안내는 잠겨 있어서 수정할 수 없어요.

**혼합**을 선택했다면 위젯에 정보성/거래성 동의 체크박스와 마케팅/홍보성 동의 체크박스가 각각 따로 표시되는지 확인하세요. 두 옵션 모두 미리 선택되어 있으면 안 되고, 동의 항목마다 해당 고지 내용이 표시되어야 해요.

![정보성 SMS 동의와 홍보성 SMS 동의 체크박스가 따로 표시된 혼합 채팅 위젯](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080734457/original/M7RLGjH-ASALiZplsDQN9UF-qrrXV2L2Vw.png?1789140188)

### 6단계. 위젯 코드를 복사해 웹사이트에 설치하기

제공된 JavaScript 임베드 코드를 복사해서, 설정 중에 확인한 웹 페이지에 설치하세요. 다음 단계에서 규정 준수 확인을 마치기 전에 위젯이 운영 중이고 누구나 볼 수 있는 상태여야 해요.

{% hint style="warning" %}
제출한 페이지에서 SMS 수신 동의를 받는 폼은 채팅 위젯 하나뿐이어야 해요. 같은 페이지에 문의 폼, 리드 캡처 폼, 예약 폼 같은 다른 SMS 수신 동의 폼을 두지 마세요.
{% endhint %}

### 7단계. 웹사이트 규정 준수 확인하기

웹사이트가 통신사와 플랫폼의 요구 사항을 충족하는지 확인하세요. 제출하는 웹사이트는 다음 조건을 갖춰야 해요.

- 운영 중이고 누구나 접속할 수 있어야 해요.
- 등록한 비즈니스를 분명하게 보여 줘야 해요.
- 브랜드 등록에 사용한 비즈니스 정보와 일치해야 해요.
- 적절한 비즈니스/연락처 정보가 표시되어야 해요.
- **개인정보처리방침**과 이용약관(Terms & Conditions)이 있어야 해요.
- 제출한 페이지에서 필요한 SMS 수신 동의 화면을 볼 수 있어야 해요.

![규정 준수 체크리스트와 샘플 메시지 필드가 있는 사용자 동의 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077192889/original/yMxbG9nvvaajdi1qkiKQooVe75_fdCFgMQ.png?1785386304)

### 8단계. 신청 내용 검토 후 제출하기

**신청 검토**를 클릭해서 규정 준수 검토를 실행하세요. 하이퍼클래스가 문제를 찾아내면 권장 사항을 확인하고, 해당하는 캠페인 정보나 웹사이트 정보를 고친 뒤 검토를 다시 실행하세요. 필수 검사를 통과하면 통신사 검토를 위해 캠페인을 제출하세요. 하이퍼클래스 검토를 통과했다고 해서 통신사 승인이 보장되지는 않아요. 최종 결정은 통신사와 등록 파트너가 내려요.

### 9단계. 캠페인 상태 확인하기

**캠페인 > 상태**로 이동해서 제출 상태를 확인하세요. 검토 시간은 달라질 수 있어요. 같은 캠페인을 중복해서 만들지 말고 **신뢰 센터**에서 상태를 확인하세요.

{% hint style="info" %}
캠페인이 통신사 검토를 위해 제출되었어요. 승인이 확인되면 SMS를 보내기 시작할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 메시지 사용 사례로 혼합을 선택하면 어떻게 되나요?

혼합을 선택하면 캠페인 사용 사례가 자동으로 **Low Volume Mixed**로 설정돼요. 생성된 채팅 위젯에는 정보성/거래성 SMS와 마케팅/홍보성 SMS에 대한 동의 선택이 따로 들어가요.

### 혼합 위젯에서 연락처가 동의 유형을 하나만 선택할 수 있나요?

네, 그럴 수 있어요. 두 동의 체크박스는 서로 독립적이에요. 연락처는 정보성 메시지만, 마케팅 메시지만, 또는 둘 다 수신하도록 동의할 수 있어요. 두 체크박스 모두 미리 선택되어 있지 않아요.

### 자동 생성된 채팅 위젯을 사용자 지정할 수 있나요?

색상, 헤더 텍스트 같은 외형 요소는 바꿀 수 있어요. 규정과 관련된 요소인 고지 문구, 필수 필드, 동의 체크박스는 잠겨 있어서 편집하거나 삭제할 수 없어요. 그래서 실제 위젯이 등록 내용과 일치해요.

### Chat Widget Setup 대신 Manual Setup은 언제 쓰나요?

기존 웹사이트 폼, 종이 양식, 리드 폼, QR 코드, 키오스크, 구두 동의처럼 이미 승인된 다른 방법으로 SMS 수신 동의를 받고 있다면 **Manual Setup**을 쓰세요. 기본 권장 옵션은 계속 **Chat Widget Setup**이에요.

### 생년월일 필드가 모든 위젯에 표시되나요?

아니요. **생년월일** 필드는 설정할 때 캠페인이 연령 제한 콘텐츠나 금융 서비스·대출 관련 내용을 다룬다고 답한 경우에만 표시돼요. 필요한 경우 이 필드는 위젯에 고정되며 삭제할 수 없어요.

### 캠페인을 제출하기 전에 채팅 위젯을 먼저 설치해야 하나요?

네. 규정 준수 검토를 실행하고 최종 제출을 하기 전에, 제출한 페이지에서 위젯이 운영 중이고 누구나 볼 수 있어야 해요. 통신사는 등록 중에 입력한 URL에서 수신 동의 방법을 볼 수 있어야 한다고 요구해요.

### 규정 준수 검토에서 문제가 발견되면 어떻게 하나요?

팝업 창에 표시된 권장 사항을 확인하고, 해당하는 캠페인 정보나 웹사이트 정보를 고친 뒤 검토를 다시 실행하세요. 필수 검사를 통과한 뒤에만 통신사 검토용으로 캠페인을 제출하세요.
