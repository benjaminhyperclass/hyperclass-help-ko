# A2P 10DLC 캠페인 사용 사례 선택 가이드

하이퍼클래스에서 선택할 수 있는 A2P 10DLC 캠페인 사용 사례를 소개하고, 내 메시지 목적에 맞는 사용 사례를 고르는 방법을 안내해요. 표준·특수·소량 사용 사례와, 승인 가능 여부에 영향을 줄 수 있는 제한 사항을 함께 알아볼 수 있어요.

올바른 사용 사례를 고르면 **캠페인 상세 정보**, 샘플 메시지, 실제 발송 메시지가 서로 어긋나지 않아요.

## 이 문서에서 알아볼 내용

A2P 10DLC 캠페인을 등록할 때는 알맞은 사용 사례를 고르는 것이 규정 준수와 메시지 전달률에 매우 중요해요. 사용 사례는 캠페인에서 보낼 메시지의 종류를 정하고, 처리량 한도와 이동통신사의 승인 요건에도 영향을 줘요.

이 문서에서는 선택할 수 있는 사용 사례를 하나씩 설명하고, 해당하는 메시지 예시를 보여 드려요. 비즈니스 메시지에 맞는 분류를 고르는 데 참고하세요.

## A2P 10DLC 캠페인 사용 사례란?

A2P 10DLC 캠페인 사용 사례는 등록한 전화번호로 보내는 비즈니스 메시지의 종류를 분류한 것이에요. 이동통신사에 10DLC 캠페인을 등록할 때는 **캠페인 사용 사례**에서 메시지의 의도와 내용을 정확하게 설명하는 주요 사용 사례를 선택해야 해요.

이동통신사는 선택한 사용 사례를 다음과 같이 활용해요.

- 캠페인 등록을 심사하고 승인해요.
- 분당 메시지 수 같은 메시지 처리량 한도를 정해요.
- 알맞은 필터링과 스팸 방지 규칙을 적용해요.
- 이동통신사의 메시지 정책을 지키고 있는지 확인해요.

### 올바르게 선택하면 좋은 점

- 규정 준수 확보: The Campaign Registry에서 캠페인이 거절될 위험을 줄여 줘요.
- 이동통신사의 이해: 이동통신사가 메시지 의도를 파악하고 필터링을 알맞게 적용하는 데 도움이 돼요.
- 법적 요건과의 정합성: 관련 메시지 규정 및 컴플라이언스 요건을 맞추는 데 도움이 돼요.
- 빠른 승인: 사용 사례를 잘못 골라서 생기는, 피할 수 있는 심사 지연을 줄여 줘요.
- 전달률 개선: 등록한 메시지 의도와 실제로 보내는 트래픽이 일치하도록 도와줘요.

## 표준 캠페인 사용 사례

표준 사용 사례는 비즈니스에서 보내려는 메시지의 주된 목적을 나타내요. 캠페인 설명, 샘플 메시지, 수신 동의 절차, 웹사이트, 실제 발송 트래픽이 모두 같은 사용 사례를 뒷받침해야 해요. 그러니 실제로 보내는 메시지를 가장 정확하게 나타내는 항목을 고르세요.

### 2FA(2단계 인증)

사용자 신원을 확인하거나 보안 접속 코드를 보내는 인증 메시지예요. 거래성 메시지이고, 시간이 중요해요.

예시 메시지:

- 로그인 인증 코드
- 비밀번호 재설정 PIN
- 다중 인증 토큰
- 사용자 조치가 필요한 계정 보안 알림

{% hint style="info" %}
2FA 메시지에는 마케팅 내용이나 홍보 문구를 넣으면 안 돼요.
{% endhint %}

### Account Notifications(계정 알림)

고객 계정의 상태, 설정, 활동 변경을 알리는 정보성 메시지예요. 계정에서 일어난 이벤트로 발송되는 거래성 알림이에요.

예시 메시지:

- 계정 생성 확인
- 프로필 업데이트 알림
- 결제 수단 변경
- 구독 상태 변경
- 보안 설정 변경

### 고객 지원

고객 지원 상담, 서비스 문의, 문제 해결과 관련된 메시지예요. 양방향 대화형 지원이 여기에 속해요.

예시 메시지:

- 지원 티켓 업데이트
- 고객 서비스 응답
- 기술 지원 대화
- 문제 해결 상태 업데이트
- 서비스 요청 확인

### Delivery Notifications(배송 알림)

상품이나 서비스 배송의 상태와 진행 상황을 알리는 메시지예요. 주문 이행 이벤트와 연결된 거래성 메시지예요.

예시 메시지:

- 배송 시작 확인
- 배송 조회 업데이트
- 배송 도착 알림
- 주문 상태 변경
- 배송 시도 알림

### 사기 경고 메시지

사기가 의심되는 계정 활동이나 수상한 거래를 알리는, 시간이 중요한 보안 알림이에요. 사용자가 바로 확인해야 하는 메시지예요.

예시 메시지:

- 의심스러운 거래 알림
- 비정상적인 로그인 시도 알림
- 결제 거절 관련 사기 경고
- 계정 탈취 알림
- 본인 확인 요청

### 고등교육

대학교와 고등교육 기관이 학생, 교직원, 입학 예정자에게 보내는 메시지예요. 학사 및 행정 커뮤니케이션이 여기에 속해요.

예시 메시지:

- 수업 일정 알림
- 교내 행사 안내
- 수강 신청 알림
- 성적 게시 안내
- 행정 업데이트
- 입학 관련 안내

### 마케팅

명시적으로 동의한 고객에게 보내는 홍보 및 마케팅 메시지예요. 판매 제안, 프로모션, 광고 콘텐츠가 여기에 속해요.

예시 메시지:

- 세일 프로모션과 할인
- 상품 출시 안내
- 한정 기간 특가
- 뉴스레터 콘텐츠
- 행사 초대
- 장바구니 이탈 알림

{% hint style="info" %}
마케팅 메시지는 수신자에게서 받은 문서화된 수신 동의(opt-in)가 필요해요.
{% endhint %}

### 혼합

하나의 메시지 프로그램 안에서 마케팅과 계정 알림처럼 여러 표준 메시지 목적을 함께 다루는 사용 사례예요.

예시 메시지:

- 같은 메시지 프로그램에서 보내는 홍보 제안과 계정 또는 예약 알림

### 투표 및 설문

의견을 묻거나, 설문을 진행하거나, 투표 절차를 돕는 메시지예요. 의견 수집과 상호작용형 설문이 여기에 속해요.

예시 메시지:

- 고객 만족도 설문
- 상품 피드백 요청
- 여론조사
- 투표 안내
- 상호작용형 설문지

### 공익광고

정부 기관, 비영리 단체, 공익 목적의 기관이 정보를 전달하는 비상업적 메시지예요. 긴급 경보와 지역사회 공지가 여기에 속해요.

예시 메시지:

- 긴급 기상 경보
- 지역사회 안전 경고
- 공중보건 알림
- 서비스 중단 안내
- 정부 소식

### 보안 경고

사용자에게 위협, 취약점, 필요한 보안 조치를 알리는 중요한 보안 알림이에요. 사기 경고 메시지와 비슷하지만 범위가 더 넓어요.

예시 메시지:

- 데이터 유출 알림
- 비밀번호 유출 경고
- 무단 접근 알림
- 보안 정책 변경
- 필수 보안 업데이트

### Conversational Messaging(대화형 메시지)

상담원 실시간 채팅과 챗봇 대화를 포함해, 비즈니스와 고객이 주고받는 양방향 대화예요. 일방향 알림이 아니라 계속 이어지는 대화를 위한 사용 사례예요.

예시 메시지:

- 상담원 실시간 대화
- 챗봇 상호작용
- 양방향 고객 커뮤니케이션
- 상호작용형 서비스 요청
- 실시간 고객 응대

## 알맞은 캠페인 사용 사례 고르기

가장 좋은 사용 사례는 수신자가 실제로 받게 될 메시지를 가장 정확하게 나타내는 항목이에요. 주된 메시지 목적을 기준으로 고르면 캠페인 등록 내용, 샘플 메시지, 실제 발송 트래픽이 서로 다르지 않게 맞출 수 있어요.

### 선택 기준

- **마케팅**: 홍보 제안, 세일, 할인 같은 마케팅 콘텐츠가 주된 목적일 때 선택해요.
- **고객 지원**: 고객이 먼저 시작한 서비스나 지원 상담을 주로 돕는 메시지일 때 선택해요.
- Account Notifications: 고객의 계정, 상태, 활동에 대한 비홍보성 업데이트일 때 선택해요.
- Delivery Notifications: 주문 이행이나 배송 상태를 주로 알리는 메시지일 때 선택해요.
- 2FA: 인증 또는 확인 코드를 보낼 때 선택해요.
- **혼합**: 하나의 메시지 프로그램이 여러 표준 메시지 목적을 실제로 함께 다룰 때 선택해요.

{% hint style="warning" %}
어떤 사용 사례가 맞는지 모르겠다는 이유로 **혼합**을 선택하지 마세요. 선택한 사용 사례는 실제 메시지 프로그램을 정확하게 나타내야 해요.
{% endhint %}

### 혼합 캠페인과 별도 캠페인

여러 메시지 유형이 같은 메시지 프로그램에 속한다면 **혼합** 캠페인이 알맞을 수 있어요. 하지만 목적이 크게 다른 메시지라면 별도 캠페인으로 나누어 등록하는 편이 더 정확할 수 있어요.

예를 들어 인증 코드와 관련 없는 홍보 메시지를 함께 보내는 비즈니스라면, 각 트래픽이 정확하게 반영되도록 캠페인을 따로 만들어야 할 수 있어요.

판단하기 어려우면, 관련 없는 트래픽을 한데 묶지 말고 메시지 프로그램별 실제 목적과 수신 동의 방식에 맞춰 등록하세요.

{% hint style="warning" %}
제출하기 전에 캠페인 사용 사례를 신중하게 선택하세요. 선택한 사용 사례가 잘못되었다면 재제출할 때 수정할 수 없을 수 있고, 새 캠페인을 만들어야 할 수도 있어요.
{% endhint %}

## 특수 캠페인 사용 사례

특수 사용 사례는 등록 과정에서 추가 확인, 서류, 사전 심사가 필요해요. 특정 업종이나 규제 대상 목적을 위한 사용 사례예요.

### Charity(자선)

등록된 501(c)(3) 비영리 단체와 자선 단체를 위한 사용 사례예요. 등록할 때 세금 면제 자격을 증명하는 서류가 필요해요.

### Emergency(긴급)

긴급 경보나 중요한 공공 안전 알림을 보내는 기관을 위한 사용 사례예요. 긴급 알림 권한을 증명하는 서류와 이동통신사 파트너의 승인이 필요해요.

### Political(정치)

캠페인, 정당, PAC 등 정치 관련 메시지에 쓰는 사용 사례예요. 등록할 때 추가 확인이나 사전 심사가 필요할 수 있어요.

### Low Volume Mixed(소량 혼합)

메시지 발송량이 적어 높은 처리량이 필요 없는 비즈니스에 알맞을 수 있어요. 표준 **혼합**과 같은 범위의 메시지를 보낼 수 있고, 월 캠페인 요금이 더 낮아요. 다만 Brand Trust Score와 관계없이 가장 낮은 처리량 등급으로 제한돼요.

발송 속도나 규모가 중요하다면 **Low Volume Mixed**를 선택하기 전에 Message Throughput(MPS) 안내를 확인하세요.

{% hint style="info" %}
특수 사용 사례는 승인 소요 기간, 필요 서류, 이동통신사 제한이 다를 수 있어요. 특수 사용 사례의 자격 요건이나 필요 서류가 궁금하면 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

## 제한 및 금지 사용 사례

캠페인 사용 사례는 메시지 목적을 나타낼 뿐, 이동통신사나 플랫폼의 제한을 면제해 주지 않아요. 업종이나 메시지 내용이 금지 또는 제한 대상이면 캠페인이 거절되거나, 필터링되거나, 정지되거나, 제재를 받을 수 있어요.

### 제한 또는 금지 카테고리 예시

- 대마초(합법인 지역 포함)
- 채권 추심 및 채무 통합
- 페이데이 론 및 고위험 금융 서비스
- 도박 및 경품 추첨(제한 적용)
- 성인 콘텐츠 및 서비스
- 암호화폐 및 비규제 투자
- 제3자 리드 생성(S.H.A.F.T.)
- 주식 알림 및 시세 조작(펌프 앤드 덤프)
- 이동통신사 정책에서 정한 기타 카테고리

{% hint style="warning" %}
캠페인을 등록하기 전에 "미국 및 캐나다의 SMS·MMS 금지 메시지 카테고리(Forbidden Message Categories for SMS and MMS in the US and Canada)" 문서에서 최신 정책을 확인하세요. 선택할 수 있는 사용 사례가 있다고 해서 금지된 업종이나 메시지 내용이 발송 가능해지는 것은 아니에요.
{% endhint %}
