# A2P 캠페인 거절 사유와 필수 수정 사항, 심사 오류 코드 확인하기

A2P 10DLC 캠페인이 거절되면 하이퍼클래스에 거절 사유와 재제출 전에 고쳐야 할 내용이 표시돼요. 이 문서에서는 필수 수정 사항을 확인하는 방법, A2P 거절·심사 오류 코드의 뜻, 재제출 가능 여부, 수신 동의·웹사이트·비즈니스 정보·사용 사례·메시지 내용과 관련한 대표적인 문제의 해결 방법을 안내해요.

---

## 필수 수정 사항이란?

거절 사유마다 **View required fixes →**(필수 수정 사항 보기) 링크가 있어요. 링크를 클릭하면 문제를 네 가지 항목으로 나누어 보여 주는 창이 열려요.

![필수 수정 사항 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067598509/original/toPmCfMxWrRzTwVst_EprwtB3aQmrseOdg.png?1774353402)

| 항목 | 설명 |
| --- | --- |
| **Error code**(오류 코드) | 통신사에서 반환한 구체적인 코드 |
| **Rejection category**(거절 분류) | 위반 내용을 알기 쉽게 표시한 이름 (예: *잘못된 웹사이트 URL*) |
| **What it means**(의미) | 제출이 실패한 이유에 대한 간단한 설명 |
| **Correction needed**(필요한 수정) | 재제출 전에 문제를 고치려면 해야 하는 정확한 조치 |

---

## A2P 캠페인 심사를 하는 이유

A2P 10DLC 캠페인은 승인 전에 심사를 거쳐요. 통신사 네트워크에서 스팸, 사기, 원치 않는 메시지를 줄이기 위해서예요. 심사를 통해 통신사는 제출한 사용 사례, 수신 동의 방법, 샘플 메시지, 비즈니스 정보가 빠짐없고 정확한지, 비즈니스가 실제로 보내려는 메시지와 맞는지 확인해요.

새로 제출한 캠페인은 심사가 끝날 때까지 **대기 중** 상태로 남아 있을 수 있어요. 통신사나 등록 파트너의 요건을 충족하지 못하면 거절될 수 있고, 이 경우 수정 후에야 승인받을 수 있어요.

**View required fixes** 창은 A2P 캠페인을 등록한 방식에 따라 안내가 달라져요.

- **Chat Widget Setup**(채팅 위젯으로 설정)을 쓴 경우: 웹사이트, 다른 SMS 수신 동의 폼, 정책 링크에서 고칠 수 있는 내용을 안내해요. 하이퍼클래스가 자동으로 만든 동의 문구나 폼 필드는 고치지 않아도 돼요.
- **Manual Setup**(수동 설정)을 쓴 경우: 직접 제출한 수신 동의 방법과 동의 정보를 기준으로 안내해요.

해당하는 경우 이 창에는 정확한 규정 준수 문구도 나와요. 재제출 전에 브랜드 등록을 바꿔야 하는 문제도 함께 알려 줘요.

---

## 필수 수정 사항 확인하는 방법

1. **설정 > 전화 시스템 > 신뢰 센터**로 이동하세요. **Brands & Campaigns**(브랜드 및 캠페인)를 열고 **캠페인** 탭을 선택하세요. **Rejected**(거절됨) 상태인 캠페인을 찾아 각 거절 사유 옆의 **View required fixes →**를 클릭하세요.

   ![신뢰 센터의 캠페인 탭에서 거절된 캠페인 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080473850/original/ZG5fAOmK_tCIs94o4bkCfeWpG0rBd2sEMg.png?1788951565)
2. 포털에서 제출한 **A2P 캠페인**으로 이동하세요.
3. 거절된 캠페인을 찾아 표시된 거절 사유를 확인하세요.
4. 거절 사유 옆의 **View required fixes →**를 클릭하세요.

   ![필수 수정 사항 보기 링크](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067598623/original/YFbcG7KVWQPjCP6smtLbZH3TfX53Fxs1FQ.png?1774353448)
5. 창에 나온 네 가지 항목을 꼼꼼히 읽어 보세요.
6. **Correction needed**에 안내된 대로 수정하세요.
7. 모든 문제를 해결한 뒤 캠페인을 다시 제출하세요.

{% hint style="info" %}
캠페인에 거절 사유가 여러 개일 수 있어요. 표시된 사유마다 **View required fixes →**를 클릭해서 확인하고, 모든 문제를 해결한 뒤에 재제출하세요.
{% endhint %}

## 재제출하기 전에

캠페인이 거절되면 수정하기 전에 거절 사유를 모두 확인하세요. 거절 사유가 여러 개일 수 있고, 표시된 문제는 재제출 전에 모두 고쳐야 해요.

거절 사유에 따라 이미 제출한 캠페인을 수정해서 해결할 수도 있고, 새 캠페인을 만들어야 할 수도 있어요. 재제출할 때 수정할 수 없는 항목을 고쳐야 하는 경우가 특히 그래요.

예를 들어 **캠페인 사용 사례**와 **Opt-in message**(수신 동의 메시지)는 재제출할 때 수정할 수 없을 수 있어요. 이 항목을 바꿔야 한다면 새 캠페인을 만들어 제출해야 할 수 있어요.

허용되지 않는 콘텐츠, 금지된 콘텐츠, 위험도가 높은 콘텐츠와 관련한 거절이라면 일반적인 수정·재제출 대상이 아닐 수 있어요.

{% hint style="warning" %}
재제출하기 전에 거절 사유로 지적된 항목만이 아니라 캠페인 전체를 검토하세요. 캠페인 설명, 사용 사례, 샘플 메시지, 웹사이트, 수신 동의 절차, 개인정보처리방침, 이용약관이 정확하고 서로 일치하는지 확인하세요. 표시된 거절 사유는 모두 고친 뒤 재제출하세요.
{% endhint %}

## 거절 코드와 필수 수정 사항

| 캠페인 상태 | 해야 할 일 |
| --- | --- |
| **대기 중** | 심사가 끝날 때까지 기다리세요. 심사 중에는 재제출하거나 다른 캠페인을 만들지 마세요. |
| 수정할 수 있는 오류로 거절됨 | **View required fixes →**를 열어 표시된 문제를 모두 고치고, 캠페인 전체를 검토한 뒤 재제출하세요. |
| 거절되었고 필요한 항목을 수정할 수 없음 | 근본 원인을 고치고, 필요하면 새 캠페인을 만드세요. |
| 금지·고위험 콘텐츠로 거절됨 | 같은 캠페인을 재제출하지 마세요. 해당하는 메시지 제한 사항을 검토하세요. |
| 승인되었지만 SMS가 작동하지 않음 | 발신 번호가 승인된 캠페인에 연결되어 있는지 확인하고, SMS 오류는 별도로 해결하세요. |

### 1부: 재제출할 수 있는 거절 유형

아래 거절 코드는 해결한 뒤 재제출할 수 있어요. 코드별 조치를 따라 캠페인 등록 정보를 수정하고 다시 심사를 요청하세요.

### 수신 동의

| 오류 코드 | 의미 | 필요한 수정 |
| --- | --- | --- |
| **30909** | 심사 담당자가 콜투액션(CTA)/**Message Flow**(메시지 흐름)를 확인할 수 없어요. | CTA 정보 전체와 최종 사용자가 수신 동의하는 모든 방법을 제공하세요. 로그인해야 볼 수 있는 화면이라면 호스팅된 스크린샷을 제공하세요. |
| **30913** | 마케팅 수신 동의는 정보성·거래성 메시지 동의와 따로 받아야 해요. | 프로모션 메시지에 대한 동의를 별도로 추가하세요. 거래성 메시지만 보낸다면 캠페인 설명에 그 점을 분명히 적으세요. |
| **30917** | 수신 동의 방법을 여러 개 선택했는데 모두 설명하지 않았어요. | 수신 동의 절차 설명이 선택한 모든 방법을 다루도록 수정하세요. |
| **30923** | 메시지 수신 동의가 필수 약관이나 계약에 묶여 있어요. | 수신 동의는 별도의 선택 동작이어야 해요. 소비자가 메시지 수신을 거부해도 서비스를 이용할 수 있어야 해요. |
| **30924** | 동의 문구에 필수 고지(발송 빈도, 수신 중단, 요금)가 빠져 있어요. | 수신 동의 체크박스 근처에 네 가지 필수 요소를 모두 추가하세요. 메시지 유형, 발송 빈도, "message and data rates may apply"(메시지 및 데이터 요금이 부과될 수 있음) 문구, STOP 안내예요. |
| **30925** | 수신 동의 폼에 체크박스가 없거나 체크박스가 미리 선택되어 있어요. | SMS 수신 동의 전용 체크박스를 추가하고, 기본값은 선택하지 않은 상태로 두세요. |
| **30931** | 수신 동의 폼의 구조 때문에 소비자가 메시지 수신을 거부할 수 없어요. | 명시적인 건너뛰기 옵션이나 선택하지 않은 체크박스를 추가하세요. 버튼 하나로 메시지 수신을 포함한 모든 권한에 동의하게 해서는 안 돼요. |
| **30932** | 개인정보처리방침에 수신 동의 데이터가 마케팅 목적으로 제3자와 공유된다고 나와 있어요. | 개인정보처리방침에 휴대전화 정보를 마케팅 목적으로 제3자와 공유하지 않는다고 명시하도록 수정하세요. |
| **30896** | 수신 동의 메시지 절차가 캠페인 유형에 충분하지 않거나, 동의가 없거나, 수신 동의 정보가 제3자와 공유되고 있어요. | 수신 동의가 CTIA 가이드라인을 충족하는지 확인하세요. 모든 수신 동의 방법을 나열해야 해요. 종이 폼이나 로그인이 필요한 화면에서 동의를 받는다면 수신 동의 화면 이미지의 호스팅 링크를 제공하세요. 웹사이트에서 받는다면 링크를 제공하세요. 그 페이지에는 개인정보처리방침과 서비스 이용약관이 있어야 해요. 수신 동의 정보가 제3자와 공유되지 않는지 확인하세요. |
| **30887** | 캠페인에 소비자의 수신 중단 요청을 받아 처리한다고 했지만, 절차가 불분명하거나 키워드 또는 수신 중단 메시지가 없어요. | 수신 중단 절차가 정확한지 확인하고, **Message Flow** 설명에 수신 중단 절차를 넣어 수정하세요. 수신 중단 키워드를 추가하고, 수신 중단 메시지에 요청 확인, 더 이상 메시지를 보내지 않는다는 안내, 브랜드 이름을 넣으세요. |
| **30890** | HELP 답장 메시지에 브랜드 이름, 전화번호, 이메일 주소가 없어요. | 구독자에게 보내는 HELP 답장 메시지에 브랜드 이름, 전화번호, 이메일 주소 중 하나가 있는지 확인하세요. "HELP"라고 답장한 고객이 누구에게 연락해야 하는지 안내해야 해요. |

### 웹사이트

| 오류 코드 | 의미 | 필요한 수정 |
| --- | --- | --- |
| **30919** | 웹사이트에 비즈니스 정보나 메시지 발송 관련 고지가 충분하지 않아요. | 회사 이름, 서비스 설명, 연락처, 개인정보처리방침, SMS 메시지 프로그램에 대한 언급을 추가하세요. |
| **30920** | 웹사이트가 비즈니스 맥락 없이 폼(리드 수집, 가입)뿐이에요. | 폼 주변에 회사 이름, 비즈니스 소개, 연락처 같은 비즈니스 맥락을 추가하세요. |
| **30921** | 웹사이트에 로그인해야 해서 심사 담당자가 접속할 수 없어요. | 비즈니스와 메시지 프로그램을 설명하는 공개 페이지를 만드세요. |
| **30922** | 웹사이트가 인증 요건을 충족하지 못해요(공사 중, 표준에 맞지 않는 URL). | 정상 작동하는 표준 URL을 제공하세요. 아직 오픈 전이라면 캠페인 설명에 그 사실을 적고 스크린샷을 제공하세요. |
| **30891** | 등록에 유효하지 않은 URL이 제공되었어요. 웹사이트는 정상 작동해야 해요. | 제공한 웹사이트가 정상 작동하는지 확인하세요. 오픈 전 웹사이트에 대한 등록이라면 캠페인 설명에 그 내용을 자세히 적으세요. |
| **30907** | 웹사이트 URL이 캠페인 설명이나 브랜드 정보와 맞지 않아요. | 웹사이트가 등록한 브랜드와 캠페인 내용 모두와 일치하는지 확인하세요. |
| **30908** | 규정에 맞는 개인정보처리방침이 **Message Flow**에 없거나 웹사이트에서 찾을 수 없어요. | 개인정보처리방침을 최종 사용자가 볼 수 있는지 확인하고, **Message Flow**에 해당 페이지의 직접 링크를 넣으세요. |
| **30888** | 웹사이트나 수신 동의 절차에 연령 확인 장치가 없어요. | 웹사이트나 수신 동의 절차에 확실한 연령 확인 장치를 확인하고 추가하세요. |

### 비즈니스 정보

| 오류 코드 | 의미 | 필요한 수정 |
| --- | --- | --- |
| **30914** | 개인 사업자 캠페인의 내용이 등록한 이름과 맞지 않아요. | 캠페인 설명, 샘플 메시지, 웹사이트를 등록한 개인 사업자 이름에 맞추세요. |
| **30915** | 개인 사업자로 등록했는데 법인 이름(LLC, Inc.)을 쓰고 있어요. | EIN과 법인 정보로 일반 브랜드로 다시 등록하세요. |

## 캠페인 심사 비용과 재제출 참고 사항

A2P 10DLC 캠페인 심사에는 인증 또는 검토 비용이 들 수 있어요. 이 비용과 주기적으로 청구되는 캠페인 요금은 등록 유형, 캠페인 유형, 현재 통신사 요건에 따라 달라질 수 있어요.

최신 요금은 "A2P 10DLC 메시지 요금: 등록비, 월 요금, 통신사 비용(A2P 10DLC Messaging Fees: Registration, Monthly, and Carrier Costs)" 문서를 참고하세요.

재제출할 수 있는 캠페인 거절은 수정한 뒤 다시 제출할 수 있어요. 허용되지 않는 콘텐츠나 고위험 콘텐츠 같은 일부 거절 유형은 다르게 처리될 수 있고, 일반적인 재제출 대상이 아닐 수 있어요.

재제출하거나 새 캠페인을 만들기 전에 거절 사유를 꼼꼼히 확인하세요.

## "Maximum 3 tries exhausted" 오류 처리하기

"Maximum 3 tries exhausted" 오류가 표시되면, **CP 575 양식**을 준비한 뒤 하이퍼클래스 고객지원에 문의하세요. 이 오류는 사업자 정보가 일치하지 않거나 올바르지 않아서 등록 시도가 실패했다는 뜻이에요.

#### 다음 단계

1. **CP 575 EIN 확인 서한**을 준비하세요. CP 575가 없다면 미국 국세청(IRS)에 147c 서한을 요청하세요.
2. 고객지원과 주고받는 문의에 **사업자 등록 서류를 업로드**하세요.
3. CP 575 양식을 **이메일로 보내거나 스크린샷으로** 하이퍼클래스 팀에 보내세요.

하이퍼클래스 팀이 이 서류를 대신 제출해서 브랜드 승인을 진행해요.

**알아 둘 점**

- **법적 사업체 이름과 EIN 번호가 CP 575 양식에 나온 내용과 정확히 일치**해야 해요.
- W2나 W9 양식에 있는 사업체 이름은 다를 수 있으니 쓰지 마세요.
- CP 575/147c 서한에서 사업체 이름이 여러 줄이라면, 등록할 때 주소 줄 위의 **모든 줄**을 입력해야 해요.

  **예시:**

  ```
  ABC Holding Group Inc.
  Division of Regional Services
  123 Main Street
  New York, NY 10001
  ```

  이 경우 입력할 법적 이름은 `ABC Holding Group Inc. Division of Regional Services`예요.

## 자주 묻는 질문

### 수정한 뒤 바로 재제출할 수 있나요?

재제출할 수 있는 거절 코드라면 네, 가능해요. 표시된 거절 사유를 모두 해결했다면 포털에서 바로 캠페인을 다시 제출할 수 있어요. 다만 재제출하면 통신사 심사 시간이 더 걸릴 수 있어요.

### 캠페인에 거절 사유가 여러 개인데, 전부 고쳐야 하나요?

네. 재제출하기 전에 거절 사유를 모두 해결해야 해요. 일부만 고치면 다시 거절될 가능성이 높아요.

### 재제출할 수 없는 코드로 거절됐는데, 이의 신청은 할 수 있나요?

네. 거절이 잘못되었다고 생각한다면 하이퍼클래스 고객지원에 문의하세요. 제목은 "10DLC Campaign Appeal for [비즈니스 이름 또는 번호]"로 쓰고, 이의 신청 내용을 자세히 적어 주세요.

### 문제를 고쳤는데 또 거절됐어요. 어떻게 해야 하나요?

새 거절 사유를 꼼꼼히 확인하세요. 통신사가 다음 심사에서 다른 문제를 추가로 찾아낼 수 있어요. 캠페인이 규정을 충족한다고 생각하는데도 계속 거절된다면 하이퍼클래스 고객지원에 문의하세요.

### 캠페인이 계속 대기 중 상태예요.

새로 제출한 A2P 10DLC 캠페인은 통신사나 등록 파트너가 심사하는 동안 **대기 중** 상태로 남아 있을 수 있어요. 캠페인이 승인되면 A2P 메시지 발송을 진행할 수 있어요. 요건을 충족하지 못하면 필수 수정 사항과 함께 거절될 수 있어요.

### 거절된 캠페인을 재제출하는 데 비용이 드나요?

재제출할 수 있는 캠페인 거절은 수정한 뒤 다시 제출할 수 있어요. 비용 처리는 거절 유형과 현재 통신사 요건에 따라 달라질 수 있어요.
