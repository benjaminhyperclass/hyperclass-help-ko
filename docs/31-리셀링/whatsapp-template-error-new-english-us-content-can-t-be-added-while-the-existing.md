# WhatsApp 템플릿 오류: 영어(미국) 콘텐츠를 삭제한 직후 다시 추가할 수 없을 때

영어(미국) 콘텐츠를 삭제한 직후 같은 콘텐츠를 다시 추가할 수 없는 이유와 해결 방법을 안내해요. WhatsApp 메시지 템플릿을 만들거나 수정할 때 이 오류가 나오면 확인해 보세요.

WhatsApp 메시지 템플릿을 만들거나 업데이트할 때 다음과 같은 오류 메시지가 표시될 수 있어요.

> "New English (US) content can't be added while the existing English (US) content is being deleted. Try again in 4 weeks or consider creating a new message template."

(뜻: 기존 영어(미국) 콘텐츠를 삭제하는 중에는 새 영어(미국) 콘텐츠를 추가할 수 없어요. 4주 뒤에 다시 시도하거나 새 메시지 템플릿을 만들어 보세요.)

## 이 오류가 나는 이유

같은 언어의 콘텐츠가 삭제되는 중이면 Meta(WhatsApp)는 새 영어(미국) 콘텐츠를 바로 추가하지 못하게 해요.

- 템플릿에서 영어(미국) 콘텐츠를 삭제하면, 다시 추가할 수 있을 때까지 Meta가 최대 4주의 대기 기간을 두어요.
- 승인된 템플릿에서 언어가 일관되게 쓰이는지 확인하는 Meta의 규정 준수 점검 중 하나예요.

## 해결 방법

두 가지 방법 중에서 고르세요.

### 방법 1. 4주 기다리기

삭제한 날부터 4주가 지나면 같은 템플릿 이름에 영어(미국) 콘텐츠를 다시 추가할 수 있어요.

### 방법 2. 새 템플릿 만들기 (권장)

- 기다리는 대신, 필요한 영어(미국) 콘텐츠로 새 템플릿을 만드세요.
- Meta 심사를 통과하도록 겹치지 않는 템플릿 이름을 쓰세요. 예를 들어 `promo_offer` 대신 `promo_offer_v2`처럼 지으면 돼요.
