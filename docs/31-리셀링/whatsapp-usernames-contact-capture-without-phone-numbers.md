# WhatsApp 사용자 이름으로 메시지를 보내는 고객, 전화번호 없이 연락처 자동 생성

WhatsApp 사용자 이름(username)을 쓰는 고객이 처음 메시지를 보내면 하이퍼클래스가 연락처를 자동으로 만들어 줘요. 이 문서에서는 사용자 이름 기반 연락처 생성이 어떻게 동작하는지, 기존 워크플로우에서 달라지지 않는 부분과 현재 제한 사항을 알려 드려요.

WhatsApp은 전화번호를 공유하지 않고도 기업에 메시지를 보낼 수 있는 사용자 이름 기능을 도입하고 있어요. 하이퍼클래스는 사용자 이름으로 온 메시지에서 연락처를 자동으로 만드는 방식으로 이 기능을 지원해요.

## WhatsApp 사용자 이름이란?

WhatsApp 사용자 이름은 전화번호를 알리지 않고 기업에 메시지를 보낼 수 있게 해 주는 개인정보 보호 기능이에요. 고객이 전화번호 대신 사용자 이름을 선택하면, WhatsApp은 그 고객과 기업의 관계에 고유한 비즈니스별 사용자 식별자(BSUID)를 부여해요.

BSUID는 사용자와 기업의 조합마다 하나씩 만들어져요. 그 관계가 유지되는 동안 바뀌지 않고, 보통 전화번호가 들어가는 자리에 메시지 데이터로 전달돼요. BSUID는 해당 기업에만 연결돼요. 같은 고객이 다른 기업에 메시지를 보내면 다른 BSUID가 생기고, 한 기업의 BSUID로는 다른 기업을 대신해 그 고객에게 메시지를 보낼 수 없어요.

이 기능은 사용자가 개인 정보를 더 직접 관리하게 하면서도 기업과 소통할 수 있게 하려는 WhatsApp의 개인정보 보호 정책의 일부예요.

## 주요 장점

사용자 이름 기반 연락처 생성을 쓰면 고객의 개인정보 설정 때문에 리드를 놓치지 않아요.

- 리드 누락 없음 — 사용자 이름을 쓰는 고객이 메시지를 보내면 연락처가 자동으로 만들어져서, 추적되지 않는 대화가 없어요.
- 간편한 적용 — 기존 WhatsApp 설정을 바꾸지 않아도 자동으로 동작해요.
- 고객 개인정보 존중 — 고객이 연락처 정보를 공유하는 방식을 선택할 수 있어요. 기업은 그대로 소통하고 후속 연락을 이어 갈 수 있어요.
- 앞으로의 변화에 대비 — 사용자 이름 사용이 늘어나면서 WhatsApp의 개인정보 보호 기능이 확대되어도 대비할 수 있어요.

## 사용자 이름 기반 연락처 생성 방식

WhatsApp 사용자 이름을 쓰는 고객이 처음 메시지를 보내면, 하이퍼클래스가 연락처 레코드를 자동으로 만들어요.

1. 고객이 먼저 연락해요. 새 고객이 전화번호 대신 사용자 이름으로 WhatsApp을 통해 메시지를 보내요.
2. WhatsApp이 사용자 이름과 BSUID를 전달해요. 메시지와 함께 전화번호 대신 고객의 사용자 이름과 비즈니스별 사용자 식별자(BSUID)가 전달돼요.
3. 연락처가 만들어져요. 하이퍼클래스가 사용자 이름과 BSUID로 새 연락처를 자동으로 만들어요. 대화는 다른 WhatsApp 메시지와 똑같이 **대화**에 표시돼요.
4. 소통하고 후속 연락을 이어 가요. 고객이 먼저 메시지를 보내면 BSUID를 사용할 수 있게 돼요. 이후에는 WhatsApp의 기본 세션 창 및 템플릿 규칙에 따라 답장할 수 있어요.

## 달라지지 않는 부분

사용자 이름 지원은 기존 기능에 더해지는 기능이에요. 기존 WhatsApp 워크플로우는 이전과 똑같이 동작해요.

### 전화번호 메시지

전화번호 기반 WhatsApp 메시지는 지금까지와 똑같이 동작해요. 보내고 받는 방식에 차이가 없어요.

### 연락처 가져오기

전화번호로 연락처를 가져오는 **연락처 가져오기**도 지금처럼 그대로 동작해요.

### 기존 연락처

기존 레코드, 대화 기록, 실행 중인 자동화는 전혀 영향을 받지 않아요. 달라지는 점은 하나예요. 사용자 이름을 쓰는 고객의 첫 메시지가 오면 전화번호 대신 사용자 이름과 BSUID로 연락처가 만들어져요.

{% hint style="info" %}
기존 고객이거나 최근에 기업과 소통한 고객(30일 이내 또는 이미 Meta 연락처에 등록된 경우)은 전화번호가 그대로 공유돼요. 전화번호가 공유되지 않는 경우는 주로 사용자 이름으로 첫 메시지를 보내는 완전히 새로운 연락처예요.
{% endhint %}

{% hint style="warning" %}
**Meta 문서로 확인이 필요해요.** 위의 "30일" 기준은 현재 공개된 Meta 개발자 문서로 별도 확인되지 않았어요. 대략 맞는 내용으로 보되, 고객에게 구체적인 일수를 안내하기 전에 최신 Meta 출시 안내를 확인하세요. Meta는 2026년 내내 사용자 이름과 BSUID 동작을 계속 조정하고 있어요.
{% endhint %}

## 메시지 및 답장 규칙

사용자 이름 기반 연락처와 어떻게 소통하는지 알아 두면 효과적으로 응대할 수 있어요.

{% hint style="warning" %}
사용자 이름만 있는 연락처에는 먼저 대화를 시작할 수 없어요. WhatsApp에는 사용자 이름 조회 기능이 없고, 메시지는 전화번호나 BSUID로만 전달돼요. 그래서 사용자 이름만 있는 리드에게 먼저 메시지를 보낼 방법이 없어요.
{% endhint %}

### 답장할 수 있어요

사용자 이름 기반 연락처가 먼저 메시지를 보내면 시스템에서 그 연락처의 BSUID를 사용할 수 있어요. 이후에는 WhatsApp의 기본 세션 창 규칙과 템플릿 메시지 요건에 따라 답장할 수 있어요. 24시간 동안은 자유 형식으로 메시지를 보낼 수 있고, 이 시간이 지나면 승인된 템플릿을 써야 해요.

{% hint style="info" %}
**제품 팀에 확인해 보세요.** Meta는 "연락처 정보 요청(Request Contact Info)" 프롬프트를 도입했어요. 기업이 진행 중인 채팅 안에서 고객에게 전화번호 공유를 요청할 수 있는 기능이에요. 먼저 메시지를 보낼 수 없다는 위 제한을 일부 보완하는 방법이에요. 워크플로우에서 이 기능을 쓰기 전에 내 하이퍼클래스 계정에서 사용할 수 있는지 확인하세요.
{% endhint %}

## 지역별 지원 현황

WhatsApp 사용자 이름 기능은 현재 Meta에서 베타로 운영 중이고, 지역별로 단계적으로 열리고 있어요. 하이퍼클래스의 사용자 이름 기반 연락처 생성은 Meta가 이 기능을 켠 모든 지역에서 쓸 수 있어요.

| 현재 지역 | 상태 |
| --- | --- |
| 알제리, 아제르바이잔, 가나, 리비아, 네팔 | 현재 사용 가능 |
| 콜롬비아, 도미니카 공화국, 싱가포르, 말레이시아, 페루 | 현재 사용 가능 |
| 추가 지역 | Meta가 지원 지역을 넓히는 대로 순차 적용 |

### 자동 지원

따로 할 일은 없어요. Meta가 더 많은 지역에서 사용자 이름을 지원하기 시작하면, 하이퍼클래스의 연락처 자동 생성도 새 지역에서 자동으로 동작해요.

## 자주 묻는 질문

### 고객이 WhatsApp 사용자 이름을 쓰면 리드를 놓치게 되나요?

아니요. 사용자 이름을 쓰는 고객이 처음 메시지를 보내면 하이퍼클래스가 사용자 이름과 BSUID로 연락처를 자동으로 만들어요.

### 사용자 이름을 쓰는 고객에게 제가 먼저 메시지를 보낼 수 있나요?

아니요. WhatsApp에는 사용자 이름 조회 기능이 없어서 사용자 이름만 있는 연락처에는 먼저 메시지를 보낼 수 없어요. 고객이 먼저 메시지를 보내면 기본 세션 창 및 템플릿 규칙에 따라 답장할 수 있어요.

### WhatsApp 사용자 이름을 지원하려면 설정을 바꿔야 하나요?

아니요. 따로 설정할 필요가 없어요. Meta가 이 기능을 켠 지역에서는 모든 하이퍼클래스 계정에서 사용자 이름 기반 연락처 생성이 자동으로 동작해요.

### WhatsApp 사용자 이름을 커스텀 필드에 저장하거나 내보낼 수 있나요?

현재는 안 돼요. 사용자 이름은 아직 별도의 연락처 필드에 저장되지 않고 내보내기도 지원되지 않아요. 알려진 제한 사항이며 따로 관리하고 있어요.

### 기존 WhatsApp 연락처와 전화번호 메시지는 어떻게 되나요?

달라지는 것은 없어요. 기존 연락처, 전화번호 메시지, 대화 기록, 자동화는 모두 그대로예요. 사용자 이름 지원은 기존 기능에 더해지는 기능이라서, 고객이 사용자 이름을 선택해도 리드를 잃지 않아요.

### 전화번호가 계속 표시되는 고객은 어떤 경우인가요?

기존 고객이거나 최근에 기업과 소통한 고객(30일 이내 또는 이미 Meta 연락처에 등록된 경우)은 전화번호가 그대로 공유돼요. 전화번호가 공유되지 않는 경우는 사용자 이름만 쓰는 완전히 새로운 연락처가 처음 메시지를 보낼 때뿐이에요.

### 우리 지역에서도 WhatsApp 사용자 이름을 쓸 수 있나요?

사용자 이름 기능은 현재 베타이고 지역별로 단계적으로 열리고 있어요. 지금은 알제리, 아제르바이잔, 가나, 리비아, 네팔, 콜롬비아, 도미니카 공화국, 싱가포르, 말레이시아, 페루에서 사용할 수 있어요. Meta가 지원 지역을 넓히는 대로 더 많은 지역이 추가될 예정이에요.

### BSUID가 무엇인가요?

비즈니스별 사용자 식별자(BSUID)는 사용자 이름을 쓰는 고객과 내 기업의 관계마다 WhatsApp이 만들어 주는 고유 식별자예요. 고객이 전화번호를 공유하지 않기로 한 선택을 존중하면서도, 메시지에 답장하고 대화를 이어 갈 수 있게 해 줘요.
