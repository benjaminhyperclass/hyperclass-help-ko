# WhatsApp 발신·수신 번호 자동 선택

WhatsApp 번호를 여러 개 운영하면 다른 비즈니스 번호로 메시지를 보내는 실수가 생기기 쉬워요. 하이퍼클래스는 **대화**에서 올바른 WhatsApp 발신 번호를 자동으로 선택하고, 필요할 때는 규정 준수 안전장치도 적용해서 이런 실수를 줄여 줘요.

## WhatsApp 발신·수신 번호란?

WhatsApp 발신·수신 번호 선택 기능은 **대화**에서 WhatsApp 메시지에 쓸 번호를 고르는 방식을 개선해요.

| | |
| --- | --- |
| 발신 번호(From number): 메시지를 보내는 비즈니스 WhatsApp 번호예요. | 수신 번호(To number): 메시지를 받는 연락처의 전화번호예요. |

하이퍼클래스는 다음 작업을 자동으로 처리해요.

1. 새 대화를 시작할 때 기본 WhatsApp 발신 번호를 알맞게 미리 선택해요.
2. 진행 중인 대화에서는 현재 WhatsApp 24시간 세션을 기준으로 올바른 발신 번호를 찾아 고정해요.
3. 전화번호가 여러 개인 연락처는 번호마다 WhatsApp 대화 상태를 따로 관리해요.
4. 사용자가 일부러 발신 번호를 바꿨고 규정상 필요하면, 승인된 템플릿 메시지로 전환해요.

## 이 기능을 쓰면 좋은 점

- 실수 감소: 다른 WhatsApp 비즈니스 번호로 메시지를 보내는 일을 막아 줘요.
- 상담 효율 향상: 작성창에서 번호를 일일이 고민하거나 바꿀 필요가 없어요.
- 일관성 유지: 대화가 올바른 비즈니스 번호와 연락처 번호로 이어져요.
- 규정 준수 내장: 필요하면 기존 규정 준수 로직에 따라 템플릿 메시지를 사용해요.
- 여러 번호 환경 정리: 연락처에 전화번호와 활성 대화가 여러 개여도 헷갈리지 않아요.

## 사용 방법

### 새 WhatsApp 대화 시작하기

1. **대화**로 이동해요.
2. 연락처에게 새 메시지를 시작해요.
3. 작성창에 표시된 WhatsApp 발신 번호를 확인해요.
4. 메시지를 보내요.

올바른 기본 WhatsApp 번호가 자동으로 미리 선택돼요.

하이퍼클래스는 진행 중인 24시간 세션에 연결된 WhatsApp 발신 번호를 자동으로 찾아 사용해요. 그래서 다른 번호로 답장할 위험이 줄어들어요.

발신 번호를 바꿀 때 규정상 필요하면, 하이퍼클래스가 규정을 지키도록 템플릿 메시지로 전환해요.

또 연락처의 전화번호별로 대화 상태를 따로 관리해요. 연락처의 전화번호를 바꾸면 WhatsApp 라우팅도 자동으로 바뀌어요.

## 자주 묻는 질문

### WhatsApp 발신 번호가 미리 선택되어 있는 이유가 뭔가요?

어떤 번호로 보낼지 헷갈리지 않게 하고, 다른 WhatsApp 비즈니스 번호로 잘못 보내는 일을 줄이기 위해서예요. 특히 WhatsApp 번호가 여러 개인 서브 계정에서 도움이 돼요.

### 일부 대화에서 WhatsApp 발신 번호를 바꿀 수 없는 이유가 뭔가요?

진행 중인 대화에서는 현재 24시간 세션을 기준으로 발신 번호를 올바른 WhatsApp 번호로 고정해요. 규정 준수와 라우팅 문제를 막기 위해서예요.

### WhatsApp 발신 번호를 바꾸면 어떻게 되나요?

규정상 필요하면, 하이퍼클래스가 기존 규정 준수 로직에 따라 승인된 템플릿 메시지로 전환해요.

### 연락처에 전화번호가 여러 개면 WhatsApp 대화에 영향이 있나요?

네. 하이퍼클래스는 연락처의 전화번호마다 WhatsApp 대화 상태를 따로 관리해요. 연락처의 전화번호를 바꾸면 WhatsApp 라우팅도 자동으로 바뀌어요.
