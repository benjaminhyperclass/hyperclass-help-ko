# WhatsApp 스니펫 보내기와 템플릿 미리보기

저장해 둔 스니펫을 WhatsApp 대화에 보내고, WhatsApp 템플릿을 보내기 전에 미리 확인하고, 템플릿 속 미디어를 한 번에 교체하는 방법을 안내해요.

## 개요

스니펫은 텍스트나 멀티미디어를 저장해 두었다가 진행 중인 WhatsApp 대화에 넣어 쓰는 기능이에요. 같은 내용을 빠르고 일관되게 답할 수 있어요. WhatsApp 템플릿(사전 승인된 메시지)은 스니펫과 별개이며, 24시간이 지난 연락처에 메시지를 보낼 때 사용해요.

**최근 업데이트**

- 대화 화면의 메시지 작성창과 일괄 작업에서 템플릿을 **보내는 시점에 바로 미리보기**할 수 있어요.
- 템플릿을 고를 때 템플릿 **카테고리**와 **언어**가 함께 표시돼요.
- 템플릿 **미디어**를 내 기기의 파일로 **한 번에 교체**할 수 있어요.
- 새 화면이 **실험실**에 먼저 제공될 수 있어요.

{% hint style="info" %}
실험실에서 제공되는 업데이트 기능을 켜려면 **서브 계정 > 실험실**로 이동하세요. 이 템플릿 업데이트는 기본으로 제공될 예정이지만, 화면이 보이지 않으면 **실험실**을 확인해 보세요.
{% endhint %}

## 스니펫 보내기, 템플릿 미리보기, 미디어 교체 단계

### 1단계. 스니펫 또는 템플릿 준비하기

1. **마케팅 > 템플릿**으로 이동하세요.
2. **템플릿(스니펫) 추가 > 텍스트 템플릿(스니펫) 추가**를 클릭해 새 스니펫을 만들거나, 기존 스니펫을 편집하세요.
3. 나중에 빨리 찾을 수 있도록 알아보기 쉬운 이름을 붙여 저장하세요.

![스니펫 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064131720/original/ceZDjknikYyX69AvwtF8oT8kh_GvgRKZLQ.png?1770168661)

### 2단계. 대화에서 스니펫 보내기

1. **대화**로 이동하세요.
2. 연락처와 진행 중인 WhatsApp 대화를 여세요. 최근 24시간 안에 연락처가 보낸 메시지가 있어야 해요.
3. 채널이 **WhatsApp**으로 선택되어 있는지 확인하세요.
4. 메시지 작성창에서 **Insert Snippets**(스니펫 삽입) 또는 스니펫 아이콘을 클릭하세요.
5. 보낼 스니펫을 선택하세요. 내용이 작성창에 자동으로 채워져요.
6. 필요하면 스니펫 내용을 수정하세요. **커스텀 값**이나 **트리거 링크**를 넣을 수 있어요.
7. **보내기**를 클릭하세요.

### 3단계. 보내는 시점에 WhatsApp 템플릿 미리보기 (대화·일괄 작업)

![템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064131725/original/TGGfxxBq0qAMAsz_Q3DGMPnhGgzElrs-mw.png?1770168682)

1. 대화의 메시지 작성창이나 일괄 작업의 템플릿 선택 화면에서, 직접 입력이나 스니펫 대신 **WhatsApp 템플릿 선택**을 고르세요.
2. 템플릿 내용이 **바로 미리보기**로 표시돼요.
3. 템플릿 이름 옆에서 **템플릿 카테고리**(예: 마케팅, 유틸리티)와 **언어**를 확인하세요.
4. 템플릿이 맞는지 확인한 뒤 보내거나 예약하세요.

{% hint style="info" %}
보내는 시점에 미리보기를 볼 수 있어서, 템플릿 내용을 확인하려고 WhatsApp 설정을 따로 열 필요가 없어요. 보내기 전에 카테고리와 언어를 미리보기로 확인하세요.
{% endhint %}

![템플릿 미리보기 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064131758/original/hQHl5nPJRG8jv5tBJJKLT1OTxwe60nWe6w.png?1770168782)

### 4단계. WhatsApp 템플릿의 미디어 한 번에 교체하기

선택한 템플릿에 미디어(이미지, 문서, 동영상)가 있으면 작성창에 미디어 자리와 **미디어 교체** 옵션이 표시돼요.

1. **미디어 교체**를 클릭하세요.
2. 파일 탐색기가 열리면 내 기기에서 파일을 고르세요.
3. 선택한 파일이 작성창 미리보기에서 바로 템플릿 미디어를 대신해요.
4. 메시지를 확인하고 보내세요.

{% hint style="info" %}
이 기능은 템플릿을 선택하는 대화와 일괄 작업에서 쓸 수 있어요. 미디어를 교체해도 Meta/WhatsApp에 등록된 템플릿 자체는 바뀌지 않아요. 보내는 그 메시지에만 미디어가 바뀌어 들어가요.
{% endhint %}

![미디어 교체 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064131831/original/okDZf39N8wkfQajbs28YJrIj0ME3JzoAdA.png?1770169177)

### 5단계. 워크플로우로 스니펫 또는 템플릿 보내기

워크플로우 편집 화면은 영어로 표시돼요.

1. **자동화**로 이동해 **Create Workflow**(워크플로우 만들기)를 클릭하세요. 기존 워크플로우를 편집해도 돼요.
2. 시작 트리거를 추가하세요.
3. 이어서 **WhatsApp: Customer Service Window Check**(WhatsApp: 고객 서비스 창 확인) 액션을 추가하세요. 연락처가 24시간 안에 있는지 확인하는 액션이에요.
4. 이 확인 액션의 **Open**(열림) 분기 아래에 **WhatsApp** 액션을 추가하세요.
5. 템플릿을 꼭 써야 하면 **WhatsApp Template**(WhatsApp 템플릿)을 고르세요. 스니펫 내용을 넣어 보내려면 **None – Free form message**(없음 – 자유 형식 메시지)를 고르고 스니펫 내용을 넣으세요.
6. 템플릿을 쓰면 워크플로우 화면에서도 대화와 비슷하게 템플릿 미리보기가 보이고 미디어를 교체할 수 있어요.
7. 워크플로우를 저장하고 게시하세요.

![워크플로우 WhatsApp 액션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064131873/original/PiyeF_OcVZKBV5AGBdT-UoddCqLnv2h4lw.png?1770169310)

### 6단계. 일괄 작업으로 템플릿 보내기와 미디어 교체

1. **연락처**(또는 일괄 작업을 쓸 수 있는 다른 화면)로 이동해 메시지를 보낼 연락처를 선택하세요.
2. **일괄 액션 > WhatsApp 보내기**를 선택하세요. **대량 WhatsApp** 흐름으로 진행해도 돼요.
3. **WhatsApp 템플릿 선택**을 고르고, 미리보기로 카테고리와 언어를 확인하세요.
4. 템플릿에 미디어가 있으면 **미디어 교체**로 내 기기의 파일로 바꿀 수 있어요.
5. **확인 및 전송**을 클릭해 일괄 발송을 마무리하세요.

{% hint style="info" %}
일괄 작업에서도 대화와 같은 템플릿 미리보기와 미디어 교체 기능을 쓸 수 있어요. 받는 사람이 수신 동의, 허용되는 콘텐츠 등 메시지 발송 규정을 충족하는지 확인하세요.
{% endhint %}

![일괄 작업 WhatsApp 템플릿 발송](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064131897/original/G6-Vtif6kGmeBjDIx5pViSPrpxF7Wu-ogQ.png?1770169397)

## 문제 해결 및 팁

- 템플릿 미리보기나 미디어 교체 옵션이 보이지 않으면 대화 화면을 새로고침하고, 내 계정에서 업데이트된 화면을 지원하는지 확인하세요.
- 미디어 교체가 안 되면 파일 형식과 크기가 WhatsApp과 플랫폼의 제한에 맞는지 확인하세요.
- 템플릿에 엄격한 자리표시자가 있으면 Meta가 승인한 구조를 그대로 따라야 할 수 있어요. 미디어를 교체해도 템플릿 형식 규칙은 피할 수 없어요.

## 자주 묻는 질문

### 스니펫이 무엇인가요?
스니펫은 CRM에 저장해 두는 텍스트나 멀티미디어 묶음이에요. 진행 중인 WhatsApp 대화에 넣어서 빠르고 일관되게 답할 수 있어요.

### 스니펫과 WhatsApp 템플릿은 뭐가 다른가요?
WhatsApp 템플릿은 24시간이 지난 사용자에게 연락할 때 꼭 필요한 사전 승인 메시지로, Meta/WhatsApp의 승인을 받아야 해요. 스니펫은 24시간 안에 쓰는 내부용 문구로, 내용을 수정할 수 있고 승인이 필요 없어요.

### WhatsApp 템플릿을 보내기 전에 미리 볼 수 있나요?
네. 이제 대화의 메시지 작성창과 일괄 작업에서 템플릿을 바로 미리 볼 수 있어요. 미리보기에는 메시지 내용과 함께 템플릿의 카테고리와 언어가 표시돼요.

### 보내는 시점에 템플릿 안의 미디어를 바꿀 수 있나요?
네. 템플릿에 미디어가 있으면 **미디어 교체**를 클릭해서 내 기기의 파일을 올릴 수 있어요. 대화와 일괄 작업에서 쓸 수 있어요.

### 24시간이 지난 연락처에도 스니펫을 보낼 수 있나요?
아니요. 스니펫은 연락처가 최근 24시간 안에 메시지를 보내서 대화가 열려 있을 때만 보낼 수 있어요. 24시간이 지났다면 사전 승인된 WhatsApp 템플릿을 사용하세요.

### 미디어를 교체하면 저장된 템플릿도 바뀌나요?
아니요. 미디어 교체는 그 발송에만 적용돼요. 저장된 템플릿은 그대로이며, 처음 승인받은 내용을 유지해요.

### 새 화면 기능이 보이지 않으면 어디서 켜나요?
**서브 계정 > 실험실**에서 선택 가능한 화면 업데이트를 확인하세요. 계정에 해당 옵션이 없는데도 기능이 보이지 않으면 하이퍼클래스 고객지원에 문의해 계정 확인을 요청하세요.
