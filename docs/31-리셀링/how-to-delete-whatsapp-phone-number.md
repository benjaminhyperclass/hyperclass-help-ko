# WhatsApp 전화번호 삭제

WhatsApp 계정에 등록된 전화번호를 삭제하는 방법이에요. 확인 단계를 몇 번 거치면 번호를 삭제할 수 있어요.

## WhatsApp 전화번호 삭제 단계

1. **설정**으로 이동해 **WhatsApp**을 선택하세요. 삭제할 번호 옆의 점 3개 아이콘을 클릭한 다음 **삭제**를 선택하세요.

   ![WhatsApp 번호 옆 점 3개 메뉴에서 삭제 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042250254/original/57yKNC0tTQyQkuTDLtc8gixVXGXAE8XqTQ.png?1740553564)

2. **삭제**를 누르면 확인 페이지로 이동해요. 여기서 **삭제**를 한 번 더 눌러 확인하세요.

   ![삭제 확인 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042249555/original/nNFdb6YZUDxetwodZZVQlOQNdmDrJBUclA.png?1740552845)

3. **비밀번호를 입력하세요** 칸에 비밀번호를 입력하고 **삭제**를 눌러 진행하세요.

   ![비밀번호 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042249619/original/fOPHM1U6UcnZqJbEAFkMJOTOhWp_GE_F3g.png?1740552907)

4. **비밀번호를 입력하세요** 칸에 비밀번호를 입력하고 **삭제**를 눌러 삭제를 확정하세요.

   ![비밀번호 입력 후 삭제 확정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042249748/original/6kBBCbeHfiAcUyVcD8fTU9b1N8exXL12wQ.png?1740553082)

## 자주 묻는 질문

### WhatsApp 전화번호를 삭제하면 어떻게 되나요?
삭제한 번호는 더 이상 WhatsApp 계정에 연결되지 않아요. 그 번호로는 메시지를 보내거나 받을 수 없어요.

### 전화번호를 삭제하면 WhatsApp 계정도 삭제되나요?
아니요. 전화번호를 삭제하면 계정에서 번호만 제거돼요. 등록된 다른 번호가 있으면 WhatsApp 계정은 그대로 유지돼요.

### 삭제한 WhatsApp 전화번호를 복구할 수 있나요?
아니요. 한 번 삭제한 번호는 복구할 수 없어요. WhatsApp에서 다시 쓰려면 번호를 새로 등록해야 해요.

### 번호를 삭제하기 전에 채팅을 백업해야 하나요?
나중에 그 번호를 다시 등록할 계획이라면 채팅을 백업해 두는 것이 좋아요. 중요한 메시지를 잃어버리지 않도록 미리 챙기세요.

### 비밀번호 없이 WhatsApp 전화번호를 삭제할 수 있나요?
아니요. 보안을 위해 삭제를 확인할 때 비밀번호를 꼭 입력해야 해요.
