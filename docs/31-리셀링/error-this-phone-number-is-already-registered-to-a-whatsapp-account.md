# 오류 "This phone number is already registered to a WhatsApp account" 해결

WhatsApp(Business 또는 API) 연결을 시작할 때 "This phone number is already registered to a WhatsApp account" 오류가 나오는 경우가 있어요. 이 문서에서 오류가 생기는 이유와 해결 방법을 안내해요.

## 이 오류는 무슨 뜻인가요?

연결하려는 전화번호가 **이미 다른 WhatsApp 계정에 연결되어 있다**는 뜻이에요. 전화번호는 한 번에 **WhatsApp 계정 하나**에만 연결할 수 있어요. 지금 연결된 계정에서 번호를 해제하기 전에는 다시 연결할 수 없어요.

## 왜 이 오류가 나타나나요?

다음 중 하나가 원인일 수 있어요.

- 번호가 **WhatsApp 모바일 앱**(개인용 또는 비즈니스용)에서 사용 중이에요.
- 번호가 이미 다른 **WhatsApp Business Platform** 또는 제공업체에 연결되어 있어요.
- 번호를 최근에 해제했지만 WhatsApp이 아직 변경 사항을 처리하고 있어요.
- 예전에 WhatsApp에서 쓰던 번호가 아직 완전히 해제되지 않았어요.

## 해결 방법

아래 단계를 순서대로 따라 해 보세요.

### 1단계: 기존 WhatsApp 계정에서 번호 해제하기

**번호가 휴대폰에서 사용 중인 경우**

1. 휴대폰에서 WhatsApp을 여세요.
2. **설정**으로 이동하세요.
3. **계정**을 선택하세요.
4. **계정 삭제**를 누르세요.
5. 전화번호를 입력해 삭제를 확인하세요.

{% hint style="warning" %}
계정을 삭제하면 채팅 기록이 영구적으로 지워지고, 번호도 WhatsApp에서 해제돼요.
{% endhint %}

**번호가 다른 제공업체에 연결된 경우**

현재 WhatsApp 제공업체에 문의해서, 해당 업체의 WhatsApp Business Platform 계정에서 번호를 **완전히 해제하거나 삭제**해 달라고 요청하세요.

### 2단계: 번호 상태가 갱신될 때까지 기다리기

번호를 해제한 뒤에는 다음 사항을 참고하세요.

- WhatsApp 시스템이 번호 상태를 갱신하도록 **최대 3분** 기다리세요.
- WhatsApp 내부 처리 상황에 따라 조금 더 걸릴 수도 있어요.

바로 여러 번 다시 시도하지 마세요. 오히려 더 늦어질 수 있어요.

### 3단계: 연결 다시 시도하기

기다린 후에 아래 순서로 진행하세요.

1. 연결(온보딩) 화면으로 돌아가요.
2. 전화번호를 다시 입력하세요.
3. 인증 단계를 진행해요.

이 오류는 시스템 장애가 아니에요. 전화번호 하나가 계정 하나에만 연결되도록 WhatsApp이 두는 안전장치예요. 번호를 제대로 해제하고 상태가 갱신되면 연결이 정상적으로 완료돼요.
