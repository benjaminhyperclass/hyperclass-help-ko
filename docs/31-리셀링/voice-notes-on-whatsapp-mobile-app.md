# WhatsApp 모바일 앱에서 음성 메모 보내기

모바일 앱의 WhatsApp 대화에서 음성 메모를 바로 녹음해 보낼 수 있어요.

## 새로 추가된 기능

- **음성 메모 녹음:** 음성 메모 아이콘을 누르면 새 음성 메모 녹음을 시작해요.
- **일시정지와 삭제:** 녹음 중인 음성 메모를 잠시 멈췄다가 다시 이어서 녹음할 수 있어요. 녹음한 내용을 삭제하고 새로 녹음할 수도 있어요.
- **음성 메모 보내기:** 녹음한 음성 메모를 대화 안에서 바로 보낼 수 있어요.

---

## 사용 방법

1. 모바일 앱을 열고 사용할 서브 계정을 선택하세요.
2. **대화** 메뉴로 이동해서 진행 중인 WhatsApp 채팅을 선택하세요.
3. 텍스트 입력란 옆에 있는 **음성 메모 녹음** 아이콘을 누르세요.
4. 음성 메모를 녹음하세요. 녹음 중에는 일시정지했다가 다시 이어서 녹음하거나, 삭제할 수 있어요.
5. 녹음을 마쳤으면 보내기 아이콘을 눌러 전송하세요.
