# WhatsApp 메시지가 "Invalid Parameter" 오류로 전송되지 않을 때

**보낸 사람**과 **받는사람** 번호가 같을 때 WhatsApp 메시지가 "Invalid Parameter"(잘못된 매개변수) 오류로 실패하는 이유와 해결 방법을 안내해요.

## 증상

WhatsApp 메시지를 보내면 아래 화면처럼 "Invalid Parameter" 오류가 나면서 전송에 실패해요.

![WhatsApp 메시지 전송 시 Invalid Parameter 오류가 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045416532/original/qfxzFl3vBfbvog8o6oToLFny6oH_7nHzAA.png?1745301423)

---

## 해결 방법

**보낸 사람**과 **받는사람** 번호가 같은지 확인하세요. 두 번호가 똑같으면 WhatsApp 메시지는 "Invalid Parameter" 오류로 실패해요.

```
보내는 번호와 같은 번호로는 WhatsApp 메시지를 보낼 수 없기 때문입니다. 테스트할 때는 다른 번호를 사용하도록 고객에게 안내해 주세요.
```
