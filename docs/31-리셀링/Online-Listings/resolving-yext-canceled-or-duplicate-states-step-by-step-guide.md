# Yext 취소됨·중복 상태 해결하기

Yext가 중복 상태이거나 취소됨 상태로 표시될 때 해결하는 방법을 안내해요. 서브 계정이나 고객사가 Yext를 구독하려는데, 다른 외부 업체를 통해 이미 Yext에 활성화된 등록 정보가 있는 경우에 따라 해 보세요.

![Yext 중복 또는 취소됨 상태 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155026988362/original/7ScSLdKbSc2k3ifEtZzPkUu-_GpruACA0g.jpeg?1717403587)

## 해결 방법

1. 해당 서브 계정에 로그인하세요.
2. **평판 관리**(Reputation)로 이동한 뒤 **리스팅** 페이지를 여세요.
3. 페이지에 강조 표시된 링크를 클릭하세요. Yext와 하이퍼클래스가 참조(CC)로 지정된 이메일 작성 화면이 열려요.
4. 이메일 본문에 비즈니스 이름, 주소, 전화번호를 적어 보내세요. Yext 지원팀이 문제를 자세히 확인하는 데 필요한 정보예요.

{% hint style="info" %}
필요한 경우 서브 계정의 Yext 요청을 다시 제출해도 되는지 Yext에 확인을 받아야 할 수 있어요. 외부 업체를 통해 Yext 서비스를 취소할 때는 처리 과정이 복잡해질 수 있기 때문에 거치는 확인 절차예요.
{% endhint %}

추가 도움이나 확인이 필요하면 하이퍼클래스 고객지원에 문의하세요.
