# WhatsApp 오류 #131037 — 표시 이름 인증서가 활성화되지 않았어요

WhatsApp 메시지를 보낼 때 표시 이름 인증서 오류가 나타나면 이 문서를 보세요. 원인과 해결 방법을 안내해요.

```
Error #131037: The display name certificate for this phone number is not currently active. Messages cannot be sent until the certificate is applied to the number.
```

## 오류가 나타나는 원인

오류 #131037은 메시지를 보내는 전화번호에 표시 이름 인증서가 활성화되어 있지 않을 때 나타나요.

계정에서 표시 이름이 **승인됨**으로 보여도, 메시지를 보내려면 인증서를 전화번호에 적용해야 해요. Cloud API 번호는 재등록으로 적용해요. 재등록은 번호에 인증서를 활성화하는 일반적인 단계예요.

- 표시 이름은 **승인됨**으로 보이지만 인증서가 번호에 적용되지 않았어요.
- 표시 이름이 승인된 뒤 재등록을 완료하지 않았어요.

## 해결 방법

WhatsApp Cloud API로 전화번호를 다시 등록하세요. 재등록하면 번호에 표시 이름 인증서가 활성화돼요. 인증서가 적용되려면 꼭 필요한 단계예요.

### 올바른 PIN 사용

- 2단계 인증을 사용 중이라면 기존 6자리 2단계 인증 PIN을 입력하세요.
- 2단계 인증을 사용하지 않는다면 이번 등록에 사용할 6자리 PIN을 새로 설정할 수 있어요.

### 발송 다시 시도

재등록이 끝나면 템플릿 메시지를 다시 보내 보세요. 오류가 더 이상 나타나지 않아야 해요.

## 오류가 계속될 때

재등록 후에도 오류 #131037이 계속되면 아래 내용을 모아 하이퍼클래스 고객지원에 문의하세요. 자세히 살펴볼게요.

- 이 번호에 현재 제출된 표시 이름과 승인된 날짜
- 번호에 2단계 인증이 켜져 있는지 여부
- 모든 템플릿에서 오류가 나는지, 특정 템플릿에서만 나는지

```
고객지원에 문의할 때는 Location ID(서브 계정 ID), 전화번호 ID, 오류 메시지 전체, 문제 상황을 담은 스크린샷이나 녹화 영상을 함께 보내 주세요. 더 빠르게 확인할 수 있어요.
```

## 자주 묻는 질문

### 표시 이름이 승인됨으로 나오는데 왜 계속 오류가 나나요?

표시 이름이 승인된 것과 인증서가 활성화된 것은 별개예요. 메시지를 보내려면 재등록으로 인증서를 전화번호에 적용해야 해요. 계정에서 표시 이름이 승인된 것으로 보여도 재등록은 꼭 필요한 단계예요.

### 재등록하면 기존 템플릿이나 연락처에 영향이 있나요?

아니요. 재등록은 전화번호에 표시 이름 인증서를 활성화할 뿐이에요. 승인된 템플릿, 연락처 데이터, 다른 계정 설정에는 영향이 없어요.

### 재등록할 때 어떤 PIN을 써야 하나요?

번호에 2단계 인증이 켜져 있다면 기존 6자리 2단계 인증 PIN을 쓰세요. 2단계 인증이 꺼져 있다면 재등록할 때 6자리 PIN을 새로 설정할 수 있어요.

### 이 오류는 모든 템플릿에 영향을 주나요, 특정 템플릿에만 영향을 주나요?

오류 #131037은 개별 템플릿이 아니라 전화번호의 인증서와 관련된 오류예요. 보통 그 번호에서 나가는 모든 메시지에 영향을 줘요. 재등록 후에도 특정 템플릿에서만 오류가 나타나면 위에서 안내한 내용을 모아 하이퍼클래스 고객지원에 문의하세요.

### 전화번호 ID는 어디에서 확인하나요?

**Meta WhatsApp Manager**의 **Account tools**(계정 도구) > **전화번호**에서 확인할 수 있어요. 하이퍼클래스의 서브 계정에서는 **설정 > WhatsApp**에서도 볼 수 있어요.
