# WhatsApp 오류 131026 — Message Undeliverable(메시지 전달 불가)

WhatsApp 메시지가 오류 코드 131026과 함께 전달되지 않을 때 보는 문제 해결 가이드예요. 오류의 뜻, 알려진 원인, 원인을 좁혀 가는 방법, 해결 방법을 설명해요.

이 문서에서 알 수 있는 내용은 다음과 같아요.

- 오류 131026의 의미
- 알려진 모든 원인
- 원인을 진단하는 방법
- 해결 방법

## 오류 131026이란?

오류 **131026**은 WhatsApp Cloud API의 전달 단계 실패예요. 메시지는 Meta 서버에 정상적으로 접수됐지만 **수신자의 기기로 전달되지 못했다**는 뜻이에요.

API 응답에서는 다음과 같이 표시돼요.

```
"errors": [
  {
    "code": 131026,
    "title": "Message Undeliverable"
  }
]
```

Meta 공식 문서에 따르면 131026은 의도적으로 **"버킷 오류(bucket error)"**로 만든 코드예요. 서로 다른 여러 원인이 모두 같은 오류 코드로 반환된다는 뜻이에요. Meta는 사용자 개인정보를 보호하려고 구체적인 이유를 항상 알려 주지는 않아요. 그래서 원인을 찾으려면 직접 하나씩 확인해야 해요.

{% hint style="warning" %}
오류 131026이 반환된 메시지에는 요금이 청구되지 않아요. 메시지가 전달되지 않았고 대화도 열리지 않았기 때문에 비용이 발생하지 않아요.
{% endhint %}

## 알려진 원인

아래 원인은 Meta 공식 문서에 나와 있거나 WhatsApp 개발자 커뮤니티에서 확인된 것들이에요.

### 1. 수신자 전화번호가 WhatsApp에 없음

메시지를 보낸 번호로 WhatsApp 계정이 등록되지 않았거나, 더 이상 존재하지 않는 번호예요. 오류 131026의 가장 흔한 원인이에요.

### 2. 수신자가 내 비즈니스 번호를 차단함

수신자가 내 WhatsApp 비즈니스 번호를 차단하면 메시지를 전달할 수 없어요. Meta는 사용자 개인정보를 보호하려고 차단 사실을 알리지 않고 오류 131026만 반환해요.

### 3. 수신자가 Meta의 서비스 이용약관 또는 개인정보처리방침에 동의하지 않음

수신자가 WhatsApp의 최신 서비스 이용약관과 개인정보처리방침에 동의하지 않았다면 일부 메시지, 특히 템플릿 메시지가 전달되지 않을 수 있어요.

### 4. 수신자가 오래된 WhatsApp 버전을 사용 중

Cloud API 메시지를 받으려면 WhatsApp 앱이 최소 버전 이상이어야 해요. 수신자가 앱을 업데이트하지 않았다면 버튼, 링크, 미디어가 포함된 메시지가 전달되지 않을 수 있어요. 필요한 최소 버전은 다음과 같아요.

- **Android:** 2.21.15.15 이상
- **iOS:** 2.21.170.4 이상
- **KaiOS:** 2.2130.10 이상

### 5. 인도(+91) 번호로 인증 템플릿을 보냄

**Authentication**(인증) 템플릿은 국가 코드가 +91(인도)인 WhatsApp 사용자에게 **보낼 수 없어요**. Meta의 절대적인 제한이라 버그가 아니고 우회할 수도 없어요. 인도 번호에는 SMS, 이메일 등 다른 OTP 채널을 사용하세요.

### 6. 마케팅 메시지 빈도 제한에 도달함

Meta는 사용자가 여러 비즈니스로부터 마케팅 메시지를 너무 많이 받지 않도록 **마케팅 템플릿 빈도 제한(Marketing Template Frequency Capping)**을 적용해요. 사용자가 짧은 기간에 여러 비즈니스에서 마케팅 메시지를 이미 여러 건 받았다면, 수신에 동의한 비즈니스의 메시지라도 추가 마케팅 메시지가 차단될 수 있어요. 정확한 제한 기준은 수시로 바뀌고 Meta가 공개하지 않아요.

{% hint style="info" %}
이 경우 오류 **131049**가 반환될 때도 있어요.
{% endhint %}

### 7. 수신자가 제한 또는 제재 대상 국가에 있음

관련 법규에 따라 제재 또는 제한 대상인 국가의 사용자에게는 메시지를 전달할 수 없어요. Meta는 API 응답에서 어떤 국가가 제한 대상인지 알려 주지 않아요.

### 8. 비즈니스 간(API to API) 메시지 전송

WhatsApp Business API는 비즈니스가 일반 소비자에게 메시지를 보내는 용도로 만들어졌어요. API 계정끼리 메시지를 주고받는 용도가 아니에요. 한 WhatsApp Business API 계정에서 다른 WhatsApp Business API 계정으로 템플릿 메시지를 보내면 항상 오류 131026이 반환돼요.

## 원인을 진단하는 방법

Meta가 여러 원인을 같은 오류 코드로 묶어 반환하기 때문에, 어떤 원인으로 131026이 발생했는지는 하나씩 제외해 가며 찾는 방법이 가장 좋아요.

1. 같은 번호로 **텍스트만 있는 유틸리티 메시지**를 보내 보세요. 버튼, 미디어, 링크 없이 **유틸리티** 템플릿으로 만든 간단한 텍스트 메시지예요.
   - **정상적으로 전달되면:** 수신자의 WhatsApp 버전이 너무 낮아 고급 메시지 형식을 표시하지 못하는 문제일 가능성이 커요. 수신자에게 WhatsApp을 업데이트해 달라고 요청하세요.
   - **이것도 실패하면:** 해당 번호가 WhatsApp에 없거나, 연결이 끊겼거나, 사용자가 내 번호를 차단했을 가능성이 커요. 활성 목록에서 제거하세요.
2. **오류가 일부에만 생기는지, 전체에서 생기는지 확인하세요.** 특정 번호 하나, 일부 연락처 그룹, 모든 메시지 중 어디에서 실패하는지 살펴보세요.
   - **번호 하나에서만 발생하면:** 해당 연락처가 WhatsApp에 없거나, 나를 차단했거나, 서비스 이용약관에 동의하지 않았을 가능성이 커요.
   - **마케팅 메시지 전반에서 실패하면:** Meta의 마케팅 빈도 제한 때문일 가능성이 커요. 대신 유틸리티 메시지를 보내 보세요.
3. **전화번호 형식을 확인하세요.** 모든 번호에 올바른 국제 국가 코드가 있고, 불필요한 문자나 공백이 없는지 확인하세요.
4. **템플릿 카테고리를 확인하세요.** 인도(+91) 번호로 보내는 경우 **Authentication** 템플릿을 쓰고 있지 않은지 확인하세요.
5. **Meta 플랫폼 상태를 확인하세요.** [metastatus.com/whatsapp-business-api](https://metastatus.com/whatsapp-business-api)에서 메시지 전달에 영향을 주는 장애가 없는지 확인하세요.

## 해결 방법

확인한 원인에 따라 다음과 같이 조치하세요.

| 원인 | 해결 방법 |
| --- | --- |
| WhatsApp에 없는 번호 | 연락처 목록에서 번호를 삭제하세요. 메시지를 보내기 전에 전화번호 검증 서비스를 사용하세요. |
| 번호가 나를 차단함 | 해당 연락처에 메시지 보내기를 중단하세요. 차단한 번호로 계속 전송을 시도해도 전달되지 않아요. |
| 서비스 이용약관에 동의하지 않음 | 내 쪽에서 할 수 있는 조치는 없어요. 수신자가 WhatsApp을 열어 직접 약관에 동의해야 해요. |
| 오래된 WhatsApp 버전 | 먼저 텍스트만 있는 간단한 메시지를 보내세요. 전달되면 수신자에게 WhatsApp 앱을 업데이트해 달라고 요청하세요. |
| 인도(+91) 번호로 인증 템플릿 전송 | 인도 번호에는 SMS, 이메일 등 다른 OTP 채널을 사용하세요. Meta의 절대적인 제한이에요. |
| 마케팅 빈도 제한 | 대신 유틸리티 메시지를 보내세요. 마케팅 메시지는 잠시 기다린 뒤 다시 보내세요. 재시도할 때는 간격을 점점 늘리고, 같은 메시지를 바로 다시 보내지 마세요. |
| 제한 대상 국가 | 제한 또는 제재 대상 국가의 연락처를 메시지 발송 목록에서 제거하세요. |
| 비즈니스 간 메시지 전송 | Meta가 지원하지 않는 방식이에요. 먼저 WhatsApp 일반 앱에서 대화창을 열어 주세요. |

{% hint style="warning" %}
바로 다시 보내지 마세요. 131026의 원인이 빈도 제한이라면 같은 메시지를 곧바로 다시 보내도 같은 오류가 반환돼요. 잠시 기다린 뒤 간격을 점점 늘려 가며 다시 시도하세요.
{% endhint %}

## 예방 방법

오류 131026을 줄이는 모범 사례예요.

- **보내기 전에 전화번호를 검증하세요.** 번호 검증 서비스로 번호가 존재하고 WhatsApp에 등록돼 있는지 확인한 뒤 연락처 목록에 추가하세요.
- **수신 동의를 제대로 받으세요.** 메시지를 보내기 전에 모든 연락처가 내 비즈니스의 WhatsApp 메시지 수신에 명시적으로 동의했는지 확인하세요.
- **연락처 목록을 깨끗하게 관리하세요.** 수신을 해지했거나, 나를 차단했거나, 계속 전달에 실패하는 연락처는 주기적으로 제거하세요.
- **올바른 템플릿 카테고리를 쓰세요.** 유틸리티 템플릿을 마케팅으로 잘못 분류하면 빈도 제한에 걸릴 가능성이 커져요.
- **템플릿 품질 등급을 모니터링하세요.** 품질 등급이 낮으면 전달 실패 위험이 높아져요. 템플릿은 수신자에게 관련성 있고, 명확하고, 도움이 되도록 유지하세요.
- **인도(+91) 번호에는 Authentication 템플릿을 쓰지 마세요.** 인도 사용자에게는 SMS나 이메일 OTP로 대신 안내하세요.

## 관련 오류 코드

131026과 함께 나타날 수 있는 다른 전달 오류예요.

| 오류 코드 | 제목 | 설명 |
| --- | --- | --- |
| 131049 | Healthy Ecosystem Engagement | 사용자를 과도한 메시지로부터 보호하려고 마케팅 메시지가 차단됐어요. 바로 다시 보내지 마세요. |
| 131051 | Unsupported Message Type | 사용한 메시지 유형을 WhatsApp Business API가 지원하지 않아요. |
| 131021 | Same Sender and Recipient | 발신자와 수신자의 전화번호가 같아요. 다른 번호로 보내세요. |
| 130497 | Restricted from Messaging Country | 내 WhatsApp 비즈니스 계정이 해당 국가 사용자에게 메시지를 보낼 수 있도록 승인되지 않았어요. |

## 자주 묻는 질문

### 오류 131026이 반환된 메시지에도 요금이 청구되나요?

아니요. 오류 131026으로 실패한 메시지는 전달되지 않고 대화도 열리지 않아서 요금이 청구되지 않아요.

### 메시지가 전달되지 않은 정확한 이유를 알 수 있나요?

직접 알 수는 없어요. Meta는 수신자의 개인정보를 보호하려고 131026을 폭넓은 코드로 의도적으로 사용해요. 이 문서의 진단 단계로 원인을 좁힐 수는 있지만, 정확한 이유가 항상 공개되는 것은 아니에요.

### 이 오류가 나면 바로 메시지를 다시 보내도 되나요?

아니요. 바로 다시 보내도 도움이 되지 않고, 원인이 빈도 제한이라면 오히려 상황이 나빠질 수 있어요. 다시 보내야 한다면 시도 사이의 간격을 점점 늘리세요. 번호가 WhatsApp에 없거나 나를 차단한 경우에는 다시 보내도 성공하지 못해요.

### 잘 전달되던 메시지가 갑자기 131026으로 실패해요. 무엇이 바뀐 건가요?

마케팅 템플릿에서 131026 오류가 갑자기 늘었다면 Meta의 마케팅 빈도 제한이 원인일 가능성이 가장 커요. 이 제한은 2024년부터 계속 확대되고 있어요. 같은 연락처에 유틸리티 메시지를 보내 전달되는지 확인해 보세요. 전달된다면 마케팅 템플릿의 전달 제한이 문제예요.

### 오류 131026과 131049는 어떻게 다른가요?

두 오류 모두 메시지를 전달할 수 없다는 뜻이지만, **131049**는 Meta의 마케팅 메시지 빈도 제한("Healthy Ecosystem Engagement")과 직접 관련된 오류예요. **131026**은 더 포괄적이어서 잘못된 번호, 차단한 연락처, 오래된 앱 버전 등 여러 원인으로 발생할 수 있어요. 경우에 따라 빈도 제한이 131026으로 나타나기도 해요.

### 인도(+91) 번호로는 메시지를 아예 보낼 수 없나요?

아니요. 인도(+91) 번호에도 **마케팅**과 **유틸리티** 템플릿은 문제없이 보낼 수 있어요. **Authentication** 템플릿만 +91 번호로 보낼 수 없어요. Meta의 절대적인 규칙이라 바꿀 수 없어요.

## 요약

오류 131026은 메시지가 전달되지 않았다는 뜻이에요. 가장 흔한 원인은 잘못된 번호, 차단한 연락처, 마케팅 빈도 제한이에요. 위의 진단 단계로 원인을 확인하고, 연락처 목록을 주기적으로 정리하고, 메시지를 보내기 전에 항상 수신 동의를 받으세요. 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.
