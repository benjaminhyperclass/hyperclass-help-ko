# WhatsApp 플랫폼 요금 및 기능 비교

하이퍼클래스 WhatsApp 애드온의 요금 구조와 포함 기능을 정리하고, 다른 WhatsApp 서비스와 비교한 문서예요. WhatsApp 도입을 검토하거나 고객사에 안내할 때 참고하세요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

{% hint style="info" %}
**WhatsApp 요금 정보가 이동했어요.** 2026년 10월 1일부터 적용되는 청구 변경 사항을 반영해 WhatsApp 요금 정보를 업데이트했어요. 최신 메시지 요금, 무료 제공량, 재청구 정보는 [WhatsApp 요금, 청구 및 재청구 가이드](WhatsApp/whatsapp-pricing-billing-and-rebilling-guide.md)에서 확인하세요. 현재 WhatsApp 요금은 이 가이드를 가장 먼저 참고하세요.
{% endhint %}

## WhatsApp 애드온 요금

요금 구조가 단순해요. 부풀린 추가 요금도, 숨은 비용도 없어요.

| 항목 | 요금 | 설명 |
| --- | --- | --- |
| 월 구독료 | $10 | 월 기준 |
| 메시지 비용 | 무료 | 수신 메시지, 답장, 서비스 대화 |
| 거래 수수료 | 5% | Stripe 결제 처리에만 적용 |

## 월 $10에 포함된 항목

- AI 기반 대화
- 워크플로우 자동화
- CRM 연동
- 메시지 통합 관리
- 인터랙티브 캘린더 알림 자동화

월 $10에 메시지 발송만이 아니라 자동화에 필요한 기능이 모두 들어 있어요.

## 메시지 비용

- 수신 메시지: 무료
- 고객에게 보내는 답장: 무료
- 서비스 대화: 무료

고객과 대화를 나눈다고 해서 요금이 부과되지 않아요.

## 거래 수수료

```
Stripe 결제 처리 수수료를 충당하기 위해서만 5%를 추가로 적용합니다.
```

이 5%는 이익을 붙이는 금액이 아니에요. 결제 대행 수수료를 충당해 결제를 안전하고 원활하게 처리하기 위한 금액이에요.

## 이 요금 구조가 중요한 이유

많은 WhatsApp 제공업체가 월 구독료를 높게 받아요. 대화마다 추가 요금을 붙이고, 플랫폼 이용료를 따로 받고, 자동화 기능에도 별도 요금을 청구하기도 해요.

WATI 등 시중 서비스와 비교하면 하이퍼클래스는 다음과 같아요.

- 구독 비용이 더 낮아요.
- AI와 자동화가 기본으로 포함돼 있어요.
- 대화에 부풀린 추가 요금이 붙지 않아요.
- 요금 구조가 투명해요.
- CRM과 WhatsApp을 한 플랫폼에서 쓸 수 있어요.

운영 비용을 늘리지 않고 사업을 키우려는 기업에 더 나은 가치를 제공해요.

## 핵심 장점 — 하이퍼클래스의 강점

- 월 비용이 낮고, 더 많은 기능이 포함돼 있어요.
- 수신 메시지, 답장, 서비스 대화는 모두 무료예요.
- AI와 자동화가 기본 요금에 포함돼 있어요.
- CRM과 WhatsApp이 기본으로 연동돼 있어서 별도의 BSP가 필요 없어요.
- 거래 수수료는 Stripe 처리 비용을 충당하는 5%뿐이라 예측하기 쉬워요.
