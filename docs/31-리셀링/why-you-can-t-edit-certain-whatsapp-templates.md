# WhatsApp 템플릿을 편집할 수 없는 이유

WhatsApp 메시지 템플릿에서 편집 옵션이 보이지 않을 때, 흔한 원인과 대신 할 수 있는 방법을 알려 드려요.

WhatsApp 메시지 템플릿을 편집하려는데 옵션을 쓸 수 없어도 놀라지 마세요. 템플릿을 수정할 수 없는 이유는 여러 가지예요. 아래에서 원인과 해결 방법을 확인해 보세요.

---

## 템플릿을 편집할 수 없는 흔한 이유

### Meta의 승인을 이미 받은 템플릿이에요

Meta의 승인을 받은 템플릿은 내용이 잠겨요. 템플릿 이름이나 카테고리 같은 사소한 부분은 바꿀 수 있는 경우도 있어요. 하지만 본문, 머리글, 바닥글 텍스트는 편집할 수 없어요. 내용을 바꾸려면 새 템플릿을 처음부터 만들어야 해요.

### API로 만든 템플릿이에요

WhatsApp API나 외부 파트너 도구에서 직접 만든 템플릿은 하이퍼클래스 화면에서 편집할 수 없을 수 있어요. 이런 템플릿은 보안과 일관성을 위해 보통 잠겨 있어요.

### 템플릿을 사용 중이거나 최근에 발송했어요

템플릿이 진행 중인 워크플로우나 대화에서 쓰이고 있거나 최근에 발송됐다면, 편집이 일시적으로 잠길 수 있어요. 메시지의 일관성을 지키고 소통이 끊기지 않게 하려는 조치예요.

### 엄격한 카테고리의 템플릿이에요 (예: **인증**)

OTP나 인증 코드를 보내는 데 쓰는 **인증** 같은 카테고리는 규칙이 훨씬 엄격해요. Meta가 이런 템플릿에 정해진 형식과 문구를 요구하기 때문에, 허용된 매개변수 외에는 편집할 수 없어요.

### 검토 중이거나 Meta가 품질 문제로 표시한 템플릿이에요

Meta가 품질이 낮다고 표시했거나 검토 중인 템플릿은 문제가 해결될 때까지 편집이 제한돼요. WhatsApp의 메시지 정책과 사용자 경험 기준을 지키기 위한 조치예요.

---

## 편집할 수 없을 때 할 수 있는 일

### 템플릿 복제하기

기존 템플릿을 복제한 뒤 새 버전에서 필요한 부분을 바꾸고, 승인을 요청하세요. WhatsApp 템플릿을 복제하는 방법은 다음과 같아요.

1. **설정 > WhatsApp > 템플릿**으로 이동하세요.
2. 복제할 템플릿 옆의 점 3개 아이콘을 클릭하세요.
3. 드롭다운 메뉴에서 **템플릿 복제**를 선택하세요.
4. 새 템플릿의 이름을 바꾸고 내용을 편집한 뒤 **저장**을 클릭하세요.
5. 새 템플릿의 승인을 요청하세요.

{% hint style="info" %}
WhatsApp 템플릿 복제 과정을 자세히 설명하는 안내 문서가 따로 있어요.
{% endhint %}

### 기존 템플릿 삭제하기

기존 템플릿이 더 이상 필요하지 않거나 맞지 않는다면 원래 버전을 삭제하세요. 그러면 템플릿 목록을 깔끔하게 최신 상태로 유지할 수 있어요.
