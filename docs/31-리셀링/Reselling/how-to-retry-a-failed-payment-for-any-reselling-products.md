# 리셀링 상품 결제가 실패했을 때 다시 결제하기

리셀링 상품을 구매하다가 결제가 실패해도 걱정하지 마세요. 아래 순서대로 따라 하면 쉽게 결제를 다시 시도할 수 있어요.

## 결제가 실패하는 이유

결제는 여러 가지 이유로 실패할 수 있어요.

- 잔액 부족
- 카드 정보 오류(카드 유효기간 만료, CVV 오입력 등)
- 은행의 이용 제한 또는 보안 차단

결제가 실패하면 결제를 다시 시도하라는 알림이 나타나요.

## 결제 다시 시도하기

1. 구독하려는 상품 페이지로 이동해요.
2. 결제에 필요한 정보를 입력해 제출해요.
3. 구매 페이지에서 **결제 재시도** 버튼을 찾아 클릭해요. 결제 절차가 다시 시작돼요.

   ![결제 재시도 버튼이 표시된 구매 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036139795/original/pW01VvpKfazWMFe763tjerTxGILxDDVFnA.jpeg?1730957431)

4. 카드 정보가 잘못되었거나 만료되어 실패한 경우에는 새 정보를 입력하라는 안내가 나와요. 필요하면 **결제 업데이트**를 이용해 정보를 바꾸세요. 진행하기 전에 입력한 내용을 한 번 더 확인하세요. 그래야 결제가 정상적으로 처리돼요.
5. 정보를 수정한 뒤 결제를 확인해요.
6. 결제가 승인되면 성공 알림이 나타나요.

## 결제를 성공시키는 방법

- 사용 중인 카드에 이용 제한이 없는지 은행에 확인하세요.
- 계좌에 잔액이 충분한지 확인하세요.
- 결제 재시도가 계속 실패하면 다른 결제 수단을 사용해 보세요.

## 계속 문제가 생기나요?

결제가 계속 진행되지 않으면 하이퍼클래스 고객지원에 문의하세요. 구매를 마칠 수 있도록 도와드릴게요.
