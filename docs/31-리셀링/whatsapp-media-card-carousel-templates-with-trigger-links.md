# WhatsApp 미디어 카드 캐러셀 템플릿과 트리거 링크 사용하기

이미지, 설명, 클릭을 추적할 수 있는 작업 버튼이 담긴 카드를 옆으로 넘겨 볼 수 있게 WhatsApp으로 보내는 방법을 안내해요. 템플릿 제작부터 발송, 성과 확인까지 모두 하이퍼클래스 안에서 할 수 있어요.

## 미디어 카드 캐러셀 템플릿이란?

미디어 카드 캐러셀 템플릿은 소개 메시지 하나와 옆으로 넘겨 보는 카드 최대 10개로 구성돼요. 카드마다 이미지 또는 동영상, 짧은 설명, 작업 버튼을 최대 2개까지 넣을 수 있어요. WhatsApp에서는 이 템플릿을 **마케팅** 카테고리로만 지원해요.

**트리거 링크**는 URL 버튼에 넣는 추적용 이동 경로예요. 연락처가 이 링크를 클릭하면 하이퍼클래스가 클릭 기록을 남기고, 미리 설정한 워크플로우를 실행할 수 있어요. 예를 들어 관심 태그를 추가하거나 영업팀에 알림을 보낼 수 있어요.

예시

가구 판매 업체가 소파, 식탁, 침대를 각각 다른 카드에 담아 보여 줄 수 있어요. 카드마다 해당 상품 페이지로 연결하고, 고객이 어떤 상품을 눌렀는지에 따라 다른 후속 워크플로우를 실행해요.

## 시작하기 전에

템플릿을 만들기 전에 아래 항목을 준비하세요.

- 카드에 넣을 미디어 파일(이미지 또는 동영상)
- 카드 설명과 이동할 링크
- 추적할 버튼마다 실행할 후속 작업

WhatsApp 발송 번호가 연결되어 있어야 하고, 템플릿과 워크플로우 설정에 접근할 수 있어야 해요. WhatsApp 워크플로우 액션에서는 연결된 번호만 선택할 수 있어요.

템플릿은 Meta의 승인을 받아야 발송할 수 있어요. 필요한 수신 동의를 받은 연락처에게만 메시지를 보내고, 수신거부 요청은 모두 지켜 주세요.

## 지원하는 콘텐츠와 제한

| 구성 요소 | 요구 사항 |
|---|---|
| 템플릿 카테고리 | 마케팅 |
| 소개 메시지 | 최대 1,024자 |
| 캐러셀 카드 | 최대 10개 |
| 카드 헤더 | 이미지 또는 동영상 |
| 이미지 파일 크기 | 이미지당 최대 5MB |
| 동영상 파일 크기 | 동영상당 최대 16MB |
| 카드 설명 | 변수 값이 들어간 뒤의 글자 수를 포함해 최대 160자 |
| 작업 버튼 | 카드당 최대 2개 |
| 지원하는 버튼 유형 | **Quick Reply**(빠른 답장), **전화번호**, **URL** |
| 개인화 | 본문과 동적 URL 필드에서 변수 사용 가능 |

{% hint style="warning" %}
모든 카드는 구성 요소 구조가 같아야 해요. 모든 카드에서 헤더 형식과 버튼 배치를 똑같이 유지하세요. 예를 들어 모든 카드를 이미지 헤더, URL 버튼, **Quick Reply** 버튼 순서로 맞추는 식이에요. 이미지, 설명, 이동할 주소는 카드마다 달라도 돼요.
{% endhint %}

## 1단계. 트리거 링크 만들기

캐러셀 템플릿을 만들기 전에 트리거 링크를 먼저 모두 만들어 두세요.

1. **마케팅 > 트리거 링크 > 링크**로 이동하세요.
2. **링크 추가**를 클릭하세요.
3. **설명이 되는 이름 입력** 칸에 이름을 입력하세요. 예: *소파 컬렉션*, *상담 예약*
4. 이동할 URL을 입력하세요.
5. **저장**을 클릭하세요.

### 정적 이동 경로와 동적 이동 경로

- **정적**: 상품 컬렉션이나 예약 페이지처럼 고정된 페이지로 보내요.
- **동적**: 지원하는 커스텀 값이나 병합 필드를 사용해요. 예: `{{custom_values.product_link}}` 값 선택 기능을 이용하고, 올바른 URL로 바뀌는지 꼭 테스트하세요.

{% hint style="warning" %}
일반 URL이나 URL이 들어 있는 커스텀 값은 자동으로 트리거 링크가 되지 않아요. 트리거 링크를 먼저 만든 다음, 저장한 링크를 캐러셀 버튼에 사용하세요.
{% endhint %}

{% hint style="info" %}
카드나 작업별로 따로 추적하고 싶다면 트리거 링크를 각각 만드세요. 상품별 후속 작업을 설정하기가 쉬워져요.
{% endhint %}

## 2단계. 캐러셀 템플릿 만들기

### 템플릿 빌더 열기

**설정 > WhatsApp > 템플릿**으로 이동해 **템플릿 만들기**를 클릭하세요. 템플릿 이름과 언어를 입력하고, 카테고리를 **마케팅**으로 설정한 다음, 빌더에서 캐러셀 설정을 켜세요.

![템플릿 빌더에서 캐러셀 설정을 켠 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083071229/original/n2Ba28FY0em-E3jt7kWR1ARZADdeBqbzGQ.png?1791796308)

### 소개 메시지 작성하기

캐러셀을 소개하는 메시지를 작성하세요. 고객이 무엇을 보고 있는지, 어떤 행동을 할 수 있는지 설명해 주세요. 빌더의 변수 설정 기능으로 각 자리표시자를 알맞은 연락처 필드에 연결하세요. Meta 심사용으로 현실적인 샘플 값도 입력하세요. 예를 들어 이름 샘플 값은 *지수*처럼 넣으면 돼요.

```
예시: 안녕하세요 {{1}}님, 새로 나온 컬렉션을 확인해 보세요. "컬렉션 보기"를 눌러 마음에 드는 상품을 찾아보세요.
```

![소개 메시지를 작성하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083071364/original/pP6ukOBf9LJXas7EzzYtPXNM0D-BJsq2_Q.png?1791796378)

### 미디어 카드 추가하기

카드마다 미디어를 업로드하고, 설명을 입력하고, 위의 제한 안에서 작업 버튼을 설정하세요.

| 버튼 유형 | 고객이 할 수 있는 동작 |
|---|---|
| **URL** | 설정한 웹사이트 주소를 열어요 |
| **Quick Reply** | 설정한 답장을 비즈니스로 보내요 |
| **전화번호** | 설정한 번호로 고객이 전화를 걸 수 있어요 |

클릭을 추적할 URL 버튼에는 1단계에서 만든 트리거 링크 중 해당 버튼에 맞는 링크를 선택하세요.

![카드의 URL 버튼에 저장한 트리거 링크를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083071432/original/-ewBj484YzseEgD0kAl8Jst-68kr14T6gA.png?1791796405)

### 미리 보고 제출하기

소개 메시지와 모든 카드를 꼼꼼히 확인하세요. 미디어, 설명, 버튼 이름, 이동할 주소, 변수 연결을 모두 살펴보세요. 확인이 끝나면 Meta 심사를 위해 템플릿을 제출하고, 승인될 때까지 기다린 뒤 발송하세요. Meta가 템플릿을 반려하면 반려 사유를 확인하고, 지적된 부분을 고쳐서 다시 제출하세요.

## 3단계. 클릭 기반 자동화 설정하기

트리거 링크를 추가한다고 해서 후속 워크플로우가 자동으로 만들어지지는 않아요. 클릭 후 하이퍼클래스가 실행할 작업을 직접 설정해야 해요.

1. **자동화 > 워크플로우**를 열고 워크플로우를 새로 만들거나 기존 워크플로우를 편집하세요.

   ![워크플로우 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083250885/original/MjFWoydh8YPOUUZj-cWEE1w6yu1d-0IcZg.png?1791943238)

2. **Trigger Link**(트리거 링크) 필터를 추가하고 WhatsApp을 선택하세요.

   ![Trigger Link 필터에서 WhatsApp을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083250937/original/Vb_b_usMw9ludsFWDsB43Y4rGf3XgUM74w.png?1791943411)

3. 캐러셀 템플릿을 선택하세요.

   ![캐러셀 템플릿을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083250963/original/xRLzRBg3CmxJ36k-FmxVnz8TrQANfMc6bw.png?1791943534)

4. 트리거 링크별로 분기가 만들어져요. 워크플로우를 **저장**하고 **게시**하세요.

   ![트리거 링크별로 분기가 만들어진 워크플로우 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083251004/original/dgY6sMJaREEI3QyG7owc7vWEyP3zMMRrjw.png?1791943675)

자동화 예시

고객이 소파 카드에서 *컬렉션 보기*를 클릭하면 워크플로우가 *소파 관심* 태그를 추가하고 영업팀에 알려요. 식탁 카드를 클릭하면 다른 후속 작업이 실행돼요.

{% hint style="warning" %}
URL 버튼을 클릭해도 WhatsApp의 24시간 고객 서비스 창이 열리거나 초기화되지 않아요. 이 창은 고객이 비즈니스로 메시지를 보낼 때만 열리거나 초기화돼요. 이 창 밖에서 후속 WhatsApp 메시지를 보낼 때는 승인된 템플릿을 사용하세요.
{% endhint %}

## 4단계. 승인된 캐러셀 보내기

서브 계정에서 이 기능이 켜져 있고, 승인된 템플릿이 각 채널의 선택 목록에 보이면 **워크플로우**, **일괄 작업**, **대화**에서 캐러셀 템플릿을 보낼 수 있어요.

### 워크플로우로 보내기

워크플로우를 열고 **WhatsApp** 액션을 추가하세요. 연결된 발송 번호를 선택하고, 승인된 캐러셀 템플릿을 고르세요. 필요한 변수 연결을 모두 마치고, 게시하기 전에 설정을 다시 확인하세요.

![워크플로우의 WhatsApp 액션에서 캐러셀 템플릿을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083073985/original/N69iM79ws7-BpuSgDHaB6CwEPe7mbXVntw.png?1791797259)

### 일괄 작업으로 보내기

**연락처**로 이동해 대상 연락처를 선택하고 WhatsApp 일괄 작업을 선택하세요. 승인된 캐러셀 템플릿을 선택해 미리보기로 확인하고, 필요한 항목을 입력한 뒤, 사용할 수 있는 발송 또는 예약 옵션을 선택하세요. 발송을 시작한 뒤에는 **연락처 > 일괄 작업**에서 진행 상황을 확인할 수 있어요. 일괄 발송에는 Meta의 메시지 발송 제한, 계정 제한, 연락처의 메시지 설정이 적용돼요.

![연락처에서 WhatsApp 일괄 작업으로 캐러셀 템플릿을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083074156/original/a10AJHWOiW2i1XjZQbacht0u3iIhf3UJvQ.png?1791797332)

### 대화에서 보내기

연락처의 **대화**를 열고 **WhatsApp**을 선택한 다음, 템플릿 선택 목록에서 승인된 캐러셀을 고르세요. 보내기 전에 내용과 개인화 값을 확인하세요.

![대화에서 템플릿 선택 목록으로 캐러셀을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083074203/original/OhIJvRveVI6qB36DUuiBIPKUfrhEu-a1Qg.png?1791797363)

{% hint style="info" %}
캠페인을 시작하기 전에 내부 테스트용 연락처에게 캐러셀을 먼저 보내 보세요. 모든 카드를 열어 보고, 추적하는 버튼을 하나씩 눌러 이동 주소를 확인하세요. 의도한 워크플로우가 실행되는지도 확인하세요.
{% endhint %}

## 참여도와 후속 활동 확인하기

### 템플릿 성과

**설정 > WhatsApp > 템플릿**으로 이동해 템플릿을 찾고 **Reports**(리포트)를 여세요. 템플릿 리포트에서 발송, 전달, 읽음 수와 지원되는 버튼 클릭 지표를 확인할 수 있어요.

### 트리거 링크 활동

연락처의 활동 타임라인에서 기록된 트리거 링크 클릭을 확인하세요. 워크플로우 기록으로는 예상한 자동화가 시작됐는지, 그 안의 작업이 끝까지 실행됐는지 확인하세요. 클릭 기록은 참여했다는 사실만 보여 줘요. 후속 작업이 완료됐거나 고객이 구매했다는 뜻은 아니에요.

## 문제 해결

| 문제 | 확인할 내용 |
|---|---|
| 캐러셀 옵션이 보이지 않아요 | 하이퍼클래스 고객지원에 문의해 사용 중인 서브 계정과 발송 채널에서 캐러셀을 쓸 수 있는지 확인하세요. |
| 템플릿이 반려됐어요 | Meta의 반려 사유를 확인하세요. 카드 구조, 콘텐츠 제한, 미디어, 버튼 설정, 샘플 변수 값을 점검하세요. |
| 미디어가 업로드되지 않아요 | 업로더가 허용하는 파일 형식과 이미지 또는 동영상 크기 제한을 확인하세요. |
| 개인화 값이 비어 있거나 잘못 나와요 | 변수 연결을 확인하고, 선택한 연락처나 커스텀 값에 기대한 데이터가 들어 있는지 확인하세요. |
| 링크는 열리는데 워크플로우가 실행되지 않아요 | 버튼에 이동할 URL만 넣지 않고 저장한 트리거 링크를 사용했는지 확인하세요. 워크플로우가 게시되어 있고, 필터에서 같은 링크를 선택했는지도 확인하세요. |
| 일괄 메시지가 실패하거나 건너뛰어졌어요 | 캠페인 상세 정보에서 템플릿 문제, 계정 제한, 메시지 발송 제한, 전화번호 누락, 수신거부 설정을 확인하세요. |

{% hint style="info" %}

## 자주 묻는 질문

### 트리거 링크 없이도 캐러셀을 쓸 수 있나요?
네, 쓸 수 있어요. 캐러셀에는 일반 **URL**, **Quick Reply**, **전화번호** 버튼을 사용할 수 있어요. 다만 버튼에 이동할 URL을 넣는다고 해서 그 URL이 하이퍼클래스의 트리거 링크가 되지는 않아요. **Trigger Link Clicked**(트리거 링크 클릭) 자동화가 필요할 때만 저장한 트리거 링크를 사용하세요.

### URL 버튼을 누르면 고객이 WhatsApp 안에 머무르나요?
아니요. URL 버튼은 기기의 기본 브라우저에서 이동할 주소를 열어요.

### 트리거 링크를 클릭했다면 구매한 것으로 볼 수 있나요?
아니요. 클릭은 링크에 반응했다는 뜻이지, 주문이 완료됐다는 뜻은 아니에요. 외부 웹사이트에서 이뤄진 구매는 미디어 카드 캐러셀의 WhatsApp 주문 웹훅을 만들지 않아요. 구매는 해당 웹사이트, 결제 화면, 결제 연동에서 추적하세요.

### 상품 카드 캐러셀과는 어떻게 다른가요?
미디어 카드 캐러셀은 직접 업로드한 미디어와 설정한 작업 버튼을 사용해요. 상품 카드 캐러셀은 카탈로그의 상품 정보를 사용해요. **View**(보기) 버튼과 함께 설정하면 WhatsApp 안에서 상품을 보고 장바구니를 이용하는 경험을 제공할 수 있어요. 두 템플릿은 서로 다른 형식이에요.
