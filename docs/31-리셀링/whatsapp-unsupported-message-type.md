# WhatsApp 지원되지 않는 메시지 유형 오류(131051) 해결

고객이 보낸 WhatsApp 메시지가 하이퍼클래스에서 "지원되지 않는 메시지"로 표시될 때 참고하세요. 왜 이런 일이 생기는지, 어떤 메시지 유형을 쓸 수 있는지, 오류 코드 131051은 어떻게 해결하는지 알려 드려요.

## 지원되지 않는 메시지 유형이란?

WhatsApp 일반 앱에는 스티커, 투표, 음성 메모, GIF, 연락처 카드 등 다양한 메시지 유형이 있어요. 하지만 하이퍼클래스가 사용하는 WhatsApp Business Platform(Cloud API)은 정해진 일부 유형만 지원해요.

고객이 투표나 삭제된 메시지처럼 Business API가 지원하지 않는 유형을 보내면, 하이퍼클래스에서는 그 내용을 표시하거나 처리할 수 없어요. 대신 지원되지 않는 메시지라는 알림이 나타나요.

하이퍼클래스의 버그가 아니에요. Meta의 WhatsApp Business Platform API 자체의 제한이며, 이 API를 기반으로 만든 모든 CRM 플랫폼에 똑같이 적용돼요.

```
지원되지 않는 메시지 유형은 Meta API의 제한이며 하이퍼클래스의 문제가 아닙니다. 이런 메시지 유형은 Business API 기반 플랫폼 어디에서도 표시하거나 응답할 수 없습니다.
```

## 오류 코드 131051 — 지원되지 않는 메시지 유형

Meta는 WhatsApp Business API가 지원하지 않는 메시지 유형에 오류 코드 131051을 지정해요. 이 오류는 두 가지 상황에서 나타나요.

| 구분 | 상황 |
| --- | --- |
| 수신(고객 → 비즈니스) | 고객이 투표, GIF, 삭제된 메시지처럼 API가 처리할 수 없는 유형을 보낸 경우예요. 하이퍼클래스는 메시지 내용 대신 `type: "unsupported"`와 오류 코드 `131051`이 담긴 웹훅 알림을 받아요. |
| 발신(비즈니스 → 고객) | 사용한 메시지 유형이나 형식을 API가 지원하지 않아 전송에 실패한 경우예요. 메시지는 전달되지 않고 오류가 반환돼요. |

```
Error Code: 131051
Title: Unsupported message type
Details: Message type is not currently supported
Type returned: unknown or unsupported
```

## 하이퍼클래스에서 지원하는 메시지 유형

아래 메시지 유형은 WhatsApp Business Platform API에서 완전히 지원해요. 하이퍼클래스의 WhatsApp 연동으로 보내고 받을 수 있어요.

| 메시지 유형 | 방향 | 상세 |
| --- | --- | --- |
| 텍스트 | 송수신 | 이모지와 링크가 포함된 일반 텍스트 메시지 |
| 이미지 | 송수신 | JPEG, PNG. 최대 5MB |
| 동영상 | 송수신 | MP4, 3GPP. 최대 16MB |
| 오디오 | 송수신 | AAC, MP4, MPEG, AMR, OGG(오디오). 최대 16MB |
| 문서 | 송수신 | PDF, Word, Excel, PowerPoint 등. 최대 100MB |
| 스티커 | 송수신 | 정적 WebP(발신), 애니메이션 WebP(수신만 가능) |
| 위치 | 송수신 | 좌표가 담긴 지도 핀 공유 및 수신 |
| 템플릿 메시지 | 발신 | 사전 승인된 마케팅, 유틸리티, 인증 템플릿 |
| 인터랙티브 | 발신 | 리스트 메시지, 답장 버튼, CTA URL 버튼 |
| 연락처 | 송수신 | API를 통해서만 보내는 구조화된 연락처 카드 |
| 반응 | 송수신 | 메시지에 다는 이모지 반응(API v2.45 이상) |

## 지원되지 않는 메시지 유형

아래 유형은 WhatsApp Business Platform API에서 표시하거나 처리할 수 없어요. 고객이 이런 메시지를 보내면 하이퍼클래스에서 지원되지 않는 메시지로 표시되고, 내용은 볼 수 없어요.

| 메시지 유형 | 설명 |
| --- | --- |
| 투표 | 고객이 보낸 WhatsApp 투표는 API로 수신하거나 표시할 수 없어요. |
| 사라지는 메시지 | 자동 삭제로 설정된 사라지는 메시지는 Business API에서 지원하지 않아요. |
| 삭제된 메시지 | 고객이 메시지를 삭제하면 API는 지원되지 않는다는 알림만 받고, 내용은 복구할 수 없어요. |
| GIF | 일반 앱에서 보낸 애니메이션 GIF는 Business API에서 지원되지 않는 유형으로 처리돼요. |
| 음성 통화 | 일반 앱의 WhatsApp 음성·영상 통화는 지원되지 않아요. Business API의 WhatsApp 통화는 별도 기능이에요. |
| 그룹 메시지 | WhatsApp 그룹에서 보낸 메시지는 Business Platform API에서 지원되지 않아요. |
| 연락처 카드(일반 앱) | 일반 사용자의 주소록에서 WhatsApp으로 바로 공유한 연락처 카드는 수신할 수 없어요. API로 보내는 구조화된 연락처 메시지는 지원돼요. |
| 비즈니스 간 메시지(API 대 API) | WhatsApp API 계정은 다른 WhatsApp API 계정에 메시지를 보내도록 만들어지지 않았어요. Meta의 제한이며 오류 131051이 발생해요. |

## 하이퍼클래스에서 지원되지 않는 메시지가 표시되는 모습

고객이 지원되지 않는 메시지를 보내면 하이퍼클래스는 대화 내역에 대체 표시를 보여 줘요. 메시지 유형에 따라 다음과 같이 보일 수 있어요.

- "Unsupported Message" 또는 "This message type is not supported"라고 적힌 메시지 말풍선
- 용량 제한을 넘는 지원되지 않는 파일 형식은 파일이 URL 링크로 바뀌어 표시될 수 있어요.
- 사용자 지정 페이로드(custom payload)는 **더 보기** 옵션이 나타나 원본 JSON 데이터를 볼 수 있어요.

메시지는 하이퍼클래스에서 수신된 것으로 표시돼요. 고객이 무언가를 보냈다는 것은 알 수 있지만 내용은 읽을 수 없어요. 연락처에는 평소처럼 답장할 수 있어요.

```
권장 방법: 고객이 지원되지 않는 콘텐츠를 보내는 것 같다면, 메시지를 텍스트, 이미지, 오디오 또는 문서로 다시 보내 달라고 답장하세요. 그래야 정상적으로 처리할 수 있어요.
```

## 해결 방법

지원되지 않는 메시지 유형 오류가 생겼을 때 다음 순서로 확인하세요.

1. 대화 내역을 보고 고객이 어떤 유형의 메시지를 보내려 했는지 확인하세요.
2. 고객에게 텍스트, 이미지, 오디오, 문서처럼 지원되는 형식으로 다시 보내 달라고 답장하세요.
3. 메시지를 보내다가 이 오류가 났다면, 보내는 메시지의 유형과 형식이 위의 지원 유형과 맞는지 확인하세요.
4. 발신 메시지에서 오류가 계속되면 API 파라미터가 올바른지, 페이로드에 지원되지 않는 필드가 들어 있지 않은지 확인하세요.

```
수신 메시지의 지원되지 않는 유형 오류는 해결할 수 없습니다. Business API로는 투표, 삭제된 메시지, GIF의 내용을 읽을 방법이 없습니다. Meta 플랫폼의 제한입니다.
```

## 자주 묻는 질문

### 고객이 투표를 보냈는데 하이퍼클래스에서 보이지 않아요. 왜 그런가요?
WhatsApp Business Platform API는 투표를 지원하지 않아요. 고객이 투표를 보내면 하이퍼클래스는 오류 코드 131051이 담긴 웹훅을 받고, 메시지는 지원되지 않는 메시지로 표시돼요. 투표 내용은 확인할 방법이 없으니, 고객에게 응답을 텍스트 메시지로 보내 달라고 요청하세요.

### 하이퍼클래스의 버그인가요?
아니에요. Meta의 WhatsApp Business Platform API의 제한이에요. 이 API를 기반으로 만든 모든 CRM과 메시징 플랫폼(하이퍼클래스 포함)에 똑같이 적용되며, 우회할 수 없어요.

### 지원되지 않는 메시지를 보낸 고객에게도 답장할 수 있나요?
네. 지원되지 않는 메시지의 내용은 볼 수 없어도 대화는 그대로 열려 있어요. 텍스트, 이미지, 오디오 등 지원되는 메시지 유형으로 평소처럼 답장하면 돼요.

### 고객이 메시지를 삭제했어요. 보낸 내용을 복구할 수 있나요?
아니요. API로는 삭제된 메시지를 복구할 수 없어요. 고객이 메시지를 삭제하면 하이퍼클래스와 Meta 서버 어디에도 그 내용이 남지 않아요.

### Meta가 앞으로 투표와 GIF를 지원할 가능성이 있나요?
Meta는 Business API의 기능을 주기적으로 넓히고 있어요. 예를 들어 반응(Reaction)은 이후 API 버전에서 추가됐어요. 업데이트는 Meta의 [WhatsApp Business Platform 변경 내역](https://developers.facebook.com/documentation/business-messaging/whatsapp/overview/)에서 확인하세요. Meta가 새 유형을 지원하면 하이퍼클래스에도 반영될 예정이에요.

### 메시지를 보낼 때 오류 131051이 나요. 무엇을 확인해야 하나요?
보내는 메시지 유형이 위의 지원 목록에 있는지 확인하세요. 애니메이션 GIF를 보냈거나, API 파라미터가 잘못됐거나, 다른 WhatsApp Business API 계정에 메시지를 보내려 한 경우에 자주 발생해요. 비즈니스 간 메시지는 Meta가 지원하지 않아요.

{% hint style="info" %}
팁: 고객이 혼란스러워하지 않도록, 지원되지 않는 메시지를 받았을 때 실행되는 자동 응답을 하이퍼클래스에 설정해 보세요. 메시지를 읽을 수 없었다고 알리고, 텍스트, 이미지, 오디오 또는 문서로 다시 보내 달라고 안내하면 돼요.
{% endhint %}
