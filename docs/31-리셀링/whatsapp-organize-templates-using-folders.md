# WhatsApp 템플릿을 폴더로 정리하기

WhatsApp 템플릿을 폴더와 하위 폴더로 묶고, 필터와 정렬로 원하는 템플릿을 빠르게 찾는 방법을 안내해요. 새로 바뀐 **템플릿**·**폴더** 화면에서는 폴더 안으로 바로 들어가 보고, 폴더와 템플릿을 다른 단계로 옮길 수 있어요.

## WhatsApp 템플릿 폴더란?

WhatsApp 템플릿 폴더를 쓰면 서브 계정 안에서 폴더와 하위 폴더를 직접 만들어 WhatsApp 메시지 템플릿을 정리할 수 있어요. 용도, 캠페인, 부서처럼 업무 방식에 맞는 기준으로 묶으면 돼요.

새로 바뀐 화면에서는 다음 작업을 할 수 있어요.

- 폴더를 바로 열어 그 안의 템플릿이나 하위 폴더 보기
- 템플릿 목록을 필터링하고 정렬하기
- 각 템플릿이 어느 폴더에 있는지 확인하기
- 템플릿과 폴더를 다른 폴더 단계로 옮기기

## WhatsApp 템플릿 관리의 장점

폴더 관리와 새 템플릿 목록을 쓰면 팀이 WhatsApp 템플릿을 더 쉽게 정리하고, 찾고, 확인할 수 있어요.

- 체계적인 정리: 캠페인, 부서, 용도별로 템플릿을 묶어 빠르게 찾을 수 있어요.
- 나만의 계층 구조: 폴더 안에 폴더를 넣어 여러 단계로 정리할 수 있어요.
- 빠른 템플릿 관리: 긴 목록을 스크롤하지 않고도 템플릿을 추가, 이동, 찾을 수 있어요.
- 즉석 폴더 만들기: 템플릿을 정리하거나 항목을 옮기는 중에도 폴더를 새로 만들 수 있어요.
- 경로 탐색(브레드크럼): 현재 폴더 경로를 확인하고 상위 폴더로 돌아갈 수 있어요.
- 템플릿 리포트: 템플릿별 리포트를 열어 전달 및 반응 정보를 확인할 수 있어요.
- 새 필터: **카테고리**, **언어**, **상태**, **날짜**로 템플릿 목록을 좁힐 수 있어요.
- 새 정렬 옵션: 템플릿 이름, 언어, 카테고리, 상태, 마지막 수정 기준으로 정렬할 수 있어요.
- 폴더 위치 확인: **폴더** 열에서 템플릿이 들어 있는 폴더를 알 수 있어요.
- 폴더별 보기: 선택한 폴더 안의 템플릿과 하위 폴더만 둘러볼 수 있어요.

## 사전 준비와 제한 사항

WhatsApp 템플릿이 있는 서브 계정에서 템플릿 관리를 열 수 있어요. 쓸 수 있는 작업은 내 사용자에게 지정된 WhatsApp 기능과 권한에 따라 달라요. 권한 설정은 [WhatsApp 사용자 권한 관리](whatsapp-user-permissions-in-hyperclass.md) 문서를 참고하세요.

- 서브 계정에서 WhatsApp 템플릿 영역을 쓸 수 있어야 해요.
- 내 사용자에게 해당하는 WhatsApp 관리 권한이 있어야 해요.
- 폴더로 정리해도 템플릿의 메시지 내용이나 Meta 승인 상태는 바뀌지 않아요.
- 필터와 정렬은 목록이 보이는 방식만 바꾸고, 템플릿의 내용이나 상태는 바꾸지 않아요.
- 폴더를 선택해 들어가면 **템플릿** 탭과 **폴더** 탭에 그 폴더에 속한 항목이 표시돼요.

## 폴더로 WhatsApp 템플릿 정리하기

서브 계정의 WhatsApp 템플릿 영역에서 시작해요. 템플릿이 늘어나면 폴더를 만들고, 폴더 단계를 오가고, 필터나 정렬을 쓰고, 항목을 옮기면서 정리하세요.

### 1. WhatsApp 템플릿 설정으로 이동하기

1. 해당 서브 계정을 열고 **설정**으로 이동해요.
2. **WhatsApp**을 클릭한 다음, 맨 위의 **템플릿** 탭을 열어요.

![설정의 WhatsApp 템플릿 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084671557/original/XxMlY-oWGcG5VuVwd3-4WZ4GTiyVo95eCA.png?1793508195)

안쪽의 **템플릿** 탭과 **폴더** 탭으로 템플릿 목록과 폴더 목록을 오갈 수 있어요.

![템플릿 탭과 폴더 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084671569/original/w76kETdognENl-ywF1IQ4TwBldbSfb5lTw.png?1793508226)

### 2. 새 폴더 만들기

1. **설정 > WhatsApp > 템플릿**으로 이동해요.
2. 안쪽의 **폴더** 탭을 선택해요.
3. **폴더 만들기**를 클릭해요.
4. 폴더 이름을 입력해요.
5. **만들기**를 클릭해 저장해요.

![폴더 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673478/original/cnMfUk5JdhMgmr4dcxgKvcjUVOa5sT-JCQ.png?1793514772)

### 3. 하위 폴더 만들기

1. **설정 > WhatsApp > 템플릿 > 폴더**로 이동해요.
2. 기존 폴더의 이름을 클릭해 폴더를 열어요.
3. **폴더 만들기**를 클릭해요.
4. 하위 폴더 이름을 입력해요.
5. **만들기**를 선택해요.

![하위 폴더 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673598/original/RE9FJrxa7mS3SwjbJTCm6pTGVnFN_3sOGQ.png?1793515459)

{% hint style="info" %}
폴더와 하위 폴더를 여러 단계로 만들어 템플릿을 정리할 수 있어요.
{% endhint %}

### 4. 경로 탐색(브레드크럼) 사용하기

1. **설정 > WhatsApp > 템플릿 > 폴더**로 이동해요.
2. 둘러볼 폴더를 열어요.
3. 폴더 내용 위에 표시된 경로(브레드크럼)를 클릭해 상위 폴더나 홈으로 돌아가요.

![폴더 경로(브레드크럼) 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673134/original/oqnmfAryLXBLBLqVc4o9eFjxe5PEawLYyQ.png?1793513317)

### 폴더 안에서 템플릿과 폴더 둘러보기

이번 개편으로 폴더별 탐색이 생겼어요. 폴더 안으로 들어가면 **템플릿** 탭과 **폴더** 탭에 선택한 폴더에 속한 내용이 표시돼요.

1. 서브 계정에서 **설정 > WhatsApp > 템플릿**으로 이동해요.
2. 안쪽의 **폴더** 탭을 선택해요.
3. 폴더 이름을 클릭해 그 폴더 안으로 들어가요.
4. **폴더**를 선택하면 그 안의 하위 폴더를 볼 수 있어요.
5. **템플릿**을 선택하면 선택한 폴더 안의 템플릿을 볼 수 있어요.
6. 상위 폴더나 홈으로 돌아가려면 경로(브레드크럼)를 사용해요.

**폴더** 탭: 선택한 폴더에 속한 하위 폴더를 보여 줘요.

![폴더 탭에서 하위 폴더 보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084671871/original/XApLN_XvRHAwfYeyn6ZzAddUTXh3moapQw.png?1793509695)

{% hint style="info" %}
선택한 폴더에 템플릿이나 하위 폴더가 없으면 해당 탭이 빈 화면으로 표시돼요. 상위 폴더로 돌아가 계속 둘러보세요.
{% endhint %}

### WhatsApp 템플릿 필터링하기

필터를 쓰면 선택한 조건으로 템플릿 목록을 좁힐 수 있어요. 언어, 카테고리, 승인 상태가 다른 템플릿을 관리할 때 편해요.

1. 해당 **서브 계정**을 열어요.
2. **설정 > WhatsApp > 템플릿**으로 이동해요.
3. 안쪽의 **템플릿** 탭을 선택해요.
4. **+ Add filter**(필터 추가)를 클릭해요.
5. 사용할 필터 항목을 선택해요.
6. 그 항목에서 쓸 수 있는 조건을 골라 목록을 좁혀요.

필터 메뉴에는 다음 항목이 있어요.

- **카테고리**: 메시지 카테고리로 템플릿을 찾아요.
- **언어**: 선택한 언어를 쓰는 템플릿을 찾아요.
- **상태**: 템플릿 상태로 목록을 좁혀요.
- **날짜**: 날짜 기준 필터 옵션을 써요.

![템플릿 필터 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673292/original/cyFGfxOsGfdhk-GOPEwyVaM0D8ICo1ks1g.png?1793513911)

{% hint style="info" %}
현재 메뉴에서는 날짜 필터가 **날짜**로 표시돼요. 템플릿 표에는 이와 별도로 **마지막 수정** 열이 있어요.
{% endhint %}

### WhatsApp 템플릿 정렬하기

정렬을 쓰면 목록에 템플릿이 표시되는 순서를 바꿀 수 있어요. 템플릿 이름, 언어, 카테고리, 상태, 마지막 수정 기준으로 정렬해 보세요.

1. 해당 **서브 계정**을 열어요.
2. **설정 > WhatsApp > 템플릿**으로 이동해요.
3. 안쪽의 **템플릿** 탭을 열어요.
4. 템플릿 목록 위의 **정렬**을 클릭해요.
5. 정렬 기준으로 쓸 항목을 선택해요.
6. 메뉴에 표시된 정렬 방향을 확인해요.

정렬 기준으로 쓸 수 있는 항목은 다음과 같아요.

- **템플릿 이름**
- **언어**
- **카테고리**
- **상태**
- **마지막 수정**

![템플릿 정렬 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084672714/original/0vaUlR4RcYUoLEtoK-ojEiYlebGu19cwsg.png?1793512326)

폴더 정렬: 안쪽의 **폴더** 탭에는 폴더 이름 기준의 별도 정렬 옵션이 있어요. 현재 화면에서는 **정렬** 옆에 **Folder name (A → Z)**(폴더 이름 A → Z)로 표시돼요.

### 템플릿이 들어 있는 폴더 찾기

새 템플릿 목록에는 **폴더** 열이 있어요. 폴더를 하나씩 열어 보지 않고도 템플릿이 어느 폴더에 있는지 알 수 있어요.

1. 해당 **서브 계정**을 열어요.
2. **설정 > WhatsApp > 템플릿**으로 이동해요.
3. 최상위 단계에서 안쪽의 **템플릿** 탭을 열어요.
4. 목록에서 템플릿을 찾아요.
5. **폴더** 열에서 템플릿이 들어 있는 폴더를 확인해요.

템플릿이 폴더에 속해 있으면 그 폴더 이름이 열에 표시돼요. 표시되는 폴더 위치가 없으면 대시(-)로 보여요.

![템플릿 목록의 폴더 열](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084672816/original/EIN3b28iPPRs-vccBSEMhhqLPPCh2uDXOA.png?1793512520)

### 5. 템플릿을 폴더로 옮기기

캠페인이나 정리 기준이 바뀌면 템플릿을 다른 폴더로 옮기세요.

1. 서브 계정에서 **설정 > WhatsApp > 템플릿**으로 이동해요.
2. 안쪽의 **템플릿** 탭을 열어요.
3. 전체 목록이나 현재 폴더 안에서 템플릿을 찾아요.
4. **작업** 아래에 있는 템플릿의 점 세 개(⋮) 메뉴를 클릭해요.
5. **폴더로 이동**을 선택해요.
6. 옮길 폴더나 하위 폴더를 선택해요.
7. **이동**을 클릭해 마무리해요.

![템플릿을 폴더로 이동하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084672814/original/XU_TQR6g73NnKUkl5k90J1hH5PWtndAWzA.png?1793512486)

### 6. 폴더를 다른 폴더나 상위 단계로 옮기기

새 폴더 관리 화면에서는 폴더를 다른 폴더 안으로 옮기거나 상위 단계로 되돌릴 수 있어요.

1. 서브 계정에서 **설정 > WhatsApp > 템플릿**으로 이동해요.
2. 안쪽의 **폴더** 탭을 열어요.
3. 옮길 폴더를 찾아요.
4. **작업** 아래의 점 세 개(⋮) 메뉴를 클릭해요.
5. **폴더 이동**을 선택해요.
6. **폴더로 이동** 창에서 옮길 위치를 선택해요.
7. **이동**을 클릭해 변경을 확인해요.

![폴더 이동 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673037/original/VQhvLlkFOVl22M364cJn4alxtyJRLF4NRg.png?1793513111)

폴더 선택 창에서 옮길 위치를 고르세요. 다른 폴더가 더 필요하면 **새 폴더** 옵션을 쓸 수도 있어요.

![폴더 선택 창과 새 폴더 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673027/original/_66k0cx2nlC-l6UVsJziMaIoygJohOB4og.png?1793513051)

### 7. 템플릿 성과 지표 확인하기

1. 서브 계정에서 **설정 > WhatsApp > 템플릿**으로 이동해요.
2. 확인할 템플릿을 찾아요.
3. **작업** 아래의 **리포트 보기**를 클릭해요.

새 **템플릿** 표에서는 리포트를 바로 열 수 있어요. 아래 이미지의 예전 표 모양은 지금 화면과 다를 수 있어요.

![템플릿 표의 리포트 보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673277/original/qcloCqqQb47lrYQcltf3J_03f3HO-PI7oQ.png?1793513869)

템플릿 리포트에서 다음 항목을 볼 수 있어요.

- **발송된 메시지**
- **전달된 메시지**
- **읽은 메시지**
- **버튼 클릭**

리포트의 날짜 조절 기능을 쓰면 원하는 기간의 활동을 확인할 수 있어요.

![템플릿 리포트 지표](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084672181/original/0qOdHn_1i6dZ-3VwAiL8gjU3NHKGDC9Nrg.png?1793511027)

{% hint style="info" %}
템플릿 분석은 쓸 수 있는 조건과 지역에 제한이 있어요. 현재 리포트 요건은 [WhatsApp 템플릿별 분석](whatsapp-template-level-analytics.md) 문서를 확인하세요.
{% endhint %}

## 전달된 메시지 수

전달된 메시지 정보를 보면 WhatsApp 템플릿 하나가 수신자에게 얼마나 자주 도달하는지 알 수 있어요. 새 관리 화면에서는 **리포트 보기**로 템플릿 리포트를 열어요.

- 선택한 템플릿에서 전달된 메시지 수를 확인해요.
- 가능한 경우 전달 정보를 발송 수, 읽음 수와 비교해요.
- 지원되는 리포트 날짜 조절 기능으로 특정 기간을 확인해요.

## 주간 전달 추이

기간별 전달 활동을 살펴보면 템플릿 사용량이 어떻게 달라지는지 알 수 있어요. 템플릿 리포트를 열고 날짜 조절 기능으로 전달 추이를 확인하세요.

- 선택한 리포트 기간의 메시지 활동을 확인해요.
- 시간에 따른 전달 및 반응 지표를 비교해요.
- 확인한 정보로 템플릿 성과를 평가해요.

![주간 전달 추이 리포트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084673429/original/G-a2PBYj0HStCyxLwF84iI16Ztj6s7sj5A.png?1793514570)

리포트 화면 구성은 앞의 템플릿 표 예시와 다를 수 있어요. 현재 **템플릿** 화면에서 **리포트 보기**를 눌러 해당 지표를 확인하세요.

## 폴더 유연하게 만들기

필요할 때마다 폴더를 만들 수 있어요. 템플릿이나 폴더를 다시 정리하는 중에도 만들 수 있어요. 새 위치 선택 창에 **새 폴더** 옵션이 있어서 메인 폴더 목록으로 돌아가지 않아도 정리할 수 있어요.

- 템플릿이 늘어나면 새 폴더를 만들어요.
- 템플릿을 다른 폴더나 하위 폴더로 옮겨요.
- 폴더를 다른 폴더 안으로 옮기거나 상위 단계로 되돌려요.
- 항목을 다시 정리할 때는 위치 선택 창에서 알맞은 폴더를 골라요.

## 자주 묻는 질문

### 폴더 안에 폴더를 만들 수 있나요?

네. 폴더와 하위 폴더를 여러 단계로 만들어 필요한 구조로 정리할 수 있어요.

### 템플릿을 다른 폴더로 옮기면 승인이나 상태에 영향이 있나요?

아니요. 템플릿을 폴더 간에 옮기면 정리 위치만 바뀌고, 승인 상태나 전달 상태는 바뀌지 않아요.

### 이름으로 템플릿을 검색할 수 있나요?

네. **템플릿** 목록에 **이름으로 검색** 입력란이 있어요. 폴더 안으로 들어가면 **템플릿** 탭에는 그 폴더에 속한 템플릿이 표시돼요.

### 폴더 안에서 템플릿 탭과 폴더 탭을 오가면 어떻게 보이나요?

**템플릿** 탭에는 선택한 폴더 안의 템플릿이 보여요. **폴더** 탭에는 같은 폴더 안의 하위 폴더가 보여요.

### 폴더를 만든 뒤에 이름을 바꾸거나 삭제할 수 있나요?

네. 폴더의 **작업** 아래에 있는 점 세 개(⋮) 메뉴를 열고 해당하는 관리 옵션을 선택하세요.

### 폴더를 상위 단계로 되돌릴 수 있나요?

네. 새 폴더 관리 화면에서는 폴더를 다른 폴더 안으로 옮기거나 상위 단계로 되돌릴 수 있어요.

### 템플릿이 들어 있는 폴더를 삭제하면 어떻게 되나요?

삭제한 폴더 안의 템플릿은 상위 폴더로 이동해요. 폴더를 삭제해도 템플릿은 삭제되지 않아요.

### 폴더에서 템플릿을 내보낼 수 있나요?

템플릿 내보내기 기능은 달라진 것이 없어요. 쓸 수 있는 템플릿 작업 메뉴에서 템플릿을 하나씩 내보낼 수 있어요.

### 템플릿의 전달 및 반응 정보는 어디에서 볼 수 있나요?

**템플릿** 목록에서 해당 템플릿을 찾아 **리포트 보기**를 선택하세요. 그 템플릿에서 확인할 수 있는 전달 및 반응 정보가 리포트에 표시돼요.
