# WhatsApp 메시지에서 연락처가 중복으로 생길 때 해결하기

**연락처 중복 허용**을 꺼 두었는데도 WhatsApp 메시지 때문에 연락처가 중복으로 만들어지는 문제를 해결하는 방법을 안내해요.

## 개요

**비즈니스 프로필**에서 **연락처 중복 허용** 설정을 껐는데도 WhatsApp 메시지로 연락처가 중복 생성될 때 해결하는 절차예요.

## 증상

- WhatsApp 메시지에서 연락처가 중복으로 표시돼요.
- **비즈니스 프로필** 설정에서 **연락처 중복 허용**이 꺼져 있어요.
- 그런데도 중복이 계속 생겨요.

## 원인

연락처 검색 기준에 전화번호가 두 번째 검색 기준으로 설정되어 있지 않으면 이런 문제가 생길 수 있어요.

## 해결 방법

1. **비즈니스 프로필**로 이동하세요.
2. **Contact Duplicate Preference**(연락처 중복 기준)로 이동하세요.
3. **Second Preference for Search (Optional)**(두 번째 검색 기준(선택))에서 **전화번호**가 선택되어 있는지 확인하세요.

![두 번째 검색 기준이 전화번호로 설정된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046756067/original/zQIwXKjIu8u1YlZnPiixEeGlN56VvGhRVA.png?1747396808)

{% hint style="info" %}
두 번째 검색 기준을 **전화번호**로 선택하면 전화번호가 같은 연락처를 같은 사람으로 인식해요. 그래서 중복 연락처가 만들어지는 것을 막을 수 있어요.
{% endhint %}
