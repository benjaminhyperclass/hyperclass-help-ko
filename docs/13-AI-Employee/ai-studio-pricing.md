# AI 스튜디오 요금 안내

AI 스튜디오는 랜딩 페이지 한 장부터 폼, 예약 흐름, 도메인 연결까지 갖춘 여러 페이지짜리 웹사이트까지 만들 수 있어요. 이 문서에서는 AI 스튜디오 프로젝트가 어떻게 진행되는지, 요금이 어떤 기준으로 정해지는지, 실제 예시 세 가지와 함께 설명해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

요청마다 범위가 달라서 AI 스튜디오가 하는 작업의 양도 프로젝트마다 달라요. 작업의 양은 프롬프트 수, 추론 단계, 생성한 자산, 연결 작업 수로 나뉘어요.

## AI 스튜디오 빌드 세션 이해하기

AI 스튜디오 프로젝트는 한 번 이상의 대화로 이루어져요. 대화마다 AI는 계획을 세우고, 추론하고, 콘텐츠와 이미지를 만들고, 실시간 미리보기를 보여 줘요. 폼이나 캘린더 연결 같은 작업도 수행해요. 세션은 입력한 프롬프트 수가 아니라 실제로 수행한 작업을 기준으로 측정해요.

일반적인 빌드 세션에는 다음 단계가 들어갈 수 있어요.

- 요청 내용 파악 중
- 요청이 넓을 때 추가 질문하기
- 참고 URL, 스크린샷, 업로드한 이미지를 방향 잡는 데 활용하기
- 단일 페이지 또는 여러 페이지 구조 기획하기
- 레이아웃, 문구, 이미지 생성하기
- 실시간으로 편집할 수 있는 미리보기 만들기
- 수정할 때마다 새 버전 만들기
- 폼, 캘린더 같은 지원되는 구성 요소 연결하기
- 미리보기 또는 사용자 도메인에 게시하기

페이지가 많거나, 수정이 잦거나, 연결할 구성 요소가 있는 복잡한 프로젝트는 일반적으로 단일 페이지 초안보다 처리 작업이 더 많아요.

## AI 스튜디오 요금 개요

AI 스튜디오는 사용량 기반으로 요금을 매겨요. 기본 포함 사용량은 사용자의 접근 유형과 AI 직원 구독에 따라 달라요. 에이전시 사용자는 공정 사용 범위 안에서 추가 비용 없이 AI 스튜디오를 쓸 수 있어요. 서브 계정 사용자는 AI 직원 구독으로 쓰거나 사용한 만큼 결제할 수 있어요.

### 사용자 유형 및 요금제별 AI 스튜디오 사용량

| 사용자 유형 / 요금제 | 포함 사용량 |
| --- | --- |
| 에이전시 관리자 및 사용자($97, $297, $497 에이전시 요금제) | 무료, 공정 사용 적용\* |
| 서브 계정 사용자(AI 직원 요금제 없음) | 포함되지 않음, 사용한 만큼 결제 |
| AI 직원 Starter(월 $20) | 표준 사용량\* |
| AI 직원 Growth(월 $50) | 높은 사용량\* |
| AI 직원 Unlimited(월 $97) | 무제한 사용량\* |

```
*공정 사용 정책: 무료, 표준, 높은 사용량, 무제한 사용량에는 과도한 사용 제한을 포함한 하이퍼클래스의 서비스 이용약관이 적용돼요. 사용량이 과도하거나 악용에 해당하거나 플랫폼 성능에 나쁜 영향을 주면, 하이퍼클래스는 사전 통보 여부와 관계없이 이용을 늦추거나 제한하거나 서비스 업그레이드를 요구하거나 접근을 종료할 수 있어요.
```

사용 제한: AI 스튜디오 사용량은 5시간 단위로 계속 이어지는 구간(롤링 윈도우)으로 측정하고, 추가 보호 장치도 있어요. 포함된 사용량은 요금제마다 달라요. 사용량이 한도에 도달했을 때 **Extra Usage**(추가 사용량)가 켜져 있으면 초과분이 사용한 만큼 내는 요금으로 청구될 수 있어요. 켜져 있지 않으면 해당 한도가 초기화될 때까지 이용이 일시 중지될 수 있어요.

사용한 만큼 결제 요금: AI 스튜디오 요금은 세션 중에 사용한 AI 모델, 토큰, 리소스, 작업을 기준으로 매겨요. 프로젝트의 복잡도, 생성한 콘텐츠, 수행한 작업에 따라 비용이 달라져요.

AI 스튜디오 사용량에 영향을 주는 요소는 다음과 같아요.

- 추론 및 계획 단계 수
- 생성한 페이지 수
- 콘텐츠와 문구 생성
- AI가 만든 이미지 등 미디어
- 참고 URL 또는 이미지 분석
- 폼과 캘린더 연결
- 반복 수정과 버전 기록
- 게시 및 사용자 도메인 설정

```
사용량을 미리 가늠해 보고 싶나요? AI Plan Calculator(AI 요금제 계산기)로 포함된 AI 스튜디오 사용량이 어느 정도인지 확인해 보세요.
```

{% hint style="warning" %}
AI 스튜디오 클라우드 호스팅은 AI 스튜디오 생성 사용량과 별도로 청구돼요. Nano 호스팅은 무료이고, Micro 이상의 클라우드 등급은 AI 직원 구독과 관계없이 추가 요금이 있어요. 자세한 요금은 AI 스튜디오 클라우드 요금(AI Studio Cloud Pricing) 문서를 참고하세요.
{% endhint %}

## 요가 리드 수집 랜딩 페이지

짧은 프롬프트 하나로 완성도 높은 단일 페이지 리드 수집 사이트를 만든 예시예요. 이미지, 테마에 맞춘 디자인 시스템, 검증이 들어간 리드 폼을 만든 뒤 CRM에 연결할지 물어봐요.

### 개요

AI 스튜디오가 요가 리드 수집용 단일 페이지 랜딩 페이지 "Sahaja"를 만들었어요. 히어로 영역, 혜택 그리드, 수업 스타일, 주간 일정, 강사 소개, 후기, 검증이 들어간 리드 폼으로 구성돼 있어요. 세이지 그린 색상과 Fraunces/Inter 서체를 적용했고, 마지막에 폼을 CRM에 연결할지 사용자에게 물었어요.

사용자 요청

## 이미지 중심 에디토리얼 패션 랜딩 페이지

자세한 프롬프트 하나로 디자인과 애니메이션이 풍부한 랜딩 페이지를 만든 예시예요. 의존성 설치, 이미지 전체 생성, 사용자 지정 서체와 모션 적용까지 진행해요.

### 개요

AI 스튜디오가 럭셔리 에디토리얼 패션 랜딩 페이지 "Maison Noir"를 만들었어요. 전체 화면 패럴랙스 히어로, 이미지와 텍스트가 번갈아 나오는 컬렉션 섹션, 전체 너비 매소니리 갤러리, 부드러운 호버 애니메이션을 갖췄어요. 모두 자세한 프롬프트 하나로 만들었어요.

사용자 요청

패션 브랜드를 위한, 시각적으로 강렬한 이미지 중심 랜딩 페이지를 만들어 줘. 전체 화면 히어로 이미지, 굵은 타이포그래피, 패럴랙스 스크롤, 이미지와 텍스트가 번갈아 나오는 섹션, 전체 너비 갤러리 그리드, 부드러운 호버 애니메이션을 넣어 줘. 여백이 넉넉하고 색상 구성이 통일된 프리미엄 에디토리얼 느낌이면 좋겠어.

![패럴랙스와 Cormorant Garamond 서체가 적용된 에디토리얼 히어로](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077343007/original/Hat38FTx6l9DQ7MgwpFyfy-DCuKOLJs4WA.jpeg?1785502316)

*패럴랙스와 Cormorant Garamond 디스플레이 서체가 적용된 "The Art of Undressing the Dark" 에디토리얼 히어로예요.*

### AI 스튜디오가 작업을 처리한 과정

AI 스튜디오는 다음 순서로 작업했어요.

- Cormorant 디스플레이 서체와 Karla 본문 서체를 쓰는 Noir & Gold 럭셔리 방향을 정했어요.
- 스크롤과 호버 애니메이션을 위해 `framer-motion`을 설치했어요.
- 히어로와 컬렉션 이미지를 전부 동시에 생성했어요.
- Noir & Gold 색상과 에디토리얼 타이포그래피로 디자인 토큰을 설정했어요.
- 패럴랙스 히어로, 번갈아 나오는 컬렉션 섹션, 갤러리 그리드, 푸터로 페이지를 만들었어요.
- 페이지 파일을 만들고 반복해서 다듬었어요.

### 만들어진 결과물

- 스크롤에 따라 이미지가 확대되고 헤드라인이 사라지는 전체 화면 패럴랙스 히어로
- Cormorant Garamond 디스플레이 서체와 Karla 본문 서체를 함께 쓴 굵은 타이포그래피`src/index.css`의 시맨틱 디자인 토큰으로 적용한 Noir & Gold 색상
- 이미지가 패럴랙스로 움직이고 호버하면 확대되는, 이미지와 텍스트가 번갈아 나오는 컬렉션 섹션 3개
- 호버하면 캡션이 나타나고 순차적으로 등장하는 애니메이션이 있는 전체 너비 매소니리 갤러리 그리드

## CMS가 있는 7페이지 여행 웹사이트

편집 가능한 콘텐츠 컬렉션, 문의 폼, 공통 내비게이션을 갖춘 더 큰 규모의 여러 페이지 사이트를 만든 예시예요. 기획과 페이지 생성이 가장 많이 필요한 유형의 프로젝트예요.

### 개요

AI 스튜디오가 인도 여행 업체를 위한 7페이지 웹사이트 "Bharat Voyages"를 완성했어요. 공통 내비게이션과 푸터, 블로그 글과 투어용 CMS, 반응형 디자인, SEO 메타데이터를 갖췄고, CRM에 연결할 수 있는 문의 폼도 들어 있어요.

사용자 요청

인도 여행 업체를 위한 CMS가 있는 7페이지 웹사이트를 만들어 줘. 홈, 소개, 서비스, 블로그(CMS 컬렉션), 포트폴리오/프로젝트(CMS 컬렉션), 요금, 문의(폼 포함)로 구성해 줘. 공통 내비게이션과 푸터, 반응형 디자인, 블로그 글과 프로젝트를 편집할 수 있는 콘텐츠 컬렉션, SEO에 유리한 구조가 필요해.

![공통 내비게이션, 히어로, 통계 영역이 있는 Bharat Voyages 홈 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077343183/original/NXEg8jyi0wUyRdWsHbs2qiUo42hpkdcLEA.jpeg?1785502362)

### AI 스튜디오가 작업을 처리한 과정

AI 스튜디오는 다음 순서로 작업했어요.

- 공통 내비게이션과 푸터가 있는 7페이지 구조를 기획했어요.
- 각 페이지에 들어갈 콘텐츠와 이미지를 생성했어요.
- 블로그 글과 투어를 위한 편집 가능한 CMS 콘텐츠 컬렉션을 만들었어요.
- 반응형 디자인과 SEO 메타데이터를 적용했어요.
- 문의 폼을 만들고 CRM에 연결할지 물었어요.

### 만들어진 페이지

| 페이지 | 용도 |

| 홈 | 히어로, 주요 소개, 핵심 행동 유도 버튼 |

## AI 스튜디오 사용량에 영향을 주는 요소

AI 스튜디오 사용량은 프롬프트 수만이 아니라 세션 중에 수행한 작업을 기준으로 정해져요. 추론, 생성, 연결 작업이 더 필요할수록 세션이 더 많은 리소스를 써요. 전체 작업량을 늘리는 요소는 다음과 같아요.

- 여러 페이지 구조와 큰 프로젝트
- 추가 질문과 여러 번의 수정
- AI가 만든 이미지 등 미디어
- 참고 URL 및 이미지 분석
- 폼과 캘린더 연결
- 사용자 도메인 설정과 게시
- 반복 수정으로 쌓이는 버전 기록

위 예시를 보면 다음과 같아요.

- AI 생성 이미지는 단일 요인으로는 가장 큰 경우가 많아요. 이미지가 많은 페이지는 페이지 수가 더 많아도 생성한 미디어가 적은 사이트보다 비용이 더 들 수 있어요.
- 페이지 수만으로는 비용을 예측하기 어려워요. 구조화된 7페이지 사이트가 이미지 중심의 단일 랜딩 페이지보다 비용이 적게 들 수도 있어요.
- 텍스트, 레이아웃, CMS 구조는 일반적으로 이미지 생성보다 처리 작업이 적어요.

## AI 스튜디오 사용량 및 지출 알림

AI 스튜디오는 한도에 도달하기 전에 사용량과 지출을 확인할 수 있도록 알림 배너를 보여 줘요. AI 스튜디오를 쓸 수 있는 사용자에게는 이 배너가 자동으로 켜져 있어서 따로 설정할 필요가 없어요.

### 구독 사용량 알림

구독 사용자는 AI 스튜디오 사용량이 늘어남에 따라 다음과 같은 알림을 받아요.

- 사용량 70%: 사용량 알림
- 사용량 85%: 경고
- 100%에 가까워지거나 도달했을 때: 심각 알림 및 사용량 소진 알림

결제 권한에 따라 배너에서 사용 한도를 조정하거나 에이전시 관리자에게 한도 증액을 요청할 수 있어요.

### 사용한 만큼 결제 지출 알림

사용한 만큼 결제하는 사용자는 AI 스튜디오에서 $50를 쓸 때마다 지출 알림을 받아요. 이 알림으로 지출이 늘어나는 동안 사용량과 비용을 확인할 수 있어요.

지출 한도 설정, 추가 사용량 요청, 한도 증액 요청 관리에 관한 자세한 내용은 AI 사용 제한(AI Usage Limits) 문서를 참고하세요.

## 자주 묻는 질문

### AI 스튜디오는 비용이 얼마인가요?

모든 하이퍼클래스 에이전시 요금제의 에이전시 사용자는 공정 사용 범위 안에서 추가 비용 없이 AI 스튜디오를 쓸 수 있어요. 서브 계정 사용자는 AI 직원 Starter(월 $20), Growth(월 $50), Unlimited(월 $97) 구독으로 쓰거나 사용한 만큼 결제할 수 있어요. Starter 요금제는 월 $497 요금제를 쓰는 에이전시에게만 제공돼요.

### 프롬프트마다 작업량이 같은가요?

아니요. 작업량은 요청의 복잡도에 따라 달라요. 페이지 수, 수정 횟수, 생성한 자산, 연결 작업이 영향을 줘요.

### 이미지 생성이 텍스트보다 작업이 더 많나요?

대체로 그래요. 이미지 같은 시각 자산을 만들 때가 텍스트만 만들 때보다 처리 작업이 더 필요해요.

### 폼과 캘린더는 자동으로 연결되나요?

아니요. AI 스튜디오는 먼저 폼이나 예약 레이아웃을 만들고, 요청하거나 **Connect**(연결)를 클릭한 뒤에 연결해요. 제출 내용과 예약은 이 단계를 거친 뒤에야 서브 계정으로 들어와요.

### URL만 주면 AI 스튜디오가 사이트를 똑같이 만들어 주나요?

참고 URL이나 이미지는 구조, 레이아웃, 스타일을 잡는 영감으로 생각해 주세요. 똑같이 복사한 결과가 나오는 것은 아니에요.
