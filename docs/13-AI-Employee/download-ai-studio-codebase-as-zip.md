# AI 스튜디오 코드베이스를 ZIP 파일로 다운로드하기

AI 스튜디오 프로젝트의 전체 코드를 내려받아 외부에서 개발을 이어 가거나, 원하는 편집기에서 수정하거나, 다른 곳에 호스팅할 수 있어요. 이 문서에서는 현재 버전과 이전 버전을 ZIP 파일로 다운로드하는 방법을 안내해요.

## 코드베이스 다운로드란?

**Download Codebase**(코드베이스 다운로드)는 AI 스튜디오 프로젝트 전체를 ZIP 파일 하나로 내보내는 기능이에요. ZIP 파일에는 프로젝트의 모든 파일과 코드가 들어 있어요. AI 스튜디오 안에서 만든 웹사이트, 애플리케이션, 도구의 코드를 직접 받아 볼 수 있어요.

프로젝트의 현재 버전을 다운로드할 수도 있고, 프로젝트 기록에서 이전 버전을 골라 받을 수도 있어요. 다운로드한 ZIP 파일에는 해당 시점의 전체 코드베이스가 담겨요.

이 기능을 쓰면 하이퍼클래스 밖에서도 프로젝트 코드를 다룰 수 있어요. 로컬에서 수정하거나, 외부 도구로 개발을 이어 가거나, 직접 운영하는 인프라에 애플리케이션을 호스팅할 수 있어요.

## 이럴 때 유용해요

코드베이스를 다운로드하면 AI 스튜디오 프로젝트를 더 자유롭게 다룰 수 있어요.

- 외부 개발: AI 스튜디오 밖에서 외부 AI 코딩 에이전트나 개발 도구로 프로젝트를 계속 만들어 갈 수 있어요.
- 로컬 편집: 자주 쓰는 텍스트 편집기나 IDE에서 코드를 직접 고쳐 세밀하게 조정할 수 있어요.
- 백업 및 보관: 버전 관리, 백업, 오프라인 참고용으로 프로젝트 코드를 내 컴퓨터에 보관할 수 있어요.
- 직접 호스팅: 외부 서버, 클라우드 플랫폼, 직접 운영하는 인프라에 애플리케이션을 호스팅하거나 배포할 수 있어요.
- 버전별 다운로드: **버전 기록**에 있는 이전 버전을 각각 별도의 ZIP 파일로 받을 수 있어요.

## 현재 버전 코드베이스 다운로드하기

현재 버전은 아래 두 가지 방법 중 하나로 다운로드할 수 있어요.

### 방법 1: 코드 화면에서

1. AI 스튜디오 프로젝트의 상단 메뉴에서 **코드**를 클릭하세요.
2. **코드** 화면 맨 아래로 스크롤하세요.
3. **Download Codebase** 버튼을 클릭하세요. 프로젝트가 ZIP 파일로 기본 다운로드 위치에 저장돼요.

![코드 화면 맨 아래의 Download Codebase 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080260139/original/fnL5Tz7L631e17C-fW4hZghj2gxx9PghRA.png?1788778518)

### 방법 2: 프로젝트 설정에서

1. AI 스튜디오 프로젝트에서 **Project Settings**(프로젝트 설정)로 이동하세요.
2. **Project Settings** 안에서 **Download Codebase** 항목을 찾으세요.
3. **Download Codebase** 버튼을 클릭하면 프로젝트가 ZIP 파일로 다운로드돼요.

![프로젝트 설정의 Download Codebase 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080260344/original/dXifCRSIfCfA4Tu8NJrUdHZ3ZJaGI20eZQ.png?1788778579)

## 이전 버전 다운로드하기

**버전 기록**에서 프로젝트의 이전 버전을 골라 다운로드할 수 있어요. 예전 코드 상태를 확인하거나 버전별 차이를 비교할 때 쓰면 좋아요.

1. AI 스튜디오에서 프로젝트의 **버전 기록**으로 이동하세요.
2. 기록 목록에서 다운로드할 버전을 찾아 그 버전 옆의 **점 세 개 메뉴** 아이콘을 클릭하세요.
3. 메뉴에서 **Download ZIP**(ZIP 다운로드)을 선택하세요. 선택한 버전이 해당 시점의 코드베이스가 담긴 별도의 ZIP 파일로 다운로드돼요.

![버전 기록에서 점 세 개 메뉴로 ZIP 다운로드를 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080269713/original/cobiS1_w6sDzn88nkeGho2xAlemAlQsYBQ.gif?1788782229)

{% hint style="info" %}
버전을 다운로드할 때마다 독립된 ZIP 파일이 만들어져요. 여러 버전을 받아 두면 코드 변경 내용을 비교하거나, 프로젝트 기록에서 특정 구현을 되살릴 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 다운로드한 ZIP 파일에는 어떤 파일이 들어 있나요?
ZIP 파일에는 프로젝트의 전체 코드베이스가 들어 있어요. AI 스튜디오 프로젝트를 이루는 HTML, CSS, JavaScript, 설정 파일, 에셋 등 모든 파일이 포함돼요.

### 다운로드한 코드를 다시 AI 스튜디오에 업로드할 수 있나요?
다운로드 기능은 코드를 내보내는 용도로 만들어졌어요. 외부에서 수정한 뒤 AI 스튜디오에서 이어서 작업하고 싶다면, 수정한 코드를 **코드** 편집기에서 프로젝트에 직접 복사해 붙여 넣으면 돼요.

### 코드베이스를 다운로드하면 AI 스튜디오 프로젝트에 영향이 있나요?
아니요. 다운로드하면 코드의 사본이 만들어질 뿐이에요. 원래 프로젝트는 AI 스튜디오에 그대로 남아 있고, 평소처럼 계속 작업할 수 있어요.

### 내가 소유하지 않은 프로젝트의 코드도 다운로드할 수 있나요?
적절한 접근 권한이 있는 프로젝트의 코드베이스만 다운로드할 수 있어요. 프로젝트 소유자와 충분한 권한을 가진 협업자가 코드를 다운로드할 수 있어요.

### 몇 개의 버전까지 다운로드할 수 있나요?
**버전 기록**에 있는 버전은 모두 다운로드할 수 있어요. 버전마다 별도의 ZIP 파일로 받아지기 때문에, 프로젝트 개발 과정의 원하는 시점을 골라 볼 수 있어요.

### 코드베이스를 다운로드한 뒤에는 무엇을 하면 되나요?
ZIP 파일을 내 컴퓨터의 폴더에 압축 해제하세요. 그런 다음 자주 쓰는 텍스트 편집기, IDE, 개발 환경에서 코드를 열면 돼요. 이 코드는 로컬에서 실행하거나 수정하거나 외부 호스팅 플랫폼에 배포할 수 있는 상태예요.

### 다운로드할 수 있는 파일 크기에 제한이 있나요?
**Download Codebase**는 크기와 상관없이 프로젝트 전체를 내보내요. 다만 코드와 에셋이 많은 큰 프로젝트는 파일을 준비하고 다운로드하는 데 시간이 더 걸릴 수 있어요.

### 다운로드한 코드를 상업적으로 사용해도 되나요?
네. AI 스튜디오에서 만들고 다운로드한 코드는 상업적 용도를 포함해 원하는 대로 사용할 수 있어요. 외부 서버에 호스팅하거나 다른 애플리케이션에 통합해도 돼요.
