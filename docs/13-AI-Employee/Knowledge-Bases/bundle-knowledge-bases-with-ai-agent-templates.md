# AI 에이전트 템플릿에 지식 베이스 함께 담기

AI 에이전트 마켓플레이스 템플릿에 **지식 베이스**를 함께 담으면, 템플릿 제작자가 에이전트와 그 에이전트가 참고할 자료를 한 번에 배포할 수 있어요. 에이전트가 FAQ, 서비스 정보, 정책, 문서, 업종별 정보를 바탕으로 정확하게 답해야 할 때 유용해요. 구매자는 더 완성도 높은 템플릿을 설치한 뒤, 운영을 시작하기 전에 지식 베이스를 자기 비즈니스에 맞게 검토하고 수정할 수 있어요.

## AI 에이전트 마켓플레이스 템플릿의 지식 베이스 번들이란?

지식 베이스를 번들로 담는다는 것은 템플릿을 게시할 때 선택한 지식 베이스 콘텐츠를 함께 포함한다는 뜻이에요. 템플릿을 설치하면, 템플릿 패키지에 포함된 자산에 따라 구매자가 에이전트와 그 지식 베이스 콘텐츠를 함께 받을 수 있어요.

신뢰할 수 있는 자료를 바탕으로 일하는 에이전트에 특히 유용해요. 예를 들면 고객지원 에이전트, 서비스 문의 에이전트, 정책 안내 에이전트, 영업 지원 에이전트, 문서 기반 에이전트가 있어요. 번들로 받은 지식 베이스도 설치한 뒤에 꼭 검토하고 테스트해서 구매자의 비즈니스에 맞는지 확인해야 해요.

## 지식 베이스 번들의 장점

지식 베이스를 번들로 담으면 템플릿 제작자가 더 완성도 높은 AI 에이전트 환경을 제공할 수 있어요. 구매자에게 자료를 처음부터 다시 만들라고 하는 대신, 에이전트의 사용 목적에 맞는 재사용 가능한 지식을 함께 넣어 줄 수 있어요.

- 빠른 효과 확인: 에이전시가 처음부터 콘텐츠를 만들 필요 없이, 바로 쓸 수 있는 답변으로 시작해요.
- 설치 직후부터 똑똑한 응답: 에이전트가 번들로 담긴 문서, 파일, 데이터를 근거로 답해요.
- 표준화된 온보딩: 설치할 때마다 일관되고 품질 높은 참고 자료를 받아요.
- 가르치는 템플릿: 지식 베이스가 안내서 역할도 해서, 에이전시가 자기 콘텐츠로 바꿔 넣을 수 있어요.
- 지원 부담 감소: 미리 채워진 예시 덕분에 설정 관련 문의가 줄어요.
- 확장 가능한 품질 관리: 제작자가 처음부터 구조, 이름, 검색하기 좋은 콘텐츠를 직접 관리해요.

## 지식 베이스를 번들로 담아야 하는 경우

에이전트의 가치가 특정 참고 콘텐츠에 달려 있다면 지식 베이스를 번들로 담는 것이 좋아요. 이미 알려진 답변, 정책, 문서를 찾아볼 수 있어야 에이전트가 제대로 작동한다면, 게시할 때 지식 베이스를 포함하세요.

다음과 같은 경우에 지식 베이스를 번들로 담으세요.

- 에이전트가 FAQ에 답해요.
- 에이전트가 서비스, 상품, 정책 정보를 사용해요.
- 에이전트에 업종별 콘텐츠가 필요해요.
- 에이전트가 고객지원, 영업, 온보딩, 접수, 문서 관련 업무를 지원해요.
- 에이전트가 **에이전트 스튜디오**의 **Knowledge Base Tool**(지식 베이스 도구)을 사용해요.
- 템플릿이 지식 베이스 콘텐츠를 바탕으로 응답하는 음성 AI용으로 만들어졌어요.
- 구매자가 에이전트 흐름이나 설정과 함께 원본 콘텐츠도 받아야 해요.

고객 개인 데이터, 오래된 정보, 특정 계정에만 쓰이는 비밀 정보, 구매자에게 공유하면 안 되는 콘텐츠가 들어 있는 지식 베이스는 번들로 담지 마세요.

## 에이전시용: 번들 지식 베이스 설치하고 수정하기

일부 마켓플레이스 템플릿은 미리 채워진 지식 베이스와 함께 제공돼요. 아래 순서대로 지식 베이스를 설치하고, 찾고, 수정하고, 확인하면 에이전트가 정확하고 브랜드에 맞는 답변을 빠르게 할 수 있어요.

### 번들 지식 베이스 설치하고 찾기

1. 마켓플레이스에서 대상 서브 계정에 템플릿을 설치해요.
2. 설치 화면에 **Knowledge Base Included**(지식 베이스 포함됨)가 표시되는지 확인하고 설치를 마쳐요.
3. **AI Tools**(AI 도구) **> 지식 베이스**에서 가져온 폴더를 찾아요. 가져온 폴더 이름 앞에 템플릿 이름이나 설치 날짜가 붙어 있을 수 있어요.

### 콘텐츠 수정하고 교체하기

- 안전하게 수정하기: 크게 바꾸기 전에 폴더를 복제해 두면 되돌릴 수 있어요.
- 자리표시자 빠르게 교체하기: `{{Brand}}`, `{{Phone}}`, `{{URL}}` 같은 문구를 검색해서 모든 문서에서 바꿔 주세요.
- 내 문서 추가하기: 정책, FAQ, 상품 자료를 업로드하세요. 검색이 더 잘 되도록 텍스트 중심의 자료를 권해요.
- 필요하면 검색 대상 다시 지정하기: 새 폴더를 만들었다면 에이전트 스튜디오에서 에이전트의 지식 베이스 노드를 열어 새 폴더나 태그를 포함하도록 업데이트하세요.

## 설치 후: 번들 지식 베이스를 찾고 관리하는 곳

에이전시는 가져온 콘텐츠가 어디에 있는지, 어떻게 맞춤 수정하는지, 에이전트가 올바른 자료를 바탕으로 답하게 하려면 어떻게 하는지 알아 두세요.

- 위치: **AI Tools > 지식 베이스**로 이동하면 새로 추가된 폴더와 문서를 볼 수 있어요. 템플릿 이름이나 타임스탬프가 표시돼 있어요.
- 편집: 문서를 열어 텍스트를 수정하고, 브랜드 이름을 바꾸고, 예시를 업데이트하세요. 변경 내용은 에이전트가 자료를 검색할 때 바로 반영돼요.
- 템플릿 콘텐츠 교체:
  - 같은 폴더에 비즈니스별 문서를 추가하거나 새 폴더를 만들고, 검색 대상을 다시 지정하세요(에이전트가 특정 지식 베이스 노드나 필터를 쓰는 경우).
  - 실제 콘텐츠로 옮긴 뒤에는 템플릿 예시를 제거하거나 보관하세요.
- 에이전트와 연결: 에이전트의 지식 베이스 노드(또는 검색 설정)에 원하는 폴더와 태그가 포함돼 있는지 확인하세요. 그래야 에이전트가 수정한 콘텐츠를 참고해요.

## 에이전시를 위한 활용 팁 (번들 지식 베이스 도입)

아래 순서를 따르면 템플릿을 내 것으로 만들고 에이전트의 정확도를 유지할 수 있어요.

- 가져온 폴더를 복제한 다음, 원본 참고 자료를 잃지 않으면서 콘텐츠를 수정하세요.
- 자리표시자(브랜드 이름, 오퍼, 연락처)는 바로 교체하세요.
- 자주 묻는 질문, 정책, 가격을 가장 먼저 추가하세요. 답변 품질이 가장 크게 좋아져요.
- 큰 파일은 크기 제한 안에 맞추고, 검색이 더 잘 되도록 텍스트 중심 자료를 권해요.
- 수정한 뒤에는 에이전트와 대화해 보면서 답변이 예상한 문서를 근거로 하는지 확인하세요.

## 에이전트 빌더용: 지식 베이스를 번들로 담아 게시하기

빌더는 마켓플레이스에 게시할 때 연결된 지식 베이스를 첨부할 수 있어요. 아래 순서를 따르면 올바른 콘텐츠가 번들로 담기고, 에이전시가 설치할 때 바로 쓸 수 있고 수정도 가능한 사본을 받아요.

### 마켓플레이스에 게시할 때 지식 베이스 포함하기

순서대로 따라 하면 게시할 때 알맞은 지식 베이스를 첨부하고, 검토 중 생길 수 있는 문제를 피하고, 에이전시가 제대로 동작하는 환경을 받게 할 수 있어요.

1. 마켓플레이스(Developer Portal, 개발자 포털)로 이동해 **My Apps**(내 앱)를 클릭하면 기존 앱이 모두 보여요. 새 앱을 만들려면 **Create App**(앱 만들기)을 클릭하세요.

![마켓플레이스 개발자 포털의 앱 목록과 앱 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059795541/original/O_Gnr3Tb3lwVHaywr2CtoA1EaIesJ5mSYQ.png?1764762599)

2. 앱의 기본 정보를 모두 입력하고 **Create App**을 클릭하세요.

![앱 기본 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059795891/original/abXTyD7r2yZG_IdV1UAUfi-_9PuoiJaL2Q.png?1764762762)

3. 앱 빌더에서 **모듈 > 대화 AI**를 열어요. 지식 베이스 링크를 붙여 넣고, 아래로 스크롤해서 **지식 베이스** 영역으로 이동하세요.

![앱 빌더의 모듈 > 대화 AI 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059796374/original/OJygnnB6pYIxyEIs3syNJ3rKsaH9-wsi9w.png?1764763060)

4. **Include Knowledge Base**(지식 베이스 포함) 토글을 켜세요. 에이전트에 지식 베이스가 연결돼 있을 때만 켤 수 있어요. 에이전트 스튜디오에서 에이전트에 올바른 지식 베이스가 연결돼 있는지 확인하세요. 연결된 것이 없으면 에이전트로 돌아가 지식 베이스를 추가한 다음, 이 화면으로 다시 오세요.

![지식 베이스 포함 토글을 켜는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059770863/original/-py14BQ8LMWjJiL8FTCZz_LvmEcYpJIXVw.gif?1764751462)

5. **What's Included**(포함 항목)를 확인하고, 등록 정보(이름, 설명, 카테고리, 가격/공개 범위)를 마무리한 뒤 **검토 제출**을 클릭하세요.

![등록 정보 입력 후 검토 제출 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059776906/original/sEsSAAU1J_ZMJuAa8a3-1D-fYm10Od6LpA.png?1764754088)

6. 승인되면 테스트용 서브 계정에 템플릿을 설치하고, 에이전트의 답변이 번들로 담긴 지식 베이스를 근거로 하는지 확인하세요.

## 에이전트 빌더를 위한 활용 팁 (템플릿용 지식 베이스 설계)

구조가 잘 잡힌 템플릿 지식 베이스는 에이전시가 성공하는 방법을 알려 주면서도, 실제 데이터로 쉽게 바꿔 넣을 수 있어요.

- 콘텐츠를 명확한 폴더로 나누세요(예: “시작하기”, “상품 FAQ”, “가격 예시”).
- 사용자가 물을 법한 질문과 비슷한, 내용이 드러나는 문서 제목을 쓰세요.
- 브랜드 이름, URL, 가격은 자리표시자로 넣어 두면 에이전시가 쉽게 찾아 바꿀 수 있어요.
- 짧은 문단, 제목, 목록처럼 간결하고 검색하기 좋은 글로 쓰세요.
- 핵심 문서로 연결되는 짧은 “여기서 시작” 문서를 넣으세요.
- 게시하기 전에 독점 자료나 기밀 자료를 제거하세요.
- 번들로 담은 지식 베이스만 연결한 상태로 에이전트를 테스트해서, 설치 직후에도 답변 품질이 좋은지 확인하세요.

## 번들 범위와 동작 방식

무엇이 패키지에 담기는지, 설치하는 계정에 무엇이 복사되는지, 그 사본이 시간이 지나면서 어떻게 동작하는지 정확히 알아 두세요.

- 복사 방식: 번들로 담은 지식 베이스 콘텐츠는 템플릿을 설치할 때 설치하는 에이전시 계정으로 복사돼요. 에이전시가 수정해도 제작자의 원본 지식 베이스에는 영향이 없어요.
- 포함되는 항목:
  - 에이전트에 연결된 지식 베이스 폴더와 문서(리치 텍스트 페이지)
  - 포함된 폴더에 속한 지원 파일 첨부(예: PDF, 이미지)
  - 검색에 쓰이는 표/CSV 자료(지식 베이스에 포함된 경우)
  - 학습된 링크(웹 URL)와 현재 색인된 콘텐츠
- 포함되지 않는 항목: 전달할 수 없는 계정 전용 항목(예: 비공개 연동이나 자격 증명). 템플릿에서는 자리표시자로 바꿔 두세요.
- 게시 후 업데이트: 나중에 원본 지식 베이스를 바꿔도, 이미 템플릿을 설치한 에이전시에는 자동으로 동기화되지 않아요. 에이전시가 수정본을 받게 하려면 새 템플릿 버전을 내놓거나 콘텐츠 업데이트 팩을 제공하세요.
- 중복 방지: 에이전시가 이름이 비슷한 지식 베이스 폴더가 들어 있는 템플릿을 여러 개 설치하면, 충돌하지 않도록 시스템이 별도 사본을 만들어요. 에이전시는 설치한 뒤에 병합하거나 이름을 바꿀 수 있어요.

## 자주 묻는 질문

### AI 에이전트 마켓플레이스 템플릿에 지식 베이스를 꼭 번들로 담아야 하나요?
아니요. 지식 베이스 번들은 선택 사항이에요. 에이전트가 정확하게 답하려면 원본 콘텐츠가 필요할 때 포함하세요.

### 지식 베이스를 포함하도록 선택하지 않으면 어떻게 되나요?
템플릿이 해당 지식 베이스 없이 설치될 수 있어요. 구매자가 설치한 뒤에 직접 지식 베이스를 만들거나 연결해야 할 수 있어요.

### 템플릿 하나에 지식 베이스를 두 개 이상 담을 수 있나요?
템플릿 유형, 에이전트 유형, 게시 방식에 따라 다를 수 있어요. 게시할 때 템플릿 자산 옵션을 확인하세요.

### 번들로 담기 전에 고객 관련 정보를 지워야 하나요?
네. 구매자에게 공유하면 안 되는 개인 정보, 민감한 정보, 오래된 정보, 고객 관련 콘텐츠는 제거하세요.

### 번들로 담으면 에이전트가 정확하게 답한다고 보장되나요?
아니요. 에이전트가 지식 베이스를 올바르게 쓰도록 설정돼 있어야 하고, 설치한 템플릿은 실제로 쓰기 전에 테스트해야 해요.

### 구매자가 설치한 뒤에 번들 지식 베이스를 수정할 수 있나요?
구매자는 설치된 지식 베이스를 검토해서 자기 비즈니스, 서비스, 정책, 고객 요구에 맞게 수정해야 해요.

### 음성 AI 템플릿에도 지식 베이스를 담을 수 있나요?
음성 AI 에이전트는 설정하면 지식 베이스 연동을 쓸 수 있어요. 판매자와 구매자는 설치된 음성 AI 에이전트가 올바른 지식 베이스에 연결돼 있는지 확인하고 응답을 테스트하세요.

### 에이전트 스튜디오 에이전트도 번들 지식 베이스를 쓸 수 있나요?
네. 에이전트 스튜디오 흐름에 **Knowledge Base Tool**이 설정돼 있고, 설치된 지식 베이스가 올바르게 선택돼 있으면 쓸 수 있어요.

### 지식 베이스가 포함된 템플릿을 설치한 뒤 구매자는 무엇을 확인해야 하나요?
운영을 시작하기 전에 지식 베이스 자료, 에이전트 연결, 커스텀 값, 변수, 워크플로우, 캘린더, 테스트 응답을 확인해야 해요.

### 판매자는 번들 지식 베이스를 어떻게 테스트해야 하나요?
테스트용 서브 계정에 템플릿을 설치하고, 지식 베이스가 제대로 설치됐는지 확인하고, 에이전트 연결을 점검한 뒤, 지식 베이스 답변이 필요한 테스트 대화를 진행하세요.
