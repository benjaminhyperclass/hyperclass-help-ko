# Conversation AI 봇 학습시키기

Conversation AI 봇이 고객 질문에 정확히 답하려면 명확하고 최신인 비즈니스 정보가 필요해요. 하이퍼클래스 **지식 베이스**(Knowledge Base)에는 웹사이트 페이지, 자주 묻는 질문, 문서, 테이블, 리치 텍스트 등 여러 소스를 함께 담을 수 있어요. 이 문서에서는 학습 콘텐츠를 추가하고 관리하는 방법, 봇에 연결하는 방법, 출시 전에 응답을 테스트하는 방법을 안내해요.

## Conversation AI 봇 학습이란?

봇 학습은 에이전트가 고객 질문에 답할 때 참고할 수 있도록, 승인된 비즈니스 정보를 연결해 주는 작업이에요. 봇은 일반적인 AI 지식에만 의존하지 않고, 연결된 지식 베이스에서 관련 내용을 찾아 그 정보로 답변을 만들어요.

학습 콘텐츠로 쓸 수 있는 자료는 다음과 같아요.

- 웹사이트 및 고객센터 페이지
- 자주 묻는 질문
- 정책과 서면 안내문
- 상품, 서비스, 가격 테이블
- 업로드한 문서
- Google Drive 파일
- 승인된 웹 기반 소스

{% hint style="info" %}
계정에 따라 **웹 크롤러**(Web Crawler)와 **Custom Bot Responses**(맞춤 봇 응답)가 봇의 **봇 학습** 탭에 바로 보이기도 해요. 개편된 화면에서는 소스를 **AI 에이전트 > 지식 베이스**에서 관리하고, 봇 안에서 해당 지식 베이스를 선택해요.
{% endhint %}

---

## 봇을 학습시키면 좋은 점

소스 콘텐츠가 명확하고 잘 정리되어 있으면 봇이 더 유용하게 답하고, 업데이트와 문제 해결도 쉬워져요.

- 더 정확한 답변: 승인된 비즈니스 정보를 바탕으로 답해요.
- 다양한 소스 지원: 웹사이트, 자주 묻는 질문, 파일, 테이블, 직접 쓴 글을 함께 쓸 수 있어요.
- 일관된 정보: 고객에게 항상 같은 정책, 가격, 서비스 정보를 안내해요.
- 쉬운 관리: 봇을 다시 만들지 않고도 소스를 새로 고치거나 교체하거나 삭제할 수 있어요.
- 더 나은 테스트: 출시 전에 올바른 정보를 찾아오는지 확인할 수 있어요.

## 알맞은 지식 소스 고르기

콘텐츠 구조에 맞는 소스 유형을 고르면 Conversation AI가 정보를 더 쉽게 찾아요.

| 소스 | 이럴 때 좋아요 |
| --- | --- |
| **웹 크롤러** | 공개된 서비스 페이지, 도움말 문서, 가격 페이지, 정책 등 웹사이트 콘텐츠 |
| **자주 묻는 질문** | 고객이 자주 묻는 질문에 대해 승인된 답변을 그대로 전달할 때 |
| **리치 텍스트** | 하이퍼클래스에서 직접 작성한 정책, 안내문, 비즈니스 정보, 메모 |
| **파일 업로드** | 검색 가능한 텍스트가 들어 있는 지원 문서 |
| **테이블** | 가격표, 상품 카탈로그, 서비스 목록처럼 구조화된 정보 |
| **웹 검색** | 업로드한 비즈니스 콘텐츠에 없는, 지원되는 외부 웹 정보 |
| **Google Drive** | 지원되는 Google Docs, PDF, DOC, DOCX 파일 가져오기 |

지식 베이스 하나에 여러 소스 유형을 함께 담을 수 있어요. 봇이 답해야 할 질문을 다룰 수 있는 범위에서, 명확하고 관련 있는 소스만 최소한으로 쓰세요.

## Conversation AI 봇 학습시키기

안정적으로 설정하려면 승인된 소스 콘텐츠를 추가하고, 처리가 끝났는지 확인한 다음, 정보 검색과 봇의 전체 응답을 모두 테스트하세요.

### 1단계: 봇 학습 열기

**봇 학습** 영역에서 Conversation AI 봇이 고객 응대에 사용할 정보를 연결해요.

1. **AI 에이전트 > 대화 AI**로 이동하세요.
2. **에이전트 목록**을 여세요.
3. 기존 봇을 선택하거나 새로 만드세요.
4. **봇 학습** 탭을 여세요.
5. 지식 베이스 선택 칸이 보이면 기존 지식 베이스를 선택하세요.

지식 베이스를 새로 만들거나 한곳에서 관리하려면 **AI 에이전트 > 지식 베이스**로 이동하세요.

![웹 크롤러, 업로드된 링크, 맞춤 봇 응답, 봇 테스트가 보이는 Conversation AI 봇 학습 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039825034/original/e16ZMdJvSNSQ2RuHp6tMSlK1Mu1jL-LHdg.jpeg?1736872885=)

### 2단계: 기존 웹사이트 소스 확인하기

콘텐츠를 더 추가하기 전에 이미 학습된 URL을 확인하면 중복, 오래된 정보, 서로 충돌하는 답변을 막을 수 있어요.

**업로드된 링크**를 펼치고 다음을 확인하세요.

- 올바른 페이지가 학습되었는지
- 각 소스의 상태가 성공으로 표시되는지
- 새로 고침 시각이 최근인지
- 내용이 아직 유효한지

![학습된 웹사이트 URL과 새로 고침 시각이 보이는 업로드된 링크 표](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039825074/original/6LJg1GHQ3QSp6KEgbacL0CwQEcIRXnHGMg.jpeg?1736872923=)

### 3단계: 웹사이트 콘텐츠 추가하기

고객에게 보여 줘도 되는 승인된 정보가 이미 공개 웹사이트에 있다면 **웹 크롤러**를 사용하세요.

1. 크롤링 방식을 선택하세요.
   - **정확한 URL**: 특정 페이지 하나만 크롤링해요.
   - **All URLs with this Path**(이 경로의 모든 URL): 같은 URL 경로를 쓰는 페이지를 찾아요.
   - **All URLs in this Domain**(이 도메인의 모든 URL): 도메인 전체에서 페이지를 찾아요.
2. `https://`를 포함해 전체 URL을 입력하세요.
3. **Get Data**(데이터 가져오기)를 클릭하세요.
4. 하이퍼클래스가 찾은 페이지를 확인하세요.
5. 고객 질문과 관련 있는 페이지만 선택하세요.
6. **봇 학습**을 클릭하세요.
7. 선택한 URL이 모두 **학습됨**으로 표시될 때까지 기다리세요.

![정확한 URL, 도메인, 경로 크롤링 옵션이 보이는 웹 크롤러 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039830261/original/AdPxdhIyOyQbqfqVnPFSEssl4AlYCQzYDA.gif?1736880673=)

![Get Data를 선택한 뒤 웹사이트 페이지를 가져오는 웹 크롤러](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039828897/original/3BKWqlTHf82HGcwKVPzpyAM5JeqDEKFR5Q.gif?1736877926=)

{% hint style="info" %}
웹사이트의 모든 페이지를 자동으로 학습시키지는 마세요. 오래된 페이지, 중복된 페이지, 메뉴만 있는 페이지, 형식적인 법적 문구, 관련 없는 페이지는 빼 주세요. 이런 페이지는 정보를 찾는 품질을 떨어뜨릴 수 있어요.
{% endhint %}

### 4단계: 문서, 테이블, 리치 텍스트, Google Drive 파일 추가하기

중요한 정보가 문서, 스프레드시트, 내부 안내문, 구조화된 목록에 있다면 웹사이트 외 소스를 사용하세요.

1. **AI 에이전트 > 지식 베이스**로 이동하세요.
2. 지식 베이스를 만들거나 여세요.
3. **소스 추가**를 클릭하세요.
4. 필요한 소스 유형을 선택하세요.
5. 콘텐츠를 추가하고 처리가 끝날 때까지 기다리세요.
6. Conversation AI 봇으로 돌아가 업데이트된 지식 베이스를 선택하세요.

소스별 용도는 다음과 같아요.

- **파일 업로드**: 검색 가능한 텍스트가 들어 있는 지원 문서
- **테이블**: 가격, 상품, 재고, 서비스처럼 구조화된 데이터
- **리치 텍스트**: 하이퍼클래스에서 직접 관리하는 정보
- **Google Drive**: 지원되는 파일을 가져올 때 사용해요. 파일을 수정한 뒤에는 직접 다시 동기화해야 해요.

Google Docs 문서를 웹 크롤러 화면에서 바로 사용하려면 먼저 공유 권한을 **링크가 있는 모든 사람**으로 설정하세요. 그런 다음 **정확한 URL**을 선택하고 문서 URL을 붙여 넣은 뒤 **Get Data**를 클릭하세요.

![웹 크롤러로 추가한 공개 Google Docs 문서가 학습됨 상태로 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039829486/original/mPxitCqoF1RBZmz6yQ9zryF7z30NqFEd2Q.png?1736879009=)

### 5단계: 맞춤 봇 응답 또는 자주 묻는 질문 추가하기

다른 소스에서 분명하게 다루지 않는 흔한 질문이 있다면, 자주 묻는 질문으로 간결하고 승인된 답변을 줄 수 있어요.

1. **+ Add Q & A**(Q&A 추가)를 클릭하세요.
2. 고객이 실제로 할 법한 말투로 질문을 입력하세요.
3. 간결하면서 빠짐없는 답변을 입력하세요.
4. Q&A를 저장하세요.
5. 같은 질문을 다양한 표현으로 바꿔 테스트하세요.

한곳에서 관리하는 지식 베이스에서는 **자주 묻는 질문** 소스 탭을 열어 질문과 답변을 추가하거나 관리하세요.

자주 묻는 질문으로 다루기 좋은 주제는 다음과 같아요.

- 운영시간
- 가격 규정
- 환불 또는 취소 정책
- 서비스 지역
- 연락처 정보
- 자주 묻는 설정 방법

![봇 학습 아래에서 맞춤 봇 응답의 질문과 답변을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039825319/original/K4p1iXpTC3XsyyNy9KtH8K_oIdO187zgBQ.gif?1736873143=)

### 6단계: 소스를 최신 상태로 유지하기

소스 콘텐츠를 꾸준히 관리하면 오래된 가격, 정책, 서비스, 안내가 고객 대화에 나오는 일을 막을 수 있어요.

사용할 수 있는 소스 관리 기능으로 다음 작업을 할 수 있어요.

- 제목이나 주소로 학습된 URL 검색
- 내용이 바뀐 웹사이트 페이지 새로 고침
- 오래되었거나 관련 없는 소스 제거
- 가능한 경우 URL 일괄 새로 고침 또는 삭제
- 수정 후 가져온 Google Drive 파일 다시 동기화
- 수정된 업로드 문서 교체
- 중복되거나 충돌하는 정보 제거

웹 URL 소스는 **Auto Refresh**(자동 새로 고침)로 매일, 매주, 매월 일정에 맞춰 콘텐츠를 다시 크롤링할 수 있어요. 페이지가 바뀌는 빈도에 맞는 주기를 고르세요.

### 7단계: 정보 검색과 봇 응답 테스트하기

테스트를 하면 하이퍼클래스가 올바른 소스를 찾는지, 봇이 그 소스로 정확하고 유용한 답변을 만드는지 확인할 수 있어요.

먼저 지식 베이스를 테스트하세요.

1. **AI 에이전트 > 지식 베이스**로 이동하세요.
2. 봇에 연결된 지식 베이스를 여세요.
3. 새로 추가했거나 업데이트한 소스의 처리가 끝날 때까지 기다리세요.
4. **Knowledge Base Retrieval Tester**(지식 베이스 검색 테스트 도구)를 여세요.
5. 실제 고객이 할 법한 질문을 입력하세요.
6. 답변과 가져온 소스를 확인하세요.
7. 불명확하거나 빠졌거나 오래된 콘텐츠를 수정하세요.
8. 같은 질문으로 다시 테스트하세요.

그다음 봇 전체를 테스트하세요.

1. Conversation AI 봇으로 돌아가세요.
2. **봇 학습**을 여세요.
3. **Test your Bot**(봇 테스트)에 질문을 입력하세요.
4. 자주 묻는 질문, 표현을 바꾼 질문, 자주 묻는 질문에 등록한 내용, 범위를 벗어난 질문을 각각 테스트하세요.
5. 다른 시나리오를 테스트하기 전에는 초기화 아이콘을 사용하세요.
6. 응답이 승인된 소스 콘텐츠와 일치하는지 확인하세요.

![봇 테스트 패널에 표시된 고객 질문과 Conversation AI 답변](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039825197/original/tGYCZueYj8SRwiF0TGF7AQAyY6F7HNGX4Q.gif?1736873045=)

봇을 출시한 뒤에는 **대화**에서 지원되는 AI 메시지 옆의 **Response Info**(응답 정보)를 사용해 어떤 지식 베이스 소스가 응답에 쓰였는지 확인할 수 있어요.

## 봇 답변을 개선하는 방법

느슨하게 관련된 정보를 많이 모으는 것보다, 주제가 분명하고 명확하게 쓴 콘텐츠가 더 유용해요.

- 고객에게 보여 줄 콘텐츠를 우선하세요. 고객이 물어볼 만한 정보를 학습시키세요.
- 제목을 명확히 쓰세요. 문서와 리치 텍스트를 주제별로 정리하세요.
- 답을 직접적으로 쓰세요. 정책, 가격, 한도, 안내를 분명하게 적으세요.
- 중복을 없애세요. 같은 정보의 서로 다른 버전이 있으면 답변 품질이 떨어질 수 있어요.
- 데이터에 맞는 소스를 쓰세요. 구조화된 정보는 테이블, 직접 답할 내용은 자주 묻는 질문을 사용하세요.
- 큰 업데이트 후에는 테스트하세요. 실제 대화에서 소스를 쓰기 전에 검색이 잘 되는지 확인하세요.

## 자주 묻는 질문

### 어떤 소스 유형을 써야 하나요?
공개 웹사이트 콘텐츠는 웹 크롤러, 직접 답할 내용은 자주 묻는 질문, 직접 관리하는 정보는 리치 텍스트, 문서는 파일 업로드, 구조화된 데이터는 테이블을 쓰세요.

### 지식 베이스 하나에 여러 소스 유형을 담을 수 있나요?
네. 지식 베이스 하나에 웹사이트, 자주 묻는 질문, 리치 텍스트, 파일, 테이블 등 지원되는 소스를 함께 담을 수 있어요.

### 웹사이트 전체를 봇에 학습시켜야 하나요?
대부분의 페이지가 고객 대화와 관련 있을 때만 그렇게 하세요. 큰 사이트에서는 관련 없는 영역까지 학습시키는 것보다 필요한 페이지만 학습시키는 편이 대체로 더 깔끔한 결과가 나와요.

### Google Docs를 쓸 수 있나요?
네. Google Drive 연동으로 지원되는 파일을 가져오거나, 웹 크롤러 화면에서 누구나 볼 수 있는 Google Docs 문서 URL을 사용하세요.

### 새로 추가한 소스를 봇이 사용하지 않아요
처리가 끝났는지, 소스 상태가 성공으로 표시되는지, 올바른 지식 베이스가 봇에 연결되어 있는지 확인하세요. **Knowledge Base Retrieval Tester**로 해당 정보를 찾을 수 있는지도 확인해 보세요.

### 학습 소스는 얼마나 자주 업데이트해야 하나요?
비즈니스 정보가 바뀔 때마다 업데이트하세요. 자주 바뀌는 웹 페이지에는 예약된 **Auto Refresh**를 사용하고, Google Drive 파일은 필요할 때 직접 다시 동기화하세요.

### 봇이 서로 충돌하거나 오래된 답변을 해요
중복되거나 겹치거나 오래된 소스가 없는지 찾아보세요. 잘못된 버전을 제거하거나 업데이트한 뒤 지식 베이스와 봇을 다시 테스트하세요.

### 지식 베이스 테스트와 봇 테스트는 같은가요?
아니요. **Knowledge Base Retrieval Tester**는 소스 콘텐츠를 찾을 수 있는지 확인해요. 봇 테스트는 지침, 목표, 액션, 응답 방식까지 포함한 전체 대화 경험을 확인해요.
