# 웹 URL과 링크로 대화 AI 학습시키기

웹사이트 페이지를 지식 베이스에 추가해 대화 AI를 학습시키는 방법을 안내해요. 하이퍼클래스가 선택한 URL의 페이지 내용을 읽어 와서 학습 자료로 쓰기 때문에, 봇이 고객 질문에 더 정확하고 관련 있는 정보로 답할 수 있어요.

### 

## 웹 URL과 링크란?

서비스 안내, 가격 페이지, 자주 묻는 질문, 정책, 블로그, 지원 문서처럼 유용한 정보가 이미 웹사이트에 있다면 웹 URL과 링크 기능을 쓰세요. 내용을 지식 베이스에 일일이 복사하지 않아도 돼요. 페이지 하나, 여러 페이지, 또는 도메인 전체를 크롤링한 뒤 학습에 쓸 URL만 골라 추가할 수 있어요.

```
하이퍼클래스는 정확한 URL, All URLs in this Domain, All URLs with this Path 등 여러 가지 URL 크롤링 방식을 지원해요. 지식 베이스 하나에서 최대 4,000개의 웹 URL을 학습시킬 수 있어요.
```

---

## 웹 URL과 링크의 장점

웹사이트 URL로 대화 AI를 학습시키면, 이미 공개된 웹 콘텐츠를 고객 대화의 믿을 만한 자료로 쓸 수 있어요. URL을 잘 고르면 답변 품질이 좋아지고, 설정 작업이 줄고, 지식 베이스가 고객이 온라인에서 보는 정보와 같은 내용으로 유지돼요.

- 더 빠른 봇 학습: 답변을 하나하나 다시 만들지 않고 웹사이트 내용을 지식 베이스에 바로 추가해요.
- 더 정확한 답변: 승인된 웹사이트 페이지로 봇을 학습시키면 비즈니스 정보에 맞는 답변을 얻을 수 있어요.
- 유연한 크롤링 옵션: 정확히 한 페이지, 도메인 전체, 특정 URL 경로가 같은 페이지 중에서 고를 수 있어요.
- 더 나은 콘텐츠 관리: 크롤링된 URL을 학습 전에 확인해서 필요한 페이지만 추가해요.
- 간편한 링크 관리: 웹사이트 내용이 바뀌면 **업로드된 링크** 표에서 학습된 URL을 새로 고치거나 **삭제**할 수 있어요.

---

## URL 크롤링 방식

크롤링 방식은 하이퍼클래스가 지식 베이스에 추가하기 전에 웹사이트 페이지를 얼마나 넓게 찾을지 정해요. 알맞은 방식을 고르면 관련 없는 내용이 학습되는 것을 막고, 대화 AI가 참고할 내용을 더 잘 관리할 수 있어요.

### 정확한 URL

특정 웹페이지 하나만 학습시키고 싶을 때는 **정확한 URL**이 가장 좋아요. 입력한 URL 하나만 크롤링하기 때문에, 정밀하게 학습시키고 싶을 때 권장하는 방식이에요.

**정확한 URL**은 다음과 같은 페이지에 쓰세요.

- 가격 페이지
- 자주 묻는 질문 페이지
- 서비스 페이지
- 환불 또는 취소 정책 페이지
- 랜딩 페이지 한 개

```
예시:
https://example.com/services 를 입력하면 해당 페이지 하나만 크롤링하고 학습해요.
```

---

### All URLs in this Domain

웹사이트 대부분의 페이지가 봇 학습에 도움이 될 때는 **All URLs in this Domain**(이 도메인의 모든 URL)이 알맞아요. 하이퍼클래스가 도메인을 크롤링해서 찾은 URL 목록을 보여 주면, 학습할 페이지를 직접 고를 수 있어요.

다음과 같은 경우에 이 방식을 쓰세요.

- 웹사이트 전체에 유용한 비즈니스 정보가 들어 있어요.
- 학습 전에 여러 웹사이트 페이지를 훑어보고 싶어요.
- 서비스, 상품, 지원 페이지가 여러 개 있고 모두 포함하고 싶어요.

하이퍼클래스가 URL을 가져오면 목록을 꼼꼼히 확인한 뒤 페이지를 선택하고 **봇 학습**을 클릭하세요. 관련 없는 페이지까지 학습하면 답변 품질이 떨어질 수 있어요.

---

### All URLs with this Path

웹사이트의 특정 섹션만 크롤링하고 싶을 때는 **All URLs with this Path**(이 경로의 모든 URL)가 알맞아요. 하이퍼클래스가 URL에 해당 경로가 들어 있는 페이지를 찾아 주고, 그중 학습할 페이지를 직접 고를 수 있어요.

유용한 콘텐츠가 다음과 같은 공통 경로 아래에 모여 있을 때 이 방식을 쓰세요.

- /services
- /blog
- /help
- /support
- /locations

```
예시:

https://example.com/services 를 입력하면 하이퍼클래스가 해당 경로 아래의 다음과 같은 페이지를 찾아 줘요.

https://example.com/services/seo
https://example.com/services/web-design
https://example.com/services/consulting
```

이렇게 하면 관련 없는 웹사이트 영역은 건너뛰면서, 같은 콘텐츠 분류의 여러 페이지를 한 번에 모을 수 있어요.

---

## 신규 페이지와 기존 페이지

가져온 URL 결과는 두 그룹으로 나뉘어요. 지식 베이스에 처음 들어오는 페이지와 이미 학습된 페이지를 구분해 주기 때문에, 학습 전에 두 그룹을 모두 확인하면 헷갈리지 않고 URL 학습을 정리해서 진행할 수 있어요.

- **New Pages**(신규 페이지): 크롤링 중에 찾았지만 아직 지식 베이스에 없는 URL이에요. 이 페이지를 선택하면 학습이 끝난 뒤 **업로드된 링크** 표에 추가돼요.
- **Existing Pages**(기존 페이지): 이미 지식 베이스에 포함되어 **업로드된 링크** 표에 보이는 URL이에요. 기존 페이지를 선택하면 학습된 내용이 새로 고쳐져요.

새로운 내용을 추가할 때는 **New Pages**를 쓰세요. 이미 추가했지만 마지막 새로고침 이후 바뀌었을 수 있는 페이지를 다시 학습시키려면 **Existing Pages**를 쓰세요.

---

## URL 학습 모범 사례

깔끔하고 관련성 높은 학습 데이터가 있어야 대화 AI가 더 나은 답변을 해요. URL을 추가하기 전에 웹사이트 내용을 살펴보고, 고객이 물어볼 만한 질문에 바로 도움이 되는 페이지를 고르세요.

권장 사항은 다음과 같아요.

- 정확하고 최신이며 고객에게 보여 주는 정보가 담긴 페이지를 학습시키세요.
- 봇에 필요한 정보가 아니라면 관련 없는 페이지는 피하세요.
- 가능하면 중복되거나 가치가 낮은 페이지는 피하세요.
- **봇 학습**을 클릭하기 전에 크롤링된 URL을 확인하세요.
- 정밀하게 학습시키려면 **정확한 URL**을 쓰세요.
- 웹사이트의 한 섹션만 필요하면 경로 크롤링을 쓰세요.
- 웹사이트 내용이 오래되면 학습된 링크를 새로 고치거나 삭제하세요.
- 선택한 URL이 모두 학습을 마칠 때까지 기다린 뒤 봇을 테스트하거나 사용하세요.

---

## 웹 URL과 링크 설정하기

설정을 제대로 해 두면 대화 AI가 알맞은 웹사이트 콘텐츠로 학습되고, 불필요하거나 오래된 페이지는 빠져요. 아래 순서대로 URL을 크롤링하고, 관련 있는 페이지를 골라 지식 베이스에 추가하세요.

1. **봇 학습**으로 이동하세요.

   ![봇 학습 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072718765/original/sSU7YsGun-_dPWhykwGAelVK2J1edwsEew.png?1780407861)
2. `https://`를 포함한 전체 URL을 입력하세요.
3. 사용할 수 있는 크롤링 방식 중 하나를 선택하세요.
   - **정확한 URL**
   - **All URLs in this Domain**
   - **All URLs with this Path**

   ![크롤링 방식 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072720787/original/0mdKyJjhUD7tSClp897nUTmtqQjFa_w0Hg.png?1780408846)
4. **Get Data**(데이터 가져오기)를 클릭하세요.

   ![데이터 가져오기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072720848/original/gsJ-2H2Demumb7rKDbxD6bHJJuku48drHA.png?1780408882)
5. 하이퍼클래스가 사용할 수 있는 URL을 가져와 크롤링할 때까지 기다리세요.
6. 가져온 URL을 확인하세요.
7. 학습에 쓸 URL을 선택하세요.
8. **봇 학습**을 클릭하세요.
9. 선택한 URL이 **업로드된 링크** 표에 나타날 때까지 기다리세요.
10. 봇을 사용하거나 테스트하기 전에 각 URL의 학습이 끝났는지 확인하세요.

## URL 학습 상태

학습 상태를 보면 URL이 아직 처리 중인지, 학습에 성공했는지, 확인이 필요한지 알 수 있어요. 봇을 테스트하기 전에 상태를 확인해서 지식 베이스를 쓸 준비가 됐는지 살펴보세요.

- **데이터 가져오는 중**: 하이퍼클래스가 URL을 처리하거나 새로 고치는 중이에요.
- **학습됨**: URL이 성공적으로 학습되어 지식 베이스에 추가됐어요.
- **실패**: 하이퍼클래스가 URL을 학습하지 못했어요. URL을 새로 고쳐 보세요. 더 이상 필요 없다면 삭제하세요.

URL이 실패하면 페이지에 접근할 수 있는지, 관련 있는 내용인지, 크롤링할 수 있는 형식인지 확인하세요. 그런 다음 링크를 새로 고치거나 학습을 다시 시도하세요.

---

## 자주 묻는 질문

### 웹사이트 전체를 학습시켜야 하나요?
대부분의 페이지가 고객 대화에 유용할 때만 도메인 전체를 학습시키세요. 더 정확한 답변을 원한다면 가장 관련 있는 페이지만 고르고, 관련 없거나 오래된 내용은 빼세요.

### 정확한 URL, 도메인, 경로 크롤링은 뭐가 다른가요?
**정확한 URL**은 특정 페이지 하나를 학습시켜요. 도메인 크롤링은 웹사이트 도메인 전체에서 페이지를 찾아요. 경로 크롤링은 `/services`나 `/help`처럼 특정 URL 경로가 같은 페이지를 찾아요.

### 웹사이트가 바뀌면 학습된 URL을 새로 고칠 수 있나요?
네. **업로드된 링크** 표에서 새로고침을 사용하면 최신 페이지 내용으로 URL을 다시 학습시킬 수 있어요.

### 학습된 URL을 삭제할 수 있나요?
네. URL을 삭제하면 그 페이지에서 학습된 내용이 지식 베이스에서 제거돼요.

### URL을 가져왔더니 Existing Pages가 보이는 이유가 뭐예요?
**Existing Pages**(기존 페이지)는 이미 지식 베이스에 포함된 URL이에요. 선택하면 새 페이지로 추가되지 않고, 학습된 내용이 새로 고쳐져요.

### URL 학습이 실패하면 어떻게 하나요?
페이지에 접근할 수 있는지, 아직 필요한 페이지인지 확인하세요. 그런 다음 새로 고쳐 보세요. URL이 유용하지 않거나 처리할 수 없다면 **업로드된 링크** 표에서 삭제하세요.

### 지식 베이스 하나에 웹 URL을 몇 개까지 학습시킬 수 있나요?
지식 베이스 하나에 최대 4,000개의 웹 URL을 학습시킬 수 있어요.

### 웹 URL과 링크를 다른 지식 베이스 소스와 함께 쓸 수 있나요?
네. 웹 URL은 지식 베이스 소스 유형 중 하나예요. 하이퍼클래스는 대화 AI 지식 베이스에서 다른 소스 유형도 지원해요.
