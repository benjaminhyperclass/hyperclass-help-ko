# 대화 AI에서 지식 베이스 트리거 사용하기

지식 베이스 트리거를 쓰면 대화 중에 대화 AI가 어떤 지식 베이스 내용을 사용할지 직접 정할 수 있어요. 이 문서에서는 Always-On 트리거와 스마트 트리거의 차이, 지식 베이스를 나누는 방법, 트리거 조건을 쓰는 방법을 안내해요. 설정부터 테스트까지 따라 하면 더 알맞은 답변을 보내 영업과 고객 응대 성과를 높일 수 있어요.

## 지식 베이스 트리거란?

**지식 베이스 트리거**(Knowledge Base Triggers)를 쓰면 대화 중 어느 시점에 어떤 **지식 베이스** 내용을 사용할지 정할 수 있어요. AI의 판단에만 맡기지 않고 트리거 조건을 정해 두면, 중요한 순간에 가장 알맞은 내용이 나와요.

대화 AI 에이전트마다 다음 트리거가 있어요.

- 일반 지식용 **Always-On**(항상 켜짐) 트리거 1개
- 조건에 따라 작동하는 **Smart Triggers**(스마트 트리거) 최대 3개

중요한 순간에는 내가 정한 조건이 작동하고, 그 밖의 대화에서는 AI가 평소처럼 자연스럽게 답해요.

### 스마트 지식 베이스 트리거와 안내 지침의 장점

- 전환율 높이기: 알맞은 때에 혜택, 사례, 가격을 보여 줘요.
- 답변 정확도 높이기: 꼭 필요한 내용이 필요한 때에 쓰이도록 해요.
- 놓치는 기회 줄이기: 구매 신호에 자동으로 응답해요.
- 더 세밀하게 제어하기: 영향이 큰 상황에서 AI가 어떻게 행동할지 안내해요.
- 콘텐츠 활용 늘리기: 트리거 하나에 여러 지식 베이스를 연결해 체계적으로 관리해요.

## Always-On 트리거

Always-On 트리거에는 모든 대화에서 쓸 수 있어야 하는 기본 정보를 넣어요. 에이전트의 기본 지식이라고 보면 돼요.

- 브랜드 메시지와 포지셔닝
- 일반 혜택과 가격대
- 운영시간과 연락처
- 자주 나오는 질문과 정책

스마트 트리거 조건에 맞는 경우가 없으면, Always-On 트리거가 계속 답변에 쓰여요.

## 스마트 트리거

스마트 트리거는 대화에서 정해 둔 조건이 충족되면 작동해요. 이때 AI는 상황에 맞는 내용으로 답할 수 있어요.

에이전트마다 Always-On 트리거 외에 스마트 트리거를 최대 3개까지 쓸 수 있어요.

### 활용 예시

부동산

- 조건: 예산, 지역, 선호 조건을 모두 알려 준 뒤
- 동작: 알맞은 매물 목록을 보여 줘요

고가 상품 판매

- 조건: 고객이 이의를 제기하거나 망설일 때
- 동작: 관련 사례를 공유해요

### 트리거 조건을 잘 쓰는 방법

- 분명하고 자연스러운 문장으로 써요.
- 상담 자격 확인 완료, 이의 제기처럼 구체적인 순간에 집중해요.
- 조건끼리 겹치지 않게 해요.
- 트리거마다 관련 있는 지식 베이스만 연결해요.

## 트리거의 한도와 지식 베이스 구성

- 트리거는 최대 4개예요(Always-On 트리거 1개 + 스마트 트리거 3개).
- 트리거 하나에 지식 베이스를 최대 7개까지 연결할 수 있어요.

### 지식 베이스 구성 방법

다음 주제별로 지식 베이스를 따로 만들어 두세요.

- 일반 자주 묻는 질문
- 상품 또는 서비스 정보
- 사례와 후기
- 정책과 규정 준수
- 온보딩 또는 도입 가이드

연결 기준은 다음과 같아요.

- 폭넓은 내용 → Always-On 트리거
- 구체적인 내용 → 스마트 트리거

이렇게 나누면 답변이 더 정확해지고 관리도 쉬워져요.

## 트리거 구성 모범 사례

- 대화 단계별로 트리거를 설계해요.
- 트리거 하나에는 목적 하나만 담아요.
- 한 트리거에 지식 베이스를 너무 많이 넣지 않아요.
- 정기적으로 테스트하고 다듬어요.
- 트리거 이름은 알아보기 쉽게 일정한 규칙으로 지어요.

## 스마트 지식 베이스 트리거 설정하기

### 1단계: 봇 학습 열기

1. **AI 에이전트 > 대화 AI**로 이동해요.
2. 설정할 에이전트를 선택해요.
3. **봇 학습** 탭을 열어요.

![봇 학습 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070237900/original/SkW66ohKlPOv0Cjnjc3me58qFzxLlaURFg.png?1777476980)

### 2단계: Always-On 트리거 설정하기

1. 일반 내용의 지식 베이스가 연결되어 있는지 확인해요.
2. 너무 구체적인 내용은 빼요.
3. **변경사항 저장**을 클릭해요.

![Always-On 트리거 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070238429/original/1HKptsYvYxDw1dYyzQI3GiSPoMeQqkFhmg.png?1777477272)

### 3단계: 스마트 트리거 만들기

1. **트리거 추가**를 클릭해요.
2. **트리거 이름**에 알아보기 쉬운 이름을 입력해요.
3. 조건을 평소 쓰는 말로 쉽게 써요.

![트리거 추가 과정 애니메이션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070303433/original/eXZjRu1vIqJWR0O1oQUoAOIbf8mqqcrzVw.gif?1777547643)

![스마트 트리거 조건 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070302805/original/-alV0cz1OTykrlPkn8xEKr4cEUyFlnMmwA.png?1777547342)

### 4단계: 지식 베이스 연결하기

1. 관련 있는 지식 베이스를 선택해요(최대 7개).
2. 트리거의 목적에 맞는 내용만 남겨요.
3. **저장**을 클릭해요.

### 5단계: 미리보기에서 테스트하기

1. **미리보기**에서 실제 대화처럼 시험해 봐요.
2. 트리거가 알맞은 때에 작동하는지 확인해요.
3. 어떤 지식 베이스가 쓰였는지 확인해요.
4. 필요하면 조건을 고쳐요.

### 6단계: 트리거 더 추가하기

1. 스마트 트리거를 최대 3개까지 만들어요.
2. 다음과 같이 서로 다른 단계를 나눠서 맡겨요.
   - 상담 자격 확인
   - 이의 제기
   - 가격 안내
   - 예약

## 자주 묻는 질문

### 스마트 트리거를 꼭 설정해야 하나요?

아니요. 트리거를 설정하지 않으면 AI는 평소처럼 작동해요.

### 어떤 트리거도 작동하지 않으면 어떻게 되나요?

Always-On 트리거가 답변을 맡아요.

### 지식 베이스는 몇 개까지 쓸 수 있나요?

트리거 하나에 최대 7개까지 쓸 수 있어요.

### 트리거는 누가 설정할 수 있나요?

대화 AI 학습 권한이 있는 사용자가 설정할 수 있어요.

### 효과적인 조건은 어떻게 쓰나요?

특정한 순간에 초점을 맞춰 분명하고 자연스러운 문장으로 쓰세요.

### 스마트 트리거를 음성 AI나 워크플로우에서도 쓸 수 있나요?

스마트 트리거는 대화 AI의 동작에 맞게 만들어진 기능이에요.
