# 대화 AI 지식 소스 추가와 답변 품질 개선

하이퍼클래스의 대화 AI에 추가된 지식 소스와 검색 품질 개선 기능을 안내해요. 테이블, 리치 텍스트, 파일 업로드와 개선된 검색 과정을 활용하면 AI 에이전트가 더 정확하고 상황에 맞는 답변을 많은 대화에서 안정적으로 할 수 있어요.

## 새 지식 소스 지원이란?

하이퍼클래스 **지식 베이스**(Knowledge Base)는 여러 가지 소스 유형을 지원해요. **테이블**, **리치 텍스트**, **파일 업로드**, **자주 묻는 질문**, **Web Crawler**(웹 크롤러), **Web Search**(웹 검색)가 있어요. 대화 AI는 답변을 만들기 전에 이 소스에서 관련 정보를 찾아요. 재순위화를 포함한 검색 개선 덕분에 가장 관련성 높은 청크가 먼저 선택되어, 답변이 더 정확해지고 검토하기도 쉬워져요.

---

## 지식 소스 지원과 품질 개선의 장점

- 답변 정확도 향상: 자동 재순위화가 답변을 만들기 전에 가장 관련성 높은 정보를 먼저 찾아 줘요.
- 빠른 적용: 처음부터 다시 학습시킬 필요 없이 데이터 소스를 바로 추가하거나 교체할 수 있어요.
- 유연한 학습: 스프레드시트, 리치 텍스트 문서, PDF 등을 지원해서 AI가 학습할 수 있는 자료가 넓어져요.
- 투명한 출처 확인: 모든 답변의 **AI 응답 정보** 사이드 패널에서 클릭할 수 있는 출처 링크를 볼 수 있어요.

---

## 재순위화로 더 정확해진 검색

이제 검색과 답변 생성 사이에 가벼운 순위 매김 단계가 있어요. 먼저 벡터 검색이 답변 후보를 찾아오면, 재순위화 단계에서 각 청크가 사용자 질문과 의미상 얼마나 가까운지 점수를 매겨요. 그리고 순위가 높은 구절만 LLM에 보내요. 그 결과 잘못된 답변(환각)이 줄고, 질문에 맞는 간결한 답변을 받을 수 있어요.

---

## 지원하는 데이터 유형

지식 베이스에는 다음과 같은 소스 유형을 넣을 수 있어요.

- **테이블**: CSV 파일을 업로드하면 AI가 가격표, 상품 목록, 고객 기록, 서비스 정보 같은 정형 데이터를 참고할 수 있어요.
- **리치 텍스트**: 문서, 정책, 안내문, 자주 묻는 질문 등을 편집기에 직접 입력해서 추가해요.
- **파일 업로드**: DOC, DOCX, PDF 같은 문서 파일을 업로드해요. 텍스트만 추출해서 색인하고, 파일에 포함된 이미지는 건너뛰어요.
- **Web Crawler**(웹 크롤러), **자주 묻는 질문**, **Web Search**(웹 검색): AI가 웹사이트 내용, 질문과 답변 형식의 내용, 웹 기반 정보를 참고하게 하려면 이 소스 유형을 써요.

---

## 명확한 출처 확인

**대화** 안의 모든 AI 응답에는 **AI 응답 정보** 아이콘이 표시돼요. 아이콘을 클릭하면 사이드 패널이 열리고 다음 내용을 확인할 수 있어요.

- 답변에 사용된 지식 청크
- 파일 또는 URL 이름, 자주 묻는 질문 레이블, 시간 정보
- 출처를 바로 수정하거나 교체할 수 있는 빠른 편집 옵션

## 지식 소스 설정하고 사용하기

### 1단계: 지식 베이스 만들기 또는 열기

1. 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **AI 에이전트** 탭을 클릭하세요.

   ![AI 에이전트 탭](https://jumpshare.com/share/xKUFkN6npwAxq0NBGb1O+/Screen+Shot+2025-10-03+at+5.44.29+PM.png)
3. **지식 베이스** 탭을 클릭하세요.

   ![지식 베이스 탭](https://jumpshare.com/share/gwW1qOgBvn3BuGjyhDnq+/Screen+Shot+2025-10-03+at+5.45.58+PM.png)
4. 새로 만들려면 **+ 지식 베이스 만들기** 버튼을 클릭하세요.

   ![지식 베이스 만들기 버튼](https://jumpshare.com/share/vu9ydypMMgBizdLzPptv+/Screen+Shot+2025-10-03+at+5.47.41+PM.png)
5. 기존 지식 베이스를 편집하려면 지식 베이스 이름을 클릭하거나, 점 세 개 메뉴를 열어 **편집**을 선택하세요.

   ![기존 지식 베이스 편집](https://jumpshare.com/share/vF9mMFEswDPVZ1BLJGI7+/Screen+Shot+2025-10-03+at+5.49.25+PM.png)

### 2단계: 지식 소스 추가하기

1. **+ Add Source**(소스 추가) 버튼을 클릭하세요.
2. AI가 사용하게 할 지식 베이스 내용에 맞춰 추가할 소스 유형을 선택하세요. **테이블**, **리치 텍스트**, **파일 업로드**, **자주 묻는 질문**, **Web Crawler**, **Web Search** 중에서 고를 수 있어요.
3. **테이블**과 파일을 업로드하거나 **리치 텍스트**를 추가하세요.

   ![소스 추가 과정](https://jumpshare.com/share/9lbg7UkhUECFSbkoFgnp+/GIF+Recording+2025-10-03+at+5.51.27+PM.gif)

### 3단계: Conversation AI 봇에 지식 베이스 연결하기

1. **AI 에이전트**에서 **대화 AI**를 클릭하세요.
2. **에이전트 목록** 탭을 클릭하세요.

   ![에이전트 목록 탭](https://jumpshare.com/share/7Yq8N30lXw3Ra3HgWwnA+/Screen+Shot+2025-10-03+at+5.57.01+PM.png)
3. 새 봇을 만들려면 **+ 봇 만들기**를 클릭하세요. 자세한 방법은 Setting Up Conversation AI 문서를 참고하세요.

   ![봇 만들기 버튼](https://jumpshare.com/share/i4OFgz9pOUOj6QGDzF3C+/Screen+Shot+2025-10-03+at+6.00.36+PM.png)
4. 기존 봇을 편집하려면 봇 이름을 클릭하거나, 점 세 개 메뉴를 열어 **편집**을 선택하세요.

   ![기존 봇 편집](https://jumpshare.com/share/gAWYl39WHZ7u5kGdJVUT+/Screen+Shot+2025-10-03+at+6.01.35+PM.png)
5. **봇 학습** 탭을 클릭하세요.
6. **지식 베이스**에서 방금 만들거나 업데이트한 지식 베이스를 선택하세요. 새로 추가한 리치 텍스트, 테이블, 파일 소스도 함께 연결돼요.

   ![지식 베이스 선택](https://jumpshare.com/share/gBFRJrm2iZ5xxiGxKRvQ+/GIF+Recording+2025-10-03+at+6.06.29+PM.gifhttps://jumpshare.com/share/gBFRJrm2iZ5xxiGxKRvQ+/GIF+Recording+2025-10-03+at+6.06.29+PM.gif)

### 4단계: 지식 베이스 검색 테스트하기

1. **AI 에이전트 > 지식 베이스**로 이동해서 테스트할 지식 베이스를 여세요.
2. 새로 추가하거나 업데이트한 내용의 처리와 색인이 끝날 때까지 기다리세요.
3. **Knowledge Base Retrieval Tester**(지식 베이스 검색 테스터)를 여세요.
4. 실제 고객이 물어볼 법한 질문을 입력하세요.
5. 답변과 검색된 소스를 확인하세요.
6. 소스가 없거나, 내용이 부족하거나, 오래됐거나, 관련이 없다면 지식 베이스를 수정하세요.
7. 같은 질문으로 다시 테스트해서 올바른 내용이 검색되는지 확인하세요.
8. 검색 결과가 올바르면 봇 테스트 창에서 Conversation AI 봇의 전체 동작도 테스트하세요.

   ![지식 베이스 검색 테스트](https://jumpshare.com/share/O54smx8AAimKSN23CJUp+/Screen+Shot+2025-10-03+at+6.26.05+PM.png)

### 5단계: 답변에 사용된 지식 청크 확인하기

1. 서브 계정에서 **대화**로 이동하세요.
2. Conversation AI 봇이 답변을 남긴 대화를 여세요.
3. 해당 AI 메시지 옆의 **AI 응답 정보** 버튼을 클릭하세요.

   ![AI 응답 정보 버튼](https://jumpshare.com/share/Yz0eU8MG6IMNk66ionlP+/Screen+Shot+2025-10-03+at+6.31.47+PM.png)
4. **지식 청크**를 열면 해당 답변에 사용된 청크를 최대 세 개까지 볼 수 있어요.

   ![지식 청크 확인](https://jumpshare.com/share/DrYl5yFdACC92Gkv9yVg+/Screen+Shot+2025-10-03+at+6.34.44+PM.png)

## 자주 묻는 질문

### 파일, 테이블 등 지식 베이스 소스를 추가한 뒤에 봇을 다시 학습시켜야 하나요?

아니요. 소스를 저장하고 처리와 색인이 끝나면 지식 베이스가 업데이트된 내용을 검색할 수 있어요. 더 확실하게 하려면 실제 대화에서 쓰기 전에 Knowledge Base Retrieval Tester(지식 베이스 검색 테스터)로 새 소스가 검색되는지 확인하세요.

### 어떤 파일 형식을 지원하나요?

PDF, DOC/DOCX, PPT/PPTX, TXT, CSV(테이블용)를 지원해요.

### 테이블에서 처리할 수 있는 최대 열 개수는 얼마인가요?

최대 500개 열이 있는 CSV 파일을 가져온 뒤, 가장 관련 있는 열 20개를 선택하세요.

### 하나의 지식 베이스에 테이블, 리치 텍스트, URL을 함께 넣을 수 있나요?

네, 가능해요. 검색 과정에서는 모든 청크를 동일하게 취급한 다음, 가장 잘 맞는 순서로 다시 순위를 매겨요.
