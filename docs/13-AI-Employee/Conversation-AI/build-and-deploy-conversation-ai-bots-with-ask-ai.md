# AI에게 문의로 대화 AI 봇 만들고 배포하기

**AI에게 문의**(Ask AI)를 쓰면 우리 비즈니스의 통화, 이메일, SMS, 소셜 메시지, 실시간 채팅 방식을 반영한 대화 AI 봇을 만들 수 있어요. 봇을 만든 뒤에는 서브 계정에서 대화 AI의 **Channel Management**(채널 관리)가 켜져 있는지에 따라 알맞은 배포 방식을 자동으로 선택해요. 채널마다 봇을 직접 배정하지 않아도, 브랜드에 맞는 봇이 적용 가능한 채널에 배치돼요.

## AI에게 문의로 대화 AI 봇 만들기란?

AI에게 문의로 대화 AI 봇을 만드는 기능은, 자연어로 요청하면 설정이 끝난 대화 AI 봇을 만들어 주는 안내형 워크플로우이에요. AI에게 문의가 사용할 수 있는 대화 기록을 살펴보고 비즈니스의 소통 방식을 파악해요. 그 패턴으로 봇의 어조, 스타일, 질문 방식을 잡아요.

AI에게 문의는 다음과 같은 여러 소스의 소통 내용을 살펴볼 수 있어요.

- 음성 통화 녹취록
- 전체 이메일 스레드
- SMS 대화
- 소셜 대화
- 실시간 채팅 대화

여러 소스를 함께 쓰면 고객이 비즈니스와 소통하는 여러 채널에서 새 봇이 더 일관되게 대화할 수 있어요. 봇을 만든 뒤에는 서브 계정의 대화 AI **Channel Management** 설정에 맞춰 배포해요.

---

## AI에게 문의로 봇을 만들 때의 장점

AI에게 문의는 대화 분석, 봇 설정, 배포를 한 번의 워크플로우으로 묶어서 효과적인 봇을 만드는 수고를 줄여 줘요. 이렇게 만든 봇은 비즈니스가 평소 리드와 고객에게 말하던 방식을 바탕으로 시작해요.

- 일관된 브랜드 커뮤니케이션: 봇의 어조와 스타일이 사용 가능한 소통 소스의 실제 대화를 기반으로 만들어져요.
- 더 넓은 대화 분석: SMS, 소셜 메시지, 실시간 채팅뿐 아니라 통화와 이메일 스레드에서도 학습할 수 있어요.
- 빠른 봇 생성: 모든 설정을 직접 입력하지 않아도, 자연어 요청 하나로 봇 만들기를 시작할 수 있어요.
- 자동 배포: **Channel Management**가 켜져 있는지 확인하고 알맞은 배포 방식을 사용해요.
- 기존 봇 배정 보호: **Channel Management**가 켜져 있으면, 이미 다른 봇이 맡고 있는 경로는 새 봇이 가져가지 않아요.
- 명확한 배포 결과: 완료 메시지에 봇이 배포된 위치가 나오고, 선택했지만 건너뛴 채널이 있으면 그 이유도 알려 줘요.
- 생성 후 정리 작업 감소: 요청 한 번으로 봇을 만들고 배정까지 마치므로, 설정 후 직접 손봐야 할 부분이 줄어요.

---

## AI에게 문의가 봇의 말투를 만드는 방식

봇의 말투는 리드와 고객에게 얼마나 자연스럽고 일관되게 소통하는지에 영향을 줘요. AI에게 문의는 사용할 수 있는 과거 대화를 분석해서 비즈니스가 쓰는 표현, 어조, 스타일, 자주 나오는 질문의 패턴을 찾아내요.

AI에게 문의는 다음 소스의 대화 기록을 활용할 수 있어요.

- 음성 통화 녹취록
- 이메일 대화와 전체 스레드
- SMS 메시지
- 소셜 메시지 채널
- 실시간 채팅 대화

이렇게 폭넓게 분석하면 텍스트 채팅이나 SMS에만 의존하지 않고, 상황별로 비즈니스가 소통하는 방식을 봇에 반영할 수 있어요.

예를 들어 대화 기록을 보고 비즈니스에서 다음 중 무엇을 자주 쓰는지 파악할 수 있어요.

- 친근한 어조 또는 전문적인 어조
- 짧은 답변 또는 자세한 답변
- 특정 인사말이나 마무리 표현
- 상담형 질문
- 자격 확인 질문
- 예약 중심의 표현
- 격식 있는 표현 또는 대화체 표현

봇을 만든 뒤에는 생성된 말투가 비즈니스의 현재 소통 기준에 맞는지 꼭 확인하세요. 어조, 행동, 질문 방식, 응답 기대치를 다듬으려면 대화 AI 프롬프트와 지침을 수정하면 돼요.

{% hint style="warning" %}
봇의 말투와 봇이 아는 사실은 서로 달라요. 대화 기록은 AI에게 문의가 봇의 소통 방식을 만드는 데 도움을 줘요. 비즈니스에 관한 질문에 정확히 답하려면 **봇 학습**과 연결된 지식 베이스가 필요해요.
{% endhint %}

---

## 봇 말투와 봇 학습의 차이

소통 스타일과 사실 지식은 쓰임이 달라요. 이 차이를 알아 두면 AI에게 문의가 봇을 만든 뒤 어떤 설정을 확인해야 할지 알 수 있어요.

- 봇 말투는 어조, 표현, 성격, 질문 방식처럼 봇이 어떻게 소통하는지를 정해요.
- **봇 학습**은 서비스, 가격, 정책, 안내 사항처럼 봇이 고객 질문에 답할 때 쓸 정보를 제공해요.
- **Bot Goals**(봇 목표)는 연락처 정보 수집, 예약 잡기, 워크플로우 실행처럼 봇이 달성해야 할 일을 정해요.

대화 AI의 **봇 학습**에서는 웹사이트 콘텐츠와 **Custom Bot Responses**(맞춤 봇 응답) 같은 소스를 활용해 답변 정확도를 높일 수 있어요. **Bot Goals**에서는 에이전트의 성격, 의도, 보조 지침, 사용할 수 있는 액션을 정할 수 있어요.

---

## 시작하기 전에

봇을 잘 만들려면 쓸 만한 대화 기록, 연결된 소통 채널, 그리고 필요한 하이퍼클래스 기능을 사용할 수 있어야 해요. 서브 계정을 먼저 점검해 두면 AI에게 문의가 봇을 만들고 배포할 때 건너뛰는 배정이 줄어들어요.

시작하기 전에 다음을 확인하세요.

- **AI에게 문의**를 사용할 수 있는지 확인해요.
- 대화 AI 봇을 만들고 관리할 수 있는 권한이 있는지 확인해요.
- 서브 계정의 기존 대화 기록을 살펴봐요.
- 통화가 봇의 말투에 반영되길 원한다면 음성 통화 녹취록이 있는지 확인해요.
- 필요한 전화번호, 페이지, 계정, 실시간 채팅이 연결되어 있는지 확인해요.
- 기존 봇 배정을 확인해요.
- 대화 AI의 **Channel Management**가 켜져 있는지 확인해요.
- 새 봇이 사용할 채널을 정해요.
- 봇의 목적을 명확하게 정리해 둬요.
- 봇을 만든 뒤 검토하고 테스트할 계획을 세워요.

**AI에게 문의**는 하이퍼클래스 안에 기본으로 들어 있는 작업 공간이에요. 플랫폼을 벗어나지 않고도 질문에 답하고, 콘텐츠를 만들고, 자산을 생성하고, 지원되는 작업을 처리할 수 있어요.

## AI에게 문의로 대화 AI 봇 설정하기

요청을 명확하게 쓰고 생성 후에 꼼꼼히 검토하면, 봇이 비즈니스 목적에 맞게 설정되고 의도한 채널에 배포돼요. 봇이 실제 고객 대화를 맡기 전에 꼭 테스트해 보세요.

### 1단계: AI에게 문의 열기

1. 해당 서브 계정에 로그인해요.
2. 내비게이션 메뉴에서 **AI에게 문의**를 열어요.
3. 새 대화를 시작해요.

### 2단계: 만들고 싶은 봇 설명하기

다음 내용을 담아 프롬프트를 입력하세요.

- 봇의 목적
- 봇이 소통할 고객 유형
- 원하는 결과
- 봇을 배포할 채널

```
예시:

신규 리드를 위한 대화 AI 봇을 만들어 줘. 지난 통화, 이메일, SMS 메시지, 소셜 대화, 실시간 채팅 기록을 활용해서 우리의 소통 스타일에 맞춰 줘. 봇은 첫 문의에 답하고 리드의 자격을 확인해야 하고, SMS, Facebook, 실시간 채팅에 배포해 줘.
```

### 3단계: 안내 질문에 답하기

봇 설정을 마치는 데 필요한 정보를 AI에게 문의가 추가로 물어볼 수 있어요. 질문을 하나씩 읽고 비즈니스, 봇의 목적, 기대하는 동작, 선택한 채널에 관해 정확하게 답해 주세요.

꼭 필요하고 해당 작업에 적절한 경우가 아니라면 고객의 민감한 정보는 입력하지 마세요.

### 4단계: 제안된 구성 검토하기

작업이 완료되기 전에 AI에게 문의가 보여 주는 요약이나 구성 내용을 확인하세요.

다음 사항을 확인해요.

- 봇의 목적이 맞아요.
- 원하는 소통 스타일이 반영되어 있어요.
- 알맞은 채널이 선택되어 있어요.
- 예상되는 배포 방식이 서브 계정의 **Channel Management** 상태와 맞아요.

### 5단계: AI에게 문의가 봇을 만들도록 허용하기

AI에게 문의가 봇을 만들 수 있도록 필요한 확인 절차를 진행하세요.

AI에게 문의는 사용할 수 있는 과거 대화를 활용해 봇의 소통 스타일을 잡고, 필요한 대화 AI 구성을 만들어요.

![AI에게 문의가 대화 AI 봇을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076706766/original/Bh20SlB7vu0R4OiMcbCC7831a3pnPaXadQ.png?1784817430)

### 6단계: 배포 확인 메시지 살펴보기

봇이 만들어지면 확인 메시지를 꼼꼼히 읽어 보세요.

**Channel Management**가 켜져 있으면 확인 메시지에 다음 내용이 나와요.

- 봇이 배포된 경로
- 건너뛴 채널
- 각 채널을 건너뛴 이유

**Channel Management**가 꺼져 있으면, 요청한 채널에서 봇이 **Primary Bot**(주 봇)으로 지정되었는지 확인하세요.

### 7단계: 새 봇 열기

1. **AI 에이전트**로 이동해요.
2. **대화 AI**를 선택해요.
3. AI에게 문의가 만든 봇을 열어요.
4. 봇의 설정을 살펴봐요.

![대화 AI 화면에서 새로 만든 봇을 연 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076717689/original/X9GneLqJYlpz8xuRwXL_bLoF0FzWo1thTA.png?1784822821)

### 8단계: 봇의 말투와 지침 검토하기

다음 항목을 검토하세요.

- 성격
- 어조
- 목표 또는 의도
- 자격 확인 질문
- 보조 지침
- 응답 방식

비즈니스를 정확하게 반영하지 못하는 표현은 직접 수정하세요.

**Bot Goals**와 프롬프트는 에이전트가 대화에서 어떻게 소통하고 무엇을 하려고 하는지에 영향을 줘요.

![봇의 말투와 지침을 검토하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076718526/original/-SE-2DYTDC6faZOM108YOqhbinDzwQBEmQ.gif?1784823305)

### 9단계: 봇 학습과 지식 소스 검토하기

봇이 고객 질문에 답하는 데 필요한 정보를 갖고 있는지 확인하세요.

다음 항목을 추가하거나 업데이트해요.

- 웹사이트 학습
- 자주 묻는 질문
- **Custom Bot Responses**
- 연결된 지식 베이스
- 정책
- 서비스 세부 정보
- 가격 정보
- 예약 정보

AI에게 문의는 안내형 워크플로우으로 지식 베이스를 만들어 대화 AI에 연결할 수도 있어요.

![봇 학습과 지식 소스를 검토하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076718701/original/q9jGEXUON7yy56sPrmB9SaqvTVOhU6Dl4g.png?1784823411)

### 10단계: 채널 또는 경로 배정 확인하기

봇이 예상한 위치에 배정되어 있는지 확인하세요.

**Channel Management**가 켜져 있을 때는 다음을 확인해요.

- 배정된 경로를 하나씩 살펴봐요.
- 기존 봇 배정이 그대로 유지되었는지 확인해요.
- 봇이 특정 경로만 사용해야 한다면 배정을 직접 조정해요.

**Channel Management**가 꺼져 있을 때는 다음을 확인해요.

- 이 봇이 의도한 **Primary Bot**인지 확인해요.
- 봇에 배정된 채널을 살펴봐요.

### 11단계: 봇 테스트하기

사용할 수 있는 테스트 도구로 다음 항목을 확인하세요.

- 어조와 표현
- 자주 묻는 질문에 대한 답변
- 자격 확인 질문
- 예약 진행 동작
- 워크플로우 액션
- 상담원 연결(휴먼 핸드오프) 동작
- 관련 채널별 응답

표준 대화 AI 설정 과정에는 목표 설정, 응답 테스트, 알맞은 봇 상태로 시작하는 단계가 포함돼요.

### 12단계: 실제 대화 모니터링하기

봇이 대화를 처리하기 시작한 뒤에는 다음을 해 주세요.

- 봇의 응답을 정기적으로 확인해요.
- 어조가 일관되게 유지되는지 살펴봐요.
- 답하지 못했거나 부정확하게 답한 질문이 있는지 찾아봐요.
- 정보가 부족하면 학습 콘텐츠를 업데이트해요.
- 응답이 비즈니스의 기대와 다르면 프롬프트와 지침을 다듬어요.
- 봇이 올바른 채널이나 경로에 계속 배정되어 있는지 확인해요.

꾸준히 검토하면 봇이 비즈니스 프로세스와 고객의 필요에 계속 맞춰져 있어요.

## 자주 묻는 질문

### AI에게 문의는 SMS와 채팅 메시지만으로 봇의 말투를 만드나요?
아니요. AI에게 문의는 SMS, 소셜 메시지, 실시간 채팅뿐 아니라 음성 통화 녹취록과 전체 이메일 스레드까지 더 폭넓은 대화 기록을 활용할 수 있어요.

### 대화 기록이 봇의 사실 학습 데이터가 되나요?
꼭 그렇지는 않아요. 과거 대화는 AI에게 문의가 봇의 어조, 스타일, 질문 방식을 만드는 데 도움을 줘요. 봇이 정확한 비즈니스 정보를 갖고 있는지는 **봇 학습**과 지식 베이스에서 따로 확인해야 해요.

### 일부 경로가 이미 다른 봇에 배정되어 있으면 어떻게 되나요?
**Channel Management**가 켜져 있으면, AI에게 문의는 그 배정을 그대로 두고 요청한 채널 안에서 사용할 수 있는 경로에만 새 봇을 배포해요.

### 선택한 채널의 모든 경로가 이미 배정되어 있으면 어떻게 되나요?
AI에게 문의는 그 채널을 건너뛰고, 사용할 수 있는 경로를 찾지 못했다고 완료 메시지에서 알려 줘요.

### 선택한 채널에 연결된 계정, 페이지, 번호, 실시간 채팅이 없으면 어떻게 되나요?
AI에게 문의는 그 채널에는 봇을 배포하지 않아요. 완료 메시지에서 건너뛴 채널을 알려 주고, 연결된 경로가 없다고 설명해요.

### 특정 전화번호나 Facebook 페이지 하나에만 봇을 배포해 달라고 요청할 수 있나요?
아니요. 지금은 AI에게 문의 요청에서 특정 경로를 지정하는 기능을 지원하지 않아요. **Channel Management**가 켜져 있으면 선택한 채널의 사용 가능한 모든 경로에 봇이 배포돼요. 봇을 만든 뒤에 경로 배정을 직접 조정할 수 있어요.

### 새 봇이 기존 봇을 대체하나요?
**Channel Management**가 켜져 있으면, 이미 경로에 배정된 봇을 새 봇이 대체하지 않아요. **Channel Management**가 꺼져 있으면 새로 만든 봇이 선택한 채널의 **Primary Bot**으로 지정되므로, 기존 **Primary Bot** 설정을 확인해 보세요.

### AI에게 문의가 봇을 자동으로 만들어 주는데도 테스트해야 하나요?
네. 실제 고객 대화에 봇을 쓰기 전에 생성된 봇을 꼭 테스트하세요. 어조, 사실 정확도, 질문, 액션, 예약 동작, 상담원 연결 로직을 함께 살펴보세요.
