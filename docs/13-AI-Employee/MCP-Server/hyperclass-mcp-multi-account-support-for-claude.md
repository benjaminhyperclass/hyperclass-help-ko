# Claude에서 여러 서브 계정 함께 사용하기 (하이퍼클래스 MCP)

Claude를 한 번만 연결하면, 같은 대화 안에서 여러 서브 계정을 안전하게 오가며 작업할 수 있어요.

하이퍼클래스 MCP(Model Context Protocol) 서버를 쓰면 Claude AI 어시스턴트가 여러 서브 계정의 CRM 데이터를 직접 다룰 수 있어요. 에이전시는 한 번 연결해 두면 다시 연결하지 않아도, 승인한 서브 계정 어디에서든 이어서 작업할 수 있어요.

이 문서에서는 다중 계정 MCP 엔드포인트, 인증 방식, 사용할 수 있는 도구, Claude 클라이언트별 설정 방법, 데이터를 지키는 보안 기능을 안내해요.

더 자세한 내용은 하이퍼클래스 고객지원에 문의하세요.

## Claude용 하이퍼클래스 MCP란?

하이퍼클래스 MCP 서버는 Claude AI 어시스턴트가 하이퍼클래스 CRM 데이터와 기능을 직접 다룰 수 있게 해 주는 연동이에요. MCP는 애플리케이션이 대규모 언어 모델에 맥락을 전달하는 방식을 표준화한 오픈 프로토콜이에요.

Anthropic 전용 엔드포인트(`https://services.leadconnectorhq.com/mcp/anthropic/v2`)를 쓰면 Claude에 자연어로 요청해서 하이퍼클래스 계정의 모든 데이터를 조회하고 자동화할 수 있어요. 내부 API를 사용자나 모델이 알 필요는 없어요.

이 엔드포인트는 Claude.ai, Claude Code(CLI), Claude Cowork에서 쓸 수 있어요.

## 주요 장점

다중 계정 MCP 엔드포인트를 쓰면 에이전시가 Claude로 서브 계정을 관리하는 방식이 달라져요.

- 하나의 연결로 여러 서브 계정 사용: 에이전시가 한 번 연결하면서 승인할 서브 계정을 고르면 돼요. 서브 계정마다 따로 연결하지 않아도 돼요.
- 서브 계정 즉시 전환: 요청에 서브 계정 이름만 말하면 같은 대화 안에서 다른 서브 계정으로 넘어가 작업해요.
- 자연어 자동화: API 문법이나 작업 이름을 몰라도 일상적인 말로 복잡한 명령을 내릴 수 있어요.
- 폭넓은 범위: 40개 제품 영역의 625개 작업을 쓸 수 있어요. 실제로 쓸 수 있는 작업은 OAuth 권한에 따라 정해져요.
- 일관된 도구 구성: 6개 도구가 모든 작업의 탐색, 확인, 실행을 맡아요. 그래서 모델의 컨텍스트가 과하게 늘어나지 않아요.
- 보안 중심 설계: 모든 요청은 서브 계정 하나에만 적용되고, 설치 시 승인한 범위 안에서 확인된 뒤 수명이 짧은 토큰으로 실행돼요.

## 다중 계정 연결 방식

Anthropic MCP 엔드포인트는 개인 연결과 에이전시 연결을 모두 지원해요. 두 방식은 쓰임새가 달라요.

### 연결 유형 1: 개인 사용자(서브 계정 1개)

개인 사용자로 연결하면 Claude가 서브 계정 하나에만 접근하도록 승인해요. 기본 연결 방식이고, 이전 MCP 구현과 똑같이 동작해요. 연결은 그 서브 계정에 계속 묶여 있어요.

### 연결 유형 2: 에이전시(서브 계정 여러 개)

에이전시로 설치하면 승인 과정에서 서브 계정을 여러 개 고를 수 있어요. 서브 계정 하나, 특정 서브 계정 여러 개, 에이전시의 모든 서브 계정 중에서 선택해요. 이후 Claude는 승인된 서브 계정에서만, 같은 대화 안에서 사용자가 지시하는 대로 오가며 작업해요.

### 작동 방식

에이전시는 설치할 때 포함할 서브 계정을 골라요. 연결은 선택한 서브 계정에서만 작동하고, 그 외 계정에는 접근하지 않아요. 요청은 한 번에 서브 계정 하나에만 실행돼요. 요청에서 서브 계정을 직접 말하면 그 계정에서 실행돼요. 어느 계정인지 모호하면 Claude가 `list_locations` 도구로 확인해요.

## 사용할 수 있는 MCP 도구

수백 개의 작업을 각각 별도 도구로 열어 두지 않고, MCP 서버는 6개의 통합 도구를 제공해요. Claude는 이 도구로 전체 작업 목록을 찾고, 확인하고, 실행해요. 도구 수가 적어서 모델의 컨텍스트 창이 과하게 차지되지 않으면서도 하이퍼클래스 API 전체를 쓸 수 있어요.

### 도구 1: `search`

이름, 이메일, 전화번호, 태그 등의 조건으로 고객이나 비즈니스 레코드를 찾아요. 이미 있는 데이터를 물어보면 Claude가 보통 가장 먼저 호출하는 도구예요.

### 도구 2: `fetch`

`search`로 찾은 레코드 하나 또는 여러 개의 전체 상세 정보를 가져와요. 연락처, 기회 같은 항목의 정보를 빠짐없이 확인할 때 써요.

### 도구 3: `search_operations`

조회, 생성, 수정, 삭제 같은 의도로 사용할 수 있는 작업을 찾아요. Claude는 실행하기 전에 요청에 맞는 작업이 무엇인지 이 도구로 찾아봐요.

### 도구 4: `describe_operation`

작업을 실행하기 전에 필수 입력값과 선택 입력값을 확인해요. 이 도구 덕분에 Claude가 어떤 데이터를 어떤 형식으로 넘겨야 하는지 알 수 있어요.

### 도구 5: `execute_operation`

하이퍼클래스 API에서 작업 하나를 실행해요. OAuth 스코프와 기본 안전 점검이 적용돼요. 생성, 수정, 삭제 작업은 모두 이 도구를 거쳐요.

### 도구 6: `list_locations`

이 연결로 접근할 수 있는 서브 계정 목록을 보여 줘요. 대상 서브 계정이 모호하거나 사용 가능한 서브 계정을 보여 달라고 할 때 Claude가 호출해요. 서브 계정 하나만 연결했다면 승인된 서브 계정 하나만 보여 줘요.

### 실제 사용 예시

Claude에게 "jane@example.com 이메일을 가진 연락처를 찾아서 'vip-2026' 태그를 추가하고, 5,000달러짜리 기회를 새로 만들어 줘"라고 요청하면 이렇게 진행돼요.

1. `search`로 Jane을 찾아요.
2. `search_operations`로 태그 추가와 기회 생성 작업을 찾아요.
3. `describe_operation`으로 각 작업의 입력값을 확인해요.
4. `execute_operation`을 두 번 실행해 두 작업을 마쳐요.

결과는 확인 메시지 하나로 받아요.

## 인증 방식

MCP 엔드포인트는 두 가지 인증 방식을 지원해요. 비공개 연동 토큰보다 OAuth가 더 넓은 범위의 스코프와 작업을 쓸 수 있어서 OAuth를 권장해요.

### 방식 1: OAuth (권장)

하이퍼클래스 동의 화면에서 한 번의 클릭으로 로그인해요. 연결을 승인할 때 동의 화면에서 스코프를 확인하고 승인해요. OAuth는 토큰을 직접 보관하거나 교체하지 않아도 되고, 가장 넓은 범위의 스코프를 쓸 수 있어요.

OAuth 접근 권한은 언제든 하이퍼클래스 계정 설정에서 확인하거나 취소할 수 있어요.

### 방식 2: 비공개 연동 토큰(PIT, Private Integration Token)

**설정 > 비공개 연동**에서 토큰을 만들고, 토큰에 부여할 스코프를 선택해요. MCP 클라이언트를 연결할 때 Authorization 헤더(`Bearer pit-your-token`)에 이 토큰을 넣어요.

PIT는 OAuth보다 쓸 수 있는 스코프가 제한적이라서, Claude가 수행할 수 있는 작업도 제한될 수 있어요.

### 스코프 필터링

두 인증 방식 모두 연동에 부여할 스코프를 직접 선택해요. Claude가 수행할 수 있는 작업은 이 스코프에 따라 걸러져요. 어시스턴트는 승인한 범위 안의 데이터와 기능에만 접근해요.

## Claude 클라이언트 연결 방법

하이퍼클래스 MCP 엔드포인트는 세 가지 Claude 환경에서 쓸 수 있어요. 사용하는 클라이언트에 맞는 설정 방법을 따라 하세요.

### 클라이언트 1: Claude.ai

1. [Claude.ai](https://claude.ai)를 열고 **Settings**(설정) > **Connectors**(커넥터) > **Add custom connector**(사용자 지정 커넥터 추가)로 이동해요.
2. 서버 URL을 `https://services.leadconnectorhq.com/mcp/anthropic/v2`로 입력해요.
3. **Connect**(연결)를 누르고 하이퍼클래스 로그인 과정을 마쳐요. 로그인 → 서브 계정 선택 → 스코프 승인 순서로 진행돼요.
4. 새 채팅을 시작하세요. 이제 하이퍼클래스 MCP 도구를 사용할 수 있어요.
5. "하이퍼클래스에서 최근에 추가한 연락처 5개를 찾아줘."라고 요청해서 연결이 잘 됐는지 확인해요.

### 클라이언트 2: Claude Code(CLI)

터미널에서 아래 명령어를 실행해요.

`claude mcp add --transport http leadconnector https://services.leadconnectorhq.com/mcp/anthropic/v2`

프로젝트 루트의 `.mcp.json`에 직접 추가해도 돼요.

```
{
  "mcpServers": {
    "leadconnector": {
      "type": "http",
      "url": "https://services.leadconnectorhq.com/mcp/anthropic/v2"
    }
  }
}
```

처음 사용할 때 Claude Code가 브라우저를 열어 하이퍼클래스 승인 화면을 보여 줘요. `claude mcp list`로 연결을 확인해요.

### 클라이언트 3: Claude Cowork

1. Claude Cowork에서 커넥터/연동 설정을 열어요.
2. **Add custom connector**(사용자 지정 커넥터 추가)를 선택해요.
3. 서버 URL을 `https://services.leadconnectorhq.com/mcp/anthropic/v2`로 입력해요.
4. 하이퍼클래스 로그인 과정을 마쳐요. 로그인 → 서브 계정 선택 → 승인 순서로 진행돼요.

이제 Cowork 에이전트가 하이퍼클래스 MCP 도구를 사용할 수 있어요.

### OAuth 대신 비공개 연동 토큰 사용하기

OAuth 대신 Authorization 헤더(`Bearer pit-your-token`)에 비공개 연동 토큰을 넣어 연결할 수도 있어요. 연결하기 전에 **설정 > 비공개 연동**에서 토큰을 만들고 필요한 스코프를 선택하세요.

## 서브 계정 사이 전환하기

여러 서브 계정에 접근하도록 승인된 에이전시 연결에서는 Claude가 같은 대화 안에서 서브 계정을 바로 오갈 수 있어요. 요청에 서브 계정 이름만 말하면 돼요.

### 대화 예시

나: "Downtown Clinic의 최신 기회를 보여 줘."

Claude가 Downtown Clinic의 기회를 가져와서 보여 줘요.

나: "이번에는 Westside Dental에 연락처를 만들어 줘."

Claude가 Westside Dental로 넘어가서 연락처를 만들어 줘요. 다시 연결할 필요가 없어요.

대상 서브 계정이 분명하지 않거나 말하지 않았다면, Claude가 `list_locations` 도구로 사용할 수 있는 서브 계정을 보여 주고 선택하라고 물어봐요. 그래서 작업은 항상 올바른 서브 계정에서 실행돼요.

### 서브 계정 1개만 연결한 경우

서브 계정 하나만 연결했다면(개인 사용자의 기본 설정) `list_locations`는 그 서브 계정만 보여 줘요. 요청할 때 서브 계정 이름을 말하지 않아도 돼요. Claude가 항상 어느 계정을 쓸지 알고 있어요.

## 보안과 권한

MCP 엔드포인트는 여러 겹의 보안 장치로 하이퍼클래스 데이터를 보호해요.

- 설치 시 서브 계정 선택: 승인 과정에서 연결이 접근할 서브 계정을 직접 골라요. 포함하지 않은 서브 계정에는 연결이 닿을 수 없어요.
- 요청당 서브 계정 1개: 에이전시 연결이어도 모든 작업은 한 번에 서브 계정 하나에서만 실행돼요. 여러 서브 계정에 걸친 작업은 할 수 없어요.
- 스코프 기반 승인: 부여한 OAuth 스코프나 비공개 연동 토큰 스코프에 따라 작업이 걸러져요. Claude는 승인된 범위의 작업만 할 수 있어요.
- 수명이 짧은 서브 계정 토큰: 요청마다 대상 서브 계정에만 유효한 임시 토큰으로 실행돼요. 토큰이 노출되더라도 피해를 줄일 수 있어요.
- 민감한 작업의 안전 점검: 되돌릴 수 없거나 데이터를 지우는 작업은 실행 전에 추가 확인 절차와 안전 점검을 거쳐요.
- 접근 권한 취소 가능: OAuth 접근 권한은 언제든 하이퍼클래스 계정 설정에서 확인하고, 수정하고, 취소할 수 있어요.

## 사용할 수 있는 작업과 범위

Anthropic MCP 엔드포인트는 40개 제품 영역의 625개 작업을 제공해요. 연결에서 실제로 쓸 수 있는 작업은 부여한 OAuth 또는 비공개 연동 토큰 스코프에 따라 달라져요.

포함되는 영역은 다음과 같아요.

- **연락처**: 조회, 목록, 검색, 생성, 수정, 삭제, 업서트, 중복 조회, 태그, 메모, 작업, 팔로워, 예약, 비즈니스 지정
- 대화 & 메시지: 대화 생성, 조회, 수정, 삭제, 검색, 메시지 읽기와 보내기, 메시지 상태 추적
- **기회 & 파이프라인**: 파이프라인, 고객전환실패 사유, 검색, 생성, 수정, 삭제, 업서트, 팔로워, 상태 변경
- 캘린더 & 예약: 캘린더, 그룹, 예약, 이벤트, 메모, 알림, 가능/차단 시간대, 리소스, 일정, 서비스, 서비스 예약
- **결제**: 쿠폰, 연동, 주문, 주문 이행, 구독, 거래 내역
