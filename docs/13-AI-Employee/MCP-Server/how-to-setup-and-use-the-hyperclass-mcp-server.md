# 하이퍼클래스 MCP 서버 설정하고 사용하기

AI 어시스턴트를 하이퍼클래스에 연결하면, 내가 내린 지시에 따라 어시스턴트가 CRM 기록을 찾고 지원되는 작업을 실행할 수 있어요. 하이퍼클래스 MCP 서버는 OAuth로 연결해요. 로그인한 뒤 연결할 서브 계정을 고르고, 요청하는 권한을 승인하면 돼요.

이 문서에서는 Claude, ChatGPT, Codex, Cursor, Muse, Grok Bot의 연결 방법과, 승인한 여러 서브 계정에서 작업하는 방법, 사용할 수 있는 작업을 찾는 방법을 안내해요.

## 하이퍼클래스 MCP 서버란?

MCP는 Model Context Protocol의 약자예요. AI 어시스턴트가 연결된 애플리케이션의 도구를 찾아서 쓰는 표준 방식이에요. 하이퍼클래스 MCP 서버를 연결하면 내부 API를 몰라도 어시스턴트가 지원되는 CRM 데이터와 작업을 다룰 수 있어요.

현재 제공되는 목록에는 **38개 영역에 걸쳐 550개가 넘는 조회·생성·수정·삭제 작업**이 있어요. 내 연결에서 쓸 수 있는 작업은 승인한 OAuth 범위(scope)와 권한에 따라 달라져요.

## 연결하기 전에

연결하려는 하이퍼클래스 서브 계정에 접근할 수 있어야 하고, 지원되는 AI 클라이언트가 있어야 해요. 사용자 지정 MCP 연결을 만들 때는 아래에서 내 클라이언트에 맞는 URL을 쓰세요. Muse와 Grok Bot은 공식 앱으로 제공돼요.

| AI 클라이언트 | 연결 방법 |
| --- | --- |
| **Claude.ai, Claude Code, Claude Cowork** | `https://services.leadconnectorhq.com/mcp/anthropic/v2` |
| **ChatGPT, Codex 및 호환되는 기타 OpenAI 클라이언트** | `https://services.leadconnectorhq.com/mcp/openai/v2/` |
| **Cursor** | `https://services.leadconnectorhq.com/mcp/cursor/v2` |
| **Muse** | Muse에서 공식 앱을 연결해요. OAuth 엔드포인트는 `https://services.leadconnectorhq.com/mcp/muse/v2/` 예요. |
| **Grok Bot** | **Connect apps**(앱 연결)에서 하이퍼클래스를 추가해요. |

모든 연결은 OAuth를 사용해요. 승인 과정에서 하이퍼클래스에 로그인하고, 선택할 수 있는 서브 계정을 고른 다음, 요청하는 범위를 승인하세요. 어떤 방식으로 연결해도 현재 제공 중인 MCP 작업 목록을 똑같이 사용해요.

## AI 클라이언트 연결하기

### Claude.ai

1. **Claude.ai > 설정 > 커넥터 > Add custom connector**(사용자 지정 커넥터 추가)를 여세요.
2. 아래 서버 URL을 입력하세요.

   ```
   https://services.leadconnectorhq.com/mcp/anthropic/v2
   ```
3. **연결**을 클릭하고 하이퍼클래스 로그인과 동의 과정을 마치세요.
4. 연결할 서브 계정을 고르고 접근을 승인하세요.
5. 새 채팅을 시작하면 하이퍼클래스 도구를 쓸 수 있어요.

### Claude Code

터미널에서 아래 명령을 실행하세요.

```
claude mcp add --transport http leadconnector https://services.leadconnectorhq.com/mcp/anthropic/v2
```

또는 프로젝트 루트의 `.mcp.json` 파일에 아래 설정을 추가해도 돼요.

```
{
  "mcpServers": {
    "leadconnector": {
      "type": "http",
      "url": "https://services.leadconnectorhq.com/mcp/anthropic/v2"
    }
  }
}
```

처음 사용할 때 Claude Code가 하이퍼클래스 승인을 위해 브라우저를 열어요. 로그인하고, 서브 계정을 고르고, 접근을 승인하세요. 아래 명령으로 연결을 확인할 수 있어요.

```
claude mcp list
```

### Claude Cowork

1. Claude Cowork에서 **connectors / integrations**(커넥터/연동) 설정을 여세요.
2. **Add custom connector**(사용자 지정 커넥터 추가)를 선택하세요.
3. `https://services.leadconnectorhq.com/mcp/anthropic/v2` 를 입력하세요.
4. 하이퍼클래스 OAuth 과정을 마치세요. 로그인하고, 서브 계정을 고르고, 접근을 승인하면 돼요.

이제 Cowork 에이전트가 하이퍼클래스 도구를 쓸 수 있어요.

### ChatGPT

1. ChatGPT에서 **설정 > Security and login**(보안 및 로그인)을 열고 **Developer mode**(개발자 모드)를 켜세요.
2. **ChatGPT Plugins**(플러그인)를 열고 **plus**(+) 버튼을 눌러 새 플러그인을 만드세요.
3. 이름과 설명을 입력하세요. **연결** 아래에 아래 MCP 서버 URL을 추가하고 연결을 만드세요.

   ```
   https://services.leadconnectorhq.com/mcp/openai/v2/
   ```
4. 하이퍼클래스 OAuth 과정을 마치세요. 로그인하고, 서브 계정을 고르고, 접근을 승인하면 돼요.
5. 새 대화를 시작하고, 도구 메뉴에서 하이퍼클래스 연결을 추가하세요.

### Codex

서버를 추가하고 OAuth 승인을 시작하는 명령이에요.

```
codex mcp add leadconnector --url https://services.leadconnectorhq.com/mcp/openai/v2/
codex mcp login leadconnector
```

**Codex IDE extension**(Codex IDE 확장)에서는 **gear menu**(톱니바퀴 메뉴) > **MCP servers** > **Add server**(서버 추가)를 열고 **Streamable HTTP**를 선택한 다음 같은 URL을 입력하세요. 안내가 나오면 **Authenticate**(인증)를 선택해 OAuth를 완료하세요.

호환되는 다른 OpenAI 클라이언트에서는 이 URL을 원격 Streamable HTTP MCP 서버로 등록하고, 안내에 따라 하이퍼클래스 OAuth 과정을 마치면 돼요.

### Cursor

프로젝트의 `.cursor/mcp.json` 파일에 아래 설정을 추가하세요. 모든 프로젝트에서 쓰려면 `~/.cursor/mcp.json` 에 추가하세요.

```
{
  "mcpServers": {
    "leadconnector": {
      "url": "https://services.leadconnectorhq.com/mcp/cursor/v2"
    }
  }
}
```

이미 다른 서버를 설정해 두었다면, 기존 `mcpServers` 객체 안에 `leadconnector` 항목을 추가하세요.

Cursor가 안내하면 하이퍼클래스 OAuth 과정을 마치세요. 로그인하고, 서브 계정을 고르고, 접근을 승인하면 돼요.

### Muse

하이퍼클래스는 Muse에서 공식 앱으로 제공돼요. 앱을 연결하고 하이퍼클래스 OAuth 과정을 마치세요. 로그인하고, 서브 계정을 고르고, 접근을 승인하면 돼요.

Muse는 OAuth 연결에 `https://services.leadconnectorhq.com/mcp/muse/v2/` 를 사용해요.

### Grok Bot

1. **Grok Bot > Connect apps**(앱 연결)를 여세요.
2. **하이퍼클래스**를 검색하고 **추가**를 선택하세요.
3. 하이퍼클래스 OAuth 과정을 마치세요. 로그인하고, 서브 계정을 고르고, 접근을 승인하면 돼요.

앱을 특정 작업에 붙이려면 채팅에서 `@` 를 입력하고 **하이퍼클래스**를 선택하세요.

## 연결 확인하기

간단한 요청으로 시작해 보세요.

> 하이퍼클래스에 내가 마지막으로 추가한 연락처 5개를 찾아 줘.

어시스턴트가 사용할 수 있는 연락처 작업을 찾아, 내가 허용한 권한 안에서 기록을 가져와요.

에이전시 연결이라면 사용할 서브 계정 이름을 함께 알려 주세요.

## 서브 계정 하나 또는 여러 개로 작업하기

### 서브 계정 하나만 연결할 때

서브 계정 하나로 만든 연결은, OAuth 승인 중에 고른 서브 계정에 그 연결이 유지되는 동안 계속 묶여 있어요.

### 에이전시 연결

에이전시 전체 접근을 쓸 수 있는 경우에는 한 번만 연결해도 설치할 때 고른 서브 계정들에서 작업할 수 있어요.

1. 설치할 때 서브 계정을 고르세요. 에이전시 설치 화면에 나오는 서브 계정 중 하나, 여러 개, 또는 전체를 선택할 수 있어요.
2. 요청에 서브 계정 이름을 적으세요. 어떤 서브 계정인지 분명하지 않으면 어시스턴트가 `list_locations` 를 사용해 선택해 달라고 물어봐요.
3. 같은 채팅 안에서 서브 계정을 바꿔 가며 쓰세요. 다시 연결하지 않아도 승인한 다른 서브 계정에 대해 물어볼 수 있어요.

예를 들면 이렇게 요청해요.

> Downtown Clinic에서 "vip-2026" 태그가 붙은 연락처를 보여 주고, Uptown Med Spa의 연락처 수와 비교해 줘.

어시스턴트는 서브 계정 이름을 확인한 뒤 서브 계정별로 따로 조회하고 결과를 비교해요. 모든 요청은 서브 계정 하나를 대상으로 하며, 내 설치 범위 안에서 승인돼요. 연결에 포함하지 않은 서브 계정에는 접근할 수 없어요.

제공 현황: 서브 계정 하나로 연결하는 방식은 지금 쓸 수 있어요. 에이전시 전체 연결은 여러 서브 계정(일괄) 설치 옵션을 통해 순차적으로 제공되고 있어요. 설치 화면에 서브 계정이 하나만 나온다면, 내 앱에서는 아직 여러 서브 계정 옵션이 활성화되지 않은 거예요.

## MCP 도구 4가지의 역할

서버는 통합 도구 4개를 제공해요. 어시스턴트는 이 도구로 내 연결에서 쓸 수 있는 작업을 찾고 실행해요.

| 도구 | 용도 |
| --- | --- |
| `list_locations` | 연결에서 사용할 수 있는 서브 계정을 찾아요. 서브 계정 하나에 묶인 연결이면 그 서브 계정을 알려 줘요. |
| `search_operations` | 작업에 맞는 활성 작업을 찾아요. 기록 검색과 조회, 생성, 수정, 삭제 작업이 포함돼요. |
| `describe_operation` | 작업의 입력값, 예시 페이로드, 필요한 범위, 안전 정보를 확인해요. |
| `execute_operation` | OAuth 범위, 권한, 서브 계정 경계, 기본 안전 점검 안에서 작업을 실행해요. |

내 연결에서 쓸 수 있는 작업이 궁금하면 언제든 어시스턴트에게 `search_operations` 로 확인해 달라고 요청하세요.

| **그 밖의 CRM 영역** | 채팅 위젯, 링크, 스냅샷, 캠페인, 코스에서 지원되는 작업 |

## 예시: 요청 하나로 작업 끝내기

연결한 뒤에는 어시스턴트에게 이런 요청을 할 수 있어요.

> 이메일이 jane@example.com 인 연락처를 찾아서 "vip-2026" 태그를 붙이고, "영업 파이프라인"에 5,000달러짜리 기회를 만들어 줘.

어시스턴트는 `search_operations` 로 연락처 조회, 태그 추가, 기회 생성 작업을 찾아요. 그다음 `describe_operation` 으로 입력값, 범위, 안전 정보를 확인하고, `execute_operation` 으로 연락처를 찾아 지원되는 작업을 실행해요. 마지막으로 결과를 자연스러운 말로 알려 줘요.

## 권한과 보안

- 서브 계정은 내가 선택해요. 모든 요청은 설치 범위 안에서 승인되며, 그 연결에 포함된 서브 계정에만 접근할 수 있어요.
- OAuth 범위가 작업을 제한해요. 어시스턴트는 내가 부여한 권한이 허용하는 작업만 할 수 있어요.
- 민감한 작업은 추가로 점검해요. 민감하거나 되돌릴 수 없는 작업은 실행하기 전에 확인과 안전 점검을 거쳐요.
- 접근 권한은 계속 내가 관리해요. 하이퍼클래스 계정에서 연결의 접근 권한을 확인하거나 취소할 수 있어요.

## 자주 묻는 질문

### 비공개 연동 토큰(Private Integration Token)이 필요한가요?

이 문서의 클라이언트 연결은 모두 OAuth를 사용해요. 하이퍼클래스 로그인과 동의 과정을 마치면 접근이 승인돼요. 이 연결을 위해 토큰을 직접 만들거나 교체할 필요는 없어요.

### 어떤 서버 URL을 써야 하나요?

위 연결 표에서 내 클라이언트에 맞는 URL을 쓰세요. Claude 클라이언트는 Anthropic 엔드포인트, ChatGPT와 Codex는 OpenAI 엔드포인트, Cursor는 전용 엔드포인트를 사용해요. Muse와 Grok Bot은 공식 앱으로도 제공돼요.

### 도구가 수백 개가 아니라 4개만 보이는 이유가 뭔가요?

이 4개 도구로 어시스턴트가 활성 작업 목록을 찾고 실행해요. 개별 CRM 작업은 `search_operations` 로 찾고, `describe_operation` 으로 살펴보고, `execute_operation` 으로 실행해요.

### 사용할 수 있는 작업은 몇 개인가요?

현재 목록에는 38개 영역에 걸쳐 550개가 넘는 작업이 있어요. 내 연결에서는 OAuth 범위와 권한이 허용하는 작업만 쓸 수 있어요. 필요한 작업이 있으면 어시스턴트에게 검색해 달라고 요청하세요.

### 어시스턴트가 기록을 만들고, 수정하고, 삭제할 수도 있나요?

네. 작업이 지원되고 내가 부여한 OAuth 권한이 허용하는 경우에 가능해요. 민감하거나 되돌릴 수 없는 작업에는 확인과 안전 점검도 적용돼요.

### 연결 하나로 서브 계정 여러 개를 쓸 수 있나요?

에이전시는 여러 서브 계정 설치 옵션이 활성화된 경우에 쓸 수 있어요. 이 경우에도 각 작업은 승인된 서브 계정 하나를 대상으로 실행돼요. 설치 화면에 서브 계정이 하나만 나온다면, 내 앱에서는 아직 여러 서브 계정 옵션이 활성화되지 않은 거예요.

### 어시스턴트가 내가 선택하지 않은 서브 계정에 접근할 수 있나요?

아니요. 설치에 포함하지 않은 서브 계정에 대한 요청은 거부돼요.

### 접근 권한을 없애려면 어떻게 하나요?

하이퍼클래스 계정에서 해당 연동의 접근 권한을 확인하거나 취소하세요.
