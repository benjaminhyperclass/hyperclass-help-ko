# Grok Bot에 하이퍼클래스 MCP 연결하기

하이퍼클래스가 Grok Bot의 공식 연결 앱으로 제공돼요. 연결하면 대화하듯 요청해서 CRM 정보를 확인하고, 지원되는 작업을 실행할 수 있어요. 이 문서에서는 Grok Bot에 하이퍼클래스를 연결하는 방법을 안내해요.

하이퍼클래스 MCP는 OAuth 인증을 사용해요. API 토큰을 직접 설정하지 않아도 서브 계정을 안전하게 연결할 수 있어요. 38개 CRM 영역에서 600개 이상의 작업을 Grok Bot으로 처리할 수 있어요.

## 하이퍼클래스 MCP란?

하이퍼클래스 MCP는 Model Context Protocol(MCP)로 CRM과 Grok Bot을 연결해요. 연결하면 AI 어시스턴트가 지원되는 하이퍼클래스 서비스를 사용할 수 있어요. 간단한 대화로 CRM 정보를 가져오고, 허용된 작업을 실행할 수 있어요.

통합된 MCP 도구 4개가 승인된 OAuth 권한 범위 안에서 작업을 찾고 실행해요. MCP 서버 설정은 [하이퍼클래스 MCP 서버 설정 및 사용 방법](how-to-setup-and-use-the-hyperclass-mcp-server.md)에서 확인할 수 있어요.

## 연결하면 좋은 점

하이퍼클래스를 Grok Bot에 연결하면 여러 CRM 화면을 오가지 않고도 CRM 정보를 확인하고 지원되는 작업을 처리할 수 있어요.

- **기본 제공 연동:** Grok Bot의 Connected Apps 디렉터리에서 하이퍼클래스를 바로 연결해요.
- **안전한 OAuth 인증:** API 토큰을 직접 만들지 않고 접근 권한을 승인해요.
- **자연어 요청:** 대화로 정보를 조회하고 지원되는 CRM 작업을 실행해요.
- **폭넓은 CRM 범위:** 38개 CRM 영역의 600개 이상 작업을 사용해요.
- **서브 계정 선택:** 승인할 CRM 서브 계정을 직접 골라요.
- **권한 기반 접근:** 승인한 OAuth 권한 범위 안에서만 작업을 실행해요.

## 지원하는 CRM 작업

하이퍼클래스 MCP는 통합 도구 4개로 지원되는 CRM 서비스에 접근해요. 쓸 수 있는 작업은 승인한 권한과 연결한 서브 계정에 따라 달라요.

지원하는 CRM 영역의 예시는 다음과 같아요.

- **연락처:** 연락처 정보를 검색하고 관리해요.
- **기회 관리:** 기회 기록을 조회하고 업데이트해요.
- **캘린더:** 일정 정보를 확인해요.
- **대화:** 지원되는 대화 정보를 조회해요.
- **결제:** 지원되는 결제 관련 작업을 사용해요.

Grok Bot에는 이렇게 요청해 볼 수 있어요.

- "가장 최근에 만든 연락처 5개를 찾아 줘."
- "내 CRM에서 진행 중인 기회를 보여 줘."
- "이메일이 [jane@example.com](mailto:jane@example.com)인 연락처를 찾아 줘."

실제 결과는 승인한 권한과 사용 가능한 작업에 따라 달라요.

## Grok Bot에서 하이퍼클래스 MCP 설정하기

공식 앱을 선택하고, CRM 계정을 인증한 뒤, 권한을 승인하면 연결돼요. 이 과정을 마치면 Grok Bot이 원하는 하이퍼클래스 정보에 접근할 수 있어요.

### 1단계. Connected Apps 열기

1. Grok Bot에 로그인하세요.
2. **Connected Apps**(연결된 앱)로 이동하세요.
3. 앱 검색 디렉터리를 여세요.

### 2단계. 하이퍼클래스 검색하기

1. **하이퍼클래스**를 검색하세요.
2. 공식 하이퍼클래스 앱을 선택하세요.
3. 화면에 나오는 안내에 따라 연결을 시작하세요.

### 3단계. 하이퍼클래스 인증하기

1. 로그인 창이 나오면 하이퍼클래스 계정으로 로그인하세요.
2. 연결할 CRM 서브 계정을 선택하세요.
3. 요청된 OAuth 권한을 확인하세요.
4. 접근을 승인해 인증을 마치세요.

{% hint style="info" %}
서브 계정을 여러 개 선택할 수 있는지는 계정의 이용 가능 여부에 따라 달라질 수 있어요.
{% endhint %}

OAuth 동의 화면에 대한 자세한 내용은 [API 보안 - 마켓플레이스 앱의 OAuth 동의](../../27-앱-마켓/Get-Started-w/App-Marketplace/api-security-oauth-consent-for-marketplace-apps.md)를 참고하세요.

### 4단계. 연결 확인하기

1. Grok Bot으로 돌아오세요.
2. 하이퍼클래스가 연결된 상태로 표시되는지 확인하세요.
3. 간단한 요청으로 연동을 테스트하세요. 예를 들면 다음과 같아요.

   "내 하이퍼클래스 CRM에서 가장 최근에 만든 연락처 5개를 보여 줘."

## 자주 묻는 질문

### API 키나 비공개 연동 토큰이 필요한가요?

아니요. Grok Bot 공식 연동은 OAuth 인증을 사용해서 API 토큰을 직접 설정하지 않아도 돼요.

### 하이퍼클래스 서브 계정을 여러 개 연결할 수 있나요?

인증 과정에서 선택할 수 있는 서브 계정을 고르면 돼요. 여러 서브 계정 지원은 제공 시점에 따라 다를 수 있어요.

### Grok Bot이 하이퍼클래스 CRM의 모든 작업을 할 수 있나요?

Grok Bot은 승인한 OAuth 권한 범위와 계정에 적용된 권한에 따라 지원되는 작업을 실행할 수 있어요.

### CRM 데이터는 안전한가요?

연결은 OAuth 인증을 사용하고, 접근은 승인한 권한 범위로 제한돼요. 연동을 승인하기 전에 요청된 권한 범위를 꼭 확인하세요.

### Grok Bot이 CRM 데이터에 접근하지 못해요.

다음 세 가지를 확인하세요.

- 하이퍼클래스가 연결되어 있는지
- 올바른 서브 계정을 인증했는지
- 필요한 권한을 승인했는지
