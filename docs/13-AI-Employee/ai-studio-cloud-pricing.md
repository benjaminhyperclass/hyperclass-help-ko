# AI 스튜디오 Cloud 요금 안내

AI 스튜디오(AI Studio) Cloud 요금은 앱을 실행하고 데이터를 저장하는 데 쓰는 리소스에 따라 정해져요. 인스턴스 크기, 예약한 데이터베이스 스토리지, 실제로 사용한 파일 스토리지, 이 세 가지가 요금에 영향을 줘요. 프로젝트마다 세 항목 모두 무료 제공량이 있어서, 규모가 작은 앱은 Cloud 요금이 나오지 않을 수도 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

{% hint style="info" %}
Cloud 요금은 앱을 만들거나 수정할 때 발생하는 AI 스튜디오 사용 요금과 별개예요.
{% endhint %}

## AI 스튜디오 Cloud란 무엇이고 비용은 얼마인가요?

AI 스튜디오 Cloud는 데이터베이스, 사용자 인증, 파일 저장이 필요한 앱에 기본으로 제공되는 백엔드예요. 별도의 백엔드 서비스를 따로 쓰지 않아도 돼요. 예를 들어 회원 포털에서 Cloud로 사용자 계정을 관리하고, 프로필 정보를 저장하고, 문서 업로드를 처리할 수 있어요.

Cloud의 작동 방식, 기능, 설정 방법은 [AI 스튜디오의 관리형 Cloud 백엔드](ai-studio-cloud-backend.md)에서 확인하세요.

Cloud 요금은 인스턴스 크기, 예약한 데이터베이스 스토리지, 실제 파일 스토리지 사용량에 따라 달라져요. 모든 프로젝트에는 무료 Tiny 인스턴스, 데이터베이스 스토리지 2 GB, 파일 스토리지 1 GB가 포함돼요. 더 큰 인스턴스를 선택하거나 무료 스토리지 제공량을 넘길 때만 요금이 부과돼요.

## Cloud 인스턴스 요금

인스턴스는 앱이 쓸 수 있는 CPU와 메모리 같은 컴퓨팅 리소스를 정해요. Tiny 인스턴스는 무료이고, 더 큰 인스턴스는 Cloud가 실행되는 동안 시간 단위로 요금이 부과돼요.

| 인스턴스 | CPU | 메모리 | 시간당 요금 | 월 예상 금액\* |
| --- | --- | --- | --- | --- |
| Tiny | 공유 CPU | 최대 0.5 GB RAM | 무료 | 무료 |
| Mini | 2코어 ARM, 공유 | 1 GB RAM | $0.015456 | $11.28 |
| Small | 2코어 ARM, 공유 | 2 GB RAM | $0.02369 | $17.29 |
| Medium | 2코어 ARM, 공유 | 4 GB RAM | $0.09453 | $69.01 |
| Large | 2코어 ARM, 전용 | 8 GB RAM | $0.174455 | $127.35 |
| X-Large | 4코어 ARM, 전용 | 16 GB RAM | $0.330855 | $241.52 |

{% hint style="info" %}
월 예상 금액은 Cloud가 한 달 내내 계속 실행된다고 보고 730시간 기준으로 계산했어요.
{% endhint %}

### 인스턴스 크기를 바꾸면 요금은 어떻게 되나요?

- 인스턴스 크기 변경: 인스턴스 크기는 시계 기준 1시간에 한 번 늘리거나 줄일 수 있어요.
- 크기를 바꾼 시간의 요금: 크기를 바꾼 시간에는 이전 인스턴스 요금 1시간분과 새 인스턴스 요금 1시간분이 함께 부과돼요. 그다음 시간부터는 새 인스턴스 요금만 적용돼요.
- Tiny로 전환: 무료 Tiny 인스턴스로 돌아가면 그다음 시간부터 유료 인스턴스 요금이 부과되지 않아요.

{% hint style="warning" %}
Cloud를 일시정지하면 인스턴스 요금이 멈출 수 있어요. 다만 일시정지한 그 시간에는 요금이 부과될 수 있어요.
{% endhint %}

## 데이터베이스 스토리지 요금

데이터베이스 스토리지는 앱의 테이블과 행을 저장하는 공간이에요. 프로젝트마다 무료 데이터베이스 스토리지 2 GB가 포함돼요. 추가 스토리지는 GB당 시간당 $0.000197이고, 한 달로 계산하면 GB당 약 $0.14예요.

파일 스토리지와 달리 데이터베이스 스토리지는 실제 사용량이 아니라 예약한 용량을 기준으로 요금이 부과돼요.

{% hint style="warning" %}
데이터베이스 스토리지를 늘리기 전에 **고급 설정 > Database storage**(데이터베이스 스토리지)에서 현재 사용량을 확인하세요. 한 번 늘리면 되돌릴 수 없으니, 데이터가 기존 한도에 가까워졌을 때만 용량을 늘리세요.
{% endhint %}

데이터베이스 스토리지 요금이 부과되는 방식은 다음과 같아요.

- 사용량이 아니라 예약한 크기만큼 내요: 데이터베이스 스토리지는 공간이 차 있는지와 관계없이, 할당(예약)된 크기를 기준으로 매시간 요금이 부과돼요. 늘릴 수 있는 가장 작은 단위는 8 GB예요. 그래서 처음 늘린 뒤에는 데이터가 0.25 GB만 차지해도 무료 2 GB를 뺀 6 GB만큼 요금이 부과돼요.
- 늘리기만 할 수 있어요: 데이터베이스 스토리지는 늘릴 수는 있지만 줄일 수는 없어요. 한 번 늘리면 Cloud를 삭제할 때까지 늘어난 크기로 요금이 부과돼요.
- 일시정지해도 멈추지 않아요: 2 GB를 넘는 데이터베이스 스토리지는 Cloud가 일시정지된 동안에도 계속 요금이 부과돼요. 이 요금은 Cloud를 삭제해야 멈춰요.

## 파일 스토리지 요금

파일 스토리지는 앱의 스토리지 버킷에 업로드한 이미지, PDF, 문서 같은 콘텐츠를 저장하는 공간이에요. 프로젝트마다 무료 파일 스토리지 1 GB가 포함돼요. 추가 스토리지는 GB당 시간당 $0.000047이고, 한 달로 계산하면 GB당 약 $0.034예요.

데이터베이스 스토리지와 달리 파일 스토리지는 파일이 실제로 차지하는 공간을 기준으로 요금이 부과돼요.

- 저장한 만큼만 내요: 파일을 업로드하면 파일 스토리지가 자동으로 늘어나고, 파일이 실제로 사용하는 공간만큼만 요금이 부과돼요.
- 파일을 지우면 요금이 줄어요: 파일을 삭제해서 사용량이 다시 1 GB 아래로 내려가면 파일 스토리지 요금이 부과되지 않아요.
- 일시정지해도 멈추지 않아요: 1 GB를 넘는 파일 스토리지는 Cloud가 일시정지된 동안에도 계속 요금이 부과돼요. 이 요금을 멈추려면 파일을 삭제하거나 Cloud를 삭제하세요.

### 스토리지 요금 한눈에 보기

데이터베이스 스토리지와 파일 스토리지는 요금이 부과되는 방식이 달라요. 두 요금과 무료 제공량을 비교해 보면 스토리지 변경이 Cloud 비용에 어떤 영향을 주는지 이해하기 쉬워요.

| 스토리지 유형 | 프로젝트당 무료 제공량 | 무료 제공량 초과 시 요금 | GB당 월 예상 금액\* | 요금 기준 |
| --- | --- | --- | --- | --- |
| 데이터베이스 스토리지 | 2 GB | GB당 시간당 $0.000197 | $0.14 | 예약한 크기 |
| 파일 스토리지 | 1 GB | GB당 시간당 $0.000047 | $0.034 | 실제 사용량 |

{% hint style="info" %}
월 예상 금액은 730시간 기준으로 계산했어요.
{% endhint %}

## Cloud를 일시정지하거나 삭제하면 요금은 어떻게 되나요?

Cloud를 일시정지할 때와 삭제할 때는 요금과 저장된 데이터에 미치는 영향이 달라요. 일시정지하면 앱이 잠시 멈추지만 데이터는 그대로 남아요. Cloud를 삭제하면 데이터베이스, 사용자, 파일이 영구적으로 삭제돼요.

| 요금 항목 | Cloud 실행 중 | Cloud 일시정지 | Cloud 삭제 |
| --- | --- | --- | --- |
| 인스턴스(Mini 이상) | 부과됨 | 부과 안 됨 | 부과 안 됨 |
| 2 GB 초과 데이터베이스 스토리지 | 부과됨 | 부과됨 | 부과 안 됨 |
| 1 GB 초과 파일 스토리지 | 부과됨 | 부과됨 | 부과 안 됨 |

요금과 관련해 꼭 알아 둘 점은 다음과 같아요.

- Cloud 일시정지: 인스턴스 요금은 Cloud가 1시간 내내 일시정지 상태였던 시간에만 멈춰요. 한 시간 중 일부라도 인스턴스가 실행됐다면 그 시간은 전체 요금이 부과돼요.
- 일시정지 중 스토리지 요금: 2 GB를 넘는 데이터베이스 스토리지와 1 GB를 넘는 파일 스토리지는 Cloud가 일시정지된 동안에도 계속 요금이 부과돼요.
- Cloud 삭제: Cloud를 삭제하면 모든 Cloud 요금이 멈추지만, 데이터베이스, 사용자, 파일이 영구적으로 삭제돼요.

앱을 잠시 멈추되 데이터는 보관하고 싶다면 **일시정지**를 선택하세요. Cloud 환경이나 저장된 데이터가 더 이상 필요 없을 때만 **Remove Cloud**(Cloud 삭제)를 선택하세요.

## Cloud 요금은 어떻게 청구되나요?

Cloud 사용 요금은 하이퍼클래스 지갑에서 청구되고, AI 스튜디오로 앱을 만드는 활동은 별도로 청구돼요. 이 차이를 알면 계속 발생하는 Cloud 비용과 AI 스튜디오 사용 요금을 구분하기 쉬워요.

- 지갑 청구: Cloud 요금은 하루 동안 쌓였다가 하루에 한 번 지갑에서 차감돼요. 자동 충전이 켜져 있으면 기존 설정에 따라 지갑이 충전돼요.
- 에이전시 재청구: 에이전시는 Cloud 요금을 서브 계정에 재청구할 수 있어요. Cloud는 AI 스튜디오에 이미 설정된 재청구 구성을 그대로 사용하므로 따로 설정할 필요가 없어요.
- 별도로 청구되는 AI 스튜디오 사용: AI 스튜디오에 보낸 메시지는 Cloud 사용이 아니라 AI 스튜디오 사용으로 청구돼요. **Optimize > Send to chat**(최적화 > 채팅으로 보내기)과 Security Advisor의 **Try to fix**(수정 시도) 같은 동작도 여기에 포함돼요.

## 잔액 부족과 지출 한도

지갑 잔액이 부족하거나 지출 한도에 도달하면, 하이퍼클래스는 Cloud를 자동으로 일시정지하기 전에 48시간의 유예 기간을 줘요. 이 시간 동안 결제 문제를 해결하면 중단 없이 계속 쓸 수 있어요.

### 사용량 이메일

스토리지가 포함된 제공량을 넘으면 하이퍼클래스가 에이전시 소유자에게 Cloud 사용량 알림을 보내요. 이 알림으로 추가 요금이 언제부터 부과될지 알 수 있어요.

- 데이터베이스 스토리지: 프로젝트의 데이터베이스 스토리지가 무료 제공량 2 GB를 넘으면 에이전시 소유자에게 이메일이 가요.
- 파일 스토리지: 프로젝트의 파일 스토리지가 무료 제공량 1 GB를 넘으면 에이전시 소유자에게 이메일이 가요.
- 자동 일시정지: 결제 문제로 일시정지가 예정되었을 때, 일시정지 24시간 전, Cloud가 일시정지된 뒤에 에이전시 소유자에게 알림이 가요.

## 자주 묻는 질문

### 유료 인스턴스를 쓰면서 Cloud 무료 제공량도 쓸 수 있나요?

네. 유료 인스턴스를 쓰더라도 모든 프로젝트는 데이터베이스 스토리지 2 GB와 파일 스토리지 1 GB를 무료로 받아요. Tiny 인스턴스도 무료예요.

### 데이터베이스 스토리지를 늘린 뒤에 다시 줄일 수 있나요?

아니요. 데이터베이스 스토리지를 늘리면 해당 Cloud 환경에서는 되돌릴 수 없어요. Cloud를 삭제할 때까지 예약한 크기를 기준으로 요금이 계속 부과돼요.

### 크기를 바꾼 직후에 Cloud를 일시정지해도 요금이 부과되나요?

네. 인스턴스 크기를 바꾼 시간에는 이전 크기와 새 크기 요금이 각각 1시간분씩 부과돼요. 그 시간 안에 일시정지해도 이 요금은 없어지지 않아요. 이후에는 Cloud가 1시간 내내 일시정지 상태인 시간부터 인스턴스 요금이 부과되지 않아요.

### Cloud 요금을 모두 멈추려면 어떻게 하나요?

Cloud를 삭제하면 인스턴스, 데이터베이스 스토리지, 파일 스토리지 요금이 모두 멈춰요. 다만 데이터베이스, 사용자, 파일이 영구적으로 삭제돼요. Cloud를 일시정지하면 1시간 내내 일시정지된 시간의 인스턴스 요금만 멈춰요.

### 에이전시가 Cloud 비용을 서브 계정에 청구할 수 있나요?

네. Cloud는 AI 스튜디오에 설정한 에이전시 재청구 설정을 그대로 사용하므로 따로 설정하지 않아도 돼요.

### 지갑 잔액이 바닥나면 어떻게 되나요?

에이전시 소유자에게 알림이 가는 동안 프로젝트는 48시간 더 실행돼요. 그 사이 문제가 해결되지 않으면 데이터는 삭제하지 않고 Cloud를 자동으로 일시정지해요. 지갑 잔액이 충분해지면 Cloud가 자동으로 다시 깨어나지만, 복구에 시간이 걸릴 수 있어요. **Cloud** 탭의 **Wake up**(깨우기)을 직접 사용할 수도 있어요.

### AI 스튜디오 메시지도 Cloud 요금에 포함되나요?

아니요. **Optimize > Send to chat**과 **Try to fix**를 포함한 AI 스튜디오 메시지는 AI 스튜디오 사용으로 별도 청구돼요.

### 쓰지 않는 스토리지에도 요금이 부과되는 이유가 뭔가요?

데이터베이스 스토리지는 일부 공간이 비어 있어도 예약한 용량을 기준으로 요금이 부과돼요. 반면 파일 스토리지는 무료 제공량을 넘어 실제로 사용한 공간에만 요금이 부과돼요.
