# 관리형 에이전트 게시 취소

관리형 에이전트를 게시 취소하면 지금까지 설정한 내용은 그대로 두고, 자동 트리거만 잠시 운영에서 뺄 수 있어요. 트리거, 앱, 지식, 지침은 그대로 남아 있어서 에이전트를 계속 편집하고 테스트할 수 있어요. 준비가 되면 다시 게시해서 최신 구성으로 운영 트리거를 켜세요.

## 관리형 에이전트 게시 취소란?

관리형 에이전트(Managed Agents)를 게시 취소하면 에이전트를 삭제하거나 구성을 지우지 않고 운영 중인 활동만 잠시 멈춰요. 운영 트리거가 더 이상 실행되지 않고, 대기 중인 예약 실행도 모두 지워져요. 그래서 에이전트는 운영 환경에서 비활성 상태로 유지돼요.

트리거, 앱, 지식, 지침 같은 구성은 그대로 남아요. 게시 취소 상태에서도 빌더에서 에이전트를 편집하고, 초안을 테스트하고, 에이전트와 대화할 수 있어요.

에이전트를 게시 취소할 때 이미 진행 중이던 이벤트는 **Activity history**(활동 기록)에 사유와 함께 **건너뜀**으로 표시돼요. 준비가 되면 에이전트를 다시 게시해서, 가장 최근에 저장한 구성으로 운영에 되돌릴 수 있어요.

{% hint style="warning" %}
게시 취소해도 관리형 에이전트의 구성은 삭제되거나 비활성화되지 않아요. 운영 트리거만 일시 중지하고 설정은 그대로 보존하므로, 에이전트 작업을 계속하다가 준비되면 다시 게시할 수 있어요.
{% endhint %}

## 게시 취소의 장점

- 구성을 잃지 않고 일시 중지할 수 있어요. 에이전트의 트리거, 앱, 지식, 지침은 그대로 두고 운영 트리거만 멈춰요.
- 게시 취소한 동안에도 계속 편집할 수 있어요. 운영 트리거를 다시 켜지 않고 빌더에서 에이전트를 다듬을 수 있어요.
- 실제 운영에 반영하기 전에 변경 사항을 테스트할 수 있어요. 게시 취소 상태에서 테스트 패널로 변경 내용을 확인한 뒤 게시하세요.
- 예약된 활동을 막을 수 있어요. 게시 취소하면 대기 중인 예약 실행이 지워져서 에이전트가 운영에서 비활성 상태로 유지돼요.
- 운영으로 쉽게 되돌릴 수 있어요. 다시 게시하면 최신 구성으로 설정된 트리거가 활성화돼요.

## 관리형 에이전트 게시 취소하는 방법

1. **AI 에이전트 > 에이전트 스튜디오**로 이동하세요.
2. 운영에서 빼려는, 게시된 관리형 에이전트를 여세요.
3. 빌더 오른쪽 위에서 **게시** 옆의 **에이전트 편집** 아이콘을 클릭하세요.
4. 같은 위치에서 **게시** 옆의 점 3개 아이콘을 클릭한 뒤, 드롭다운에서 **게시 취소**를 선택하세요.

게시 취소가 끝나면 빌더에서 에이전트를 계속 편집하거나 테스트할 수 있어요. 에이전트를 운영에 되돌리려면 **게시**를 클릭하세요. 가장 최근에 저장한 구성이 게시되고, 설정해 둔 운영 트리거가 다시 활성화돼요.

## 자주 묻는 질문

### 게시 취소하면 관리형 에이전트가 삭제되나요?
아니요. 에이전트와 구성은 그대로 남아 있어요. 게시 취소는 에이전트를 삭제하는 것이 아니라, 설정해 둔 운영 트리거를 멈추는 기능이에요.

### 게시 취소한 관리형 에이전트도 테스트할 수 있나요?
네. 테스트 패널을 계속 쓸 수 있어서, 다시 게시하기 전에 초안을 확인할 수 있어요.

### 게시 취소한 상태에서도 관리형 에이전트와 대화할 수 있나요?
네. 게시 취소한 상태에서도 관리형 에이전트와 계속 대화할 수 있어요. 게시 취소는 설정해 둔 운영 트리거를 멈추기 위한 기능이고, 에이전트와 직접 대화하는 것을 막지는 않아요.
