# 지식 베이스 검색 도구로 AI 에이전트가 고객 문의에 답하게 하기

에이전트 스튜디오의 **지식 베이스 검색** 도구를 쓰면 AI 에이전트가 선택한 지식 베이스에 저장된 정보로 질문에 답할 수 있어요. 지식 베이스에는 웹사이트 페이지, 자주 묻는 질문, 테이블, 리치 텍스트, 업로드한 파일, 웹 검색 콘텐츠 같은 비즈니스 정보를 담을 수 있어요. 도구를 **AI 에이전트** 노드에 추가하면, 에이전트가 대화 중에 지식 베이스를 검색해서 관련 정보로 답해요.

이 문서에서는 지식 베이스를 만들거나 선택하는 방법, **AI 에이전트** 노드에 도구를 추가하는 방법, 에이전트가 도구를 언제 쓸지 정하는 방법, 응답을 테스트하는 방법을 설명해요.

## 에이전트 스튜디오의 지식 베이스 검색 도구란?

**지식 베이스 검색** 도구는 에이전트 스튜디오의 에이전트와 저장된 비즈니스 정보를 연결해요. 그러면 에이전트가 믿을 수 있는 콘텐츠를 바탕으로 질문에 답할 수 있어요. 지식 베이스는 정보를 정리해 두는 곳이고, 사용자가 질문하면 AI 에이전트가 여기서 답을 찾아요.

에이전트 스튜디오에서 도구를 추가하기 전에 지식 베이스를 먼저 만들어 두세요. 그래야 에이전트가 참고할 콘텐츠가 준비돼 있어요. 이 도구는 에이전트가 아래와 같은 질문에 답해야 할 때 유용해요.

- 상품 또는 서비스 상세 정보
- 고객 지원 주제
- 반품, 환불, 정책 정보
- 문제 해결 방법
- 내부 또는 외부 문서
- 가격 또는 테이블 형태의 정형 데이터
- 자주 묻는 질문

지식 베이스는 **AI 에이전트**(AI Agents) **> 지식 베이스**에서 만들고 관리해요. 만든 지식 베이스는 에이전트 스튜디오의 **지식 베이스 검색** 도구에서 선택할 수 있어요. 지식 베이스에서 지원하는 소스 유형은 다음과 같아요.

- **웹 크롤러:** 웹사이트 페이지를 수집해서 웹사이트 콘텐츠를 지식 베이스의 소스로 쓸 수 있게 해요.
- **자주 묻는 질문:** 에이전트가 참고할 질문과 답변을 저장해요.
- **웹 검색:** 웹 기반 정보 소스를 지식 베이스에 추가해요.
- **테이블:** 가격, 상품 목록, 서비스 정보처럼 표 형태의 정형 데이터를 저장해요.
- **리치 텍스트:** 문서, 정책, 안내문처럼 직접 입력한 텍스트 콘텐츠를 저장해요.
- **파일 업로드:** 지원하는 문서 파일 등 업로드한 문서를 지식 베이스에 추가해요.

{% hint style="info" %}
아직 지식 베이스를 만들지 않았다면, 에이전트에 도구를 추가하기 전에 [지식 베이스 개요](../knowledge-base-overview.md) 문서의 단계를 따라 지식 베이스를 만들고 관리하세요.
{% endhint %}

## 지식 베이스 검색 도구의 주요 장점

이 도구를 쓰면 하이퍼클래스에 이미 추가해 둔 정보를 바탕으로 에이전트가 답해서 응답이 더 정확해져요. 답변이 알려진 비즈니스 콘텐츠에서 나와야 하는 지원, 서비스, 문의 대응 대화에 특히 도움이 돼요.

- **지식에 기반한 답변:** 근거 없는 추측 대신 선택한 지식 베이스의 콘텐츠로 에이전트가 답해요.
- **빠른 고객 지원:** 고객이 상담원의 수동 답변을 기다리지 않고 자주 묻는 질문의 답을 바로 얻을 수 있어요.
- **재사용 가능한 비즈니스 정보:** 이미 갖고 있는 자주 묻는 질문, 문서, 테이블, 리치 텍스트, 웹사이트 콘텐츠를 AI 에이전트에 연결할 수 있어요.
- **일관된 응답:** 관련된 에이전트 대화마다 같은 지식 베이스 콘텐츠를 사용해요.
- **다양한 문의 대응:** 상품, 서비스, 정책, 문제 해결, 가격, 문서 기반 질문에 모두 대응할 수 있어요.

## AI 에이전트에 지식 베이스 검색 도구 설정하기

**지식 베이스 검색** 도구는 지식 베이스가 **AI 에이전트** 노드에 연결돼 있어야 동작해요. 설정 순서는 다음과 같아요. 먼저 지식 베이스를 만들거나 선택하고, 에이전트 플로우를 만들어요. 그다음 에이전트를 시작할 트리거를 추가하고, **AI 에이전트** 노드 안에서 도구를 설정해요.

### 1단계: 지식 베이스 만들기 또는 선택하기

지식 베이스는 **AI 에이전트** 노드가 고객 질문에 답할 때 검색하는 소스 콘텐츠예요.

1. **AI 에이전트 > 지식 베이스**로 이동하세요.
2. 새 지식 베이스를 만들거나 기존 지식 베이스를 여세요.
3. 에이전트가 사용할 소스 콘텐츠(웹사이트 페이지, 자주 묻는 질문, 테이블, 리치 텍스트, 업로드한 파일 등)를 추가하세요.
4. 예상되는 고객 질문에 답하는 데 필요한 정보가 지식 베이스에 들어 있는지 확인하세요.

![지식 베이스를 만들고 소스 콘텐츠를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070673761/original/32YyAfqbb1J7ffyeLX-qvi8piFJRbk7HXg.gif?1778055810)

### 2단계: 에이전트 만들기 또는 열기

에이전트 플로우는 에이전트가 시작된 뒤 대화나 프로세스가 어떻게 진행될지 정해요. 지식 베이스 검색 도구를 쓸 에이전트를 여세요.

1. **AI 에이전트 > 에이전트 스튜디오**로 이동하세요.
2. 새 에이전트를 만들거나 기존 에이전트를 여세요.
3. 에이전트 빌더 캔버스를 여세요.

![에이전트 스튜디오에서 에이전트를 만들고 빌더 캔버스를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070673861/original/nev7FTusRTDo5BkpIHgS3JwW9HEqUptxPw.gif?1778055864)

### 3단계: 에이전트를 시작할 트리거 추가하기

트리거는 에이전트가 언제 실행을 시작할지 정해요. **지식 베이스 검색** 도구가 에이전트를 직접 시작하지는 않아요. 트리거가 에이전트를 시작하면, **AI 에이전트** 노드가 선택한 지식 베이스를 검색해서 관련 질문에 답해요.

- **Chat Message**(채팅 메시지): 에이전트가 들어오는 채팅 메시지에 응답해야 할 때 쓰는 트리거예요. 고객이 채팅에서 지원, 상품, 서비스, 정책, 문제 해결 같은 질문을 바로 하는 경우가 많아서, 이 도구를 가장 흔하게 쓰는 경우예요.
- **폼 제출:** 제출된 폼이 에이전트를 시작해야 할 때 쓰는 트리거예요. **AI 에이전트** 노드가 제출된 폼 내용을 확인한 뒤, 지식 베이스 검색 도구로 다음 단계를 안내하거나 상품·서비스 질문에 답하거나 지원 정보를 제안할 수 있어요.
- **Lead Tag**(리드 태그): 태그를 추가하거나 제거할 때 에이전트를 시작하려면 쓰는 트리거예요. **AI 에이전트** 노드가 지식 베이스 검색 도구로 연락처의 태그와 관련된 정보(온보딩 안내, 상품 상세, 지원 자료, 정책 안내 등)를 제공할 수 있어요.

{% hint style="info" %}
트리거 유형별 자세한 설정 방법은 'How to Set Up Agent Studio Triggers for Real-Time Starts' 문서를 참고하세요.
{% endhint %}

![에이전트를 시작하는 트리거를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070674137/original/c-MFK3AMLYnD7UmX1qr-a43jOgy7upi7Cw.png?1778056012)

### 4단계: AI 에이전트 노드 추가하기

에이전트가 지식 베이스를 검색하고 그 콘텐츠로 답변을 만들려면 AI 추론이 필요해요. 그래서 **지식 베이스 검색** 도구는 **AI 에이전트** 노드 안에서 사용해요.

1. 에이전트 플로우에 **AI 에이전트** 노드를 추가하세요.
2. **AI 에이전트** 노드 설정을 여세요.
3. 노드에 도구를 추가할 수 있는 도구 영역을 찾으세요.

![AI 에이전트 노드를 추가하고 도구 영역을 찾는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070677694/original/Xsss1vDd8StXQeDOKLPkVP-soEWC0k9Kmg.png?1778057817)

### 5단계: 지식 베이스 검색 도구 추가하고 설정하기

**지식 베이스 검색** 도구는 AI 에이전트가 하나 이상의 지식 베이스에 접근해서 관련 정보를 찾고 사용자의 질문에 답하게 해 줘요. 에이전트가 대화 중에 지식 베이스 콘텐츠를 언제 써야 하는지 알 수 있도록 도구를 꼼꼼히 설정하세요.

**AI 에이전트** 노드에 **지식 베이스 검색**을 추가하는 방법은 두 가지예요. 어느 쪽을 써도 같은 도구가 추가되고 같은 설정 패널이 열려요.

- **AI 에이전트 노드 안에서 추가하기:** 이미 **AI 에이전트** 노드를 설정하는 중이고 노드 설정에서 바로 도구를 추가하고 싶을 때 쓰세요. **도구 추가** 드롭다운을 열고 **지식 베이스 검색**을 선택하세요.
- **노드 추가 패널에서 AI 에이전트 노드로 끌어다 놓기:** 캔버스에서 눈으로 보면서 만들고 싶거나, **AI 에이전트** 노드를 먼저 만든 뒤에 도구를 추가하고 싶을 때 쓰세요. **AI 에이전트** 노드 안의 **도구 추가** 필드는 비워 둬도 돼요. 나중에 **노드 추가** 패널에서 **지식 베이스 검색**을 **AI 에이전트** 노드로 끌어다 놓으면 돼요.

도구를 설정하려면 다음 순서로 진행하세요.

1. **AI 에이전트** 노드 안에서 **지식 베이스 검색**을 추가하거나 선택하세요.
2. **안내** 필드에 에이전트가 이 도구를 언제 써야 하는지 적으세요.
3. **Knowledge Base Selection**(지식 베이스 선택)에서 도구가 검색할 지식 베이스를 하나 이상 선택하세요.
4. **저장**을 클릭하세요.

**지식 베이스 검색** 설정 화면에는 다음 요소가 있어요.

- **안내:** AI 에이전트가 이 도구를 언제, 어떻게 써야 하는지 알려 주는 필수 입력 필드예요. 필드 아래 도움말에 따르면, 이 내용은 AI 에이전트가 도구를 언제 써야 하는지 이해하는 데 도움이 돼요.
- **지침 개선:** 저장하기 전에 안내 내용을 다듬거나 보강해 줘요.
- **Variable picker**(변수 선택기): 필요할 때 안내 내용에 동적 값을 넣을 수 있어요.
- **Knowledge Base Selection:** 도구가 검색할 지식 베이스를 하나 이상 선택해요. 이 에이전트가 답해야 할 질문과 가장 관련 있는 정보가 담긴 지식 베이스를 고르세요. 예를 들면 지원 문서, 자주 묻는 질문, 상품 상세, 가격 테이블, 정책, 문제 해결 방법이 있는 지식 베이스예요.
- **취소:** 변경 사항을 저장하지 않고 설정 패널을 닫아요.
- **저장:** 선택한 지식 베이스와 안내 내용을 저장해요. 저장하면 에이전트가 실행될 때 **AI 에이전트** 노드가 이 도구를 쓸 수 있어요.

![지식 베이스 검색 도구 설정 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070678818/original/xyq91SbJV8m9oXCrI5uiXXbUDn98A7cRTw.png?1778058450)

## 지식 베이스 검색 도구 테스트하기

테스트를 하면 에이전트가 선택한 지식 베이스 콘텐츠를 제대로 찾아서 쓰는지 확인할 수 있어요. 안내 내용이 너무 넓은지, 너무 좁은지, 중요한 맥락이 빠졌는지도 알 수 있어요.

지식 베이스 검색 도구를 테스트하려면 다음 순서로 진행하세요.

1. 에이전트 스튜디오에서 에이전트를 여세요.
2. 테스트 대화를 실행하세요.
3. 선택한 지식 베이스에서 답이 나와야 하는 질문을 해 보세요.
4. 응답이 지식 베이스 콘텐츠와 일치하는지 확인하세요.
5. 관련 없는 질문을 해서 에이전트가 지식 베이스를 과하게 쓰지 않는지 확인하세요.
6. 에이전트가 지식 베이스를 너무 자주 쓰거나 충분히 쓰지 않으면 도구의 안내 내용을 조정하세요.
7. 저장한 뒤 다시 테스트하세요.

예를 들어 지식 베이스에 냉장고 상품 정보가 들어 있다면 "삼성 냉장고 가격이 얼마인가요?"처럼 관련된 질문을 해 보세요. 에이전트가 선택한 지식 베이스를 검색해서, 있는 콘텐츠로 답해야 해요.

## 자주 묻는 질문

### 지식 베이스는 어디에서 만드나요?
지식 베이스는 **AI 에이전트 > 지식 베이스**에서 만들고 관리해요.

### 지식 베이스 검색 도구는 어디에서 쓰나요?
에이전트 스튜디오의 **AI 에이전트** 노드 안에서 써요.

### 지식 베이스 검색 도구가 에이전트를 시작하나요?
아니요. 에이전트는 트리거가 시작해요. 지식 베이스 검색 도구는 **AI 에이전트** 노드가 관련 질문에 답해야 할 때 에이전트 로직 안에서 쓰여요.

### 지식 베이스에는 어떤 콘텐츠를 넣을 수 있나요?
**웹 크롤러**, **자주 묻는 질문**, **웹 검색**, **테이블**, **리치 텍스트**, **파일 업로드** 같은 소스 유형의 콘텐츠를 넣을 수 있어요.

### 도구의 안내 내용에는 무엇을 적어야 하나요?
에이전트가 선택한 지식 베이스를 언제 써야 하는지 적으세요. 지식 베이스가 다뤄야 할 주제, 질문 유형, 상황도 함께 적어 주세요.

### 지식 베이스에 없는 질문에도 에이전트가 답할 수 있나요?
지식 베이스 검색 도구는 선택한 지식 베이스의 콘텐츠로 질문에 답하도록 도와줘요. 정보가 없을 때는, 관련 답을 찾지 못한 경우 어떻게 응답할지 에이전트에 추가 안내가 필요할 수 있어요.

### 지식 베이스 검색 도구가 잘 동작하는지 어떻게 확인하나요?
선택한 지식 베이스에서 답이 나와야 하는 질문으로 에이전트를 테스트하고, 응답을 원본 콘텐츠와 비교해 보세요.
