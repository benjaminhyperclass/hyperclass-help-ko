# 에이전트 스튜디오에서 웹 검색 도구로 실시간 답변 만들기

**에이전트 스튜디오**에서 웹 검색 도구가 어떻게 동작하는지, 인터넷의 실시간 정보를 가져오려면 어떻게 설정하는지 알려 드려요. 언제 쓰면 좋은지, 정확하고 믿을 만한 답변을 위해 도구 사용을 어떻게 조절하는지도 함께 다뤄요.

이 문서를 끝까지 읽으면 웹 검색을 다른 도구와 함께 써서 더 똑똑하고 반응이 빠른 AI 에이전트를 만들 수 있어요.

---

## 에이전트 스튜디오의 웹 검색 도구란?

웹 검색 도구는 **AI Agent Node**(AI 에이전트 노드)에서 쓸 수 있는 기능이에요. 에이전트가 인터넷에서 실시간 정보를 가져올 수 있어요. 미리 정해 둔 데이터에만 의존하지 않고, 필요할 때 외부 정보를 그때그때 가져와요.

**AI Agent Node** 안에서 웹 검색 도구는 외부 지식 소스 역할을 해요. 지식 베이스 같은 내부 데이터만 쓰는 대신, 최신 정보나 공개된 정보가 필요한 질문에 이 도구로 답할 수 있어요.

정보가 자주 바뀌거나 내부에 저장되어 있지 않은 질문에 답해야 할 때 특히 유용해요.

### 웹 검색 도구를 쓰면 좋은 때

다음과 같은 질문에 답해야 할 때 웹 검색 도구를 사용하세요.

- 지식 베이스에 없는 내용
- 실시간 정보가 필요한 내용
- 일반 상식에 해당하는 내용

시사 이슈, 시장 동향, 시간이 지나면 바뀔 수 있는 상품 정보가 대표적인 예예요.

### 웹 검색 도구가 동작하는 방식

사용자가 질문하면 에이전트는 요청의 의도를 파악해서 검색 쿼리로 바꿔요. 그다음 웹 검색 도구로 관련 결과를 가져오고, 가져온 정보를 바탕으로 답변을 만들어요.

---

## 웹 검색 도구의 장점

웹 검색 도구를 쓰면 AI 에이전트가 외부 데이터를 실시간으로 활용할 수 있어요.

- 웹의 실시간 정보를 가져올 수 있어요.
- 내부 데이터 소스보다 에이전트가 아는 범위가 넓어져요.
- 미리 알 수 없거나 계속 바뀌는 질문도 처리할 수 있어요.
- 미리 구성해 둔 지식 베이스에 덜 의존해도 돼요.

---

## 웹 검색 도구의 핵심 요소

웹 검색 도구는 세 가지 요소로 설정해요. 이 요소들이 에이전트가 어떻게 검색하고 외부 데이터를 어떻게 쓸지 결정해요. 정확하고 관련성 높은 결과를 얻으려면 세 요소를 잘 이해해야 해요.

### 쿼리

**쿼리**는 웹 검색 도구가 실행될 때 에이전트가 무엇을 검색할지 정하는 항목이에요. 검색 엔진에 전달되는 입력값이라서, 돌아오는 결과가 얼마나 관련 있는지를 좌우해요.

대부분은 고정된 문구보다 사용자 입력을 바탕으로 한 동적인 값을 쓰는 것이 좋아요. 그러면 사용자가 묻는 내용에 따라 다른 검색을 할 수 있고, 답변도 상황에 맞게 나와요.

### 안내

**안내**는 에이전트가 웹 검색 도구를 언제, 어떻게 쓸지 정하는 항목이에요. "내부 데이터가 없을 때만 웹 검색을 사용한다", "실시간 정보가 필요할 때 사용한다"처럼 조건을 적어서 에이전트의 판단을 이끌어요.

안내를 잘 써 두면 불필요한 검색이 줄고, 알맞은 상황에서만 도구를 쓰게 되어 답변 품질을 관리하기 쉬워요. 웹 검색을 지식 베이스 같은 다른 도구와 함께 쓸 때 특히 중요해요.

### 변수

**변수**는 쿼리에 들어가는 동적인 입력값이에요. 사용자와 상호작용하는 내용에 맞춰 에이전트가 검색을 바꿀 수 있게 해 줘요. 보통 대화 중 사용자의 질문이나 입력을 담는 런타임 변수를 써요.

변수를 쓰면 에이전트가 사용자 질문을 검색 요청으로 바꿀 수 있어서, 웹 검색 도구가 유연하게 반응해요. 변수가 없으면 매번 같은 결과만 나와서 실제 상황에서는 쓸모가 떨어져요.

---

## 웹 검색에서 변수 사용하기

웹 검색 도구가 잘 동작하려면 쿼리를 어떻게 정하는지가 중요해요. 고정된 쿼리 대신 런타임 변수를 쓰면 사용자 입력에 맞춰 검색이 달라져요.

사용자가 질문하면 그 입력이 런타임 변수에 저장돼요. 이 변수가 웹 검색 도구의 쿼리로 쓰여서 에이전트가 동적인 검색을 할 수 있어요.

**예시**

- 사용자가 "나이키 러닝화 찾아줘"라고 물어봐요.
- 입력이 변수에 저장돼요.
- 그 변수가 검색 쿼리로 쓰여요.

이렇게 하면 매번 같은 결과를 내놓지 않고, 사용자의 요청에 맞는 결과를 가져와요.

---

## 웹 검색 도구 설정하기

### 1단계: 도구 추가

**AI Agent Node**를 열고 **도구 추가**를 클릭한 다음, 목록에서 **웹 검색**을 선택하세요.

![도구 추가에서 웹 검색을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071476096/original/fNrZgWq_40K3o7i9yKK9tGsT7VTDK5T-Fw.png?1778929268)

### 2단계: 웹 검색 도구 설정

#### 안내 입력

에이전트가 도구를 어떻게 쓸지 정해 주세요. 예를 들어 지식 베이스에 답이 없을 때만 웹 검색을 사용하도록 안내할 수 있어요.

#### 쿼리 정하기

에이전트가 무엇을 검색할지 입력하세요. 고정된 쿼리를 쓰거나, 변수를 넣은 동적인 값을 쓸 수 있어요.

#### 변수 사용

`{}` 선택기로 런타임 변수를 넣으면, 쿼리가 사용자 입력에 따라 달라져요.

아래 예시는 AI 에이전트에 웹 검색 도구를 추가하고, 인터넷의 실시간 정보를 가져오도록 설정한 화면이에요. **안내** 필드에는 도구를 언제 쓸지 에이전트에게 알려 주는 문구를 적어요. 예를 들어 "최신 정보가 필요하면 웹에서 검색하세요."라고 쓰면 에이전트가 검색의 목적을 이해해요.

**쿼리** 필드에는 에이전트가 검색할 내용을 정해요. 고정된 쿼리나 변수를 넣은 동적인 값을 쓸 수 있어요. 대부분은 사용자 입력과 연결해서, 사용자가 묻는 내용을 기준으로 검색하게 하는 것이 좋아요.

필드 안에 보이는 `{}` 변수 선택기로 런타임 변수를 넣을 수 있어요. 이게 중요한 이유는 검색이 동적으로 바뀌기 때문이에요. 매번 같은 결과를 내는 대신, 에이전트가 사용자의 입력을 검색 쿼리로 써요.

이 설정에서는 다음과 같이 동작해요.

- 에이전트는 필요할 때만 웹을 검색하도록 안내받아요.
- 쿼리는 관련 정보를 가져오도록 설정돼 있어요.
- 변수를 쓰면 사용자 입력을 검색에 넘길 수 있어요.

에이전트는 질문을 받으면 이 설정에 따라 웹 검색을 하고, 사용자의 요청에 맞는 결과를 돌려줘요.

{% hint style="info" %}
스크린샷에 나온 **안내**와 **쿼리**는 데모용이에요. 웹 검색 도구가 상황에 맞는 관련 결과를 가져오게 하려면 안내를 분명하게 쓰고, 쿼리에는 변수를 사용하세요.
{% endhint %}

![안내와 쿼리 필드로 웹 검색 도구를 설정한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071476191/original/WEPhFjogrW3IQFMXfQfiij0Y5y29pVNl8w.png?1778929405)

### 3단계: 테스트

다양한 입력으로 에이전트를 **테스트**해서, 웹 검색 도구가 관련성 높고 정확한 결과를 가져오는지 확인하세요.

## 자주 묻는 질문

### 웹 검색 결과가 가끔 달라져요. 왜 그런가요?
웹 검색은 외부 데이터 소스를 이용하고, 외부 데이터는 시간이 지나면서 바뀔 수 있어요. 결과는 쿼리와 그 시점에 인터넷에 있는 정보에 따라 정해지기 때문에 답변이 달라질 수 있어요.

### 지식 베이스 대신 웹 검색은 언제 쓰나요?
통제된 일관된 정보가 필요하면 지식 베이스를 쓰세요. 내부에 없는 정보이거나 실시간 업데이트가 필요하면 웹 검색을 쓰세요.

### 에이전트가 웹 검색을 쓰는 시점을 조절하려면 어떻게 하나요?
프롬프트 안내로 도구 사용을 조절할 수 있어요. 내부 데이터가 부족할 때만 쓰도록 하는 것처럼, 웹 검색을 언제 쓸지 분명하게 적어 주세요.

### 웹 검색 도구가 찾는 내용을 제한할 수 있나요?
네, 안내와 쿼리로 검색 방향을 정할 수 있어요. 특정 유형의 출처나 주제로 범위를 좁히는 것도 가능해요.
