# 에이전트 스튜디오에서 폴더 만들고 관리하기

하이퍼클래스 **에이전트 스튜디오**(Agent Studio)의 폴더 관리 기능을 쓰면 AI 에이전트가 많아도 폴더로 나누고, 검색하고, 한꺼번에 정리할 수 있어요. 이 문서에서는 폴더, 일괄 작업, 서버 기반 페이지 나누기, 보기 설정을 쓰는 방법을 안내해요.

## 폴더 관리란?

폴더 관리는 **에이전트 스튜디오** 목록 페이지에 폴더 단위를 더해 주는 기능이에요. 에이전트를 폴더로 묶고, 일괄 이동·일괄 삭제, 상태 표시, API 기반 페이지 나누기를 쓸 수 있어요. 테스트용 봇 몇 개부터 운영 중인 에이전트 수백 개까지, 놓치는 것 없이 관리할 수 있어요.

## 폴더 관리의 장점

- 구조가 한눈에 보여요: 테스트 중인 에이전트와 운영 중인 에이전트를 나누거나, 팀·고객·프로젝트별로 정리할 수 있어요.
- 정리가 빨라져요: 일괄 작업으로 반복 작업을 줄여요.
- 상태를 바로 알 수 있어요: **Draft**(초안)와 **Published**(게시됨) 표시로 헷갈릴 일이 없어요.
- 많은 에이전트도 빠르게 불러와요: 서버 기반 페이지 나누기와 페이지당 행 수 조절 덕분에 목록이 느려지지 않아요.
- 보기 방식을 고를 수 있어요: 폴더 먼저 또는 에이전트 먼저로 묶고, 이름이나 최근 수정 기준으로 정렬할 수 있어요.
- 실수를 줄여 줘요: 삭제 전에 확인 창이 나와서 실수로 지우는 일을 막아 줘요.

## 폴더 구성

필요한 만큼 최상위 폴더를 만든 다음, 에이전트를 끌어서 옮기거나 일괄 이동할 수 있어요. 폴더 이름을 바꾸거나 폴더를 삭제하는 것은 언제든 할 수 있고, 폴더 안의 에이전트는 그대로 남아요.

### 일괄 작업

에이전트나 폴더를 여러 개 선택하면 다음 작업을 할 수 있어요.

- 일괄 삭제: 선택한 항목을 영구 삭제해요.
- 일괄 이동: 여러 에이전트를 다른 폴더로 한 번에 옮겨요.
- 폴더 일괄 삭제: 쓰지 않는 폴더를 정리해요. 폴더 안의 에이전트는 따로 삭제하기 전까지 남아 있어요.

이 작업들은 사용자 권한에 따라 쓸 수 있고, 실행 전에 영향을 받는 항목 수가 확인 창에 표시돼요.

![일괄 작업으로 에이전트를 선택하고 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066049302/original/Wk2jpP5kcHA1urfpeb5se_garvUg4IslgQ.gif?1772503843)

## 폴더 설정하고 관리하기

다음 순서대로 따라 하면 작업 공간을 깔끔하게 정리할 수 있어요.

### 새 폴더 만들기

1. **에이전트 스튜디오** 오른쪽 위의 **새 폴더**를 클릭해 폴더 만들기 창을 여세요.
2. **폴더 이름** 필드에 알아보기 쉬운 이름을 입력하세요.
3. (선택) **연결된 에이전트** 드롭다운을 열고, 이 폴더에 넣을 에이전트를 선택하세요. 아직 폴더에 속하지 않은 에이전트만 고를 수 있어요.
4. **저장**을 클릭해 폴더를 만드세요. 선택한 에이전트는 목록에서 바로 이 폴더 아래로 묶여 표시돼요.

![새 폴더를 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066049289/original/n4FqSj8jib0DCRSthOCkQU8iCF6Cc_6bNA.gif?1772503741)

### 정렬하고 묶어 보기

**정렬 기준** 드롭다운을 클릭하면 에이전트가 표시되는 방식을 바꿀 수 있어요. **에이전트 우선**과 **폴더 먼저** 중에서 고를 수 있고, **이름**, **최근 수정**, **생성일** 기준으로 정렬할 수 있어요.

![정렬 기준 드롭다운 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066049312/original/Ft4l6JVh6shTZIxxQceA8KT7DoXH2CzZBg.png?1772503900)

### 에이전트 검색하기

오른쪽 위의 **검색** 창에 이름을 입력하면 에이전트를 바로 걸러 볼 수 있어요. 결과가 즉시 바뀌어서 에이전트가 많아도 원하는 에이전트를 쉽게 찾을 수 있어요.

![에이전트를 검색하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066049320/original/wbMIb7vuB0lZwJr7t8aK-WpGf5t0cCt19g.png?1772503946)

### 일괄 작업 사용하기

목록에서 에이전트 옆의 체크박스를 하나 이상 선택하면 일괄 작업을 쓸 수 있어요. 화면 위쪽에 선택한 개수가 표시되어, 다음 작업이 몇 개에 적용되는지 확인할 수 있어요.

1. 에이전트를 선택한 뒤 오른쪽 위의 **일괄 작업** 드롭다운을 클릭하세요.
2. **폴더로 이동** 또는 **삭제**를 선택하면 선택한 항목 전체에 한 번에 적용돼요.
3. 확인 창이 나타나면 다음과 같이 진행해요.
   - **폴더로 이동**: 옮길 폴더를 선택하세요.
   - **삭제**: **에이전트 삭제**를 클릭해 선택한 에이전트의 일괄 삭제를 확정해요.

![일괄 작업 드롭다운과 확인 창 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066049336/original/I59ny1ZPaUmXSQ9ah0M-bhJch9vrDcdsgA.png?1772504007)

### 점 세 개 메뉴

에이전트 행의 점 세 개(**⋮**) 메뉴를 클릭하면 에이전트 하나에 대한 작업을 할 수 있어요. 세부 정보를 **편집**하거나, 에이전트를 **폴더로 이동**하거나, **삭제**할 수 있어요.

![에이전트 행의 점 세 개 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066049608/original/T0N2msAVoeePoCZXsJZfEwa11MUz-uujHQ.png?1772504612)

### 폴더 관리하기

폴더 행에는 폴더 아이콘이 표시되어 에이전트와 쉽게 구분돼요. 폴더 행의 점 세 개 메뉴를 클릭하면 폴더 세부 정보를 편집하거나 폴더 자체를 삭제할 수 있어요.

![폴더 행과 점 세 개 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066049435/original/aR3pwTyNb6zJt7LgJaIAHFwHjXAUIzSigw.jpeg?1772504076)

### 페이지당 표시 개수 바꾸기

목록 아래쪽의 **페이지당 행 수** 드롭다운에서 화면에 보일 에이전트 수를 정할 수 있어요. 10개, 25개, 50개, 100개 중에서 작업 방식에 맞게 고르세요.

![페이지당 행 수 드롭다운 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066048190/original/2y0uat-uGzkLy5OqzEczz5l-_Ip1idj6TA.png?1772499872)

## 자주 묻는 질문

### 폴더를 삭제하면 안에 있는 에이전트도 삭제되나요?
아니요. 에이전트는 **Unfiled**(미분류)로 이동하고, 따로 삭제하기 전까지 계속 사용할 수 있어요.

### 폴더 안에 폴더를 만들 수 있나요?
첫 번째 버전에서는 폴더를 한 단계까지만 만들 수 있어요. 폴더 안에 폴더를 만드는 기능은 이후 업데이트에서 지원할 예정이에요.

### 일괄 작업도 사용자 권한에 따라 달라지나요?
네. 삭제·이동 권한이 있는 사용자에게만 해당 작업이 보여요. 워크플로우 일괄 작업과 같은 방식이에요.

### 서버 기반 페이지 나누기를 쓰면 기존 필터가 바뀌나요?
아니요. 페이지를 넘겨도 적용한 필터는 그대로 유지돼요.

### 지난주에 게시한 에이전트인데 왜 **Draft**(초안)로 보이나요?
게시하면 운영 중인 버전이 만들어져요. 그 뒤에 다시 게시하지 않고 에이전트를 수정하면, 작업 중인 사본이 다시 게시하기 전까지 **Draft**로 표시돼요.

### 두 사용자가 같은 에이전트를 동시에 이동하면 어떻게 되나요?
마지막으로 저장한 변경이 적용돼요. 내가 보고 있는 화면이 최신이 아니면 충돌 알림이 표시돼요.
