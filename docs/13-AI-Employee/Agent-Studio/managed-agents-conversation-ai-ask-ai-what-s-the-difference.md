# 관리형 에이전트, 대화 AI, AI에게 문의: 무엇이 다를까요?

하이퍼클래스의 AI 제품은 **관리형 에이전트**(Managed Agents, 이전 이름: 슈퍼 에이전트), **대화 AI**(Conversation AI), **AI에게 문의**(Ask AI) 세 가지예요. 모두 AI를 쓰지만 대상 사용자, 작업 방식, 자율성 수준이 달라요. 이 문서에서 세 제품을 비교하고, 언제 무엇을 쓰면 좋은지 알려 드려요. 내부 팀과 고객에게 같은 기준으로 설명할 수 있도록 제품별 한 줄 소개도 정리했어요.

## 한눈에 보기

세 제품은 하는 일이 꽤 달라요. 가장 쉬운 구분법은 각 제품이 누구를 위한 기능인지, 누가 먼저 시작하는지를 보는 거예요.

- **AI에게 문의**는 앱 안에서 나를 도와주는 코파일럿이에요. 하이퍼클래스에 로그인한 사용자가 입력이나 음성으로 요청하면 **브랜드 콘텐츠** 작성, 퍼널·커뮤니티 구축, 연락처 요약, **이미지 생성**, 간단한 CRM 작업을 도와줘요. 내가 요청할 때만 움직여요.
- **대화 AI**는 고객을 직접 상대하는 챗봇이에요. 하는 일은 좁지만 깊어요. SMS, 이메일, 웹 채팅, WhatsApp, Facebook, Instagram에서 리드·연락처와 대화하며 질문에 답하고, 리드를 선별하고, 예약을 잡아요. 답변 초안만 만들어 주는 방식(**Suggestive**)과 처음부터 끝까지 알아서 처리하는 방식(**Auto-Pilot**) 중에서 고를 수 있어요.
- **관리형 에이전트**는 **에이전트 스튜디오**에서 자연어로 만드는 맞춤형 AI 팀원이에요. 서브 계정(로케이션) 단위로 CRM 이벤트가 발생하면 시작돼서 일상 업무와 워크플로우를 자동화해요. 하이퍼클래스 안에서도, 커넥터를 통해 바깥에서도 거의 모든 작업을 할 수 있어요. AI 제품군 중에서 활용 범위가 가장 넓은 제품이에요.

간단히 정리하면 이래요.

- 최종 고객에게 응답하고 대화하는 에이전트가 필요하면 **대화 AI**를 쓰세요.
- **관리형 에이전트**는 팀의 한 사람처럼 생각하세요. 직접 작성한 프롬프트에 따라 트리거를 기준으로, 서브 계정(로케이션) 단위에서 일상 업무와 워크플로우를 자동화해요. 하이퍼클래스 안팎에서 모두 일할 수 있어요.

## 제품별 소개

### 관리형 에이전트: 스스로 일하는 팀원

**관리형 에이전트**는 **에이전트 스튜디오**에서 자율적으로 일하는 AI 팀원을 만드는 AI 중심 방식이에요. 기존 챗봇과 달리 에이전트의 역할과 허용할 작업을 일상 언어로 설명하면, 안내형 빌더가 테스트할 수 있는 완성된 에이전트를 만들어 줘요. 노드 기반 빌더의 뒤를 잇는 제품으로, CRM 이벤트로 시작하는 열린 형태의 자동화에 초점을 둬요.

주요 기능과 특징은 다음과 같아요.

- 실제 CRM 이벤트에서 시작해요. 트리거는 **Contact Created**(연락처 생성), **기회 생성**, **기회 상태 변경**, **Tag Changed**(태그 변경), **폼 제출**, **Facebook Lead Form Submitted**(Facebook 리드 폼 제출), **설문이 제출되었습니다**, **예약**, **Chat**(채팅), **일정**이에요. 이런 이벤트가 생기면 에이전트가 자동으로 움직여요.
- 하이퍼클래스 안팎에서 실제로 작업해요. 필드와 태그를 업데이트하고, 워크플로우를 실행하고, 작업·메모·예약을 만들어요. 커넥터를 통해 외부 앱(Monday.com, Cal.com, Higgsfield, 계속 늘어나는 MCP 카탈로그)에도 연결할 수 있어요.
- 근거를 갖고 답해요. **지식 베이스**(문서, 표/CSV, 크롤링한 웹)에서 정보를 가져와요. 실시간 웹 검색을 사용하면 답변 안에 출처가 표시되고, 출처를 클릭해서 확인할 수 있어요.
- 안내형 빌더로, 수정 중심으로 만들어요. 변경을 요청하면 그 부분만 고쳐요. 선택이 모호하면 먼저 되물어요. 모든 트리거, 도구, 지식 베이스는 실제 계정 데이터를 기준으로 하고, 실시간으로 편집할 수 있는 설정 패널에 표시돼요.
- 멀티미디어를 지원해요. 이미지·영상·오디오를 읽고, 편집하고, 만들 수 있어서 **소셜 미디어** 에이전트를 만들 때 유용해요.

### 대화 AI

**대화 AI**는 지원되는 채널에서 연락처와의 대화를 자동화하는 AI 커뮤니케이션 에이전트예요. 들어오는 메시지에 응답하고, 리드 정보를 수집하고, 질문에 답하고, 예약을 잡도록 도와줘요. 어떻게 하는지는 봇을 설정한 방식에 따라 달라요.

주요 특징은 다음과 같아요.

- 여러 채널을 지원해요. SMS, 이메일, Facebook, Instagram, WhatsApp, **채팅 위젯** / SMS 채팅, 실시간 채팅에서 쓸 수 있고, 채널마다 켜고 끌 수 있어요.
- 설정 방법이 세 가지예요. **Guided Form**(안내형 폼, 초보자에게 적합), **Prompt-Based**(프롬프트 기반, 더 세밀한 제어·모델 선택·액션 설정), 시각적인 **Flow-Based Builder**(플로우 기반 빌더, 분기와 여러 단계 로직)가 있어요.
- 실행 모드가 두 가지예요. **Suggestive**는 사람이 검토하고 보낼 수 있도록 답변 초안을 만들어요. **Auto-Pilot**은 자동으로 응답하면서 예약으로 이어지도록 대화를 이끌어요.
- 목적이 분명한 작업에 맞춰져 있어요. 리드 수집, 일반 Q&A, 예약 잡기가 기본이에요. 상담원 연결, 워크플로우 트리거, 자동 후속 연락, 여러 캘린더 예약, 대화 요약 같은 액션도 쓸 수 있어요.

### AI에게 문의

**AI에게 문의**(Ask AI)는 하이퍼클래스 사용자가 플랫폼을 벗어나지 않고 콘텐츠를 만들고, 답을 얻고, 에셋을 생성하고, 지원되는 작업을 끝낼 수 있게 도와주는 내장 AI 코파일럿이에요. 상단 내비게이션 바와 왼쪽 사이드바(전체 화면 작업 공간)에서 열 수 있어요. 에이전시와 서브 계정 모두에서 쓸 수 있고, 텍스트와 음성 프롬프트를 모두 지원해요.

주요 기능은 다음과 같아요.

- 계정의 **Brand Voice**(브랜드 보이스)를 반영한 **브랜드 콘텐츠** 생성: 이메일, 소셜 게시물, 광고, 블로그
- 커뮤니티, 퍼널(**Funnel Creation Agent**, 퍼널 생성 에이전트), **음성 AI 에이전트**를 단계별로 안내받으며 만들기
- 캠페인과 페이지에 쓸 **이미지 생성** 및 편집
- 채팅창에서 바로 실행하는 앱 내 CRM 액션(Skills 기반): 연락처 만들기, 리드 요약, 기회 업데이트, 예약 목록 확인·일정 변경, 태그 적용, 일괄 업데이트 등

## 어떤 제품을 써야 할까요?

먼저 누구를 위한 작업인지, 누가 시작하는지를 따져 본 다음 표에서 찾아보세요.

- 고객과 대화하나요? AI가 메시지 채널에서 리드나 연락처에게 답하고 대화하길 원하면 **대화 AI**예요.
- 앱 안에서 나를 도와줄 도구가 필요한가요? 일하는 동안 콘텐츠 초안을 쓰거나, 무언가를 만들거나, 간단한 작업을 실행해 줄 코파일럿이 필요하면 **AI에게 문의**예요.
- 업무나 워크플로우를 자동화하나요? 트리거에 따라 실행되고, 하이퍼클래스와 연결된 앱 전반에서 여러 단계를 처리하고, 직접 작성한 프롬프트대로 정확히 일하는 팀원이 필요하면 **관리형 에이전트**예요.

| 이런 목표라면 | 이 제품을 쓰세요 |
| --- | --- |
| AI가 SMS, 소셜, 웹 채팅에서 리드·연락처에게 답하고 대화하게 하고 싶어요 | 대화 AI |
| 인바운드 리드를 선별하고, 복잡해지면 사람에게 넘기고 싶어요 | 대화 AI |
| 실시간 대화 중에 예약을 자동으로 잡고 싶어요 | 대화 AI |
| 브랜드 콘텐츠를 쓰고, 퍼널을 만들고, 연락처를 요약하는 데 도움을 받고 싶어요 | AI에게 문의 |
| 앱에서 입력하거나 말로 요청해서 간단한 CRM 작업을 한 번 실행하고 싶어요 | AI에게 문의 |
| CRM 이벤트가 발생할 때 시작되는 일상 업무나 여러 단계의 워크플로우를 자동화하고 싶어요 | 관리형 에이전트 |
| 연락처나 기회가 생성되거나 기회 상태가 바뀔 때 자동으로 반응하게 하고 싶어요 | 관리형 에이전트 |
| AI가 하이퍼클래스 밖에서도 일하게 하고 싶어요(예: Monday.com, Cal.com, 기타 커넥터) | 관리형 에이전트 |
| 지식 베이스 지원 데스크, 소셜 어시스턴트, 캠페인 매니저, 모더레이터처럼 맞춤형 역할을 만들고 싶어요 | 관리형 에이전트 |

## 제품별 한 줄 소개

마케팅, 영업, 고객 지원, 앱 안의 문구에서 아래 표현을 통일해서 쓰세요. "다 똑같은 AI 아니야?" 하는 혼란을 줄일 수 있어요.

| | |
| --- | --- |
| AI에게 문의 | "하이퍼클래스 안에서 일을 끝내도록 도와주는 어시스턴트이자 코파일럿" |
| 대화 AI | "리드와 대화하고 예약을 잡아 주는, 항상 켜져 있는 봇" |
| 관리형 에이전트 | "AI 팀원을 설명하기만 하면 돼요. 대화하고, 내 비즈니스를 알고, 하이퍼클래스와 연결된 앱 전반에서 직접 작업해요." |
