# 에이전트 스튜디오 플로 빌더에서 브랜드 보이스와 브랜드 킷 사용하기

**에이전트 스튜디오**의 **플로 빌더**에서 **브랜드 보이스**와 **디자인 킷**(브랜드 킷)을 바로 적용할 수 있어요. 이렇게 하면 AI 에이전트가 만드는 텍스트, 이미지, 동영상, 오디오에 우리 비즈니스의 메시지와 시각적 정체성이 일관되게 담겨요.

## 브랜드 보이스와 브랜드 킷이란?

**에이전트 스튜디오**에서 **브랜드 보이스**와 **디자인 킷**을 사용하면, 브랜드의 말투와 스타일, 시각적 정체성에 맞는 AI 콘텐츠를 만들 수 있어요.

- **브랜드 보이스**: AI가 만드는 콘텐츠의 어조, 언어, 메시지를 일관되게 유지해요.
- **디자인 킷**(브랜드 킷): 색상, 글꼴, 로고 같은 브랜드의 시각적 정체성을 지원되는 AI 생성 콘텐츠에 적용해요.

**브랜드 보드**에서 메시지, 로고, 색상, 글꼴 등을 수정하면 이후 AI 생성부터 자동으로 반영돼요.

{% hint style="warning" %}
이 문서는 **에이전트 스튜디오**의 **Flow Agent**(플로 에이전트)에 해당하는 내용이에요. **관리형 에이전트**는 사용하는 화면이 달라서, 여기서 설명하는 **생성형 AI** 노드 설정 방식을 따르지 않아요.
{% endhint %}

## 에이전트 스튜디오에서 브랜드 보이스와 디자인 킷 적용하기

1. **AI 에이전트 > 에이전트 스튜디오**로 이동하세요.
2. 기존 **Flow Agent**를 열거나, **플로 빌더**로 새 에이전트를 만드세요.
3. **플로 빌더**에서 **처리 노드 추가**를 클릭하세요.
4. **생성형 AI** 아래에서 **텍스트 생성**, **오디오 생성**, **이미지 생성**, **동영상 생성** 중 하나를 선택하세요.
5. 노드 설정에서 **브랜드 보이스** 드롭다운을 열고 사용할 브랜드 보이스를 선택하세요. **없음**을 선택하거나, **새로 추가 +** 를 선택해 브랜드 보이스를 새로 만들 수도 있어요.
6. **이미지 생성**이나 **동영상 생성**을 쓰는 경우, 브랜드의 시각적 스타일을 적용할 **디자인 킷**을 선택하세요.
7. 나머지 노드 설정을 마치고 **저장**을 클릭하세요.
8. **에이전트 테스트하기**를 눌러 생성된 콘텐츠가 선택한 브랜딩을 따르는지 확인하세요.

설정한 **생성형 AI** 노드가 실행될 때 선택한 브랜드 보이스와 디자인 킷이 적용돼요.

![플로 빌더에서 생성형 AI 노드에 브랜드 보이스와 디자인 킷을 선택하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084539574/original/7fiyDMZRGP99w8AeuNCfXec7Ll9byH_3Zw.gif?1793296818)

## 지원되는 생성형 AI 도구

| 생성형 AI 도구 | 브랜드 보이스 | 디자인 킷 |
| --- | --- | --- |
| 텍스트 생성 | ✓ | — |
| 오디오 생성 | ✓ | — |
| 이미지 생성 | ✓ | ✓ |

{% hint style="info" %}
**생성형 AI** 노드마다 브랜딩 설정을 따로 지정할 수 있어요. 그래서 한 에이전트 플로 안에서 서로 다른 브랜드 킷을 쓸 수도 있어요.
{% endhint %}

## 자주 묻는 질문

### 관리형 에이전트에서도 브랜드 보이스를 쓸 수 있나요?
아니요. 이 문서는 **플로 빌더**의 **생성형 AI** 노드로 브랜드 보이스를 설정하는 방법을 다뤄요. **관리형 에이전트**는 설정 화면이 달라요.

### 에이전트 스튜디오에서 바로 브랜드 보이스를 만들 수 있나요?
네, 가능해요. 지원되는 **생성형 AI** 노드의 **브랜드 보이스** 드롭다운에서 **새로 추가 +** 를 선택하세요.

### 브랜드 보이스 없이 콘텐츠를 생성할 수 있나요?
네, 가능해요. **브랜드 보이스** 드롭다운에서 **없음**을 선택하세요.

### 한 에이전트에서 서로 다른 브랜드 보이스를 쓸 수 있나요?
네, 가능해요. 지원되는 **생성형 AI** 노드마다 브랜드 보이스를 따로 설정할 수 있어요.
