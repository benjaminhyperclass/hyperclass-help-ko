# 에이전트 스튜디오에서 정보 수집 도구로 사용자 입력 받기

**에이전트 스튜디오**(Agent Studio)의 **정보 수집** 도구를 쓰면 대화 중에 이메일 주소, 전화번호, 선택한 옵션, 자유 형식 텍스트 같은 정보를 사용자에게 직접 받을 수 있어요. 이 도구는 **Sequential Node**(순차 노드) 안에서 사용해요. 에이전트가 다음 단계로 넘어가기 전에, 필요한 정보를 한 단계씩 차례로 모을 수 있어요.

## 에이전트 스튜디오의 정보 수집 도구란?

**정보 수집** 도구는 에이전트가 사용자에게 특정 정보를 묻고, 그 답을 저장해 두었다가 대화 뒤쪽에서 쓸 수 있게 해 주는 입력 수집 도구예요.

열린 질문에 대한 답에서 AI가 내용을 이해해 뽑아내는 방식이 아니에요. **정보 수집** 도구는 직접 질문하고, 답을 정해진 형식으로 받아요. 에이전트가 다음으로 넘어가기 전에 연락처, 선호 사항, 주제, 사용자의 선택 같은 필수 정보가 필요할 때 유용해요.

예를 들어 에이전트가 사용자에게 이메일 주소를 받거나, 전화번호를 입력하게 하거나, 목록에서 옵션을 고르게 하거나, 짧은 답변을 입력하게 할 수 있어요. 이렇게 모은 정보는 에이전트 흐름의 다음 노드에서 쓸 수 있어요.

---

## 정보 수집 도구를 쓰면 좋은 경우

에이전트가 다음 작업을 하기 전에 명확하고 정해진 형식의 정보를 모아야 할 때 **정보 수집** 도구를 쓰세요.

자주 쓰는 사례는 다음과 같아요.

- 확인 메시지나 후속 메시지를 보내기 전에 사용자의 이메일 주소 받기
- 리드를 영업 또는 지원 흐름으로 보내기 전에 전화번호 받기
- 올바른 경로로 안내하기 전에 목록에서 옵션 하나 고르게 하기
- 주제, 요청, 질문, 설명 같은 자유 형식 텍스트 받기
- **AI Agent**(AI 에이전트) 노드가 콘텐츠를 만들거나 질문에 답하거나 다른 작업을 하기 전에 필요한 정보 모으기

이 도구는 받을 정보가 예측 가능하고, 정보를 받는 데 AI의 판단이 필요 없을 때 특히 도움이 돼요.

---

## 정보 수집 도구가 동작하는 방식

**정보 수집** 도구는 **Sequential Node** 안에서 동작해요. **Sequential Node**는 설정된 단계를 하나씩 순서대로 실행하므로, 에이전트가 정해진 순서로 정보를 물어볼 수 있어요.

{% hint style="info" %}
**Sequential Node**의 동작 방식은 [에이전트 스튜디오에서 순차 노드로 체계적인 에이전트 흐름 만들기](how-to-build-structured-agent-flows-using-sequential-node-in-agent-studio.md)에서 자세히 볼 수 있어요.
{% endhint %}

**Sequential Node**에 **정보 수집** 도구를 추가하면, 에이전트가 사용자에게 필요한 입력을 요청해요. 사용자가 답하면 그 답이 저장되고, 흐름의 뒤쪽에서 쓸 수 있어요.

예를 들어 다음과 같이 묻는 순서를 만들 수 있어요.

- 이메일 주소가 어떻게 되나요?
- 전화번호가 어떻게 되나요?
- 타겟 고객은 누구인가요?

사용자가 각 질문에 답하면, 수집된 답변을 **AI Agent** 노드 같은 다른 노드로 넘길 수 있어요. 그 노드에서 맞춤 응답을 만들거나 다음 작업을 처리해요.

---

## 사용할 수 있는 정보 수집 도구

에이전트 스튜디오에는 현재 **정보 수집** 도구가 4가지 있어요.

### 이메일 주소

**이메일 주소** 도구는 사용자에게 이메일 주소를 받아요.

확인 메일, 후속 메일, 리드 상세 정보, 신청 안내를 보내는 등 에이전트가 유효한 이메일을 받아야 다음으로 넘어갈 수 있을 때 사용하세요.

**예시:**

자세한 내용을 보내 드릴 수 있도록 이메일 주소를 입력해 주세요.

### 전화번호

**전화번호** 도구는 사용자에게 전화번호를 받아요.

콜백, 영업 적격 판단, 예약 후속 안내, 지원 연결 등을 위해 에이전트가 연락처를 받아야 할 때 사용하세요. 이 도구는 흐름이 계속되기 전에 사용자가 유효한 전화번호를 입력하도록 도와요.

**예시:**

담당 팀이 연락드릴 수 있도록 전화번호를 입력해 주세요.

### 단일 선택

**단일 선택** 도구는 사용자가 미리 정해진 목록에서 옵션 하나를 고르게 해요.

서비스 유형, 관심 수준, 고객 분류, 지원 주제, 다음 단계처럼 정해진 선택지 중에서 고르게 할 때 사용하세요. 선택한 옵션으로 대화를 분기하거나 다음 응답을 맞춤으로 만들 수 있어요.

**예시:**

어떤 도움이 필요하세요?

- 가격 문의
- 통화 예약
- 제품 지원
- 일반 문의

### 텍스트 입력

**텍스트 입력** 도구는 사용자에게 자유 형식 텍스트를 받아요.

주제, 질문, 설명, 사업체 이름, 목표, 특별 요청처럼 사용자가 직접 답을 입력해야 할 때 사용하세요.

**예시:**

어떤 주제로 콘텐츠를 만들까요?

## 순차 노드에서 정보 수집 도구 사용하기

**정보 수집** 도구는 **Sequential Node** 안에 추가해야 해요.

일반적인 구성은 다음과 같아요.

- **채팅 메시지**나 **Lead Tag**(리드 태그) 같은 트리거로 시작해요.
- **Sequential Node**를 추가해요.
- **Sequential Node** 안에 **정보 수집** 도구를 하나 이상 추가해요.
- 각 도구의 프롬프트를 설정해요.
- 사용자의 답을 변수에 저장해요.
- 수집한 값을 다음 노드나 경로에서 사용해요.

예시 흐름은 **채팅 메시지** 트리거로 시작해요. 그다음 **단일 선택** 도구가 들어 있는 **Sequential Node**로 대화가 넘어가요. 사용자가 옵션을 고르면 흐름은 **Router**(라우터)를 거쳐 **Triage Agent**(분류 에이전트)로 이어지고, 대화 설계에 따라 사용자를 알맞은 경로로 보내요.

이렇게 하면 에이전트가 다음에 할 일을 정하기 전에 필요한 입력을 먼저 받을 수 있어요.

---

## 수집된 정보를 흐름 뒤쪽에서 사용하기

수집된 정보는 에이전트 흐름의 뒤쪽에서 **런타임 변수**로 다시 쓸 수 있어요.

사용자에게 받은 답을 이후의 프롬프트, 메시지, 작업에 넣을 수 있다는 뜻이에요.

예를 들어 **Sequential Node**에서 다음 정보를 수집했다고 해 볼게요.

- 주제: 뷰티 분야의 AI
- 타겟 고객: 고령층
- 이메일 주소: user@example.com
- 전화번호: +1 555 123 4567

다음 **AI Agent** 노드는 이 값들을 사용해 아래와 같은 맞춤 결과를 만들 수 있어요.

수집된 주제로 선택된 타겟 고객을 위한 블로그 글을 작성해 줘. 수집된 이메일 주소와 전화번호를 연락처로 넣어 줘.

이렇게 하면 정해진 형식의 데이터 수집과 AI 기반 작업을 연결하면서도, 입력 과정은 예측 가능하게 유지할 수 있어요.

## 에이전트 스튜디오에서 정보 수집 도구 설정하기

다음 단계를 따르세요. 에이전트 흐름에 **정보 수집** 도구를 추가할 수 있어요.

### 1단계: 에이전트 열기

**에이전트 스튜디오**로 이동해요.

편집할 에이전트를 열어요.

### 2단계: 순차 노드 추가 또는 선택

캔버스에 **Sequential Node**를 추가해요. 이미 있는 **Sequential Node** 중에 정보를 받을 노드가 있으면 그 노드를 열어도 돼요.

![캔버스에 Sequential Node를 추가한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070443729/original/2KJB0o6RlzHPsz5FDtE6p510AuK3WTilhw.png?1777776053)

### 3단계: 정보 수집 도구 선택

왼쪽 패널에서 **정보 수집**으로 이동해요.

사용할 수 있는 도구 중에 하나를 골라요.

- **이메일 주소**
- **전화번호**
- **단일 선택**
- **텍스트 입력**

고른 도구를 **Sequential Node** 안으로 끌어다 놓아요.

![정보 수집 도구를 Sequential Node로 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070443736/original/y9DtLbFHSPR9yuQtlgmlW1s8NSyboj6yYQ.png?1777776143)

### 4단계: 프롬프트 설정

에이전트가 사용자에게 할 메시지나 질문을 입력해요.

예시:

- 이메일 주소를 입력해 주세요.
- 연락드릴 전화번호를 알려 주세요.
- 문의 내용에 가장 가까운 옵션을 골라 주세요.
- 어떤 주제로 콘텐츠를 만들까요?

![프롬프트를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070443999/original/YicjbmGtLsOUuwJV8aI_YagdqGnz0hm4sw.gif?1777777821)

### 5단계: 답변을 변수로 저장

수집한 답변에 변수 이름을 지정해 두면 나중에 불러다 쓸 수 있어요.

예시:
`email``phone_number``selected_interest``topic`

이 변수는 에이전트 흐름의 나머지 부분에서 다시 쓸 수 있는 값처럼 동작해요.

### 6단계: 다음 노드 연결

**Sequential Node**가 필요한 정보를 모으고 나면, 흐름의 다음 단계에 연결해요.

연결할 수 있는 대상은 다음과 같아요.

- **Router**
- **AI Agent** 노드
- 확인 메시지
- 다른 작업 또는 처리 노드

예시 화면에서는 **Sequential Node**가 **Triage Agent**에 연결되어 있어요. **Triage Agent**의 라우터 출력은 사용자가 선택한 응답에 따라 서로 다른 후속 에이전트 노드로 이어져요. 수집 단계가 끝나면 흐름이 대화를 알맞은 다음 단계로 보낼 수 있다는 뜻이에요. 예를 들면 은 시세 안내, 투자 관심 안내, 이메일 확인, 투자 안 함 응답, 일반 폴백(기본 응답) 같은 경로가 있어요.

![Sequential Node가 Triage Agent와 후속 노드로 연결된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070444016/original/RYawZMf5tCtp2PLmh06cl13A7wCIOZgn0Q.png?1777778055)

### 7단계: 흐름 테스트

테스트 대화를 실행해서 다음을 확인해요.

- 각 질문이 올바른 순서로 나오는지
- 이메일과 전화번호 입력이 제대로 검증되는지
- **단일 선택** 옵션이 의도한 대로 표시되는지
- 답변이 알맞은 변수에 저장되는지
- 다음 노드가 수집된 정보를 제대로 사용하는지

## 자주 묻는 질문

### 정보 수집 도구는 어디에서 찾을 수 있나요?
**정보 수집** 도구는 **에이전트 스튜디오**의 왼쪽 패널에 있는 **정보 수집** 섹션에서 찾을 수 있어요.

### 어떤 정보 수집 도구를 쓸 수 있나요?
**이메일 주소**, **전화번호**, **단일 선택**, **텍스트 입력** 도구를 쓸 수 있어요.

### 정보 수집 도구는 AI를 사용하나요?
아니요. **정보 수집** 도구는 정해진 형식으로 입력을 받도록 만들어졌고, 답을 받는 데 AI가 필요하지 않아요.

### 어떤 노드에서 정보 수집 도구를 쓸 수 있나요?
**정보 수집** 도구는 **Sequential Node** 안에서 사용해요.

### AI Agent 노드 안에서도 정보 수집 도구를 쓸 수 있나요?
**정보 수집** 도구는 **Sequential Node**에서 쓰도록 만들어졌어요. AI의 판단이 필요하면, 값을 먼저 수집한 뒤에 **AI Agent** 노드를 사용하세요.

### 수집한 정보를 흐름 뒤쪽에서 쓸 수 있나요?
네. 수집한 답변은 변수로 저장해서 이후의 노드, 프롬프트, 메시지, 작업에서 불러다 쓸 수 있어요.

### 단일 선택으로 사용자를 서로 다른 경로로 보낼 수 있나요?
네. 선택한 옵션을 **Router**나 이후 로직에 연결하면 사용자를 알맞은 경로로 보낼 수 있어요.

### 전화번호 도구가 사용자의 번호를 검증해 주나요?
네. **전화번호** 도구는 유효한 전화번호를 받도록 도와요. 입력한 값이 올바르지 않으면 사용자에게 다시 입력을 요청할 수 있어요.

### 텍스트 입력은 어떤 경우에 쓰면 좋나요?
**텍스트 입력**은 주제, 설명, 질문, 사업체 이름, 맞춤 요청 같은 자유 형식 답변을 받을 때 유용해요.
