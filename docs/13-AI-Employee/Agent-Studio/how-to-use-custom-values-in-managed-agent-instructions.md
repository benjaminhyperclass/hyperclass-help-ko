# 관리형 에이전트 지침에서 커스텀 값 사용하기

관리형 에이전트의 지침에는 커스텀 값과 비즈니스 프로필 정보를 바로 넣을 수 있어요. 이 값은 에이전트가 실행될 때마다 자동으로 최신 내용으로 바뀌어요. 그래서 비즈니스 정보를 일일이 고치지 않고도 같은 에이전트를 서브 계정, 템플릿, 스냅샷에서 다시 쓸 수 있어요. 이 문서에서는 관리형 에이전트 지침에 커스텀 값을 넣고, 관리하고, 게시하는 방법을 안내해요.

## 관리형 에이전트 지침의 커스텀 값이란?

커스텀 값은 서브 계정의 정보를 관리형 에이전트 지침으로 가져오는 재사용 가능한 자리표시자예요. 예약 링크, 이메일 주소, 비즈니스 정보를 직접 입력하는 대신 참조를 넣어 두면, 에이전트가 실행될 때마다 현재 값을 자동으로 불러와요.

값은 **설정 > 커스텀 값**에서 수정할 수 있어요. 값을 수정해도 에이전트를 다시 게시할 필요는 없어요.

## 관리형 에이전트에서 커스텀 값을 쓰면 좋은 점

커스텀 값을 쓰면 비즈니스 정보를 일정하게 유지하고, 수동으로 고치는 일을 줄일 수 있어요.

- 에이전트 재사용: 서브 계정별 값을 쓰면서 같은 에이전트를 서브 계정, 템플릿, 스냅샷에서 그대로 쓸 수 있어요.
- 자동 업데이트: 저장된 값을 바꾸면 다시 게시하지 않아도 에이전트의 다음 실행부터 반영돼요.
- 간편한 삽입: **안내** 편집기에서 바로 커스텀 값과 비즈니스 프로필 정보를 넣을 수 있어요.
- 쉬운 게시: 게시하기 전에 비어 있는 값을 찾아서 채울 수 있어요.
- 일관된 정보: 예약 링크, 연락처, 비즈니스 정보를 한곳에서 관리해요.
- 추가 비용 없음: 일반 커스텀 값과 비즈니스 프로필 정보는 같은 텍스트를 직접 입력할 때와 비용이 같아요.

## 사용할 수 있는 커스텀 값과 비즈니스 정보

관리형 에이전트 지침에는 서브 계정에 저장된 정보를 재사용할 수 있어요. 그래서 비즈니스마다 지침을 따로 만들지 않아도 에이전트를 맞춤 설정할 수 있어요. **안내** 영역 상단의 **값 삽입**을 클릭하면 검색할 수 있는 두 가지 분류가 나와요.

- **커스텀 값**: 예약 링크, 지원 이메일처럼 저장해 둔 재사용 정보예요.
- **비즈니스 프로필**: 회사명, 이메일, 전화번호, 웹사이트, 주소, 대표자 정보 등 지원되는 정보예요.

삽입한 값은 이름이 표시된 칩 형태로 나타나요. 커스텀 값 칩에 마우스를 올리면 현재 저장된 값을 볼 수 있어요.

## 커스텀 값 만들고 삽입하기

커스텀 값은 **안내** 편집기에 바로 넣을 수 있어요. **설정**으로 이동하지 않고도 새 값을 만들 수 있어요.

- 기존 값 삽입: 저장해 둔 커스텀 값이나 비즈니스 프로필 정보를 검색해서 선택해요.
- 새 값 만들기: **새 커스텀 값…**을 선택하면 값을 만들고 바로 삽입해요.
- 삽입 위치: 삽입한 값은 현재 커서 위치에 들어가요.
- 값 미리 보기: 커스텀 값 칩에 마우스를 올리면 저장된 정보를 볼 수 있어요.

자세한 내용은 커스텀 값 사용 방법을 참고하세요.

## 비어 있는 커스텀 값과 게시 검증

관리형 에이전트는 지침에서 참조한 커스텀 값이 현재 서브 계정에 있는지 확인해요. 비즈니스 정보가 비어 있는 채로 에이전트가 게시되는 일을 막아 줘요.

- 누락 경고: 없는 값에는 **이 서브 계정에 설정되지 않음**이라고 표시돼요.
- 누락된 값 입력: 안내 아래에 표시되는 입력란에 비어 있는 정보를 입력해요.
- 게시 검증: 비어 있는 값이 있는 상태에서 게시하면 **게시하려면 커스텀 값을 설정하세요** 창이 열려요.
- 저장 및 게시: **저장 및 게시**를 클릭하면 비어 있던 값을 만들고 에이전트를 한 번에 게시해요.
- API 검증: API로 게시할 때도 누락된 값을 확인하고, 누락된 값마다 오류를 알려 줘요.

`Dear {{name}},`처럼 문구 그대로 남겨야 하는 텍스트는 지워지지 않고 그대로 유지돼요.

## AI 빌더와 자동 값 업데이트

AI 빌더는 관리형 에이전트 지침을 만들 때 이미 있는 커스텀 값을 알아볼 수 있어요. 값을 하나하나 찾지 않아도 재사용할 수 있는 지침을 만들 수 있어요.

저장된 링크나 비즈니스 정보를 사용해 달라고 요청하면, 빌더는 이름이 맞는 커스텀 값을 찾아요.

- 맞는 값이 있으면 그 값을 써요.
- 맞는 값이 없으면 입력한 정보를 쓰거나 무엇을 쓸지 되물어요.
- 없는 커스텀 값을 임의로 만들어 내지 않아요.

관리형 에이전트는 실행될 때마다 저장된 최신 값을 불러와요. **설정 > 커스텀 값**에서 커스텀 값을 수정하면, 에이전트의 다음 실행부터 바뀐 정보가 자동으로 쓰여요.

{% hint style="info" %}
일반 커스텀 값과 비즈니스 프로필 정보는 프롬프트 캐싱을 지원해요. 같은 텍스트를 직접 입력할 때와 비교해 추가 비용이 없어요. 날짜/시간 자리표시자는 실행 중에 값이 바뀌어 비용이 늘어날 수 있고, **값 삽입** 목록에는 포함되지 않아요.
{% endhint %}

## 관리형 에이전트 지침에 커스텀 값 넣기

관리형 에이전트 지침에 커스텀 값을 넣으면 에이전트마다 서브 계정에 맞는 정확한 정보를 쓸 수 있어요.

1. **AI 에이전트 > 에이전트 스튜디오**로 이동하세요.

   ![에이전트 스튜디오 메뉴로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084049451/original/1Pb401EM84WoFu0oG08qsIUjVvrw_D-K7Q.png?1792752617)
2. **관리형 에이전트**를 여세요. 이미 저장한 에이전트를 수정하려면 **Edit Agent**(에이전트 편집)를 클릭하세요.

   ![관리형 에이전트를 열고 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084049625/original/hySs1KN433A_7D2evhW-dWUMVUoQ46LHKw.png?1792752692)
3. **안내** 편집기에서 값을 넣을 위치에 커서를 두세요.
4. **안내** 영역 상단의 **값 삽입**을 클릭하세요.

   ![안내 영역 상단의 값 삽입 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084049734/original/wlWk7khad-_O28B1_XhhsiXHWnFYD9cO9g.png?1792752754)
5. **커스텀 값** 또는 **비즈니스 프로필**에서 필요한 값을 검색해 선택하세요.

   ![커스텀 값과 비즈니스 프로필에서 값을 검색하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084049763/original/jA-Fq0FFBt38XzeyeK-Yj1amNgxWZtuLBg.png?1792752790)
6. 새 값이 필요하면 **새 커스텀 값…**을 선택해 값을 만들고 삽입하세요.

   ![새 커스텀 값을 만들어 삽입하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084049891/original/tb0xUmBoOiGiTGqeQBGk384dH3RTHmp5cQ.png?1792752844)
7. 삽입된 값 칩을 확인하고, **이 서브 계정에 설정되지 않음** 경고가 있으면 해결하세요.
8. **게시**를 클릭하세요. 안내가 나오면 비어 있는 값을 입력하고 **저장 및 게시**를 선택하세요.

   ![누락된 값을 입력하고 저장 및 게시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084050214/original/FW7DjCep4g-n5I4VV3zNQ_6ipU_URYu31Q.png?1792752958)

이제 에이전트는 실행될 때마다 서브 계정의 현재 값을 사용해요.

## 자주 묻는 질문

### 커스텀 값을 수정한 뒤에 에이전트를 다시 게시해야 하나요?
아니요. 에이전트가 다음 실행 때 수정된 값을 불러와요.

### 같은 관리형 에이전트를 여러 서브 계정에서 재사용할 수 있나요?
네. 서브 계정마다 저장된 값을 따로 제공하므로, 같은 에이전트 지침으로 서로 다른 비즈니스 정보를 쓸 수 있어요.

### 커스텀 값이 비어 있으면 어떻게 되나요?
하이퍼클래스가 비어 있는 값을 표시하고, 게시하기 전에 값을 입력하라고 안내해요.

### AI 빌더가 없는 커스텀 값을 자동으로 만들어 주나요?
아니요. 빌더는 이미 있는 커스텀 값만 참조해요. 맞는 값이 없으면 입력한 정보를 쓰거나 무엇을 쓸지 되물어요.

### 커스텀 값을 쓰면 에이전트 사용 비용이 늘어나나요?
일반 커스텀 값과 비즈니스 프로필 정보는 같은 텍스트를 직접 입력할 때보다 비용이 늘지 않아요. 날짜/시간 자리표시자는 실행 중에 값이 바뀌기 때문에 비용이 늘어날 수 있어요.

### 에이전트 스튜디오를 나가지 않고 커스텀 값을 만들 수 있나요?
네. **값 삽입** 메뉴에서 **새 커스텀 값…**을 선택하면 값을 바로 만들고 삽입할 수 있어요.
