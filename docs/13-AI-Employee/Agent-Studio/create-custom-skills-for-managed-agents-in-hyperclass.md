# 관리형 에이전트용 커스텀 스킬 만들기

커스텀 스킬을 만들면 자주 쓰는 지침을 한 번만 저장해 두고, 서브 계정의 여러 관리형 에이전트에 가져다 쓸 수 있어요. 에이전트마다 같은 업무 방식이나 서식 규칙, 업무 안내를 반복해서 적을 필요가 없어요. 스킬은 필요한 에이전트에만 켜 두세요. 관리형 에이전트는 관련 있는 스킬을 자동으로 적용해요. 대화 중에 `/` 선택기로 원하는 스킬을 직접 고를 수도 있어요.

## 관리형 에이전트의 커스텀 스킬이란?

커스텀 스킬은 특정 업무를 우리 회사 방식대로 처리하도록 관리형 에이전트에게 알려 주는, 재사용 가능한 지침 모음이에요. 스킬 하나에는 이름, 언제 쓰는 스킬인지 알려 주는 설명, 에이전트가 따를 지침이 들어 있어요. 스킬은 여러 관리형 에이전트가 함께 쓸 수 있어요. 그래서 에이전트마다 같은 안내를 따로 관리하지 않아도 업무 방식을 통일할 수 있어요.

커스텀 스킬은 하이퍼클래스 스킬 플랫폼의 일부예요. 하지만 CRM 작업이나 **지식 베이스** 검색 같은 기능을 제공하는 기본 제공 스킬과는 역할이 달라요. 커스텀 스킬은 에이전트가 반복되는 업무를 어떻게 처리하고, 정해진 절차를 어떻게 따를지에 초점을 맞춰요. 스킬 플랫폼 전반이 궁금하다면 AI 에이전트용 스킬 플랫폼을 참고하세요.

커스텀 스킬은 예를 들어 이런 업무에 쓸 수 있어요.

- 우리 회사 기준으로 리드 선별하기
- 후속 이메일을 정해진 서식으로 작성하기
- 일관된 형식으로 미팅 요약 만들기
- 사내 업무 절차(SOP) 따르기
- 반복 업무에 회사 고유 규칙 적용하기

## 커스텀 스킬을 쓰면 좋은 점

스킬을 재사용하면 설정을 반복하지 않아도 되고, 여러 관리형 에이전트가 같은 운영 기준을 따르게 할 수 있어요. 업무별 지침을 한곳에 모아 두면 에이전트와 활용 사례가 늘어나도 일관된 업무 방식을 유지하기 쉬워요.

- 지침 재사용: 업무별 지침을 한 번 만들어 여러 관리형 에이전트에서 쓸 수 있어요.
- 일관된 에이전트 동작: 에이전트가 같은 선별 기준, 서식, 규칙, 업무 절차를 따르도록 도와줘요.
- 간편한 관리: 에이전트마다 같은 안내를 고치지 않고, 스킬 하나만 수정하면 공유된 지침이 바뀌어요.
- 에이전트별 제어: 각 관리형 에이전트가 하는 일에 맞게 스킬을 켜거나 끌 수 있어요.
- 자동 적용: 요청이 스킬 설명에 맞으면 에이전트가 켜져 있는 스킬을 알아서 적용해요.
- 직접 선택: 에이전트 채팅에서 `/`를 입력하면 사용할 수 있는 스킬 중 하나를 직접 고를 수 있어요.

## 커스텀 스킬의 구성

커스텀 스킬은 분명한 목적과 자세한 지침을 함께 담고 있어요. 그래서 관리형 에이전트가 언제 이 스킬이 필요한지, 요청받은 업무를 어떻게 처리할지 판단할 수 있어요. 두 가지를 꼼꼼히 작성할수록 에이전트가 알맞은 절차를 더 일관되게 고르고 실행해요.

커스텀 스킬은 세 가지 핵심 요소로 이루어져 있어요.

- **이름**: 스킬 라이브러리와 `/` 선택기에서 스킬을 구분하는 이름이에요.
- **설명**: 스킬을 언제 써야 하는지 알려 줘요. 설명이 분명하면 관리형 에이전트가 스킬에 맞는 요청을 더 잘 알아봐요.
- **안내**: 에이전트가 따를 절차, 규칙, 서식 요건 등의 지침을 정해요.

설명에는 스킬 이름을 그대로 반복하지 말고, 스킬이 쓰이는 상황을 적는 것이 좋아요. 예를 들어 리드 선별 스킬이라면 어떤 리드를 평가해야 하는지, 어떤 결과를 내야 하는지를 설명에 적을 수 있어요.

**안내**에는 이런 내용을 넣을 수 있어요.

- 번호를 붙인 절차
- 선별 기준
- 결과물에 필요한 서식
- 업무 규칙
- 제한 사항이나 가드레일
- 꼭 수집해야 할 정보
- 에스컬레이션하거나 다른 작업을 진행할 조건

## 커스텀 스킬, 에이전트 지침, 지식 베이스의 차이

커스텀 스킬, **에이전트 지침**, **지식 베이스**는 모두 관리형 에이전트에 영향을 주지만, 담는 내용의 종류가 달라요. 정보를 알맞은 곳에 두면 에이전트 설정을 이해하고 관리하기가 쉬워져요.

- 커스텀 스킬: 한 개 이상의 관리형 에이전트가 쓸 수 있는, 업무별 재사용 절차에 알맞아요. 리드 선별 규칙, 미팅 요약 형식, 표준화된 후속 절차 등이 그 예예요.
- **에이전트 지침**: 관리형 에이전트 하나에 전반적으로 적용할 행동 방식이나 규칙에 알맞아요.
- **지식 베이스**: 에이전트가 찾아 써야 하는 사실 정보에 알맞아요. 정책, 상품 정보, 자주 묻는 질문, 승인된 참고 자료 등이 그 예예요.

예를 들어 가격 정책은 **지식 베이스**에 두고, 잠재 고객을 선별할 때 에이전트가 따를 구체적인 단계는 커스텀 스킬에 둘 수 있어요.

하이퍼클래스의 **지식 베이스** 도구를 쓰면 에이전트 스튜디오의 에이전트가 답변하거나 작업을 처리할 때 연결된 소스에서 승인된 정보를 가져와 쓸 수 있어요. 자세한 내용은 [에이전트 스튜디오의 지식 베이스 도구](how-ai-agents-use-the-knowledge-base-tool-to-answer-customer-inquiries.md)를 참고하세요.

## 관리형 에이전트별로 커스텀 스킬 켜기

에이전트별 설정으로 각 커스텀 스킬을 쓸 수 있는 관리형 에이전트를 정할 수 있어요. 에이전트가 맡은 역할에 필요한 절차에 집중하게 하면서, 필요하면 다른 에이전트와 같은 스킬을 공유할 수도 있어요.

관리형 에이전트에 커스텀 스킬을 켜 두면, 해당 에이전트는 맞는 요청에 응답할 때 그 스킬을 쓸 수 있어요. 스킬을 다시 만들지 않고도 에이전트에 스킬을 추가하거나 뺄 수 있어요.

새로 만든 스킬은 만든 관리형 에이전트에 자동으로 켜져요. 이후 필요에 따라 다른 관리형 에이전트에서 켜거나 끌 수 있어요.

관리형 에이전트 전체 설정 방법은 [에이전트 스튜디오에서 관리형 에이전트 설정하고 사용하기](setup-and-use-managed-agents-in-agent-studio.md)를 참고하세요.

현재 관리형 에이전트는 **AI 에이전트 > 에이전트 스튜디오 > 관리형 에이전트**에서 확인할 수 있어요.

## 에이전트 채팅에서 커스텀 스킬 사용하기

스킬 선택기를 쓰면 현재 요청에 어떤 스킬을 적용할지 관리형 에이전트에게 바로 알려 줄 수 있어요. 에이전트가 따라 줬으면 하는 절차를 이미 알고 있고, 자동 스킬 매칭에만 맡기고 싶지 않을 때 유용해요.

스킬을 직접 고르려면 다음 순서로 진행하세요.

1. 관리형 에이전트의 채팅을 열어요.
2. 메시지 입력창을 클릭해요.
3. `/`를 입력해요.
4. 사용할 스킬을 검색하거나 선택해요.
5. 나머지 요청 내용을 입력해요.
6. 메시지를 보내요.

![채팅에서 / 를 입력해 스킬을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079852295/original/CdkJ3JTTcckMqNX3RPHNTlk64DSWQnHIbA.png?1788299498)

## 관리형 에이전트용 커스텀 스킬 설정하기

설명이 분명하고 지침이 정확한 스킬을 만들면, 관리형 에이전트가 이 스킬을 언제 써야 하는지와 무엇을 해야 하는지를 모두 잘 이해해요. 스킬을 만든 뒤에는 그 절차가 필요한 에이전트에만 켜 두세요.

### 1. 커스텀 스킬 만들기

1. 해당 하이퍼클래스 서브 계정에 로그인해요.
2. **AI 에이전트 > 에이전트 스튜디오 > 관리형 에이전트**로 이동해요.
3. 설정할 관리형 에이전트를 열어요.
4. **Custom skills**(커스텀 스킬)를 열어요.
5. **Manage skills**(스킬 관리)를 선택해요.
6. **스킬 추가**를 클릭해요.
7. 스킬의 **이름**을 알아보기 쉽게 입력해요.
8. 스킬을 언제 써야 하는지 알려 주는 짧은 **설명**을 입력해요.
9. 관리형 에이전트가 따를 자세한 지침을 **안내**에 입력해요.
10. 지침에 단계, 규칙, 기대하는 결과물이 분명하게 적혀 있는지 확인해요.
11. 스킬을 저장해요.

새로 만든 스킬은 만든 관리형 에이전트에 자동으로 켜져요.

![커스텀 스킬을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079912771/original/FitaGAElGWzXTBdbNIQVbsYK9gXCcxuROA.gif?1788353598)

### 2. 커스텀 스킬 업로드하기

재사용 가능한 스킬 파일로 저장해 둔 지침이 있다면, 지침을 직접 다시 입력하지 않고 **Upload skill**(스킬 업로드) 옵션을 쓸 수 있어요.

1. **Manage skills**를 열어요.
2. **Upload skill**을 클릭해요.
3. 추가할 지침 파일을 선택해요.
4. 가져온 스킬 정보를 확인해요.
5. 이름, 설명, 안내가 해당 업무 절차를 정확히 나타내는지 확인해요.
6. 스킬을 저장해요.
7. 이 스킬을 써야 하는 다른 관리형 에이전트가 있으면 해당 에이전트에도 켜요.

{% hint style="info" %}
파일 요건은 구현 방식에 따라 다를 수 있어요. 스킬을 추가할 때는 관리형 에이전트 업로드 화면에 나오는 파일 옵션을 따르세요.
{% endhint %}

![스킬 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079912889/original/GnqHpEjWltj0DTBOerMlKA-KxYuDCqrQpA.png?1788353637)

### 3. 에이전트별로 스킬 켜기·끄기

1. 관리형 에이전트를 열어요.
2. **Custom skills**를 선택해요.
3. 관리할 스킬을 찾아요.
4. 해당 에이전트에서 스킬을 켜거나 꺼요.
5. 같은 스킬을 쓰거나 그만 쓰게 할 다른 관리형 에이전트가 있으면 같은 방법으로 반복해요.

관리형 에이전트 한 곳에서 스킬을 꺼도 공유 스킬 라이브러리에서 스킬을 삭제할 필요는 없어요.

![에이전트별 스킬 켜기·끄기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079913137/original/KpsadHeLREhROJ6R-p2SAJKhRxf1gQDVGA.png?1788353730)

### 4. 커스텀 스킬 편집하기

1. **Manage skills**를 열어요.
2. 스킬을 검색하거나 선택해요.
3. 편집할 스킬을 열어요.
4. 필요에 따라 설명이나 안내를 수정해요.
5. **변경사항 저장**을 클릭해요.

비슷한 업무를 다루는 스킬이 여러 개라면, 스킬끼리 구분되도록 설명을 구체적으로 적으세요.

![스킬 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079913201/original/obihTrMNGFwm6IPMkA2yahlsuRKCedsocA.png?1788353762)

### 5. 커스텀 스킬 삭제하기

1. **Manage skills**를 열어요.
2. 제거할 스킬을 선택해요.
3. **삭제**를 클릭해요.
4. 화면에 나오는 확인 절차를 따라요.

스킬이 더 이상 필요 없을 때만 삭제하세요. 특정 관리형 에이전트가 그 스킬을 쓰지 않게만 하고 싶다면, 삭제하지 말고 해당 에이전트에서 스킬을 끄세요.

## 자주 묻는 질문

### 커스텀 스킬 하나를 여러 관리형 에이전트가 함께 쓸 수 있나요?
네, 쓸 수 있어요. 커스텀 스킬은 서브 계정의 여러 관리형 에이전트에서 재사용 가능한 지침을 쓸 수 있도록 만들어졌어요. 스킬을 켜 둘 에이전트는 직접 정할 수 있어요.

### 관리형 에이전트가 스킬을 쓰려면 꼭 `/` 명령을 써야 하나요?
아니요. 요청이 스킬에 적힌 목적과 맞으면 관리형 에이전트가 켜져 있는 스킬을 자동으로 적용해요. `/` 선택기는 스킬을 직접 고르고 싶을 때 쓰는 방법이에요.

### 스킬 설명이 왜 중요한가요?
설명은 관리형 에이전트가 이 스킬을 언제 써야 하는지 판단할 근거가 돼요. 목적이 분명하고 구체적인 설명을 쓰면 다른 스킬과 쉽게 구분돼요.

### 회사 정보나 문서를 커스텀 스킬에 저장해도 되나요?
참고용 정보는 보통 **지식 베이스**에 두는 편이 알맞아요. 커스텀 스킬은 재사용할 절차, 규칙, 서식, 업무별 지침에 가장 유용해요.

### 커스텀 스킬은 스킬 플랫폼의 기본 제공 스킬과 같은가요?
아니요. 스킬 플랫폼에서도 CRM 작업, **지식 베이스** 검색, 외부 작업 같은 기능을 '스킬'이라고 불러요. 관리형 에이전트의 커스텀 스킬은 사용자가 직접 정의하는 재사용 지침으로, 특정 업무를 어떻게 처리할지 설명해요.

### 관리형 에이전트의 커스텀 스킬은 **AI에게 문의**의 스킬과 같은가요?
재사용 가능한 지침을 저장한다는 점에서 역할은 비슷하지만, 서로 다른 하이퍼클래스 기능에 속해요. **AI에게 문의**에는 자체 스킬 라이브러리와 동작 방식이 따로 있어요. 이 문서는 관리형 에이전트에서 쓰는 커스텀 스킬만 다뤄요. **AI에게 문의**의 스킬은 [AI에게 문의의 스킬과 커넥터](../Ask-AI/ask-ai-skills-and-connectors.md)를 참고하세요.

### 스킬을 삭제하지 않고 끌 수 있나요?
네, 끌 수 있어요. 특정 관리형 에이전트가 스킬을 쓰지 않게 하면서 다른 에이전트에서는 계속 쓰게 하려면 에이전트별 설정을 이용하세요.

### 비슷한 상황을 다루는 스킬이 두 개 있으면 어떻게 하나요?
각 스킬의 설명을 더 구체적으로 적어서 쓰임새가 분명히 구분되게 하세요. 설명이 서로 다르고 지침이 한 가지에 집중돼 있으면, 에이전트가 어떤 절차를 적용할지 판단하기가 쉬워요.
