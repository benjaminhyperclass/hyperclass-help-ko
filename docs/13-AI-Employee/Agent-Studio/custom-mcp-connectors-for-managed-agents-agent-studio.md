# 관리형 에이전트에 커스텀 MCP 커넥터 연결하기

어떤 MCP 서버든 관리형 에이전트에 연결해서, 외부 서비스나 사내 시스템의 도구를 에이전트가 쓸 수 있게 하는 방법을 안내해요. 커스텀 MCP 커넥터가 무엇인지, **에이전트 스튜디오**(Agent Studio)에서 어떻게 추가하고 설정하는지 알아봐요.

하이퍼클래스의 관리형 에이전트는 커스텀 MCP(Model Context Protocol) 커넥터를 지원해요. 하이퍼클래스 카탈로그에 있는 서버뿐 아니라, 외부 서비스의 MCP 서버나 회사 내부 시스템의 MCP 서버도 연결할 수 있어요.

## 커스텀 MCP 커넥터란?

커스텀 MCP 커넥터를 쓰면 어떤 MCP(Model Context Protocol) 서버든 관리형 에이전트에 연결할 수 있어요. MCP는 AI 에이전트가 외부 도구와 서비스를 표준화된 방식으로 다루게 해 주는 프로토콜이에요.

하이퍼클래스는 자주 쓰는 서비스용으로 미리 만들어 둔 MCP 커넥터 카탈로그를 제공해요. 커스텀 MCP 커넥터를 쓰면 카탈로그에 없는 서버도 연결할 수 있어요. 외부 업체의 MCP 서버나 회사 내부 도구를 연결해서, 비즈니스에 꼭 맞는 기능을 에이전트에 줄 수 있어요.

커스텀 MCP 커넥터에는 서버 이름과 서버 URL이 필요해요. 연결한 뒤에는 그 서버의 도구 중 에이전트가 사용할 도구를 골라서 지정해요.

## 이럴 때 좋아요

- 연동 대상 제한 없음 — 하이퍼클래스 카탈로그에 있는 서버뿐 아니라 어떤 MCP 서버든 연결해서 에이전트의 기능을 자유롭게 넓힐 수 있어요.
- 내부 도구 연동 — 회사 내부 MCP 서버를 연결하면 에이전트가 조직 고유의 시스템과 업무 흐름을 다룰 수 있어요.
- 안전한 인증 — 인증이 필요한 서버는 클라이언트 ID와 클라이언트 시크릿을 설정해서 보호된 리소스에 안전하게 연결해요.
- 도구 단위 선택 — MCP 서버의 도구 중 에이전트가 쓸 도구만 골라서, 에이전트의 기능과 권한을 세밀하게 조절할 수 있어요.
- 외부 서비스 활용 — 에이전트가 외부 MCP 서버에서 작업을 수행해서, 하이퍼클래스 기본 연동 이상으로 자동화 범위를 넓힐 수 있어요.

## 커스텀 MCP 커넥터 추가하기

**에이전트 스튜디오**에서 관리형 에이전트에 커스텀 MCP 커넥터를 추가하는 순서예요.

1. 관리형 에이전트를 만들고 관리하는 **에이전트 스튜디오**를 열어요.

   ![에이전트 스튜디오 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077622333/original/-0F4mUA8AXSZn8KTJIxwhW-MQKcroEB3Rw.png?1785862346)

2. 에이전트 설정에서 MCP 앱을 추가하는 옵션을 클릭해요.

   ![MCP 앱 추가 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077622379/original/ZYNjCuy29k1HLpbyZdvCkNdwJLTC0RKCYQ.png?1785862367)

3. **+ Add custom MCP**(커스텀 MCP 추가) 버튼을 클릭하면 커스텀 커넥터 설정 폼이 열려요.

   ![커스텀 MCP 설정 폼 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077622472/original/1DYv0Q_gtCkQxdwuNWho7XrsBTIcUcQCnw.png?1785862458)

4. MCP 커넥터를 알아보기 쉬운 이름으로 입력하고, MCP 서버가 있는 서버 URL을 입력해요.

   ![서버 이름과 URL 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077622611/original/Ht8uNKPsD_swoN6PFa_rCVxvO30A30pMZg.png?1785862502)

5. **MCP 추가**를 클릭해서 커넥터 설정을 저장해요.
6. 추가한 커스텀 MCP 커넥터를 에이전트에 연결해요. 연결하면 에이전트가 MCP 서버의 도구를 쓸 수 있어요.

   ![MCP를 에이전트에 연결](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077622796/original/3K2N9grPba4SMJGYaQCe8N3syBWslqKeSQ.png?1785862540)

{% hint style="info" %}
커스텀 MCP 커넥터를 추가했어요. 인증이 필요하면 인증 정보를 설정하고, 에이전트가 쓸 도구를 선택하세요.
{% endhint %}

## 커스텀 MCP 인증 설정하기

MCP 서버 중에는 안전하게 연결하려고 인증 정보를 요구하는 서버가 있어요. 하이퍼클래스는 커스텀 MCP 커넥터에 클라이언트 ID와 클라이언트 시크릿을 설정하는 기능을 지원해요.

인증 정보는 다음 순서로 설정해요.

1. 커스텀 MCP 커넥터를 추가하거나 편집할 때, 설정 폼에서 **고급 설정** 섹션을 찾아요.

   ![고급 설정 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077622875/original/Rwxvv6JXcBtTXa_79f2qF9XK92BJEXLI4w.png?1785862618)

2. **Client ID**(클라이언트 ID)에 MCP 서버 제공업체에서 발급받은 클라이언트 ID를 입력해요.
3. **클라이언트 시크릿**에 MCP 서버 제공업체에서 발급받은 클라이언트 시크릿을 입력해요. 이 필드는 보안을 위해 암호화돼요.

{% hint style="info" %}
MCP 서버가 요구할 때만 인증 정보를 설정하세요. 모든 MCP 서버가 인증을 요구하는 것은 아니에요. 인증 요건은 사용하는 MCP 서버의 문서를 확인하세요.
{% endhint %}

## 자주 묻는 질문

### 카탈로그 MCP 커넥터와 커스텀 MCP 커넥터는 어떻게 다른가요?
카탈로그 MCP 커넥터는 하이퍼클래스가 자주 쓰는 서비스용으로 미리 만들어 둔 연동이에요. 커스텀 MCP 커넥터는 서버 URL만 입력하면 어떤 MCP 서버든 추가할 수 있어요. 외부 서비스나 회사 내부 도구도 연결할 수 있어요.

### 커스텀 MCP 커넥터마다 인증을 설정해야 하나요?
아니요. MCP 서버가 요구할 때만 인증 정보(클라이언트 ID와 클라이언트 시크릿)를 설정하면 돼요. 인증이 필요 없는 MCP 서버도 많아요. 인증 요건은 MCP 서버 문서를 확인하세요.

### 커스텀 MCP 커넥터로 우리 회사 내부 시스템을 연동할 수 있나요?
네. 커스텀 MCP 커넥터는 외부 서비스와 내부 도구를 모두 지원해요. 내부 시스템이 MCP 서버를 제공한다면, 커스텀 MCP 커넥터로 관리형 에이전트와 연결할 수 있어요.

### 에이전트 하나에 커스텀 MCP 커넥터를 몇 개까지 추가할 수 있나요?
에이전트 하나에 커스텀 MCP 커넥터를 여러 개 추가할 수 있어요. 정해진 한도는 없지만, 도구가 너무 많으면 에이전트 성능에 영향을 줄 수 있어요. 에이전트가 맡은 용도에 필요한 도구 위주로 추가하세요.

### 커스텀 MCP 서버의 도구 중 에이전트가 쓸 도구를 고를 수 있나요?
네. 커스텀 MCP 커넥터를 추가한 뒤, 그 서버의 도구 중 에이전트가 사용할 수 있는 도구를 직접 선택할 수 있어요. 에이전트의 기능과 보안을 세밀하게 조절할 수 있어요.

### 하이퍼클래스는 앞으로도 카탈로그 MCP 커넥터를 계속 추가하나요?
네. 하이퍼클래스는 미리 만들어 둔 MCP 커넥터 카탈로그를 계속 늘리고 있어요. 커스텀 MCP 커넥터는 아직 카탈로그에 없는 서비스나 내부 도구를 연결할 때 쓰세요.

### 커스텀 MCP 커넥터를 추가하려면 어떤 정보가 필요한가요?
MCP 서버 이름(알아보기 쉬운 이름)과 MCP 서버가 있는 서버 URL이 필요해요. 서버가 인증을 요구하면 클라이언트 ID와 클라이언트 시크릿도 필요해요.

### 커스텀 MCP 커넥터를 추가한 뒤에 편집하거나 삭제할 수 있나요?
네. **에이전트 스튜디오**에서 언제든 커스텀 MCP 커넥터의 설정을 편집하거나 에이전트에서 제거할 수 있어요. 변경 사항은 바로 적용돼요.
