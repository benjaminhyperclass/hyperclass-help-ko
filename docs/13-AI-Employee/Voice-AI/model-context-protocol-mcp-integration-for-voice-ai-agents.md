# 음성 AI 에이전트에 MCP(Model Context Protocol) 연동하기

Model Context Protocol(MCP)을 사용하면 음성 AI 에이전트를 외부 도구·시스템과 연결할 수 있어요. 대화 맥락에 맞는 자동화를 더 똑똑하게 처리할 수 있어요.

이 문서에서는 음성 AI 에이전트에 MCP 연동을 켜고 설정하는 방법을 안내해요. 에이전트가 외부 도구에 접근해 상황에 맞는 작업을 실행하게 만들 수 있어요. **실험실**에서 MCP 지원을 켜고, 사용자 지정 MCP 서버를 추가하고, 도구 접근 권한을 관리하는 방법을 알아보세요.

## Model Context Protocol(MCP)이란?

MCP는 음성 AI 에이전트를 외부 도구·시스템과 이어 주는 연동 방식이에요. 에이전트에 MCP를 추가하면 기본 기능을 넘어 사용자 지정 API, 타사 서비스, 자체 업무 도구까지 사용할 수 있어요.

MCP를 쓰면 AI 에이전트가 표준화된 방식으로 사용 가능한 도구를 찾고, 각 도구의 기능을 파악하고, 대화 맥락에 따라 작업을 실행해요. 그래서 음성 AI 에이전트가 CRM 시스템에서 데이터를 가져오거나, 워크플로우를 실행하거나, 외부 플랫폼과 상호작용하는 일을 자연스러운 대화 흐름을 유지한 채 할 수 있어요.

## 주요 장점

MCP 연동을 쓰면 음성 AI 에이전트를 더 폭넓게 자동화하고 맞춤 설정할 수 있어요. 여러 단계로 이어지는 복잡한 대화도 처리할 수 있어요.

- 에이전트 기능 확장 — 에이전트를 어떤 외부 도구나 API와도 연결해서, 기본 음성 AI 기능을 넘어서는 작업을 하게 할 수 있어요.
- 맥락 기반 자동화 — 도구를 언제 쓸지 조건을 정해 두면, 에이전트가 대화 맥락에 맞는 때에 맞는 작업을 실행해요.
- 간단한 활성화 — 에이전시 **설정**의 **실험실**에서 토글 하나로 MCP 지원을 켤 수 있어요. 복잡한 인프라를 따로 구축하지 않아도 돼요.
- 유연한 도구 관리 — MCP 서버를 여러 개 추가하고, 에이전트마다 쓸 도구를 고르고, 접근 권한을 관리해서 보안과 운영을 통제할 수 있어요.
- 매끄러운 연동 — 워크플로우를 다시 만들지 않고 기존 도구와 서비스를 그대로 연결해요. MCP가 음성 AI 에이전트와 외부 시스템 사이의 다리 역할을 해요.

## MCP 연동의 구성 요소

MCP 연동은 세 가지 구성 요소가 함께 작동해서 음성 AI 에이전트와 외부 도구를 연결해요.
### 구성 요소 1. MCP 서버 설정

사용자 지정 MCP 서버의 연결 정보를 입력해 서버를 추가해요. 연결 정보에는 MCP 이름, 서버 URL, 인증 헤더, 선택 사항인 쿼리 파라미터가 있어요. 이렇게 하면 하이퍼클래스와 외부 도구 사이에 통신 경로가 생겨서, 에이전트가 사용 가능한 서비스를 찾고 상호작용할 수 있어요.

### 구성 요소 2. 도구 관리와 접근 제어

MCP 서버의 도구 중에서 에이전트마다 쓸 수 있는 도구를 고르고, 실행 조건을 정해요. 도구를 언제, 어떻게 쓸지 정해 두면 에이전트가 알맞은 상황에서만 작업을 실행해요. 자동화된 워크플로우를 통제하고 의도하지 않은 동작을 막을 수 있어요.

## MCP 연동 설정하기

다음 단계에 따라 MCP 연동을 켜고 음성 AI 에이전트를 외부 도구와 연결하세요.

### 1단계. MCP 서버 추가

MCP 지원을 켠 뒤, 사용자 지정 MCP 서버의 설정 정보를 입력해 서버를 추가해요.

- **MCP 이름**: 서버를 알아보기 쉽게 구분하는 이름이에요.
- **Server URL**(서버 URL): MCP 서버가 호스팅된 엔드포인트 주소예요.
- **헤더**: API에 접근할 때 필요한 인증 정보나 헤더예요.
- **쿼리 파라미터**(선택 사항): 서버와 통신할 때 필요한 추가 파라미터예요.

### 2단계. 에이전트에 도구 지정

음성 AI 에이전트 설정으로 이동해서 MCP 도구 관리 화면을 열어요. MCP 서버의 도구 중에서 이 에이전트가 쓸 도구를 선택하세요. 에이전트가 맡을 역할과 관련된 도구만 고르는 것이 좋아요.

### 3단계. 도구 실행 조건 정하기

지정한 도구마다 에이전트가 언제 실행해야 하는지 조건을 적어요. 대화 맥락, 사용자 요청, 특정 상황을 기준으로 도구를 언제 실행할지 분명하게 안내하세요.

예를 들어 이렇게 쓸 수 있어요. "고객이 예약 가능한 시간을 물어보면 이 도구를 사용하세요." 또는 "결제 정보를 확인한 뒤에 이 작업을 실행하세요."

### 설정 완료

음성 AI 에이전트가 MCP 도구를 쓸 수 있도록 설정됐어요. 도구 실행 조건에 해당하는 대화를 직접 해 보고, 연동이 제대로 작동하는지 확인하세요.
