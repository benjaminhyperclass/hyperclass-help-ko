# 음성 AI 에이전트 테스트하기

음성 AI 에이전트를 실제 고객에게 연결하기 전에 테스트 통화로 먼저 확인할 수 있어요. 이 문서에서는 **웹 통화**와 **전화 통화** 테스트를 언제 쓰는지, 각각 어떻게 실행하는지, 테스트 통화 로그는 어디서 보는지 알려 드려요. **웹 통화**의 제한 사항과 **발신** 시나리오가 보이지 않을 때 확인할 내용도 함께 안내해요.

테스트 전에 프롬프트의 빈틈, 잘못된 응답, 액션 실패, 전화 연결 문제를 미리 찾아낼 수 있어요. 하이퍼클래스는 브라우저에서 바로 하는 **웹 통화** 테스트와, 실제 전화에 더 가까운 **전화 통화** 테스트를 모두 지원해요. 테스트 통화 로그는 대시보드 분석이나 성과 지표에 영향을 주지 않고 따로 확인할 수 있어요.

{% hint style="warning" %}
**웹 통화**는 전화 환경에서 하는 검증을 대신하지 못해요. 프롬프트와 대화 테스트는 **웹 통화**가 빠르고 편하지만, **웹 통화** 체험 중에는 통화 전환이 지원되지 않아요. 또 브라우저 테스트로는 전화번호 라우팅 전체를 확인할 수 없어요. 전화와 관련된 동작을 확인해야 한다면 출시 전에 **전화 통화** 테스트를 하세요.
{% endhint %}

## 음성 AI 에이전트의 테스트 통화란?

테스트 통화는 실제 고객 대화에 에이전트를 투입하기 전에 직접 대화해 보는 기능이에요. 프롬프트, 지식 베이스 답변, 인사말, 액션, 대화 흐름, 전체적인 통화 경험을 확인하고 출시 전에 문제를 고칠 수 있어요.

하이퍼클래스에는 두 가지 테스트 방법이 있어요. 브라우저에서 빠르게 테스트하는 **웹 통화**와, 실제 전화 연결로 경험을 확인하는 **전화 통화**예요. 테스트가 끝나면 음성 AI 로그에서 통화 기록, 녹음, 결과 같은 통화 상세 정보를 볼 수 있어요.

### 테스트 통화의 장점

테스트를 하면 실제 고객이 쓰기 전에 에이전트를 고쳐 나갈 수 있어요. 상황에 맞는 방법을 고르면 프롬프트 품질 문제와 전화 라우팅·통신 문제도 구분하기 쉬워요.

- **빠른 확인:** 전화번호를 구매하거나 할당하지 않고도 브라우저에서 바로 **웹 통화**를 시작할 수 있어요.
- **실제와 비슷한 테스트:** **전화 통화** 테스트로 실제 전화 연결에서의 동작을 확인할 수 있어요.
- **프롬프트 개선:** 에이전트의 응답을 듣고, 프롬프트나 지식을 고친 뒤 바로 다시 테스트할 수 있어요.
- **액션 테스트:** 지원되는 에이전트 액션이 실제 대화에서 잘 작동하는지 미리 확인할 수 있어요.
- **대화 검토:** 통화 기록과 녹음으로 말의 속도, 응답, 통화 경험을 평가할 수 있어요.
- **깨끗한 분석 데이터:** 테스트 통화는 로그에는 나타나지만 대시보드 분석과 성과 지표에서는 제외돼요.

### 웹 통화와 전화 통화 비교

두 방법은 확인할 수 있는 범위가 달라요. 브라우저에서 빠르게 반복해서 고쳐 볼 때는 **웹 통화**가 좋고, 실제 전화 환경에 따라 달라지는 동작을 확인할 때는 **전화 통화**가 알맞아요.

| 항목 | 웹 통화 | 전화 통화 |
| --- | --- | --- |
| 전화번호 필요 여부 | 필요 없어요 | 설정해 둔 전화 환경을 사용해요 |
| 적합한 용도 | 프롬프트, 응답, 대화 흐름, 지원되는 액션 | 전화 라우팅, 발신자 ID, 통화 전환 경로, 실제 운영과 비슷한 동작 |
| 통화 전환 | **웹 통화** 체험 중에는 지원되지 않아요 | **전화 통화** 테스트로 통화 전환 동작을 확인하세요 |
| 통화 상대 정보 | 체험하는 동안 로그인한 사용자의 연락처를 사용해요 | 테스트용으로 입력한 전화번호를 사용해요 |
| 비용 | 전화번호 설정이 필요 없어요 | 일반 전화 요금이 부과될 수 있어요 |

### 테스트 전에 준비할 것

에이전트와 테스트 환경을 먼저 준비해 두면 잘못된 실패 결과를 줄이고, 실제로 적용할 설정 그대로 테스트할 수 있어요.

- 테스트를 시작하기 전에 최신 에이전트 설정을 저장하세요.
- 프롬프트, 인사말, 지식 베이스, 설정한 액션이 테스트할 준비가 되었는지 확인하세요.
- **웹 통화**를 할 때는 최신 브라우저를 쓰고 마이크 접근을 허용하세요.
- 올바른 입력·출력 장치가 선택되어 있는지 확인하세요.
- 마이크를 쓰고 있는 다른 프로그램은 닫거나 설정을 조정하세요.
- **전화 통화** 테스트를 할 때는 사용할 발신자 ID와 받을 전화번호를 확인하세요.

## 음성 AI 에이전트 테스트 방법

빠르게 대화를 테스트할 때는 **웹 통화**를, 실제 전화 경험을 확인할 때는 **전화 통화**를 사용하세요. 프롬프트, 지식, 액션, 통화 설정을 의미 있게 바꿨다면 다시 테스트해서 출시 전에 최신 설정을 확인하세요.

### 방법 1: 웹 통화 시작하기

**웹 통화**는 브라우저에서 바로 실행돼요. 전화번호를 할당하지 않고도 프롬프트, 응답, 대화 흐름, 지원되는 액션을 가장 빠르게 테스트할 수 있어요.

1. **AI 에이전트 > 음성 AI**로 이동하세요.
2. 테스트할 음성 AI 에이전트를 여세요.
3. **에이전트 테스트하기** 패널을 찾으세요.
4. **웹 통화**를 선택하세요.
5. 사용할 수 있는 **수신** 또는 **발신** 시나리오를 선택하세요.
6. **웹 통화 시작**을 클릭하세요.
7. 마이크 접근을 묻는 창이 나오면 허용하세요.
8. 에이전트와 대화하면서 응답, 액션, 대화 흐름을 확인하세요.

{% hint style="warning" %}
**웹 통화** 제한 사항: **웹 통화** 체험 중에는 통화 전환이 지원되지 않아요. 통화 전환 동작을 확인해야 한다면 **전화 통화** 테스트나 실제로 배포한 전화 환경을 이용하세요.
{% endhint %}

### 방법 2: 전화 통화 시작하기

**전화 통화** 테스트는 설정해 둔 전화 환경을 사용해요. 출시 전에 발신자 ID, 실제 전화 연결, 통화 전환 경로 같은 전화 관련 동작을 확인할 때 알맞아요.

1. 음성 AI 에이전트를 열고 **에이전트 테스트하기**를 찾으세요.
2. **전화 통화**를 선택하세요.
3. 사용할 수 있는 **수신** 또는 **발신** 시나리오를 선택하세요.
4. 에이전트가 전화를 거는 번호로 쓸 **발신자 ID**를 선택하세요.
5. 테스트 전화를 받을 전화번호를 입력하세요.
6. **Call me**(전화 받기)를 클릭하세요.
7. 전화를 받고, 실제 고객처럼 에이전트와 대화해 보세요.

{% hint style="info" %}
요금 안내: **전화 통화** 테스트는 평소 쓰는 전화 환경을 그대로 사용해서 일반 전화 요금이 부과될 수 있어요.
{% endhint %}

## 테스트 통화 기록과 로그

테스트 통화 로그를 보면 에이전트가 테스트 대화를 어떻게 처리했는지 자세히 알 수 있어요. 녹음과 통화 기록을 함께 살펴보면 응답 오류, 타이밍 문제, 침묵, 말 끊김, 액션 동작 같은 개선할 부분을 찾을 수 있어요.

{% hint style="info" %}
분석 데이터 안내: 테스트 통화는 음성 AI 로그에는 나타날 수 있지만 대시보드 분석과 성과 지표에서는 제외돼요.
{% endhint %}

1. **AI 에이전트 > 음성 AI > 대시보드 & 로그**로 이동하세요.
2. **전체 에이전트**를 선택하거나, 테스트한 에이전트를 선택하세요.
3. 날짜 범위에 테스트한 날짜가 들어 있는지 확인하세요.
4. 로그 표에서 **라이브/테스트** 필터를 열고 **테스트**를 선택하세요.
5. 확인할 로그 항목을 열어 통화 상세 정보를 보세요.

| 항목 | 활용 방법 |

| **Call Status**(통화 상태) / **결과** | 테스트가 정상적으로 끝났는지, 통화 문제가 있었는지 확인해요. |
| **통화 기록** | 대화를 빠르게 훑어보고 프롬프트나 지식의 부족한 부분을 찾아요. |
| **녹음 중** | 음성 품질, 말의 속도, 말 끊김, 침묵, 전체적인 통화 경험을 평가해요. |
| **트리거된 액션** | 설정한 액션 중 지원되는 것이 의도한 때에 실행됐는지 확인해요. |
| **통화 요약** | 전체 통화 기록이나 녹음을 보기 전에 대화 결과를 먼저 살펴봐요. |

## 발신 시나리오를 쓸 수 있는 조건

**발신** 테스트 시나리오는 서브 계정이 음성 AI 발신 자격과 규정 준수 요건을 충족해야 쓸 수 있어요. 예전에 따로 있던 **발신 통화 켜기** 설정 과정은 더 이상 발신 통화 약관에 동의하는 필수 경로가 아니에요.

**발신** 시나리오가 보이지 않으면 다음을 확인하세요.

- 서브 계정이 음성 AI 발신 자격 요건을 충족하는지 확인하세요.
- 안내가 나오면 해당하는 KYC 또는 서브 계정 인증 절차를 완료하세요.
- 사용할 수 있는 음성 AI 에이전트와 발신용 전화번호가 있는지 확인하세요.
- 필수 발신 약관에 아직 동의하지 않았다면, 워크플로우에서 **Voice AI Outbound Call**(음성 AI 발신 통화) 액션을 설정하면서 동의할 수 있어요.

자세히 보기: [음성 AI 발신 통화](voice-ai-outbound-calling.md), [음성 AI 발신 통화 규정 준수 확인](voice-ai-outbound-calling-compliance-checks.md)

## 자주 묻는 질문

### 음성 AI 에이전트를 테스트하려면 전화번호를 구매해야 하나요?
**웹 통화**는 구매하지 않아도 돼요. **웹 통화**는 전화번호를 구매하거나 할당하지 않고 브라우저에서 실행돼요. **전화 통화** 테스트는 설정해 둔 전화 환경을 사용해요.

### 테스트 통화도 음성 AI 대시보드 분석에 포함되나요?
아니요. 테스트 통화는 확인할 수 있도록 로그에는 나타나지만, 대시보드 분석과 성과 지표에서는 제외돼요.

### 완료된 테스트 통화는 어디서 찾나요?
**AI 에이전트 > 음성 AI > 대시보드 & 로그**로 이동해서 에이전트와 날짜 범위를 확인한 뒤, **라이브/테스트** 필터로 테스트 통화를 표시하세요.

### 테스트 통화의 통화 기록과 녹음도 볼 수 있나요?
네. 통화 기록과 녹음이 있고 처리가 끝났다면 테스트 통화 로그에서 볼 수 있어요.

### 웹 통화로 통화 전환을 테스트할 수 있나요?
아니요. **웹 통화** 체험 중에는 통화 전환이 지원되지 않아요. 통화 전환 동작을 확인하려면 **전화 통화** 테스트나 실제로 배포한 전화 환경을 이용하세요.

### 대시보드 & 로그에서 테스트 통화가 안 보여요.
선택한 에이전트, 날짜 범위, **라이브/테스트** 필터를 확인하세요. 테스트 통화가 정상적으로 끝났는지도 확인하고, 통화 상세 정보가 처리될 때까지 잠시 기다려 보세요.

### 출시 전에는 어떤 테스트 방법을 써야 하나요?
