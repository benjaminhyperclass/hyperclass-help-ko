# 음성 AI 에이전트에 지식 베이스 연동하기

음성 AI 에이전트마다 전용 지식 베이스를 연결하면, 통화 중 고객의 질문에 정확하고 상황에 맞는 답변을 할 수 있어요. 이 문서에서는 지식 베이스 연동의 설정 방법과 관리 요령을 안내해요.

## 음성 AI 지식 베이스 연동이란?

음성 AI 지식 베이스 연동을 쓰면 하이퍼클래스의 음성 AI 에이전트마다 지식 베이스를 하나씩 지정할 수 있어요. 사용자가 말한 내용이 설정해 둔 트리거 프롬프트와 맞으면, 에이전트가 연결된 지식 베이스를 자동으로 검색해 가장 관련 있는 답변을 전달해요. 그래서 음성 에이전트가 비즈니스에 맞는 최신 답변을 할 수 있어요.

## 주요 장점

- 에이전트별 맞춤 응답: 에이전트마다 다른 지식 베이스를 지정해서, 에이전트의 분야나 역할에 맞는 답변을 하게 할 수 있어요.
- 트리거 기반 활성화: 커스텀 프롬프트로 지식 베이스를 언제 조회할지 정확히 정할 수 있어요. 사용자의 의도에 맞게 답변을 조절할 수 있어요.
- 실시간 동적 답변: 음성 에이전트가 사용자의 질문을 분석해 지식 베이스에서 알맞은 답을 바로 찾아와요.
- 간편한 업데이트: 지식 베이스를 수정하면 에이전트 답변에 바로 반영돼요. 추가 설정은 필요 없어요.
- 확장과 유지 관리가 쉬움: 복잡한 로직이나 별도 개발 없이 여러 에이전트와 지식 베이스를 관리할 수 있어요.

## 설정 방법

설정을 제대로 해 두면 음성 AI 에이전트가 상황에 맞는 정확한 답변을 하는 데 도움이 돼요. 아래 단계에 따라 에이전트에 지식 베이스를 연동하세요.

### 1단계: 음성 AI 에이전트 화면 열기

1. 하이퍼클래스 계정에서 **AI 에이전트 > 음성 AI**를 클릭하세요.

   ![음성 AI 메뉴 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046776161/original/ymUGO2sv0S4ftb8vi5i6kQ0jzETd0ani0w.png?1747410217)

### 2단계: 기존 에이전트를 편집하거나 새 에이전트 만들기

- 새 에이전트를 만들 수 있어요. 만드는 방법은 음성 AI 에이전트 만들기 가이드를 참고하세요.
- 기존 에이전트를 편집할 수도 있어요.
- 편집하려면 에이전트 이름 옆의 점 3개 아이콘을 클릭하고 **편집**을 선택하세요.

  ![에이전트 이름 옆 점 3개 메뉴에서 편집 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046776495/original/-YIkGk_vCPz9NKt3aGw7W7yUKwEXWpqg9A.png?1747410561)

### 3단계: 에이전트 목표 탭으로 이동하기

1. 에이전트 편집 화면에서 **에이전트 목표** 탭을 클릭하세요. 이 탭에서 에이전트의 성격과 동작 방식을 설정할 수 있어요.
2. **지식 베이스 선택**에서 기존 지식 베이스를 고르세요. 새로 만들려면 **새로 만들기**를 클릭하세요.

{% hint style="info" %}
팁: 에이전트의 역할이나 상대하는 고객에 맞는 지식 베이스를 지정하세요(예: 영업, 상품 지원).
{% endhint %}

![에이전트 목표 탭의 지식 베이스 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046776949/original/Uvc_ds_usGtNRCjJFD733aRKVA-bevndJQ.png?1747411107)

### 4단계: 지식 베이스를 사용할 시점 정하기(트리거 프롬프트)

1. **이 지식 베이스를 사용할 시점** 필드에, 에이전트가 언제 지식 베이스를 활성화할지 알려 주는 프롬프트를 자세히 입력하세요.

   예시: "사용자가 비즈니스, 서비스, 상품, 연락처 등 관련 정보에 대해 질문하면 이 지식 베이스를 사용하세요. 정확하고 최신 정보를 안내하려면 비즈니스 위키를 참고해야 합니다."

### 5단계: 프롬프트를 명확하고 자세하게 쓰기

1. 프롬프트를 잘 써 두면 에이전트가 질문을 더 정확하게 찾아 연결해요. 지시가 구체적일수록 실시간 응답이 더 좋아져요.
2. **저장**을 클릭하면 설정이 적용되고 지식 베이스가 에이전트에 연결돼요.

## 지식 베이스 관리 모범 사례

지식 베이스를 잘 활용하려면 설정만 해서는 부족해요. 사전 계획, 프롬프트 설계, 콘텐츠 관리, 성과 모니터링도 함께 해야 해요.

- 여러 지식 베이스 관리하기
  에이전트마다 다른 지식 베이스를 지정하면 부서, 상품, 서비스별로 답변을 맞출 수 있어요.

  - 영업, 지원, 상품 정보 등 용도별로 지식 베이스를 따로 만드세요.
  - 각 에이전트에 알맞은 지식 베이스를 연결해 전문성을 높이세요.
- 트리거 프롬프트 최적화하기
  트리거 프롬프트를 잘 쓰면 에이전트가 알맞은 때에 지식 베이스를 조회해요.

  - 사용자가 자주 하는 질문의 의도에 맞게 명확하고 구체적으로 쓰세요.
  - 여러 프롬프트를 테스트해서 고객에게 가장 잘 맞는 것을 찾으세요.
- 지식 베이스 콘텐츠 업데이트하기
  지식 베이스를 최신 상태로 유지해야 에이전트 답변이 정확해요.

  - 문서나 자주 묻는 질문을 정기적으로 검토하고 업데이트하세요.
  - 수정한 내용은 모든 에이전트 대화에 바로 반영돼요.
- 에이전트 성과 모니터링하기
  지식 베이스가 얼마나 자주 조회되는지, 답변 품질은 어떤지 확인하세요.

  - 분석 기능으로 지식 베이스에서 부족한 부분을 찾으세요.
  - 사용자 피드백과 에이전트 로그를 보고 프롬프트나 콘텐츠를 다듬으세요.

## 자주 묻는 질문

### 음성 AI 에이전트 하나에 지식 베이스를 두 개 이상 연결할 수 있나요?
현재는 에이전트 하나에 지식 베이스를 한 번에 하나만 연결할 수 있어요.

### 사용자의 말이 트리거 프롬프트와 맞지 않으면 어떻게 되나요?
지식 베이스를 조회하지 않고, 에이전트가 기본 동작대로 응답해요.

### 기본(Basic) 모드와 고급(Advanced) 모드 모두에서 쓸 수 있나요?
네, **에이전트 목표**에서 **Basic**(기본) 모드와 **Advanced**(고급) 모드 모두 지식 베이스 연동을 쓸 수 있어요.

### 지식 베이스를 수정하면 에이전트 응답에 얼마나 빨리 반영되나요?
바로 반영돼요. 지식 베이스를 바꾸면 에이전트가 즉시 그 내용을 쓸 수 있어요.

### 연결할 수 있는 지식 베이스의 크기에 제한이 있나요?
공개된 제한은 없어요. 다만 지식 베이스가 아주 크면 성능이 달라질 수 있어요.

### 에이전트마다 트리거 프롬프트를 다르게 설정할 수 있나요?
네, 에이전트마다 고유한 트리거 프롬프트를 설정할 수 있어요.

### 외부(타사) 지식 베이스도 연동할 수 있나요?
현재는 하이퍼클래스에 기본으로 있는 지식 베이스용으로 만들어진 기능이에요.

### 지식 베이스 연동이 제대로 작동하는지 어떻게 확인하나요?
에이전트 설정의 테스트 기능을 쓰거나, 트리거 프롬프트에 맞는 말로 에이전트와 직접 대화해 보면서 응답을 확인하세요.
