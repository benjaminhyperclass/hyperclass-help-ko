# 플로 빌더 템플릿과 안내형 설정으로 음성 AI 에이전트 만들기

자주 쓰는 통화 유형별 템플릿으로 음성 AI 에이전트를 빠르게 시작하는 방법을 안내해요. 템플릿을 고르면 하이퍼클래스가 기본 지침과 액션을 자동으로 추가하고, 사용자는 아직 입력이 필요한 설정만 마무리하면 돼요. 이번 업데이트로 새 **Update Tag**(태그 업데이트) 액션과 더 알기 쉬운 설정 안내도 추가됐어요. 에이전트를 테스트하고 배포하기 전에 준비 상태를 확인하는 데 도움이 돼요.

## 플로 빌더 안내형 설정이란?

**플로 빌더**는 통화 중에 에이전트가 따를 지침과 액션을 서로 연결해서 음성 에이전트를 만드는 화면이에요. 이제 안내형 설정으로 자주 쓰는 업무 상황에 맞는 템플릿에서 바로 시작할 수 있어요.

템플릿은 미리 만들어 둔 시작점이에요. 템플릿을 고르면 하이퍼클래스가 에이전트의 주요 지침과 관련 액션을 플로 빌더에 자동으로 추가해요.

액션을 하나하나 직접 설정하지 않아도 돼요. 에이전트가 할 일을 고른 뒤, 만들어진 설정을 필요에 맞게 고치면 돼요.

하이퍼클래스는 미리 구성된 템플릿 5개를 제공해요.

- **비즈니스 FAQ 어시스턴트:** 영업시간, 가격, 서비스, 정책처럼 비즈니스에 대한 자주 묻는 질문에 답해요.
- **프런트 데스크 안내원:** 전화를 건 사람에게 인사하고, 용건을 파악해서 알맞은 담당자에게 연결하도록 도와요.
- **리드 자격 검증:** 자격 확인 질문을 하고, 연락처 정보를 저장하고, 결과에 따라 태그를 달아요.
- **통화 후 자동화:** 통화가 끝난 뒤 태그 추가나 워크플로우 시작 같은 후속 작업을 처리해요.
- **SMS 후속 조치:** 통화가 끝난 뒤 전화를 건 사람에게 문자 메시지를 보내요.

직접 설정하고 싶다면 **커스텀 에이전트 만들기**를 선택하세요.

{% hint style="info" %}
기존 음성 AI 에이전트는 이번 업데이트로 바뀌지 않아요. 현재 지침과 액션이 설정한 그대로 유지돼요.
{% endhint %}

## 플로 빌더 템플릿의 장점

템플릿과 안내형 설정을 쓰면 사용 가능한 음성 AI 에이전트를 만드는 수작업이 줄어들어요. 테스트나 출시 전에 아직 손봐야 할 부분을 확인하기도 쉬워요.

- **빠른 설정:** 자주 쓰는 통화 유형에 맞는 지침과 액션이 이미 추가된 상태로 시작해요.
- **초보자에게 맞는 시작점:** 모든 액션을 처음부터 정하는 대신 비즈니스 목표를 골라요.
- **수정할 수 있는 설정:** 템플릿을 고른 뒤에도 에이전트 지침, 액션, 설정을 바꿀 수 있어요.
- **알기 쉬운 설정 안내:** 입력이 더 필요한 액션을 하이퍼클래스가 알려 줘요.
- **미완료 액션으로 바로 이동:** 대기 중인 항목을 클릭하면 손봐야 할 설정이 열려요.
- **언제든 진행 상황 저장:** 완성하지 못한 에이전트도 저장해 두었다가 나중에 이어서 설정할 수 있어요.
- **통화 결과 기록:** 새 **Update Tag** 액션으로 연락처에 유용한 태그를 추가할 수 있어요.

## 음성 AI 에이전트를 만드는 방법 선택하기

음성 AI 에이전트를 만드는 방법은 여러 가지예요. 이 문서에서 설명하는 안내형 설정과 미리 만들어진 사용 사례는 **플로 빌더**를 선택하면 쓸 수 있어요.

음성 AI 에이전트를 만들 때 다음과 같은 옵션이 보일 수 있어요.

- **마켓플레이스 둘러보기:** 마켓플레이스에 있는 에이전트로 시작해요.
- **커스텀 에이전트 만들기:** 기본 설정 방식으로 에이전트를 만들어요.
- **플로 빌더:** 통화 흐름을 시각적으로 만들고, 새로 나온 미리 구성된 템플릿을 사용해요.

안내형 사용 사례에서 시작하려면 **플로 빌더**를 선택하세요.

![에이전트 만들기 방법 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079933973/original/tVyTK44ZU4H8Y8yVjIsFjlrRvmakFwoiqQ.png?1788362591)

## 미리 구성된 음성 AI 템플릿

미리 구성된 템플릿은 자주 있는 비즈니스 통화에 맞춘 시작 설정이에요. 각 템플릿에는 음성 대화에 맞게 만든 지침과, 선택한 사용 사례에 맞는 액션이 들어 있어요.

**플로 빌더**를 선택하면 다음 중에서 고를 수 있어요.

### 비즈니스 FAQ 어시스턴트

에이전트가 가지고 있는 지식을 바탕으로 비즈니스에 관한 자주 묻는 질문에 답하게 하고 싶을 때 선택하세요.

예를 들면 이런 질문이 있어요.

- 영업시간이 어떻게 되나요?
- 서비스 비용은 얼마인가요?
- 어떤 서비스를 제공하나요?
- 취소 정책은 어떻게 되나요?

### 프런트 데스크 안내원

전화를 건 사람에게 인사하고, 전화한 이유를 파악해서 알맞은 담당자나 팀에 연결하게 하고 싶을 때 선택하세요.

### 리드 자격 검증

에이전트가 자격 확인 질문을 하고, 전화를 건 사람에 대한 유용한 정보를 저장하게 하고 싶을 때 선택하세요.

다음과 같은 작업에 도움이 돼요.

- 연락처 정보 수집
- 자격 확인 질문
- 연락처 정보 업데이트
- 결과에 따라 태그 추가

### 통화 후 자동화

통화가 끝난 뒤 처리할 작업이 있을 때 선택하세요.

예를 들어 에이전트가 다음 작업을 도와요.

- 태그 추가
- 연락처 정보 업데이트
- 워크플로우 시작

### SMS 후속 조치

대화가 끝난 뒤 에이전트가 문자 메시지를 보내게 하고 싶을 때 선택하세요.

문자 메시지에는 예를 들어 다음 내용을 담을 수 있어요.

- 확인 안내
- 링크
- 견적
- 후속 안내 정보

### 커스텀 에이전트 만들기

맞는 템플릿이 없거나 에이전트를 직접 만들고 싶다면 **커스텀 에이전트 만들기**를 선택하세요.

특정 사용 사례에 맞춘 액션 묶음이 자동으로 추가되지 않고, 기본적인 에이전트만 만들어져요.

![미리 구성된 템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079934196/original/B9G-3C5u6DvBqT8hh9AhcjuClfMiVk6P5g.png?1788362727)

## 음성 액션이란?

음성 액션은 에이전트가 통화 중이나 통화 후에 수행하는 작업이에요. 액션 덕분에 에이전트가 통화 상대와 대화하는 것 이상의 일을 할 수 있어요.

설정에 따라 쓸 수 있는 액션은 다음과 같아요.

- **Tag contact**(연락처 태그 지정): 연락처에 태그를 추가해요.
- **SMS 전송:** 전화를 건 사람에게 문자 메시지를 보내요.
- **이메일 보내기:** 이메일을 보내요.
- **Custom API**(커스텀 API): 외부 시스템으로 정보를 보내요.
- **워크플로우 트리거:** 연락처를 하이퍼클래스 워크플로우에 추가해요.
- **통화 전환:** 전화를 건 사람을 다른 전화번호로 연결해요.
- **연락처 필드 업데이트:** 대화에서 얻은 정보를 연락처 정보에 저장해요.

템플릿이 관련 액션을 자동으로 추가해 주지만, 에이전트에 필요한 대로 액션을 편집하거나 제거하거나 추가할 수 있어요.

![음성 액션 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079934290/original/7fXaE2aWaY9IEoI0R1mGbIX42hv9nC21xA.png?1788362804)

## Update Tag 액션 사용하기

**Update Tag** 액션을 쓰면 음성 AI 에이전트가 대화 결과를 연락처 태그로 저장해요. 연락처를 정리하기 쉬워지고, 통화 결과를 하이퍼클래스의 다른 기능에서도 활용할 수 있어요.

예를 들어 에이전트가 다음과 같은 태그를 추가할 수 있어요.

- 적격 리드
- 관심 없음
- 후속 조치 필요
- 예약됨

태그는 다음 작업에 도움이 돼요.

- 연락처 정리
- 스마트 리스트 만들기
- 워크플로우 시작
- 후속 캠페인 만들기

예를 들어 전화를 건 사람이 자격 요건을 충족하면 에이전트가 '적격 리드' 태그를 추가할 수 있어요. 그러면 워크플로우가 이 태그를 기준으로 영업 과정의 다음 단계를 시작할 수 있어요.

액션을 설정할 때는 태그를 언제 적용해야 하는지 에이전트가 알 수 있도록 트리거 조건을 분명하게 입력하세요.

![Update Tag 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079934718/original/Nk5DIcYNRWQB91E0c2G2pKZSGahHjTLE-g.png?1788363027)

## 안내형 설정 알림

안내형 설정 알림은 설정이 덜 끝난 액션을 찾아 줘요. 플로 빌더 전체를 뒤지지 않아도, 입력이 더 필요한 항목을 목록으로 볼 수 있어요.

필수 액션 중 설정이 끝나지 않은 것이 있으면 **에이전트 설정 완료하기**가 보일 수 있어요.

알림에는 다음과 같은 미완료 항목이 나올 수 있어요.

- **Transfer Call**(통화 전환)
- **이메일 보내기**
- **Custom API**
- **워크플로우 트리거**
- **연락처 필드 업데이트**

목록의 항목을 클릭하면 손봐야 할 액션이 열려요.

하이퍼클래스가 관련 액션으로 자동 이동하므로 바로 설정을 마칠 수 있어요.

설정할 액션이 여러 개라면 각각 따로 표시되니, 하나씩 차례로 처리하면 돼요.

![에이전트 설정 완료하기 알림 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079936693/original/b0gr3u29nhOGEr-Ri8I_vlzcMy8iyoy4hw.png?1788364014)

## 에이전트 저장, 테스트, 배포

하이퍼클래스에서는 작업 내용을 저장하는 것과 에이전트를 사용할 준비를 마치는 것을 구분해요. 완성하지 못한 에이전트도 저장할 수 있지만, 테스트하거나 배포하려면 필수 설정을 먼저 끝내야 해요.

### 저장

아직 설정이 필요한 액션이 있어도 에이전트를 저장할 수 있어요.

그래서 다음과 같이 할 수 있어요.

- 설정 도중에 멈추기
- 작업 내용 저장하기
- 나중에 다시 돌아오기
- 미완료 액션 이어서 설정하기

### 테스트

테스트 통화를 하려면 먼저 필수 설정을 끝내야 해요.

테스트에서는 다음을 확인할 수 있어요.

- 에이전트가 지침을 따르는지
- 대화가 자연스럽게 들리는지
- 액션이 알맞은 시점에 실행되는지
- 정보가 제대로 저장되는지

{% hint style="info" %}
실제 통화 전환을 테스트하려면 **Phone Call**(전화 통화) 테스트를 사용하세요. **Web Call**(웹 통화) 테스트에서는 통화 전환을 쓸 수 없어요.
{% endhint %}

### 배포

필수 설정 항목을 모두 끝내기 전에는 **배포**를 쓸 수 없어요.

중요한 액션을 설정하기 전에 미완성 에이전트가 출시되는 것을 막아 줘요.

## 템플릿과 AI로 빌드하기 비교

템플릿과 **AI로 빌드하기**는 둘 다 에이전트를 더 빠르게 만들 수 있게 도와주지만, 방식이 달라요. 차이를 알면 더 알맞은 시작점을 고를 수 있어요.

**미리 구성된 템플릿**은 자주 있는 비즈니스 사용 사례를 바탕으로 정해진 설정을 제공해요.

예를 들어 **프런트 데스크 안내원**을 선택하면 안내 데스크 통화에 맞게 설계된 시작 구성이 만들어져요.

**AI로 빌드하기**는 원하는 경험을 직접 말로 설명하면, 하이퍼클래스가 그 설명을 바탕으로 플로를 만들거나 바꿔 줘요.

제공되는 사용 사례 중에 목표에 맞는 것이 있으면 템플릿을 쓰세요. 좀 더 맞춤형 플로를 원한다면 AI로 빌드하기를 쓰세요.

## 템플릿으로 음성 AI 에이전트 설정하기

템플릿으로 시작하면 자주 쓰는 사용 사례에 필요한 주요 지침과 액션이 이미 갖춰져 있어요. 테스트하기 전에 필수 설정을 마무리하고 에이전트를 원하는 대로 고치면 돼요.

### 1단계: 플로 빌더 열기

1. **AI 에이전트 > 음성 AI**로 이동하세요.
2. **에이전트 만들기**를 클릭하세요.
3. **플로 빌더**를 선택하세요.
4. **계속**을 클릭하세요.

![플로 빌더 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079936813/original/16MQQ9EymuQCkfm_vkP3Ck4TeoWf-oKyNQ.jpeg?1788364092)

### 2단계: 템플릿 선택하기

1. 사용할 수 있는 사용 사례를 살펴보세요.
2. 목표에 가장 잘 맞는 템플릿을 선택하세요.
3. 템플릿을 쓰지 않으려면 **커스텀 에이전트 만들기**를 선택하세요.
4. **에이전트 만들기**를 클릭하세요.

![템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079988135/original/KoPIiVTTjNU7FGEuohOyqBw2gXHuSk-bTw.jpeg?1788428359)

### 3단계: 생성된 에이전트 검토하기

에이전트가 만들어지면 다음을 진행하세요.

1. 에이전트 지침을 검토하세요.
2. 하이퍼클래스가 추가한 액션을 검토하세요.
3. 필요 없는 액션은 제거하세요.
4. 필요하면 다른 액션을 추가하세요.
5. 비즈니스에 맞게 지침을 조정하세요.

템플릿이 추가한 내용은 모두 편집할 수 있어요.

### 4단계: 대기 중인 액션 완료하기

1. 액션에 경고 아이콘이 있는지 확인하세요.
2. **에이전트 설정 완료하기**가 보이면 열어 보세요.
3. 미완료 항목을 클릭하세요.
4. 필요한 정보를 입력하세요.
5. 액션을 저장하세요.
6. 남은 경고마다 같은 과정을 반복하세요.

입력해야 할 정보의 예는 다음과 같아요.

- 통화 전환 전화번호
- 워크플로우
- 연락처 필드
- SMS 내용
- 이메일 정보
- 액션 트리거 조건

![미완료 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079988275/original/-iZZdGbWkAGmNQ5Wa6oCigadHJuHj8bsxQ.jpeg?1788428465)

### 5단계: 필요하면 Update Tag 설정하기

1. **Update Tag** 액션을 추가하거나 여세요.
2. 태그를 언제 추가해야 하는지 설명하는 조건을 분명하게 입력하세요.
3. 필요한 태그 정보를 설정하세요.
4. 필요하면 변수 이름을 입력하세요. 변수 이름은 선택 사항이에요.
5. **저장**을 클릭하세요.

### 6단계: 저장하고 테스트하기

1. **저장**을 클릭하세요.
2. 필수 경고가 모두 해결됐는지 확인하세요.
3. **테스트**를 클릭하세요.
4. 상황에 맞는 테스트 통화를 진행하세요.
5. 에이전트가 제대로 응답하고 액션을 올바르게 수행하는지 확인하세요.

### 7단계: 에이전트 배포하기

테스트가 끝나면 다음을 진행하세요.

1. **배포**를 여세요.
2. 에이전트를 연결할 수 있는 대상을 선택하세요.
3. 배포 설정을 완료하세요.
4. **변경사항 저장**을 클릭하세요.

## 자주 묻는 질문

### 템플릿을 꼭 사용해야 하나요?
아니요. 기본 설정으로 시작해서 직접 에이전트를 만들고 싶다면 **커스텀 에이전트 만들기**를 선택하세요.

### 템플릿을 선택한 뒤에도 에이전트를 편집할 수 있나요?
네. 템플릿으로 에이전트를 만든 뒤에도 지침, 액션, 플로를 모두 편집할 수 있어요.

### 템플릿에 액션을 더 추가할 수 있나요?
네. 만들어진 플로를 원하는 대로 바꾸고, 사용 사례에 필요한 액션을 추가할 수 있어요.

### 템플릿에 포함된 액션을 제거할 수 있나요?
네. 템플릿은 고정된 구성이 아니라 시작점이에요.

### **테스트**를 쓸 수 없는 이유는 무엇인가요?
설정이 필요한 필수 액션이 아직 남아 있을 수 있어요. 경고 아이콘과 **에이전트 설정 완료하기** 알림을 확인하세요.

### **배포**를 쓸 수 없는 이유는 무엇인가요?
에이전트를 배포하려면 필수 설정을 먼저 끝내야 해요.

### 완성하지 못한 에이전트도 저장할 수 있나요?
네. 아직 설정이 필요한 액션이 있어도 저장할 수 있어요.

### Update Tag는 어떤 일을 하나요?
통화 중에 일어난 일에 따라 에이전트가 연락처에 태그를 추가해요.

### 음성 AI가 추가한 태그로 워크플로우를 시작할 수 있나요?
네. 워크플로우를 해당 태그에 맞게 설정해 두면, 연락처 태그를 워크플로우 트리거로 쓸 수 있어요.

### 기존 음성 AI 에이전트도 이 템플릿 때문에 바뀌나요?
아니요. 기존 에이전트는 현재 지침과 액션을 그대로 유지해요.

### 템플릿과 AI로 빌드하기는 어떻게 다른가요?
템플릿은 특정 사용 사례에 맞춰 정해진 설정을 제공해요. AI로 빌드하기는 사용자가 입력한 설명을 바탕으로 플로를 만들거나 바꿔 줘요.
