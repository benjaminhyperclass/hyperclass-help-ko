# 음성 AI 에이전트 다국어 설정

음성 AI 에이전트는 언어 하나만 쓰게 할 수도 있고, 통화 고객에게 필요한 언어만 골라 함께 쓰게 할 수도 있어요. 고정된 **다국어** 묶음 대신 비즈니스에 필요한 언어만 선택하면 돼요. 선택한 언어에 맞춰 음성 목록이 자동으로 바뀌고, 함께 쓸 수 없는 언어 조합은 설정 중에 알려 줘요. 이 문서에서는 언어 선택 방법, 호환되는 음성 고르기, 기존 **다국어** 에이전트의 자동 전환, S2S 에이전트의 언어 설정을 설명해요.

---

## 음성 AI 에이전트 다국어 지원이란?

다국어 지원을 쓰면 음성 AI 에이전트가 통화에서 사용할 언어를 정확히 정할 수 있어요.

에이전트가 언어 하나만 쓰게 하려면 **단일 선택**을 사용하세요. 특정 언어 조합을 지원하게 하려면 **다중 선택**을 사용하세요.

예를 들어 영어와 스페인어를 쓰는 고객을 응대하는 에이전트라면, 필요하지 않은 언어는 켜지 않고 이 두 언어만 선택하면 돼요.

언어를 여러 개 선택하면 가장 먼저 선택한 언어가 에이전트의 주 언어로 유지돼요.

---

## 다국어 음성 AI의 장점

언어를 정확히 골라 쓰면 다국어 통화를 더 세밀하게 관리할 수 있고, 호환되지 않는 설정도 미리 막을 수 있어요.

- 정확한 언어 선택: 음성 AI 에이전트가 지원해야 할 언어만 선택해요.
- 에이전트 수 절감: 언어마다 에이전트를 따로 두지 않고, 선택한 여러 언어를 쓰는 고객을 호환되는 에이전트 하나로 응대할 수 있어요.
- 주 언어 유지: 가장 먼저 선택한 언어가 에이전트의 주 언어로 유지돼요.
- 호환되는 음성 선택: 선택한 모든 언어를 지원하는 음성만 목록에 나타나요.
- 호환성 안내: **언어** 선택 메뉴에서 함께 쓸 수 없는 언어 조합을 알려 줘요.
- 기존 에이전트의 유연한 전환: 기존 **다국어** 에이전트는 계속 작동하고, 나중에 원할 때 조정하면 돼요.

---

## 사전 준비와 제한 사항

에이전트를 설정하기 전에 언어와 음성의 호환 관계를 알아 두면, 지원되지 않는 조합이나 예상 밖의 음성 목록을 피할 수 있어요.

언어를 설정하기 전에 다음을 확인하세요.

- 설정할 음성 AI 에이전트를 여세요.
- 에이전트에 언어가 하나 필요한지, 여러 개 필요한지 정해요.
- 에이전트에 지정한 모든 언어를 지원하는 음성을 고르세요.

현재 제한 사항은 다음과 같아요.

- 일부 언어는 단독으로만 쓸 수 있어서 다른 언어와 함께 선택할 수 없어요.
- 함께 쓸 수 없는 조합을 선택하면 **언어** 선택 메뉴에서 알려 줘요.
- 사용할 수 있는 음성은 에이전트에 선택한 언어 전체에 따라 달라져요.

이전의 고정된 **다국어** 언어 묶음을 현재 지원 언어 목록으로 생각하면 안 돼요. 사용 가능한 언어는 새로 바뀐 **언어** 선택 메뉴에서 직접 확인하세요.

---

## 음성 AI 에이전트의 언어 설정하기

에이전트 빌더 맨 위에 있는 **언어** 선택 메뉴에서 에이전트가 언어 하나를 쓸지, 특정 언어 조합을 쓸지 정해요. 에이전트를 처음 만드는 방법은 [음성 AI 에이전트 만들기](../how-to-create-voice-ai-agents.md) 문서를 참고하세요.

1. **서브 계정** 화면의 왼쪽 메뉴에서 **AI 에이전트**를 선택하세요.
2. **음성 AI**를 선택하세요.

   ![음성 AI 메뉴 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082321456/original/illPuM7PELoQst0V37cLwXoybr1woLquaw.png?1790873665)

3. **에이전트 목록** 탭을 여세요.
4. 편집할 음성 AI 에이전트를 선택하세요.

   ![에이전트 목록에서 에이전트를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082321514/original/ItDEOvOOrkHrYtVwhfdwchEqo5p5jES2Cg.png?1790873767)

5. 에이전트 빌더 맨 위에서 **언어**를 찾으세요.
6. **단일 선택** 또는 **다중 선택**을 고르세요.

   ![언어 선택 방식을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082321622/original/mjeryYBkiPgYrZWN-MvFC9mg78jxpmh0jw.png?1790873872)

7. 언어 하나만 쓰려면 **단일 선택**을 그대로 두고 필요한 언어를 고르세요.
8. 언어를 여러 개 쓰려면 **다중 선택**으로 바꾸고, 에이전트가 지원해야 할 언어를 하나씩 선택하세요.

   ![다중 선택으로 여러 언어를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082321700/original/ro1Gg-IgZljmjCbN9l3ChR9Nb1TTrzCgFQ.png?1790873929)

9. 가장 먼저 선택한 언어가 에이전트의 주 언어로 유지되는지 확인하세요.
10. 사용 가능한 음성을 살펴보고, 선택한 모든 언어를 지원하는 음성을 고르세요.
11. 에이전트 설정을 마치면 **저장**을 클릭하세요.

실제 통화에 쓰기 전에 가능하면 선택한 언어로 에이전트를 테스트해 보세요. 하이퍼클래스의 음성 AI 설정 문서에서도 테스트를 에이전트 설정 과정에 포함하고 있어요. 인사말이 언어에 따라 어떻게 자동 번역되는지는 [음성 AI 자동 번역 인사말 작동 방식](how-auto-translated-greetings-work-in-voice-ai.md) 문서에서 확인할 수 있어요.

## 여러 언어를 선택했을 때 음성 선택 방식

음성 목록은 에이전트에 선택한 언어에 맞춰 자동으로 바뀌어요. 에이전트가 처리하도록 설정된 언어를 모두 말할 수 없는 음성은 지정되지 않도록 막아 주는 거예요.

에이전트의 언어를 선택하고 나면 다음과 같이 동작해요.

- 음성 라이브러리에는 **선택한 모든 언어**를 지원하는 음성만 나타나요.
- 언어를 추가하거나 빼면 사용할 수 있는 음성이 달라질 수 있어요.
- 에이전트 설정을 마치기 전에, 걸러진 목록에서 음성을 고르세요.

하이퍼클래스에서는 음성 AI 에이전트 빌더에서 음성을 비교하고 지정할 수 있어요. 이번 언어 선택 기능에는 선택한 언어 전체를 기준으로 호환되는 음성만 보여 주는 필터가 더해졌어요. 음성을 바꾸는 방법은 [음성 AI 에이전트 음성 편집](../기타/how-to-edit-a-voice-ai-agents-voice.md) 문서를 참고하세요.

## 여러 언어를 쓸 때 번역 동작

**번역**은 음성 AI 에이전트가 실시간 통화에서 쓰는 언어와는 별개예요. **번역**은 통화 후 번역된 통화 녹취록과 요약에 쓰이는 언어를 정해요. 자세한 내용은 [음성 AI: 통화 녹취록·요약 번역 서비스](voice-ai-translation-service-for-call-transcript-summary.md) 문서를 참고하세요.

새로 바뀐 다국어 설정에서는 다음과 같이 동작해요.

- 번역된 통화 기록이 필요하면 **번역**을 켜세요.
- **번역**을 켜면 번역 대상 언어로 **영어**가 미리 선택돼 있어요.
- **번역** 설정은 실시간 음성 AI 통화에 선택한 언어를 바꾸지 않아요.

![번역 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082321799/original/dttziSpYS1JoQe6enFIbxvqZK56K__jDGA.png?1790874114)

## 기존 다국어 음성 AI 에이전트

이전에 **다국어** 옵션을 쓰던 에이전트는 자동으로 전환돼요. 현재 동작은 그대로 유지하면서, 앞으로 언어를 개별로 조정할 수 있게 돼요.

기존 **다국어** 에이전트에는 다음 열 가지 언어가 설정돼요.

- **영어 (미국)**
- **스페인어**
- **프랑스어**
- **독일어**
- **Hindi**(힌디어)
- **러시아어**
- **포르투갈어(브라질)**
- **일본어**
- **이탈리아어**
- **네덜란드어**

에이전트의 기존 주 언어는 바뀌지 않아요.

전환 후에 따로 할 일은 없어요. 에이전트는 전과 똑같이 전화를 받아요.

나중에 에이전트의 **언어** 선택 메뉴를 열어서, 비즈니스에서 쓰지 않는 언어를 빼거나 호환되는 다른 언어를 추가할 수 있어요.

---

## S2S 에이전트의 언어 선택

S2S 에이전트는 설정 사이드바에 있던 이전 언어 설정 대신, 빌더 맨 위의 **언어** 선택 메뉴를 사용해요.

S2S 에이전트는 다음과 같이 설정하세요.

- 에이전트가 고객이 쓴 언어로 답하게 하려면 **다국어**를 켜 두세요.
- 에이전트가 직접 선택한 언어만 쓰게 하려면 **다국어**를 끄세요.
- 언어 설정은 빌더 맨 위의 **언어** 선택 메뉴에서 관리해요.

---

## 자주 묻는 질문

### 음성 AI 에이전트에 언어 하나만 계속 쓸 수 있나요?
네. **언어** 선택 메뉴를 **단일 선택**으로 두고, 에이전트가 쓸 언어를 선택하세요.

### 언어를 여러 개 선택하면 어떤 언어가 주 언어가 되나요?
가장 먼저 선택한 언어가 에이전트의 주 언어로 유지돼요.

### 언어를 여러 개 선택했더니 사용할 수 있는 음성이 줄었어요. 왜 그런가요?
음성 라이브러리에는 에이전트에 선택한 모든 언어를 말할 수 있는 음성만 나타나기 때문이에요.

### 모든 언어를 다른 언어와 함께 쓸 수 있나요?
아니요. 일부 언어는 단독으로만 쓸 수 있어요. 함께 쓸 수 없는 조합은 설정 중에 **언어** 선택 메뉴에서 알려 줘요.

### 예전에 다국어를 쓰던 에이전트를 업데이트해야 하나요?
아니요. 기존 **다국어** 에이전트는 자동으로 전환되고 주 언어도 그대로예요. 바로 바꾸지 않아도 계속 작동해요.

### 전환된 다국어 에이전트의 언어를 바꿀 수 있나요?
네. **언어** 선택 메뉴를 열어서 쓰지 않는 언어를 빼거나 호환되는 다른 언어를 추가하세요.

### S2S 에이전트는 언어 선택이 어떻게 동작하나요?
고객의 언어로 답하게 하려면 **다국어**를 켜 두세요. 선택한 언어만 쓰게 하려면 **다국어**를 끄세요.
