# 음성 AI 대시보드에서 테스트 통화 로그 확인하기

테스트 통화 로그를 보면 실제 통화 분석에 영향을 주지 않고 에이전트가 테스트에서 어떻게 대응했는지 확인할 수 있어요. **대시보드 & 로그**에서 **라이브/테스트** 필터를 쓰면 실제 통화와 테스트 통화를 함께 또는 따로 볼 수 있어요. 이 문서에서는 테스트 통화를 찾는 방법, 녹음과 대화 내용을 확인하는 방법, 테스트 통화가 대시보드 성과 지표에서 빠지는 이유를 설명해요.

## 음성 AI의 테스트 통화 로그란?

테스트 통화 로그는 음성 AI 에이전트를 출시 전이나 출시 후에 테스트할 때 만들어지는 기록이에요. 이 로그로 에이전트의 응답을 살펴보고, 의도한 대로 동작하는지 확인하고, 실제 고객 통화를 연결하기 전에 개선할 부분을 찾을 수 있어요.

테스트 통화 로그에는 통화 녹음, 대화 내용(트랜스크립트), 통화 시간, 에이전트 정보 등 확인 가능한 통화 정보가 담길 수 있어요. 품질 점검과 문제 해결에 유용하지만, 대시보드 분석이나 성과 지표에는 포함되지 않아요.

---

## 음성 AI 대시보드에서 테스트 통화 로그를 보면 좋은 점

테스트 통화 로그를 보면 실제 통화에 에이전트를 투입하기 전에 동작을 미리 검증하기 쉬워요. 테스트 활동을 실제 통화와 따로 확인하므로, 실제 운영 리포트에 영향을 주지 않고 프롬프트, 통화 설정, 액션을 개선할 수 있어요.

- 테스트 대화 확인: 테스트 통화의 녹음을 듣고 대화 내용을 읽어 볼 수 있어요.
- 에이전트 동작 검증: 실제 운영을 시작하기 전에 에이전트가 올바르게 응답하는지 확인해요.
- 안전한 문제 해결: 실제 통화 분석에 영향을 주지 않고 문제를 살펴봐요.
- 실제 통화와 테스트 비교: **라이브/테스트** 필터로 통화 유형을 전환하며 볼 수 있어요.
- 리포트 정확도 유지: 테스트 활동이 대시보드 성과 지표에 섞이지 않아요.

---

## 테스트 통화와 실제 통화의 차이

두 통화의 차이를 알면 로그를 올바르게 활용할 수 있어요. 테스트 통화는 검증과 문제 해결을 위한 통화예요. 실제 통화는 실제 고객과 이루어진 통화이고, 운영 성과 분석에 반영돼요.

- 테스트 통화: 음성 AI 에이전트를 테스트하면서 건 통화예요.
- 실제 통화: 음성 AI 에이전트가 응대한 실제 고객 통화예요.

테스트 통화도 로그에는 표시되므로 내용을 확인할 수 있어요. 다만 대시보드 분석과 성과 지표에서는 빠져요.

---

## 테스트 통화 로그를 확인하면 좋은 때

에이전트를 수정했거나 실제 운영 전에 동작을 검증할 때 테스트 통화 로그가 가장 유용해요. 큰 변경을 할 때마다 로그를 확인하면 문제를 일찍 발견할 수 있고, 에이전트가 준비됐는지 믿을 만하게 확인할 수 있어요.

다음과 같은 경우에 테스트 통화 로그를 확인하세요.

- 새 음성 AI 에이전트를 테스트할 때
- 프롬프트, 통화 설정, 커스텀 값, 액션을 수정했을 때
- **Web Call**(웹 통화) 또는 전화 통화 테스트 결과를 확인할 때
- 품질 점검을 위해 녹음과 대화 내용을 살펴볼 때
- 테스트 통화가 로그에 제대로 기록됐는지 확인할 때
- 번호를 연결하거나 실제 통화를 에이전트에 보내기 전에 동작을 검증할 때

---

## 음성 AI 대시보드에서 테스트 통화 로그 보는 방법

테스트 통화 로그는 음성 AI의 **대시보드 & 로그** 영역에서 볼 수 있어요. 로그 표와 **라이브/테스트** 필터를 사용하면 테스트 활동, 실제 활동, 또는 둘 다 골라서 볼 수 있어요.

### 1. AI 에이전트 > 음성 AI로 이동하기

**AI 에이전트**를 열고 **음성 AI**를 선택하세요. 이 영역에서 음성 AI 에이전트, 대시보드 분석, 통화 로그를 볼 수 있어요.

![AI 에이전트 메뉴에서 음성 AI 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073886535/original/NZdw8uEh4wUR1W8zXXVqFrJfArMjvs0j0Q.png?1781702781)

### 2. 대시보드 & 로그 열기

**대시보드 & 로그**를 선택하면 음성 AI 성과 정보와 통화 활동을 볼 수 있어요. 대시보드에는 분석 카드, 차트, 필터, 로그 표가 있어요.

![대시보드 & 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073886742/original/wNjC72GYr-uOuGXQ6FXzunJvLuVTfcMHUg.png?1781702901)

### 3. 전체 에이전트 또는 특정 에이전트 선택하기

에이전트 필터에서 **전체 에이전트**를 선택하면 모든 에이전트의 통화 활동을 볼 수 있어요. 특정 음성 AI 에이전트 하나를 선택하면 그 에이전트의 로그만 볼 수 있어요. 여러 에이전트를 테스트 중일 때 테스트 통화를 더 빨리 찾을 수 있어요.

![에이전트 필터에서 에이전트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073890497/original/ZGlJEiVMCq7B345sLrYSeVwh7-Ell3l-Xg.png?1781704409)

### 4. 날짜 범위 확인하기

날짜 범위 선택기에서 찾으려는 테스트 통화 날짜가 포함돼 있는지 확인하세요. 테스트 통화가 보이지 않으면 선택한 날짜 범위부터 먼저 확인해 보세요.

![날짜 범위 선택기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073890692/original/F8BcCT_imEn2URpDHfZXl97JQtewemQNRQ.png?1781704468)

### 5. 로그 표 찾기

대시보드 분석 영역 아래에 있는 로그 표로 스크롤하세요. 테스트 통화는 대시보드 지표 카드가 아니라 로그 표에서 확인해요.

로그 표에서 **라이브/테스트** 필터를 열고, 보려는 통화 유형에 맞는 옵션을 선택하세요.

![로그 표의 라이브/테스트 필터](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073890886/original/SrPM6mmU-QNDIPD1bvAhGXL_CCnBEbOUGw.png?1781704591)

### 6. 테스트 통화 항목 열기

테스트 통화 항목을 선택하면 확인 가능한 통화 정보를 볼 수 있어요. 통화에 따라 **통화 녹음**, 대화 내용, 연락처 또는 발신자 정보, 에이전트 이름, **날짜 및 시간**, 통화 결과, 그 밖에 기록된 활동을 확인할 수 있어요.

![테스트 통화 항목의 상세 정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073891260/original/KEASsf1YnfffsHo3rxg9PvuQk48WYqWWEA.png?1781704731)

### 7. 필터 해제하거나 변경하기

테스트 통화 확인을 마쳤으면 **라이브/테스트** 필터를 해제하거나 바꿔서 실제 통화 또는 전체 로그 보기로 돌아가세요.

## 테스트 통화 로그에서 확인할 수 있는 내용

테스트 통화 로그를 보면 음성 AI 에이전트가 테스트 대화를 어떻게 처리했는지 파악할 수 있어요. 이 정보로 지침의 빈틈, 라우팅 동작, 액션 트리거, 발신자 경험에서 부족한 점을 찾을 수 있어요.

확인 가능한 통화 데이터에 따라 테스트 통화 로그에는 다음 내용이 있을 수 있어요.

- **통화 녹음**
- 통화 대화 내용
- 에이전트 이름
- 연락처 또는 발신자 정보
- **날짜 및 시간**
- 통화 상태 또는 결과
- 통화 중에 실행된 액션
- 문제 해결에 도움이 되는 대화 세부 정보

가능하면 대화 내용과 녹음을 함께 확인하세요. 대화 내용으로는 대화를 빠르게 훑어볼 수 있고, 녹음으로는 어조, 응답 타이밍, 침묵, 끼어들기, 발신자 경험을 확인할 수 있어요.

---

## 테스트 통화가 분석에서 빠지는 이유

테스트 통화는 내부 검토, 문제 해결, 품질 점검을 위한 통화예요. 대시보드 분석에서 제외하면 리포트가 실제 고객 응대에 집중되고, 테스트 활동 때문에 운영 성과 지표가 달라지지 않아요.

테스트 통화는 녹음과 대화 내용과 함께 로그에는 나타날 수 있어요. 하지만 실제 통화 수, 통화 결과, 감정 분석, 완료된 통화, 실행된 액션 같은 지표와 그 밖의 대시보드 성과 리포트에는 영향을 주지 않아요.

---

## 전체 에이전트 로그와 특정 에이전트 로그

**대시보드 & 로그**에서는 모든 음성 AI 에이전트의 활동을 보거나, 선택한 에이전트 하나의 활동만 볼 수 있어요. 상황에 맞게 보기를 고르면 원하는 테스트 통화를 더 빨리 찾을 수 있고, 여러 에이전트를 테스트할 때 헷갈리지 않아요.

서브 계정의 모든 음성 AI 에이전트에 대한 테스트 활동을 보려면 **전체 에이전트**를 선택하세요.

선택한 음성 AI 에이전트 하나의 통화만 보려면 특정 에이전트 보기를 사용하세요.

엉뚱한 통화가 표시되면 선택한 에이전트 필터, 날짜 범위, **라이브/테스트** 필터를 확인하세요.

---

## 자주 묻는 질문

### 음성 AI 테스트 통화는 어디에서 볼 수 있나요?
**AI 에이전트 > 음성 AI > 대시보드 & 로그**로 이동한 뒤, 로그 표의 **라이브/테스트** 필터로 테스트 통화를 볼 수 있어요.

### 라이브/테스트 필터는 무엇인가요?
로그 표에 실제 통화, 테스트 통화, 또는 둘 다 표시할지 정하는 필터예요.

### 테스트 통화도 음성 AI 대시보드 지표에 포함되나요?
아니요. 테스트 통화는 확인용으로 로그에는 표시되지만, 대시보드 분석과 성과 지표에서는 제외돼요.

### 테스트 통화의 녹음과 대화 내용도 볼 수 있나요?
네, 확인 가능한 정보가 있고 처리가 끝났다면 테스트 통화 로그에 녹음과 대화 내용이 포함될 수 있어요.

### 테스트 통화와 실제 통화는 어떻게 다른가요?
테스트 통화는 음성 AI 에이전트를 검증하거나 문제를 해결하기 위한 통화예요. 실제 통화는 에이전트가 응대한 실제 고객 통화예요.

### 특정 에이전트의 테스트 통화만 보려면 어떻게 하나요?
**대시보드 & 로그**에서 해당 에이전트를 선택한 뒤 **라이브/테스트** 필터를 사용하면 그 에이전트의 테스트 통화 활동을 볼 수 있어요.

### 테스트 통화가 안 보여요.
선택한 날짜 범위, 에이전트 필터, **라이브/테스트** 필터를 확인하세요. 테스트 통화가 정상적으로 완료됐는지도 확인해 보세요.

### Web Call 테스트도 로그에 표시되나요?
**Web Call** 테스트는 완료된 뒤 로그에 표시될 수 있어요. **라이브/테스트** 필터, 올바른 에이전트 선택, 날짜 범위를 사용해 찾아보세요.

### 에이전트를 실제 운영에 투입하기 전에 테스트 통화 로그를 확인해야 하나요?
네. 테스트 통화 로그를 확인하면 실제 발신자가 에이전트와 통화하기 전에 에이전트가 올바르게 응답하는지 확인할 수 있어요.
