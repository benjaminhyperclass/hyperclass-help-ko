# 워크플로우 트리거 — AI Studio Form Submitted(AI 스튜디오 폼 제출)

방문자가 AI 스튜디오 사이트에서 연결된 폼을 제출하면 워크플로우를 자동으로 시작하는 트리거예요. AI 스튜디오(Vibe) 웹사이트로 들어온 리드에게 이메일·SMS 보내기, 태그 추가, 기회 만들기 같은 후속 작업을 자동으로 처리하고 싶을 때 쓰세요. 이 문서에서는 트리거 설정 방법과, 프로젝트·폼·페이지 경로·도메인별 필터 설정 방법을 안내해요.

## AI Studio Form Submitted 트리거란?

**AI Studio Form Submitted**(AI 스튜디오 폼 제출) 트리거는 방문자가 AI 스튜디오(Vibe) 사이트에서 연결된 폼을 제출할 때마다 워크플로우를 자동으로 시작해요. AI 스튜디오 폼 제출 전용 트리거라서, AI 스튜디오 사이트로 들어온 리드의 후속 작업을 따로 자동화할 수 있어요.

필터를 쓰면 특정 AI 스튜디오 프로젝트, 폼, 페이지 경로, 도메인에만 워크플로우를 적용할 수도 있어요.

이 트리거는 기존 **External Tracking**(외부 트래킹) 기능과 함께 쓸 수 있어요. 기존 폼은 **External Tracking** 폼 트리거로 계속 동작해요. 그 트리거를 계속 쓸 거라면 따로 업데이트하지 않아도 돼요. 기존 폼에 새 **AI Studio Form Submitted** 트리거를 쓰고 싶을 때만 폼 연동을 다시 실행하고 CRM에 다시 연결하세요.

## 이럴 때 편해요

- AI 스튜디오 전용 연동: AI 스튜디오 폼 제출만을 위한 트리거라서, AI 스튜디오 웹사이트의 워크플로우를 다른 폼 출처와 분리해서 관리하기 쉬워요.
- 후속 작업 자동화: 폼이 제출되면 알림, 이메일, SMS를 보내거나 태그 추가, 기회 만들기 등 원하는 워크플로우 액션을 자동으로 실행할 수 있어요.
- 세밀한 필터: 특정 AI 스튜디오 프로젝트, 폼, 페이지 경로, 도메인에서 들어온 제출에만 워크플로우가 실행되도록 정할 수 있어요.
- 간편한 리드 관리: AI 스튜디오 리드를 CRM에서 바로 받아 연락처를 자동으로 만들고 워크플로우를 실행해요.
- External Tracking과 함께 사용: 두 방식이 서로 충돌하지 않아서 워크플로우에 맞는 방식을 골라 쓸 수 있어요.

## 시작하기 전에

**AI Studio Form Submitted** 트리거로 워크플로우를 만들기 전에 아래 사항을 먼저 확인하세요.

- 서브 계정에서 AI 스튜디오가 켜져  있어야 해요.
- AI 스튜디오 프로젝트에 폼이 있어야 해요.
- 폼을 CRM 트래킹에 연결해야 해요.
- 프로젝트를 게시해야 해요.
- 테스트 폼을 한 번 제출해야 트리거가 선택 가능한 필터 옵션을 불러올 수 있어요.

## 기존 폼 다시 연결하기

**AI Studio Form Submitted** 트리거가 나오기 전에 이미 폼을 연결해 둔 AI 스튜디오 프로젝트라면 폼 연동을 다시 연결하세요. 폼 트래킹 설정이 새로 갱신되면서, 트리거가 AI 스튜디오 프로젝트와 폼을 정확히 알아보는 데 필요한 정보가 추가돼요.

{% hint style="warning" %}
기존 폼은 **External Tracking** 폼 트리거로 계속 동작해요. 그 트리거를 계속 쓸 거라면 업데이트하지 않아도 돼요. 기존 폼에 새 **AI Studio Form Submitted** 트리거를 쓰고 싶을 때만 폼 연동을 다시 실행하고 CRM에 다시 연결하세요.
{% endhint %}

이 트리거를 쓰려는 기존 AI 스튜디오 폼마다 아래 과정을 반복하세요.

1. 폼이 들어 있는 AI 스튜디오 프로젝트를 열어요.
2. AI 스튜디오 채팅 화면에서 폼 연동을 다시 실행해 달라고 요청해요. 프롬프트는 `Re-trigger form integration.` 을 그대로 입력하세요. AI 스튜디오가 요청을 분석하고 폼 연동을 업데이트할 때까지 기다려요.

   ![AI 스튜디오 채팅 화면에서 폼 연동 재실행을 요청하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077117010/original/MuXuXjChoh2zyyHxPevcH0Sfw2FiwUo3Ig.png?1785319044)

3. AI 스튜디오가 요청을 처리하면 폼을 CRM 트래킹에 다시 연결해요. 연동이 갱신되면서 **AI Studio Form Submitted** 트리거와 호환돼요.
4. AI 스튜디오 프로젝트를 다시 게시해서 바뀐 트래킹 설정을 실제 웹사이트에 반영해요.
5. 게시한 AI 스튜디오 웹사이트에 접속해 테스트 폼을 제출하고, 트래킹이 제대로 동작하는지 확인해요.

## 워크플로우 만들기

**AI Studio Form Submitted** 트리거로 워크플로우를 만드는 순서예요.

1. 하이퍼클래스 계정에서 **자동화 > 워크플로우**로 이동해요. 새 워크플로우를 만들거나, 트리거를 추가할 기존 워크플로우를 열어요.
2. 워크플로우 빌더에서 **Add New Trigger**(새 트리거 추가)를 클릭해요. 트리거 목록에서 **AI Studio Form Submitted**를 검색해 선택해요.

   ![워크플로우 빌더에서 AI Studio Form Submitted 트리거를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077117227/original/zI7CY_Gut2GvYxGyOMAyUuzDOIJUTdavGg.png?1785319118)

3. 필요하면 필터를 추가해서 워크플로우를 시작할 AI 스튜디오 제출을 정해요. 프로젝트, 폼, 페이지 경로, 도메인으로 필터링할 수 있어요. 자세한 내용은 아래 사용 가능한 필터를 참고하세요. 필터를 추가하지 않으면 모든 AI 스튜디오 프로젝트의 폼 제출에서 워크플로우가 시작돼요.
4. 트리거 설정이 끝나면 워크플로우 액션을 추가해요. 이메일·SMS 보내기, 태그 추가, 기회 만들기, 연락처 필드 업데이트, 팀원에게 연락처 배정 등을 자주 써요.
5. 변경사항을 저장하고 워크플로우를 **Published**(게시됨)로 전환해 활성화해요.

{% hint style="info" %}
이제 방문자가 AI 스튜디오 웹사이트에서 설정한 필터에 맞는 폼을 제출할 때마다 워크플로우가 자동으로 시작돼요.
{% endhint %}

## 사용 가능한 필터

필터를 하나 이상 사용해서 워크플로우에 들어오는 AI 스튜디오 제출을 정해요. 필터를 쓰면 특정 프로젝트, 폼, 페이지, 도메인만 골라서 대상으로 삼을 수 있어요.

| 필터 | 설명 |
| --- | --- |
| **AI Studio Project**(AI 스튜디오 프로젝트) | 선택한 AI 스튜디오 프로젝트에서 제출된 경우에만 워크플로우가 실행돼요. |
| **AI Studio Form**(AI 스튜디오 폼) | 선택한 폼이 제출된 경우에만 워크플로우가 실행돼요. |
| **Page Path**(페이지 경로) | 선택한 페이지 경로에서 제출된 경우에만 워크플로우가 실행돼요. |
| **Domain**(도메인) | 선택한 도메인에서 제출된 경우에만 워크플로우가 실행돼요. |

{% hint style="info" %}
**AI Studio Project**를 먼저 선택하면 다른 필터에서 고를 수 있는 폼, 페이지 경로, 도메인 옵션이 해당 프로젝트 기준으로 좁혀져요.
{% endhint %}

## 문제 해결

### 필터 목록에 프로젝트나 폼이 안 보여요

프로젝트나 폼이 필터 옵션에 나타나지 않으면 아래 순서로 확인하세요.

- 폼이 CRM 트래킹에 연결되어 있는지 확인해요.
- 기존 폼이라면 AI 스튜디오에 폼 연동을 다시 실행해 달라고 요청해요.
- 폼을 CRM 트래킹에 다시 연결해요.
- 새 테스트 폼을 제출해요.
- 워크플로우 빌더를 새로고침한 뒤 다시 시도해요.

### 폼을 제출했는데 워크플로우가 실행되지 않아요

폼을 제출해도 워크플로우가 시작되지 않으면 아래 순서로 확인하세요.

- 워크플로우가 게시되어 있는지 확인해요.
- 폼이 CRM 트래킹에 연결되어 있는지 확인해요.
- 기존 폼이라면 폼 연동을 다시 실행하고 CRM 트래킹에 다시 연결해요.
- 게시된 AI 스튜디오 페이지에서 새 폼을 제출해요.
- 선택한 필터가 테스트 제출에 사용한 프로젝트, 폼, 페이지 경로, 도메인과 맞는지 확인해요.
