# 대화 AI에서 워크플로우 트리거하기

**워크플로우 트리거** 기능을 쓰면 대화 AI 봇이 고객과 대화하다가 정해 둔 조건에 맞을 때 워크플로우를 자동으로 실행해요. 이 문서에서는 워크플로우 트리거를 설정하는 방법과 조건을 쓸 때 알아 둘 점을 안내해요.

## 소개

**워크플로우 트리거** 기능은 대화 AI 안에 워크플로우를 연결해서 특정 작업을 자동화해 줘요. 고객과 대화하는 중에 정해 둔 조건이 충족되면 AI 봇이 선택한 워크플로우를 자동으로 실행해요.

이렇게 하면 업무 진행이 매끄러워지고 고객 경험도 좋아져요. 프롬프트에 모든 조건을 직접 입력하지 않아도 원하는 결과를 얻을 수 있어요.

## 1단계: Bot Goals 탭에서 워크플로우 트리거 버튼 열기

**Bot Goals**(봇 목표) 탭으로 이동한 뒤 **워크플로우 트리거** 버튼을 클릭해 세부 내용을 확인하세요.

{% hint style="info" %}
새 봇을 만드는 중이라면, 이 기능을 열기 전에 **Bot name**(봇 이름)을 수정하거나 새 이름을 지정해야 해요.
{% endhint %}

## 2단계: 워크플로우 트리거 버튼을 클릭하고 필요한 내용 입력하기

### 필드 설정 방법

다음을 따라 워크플로우 트리거를 설정하세요.

- **액션 이름**: 원하는 액션 이름을 입력하세요. 나중에 이 워크플로우를 쉽게 알아볼 수 있어요. 예를 들어 "구독 워크플로우"처럼 지을 수 있어요.
- **트리거할 게시된 워크플로우 선택**: 드롭다운 메뉴에서 실행할 워크플로우를 고르세요. 이 워크플로우는 미리 게시되어 있어야 해요. 정해 둔 조건이 충족되면 여기서 고른 워크플로우가 실행돼요.
- **When to trigger a workflow**(워크플로우를 트리거할 시점): 세 번째 필드에 워크플로우를 실행할 조건을 짧게 적으세요. AI가 워크플로우를 언제 실행할지 알려면 꼭 필요한 내용이에요. 예시는 다음과 같아요.
  - 고객이 구독을 구매하고 싶어 할 때 워크플로우를 실행하려면 "고객이 구독을 구매하려고 함"이라고 쓸 수 있어요.
  - 고객이 예약을 잡고 싶어 할 때 워크플로우를 실행하려면 "고객이 예약을 잡으려고 함"이라고 쓸 수 있어요.
  - 이렇게 적어 두면 AI가 대화 중에 비슷한 상황이 생겼을 때 조건을 알아보고 워크플로우를 실행해요.
- 입력을 마치면 **저장**을 클릭해 설정을 마무리하세요.
- 이렇게 설정하면 정해 둔 조건이 생길 때마다 봇이 지정한 워크플로우를 자동으로 실행해서, 업무가 더 매끄럽게 진행되고 고객과의 소통도 좋아져요.

## 트리거 조건을 쓸 때 알아 둘 점

1. **효과적인 트리거 조건 쓰는 법**
   "고객이 구독 비용을 결제하려고 함"이나 "고객이 예약을 잡으려고 함" 같은 트리거 조건을 정할 때는 프롬프트를 다음처럼 작성하세요.

   - 봇이 자연스럽게 관련 질문을 하도록 대화를 이끌어 가야 해요.
   - 고객의 답변이 트리거 조건과 맞아야 해요.
     예를 들어 조건이 "고객이 예약을 잡으려고 함"이라면, 봇이 "예약을 잡아 드릴까요?" 같은 질문을 하도록 프롬프트를 구성하세요. 그러면 대화 중에 조건이 자연스럽게 나타나요.
2. **트리거 조건이 겹칠 때**
   트리거 조건 하나가 동시에 여러 조건에 해당하면(예: **연락처 정보 업데이트**와 **워크플로우 트리거**) AI가 어떤 액션을 실행할지 판단해요. 예를 들면 다음과 같아요.

   - **연락처 정보 업데이트**: 사용자가 생년월일을 알려 주면 생년월일을 업데이트해요.
   - **워크플로우 트리거**: 사용자가 생년월일을 알려 주면 워크플로우를 실행해요.
     이런 경우에는 두 조건의 트리거가 같기 때문에, 어떤 것이 실행될지는 AI가 우선순위를 어떻게 정하느냐에 따라 달라져요.
3. **봇 또는 사용자의 응답으로 조건 충족하기**
   트리거 조건은 봇의 응답으로도, 사용자의 응답으로도 충족될 수 있어요. 봇이 대화를 이끌든 사용자가 먼저 말을 꺼내든, 조건이 충족되면 워크플로우가 실행돼요.
4. **이미 게시된 워크플로우와 중복하지 않기**
   **워크플로우 자동화**에서 이미 같은 트리거로 게시한 워크플로우에는 **워크플로우 트리거** 액션을 설정하지 마세요. 그렇게 하면 워크플로우가 두 번 실행되어 액션이 의도치 않게 중복돼요.

## 자주 묻는 질문

### AI 봇이 트리거한 워크플로우에서 연락처 필드를 업데이트할 수 있나요?

네, 할 수 있어요. 선택한 워크플로우 안에 **Update Contact Field**(연락처 필드 업데이트) 액션을 넣으면 돼요. 이렇게 하면 자동 후속 작업의 일부로 연락처 정보를 보강할 수 있어요.
