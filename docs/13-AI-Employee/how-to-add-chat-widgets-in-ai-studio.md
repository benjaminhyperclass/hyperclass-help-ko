# AI 스튜디오에서 채팅 위젯 추가하기

**AI 스튜디오**에서 만든 웹사이트나 앱에 브랜드와 어울리는 채팅 위젯을 직접 만들어 붙일 수 있어요. 기본 채팅 말풍선 대신 내 사이트 분위기에 맞는 채팅 화면을 쓰면서, 하이퍼클래스의 기존 채팅 기능도 그대로 사용해요. 이 문서에서는 채팅 위젯을 만들고, 설정하고, 성과를 확인하는 방법을 안내해요.

---

## AI 스튜디오의 채팅 위젯

**AI 스튜디오**의 채팅 위젯은 내 웹사이트의 일부처럼 자연스럽게 보이는 채팅 화면이에요. **AI 스튜디오**에 채팅 위젯을 추가해 달라고 요청하면, 사이트의 색상·글꼴·레이아웃에 맞춰 위젯을 만들어 줘요. 인사말, 위치, 전체적인 모양은 AI 프롬프트로 바꾸거나 코드를 직접 수정해서 원하는 대로 조정할 수 있어요.

채팅 화면은 **AI 스튜디오**가 내 애플리케이션 코드에 직접 만들어 넣고, 메시지 전송과 수신은 하이퍼클래스가 맡아요. 그래서 디자인은 완전히 내 마음대로 꾸미면서도 기존 하이퍼클래스 연락처, **대화**, 채팅 위젯 설정을 그대로 쓸 수 있어요. 한 프로젝트 안에 페이지나 방문자 경험에 따라 채팅 위젯을 여러 개 만들 수도 있어요.

{% hint style="info" %}
**AI 스튜디오**는 라이브 채팅과 SMS / 이메일 채팅을 지원해요. 음성 채팅, WhatsApp, Facebook Messenger, Instagram 채팅 위젯은 아직 지원하지 않아요.
{% endhint %}

---

## 채팅 위젯이 동작하는 방식

방문자가 위젯으로 메시지를 보내면 **대화**에 메시지가 들어와요. 팀원이 여기서 메시지를 읽고 답장하면, 답장은 채팅 위젯을 통해 방문자에게 전달돼요. 일반 라이브 채팅 대화와 똑같아요.

위젯은 하이퍼클래스의 기존 채팅 기능도 그대로 지원해요. 대화 기록, 파일 첨부, 메시지 전송 상태, 영업 시간, 스팸 방지가 해당돼요. 다시 방문한 사람은 이전 대화를 이어 갈 수 있고, 위젯은 내가 설정한 채팅 설정을 따라요.

**AI 스튜디오**로 만든 위젯은 하이퍼클래스 계정의 **사이트 > 채팅 위젯**에도 다른 채팅 위젯과 함께 표시돼요. **AI 스튜디오**에서 만든 위젯을 편집하려고 열면 **AI 스튜디오**로 이동해서 설정을 관리하게 돼요.

## AI 스튜디오에서 채팅 위젯 추가하기

**AI 스튜디오**가 안내하는 순서대로 진행하면 위젯이 만들어지고 연결돼요. 임베드 코드를 직접 설치할 필요가 없어요.

1. **AI 스튜디오** 프로젝트에서 채팅 위젯을 추가해 달라는 프롬프트를 입력하세요.

   예: *"내 웹사이트에 채팅 위젯을 추가해 줘."*

   ![AI 스튜디오 프로젝트에서 채팅 위젯 추가를 요청하는 프롬프트 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083350937/original/wG479pfO5CCoKPiLEHZ5J6z4t0wYBcM1oA.png?1792004698)
2. 추가할 채팅 유형을 고른 다음 **연결**을 클릭하세요.

   ![채팅 유형을 선택하고 연결 버튼을 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083350987/original/0Ag2hUQFg-Whp7GJ9oLAjmMQS_VBhtQ5jw.png?1792004806)
3. **AI 스튜디오**가 묻는 디자인 질문에 답해서 채팅 화면을 꾸미세요. 위젯이 방문자에게 어떻게 인사할지, 어디에 표시할지, 메시지 말투는 어떻게 할지 정할 수 있어요.

   ![채팅 화면 디자인 질문에 답하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083350988/original/64RJNPW5zvMHV9nF8-5wnCJdEr-SnhBiQw.png?1792004806)
4. **AI 스튜디오** 작업이 끝나면 하이퍼클래스 계정에 채팅 위젯이 만들어져요. 위젯 이름은 프로젝트 이름을 따르고, 애플리케이션에도 자동으로 연결돼요. 애플리케이션 미리보기를 열어 위젯의 모양과 방문자와의 상호작용을 확인하세요.

   ![애플리케이션 미리보기에 표시된 채팅 위젯](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083351807/original/JJdj-VO35y9f8hquceNwd1oxx83E7YUQTg.png?1792006132)
5. 수정하고 싶으면 **AI 스튜디오**에 위젯 모양을 바꿔 달라고 요청하세요. 디자인을 더 세밀하게 조정하고 싶다면 생성된 코드를 직접 편집해도 돼요.

   예: *"눈에 잘 띄도록 채팅 위젯 배경색을 노란색으로 바꿔 줘."*

   ![AI 스튜디오에 채팅 위젯 배경색 변경을 요청한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083351932/original/dGnai1whVL0dg_GCHxsXHmWMuQBnonHJ7g.png?1792006352)

## 채팅 위젯 설정

프로젝트를 벗어나지 않고 **AI 스튜디오**에서 채팅 위젯 설정을 관리할 수 있어요. 위젯의 모양은 **AI 스튜디오** 프롬프트로 꾸밀 수 있어요. **채팅 위젯** 설정에서는 대화 중 방문자에게 보이는 내용, 방문자가 입력해야 하는 정보, 채팅이 동작하는 방식을 조정해요.

설정은 **AI 스튜디오** 프로젝트를 열고 **더보기 > 채팅 위젯**으로 이동해서 열어요. 관리할 위젯을 선택하면 설정이 열려요.

여기서 위젯 이름을 바꾸고 아래 항목을 설정할 수 있어요.

- **메시지**: 환영 메시지, 비활성 시간 초과, 채팅 종료 메시지, 확인 메시지, 피드백 메시지를 설정해요.
- **Contact Form**(문의 폼): 방문자가 대화를 시작하기 전에 입력해야 하는 연락처 정보를 정해요.
- **규정 준수 고지 및 동의**: 개인정보, 마케팅, SMS, 해당되는 경우 HIPAA 요건에 맞는 법적 고지와 동의 옵션을 설정해요.
- **스팸 방지**: 의심스러운 리드, 태그 지정, 선택 사항인 수신거부(DND) 제한을 관리해요.
- **영업 시간**: 라이브 채팅에서 팀이 응대할 수 있는 시간과, 그 시간 밖에 방문자에게 보이는 내용을 설정해요.

{% hint style="info" %}
프로젝트에 아직 위젯이 없다면 **채팅 위젯** 페이지에서 **Add a chat widget**(채팅 위젯 추가)을 클릭하세요. **AI 스튜디오**가 위젯을 만들어 줘요.
{% endhint %}

## 채팅 위젯 분석

채팅 위젯 분석에서는 **AI 스튜디오** 애플리케이션의 채팅 위젯을 방문자가 어떻게 쓰는지 확인할 수 있어요. 위젯이 얼마나 자주 로드되고 열리는지, 방문자 피드백과 만족도 평가는 어떤지, 어떤 위젯에서 리드가 생기는지 볼 수 있어요.

분석은 **AI 스튜디오** 프로젝트를 열고 **더보기 > 분석 > 채팅 위젯**으로 이동해서 확인하세요.

대시보드에는 위젯이 **로드됨**과 **열림**이 된 횟수가 표시돼요. **오픈율**(로드된 횟수 중 실제로 열린 비율)과 방문자의 채팅 평가를 모은 **피드백**도 함께 볼 수 있어요.

**모든 리드** 표에는 채팅 위젯으로 생긴 연락처가 나와요. 확인할 수 있는 연락처 정보, 채팅 유형, 위젯 이름, 각 대화가 시작된 페이지가 함께 표시돼요.
