# iPhone에서 AI에게 문의 단축어 사용하기

iPhone에서 모바일 앱을 열고 메뉴를 찾아가지 않아도 하이퍼클래스의 AI 어시스턴트를 바로 열 수 있어요. 단축어는 **새 채팅**, **Dictation**(음성 받아쓰기), **Voice Mode**(음성 모드) 세 가지예요. iPhone의 작업 버튼, Siri, Spotlight 검색 중 편한 방법으로 실행하세요.

## iPhone의 AI에게 문의 단축어란?

**AI에게 문의**(Ask AI) iOS 단축어는 iPhone에서 AI에게 문의 기능을 바로 실행하는 기본 제공 동작이에요. 모바일 앱을 열고 AI에게 문의로 직접 이동하는 대신, 단축어로 새 대화를 시작하거나 말로 메시지를 입력하거나 음성 대화를 시작할 수 있어요.

이 단축어는 iPhone의 작업 버튼, Siri, Spotlight 같은 iOS 기능과 연결돼요. 제공되는 단축어는 세 가지예요.

- **새 채팅:** AI에게 문의를 열고 새 대화를 시작해요.
- **Dictation**(음성 받아쓰기): 마이크가 켜진 상태로 새 대화를 열어요. 말로 입력할 수 있어요.
- **Voice Mode**(음성 모드): 새 대화를 음성 모드로 열어요. 자연스럽게 말을 주고받을 수 있어요.

모바일 앱이 열려 있지 않아도 단축어로 앱을 실행할 수 있어요. 마이크는 필요한 권한과 액세스 확인을 거쳐야 켜져요.

{% hint style="info" %}
AI에게 문의 iOS 단축어는 기존 [AI에게 문의 홈 화면 위젯](how-to-use-the-ask-ai-home-screen-widget-in-hyperclass.md), 앱 안의 **빠른 액션**과는 달라요. 모두 AI에게 문의를 여는 방법이지만 설정 방식과 쓸 수 있는 동작이 서로 달라요.
{% endhint %}

## AI에게 문의 단축어의 장점

단축어를 쓰면 iPhone에서 AI의 도움을 받기까지의 단계가 줄어들어요. 회의 사이에 아이디어를 남기거나, 말로 업데이트를 입력하거나, 다른 일을 하면서 질문할 때 더 빨리 시작할 수 있어요.

- **바로 열기:** 여러 앱 화면을 거치지 않고 iPhone에서 새 대화를 바로 열어요.
- **빠른 음성 사용:** Dictation이나 Voice Mode를 실행하면 마이크가 입력 준비 상태가 돼요. 필요한 권한이 허용되어 있어야 해요.
- **손 안 대고 사용:** 화면을 터치하기 불편할 때 Siri로 단축어를 실행할 수 있어요.
- **대화 분리:** 이전 채팅으로 돌아가지 않고도 질문이나 작업마다 새 대화를 시작할 수 있어요.
- **다양한 실행 방법:** 기기와 취향에 맞게 작업 버튼, Siri, Spotlight 중에서 골라 쓸 수 있어요.
- **진행 중인 세션 보호:** 음성 또는 받아쓰기 세션이 진행 중일 때 다른 단축어를 실행해도 기존 세션이 끊기지 않아요.
- **권한 기준 유지:** 단축어를 써도 기존 AI에게 문의 액세스 제어와 마이크 권한이 그대로 적용돼요.

## iPhone 작업 버튼으로 단축어 설정하기

AI에게 문의 단축어를 iPhone의 작업 버튼에 지정하면 원하는 동작을 바로 실행할 수 있어요. 설정을 마치면 **작업 버튼**을 길게 눌러서 선택한 단축어를 실행해요. 모바일 앱에서 직접 이동할 필요가 없어요.

다음 단계를 따르세요.

1. iPhone에서 **설정** 앱을 엽니다.
2. 아래로 스크롤해서 **작업 버튼**을 선택합니다.
3. 작업 버튼 옵션을 옆으로 넘겨 **Shortcut**(단축어)이 나올 때까지 이동합니다.
4. **Choose a Shortcut**(단축어 선택)을 눌러 단축어 선택 화면을 엽니다.
5. 앱 단축어 목록에서 **하이퍼클래스** 또는 사용 중인 화이트라벨 앱 이름을 찾습니다.
6. 다음 단축어 중 하나를 선택합니다.
   - **새 채팅**
   - **Dictation**
   - **Voice Mode**
7. **작업 버튼** 설정 화면으로 돌아가 선택한 단축어가 지정됐는지 확인합니다.
8. **작업 버튼**을 길게 눌러 단축어를 실행합니다. 선택한 단축어에 따라 AI에게 문의가 새 채팅을 열거나, 받아쓰기를 켜거나, 음성 모드를 시작해요.

{% hint style="info" %}
말로 AI에게 문의를 자주 쓴다면 Dictation이나 Voice Mode를 고르세요. 지시 내용을 직접 입력하는 편이 좋다면 **새 채팅**을 고르세요.
{% endhint %}

## Siri로 단축어 실행하기

작업 버튼에 지정하지 않아도 Siri로 AI에게 문의 단축어를 실행할 수 있어요. 화면을 거치지 않고 AI에게 문의를 열고 싶을 때 편해요.

Siri로 AI에게 문의 단축어를 실행하는 방법은 다음과 같아요.

1. iOS 16.6 이상이 설치된 지원 iPhone이고, 사용 가능한 버전의 모바일 앱이 설치되어 있는지 확인합니다.
2. 기기에서 지원하는 방법으로 Siri를 실행합니다.
3. 설치된 앱 이름을 넣어 단축어 명령을 말합니다.
   - **새 채팅:** "하이퍼클래스에서 새 채팅 시작"
   - **Voice Mode**: "하이퍼클래스에서 음성 모드 시작"

   화이트라벨 모바일 앱을 쓴다면 하이퍼클래스 대신 해당 앱 이름을 말하세요.
4. Siri가 앱을 열고 선택한 AI에게 문의 기능을 시작할 때까지 기다립니다.

## Spotlight에서 단축어 찾기

Spotlight로도 iPhone에서 AI에게 문의 단축어를 찾아 바로 실행할 수 있어요. 작업 버튼이 없는 기기이거나, 앱에서 메뉴를 찾기보다 동작을 검색하는 편이 좋을 때 유용해요.

Spotlight로 AI에게 문의 단축어를 찾는 방법은 다음과 같아요.

1. iPhone 홈 화면 가운데에서 아래로 쓸어내려 Spotlight 검색을 엽니다.
2. 실행하려는 단축어 이름을 입력합니다.
   - 새 채팅
   - Dictation
   - Voice Mode
3. 검색 결과에서 하이퍼클래스 또는 사용 중인 화이트라벨 앱과 연결된 단축어를 찾습니다.
4. 해당 단축어를 눌러 AI에게 문의를 실행합니다. 모바일 앱이 열리고 선택한 AI에게 문의 기능이 시작돼요.

{% hint style="info" %}
비슷한 이름의 단축어나 앱이 여러 개라면 Spotlight 검색어에 앱 이름도 함께 입력하세요.
{% endhint %}

## 마이크 권한과 진행 중인 세션

AI에게 문의 단축어에는 기존 앱 권한과 세션 보호가 그대로 적용돼요. 이 내용을 알아 두면 음성 대화를 시작하거나 대화를 바꿀 때 어떻게 동작하는지 예상할 수 있어요.

### 마이크 권한

Dictation과 Voice Mode는 말을 입력받으려면 마이크 액세스가 필요해요. 권한이 아직 허용되지 않았다면 앱이 해당 권한 확인을 마친 뒤에 녹음을 시작해요.

{% hint style="warning" %}
단축어를 써도 마이크 권한 요건과 AI에게 문의 계정 액세스 제어는 건너뛸 수 없어요.
{% endhint %}

### 진행 중인 음성·받아쓰기 세션

AI에게 문의 단축어는 진행 중인 음성·받아쓰기 세션을 갑자기 끊지 않도록 만들어졌어요. 단축어는 보통 새 대화를 시작하지만, 음성 또는 받아쓰기 세션이 이미 실행 중일 때 다른 단축어를 실행해도 기존 세션은 중단되지 않아요.

진행 중인 음성 대화를 관리하는 방법은 [AI에게 문의 음성 모드 사용하기](../../44-신기능-2026/how-to-use-ask-ai-voice-mode.md)를 참고하세요.

### 새 대화와 채팅 기록

새 AI에게 문의 대화를 시작하면 기존 채팅과 별개로 대화가 진행돼요. 이전 대화는 **채팅 기록**에서 계속 볼 수 있어요. 새 대화를 시작해도 이전 채팅이 삭제되거나 저장된 AI에게 문의 메모리가 지워지지 않아요. 메모리에 대한 자세한 내용은 [AI에게 문의 메모리란?](what-is-ask-ai-memory-008947.md)을 참고하세요.

자세한 내용은 [AI에게 문의 멀티스레딩: 여러 작업을 동시에 실행하기](ask-ai-multi-threading-run-multiple-tasks-at-once.md)를 참고하세요.

## 자주 묻는 질문

### iPhone에 작업 버튼이 없어도 AI에게 문의 단축어를 쓸 수 있나요?
네. iOS 16.6 이상이 설치된 지원 iPhone이라면 Siri나 Spotlight로 AI에게 문의 단축어를 실행할 수 있어요.

### iPhone 설정에서 AI에게 문의 단축어가 보이지 않아요.
모바일 앱이 버전 4.27.0 이상으로 업데이트되어 있는지, 계정에서 AI에게 문의가 활성화되어 있는지 확인하세요. 올바른 설치 앱에서 단축어를 고르고 있는지도 확인하세요. 화이트라벨 앱을 쓴다면 설치된 빌드가 이 기능을 지원하는지 확인하세요.

### 세 가지 AI에게 문의 단축어를 모두 작업 버튼에 지정할 수 있나요?
**작업 버튼**에는 한 번에 하나의 동작만 지정할 수 있어요. 지정된 AI에게 문의 단축어를 바꾸려면 **설정 > 작업 버튼 > Shortcut**(단축어)으로 돌아가 다른 단축어를 선택하세요. 나머지 단축어는 다른 실행 방법으로 쓸 수 있어요.

### 하이퍼클래스 앱이 닫혀 있을 때 단축어를 실행하면 어떻게 되나요?
단축어가 설치된 모바일 앱을 열고 선택한 AI에게 문의 기능을 시작할 수 있어요. 이때 필요한 인증, 권한, 액세스 확인은 그대로 거쳐요.

### 새 대화를 시작하면 이전 AI에게 문의 채팅이 삭제되나요?
아니요. 새 대화를 시작해도 이전 AI에게 문의 채팅 기록은 삭제되지 않아요. 이전 대화는 **채팅 기록**에서 볼 수 있어요.

### Dictation이나 Voice Mode를 실행했는데 마이크가 켜지지 않아요.
앱에 마이크 접근 권한이 없을 수 있어요. iPhone 설정에서 마이크 액세스를 확인하고, 계정에서 AI에게 문의를 사용할 수 있는지도 확인하세요. 다른 앱이 마이크를 사용 중이라면 오디오 입력이 충돌하는지 확인하세요.

### 화이트라벨 모바일 앱에서도 AI에게 문의 단축어를 쓸 수 있나요?
네. 버전 4.27.0 이상이 설치된 지원 대상 화이트라벨 모바일 앱에서 AI에게 문의가 활성화되어 있다면 쓸 수 있어요. 단축어를 고르거나 실행할 때 하이퍼클래스 대신 해당 앱 이름이 표시될 수 있어요.

### AI에게 문의 iOS 단축어와 AI에게 문의 홈 화면 위젯은 같은 건가요?
아니요. iOS 단축어는 작업 버튼, Siri, Spotlight로 실행하고 새 채팅, Dictation, Voice Mode 동작을 제공해요. AI에게 문의 홈 화면 위젯은 별도 기능이며, 홈 화면에서 채팅, 음성, 카메라 동작을 바로 실행할 수 있어요.
