# AI에게 문의로 워크플로우 바로 만들기

**AI에게 문의**에서 원하는 자동화를 문장으로 설명하면 AI가 워크플로우를 대신 만들어 줘요. 이 문서에서는 워크플로우를 만들고, 확인하고, 수정하고, 마무리하는 방법을 알려 드려요.

## AI에게 문의로 워크플로우 만들기

**워크플로우 빌더**에서 처음부터 시작하지 않아도 돼요. **AI에게 문의**에서 만들고 싶은 자동화를 설명하면 AI가 워크플로우를 만들어 줘요.

만들어진 워크플로우는 실시간 미리보기로 보여 줘요. **워크플로우 빌더**를 열기 전에 전체 구조를 먼저 확인할 수 있어요. 트리거와 액션을 하나씩 선택하면 설정 내용도 볼 수 있어요. 바꾸고 싶은 부분이 있으면 대화를 이어서 요청하세요.

추가로 요청하면 AI가 그 내용대로 워크플로우를 고쳐 줘요. 워크플로우가 준비되면 **워크플로우 빌더**에서 열어 직접 수정하고, 테스트하고, 게시하세요.

WhatsApp에서 AI에게 문의하는 기능으로도 워크플로우를 만들 수 있어요. 자동화를 시작하는 또 다른 방법이에요.

{% hint style="info" %}
**AI에게 문의**에서는 대화로 워크플로우를 수정할 수 있지만, 미리보기 패널에서 직접 편집할 수는 없어요. 직접 수정, 테스트, 게시는 **워크플로우 빌더**에서 하세요.
{% endhint %}

## 따라 하기

1. **AI에게 문의**를 열고 새 채팅을 시작하세요.
2. 만들고 싶은 워크플로우를 설명하세요.

   예시: *"폼을 제출하면 이메일을 보내고, 우리 팀에 알림을 보내고, 그 연락처에 전화하는 작업을 만드는 워크플로우를 만들어 줘."*

   ![워크플로우를 요청하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081568906/original/5rBzqH-LYdowoBjfD2X7cxVC8g_1n-gzvQ.gif?1790085636)
3. 미리보기 패널에서 만들어진 워크플로우를 확인하세요. 트리거나 액션을 선택하면 설정 내용을 볼 수 있어요.
4. 바꾸고 싶은 내용을 **AI에게 문의**에 알려 주세요. 요청한 내용대로 워크플로우가 수정돼요.

   예시: *"폼을 제출하고 2시간 뒤에 연락처에게 이메일을 보내 줘."*

   ![수정 사항을 요청하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081570926/original/kBD9wiz2ekfTCiLFg9lFcOYkTBr74DUryA.gif?1790086642)
5. **워크플로우 빌더**에서 이어서 작업하려면 **Open in automation to edit**(자동화에서 열어 편집)를 클릭하세요.
6. 빌더에서 필요한 부분을 직접 수정하고, 워크플로우를 테스트한 뒤 게시하세요. **워크플로우 빌더** 사용법은 「워크플로우 빌더 둘러보기」(Workflow Builder Walkthrough) 문서를 참고하세요.

   ![워크플로우 빌더에서 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081572176/original/xwPrlGuhti274agPTJ8-HGjsY2YgIEa6PQ.gif?1790086995)
