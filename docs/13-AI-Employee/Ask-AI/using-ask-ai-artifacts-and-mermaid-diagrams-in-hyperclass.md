# AI에게 문의의 아티팩트와 Mermaid 다이어그램 활용하기

**AI에게 문의**(Ask AI)는 답변을 일반 텍스트로만 주지 않고 테이블, 차트, 할 일 목록, 안내 질문, 코드 블록, 웹 검색 카드, 미디어, 승인 요청, Mermaid 다이어그램 같은 구조화된 형태로 보여 줘요. 이 문서에서는 각 형태(아티팩트)가 무엇이고 어떻게 요청하는지 알려 드려요. 데이터 분석, 워크플로우 시각화, 콘텐츠 제작, 팀 협업을 **AI에게 문의** 안에서 바로 할 수 있어요.

## 아티팩트란 무엇인가요?

**AI에게 문의**의 아티팩트는 AI가 만든 답변을 읽고, 이해하고, 실행에 옮기기 쉬운 구조화된 형태로 정리한 것이에요. 정보를 텍스트로만 보여 주는 대신, 상황에 가장 알맞은 레이아웃을 **AI에게 문의**가 자동으로 골라요. 원하는 레이아웃을 직접 요청할 수도 있어요. 데이터를 한눈에 보고, 작업을 정리하고, 워크플로우를 설명하고, 더 나은 결정을 내리는 데 도움이 돼요.

요청 내용에 따라 다음과 같은 형태로 답변을 받을 수 있어요.

- 테이블
- 차트
- 할 일 목록
- 안내 질문
- 승인 요청
- 코드 블록
- Mermaid 다이어그램
- 미디어 아티팩트
- 웹 검색 카드
- 오류 블록

아티팩트는 가독성을 높이고, 아이디어를 실행으로 옮기는 과정을 더 효율적으로 만들어 줘요. 많은 아티팩트가 정보를 대신 정리해 주지만, 일부 워크플로우는 작업이 끝나기 전에 사용자의 확인이나 **AI에게 문의**에서 지원하는 기능이 필요할 수 있어요.

## 아티팩트의 주요 장점

구조화된 AI 답변은 아이디어를 정리된 결과물로 바꿔 줘요. 캠페인을 계획하거나, 마케팅 성과를 분석하거나, 워크플로우를 문서화하거나, 새 아이디어를 구상할 때 내용이 더 분명해지고 협업도 쉬워져요.

- 가독성 향상: 복잡한 정보를 검토하기 쉬운 구조로 정리해요.
- 빠른 의사 결정: 중요한 데이터를 테이블과 차트로 시각화해요.
- 워크플로우 시각화: 자동화와 프로세스를 Mermaid 다이어그램으로 보여 줘요.
- 대화형 진행: 안내 질문으로 부족한 정보를 먼저 모은 뒤 결과를 만들어요.
- 협업 개선: 팀과 공유하기 쉬운 체크리스트, 다이어그램, 리포트를 만들어요.
- 유연한 출력 형식: 요청에 가장 잘 맞는 형식을 자동으로 고르거나, 원하는 형식을 직접 지정할 수 있어요.

## 지원하는 아티팩트 유형

각 아티팩트는 요청에 가장 알맞은 형태로 정보를 보여 주도록 만들어졌어요. 가능하면 **AI에게 문의**가 가장 알맞은 표현 방식을 자동으로 정해요. 프롬프트에서 원하는 형식을 직접 요청할 수도 있어요.

## 테이블

테이블은 구조화된 정보를 행과 열로 정리해 줘요. 많은 양의 데이터를 비교하고, 우선순위를 정하고, 검토하기 쉬워져요.

자주 쓰는 경우는 다음과 같아요.

- 콘텐츠 캘린더
- 캠페인 점검
- 리드 리포트
- 파이프라인 요약
- 예산 비교
- 성과 추적

예시 프롬프트:

> 부동산 중개인을 위한 4주 콘텐츠 캘린더를 만들어 줘. 플랫폼, 게시 요일, 콘텐츠 형식, 주제를 열로 하는 테이블로 보여 줘.

## 차트

차트는 숫자 정보를 시각적으로 바꿔 줘서 더 쉽게 이해할 수 있어요. 프롬프트에 지표나 성과 데이터가 있으면 **AI에게 문의**가 차트를 만들어 추세, 비교, 기회를 파악하도록 도와줘요.

지원하는 차트 유형은 다음과 같아요.

- 막대 차트
- 선 차트
- 원형 차트
- 퍼널 차트
- 레이더 차트

예시 프롬프트:

> 우리 에이전시의 성과를 분석해서 리드 수, 매출 성장, 트래픽 추세, 퍼널 전환을 차트로 만들어 줘.

## 안내 질문

안내 질문은 **AI에게 문의**가 답변을 만들기 전에 중요한 정보를 모으는 방법이에요. 요청에 핵심 내용이 빠져 있으면, 더 정확하고 맞춤화된 결과를 위해 추가 질문을 할 수 있어요.

예를 들어 다음과 같이 요청했다고 해 볼게요.

> 콘텐츠를 만들어 줘

그러면 **AI에게 문의**가 먼저 이렇게 물어볼 수 있어요.

- 어떤 종류의 콘텐츠를 만들고 싶으세요?
- 어느 플랫폼에 올릴 콘텐츠인가요?
- 타깃 고객은 누구인가요?
- 어떤 업종 또는 비즈니스를 운영하고 있나요?

이 질문에 답해 주면 더 알맞은 추천을 받을 수 있어요.

## 할 일 목록

할 일 목록은 프로젝트와 프로세스를 따라 하고 관리하기 쉬운 체크리스트로 정리해 줘요.

자주 쓰는 예는 다음과 같아요.

- 고객 온보딩
- 캠페인 런칭
- 표준 운영 절차(SOP)
- 팀 내부 프로세스
- 마케팅 업무 계획
- 프로젝트 관리

---

## 코드 블록

코드 블록은 여러 프로그래밍·스크립트 언어의 코드를 구문 강조가 적용된 깔끔한 형태로 만들어 줘요. 서식이 정리되어 있어서 생성된 코드를 복사하고, 검토하고, 적용하기 쉬워요.

지원하는 언어는 다음과 같아요.

- HTML
- CSS
- JavaScript
- SQL
- JSON
- Python

더 좋은 결과를 얻으려면 프롬프트에 프로그래밍 언어를 지정하세요.

예시 프롬프트:

> 이메일 주소가 올바른지 검사하는 JavaScript 함수를 만들어 줘.

## Mermaid 다이어그램

Mermaid 다이어그램은 텍스트로 쓴 워크플로우 설명을 대화형 시각 다이어그램으로 바꿔 줘요. 자동화, 고객 여정, 비즈니스 프로세스, 의사 결정 트리를 문서화할 때 잘 맞아요.

자주 쓰는 경우는 다음과 같아요.

- 자동화 워크플로우
- 리드 여정
- 캠페인 흐름
- 의사 결정 트리
- 고객 온보딩
- 표준 운영 절차(SOP)

큰 다이어그램에서는 다음 기능을 쓸 수 있어요.

- 전체 화면 보기
- 이동(패닝)
- 확대/축소
- 도구 모음 컨트롤

예시 프롬프트:

- 부재중 전화 문자 회신 자동화를 Mermaid 순서도로 만들어 줘.
- 신규 리드부터 계약 체결까지 내 리드 라이프사이클을 그려 줘.
- 7일 재활성화 캠페인을 Mermaid 다이어그램으로 만들어 줘.

## 미디어 아티팩트

미디어 아티팩트는 지원되는 AI 생성 미디어를 대화 안에서 바로 보여 줘요. **AI에게 문의**를 떠나지 않고 시각 콘텐츠를 확인할 수 있어요.

지원되는 워크플로우에 따라 생성된 이미지나 그 밖의 지원되는 시각 결과물이 표시될 수 있어요.

---

## 웹 검색 카드

웹 검색 카드는 지원되는 웹 검색 결과를 대화 안에 미리보기 카드 형태로 보여 줘요. **AI에게 문의** 안에서 작업을 이어 가면서 관련 정보를 빠르게 확인할 수 있어요.

---

## 승인 요청

일부 **AI에게 문의** 워크플로우는 계속 진행하기 전에 확인이 필요해요. 승인 요청은 정리된 검토 단계를 보여 줘서, **AI에게 문의**가 지원되는 작업을 진행하기 전에 정보를 확인할 수 있게 해 줘요.

---

## 오류 블록

**AI에게 문의**가 요청한 아티팩트를 만들거나 표시하지 못하면 오류 블록이 나타날 수 있어요. 무엇이 잘못됐는지 알려 주고, 가능하면 성공적으로 이어 가기 위해 필요한 정보도 안내해 줘요.

---

## 아티팩트 사용 방법

지시를 분명하게 쓸수록 **AI에게 문의**가 알맞은 아티팩트를 고르고 더 좋은 답변을 만들어요.

1. 왼쪽 메뉴에서 **AI에게 문의**를 여세요.
2. **새 대화 시작**을 선택하세요.
3. 하고 싶은 작업을 설명해요.
4. 원하는 출력 형식이 있으면 지정하세요. 예를 들면 다음과 같아요.
   - 테이블
   - 차트
   - 할 일 목록
   - Mermaid 다이어그램
   - 코드 블록
5. 관련 비즈니스 상황, 캠페인 목표, 워크플로우, 참고 데이터를 함께 적습니다.
6. 생성된 아티팩트를 확인하세요.
7. 필요하면 대화를 이어 가며 답변을 다듬거나, 늘리거나, 수정해요.

### 예시 프롬프트

콘텐츠 캘린더:

> 부동산 중개인을 위한 4주 콘텐츠 캘린더를 만들어 줘. 플랫폼, 게시 요일, 콘텐츠 형식, 주제를 열로 하는 테이블로 보여 줘.

캠페인 분석:

> 이 캠페인 데이터를 검토해서 리드 수, 매출 성장, 퍼널 전환을 차트로 만들어 줘.

자동화 워크플로우:

> 대체 분기가 포함된 부재중 전화 문자 회신 자동화를 Mermaid 순서도로 만들어 줘.

---

## 활용 팁

프롬프트를 쓸 때 몇 가지를 지키면 **AI에게 문의**가 더 정확하고 쓸모 있는 아티팩트를 만들어요.

- 가능하면 원하는 출력 형식을 요청하세요.
- 비즈니스 목표를 분명하게 설명하세요.
- 관련 데이터, 워크플로우, 캠페인 정보를 포함하세요.
- 상황에 따라 요약보다 추천을 요청하세요.
- 선택지를 평가할 때는 순위, 비교, 우선순위 기준을 지정하세요.
- 추가 정보가 필요하면 **AI에게 문의**가 안내 질문을 하도록 두세요.
- 대화를 이어 가며 생성된 아티팩트를 다듬거나 늘리세요.

## 자주 묻는 질문

### 특정 아티팩트를 꼭 요청해야 하나요?

아니요. **AI에게 문의**가 요청에 가장 알맞다고 판단하는 형식을 자동으로 골라요. 다만 출력 형식을 직접 지정하면 보통 더 예측하기 쉬운 결과가 나와요.

### Mermaid 다이어그램은 어디에 쓰나요?

워크플로우, 자동화, 리드 라이프사이클, 캠페인 흐름, 의사 결정 트리, 표준 운영 절차를 시각적으로 나타낼 때 써요.

### Mermaid 다이어그램을 전체 화면으로 볼 수 있나요?

네. 큰 Mermaid 다이어그램은 전체 화면 보기를 지원하고, 이동, 확대/축소, 도구 모음 컨트롤로 더 편하게 살펴볼 수 있어요.

### 안내 질문이 뭔가요?

**AI에게 문의**가 답변을 만들기 전에 부족한 정보를 모으려고 던지는 대화형 질문이에요. 최종 결과가 더 정확해지도록 도와줘요.

### AI에게 문의로 차트와 테이블을 만들 수 있나요?

네. 프롬프트에 구조화된 데이터나 성과 지표가 있으면, **AI에게 문의**가 정보를 테이블로 정리하고 지원되는 차트를 만들어 줘요.

### 아티팩트가 하이퍼클래스에서 작업을 자동으로 처리해 주나요?

항상 그런 것은 아니에요. 아티팩트는 정보를 정리해서 보여 주는 역할을 해요. 일부 작업은 여전히 사용자의 확인, **AI에게 문의**에서 지원하는 기능, 또는 알맞은 사용자 권한이 필요해요.

### 아티팩트 형식을 바꿔 달라고 요청할 수 있나요?

네. 대화를 이어 가면서 다른 형식을 요청할 수 있어요. 예를 들어 테이블을 차트로 바꾸거나, 글로 쓴 워크플로우를 Mermaid 다이어그램으로 만들어 달라고 할 수 있어요.

### 어떤 프롬프트가 가장 좋은 아티팩트를 만드나요?

목표를 분명하게 설명하고, 관련 상황이나 데이터를 주고, 가능하면 원하는 출력 형식까지 지정한 프롬프트가 가장 좋은 결과를 만들어요.
