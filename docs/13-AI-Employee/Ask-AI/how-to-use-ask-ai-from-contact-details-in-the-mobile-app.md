# 모바일 앱 연락처 세부정보에서 AI에게 문의 사용하기

**AI에게 문의**를 쓰면 연락처 프로필에서 나가지 않고도 해당 연락처의 활동을 빠르게 파악하고, 미팅을 준비하고, 메모를 남길 수 있어요. 대화, 예약, 기회, 작업이 한 화면에 모이고, 연락처의 기존 정보를 바탕으로 질문하거나 요약을 만들거나 음성으로 메모를 받아 적게 할 수 있어요.

## 연락처 세부정보의 AI에게 문의란?

**AI에게 문의**는 연락처 세부정보 화면에서 바로 그 연락처에 관한 정보를 알려 주는 모바일 어시스턴트예요. 실제 CRM 기록으로 만든 요약 카드를 보여 주고, 고객 관계를 관리하는 데 도움이 되는 AI 작업을 제안해요.

이 기능은 iOS와 Android의 하이퍼클래스 모바일 앱, 그리고 4.27.0 버전 이상을 쓰는 지원 대상 화이트라벨 앱에서 쓸 수 있어요. **'AI에게 문의' 액세스**가 있는 사용자만 사용할 수 있어요.

## 연락처 세부정보에서 AI에게 문의를 쓰면 좋은 점

연락처 기록을 찾아보는 시간이 줄고, 후속 작업을 더 효율적으로 끝낼 수 있어요.

- 연락처 한눈에 보기: 메시지, 예약, 기회, 작업을 한곳에서 볼 수 있어요.
- 미팅 준비: 다가오는 예약 전에 브리핑을 만들 수 있어요.
- 간편한 메모: 음성으로 메모를 남기고, 저장하기 전에 내용을 확인할 수 있어요.
- 최신 정보: 질문에 답할 때 **AI에게 문의**가 가져올 수 있는 가장 최신 연락처 기록을 사용해요.
- 직접 통제: AI가 제안한 메모와 작업은 내가 승인해야 저장돼요.

## 연락처 요약 카드 살펴보기

요약 카드에는 기존 CRM 기록에서 가져온 주요 연락처 정보가 표시돼요. 지금 이 연락처와 어떤 관계인지 빠르게 파악할 수 있어요.

| 정보 | 내용 |
| --- | --- |
| **Last Message**(마지막 메시지) | 마지막 메시지의 커뮤니케이션 채널과 그 뒤로 지난 시간 |
| **Next Appointment**(다음 예약) | 다가오는 예약, 예약 상태, 추가 예약 건수(+N more) |
| **Biggest Open Deal**(가장 큰 진행 중 딜) | 파이프라인, 단계, 마지막으로 단계가 바뀐 뒤 지난 일수 |
| **Open Tasks**(미완료 작업) | 아직 끝나지 않은 작업과 기한 초과 표시 |

행을 탭하면 해당 기록이 열려요. 카드에는 내가 볼 권한이 있는 정보만 표시돼요.

## 연락처에서 쓸 수 있는 AI에게 문의 작업

**AI에게 문의**는 선택한 연락처에 맞는 작업을 제안해요. 대화를 준비하고 중요한 내용을 기록하기가 쉬워져요.

**Prep Me for Next Appointment**(다음 예약 준비)

다가오는 미팅 전에 연락처의 기록을 바탕으로 짧은 브리핑을 만들어 줘요. 연락처에 7일 이내 예약이 있을 때만 이 옵션이 나타나요.

**Summarize This Contact**(이 연락처 요약)

연락처와의 관계 이력과 활동을 AI가 정리해 줘요. 모든 연락처에서 쓸 수 있고, 이어서 추가 질문도 할 수 있어요.

**Dictate to Add a Note**(음성으로 메모 추가)

메모를 타자 대신 말로 남길 수 있어요. **AI에게 문의**가 음성을 메모 초안으로 바꿔 주고, 후속 조치가 필요하면 작업도 제안해요.

```
제안된 작업은 승인하기 전까지 아무것도 저장되지 않아요.
```

연락처에 대해 궁금한 점을 직접 입력해서 물어볼 수도 있어요.

## 권한, 데이터 접근, 채팅 동작

**AI에게 문의**는 내가 가진 기존 접근 권한을 기준으로 볼 수 있는 연락처 기록을 정해요. 아래 내용을 알아 두면 기능을 안전하게 쓰고 대화를 잘 관리할 수 있어요. 권한 관리에 관한 자세한 내용은 [AI에게 문의 이용 권한 설정: 사용자 권한 관리](../../44-신기능-2026/ask-ai-access-controls-manage-user-permissions.md)를 참고하세요.

- 권한: 이 기능만을 위한 별도 권한은 필요하지 않아요. 다만 **'AI에게 문의' 액세스**가 있어야 해요.
- 새 채팅: 연락처에서 **AI에게 문의**를 열면 새 채팅이 시작돼요. 첫 메시지를 보낸 뒤 같은 연락처로 다른 채팅을 시작하려면 + 아이콘을 탭하세요.
- 오프라인 접근: 이전에 불러온 연락처 세부정보는 오프라인에서도 계속 보일 수 있어요. 볼 수 있는 내용이 없으면 앱에 "Couldn't load details."(세부정보를 불러올 수 없음)라고 표시돼요. 다시 연결한 뒤 화면을 아래로 당겨 다시 시도하세요.
- 삭제된 연락처: 연락처가 삭제됐거나 접근 권한이 없어지면 **AI에게 문의**가 연락처를 사용할 수 없다는 메시지를 보여 줘요.
- **Voice Mode**(음성 모드): 연락처 전용 채팅에서는 **Voice Mode** 전체 기능을 쓸 수 없어요. 대신 **Dictate to Add a Note**를 사용하세요. **Voice Mode**는 [AI에게 문의 음성 모드 사용 방법](../../44-신기능-2026/how-to-use-ask-ai-voice-mode.md)에서 자세히 볼 수 있어요.

## 연락처 세부정보에서 AI에게 문의 사용하기

연락처에서 바로 **AI에게 문의**를 열면 어시스턴트가 그 연락처의 정보를 이미 알고 있어요. 연락처를 다시 검색할 필요가 없어요.

1. 모바일 앱에서 **연락처**, **대화**, **검색** 중 한 곳으로 이동해 연락처를 선택하세요.
2. 연락처 상단 바에서 **AI에게 문의** 아이콘을 탭하세요.

   ![연락처 상단 바의 AI에게 문의 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084764878/original/NB4PRn9jgoOr4IlnA1vIUzjTkPanb_m2JQ.png?1793634030)
3. 최근 메시지, 다가오는 예약, 진행 중인 기회, 작업을 요약 카드에서 확인하세요.
4. **Prep Me**(예약 준비), **Summarize**(요약), **Dictate**(음성 메모) 중 하나를 고르거나 궁금한 점을 직접 입력하세요.

   ![AI에게 문의 작업 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084764967/original/knP4OXSU9mlX8DIQjRPj_ayfnhGlCs1Oxg.png?1793634078)
5. 제안된 메모나 작업을 확인하고 승인한 뒤 저장하세요.

## 자주 묻는 질문

### Prep Me 버튼이 안 보여요.
연락처에 7일 이내 예약이 있을 때만 나타나요.

### 연락처 정보 일부가 보이지 않아요.
요약 카드에는 내가 접근할 권한이 있는 기록만 표시돼요.

### 음성으로 남긴 메모에서 AI에게 문의가 작업도 만들 수 있나요?
네. 필요하면 **AI에게 문의**가 작업을 제안해요. 다만 승인해야 저장돼요.

### 오프라인에서도 AI에게 문의를 쓸 수 있나요?
이전에 불러온 연락처 세부정보는 오프라인에서 볼 수 있을 수 있어요. 정보를 새로 고치려면 다시 연결하세요.

### AI에게 문의가 이전 연락처 채팅을 기억하나요?
연락처에서 **AI에게 문의**를 열면 새 채팅이 시작돼요. 첫 메시지를 보낸 뒤 +를 탭해서 처음부터 다시 시작할 수도 있어요.

### 연락처 채팅에서도 Voice Mode 전체 기능을 쓸 수 있나요?
아니요. 연락처 전용 채팅에서는 아직 **Voice Mode** 전체 기능을 지원하지 않아요. **Dictate to Add a Note**를 사용하세요.

### 기회 금액에 통화 기호가 표시되지 않아요.
현재 AI가 만든 답변에서는 딜 금액이 통화 기호 없이 숫자로만 표시돼요.
