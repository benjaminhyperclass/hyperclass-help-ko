# AI에게 문의로 미디어 저장소 열고 관리하기

**AI에게 문의**(Ask AI)에서 대화하듯 말하면 **미디어 라이브러리**, Google Drive, Canva 파일을 관리할 수 있어요. 이 문서에서는 어떤 작업을 할 수 있는지, 그리고 변경 전에 승인을 받는 안전장치가 어떻게 작동하는지 설명해요.

## 미디어 저장소 × AI에게 문의 연동이란?

**미디어 저장소**(Media Storage) 기능이 하이퍼클래스의 AI 어시스턴트인 **AI에게 문의**와 연결되었어요. 대화로 파일, 폴더, Google Drive 내용, Canva 디자인을 찾아보고 정리하고 처리할 수 있어요.

**미디어 라이브러리** 화면을 일일이 열어 볼 필요 없이 하고 싶은 일을 말하면 돼요. 파일 이동, 폴더 만들기, 저장 용량 확인, Canva 디자인 내보내기 같은 작업이 가능해요. **AI에게 문의**가 작업 과정을 안내하고, 변경하기 전에는 항상 승인을 요청해요.

이번 연동은 미디어 저장소 AI 기능의 첫 단계예요. 기존 기능을 **AI에게 문의**에서 쓸 수 있게 했고, 앞으로 더 다양한 미디어 작업을 지원하기 위한 기반이 돼요.

## 이럴 때 편해요

- 미디어 정리가 빨라져요: 화면을 오가지 않고 대화만으로 파일을 찾고, 정리하고, 옮기고, 지울 수 있어요.
- 저장 용량을 바로 확인해요: 사용량 화면을 열지 않고도 무엇이 저장 공간을 차지하는지 물어볼 수 있어요.
- 연결된 서비스를 한곳에서 써요: 내 미디어와 같은 대화에서 Google Drive와 Canva에도 접근할 수 있어요.
- 더 안전하게 실행해요: 변경 작업은 승인을 받은 뒤에 실행하고, 삭제는 휴지통으로만 이동해서 모든 작업을 직접 통제할 수 있어요.
- 앞으로의 기능을 위한 기반이 돼요: 이후 출시될 고급 AI 미디어 작업의 토대가 돼요.

## 미디어 라이브러리에서 할 수 있는 작업

### 파일 찾아보기와 정리

- **미디어 라이브러리**의 파일과 폴더를 목록으로 보고 필터링해요.
- 새 폴더를 만들고, 파일과 폴더의 이름과 세부 정보를 바꿔요.
- 파일과 폴더를 원하는 폴더로 옮겨요.
- 미디어 URL이나 ID로 특정 파일을 찾고, 그 파일이 있는 폴더 경로를 확인해요.

### 외부 URL에서 파일 가져오기

외부 URL의 파일을 **미디어 라이브러리**로 가져와요. 가져오기 전에 **AI에게 문의**가 서버에서 URL을 검증해요.

### 휴지통 이동과 복원

- 파일이나 폴더 하나를 휴지통으로 옮기거나, 여러 개를 한 번에 옮겨요.
- 휴지통으로 옮긴 항목을 다시 복원해요.
- 삭제한 항목은 모두 복구할 수 있어요. **AI에게 문의**에서는 영구 삭제를 할 수 없어요.

### 저장 용량 확인

서브 계정이 사용 중인 미디어 저장 용량 전체를 물어보거나, 그룹이나 카테고리별로 나눠서 볼 수 있어요.

### 스톡 자산 둘러보기

서브 계정에서 쓸 수 있는 배경과 텍스처 자산을 목록으로 볼 수 있어요.

{% hint style="info" %}
삭제하면 항상 항목이 휴지통으로 이동하고, 확인 절차를 거쳐요. **AI에게 문의**로는 파일이 영구 삭제되지 않아요.
{% endhint %}

## Google Drive 연동

Google Drive가 미디어 저장소의 소스로 연결되어 있으면, **AI에게 문의**가 Drive의 파일과 폴더를 직접 관리해요. 연결 정보는 **AI에게 문의**가 자동으로 가져오기 때문에 연결 ID를 직접 찾을 필요가 없어요.

### 연결 상태 확인

서브 계정에 Google Drive가 미디어 저장소 소스로 연결되어 있는지 확인해요. 연결된 Drive 계정 정보와 저장 용량 할당량도 볼 수 있어요.

### Drive 파일 목록 보기와 필터링

연결된 Google Drive의 파일을 목록으로 볼 수 있어요. 폴더, 검색어, 파일 형식으로 필터링하는 것도 가능해요. Drive 폴더만 따로 볼 수도 있어요.

### Drive 폴더 만들기

**AI에게 문의**에서 바로 연결된 Google Drive에 새 폴더를 만들어요.

{% hint style="info" %}
**AI에게 문의**로 내 컴퓨터의 파일을 Google Drive에 바로 올리거나, Drive 파일을 내려받는 기능은 지원하지 않아요. 대신 URL을 이용해 **미디어 라이브러리**로 가져올 수 있어요.
{% endhint %}

## Canva 연동

서브 계정에 Canva가 연결되어 있으면, **AI에게 문의**에서 디자인 목록 보기, 새 디자인 만들기, Canva에 미디어 자산 업로드, 디자인 내보내기를 할 수 있어요.

### 연결 상태와 사용자 확인

Canva가 연결되어 있는지 확인하고, 연결된 Canva 사용자를 알려 줘요.

### 디자인 목록과 내용 확인

- Canva 디자인 목록을 보고, 디자인의 세부 정보와 편집 링크를 열어요.
- 디자인의 페이지와 내보낼 수 있는 형식을 확인해요.

### 새 디자인 만들기

**AI에게 문의**에서 바로 새 Canva 디자인을 만들어요.

### 미디어 자산 업로드

미디어 파일을 Canva에 자산으로 업로드하고, 업로드 상태를 확인해요.

### 디자인 내보내기

Canva 디자인을 지원되는 형식으로 내보내요. 내보내기가 끝나면 내보낸 파일을 받을 수 있어요.

{% hint style="info" %}
모든 작업은 승인 후에 실행돼요. **AI에게 문의**는 미디어를 되돌릴 수 없게 바꾸지 않아요. 만들기, 이름 변경, 이동, 휴지통 이동, 복원, 가져오기, Canva 작업 같은 모든 변경 작업은 실행 전에 직접 확인을 받아요.
{% endhint %}

## 사용자 통제와 안전장치

**AI에게 문의**는 미디어를 되돌릴 수 없게 바꾸지 않고 작업을 돕도록 만들어졌어요. 여러 안전장치가 있어서 모든 단계에서 직접 통제할 수 있어요.

- 변경은 승인 후 실행: 만들기, 이름 변경, 이동, 휴지통 이동, 복원, 가져오기, Canva 만들기·업로드·내보내기 같은 모든 변경은 실행 전에 승인을 요청해요.
- 조회는 바로 실행: 파일 목록 보기, 사용량 확인, 디자인 확인, Drive 내용 보기처럼 데이터를 읽기만 하는 작업은 바로 실행되고 아무것도 바꾸지 않아요.
- 삭제는 휴지통으로만: 삭제한 항목은 언제나 복구할 수 있어요. **AI에게 문의**에서는 영구 삭제를 할 수 없어요.
- 연결 상태 확인: Canva와 Google Drive 작업을 하려면 서브 계정에 해당 연동이 연결되어 있어야 해요. 연결되어 있지 않으면 추측해서 진행하지 않고 연결하라고 안내해요.
- ID를 임의로 만들지 않음: 파일, 폴더, 디자인, 연결 ID를 지어내지 않아요. 먼저 값을 찾아보거나 알려 달라고 요청해요.
- 서버에서 URL 검증: 미디어 저장소가 가져오는 외부 URL은 가져오기 전에 서버에서 검증해요.
- 서브 계정 범위 적용: 모든 작업은 현재 서브 계정 안에서만 이루어져요. 기존 미디어 저장소 권한과 접근 규칙도 그대로 적용돼요.

## AI에게 문의로 미디어 저장소 사용하기

하려는 작업을 말이나 글로 설명하기만 하면 돼요. 더 필요한 정보가 있으면 **AI에게 문의**가 물어보고, 실행할 작업을 보여 주고 승인을 요청해요.

1. 하이퍼클래스에서 **AI에게 문의**를 여세요.
2. 하려는 미디어 작업을 입력하거나 말하세요. 자연스러운 말로 충분해요. 예를 들어 "내 미디어 라이브러리의 파일을 보여 줘" 또는 "Q3 Creatives라는 폴더를 만들어 줘"라고 하면 돼요.
3. 추가 세부정보를 알려 주세요. 이동할 대상 폴더나 가져올 파일 URL처럼 정보가 더 필요하면 **AI에게 문의**가 되물어요.
4. **AI에게 문의**가 보여 주는 실행 예정 작업의 내용을 꼼꼼히 확인하세요.
5. 안내가 나오면 작업을 승인하세요. **AI에게 문의**가 작업을 실행하고 완료되었다고 알려 줘요.

### 요청 예시

- "내 미디어 라이브러리의 파일을 보여 줘."
- "Q3 Creatives라는 폴더를 만들어 줘."
- "이 이미지들을 Q3 Creatives 폴더로 옮겨 줘."
- "이 이미지를 URL로 내 미디어 라이브러리에 가져와 줘."
- "휴지통에 넣은 파일을 복원해 줘."
- "내 서브 계정은 저장 용량을 얼마나 쓰고 있어?"
- "내 Google Drive가 미디어에 연결되어 있어?"
- "내 Google Drive의 폴더 목록을 보여 줘."
- "내 Canva 디자인을 보여 줘."
- "이 Canva 디자인을 PNG로 내보내 줘."

## 자주 묻는 질문

### AI에게 문의를 쓰려면 파일 ID나 연결 ID를 직접 알려 줘야 하나요?

아니요. **AI에게 문의**가 연결 정보를 자동으로 가져오고, 설명한 내용을 바탕으로 파일, 폴더, 디자인 ID도 직접 찾아요. 기술적인 식별자를 직접 입력할 필요가 없어요.

### AI에게 문의로 파일을 영구 삭제할 수 있나요?

아니요. **AI에게 문의**에서 하는 삭제는 모두 휴지통으로 이동하는 방식이라 복구할 수 있어요. 되돌릴 수 없는 데이터 손실을 막기 위해 영구 삭제는 지원하지 않아요.

### Google Drive나 Canva를 연결하지 않았는데 AI에게 문의로 작업하려고 하면 어떻게 되나요?

**AI에게 문의**가 연동이 연결되어 있지 않다고 알려 주고 연결하라고 안내해요. 추측해서 진행하거나 유효한 연결 없이 작업하지 않아요.

### AI에게 문의로 내 컴퓨터의 파일을 Google Drive에 올릴 수 있나요?

아니요. 이번 버전에서는 **AI에게 문의**로 로컬 파일을 Google Drive에 바로 올리거나 Drive 파일을 내려받을 수 없어요. 대신 URL로 **미디어 라이브러리**와 Canva에 가져오는 기능은 쓸 수 있어요.

### AI에게 문의가 하는 모든 작업을 승인해야 하나요?

변경 작업은 모두 승인해야 해요. 만들기, 이름 변경, 이동, 휴지통 이동, 복원, 가져오기, Canva 작업이 해당돼요. 파일 목록 보기, 사용량 확인, 디자인 확인 같은 조회 작업은 아무것도 바꾸지 않으므로 승인 없이 바로 실행돼요.

### AI에게 문의에서 에이전시 전체의 저장 용량도 볼 수 있나요, 서브 계정만 볼 수 있나요?

현재 서브 계정의 저장 용량만 보여 줘요. 에이전시 전체 단위의 저장 용량 내역은 이번 버전에 포함되지 않아요.

### AI에게 문의로 미디어 라이브러리와 Google Drive 사이에서 파일을 옮길 수 있나요?

직접 옮길 수는 없어요. **AI에게 문의**로 Google Drive의 폴더를 보거나 만들 수 있고, 외부 URL의 파일을 **미디어 라이브러리**로 가져올 수 있어요. 두 곳 사이에서 파일을 옮기는 기능은 이번 버전에서 지원하지 않아요.

### 이 연동이 기존 미디어 저장소 권한을 바꾸나요?

아니요. **AI에게 문의**로 하는 모든 작업은 현재 서브 계정 범위 안에서 이루어지고, 기존 미디어 저장소 권한과 접근 규칙을 그대로 따라요.
