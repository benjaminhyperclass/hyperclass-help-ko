# AI에게 문의 세션 예시와 사용 비용

## AI에게 문의 세션 비용 이해하기

AI에게 문의 세션은 한 번 이상의 대화 턴으로 이루어져요. AI는 이 과정에서 계획을 세우고, 판단하고, 콘텐츠를 만들고, 지원되는 플랫폼 작업을 수행하고, 필요할 때 승인을 요청해요. 세션 비용은 제출한 프롬프트 수가 아니라 AI가 수행한 작업을 기준으로 측정해요.

한 세션에는 보통 다음과 같은 과정이 들어가요.

- 요청 내용 파악
- **Guided Questions**(안내 질문)로 추가 정보 수집
- 플랫폼 또는 외부 데이터 가져오기
- 여러 단계 계획
- 콘텐츠 또는 자산 만들기
- 표나 승인 카드 같은 구조화된 결과물 표시
- 지원되는 플랫폼 작업 실행
- 변경 전 승인 요청

더 복잡한 작업일수록 처리할 내용이 늘어나서 사용 비용도 높아지는 편이에요.

## AI에게 문의 요금 개요

에이전시 사용자는 하이퍼클래스 에이전시 요금제($97, $297, $497) 모두에서 추가 비용 없이 AI에게 문의를 쓸 수 있어요. 단, 공정 사용 정책이 적용돼요. 서브 계정 사용자는 AI 직원 구독 또는 사용한 만큼 결제하는 방식으로 쓸 수 있어요.

### AI 직원 요금제

AI 직원 Starter(월 $20), Growth(월 $50), Unlimited(월 $97) 요금제에는 AI에게 문의 사용량이 포함돼요. 상위 요금제일수록 사용 가능량이 더 많아요. 사용량은 5시간 단위로 이어지는 구간을 기준으로 측정하고, 해당 사용 한도가 적용돼요.

### 사용한 만큼 결제

AI 직원 구독이 없는 서브 계정 사용자는 사용한 만큼 결제하는 방식으로 AI에게 문의를 쓸 수 있어요. 요금은 세션마다 사용한 AI 모델, 리소스, 작업에 따라 달라져요.

세션 비용에 영향을 주는 요소는 다음과 같아요.

- 추론 단계 수
- 작업의 복잡도
- 콘텐츠 생성
- 이미지 등 생성된 미디어
- 차트, Mermaid 다이어그램, 구조화된 결과물
- 외부 데이터 가져오기
- 플랫폼 작업
- 승인 절차

간단한 초안 작성 세션은 여러 단계, 자산 생성, 플랫폼 업데이트가 이어지는 복잡한 작업보다 보통 비용이 적어요.

에이전시 사용자와 서브 계정 사용자에게 각각 포함되는 AI 기능, AI 직원 요금제별 사용 가능량, 사용한 만큼 결제 요금이 궁금하면 AI Products Pricing 문서를 참고하세요.

## 상품 가져오기 및 통화 변경

## 피트니스 퍼널 및 이메일 템플릿 만들기

AI에게 문의는 계획 수립, 비즈니스 파악, 지원되는 플랫폼 작업을 하나의 안내형 흐름으로 묶어 처리할 수 있어요. API로 지원되지 않는 플랫폼 기능이 있으면, 그 부분은 대신 설정 방법을 안내해 줘요.

### 개요

AI에게 문의가 코칭 퍼널 전체를 설계하고, 바로 쓸 수 있는 이메일 템플릿을 만들어 줬어요.

### 사용자 요청

> 내 피트니스 코칭 비즈니스를 위한 퍼널을 랜딩 페이지, 폼, 이메일 후속 발송, 예약 캘린더까지 전부 만들어 줘.

- 리드 수집 필드 제안

## AI에게 문의 세션 비용에 영향을 주는 요소

AI에게 문의 사용량은 프롬프트 수만이 아니라 세션 중에 수행한 작업을 기준으로 해요. 추론, 콘텐츠 생성, 플랫폼 작업이 더 필요할수록 세션이 더 많은 리소스를 사용해요.

다음과 같은 요소가 세션 비용을 높일 수 있어요.

- 여러 단계에 걸친 추론과 계획
- **Guided Questions**와 이어지는 추가 질의응답
- 플랫폼 연동
- 상품 가져오기
- 이메일 또는 마케팅 캠페인 만들기
- 승인 절차
- 차트, 표, Mermaid 다이어그램
- AI가 생성한 이미지와 미디어
- 분량이 큰 문서 작성
- 외부 데이터 가져오기
- 멀티채널 캠페인 준비

일반적으로는 다음과 같아요.

- 간단한 초안 작성은 사용 비용이 가장 낮은 편이에요.
- 구조화된 결과물이 포함된 콘텐츠 생성은 처리할 내용이 더 많아요.
- 승인과 플랫폼 작업이 포함된 여러 단계의 작업은 보통 AI 리소스를 더 많이 사용해요.
- 이미지 생성이나 그 밖의 렌더링 미디어는 대개 총 세션 비용을 높여요.

## 자주 묻는 질문

### AI에게 문의 요금은 어떻게 계산되나요?

세션 중에 사용한 AI 리소스를 기준으로 계산해요. 추론, 콘텐츠 생성, 결과물 렌더링, 외부 데이터 가져오기, 지원되는 플랫폼 작업이 모두 포함돼요.

### 프롬프트마다 비용이 똑같나요?

아니요. 요청의 복잡도와 필요한 처리량에 따라 비용이 달라져요.

### 승인 요청도 세션 비용에 영향을 주나요?

승인 절차에는 추가 추론과 구조화된 렌더링이 들어가므로 전체 세션 사용량에 포함될 수 있어요.

### 이미지 생성은 텍스트 생성보다 비용이 더 드나요?

대체로 그래요. 이미지나 그 밖의 시각 자산을 렌더링하는 데는 텍스트만 생성할 때보다 보통 AI 리소스가 더 많이 필요해요.

### AI에게 문의가 작업을 자동으로 완료할 수 있나요?

지원되는 일부 작업은 승인 후 바로 완료할 수 있어요. 그 밖의 작업은 연동 연결, 플랫폼 권한, 직접 설정이 필요할 수 있어요.

### 세 번째 예시에서 AI에게 문의가 모든 작업을 끝내지 못한 이유는 무엇인가요?

일부 게시 작업에는 연결된 소셜 계정이나 활성화된 WhatsApp 구독이 필요했기 때문이에요. AI에게 문의는 지원되는 작업을 모두 마치고, 남은 필수 조건을 알려 줬어요.
