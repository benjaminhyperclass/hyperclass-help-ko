# AI에게 문의 Chrome 확장 프로그램 설치하기

**AI에게 문의**(Ask AI) Chrome 확장 프로그램을 설치하면 AI가 대신 웹페이지를 열고, 클릭하고, 입력하고, 스크롤할 수 있어요. 지원하는 브라우저 작업을 AI에게 맡길 수 있어요.

**AI에게 문의**에 브라우저 작업이 필요한 요청을 입력하고, 안내가 나오면 **설치**를 선택하면 설치할 수 있어요. 아래 링크로 직접 들어가도 돼요: [Chrome 웹 스토어의 AI에게 문의 확장 프로그램](https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl)

---

## Chrome 확장 프로그램 설치 방법

위 링크로 바로 설치하거나, 아래 순서를 따라 설치하세요.

1. 왼쪽 메뉴에서 **AI에게 문의**를 선택하세요.

   ![왼쪽 메뉴에서 AI에게 문의 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734216/original/ElsRnREAoOPQAfEZ0tc9BbYwabWodIHdAg.png?1784844635)
2. 브라우저를 직접 조작해야 하는 요청을 입력하세요.

   *예: "Google Docs를 열어서 이벤트 랜딩 페이지 개요를 만들어 줘."*

   ![브라우저 작업 요청 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734319/original/_lV-VWRzUKewUmkuuMYPz9DJnOtcQJDY3g.png?1784844929)
3. **AI에게 문의**가 브라우저 확장 프로그램 설치를 안내하면 **설치**를 선택하세요. Chrome 웹 스토어의 [AI에게 문의 확장 프로그램](https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl) 페이지로 이동해요.

   ![설치 버튼 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734321/original/BB_uwkwQnahpTR-L_Ggf46ER-929MIZVOg.png?1784844942)
4. Chrome 웹 스토어 페이지에서 **Add to Chrome**(Chrome에 추가)을 선택하세요.

   ![Chrome에 추가 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734324/original/KTudp0XyyH0hfJUFM5Fwxd_1rOvoa6CeIQ.png?1784844953)
5. 확장 프로그램의 권한을 확인한 다음 **Add extension**(확장 프로그램 추가)을 선택하세요.

   ![확장 프로그램 권한 확인 후 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734391/original/d5UWdrW0H4eDQlDyygZrbRUFF3Gqlmftgw.png?1784845199)
