# AI에게 문의 분할 보기 사용하기

**AI에게 문의**의 분할 보기를 쓰면 작업 중인 하이퍼클래스 화면을 그대로 보고 조작하면서 옆에서 AI와 대화할 수 있어요. 이 문서에서는 분할 보기가 무엇인지, 어디서 쓸 수 있는지, 어떻게 켜고 끄는지 알려 드려요.

## 분할 보기란?

분할 보기는 **AI에게 문의** 패널을 하이퍼클래스 작업 화면 옆에 붙여 두는 보기 방식이에요. 지금 보고 있는 화면을 참고하거나 조작하면서 동시에 **AI에게 문의**를 쓰고 싶을 때 알맞아요.

분할 보기를 켜면 하이퍼클래스 화면이 그대로 보이고 클릭도 할 수 있어요. **AI에게 문의**를 닫지 않아도 화면을 이동하고 정보를 확인하면서 작업을 이어갈 수 있어요. 떠 있는 패널이 필요한 내용을 가리는 일도 없어요.

분할 보기 설정은 하이퍼클래스 안에서 화면을 옮겨 다녀도 기억돼요. 분할 보기를 지원하지 않는 화면으로 이동하면 **AI에게 문의**가 플로팅 패널로 바뀌어요. 지원하는 화면으로 돌아오면 분할 보기 설정이 자동으로 다시 적용돼요.

## 분할 보기의 장점

- **나란히 작업:** **AI에게 문의**와 하이퍼클래스 작업 화면을 동시에 볼 수 있어요.
- 화면을 그대로 쓸 수 있어요: AI와 대화하면서 하이퍼클래스 화면을 클릭하고, 스크롤하고, 조작할 수 있어요.
- 방해가 줄어요: 아래 내용을 보려고 플로팅 패널을 계속 열고 닫거나 옮기지 않아도 돼요.
- 선호하는 보기가 유지돼요: 지원하는 화면과 지원하지 않는 화면을 오가도 분할 보기 설정을 기억해요.

## 분할 보기를 쓸 수 있는 곳

현재 분할 보기는 다음 화면에서 지원해요.

- 에이전시 대시보드
- 에이전시 런치패드
- 서브 계정 대시보드
- 서브 계정 런치패드
- 캘린더
  - 캘린더 보기
  - 예약
  - **Troubleshoot**(문제 해결)
- 캘린더 설정
  - 환경설정
  - 가용성
  - 연결
  - 서비스
  - 대여

지원하지 않는 화면으로 이동하면 **분할 보기 열기** 옵션이 숨겨지고 **AI에게 문의**가 플로팅 패널로 열려요. 분할 보기 설정은 사라지지 않아요. 지원하는 화면으로 돌아오면 분할 보기가 저절로 다시 적용돼요.

{% hint style="info" %}
분할 보기 지원 여부는 **AI에게 문의**를 화면 옆에 붙일 수 있는지에만 영향을 줘요. 페이지 요소 선택과 자동 페이지 컨텍스트는 호스트 페이지가 있으면 플로팅 패널에서도 쓸 수 있어요.
{% endhint %}

## AI에게 문의 분할 보기 켜는 방법

1. 하이퍼클래스에 로그인한 뒤 분할 보기를 지원하는 화면으로 이동하세요.
2. 오른쪽 위에 있는 버튼을 눌러 **AI에게 문의**를 여세요.
3. **AI에게 문의** 패널 위쪽에서 **분할 보기 열기**를 클릭하세요.
4. **AI에게 문의**가 현재 하이퍼클래스 화면 옆에 붙어요. 화면을 계속 조작하면서 AI에게 질문하거나 지시할 수 있어요.
5. 플로팅 패널로 돌아가려면 **AI에게 문의** 패널 위쪽에서 **분할 보기 닫기**를 클릭하세요.

## 자주 묻는 질문

### 분할 보기 열기 옵션이 보이지 않아요.
지금 보고 있는 화면이 분할 보기를 지원하지 않을 수 있어요. 지원하지 않는 화면에서는 분할 보기 버튼이 숨겨지고 **AI에게 문의**가 플로팅 패널로 열려요.

### 지원하는 화면으로 돌아오면 분할 보기를 다시 켜야 하나요?
아니요. 분할 보기를 저장된 설정으로 쓰고 있다면, 지원하는 화면으로 돌아왔을 때 **AI에게 문의**가 자동으로 붙은 상태로 돌아와요.

### 분할 보기를 연 상태에서도 하이퍼클래스 화면을 조작할 수 있나요?
네. **AI에게 문의**가 옆에 붙어 있어도 하이퍼클래스 화면은 그대로 보이고 클릭할 수 있어요.

### 페이지 요소 선택을 쓰려면 분할 보기가 필요한가요?
아니요. 페이지 요소 선택은 **AI에게 문의**의 기능이라서, 호스트 페이지가 있으면 플로팅 패널에서도 쓸 수 있어요.

### 분할 보기에서도 페이지 컨텍스트를 쓸 수 있나요?
네. 분할 보기를 연 상태에서도 **AI에게 문의**가 페이지 컨텍스트를 쓸 수 있어요. 지원하는 호스트 페이지에서는 페이지 요소 선택과 자동 페이지 컨텍스트도 포함돼요. 이 기능들은 분할 보기에서만 쓰는 게 아니라, **AI에게 문의**가 플로팅 패널로 열려 있을 때도 쓸 수 있어요.
