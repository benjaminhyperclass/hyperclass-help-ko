# 지식 베이스 개요

**지식 베이스**는 지원되는 AI 도구가 참고할 소스 콘텐츠를 만들고, 정리하고, 관리하는 하이퍼클래스의 중심 공간이에요. 새로 바뀐 지식 베이스 화면에서는 요약 보기로 전체 구성을 한눈에 확인하고, 데이터 소스를 탭별로 나눠 관리할 수 있어요. 이 문서에서는 랜딩 페이지, 소스 탭, 사용자 권한, 테스트 방법, 달라진 점을 안내해요.

---

## 지식 베이스란?

지식 베이스에는 웹사이트 페이지, 자주 묻는 질문, 테이블, 서식 있는 텍스트, 업로드한 파일 같은 소스 콘텐츠가 저장돼요. 지원되는 AI 도구는 질문에 답할 때 이 콘텐츠에서 알맞은 정보를 찾아 써요. ▶ 영상 [10강 1부 24:46](https://www.youtube.com/watch?v=c4QmTGpfdCc&t=1486s) · [10강 1부 25:22](https://www.youtube.com/watch?v=c4QmTGpfdCc&t=1522s)

새 화면에서는 어떤 콘텐츠가 있는지, 어디에서 가져온 것인지, 어떻게 관리되는지를 더 분명하게 볼 수 있어요. 요약 보기와 탭으로 나뉜 데이터 소스가 있고, 하이퍼클래스의 지원되는 여러 제품에서 같은 지식 베이스 컴포넌트를 함께 써요.

메뉴 경로: **AI 에이전트 > 지식 베이스**

## 지식 베이스 랜딩 페이지

지식 베이스 랜딩 페이지에서는 만들어 둔 지식 베이스를 모두 볼 수 있어요. 새 지식 베이스를 만들 수도 있고, 지식 베이스를 열어 소스를 관리할 수도 있어요.

## 새 지식 베이스 화면의 장점

새 화면에서는 AI가 활용할 콘텐츠를 덜 헷갈리게 관리할 수 있어요. 여러 페이지를 오가며 찾을 필요 없이, 지식 베이스 구조와 소스 개수, 소스별 설정을 한 화면에서 확인할 수 있어요.

- 소스를 한눈에 볼 수 있어요. 어떤 콘텐츠가 있고 어디에서 왔는지 확인할 수 있어요.
- 더 빠르게 이동할 수 있어요. 소스 탭을 눌러 페이지를 바꾸지 않고도 소스 유형별로 관리할 수 있어요.
- 한곳에서 관리할 수 있어요. 지식 베이스를 만들고, 열고, 확인하고, 관리하는 일을 한 영역에서 해요.
- AI 설정이 일관돼요. 지원되는 여러 제품에서 같은 지식 베이스 화면을 써요.
- 콘텐츠를 더 쉽게 관리할 수 있어요. 소스 개수를 확인하고, 새 소스를 추가하고, 기존 콘텐츠를 수정할 수 있어요.
- 설정이 덜 헷갈려요. 관리자와 편집자가 AI용 콘텐츠를 관리하기 쉬운 구조예요.

## 달라진 점

### 요약 보기

이제 지식 베이스를 열면 요약 보기가 가장 먼저 나와요. 연결된 소스와 전체 구조를 간략하게 보여 주기 때문에 현재 상태를 빠르게 파악할 수 있어요.

### 탭으로 나뉜 데이터 소스

모든 데이터 소스가 개별 탭으로 나뉘어 있어요. 탭 하나가 소스 유형 하나를 뜻해서, 페이지를 바꾸지 않고도 콘텐츠를 관리하고 확인할 수 있어요. 새로운 데이터 소스가 출시되면 새 탭으로 추가돼요.

### 공용(federated) 컴포넌트 사용

지식 베이스는 여러 제품에서 함께 쓰는 공용(federated) 컴포넌트를 사용해요. 그래서 하이퍼클래스 어디에서 지식 베이스를 열어도 레이아웃, 이동 방법, 관리 방법이 같아요.

---

## 지식 베이스 소스 (탭 구성)

지식 베이스를 열면 지원되는 소스 유형이 탭으로 나타나요. 예를 들어 다음과 같아요.

- **Web Crawler**(웹 크롤러)
- **FAQ**(자주 묻는 질문)
- **Web Search**(웹 검색)
- **Tables**(테이블)
- **Rich Text**(서식 있는 텍스트)
- **File Upload**(파일 업로드)

각 탭에는 연결된 항목의 개수가 표시되고, 소스를 추가하거나 관리하는 기능이 있어요.

## 이런 분께 맞는 화면이에요

새 지식 베이스 화면은 다음 사용자를 위해 만들었어요.

- 지식 베이스와 데이터 소스를 관리하는 관리자
- 지식 콘텐츠를 다듬고 유지하는 편집자

보기 권한만 있는 사용자는 콘텐츠를 볼 수 있지만, 관리 기능은 보이지 않아요.

---

## 달라지지 않은 점

이번 업데이트는 다음 내용에 영향을 주지 않아요.

- 콘텐츠를 작성하고 편집하는 방법
- 권한과 접근 수준
- 인덱싱 로직과 AI 동작
- 기존 지식 베이스와 소스

---

## 적용 시기

새 지식 베이스 화면은 순차적으로 적용되고 있어요. 아직 요약 보기나 탭으로 나뉜 데이터 소스가 보이지 않아도, 업데이트가 계정에 적용되면 자동으로 나타나요. 따로 할 일은 없어요.

---

## 자주 묻는 질문

### 요약 보기가 무엇인가요?
요약 보기는 지식 베이스를 간략하게 보여 주는 화면이에요. 연결된 소스와 전체 구조를 확인할 수 있어요.

### 요약 보기가 소스 탭을 대신하나요?
아니요. 요약 보기는 전체를 넓게 보여 주고, 각 소스 탭에서는 소스별 상세 정보와 관리 옵션을 볼 수 있어요.

### 같은 유형의 소스를 여러 개 추가할 수 있나요?
네. 지원되는 경우 같은 소스 탭 안에 소스를 여러 개 추가할 수 있어요.

### 탭으로 나타날 수 있는 소스 유형에는 어떤 것이 있나요?
**Web Crawler**, **FAQ**, **Web Search**, **Tables**, **Rich Text**, **File Upload** 탭이 나타날 수 있어요.

### 관리 기능이 보이지 않아요.
사용자 권한으로는 소스를 관리할 수 없는 상태일 수 있어요. 보기 권한만 있는 사용자는 허용된 범위에서 콘텐츠를 볼 수 있지만, 관리 기능은 보이지 않아요.

### 새 화면이 되면 기존 지식 베이스가 바뀌나요?
아니요. 기존 지식 베이스와 소스는 그대로 사용할 수 있어요. 이번 개편으로 바뀌는 것은 이동 방식과 화면 구성이고, 기존 콘텐츠는 바뀌지 않아요.

### 새 화면이 인덱싱이나 AI 동작을 바꾸나요?
아니요. 이번 업데이트는 인덱싱 로직과 AI 동작을 바꾸지 않아요.

### 새 화면이 아직 보이지 않아요.
새 지식 베이스 화면은 순차적으로 적용되고 있어요. 업데이트가 계정에 적용되면 자동으로 나타나요.

### 지식 베이스 콘텐츠를 AI가 제대로 찾아오는지 어떻게 테스트하나요?
**Knowledge Base Retrieval Tester**(지식 베이스 검색 테스터)에서 샘플 질문을 입력해 보세요. 어떤 소스가 결과로 나오는지 확인할 수 있어요.

### 지식 베이스를 만들면 AI 에이전트에 자동으로 연결되나요?
아니요. AI 응답에 활용하려면 지식 베이스를 해당 AI 제품, 에이전트, 도구에 연결하거나 첨부해야 해요.

### 어떤 소스 유형을 써야 하나요?
- 웹사이트 콘텐츠는 **Web Crawler**를 쓰세요.
- 질문과 답변을 직접 입력하려면 **FAQ**를 쓰세요.
- CSV 같은 구조화된 데이터는 **Tables**를 쓰세요.
- 직접 작성한 콘텐츠는 **Rich Text**를 쓰세요.
- 지원되는 문서 파일은 **File Upload**를 쓰세요.
