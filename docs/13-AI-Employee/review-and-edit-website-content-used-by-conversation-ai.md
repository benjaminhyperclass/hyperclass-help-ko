# 대화 AI가 사용하는 웹사이트 콘텐츠 검토하고 편집하기

웹사이트를 학습 소스로 추가하면 대화 AI가 해당 페이지의 내용을 수집해서 답변에 활용해요. 수집된 웹사이트 콘텐츠를 검토하고 편집해 두면 AI 답변을 현재 비즈니스 정보에 맞게 정확하게 유지할 수 있어요. 이 문서에서는 수집된 콘텐츠를 검토·수정하고, 편집된 소스를 확인하고, 다시 수집하는 방법을 안내해요.

---

## 웹사이트 콘텐츠 검토란?

웹사이트 콘텐츠 검토를 이용하면 대화 AI가 사용하는 웹사이트 소스에서 하이퍼클래스가 추출한 내용을 보고 편집할 수 있어요. AI 에이전트가 고객 질문에 답할 때 참고하는 원본 자료를 직접 다듬을 수 있죠. 웹사이트 페이지에는 오래된 정보, 관련 없는 문구, 서식 문제, 빠진 맥락이 섞여 있을 수 있어요. 수집된 콘텐츠를 검토하면 대화 AI가 쓰는 정보를 더 잘 관리할 수 있어요.

웹사이트 콘텐츠는 **봇 학습**이나 **지식 베이스**에서 사용하는 **Web Crawler**(웹 크롤러) 소스에서 가져와요. Web Crawler는 정확한 URL, 경로, 도메인, 지원되는 웹 기반 소스로 봇을 학습시킬 수 있어서, 대화 AI가 상황에 맞는 답변을 하는 데 도움이 돼요.

---

## 웹사이트 콘텐츠를 검토하고 편집하면 좋은 점

수집된 콘텐츠를 검토하면 대화 AI가 깔끔하고 최신이며 고객에게 보여 주기 적합한 정보를 사용하게 돼요. 웹사이트에 지난 프로모션, 중복 콘텐츠, 복잡한 서식, 고객 대화에서 쓰면 안 되는 정보가 있을 때 특히 유용해요.

- 정확도 향상: 오래되었거나 불완전한 웹사이트 정보를 수정해서 대화 AI가 더 좋은 자료를 참고하도록 해요.
- 더 적합한 답변: 고객 질문에 도움이 되지 않는 관련 없는 페이지 내용, 메뉴 문구, 불필요한 웹사이트 문구를 지울 수 있어요.
- 더 나은 고객 경험: 서비스, 정책, 가격, 위치, 영업시간, 지원 안내에 맞게 답변을 유지해요.
- 더 큰 관리 권한: 실제 웹사이트는 바꾸지 않고 수집된 콘텐츠만 직접 조정할 수 있어요.
- 쉬운 유지 관리: 편집된 소스를 확인하고, 웹사이트 콘텐츠를 새로 고치거나 다시 수집하기 전에 검토할 수 있어요.

---

## 웹사이트 소스와 수집된 콘텐츠

웹사이트 소스는 대화 AI가 고객 질문에 답할 때 쓰는 **지식 소스** 중 하나예요. 하이퍼클래스 **지식 베이스**에는 자주 묻는 질문(FAQ), 서식 있는 텍스트, 표, 파일 업로드, Web Crawler 소스, 웹 검색 소스 같은 다른 소스 유형도 포함할 수 있어요. 대화 AI는 답변을 만들기 전에 이런 소스에서 관련 정보를 찾아와요.

웹사이트 구조에 따라 수집된 콘텐츠에는 페이지, 섹션, 상호작용 요소의 정보가 들어갈 수 있어요. 향상된 웹 크롤러(Enhanced Web Crawler)는 최신 웹사이트에서 더 많은 콘텐츠를 가져오도록 만들어졌어요. 탭, 아코디언, 지연 로딩(lazy-load) 섹션 등 상호작용 영역의 내용도 수집해요.

---

## 수집된 웹사이트 콘텐츠를 편집해야 할 때

웹사이트의 정보가 AI 답변에 적합하지 않을 수 있다면 수집된 콘텐츠를 검토하세요. 소스가 깔끔하면 대화 AI가 더 일관되게 답하고, 고객이 오래된 정보나 관련 없는 정보를 받을 가능성도 줄어요.

다음과 같은 경우에 수집된 콘텐츠를 편집해 보세요.

- 지난 가격, 만료된 오퍼, 오래된 프로모션이 있어요.
- 영업시간, 위치, 서비스 정보가 잘못되어 있어요.
- 웹사이트 문구가 너무 광범위하거나 모호하거나 불분명해요.
- 머리글, 바닥글, 메뉴, 반복되는 페이지 영역에서 가져온 중복 콘텐츠가 있어요.
- 대화 AI가 고객 질문에 답하는 데 도움이 될 맥락이 빠져 있어요.
- 웹사이트에는 남겨 두어야 하지만 AI 에이전트가 쓰면 안 되는 내용이 있어요.

수집된 콘텐츠를 편집하면 대화 AI가 사용하는 소스 콘텐츠만 바뀌어요. 실제 웹사이트는 수정되거나 게시되지 않아요.

---

## 편집된 웹사이트 콘텐츠 확인하기

처음 수집한 뒤 직접 수정한 소스에는 표시가 붙어서 구분할 수 있어요. 어떤 소스에 직접 편집한 내용이 있고, 어떤 소스가 수집 당시 웹사이트 데이터 그대로인지 한눈에 파악할 수 있어요.

소스를 새로 고치거나 다시 수집하기 전에 편집 표시를 보고 중요한 소스를 검토하세요. 직접 고친 서비스 정보, 가격 설명, 정책 문구 등 고객에게 보이는 정보를 그대로 유지해야 할 때 특히 도움이 돼요.

---

## 웹사이트 콘텐츠 새로 고침 또는 다시 수집하기

웹사이트 소스를 새로 고치거나 다시 수집하면 웹사이트에서 최신 콘텐츠를 바로 가져와요. 실제 웹사이트를 업데이트했고, 대화 AI가 더 새로운 페이지 정보를 쓰길 원할 때 유용해요. 다만 새로 고치면 이전에 편집한 내용을 덮어쓰고 새로 수집한 웹사이트 데이터로 바뀔 수 있어요.

**Auto Refresh**(자동 새로고침)를 사용하면 웹 URL 소스를 매일, 매주 또는 매월 주기로 다시 수집하고 재학습해요. 예약된 새로 고침은 **지식 베이스** 콘텐츠를 최신 웹사이트 내용과 맞추기 위한 기능이에요. 직접 편집해야 하는 소스에는 신중하게 사용하세요.

---

## 대화에서 소스 사용 내역 확인하기

수집된 콘텐츠 검토는 봇을 테스트하기 전이나 후에 웹사이트 소스 자료를 미리 정리할 때 가장 좋아요. 특정 AI 답변의 문제를 살펴볼 때는 **대화**의 **AI 응답 정보**를 사용하세요. 그 답변에 어떤 프롬프트, 의도, 액션, 데이터 소스가 쓰였는지 볼 수 있어요.

**AI 응답 정보**에서는 **지식 청크**와 **자주 묻는 질문**을 포함해 AI 답변에 사용된 소스를 확인할 수 있어요. 가능한 경우에는 대화 화면에서 바로 자주 묻는 질문이나 웹사이트 데이터 같은 지식 베이스 항목을 편집할 수도 있어요.

---

## 대화 AI용 웹사이트 콘텐츠 검토 설정하기

올바른 웹사이트 소스를 편집하고, 저장한 변경 내용이 대화 AI에 반영되도록 아래 순서를 따르세요. 저장하기 전에 소스를 꼼꼼히 검토해서 AI 에이전트가 정확하고 고객에게 보여 주기 적합한 정보를 참고하게 하세요.

1. **대화 AI**에서 **봇 학습** 또는 **지식 베이스** 설정으로 이동하세요.
2. 가져온 웹사이트 또는 **Web Crawler** 소스 목록에서 해당 웹사이트 URL을 찾으세요.

   ![웹사이트 소스 목록에서 URL 찾기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072728812/original/wrLp97bft5m5tCi1BziYWZYDoIVN-wxXWg.jpeg?1780412514)
3. 웹사이트 항목 옆의 콘텐츠 검토 아이콘을 클릭하세요.
4. 추출된 웹사이트 콘텐츠를 살펴보세요.
5. 오래되었거나 관련 없거나 중복되었거나 불분명한 정보를 지우세요.

   ![추출된 웹사이트 콘텐츠에서 불필요한 내용 삭제하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072728908/original/RK--AJlBUrtJn6N9mo4dQckH535rd9Up4w.jpeg?1780412538)
6. 필요하면 빠진 맥락을 추가해서 대화 AI가 콘텐츠를 더 쉽게 활용하도록 하세요.
7. **변경사항 저장**을 클릭하세요.
8. 웹사이트 소스에 편집 표시가 나타나는지 확인하세요(표시되는 경우).
9. 고객이 물을 법한 질문으로 대화 AI를 테스트해서 수정한 콘텐츠가 의도대로 쓰이는지 확인하세요.

저장하면 수정한 콘텐츠를 대화 AI가 답변을 만들 때 사용할 수 있어요.

## 자주 묻는 질문

### 수집된 웹사이트 콘텐츠를 편집하면 실제 웹사이트도 바뀌나요?
아니요. 수집된 웹사이트 콘텐츠를 편집하면 대화 AI가 사용하는 소스 콘텐츠만 업데이트돼요. 실제 웹사이트는 바뀌거나 게시되거나 수정되지 않아요.

### 웹사이트를 고치는 대신 수집된 콘텐츠를 편집해야 하는 경우는 언제인가요?
방문자에게는 웹사이트 내용이 맞지만 AI 답변용으로는 정리가 필요할 때 수집된 콘텐츠를 편집하세요. 공개된 페이지 자체에 잘못되었거나 오래된 정보가 있다면 웹사이트를 업데이트하세요.

### 편집한 웹사이트 콘텐츠를 저장하면 어떻게 되나요?
저장한 콘텐츠를 대화 AI가 이후 답변을 만들 때 사용할 수 있어요.

### 웹사이트 소스를 새로 고치면 직접 편집한 내용이 사라지나요?
새로 고치거나 다시 수집하면 이전에 편집한 내용을 덮어쓰고 새로 수집한 웹사이트 데이터로 바뀔 수 있어요. 새로 고치기 전에 중요한 편집 내용을 검토하고 복사해 두세요.

### 저장한 편집 내용을 되돌릴 수 있나요?
한 번에 되돌리는 기능은 없을 수 있어요. 콘텐츠를 직접 다시 편집하거나, 웹사이트 소스를 새로 고치거나 다시 수집해서 실제 웹사이트의 최신 콘텐츠를 가져올 수 있어요. 새로 고치면 직접 편집한 내용이 바뀔 수 있다는 점에 유의하세요.

### 특정 AI 답변에 어떤 웹사이트 콘텐츠가 쓰였는지 어떻게 알 수 있나요?
**대화**의 **AI 응답 정보**에서 AI가 만든 메시지의 소스 정보를 볼 수 있어요. **지식 청크**, **자주 묻는 질문** 같은 소스가 표시돼요.

### 수집된 콘텐츠에 탭, 아코디언, 숨겨진 섹션의 텍스트가 들어 있는 이유는 무엇인가요?
향상된 웹 크롤러가 탭, 아코디언, 지연 로딩 영역 같은 상호작용 요소와 비슷한 페이지 섹션의 내용을 수집할 수 있기 때문이에요.

### 직접 편집한 소스에도 Auto Refresh를 사용해도 되나요?
신중하게 사용하세요. **Auto Refresh**는 정해진 일정에 따라 웹 URL 소스를 다시 수집해서 최신 상태로 유지하는 기능이에요. 소스에 중요한 편집 내용이 있다면 자동 일정을 켜기 전에 새로 고침이 그 소스에 어떤 영향을 주는지 확인하세요.
