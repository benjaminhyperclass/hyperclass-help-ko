# 지식 베이스 웹 크롤러

향상된 웹 크롤러는 탭, 아코디언, 지연 로딩 영역처럼 화면 속에 숨어 있는 내용까지 읽어 와서 하이퍼클래스 대화 AI 봇을 학습시켜요. 페이지 콘텐츠를 최대 50%까지 더 많이 가져오기 때문에, 봇이 더 많은 질문에 더 정확하게 답할 수 있어요.

## 향상된 웹 크롤러란?

향상된 웹 크롤러는 **봇 학습**(Bot Training) 안에 있는 웹사이트 수집 엔진을 업그레이드한 기능이에요. 실제 방문자처럼 아코디언을 열고, 탭을 클릭하고, 스크롤하고, 나중에 불러오는 데이터를 펼쳐서 웹사이트에 숨어 있는 정보를 가져와요. 이렇게 모은 내용은 봇의 학습 데이터에 추가돼요. 기존의 **정확한 URL**, 도메인, 경로 크롤링 옵션도 그대로 쓸 수 있어요.

## 향상된 웹 크롤러의 주요 장점

- 더 깊은 텍스트 수집: React, Vue, Angular, Gutenberg 등으로 만든 최신 SPA에서 페이지 콘텐츠를 30~50% 더 많이 가져와요.
- 숨은 콘텐츠 인식: 아코디언, 탭, 모달, 지연 로딩, 무한 스크롤 영역도 읽어요.
- 빠른 다중 전략 분석: 12개 이상의 콘텐츠 감지 전략을 동시에 실행해서 속도를 높여요.- 안전한 상호작용 엔진: 폼, 필터 변경, 장바구니 동작처럼 위험할 수 있는 클릭은 피해요.
- 병렬 추출: 크고 복잡한 사이트의 전체 크롤링 시간을 줄여요.
- 확인 가능한 크롤링 지표: 소요 시간, 상호작용 횟수, 콘텐츠 길이, 메모리 사용량을 기록해서 문제 해결과 최적화에 쓸 수 있어요.

## 지능형 동적 콘텐츠 추출

- 아코디언을 자동으로 펼치고, 탭을 차례로 클릭하고, 지연 로딩을 실행해서 숨은 콘텐츠를 드러내요.
- 2개 이상의 스마트 감지 전략(시맨틱 콘텐츠, 구조화된 데이터, 메타데이터)을 동시에 실행해서 아주 빠르게 추출해요.- 폼 제출이나 필터 변경처럼 방해가 되는 동작은 하지 않는 안전한 상호작용 엔진을 써요.

## 고급 링크 탐색

- 재귀적 사이트맵 크롤링: 중첩된 사이트맵을 계속 따라가며 찾아서 처리해요. 여러 단계로 된 사이트 구조에서 URL을 더 잘 찾을 수 있어요.
- 압축 사이트맵 지원: `.xml.gz`, `.gzip` 같은 압축 사이트맵 파일을 지원해서 대역폭 사용량을 줄이고 크롤링 효율을 높여요.
- 탐색 경계 감지: 탐색 경계를 감지해서 크롤러가 범위를 벗어나는 일을 줄이고, 의도한 지식 베이스 범위 안에서만 링크를 찾아요.
- 다중 소스 감지: HTML 분석, JavaScript 평가, 상호작용 기반 탐색을 함께 사용해요.
- 펼침 영역이나 동적 콘텐츠 뒤에 숨은 링크도 찾아요.
- 중복 링크는 똑똑하게 걸러 내면서 링크 설명 텍스트는 그대로 유지해요.

## 모든 웹사이트 지원

- 정적 HTML, WordPress, React SPA, Vue 앱, Angular 애플리케이션 등 어떤 유형의 웹사이트에서도 작동해요.
- 콘텐츠를 병렬로 추출해서 크롤링이 더 빨라요.
- 처리 시간, 상호작용 횟수, 콘텐츠 길이, 메모리 사용량 같은 상세 지표로 전 과정을 확인할 수 있어요.

## 향상된 웹 크롤러 사용하기

### 1단계: 지식 베이스로 이동하기

1. 서브 계정에서 **AI 에이전트**를 클릭하세요.
2. **지식 베이스** 탭을 클릭하세요.
3. 새 지식 베이스를 만들려면 **만들기**를 클릭하고, 기존 지식 베이스를 수정하려면 **편집**을 클릭하세요.
4. **+ Add Source**(소스 추가) 버튼을 클릭하세요.
5. **Web Crawler**(웹 크롤러)를 클릭하세요.

![지식 베이스에서 웹 크롤러를 선택하는 화면](https://jumpshare.com/share/O4Vtc06bfshFLpvHkl0W+/GIF+Recording+2025-10-10+at+7.39.28+PM.gif)

### 2단계: 도메인 유형 선택하고 도메인 입력하기

1. 봇을 학습시킬 때 크롤링할 수 있는 도메인 유형은 여러 가지예요. 어떤 유형을 고르느냐에 따라 크롤링하는 URL 수가 달라져요.

   - **정확한 URL**: 특정 웹페이지 하나만 크롤링해서 그 데이터로 학습해요. 예를 들어 `https://www.example.com/`을 입력하면 정확히 그 페이지만 크롤링해요.
   - **All URLs with the Path**(경로 내 모든 URL): 특정 경로 안의 모든 페이지를 크롤링해요. 예를 들어 `https://www.example.com/marketing`을 입력하면 `/marketing/offers`, `/marketing/promotions`처럼 이 경로를 쓰는 모든 페이지가 포함돼요.
   - **All URLs in this Domain**(이 도메인의 모든 URL): 도메인 안의 모든 페이지를 크롤링해요. 예를 들어 `https://www.example.com/promo`를 입력하면 루트 도메인 `www.example.com`의 모든 페이지가 포함돼요.
2. **URL**을 입력하세요.
3. **데이터 추출** 버튼을 클릭하세요.

![도메인 유형을 고르고 URL을 입력해 데이터를 추출하는 화면](https://jumpshare.com/share/Nzx9IAkaXBtJYyDXQCD9+/GIF+Recording+2025-10-10+at+7.52.11+PM.gif)

### 3단계: 크롤링된 URL 선택하기

1. URL 크롤링이 끝나면 **View All Pages**(모든 페이지 보기)를 클릭하세요.
2. URL을 모두 선택하거나, 학습 데이터에 추가할 URL 옆의 체크박스를 클릭해서 하나씩 선택하세요.
3. 선택을 마쳤으면 **Train Bot**(봇 학습시키기) 버튼을 클릭하세요.

![크롤링된 URL을 선택하고 봇을 학습시키는 화면](https://jumpshare.com/share/l8eRZzthdUDzQM4ubX8A+/GIF+Recording+2025-10-10+at+8.55.08+PM.gif)

## 자주 묻는 질문

### '더 스마트한 콘텐츠 탐색'은 무슨 뜻인가요?
이제 크롤러가 웹사이트 콘텐츠를 최대 5.2배까지 더 많이 가져와요. 예전에는 자주 놓치던 고객 후기, 기능 설명, 연락처, 서비스 설명도 포함돼요.
### 새 크롤러로 학습하면 얼마나 안정적인가요?
비즈니스, 이커머스, 최신 인터랙티브 사이트 전반에서 성공률이 81.6%에서 94.7%로 올랐어요. 그만큼 수집이 실패하는 일이 훨씬 줄었어요.

### 핵심 섹션을 가져오려면 따로 설정해야 하나요?
아니요. 6개 이상의 병렬 감지 전략이 히어로 섹션, 고객 후기, 상품 설명, 팀 소개, 가격표, 연락처를 자동으로 찾아요.
### 상호작용이 필요한 콘텐츠나 숨은 콘텐츠도 읽을 수 있나요?
네. 아코디언을 펼치고, 탭을 이동하고, 지연 로딩되거나 숨겨진 섹션을 열어서 후기 전문과 자세한 서비스 정보까지 가져와요.

### 어떤 구조화된 데이터를 가져오고, 왜 중요한가요?
영업시간, 연락처, 가격, 서비스 같은 구조화된 데이터를 94% 더 많이 추출해요. 그래서 AI가 내 비즈니스를 더 풍부하고 정확하게 이해할 수 있어요.

### 결제 버튼을 클릭하거나 폼을 제출하기도 하나요?
아니요. 안전한 상호작용 엔진이 폼 요소를 무시하기 때문에 실수로 폼이 제출되는 일은 없어요.

### 로그인 뒤에 있는 숨은 섹션에는 접근하지 못하나요?
상호작용 엔진은 공개된 콘텐츠에서만 작동해요. 비공개 데이터나 로그인이 필요한 데이터는 크롤링하지 않아요.
