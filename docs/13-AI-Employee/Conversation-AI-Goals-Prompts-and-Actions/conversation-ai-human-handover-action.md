# 대화 AI 상담원 전환 액션 설정

대화 AI 봇이 해결하기 어려운 상황에서 대화를 팀원에게 자연스럽게 넘기도록 설정하는 방법이에요. 상담원 전환을 설정해 두면 고객이 도움을 받지 못한 채 대화가 끝나는 일을 줄일 수 있어요.

---

# 상담원 전환이란?

상담원 전환(**상담원 전환**, Human Handover)은 하이퍼클래스 대화 AI의 기능이에요. 정해 둔 조건이 되면 AI 봇이 진행하던 대화를 팀원에게 자동으로 넘겨요. 복잡한 문의가 들어왔을 때, 봇이 같은 질문을 반복해서 이해하지 못할 때, 고객이 직접 사람과 이야기하고 싶다고 요청할 때처럼 AI가 한계에 부딪히는 상황에서 쓰면 좋아요.

이 기능을 쓰면 고객이 답답함을 느끼기 전에 문제를 해결할 수 있고, 자동화 응대와 실시간 상담이 끊기지 않고 이어져요.

{% hint style="info" %}
상담원 전환은 **실험실**(Labs)을 통해 제공돼요. 대화 AI에 보이지 않으면 먼저 실험실에서 기능을 켜야 할 수 있어요.
{% endhint %}

---

## 상담원 전환의 주요 이점

- 막다른 길 없애기: 봇이 문제를 해결하지 못해도 고객이 지원을 받지 못한 채 남겨지지 않아요.
- 똑똑한 에스컬레이션: AI가 답을 못 찾거나 계속 실패하거나, 고객이 사람을 직접 요청하는 상황을 자동으로 감지해요.
- 매끄러운 전환: 팀원 배정, 후속 작업 생성, 마무리 메시지 발송, 봇 일시정지를 한 번에 처리해요.
- 고객 만족도 향상: 필요할 때 실제 사람이 응대한다는 믿음을 줘요.
- 빠른 팀 알림: 전환이 일어나거나 새 작업이 생기면 담당 직원에게 바로 알려 줘서 응답 시간이 줄어요.
- 트리거와 액션 사용자 지정: 전환 시점과 방식을 비즈니스에 맞게 조정할 수 있어요.

## 상담원 전환 액션 설정

상담원 전환을 설정하면 고객이 필요한 순간에 알맞은 지원을 받을 수 있어요. 아래 순서대로 하이퍼클래스에서 이 기능을 켜고 설정하세요. ▶ 영상 [10강 1부 28:49](https://www.youtube.com/watch?v=c4QmTGpfdCc&t=1729s)

### 1단계: 봇 목표로 이동하기

1. 서브 계정에서 **AI 에이전트**를 클릭하세요.
2. **대화 AI** 탭을 클릭하세요.

   ![AI 에이전트의 대화 AI 탭](https://jumpshare.com/v/GagVAP7gVSPaJBadjA8g+/Screen+Shot+2025-06-27+at+7.22.09+PM.png)
3. 봇 이름을 클릭하거나, 마지막 업데이트 옆의 점 세 개 아이콘을 클릭한 뒤 **편집**을 클릭하세요.

   ![봇 이름과 점 세 개 메뉴의 편집 버튼](https://jumpshare.com/v/BLk3LnWKYy80y8eibjSt+/Screen+Shot+2025-06-27+at+7.24.29+PM.png)
4. **봇 목표** 탭을 클릭하세요.
5. 아래로 스크롤해 **액션 설정** 섹션에서 **상담원 전환** 버튼을 클릭하세요.

   ![액션 설정 섹션의 상담원 전환 버튼](https://jumpshare.com/v/a9ykW3E9zMabwGvnj5hN+/Screen+Shot+2025-06-27+at+7.27.56+PM.png)

### 2단계: 미리 만들어진 시나리오 선택하기

봇이 상담원 전환을 실행할 조건을 아래 시나리오 중에서 고르세요.

#### 1. 상담원 요청됨

- **시나리오 활성화** 토글을 켜면 사용할 수 있어요.
- **트리거**: 고객이 사람과 이야기하고 싶다고 직접 요청할 때예요.
- **+ 예시 문구 추가** 버튼을 클릭해 직접 문구를 추가할 수 있어요.
- **예시 문구**: 사람과 이야기하고 싶어요 | 실제 사람이 도와줄 수 있나요? | 상담원 연결해 주세요

  ![상담원 요청됨 시나리오 설정 화면](https://jumpshare.com/v/PoOQiLisH28GDqtTX7Lv+/Screen+Shot+2025-06-27+at+7.35.39+PM.png)

#### 2. Lack of Information(정보 부족)

- **시나리오 활성화** 토글을 켜면 사용할 수 있어요.
- **트리거**: AI가 문의와 관련된 정보를 찾지 못하거나 해당 내용을 모를 때예요.
- 예시 문구를 따로 입력하지 않아도 돼요.

  ![Lack of Information 시나리오 설정 화면](https://jumpshare.com/v/iFTap75ySewhRodwoV3M+/Screen+Shot+2025-06-27+at+7.44.06+PM.png)

#### 3. Failed to Resolve Issue(문제 해결 실패)

- **시나리오 활성화** 토글을 켜면 사용할 수 있어요.
- **트리거**: 문제를 해결하려고 여러 번 시도했지만 실패했을 때예요.
- 최대 2회까지 재시도해요.
- 예시 문구를 따로 입력하지 않아도 돼요.

  ![Failed to Resolve Issue 시나리오 설정 화면](https://jumpshare.com/v/hrU2e9VuNLLF5aOshLis+/Screen+Shot+2025-06-27+at+7.47.48+PM.png)

### 3단계: 전환 후 동작 설정하기

봇이 대화를 넘긴 뒤에 어떤 일이 일어날지 정해요.

#### 1. Assign Conversation to a User(대화를 사용자에게 배정)

- 대화를 배정할 특정 사용자를 고르세요.
- **선택사항**: 연락처에 이미 배정된 사용자가 있으면 배정을 건너뛸 수 있어요.

  ![대화를 배정할 사용자 선택 화면](https://jumpshare.com/v/rYFRvoUTRYobTSkt30p4+/Screen+Shot+2025-06-27+at+7.56.04+PM.png)

#### 2. 최종 메시지

- 봇이 대화를 사람에게 넘기기 전에 보내는 마지막 메시지예요.
- 예시 메시지: "감사합니다! 팀 담당자가 곧 연락드릴게요."

  ![최종 메시지 입력 화면](https://jumpshare.com/v/r127iNEyvhC3k0e8WILt+/Screen+Shot+2025-06-27+at+8.05.45+PM.png)

#### 3. Bot Pause Behaviour(봇 일시정지 동작)

- 타이머를 설정하면 정해진 시간이 지난 뒤 봇이 다시 대화에 참여해요.
- 기간은 일, 시간, 분 단위로 정할 수 있어요.

  ![봇 일시정지 시간 설정 화면](https://jumpshare.com/v/9wnBDaIIT1jIVTNsDIRf+/Screen+Shot+2025-06-27+at+8.09.28+PM.png)

#### 4. Create a Task(작업 만들기)

- 상담원 전환이 실행되면 해당 연락처에 작업이 만들어져요.
- 기한: 트리거된 시점부터 24시간이에요.

  ![작업 만들기 설정 화면](https://jumpshare.com/v/zZWAy3ZAfVU4BtjUQe5Q+/Screen+Shot+2025-06-27+at+8.11.25+PM.png)

#### 5. Create Tags(태그 만들기)

- 상담원 전환이 끝나면 연락처에 태그를 추가해요.
- 기본 태그: human\_handover

  ![태그 만들기 설정 화면](https://jumpshare.com/v/eifeAIQnGT7pnlJ5rXER+/Screen+Shot+2025-06-27+at+8.15.21+PM.png)

## 배정된 사용자 알림 관리

직원이 알림을 제때 받아야 사람이 바로 대응할 수 있어요. 아래 순서로 알림을 설정하세요.

1. 서브 계정에서 **설정**으로 이동하세요.

   ![서브 계정의 설정 메뉴](https://jumpshare.com/v/vmz3iKoKFKDz1J0u7mIz+/Screen+Shot+2025-06-27+at+8.26.11+PM.png)
2. **스태프 관리** 탭을 클릭하세요.

   ![스태프 관리 탭](https://jumpshare.com/v/IsaEmUB2SQXRhiBSPDwb+/Screen+Shot+2025-06-27+at+9.17.12+PM.png)
3. 알림을 받을 직원 옆의 **편집** 버튼을 클릭하세요.

   ![직원 옆의 편집 버튼](https://jumpshare.com/v/P4BnEaMV15lvjdiUsMVe+/Screen+Shot+2025-06-27+at+9.21.14+PM.png)
4. **알림 설정** 탭을 클릭하세요.

   ![알림 설정 탭](https://jumpshare.com/v/DJSmxApyDBhBaU5nFkaA+/Screen+Shot+2025-06-27+at+9.24.28+PM.png)
5. 모든 채널에서 아래 알림을 켜세요.

   - **When a conversation gets assigned to me**(나에게 대화가 배정될 때)
   - **When a task gets assigned to me**(나에게 작업이 배정될 때)
   - **저장**을 클릭하세요.

     ![알림 켜기와 저장 버튼](https://jumpshare.com/v/Aj5BMWUzPiQlVYwxSM2L+/Screen+Shot+2025-06-27+at+9.27.55+PM.png)

{% hint style="info" %}
봇 하나당 상담원 전환 액션은 최대 6개까지 설정할 수 있어요.
{% endhint %}

## 전환 액션 맞춤 설정

팀의 업무 방식과 고객이 기대하는 응대 수준에 맞게 전환 과정을 조정해 보세요.

- 전문 분야나 근무 가능 여부에 따라 특정 직원에게 대화를 배정할 수 있어요.
- 명확한 기한이 있는 작업을 자동으로 만들 수 있어요.
- 마무리 메시지를 친근하면서도 전문적인 말투로 바꿀 수 있어요.
- 봇 일시정지 시간을 조정해, 자동화가 다시 시작되기 전에 사람이 후속 응대를 할 시간을 줄 수 있어요.
- 대화 태그를 리포팅과 워크플로우 자동화에 활용할 수 있어요.

  ![상담원 전환 맞춤 설정 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072661968/original/VJQDwQScN8CDXNTT6qmYsghT9hsfzhBTMQ.png?1780380309)

## 자주 묻는 질문

### 상담원 전환이 실행될 때 고객에게 가는 메시지를 바꿀 수 있나요?
네, 상담원 전환이 실행될 때 보내는 마무리 메시지를 원하는 대로 바꿀 수 있어요.

### 상담원 전환 때 배정된 팀원이 없으면 어떻게 되나요?
직원이 직접 맡기 전까지 대화는 배정되지 않은 상태로 남아요. 매끄러운 지원을 위해 기본 담당자를 미리 설정해 두는 게 좋아요.

### 봇이나 워크플로우마다 다른 트리거를 설정할 수 있나요?
네, **봇 목표** 섹션에서 봇별 또는 워크플로우별로 트리거를 사용자 지정할 수 있어요.

### 봇은 언제, 얼마 동안 멈추나요?
봇이 응답하지 않는 대기 시간을 직접 설정할 수 있어요. 그 시간 동안 팀이 대화에 개입할 수 있어요.

### 상담원 전환 후 팀에 바로 알림이 가나요?
네, 직원 설정에서 대화 배정 알림과 새 작업 알림을 켜 두었다면 바로 알림이 가요.

### 상담원 전환이 일어난 대화를 한꺼번에 확인할 수 있나요?
네, 해당 대화에는 human\_handover 태그가 붙어서 필터링이나 리포팅에 활용할 수 있어요.

### 특정 워크플로우에서는 상담원 전환을 끌 수 있나요?
네, 해당 **봇 목표** 설정에서 이 기능을 끄면 돼요.
