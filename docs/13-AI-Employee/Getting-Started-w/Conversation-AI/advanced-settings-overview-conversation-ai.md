# 대화 AI 고급 설정 개요

대화 AI 봇이 연락처에게 응답하는 방식을 세밀하게 조정하는 **고급 설정**을 안내해요. 메시지 수 제한(최대 100개), 응답 지연 시간, 채널별 사용 여부, 안전 장치를 다루고 있어요. 자동화와 사람의 관리를 균형 있게 설정할 때 참고하세요.

## 고급 설정 열기

프롬프트 기반 봇이든 폼 기반 봇이든, 모든 대화 AI 봇에는 메시지 제한, 응답 시간, 채널 동작을 조정하는 **봇 설정** 패널이 있어요.

1. **서브 계정 > 대화 AI > Bots**(봇)로 이동하세요.
2. 설정할 봇을 클릭한 다음, 탐색 메뉴에서 **봇 설정**을 선택하세요.
3. 아래 항목을 원하는 대로 바꾸고, 패널 아래쪽의 **저장**을 클릭하세요.

## 최대 메시지 수 제한 (1~100)

**Maximum messages a Bot can send in a Conversation**(한 대화에서 봇이 보낼 수 있는 최대 메시지 수) 필드는 하나의 대화에서 봇이 답장을 보낼 수 있는 횟수의 상한이에요. 이 횟수에 도달하면 봇은 잠들어요. 하이퍼클래스에서 이 상한을 최근 25개에서 **100개**로 올렸어요. 그래서 봇이 사람의 개입 없이 더 길고 복잡한 대화도 처리할 수 있어요. ▶ 영상 [10강 1부 23:32](https://www.youtube.com/watch?v=c4QmTGpfdCc&t=1412s)

이전에는 매일 5,000명이 넘는 연락처가 25개 제한에 걸려 대화가 멈췄어요. 100개로 늘어나면서 사람이 직접 넘겨받아야 하는 경우가 줄고, 고객과의 대화가 끊기지 않고 이어져요.

### 작동 방식

봇이 한 대화에서 보낼 수 있는 최대 메시지 수를 다 보내면 자동으로 휴면 상태가 돼요. 횟수에 들어가는 것은 봇이 만든 메시지뿐이에요. 상담원의 답장, 워크플로우 메시지, 연락처가 보낸 메시지는 횟수에 들어가지 않아요.

| 대화 유형 | 권장 제한 |
| --- | --- |
| 간단한 FAQ, 리드 수집 | 10~25개 |
| 예약 잡기, 간단한 문제 해결 | 26~60개 |
| 심층 안내, 여러 단계로 된 폼 | 61~100개 |

{% hint style="info" %}
제한을 높이면 대화 AI 사용 비용이 늘어날 수 있어요. 봇이 만든 메시지는 모두 요금제의 AI 생성 한도에 포함돼요. 설정을 바꾼 뒤에는 사용량을 확인하세요.
{% endhint %}

### 제한 설정하기

1. **봇 설정** 패널에서 **Maximum messages a Bot can send in a Conversation** 필드를 찾으세요.
2. **1~100** 사이의 값을 입력하세요. 새 봇의 기본값은 100이에요.
3. **저장**을 클릭하세요. 변경 내용이 진행 중인 모든 대화에 바로 적용돼요.

## 응답 지연 설정

봇이 답하는 속도를 조절해 대화 흐름을 더 자연스럽게 만들 수 있어요. 사람이 타이핑하는 것처럼 일부러 지연을 줄 수도 있고, 문의가 많은 고객 지원 창구에서는 즉시 답하게 둘 수도 있어요. ▶ 영상 [10강 1부 22:59](https://www.youtube.com/watch?v=c4QmTGpfdCc&t=1379s)

- **Minimum Response Delay**(최소 응답 지연): 봇이 답하기 전에 기다리는 최소 시간(초)을 정해요. 사람이 읽는 시간처럼 보이게 하려면 2~5초를 쓰세요.
- **Maximum Response Delay**(최대 응답 지연): 지연 시간의 상한(초)을 정해요. 봇이 너무 늦게 답해서 답답해지는 일을 막아 줘요.

## 채널별 설정

SMS, Facebook Messenger, Instagram, WhatsApp 등 채널마다 봇을 켜거나 끌 수 있어요. 최대 메시지 수 제한은 켜 둔 모든 채널에 똑같이 적용돼요. 채널마다 다른 제한을 둘 수는 없어요.

{% hint style="info" %}
짧은 대화가 알맞은 채널이 있다면, 메시지 제한을 낮게 설정한 봇을 따로 만들어 그 채널에만 연결하세요.
{% endhint %}

## 안전 및 대체 응답 옵션

같은 말을 반복하거나 브랜드와 맞지 않는 답이 나가지 않도록 안전 장치를 설정할 수 있어요. 이 설정은 메시지 수 제한과 함께 쓰여서 대화 품질을 지켜 줘요.

- **Fallback Message**(대체 메시지): 봇이 확신 있는 답을 만들지 못할 때, 또는 메시지 제한에 도달했을 때 표시돼요.
- **Content Filters**(콘텐츠 필터): 특정 단어나 문구를 막아서 봇이 민감한 주제를 다루지 않게 해요.
- **Auto-Escalation**(자동 에스컬레이션): 봇이 제한에 도달하거나 고객이 불만을 보이면 대화를 자동으로 상담원에게 배정해요.

## 메시지 횟수 초기화

봇이 최대 메시지 수에 도달하면 잠들어요. 직접 또는 워크플로우로 깨우면 대화를 다시 이어 갈 수 있어요.

### 직접 초기화하기

**대화** 받은편지함에서 잠든 봇의 대화를 열고 **읽기**로 표시하세요. 그러면 횟수가 0으로 돌아가고 봇이 바로 다시 켜져요.

### 워크플로우로 초기화하기

**Update Conversation AI Bot and Status**(Conversation AI 봇 및 상태 업데이트) 워크플로우 액션을 쓰면 자동으로 봇을 깨울 수 있어요. 여기에 조건을 함께 걸 수 있어요. 예를 들어 연락처가 특정 키워드로 답했을 때만 자동화를 다시 시작하도록 설정해요.

{% hint style="info" %}
**Conversation Status**(대화 상태)가 **Bot Sleeping**(봇 휴면 중)일 때 실행되는 워크플로우 트리거를 설정하세요. 연락처가 새 메시지를 보내면 24시간 뒤에 봇이 자동으로 다시 대화에 참여하게 할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 100개 제한은 이미 만든 봇에도 적용되나요?

네. 프롬프트 기반 봇과 폼 기반 봇 모두 새 상한인 100개가 자동으로 적용돼요. 더 짧은 대화가 필요하면 제한을 낮추면 돼요.

### 채널마다 다른 제한을 설정할 수 있나요?

아니요. 최대 메시지 수 제한은 봇 단위로 설정하고, SMS, Facebook, Instagram, WhatsApp 등 켜 둔 모든 채널에 똑같이 적용돼요.

### 제한을 높이면 비용이 늘어나나요?

늘어날 수 있어요. AI가 만든 메시지는 모두 대화 AI 사용 한도에 포함돼요. 제한을 높인 뒤에는 **청구/결제** 대시보드에서 사용량이 어떻게 달라졌는지 확인하세요.

### 상담원이 보낸 메시지도 제한에 포함되나요?

아니요. 봇이 만든 메시지만 횟수에 들어가요. 상담원, 워크플로우, 연락처가 보낸 메시지는 횟수에 들어가지 않아요.

### 대화 도중에 봇이 제한에 도달하면 어떻게 되나요?

봇이 허용된 마지막 메시지를 보낸 직후 바로 잠들어요. 직접 다시 켜려면 대화를 **읽기**로 표시하세요. **Update Conversation AI Bot and Status** 워크플로우 액션으로도 다시 켤 수 있어요.
