# 대화 AI의 Auto-Pilot 모드

Auto-Pilot 모드를 켜면 Conversation AI 봇이 사람의 확인 없이 고객 대화를 스스로 이어 가요. 이제 대화 한 건에서 최대 100개까지 메시지를 보낼 수 있어요. 이전 한도의 4배예요.

이 문서에서는 Auto-Pilot 모드가 어떻게 동작하는지, 봇이 언제 휴면 상태가 되는지, 늘어난 메시지 한도를 어떻게 활용하면 좋은지 알려 드려요.

## Auto-Pilot 모드란?

Auto-Pilot 모드에서는 Conversation AI 봇이 매번 사람이 지켜보지 않아도 혼자 대화를 처리해요. 이 모드를 켜면 SMS, Facebook Messenger, Instagram, WhatsApp 등 연결된 모든 채널로 들어오는 메시지를 봇이 처리해요. 설정한 메시지 한도에 닿거나 사람이 개입해야 하는 상황이 생기면 멈춰요.

리드 선별, 예약 일정 잡기, 자주 묻는 질문 응대, 간단한 문제 해결처럼 문의량이 많고 봇이 대부분 해결할 수 있는 업무에 알맞아요.

{% hint style="info" %}
메시지 한도가 100개로 늘어서 Auto-Pilot 봇이 이전보다 4배 긴 대화를 처리할 수 있어요. 사람이 직접 개입해야 하는 경우가 줄고, 여러 단계로 이어지는 복잡한 흐름도 만들기 쉬워졌어요.
{% endhint %}

## 새로운 100개 메시지 한도

하이퍼클래스는 봇이 대화 한 건에서 보낼 수 있는 최대 메시지 수를 25개에서 100개로 늘렸어요. 그래서 Auto-Pilot 봇이 훨씬 긴 대화도 사람이 다시 켜 주지 않고 이어 갈 수 있어요.

{% hint style="info" %}
이전에는 매일 5,000명이 넘는 연락처가 25개 한도에 걸려서 대화가 중간에 멈췄어요. 새 한도 100개로 대부분의 경우 이 문제가 없어져요.
{% endhint %}

### 한도에 포함되는 메시지

봇이 만든 메시지만 횟수에 포함돼요. 아래 메시지는 포함되지 않아요.

- 사람 상담원 메시지 — **대화** 받은편지함에서 팀원이 보낸 답장
- 워크플로우 메시지 — 워크플로우나 캠페인으로 자동 발송된 메시지
- 연락처가 보낸 메시지 — 연락처에게서 받은 메시지

## Auto-Pilot이 메시지 한도를 처리하는 방식

Auto-Pilot 모드의 봇이 설정한 메시지 한도(1~100개)에 닿으면 해당 대화에서 자동으로 휴면 상태가 돼요. 봇이 끝없이 반복해서 답하는 일을 막고, 자동화를 멈출 시점을 직접 정할 수 있어요.

### 휴면 상태가 되는 과정

봇이 한도에 닿으면 다음 순서로 진행돼요.

1. 봇이 마지막으로 허용된 답장을 보내요. 25번째, 50번째, 100번째 등 설정한 한도에 해당하는 메시지예요.
2. 봇이 휴면 상태가 돼요. 직접 또는 워크플로우로 다시 켜기 전까지 해당 대화에서 새 메시지에 답하지 않아요.
3. 대화는 받은편지함에 열린 채로 남아요. 사람 상담원은 계속 답장할 수 있고 워크플로우도 계속 실행되지만, 봇은 새 메시지를 만들지 않아요.

{% hint style="info" %}
봇은 한도에 닿아도 "안녕히 가세요" 같은 마무리 메시지를 자동으로 보내지 않아요. 봇이 잠시 멈춘다는 사실을 연락처에게 알리고 싶다면 봇 프롬프트에 그 안내를 넣거나 워크플로우로 대체 메시지를 보내세요.
{% endhint %}

## Auto-Pilot 켜기와 설정

Auto-Pilot 모드는 모든 Conversation AI 봇에서 기본으로 켜져 있어요. 설정할 것은 용도에 맞는 메시지 한도뿐이에요.

1. **서브 계정 > 대화 AI > Bots**(봇)로 이동한 뒤, 설정할 봇을 선택하세요.
2. **봇 설정**에서 **Maximum messages a Bot can send in a Conversation**(봇이 대화 하나에서 보낼 수 있는 최대 메시지 수)을 찾으세요.
3. 1~100 사이의 값을 입력하세요. 새 봇의 기본값은 100이에요.
4. **저장**을 클릭하세요.

새 한도는 새로 시작하는 모든 대화에 바로 적용돼요. 이미 진행 중인 대화는 현재까지 센 횟수를 그대로 유지하고, 앞으로는 새 한도를 기준으로 해요.

## 봇이 휴면 상태가 되는 경우

Auto-Pilot 모드의 봇은 아래 두 경우에 휴면 상태가 돼요.

- 메시지 한도에 도달했을 때: 현재 대화에서 봇이 설정한 최대 메시지 수(1~100개)를 모두 보냈어요.
- 직접 또는 워크플로우로 멈췄을 때: 사람 상담원이나 워크플로우 액션이 **Update Conversation AI Bot and Status**(Conversation AI 봇 및 상태 업데이트) 액션으로 봇을 휴면 상태로 바꿨어요.

{% hint style="info" %}
100개 한도에 계속 걸리는 대화를 눈여겨보세요. 이런 패턴이 보이면 한도를 더 높이거나, 봇 프롬프트를 손봐서 답변을 더 간결하게 만들어 보세요.
{% endhint %}

## 휴면 상태의 봇 다시 켜기

봇이 메시지 한도에 닿아 휴면 상태가 되었다면, 아래 두 가지 방법으로 다시 켜고 메시지 횟수를 0으로 되돌릴 수 있어요.

### 직접 다시 켜기

**대화** 받은편지함에서 해당 대화를 열고 **읽기**로 표시하세요. 그러면 봇이 바로 다시 켜지고 횟수가 0으로 돌아가요. 봇은 다시 최대 100개(또는 설정한 한도)까지 메시지를 보낼 수 있어요.

### 워크플로우로 다시 켜기

**Update Conversation AI Bot and Status** 워크플로우 액션을 쓰면 봇을 자동으로 다시 켤 수 있어요. 이런 상황에 유용해요.

- 시간 기반 재개 — 연락처가 새 메시지를 보내면 24시간 뒤에 봇을 다시 켜요.
- 키워드 트리거 — 연락처가 "도움이 필요해요" 같은 말을 할 때만 봇을 켜요.
- 태그 기반 조건 — 연락처에게 "VIP"나 "높은 우선순위" 태그가 붙어 있으면 봇을 다시 켜요.

{% hint style="info" %}
**Conversation Status = Bot Sleeping**(대화 상태 = 봇 휴면 중) 조건으로 워크플로우 트리거를 만들면, 중요한 대화를 봇을 다시 켜는 대신 사람 상담원에게 바로 넘길 수 있어요.
{% endhint %}

## 메시지 한도 설정 권장 가이드

적절한 메시지 한도는 자동화와 응대 품질 사이의 균형을 맞춰 줘요. 대화의 복잡도에 따라 아래 범위를 권장해요.

| 용도 | 권장 한도 |
| --- | --- |
| 간단한 자주 묻는 질문 응대, 리드 수집 | 10~25개 |
| 예약 일정 잡기, 간단한 문제 해결 | 26~60개 |
| 상품 상세 안내, 여러 단계의 폼 | 61~100개 |

### 모니터링과 조정

대화 기록을 매주 확인하세요. 대부분의 대화가 한도보다 훨씬 일찍 끝난다면 한도를 낮춰서 지표를 깔끔하게 유지하고 불필요한 AI 사용 비용도 줄일 수 있어요. 한도에 걸리는 대화가 많다면 한도를 올리거나 봇 프롬프트를 더 간결하게 다듬어 보세요.

{% hint style="warning" %}
AI가 만든 메시지는 모두 대화 AI 사용량에 포함돼요. 대화마다 한도를 거의 다 쓴다면, 한도를 25개에서 100개로 올릴 때 비용이 늘어날 수 있어요. 설정을 바꾼 뒤에는 청구 대시보드를 확인하세요.
{% endhint %}

## 자주 묻는 질문

### 100개 메시지 한도가 기존 봇에도 적용되나요?

네. 프롬프트 기반 봇과 폼 기반 봇 모두 새 한도인 100개가 자동으로 적용돼요. 더 짧은 대화가 필요하면 **봇 설정**에서 한도를 낮추세요.

### 채널마다 메시지 한도를 다르게 설정할 수 있나요?

아니요. 최대 메시지 한도는 봇 단위로 설정하고, SMS, Facebook, Instagram, WhatsApp 등 켜져 있는 모든 채널에 똑같이 적용돼요.

### 봇이 휴면 상태가 된 뒤에도 연락처가 계속 메시지를 보내면 어떻게 되나요?

봇은 휴면 상태를 유지하며 답하지 않아요. 대화는 받은편지함에 열린 채로 남아요. 해당 대화를 **읽기**로 표시해서 봇을 다시 켜거나, 사람 상담원이 직접 이어받으면 돼요.

### 횟수를 초기화하면 0부터 다시 세나요?

네. 대화를 **읽기**로 표시하거나 워크플로우 액션으로 봇을 다시 켜면 메시지 횟수가 0으로 돌아가요. 봇이 최대 100개(또는 설정한 한도)까지 한 번 더 메시지를 보낼 수 있어요.

### 사람과 봇이 함께 대화하는 방식에도 Auto-Pilot을 쓸 수 있나요?

네. 사람 상담원은 언제든 Auto-Pilot 대화에 들어올 수 있어요. 상담원이 보낸 메시지는 봇의 한도에 포함되지 않아요. 직접 봇을 휴면 상태로 바꾸거나 한도에 닿지 않는 한, 봇은 한도 안에서 계속 답해요.
