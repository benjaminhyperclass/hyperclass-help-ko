# AI에게 문의로 이미지 만들고 편집하기

**AI에게 문의**로 이미지를 만들고, 편집하고, 이미지에 대해 질문하는 방법을 안내해요. 대화하듯 요청 문장(프롬프트)을 입력하면 이미지를 만들 수 있어요. 만든 이미지나 첨부한 이미지를 수정할 수도 있어요. 소셜 게시물, 스토리, 영상, 배너, 세로형·가로형 콘텐츠에 맞는 여러 화면 비율도 지원해요.

## 이미지 만들기와 편집이란?

**AI에게 문의**에 문장으로 요청하면 이미지를 만들고 다룰 수 있어요. 새 이미지를 만들거나, 기존 이미지를 편집하거나, 이미지를 첨부해서 설명이나 분석을 요청할 수 있어요.

이미지를 만들 때 화면 비율을 지정하거나 사용할 플랫폼·용도를 설명하면, 그에 맞는 형식으로 이미지를 만들어 줘요.

## 이런 점이 좋아요

- 원하는 장면을 글로 설명하기만 하면 바로 이미지를 만들 수 있어요.
- 배경이나 그림 스타일 같은 세부 요소를 문장으로 요청해서 쉽게 고칠 수 있어요.
- 세션 기록이 그대로 남아서, 이전 버전을 잃지 않고 계속 수정할 수 있어요.
- 마음에 드는 이미지를 **미디어 라이브러리**에 저장해 두고 다음 작업에서 다시 쓸 수 있어요.
- 소셜 미디어, 이메일, 웹에 쓸 이미지를 적은 노력으로 다듬을 수 있어요.

## 이미지 만들고 편집하는 방법

{% hint style="info" %}
계정에 AI 직원 구독(월 $97)이 있거나 콘텐츠 AI의 사용한 만큼 결제가 켜져 있어야 해요.
{% endhint %}

### 1. AI에게 문의 창에서 이미지 만들고 편집하기

1. 서브 계정에 로그인하세요.
2. 오른쪽 위 상단 메뉴 바에서 **AskAI** 버튼을 클릭하세요.

   ![AskAI 버튼이 있는 상단 메뉴 바](https://jumpshare.com/share/DUzy0cZ7xjFNglrUdD9J+/Screen+Shot+2025-07-29+at+4.11.51+PM.png)
3. 입력창에 요청 문장을 입력하세요. 예: "아름다운 노을 이미지를 만들어 줘"
4. Enter 키를 누르거나 화살표 버튼을 클릭해서 제출하세요.
5. AI가 이미지를 만들 때까지 몇 초 기다리세요.

   ![AI가 생성한 노을 이미지](https://jumpshare.com/share/IbMocB6PRhYVwFMQyioa+/Screen+Shot+2025-07-29+at+4.14.02+PM.png)
6. 만들어진 이미지 아래의 입력창을 클릭하세요.
7. 수정하고 싶은 내용을 입력하세요. 예: "하늘에 새를 몇 마리 추가해 줘"
8. 수정 요청을 제출하세요.
9. AskAI가 변경 내용을 적용해 수정된 이미지를 만들 때까지 기다리세요.

   ![수정되어 새가 추가된 이미지](https://jumpshare.com/share/XEQKHwrmQVOHjzivpfqf+/Screen+Shot+2025-07-29+at+4.18.59+PM.png)

### 2. 콘텐츠 AI로 만든 이미지 편집하기

콘텐츠 AI에서 만든 AI 이미지도 편집할 수 있어요.

1. 콘텐츠 AI를 쓰는 화면으로 이동하세요. 예: **마케팅 > 소셜 플래너**
2. 새 게시물을 만들어 AI로 이미지를 생성하거나, 콘텐츠 AI로 만든 기존 게시물을 여세요.
3. **Edit with AskAI**(AskAI로 편집) 버튼을 클릭하세요.
4. 수정 요청을 입력하세요. 예: "라테 아트를 고양이로 바꿔 줘"

   ![AskAI로 이미지를 편집하는 화면 녹화](https://jumpshare.com/share/fmqeP9CRAfyacEdGCznF+/GIF+Recording+2025-07-29+at+4.30.50+PM.gif)
5. 제출한 뒤 수정된 이미지가 나타날 때까지 기다리세요.

   ![편집이 끝난 이미지](https://jumpshare.com/share/3deAXQzSYklRBjzw0dPK+/Screen+Shot+2025-07-29+at+4.35.01+PM.png)

### 3. 이미지 저장하거나 복사하기

이미지를 만들거나 편집한 뒤에는 이렇게 할 수 있어요.

1. **저장** 아이콘을 클릭하면 이미지가 **미디어 라이브러리**에 계속 보관돼요.
2. **복사** 버튼을 클릭하면 이미지가 클립보드에 복사돼서 다른 곳에 붙여 넣을 수 있어요.
3. 저장하지 않은 이미지는 AskAI 세션 안에서만 볼 수 있어요.

   ![저장과 복사 버튼이 있는 화면](https://jumpshare.com/share/hrfvB7q49oTSPdsJQgqe+/Screen+Shot+2025-07-29+at+4.42.54+PM.png)

## 지원하는 화면 비율

**AI에게 문의**는 아래 화면 비율을 지원해요.

| 화면 비율 | 주로 쓰는 곳 |
| --- | --- |
| 1:1 | 정사각형 게시물, 프로필 이미지 |
| 4:5 | Instagram 피드 게시물 |
| 9:16 | 스토리, 릴스, TikTok 콘텐츠 |
| 16:9 | YouTube 썸네일, 배너 |
| 21:9 | 영화 같은 와이드 그래픽, 넓은 헤더 |
| 2:3 | 세로형 이미지 |
| 3:4 | 세로형 이미지 |
| 3:2 | 가로형 이미지 |
| 4:3 | 가로형 이미지 |
| 5:4 | 가로형 이미지 |

특정 형식이 필요하면 요청 문장에 비율을 직접 넣으세요.

예시:

밤의 도시 스카이라인을 영화처럼 21:9 화면 비율로 만들어 줘.

사용할 플랫폼이나 용도를 설명해도 돼요.

예시:

여름 이벤트를 홍보하는 Instagram 스토리용 이미지를 만들어 줘.

비율을 지정하지 않으면, 요청 문장의 의도를 보고 알맞은 이미지 형식을 정해요.

## 활용 예시

- 시즌 프로모션에 맞는 소셜 미디어 게시물 이미지
- 세일즈 페이지나 웹사이트 섹션의 대표 이미지
- 참여율을 높이는 사용자 지정 이메일 배너 이미지
- 광고에 쓸 상품 목업이나 라이프스타일 이미지
- 블로그나 랜딩 페이지에 쓸 스토리텔링 이미지

## 세션 기록과 이어서 편집하기

**AI에게 문의**는 편집 맥락을 유지해서, 처음부터 다시 시작하지 않고 계속 수정할 수 있어요.

- 편집 내용은 처음 시작한 그 이미지에 연결돼요.
- 원래의 AI에게 문의 세션으로 돌아가 계속 다듬을 수 있어요.
- 이미지는 직접 저장을 선택할 때만 **미디어 라이브러리**에 저장돼요. 필요 없는 이미지가 쌓이지 않아요.

## 자주 묻는 질문

### 생성되는 이미지의 스타일을 정할 수 있나요?
네. 요청 문장에 "만화", "사실적", "3D" 같은 표현을 넣으면 원하는 스타일로 만들 수 있어요.

### 생성된 이미지는 어디에 저장되나요?
처음에는 AI에게 문의 세션 안에 저장돼요. **저장**을 클릭하면 **미디어 라이브러리**로 옮겨져요.

### 화면 비율은 어떻게 선택하나요?
요청 문장에 화면 비율을 넣으세요. 예를 들어 "상품 이미지를 4:5 화면 비율로 만들어 줘"라고 입력하면 돼요.

### AI에게 문의가 화면 비율을 자동으로 정해 줄 수도 있나요?
네. Instagram 스토리나 YouTube 썸네일처럼 사용할 플랫폼이나 용도를 요청 문장에 설명하면, 그 의도에 맞는 형식을 골라 줘요.

### AI에게 문의로 편집한 내용이 콘텐츠 AI 기록에도 나타나나요?
아니요. 현재 이 편집 내용은 AI에게 문의의 세션 기록에만 남아요.

### 이 기능을 쓰면 추가 요금이 있나요?
추가 요금은 없어요. AI 직원을 이용 중인 계정이거나 콘텐츠 AI를 사용한 만큼 결제로 쓰는 경우에 이 기능이 포함돼 있어요.

### 한 이미지를 계속 편집할 수 있나요?
네. AI에게 문의 세션 안에서는 횟수와 관계없이 이미지를 다듬을 수 있어요.

### 디자인 실력이 있어야 하나요?
아니요. 원하는 이미지를 명확하게 설명하기만 하면 디자인은 AI에게 문의가 맡아요.
