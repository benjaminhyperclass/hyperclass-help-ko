# AI 어시스턴트 문의

**AI에게 문의**(Ask AI)는 하이퍼클래스 안에서 콘텐츠 작성, 질문 답변, 이미지 생성, 실제 작업 실행까지 한 곳에서 처리하는 AI 어시스턴트예요. 이 문서에서는 이용할 수 있는 사용자, 기능 범위, 사용 방법, 활용 사례를 안내해요.

****

---

## AI 어시스턴트 문의란?

**AI에게 문의**는 하이퍼클래스에 내장된 AI 작업 공간이에요. 코파일럿처럼 대화하면서 콘텐츠를 만들고, 데이터를 조회하고, 플랫폼 기능을 실행하고, 질문의 답을 받을 수 있어요. 평소에 쓰는 말로 요청하면 돼요. 여러 메뉴와 화면을 오가지 않아도, 하고 싶은 일을 한 번에 설명하면 **AI에게 문의**가 처리해요.

**AI에게 문의**는 하이퍼클래스 플랫폼과 깊이 연결되어 있어요. 데이터를 읽고, 레코드를 만들고, 설정을 바꾸고, 콘텐츠를 생성하고, 연락처를 관리하고, 일괄 작업을 실행하고, 수십 개 모듈에 걸친 작업을 하나의 채팅 화면에서 처리해요. 글로 입력하거나 음성으로 요청할 수 있어요. 사이드바 패널로 열 수도 있고, 많은 양의 작업에 집중할 수 있는 전체 화면 작업 공간으로 열 수도 있어요. 하이퍼클래스 모바일 앱에서도 쓸 수 있어서, 사용 권한이 있는 사용자는 모바일에서 **AI에게 문의** 작업 공간을 열 수 있어요.

## AI에게 문의의 핵심 기능

**AI에게 문의**는 코파일럿으로서 크게 세 가지 일을 해요. 콘텐츠와 이미지 생성, CRM 플랫폼 작업 실행, 계정 데이터 조회와 수정이에요. 아래 표에서 주요 기능과 예시 프롬프트를 확인하세요.

| **기능** | **설명** | **예시 프롬프트** |
| --- | --- | --- |
| 브랜드 콘텐츠 생성 | 브랜드 보이스 설정을 활용해 이메일, 소셜 게시글, 광고, 블로그, 캠페인용 콘텐츠를 브랜드에 맞게 만들어요. | “내 브랜드 보이스로 Facebook 광고 게시글을 써 줘.”<br>“여름 세일 프로모션 이메일 초안을 작성해 줘.” |
| 이미지 생성 및 편집 | 캠페인, 웹사이트, 이메일, 소셜 게시글에 쓸 이미지를 하이퍼클래스 안에서 바로 만들고 편집해요. | “치과 랜딩 페이지에 쓸 메인 이미지를 만들어 줘.”<br>“이 이미지의 배경을 더 어둡게 편집해 줘.” |
| CRM 작업 실행 및 데이터 조회 | 연락처, 기회, 파이프라인, 캘린더 등의 CRM 레코드를 평소 쓰는 말로 요청해서 만들고, 수정하고, 검색하고, 관리해요. | “이메일이 jane@example.com인 Jane Smith 연락처를 만들어 줘.”<br>“Sales 파이프라인에서 진행 중인 기회를 모두 보여 줘.” |
| 일괄 작업 | 여러 연락처를 한꺼번에 수정하거나, 전체 목록에 대량 SMS·이메일을 보내요. | “'Webinar-July' 태그가 붙은 모든 연락처에 후속 SMS를 보내 줘.”<br>“지난달 캠페인의 모든 연락처에 'Q3-Lead' 태그를 달아 줘.” |
| 블로그 및 콘텐츠 작성 | SEO 최적화와 구조화된 서식을 포함해, AI의 도움으로 블로그 글을 초안 작성하고 게시해요. | “SMS 마케팅의 장점을 다루는 1,000단어 분량의 블로그 글을 써 줘.”<br>“부동산 중개 회사용 블로그 제목 아이디어 5개를 만들어 줘.” |
| 퍼널 생성 에이전트 | 비즈니스 정보, 템플릿, 브랜드 맞춤 설정을 바탕으로 안내를 받으며 AI와 함께 퍼널을 만들어요. | “코칭 비즈니스용 리드 마그넷 퍼널을 만들어 줘.”<br>“치과용 예약 퍼널을 만들어 줘.” |
| 연락처 요약 에이전트 | 여러 탭을 열어 보지 않고도 커뮤니케이션, 결제, 예약, 작업을 포함한 연락처 기록을 요약해요. | “이 연락처의 이력을 요약해 줘.”<br>“이 리드에게 후속 연락하기 전에 알아야 할 내용이 뭐야?” |
| AI 에이전트 관리 | **AI에게 문의**에서 바로 대화 AI 채팅 에이전트와 음성 AI 전화 에이전트를 만들고, 설정하고, 관리해요. | “우리 치과용 새 AI 채팅 에이전트를 만들어 줘.”<br>“예약 전화를 받는 음성 에이전트를 설정해 줘.” |
| 고객지원 및 지식 베이스 검색 | 하이퍼클래스 도움말 콘텐츠를 검색해서 플랫폼 질문, 문제 해결, 기능 사용법에 대한 안내를 받아요. | “A2P 등록은 어떻게 해?”<br>“내 이메일 도메인이 인증되지 않는 이유가 뭐야?” |
| 광고 캠페인 관리 | Google, Facebook, LinkedIn 광고 플랫폼의 캠페인을 만들고, 목록을 보고, 성과를 검토해요. | “성과가 가장 좋은 Google 캠페인을 보여 줘.”<br>“새 Facebook 리드 광고 캠페인을 만들어 줘.” |
| 작업 예약 및 자동화 | **AI에게 문의** 채팅 안에서 작업을 나중 시점이나 반복 일정에 실행하도록 예약해요. | “매주 월요일 오전 9시에 연락처 리포트를 보내 줘.”<br>“3일 뒤에 이 연락처에 후속 연락하도록 알려 줘.” |
| 마켓플레이스 앱 찾기 | 비즈니스 요구나 사용 사례를 평소 쓰는 말로 설명해서 알맞은 마켓플레이스 앱과 연동을 찾아요. | “부동산용 IDX 연동이 있어?” |
| 병렬 조사 및 복합 작업 | 복잡한 요청을 작업 단위로 나누고, 조사 에이전트를 병렬로 실행해서 결과를 하나의 답변으로 합쳐요. | “정체된 기회를 찾고, 후속 연락 활동을 검토하고, 연락처 데이터 문제를 찾아 줘.” |

## 복합 작업과 병렬 조사

**AI에게 문의**는 복잡한 요청을 작은 작업으로 나눠서 전문 조사 에이전트에게 맡길 수 있어요. 여러 에이전트가 동시에 일하는 동안 메인 어시스턴트가 작업을 조율하고, 결과를 하나의 답변으로 합쳐요.

### 병렬 조사는 이렇게 진행돼요

1. **AI에게 문의**가 요청을 분석해서 따로 처리할 수 있는 작업을 찾아요.

4. 조사 에이전트가 결과, 출처, 관련 파일 참조를 돌려줘요.
5. 메인 어시스턴트가 결과를 합치고, 추가로 필요한 사항을 처리한 뒤 최종 답변을 준비해요.

**AI에게 문의**는 정체된 기회 찾기, 후속 연락 활동 검토, 연락처 데이터 품질 확인을 각각 다른 조사 작업으로 맡길 수 있어요. 그리고 결과를 합쳐 우선순위가 매겨진 실행 목록으로 정리해요. 이후 일괄 변경을 요청하면, 지원되는 업데이트는 실행하기 전에 승인할 수 있도록 계획을 먼저 준비해 줘요.

네. **AI에게 문의**는 태그 지정, 대량 SMS, 대량 이메일을 포함한 일괄 작업을 지원해요. 작업을 진행하기 전에 항상 작업 범위를 확인해 줘요.

### AI에게 문의가 이전 대화를 기억하나요?

네. 대화는 저장되고 사이드바에서 열어 볼 수 있어요. 또 사용자가 시간이 지나며 알려 준 선호와 정보를 계속 기억해서, 이후 대화에서 답변을 맞춤형으로 제공해요.

### 입력하지 않고 말로 요청할 수 있나요?

네. **AI에게 문의** 입력 창의 마이크 아이콘을 클릭하면 음성 입력을 쓸 수 있어요.

### AI에게 문의와 대화 AI 또는 음성 AI 에이전트는 어떻게 다른가요?

**AI에게 문의**는 하이퍼클래스 안에서 일을 도와주는 나만의 AI 코파일럿이에요. 대화 AI와 음성 AI는 채팅과 전화로 내 연락처와 소통하는 고객 응대용 에이전트예요. **AI에게 문의**로 이런 에이전트를 만들고 설정하는 것도 도울 수 있어요.

### AI에게 문의로 이미지를 만들 수 있나요?

네. 브랜드 색상과 스타일을 활용해서 새 이미지를 만들고 기존 이미지를 편집할 수 있어요. 필요한 이미지를 설명하면 채팅 안에서 바로 만들어 줘요.

### AI에게 문의로 좋은 결과를 얻으려면 어떻게 해야 하나요?

구체적으로 요청하세요. 이름, 날짜, 파이프라인 이름, 태그 등 관련 정보를 프롬프트에 넣어 주세요. 자세히 알려 줄수록 답변이 더 정확하고 유용해져요.
