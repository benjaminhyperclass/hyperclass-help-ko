# 워크플로우 프리미엄 기능 켜기와 재청구 설정

워크플로우 프리미엄 기능을 켜면 서브 계정이 워크플로우 안에서 지원되는 프리미엄 트리거, 액션, 마켓플레이스 앱, 하이퍼클래스 앱을 쓸 수 있어요. 에이전시는 이 기능을 서브 계정에 켜 주고, 사용량을 고객에게 재청구할 수 있어요. 할인된 가격에 프리미엄 실행 횟수를 묶어 주는 워크플로우 Pro 요금제도 선택해서 판매할 수 있어요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## 워크플로우 프리미엄 기능이란?

워크플로우 프리미엄 기능은 프리미엄 실행 요금이 붙는, 지원되는 워크플로우 트리거와 액션이에요.

예를 들면 다음과 같아요.

- **Inbound Webhooks**(인바운드 웹훅)
- **Custom Webhooks**(커스텀 웹훅)
- **Google Sheets** 액션
- **Slack** 액션
- 마켓플레이스 앱
- 하이퍼클래스 앱
- 그 밖에 지원되는 프리미엄 워크플로우 트리거와 액션

{% hint style="warning" %}
일부 워크플로우 기능은 별도의 요금 체계를 쓸 수 있어요. 요금이 표준 프리미엄 실행 요금과 다르다면 항상 해당 기능의 문서를 확인하세요.
{% endhint %}

## 프리미엄 실행으로 계산되는 경우

지원되는 프리미엄 워크플로우 트리거나 액션이 실행되면 프리미엄 실행 1회로 계산돼요.

프리미엄 실행에는 다음이 포함될 수 있어요.

- 프리미엄 워크플로우 트리거
- 프리미엄 워크플로우 작업
- 마켓플레이스 앱 액션
- 하이퍼클래스 앱 액션

표준 워크플로우 액션은 워크플로우 Pro의 프리미엄 실행 포함 횟수를 쓰지 않아요. AI 관련 워크플로우 기능 중에는 별도 요금이 적용되는 것도 있으니 각각 확인하세요.

## 무료 프리미엄 실행

대상이 되는 서브 계정마다 다음이 제공돼요.

**평생 무료 프리미엄 실행 100회**

무료 실행을 모두 쓰면, 워크플로우 Pro 요금제를 쓰지 않는 서브 계정에는 표준 프리미엄 실행 요금이 부과돼요.

{% hint style="info" %}
무료 100회는 평생 제공되는 횟수라서 매달 초기화되지 않아요.
{% endhint %}

## 표준 프리미엄 실행 요금

유료 워크플로우 Pro 요금제가 없으면 프리미엄 워크플로우 실행은 실행 횟수만큼 내는 표준 요금으로 부과돼요.

현재 표준 요금은 다음과 같아요.

**프리미엄 실행 1회당 $0.01**

워크플로우 Pro 요금제를 쓰는 서브 계정에는 선택한 요금제에 따라 포함 실행 횟수와 할인된 초과 요금이 적용돼요.

## 워크플로우 Pro 요금제

워크플로우 Pro는 프리미엄 실행을 할인된 가격으로 월 단위 묶음으로 제공해요.

현재 요금제는 다음과 같아요.

| 요금제 | **월 가격** | 포함 실행 횟수 | 초과 요금 |
| --- | --- | --- | --- |
| Free | $0 | 평생 100회 | 실행당 $0.01 |
| Starter | 월 $10 | 월 10,000회 | 실행당 $0.008 |
| Growth | 월 $25 | 월 30,000회 | 실행당 $0.006 |
| Scale | 월 $50 | 월 65,000회 | 실행당 $0.004 |

유료 워크플로우 Pro의 포함 실행 횟수는 결제 주기가 시작될 때마다 초기화돼요.

쓰지 않은 월 실행 횟수는 다음 결제 주기로 이월되지 않아요.

포함 실행 횟수를 넘어도 워크플로우는 계속 실행되고, 해당 요금제의 초과 요금이 부과돼요.

## 워크플로우 프리미엄 기능 켜기

에이전시 관리자만 쓸 수 있어요. 에이전시에서 워크플로우 프리미엄 기능을 켜려면 다음 순서로 진행하세요.

1. **에이전시 보기**에서 **설정**으로 이동하세요.
2. **회사** 설정을 여세요.
3. **워크플로우 - 프리미엄 기능**을 찾으세요.

   ![워크플로우 - 프리미엄 기능 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081999701/original/SfLU2Xpbor1bIyS8-iNVdqjF569sdPdOAw.png?1790597382)
4. 기능을 켜세요.
5. **변경사항 저장**을 클릭하세요.

기능을 켜면 대상 서브 계정이 지원되는 프리미엄 워크플로우 트리거와 액션을 쓸 수 있어요.

{% hint style="info" %}
기능 사용 가능 여부와 청구 설정은 별개예요. 워크플로우 프리미엄 기능을 켠다고 해서 모든 서브 계정에 재청구가 자동으로 설정되는 것은 아니에요.
{% endhint %}

## 서브 계정에 재청구 켜기

에이전시 관리자만 쓸 수 있어요. 에이전시는 프리미엄 워크플로우 사용량을 서브 계정별로 재청구할 수 있어요.

재청구를 설정하려면 다음 순서로 진행하세요.

1. **에이전시 보기**에서 **서브 계정**으로 이동하세요.
2. 해당 서브 계정을 찾으세요.
3. **더 보기** 메뉴를 클릭하세요.
4. **고객 관리**를 선택하세요.
5. **재청구** 섹션을 여세요.
6. **워크플로우 - 프리미엄 기능**을 찾으세요.
7. **재청구 활성화**를 켜세요.
8. 마크업을 설정하세요.
9. **변경사항 저장**을 클릭하세요.

켜고 나면 설정한 재청구 내용에 따라 프리미엄 워크플로우 사용량이 고객에게 청구돼요.

## 마크업 설정

고객에게 재청구할 때 프리미엄 워크플로우 사용량에 마크업을 붙일 수 있어요.

예를 들어 원가가 다음과 같고

**실행 1회당 $0.01**

배수를 **2배**로 설정하면 고객에게는 다음 금액이 청구돼요.

**실행 1회당 $0.02**

원가와 고객 청구 금액의 차이는 에이전시의 매출총이익이 돼요.

{% hint style="warning" %}
배수와 마진율은 달라요. 예를 들어 원가의 5배를 청구하면 원가 대비 마크업은 400%이고, 마진이 500%인 것은 아니에요.
{% endhint %}

## 재청구가 동작하는 방식

재청구를 켜면 프리미엄 실행 사용량에 대해 청구 관계가 두 가지 생겨요.

### 에이전시 사용 비용

에이전시에는 해당 실행 요금에 따라 프리미엄 워크플로우 사용량의 원가가 청구돼요.

### 고객 재청구

고객에게는 에이전시가 설정한 가격이나 마크업대로 청구돼요. 이렇게 하면 에이전시는 사용 원가를 회수하고, 원하면 마크업을 더할 수 있어요.

## 에이전시와 서브 계정 지갑

프리미엄 워크플로우 요금은 에이전시 단위와 서브 계정 단위 청구에 모두 관련될 수 있어요. 계정 설정에 따라 다음과 같이 적용돼요.

- 워크플로우 실행 원가는 에이전시가 부담해요.
- 재청구를 쓰면 그 요금을 고객에게 넘길 수 있어요.
- 고객에게 청구되는 금액은 에이전시가 설정한 마크업을 기준으로 해요.

프리미엄 워크플로우 요금이 어떻게 전달되는지 확인하려면 서브 계정의 재청구 설정을 살펴보세요.

## 워크플로우 Pro 재판매

에이전시 관리자만 쓸 수 있어요. 에이전시는 서브 계정에 워크플로우 Pro 요금제를 판매할 수도 있어요. 재판매를 설정하려면 다음 순서로 진행하세요.

1. **에이전시 보기**에서 **재판매**로 이동하세요.
2. **워크플로우 Pro**를 찾으세요.
3. 재판매를 켜세요.
4. 마크업이나 고객에게 보일 가격을 설정하세요.
5. **변경사항 저장**을 클릭하세요.

설정한 가격이 고객이 워크플로우 Pro 요금제를 구매할 때 내는 금액이 돼요.

## 서브 계정에서 워크플로우 Pro 구매하기

서브 계정 사용자는 **워크플로우 설정**에서 워크플로우 Pro 요금제를 확인하고 구매할 수 있어요.

1. 해당 서브 계정을 여세요.
2. **자동화 > 워크플로우**로 이동하세요.
3. **글로벌 워크플로우 설정**을 여세요.
4. **Workflow Pro Plans**(워크플로우 Pro 요금제)를 찾으세요.

   ![글로벌 워크플로우 설정의 Workflow Pro Plans 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082000468/original/qlkSPV3oIhRJRT6zZGgg9_xfQPooqnx2ww.png?1790597724)
5. **View Plans**(요금제 보기)를 클릭하세요.

   ![요금제 보기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082000507/original/_Y6b4dtR_hMlA0AYoUKPosoo2M3bma_pCQ.png?1790597760)
6. 원하는 요금제를 선택하세요.
7. 구매를 완료하세요.

요금제가 활성화되면 대상 프리미엄 워크플로우 실행에 포함 실행 횟수가 적용돼요.

## 실행 한도에 도달하면 어떻게 되나요?

워크플로우 Pro 요금제는 포함 실행 횟수를 다 써도 워크플로우를 멈추지 않아요.

대신 다음 순서로 처리돼요.

1. 포함된 월 실행 횟수를 먼저 사용해요.
2. 추가 프리미엄 실행은 해당 요금제의 초과 요금으로 청구돼요.
3. 워크플로우는 그대로 계속 실행돼요.

월 포함 횟수를 다 썼다고 워크플로우가 갑자기 멈추는 일을 막기 위한 방식이에요.

## 자주 묻는 질문

### 무료 100회는 매달 초기화되나요?

아니요. 무료 100회는 대상 서브 계정에 평생 제공되는 프리미엄 실행 횟수예요.

### 워크플로우 Pro 실행 횟수는 매달 초기화되나요?

네. 유료 워크플로우 Pro 요금제의 월 실행 횟수는 결제 주기마다 초기화돼요.

### 쓰지 않은 워크플로우 Pro 실행 횟수는 다음 달로 넘어가나요?

아니요. 쓰지 않은 포함 실행 횟수는 일반적으로 다음 결제 주기로 넘어가지 않아요.

### 서브 계정이 워크플로우 Pro 포함 횟수를 넘으면 어떻게 되나요?

워크플로우는 계속 실행돼요. 추가 프리미엄 실행에는 선택한 요금제의 초과 요금이 부과돼요.

### 에이전시가 프리미엄 워크플로우 사용량을 재청구할 수 있나요?

네. 대상 서브 계정에는 다음 경로에서 재청구를 켤 수 있어요.

**에이전시 보기 > 서브 계정 > 고객 관리 > 재청구 > 워크플로우 - 프리미엄 기능**

### 에이전시가 워크플로우 Pro 요금제를 재판매할 수 있나요?

네. 다음 경로에서 워크플로우 Pro 재판매를 설정할 수 있어요.

**에이전시 보기 > 재판매 > 워크플로우 Pro**

### 모든 워크플로우 액션이 프리미엄 실행으로 청구되나요?

아니요. 표준 워크플로우 액션은 프리미엄 실행으로 계산되지 않아요. 지원되는 프리미엄 트리거, 프리미엄 액션, 마켓플레이스 앱, 하이퍼클래스 앱은 일반적으로 프리미엄 실행 사용량에 포함돼요.

일부 기능은 별도의 요금 체계를 쓸 수 있어요.
