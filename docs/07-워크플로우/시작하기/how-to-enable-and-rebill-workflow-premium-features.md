# 워크플로우 프리미엄 기능 활성화 및 재청구 방법

워크플로우 프리미엄 기능(Workflow Premium Features)을 사용하면 하위 계정(Sub-account)에서 지원되는 프리미엄 트리거, 액션, 마켓플레이스 앱(Marketplace Apps), LC 앱을 워크플로우 안에서 사용할 수 있어요.

에이전시는 하위 계정에 이 기능을 활성화해주고, 사용량을 고객에게 재청구하며, 선택적으로 할인된 요금으로 프리미엄 실행이 번들된 워크플로우 프로(Workflow Pro) 플랜을 제공할 수 있습니다.

## 워크플로우 프리미엄 기능이란?

워크플로우 프리미엄 기능에는 프리미엄 실행 요금이 부과되는 워크플로우 트리거(Trigger)와 액션(Action)이 포함돼요.

예시는 다음과 같습니다:

- 인바운드 웹훅(Inbound Webhooks)
- 커스텀 웹훅(Custom Webhooks)
- Google Sheets 액션
- Slack 액션
- 마켓플레이스 앱(Marketplace Apps)
- LC 앱
- 기타 지원되는 프리미엄 워크플로우 트리거 및 액션

중요: 일부 워크플로우 기능은 별도의 가격 체계를 사용할 수 있어요. 표준 프리미엄 실행 요금과 다를 경우 반드시 해당 기능의 개별 문서를 참고하세요.

## 프리미엄 실행으로 집계되는 기준은?

프리미엄 실행(Premium Execution)은 지원되는 프리미엄 워크플로우 트리거 또는 액션이 실행될 때 발생해요.

프리미엄 실행에는 다음이 포함될 수 있습니다:

- 프리미엄 워크플로우 트리거
- 프리미엄 워크플로우 액션
- 마켓플레이스 앱 액션
- LC 앱 액션

표준 워크플로우 액션은 워크플로우 프로의 프리미엄 실행 할당량을 소모하지 않아요. 일부 AI 관련 워크플로우 기능도 별도의 가격 체계를 사용할 수 있으니 개별적으로 확인해야 해요.

## 무료 프리미엄 실행

조건을 충족하는 각 하위 계정은 다음을 받습니다:

**평생 무료 프리미엄 실행 100회**

무료 실행을 모두 사용한 후에는, 하위 계정이 활성 워크플로우 프로 플랜을 보유하고 있지 않는 한 표준 프리미엄 실행 요금이 적용돼요.

참고: 무료 실행 100회는 평생 기준이며 매월 초기화되지 않아요.

## 표준 프리미엄 실행 요금

유료 워크플로우 프로 플랜이 없는 경우, 프리미엄 워크플로우 실행은 표준 실행당 요금으로 청구돼요.

현재 표준 요금:

**프리미엄 실행당 $0.01**

워크플로우 프로 플랜을 사용 중인 하위 계정은 선택한 플랜에 따라 포함된 실행 횟수와 할인된 초과 요금이 적용돼요.

## 워크플로우 프로 플랜

워크플로우 프로(Workflow Pro)는 할인된 요금으로 매월 프리미엄 실행 번들을 제공해요.

현재 제공되는 플랜:

| 플랜 | 월 요금 | 포함 실행 횟수 | 초과 요금 |
|---|---|---|---|
| Free | $0 | 평생 100회 | 실행당 $0.01 |
| Starter | 월 $10 | 월 10,000회 | 실행당 $0.008 |
| Growth | 월 $25 | 월 30,000회 | 실행당 $0.006 |
| Scale | 월 $50 | 월 65,000회 | 실행당 $0.004 |

유료 워크플로우 프로 실행 할당량은 매 결제 주기 시작 시 초기화돼요.

사용하지 않은 월간 실행 횟수는 다음 결제 주기로 이월되지 않아요.

포함된 실행 할당량을 초과하면 워크플로우는 계속 실행되며, 해당 초과 요금이 청구돼요.

## 워크플로우 프리미엄 기능 활성화

에이전시에서 워크플로우 프리미엄 기능을 활성화하려면:

- **Agency View(에이전시 뷰)**에서 **Settings(설정)**로 이동하세요.
- **Company(회사)** 설정을 여세요.
- **Workflow - Premium Features(워크플로우 - 프리미엄 기능)**를 찾으세요.

![워크플로우 프리미엄 기능 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081999701/original/SfLU2Xpbor1bIyS8-iNVdqjF569sdPdOAw.png?1790597382)

- 기능을 활성화하세요.
- 변경사항을 저장하세요.

활성화되면, 조건을 충족하는 하위 계정에서 지원되는 프리미엄 워크플로우 트리거 및 액션을 사용할 수 있어요.

참고: 기능 사용 가능 여부와 청구 설정은 별개예요. 워크플로우 프리미엄 기능을 활성화한다고 해서 모든 하위 계정에 재청구가 자동으로 설정되는 것은 아니에요.

## 하위 계정에 재청구 활성화

에이전시는 개별 하위 계정에 프리미엄 워크플로우 사용량을 재청구할 수 있어요.

재청구를 설정하려면:

- **Agency View(에이전시 뷰)**에서 **Sub-Accounts(하위 계정)**로 이동하세요.
- 해당 하위 계정을 찾으세요.
- **More Options(추가 옵션)** 메뉴를 클릭하세요.
- **Manage Client(클라이언트 관리)**를 선택하세요.
- **Rebilling(재청구)** 섹션을 여세요.
- **Workflow - Premium Features(워크플로우 - 프리미엄 기능)**를 찾으세요.
- 재청구를 활성화하세요.
- 마크업(Markup)을 설정하세요.
- 변경사항을 저장하세요.

활성화되면, 설정된 재청구 옵션에 따라 프리미엄 워크플로우 사용량이 고객에게 청구될 수 있어요.

## 마크업 설정하기

고객에게 재청구할 때 프리미엄 워크플로우 사용량에 마크업을 적용할 수 있어요.

예시:

기본 비용이

**실행당 $0.01**

이고, **2배 배율**을 설정하면 고객에게 청구되는 금액은

**실행당 $0.02**

예요.

기본 비용과 고객 청구 금액의 차이가 에이전시의 총이익이 돼요.

중요: 배율(multiplier)과 마진율(margin percentage)은 같지 않아요. 예를 들어 기본 비용의 5배를 청구하는 것은 원가 대비 400% 마크업이지, 500% 마진이 아니에요.

## 재청구는 어떻게 작동하나요?

재청구가 활성화되면, 프리미엄 실행 사용량은 두 가지 청구 관계를 만들어요.

### 에이전시 사용 비용

에이전시는 해당 실행 요금에 따라 기본 프리미엄 워크플로우 사용량에 대해 청구돼요.

### 클라이언트 재청구

클라이언트는 에이전시가 설정한 가격 또는 마크업에 따라 청구돼요. 이를 통해 에이전시는 기본 사용 비용을 회수하고, 선택적으로 마크업을 추가할 수 있어요.

## 에이전시 및 하위 계정 지갑

프리미엄 워크플로우 요금은 에이전시 레벨과 하위 계정 레벨 청구를 모두 포함할 수 있어요. 계정 설정에 따라:

- 에이전시는 기본 워크플로우 실행 요금에 대한 책임이 있어요.
- 재청구를 통해 해당 요금을 클라이언트에게 전가할 수 있어요.
- 클라이언트에게 청구되는 금액은 에이전시가 설정한 마크업을 기준으로 해요.

프리미엄 워크플로우 요금이 어떻게 전가되는지 확인하려면 하위 계정의 재청구 설정을 검토하세요.

## 워크플로우 프로 재판매

에이전시는 하위 계정에 워크플로우 프로 플랜을 제공할 수도 있어요. 워크플로우 프로 재판매를 설정하려면:

- **Agency View(에이전시 뷰)**에서 **Reselling(재판매)**으로 이동하세요.
- **Workflow Pro**를 찾으세요.
- 재판매를 활성화하세요.
- 마크업 또는 고객 청구 가격을 설정하세요.
- 변경사항을 저장하세요.

설정한 가격에 따라 고객이 워크플로우 프로 플랜을 구매할 때 지불하는 금액이 결정돼요.

## 하위 계정에서 워크플로우 프로 구매하는 방법

하위 계정 사용자는 워크플로우(Workflow) 설정에서 워크플로우 프로 플랜을 확인하고 구매할 수 있어요.

- 해당 하위 계정을 여세요.
- **Automation(자동화) → Workflows(워크플로우)**로 이동하세요.
- **Global Workflow Settings(전역 워크플로우 설정)**를 여세요.
- **Workflow Pro Plans(워크플로우 프로 플랜)**를 찾으세요.

![워크플로우 프로 플랜 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082000468/original/qlkSPV3oIhRJRT6zZGgg9_xfQPooqnx2ww.png?1790597724)

- **View Plans(플랜 보기)**를 클릭하세요.

![워크플로우 프로 플랜 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082000507/original/_Y6b4dtR_hMlA0AYoUKPosoo2M3bma_pCQ.png?1790597760)

- 원하는 플랜을 선택하세요.
- 구매를 완료하세요.

플랜이 활성화되면, 포함된 프리미엄 실행 할당량이 조건을 충족하는 프리미엄 워크플로우 실행에 적용돼요.

## 실행 한도에 도달하면 어떻게 되나요?

워크플로우 프로 플랜은 포함된 실행 할당량을 모두 사용했다고 해서 워크플로우를 중단시키지 않아요.

대신:

- 포함된 월간 실행 횟수가 먼저 사용돼요.
- 추가 프리미엄 실행은 플랜에 해당하는 초과 요금으로 청구돼요.
- 워크플로우는 평소대로 계속 실행돼요.

이를 통해 월간 포함 할당량이 소진되었다는 이유로 워크플로우가 예기치 않게 멈추는 상황을 방지해요.

## 자주 묻는 질문

### 무료 실행 100회는 매월 초기화되나요?

아니요. 무료 실행 100회는 조건을 충족하는 하위 계정의 평생 프리미엄 실행이에요.

### 워크플로우 프로 실행은 매월 초기화되나요?

네. 유료 워크플로우 프로 플랜은 매 결제 주기마다 초기화되는 월간 실행 할당량을 포함해요.

### 사용하지 않은 워크플로우 프로 실행은 이월되나요?

아니요. 사용하지 않은 포함 실행 횟수는 일반적으로 다음 결제 주기로 이월되지 않아요.

### 하위 계정이 워크플로우 프로 할당량을 초과하면 어떻게 되나요?

워크플로우는 계속 실행돼요. 추가 프리미엄 실행은 선택한 플랜에 해당하는 초과 요금으로 청구돼요.

### 에이전시가 프리미엄 워크플로우 사용량을 재청구할 수 있나요?

네. 다음 경로에서 조건을 충족하는 하위 계정에 재청구를 활성화할 수 있어요:

Agency View(에이전시 뷰) → Sub-Accounts(하위 계정) → Manage Client(클라이언트 관리) → Rebilling(재청구) → Workflow - Premium Features(워크플로우 - 프리미엄 기능)

### 에이전시가 워크플로우 프로 플랜을 재판매할 수 있나요?

네. 에이전시는 다음 경로에서 워크플로우 프로 재판매를 설정할 수 있어요:

Agency View(에이전시 뷰) → Reselling(재판매) → Workflow Pro

### 모든 워크플로우 액션이 프리미엄 실행으로 청구되나요?

아니요. 표준 워크플로우 액션은 프리미엄 실행으로 집계되지 않아요. 지원되는 프리미엄 트리거, 프리미엄 액션, 마켓플레이스 앱, LC 앱은 일반적으로 프리미엄 실행 사용량에 포함돼요.

일부 기능은 별도의 가격 체계를 사용할 수 있어요.
