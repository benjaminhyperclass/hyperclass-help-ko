# Browse AI 워크플로우 트리거·액션 — New Completed Task, Run Task 등

Browse AI를 워크플로우에 연결해 웹 스크랩이 끝나면 자동화를 실행하고, 반대로 워크플로우에서 Browse AI 로봇을 실행하거나 수집된 데이터를 가져오는 방법을 안내해요. 이 문서에서는 Browse AI 트리거 1개와 액션 4개의 설정 방법, 테스트 방법, 활용 사례를 다뤄요.

## 개요

Browse AI는 코드 없이 웹 스크랩과 모니터링을 할 수 있는 플랫폼이에요. 핵심은 로봇(Robot)으로, 웹 페이지에서 구조화된 데이터를 추출하도록 학습시킨 스크레이퍼예요. 로봇을 한 번 실행하면 태스크(Task) 1개가 만들어지고, 대량 실행(bulk run)은 같은 로봇의 태스크 여러 개를 한 번에 대기열에 올려요.

Browse AI 연동을 쓰면 이 기능들을 워크플로우 빌더(Workflow Builder) 안에서 바로 쓸 수 있어요. 스크랩이 끝나는 순간 자동화를 실행할 수 있고, 반대로 필요할 때 로봇을 실행해 수집된 데이터를 가져올 수도 있어요.

## 연동 구성

이 연동은 두 부분으로 이루어져 있어요.

- 트리거(Browse AI → 워크플로우): 즉시 실행되는 트리거 1개, **New Completed Task**(완료된 새 태스크)가 있어요. Browse AI 로봇 태스크가 끝나면 실행돼요. **Robot**과 **Select Operator**로 조건을 좁힐 수 있어요.
- 액션(워크플로우 → Browse AI): 태스크 1개 실행, 대량 실행, ID로 결과 가져오기를 다루는 액션 4개가 있어요.

모든 액션과 트리거는 프리미엄 워크플로우 구성 요소예요. 프리미엄 액션 크레딧이 표준 자동화 요율로 적용돼요. Browse AI 사용량(로봇 크레딧, 태스크 크레딧)은 Browse AI 계정에서 Browse AI가 직접 청구해요.

## Browse AI 연결하기

Browse AI 트리거나 액션을 실행하려면 먼저 API 키로 연동을 연결해야 해요.

### 워크플로우 빌더에서 연결하기 (권장)

1. **자동화 > 워크플로우**로 이동해 워크플로우를 선택하거나 새로 만들어요.
2. Browse AI 트리거나 액션을 추가해요. **Apps** 탭에서 Browse AI를 검색하세요.
3. Browse AI 트리거나 액션을 아무거나 선택해요.
4. 액션 카드에서 **Connect your account**(계정 연결)를 클릭해요.
5. 나타난 창에 Browse AI API 키를 붙여 넣어요. API 키는 Browse AI에 로그인해 대시보드를 연 다음, **Settings > API Keys**로 이동해 **Create new API key**를 클릭하고, 이름(예: 'Workflows integration')을 정한 뒤 값을 복사하면 돼요.
6. **Save**(저장)를 클릭해요. 패널에 **Connected**(연결됨)로 표시돼요.

### 설정에서 연결하기 (다른 방법)

1. **설정 > 연동**으로 이동해요.
2. Browse AI를 찾아 **Connect**(연결)를 클릭해요.
3. Browse AI API 키를 붙여 넣고 **저장**을 클릭해요.

### Browse AI 계정이 여러 개일 때

Browse AI 계정을 2개 이상 연결하면 모든 트리거·액션 패널에 **Connected Account**(연결된 계정) 드롭다운이 나타나요. 단계마다 사용할 계정을 고를 수 있어요. 연결된 계정이 1개뿐이면 기본 계정이 자동으로 선택돼요.

## 트리거 목록

이번 버전에는 트리거가 1개 있어요. 어떤 이벤트에서 실행할지는 필터로 정해요.

| 트리거 | 하는 일 |
| --- | --- |
| **New Completed Task** | Browse AI 로봇 태스크가 끝나면 실행돼요(기본값은 성공적으로 완료된 경우). **Robot**과 **Select Operator**로 조건을 좁힐 수 있어요. 웹훅 기반이라 즉시 실행돼요. |

## 액션 목록

| 액션 | 용도 |
| --- | --- |
| **Run Task**(태스크 실행) | Browse AI 로봇 1개를 실행해요. 입력 파라미터는 선택 사항이에요. |
| **Bulk Run Tasks**(태스크 대량 실행) | 같은 로봇의 실행 여러 건을 한 번에 대기열에 올려요. 입력값 한 행당 태스크 1개가 만들어져요. |
| **Get Task**(태스크 가져오기) | 이미 실행한 태스크를 ID로 가져와요. 수집된 데이터가 준비되면 함께 가져와요. |
| **Get Bulk Run**(대량 실행 가져오기) | 대량 실행 전체를 ID로 가져와요. 하위 태스크 결과가 모두 포함돼요. |

## 예시: 트리거 설정하기 (New Completed Task)

특정 Browse AI 로봇이 태스크를 끝낼 때마다 실행되는 워크플로우를 만들어 볼게요. 수집된 데이터(페이로드)는 이후 모든 액션에서 쓸 수 있어요.

### 1단계: 트리거 추가하기

1. 워크플로우를 열고 **Add Trigger**(트리거 추가)를 클릭해요.
2. **Apps** 탭으로 이동해 Browse AI를 검색해요.
3. 트리거 목록에서 **New Completed Task**를 선택해요.

### 2단계: 트리거 설정하기

- **Connected Account** — 이 트리거가 감시할 Browse AI 계정을 골라요. 연결된 계정이 1개뿐이면 자동으로 선택돼요.
- **Workflow Trigger Name**(워크플로우 트리거 이름) — 알아보기 쉬운 이름을 붙여요. 예: 'New Competitor Page Scrape'.
- **Filters > Robot** — 모니터링할 Browse AI 로봇을 골라요. 드롭다운에는 연결된 계정의 로봇이 나타나고, 아래 도움말에는 'Select the robot to monitor for completed tasks.'라고 표시돼요.
- **Filters > Select Operator**(선택 사항) — 상태, 수집된 필드 값, 실행 입력값으로 범위를 더 좁혀요. 로봇 하나를 여러 입력값으로 실행하는데 일부만 필요할 때 유용해요.
- **Add filters** — 특정 상황에서만 실행하고 싶다면 조건을 더 추가해요.

### 3단계: 트리거 테스트하기

1. **Test Your Trigger** 패널에서 **Find New Records**(새 레코드 찾기)를 클릭해요.
2. Browse AI에서 조건에 맞는 최근 완료 태스크를 가져와요.
3. **Records — Select Mapping Reference** 드롭다운에서 가져온 레코드 중 하나를 골라요. 이렇게 하면 이후 단계에서 쓸 수집 데이터 구조가 고정돼요.
4. **Save Trigger**(트리거 저장)를 클릭해 마무리해요.

## 예시: 액션 설정하기 (Run Task)

고객이 제출한 URL로 Browse AI 로봇을 실행하고, 수집된 데이터가 준비되면 워크플로우를 이어 가는 예시예요.

### 1단계: 액션 추가하기

1. 워크플로우 안에서 **Add**(추가)를 클릭해 새 단계를 넣어요.
2. **Apps** 탭을 열고 Browse AI를 선택해요.
3. 액션 목록에서 **Run Task**를 선택해요.

### 2단계: 연결하기 (처음 한 번만)

1. 연동이 아직 연결되지 않았다면 액션 카드에서 **Connect your account**를 클릭해요.
2. Browse AI API 키를 붙여 넣고 **Save**를 클릭해요.

### 3단계: 액션 설정하기

- **Action Name**(액션 이름) — 알아보기 쉬운 이름을 붙여요. 예: 'Scrape Customer-Submitted URL'.
- **Robot** — 실행할 Browse AI 로봇을 골라요. 드롭다운에는 연결된 계정의 로봇이 나타나요.
- **Input Parameters**(입력 파라미터) — 로봇마다 입력 형태가 달라요(URL, 검색어, 필드 목록 등). 워크플로우 변수(예: `{{form.submitted_url}}`)를 해당 필드에 넣어요.

### 4단계: 결과로 워크플로우 이어 가기

**Run Task**는 태스크 ID를 돌려줘요. 이어 가는 방법은 두 가지예요.

- 트리거로 기다리기: 워크플로우를 나눌 수 있다면, 태스크 ID를 연락처에 저장한 채로 이 워크플로우를 끝내요. 스크랩이 끝나면 **New Completed Task**를 기다리던 별도 워크플로우가 이어받아요.
- 폴링으로 기다리기: 스크랩이 보통 빨리 끝난다면 **Wait**(대기) 단계(예: 30초)를 넣고, 그 뒤에 **Get Task** 액션에서 돌려받은 태스크 ID로 수집된 데이터를 바로 가져와요.

![Run Task 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072316756/original/8-m_SPDqk2LvHaVOWxz3q3BZ-8zOLGBsAw.png?1779887500)

## 트리거와 액션 테스트하기

게시하기 전에 항상 테스트하세요. 테스트하면 페이로드 구조가 고정되고, 이후 단계에서 연결할 실제 레코드를 쓸 수 있어요.

### 트리거 테스트

1. 트리거 패널에서 **Find New Records**를 클릭해요.
2. 완료된 태스크가 보이지 않으면 Browse AI에서 로봇을 직접 실행해 샘플을 만든 다음, 다시 가져와요.
3. 가져온 태스크를 매핑 참조(mapping reference)로 선택해요. 수집된 데이터 필드(로봇이 추출하는 열)가 페이로드 미리보기에 나타나는지 확인하세요.

### 액션 테스트

1. 액션 패널에서 **Test Action**(액션 테스트)을 클릭해요.
2. 샘플 값으로 실제 Browse AI 계정에 대해 액션이 실행돼요.
3. Browse AI를 열어 해당 로봇의 실행 기록에 태스크가 나타나는지 확인해요.
4. 결과가 맞지 않으면 로봇 ID와 입력 파라미터 매핑을 다시 확인하고 테스트해요. 문제가 없으면 **Save action**(액션 저장)을 클릭하고, 게시하기 전에 **Test Workflow**(워크플로우 테스트)로 전체 흐름을 테스트하세요.

## 활용 사례

### 사례 1: 경쟁사 모니터링과 즉시 알림

목표: 경쟁사 페이지가 바뀌는 즉시 알아채기.

워크플로우 구성:

- 트리거: **New Completed Task**(경쟁사 페이지 로봇으로 필터링)
- 액션: 수집된 필드(예: 가격, 헤드라인, 상태) 값으로 분기
- 액션: 필드가 바뀌었다면 내부 알림 보내기(Slack/SMS/이메일)

예시: 로봇이 Browse AI의 일정에 따라 경쟁사 가격 페이지를 스크랩해요. 태스크가 완료될 때마다 워크플로우가 실행돼요. 지난번 실행 때보다 가격이 바뀌었다면 마케팅 팀이 이전 값과 새 값이 담긴 Slack 메시지를 받아요.

### 사례 2: 고객이 제출한 URL → 요청 시 스크랩

목표: 고객이 방금 입력한 URL로 스크랩을 실행하고, 수집된 데이터로 워크플로우를 이어 가기.

워크플로우 구성:

- 트리거: **Form Submission**(폼 제출, URL 필드 포함)
- 액션: **Run Task**(제출된 URL을 로봇 입력값으로 사용)
- 워크플로우 2개로 나누기: 태스크 ID를 연락처에 저장하고 이 워크플로우를 끝내요.
- 두 번째 워크플로우 — 트리거: **New Completed Task** → 태스크 ID로 연락처 찾기 → 수집된 데이터로 업데이트

예시: 고객이 요청 폼으로 경쟁사 URL을 제출해요. 워크플로우가 해당 URL에 맞는 Browse AI 로봇을 실행하고 태스크 ID를 연락처에 저장해요. 스크랩이 끝나면 두 번째 워크플로우가 연락처를 찾고, 수집된 필드를 분석해 CRM 레코드를 업데이트해요. 고객에게는 분석 결과가 담긴 후속 메시지가 전달돼요.

### 사례 3: CSV로 리드 정보 일괄 보강

목표: URL이나 회사 이름 목록을 한꺼번에 처리하고, 보강된 데이터를 연락처에 다시 기록하기.

워크플로우 구성:

- 트리거: **File upload**(파일 업로드, N개 행이 있는 CSV)
- 액션: **Bulk Run Tasks**(행마다 태스크 1개, 행의 값을 로봇의 입력 파라미터로 전달)
- 대량 실행이 끝날 때까지 대기하거나 완료 시점을 트리거로 사용
- 액션: **Get Bulk Run**(집계된 결과 가져오기)
- 액션: 결과마다 CRM에서 일치하는 연락처 업데이트

예시: 에이전시가 회사 웹사이트 200개가 담긴 CSV를 업로드해요. 워크플로우가 행마다 태스크 1개씩 **Bulk Run Tasks** 단계를 실행해요. 대량 실행이 끝나면 **Get Bulk Run**이 모든 행의 수집 데이터를 가져오고, 워크플로우가 결과를 하나씩 돌면서 각 연락처의 기업 정보 커스텀 필드를 업데이트해요.

## 자주 묻는 질문

### Browse AI가 무엇인가요?
Browse AI는 코드 없이 웹 스크랩과 모니터링을 할 수 있는 플랫폼이에요. 로봇을 직접 학습시키거나 250개 이상의 사전 제작 로봇 중에서 골라 웹 페이지의 구조화된 데이터를 추출하고, 필요할 때 또는 일정에 맞춰 실행해요. 로봇을 한 번 실행하면 태스크 1개가 만들어지고, 대량 실행은 같은 로봇의 태스크 여러 개를 한 번에 대기열에 올려요.

### Browse AI 액션은 프리미엄 워크플로우 액션인가요?
네. 액션 4개와 트리거 모두 프리미엄으로 분류되어 있고, 표준 자동화 요율로 프리미엄 액션 크레딧이 차감돼요. Browse AI 사용량(로봇 크레딧, 태스크 크레딧)은 Browse AI 계정에서 Browse AI가 직접 청구해요.

### 트리거는 즉시 실행되나요, 아니면 주기적으로 확인하나요?
즉시 실행돼요. 웹훅 기반이라 Browse AI에서 로봇 태스크가 끝나고 몇 초 안에 워크플로우가 실행돼요.

### Browse AI API 키는 어디서 받나요?
Browse AI에 로그인해 대시보드를 열고 **Settings > API Keys**로 이동한 다음 **Create new API key**를 클릭해요. 이름(예: 'Workflows integration')을 정하고 값을 복사하세요. 복사한 값은 Browse AI 연결 화면의 **API Key**(API 키) 필드에 붙여 넣으면 돼요.
