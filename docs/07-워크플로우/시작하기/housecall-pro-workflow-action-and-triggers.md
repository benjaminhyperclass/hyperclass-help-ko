# Housecall Pro 연동 — 워크플로우 트리거와 액션(Job scheduled, Create new customer)

Housecall Pro 트리거와 액션을 워크플로우에 연결해서 작업 예약·완료 같은 이벤트로 자동화를 실행하는 방법을 안내해요. 워크플로우에서 Housecall Pro에 새 고객을 만들 수도 있어요.

## 개요

Housecall Pro는 주택 서비스 업체가 작업, 고객, 일정, 인보이스, 견적, 결제를 관리하는 현장 서비스 관리 플랫폼이에요. 이 연동을 쓰면 작업과 고객 같은 핵심 데이터를 워크플로우 빌더에서 바로 활용할 수 있어요. 작업이 예약되거나 완료되면 고객에게 보내는 자동화가 실행되고, 어떤 워크플로우에서든 Housecall Pro에 새 고객을 등록할 수 있어요.

예를 들면 이런 일을 할 수 있어요.

- 새 작업이 예약되면 확인 문자를 바로 보내요.
- 작업이 완료되면 감사 메시지와 리뷰 요청을 보내요.
- 일정이 바뀌면 고객과 배정된 팀원에게 함께 알려요.
- 웹 폼으로 들어온 신규 리드를 Housecall Pro 고객으로 등록해서, 서비스 팀이 견적과 일정을 잡을 수 있게 해요.

## 연동 구성

이 연동은 두 부분으로 이루어져 있어요.

- 트리거(Housecall Pro → 워크플로우): 폴링 방식 트리거 9개가 있어요. 작업의 진행 단계(생성, 예약, 완료, 취소), 견적의 진행 단계(생성, 예약, 완료), 신규 리드와 신규 고객 이벤트를 다뤄요.
- 액션(워크플로우 → Housecall Pro): 액션 14개가 있어요. 고객 관리(생성, 조회, 수정, 검색, 주소 생성·조회), 작업 관리(생성, 조회, 예약 생성·수정), 견적 관리(생성, 조회), 리드 관리(생성, 조회)를 다뤄요.

모든 트리거와 액션은 프리미엄 워크플로우 구성 요소예요. 프리미엄 액션 크레딧이 표준 자동화 요율로 차감돼요. Housecall Pro 요금제 사용량(작업, 고객, 인보이스, 결제)은 Housecall Pro 계정에서 Housecall Pro가 직접 청구해요.

## Housecall Pro 연결하기

Housecall Pro 트리거나 액션을 쓰려면 먼저 API 키로 연동을 연결해야 해요.

### 워크플로우 빌더에서 연결하기 (권장)

1. **자동화 > 워크플로우**를 열고 워크플로우를 고르거나 새로 만드세요.
2. Housecall Pro 트리거나 액션을 추가하세요. **Apps**(앱) 탭에서 Housecall Pro를 검색하면 돼요.
3. 트리거(**Job scheduled**) 또는 액션(**Create new customer**)을 선택하세요.
4. 패널에서 **Connect your account**(계정 연결)를 클릭하세요.
5. **Connect with API Key**(API 키로 연결) 창에 Housecall Pro API 키를 붙여 넣으세요.
6. **Save**(저장)를 클릭하세요. 패널에 **Connected**(연결됨)로 바뀌어요.

### 설정에서 연결하기 (다른 방법)

1. **설정 > 연동**으로 이동하세요.
2. Housecall Pro를 찾아 **Connect**(연결)를 클릭하세요.
3. API 키를 붙여 넣고 **저장**을 클릭하세요.

## 트리거 목록

모든 트리거는 정해진 주기로 Housecall Pro를 확인(폴링)해요. 마지막 확인 이후 조건에 맞는 레코드를 순서대로 가져와요. 생성 이벤트는 5분마다, 예약·완료·취소 이벤트는 10분마다 확인해요.

작업

| 트리거 | 동작 |
| --- | --- |
| **Job created (5 min)**(작업 생성) | Housecall Pro에서 새 작업이 만들어지면 실행돼요. 중첩된 고객 객체가 포함된 작업 데이터를 전달해요. |
| **Job scheduled (10 min)**(작업 예약) | 작업이 예약되거나, 기존 작업의 일정이 바뀌면 실행돼요. 데이터 구조는 같아요. |
| **Job finished (10 min)**(작업 완료) | 작업이 완료로 표시되면 실행돼요. 리뷰 요청, 영수증, 설문, 추가 판매 흐름 같은 서비스 후속 조치에 알맞아요.|
| **Job canceled (10 min)**(작업 취소) | 작업이 취소되면 실행돼요. 일정 재안내와 팀원 알림에 함께 쓰세요. |

견적

| 트리거 | 동작 |
| --- | --- |
| **Estimate created (5 min)**(견적 생성) | 새 견적이 만들어지면 실행돼요. |
| **Estimate scheduled (10 min)**(견적 예약) | 견적 방문이 예약되거나 일정이 바뀌면 실행돼요. |
| **Estimate finished (10 min)**(견적 완료) | 견적 방문이 완료로 표시되면 실행돼요. 확정된 견적서를 고객에게 보내 검토·승인을 받을 때 유용해요. |

리드와 고객

| 트리거 | 동작 |
| --- | --- |
| **Lead created (5 min)**(리드 생성) | Housecall Pro에 새 리드가 들어오면 실행돼요. 리드 확인이나 담당자 배정 흐름을 시작할 때 알맞아요. |
| **Customer created (5 min)**(고객 생성) | 새 고객 레코드가 만들어지면 실행돼요. 직접 등록하거나, 가져오기나 다른 연동으로 만든 경우에도 실행돼요. |

## 예시: 트리거 설정하기 (Job scheduled)

특정 Housecall Pro 계정에서 작업이 예약되거나 일정이 바뀔 때마다 실행되는 워크플로우를 만들어 볼게요. **Job completed** 트리거도 설정 방식이 같아요. 트리거 선택과 **Workflow Trigger Name**(워크플로우 트리거 이름)만 달라요.
### 1단계: 트리거 추가하기

1. 워크플로우를 열고 **Add Trigger**(트리거 추가)를 클릭하세요.
2. **Apps**(앱) 탭으로 이동해 Housecall Pro를 검색하세요.
3. 트리거 목록에서 **Job scheduled**(작업 예약)를 선택하세요.

### 2단계: 트리거 설정하기

- **Connected Account**(연결된 계정): 이 트리거가 확인할 Housecall Pro 계정을 고르세요. 연결된 계정이 하나뿐이면 자동으로 선택돼요.
- **Workflow Trigger Name**(워크플로우 트리거 이름): 알아보기 쉬운 이름을 붙이세요. 예: '신규 작업 예약', '작업 예약 또는 일정 변경'
- **Add filters**(필터 추가, 선택): 특정 상황에서만 워크플로우를 실행하려면 조건을 더하세요. 고객 속성, 작업 유형이나 태그, 담당 직원 같은 조건을 자주 써요.

### 3단계: 트리거 테스트하기

1. **Test your trigger**(트리거 테스트) 패널에서 **Find new records**(새 레코드 찾기)를 클릭하세요.
2. Housecall Pro에서 최근에 예약된 작업 중 조건에 맞는 것을 가져와요.
3. **Records — Select Mapping Reference**(레코드 — 매핑 참조 선택) 드롭다운에서 가져온 레코드 하나를 고르세요. 그러면 작업과 중첩된 고객 구조가 이후 단계에서 쓸 수 있도록 고정돼요.
4. 미리보기에 가져온 필드가 보이는지 확인하세요. 예: job id, invoice_number, description, customer.id, customer.first_name, customer.last_name, customer.email, customer.mobile_number, customer.home_number 등
5. **Save trigger**(트리거 저장)를 클릭해 마무리하세요.

## 예시: 액션 설정하기 (Create new customer)

워크플로우에서 새 연락처를 Housecall Pro에 고객으로 복사하는 예시예요. **Create new customer** 액션을 써요.

### 1단계: 액션 추가하기

1. 워크플로우 안에서 **Add**(추가)를 클릭해 새 단계를 넣으세요.
2. **Apps**(앱) 탭을 열고 Housecall Pro를 선택하세요.
3. 액션 목록에서 **Create new customer**(새 고객 생성)를 고르세요.

### 2단계: 액션 설정하기

- **Connected Account**(연결된 계정): 고객을 만들 Housecall Pro 계정을 고르세요.
- **Action Name**(액션 이름): 알아보기 쉬운 이름을 붙이세요. 예: '웹 폼에서 고객 생성'
- **First Name**(이름, 필수): 워크플로우 변수를 넣으세요. 예: {{contact.first_name}}
- **Last Name**(성, 필수): 워크플로우 변수를 넣으세요. 예: {{contact.last_name}}
- **Email**(이메일, 선택): 워크플로우 변수나 직접 입력한 값을 넣으세요.
- **Company**(회사, 선택): 고객이 사업체와 연결된 B2B나 협력업체 관계일 때 쓰세요.
- **Mobile Number**(모바일 번호, 선택): 숫자 10자리, 숫자만 입력해야 해요. 예: 5125551234. 형식이 맞지 않는 값은 호출 전에 거부돼요.
- **Home Number**(집 전화번호, 선택): **Mobile Number**와 같은 10자리 형식이에요.

### 3단계: 액션 테스트하기

1. **Test Action**(액션 테스트)을 클릭하세요.
2. 확인 창이 나오면 내용을 확인하세요. 이 테스트는 실제 API 호출이라서 Housecall Pro에 진짜 고객 레코드가 만들어져요. 운영 계정으로 반복해서 테스트한다면, 나중에 지우기 쉽게 'TEST — DELETE'처럼 테스트임이 분명한 이름을 쓰세요.
3. **Test Drawer**(테스트 패널)에서 응답을 확인하세요. 새 고객 ID가 응답 데이터에 표시돼요.
4. 액션을 저장하고, 게시하기 전에 **Test Workflow**(워크플로우 테스트)로 전체를 한 번 실행해 보세요.

## 트리거와 액션 테스트하기

게시하기 전에 꼭 테스트하세요. 테스트하면 데이터 구조가 고정되고, 이후 단계에서 연결해 쓸 실제 레코드를 받을 수 있어요.

### 트리거 테스트 (둘 중 어느 트리거든 같아요)

1. 트리거 패널에서 **Find new records**(새 레코드 찾기)를 클릭하세요.
2. 조건에 맞는 레코드가 없으면 Housecall Pro에서 직접 작업을 해 보세요. **Job scheduled**는 테스트 고객으로 작업을 예약하고, **Job completed**는 작업을 완료로 표시한 다음 다시 가져오세요.
3. 가져온 레코드를 매핑 참조로 선택하세요. 미리보기에 작업과 고객 필드가 나타나는지 확인하세요.

### 액션 테스트

1. 액션 패널에서 **Test Action**(액션 테스트)을 클릭하세요.
2. 설정한 입력값으로 실제 Housecall Pro 계정에서 액션이 실행돼요. 진짜 고객 레코드가 만들어져요.
3. Housecall Pro를 열어 **Customers**(고객) 목록에 고객이 보이는지 확인하세요. 반환된 고객 ID는 액션 응답 데이터에 기록돼요.
4. 결과가 맞지 않으면 필드 연결을 다시 확인하고(특히 **Mobile Number**는 숫자 10자리, 숫자만 가능해요) 다시 테스트하세요. 테스트가 끝나면 Housecall Pro에서 테스트 레코드를 정리하세요. 결과가 만족스러우면 **Save action**(액션 저장)을 클릭하고, 게시하기 전에 **Test Workflow**로 전체를 실행해 보세요.

## 활용 사례

### 사례 1: 새 작업 예약 → 고객 확인 메시지 + CRM 동기화

목표: 예약을 바로 확인해 주고, CRM이 실제 운영 데이터와 같은 상태를 유지하게 해요.

워크플로우 구성:

- 트리거: **Job scheduled**
- 액션: 고객에게 확인 문자나 이메일 보내기 (customer.mobile_number / customer.email 사용)
- 액션: CRM 연락처 찾기 또는 만들기 (이메일 기준)
- 액션: 연락처 업데이트 — 작업 유형을 태그로 붙이고, 작업 ID와 예약 시간대를 커스텀 필드에 저장

예시: 집주인이 다음 주 화요일로 보일러 점검을 예약해요. 곧바로 워크플로우가 예약 시간대가 담긴 확인 문자를 보내고, 일치하는 CRM 연락처를 찾거나 새로 만들어요. 그 연락처에 'HVAC — 점검' 태그를 붙이고, 시스템 간 리포팅에 쓸 수 있도록 Housecall Pro 작업 ID도 저장해요.

### 사례 2: 작업 일정 변경 → 고객 + 팀원 알림

목표: 별도 이벤트 유형 없이, 같은 트리거로 일정 변경까지 잡아요.

워크플로우 구성:

- 트리거: **Job scheduled** (새 예약과 일정 변경 모두에서 실행돼요)
- 분기: 이전에 본 작업인가요? (작업 ID를 CRM 커스텀 필드와 대조해 확인)
- 예(일정 변경): 고객에게 변경된 시간대를 알리는 메시지를 보내고, 배정된 팀원에게 디스패치 메모를 보내요
- 아니요(새 예약): 새 작업 확인 흐름을 실행해요 (사례 1)

예시: 고객이 배수구 청소 방문을 수요일에서 금요일로 바꿔요. 같은 **Job scheduled** 트리거가 실행되고, 워크플로우가 이미 본 작업 ID임을 확인해요. 그러면 고객에게 '방문 일정이 금요일로 변경되었어요' 문자를 보내고, 팀에는 새 시간대를 알리는 디스패치 메모를 남겨요.

### 사례 3: 작업 완료 → 리뷰 요청 + 영수증 전달

목표: 기술자가 작업을 완료로 표시하는 즉시 고객에게 감사 인사를 하고, 리뷰를 요청하고, 영수증을 보내 서비스를 마무리해요.

워크플로우 구성:

- 트리거: **Job completed**
- 액션: 한 번에 누를 수 있는 리뷰 링크(Google, Yelp 또는 플랫폼의 리뷰 시스템)가 담긴 감사 메시지(문자 또는 이메일) 보내기
- 분기: 작업 완료 시점에 전액 결제됐나요?
- 결제됨: 항목별 내역과 결제 확인이 담긴 영수증 보내기
- 미결제: 결제 링크가 담긴 정중한 인보이스 안내 보내기
- 선택 액션: 이후 라이프사이클 마케팅을 위해 CRM 연락처의 라이프사이클 단계를 '고객 — 작업 완료'로 업데이트

예시: 배관공이 토요일 아침에 긴급 수리 작업을 완료로 표시해요. 몇 분 안에 워크플로우가 집주인에게 Google 리뷰 링크가 담긴 감사 문자를 보내요. 결제 상태에 따라 분기해서(현장에서 카드로 결제된 작업이에요) 영수증을 자동으로 보내고, CRM 연락처의 라이프사이클 단계를 올려요. 그러면 90일 뒤에 재방문 유도 흐름이 이 고객을 이어받을 수 있어요.

## 자주 묻는 질문

### Housecall Pro가 무엇인가요?
Housecall Pro는 주택 서비스 업체가 작업, 고객, 일정, 인보이스, 견적, 결제를 관리하는 현장 서비스 관리 플랫폼이에요. 냉난방, 배관, 전기부터 청소, 잔디 관리, 해충 방제까지 다양한 서비스 업종에서 써요.

### Housecall Pro 트리거와 액션은 프리미엄 워크플로우 구성 요소인가요?
네. 트리거와 액션 모두 프리미엄으로 분류되고, 프리미엄 액션 크레딧이 표준 자동화 요율로 차감돼요. Housecall Pro 요금제 사용량(작업, 고객, 인보이스, 결제)은 Housecall Pro 계정에서 Housecall Pro가 직접 청구해요.

### 새 예약과 일정 변경 모두에서 트리거가 실행되나요?
네. **Job scheduled**는 작업의 예약 날짜나 시간이 설정될 때마다 실행돼요. 처음 예약할 때도, 같은 작업의 일정을 나중에 바꿀 때도 실행돼요. 이후 동작을 다르게 하고 싶다면 **Add filters**(필터 추가)나 워크플로우 분기(이전에 본 작업 ID인지 확인)로 구분하세요.

### Job scheduled와 Job completed는 무엇이 다른가요?
**Job scheduled**는 현장 서비스 흐름의 시작, 즉 작업이 예약되거나 일정이 바뀔 때 실행돼요. **Job completed**는 끝, 즉 기술자가 Housecall Pro에서 작업을 완료로 표시할 때 실행돼요. 두 트리거 모두 작업과 중첩된 고객 데이터를 같은 구조로 반환해서, 이후 단계에서 같은 방식으로 필드를 연결할 수 있어요. 함께 쓰면 전체 흐름을 이어 줄 수 있어요. **Job scheduled**에서는 확인 메시지를, **Job completed**에서는 리뷰 요청과 영수증을 보내세요.
### Housecall Pro API 키는 어떻게 만드나요?
Housecall Pro에 로그인한 뒤 오른쪽 위의 **My Apps**(내 앱) 아이콘을 클릭하세요. **Go to App Store**(앱 스토어로 이동)를 선택하고 **API Key Management**(API 키 관리) 앱을 연 다음 **Generate API Key**(API 키 생성)를 클릭하세요. 이름을 붙이고(예: 'Workflows integration') 권한을 **Full Access**(전체 권한)로 설정하세요. 생성된 값을 연결 창의 **API Key** 필드에 복사해 붙여 넣으면 돼요.

### Housecall Pro의 MAX 요금제가 필요한가요?
아니요. Housecall Pro의 기본 웹훅 설정은 MAX 요금제에서만 쓸 수 있지만, 이 연동은 API 키 인증을 사용해요. 전체 권한(Full Access)의 API 키를 지원하는 Housecall Pro 유료 요금제라면 사용할 수 있어요. 잘 모르겠다면 Housecall Pro 고객지원에 요금제가 API 접근을 지원하는지 확인하세요.
