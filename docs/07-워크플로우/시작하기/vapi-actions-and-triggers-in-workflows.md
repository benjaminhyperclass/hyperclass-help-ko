# 워크플로우에서 VAPI 트리거·액션 사용하기 (Vapi - Actions and Triggers in Workflows)

하이퍼클래스 워크플로우를 VAPI(Voice AI Platform Integration)와 연결하면 AI 음성 어시스턴트, 통화, 채팅, 파일 관리를 별도 외부 도구 없이 자동화할 수 있어요. 이 문서에서는 연동의 개념과 장점, 설정 방법, 사용할 수 있는 트리거와 액션, 활용 사례, 사용 시 권장 사항을 안내해요.

## 워크플로우에서 VAPI는 무엇인가요?

VAPI를 연결하면 하이퍼클래스 워크플로우에서 AI 음성·채팅 상호작용을 시작하고 관리할 수 있어요.

자동화 방향은 두 가지예요.

### VAPI → 하이퍼클래스 (트리거)

VAPI에서 이벤트가 생기면 하이퍼클래스 워크플로우를 시작해요. 예를 들어 새 통화가 만들어질 때예요.

### 하이퍼클래스 → VAPI (액션)

CRM에서 이벤트가 생기면 VAPI 안에서 AI 통화, 채팅, 파일 업로드를 실행해요. 예를 들어 새 리드가 폼을 제출할 때예요.

이 연동으로 에이전시와 비즈니스는 AI 음성 자동화를 이용해 리드 자격 검증, 예약 알림, 온보딩 안내, 아웃바운드 캠페인을 자동화할 수 있어요.

## 주요 장점

- 즉시 AI 리드 자격 검증: 폼을 제출한 리드에게 자동으로 전화해요.
- CRM과 AI 동기화: AI 통화 결과에 따라 기회를 업데이트해요.
- 예약 확인 자동화: 알림 통화로 노쇼를 줄여요.
- 지식 기반 어시스턴트: 문서를 업로드해서 AI 답변의 품질을 높여요.
- 수작업 감소: 외부 웹훅이나 Zapier 설정이 필요 없어요.

## 사전 준비 및 권한

워크플로우에서 VAPI를 쓰기 전에 아래 항목을 확인하세요.

- **자동화 > 워크플로우**에 접근할 수 있어야 해요.
- VAPI 계정이 연결되어 있고 활성 상태여야 해요.
- 프리미엄 워크플로우 기능이 켜져 있어야 해요.

## VAPI 계정 연결하기

### 워크플로우 빌더에서 연결하기

1. **자동화 > 워크플로우**로 이동해요.
2. 워크플로우 빌더에서 VAPI 트리거나 액션을 추가해요.
3. **Connect Now**(지금 연결)를 클릭해요.
4. VAPI 계정을 승인해요.

### 연동 페이지에서 연결하기

1. **설정 > 연동**으로 이동해요.
2. **VAPI**를 선택해요.
3. **연결**을 클릭해요.
4. 인증을 완료해요.

연결이 끝나면 워크플로우 빌더에서 VAPI 단계가 자동으로 불러와져요.

### VAPI API 키 찾기

VAPI 대시보드는 VAPI의 화면이라 영어로 표시돼요.

1. [dashboard.vapi.ai](http://dashboard.vapi.ai)에 접속해 로그인해요.
2. **Account** 메뉴를 열어요.
3. **API Keys**를 클릭해요.
4. 필요하면 새 키를 만들고 **Private API Key**를 복사해요.

## 사용할 수 있는 트리거 (VAPI → 하이퍼클래스)

| 트리거 | 설명 |
| --- | --- |
| **New Assistant**(새 어시스턴트) | VAPI에서 새 AI 어시스턴트가 만들어질 때 실행돼요 |
| **New Call**(새 통화) | VAPI에서 새 통화가 시작될 때 실행돼요 |
| **New File**(새 파일) | VAPI에 지식 파일이 업로드될 때 실행돼요 |

필요하면 필터를 사용해 워크플로우에 들어오는 대상을 제한할 수 있어요. 이 트리거들은 5분마다 확인하는 폴링 방식으로 작동해요.

## 사용할 수 있는 액션 (하이퍼클래스 → VAPI)

| 액션 | 설명 |
| --- | --- |
| **Create a Call**(통화 생성) | AI 음성 통화를 시작해요 |
| **Create Chat**(채팅 생성) | 새 AI 채팅 세션을 시작해요 |
| **Upload File**(파일 업로드) | AI 어시스턴트가 참고할 지식 파일을 업로드해요 |
| **Delete Call Data**(통화 데이터 삭제) | 저장된 통화 데이터를 삭제해요 |
| **Delete Chat Data**(채팅 데이터 삭제) | 채팅 세션 데이터를 삭제해요 |
| **Delete File**(파일 삭제) | 지식 파일을 삭제해요 |
| **Update Call Name**(통화 이름 업데이트) | 통화 메타데이터를 수정해요 |
| **Find Call**(통화 찾기) | ID로 통화 상세 정보를 가져와요 |

## Upload File — 지원하는 파일 형식

**Upload File** 액션 단계 하나에는 파일을 하나만 업로드할 수 있어요.

파일이 여러 개 필요하면 **Upload File** 단계를 순서대로 여러 개 추가하세요.

### 지원하는 파일 형식

- Markdown (.md)
- PDF (.pdf)
- 텍스트 파일 (.txt, .log)
- CSV / TSV (.csv, .tsv)
- HTML / CSS / JS / TS (.html, .css, .js, .ts)
- XML (.xml)
- JSON (.json)
- YAML (.yaml, .yml)
- Microsoft Word (.doc, .docx)

이 파일들은 보통 AI 어시스턴트의 지식 소스로 쓰여요.

## 통화 동시 실행 수와 요청 제한

### 기본 동시 실행 수

VAPI 계정에는 기본적으로 동시 통화 슬롯이 10개 있어요.

즉, 다음과 같이 동작해요.

- 동시에 진행할 수 있는 통화는 10건뿐이에요.
- 초과한 통화는 자동으로 대기열에 들어가고, 슬롯이 비면 다시 시도돼요.

예를 들어 통화 25건이 동시에 실행되면 이렇게 처리돼요.

- 10건은 바로 시작해요.
- 15건은 슬롯이 빌 때까지 대기열에서 기다려요.

### 동시 실행 수 늘리기

VAPI 대시보드에서 늘릴 수 있어요.

**Settings > Billing > Reserved Concurrency**

VAPI 구독에 따라 추가 요금이 발생할 수 있어요.

### API 요청 제한

동시 실행 수 제한과 별개로, VAPI 구독 등급에 따라 API 요청 제한이 적용될 수 있어요.

통화량이 많은 캠페인을 운영할 때는 이렇게 하세요.

- 수백 건의 통화를 한꺼번에 실행하지 않아요.
- 워크플로우에 **Wait**(대기) 단계를 사용해요.
- 아웃바운드 자동화를 시차를 두고 실행해요.
- **Execution Logs**(실행 로그)에서 API 오류가 없는지 확인해요.

## 지원하는 전화번호

현재는 VAPI 안에서 직접 구매한 전화번호만 지원해요.

아래 번호는 지원하지 않아요.

- 직접 연결한 Twilio 번호 (출시 예정)
- 하이퍼클래스 전화번호 (출시 예정)
- 외부에서 가져온 번호 (출시 예정)

지원하지 않는 번호로 통화를 시작하면 통화가 실패해요.

## 워크플로우에서 VAPI 설정하기

1. **자동화 > 워크플로우**로 이동해요.
2. 워크플로우를 새로 만들거나 기존 워크플로우를 열어요.
3. 트리거를 선택해요. 예를 들어 **Form Submitted**(폼 제출), **Appointment Created**(예약 생성), **Pipeline Stage Changed**(파이프라인 단계 변경)가 있어요.
4. VAPI 액션을 추가해요. 예를 들어 **Create a Call**이에요.
5. 다음과 같은 머지 값으로 동적 필드를 연결해요.
`{{contact.first_name}}``{{contact.phone}}``{{opportunity.name}}``{{custom_values}}`
6. 필요하면 조건이나 **Wait** 단계를 추가해요.
7. 초안 상태에서 테스트해요.
8. **Publish**(게시)를 클릭해요.

## 활용 사례

**1. 즉시 AI 리드 자격 검증**
트리거: **Form Submitted** → 액션: **Create a Call**
AI 결과가 적격(Qualified)이면 영업 단계로 이동해요.
부적격(Unqualified)이면 육성 캠페인에 추가해요.

**2. AI 예약 알림**
트리거: **Appointment Created** → **Wait**(예약 시간 전까지) → **Create a Call**
전화를 받지 않으면 SMS 알림을 보내요.

**3. AI 온보딩 어시스턴트**
트리거: **Deal Closed Won**(고객전환성공) → **Upload File**(온보딩 PDF) → **Create Chat** → **Internal Notification**(내부 알림)

**4. 데이터 자동 정리**
트리거: **Deal Closed Lost**(고객전환실패) → **Find Call** → **Delete Call Data** → **Delete Chat Data**

### 통화 상세 정보는 어디서 볼 수 있나요?

하이퍼클래스에서는 통화가 시작됐는지 확인할 수 있어요.

통화별 상세 정보는 **VAPI 대시보드**에서 확인하세요.

VAPI 대시보드에서는 다음 정보를 볼 수 있어요.

- 통화 대화 기록
- 통화 시간
- 통화 지연 시간
- AI 상호작용 로그
- 녹음 (켜 둔 경우)
- 통화 결과와 상태
- 어시스턴트의 동작과 분석

상세한 통화 데이터는 모두 VAPI에 저장돼요.

## 자주 묻는 질문

### 기본 동시 실행 수는 몇 건인가요?

VAPI 계정당 동시 통화 10건이에요.

### 동시 실행 수를 늘릴 수 있나요?

네, VAPI 결제 설정의 Reserved Concurrency나 VAPI의 엔터프라이즈 요금제를 통해 늘릴 수 있어요. 이 설정은 VAPI 대시보드에서 해야 해요.

### 파일을 여러 개 업로드할 수 있나요?

**Upload File** 단계 하나에는 파일을 하나만 올릴 수 있어요. 필요하면 단계를 여러 개 추가하세요.

### 어떤 파일 형식을 지원하나요?

.md, .pdf, .txt, .log, .csv, .tsv, .html, .css, .js, .ts, .xml, .json, .yaml, .yml, .doc, .docx를 지원해요.

### 제가 가진 전화번호를 사용할 수 있나요?

아니요. VAPI 안에서 직접 구매한 전화번호만 지원해요.

### 이 단계들은 프리미엄 워크플로우 단계인가요?

네. VAPI 액션과 트리거는 프리미엄 워크플로우 요금 기준을 따라요. 기본 프리미엄 액션·트리거 요금이 청구돼요.

### 자주 발생하는 오류 원인에는 어떤 것이 있나요?

- 동시 실행 수 제한에 도달했어요.
- 지원하지 않는 전화번호를 썼어요.
- 연동이 끊겼어요.
- 어시스턴트 설정이 없어요.
- 전화번호 형식이 올바르지 않아요.
- API 요청 제한을 초과했어요.
