# Todoist 워크플로우 트리거·액션 (New incomplete task, Create task 등)

Todoist 연동을 쓰면 Todoist의 작업 변화로 워크플로우를 시작하거나, 워크플로우 안에서 Todoist 작업과 프로젝트를 관리할 수 있어요. 이 문서에서는 연동 방법, 트리거·액션 목록, 설정 예시, 테스트 방법을 안내해요.

## 개요

Todoist는 개인과 팀이 일을 프로젝트, 섹션, 작업으로 나누어 관리하는 작업 관리 플랫폼이에요. 라벨, 우선순위, 마감일, 기한, 댓글, 협업 기능을 지원해요.

Todoist 연동을 쓰면 이런 작업 활동이 고객에게 보이는 자동화를 실행할 수 있어요. 워크플로우 빌더(Workflow Builder)를 벗어나지 않고도 Todoist 작업과 프로젝트를 관리할 수 있어요.

## 연동 구성

이 연동은 트리거와 액션 두 부분으로 이루어져요.

- 트리거(Todoist → 워크플로우): 폴링(주기적 확인) 방식 트리거 3개가 있어요. **New incomplete task**, **New completed task**, **New project**이고, 모두 5분마다 확인해요.
- 액션(워크플로우 → Todoist): 액션 12개가 있어요. 작업 처리(만들기, 업데이트, 완료 처리), 작업·프로젝트 댓글, 프로젝트 만들기와 섹션 이동, 검색(작업 찾기, 프로젝트 찾기, 사용자 찾기), 협업자 관리(협업자 조회, 사용자 초대)를 다뤄요.

모든 트리거와 액션은 프리미엄 워크플로우 구성 요소예요. 프리미엄 액션 크레딧이 표준 자동화 요율로 적용돼요. Todoist 플랜 사용량(프로젝트, 작업, 협업자, 연동)은 Todoist 계정에서 Todoist가 직접 청구해요.

## Todoist 연결하기

Todoist 트리거나 액션을 실행하려면 먼저 OAuth로 연동을 연결해야 해요.

### 워크플로우 빌더에서 연결하기 (권장)

1. **자동화 > 워크플로우**를 열고 워크플로우를 선택하거나 새로 만드세요.
2. Todoist 트리거나 액션을 추가해요. **Apps**(앱) 탭에서 Todoist를 검색하세요.
3. Todoist 트리거나 액션을 아무거나 선택하세요.
4. 패널에서 **Connect your account**(계정 연결)를 클릭하세요.
5. Todoist의 OAuth 승인 화면으로 이동해요. 요청된 권한을 승인하세요.
6. 워크플로우 빌더로 돌아오면 패널에 **Connected**(연결됨)로 표시돼요.

### 설정에서 연결하기 (다른 방법)

1. **설정 > 연동**으로 이동하세요.
2. Todoist를 찾아 **Connect**(연결)를 클릭하세요.
3. OAuth 연결 과정을 마치세요.

## 트리거 목록

모든 트리거는 Todoist를 5분마다 확인해요. 마지막 확인 이후 조건에 맞는 레코드를 순서대로 가져와요.

| 트리거 | 하는 일 |
| --- | --- |
| **New incomplete task**(새 미완료 작업) | 프로젝트에 새 작업이 추가되면 실행돼요. **Project**(프로젝트)로 필터링할 수 있어서 특정 프로젝트의 작업에만 실행할 수도 있어요. 작업 정보(제목, 메모, 마감일, 기한, 우선순위, 라벨, 프로젝트, 섹션)를 가져와요. |
| **New completed task**(새 완료 작업) | 기존 작업이 완료 처리되면 실행돼요. 완료 알림이나 완료 후 이어지는 흐름에 알맞아요. |
| **New project**(새 프로젝트) | 연결된 계정에 새 프로젝트가 만들어지면 실행돼요. 프로젝트 시작에 필요한 항목을 자동으로 준비할 때 유용해요. |

## 액션 목록

액션은 관리하는 대상별로 나뉘어 있어요.

작업 처리

| 액션 | 용도 |
| --- | --- |
| **Create task**(작업 만들기) | Todoist에 새 작업을 만들어요. 프로젝트, 섹션, 라벨, 우선순위, 마감일은 선택 사항이에요. 필수 항목은 **Title**(제목)이고, 프로젝트를 지정하지 않으면 Inbox에 만들어져요. |
| **Update task**(작업 업데이트) | ID로 기존 작업을 찾아 제목, 메모, 마감일, 기한, 우선순위, 라벨을 수정해요. |
| **Mark task as completed**(작업 완료 처리) | 기존 작업을 완료로 표시해요. 같은 계정에서 **New completed task** 트리거를 쓰는 워크플로우가 있으면 그 워크플로우가 실행돼요. |
| **Move task to section**(작업을 섹션으로 이동) | 기존 작업을 같은 프로젝트 안의 특정 섹션으로 옮겨요. |

댓글

| 액션 | 용도 |
| --- | --- |
| **Add comment to task**(작업에 댓글 추가) | 기존 작업에 댓글을 달아요. 진행 상황을 기록하거나 외부 시스템의 정보를 덧붙일 때 유용해요. |
| **Add comment to project**(프로젝트에 댓글 추가) | 특정 작업이 아니라 프로젝트 전체에 댓글을 달아요. |

프로젝트

| 액션 | 용도 |
| --- | --- |
| **Create project**(프로젝트 만들기) | Todoist 프로젝트를 새로 만들어요. 신규 고객, 신규 계약, 새 스프린트마다 워크플로우로 프로젝트 틀을 자동으로 만들 때 유용해요. |

검색

| 액션 | 용도 |
| --- | --- |
| **Find tasks**(작업 찾기) | 이름, 프로젝트, 라벨, 필터로 Todoist 작업을 검색해요. 조건에 맞는 작업을 가져와 다음 분기에 쓸 수 있어요. |
| **Find projects**(프로젝트 찾기) | 연결된 계정의 프로젝트를 나열하거나 이름으로 필터링해요. 프로젝트 ID를 가져오는데, Inbox가 아닌 프로젝트에 **Create task**를 쓰려면 앞 단계에서 이 액션이 필요해요. |
| **Find user**(사용자 찾기) | 이름이나 이메일로 Todoist 사용자를 찾아요. |

협업

| 액션 | 용도 |
| --- | --- |
| **Get project collaborators**(프로젝트 협업자 조회) | 특정 Todoist 프로젝트에서 함께 일하는 사용자를 나열해요. |
| **Invite user to project**(프로젝트에 사용자 초대) | 이메일로 사용자를 초대해 프로젝트에서 협업하게 해요. |

## 예시: 트리거 설정하기 (New incomplete task)

특정 Todoist 프로젝트에 새 작업이 만들어질 때마다 실행되는 워크플로우를 설정해 볼게요. **New completed task**와 **New project**도 같은 방식으로 설정하고, 트리거 선택과 쓸 수 있는 필터만 달라요.

### 1단계: 트리거 추가하기

1. 워크플로우를 열고 **Add trigger**(트리거 추가)를 클릭하세요.
2. **Apps** 탭으로 이동해 Todoist를 검색하세요.
3. **New incomplete task**를 선택하세요.

### 2단계: 트리거 설정하기

1. **Connected Account**(연결된 계정): 이 트리거가 지켜볼 Todoist 계정을 선택하세요.
2. **Workflow Trigger Name**(워크플로우 트리거 이름): 알아보기 쉬운 이름을 입력하세요. 예: ‘새 지원 작업’
3. **Filters**(필터) > **Project**: 범위를 좁힐 프로젝트를 선택하세요. 도움말에는 ‘Only trigger for tasks in this project’(이 프로젝트의 작업에만 트리거)라고 표시돼요. 비워 두면 모든 프로젝트의 작업에서 실행돼요.
4. **Add filters**(필터 추가, 선택 사항): 라벨, 우선순위, 마감일 범위 같은 조건을 더할 수 있어요.

### 3단계: 트리거 테스트하기

1. **Test your trigger**(트리거 테스트) 패널에서 **Find new records**(새 레코드 찾기)를 클릭하세요.
2. 조건에 맞는 레코드가 나타나지 않으면 대상 Todoist 프로젝트에 작업을 추가하고, 확인 주기(5분)를 한 번 기다린 뒤 다시 가져오세요.
3. 가져온 레코드를 매핑 기준으로 선택하세요.
4. **Save trigger**(트리거 저장)를 클릭하세요.

## 예시: 액션 설정하기 (Create task)

워크플로우 이벤트로 Todoist 작업을 만드는 설정이에요. 워크플로우에서 Todoist로 보내는 방식 중 가장 흔한 형태예요.

### 1단계: 액션 추가하기

1. 워크플로우 안에서 **Add**(추가)를 클릭해 새 단계를 넣으세요.
2. **Apps** 탭을 열고 Todoist를 선택하세요.
3. 액션 목록에서 **Create task**를 선택하세요.

### 2단계: 액션 설정하기

1. **Connected Account**: 작업을 만들 Todoist 계정을 선택하세요.
2. **Action Name**(액션 이름): 알아보기 쉬운 이름을 입력하세요. 예: ‘폼 제출로 작업 만들기’
3. **Project**: 드롭다운에서 선택하세요. 지정하지 않으면 Inbox에 만들어져요. 워크플로우를 만들 때 프로젝트 ID를 모르면, 앞 단계에서 **Find projects**로 프로젝트 이름에서 ID를 찾아 쓰세요.
4. **Title**(제목, 필수): 작업 제목이에요. Todoist 작업 목록에서 깔끔하게 보이도록 짧게 쓰세요.
5. **Note**(작업 설명): 제목만으로 내용이 부족할 때 자세한 설명을 쓰세요.
6. **Due Date (Human Formatted)**(마감일, 사람이 읽는 형식) 또는 **Due Date (Raw Formatted)**(마감일, 원시 형식): 둘 중 하나만 고르세요. 둘 다 쓰면 안 돼요. 자세한 내용은 위의 ‘Working with Due Dates and Deadlines’를 참고하세요.7. **Deadline Date**(기한, 선택 사항): 엄격한 기한을 YYYY-MM-DD 형식으로 입력하세요. Todoist 기한에는 시간을 넣을 수 없어요.
8. **Priority**(우선순위): P1(빨간색, 가장 높음)부터 P4(회색, 가장 낮음, 기본값)까지 선택하세요.
9. **Labels**(라벨): 라벨을 하나 이상 선택하세요. 라벨은 Todoist 계정에 먼저 만들어져 있어야 해요.

### 3단계: 액션 테스트하기

1. **Test action**(액션 테스트)을 클릭하세요.
2. 안내에 따라 **Confirm**(확인)하세요. 이때 Todoist에 실제 작업이 만들어져요. 운영 중인 프로젝트에서 테스트한다면 ‘TEST — DELETE’처럼 테스트임을 분명히 알 수 있는 제목을 쓰세요.
3. 액션을 저장하고, 게시하기 전에 **Test workflow**(워크플로우 테스트)로 전체 흐름을 한 번 실행해 보세요.

## 트리거와 액션 테스트하기

게시하기 전에 꼭 테스트하세요. 테스트하면 데이터 구조가 확정되고, 뒤따르는 단계에서 실제 레코드를 기준으로 값을 연결할 수 있어요.

### 트리거 테스트

1. 트리거 패널에서 **Find new records**를 클릭하세요.
2. 조건에 맞는 레코드가 나타나지 않으면 Todoist에서 작업을 만들거나 완료하세요(또는 프로젝트를 만드세요). 확인 주기(5분)를 한 번 기다린 뒤 다시 가져오세요.
3. 가져온 레코드를 매핑 기준으로 선택하세요.

### 액션 테스트

1. 액션 패널에서 **Test action**을 클릭하세요.
2. 액션은 실제 Todoist 계정에서 실행돼요. 실제 작업, 댓글, 프로젝트가 만들어져요.
3. Todoist에서 결과를 확인하고, 테스트로 만든 레코드는 나중에 정리하세요.

## 활용 사례

### 사례 1: 폼 제출 → 알맞은 프로젝트에 Todoist 작업 만들기

목표: 들어온 요청을 알맞은 프로젝트, 라벨, 우선순위로 Todoist 작업에 연결해요.

워크플로우 구성:

- 트리거: **Form submission**(폼 제출)
- 선택 사항: 폼 입력값에 따라 분기해서 알맞은 프로젝트나 우선순위를 정해요.
- 액션: **Find projects**(이름으로 대상 프로젝트 ID 찾기)
- 액션: **Create task**(제목은 폼에서 가져오고, 설명에는 제출 내용 전체를 넣어요. 우선순위는 긴급도에 따라 정하고, 팀별 분류용 라벨을 붙여요.)

예시: 고객이 ‘긴급’으로 표시한 지원 요청을 제출해요. 워크플로우가 ‘Support Backlog’ 프로젝트를 찾아 요청 전체를 설명에 담고 ‘external-report’ 라벨을 붙인 P1 작업을 만들어요. 지원 팀장은 작업 목록을 벗어나지 않고 몇 초 안에 Todoist에서 확인할 수 있어요.

### 사례 2: 작업 완료 → 플랫폼에 결과 반영하기

목표: Todoist 작업이 완료 처리되면 후속 조치를 해요.

워크플로우 구성:

- 트리거: **New completed task**(프로젝트로 필터링)
- 액션: 작업을 처음 요청한 CRM 연락처와 연결해요. 저장해 둔 작업 ID나 연락처 정보를 담은 라벨을 이용해요.
- 액션: 연락처 업데이트, 알림 보내기, 단계 이동 중 필요한 작업을 해요.

예시: 영업 담당자(AE)의 Todoist에서 ‘Follow up with Acme’ 작업이 완료돼요. 5분 안에 CRM 연락처의 커스텀 필드가 업데이트되고(‘last touched: today’), 기회 단계가 한 단계 올라가요. AE는 Todoist를 그대로 쓰고, CRM 기록은 별도 작업 없이 갱신돼요.

### 사례 3: 마감일과 라벨이 있는 팀 작업

목표: 공유 프로젝트에 분류와 리포팅에 필요한 정보를 갖춘 작업을 만들어요.

워크플로우 구성:

- 트리거: 후속 조치가 필요한 모든 업무 이벤트
- 액션: **Create task**(Project = 공유 팀 프로젝트, Priority = P2, Labels = ‘needs-review’)
- 액션: **Add comment to task**(상황 설명, 링크, 안내 사항)

예시: 가입 이탈 자동화가 CS 팀의 Todoist 프로젝트에 작업을 만들어요. 설명에는 이탈한 세션 링크를 넣고, 우선순위는 P2, 라벨은 ‘needs-review’로 지정해요. CS 담당자는 평소 업무 흐름 안에서 이 작업을 가져가요.

## 자주 묻는 질문

### Todoist가 무엇인가요?
Todoist는 개인과 팀이 일을 프로젝트, 섹션, 작업으로 나누어 관리하는 작업 관리 플랫폼이에요. 라벨, 우선순위, 마감일, 기한, 댓글, 협업자를 지원해요. 무료와 유료 요금제가 있고, 유료 플랜에서는 알림, 더 큰 첨부파일, 더 많은 협업자, 고급 필터 같은 기능을 쓸 수 있어요.

### Todoist 트리거와 액션은 프리미엄 워크플로우 구성 요소인가요?
네. 트리거 3개와 액션 12개 모두 프리미엄으로 분류되어 있고, 표준 자동화 요율로 프리미엄 액션 크레딧이 차감돼요. Todoist 플랜 사용량(프로젝트, 작업, 협업자, 연동)은 Todoist 계정에서 Todoist가 직접 청구해요.

### 트리거는 즉시 실행되나요, 주기적으로 확인하나요?
주기적으로 확인해요. 트리거 3개 모두 Todoist를 5분마다 확인하고, 마지막 확인 이후 조건에 맞는 레코드를 순서대로 가져와요.
