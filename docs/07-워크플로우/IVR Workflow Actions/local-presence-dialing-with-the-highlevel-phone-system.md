# 하이퍼클래스 전화 시스템의 로컬 프레즌스 다이얼링(Local Presence Dialing)

로컬 프레즌스 다이얼링(Local Presence Dialing)은 발신 통화 시 관련성 높은 지역 발신자 번호(Caller ID)를 자동으로 선택해주는 기능이에요. 하이퍼클래스는 위치 기반 매칭을 통해 보유하신 전화번호 중에서 적절한 번호를 선택하여, 고객이 전화를 받을 때 익숙한 발신자 번호를 볼 수 있도록 도와드려요.

새롭게 구축된 로컬 프레즌스 엔진은 미국, 캐나다, 영국, 호주에서의 위치 기반 매칭을 지원해요. 또한 반복 발신 시에도 일관된 발신자 번호를 선택해주며, 웹 다이얼러(Web Dialer), 모바일 앱, 데스크폰에서의 발신 통화를 지원해요.

## **로컬 프레즌스 다이얼링이란?**

로컬 프레즌스 다이얼링은 연락처(Contacts)의 위치를 기반으로 가장 관련성 높은 발신 가능한 발신자 번호를 자동으로 선택해주는 기능이에요.

하이퍼클래스는 위치 정보와 매칭 우선순위를 활용하여 사용 가능한 번호를 평가해요. 정확한 지역 매칭 번호가 없을 경우, 하이퍼클래스는 추가 매칭 옵션을 순차적으로 검토한 후 계정 기본 번호를 사용해요.

## **꼭 알아두세요**

- 위치 기반 매칭은 미국, 캐나다, 영국, 호주에서 사용 가능해요.
- 하이퍼클래스는 인근 번호를 평가할 때 우편번호 거리 계산을 활용해요.
- 동일한 연락처로 반복 발신하는 경우, 이전에 선택된 동일한 로컬 프레즌스 번호를 사용해요.
- 로컬 프레즌스 다이얼링은 웹 다이얼러, 하이퍼클래스 모바일 앱, 데스크폰 전반에서 작동해요.
- 하위 계정(Sub-account)당 최대 50개의 번호를 예약(reserve)하여 자동 로컬 프레즌스 선택에서 제외할 수 있어요.
- 예약된 번호는 수동 발신 시에는 계속 사용할 수 있어요.
- 적절한 로컬 프레즌스 매칭 번호를 찾지 못하면, 통화는 계정 기본 번호를 사용해요.

## **로컬 프레즌스 다이얼링의 주요 장점**

로컬 프레즌스 다이얼링은 매번 통화할 때마다 발신 번호를 수동으로 선택해야 하는 번거로움을 줄여줘요.

- **자동 번호 선택**: 하이퍼클래스가 관련성 높은 사용 가능한 발신자 번호를 자동으로 선택해요.
- **일관된 발신자 번호**: 동일한 연락처로 반복 발신 시 이전에 선택된 동일한 로컬 프레즌스 번호를 사용해요.
- **위치 기반 매칭**: 하이퍼클래스는 번호 선택 시 ZIP 코드/우편번호, 지역 번호(area code), 오버레이 코드, 거리, 지역(region)을 평가할 수 있어요.
- **폭넓은 국가 지원**: 위치 기반 매칭은 미국, 캐나다, 영국, 호주를 지원해요.
- **다양한 발신 방식 지원**: 동일한 로컬 프레즌스 엔진이 웹 다이얼러, 모바일 앱, 데스크폰 전반에서 작동해요.
- **예약 번호 관리**: 중요한 번호는 자동 선택 대상에서 제외하면서도 수동 발신 시에는 계속 사용할 수 있어요.
- **자동 폴백(Fallback)**: 적절한 지역 매칭 번호가 없을 경우, 통화는 계속 계정 기본 번호를 사용해 진행돼요.

## **로컬 프레즌스 다이얼링 작동 방식**

발신 통화를 할 때, 하이퍼클래스는 보유하신 사용 가능한 번호를 평가하고 매칭 우선순위에 따라 가장 관련성 높은 발신자 번호를 선택해요.

### **발신자 번호 매칭 순서**

하이퍼클래스는 다음 순서로 적절한 번호를 확인해요:

- 리드(Lead)의 ZIP 코드 또는 우편번호
- 지역 번호(Area code)
- 오버레이 코드(Overlay code)
- 거리상 가장 가까운 사용 가능 번호
- 동일 지역(Region)
- 계정 기본 번호

하이퍼클래스는 이 우선순위 중에서 가장 먼저 매칭되는 적절한 번호를 사용해요.

### **반복 발신 시 일관된 발신자 번호**

하이퍼클래스가 특정 연락처에 대해 로컬 프레즌스 번호를 한 번 선택하면, 이후 해당 연락처로 반복 발신할 때도 동일한 번호를 계속 사용해요.

이를 통해 반복 발신 시마다 다른 번호가 선택되는 대신, 일관된 발신자 번호를 유지할 수 있어요.

### **지원되는 발신 통화 방식**

로컬 프레즌스 다이얼링은 다음과 같은 발신 통화 방식 전반에서 작동해요:

- 웹 다이얼러(Web Dialer)
- 하이퍼클래스 모바일 앱
- 데스크폰

### **자동 폴백(Fallback)**

로컬 프레즌스 다이얼링은 지역 매칭 번호가 없더라도 발신 통화 자체를 막지 않아요.

하이퍼클래스가 적절한 지역 번호를 찾지 못하거나 필요한 위치 데이터가 없는 경우, 시스템은 계정 기본 번호를 사용해요.

### **로컬 프레즌스 선택에서 번호 예약하기**

하위 계정당 최대 50개의 번호를 예약할 수 있어요. 예약된 번호는 로컬 프레즌스 다이얼링에서 자동으로 선택되지 않아요. 다만 발신 통화 시 수동으로 번호를 선택할 때는 계속 사용할 수 있어요.

예를 들어, 본사 대표 번호를 예약해두면 로컬 프레즌스 다이얼링이 자동으로 선택하지 못하게 하면서도, 필요할 때 수동으로 발신할 수 있도록 유지할 수 있어요.

*현재 UI 구성을 확인한 후, 정확한 예약 번호 설정 단계를 추가할 예정이에요.*

## **예시: 하이퍼클래스가 번호를 선택하는 방식**

로컬 프레즌스 다이얼링이 활성화된 상태에서 연락처에게 발신 통화를 건다고 가정해볼게요. 하이퍼클래스는 먼저 해당 연락처의 ZIP 코드 또는 우편번호를 기준으로 적절한 번호가 있는지 확인해요.

적절한 매칭 번호가 없다면, 하이퍼클래스는 다음 매칭 우선순위를 순서대로 검토해요:

- 지역 번호(Area code)
- 오버레이 코드(Overlay code)
- 거리상 가장 가까운 사용 가능 번호
- 동일 지역(Region)
- 계정 기본 번호

이를 통해 정확한 지역 번호가 없더라도 통화가 계속 진행될 수 있어요.

## **자주 묻는 질문**

### **연락처의 지역 번호가 보유한 번호 중 어느 것과도 일치하지 않으면 어떻게 되나요?**

하이퍼클래스는 바로 계정 기본 번호를 사용하는 대신, 로컬 프레즌스 매칭 우선순위를 계속 검토해요.

계정 기본 번호를 사용하기 전에 오버레이 코드, 거리상 가장 가까운 사용 가능 번호, 동일 지역 옵션을 순서대로 평가해요.

### **연락처에 필요한 위치 데이터가 없으면 어떻게 되나요?**

발신 통화는 계정 기본 번호를 사용하여 계속 진행돼요.

### **동일한 연락처에 전화할 때마다 매번 다른 발신자 번호가 사용되나요?**

아니요. 동일한 연락처로 반복 발신하는 경우, 이전에 선택된 동일한 로컬 프레즌스 번호를 사용해요.

### **위치 기반 로컬 프레즌스 다이얼링을 지원하는 국가는 어디인가요?**

위치 기반 매칭은 다음 국가에서 지원돼요:

- 미국
- 캐나다
- 영국
- 호주

### **어떤 발신 통화 방식에서 로컬 프레즌스 다이얼링을 사용할 수 있나요?**

로컬 프레즌스 다이얼링은 웹 다이얼러, 하이퍼클래스 모바일 앱, 데스크폰 전반에서 작동해요.

### **특정 번호가 로컬 프레즌스 다이얼링에 의해 선택되지 않도록 할 수 있나요?**

네, 가능해요. 하위 계정당 최대 50개의 번호를 예약할 수 있어요.

예약된 번호는 자동 로컬 프레즌스 선택에서는 제외되지만, 수동 발신 시에는 계속 사용할 수 있어요.

### **예약된 번호를 수동으로 사용할 수 있나요?**

네, 가능해요. 번호를 예약하면 로컬 프레즌스 다이얼링이 해당 번호를 자동으로 선택하지 못하게 할 뿐, 수동으로 사용하는 것을 막지는 않아요.

### **하이퍼클래스가 로컬 프레즌스 매칭 번호를 찾지 못하면 어떻게 되나요?**

하이퍼클래스는 계정 기본 번호를 사용하여 발신 통화가 계속 진행될 수 있도록 해요.

### **특정 통화에 대해 자동으로 선택된 번호를 수동으로 변경할 수 있나요?**

네, 가능해요. 개별 통화마다 다른 사용 가능한 번호를 수동으로 선택할 수 있어요.

### **추가할 수 있는 번호 개수에 제한이 있나요?**

하이퍼클래스는 현재 별도의 로컬 프레즌스 번호 풀(pool) 제한 없이, 하위 계정 내 보유한 전화번호와 인증된 발신자 번호(Verified Caller ID)를 지원해요. 50개 제한은 예약(reserved) 표시된 번호에만 적용돼요.

### **로컬 프레즌스 다이얼링이 인증된 발신자 번호(Verified Caller ID)를 지원하나요?**

현재 로컬 프레즌스 다이얼링은 인증된 발신자 번호를 지원해요.

### **제 Twilio 계정으로도 로컬 프레즌스 다이얼링을 사용할 수 있나요?**

네, 가능해요. 현재 로컬 프레즌스 다이얼링은 자체 Twilio 계정을 사용하는 하위 계정도 지원해요.

### **특정 사용자에 대해서만 로컬 프레즌스 다이얼링을 비활성화할 수 있나요?**

로컬 프레즌스 다이얼링은 개별 사용자가 아닌 하위 계정 단위로 설정돼요.

### **로컬 프레즌스 다이얼링을 사용하면 응답률이 더 높아지나요?**

아니요. 지역과 관련성 높은 발신자 번호는 수신자에게 더 친숙하게 느껴질 수 있지만, 응답률 상승을 보장하지는 않아요.
