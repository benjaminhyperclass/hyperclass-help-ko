# 맵 읽는 법과 연결 관계 이해하기

폴더, 워크플로우 칩, 자산, 화살표, 배지가 각각 무엇을 의미하는지, 그리고 맵에 표시되는 자산 유형에는 어떤 것들이 있는지 알아봐요.

## 맵 한눈에 보기

| 항목 | 의미 |
|---|---|
| 폴더 아일랜드 | 워크플로우 폴더예요. 폴더에 속하지 않은 워크플로우는 한데 모여 표시돼요. |
| 중첩 폴더 | 다른 폴더 안에 들어있는 폴더로, 상위 폴더 아일랜드 안에 표시돼요. 마우스를 올리면 전체 경로를 확인할 수 있어요. |
| 초록색 테두리의 파란색 워크플로우 칩 | 발행됨(Published) 상태의 워크플로우예요. |
| 회색 테두리의 파란색 워크플로우 칩 | 초안(Draft) 상태의 워크플로우예요. |
| 작은 색상 자산 칩 | 워크플로우가 사용하거나, 감시하거나, 변경하는 자산이에요. 색상으로 자산 유형을 구분해요. |
| 스티키 노트 | 팀에서 맵에 남긴 설명 메모예요. |

워크플로우를 클릭하면 상세 정보를 확인할 수 있어요. 자산을 클릭하면 해당 자산을 사용하는 워크플로우를 찾을 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352863/original/uC_2_K_OpxafUFxxyDdK8fLUaUtuA51clg.jpg?1793135769)

폴더를 선택하면 해당 폴더의 워크플로우와 자산을 확인할 수 있어요. 폴더 메뉴에는 조직화 관련 작업들이 들어있어요.

## 화살표의 의미

연결 관계는 점에서 화살촉 방향으로 읽으면 돼요.

| 방향 | 의미 | 예시 |
|---|---|---|
| 자산 → 워크플로우 | 트리거(Trigger) 관계예요. 워크플로우가 해당 자산을 감시해요. | 폼 제출이 워크플로우를 시작시켜요. |
| 워크플로우 → 자산 | 액션(Action) 관계예요. 워크플로우가 해당 자산을 변경해요. | 워크플로우가 태그를 추가해요. |
| 자산 ↔ 워크플로우 | 워크플로우가 해당 자산을 감시하면서 동시에 변경해요. | 하나의 태그가 트리거와 액션 모두에 사용돼요. |
| 워크플로우 → 워크플로우 | 직접 액션으로 다른 워크플로우에 연락처를 추가하거나 제거해요. | 한 워크플로우가 후속 워크플로우에 연락처를 추가해요. |

이 연결 관계들은 자동화가 어떻게 설정되어 있는지를 보여줘요. 특정 연락처의 이력을 확인하려면 연락처 추적(contact tracing) 기능을 사용하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352859/original/GzIctBahOpdd79HsFPCA8EtA6cXhFKSxKA.jpg?1793135766)

화살촉은 워크플로우와 자산 사이에 설정된 관계의 방향을 보여줘요.

## 선 스타일의 의미

| 선 스타일 | 의미 |
|---|---|
| 실선 | 무언가를 시작시키거나 변경할 수 있는 트리거 또는 액션 연결이에요. |
| 점선 | 필터에서 사용되는 자산처럼 단순 참조 관계예요. 이 참조는 스스로 무언가를 시작시키거나 변경하지 않아요. |
| 폴더 간 곡선 | 같은 자산이 여러 폴더에서 사용되고 있다는 뜻이에요. 각 폴더에는 해당 자산의 사본이 표시돼요. |
| 움직이는 화살표가 있는 밝은 파란색 선 | 현재 마우스를 올리고 있거나 선택한 항목의 연결을 나타내요. 화살표는 연결 방향을 따라 움직여요. |
| 더 굵은 파란색 선 | 선택한 연결을 나타내요. 세부 정보는 사이드 패널에 표시돼요. |

움직이는 화살표는 연결의 방향을 강조해서 보여줘요. 특정 실행 건을 조사하려면 연락처 이력(contact history)을 활용하세요.

## 연결 관계 확인 단계

- 맵이 완전히 축소된 상태라면 확대하세요.
- 워크플로우나 자산에 마우스를 올려서 연결을 강조 표시하세요.
- 확인하고 싶은 선을 클릭하세요.
- 사이드 패널에 표시된 트리거와 액션을 확인하세요.

맵이 완전히 축소된 상태에서는 선을 선택할 수 없어요.

## 배지의 의미

| 배지 | 의미 |
|---|---|
| 오류(Errors) | 최근 실행 중 워크플로우에서 오류가 발생했어요. |
| 사용 현황(Usage) | 클릭하면 여러 폴더에 걸친 자산 사용 현황을 확인할 수 있어요. |
| 누락된 자산(Missing asset) | 자산이 더 이상 존재하지 않지만, 워크플로우가 여전히 이를 참조하고 있어요. |

오류를 조사하려면 **오류가 있는 워크플로우 검토** 기능을 사용하세요. 누락된 자산의 경우, 워크플로우 참조를 확인해서 해당 자산이 어디서 여전히 사용되고 있는지 파악하세요.

## 지원되는 자산 유형

맵에서는 다음과 같은 자산 유형을 지원해요:

- **태그 및 필드:** 태그, 연락처 커스텀 필드(Contact Custom Fields), 기회 커스텀 필드(Opportunity Custom Fields), 커스텀 값(Custom Values), 커스텀 오브젝트(Custom Objects)
- **폼 및 참여:** 폼, 설문, 페이스북 폼(Facebook Forms), 틱톡 폼(TikTok Forms), 퀴즈(Quizzes), 트리거 링크, 채팅 위젯
- **일정 및 영업:** 캘린더, 사용자(Users), 파이프라인, 파이프라인 단계(Pipeline Stages), 서비스
- **퍼널 및 상품:** 퍼널, 퍼널 페이지(Funnel Pages), 퍼널 상품(Funnel Products), 글로벌 상품(Global Products), 글로벌 상품 가격(Global Product Prices)
- **멤버십 및 콘텐츠:** 멤버십 오퍼(Membership Offers), 멤버십 상품(Membership Products), 멤버십 카테고리(Membership Categories), 멤버십 레슨(Membership Lessons), 동영상(Videos)
- **템플릿 및 청구:** 템플릿, 수료증 템플릿(Certificate Templates), 인보이스 템플릿(Invoice Templates), 견적서 템플릿(Estimate Templates)
- **기타 자산:** 광고 계정(Ad Accounts), 워크플로우 링크(Workflow Links), AI 스튜디오 프로젝트(AI Studio Projects), 리스팅(Listings), 리스팅 카테고리(Listing Categories)

이러한 그룹 분류는 목록을 빠르게 훑어볼 수 있도록 도와주는 용도이며, 실제 지원되는 자산 유형은 각각의 개별 명칭이에요.

## 자주 묻는 질문

**Q: 같은 자산이 여러 폴더에 보이는 이유가 뭔가요?**

여러 폴더에서 사용되는 자산은 관련된 각 폴더에 모두 표시돼요. 이 사본들은 곡선으로 서로 연결돼요.

**Q: 대기(Wait), 조건 분기(If/Else), 이동(GoTo) 단계가 안 보이는 이유가 뭔가요?**

이 단계들은 워크플로우 내부 로직이기 때문이에요. 해당 단계를 확인하려면 빌더를 열어보세요. 단, 조건 분기 안에서 참조되는 태그는 검색으로 찾을 수 있어요.

**Q: 점선은 워크플로우가 해당 자산을 변경한다는 뜻인가요?**

아니요. 점선은 필터에서처럼 워크플로우가 해당 자산을 단순히 참조하고 있다는 의미예요.

**Q: 누락된 자산 배지는 무슨 뜻인가요?**

해당 자산이 삭제되었지만, 워크플로우에는 여전히 그 자산에 대한 참조가 남아있다는 뜻이에요.
