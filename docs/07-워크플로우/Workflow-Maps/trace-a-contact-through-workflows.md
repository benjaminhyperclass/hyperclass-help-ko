# 워크플로우에서 연락처 추적하기

연락처(Contacts)를 검색하고, 워크플로우 이력을 확인하고, 조사가 필요한 단계나 실행 내역을 열어볼 수 있어요.

## 연락처 추적으로 알 수 있는 것

연락처 추적 기능을 사용하면 "왜 이 고객에게 메시지가 발송됐을까?", "이 고객이 지금 자동화의 어느 단계에서 대기 중일까?" 같은 질문을 조사할 수 있어요.

이력에는 해당 연락처가 거쳐간 워크플로우, 발생 시점, 그리고 워크플로우가 완료됐는지, 대기 중인지, 오류가 발생했는지가 표시돼요.

연락처 이력은 **최근 60일**까지 확인할 수 있어요.

## 연락처 찾는 방법

- **Automation(자동화) → Workflows(워크플로우) → Workflow Maps** 메뉴로 이동하세요.
- 맵 왼쪽 패널에서 **Contacts(연락처)**를 여세요.
- 연락처의 **이름**, **이메일**, **전화번호** 중 하나로 검색하세요.
- 연락처를 선택해서 이력을 확인하세요.

## 워크플로우 이력 확인하기

**Workflows(워크플로우)** 탭과 **Timeline(타임라인)** 탭을 통해 연락처의 이력을 살펴볼 수 있어요.

각 행에는 워크플로우 이름, 발생 시간, 실행 상태가 표시돼요. 순서대로 확인하면서 이 연락처가 어떤 워크플로우에 진입했는지, 어디서 완료됐는지, 대기 중인지, 오류가 발생했는지를 파악하세요.


![예시 연락처의 워크플로우 이력과 실행 상태가 순서대로 표시된 타임라인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352908/original/ZKDVf9wWymOuS6aUefCsuQIPd61MkDfsQw.jpg?1793135921)


Timeline(타임라인) 탭에는 예시 연락처의 워크플로우 이력과 실행 상태가 순서대로 표시돼요.

## 단계 또는 실행 내역 열어보기

- 연락처 이력에서 워크플로우를 클릭하면 해당 연락처가 도달한 단계를 볼 수 있어요.
- 단계를 클릭하면 정확히 해당 실행 시점의 워크플로우가 열려요.
- 실행 세부 정보를 확인하며 조사하려는 동작을 살펴보세요.

예를 들어, 고객이 예상치 못한 이메일에 대해 문의하는 경우, 맵에 설정된 연결 관계만 보고 판단하기보다 해당 워크플로우를 찾아 실제 실행 내역을 확인하는 것이 좋아요.

실행 내역을 선택하면 워크플로우 미리보기에서 연락처가 완료한 단계와 강조 표시된 경로를 확인할 수 있어요.

## 자주 묻는 질문

**Q: 연락처는 최대 얼마나 거슬러 올라가서 추적할 수 있나요?**

연락처 이력은 최근 **60일**까지 확인할 수 있어요.

**Q: 이메일 주소나 전화번호로도 검색할 수 있나요?**

네. 이름, 이메일, 전화번호로 검색할 수 있어요.

**Q: 연락처가 어디서 대기 중인지 확인할 수 있나요?**

이력에서 대기 중인 워크플로우를 확인할 수 있어요. 워크플로우를 클릭하면 해당 연락처가 도달한 단계를 볼 수 있어요.

**Q: 정확한 실행 내역은 어떻게 열어보나요?**

연락처의 워크플로우 이력에서 해당 단계를 클릭하세요.
