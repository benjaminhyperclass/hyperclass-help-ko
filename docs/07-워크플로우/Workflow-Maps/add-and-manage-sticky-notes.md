# 워크플로우 맵에 스티커 메모 추가하고 관리하기 — Add sticky note(스티커 메모 추가)

맵 위에 메모를 놓고, 워크플로우·에셋·폴더에 연결하고, 표시 여부를 조절하는 방법을 안내해요.

## 스티커 메모는 이럴 때 써요

스티커 메모는 맵의 어느 부분이 왜 그렇게 배치되고 설정되어 있는지 설명해 줘요. 팀원이나 고객에게 배경 설명을 남길 때 사용하세요.

예를 들어 후속 안내 워크플로우 옆에 메모를 두면, 이 워크플로우가 어떤 리드 유입 경로를 위한 것인지 알려 줄 수 있어요. 변경하기 전에 먼저 확인해야 할 연결된 워크플로우를 적어 둘 수도 있어요.

## 스티커 메모 추가하기

1. **자동화 > 워크플로우 > Workflow Maps**(워크플로우 맵)를 여세요.
2. 하단 툴바에서 **Add sticky note**(스티커 메모 추가)를 누르고 색상을 고르세요.
3. 설명하려는 맵 부분 옆에 메모를 놓으세요.
4. 다음 사람이 이 부분을 이해할 수 있도록 짧은 설명을 입력하세요.

![하단 툴바의 Add sticky note에서 메모 색상을 고르거나 기존 메모를 숨길 수 있어요.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352695/original/RNgmiq7e6tF4Fu9iefslg-CHqNKy5KipWg.jpg?1793135353)

하단 툴바의 **Add sticky note**에서 메모 색상을 고르거나 기존 메모를 숨길 수 있어요.

## 메모를 항목에 연결하기

메모를 워크플로우, 에셋, 폴더에 연결하면 메모가 그 항목과 함께 유지돼요.

메모는 설명하려는 항목에 붙여 두세요. 예를 들어 인수인계 메모는 위치에만 의존하지 말고, 설명하는 워크플로우에 연결하세요.

![메모는 자동화를 설명하고, 설명 대상인 워크플로우에 연결할 수 있어요.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352674/original/9C71UUGvJzpt9uR5pD9vIyw1inq88nMQrw.jpg?1793135312)

메모는 자동화를 설명하고, 설명 대상인 워크플로우에 연결할 수 있어요.

## 메모 숨기기·표시하기

**Hide all sticky notes**(모든 스티커 메모 숨기기) / **Show all sticky notes**(모든 스티커 메모 표시)를 누르면 스티커 메모를 한꺼번에 숨기거나 표시할 수 있어요.

맵이 복잡할 때 메모를 숨기면 한눈에 살펴보기 쉬워요. 설명이 필요할 때 다시 표시하세요.

워크플로우 맵이 처음이라면 [Workflow Maps 소개](introduction-to-workflow-maps.md)도 함께 참고하세요.

## 자주 묻는 질문

### 메모는 무엇에 연결할 수 있나요?
워크플로우, 에셋, 폴더에 연결할 수 있어요.

### 모든 메모를 한 번에 숨길 수 있나요?
네. **Hide all sticky notes / Show all sticky notes**를 사용하세요.

### 스티커 메모가 자동화를 바꾸나요?
아니요. 메모는 맵에서 맥락을 알려 주는 용도예요. 워크플로우 단계는 워크플로우 빌더에서 편집하세요.
