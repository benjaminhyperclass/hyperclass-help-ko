# 스티키 노트 추가 및 관리하기

맵 위에 노트를 배치하고 워크플로우, 자산, 폴더에 연결하여 표시 여부를 관리할 수 있어요.

## 스티키 노트의 용도

스티키 노트는 맵의 특정 부분이 왜 그렇게 구성되거나 설정되었는지 설명하는 용도예요. 팀원이나 클라이언트에게 맥락을 남기고 싶을 때 사용하세요.

예를 들어, 후속 조치 워크플로우 옆에 노트를 달아두면 어떤 리드 소스를 처리하는 워크플로우인지, 또는 변경하기 전에 먼저 검토해야 할 연결된 워크플로우가 무엇인지 설명할 수 있어요.

## 스티키 노트 추가하는 방법

- **Automation(자동화) → Workflows(워크플로우) → Workflow Maps**로 이동하세요.
- 하단 툴바에 있는 **Add sticky note(스티키 노트 추가)** 컨트롤을 사용해서 색상을 선택하세요.
- 설명하려는 맵 부분 옆에 노트를 배치하세요.
- 다음 담당자가 해당 부분을 이해하는 데 도움이 될 간단한 설명을 입력하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352695/original/RNgmiq7e6tF4Fu9iefslg-CHqNKy5KipWg.jpg?1793135353)

하단 툴바에서 Add sticky note(스티키 노트 추가)를 열어 노트 색상을 선택하거나 기존 노트를 숨길 수 있어요.

## 노트를 항목에 연결하기

노트를 워크플로우, 자산, 또는 폴더에 연결하면 해당 항목과 함께 유지돼요.

노트는 설명 대상인 항목에 직접 연결하세요. 예를 들어, 인수인계 노트는 단순히 위치에만 의존하지 않고 설명 대상 워크플로우에 직접 연결하는 것이 좋아요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352674/original/9C71UUGvJzpt9uR5pD9vIyw1inq88nMQrw.jpg?1793135312)

노트는 자동화 내용을 설명하며, 설명 대상 워크플로우에 연결할 수 있어요.

## 노트 숨기기/표시하기

**Hide all sticky notes(모든 스티키 노트 숨기기) / Show all sticky notes(모든 스티키 노트 표시하기)**를 사용해서 모든 스티키 노트를 숨기거나 표시할 수 있어요.

노트를 숨기면 복잡한 맵을 좀 더 깔끔하게 확인할 수 있어요. 설명이 다시 필요할 때는 언제든 다시 표시하면 돼요.

## 자주 묻는 질문

**Q: 노트는 어떤 항목에 연결할 수 있나요?**

워크플로우, 자산, 폴더에 연결할 수 있어요.

**Q: 모든 노트를 한 번에 숨길 수 있나요?**

네, 가능해요. **Hide all sticky notes(모든 스티키 노트 숨기기) / Show all sticky notes(모든 스티키 노트 표시하기)**를 사용하세요.

**Q: 스티키 노트가 자동화 동작에 영향을 주나요?**

아니요. 노트는 맵 위에 맥락을 제공하는 용도일 뿐이에요. 워크플로우 단계 자체를 수정하려면 빌더에서 편집해야 해요.
