# Workflow Maps 탐색, 검색, 필터링하기

맵을 이동하고, 보기 방식을 전환하고, 워크플로우나 자산을 찾고, 필터로 맵을 좁혀서 보는 방법을 안내해요.

목차

- 맵 이동, 확대/축소, 전체 화면 맞추기
- 2D와 3D 전환하기
- 맵 검색하기
- 맵 필터링하기
- 맵 데이터 새로고침하기
- 워크플로우가 안 보이거나 맵이 느릴 때 문제 해결하기
- 자주 묻는 질문

## 맵 이동, 확대/축소, 전체 화면 맞추기

맵을 드래그하면 화면을 이동할 수 있어요. **+**를 누르면 확대, **−**를 누르면 축소돼요.

**Fit**을 클릭하면 전체 맵이 한눈에 보이도록 돌아와요. 특정 폴더를 둘러본 후나 현재 위치를 못 찾을 때 유용해요.

## 2D와 3D 전환하기

**2D / 3D**를 사용해서 보기 방식을 전환할 수 있어요.

- **3D**는 입체감 있는 맵을 보여줘요.
- **2D**는 위에서 내려다본 평면 뷰로, 데이터가 많은 계정이나 스크린샷을 찍을 때 더 읽기 편해요.
맵이 너무 커서 탐색하기 어려울 때는 2D를 사용해 보세요.

## 맵 검색하기

- **Search(검색)**를 열어주세요. Mac에서는 **⌘K**를 눌러도 돼요.
- 워크플로우, 자산, 또는 트리거 이름(태그명이나 폼 이름 등)을 입력하세요.
- 검색 결과를 확인하세요.
- 결과를 클릭하면 맵에서 해당 위치로 이동해요.
검색을 통해 특정 자산이 사용된 정확한 트리거, 액션, 또는 조건 분기(If/Else)를 찾을 수 있어요. 워크플로우를 하나씩 열어보지 않고도 참조 관계를 빠르게 확인할 수 있어요.

이름으로 검색한 후 결과를 선택하면 해당 위치를 찾아 세부 정보를 열 수 있어요.

## 맵 필터링하기

- 상단의 빠른 필터를 사용하면 발행된(Published) 워크플로우, 초안(Draft) 워크플로우, 또는 특정 자산 유형만 표시할 수 있어요.
- 더 많은 옵션이 필요하면 왼쪽 레일의 필터 패널을 열어주세요.
- 필요한 워크플로우나 자산에 집중할 수 있도록 필터를 조정하세요.
- 전체 맵을 다시 보고 싶으면 필터를 초기화하세요.
오류가 표시된 워크플로우만 확인하고 싶을 때는 **Has issues**를 사용하세요.


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352867/original/Yq0zOrnIBqdEdrI6BCJf_0pjS6YXaZlbTQ.jpg?1793135780)


필터(Filters) 패널을 사용해서 워크플로우 상태, 자산 유형, 폴더별로 맵을 좁혀볼 수 있어요.

## 맵 데이터 새로고침하기

**Refresh map data(맵 데이터 새로고침)**를 사용하면 맵 데이터를 다시 불러올 수 있어요. 이 버튼에는 데이터가 마지막으로 업데이트된 시점도 함께 표시돼요.

워크플로우가 보이지 않아 확인하고 있다면, 먼저 적용된 필터를 확인해 보세요.

## 워크플로우가 안 보이거나 맵이 느릴 때 문제 해결하기

**워크플로우가 보이지 않아요**

- 적용된 필터를 확인하고, 워크플로우를 가리고 있을 만한 필터를 해제하세요.
- 워크플로우 이름으로 검색해 보세요.
- 그래도 보이지 않는다면 **Give feedback(피드백 보내기)**을 이용해서 워크플로우 이름과 함께 문의해 주세요.
**연결선이 열리지 않아요**

확대한 후 선을 다시 클릭해 보세요. 가장 넓은 확대 배율에서는 선을 선택할 수 없어요.

**맵이 느리거나 로드되지 않아요**

데이터가 많은 계정은 브라우저에서 그래픽 가속 기능을 켜야 해요. 해당 설정을 확인하고, 계정 규모가 매우 크다면 **2D** 보기를 시도해 보세요.

## 자주 묻는 질문

**Q: 전체 맵으로 돌아가려면 어떻게 하나요?**

**Fit**을 클릭하세요. 워크플로우가 숨겨져 있다면 필터도 함께 확인하고 초기화해 주세요.

**Q: 조건 분기(If/Else) 안에서 사용된 자산도 검색할 수 있나요?**

네, 가능해요. 맵에는 내부 로직 단계가 노드로 표시되지 않지만, 검색을 통해서는 해당 참조를 찾을 수 있어요.

**Q: 맵 데이터가 언제 업데이트됐는지 어디서 확인할 수 있나요?**

**Refresh map data(맵 데이터 새로고침)**를 사용하면 마지막 업데이트 정보를 확인할 수 있어요.
