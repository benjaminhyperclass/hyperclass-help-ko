# 폴더 정리하고 맵 레이아웃 저장하기

워크플로우를 폴더로 옮기고, 워크플로우와 폴더 이름을 바꾸고, 폴더 색상을 바꾼 뒤 공유 레이아웃을 저장하는 방법을 안내해요.

## 정리하고 저장할 수 있는 사용자

에이전시 관리자는 항목을 옮기고 레이아웃을 저장할 수 있어요. 레이아웃을 저장하면 서브 계정의 모든 사용자에게 바뀐 레이아웃이 적용돼요.

맵에서 바꾼 구성은 **워크플로우** 목록에도 반영돼요. 워크플로우를 다른 폴더로 옮기는 것도 구성 변경에 해당하고, 이름을 바꾸면 워크플로우 이름이 바뀌어요.

## 워크플로우 옮기기

1. **자동화 > 워크플로우 > Workflow Maps**(워크플로우 맵)를 여세요.
2. 옮기려는 워크플로우를 찾으세요.
3. 워크플로우를 목적지 폴더로 끌어다 놓습니다.
4. 놓인 위치를 확인하세요.
5. 변경 내용을 유지하려면 **Save**(저장)를 클릭하세요.

## 워크플로우나 폴더 이름 바꾸기

워크플로우 또는 폴더 이름을 더블클릭한 뒤 새 이름을 입력하세요.

워크플로우나 폴더의 용도가 드러나는 이름을 쓰면 좋아요. **Save**를 클릭하기 전에 바뀐 내용을 확인하세요.

![폴더 추가 작업 메뉴에서 폴더 이름 변경 또는 폴더 색상 변경 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352863/original/uC_2_K_OpxafUFxxyDdK8fLUaUtuA51clg.jpg?1793135769)

**More folder actions**(폴더 추가 작업)를 열어 폴더 이름을 바꾸거나 **Change folder color**(폴더 색상 변경)를 선택하세요.

## 폴더 색상 바꾸기

폴더 레이블 위에 마우스를 올리고 색상을 선택하세요.

관련 있는 폴더를 같은 계열의 색으로 표시하면 구분하기 쉬워요. 레이아웃 변경 내용을 유지하려면 **Save**를 클릭하세요.

## 폴더 추가하기

1. 하단 도구 모음에서 **Add folder**(폴더 추가)를 사용하세요.
2. 폴더 이름을 입력하세요.
3. 정리하려는 워크플로우를 폴더로 끌어다 놓습니다.
4. 레이아웃을 확인하세요.
5. **Save**를 클릭하세요.

## 실행 취소, 다시 실행, 최근 변경 사항 확인

**Undo**(실행 취소)를 사용하면 레이아웃 변경을 한 단계씩 되돌릴 수 있고, **Redo**(다시 실행)를 사용하면 되돌린 변경을 다시 적용할 수 있어요.

**Recent changes**(최근 변경 사항)를 열면 레이아웃 변경 목록을 확인하고 실행 취소하거나 다시 실행할 수 있어요. 공유 레이아웃을 저장하기 전에 이 목록을 확인하세요.

## Rearrange layout(레이아웃 재정렬)으로 맵 다시 정렬하기

**Rearrange layout**은 맵을 처음부터 다시 정렬해요. 사용하기 전에 현재 레이아웃을 저장하고, 적용 중인 필터를 해제하세요.

다시 정렬한 결과를 되돌리려면 **Recent changes**에서 실행 취소하세요. 정렬 결과가 마음에 들면 **Save**를 클릭하세요.

![새 레이아웃을 적용하기 전에 재정렬 확인 창을 검토하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084353013/original/YRM-ck9VsB_ndKpWOlugft1oZgcIwgMzLw.jpg?1793136028)

새 레이아웃을 적용하기 전에 재정렬 확인 창을 살펴보세요. **Save**를 클릭하면 결과로 나온 레이아웃이 저장돼요.

## 자주 묻는 질문

### 레이아웃은 누가 저장할 수 있나요?

에이전시 관리자예요.

### 저장한 레이아웃은 나에게만 적용되나요?

아니요. 저장한 레이아웃은 서브 계정의 모든 사용자에게 적용돼요.

### 워크플로우를 옮기거나 이름을 바꾸면 워크플로우 목록에도 영향이 있나요?

네. 맵에서 바꾼 구성은 목록에도 반영돼요.

### 레이아웃 변경을 되돌릴 수 있나요?

**Undo**, **Redo**, **Recent changes**를 사용해 레이아웃 변경을 되돌리거나 다시 적용할 수 있어요.

### 맵을 정리하면 워크플로우 단계도 바뀌나요?

트리거, 액션, 로직 단계를 편집하려면 빌더에서 워크플로우를 여세요.
