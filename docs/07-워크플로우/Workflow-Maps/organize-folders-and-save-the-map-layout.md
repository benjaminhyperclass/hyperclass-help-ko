# 폴더 정리 및 맵 레이아웃 저장하기

워크플로우를 이동하고, 워크플로우와 폴더 이름을 변경하고, 폴더 색상을 바꾸고, 공유 레이아웃을 저장하는 방법을 알아봐요.

## 맵을 정리하고 저장할 수 있는 사람

**에이전시 관리자(Agency admin)**는 항목을 이동하고 레이아웃을 저장할 수 있어요. 저장하면 하위 계정(Sub-account) 내 모든 사용자에게 레이아웃이 업데이트됩니다.

맵에서 변경한 정리 작업은 워크플로우(Workflows) 목록에도 반영돼요. 워크플로우를 다른 폴더로 옮기는 것도 정리 작업에 해당하며, 이름을 바꾸면 워크플로우 이름도 함께 변경됩니다.

## 워크플로우 이동하는 방법

- **Automation(자동화) → Workflows(워크플로우) → Workflow Maps(워크플로우 맵)**로 이동하세요.
- 이동하려는 워크플로우를 찾으세요.
- 원하는 폴더로 드래그하세요.
- 배치 위치를 확인하세요.
- **Save(저장)**를 클릭해서 변경 사항을 저장하세요.

## 워크플로우나 폴더 이름 변경하기

워크플로우 또는 폴더 이름을 더블클릭한 후 새 이름을 입력하세요.

워크플로우나 폴더의 목적을 잘 설명할 수 있는 이름을 선택하는 게 좋아요. 변경 내용을 확인한 후 **Save(저장)**를 클릭하세요.


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352863/original/uC_2_K_OpxafUFxxyDdK8fLUaUtuA51clg.jpg?1793135769)


More folder actions(폴더 추가 작업)를 열면 폴더 이름을 변경하거나 Change folder color(폴더 색상 변경)를 선택할 수 있어요.

## 폴더 색상 변경하기

폴더 라벨에 마우스를 올린 후 원하는 색상을 선택하세요.

색상을 활용하면 관련된 폴더를 더 쉽게 구분할 수 있어요. 레이아웃 변경 사항을 유지하려면 **Save(저장)**를 클릭하세요.

## 폴더 추가하는 방법

- 하단 툴바의 **Add folder(폴더 추가)** 기능을 사용하세요.
- 폴더 이름을 입력하세요.
- 정리하려는 워크플로우를 폴더 안으로 드래그하세요.
- 레이아웃을 확인하세요.
- **Save(저장)**를 클릭하세요.

## 실행 취소, 다시 실행, 최근 변경 내역 확인하기

**Undo(실행 취소)**를 사용하면 레이아웃 변경 내용을 이전 단계로 되돌릴 수 있고, **Redo(다시 실행)**를 사용하면 되돌린 내용을 다시 적용할 수 있어요.

**Recent changes(최근 변경 내역)**를 열면 레이아웃 변경 목록을 확인하고 실행 취소하거나 다시 실행할 수 있어요. 공유 레이아웃을 저장하기 전에 이 목록을 꼭 확인하세요.

## Rearrange layout(레이아웃 재배치)으로 맵 재정렬하기

**Rearrange layout(레이아웃 재배치)**은 맵을 처음부터 새롭게 재배치하는 기능이에요. 이 기능을 사용하기 전에 현재 레이아웃을 저장하고 적용 중인 필터를 해제하세요.

재배치를 취소하고 싶다면 **Recent changes(최근 변경 내역)**를 사용해서 실행 취소하세요. 원하는 배치가 완성되면 **Save(저장)**를 클릭하세요.

새 레이아웃을 적용하기 전에 재배치 확인 내용을 검토하세요. 저장하면 결과 레이아웃이 유지됩니다.

## 자주 묻는 질문

**Q: 레이아웃은 누가 저장할 수 있나요?**

에이전시 관리자만 저장할 수 있어요.

**Q: 저장한 레이아웃은 저만 볼 수 있나요?**

아니요. 저장된 레이아웃은 하위 계정 내 모든 사용자에게 동일하게 적용돼요.

**Q: 워크플로우를 이동하거나 이름을 변경하면 워크플로우 목록에도 영향이 있나요?**

네. 맵에서의 정리 작업은 목록에도 함께 반영돼요.

**Q: 레이아웃 변경을 취소할 수 있나요?**

**Undo(실행 취소)**, **Redo(다시 실행)**, **Recent changes(최근 변경 내역)**를 활용해서 레이아웃 변경 내용을 조정할 수 있어요.

**Q: 맵을 정리하면 워크플로우의 단계도 변경되나요?**

트리거, 액션, 로직 단계를 수정하려면 빌더(Builder)에서 해당 워크플로우를 열어야 해요.
