# 연결된 워크플로우 확인하기

워크플로우(Workflow) 뷰를 열어서 특정 워크플로우가 다른 폴더의 워크플로우들과 어떻게 연결되어 있는지 확인할 수 있어요.

## 연결된 워크플로우가 보여주는 것

워크플로우는 다른 워크플로우와 직접 연결되거나, 공유 자산을 통해 간접적으로 연결될 수 있어요.

예를 들어, 한 워크플로우가 태그를 추가하면 그 태그가 다른 워크플로우를 시작시킬 수 있어요. 또는 액션을 통해 연락처(Contacts)를 다른 워크플로우에 추가하거나 제거할 수도 있어요.

**연결된 워크플로우(Linked workflows)** 기능은 이런 관계들을 **워크플로우 뷰(Workflow view)** 모달에 모아서 보여줘요. 폴더 간 연결까지 포함해서요.

## 연결된 워크플로우 여는 방법

- **Automation(자동화) → Workflows(워크플로우) → Workflow Maps(워크플로우 맵)**를 엽니다.
- 확인하고 싶은 워크플로우를 찾아 클릭합니다.
- 상세 패널에서 **Linked workflows(연결된 워크플로우)**를 클릭합니다.
- **Workflow view(워크플로우 뷰)** 모달에서 연결 관계를 확인합니다.

직접 연결된 워크플로우가 있는 항목을 선택한 후, 상세 패널에서 Linked workflows를 클릭하세요.

## 연결 관계 읽는 법

연결 방향을 보면 워크플로우 간의 관계를 이해할 수 있어요.

- 자산(asset)에서 워크플로우로 향하는 화살표는 트리거(Trigger) 관계를 의미해요.
- 워크플로우에서 자산으로 향하는 화살표는 해당 자산을 변경하는 액션(Action)을 의미해요.
- 워크플로우에서 워크플로우로 직접 이어지는 화살표는 연락처를 다른 워크플로우에 추가하거나 제거하는 액션을 의미해요.

공유 자산의 경우, 맵으로 돌아가서 해당 자산을 클릭하면 사용 현황을 확인할 수 있어요. 관련 워크플로우 행을 펼친 다음 **View step(단계 보기)**을 사용해서 목록에 표시된 트리거나 액션을 살펴보세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352783/original/2qwRy8Fot3WzS9K_sQkNh_wJtcQGWB4mBA.jpg?1793135631)

워크플로우 뷰에서는 연결된 워크플로우들을 함께 보여주며, 이들을 연결하는 액션도 함께 표시돼요.

## 자주 묻는 질문

**Q: 연결된 워크플로우에 다른 폴더의 워크플로우도 포함되나요?**

네. 연결된 워크플로우(Linked workflows)는 폴더 간 관계도 포함해서 보여줘요.

**Q: 연결된 워크플로우는 어디에서 열리나요?**

**워크플로우 뷰(Workflow view)**라는 제목의 모달 창에서 열려요.

**Q: 그래프가 특정 연락처의 이동 경로를 보여주나요?**

맵 왼쪽의 **Contacts(연락처)** 메뉴를 사용하면 특정 연락처의 워크플로우 이력을 확인할 수 있어요. 연결된 워크플로우 기능은 설정된 관계 자체를 설명해주는 기능이에요.
