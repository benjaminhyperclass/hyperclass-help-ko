# 워크플로우 트리거 — Opportunity Created(기회 생성됨)

**Opportunity Created**(기회 생성됨) 트리거는 새 기회가 만들어질 때 워크플로우를 시작해요. 기회가 생길 때마다 자동으로 후속 작업을 실행하고 싶을 때 사용하세요.

## 기회가 만들어지면 실행돼요

## Filters

**Filters**(필터)를 사용하면 조건에 맞는 기회가 만들어질 때만 워크플로우가 실행되도록 제한할 수 있어요.
