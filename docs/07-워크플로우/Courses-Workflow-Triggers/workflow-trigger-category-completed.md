# 워크플로우 트리거 — Category Completed(카테고리 완료)

**Category Completed**(카테고리 완료) 트리거는 연락처가 상품이나 코스의 특정 카테고리를 완료했을 때 워크플로우를 시작해요. 이 문서에서는 트리거의 쓰임새와 설정 방법, 업종별 사용 사례, 자주 묻는 질문을 안내해요.

## Category Completed 트리거란?

**Category Completed** 트리거는 연락처가 지정한 상품 또는 코스 카테고리를 완료하면 워크플로우를 시작해요. 사용자의 진행 상황을 추적하면서 완료 이메일 발송, 수료증 발급, 다음 단계 추천 같은 후속 작업을 자동으로 처리할 때 쓰면 좋아요. 필터를 함께 쓰면 원하는 카테고리를 완료했을 때만 워크플로우가 실행돼요.

## 이 트리거를 쓰면 좋은 점

- 후속 작업 자동화: 이메일 발송, 수료증 발급, 새 워크플로우 배정 같은 완료 후 작업을 자동으로 처리해요.
- 맞춤형 소통: 연락처의 완료 이력에 맞춰 추천이나 축하 메시지를 보낼 수 있어요.
- 업무 효율 향상: 카테고리 완료 여부를 직접 확인하지 않아도 되어 시간과 인력을 아낄 수 있어요.
- 재참여 유도: 코스나 상품 카테고리를 마친 뒤 알맞은 다음 단계를 안내해 계속 참여하도록 도와요.
- 필터 설정: 특정 카테고리만 골라 워크플로우를 실행할 수 있어 정확하게 대상을 정할 수 있어요.

## 트리거 설정 방법

### 1. 워크플로우 트리거 화면 열기

왼쪽 메뉴에서 **자동화 > 워크플로우**로 이동해 자동화 또는 워크플로우 설정 화면을 열어요.

![워크플로우 트리거 화면 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038559022/original/I2Ovj9gAOCOFZ5geTGg5-ZjpieCD_pQl6A.png?1734530360)

### 2. 트리거 선택하기

사용할 수 있는 트리거 목록에서 **Category Completed**(카테고리 완료)를 선택해요.

![트리거 목록에서 Category Completed 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038559211/original/1Q_wbvh5TJ5xkyO_H8YbRB3ocWZbFVUcaA.png?1734530497)

### 3. 트리거 이름 정하기

**Name**(이름) 필드에 설명이 되는 이름을 입력해요. 예를 들어 "수강 완료 트리거"나 "상품 카테고리 완료"처럼 쓸 수 있어요.

![트리거 이름 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038587203/original/DhrDcUYVkwX5ag3df9mJ5Ml-rOVlE7FBBw.png?1734569894)

### 4. 필터 설정하기

**Filters**(필터)에서 조건을 지정해 트리거 범위를 좁혀요. 예를 들어 특정 상품이나 코스 카테고리를 선택할 수 있어요.

![필터 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038587235/original/E9VB9aIBT9CwBfBIxII_5UqU385HM_03WQ.gif?1734570116)

### 5. 트리거 저장하기

설정 내용을 확인하고 저장해요. 그런 다음 워크플로우를 테스트해서 의도한 대로 동작하는지 확인하세요.

### 6. 워크플로우 게시하기

워크플로우를 활성화하면 트리거 조건이 충족될 때 자동화가 시작돼요.

## 사용 사례

### 교육 플랫폼

시나리오: 온라인 학습 플랫폼에서 코스의 첫 3개 강의를 마친 수강생에게 후속 안내를 자동으로 보내려고 해요.

트리거 설정:

- **Trigger**(트리거): **Category Completed**
  - **Name**(이름): 3개 강의 완료
  - **Filters**(필터): **Product**(상품) **Is any of**(다음 중 하나): "스프린트 코스", "마라톤 코스"
- 워크플로우 액션
  - 수강생에게 축하 이메일을 보내요.
  - 강사에게 알려 후속 안내를 할 수 있게 해요.

결과: 알맞은 시점에 맞춤형 후속 안내를 보내 수강생의 학습 경험을 높여요.

### 이커머스

시나리오: 이커머스 스토어에서 고객이 특정 상품 카테고리의 구매를 마치면 관련 상품을 추천하려고 해요.

- 트리거 설정:
  - **Trigger**: **Category Completed**
  - **Name**: 교차 판매 트리거
  - **Filters**: **Product Category**(상품 카테고리): "전자제품"
- 워크플로우 액션:
  - 구매한 상품에 어울리는 액세서리나 업그레이드 상품을 안내하는 이메일을 보내요.

결과: 고객이 함께 쓰기 좋은 상품을 살펴보도록 유도해 매출을 높여요.

## 자주 묻는 질문

### 연락처가 여러 카테고리를 한꺼번에 완료하면 어떻게 되나요?

필터를 올바르게 설정했다면 연락처가 여러 카테고리를 동시에 완료했을 때 카테고리별로 각각 워크플로우를 실행할 수 있어요.

### 한 워크플로우에서 이 트리거를 다른 트리거와 함께 쓸 수 있나요?

네, **Category Completed** 트리거는 **Task Completed**(작업 완료), **Purchase Made**(구매 완료) 같은 다른 트리거와 함께 쓸 수 있어요. 이렇게 하면 더 복잡한 워크플로우도 만들 수 있어요.

### 연락처가 같은 카테고리를 여러 번 완료하면 어떻게 되나요?

완료 조건이 충족될 때마다 트리거가 실행돼서 놓치는 완료 건이 없어요.

### 카테고리 안의 특정 상품만 대상으로 할 수 있나요?

네, 필터를 쓰면 특정 상품이나 하위 카테고리만 대상으로 좁혀서 정확하게 실행할 수 있어요.
