# 워크플로우 레시피 — Facebook 댓글 자동화

이 레시피로 워크플로우를 만들면 "댓글을 남기면 파일을 받는" 방식의 Facebook 댓글 자동화 예시를 처음부터 끝까지 볼 수 있어요.

레시피로 만든 워크플로우는 아래 순서로 동작해요.

1. 트리거: 게시물에 달린 모든 1단계 댓글(최상위 댓글)에서 실행돼요.
2. 액션: 댓글에 "DM 확인해 보세요" 또는 "관심 가져 주셔서 감사합니다. DM을 확인해 주세요."라고 답글을 달아요.
3. 액션: 댓글을 남긴 사람에게 DM으로 인터랙티브 메신저 답장을 보내요. 메시지는 "개인 재무 관리를 시작하고 싶으시다니 정말 기뻐요."이고, "웹사이트 방문하기"와 "체크리스트 받기" 버튼이 함께 들어가요.
4. 액션: 상대가 버튼을 누르면 DM에 인터랙티브 메신저 답장으로 "여기 체크리스트를 보내드려요."라고 답해요.
