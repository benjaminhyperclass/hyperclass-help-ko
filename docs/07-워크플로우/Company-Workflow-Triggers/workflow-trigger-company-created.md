# 워크플로우 트리거 — Company Created(회사 생성됨)

**Company Created**(회사 생성됨) 트리거는 CRM에 새 회사 레코드가 추가될 때마다 워크플로우를 시작해요. 직접 만들었든, 가져오기로 들어왔든, 폼·웹훅·연동으로 자동 추가됐든 상관없어요.

## 트리거 이름

Company Created

## 트리거 설명

이 트리거는 아래 경우에 실행돼요.

- 계정에 새 회사 레코드가 만들어질 때
- 지원하는 방식(직접 입력, 폼 제출, 가져오기, API, 웹훅) 중 어떤 방법으로 만들어졌든 해당될 때

이 트리거로 새 회사 온보딩, 연락처 연결, 다른 시스템으로 데이터 동기화 같은 워크플로우를 자동으로 시작할 수 있어요.

## 설정 방법

![Company Created 트리거 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055609900/original/Wbj5hmmod2uxr-2peomD6ly_OMWJym8AfQ.png?1760010716)

- 트리거 추가

  - 워크플로우 편집 화면을 열고 시작 트리거로 **Company Created**를 선택하세요.
  - 이 트리거는 워크플로우 유형이 **Company-based**(회사 기반)일 때만 쓸 수 있어요.
- 필터 추가(선택)

  - 특정 조건의 회사 생성에만 반응하도록 필터를 추가할 수 있어요. 예를 들면 다음과 같아요.

    - *업종(**Industry**)이 "부동산"을 포함(**contains**)*
    - *회사명(**Company Name**)이 "LLC"를 포함(**contains**)*
    - *담당자(**Owner**)가 비어 있지 않음(**is not empty**)*
- 트리거 저장

  - 설정을 마쳤으면 **Save Trigger**(트리거 저장)를 클릭하세요.
  - 이제 필터 조건을 만족하는 새 회사 레코드가 만들어질 때마다 워크플로우가 자동으로 시작돼요. 필터를 설정하지 않았다면 새 회사가 만들어질 때마다 시작돼요.

## 예시

#### 새 회사 온보딩 자동화

목표: 새 회사가 추가될 때마다 워크플로우를 시작해 환영 이메일 보내기

셋업

- 트리거: Company Created
- 작업:

  1. **Send Email**(이메일 보내기) – 새 회사에 CRM 가입을 환영하는 이메일을 보내요.

플로

1. 폼이나 가져오기로 CRM에 새 회사가 만들어져요.
2. 워크플로우가 자동으로 시작돼요.
3. 시스템이 환영 이메일을 보내요.
