# 워크플로우 액션 — Clear Associated Company Fields(연결된 회사 필드 지우기)

워크플로우에서 연락처에 연결된 회사 정보 중 선택한 필드의 값을 자동으로 비우는 액션이에요. 더 이상 맞지 않는 회사 정보를 정리할 때 쓰세요.

## 개요

**Clear Associated Company Fields**(연결된 회사 필드 지우기) 액션은 워크플로우에서 연락처에 연결된 회사 레코드의 필드 값을 자동으로 제거하거나 초기화해요.

태그, 주소, 커스텀 필드처럼 더 이상 해당되지 않는 회사 정보를 비울 때 사용하세요.

## 액션 이름

Clear Associated Company Fields

## 액션 설명

이 액션은 다음과 같은 경우에 사용해요.

- 연락처에 연결된 회사의 필드 중 선택한 필드를 자동으로 비우거나 초기화해요.
- 태그, 위치, 커스텀 상태처럼 오래되었거나 관련 없는 정보를 지워요.
- 연락처가 다른 회사로 옮기거나 관계가 끊겼을 때 데이터를 정확하게 유지해요.

이 액션은 지정한 필드의 기존 값만 비워요. 회사 레코드가 삭제되거나 연락처와의 연결이 끊어지지는 않아요.

필드 값을 비우지 않고 수정하려면 **Update Associated Company**(연결된 회사 업데이트) 액션을 사용하세요.

## 액션 상세 정보

### 1. 지울 필드 선택

- 연결된 회사 레코드에서 비울 필드를 하나 이상 선택하세요.
- **Industry**(업종), **Domain**(도메인), **Address**(주소) 같은 기본 필드나 CRM에서 만든 커스텀 필드를 선택할 수 있어요.

### 2. 여러 필드 선택

- 필드를 목록에 추가하면 액션 하나로 여러 필드를 한꺼번에 비울 수 있어요.
- 예: **Tags**(태그), **Address**, **Website**(웹사이트)를 동시에 비울 수 있어요.

### 3. 지우기 동작

- 워크플로우를 실행시킨 연락처에 연결된 회사에서, 선택한 필드 값을 비워요.
- 연결된 회사가 없으면 이 액션은 자동으로 건너뛰어요.

### 4. 액션 저장

1. 필드를 선택한 뒤 **Save Action**(액션 저장)을 클릭하세요.
2. 워크플로우가 실행되면 연결된 회사 레코드의 선택한 필드가 초기화(비움)돼요.

### 5. 예외 상황 및 참고 사항

- 연락처 기반 워크플로우에서만 사용할 수 있어요.
- 연락처 필드는 지울 수 없어요. 연락처에 연결된 회사 필드만 지울 수 있어요.
- 연락처에 연결된 회사가 여러 개이면 주(primary)로 연결된 회사가 대상이에요.

## 예시

### 연락처의 회사가 바뀌면 이전 회사의 태그 지우기

목표: 연락처가 다른 조직으로 옮겼을 때, 이전 회사에 남은 관련 없는 POC 정보를 지워요.

셋업

- 워크플로우 유형: 연락처 기반
- 트리거: **Contact Changed**(연락처 변경) → **Company Name**(회사명) 필드 업데이트
- 액션: **Clear Associated Company Fields**
- 지울 필드: **POC**

플로

1. 연락처가 회사명을 새 조직의 이름으로 바꿔요.
2. 워크플로우가 실행되어 이 액션이 동작해요.
3. 이전에 연결되어 있던 회사 레코드에서 **POC** 필드가 지워져요.
