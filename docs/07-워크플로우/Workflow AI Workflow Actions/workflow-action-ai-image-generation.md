# 워크플로우 액션 – AI 이미지 생성(AI Image Generation)

이 아티클에서는 워크플로우에서 AI 이미지 생성(AI Image Generation) 액션을 사용해 AI로 이미지를 만드는 방법을 설명해요. 단계별 설정 방법, 사용 가능한 모델과 옵션 안내, 생성된 이미지에 접근하는 방법, 실전 활용 사례, 그리고 자주 묻는 질문에 대한 답변을 확인하실 수 있어요.

**참고:** 이 액션은 **프리미엄 액션**이에요. 이 액션을 사용하면 실행할 때마다 추가 요금이 발생해요.

# AI 이미지 생성 액션이란?

워크플로우(Workflow)의 AI Actions(AI 액션) 항목에서 사용할 수 있는 AI 이미지 생성 액션은 자동화 안에서 바로 AI 모델을 사용해 이미지를 생성할 수 있게 해줘요. 원하는 이미지를 설명하는 텍스트 프롬프트를 입력하고, 모델과 품질 수준을 선택하면 액션이 공개적으로 접근 가능한 URL에 저장된 생성 이미지를 반환해요. 생성된 이미지는 미디어 스토리지(Media Storage)에 자동으로 저장되며, 이후 액션에서 변수로 사용할 수 있어요. 즉, 이메일에 첨부하거나 SMS(문자)로 전송하고, SNS 채널에 게시하거나 외부 시스템으로 전달할 수 있어요.

## AI 이미지 생성 액션의 주요 장점

- **다양한 AI 모델:** 원하는 품질, 스타일, 속도 요구사항에 맞는 다양한 이미지 모델 중에서 선택할 수 있어요.

- **프롬프트 개선(Prompt Enhancement):** 간단한 프롬프트를 클릭 한 번으로 더 상세하게 다듬어 눈에 띄게 좋은 결과물을 만들 수 있어요.

- **바로 사용 가능한 템플릿:** 제품 목업, SNS 게시물, 프로모션 전단지, 라이프스타일 이미지 등 자주 쓰는 형식에 맞는 미리 작성된 프롬프트로 시작할 수 있어요.

- **브랜드 일관성:** 기존에 설정한 디자인 키트(Design Kit)와 브랜드 보이스(Brand Voice)를 적용해 생성된 이미지를 브랜드에 맞게 유지할 수 있어요.

- **동적 프롬프트:** 커스텀 값(Custom Value)을 활용해 프롬프트를 구성하면 연락처, 상품, 웹훅(Webhook) 데이터마다 서로 다른 이미지를 만들 수 있어요.

- **자동 저장:** 생성된 모든 이미지는 공개 접근 가능한 URL로 미디어 스토리지에 저장되어 어디서든 바로 사용할 수 있어요.

## 액션 상세 정보

| 필드 | 설명 |
|---|---|
| **액션 이름(Action Name)** | 워크플로우 캔버스와 실행 로그에서 이 액션을 구분하기 위한 사용자 지정 이름이에요. |
| **모델(Model)** | 이미지 생성에 사용할 AI 모델이에요. 아래 모델 옵션 목록을 참고하세요. |
| **품질(Quality)** | 생성 품질 수준이에요. Auto(기본값), High(높음), Medium(보통), Low(낮음) 중 선택할 수 있어요. |
| **프롬프트(Prompt)** | 생성하려는 이미지를 설명하는 텍스트예요. 커스텀 값을 지원하므로 연락처 필드, 웹훅 데이터, 이전 액션의 결과값으로 동적 프롬프트를 만들 수 있어요. |
| **템플릿(Templates)** | 자주 쓰는 이미지 유형에 맞는 미리 작성된 프롬프트예요. 하나를 선택하면 프롬프트 필드가 자동으로 채워지고, 이후 직접 편집할 수 있어요. |
| **추가 설정(Additional Settings)** | 크기, 배경, 출력 형식, 디자인 키트, 브랜드 보이스에 대한 선택적 옵션이에요. 아래 추가 설정 섹션을 참고하세요. |

## AI 이미지 생성 액션 사용 방법

### 1단계: 액션 추가하기

- **Automation(자동화)** > **Workflows(워크플로우)** 메뉴로 이동하세요.

- 새 워크플로우를 **생성(Create)**하거나 기존 워크플로우를 **편집(Edit)**하세요.

![](https://jumpshare.com/share/sdAZAU36nE7nJWCjV65F+/Screen+Shot+2026-08-26+at+16.44.40.png)

- 워크플로우에서 **+** 아이콘을 클릭해 새 액션을 **추가**한 다음, **AI Actions(AI 액션)** 항목에서 AI 이미지 생성(AI Image Generation)을 찾아 선택하세요. 캔버스에서 쉽게 구분할 수 있도록 액션에 명확하고 이해하기 쉬운 이름을 붙여주세요.

![](https://jumpshare.com/share/IC3WjmPC4gIkKKAAp4Bu+/GIF+Recording+2026-08-26+at+16.48.31.gif)

### 2단계: 모델 선택하기

프롬프트 섹션 안에서 **생성에 사용할 AI 모델을 선택**하세요. 다음 모델을 사용할 수 있어요:

- GPT Image 2
- Gemini 3 Pro Image (Nano Banana Pro)
- Gemini 3.1 Flash Image (Nano Banana 2)
- Gemini 2.5 Flash Image (Nano Banana)

모델마다 시각적 스타일, 이미지 내 텍스트 표현, 사실감, 구도 처리 방식이 달라요. 어떤 모델을 선택해야 할지 잘 모르겠다면 같은 프롬프트를 두 모델에 적용해보고 결과물을 비교해보세요.

![](https://jumpshare.com/share/14qfCsrYTrO9GwZFtzFl+/Screen+Shot+2026-08-26+at+17.03.15.png)

### 3단계: 품질 설정하기

**품질 선택기(quality selector)**를 클릭해 품질 옵션을 여세요.

기본적으로는 **Auto**로 설정되어 있어서 시스템이 프롬프트에 적합한 수준을 알아서 선택해줘요. High(높음), Medium(보통), Low(낮음) 중에서 직접 선택할 수도 있어요.

품질이 높을수록 더 상세한 이미지가 생성되지만 생성 시간이 더 오래 걸려요.

![](https://jumpshare.com/share/n0OWm7rz6KySFe7FV0JO+/Screen+Shot+2026-08-26+at+17.07.42.png)

### 4단계: 프롬프트 작성하기

프롬프트 입력창에 **생성하고 싶은 이미지를 설명**해주세요.

주제, 스타일, 배경, 조명, 구도를 **구체적으로** 작성할수록 대체로 더 좋은 결과가 나와요. **프롬프트 필드는 커스텀 값을 지원**하므로 연락처 필드, 웹훅 데이터, 이전 액션의 결과값을 넣어 동적 프롬프트를 만들 수 있어요.

프롬프트 입력창 위에 있는 **프롬프트 개선(Enhance Prompt)** 버튼을 클릭하면 AI가 작성한 내용을 확장하고 다듬어줘요. 직접 명시하지 않았던 스타일, 조명, 구도에 대한 세부 사항을 추가해주기 때문에 대체로 눈에 띄게 더 좋은 결과물이 나와요. 저장하기 전에 개선된 프롬프트를 추가로 편집할 수도 있어요.

![](https://jumpshare.com/share/aB48kfaQ7HLajvYoSz8G+/Screen+Shot+2026-08-26+at+17.18.38.png)

### 5단계: 템플릿으로 시작하기 (선택 사항)

프롬프트를 처음부터 작성하는 대신, 프롬프트 입력창 아래에 표시되는 4가지 템플릿 중 하나로 시작할 수 있어요:

- Product Mockups(제품 목업) – 제품 촬영 및 목업 프레젠테이션
- Social Post(소셜 게시물) – SNS 피드용 크기와 스타일의 그래픽
- Promo Flyer(프로모션 전단지) – 프로모션 전단지 및 이벤트 안내
- Lifestyle(라이프스타일) – 라이프스타일 및 실제 상황 연출 이미지

템플릿을 클릭하면 해당 형식에 맞는 미리 작성된 프롬프트가 프롬프트 필드에 자동으로 채워져요. 저장하기 전에 원하는 요구사항에 맞게 조정할 수 있어요.

![](https://jumpshare.com/share/rSkmiZJFPyrLsRrtIDnu+/Screen+Shot+2026-08-26+at+17.56.38.png)

### 6단계: 추가 설정 (선택 사항)

추가 설정(Additional Settings)을 펼쳐서 출력 형식을 세부적으로 조정하고 브랜드 자산을 적용할 수 있어요.

| 설정 | 설명 |
|---|---|
| **크기(Size)** | 생성된 이미지의 가로세로 비율이에요 – Square(정사각형), Landscape(가로형), Portrait(세로형) 중 선택할 수 있어요. 각 옵션의 정확한 픽셀 크기는 선택기 아래에 표시돼요. |
| **배경(Background)** | 생성된 이미지가 투명 배경인지 불투명 배경인지 설정해요. 기본값은 Auto이며, Opaque(불투명)를 선택할 수도 있어요. 투명 배경은 로고, 제품 컷아웃, 오버레이 작업에 유용해요. |
| **출력 형식(Output Format)** | 생성된 이미지의 파일 형식이에요 – PNG, JPEG, WebP 중 선택할 수 있어요. 투명도가 필요하면 PNG, 파일 크기를 줄이려면 JPEG, 웹 최적화 전달에는 WebP를 사용하세요. |
| **디자인 키트(Design Kit)** | 계정에 설정된 디자인 키트 스타일을 적용해 생성 이미지의 방향을 잡아주며, 기존 디자인 시스템과의 일관성을 유지해줘요. |
| **브랜드 보이스(Brand Voice)** | 브랜드 보이스 정보를 적용해 생성 이미지의 방향을 잡아주며, AI에게 추가적인 브랜드 맥락을 제공해요. |

**참고:** [디자인 키트](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000003145)와 [브랜드 보이스](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000005085) 옵션은 계정에 이미 설정된 자산에서 불러와요. 아직 설정하지 않았다면 먼저 설정을 완료해야 이 항목에서 선택할 수 있어요.

![](https://jumpshare.com/share/0gvamwqao9pVyKAhpjo9+/Screen+Shot+2026-08-26+at+18.01.29.png)

### 7단계: 액션 저장하기

프롬프트와 설정을 모두 구성했다면 **액션을 저장**하세요. 워크플로우가 실행되면 생성된 이미지는 이후의 모든 액션에서 변수로 사용할 수 있게 돼요.

![](https://jumpshare.com/share/1bJv5BItQOjqmsNBUpqX+/Screen+Shot+2026-08-26+at+18.03.12.png)

## 생성된 이미지에 접근하는 방법

액션이 실행되면 생성된 이미지는 두 곳에서 확인할 수 있어요.

### 1. 이후 액션의 커스텀 값으로

AI 이미지 생성 단계 이후의 모든 액션에서 커스텀 값 선택기(custom value picker)를 열고 AI Image Generation(AI 이미지 생성) 항목으로 이동하세요. 생성된 이미지를 선택하면 다음 3가지 값을 확인할 수 있어요:

- **Image URL(이미지 URL):** 생성된 이미지의 공개 접근 가능한 URL이에요. 이 링크를 열면 이미지가 바로 표시되고, 여기서 다운로드도 할 수 있어요. 이 값을 사용해 이메일에 이미지를 첨부하거나, SMS/MMS로 전송하거나, 웹훅을 통해 외부 시스템으로 전달할 수 있어요.

- **Image File Path(이미지 파일 경로):** 생성된 이미지 파일의 저장 경로예요.

- **Image File Name(이미지 파일명):** 생성된 이미지의 파일명이에요.

![](https://jumpshare.com/share/FocsM50SM5es4RBtZSWV+/GIF+Recording+2026-08-26+at+18.06.40.gif)

### 2. 미디어 스토리지에서

생성된 모든 이미지는 **미디어 스토리지(Media Storage)에 자동으로 저장**돼요. 다른 업로드 자산과 마찬가지로 언제든지 이곳에서 찾아보고, 다운로드하고, 재사용할 수 있어요 – 워크플로우 외부에서 만든 이메일, 퍼널, 웹사이트, SNS 게시물에도 활용할 수 있어요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079283565/original/exD52h52k3LNgtI54vmGtNuRfFgI7R_MfQ.png?1787685600)

## 활용 사례

### 1. 요청이 들어올 때마다 제품 목업 생성하기

**시나리오:** 디자이너를 기다리지 않고도 빠르게 제품 목업이나 시각적 콘셉트를 만들어 고객에게 공유하고 싶으신 경우예요. 요청은 구글 시트, 폼, 파트너 플랫폼 같은 외부 시스템에서 필요한 내용에 대한 간단한 설명과 함께 들어와요.

**설정:**

- **트리거:** Inbound Webhook(인바운드 웹훅) (제품 설명 포함)

- **액션 1:** AI 이미지 생성 – Product Mockups(제품 목업) 템플릿을 사용하고, 들어온 설명을 커스텀 값으로 프롬프트에 삽입해요. 브랜드 일관성을 위해 디자인 키트를 적용하세요.

- **액션 2:** 이메일 발송 – 고객이 목업을 바로 받아볼 수 있도록 이미지 URL을 포함하세요.

### 2. 개인화된 캠페인 비주얼

**시나리오:** 캠페인에 참여한 모든 연락처에게 똑같은 스톡 이미지를 보내는 대신, 각 연락처의 관심사, 지역, 구매 이력에 맞춘 비주얼을 제공하고 싶으신 경우예요.

**설정:**

- **트리거:** 연락처 태그 추가 (예: "campaign-enrolled")

- **액션 1:** AI 이미지 생성 – 연락처의 커스텀 값을 활용해 프롬프트를 구성하여 해당 연락처의 세그먼트를 반영한 이미지를 만드세요. 톤의 일관성을 위해 브랜드 보이스를 적용하세요.

- **액션 2:** 이메일 또는 MMS 발송 – 이미지 URL을 캠페인 비주얼로 사용하세요.

### 3. 대화 중 즉시 이미지 생성하기

**시나리오:** 챗봇과 대화하던 고객이 디자인 콘셉트, 방 배치, 스타일링된 제품 사진 같은 비주얼을 요청하는 경우예요. 사람이 개입하지 않고 대화 안에서 바로 생성해 전달하고 싶으신 경우예요.

**설정:**

- **트리거:** 고객 답장(Customer Replied) / 대화 AI(Conversation AI) 핸드오프

- **액션 1:** AI 이미지 생성 – 고객 메시지 내용을 프롬프트 입력으로 사용하세요.

- **액션 2:** SMS/MMS 발송 – 같은 대화 스레드에서 고객에게 이미지 URL을 전달하세요.

**더 많은 아이디어**

- **소셜 콘텐츠 파이프라인:** 새로운 블로그, 오퍼, 공지가 게시될 때마다 게시물 그래픽을 자동으로 생성해서 콘텐츠 캘린더에 맞춰 비주얼을 계속 준비할 수 있어요.

- **프로모션 및 이벤트 전단지:** 매번 디자인을 요청하지 않고도 반복되는 프로모션, 시즌 오퍼, 지역 이벤트용 전단지를 만들 수 있어요.

- **카탈로그 및 리스팅 비주얼:** 모든 SKU를 촬영하기 어려운 상황에서 제품군 전체에 걸쳐 일관된 라이프스타일 사진이나 흰 배경 사진을 만들 수 있어요.

- **테스트용 크리에이티브 베리에이션:** 같은 캠페인 콘셉트에 대해 여러 비주얼 방향을 만들어보고, 최종 제작에 들어가기 전에 어떤 것이 더 효과적인지 테스트할 수 있어요.

- **블로그 및 아티클 이미지:** 일반 스톡 사진 대신 콘텐츠 발행 워크플로우의 일부로 브랜드에 맞는 대표 이미지를 생성할 수 있어요.

## 더 좋은 결과를 위한 팁

- 프롬프트는 구체적으로 작성하세요. 대상 이름만 쓰기보다 주제, 스타일, 배경, 조명, 분위기를 설명해주세요.

- 짧거나 대략적인 설명으로 시작할 때는 프롬프트 개선(Enhance Prompt)을 사용하세요 – 모델에게 필요한 세부 사항을 채워줘요.

- 고객에게 노출되는 콘텐츠라면 디자인 키트와 브랜드 보이스를 적용해서 결과물이 일반적인 느낌이 아니라 브랜드에 맞게 유지되도록 하세요.

- 용도에 맞게 크기를 맞추세요 – SNS 피드는 Square(정사각형), 이메일 헤더와 배너는 Landscape(가로형), 스토리와 모바일은 Portrait(세로형)이 적합해요.

- 대량으로 실행되는 워크플로우를 발행하기 전에 몇 개의 샘플 연락처로 프롬프트를 먼저 테스트해보세요.

- 잘 작동하는 프롬프트는 저장해두세요. 검증된 프롬프트 구조를 재사용하면 매번 새로 작성하는 것보다 더 일관된 결과를 얻을 수 있어요.

## 자주 묻는 질문

**Q: 생성된 이미지는 어디에 저장되나요?**

생성된 모든 이미지는 자동으로 미디어 스토리지에 저장되며 공개 접근 가능한 URL로 호스팅돼요. 이후 액션의 커스텀 값 선택기를 통해 접근하거나 미디어 스토리지에서 직접 찾아볼 수 있어요.

**Q: 어떤 모델을 선택해야 하나요?**

용도에 따라 달라져요. 모델마다 시각적 스타일, 사실감, 이미지 내 텍스트 렌더링 품질이 달라요. 확신이 서지 않는다면 워크플로우를 발행하기 전에 같은 프롬프트를 두 모델에 돌려보고 결과를 비교해보세요.

**Q: 품질(Quality) 설정은 무엇에 영향을 주나요?**

품질은 생성된 이미지의 디테일 수준을 조절해요. Auto(기본값)는 시스템이 프롬프트에 적합한 수준을 알아서 선택해줘요. High(높음)는 가장 상세한 결과물을 만들지만 생성 시간이 더 오래 걸리고, Low(낮음)는 더 빠르고 가벼워요. 고객에게 노출되는 이미지인지, 내부 초안인지에 따라 선택하시면 돼요.

**Q: 프롬프트에 동적 데이터를 사용할 수 있나요?**

네, 가능해요. 프롬프트 필드는 커스텀 값을 지원하므로 연락처 필드, 웹훅 페이로드 데이터, 이전 액션의 결과값을 삽입할 수 있어요. 이를 통해 하나의 워크플로우로 연락처마다, 또는 요청마다 서로 다른 이미지를 생성할 수 있어요.

**Q: 프롬프트 개선(Enhance Prompt)은 무엇을 하나요?**

AI를 활용해 프롬프트를 확장하고 다듬어, 직접 명시하지 않았던 스타일, 구도, 조명에 대한 세부 사항을 추가해줘요. 대체로 눈에 띄게 더 좋은 결과물을 만들어줘요. 액션을 저장하기 전에 개선된 프롬프트를 확인하고 편집할 수 있어요.

**Q: 템플릿을 꼭 사용해야 하나요?**

아니요. 템플릿은 필수가 아니라 시작점일 뿐이에요. 프롬프트를 처음부터 직접 작성하거나, 템플릿을 적용한 뒤 미리 채워진 프롬프트를 원하는 요구사항에 맞게 수정할 수도 있어요.

**Q: 투명 배경은 어떻게 만드나요?**

추가 설정(Additional Settings)을 열고 배경(Background) 옵션을 설정하세요. 기본값은 Auto이며, Opaque(불투명)를 선택할 수도 있어요. 최종 파일에서 투명도가 유지되도록 하려면 출력 형식을 PNG나 WebP로 선택하세요 – JPEG는 투명도를 지원하지 않아요.

**Q: 디자인 키트와 브랜드 보이스는 어떤 용도인가요?**

둘 다 생성 이미지가 브랜드와 잘 맞도록 AI에게 추가적인 맥락을 제공해요. 디자인 키트는 시각적 스타일을 적용하고, 브랜드 보이스는 브랜드 정보를 제공해요. 이 옵션들은 계정에 이미 설정된 자산에서 불러오는 것이라, 아직 설정하지 않았다면 먼저 설정을 완료해야 이곳에서 선택할 수 있어요.

**Q: 생성된 이미지를 외부 시스템으로 전송할 수 있나요?**

네, 가능해요. 이미지는 공개 접근 가능한 URL로 호스팅되기 때문에 이미지 URL 값을 이후의 모든 액션에 전달할 수 있어요 – 외부 플랫폼으로 전달하는 아웃바운드 웹훅도 포함돼요.
