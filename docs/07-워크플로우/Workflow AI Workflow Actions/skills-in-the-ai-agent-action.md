# AI Agent 액션의 스킬(Skills)

## 개요

스킬(Skills)은 AI Agent가 특정 상황이 필요할 때만 불러오는 재사용 가능한 절차입니다. 콜드 이메일 작성법, 문자 메시지 작성법, 리드가 긴급 상황을 알려왔을 때 대처법처럼, 모든 실행에는 적용되지 않지만 일부 실행에만 적용되는 규칙에 스킬을 사용하세요.

AI Agent 지시사항(Instructions)은 하나의 액션이 수행할 작업을 설명하며 매 실행마다 포함됩니다. 반면 스킬은 스킬 라이브러리에 저장되어 있으며, 어떤 AI Agent 액션에든 연결할 수 있고, 관련이 없을 때는 사용되지 않고 대기 상태로 남아 있습니다. 에이전트는 매 실행마다 연결된 모든 스킬의 짧은 설명을 읽고, 상황이 그 설명과 일치할 때만 해당 스킬의 전체 지시사항을 불러옵니다.

## 주요 이점

- **더 짧고 집중된 지시사항:** 상황별 규칙을 지시사항 입력란에서 빼내면 각 액션은 자신의 작업만 설명하면 됩니다.
- **한 번 작성하고 어디서나 재사용:** 스킬은 라이브러리에 저장되어 하위 계정(Sub-account) 내 어떤 AI Agent 액션에도 연결할 수 있습니다.
- **실행당 비용 절감:** 매 실행마다 스킬의 설명만 포함됩니다. 전체 지시사항은 스킬이 실제로 사용될 때만 불러와집니다.
- **바로 사용 가능:** 모든 하위 계정에는 연결, 편집, 삭제할 수 있는 기본 제공 글쓰기 스킬 4개가 포함되어 있습니다.
- **손쉬운 설정:** AI 어시스턴트로 스킬을 만들거나, 직접 작성하거나, 라이브러리에서 연결할 수 있습니다.

## 스킬 상세 항목

모든 스킬에는 세 가지 필드가 있습니다.

| 필드 | 설명 | 필수 여부 |
|---|---|---|
| **이름(Name)** | "긴급 서비스 요청"처럼 스킬을 나타내는 짧은 이름입니다. 액션과 라이브러리에 이 이름으로 표시됩니다. | 예 |
| **에이전트가 언제 이 스킬을 사용해야 하나요?** | 에이전트가 이 스킬을 사용해야 할 상황을 설명하는 한두 문장입니다. 에이전트는 매 실행마다 이 필드를 읽고 스킬을 불러올지 판단하므로, 구체적인 상황, 키워드, 조건을 명시하세요. | 예 |
| **지시사항(Instructions)** | 에이전트가 이 스킬을 사용할 때 따라야 할 절차입니다. 번호가 매겨진 단계, 판단 규칙, 절대 하면 안 되는 사항 등을 작성하세요. 에이전트는 이 스킬을 실제로 사용할 때만 이 필드를 읽습니다. | 예 |

## 기본 제공 스킬

모든 하위 계정에는 라이브러리에 **Built-in** 태그가 표시된 기본 제공 스킬 4개가 포함되어 있습니다. 이 스킬들도 다른 스킬과 동일하게 작동합니다. 즉, 어떤 AI Agent 액션에든 연결할 수 있고, 편집하거나 삭제할 수도 있습니다.

| 스킬 | 에이전트가 사용하는 시점 |
|---|---|
| **Humanizer** | 채널에 관계없이 메시지나 텍스트를 작성할 때. AI가 생성한 글의 특징적인 흔적을 제거합니다. |
| **Write-well** | 채널에 관계없이 메시지나 텍스트를 작성할 때. AI 특유의 작문 패턴을 제거하고 명확하고 간결하며 직접적인 글을 유지합니다. |
| **Cold-email** | 이전에 답장하거나 대화한 적 없는 리드에게 첫 연락 또는 후속 이메일을 보낼 때. 예: 아웃바운드, 잠재고객 발굴, 재참여 유도 |
| **Sms-writer** | 연락처(Contacts)에게 SMS(문자)를 보낼 때. 예: 리마인더, 후속 연락, 확인 문자, 윈백, 프로모션 문자 |

## 스킬 관리

- **스킬 편집:** 액션 안의 스킬 행에 마우스를 올리고 연필 아이콘을 클릭하세요. **Add existing skill**에서 스킬을 연 다음 옵션 메뉴에서 **Edit**을 선택할 수도 있습니다.
- **스킬 연결 해제:** 스킬 행에 마우스를 올리고 **X** 아이콘을 클릭하세요. 해당 액션에서만 스킬이 제거되며 라이브러리에는 그대로 남아 있습니다.
- **스킬 삭제:** **Add existing skill**에서 스킬을 연 다음 옵션 메뉴에서 **Delete**를 선택하세요. 삭제하면 라이브러리와 해당 스킬을 사용하는 모든 액션에서 제거됩니다.

**참고:** 스킬은 연결된 모든 액션에서 공유됩니다. 스킬을 편집하면 해당 변경사항이 연결된 모든 액션에 적용됩니다.

## 예시: 리드 후속 관리 에이전트

한 냉난방 업체가 견적 요청 폼을 제출한 모든 리드에게 후속 연락을 하고 싶어 합니다. 대부분의 리드는 친근한 이메일과 문자만으로 충분하지만, 가스 냄새나 난방 중단 같은 긴급 상황을 알려오는 리드도 소수 있으며, 이들에게는 다른 대응이 필요합니다.

### 설정

- **트리거(Trigger):** Form Submitted(견적 요청 폼)
- **액션 이름(Action Name):** Lead follow-up agent
- **지시사항(Instructions):** "당신은 Apex Heating and Cooling의 신규 리드를 후속 관리합니다. 방금 리드가 견적 요청 폼을 제출했습니다. 감사 인사를 전하고, 요청 내용을 다시 언급하며, 통화 일정을 제안하는 이메일 1통과 SMS 1통을 리드에게 보내세요."
- **도구(Tools):** Send email과 Send SMS. **Let AI decide all field values** 옵션을 켬.
- **스킬(Skills):** Cold-email(기본 제공), Sms-writer(기본 제공), 그리고 Emergency service requests라는 커스텀 스킬

### 커스텀 스킬

| 필드 | 값 |
|---|---|
| **이름(Name)** | Emergency service requests |
| **에이전트가 언제 이 스킬을 사용해야 하나요?** | 리드가 난방 중단, 냉방 중단, 가스 냄새, 누수를 신고하거나, 요청이 긴급하다고 말할 때 사용 |
| **지시사항(Instructions)** | 리드가 가스 냄새를 신고하면 건물에서 나가서 먼저 가스 회사에 연락하라고 안내하세요. 가스 냄새의 경우 절대 방문 예약을 잡지 마세요. 난방 중단, 냉방 중단, 누수의 경우 당일 가능한 긴급 예약 시간을 제안하세요. 첫 답변은 두 문장 이내로 짧게 유지하세요. 절대 가격을 제시하지 마세요. 비용은 기사가 현장에서 확인한다고 안내하세요. |

*도구 2개와 스킬 3개가 설정된 완성된 액션*

### 실행 시 일어나는 일

- **일반적인 견적 요청:** 에이전트가 Cold-email을 불러와 이메일을 작성하고, Sms-writer를 불러와 문자를 작성합니다. Emergency service requests는 불러오지 않습니다.
- **"어젯밤부터 난방이 안 돼요"라고 작성한 리드:** 에이전트가 Cold-email, Sms-writer와 함께 Emergency service requests를 불러와서 가격을 언급하지 않고 당일 예약 시간을 제안합니다.
- **가스 냄새를 신고한 리드:** Emergency service requests가 에이전트에게 안전 안내를 먼저 전달하고 방문 예약을 잡지 말라고 지시합니다.

## 에이전트가 스킬을 사용하는 방식

- **여러 스킬이 동시에 적용될 수 있음:** 상황이 여러 스킬과 일치하면 에이전트는 해당 스킬을 모두 불러와서 함께 따릅니다.
- **액션 지시사항이 우선:** 스킬과 액션 지시사항이 서로 상충하면 에이전트는 액션 지시사항을 따릅니다.
- **구체적인 규칙이 일반적인 규칙보다 우선:** "제목을 5단어 이내로 유지하라"처럼 구체적인 규칙은 "짧게 작성하라"처럼 일반적인 규칙보다 우선합니다.
- **"절대 하지 마세요" 규칙이 우선:** 한 스킬은 특정 행동을 하라고 하고 다른 스킬은 절대 하지 말라고 할 경우, 에이전트는 해당 행동을 하지 않습니다.

## 좋은 스킬 작성 팁

- **구체적인 트리거를 명시하세요:** "긴급 상황을 처리함"보다는 "리드가 난방 중단이나 가스 냄새를 신고할 때 사용"처럼 작성하세요. 에이전트는 이 필드만 보고 판단합니다.
- **스킬 하나당 목적 하나:** 여러 상황을 포괄하는 큰 스킬 하나보다 작은 스킬 두 개가 관리하기 쉽습니다.
- **금지 사항은 맨 마지막에:** 지시사항 끝부분에 명확한 "절대 하지 마세요" 문장을 배치하세요.
- **액션의 역할을 반복하지 마세요:** 하나의 액션이 수행할 작업은 해당 액션의 지시사항에 작성해야 합니다. 여러 액션에서 재사용하거나 때때로만 적용되는 규칙은 스킬에 작성하세요.

## 자주 묻는 질문 (FAQ)

**지시사항과 스킬의 차이는 무엇인가요?**

지시사항은 하나의 AI Agent 액션이 수행할 작업을 설명하며 매 실행마다 전송됩니다. 스킬은 라이브러리에 저장된 재사용 가능한 절차로, 여러 액션에 연결할 수 있으며 상황이 설명과 일치할 때만 불러와집니다.

**스킬은 액션이 실행될 때마다 매번 실행되나요?**

아니요. 에이전트는 매 실행마다 연결된 모든 스킬의 이름과 설명을 읽고, 상황이 그 설명과 일치할 때만 해당 스킬의 지시사항을 불러옵니다.

**두 스킬이 동시에 적용되면 어떻게 되나요?**

에이전트가 두 스킬을 모두 불러와서 함께 따릅니다. 서로 상충하면 액션 지시사항이 가장 먼저 우선하고, 그다음 더 구체적인 규칙이 우선하며, "절대 하지 마세요" 규칙이 특정 행동을 하라는 규칙보다 우선합니다.

**같은 스킬을 여러 워크플로우에서 사용할 수 있나요?**

네. 스킬은 하위 계정 라이브러리에 저장됩니다. 어떤 워크플로우의 어떤 AI Agent 액션에든 동일한 스킬을 연결할 수 있어요.

**스킬을 편집하면 어디서나 변경되나요?**

네. 스킬은 연결된 모든 액션에서 공유되므로, 편집하면 해당 변경사항이 모든 액션에 적용됩니다.

**연결 해제와 삭제의 차이는 무엇인가요?**

연결 해제는 해당 액션 하나에서만 스킬을 제거합니다. 삭제는 라이브러리와 해당 스킬을 사용하는 모든 액션에서 제거합니다.

**기본 제공 스킬을 편집하거나 삭제할 수 있나요?**

네. 기본 제공 스킬도 라이브러리의 다른 스킬과 동일하게 작동합니다.

**스킬에서 지식 베이스(Knowledge Base)를 사용할 수 있나요?**

네. 스킬 지시사항에 지식 베이스 이름을 명시하면 됩니다. 예: "보증 조건에 대해 Service policies 지식 베이스를 검색하세요." 단, 해당 액션에 **Knowledge base search** 도구가 추가되어 있어야 합니다.

**스킬이 자체적으로 메시지를 보내거나 연락처를 업데이트할 수 있나요?**

아니요. 스킬은 에이전트에게 작업 수행 방법을 알려줄 뿐입니다. 실제로 작업을 수행하려면 Send email이나 Send SMS 같은 적절한 도구가 액션에 설정되어 있어야 합니다.

**AI Agent 액션을 사용하려면 스킬이 반드시 필요한가요?**

아니요. 스킬은 선택 사항입니다. 많은 사용자가 지시사항과 도구만으로 시작한 다음, 반복되는 패턴이 생기면 나중에 스킬을 추가합니다.
