# AI 데이터 추출 액션으로 이메일 파싱하는 방법

수신 이메일에 리드 정보, 서비스 요청, 기타 중요한 내용이 정형화되지 않은 텍스트로 담겨 있는 경우, 팀에서는 그 데이터를 CRM에 수동으로 옮기느라 시간을 낭비하는 경우가 많아요. AI 데이터 추출(AI Extract Data) 액션(Action)을 사용하면 이메일 내용을 워크플로우(Workflow)에서 바로 활용할 수 있는 구조화된 값으로 변환할 수 있어요. 이 아티클에서는 하이퍼클래스 워크플로우에서 이메일 데이터를 파싱하는 방법, 후속 액션을 사용해 추출된 값을 저장하는 방법, 그리고 그 데이터를 자동화에 활용하는 방법을 안내해요.

**참고:** AI 데이터 추출은 **프리미엄** **워크플로우 액션**이며, 실행할 때마다 **추가 요금**이 부과돼요.

# **AI 데이터 추출 액션을 이용한 이메일 파싱이란?**

AI 데이터 추출을 이용한 이메일 파싱을 사용하면 하이퍼클래스가 수신 이메일 내용을 읽고 리드의 이름, 이메일 주소, 전화번호, 예산, 서비스 요청 사항 등 구체적인 정보를 추출할 수 있어요. 이를 통해 수동으로 복사하지 않고도 정형화되지 않은 이메일 텍스트를 워크플로우에서 바로 사용할 수 있는 값으로 변환할 수 있죠. 값을 추출한 후에는 후속 워크플로우 액션을 활용해 레코드를 생성 또는 업데이트하거나, 후속 조치를 트리거하거나, 팀에 알림을 보낼 수 있어요.

AI 데이터 추출은 리드 소스, 마켓플레이스, 추천, 또는 깔끔한 CRM 형식으로 정보를 보내지 않는 외부 시스템에서 오는 이메일을 처리할 때 특히 유용해요.

## AI 데이터 추출 액션으로 이메일을 파싱할 때의 주요 이점

- **더 빠른 리드 처리**: 수신 이메일에서 중요한 정보를 자동으로 캡처해서 팀이 더 빨리 후속 조치를 취할 수 있어요.

- 수작업 입력 감소: 이메일 내용에서 구조화된 값을 직접 추출해 복사/붙여넣기 작업을 줄일 수 있어요.

- 일관된 데이터 수집: 추출된 값을 연락처(Contacts) 또는 기회 관리(Opportunities) 필드에 매핑해서 더 깔끔한 레코드를 유지할 수 있어요.

- 더 나은 워크플로우 자동화: 연락처 생성, 기회 관리 생성, 알림, 이메일, 전화, SMS 등 후속 액션에서 파싱된 값을 활용할 수 있어요.

- 더 유연한 인테이크(접수) 프로세스: 폼이나 CRM 직접 입력이 아닌 이메일로 중요한 정보가 들어오는 사용 사례를 지원해요.

## **AI 데이터 추출 액션으로 이메일 데이터 파싱하는 방법**

완전한 이메일 파싱 워크플로우는 단순히 이메일에서 값을 추출하는 것 이상의 작업을 해요. 추출된 데이터를 실제로 활용하려면, 워크플로우가 연락처 생성(Create Contact), 연락처 필드 업데이트(Update Contact Field), 기회 생성(Create Opportunity)과 같은 후속 액션에서 그 값을 저장하거나 사용해야 해요.

**참고:** AI 데이터 추출 액션의 작동 방식을 더 자세히 알아보려면 [워크플로우 액션 - AI 데이터 추출](https://help.gohighlevel.com/support/solutions/articles/155000007992-workflow-action-ai-extract-data)을 참고하세요.

시작하기 전에:

- 어떤 메일함이나 이메일 흐름이 워크플로우를 트리거해야 하는지 확인하세요.

- 이메일에서 추출하고 싶은 값을 결정하세요.

- 추출된 값을 어디에 저장하거나 어떻게 사용할지 결정하세요.

- AI 데이터 추출은 프리미엄 워크플로우 액션이며, 실행할 때마다 추가 요금이 부과된다는 점을 기억하세요.

### 1단계: 새 워크플로우 생성

- **Automation(자동화)** > Workflows(워크플로우)로 이동하세요.

- **+ Create Workflow(워크플로우 생성)**를 클릭하세요.

- **Start from Scratch(처음부터 시작)**를 선택하세요.

- 원하는 대로 Standard Builder(표준 빌더) 또는 Advanced Builder(고급 빌더)를 선택하세요.

![](https://jumpshare.com/share/d2BdXJDO3sLLJUZ0ip3P+/GIF+Recording+2026-07-03+at+18.01.03.gif)

### 2단계: 이메일 트리거 추가

참고: 새로 수신된 이메일이 아니라 답장에 의존하는 사용 사례라면, 답장 채널(reply channel)을 **Email(이메일)**로 설정한 **Customer Replied(고객 답장)** 트리거를 사용할 수도 있어요.

- **+ Add New Trigger(새 트리거 추가)**를 클릭하세요.

- **Inbound Email(수신 이메일)**을 선택하세요.

- 모니터링하고 싶은 메일함이나 이메일 패턴에 맞게 트리거를 구성하세요.

- 다음과 같은 필터를 사용하세요:

  - Email Sent To Mailbox(수신 메일함)
  - Email Sent From(발신자)
  - Subject(제목)
  - Body Plain Text(본문 텍스트)
  - Has Attachments(첨부파일 여부)

- Advanced Settings(고급 설정)에서 새로운 이메일 대화(conversation)에 대해서만 워크플로우를 실행할지 여부를 선택하세요.

![](https://jumpshare.com/share/iNckpBfLhtAz9ZAIGauw+/GIF+Recording+2026-07-03+at+18.10.17.gif)

### 3단계: AI 데이터 추출 액션 추가

- 트리거 아래의 **+** 아이콘을 클릭하세요.

![](https://jumpshare.com/share/8IlHbwUlIP0TTgFXCL8x+/Screen+Shot+2026-07-03+at+18.15.37.png)

- **AI Extract Data(AI 데이터 추출)**를 검색해서 선택하세요.

![](https://jumpshare.com/share/aB21vBl6HJ4oEiXeqKxy+/Screen+Shot+2026-07-03+at+18.18.19.png)

- 워크플로우를 이해하기 쉽게 만들고 싶다면 필요에 따라 **액션 이름을 변경**하세요.

![](https://jumpshare.com/share/tO6ZKQBmL2EFF8klliig+/Screen+Shot+2026-07-03+at+19.40.27.png)

### 4단계: 추출할 이메일 콘텐츠 선택

- Extract From(추출 대상)에서 **커스텀 값 선택기(custom value picker)**를 여세요.

- **Inbound Email(수신 이메일)**로 이동하세요.

- 파싱하고 싶은 이메일 콘텐츠를 선택하세요. 일반적인 옵션은 다음과 같아요:

  - Body Plain Text(본문 텍스트)
  - Full Body Includes Reply Thread(답장 스레드를 포함한 전체 본문)
  - Subject(제목)
  - Message ID(메시지 ID)
  - **From Email(발신 이메일)**
  - **From Name(발신자 이름)**
  - **CC(참조)**
  - Date(날짜)

![](https://jumpshare.com/share/iACr6EbxL0HvDgiw1HCf+/GIF+Recording+2026-07-03+at+18.26.17.gif)

### 5단계: 추출 정확도를 높이기 위한 추가 컨텍스트(Additional Context) 입력

- Additional Context(추가 컨텍스트)를 사용해서 이 액션이 어떤 종류의 이메일을 처리해야 하는지 설명하세요.

- AI가 정확한 값을 식별하는 데 도움이 되는 세부 정보를 추가하세요.

추가 컨텍스트 예시: "Zillow나 Realtor.com 같은 플랫폼에서 오는 수신 리드 이메일입니다. 리드의 이름, 이메일, 전화번호, 예산, 관심 매물을 추출하세요. 전화번호는 일반 텍스트로 표시될 수 있습니다."

이 기능은 이메일 형식이 발신자마다 다르거나, 특정 값이 발신자에 따라 다르게 표시될 때 특히 유용해요.

- 커스텀 값을 추가할 수도 있어요.

![](https://jumpshare.com/share/3xdy5hc8PdGqWpG3i4tY+/Screen+Shot+2026-07-03+at+18.28.53.png)

### 6단계: 추출하고 싶은 데이터 정의

- 시작하는 데 도움이 되도록 다음과 같은 미리 만들어진 템플릿을 사용할 수 있어요:

  - Contact Info(연락처 정보)
  - Opportunity Info(기회 정보)
  - Order Info(주문 정보)
  - Appointment Info(예약 정보)

- 템플릿을 적용한 후에는 사용 사례에 맞게 필드를 편집하세요.

- 필요에 따라 필드를 추가, 삭제, 이름 변경하세요.

- 리드 알림 이메일의 필드 예시:

  - Lead Name(리드 이름)
  - Contact Email(연락처 이메일)
  - Contact Phone(연락처 전화번호)
  - Budget(예산)

- 나중에 저장하고 싶은 데이터와 일치하는 필드 이름을 선택하세요. 이렇게 하면 이후 매핑 작업이 더 쉽고 정확해져요.

- **Save Action(액션 저장)**을 클릭하세요.

![](https://jumpshare.com/share/FNflsiEp7iFzsPc5dqlz+/GIF+Recording+2026-07-03+at+19.43.41.gif)

### 7단계: 추출된 값을 저장하거나 사용할 후속 액션 추가

중요: AI 데이터 추출 자체는 추출된 값을 영구적으로 저장하지 않아요. 추출된 값은 후속 액션의 커스텀 값 선택기를 통해서만 워크플로우 안에서 사용할 수 있어요. AI 데이터 추출 이후에 다른 액션을 추가하지 않으면, 추출된 데이터는 연락처, 기회, 또는 어떤 다른 레코드에도 저장되지 않아요.

- 일반적인 후속 액션에는 다음이 포함돼요:

  - Create Contact(연락처 생성)
  - Update Contact Field(연락처 필드 업데이트)
  - Create Opportunity(기회 생성)
  - Create/Update Opportunity(기회 생성/업데이트)
  - Internal Notification(내부 알림)
  - Send Email/SMS(이메일/SMS 발송)

- Create Contact(연락처 생성) 또는 **Update Contact Field(연락처 필드 업데이트)**에서, 커스텀 값 선택기를 통해 각 대상 필드를 **AI Extract Data(AI 데이터 추출)**에서 나온 해당 값에 매핑하세요.

- 기회를 생성하거나 업데이트하고 싶다면, 예산, 서비스 유형, 작업 세부사항 등 관련된 추출 값을 올바른 기회 필드에 매핑하세요.

![](https://jumpshare.com/share/7musNYUnP6MkBRxNXExA+/GIF+Recording+2026-07-03+at+19.47.11.gif)

### 8단계: 필요한 후속 액션 추가

- 값이 저장된 후, 다음과 같은 추가 액션으로 워크플로우를 이어갈 수 있어요:

  - 팀원에게 내부 알림 보내기
  - 이메일이나 SMS로 후속 조치 보내기
  - 후속 조치를 위해 리드 배정하기
  - 기회 생성 또는 업데이트하기
  - 업데이트된 연락처 또는 기회 데이터를 기반으로 다른 워크플로우 트리거하기

## 활용 사례

### 부동산 리드 알림

부동산 팀은 매물 등록 플랫폼이나 추천 소스로부터 이메일로 리드 알림을 받는 경우가 많아요. 이런 이메일에는 보통 리드의 이름, 전화번호, 이메일 주소, 예산, 관심 매물 등 중요한 정보가 담겨 있지만, 정형화되지 않은 텍스트 형태로 나타날 수 있어요. AI 데이터 추출로 이런 이메일을 파싱하면 에이전트가 더 빠르게 정보를 확보하고 수동 입력을 기다리지 않고 바로 후속 조치를 시작할 수 있어요.

활용 사례 예시

- 부동산 팀이 외부 플랫폼으로부터 리드 알림 이메일을 받아요.

- 이메일이 지정된 메일함에 도착하면 워크플로우가 트리거돼요.

- AI 데이터 추출이 이메일 본문에서 리드 정보를 파싱해요.

- 후속 액션이 연락처 또는 기회를 생성해요.

- 그런 다음 워크플로우가 내부 알림을 보내서 팀원이 빠르게 후속 조치를 할 수 있게 해요.

## **자주 묻는 질문**

**Q: AI 데이터 추출이 추출된 값을 자동으로 저장하나요?**
아니요. 추출된 값은 커스텀 값 선택기를 통해 후속 워크플로우 액션에서만 사용할 수 있어요. 값을 영구적으로 저장하려면 연락처 생성, 연락처 필드 업데이트, 기회 생성 같은 다른 액션을 추가해야 해요.

Q: 이메일 파싱에는 어떤 트리거를 사용해야 하나요?
새로운 이메일이 메일함에 도착했을 때 워크플로우를 실행하려면 **Inbound Email(수신 이메일)**을 사용하세요. 이메일 답장 이벤트에서 워크플로우를 실행하려면 답장 채널을 **Email(이메일)**로 설정한 **Customer Replied(고객 답장)**를 사용하세요.

Q: Extract From(추출 대상) 필드에서는 무엇을 선택해야 하나요?
대부분의 이메일 파싱 워크플로우에서는 **Body Plain Text(본문 텍스트)** 또는 Full Body Includes Reply Thread(답장 스레드를 포함한 전체 본문) 같은 수신 이메일 값을 사용하세요. 최적의 옵션은 현재 메시지만 파싱할지, 아니면 더 긴 이메일 스레드를 파싱할지에 따라 달라져요.

Q: 왜 추가 컨텍스트를 입력해야 하나요?
추가 컨텍스트는 AI가 어떤 종류의 이메일을 파싱하고 있는지, 그리고 어떤 값이 가장 중요한지 이해하는 데 도움을 줘요. 특히 이메일 형식이 다양할 때 추출 정확도를 높일 수 있어요.

Q: 파싱된 이메일 데이터를 사용해서 기회를 생성할 수 있나요?
네. 데이터를 추출한 후, 관련 값을 사용해서 기회를 생성하거나 업데이트할 수 있어요. 많은 워크플로우에서 가장 깔끔한 방식은 먼저 연락처를 생성 또는 업데이트한 후, 기회를 생성하는 거예요.

Q: AI 데이터 추출에서 반드시 템플릿을 사용해야 하나요?
아니요. 템플릿을 사용하면 더 빠르게 시작할 수 있지만, 사용 사례에 맞게 템플릿 필드를 편집하거나 추출 필드를 직접 만들 수도 있어요.
