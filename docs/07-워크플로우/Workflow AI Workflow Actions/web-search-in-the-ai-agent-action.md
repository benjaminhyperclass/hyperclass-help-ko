# AI 에이전트(AI Agent) 액션의 웹 검색(Web Search) 기능

AI 에이전트(AI Agent) 액션의 웹 검색(Web Search)을 사용하면 워크플로우 실행 중에 에이전트가 인터넷에서 정보를 가져올 수 있어요. 이 문서에서는 웹 검색을 활성화하는 방법, 선호하는 웹사이트 URL을 사용해 에이전트를 안내하는 방법, 그리고 검색 요금 체계에 대해 설명합니다.

자동화된 워크플로우에서 더 정확하고 최신 정보를 제공하기 위해 이 기능을 어떻게 활용하는지도 함께 알아볼게요.

## **AI 에이전트 액션의 웹 검색이란 무엇인가요?**

웹 검색(Web Search)을 사용하면 하이퍼클래스 워크플로우(Workflows)의 AI 에이전트가 실행 중에 인터넷에서 정보를 가져올 수 있어요. 에이전트는 최신 정보를 조회하고, 지시사항(Instructions)에 제공된 선호 웹사이트를 참고하며, 이 정보를 활용해 작업을 완료합니다.

가격, 리베이트, 공공 프로그램처럼 자주 바뀌는 정보를 다룰 때 특히 유용해요.

웹 검색은 AI 에이전트 액션의 **내장 도구(Built-in tools)** 항목에서 사용할 수 있어요. 활성화하면 에이전트는 추가 정보가 필요할 때만 검색을 수행합니다.

---

## **웹 검색의 주요 장점**

웹 검색을 사용하면 사용자가 지시사항의 모든 세부 정보를 일일이 수동으로 업데이트하지 않아도 AI 에이전트가 관련 정보를 가져올 수 있어요.

- **최신 정보**: 업데이트된 가격, 프로그램, 공공 정보를 인터넷에서 검색합니다.
- **더 나은 응답**: 검색된 정보를 활용해 더 적절한 답변을 준비합니다.
- **선호 출처 지정**: 지시사항에 웹사이트 URL을 입력해 에이전트를 안내할 수 있습니다.
- **자동 검색**: 검색이 필요한 시점을 에이전트가 스스로 판단합니다.
- **워크플로우 연동**: 이메일 발송, SMS 발송 등의 도구와 웹 검색을 함께 사용할 수 있습니다.
- **사용량 기반 요금**: 검색이 실제로 수행될 때만 요금이 부과됩니다.

---

## **AI 에이전트 액션의 내장 도구(Built-in Tools)**

내장 도구(Built-in tools)는 수동으로 설정하는 도구와 별도로, AI 에이전트 액션 안에서 바로 제공되는 기능이에요. 내장 도구 섹션은 **도구(Tools)** 항목 아래에 표시되며 다음을 포함합니다:

- **웹 검색(Web search)**: 인터넷 검색 기능을 켜거나 끌 수 있어요.
- **정보 아이콘(i)**: 마우스를 올리면 해당 도구에 대한 설명을 볼 수 있어요.
- **왕관 아이콘**: 마우스를 올리면 프리미엄 도구의 비용을 확인할 수 있어요.

**중요**: 웹 검색은 정보를 가져올 뿐, 직접 메시지를 보내거나 CRM 레코드를 업데이트할 수는 없어요. 이런 작업을 하려면 해당 액션 도구가 별도로 필요합니다.

---

## **웹 검색 작동 방식**

웹 검색이 활성화되면, AI 에이전트는 워크플로우 실행 중 필요할 때마다 외부 정보를 가져올 수 있어요.

- 워크플로우 트리거(Trigger)가 AI 에이전트 액션을 시작시킵니다.
- 에이전트가 지시사항과 현재 보유한 정보를 평가합니다.
- 추가 정보가 필요하면 인터넷 검색을 수행합니다.
- 에이전트는 검색된 정보를 활용해 작업을 계속 진행합니다.
- 필요한 경우 설정된 도구를 사용해 액션(Action)을 실행합니다.

예를 들어, HVAC(냉난방) 업체의 에이전트는 고객에게 답변하기 전에 현재 적용 중인 히트펌프 리베이트 정보를 검색할 수 있어요.

참고: 모든 실행에서 검색이 필요한 것은 아니에요. 한 번의 실행 안에서 여러 번 검색을 수행할 수도 있습니다.

## **에이전트 지시사항에 웹사이트 URL 사용하기**

지시사항(Instructions)에 URL을 추가하면 에이전트가 공식 웹사이트나 공공 자료 같은 선호 정보 출처를 참고하도록 안내할 수 있어요.

지시사항 예시:

냉난방 회사의 신규 리드를 후속 관리하는 역할입니다. 리드가 히트펌프 리베이트에 대해 문의하면, 답변하기 전에 [https://www.energystar.gov/rebate-finder](https://www.energystar.gov/rebate-finder)를 참고하세요. 추가 정보가 필요하면 웹을 검색하세요. 리베이트 금액이나 자격 요건을 임의로 만들어내지 마세요. 정보를 확인할 수 없는 경우, 확인이 필요하다고 설명하세요.

이러한 지시사항은 에이전트에게 언제 검색해야 하는지, 어떤 출처를 참고해야 하는지, 불확실한 정보는 어떻게 처리해야 하는지를 알려줍니다.

**참고**: URL은 에이전트가 선호 출처를 참고하도록 안내할 뿐, 웹사이트 접근 가능 여부나 완전한 정보 획득을 보장하지는 않아요.

## **웹 검색 vs. 지식 베이스 검색(Search Knowledge Base)**

두 기능 모두 정보를 가져오지만, 사용하는 출처가 달라요. 차이를 이해하면 상황에 맞는 적절한 도구를 선택할 수 있습니다.

| 구분 | 웹 검색(Web Search) | 지식 베이스 검색(Search Knowledge Base) |
|---|---|---|
| 검색 대상 | 인터넷 소스 | 선택한 하이퍼클래스 지식 베이스(Knowledge Base) |
| 적합한 용도 | 수시로 바뀌는 공개 정보 | 저장된 비즈니스 정보 |
| 활성화 위치 | 내장 도구(Built-in tools) | 도구(Tools) 섹션에 추가 |
| 예시 | 현재 리베이트 정보 | 회사 정책, FAQ |

두 기능은 서로 보완적으로 사용할 수 있어요.

중요: 워크플로우 AI 에이전트의 웹 검색은 Agent Studio의 웹 검색(Search the Web) 도구와는 달라요. Agent Studio의 도구는 별도의 설정 과정이 필요합니다.

---

## **웹 검색 요금**

웹 검색은 기존 AI 에이전트 액션 비용과 별도로, 검색 건당 요금이 부과되는 프리미엄 기능이에요.

| 모델 제공사 | 검색당 비용 |
|---|---|
| OpenAI | $0.01 (1센트) |
| Claude | $0.01 (1센트) |
| Gemini | $0.014 (1.4센트) |

예시: OpenAI 모델로 3회 검색하면 웹 검색 추가 요금으로 $0.03이 부과됩니다. Gemini로 3회 검색하면 $0.042가 부과됩니다.

- 각 검색은 개별적으로 과금됩니다.
- 한 번의 실행에서 여러 번 검색하면 그만큼 요금이 누적됩니다.
- 검색이 수행되지 않은 실행에는 추가 웹 검색 요금이 발생하지 않습니다.

## **AI 에이전트 액션에서 웹 검색 설정하는 방법**

웹 검색을 활성화하면 워크플로우 실행 중 에이전트가 외부 정보를 가져올 수 있어요. 작업 완료에 필요한 명확한 지시사항과 추가 도구를 함께 설정해 주세요.

1. 하이퍼클래스 하위 계정(Sub-account)에서 **Automations(자동화) → Workflows(워크플로우)** 로 이동합니다.
2. 워크플로우를 새로 만들거나 기존 워크플로우를 열고, 적절한 트리거(Trigger)를 설정합니다.
3. **AI Agent(AI 에이전트)** 액션을 추가하거나 기존 액션을 엽니다.
4. 에이전트의 **지시사항(Instructions)** 을 입력하고 AI **모델(Model)** 을 선택합니다.
5. 도구(Tools) 섹션 아래의 **내장 도구(Built-in tools)** 를 펼칩니다.
6. **웹 검색(Web search)** 을 켭니다.
7. (선택) 지시사항에 선호 웹사이트 URL을 추가합니다.
8. (선택) 이메일 발송(Send email), SMS 발송(Send SMS) 등 추가 도구를 설정합니다.
9. **액션 저장(Save action)** 을 클릭합니다.
10. 최신 정보가 필요한 질문으로 워크플로우를 테스트합니다.

실행 후에는 **실행 로그(Execution Logs)** 에서 에이전트 활동을 확인할 수 있어요. 실행 추적, 도구 호출 내역, 입력값, 출력값, 토큰 사용량 등을 확인할 수 있습니다.

### 예시: 고객 리베이트 문의 응답하기

한 HVAC(냉난방) 업체는 AI 에이전트가 견적 요청에 후속 응대를 하고, 히트펌프 리베이트 관련 질문에 답변하기를 원합니다.

**지시사항:**

이메일과 SMS를 통해 신규 리드의 견적 요청에 감사 인사를 전하세요. 리드가 히트펌프 리베이트에 대해 문의하면 [https://www.energystar.gov/rebate-finder](https://www.energystar.gov/rebate-finder)를 참고하세요. 필요한 경우 추가 정보를 인터넷에서 검색하세요. 자격 요건이나 리베이트 금액에 대해 확인되지 않은 내용을 주장하지 마세요. 팀과 상담할 시간을 제안하세요.

도구: 이메일 발송, SMS 발송

내장 도구: 웹 검색 활성화

이렇게 설정하면 에이전트는 관련 리베이트 정보를 조회하고, 답변을 준비한 뒤, 설정된 도구를 통해 메시지를 전송할 수 있어요.

## **자주 묻는 질문**

**Q: 워크플로우가 실행될 때마다 웹 검색이 매번 실행되나요?**

아니요. 에이전트가 추가 정보가 필요하다고 판단할 때만 검색이 수행돼요.

**Q: 한 번의 실행에서 여러 웹사이트를 검색할 수 있나요?**

네, 가능해요. 여러 번 검색할 수 있으며, 각 검색은 개별적으로 과금됩니다.

**Q: 지정한 웹사이트에 접속할 수 없으면 어떻게 되나요?**

대체 동작이 보장되지는 않아요. 에이전트가 정보를 임의로 만들어내지 않도록 지시하고, 확인할 수 없는 내용은 그렇게 안내하도록 설정해 주세요.

**Q: 특정 웹사이트로만 검색을 제한할 수 있나요?**

지시사항에 선호하는 URL을 제공할 수는 있지만, 이 기능에서 엄격한 도메인 제한 기능은 문서화되어 있지 않아요.

**Q: 웹 검색으로 CRM 레코드를 업데이트하거나 메시지를 보낼 수 있나요?**

단독으로는 불가능해요. 해당 작업을 위해서는 적절한 도구가 별도로 설정되어 있어야 합니다.

**Q: 웹 검색이 지식 베이스 검색(Search Knowledge Base)을 대체할 수 있나요?**

완전히 대체하지는 않아요. 웹 검색은 외부 정보를 가져오고, 지식 베이스 검색은 저장된 비즈니스 정보를 가져옵니다.

**Q: 웹 검색 비용은 AI 에이전트 액션 비용에 포함되나요?**

아니요. 검색 요금은 해당 AI 에이전트 액션 비용과 별도로 청구됩니다.

**Q: 실행마다 검색 결과가 다르게 나오는 이유는 무엇인가요?**

웹사이트 콘텐츠, 검색 결과, 출처의 접근 가능 여부, 검색 쿼리 등이 변경될 수 있어요. 명확한 지시사항과 선호 출처를 지정하면 일관성을 높이는 데 도움이 됩니다.
