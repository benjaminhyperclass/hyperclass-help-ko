# 워크플로우 트리거 — Order Submitted(주문 제출)

**Order Submitted**(주문 제출) 트리거는 결제 링크에서 고객이 구매를 마쳤을 때 워크플로우를 자동으로 시작해요. 구매 후 처리를 자동화하고 싶을 때 쓰세요. 이 문서에서는 트리거 사용법과 정기 인보이스의 PayPal 결제 지원도 함께 안내해요.

## 결제 링크에서 쓰는 Order Submitted 트리거란?

**Order Submitted** 트리거는 **결제 링크**에서 사용할 수 있어요. 고객이 구매를 완료하면 구매 후 워크플로우가 자동으로 실행돼요.

### 이런 점이 좋아요

- 자동화: 확인 이메일, 알림 같은 구매 후 작업을 자동으로 처리해요.
- 고객 경험 개선: 결제가 끝난 뒤 바로 후속 안내를 보낼 수 있어요.
- 데이터 관리: 주문이 제출되면 관련 정보를 자동으로 업데이트해요.

### Order Submitted 트리거 사용 방법

1. **자동화 설정**으로 이동하세요.
2. **결제 링크 워크플로우**를 선택하세요.
3. **Order Submitted** 트리거를 켜세요.
4. 아래와 같은 액션을 설정하세요.
   - 확인 이메일 보내기
   - 고객 데이터 업데이트
   - 관련 팀에 알림 보내기
5. 워크플로우를 저장하고 활성화하세요.

## 정기 인보이스의 PayPal 지원

자동 결제가 켜져 있지 않다면, **정기 인보이스**의 결제 수단으로 PayPal을 제공할 수 있어요.

### 이런 점이 좋아요

- 더 다양한 결제 수단: 고객이 정기 인보이스를 PayPal로 결제할 수 있어요.
- 사용 편의성 향상: 구독형이나 반복 청구 방식으로 운영하는 비즈니스에 도움이 돼요.
- 고객 만족도 향상: 결제 수단을 더 유연하게 고를 수 있어요.

### 정기 인보이스에서 PayPal 사용 설정

1. 시스템에서 PayPal 연동이 활성화되어 있는지 확인하세요.
2. 현재 PayPal은 자동 결제를 지원하지 않아요. 자동 결제를 켠 정기 인보이스를 만들지 않도록 주의하세요. PayPal을 쓰기 위해 따로 해야 할 설정은 없어요.

이제 고객이 인보이스를 결제할 때 PayPal을 결제 수단으로 고를 수 있어요.

## 자주 묻는 질문

### Order Submitted 트리거는 어떤 용도로 쓰나요?
워크플로우에서 고객이 구매를 완료했을 때 자동 작업을 시작하는 데 써요. 일회성 상품 주문과 정기 인보이스 구독이 모두 해당돼요. 확인 이메일, 내부 알림, 업셀 흐름 같은 구매 후 과정을 간단하게 만들어 줘요.

### Order Submitted 트리거가 PayPal에서도 작동하나요?
네, 이제 정기 인보이스를 포함한 PayPal 거래도 모두 지원해요. 사용자가 PayPal 결제를 마치면 Stripe 거래와 똑같이 트리거가 실행돼요.

### 일회성 구매와 정기 구매에 모두 쓸 수 있나요?
네, 일회성 상품 구매와 정기 인보이스 설정 모두에서 작동해요. 워크플로우 설정의 필터로 두 경우를 구분할 수 있어요.

### PayPal 결제가 실패해도 트리거가 실행되나요?
아니요. **Order Submitted** 트리거는 주문 제출과 결제 확인이 **성공한 뒤에만** 실행돼요. Stripe든 PayPal이든 마찬가지예요. 결제가 실패했거나 끝나지 않았다면 트리거가 실행되지 않아요.

### PayPal 정기 결제가 이루어진 뒤 자동으로 이메일을 보낼 수 있나요?
네. 워크플로우에서 **Order Submitted** 트리거와 **Send Email**(이메일 보내기) 액션을 함께 쓰면, PayPal 정기 결제가 제출될 때마다 확인 이메일이나 온보딩 이메일을 자동으로 보낼 수 있어요. 또는 **결제 > 설정**에서 판매 영수증을 사용해도 돼요.
