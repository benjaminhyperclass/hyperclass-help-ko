# 워크플로우 Pro 요금제 — 새 요금 구간 안내

워크플로우 프리미엄 액션에 쓰는 **워크플로우 Pro** 요금제가 사용량 기준의 4개 구간으로 바뀌었어요. 이 문서에서 요금 구간, 실행 횟수와 초과 요금 계산 방식, 요금제 구매 방법을 알아보세요.

새 요금 구간은 소규모 프로젝트부터 대규모 자동화 팀까지 모든 계정이 더 낮은 금액으로 시작하고, 사용량에 맞춰 예측 가능하게 늘려 갈 수 있도록 만들었어요. 기존의 단일 Pro 요금제 대신 4개 구간이 생겼어요.

## 워크플로우 Pro 요금제란?

워크플로우 Pro 요금제는 프리미엄 워크플로우 트리거와 액션만 따로 관리하는 추가 구독이에요. 하이퍼클래스 기본 요금제(예: Agency Pro, Agency Unlimited)와 함께 쓰며, 추가 비용이 드는 실행만 처리해요.

에이전시는 워크플로우 Pro로 프리미엄 트리거와 액션을 할인된 가격에 한꺼번에 구매한 뒤, 서브 계정에 재판매하거나 나눠 줄 수 있어요. 그래서 CRM, 웹사이트 빌더, 기본 자동화 워크플로우 같은 핵심 기능은 기본 요금제에 두고, 프리미엄 워크플로우 비용은 Pro 요금제에서 한곳에 모아 관리할 수 있어요.

## 워크플로우 Pro 요금제의 장점

- 사용량에 맞는 절약: 사용량에 맞는 구간을 고르세요. 높은 구간일수록 포함된 실행 횟수가 많고 초과 요금이 낮아요.
- 간단한 재판매·마크업: 계정에서 재청구를 지원하면 프리미엄 액션 사용 비용을 서브 계정에 그대로 전달하거나 마크업을 붙여 청구할 수 있어요. 사용량 기준은 한곳에서 확인해요.
- 예측 가능한 기본 요금과 유연한 초과 요금: 월 정액 요금에 포함 실행 횟수가 들어 있어요. 포함 횟수를 넘기면 투명한 초과 요금이 자동으로 적용돼요.
- 통합 청구: 프리미엄 트리거/액션, 마켓플레이스 앱, 하이퍼클래스 앱 비용이 기본 구독과 별도로 함께 청구돼요.

## 새 요금 구간

| 요금제 | 월 가격 | 월 포함 실행 횟수 | 초과 요금 |
| --- | --- | --- | --- |
| **무료** | $0 | 평생 100회 무료 실행 | 실행당 $0.01 |
| **스타터** | 월 $10 | 10,000회 | 실행당 $0.008 |
| **성장** | 월 $25 | 30,000회 | 실행당 $0.006 |
| **스케일** | 월 $50 | 65,000회 | 실행당 $0.004 |

## 실행 횟수와 초과 요금 계산 방식

- 실행은 프리미엄 액션이 한 번 동작하는 것을 말해요. 프리미엄 트리거/액션, 마켓플레이스 앱, 하이퍼클래스 앱의 실행이 모두 포함돼요. 일반(프리미엄이 아닌) 워크플로우 단계와 외부 AI 모델 단계는 월 실행 횟수에 포함되지 않아요.
- 포함된 실행 횟수는 결제 주기에 맞춰 매달 초기화돼요.
- 월 포함 실행 횟수를 넘기면 추가 사용량은 해당 요금 구간의 초과 요금으로 청구돼요.
- **무료** 요금제(구독 없음)에서 평생 100회 실행을 모두 쓰면, 이후에는 매달 실행당 $0.01이 청구돼요. 원하면 언제든 상위 구간으로 업그레이드할 수 있어요.

## 플랜 상세

- **구독 요금제**: 에이전시는 요금 구간을 구매해 매달 쓸 수 있는 프리미엄 실행 횟수를 확보할 수 있어요.
- 유효 기간과 초기화: 실행 횟수는 결제 시점에 초기화돼요. 결제 주기 중간에 업그레이드하면 남은 실행 횟수가 다음 결제 주기까지 이어져요.
- 사용 범위: 워크플로우에서 쓰는 프리미엄 트리거, 프리미엄 액션, **마켓플레이스 앱**, 하이퍼클래스 앱에 적용돼요.
- 이월 없음: 쓰지 않은 실행 횟수는 다음 달로 넘어가지 않아요. 결제 주기 중간에 요금제를 바꿀 때만 다음 결제 주기까지 이어져요.
- 초과 사용: 포함된 횟수를 모두 쓰면 실행은 계속되고, 해당 요금제의 초과 요금이 청구돼요.
- 요금제 가입 불필요: 구독하지 않아도 무료 평생 실행 100회(서브 계정별) 이후에는 실행당 $0.01로 프리미엄 액션을 계속 쓸 수 있어요.
- 계산 단위: 무료 평생 실행 횟수는 서브 계정별로 계산돼요.

## 워크플로우 Pro 요금제 재판매하기

에이전시 관리자만 쓸 수 있어요.

1. 에이전시 계정으로 로그인하세요.
2. **재판매 > 워크플로우 Pro** 섹션으로 이동하세요.
3. 재판매 금액의 마크업 배수를 조정하세요. 이 배수는 모든 요금 구간에 똑같이 적용돼요.
4. **저장** 버튼을 클릭하세요.

![재판매 화면에서 마크업 배수를 조정하는 모습](https://jumpshare.com/share/8zezX2ibf2URYIsWerrT+/GIF+Recording+2025-09-04+at+9.05.31+PM.gif)

에이전시 관리자만 쓸 수 있어요.

1. 에이전시 계정에서 **서브 계정** 탭을 클릭하세요.
2. 해당 서브 계정을 찾아 계정 전환 버튼 옆의 점 세 개를 클릭하세요.
3. **고객 관리**를 클릭하세요.

5. **워크플로우 - 프리미엄 기능** 탭을 클릭하세요.

7. **Markup Margin**(마크업 마진)을 설정하세요.
8. **변경사항 저장** 버튼을 클릭하세요.

## 달라지는 점

- 출시 시점에는 에이전시 관리자에게만 새 요금 구간이 보여요.
- 이미 설정된 사용자 지정 배수가 없으면, 에이전시는 기본 마크업 1.2배(수익률 20%)로 시작해요.
- 현재 Pro 요금제를 쓰는 사용자는 별도 조치 없이 **스타터** 구간(월 $10)으로 자동 이동해요.

## 자주 묻는 질문

### 워크플로우 프리미엄 액션에는 어떤 요금 구간이 있나요?
**무료**, **스타터**, **성장**, **스케일** 구간이 있어요. 구간마다 포함 실행 횟수와 초과 요금이 달라요.

### 어떤 것이 실행으로 계산되고, 어떤 실행이 한도에 포함되나요?
프리미엄 액션이 한 번 동작하는 것이 실행이에요. 프리미엄 트리거/액션, 마켓플레이스 앱, 하이퍼클래스 앱의 실행이 해당돼요. 일반 워크플로우 액션과 외부 AI 모델 실행은 월 한도에 포함되지 않아요.

### 실행 횟수는 계정 기준인가요, 서브 계정 기준인가요?
서브 계정 기준이에요.

### 실행 횟수는 언제 초기화되나요?
결제 주기에 맞춰 초기화돼요. 결제 주기 중간에 요금제를 바꾸면 남은 실행 횟수가 다음 결제 주기 말까지 이어져요.
### 월 포함 횟수를 넘기면 초과 요금은 어떻게 청구되나요?
추가 실행은 해당 요금 구간의 초과 요금으로 청구돼요.

### 워크플로우가 실행 중에 한도에 도달하면 어떻게 되나요?
워크플로우는 계속 처리되고, 요금 구간에 따른 초과 요금이 적용돼요.

### 기존 워크플로우 Pro 요금제 사용자는 따로 해야 할 일이 있나요?
아니요. 현재 Pro 사용자는 **스타터** 구간(월 $10)으로 자동 이동해요.

### 출시 시점에 새 요금 구간은 누가 볼 수 있나요?
처음에는 에이전시 관리자만 볼 수 있어요. 청구를 한곳에서 관리하기 위해서예요.

### 이 요금 구간에서도 재판매와 재청구를 쓸 수 있나요?
네, 모든 요금 구간에서 재판매와 재청구를 쓸 수 있어요.
