# 워크플로우 액션 — Add Associated Records to Workflow(연관 레코드를 워크플로우에 추가)

**Add Associated Records to Workflow**(연관 레코드를 워크플로우에 추가) 액션은 트리거 오브젝트와 연관된 레코드를 다른 워크플로우에 자동으로 추가해요. 트리거가 된 레코드뿐 아니라, 그 레코드에 연결된 연락처·회사·사용자 지정 객체까지 다른 워크플로우로 보내고 싶을 때 쓰세요.

## 개요

이 액션은 연락처 기반, 회사 기반, 사용자 지정 객체 기반 등 모든 워크플로우 유형에서 쓸 수 있어요. 트리거 레코드와 연관된 레코드를 다른 워크플로우에 자동으로 추가해 줘요.

기존 **Add to Workflow**(워크플로우에 추가) 액션을 확장한 기능이에요. **Add to Workflow**는 현재 레코드(예: 연락처)만 다른 워크플로우에 추가해요. 반면 **Add Associated Records to Workflow**는 연관 라벨을 기준으로 연관 레코드(연락처, 회사, 사용자 지정 객체)를 다른 워크플로우에 등록해요.

## 액션 이름

Add Associated Records to Workflow

## 액션 설명

이 액션으로 할 수 있는 일은 다음과 같아요.

- 오브젝트 유형을 선택해요.
- 어떤 연관 레코드를 가져올지 정하는 연관 라벨을 선택해요. (회사–연락처 연관에는 적용되지 않아요.)
- 가져온 연관 레코드를 다른 워크플로우에 바로 등록해요.

이 액션은 서브 계정에 사용자 지정 객체를 만들었거나 연락처를 쓰고 있고, 트리거 레코드와 연관 레코드 사이에 연관 라벨이 있을 때만 쓸 수 있어요.

## 액션 상세 정보

![다른 워크플로우에 연관 레코드를 추가하는 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054809211/original/AsJo3DMQEwM_1N24PA3G-AYtaD1Dyxju5g.png?1759143523)

- **Select an Object**(오브젝트 선택): 추가할 레코드의 유형을 선택해요.
- **Association Label**(연관 라벨): 필수 드롭다운이에요. 어떤 연관 레코드를 포함할지 정해요.
- **Workflow**(워크플로우): 연관 레코드를 추가할 워크플로우를 선택해요.

## 예시

### 예시 1: 자동차 ↔ 딜러 (사용자 지정 객체 워크플로우)

자동차 업계 CRM에서 자동차(Cars)가 딜러(Dealers)와 연관되어 있어요. 자동차 레코드의 상태가 '판매 준비 완료'로 바뀌면, '담당 딜러' 라벨로 연관된 딜러를 모두 '딜러 알림 워크플로우'에 자동으로 추가해요.

**설정**

- **Select an Object** → Dealer
- **Association Label** → 담당 딜러
- **Workflow** → 딜러 알림 워크플로우

**작동 방식**

1. 자동차 레코드가 '판매 준비 완료'로 업데이트돼요.
2. 액션이 '담당 딜러' 라벨로 연관된 딜러를 모두 찾아요.
3. 각 딜러가 '딜러 알림 워크플로우'에 등록되어 자동 알림을 받아요.

---

### 예시 2: 연락처 ↔ 연락처 (연락처 워크플로우)

한 대학교가 학생과 보호자를 모두 연락처로 관리해요. 새 학기가 시작되면 '부모-자녀' 라벨로 연관된 부모 연락처를 모두 '새 학기 시작 알림 워크플로우'에 자동으로 추가해요.

**설정**

- **Select an Object** → Contact(부모 연락처)
- **Association Label** → 부모-자녀
- **Workflow** → 새 학기 시작 알림

**작동 방식**

1. 학기가 시작될 때 학생 연락처 레코드가 워크플로우를 트리거해요.
2. 액션이 '부모-자녀' 라벨로 연관된 부모 연락처를 모두 찾아요.
3. 해당 부모들이 '새 학기 시작 알림 워크플로우'에 등록되어 필요한 소식을 제때 받아요.

---

### 예시 3: 회사 ↔ 연락처 (회사 워크플로우)

한 마케팅 에이전시가 회사와 그에 연관된 연락처를 관리해요. 회사 레코드가 'VIP 고객 프로그램'에 추가되면, 연관된 연락처를 모두 'VIP 커뮤니케이션 워크플로우'에 자동으로 등록해요.

**설정**

- **Select an Object** → Contact
- **Workflow** → VIP 커뮤니케이션 워크플로우

**작동 방식**

1. 회사 레코드가 새 상태('VIP 고객')로 업데이트돼요.
2. 연관된 연락처가 'VIP 커뮤니케이션 워크플로우'에 등록되어 VIP 전용 소식을 받아요.
