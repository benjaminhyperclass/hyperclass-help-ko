# 워크플로우 액션 — AI Image Generation(AI 이미지 생성)

워크플로우의 **AI Image Generation**(AI 이미지 생성) 액션으로 AI 이미지를 만드는 방법을 설명해요. 설정 순서, 사용할 수 있는 모델과 옵션, 생성된 이미지를 꺼내 쓰는 방법, 활용 사례, 자주 묻는 질문을 차례로 확인할 수 있어요.

{% hint style="info" %}
이 액션은 프리미엄 액션이에요. 실행할 때마다 추가 요금이 청구돼요.
{% endhint %}

---

## AI Image Generation 액션이란?

**AI Image Generation** 액션은 워크플로우의 **AI Actions**(AI 액션)에 있어요. 자동화 안에서 바로 AI 모델로 이미지를 만들 수 있어요.

만들고 싶은 이미지를 글(프롬프트)로 설명하고, 모델과 품질을 고르면 돼요. 그러면 누구나 열어 볼 수 있는 URL에 생성된 이미지가 저장돼요.

생성된 이미지는 자동으로 **미디어 저장소**에 저장돼요. 이후 액션에서는 변수로 쓸 수 있어서, 이메일에 첨부하거나 SMS로 보내거나 소셜 채널에 올리거나 외부 시스템에 넘길 수 있어요.

---

## AI Image Generation 액션의 장점

- 여러 AI 모델: 원하는 품질, 스타일, 속도에 맞춰 다양한 이미지 모델 중에서 고를 수 있어요.
- 프롬프트 개선: 대략 쓴 프롬프트를 한 번의 클릭으로 구체적인 프롬프트로 다듬을 수 있어요. 결과물이 눈에 띄게 좋아져요.
- 바로 쓸 수 있는 템플릿: 상품 목업, 소셜 게시물, 프로모션 전단, 라이프스타일 이미지처럼 자주 쓰는 형식은 미리 써 둔 프롬프트로 시작할 수 있어요.
- 브랜드 일관성: 이미 만들어 둔 **Design Kit**(디자인 킷)과 **Brand Voice**(브랜드 보이스)를 적용해서 생성 이미지를 브랜드에 맞출 수 있어요.
- 동적 프롬프트: 커스텀 값으로 프롬프트를 만들면 연락처, 상품, 웹훅 데이터마다 다른 이미지가 만들어져요.
- 자동 저장: 생성된 이미지는 모두 누구나 열어 볼 수 있는 URL로 **미디어 저장소**에 저장돼서 어디서든 바로 쓸 수 있어요.

## 액션 상세 정보

| 항목 | 설명 |
| --- | --- |
| **Action Name**(액션 이름) | 워크플로우와 실행 로그에서 이 액션을 구분하는 이름이에요. |
| **Model**(모델) | 이미지를 만들 AI 모델이에요. |
| **Quality**(품질) | 이미지 생성 품질이에요. 선택지는 **Auto**(자동), **High**(높음), **Medium**(보통), **Low**(낮음)예요. |
| **Prompt**(프롬프트) | 만들 이미지를 글로 설명하는 칸이에요. 연락처 필드, 웹훅 데이터, 이전 워크플로우 액션의 결과를 커스텀 값으로 넣을 수 있어요. |
| **Templates**(템플릿) | 자주 쓰는 이미지 유형별로 미리 써 둔 프롬프트예요. 템플릿을 고르면 프롬프트 칸이 채워지고, 그 내용을 편집할 수 있어요. |
| **Reference images**(참조 이미지) | 프롬프트와 함께 모델에 시각적 맥락으로 전달하는 선택 이미지예요. **System upload**(시스템 업로드), **Media library**(미디어 라이브러리), **URL** 중 하나로 최대 5장까지 추가할 수 있어요. URL 칸에는 이전 액션, 웹훅 데이터, 연락처 필드의 커스텀 값을 쓸 수 있어요. |
| **Additional Settings**(추가 설정) | 크기, 배경, 출력 형식, **Design Kit**, **Brand Voice**를 정하는 선택 설정이에요. |

## AI Image Generation 액션 사용하기

### 1단계: 액션 추가

1. **자동화 > 워크플로우**로 이동해요.
2. 새 워크플로우를 만들거나 기존 워크플로우를 열어 편집해요.

   ![워크플로우 편집 화면](https://jumpshare.com/share/sdAZAU36nE7nJWCjV65F+/Screen+Shot+2026-08-26+at+16.44.40.png)
3. 워크플로우에서 **+** 아이콘을 눌러 새 액션을 추가해요. **AI Actions** 아래에서 **AI Image Generation**을 찾아 선택해요. 캔버스에서 쉽게 알아볼 수 있도록 액션 이름을 알기 쉽게 지어 주세요.

   ![AI Image Generation 액션 추가 과정](https://jumpshare.com/share/IC3WjmPC4gIkKKAAp4Bu+/GIF+Recording+2026-08-26+at+16.48.31.gif)

### 2단계: 모델 선택

프롬프트 영역에서 이미지를 만들 AI 모델을 고르세요. 사용할 수 있는 모델은 다음과 같아요.

- GPT Image 2
- GPT Image 2.5 Flare
- GPT Image 2.5 Sunburst
- Gemini 3 Pro Image (Nano Banana Pro)
- Gemini 3.1 Flash Image (Nano Banana 2)
- Gemini 2.5 Flash Image (Nano Banana)

모델마다 시각적 스타일이 다르고, 이미지 안의 글자, 사실적인 표현, 구도를 다루는 방식도 달라요. 어떤 모델이 좋을지 모르겠다면 같은 프롬프트를 두 모델에 넣어 결과를 비교해 보세요.

![모델 선택 목록](https://jumpshare.com/share/14qfCsrYTrO9GwZFtzFl+/Screen+Shot+2026-08-26+at+17.03.15.png)

### 3단계: 품질 설정

**Quality** 선택 상자를 눌러 품질 옵션을 열어요.

기본값은 **Auto**예요. 시스템이 프롬프트에 맞는 수준을 알아서 골라요. **High**, **Medium**, **Low** 중에서 직접 고를 수도 있어요.

품질이 높을수록 더 세밀한 이미지가 나오지만 생성 시간이 더 걸려요.

![품질 선택 옵션](https://jumpshare.com/share/n0OWm7rz6KySFe7FV0JO+/Screen+Shot+2026-08-26+at+17.07.42.png)

### 4단계: 프롬프트 작성

프롬프트 입력 칸에 만들고 싶은 이미지를 설명해 주세요.

피사체, 스타일, 배경 설정, 조명, 구도를 구체적으로 쓸수록 대체로 결과가 좋아요. 프롬프트 칸에는 커스텀 값을 쓸 수 있어요. 연락처 필드, 웹훅 데이터, 이전 액션의 결과를 넣어서 동적 프롬프트를 만들어 보세요.

프롬프트 입력 칸 위의 **Enhance Prompt**(프롬프트 개선) 버튼을 누르면 AI가 쓴 내용을 확장하고 다듬어 줘요. 스타일, 조명, 구도처럼 빠뜨린 부분이 보강돼서 결과가 눈에 띄게 좋아지는 경우가 많아요. 개선된 프롬프트는 저장하기 전에 더 편집할 수 있어요.

![프롬프트 입력과 프롬프트 개선 버튼](https://jumpshare.com/share/aB48kfaQ7HLajvYoSz8G+/Screen+Shot+2026-08-26+at+17.18.38.png)

### 5단계: 템플릿으로 시작 (선택)

프롬프트를 처음부터 쓰는 대신, 프롬프트 칸 아래에 있는 템플릿 네 가지 중 하나로 시작할 수 있어요.

- **Product Mockups**(상품 목업): 상품 사진과 목업 프레젠테이션용이에요.
- **Social Post**(소셜 게시물): 소셜 미디어 피드에 맞는 크기와 스타일의 그래픽이에요.
- **Promo Flyer**(프로모션 전단): 프로모션 전단과 행사 안내용이에요.
- **Lifestyle**(라이프스타일): 라이프스타일 이미지나 실제 사용 장면 이미지예요.

템플릿을 누르면 해당 형식에 맞게 미리 써 둔 프롬프트가 프롬프트 칸에 채워져요. 저장하기 전에 필요에 맞게 고쳐 쓰세요.

![템플릿 선택](https://jumpshare.com/share/rSkmiZJFPyrLsRrtIDnu+/Screen+Shot+2026-08-26+at+17.56.38.png)

### 6단계: 참조 이미지 추가 (선택)

시각적 맥락으로 이미지를 최대 5장까지 액션에 붙일 수 있어요. 이 이미지는 프롬프트와 함께 이미지 모델에 전달돼요. 배경, 피사체, 브랜드 요소를 글로만 설명하지 않고 직접 지정할 수 있어요.

GPT Image 2.5를 쓰면 참조 이미지로 새로운 배경, 스타일, 구도, 변형에서도 더 일관된 결과를 얻을 수 있어요. 모델은 원본 이미지에서 알아볼 수 있는 피사체, 조명, 질감, 고유한 특징 등을 유지할 수 있어요. 상품, 배경, 텍스트처럼 특정 요소만 바꾸고 피사체, 구도, 브랜드 표현은 그대로 두라고 GPT Image 2.5에 요청할 수도 있어요.

#### 참조 이미지 추가하기

**Reference images** 섹션은 템플릿 아래에 있어요. 세 가지 방법 중 하나를 고르세요.

| 출처 | 사용 방법 |
| --- | --- |
| **System upload** | 컴퓨터에서 이미지 파일을 바로 올려요. **Click to upload**(클릭하여 업로드)를 누르거나 파일을 끌어다 놓으면 돼요. 여러 파일을 한 번에 선택할 수 있어요. |
| **Media library** | **미디어 라이브러리**에 이미 저장된 이미지를 찾아서 선택해요. |
| **URL** | 이미지 URL을 입력하고 **Add**(추가)를 눌러요. 이 칸에는 커스텀 값을 쓸 수 있어서, 이전 액션, 웹훅 데이터, 연락처 필드에서 URL을 가져올 수 있어요. |

#### 프롬프트에서 참조 이미지 가리키기

참조 이미지는 추가한 순서대로 전달돼요. 프롬프트에서 순서로 가리킬 수 있어요. 예를 들면 “첫 번째 참조 이미지에 나온 장소”, “세 번째 참조 이미지의 로고”처럼요. 이렇게 하면 모델이 각 이미지의 역할을 짐작하지 않고 정확히 알 수 있어요.

#### 예시: 배경, 인물, 로고 합치기

이 예시에서는 참조 이미지를 세 장 추가했어요. 장소, 인물, 브랜드 로고이고, 프롬프트에서 각 이미지를 어떻게 쓸지 설명해요.

| 1. 장소 | 2. 인물 | 3. 로고 |
| --- | --- | --- |

프롬프트는 각 이미지를 순서로 가리켜요.

*“파랑과 흰색 같은 밝은 색의 예쁜 여름 원피스를 입은 여성이 첫 번째 참조 이미지에 나온 장소에 앉아 카메라를 똑바로 보며 웃고 있는 사실적인 이미지. 그 배경 안에서 여성이 선명하고 자연스럽게 담겨 있어야 해요. 세 번째 참조 이미지의 로고를 이미지의 왼쪽 아래나 오른쪽 아래 모서리에 눈에 띄게, 전체 구도와 어울리게 배치해 주세요.”*

*![참조 이미지 세 장을 추가한 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080566403/original/EpPY43gtsGvR70EHqwfwQWE_PX1NaY1Ppg.png?1789030055)*

생성된 이미지는 첫 번째 참조의 장소에 두 번째 참조의 인물을 넣고, 세 번째 참조의 로고를 모서리에 적용해요.

![생성된 결과 이미지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080566482/original/Jn550VuchligJHe74QUvOTvLcmeCmSyC6Q.png?1789030083)

### 7단계: 추가 설정 (선택)

**Additional Settings**(추가 설정)를 펼치면 출력 형식을 세부 조정하고 브랜드 자산을 적용할 수 있어요.

| 설정 | 설명 |
| --- | --- |
| **Size**(크기) | 생성할 이미지의 가로세로 비율이에요. **Square**(정사각형), **Landscape**(가로), **Portrait**(세로) 중에서 골라요. 각 옵션의 정확한 픽셀 크기는 선택 상자 아래에 표시돼요. |
| **Background**(배경) | 생성 이미지의 배경을 투명하게 할지 불투명하게 할지 정해요. 기본값은 **Auto**이고, **Opaque**(불투명)를 고를 수도 있어요. 투명 배경은 로고, 상품 누끼, 오버레이에 유용해요. |
| **Output Format**(출력 형식) | 생성 이미지의 파일 형식이에요. PNG, JPEG, WebP 중에서 골라요. 투명 배경에는 PNG, 용량이 작은 사진 파일에는 JPEG, 웹에 최적화된 전송에는 WebP를 쓰세요. |
| **Design Kit**(디자인 킷) | 계정에 있는 디자인 킷 스타일을 적용해 이미지를 만들어요. 기존 디자인 체계와 일관된 비주얼을 유지할 수 있어요. |
| **Brand Voice**(브랜드 보이스) | 브랜드 보이스 정보를 적용해 이미지를 만들어요. AI에 브랜드 맥락을 더 알려 주는 역할을 해요. |

{% hint style="info" %}
**Design Kit**과 **Brand Voice**는 계정에 이미 설정해 둔 자산을 불러와요. 아직 설정하지 않았다면 먼저 설정하세요. 그러면 여기에서 선택할 수 있어요.
{% endhint %}

### 8단계: 액션 저장

프롬프트와 설정을 모두 마쳤다면 액션을 저장하세요. 워크플로우가 실행되면 생성된 이미지를 이후의 모든 액션에서 변수로 쓸 수 있어요.

## 생성된 이미지 확인하기

액션이 실행되면 생성된 이미지를 두 곳에서 확인할 수 있어요.

### 1. 후속 액션의 커스텀 값으로 쓰기

**AI Image Generation** 단계 뒤에 오는 액션에서 커스텀 값 선택기를 열고 **AI Image Generation**으로 이동해요. 생성된 이미지를 선택하면 값이 세 가지 나와요.

- **Image URL**(이미지 URL): 생성된 이미지의 공개 URL이에요. 링크를 열면 이미지가 바로 표시되고, 거기서 내려받을 수도 있어요. 이 값으로 이메일에 이미지를 첨부하거나, SMS/MMS로 보내거나, 웹훅으로 외부 시스템에 넘길 수 있어요.
- **Image File Path**(이미지 파일 경로): 생성된 이미지 파일의 저장 경로예요.
- **Image File Name**(이미지 파일 이름): 생성된 이미지 파일의 이름이에요.

![커스텀 값 선택기에서 생성 이미지 값 고르기](https://jumpshare.com/share/FocsM50SM5es4RBtZSWV+/GIF+Recording+2026-08-26+at+18.06.40.gif)

### 2. 미디어 저장소에서 확인하기

생성된 이미지는 모두 **미디어 저장소**에 자동으로 저장돼요. 직접 올린 다른 파일처럼 언제든 이곳에서 찾아보고 내려받고 다시 쓸 수 있어요. 워크플로우 밖에서 만드는 이메일, 퍼널, 웹사이트, 소셜 게시물에도 쓸 수 있어요.

## 사용 사례

### 1. 들어온 요청으로 상품 목업 만들기

시나리오: 디자이너를 기다리지 않고 고객에게 보여 줄 상품 목업이나 비주얼 콘셉트를 빠르게 만들고 싶어요. 요청은 Google Sheet, 폼, 파트너 플랫폼 같은 외부 시스템에서 필요한 내용을 짧게 적어 들어와요.

구성:

- 트리거: **Inbound Webhook**(인바운드 웹훅) — 상품 설명을 함께 받아요.
- 액션 1: **AI Image Generation** — **Product Mockups** 템플릿을 쓰고, 들어온 설명을 커스텀 값으로 프롬프트에 넣어요. 브랜드 일관성을 위해 **Design Kit**을 적용해요.
- 액션 2: **Send Email**(이메일 보내기) — **Image URL**을 넣어서 고객이 목업을 바로 받게 해요.

### 2. 개인화된 캠페인 비주얼

시나리오: 모든 사람에게 똑같은 스톡 이미지를 보내지 않고, 캠페인에 참여한 연락처마다 관심사, 지역, 구매 이력에 맞는 비주얼을 보내고 싶어요.

구성:

- 트리거: **Contact Tag Added**(연락처 태그 추가됨) — 예: “campaign-enrolled”
- 액션 1: **AI Image Generation** — 연락처 커스텀 값으로 프롬프트를 만들어서 그 연락처의 세그먼트에 맞는 이미지를 만들어요. 톤을 일관되게 하려면 **Brand Voice**를 적용해요.
- 액션 2: **Send Email**(이메일 보내기) 또는 MMS 보내기 — **Image URL**을 캠페인 비주얼로 써요.

### 3. 대화 중 요청에 맞춰 이미지 만들기

시나리오: 봇과 대화하던 고객이 디자인 콘셉트, 방 배치, 스타일링한 상품 컷 같은 이미지를 요청해요. 사람이 개입하지 않고 이미지를 만들어 대화로 바로 돌려주고 싶어요.

구성:

- 트리거: **Customer Replied**(고객 답장) / 대화 AI 인계
- 액션 1: **AI Image Generation** — 고객 메시지 내용을 프롬프트 입력으로 써요.
- 액션 2: **Send SMS/MMS**(SMS/MMS 보내기) — 같은 대화 스레드에서 **Image URL**을 고객에게 돌려줘요.

#### 더 많은 활용 아이디어

- 소셜 콘텐츠 파이프라인: 새 블로그, 오퍼, 공지가 게시될 때마다 게시물용 그래픽을 자동으로 만들어서 비주얼이 콘텐츠 일정에 맞춰 나오게 해요.
- 프로모션 및 행사 전단: 정기 프로모션, 시즌 오퍼, 지역 행사 전단을 매번 디자인을 요청하지 않고 만들어요.
- 카탈로그 및 리스팅 비주얼: 상품군 전체에 일관된 라이프스타일 컷이나 흰 배경 컷을 만들어요. 모든 SKU를 일일이 촬영하기 어려울 때 유용해요.
- 테스트용 크리에이티브 변형: 같은 캠페인 콘셉트로 여러 비주얼 방향을 만들고, 최종 제작 전에 어느 쪽 성과가 좋은지 테스트해요.
- 블로그 및 아티클 이미지: 콘텐츠 게시 워크플로우의 일부로 브랜드에 맞는 대표 이미지를 만들어서 일반 스톡 사진을 대신해요.

## 더 좋은 결과를 얻는 팁

- 프롬프트를 구체적으로 쓰세요. 사물 이름만 쓰지 말고 피사체, 스타일, 배경, 조명, 분위기를 설명하세요.
- 짧거나 대략적인 설명으로 시작할 때는 **Enhance Prompt**를 쓰세요. 모델에 필요한 세부 내용을 채워 줘요.
- 고객에게 보이는 이미지라면 **Design Kit**과 **Brand Voice**를 적용하세요. 결과물이 평범하지 않고 브랜드에 맞게 나와요.
- **Size**는 쓰임새에 맞추세요. 소셜 피드에는 **Square**, 이메일 헤더와 배너에는 **Landscape**, 스토리와 모바일에는 **Portrait**가 좋아요.
- 대량으로 실행될 워크플로우를 게시하기 전에 샘플 연락처 몇 명으로 프롬프트를 먼저 테스트하세요.
- 결과가 좋았던 프롬프트는 저장해 두세요. 검증된 프롬프트 구조를 재사용하면 매번 새로 쓰는 것보다 결과가 일정해요.

## 가격

이미지 생성은 실행할 때마다 요금이 청구돼요. 아래 금액은 이미지 한 장을 만들 때 보통 드는 비용을 가늠할 수 있게 한 것이에요. 대부분의 생성은 이 범위 안에 들어와요.

{% hint style="info" %}
이 금액은 고정 요금이 아니라 계획용 추정치로 봐 주세요.
{% endhint %}

| 구분 | 이미지당 비용 | 센트 |
| --- | --- | --- |
| 중앙값 | $0.0388 | 3.88¢ |
| 평균 | $0.0499 | 4.99¢ |

실제 이미지당 비용은 액션을 어떻게 설정하느냐에 따라 달라져요. 주요 요인은 다음과 같아요.

- **Model**: 선택한 AI 모델
- **Quality**: 설정한 품질 수준(**Auto**, **High**, **Medium**, **Low**)
- **Size**: 생성하는 이미지 크기
- 추가 컨텍스트: **Design Kit**이나 **Brand Voice**를 적용하면 모델에 추가 컨텍스트가 전달돼서 비용이 달라질 수 있어요.

## 자주 묻는 질문

### 이미지를 한 장 만드는 데 비용이 얼마나 드나요?

이미지 한 장을 만드는 비용은 보통 $0.0388(3.88¢)에서 $0.0499(4.99¢) 사이예요. 실제 비용은 선택한 모델, 품질 수준, 이미지 크기, 그리고 **Design Kit**이나 **Brand Voice**를 적용했는지에 따라 달라져요. 자세한 내용은 위의 가격 섹션을 참고하세요.

### 생성된 이미지는 어디에 저장되나요?

생성된 이미지는 모두 **미디어 저장소**에 자동으로 저장되고, 누구나 열어 볼 수 있는 URL에 올라가요. 후속 액션의 커스텀 값 선택기에서 가져오거나, **미디어 저장소**에서 직접 찾아볼 수 있어요.

### 어떤 모델을 골라야 하나요?

크리에이터·소셜 콘텐츠, 상품 비주얼, 비주얼 검색, 빠른 프로토타입, 대량 생성에는 GPT Image 2.5 Flare를 쓰세요. 프리미엄 캠페인 크리에이티브나 다듬어진 상품 이미지처럼 편집 전반을 더 세밀하게 제어해야 할 때는 GPT Image 2.5 Sunburst를 쓰세요.

다른 모델도 각기 다른 시각적 요구에 맞게 쓸 수 있어요. 잘 모르겠다면 같은 프롬프트를 여러 모델에 돌려 보고, 결과를 비교한 뒤 워크플로우를 게시하세요.

### Quality 설정은 무엇에 영향을 주나요?

**Quality**는 생성 이미지의 세밀함을 조절해요. 기본값인 **Auto**는 시스템이 프롬프트에 맞는 수준을 골라요. **High**는 가장 세밀한 결과가 나오지만 생성 시간이 더 걸려요. **Low**는 더 빠르고 가벼워요. 고객에게 보이는 이미지인지, 내부용 초안인지에 따라 고르세요.

### 프롬프트에 동적 데이터를 쓸 수 있나요?

네, 쓸 수 있어요. 프롬프트 칸은 커스텀 값을 지원해서 연락처 필드, 웹훅 데이터, 이전 액션의 결과를 넣을 수 있어요. 그래서 워크플로우 하나로 연락처마다, 또는 들어오는 요청마다 다른 이미지를 만들 수 있어요.

### Enhance Prompt는 어떤 기능인가요?

AI로 프롬프트를 확장하고 다듬어 주는 기능이에요. 스타일, 구도, 조명처럼 빠뜨렸을 만한 세부 내용을 보강해서 결과가 눈에 띄게 좋아지는 경우가 많아요. 액션을 저장하기 전에 개선된 프롬프트를 확인하고 편집할 수 있어요.

### 템플릿을 꼭 써야 하나요?

아니요. 템플릿은 시작점일 뿐 필수가 아니에요. 프롬프트를 처음부터 직접 써도 되고, 템플릿을 적용한 뒤 채워진 프롬프트를 원하는 대로 고쳐도 돼요.

### 투명 배경은 어떻게 만들 수 있나요?

**Additional Settings**를 열고 **Background** 옵션을 설정하세요. 기본값은 **Auto**이고 **Opaque**를 고를 수도 있어요. 최종 파일에서 투명도를 유지하려면 출력 형식을 PNG나 WebP로 고르세요. JPEG는 투명도를 지원하지 않아요.

### Design Kit과 Brand Voice는 어디에 쓰나요?

둘 다 AI에 추가 컨텍스트를 줘서 생성 이미지를 브랜드에 맞게 해 줘요. **Design Kit**은 시각적 스타일을, **Brand Voice**는 브랜드 정보를 전달해요. 계정에 이미 설정해 둔 자산을 불러오는 방식이라, 아직 설정하지 않았다면 먼저 설정하세요. 그러면 여기에서 선택할 수 있어요.

### 생성된 이미지를 외부 시스템으로 보낼 수 있나요?

네, 보낼 수 있어요. 이미지가 누구나 열어 볼 수 있는 URL에 올라가 있으니, **Image URL** 값을 어떤 후속 액션에도 넘길 수 있어요. 외부 플랫폼으로 전달하는 아웃바운드 웹훅도 포함돼요.
