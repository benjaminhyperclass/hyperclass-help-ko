# 워크플로우 액션 — AI Agent(AI 에이전트)의 Skills(스킬)

**AI Agent**(AI 에이전트) 액션에 스킬을 붙이면, 특정 상황에서만 필요한 규칙을 따로 관리할 수 있어요. 이 문서에서는 스킬을 만들고 붙이고 관리하는 방법을 알려 드려요.

## 스킬이란

스킬은 AI 에이전트가 필요한 상황에서만 불러와 쓰는, 재사용할 수 있는 절차예요. 콜드 이메일 쓰는 법, 문자 메시지 쓰는 법, 리드가 긴급 상황을 알려 왔을 때 대처하는 법처럼 매번은 아니고 일부 실행에만 해당하는 규칙에 쓰면 좋아요.

**Instructions**(안내)는 액션 하나가 맡은 일을 설명하는 글이고, 모든 실행에 들어가요. 스킬은 스킬 라이브러리에 저장해 두고 어떤 AI Agent 액션에든 붙일 수 있어요. 해당 상황이 아니면 에이전트가 쓰지 않아요. 에이전트는 실행할 때마다 붙어 있는 모든 스킬의 짧은 설명을 읽고, 상황이 그 설명과 맞을 때만 해당 스킬의 전체 지침을 불러와요.

## 이럴 때 좋아요

- **Instructions**가 짧고 분명해져요. 상황별 규칙을 **Instructions** 입력란에서 빼면, 액션에는 자기 일에 대한 설명만 남아요.
- 한 번 쓰면 어디서든 다시 쓸 수 있어요. 스킬은 라이브러리에 저장되고, 서브 계정의 모든 AI Agent 액션에 붙일 수 있어요.
- 실행당 비용이 줄어요. 매 실행에는 스킬 설명만 들어가고, 전체 지침은 스킬을 쓸 때만 불러와요.
- 바로 쓸 수 있는 스킬이 있어요. 모든 서브 계정에 글쓰기용 **Built-in**(내장) 스킬 4개가 들어 있어요. 붙이거나 편집하거나 삭제할 수 있어요.
- 설정이 쉬워요. **AI Assistant**(AI 어시스턴트)로 만들거나, 직접 쓰거나, 라이브러리에 있는 스킬을 붙이면 돼요.

## 스킬 구성 항목

스킬에는 세 가지 항목이 있어요.

| 항목 | 설명 | 필수 여부 |
| --- | --- | --- |
| **Name**(이름) | 스킬의 짧은 이름이에요. 예: "Emergency service requests". 액션과 라이브러리에 이 이름으로 표시돼요. | 필수 |
| **When should the agent use this?**(에이전트는 언제 이 스킬을 사용하나요?) | 에이전트가 이 스킬을 써야 하는 때를 한두 문장으로 적어요. 에이전트는 실행할 때마다 이 항목을 읽고 스킬을 불러올지 정해요. 구체적인 상황, 키워드, 조건을 넣어 주세요. | 필수 |
| **Instructions**(안내) | 에이전트가 스킬을 쓸 때 따르는 절차예요. 번호를 붙인 단계, 판단 기준, 에이전트가 절대 하면 안 되는 일을 적어요. 에이전트는 스킬을 쓸 때만 이 항목을 읽어요. | 필수 |

## 내장 스킬

모든 서브 계정에는 내장 스킬 4개가 있어요. 라이브러리에서 **Built-in** 태그로 구분할 수 있어요. 다른 스킬과 똑같이 어떤 AI Agent 액션에든 붙일 수 있고, 편집하거나 삭제할 수도 있어요.

| 스킬 | 에이전트가 쓰는 때 |
| --- | --- |
| Humanizer | 채널에 상관없이 메시지나 글을 쓸 때 써요. AI가 쓴 글에서 흔히 보이는 티를 없애 줘요. |
| Write-well | 채널에 상관없이 메시지나 글을 쓸 때 써요. AI 특유의 글쓰기 패턴을 없애고, 글을 명확하고 간단하고 직접적으로 유지해요. |
| Cold-email | 답장이나 대화가 아직 없는 리드에게 첫 이메일이나 후속 이메일을 보낼 때 써요. 아웃리치, 잠재고객 발굴, 재참여 유도 같은 경우예요. |
| Sms-writer | 연락처에게 SMS를 보낼 때 써요. 리마인더, 후속 연락, 확인 메시지, 재방문 유도, 프로모션 문자 같은 경우예요. |

## 스킬 추가하기

1. 워크플로우를 열고 **AI Agent** 액션을 추가하거나 선택하세요.
2. 액션 패널을 아래로 스크롤해 **Skills**(스킬) 섹션을 펼치세요.
3. **+ Add skill**(스킬 추가)을 클릭하세요. 액션에 이미 스킬이 있으면 Skills 제목 옆의 **+ Add**(추가)를 클릭하세요.
4. 아래 세 가지 방법 중 하나를 고르세요.

### 방법 1: Create with AI(AI로 만들기)

왼쪽에 **AI Assistant**가 열리고, 스킬이 무엇을 해야 하는지, 언제 써야 하는지, 절대 하면 안 되는 일은 무엇인지 물어봐요. 편한 말로 답하면 돼요. 빠진 내용이 있을 때만 짧게 되묻고, 그다음 스킬 초안을 써 줘요.

스킬 입력 화면에서 초안을 확인하고 필요하면 고친 뒤 **Create & attach**(만들고 첨부하기)를 클릭하세요.

![AI Assistant에서 짧은 대화로 스킬을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084497360/original/UwyUc0PrEovYTtBh-XXP89Z_lX1xDYdusg.png?1793273550)

*Create with AI를 선택하면 AI Assistant에서 짧은 대화가 시작돼요.*

### 방법 2: Write skill instructions(스킬 지침 작성)

1. **Name**을 입력하세요.
2. **When should the agent use this**?에 스킬을 불러와야 하는 상황을 적으세요.
3. **Instructions**를 작성하세요. 툴바로 목록과 제목을 넣을 수 있어요. **Enhance prompt**(프롬프트 개선)를 클릭하면 AI가 문장을 다듬어 줘요.
4. **Create & attach**를 클릭하세요. 스킬이 라이브러리에 저장되고, 이 액션에 붙어요.

![세 항목을 모두 채운 스킬 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084497379/original/HgJhIi39akmeSvqs47NAf_rvdQUiev0fpA.png?1793273554)

*세 항목을 모두 채운 스킬 입력 화면이에요.*

### 방법 3: Add existing skill(기존 스킬 추가)

1. 라이브러리에서 스킬을 검색하거나 스크롤해서 찾으세요. 내장 스킬에는 **Built-in** 태그가 붙어 있어요.
2. 스킬 행을 클릭하면 붙이기 전에 전체 설명과 지침을 읽어 볼 수 있어요.
3. **Attach**(첨부)를 클릭하세요. 붙인 스킬은 목록 맨 위의 **Attached**(첨부됨) 그룹으로 옮겨져요.
4. 다 끝나면 **Done**(완료)을 클릭하세요.

## 스킬 관리하기

- 스킬 편집: 액션에서 스킬 행에 마우스를 올리고 연필 아이콘을 클릭하세요. **Add existing skill**에서 스킬을 연 다음, 옵션 메뉴에서 **Edit**(편집)을 선택해도 돼요.
- 스킬 떼어 내기: 스킬 행에 마우스를 올리고 **X** 아이콘을 클릭하세요. 이 액션에서만 스킬이 빠지고, 라이브러리에는 그대로 남아요.
- 스킬 삭제: **Add existing skill**에서 스킬을 연 다음, 옵션 메뉴에서 **Delete**(삭제)를 선택하세요. 삭제하면 라이브러리에서도, 그 스킬을 쓰는 모든 액션에서도 사라져요.

{% hint style="info" %}
스킬 하나는 붙어 있는 모든 액션이 함께 써요. 스킬을 편집하면 그 스킬을 쓰는 모든 액션에 변경 내용이 적용돼요.
{% endhint %}

## 예시: 리드 후속 연락 에이전트

냉난방 업체가 견적을 요청한 모든 리드에게 후속 연락을 하려고 해요. 대부분의 리드에게는 친절한 이메일과 문자를 보내면 돼요. 일부 리드는 가스 냄새나 난방 고장 같은 긴급 상황을 알려 오는데, 이런 경우에는 다르게 대응해야 해요.

### 설정

- **Trigger**(트리거): **Form Submitted**(폼 제출) (견적 요청 폼)
- **Action Name**(액션 이름): Lead follow-up agent
- **Instructions**: "당신은 Apex Heating and Cooling의 신규 리드에게 후속 연락을 합니다. 리드가 방금 견적 요청 폼을 제출했습니다. 리드에게 감사 인사를 전하고, 요청 내용을 다시 정리하고, 통화 가능한 시간을 제안하는 이메일 1통과 SMS 1통을 보내세요."
- **Tools**(도구): **Send email**(이메일 보내기)과 **Send SMS**(SMS 보내기). **Let AI decide all field values**(모든 필드 값을 AI가 결정)를 켜 두었어요.
- **Skills**: Cold-email(내장), Sms-writer(내장), 그리고 직접 만든 Emergency service requests 스킬

### 직접 만든 스킬

| 항목 | 값 |
| --- | --- |
| **Name** | Emergency service requests |
| **When should the agent use this?** | 리드가 난방 안 됨, 냉방 안 됨, 가스 냄새, 누수를 알려 오거나 요청이 급하다고 말할 때 사용해요. |
| **Instructions** | 리드가 가스 냄새가 난다고 알리면, 먼저 건물 밖으로 대피하고 가스 회사에 전화하라고 안내해요. 가스 냄새로는 절대 방문 일정을 잡지 않아요. 난방 안 됨, 냉방 안 됨, 누수의 경우에는 당일 가장 빠른 긴급 방문 시간을 제안해요. 첫 답장은 짧은 두 문장으로 써요. 가격은 절대 말하지 않아요. 비용은 기사가 현장에서 확인해 드린다고 안내해요. |

![도구 2개와 스킬 3개가 설정된 완성된 액션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084497412/original/l_8SxeAjWjBKJSf6lsIAVQ2Xz5LkdPN1Wg.png?1793273582)

*도구 2개와 스킬 3개가 설정된 완성된 액션이에요.*

### 실행하면 이렇게 동작해요

- 일반적인 견적 요청: 에이전트가 Cold-email을 불러와 이메일을 쓰고, Sms-writer를 불러와 문자를 써요. Emergency service requests는 불러오지 않아요.
- "어젯밤부터 난방이 안 돼요"라고 쓴 리드: 에이전트가 Cold-email, Sms-writer와 함께 Emergency service requests를 불러와요. 그리고 가격은 말하지 않고 당일 방문 시간을 제안해요.
- 가스 냄새를 알려 온 리드: Emergency service requests에 따라 에이전트가 안전 안내를 먼저 보내고, 방문 일정은 잡지 않아요.

## 에이전트가 스킬을 쓰는 방식

- 스킬이 여러 개 해당할 수 있어요. 상황이 여러 스킬과 맞으면 에이전트가 모두 불러와 함께 따라요.
- 액션의 Instructions가 먼저예요. 스킬과 액션의 Instructions가 서로 다르면 에이전트는 액션의 Instructions를 따라요.
- 구체적인 규칙이 일반적인 규칙보다 앞서요. "제목은 다섯 단어 이내로"처럼 구체적인 규칙이 "짧게 써라" 같은 일반적인 규칙보다 우선해요.
- "Never" 규칙이 우선해요. 한 스킬은 어떤 일을 하라고 하고 다른 스킬은 절대 하지 말라고 하면, 에이전트는 그 일을 하지 않아요.

## 좋은 스킬을 쓰는 팁

- 구체적인 상황을 적으세요. "긴급 상황 처리"보다 "리드가 난방 안 됨이나 가스 냄새를 알려 올 때 사용"처럼 쓰세요. 에이전트는 이 항목만 보고 스킬을 쓸지 정해요.
- 스킬 하나에는 목적 하나만 담으세요. 여러 상황을 한꺼번에 다루는 큰 스킬 하나보다 작은 스킬 두 개가 관리하기 쉬워요.
- 금지 사항은 마지막에 쓰세요. 지침 끝에 "Never"로 시작하는 분명한 문장을 넣으세요.
- 액션이 맡은 일을 스킬에 다시 쓰지 마세요. 액션 하나의 일은 그 액션의 Instructions에 쓰세요. 여러 액션에서 재사용하는 규칙이나 가끔만 적용되는 규칙은 스킬에 쓰세요.

## 자주 묻는 질문

### Instructions와 스킬은 뭐가 다른가요?
Instructions는 AI Agent 액션 하나가 맡은 일을 설명하는 글이고, 매 실행에 보내져요. 스킬은 라이브러리에 저장해 두는 재사용 가능한 절차예요. 여러 액션에 붙일 수 있고, 스킬 설명이 상황과 맞을 때만 불러와요.

### 액션이 실행될 때마다 스킬도 실행되나요?
아니요. 에이전트는 실행할 때마다 붙어 있는 모든 스킬의 이름과 설명을 읽어요. 상황이 설명과 맞을 때만 그 스킬의 지침을 불러와요.

### 스킬 두 개가 동시에 해당하면 어떻게 되나요?
에이전트가 둘 다 불러와서 함께 따라요. 서로 다르면 액션의 Instructions가 먼저 적용되고, 그다음에 더 구체적인 규칙이 적용돼요. "Never" 규칙은 무언가를 하라는 규칙보다 우선해요.

### 같은 스킬을 여러 워크플로우에서 쓸 수 있나요?
네. 스킬은 서브 계정의 라이브러리에 저장돼요. 어떤 워크플로우에 있는 AI Agent 액션이든 같은 스킬을 붙일 수 있어요.

### 스킬을 편집하면 모든 곳에 바뀌나요?
네. 스킬 하나는 붙어 있는 모든 액션이 함께 쓰기 때문에, 편집하면 그 액션 모두에 적용돼요.

### 스킬을 떼어 내는 것과 삭제하는 것은 뭐가 다른가요?
떼어 내면 그 액션에서만 스킬이 빠져요. 삭제하면 라이브러리에서도, 그 스킬을 쓰는 모든 액션에서도 사라져요.

### 내장 스킬도 편집하거나 삭제할 수 있나요?
네. 내장 스킬도 라이브러리의 다른 스킬과 똑같이 쓸 수 있어요.

### 스킬에서 지식 베이스를 쓸 수 있나요?
네. 스킬 지침에 지식 베이스 이름을 적어 주세요. 예: "Service policies 지식 베이스에서 보증 조건을 검색한다." 이때 액션에 **Knowledge base search** 도구가 추가되어 있어야 해요.

### 스킬이 직접 메시지를 보내거나 연락처를 업데이트할 수 있나요?
아니요. 스킬은 에이전트에게 어떻게 할지를 알려 줄 뿐이에요. 실제로 실행하려면 액션에 **Send email**이나 **Send SMS** 같은 알맞은 도구가 있어야 해요.

### AI Agent 액션을 쓰려면 스킬이 꼭 있어야 하나요?
아니요. 스킬은 선택 사항이에요. 처음에는 Instructions와 도구만으로 시작하고, 비슷한 패턴이 반복될 때 스킬을 추가하는 사용자가 많아요.
