# 워크플로우 액션 – AI 영상 분석 (AI Analyze Video)

이 아티클에서는 워크플로우 안에서 AI가 영상을 이해할 수 있도록 도와주는 AI 영상 분석(AI Analyze Video) 액션 사용법을 설명해요. 단계별 설정 방법, 사용 가능한 영상 URL 종류, 출력값 활용법, 실제 사용 사례, 그리고 자주 묻는 질문까지 모두 안내해드릴게요.

**참고: **이 액션은 프리미엄 액션이에요. 사용할 때마다 실행 건당 추가 요금이 발생해요.

## 워크플로우의 AI 영상 분석 액션이란?

워크플로우(Workflow)의 AI 액션(AI Actions) 아래에서 사용할 수 있는 AI 영상 분석 액션은 Google Gemini 모델을 활용해 영상을 보고 텍스트로 응답을 돌려줘요. 영상 URL과 AI가 무엇을 찾아야 하는지 설명하는 프롬프트를 입력하면, 이 액션이 분석 결과를 텍스트로 반환해서 이후 액션에서 활용할 수 있어요.

이 모델은 영상의 장면을 보는 동시에 오디오도 들어요. 그래서 영상 요약, 장면 설명, 음성이나 화면에 나오는 정보 추출, 타임스탬프와 함께 영상에 등장하는 내용 나열 등에 유용해요. 즉, 단순히 링크만 전달하는 게 아니라 워크플로우가 영상 콘텐츠 자체를 이해할 수 있게 해줘요.

## AI 영상 분석 액션의 주요 장점

- **영상 요약: **긴 영상을 몇 초 만에 읽을 수 있는 몇 개의 핵심 포인트로 바꿔줘요.
- **장면과 음성 동시 이해: **모델이 화면과 소리를 모두 활용하기 때문에 무슨 일이 일어나는지, 무슨 말을 하는지 함께 설명할 수 있어요.
- **타임스탬프: **특정 상품, 인물, 주제가 등장하는 정확한 시점을 찾기 위해 타임스탬프를 요청할 수 있어요.
- **유튜브 링크 지원: **youtu.be, Shorts 링크를 포함한 공개 유튜브 영상은 물론, 직접 영상 파일 링크도 분석할 수 있어요.
- **자유로운 프롬프트: **영상에 대해 무엇이든 물어볼 수 있어요. 프롬프트로 AI가 정확히 무엇을 찾고 어떻게 응답할지 제어할 수 있어요.
- **영상 생성 기능과의 조합: **AI 영상 생성(AI Video Generation) 액션과 함께 사용해서 워크플로우가 방금 만든 영상을 설명하거나 검증할 수 있어요.

## 액션 상세 정보

| 필드 | 설명 |
|---|---|
| 액션 이름(Action Name) | 액션을 식별하기 위한 커스텀 이름이에요. 워크플로우 캔버스와 실행 로그에서 사용돼요. |
| 모델(Model) | 분석에 사용할 Google Gemini 모델이에요. Gemini 3.8 Flash(기본값)와 Gemini 3.5 Flash Lite 두 가지를 선택할 수 있어요. |
| 영상(Video) | 필수 입력 항목이에요. 분석할 영상의 공개 HTTPS URL로, 공개 유튜브 링크 또는 영상 파일(MP4, MOV, WebM, MPEG, FLV, WMV, 3GP) 직접 링크를 사용할 수 있어요. 이전 단계의 결과값이나 커스텀 값(Custom Value)을 가져오거나 직접 입력할 수 있어요. 아래 '영상 URL 요구 사항'을 참고하세요. |
| 분석 프롬프트(Analysis Prompt) | 필수 입력 항목이에요. AI가 영상에서 무엇을 찾고 어떻게 응답해야 하는지 지시하는 내용이에요. 동적인 프롬프트를 위해 커스텀 값을 지원해요. |

## AI 영상 분석 액션 사용 방법

### 1단계: 액션 추가하기

- **Automation(자동화) > Workflows(워크플로우)**로 이동하세요.
- 새 워크플로우를 만들거나 기존 워크플로우를 편집하세요.
- **+** 아이콘을 클릭해 새 액션을 추가하세요. "analyze video"를 검색하거나 **AI Actions(AI 액션)**를 열고 **AI analyze video**를 선택하세요.
- 캔버스에서 쉽게 알아볼 수 있도록 액션에 명확하고 설명적인 이름을 지어주세요.

![AI Actions에서 AI 영상 분석 액션 추가하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084517280/original/3f0yUcxbuw_IMljFyoEbLhtwppTPruoBNw.gif?1793282972)

*AI Actions에서 AI 영상 분석 액션 추가하기*

### 2단계: 모델 선택하기

분석에 사용할 Gemini 모델을 선택하세요. 두 가지 모델을 사용할 수 있어요:

- **Gemini 3.8 Flash**(기본값)
- **Gemini 3.5 Flash Lite**

어떤 모델을 사용할지 확신이 서지 않는다면, 워크플로우를 발행하기 전에 동일한 영상과 프롬프트로 두 모델을 모두 테스트하고 결과를 비교해보세요.

### 3단계: 영상 URL 입력하기

분석하고 싶은 영상의 URL을 입력하세요. 링크를 직접 입력하거나 붙여넣을 수 있고, 태그 아이콘을 클릭해 값을 삽입할 수도 있어요:

- **이전 단계(Previous steps)** – 워크플로우의 이전 단계에서 생성된 영상 URL이에요. 예를 들어 AI 영상 생성 액션의 결과값이나 인바운드 웹훅(Webhook)에서 받은 값이 해당돼요.
- **커스텀 값(Custom values)** – 영상 URL을 담고 있는 연락처(Contacts) 필드나 다른 커스텀 값이에요.

URL은 반드시 공개 HTTPS 링크여야 해요. 필드 라벨 옆의 정보 아이콘에 마우스를 올리면 지원되는 파일 형식을 확인할 수 있어요.

![모델을 선택하고 유튜브 영상 URL 추가하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084517206/original/Q9fB0VmTKNgo2MIQDTECwfDs7pZo_TQc2g.gif?1793282926)

*모델을 선택하고 유튜브 영상 URL 추가하기*

### 4단계: 분석 프롬프트 입력하기

AI가 영상에서 무엇을 찾고 어떻게 응답해야 하는지 알려주는 프롬프트를 작성하세요. 프롬프트가 구체적일수록 더 유용한 결과를 얻을 수 있어요.

**예시:**

- 이 영상의 주요 내용을 3가지 핵심 포인트로 요약해주세요.
- 영상에 등장하는 상품을 타임스탬프와 함께 나열해주세요.
- 화자가 가격에 대해 언급한 모든 내용을 적어주세요.
- 화면에 표시된 텍스트를 읽고 목록으로 반환해주세요.

프롬프트 필드는 커스텀 값을 지원하므로, 연락처 필드, 웹훅 데이터, 이전 액션의 결과값을 활용해 프롬프트를 동적으로 구성할 수도 있어요.

### 5단계: 액션 저장하기

**Save action(액션 저장)**을 클릭하세요. 워크플로우가 실행되면 분석 결과값을 이후의 모든 액션에서 변수로 사용할 수 있어요.

![분석 프롬프트를 작성하고 액션 저장하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084517318/original/x7Hky-LUuVtuqi2Oe-PEqNj1tXgwmPTykA.gif?1793282994)

*분석 프롬프트를 작성하고 액션 저장하기*

### 6단계: 액션 테스트하기 (선택 사항)

워크플로우를 발행하기 전에 빌더에서 바로 AI 영상 분석 액션을 테스트하고 AI의 답변을 확인할 수 있어요. 테스트는 트리거(Trigger)의 데이터를 기반으로 실행되므로, 먼저 트리거를 테스트해두세요.

- **Test(테스트)** 탭을 여세요. **Input(입력)** 화면에서 영상 URL, 프롬프트 등 액션이 사용할 값을 확인할 수 있어요.
- **Test Action(액션 테스트)** (이전에 테스트한 적이 있다면 **Retest(재테스트)**)을 클릭하세요.
- 실행이 끝나면 **Output(출력)** 화면에 결과가 표시돼요. **Response(응답)** 값을 클릭하면 AI의 전체 답변을 읽을 수 있어요.

긴 영상의 경우 테스트에 시간이 좀 걸릴 수 있어요. 저희 테스트에서는 10분짜리 유튜브 영상을 분석하는 데 약 30초가 걸렸어요. 테스트 실행도 실제 영상을 분석하기 때문에 일반 실행과 동일하게 요금이 청구돼요.

## 영상 URL 요구 사항

AI 모델은 URL에서 영상을 직접 가져와요. 따라서 URL은 반드시 공개 상태여야 하며, 누구나 로그인 없이 열람할 수 있어야 해요.

| 영상 링크 종류 | 작동 여부 | 참고 사항 |
|---|---|---|
| 공개 유튜브 영상 (youtube.com/watch, youtu.be, Shorts 링크) | 가능 | 일반 공유 링크를 붙여넣으세요. 영상이 공개 상태여야 해요. |
| 영상 파일 직접 링크 (.mp4, .webm, .mov 등으로 끝남) | 가능 | 링크는 로그인 없이 파일 자체를 열거나 다운로드할 수 있어야 해요. |
| 미디어 스토리지(Media Storage) 영상 (AI 영상 생성으로 만든 영상 포함) | 가능 | - |
| Vimeo, TikTok 등 다른 영상 플랫폼의 페이지 링크 | 불가능 | 이런 사이트들은 자동화된 접근을 차단하기 때문에 모델이 영상을 가져올 수 없어요. |
| 로그인, 비밀번호, 공유 권한이 필요한 링크 | 불가능 | 예: 비공개 클라우드 드라이브 링크, 만료된 서명 링크 |
| 영상이 아닌 일반 웹페이지 | 불가능 | 영상이 표시되는 페이지가 아니라 영상 자체의 링크를 사용하세요. |

**팁: **URL을 시크릿/프라이빗 브라우저 창에서 열어보세요. 로그인 없이 영상이 재생되거나 다운로드된다면 대부분 이 액션이 접근할 수 있어요. 유튜브 외의 호스팅 플랫폼이라면 페이지 링크 대신 직접 파일 링크를 사용하세요.

**중요: **항상 실제 영상을 가리키는 URL을 사용하세요. URL이 일반 웹페이지라면 액션이 응답을 반환하더라도 그 응답은 실제 영상을 설명한 내용이 아닐 수 있어요.

### 자주 발생하는 오류

| 오류 메시지 | 의미 | 해결 방법 |
|---|---|---|
| Cannot fetch content from the provided URL. The URL is blocked by robots.txt rules. | 해당 웹사이트가 자동화된 접근을 허용하지 않아요. Vimeo와 TikTok 페이지에서 이 오류가 발생해요. | 공개 유튜브 링크나 영상 파일 직접 링크를 사용하세요. |
| Cannot fetch content from the provided URL. Please ensure the URL is valid and accessible. Status: URL_ERROR_ERROR_OTHER | URL을 열 수 없어요. 로그인이 필요하거나 더 이상 존재하지 않는 경우에 발생해요. | 프라이빗 브라우저 창에서 URL을 열어 영상이 로드되는지 확인하세요. |
| Cannot fetch content from the provided URL. Status: URL_REJECTED_REJECTED_SCHEDULE_TIME_OVER_DEADLINE | 영상을 가져오는 데 시간이 너무 오래 걸렸어요. | 액션을 다시 실행해보세요. 계속 실패한다면 더 작은 파일이나 유튜브 링크를 사용하세요. |

## 다음 액션에서 출력값 활용하기

액션이 실행되면, 커스텀 값 선택기(custom value picker)를 통해 이후의 모든 액션에서 응답값을 사용할 수 있어요. 선택기를 열고 **Previous steps(이전 단계)**로 이동한 뒤, **AI analyze video**를 선택하고 해당 단계를 고른 다음 **Response(응답)**를 선택하세요.

출력값은 프롬프트에 대한 AI의 답변을 담은 텍스트 값이에요. 요약, 스크립트, 타임스탬프가 포함된 목록 등 프롬프트에서 요청한 내용이 들어있어요. 응답에는 제목(###)이나 글머리 기호(*) 같은 마크다운(Markdown) 서식이 포함될 수 있어요. 순수 텍스트가 필요하다면 프롬프트에서 "마크다운 없이 일반 텍스트로 반환해주세요"처럼 요청하세요.

출력값이 텍스트이기 때문에, 텍스트 값을 사용할 수 있는 곳이라면 어디에서든 활용할 수 있어요. 연락처 커스텀 필드에 저장하거나, 이메일이나 SMS(문자)에 포함하거나, 아웃바운드 웹훅으로 전달하거나, 추가 처리를 위해 다른 AI 액션에 입력할 수 있어요.

## 사용 사례

### 1. 리드가 공유한 영상 요약하기

**시나리오: **리드(Lead)가 매물 투어, 제품 데모, 또는 도움이 필요한 문제를 담은 유튜브 링크를 보내요. 팀에서는 모든 영상을 직접 보는 대신 연락처 상세(Contact Record)에서 짧은 요약만 확인하고 싶어 해요.

**설정:**

- **트리거: **폼 제출(Form Submitted) (영상 링크 필드 포함)
- **액션 1: **AI 영상 분석 – 폼 필드의 영상을 사용. 프롬프트: "이 영상을 3가지 핵심 포인트로 요약해주세요."
- **액션 2: **연락처 필드 업데이트 – Response를 검토용 커스텀 필드에 저장

### 2. 생성된 영상 검증하기

**시나리오: **워크플로우가 AI 영상 생성 액션으로 영상을 만들었고, 고객에게 전달하기 전에 결과물을 확인하고 싶어요.

**설정:**

- **액션 1: **AI 영상 생성 – 프롬프트로 영상 생성
- **액션 2: **AI 영상 분석 – 이전 액션의 영상 URL 출력값 사용. 프롬프트: "이 영상을 설명해주세요. 나무 테이블 위에 커피잔이 보이나요? 먼저 예/아니오로 답해주세요."
- **액션 3: **조건 분기(If/Else) 또는 내부 알림 – 답변에 따라 워크플로우를 분기하거나, 전달 전에 팀에서 빠르게 확인하도록 전송

### 3. 웨비나 녹화본 콘텐츠 노트 만들기

**시나리오: **외부 시스템에서 직접 영상 링크 형태로 녹화본이 도착해요. 각 영상에 대한 쇼노트, 핵심 포인트, 타임스탬프가 필요해요.

**설정:**

- **트리거: **인바운드 웹훅(Inbound Webhook) (영상 URL 포함)
- **액션 1: **AI 영상 분석 – 프롬프트: "논의된 핵심 주제를 각각 타임스탬프와 함께 나열해주세요."
- **액션 2: **아웃바운드 웹훅 또는 이메일 발송 – 콘텐츠 팀에 노트 전달

### 더 많은 활용 아이디어

- **고객 후기 검토: **고객 후기 영상에서 가장 인상적인 발언을 추출해요.
- **제출물 확인: **제출된 영상이 요청한 내용(예: 완료된 설치 작업, 언박싱)을 보여주는지 확인해요.
- **영상 태깅: **모델에게 간단한 주제/카테고리 목록을 요청한 뒤, 그 결과로 연락처에 태그(Tag)를 붙이거나 워크플로우를 분기해요.
- **스크립트 작성: **화자가 말한 내용을 텍스트로 기록해달라고 요청한 뒤, 팀에 전달하거나 연락처에 저장해요.

## 더 좋은 결과를 위한 팁

- **원하는 출력 형식을 구체적으로 지정하세요. **"제품 이름만 한 줄씩 반환해주세요"라고 요청하면 바로 사용할 수 있는 값을 얻을 수 있어요. "이 영상에 대해 알려주세요"라고만 하면 긴 문단이 나와요.
- **영상에서 특정 순간을 찾아야 할 때는 타임스탬프를 요청**하세요.
- **공개 유튜브 링크나 직접 파일 링크를 사용**하세요. 다른 영상 플랫폼의 페이지 링크는 대부분 차단돼요.
- **커스텀 필드에 저장하거나 조건 분기(If/Else)에서 사용할 계획이라면, 일관된 형식을 요청**하세요.
- **대량으로 워크플로우를 실행하기 전에 실제 영상 몇 개로 미리 테스트**해보세요.

## 요금 안내

영상 분석은 실행 건당 요금이 청구돼요.

실제 분석 비용은 액션을 어떻게 설정하는지에 따라 달라져요. 주요 요인은 다음과 같아요:

- **모델** – 선택한 Gemini 모델
- **영상 길이** – 영상이 길수록 모델이 처리할 내용이 많아져서 짧은 클립보다 비용이 더 들어요.
- **응답 길이** – 길고 상세한 답변은 짧은 답변보다 비용이 더 들어요.

## 자주 묻는 질문

**Q: 유튜브 링크를 사용할 수 있나요?**

네. youtube.com/watch, youtu.be, 유튜브 Shorts 링크를 포함한 공개 유튜브 영상을 사용할 수 있어요. 일반 공유 링크를 붙여넣으면 돼요.

**Q: 아무 공개 영상 URL이나 사용할 수 있나요?**

모든 URL이 가능한 건 아니에요. 공개 유튜브 링크와 영상 파일 직접 링크는 사용할 수 있어요. 하지만 Vimeo, TikTok 같은 플랫폼의 페이지 링크는 해당 사이트가 자동화된 접근을 차단하기 때문에 작동하지 않아요. 이런 경우 플랫폼에서 직접 파일 링크를 제공한다면 그것을 사용하세요.

**Q: 어떤 영상 형식을 지원하나요?**

MP4, MOV, WebM, MPEG, FLV, WMV, 3GP를 지원해요.

**Q: 영상 URL이 로그인 뒤에 있으면 어떻게 되나요?**

액션이 실패해요. AI 모델은 URL에서 영상을 직접 가져오기 때문에, 로그인, 토큰, 권한 확인 없이 공개적으로 접근 가능해야 해요. 프라이빗 브라우저 창에서 URL을 열어 누구나 로드할 수 있는지 확인해보세요.

**Q: AI가 오디오도 듣나요?**

네. 모델은 화면과 소리를 모두 활용하기 때문에 영상에서 보여지는 내용뿐 아니라 말하는 내용에 대해서도 질문할 수 있어요.

**Q: 영상이 얼마나 길어도 되나요?**

저희 테스트에서는 10분짜리 유튜브 영상이 정상적으로 작동했고 약 30초가 걸렸어요.

**Q: 어떤 모델을 선택해야 하나요?**

Gemini 3.8 Flash(기본값)와 Gemini 3.5 Flash Lite 두 가지 모델을 사용할 수 있어요. 확신이 서지 않는다면, 워크플로우를 발행하기 전에 동일한 영상과 프롬프트로 두 모델을 모두 테스트하고 결과를 비교해보세요.

**Q: 출력값은 어떤 형식인가요?**

출력값은 Response라는 이름의 텍스트 값이에요. 제목이나 글머리 기호 같은 마크다운 서식이 포함될 수 있어요. 순수 텍스트가 필요하다면 프롬프트에서 요청하세요.

**Q: 타임아웃 오류로 액션이 실패했어요. 왜 그런가요?**

영상을 가져오는 데 시간이 너무 오래 걸렸기 때문이에요. 액션을 다시 실행해보세요. 계속 실패한다면 더 작은 파일이나 유튜브 링크를 사용하세요.

**Q: AI 영상 생성 액션과 함께 사용할 수 있나요?**

네. AI 영상 생성 단계 다음에 AI 영상 분석을 추가하고, 생성된 영상 URL을 전달하면 돼요. 이렇게 하면 영상을 전달하기 전에 생성된 내용을 설명하거나 검증할 수 있어요.

**Q: 하나의 액션에서 여러 개의 영상을 분석할 수 있나요?**

AI 영상 분석 액션 하나는 영상 URL 하나만 처리해요. 워크플로우에서 여러 영상을 분석하려면 각각에 대해 별도의 액션을 추가하고, 이후 단계에서 각 액션의 출력값을 개별적으로 참조하세요.
