# 워크플로우 액션 — AI Analyze Image(AI 이미지 분석)

워크플로우에서 **AI Analyze Image**(AI 이미지 분석) 액션으로 AI 비전 모델이 이미지를 분석하게 하는 방법을 안내해요. 설정 순서, 이미지 URL 조건, 결과를 활용하는 방법, 사용 사례, 자주 묻는 질문을 확인할 수 있어요.

{% hint style="info" %}
이 액션은 프리미엄 액션이에요. 실행할 때마다 추가 요금이 발생해요.
{% endhint %}

## AI Analyze Image 액션이란?

**AI Analyze Image** 액션은 워크플로우의 **AI Actions**(AI 액션)에 있어요. AI 비전 모델로 이미지를 분석하고, 그 결과를 텍스트로 돌려줘요. 이미지 URL과 AI가 살펴볼 내용을 적은 프롬프트를 입력하면, 분석 결과가 텍스트로 나와요. 이 텍스트는 뒤에 오는 액션에서 사용할 수 있어요.

이미지에서 글자 추출(OCR), 이미지 설명 생성, 사물이나 특징 식별, 이미지 내용 확인에 쓸 수 있어요. 워크플로우가 이미지를 그냥 전달하는 데서 그치지 않고, 이미지를 해석할 수 있게 돼요.

---

## 주요 장점

- 글자 추출(OCR): 스크린샷, 영수증, 문서 등 이미지 속 글자를 꺼내 워크플로우 데이터로 쓸 수 있어요.
- 이미지 설명 생성: 이미지에 무엇이 담겨 있는지 자세히 설명해 줘요. 자료 분류, 대체 텍스트, 콘텐츠 요약에 유용해요.
- 자유로운 프롬프트: 이미지에 대해 무엇이든 물어볼 수 있어요. 프롬프트로 AI가 무엇을 찾고 어떻게 답할지 정해요.
- 조절 가능한 상세 수준: 분석을 얼마나 꼼꼼히 할지 골라서 정확도와 속도 사이에서 균형을 맞출 수 있어요.
- 이미지 생성과 함께 사용: **AI Image Generation**(AI 이미지 생성) 액션과 함께 쓰면, 워크플로우가 방금 만든 이미지를 설명하거나 확인할 수 있어요.

## Action Details(액션 상세 정보)

| 필드 | 설명 |
| --- | --- |
| **Action Name**(액션 이름) | 액션의 이름이에요. 워크플로우 캔버스와 실행 로그에서 이 액션을 구분하는 데 쓰여요. |
| **Model**(모델) | 분석에 쓸 AI 비전 모델이에요. GPT-5.6 Luna와 GPT-5.6 Tera, 두 가지가 있어요. |
| **Image URL**(이미지 URL) | 분석할 이미지의 URL이에요. 이전 단계의 결과나 커스텀 값에서 가져올 수 있어요. URL은 공개적으로 접근할 수 있어야 해요. 아래 '이미지 URL 조건'을 참고하세요. |
| **Analysis Prompt**(분석 프롬프트) | 이미지에서 무엇을 찾고 어떻게 답할지 AI에게 알려 주는 지시문이에요. 커스텀 값을 넣어 상황에 따라 바뀌는 프롬프트를 만들 수 있어요. |
| **Detail Level**(상세 수준) | 이미지를 얼마나 꼼꼼히 분석할지 정해요. 기본값은 **Auto**(자동)이고, **High**(높음)나 **Low**(낮음)로 바꿀 수 있어요. |

## AI Analyze Image 액션 사용하기

### 1단계: 액션 추가하기

1. **자동화 > 워크플로우**로 이동하세요.
2. 새 워크플로우를 만들거나 기존 워크플로우를 편집하세요.

3. 워크플로우에서 **+** 아이콘을 눌러 새 액션을 추가하세요. **AI Actions**에서 **AI Analyze Image**를 찾아 선택하세요. 캔버스에서 쉽게 알아볼 수 있도록 액션 이름을 알기 쉽게 지어 주세요.

   ![AI Analyze Image 액션을 추가하는 모습](https://jumpshare.com/share/kQLCL5FaVCUr4s1hKvvY+/GIF+Recording+2026-08-28+at+17.26.42.gif)

### 2단계: 모델 선택하기

분석에 쓸 AI 비전 모델을 고르세요. 모델은 두 가지예요.

- GPT-5.6 Luna
- GPT-5.6 Tera

어떤 모델을 쓸지 잘 모르겠다면, 같은 이미지와 프롬프트를 두 모델에 모두 실행해 보세요. 결과를 비교한 뒤 워크플로우를 게시하면 돼요.

![모델 선택 화면](https://jumpshare.com/share/U2OY2Fou3rn6EuItyWye+/Screenshot+2026-08-28+at+17.34.07.png)

### 3단계: 이미지 URL 입력하기

분석할 이미지의 URL을 입력하세요.

워크플로우의 이전 단계 결과에서 가져올 수 있어요. 예를 들어 **AI Image Generation** 액션의 **Image URL** 결과를 쓸 수 있어요. 이미지 URL이 담긴 커스텀 값에서도 가져올 수 있어요. URL은 공개적으로 접근할 수 있어야 해요.

![이미지 URL 입력 화면](https://jumpshare.com/share/Z8S6ZdH2R7fdMm7vr2Ht+/GIF+Recording+2026-08-28+at+17.48.19.gif)

### 4단계: 분석 프롬프트 입력하기

이미지에서 무엇을 찾고 어떻게 답할지 AI에게 알려 주는 프롬프트를 쓰세요. 프롬프트가 구체적일수록 결과가 더 쓸모 있어요.

예시:

- 이 상품 이미지를 자세히 설명해 줘.
- 이 이미지에 보이는 글자를 모두 추출해 줘.
- 이 사진에 보이는 물건을 목록으로 적어 줘.
- 이 영수증에서 합계 금액을 읽고 숫자만 알려 줘.

프롬프트 입력란에는 커스텀 값을 쓸 수 있어요. 연락처 필드, 웹훅 데이터, 앞선 액션의 결과로 프롬프트를 만들 수 있어요.

![분석 프롬프트 입력 화면](https://jumpshare.com/share/BrqlEWMFrFuZdOoyfJrw+/Screen+Shot+2026-08-28+at+17.54.02.png)

### 5단계: 상세 수준 설정하기

이미지를 얼마나 꼼꼼히 분석할지 고르세요.

기본값은 **Auto**이고, 시스템이 알맞은 수준을 알아서 정해요. 작은 부분까지 꼼꼼히 분석하려면 **High**를 고르세요. 이미지를 대략 훑어보면 충분하다면 **Low**를 고르세요. 더 빠르고 가볍게 분석해요.

### 6단계: 액션 저장하기

액션을 저장하세요. 워크플로우가 실행되면 분석 결과가 변수로 만들어져서, 뒤에 오는 모든 액션에서 쓸 수 있어요.

## 이미지 URL 조건

입력하는 이미지 URL은 공개적으로 접근할 수 있어야 해요. AI 모델이 URL에서 이미지를 직접 가져오기 때문에, 익명 접근을 막는 URL이면 액션이 실패해요.

{% hint style="info" %}
URL을 시크릿(비공개) 브라우저 창에서 열어 보면 간단히 확인할 수 있어요. 로그인하지 않아도 이미지가 열리면 액션도 접근할 수 있어요. **미디어 저장소**에 저장된 이미지는 이미 공개 URL로 호스팅되어 있어서, 따로 설정하지 않아도 돼요. **AI Image Generation** 액션이 만든 이미지도 마찬가지예요.
{% endhint %}

다음과 같은 URL은 쓸 수 없어요.

- 보려면 로그인, 비밀번호, 인증 토큰이 필요한 URL
- 비공개 공유 링크, 권한이 제한된 드라이브, 내부 네트워크 뒤에 있는 URL
- 이미지 파일 자체가 아니라 이미지가 들어 있는 페이지를 가리키는 URL

## 뒤에 오는 액션에서 결과 사용하기

액션이 실행되면, 뒤에 오는 모든 액션에서 그 결과를 쓸 수 있어요. 커스텀 값 선택기의 **AI Analyze Image** 아래에서 골라요. 결과는 프롬프트에 대한 AI의 답이 담긴 텍스트 값이에요. 설명, 추출한 글자, 목록 등 프롬프트로 요청한 내용이 나와요.

결과가 일반 텍스트이므로 텍스트 값을 받는 곳이면 어디든 쓸 수 있어요. 연락처 커스텀 필드에 저장하거나, 이메일이나 SMS에 넣을 수 있어요. 아웃바운드 웹훅으로 보내거나, 다른 AI 액션에 넘겨 추가로 처리할 수도 있어요.

## 사용 사례

### 1. 고객이 보낸 이미지에서 글자 추출하기

시나리오: 고객이 영수증, 인보이스, 문서 사진을 MMS로 보내요. 이미지를 하나씩 직접 확인하는 대신, 이미지 속 글자를 읽어서 연락처 기록에 저장하고 싶어요.

구성:

- **Trigger**(트리거): **Customer Replied**(고객 답장) — 이미지 첨부 포함
- **Action 1**: **AI Analyze Image** — **Image URL**은 첨부 파일에서 가져와요. 프롬프트는 "이 이미지에 보이는 글자를 모두 추출해 줘."로 해요. **Detail Level**은 **High**로 해요.
- **Action 2**: **Update Contact**(연락처 업데이트) — 추출한 글자를 커스텀 필드에 저장해서 검토나 후속 조치에 써요.

### 2. 생성된 이미지 검증하기

시나리오: 워크플로우가 **AI Image Generation** 액션으로 이미지를 만들어요. 고객에게 보내기 전에, 실제로 어떤 이미지가 만들어졌는지 한 번 더 확인하고 싶어요.

구성:

- **Action 1**: **AI Image Generation** — 프롬프트로 이미지를 생성해요.
- **Action 2**: **AI Analyze Image** — 이전 액션의 **Image URL** 결과를 써요. 프롬프트는 "이 이미지를 자세히 설명해 줘."로 해요.
- **Action 3**: **If/Else**(조건 분기) 또는 **Internal Notification**(내부 알림) — 설명 내용에 따라 워크플로우를 나누거나, 팀에 보내서 발송 전에 간단히 확인받아요.

### 3. 웹훅으로 들어온 상품 이미지 설명하기

시나리오: 외부 시스템에서 상품 이미지가 들어오는데, 설명 문구는 함께 오지 않아요. 이미지마다 설명을 자동으로 만들고 싶어요.

구성:

- **Trigger**: **Inbound Webhook**(인바운드 웹훅) — 이미지 URL을 함께 받아요.
- **Action 1**: **AI Analyze Image** — 프롬프트는 "이 상품 이미지를 색상, 소재, 스타일을 포함해 자세히 설명해 줘."로 해요.
- **Action 2**: **Outbound Webhook**(아웃바운드 웹훅) — 만든 설명을 상품 카탈로그나 콘텐츠 시스템으로 다시 보내요.

더 많은 활용 아이디어:

- 스크린샷 분류: 고객지원 스크린샷에서 오류 메시지를 읽어 내용별로 티켓을 자동 분류해요.
- 대체 텍스트 생성: 사이트와 캠페인에 쓰는 이미지에 접근성 설명을 만들어요.
- 이미지 태그 지정: 모델에게 카테고리나 키워드를 짧은 목록으로 받아서, 연락처에 태그를 달거나 워크플로우를 나눌 때 써요.
- 제출물 확인: 업로드된 이미지에 요청한 내용이 담겨 있는지 확인한 뒤 다음 단계로 넘겨요.

## 더 좋은 결과를 얻는 팁

- 원하는 결과를 구체적으로 적으세요. "인보이스 번호만 알려 줘"라고 하면 바로 쓸 수 있는 값이 나와요. "이 이미지에 대해 알려 줘"라고 하면 직접 정리해야 하는 문단이 나와요.
- 작은 글씨, 깨알 같은 문구, 내용이 빽빽한 문서에는 **High**를 쓰세요. 일반적인 설명에는 **Auto**로 충분해요.
- 게시하기 전에 이미지 URL이 공개적으로 열리는지 확인하세요. 액션이 실패하는 가장 흔한 원인이에요.
- 결과를 커스텀 필드에 저장할 계획이라면, 프롬프트에서 값을 일정한 형식으로 돌려 달라고 요청하세요. 그러면 뒤 단계에서 믿고 쓸 수 있어요.
- 워크플로우를 대량으로 실행하기 전에 실제 이미지 몇 개로 먼저 테스트하세요. 이미지는 텍스트 입력보다 품질 차이가 커요.

## 가격

이미지 분석은 실행 1회당 요금이 부과돼요. 아래 금액은 이미지 1장을 분석할 때 보통 얼마가 드는지 가늠할 수 있게 해 줘요. 대부분의 분석이 이 범위 안에 들어와요.

{% hint style="info" %}
아래 금액은 고정 요금이 아니라 예산을 잡기 위한 예상치로 봐 주세요.
{% endhint %}

| 구분 | 분석 1회당 비용 | 센트 환산 |
| --- | --- | --- |
| 중앙값 | $0.0004 | 0.04¢ |
| 평균 | $0.0013 | 0.13¢ |

실제 분석 비용은 액션 설정에 따라 달라져요. 주요 요인은 다음과 같아요.

- **Model**: 선택한 비전 모델
- **Detail Level**: 설정한 수준(**Auto**, **High**, **Low**). **High**는 이미지를 더 꼼꼼히 분석하고, **Low**보다 비용이 더 들어요.

## 자주 묻는 질문

### 이미지를 분석하는 데 비용이 얼마나 드나요?

이미지 1장을 분석하는 데 보통 $0.0004(0.04¢)에서 $0.0013(0.13¢) 사이가 들어요. 실제 비용은 선택한 모델과 **Detail Level**에 따라 달라져요. 자세한 내용은 위 '가격' 섹션을 참고하세요.

### 이미지 URL이 로그인해야 열리는 주소면 어떻게 되나요?

액션이 작동하지 않아요. AI 모델이 URL에서 이미지를 직접 가져오기 때문에, 로그인·토큰·권한 확인 없이 공개적으로 접근할 수 있는 URL이어야 해요. 시크릿 브라우저 창에서 URL을 열어, 누구에게나 이미지가 열리는지 확인해 보세요.

### 이미지 URL은 어디에서 가져오나요?

워크플로우에서 이미지 URL을 만들어 내는 이전 단계에서 가져와요. 예를 들면 **AI Image Generation** 액션의 **Image URL** 결과, 인바운드 웹훅 페이로드, 메시지 첨부 파일이 있어요. 이미지 URL을 저장해 둔 커스텀 값에서도 가져올 수 있어요.

### 어떤 모델을 골라야 하나요?

비전 모델은 GPT-5.6 Luna와 GPT-5.6 Tera, 두 가지예요. 잘 모르겠다면 같은 이미지와 프롬프트를 두 모델에 모두 실행해 보세요. 결과를 비교한 뒤 워크플로우를 게시하면 돼요.

### Detail Level 설정은 무엇에 영향을 주나요?

이미지를 얼마나 꼼꼼히 분석할지 정해요. **Auto**(기본값)는 시스템이 알아서 정해요. **High**는 이미지를 더 자세히 살펴서 작은 글씨나 세부 내용에 도움이 돼요. **Low**는 더 빠르고 가볍게 분석하는 방식으로, 대략적인 설명에 알맞아요.

### 이 액션으로 이미지에서 글자를 추출(OCR)할 수 있나요?

네. 프롬프트를 "이 이미지에 보이는 글자를 모두 추출해 줘"처럼 쓰면, 액션이 글자를 결과로 돌려줘요. 영수증, 인보이스처럼 글씨가 작거나 빽빽한 이미지는 **Detail Level**을 **High**로 설정하세요.

### 결과는 어떤 형식으로 나오나요?

프롬프트에 대한 AI의 답이 담긴 텍스트 값이에요. 뒤에 오는 액션에서 커스텀 값 선택기의 **AI Analyze Image** 아래에서 고를 수 있어요. 텍스트 값을 받는 곳이면 어디든 쓸 수 있어요.

### AI Image Generation 액션과 함께 쓸 수 있나요?

네. **AI Image Generation** 단계 뒤에 **AI Analyze Image**를 추가하고, 생성된 **Image URL**을 넘겨 주세요. 이미지를 다음 단계로 보내기 전에 만들어진 이미지를 설명하거나 확인할 수 있어요. **AI Image Generation**이 만든 이미지는 공개 URL에 저장되기 때문에 따로 설정할 필요가 없어요.

### 액션 하나로 이미지를 여러 장 분석할 수 있나요?

**AI Analyze Image** 액션 하나는 이미지 URL 하나만 처리해요. 이미지 여러 장을 분석하려면 이미지마다 액션을 따로 추가하고, 뒤 단계에서 각 액션의 결과를 따로 가져다 쓰세요.
