# 워크플로우의 AI 이미지 분석 액션이란?

AI 이미지 분석(AI Analyze Image) 액션은 워크플로우(Workflows)의 AI 액션(AI Actions) 항목에서 사용할 수 있으며, AI 비전 모델을 사용해 이미지를 분석하고 텍스트 결과를 반환해요. 이미지 URL과 AI가 무엇을 찾아야 하는지 설명하는 프롬프트를 입력하면, 액션이 분석 결과를 텍스트로 반환하고 이를 후속 액션에서 활용할 수 있어요.

이 기능은 이미지에서 텍스트를 추출(OCR)하거나, 이미지 설명을 생성하거나, 객체나 속성을 식별하거나, 이미지 콘텐츠를 검증할 때 유용해요. 즉, 워크플로우가 이미지를 단순히 전달만 하는 게 아니라 시각적 입력을 실제로 해석할 수 있게 해줘요.

## AI 이미지 분석 액션의 주요 장점

- **텍스트 추출(OCR):** 스크린샷, 영수증, 문서 등 이미지 기반 콘텐츠에서 텍스트를 추출해서 워크플로우 데이터로 활용할 수 있어요.

- **이미지 설명:** 이미지에 담긴 내용을 상세하게 설명해줘요. 카탈로그 작성, 대체 텍스트(alt text), 콘텐츠 요약 등에 유용해요.

- **유연한 프롬프트:** 이미지에 대해 원하는 것은 무엇이든 AI에게 물어볼 수 있어요. 프롬프트로 AI가 무엇을 찾고 어떻게 응답할지 정확하게 제어할 수 있어요.

- **분석 상세도 조절:** 이미지를 얼마나 꼼꼼하게 분석할지 선택할 수 있어요. 정확도와 속도 사이에서 균형을 맞출 수 있어요.

- **이미지 생성 기능과 연계:** AI 이미지 생성(AI Image Generation) 액션과 결합하여, 방금 워크플로우에서 만든 이미지를 설명하거나 검증할 수 있어요.

## 액션 세부 정보

| 필드 | 설명 |
|---|---|
| **액션 이름(Action Name)** | 워크플로우 캔버스와 실행 로그에서 액션을 식별하기 위한 사용자 지정 이름이에요. |
| **모델(Model)** | 분석에 사용할 AI 비전 모델이에요. GPT-5.6 Luna와 GPT-5.6 Tera 두 가지 모델을 사용할 수 있어요. |
| **이미지 URL(Image URL)** | 분석할 이미지의 URL이에요. 이전 단계의 결과값이나 커스텀 값(Custom Value)에서 가져올 수 있어요. URL은 반드시 외부에서 공개적으로 접근 가능해야 해요. 자세한 내용은 아래 이미지 URL 요구 사항을 참고하세요. |
| **분석 프롬프트(Analysis Prompt)** | AI에게 이미지에서 무엇을 찾고 어떻게 응답해야 하는지 알려주는 지시사항이에요. 동적인 프롬프트 작성을 위해 커스텀 값을 지원해요. |
| **상세도(Detail Level)** | 이미지를 얼마나 꼼꼼하게 분석할지 설정해요. 기본값은 Auto(자동)이며, High(높음) 또는 Low(낮음)로 설정할 수 있어요. |

## AI 이미지 분석 액션 사용 방법

### 1단계: 액션 추가하기

- **Automation(자동화)** > **Workflows(워크플로우)** 메뉴로 이동해요.

- 새 워크플로우를 **생성**하거나 기존 워크플로우를 **편집**해요.

![](https://jumpshare.com/share/sdAZAU36nE7nJWCjV65F+/Screen+Shot+2026-08-26+at+16.44.40.png)

- 워크플로우에서 **+** 아이콘을 클릭해 새 액션을 **추가**하고, **AI 액션(AI Actions)** 항목에서 AI 이미지 분석(AI Analyze Image)을 찾아 선택해요. 캔버스에서 쉽게 구분할 수 있도록 액션에 명확하고 설명적인 이름을 지정해주세요.

![](https://jumpshare.com/share/kQLCL5FaVCUr4s1hKvvY+/GIF+Recording+2026-08-28+at+17.26.42.gif)

### 2단계: 모델 선택하기

분석에 사용할 AI 비전 모델을 선택해요. 다음 두 가지 모델을 사용할 수 있어요:

- GPT-5.6 Luna
- GPT-5.6 Tera

어떤 모델을 사용해야 할지 잘 모르겠다면, 워크플로우를 발행하기 전에 동일한 이미지와 프롬프트로 두 모델을 모두 실행해서 결과를 비교해보세요.

![](https://jumpshare.com/share/U2OY2Fou3rn6EuItyWye+/Screenshot+2026-08-28+at+17.34.07.png)

### 3단계: 이미지 URL 입력하기

분석하고 싶은 이미지의 **URL**을 입력해요.

이 값은 워크플로우의 이전 단계에서 가져올 수 있어요. 예를 들어 [AI 이미지 생성(AI Image Generation) 액션](https://hyperclass.gitbook.io/hyperclass-docs/en/support/solutions/articles/155000008497)의 Image URL 결과값을 사용하거나, 이미지 URL을 저장해둔 커스텀 값을 사용할 수 있어요. URL은 반드시 외부에서 공개적으로 접근 가능해야 해요.

![](https://jumpshare.com/share/Z8S6ZdH2R7fdMm7vr2Ht+/GIF+Recording+2026-08-28+at+17.48.19.gif)

### 4단계: 분석 프롬프트 입력하기

AI에게 이미지에서 무엇을 찾고 어떻게 응답해야 하는지 알려주는 프롬프트를 작성해요. 프롬프트가 구체적일수록 더 유용한 결과를 얻을 수 있어요.

예시:

- 이 상품 이미지를 자세히 설명해줘.
- 이 이미지에서 보이는 모든 텍스트를 추출해줘.
- 이 사진에 보이는 항목을 나열해줘.
- 이 영수증에서 총액을 읽어서 숫자만 반환해줘.

프롬프트 필드는 커스텀 값을 지원하므로, 연락처 필드, 웹훅 데이터, 이전 액션의 결과값을 활용해 동적으로 프롬프트를 구성할 수 있어요.

![](https://jumpshare.com/share/BrqlEWMFrFuZdOoyfJrw+/Screen+Shot+2026-08-28+at+17.54.02.png)

### 5단계: 상세도 설정하기

이미지를 **얼마나 꼼꼼하게** 분석할지 선택해요.

기본값은 **Auto(자동)**이며, 시스템이 적절한 수준을 자동으로 선택해요. 세부적인 요소를 좀 더 정밀하게 분석하고 싶다면 **High(높음)**를 선택하고, 이미지를 전체적으로 빠르게 훑어보는 정도면 충분할 때는 **Low(낮음)**를 선택하세요.

![](https://jumpshare.com/share/NZGbmcfO6bnZOzWBZtoU+/Screenshot+2026-08-28+at+18.01.36.png)

### 6단계: 액션 저장하기

액션을 저장해요. 워크플로우가 실행되면 분석 결과값이 모든 후속 액션에서 변수로 사용 가능해져요.

![](https://jumpshare.com/share/b5dO4SBiQDmZxj1Kcu7t+/Screen+Shot+2026-08-28+at+18.05.31.png)

## 이미지 URL 요구 사항

입력하는 이미지 URL은 반드시 외부에서 공개적으로 접근 가능해야 해요. AI 모델이 URL에서 이미지를 직접 가져오기 때문에, 익명 접근을 차단하는 URL은 액션 실행이 실패해요.

팁: 시크릿 모드(비공개 브라우징) 창에서 URL을 열어보는 것으로 간단하게 확인할 수 있어요. 로그인 없이 이미지가 로드되면 액션도 정상적으로 접근할 수 있어요. 미디어 스토리지(Media Storage)에 저장된 이미지(AI 이미지 생성 액션으로 만든 이미지 포함)는 이미 공개적으로 접근 가능한 URL에 호스팅되어 있어서 별도 설정 없이 바로 사용할 수 있어요.

즉, URL은 다음 조건에 해당하면 안 돼요:

- 조회를 위해 로그인, 비밀번호, 인증 토큰이 필요한 경우

- 비공개 공유 링크, 권한이 제한된 드라이브, 또는 내부 네트워크 뒤에 있는 경우

- 이미지 파일 자체가 아니라 이미지가 포함된 페이지를 가리키는 경우

## 후속 액션에서 결과값 사용하기

액션이 실행되면, 그 응답값은 AI 이미지 분석(AI Analyze Image) 항목 아래의 커스텀 값 선택기를 통해 이후의 모든 액션에서 사용할 수 있어요. **결과값은 프롬프트에 대한 AI의 답변을 담은 텍스트 값**이에요. 설명, 추출된 텍스트, 목록 등 프롬프트에서 요청한 내용에 따라 달라져요.

결과값이 일반 텍스트이기 때문에, 텍스트 값을 사용할 수 있는 곳이라면 어디든 활용할 수 있어요. 연락처 커스텀 필드에 저장하거나, 이메일이나 SMS에 포함하거나, 아웃바운드 웹훅으로 전달하거나, 추가 처리를 위해 다른 AI 액션에 입력할 수 있어요.

![](https://jumpshare.com/share/iUgQiDneO23xj0y0qbfR+/GIF+Recording+2026-08-28+at+18.16.48.gif)

## 사용 사례

### 1. 고객이 제출한 이미지에서 텍스트 추출하기

**시나리오:** 고객이 MMS로 영수증, 인보이스, 문서 사진을 보내와요. 이런 이미지에서 텍스트를 읽어내서 연락처 레코드에 저장하고 싶고, 매번 직접 확인하고 싶지는 않아요.

**설정:**

- **트리거:** 고객 응답(Customer Replied) (이미지 첨부 포함)

- **액션 1:** AI 이미지 분석 – 첨부 파일에서 이미지 URL 가져오기. 프롬프트: "이 이미지에서 보이는 모든 텍스트를 추출해줘." 상세도: High(높음)

- **액션 2:** 연락처 업데이트 – 추출한 텍스트를 검토 또는 후속 작업을 위해 커스텀 필드에 저장

## 2. 생성된 이미지 검증하기

**시나리오:** 워크플로우에서 AI 이미지 생성(AI Image Generation) 액션으로 이미지를 만들고, 고객에게 전달되기 전에 실제로 어떤 이미지가 생성됐는지 한 번 더 확인하고 싶어요.

**설정:**

- **액션 1:** AI 이미지 생성 – 프롬프트로부터 이미지 생성

- **액션 2:** AI 이미지 분석 – 이전 액션의 Image URL 결과값 사용. 프롬프트: "이 이미지를 자세히 설명해줘."

- **액션 3:** 조건 분기(If/Else) 또는 내부 알림(Internal Notification) – 설명 내용에 따라 워크플로우를 분기하거나, 전달 전 팀에 빠른 검토를 요청

### 3. 웹훅으로 받은 상품 이미지 설명하기

**시나리오:** 외부 시스템에서 상품 이미지가 들어오는데 별도의 설명 텍스트가 없어요. 각 이미지에 대해 자동으로 설명 텍스트를 생성하고 싶어요.

**설정:**

- **트리거:** 인바운드 웹훅(Inbound Web-hook) (이미지 URL 포함)

- **액션 1:** AI 이미지 분석 – 프롬프트: "이 상품 이미지를 색상, 소재, 스타일을 포함해서 자세히 설명해줘."

- **액션 2:** 아웃바운드 웹훅(Outbound Web-hook) – 생성된 설명을 카탈로그 또는 콘텐츠 시스템으로 전송

**더 많은 아이디어**

- **스크린샷 분류:** 고객지원 스크린샷에서 오류 메시지를 읽어내서, 수동이 아니라 내용에 따라 티켓을 자동 분류할 수 있어요.

- **대체 텍스트(alt text) 생성:** 사이트와 캠페인에서 사용하는 이미지에 대한 접근성 설명 텍스트를 생성할 수 있어요.

- **이미지 태깅:** AI에게 카테고리나 키워드를 짧게 나열해달라고 요청한 다음, 그 결과값으로 연락처에 태그를 달거나 워크플로우를 분기할 수 있어요.

- **제출물 확인:** 업로드된 이미지가 요청한 내용을 실제로 담고 있는지 다음 단계로 넘어가기 전에 확인할 수 있어요.

## 더 나은 결과를 위한 팁

- 원하는 결과물이 무엇인지 구체적으로 명시하세요. "인보이스 번호만 반환해줘"라고 하면 바로 사용 가능한 값을 얻을 수 있지만, "이 이미지에 대해 알려줘"라고 하면 직접 해석해야 하는 문단이 나와요.

- 작은 텍스트, 세밀한 인쇄물, 밀도 높은 문서에는 High(높음) 상세도를 사용하세요. 일반적인 설명에는 Auto(자동)로도 충분해요.

- 발행하기 전에 이미지 URL이 외부에서 접근 가능한지 확인하세요. 이것이 액션 실패의 가장 흔한 원인이에요.

- 결과값을 커스텀 필드에 저장할 계획이라면, 프롬프트에서 일관된 형식으로 값을 반환하도록 요청해서 후속 단계에서 안정적으로 활용할 수 있게 하세요.

- 대량으로 워크플로우를 실행하기 전에 실제 이미지 몇 개로 먼저 테스트해보세요. 이미지 품질은 텍스트 입력보다 편차가 훨씬 커요.

## 자주 묻는 질문

**Q: 이미지 URL이 인증이 필요한 상태면 어떻게 되나요?**

액션이 작동하지 않아요. AI 모델은 URL에서 이미지를 직접 가져오기 때문에, 로그인이나 토큰, 권한 확인 없이 외부에서 공개적으로 접근 가능해야 해요. 시크릿 모드 브라우저 창에서 URL을 열어서 아무나 접근 가능한지 확인해보세요.

**Q: 이미지 URL은 어디서 가져오나요?**

이미지 URL 결과값을 생성하는 워크플로우의 이전 단계에서 가져올 수 있어요. 예를 들어 AI 이미지 생성 액션의 Image URL 결과값, 인바운드 웹훅 페이로드, 메시지 첨부 파일, 또는 이미지 URL을 저장해둔 커스텀 값 등을 활용할 수 있어요.

**Q: 어떤 모델을 선택해야 하나요?**

GPT-5.6 Luna와 GPT-5.6 Tera, 두 가지 비전 모델을 사용할 수 있어요. 어떤 모델을 선택해야 할지 확신이 서지 않는다면, 워크플로우를 발행하기 전에 동일한 이미지와 프롬프트로 두 모델을 모두 실행해서 결과를 비교해보세요.

**Q: 상세도(Detail Level) 설정은 무엇에 영향을 주나요?**

이미지를 얼마나 꼼꼼하게 분석할지를 결정해요. Auto(자동, 기본값)는 시스템이 알아서 판단하게 해요. High(높음)는 이미지를 더 정밀하게 살펴보기 때문에 작은 텍스트나 세밀한 요소를 파악하는 데 도움이 돼요. Low(낮음)는 더 빠르고 가볍게 처리하며, 전체적인 설명에 적합해요.

**Q: 이 기능으로 이미지에서 텍스트를 추출(OCR)할 수 있나요?**

네, 가능해요. 프롬프트를 "이 이미지에서 보이는 모든 텍스트를 추출해줘"와 같이 설정하면 액션이 텍스트를 결과값으로 반환해요. 영수증, 인보이스처럼 텍스트가 작거나 밀도가 높은 경우에는 상세도를 High(높음)로 설정하세요.

**Q: 결과값은 어떤 형식인가요?**

결과값은 프롬프트에 대한 AI의 응답을 담은 텍스트 값이에요. AI 이미지 분석(AI Analyze Image) 항목 아래의 커스텀 값 선택기를 통해 후속 액션에서 사용할 수 있으며, 텍스트 값을 사용할 수 있는 어디에나 활용할 수 있어요.

**Q: AI 이미지 생성(AI Image Generation) 액션과 함께 사용할 수 있나요?**

네, 가능해요. AI 이미지 생성 단계 다음에 AI 이미지 분석을 추가하고, 생성된 Image URL을 전달하면 돼요. 이렇게 하면 이미지가 다음 단계로 전달되기 전에 생성된 결과물을 설명하거나 검증할 수 있어요. AI 이미지 생성으로 만든 이미지는 공개적으로 접근 가능한 URL에 저장되므로 별도 설정이 필요 없어요.

**Q: 하나의 액션에서 여러 개의 이미지를 분석할 수 있나요?**

각 AI 이미지 분석 액션은 하나의 이미지 URL만 처리해요. 워크플로우에서 여러 이미지를 분석하려면 각각에 대해 별도의 액션을 추가하고, 후속 단계에서 각 액션의 결과값을 개별적으로 참조하면 돼요.
