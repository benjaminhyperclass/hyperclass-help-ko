# AI Agent 액션의 Web search(웹 검색) 사용하기

**AI Agent**(AI 에이전트) 액션에서 **Web search**(웹 검색)를 켜면 워크플로우가 실행되는 중에 에이전트가 인터넷에서 정보를 찾아 쓸 수 있어요. 이 문서에서는 웹 검색을 켜는 방법, 에이전트가 참고할 웹사이트 URL을 안내하는 방법, 검색 요금을 설명해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## AI Agent 액션의 Web search란?

하이퍼클래스 워크플로우의 AI Agent 액션은 [워크플로우 액션 – AI Agent](workflow-action-ai-agent.md) 문서에서 자세히 볼 수 있어요. 웹 검색을 켜면 에이전트가 실행 중에 최신 정보를 찾아보고, **Instructions**(에이전트 지침)에 적어 둔 웹사이트를 참고해서 작업을 처리해요.

가격, 리베이트, 공공 프로그램처럼 자주 바뀌는 정보를 다룰 때 특히 유용해요.

**Web search**는 AI Agent 액션의 **Built-in tools**(기본 제공 도구) 안에 있어요. 켜 두면 에이전트는 추가 정보가 필요할 때만 검색해요.

## Web search의 장점

지침에 모든 내용을 일일이 업데이트하지 않아도 에이전트가 필요한 정보를 가져올 수 있어요.

- 최신 정보: 인터넷에서 최신 가격, 프로그램, 공개 정보를 검색해요.
- 더 적절한 답변: 찾아온 정보로 상황에 맞는 답변을 준비해요.
- 선호하는 출처 지정: 지침에 웹사이트 URL을 넣어 에이전트가 참고할 곳을 안내할 수 있어요.
- 자동 검색: 검색이 필요한지는 에이전트가 판단해요.
- 워크플로우 연계: 웹 검색을 Send email, Send SMS 같은 도구와 함께 쓸 수 있어요.
- 사용량 기준 요금: 검색한 만큼만 비용을 내요.

## AI Agent 액션의 기본 제공 도구

기본 제공 도구는 직접 설정해서 추가하는 도구와 별개로, AI Agent 액션 안에 처음부터 들어 있는 기능이에요. **Tools**(도구) 아래에 **Built-in tools** 섹션이 있고, 다음 항목이 들어 있어요.

- **Web search**: 인터넷 검색을 켜거나 꺼요.
- **Information icon (i)**(정보 아이콘): 마우스를 올리면 도구 설명이 보여요.
- **Crown icon**(왕관 아이콘): 마우스를 올리면 프리미엄 도구 비용이 보여요.

{% hint style="warning" %}
**Web search**는 정보를 찾아오기만 해요. 혼자서 메시지를 보내거나 CRM 기록을 업데이트할 수는 없어요. 이런 작업에는 해당 액션 도구가 필요해요.
{% endhint %}

## Web search가 동작하는 방식

웹 검색을 켜면 AI 에이전트가 워크플로우 실행 중에 필요할 때마다 외부 정보를 가져와요.

1. 워크플로우 트리거가 AI Agent 액션을 시작해요.
2. 에이전트가 **Instructions**와 이미 가진 정보를 살펴봐요.
3. 추가 정보가 필요하면 인터넷에서 검색해요.
4. 찾아온 정보를 활용해 작업을 이어 가요.
5. 필요하면 설정된 도구로 액션을 실행해요.

예를 들어 냉난방 업체의 에이전트가 고객에게 답하기 전에 현재 히트펌프 리베이트를 검색할 수 있어요.

{% hint style="info" %}
실행할 때마다 검색하는 것은 아니에요. 한 번 실행하는 동안 여러 번 검색할 수도 있어요.
{% endhint %}

## 에이전트 지침에 웹사이트 URL 넣기

**Instructions**에 URL을 넣으면 공식 웹사이트나 공개 자료 같은 선호 출처를 참고하도록 안내할 수 있어요.

**지침 예시:**

> 당신은 냉난방 업체의 신규 리드에게 후속 연락을 하는 에이전트입니다. 리드가 히트펌프 리베이트를 물어보면 답변하기 전에 <https://www.energystar.gov/rebate-finder>를 확인하세요. 추가 정보가 필요하면 웹에서 검색하세요. 리베이트 금액이나 자격 요건을 지어내지 마세요. 확인할 수 없는 정보는 확인이 필요하다고 안내하세요.

이 지침은 에이전트에게 언제 검색할지, 어떤 출처를 볼지, 불확실한 정보는 어떻게 다룰지를 알려 줘요.

{% hint style="info" %}
URL은 에이전트가 참고할 출처를 안내할 뿐이에요. 해당 웹사이트에 접속할 수 있다는 것도, 정보를 빠짐없이 가져온다는 것도 보장하지 않아요.
{% endhint %}

## Web search와 Search Knowledge Base 비교

두 기능 모두 정보를 찾아오지만 찾는 곳이 달라요. 차이를 알면 알맞은 도구를 고르기 쉬워요.

| **Web search** | **Search Knowledge Base**(지식 베이스 검색) |
| --- | --- |
| 인터넷에서 검색해요 | 선택한 하이퍼클래스 지식 베이스에서 검색해요 |
| 자주 바뀌는 공개 정보에 알맞아요 | 저장해 둔 비즈니스 정보에 알맞아요 |
| **Built-in tools**에서 켜요 | **Tools**에서 추가해요 |
| 예: 최신 리베이트 | 예: 회사 정책, 자주 묻는 질문 |

두 기능을 함께 쓰면 서로 보완돼요. 지식 베이스 도구가 답변하는 방식은 [AI 에이전트가 지식 베이스 도구로 고객 문의에 답하는 방법](../../13-AI-Employee/Agent-Studio/how-ai-agents-use-the-knowledge-base-tool-to-answer-customer-inquiries.md) 문서에서 볼 수 있어요.

{% hint style="warning" %}
워크플로우 AI Agent 액션의 **Web search**는 에이전트 스튜디오의 **웹 검색** 도구와 달라요. 에이전트 스튜디오의 도구는 별도로 설정해야 해요. 자세한 내용은 [에이전트 스튜디오에서 웹 검색 도구로 실시간 답변하기](../../13-AI-Employee/Agent-Studio/how-to-use-web-search-tool-in-agent-studio-for-real-time-responses.md) 문서를 참고하세요.
{% endhint %}

## Web search 요금

웹 검색은 프리미엄 기능이에요. 검색 한 번마다 요금이 부과되고, 기존 AI Agent 액션 요금에 추가돼요.

| 모델 제공업체 | 검색 1회당 비용 |
| --- | --- |
| OpenAI | $0.01 (1센트) |
| Claude | $0.01 (1센트) |
| Gemini | $0.014 (1.4센트) |

**예시:** OpenAI 모델로 3번 검색하면 웹 검색 추가 요금은 $0.03이에요. Gemini로 3번 검색하면 $0.042예요.

- 검색은 한 번마다 따로 요금이 부과돼요.
- 한 번 실행하는 동안 여러 번 검색하면 그만큼 요금이 부과돼요.
- 검색하지 않은 실행에는 웹 검색 추가 요금이 없어요.

## AI Agent 액션에서 Web search 설정하기

웹 검색을 켜면 에이전트가 워크플로우 실행 중에 외부 정보를 가져올 수 있어요. 지침을 분명하게 쓰고, 작업에 필요한 다른 도구도 함께 설정하세요.

1. 하이퍼클래스 서브 계정에서 **자동화 > 워크플로우**로 이동하세요.
2. 워크플로우를 만들거나 열고, 알맞은 트리거를 설정하세요.
3. **AI Agent** 액션을 추가하거나 기존 액션을 여세요.
4. **Instructions**를 입력하고 AI **Model**(모델)을 선택하세요.
5. **Tools** 아래의 **Built-in tools**를 펼치세요.
6. **Web search**를 켜세요.
7. 
8. (선택) **Instructions**에 선호하는 웹사이트 URL을 추가하세요.
9. (선택) Send email, Send SMS 같은 도구를 추가로 설정하세요.
10. **Save action**(작업 저장)을 클릭하세요.
11. 최신 정보가 필요한 질문으로 워크플로우를 테스트하세요.

실행한 뒤에는 **Execution Logs**(실행 로그)에서 에이전트의 활동을 확인할 수 있어요. 확인할 수 있는 실행 추적, 도구 호출, 입력, 출력, 토큰 사용량을 볼 수 있어요. 자세한 내용은 [워크플로우 개선된 실행 로그 및 등록 내역](../시작하기/workflows-improved-execution-logs-enrollment-history.md) 문서를 참고하세요.

### 예시: 고객의 리베이트 질문에 답하기

냉난방 업체가 AI 에이전트로 견적 요청 고객에게 후속 연락을 하고, 히트펌프 리베이트 질문에도 답하려고 해요.

**Instructions:**

> 견적을 요청한 신규 리드에게 이메일과 SMS로 감사 인사를 전하세요. 리드가 히트펌프 리베이트를 물어보면 <https://www.energystar.gov/rebate-finder>를 확인하세요. 필요하면 인터넷에서 추가 정보를 검색하세요. 자격 요건이나 리베이트 금액은 확인되지 않은 내용을 말하지 마세요. 팀과 통화할 수 있는 시간을 제안하세요.

**Tools:** Send email, Send SMS

**Built-in tools:** **Web search** 켜짐

에이전트는 관련 리베이트 정보를 찾아 답변을 준비하고, 설정된 도구로 메시지를 보낼 수 있어요.

## 자주 묻는 질문

### 워크플로우가 실행될 때마다 Web search도 실행되나요?
아니요. 에이전트가 추가 정보가 필요하다고 판단할 때만 검색해요.

### 한 번 실행하는 동안 여러 웹사이트를 검색할 수 있나요?
네. 여러 번 검색할 수 있고, 검색마다 따로 요금이 부과돼요.

### 지정한 웹사이트에 접속할 수 없으면 어떻게 되나요?
이때의 동작은 보장되지 않아요. 에이전트에게 정보를 지어내지 말고, 확인할 수 없는 내용은 확인이 필요하다고 알리도록 지침에 적어 두세요.

### 특정 웹사이트에서만 검색하도록 제한할 수 있나요?
**Instructions**에 선호하는 URL을 넣을 수는 있어요. 하지만 이 기능에서 특정 도메인으로 엄격하게 제한하는 방법은 안내된 바 없어요.

### Web search로 CRM 기록을 업데이트하거나 메시지를 보낼 수 있나요?
혼자서는 할 수 없어요. 에이전트에 해당 도구를 설정해야 해요.

### Web search가 Search Knowledge Base를 대신할 수 있나요?
완전히 대신하지는 못해요. **Web search**는 외부 정보를 가져오고, **Search Knowledge Base**는 저장해 둔 비즈니스 정보를 가져와요.

### Web search 요금이 AI Agent 액션 요금에 포함되어 있나요?
아니요. 검색 요금은 AI Agent 액션 요금과 별도로 부과돼요.

### 실행할 때마다 검색 결과가 달라지는 이유는 뭔가요?
웹사이트 내용, 검색 결과, 출처 접근 여부, 검색어가 바뀔 수 있기 때문이에요. 지침을 분명하게 쓰고 선호 출처를 지정하면 결과가 더 일정해져요.
