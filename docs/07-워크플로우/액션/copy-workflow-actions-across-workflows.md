# 워크플로우 간 액션 복사하기

하이퍼클래스에서는 같은 서브 계정 안의 다른 워크플로우로 액션 하나, 또는 여러 액션을 묶어서 복사할 수 있어요. 클릭 한 번으로 붙여넣을 수 있어서, 똑같은 설정을 처음부터 다시 만들 필요가 없어요.

## 워크플로우 간 액션 복사란?

기존 단계를 같은 서브 계정 안의 다른 워크플로우로 복제하는 기능이에요. 액션 하나만 복사해도 되고, 이어진 여러 액션을 한 번에 복사해도 돼요. 반복 설정이 줄어들고, 여러 프로젝트에서 자동화 기준을 일정하게 맞추기 쉬워요.

## 워크플로우 간 액션 복사의 장점

- 속도: 미리 설정해 둔 단계를 처음부터 만들지 않고 몇 초 만에 붙여넣을 수 있어요.
- 여러 번 붙여넣기: 복사한 액션은 15분 동안 여러 워크플로우에 계속 붙여넣을 수 있어요.
- 일관성: 이름, 설정, 로직을 워크플로우마다 똑같이 유지해 실수를 줄일 수 있어요.
- 탭 간 복사: 한 탭에서 복사하고 다른 탭에서 붙여넣어도 작업하던 위치를 잃지 않아요.
- 같은 서브 계정 범위: 이메일, 폼 같은 자산이 같은 환경에 있어서 호환 문제가 생기지 않아요.
- 낮은 오류 위험: 이미 검증된 단계에서 시작하고, 달라지는 부분만 고치면 돼요.

## 워크플로우 간 액션 복사 사용 방법

복사할 위치와 붙여넣는 방법을 순서대로 안내해요.

1. **자동화 > 워크플로우**를 여세요.
2. 복사할 액션이 있는 워크플로우를 선택하고, 재사용할 액션을 찾으세요.
3. 해당 액션의 점 세 개 메뉴를 클릭하세요.
4. 아래 중 하나를 선택하세요.
   - **Copy Action**(액션 복사): 해당 액션 하나만 복사해요.
   - **Copy All Actions From Here**(여기서부터 모든 액션 복사): 선택한 액션부터 이어지는 액션 묶음을 복사해요.

   ![액션의 점 세 개 메뉴에서 복사 옵션을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052094641/original/fn5HsFGRNeAtjoG4W5R-med1BeXisJdtUw.png?1755785648)

5. 붙여넣을 워크플로우로 이동하세요. 같은 탭이어도 되고, 같은 서브 계정 안의 다른 탭이어도 돼요.
6. 아래 두 방법 중 하나로 붙여넣으세요.
   - 새 액션을 추가하는 **+** 버튼 옆의 **Quick Paste**(빠른 붙여넣기)를 클릭하세요.

     ![+ 버튼 옆의 Quick Paste 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052094723/original/m54deH56wAwIcqEEVybb_sibNN9X8xxEpg.png?1755785705)

   - 또는 아무 액션이나 점 세 개 메뉴를 열고 **Paste Below**(아래에 붙여넣기)를 선택하세요.

     ![액션의 점 세 개 메뉴에서 Paste Below를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052795534/original/CKIGsJ1Ic1ggf5D0RB629-ODjMzTzT7mXw.png?1756721355)

7. 붙여넣은 액션의 자산과 로직이 올바른지 확인한 뒤 **Save**(저장)를 클릭하세요.

   ![붙여넣은 액션을 확인하고 Save를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052116340/original/jPTujJ_4cupbqbaoGsySSOEiCIAB5za8ng.png?1755796215)

## 클립보드와 보관 규칙

- 복사한 액션은 15분 동안 붙여넣을 수 있어요.
- 이 시간 안에는 여러 번 붙여넣을 수 있어요. 같은 서브 계정 안의 다른 워크플로우에도 붙여넣을 수 있어요.
- 15분이 지나면 붙여넣기 옵션을 눌러도 복사한 내용이 들어가지 않아요. 계속 작업하려면 다시 복사하세요.
- 탭을 오가며 작업할 수 있어요. 단, 로그인한 상태와 같은 서브 계정을 유지해야 해요.

## 자주 묻는 질문

### 여러 액션을 한 번에 복사할 수 있나요?
네. **Copy All Actions From Here**를 사용하면 선택한 액션부터 이어지는 액션 묶음을 복사할 수 있어요.

### 다른 탭에서 붙여넣을 수 있나요?
네. 15분 안에, 같은 서브 계정 안이라면 한 탭에서 복사하고 다른 탭에서 붙여넣을 수 있어요.

### 트리거도 같이 복사되나요?
아니요. 액션을 복사해도 트리거는 포함되지 않아요. 트리거를 재사용하려면 [워크플로우에서 트리거 복사 또는 삭제하기](../트리거/copy-or-delete-triggers-in-workflows.md)의 트리거 복제 기능을 사용하세요.

### 이메일, 폼, 캘린더 같은 자산 참조도 그대로 유지되나요?
해당 자산이 같은 서브 계정에 있으면 참조가 유지돼요. 붙여넣은 뒤에는 항상 내용을 확인하세요.

### 복사한 액션은 얼마 동안 붙여넣을 수 있나요?
15분이에요. 이 시간 안에는 다시 복사하지 않아도 여러 번 붙여넣을 수 있어요.

### 붙여넣기를 취소할 수 있나요?
저장하기 전에는 붙여넣은 액션을 삭제하거나 옮길 수 있어요. 위치와 설정을 확인한 뒤 저장하세요.

### 다른 서브 계정으로도 복사할 수 있나요?
아니요. 액션 복사는 같은 서브 계정 안에서만 쓸 수 있어요. 다른 서브 계정으로 옮기려면 [워크플로우를 다른 서브 계정으로 복사하기](../빌더/how-to-copy-workflow-to-another-sub-account.md)를 참고해 워크플로우 전체를 복사하세요.
