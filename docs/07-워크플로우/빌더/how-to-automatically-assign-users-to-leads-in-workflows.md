# 워크플로우에서 리드에게 사용자 자동 배정하기

새 연락처가 생길 때마다 지정한 사용자에게 순서대로 돌아가며(라운드 로빈 방식) 배정하고, 배정받은 사용자에게 알림을 보내는 워크플로우를 만드는 방법을 안내해요.

## 1단계: 새 워크플로우 만들기

1. **자동화 > 워크플로우**로 이동해요.
2. **Create Workflow**(워크플로우 만들기) 버튼을 클릭해요.
3. **처음부터 시작**을 선택해요.

## 2단계: 트리거 추가하기

1. 리드가 들어오는 경로에 맞춰 트리거를 정해요. 간단하게 시작하려면 **Contact Created**(연락처 생성됨) 트리거를 쓰면 돼요. 새 연락처가 만들어질 때마다 워크플로우가 실행돼요.

## 3단계: 사용자 배정하기

1. 워크플로우 액션 **Assign to User**(사용자에게 배정)를 추가해요. 이 액션은 새 연락처를 사용자에게 라운드 로빈 방식으로 배정해요.
2. **Select users**(사용자 선택)에서 라운드 로빈에 넣을 사용자를 서브 계정에서 골라요.
3. 모두에게 고르게 배정하려면 **split traffic**(트래픽 분배) 필드를 **equally**(균등하게)로 그대로 두세요.

## 4단계: 배정된 사용자에게 알리기

1. 워크플로우 액션 **Internal Notification**(내부 알림)을 추가해요. 이 액션은 워크플로우에 들어온 새 리드를 배정된 사용자에게 알려 줘요.
2. 알림 채널을 선택해요. 앱 내 알림, SMS, 이메일 중에서 고르고, 필요하면 여러 채널을 함께 선택할 수 있어요.
3. **Select User Type**(사용자 유형 선택)에서 **assigned user**(배정된 사용자)를 선택해요. 그러면 다른 사용자에게는 알림이 가지 않고, 배정된 사용자에게만 알림이 가요.

{% hint style="info" %}
**Internal Notification** 액션은 사용자를 배정하는 액션보다 뒤에 두세요. 그래야 알림이 올바른 사용자에게 가요.
{% endhint %}

## 5단계: 게시하고 저장하기

1. 트리거, 사용자 배정 액션, 알림 액션 설정을 마쳤다면 화면 오른쪽 위의 **Publish**(게시) 토글을 켜요.
2. **Save**(저장)를 클릭하면 워크플로우가 활성화돼요.

## 마무리

이제 새 연락처를 사용자에게 라운드 로빈 방식으로 배정하고, 새 리드를 알려 주는 워크플로우가 완성됐어요. 궁금한 점이 있으면 하이퍼클래스 고객지원에 문의하세요.
