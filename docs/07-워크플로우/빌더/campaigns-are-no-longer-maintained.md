# 캠페인 기능 지원 종료 안내

하이퍼클래스는 **캠페인** 기능을 종료하고 있어요. 이 문서에서는 종료 일정과 앞으로 해야 할 일을 안내해요.

하이퍼클래스는 빠르게 발전하고 있어요. 그 과정에서 자동화 기능으로 워크플로우를 제공하고, **캠페인** 기능은 종료하기로 했어요.

## 기능을 종료하는 이유

워크플로우는 더 강력하고 유연한 자동화 기능이에요. 워크플로우를 쓰면 자동화를 만들고 관리하기도 더 쉬워요.

## 캠페인 종료 일정

1. 2024년 4월 15일부터 새 캠페인과 트리거를 만들 수 없어요.
2. 2024년 4월 15일부터 캠페인과 트리거에 대한 지원이 제공되지 않아요.

## 사용자에게 어떤 영향이 있나요?

- 기존 캠페인은 워크플로우로 옮기세요. 그러면 끊김 없이 전환할 수 있어요.

{% hint style="info" %}
이제 CRM에서 **캠페인** 탭과 **트리거** 탭이 표시되지 않아요. 더 나은 기능을 쓰려면 워크플로우를 사용하세요. 사용법은 **워크플로우 빌더** 안내 문서를 참고하세요.
{% endhint %}
