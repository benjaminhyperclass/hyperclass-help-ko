# 워크플로우 빌더 — Undo(실행 취소)·Redo(다시 실행)와 Recent Changes(최근 변경 사항)

**Workflow Builder**(워크플로우 빌더)에서 편집하다가 실수해도 괜찮아요. **Undo**(실행 취소)와 **Redo**(다시 실행)로 작업을 되돌리거나 다시 적용하고, **Recent Changes**(최근 변경 사항) 목록에서 원하는 시점으로 바로 이동할 수 있어요. 이 문서에서는 세 기능을 쓰는 방법과 동작 규칙을 설명해요.

## Undo, Redo, Recent Changes란?

**Undo**, **Redo**, **Recent Changes**는 워크플로우 캔버스에서 쓰는 세션 단위 편집 기능이에요. 자동 저장된 변경은 현재 세션 안에서 되돌리거나 다시 적용할 수 있어요. 그래서 실수해도 부담 없이 시도해 볼 수 있고, 저장된 **Version History**(버전 기록)에는 영향을 주지 않아요.

**Workflow Builder**는 캔버스에서 한 편집을 자동으로 기록해요. **Undo**는 가장 최근 작업을 취소하고, **Redo**는 취소한 작업을 다시 적용해요. **Recent Changes** 목록에는 최근 편집이 시간순으로 나오고, 항목을 선택하면 캔버스가 그 시점으로 돌아가요.

**Undo**와 **Redo**는 **Workflow AI Builder**(워크플로우 AI 빌더)로 바꾼 내용에도 쓸 수 있어요. 현재 편집 세션 안에서는 AI가 바꾸기 전 상태로 되돌리거나, 되돌렸던 AI 변경을 다시 적용할 수 있어요. 액션 추가, 기존 단계 수정, 워크플로우 구조 변경 같은 AI 변경도 모두 해당돼요.

## 이 기능을 쓰면 좋은 점

- 안전: 실수로 지우거나 고쳐도 지금까지의 작업을 잃지 않고 바로 복구할 수 있어요.
- 속도: 키보드 단축키로 편집 내용을 앞뒤로 빠르게 오갈 수 있어요.
- 정확성: **Recent Changes** 목록에서 원하는 편집으로 바로 이동해 상태를 비교하거나, 여러 단계를 한 번에 되돌릴 수 있어요.
- 안심: 현재 세션 안에서는 되돌리거나 다시 적용할 수 있어서 과감하게 수정해 볼 수 있어요.
- 집중: 대부분의 캔버스 편집이 자동 저장되고 세션 중에 기록되므로, 작업에만 집중할 수 있어요.

## Undo·Redo 사용 위치와 단축키

**Workflow Builder**에서 **Undo**와 **Redo**의 위치와 단축키를 알아 두면 더 빠르게 편집할 수 있어요.

- 워크플로우 캔버스에 **Undo**와 **Redo** 툴바 버튼이 있어요.
- 키보드 단축키
  - Windows: Ctrl + Z (**Undo**), Ctrl + Y (**Redo**)
  - macOS: Cmd + Z (**Undo**), Cmd + Y 또는 Cmd + Shift + Z (**Redo**)
- **Undo**는 기록된 가장 최근 캔버스 작업을 되돌려요. 마음이 바뀌면 **Redo**로 다시 적용할 수 있어요.
- 현재 편집 세션 중에는 **Workflow AI Builder**로 한 변경 중 지원되는 것에도 같은 기능을 쓸 수 있어요.

## 세션 동작과 한계

기록이 언제 초기화되고 무엇이 유지되는지 알아 두면 예상치 못한 상황을 피할 수 있어요.

- 세션 단위: 변경 기록은 현재 편집 세션에만 있어요. 편집 화면을 나가거나 브라우저를 새로고침하면 초기화돼요.
- 버전 복원: **Version History**에서 이전 버전을 복원하면 **Undo/Redo** 기록이 초기화되고, 복원된 상태에서 새로 시작해요.
- 내 세션에만 적용: 기록은 내 세션 안에만 있어서 다른 사용자의 편집은 들어 있지 않아요.

## 여러 명이 함께 편집할 때

여러 사용자가 동시에 편집할 때 누가 무엇을 되돌릴 수 있는지 알아 두세요.

- **Undo/Redo**와 **Recent Changes**는 내 세션에서 내가 한 편집만 기록해요.
- 다른 편집자의 변경은 내 세션 기록에 들어가지 않아요.
- 팀 전체 단위나 오래전 시점으로 되돌릴 때는 모두가 함께 쓰는 저장 지점인 **Version History**를 이용하세요.

## Undo, Redo, Recent Changes 사용하기

**Workflow Builder**에서 **Undo/Redo**와 **Recent Changes**를 쓰는 순서예요.

1. **자동화 > 워크플로우**로 이동하세요.

   ![자동화 > 워크플로우 화면](https://jumpshare.com/share/OdWO0lVUDtvqQi8MC2Jk+/Screen+Shot+2025-10-28+at+6.45.42+PM.png)
2. 새 워크플로우를 만들거나 기존 워크플로우를 열어 캔버스에서 편집하세요.
3. 캔버스에서 단계나 설정을 추가하거나 수정하세요.
4. 빌더의 **Undo/Redo** 버튼을 사용하세요. **Workflow Builder**에서 직접 변경하거나 **Workflow AI Builder**로 워크플로우를 생성·수정한 뒤에도 쓸 수 있어요.
5. 단축키로도 쓸 수 있어요. 마지막 편집은 Ctrl/Cmd + Z로 되돌리고, 다시 적용할 때는 Ctrl/Cmd + Y(macOS는 Cmd + Shift + Z도 가능)를 누르세요.
6. 캔버스에서 **Recent Changes**를 클릭하면 최근 편집 목록이 나와요. 항목을 선택하면 그 시점으로 이동해요.

   ![Recent Changes에서 이전 시점으로 이동하는 모습](https://jumpshare.com/share/Y17k4kd5gI85mAf6SkGk+/GIF+Recording+2025-10-28+at+7.23.18+PM.gif)

## 자주 묻는 질문

### 되돌릴 수 있는 작업 횟수에 제한이 있나요?
**Undo/Redo**는 세션 단위로 동작해요. 목록에는 최근 편집이 표시되지만, 세션이 끝나거나(예: 새로고침, 나가기) 버전을 복원하면 기록이 초기화돼요.

### 새로고침하거나 탭을 닫아도 기록이 남아 있나요?
아니요. 변경 기록은 현재 편집 세션 안에만 있어요.

### Recent Changes와 Version History는 무엇이 다른가요?
**Recent Changes**는 이번 세션의 최근 편집을 보여 줘서 빠르게 되돌릴 때 쓰고, **Version History**는 워크플로우 버전을 계속 보관해서 오래된 시점이나 팀 단위로 되돌릴 때 써요.

### 다른 사용자가 한 편집도 되돌릴 수 있나요?
아니요. **Undo/Redo**는 내 세션에만 적용되고 내 편집만 기록해요. 함께 작업하는 경우의 롤백은 **Version History**를 사용하세요.

### Undo/Redo가 실행 중인 워크플로우에도 영향을 주나요?
**Undo/Redo**는 편집기의 캔버스에만 영향을 줘요. 변경이 실제 실행에 어떻게 반영되는지는 게시와 버전 관리가 정해요. 실행 중인 워크플로우를 안전하게 바꾸려면 **Version History**와 게시 기능을 활용하세요.

### 이전 버전을 복원하면 어떻게 되나요?
**Undo/Redo** 기록이 초기화되고, 복원된 상태에서 새로 시작해요.
