# 수료증 발급 트리거와 액션 — Certificate Issued(수료증 발급됨), Issue Certificate(수료증 발급)

워크플로우에서 수료증 발급 트리거와 액션을 쓰면 수료증을 자동으로 보내거나, 수료증이 발급된 뒤 이어서 할 작업을 실행할 수 있어요.

## 트리거 추가하기

**Certificate Issued**(수료증 발급됨) 트리거는 수료증이 발급되었을 때 워크플로우를 시작해요.

1. **자동화 > 워크플로우**로 이동하세요.
2. 화면 오른쪽 위의 **Create a Workflow**(워크플로우 만들기) 버튼을 클릭하세요.
3. **Add New Trigger**(새 트리거 추가)를 클릭하세요.
4. **Certificate Issued** 트리거를 검색해서 선택하세요.

![수료증 발급됨 트리거를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025554989/original/oq7fLqMbpDzjLpauJFRHfrSZ_nGxDXj3CQ.gif?1714982687)

## 액션 추가하기

**Issue Certificate**(수료증 발급) 액션은 워크플로우 안에서 수료증을 발급해요.

1. **자동화 > 워크플로우**로 이동하세요.
2. 화면 오른쪽 위의 **Create a Workflow** 버튼을 클릭하세요.
3. **Add New Action**(새 액션 추가)을 클릭하세요.
4. **Issue Certificate** 액션을 검색해서 선택하세요.

![수료증 발급 액션을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025555191/original/TZTevijeYKIATGoFl-X9zUaz869U83DSxw.gif?1714982829)

{% hint style="info" %}
워크플로우로 발급한 수료증은 모두 **멤버십 > 수료증 > 발급된 수료증**에 표시돼요. 이곳에서 쉽게 찾아볼 수 있어요.
{% endhint %}
