# 워크플로우 자동 저장(Auto Save)

하이퍼클래스의 워크플로우 빌더는 캔버스에서 수정한 내용을 임시 저장본에 계속 저장해 줘요. 자동 저장을 한 번 켜 두면 안심하고 작업을 이어 갈 수 있어요. **Publish**(게시)하기 전에는 아무것도 실제로 적용되지 않아요. 이 문서에서는 워크플로우의 자동 저장 기능을 소개해요.

## 워크플로우의 자동 저장이란?

자동 저장은 워크플로우를 만드는 동안 캔버스에서 수정한 내용을 백그라운드에서 계속 저장하는 기능이에요. 수정한 내용은 현재 임시 저장본에 기록되기 때문에 작업 내용을 잃어버리지 않아요. 변경 사항을 실제로 적용하는 시점은 **Publish**를 클릭해서 직접 정해요.

## 자동 저장의 장점

- **수동 저장이 필요 없어요**: 캔버스에서 수정한 내용이 자동으로 저장되어 **Save**(저장) 버튼을 누르지 않아도 돼요.
- **임시 저장본에만 저장돼요**: 변경 사항은 임시 저장본에만 저장돼요. **Publish**를 클릭하기 전에는 이미 운영 중인 워크플로우에 영향을 주지 않아요.
- **클릭이 줄어요**: 자동 저장을 한 번만 켜 두면 저장하느라 멈추지 않고 더 빠르게 작업할 수 있어요.
- **믿을 수 있는 체크포인트**: **Save Version**(버전 저장)으로 언제든 이름을 붙인 체크포인트를 만들 수 있어요. 문제가 없던 시점으로 쉽게 돌아갈 수 있어요.
- **협업 상황 반영**: 여러 사람이나 여러 탭에서 같은 워크플로우를 수정하면, 가장 최근에 자동 저장된 내용이 현재 임시 저장본이 돼요.

## 임시 저장과 게시의 차이

자동 저장은 수정 중인 내용을 임시 저장 상태로 기록해요. 변경 사항을 실제로 적용하는 일은 여전히 직접 **Publish**를 클릭해서 해요.

임시 저장과 게시의 차이를 알아 두면, 의도하지 않은 변경이 운영 중인 워크플로우에 영향을 주는 일을 막을 수 있어요.

- **자동 저장은 임시 저장본에만 반영돼요**: 작업하는 동안 수정한 내용이 임시 저장본에 보관돼요.
- **적용은 Publish로 해요**: 임시 저장본이 실행할 준비가 되면 **Publish**를 클릭하세요.
- **안전하게 수정할 수 있어요**: 현재 게시된 동작에 영향을 주지 않고 여러 번 수정하고 저장해 둘 수 있어요.

## 자동 저장되는 항목

어떤 내용이 저장되는지 알아 두면 중요한 변경을 놓치지 않아요. 자동 저장은 다음 작업을 할 때 동작해요.

- 캔버스에 액션이나 트리거를 추가할 때
- 캔버스에서 액션이나 트리거를 삭제할 때
- 워크플로우의 **Settings**(설정) 탭에서 내용을 바꿀 때
- **Workflow name**(워크플로우 이름)을 수정할 때
- 워크플로우 상태(**Draft**(임시 저장) 또는 **Publish**)를 바꿀 때

## 자동 저장되지 않는 항목 (설정 창)

자동 저장은 개별 액션·트리거의 설정 창(모달) 안에서는 동작하지 않아요. 설정 창 안에서 바꾼 내용은 캔버스에 반영하기 전까지 저장되지 않아요.

- 설정 창에서 단계의 설정을 수정할 때는 **Save**/**Apply**(적용)(또는 이와 같은 버튼)를 클릭해서 캔버스에 반영하세요.
- 캔버스에 반영하고 나면 자동 저장이 그 수정 내용을 임시 저장본에 저장해 줘요.
- 예시: 설정 창 안에서 **Wait**(대기) 단계의 시간을 바꿨다면, 설정 창에서 **Save**를 클릭해 캔버스에 반영하기 전까지는 자동 저장되지 않아요.

## 버전 기록과 체크포인트

자동 저장을 켠 상태에서 수정하면, 편집 세션마다 **Version History**(버전 기록)에 항목이 자동으로 만들어져요. **Save Version**으로 이름을 붙인 체크포인트를 만들 수도 있어요.

**Version History**에는 작업 진행 내용이 복구할 수 있는 기록으로 남아요. 이름을 붙인 체크포인트가 있으면 중요한 시점으로 쉽게 되돌릴 수 있어요.

- **세션 항목**: 자동 저장을 켠 상태에서 수정하면 자동으로 만들어져요.
- **Save Version**: 직접 만드는 방식이에요. 나중에 쉽게 알아볼 수 있도록 이름을 붙인 체크포인트가 만들어져요.
- **Restore**(복원): **Version History**에서 이전 상태를 확인하고, 필요하면 **Restore**로 복원하세요.

## 여러 명이 편집하거나 여러 탭을 열었을 때

여러 사용자나 여러 브라우저 탭에서 같은 워크플로우를 수정하면, 가장 최근에 자동 저장된 내용이 현재 임시 저장본이 돼요.

수정 시점을 서로 조율하면 다른 사람의 변경 사항을 덮어쓰지 않고, 모두가 최신 임시 저장본으로 작업할 수 있어요.

- 중요한 수정은 한 번에 한 명이 하는 것이 좋아요.
- 함께 작업할 때는 수정 시간을 서로 알려서 충돌을 피하세요.
- 한동안 작업하지 않다가 돌아왔다면 새로 고침해서 최신 임시 저장본을 보고 있는지 확인하세요.

## 자동 저장 설정하기

자동 저장을 설정해 두면 작업하는 동안 수정한 내용이 계속 저장돼요.

### 방법 1: 워크플로우 빌더에서 켜기

1. 서브 계정에 로그인하세요.
2. **자동화 > 워크플로우**로 이동해 워크플로우를 하나 여세요.
3. 처음 열면 안내 팝업이 나타날 수 있어요.
4. **Enable Auto Save Now**(지금 자동 저장 켜기)를 선택하면 바로 켜져요.

1. 서브 계정에 로그인하세요.
2. **자동화 > 글로벌 워크플로우 설정**으로 이동하세요.

   ![글로벌 워크플로우 설정 메뉴 화면](https://jumpshare.com/share/lHPmnBEquY46XBx14ujH+/Screen+Shot+2025-10-29+at+5.38.13+PM.png)

## 자주 묻는 질문

### 자동 저장을 켜면 변경 사항이 자동으로 게시되나요?

아니요. 자동 저장은 임시 저장본만 업데이트해요. 변경 사항을 실제로 적용하려면 **Publish**를 클릭하세요.

### 단계 설정 창 안에서도 Save를 클릭해야 하나요?

네. 단계의 설정 창 안에서 바꾼 내용은 **Save**/**Apply**로 캔버스에 반영해야 해요. 그러고 나면 자동 저장이 그 내용을 저장해요.

### 수정하는 중에 인터넷 연결이 끊기면 어떻게 되나요?

연결이 다시 되면 캔버스 저장이 재개될 수 있어요. 어떤 임시 저장본이 최신인지 확실하지 않다면 워크플로우를 새로 고침하고 **Version History**를 확인하세요.

### AI 워크플로우 빌더에서도 자동 저장이 되나요?

네. **AI Builder**(AI 빌더)로 워크플로우를 만들면 자동으로 저장돼요. 이후 **AI Builder**로 수정한 내용도 자동으로 저장돼요.
