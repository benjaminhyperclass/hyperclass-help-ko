# 워크플로우를 다른 서브 계정으로 복사하기

**Copy to Sub-Account**(서브 계정에 복사)를 쓰면 워크플로우를 다른 서브 계정으로 바로 복사할 수 있어요. 복사된 워크플로우의 이력과 함께 복사되는 항목도 이 문서에서 확인해 보세요.

###  커뮤니티 튜토리얼 더 보기

**스냅샷** 전체 과정을 거치지 않아도, 워크플로우 하나를 다른 서브 계정으로 간단히 복사할 수 있어요. 워크플로우 복사는 **에이전시 관리자**만 할 수 있어요.

### Copy to Sub-Account(서브 계정에 복사)

![서브 계정에 복사 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010518416/original/qkFg8Hcug6YAH4mmV0H5gBVYDGb48UQG8A.png?1697704090)

### 서브 계정 선택

![서브 계정 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010415170/original/Qik7rpWoi8n9fvpnlFjEj5CDfAvXX_hTfw.png?1697624900)

- 로그인한 사용자가 접근할 수 있는 서브 계정만 **서브 계정 선택** 목록에 보여요.
- 제출하면 워크플로우가 선택한 서브 계정으로 복사돼요.
- 다른 서브 계정으로 복사된 워크플로우는 기본적으로 초안(Draft) 상태예요.

### Copy Workflow History(워크플로우 복사 이력)

![워크플로우 복사 이력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010518546/original/4ry62KeHcXiu5vXe9NT5pJTThrk6Y3F0_Q.png?1697704113)

- 다른 서브 계정으로 복사한 워크플로우의 이력이 목록으로 나타나고, 각 로그마다 현재 상태가 함께 표시돼요.

### Copy Workflow History Details(복사 이력 상세)

- 복사하는 중에 오류가 생기면 해당 이력을 클릭해 자세한 정보를 보고 원인을 확인할 수 있어요.

### 워크플로우를 복사하면 연결된 항목은 어떻게 되나요?

워크플로우를 다른 서브 계정으로 복사할 때, 워크플로우에 포함된 다음 항목이 함께 복사돼요.

- 연락처 태그
- 연락처 커스텀 필드 (필드 유형이 같아야 해요)
- 서브 계정 커스텀 값
- 기회 커스텀 필드
- 기회 파이프라인과 단계
- 이메일/SMS 문자 템플릿
- 이메일 빌더 템플릿 (출시 예정)

{% hint style="info" %}
위에 없는 다른 항목이나 참조는 선택한 서브 계정으로 복사하기 전에 워크플로우에서 지워져요.
{% endhint %}
