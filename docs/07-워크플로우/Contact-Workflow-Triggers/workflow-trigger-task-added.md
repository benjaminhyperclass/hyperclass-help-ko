# 워크플로우 트리거 — Task Added(작업 추가됨)

**Task Added**(작업 추가됨) 트리거는 연락처 기록에 새 작업이 추가될 때 워크플로우를 시작해요. 담당자에게 알림 보내기, 작업 관련 필드 업데이트, 후속 메시지 보내기처럼 작업 생성에 맞춰 자동으로 처리할 때 쓰세요.

## 트리거 이름

**Task Added**(작업 추가됨)

## 트리거 설명

연락처 기록에 새 작업이 추가되면 이 트리거가 실행돼요. 필터를 쓰면 특정 사용자에게 할당된 작업처럼 워크플로우를 시작할 작업을 좁힐 수 있어요.

## 설정 방법

- **Choose a Workflow Trigger**(워크플로우 트리거 선택): 사용할 수 있는 트리거 목록에서 **Task Added**를 선택하세요.
- **Workflow Trigger Name**(워크플로우 트리거 이름): 트리거를 알아보기 쉬운 이름으로 입력하세요. 예를 들면 "작업 추가됨"처럼 쓸 수 있어요.
- **Filters**(필터): 트리거가 실행되는 조건을 좁힐 때 사용해요. 할당된 사용자를 기준으로 워크플로우를 시작할 작업을 지정할 수 있어요.

| 값 | 설명 | 필수 여부 |
| --- | --- | --- |
| **Assigned User**(할당된 사용자) | 작업이 할당된 특정 사용자를 선택해요. 해당 사용자에게 작업이 할당되면 워크플로우가 시작돼요. 사용자는 한 명 또는 여러 명을 선택할 수 있어요. | 아니요 |

## 예시

새 작업이 추가되고 그 작업이 특정 사용자에게 할당되면 시작되는 워크플로우를 만든다고 해 볼게요. 이 워크플로우는 새 작업이 생겼다는 이메일을 해당 사용자에게 보내요.

- **Workflow Trigger Name**: "새 작업 할당됨"
- **Filters**:
  - **Assigned User**: "홍길동" (작업이 홍길동에게 할당된 경우에만 시작돼요)

**워크플로우 단계**:

1. **Trigger**(트리거): **Task Added** (위에서 설정한 대로)
2. **Action**(액션): **Send Email**(이메일 보내기) - 할당된 사용자에게 새 작업을 알려요.
3. **Action**: **Update Task Status**(작업 상태 업데이트) - 작업 상태를 "알림 완료"로 바꿔요.
