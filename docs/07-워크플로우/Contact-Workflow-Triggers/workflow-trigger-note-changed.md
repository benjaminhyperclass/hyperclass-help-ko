# 워크플로우 트리거 — Note Changed(메모 변경됨)

**Note Changed**(메모 변경됨) 트리거는 연락처 기록에 있는 기존 메모가 수정될 때 워크플로우를 시작해요. 중요한 메모의 변경 사항을 놓치지 않고 팀원에게 알리고 싶을 때 쓰세요.

## 개요

**Note Changed** 트리거는 연락처 기록에 있는 기존 메모가 수정될 때마다 워크플로우 안의 지정한 액션을 실행해요. 이 트리거를 쓰면 중요한 메모의 변경 내용을 추적하고, 팀원에게 변경 사실을 알리고, 최신 소통 기록을 유지할 수 있어요.

## 트리거 이름

**Note Changed**

## 트리거 설명

**Note Changed** 트리거는 연락처 프로필의 기존 메모가 수정되면 워크플로우를 실행해요. 메모 내용이 바뀐 것에 맞춰 관련 팀원에게 알리거나, 연락처 정보를 업데이트하거나, 바뀐 정보를 기준으로 연락처에 태그를 추가할 수 있어요.

## 설정 방법

**Note Changed** 트리거를 설정하려면 워크플로우 트리거 이름을 입력하고, 워크플로우가 실행될 조건을 좁힐 필터를 선택하세요.

| 필드 | 설명 | 필수 여부 |
| --- | --- | --- |
| **Workflow Trigger Name**(워크플로우 트리거 이름) | 트리거를 쉽게 알아볼 수 있도록 붙이는 이름이에요. | 예 |
| **Doesn't Have Tag**(태그 미보유) | 연락처에 지정한 태그가 없을 때만 워크플로우가 실행돼요. | 아니요 |
| **Has Tag**(태그 보유) | 연락처에 지정한 태그가 있을 때만 워크플로우가 실행돼요. | 아니요 |

## 예시

이 예시는 특정 태그가 있는 연락처의 기존 메모가 변경될 때 실행되도록 워크플로우를 설정한 경우예요.

1. **Workflow Trigger Name:** `Note Changed`
2. **Filters**(필터):
   - **Has Tag:** `Important Client`

### 워크플로우 예시

연락처 기록의 메모가 변경되면 다음과 같은 액션을 실행할 수 있어요.

- 담당 어카운트 매니저에게 알림 보내기: 담당 매니저에게 내부 알림을 보내 중요한 고객 프로필의 메모 변경 내용을 확인하게 해요.
- **Update Task**(작업 업데이트): 수정된 메모 내용에 맞춰 팀원이 후속 조치를 할 수 있도록 작업을 자동으로 업데이트하거나 만들어요.
- 변경 기록 남기기: 메모 변경 사실을 별도의 로그에 기록하거나 CRM을 업데이트해서 수정 이력을 남겨요.

이렇게 설정하면 메모가 변경될 때 워크플로우가 실행되므로, 메모가 바뀌는 즉시 조치하고 팀원과 내용을 공유할 수 있어요.
