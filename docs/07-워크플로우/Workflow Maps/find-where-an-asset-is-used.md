# 자산(Asset)이 사용된 위치 찾기

자산(Asset)과 연결된 워크플로우를 확인하고, 해당 자산을 사용하는 트리거나 액션을 열어보세요.

## 자산 사용 현황이 보여주는 정보

자산(Asset)을 선택하면 어떤 워크플로우가 이를 사용하는지, 어떻게 사용하는지 확인할 수 있어요. 태그, 폼, 캘린더, 파이프라인 등 지원되는 자산의 이름을 변경하거나 삭제하기 전에 이 기능을 먼저 활용해보세요.

하나의 워크플로우가 동일한 자산을 여러 곳에서 사용할 수도 있어요. 이 경우 사용 현황 행에 **2 triggers · 1 action**처럼 트리거와 액션 개수가 각각 표시돼요.

예를 들어, 리드 태그를 변경하기 전에 해당 태그가 추가될 때 시작되는 워크플로우와, 그 태그를 추가하거나 제거하는 워크플로우를 먼저 확인해보는 거예요.

## 자산 사용 현황 찾는 방법

- **Automation(자동화) → Workflows(워크플로우) → Workflow Maps**로 이동하세요.
- 맵이나 **Search(검색)**를 이용해 자산을 찾으세요.
- 해당 자산을 클릭하세요.
- 패널에 표시된 워크플로우 목록을 확인하세요.
- 워크플로우 행을 펼쳐서 개별 트리거와 액션을 자세히 확인하세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352879/original/QtOggVjqcUAGURCInqFMKFOlur3uWi5JPA.jpg?1793135839)

자산 패널에는 해당 자산의 워크플로우 사용 현황, 트리거 및 액션 합계, 발행됨(Published) 또는 초안(Draft) 상태의 워크플로우가 표시돼요.

## 자산을 사용하는 단계 열기

- 자산 사용 현황 패널에서 확인하고 싶은 워크플로우 행을 펼치세요.
- 살펴보고 싶은 트리거나 액션에 마우스를 올리세요.
- **View step(단계 보기)**을 클릭하세요.

그러면 해당 자산을 사용하는 단계에서 워크플로우가 열려요. 변경 사항을 결정하기 전에 해당 단계를 꼼꼼히 확인해보세요.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352883/original/yttaRrzProz9zdRH4MnPOEO__MHOOOLO3w.jpg?1793135842)

워크플로우를 펼쳐서 선택한 자산을 사용하는 액션이나 트리거를 확인해보세요.

## 폴더 전체에서 사용 현황 하이라이트하기

자산 패널에서 **Show usage on map(맵에서 사용 현황 표시)**을 클릭하면 여러 폴더에 걸쳐 해당 자산을 사용하는 워크플로우가 하이라이트돼요.

하나의 자산이 여러 폴더에 나타날 수 있는데, 이는 해당 폴더 안의 워크플로우들이 이 자산을 사용하고 있기 때문이에요. 폴더별 사본들은 곡선으로 서로 연결돼요. 사용 현황 배지를 클릭해서 폴더 간 사용 현황을 확인할 수도 있어요.

## 빈 목록이나 누락된 자산 이해하기

워크플로우 사용 목록이 비어 있다면 해당 자산에 대한 워크플로우 사용 내역이 없다는 뜻이에요. 다만 이 확인 기능은 워크플로우 의존성만 다루므로, 자산을 삭제하기 전에 워크플로우 외부에서의 사용 여부도 함께 고려해야 해요.

**Missing asset(누락된 자산)** 배지가 표시되면 해당 자산은 더 이상 존재하지 않지만, 여전히 일부 워크플로우가 이를 참조하고 있다는 뜻이에요. 참조 내역을 살펴보고 검토가 필요한 단계를 찾아보세요.

## 자주 묻는 질문

**Q: 하나의 워크플로우에서 자산을 여러 번 사용할 수 있나요?**

네, 가능해요. 워크플로우 행을 펼치면 개별 트리거와 액션을 각각 확인할 수 있어요.

**Q: 현재 폴더 외부의 사용 현황도 확인할 수 있나요?**

네, 가능해요. **Show usage on map**을 사용하면 여러 폴더에 걸쳐 연결된 워크플로우가 하이라이트돼요.

**Q: 필터나 조건 분기(If/Else) 안에서만 사용된 자산도 찾을 수 있나요?**

점선으로 연결된 경우는 필터와 같은 참조를 나타내요. 검색 기능을 이용하면 조건 분기(If/Else) 안에서 사용된 태그도 찾을 수 있어요.

**Q: 자산을 선택하면 해당 자산이 변경되나요?**

아니요. 자산을 선택하는 것은 사용 현황 세부 정보를 열어보는 것뿐이에요. 워크플로우 단계를 변경하려면 빌더에서 직접 수정해야 해요.
