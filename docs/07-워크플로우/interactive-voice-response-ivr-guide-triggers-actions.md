# IVR(자동 응답) 설정 가이드 — Start IVR 트리거와 IVR 액션

하이퍼클래스 워크플로우로 IVR(자동 응답) 시스템을 만드는 방법을 안내해요. 미리 만들어 둔 IVR 레시피로 빠르게 시작할 수도 있고, 처음부터 직접 만들 수도 있어요.

IVR(Interactive Voice Response)은 미리 녹음한 안내 음성으로 발신자를 안내하고, 사람이 응대하지 않아도 알맞은 부서나 동작으로 연결해 주는 시스템이에요. 걸려 오는 전화를 효율적으로 관리하면 고객 경험이 좋아져요.

## 

---

## IVR 시스템이란?

IVR은 미리 녹음한 메시지, 텍스트 음성 변환(TTS) 안내, 키패드 입력으로 발신자와 소통하는 자동 전화 시스템이에요. 사람이 응대하지 않아도 발신자를 알맞은 부서로 안내하거나, 정보를 받거나, 셀프서비스 옵션을 제공할 수 있어요. 하이퍼클래스에서는 워크플로우로 IVR을 설정해 통화 라우팅과 고객 응대를 자동화해요.

아래 표는 IVR을 만들 때 쓰는 주요 트리거, 액션, 조건을 정리한 거예요. 워크플로우 안에서 IVR이 어떻게 동작하는지 이해하는 데 참고하세요.

| IVR 구성 요소 | 기능 | 사용 예 |
| --- | --- | --- |
| 트리거 - **Start IVR**(IVR 시작) | 지정한 번호로 전화가 오면 IVR을 시작해요. | 고객이 비즈니스 번호로 전화하면 IVR 워크플로우가 시작돼요. |
| 액션 - **Say/Play Message**(메시지 말하기/재생) | 녹음한 메시지나 텍스트 음성 변환 메시지를 들려주며 발신자를 안내해요. | “XYZ 회사에 오신 것을 환영합니다! 영업 문의는 1번, 지원 문의는 2번을 눌러 주세요.” |
| 액션 - **Gather Input**(입력 수집) | IVR 메뉴를 이동할 수 있도록 발신자가 누른 키 입력을 받아요. | 발신자가 영업은 1번, 지원은 2번을 눌러요. |
| 조건 - **Map Caller Input**(발신자 입력 매핑) | 입력한 값에 따라 발신자를 알맞은 동작이나 팀으로 보내요. | 1번을 누르면 영업팀으로, 2번을 누르면 지원팀으로 연결해요. |
| 액션 - **Connect Call**(통화 연결) | 발신자를 선택한 상담원, 부서, 외부 번호로 전환해요. | 1번을 누르면 영업 담당자에게 통화를 연결해요. |
| 액션 - **Record Voicemail**(음성사서함 녹음) | 전화를 받을 사람이 없을 때 발신자가 음성 메시지를 남길 수 있게 해요. | 상담원이 응대할 수 없으면 IVR이 메시지를 남기도록 안내해요. |
| 조건 - **Call Status Check**(통화 상태 확인) | 통화 결과(응답, 부재중, 연결 끊김)에 따라 다음 동작을 정해요. | 전화를 받지 않으면 안내 메시지를 들려주고 콜백 옵션을 제공해요. |

---

## IVR의 장점

- 통화 관리 개선: 발신자를 알맞은 팀으로 자동 연결해 대기 시간을 줄이고 고객 경험을 높여요.
- 업무 효율 향상: 전화를 직접 받아 처리하는 일이 줄어서, 직원이 더 중요한 업무에 집중할 수 있어요.
- 24시간 응대: 영업시간이 아니어도 고객 문의를 받을 수 있어요.
- 맞춤형 상호작용: 텍스트 음성 변환 메시지, 통화 라우팅, 음성사서함 수집, 발신자 입력에 따른 데이터 수집을 지원해요.
- 워크플로우와 매끄러운 연동: 하이퍼클래스 자동화 기능 안에서 동작하므로 후속 조치, 예약 일정 잡기, 리드 분류 같은 액션을 이어서 실행할 수 있어요.

## 워크플로우로 IVR 설정하기

IVR을 설정하는 방법은 두 가지예요. 워크플로우 레시피로 빠르게 설정하거나, 처음부터 만들어 원하는 대로 구성할 수 있어요.

### 방법 1: IVR 워크플로우 레시피로 설정하기 (빠른 설정)

미리 만들어 둔 IVR 구조로 시간을 아끼고 싶다면 IVR 워크플로우 레시피를 쓰세요. 레시피에는 기본 트리거, 액션, 조건이 이미 들어 있어요.

1. 하이퍼클래스 대시보드에서 **자동화**로 이동하세요.
2. **Create Workflow**(워크플로우 만들기)를 클릭하세요.
3. **Select a Recipe**(레시피 선택)를 클릭하세요. 거의 수정하지 않고도 IVR 시스템을 빠르게 설정할 수 있어요.

![자동화에서 레시피 선택 옵션 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041886156/original/3l8-lM-iblc4GVHrRi-8IhRW2xCRmZ6Tsg.png?1739972988)

#### IVR 워크플로우 레시피 선택

워크플로우 만들기 화면에서 레시피 선택 옵션을 쓰면 설정이 간단해져요. 이 레시피에는 필수 트리거, 액션, 통화 라우팅 로직이 들어 있어서 직접 설정할 부분이 줄어들어요. IVR 워크플로우 레시피를 선택한 뒤 비즈니스에 맞게 수정하세요.

![IVR 워크플로우 레시피 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041886204/original/ZHNn6_Z56c2duoC4liKc--nFsOKTlXVijA.png?1739973016)

#### 트리거 수정

**Workflow Trigger**(워크플로우 트리거) 설정에서 **Phone Number**(전화번호)를 선택하세요. IVR 시스템에 사용할 번호예요. 이렇게 해야 걸려 오는 전화가 IVR 워크플로우를 시작해요. 번호가 제대로 연결되지 않으면 IVR이 동작하지 않아요. 이후의 IVR 액션은 이 설정을 바탕으로 발신자를 자동 안내해요. 드롭다운을 클릭하면 사용자의 사용 가능한 전화번호가 모두 표시돼요. 번호를 하나 이상 선택할 수 있어요.
![트리거 설정에서 전화번호 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041885054/original/JkXb463bY70qAH4y6dK73xEgndgb3IcV7Q.png?1739972307)

#### Say/Play Message 수정

워크플로우 액션 설정에서 텍스트 음성 변환 문구나 업로드한 음성 파일을 수정하세요. 그러면 IVR이 발신자에게 정확하고 전문적인 안내를 들려줘요. 인사말, 메뉴 옵션, 안내 문구를 원하는 대로 바꿀 수 있어요.

![Say/Play Message 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041885125/original/xTvFuUFCNtTcKTjqrwDvy8iTG58BUcVCsw.png?1739972335)

#### 통화 라우팅 로직 수정

IVR 워크플로우의 입력 조건을 수정해 발신자가 알맞은 부서나 담당자에게 연결되도록 하세요. 발신자가 누른 키에 따라 고객지원, 영업, 음성사서함 등으로 통화를 전환하는 경로를 정할 수 있어요. 이렇게 설정하면 발신자가 효율적이고 매끄럽게 안내받아요. 설정을 마쳤으면 **Save**(저장)와 **Publish**(게시)를 눌러 IVR을 활성화하세요.

![통화 라우팅 로직 수정 후 저장 및 게시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041885222/original/V2Zd2QpS0cXgoTUimEXHQpGIOxhByiTylQ.gif?1739972402)

### 방법 2: IVR 워크플로우를 처음부터 만들기 (완전 사용자 지정)

통화 라우팅 요건이 구체적이라면 IVR 시스템을 처음부터 만들어 워크플로우 설계를 완전히 직접 정할 수 있어요.

### 1단계. 워크플로우 빌더 열기

1. 하이퍼클래스 계정에서 **자동화**로 이동하세요.
2. **Create Workflow**를 클릭하세요.
3. **처음부터 시작**을 클릭하세요.

워크플로우 빌더가 열려요. 여기서 IVR 시스템을 처음부터 구성하거나, 미리 만들어 둔 IVR 워크플로우 레시피를 써서 구성할 수 있어요.

![자동화에서 처음부터 시작 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041896996/original/kfpdFfMGGODU1vsv4UNRNq_0dj2zr96_oA.png?1739979472)

### 2단계. IVR 트리거 추가

1. 워크플로우 빌더에서 **Add New Trigger**(새 트리거 추가)를 클릭하세요.
2. 트리거 목록에서 **Start IVR**을 검색해 선택하세요.

이 트리거를 선택하면 지정한 전화번호로 전화가 왔을 때 IVR 워크플로우가 시작돼요. 걸려 오는 전화를 자동으로 처리하는 IVR 시스템을 구성하는 첫 단계예요.

![Start IVR 트리거 검색 및 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041897064/original/rBa3NLNS4UtjZo9eHwTsF0inZ7XPsQL3ZA.png?1739979510)

### 3단계. Start IVR 트리거 설정

#### 전화번호 지정

**Workflow Trigger** 설정에서 IVR 시스템에 사용할 **Phone Number**를 선택하세요. 전화번호 하나는 한 번에 IVR 워크플로우 하나에만 지정할 수 있어요. 번호를 선택한 뒤 **Save**를 클릭해 설정을 확정하세요. 그러면 지정한 번호로 걸려 오는 전화가 IVR 워크플로우를 시작해요.

![Start IVR 트리거에서 전화번호 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041897180/original/KBylowqsqanJ5tOJ9mrnYTRaETXcTTiN5A.png?1739979601)

### 4단계. IVR 액션 설정

트리거를 추가한 뒤에는 IVR이 발신자와 어떻게 소통할지 액션으로 정해요. 아래 화면에서 워크플로우에 쓸 수 있는 IVR 액션을 볼 수 있어요. 이어지는 내용에서 IVR 액션을 하나씩 살펴볼게요.

![사용할 수 있는 IVR 워크플로우 액션 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041922612/original/nrk8CoJ8Af2WyYh5z1xykSf0RniuSzb3aA.png?1740031934)

#### Gather Input on Call 액션

**Gather Input on Call**(통화 중 입력 수집) 액션은 발신자가 키패드로 누른 입력을 받아요. 발신자가 IVR 메뉴를 이동할 수 있게 해 줘요. 발신자를 알맞은 부서로 안내하거나, 계정 정보를 조회하거나, 고객 요청을 효율적으로 처리할 때 꼭 필요한 액션이에요.

이 액션에서는 다음 옵션을 설정할 수 있어요.

- **Say or Play Message**(메시지 말하기 또는 재생): IVR이 메시지를 들려주는 방식을 선택해요.
  - **Say Message**(메시지 말하기): 텍스트를 입력하면 음성으로 변환돼요.
  - **Play Message**(메시지 재생): 미리 녹음한 음성 파일을 업로드해서 재생해요. 예: “계좌 잔액 확인은 1번, 상담원 연결은 2번을 눌러 주세요.”
- **Text to Say**(말할 텍스트): 발신자가 번호를 선택하기 전에 들려줄 메시지를 입력해요. 선택할 수 있는 옵션을 분명하게 안내할 수 있어요.
- **Language & Message Voice**(언어 및 메시지 음성): 텍스트 음성 변환을 쓰면 기본 언어는 영어(미국)예요. 남성 또는 여성 음성을 골라 발신자 경험을 맞출 수 있어요.
- **Number of Loops**(반복 횟수): 시스템이 응답 대기를 멈추기 전에 메시지를 몇 번 반복할지 정해요. 발신자가 안내를 이해하고 반응할 시간을 충분히 줄 수 있어요.

**Match Conditions**(조건 일치)

**Match Conditions** 토글은 발신자의 입력을 시스템이 어떻게 처리하고, 키 입력에 따라 어떤 워크플로우 경로로 보낼지 정해요. **Match Conditions**를 켜면 발신자가 누른 키별로 분기를 여러 개 만들 수 있어요. 각 분기는 발신자가 할 수 있는 응답 하나를 나타내고, 선택에 따라 특정 액션으로 안내해요.

Match Conditions의 구성 요소는 다음과 같아요.

- **Branch Name**(분기 이름): 키 입력 동작을 설명하는 이름이에요.  
  예: “발신자가 1번 누름”, “발신자가 2번 누름”
- **On Key Press**(키 입력 시): 발신자가 어떤 키를 눌러야 해당 분기를 따라가는지 정해요.  
  예: 발신자가 1번을 누르면 한 액션으로, 2번을 누르면 다른 액션으로 가요.
- **None Branch**(해당 없음 분기): 발신자가 유효한 키를 누르지 않았을 때 어떻게 할지 정해요.  
  예: 1번이나 2번이 아닌 잘못된 키를 누르면 메뉴를 다시 들려주거나 상담원에게 연결하는 등 기본 액션으로 보낼 수 있어요.

입력 수집 **Advanced Settings**(고급 설정)

- **Stop Gathering After (Seconds)**(입력 대기 시간, 초): 발신자 입력을 기다리는 제한 시간을 5초에서 30초 사이로 정해요. 이 시간 안에 입력이 없으면 시스템이 다음 단계로 넘어가요.
- **Stop Gathering on Key Press**(키 입력 시 수집 중단): 켜면 발신자가 키를 누르는 즉시 입력 수집을 멈춰요. 끄면 제한 시간이 지나거나 예상한 키 입력 수가 채워질 때까지 기다려요.
- **Stop Gathering After (Digits)**(자릿수 도달 시 수집 중단): 시스템이 발신자에게서 받을 자릿수를 정해요. 이 자릿수에 도달하면 입력이 자동으로 제출돼요.

![Gather Input on Call 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041897491/original/PdWOOr3dq4GJ9RgkwKDn29zqmSzWmov0Wg.jpeg?1739979867)

#### Say/Play Message 액션

**Say/Play Message** 액션은 텍스트 음성 변환이나 미리 녹음한 음성 파일로 발신자에게 안내나 중요한 정보를 전달해요. 발신자에게 입력을 요청하거나 다음 단계로 보내기 전에 자동 메시지를 들려주므로, IVR 안내에서 중요한 역할을 해요. 자동 음성이든 녹음된 메시지든 발신자가 분명한 안내를 받을 수 있어서 전체 IVR 경험이 좋아져요.

이 액션에서는 다음 설정을 바꿀 수 있어요.

- **Say or Play Message**: 두 가지 중에서 선택해요.
  - **Say Message**: 텍스트를 입력하면 음성으로 변환되어 발신자에게 재생돼요.
  - **Play Message**: 텍스트 음성 변환 대신 미리 녹음한 음성 파일을 업로드해서 재생해요.
- **Text or Audio File Input**(텍스트 또는 음성 파일 입력): 위에서 선택한 방식에 따라 입력란에 메시지를 직접 입력하거나 음성 파일을 업로드해요.
- **Recommended Format**(권장 형식): 최적의 성능을 위해 .wav 파일을 권장해요. .mp3 파일은 호환되지 않을 수 있어요.
- **Language Support**(지원 언어): 현재 텍스트 음성 변환의 기본 언어이자 유일하게 지원하는 언어는 영어(미국)예요.
- **Message Voice**(메시지 음성): 텍스트 음성 변환을 쓸 때 남성 음성과 여성 음성 중에서 고를 수 있어요.
- **Number of Loops**: 다음 단계로 넘어가기 전에 메시지를 몇 번 반복할지 정해요. +와 - 버튼으로 반복 횟수를 조절할 수 있고, 기본값은 1회예요.

![Say/Play Message 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041897285/original/_yXbsBRV0ctdMgFl8AU1Tm9uE1TD-elZVA.png?1739979711)

#### Connect Call (IVR) 액션

**Connect Call (IVR)** 액션은 진행 중인 IVR 통화를 선택한 사용자, 부서, 외부 전화번호로 연결해요. 발신자가 추가 도움을 받을 알맞은 사람이나 팀에 빠르게 연결돼요.

이 액션에서는 다음 옵션을 설정할 수 있어요.

- **Connect Call To**(통화 연결 대상): 통화를 어디로 보낼지 선택해요.
- **Select Users**(사용자 선택): 시스템에 있는 사용자 중에서 통화를 받을 사람을 골라요.
- **Add Custom Number**(사용자 지정 번호 추가): 조직 밖으로 통화를 넘겨야 하면 외부 전화번호를 입력해요.
- **Multiple Numbers**(여러 번호): 번호를 최대 10개까지 추가할 수 있어요. 여러 회선에서 동시에 벨이 울려 전화를 받을 가능성이 높아져요.

**Advanced Call Settings**(고급 통화 설정)

- **Detect Voicemail**(음성사서함 감지): 켜면 사람이 전화를 받았는지, 음성사서함으로 넘어갔는지 판단해요. 통화가 불필요하게 음성사서함으로 연결되는 것을 막는 데 도움이 돼요.
  {% hint style="info" %}
  이 기능을 켜면 약간의 지연이 생길 수 있고 추가 요금이 발생할 수 있어요.
  {% endhint %}
- **Record Call**(통화 녹음): 켜면 연결된 통화를 자동으로 녹음해요. 품질 관리나 규정 준수 목적으로 쓸 수 있어요.
- **Timeout (Seconds)**(응답 대기 시간, 초): 상대방이 전화를 받을 때까지 시스템이 기다리는 최대 시간을 정해요. 이 시간이 지나면 다른 곳으로 연결하거나 통화를 끝내요. 기본값은 10초이고, 1초에서 600초 사이로 설정할 수 있어요.
- **Time Limit (Seconds)**(통화 시간 제한, 초): 연결된 통화가 얼마나 오래 이어질 수 있는지 정해요. 기본적으로 시간 제한은 없어요. 통화가 끝없이 이어지지 않도록 최대 24시간까지 제한을 둘 수 있어요.

![Connect Call (IVR) 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041898099/original/FjpmKYteP-O6b7CMk55-SvJzrJf5wxJeMA.png?1739980387)

#### End Call (IVR) 액션

**End Call (IVR)**(통화 종료) 액션은 진행 중인 IVR 통화를 끊어요. 기본적으로 통화는 바로 끝나지만, 끊기 전에 마지막 메시지나 원하는 소리를 재생할 수도 있어요. 마무리 인사든 대기 음악이든, 통화가 끝나기 전에 발신자가 매끄럽게 마무리할 수 있어요.

설정할 수 있는 옵션은 다음과 같아요.

- **Add Voice Instructions**(음성 안내 추가): 통화를 끝내기 전에 메시지나 소리를 재생해 발신자에게 통화가 곧 끝난다는 것을 분명히 알려 줘요.
- **Say or Play Message**: 두 가지 중에서 선택해요.
  - **Say a Message**(메시지 말하기): 시스템이 음성으로 변환할 메시지를 직접 입력해요.
  - **Play a Message**(메시지 재생): 통화를 끊기 전에 재생할 음성 파일을 업로드해요(권장 형식: .wav).
- **Text to Say**: 텍스트 음성 변환을 쓰면, 통화가 끝나기 전에 발신자에게 들려줄 메시지를 입력해요.
- **Language**(언어): IVR 시스템은 현재 텍스트 음성 변환에서 영어(미국)를 지원해요.
- **Message Voice**: 텍스트 음성 변환에 쓸 음성을 선택해요. 선택할 수 있는 옵션은 **Man**(남성), **Woman**(여성)이에요.
- **Number of Loops**: 통화가 끊기기 전에 메시지를 몇 번 반복할지 정해요. 기본값은 1이고, 필요에 따라 늘릴 수 있어요.

![End Call (IVR) 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041898572/original/PnYS-U2q4HxeusttUQ0ApMPUg59YrMJAZA.png?1740031934)

#### Record Voicemail (IVR) 액션

**Record Voicemail (IVR)** 액션은 전화를 받을 사람이 없을 때 발신자가 음성 메시지를 남길 수 있게 해요. 중요한 메시지를 놓치지 않고, 고객 문의가 누락되지 않도록 하려는 비즈니스에 유용해요.

설정할 수 있는 옵션은 다음과 같아요.

- **Play Beep**(비프음 재생): 음성사서함 녹음이 시작됐다는 것을 알리는 비프음을 재생해요. 발신자가 메시지가 녹음되고 있음을 분명히 알 수 있어요.
- **Stop Recording After (Seconds of Silence)**(무음 지속 시 녹음 중단, 초): 무음이 몇 초 이어지면 시스템이 자동으로 녹음을 멈출지 정해요. 기본값은 5초이고, 원하는 정수로 바꿀 수 있어요.
- **Stop Recording on Keypress**(키 입력 시 녹음 중단): 발신자가 지정한 키를 눌러 음성사서함 녹음을 직접 멈출 수 있게 해요. 사용할 수 있는 키 값은 0-9, * 와 # 이에요. 기본적으로 지정된 키가 없어서, 무음 지속 시간에 도달해야만 녹음이 멈춰요.
- **Max Recording Length**(최대 녹음 길이): 음성사서함 녹음의 최대 길이를 정해요. 1초에서 14,400초(4시간) 사이로 설정할 수 있고, 기본값은 3,600초(1시간)예요.
- **Add Voice Instructions**: 음성사서함 녹음을 시작하기 전에 메시지를 재생하는 옵션이에요. 텍스트 음성 변환 메시지나 미리 녹음한 음성 파일을 쓸 수 있어서, 발신자가 음성사서함의 목적을 이해할 수 있어요.

![Record Voicemail (IVR) 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041916436/original/9235Ht5a7ANf1861Qswh9SNGrDX-ZdP5UA.png?1740015762)

#### IVR 워크플로우에서 조건 분기(IF/ELSE 로직) 쓰기

조건 분기를 쓰면 사용자 입력에 따라 통화를 동적으로 라우팅할 수 있어요. 발신자가 알맞은 부서나 동작으로 안내돼요. 워크플로우에서 IF/ELSE 로직을 쓰고, 응답에 따라 서로 다른 경로로 나뉘어요.

예를 들면 다음과 같아요.

발신자가 1번을 누르면 통화를 영업팀으로 라우팅해요.

발신자가 2번을 누르면 통화를 지원팀으로 연결해요.

입력이 없으면 시스템이 안내를 반복하거나 기본 액션으로 라우팅할 수 있어요.

**IVR Gather로 조건 로직 쓰기**

**IVR Gather**(IVR 입력 수집) 액션은 키 입력으로 사용자 응답을 받아요. 발신자가 옵션을 선택하면 시스템이 그 입력을 처리하고, 미리 정한 로직에 따라 다음 단계를 정해요.

IVR Gather에서 조건 로직을 설정하는 순서는 다음과 같아요.

1. **IVR Gather** 액션을 추가하세요. 이 액션이 발신자에게 선택을 요청해요(예: “서비스 문의는 1번, 예약은 2번을 눌러 주세요.”).
2. IF/Else 조건 로직을 설정하세요. 워크플로우에서 **IF/Else Condition**(조건 분기) 액션을 쓰고, 조건 소스로 **IVR Gather**를 선택하세요.
3. 키 입력별 응답을 정하세요.
   - 1번을 누르면 서비스 상세 안내 메시지로 라우팅해요.
   - 2번을 누르면 예약을 위해 상담원에게 연결해요.
4. 응답이 없는 통화를 처리하세요. 입력이 없을 때를 대비해 안내 반복이나 음성사서함 연결 같은 대체 액션을 설정하세요.

## 자주 묻는 질문

### 발신자가 IVR 워크플로우 도중 전화를 끊으면 어떻게 되나요?

발신자가 워크플로우 중간에 전화를 끊어도 연락처는 다음 단계로 넘어가요. 하지만 통화 전환이나 음성사서함 녹음처럼 IVR에만 해당하는 액션은 건너뛰어요. 연락처에 태그를 추가하거나 후속 메시지를 보내는 등 다른 워크플로우 액션은 설정한 대로 계속 실행돼요.

### 하나의 IVR 워크플로우에 여러 전화번호를 사용할 수 있나요?

아니요. 전화번호 하나는 한 번에 IVR 워크플로우 하나에만 지정할 수 있어요.
### IVR 통화를 외부 번호로 연결할 수 있나요?

네. **Connect Call** 액션으로 통화를 시스템 안의 사용자나 외부 번호로 전환할 수 있어요.

### 발신자가 시간 안에 응답하지 않으면 어떻게 되나요?

**IVR Gather** 액션에서 타임아웃 설정을 해서 안내를 반복하거나, 음성사서함 같은 대체 액션으로 통화를 보내도록 정할 수 있어요.

### IVR 통화 녹음은 어디에서 볼 수 있나요?

음성사서함 녹음은 모두 저장되어 있고, 하이퍼클래스의 **대화**에서 볼 수 있어요. 음성사서함 메시지를 확인하고, 내려받고, 효율적으로 관리할 수 있어요.

### IVR 통화에서 블라인드 전환이나 웜 전환을 할 수 있나요?

아니요. 현재 IVR 통화가 웹 앱으로 라우팅되면 블라인드 전환과 웜 전환을 지원하지 않아요.
