# 워크플로우 트리거 - 메시징 오류 코드 - SMS(문자)

## 개요

"메시징 오류 - SMS" 트리거를 사용하면 SMS(문자)가 전송되지 않고 아래에 나열된 오류 코드 중 하나가 반환됐을 때 워크플로우를 자동으로 시작할 수 있어요.

## 트리거 이름

메시징 오류 - SMS

## 트리거 설명

이 트리거는 전송되지 않은 메시지에 대해 수신된 오류를 기준으로 워크플로우를 실행해요. 이를 활용하면 연락처(Contacts) 목록을 정리하기 위한 적절한 조치를 취할 수 있고, 결과적으로 전달률을 개선할 수 있어요.

## 설정 방법

- **워크플로우 트리거 선택:**
  드롭다운 목록에서 "메시징 오류 - SMS"를 선택하세요.
- **워크플로우 트리거 이름:**
  워크플로우 안에서 쉽게 구분할 수 있도록 설명이 담긴 이름을 입력하세요.
- **필터:**
  아래 나열된 특정 오류 코드로 트리거를 좁히기 위해 필터를 추가할 수 있어요:

| 코드 | 설명 |
|---|---|
| 30007 | 통신사 정책 위반 |
| 30034 | 번호에 대한 A2P 등록 대기 중 |
| 30032 | 무료 수신 번호(Toll Free) 미인증 |
| 30005 | 사용자 비활성/존재하지 않는 번호 |
| 30003 | 연결 불가/서비스 정지 번호 |
| 30004 | SMS 수신 거부/DND 활성화 |
| 30006 | 유선전화/SMS 수신 불가 |
| 30023 | US A2P 10DLC - 일일 메시지 발송 한도 도달 |
| 21408 | 해당 지역에 대한 SMS 발송 권한 미활성화 |
| 30008 | 알 수 없는 오류 |
| 21606 | 잘못된 '발신' 전화번호 |
| 21211 | 잘못된 '수신' 전화번호 |
| 21614 | '수신' 번호가 유효한 휴대폰 번호가 아님 |
| 21610 | 사용자가 STOP으로 응답함(수신 거부) |
| 30011 | 수신 번호 또는 지역에서 MMS 미지원 |
| 30033 | A2P 캠페인이 중단되거나 삭제됨 |
| 21661 | '발신' 번호가 SMS 발송 불가능한 번호임 |
| 21635 | '수신' 번호가 유선전화일 수 없음 |
| 30037 | 발신 메시징 비활성화됨 |
| 30002 | 하위 계정(Sub-account) 정지됨 |

## 예시
