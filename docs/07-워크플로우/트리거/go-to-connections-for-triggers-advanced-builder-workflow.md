# 트리거별 시작 액션 연결 — Go-To Connections for Triggers(Advanced Builder)

**Advanced Builder**(고급 빌더)의 캔버스에서 트리거마다 경로를 시작할 액션을 직접 정하는 기능이에요. 워크플로우를 복제하거나 if/else 분기를 길게 쌓지 않고도 복잡한 진입 조건을 깔끔하게 정리할 수 있어요.

{% hint style="info" %}
노드와 노드를 연결하세요. 트리거의 작은 연결 점을 클릭하고 액션의 연결 점까지 끌어다 놓으면 돼요.
{% endhint %}

## Go-To Connections for Triggers란?

Go-To Connections for Triggers는 점선 연결선이에요. 워크플로우 캔버스에서 트리거마다 서로 다른 "첫 번째 액션"을 정할 수 있어요. 트리거 조건이 맞으면 연락처는 연결된 액션으로 바로 이동하고, 거기서부터 워크플로우가 이어져요. 돌아가는 단계도, 중복된 워크플로우도 필요 없어요.

트리거에서 캔버스의 원하는 액션까지 Go-To 연결을 끌어다 놓으면 돼요. 이제 진입 경로가 하나로 고정되지 않고, 트리거마다 진입 경로를 따로 정할 수 있어요.

{% hint style="warning" %}
1. **Advanced Builder**에서만 쓸 수 있어요. Go-To Connections for Triggers는 Advanced Builder 전용 기능이에요.
2. 모든 트리거는 한 번 연결되어야 해요. 연결하지 않은 트리거는 **Root**(첫 번째 액션)에 자동으로 연결되지만, 올바른 시작 액션을 직접 지정하는 것이 좋아요.
3. 연락처는 한 번만 진입해요. 한 연락처가 같은 워크플로우의 여러 분기를 동시에 진행하지 않아요.
4. **Standard Builder**(기본 빌더)로 돌아갈 때는 Advanced Builder 전용 기능(**Trigger Go-To**, **Delinked nodes**(연결이 끊긴 노드), **Disabled nodes**(비활성화된 노드))을 먼저 없애야 해요.
{% endhint %}

## 이럴 때 좋아요

- 트리거 하나에 여정 하나를 연결해서, 워크플로우 하나 안에 진입 경로를 여러 개 만들 수 있어요.
- 거대한 if/else 분기가 없어져서 캔버스를 한눈에 보기 쉬워요.
- 연락처가 불필요한 단계를 건너뛰고 원하는 위치에서 바로 시작해요.
- 점선을 새로 끌어다 놓으면 트리거가 가리키는 곳을 몇 초 만에 바꿀 수 있어요.

## 동작 방식

1. 트리거마다 시작 액션을 정해요. 트리거에서 그 트리거가 시작할 액션까지 점선 Go-To 연결을 끌어다 놓으세요.
2. 경로가 눈에 잘 보여요. 트리거의 Go-To 연결은 화살촉이 있는 점선으로, 일반 순차 경로는 실선으로 표시돼요.
3. 바로 실행돼요. 트리거 조건이 맞으면 워크플로우가 연결된 시작 액션으로 곧장 이동하고, 거기서부터 이어져요.

예시:

트리거마다 Go-To 연결을 여러 개 설정해서, 그 트리거가 실행될 때 연락처가 어디서 시작할지 정할 수 있어요.

## 연결 규칙 (빌더)

- 1:1 연결만 가능해요. 트리거 하나는 다음 액션 하나에만 연결할 수 있고, 액션 하나는 들어오는 연결을 하나만 가질 수 있어요(트리거 또는 이전 액션에서 오는 연결).
- 액션 하나에서 갈라질 수 없어요. 액션에는 **Next step**(다음 단계)이 하나만 있어요. 이미 다음 단계가 있는 액션을 다른 액션에 연결하면 기존 연결이 덮어써져요. 이전 연결은 사라져요.

## 진입 규칙 (연락처가 들어오는 방식, Enrollment Rules)

한 번 진입할 때 트리거는 하나예요. 연락처는 한 번 실행할 때 워크플로우에 한 번 진입하고, 그 진입은 조건이 맞은 트리거 하나에 연결돼요. 내레이션과 통계에도 그 트리거가 반영돼요.

- 같은 시점에 여러 트리거가 조건을 충족해도, 워크플로우는 그 시점의 진입을 한 번만 기록해요(트리거 하나에 연결).
- 워크플로우 설정에서 재진입을 허용했다면, 다른 트리거가 실행될 때 같은 연락처가 나중에 다시 진입할 수 있어요. 이때도 실행은 항상 트리거 하나로 시작돼요.

## 주요 동작

- 점선 연결선: Trigger Go-To는 트리거에서 시작 액션까지 이어지는 화살촉 달린 점선으로 표시돼요.
- 기본("연결되지 않은") 동작: Go-To를 설정하지 않은 트리거는 **Root**(첫 번째 액션)에 자동으로 연결돼요.
- 저장 규칙: 워크플로우를 저장하려면 모든 트리거가 액션 하나에 정확히 연결되어 있어야 해요. 점선 연결선을 끌어다 놓으면 언제든 다시 지정할 수 있어요.
- 실행: 트리거 조건이 맞으면 연락처는 대상 액션으로 바로 이동하고, 나머지 경로는 평소처럼 진행돼요.

## Go-To Connections for Triggers 사용하기

1. **Advanced Builder**에서 워크플로우를 열어요.
2. 트리거와 액션을 추가하고 배치해요.
3. 각 트리거에서 시작할 액션까지 점선 Go-To 연결을 끌어다 놓아요.
4. 나중에 바꾸려면 같은 연결선을 다른 노드로 끌어다 놓아요.
5. 준비가 끝나면 **Save**(저장)를 누르고 **Publish**(게시)를 눌러요.

## 자주 묻는 질문

### 트리거 하나에 Go-To 연결을 여러 개 만들 수 있나요?
아니요. 실행 경로가 하나로 정해지도록 트리거는 액션 하나에만 연결해야 해요.

### 트리거가 가리키던 액션을 삭제하면 어떻게 되나요?
Go-To 연결이 유효하지 않게 되어, 새 대상을 지정할 때까지 트리거가 **Root** 액션에 자동으로 다시 연결돼요.

### 다시 게시하면 이미 워크플로우에 있던 연락처도 새 경로를 따르나요?
아니요. 경로 변경은 업데이트를 게시한 뒤 워크플로우에 진입하는 연락처에만 적용돼요.

### Trigger Go-To가 있는 워크플로우를 스냅샷으로 내보낼 수 있나요?
네. 스냅샷에는 Trigger Go-To를 포함한 **Advanced Builder** 기능이 모두 그대로 담겨요.

### Standard Builder에서도 이 기능을 쓸 수 있나요?
아직은 쓸 수 없어요. **Advanced Builder**에 계속 머물거나, 전환하기 전에 점선 연결을 없애야 해요.
