# 워크플로우 트리거 복사·삭제 — Copy, Delete

워크플로우 편집 화면에서 트리거를 복사해 재사용하고, 필요 없는 트리거는 한 번에 삭제하는 방법을 안내해요. 비슷한 트리거를 여러 개 만들거나 테스트용 트리거를 정리할 때 쓰면 편해요.

## 트리거 복사·삭제 기능이란?

이제 트리거를 더 빠르게 복제하고 삭제할 수 있어요. 예전에는 비슷한 트리거를 직접 다시 만들어야 했고, 삭제하려면 트리거를 하나씩 열어야 했어요.

지금은 어떤 트리거든 설정을 그대로 유지한 채 바로 복제할 수 있어요. 삭제도 캔버스에서 드롭다운 메뉴로 바로 할 수 있어요.

## 주요 장점

트리거를 재사용하고 관리하기가 한결 쉬워져요.

- 몇 초 만에 복제: 트리거를 복사해 바로 재사용할 수 있어요.
- 자동 이름 지정: 복제한 트리거에는 **Copy of "[Trigger Name]"**(트리거 이름 복사본)이라는 이름이 붙어서 원본을 바로 알 수 있어요.
- 빠른 편집: 복사한 트리거의 필터 조건만 간단히 고치면 돼요.
- 한 번에 삭제: 트리거를 열지 않고도 삭제할 수 있어요.
- 더 깔끔한 워크플로우 캔버스: 자동화 로직을 정리하고 다듬기 쉬워요.
- 수작업 실수 감소: 검증된 트리거 설정을 복제해서 쓰면 실수가 줄어요.

## 트리거 복사·삭제 사용 방법

트리거 카드의 메뉴에서 새 옵션을 사용해 워크플로우 편집 속도를 높여 보세요.

## 트리거 복사

자동화끼리 로직이 비슷하다면 트리거를 복사해서 더 빠르게 만들 수 있어요. 처음부터 만들지 않고, 기존 트리거를 복제한 다음 조금만 고치면 돼요.

### 트리거를 복사하는 순서

1. 트리거 카드의 점 세 개 메뉴를 클릭하세요.
2. **Copy**(복사)를 선택하세요.
   ![트리거 카드의 점 세 개 메뉴에서 Copy를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047382614/original/c0oIeCXRZh79HNaMnwzh4N5iC6ylO7161g.png?1748447921)
3. **Copy of "[Trigger Name]"**이라는 이름의 새 트리거가 나타나요.
4. 필요하면 트리거의 필터나 조건을 수정하세요.
   ![복사된 트리거의 필터와 조건을 수정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047382627/original/vBlbEL7IPcknxYPIHp-agur8zn50flO2PQ.png?1748447943)
5. **Save**(저장)를 클릭하세요.

{% hint style="info" %}
팁: 같은 트리거를 여러 번 복사한 다음, 연락처 대상이나 로직 분기에 맞게 각각 조정할 수 있어요.
{% endhint %}

## 트리거 삭제

이제 트리거를 먼저 열지 않아도 바로 삭제할 수 있어요. 테스트용 트리거나 오래된 자동화 로직을 정리할 때 편해요.

### 트리거를 삭제하는 순서

1. 트리거 카드의 점 세 개 메뉴를 클릭하세요.
2. **Delete**(삭제)를 클릭하세요.
   ![트리거 카드의 점 세 개 메뉴에서 Delete를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047382707/original/vYDC540acTYyNilb5M-h9VnhiOSh0veRSQ.png?1748447995)
3. 삭제를 확인하세요.
4. 트리거가 워크플로우에서 바로 사라져요.

{% hint style="warning" %}
주의: 삭제하면 되돌릴 수 없어요. 트리거를 지우기 전에 꼭 확인하세요.
{% endhint %}

## 자주 묻는 질문

### 복사한 트리거에도 원본의 필터 설정이 모두 들어 있나요?

네, 복제한 트리거는 필터, 로직, 설정까지 원본과 똑같아요.

### 복사한 트리거의 이름을 바꿀 수 있나요?

네, 복사한 트리거를 열고 **Trigger Name**(트리거 이름) 필드에서 이름을 수정하세요.

### 트리거를 삭제하면 이미 실행된 자동화에 영향이 있나요?

아니요. 현재 워크플로우 캔버스에서 트리거만 삭제되고, 이전에 실행된 자동화에는 영향을 주지 않아요.

### 삭제한 트리거를 되돌릴 수 있나요?

아직은 되돌리기 기능이 없어요. 삭제를 확인하기 전에 한 번 더 확인하세요.

### 트리거 복사 기능은 어디서 쓸 수 있나요?

트리거 카드가 있는 워크플로우라면 어디서든 쓸 수 있어요. 제한은 없어요.

## 다음 단계

- 자주 쓰는 워크플로우를 열어서 트리거를 복사해 보세요. 만드는 시간이 줄어들어요.
- 삭제 옵션으로 테스트용 트리거나 쓰지 않는 로직을 정리해 보세요.
- 워크플로우 자동화에 앞으로 추가될 개선 사항도 살펴보세요.
- 워크플로우가 처음이라면 [워크플로우와 자동화 소개](../introduction-to-workflows-and-automations.md)를 먼저 읽어 보세요.
