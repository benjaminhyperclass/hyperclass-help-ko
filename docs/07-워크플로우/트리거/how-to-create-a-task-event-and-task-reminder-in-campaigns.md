# 캠페인에서 작업 이벤트와 작업 알림 트리거 만들기 — Task Event, Task Reminder(작업 알림)

하이퍼클래스 **캠페인**에 작업 이벤트(**Task Event**)와 작업 알림(**Task Reminder**) 트리거를 추가하는 방법을 안내해요. 연락처가 캠페인의 특정 단계에 도달하면 팀원에게 할 일을 배정해서, 내부 후속 조치를 자동화할 수 있어요.

## 캠페인과 트리거 개요

### 캠페인에서 작업 이벤트 만들기

작업 이벤트(**Task Event**)를 쓰면 연락처가 거치는 주요 시점마다 팀원에게 내부 할 일을 배정할 수 있어요. 연락처가 캠페인의 특정 단계에 도달했을 때 처리해야 하는 알림이나 수동 할 일로 쓰여요.

작업 이벤트는 내부 업무를 간소화하는 데 쓰세요. 예를 들면 팀원에게 리드에게 후속 연락하기, 전화 걸기, 계정 검토하기를 알려 줄 수 있어요. 캠페인 단계 안에서 작업 이름, 마감일, 우선순위, 메모, 담당자를 직접 설정할 수 있어요.

### Task Reminder 트리거 설정하기

**Task Reminder**(작업 알림) 트리거를 쓰면 작업에서 일어난 일을 기준으로 자동화를 시작할 수 있어요. 작업 완료, 담당자 배정, 상태 변경 같은 경우가 해당돼요. 팀이 작업을 처리하는 방식에 맞춰 후속 조치가 자동으로 실행되길 원할 때 유용해요.
