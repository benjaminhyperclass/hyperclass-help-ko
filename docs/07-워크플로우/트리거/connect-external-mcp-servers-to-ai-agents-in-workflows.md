# 워크플로우의 AI 에이전트에 외부 MCP 서버 연결하기

워크플로우의 AI 에이전트(**AI Agent** 액션)를 MCP(Model Context Protocol)로 외부 서비스에 연결하는 방법을 안내해요. 웹 검색, 브라우저 자동화, 데이터베이스, 직접 만든 API 같은 도구에서 실시간 정보를 가져올 수 있어요. CRM 데이터 밖의 정보까지 활용하면 조사를 자동화하고, 레코드를 보강하고, 더 똑똑한 워크플로우 액션을 만들 수 있어요.

## AI 에이전트의 MCP 연결이란?

MCP(Model Context Protocol)는 AI 애플리케이션이 외부 도구·서비스와 안전하게 통신하도록 하는 개방형 표준이에요. 워크플로우에서 MCP 연결을 쓰면 AI 에이전트가 호환되는 MCP 서버에 연결해, 워크플로우 액션을 실행하는 동안 그 서버의 도구를 사용할 수 있어요.

기본 AI 에이전트 기능은 주로 하이퍼클래스 안에 있는 정보를 바탕으로 동작해요. MCP 연결을 쓰면 에이전트가 실시간 정보를 가져오고, 브라우저 작업을 자동화하고, 검색을 수행하고, 외부 시스템과 실시간으로 상호작용할 수 있어요.

---

## MCP 연결의 주요 이점

외부 MCP 서버를 연결하면 워크플로우를 실행하는 동안 AI 에이전트가 할 수 있는 일이 늘어나요.

- 실시간 데이터 접근: 워크플로우가 실행되는 동안 외부 서비스에서 최신 정보를 가져올 수 있어요.
- 확장 가능한 AI 기능: 기본 제공 도구에 한정되지 않고, 호환되는 어떤 MCP 서버든 연결할 수 있어요.
- 자동 도구 탐색: 연결을 테스트하면 사용할 수 있는 도구를 자동으로 찾아 줘요.
- 세분화된 도구 권한: AI 에이전트마다 사용할 수 있는 도구를 정확히 골라 줄 수 있어요.
- 워크플로우 자동화: AI 에이전트가 외부 서비스와 직접 상호작용하므로 수동 조사와 반복 작업을 줄일 수 있어요.
- 유연한 인증: MCP 제공업체에 따라 여러 인증 방식을 지원해요.

---

## 지원하는 MCP 서버

하이퍼클래스는 MCP와 호환되는 서버라면 어디든 연결할 수 있어요.

대표적인 예는 다음과 같아요.

- Exa – 기업, 인물, 뉴스를 대상으로 한 AI 기반 웹 검색
- Tavily – 실시간 웹 검색과 웹페이지 추출
- Browserbase – 페이지 이동, 클릭, 스크린샷, 데이터 추출을 위한 브라우저 자동화
- 사용자 지정 MCP 서버 – MCP 사양을 따르는, 직접 호스팅했거나 사내에서 개발한 MCP 서버

{% hint style="info" %}
하이퍼클래스는 외부 업체의 MCP 서버를 호스팅하거나 관리하지 않아요. 서버 이용 가능 여부, 가격, 인증 요건, 지원하는 도구는 해당 제공업체가 정해요.
{% endhint %}

---

## 인증 옵션

MCP 제공업체마다 필요한 인증 방식이 달라요. 하이퍼클래스는 다양한 서비스에 맞춰 여러 인증 유형을 지원해요.

지원하는 인증 방식은 다음과 같아요.

- **None**(없음)
- **API Key**(API 키)
- **Bearer Token**(베어러 토큰)
- **OAuth2**
- **Custom Header**(사용자 지정 헤더)

제공업체에 따라 API 키를 HTTP 헤더로 전달하기도 하고, 쿼리 파라미터로 전달하도록 요구하기도 해요. 올바른 설정 방법은 사용하는 MCP 제공업체의 문서를 확인하세요.

---

## 지원하는 전송 유형

전송 유형은 하이퍼클래스가 MCP 서버와 통신하는 방식을 정해요.

지원하는 전송 옵션은 다음과 같아요.

- **HTTP Streamable**(기본값)
- **Server-Sent Events (SSE)**(서버 전송 이벤트)

제공업체가 따로 지정하지 않았다면 권장 기본값인 **HTTP Streamable**을 사용하세요.

---

## 도구 탐색 방식

연결 정보를 입력하면 하이퍼클래스가 연결을 확인하고, MCP 서버가 제공하는 도구를 가져와요.

**Test Connection**(연결 테스트)을 선택하면 다음 작업이 진행돼요.

- 서버와 통신이 되는지 확인해요.
- 인증 자격 증명이 올바른지 확인해요.
- 사용할 수 있는 도구를 자동으로 찾아요.
- MCP 서버가 돌려준 도구를 모두 보여 줘요.

도구를 찾은 뒤에는 AI 에이전트가 사용할 수 있는 도구를 선택해요.

---

## MCP 연결 설정하기

설정을 제대로 해 두면 워크플로우를 실행하는 동안 AI 에이전트가 외부 서비스와 안전하게 통신할 수 있어요.

1. 원하는 워크플로우를 여세요.
2. **AI Agent**(AI 에이전트) 액션을 추가하거나 편집하세요.
3. **Add Tools**(도구 추가)를 선택하세요.

   ![도구 추가 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075528017/original/tAnm6_KhDvo0fiNH5zIJD8U63K63H8X54w.png?1783518106)
4. **MCP** 탭을 여세요.

   ![MCP 탭 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075528140/original/4yKAL_sQBGQZIafmA-Z9vBRyVQagnu9nlw.png?1783518152)
5. **Add Connection**(연결 추가)을 클릭하세요.

   ![연결 추가 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075528294/original/xtoMJjTQ1Tbh03IciVOAf3BMnylMa427cA.png?1783518193)
6. 연결 정보를 입력하세요.
   - **Connection Name**(연결 이름)에 알아보기 쉬운 이름을 입력하세요.
   - **Server URL**(서버 URL)에 MCP 제공업체가 알려 준 서버 URL을 입력하세요.
   - **Transport Type**(전송 유형)에서 알맞은 유형을 선택하세요.
   - **Authentication Type**(인증 유형)에서 필요한 유형을 선택하세요.
   - 필요한 자격 증명을 입력하세요.

   ![연결 정보 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075528721/original/CUKOQ4tJfUyQE_pu5RgatQ_pbKTpTMRhAg.png?1783518316)
7. **Test Connection**(연결 테스트)을 클릭하세요.

   ![연결 테스트 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075529008/original/MNO4-rmrRsQBsYdOWsxZtMAgvK7FgKNXgg.png?1783518387)
8. 찾아낸 도구를 확인하세요.
9. AI 에이전트가 사용해도 되는 도구만 켜요.
10. 연결을 저장하세요.

---

## 도구 권한 관리

MCP 서버 하나가 여러 도구를 제공하는 경우가 많아요. 모든 워크플로우에 모든 기능이 필요하지는 않아요.

도구 접근을 제한하면 보안이 좋아지고, AI의 판단이 단순해지고, 에이전트가 승인된 작업만 수행하게 돼요.

연결을 테스트한 뒤에 다음과 같이 진행하세요.

- 찾아낸 도구를 확인하세요.
- 필요한 도구만 켜요.
- 워크플로우에 필요 없는 도구는 끄세요.
- 선택한 내용을 저장하세요.

이 권한은 AI 에이전트 단위로 적용돼요. 같은 서버에 연결하더라도 에이전트마다 다른 도구 조합을 쓸 수 있어요.

---

## 모범 사례

아래 권장 사항을 따르면 외부 MCP 서비스를 더 안정적이고 안전하게 쓸 수 있어요.

- 신뢰할 수 있는 MCP 제공업체만 연결하세요.
- 연결마다 알아보기 쉬운 이름을 쓰세요.
- 워크플로우에 필요한 도구만 켜세요.
- 운영 중인 워크플로우를 활성화하기 전에 모든 연결을 테스트하세요.
- 조직의 보안 정책에 맞춰 API 자격 증명을 주기적으로 교체하세요.
- 외부 서비스가 정상 운영되는지 확인하세요.
- 워크플로우가 바뀌면 도구 권한을 정기적으로 점검하세요.

## 자주 묻는 질문

### MCP 서버가 무엇인가요?
MCP 서버는 AI 애플리케이션이 Model Context Protocol을 통해 사용할 수 있는 도구를 제공하는 서버예요.

### AI 에이전트 하나에 MCP 서버를 여러 개 연결할 수 있나요?
AI 에이전트 구성에서 지원하는 경우 MCP 연결을 여러 개 추가할 수 있어요. 그러면 에이전트가 서로 다른 제공업체의 도구를 함께 쓸 수 있어요.

### 하이퍼클래스에서 MCP 서버를 제공하나요?
아니요. 하이퍼클래스는 호환되는 MCP 서버에 연결하는 기능을 제공해요. 서버의 호스팅과 관리는 외부 제공업체나 사용자의 조직이 맡아요.

### 연결 테스트가 실패하면 어떻게 하나요?
서버 URL, 인증 설정, API 자격 증명, 전송 유형을 확인하세요. MCP 서버가 온라인 상태이고 접속할 수 있는지도 확인하세요.

### AI 에이전트가 사용하는 도구를 제한할 수 있나요?
네. 도구를 찾은 뒤 연결을 저장하기 전에 도구를 하나씩 켜거나 끌 수 있어요.

### 외부 MCP 서비스도 하이퍼클래스 구독에 포함되어 있나요?
아니요. 외부 제공업체는 별도 계정, 구독, API 사용료를 요구할 수 있어요.
