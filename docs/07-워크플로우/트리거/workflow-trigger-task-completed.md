# 워크플로우 트리거 — Task Completed(작업 완료)

**Task Completed**(작업 완료) 트리거를 쓰면 작업이 완료됐을 때 후속 작업을 자동으로 실행할 수 있어요. 사용자에게 할당된 작업이 완료로 표시되는 순간 워크플로우가 시작돼요.

## 개요

**Task Completed** 트리거는 작업 완료를 기준으로 후속 작업을 자동화해요. 사용자에게 할당된 작업이 완료로 표시되면 워크플로우를 시작하므로, 작업과 관련된 처리를 효율적으로 이어 갈 수 있어요.

## 트리거 이름

**Task Completed**

## 트리거 설명

사용자에게 할당된 작업이 완료되면 이 트리거가 실행돼요. 작업 완료를 기준으로 워크플로우를 자동으로 다음 단계로 넘길 때 유용해요. 팀에 알리거나, 연락처에 후속 연락을 하거나, 시스템 상태를 업데이트하는 경우가 그 예예요. 특정 사용자나 작업에 연결된 커스텀 필드를 기준으로 필터를 걸어, 해당하는 경우에만 실행되게 할 수도 있어요.

## 트리거 상세 정보

| 필드 이름 | 설명 | 필수 여부 |
| --- | --- | --- |
| **Assigned User**(할당된 사용자) | 작업이 할당된 사용자예요. 특정 사용자를 지정할 수 있고, 비워 두면 작업을 완료하는 모든 사용자에게 적용돼요. | 아니요 |
| **Business Niche**(비즈니스 니치) | 연락처나 작업에 연결된 비즈니스 니치를 기준으로 작업 완료를 걸러 내는 커스텀 필드예요. | 아니요 |
| **Description**(설명) | 작업 설명에 들어 있는 특정 내용을 기준으로 작업 완료를 걸러 내는 데 쓸 수 있는 커스텀 필드예요. | 아니요 |

## 설정 방법

1. **Workflow Trigger**(워크플로우 트리거) 목록에서 **Task Completed**를 선택해요.
2. **Trigger Name**(트리거 이름)에 설명이 되는 이름을 입력해요. 예를 들면 "작업 완료 후속 조치"처럼 쓸 수 있어요.
3. 필요하면 **Apply Filters**(필터 적용)로 필터를 추가해 트리거가 실행되는 조건을 좁혀요. 이 단계는 선택 사항이에요.
   - 예를 들어 특정 사용자가 완료한 작업에만 트리거가 실행되게 할 수 있어요.
   - 커스텀 필드에 특정 값이 들어 있는 작업에만 실행되게 할 수도 있어요.
4. 트리거와 필터 설정을 마쳤으면 저장해요.

## 예시

영업 작업을 특정 사용자가 완료하면, 연락처에 후속 이메일이 자동으로 나가게 하고 싶다고 해 볼게요.

- **Trigger Name:** 영업 작업 완료
- **Assigned User:** John Doe
- **Filter:** Business Niche = 부동산

John Doe가 부동산 니치 연락처에 할당된 작업을 완료하면 이 트리거가 실행돼요. 그러면 워크플로우가 다음 단계로 넘어가서, 연락처에 이메일을 보내거나 CRM 상태를 업데이트하는 식으로 이어 갈 수 있어요.
