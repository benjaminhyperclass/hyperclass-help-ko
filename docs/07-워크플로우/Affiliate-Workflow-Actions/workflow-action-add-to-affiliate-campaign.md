# 워크플로우 액션 — Add To Affiliate Campaign(제휴 캠페인에 추가)

**Add To Affiliate Campaign**(제휴 캠페인에 추가) 액션은 연락처를 선택한 제휴 캠페인에 활성 제휴 파트너로 추가해요. 기존 연락처나 고객을 특정 제휴 캠페인의 제휴 파트너로 등록할 때 쓰면 편해요.

## 개요

**Add To Affiliate Campaign** 액션은 연락처를 선택한 제휴 캠페인에 활성 제휴 파트너로 추가해요. 기존 연락처나 고객을 특정 제휴 캠페인의 제휴 파트너로 등록할 때 유용해요.

## 액션 이름

**Add To Affiliate Campaign**

## 액션 설명

**Add To Affiliate Campaign** 액션은 기존 연락처를 선택한 제휴 캠페인의 제휴 파트너로 자동 전환해 줘요.

## 액션 상세 정보

### 설정 순서

1. **액션 유형 선택:** 사용할 수 있는 액션 목록에서 **Add To Affiliate Campaign**을 선택해요.
2. **액션 이름 입력:** 액션을 알아보기 쉬운 이름으로 입력해요. 예: "캠페인 XYZ에 제휴 파트너 등록"
3. **제휴 캠페인 선택:** 드롭다운에서 새로 모집한 제휴 파트너를 추가할 제휴 캠페인을 선택해요.
   ![제휴 캠페인 선택 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031801410/original/FJOIM0KpBTlNCb3wfUuxX6OH7cB8OypTKg.png?1724838721)

## 예시

연락처에 태그가 추가되면 기존 연락처를 제휴 테스트 캠페인의 제휴 파트너로 전환하기

시나리오: 어떤 업체가 게시물에 댓글을 남겼거나 제휴 네트워크 참여에 관심을 보인 고객을 제휴 파트너로 모집하려고 해요. 담당자는 이런 연락처에 태그를 추가해 구분한 뒤 활성 제휴 파트너로 전환해요. 그리고 새 제휴 파트너를 제휴 테스트 캠페인에 자동으로 추가하려고 해요.

**액션 설정:**

- 액션: **Add To Affiliate Campaign**
- 이름: 제휴 테스트 캠페인에 제휴 파트너로 등록

**워크플로우 트리거:**

1. **Contact Changed**(연락처 변경): 선택한 필터 값이 바뀌거나 추가되면 연락처가 워크플로우에 들어와요.
2. **Filters**(필터): **Tags added**(태그 추가됨)에 "제휴" 태그를 지정해요.

**워크플로우 액션:**

1. **Add To Affiliate Campaign**을 추가해요.
2. 제휴 테스트 캠페인을 선택해요.

**결과:**
연락처에 이 태그가 추가될 때마다 해당 연락처가 제휴 파트너로 전환되어 제휴 테스트 캠페인에 추가돼요. 이제 이 제휴 파트너는 상품이나 서비스를 판매해 수수료를 벌 수 있어요.
