# 워크플로우 액션 — Manual SMS(수동 SMS)

**Manual SMS**(수동 SMS) 액션은 담당 사용자가 연락처에게 직접 SMS를 보내도록 작업을 만들어 주는 액션이에요. 사람이 직접 보내야 하는 맞춤 메시지가 필요할 때 사용해요. 만들어진 작업은 **대화 > 수동 작업** 탭에 표시돼요.

## 액션 이름

**Manual SMS**(수동 SMS)

## 액션 설명

이 액션은 특정 연락처에게 SMS를 보내는 수동 작업을 만들어요. 사용자가 직접 메시지를 확인하고 보내야 해요. 사용자는 템플릿을 고르고, 커스텀 값과 트리거 링크를 넣고, 보내기 전에 메시지를 테스트할 수 있어요. 기본 담당자인 연락처 담당자 대신 특정 사용자에게 작업을 배정할 수도 있어요.

## 액션 상세 정보

| 필드 | 설명 | 필수 |
| --- | --- | --- |
| **Action Name**(액션 이름) | 워크플로우에서 이 액션을 구분하기 위한 이름이에요. | 예 |
| **Templates**(템플릿) | 미리 만들어 둔 SMS 템플릿 중에서 하나를 선택해요. | 아니요 |
| **Message**(메시지) | 보낼 메시지 본문이에요. 커스텀 값과 트리거 링크를 넣을 수 있어요. | 예 |
| **Custom Values**(커스텀 값) | 메시지를 개인화할 때 쓰는 커스텀 값이에요. 연락처 이름, 예약 정보 등이 있어요. | 아니요 |
| **Add Attachment**(첨부파일 추가) | URL을 입력해 SMS에 첨부파일을 추가해요. | 아니요 |
| **Test Phone Number**(테스트 전화번호) | 테스트 SMS를 받을 전화번호예요. 국가 선택은 서브 계정의 국가가 기본으로 선택돼 있어요. 다른 국가가 필요하면 선택한 뒤 해당 국가의 지역 번호 형식으로 번호를 입력하세요. | 아니요 |
| **Assign To**(담당자 지정) | 수동 SMS 작업을 맡길 사용자를 선택해요. **Advanced Settings**(고급 설정) 아래에 있어요. 비워 두면 연락처 담당자에게 배정돼요. 선택한 사용자에게 연락처 접근 권한이 없으면 작업이 연락처 담당자에게 배정되거나, **Unassigned**(미배정) 상태가 돼요…| 아니요 |

### 설정 방법

1. **Select Template**(템플릿 선택): 필요하면 미리 만들어 둔 SMS 템플릿을 선택하세요. 템플릿 내용이 메시지 필드에 자동으로 채워져요.
2. **Enter Message**(메시지 입력): 보낼 메시지를 작성하세요. **Custom Values** 드롭다운에서 연락처 이름, 예약 정보 같은 값을 골라 넣으면 연락처마다 다른 내용이 들어가요.
3. **Add Attachment**: 첨부파일이 필요하면 URL을 입력해 추가하세요.
4. **Test SMS**(테스트 SMS): 전화번호를 입력해 SMS가 받는 사람에게 어떻게 보이는지 확인하세요.
5. **Test SMS:** **Test Phone Number** 필드의 국가 국기를 확인하세요. 서브 계정의 국가가 기본으로 선택돼 있어요. 다른 국가를 쓰려면 국기를 클릭한 뒤 국가 이름이나 국가 번호로 검색하세요. 선택한 국가의 지역 번호 형식으로 전화번호를 입력하고 **Send test SMS**(테스트 SMS 발송)를 클릭하세요.
6. 하이퍼클래스는 테스트 SMS를 보내기 전에 번호를 국제 번호 형식으로 저장해요. 번호가 올바르지 않으면 필드에 **Invalid phone number**(유효하지 않은 전화번호예요)라고 표시돼요.
7. **Assign To**(**Advanced Settings**): 필요하면 작업을 맡길 사용자를 선택하세요. 선택한 사용자가 기본 담당자인 연락처 담당자보다 우선해요.

### 커스텀 값과 트리거 링크

Manual SMS 액션은 메시지 본문에 커스텀 값과 **Trigger Links**(트리거 링크)를 넣을 수 있어요.

트리거 링크는 클릭할 수 있고, 연락처를 특정 동작으로 연결해 줘요. 예를 들어 캘린더 커뮤니티에 참여하거나 커스텀 폼을 작성하게 할 수 있어요.

### Assign To 동작 방식

**Advanced Settings**의 **Assign To** 필드를 쓰면 수동 SMS 작업을 연락처 담당자 대신 특정 사용자에게 배정할 수 있어요. 연락처 담당자가 누구든 특정 팀원이 맡아야 하는 작업이 있을 때 유용해요.

**배정 기준**

- 사용자를 선택했고 그 사용자에게 연락처 접근 권한이 있으면, 작업은 그 사용자에게 배정돼요.
- 사용자를 선택했지만 연락처 접근 권한이 없으면, 작업은 연락처 담당자에게 배정돼요.
- 선택한 사용자가 없으면, 작업은 연락처 담당자에게 배정돼요.
- 선택한 사용자도 연락처 담당자도 없으면, 작업은 **Unassigned** 상태가 돼요.

## 예시

- **Trigger**(트리거): 리드가 웹사이트의 폼을 작성했을 때
- **Action**(액션): 배정된 사용자가 후속 SMS를 보내도록 Manual SMS 작업을 만들어요.
- **Message**: "{{Contact Name}}님, 폼을 작성해 주셔서 감사합니다. 여기를 눌러 예약해 주세요: [Calendar Link]."
- **Test Phone Number:** 국가 선택에서 알맞은 국가를 확인한 뒤, 테스트 번호를 지역 번호 형식으로 입력해요.

이 예시에서는 리드가 폼을 제출하면 예약 링크가 담긴 맞춤 SMS를 보내는 수동 작업이 만들어져요. 메시지는 커스텀 값으로 내용을 개인화하고, 트리거 링크로 일정 예약을 안내해요.
