# 워크플로우 액션 — Voicemail(음성 메시지)

**Voicemail**(음성 메시지) 액션은 미리 녹음해 둔 음성 메시지를 연락처에게 바로 보내요. 직접 통화하지 않고도 후속 안내나 알림, 특정 메시지를 전달할 때 쓰세요.

## 액션 이름

**Voicemail**(음성 메시지)

## 액션 설명

미리 녹음한 음성 메시지 파일을 선택한 연락처에게 보내요.

## 액션 상세 정보

| 필드 | 설명 | 필수 여부 |
| --- | --- | --- |
| Action Name(액션 이름) | 액션의 이름이에요. "Voicemail"로 설정돼 있어요. | 예 |
| Drop Your File(파일 올리기) | 보낼 음성 메시지 파일을 업로드해요. 음성 메시지로 재생할 수 있는 파일 형식이어야 해요. | 예 |

### 설정 방법

1. **Action Name** 항목에 "Voicemail"이라고 적혀 있는지 확인하세요. 어떤 액션인지 구분하는 이름이에요.
2. **Upload file**(파일 업로드) 버튼을 클릭해 내 컴퓨터에서 미리 녹음한 음성 메시지 파일을 선택하세요. 업로드한 뒤에는 재생해서 올바른 파일인지 확인할 수 있어요.
3. 설정을 마치면 **Save**(저장)를 클릭해 워크플로우에 변경 사항을 적용하세요.

### 함께 쓰기 좋은 트리거

아래는 예시일 뿐이에요. 이 밖의 트리거와도 함께 쓸 수 있어요.

1. 예약 노쇼: 연락처가 예약된 일정에 나타나지 않으면 일정을 다시 잡도록 안내하는 음성 메시지를 자동으로 보내요.
2. 후속 알림: 정해 둔 시간 안에 연락처가 이전 메시지에 답하지 않으면 음성 메시지를 보내요.

## 예시

- 트리거: **Appointment Status Changes**(예약 상태 변경)가 **No-Show**(노쇼)로 변경됨
- 액션: **Voicemail**(음성 메시지)
- 업로드한 파일: "Reschedule.mp3" (놓친 예약을 다시 잡도록 안내하는 녹음 메시지)

이 워크플로우는 연락처가 예약에 나타나지 않은 것을 확인하면 다시 예약하라는 음성 메시지를 자동으로 보내요. 직접 후속 연락을 하지 않아도 연락처의 반응을 이끌어 낼 수 있어요.
