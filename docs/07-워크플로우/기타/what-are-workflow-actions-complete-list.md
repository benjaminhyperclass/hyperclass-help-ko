# 워크플로우 액션 전체 목록

워크플로우 액션은 워크플로우 빌더에서 여러 작업을 자동으로 처리하게 해 주는 구성 요소예요. 액션은 트리거가 일어난 뒤 정해 둔 순서대로 차례차례 실행돼요. 이 문서에서 액션 종류와 쓰임새를 한눈에 확인해 보세요.

## 함께 보면 좋은 문서

- [워크플로우 시작하기](getting-started-with-workflows.md)
- [워크플로우 빌더 둘러보기](workflow-builder-walkthrough.md)
- [워크플로우 설정](../빌더/workflow-settings-overview.md)
- 워크플로우 트리거 목록(A List of Workflow Triggers)

## 트리거와 액션 이해하기

트리거는 워크플로우를 시작하는 이벤트예요. 트리거가 일어나면 여러 액션이 실행되고, 액션은 워크플로우에 지정한 순서를 따라요.

- 워크플로우 트리거: 특정 이벤트가 일어나면 워크플로우를 시작해요.
- 워크플로우 액션: 트리거 다음에 실행되어, 지정한 작업을 수행해요.

## 액션 카테고리

액션은 찾기 쉽고 쓰기 쉽도록 카테고리별로 나뉘어 있어요. 카테고리는 다음과 같아요.

- **Contact Actions**(연락처 액션)
- **Communication Actions**(커뮤니케이션 액션)
- **Send Data**(데이터 보내기)
- **Internal Tools Actions**(내부 도구 액션)
- **Workflow AI Action**(워크플로우 AI 액션)
- **Eliza Actions**(Eliza 액션)
- **Appointments Actions**(예약 액션)
- **Opportunities Actions**(기회 액션)
- **Payments Actions**(결제 액션)
- **Marketing Actions**(마케팅 액션)
- **Affiliate Actions**(제휴 액션)
- **Courses Actions**(코스 액션)
- **IVR (Interactive Voice Response) Actions**(음성 자동응답 액션)
- **Communities Actions**(커뮤니티 액션)

워크플로우를 만드는 화면에서 **Add Action**(액션 추가) 버튼을 선택하면 액션을 고를 수 있어요.

## 연락처 액션 (Contact Actions)

**Create Contact**(연락처 만들기)

- 시스템에 새 연락처를 추가해요. 새 리드를 관리할 때 쓸 수 있어요.
- 이럴 때 좋아요: 리드 수집과 정리를 자동화할 수 있어요.

**Find Contact**(연락처 찾기)

- 입력한 정보를 기준으로 시스템에서 연락처를 찾아요.
- 이럴 때 좋아요: 기존 연락처를 찾아 정보를 업데이트하거나 참조할 때 도움이 돼요.

**Update Contact Field**(연락처 필드 업데이트)

- 연락처의 특정 필드를 수정해요.
- 이럴 때 좋아요: 연락처 정보를 상황에 맞게 자동으로 바꿀 수 있어요.

**Add Contact Tag**(연락처 태그 추가)

- 연락처에 태그를 추가해 정리하고 그룹으로 나눠요.
- 이럴 때 좋아요: 연락처를 더 쉽게 관리하고 대상을 좁혀 보낼 수 있어요.

**Remove Contact Tag**(연락처 태그 제거)

- 연락처에서 태그를 제거해요.
- 이럴 때 좋아요: 연락처 목록의 정리와 그룹 구분을 유지하는 데 도움이 돼요.

**Assign to User**(사용자에게 배정)

- 연락처를 시스템의 사용자에게 배정해요.
- 이럴 때 좋아요: 담당자별로 맞춤 소통을 하고 업무를 나눌 수 있어요.

**Remove Assigned User**(할당된 사용자 제거)

- 연락처에 배정된 사용자를 제거해요.
- 이럴 때 좋아요: 담당자를 바꾸거나 연락처를 정리할 때 도움이 돼요.

**Edit Conversation**(대화 편집)

- 대화를 표시하거나, 보관 또는 보관 해제해서 편집해요.
- 이럴 때 좋아요: 하이퍼클래스 안에서 대화를 관리하기 쉬워져요.

**Disable/Enable DND**(수신거부 비활성화/활성화)

- 연락처의 수신거부(DND, Do Not Disturb)를 비활성화하거나 활성화해요.
- 이럴 때 좋아요: 연락처의 수신 선호도에 맞게 발신 메시지를 조절할 수 있어요.

**Add Note**(메모 추가)

- 연락처에 메모를 직접 추가해요.
- 이럴 때 좋아요: 연락처와의 상호작용을 수동으로 기록할 수 있어요.

**Add Task**(작업 추가)

- 연락처와 관련된 작업을 만들어요. 연락처가 있으면 그 연락처에 연결하고, 연락처 없이 워크플로우가 실행되면 연락처가 없는 작업을 만들어요. **Inbound Webhook**(인바운드 웹훅)과 함께 쓰면 연락처가 없을 때도 내부 작업을 만들 수 있어요.
- 이럴 때 좋아요: 후속 조치와 할 일을 관리하는 데 도움이 돼요.

**Copy Contact**(연락처 복사)

- 연락처를 다른 서브 계정으로 복제해요.
- 이럴 때 좋아요: 계정 간에 데이터를 공유하고 관리하기 쉬워져요.

**Delete Contact**(연락처 삭제)

- 시스템에서 연락처를 삭제해요.
- 이럴 때 좋아요: 연락처 목록을 정리할 때 도움이 돼요.

**Modify Contact Engagement Score**(연락처 참여 점수 수정)

- 연락처의 참여 점수를 조정해요.
- 이럴 때 좋아요: 연락처가 얼마나 반응하고 상호작용하는지 평가하는 데 도움이 돼요.

**Add/Remove Contact Followers**(연락처 팔로워 추가/제거)

- 연락처에 팔로워를 추가하거나 제거해요.
- 이럴 때 좋아요: 팀이나 부서가 연락처를 함께 볼 수 있어요.

## 커뮤니케이션 액션 (Communication Actions)

**Send Email**(이메일 보내기)

- 연락처에게 이메일을 보내요.
- 이럴 때 좋아요: 이메일로 맞춤 소통을 하며 후속 안내, 업데이트, 알림을 보낼 수 있어요.

**Send SMS**(SMS 전송)

- 연락처에게 SMS를 보내요.
- 이럴 때 좋아요: 문자로 바로 연락할 수 있어서 알림, 리마인더, 짧은 소통에 알맞아요.

**Send Slack Message**(Slack 메시지 보내기)

- Slack이 연동되어 있으면 Slack으로 메시지를 보내요.
- 이럴 때 좋아요: Slack에서 팀 소통과 내부 알림을 처리해 협업과 업무 관리가 수월해져요.

**Call**(통화)

- 연락처에게 전화를 걸어요. 연락처가 받으면 사용자에게 전화를 연결하려고 시도해요.
- 이럴 때 좋아요: 리드 아웃리치와 관리를 자동화할 수 있어요. 자동 발신하거나 리드를 배정된 사용자와 바로 연결할 때 유용해요.

**Messenger**(메신저)

- 연락처에게 Facebook 메시지를 보내요.
- 이럴 때 좋아요: Facebook Messenger로 들어온 메시지를 관리하며 맞춤 소통과 고객 참여를 이어갈 수 있어요.

**Instagram DM**(Instagram DM)

- Instagram 다이렉트 메시지를 보내요.
- 이럴 때 좋아요: Instagram 다이렉트 메시지로 고객과 소통해서 소셜 미디어 상호작용과 고객 지원을 강화할 수 있어요.

**Manual Action**(수동 작업)

- 연락처에 대해 사용자가 직접 수행할 작업을 요청해요.
- 이럴 때 좋아요: 사람이 직접 개입해야 할 때 유연하게 쓸 수 있어요. 리드 관리와 맞춤 소통에 유용해요.

**GMB Messaging**(GMB 메시징)

- Google My Business 메시지에 답해요.
- 이럴 때 좋아요: GMB로 고객과 소통해서 지역 비즈니스 참여와 고객 서비스를 높일 수 있어요.

**Send Internal Notification**(내부 알림 보내기)

- 배정된 사용자나 연락처에게 알림을 보내요.
- 이럴 때 좋아요: 시스템의 업데이트나 트리거 소식을 팀원에게 알려서 협업과 업무 관리에 도움이 돼요.

**Send Review Request**(리뷰 요청 보내기)

- 리뷰 요청을 보내요.
- 이럴 때 좋아요: 리뷰 요청을 자동화해서 평판 관리와 고객 피드백 수집을 강화할 수 있어요.

**Conversation AI**(대화 AI)

- 고객과의 인바운드 대화를 관리해요.
- 이럴 때 좋아요: AI가 여러 채널의 고객 문의를 처리해서 응답 시간을 줄이고 고객 만족도를 높여요.

**Facebook Interactive Messenger**(Facebook 인터랙티브 메신저)

- 게시물에 달린 Facebook 댓글에 답해요.
- 이럴 때 좋아요: Facebook에서 고객과 소통해서 소셜 미디어 존재감과 상호작용을 높일 수 있어요.

**Instagram Interactive Messenger**(Instagram 인터랙티브 메신저)

- 게시물에 달린 Instagram 댓글에 답해요.
- 이럴 때 좋아요: Instagram 참여를 높이고 커뮤니티 상호작용과 브랜드 인지도를 키울 수 있어요.

**Reply in Comments**(댓글에 답글)

- Facebook이나 Instagram 게시물의 댓글에 답글을 달아요.
- 이럴 때 좋아요: 댓글에 답하면서 팔로워와 관계를 쌓을 수 있어요.

**WhatsApp**(WhatsApp)

- WhatsApp 메시지를 보내요.
- 이럴 때 좋아요: WhatsApp으로 소통할 수 있어요. 고객 지원과 고객 참여에 관한 WhatsApp 가이드라인을 지켜야 해요.

**Send Live Chat Message**(라이브 채팅 메시지 보내기)

- 라이브 채팅 메시지에 답해요.
- 이럴 때 좋아요: 라이브 채팅 문의에 바로 답해서 실시간 고객 지원을 강화하고 고객 만족도를 높일 수 있어요.

## 데이터 보내기 (Send Data)

**Webhook/Custom Webhook**(웹훅/커스텀 웹훅)

- 하이퍼클래스의 데이터를 외부 애플리케이션이나 서비스로 보내요.
- 이럴 때 좋아요: 다른 도구나 서비스와 연동하기 쉬워져요.

**Google Sheets**(Google Sheets)

- Google Sheets의 데이터를 관리하며 업데이트하거나 조회해요.
- 이럴 때 좋아요: 데이터 관리와 리포팅을 자동화할 수 있어요.

## 내부 도구 액션 (Internal Tools Actions)

**If/Else**(조건 분기)

- 조건에 따라 분기를 만들어요.
- 이럴 때 좋아요: 조건에 맞는 경로로 연락처를 보내 맞춤 경험을 줄 수 있어요. 그룹 나누기와 맞춤 설정에 유용해요.

**Wait**(대기)

- 정해진 시간 동안 워크플로우를 멈춰요.
- 이럴 때 좋아요: 나중에 실행할 액션이나 메시지를 예약해서 워크플로우의 효율과 타이밍을 높일 수 있어요.

**Goal Event**(목표 이벤트)

- 연락처를 특정 목표 이벤트로 보내요.
- 이럴 때 좋아요: 연락처가 워크플로우의 불필요한 단계를 건너뛰게 해서 고객 여정과 자동화를 최적화할 수 있어요.

**Split**(분할)

- 워크플로우 안에서 분할 테스트(A/B 테스트)를 해요.
- 이럴 때 좋아요: 서로 다른 경로나 액션을 비교해서 마케팅 메시지와 전략을 개선할 수 있어요.

**Update Custom Value**(커스텀 값 업데이트)

- 커스텀 값을 업데이트해요.
- 이럴 때 좋아요: 이벤트나 트리거에 따라 커스텀 필드를 자동으로 바꿔서 데이터 관리와 맞춤 설정을 강화할 수 있어요.
**Go To**(이동)

- 연락처를 다른 워크플로우로 보내요.
- 이럴 때 좋아요: 연락처를 워크플로우 사이에서 옮길 수 있어서, 복잡한 고객 여정도 워크플로우를 복제하지 않고 관리할 수 있어요.

**Remove from Workflow**(워크플로우에서 제거)

- 워크플로우에서 연락처를 제거해요.
- 이럴 때 좋아요: 특정 워크플로우에서 연락처를 빼서 소통과 액션을 관리하고, 대상에 맞는 상호작용을 유지할 수 있어요.

**Arrays**(배열)

- 여러 값을 하나의 묶음으로 다뤄요.
- 이럴 때 좋아요: 데이터 컬렉션을 정렬, 검색, 반복 처리할 수 있어서 데이터 관리와 가공이 간단해져요.
- 목록 형태의 데이터에서 값을 찾고, 거르고, 변환하고, 계산할 수 있어요.

**Drip Mode**(드립 모드)

- 연락처를 일정한 묶음 단위로 나누어 워크플로우에 천천히 흘려보내요.
- 이럴 때 좋아요: 연락처가 워크플로우를 지나가는 속도를 조절해 커뮤니케이션 채널에 과부하가 걸리는 것을 막고, 평판과 전달률을 지킬 수 있어요.

**Text Formatter**(텍스트 서식)

- 텍스트의 형식을 바꿔요.
- 이럴 때 좋아요: 텍스트 데이터를 원하는 형식으로 바꿔서 데이터를 더 쉽게 다루고 관리할 수 있어요.

**Custom Code**(커스텀 코드)

- 직접 작성한 코드를 실행해요.
- 이럴 때 좋아요: 사용자 스크립트나 프로그램을 실행하는 고급 기능으로, 복잡한 데이터 처리와 자동화에 쓸 수 있어요.

## 워크플로우 AI 액션 (Workflow AI Action)

**AI Prompt (GPT-3 Powered)**(AI 프롬프트, GPT-3 기반)

- 이럴 때 좋아요: AI 응답을 자동으로 만들어 고객 참여를 높일 수 있어요.

## Eliza 액션 (Eliza Actions)

**Eliza AI Appointment Booking**(Eliza AI 예약 부킹)

- 마켓플레이스 서비스의 Eliza 플랫폼을 사용해, AI로 예약 부킹을 자동화해요.
- 이럴 때 좋아요: 예약 일정을 잡는 대화를 AI로 자동화할 수 있어요.

**Send to Eliza Agent Platform**(Eliza 에이전트 플랫폼으로 보내기)
