# 워크플로우에서 GPT-5 사용하기 — GPT powered by OpenAI 액션

워크플로우 안에서 OpenAI의 GPT-5 계열 모델(GPT-5, GPT-5 Mini, GPT-5.1, GPT-5 Nano)을 쓰는 방법을 안내해요. 기능의 특징, 모델별 요금과 토큰 계산 방법, 설정 순서를 차례로 설명해요.

{% hint style="info" %}
문서에 나온 금액(달러)과 요금제 이름은 참고용이에요. 하이퍼클래스에서 실제로 적용되는 요금은 [요금제 안내](../../00-자주묻는질문/pricing-plans.md)와 [AI·SMS·음성 사용료](../../00-자주묻는질문/usage-costs.md)를 확인하세요.
{% endhint %}

## GPT-5 워크플로우 기능이란?

워크플로우에서 OpenAI의 GPT-5 계열 모델을 쓸 수 있는 기능이에요. 이 기능을 쓰면 워크플로우가 텍스트를 만들거나 바꿀 때 이전 모델보다 더 정확하고 빠르게 처리해요.

GPT 액션을 고르고 GPT-5 계열 모델을 선택하면, 이전 모델보다 긴 컨텍스트 창, 더 풍부한 추론, 낮은 지연 시간을 쓸 수 있어요.

## GPT-5 워크플로우의 주요 장점

자동화 단계에서 실시간에 가까운 수준의 언어 이해를 쓸 수 있어요.

- 속도: 처리가 빨라서 거의 실시간으로 실행돼요. 고객 대기 시간이 줄어요.
- 신뢰성: GPT-5의 향상된 추론 능력 덕분에 일관되고 품질 높은 결과를 얻을 수 있어요.
- 유연성: 모델 등급 세 가지 중에서 골라 성능과 비용의 균형을 맞출 수 있어요. 워크플로우를 다시 만들 필요가 없어요.- 간편함: 기본 제공 액션이라 클릭만으로 설정할 수 있어요. 연동과 유지보수 부담이 적어요.

### 토큰 계산

토큰 계산 방법을 알아 두면 AI 비용을 미리 예상할 수 있어서 예상치 못한 청구를 피할 수 있어요.

하이퍼클래스는 GPT-5 사용량을 OpenAI와 같은 방식으로 청구해요. 입력 토큰(프롬프트와 컨텍스트)과 출력 토큰(모델의 응답)을 각각 세어요. 토큰 1개는 영어 텍스트 기준으로 약 4자예요. 요금은 100만 토큰의 1,000분의 1(0.001M) 단위로 가장 가깝게 맞춰 비례 계산해요.

#### 예시

400단어짜리 이메일(약 2,000자, 약 500토큰)을 GPT-5 Mini에 보내면 비용은 다음과 같아요.

- 입력: 500토큰 × $0.25 / 100만 = $0.000125
- 출력: 500토큰 × $2.00 / 100만 = $0.001
- 합계: 이 액션 한 번에 $0.001125

## GPT-5 워크플로우 설정하기

설정을 제대로 해 두면 알맞은 GPT-5 모델이 적용돼요. 속도와 비용의 균형도 맞추고, 워크플로우를 바로 운영에 쓸 수 있어요. 몇 번의 클릭으로 설정할 수 있어요.

### 1단계: GPT 액션 선택

1. 워크플로우를 열어요.
2. AI 단계를 넣을 자리에서 **Add Action**(액션 추가) 아래의 "+" 아이콘을 클릭해요.
3. "GPT powered by OpenAI"를 검색해요.
4. **GPT powered by OpenAI** 액션을 선택해요.

![워크플로우에서 GPT powered by OpenAI 액션 검색](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051630525/original/xqhHze4dKq1K8OUUxD6KbnJU_g9-AKFQMw.png?1755178385)

GPT 액션에 대한 자세한 내용은 [워크플로우 액션 - GPT powered by OpenAI](../Workflow-AI-Workflow-Actions/workflow-action-gpt-powered-by-openai.md)를 참고하세요.

### 2단계: GPT-5 Mini, GPT-5, GPT-5 Nano 또는 GPT-5.1 선택

**Model**(모델) 드롭다운에서 기본값인 GPT-5 Mini를 그대로 두거나, 용도에 맞게 GPT-5 또는 GPT-5 Nano를 선택해요.

![Model 드롭다운에서 GPT-5 모델 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051630743/original/Y2gNqJmyLdVsbkiusI1G3MlhrYXJ6lwIpg.png?1755178517)

{% hint style="info" %}
프롬프트를 작성하거나 들어오는 데이터 필드를 매핑하세요. 모범 사례는 [AI 프롬프팅 101](../../13-AI-Employee/Conversation-AI-Goals-Prompts-and-Actions/ai-prompting-101.md)을 참고하세요. 단계를 저장하고 워크플로우를 게시하면 자동화가 GPT-5로 실행돼요.
{% endhint %}

## GPT-5 모델 프롬프트 작성 팁

- 역할과 형식을 알려 주세요: 시스템 프롬프트를 모델의 역할로 시작하고, 원하는 출력 형식을 정확히 적어 주세요.
- 긴 입력은 구분 기호로 감싸세요: 큰 문서는 백틱 3개(`` ``` ``)로 감싸면 서식이 유지돼요.
- 가능하면 나눠서 보내세요: Nano를 쓸 때는 여러 페이지 분량의 내용을 작게 나눠 호출하면 비용을 아주 낮게 유지할 수 있어요.
- 예시를 넣어 주세요: 몇 가지 예시를 함께 주면 일관성이 좋아져요. Mini나 Nano에서 특히 효과가 있어요.

## 자주 묻는 질문

### 대량 작업에는 어떤 GPT-5 모델이 가장 비용 효율적인가요?
GPT-5 Nano의 토큰당 요금이 가장 낮아요. 속도가 덜 중요한 대량 작업이나 백그라운드 작업에 알맞아요.

### 워크플로우를 다시 만들지 않고 나중에 모델을 바꿀 수 있나요?
네, 가능해요. GPT 액션을 편집해서 다른 모델을 선택하고 저장하면 돼요. 다른 단계는 손볼 필요가 없어요.

### 입력 토큰과 출력 토큰은 어떻게 계산하나요?
입력 토큰에는 프롬프트와 컨텍스트가 포함되고, 출력 토큰은 모델의 응답이에요. 두 가지를 따로 측정하고 따로 요금을 계산해요.

### GPT-5 요청에 사용 한도가 있나요?
하이퍼클래스는 OpenAI와 같은 요청 한도를 적용해요. 사용량이 많으면 트래픽이 몰리는 시간대에 요청이 대기열에 들어갈 수 있어요.

### GPT-5는 [GPT-4 Turbo](gpt-4-in-hyperclass.md)보다 긴 컨텍스트 창을 지원하나요?
네, GPT-5는 최대 256k 토큰의 컨텍스트를 지원해요. 그래서 더 풍부한 대화와 여러 단계에 걸친 추론이 가능해요.
