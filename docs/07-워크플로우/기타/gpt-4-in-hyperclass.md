# 워크플로우에서 GPT-4 사용하기 — GPT powered by OpenAI 액션

하이퍼클래스 워크플로우에서 GPT 기반 AI 모델(최신 GPT-4 Turbo 포함)을 쓰는 방법을 안내해요. AI 스텝을 설정하고 프롬프트를 구성해서 리드 후속 연락, 대화 요약, 맞춤 메시지 작성 같은 작업을 자동화할 수 있어요.

{% hint style="info" %}
이 문서는 ChatGPT와 그 버전인 GPT-4를 다뤄요. 워크플로우에서 AI를 사용하는 전반적인 방법이 궁금하다면 [워크플로우 액션 - GPT powered by OpenAI](../Workflow-AI-Workflow-Actions/workflow-action-gpt-powered-by-openai.md)를 참고하세요.
{% endhint %}

---

## GPT-4 Turbo로 더 똑똑해진 자동화

대화 AI가 빠르게 퍼지면서, 똑똑하고 확장하기 쉬우며 다른 기능과 잘 연결되는 도구가 필요해졌어요. 하이퍼클래스는 GPT 기반 AI 워크플로우 스텝으로 이 기능을 자동화 엔진에 넣었어요. 개인 맞춤 후속 메시지 작성, 대화 요약, 이메일 내용과 소셜 캡션 생성까지 최소한의 설정으로 더 지능적이고 자연스러운 자동화를 만들 수 있어요.

마케팅 에이전시, 서비스 업체, 영업팀 모두 기존 하이퍼클래스 워크플로우에 AI를 더해 새로운 기능을 활용할 수 있어요.

## 새로 추가된 기능

- GPT-4 Turbo: 이제 AI 스텝에서 쓸 수 있어요. 이전 GPT-4 모델보다 응답이 빠르고 호출당 비용이 낮아요.
- **Model Switcher UI**(모델 전환 화면): 워크플로우 스텝에서 바로 GPT-3.5, GPT-4, GPT-4 Turbo 중에서 고를 수 있어요.
- 프롬프트 처리 개선: 병합 필드(merge field)를 더 잘 지원하고, 복잡한 지시도 더 잘 처리해요.
- **System Prompt**(시스템 프롬프트, 선택 사항): 어조나 행동 방식을 안내해서 AI의 성격과 출력 스타일을 정할 수 있어요.

## GPT-4 요금

하이퍼클래스의 GPT 액션은 이제 마크업 없음(Zero Markup)으로 청구돼요. OpenAI가 부과하는 금액만큼만 내고, 추가 수수료는 없어요. 요금은 토큰 기준이에요. 입력 토큰(내가 작성한 프롬프트)과 출력 토큰(AI의 응답) 수로 계산하고, 선택한 모델(예: GPT-4o, GPT-4o Mini)에 따라 달라져요. 비용 구조가 투명해지고, 예전의 고정 실행 요금 방식 대신 사용량에 따라 비용이 늘어나요.

{% hint style="warning" %}
요금이 고정 실행 요금에서 토큰 기반 마크업 없음 방식으로 바뀌었어요. 비용은 다음에 따라 정해져요.

1. 프롬프트에 사용한 입력 토큰
2. 응답으로 생성된 출력 토큰
3. 선택한 AI 모델

OpenAI의 요금 그대로 내고, 더 내거나 덜 내는 일은 없어요.
{% endhint %}

### 외부 AI 모델 - 사용한 토큰 기준

- GPT-4o (100만 토큰당)
  - 입력: $2.5
  - 출력: $10.00
- GPT-4o-mini (100만 토큰당)
  - 입력: $0.15
  - 출력: $0.60

예를 들어 $10만 사용해도 GPT-4o는 입력 약 300만 단어를 처리하거나 출력 약 75만 단어를 생성할 수 있어요. GPT-4o Mini는 훨씬 많은 양을 다뤄서 입력 약 5,000만 단어를 처리하거나 출력 약 1,250만 단어를 만들 수 있어요. 워크플로우에 맞는 모델을 골라 비용과 성능의 균형을 맞춰 보세요.

### $10로 할 수 있는 일

GPT-4o:

- 입력 약 300만 단어 처리 또는
- 출력 약 75만 단어 생성

GPT-4o Mini:

- 입력 약 5,000만 단어 처리 또는
- 출력 약 1,250만 단어 생성

## GPT가 생성하는 출력

사용할 AI 모델을 고르고 설정했다면, 워크플로우에 **GPT powered by OpenAI** 액션을 추가해서 설정한 프롬프트에 맞는 동적 출력을 만들 수 있어요.

1. **Action Type**(액션 유형)을 선택해요.

   - 미리 정해진 옵션 중에서 골라요.
     - **Analyze Text Sentiment**(텍스트 감정 분석)
     - **Summarize Text**(텍스트 요약)
     - **Translate**(번역)
     - **Custom**(직접 작성한 프롬프트 사용)
   - **Custom**을 선택했다면 직접 프롬프트를 입력해요. 예: "이 메시지를 바탕으로 후속 이메일을 작성해 줘: `{{contact.message}}`"

2. 동적 변수를 사용해요(선택 사항).

   - 프롬프트에 `{{contact.first_name}}`, `{{event.notes}}` 같은 동적 필드를 넣으면 출력을 개인에게 맞출 수 있어요.

3. 워크플로우를 테스트하거나 실행해요.

   - 액션을 추가한 뒤 연락처 한 명으로 워크플로우를 테스트하면 GPT 출력 결과를 바로 볼 수 있어요.
   - AI 출력은 이후 워크플로우 스텝에서 쓸 수 있어요(예: 이메일이나 SMS로 보내기).

{% hint style="warning" %}
출력이 어디로 가는지 궁금하다면, AI가 생성한 내용은 다음과 같이 쓸 수 있어요.

1. 커스텀 필드에 저장
2. 이메일 또는 SMS 스텝에서 바로 사용
3. 내부 기록으로 남기거나 Slack/웹훅으로 팀에 전송
{% endhint %}

## 자주 묻는 질문

### GPT-4 Turbo가 무엇이고, GPT-4나 GPT-3.5와 어떻게 다른가요?
GPT-4 Turbo는 GPT-4의 변형 모델로, 더 빠르고 비용 효율이 높으며 대량 사용 환경에서 성능이 개선되었어요. GPT-3.5와 비교하면 맥락 이해력이 더 좋고, 더 정확하게 콘텐츠를 생성하며, 더 큰 프롬프트를 지원해요.

### GPT-4 Turbo를 모든 하이퍼클래스 요금제에서 쓸 수 있나요?
아니요. GPT-4 Turbo는 하이퍼클래스의 프리미엄 콘텐츠 AI 기능에 포함돼요. 구독 요금제와 사용량 설정에 따라 이용 가능 여부가 다를 수 있어요. 요금제를 확인하거나 하이퍼클래스 고객지원에 업그레이드 옵션을 문의하세요.

### 워크플로우에서 GPT-4 Turbo를 쓰면 추가 비용이 드나요?
네. GPT-4 Turbo는 프리미엄 워크플로우 액션이고, 실행할 때마다 처리된 토큰 수에 따라 사용료가 청구돼요. 사용량과 비용은 계정의 **AI Billing Settings**(AI 결제 설정)에서 확인할 수 있어요.

### 같은 워크플로우 안에서 GPT-3.5와 GPT-4 Turbo를 바꿔 쓸 수 있나요?
네. AI 스텝마다 모델을 따로 고를 수 있어요. 각 스텝의 복잡도나 예산에 맞춰 한 워크플로우 안에서 GPT-3.5, GPT-4, GPT-4 Turbo를 섞어 쓸 수 있어요.

### 100만 토큰은 몇 단어인가요?
추정치이며 실제 결과는 다를 수 있어요. 1,000,000토큰 × 0.75단어/토큰 = 750,000단어예요.
