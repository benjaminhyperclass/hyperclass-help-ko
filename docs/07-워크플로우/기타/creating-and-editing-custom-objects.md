# 사용자 지정 객체 만들기와 편집

연락처와 기회로는 담기 어려운 데이터(부동산, 반려동물, 케이스, 차량 등)를 사용자 지정 객체로 직접 만들어 관리할 수 있어요. 이 문서에서는 사용자 지정 객체를 쓸 수 있는 기능, 만드는 순서, 워크플로우 활용법, 자주 묻는 질문을 안내해요.

## 사용자 지정 객체란?

사용자 지정 객체는 직접 정의하는 새로운 레코드 유형이에요. 객체마다 필드, 연관 관계, 자동화를 따로 설정할 수 있어서, CRM을 실제 업무 방식에 맞게 구성할 수 있어요.

기본 객체만으로 부족할 때 쓰면 좋아요. 예를 들어 MLS, 침실 수, 상태를 가진 '부동산'이나 품종, 예방접종 정보를 가진 '반려동물'을 관리할 수 있어요. 객체를 만든 뒤에는 보기, 필터, 자동화에서 활용할 수 있어요.

---

## 사용자 지정 객체의 주요 장점

- 유연성: 커스텀 필드, 레이블, 연관 관계를 넣어 원하는 대상을 자유롭게 정의할 수 있어요.
- 자동화: 레코드가 생성되거나 수정될 때 워크플로우를 시작하고, 객체 전용 액션을 실행할 수 있어요.
- 인사이트: 스마트 리스트와 목록 보기로 객체 데이터를 분석하고, 상세 필터로 원하는 조건만 정확하게 걸러 낼 수 있어요.
- 관리: 관리자가 객체 정의를 관리하므로 데이터 일관성을 지키기 쉬워요.
- 요금제 및 제한: 모든 요금제에서 쓸 수 있고, 서브 계정당 최대 10개까지 만들 수 있어요.

---

## 필드 유형과 고유 필드

필드 유형과 고유 규칙을 잘 정해 두면 데이터가 깔끔하게 유지되고 병합도 쉬워져요.

- 지금 고유 필드로 쓸 수 있는 유형: **Single Line Text**(한 줄 텍스트), **Multi Line Text**(여러 줄 텍스트), **Number**(숫자), **Phone**(전화번호)
- 제한: 객체당 고유 필드는 최대 10개예요.
- 적용 범위: 고유성은 서브 계정 전체에 적용되고, 화면(UI), 워크플로우, 폼, API 등 모든 입력 경로에서 지켜져요.
- 되돌릴 수 없는 변경: 고유 필드를 고유하지 않은 필드로 바꾸면 다시 고유 필드로 바꿀 수 없어요.

---

## 연관 관계와 레이블

연관 관계는 레코드끼리 연결해 줘요(예: 기회 ↔ 부동산). 실제 업무의 관계를 그대로 반영할 수 있고, 여러 객체를 함께 보는 화면에도 활용돼요.

- 객체 사이에 다대다 또는 일대다 연결을 만들 수 있어요.
- 스마트 리스트, 필터, 자동화에서 연관 관계를 쓸 수 있어요.
- 레이블 제한: 두 객체 사이에 고유 레이블을 최대 10개까지 만들 수 있어요. 관계를 분명히 나타내는 “구매자”, “게시 위치” 같은 이름을 붙이면 좋아요.
- 이제 기회도 사용자 지정 객체와 유연하게 연관 지을 수 있어서, 파이프라인에서 한눈에 맥락을 볼 수 있어요.

## 사용자 지정 객체를 쓸 수 있는 곳

아래 표에서 기능별 지원 현황을 확인하고 설계에 참고하세요.

| 지원 여부 | 기능 |
| --- | --- |
| **지원됨** | 연락처 및 기회(연관 관계), 워크플로우(트리거 및 액션), 폼, 설문 및 퀴즈, 스마트 리스트, 목록 보기, 상세 필터, 리포팅/대시보드, API, 웹훅, 작업 |
| **지원되지 않음** | 이메일 캠페인, 대량 이메일, 대량 SMS, 대화 화면, 퍼널 및 웹사이트(사용자 지정 객체 동적 데이터), 캘린더 및 예약, 평판/리뷰, 결제 및 인보이스, 회사 객체 내부 |
| **출시 예정** | 메모, 퍼널 및 웹사이트(동적 연결), AI 지식 베이스, 워크플로우로 연관 연락처에게 이메일 보내기 |

## 사용자 지정 객체 설정하는 방법

처음에 깔끔하게 설정해 두면 데이터가 늘어나도 자동화와 리포팅이 안정적으로 돌아가요.

### 1단계 — 객체 만들기

1. 서브 계정에서 **설정 > 오브젝트**로 이동하세요.
2. **Add Custom Object**(사용자 지정 객체 추가)를 클릭하세요.

   ![오브젝트 페이지에서 사용자 지정 객체 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058405899/original/19muD-f-IgODYh2yNQ--bLnKCPn89sP4Yg.png?1763126731)

### 2단계 — 객체 정보 입력하기

1. **Singular name**(단수 이름)을 입력하세요(예: Pet).
2. **Plural name**(복수 이름)을 입력하세요(예: Pets).
3. **Internal Name**(내부 이름)과 **기본 필드**를 확인하세요. 기본 필드는 자동으로 만들어져요. 내부 이름은 **</>** 를 클릭해서 객체를 만드는 중에만 바꿀 수 있어요.
4. **기본 표시 필드**의 레이블을 입력하세요(예: Pet Name, Pet Identification Number).
5. **아이콘**을 고르고 **설명**을 입력하세요. 팀원들이 객체의 용도를 이해하는 데 도움이 돼요.
6. **Create Custom Object**(사용자 지정 객체 만들기)를 클릭하세요.

   ![객체 이름과 필드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058406204/original/fgF0GrDpzjlp6BKbCr0R0F-t6lSOdYrBxA.png?1763126831)

### 3단계 — 객체 정보 편집하기

1. 객체를 만들면 **오브젝트** 페이지에 나타나요.
2. 객체를 클릭해서 열고 정보를 수정하세요.

   ![오브젝트 페이지에서 객체 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058406333/original/_BTexHTI5lwA1w4QfD8N8itV1YC4bALzAw.jpeg?1763126905)

### 선택 — 사용자 지정 객체 삭제하기 (되돌릴 수 없어요)

1. 객체 이름 옆의 **⋯**(점 세 개)을 클릭하세요.
2. **삭제**를 선택하세요.
3. **확인하려면 DELETE를 입력하세요**라는 안내가 나오면 **DELETE**를 입력해 확인하세요.

   ![객체 삭제 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058406564/original/DIem8kq3voYpJAFkfcf-oqn43QIQXi24Cg.gif?1763127036)

{% hint style="warning" %}
객체를 삭제하면 그 객체와 연결된 모든 레코드, 연관 관계, 워크플로우, 커스텀 필드가 함께 삭제돼요. 삭제한 데이터는 복구할 수 없어요.
{% endhint %}

## 워크플로우에서 사용자 지정 객체 활용하기 (자동화)

사용자 지정 객체와 그 필드·연관 관계를 만들었다면, 객체 기반 워크플로우로 업무를 자동화할 수 있어요. 객체 기반 워크플로우는 연락처가 아니라 사용자 지정 객체 레코드 자체를 기준으로 실행돼요. 레코드가 생성되거나 수정될 때 워크플로우를 시작하고, 관련 레코드 생성·수정, 필드 비우기, 다른 도구로 객체 데이터 보내기 같은 작업을 이어서 실행할 수 있어요.

### 사용할 수 있는 트리거

객체 기반 워크플로우는 아래 트리거로 시작할 수 있어요.

| 트리거 이름 | 하는 일 |
| --- | --- |
| **[Custom Object] Created**(사용자 지정 객체 생성됨)<br>예: *Home Created* | 사용자 지정 객체 레코드가 생성되면 워크플로우를 시작해요. |
| **[Custom Object] Changed**(사용자 지정 객체 변경됨)<br>예: *Home Changed* | 사용자 지정 객체 레코드가 수정되면 워크플로우를 시작해요. |
| **Inbound Webhook**(인바운드 웹훅) | 인바운드 웹훅을 받으면 워크플로우를 시작해요. 외부 시스템에서 변경된 내용을 받을 때 유용해요. |

### 사용할 수 있는 액션

트리거가 실행된 뒤에는 아래 액션으로 다음 단계를 자동화할 수 있어요.

| 액션 이름 | 하는 일 |
| --- | --- |
| **Create [Custom Object] or Associated Record**(사용자 지정 객체 또는 연관 레코드 생성) | 새 사용자 지정 객체 레코드나 그 객체와 연관된 레코드를 만들어요. |
| **Update [Custom Object] or Associated Record**(사용자 지정 객체 또는 연관 레코드 업데이트) | 사용자 지정 객체 레코드나 연관 레코드의 필드를 업데이트해요. |
| **Clear fields of [Custom Object] or Associated Record**(사용자 지정 객체 또는 연관 레코드의 필드 비우기) | 사용자 지정 객체 레코드나 연관 레코드에서 선택한 필드를 비워요. |
| **Custom Webhook**(커스텀 웹훅) | 사용자 지정 객체 데이터를 외부 엔드포인트로 보내요. |
| **Google Sheets** | 사용자 지정 객체 데이터를 Google 스프레드시트로 보내거나 기록해요. |

**If/Else**(조건 분기), **Wait**(대기), **Go To**(이동), **Formatters**(서식 변환), **Update Custom Value**(커스텀 값 업데이트), **Add/Remove from Workflow**(워크플로우에 추가/제거) 같은 기본 액션도 함께 써서 더 복잡한 흐름을 만들 수 있어요.

### 사용자 지정 객체 워크플로우 만드는 방법

1. **자동화**로 이동해 **+ Create Workflow**(워크플로우 만들기)를 클릭한 뒤, 워크플로우를 만들 사용자 지정 객체 기반 워크플로우를 선택하세요(예: Home, Vehicle, Policy, Pet).

   ![사용자 지정 객체 기반 워크플로우 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066166834/original/HB5GGuksdOUVBlyrYBY4q4jz9DuYfhyRWQ.png?1772619858)
2. 트리거를 추가하고, 필요하면 조건과 필터를 설정하세요.

   ![트리거 추가와 조건 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066168078/original/FR82hFpZeWDIIwH9O8WYI1M9VBGCi4jpUA.png?1772620562)
3. 실행할 액션을 추가한 다음 **Publish**(게시)를 클릭하세요.

   ![액션 추가 후 게시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066168103/original/E8Kzs88A-nFeOvxnWYhJfiRjA1cERDXcbg.gif?1772620578)

더 알아보려면 [워크플로우 트리거·액션에서 사용자 지정 객체 사용하기](using-custom-objects-in-workflow-actions-and-triggers.md)를 참고하세요.

## 자주 묻는 질문

### 사용자 지정 객체는 누가 만들고 편집할 수 있나요?
서브 계정 단위의 관리자만 만들고 편집할 수 있어요. 일반 사용자는 읽기만 할 수 있어요.

### 사용자 지정 객체는 몇 개까지 만들 수 있나요?
모든 요금제에서 서브 계정당 최대 10개까지 만들 수 있어요.

### 내부 이름이나 기본 표시 필드를 나중에 바꿀 수 있나요?
아니요. 객체를 만든 뒤에는 이 필드들을 편집할 수 없어요.

### 사용자 지정 객체는 지금 어디서 쓸 수 있나요?
위의 '사용자 지정 객체를 쓸 수 있는 곳' 표에서 현재 지원 현황과 지원 예정 기능을 확인하세요.

### 사용자 지정 객체를 삭제하면 어떻게 되나요?
삭제하면 되돌릴 수 없어요. 객체와 함께 연결된 모든 레코드, 연관 관계, 워크플로우, 커스텀 필드가 삭제돼요.

### 사용자 지정 객체가 생성되거나 수정될 때 자동으로 작업을 실행하려면 어떻게 하나요?
워크플로우에서 사용자 지정 객체 트리거와 액션을 사용하세요(예: 생성/업데이트/필드 비우기, 레코드 찾기, 웹훅).
