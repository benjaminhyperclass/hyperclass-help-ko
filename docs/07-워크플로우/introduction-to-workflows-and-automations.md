# 워크플로우와 자동화 소개

워크플로우 자동화는 특정 이벤트가 일어나면 미리 정해 둔 작업이 차례로 실행되도록 해서, 반복 업무를 줄여 줘요. 이 문서에서는 워크플로우 자동화의 핵심 구성 요소인 트리거와 액션, 주요 장점, 활용 사례, 워크플로우를 처음 만드는 순서를 간단히 소개해요.

## 워크플로우 자동화란?

워크플로우 자동화는 반복되는 업무를 기술이 자동으로 처리하게 하는 방식이에요. 시작 지점인 트리거와 실행할 작업인 액션을 정해 두면, 시간을 아끼고 실수를 줄이는 업무 흐름을 만들 수 있어요.

예를 들어 폼이 제출될 때마다 리드 정보를 직접 기록하고 후속 이메일을 보내는 대신, 자동화된 워크플로우가 다음 작업을 대신 처리해요.

1. 리드 정보를 CRM에 추가해요.
2. 영업 담당자에게 리드를 배정해요.
3. 맞춤 환영 이메일을 보내요.

이렇게 하면 사람이 일일이 개입하지 않아도 같은 방식으로 빠르게 처리돼요.

## 워크플로우 자동화의 주요 장점

- 효율 향상: 시간이 많이 드는 작업을 자동화해서, 팀이 더 중요한 일에 집중할 수 있어요.
- 정확도 향상: 일상적인 작업을 자동화해서 수작업 실수를 없애요.
- 비용 절감: 수작업 의존도를 줄여 자원을 아껴요.
- 고객 경험 개선: 고객의 문의나 행동에 자동화된 액션으로 더 빠르게 응답해요.
- 확장성: 추가 인력 없이도 늘어난 업무량을 무리 없이 처리해요.

## 워크플로우 자동화 활용 사례

1. 리드 관리: 리드를 자동으로 수집하고, CRM 기록을 업데이트하고, 환영 이메일을 보내요.
2. 예약 일정 관리: 사람이 직접 입력하지 않아도 예약을 확인하고 알림을 보내요.
3. 고객 지원: 고객 문의 내용에 따라 티켓을 배정하고 팀원에게 알려요.
4. 마케팅 캠페인: 링크 클릭이나 이메일 열람 같은 사용자 행동을 기준으로 맞춤 후속 메시지를 보내요.

## 트리거와 액션: 워크플로우 자동화의 핵심

워크플로우 자동화의 중심에는 트리거와 액션이 있어요. 이 두 요소가 자동화가 어떻게 동작할지를 정하고, 모든 자동화 워크플로우의 기반이 돼요.

### 트리거: 시작 지점

트리거는 워크플로우를 움직이게 하는 이벤트예요. 자동화 공식에서 “만약(if)”에 해당해요. 어떤 일이 일어났으니 그에 맞는 액션이 이어져야 한다는 뜻이에요.

자주 쓰는 트리거 예시는 다음과 같아요.

- 고객이 예약을 잡았을 때
- 폼이 제출되었을 때
- 연락처가 메시지에 답장했을 때

트리거 덕분에 워크플로우는 실시간으로 일어나는 이벤트에 반응하고, 필요한 순간에 바로 시작돼요.

### 액션: 작업 실행

액션은 트리거에 반응해 실행되는 작업이에요. 자동화 공식에서 “그러면(then)”에 해당해요. 트리거가 발생한 뒤 워크플로우가 실제로 하는 일이에요.

액션 예시는 다음과 같아요.

- 이메일 보내기
- 연락처 정보 업데이트
- 팀원에게 리드 배정

액션이 프로세스를 앞으로 진행시키는 데 필요한 작업을 수행하면서 워크플로우가 완성돼요.

{% hint style="info" %}
트리거와 액션을 더 자세히 알아보려면: 이 문서에서는 트리거와 액션의 개념만 소개해요. 트리거와 액션마다 설정과 활용 방법이 달라요. 각 트리거와 액션을 다룬 개별 문서에서 내 워크플로우에 맞게 설정하는 방법을 자세히 확인해 보세요.
{% endhint %}

## 워크플로우 설정 순서

1. 왼쪽 메뉴에서 **자동화 > 워크플로우**로 이동하세요.

   ![워크플로우 화면으로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037820668/original/zmXrHwJbwULUQZA9hZBXjXPjxppJWs4yyQ.png?1733405305)

2. **+ Create Workflow**(워크플로우 만들기)를 클릭하세요. 새 워크플로우를 처음부터 만들 수도 있고, 기존 템플릿이나 레시피로 시작할 수도 있어요.

   ![새 워크플로우를 만드는 방법 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037824117/original/QM_Pl55gjD6rCq6pN8Ye3FSzJIAnu3jTTw.jpeg?1733407465)

3. 레시피로 시작하려면 레시피를 선택하세요. 워크플로우 레시피는 바로 쓸 수 있게 짜인 구조를 제공해요. 내 상황에 맞게 고쳐 쓰면 자동화를 더 쉽게 설계하고 적용할 수 있어요. 다음 화면에서 사용할 수 있는 여러 레시피를 볼 수 있어요.

   ![사용할 수 있는 레시피 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037822630/original/p_wS1eWLzNd59dwL0BwRYLMwOatWeRPIVg.png?1733406526)

4. 다양한 레시피 중에서 내게 맞는 워크플로우 레시피를 고르세요.

   ![레시피 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037824426/original/PaJtIFejKr5XXzVA3VQ-wA5W9UHxnbjlMQ.jpeg?1733407642)

5. 미리 만들어 둔 템플릿으로 워크플로우를 만들려면 **Select from Template**(템플릿에서 선택)을 클릭하세요. 템플릿 라이브러리가 열려요.

   ![템플릿 라이브러리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037822673/original/jSWspVU1tLi3vvkAnQspP6gpEC_qlDpVgA.png?1733406563)

6. 직접 만들려면 **처음부터 시작**을 선택하세요. 트리거와 액션을 여러 개 추가해서 비즈니스 운영 전반을 자동화할 수 있어요.

   ![처음부터 시작하는 워크플로우 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037824930/original/-qJg3EmQnuFSmPAFftt0YEwm0yzpFIIQ5g.png?1733407954)

7. 트리거를 선택하세요. 워크플로우를 시작할 이벤트를 정하는 단계예요(예: 고객이 예약을 잡았을 때).

   ![트리거 선택 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037827572/original/-zvZzXwhAKxgmi7_BBVTi1_3ysNyBZXDMw.gif?1733409691)

8. 액션을 추가하세요. 트리거 뒤에 실행할 작업을 정해요(예: 알림 보내기, 기록 업데이트).

   ![액션 추가 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037827640/original/VaUbFCVYjWBTTFACXj631OWpkAHYH3ua6g.gif?1733409724)

9. 트리거와 액션을 모두 추가했다면 **Save**(저장) 버튼을 클릭하세요. 워크플로우를 게시하기 전에 **Test Workflow**(워크플로우 테스트) 버튼으로 먼저 테스트해 볼 수 있어요.

   ![워크플로우 저장 및 테스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155037821555/original/HiuA9UH97IHNAsYTMVpwchRL32w6EYbTwg.png?1733405874)

## 자주 묻는 질문

### 트리거와 액션은 어떻게 다른가요?
트리거는 워크플로우를 시작하는 이벤트(예: 폼 제출)이고, 액션은 그 결과로 실행되는 작업(예: 이메일 보내기)이에요.

### 워크플로우로 여러 단계가 있는 복잡한 프로세스도 처리할 수 있나요?
네, 워크플로우에 트리거와 액션을 여러 개 넣어서 복잡한 프로세스도 간소화할 수 있어요.

### 워크플로우를 만들려면 기술 지식이 필요한가요?
아니요, 대부분의 플랫폼은 직관적인 화면을 제공해서 코딩 없이도 누구나 워크플로우를 설정할 수 있어요.

### 연락처를 워크플로우에 직접 추가하려면 어떻게 하나요?
연락처를 열고 **자동화 > 워크플로우 추가**를 클릭하세요. 워크플로우를 고르고 시작 시간을 정한 다음 **추가**를 클릭하면 돼요.
