# 여러 연락처에 맞춤 결제 링크 보내기

연락처의 이름, 이메일, 전화번호가 미리 채워진 결제 링크를 여러 연락처에 한꺼번에 보내는 방법을 안내해요. 받는 사람은 정보를 직접 입력하지 않아도 되니 결제 경험이 좋아지고, 보내는 사람은 전환율을 높이는 데 도움이 돼요.

[동영상](https://www.youtube.com/embed/\_iMPMrZoxWs?&wmode=opaque)

## 개요

이 문서에서는 이름, 이메일, 전화번호 같은 연락처 정보가 이미 채워진 결제 링크를 보내는 방법을 다뤄요.

## 결제 링크를 만들 때 할 수 있는 일

1. 편집 화면 오른쪽 위의 복사/보내기 버튼을 눌러 연락처를 여러 명 선택하고, 맞춤 결제 링크를 이메일과 SMS로 바로 보낼 수 있어요.

2. 이메일·SMS 템플릿을 직접 설정해서 보내거나, 기본 템플릿을 그대로 사용할 수 있어요.

![복사/보내기 화면에서 이메일과 SMS 템플릿을 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027642475/original/IjY8JG4Bnwcc-WKG-JRGQ0Wpdnh18zLSww.png?1718346737)

3. 기본 링크를 복사할 수도 있고, 드롭다운에서 연락처를 선택해 그 연락처 전용 맞춤 결제 링크를 받을 수도 있어요.

![드롭다운에서 연락처를 선택해 맞춤 결제 링크를 받는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027642787/original/1lYoOee9fdNiOls_vSzIwWauNwPIBuR8VQ.png?1718347129)

## 링크를 받는 사람에게는 어떻게 보이나요?

1. 위 템플릿으로 보낸 결제 링크를 받는 사람이 링크를 열면 이름, 이메일, 전화번호 같은 정보가 이미 채워져 있어요. 그래서 맞춤형 결제 경험을 할 수 있어요.

![이름, 이메일, 전화번호가 미리 채워진 결제 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027642805/original/l0UGhwipSaja2hHix39w_K-6KqWuwjD-bw.png?1718347178)

## 사용 방법

1. **결제 > Payment-Links**(결제 링크)로 이동한 다음 **편집**을 선택하세요.

2. 오른쪽 위에서 **Copy / Send**(복사/보내기) 버튼을 확인하세요. 저장된 링크이거나, 새 링크를 저장한 뒤에 보여요.

{% hint style="info" %}
결제 링크를 먼저 저장해야 이 기능을 쓸 수 있어요. 이미 저장해 둔 링크에서도 쓸 수 있어요.
{% endhint %}

![편집 화면 오른쪽 위의 복사/보내기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027642860/original/6VvEjBknfwusFltbgGqEJu54WSg5lfyfZg.png?1718347272)

## 맞춤 결제 링크의 제한 사항

1. 한 번에 최대 50명의 연락처에 맞춤 결제 링크를 보낼 수 있어요.

2. 연락처에 유효한 이메일 주소와 전화번호가 모두 있어야 맞춤 링크가 발송돼요.

3. 수신거부가 설정된 연락처에는 결제 링크가 발송되지 않아요.
