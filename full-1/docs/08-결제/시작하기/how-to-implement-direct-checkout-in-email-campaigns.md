# 이메일 캠페인에 바로 결제 연결하기

이메일 캠페인에 상품 요소를 넣고 바로 결제(direct checkout)를 설정하는 방법을 안내해요. 이번 업데이트로 상품 요소를 추가하고 설정하는 과정이 더 쉬워졌어요.

[동영상](https://www.youtube.com/embed/X544bUPUiPo?&wmode=opaque)

## 기존 문제

이전에는 이동 링크로 일반 URL만 쓸 수 있었어요. 상품마다 링크를 따로 설정할 방법이 없었어요.

## 달라진 점

1. 상품마다 바로 결제 링크를 만들 수 있어요.
2. 같은 캠페인 안에서 상품별로 결제 페이지를 사용자 지정할 수 있어요.
3. 구매 내역이 전환 통계와 캠페인 통계에 자동으로 반영돼요.

## 장점

1. 상품 요소를 더 쉽게 설정하고 사용할 수 있어요.
2. 전환 지표를 더 잘 추적할 수 있어요.

## 사용 방법

1. **이메일 마케팅**(Email Marketing)으로 이동하세요.
2. 새 이메일 캠페인을 만드세요.
3. **상품** 요소를 추가하고 **Direct Checkout**(바로 결제)을 선택하세요.

   ![상품 요소에서 바로 결제를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031305008/original/vcTK-ArmEr4mLBMlw8ZMG0rF1Q8gJ-tNRA.jpeg?1724102755)

4. 상품 옆의 링크 아이콘을 클릭해 결제 페이지를 사용자 지정하세요.
5. 결제 페이지 레이아웃을 수정한 뒤 변경 내용을 저장하세요.

   ![결제 페이지 레이아웃을 수정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031305007/original/YZBlaT9XJ8K4fcGGdhxK00IDEUUiCU2P4Q.jpeg?1724102755)

6. 테스트 이메일을 보내 모든 기능이 제대로 작동하는지 확인하세요.
