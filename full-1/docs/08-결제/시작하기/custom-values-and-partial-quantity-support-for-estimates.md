# 견적서의 커스텀 값과 소수 수량 지원

**견적서**(Estimates)에서 커스텀 값을 쓰고, 항목 수량을 1.5처럼 소수로 입력하는 방법을 안내해요. 견적서를 사업 방식에 맞게 만들고, 가격을 더 정확하게 계산하고 싶을 때 보세요.

[동영상](https://www.youtube.com/embed/HAoXRKnDY-4?&wmode=opaque)

## 커스텀 값과 소수 수량 지원이란?

이 기능을 쓰면 견적서를 더 유연하게 만들 수 있어요.

- 견적서에서 커스텀 값을 정의해 쓸 수 있어요. 견적서마다 같은 정보를 일관되게 넣고, 필요에 맞게 바꿀 수 있어요.
- 항목의 수량을 소수로 설정할 수 있어요. 서비스나 상품을 더 세밀하게 제안할 수 있어요.

사업 상황에 맞게 견적서를 꾸미면서도 가격과 계산은 정확하게 유지할 수 있어요.

## 견적서에서 커스텀 값 사용하기

커스텀 값은 두 가지 방식으로 쓸 수 있어요.

### 1. 편집 화면에서 직접 설정하기

견적서를 편집하면서 커스텀 값을 바로 조정하는 방식이에요.

1. 대시보드에서 **견적서** 메뉴로 이동하세요.
2. 기존 견적서를 열거나 새 견적서를 만드세요.
3. **커스텀 값** 필드를 찾아 필요한 정보를 입력하세요.
4. 저장한 뒤 고객에게 견적서를 보내세요.

### 2. 설정에서 미리 정해 두기

모든 견적서에 같은 커스텀 값을 적용하려면 설정에서 값을 미리 정해 두세요.

1. 관리 화면에서 **설정**으로 이동하세요.
2. **Estimates Preferences**(견적서 환경설정)를 선택하세요.
3. 사용할 커스텀 값을 정의하고 저장하세요.
4. 이제 견적서를 만들 때 이 값들을 자동으로 사용할 수 있어요.

## 견적서에서 소수 수량 사용하기

시간이나 자재처럼 소수 단위로 측정하는 서비스·상품이라면, 견적서 항목의 수량을 소수로 설정할 수 있어요.

1. **견적서** 메뉴를 여세요.
2. 기존 견적서를 선택하거나 새 견적서를 만드세요.
3. 항목을 추가할 때 **Quantity**(수량) 필드에 소수 값을 입력하세요. 예를 들어 1.5시간, 0.25개처럼 입력해요.
4. 입력한 소수 수량에 맞춰 가격이 자동으로 계산돼요.
5. 저장한 뒤 견적서를 보내세요.

시간 단위로 제공하는 서비스, 건축 자재, 그 밖에 정수로 나누어 떨어지지 않는 항목을 다루는 사업에 알맞은 기능이에요.

## 자주 묻는 질문

### 한 견적서에서 편집 화면의 커스텀 값과 설정의 커스텀 값을 함께 쓸 수 있나요?

네, 설정에서 미리 정한 값이 있어도 편집 화면에서 커스텀 값을 직접 조정할 수 있어요.

### 소수 수량을 쓰면 가격 계산에 영향이 있나요?

아니요, 입력한 소수 수량을 기준으로 시스템이 가격을 자동으로 계산하기 때문에 견적이 정확하게 나와요.

### **Order Submitted**(주문 제출됨) 트리거로 여러 팀에 알림을 보낼 수 있나요?

네, 여러 액션을 설정할 수 있어요. 팀마다 다른 알림을 보내거나 CRM 데이터를 업데이트할 수도 있어요.

### PayPal로 **정기 인보이스**의 자동 결제를 사용할 수 있나요?

아니요, **정기 인보이스**에서는 자동 결제를 끈 경우에만 PayPal을 쓸 수 있어요.

## 다음 단계

- 견적서를 빠르게 만들 수 있도록 커스텀 값을 설정하세요.
- 더 정확한 청구를 위해 소수 수량을 사용하세요.
- 워크플로우를 자동화하려면 [Order Submitted 트리거](../../07-워크플로우/workflow-trigger-order-submitted.md)를 설정하세요.
- 견적서와 관련된 워크플로우는 [견적서 워크플로우 트리거](../../07-워크플로우/Payments-Workflow-Triggers/workflow-trigger-estimates.md)로 자동화할 수 있어요.
- **정기 인보이스**에서 PayPal을 쓰려면 [Order Submitted 트리거와 PayPal 지원](../../07-워크플로우/workflow-trigger-order-submitted.md) 문서를 참고하세요.
