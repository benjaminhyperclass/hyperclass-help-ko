# 제안서 & 견적서에 여러 수신자 지정하기

제안서 & 견적서 하나에 수신자를 여러 명 추가하고, 수신자마다 서명 요소를 지정하는 방법을 안내해요. 한 문서에 서명할 사람이 여러 명일 때 활용하세요.

[동영상](https://www.youtube.com/embed/5Qb\_7NiPt6s?&wmode=opaque)

## 여러 수신자 기능 살펴보기

- 문서 하나에 수신자를 여러 명 지정해 보낼 수 있고, 서명 요소도 수신자별로 나누어 지정할 수 있어요. 이전에는 수신자를 한 명만 지정할 수 있었어요.
- 제안서를 보내는 비즈니스 사용자에게도 서명을 지정할 수 있어요.
- 수신자마다 고유한 링크가 발송돼요. 각 수신자는 이 링크로 자기 몫의 서명만 할 수 있어요.
- 서명 필드가 지정된 수신자는 서명자(Signer)라고 해요. 문서에 추가했지만 서명 필드가 지정되지 않은 연락처는 참조 수신자(CC recipient)라고 해요.
- 모든 참여자가 문서에 서명하거나 수락하고 나면, 서명이 완료된 PDF 사본과 서명 인증서가 생성돼요.
- 서명 인증서에는 문서에 서명하는 모든 수신자의 IP 주소, 위치, 열람 일시, 서명 일시 같은 정보가 기록돼요.
- 기본적으로 가장 먼저 추가한 수신자가 문서의 주 수신자(Primary recipient)가 돼요. 이 경우 커스텀 필드는 주 수신자의 정보로 채워져요. 모든 참여자가 문서를 수락하거나 서명하고 나면 주 수신자 앞으로 인보이스도 만들어져요.
