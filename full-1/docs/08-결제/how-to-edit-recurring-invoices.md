# 정기 인보이스 편집하기

이미 만들어 둔 정기 인보이스의 청구 주기, 날짜, 상품·서비스를 수정하는 방법을 안내해요. 고객의 결제 일정이나 계약 내용이 바뀌었을 때 새 인보이스를 처음부터 만들지 않고 기존 인보이스를 고쳐 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/ekTVx92iEhM?&wmode=opaque)

## 새로 달라진 점

### 정기 인보이스 편집 기능 강화

- 청구 주기 변경: 기존 정기 인보이스의 청구 주기(예: 매주, 매월, 매년)를 고객의 결제 일정이나 프로젝트 일정에 맞게 바꿀 수 있어요.
- 날짜 변경: 예약된 인보이스의 시작일과 종료일을 수정해, 서비스 기간이나 계약 내용이 바뀐 경우에 맞출 수 있어요.
- 상품/서비스 수정: 진행 중이거나 예약된 정기 인보이스에 들어 있는 상품과 서비스를 추가, 제거, 변경할 수 있어요. 판매하는 상품이나 고객 요구가 바뀐 경우에 쓰세요.
- 자동 이메일 알림: 편집한 정기 인보이스에서 자동 결제가 켜져 있으면, 사용자에게 이메일 알림이 자동으로 발송돼요.
- 알림 내용 사용자 지정: 인보이스 설정에서 알림 이메일의 내용을 브랜드 말투에 맞게 바꿀 수 있어요.

## 새 기능 사용 방법

1. 하이퍼클래스 대시보드에서 **Invoicing**(인보이스) 섹션으로 이동한 뒤 **정기 인보이스**를 선택하세요.

   ![정기 인보이스 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430829/original/kWgmDF9xxIivX_DxGicJXyqwYygMkiusoQ.jpeg?1734374449)

2. 수정하려는 진행 중이거나 예약된 정기 인보이스를 선택해 내용을 확인하세요.

   ![수정할 정기 인보이스 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430831/original/MOaI2YNPd26w1ylyrHyKltDKcO4qtJXCeg.jpeg?1734374449)
   ![정기 인보이스 상세 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430834/original/oFeruYaQHZz61niISWniDzaeuMMXHl34GA.jpeg?1734374449)

3. 필요에 따라 청구 주기, 날짜, 상품/서비스를 변경하세요.

   ![청구 주기와 날짜 수정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430827/original/qp0Xu3IfwZj6sFhzth1L3I50lMsWojHAlw.jpeg?1734374448)
   ![상품과 서비스 수정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430830/original/nSAvzm4md-7wyv89rZK4_U6HAYu8SCx7gw.jpeg?1734374449)

4. 수정을 마쳤으면 **변경사항 저장**을 선택해 인보이스에 반영하세요.

   ![변경사항 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430832/original/Tu0lAbSYgUSmHBhpCfbT7nJb3VfzBZxyeg.jpeg?1734374449)

5. 이메일 알림 내용을 바꾸려면 **인보이스 설정**으로 이동해 **customer notifications**(고객 알림)를 열어요.

6. **자동 결제 금액이 변경되었습니다** 알림을 편집해서 제목, 본문 등 알림 이메일의 세부 내용을 수정하세요.

   ![인보이스 설정의 고객 알림 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430833/original/o75rgDL5JUAxCdcBQsxZxnTbtA_P7t_7eQ.jpeg?1734374449)
   ![자동 결제 금액 변경 알림 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038430825/original/ccvogSUubxC9vWuZkfMH-LLKScJ9xgmYuw.jpeg?1734374449)

## 이 기능이 만들어진 이유

유연한 청구: 사업을 하다 보면 서비스 계약, 프로젝트 범위, 고객 요구가 바뀌는 일이 자주 있어요. 정기 인보이스를 쉽게 수정할 수 있으면 새 인보이스를 처음부터 만드는 번거로움 없이도, 청구 내용을 현재 운영 상황에 맞게 정확하게 유지할 수 있어요.
