# Stripe에서 상품·가격 가져오기

Stripe 계정에 있는 정기 구독 요금제와 가격을 하이퍼클래스 상품으로 가져오는 방법을 안내해요. 어떤 가격을 가져올 수 있는지, 가져올 때 무엇이 만들어지는지, 가격을 수정하면 어떻게 동기화되는지 확인하세요.

**[동영상](https://www.youtube.com/embed/xda0tiVYylI?&wmode=opaque)**

## 가져올 수 있는 요금제

- **정기 구독** / **구독** 요금제만 가져올 수 있어요. 일회성 가격은 가져올 수 없어요. 일회성 가격은 하이퍼클래스에서 직접 만들어야 해요.
- Stripe에서 요금제·가격을 가져오려면 라이브 모드여야 해요. 테스트 모드의 가격은 가져올 수 없어요.
- 정기 요금제·가격을 가져올 때 "종량제(Metered)" 가격은 가져올 수 **없어요**.
- 이미 하이퍼클래스로 가져온 Stripe 요금제·가격은 **Import From Stripe**(Stripe에서 가져오기) 기능의 선택 목록에 나타나지 않아요.

## Stripe에서 가격을 가져오면 일어나는 일

- 가격과 연결된 Stripe 상품을 가져오고, 하이퍼클래스에 해당 상품이 없으면 새로 만들어요.
- 그 상품 아래에 가격을 만들어요.
- Stripe 테스트 모드와 PayPal에도 같은 상품과 가격을 만들어요. PayPal은 연동이 되어 있을 때만 해당돼요.

## Stripe 계정의 가격 유형 3가지

Stripe 계정에 있는 가격은 만들어진 방식에 따라 3가지로 나뉘고, 유형마다 수정 방식이 달라요.

1. 에이전시 수준에서 **SaaS 구성기**로 만든 가격

- **SaaS 구성기**로 만든 가격은 상품 목록과 상품 상세 페이지에서 상품·가격 이름과 함께 **에이전시 플랜** 태그가 표시돼요.
- **SaaS 구성기**로 만든 가격은 하이퍼클래스 결제에서 편집할 수 없어요.
- Stripe에서 가격을 직접 수정해도 하이퍼클래스 상품·가격에는 반영되지 않아요.
- **SaaS 구성기**로 만든 상품의 가격을 바꾸려면 Stripe에서 가격을 수정하세요. 그런 다음 **Import From Stripe** 버튼으로 새 가격을 가져오세요. 그러면 **에이전시 플랜** 태그가 붙은 새 하이퍼클래스 상품이 만들어져요. 이 상품은 퍼널이나 **웹사이트 페이지** 설정에서 선택할 수 있어요.

![SaaS 구성기로 만든 상품에 에이전시 플랜 태그가 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48158655926/original/_4ysyT1_RvDXKVtRAtamCvGXle9eLywe-A.jpeg?1636734358)

2. 하이퍼클래스에서 상품을 만들면서 함께 생성된 가격

- 하이퍼클래스에서 상품을 만들면 Stripe에도 그에 맞는 요금제·가격이 만들어져요.
- 하이퍼클래스 상품 가격을 수정하면 Stripe에 새 가격이 만들어지는 방식으로 자동 동기화돼요. Stripe API가 기존 가격의 수정을 지원하지 않기 때문이에요.
- Stripe에서 가격을 수정하면 하이퍼클래스에는 자동으로 동기화되지 **않아요**. Stripe에서 바꾼 가격은 새 상품으로 하이퍼클래스에 가져와야 해요.

3. Stripe에서 직접 만든 가격

- Stripe에서 요금제·가격을 직접 만들었다면 **Import From Stripe** 버튼으로 하이퍼클래스 상품으로 가져올 수 있어요.
- 가져온 상품의 가격을 수정해야 하면 하이퍼클래스에서 수정하세요. 수정한 내용은 Stripe에 새 가격이 만들어지는 방식으로 동기화돼요.
- 가져온 요금제·가격을 Stripe에서 수정하면 하이퍼클래스 상품에는 반영되지 않아요. 바뀐 요금제·가격을 새 하이퍼클래스 상품으로 가져와야 해요.
