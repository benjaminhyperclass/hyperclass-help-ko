# 모바일에서 자동 세금 사용하기

하이퍼클래스 모바일 앱에서 인보이스, POS 결제, 견적서를 만들 때 세금을 자동으로 계산하고 적용하는 기능이에요. 고객 위치와 상품 세금 코드를 기준으로 세금을 계산하므로, 직접 입력하는 수고를 줄이고 세금 처리의 정확도를 높일 수 있어요.

## 모바일 결제의 자동 세금이란?

자동 세금은 설정해 둔 세금 정보, 고객 주소, 상품 세금 카테고리를 바탕으로 세금을 실시간으로 계산해요. 모바일에서 인보이스를 만들거나 POS 결제를 처리하거나 견적서를 작성할 때 알맞은 세금이 자동으로 적용돼요.

nexus 지역, 세금 ID 같은 세금 설정과 상품별 세금 코드를 연결해 두면, 하이퍼클래스가 직접 입력하지 않아도 알맞은 세율을 정해 줘요. 지역마다 세금 규정이 다른 여러 지역에서 사업을 운영한다면 특히 유용해요.

**가용성:**

1. 하이퍼클래스 v3.108.4 이상
2. 하이퍼클래스 모바일 앱 v3.108.4 이상
3. 화이트라벨 앱 - 셀프 서브

---

## 자동 세금의 주요 이점

자동 세금을 쓰면 결제 과정에서 업무 효율을 높이고, 규정을 지키고, 수작업을 줄일 수 있어요.

- 세금 자동 계산: 고객 주소와 설정된 세금 정보를 기준으로 세금을 바로 계산해요.
- 정확도 향상: 세금을 직접 입력하다 생기는 실수를 줄여 줘요.
- 글로벌 규정 준수: 여러 국가와 지역의 세금 계산을 지원해요.
- 시간 절약: 거래마다 세율을 직접 적용하지 않아도 돼요.
- 상품별 유연성: 특정 상품에 세금 코드를 지정해 세금을 세밀하게 처리할 수 있어요.

---

## 상품 세금 코드 설정

상품 세금 코드를 지정하면 거래할 때 각 항목에 알맞은 세금 규정이 적용돼요. 상품마다 세금이 다르게 부과될 때 정확하게 계산하려면 꼭 필요해요.

- 상품을 만들거나 편집할 때 **상품 세금 코드**를 선택하세요.
- 세금 코드에 따라 관할 지역별로 상품에 세금이 부과되는 방식이 정해져요.
- 직접 선택하지 않으면 시스템이 미리 정해 둔 세금 설정을 기본값으로 쓸 수 있어요.

---

## 결제 설정에서 자동 세금 켜기 (모바일)

**결제 설정**에서 자동 세금을 켜면 모바일 앱에서 만드는 인보이스, POS 결제, 견적서에 세금 계산이 적용돼요.

- 모바일 앱에서 **결제 설정**으로 이동하세요.
- **자동 세금** 토글을 찾으세요.
- 토글을 켜면 세금이 자동으로 계산돼요.

---

## 주소 기반 세금 계산

세금 계산은 고객 주소에 크게 좌우돼요. 주소가 정확해야 하이퍼클래스가 위치에 맞는 세율을 정할 수 있어요.

- 고객 주소로 세금을 계산해요.
- 시스템이 고객 주소를 설정해 둔 nexus 지역과 맞춰 봐요.
- 주소가 없거나 틀리면 세금이 제대로 계산되지 않을 수 있어요.
- 인보이스를 검토하는 단계에서 주소를 수정할 수 있어요.

---

## 인보이스 세금 내역 확인

인보이스를 보내기 전에 세금 내역을 확인하면 청구 내용을 투명하고 정확하게 관리할 수 있어요. 하이퍼클래스는 계산된 세금을 인보이스 요약에 자동으로 보여 줘요.

- 세금 금액이 인보이스 요약에 자동으로 나타나요.
- 주세, 시세, 특별세처럼 세금 항목이 여러 개면 나누어 표시될 수 있어요.
- 설정에 따라 세금이 소계에 포함되거나 소계에 추가로 더해질 수 있어요.

---

## 자동 세금 설정 방법

세금을 정확하게 계산하고 규정을 지키려면 설정을 제대로 해 두는 것이 중요해요. 웹에서 세금 설정을 먼저 한 뒤, 모바일에서 기능을 켜면 돼요.

### 1단계: 자동 세금 설정하기 (웹)

1. **결제 > 설정 > 세금 > 자동 세금**으로 이동하세요.
2. nexus 지역(세금을 징수하는 국가·주)을 추가하세요.
3. 해당하는 지역마다 세금 ID(Tax ID)를 입력하세요.
4. 설정을 저장하세요.

![웹에서 자동 세금을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071183234/original/uMdjc1rpu4List08tRJyZyLMNYLuPA5vRg.png?1778617106)

### 2단계: 모바일에서 자동 세금 켜기

1. 하이퍼클래스 모바일 앱을 여세요.
2. **인보이스** 또는 **POS**(판매 시점 결제)로 이동하세요.
3. **+**(만들기) 버튼을 눌러 새 인보이스를 시작하세요.
4. 오른쪽 위에 있는 설정 아이콘을 누르세요.
5. **자동 세금**을 켜세요.

![모바일에서 자동 세금을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071183099/original/glu9q1z64Hn88MpcxV2dbYLT23cYwKyN-A.png?1778616918)

### 3단계: 자동 세금으로 인보이스 만들기

1. **상품 추가**로 상품이나 직접 입력한 항목을 인보이스에 추가하세요.
2. 상품에 세금 코드가 지정되어 있는지 확인하세요.

   ![상품에 세금 코드가 지정된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071183128/original/sb7hBWaXNvpZ5oJtf8LgSoH7lHl-V6Sn2Q.png?1778616975)
3. 고객 주소를 입력하거나 확인하세요.

   ![고객 주소를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071183164/original/sUiZHba1SQOqvpBB0POxLrZutsqil-pqxw.png?1778617007)
4. 인보이스 요약을 검토하세요.
5. 세금이 자동으로 계산되었는지 확인하세요.
6. **보내기**를 누르세요.

![세금이 계산된 인보이스 요약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071183189/original/FK98yMEEgYGrza604CX37JYRruxDQD0Ndw.png?1778617037)

## 자주 묻는 질문

### 모바일에서 이 기능을 쓰기 전에 웹에서 세금을 먼저 설정해야 하나요?
네. 자동 세금을 쓰려면 먼저 웹에서 nexus 지역과 세금 ID 같은 설정을 해 두어야 해요.

### 상품에 세금 코드가 없으면 어떻게 되나요?
시스템이 기본 세금 설정을 사용할 수 있어요. 다만 상품 세금 코드를 지정하면 더 정확하게 계산돼요.

### 세금을 직접 적용할 수도 있나요?
네, 수동으로 세금을 적용하는 옵션을 쓸 수 있는 경우가 있어요. 다만 정확성과 효율을 위해 자동 세금을 권장해요.

### 인보이스에 세금이 표시되지 않아요.
고객 주소가 없거나, 자동 세금이 꺼져 있거나, 세금 설정이 끝나지 않아서일 수 있어요.

### 인보이스를 만든 뒤에도 고객 주소를 수정할 수 있나요?
네. 인보이스 검토 단계에서 주소를 수정할 수 있어요.

### POS와 견적서에서도 쓸 수 있나요?
네. 자동 세금은 인보이스, POS 결제, 견적서에 모두 적용돼요.
