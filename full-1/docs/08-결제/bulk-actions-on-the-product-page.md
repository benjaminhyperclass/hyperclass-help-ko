# 상품 페이지에서 일괄 작업 사용하기

**일괄 작업**(Bulk Actions)을 쓰면 여러 상품이나 옵션을 한 번에 수정할 수 있어요. 반복 작업이 줄고 재고도 더 정확하게 관리할 수 있어요. 이 문서에서는 **상품** 페이지에서 공개 설정, 가격, 컬렉션, 삭제, 재고 수량, 재고 상태를 한꺼번에 바꾸는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/ej-tDQkOIAY?&wmode=opaque)

## 상품 페이지의 일괄 작업이란?

**일괄 작업**은 많은 상품을 한 화면에서 관리하는 기능이에요. 여러 상품을 선택해 스토어 공개 설정, 가격, 컬렉션 등을 몇 번의 클릭으로 바꿀 수 있어요. 상품 수가 많거나 가격·재고를 자주 바꿔야 할 때 편해요.

## 일괄 작업의 장점

- 시간 절약: 수백 개 상품에 같은 변경을 몇 번의 클릭으로 적용해요.
- 일관성: 가격이나 재고 정책을 옵션과 상품 전체에 똑같이 맞춰요.
- 오류 감소: 미리보기와 검증 단계가 있어서 하나씩 직접 고칠 때보다 실수가 줄어요.
- 확장성: 필터와 페이지 나누기로 상품이 많아도 안심하고 관리할 수 있어요.
- 운영 정확도: 재고 수량과 판매 규칙을 실제 재고와 맞춰 둘 수 있어요.

## 사용할 수 있는 일괄 작업

| 작업 | 설명 |
| --- | --- |
| **Include in Online Store**(온라인 스토어에 포함) | 선택한 상품을 온라인 스토어에 표시해요. |
| **Exclude in Online Store**(온라인 스토어에서 제외) | 선택한 상품이 온라인 스토어에 표시되지 않게 해요. |
| **가격 변경** | 고정 금액이나 비율로 여러 상품의 가격을 올리거나 내리거나 새로 지정해요. |
| **비교 가격 변경** | 위와 같은 방식으로 **비교 가격** 필드의 값을 바꿔요. |
| **콜렉션에 추가** | 상품을 하나 이상의 컬렉션에 추가해요. 그 자리에서 새 컬렉션을 만들 수도 있어요. |
| **삭제** | 선택한 상품을 한꺼번에 삭제해요. 삭제 전에 확인 창이 나와요. |

{% hint style="warning" %}
가격 변경은 선택한 상품의 모든 옵션에 적용돼요.
{% endhint %}

## 일괄 작업 여는 방법

1. 이커머스 스토어에서 **결제 > 상품**으로 이동하세요.

   ![상품 페이지 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055466197/original/7NAAYMAc3rYuLeYkOWxrWsPfvamlpcMuzA.png?1759872698)

2. 일괄 작업을 적용할 상품을 선택하세요.
   - 각 행의 체크박스를 눌러 상품을 하나씩 선택하거나, 맨 위 체크박스를 눌러 현재 페이지의 상품을 모두 선택하세요.
   - 서브 계정의 모든 상품을 선택하려면, 한 페이지를 전체 선택한 뒤 나타나는 **전체 선택** 안내를 누르세요.

   ![상품 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055466250/original/Y2EO20iN9hCW1XbweBE41dVqrMNAb1tnag.png?1759872811)

3. **일괄 작업** 드롭다운을 열고 원하는 작업을 선택하세요.

   ![일괄 작업 드롭다운 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055466285/original/UXVSspDqorr4JLDr0CfZdocpX6GXBImwRQ.png?1759872908)

## 일괄 작업 전에 상품 필터링하기

필터 패널로 대상 상품을 먼저 좁힌 다음 일괄 작업을 적용하세요. 필터와 **전체 선택**을 함께 쓰면 더 정확하게 대상을 고를 수 있어요. 작업 전에 필터로 상품 그룹을 따로 추려 두면 엉뚱한 상품을 수정할 위험이 줄어요.

사용할 수 있는 필터는 다음과 같아요.

- **스토어 공개 설정**: 포함 / 숨김
- **컬렉션**: 이름으로 선택
- **출처**: **전체 상품**, WooCommerce

필터를 적용하려면 오른쪽 위의 **필터** 버튼을 누르고, 드롭다운에서 원하는 필터를 고르세요.

![필터 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055466377/original/FdMysgt6m5pE_GfWYSUxcDnYtNroW-CVoA.png?1759873120)

## 알아 둘 점

### 동작 방식과 제한

- 음수 값 방지: 가격 변경 결과가 음수가 되는 상품은 건너뛰어요. 나머지 상품은 그대로 변경돼요.
- 한 번에 하나의 작업만: 진행 중인 일괄 작업이 끝나야 새 작업을 시작할 수 있어요.
- 전체 스토어에 적용되는 공개 설정: 공개 설정 변경은 연결된 모든 스토어에 적용돼요. 특정 스토어만 제외하려면 **사이트 > 스토어** > 스토어 선택 > **상품**에서 설정하세요.
- 가격 변경에는 기준 값이 필요해요: **Increase**(인상)나 **Decrease**(인하) 작업은 **가격** 또는 **비교 가격**에 기존 값이 있어야 해요. 기준 값이 없는 상품은 변경되지 않아요.
- 많은 상품을 삭제할 때의 확인: 50개를 넘는 상품을 삭제하려면 확인 창에 “Delete”를 입력해야 해요. 삭제한 상품은 복구할 수 없어요.
- 일괄 삭제와 삭제 제한 상품: 삭제가 제한된 상품이 선택에 포함되어 있어도 일괄 삭제는 실패하지 않아요. 하이퍼클래스가 제한된 상품은 자동으로 건너뛰고, 삭제할 수 있는 상품만 삭제해요. 삭제가 제한되는 상품은 다음과 같아요.

  - 캘린더에서 만든 상품
  - 멤버십·커뮤니티에서 만든 상품
  - 활성(active) 또는 연체(past_due) 상태의 구독이 있는 SaaS 상품

  자세한 내용은 상품 삭제 방식(How Product Deletion Works) 문서를 참고하세요.
- 대량 변경 시 지연: 300개가 넘는 상품을 변경하면 반영되기까지 잠시 걸릴 수 있어요.

### 선택 유지 방식

| 동작 | 결과 |
| --- | --- |
| 맨 위 체크박스 클릭 | 현재 페이지의 모든 상품을 선택해요. |
| 다른 페이지로 갔다가 돌아오기 | 선택이 유지돼요(현재 페이지 선택에만 해당). |
| **전체 선택**으로 전체 목록 선택 | 다른 페이지로 이동하면 선택이 유지되지 않아요. |

## 자주 묻는 질문

### 디지털 상품과 실물 상품에 일괄 작업을 함께 적용할 수 있나요?
네, 상품의 배송 유형과 상관없이 적용돼요.

### 일괄 변경이 옵션에도 반영되나요?
네, 가격과 관련된 변경은 모두 옵션 단위에도 반영돼요.

### 일괄 삭제를 되돌릴 수 있나요?
아니요, 삭제한 상품은 영구적으로 삭제되니 신중하게 사용하세요.
