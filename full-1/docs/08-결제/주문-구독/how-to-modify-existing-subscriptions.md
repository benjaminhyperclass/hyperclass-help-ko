# 기존 구독 수정하기

이미 만든 구독에서 상품, 수량, 시작일·종료일을 바꾸는 방법을 안내해요. 구독을 취소하고 다시 만들지 않아도 고객 요구에 맞게 바꿀 수 있고, 결제일도 그대로 유지돼요.

## 개요

구독은 상품, 수량, 구독 시작일·종료일이 바뀌면 그에 맞게 업데이트할 수 있어요. 구독을 취소하고 다시 만들 필요가 없고, 결제일도 그대로예요.

## 이 기능으로 할 수 있는 일

**Modify Subscription**(구독 수정) 기능으로 다음 작업을 할 수 있어요.

- 기존 구독에 상품을 추가해요. 결제 주기와 통화가 같은 상품만 추가할 수 있어요.
- 상품을 제거해요. 제거한 상품은 이후 결제 주기에 청구되지 않아요.
- 구독에 포함된 상품의 수량을 바꿔요(1개에서 1,000개 사이).
- 구독 날짜를 수정해요.

  - 구독이 예정 상태이고 아직 시작 전이면 시작일을 바꿀 수 있어요.
  - 활성 구독이면 종료일을 바꿀 수 있어요.
- 저장하기 전에 변경 내용과 바뀐 합계 금액을 미리 확인해요.
- 아직은 요금을 일할 계산하는 기능이 없어요. 이 기능은 곧 지원될 예정이에요.

---

## 사용하려면 필요한 것

- **결제 > 구독** 메뉴에 접근할 수 있어야 해요.
- 구독 상태가 **Scheduled**(예정), **Trialing**(체험 중), **활성** 중 하나여야 해요.
- **지원되는 결제 제공업체**: Stripe, Square, NMI, Authorize

---

## 구독 수정하는 순서

### 1단계: 구독 열기

1. **결제 > 구독**으로 이동해요.
2. 수정할 구독을 선택해요.
3. 메뉴를 열고 **업데이트**를 클릭해요.
4. **구독 세부정보** 페이지를 열어서 **작업** 아래의 **업데이트**를 눌러도 돼요.

![구독 목록에서 업데이트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052169881/original/NrbU-k4ekQ9mhTSx6Ch6YnkZjaLAQcQJhg.png?1755866685)

![구독 세부정보 페이지의 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052167816/original/Jr2IPswjkQ5QVV08f10ImLLBsaQ3K1fDcQ.png?1755865362)

### 2단계: 변경하기

- 상품을 추가하려면 **+** 버튼을 클릭해요. 구독의 결제 주기와 같은 상품만 목록에 나와요.
- 상품을 제거하려면 상품 이름 옆의 **삭제** 아이콘을 클릭해요.
- 수량을 바꾸려면 **Quantity**(수량) 필드의 숫자를 수정해요.
- 날짜를 바꾸려면 **Scheduled** 상태 구독은 **시작일**을, **활성** 상태 구독은 **종료일**을 수정해요.

![상품 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052167853/original/5AL29N50Z2_q8TKy3nHmVy9p3C1saefPig.png?1755865395)

![시작일과 종료일 수정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052167876/original/1u91FfeQwL9IHKr2KRTJAtvBEreQ8yY9nQ.png?1755865415)

### 3단계: 확인하고 저장하기

- 미리보기에서 바뀐 상품, 수량, 날짜, 새 합계 금액을 확인해요.
- 변경 내용을 확인한 뒤 확정하면 구독이 업데이트돼요.
- 새 설정은 다음 결제 주기부터 적용돼요.

{% hint style="info" %}
요금을 일할 계산하는 기능은 곧 지원될 예정이에요. 지금은 새 합계 금액이 다음 결제일에 적용돼요.
{% endhint %}

## 자주 묻는 질문

### 상품이나 수량을 바꾸면 지난 거래에도 영향이 있나요?
아니요, 지난 거래는 그대로예요. 변경 내용은 앞으로의 결제 주기에만 적용돼요.

### 변경하면 결제일이 달라지나요?
결제일은 바뀌지 않아요. 모든 변경은 기존 결제 일정에 맞춰 적용돼요.

### 상품을 한 번에 여러 개 추가할 수 있나요?
네, 결제 주기가 같은 상품이면 여러 개를 함께 추가할 수 있어요.

### 수정 내역은 어디서 볼 수 있나요?
모든 변경 내역은 **구독 세부정보** 페이지에 기록돼요. 확인하거나 점검할 때 참고하세요.

### 체험 기간이 있는 상품을 구독에 추가하면 어떻게 되나요?

- 진행 중인 **활성** 구독에 상품을 추가하거나 상품 수량을 바꾸면 체험 기간은 건너뛰거나 적용되지 않아요.
- 구독이 **체험판** 상태이면 새로 추가한 상품도 기존 구독의 체험 종료일까지 체험으로 이용해요. 요금은 체험이 끝난 뒤 다음 결제 주기에 청구돼요.

### 체험 기간이 있는 상품을 구독에 추가하면 어떻게 되나요?
<!-- 검토 필요: 원문 내용이 서로 다름 -->

- 새로 추가한 상품에 셋업 비용이 있으면 일회성 요금으로 합계에 더해져 다음 결제 주기에 청구돼요. 기존 상품의 수량을 늘렸고 그 상품에 셋업 비용이 있으면, 늘어난 수량만큼의 셋업 비용이 다음 결제 주기에 청구돼요.
- 구독이 **체험판** 상태이면 새 상품의 셋업 비용은 다음 결제 주기, 즉 체험이 끝나는 시점에 청구돼요.

### 구독에 진행 중인 쿠폰이 있으면 어떻게 되나요?
진행 중인 쿠폰이 새로 추가한 상품에도 적용되는 쿠폰이면, 다음 결제 주기부터 새 상품에 적용돼요.

{% hint style="info" %}
진행 중인 구독의 쿠폰을 바꾸는 옵션은 곧 제공될 예정이에요.
{% endhint %}

### Cancelled, Overdue, Unpaid 상태의 구독도 수정할 수 있나요?
아니요. **Scheduled**, **활성**, **Trialing** 상태의 구독만 수정할 수 있어요.

### 구독에 등록된 고객의 신용카드 정보를 업데이트하려면 어떻게 하나요?
구독에서 보안 결제 정보 업데이트 링크를 공유하면 돼요.

1. 서브 계정에서 **결제 > 구독**으로 이동해요.
2. 해당 고객의 구독을 찾아 선택해요.
3. 오른쪽의 점 세 개(⋮)를 클릭해요.
4. **Share Payment Update Link**(결제 정보 업데이트 링크 공유)를 선택해요.
5. 고객에게 링크를 보내요.

   - 링크를 복사해서 채팅이나 메시지로 공유해요.
   - 또는 **이메일** 옵션으로 플랫폼에서 바로 보내요.

고객은 이 보안 링크에서 직접 카드 정보를 업데이트할 수 있어요.
