# 기프트 카드 시작하기

기프트 카드 상품을 만들고, 판매하거나 연락처에게 바로 보내고, 발행한 카드를 추적하는 전체 흐름을 안내해요. 기프트 카드를 처음 쓸 때 먼저 읽어 보세요.

[동영상](https://www.youtube.com/embed/w-Xd_jRd83w?&wmode=opaque)

기프트 카드를 쓰면 기존 결제 환경 안에서 고객과 소통하고, 매출을 늘리고, 단골을 만들 수 있어요. 브랜드에 맞춰 꾸민 디지털 카드를 만들어 판매할 수 있어요. 아트워크와 금액 단위, 만료일, 이용 약관까지 카드의 모양과 동작을 직접 정할 수 있어요.

---

## 기프트 카드란?

기프트 카드는 매출을 올리고, 단골 고객에게 보상하고, 프로모션을 간단하게 운영하도록 도와줘요. 브랜드가 담긴 기프트 카드 상품을 만들어 판매하거나 보낼 수 있어요. 발행한 모든 카드는 **결제** 메뉴 안의 전용 **Gift Card Orders**(기프트 카드 주문) 페이지에서 추적해요.

고객이 소중한 사람에게 선물하려고 구매할 수도 있고, 단골 고객에게 무료 크레딧을 선물로 줄 수도 있어요. 기프트 카드를 쓰면 모든 거래가 한층 더 개인적인 경험이 돼요. 전용 결제 화면에서 판매하거나 웹사이트에 삽입할 수 있어요. QR 코드로 공유하거나, 사용자 지정 메시지와 함께 연락처에 바로 보내는 것도 가능해요. 발행한 카드는 모두 자동으로 **Gift Card Orders**에 기록돼서 잔액, 상태, 사용 내역을 한눈에 볼 수 있어요. 고객도 편하게 결제할 수 있고요.

기프트 카드로 할 수 있는 일은 다음과 같아요.

- **기프트 카드 상품 만들기**: 브랜딩, 금액 단위, 만료일 등을 설정해요.
- **기프트 카드 판매하기**: 전용 결제 화면, 웹사이트 삽입, QR 코드로 판매해요.
- **기프트 카드 바로 보내기**: 결제를 받지 않고 연락처에게 보내요. 프로모션이나 서비스 불만 보상에 알맞아요.
- **발행한 모든 카드 추적하기**: **Gift Card Orders** 페이지에서 상태, 잔액, 상세 정보를 확인해요.
- **고객이 기프트 카드를 편하게 사용하게 하기**: 지원되는 결제 화면에서 잔액이 자동으로 표시되고, 잔액이 부족하면 나머지 금액을 결제 수단으로 받아요.

---

## 기프트 카드의 주요 장점

- **유연한 판매 방식**: 전용 결제 화면, 삽입 코드, QR 코드를 쓰거나 기존 결제 화면에 추가할 수 있어요.
- **예약 전달**: 바로 전달하거나 원하는 날짜로 예약할 수 있어요.
- **운영 현황 확인**: **Gift Card Orders**에서 주문, 코드, 금액, 상태를 추적해요.
- **일관된 브랜드 이미지**: 그라데이션을 쓰거나 아트워크를 올려서 카드를 브랜드에 맞춰요.
- **선물 기능 기본 제공**: **Myself**(나에게)와 **Someone Else**(다른 사람에게) 흐름이 있어서, 다른 사람에게 선물하고 전달일을 예약하기 쉬워요.
- **간편한 사용**: 받는 사람은 지원되는 결제 화면에서 코드나 링크로 바로 사용할 수 있어요.

## 기프트 카드를 쓰기 전에 준비할 것

- 계정에서 **결제 > 기프트 카드**에 접근할 수 있어야 해요.
- 기프트 카드 상품을 1개 이상 만들어 두어야 해요.
- 기프트 카드를 사용할 수 있는 활성 결제 화면(폼, 퍼널, 결제 링크, 인보이스, 스토어, 캘린더 등)이 있어야 해요.
- (선택) 기프트 카드 브랜딩에 쓸 아트워크와 이용 약관을 준비해요.

## 기프트 카드 상품 만들기

#### 1단계: 기프트 카드로 이동하기

왼쪽 메뉴에서 **결제**를 클릭하세요. 상단 메뉴에서 **기프트 카드**를 클릭하면 기프트 카드 대시보드가 열려요.

![기프트 카드 대시보드로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059743397/original/KwY56sj5jUXMOc_MDBKuivCtgubSPB4xpw.jpeg?1764703978)

#### 2단계: 기프트 카드 만들기

파란색 **+ 기프트 카드 만들기** 버튼을 클릭하세요. 처음 사용할 때는 카드를 만드는 옵션만 보여요. 첫 기프트 카드 상품을 만들고 나면 주문, 판매·보내기 옵션 등 다른 항목이 나타나요.

![기프트 카드 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059746397/original/3_s4qQtEqYpduNe64j44eCsV717VbFnqtg.png?1764709447)

#### 3단계: 상세 정보 입력하기

**기본 정보**를 입력하세요. 주요 항목은 다음과 같고, 이 외에도 더 있어요.

- **이름 및 설명**
- **Terms & Conditions**(이용 약관)
- 기프트 카드 상품의 만료일 (이 상품의 모든 기프트 카드 주문에 적용돼요)
- 사용 방법 안내 URL

![기본 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059746470/original/p31AcDEMX2FmCtIG6L2-9-xf3ukhs5wsPA.jpeg?1764709621)

#### 4단계: 기프트 카드 디자인 꾸미기

브랜드에 어울리게 카드 모양을 정하세요. 방법은 두 가지예요.

- **Create a Gradient**(그라데이션 만들기): 브랜드에 맞는 색상과 그라데이션 스타일·방향을 골라요.

  ![그라데이션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059746632/original/zy941ahel2IEjOyCpvUmPUYsZt1hUkigOQ.jpeg?1764710085)
- **커스텀 아트워크 업로드**: 브랜드에 맞는 고해상도 이미지(PNG, JPG 등)를 올려요.

  ![커스텀 아트워크 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059746674/original/0kewnxsutJzKU8V5wkd7xg-Dm-WV60Erqw.jpeg?1764710168)

#### 5단계: 금액, 세금, 카테고리 설정하기

- 금액 단위를 1개 이상 추가해요. (예: $25, $50, $100)
- 수량(재고)을 설정해요.
- (선택) 자동 세금을 켜요.
- (선택) 프로모션을 필터링하고 리포트를 볼 때 쓸 카테고리를 지정해요.

{% hint style="info" %}
금액 단위마다 재고를 따로 정하는 기능은 아직 지원되지 않아요. 재고를 정하면 금액 단위마다 각각 적용돼요. 예를 들어 수량이 100이고 금액 단위가 2개라면, 금액 단위마다 100개씩 총 200장이 돼요.
{% endhint %}

![금액, 세금, 카테고리 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059746723/original/uC6glt04uVaBVn07d3Rk1eYHAT30X5l12g.jpeg?1764710304)

#### 6단계: 검토하고 저장하기

요약과 미리보기를 확인하세요. 모두 맞다면 **기프트 카드 만들기**를 클릭해 마무리해요.

![요약 검토 후 기프트 카드 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059746744/original/aiK6EHe7qM4FmpMagvEXNCdpcZZboX66cQ.jpeg?1764710355)

### 기프트 카드 편집·보관·비활성화하기

기프트 카드 상품은 언제든 편집하거나 보관하거나 비활성화할 수 있어요.

- **편집**: 금액 단위, 수량(재고), 약관, 만료일, 카테고리, 세금 설정을 수정해요. 변경 내용은 앞으로 발행하는 카드에 적용돼요.

  ![기프트 카드 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059748723/original/vD3xJYhtRszHu11M04nC30wxCKMIeyHzAg.png?1764715237)
- **삭제**: 더 이상 쓰지 않는 기프트 카드 상품을 보관해요.

  ![기프트 카드 삭제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059748745/original/1klQBsXDvLjlCL_ouUbe27VyBKm3dnhnRQ.png?1764715302)
- **비활성화**: 비활성화하면 **판매**와 **보내기** 작업을 쓸 수 없어요. 전용 결제 링크와, 이 기프트 카드를 상품으로 추가한 스토어는 즉시 작동하지 않아요. 그 밖의 결제 화면에 상품으로 추가해 둔 경우에는 직접 제거하기 전까지 계속 판매돼요.

  ![기프트 카드 비활성화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059748731/original/htdTxdPTOykic4Uxtzei-ctBXTQGaFXMUg.png?1764715259)
- **활성화**: 기프트 카드 상품의 판매와 보내기를 다시 켜요. 기존 결제 화면에서 상품을 제거했다면 필요한 곳에 다시 추가하세요.

  ![기프트 카드 활성화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059748765/original/XdRR0YSK3KLHLXDHZ_Yiah1brTqFQoEA0w.png?1764715334)

## 기프트 카드 판매하기

기프트 카드는 전용 결제 화면에서 판매할 수 있어요. 기존에 쓰던 판매 경로(퍼널, 폼, 스토어, 웹사이트, 결제 링크, 인보이스, 캘린더)에 추가해서 팔 수도 있어요. 고객이 평소 구매하는 곳 어디서든 기프트 카드를 판매할 수 있어요.

고객이 구매를 완료하면 하이퍼클래스가 기프트 카드 주문을 만들어요. 그리고 결제 화면에서 고객이 고른 전달 방식(바로 전달 또는 예약 전달)에 따라 기프트 카드를 전달해요.

{% hint style="warning" %}
**중요**: 기프트 카드는 QR 코드와 기존 하이퍼클래스 결제 화면으로도 판매할 수 있어요. 여러 판매 방법과 방법별 전달 방식을 자세히 알고 싶다면 「기프트 카드 판매 방법(How to Sell Gift Cards)」 문서를 참고하세요.
{% endhint %}

### 전용 결제 화면으로 기프트 카드 판매하기

전용 결제 화면에서 기프트 카드를 판매하는 순서예요.

#### 1단계: 기프트 카드로 이동하기

왼쪽 메뉴에서 **결제**를 클릭하세요. 상단 메뉴에서 **기프트 카드**를 클릭하면 기프트 카드 대시보드가 열려요.

![기프트 카드 대시보드로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059743397/original/KwY56sj5jUXMOc_MDBKuivCtgubSPB4xpw.jpeg?1764703978)

#### 2단계: 기프트 카드 고르기

전용 결제 링크를 열고 싶은 카드를 찾으세요. 기프트 카드 타일에서 **판매**를 클릭하세요.

![기프트 카드 타일의 판매 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059743528/original/Kbns5kMT0R0_z-MD-yL0gfqu4UTPXCm6EQ.png?1764704005)

#### 3단계: 전용 결제 화면 공유하기

전용 결제 화면은 여러 방법으로 공유할 수 있어요.

- **결제 링크 복사하기**: **복사** 아이콘을 클릭해 **라이브 모드 결제 링크**를 복사하세요. 이 링크를 고객에게 공유하면 고객이 기프트 카드를 구매할 수 있어요.

  ![라이브 모드 결제 링크 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059743575/original/JIUq3St7m2YyMPz92xc7owIkaUt7cCNIfA.png?1764704124)
- **삽입 코드 복사하기**: **복사** 버튼을 클릭해 삽입 코드를 복사하세요. 이 코드를 쓰면 외부 웹페이지 어디에든 전용 기프트 카드 결제 화면을 삽입할 수 있어요.

  ![삽입 코드 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059743590/original/EvMEcU2J2_owDUEBM_MEgNYUUoIo5_y-JQ.png?1764704168)

### 전용 결제 화면에서 고객이 겪는 과정

전용 결제 화면에서 기프트 카드를 구매할 때 구매자가 거치는 흐름이에요.

#### 1단계: 금액 단위 선택

구매자가 선택할 수 있는 금액 중 하나를 골라요. (예: $10, $25, $50, $100)

![금액 단위 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059744101/original/NHiEq61v1kgUCAZO7z2yt2ggYdwmv5_I9Q.png?1764705089)

#### 2단계: 기프트 카드를 받을 사람 선택

구매자가 **Myself**(나에게) 또는 **Someone Else**(다른 사람에게) 중에서 받을 사람을 골라요.

- **다른 사람에게 선물하는 경우**: 결제 화면에서 받는 사람의 이름과 이메일, 보내는 사람의 이름과 이메일을 입력받아요.

  ![다른 사람에게 선물하는 경우의 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059744145/original/-SEp_FfXP6nTDr6lbEmTFjzoEemqUB0qUA.png?1764705189)
- **나에게 선물하는 경우**: 결제 화면에서 구매자의 이름과 이메일을 입력받아요.

  ![나에게 선물하는 경우의 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059744200/original/qoBBbuYn3v1oKVw9LTyL6epAAG7XdousGA.png?1764705258)

#### 3단계: 배송일 추가

**Deliver Now**(지금 전달)를 고르면 바로 전달돼요. **나중에 예약**을 고르면 날짜를 정할 수 있어요. 시간 선택이 보이면 시간도 정해요.

받는 사람에게 남길 메시지는 선택으로 입력할 수 있어요.

라이브 모드 기프트 카드는 라이브 결제 화면에서, 테스트 모드 기프트 카드는 테스트 결제 화면에서만 사용할 수 있어요. 반대로는 사용할 수 없어요. 기프트 카드 테스트 모드에 대한 자세한 내용은 관련 문서를 참고하세요.
{% endhint %}

#### 4단계: 결제 및 확인

구매자가 사용할 수 있는 결제 수단을 고르고 **결제**를 클릭해요.

결제가 확인되면 구매자는 이 화면에서 기프트 카드를 다운로드할 수 있어요. 다른 사람에게 선물한 경우에는 받는 사람이 정해진 시간(바로 또는 예약한 날짜)에 이메일로 기프트 카드를 받아요.

## 결제 없이 기프트 카드 보내기

기프트 카드 보내기를 쓰면 구매나 결제 없이 원하는 고객에게 바로 기프트 카드를 발행할 수 있어요.

기프트 카드를 보내면 **일회성 선불 크레딧**이 만들어져요. 이 크레딧은 이메일, SMS, PDF, QR 코드 중 하나로 받는 사람에게 전달돼요. 연락처가 따로 구매할 필요는 없어요. 보상 제공, 단골 감사 선물, VIP 혜택, 내부 테스트에 알맞아요. 크레딧은 기프트 카드를 받는 하이퍼클래스 결제 화면에서 사용해요. 현재 보내기 흐름은 **라이브 모드**에서만 작동해요. 그래서 실제로 쓸 수 있는 기프트 카드만 전달돼요.

{% hint style="warning" %}
**중요**: 기프트 카드를 보내는 여러 방법과 방법별 전달 방식을 자세히 알고 싶다면 「기프트 카드 보내기 방법(How to Send Gift Cards)」 문서를 참고하세요.
{% endhint %}

#### 1단계: 기프트 카드로 이동하기

## 기프트 카드 주문 추적하기

판매했거나 보낸 모든 기프트 카드는 **결제 > 기프트 카드 > Gift Card Orders**에 표시돼요.

**Gift Card Orders** 페이지에는 판매하거나 보낸 기프트 카드가 상태, 잔액, 필터, 연락처 정보와 함께 나와요. 이 페이지의 카드는 모두 클릭할 수 있고, 클릭하면 해당 주문의 상세 페이지가 열려요.

{% hint style="info" %}
일반 **결제 > 주문** 페이지에는 결제가 완료된 주문만 표시돼요. 결제 없이 바로 보낸 기프트 카드는 여기에 나타나지 않아요. 발행했거나 구매된 모든 카드는 **Gift Card Orders** 페이지에서 한곳에서 확인하세요.
{% endhint %}

![Gift Card Orders 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058727985/original/MiqnSulsGtG2CoQfRGkeU_jICA8dlJpXFQ.png?1763547579)

### 기프트 카드 대시보드

기프트 카드 대시보드에서는 전체 기프트 카드 성과를 한눈에 볼 수 있어요. 다음과 같은 주요 지표를 확인해요.

- **발행된 총 기프트 카드** (판매 + 보냄)
- 선택한 기간 동안의 **발행된 기프트 카드 총액**
- 선택한 기간 동안의 **Average Gift Card Order Value**(평균 기프트 카드 주문 금액)
- 선택한 기간에 기프트 카드를 구매했거나 받은 **Number of Unique Customers**(고유 고객 수)
- 발행된 **Top Denominations**(상위 금액 단위): 가장 인기 있는 금액 단위와 상위 5개 차트

이 정보로 고객의 행동을 파악하고, 기프트 카드 이용 현황을 추적하고, 재고나 프로모션 전략을 더 잘 세울 수 있어요.

{% hint style="info" %}
지표별 설명, 차트 유형, 데이터를 해석하는 방법은 「기프트 카드 성과 추적하기(분석 및 지표 추적)」 문서(How to Track Gift Card Performance (Analytics and Metric tracking))에서 자세히 볼 수 있어요.
{% endhint %}

![기프트 카드 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058727853/original/57IAR4a0G5LaEr8nS129MPNLl6qPUy8qCA.png?1763547502)

### 기프트 카드 주문 상세 페이지

**기프트 카드 주문 상세** 페이지는 계정 안의 모든 기프트 카드에 대한 기준이 되는 정보 창구예요. 기프트 카드 주문마다 다음 정보를 볼 수 있어요.

- 구매자 정보
- **수신자 정보**
- 금액 단위
- 만료일 (기프트 카드 상품의 만료일과 같아요)
- **남은 잔액**
- 상태 (예약됨, 활성, 비활성)
- 숨겨진 기프트 카드 번호 (주문 상세 페이지 안에서 볼 수 있어요)
- 배송 방법과 배송 일정
- 거래 참조 정보 (결제된 카드)

기프트 카드 추적에 대한 자세한 내용은 「기프트 카드 성과 추적하기(분석 및 지표 추적)」 문서(How to Track Gift Card Performance (Analytics and Metric tracking))를 참고하세요.

## 고객이 기프트 카드를 사용하는 방법

1. 고객이 지원되는 결제 화면으로 이동해요. (폼, 퍼널, 결제 링크, 인보이스, 스토어, 캘린더, 서비스 V2(예약 시에만) 등)
2. 기프트 카드 입력란에 **기프트 카드 코드**를 입력해요.
3. 기프트 카드가 적용되고 다음 내용이 표시돼요.

   - **Gift card applied**(적용된 기프트 카드 금액): 기프트 카드에서 사용된 금액
   - **Remaining gift card balance**(기프트 카드 남은 잔액): 사용 후 기프트 카드에 남은 금액
   - **Amount left to pay**(남은 결제 금액): 기프트 카드로 충당되지 않아 더 결제해야 하는 금액 (추가 결제가 필요할 때만 표시돼요)

{% hint style="info" %}
멤버십, 기부 폼, 대여에서는 아직 기프트 카드를 지원하지 않아요. 서비스 V1은 앞으로도 지원하지 않을 예정이에요.
{% endhint %}

{% hint style="info" %}
기프트 카드 사용은 Stripe, NMI, Authorize, Square에서 완전히 지원돼요. PayPal, Adyen, 사용자 지정 결제 업체는 지원이 제한적이에요. 이런 업체에서는 기프트 카드 잔액이 주문/인보이스 총액을 전부 충당하고, 주문/인보이스에 반복 결제나 구독 상품이 없을 때만 결제 화면에서 기프트 카드를 사용할 수 있어요. 기프트 카드로 총액을 다 충당하지 못하거나 총액에 반복 상품이 포함되어 있으면, 고객은 그 구매에 기프트 카드를 사용할 수 없어요.
{% endhint %}

![기프트 카드 사용 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069536421/original/PMdD08Le4KICncAfPq3LVJlrRJxPH7YH8g.png?1776701677)

## 자주 묻는 질문

### Gift Card Orders와 일반 주문 페이지는 어떻게 달라요?
**결제 > 기프트 카드** 안의 **Gift Card Orders**에는 발행했거나 구매된 모든 카드가 기록돼요. 일반 **주문** 페이지에는 결제가 이루어진 거래만 기록돼요.

### 어떤 결제 업체에서 기프트 카드를 사용할 수 있나요?
기프트 카드 사용은 Stripe, NMI, Authorize, Square에서 완전히 지원돼요. PayPal, Adyen, 사용자 지정 결제 업체는 지원이 제한적이에요. 이런 업체에서는 기프트 카드 잔액이 주문/인보이스 총액을 전부 충당하고, 주문/인보이스에 반복 결제나 구독 상품이 없을 때만 결제 화면에서 기프트 카드를 사용할 수 있어요. 기프트 카드로 일부만 결제하거나 반복 상품을 구매할 때 기프트 카드를 쓰는 기능은 PayPal, Adyen, 사용자 지정 결제 업체에서 아직 제공되지 않아요.

### 주문마다 만료일을 다르게 정할 수 있나요?
아직 안 돼요. 한 상품의 모든 기프트 카드 주문은 상품의 만료일을 똑같이 따라요. 주문별 유효기간은 이후 업데이트에서 제공될 예정이에요.

### 금액 단위가 여러 개일 때 재고는 어떻게 계산되나요?
재고는 금액 단위마다 적용돼요. 예를 들어 금액 단위 3개에 각각 재고가 50이면 총 150장이에요.

### 기프트 카드를 사용할 수 있는 곳을 제한할 수 있나요?
현재 버전(MVP) 기준으로, 기프트 카드를 구매하는 경우를 제외한 모든 상품에서 기프트 카드를 사용할 수 있어요. 상품 단위, 변형 단위 같은 세부 제어는 곧 제공될 예정이에요.

### 고객이 결제를 시작하지 않고 잔액을 확인할 수 있나요?
아직 안 돼요. 지금은 지원되는 결제 화면에서 카드 번호를 입력하면 잔액이 표시돼요. 잔액 확인 전용 링크는 곧 제공될 예정이에요.

### 기프트 카드로 기프트 카드를 살 수 있나요?
아직 안 돼요. 지금은 결제 화면에 기프트 카드 상품을 추가한 뒤 다른 기프트 카드를 사용해 결제할 수 없어요. 기프트 카드로 다른 기프트 카드를 구매하는 것을 허용할지 비즈니스가 선택하는 옵션은 곧 제공될 예정이에요.

### 서브 계정에서 결제 화면에 기프트 카드 사용 옵션은 언제부터 보이나요?
기프트 카드 상품을 만든 뒤 기프트 카드 주문이 한 건이라도 생성되면 사용 옵션이 나타나요. 주문 상태는 상관없어요. 지금은 기프트 카드 사용 기능을 끄는 방법이 없어요. 이 기능은 개발 중이며 곧 제공될 예정이에요.

### 어떤 결제 화면에서 기프트 카드 사용 옵션을 볼 수 있나요?
지원되는 결제 화면은 폼(상품 판매), 퍼널, 결제 링크, 인보이스, 스토어, 캘린더, 서비스 V2예요.

멤버십, 기부 폼, 대여에서는 아직 기프트 카드를 지원하지 않아요. 서비스 V1은 앞으로도 지원하지 않을 예정이에요.
