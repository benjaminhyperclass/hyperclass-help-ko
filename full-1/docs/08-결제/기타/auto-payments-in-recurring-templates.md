# 반복 템플릿의 자동 결제

정기 인보이스의 납부 기한마다 고객의 카드로 자동 결제가 이뤄지게 하는 기능이에요. 사용할 수 있는 카드 종류, 결제 실패 시 처리 방식, 설정 방법, 알림을 맞춤 설정하는 위치를 안내해요.

{% hint style="warning" %}
자동 결제 동작은 정기 인보이스를 만든 시점, 다음 인보이스가 이미 생성되었는지, 유효한 카드가 있는지에 따라 달라질 수 있어요. 자동 결제를 켠 뒤에는 다음 예정 일정과 선택한 결제 수단을 항상 확인하세요.
{% endhint %}

## 반복 템플릿의 자동 결제란?

자동 결제는 정기 인보이스의 납부 기한이 될 때마다 고객이 저장했거나 입력한 카드로 자동 결제하는 기능이에요. 회차마다 고객이 직접 결제하기를 기다릴 필요 없이, 하이퍼클래스가 선택한 카드로 일정에 맞춰 결제를 처리해요.

자동 결제에는 아래 세 가지 카드 중 하나를 쓸 수 있어요. 어떤 카드를 고르느냐에 따라 자동 결제가 시작되는 시점과 이후 인보이스 처리 방식이 달라져요.

### 사전 준비

자동 결제를 켜기 전에, 앞으로의 정기 인보이스 날짜에 결제가 제대로 이뤄질 수 있는지 확인하세요.

- 정기 인보이스를 이미 만들었거나 만드는 중이어야 해요.
- 지원되는 결제 게이트웨이가 연결되어 있어야 해요.
- 앞으로의 정기 인보이스를 자동으로 결제하려면 고객의 유효한 카드가 있어야 해요.
- 자동 결제는 정기 결제에 적용되므로, 다음 인보이스가 생성되기 전에 확인하세요.

### 고객 카드

- 고객이 일정 안의 인보이스 중 아무 인보이스든 처음 결제할 때 사용한 카드를 써요.
- 자동 결제는 그 첫 결제가 성공한 뒤 다음 회차부터 시작돼요.
- 예: 첫 결제가 4번째 인보이스에서 이뤄졌다면, 5번째 인보이스부터 자동 결제돼요(5번째 인보이스가 예정되어 있는 경우).

### 저장된 카드

- 고객 프로필에 이미 등록된 카드를 써요.
- 일정의 첫 회차부터 자동 결제돼요. 처음에 직접 결제하지 않아도 돼요.
- 결제가 실패하면 서브 계정 사용자와 고객 모두에게 알림이 가요.

### 새 카드

- 일정을 만들거나 편집할 때 새 카드를 추가해요. 추가한 카드는 이후 결제에 쓰도록 저장돼요.
- 카드를 저장한 뒤의 첫 회차부터 자동 결제돼요.
- 카드를 추가할 때 소액의 승인·인증 결제가 발생할 수 있어요.

{% hint style="info" %}
등록된 카드는 연락처 레코드를 연 다음 **결제 > 등록된 카드**에서 관리해요. 카드 끝자리와 만료일만 보여요.
{% endhint %}

## 자동 결제의 장점

장점을 알아 두면 언제 자동 결제를 켜고 어떤 카드를 고를지 정하기 쉬워요.

- 빠른 수금: 납부 기한에 자동으로 결제가 처리되어 지연이 줄어요.
- 관리 부담 감소: 회차마다 직접 독촉하고 대조하는 일이 줄어요.
- 예측 가능한 현금 흐름: 청구 주기마다 수입 시점이 더 일정해져요.
- 유연한 카드 선택: 설정할 때 고객 카드, 저장된 카드, 새 카드 중에서 고를 수 있어요.
- 고객 경험 개선: 선택형 리마인더와 결제 성공 알림으로 고객이 진행 상황을 알 수 있어요.

## 자동 결제 동작 방식 (새 일정 vs. 기존 일정)

자동 결제 시점은 이미 진행 중인 정기 일정에 나중에 추가하는지, 일정을 만들 때 설정하는지에 따라 달라요.

자동 결제는 정해 둔 청구 일정에 따라 앞으로의 정기 인보이스 회차를 고객의 카드로 자동 결제해요. 자동 결제를 켠 뒤에는 어떤 카드가 사용되는지, 다음 인보이스가 아직 예정 상태인지 이미 생성되었는지 확인하는 게 중요해요.

### 기존 정기 일정에서 자동 결제 켜기

- 순서상 다음 인보이스는 한 번 직접 결제해야 해요.
- 그 결제가 성공하면 이후 모든 인보이스는 선택한 카드로 자동 결제돼요.
- 이미 만들어진 인보이스의 날짜는 바꿀 수 없어요. 예를 들어 12월 1일에 생성된 인보이스의 날짜를 12월 3일로 바꿀 수 없어요.

<!-- 검토 필요: 원문 내용이 서로 다름 -->

{% hint style="info" %}
자동 결제를 켜도 이미 생성된 인보이스가 항상 소급해서 바뀌는 것은 아니에요. 일반적으로 결제 관련 변경은 이전에 만든 인보이스가 아니라 앞으로 생성될 인보이스에 적용돼요.
{% endhint %}

### 새 정기 일정 만들기

- 저장된 카드가 있는 경우: 첫 인보이스부터 자동 결제되고, 이후 인보이스도 모두 자동 결제돼요.
- 저장된 카드가 없는 경우: 첫 인보이스는 직접 결제해야 해요. 그 결제 후 카드가 저장되고(해당되는 경우), 이후 인보이스는 자동 결제돼요.

아래 표로 설정에 따라 첫 인보이스가 자동 결제되는지, 직접 결제해야 하는지 빠르게 확인하세요.

| 시나리오 | 첫 인보이스 | 이후 인보이스 | 참고 |
| --- | --- | --- | --- |
| 기존 정기 일정에서 자동 결제를 켠 경우 | 수동 | 자동 | 직접 결제할 때 카드(고객 카드)가 저장되어 이후 자동 결제에 쓰여요. |
| 새 일정 + 등록된 저장된 카드 있음 | 자동 | 자동 | 첫 회차부터 바로 결제돼요. |
| 새 일정 + 저장된 카드 없음 | 수동 | 자동 | 고객이 처음 결제에 성공하면 카드가 저장되어 이후 자동 결제에 쓰여요. |

## 알림과 리마인더

리마인더, 성공 알림, 실패 알림으로 팀과 고객에게 상황을 알릴 수 있어요. 일부 템플릿은 맞춤 설정도 가능해요.

- 고객이 받는 알림:
  - 리마인더 설정에 따른 결제 예정 알림(선택)
  - 결제 성공 알림
  - 결제 실패 알림

- 서브 계정 사용자가 받는 알림:
  - 결제 성공 알림
  - 결제 실패 알림
  - 자동 결제 전에 자식 인보이스(정기 일정에서 생성된 개별 인보이스)가 편집되었다는 알림(해당 인보이스의 자동 결제는 일시 중지돼요)

- 인보이스 알림 맞춤 설정: 브랜드에 맞게 메시지를 바꾸려면 [인보이스 이메일·SMS 알림 맞춤 설정](../customize-email-and-sms-notifications-for-invoicing.md) 문서를 참고하세요.

- 자동 리마인더: 인보이스 설정에서 리마인더를 여러 시점에 맞춰 설정할 수 있어요. 자세한 내용은 [자동 인보이스 리마인더로 결제를 간편하게 받는 방법](../시작하기/how-to-streamline-payments-with-automated-invoice-reminders.md) 문서에 있어요.

## 결제 실패와 재시도

하이퍼클래스가 실패한 자동 결제를 어떻게 재시도하는지, 그리고 담당자나 고객이 할 수 있는 일을 알아보세요.

1. 자동 결제가 실패하면 고객과 서브 계정 사용자 모두에게 알림이 가요.
2. 고객은 다음 중 하나를 할 수 있어요.
   - 같은 카드로 직접 결제해요.
   - 새 카드로 결제해요. 새 카드는 이 일정의 이후 자동 결제에 기본 카드로 쓰여요.
3. 시스템이 24시간 간격으로 두 번 더 재시도해요.
4. 그래도 결제되지 않으면:
   - 해당 인보이스에 대한 자동 시도는 더 이상 없어요.
   - 인보이스는 직접 결제해야 해요.

## 일정 편집과 자동 결제 일시 중지

생성된 자식 인보이스를 일부 수정하면 의도하지 않은 결제를 막기 위해 해당 인보이스의 자동 결제가 일시 중지돼요.

- 생성된 자식 인보이스를 결제 시각 전에 편집하면 그 인보이스의 자동 결제만 일시 중지돼요.
- 편집한 정기 인보이스에서 자동 결제가 켜져 있으면, 하이퍼클래스가 자동 결제 변경에 대한 이메일 알림도 보내요.
- 결제를 다시 진행하려면 내용이 맞는지 확인하고 일정이 그대로 진행되게 두세요. 이후 회차는 편집하지 않는 한 영향을 받지 않아요.

## 자동 결제 설정하기

정기 인보이스 편집 화면에서 자동 결제를 켜고 끄는 단계예요. 각 스크린샷에서 강조된 부분을 보고 알맞은 컨트롤을 클릭하세요.

### 진행 중인 일정에서 자동 결제 켜기

정기 인보이스 목록으로 이동해요. **결제 > 인보이스 & 견적서 > 정기 인보이스**로 이동한 뒤, 업데이트할 일정을 열어요.

![정기 인보이스 목록으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066021956/original/T4jXoElWy1lXP2-3zo4wtV8Slqex3E4rsw.gif?1772465470)

### 새 일정 만들기 또는 기존 일정 열기

다음 중 하나를 할 수 있어요.

- 새 일정 만들기: **신규 > 새 정기 인보이스**를 클릭해요.
- 기존 일정 열기: 목록에서 일정을 클릭하면 편집할 수 있어요.

![새 일정 만들기 또는 기존 일정 열기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066022193/original/mIqhKhP_Ro6dOXVY6fBp7DD9s-FlQXC89A.png?1772465559)

### 자동 결제 관리

자동 결제 설정을 열어요. 편집 화면 오른쪽 위의 ⋮(점 세 개) 메뉴를 클릭한 다음 **자동 결제 관리**를 선택해요.

![⋮ 메뉴에서 자동 결제 관리를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066021021/original/q7O6b9dTZILk4iRosVQLyj0YWaDQIJsK7A.png?1772465027)

### 자동 결제를 켜고 카드 종류 선택하기

**자동 결제 켜기**를 켠 다음 **고객 카드**, **저장된 카드**, **새 카드** 중 하나를 선택하고 **저장**을 클릭해요.

![자동 결제 켜기와 카드 종류 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066022283/original/ba9R-wBTm6CpVGA9HlHr7xYu6SwqgfSI5g.png?1772465612)

### 이후 인보이스의 자동 결제 끄기

1. 같은 일정을 열고 ⋮ 메뉴 > **자동 결제 관리**를 클릭해요.
2. 창에서 **자동 결제 켜기**를 **끄기** 상태로 바꾸고 **저장**을 클릭해요.
3. 다음 인보이스 회차부터 자동 결제가 중단돼요.

![자동 결제 켜기를 끄고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060974618/original/0Q6CA1GUBLwOiIvf_N8H-qVE6Z1xog5WGQ.png?1766130297)

### 자동 결제가 켜졌는지 확인하기

정기 인보이스 설정을 저장한 뒤 다음을 확인하세요.

1. 정기 인보이스 설정에 자동 결제가 켜진 것으로 표시돼요.
2. 원하는 결제 수단이 선택되어 있어요.
3. 다음 예정 회차가 이전 설정으로 이미 지나갔거나 생성되지 않았어요.
4. 고객에게 앞으로의 결제에 쓸 수 있는 유효한 카드가 있어요.

## 자동 결제 문제 해결

자동 결제가 예상대로 실행되지 않는다면 설정을 바꾸기 전에 아래 원인을 먼저 확인하세요.

- 자동 결제를 켜기 전에 다음 인보이스가 이미 생성되었어요.
- 고객에게 유효한 카드가 없어요.
- 이전 회차가 이미 생성된 뒤에 정기 인보이스를 수정했어요.
- 자동 결제가 되도록 결제 설정이 구성되어 있지 않아요.
- 결제가 정상적으로 완료되지 않아 인보이스를 직접 확인해야 해요.

## 자주 묻는 질문

### 자동 결제 관리 옵션은 어디에 있나요?

정기 인보이스를 열고 오른쪽 위의 ⋮ 메뉴 > **자동 결제 관리**를 클릭하세요. 여기서 자동 결제를 켜고 끄거나 카드 종류를 고를 수 있어요.

### 첫 인보이스는 항상 자동으로 결제되나요?

항상 그런 것은 아니에요. 일정을 만들 때 등록된 카드가 없으면 첫 인보이스는 직접 결제해야 하고, 그 결제가 성공한 뒤의 인보이스부터 자동 결제돼요. **저장된 카드**가 있으면 첫 인보이스부터 자동 결제돼요.

### 자동 결제에는 어떤 결제 수단을 쓸 수 있나요?

카드 결제만 가능해요. 현금, 계좌 이체 같은 수동 결제 방식은 자동으로 결제되지 않아요.

### 카드가 거절되면 어떻게 되나요?

하이퍼클래스가 고객과 서브 계정 사용자에게 알리고, 24시간 간격으로 두 번 재시도한 뒤 자동 시도를 멈춰요. 이후에는 새 카드로 직접 결제를 받을 수 있어요.

### 앞으로의 자동 결제에 쓰는 카드를 바꿀 수 있나요?

네. 고객 프로필에서 다른 카드를 추가하거나 선택하세요. 다음 자동 결제부터 바뀐 카드가 사용돼요.

### 생성된 인보이스를 편집하면 자동 결제에 영향이 있나요?

자식 인보이스를 결제 시각 전에 편집하면 그 인보이스의 자동 결제만 일시 중지돼요. 이후 회차는 일정대로 계속 진행돼요.

### 결제 이메일을 브랜드에 맞게 바꿀 수 있나요?

네. 인보이스 알림 설정에서 제목, 본문, 브랜딩을 맞춤 설정할 수 있어요. 자세한 방법은 [인보이스 이메일·SMS 알림 맞춤 설정](../customize-email-and-sms-notifications-for-invoicing.md) 문서를 참고하세요.

### 결제 실패 후속 조치를 자동화하려면 어떻게 하나요?

**Invoice**(인보이스), **Payment Received**(결제 완료) 같은 워크플로우 트리거를 사용하면 팀에 알리거나, 연락처에 태그를 달거나, 결제 회수 메시지를 보낼 수 있어요.

### 자동 결제가 바로 다음 인보이스부터 시작되지 않은 이유는 뭔가요?

자동 결제를 켠 시점과 다음 인보이스가 이미 생성되었는지에 따라, 자동 결제는 앞으로 생성될 정기 인보이스 회차에만 적용될 수 있어요. 자동 결제를 켠 뒤에는 다음 예정 회차를 확인하고 선택한 결제 수단이 맞는지 점검하세요.
