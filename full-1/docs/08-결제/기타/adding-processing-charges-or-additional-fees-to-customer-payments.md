# 결제에 처리 요금·추가 수수료 붙이기

하이퍼클래스의 처리 요금 기능을 쓰면 처리 요금, 편의 수수료 같은 추가 수수료를 고객 결제에 붙일 수 있어요. 이 문서에서는 수수료를 설정하고, 고객에게 보이는 이름을 정하고, 적용 결과를 확인하는 방법을 안내해요.

{% hint style="warning" %}
중요: 할증료(surcharge) 부과와 관련된 법률을 지킬 책임은 사용자에게 있어요. 일부 지역에서는 할증료 부과가 금지되어 있을 수 있어요.
{% endhint %}

## 처리 요금 기능이란?

처리 요금 기능을 쓰면 처리 요금, 편의 수수료, 기타 요금 같은 추가 수수료를 고객 결제에 자동으로 붙일 수 있어요. 결제 처리에 드는 비용을 보전하고, 결제나 인보이스 단계에서 고객에게 수수료를 항목별로 투명하게 보여 줄 때 유용해요.

처리 요금은 결제 처리 비용이나 기타 서비스 비용을 충당하려고 고객의 거래 총액에 더하는 추가 수수료예요. 고객은 결제 화면에서 이 요금을 볼 수 있고, 결제 영수증에도 반영돼요.

처리 요금은 아래 금액을 기준으로 계산해요. 이 금액이 실제로 결제 제공업체를 통해 처리되는 금액이에요.

- (소계 - 할인 + 세금)
- 이커머스는 (소계 - 할인 + 세금 + 배송비)

수수료는 소수점 둘째 자리까지 반올림한 뒤 총액에 더해요.

이 기능을 켜면 수수료 비율을 정하고, 고객에게 보이는 이름을 바꾸고, 수수료를 적용할 결제 채널(인보이스, 퍼널, 결제 링크, 폼, 설문)을 고를 수 있어요. 수수료는 실제 거래 금액을 기준으로 계산해요.

{% hint style="warning" %}

5. 설문
6. 결제 링크
7. 서비스

## 꼭 알아야 할 동작 방식

- 초안 인보이스는 기능을 켠 뒤에 편집해야 처리 요금이 반영돼요.
- 이커머스 업셀 상품에는 적용되지 않아요.
- 수수료는 소수점 둘째 자리까지 반올림한 뒤 총액에 더해요.
- 기능을 켜기 전에 이미 발송한 인보이스나 이미 접수된 주문에는 영향이 없어요.
- 기능을 꺼도 기존 인보이스나 주문에 붙은 요금이 소급해서 사라지지는 않아요. 다만 해당 문서를 아직 편집할 수 있다면 달라질 수 있어요.
- 처리 요금은 결제 화면에 별도 항목으로 표시되고, 고객에게 보이는 최종 금액에 포함돼요.
- 모바일 앱에서 결제하는 인보이스에는 처리 요금이 적용되지 않아요. 해당 기능은 출시 예정이에요.

## 처리 요금 설정하기

처리 요금을 설정해 두면 추가 수수료를 효율적으로 관리하고, 고객에게도 명확하게 안내할 수 있어요. 아래 순서대로 설정하세요.

### 1단계: 결제 설정 열기

1. 서브 계정에 로그인하세요.
2. **결제 > 설정**으로 이동하세요.
3. 아래로 스크롤해 **기타 요금** 섹션을 찾으세요.

![결제 설정의 기타 요금 섹션으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048999917/original/lCASgu57QWlKOhd7HwqOYYGs5GlfQDPyLg.gif?1751035783)

### 2단계: 처리 요금 정하기

1. **처리 요금** 토글을 켜세요.
2. 수수료에 쓸 사용자 지정 이름(레이블)을 입력하세요. 예: 편의 수수료, 처리 요금. 이 이름은 고객의 결제 요약과 영수증에 표시돼요.
3. 적용할 수수료 비율을 입력하세요. 예: 2.5%

![처리 요금 토글과 수수료 이름, 비율을 입력하는 화면](https://jumpshare.com/share/CafDkcwpe00RbbwXFCEz+/Screen+Shot+2025-12-29+at+6.56.56+PM.png)

### 3단계: 처리 요금을 적용할 결제 경로 선택하기

{% hint style="info" %}
참고: 할증료 부과와 관련된 법률을 지킬 책임은 사용자에게 있어요. 일부 지역에서는 할증료 부과가 금지되어 있을 수 있어요.
{% endhint %}

1. 체크박스에서 처리 요금을 적용할 곳을 고르세요.

   - 인보이스 & 견적서
   - 퍼널
   - 이커머스 스토어
   - 결제 링크
   - 폼
   - 설문
2. 필요에 따라 1개 또는 여러 개를 선택하세요.
3. **저장**을 클릭해 설정을 마치세요. 선택한 결제 경로에서는 결제할 때 처리 요금이 자동으로 적용돼요.

![처리 요금을 적용할 결제 경로를 선택하고 저장하는 화면](https://jumpshare.com/share/DIdIKzc4H9pUgDuZBUuJ+/Screen+Shot+2025-12-29+at+7.01.23+PM.png)

## 리포트에서 처리 요금 확인하기

적용된 처리 요금을 항목별로 자세히 볼 수 있어요. 기간, 결제 채널, 사용자 지정 이름으로 필터링하고 결과를 내보내 정산과 분석에 활용하세요.

적용된 처리 요금을 확인하려면 다음과 같이 하세요.

- **Transactions CSV**(거래 내역 CSV) 또는 **Orders CSV**(주문 CSV) 내보내기 파일을 여세요.

![내보내기 파일에서 처리 요금 필드를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049088906/original/fvcJlbxyjXGTZdZRjuUKMIPzsgvlXyifwQ.png?1751289701)

이 필드에서 개별 거래와 주문에 적용된 처리 요금의 상세 내역을 볼 수 있어요.

## 문제 해결: 인보이스에 처리 요금이 표시되지 않아요

1. 인보이스 채널을 확인하세요. **결제 > 설정 > 기타 요금**에서 **인보이스 & 견적서**가 체크되어 있는지, 그리고 **저장**을 클릭했는지 확인하세요.

   ![기타 요금에서 인보이스 & 견적서가 체크된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066104313/original/0jQuU6REHMqmVCryMjEpsJqOXD0m4lRJSQ.png?1772548206)
2. 인보이스에서 어디를 보고 있는지 확인하세요. 인보이스의 처리 요금은 고객이 **결제** 버튼을 클릭한 뒤에 표시돼요. 결제 전 인보이스 미리보기에는 보이지 않을 수 있어요.
3. 이전에 만든 초안 인보이스라면 한 번 편집하세요. 초안 인보이스는 기능을 켠 뒤에 편집해야 처리 요금이 표시돼요.
4. 기능을 켜기 전에 이미 발송한 인보이스는 바뀌지 않아요. 처리 요금을 켜기 전에 이미 발송한 인보이스나 접수된 주문에는 영향이 없어요.
5. 고객이 지원되는 경로에서 결제하는지 확인하세요. 모바일 앱에서 결제하는 인보이스에는 처리 요금이 적용되지 않아요.
6. 간단하게 테스트해 보세요. 기능을 켠 뒤 새 테스트 인보이스를 만들고, 고객처럼 인보이스 링크를 연 다음 **결제**를 클릭해 보세요. 결제 총액에 처리 요금 항목이 나타나는지 확인하면 돼요.

## 자주 묻는 질문

### 결제 채널마다 다른 처리 요금을 설정할 수 있나요?

아직은 할 수 없어요. 지금은 선택한 모든 채널에 같은 수수료가 적용돼요. 채널별 수수료는 앞으로 업데이트할 예정이에요.

### 처리 요금을 끄면 이미 발행한 인보이스에서도 요금이 사라지나요?

아니요. 기능을 끄면 새 인보이스나 주문에만 영향을 줘요. 기존 기록은 편집할 수 있는 경우가 아니라면 수수료가 그대로 남아요.

### 모든 결제 제공업체에서 처리 요금을 쓸 수 있나요?

인보이스 & 견적서는 모든 결제 제공업체에서 쓸 수 있어요. 그 밖의 결제에서는 PayPal과 사용자 지정 결제 제공업체가 지원되지 않아요.

### 처리 요금은 어떻게 계산하나요?

(소계 - 할인 + 세금)을 기준으로 계산해요. 실제로 거래되는 금액이에요.

이커머스는 (소계 - 할인 + 세금 + 배송비)를 기준으로 계산해요.

### 모바일 앱 결제에도 처리 요금을 적용할 수 있나요?

아직은 할 수 없어요. 해당 기능은 출시 예정이에요.

### 고객은 처리 요금을 어디에서 볼 수 있나요?

결제 화면, 인보이스, 거래 영수증에서 별도 항목으로 볼 수 있어요.

### 처리 요금의 이름을 바꿀 수 있나요?

네, 고객에게 표시할 이름을 직접 정할 수 있어요.

### 처리 요금 리포트도 볼 수 있나요?

네, 거래 내역과 주문 내보내기 파일에 수수료 이름과 금액이 포함돼요.
