# 스토어에서 구독형 서비스·반복 결제 상품 판매하기

이커머스 스토어에서 구독형 서비스나 반복 결제 상품을 판매하고, 결제 주기에 맞춰 고객에게 요금을 청구할 수 있어요. 매달 이어지는 매출과 반복 매출을 늘리고 싶을 때 쓰세요.

[동영상](https://www.youtube.com/embed/Zvzq0bVmkR0?&wmode=opaque)

그동안 스토어에서 구독형 상품을 팔기 어렵다는 의견이 많았어요. 이제 구독형 상품을 스토어에 올려 판매할 수 있어요.

## 사용 방법

1. **결제 > 상품**으로 이동하세요.
2. 반복 결제 가격이 있는 상품을 편집하거나 새로 추가하세요. 이때 **온라인 스토어에 포함** 토글을 꼭 켜세요.
3. 페이지 빌더에서 스토어를 열어 보세요. 반복 결제 상품을 지원하도록 화면이 조금 달라진 것을 볼 수 있어요. 필(pill) 색상과 필 텍스트 색상은 원하는 대로 바꿀 수 있어요.

   {% hint style="warning" %}
   이 단계는 중요해요. 반드시 스토어 페이지를 열어 변경된 화면을 확인하세요.
   {% endhint %}

4. 모든 페이지를 저장하고 게시하면 스토어에 반복 결제 상품이 표시돼요.

{% hint style="info" %}
필 색상을 바꾸지 않았더라도 스토어 페이지를 모두 저장하고 게시하세요. 그래야 빌더에서 보던 스타일이 실제 사이트에도 똑같이 적용돼요. 저장하고 게시하지 않으면 실제 사이트가 빌더와 다르게 보여요.
{% endhint %}
