# 인보이스 레이아웃 맞춤 설정

인보이스의 모양과 문구를 브랜드와 업무 방식에 맞게 바꾸는 방법을 알려 드려요. 버튼 색상과 텍스트를 바꾸고, 섹션 이름과 항목 라벨을 수정해서 고객이 믿을 수 있는 브랜드다운 인보이스를 만들 수 있어요.

## 인보이스 레이아웃 맞춤 설정이란?

인보이스 레이아웃 맞춤 설정은 서브 계정 단위로 인보이스의 디자인과 섹션 문구를 바꾸는 기능이에요. 고정된 템플릿 하나만 쓰는 대신 브랜딩, 비즈니스·연락처 섹션, 항목 라벨을 조정해서 브랜드와 업종에 맞는 인보이스를 만들 수 있어요.

## 맞춤 설정의 주요 장점

- 브랜드 일관성: 색상과 문구를 브랜드에 맞춰 깔끔하고 믿음직한 인보이스를 만들 수 있어요.
- 고객이 이해하기 쉬움: 섹션과 라벨 이름을 바꿔서 고객이 한눈에 내용을 알아보게 할 수 있어요.
- 유연성: 필드를 표시하거나 숨기고, **비즈니스 정보**에 커스텀 값을 최대 3개까지 추가해 지역이나 업종에 맞출 수 있어요.
- 효율성: 한 번 편집해 두면 저장한 레이아웃이 인보이스 미리보기와 PDF에 계속 반영돼요.

## 브랜딩 설정

**브랜딩 설정**에서는 결제 버튼의 색상, 테두리, 텍스트를 조정해요. 고객이 인보이스를 처음 볼 때 받는 인상을 정하고, 상황에 맞는 문구(예: "결제"와 "기부")를 쓸 수 있어요.

할 수 있는 일:

- **결제 버튼 색상** (색상 선택기 사용)
- **테두리 색상** (색상 선택기 사용)
- **버튼 텍스트** (예: **결제**를 "기부"로 변경)

![브랜딩 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056925009/original/Fm7WAtJS1zxj6eo4VwfW94n1BJjyfKQJwg.png?1761577739)

## 비즈니스 정보

**비즈니스 정보**는 인보이스를 발행하는 쪽이 누구인지 보여 주는 영역이에요. 필드를 켜고 끄거나 커스텀 값을 추가하면, 복잡해지지 않으면서 지역별로 필요한 정보를 담을 수 있어요.

할 수 있는 일:

- **회사명**, **Phone**(전화번호), **Address**(주소), **Tax IDs**(세금 ID) 같은 기본 필드를 표시하거나 숨겨요.
- 커스텀 값을 최대 3개까지 추가해요(예: 사업자 등록 정보, VAT/GST, 웹사이트).
- 필요에 따라 커스텀 값의 순서를 바꾸거나 제거해요(삭제하면 제거돼요).

{% hint style="info" %}
체크를 해제한 필드는 받는 사람에게 보이지 않아요. 하지만 팀에서는 인보이스를 만들 때 그 필드의 값을 계속 편집할 수 있어요.
{% endhint %}

![비즈니스 정보 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056925491/original/OBfFw5p18L5Qqr-ExrQMWOZE1SONElxHeA.png?1761577982)

## 연락처 정보

**연락처 정보**는 인보이스를 받는 사람의 정보를 보여 주는 영역이에요(예: **청구 대상** 또는 "배송 정보"). 섹션 이름을 바꾸면 비영리 단체, 배송이 많은 업종, B2B 등 용도에 맞게 더 분명하게 표시할 수 있어요.

할 수 있는 일:

- 섹션 제목을 변경해요(예: **청구 대상** → "배송 정보").
- **커스텀 필드 추가**로 받는 사람의 추가 정보를 입력받아요.

![연락처 정보 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056925822/original/dCYgLrqQx1VtYBIwrWt-BuJJ3cM95qViKQ.png?1761578086)

## 인보이스 정보

**인보이스 정보**는 인보이스 번호와 날짜 같은 기본 문서 정보를 다뤄요. 꼭 필요한 항목만 남기면 고객이 보기에 더 간결해져요.

할 수 있는 일:

- **인보이스 번호**, **발급일**, **마감일** 등의 필드를 표시하거나 숨겨요.
- 받는 사람 화면에서 숨긴 내부용 필드도 인보이스를 만들 때는 계속 편집할 수 있어요.

![인보이스 정보 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056926101/original/qEBj-ysK3jun6PBadHsvh6ugYS6vFAzVSA.png?1761578206)

## 라벨

**라벨**은 항목 목록의 열 제목이에요. 고객이 한눈에 읽는 부분이라서, 라벨이 분명하면 문의가 줄고 결제도 빨라져요.

할 수 있는 일:

- 열 제목을 변경해요(예: **Item Name**(항목명) → **상품명**).
- **Price**(가격), **Quantity**(수량), **Tax**(세금), **Subtotal**(소계) 등을 표시하거나 숨겨요.
- 글자 수 표시를 확인해서(예: 최대 75자) 줄바꿈이 생기지 않게 해요.

{% hint style="info" %}
라벨을 체크 해제하면 해당 열이 받는 사람에게 보이지 않아요. 팀에서는 인보이스를 만들 때 그 열의 값을 계속 입력할 수 있어요.
{% endhint %}

![라벨 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056926419/original/Mx8LTrXcLvpdZ8AEVR280cKv83utIRU9YA.png?1761578408)

## 인보이스 레이아웃 맞춤 설정 방법

아래 순서대로 설정 화면을 찾아 레이아웃을 바꾸고 저장하세요. 저장하면 이후 만드는 모든 인보이스에 같은 스타일이 적용돼요.

### 1단계. 인보이스 화면으로 이동하기

서브 계정 대시보드에서 **결제 > 인보이스 & 견적서**로 이동하세요.

![결제 메뉴의 인보이스 & 견적서 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056946969/original/XN3ho3AwucKdpBgHCWOlD1xYcMBYW2Wl3Q.png?1761592498)

### 2단계. 설정 열기

오른쪽 위의 **설정** 버튼을 클릭하세요.

![오른쪽 위의 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056947003/original/O3y68ZhdaYrWxKzH9f7jJFEUZwCeywxQaA.png?1761592540)

### 3단계. 레이아웃 메뉴로 이동하기

설정 화면의 메뉴에서 **제목, 약관 및 레이아웃**을 선택하세요.

![제목, 약관 및 레이아웃 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056947032/original/LTcoqUOgkDGAZM6mjfmH7KDPcNW3pprExg.png?1761592572)

### 4단계. 레이아웃 맞춤 설정 클릭하기

**인보이스 레이아웃**까지 스크롤한 뒤 **레이아웃 맞춤 설정**을 클릭하세요.

![레이아웃 맞춤 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056947050/original/5mK453NMXcefScACguKvNAknu-0Cy9iXPw.png?1761592600)

### 5단계. 레이아웃 탭 설정하기

**레이아웃** 탭에서 아래 항목을 설정하세요.

- **브랜딩 설정**을 열고 색상 선택기로 **결제 버튼 색상**과 **테두리 색상**을 고르세요. 필요하면 **버튼 텍스트**도 바꾸세요(예: "기부").
- **비즈니스 정보**를 펼쳐 필드를 체크하거나 체크 해제하세요. 커스텀 값은 최대 3개까지 추가할 수 있어요.
- **연락처 정보**를 펼쳐 섹션 제목을 바꾸고(예: "배송 정보"), 필요하면 **커스텀 필드 추가**로 필드를 더하세요.
- (선택) **인보이스 정보**를 펼쳐 **인보이스 번호**, **발급일**, **마감일**을 표시하거나 숨기세요.

![레이아웃 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056947144/original/A3R_5DM9DQgRt-NXaUVGXFKcX85Nfhgg9Q.png?1761592787)

### 6단계. 라벨 수정하기

**라벨** 탭으로 이동해 항목 열(**Item Name**, **Price**, **Quantity**, **Tax**, **Subtotal**)의 이름을 바꾸거나 숨기세요.

![라벨 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056947075/original/FSRtmhiOT-QWKJ4yQjJKgKuQNPqpJbc4iQ.jpeg?1761592635)

### 7단계. 미리보기 확인 후 저장하기

실시간 미리보기에서 모든 내용이 제대로 보이는지 확인하세요. 오른쪽 위의 **변경사항 저장**을 클릭하면 디자인이 적용돼요.

{% hint style="info" %}
처음부터 다시 하고 싶다면 **모든 변경사항 초기화**를 클릭해 기본값으로 되돌리세요.
{% endhint %}

![미리보기와 변경사항 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056947116/original/Z-zfPz8tryRSR0UvCBdKoJFHy8r5AMdywQ.png?1761592739)

## 자주 묻는 질문

### 이 변경사항이 서브 계정의 모든 인보이스에 적용되나요?
네. 레이아웃 맞춤 설정은 서브 계정 단위로 저장되고, 그 서브 계정에서 만드는 인보이스에 사용돼요.

### 레이아웃을 바꾸면 이미 보낸 PDF도 바뀌나요?
아니요. 이미 전달된 PDF는 자동으로 바뀌지 않아요. 받는 사람이 최신 레이아웃을 보려면 PDF를 새로 만들거나 인보이스를 다시 보내세요.

### 열을 숨겨도 인보이스를 만들 때 그 값을 입력할 수 있나요?
네. 라벨을 숨기면 받는 사람 화면에서만 숨겨져요. 팀에서는 인보이스를 만들 때 값을 계속 편집할 수 있어요.

### 비즈니스 정보에 커스텀 값을 몇 개까지 추가할 수 있나요?
최대 3개까지 추가할 수 있어요.

### 레이아웃 변경이 다운로드하거나 이메일로 보낸 PDF에도 반영되나요?
네. PDF를 생성하거나 다시 보낼 때 저장된 레이아웃이 반영돼요. 자세한 내용은 "인보이스와 영수증 PDF 생성(PDF Generation for Invoices and Receipts)" 문서를 참고하세요.
