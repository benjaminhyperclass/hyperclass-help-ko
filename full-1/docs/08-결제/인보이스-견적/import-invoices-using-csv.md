# CSV로 인보이스 가져오기

다른 플랫폼에서 쓰던 인보이스를 CSV 파일로 한 번에 가져오는 방법을 안내해요. 다른 시스템에서 옮겨 오거나 지난 청구 데이터를 정리할 때 쓰면 수작업 시간을 줄일 수 있어요.

## CSV 인보이스 가져오기란?

스프레드시트나 다른 플랫폼에서 내보낸 인보이스 데이터를 하이퍼클래스 계정으로 바로 가져오는 기능이에요. 가져오는 중에 발행일, 만기일, 세금 같은 주요 필드를 직접 연결(매핑)할 수 있어요. 가져오기가 끝나면 결과 요약도 자동으로 받아요. 기존 시스템에서 매끄럽게 옮겨 오고, 청구 정보를 한곳에서 관리할 수 있어요.

## CSV 인보이스 가져오기의 장점

CSV 파일로 인보이스를 가져오면 같은 데이터를 다시 입력하지 않아도 돼요.

- 다른 청구 시스템이나 스프레드시트의 인보이스 데이터를 빠르게 옮길 수 있어요.
- 발행일, 만기일, 세금 값 같은 주요 필드를 연결할 수 있어요.
- 가져오기가 끝나면 결과 요약 이메일을 자동으로 받아요.
- 직접 입력하다 생기는 실수를 줄일 수 있어요.
- 인보이스 기록을 한곳에 모아 리포트의 정확도를 높일 수 있어요.

## CSV로 인보이스 가져오는 순서

파일을 올리고, 열을 올바르게 연결한 뒤, 결과를 확인하는 순서로 진행해요.

1. **결제 > 인보이스 & 견적서**로 이동하세요.
2. 오른쪽 위에 있는 **+ 신규** 버튼을 클릭하세요.
3. 드롭다운 메뉴에서 **CSV로 인보이스 가져오기**를 선택하세요.
4. 샘플 CSV 파일을 내려받아 필요한 열 구조를 확인하세요.
5. 샘플 형식에 맞춰 CSV 파일을 준비하세요.
6. **설정 > 세금**에서 사용할 세율이 모두 만들어져 있는지 확인하세요.
7. CSV 파일을 업로드하세요.
8. CSV의 각 열을 알맞은 인보이스 필드와 연결하세요. 발행일, 만기일 같은 날짜 필드는 올바른 날짜 형식으로 연결해야 해요.
   화면 예시: CSV 열을 필드에 맞추는 드롭다운이 있는 필드 매핑 화면
9. 세금 관련 열이 있으면 시스템이 자동으로 찾아서, 기존 세율과 연결하라고 안내해요.
   화면 예시: CSV의 세금 이름을 시스템에 등록된 세율과 맞추는 드롭다운이 있는 세금 매핑 영역
10. **가져오기 시작**을 클릭해서 가져오기를 시작하세요.
    화면 예시: 가져오기가 시작됐음을 알리는 초록색 확인 배너
11. 가져온 인보이스와 실패한 인보이스의 내용이 담긴 인보이스 가져오기 요약 이메일을 받아요.

## 세금 매핑

세금을 올바르게 연결해야 가져온 인보이스에 기존 세금 설정과 일치하는 세금 값이 반영돼요.

가져오는 중 세금 관련 열이 발견되면 아래 조건이 적용돼요.

- 발견된 열은 각각 **설정 > 세금**에 미리 만든 세율과 연결해야 해요.
- 맞는 세율이 없으면 먼저 추가한 뒤 매핑을 마쳐야 해요.
- 연결되지 않은 세금 필드가 남아 있으면 가져오기가 일시 중지돼요. 잘못된 데이터가 들어가지 않게 하기 위해서예요.

## 가져오기 요약 이메일

가져오기가 끝나면 등록된 이메일 주소로 요약 이메일이 자동으로 발송돼요. 이메일에는 다음 내용이 들어 있어요.

- 성공적으로 가져온 인보이스 수
- 실패한 항목 목록과 항목별 실패 사유
- 인보이스 행마다 가져오기 결과가 표시된 CSV 첨부 파일

## 알아 두세요

가져온 인보이스는 플랫폼에서 직접 만든 인보이스와 다르게 동작해요.

### 자동 리마인더 없음

가져온 인보이스는 자동 리마인더 이메일이나 문자를 보내지 않아요. 리마인더 워크플로우는 플랫폼 안에서 직접 새로 만든 인보이스에만 적용돼요.

### 연체료와 팁

가져온 인보이스에는 연체료와 팁에 대해 설정해 둔 기본 설정 또는 글로벌 설정이 적용돼요. 특정 인보이스에서 이 기능을 끄려면 가져온 뒤에 직접 편집해야 해요.

## 자주 묻는 질문

### 세금 종류가 여러 개인 인보이스도 가져올 수 있나요?
네, 가능해요. CSV 파일에 세금 종류별로 이름이 제대로 표시되어 있고, 같은 세금이 **설정 > 세금**에 이미 등록되어 있으면 연결해서 가져올 수 있어요.

### 가져온 인보이스에 대해 고객에게 이메일이나 알림이 가나요?
아니요. 가져온 인보이스는 지난 기록으로 취급돼서 리마인더나 알림 이메일이 발송되지 않아요.

### 가져오기 기능으로 기존 인보이스를 수정하거나 덮어쓸 수 있나요?
아니요. CSV 가져오기는 새 인보이스를 만드는 용도로만 쓸 수 있어요. 이미 만든 인보이스를 수정하거나 바꿀 수는 없어요.

### 가져오는 중에 일부 행이 실패하면 어떻게 되나요?
가져오지 못한 행은 요약 이메일에 목록으로 나오고, 행마다 실패 사유가 함께 표시돼요. 날짜 형식이 올바르지 않거나 세금 값이 맞지 않는 경우 등이 있어요.

### 한 번에 가져올 수 있는 인보이스 수에 제한이 있나요?
엄격한 상한은 없어요. 다만 성능을 위해, 그리고 오류를 더 쉽게 관리하려면 500개 이하로 나눠서 가져오는 것을 권장해요.
