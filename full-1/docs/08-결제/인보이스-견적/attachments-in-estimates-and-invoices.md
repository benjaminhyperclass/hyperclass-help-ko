# 견적서와 인보이스에 파일 첨부하기

견적서, 인보이스, 정기 인보이스, 견적서 템플릿에 파일을 최대 10개까지 첨부할 수 있어요. 전체 용량은 20MB까지예요. 사양서, 약관, 이미지 같은 보충 자료를 함께 보내면 고객에게 더 충실한 자료를 처음부터 전달할 수 있어요.

[동영상](https://www.youtube.com/embed/xEQbYLvyjy4?&wmode=opaque)

## 새로 생긴 기능

- 견적서 하나에 파일을 최대 10개까지 첨부할 수 있어요. 첨부한 파일은 이메일에 함께 담겨 발송돼요.
- 견적서 하나당 전체 파일 용량은 20MB까지예요.
- 사양서, 약관, 시각 자료 같은 추가 문서를 자유롭게 넣을 수 있어요.

## 사용할 수 있는 곳

- **인보이스**
- **정기 인보이스**
- **견적서**
- 견적서 템플릿

## 사용 방법

1. **결제** 메뉴의 **견적서**로 이동하세요.
2. 견적서를 만들거나 편집할 때 첨부 아이콘을 찾으세요.

   ![견적서 화면의 첨부 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047518869/original/F0DzFLiBSv9-9JWfmR_JM4rUKWySC8FIWQ.jpeg?1748637862)

3. 아이콘을 클릭해 내 기기에서 파일을 업로드하세요.

   ![기기에서 파일을 업로드하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047518867/original/adNlY50FyXe_SG4UhF9C-Xipi4BCTBOELw.jpeg?1748637862)

4. 첨부한 파일의 전체 용량이 20MB를 넘지 않는지 확인하세요.
5. 받는 사람은 이메일로 첨부파일을 받아요.

   ![이메일에 첨부파일이 포함된 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047518868/original/v8UaL4OoNIIy65-U49tEWK2vM7i9wc8CBg.jpeg?1748637862)

## 이 기능을 만든 이유

- 자세한 자료와 보충 문서를 고객에게 더 쉽게 공유할 수 있어요.
- 견적서 안에 필요한 내용을 갖춰 전문적인 자료를 보낼 수 있어요.
- 추가 정보를 묻고 답하느라 오가는 연락을 줄이고 명확하게 소통할 수 있어요.

{% hint style="info" %}
첨부파일은 인보이스를 처음 보낼 때만 함께 발송돼요. 이후에 예약된 발송에는 첨부되지 않아요.
{% endhint %}

## 앞으로 추가될 기능

- **정기 인보이스**에서 첨부파일 편집
- 결제 일정이 있는 인보이스에서 첨부파일 편집
- 영업시간 안에서 리마인더 설정
