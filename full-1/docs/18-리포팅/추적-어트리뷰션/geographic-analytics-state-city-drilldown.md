# 지역별 분석 — 주·도시별 방문자 보기(Geographic Analytics)

방문자가 어느 주, 어느 도시에서 들어오는지 한눈에 확인하는 기능이에요. 캠페인을 반응이 가장 좋은 지역에 집중할 때 활용해 보세요.

[동영상](https://www.youtube.com/embed/DjG\_FBfw5II?&wmode=opaque)

## 지역별 분석이란?

**Geographic Analytics**(지역별 분석)는 웹 트래픽을 국가, 주, 도시 단위로 보여 주는 인터랙티브 히트맵이에요. 국가에서 주, 도시로 범위를 좁혀 가면 관심이 높은 지역을 찾을 수 있어요. 지역 시장끼리 성과를 비교하고, 마케팅 전략도 바로 다듬을 수 있어요.

드롭다운을 바꾸는 즉시 지도와 순위 목록이 함께 갱신돼요. 직접 새로 고칠 필요가 없어요. 회의나 화면 공유 중에 필요한 정보를 바로 보여 줄 때 편해요.

## 지역별 분석의 장점

위치 데이터를 실제로 활용할 수 있는 정보로 바꿔 줘요.

- 지역 맞춤 타기팅: 성과가 가장 좋은 도시를 찾아 지역 기반 광고와 프로모션을 진행할 수 있어요.
- 더 똑똑한 예산 배분: 참여도 높은 방문이 가장 많은 주로 광고비를 옮길 수 있어요.
- 캠페인 비교: 위치 기반 오퍼를 시작한 뒤 지역별 상승 효과를 측정할 수 있어요.
- 빠른 의사 결정: 페이지를 새로 고치지 않아도 지도와 순위 목록이 실시간으로 갱신돼요.
- 통합 보기: 방문자 수, 지도, 순위를 한 대시보드에서 모두 보기 때문에 리포트를 만들기 쉬워요.

## 지역 선택 드롭다운

**Country**(국가), **State**(주), **City**(도시) 중 하나를 고르면 히트맵과 순위 목록이 바로 바뀌어요. 클릭 횟수가 줄어서 메뉴를 옮겨 다니지 않고 데이터 확인에 집중할 수 있어요.

## 총 방문자 수와 순위 목록

각 단계마다 옆 패널에 방문 수 기준 상위 지역 순위가 자동으로 나와요. 단계를 바꾸면 목록도 실시간으로 바뀌어서 트래픽이 가장 많은 지역을 한눈에 찾을 수 있어요.

선택한 단계의 전체 방문 수는 지도 위에 계속 표시돼요. 주에서 도시로 단계를 바꾸면 합계도 자동으로 갱신돼서, 지금 분석 중인 전체 방문자 규모를 늘 알 수 있어요.

![총 방문자 수와 순위 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054958904/original/zPTCcxaeoCRC-J9l0URJHsKBnFWHB8bSKQ.png?1759253710)

## 동적 히트맵

트래픽이 많을수록 지도의 색이 진해져요. 스프레드시트를 뒤지지 않아도 방문이 몰리는 지역을 바로 알 수 있어요. 지도 위로 마우스를 움직이면 각 주나 도시의 정확한 방문자 수가 나타나요. 툴팁이 바로 뜨기 때문에 숫자 하나만 필요할 때 옆 목록을 스크롤하지 않아도 돼요.

![동적 히트맵](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054959006/original/OeLi2nCmC6ltUsUXPyFAvVo4V2oT182VJA.png?1759253900)

## 지역별 분석 열기

서브 계정이라면 **사이트** 의 **분석** 페이지에서 별도 설정 없이 지역별 분석을 쓸 수 있어요. 다음 단계를 따라 데이터를 확인해 보세요.

#### 1단계: **분석**으로 이동

1. 서브 계정 대시보드 왼쪽 메뉴에서 **사이트**를 선택하세요.
2. 상단 메뉴에서 **분석** 탭을 선택하세요.

#### 2단계: **Geographic Analytics** 카드 확인

아래로 스크롤해서 **Geographic Analytics**(지역별 분석) 카드를 찾으세요. **Page Views**(페이지 조회수) 카드 바로 아래에 있어요. 여기서 다음을 할 수 있어요.

- 지도 위의 드롭다운(**Country** / **State** / **City**)에서 보려는 단계를 선택해요.
- 색이 칠해진 지역에 마우스를 올리면 방문자 수가 보여요.
- 오른쪽 순위 목록에서 상위 지역을 비교해요.

![Geographic Analytics 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054959809/original/vMOCFKs4B2t3vAyzGOn5R3FkNpjDKpAA-Q.png?1759254283)

#### 3단계: 데이터 활용

확인한 결과를 지역별 성과를 높이는 데 활용하세요. 예를 들어 광고비를 옮기거나, 지역에 맞춘 랜딩 페이지를 만들 수 있어요.

## 자주 묻는 질문

### 주·도시별 데이터를 보려면 추적 스크립트를 따로 추가해야 하나요?

아니요. **사이트** 분석이 이미 페이지 조회수를 수집하고 있다면 지역별 분석 데이터는 자동으로 채워져요.

### 히트맵 데이터를 실시간으로 볼 수 있나요?

새 세션이 기록되는 대로 방문자 수가 업데이트돼요. 그래서 페이지 전체를 새로 고치지 않아도 지도가 자동으로 갱신돼요.

### 퍼널과 웹사이트 데이터가 모두 포함되나요?

**분석** 페이지에서 선택한 대상(예: 퍼널, 웹사이트, 둘 다)과 기간을 그대로 따라가요. 그래서 결과도 **분석** 페이지에서 선택한 범위를 기준으로 보여 줘요.
