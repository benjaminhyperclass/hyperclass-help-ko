# 채팅 위젯으로 들어온 대화의 유입 경로 확인하기

웹사이트의 채팅 위젯으로 대화를 시작한 연락처가 어떤 경로로 들어왔는지 확인하는 방법을 안내해요. 연락처 상세 페이지와 **폼 제출**, 두 곳에서 볼 수 있어요.

## 웹 채팅 대화의 유입 경로 보기

### 1. 연락처 상세 페이지에서 채팅 위젯 유입 경로 확인하기

연락처가 채팅 위젯으로 대화를 시작하면, **연락처**의 연락처 상세 페이지에 있는 **Activity**(활동) 탭에 그 기록이 표시돼요.

![연락처 상세 페이지의 Activity 탭에 표시된 채팅 위젯 대화 기록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48087692052/original/cHxVNz-bkXEPjlbMI6bxwTHMO5PU1ni4Og.jpg?1613574964)

클립보드 아이콘을 클릭하면 폼 제출 내용이 열려요. 연락처가 채팅 위젯에 처음 입력한 메시지가 바로 이 폼 제출 내용이에요. 여기에서 유입 경로(자연 검색, 직접 유입 등)를 비롯한 자세한 정보를 볼 수 있어요.

![폼 제출 내용에 표시된 유입 경로 정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48087692717/original/BoqPdR_08SjAQndwajoOr2I8Hm_aNy53Aw.jpg?1613575103)

### 2. 폼 제출에서 채팅 위젯 유입 경로 확인하기

채팅 위젯으로 시작된 대화의 유입 경로는 **폼 제출**에서도 확인할 수 있어요.

1. **마케팅 > 폼 빌더**로 이동하세요.
2. **제출** 탭을 클릭하세요.
3. **Form Selector**(폼 선택기) 드롭다운을 열고, **채팅 위젯** 섹션에서 **Widget Form**(위젯 폼)을 선택하세요.

![폼 선택기 드롭다운에서 Widget Form을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48087689254/original/Yjx-8g6ASgeLimbZr2sAbPRWLZWdxOJy_A.jpg?1613574447)

{% hint style="info" %}
- 하이퍼클래스로 만들지 않은 웹사이트에 추가한 채팅 위젯도 어트리뷰션이 적용돼요. 하이퍼클래스 WordPress 위젯을 사용하는 사이트도 마찬가지예요.
- 일부 iOS 사용자나 개인정보 보호 모드를 켠 사용자는 쿠키가 차단되어 어트리뷰션이 적용되지 않을 수 있어요.
{% endhint %}
