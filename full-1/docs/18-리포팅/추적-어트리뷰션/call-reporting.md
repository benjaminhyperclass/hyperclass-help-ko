# 통화 리포팅

**통화 리포팅**은 고객과 팀원 사이에 오간 수신·발신 통화를 한곳에서 확인하는 리포트예요. 통화 상태, 유입 경로, 상담원별 통화 현황을 볼 수 있어요.

[동영상](https://www.loom.com/embed/24a0fa26c1d34c71b2ddbabef99c1b10?sid=118be027-a497-415b-b171-db369f09df9b)

---

통화 리포팅은 Agency Pro 플랜에서 사용할 수 있어요.

{% hint style="info" %}
더 세밀하게 맞춘 리포트가 필요하면 사용자 지정 대시보드를 활용하세요. 사용자 지정 위젯을 추가하고 수정해서 하이퍼클래스 주요 영역의 지표를 보여 줄 수 있어요. 자세한 내용은 사용자 지정 위젯 도움말을 참고하세요.
{% endhint %}

## 리포트 열기

왼쪽 메뉴에서 **리포팅**을 선택한 다음, 상단 메뉴에서 **통화 리포팅**을 선택하세요.

## 리포트에서 볼 수 있는 내용

- **통화 리포팅 개요**: 고객과 팀원 사이의 모든 통화(수신·발신)를 한눈에 볼 수 있어요.
- **탭과 데이터 필터**: 수신 통화와 발신 통화, 두 개의 탭으로 나뉘어 있어요. 프로필에 등록된 전체 번호 기준으로 보거나, 특정 번호만 골라서 볼 수 있어요.
- **위젯과 데이터 시각화**:

  - 도넛 차트: 수신 통화의 상태(부재중, 통화 중, 응답) 비율을 보여 줘요.
  - 첫 통화 위젯: 처음 걸려 온 수신 통화의 상태와 평균·총 통화 시간을 보여 줘요.
  - 상위 통화 유입 경로: 통화가 어디에서 들어왔는지(예: Google 자연 검색, 유료 검색) 알려 줘요. 총 통화 수, 고객전환성공 건수, 통화 시간도 함께 볼 수 있어요.
- **과거 데이터 표**: 모든 통화의 과거 기록을 수신 통화와 발신 통화로 나눠서 보여 줘요. 표를 필터링할 수 있고, IVR 통화는 드롭다운으로 여러 통화 녹음을 골라 들을 수 있어요.
- **발신 통화 인사이트**:

  - 통화 상태 분포: 발신 통화의 상태별 비율을 보여 줘요.
  - **상위 상담원**: 통화를 가장 많이 한 상담원을 보여 줘요. 연락한 리드 수도 중복 없이 센 값으로 함께 표시돼요.
- **사용자 지정 및 내보내기**: CSV로 내보낼 때 포함할 열을 직접 고를 수 있어요. 데이터를 더 자세히 분석할 때 유용해요.
- **IVR 통화의 다중 녹음 선택**: IVR 통화는 여러 통화 녹음 중에서 원하는 녹음을 골라 들을 수 있어요.
