# 사용자 지정 리포트 템플릿 라이브러리

사용자 지정 리포트를 처음부터 만들지 않고, 미리 만들어 둔 템플릿으로 시작하는 방법을 안내해요. 템플릿 선택부터 브랜딩 맞춤, 일정 발송까지 한 번에 살펴봐요.

[동영상](https://www.youtube.com/embed/eEsM5Y1kfYw?&wmode=opaque)

디자인 경험이 없어도 보기 좋은 데이터 리포트를 몇 분 만에 만들고, 일정에 맞춰 보내고, 공유할 수 있어요. 사용자 지정 리포트 템플릿 라이브러리에서 완성된 레이아웃을 고르고, 브랜딩을 맞추고, 발송을 자동화해 보세요. 페이지를 일일이 꾸밀 필요가 없어요. 이 문서에서는 템플릿 라이브러리의 사용 가능 범위, 설정, 사용 방법, 운영 기준을 다뤄요. 팀의 리포트를 같은 기준으로 맞출 때 참고하세요.

---

## 사용자 지정 리포트 템플릿 라이브러리란?

사용자 지정 리포트 템플릿 라이브러리는 **리포팅**(Reporting) > **사용자 지정 리포트**에서 볼 수 있는 템플릿 모음이에요. 전문가가 디자인한 리포트 레이아웃이 들어 있어요. 처음부터 만들지 않고 템플릿으로 시작해서 브랜딩을 맞추고, PDF나 이메일로 일정에 따라 보낼 수 있어요. 에이전시는 템플릿으로 디자인 기준을 지키면서 고객 리포트를 더 빠르게 만들 수 있어요.

새 사용자 지정 리포트를 만들 때 라이브러리가 나타나요. 템플릿을 둘러보고 미리 본 다음 적용하면, 페이지·위젯·테마가 미리 설정된 리포트가 통째로 열려요.

---

## 템플릿 라이브러리의 장점

템플릿을 쓰면 일관성을 지키면서 빠르게 만들 수 있고, 설정 실수도 줄어요. 에이전시와 고객을 직접 상대하는 팀에 특히 도움이 되는 점을 정리했어요.

- 브랜드 일관성: 고객이 달라도 글꼴, 색상, 레이아웃을 같게 유지할 수 있어요.
- 빠른 리포트 제작: 준비된 템플릿으로 새 리포트를 몇 분 만에 만들어 바로 쓸 수 있어요.
- 검증된 모범 사례: 모든 템플릿은 데이터·비즈니스 전문가가 정확성과 효율을 고려해 디자인했어요.
- 지속적인 업데이트: 업계 트렌드와 사용자 의견을 반영해 새 템플릿이 정기적으로 추가돼요.
- 자유로운 수정: 지표, 필터, 시각 자료, 레이아웃 등 모든 구성 요소를 필요에 맞게 편집할 수 있어요.
- 낮은 학습 부담: 리포팅이 처음인 사용자나, 분석 리포트 만드는 방식을 통일하려는 팀에 알맞아요.
- 시간 절약: 반복되는 설정 작업을 줄이고, 서식 대신 데이터 분석에 집중할 수 있어요.

## 사용자 지정 리포트를 템플릿 라이브러리에 추가하기

완성한 리포트를 템플릿으로 바꿔 두면 모든 팀이 같은 레이아웃과 브랜딩을 다시 쓸 수 있어요. 먼저 권한을 설정한 뒤 리포트를 템플릿으로 업로드하면, 서브 계정 전체에서 쓸 수 있어요.

**최소 접근 권한 설정하기**

1. **리포팅 > 사용자 지정 리포트**의 **Reports Overview**(리포트 개요)에서 완성한 리포트를 찾아요.
2. 리포트 이름 옆의 **⋮ (점 3개)** 를 클릭하고 **권한 관리**를 선택해요.

**에이전시 사용자**, **계정 관리자**, **계정 사용자** 역할에 최소한 **읽기** 권한을 주세요.

![권한 관리에서 역할별 읽기 권한을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055789165/original/oGQm8KKTXfA84EK8mf31qFD-A7E8r2n7nw.gif?1760253320)

**업로드 전에 템플릿용 리포트 준비하기**

1. 레이아웃, 브랜딩, 페이지 순서를 확정해요.
2. 특정 고객에 관한 문구나 스크린샷은 일반적인 문구나 자리표시자로 바꿔요.
3. 재사용하려는 날짜 범위와 위젯 설정을 정리해요.
4. **⋮ (점 3개)** 를 클릭하고 **Upload Report Template**(리포트 템플릿 업로드)을 선택해요.

![리포트 메뉴에서 템플릿 업로드를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055789208/original/iM1_LnXENcueFLixoWgjemiN2_tYNQDDIg.png?1760253434)

## 사용자 지정 리포트 템플릿 라이브러리 사용하기

완성된 템플릿으로 시작해 실제 지표로 미리 보고, 정해진 일정에 맞춰 보내면 리포팅 업무를 가장 빨리 자리 잡게 할 수 있어요. 아래 단계를 따르면 템플릿 선택부터 발송까지 한 흐름으로 끝낼 수 있어요.

1. 대상 서브 계정을 열고 **리포팅 > 사용자 지정 리포트**로 이동해요. **New Report**(새 리포트)를 클릭하면 리포트 만들기 창이 열려요.

   ![새 리포트 만들기 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055788775/original/bOerS69c7IAqYF97wd3jjFp60ozsmKwnYQ.png?1760252504)
2. 시작 방식으로 **From Dashboard**(대시보드로 만들기), **처음부터 만들기**, **템플릿으로 만들기** 중 하나를 선택해요. 엄선된 디자인을 둘러보려면 **템플릿으로 만들기**를 선택하세요.

   ![시작 방식을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055788781/original/zL1Oa1FSyA-bYzqt3vCb6miXabxjU-__og.png?1760252547)
3. **템플릿 라이브러리**에서 **Niche**(업종)와 **태그**로 필터링해 알맞은 레이아웃을 찾아요. 템플릿을 클릭해 미리 본 다음 **템플릿 사용**을 클릭하면 적용돼요.

   ![템플릿을 필터링하고 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055788793/original/wQmdeHQ2nsazF2GNrkgktHVIrW1T7GQzQA.png?1760252595)
4. 적용하면 실제 데이터로 보는 미리보기가 나타나요. **저장 > 일정**을 클릭해 특정 날짜나 매주 반복으로 발송 일정을 정해요. 필요하면 바로 **보내기**를 하거나 PDF를 **다운로드**할 수도 있어요. 일정 설정과 PDF 내보내기는 [사용자 지정 리포트 만들기·일정 설정·PDF 내보내기](커스텀-리포트/how-to-create-a-custom-report-schedule-and-export-report-as-pdf.md) 문서에서 자세히 볼 수 있어요.

   ![실제 데이터 미리보기와 일정 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055788799/original/_2PE-ilAIivwY__lJ35_RuO4jvS0Gvk7fw.png?1760252621)

## 자주 묻는 질문

### 템플릿을 수정하면 이미 그 템플릿으로 만든 리포트도 바뀌나요?
아니요. 템플릿은 시작점일 뿐이에요. 수정한 내용은 이후에 그 템플릿으로 만드는 리포트에만 적용돼요. 이미 만든 리포트나 일정이 설정된 리포트는 그대로 유지돼요.

### 특정 서브 계정에서 일부 템플릿만 숨길 수 있나요?
템플릿 하나만 직접 숨길 수는 없어요. 숨김 카테고리를 만들고, 숨기려는 템플릿이 공개된 카테고리에 하나도 들어 있지 않게 해 주세요. 자세한 방법은 [서브 계정에서 개별 템플릿 숨기기](../10-마케팅/템플릿-라이브러리/hide-individual-templates-from-subaccounts.md) 문서를 참고하세요.

### 빌더, 이메일 미리보기, 광고 위젯에서 숫자가 서로 다른 이유는 무엇인가요?
시간대가 달라서예요. 빌더는 브라우저의 시간대를 쓰고, 일정 발송 이메일 미리보기는 서브 계정의 시간대를 써요. 연결된 광고 플랫폼(예: Google, Facebook)은 각 광고 계정의 시간대를 따라요.

### 다운로드한 PDF에 이미지가 들어가나요?
이미지와 iframe은 미리보기나 이메일에는 나타날 수 있지만, 보안 제한 때문에 다운로드한 PDF에는 포함되지 않아요.
