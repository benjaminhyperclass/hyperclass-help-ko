# 워크플로우 AI 빌더의 버전 기록 — Version History

**Workflow AI Builder**(워크플로우 AI 빌더)는 AI가 만든 워크플로우 버전을 모두 기록하고, 이전 버전으로 한 번에 되돌릴 수 있게 해 줘요. 이 문서에서는 아티팩트 카드의 작동 방식, 버전 복원 방법, 그리고 기존 **Version History**(버전 기록) 탭과 어떻게 이어지는지 설명해요.

## AI Builder의 버전 기록이란?

**AI Assistant**(AI 어시스턴트)가 워크플로우를 만들거나 편집할 때마다 그 버전이 하나씩 저장돼요. 변경이 생길 때마다 채팅 대화 안에 아티팩트 카드가 표시되고, 이 카드들이 AI가 만든 수정 내역의 전체 타임라인이 돼요.

아티팩트 카드로 이전 버전을 한 번에 복원할 수 있어요. AI가 트리거를 지우거나, 액션 설정을 덮어쓰거나, 원하지 않는 변경을 했을 때 워크플로우를 처음부터 다시 만들지 않아도 돼요. 모든 버전은 그대로 남아 있고 언제든 복원할 수 있어서, 앞뒤로 자유롭게 오갈 수 있고 어떤 버전도 사라지지 않아요.

이 기능은 기존 **Version History** 탭과 연동돼요. AI가 만든 버전과 직접 편집한 버전이 한 타임라인에 함께 표시되고, 버전 번호는 **Version History** 탭을 기준으로 매겨져요.

## 주요 장점

AI가 만든 워크플로우를 다룰 때 안심하고 여러 가지를 시도해 볼 수 있어요.

- 한 번에 복구: AI가 트리거를 지우거나 액션 설정을 덮어쓰거나 원하지 않는 변경을 했을 때 이전 버전을 바로 복원해요. 직접 다시 만들 필요가 없어요.
- 끊김 없는 작업: **AI Assistant** 화면을 벗어나거나 대화 흐름을 끊지 않고 버전을 복원해요. 되돌린 뒤에도 바로 작업을 이어갈 수 있어요.
- 안전한 실험: 과감하게 수정해 보세요. 결과를 비교해 보고, 마음에 들지 않으면 바로 되돌리면 돼요.
- 기존 내용을 지우지 않는 버전 관리: 이전 버전을 복원해도 최신 버전은 그대로 남아요. 어떤 버전도 없애지 않고 자유롭게 오갈 수 있어요.
- 한눈에 보이는 현재 상태: 지금 캔버스와 일치하는 버전이 어느 것인지 표시돼요. 자동 저장이 꺼져 있으면 저장되지 않은 버전도 표시돼요.

## 아티팩트 카드가 작동하는 방식

아티팩트 카드는 AI가 만든 각 버전을 보여 주고 제어하는 카드예요. 구성 요소를 알아 두면 버전 기록을 더 쉽게 다룰 수 있어요.

### 1. 아티팩트 카드 생성

**AI Assistant**가 워크플로우를 만들거나 편집할 때마다 채팅에 아티팩트 카드가 표시돼요. 카드는 대화에서 변경이 일어난 바로 그 위치에 놓여서, AI가 만든 수정 내역이 시간순 타임라인으로 쌓여요.

### 2. 현재 버전 표시

지금 캔버스와 일치하는 아티팩트 카드에는 보라색 테두리가 표시돼요. 채팅 기록에 버전이 여러 개 있어도 지금 보고 있는 버전이 어느 것인지 알 수 있어요.

### 3. 복원 메뉴

각 아티팩트 카드에는 점 세 개 메뉴가 있고, 여기에 **Restore this version**(이 버전으로 복원) 옵션이 있어요. 이 옵션을 선택하면 캔버스가 그 버전으로 바로 바뀌어요. 보라색 테두리는 복원한 카드로 옮겨 가고, 이전에 현재 버전이던 카드에는 복원 메뉴가 생겨요.

### 4. 양방향 이동

이전 버전을 복원해도 최신 버전은 계속 복원할 수 있어요. 어느 버전으로든 앞뒤로 오갈 수 있고, 복원 과정에서 삭제되는 버전은 없어요.

[스크린샷: 채팅의 아티팩트 카드. 현재 버전에는 보라색 테두리, 이전 버전에는 복원 옵션이 있는 점 세 개 메뉴가 표시됨]

{% hint style="info" %}
팁: 걱정 없이 실험해 보세요. 버전 기록이 있으니 AI에게 과감한 수정을 시켜 보고, 결과를 비교한 뒤 필요하면 바로 되돌릴 수 있어요.
{% endhint %}

## AI Builder에서 버전 기록 사용하기

아티팩트 카드로 AI가 만든 워크플로우 버전을 확인하고 복원하려면 다음 단계를 따르세요.

1. **Workflow AI Builder**를 열고 **AI Assistant**에게 워크플로우를 만들거나 편집해 달라고 요청하세요. AI가 요청에 맞춰 워크플로우를 만들어요.
2. AI가 작업을 마치면 채팅에 첫 번째 아티팩트 카드가 바로 표시돼요. 이 카드에는 보라색 테두리가 있어서 지금 캔버스와 같은 버전임을 알려 줘요.
3. AI에게 워크플로우를 한 번 더 바꿔 달라고 요청하세요. AI가 새 버전을 만들고 채팅에 두 번째 아티팩트 카드가 표시돼요.
4. 보라색 테두리가 가장 최근 아티팩트 카드로 옮겨 가요. 이전 카드에서는 보라색 테두리가 사라지지만 채팅 기록에는 그대로 남아 있어요.
5. 이전 버전으로 돌아가려면 오래된 아티팩트 카드의 점 세 개 메뉴를 클릭하고 **Restore this version**을 선택하세요. 캔버스가 그 버전으로 바로 바뀌고, 보라색 테두리는 복원한 카드로 옮겨 가요.

{% hint style="info" %}
팁: 버전은 순서에 상관없이 여러 번 복원할 수 있어요. 이전 버전을 복원한 뒤에도 최신 버전은 그대로 남아 있어서, 여러 방식을 자유롭게 비교해 볼 수 있어요.
{% endhint %}

## 저장되지 않은 버전 표시 이해하기

서브 계정에서 자동 저장이 꺼져 있으면, 아티팩트 카드에 **Unsaved**(저장되지 않음) 표시가 나타나요. 직접 저장하지 않은 버전을 알려 주는 표시로, 아직 저장되지 않은 채 임시로만 있는 버전을 확인할 수 있어요.

**Unsaved** 표시는 자동 저장이 꺼져 있을 때만 나타나요. 자동 저장이 켜져 있으면 모든 버전이 자동으로 저장되어서 아티팩트 카드에 이 표시가 나타나지 않아요.

{% hint style="warning" %}
중요: 아티팩트 카드에 **Unsaved** 표시가 보이면, 워크플로우를 떠나기 전에 직접 저장해서 그 버전을 보존하세요. 저장하지 않고 워크플로우를 나가면 저장되지 않은 버전은 사라져요.
{% endhint %}

[스크린샷: 자동 저장이 꺼져 있을 때 Unsaved 표시가 나타난 아티팩트 카드]

## Version History 탭과의 연동

AI Builder의 아티팩트 카드는 **Version History** 탭과 동기화돼요. AI가 만든 버전과 직접 편집한 버전이 한 타임라인에 함께 나타나고, 버전 번호는 **Version History** 탭을 기준으로 해요.

각 아티팩트 카드의 점 세 개 메뉴에는 **Show in version history**(버전 기록에서 보기) 옵션이 있어요. 이 옵션을 선택하면 **Version History** 탭이 열리고 해당 항목이 강조돼서, AI 변경과 직접 편집한 변경의 전체 흐름을 확인할 수 있어요.

AI Assistant가 만든 버전이든 직접 편집한 버전이든, 모든 워크플로우 버전이 **Version History** 탭에 시간순으로 표시돼요. 워크플로우가 어떻게 바뀌어 왔는지 한눈에 볼 수 있어요.

[스크린샷: AI가 만든 버전과 직접 편집한 버전이 하나의 타임라인에 함께 표시된 Version History 탭]

## 자주 묻는 질문

### 이전 버전을 복원하면 최신 버전은 어떻게 되나요?
최신 버전은 그대로 남아 있고 언제든 다시 복원할 수 있어요. 이전 버전을 복원해도 최신 버전이 삭제되거나 사라지지 않아요. 작업 내용을 잃지 않고 어느 버전으로든 오갈 수 있어요.

### 제가 직접 워크플로우를 편집해도 아티팩트 카드가 생기나요?
아니요. 아티팩트 카드는 **AI Assistant**가 만들거나 편집한 내용에만 생겨요. 워크플로우 캔버스에서 직접 편집한 내용은 채팅에 아티팩트 카드를 만들지 않지만, **Version History** 탭에는 표시돼요.

### 지금 캔버스에 있는 버전이 어느 것인지 어떻게 알 수 있나요?
지금 캔버스와 일치하는 아티팩트 카드에 보라색 테두리가 표시돼요. 다른 버전을 복원하거나 AI가 새 버전을 만들면 이 표시도 자동으로 바뀌어요.

### 아티팩트 카드에 나오는 Unsaved 표시는 무슨 뜻인가요?
서브 계정에서 자동 저장이 꺼져 있고, 그 버전을 아직 직접 저장하지 않았다는 뜻이에요. 그 버전을 보존하려면 워크플로우를 직접 저장해야 해요. 자동 저장이 켜져 있으면 이 표시는 나타나지 않아요.

### 아티팩트 카드 대신 Version History 탭에서 버전을 복원할 수도 있나요?
네. **Version History** 탭에는 AI가 만든 버전을 포함한 모든 워크플로우 버전이 표시돼요. 이 탭에서 기본 복원 기능으로 원하는 버전을 복원할 수 있어요. 아티팩트 카드의 **Show in version history** 옵션을 쓰면 탭에서 해당 버전으로 바로 이동해요.

### 하나의 AI Builder 대화에 아티팩트 카드가 몇 개까지 생기나요?
개수 제한은 없어요. AI가 워크플로우를 만들거나 편집할 때마다 새 카드가 생기고, 그 워크플로우에서 AI가 바꾼 모든 내용이 타임라인으로 남아요.

### 버전을 복원한 뒤에 직접 저장해야 하나요?
서브 계정에서 자동 저장이 꺼져 있을 때만 그래요. 자동 저장이 켜져 있으면 복원한 버전도 자동으로 저장돼요. 자동 저장이 꺼져 있으면 복원한 버전을 보존하기 위해 직접 저장해야 해요.

### 채팅 기록에서 아티팩트 카드를 삭제할 수 있나요?
아니요. 아티팩트 카드는 대화 기록의 일부라서 삭제할 수 없어요. AI가 만든 모든 버전의 기록으로 남아서, 참고하거나 복원할 때 쓸 수 있어요.
