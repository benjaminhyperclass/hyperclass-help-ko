# 워크플로우 트리거 — Forms, Surveys, Contains Phrase, Exact Match 다중 선택

워크플로우 트리거의 **Forms**(폼), **Surveys**(설문), **Contains Phrase**(문구 포함), **Exact Match**(정확히 일치) 필드에서 옵션을 여러 개 선택하는 방법을 안내해요. 조건이 여러 개일 때 트리거를 하나만 만들어도 돼요.

[동영상](https://www.youtube.com/embed/amx31SkZLcE?&wmode=opaque)

예전에는 여러 옵션을 선택할 수 없었고, 같은 필터를 다시 고를 수도 없었어요. 그래서 조건마다 트리거를 따로 만들어야 했어요.

## 새로운 기능

- 이제 **Forms**, **Surveys**, **Contains Phrase**, **Exact Match** 필드에서 옵션을 여러 개 선택할 수 있어요.
- 여러 옵션은 "Or"(또는) 조건처럼 동작해요. 예를 들어 **FB - Comments on a Post**(Facebook 게시물 댓글) 트리거의 **Contains Phrase** 필드에 옵션이 5개 있다면, 연락처가 그중 하나라도 댓글로 남기면 트리거가 실행돼요.

## 사용 방법

- **Forms**, **Surveys**: 트리거의 필터에서 드롭다운 목록의 옵션을 클릭해 여러 개 선택할 수 있어요.
- **Contains Phrase**, **Exact Match**: 텍스트를 입력한 뒤 Enter 또는 Return 키를 누르면 옵션을 여러 개 추가할 수 있어요.
