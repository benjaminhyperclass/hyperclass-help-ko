# 워크플로우 액션 일시 중지 — Pause Workflow Actions

워크플로우의 액션을 삭제하거나 연결을 끊지 않고 잠시 꺼 둘 수 있어요. 테스트와 오류 확인, 수정 작업을 더 안전하고 빠르게 할 수 있고, 준비가 되면 해당 단계를 다시 켜면 돼요.

[동영상](https://www.youtube.com/embed/mzfjxKgMVGk?&wmode=opaque)

## 액션 일시 중지란?

액션 일시 중지는 **Advanced Builder**(고급 빌더)와 **Standard Builder**(표준 빌더)에서 워크플로우 노드를 잠시 켜거나 끄는 기능이에요. 꺼 둔 노드는 실행할 때 건너뛰어요. 기존 설정을 그대로 둔 채 오류를 찾거나 A/B 테스트를 하고 설정을 고칠 수 있어요.

- 연결을 끊지 않고 일시 중지: 노드를 하나씩 꺼서 변형을 테스트하거나 문제가 되는 지점을 찾을 수 있어요.
- 기존 설정 유지: 연결 상태가 그대로라서 연결을 지우거나 다시 만들 필요가 없어요.
- 화면에서 바로 확인: 꺼 둔 단계는 캔버스에서 흐리게 보이고, 실행할 때 건너뛰어요.

각 빌더에 대한 자세한 내용은 [고급 빌더 문서](advanced-builder-for-workflows.md)를 참고하세요.

## 이럴 때 편해요

- 두 빌더에서 모두 사용: **Advanced Builder**와 **Standard Builder** 모두에서 쓸 수 있어요. 어느 빌더를 쓰든 같은 방법으로 테스트하고 문제를 확인할 수 있어요.
- 빠른 테스트: 단계를 끄고 워크플로우를 실행한 다음, 바로 다시 켤 수 있어요.
- 다시 만들 필요 없음: 설정이 그대로 남아 있어서 경로를 다시 연결하지 않아도 돼요.
- 깔끔한 실행: 하이퍼클래스가 꺼 둔 노드를 자동으로 건너뛰기 때문에 연락처가 중간에 멈추지 않아요.
- 안전한 수정: 운영 중인 로직에 영향을 주지 않고 오류를 확인하거나 A/B 테스트를 할 수 있어요.

## Enable/Disable 스위치

**Advanced Builder** 또는 **Standard Builder**에서 노드 위에 마우스를 올리면 **Enable/Disable**(켜기/끄기) 스위치가 나타나요. 스위치를 끄면 노드가 회색으로 바뀌고 **Disabled**(비활성화됨) 라벨이 붙어요. 다시 켜면 원래 색으로 돌아오고 정상적으로 실행돼요. 꺼 둔 노드는 실제 실행에서 완전히 무시돼요.

## 화면 표시와 실행 방식

- 노드가 회색으로 표시되고 **Disabled** 태그가 붙어요.
- 꺼 둔 노드: 그 노드가 다음 단계로 가는 유일한 경로여도 자동으로 건너뛰어요. 그래서 뒤에 있는 액션은 그대로 실행돼요.
- 켠 노드: 다시 켠 뒤에는 설정한 그대로 실행돼요.

## 액션 일시 중지는 이렇게 사용해요

1. 일시 중지할 노드 위에 마우스를 올려요.
2. 일시 중지 아이콘을 클릭해요.

이렇게 하면 다음과 같이 동작해요.

- 캔버스: 꺼 둔 노드는 흐리게 표시돼요. 실행되지 않는다는 뜻이에요.
- 실행: 워크플로우를 실행할 때 꺼 둔 노드는 건너뛰어요.
- 이후 로직: 꺼 둔 노드가 이후 액션으로 가는 유일한 경로에 있으면, 워크플로우는 꺼 둔 노드를 건너뛰고 현재 경로에서 이어지는 켜진 노드를 계속 실행해요.

## 자주 묻는 질문

### 연락처가 꺼 둔 노드에서 멈추나요?

아니요. 하이퍼클래스가 꺼 둔 노드를 자동으로 건너뛰고, 켜져 있는 경로를 따라 계속 진행해요.

### 분기 전체를 끌 수 있나요?

네, 그 분기에 있는 노드를 하나씩 모두 끄면 돼요. 꺼 둔 노드는 다시 켤 때까지 모두 건너뛰어요.

### 이 기능은 "특정 날짜에 워크플로우 일시 중지"와 같은 기능인가요?

아니요. 액션 일시 중지는 워크플로우 하나 안에서 개별 단계를 멈추는 기능이에요. [특정 날짜에 워크플로우 일시 중지](pause-workflows-on-certain-dates.md)는 게시된 워크플로우 전체를 정해진 기간 동안 멈추는 기능이에요.

### 꺼 둔 노드가 있는 상태에서 Standard Builder로 바꾸면 어떻게 되나요?

빌더를 불러오기 전에 해당 노드를 삭제할지, 다시 켤지 선택하라는 안내가 나와요.

### 꺼 둔 노드도 실행 한도에 포함되나요?

아니요. 건너뛰는 노드는 실행으로 계산되지 않아서 실행 횟수를 쓰지 않아요.

### 여러 노드를 한꺼번에 켜거나 끌 수 있나요?

출시 시점에는 노드를 하나씩 켜고 끄는 방식이에요. **Bulk actions**(대량 액션)는 아직 지원하지 않아요.

### 로그에서도 건너뛴 노드를 볼 수 있나요?

네. 실행 로그에 꺼 둔 노드가 **Skipped**(건너뜀)로 표시돼요. 테스트할 때 어떤 노드를 건너뛰었는지 쉽게 확인할 수 있어요.
