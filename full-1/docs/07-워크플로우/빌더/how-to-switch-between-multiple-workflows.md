# Workflow Switcher(워크플로우 전환기)로 여러 워크플로우 오가기

**Advanced Builder**(고급 빌더)에서 **Workflow Switcher**를 쓰면 지금 작업 중인 화면을 벗어나지 않고 다른 워크플로우로 빠르게 이동할 수 있어요. 이 문서에서는 검색 패널에서 최근 워크플로우를 찾아 새 브라우저 탭에서 여는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/-bN\_nJfPhc8?&wmode=opaque)

## Workflow Switcher란?

**Workflow Switcher**는 **Advanced Builder** 왼쪽 사이드바에 있는 도구예요. 최근에 연 워크플로우 목록과 빠른 검색을 보여 주고, 선택한 워크플로우를 새 브라우저 탭에서 열어 줘요. 현재 캔버스는 그대로 두고 다른 워크플로우로 빠르게 넘어갈 수 있어요.

## Workflow Switcher를 쓰면 좋은 점

- 작업 흐름 유지: 지금 쓰는 빌더 탭을 벗어나지 않고 다른 워크플로우로 이동해요.
- 나란히 편집: 다른 워크플로우를 새 탭에서 열어 두고 분기 로직을 쉽게 비교해요.
- 손쉬운 재사용: 워크플로우 사이에서 액션이나 분기를 복사·붙여넣기해 일관된 자동화를 만들어요.
- 시간 절약: 페이지를 새로 불러오거나 다시 검색하지 않고, 한 번의 클릭으로 다음 워크플로우로 가요.
- 실수 위험 감소: 다른 자동화를 살펴보는 동안에도 현재 캔버스는 그대로 있어요.

## Workflow Switcher 사용하기

아래 순서를 따르면 지금 작업을 끊지 않고 다른 워크플로우를 찾아 열 수 있어요.

1. **자동화 > 워크플로우**로 이동하세요.

   ![자동화 > 워크플로우 화면](https://jumpshare.com/share/BacusbpA5AlE9Qm9Ek9C+/Screen+Shot+2025-10-30+at+10.52.18+PM.png)
2. **만들기**를 눌러 새 워크플로우를 만들거나, 기존 워크플로우를 여세요.
3. **Advanced Builder**로 전환하세요. 기본 빌더가 아닌지 확인하세요.

   ![Advanced Builder로 전환한 화면](https://jumpshare.com/share/ZWEDtuo2Q7rC8n6rMKpA+/Screen+Shot+2025-10-30+at+10.53.35+PM.png)
4. 왼쪽 사이드바의 **Workflow Switcher** 버튼을 클릭하거나 Shift + W를 누르세요.

   ![왼쪽 사이드바의 Workflow Switcher 버튼](https://jumpshare.com/share/whLvZOaH27TKnWTs8WqK+/Screenshot+2025-10-30+at+10.58.02%E2%80%AFPM.png)
5. **Quick Search**(빠른 검색)를 쓰거나 **Recent Workflows**(최근 워크플로우)에서 워크플로우를 고르세요.
6. 워크플로우를 클릭하면 새 브라우저 탭에서 열려요. 현재 캔버스는 그대로 열려 있어요.

   ![워크플로우를 새 탭에서 여는 모습](https://jumpshare.com/share/6F25VAQ1WVvEzuDrgXKK+/GIF+Recording+2025-10-30+at+11.01.22+PM.gif)

## 자주 묻는 질문

### 기본 빌더에서도 Workflow Switcher를 쓸 수 있나요?

Workflow Switcher는 **Advanced Builder**에서만 나타나요.

### Quick Search는 무엇으로 검색하나요?

Quick Search는 워크플로우 이름으로 찾아 줘요. 이름을 입력하면 원하는 워크플로우를 빠르게 열 수 있어요.

### 다른 워크플로우를 열면 변경 사항이 사라지나요?

다른 워크플로우는 새 탭에서 열려서, 지금 작업 중인 캔버스는 그대로 열려 있어요.

### 열어 둔 두 워크플로우 사이에서 단계를 복사할 수 있나요?

네, 워크플로우 간 복사·붙여넣기로 액션이나 분기를 재사용할 수 있어요.

### 단축키가 있나요?

네, 빌더 탭에 포커스가 있을 때 Shift + W를 누르면 Switcher 패널이 열리고 닫혀요.
