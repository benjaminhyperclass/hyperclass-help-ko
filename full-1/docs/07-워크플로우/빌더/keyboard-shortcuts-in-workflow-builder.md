# 워크플로우 빌더 키보드 단축키 (Keyboard Shortcuts in Workflow Builder)

워크플로우 빌더의 **Advanced Builder**(고급 빌더)에서 키보드 단축키를 쓰면 마우스 없이 자동화를 빠르게 만들 수 있어요. 노드를 복사·잘라내기·붙여넣기 하고, 화면을 확대·축소하고, 방향키로 캔버스를 돌아다니는 방법을 안내해요.

macOS에서는 `⌘`, Windows와 Linux에서는 `Ctrl`을 사용하세요.

## Advanced Builder의 키보드 단축키란?

키보드 단축키는 빌더의 자주 쓰는 명령을 키 조합으로 실행하는 기능이에요. 잘라내기, 복사, 붙여넣기, 확대·축소, 저장 같은 명령을 마우스 없이 쓸 수 있어요.

`K` 키를 누르거나 키보드 아이콘 버튼을 클릭하면 단축키 목록 화면이 나타나요. 명령이 탭별로 나뉘어 있어서 필요한 단축키를 금방 찾을 수 있어요. `⌘`는 macOS의 Command 키이고, Windows와 Linux에서는 `Ctrl`을 써요.

## 키보드 단축키의 장점

- 반복적인 클릭이 줄어서 복잡한 워크플로우를 최대 50% 더 빠르게 만들 수 있어요.
- 뒤에 이어진 액션까지 포함한 브랜치 전체를 키 한 번으로 복사하거나 잘라낼 수 있어요.
- 방향키와 확대·축소·화면 맞춤 키로 캔버스를 빠르게 이동할 수 있어요.
- 키보드를 더 편하게 쓰는 사용자의 피로를 줄이고 접근성을 높여 줘요.
- 더 빨리 익힐 수 있어요. 단축키 화면은 **Essential**(필수), **Edit**(편집), **View**(보기), **Navigation**(탐색), **Tools**(도구) 탭으로 나뉘어 있어요.

## 단축키 화면 여는 방법

1. 워크플로우를 **Advanced Builder**로 열어요.
2. 왼쪽 위의 **Keyboard Shortcuts**(키보드 단축키) 버튼을 클릭하거나 `K` 키를 눌러요.

단축키 화면에는 **Essential**, **Edit**, **View**, **Navigation**, **Tools** 탭이 있어요.

## 단축키 목록

### 1. Edit(편집)

노드와 브랜치 전체에 쓰는 기본 명령이에요.

| 동작 | 단축키 |
| --- | --- |
| 선택한 노드 잘라내기 | `⌘/Ctrl + X` |
| 선택한 노드 복사 | `⌘/Ctrl + C` |
| 노드 붙여넣기 | `⌘/Ctrl + V` |
| 선택한 노드부터 뒤의 모든 액션 복사 | `⌘/Ctrl + Shift + C` |
| 선택한 노드부터 뒤의 모든 액션 잘라내기 | `⌘/Ctrl + Shift + X` |

### 2. View(보기)

확대·축소와 화면 맞춤 명령이에요.

| 동작 | 단축키 |
| --- | --- |
| 확대 / 축소 | `+` / `−` |
| 100%로 보기 | `0` |
| 화면에 맞추기 | `1` |

### 3. Navigation(탐색)

마우스 없이 캔버스에서 선택 위치를 옮기는 명령이에요.

| 동작 | 단축키 |
| --- | --- |
| 다음 / 이전 노드로 이동 | `→` / `←` |
| 위 / 아래 형제 노드로 이동 | `↑` / `↓` |
| 앞쪽(upstream) / 뒤쪽(downstream) 노드 선택 | `Shift + ←` / `Shift + →` |

### 4. Tools(도구)

전체 화면과 패널에 쓰는 명령이에요.

| 동작 | 단축키 |
| --- | --- |
| 워크플로우 저장 | `⌘/Ctrl + S` |
| 모든 노드 선택 | `⌘/Ctrl + A` |
| 선택한 노드 삭제 | `Delete` / `Backspace` |
| 선택한 노드부터 뒤의 모든 액션 삭제 | `⌘/Ctrl + Delete` |
| **Action**(액션) 패널 열기 | `Tab` |
| **Trigger**(트리거) 패널 열기 | `Shift + Tab` |

## Standard Builder 키보드 단축키

**Standard Builder**(표준 빌더)의 키보드 단축키를 쓰면 워크플로우를 편집할 때 더 빠르게 이동하고 반복 클릭을 줄일 수 있어요. 선택한 노드에만 작동하는 단축키도 있고, 선택한 노드부터 뒤의 모든 액션에 적용되는 단축키도 있어요. 현재 빌더 화면에 적용되는 단축키도 있어요.

## 키보드 단축키 사용 방법

1분이면 단축키를 익힐 수 있어요.

1. 워크플로우를 열고 **Advanced Builder**로 전환해요.

![Advanced Builder로 전환한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058120122/original/pUfmhgi2k2vzWORkRj49pPBIyOiu4lfJqA.png?1762878624)

2. `K` 키를 누르거나 왼쪽 위의 키보드 아이콘 버튼을 클릭해 단축키 화면을 열어요.

![키보드 아이콘 버튼으로 단축키 화면을 여는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058120138/original/1tIjv9B_a-lzTU51_L0MeZm1YxHBj_1l6g.png?1762878656)

3. **Essential** 탭에서 꼭 알아야 할 명령을 먼저 확인해요.

![Essential 탭의 필수 명령](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058120188/original/qtGSF67qoVWLQ4gFC3hk0sdDtnH8hv0unQ.png?1762878696)

4. **Edit** 단축키로 노드나 브랜치 전체를 복사하고, 잘라내고, 붙여넣어요.

![Edit 탭의 편집 단축키](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058120235/original/ZmffbmaEeGTbe9XSV9U6ZTN3SwBZgqaMSg.png?1762878738)

5. **View**와 **Navigation** 키로 확대·축소하고 이동하면서 손에 익을 때까지 써 봐요.

![View와 Navigation 탭의 단축키](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058120323/original/GwFcmcIBXggfnHJi6qEz8TgeuOZ92KrIkA.png?1762878771)

6. **Navigation**으로 노드 사이를 이동하고, **View**로 확대·축소하거나 화면에 맞춰요.

![Navigation 탭으로 노드 사이를 이동하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058120379/original/zg486o6VMOVFPfX1o0rB6ixQ6qGXP7C99w.png?1762878805)

7. **Tools**로 저장하고 패널을 열어요. 키보드에서 손을 뗄 필요가 없어요.

![Tools 탭의 저장 및 패널 단축키](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058120442/original/itj_w3mhn-wUFUyN7GZwpOfnd6MY6KFEeA.png?1762878839)

## 중요 사항 및 제한 사항

- 제공 범위: 출시 시점에는 Advanced Builder에서만 쓸 수 있어요. Standard Builder에는 곧 제공될 예정이에요. <!-- 검토 필요: 원문 내용이 서로 다름 -->
- 선택이 먼저예요: 일부 단축키는 현재 선택한 노드에 적용돼요. 사용하기 전에 노드를 먼저 선택하세요.
- 운영체제와 키보드 배열: 운영체제와 키보드 배열에 따라 키가 조금 다를 수 있어요.

## 자주 묻는 질문

### Standard Builder에서도 단축키를 쓸 수 있나요?

출시 시점에는 Advanced Builder에서만 쓸 수 있어요. Standard Builder 지원은 로드맵에 있어요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

### 제 키보드에서는 일부 키가 다르게 느껴져요. 왜 그런가요?

AZERTY 같은 물리적 키보드 배열이나 운영체제의 키 매핑 때문에 기호 위치가 달라질 수 있어요. 화면에 나오는 단축키 목록에서 내 키보드가 실제로 보내는 문자를 확인하세요.

### 단축키가 브라우저 기본 단축키를 덮어쓰나요?

빌더 캔버스에 포커스가 있을 때만 그래요. `⌘/Ctrl + T`(새 탭) 같은 브라우저 전체 단축키는 그대로 작동해요.

### 단축키를 직접 바꾸거나 끌 수 있나요?

아직은 할 수 없어요. 앞으로 업데이트에서 키를 직접 지정하는 환경설정 패널이 추가될 수 있어요.

### 브랜치를 다른 워크플로우로 복사하려면 어떻게 하나요?

`⌘/Ctrl + Shift + C`로 브랜치를 복사해요. 그다음 **Workflow Switcher**(워크플로우 전환기)로 새 탭에서 대상 워크플로우를 열고 `⌘/Ctrl + V`로 붙여넣으세요.

### 선택한 노드 뒤의 모든 액션을 삭제하면 Goal이나 Wait도 함께 지워지나요?

네, 선택한 노드 뒤에 화면상으로 이어진 항목은 모두 삭제돼요. 삭제를 확정하기 전에 강조 표시된 미리보기를 한 번 더 확인하세요.
