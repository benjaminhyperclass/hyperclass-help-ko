# 워크플로우 빌더 — 사이드바 크기 조절과 전체 화면 확장

워크플로우 빌더에서 설정 사이드바의 너비를 직접 조절하거나, 트리거·액션 설정 화면을 전체 화면으로 넓혀 편하게 편집하는 방법을 안내해요.

## 이 문서에서 배울 내용

워크플로우 빌더의 사이드바 크기 조절·확장 기능을 쓰면 워크플로우 설정 패널이 화면을 얼마나 차지할지 정할 수 있어요. 액션이나 트리거 사이드바를 원하는 너비까지 끌어서 조절할 수 있고, 편집에 집중하고 싶을 때는 액션이나 트리거를 전체 화면으로 확장할 수 있어요.

화면 크기와 작업 방식이 달라도 쓸 수 있게 만든 기능이에요. 간단한 단계를 빠르게 고칠 때도, 긴 이메일이나 폼, 입력 항목이 많은 액션을 설정할 때도 도움이 돼요.

## 사이드바 조절·확장 기능의 장점

사이드바 크기 조절과 확장이 어떤 점에서 좋은지 알아 두면, 언제 화면 배치를 바꿔야 할지 판단하기 쉬워요. 그만큼 작업이 빨라지고 실수도 줄어요.

**어떤 화면에서도 편한 편집** — 작은 노트북부터 초광폭 모니터까지, 화면에 맞게 액션·트리거 사이드바의 너비를 조절할 수 있어요.

**복잡한 설정에 더 집중** — 긴 이메일, 여러 단계로 된 폼, 입력 항목이 많은 액션을 작업할 때는 액션이나 트리거를 전체 화면으로 확장해 보세요. 좁은 패널에 갇혀 작업하지 않아도 돼요.

**유연한 작업 공간 배치** — 워크플로우 캔버스와 설정 패널이 화면을 각각 얼마나 쓸지 정할 수 있어요. 작업 내용이 바뀌면 그때그때 다시 조절하면 돼요.

**스크롤과 잘못된 클릭 감소** — 패널이 넓거나 전체 화면이면 스크롤이 줄고, 폼 필드를 읽고 정확히 선택하기도 쉬워요.

**워크플로우 구성 요소 전반에서 같은 사용 방식** — 워크플로우 액션, 트리거, 왼쪽 사이드바의 도구에 같은 조작이 적용돼요. 한 가지 방법만 익히면 돼요.

## 액션·트리거 사이드바 크기 조절

액션·트리거 사이드바의 크기를 조절하면 설정 패널과 워크플로우 캔버스가 차지하는 공간을 세밀하게 정할 수 있어요. 빠른 수정과 자세한 설정을 번갈아 할 때 특히 유용해요.

### 크기 조절이 가능한 곳

- 액션 사이드바: 이메일, SMS, 조건, 웹훅 등 워크플로우 단계를 설정하는 곳이에요.
- 트리거 사이드바: 사용할 수 있는 트리거 중에서 워크플로우를 시작하는 조건을 설정하는 곳이에요.
- 왼쪽 워크플로우 사이드바: 워크플로우 단위의 기능과 도구가 들어 있어요.

### 크기 조절이 동작하는 방식

- 사이드바 너비를 왼쪽이나 오른쪽으로 끌어서 설정 영역을 넓히거나 줄일 수 있어요.
- 너비는 화면 크기에 맞춰져요. 큰 모니터에서는 넓게 열고, 작은 화면에서는 좁게 둘 수 있어요.
- 크기를 조절하면 캔버스 영역도 자동으로 따라 바뀌어요. 빌더 화면과 설정 내용이 균형이 맞는 크기를 찾아보세요.

### 사이드바 크기 조절 방법

1. **자동화 > 워크플로우**로 이동해서 워크플로우를 하나 열어요.
2. 트리거나 액션을 클릭해 설정 사이드바를 열어요.
3. 설정 사이드바의 안쪽 가장자리(사이드바와 캔버스 사이의 경계)로 마우스를 가져가요.
4. 커서가 좌우 크기 조절 모양으로 바뀌면 클릭한 채 왼쪽이나 오른쪽으로 끌어요.
   - 오른쪽으로 끌면 사이드바가 넓어져요. 필드를 읽고 편집할 공간이 더 생겨요.
   - 왼쪽으로 끌면 사이드바가 좁아져요. 캔버스에 공간이 더 생겨요.
5. 사이드바가 원하는 너비가 되면 마우스를 놓아요.

### 활용 팁

- 긴 이메일 내용, 여러 단계로 된 폼, 설정 필드가 많은 액션을 편집할 때는 사이드바를 넓히세요. 한 번에 더 많이 볼 수 있어요.
- 워크플로우 구조를 짜면서 노드를 보거나 옮길 공간이 필요할 때는 사이드바를 좁히세요. **Advanced Builder**(고급 빌더)에서 특히 유용해요.
- 크기 조절과 워크플로우 빌더의 키보드 단축키를 함께 쓰면, 화면 배치를 바꾸면서도 빠르게 이동하고 편집할 수 있어요.

## 액션·트리거를 전체 화면으로 확장하기

전체 화면으로 확장하면 액션이나 트리거 설정 화면이 넓은 전용 작업 공간으로 바뀌어요. 사이드바에 제약받지 않고 한 단계의 세부 내용에 집중할 수 있어요.

### 전체 화면 확장이 특히 유용한 경우

- 풍부한 콘텐츠와 고급 개인화를 넣은 이메일 액션
- 문구, 발송 시점, 커스텀 값을 세밀하게 다듬는 메시지 액션(SMS, WhatsApp 등)
- 필드, 조건, 고급 설정이 여러 개 들어 있는 폼 관련 단계
- 필터, 조건, 제외 항목이 여러 개인 복잡한 트리거

### 전체 화면 확장이 동작하는 방식

- 어떤 액션이나 트리거든 설정 화면에서 전체 화면으로 확장할 수 있어요.
- 설정 패널이 브라우저 창 전체를 사용하므로 텍스트와 입력란을 읽고 편집하기 쉬워요.
- 전체 화면 모드를 끝내면 변경한 내용은 그대로 둔 채 기본 빌더 화면으로 돌아와요.

### 전체 화면으로 확장하는 방법

1. **자동화 > 워크플로우**에서 워크플로우를 열어요.
2. 액션이나 트리거 노드를 클릭해 사이드바 설정을 열어요.
3. 설정 패널에서 해당 단계의 확장 버튼을 눌러 전체 화면 모드로 바꿔요.
4. 넓어진 화면에서 모든 필드를 확인하고 편집해요.
5. 작업이 끝나면 닫기 또는 축소 버튼을 눌러 기본 사이드바와 캔버스 화면으로 돌아와요.

### 활용 팁

- 긴 이메일이나 자세한 메시지를 쓸 때는 전체 화면을 쓰세요. 계속 스크롤하지 않고도 내용을 더 많이 볼 수 있어요.
- 조건이나 필터가 많은 복잡한 트리거는 확장해서 작업하세요. 게시하기 전에 모든 설정을 꼼꼼히 다시 확인할 수 있어요.
- 전체 화면 편집은 워크플로우 빌더의 찾아 바꾸기(Find & Replace) 기능과 함께 쓰면 좋아요. 설정 안에서 커스텀 값, 태그, 문구를 빠르게 찾을 수 있어요.

## 워크플로우 기능 전반에서 사이드바 컨트롤 활용하기

사이드바 크기 조절과 확장은 워크플로우 빌더의 다른 개선 기능과 함께 쓸 수 있어요. Standard 빌더와 Advanced 빌더 모두에서 일관되고 유연한 편집 환경을 쓸 수 있어요.

### 이 기능이 적용되는 곳

- 액션과 트리거: 설정 패널이 열리는 모든 단계에서 크기 조절과 확장을 쓸 수 있어요.
- 왼쪽 워크플로우 도구: 왼쪽 사이드바의 기능도 너비를 조절할 수 있어서 설정과 보조 패널을 쓰기 편해요.

### 다른 워크플로우 개선 기능과 함께 쓰기

- **Workflow Switcher**(워크플로우 전환 기능)로 워크플로우 사이를 오간 뒤, 각 워크플로우에서 필요한 대로 사이드바를 조절하거나 확장하세요.
- 이 화면 배치 기능을 **Undo, Redo & Recent Changes**(실행 취소, 다시 실행, 최근 변경 사항)와 함께 쓰면 복잡한 단계를 다듬으면서 안심하고 이것저것 시도해 볼 수 있어요.
- 처음부터 직접 만들 때나 **Workflow AI Builder**로 만들 때도 마찬가지예요. AI가 첫 흐름을 만들어 준 뒤 세부 편집을 할 때 크기 조절과 확장을 쓸 수 있어요.

## 사이드바 크기 조절·확장 사용 단계

이 기능은 따로 설정할 필요가 없어요. 워크플로우를 만들면서 어디서 쓸 수 있는지만 알면 돼요. 아래 단계는 워크플로우를 연 순간부터 크기 조절과 확장을 쓰는 과정을 보여 줘요.

### 1단계. 워크플로우 빌더 열기

1. 서브 계정에서 **자동화 > 워크플로우**로 이동해요.
2. 기존 워크플로우를 열거나 새로 만들어요(Standard 빌더 또는 Advanced 빌더).

![워크플로우 빌더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077545055/original/c59eJ3LFSzrlKqeFhWp7b7l7vwK_ACleQw.png?1785827402)

### 2단계. 트리거 또는 액션 설정 열기

1. 워크플로우 맨 위의 트리거, 또는 캔버스나 목록에 있는 액션 노드를 클릭해 설정 사이드바를 열어요.
2. 오른쪽(또는 왼쪽)에 설정 패널이 보이는지 확인해요.

![트리거 또는 액션 설정 사이드바 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077545243/original/TYw8W3Qi47x4jaboTyivftdfTDv-ojUdww.gif?1785827600)

### 3단계. 사이드바 크기 조절

1. 설정 사이드바의 안쪽 가장자리에 마우스를 올려요. 커서가 좌우로 크기를 조절할 수 있는 모양으로 바뀔 때까지 기다려요.
2. 클릭한 채 왼쪽이나 오른쪽으로 끌어요.
   - 오른쪽으로 끌면 패널이 넓어져서 한 번에 더 많은 설정을 볼 수 있어요.
   - 왼쪽으로 끌면 패널이 좁아져서 워크플로우 레이아웃을 볼 공간이 늘어나요.
3. 마우스를 놓으면 원하는 너비로 고정돼요.

![사이드바를 끌어서 너비 조절하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077545383/original/GBaccbA-cjJEPVJdVgYtuPdPzo82PgWqJQ.gif?1785827709)

### 4단계. 액션 또는 트리거를 전체 화면으로 확장

1. 설정 사이드바가 열린 상태에서 해당 단계의 확장 버튼을 찾아요.
2. 확장 모드를 켜면 현재 액션이나 트리거가 전체 화면 설정 화면으로 바뀌어요.
3. 전체 화면 화면에서 내용을 편집하고 모든 필드를 확인해요. 필요하면 화면 안에서 스크롤해요.

![액션을 전체 화면으로 확장하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077545603/original/KT5tFbygLb4I6FZmfmFVIVxcuqkI3iVxAg.gif?1785827813)

### 5단계. 기본 화면으로 돌아가기

1. 전체 화면에서 닫기 또는 축소 버튼을 눌러 기본 사이드바 레이아웃으로 돌아와요.
2. 이어서 워크플로우를 편집해요. 필요하면 사이드바 크기를 조절하거나 다른 단계를 확장해요.

### 6단계. 변경 사항 저장·관리

1. 워크플로우 빌더의 자동 저장 기능이 작업하는 동안 편집 내용을 초안으로 보관해요.
2. **Publish**(게시)로 변경 사항을 언제 적용할지 정해요. 필요하면 **Version History**(버전 기록)나 **Recent Changes**(최근 변경 사항)를 이용해 이전 상태로 되돌릴 수 있어요.
