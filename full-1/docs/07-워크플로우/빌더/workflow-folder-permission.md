# 워크플로우 폴더 권한 설정

워크플로우가 들어 있는 폴더에 접근 권한을 설정하면, 권한이 없는 사용자가 그 폴더의 워크플로우를 볼 수도, 만들거나 편집할 수도 없어요. 중요한 워크플로우를 실수나 무단 변경으로부터 지키고 싶을 때 쓰세요.

{% hint style="warning" %}
워크플로우 폴더 권한은 **에이전시 프로 플랜** 이상에서만 사용할 수 있어요.
{% endhint %}

## 폴더 권한으로 워크플로우 폴더 접근 제한하기

폴더로 콘텐츠를 정리하고, 워크플로우로 작업을 자동화할 수 있어요. 오랜 시간 공들여 만든 워크플로우가 허락 없이 바뀌면 곤란하죠.

폴더 권한을 설정하면 접근 권한이 없는 사용자는 해당 폴더 안의 워크플로우를 볼 수 없고, 만들거나 편집할 수도 없어요. 예를 들어 폴더 권한을 **에이전시 관리자**로 설정하면, 에이전시 관리자 역할의 사용자만 그 폴더의 워크플로우를 보고, 만들고, 편집할 수 있어요.

## 워크플로우 폴더에 권한 설정하기

1. 워크플로우 폴더 위에 마우스를 올리거나, 새 폴더를 만들어요.
2. **Actions**(작업) 드롭다운 버튼을 클릭해요.
3. **Manage Permissions**(권한 관리)를 클릭해요.
4. **사용자 유형 선택**에서 이 폴더와 안의 워크플로우에 접근할 수 있는 사용자 유형과 역할을 선택해요.

{% hint style="info" %}
폴더 권한과 상관없이 모든 사용자는 **연락처 세부정보** 페이지에서 해당 연락처가 속한 워크플로우 목록을 볼 수 있어요. 또 모든 사용자가 어떤 워크플로우에든 연락처를 추가하거나 제거할 수 있어요.
{% endhint %}

## 사용자 유형과 역할별 접근 범위

| 폴더 권한 설정 | 접근할 수 있는 사용자 |
| --- | --- |
| 에이전시 관리자 | 에이전시 관리자만 |
| **Agency User**(에이전시 사용자) | 에이전시 관리자, 에이전시 사용자 |
| 계정 관리자 | 에이전시 관리자, 에이전시 사용자, 계정 관리자 |
| **All**(전체) | 모든 사용자 |
