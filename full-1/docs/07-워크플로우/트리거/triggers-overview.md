# 트리거 개요 — Triggers

트리거는 하이퍼클래스의 여러 기능을 서로 연결해 주는 조건문이에요. 이 문서에서는 트리거가 무엇인지 알아보고, 트리거를 만들어 이름을 붙이고 활성화하는 순서를 안내해요.

{% hint style="info" %}
이제 모든 계정에서 워크플로우를 쓸 수 있어요. 트리거와 캠페인으로 하던 일을 모두 할 수 있고, 그 이상도 하나의 빌더에서 처리할 수 있어요. 자세한 내용은 워크플로우 빌더 개요 문서를 참고하세요.
{% endhint %}

트리거는 Zapier의 Zap과 비슷한 조건문이에요. 하이퍼클래스의 여러 모듈을 이어 주는 배선이라고 생각하면 돼요. 화면 뒤에서 여러 기능이 실제로 동작하게 만드는 핵심 장치예요.

## 예시

Zapier에서 Zap을 하나 만들었다고 해 볼게요. ClickFunnels 랜딩 페이지에 삽입한 폼을 방문자가 작성하면, 그 리드를 하이퍼클래스 캠페인에 넣는 Zap이에요. 이때 클라이언트에게 SMS로 알림도 보내고 싶어요. 새 리드가 들어왔다는 사실을 알려 주려는 거예요.

이 일은 어떻게 처리할까요?

답: 트리거를 설정하면 돼요!

## 트리거 만들고, 이름 붙이고, 활성화하기

아래 순서대로 트리거를 만들고 이름을 붙인 뒤 활성화하세요.

1. **트리거**를 클릭해요.
2. **+ New Basic Rule**(새 기본 규칙)을 클릭해요.
3. **Choose a trigger**(트리거 선택) 드롭다운에서 트리거를 고르고, 필요한 필터를 모두 추가해요.
4. **+Add action**(액션 추가)을 클릭해요.
5. **Choose an action**(액션 선택) 드롭다운에서 액션을 고르고, 필요한 필터를 모두 추가해요.
6. **Trigger name**(트리거 이름) 필드에 트리거 이름을 입력해요.
7. **Draft**(초안) 드롭다운을 클릭한 뒤 **Activate**(활성화)를 클릭해요.
