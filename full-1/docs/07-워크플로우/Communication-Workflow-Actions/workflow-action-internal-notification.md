# 워크플로우 액션 — Internal Notification(내부 알림)

워크플로우에서 내부 알림 액션을 쓰면 중요한 일이 생겼을 때 팀원에게 바로 알릴 수 있어요. 이메일, 인앱 알림, SMS, WhatsApp 중에서 알림 방식을 고를 수 있어요. 이 문서에서는 설정 방법과 제한 사항을 안내해요.

[동영상](https://www.youtube.com/embed/exTZbBItK50?&wmode=opaque)

새 리드가 들어왔을 때, 고액 결제가 있었을 때, 내부 소식을 전할 때 등 알려야 할 사람에게 알림을 보낼 수 있어요. 알림 유형과 설정에 따라 연락처 없이도 실행할 수 있어요.

## 내부 알림이란?

내부 알림은 하이퍼클래스 계정 안에서 선택한 사용자, 역할, 팀에게 자동으로 보내는 알림이에요. 워크플로우의 특정 조건이 충족되면 실행돼요. 팀원은 자신이 쓰는 채널로 바로 소식을 받을 수 있어요.

영업, 고객 지원, 운영 팀처럼 새 리드, 제출된 폼, 파이프라인 변경 같은 중요한 일을 바로 알아야 하는 팀에 유용해요.

## 내부 알림의 장점

내부 알림을 쓰면 팀 안의 소통이 쉬워지고 중요한 소식을 놓치지 않아요.

- 실시간 알림: 중요한 워크플로우 트리거가 작동하면 팀원에게 바로 알려요.
- 여러 채널 지원: 이메일, 인앱 알림, SMS, WhatsApp으로 보낼 수 있어요.
- 역할 기반 대상 지정: 개별 사용자, 사용자 역할(예: 모든 관리자), 특정 팀에게 보낼 수 있어요.
- 책임 소재 명확화: 리드나 작업이 배정되었을 때 담당자가 확실히 알 수 있어요.
- 내용 맞춤 설정: 템플릿, 트리거 링크, 동적 필드로 알림 내용을 상황에 맞게 바꿀 수 있어요.

## 내부 알림 설정하기

워크플로우에 내부 알림을 설정하는 방법은 간단해요. 아래 단계를 따라 하세요.

### 워크플로우 빌더 열기

워크플로우를 새로 만들거나 편집하려면 먼저 워크플로우 빌더를 열어요. 내부 알림을 포함한 모든 워크플로우 액션을 이곳에서 관리해요.

1. 왼쪽 메뉴에서 **자동화**로 이동해요.
2. 오른쪽 위의 **+ Create Workflow**(워크플로우 만들기) 버튼을 클릭해요.
3. 처음부터 시작할지, 템플릿을 쓸지, 레시피를 고를지 선택해요.

![워크플로우 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052237482/original/fPZgN9LK1Yzck1-b_WGA5Eqqv9XaQhKYGg.png?1756041643)

### 내부 알림 액션 선택하기

1. 워크플로우 빌더에서 **+** 버튼을 클릭해요. 이 단계에 추가할 수 있는 액션 목록이 열려요.
2. 목록을 아래로 스크롤해서 **Send Internal Notification**(내부 알림 보내기)을 선택해요.

이제 이메일, 인앱, SMS, WhatsApp으로 팀원에게 보낼 알림을 설정할 수 있어요.

![내부 알림 액션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239636/original/QELi4ehOwplU_E6tcLJ36RLcsJI7pTXdZg.png?1756048657)

### 액션 이름 정하기

**Action Name**(액션 이름)에 알림이 무엇인지 알 수 있는 이름을 입력해요. "영업팀 알림 – 이메일"처럼 구체적으로 지으면 워크플로우를 정리하고 관리하기 쉬워요.

![액션 이름 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239638/original/2S_Dguqq1hvKNxEMtUBWP843lJq9uaWxRA.png?1756048681)

### 알림 유형 선택하기

드롭다운 메뉴의 **Type of Notification**(알림 유형)에서 보낼 알림의 종류를 골라요. 선택할 수 있는 항목은 다음과 같아요.

- **Email**(이메일)
- **In-App Notification**(인앱 알림)
- **SMS**
- **WhatsApp**

팀에 어떻게 알릴지에 맞춰 채널을 고르세요. 자세한 소식은 이메일, 빠른 알림은 인앱 알림, 급한 소식은 SMS, 대화하듯 전할 때는 WhatsApp이 잘 맞아요.

![알림 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239646/original/xLZijg_xs6D6typPqeEuzKZHHcvFi6RcdQ.png?1756048698)

### 1. 알림 유형 — Email(이메일)

**Email**을 고르면 메시지가 어떻게 전달되고 보이는지 정하는 항목을 설정해요. 이 항목들을 채우면 이메일이 깔끔하게 만들어지고 알맞은 팀원에게 도착해요.

- **From Name**(보내는 사람): 받는 사람의 받은편지함에 보낸 사람으로 표시될 이름을 입력해요. **tag icon**(태그 아이콘)을 눌러 커스텀 값을 넣으면 보낸 사람 정보를 상황에 따라 바뀌게 할 수 있어요.
- **From Email**(보내는 이메일): 알림을 보낼 이메일 주소를 입력해요. 비워 두면 시스템 기본값이 적용돼요. **tag icon**으로 커스텀 값을 넣을 수도 있어요.
- **To User Type**(받는 사용자 유형): 이메일을 받을 내부 사용자의 유형을 선택해요(예: 관리자, 할당된 사용자, 특정 역할). 알맞은 팀원에게 메시지가 가도록 해 줘요.
- **CC/BCC**(참조/숨은 참조): 수신자를 더 추가해요. **CC**는 모든 수신자에게 보이고, **BCC**는 다른 사람에게 보이지 않아요. 여기에 추가한 항목은 각각 별도의 이메일 한 통으로 계산돼요. 워크플로우 진행에는 영향을 주지 않고 관계자에게 사본을 보낼 수 있어요.
- **Subject**(제목): 이메일의 목적이 드러나는 제목을 입력해요. 제목이 이미 정해진 템플릿을 쓴다면 비워 둘 수 있어요. 커스텀 값을 넣어 제목을 상황에 맞게 바꿀 수도 있어요.

![이메일 알림 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239655/original/xynD9Dxq2JUqaUyfWN-oKhtfx6D9_-aIKg.png?1756048712)

### 이메일 내용 설정

1. **Templates**(템플릿): 드롭다운에서 미리 만들어 둔 이메일 템플릿을 선택해요. 시간을 아끼고 일관된 형식을 유지할 수 있어요. 필요하면 템플릿에 내용을 더 추가해 고칠 수 있어요.
2. **Message**(메시지): 직접 메시지를 쓰거나 고쳐요. 도구 모음으로 서식을 꾸미고, **tag icon**으로 연락처 이름이나 사용자 정보 같은 동적 값을 넣어 알림을 맞춤 설정해요.

**Write with AI**(AI로 작성)를 클릭하면 이메일 메시지 내용을 AI가 제안해 줘요. 전문적인 알림 초안을 빠르게 만들고, 필요에 맞게 고칠 수 있어요.

3. **Add Attachment**(첨부파일 추가): 알림에 파일을 넣으려면 **Add Attachment**를 클릭해요. 문서, 계약서, 참고 자료를 팀과 공유할 때 유용해요.

![이메일 내용 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239659/original/lM76enR7jRBBiyRRa7QP6K8avA-hnvbwWA.png?1756048728)

### 2. 알림 유형 — Notification(인앱 알림)

유형으로 **Notification**을 고르면 하이퍼클래스 안의 **벨 아이콘**에 알림이 표시돼요. 이메일이나 SMS까지 필요 없는 간단한 소식에 알맞아요.

1. **Type of Notification**(알림 유형): **Notification**을 선택하면 인앱 알림이 전송돼요. 플랫폼 안에서 보이기 때문에 팀원이 실시간으로 소식을 알 수 있어요.
2. **Title**(제목): 알림 맨 위에 표시될 짧은 제목을 입력해요. **tag icon**으로 동적 값을 넣어 알림을 맞춤 설정할 수도 있어요.
3. **Message**(메시지): 알림의 핵심 내용을 써요. 짧고 바로 행동할 수 있게 쓰고, 서식 도구나 커스텀 값으로 필요한 세부 정보를 넣어요.

![인앱 알림 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239661/original/cLIiLFgRZnLNeeoZHN6Ixo6ED4LQmGnNgg.png?1756048745)

### 알림 이동 페이지와 수신자

1. **Redirect Page**(이동 페이지): 사용자가 알림을 클릭했을 때 이동할 페이지를 선택해요. 연락처 상세나 기회처럼 가장 관련 있는 화면으로 바로 안내할 수 있어요.
2. **To User Type**(받는 사용자 유형): 알림을 받을 **User Type**(사용자 유형)을 선택해요. 특정 역할, 할당된 사용자, 팀 중에서 고를 수 있어서 알맞은 사람에게 알림이 가요.

![이동 페이지와 수신자 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239672/original/NuKFhobJ5ZoybcjN5DsseRF2OIuU1SRDBA.png?1756048759)

### 3. 알림 유형 — SMS

**SMS**를 고르면 사용자가 등록한 전화번호로 문자 알림을 보낼 수 있어요. 급하거나 시간이 중요한 소식에 알맞아요.

1. **Type of Notification**: **SMS**를 선택하면 내부 사용자에게 문자 메시지로 알림이 전달돼요.
2. **To User Type**: SMS를 받을 사용자 유형을 선택해요(예: 관리자, 할당된 사용자, 팀).
3. **Templates**: 미리 만들어 둔 SMS 템플릿을 고르면 설정이 빨라요. 직접 메시지를 쓰려면 비워 두세요.
4. **Message**: SMS 내용을 써요. 짧고 분명하게 쓰고, **tag icon**으로 커스텀 값을 넣고 **Write with AI**로 AI의 도움을 받아 맞춤 설정할 수 있어요.

![SMS 알림 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239682/original/C8JdrCrAiydqRAp6q-1e8bibRRsVCaq2kg.png?1756048780)

### SMS 첨부파일과 테스트

1. **Add Attachment**: SMS 알림에 파일을 넣으려면 **Add Attachment**를 클릭해요. 참고 문서나 자료를 팀과 공유할 때 유용해요.
2. **Add Files via URL**(URL로 파일 추가): 파일 URL을 입력란에 붙여 넣고 **+ Add**(+ 추가)를 클릭하면 SMS에 파일이 바로 첨부돼요. 팀원이 링크된 자료를 바로 열어 볼 수 있어요.
3. **Test Phone Number**(테스트 전화번호): 국가 번호를 포함한 유효한 전화번호를 입력하고 **Send Test SMS**(테스트 SMS 발송)를 클릭해 알림을 미리 확인해요. 실제로 보내기 전에 SMS 내용과 첨부파일이 제대로 보이는지 확인할 수 있어요.

![SMS 첨부파일과 테스트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239687/original/FFweZxUkmZpNJvnp9fBbbbod_isS0DUiHA.png?1756048794)

### 4. 알림 유형 — WhatsApp

**WhatsApp**을 고르면 팀원이 등록한 WhatsApp 번호로 메시지를 바로 보낼 수 있어요. 대화하듯 실시간으로 소식을 전할 때 알맞아요.

1. **Type of Notification**: **WhatsApp**을 선택하면 WhatsApp 메시지 채널로 알림이 전송돼요.
2. **To User Type**: WhatsApp 메시지를 받을 **User Type**을 선택해요(예: 관리자, 특정 역할, 할당된 사용자).
3. **Templates**: 승인된 WhatsApp 템플릿을 선택해요. 일관된 형식을 유지하고 WhatsApp의 메시지 요건을 맞출 수 있어요.
4. **Message**: 직접 쓸 WhatsApp 메시지를 입력해요. **tag icon**으로 사용자나 연락처 정보 같은 동적 값을 넣어 맞춤 설정할 수 있어요.

![WhatsApp 알림 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052239688/original/-3wHO1al6hBPBOI-bWpaDQ1ebJwfF4I6sg.png?1756048807)

## 기술 참고 사항 및 제한

- 전송 속도 제한: 기본적으로 사용자 한 명당 5분에 최대 500건의 알림(이메일, SMS, 인앱)을 받을 수 있어요.
- 사전 준비: 전화번호, 이메일 주소, WhatsApp 연동이 제대로 설정되어 있어야 해요.
- 외부 사용자: 내부 알림은 하이퍼클래스 안의 팀원에게만 보낼 수 있어요. 연락처나 고객에게는 보낼 수 없어요.
- CC/BCC 제한: 이메일 알림에서만 쓸 수 있어요. 참조와 숨은 참조 수신자가 늘어날 때마다 이메일 사용량과 요금이 늘어나요.

## 연락처 없이 내부 알림 실행하기

알림 유형과 수신자 선택에 따라 내부 알림은 연락처 없이도 실행돼요. 이 액션이 항상 연락처 기록이나 연락처 데이터가 있어야 실행되는 것은 아니라는 뜻이에요.

- 인앱 내부 알림: 연락처가 있어도, 없어도 실행할 수 있어요.
- 단순한 연락처 없는 메시지: 알림이 간단한 내부 메시지만 보내고 연락처 관련 필드나 커스텀 필드를 쓰지 않으면, 연락처를 만들거나 요구하지 않고도 정상적으로 실행돼요.
- 동적 데이터와 연락처 관련 데이터: 알림 내용이 할당된 사용자 정보, 연락처 필드, 커스텀 필드처럼 연락처 고유 정보에 의존하면, 연락처 없는 흐름에서는 그 값이 제대로 채워지지 않을 수 있어요.

### 연락처 없이 들어온 항목의 표시

연락처 없이 내부 알림이 실행되면 해당 항목에 일반적인 연락처 상세 정보가 보이지 않을 수 있어요. 이럴 때는 알림이 일반 연락처 프로필 화면 대신 영문자와 숫자로 된 식별자로 표시될 수 있어요. 연락처 없이 실행될 때는 정상적인 동작이에요.

![연락처 없는 항목의 알림 표시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068101684/original/flSHm0cyVlMSRWFgTWJGF1YuRt2s3C6CJQ.png?1774938348)

### 이메일/SMS 수신자 처리

| 수신자 옵션 | 동작 |
| --- | --- |
| **All Users**(전체 사용자) | 사용자가 설정한 이메일 주소나 전화번호로 보내요. |
| **Particular Users**(특정 사용자) | 선택한 사용자에게 보내요. |
| **Assigned User**(할당된 사용자) | 연락처가 있고 그 연락처에 할당된 사용자가 있을 때만 보내요. SMS의 경우 유효한 전화번호도 있어야 해요. 연락처나 할당된 사용자가 없으면 이 단계는 건너뛰고 워크플로우는 계속 진행돼요. |

## 자주 묻는 질문

### 워크플로우에는 내부 알림이 실행된 것으로 나오는데, 사용자가 받지 못했거나 대화/프로필에서 보이지 않아요. 왜 그런가요?

흔한 원인은 해당 사용자 프로필이 이전에 **수신거부**로 설정된 경우예요. 이런 경우 워크플로우에는 알림이 실행된 것으로 표시되어도, 관련 이메일이나 알림 기록이 사용자에게 보이지 않을 수 있어요. 아래처럼 해결해 보세요.

1. **연락처**로 이동해요. 해당 연락처(프로필)를 열어요.
2. **왼쪽 패널**에서 **수신거부**를 찾아 껐다가 다시 켜서 프로필 상태를 새로 고쳐요.
3. 워크플로우를 다시 테스트해요.

### 한 사용자가 여러 수신자 범주(예: 할당된 사용자, 참조, 팀)에 함께 들어 있으면 하이퍼클래스는 어떻게 보내나요?

하이퍼클래스는 범주가 달라도 수신자 중복을 자동으로 없애요. 같은 사용자가 여러 수신자 항목(예: 참조와 사용자 역할)에 들어 있어도 알림은 한 번만 받아서 중복 발송이 없어요.

### 선택한 알림 유형(SMS, 이메일, WhatsApp)이 수신자에게 제대로 설정되어 있지 않으면 어떻게 되나요?

선택한 채널이 설정되어 있지 않으면 해당 채널의 알림은 실패해요. 예를 들어 사용자에게 SMS를 받을 유효한 전화번호가 없거나 WhatsApp 연동이 연결되어 있지 않은 경우예요. 하지만 워크플로우는 멈추지 않고 다음 액션으로 계속 진행돼요.

### 내부 알림의 첨부파일도 저장 용량이나 메시지 제한에 포함되나요?

네. 이메일, SMS, WhatsApp 알림에 넣은 첨부파일은 계정의 파일 저장 용량에 포함돼요. 채널에 따라 메시지 크기 제한에도 영향을 줄 수 있어요(예: SMS 통신사는 파일 크기를 제한해요). 용량이 큰 파일은 전달되지 않을 수 있으니 첨부파일은 항상 작게 줄여서 쓰세요.

### 워크플로우가 대량으로 실행되면(예: 연락처 수천 명을 한꺼번에 등록할 때) 내부 알림은 어떻게 되나요?

알림에는 사용자당 5분에 500건이라는 하이퍼클래스의 전송 속도 제한이 적용돼요. 워크플로우가 알림을 대량으로 발생시키면 이 기준을 넘는 알림은 대기열에 쌓여요. 시스템 부하에 따라 제한이 초기화된 뒤 전달될 수도 있고, 그 사이에 워크플로우 조건이 만료되면 삭제될 수도 있어요.
