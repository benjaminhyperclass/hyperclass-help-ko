# 워크플로우 액션 — Manual Call(수동 통화)

**Manual Call**(수동 통화) 액션은 담당 사용자가 연락처에게 직접 전화하도록 통화 작업을 만들어 줘요. 신규 리드에게 제때 연락하거나 예정된 통화를 직접 진행하고 싶을 때 쓰세요.

## 개요

**Manual Call** 액션을 쓰면 사용자가 연락처에게 직접 전화하도록 통화 작업을 만들 수 있어요. 통화를 사람이 직접 처리해야 할 때 유용해요. 후속 연락을 놓치지 않거나, 리드에게 먼저 연락하거나, 예정된 통화를 직접 진행할 때 쓰기 좋아요. 만들어진 작업은 **대화 > 수동 작업** 탭에 표시돼요.

## 액션 이름

Manual Call

## 액션 설명

**Manual Call** 액션은 연락처에게 직접 전화하는 작업을 **대화 > 수동 작업** 탭에 만들어요. 이 작업은 사용자가 직접 연락처에게 전화해야 끝나요. 이 탭에서 작업을 삭제하면 연락처가 워크플로우의 다음 액션으로 넘어가요.

기본적으로 작업은 연락처 담당자에게 배정돼요. 다른 사용자에게 맡기려면 **Advanced Settings**(고급 설정)의 **Assign To**(담당자 지정) 필드를 사용하세요.

## 액션 상세 정보

### 단계별 안내

1. 워크플로우에서 사용할 수 있는 액션 목록 중 **Manual Call**을 선택하세요.
2. 액션의 이름을 입력하세요. 어떤 액션인지 알 수 있는 이름이면 좋아요. 예: "후속 통화"
3. (선택) **Advanced Settings**의 **Assign To**에서 작업을 맡길 사용자를 고르세요. 이렇게 하면 기본 배정인 연락처 담당자 대신 선택한 사용자에게 작업이 배정돼요.
4. **대화 > 수동 작업** 탭으로 이동하세요.
   - 만들어진 작업을 확인하세요.
   - 통화를 마치면 작업을 삭제하세요.

### Assign To 동작 방식

**Assign To** 필드를 쓰면 수동 통화 작업을 연락처 담당자가 아닌 특정 사용자에게 배정할 수 있어요. 연락처 담당자가 누구든 특정 팀원이 맡아야 하는 통화가 있을 때 유용해요.

**배정 기준:**

- 선택한 사용자에게 연락처 접근 권한이 있으면, 작업이 그 사용자에게 배정돼요.
- 선택한 사용자에게 연락처 접근 권한이 없으면, 작업이 연락처 담당자에게 배정돼요.
- 선택한 사용자가 없으면, 작업이 연락처 담당자에게 배정돼요.
- 선택한 사용자와 연락처 담당자 모두 배정할 수 없으면, 작업이 **Unassigned**(미배정) 상태가 돼요.

### 실행 로그

액션 로그에 "Manual Call added to the manual queue"라는 메시지와 함께 수동 통화 액션이 표시돼요. 이 로그로 통화 작업의 진행 상황을 추적할 수 있어요.

{% hint style="warning" %}
**Manual Call** 액션은 **수동 작업** 탭에서 작업을 직접 삭제해야만 워크플로우가 다음으로 넘어가요. **연락처** 페이지나 다른 곳에서 연락처에게 전화하는 것만으로는 작업이 완료되지 않고, 워크플로우도 진행되지 않아요.
{% endhint %}

## 예시

**시나리오:** 한 회사가 신규 리드가 문의한 지 24시간 안에 영업 담당자가 모든 리드에게 후속 연락을 하도록 하고 싶어요. 통화를 마치면 작업을 삭제해서 워크플로우의 다음 단계로 넘어가게 해요.

**워크플로우 설정:**

- **Trigger:** **New Contact Created**(새 연락처 생성)
- **Action:** **Manual Call**
  - **Name:** "리드 후속 통화"

**결과:** 영업팀 담당자에게 신규 리드에게 전화하라는 작업이 전달돼요. 덕분에 제때 후속 연락을 할 수 있고, 전환 가능성도 크게 높일 수 있어요.

## 자주 묻는 질문

### 수동 통화 작업은 직접 삭제해야 하나요?

네, 통화를 마친 뒤 **대화 > 수동 작업** 탭에서 작업을 직접 삭제해야 해요. 삭제하면 시스템이 연락처를 워크플로우의 다음 액션으로 보내요.

### 수동 통화 작업을 연락처 담당자가 아닌 다른 사람에게 배정할 수 있나요?

네, **Advanced Settings**의 **Assign To** 필드에서 사용자를 선택하세요. 선택한 사용자에게 연락처 접근 권한이 있으면 작업이 그 사용자에게 배정돼요. 권한이 없으면 연락처 담당자에게 배정되고, 연락처 담당자도 배정할 수 없으면 **Unassigned** 상태가 돼요.

### 배정된 사용자가 연락처에 접근할 수 없으면 어떻게 되나요?

선택한 사용자에게 연락처 접근 권한이 없으면, 작업은 자동으로 연락처 담당자에게 배정돼요. 연락처 담당자도 배정할 수 없으면 작업은 **Unassigned** 상태가 돼요.
