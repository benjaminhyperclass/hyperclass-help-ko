# 워크플로우 액션 — Remove Associated Records from Workflow(연결된 레코드를 워크플로우에서 제거)

트리거 레코드와 연결된 레코드를 다른 워크플로우에서 자동으로 빼 주는 액션이에요. 조건이 바뀌었을 때 관련 연락처, 회사, 사용자 지정 객체 레코드를 깔끔하게 제외하고 싶을 때 써요.

## 개요

**Remove Associated Records from Workflow**(연결된 레코드를 워크플로우에서 제거) 액션은 연락처 기반, 회사 기반, 사용자 지정 객체 기반 등 모든 워크플로우 유형에서 쓸 수 있어요. 선택한 오브젝트와 레이블을 기준으로, 트리거 레코드와 연결된 레코드를 다른 워크플로우에서 제거해요. 그래서 조건이 바뀌었을 때 관련 연락처, 회사, 사용자 지정 객체 레코드를 깔끔하게 등록 해제할 수 있어요.

이 액션은 기존 [**Remove from Workflow**(워크플로우에서 제거) 액션](../Internal-Tools-Workflow-Actions/workflow-action-remove-from-workflow.md)과 달라요. 기존 액션은 현재 레코드(예: 연락처) 하나만 워크플로우에서 제거해요. 반면 **Remove Associated Records from Workflow**는 연결 레이블을 기준으로 연결된 레코드(연락처, 회사, 사용자 지정 객체)를 등록 해제해요.

## 액션 이름

Remove Associated Records From Workflow

## 액션 설명

이 액션에서는 다음을 설정해요.

- 오브젝트 유형 선택
- 제거할 연결 레코드를 정하는 연결 레이블 선택
- 연결된 레코드를 제거할 워크플로우 선택

이 액션은 서브 계정에 사용자 지정 객체를 만들었거나(또는 연락처·회사를 사용하고), 트리거 레코드와 제거할 레코드 사이에 연결 레이블이 있어야 쓸 수 있어요. 연락처-연락처 연결과 회사-연락처 연결도 포함돼요.

## 액션 상세 정보

![액션 상세 정보 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054812396/original/5fxj8Jwe5eWzFilNjCjFCjgaPgYdH7KDig.png?1759145373)

- **Select an object**(오브젝트 선택): 제거할 연결 레코드의 유형을 골라요. 예: 연락처, 딜러, 부동산
- **Association Label**(연결 레이블, 필수): 어떤 연결 레코드를 제거할지 정해요. 회사-연락처 연결에는 적용되지 않아요.
- **Workflow**(워크플로우): 연결된 레코드를 제거할 대상 워크플로우를 골라요.
- 참고할 점
  - 레이블이 일치하는 연결이 하나 이상 있어야 해요. 없으면 제거되는 레코드가 없어요.
  - 제거는 바로 적용돼요. 나중에 다시 등록해야 한다면 **Add Associated Records to Workflow**(연결된 레코드를 워크플로우에 추가) 액션이나 별도의 자동화를 사용하세요.

## 예시

#### 예시 1: 자동차 ↔ 딜러 (사용자 지정 객체 워크플로우)

**자동차** 레코드의 상태가 *판매 완료*로 바뀌면, 연결된 **딜러**(레이블: *담당 딜러*)를 *딜러 알림 워크플로우*에서 제거해요. 그러면 해당 딜러는 더 이상 업데이트를 받지 않아요.

설정

- **Object** → 딜러
- **Association Label** → 담당 딜러
- **Workflow** → 딜러 알림 워크플로우

동작 방식

1. 자동차 상태가 *판매 완료*로 바뀌어 워크플로우가 시작돼요(트리거).
2. 액션이 *담당 딜러* 레이블로 해당 자동차와 연결된 딜러를 찾아요.
3. 찾은 딜러를 *딜러 알림 워크플로우*에서 제거해요.

---

#### 예시 2: 연락처 ↔ 연락처 (부모-자녀, 연락처 워크플로우)

**학생 연락처**가 졸업하면, 모든 **학부모 연락처**(레이블: *부모-자녀*)를 *학기 시작 안내* 워크플로우에서 제거해요.

설정

- **Object** → 연락처(학부모)
- **Association Label** → 부모-자녀
- **Workflow** → 학기 시작 안내

동작 방식

1. 학생 레코드가 *졸업* 상태가 되면서 워크플로우가 시작돼요.
2. 액션이 *부모-자녀* 레이블로 연결된 학부모를 찾아요.
3. 찾은 학부모를 *학기 시작 안내* 워크플로우에서 제거해요.

---

#### 예시 3: 회사 ↔ 연락처 (회사 워크플로우)

**회사** 레코드의 상태가 *비활성*으로 바뀌면, 모든 **연락처**를 *활성 고객 커뮤니케이션 워크플로우*에서 제거해요.

설정

- **Object** → 연락처
- **Workflow** → 활성 고객 커뮤니케이션 워크플로우

동작 방식

1. 회사 레코드가 *비활성*으로 업데이트돼요.
2. 해당 회사와 연결된 연락처를 *활성 고객 커뮤니케이션 워크플로우*에서 제거해요.
