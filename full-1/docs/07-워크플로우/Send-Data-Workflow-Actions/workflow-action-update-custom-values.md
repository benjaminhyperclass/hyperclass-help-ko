# 워크플로우 액션 — Update Custom Value(커스텀 값 업데이트)

**Update Custom Value**(커스텀 값 업데이트) 액션은 워크플로우 안에서 이미 있는 [커스텀 값](../../23-레거시-자동화/how-to-use-custom-values.md)을 새 값으로 바꿔 주는 액션이에요. 로열티 등급 변경, 외부 API 데이터 동기화, 자동화 조건 관리처럼 하이퍼클래스의 데이터를 자동으로 최신 상태로 유지하고 캠페인을 개인화할 때 쓸 수 있어요.

## Update Custom Value 액션이란?

**Update Custom Value** 액션은 워크플로우에서 커스텀 값을 동적으로 바꿔요. 현재 값이나 특정 조건에 따라 기존 커스텀 값을 설정하거나 업데이트하거나 교체할 수 있어요.

- 실시간 트리거에 맞춰 하이퍼클래스 데이터를 자동으로 업데이트해요.
- 변수를 사용해 동적인 값을 설정해요.
- 하이퍼클래스 전체에서 데이터를 정확하고 일관되게 유지해요.

---

## 주요 활용 사례

- 캠페인 개인화: 구매 금액이 일정 기준을 넘으면 고객의 로열티 등급을 자동으로 업데이트해요.
- 데이터 동기화: 외부 API에서 받은 데이터로 필드를 자동으로 업데이트해요.
- 실시간 자동화: 고객의 행동에 따라 할인 코드나 로열티 포인트를 바로 조정해요.
- 트리거 기반 업데이트: 사용자의 행동에 따라 상태 필드를 자동으로 바꿔요.
- 예시 시나리오: "고객이 500달러를 넘게 구매하면 **Update Custom Value** 액션으로 로열티 등급을 '브론즈'에서 '골드'로 업데이트해요."

아래 예시에서는 연락처에 "VIP" 태그가 추가되면 할인율 커스텀 값이 10%에서 15%로 바뀌어요. 그러면 이후 이 연락처는 더 높은 할인을 받을 수 있어요.

- 트리거: **Contact Tag Added**(연락처 태그 추가됨). 조건은 연락처에 "VIP" 태그가 추가되는 경우예요.
- 액션: **Update Custom Value**
- **Custom Value**(커스텀 값): 할인율(미리 만들어 둔 값)
- **Current Value**(현재 값): 10%
- **New Value**(새 값): 15%

---

## Update Custom Value 액션 설정하기

워크플로우에서 **Update Custom Value** 액션을 설정하려면 다음 단계를 따르세요.

1. **자동화 > 워크플로우**로 이동해요. 새 워크플로우를 만들거나 기존 워크플로우를 열어요.

   ![워크플로우 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039509092/original/xIr8vhfB8RNFCvCUZQo5FoAKjjDTrfzNvw.png?1736383274)

2. **+** 버튼을 눌러 액션을 추가해요. 목록에서 찾거나 "update custom value"처럼 이름의 일부를 검색하세요.

   ![액션 추가에서 Update Custom Value 검색](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039509111/original/S7pIzLiepub8l1e-HLgEbi-j90CkZEXSdw.png?1736383408)

3. 바꿀 **Custom Value**를 고르고 **New Value**를 설정해요. 예를 들어 커스텀 값이 특정 캘린더로 가는 링크라면, 다른 링크로 바꿀 수 있어요.

   ![Update Custom Value 필드 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039509144/original/ZcXp5SXMnQPSDfCv7p2tqCrmk-w-RTqIRw.png?1736383538)

4. 액션과 워크플로우를 저장한 뒤 테스트해요. 새 값은 워크플로우에서 이 액션이 실행된 직후부터 바로 쓸 수 있어요. 같은 커스텀 값을 불러오면 새 데이터가 들어 있어요.

### 필드 설명

| 필드 | 설명 | 예시 |
| --- | --- | --- |
| **Action Name**(액션 이름) | 워크플로우에 표시되는 액션의 이름이에요. | 로열티 등급 업데이트 |
| **Custom Value** | 업데이트할 커스텀 값을 선택해요. | 로열티 등급 |
| **Current Value** | 현재 값이 있으면 보여 줘요. | 브론즈 |
| **New Value** | 고정 값이나 동적 변수를 설정해요. | 골드 |

## 고급 활용 사례

- **If/Else**(조건 분기) 액션으로 조건 걸기: 특정 조건을 만족할 때만 값을 바꿔요. 예: 현재 값이 "브론즈"일 때만 로열티 등급을 업데이트해요.
- API 연동: 외부 API에서 들어온 데이터로 커스텀 값을 자동으로 업데이트해요. 예: "마지막 API 동기화 날짜" 커스텀 필드를 동적으로 업데이트해요.
- **Math Operation**(수학 연산) 연동: 수학 연산으로 숫자형 커스텀 값을 계산해 업데이트해요. 예: 사용자의 적립 포인트에 50포인트를 더해요.
- 동적 할인 코드: 실시간 워크플로우에서 할인 코드를 바로 바꿔요. 예: "고객이 한 달에 세 번 구매하면 할인 등급을 '다음 구매 10% 할인'으로 자동 업데이트해요."

## 추천 트리거

- **Contact Tag Added**: 연락처에 "VIP", "높은 우선순위" 같은 새 태그가 추가되면, 그 연락처의 중요도를 반영하도록 관련 커스텀 값을 업데이트할 수 있어요.
  - 예시: "VIP" 태그가 추가되면 할인율 커스텀 값을 업데이트해서 더 높은 비율을 제공해요.

- **Contact Updated**(연락처 업데이트됨): 특정 연락처 필드가 업데이트될 때 액션이 실행돼요. 예를 들어 고객의 환경설정이나 연락처 정보가 바뀌면 그에 맞는 커스텀 값을 업데이트할 수 있어요.
  - 예시: "이메일 구독" 필드가 "구독됨"으로 바뀌면 "이메일 발송 빈도" 커스텀 값을 "매주"로 업데이트해요.

**Form Submitted**(폼 제출): 폼이 제출된 뒤, 폼에 입력된 데이터를 바탕으로 커스텀 값을 업데이트할 수 있어요.

- 예시: 폼이 제출되면 워크플로우가 실행되어 "설문 점수"나 "환경설정" 커스텀 값을 업데이트해요.

**Appointment Booked**(예약 완료): 예약이 완료된 뒤, 예약 유형이나 관련 기준에 따라 커스텀 값을 업데이트할 수 있어요.

- 예시: 연락처가 고가 서비스 예약을 하면 "예약 중요도" 커스텀 값을 "높음"으로 업데이트해요.

**Opportunity Status Changed**(기회 상태 변경됨): 파이프라인에서 기회의 상태가 바뀌면(예: "적합"에서 "고객전환성공"으로), 고객 관리에 도움이 되는 커스텀 값을 업데이트할 수 있어요.

- 예시: 기회 상태가 "고객전환성공"으로 바뀌면 "고객 등급" 커스텀 값을 "플래티넘"으로 업데이트해요.

**Survey Submitted**(설문 제출됨): 연락처가 설문을 제출하면, 응답 내용을 이후 소통에 활용할 커스텀 값에 반영할 수 있어요.

- 예시: 고객 설문에서 만족도 점수가 높게 나오면 "고객 만족도" 커스텀 값을 그 점수로 업데이트해요.

**Order Fulfilled**(주문 처리 완료): 주문이 처리된 뒤, 연락처의 커스텀 값을 업데이트해 주문 이력이나 고객 상태를 기록할 수 있어요.

- 예시: 주문이 처리되면 "마지막 주문일" 커스텀 값을 오늘 날짜로 업데이트해요.

**Link Clicked**(링크 클릭됨): 연락처가 이메일이나 SMS의 링크를 클릭하면, 그 행동에 따라 커스텀 값을 업데이트할 수 있어요.

- 예시: 신상품 링크가 클릭되면 "상품 관심도" 커스텀 값에 해당 상품에 대한 관심을 반영해요.

## 자주 묻는 질문

### Update Custom Value 액션에서 변수를 쓸 수 있나요?
네, `{{contact.custom_field}}` 같은 변수를 사용해 동적으로 업데이트할 수 있어요.

### 이 액션으로 다른 워크플로우를 실행할 수 있나요?
네, 업데이트가 다른 워크플로우의 트리거가 될 수 있어요.

### 한 워크플로우에 Update Custom Value 액션을 몇 개까지 쓸 수 있나요?
제한은 없어요. 필요한 만큼 여러 개를 쓸 수 있어요.

### 현재 값이 조건과 맞지 않으면 어떻게 되나요?
조건이 설정되어 있다면, 현재 값이 그 조건과 맞아야 업데이트가 진행돼요.

### If/Else 액션 안에서도 Update Custom Value를 쓸 수 있나요?
네, 조건 분기와 함께 쓰면 더 복잡한 워크플로우도 만들 수 있어요.

### 여러 커스텀 값을 한 번에 업데이트할 수 있나요?
액션 하나는 커스텀 값 하나를 한 번 업데이트해요. 다른 커스텀 값을 업데이트하거나 같은 값을 다시 바꾸려면 액션을 더 추가하세요.

### 다른 서브 계정의 커스텀 값도 업데이트할 수 있나요?
업데이트할 커스텀 값은 워크플로우가 실행되는 서브 계정에 있어야 해요.

### 업데이트한 뒤에 되돌릴 수 있나요?
아니요, Update Custom Value 액션에는 되돌리기 기능이 없어요.
