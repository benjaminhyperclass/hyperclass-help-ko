# 워크플로우 트리거 — Company Changed(회사 변경)

**Company Changed**(회사 변경) 트리거는 회사 레코드에서 선택한 필드가 바뀔 때 워크플로우를 시작해요. 회사 정보가 바뀌는 즉시 자동화가 반응하므로, 항상 최신 데이터를 기준으로 자동화를 돌릴 수 있어요.

## 트리거 이름

Company Changed

## 트리거 설명

이 트리거는 다음 조건을 모두 충족할 때 실행돼요.

- 회사 레코드가 업데이트됐어요.
- 업데이트된 내용이 트리거에 설정한 필드 조건 중 하나 이상과 일치해요.

확인할 필드를 직접 고를 수 있어요. 예를 들어 **Industry**(업종), **Status**(상태), **Domain**(도메인) 같은 필드예요. 고른 필드의 값이 바뀌면 워크플로우가 자동으로 시작돼요.

## 설정 방법

![Company Changed 트리거 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055005957/original/2jOQH3Y4U0-yFKxL8sniERm7idQUxcGW4A.png?1759320818)

1. 트리거 추가
   - 워크플로우 트리거로 **Company Changed**를 선택해요.
2. 확인할 필드 선택
   - 변경 여부를 확인할 회사 필드(기본 필드 또는 커스텀 필드)를 하나 이상 골라요.
   - 예: **Industry**, **Domain**, **Status**
3. 연산자 적용
   - 필드마다 연산자를 골라요.
     - **Is not empty**(비어있지 않음): 필드에 값이 하나라도 있으면 실행돼요.
     - **Contains Phrase**(문구 포함): 필드 값에 지정한 키워드나 문구가 들어 있으면 실행돼요.
4. 필터 여러 개 추가(선택)
   - 필터를 여러 개 추가하면 AND 조건으로 결합돼요. 모든 조건을 충족해야 트리거가 실행돼요.
5. 트리거 저장
   - 저장하면 설정한 조건을 충족하는 회사가 워크플로우에 자동으로 등록돼요.

## 예시

### 예시 1: 업종 변경 추적하기

목표: 회사의 **Industry** 값에 "의료"가 포함되면 온보딩을 시작해요.

설정

- **Filter**(필터): **Industry** → **Contains Phrase**(문구 포함) → 의료
- **Action**(액션): 의료 온보딩 워크플로우에 등록

동작 방식

1. 회사의 **Industry** 필드가 "의료 기관"으로 업데이트돼요.
2. 워크플로우가 시작돼요.
3. 해당 회사가 의료 전용 워크플로우에 등록돼요.

---

### 예시 2: 도메인 정보 놓치지 않기

목표: 도메인이 비어 있지 않은 상태로 회사 레코드가 생성되거나 업데이트되면 팀원에게 알려요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

설정

- **Filter**: **Domain** → **Is not empty**
- **Action**: **Send Internal Notification**(내부 알림 보내기)

동작 방식

1. 회사의 **Domain** 필드에 값이 입력돼요.
2. 워크플로우가 시작돼요.
3. 영업팀에 내부 알림이 전송돼요.
