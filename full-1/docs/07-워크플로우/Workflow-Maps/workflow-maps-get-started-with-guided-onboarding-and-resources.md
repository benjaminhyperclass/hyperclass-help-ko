# Workflow Maps(워크플로우 맵) 시작하기 — 가이드 온보딩과 Resources

Workflow Maps에는 처음 쓰는 사람을 위한 가이드 온보딩과 **Resources**(리소스) 허브가 있어요. 이 문서에서는 맵을 둘러보는 방법과, 연락처 추적·오류 확인·자산 사용 현황 확인 같은 작업별 안내를 찾는 방법을 설명해요.

## 가이드 온보딩과 Resources란?

가이드 온보딩은 짧은 소개 투어와, 맵을 둘러보는 중에 나타나는 상황별 팁으로 Workflow Maps에 익숙해지도록 도와줘요. **Resources** 허브에는 검색할 수 있는 가이드, 단계별 안내, 빠른 참조가 모여 있어서 필요할 때 바로 찾아볼 수 있어요.

## 가이드 온보딩과 Resources를 쓰면 좋은 점

- 빠르게 익히기: 가이드 온보딩으로 맵 조작 방법, 워크플로우 간 연결, 2D/3D 보기를 익힐 수 있어요.
- 작업별 안내: 연락처 추적, 워크플로우 오류 확인, 자산 사용 현황 확인 방법을 단계별로 볼 수 있어요.
- 필요할 때 바로 도움받기: **Resources**를 검색하고, 학습 자료를 언제든 다시 볼 수 있어요.

## Workflow Maps의 가이드 온보딩

가이드 온보딩은 맵의 화면 구성, 이동 방법, 사용할 수 있는 기능을 소개해요. 워크플로우와 연결된 자산을 살펴보는 동안에는 유용한 도구도 상황에 맞게 안내해 줘요.

- 첫 방문 소개: Workflow Maps의 기본 사용법을 알아보고 2D와 3D 보기 중에서 선택할 수 있어요.
- 상황별 팁: 워크플로우, 폴더, 자산을 둘러볼 때 관련 안내가 나타나요.
- 가이드 투어: **Start guided tour**(가이드 투어 시작) 옵션으로 사용할 수 있는 기능과 조작 방법을 둘러볼 수 있어요.

{% hint style="info" %}
편집과 관련된 안내는 회원님의 권한에 따라 표시돼요.
{% endhint %}

## Workflow Maps의 Resources 허브

**Resources** 허브는 Workflow Maps 사용법을 한곳에서 배울 수 있는 공간이에요. 주제별로 둘러보거나, 하려는 작업에 맞춰 검색할 수 있어요.

제공되는 자료는 다음과 같아요.

- **Start here**(여기서 시작): 맵을 읽는 방법, 연결 관계를 이해하는 방법, 맵을 이동하는 방법을 알려 줘요.
- **Do more with the map**(맵 더 활용하기): 연락처 추적, 오류 확인, 폴더 살펴보기, 자산 사용 현황 확인, 맵 정리 방법을 단계별로 안내해요.
- **Quick reference**(빠른 참조), **Supported assets**(지원되는 자산), **FAQ**(자주 묻는 질문): 추가 정보와 자주 묻는 질문의 답을 볼 수 있어요.

## 자주 묻는 질문

### 처음 방문한 뒤에도 가이드 온보딩을 다시 볼 수 있나요?

네, 볼 수 있어요. Workflow Maps에서 **Help**를 클릭해 **Resources**를 다시 열거나, **Start guided tour**를 선택하면 가이드 투어를 다시 시작할 수 있어요.

### Resources 검색은 Workflow Maps 검색과 같은가요?

아니요. **Resources** 검색은 가이드와 단계별 안내를 찾는 데 쓰고, Workflow Maps 검색은 워크플로우와 자산을 찾는 데 써요.

### 모든 사용자가 편집 관련 안내를 볼 수 있나요?

편집 관련 안내는 권한에 따라 달라요. 일부 작업은 모든 사용자에게 제공되지 않을 수 있어요.
