# 워크플로우 맵 탐색·검색·필터 사용하기

맵을 움직이고 보기 방식을 바꾸고, 워크플로우나 에셋을 찾고, 필터로 맵을 좁혀 보는 방법을 안내해요.

## 맵 이동, 확대·축소, 맞춤

맵을 끌어서 움직이세요. **+** 를 누르면 확대되고 **−** 를 누르면 축소돼요.

**Fit**(맞춤)을 누르면 맵 전체가 한 화면에 다시 보여요. 폴더 하나를 살펴본 뒤나, 지금 어디를 보고 있는지 모르겠을 때 쓰면 좋아요.

## 2D와 3D 전환

**2D / 3D**(2D / 3D 보기 전환)로 보기 방식을 바꿀 수 있어요.

- **3D**는 깊이감이 있는 맵을 보여 줘요.
- **2D**는 위에서 내려다본 평면 화면을 보여 줘요. 규모가 큰 계정이나 스크린샷에서는 2D가 더 읽기 쉬울 수 있어요.

맵이 매우 커서 이동하기 어렵다면 2D로 바꿔 보세요.

## 맵 검색하기

1. **Search**(검색)를 여세요. Mac에서는 **⌘K** 를 눌러도 돼요.
2. 워크플로우, 에셋, 트리거의 이름을 입력하세요. 태그나 폼 이름도 괜찮아요.
3. 일치하는 결과를 확인하세요.
4. 결과를 클릭하면 맵에서 해당 위치로 이동해요.

검색하면 에셋이 쓰인 정확한 트리거, 액션, if/else를 찾을 수 있어요. 워크플로우를 하나씩 열어 보지 않고도 어디에서 참조되는지 확인할 수 있어요.

![이름으로 검색한 뒤 결과를 선택하면 해당 위치로 이동하고 상세 정보가 열려요.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352801/original/debSTY2Njm6YRWHuQ7H_AiyRKxItspA_0w.jpg?1793135716)

이름으로 검색한 뒤 결과를 선택하면 해당 위치로 이동하고 상세 정보가 열려요.

## 맵 필터링하기

1. 화면 위쪽의 빠른 필터로 게시된 워크플로우, 초안 워크플로우, 또는 에셋 유형 하나만 보이게 하세요.
2. 옵션이 더 필요하면 왼쪽 레일에서 필터 패널을 여세요.
3. 필요한 워크플로우나 에셋만 보이도록 필터를 조정하세요.
4. 전체 맵을 다시 보고 싶으면 필터를 해제하세요.

오류가 표시된 워크플로우만 보려면 **Has issues**(문제 있음)를 사용하세요.

![Filters 패널에서 워크플로우 상태, 에셋 유형, 폴더로 맵을 좁힐 수 있어요.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352867/original/Yq0zOrnIBqdEdrI6BCJf_0pjS6YXaZlbTQ.jpg?1793135780)

**Filters**(필터) 패널에서 워크플로우 상태, 에셋 유형, 폴더로 맵을 좁힐 수 있어요.

## 맵 데이터 새로고침

**Refresh map data**(맵 데이터 새로고침)를 누르면 맵 데이터를 다시 불러와요. 이 버튼에는 데이터가 마지막으로 업데이트된 시점도 함께 표시돼요.

찾는 워크플로우가 보이지 않을 때는 먼저 적용된 필터를 확인하세요.

## 워크플로우가 안 보이거나 맵이 느릴 때

**워크플로우가 보이지 않아요**

1. 적용된 필터를 확인하고, 워크플로우를 가릴 수 있는 필터는 해제하세요.
2. 워크플로우 이름으로 검색하세요.
3. 그래도 보이지 않으면 **Give feedback**(피드백 보내기)을 누르고 워크플로우 이름을 함께 적어 보내세요.

**연결선이 열리지 않아요**

맵을 확대한 다음 선을 다시 클릭하세요. 가장 넓게 축소한 상태에서는 선을 선택할 수 없어요.

**맵이 느리거나 불러와지지 않아요**

규모가 큰 계정은 브라우저에서 그래픽 가속을 켜 두어야 해요. 해당 설정을 확인하고, 매우 큰 계정이라면 **2D**로 바꿔 보세요.

## 자주 묻는 질문

### 전체 맵으로 돌아가려면 어떻게 하나요?

**Fit**을 누르세요. 워크플로우가 가려져 있다면 필터도 확인해서 해제하세요.

### if/else 안에서 쓰인 에셋도 검색할 수 있나요?

네. 맵에는 내부 로직 단계가 노드로 표시되지 않지만, 검색하면 해당 참조를 찾을 수 있어요.

### 맵 데이터가 언제 업데이트됐는지는 어디서 볼 수 있나요?

**Refresh map data**에서 마지막 업데이트 정보를 볼 수 있어요.
