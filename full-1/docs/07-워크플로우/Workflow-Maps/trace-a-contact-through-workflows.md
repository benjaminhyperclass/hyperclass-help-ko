# 연락처가 거친 워크플로우 추적하기

연락처를 검색해서 워크플로우 기록을 확인하고, 살펴보려는 단계나 실행을 열어 볼 수 있어요.

## 연락처 추적으로 알 수 있는 것

연락처 추적은 "이 사람이 왜 이 메시지를 받았지?", "지금 자동화의 어느 단계에서 기다리고 있지?" 같은 궁금증을 확인할 때 써요.

기록에는 연락처가 거친 워크플로우, 각 이벤트가 일어난 시간, 워크플로우의 상태가 나와요. 상태는 완료, 대기 중, 오류 중 하나예요.

연락처 기록은 최근 60일까지 볼 수 있어요.

## 연락처 찾기

1. **자동화 > 워크플로우 > Workflow Maps**(워크플로우 맵)를 엽니다.
2. 맵 왼쪽 메뉴에서 **Contacts**(연락처)를 엽니다.
3. 연락처의 이름, 이메일, 전화번호 중 하나로 검색합니다.
4. 기록을 확인할 연락처를 선택합니다.

## 워크플로우 기록 읽기

**Workflows**(워크플로우) 탭과 **Timeline**(타임라인) 탭에서 연락처의 기록을 확인할 수 있어요.

각 행에는 워크플로우, 시간, 실행 상태가 표시돼요. 순서대로 따라가면 연락처가 어떤 워크플로우에 들어갔고, 어디에서 끝났는지, 기다렸는지, 오류가 났는지 알 수 있어요.

![Timeline 탭에 샘플 연락처의 워크플로우 기록과 실행 상태가 순서대로 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352908/original/ZKDVf9wWymOuS6aUefCsuQIPd61MkDfsQw.jpg?1793135921)

**Timeline** 탭에는 샘플 연락처의 워크플로우 기록과 실행 상태가 순서대로 표시돼요.

## 단계나 실행 열기

1. 연락처 기록에서 워크플로우를 클릭하면 연락처가 도달한 단계를 볼 수 있어요.
2. 단계를 클릭하면 해당 실행 시점의 워크플로우가 열려요.
3. 실행 세부 내용을 보면서 확인하려는 동작을 살펴봅니다.

예를 들어 연락처가 예상하지 못한 이메일에 대해 문의했다면, 맵에 설정된 연결만 보지 말고 해당 워크플로우를 찾아 실행 내용을 직접 확인해 보세요.

![워크플로우 미리보기에서 실행을 선택해 연락처가 완료한 단계와 강조 표시된 경로를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084352909/original/vRKgKYf_YXs0hU6mfd4-n6U5GHMHmhSRWg.jpg?1793135924)

실행을 선택하면 워크플로우 미리보기에서 연락처가 완료한 단계와 강조 표시된 경로를 확인할 수 있어요.

## 자주 묻는 질문

### 연락처를 얼마나 오래전 기록까지 추적할 수 있나요?

최근 60일까지의 기록을 볼 수 있어요.

### 이메일 주소나 전화번호로도 검색할 수 있나요?

네. 이름, 이메일, 전화번호로 검색할 수 있어요.

### 연락처가 어디에서 대기 중인지 볼 수 있나요?

기록에서 대기 중인 워크플로우를 확인할 수 있어요. 워크플로우를 클릭하면 연락처가 도달한 단계가 보여요.

### 정확한 실행을 열려면 어떻게 하나요?

연락처의 워크플로우 기록에서 해당 단계를 클릭하세요.
