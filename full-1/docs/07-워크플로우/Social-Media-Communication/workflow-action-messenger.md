# 워크플로우 액션 — Messenger(메신저)

**Messenger**(메신저) 액션은 Facebook Messenger로 연락처에게 메시지를 바로 보내는 워크플로우 액션이에요. 리마인더, 소식 안내, 프로모션 메시지 등을 보낼 때 쓸 수 있어요.

## 개요

**Messenger** 액션을 쓰면 Facebook Messenger로 연락처에게 메시지를 직접 보낼 수 있어요. 연락처가 워크플로우에서 이 액션에 도달하기 24시간 이내에, 연결된 Facebook 페이지로 메시지를 보낸 적이 있어야 해요. 그래야 Facebook의 메시징 정책에 맞게 메시지가 전달돼요.

## 액션 이름

**Messenger**

## 액션 설명

**Messenger** 액션은 Facebook Messenger로 맞춤 메시지를 보내는 액션이에요. 최근 24시간 이내에 연결된 Facebook 페이지와 상호작용한 연락처와 소통할 때 알맞아요. 리마인더, 소식 안내, 프로모션 메시지처럼 다양한 용도로 쓸 수 있어요.

### 액션 설정 방법

1. 원하는 워크플로우에 **Messenger** 액션을 끌어다 놓아요.
2. 자주 쓰는 메시지를 템플릿으로 만들어 두었다면, 사용할 템플릿을 선택해요. (선택 사항)
3. 메시지 입력란에 보낼 내용을 입력해요. 커스텀 값을 쓰면 연락처 정보에 맞춰 내용을 개인화할 수 있어요.
4. 메시지에 파일이나 미디어를 함께 보내려면 **Add attachment**(첨부 파일 추가)를 클릭해요. 이미지, 문서, 프로모션 자료 등을 보낼 수 있어요. (선택 사항)
5. 파일이 온라인에 올라가 있다면 **+ Add** 버튼을 클릭해 URL로 파일을 추가해요. (선택 사항)
6. 마무리하기 전에 **Send Test SMS**(테스트 SMS 발송)로 수신자에게 메시지가 어떻게 보이는지 미리 확인해요. 형식이 올바른지, 내용이 정확한지 점검할 수 있어요. (선택 사항)

## 예시

- **Trigger**(트리거): **Contact Form Submission**(연락처 폼 제출)
  - **Condition**(조건): Facebook 광고 캠페인을 통해 연락처 폼이 제출된 경우
  - **Action**(액션): **Messenger**
    - **Message**: "문의해 주셔서 감사합니다! Facebook 광고를 통해 보내 주신 문의를 잘 받았어요. 담당 팀이 곧 연락드릴게요."
    - **Template**: 메시지 목적에 맞는 템플릿이 있다면 선택해요.
    - **Add Attachment**: 캠페인과 관련된 브로슈어나 이미지를 첨부해요.

워크플로우에 **Messenger** 액션을 넣으면, 많은 사람이 쓰는 메신저로 개인화된 메시지를 제때 보내 고객과 꾸준히 소통할 수 있어요.
