# 워크플로우 트리거 — Group Access Granted(그룹 접근 권한 부여됨)

**Group Access Granted** 트리거를 쓰면 그룹 접근 권한 관리를 자동화할 수 있어요. 커뮤니티 안에서 소통이 더 원활해지고 사용 경험도 좋아져요.

## 트리거 이름

Group Access Granted

## 트리거 설명

커뮤니티 안의 특정 그룹에 사용자가 접근 권한을 받으면 이 트리거가 실행돼요. 사용자에게 필요한 알림을 제때 보내고, 관련 콘텐츠와 멤버들과 바로 소통하도록 도울 수 있어요.

## 설정 방법

1. 하이퍼클래스 계정에서 **워크플로우 빌더**를 열어요.
2. 새 워크플로우를 만들어요.
   - **Create a Workflow**(워크플로우 만들기)를 클릭해요.
   - 트리거 유형으로 **Group Access Granted**(그룹 접근 권한 부여됨)를 선택해요.
3. 트리거 세부 내용을 설정해요.
   - 어떤 그룹의 접근 권한이 부여되는지 지정해요.
   - 이어서 자동으로 실행할 액션을 추가해요(예: 환영 메시지나 알림 보내기).
4. 워크플로우를 테스트해요. 제한된 환경에서 테스트해서 의도한 대로 동작하는지 확인하세요.
5. 확인이 끝나면 워크플로우를 저장하고 활성화해요.

## 예시

새 멤버가 독서 모임 커뮤니티에 가입하면 "독서 토론" 그룹에 자동으로 접근 권한을 부여하는 워크플로우를 만들 수 있어요. 그러면 멤버가 예정된 토론 소식을 바로 받고, 다른 멤버들과도 곧바로 소통할 수 있어요.
