# 워크플로우 액션 — Update Associated Record for Contact(연락처의 연결된 레코드 업데이트)

연락처에 연결된 커스텀 오브젝트 레코드의 필드를 워크플로우가 자동으로 수정하게 하는 액션이에요. 직접 고치지 않아도 중요한 정보를 항상 최신 상태로 유지하고 싶을 때 쓰세요.

## 개요

**Update an Associated Record**(연결된 레코드 업데이트) 액션을 쓰면 연락처에 연결된 커스텀 오브젝트의 특정 필드를 수정할 수 있어요. 사람이 일일이 고치지 않아도 핵심 정보가 정확하고 최신 상태로 유지돼요.

---

## 액션 이름

**Update Associated Record for Contact**(연락처의 연결된 레코드 업데이트)

## 액션 설명

![액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041053104/original/i1jCeUn69LXyTgcgnRKn9rEdCkggGSm_tw.png?1738755088)

이 액션은 연락처에 연결된 기존 커스텀 오브젝트 레코드를 업데이트해요. 선택한 연결 레이블에 따라 레코드 한 개만 업데이트할 수도 있고, 여러 개를 한꺼번에 업데이트할 수도 있어요.

---

## 액션 상세 정보

- 서브 계정에서 커스텀 오브젝트를 만들고, 그중 하나 이상의 오브젝트와 연락처 사이에 연결 레이블을 만든 뒤에야 이 액션을 쓸 수 있어요.
- 선택한 레코드 안의 필드를 하나 이상 업데이트해요.
- 연결 레이블로 업데이트할 레코드를 정해요. **All associated records**(연결된 모든 레코드)를 선택하면 연결된 레코드를 모두 업데이트할 수도 있어요.
- 커스텀 값과 커스텀 필드 머지 필드를 사용해 오브젝트 레코드에 정보를 넣을 수도 있어요.

## 예시: 여행 잔여 좌석 추적

<!-- 검토 필요: 원문 내용이 서로 다름 (예시 제목은 여행 잔여 좌석 추적인데 본문은 제품 보증 관리 내용임) -->

가전제품 회사에서 보증이 있는 제품을 판매하고, 제품마다 보증 커스텀 오브젝트로 다음 정보를 관리한다고 해 볼게요.

- 보증 시작일
- 보증 만료일
- 서비스 이력

제품을 구매하면 보증 시작일이 자동으로 입력되어야 하고, 보증 요청이 들어오면 서비스 이력 필드가 업데이트되어야 해요.

### 설정 예시 (서비스 요청 후 보증 정보를 업데이트하는 경우)

1. **Object to Update**(업데이트할 오브젝트) → 보증
2. **Association Label**(연결 레이블) → 구매한 상품
3. **Fields to Update**(업데이트할 필드)
   - 서비스 이력 → 서비스 내용 추가
   - 마지막 서비스일 → 오늘 날짜로 설정

<!-- 검토 필요: 원문 내용이 서로 다름(앞에서 소개한 오브젝트 필드 목록에 '마지막 서비스일'이 없음) -->

### 동작 방식

- 제품을 구매하면 **Create an Associated Record**(연결된 레코드 만들기) 액션으로 보증 시작일이 입력돼요.
- 고객이 서비스 요청을 제출하면 워크플로우가 **Update Associated Record** 액션을 실행해요.
  - 서비스 이력 필드에 진행한 서비스 내용이 업데이트돼요.
  - 마지막 서비스일이 오늘 날짜로 설정돼요.

이렇게 하면 회사는 제품별 서비스 기록을 최신 상태로 관리할 수 있고, 보증 추적과 보증 요청 처리도 원활해져요.
