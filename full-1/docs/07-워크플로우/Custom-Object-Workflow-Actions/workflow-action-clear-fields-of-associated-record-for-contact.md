# 워크플로우 액션 — Clear Fields of Associated Record for Contact(연락처의 연결된 레코드 필드 지우기)

연락처에 연결된 커스텀 오브젝트 레코드에서 선택한 필드의 값만 지우는 워크플로우 액션이에요. 오래된 정보를 비우거나, 폼 입력값을 초기화하거나, 특정 조건을 처리할 때 사용해요.

## 개요

**Clear Fields of an Associated Record**(연결된 레코드의 필드 지우기) 액션은 연락처에 연결된 커스텀 오브젝트의 특정 필드를 초기화해요. 오래된 정보를 지우거나 폼 입력값을 초기화할 때, 또는 워크플로우에서 특별한 조건을 처리할 때 유용해요.

## 액션 이름

**Clear Fields of Associated Record for Contact**(연락처의 연결된 레코드 필드 지우기)

## 액션 설명

이 액션은 커스텀 오브젝트에서 원하는 필드를 골라 값을 지워요. 레코드 자체는 그대로 남아요. 어떤 레코드의 필드를 지울지는 연결 레이블(association label)이 정해요.

## 액션 상세 정보

- 서브 계정에 커스텀 오브젝트를 만들고, 그중 하나 이상의 오브젝트와 연락처 사이에 연결 레이블을 만든 뒤에만 이 액션을 쓸 수 있어요.
- 액션이 작동하려면 커스텀 오브젝트와 연락처 사이에 연결이 하나 이상 있어야 해요.
- 초기화할 필드를 여러 개 선택할 수 있어요.
- 이 액션은 레코드를 삭제하지 않아요. 선택한 필드의 값만 지워요.

## 예시

소매 업체가 로열티 프로그램 커스텀 오브젝트로 고객의 로열티 포인트를 관리한다고 해 볼게요. 고객이 포인트를 리워드로 교환하면, 교환 내역이 반영되도록 로열티 포인트 필드를 비워야 해요.

워크플로우는 특정 날짜에 맞춰 트리거할 수 없어요. 그래서 포인트 교환 요청이 처리될 때처럼 관련 이벤트가 발생했을 때 이 액션이 실행되도록 설정해요.

#### 설정 예시

1. **Object to Update**(업데이트할 오브젝트) → 로열티 프로그램
2. **Association Label**(연결 레이블) → 고객 리워드
3. **Fields to Clear**(지울 필드):
   - 로열티 포인트
   - 마지막 교환일

#### 동작 방식

- 고객이 포인트를 교환하면 워크플로우가 실행되어 로열티 포인트 필드를 지워요.
- 마지막 교환일 필드도 함께 초기화되어, 이후 교환 내역을 정확하게 기록할 수 있어요.
- 이미 교환한 포인트를 실수로 다시 쓰는 일을 막을 수 있어요. 고객의 로열티 레코드는 그대로 남아요.

이렇게 하면 로열티 포인트 교환 내역을 정확하게 관리하고, 고객이 교환한 포인트를 다시 쓰지 못하게 할 수 있어요.
