# 워크플로우 액션 — Create Associated Record for Contact(연락처 연관 레코드 만들기)

연락처 기반 워크플로우에서 커스텀 오브젝트 레코드를 새로 만들고, 그 레코드를 연락처와 연결하는 액션이에요. 연락처에 딸린 부동산, 계약처럼 커스텀 오브젝트로 관리하는 항목을 다룰 때 유용해요.

## 액션 이름

**Create Associated Record for Contact**(연락처 연관 레코드 만들기)

## 액션 설명

![액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041052361/original/3dCs8bbLAWbHlPfWuwNbASA2jKu2OBKKfg.png?1738754630)워크플로우 안에서 커스텀 오브젝트 레코드를 바로 만들고, 그 레코드를 연락처와 연결할 수 있어요. 만들 수 있는 오브젝트는 서브 계정에 설정된 커스텀 오브젝트에 따라 달라져요.

## 액션 상세 정보

- 서브 계정에 커스텀 오브젝트를 먼저 만들고, 그중 하나 이상의 오브젝트와 연락처 사이에 연관 레이블을 만들어 두어야 이 액션을 쓸 수 있어요.
- 새 오브젝트 레코드에 여러 필드를 지정할 수 있어요.
- 연관 레이블을 지정하면 연락처와 커스텀 오브젝트가 어떤 관계인지 구분할 수 있어요.
- 새로 만든 레코드는 선택한 레이블로 연락처에 자동으로 연결돼요.
- 커스텀 값과 커스텀 필드 병합 필드를 사용해서 오브젝트에 정보를 채울 수도 있어요.

## 예시

태양광 설치 회사가 설치 관련 주요 날짜를 관리해야 한다고 가정해 볼게요.

- 현장 조사일
- 설치일

기회가 "고객전환성공" 상태가 되면, 이 날짜들을 관리할 "설치" 커스텀 오브젝트 레코드가 자동으로 만들어지게 할 수 있어요.

**설정 예시**

1. **Object Record to Create**(만들 오브젝트 레코드) → 설치
2. **Fields**(필드)
   - 현장 조사일 → 오늘 날짜로 자동 입력
   - 설치일 → 일정에 따라 자동 입력
3. **Association Label**(연관 레이블) → 설치 예정

워크플로우가 실행되면 설치 레코드가 만들어지고 연락처에 연결돼요. 그래서 날짜를 한곳에서 쉽게 추적할 수 있어요.
