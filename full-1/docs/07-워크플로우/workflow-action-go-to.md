# 워크플로우 액션 — Go To(이동)

**Go To**(이동) 액션을 쓰면 워크플로우 안에서 연락처를 한 단계에서 다른 단계로 바로 건너뛰게 할 수 있어요.

[동영상](https://www.youtube.com/embed/owRWoMHUxJQ?&wmode=opaque)

사용 방법은 간단해요.

1. 워크플로우에 **Go To** 액션을 추가하세요.
2. **Go To** 액션에서 연락처를 보내려는 위치까지 선을 그어 연결하세요.

이렇게 하면 설정이 끝나요.
