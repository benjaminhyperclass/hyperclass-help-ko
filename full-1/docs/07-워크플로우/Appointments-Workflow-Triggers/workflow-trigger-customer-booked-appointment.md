# 워크플로우 트리거 — Customer Booked Appointment(고객 예약 완료)

**Customer Booked Appointment**(고객 예약 완료) 트리거는 고객이 직접 예약을 잡을 때 워크플로우를 자동으로 시작해요. 이 문서에서는 트리거가 어떻게 동작하는지, 어떤 장점이 있는지, 설정 방법과 활용 사례를 설명해요.

## Customer Booked Appointment 트리거란?

고객이 예약 링크나 온라인 예약 시스템으로 직접 예약하면, 팀이 개입하지 않아도 이 트리거가 실행돼요. 예약을 기준으로 후속 조치, 알림, 팀 공지를 자동화하고 싶을 때 쓰세요.

이 트리거는 일반 예약에서만 작동해요. 반복 예약은 지원하지 않아요.

## 이 트리거의 장점

예약과 관련된 워크플로우를 자동화하면 업무 효율과 고객 경험을 함께 높일 수 있어요.

- 자동 알림: 이메일이나 SMS로 예약 알림을 제때 보내서 노쇼를 줄여요.
- 고객 경험 개선: 예약 확인 메시지와 후속 메시지를 자동으로 보내 고객이 계속 안내를 받을 수 있어요.
- 게스트 등록 지원: 대표 연락처뿐 아니라 예약에 포함된 게스트에게도 워크플로우를 실행할 수 있어요. 여러 명이 참여하는 예약이라면 모든 참석자에게 알림, 확인, 후속 메시지를 보낼 수 있어요.
- 팀 알림 효율화: 예약이 잡힐 때마다 담당 팀원에게 자동으로 알려 줘요.
- 유연한 설정: 필터를 써서 특정 캘린더, 캘린더 그룹, 특정 태그를 가진 고객에게만 워크플로우를 실행할 수 있어요.
- 리소스 관리: 알림과 후속 조치를 자동화하면 팀이 일정을 직접 관리하는 대신 서비스에 집중할 수 있어요.

## Customer Booked Appointment 트리거 설정하기

워크플로우에 이 트리거를 추가하는 순서예요.

### 1. 워크플로우 빌더 열기

왼쪽 메뉴에서 **자동화**(Automation)로 이동해요. 새 워크플로우를 처음부터 만들거나, 이 트리거를 추가할 기존 워크플로우를 선택하세요.

### 2. 트리거 추가하기

1. **Add New Trigger**(새 트리거 추가)를 클릭해요.
2. 검색창에 **Customer Booked Appointment**를 입력해요.
3. 목록에서 해당 트리거를 선택해요.

![새 트리거 추가 화면에서 Customer Booked Appointment 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039511639/original/QEwrxU5nNDDAWa5ooiHjxx9uGsDQpXDLhg.png?1736393761)

### 3. 트리거 이름 정하기

나중에 알아보기 쉬운 이름을 입력해요. 예를 들어 "신규 예약 트리거"처럼 쓸 수 있어요.

![트리거 이름 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068508556/original/mu54oUjD-RgoXPvg080TspkhC-hlttuL-Q.png?1775457382)

### 4. 워크플로우 등록 대상 선택하기

트리거 이름을 입력한 다음, 트리거가 실행될 때 누구를 워크플로우에 등록할지 정해요. **Who should be enrolled into the workflow?**(워크플로우에 누구를 등록할까요?) 항목에서 세 가지 중 하나를 선택해요.

- **Contact only**(연락처만): 예약의 대표 연락처에게만 워크플로우를 실행해요. 기본값이에요.
- **Contact and Guests**(연락처와 게스트): 대표 연락처에게 한 번, 예약에 포함된 게스트 연락처에게 각각 한 번씩 워크플로우를 실행해요. 여러 명이 참여하는 예약에서 모든 참석자에게 알림이나 후속 메시지를 보낼 때 유용해요.
- **Guests only**(게스트만): 게스트 연락처에게만 워크플로우를 실행하고 대표 연락처는 건너뛰어요. 대표 연락처에게 이미 다른 워크플로우가 있어서 게스트만 대상으로 하고 싶을 때 쓰세요.

{% hint style="warning" %}
**Customer Booked Appointment** 트리거에서는 예약이 잡힌 **이후**에 추가된 게스트는 이 트리거로 등록되지 않아요. 예약 당시에 있던 게스트만 포함돼요.
{% endhint %}

### 5. 필터 설정하기

다음 필터로 트리거 조건을 좁힐 수 있어요.

- **Has Tag**(태그 보유): 특정 태그가 있는 고객이 예약할 때만 트리거를 실행하고 싶을 때 선택해요.
- **In Calendar**(캘린더 내): 특정 캘린더를 대상으로 해요. 선택한 캘린더에서 예약이 잡힐 때만 워크플로우가 실행돼요.
- **In Calendar Group**(캘린더 그룹 내): 캘린더 그룹을 대상으로 해요. 선택한 그룹에 속한 캘린더 중 어느 곳에서든 예약이 잡히면 워크플로우가 실행돼요.

![트리거 필터 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039511687/original/n4_hvmC9gRzuiDr8BmhogC3uwBodFFTN8A.png?1736393909)

### 6. 트리거 저장하기

1. 필터 설정을 마치면 트리거 패널에서 **Save**(저장) 버튼을 클릭해요.
2. 워크플로우 전체도 저장해야 해요. 오른쪽 위의 파란색 **Save** 버튼을 클릭하세요.

## 사용 사례

이 트리거를 활용할 수 있는 예시예요.

### 사용 사례 1. 예약 알림

시나리오: 치과에서 노쇼를 줄이려고 예약 24시간 전에 환자에게 알림을 자동으로 보내고 싶어요.

결과: 워크플로우가 예약 24시간 전에 환자에게 이메일과 SMS 알림을 보내서 방문율을 높여 줘요.

![예약 알림 워크플로우 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039511748/original/9Kilbs6sq3qCI1HuzyoO18UEqIcNUHQB-A.png?1736394204)

### 사용 사례 2. 예약 후 후속 안내

시나리오: 부동산 중개 회사에서 매물 방문을 예약한 고객에게 후속 이메일을 보내 상세 내용을 확인하고 필요한 안내를 전하고 싶어요.

결과: 워크플로우가 예약 상세 정보, 매물 위치 안내, 준비 서류 체크리스트가 담긴 확인 이메일을 보내요.

### 사용 사례 3. VIP 고객 예약 시 내부 알림

시나리오: 재무 자문 회사에서 VIP 고객이 예약할 때마다 시니어 어드바이저에게 알리고 싶어요.

결과: 워크플로우가 시니어 어드바이저에게 내부 이메일 알림을 보내서 다가오는 예약을 미리 준비할 수 있어요.

### 사용 사례 4. 그룹 예약 관리

시나리오: 피트니스 센터에서 그룹 캘린더로 고객이 수업을 예약할 때마다 알림을 자동으로 보내 그룹 트레이닝을 관리하고 싶어요.

결과: 워크플로우가 고객에게 확인 이메일을, 담당 트레이너에게 내부 알림을 보내요.

### 사용 사례 5. 여러 참석자에게 예약 알림 보내기

시나리오: 컨설팅 회사에서 대표 고객과 게스트로 참여하는 다른 이해관계자가 함께하는 전략 세션을 잡아요. 모든 참석자에게 확인 이메일과 준비 체크리스트를 보내고 싶어요.

결과: 등록 대상 설정에서 **Contact and Guests**를 선택하면, 워크플로우가 대표 연락처와 각 게스트에게 개인별 확인 이메일과 준비 체크리스트를 보내요. 모든 참석자가 준비된 상태로 참석할 수 있어요.

## 자주 묻는 질문

### 이 트리거를 반복 예약에도 쓸 수 있나요?

아니요. **Customer Booked Appointment** 트리거는 일반(1회성) 예약에서만 작동해요. 반복 예약은 지원하지 않아요.

### 예약 유형별로 다른 워크플로우를 실행하려면 어떻게 하나요?

**In Calendar**나 **In Calendar Group** 같은 필터로 특정 예약 유형을 지정하고, 유형별로 워크플로우를 따로 만드세요.

### 팀원이 고객 대신 직접 예약을 잡으면 어떻게 되나요?

이 트리거는 고객이 예약 링크로 직접 예약할 때만 실행돼요. 팀원이 수동으로 잡은 예약은 워크플로우를 실행하지 않아요.

### 예약 48시간 전과 24시간 전처럼 여러 번 알림을 보낼 수 있나요?

네. 같은 워크플로우 안에 알림 액션을 여러 개 추가하고, 각각 대기 시간을 다르게 설정하면 돼요. 예를 들어 48시간 기다린 뒤 첫 번째 알림을 보내고, 24시간 더 기다린 뒤 두 번째 알림을 보내도록 만들 수 있어요.

### VIP 고객의 예약은 어떻게 따로 관리하나요?

**Has Tag** 필터를 쓰면 돼요. "VIP 고객" 같은 특정 태그가 있는 고객이 예약할 때만 실행되는 워크플로우를 만들 수 있어요. 중요한 고객에게 제때 후속 조치를 하고 별도로 응대할 수 있어요.

### 예약 게스트에게도 워크플로우 알림을 보낼 수 있나요?

네. 트리거를 설정할 때 **Who should be enrolled into the workflow?** 항목에서 **Contact and Guests** 또는 **Guests only**를 선택하세요. 예약에 포함된 게스트 연락처에게도 워크플로우가 실행돼요.

### 예약이 잡힌 뒤에 게스트를 추가하면 어떻게 되나요?

예약이 잡힌 뒤에 추가한 게스트는 기존 트리거 이벤트로 등록되지 않아요. 예약 당시에 있던 게스트만 포함돼요.

### 등록 대상 설정을 바꾸면 기존 워크플로우에 영향이 있나요?

아니요. 기존 트리거 설정은 기본값인 **Contact only** 그대로 유지돼요. 게스트를 포함하려면 직접 등록 대상 설정을 바꿔야 해요.
