# 워크플로우 트리거 — Contact Created(연락처 생성)

**Contact Created**(연락처 생성) 트리거는 새 연락처가 추가될 때 워크플로우를 시작해요. 환영 이메일 보내기, 영업 담당자에게 리드 배정하기, CRM 데이터 실시간 업데이트 같은 작업을 자동으로 처리할 수 있어요. 이 문서에서는 트리거의 개념과 장점, 설정 방법, 자주 묻는 질문을 안내해요.

## Contact Created 트리거란?

**Contact Created** 트리거는 CRM에 새 연락처가 추가될 때마다 워크플로우를 실행해요. 후속 연락을 자동화하고, 새 리드에게 바로 응대하고, 연락처 관리를 간소화할 수 있어요. 직접 추가하든, 폼 제출로 생기든, 연동으로 들어오든 연락처가 만들어진 방식과 상관없이 작동해요.

## Contact Created 트리거의 장점

- 새 연락처 응대 자동화: 사람이 직접 처리하지 않아도 새 연락처에게 바로 응답이 가요.
- 영업·리드 배정 간소화: 미리 정한 필터에 따라 영업 담당자에게 리드를 배정해서 후속 연락이 늦어지는 일을 줄여요.
- CRM 데이터 관리 개선: CRM 필드가 자동으로 업데이트되어 수동 입력 실수가 줄어요.
- 고객 경험 향상: 연락처가 만들어지는 즉시 환영 이메일, 온보딩 메시지, 안내 정보를 보낼 수 있어요.

## Contact Created 트리거 설정하기

트리거를 제대로 설정해 두면 원하는 때에 정확히 자동화가 실행돼요. 액션을 추가하기 전에 어떤 연락처에서, 언제 워크플로우를 시작할지 먼저 정하세요. 아래 순서대로 설정하면 돼요.

### 새 워크플로우 만들기

**자동화**(Automations)로 이동해 **+ Create Workflow**(워크플로우 만들기)를 클릭하고 **처음부터 시작**을 선택하세요. 이미 만든 워크플로우를 편집해도 돼요.

![자동화에서 워크플로우를 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043021619/original/KClg8zGU0-l-yCN24tTR4cs5dz_r5_UErQ.png?1741683874)

### 트리거 추가하기

**Add New Workflow Trigger**(새 워크플로우 트리거 추가)를 클릭하고 목록에서 **Contact Created**를 선택하세요.

![트리거 목록에서 Contact Created를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043023262/original/tzX7wIoN8po8anxDXhAUx5LDfPEVVNozYA.png?1741684491)

### 트리거 이름 정하기

나중에 쉽게 알아볼 수 있도록 **Trigger Name**(트리거 이름)에 이름을 입력하세요. 예를 들어 "신규 연락처 환영 시퀀스"처럼 쓸 수 있어요.

![트리거 이름을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043023252/original/P0-Lt6U1wrbgCOz--oL9DWmwnuJFRfSrXA.png?1741684479)

### 필터 적용하기

필터를 쓰면 워크플로우가 시작되는 조건을 좁힐 수 있어요. 조건에 맞는 연락처만 자동화에 들어오기 때문에, 새 연락처 전체에 불필요한 액션이 실행되는 일을 막을 수 있어요. 사용할 수 있는 필터는 다음과 같아요.

1. **Tag**(태그): 어떤 태그가 붙은 연락처를 워크플로우에 들어오게 할지 정해요.
   - 연산자(모두 여러 개 선택할 수 있어요):
     - **Equals to**(같음) / **Not equals to**(같지 않음)
     - **Any of**(다음 중 하나): 선택한 태그 중 하나라도 있으면 실행돼요.
     - **None of**(다음 중 해당 없음): 선택한 태그가 하나도 없으면 실행돼요.

2. 여러 개의 **Tag** 필터(**AND**(그리고) 조건): 같은 트리거에 **Tag** 필터를 두 개 이상 추가하면 포함·제외 조건을 더 세밀하게 만들 수 있어요.
   - 예: **Tag Equals to** “리드” **AND** **Tag Not equals to** “저품질”

태그 트리거에 대한 자세한 내용은 [워크플로우 트리거 — Contact Tag(연락처 태그)](../workflow-trigger-contact-tag.md) 문서를 참고하세요.

![Tag 필터를 여러 개 추가한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064968474/original/BCsNUXWTzMMtlUfZnZfei3v74v4hkgpXJw.png?1771224535)

3. **Custom Fields**(커스텀 필드): CRM에 "업종", "리드 점수", "고객 카테고리" 같은 커스텀 필드가 있다면, 이 필터로 특정 조건을 만족할 때만 워크플로우를 시작할 수 있어요. 업종이나 참여도, 그 밖의 맞춤 속성에 따라 리드를 나눌 때 유용해요.

![Custom Fields 필터를 설정한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064338470/original/OEh_C0Lf568PF-zBCKVEk2rG_7Dy-P_hHg.png?1770373875)

## 자주 묻는 질문

### 일괄 가져오기로 추가한 연락처에도 이 트리거가 작동하나요?

아니요. **Contact Created** 트리거는 연락처를 직접 추가하거나, 폼으로 제출하거나, API로 만들거나, 연동으로 추가했을 때만 작동해요. 자동화가 한꺼번에 몰리는 사고를 막으려고 일괄 가져오기에는 이 워크플로우가 실행되지 않아요. 가져온 연락처에 자동화가 필요하면 수동 등록을 사용하는 별도 워크플로우를 만들어 보세요.

### 특정 연락처에서만 워크플로우가 시작되게 할 수 있나요?

네, 필터를 적용하면 돼요. 태그, 커스텀 필드, 유형을 기준으로 대상을 정할 수 있어요. 예를 들어 연락처에 “새 리드” 태그가 붙었을 때만 실행되게 설정할 수 있어요. 필요한 연락처만 워크플로우를 시작하므로 불필요한 자동화를 막을 수 있어요.

### 같은 연락처가 여러 번 추가되면 워크플로우가 다시 실행되나요?

같은 이메일이나 전화번호의 연락처가 다시 추가되면, CRM의 중복 감지 설정에 따라 기존 연락처로 인식될 수 있어요. 기존 기록과 병합되면 워크플로우는 다시 실행되지 않아요. 반대로 완전히 새로운 연락처로 처리되면 워크플로우가 그대로 실행돼요.

### 이 트리거로 새 연락처를 팀원에게 자동 배정할 수 있나요?

네, 특정 조건에 따라 영업 담당자나 팀원에게 새 연락처를 배정하도록 워크플로우를 설정할 수 있어요. 지역, 태그, 유형 같은 필터를 쓰면 돼요. 순차 배정(라운드 로빈)을 설정하면 팀원에게 리드를 고르게 나눠 줄 수도 있어요.

### 이 워크플로우가 잘 작동하는지 어떻게 확인하나요?

워크플로우 실행 로그에서 트리거가 얼마나 자주 실행됐는지, 어떤 연락처가 처리됐는지 볼 수 있어요. 이메일 액션이라면 오픈율과 응답률을 확인해 참여도를 파악할 수 있어요. 연락처를 영업 담당자에게 배정하는 워크플로우라면 후속 조치 완료율로 효과를 가늠할 수 있어요. 워크플로우 성과를 주기적으로 살펴보면 자동화를 더 효율적으로 개선할 수 있어요.
