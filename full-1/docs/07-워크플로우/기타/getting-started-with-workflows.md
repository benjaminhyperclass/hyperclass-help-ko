# 워크플로우 시작하기

워크플로우는 반복되는 일을 자동으로 처리해 주는 기능이에요. 한 번 설정해 두면 트리거에 맞춰 알아서 실행되고, 정해 둔 액션을 순서대로 수행해요. 이 문서에서는 워크플로우의 기본 개념과 만드는 순서, 문제가 생겼을 때 확인할 점을 안내해요.

워크플로우로 리드 관리, 후속 연락 자동화, 메시지 발송 등 비즈니스 전반의 업무를 간소화할 수 있어요.

## 워크플로우란?

워크플로우는 특정 이벤트가 일어나면 자동으로 실행되는 액션의 흐름이에요.

예시:

- 리드가 폼을 제출하면 → 확인 이메일과 SMS 보내기
- 고객이 예약하면 → 팀에 알리고 후속 연락 보내기

워크플로우는 두 가지로 구성돼요.

- 트리거: 워크플로우를 시작해요.
- 액션: 트리거가 실행된 뒤에 수행하는 작업이에요.

## 워크플로우 트리거

트리거는 워크플로우가 언제 시작할지 정해요.

예시:

- **Form submitted**(폼 제출)
- **Appointment booked**(예약 완료)
- **Payment received**(결제 완료)

## 워크플로우 액션

액션은 트리거가 실행된 뒤에 이어지는 단계예요.

예시:

- 이메일 또는 SMS 보내기
- 연락처 만들기 또는 업데이트
- 작업이나 기회 배정

## 자동화하면 좋은 업무

다음과 같은 반복 업무를 자동화해 보세요.

- 리드 육성 캠페인
- 예약 일정 잡기
- 후속 연락과 알림
- 고객 온보딩
- 피드백 수집
- CRM 업데이트

자동화하면 업무 효율과 일관성이 높아지고, 규모를 키우기도 쉬워져요.

## 워크플로우 레시피: 기본 제공 템플릿

하이퍼클래스는 빠르게 시작할 수 있도록 기본 템플릿을 제공해요.

템플릿으로 이런 일을 할 수 있어요.

- 만들어진 워크플로우를 그대로 사용해요.
- 내 비즈니스에 맞게 수정해요.
- 처음부터 만드는 시간을 줄여요.

## 워크플로우 만드는 순서

워크플로우는 크게 세 단계로 만들어요.

### 1단계: 트리거 선택

워크플로우를 시작할 이벤트를 선택해요.

1. **Add New Trigger**(새 트리거 추가)를 클릭하세요.
2. 사용할 수 있는 트리거 중에서 선택하세요.

### 2단계: 트리거 필터 추가(선택)

필터를 쓰면 워크플로우가 실행되는 조건을 더 좁힐 수 있어요.

예시:

- 걸려 오는 전화일 때만 실행
- 특정 전화번호일 때만 실행

### 3단계: 워크플로우 액션 추가

액션은 트리거 이후에 일어날 일을 정해요.

1. **Add Action**(액션 추가)을 클릭하세요.
2. 원하는 액션을 선택하세요.

## 워크플로우 랜딩 페이지(개선된 화면)

워크플로우 랜딩 페이지가 더 쉽게 시작할 수 있도록 새로 바뀌었어요.

이제 다음 세 가지 중에서 고를 수 있어요.

- **Build using AI**(AI로 만들기): 만들고 싶은 워크플로우를 설명하면 AI가 만들어 줘요.
- **템플릿 둘러보기**: 미리 만들어 둔 워크플로우 중에서 골라요.
- **Create Workflow**(워크플로우 만들기): 처음부터 시작해요.

처음 쓰는 사용자도 자신에게 맞는 방법을 빠르게 고를 수 있어요.

**실험실**에서 **AI Builder**(AI 빌더)를 꺼 두었다면 이전 랜딩 화면이 표시돼요.

## 고급 워크플로우 유형

### IF/Else 조건

**IF/Else**(조건 분기)를 쓰면 조건에 따라 연락처를 서로 다른 경로로 나눌 수 있어요.

## 여러 워크플로우 연결하기

여러 워크플로우를 연결하면 파이프라인 전체나 고객 여정을 자동화할 수 있어요.

## 웹훅(트리거와 액션)

웹훅을 쓰면 하이퍼클래스가 외부 시스템과 데이터를 주고받을 수 있어요. 그래서 여러 플랫폼에 걸쳐 워크플로우를 자동화할 수 있어요.

## 문제 해결

1. 새 연락처로 테스트하세요. 워크플로우에 들어온 적이 없는 연락처를 써야 이전 등록 이력이나 재진입 제한 때문인지 가려낼 수 있어요.
2. 트리거 필터를 확인하세요. 연락처가 워크플로우에 들어오는 데 필요한 트리거 조건과 필터를 모두 충족하는지 살펴보세요.
3. 재진입 설정을 확인하세요. 같은 연락처가 여러 번 들어와야 하는 경우라면, 워크플로우가 반복 등록을 허용하는지 확인하세요.
4. 라이브 동작과 테스트 모드를 비교하세요. 테스트 모드에서는 되는데 실제 연락처에서는 안 된다면, 실제 트리거 이벤트와 등록 조건을 점검하세요.
5. 실행 기록과 오류 로그를 확인하세요. 워크플로우 실행 기록에서 건너뛴 단계, 실패한 액션, 오류 메시지를 찾아보면 원인을 파악하는 데 도움이 돼요.
6. 근거를 갖춰 문의하세요. 문제가 계속되면 하이퍼클래스 고객지원에 문의할 때 해당 연락처, 워크플로우 이름, 테스트한 대략적인 시각, 스크린샷, 관련 실행 기록과 오류 내용을 함께 알려 주세요.

## 자주 묻는 질문

### 트리거와 액션은 어떻게 다른가요?

트리거는 특정 이벤트가 일어났을 때 워크플로우를 시작해요. 액션은 트리거가 실행된 뒤에 이어서 수행하는 단계예요.

### 워크플로우 하나에 트리거를 여러 개 쓸 수 있나요?

네, 쓸 수 있어요. 트리거를 여러 개 추가하면 연락처가 다양한 경로로 워크플로우에 들어올 수 있어요.

### 필터는 꼭 설정해야 하나요?

아니요, 필터는 선택 사항이에요. 다만 워크플로우가 특정 조건에서만 실행되게 하려면 필터를 쓰는 것을 권장해요.

### 워크플로우를 만든 뒤에도 수정할 수 있나요?

네, 트리거와 필터, 액션을 언제든지 수정할 수 있어요.

### 워크플로우는 만들면 자동으로 실행되나요?

네, 워크플로우가 게시된 상태이고 트리거 조건이 맞으면 자동으로 실행돼요.

### 워크플로우가 제대로 작동하지 않으면 어떻게 하나요?

트리거 조건, 필터, 워크플로우 설정을 확인해 보세요. 새 연락처로 테스트해 보는 것도 권장해요.

### AI로 워크플로우를 만들 수 있나요?

네, 가능해요. 개선된 워크플로우 랜딩 페이지에서 **Build using AI**(AI로 만들기)를 선택해 만들고 싶은 워크플로우를 설명하면 AI가 만들어 줘요.
