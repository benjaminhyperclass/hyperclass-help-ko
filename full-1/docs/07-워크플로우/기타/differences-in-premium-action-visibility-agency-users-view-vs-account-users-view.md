# 프리미엄 액션이 꺼져 있을 때 보이는 화면 — 에이전시 관리자와 계정 사용자 비교

에이전시에서 하이퍼클래스 **Premium Actions**(프리미엄 액션)를 켜지 않은 경우, 에이전시 관리자와 계정 관리자·사용자에게 보이는 화면이 서로 달라요. 이 문서에서 두 화면을 비교해 볼 수 있어요.
