# 회사·사용자 지정 객체 워크플로우의 Send Email(이메일 보내기) 액션

회사와 사용자 지정 객체 워크플로우에서 연결된 연락처에게 자동으로 이메일을 보내는 방법을 안내해요. 연락처 워크플로우를 따로 만들 필요가 없어요. 회사나 사용자 지정 객체에서 이벤트가 생기면 연결 레이블로 수신 대상을 골라 이메일을 보낼 수 있어요.

{% hint style="info" %}
회사·사용자 지정 객체 워크플로우의 이메일 액션은 실험실 기능이에요. 사용하기 전에 **설정 > 실험실**에서 켜 주세요. 실험실 기능은 개발이 계속 진행 중이라, 사용자 의견에 따라 업데이트될 수 있어요.
{% endhint %}

## Send Email 액션이란?

**Send Email**(이메일 보내기) 액션은 하이퍼클래스의 회사·사용자 지정 객체 워크플로우에서 자동 이메일을 바로 보내는 액션이에요. 예전에는 이메일 액션을 연락처 워크플로우에서만 쓸 수 있었어요. 회사나 사용자 지정 객체에 연결된 연락처에게 이메일을 보내려면 워크플로우를 따로 만들거나 복잡한 변환 단계를 거쳐야 했어요.

이제는 회사나 사용자 지정 객체 이벤트를 기준으로 이메일을 자동 발송할 수 있어요. 연락처 워크플로우를 추가로 만들 필요가 없어요. 회사나 사용자 지정 객체 워크플로우에 이 액션을 추가하면 연결 레이블과 수신자 선택 옵션으로 이메일을 받을 연락처를 정해요.

회사·사용자 지정 객체와 연락처 사이에 설정된 연결 관계를 바탕으로, 워크플로우 트리거가 실행되면 메시지가 자동으로 발송돼요.

## 이런 때 활용해 보세요

- 고객 온보딩: 새 회사 또는 사용자 지정 객체 레코드가 만들어지면 환영 이메일을 보내요.
- 갱신 알림: 보험 계약 만료가 다가오면 계약자에게 안내 메일을 자동으로 보내요.
- 생일 축하: 반려동물 보호자에게 반려동물 생일 축하 메시지를 보내요.
- 매물 소식: 부동산 리드에게 매물과 부동산 정보를 자동으로 보내요.
- 내부 승인: 연결된 지원 담당자나 팀원에게 승인 요청을 보내요.
- 마케팅 후속 안내: 서비스 기록이나 진료 이력을 바탕으로 맞춤 후속 마케팅 이메일을 보내요.

## Send Email 액션 설정하기

회사 또는 사용자 지정 객체 워크플로우에서 **Send Email** 액션을 설정하는 순서예요.

1. 하이퍼클래스 계정에서 **설정 > 실험실**로 이동해요.
2. **Email Action in Company & Custom Object Workflows**(회사·사용자 지정 객체 워크플로우의 이메일 액션)를 찾아 켜요.

   ![실험실에서 이메일 액션 기능을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077245088/original/zW0xIXt7qL2-7oGnzkEujxosvp6stktMlg.png?1785416058)

3. **자동화 > 워크플로우**에서 회사 또는 사용자 지정 객체 워크플로우를 새로 만들거나 기존 워크플로우를 열어요.
4. 워크플로우에서 **+ Add**(추가)를 클릭해요.
5. **Actions**(액션) 패널의 **Communication**(커뮤니케이션) 섹션에서 **Send email**(이메일 보내기)을 선택해요. 검색창에 "Send email"을 입력해 바로 찾을 수도 있어요.

   ![액션 패널에서 Send email 액션을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077245335/original/aFQlf2w9cfxbghyNTCXvhsb_W2kudkpTow.png?1785416142)

6. **Email Recipients**(이메일 수신자) 드롭다운의 **Associations**(연결) 섹션에서 다음 중 하나를 선택해요.
   - **All associated contacts**(연결된 모든 연락처): 회사 또는 사용자 지정 객체에 연결된 모든 연락처에게 보내요.
   - **Most recently associated contact**(가장 최근에 연결된 연락처): 가장 최근에 연결된 연락처에게만 보내요. 사용자 지정 객체 워크플로우에서만 쓸 수 있어요.
   - **Earliest associated contact**(가장 먼저 연결된 연락처): 가장 먼저 연결된 연락처에게만 보내요. 사용자 지정 객체 워크플로우에서만 쓸 수 있어요.

   ![이메일 수신자 드롭다운에서 연결 옵션을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077245534/original/sNetnWzLL6UejE84FaYgq7pum_otrDLa0Q.png?1785416185)

7. (선택) 특정 유형의 연락처에게만 보내려면 **Association Label**(연결 레이블) 필드에서 레이블을 하나 이상 선택해요. 연락처와의 관계 유형을 기준으로 수신 대상이 걸러져요. 이 필드를 비워 두면 연결 유형으로 거르지 않고 **Email Recipients** 선택대로 발송돼요.

   {% hint style="info" %}
   **Association Label** 옵션은 현재 사용자 지정 객체 워크플로우에서만 지원해요. 회사 워크플로우에서는 이 필드가 보이지 않아요.
   {% endhint %}

8. 이메일 설정 항목을 채워요.
   - **From Name**(보내는 사람): 보내는 사람 이름을 입력해요.
   - **From Email**(보내는 이메일): 보내는 이메일 주소를 입력해요.
   - **Subject**(제목): 이메일 제목을 입력해요.
   - **Cc/Bcc**(참조/숨은 참조): 필요하면 참조나 숨은 참조 수신자를 추가해요.

   ![이메일 설정 항목을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077245636/original/qQ5R8EtbTeZa_Sv7iGfJwrLzOZOBH3a58A.png?1785416233)

9. 이메일 에디터에서 이메일 내용을 작성해요. 커스텀 필드, 개인화 토큰, 서식을 필요한 대로 넣을 수 있어요. 연결된 연락처와 회사 또는 사용자 지정 객체 레코드의 개인화 토큰을 모두 쓸 수 있어서 내용을 동적으로 맞춤 작성할 수 있어요. 에디터는 다른 워크플로우 이메일 액션과 같은 기능을 지원해요.

   ![이메일 에디터에서 내용을 작성하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077245680/original/I31f4om-cIJeBCTBxnMK5mRm0PjW3Ki6iw.png?1785416257)

10. **Save action**(작업 저장)을 클릭해 이메일 설정을 저장해요.
11. **Publish**(게시)를 클릭해 워크플로우를 게시해요. 워크플로우가 실행되면 선택한 연결 연락처에게 이메일이 자동으로 발송돼요.

{% hint style="warning" %}
**중요 사항**

- 이메일은 계정에 설정된 대량 이메일 발송 도메인(Bulk Email)으로 발송돼요.
- 이메일은 계정의 시간대 설정에 따라 발송돼요.
- **From Name**과 **From Email**을 비워 두면 계정 설정에 지정된 기본값으로 발송돼요.
- 한 연락처가 선택한 연결 레이블 여러 개에 해당해도 이메일은 한 번만 받아요. 중복 발송이 없도록 수신자 중복 제거가 자동으로 처리돼요.
{% endhint %}

## 자주 묻는 질문

### 이 기능을 쓰기 전에 실험실에서 켜야 하나요?

네, 현재 실험실 기능이라서 먼저 켜야 해요. **설정 > 실험실**에서 **Email Action in Company & Custom Object Workflows**를 켜면 회사·사용자 지정 객체 워크플로우에 **Send Email** 액션이 나타나요.

### 워크플로우 빌더에서 Send Email 액션은 어디에 있나요?

워크플로우에서 **+ Add**를 클릭하면 **Actions** 패널의 **Communication** 섹션에 **Send Email** 액션이 있어요. 검색창에 "Send email"을 입력해서 바로 찾을 수도 있어요.

### All associated contacts를 선택하는 것과 연결 레이블을 쓰는 것은 어떻게 달라요?

**Email Recipients** 드롭다운에서 **All associated contacts**를 선택하고 **Association Label**을 지정하지 않으면, 회사나 사용자 지정 객체에 연결된 모든 연락처에게 이메일이 가요. **Association Label** 필드에서 레이블을 지정하면 해당 관계 유형의 연락처에게만 발송돼요. 연결된 연락처 중 일부만 골라서 보낼 수 있어요.

### 한 연락처가 선택한 레이블 여러 개에 해당하면 어떻게 되나요?

이메일은 한 번만 받아요. 여러 연결 경로에 해당해도 수신자 중복 제거로 같은 연락처에게 중복 발송되지 않아요.

### 사용자 지정 객체 워크플로우에서 어떤 연결 연락처가 이메일을 받을지 고를 수 있나요?

네, 사용자 지정 객체 워크플로우에서 **Send Email** 액션을 설정할 때 **Email Recipients** 드롭다운의 **Associations** 섹션에서 정해요. 가장 먼저 연결된 연락처, 가장 최근에 연결된 연락처, 연결된 모든 연락처 중에서 고를 수 있어요. 업무 흐름에 가장 알맞은 수신자를 고르면 돼요.

### 회사 워크플로우에서도 사용자 지정 객체 워크플로우와 똑같이 동작하나요?

<!-- 검토 필요: 원문 내용이 서로 다름 -->
핵심 기능은 비슷해요. 두 경우 모두 **Association Label** 필드로 수신 연락처를 정해요. 다만 사용자 지정 객체 워크플로우에서는 **Email Recipients** 드롭다운에서 수신자 옵션(가장 먼저 연결, 가장 최근 연결, 연결된 모든 연락처)을 추가로 고를 수 있어요. 회사 워크플로우는 선택한 레이블에 해당하는 연결된 모든 연락처에게 기본으로 보내요.

### 이 이메일에도 개인화 토큰을 쓸 수 있나요?

네, 이메일 내용을 작성할 때 커스텀 필드와 개인화 토큰을 쓸 수 있어요. 이메일 에디터는 다른 워크플로우 이메일 액션과 같은 개인화 기능을 지원해요. 연락처 필드, 사용자 지정 객체 필드, 시스템 토큰도 포함돼요.

### 워크플로우가 실행될 때 선택한 레이블에 해당하는 연락처가 없으면 어떻게 되나요?

**Send Email** 액션이 실행될 때 선택한 **Association Label**에 해당하는 연락처가 없으면 이메일은 발송되지 않아요. 오류 없이 다음 액션으로 넘어가요. 아직 연결이 없는 상황에서도 자동화가 문제없이 진행돼요.

### 이 이메일은 어떤 발송 도메인으로 보내나요?

회사·사용자 지정 객체 워크플로우에서 보내는 이메일은 계정에 설정된 대량 이메일 발송 도메인(Bulk Email)을 사용해요. 이메일이 잘 전달되도록 대량 이메일 도메인이 올바르게 설정되고 인증되어 있는지 확인하세요.
