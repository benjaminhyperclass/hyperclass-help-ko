# 워크플로우 빌더 — Learn More Using AI(AI로 자세히 알아보기) 사용하기

Learn More Using AI는 하이퍼클래스 워크플로우 빌더 안에서 트리거와 액션에 대한 설명을 바로 보여 주는 AI 도움말 기능이에요. 문서를 따로 찾지 않고도 빌더 화면에서 설정 방법을 확인하고, 워크플로우를 자신 있게 만들 수 있어요.

## Learn More Using AI란?

Learn More Using AI는 워크플로우 빌더에 들어 있는 상황별 도움말 기능이에요. 지금 설정 중인 트리거나 액션에 맞는 설명, 상세한 설정 방법, 활용 예시를 AI가 바로 알려 줘요. 빌더 화면을 벗어나지 않고도 각 구성 요소를 이해하고 설정할 수 있어서 실수를 줄이고 설정 시간도 아낄 수 있어요.

## 이런 점이 좋아요

- 바로 답을 얻어요: 문서를 뒤지지 않고 빌더 안에서 곧바로 답을 확인할 수 있어요.
- 만들면서 배워요: 필요한 순간에 지금 보고 있는 요소에 맞는 설명을 볼 수 있어요.
- 안심하고 만들어요: 명확한 안내와 유효성 검사 팁 덕분에 처음부터 정확하게 설정할 수 있어요.
- 시간을 아껴요: 필요한 때에 정확한 AI 안내를 받아 설정 속도가 빨라져요.

## Learn More 버튼

**Learn More**(자세히 보기) 버튼을 누르면 AI 어시스턴트를 바로 열 수 있어요.

- 모든 트리거와 액션 설정 패널의 오른쪽 위에 전구 아이콘이 있는 파란색 **Learn More** 버튼이 있어요.
- 한 번만 클릭하면 상세한 설명이 담긴 **Workflow AI Assistant**(워크플로우 AI 어시스턴트) 사이드바가 열려요.
- 워크플로우 구성 요소를 설정하다가 궁금할 때 바로 눌러 볼 수 있어요.

## Workflow AI Assistant 사이드바

**Workflow AI Assistant** 사이드바는 AI 안내를 보기 좋게 정리해서 보여 줘요.

- **Learn More** 버튼을 누르면, 지금 설정 중인 트리거나 액션에 맞는 도움말이 열려요.
- 설정 방법을 알려 주고, 유효성 규칙과 제약 사항을 설명하고, 실제 활용 예시도 보여 줘요.
- 이어서 궁금한 점을 질문할 수 있어서 상황에 맞는 답을 받을 수 있어요.

```
Learn Mode 2.0

Learn Mode에서는 답변이 실시간으로 표시되고, 답변이 끝나면 이어서 물어볼 만한 질문을 추천해 줘요.

Continue in Build Mode
Learn Mode에서 워크플로우를 만드는 질문을 하면 Continue in Build Mode 버튼으로 Build Mode로 전환할 수 있어요.

입력한 요청이 그대로 유지되어 Build Mode에서 다시 입력하지 않아도 바로 전달돼요.
```

## Learn More Using AI 사용 방법

### 워크플로우 빌더 열기

1. 왼쪽 메뉴에서 **자동화 > 워크플로우**를 선택하세요.
2. 오른쪽 위의 **+ Create Workflow**(워크플로우 만들기)를 클릭하세요. 레시피, 템플릿, 처음부터 만들기 중에서 시작 방법을 고를 수 있어요.

![자동화 메뉴의 워크플로우 탭과 워크플로우 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050591382/original/1VFdXe2O8RGpqNXPjuxMVJ9spU0C-mth7A.png?1753788067)

### 트리거 또는 액션 열기

Learn More 기능을 쓰려면 트리거나 액션의 설정 패널을 열어야 해요. 이 예시에서는 **+ Add New Trigger**(새 트리거 추가)를 클릭해서 시작해요.

![새 트리거 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050591191/original/b1aXS9HsYYmxLsaKRVdhIgfiKt6-TwLREQ.png?1753787966)

### 트리거 고르기

설정 패널이 열리면 목록에서 트리거를 선택하세요. 이 예시에서는 **Contact Tag**(연락처 태그)를 골랐어요. 다른 표준 트리거나 액션에서도 **Learn More** 버튼이 똑같이 나타나요.

![트리거 목록에서 Contact Tag 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050591203/original/7xDUSQEZVe5DN8f8X31co_DglLjFTQ5Cyg.png?1753787985)

### Learn More 버튼 클릭하기

설정 패널 오른쪽 위에 있는 전구 아이콘이 달린 파란색 **Learn More** 버튼을 클릭하세요. **Workflow AI Assistant**가 열리면서 상황에 맞는 안내가 나와요.

![설정 패널 오른쪽 위의 파란색 Learn More 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050591445/original/NMgYuqvPgB0ZXmIICD6XW5BP80ntmwvQvA.png?1753788101)

### 안내 내용 확인하기

**Learn More** 버튼을 클릭하면 왼쪽에 **Workflow AI Assistant** 사이드바가 열려요. 지금 설정 중인 트리거나 액션에 딱 맞는 설명이 나와요.

기능이 무엇을 하는지, 어떻게 동작하는지, 단계별 설정 방법, 실제 활용 사례를 볼 수 있어요. 채팅창에 궁금한 점을 직접 입력하면 그에 맞는 답도 받을 수 있어요. 이 화면을 벗어나지 않고도 문제를 해결하고, 배우고, 워크플로우를 올바르게 설정할 수 있어요.

![워크플로우 AI 어시스턴트 사이드바에 표시된 상황별 안내](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050591483/original/aKdUq6Y_ymwBWZaPn6rHav543td9tw7PLQ.png?1753788122)

## 자주 묻는 질문

### 모든 워크플로우 구성 요소에서 Learn More Using AI를 쓸 수 있나요?

표준 트리거와 액션에서는 모두 쓸 수 있어요. 단, 마켓플레이스 액션과 트리거는 지원하지 않아요.

### Learn More Using AI를 쓰려면 추가 요금을 내야 하나요?

아니요. 모든 하이퍼클래스 사용자가 무료로 쓸 수 있어요.

### 사이드바에서 추가로 질문할 수 있나요?

네. AI 어시스턴트와 대화하면서 이어서 질문하면 상황에 맞는 안내를 더 받을 수 있어요.

### AI 어시스턴트는 어떤 안내를 해 주나요?

트리거와 액션이 어떻게 동작하는지, 단계별 설정 방법, 유효성 제약 사항, 실제 활용 예시를 자세히 알려 줘요.

### Learn More Using AI에 대한 문서는 어디서 더 볼 수 있나요?

추가 설명과 참고 자료는 하이퍼클래스 도움말 센터의 관련 문서에서 확인할 수 있어요.
