# 워크플로우 빌더에서 워크플로우 전환하기 — Workflow Switcher(워크플로우 전환기)

**Workflow Switcher**(워크플로우 전환기)를 쓰면 워크플로우 빌더를 벗어나지 않고 다른 워크플로우로 바로 이동할 수 있어요. 전환기 패널에서 워크플로우를 검색하고, 열고, 만들고, 복제하고, 삭제할 수 있어요.

## 새로워진 점

Workflow Switcher에 다음 기능이 추가되었어요.

- 같은 탭에서 워크플로우를 전환해서 열린 탭이 많아지지 않아요.
- 더 빠르게 불러오고 더 부드럽게 이동해요.
- 무한 스크롤로 모든 워크플로우를 훑어볼 수 있어요.
- 패널 안에서 워크플로우를 만들고, 복제하고, 삭제할 수 있어요.
- Advanced Workflow Builder와 Standard Workflow Builder 모두에서 쓸 수 있어요.

## Workflow Switcher 여는 방법

1. **자동화 > 워크플로우**로 이동하세요.
2. 워크플로우를 아무거나 하나 여세요.
3. 왼쪽 사이드바에서 **Workflow Switcher**를 클릭하세요.
   - 키보드에서 **Shift + W**를 눌러도 열려요.

## 워크플로우 전환하는 방법

1. Workflow Switcher를 여세요.
2. 검색창을 쓰거나 스크롤해서 워크플로우를 찾으세요.
3. 워크플로우 이름을 클릭하세요.

선택한 워크플로우가 같은 탭에서 열려요.

## 전환기에서 워크플로우 관리하기

전환기 안에서 다음 작업을 할 수 있어요.

- **+** 아이콘을 눌러 새 워크플로우를 만들 수 있어요.
- 옵션 메뉴에서 워크플로우를 복제할 수 있어요.
- 더 이상 필요 없는 워크플로우를 삭제할 수 있어요.

이 작업은 모두 패널 안에서 할 수 있어서 빌더를 벗어날 필요가 없어요.

## 이동이 편해진 부분

- 같은 탭에서 전환하므로 작업 공간이 어수선해지지 않아요.
- 무한 스크롤을 지원해서, 워크플로우가 많아도 페이지를 넘기지 않고 목록을 볼 수 있어요.
- 성능이 개선되어 워크플로우를 불러오고 전환하는 속도가 빨라졌어요.

## 키보드 단축키

**Shift + W**를 누르면 Workflow Switcher가 열리거나 닫혀요.

## 자주 묻는 질문

### 워크플로우를 새 탭에서 열 수 있나요?

네, 가능해요. 워크플로우의 옵션 메뉴를 쓰거나 워크플로우를 마우스 오른쪽 버튼으로 클릭한 뒤 **Open in new tab**(새 탭에서 열기)을 선택하세요.

### 워크플로우를 전환하면 저장하지 않은 변경 사항이 사라지나요?

아니요. 전환하기 전에 변경 사항을 저장할지 버릴지 묻는 메시지가 나와요.

### Workflow Switcher는 모든 빌더에서 쓸 수 있나요?

네. Advanced Workflow Builder와 Standard Workflow Builder 모두에서 쓸 수 있어요.

### 볼 수 있는 워크플로우 개수에 제한이 있나요?

아니요. 무한 스크롤로 페이지를 넘기지 않고 모든 워크플로우를 볼 수 있어요.
