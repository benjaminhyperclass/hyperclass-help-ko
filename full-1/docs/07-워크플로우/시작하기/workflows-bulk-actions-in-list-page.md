# 워크플로우 목록 페이지에서 일괄 작업 사용하기

워크플로우와 폴더를 하나씩 관리하면 번거로워요. **일괄 작업**을 쓰면 목록 페이지에서 여러 항목을 골라 자주 쓰는 작업을 한 번에 처리할 수 있어요. 이 문서에서는 워크플로우 목록 페이지에서 일괄 작업을 사용하는 방법을 안내해요.

## 워크플로우 목록의 일괄 작업이란?

워크플로우 목록 보기에서 **일괄 작업**을 쓰면 이동, 게시/임시 저장, 삭제, 권한 관리(폴더) 같은 작업을 여러 항목에 한꺼번에 적용할 수 있어요. 반복 작업이 줄고, 정리 상태를 일정하게 유지할 수 있어요. 워크플로우가 수십~수백 개인 팀의 일상 관리도 빨라져요.

## 일괄 작업의 장점

- 시간 절약: 같은 작업을 여러 항목에 한 번에 적용해요. 단계를 반복하지 않아도 돼요.
- 일관성: 관련 워크플로우의 상태, 위치, 권한을 같게 맞출 수 있어요.
- 실수 감소: 수작업 클릭이 줄어 실수할 가능성도 낮아져요.
- 쉬운 정리: 하위 폴더를 포함해 워크플로우와 폴더를 알맞은 위치로 한 번에 옮길 수 있어요.
- 권한 반영: 사용자 권한을 따르므로 권한이 있는 변경만 적용돼요.

## 워크플로우 목록 페이지에서 일괄 작업 사용하기

아래 순서로 일괄 작업을 안전하게 진행해 보세요. 되돌릴 수 없는 변경을 적용하기 전에는 항상 선택한 항목 수와 확인 창을 살펴보세요.

1. 서브 계정에 로그인해요.
2. **자동화** > **워크플로우**로 이동해요.

   ![워크플로우 목록 페이지](https://jumpshare.com/share/YLjwmidApgqa2ADnJUCR+/Screen+Shot+2025-11-28+at+5.39.31+PM.png)
3. (선택) 필터를 적용하거나 스마트 리스트를 열어 목록을 좁혀요.

   ![필터와 스마트 리스트로 목록 좁히기](https://jumpshare.com/share/Xg1aYYGwd3bjHH04cnsm+/Screen+Shot+2025-11-28+at+5.42.36+PM.png)
4. 항목의 체크박스로 폴더 또는 워크플로우 중 한 가지 종류만 선택해요.
5. **전체 선택**을 누르면 페이지에 보이는 폴더 또는 워크플로우를 모두 선택해요.

   ![전체 선택 사용 화면](https://jumpshare.com/share/RQfuAWQC71O7lLLevmqv+/GIF+Recording+2025-11-28+at+5.44.37+PM.gif)
6. **전체 선택** 드롭다운을 열어 **All Workflows**(전체 워크플로우), **All Folders**(전체 폴더), **Published Workflows**(게시된 워크플로우), **Draft Workflows**(임시 저장된 워크플로우) 중에서 고를 수 있어요.

   ![전체 선택 드롭다운에서 항목 유형 바꾸기](https://jumpshare.com/share/cx1ewT1Rs7zzdPXfl8qS+/GIF+Recording+2025-11-28+at+5.48.54+PM.gif)
7. 일괄 작업 도구 모음에서 작업을 선택해요.

   - **게시**/**임시 저장** (워크플로우만 가능)
   - **이동** (워크플로우 또는 폴더)
   - **삭제** (워크플로우 또는 폴더)
   - **Manage Permissions**(권한 관리) (폴더만 가능)
8. 확인 창을 살펴봐요. 몇 개의 항목에 적용되는지와 경고 내용이 표시돼요.

   ![일괄 작업 확인 창](https://jumpshare.com/share/zQD8UVJQdCyS9pwiWI7v+/Screen+Shot+2025-11-28+at+5.53.35+PM.png)

## 사용 범위와 권한

일괄 작업은 사용자 역할과 기존 폴더 권한을 따라요. 권한이 있는 변경만 적용돼요.

- 사용 위치: 전체 워크플로우 목록과, 직접 만든 모든 스마트 리스트에서 쓸 수 있어요.
- 권한: 권한이 있는 일괄 작업만 할 수 있어요. 권한이 없으면 작업이 보이지 않거나 비활성화될 수 있어요.
- 적용 범위: 기본적으로 **전체 선택**은 현재 페이지에 보이는 항목을 대상으로 해요. 필터나 스마트 리스트를 쓰면 화면에 보이는 필터 결과가 선택돼요.
- 지원 화면: 워크플로우 목록 페이지에 맞게 만들어졌어요. 화면 크기가 작으면 동작이 다를 수 있어요.

## 자주 묻는 질문

### 폴더와 워크플로우를 함께 선택할 수 있나요?
아니요. 폴더 또는 워크플로우 중 한 가지 종류만 선택할 수 있어요.

### **게시**/**임시 저장**이 비활성화돼 있어요. 왜 그런가요?
**게시**/**임시 저장**은 워크플로우에만 적용돼요. 선택한 항목에 폴더가 포함되어 있거나 폴더만 선택했다면 이 작업은 쓸 수 없어요.

### **Manage Permissions**로 워크플로우 권한도 바꿀 수 있나요?
아니요. **Manage Permissions**는 폴더용이에요. 워크플로우 선택을 해제하면 이 작업을 쓸 수 있어요.

### **전체 선택**을 누르면 현재 페이지 밖의 항목도 선택되나요?
**전체 선택**은 페이지에 보이는 항목을 대상으로 해요. 필터를 적용하거나 페이지를 넘겨서 선택을 조정하세요. 드롭다운에서 항목 유형을 좁힐 수도 있어요.

### 접근 권한이 없는 폴더로 항목을 옮길 수 있나요?
아니요. 이동을 마치려면 이동할 폴더에 접근할 수 있어야 해요.

### 항목을 옮기면 권한도 바뀌나요?
이동한 뒤에는 워크플로우가 이동한 폴더의 구조와 공개 범위를 따라요.

### 일괄 작업 도구 모음이 보이지 않아요.
도구 모음은 항목을 하나 이상 선택해야 나타나요. 선택했는데도 보이지 않는다면 일괄 작업을 할 권한이 없는 것일 수 있어요.
