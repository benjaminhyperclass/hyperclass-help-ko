# 워크플로우 액션 — AI Decision Maker(AI 의사결정)

**AI Decision Maker**(AI 의사결정)는 참여도, 회사 규모, 행동 같은 데이터를 바탕으로 연락처를 워크플로우의 알맞은 경로로 자동 분류하는 액션이에요. 복잡한 조건을 여러 개 쌓지 않고, 일상 언어로 기준을 적어 두면 AI가 가장 알맞은 분기를 골라 줘요.

연락처가 많아도 정확하고 유연하게 분류할 수 있어서 워크플로우 구성이 한결 간단해져요.

{% hint style="info" %}
이 액션은 프리미엄 액션이에요. 실행할 때마다 추가 요금이 부과돼요.
{% endhint %}

## AI Decision Maker란?

**AI Decision Maker**는 워크플로우 안에서 연락처를 알맞은 경로로 보내 주는 분류 기능이에요. 기존의 if/then 규칙이나 직접 설정하는 필터 대신, 분류 조건을 일상 언어로 적어요.

AI가 연락처 데이터를 살펴보고 맞는 분기를 자동으로 정해요. 그래서 조건을 계속 고치지 않아도 워크플로우가 데이터 변화에 맞춰 움직여요.

## AI Decision Maker의 장점

### 워크플로우 관리 부담이 줄어요

한 번 설정해 두면 AI가 연락처 데이터의 변화에 맞춰 판단해요. 필터와 조건 규칙을 여러 개 고쳐야 하는 일이 줄어들어요.

### 규모가 커져도 쉽게 대응할 수 있어요

연락처가 수백 명이든 수천 명이든 AI가 복잡한 분류를 처리해요. 워크플로우 성능도 느려지지 않아요.

### 사람의 실수를 없애 줘요

AI 기반 판단 로직이라서 조건을 빠뜨리거나 규칙이 겹쳐서 생기는 불일치가 없어요.

### 일상 언어로 지시해요

코딩도, 규칙을 겹겹이 쌓는 작업도 필요 없어요.

## AI Decision Maker 설정하기

아래 단계에 따라 워크플로우에 액션을 추가하고 설정하세요.

### 1단계: 워크플로우 선택 또는 만들기

1. 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **자동화**를 클릭하세요.
3. 기존 워크플로우를 편집하거나, **+ Create Workflow**(워크플로우 만들기)를 클릭해 처음부터, 템플릿으로, 또는 레시피로 새로 만드세요.

### 2단계: AI Decision Maker 액션 추가

1. 트리거가 설정되어 있는지 확인하세요. 예: **Contact Changed**(연락처 변경), **Form Submitted**(폼 제출)
2. 워크플로우 빌더 안에서 **+** 아이콘을 클릭하세요.
3. 오른쪽 패널에서 **AI Actions**(AI 액션)까지 스크롤하세요.
4. **AI Decision Maker**를 선택하세요.

분기가 많은 워크플로우를 정리해 두려면 **Action Name**(액션 이름)을 알아보기 쉽게 지어 주세요.

![AI Decision Maker 액션 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065903852/original/G8V4nN8wSV8mKMONH_lyGqGiTZgOsISdHg.png?1772231259)

### 3단계: AI 지시문 작성

**Instructions**(지시문) 필드에 연락처를 어떻게 분류할지 적으세요.

AI가 무엇을 살펴봐야 하는지 구체적으로 적는 것이 좋아요. 예를 들어 참여 점수, 업종, 회사 규모 같은 기준이에요.

변수 선택기(태그 아이콘)를 쓰면 아래와 같은 동적 필드를 넣을 수 있어요.

- `{{contact.engagement_score}}`
- `{{contact.company_size}}`
- `{{contact.tags}}`

이렇게 하면 AI가 실제 연락처 데이터를 보고 판단해요.

#### 지시문 예시

> 연락처의 참여 점수와 회사 규모를 확인하세요.
>
> 참여 점수가 60점을 넘거나 대기업에 다니는 경우 영업팀으로 보내세요.
>
> 참여 점수가 30~60점이고 중소기업인 경우 이메일 육성으로 보내세요.
>
> 참여 점수가 30점 미만이면 재참여 캠페인으로 보내세요.

{% hint style="warning" %}
AI가 제대로 판단하려면 맥락이 필요해요. 관련 연락처 필드, 커스텀 필드, 태그, 앞선 워크플로우 단계의 데이터를 항상 함께 넣어 주세요.

유용한 변수 예시:

- 연락처 정보: `{{contact.email}}`, `{{contact.phone}}`
- 커스텀 필드: `{{contact.lead_score}}`, `{{contact.company_size}}`
- 태그: `{{contact.tags}}`
- 앞선 단계의 데이터(폼, 설문 등)
{% endhint %}

![지시문 필드 작성 화면](https://jumpshare.com/share/bAacCuRQFPrlmvWOC1v0+/Screen+Shot+2026-01-06+at+9.21.41+PM.png)

### 4단계: 추가 맥락 입력

**Additional Context**(추가 맥락) 필드에 AI가 더 정확히 판단하도록 돕는 정보를 적으세요.

비즈니스 규칙, 고객 분류 기준, 운영상의 제약 같은 내용을 넣을 수 있어요.

#### 예시

> 저희는 직원 수가 10~500명인 회사에 소프트웨어를 판매합니다.
>
> 소규모 회사는 직원이 1~50명입니다.
>
> 중간 규모 회사는 직원이 51~200명입니다.
>
> 대규모 회사는 직원이 200명을 넘습니다.
>
> 참여 점수는 0~100점입니다.
>
> 영업팀은 일주일에 신규 리드를 약 20건 처리할 수 있습니다.

맥락을 체계적으로 정리해 주면 분류가 더 정확해져요.

![추가 맥락 입력 화면](https://jumpshare.com/share/JZs9kpsBQQ4BhjVciDx2+/Screen+Shot+2026-01-06+at+9.22.46+PM.png)

### 5단계: 기본 분기

**Default Branch**(기본 분기)는 자동으로 들어 있어요. 다른 조건에 맞지 않는 연락처를 받아 주는 예비 경로예요.

- 분기 이름은 **Default Branch**로 고정되어 있어요.
- 워크플로우가 끊기지 않고 계속 실행되게 해 줘요.
- 삭제하거나 이름을 바꿀 수 없어요.

이 분기 덕분에 연락처가 중간에 멈추지 않아요.

![기본 분기 화면](https://jumpshare.com/share/7bDj1sXBqUnP6CxMI21r+/Screen+Shot+2025-09-12+at+1.36.27+PM.png)

### 6단계: 커스텀 분기 추가

특정 기준에 따라 연락처를 나눠 보낼 분기를 더 만드세요.

각 분기에는 아래 내용을 넣어 주세요.

- 알아보기 쉬운 **Branch Name**(분기 이름). 예: “높은 우선순위 – 영업”
- 어떤 연락처가 이 경로로 들어와야 하는지 설명하는 짧은 문장

예시:

> `{{contact.engagement_score}}` 가 60보다 크거나 회사 규모가 대규모이면 영업팀으로 보내세요.

![커스텀 분기 설정 화면](https://jumpshare.com/share/ZRdpyhh0a1xMIkhDmzRk+/Screen+Shot+2025-09-12+at+1.41.47+PM.png)

### 7단계: 분기 더 추가

**+ New Branch**(새 분기)를 클릭해 경로를 더 만드세요.

분기마다 이름은 알아보기 쉽게, 설명은 간결하게 적어 주세요. 이렇게 하면 아래와 같은 후속 조치를 연락처별로 다르게 설정할 수 있어요.

- 할인 혜택 안내
- 제품 교육
- 사례 연구
- 재참여 캠페인

![새 분기 추가 화면](https://jumpshare.com/share/8aZdrSywTzpks0v6zWU2+/Screen+Shot+2025-09-12+at+1.43.52+PM.png)

### 8단계: 액션 저장

지시문과 분기 설정을 모두 마쳤으면 **Save Action**(액션 저장)을 클릭하세요.

이제 워크플로우가 AI 판단에 따라 연락처를 자동으로 평가하고 알맞은 경로로 보내요.

![액션 저장 화면](https://jumpshare.com/share/8wbPvJBdqIUuxcoNJKXl+/Screen+Shot+2025-09-12+at+1.46.30+PM.png)

## 많이 쓰는 활용 사례

### 스팸 제출 감지

웹사이트 폼 제출을 AI Decision Maker로 판단할 수 있어요.

1. 폼 제출 내용을 **AI Decision Maker**로 보내세요.
2. AI가 제출 내용을 스팸과 정상으로 분류하도록 지시하세요.
3. 스팸 예시를 함께 알려 주면 분류 정확도가 올라가요.
4. 정상 제출에 대해서만 기회를 만들도록 설정하세요.

이렇게 하면 직접 검토하는 일이 줄고 파이프라인 품질도 지킬 수 있어요.

## 자주 묻는 질문

### AI는 연락처를 어디로 보낼지 어떻게 정하나요?

AI가 작성한 지시문을 읽고, 함께 전달된 연락처 데이터를 살펴서 가장 알맞은 분기를 정해요.

### 어떤 규칙에도 맞지 않는 연락처는 어떻게 되나요?

자동으로 **Default Branch**로 보내져요.

### Default Branch를 삭제하거나 편집할 수 있나요?

아니요. **Default Branch**는 삭제하거나 편집할 수 없어요. 어떤 조건에도 맞지 않는 연락처를 받아 주는 예비 경로 역할을 해요.

### 연락처가 어느 경로로 갔는지 확인하려면 어떻게 하나요?

워크플로우의 **Execution Logs**(실행 로그) 탭에서 분류된 경로를 확인할 수 있어요.

### 폼이나 설문 데이터도 쓸 수 있나요?

네. 변수 선택기로 앞선 워크플로우 단계의 변수를 넣으면 돼요.
