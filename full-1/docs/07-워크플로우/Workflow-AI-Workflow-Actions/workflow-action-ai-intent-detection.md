# 워크플로우 액션 — AI Intent Detection(AI 의도 감지)

**AI Intent Detection**(AI 의도 감지) 액션은 텍스트를 분석해서 감정을 **POSITIVE**, **NEGATIVE**, **NONE** 중 하나로 자동 분류해요. 이 프리미엄 액션은 **IF/Else** 조건에 있던 기존 의도 감지를 대신해요. 정확도가 더 높고 설정도 쉬워서, 고객의 감정에 따라 응답을 자동화할 때 쓰기 좋아요.

## AI Intent Detection이란?

**AI Intent Detection** 액션은 AI로 텍스트에 담긴 감정이나 의도를 자동으로 분석하는 워크플로우 도구예요. 고객 메시지, 설문 응답, 폼 제출 내용 등 어떤 텍스트든 분석할 수 있어요. 분석 결과는 아래 세 갈래 중 하나로 나뉘어요.

- **POSITIVE**: 긍정, 만족, 동의를 나타내는 텍스트
- **NEGATIVE**: 부정, 불만, 반대를 나타내는 텍스트
- **NONE**: 감정이 중립적이거나, 시스템이 확신을 갖고 분류하기 어려운 텍스트

이 액션을 추가하면 워크플로우 분기 세 개가 자동으로 만들어져요. 감지된 감정에 따라 서로 다른 자동화 경로를 짤 수 있어요.

## 이럴 때 좋아요

- 자동 감정 분석: 사람이 일일이 확인하지 않아도 고객 응답을 바로 분류해요.
- 향상된 정확도: 기존 **IF/Else** 의도 감지 방식보다 믿을 만해요.
- 간단한 워크플로우 설계: 분기가 세 개로 정해져 있어서 복잡한 조건 설정이 필요 없어요.
- 실시간 대응: 고객의 감정에 맞는 액션을 바로 실행해요.
- 더 나은 고객 경험: 고객의 감정에 맞춰 개인화된 응답을 보낼 수 있어요.
- 확장 가능한 자동화: 사람이 개입하지 않아도 메시지를 제한 없이 처리해요.

## AI Intent Detection 설정하기

### 1단계: AI Intent Detection 액션 추가하기

워크플로우 빌더에서 액션 목록을 열고 "AI Intent Detection"을 검색하세요. 텍스트 감정을 분석하려는 위치에 이 액션을 추가하면 돼요.

![워크플로우 빌더에서 AI Intent Detection 액션 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062013506/original/o_RXz8dxn-FiBPvkv_xSI0KmQQXuHfr8Jw.png?1767706286)

### 2단계: 액션 설정하기

1. **Action Name**(액션 이름)에 어떤 액션인지 알 수 있는 이름을 입력하세요. 예: "피드백 감정 분석"
2. **Input Text**(입력 텍스트)에 분석할 텍스트를 지정하세요. 방법은 두 가지예요.
   - **Static Value**(고정값): 정해진 텍스트를 직접 입력해요.
   - **Dynamic Variable**(동적 변수): 커스텀 값 선택기에서 변수를 골라요.
     - 수신 메시지를 분석하려면 `{{message.body}}`를 선택해요.
     - 분류할 텍스트가 담긴 다른 변수도 선택할 수 있어요.

![액션 이름과 입력 텍스트 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062013560/original/rW97oR8OAidk5wPExVEoPfk23qgeUbG1hA.png?1767706331)

### 3단계: 분기별 액션 설정하기

액션을 저장하면 분기 세 개가 자동으로 만들어져요.

![POSITIVE, NEGATIVE, NONE 분기 세 개가 만들어진 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062013821/original/hxCmz80mTWBT3drPXjJJXnQTHxtoiqMzBQ.png?1767706390)

**1. POSITIVE 분기**: 긍정 응답에 실행할 액션을 설정해요.

- 감사 메시지 보내기
- 앱스토어 리뷰 요청하기
- 로열티 보상 제공하기
- "만족한 고객" 태그 추가하기

**2. NEGATIVE 분기**: 부정 응답에 실행할 액션을 설정해요.

- 고객지원 에스컬레이션 시작하기
- 할인 코드나 쿠폰 보내기
- 후속 통화 일정 잡기
- "확인 필요" 태그 추가하기

**3. NONE 분기**: 중립적이거나 판단하기 어려운 응답에 실행할 액션을 설정해요.

- 내용을 다시 물어보는 메시지 보내기
- 담당자가 직접 검토하도록 넘기기
- 기본 후속 시퀀스 적용하기

## 활용 예시

### 1. 고객 피드백 관리

시나리오: 설문으로 피드백을 받은 뒤

- **POSITIVE** 응답: "서비스가 정말 훌륭해요!"
  - 액션: 앱스토어 리뷰 요청 링크 보내기
- **NEGATIVE** 응답: "경험이 너무 실망스러웠어요"
  - 액션: 다음 구매에 쓸 20% 할인 쿠폰 보내기
- **NONE** 응답: "괜찮아요" 또는 "해당 없음"
  - 액션: 자세한 내용을 묻는 후속 질문 보내기

### 2. 구매 후 후속 관리

시나리오: 배송 완료를 확인한 뒤

- **POSITIVE**: 상품 리뷰와 후기 요청하기
- **NEGATIVE**: 반품/환불 워크플로우 시작하기
- **NONE**: 상품 사용 팁 보내기

## 가격

- 비용: 실행 1회당 1센트(0.01달러)
- 프리미엄 액션에 포함돼요.

## 자주 묻는 질문

### 기존 IF/Else 의도 감지와 무엇이 다른가요?

**AI Intent Detection** 액션은 고급 AI로 감정을 더 정확하게 분석해요. 분기도 자동으로 만들어 주기 때문에 복잡한 조건을 따로 설정하지 않아도 돼요.

### 한 워크플로우에서 AI Intent Detection 액션을 여러 개 쓸 수 있나요?

네, 쓸 수 있어요. 여러 액션을 이어 붙여서 서로 다른 텍스트를 분석하거나, 감정을 여러 단계로 나눠 분석하는 워크플로우를 만들 수 있어요.

### 텍스트에 여러 감정이 섞여 있으면 어떻게 되나요?

시스템이 전체적으로 가장 두드러진 감정을 기준으로 분석해요. 뚜렷한 감정이 감지되지 않으면 **NONE** 분기로 넘어가요.

### 실제로 적용하기 전에 의도 감지를 테스트할 수 있나요?

네, 할 수 있어요. 워크플로우 테스트 모드에서 샘플 텍스트를 입력하면 워크플로우를 활성화하기 전에 감정 감지 정확도를 확인할 수 있어요.

### 텍스트가 왜 그렇게 분류됐는지 알 수 있나요?

지금은 분류 결과만 보여 줘요. 자세한 판단 근거나 신뢰도 점수는 이후 업데이트에서 추가될 수 있어요.
