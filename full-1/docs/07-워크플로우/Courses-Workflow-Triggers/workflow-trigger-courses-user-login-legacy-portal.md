# 워크플로우 트리거 — Courses User Login(코스 사용자 로그인, 레거시 포털)

**User Login**(사용자 로그인) 트리거는 레거시 포털에서 사용자가 계정에 로그인할 때 워크플로우를 시작해요. 사용자 활동을 추적하거나, 로그인 알림을 보내거나, 로그인한 사용자에게 맞춤 동작을 실행할 때 쓰면 좋아요.

## 개요

**User Login** 트리거는 레거시 포털에서 사용자가 계정에 로그인할 때 워크플로우 안의 지정한 동작을 시작해요.

## 트리거 이름

**User Login**

## 트리거 설명

**User Login** 트리거는 사용자가 계정에 로그인할 때마다 워크플로우를 실행해요. 다음과 같은 동작을 자동으로 처리할 수 있어요.

- 다시 방문해 준 사용자에게 환영 이메일 보내기
- 로그인 빈도 추적하기
- 로그인한 시점에 알림이나 혜택 보내기

## 설정 방법

**User Login** 트리거는 **Workflow Trigger Name**(워크플로우 트리거 이름)만 입력하면 설정이 끝나요. 워크플로우가 실행되는 조건을 더 좁히고 싶으면 필터를 추가하세요.

#### 필드와 속성

| --- | --- | --- |
| Workflow Trigger Name | 트리거를 쉽게 구별할 수 있도록 붙이는 이름이에요. | 예 |

## 예시

이 예시에서는 사용자가 계정에 로그인하면 워크플로우가 실행되도록 설정해요.

1. **Workflow Trigger Name**: Courses `User Login`

#### 워크플로우 예시

사용자가 계정에 로그인하면 다음과 같은 동작을 실행할 수 있어요.

- 다시 방문한 사용자를 환영하는 이메일 보내기: 계정으로 돌아온 사용자에게 맞춤 환영 이메일을 자동으로 보내요.
- 맞춤 혜택 보내기: 사용자가 일정 기간 로그인하지 않았다면 특별 혜택이나 알림을 자동으로 보내요.

이렇게 설정하면 사용자가 로그인할 때마다 워크플로우가 실행되므로, 실시간으로 사용자와 소통하고 맞춤 메시지를 보낼 수 있어요.
