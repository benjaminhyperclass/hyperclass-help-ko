# 워크플로우 트리거 — Offer Access Granted(오퍼 접근 권한 부여)

**Offer Access Granted**(오퍼 접근 권한 부여) 트리거는 연락처가 특정 오퍼에 접근할 수 있게 되었을 때 워크플로우를 자동으로 시작해요. 이 문서에서는 트리거의 기능과 장점, 설정 방법, 활용 사례, 자주 묻는 질문을 안내해요.

## Offer Access Granted 트리거란

**Offer Access Granted** 트리거는 연락처가 지정한 오퍼에 접근 권한을 얻을 때마다 실행돼요. 이 트리거로 웰컴 이메일 발송, 연락처 정보 업데이트, 팀원 알림 같은 작업을 자동화할 수 있어요. 워크플로우에 넣어 두면 고객 온보딩이 매끄러워지고 고객 경험도 좋아져요.

## Offer Access Granted 트리거의 장점

- 고객 소통 자동화: 접근 권한이 부여된 직후 맞춤 메시지를 바로 보내 고객 만족도를 높여요.
- 팀 협업 개선: 영업팀이나 고객지원팀 같은 담당 팀에 새 접근 권한 부여 사실을 알려, 제때 후속 대응을 할 수 있어요.
- 업무 간소화: 연락처 정보 업데이트 같은 관리 작업을 자동화해 수작업과 실수를 줄여요.
- 필터로 워크플로우 좁히기: 필터로 특정 오퍼에서만 자동화가 실행되도록 할 수 있어요.
- 리포팅 강화: 오퍼 접근 기록을 정확하게 남겨 두면 추적과 분석에 도움이 돼요.

## 트리거 설정 방법

### 워크플로우 열기

**자동화 > 워크플로우**로 이동하세요. 새 워크플로우를 처음부터 만들거나, **Offer Access Granted** 트리거를 넣을 기존 워크플로우를 선택하세요.

### 새 워크플로우 트리거 추가

1. **+ Add New Trigger**(새 트리거 추가)를 클릭하세요.
2. 드롭다운 메뉴에서 **Offer Access Granted**를 선택하세요.

![새 트리거 추가에서 Offer Access Granted 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038864276/original/TMZOF0s0e3tSlM0MHy6f6JsjVmFU7D4Lxw.png?1735052755)

### 트리거 이름 정하기

“15% 할인 접근 권한 부여”처럼 한눈에 알아볼 수 있는 이름을 입력하세요.

![트리거 이름 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038864282/original/XSGjrepFzAUndxU-Gbci-Xqh8wE40oom6w.png?1735052768)

### 필터 설정

필터를 설정해 워크플로우가 실행되는 조건을 좁혀요.

**Offer**(오퍼) 필터에서 워크플로우를 시작할 오퍼를 선택하세요. 예를 들어 “얼리버드 할인”을 선택할 수 있어요.

![Offer 필터에서 오퍼 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038864308/original/zBvphsEaWtQA7l6eeSZFO36D-riaJOjB9A.png?1735052805)

### 트리거 저장

트리거를 저장하세요.

### 테스트하고 게시하기

1. 샘플 데이터로 워크플로우를 테스트해 정상적으로 동작하는지 확인하세요.
2. 확인이 끝나면 **Publish**(게시) 토글을 켜서 워크플로우를 활성화하세요.

## 사용 사례

### 신규 멤버 웰컴 이메일

- 시나리오: 연락처가 멤버십 오퍼에 접근 권한을 얻으면 웰컴 이메일을 받아야 해요.
- 트리거 설정
  - 트리거: **Offer Access Granted**
  - 필터: **Offer** — “프리미엄 멤버십”
- 결과: 멤버십 안내와 추가 온보딩 정보가 담긴 맞춤 웰컴 이메일이 발송돼요.

### 할인 오퍼 영업 알림

- 시나리오: 연락처가 기간 한정 할인 오퍼에 접근 권한을 얻으면 영업팀에 알려야 해요.
- 트리거 설정
  - 트리거: **Offer Access Granted**
  - 필터: **Offer** — “15% 얼리버드 할인”
- 결과: 담당 영업 사원에게 연락처에 후속 연락을 하라는 내부 알림이 가요.

### 접근 권한을 기준으로 한 업셀링

- 시나리오: 고객이 기본 오퍼에 접근 권한을 얻으면 업그레이드 옵션을 안내해야 해요.
- 트리거 설정
  - 트리거: **Offer Access Granted**
  - 필터: **Offer** — “기본 플랜”
- 결과: 전용 혜택을 포함해 프리미엄 플랜으로 업그레이드하도록 추천하는 이메일이 발송돼요.

## 자주 묻는 질문

### 같은 오퍼가 한 연락처에 여러 번 부여되면 어떻게 되나요?

접근 권한이 부여될 때마다 트리거가 실행돼요. 같은 워크플로우가 불필요하게 반복되지 않도록 조건이나 쿨다운을 사용하는 것이 중요해요.

### 한 워크플로우에서 다른 트리거와 함께 쓸 수 있나요?

네, 쓸 수 있어요. 고급 워크플로우에서는 **Offer Access Granted** 트리거를 **Tag Added**(태그 추가됨)나 **Opportunity Status Changed**(기회 상태 변경됨) 같은 다른 트리거와 함께 쓸 수 있어요.

### 같은 트리거에서 조건에 따라 다른 액션을 실행할 수 있나요?

네, 가능해요. 워크플로우 안에 조건부 액션을 설정하면 연락처 태그나 파이프라인 단계 같은 추가 조건에 따라 다르게 대응할 수 있어요.
