# 워크플로우 액션 — Add Manual Sales For An Affiliate(제휴 회원 수동 매출 추가)

워크플로우에서 선택한 캠페인의 특정 제휴 회원에게 수동 매출을 배정하는 액션이에요. 배정하면 캠페인의 기본 수수료 설정에 따라 수수료가 계산돼요. 수수료를 정확하고 제때 지급하고 싶을 때 쓰세요.

## **Add Manual Sales For An Affiliate** 액션이란?

**Add Manual Sales For An Affiliate**(제휴 회원 수동 매출 추가) 액션은 선택한 제휴 캠페인에서 특정 제휴 회원에게 수동 매출을 배정해요. 액션이 실행되면 캠페인의 기본 수수료 설정에 따라 수수료가 계산되고, 해당 제휴 회원에게 배정돼요.

![Add Manual Sales For An Affiliate 액션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027979857/original/jfGz0tJNjp7ekdlcpBZ9Oln3WAoQS2WROg.png?1718955077)

### 어떤 경우에 쓰면 좋나요?

아래는 워크플로우에서 "Add Leads under an Affiliate" 액션을 쓰기 좋은 대표적인 경우예요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

- 반복되는 수동 수수료 자동화: 제휴 회원에게 수동 매출과 수수료를 주기적으로 자동 배정해요. 시스템 밖에서 발생하거나 시스템이 추적하지 못하는 반복 매출에 특히 유용하고, 제휴 회원이 수수료를 꾸준히 받을 수 있어요.
- 오프라인 매출 기록: 오프라인이나 하이퍼클래스가 추적하지 못하는 채널에서 발생한 매출을 기록하고 반영해요. 수동 매출 입력을 자동화하면 제휴 회원이 만든 매출이 빠짐없이 집계되어 수수료 추적이 더 정확해져요.
- 제휴 회원 활동 보상: 수동 매출을 자동으로 추가해 금전과 무관한 기여나 특정 성과에 보상할 수 있어요. 교육 세션 참석, 뛰어난 고객 응대, 우수한 리드 확보 같은 활동이 예가 될 수 있어요.

## 사용 방법

### 1. **Add Manual Sales For An Affiliate** 액션 선택

워크플로우에서 **Add Manual Sales For An Affiliate** 액션을 선택해요.

### 2. 제휴 캠페인과 제휴 회원 선택

1. 드롭다운에서 제휴 캠페인(**Affiliate Campaign**)을 선택해요.
2. 제휴 회원(**Affiliate**) 드롭다운에서 제휴 회원을 선택해요. 이 드롭다운에는 앞서 선택한 캠페인에 추가된 제휴 회원만 보여요.

![제휴 캠페인과 제휴 회원 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027980002/original/n9alMPIimEYVn_tXhRl44OrcsDJdLJNsNA.png?1718955203)

### 3. 매출액과 기타 정보 입력

1. **Revenue**(매출액)에 해당 제휴 회원의 거래 매출 금액을 입력해요.
2. 필요하면 **Event date**(이벤트 날짜, 매출이 발생한 날짜)와 **Event ID**(참조 ID, 거래 ID)도 입력해요. 두 항목은 선택 사항이에요.

![매출액과 이벤트 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027980127/original/YXF9XqJMhoAhNCp-O8R-MGnS5uBkW1ePfg.png?1718955306)

### 4. 액션 저장

액션을 저장해요.

{% hint style="info" %}
이 액션은 제휴 회원에게 수동 매출만 추가해요. 수수료는 선택한 제휴 캠페인의 기본 수수료 설정에 따라 계산돼요.
{% endhint %}
