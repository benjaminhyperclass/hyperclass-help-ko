# 워크플로우 액션 — Go To(이동)

**Go To**(이동) 액션은 연락처를 워크플로우 안의 다른 액션으로 보내는 액션이에요. 조건에 맞지 않는 연락처를 앞쪽 액션으로 되돌리거나, 다른 브랜치로 넘길 때 써요.

## 개요

**Go To** 액션을 쓰면 연락처를 워크플로우 안의 원하는 지점으로 이동시킬 수 있어요. 연락처의 반응이나 행동에 따라 다른 흐름을 타게 하면 워크플로우를 더 간결하게 만들 수 있어요.

## 액션 이름

Go To

## 액션 설명

**Go To** 액션은 연락처를 워크플로우의 다른 액션으로 보내요. 연락처를 다른 브랜치로 보내고 싶을 때, 또는 특정 조건을 만족하지 못한 연락처를 앞의 몇 개 액션으로 되돌리고 싶을 때 유용해요.

{% hint style="info" %}
**Go To** 액션은 워크플로우나 브랜치의 맨 마지막 단계로만 추가할 수 있어요. 액션과 액션 사이에는 추가할 수 없어요.
{% endhint %}

## 설정 방법

1. **자동화 > 워크플로우**에서 워크플로우를 열어요.
2. 사용할 수 있는 액션 목록에서 **Go To**를 선택해요.
3. 액션 이름을 입력해요. 예를 들어 "Go to Wait action"처럼 무슨 일을 하는 액션인지 알 수 있게 적으세요.
4. **Save**(저장) 버튼을 클릭해요.
5. **Configure**(구성): 워크플로우의 모든 액션이 강조 표시돼요. 연락처를 보내려는 액션을 클릭하세요.
6. 이미 선택한 액션을 바꾸고 싶다면 **Go To** 액션 아래의 **Disconnect GoTo**(Go To 연결 해제) 아이콘을 클릭하세요. 그런 다음 연락처를 보낼 다른 액션을 선택하면 돼요.

## 예시

상품을 이미 구매한 고객에게는 이메일을 보내지 않기

시나리오: 온라인 쇼핑몰에서 상품을 구매하지 않은 고객에게 다시 연락하려고 해요. 이미 구매한 고객에게는 이메일을 보내고 싶지 않아요.

**트리거 설정:**

- **Trigger**(트리거): **Abandoned Checkout**(결제 중단)
- **Name**(이름): Abandoned Checkout
- **Filters**(필터):
  - **Duration (minutes)**(기간(분)): 10 (장바구니가 10분 넘게 방치되면 워크플로우를 시작해요)
  - **Cart Value**(카트 금액): **Greater than**(초과) 50 (카트 금액이 $50를 넘을 때만 워크플로우를 시작해요)

**워크플로우 액션:**

1. **Email Notification**(이메일 알림): 장바구니에 남은 상품을 알려 주고 할인 같은 혜택을 제안하는 맞춤 이메일을 고객에게 보내요.
2. **Wait**(대기): 1일 동안 기다려요.
3. **If/Else**(조건 분기): 연락처에 "Purchased" 태그가 있는지 확인하는 조건을 추가해요. 태그가 있으면 첫 번째 브랜치로, 없으면 **None** 브랜치로 연락처가 이동해요.
4. **Email**(이메일) — 브랜치 2: 장바구니에 상품이 남아 있다고 다시 알리는 이메일을 보내요.
5. **Wait**(대기) — 브랜치 2: 추가된 태그가 "Purchased"이면 진행하는 조건으로 대기 단계를 추가해요.
6. **Go To** — 브랜치 1: 연락처를 두 번째 브랜치의 대기 단계로 바로 보내는 **Go To** 액션을 추가해요.

결과: 장바구니를 두고 떠난 고객에게 다시 연락해 놓칠 뻔한 매출을 되찾을 수 있어요. 이미 상품을 구매한 고객에게는 이메일이 가지 않아요.
