# 구독을 해지하면 데이터는 어떻게 되나요?

하이퍼클래스 구독을 해지하면 에이전시 계정과 모든 서브 계정에서 데이터와 주요 기능을 쓸 수 없게 돼요. 이 문서에서는 해지 후 일어나는 일, 데이터 보관 기간, 해지 전에 저장해 둘 것, 재활성화·일시 중지·조기 삭제 요청 방법을 안내해요.

하이퍼클래스는 해지된 계정의 데이터를 **해지 후 90일 동안** 보관해요. 이 기간에 계정을 재활성화하면 다시 접근할 수 있고 데이터도 그대로 유지돼요.

다만 **전화번호와 A2P 등록은 보관 기간이 더 짧아서 해지 14일 후에 삭제돼요.**

## 해지 직후에는 어떻게 되나요?

해지하면 모든 서브 계정에서 아래 기능과 데이터를 쓸 수 없어요.

| 기능 또는 데이터 | 해지 후 상태 |
| --- | --- |
| **연락처** | 저장된 연락처 데이터에 접근할 수 없어요. |
| **대화** | 진행 중인 대화와 지난 대화에 접근할 수 없어요. |
| **캘린더** | 예정된 이벤트와 예약에 접근할 수 없어요. |
| **자동화** | 워크플로우와 자동화가 작동을 멈춰요. |
| **퍼널** | 모든 퍼널과 관련 데이터에 접근할 수 없어요. |
| **전화번호** 및 **A2P** | 전화번호와 A2P 등록은 해지 14일 후에 삭제돼요. 이 14일 동안에도 요금이 계속 청구돼요. 14일이 지나면 전화번호는 영구 삭제돼요. |
| **애드온** / 재판매 구독 | 회사의 하이퍼클래스 구독을 해지하면 연결된 애드온 구독도 자동으로 해지돼요. 구독이 끝나면 이 애드온과 관련 기능을 쓸 수 없을 수 있어요. |

{% hint style="warning" %}
계정에 접근할 수 없다고 해서 계정 데이터가 바로 삭제되는 것은 아니에요. 해지된 계정 데이터는 대부분 아래 설명처럼 90일 동안 보관돼요.
{% endhint %}

## 전화번호와 A2P 등록

전화번호와 A2P 등록은 일반 계정 데이터의 90일 보관 기간과 다른 일정으로 처리돼요.

**전화번호와 A2P 등록은 해지 14일 후에 삭제돼요.**

이 14일 동안에는 다음과 같아요.

- 전화번호와 A2P 등록은 아직 삭제되지 않은 상태예요.
- 전화번호 요금은 계속 청구돼요.

14일이 지나면 전화번호는 **영구 삭제**돼요.

{% hint style="warning" %}
전화번호가 계정 보관 기간인 90일 내내 남아 있을 거라고 생각하지 마세요. 전화번호는 해지 14일 후에 삭제돼요.
{% endhint %}

## 데이터 보관과 계정 삭제

하이퍼클래스는 해지된 계정의 데이터를 **해지 후 90일 동안** 보관해요.

이 90일 동안 **계정을 재활성화**하면 다시 접근할 수 있고 데이터도 유지돼요.

**90일 안에 재활성화하지 않으면** 다음 항목이 **영구 삭제**돼요.

- 에이전시 계정
- 서브 계정
- 계정에 연결된 데이터

### 해지 후 일정

| 시점 | 일어나는 일 |
| --- | --- |
| **해지 직후** | 서브 계정에서 위에 나열한 데이터와 기능을 쓸 수 없어요. 워크플로우와 자동화가 작동을 멈춰요. |
| **처음 14일 동안** | 전화번호와 A2P 등록은 삭제 대기 상태로 남아 있고, 전화번호 요금은 계속 청구돼요. |
| **14일 후** | 전화번호와 A2P 등록이 삭제돼요. 전화번호는 영구 삭제돼요. |
| **90일 보관 기간 중** | 하이퍼클래스가 해지된 계정 데이터를 보관해요. 계정을 재활성화하면 다시 접근할 수 있고 데이터도 유지돼요. |
| **재활성화 없이 90일 후** | 에이전시 계정, 서브 계정, 연결된 데이터가 영구 삭제돼요. |

## 영구 삭제 전에 받는 알림 이메일

하이퍼클래스는 계정이 영구 삭제되기 전에 자동 알림 이메일을 보내요.

받을 수 있는 알림은 다음과 같아요.

- **"하이퍼클래스 계정이 60일 후 삭제됩니다"**
- **"하이퍼클래스 계정이 30일 후 삭제됩니다"**
- **"최종 안내: 하이퍼클래스 계정이 5일 후 삭제됩니다"**

90일 보관 기간이 끝나기 전에 이 알림을 보고 계정을 재활성화할 수 있어요.

## 영구 삭제는 되돌릴 수 없어요

90일 보관 기간이 지나면 삭제된 **에이전시 계정, 서브 계정, 계정 데이터**를 복구할 수 없어요.

하이퍼클래스는 **완전히 삭제된 계정 데이터의 백업을 보관하지 않으며**, 하이퍼클래스 팀도 **삭제 과정을 되돌리거나 중단할 수 없어요.**

데이터를 더 빨리 삭제하고 싶다면 데이터 삭제 요청 폼으로 요청할 수 있어요. 요청 방법은 하이퍼클래스 고객지원에 문의하세요.

{% hint style="warning" %}
계정이 영구 삭제되면 되돌릴 수 없어요.
{% endhint %}

## 해지하기 전에 할 일

하이퍼클래스 구독을 해지하기 전에 보관하고 싶은 중요한 데이터는 내보내거나 다운로드해 두세요.

**저장해 둘 만한 데이터는 다음과 같아요.**

- 연락처
- 대화
- 캘린더와 예약
- 퍼널과 웹사이트
- 자동화
- 인보이스, 결제, 주문, 거래 내역
- 상품
- 멤버십과 코스
- 리포트, 감사 로그, 그 밖의 계정 자산

{% hint style="warning" %}
90일이 지나 계정이 영구 삭제되면 이 데이터는 복구할 수 없어요.
{% endhint %}

## 해지 전후에 선택할 수 있는 방법

상황에 따라 아래 방법을 쓸 수 있어요.

### 1. 계정 재활성화

**90일 보관 기간 안에** 계정을 재활성화하면 다시 접근할 수 있고 데이터도 유지돼요.

90일 안에 재활성화하지 않으면 에이전시 계정, 서브 계정, 연결된 데이터가 영구 삭제돼요.

### 2. 데이터 조기 삭제 요청

**90일 보관 기간이 끝나기 전에** 데이터를 삭제하고 싶다면 데이터 삭제 요청 폼으로 요청하세요. 요청 방법은 하이퍼클래스 고객지원에 문의하세요.

### 3. 계정 일시 중지

잠시만 해지할 계획이라면, 월 $27인 [계정 일시 중지 기능](pause-account-feature-everything-you-need-to-know.md)으로 데이터를 그대로 유지할 수 있어요.

구독을 해지하기 전에 보관하고 싶은 중요한 데이터는 내보내거나 다운로드해 두세요. 연락처, 대화, 캘린더, 예약, 퍼널, 웹사이트, 자동화, 인보이스, 결제, 상품, 멤버십/코스, 그 밖의 계정 자산이 여기에 해당할 수 있어요.

90일이 지나 계정이 영구 삭제되면 이 데이터는 **복구할 수 없어요**.

## 자주 묻는 질문

### 해지하면 데이터가 바로 삭제되나요?

아니요. 하이퍼클래스는 해지된 계정 데이터를 **해지 후 90일 동안** 보관해요.

다만 해지하면 서브 계정에서 해당 데이터와 기능을 쓸 수 없고, 워크플로우와 자동화는 작동을 멈춰요.

전화번호와 A2P 등록은 별도로 **14일** 후에 삭제돼요.

### 해지한 뒤에도 데이터를 볼 수 있나요?

해지하면 서브 계정에서 연락처, 대화, 캘린더, 퍼널 등 해당 데이터와 기능을 쓸 수 없어요.

**90일 보관 기간** 안에 계정을 재활성화하면 다시 접근할 수 있고 데이터도 유지돼요.

### 하이퍼클래스는 데이터를 얼마나 오래 보관하나요?

해지된 계정 데이터는 **해지 후 90일 동안** 보관해요.

이 기간 안에 재활성화하지 않으면 에이전시 계정, 서브 계정, 연결된 데이터가 영구 삭제돼요.

### 워크플로우와 자동화는 어떻게 되나요?

모든 워크플로우와 자동화는 **해지 후 작동을 멈춰요.**

### 전화번호와 A2P 등록은 어떻게 되나요?

전화번호와 A2P 등록은 **해지 14일 후에** 삭제돼요.

이 기간에도 전화번호 요금은 계속 청구돼요. 14일이 지나면 전화번호는 영구 삭제돼요.

### 애드온과 재판매 구독은 어떻게 되나요?

회사의 하이퍼클래스 구독을 해지하면 연결된 애드온 구독도 **자동으로 해지**돼요.

구독이 끝나면 이 애드온과 관련 기능을 쓸 수 없을 수 있어요.

### 해지한 계정을 다시 활성화할 수 있나요?

네. **90일 보관 기간** 안에 계정을 재활성화하면 다시 접근할 수 있고 데이터도 유지돼요.

### 90일이 지난 뒤에도 하이퍼클래스가 계정을 복구해 줄 수 있나요?

**아니요.**

계정이 영구 삭제되면 되돌릴 수 없어요.

90일 보관 기간이 지나면 삭제된 에이전시 계정, 서브 계정, 계정 데이터를 복구할 수 없어요. 하이퍼클래스는 완전히 삭제된 계정 데이터의 백업을 보관하지 않으며, 하이퍼클래스 팀도 삭제 과정을 되돌리거나 중단할 수 없어요.

### 90일 보관 기간이 끝나기 전에 데이터를 삭제할 수 있나요?

네. 더 빨리 삭제하고 싶다면 데이터 삭제 요청 폼으로 요청하세요. 요청 방법은 하이퍼클래스 고객지원에 문의하세요.

### 해지하는 대신 계정을 일시 중지할 수 있나요?

잠시만 해지할 계획이라면 월 $27인 [계정 일시 중지 기능](pause-account-feature-everything-you-need-to-know.md)으로 데이터를 그대로 유지할 수 있어요.

## 도움이 필요하세요?

더 자세한 내용은 하이퍼클래스 고객지원에 문의하세요. 로그인한 상태에서 화면 오른쪽 위에 있는 파란색 물음표 아이콘을 누르면 24시간 문의할 수 있어요.
