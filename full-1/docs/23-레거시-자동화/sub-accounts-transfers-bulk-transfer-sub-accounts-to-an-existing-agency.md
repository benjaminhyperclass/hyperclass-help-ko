# 서브 계정 대량 이전 — 기존 에이전시로 한꺼번에 보내기

여러 서브 계정을 다른 에이전시로 한 번에 이전하는 방법을 안내해요. 이전 요청을 보내는 방법, 진행 상황을 확인하는 방법, 받는 에이전시가 요청을 수락하거나 거절하는 방법을 다뤄요. 에이전시 관리자만 쓸 수 있어요.

## 서브 계정 대량 이전하기 (보내는 쪽)

### 1단계: 서브 계정 이전 화면으로 이동하기

1. **에이전시** 계정으로 로그인하세요.
2. **Agency Level**(에이전시 레벨) > **서브 계정** > **서브 계정 이전**으로 이동하세요.
   ![서브 계정 이전 메뉴로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026298/original/PZfmL4mcvZVXzNUpK9hP3YTOtgr0-upzYQ.png?1738737736)
3. **Bulk Transfer Subaccount**(서브 계정 대량 이전) 버튼을 클릭하세요.
   ![서브 계정 대량 이전 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026306/original/2EDhuBSGMauo4NkBOgNmNKrGD2Adrkdb8w.png?1738737746)
4. **계속하기**를 클릭해 다음 단계로 이동하세요.
   ![계속하기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026314/original/XQcXWXVqS9KZeUVZvxfgmLm0HRMTVuefnw.png?1738737761)

### 2단계: 이전할 서브 계정 선택하기

다음 화면에서는 이전할 서브 계정을 고르는 방법이 두 가지 있어요.
![서브 계정 선택 방법 두 가지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026364/original/vL8mCefA6U4ypVZGwF7zWIxbSMEV224IzA.png?1738737838)

- **Select from the List**(목록에서 선택)
  - 서브 계정을 검색해서 원하는 계정만 선택하세요.
  - 모든 서브 계정을 이전하려면 **전체 선택**을 사용하세요. (한 번에 최대 1,000개까지 선택할 수 있어요.)
    ![목록에서 서브 계정 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026324/original/SeGbO3UNwrBM_B99GuAy0shQMJr0LyQDCg.png?1738737794)
- **Enter Location IDs**(로케이션 ID 입력)
  - 이전할 서브 계정의 **Location IDs**(로케이션 ID)를 직접 입력하세요.
  - ID는 쉼표로 구분해서 정확하게 입력하세요. (예: `12345,67890,54321`)
    ![로케이션 ID 직접 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026333/original/_KoqNJiLqb7qMB0GPDANC3n1uS8D5MCuYw.png?1738737812)

### 3단계: 받는 에이전시의 관계 번호 입력하기

1. 선택한 서브 계정을 받을 에이전시의 **관계 번호**를 입력하세요.
2. 번호가 맞는지 한 번 더 확인하세요.
   ![관계 번호 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026418/original/C2L66nD5viNUIINnTAwhWxb8gLuUyLRRDg.png?1738737899)

### 4단계: 이전 요청 확인하고 보내기

1. 이전 내용을 확인하세요.
2. **비밀번호를 입력하세요** 입력란에 비밀번호를 입력하고 **확인**을 클릭하면 받는 에이전시에 이전 요청이 전달돼요.
3. 받는 에이전시가 요청을 승인하면 서브 계정이 이전돼요.
   ![이전 요청 확인 및 발송 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041026433/original/e7RpvtQcQ5BG6T1MFNsZFQIRLmUht9DrgQ.png?1738737934)

### 이전 요청 진행 상황 확인하기

**서브 계정 이전** 화면의 **발송됨** 탭에서 이전 요청의 진행 상황을 확인할 수 있어요.

1. **대량 요청** 탭으로 이동하세요.
   ![대량 요청 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041027602/original/cwkL0rbMiSZtb8Q8XSBQDRu8v45z2SuXzA.png?1738739231)
2. **상세 보기**를 클릭하면 이전 요청에 포함된 서브 계정별 상태를 볼 수 있어요.
   ![상세 보기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041027588/original/ZHD5GzkCoDERHAKTS9AXc69ikOf-iWhOqg.png?1738739219)

**전환 상태** 값의 의미는 다음과 같아요.

- **완료**: 받는 에이전시가 서브 계정 이전을 수락했어요.
- **거절됨**: 받는 에이전시가 이전 요청을 거절했어요.
- **대기 중**: 받는 에이전시가 아직 요청에 아무 조치도 하지 않았어요.
- **실패**: 이전할 수 없는 서브 계정이에요. (예: HIPAA 또는 SaaS 제한)

{% hint style="info" %}
받는 에이전시는 대량 이전 요청에 포함된 서브 계정을 모두 수락하거나 모두 거절할 수만 있어요. 일부만 승인하는 것은 안 돼요.
{% endhint %}

## 받는 에이전시가 이전 요청을 수락하거나 거절하기

### 1단계: 알림 확인하고 요청 화면으로 이동하기

- 이전 요청이 들어오면 받는 에이전시 소유자에게 **이메일 알림**이 가요.

- 앱 안에서도 **앱 내 알림**이 표시돼요. 알림을 누르면 **서브 계정 이전** 화면의 **수신됨** 섹션으로 이동해요.
  ![앱 내 알림](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041027050/original/yBbExYsLgnHQxrQddqhtNPJz3cGIyhfxtQ.png?1738738628)
  ![수신됨 섹션으로 이동한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041027188/original/FWwZp29CQw44dU9b3cz19Gn5eNsu7fiLWA.png?1738738729)

### 2단계: 이전 요청 검토하기

1. **Take Action**(조치하기)을 클릭하면 이전 요청에 포함된 서브 계정 목록을 볼 수 있어요.
   ![조치하기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041027399/original/NUmnIa_-QJ-ToOhb04NJkdvPzyvZfWbKeg.png?1738739017)

   ![서브 계정 상세 정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041027204/original/BnnU-Qg7QBd2vVxfKngqLE1FEUae9WHLFw.png?1738738763)

{% endhint %}

## 이전되는 정보와 자산

- 웹사이트와 퍼널이 모두 이전돼요.
- 하이퍼클래스 캘린더가 이전돼요.
  {% hint style="info" %}
  외부 캘린더 연동은 연결이 해제돼요.
  {% endhint %}
- 모든 자동화가 라이브 상태로 이전돼요.
- 연락처와 연락처의 대화, 예약, 기회, 이력이 이전돼요.
- 연락처는 워크플로우에 그대로 남아 있어요.
- 워크플로우에 등록된 데이터도 워크플로우 안에 그대로 있어요.
- 멤버십 접근 권한이 유지돼요.
- 서브 계정 단위 API 키는 그대로 유지돼요.
- **User Type**(사용자 유형)이 **Account**(계정)이고, 이전하는 서브 계정에만 배정된 사용자만 이전돼요. 다른 서브 계정에도 배정된 사용자는 이전되지 않아요.

## 이전되지 않는 정보와 자산

{% hint style="warning" %}
아래 항목은 이전되지 않아요. 이전 전에 꼭 확인하세요.
{% endhint %}

- 모든 인증 연결이 삭제돼요. (예: Google, Facebook, Instagram, Quickbooks, Clio, DrChrono, Yext)
- Facebook과 Google 설정이 모두 초기화돼요.
- 서브 계정 단위 Stripe 필드가 초기화돼요.
- SaaS 설정은 이전되지 않아요.
  {% hint style="info" %}
  이전이 진행되기 전에 SaaS 모드가 자동으로 비활성화돼요.
  {% endhint %}
- 스마트 리스트는 현재 서브 계정과 함께 이전되지 않아요.
- Mailgun/SMTP는 이전되지 않아요.
- WordPress, Yext, WhatsApp, 전용 IP 등 사용 중인 구독은 이전되지 않아요. 이전하기 전에 먼저 해지해야 해요.

## 전화번호 이전

### 두 에이전시 모두 하이퍼클래스 전화를 쓰는 경우

- 보내는 에이전시, 받는 에이전시, 이전할 서브 계정이 모두 하이퍼클래스 전화를 쓰면 전화번호가 서브 계정과 함께 자동으로 이전돼요.
- A2P DLC 등록 상태는 그대로 유지돼요. 이미 등록한 전화번호는 서브 계정에서 다시 등록하지 않아도 돼요.
- 이후 발생하는 전화 사용 요금은 모두 받는 에이전시에 부과돼요.

### 하이퍼클래스 전화를 쓰지 않는 에이전시가 있는 경우 (한쪽 또는 양쪽이 Twilio)

하이퍼클래스에서는 전화번호를 이전하지 않아요. 이전한 서브 계정에 계속 연결해 두고 싶은 전화번호가 있다면, 이전 계정 소유자 및 Twilio와 직접 협의해서 옮겨야 해요.

궁금한 점이 있으면 하이퍼클래스 고객지원에 문의하세요.

## 서브 계정 이전 FAQ

### 서브 계정 하나를 다른 서브 계정과 합칠 수 있나요?
아니요. 서브 계정 이전은 서브 계정 안의 데이터만 옮기는 것이 아니라, 서브 계정 전체를 한 에이전시에서 다른 에이전시로 옮기는 거예요.

### HIPAA가 활성화된 서브 계정도 이전할 수 있나요?
받는 에이전시도 하이퍼클래스 마켓플레이스에서 **HIPAA 규정 준수** 애드온 패키지를 구매한 경우에만 HIPAA 규정을 준수하는 서브 계정을 이전할 수 있어요.

### 이전하기 전에 서브 계정에서 미리 준비해야 할 것이 있나요?
- 이전하려는 사용자는 모두 **User Type**(사용자 유형)을 **Account**로 설정하고, 이전하는 서브 계정에만 배정하세요.
- SaaS를 쓰는 서브 계정은 SaaS를 비활성화해야 해요.
- WordPress, Yext, WhatsApp, 전용 IP 등 사용 중인 구독은 이전을 요청하기 전에 모두 해지해야 해요.

### 이전이 끝난 뒤에는 어떤 설정을 다시 해야 하나요?
- 모든 인증 연결(예: Google, Facebook, Quickbooks, Clio, DrChrono)을 다시 연결하세요.
- Facebook과 Google을 다시 연동하세요.
- 서브 계정 단위 Stripe를 다시 설정하세요.
- 하이퍼클래스 이메일, Mailgun/SMTP, Twilio를 다시 추가하세요.
- 도메인을 다시 추가하세요.
- SaaS를 쓰던 서브 계정은 SaaS를 다시 활성화하세요.

### 서브 계정을 이전하면 삭제한 워크플로우가 **삭제됨** 탭에 보이나요?
이전 서브 계정에서 삭제한 워크플로우는 새 서브 계정에서 보이지 않아요. 새 서브 계정에서 삭제한 워크플로우만 **삭제됨** 탭에 표시돼요.
