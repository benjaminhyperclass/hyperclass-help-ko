# 커스텀 값 사용하기

커스텀 값은 커뮤니케이션, 페이지, 워크플로우 등 지원되는 기능 곳곳에서 같은 정보를 반복해서 쓸 수 있게 해 주는 재사용 가능한 자리표시자예요. 커스텀 값을 한 번 만들어 두고, 그 정보가 필요한 곳마다 병합 필드를 넣으면 돼요.

예를 들어 지원 이메일 주소, 회사 전화번호, 웹사이트 URL, 면책 문구, 마무리 인사말, 자주 쓰는 메시지를 커스텀 값으로 만들 수 있어요.

커스텀 값을 수정하면, 그 값을 사용하는 모든 곳에 수정된 내용이 반영돼요.

{% hint style="warning" %}
커스텀 값은 재사용하는 정보를 위한 기능이에요. 연락처나 기회마다 달라지는 정보를 저장하려면 **커스텀 필드**를 사용하세요.
{% endhint %}

## 커스텀 값이란?

커스텀 값은 **설정 > 커스텀 값**에서 만드는, 이름과 값으로 이루어진 재사용 가능한 쌍이에요.

커스텀 값 하나에는 다음이 들어 있어요.

- 값을 구분하기 위한 이름
- 커스텀 값을 사용할 때 표시되는 저장된 값
- 지원되는 영역에 넣을 수 있는 병합 필드

예를 들어 이렇게 만들 수 있어요.

**이름:** 지원 이메일
**값:** [support@example.com](mailto:support@example.com)

그런 다음 해당 커스텀 값의 병합 필드를 이메일, 워크플로우, 웹사이트, 퍼널 등 지원되는 콘텐츠에 넣으면 돼요.

나중에 지원 이메일이 바뀌어도 이메일 주소가 들어간 곳을 하나하나 고칠 필요 없이 커스텀 값 한 곳만 수정하면 돼요.

## 커스텀 값의 주요 장점

- 한곳에서 관리: 자주 쓰는 정보를 한 곳에 저장해 두고, 지원되는 기능 전반에서 다시 사용해요.
- 일관성: 이메일, 메시지, 워크플로우, 페이지 등에서 매번 직접 입력하지 않고도 같은 정보를 쓸 수 있어요.
- 쉬운 업데이트: 원본 커스텀 값을 수정하면 그 값을 쓰는 모든 곳의 정보가 바뀌어요.
- 자동화: 지원되는 워크플로우 액션, 메시지, 알림 등 자동화된 콘텐츠에 커스텀 값을 넣을 수 있어요.
- **개인화**: 커스텀 값을 다른 병합 필드와 함께 써서 상황에 맞게 달라지는 메시지와 경험을 만들 수 있어요.
- 유연한 정리: 비즈니스에 필요한 정보로 커스텀 값을 만들고, 폴더로 나눠 관리할 수 있어요.

## 커스텀 값과 커스텀 필드의 차이

커스텀 값과 커스텀 필드는 쓰임새가 달라요.

**커스텀 값**은 어디에서 쓰든 똑같이 유지되는 재사용 정보를 저장해요.

예를 들면 다음과 같아요.

- 지원 이메일 주소
- 비즈니스 전화번호
- 웹사이트 URL
- 표준 면책 문구
- 브랜드 슬로건
- 영업시간
- 자주 쓰는 링크

**커스텀 필드**는 연락처나 기회처럼 개별 레코드에 연결된 정보를 저장해요.

예를 들면 다음과 같아요.

- 연락처가 선호하는 서비스
- 멤버십 등급
- 관심 상품
- 계약 갱신일
- 고객 선호 사항

같은 정보를 반복해서 쓰고 싶다면 커스텀 값을, 레코드마다 정보가 달라질 수 있다면 커스텀 필드를 사용하세요.

## 커스텀 값 만들기, 편집하기, 삭제하기

### 커스텀 값 화면으로 이동하기

1. **설정**으로 이동하세요.
2. **커스텀 값**을 선택하세요.

### 커스텀 값 만들기

1. **+ 커스텀 값 추가**를 클릭하세요.

   ![커스텀 값 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081196452/original/qoCoR58ioue7ck3y3QY64f3FVmw8Ao4FNA.png?1789653711)
2. **이름**에 커스텀 값의 이름을 입력하세요.
3. **값**에 표시할 내용을 입력하세요.
4. 값을 폴더로 정리하려면 **폴더 선택**에서 폴더를 고르세요.
5. **저장**을 클릭하세요.

   ![커스텀 값 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081196519/original/3On40K5QtaBbl9bjrPzz7y7i5gbczLNxpg.png?1789653743)

### 커스텀 값 편집하기

1. **설정 > 커스텀 값**으로 이동하세요.
2. 수정할 커스텀 값을 찾으세요.
3. 값 옆의 점 세 개 메뉴(⋮)를 클릭하세요.
4. **커스텀 값 편집**을 선택하세요.
5. 내용을 수정하세요.
6. **저장**을 클릭하세요.

![커스텀 값 편집 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081196356/original/Sm1-pcy6YkwG1rYmzV52a-P0WLuw1MgzgA.png?1789653655)

원본 커스텀 값을 수정하면 그 값을 사용하는 모든 곳의 정보가 함께 바뀌어요.

### 커스텀 값 삭제하기

1. **설정 > 커스텀 값**으로 이동하세요.
2. 삭제할 커스텀 값을 찾으세요.
3. 값 옆의 점 세 개 메뉴(⋮)를 클릭하세요.
4. **삭제**를 선택하세요.
5. 삭제를 확인하세요.

![커스텀 값 삭제 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081196121/original/56j3Rps8vsS5VhSr29rQQ28dmeDjE7PVSw.png?1789653585)

커스텀 값을 삭제하기 전에 템플릿, 워크플로우, 페이지 등 다른 콘텐츠에서 더 이상 필요하지 않은지 확인하세요.

## 활용 예시

커스텀 값은 여러 곳에서 다시 써야 하는 정보에 잘 맞아요.

**예시 1: 비즈니스 연락처 정보**

같은 지원 정보를 커뮤니케이션마다 자주 넣는다고 해 볼게요.

다음 항목을 커스텀 값으로 만들 수 있어요.

- 지원 전화번호
- 지원 이메일 주소
- 사업장 주소
- 웹사이트 URL
- 영업시간

이 값들을 이메일 템플릿, 워크플로우, 페이지 등 지원되는 콘텐츠에 넣을 수 있어요.

전화번호나 이메일 주소가 바뀌면 항목마다 고치지 않고 커스텀 값만 수정하면 돼요.

**예시 2: 표준 문구**

다음처럼 자주 다시 쓰는 콘텐츠도 커스텀 값으로 만들 수 있어요.

- 이메일 마무리 인사말
- 규정 준수 문구
- 면책 문구
- 프로모션 메시지
- 자주 쓰는 URL
- 시즌 인사말

반복해서 쓰는 콘텐츠를 일관되게 유지하는 데 도움이 돼요.

## 커스텀 값을 쓸 수 있는 곳

커스텀 값은 지원되는 여러 기능에서 쓸 수 있어요.

편집 중인 필드나 기능에 따라 사용 가능 여부가 다를 수 있어요. 병합 필드 또는 커스텀 값 선택기가 보이면 그것을 사용하세요.

### 1. 대화

지원되는 대화 메시지에 커스텀 값을 넣어 정보를 직접 입력하지 않고 재사용할 수 있어요.

커뮤니케이션 채널과 에디터에 따라 커스텀 값을 연락처, 사용자 등 다른 병합 필드와 함께 쓸 수도 있어요.

### 2. 자동화와 워크플로우

지원되는 워크플로우 필드, 액션, 메시지, 알림에 커스텀 값을 넣을 수 있어요.

**워크플로우 텍스트 필드에서 동적 값 추가·편집하기**

지원되는 워크플로우 텍스트 필드에서는 인식된 동적 값이 칩 형태로 표시돼요.

다음 작업을 할 수 있어요.

- 값 넣기: 지원되는 워크플로우 텍스트 필드에 `/`를 입력하면 값을 검색해서 넣을 수 있어요.
- 값 바꾸기: 이미 들어 있는 값 칩을 클릭한 다음, 사용 가능한 다른 값을 선택하세요.
- 잘못된 값 확인하기: 인식되지 않거나 오래된 값은 빨간색으로 강조돼 보일 수 있어요. 이럴 때는 선택기에서 지원되는 값으로 바꾸세요.

워크플로우가 커스텀 값을 자동으로 바꾸게 하려면 **Update Custom Value**(커스텀 값 업데이트) 워크플로우 액션을 사용하세요.

### 3. 웹사이트와 퍼널

지원되는 웹사이트·퍼널 콘텐츠에 커스텀 값을 넣을 수 있어요.

다음처럼 재사용하는 정보에 유용해요.

- 비즈니스 연락처 정보
- 지원 정보
- 링크
- 표준 문구
- 프로모션 정보

일부 동적 병합 필드는 해당 레코드의 데이터가 있어야 값이 표시돼요.

### 4. 이메일 캠페인과 템플릿

이메일 빌더의 지원되는 영역에서 커스텀 값을 사용해 재사용 가능하고 동적인 이메일 콘텐츠를 만들 수 있어요.

필드에 따라 다음과 같은 영역에서 값을 쓸 수 있어요.

- 이메일 본문
- 제목
- 발신자 정보
- 지원되는 디자인 설정

**배경 색상**, **본문 색상**, **버튼 색상** 같은 색상 입력란에서도 커스텀 값을 쓸 수 있어요.

색상이 담긴 지원되는 커스텀 값을 입력하면 빌더가 캔버스에 그 색을 바로 적용해요.

### 5. 소셜 플래너

지원되는 **소셜 플래너** 콘텐츠에 커스텀 값을 넣을 수 있어요.

소셜 게시글을 만들 때 공통 정보, 메시지, 링크 등을 다시 쓰는 데 도움이 돼요.

## 커스텀 값을 폴더로 정리하기

목록이 늘어나도 폴더를 쓰면 커스텀 값을 깔끔하게 관리할 수 있어요.

관련 있는 값끼리 묶어 둘 수 있어요. 예를 들면 다음과 같아요.

- 연락처 정보
- 사업 세부정보
- 링크
- 법률 또는 규정 준수 문구
- 프로모션 콘텐츠
- 내부용 정보

커스텀 값을 만들거나 편집할 때 알맞은 폴더에 지정하세요.

이름을 알아보기 쉽게 짓고 폴더를 논리적으로 나누면, 커스텀 값 선택기에서 값을 더 쉽게 찾을 수 있어요.

## 커스텀 값과 병합 필드

커스텀 값은 병합 필드를 사용해 저장된 정보를 동적으로 넣어요.

병합 필드는 이중 중괄호를 사용해요. 예: `{{contact.first_name}}`

지원되는 콘텐츠가 표시되거나 발송될 때 병합 필드는 해당하는 정보로 바뀌어요.

기능과 상황에 따라 사용할 수 있는 병합 필드 분류가 달라요.

일반적인 분류는 다음과 같아요.

- 연락처
- 사용자
- 예약
- 캘린더
- 캠페인
- 메시지
- 계정
- Right Now(현재 시각)
- 어트리뷰션
- 인보이스
- 코스
- 서비스 예약
- 커스텀 값

{% hint style="info" %}
병합 필드 선택기가 있으면 선택기로 필드를 넣는 것을 권장해요. 설정하는 기능에 맞는 필드를 정확히 쓸 수 있어요.
{% endhint %}

## 연락처 병합 필드

연락처 병합 필드는 연락처 레코드의 정보를 가져와요.

자주 쓰는 예시는 다음과 같아요.

| 이름 | 병합 필드 |
| --- | --- |
| 전체 이름 | `{{contact.name}}` |
| 이름 | `{{contact.first_name}}` |
| 성 | `{{contact.last_name}}` |
| 이메일 | `{{contact.email}}` |
| 전화번호 | `{{contact.phone}}` |
| 전화번호 — 원본 형식 | `{{contact.phone_raw}}` |
| 회사명 | `{{contact.company_name}}` |
| 전체 주소 | `{{contact.full_address}}` |
| 도시 | `{{contact.city}}` |
| 시/도(주) | `{{contact.state}}` |
| 우편번호 | `{{contact.postal_code}}` |
| 시간대 | `{{contact.timezone}}` |
| 생년월일 | `{{contact.date_of_birth}}` |
| 소스 | `{{contact.source}}` |
| 웹사이트 | `{{contact.website}}` |
| 연락처 ID | `{{contact.id}}` |

## 사용자 병합 필드

사용자 병합 필드는 활동, 대화, 예약과 관련된 해당 사용자의 정보를 가져와요.

자주 쓰는 예시는 다음과 같아요.

| 이름 | 병합 필드 |
| --- | --- |
| 전체 이름 | `{{user.name}}` |
| 이름 | `{{user.first_name}}` |
| 성 | `{{user.last_name}}` |
| 이메일 | `{{user.email}}` |
| 전화번호 | `{{user.phone}}` |
| 전화번호 — 원본 형식 | `{{user.phone_raw}}` |
| 이메일 서명 | `{{user.email_signature}}` |
| 예약 링크 | `{{user.calendar_link}}` |

사용할 수 있는 값은 상황에 따라 달라질 수 있어요. 병합 필드 선택기에서 지원되는 값을 선택하세요.

## 예약 병합 필드

예약 병합 필드는 예약 레코드의 정보를 가져와요.

자주 쓰는 예시는 다음과 같아요.

| 이름 | 병합 필드 |
| --- | --- |
| 제목 | `{{appointment.title}}` |
| 시작 날짜 및 시간 | `{{appointment.start_time}}` |
| 시작 날짜 | `{{appointment.only_start_date}}` |
| 시작 시간 | `{{appointment.only_start_time}}` |
| 종료 날짜 및 시간 | `{{appointment.end_time}}` |
| 종료 날짜 | `{{appointment.only_end_date}}` |
| 종료 시간 | `{{appointment.only_end_time}}` |
| 요일 | `{{appointment.day_of_week}}` |
| 시간대 | `{{appointment.timezone}}` |
| 취소 링크 | `{{appointment.cancellation_link}}` |
| 일정 변경 링크 | `{{appointment.reschedule_link}}` |
| 미팅 장소 | `{{appointment.meeting_location}}` |
| 메모 | `{{appointment.notes}}` |

예약 필드에는 배정된 사용자 정보와 캘린더 링크도 들어갈 수 있어요.

## 캘린더 및 캠페인 병합 필드

지원되는 캘린더·캠페인 병합 필드로 캘린더 이벤트와 캠페인 일정에 관한 정보를 넣을 수 있어요.

**예시:**

`{{calendar.name}}`

`{{campaign.event_date_time}}`

`{{campaign.event_date}}`

`{{campaign.event_time}}`

## 메시지 병합 필드

메시지 병합 필드는 현재 메시지의 정보를 가져와요.

**예시:**

`{{message.body}}`

`{{message.subject}}`

## 계정 병합 필드

계정 병합 필드는 저장된 비즈니스 정보를 제공해요.

**예시:**

| 이름 | 병합 필드 |
| --- | --- |
| 이름 | `{{location.name}}` |
| 전체 주소 | `{{location.full_address}}` |
| 주소 | `{{location.address}}` |
| 도시 | `{{location.city}}` |
| 시/도(주) | `{{location.state}}` |
| 국가 | `{{location.country}}` |
| 우편번호 | `{{location.postal_code}}` |
| 이메일 | `{{location.email}}` |
| 전화번호 | `{{location.phone}}` |
| 웹사이트 | `{{location.website}}` |
| 로고 URL | `{{location.logo_url}}` |
| ID | `{{location.id}}` |

이 이름들은 시스템 병합 필드 이름이에요. 가능하면 선택기를 통해 넣으세요.

## Right Now 병합 필드

Right Now 병합 필드는 현재 날짜와 시간 정보를 넣어요.

**예시:**

`{{right_now.second}}`

`{{right_now.minute}}`

`{{right_now.hour}}`

`{{right_now.hour_ampm}}`

`{{right_now.ampm}}`

`{{right_now.day_of_week}}`

`{{right_now.month_name}}`

`{{right_now.day}}`

`{{right_now.month}}`

`{{right_now.year}}`

`{{right_now.middle_endian_date}}`

`{{right_now.little_endian_date}}`

콘텐츠에서 현재 날짜나 시간을 동적으로 보여 줘야 할 때 유용한 값이에요.

## 어트리뷰션 병합 필드

어트리뷰션 병합 필드는 연락처가 어떻게 유입됐는지, 또는 가장 최근에 마케팅과 어떻게 상호작용했는지에 관한 정보를 제공해요.

사용할 수 있는 필드는 다음과 같아요.

- 세션 소스
- URL
- 캠페인
- UTM 소스
- UTM 매체
- UTM 콘텐츠
- 리퍼러
- 캠페인 ID
- Facebook 클릭 ID
- Google 클릭 ID
- UTM 키워드
- UTM 일치 유형
- 광고 그룹 ID
- 광고 ID

최초 어트리뷰션 필드는 연락처의 처음 어트리뷰션 데이터를 쓰고, 최근 어트리뷰션 필드는 가장 최근에 확인된 어트리뷰션 데이터를 써요.

설정 중인 기능에서 지원하는 정확한 어트리뷰션 값은 병합 필드 선택기에서 고르세요.

## 원본 전화번호 형식

일부 전화번호 병합 필드는 원본 형식으로 쓸 수 있어요.

**예:** `{{contact.phone_raw}}`

원본 전화번호 값은 공백, 괄호, 하이픈 같은 서식을 없앤 값이에요.

이런 경우에 유용해요.

- 국제 전화번호
- 링크
- 트래킹 파라미터
- 서식 없는 번호가 필요한 다른 필드

## 자주 묻는 질문

### 커스텀 값과 커스텀 필드는 어떻게 다른가요?

커스텀 값은 어디에 넣든 똑같이 유지되는 재사용 정보를 저장해요.

커스텀 필드는 연락처나 기회처럼 개별 레코드에 연결된 정보를 저장해요.

### 커스텀 값을 수정하면 어떻게 되나요?

그 커스텀 값을 참조하는 모든 곳에서 새 값이 사용돼요.

### 커스텀 값을 정리할 수 있나요?

네. 커스텀 값을 폴더로 나누면 관리하고 찾기가 더 쉬워져요.

### 웹사이트와 퍼널에서도 커스텀 값을 쓸 수 있나요?

네. 해당하는 웹사이트·퍼널 필드에서 커스텀 값이 지원돼요.

### 워크플로우에서도 커스텀 값을 쓸 수 있나요?

네. 지원되는 워크플로우 필드에 커스텀 값을 넣을 수 있어요. 지원되는 경우 워크플로우의 **Update Custom Value** 액션으로 커스텀 값을 바꿀 수도 있어요.

### 병합 필드에 값이 없으면 어떻게 되나요?

기능에 따라 동작이 다를 수 있어요. 대부분의 경우, 해당 데이터가 없는 병합 필드는 빈칸으로 표시돼요.

실제 커뮤니케이션이나 자동화에 쓰기 전에 필요한 원본 정보가 있는지 확인하세요.

### 병합 필드는 대소문자를 구분하나요?

네. 선택기에 표시된 그대로 병합 필드를 사용하세요.

### 병합 필드는 어떻게 넣는 게 좋나요?

병합 필드 또는 커스텀 값 선택기가 있으면 선택기를 사용하세요. 해당 기능에서 지원되는 값을 정확히 고를 수 있어요.

### 현재 지원되는 병합 필드 전체 목록은 어디에서 볼 수 있나요?

하이퍼클래스 도움말 센터의 병합 필드 목록 문서에서 현재 지원되는 병합 필드를 확인하세요.
