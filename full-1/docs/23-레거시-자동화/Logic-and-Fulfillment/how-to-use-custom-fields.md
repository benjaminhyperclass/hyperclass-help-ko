# 커스텀 필드 사용하기

커스텀 필드를 쓰면 이름, 이메일, 전화번호 같은 기본 연락처 정보 외의 내용도 저장하고 정리할 수 있어요. 비즈니스 방식에 맞게 레코드, 폼, 워크플로우, 파이프라인을 꾸며 리드와 기회를 더 잘 관리해 보세요.

## 커스텀 필드란?

커스텀 필드는 계정에 기본으로 있는 필드 외에, 연락처나 기회에 대한 정보를 추가로 저장하는 필드예요.

커스텀 필드는 다음 위치에서 쓸 수 있어요.

- 폼
- 설문
- 파이프라인
- 워크플로우
- 자동화
- 스마트 리스트
- 연락처 레코드
- 기회 레코드

커스텀 필드로 비즈니스에 맞는 다음과 같은 정보를 모을 수 있어요.

- 리드 유형
- 예산 범위
- 선호 연락 방법
- 유입 경로
- 부동산 유형
- 계약까지 걸리는 기간

이렇게 하면 레코드가 깔끔해지고, 고객 분류가 쉬워지며, 자동화도 더 개인화할 수 있어요.

## 커스텀 필드의 장점

커스텀 필드는 계정과 자동화 설정에 유연함과 체계를 더해 줘요.

- 비즈니스에 맞는 데이터를 수집할 수 있어요.
- 연락처와 딜 정보를 더 효율적으로 정리할 수 있어요.
- 병합 필드를 사용해 이메일과 SMS 자동화를 개인화할 수 있어요.
- 더 정교한 스마트 리스트와 워크플로우 필터를 만들 수 있어요.
- 중요한 정보를 레코드와 파이프라인 안에 바로 보여 줄 수 있어요.
- 관련된 필드를 폴더로 묶어 레이아웃을 깔끔하게 만들 수 있어요.

## 연락처 커스텀 필드와 기회 커스텀 필드

연락처 필드와 기회 필드는 시스템 안에서 동작이 달라요. 그래서 알맞은 유형을 고르는 것이 중요해요.

### 연락처 커스텀 필드

연락처 커스텀 필드는 사람에게 직접 연결돼요.

연락처 필드는 다음과 같은 정보에 사용하세요.

- 구매자 또는 판매자 유형
- 생일
- 선호 연락 방법
- 유입 경로
- 비즈니스 웹사이트

연락처 필드는 다음 위치에서 쓸 수 있어요.

- 연락처 레코드
- 폼
- 설문
- 연락처 워크플로우
- 스마트 리스트
- 이메일·SMS 개인화

### 기회 커스텀 필드

기회 커스텀 필드는 특정 딜(영업 기회)에 속해요.

기회 필드는 다음과 같은 정보에 사용하세요.

- 예산 범위
- 부동산 유형
- 딜 긴급도
- 계약까지 걸리는 기간
- 영업 단계 상세 정보

기회 필드는 다음 위치에 나타나요.

- 기회 레코드
- 파이프라인 보기
- 기회 워크플로우
- 딜 리포팅 및 자동화

{% hint style="info" %}
필드를 연락처 필드나 기회 필드로 한번 만들면 다른 유형으로 바꿀 수 없어요.
{% endhint %}

## 폴더로 커스텀 필드 정리하기

폴더는 관련된 필드를 섹션으로 묶어서 레코드를 깔끔하고 탐색하기 쉽게 만들어 줘요. 폴더는 레코드 레이아웃 안에 그대로 표시되고, 관련 정보를 한곳에 모아 보여 줘요.

폴더 이름 예시는 다음과 같아요.

- 구매자 정보
- 부동산 세부 정보
- 영업 적격성 판단
- 예약 선호 사항

### 폴더 만들기

1. **설정**을 엽니다.
2. **커스텀 필드**로 이동합니다.
3. 오브젝트 선택기에서 관리할 오브젝트를 고릅니다.
4. **폴더** 탭을 엽니다.
5. **폴더 만들기**를 클릭합니다.
6. 폴더 이름을 입력합니다.
7. **저장**을 클릭합니다.

폴더를 만든 뒤에는 필드를 폴더에 지정해 더 체계적으로 정리할 수 있어요.

## 커스텀 필드 만들기

다음 순서를 따라 계정에서 커스텀 필드를 만들고 정리해 보세요.

1. **설정 > 커스텀 필드**로 이동합니다. 계정에서 **설정**을 클릭한 다음 **커스텀 필드**를 클릭하세요.

   ![설정에서 커스텀 필드 메뉴 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079788258/original/Geeq2-Ipr1WJ5QcFAsuNs-A2yKdvRQUzqQ.png?1788259685)

2. 오브젝트를 선택합니다. 페이지 맨 위의 오브젝트 선택기에서 관리할 오브젝트를 고르세요.
3. **필드** 탭을 엽니다. **필드** 탭에서 기존 필드를 확인하고 새 필드를 만들 수 있어요.

   ![필드 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072345406/original/ArQjXTbBSaOsAf_SSKGA7cQQeD6LjThitw.png?1779911757)

4. 페이지 오른쪽 위의 **필드 만들기**를 클릭합니다.
5. **필드 유형 선택** 화면에서 만들려는 필드 유형을 고릅니다.

   ![필드 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069290219/original/WlNtThFx6snR4gViN1jaJQJGxgatzCMoPQ.png?1776338844)

6. 필드 이름 등 필드 정보를 입력합니다. 필요하면 폴더도 지정하세요.

   ![필드 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069290765/original/6zaShf6HHJz7SAL7gro4_9WumqfukG6YWw.png?1776339089)

7. **실시간 미리보기** 패널에서 필드가 어떻게 보일지 확인합니다.

   ![실시간 미리보기 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069291322/original/EPYVFabzkOzqPJKnuMsnoK2DdkBzTkKCUA.png?1776339395)

8. **커스텀 필드 만들기**를 클릭해 필드를 저장합니다.

   ![커스텀 필드 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069291497/original/LEN3EzAyraO2t3sfRVZy7T0pi0QgOfAHSQ.png?1776339485)

### 커스텀 필드 페이지 활용하기

커스텀 필드 페이지는 레이아웃이 새로워져서 필드를 더 효율적으로 관리할 수 있어요.

1. 페이지 맨 위의 오브젝트 선택기로 지원되는 오브젝트 사이를 전환하세요.
2. **필드** 탭에서 커스텀 필드를 확인하고 관리하세요.
3. **폴더** 탭에서 폴더를 만들고 관리하세요.
4. 열 기준으로 표를 정렬하면 필드를 더 빨리 찾을 수 있어요.
5. 필드 목록의 아이콘으로 특별한 상태의 필드를 구분하세요.

## 자주 묻는 질문

### 연락처 필드를 기회 필드로(또는 그 반대로) 바꿀 수 있나요?

아니요. 알맞은 오브젝트 유형으로 필드를 다시 만들어야 해요. 필드의 오브젝트는 만든 뒤에 바꿀 수 없어요.

### 어떤 유형의 필드를 만들 수 있나요?

**Short Text**(짧은 텍스트), **Long Text**(긴 텍스트), **Drop downs**(드롭다운), **Date Pickers**(날짜 선택), **Phone**(전화번호), **Email**(이메일), **Radio Selects**(라디오 선택), **Checkbox Groups**(체크박스 그룹), **URLs**(URL) 등을 만들 수 있어요.

### 만든 필드가 폼이나 워크플로우에 안 보여요.

오브젝트 유형이 사용하려는 곳과 맞는지 확인하세요. 폼과 연락처 워크플로우에는 연락처 필드만 나타나요.

### **Dropdown (multiple)**(다중 선택 드롭다운) 커스텀 필드에는 옵션을 몇 개까지 넣을 수 있나요?

**Dropdown (multiple)** 필드에는 옵션을 50개 이상 넣을 수 있어서 사실상 제한이 없어요.

## 도움이 필요하신가요?

커스텀 필드를 만들거나 정리하다가 문제가 생기면 하이퍼클래스 고객지원이나 시스템 관리자에게 문의하세요.
