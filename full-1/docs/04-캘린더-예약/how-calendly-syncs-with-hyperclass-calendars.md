# Calendly와 하이퍼클래스 캘린더 동기화 방식

Calendly 연동을 연결한 뒤 Calendly와 하이퍼클래스 사이에서 동기화가 어떻게 이루어지는지 설명해요. 어떤 정보가 동기화되는지, 예약과 연락처가 어떻게 처리되는지, 어떤 제한이 있는지 알아볼 수 있어요.

## 동기화 이해하기

하이퍼클래스 캘린더를 Calendly와 동기화하면, 선택한 Calendly 캘린더로 새로 예약된 이벤트가 하이퍼클래스에 예약으로 자동 표시돼요. 직접 입력하지 않아도 연락처가 만들어지고, 실시간 예약을 기준으로 자동화 트리거가 작동해요.

이 연동은 단방향 동기화예요. Calendly의 이벤트를 하이퍼클래스로 가져오기만 하고, 반대 방향으로는 보내지 않아요.

- 동기화는 **캘린더 설정 > 연결**에서 연동을 연결한 뒤에 시작돼요.
- 설정할 때 선택한 캘린더에만 적용돼요.
- 나중에 캘린더 선택을 해제하면 그 캘린더의 동기화가 멈춰요. 다시 선택해도 놓친 이벤트는 가져오지 않고, 그 이후의 새 이벤트만 동기화돼요.
- Calendly에서 예약이 들어오면 실시간 또는 실시간에 가까운 속도로 동기화돼요.

원활하게 쓰려면 지원되는 Calendly 요금제를 사용하고, 필요한 캘린더만 선택하세요. 또 이벤트 유형에서 이름과 이메일 같은 필수 게스트 정보를 받도록 설정하세요. 동기화가 캘린더 선택에 따라 달라진다는 점을 알아 두면 데이터 충돌을 막고 워크플로우를 의도대로 운영할 수 있어요.

## Calendly에서 어떤 정보가 동기화되나요?

연동은 CRM 워크플로우를 돌리고 예약을 관리하는 데 필요한 핵심 정보를 중심으로 동기화해요.

| 동기화됨 | 동기화되지 않음 |
| --- | --- |
| 이벤트 날짜 및 시간 | 취소되거나 일정이 변경된 이벤트는 하이퍼클래스에 반영되지 않아요 |
| 게스트 이름 및 이메일 | Calendly 계정을 연결하기 180일보다 더 전에 만들어진 지난 이벤트 |
| 예약 제목 | 첨부파일 또는 메모 |
| 소스("Calendly"로 표시) | |
| 이벤트가 속한 캘린더 | |
| 위치 또는 Q&A 필드의 전화번호 | |

## Calendly 연동은 어떻게 작동하나요?

Calendly 연동은 Google, Outlook, iCloud 같은 다른 캘린더 플랫폼과 조금 달라요. Calendly의 이벤트를 하이퍼클래스로 가져오도록 만들어졌고, 반대 방향은 지원하지 않아요. 동기화가 어떻게 작동하는지 알아 두면 더 잘 활용할 수 있어요.

### Calendly 이벤트 동기화

Calendly 계정을 연결하고 캘린더를 하나 이상 선택하면, 하이퍼클래스는 연결 시점에 예정된 모든 이벤트와 최근 180일 이내에 만들어진 지난 이벤트를 가져와요. 설정 이후의 새 Calendly 이벤트도 계속 동기화돼요.

나중에 연결에서 캘린더를 제거하면 그 캘린더의 새 이벤트는 더 이상 하이퍼클래스로 동기화되지 않아요. 그 캘린더를 다시 연결하면 Calendly 계정을 연결한 시점 기준으로 예정된 이벤트와 최근 180일 이내에 만들어진 지난 이벤트가 동기화돼요. 캘린더 연결이 끊긴 동안 만들어진 예약은 소급해서 가져오지 않아요.

### 단방향 동기화

Calendly 연동은 단방향이에요. 하이퍼클래스가 Calendly에서 이벤트를 가져오기만 하고, 반대로는 보내지 않아요. 그래서 다음과 같아요.

- 하이퍼클래스에서 만든 이벤트는 Calendly에 나타나지 않아요.
- Calendly에서 가져온 이벤트는 하이퍼클래스에서 편집할 수 없어요. 내용이 정확하게 유지되도록 Calendly에서 직접 수정하세요.

### 예약으로 연락처 만들기

하이퍼클래스로 동기화된 Calendly 이벤트는 모두 예약으로 처리돼요. 단순한 자리표시나 차단된 시간이 아니에요. 이벤트에 게스트가 있으면 게스트의 이름과 이메일로 연락처가 자동으로 만들어져요. 이후에는 다른 연락처와 똑같이 자동화를 실행하고, 워크플로우에 추가하고, 관리할 수 있어요.

### 예약 소유자는 누구인가요?

소유자는 캘린더 유형에 따라 정해져요.

- 개인 Calendly 링크: Calendly 계정을 연결한 사용자가 예약 소유자로 지정돼요.
- 공유 캘린더(라운드 로빈, 팀 링크 등): 연결된 Calendly 사용자 중 한 명이 무작위로 예약 소유자로 지정돼요.

### 연락처 배정

연락처의 **할당된 사용자** 필드는 가장 최근 예약의 소유자로 자동 업데이트돼요. 그래서 알맞은 팀원이 연락처와 연결되고, 후속 자동화도 올바른 사용자에게 전달돼요.

## 연락처 생성과 관리

### Calendly 예약이 동기화되면

- 게스트의 이름과 이메일로 하이퍼클래스에 연락처가 자동으로 만들어져요.
- 이미 있는 연락처라면 그 연락처 기록에 예약이 추가돼요.
- 이 연락처들은 예약 상태를 기준으로 실행되는 자동화 대상이 될 수 있어요.

### 예약 소유자와 사용자 배정

하이퍼클래스의 예약에는 작업, 알림, 자동화를 알맞게 전달하기 위한 소유자가 필요해요.

#### 예약 소유자

- 개인 캘린더: Calendly를 연결한 사용자가 소유자예요.
- 공유 캘린더(예: 라운드 로빈): 연결된 팀에서 한 명이 무작위로 지정돼요.

#### 연락처의 할당된 사용자

연락처의 **할당된 사용자**는 가장 최근 예약의 소유자로 업데이트돼요. 그래서 후속 조치를 해야 할 사용자에게 연락처가 정확히 전달돼요.

## 설정 후 캘린더 관리하기

캘린더 선택은 언제든 바꿀 수 있어요.

1. **캘린더 설정**으로 이동해요.
2. **연결** 탭을 클릭해요.
3. 연결된 캘린더 목록에서 Calendly 연동을 찾아요.
4. 옆에 있는 **아이콘 편집**을 클릭해 캘린더 선택 패널을 열어요.
5. 동기화할 캘린더를 추가하거나, 더 이상 필요 없는 캘린더를 제거해요.
6. **저장**을 클릭해 변경 사항을 적용해요.

현재 선택된 캘린더의 이벤트만 앞으로 동기화돼요.

{% hint style="info" %}
새로 추가한 캘린더의 이벤트는 선택한 시점부터만 동기화돼요. 이전 데이터는 가져오지 않아요.
{% endhint %}

### 동기화된 Calendly 이벤트 삭제하기

캘린더 연결을 끊거나 Calendly를 제거할 때, 동기화된 이벤트를 삭제할지 선택하는 창이 나타나요.

#### 캘린더 하나의 이벤트 삭제

특정 캘린더에서 동기화된 이벤트를 모두 삭제할 수 있어요.

삭제한 이벤트는 나중에 복원할 수 없어요.

![특정 캘린더의 동기화된 이벤트 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045368934/original/n9wsbf8nBBDNQQVrVGudhhC-fl4wqAOO6A.png?1745157796)

#### 공유 캘린더

여러 사용자가 같은 공유 캘린더에 Calendly를 연결했다면, 이벤트가 삭제되려면 모든 사용자가 이벤트 삭제를 선택해야 해요.

한 명이라도 캘린더를 유지하면 공유 이벤트는 계속 표시돼요.

#### Calendly 연결 완전히 끊기

모든 캘린더에서 동기화된 이벤트를 전부 삭제할지 선택할 수 있어요. 삭제는 되돌릴 수 없어요. Calendly를 다시 연결하면 Calendly 계정을 연결한 시점 기준으로 예정된 이벤트와 최근 180일 이내에 만들어진 지난 이벤트를 자동으로 가져와요.

## Calendly 연동의 알려진 제한 사항

Calendly 연동을 쓸 때 알아 두어야 할 주요 제한 사항이에요.

- 서브 계정 하나당 사용자 한 명이 Calendly 계정 하나만 연결할 수 있어요.
- 소속된 여러 서브 계정에 같은 Calendly 계정을 연결할 수 있어요.
- Calendly의 Standard, Teams, Enterprise 요금제에서만 지원돼요.
- Calendly의 Free 또는 Essentials 요금제는 지원되지 않아요.
- 하이퍼클래스에서는 이벤트를 편집할 수 없어요.
- 게스트의 이름과 이메일만 동기화돼요(Q&A나 커스텀 필드는 동기화되지 않아요).

## 전화번호 가져오기 규칙(Calendly → 연락처)

하이퍼클래스는 직접 정리할 일을 줄이기 위해 명확한 규칙에 따라 Calendly에서 전화번호를 가져와요.

- 게스트 전화번호가 미팅 위치에 입력되어 있고 Calendly 폼에 전화번호 필드가 없으면, 위치의 전화번호를 연락처에 자동으로 동기화해요.
- Calendly 폼에 전화번호 필드가 있으면, 하이퍼클래스에 매핑 화면이 나타나요. 여기서 폼의 전화번호, 위치의 전화번호(있는 경우), **do not sync**(동기화하지 않음) 중에서 소스를 고를 수 있어요.
- 전화번호 소스가 없으면(위치 전화번호도, 폼 전화번호도 없는 경우) 전화번호 동기화는 건너뛰어요.

공유 캘린더: 전화번호 동기화 옵션을 바꾸면 그 캘린더에 연결된 모든 사용자에게 영향을 줘요.

## 자주 묻는 질문

### 이전 Calendly 이벤트가 하이퍼클래스에 보이지 않는 이유가 뭔가요?

Calendly를 처음 연결하면 하이퍼클래스는 최근 180일 이내에 만들어진 지난 이벤트를 가져와요. 연결 시점보다 180일보다 더 전에 만들어진 지난 이벤트는 처음 가져오기에 포함되지 않아요. 예정된 이벤트는 모두 가져와요.

### 하이퍼클래스에서 Calendly 이벤트를 편집하거나 일정을 변경할 수 있나요?

아니요. 이벤트는 Calendly에서 직접 편집해야 해요.

### Calendly를 다시 연결하면 어떻게 되나요?

Calendly를 다시 연결하면 하이퍼클래스는 연결 시점 기준으로 예정된 이벤트와 최근 180일 이내에 만들어진 지난 이벤트를 가져와요.

### 공유 캘린더에서 동기화된 예약의 소유자는 누구인가요?

공유 캘린더에서는 Calendly를 연결한 사용자 중 한 명이 무작위로 소유자로 지정돼요.

### Calendly 계정 하나를 여러 하이퍼클래스 사용자나 서브 계정에 연결할 수 있나요?

네. Calendly 계정 하나를 여러 서브 계정의 여러 사용자에게 연결할 수 있어요.
