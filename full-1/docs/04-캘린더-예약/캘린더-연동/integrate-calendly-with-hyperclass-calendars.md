# Calendly를 하이퍼클래스 캘린더에 연동하기

Calendly 계정을 하이퍼클래스 캘린더에 연결하는 방법을 안내해요. 접근 권한을 승인하고, 동기화할 캘린더를 고르고, 나중에 동기화 설정을 바꾸는 방법까지 다뤄요.

[동영상](https://www.youtube.com/embed/krl_xZfAlaA?&wmode=opaque)

## Calendly 연동이란?

Calendly 연동을 켜면 하이퍼클래스가 선택한 Calendly 캘린더의 이벤트를 자동으로 가져와요. 실시간 예약을 바탕으로 자동화 트리거를 실행하고, 연락처를 만들고, 워크플로우를 예약할 수 있어요. 연동 설정은 Calendly 일정 활동을 CRM과 맞추는 첫 단계예요.

## Calendly를 연결하면 좋은 점

Calendly 계정을 연결하면 아래 기능을 쓸 수 있어요. 동기화된 이벤트는 하이퍼클래스로 자연스럽게 들어와서 다른 기능에 활용할 수 있어요.

- 새 예약을 캘린더로 자동으로 가져와요.
- Calendly 예약으로 연락처를 만들어요.
- 캘린더 소유자를 기준으로 예약을 사용자에게 배정해요.
- 공유 캘린더와 개인 캘린더를 모두 동기화해요.
- 새 예약을 기준으로 자동화 트리거를 실행해요.

## Calendly 계정 연결하기

클릭 몇 번이면 연결할 수 있어요. 아래 순서대로 Calendly 계정을 안전하게 연결하고 동기화할 캘린더를 선택하세요.

### 캘린더 설정 열기

1. 왼쪽 메뉴에서 **캘린더**를 클릭해요.
2. 오른쪽 위에 있는 **캘린더 설정**을 클릭해요. Calendly를 포함한 모든 캘린더 연결을 이곳에서 관리해요.

경로: **캘린더 > 캘린더 설정**

![캘린더 메뉴에서 캘린더 설정으로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045071601/original/vZZKvoSawr1RWtOWQj1kP-CDjnbRO_CvGg.png?1744648219)

### 연결 탭 열기

위쪽의 **연결** 탭을 클릭해요. 연동된 캘린더 계정을 확인하고 관리하는 화면이에요. Calendly 같은 외부 캘린더를 추가하거나 편집하고, 제거할 수도 있어요.

![연결 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045072687/original/5MKziRpBSJ71mdpIOzryZhQaoTnx_i2OvA.png?1744649594)

### 새 연동 추가하기

**새로 추가 +** 버튼을 클릭해 새 캘린더 연결을 시작해요. 여기서 Calendly 계정을 하이퍼클래스와 연결하는 과정이 시작돼요.

![새로 추가 + 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045085523/original/azEr6YdXCbtVcFZvrW5okbNILcMSCyEI7Q.png?1744684783)

### Calendly 선택하기

캘린더 제공업체 목록에서 **Calendly**를 찾아 **연결**을 클릭해요. Calendly 이벤트를 하이퍼클래스와 동기화하기 위한 승인 절차가 시작돼요.

![Calendly 항목의 연결 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045085588/original/XZ1xeFIB8pzm2LXCeDcv8rIKJgUUmrDWdQ.png?1744685049)

### Calendly에 로그인하기

Calendly 계정에 로그인하고 접근 권한을 승인해 인증을 마쳐요. Calendly 계정에 쓰는 이메일 주소를 입력하고 **계속**을 클릭하세요. Google이나 Microsoft 계정을 Calendly에 연결해 두었다면 그 계정으로 로그인해도 돼요.

![Calendly 로그인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045085817/original/NW3v4HAVhVc1P-sk5Di-OtQcUJZiZJlO8w.png?1744685803)

### Calendly 캘린더 선택하기

하이퍼클래스로 동기화할 Calendly 캘린더를 선택해요. 여기서 선택한 캘린더의 이벤트만 예약으로 가져와요.

![동기화할 Calendly 캘린더 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045085848/original/U2vaqQjMGOFL3avKm1IMMeB70oUHy4e_DQ.png?1744685820)

### 동기화 접근 승인하기

1. 하이퍼클래스가 Calendly 이벤트와 관련 정보를 가져오는 것에 동의하는 체크박스를 선택해요.
2. **저장**을 클릭해 동기화 설정을 마쳐요.

{% hint style="info" %}
Calendly 계정을 연결하는 시점에 예정된 이벤트와 최근 180일 이내에 만들어진 지난 이벤트를 모두 자동으로 가져와요.
{% endhint %}

{% hint style="warning" %}
워크플로우는 앞으로 있을 이벤트에만 실행돼요. 처음 연결할 때 가져온 지난 이벤트로는 워크플로우가 실행되지 않아요.
{% endhint %}

![동의 체크박스와 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045085950/original/Utshyqs6u4d3HlZC1zbxHYnmebShkoSiaQ.png?1744686152)

## 전화번호 동기화(미팅 장소와 폼 필드)

하이퍼클래스는 Calendly에서 게스트의 전화번호를 여러 방법으로 가져올 수 있어요. 전화번호가 들어올 수 있는 곳이 여러 군데이면, 연락처 프로필에 어떤 값을 동기화할지 직접 고를 수 있어요.

### 미팅 장소의 전화번호를 자동으로 동기화하기

게스트의 전화번호가 **Calendly 미팅 장소**(meeting location)에 입력되어 있고 Calendly 폼에 **전화번호 필드**가 없으면, 하이퍼클래스가 그 번호를 연락처에 자동으로 동기화해요.

### Calendly 폼 필드에서 전화번호를 가져올 때의 매핑 화면

Calendly 폼(질문과 답변)에 **전화번호 필드가 있으면** 하이퍼클래스가 매핑 화면을 보여 줘요. 이 화면에서 동기화할 값을 선택하세요.

- 폼 필드에서 전화번호 값을 선택해요.
- 미팅 장소의 전화번호 필드를 선택해요(있는 경우).
- **Do not sync**(동기화 안 함)를 선택해요. 전화번호를 매핑하지 않으려는 경우예요.

{% hint style="info" %}
선택한 Calendly 캘린더나 이벤트 유형에 전화번호 필드가 하나도 없으면(미팅 장소 전화번호도, 폼 전화번호도 없는 경우) 전화번호 동기화 단계를 건너뛰어요. 안내 창이나 오류도 나오지 않아요.

공유 캘린더: 한 사용자가 전화번호 동기화 옵션을 바꾸면, 그 캘린더에 연결된 모든 사용자에게 변경 내용이 적용돼요.
{% endhint %}

## 동기화된 캘린더 편집하기

### 캘린더 선택 편집하기

연결을 마치면 Calendly 연동이 **Connected Calendars**(연결된 캘린더) 아래에 나타나요. **연필 아이콘**을 클릭하면 하이퍼클래스와 동기화할 Calendly 캘린더를 바꿀 수 있어요.

원하는 설정이 바뀌거나 팀 캘린더가 새로 생겼을 때 캘린더 선택을 쉽게 업데이트할 수 있어요.

![연결된 캘린더의 연필 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045088297/original/ujUVrZ68WR2OPJ_jzSfp6OKcPYgNgMi9Wg.png?1744693740)

### 동기화할 캘린더 변경하기

동기화할 캘린더를 체크하거나 체크 해제해서 선택을 바꿔요. 여기서 선택한 캘린더만 계속 하이퍼클래스로 동기화돼요.

{% hint style="info" %}
새로 선택한 캘린더의 이벤트는 변경 내용을 저장한 뒤부터 동기화돼요.
{% endhint %}

![동기화할 캘린더 변경 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045088388/original/c4hvqQvJ4P_uMmHSAthFqkuggh0O8b6MqQ.png?1744693886)

{% hint style="info" %}
Calendly 캘린더는 **Conflict Calendars**(충돌 확인용 캘린더)로만 추가할 수 있어요. **Linked Calendars**(연결 캘린더)로는 추가할 수 없어요.
{% endhint %}

## 자주 묻는 질문

### 한 사용자에게 Calendly 계정을 여러 개 연결할 수 있나요?
아니요. 사용자 한 명은 서브 계정마다 Calendly 계정을 하나만 연결할 수 있어요.

### 같은 Calendly 계정을 여러 사용자가 쓸 수 있나요?
네. Calendly 계정 하나를 서로 다른 서브 계정의 여러 사용자에게 연결할 수 있어요.

### 어떤 요금제에서 이 연동을 쓸 수 있나요?
Calendly의 Standard, Teams, Enterprise 요금제만 지원해요. Free와 Essentials 요금제는 호환되지 않아요.

### 체험 기간 중에도 연결할 수 있나요?
체험 기간 중에도 Calendly를 연결할 수 있어요. 다만 체험이 끝난 뒤 지원되는 요금제로 업그레이드하지 않으면 연동이 작동하지 않아요.

### 하이퍼클래스에서 Calendly 이벤트를 편집할 수 있나요?
아니요. 단방향 동기화예요. 이벤트 변경은 모두 Calendly 안에서 해야 해요.

### Calendly 캘린더를 Linked Calendar(연결 캘린더)로 쓸 수 있나요?
아니요. Calendly는 Conflict Calendar(충돌 확인용 캘린더)로만 쓸 수 있어요. 두 시스템 사이에서 예약을 동기화하려면 Google, Outlook, iCloud 중 하나를 Linked Calendar로 사용하세요.
