# Facebook 리드 광고에서 하이퍼클래스 캘린더 임베드 예약 사용하기

임베드 예약을 쓰면 Facebook 리드 광고의 인스턴트 폼을 제출한 리드가 감사 페이지에서 바로 예약할 수 있어요. 상담, 데모, 견적, 서비스 예약처럼 예약이 목표인 캠페인에 쓰기 좋아요.

## 하이퍼클래스 캘린더 임베드 예약이란?

임베드 예약은 리드가 정보를 제출한 뒤 인스턴트 폼의 감사 페이지에서 바로 예약하는 기능이에요. 별도의 예약 페이지로 보내지 않고, Meta가 Facebook 모바일 앱 화면 안에 지원되는 캘린더 예약 화면을 보여 줘요.

하이퍼클래스 캘린더를 지원하므로, Meta의 인스턴트 폼 편집기에서 **Book time**(시간 예약) CTA의 예약 연결 주소로 하이퍼클래스 캘린더 예약 링크를 쓸 수 있어요. Meta가 임베드 화면을 지원하면 리드는 감사 페이지에서 시간을 고를 수 있어요. 이때 제출한 폼의 이름, 이메일, 전화번호 같은 정보가 예약 화면으로 넘어올 수 있어요.

## 임베드 예약의 장점

- 리드의 단계가 줄어요: 별도 예약 페이지로 이동하지 않고 감사 페이지에서 바로 예약할 수 있어요.
- 예약 전환율을 높일 수 있어요: 페이지 이동과 정보 재입력이 줄어들면 리드가 예약을 끝까지 마칠 가능성이 높아질 수 있어요.
- 하이퍼클래스 캘린더의 가용 시간이 그대로 보여요: 예약 화면에 나오는 시간은 하이퍼클래스 캘린더 링크와 거기에 설정한 가용 시간을 기준으로 해요.
- 캠페인 설정이 간단해요: 지원되는 예약 링크를 인스턴트 폼 편집기에 붙여 넣고 **Book time** CTA를 쓰면 돼요.
- 리드 후속 관리가 쉬워요: Facebook 리드 광고의 리드 정보를 하이퍼클래스로 동기화하면, 팀이 CRM 기록, 워크플로우, 리드 육성 캠페인으로 후속 관리를 할 수 있어요.
- 예약 기반 자동화를 만들 수 있어요: 예약이 완료되면 하이퍼클래스 워크플로우가 실행되어 확인, 리마인더, 내부 알림, 예약 후 후속 연락을 보낼 수 있어요.

## Facebook 리드 광고 인스턴트 폼과 하이퍼클래스 캘린더 링크

Facebook 리드 광고의 인스턴트 폼은 Meta 광고 화면 안에서 리드 정보를 받아요. 하이퍼클래스는 Facebook 리드 광고를 CRM에 동기화해 리드 확보와 후속 관리를 지원하고, 하이퍼클래스 캘린더 링크는 예약 일정을 맡아요.

임베드 예약을 쓰려면 먼저 리드가 예약할 하이퍼클래스 캘린더를 만들거나 정한 다음, 그 캘린더의 공개 예약 링크를 복사하세요. 이 링크는 광고 캠페인에서 쓰려는 캘린더, 서비스, 예약 화면을 정확히 가리켜야 해요.

![예약 링크 복사 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074424875/original/aJgQRDOPxqUUGh178OGPK6BKZUN8Ilh3iw.gif?1782316110)

{% hint style="warning" %}
**중요:** 인스턴트 폼, CTA, 감사 페이지, 제공업체 감지, 미리보기, 게재 위치 동작은 Meta가 관리해요. 캘린더 링크, 예약 가능 시간, 예약 규칙, 캘린더 알림, 예약 기록은 하이퍼클래스가 관리해요.
{% endhint %}

## 설정 방법

인스턴트 폼이 리드를 받고, **Book time** 버튼을 보여 주고, 리드를 올바른 하이퍼클래스 캘린더로 연결하려면 설정을 정확히 해야 해요. 먼저 하이퍼클래스 캘린더를 만들거나 확인하고, 그 예약 링크를 Meta의 인스턴트 폼 편집기에 넣으세요.

1. 하이퍼클래스 서브 계정에서 아래 두 경로 중 하나로 캘린더 페이지를 여세요.
   - 왼쪽 메뉴에서 **캘린더 > 캘린더 설정**으로 이동해요.
   - 왼쪽 메뉴에서 **설정 > 캘린더**로 이동해요.

   이 캠페인에 쓸 예약 캘린더가 이미 있으면 그대로 쓰고, 없으면 새로 만드세요. 캘린더를 먼저 만들어야 한다면 [하이퍼클래스로 개인 예약 캘린더 설정하기](../../01-시작하기/기본-설정/getting-started-setup-a-booking-calendar.md)를 참고하세요.

   ![캘린더 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074422420/original/D790ErYr-dS5-HdMsBTzYJVfc36qYrhXGg.png?1782315153)
2. Facebook 리드가 예약할 캘린더의 하이퍼클래스 캘린더 예약 링크를 복사하세요.

   ![캘린더 예약 링크 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074422722/original/BNg7zrx5tZ3qf3YPA5Y3bhPPwreRuEJkww.gif?1782315248)
3. **Facebook에 로그인**하고 **광고 관리자**로 이동한 다음 **+ 만들기**를 클릭하세요. 캠페인 목표로 **리드**를 선택하고 **계속**을 클릭하세요.

   ![캠페인 목표로 리드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074423120/original/joON6S5rBIZFbwWKt371DRTwjV5mdE5Apw.png?1782315420)
4. 광고 만들기 단계를 진행하다가 광고 세트 단계에서 전환 위치로 **인스턴트 폼**을 선택하세요.

   ![전환 위치로 인스턴트 폼 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074423428/original/CQbtsYOjoHb0XgDy2PUn1iCMS5Y7DBzwgg.png?1782315510)
5. 인스턴트 폼을 만들고 필요한 설정 단계를 마치세요. **Ending**(마무리) 섹션의 **Additional actions**(추가 작업)에서 **Book time**을 선택하세요.

   ![Ending 섹션에서 Book time 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074423859/original/ZwTL8cCixJLcXzVn5YWYrxLcuwWkQNBj_Q.png?1782315697)
6. **예약 링크**에 하이퍼클래스 캘린더 URL을 붙여 넣으세요. 지원되는 경우 Meta가 캘린더 제공업체를 자동으로 감지하고, 광고 관리자에 임베드 캘린더 위젯의 실시간 미리보기를 보여 줘요.

   ![예약 링크 입력과 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074424018/original/_M8ShhQJRl54Gn5xQC6BNue3z2nL2uhYrA.png?1782315758)
7. 나머지 인스턴트 폼 설정을 마치고, 광고가 준비되면 **게시**를 클릭하세요.

   ![인스턴트 폼 게시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074424082/original/8gPJcZwLuhedf8NbHgWYYDEpupcVpRboow.png?1782315830)
8. 폼 제출 이후의 상황에 맞춰 하이퍼클래스에서 후속 워크플로우를 만들어 보세요. 예를 들어 인스턴트 폼을 제출한 리드에게 연락할 때는 **Facebook Lead Form Submitted**(Facebook 리드 폼 제출)를, 예약을 마친 연락처에게는 **Customer Booked Appointment**(고객이 예약함)를 쓸 수 있어요. 예약 리마인더나 내부 알림을 더하면 노쇼를 줄이고 팀에 상황을 알리는 데 도움이 돼요.

{% hint style="warning" %}
**중요:** 임베드 예약은 현재 Facebook 모바일 앱에 게재되는 광고에서 쓸 수 있어요. Instagram 같은 다른 게재 위치에서는 **Book time** CTA가 보여도, 감사 페이지에 캘린더가 임베드되지 않고 별도의 인앱 브라우저에서 예약 페이지가 열릴 수 있어요.
{% endhint %}

{% hint style="info" %}
**참고:** 임베드 예약에는 하이퍼클래스 기본 도메인의 캘린더 링크를 사용하세요. 브랜드 도메인 캘린더 링크는 광고 관리자에서 임베드 미리보기가 보이지 않을 수 있어요. 실제 광고에서도 임베드 화면 대신 브라우저에서 예약 페이지가 열릴 수 있어요.
{% endhint %}

## 자주 묻는 질문

### Instagram 게재 위치에서도 사용할 수 있나요?
임베드 예약은 Facebook 모바일 앱에 맞춰져 있어요. Instagram을 포함해 지원되지 않는 게재 위치에서는 기존 인앱 브라우저 방식으로 예약 링크가 열리고, 감사 페이지에 바로 임베드되지 않을 수 있어요.

### 예약 내역은 어디에서 확인하나요?
캠페인에 쓴 서브 계정에서 **캘린더**로 이동하세요. 인스턴트 폼에 넣은 예약 링크와 연결된 캘린더의 **캘린더 보기**나 **예약 목록 보기**를 확인하면 돼요. 날짜 범위, 캘린더, 팀 구성원 필터를 쓰면 해당 캠페인으로 들어온 예약을 찾을 수 있어요.

### 리드의 정보가 예약 화면에 미리 채워지나요?
지원되는 경우 이름, 이메일, 전화번호 같은 리드 정보가 인스턴트 폼에서 예약 화면으로 넘어와요. 같은 정보를 다시 입력하는 번거로움이 줄어들어요.

### 광고마다 다른 하이퍼클래스 캘린더를 쓸 수 있나요?
네, 쓸 수 있어요. 각 캠페인에 맞는 하이퍼클래스 캘린더, 서비스, 예약 화면의 예약 링크를 사용하세요.

### 임베드 캘린더는 뜨는데 선택할 수 있는 시간이 없어요. 무엇을 확인해야 하나요?
하이퍼클래스 캘린더의 가용 시간, 배정된 팀 구성원, 충돌 캘린더, 버퍼, 날짜별 영업시간, 예약 규칙을 확인하세요. 그리고 Meta 밖에서 하이퍼클래스 캘린더 링크를 열어 보고 정상적으로 작동하는지도 확인하세요.

### 예약 확인 메시지는 Meta가 보내나요, 하이퍼클래스가 보내나요?
예약 확인과 리마인더는 예약 링크에 연결된 하이퍼클래스 캘린더와 알림 설정에서 관리해야 해요.

### 이 기능을 쓰려면 코딩이 필요한가요?
기본 설정에는 코딩이 필요 없어요. 옵션이 보이면 인스턴트 폼 편집기의 **Book time** CTA에 하이퍼클래스 캘린더 예약 링크를 넣으면 돼요.

### 리드가 예약을 마치기 전에 예약 위젯을 닫으면 어떻게 되나요?
리드가 예약 위젯을 닫아도 감사 페이지의 **Book time** 버튼을 눌러 다시 열 수 있어요. 메시지 기능이 켜져 있으면 예약을 마치도록 알려 주는 Messenger 리마인더를 받을 수도 있어요.

### 광고 관리자에서 예약 건수를 볼 수 있나요?
이 임베드 예약에서는 예약 건수가 **광고 관리자**에 표시되지 않아요. 확정된 예약은 인스턴트 폼에 사용한 예약 링크와 연결된 하이퍼클래스 캘린더에서 확인하세요.

### Facebook에 표시되는 임베드 캘린더를 꾸밀 수 있나요?
캘린더의 모양은 하이퍼클래스 캘린더 설정에서 정해져요. Meta는 인스턴트 폼 안의 임베드 캘린더에 대해 별도의 사용자 지정 옵션을 제공하지 않아요.
