# Zoom을 하이퍼클래스 캘린더와 연동하기

Zoom을 하이퍼클래스 캘린더와 연동하면 예약마다 Zoom 미팅 링크가 자동으로 만들어져요. 이 문서에서는 Zoom 계정을 연결하는 두 가지 방법과 연결 상태를 확인하는 방법을 안내해요.

## Zoom 연동이란?

Zoom을 캘린더와 연동하면 예약이 잡힐 때 Zoom 미팅 링크가 자동으로 만들어져요. 캘린더 일정과 화상 미팅이 바로 이어지기 때문에 링크를 직접 만들 필요가 없고, 실수도 줄어요.

{% hint style="info" %}
Zoom 동적 링크는 개인(Personal), 라운드 로빈(Round Robin), 서비스(Service), 콜렉티브(Collective) 캘린더에서만 사용할 수 있어요.
{% endhint %}

## Zoom 연동의 장점

미팅 링크 만드는 일을 자동화하면 관리 업무가 줄고, 고객과 화상으로 만나는 경험도 좋아져요.

- Zoom 링크 자동 생성: 캘린더 예약마다 Zoom 미팅 링크를 자동으로 넣을 수 있어요. 직접 만들 필요가 없어요.
- 수작업 실수 감소: 미팅 정보나 링크를 깜빡하고 빠뜨리는 실수를 줄여 줘요.
- 시간 절약: 직접 하던 작업을 자동화해서 더 중요한 일에 집중할 수 있어요.
- 예약 관리 간소화: 예약을 더 효율적이고 안정적으로 관리할 수 있어요.
- 고객에게 전문적인 경험 제공: 모든 고객이 일관되고 준비가 갖춰진 미팅 초대를 받아요.
- 여러 위치·여러 사용자가 함께 사용: 같은 Zoom 계정을 여러 위치(location)에 연결하고, 여러 사용자가 그 Zoom 계정으로 예약을 받을 수 있어요.

  최신 연결 방식으로 Zoom을 연결하려면 아래 경로로 이동하세요.

  **캘린더 > 설정 > 연결 > Video Conferencing**(화상 회의) **> 새로 추가 > Zoom**

  단계별 설정과 관리자 시나리오는 "Zoom 연동: 사용자 캘린더 예약" 문서를 참고하세요.

## Zoom 연동 설정하기

Zoom 계정을 연결하는 방법은 두 가지예요. 어느 쪽으로 연결해도 캘린더 예약에 Zoom 링크가 자동으로 만들어져서, 고객에게 링크를 따로 보낼 필요가 없어요. 내 프로필에서 연결해도 되고, 캘린더 설정에서 바로 연결해도 돼요.

### 방법 1: 내 프로필에서 Zoom 연결하기

1. **설정 내비게이션**에서 **내 프로필**을 클릭하세요.
2. **캘린더** 섹션으로 이동한 뒤, 보조 내비게이션의 **Video Conferencing** 탭을 클릭하세요.
3. 파란색 **새로 추가** 버튼을 클릭하세요.
4. Zoom 옆의 파란색 **연결** 버튼을 클릭하세요. Zoom 로그인 창이 열려요.
5. Zoom 계정으로 로그인하고 접근을 허용하세요.

![내 프로필에서 Zoom 연결하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045060111/original/zud4q5MiZ0k7LHLU6A5Mkq11EpuUdzMltA.png?1744640417)

### 방법 2: 캘린더 설정에서 Zoom 연결하기

1. **설정 내비게이션**에서 **캘린더 설정**을 클릭하세요.
2. 보조 내비게이션의 **연결** 탭을 클릭하세요.
3. **연결** 아래 내비게이션 바에서 **Video Conferencing** 탭을 선택하세요.
4. Video Conferencing 영역에서 파란색 **새로 추가** 버튼을 클릭하세요.
5. Zoom 옆의 **연결**을 클릭하세요.
6. Zoom 계정으로 로그인하고 접근을 허용하세요.

![캘린더 설정에서 Zoom 연결하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044906616/original/eeNzLyA9tdU0lhQ98K5JxtFohCRxY9_8_w.png?1744312261)

## 연결 상태 확인하기

Zoom 계정이 연결됐는지 확인하려면 **내 프로필 > 캘린더 설정 > Video Conferencing**으로 이동하세요. 연결된 계정이 이 화면에 표시돼요.

{% hint style="info" %}
Zoom 연결이 해제됐다가 다시 연결되면, 연결이 끊긴 동안 만들어져서 링크가 없던 예정된 예약에 하이퍼클래스가 Zoom 링크를 자동으로 만들어 줘요. 예약을 하나씩 직접 수정하지 않아도 돼요.
{% endhint %}

![Zoom 연결 상태 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044906774/original/3a8AxwfvpQNN0HZTYP_GJc-AGna0g7xCYg.png?1744312564)

## 자주 묻는 질문

### 하이퍼클래스와 연동하려면 유료 Zoom 계정이 필요한가요?
아니요. 무료 Zoom 계정으로도 연동할 수 있어요. 다만 유료 요금제에서는 미팅 시간이 더 길거나 추가 기능이 제공될 수 있어요.

### 캘린더마다 다른 Zoom 계정을 지정할 수 있나요?
Zoom 연동은 사용자 프로필에 연결되기 때문에, 사용자 한 명당 Zoom 계정은 하나만 연결할 수 있어요.

### Zoom 계정을 연결 해제하거나 바꾸려면 어떻게 하나요?
**캘린더 설정 > 연결 > Video Conferencing** 또는 **내 프로필 > 캘린더 설정 > Video Conferencing**으로 이동하세요. Zoom 옆의 **연결 해제**를 클릭한 뒤, 다른 계정으로 다시 연결하면 돼요.

### 예약 이메일과 SMS에 Zoom 링크가 자동으로 들어가나요?
네. **미팅 장소**를 Zoom으로 선택하고 알림 템플릿에 `{{appointment.location}}` 머지 필드를 넣으면 링크가 포함돼요.

### 확인 이메일에 Zoom 미팅 링크가 안 들어가요
**미팅 장소**가 Zoom으로 설정되어 있는지 확인하세요. 그리고 메시지 템플릿에 `{{appointment.location}}` 머지 필드가 들어 있는지도 확인하세요.

### Zoom과 Google Meet을 동시에 사용할 수 있나요?
<!-- 검토 필요: 원문 내용이 서로 다름 -->
네. 연동 설정에서 Zoom과 Google Meet이 모두 연결되어 있으면 둘 다 사용할 수 있어요. 다만 사용자 프로필 또는 캘린더 하나에서는 한 번에 하나의 화상 회의 플랫폼만 활성화할 수 있어요.

### Zoom 연동은 하이퍼클래스 모든 요금제에서 쓸 수 있나요?
네. Zoom 연동은 모든 요금제에서 사용할 수 있어요.

### 어떤 캘린더가 동적 Zoom 링크를 지원하나요?
개인 예약(Personal Booking), 라운드 로빈, 서비스, 콜렉티브 캘린더가 Zoom 연동을 지원해요. 예약이 잡힐 때마다 새 Zoom 링크가 만들어져요.
