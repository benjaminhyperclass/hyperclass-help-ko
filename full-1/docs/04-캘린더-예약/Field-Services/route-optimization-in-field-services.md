# 현장 서비스 경로 최적화

경로 최적화는 직원 한 명의 하루 방문 순서를 이동 시간이 줄도록 다시 짜 주는 기능이에요. 잠가 둔 방문은 그 자리에 그대로 두고, 제안된 경로를 먼저 확인한 뒤 적용해야 일정이 바뀌어요.

{% hint style="info" %}
현장 서비스는 현재 비공개 베타 기능이며, 선택된 계정에서만 쓸 수 있어요. 기능과 화면은 개선 과정에서 바뀔 수 있어요.
{% endhint %}

## 경로 최적화란?

직원과 날짜를 정하면, 그날의 방문을 살펴보고 더 효율적인 방문 순서를 제안해요. 이때 이동 시간, 직원의 근무 시간, 이동 여유 시간, 이미 잡힌 예약을 함께 고려해요. 경로는 직원의 **Route start**(경로 시작 위치)에서 출발해 **Route end**(경로 종료 위치)에서 끝나요.

{% hint style="info" %}
제안된 경로는 항상 먼저 확인할 수 있어요. **Apply optimized route**(최적화된 경로 적용)를 누르기 전에는 일정이 바뀌지 않아요.
{% endhint %}

## 시작하기 전에

- 직원별 **Route start**와 **Route end**를 **서비스 및 직원 > 직원 > 편집 > Dispatch settings**(디스패치 설정)에서 설정하세요. 자세한 내용은 [현장 서비스의 직원](staff-in-field-services.md)을 참고하세요.
- 최적화할 방문에 서비스 주소가 있고 해당 직원에게 배정되어 있는지 확인하세요.

## 경로를 최적화하는 방법

1. **현장 서비스 > 일정 > 캘린더 보기**로 이동하세요.
2. 오른쪽 도구 모음의 첫 번째 아이콘인 **Route optimization**(경로 최적화) 버튼을 클릭하세요.
3. **Staff member**(직원)를 선택하세요.
4. **날짜**를 선택하세요. 시간대는 필드 옆에 표시돼요. 직원을 고르면 날짜가 자동으로 채워지고, 원하면 바꿀 수 있어요.
5. **Start location**(시작 위치)과 **End location**(종료 위치)은 직원의 디스패치 설정에서 자동으로 채워져요. 여기서는 수정할 수 없어요.
6. **Visit schedule**(방문 일정)을 확인하세요. 방문은 처음에 모두 잠긴 상태이므로, 옮겨도 되는 방문은 잠금을 해제하세요.
7. **Optimize route**(경로 최적화)를 클릭하세요.

## 경로 최적화 화면 살펴보기

- **Visit schedule.** 왼쪽 패널에 그날의 경로가 *Departs home*(집에서 출발)부터 *Returns home*(집으로 복귀)까지 나열돼요. 요약 줄에는 예약된 방문 수, 잠긴 방문 수, **Anytime**(시간 미지정) 방문 수, 그날의 근무 시간이 표시돼요. 예를 들면 *4 scheduled (4 locked) · 1 anytime · 8:00 AM – 5:00 PM* 같은 식이에요.
- 각 방문에는 경로상 순서, 방문 제목, 소요 시간, 서비스 주소, 서비스, 예약 시간이 표시돼요. 방문과 방문 사이에는 예상 이동 시간과 거리가 보여요. 예를 들면 *30m · 20.8 km* 같은 식이에요.
- **잠금과 잠금 해제.** 방문에 있는 잠금 버튼을 누르면 그 방문이 예약된 시간에 고정돼요. 잠긴 방문은 움직이지 않아요. 잠금을 해제하면 경로 최적화가 그 방문을 옮길 수 있어요.
- **Anytime 방문.** 날짜는 있지만 구체적인 시간이 없는 방문은 경로 아래의 Anytime 영역에 표시돼요. 아직 경로에 들어가 있지 않으며, 최적화할 때 구체적인 시간이 배정돼요.
- **지도.** 지도에는 각 정차 지점이 번호가 붙은 핀으로 표시되고, 시작 위치부터 종료 위치까지 이어지는 경로가 그려져요.

![잠금이 해제되어 최적화할 준비가 된 방문](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162990/original/WzWkNOSgWDHgbD-kmz1fdhHYUjOIX-Tsnw.jpg?1792999612)

페이지 제목 옆의 **작동 방식**을 클릭하면 제품 안에서 짧은 설명과 아이콘 안내를 볼 수 있어요.

| 아이콘 | 의미 |
| --- | --- |
| **잠김** | 방문이 예약된 시간에 그대로 유지돼요. |
| **잠금 해제됨** | 최적화하는 동안 방문이 옮겨질 수 있어요. |
| **Anytime** | 방문에 구체적인 시간이 배정될 수 있어요. |
| **Multiple staff**(여러 직원) | 방문이 최적화에 포함되지 않아요. |
| **검토 필요** | 방문을 최적화된 일정에 포함하지 못했어요. |

![작동 방식 아이콘 안내](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162993/original/R2qJdFyXwkl35DgkzlnFouIgK83Es0UFqA.jpg?1792999617)

경로 최적화는 잠긴 방문과 직원이 여러 명 배정된 방문을 바꾸지 않아요. 가용 일정 안에 들어가지 않는 방문도 그대로 남아 직접 검토해야 할 수 있어요.

## 제안된 경로 확인하고 적용하기

**Optimize route**를 클릭하면 **Proposed route**(제안된 경로) 요약이 나타나요.

| 항목 | 표시되는 내용 |
| --- | --- |
| **Drive time**(이동 시간) | 그날의 예상 총 이동 시간이에요. |
| **Day ends**(종료 시각) | 직원의 업무가 끝나는 시각이에요. 이전 시각은 취소선으로 표시되고, 그 옆에 새 시각이 나와요. |
| **상태** | 예를 들면 *Route optimized*(경로 최적화 완료)와 함께 일정이 바뀐 방문 수, 시간이 배정된 Anytime 방문 수가 표시돼요. |

옮겨진 방문에는 이전 시간이 취소선으로 표시되고, 그 뒤에 새 시간이 나와요. 이동 시간은 예상치로 표시돼요.

1. 새로운 순서와 시간을 확인하세요.
2. 새 시간을 일정에 저장하려면 **Apply optimized route**를 클릭하세요.
3. 저장하지 않고 현재 경로로 돌아가려면 **Back to current route**(현재 경로로 돌아가기)를 클릭하세요.
4. 일정을 그대로 두려면 **취소**를 클릭하세요.

![새 시간이 표시된 제안 경로](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162992/original/feS24PFw-vUqnUgJYzxQsBxLUvCugZvqqQ.jpg?1792999615)

{% hint style="info" %}
Anytime 방문이 경로에 들어가면 그 방문이 시간을 차지하므로, 하루가 이전보다 늦게 끝날 수 있어요.
{% endhint %}

## 자주 묻는 질문

### Start location과 End location을 수정할 수 없는 이유가 뭔가요?
직원의 디스패치 설정에서 가져오는 값이기 때문이에요. 바꾸려면 해당 직원을 편집하세요.

### 고객이 이미 확정한 방문도 옮겨지나요?
잠그지 않은 경우에만 옮겨져요. 시간이 바뀌면 안 되는 방문은 최적화하기 전에 잠가 두세요.

### 주소가 없는 방문도 최적화되나요?
경로에 넣으려면 방문에 서비스 주소가 있어야 해요.

### 직원이 여러 명 배정된 방문도 최적화되나요?
아니요. 여러 직원이 배정된 방문은 최적화에 포함되지 않고 그대로 유지돼요.

### 하루 일정 안에 들어가지 않는 방문은 어떻게 되나요?
그대로 남고 **검토 필요**로 표시될 수 있어요. 이런 방문은 직접 일정을 조정하세요.

### Optimize route를 누르면 바로 일정이 바뀌나요?
아니요. 먼저 제안된 경로가 나타나요. **Apply optimized route**를 클릭해야 일정이 바뀌어요.
