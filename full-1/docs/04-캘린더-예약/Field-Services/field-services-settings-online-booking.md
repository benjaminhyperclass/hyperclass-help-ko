# 현장 서비스 설정 — 온라인 예약

온라인 예약 설정에서는 고객이 시간을 고르는 방식, 얼마나 먼저 예약할 수 있는지, 결제 방법, 서비스를 요청할 때 작성하는 폼을 정해요. 이 문서에서 각 설정을 차례로 안내해요.

{% hint style="info" %}
**현장 서비스**(Field Services)는 현재 비공개 베타 상태이며, 선택된 계정에서만 사용할 수 있어요. 기능과 화면은 개선되면서 바뀔 수 있어요.
{% endhint %}

## 온라인 예약 설정 위치

1. **현장 서비스 > Field Services Settings**(현장 서비스 설정)로 이동하세요.
2. **글로벌 설정** 탭에 그대로 머무르세요.
3. **Online booking**(온라인 예약) 아래에서 **Booking rules**(예약 규칙), **결제**, **Request form**(요청 폼) 중 하나를 선택하세요.

설정 메뉴 위쪽의 검색창에 이름을 입력하면 원하는 설정을 바로 찾을 수 있어요. 변경한 뒤에는 오른쪽 위의 **변경사항 저장**을 클릭하세요. **예약 페이지 보기**를 클릭하면 고객에게 보이는 화면을 확인할 수 있어요.

---

## Booking rules(예약 규칙)

### Booking preferences(예약 방식)

고객이 시간을 고르는 방식을 선택해요.

| 옵션 | 고객이 하는 일 |
| --- | --- |
| **날짜 및 시간** | 예약 가능한 슬롯에서 날짜와 시작 시간을 골라요. |
| **Date and time window**(날짜 및 시간대) | 정확한 시간 대신 날짜와 시간대(예: 오전 8시~11시)를 골라요. 시간대는 이 옵션 아래에서 설정해요. |
| **Date only**(날짜만) | 날짜만 골라요. 방문 시간은 나중에 직접 정해요. |

### Book or request(예약 또는 요청)

고객이 예약 페이지에서 제출하면 어떻게 처리할지 선택해요.

| 옵션 | 처리 방식 |
| --- | --- |
| **Booking request**(예약 요청) | 고객이 요청을 보내면 팀에서 방문 일정을 잡아요. |
| **Instant booking**(즉시 예약) | 고객이 제출하는 즉시 방문이 예약돼요. **Accept requests when no times are open**(가능한 시간이 없을 때 요청 받기)을 체크하면, 예약 가능한 시간이 없을 때 고객이 시간 없음 화면 대신 요청을 보낼 수 있어요. |

### Booking availability(예약 가능 조건)

| 설정 | 하는 일 |
| --- | --- |
| **슬롯 간격** | 예약할 수 있는 시간 사이의 간격을 분 단위로 정해요. |
| **Minimum notice**(최소 사전 예약 기간) | 방문 며칠 전까지 고객이 예약할 수 있는지 일 단위로 정해요. |
| **예약 가능 기간** | 고객이 얼마나 먼저 예약할 수 있는지 정해요. **날짜 기반**을 선택하면 오늘부터 일정 일수를 기준으로 보여 주고, 범위 기반 기간을 선택할 수도 있어요. **Count available days only**(예약 가능한 날만 계산)를 체크하면 예약 가능한 날만 일수에 포함해요. |

### 연락처 배정

**연락처 배정**을 켜면 방문이 예약될 때마다 해당 연락처가 그 방문의 담당 직원에게 배정돼요.

## 결제

- **결제 모드**: **테스트**와 **라이브** 중에서 선택해요. 테스트 모드에서는 실제 거래가 처리되지 않아요. 설정하는 동안에는 테스트 모드를 사용하세요.
- **통화**: 가격에 사용할 통화를 선택해요. 통화를 바꾸면 각 서비스의 가격도 맞게 수정하세요.
- **결제 제공업체**: **기본 결제 제공업체를 찾을 수 없습니다**라는 문구가 보이면 **결제 제공업체 관리**를 클릭해 제공업체를 연결하세요. **온라인 결제**를 쓰려면 결제 제공업체가 필요해요.

### 예약 결제 옵션

| 옵션 | 처리 방식 |
| --- | --- |
| **온라인 결제** | 연락처가 예약할 때 온라인으로 결제해요. **보증금 또는 전액 결제 선택 허용**을 체크하면 보증금만 낼지 전액을 낼지 고를 수 있어요. |
| **현장 결제** | 직원이 도착했을 때 결제해요. 예약 중에는 카드나 결제 정보를 받지 않아요. |
| **등록된 카드만** | 보안을 위해 카드 정보는 받지만, 예약할 때는 결제하지 않아요. |

**세금**: **수동 세금**은 각 서비스 또는 해당 상품에서 설정해요. 설정하면 예약 상세 정보에 세금이 표시돼요.

![결제 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162852/original/rBBlEq_2HZVjqlhUoixDvE1sQo3YRql-WQ.jpg?1792999550)

{% hint style="info" %}
아직 결제 제공업체를 연결하지 않았다면 **현장 결제**를 선택하세요. 그래야 고객이 예약을 완료할 수 있어요.
{% endhint %}

## Request form(요청 폼)

요청 폼은 고객이 예약 페이지에서 서비스를 요청할 때 작성하는 폼이에요. 기본 **Request Form**(요청 폼)이 자동으로 만들어지고, **Used on booking page**(예약 페이지에서 사용 중) 표시가 붙어요. 목록에서 항목 수와 마지막 수정 시간을 볼 수 있어요. 점 세 개를 클릭하면 **Edit form**(폼 편집)이나 **Copy shareable link**(공유 링크 복사)를 선택할 수 있어요.

## 자주 묻는 질문

### Booking request와 Instant booking은 어떻게 다른가요?
**Booking request**(예약 요청)에서는 고객이 요청을 보내면 팀이 시간을 정해요. **Instant booking**(즉시 예약)에서는 고객이 예약 가능한 시간을 직접 고르면 방문이 바로 예약돼요.

### 고객이 온라인으로 결제할 수 없어요. 어떻게 해야 하나요?
**결제 제공업체 관리**에서 결제 제공업체를 연결하세요. 준비가 되면 **라이브** 모드로 바꾸고 **온라인 결제**를 선택하세요.

### 이 설정은 팀이 앱에서 만드는 방문에도 적용되나요?
아니요. **Minimum notice**(최소 사전 예약 기간)와 **예약 가능 기간**은 예약 페이지에서 예약하는 고객에게만 적용돼요. 팀은 앱 안에서 원하는 시간에 일정을 잡을 수 있어요.
