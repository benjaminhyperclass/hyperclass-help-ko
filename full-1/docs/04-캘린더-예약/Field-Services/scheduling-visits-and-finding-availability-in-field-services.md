# 현장 서비스에서 방문 일정 잡고 가능한 시간 찾기

작업을 캘린더의 실제 날짜로 옮기는 단계가 일정 잡기예요. **Find availability**(가능 시간 찾기)를 쓰면 직원, **서비스 지역**, 작업 사이 이동 시간에 맞는 시간을 추천해 줘요. 일정을 조율하는 시간은 줄이고 예약은 더 빠르게 잡을 수 있어요.

{% hint style="info" %}
**현장 서비스**(Field Services)는 현재 비공개 베타이고, 선택된 계정에서만 사용할 수 있어요. 기능과 화면은 개선 과정에서 바뀔 수 있어요.
{% endhint %}

## 방문이란?

방문에는 날짜와 시간, 배정된 직원 1명 이상, 상태, 처리할 서비스와 상품이 들어 있어요. 하나의 작업에 방문이 여러 개 있을 수 있어요. 요청에는 현장 방문(site visit)을 붙일 수도 있어요. 작업을 확정하기 전에 현장을 미리 살펴보는 짧은 방문이에요.

---

## 방문 일정 잡기

1. 작업을 열고 **Schedule visit**(방문 일정 잡기)을 클릭하세요. 캘린더의 **Jobs to schedule**(일정을 잡아야 할 작업) 패널에서 시작해도 돼요. 이 패널에는 아직 방문이 없는 작업이 나와요.
2. **Visit title**(방문 제목)을 확인하세요. 기본값은 연락처의 전체 이름이에요.
3. **일정**에서 **날짜**, **시작 시간**, **종료 시간**을 선택하세요. 소요 시간은 작업에 포함된 서비스를 기준으로 채워져요. 시간대는 섹션 오른쪽 위에 표시되며, **편집**을 눌러 바꿀 수 있어요.
4. 방문 시간이 정해져 있지 않으면 **Anytime**(시간 지정 없음)을 체크하세요. 그러면 방문이 캘린더의 **Anytime** 행에 표시돼요.
5. 고객에게 방문 시간을 보여 주는 방식을 바꾸려면 **Arrival window**(도착 시간대) 옆의 **편집**을 클릭하세요. 정확한 시간이나 시간대 중에서 고를 수 있어요.
6. **직원**에서 **Assigned staff**(배정된 직원)를 선택하세요. 2명 이상 배정할 수 있어요.
7. 내부용 메모를 남기려면 **Add visit note**(방문 메모 추가)를 클릭하세요.
8. 방문 **상태**를 선택하세요. 새 방문의 상태는 **시작 안 함**으로 시작해요.
9. **Schedule visit**을 클릭하세요.

## Find availability로 가능한 시간 찾기

1. **일정** 옆의 **Find availability**를 클릭해 **Find available time**(가능한 시간 찾기)을 여세요.
2. **언제**에서 검색할 주를 선택하세요. **Preferred time**(선호 시간대)에서는 하루 중 원하는 시간대나 **언제든지**를 선택하세요.
3. **소요 시간**을 확인하세요. 처음에는 작업의 서비스를 기준으로 채워지고, 시간과 분을 바꿀 수 있어요.
4. 직원 필터에서 전체 직원 또는 특정 직원을 선택하세요. 예를 들어 **All staff**(전체 직원)를 고르면 모든 직원을 대상으로 검색해요.
5. **Suggested times**(추천 시간)를 확인하세요. 상위 추천에는 **가장 일치하는 항목**(이동 시간이 가장 짧은 시간) 또는 **Earliest**(가장 이른 시간) 태그가 붙어요. 담당 직원과 이전 위치에서 오는 이동 시간도 함께 보여요.
6. 추천 대신 **날짜 선택**에서 날짜를 고른 뒤 **All open times**(전체 가능 시간)에서 시간을 선택할 수도 있어요.
7. **Use this time**(이 시간 사용)을 클릭하면 방문 정보에 시간이 채워져요.

## Find availability가 확인하는 항목

**Find availability**는 실제로 가능한 시간만 추천해요. 아래 항목을 모두 고려해요.

| 확인 항목 | 이유 |
| --- | --- |
| 고객의 서비스 지역을 담당하는 직원 | 알맞은 지역에 알맞은 사람을 보내요. |
| 선택한 서비스에 배정된 직원 | 해당 서비스를 처리할 수 있는 직원만 추천해요. |
| 근무 시간, 휴무, 차단된 시간 | 직원별 실제 가능 시간을 반영해요. |
| 이미 예약된 방문 | 중복 예약을 막아요. |
| 방문 소요 시간과 슬롯 간격 | 작업을 깔끔한 시간대에 맞춰 넣어요. |
| 서비스 지역에 설정한 이동 시간과 방문 전 추가 시간 | 이동할 여유를 남겨 둬요. |
| 직원별 하루 방문 한도 | 한 사람에게 일이 몰리지 않게 해요. |
| 선택한 직원 모두가 같은 시간에 비어 있는지 | 여러 명이 함께 가는 방문에도 쓸 수 있어요. |

{% hint style="info" %}
앱 안의 **Find availability**는 온라인 예약 페이지와 달리 최소 사전 예약 시간, 예약 가능 기간처럼 고객에게 적용되는 규칙을 따르지 않아요. 그래서 팀은 고객보다 더 빠르게, 또는 더 먼 날짜로 일정을 잡을 수 있어요.
{% endhint %}

## 직접 일정 잡기

추천 시간을 꼭 쓸 필요는 없어요. 원하는 날짜와 시간을 입력하고 직원도 직접 선택할 수 있어요. 서비스 지역 밖이거나 해당 서비스에 배정되지 않은 직원도 선택할 수 있어요. 긴급 작업처럼 평소 규칙을 벗어나야 할 때 쓰세요. 가능한 시간이 없으면 **Find availability**가 그렇게 알려 주고, 이 경우에도 직접 일정을 잡을 수 있어요.

---

## 방문 보기, 편집, 삭제

작업 화면에서 방문 옆의 아이콘으로 방문을 보거나 편집하거나 삭제할 수 있어요. 캘린더에서 방문을 클릭하거나 방문 목록을 열어도 세부 내용을 확인하고, 상태를 바꾸고, 메모를 추가하고, 체크리스트를 작성할 수 있어요. 자세한 내용은 [현장 서비스의 방문 상태](visit-statuses-in-field-services.md)와 [현장 서비스의 체크리스트, 메모, 폼](checklists-notes-and-forms-in-field-services.md)을 참고하세요.

---

## 모바일 앱에서 사용하기

팀원은 현장에서도 일정을 잡을 수 있어요. 모바일 앱에서 직원이 새 방문을 잡고, 기존 방문의 일정을 바꾸고, 작업 진행에 따라 방문 상태를 바꿀 수 있어요. 변경 내용은 모바일 앱과 웹에 동기화돼요. 사무실과 현장에서 같은 일정을 볼 수 있어요.

## 자주 묻는 질문

### 추천 시간이 하나도 안 보여요. 왜 그런가요?
방문에 포함된 서비스에 배정된 직원이 1명 이상 있는지, 그 직원이 고객의 서비스 지역을 담당하는지, 선택한 주에 근무 시간이 있는지 확인하세요.

### 과거 날짜로 방문을 잡을 수 있나요?
이미 끝난 작업을 기록해야 할 때는 과거 날짜를 직접 입력할 수 있어요. **Find availability**는 미래 시간만 추천해요.

### 고객이 선호하는 직원을 선택할 수 있나요?
비공개 베타에서는 고객이 선호하는 직원을 선택하는 기능을 지원하지 않아요. 대신 원하는 직원을 직접 배정할 수 있어요.

### 추천 시간에 표시되는 이동 시간은 무엇인가요?
직원의 이전 방문 장소, 또는 경로 시작 지점에서 이 고객의 주소까지 걸리는 예상 이동 시간이에요.
