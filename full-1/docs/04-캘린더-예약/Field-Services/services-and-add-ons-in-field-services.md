# 현장 서비스의 서비스와 애드온 설정

서비스 카탈로그는 제공하는 서비스를 모아 둔 메뉴판이에요. 고객이 예약 페이지에서 예약할 수 있는 항목과, 팀이 요청·작업에 추가할 수 있는 항목이 여기서 정해져요. 이 문서에서는 서비스를 만들고, 가격과 소요 시간을 정하고, 선택형 애드온을 제공하는 방법을 안내해요.

{% hint style="info" %}
현장 서비스(Field Services)는 현재 비공개 베타예요. 선택된 계정에서만 쓸 수 있고, 기능과 화면은 개선 과정에서 바뀔 수 있어요.
{% endhint %}

## 서비스와 애드온이란?

서비스는 "에어컨 점검"처럼 직접 수행하는 작업의 종류예요. 어떤 서비스를 고르느냐에 따라 방문 시간이 얼마나 걸리는지, 어떤 직원을 배정할 수 있는지도 정해져요. 애드온은 필터 교체처럼 고객이 서비스에 덧붙일 수 있는 선택형 추가 항목이에요.

![서비스 목록: 소요 시간, 가격, 배정된 직원](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084172107/original/fy9QhXx2rRa9UWj8icsuNk1tF88G9Gg6CA.jpg)

## 서비스 위치 찾기

1. **현장 서비스 > 서비스 및 직원**으로 이동하세요.
2. **Catalog**(카탈로그) 아래의 **서비스**를 클릭하세요.

목록에는 서비스마다 이름, 소요 시간, 가격, 배정된 직원이 표시돼요. **전체 카테고리**로 필터링하고, **정렬 기준**으로 순서를 바꾸고, 검색창에서 서비스를 찾을 수 있어요.

## 서비스 만들기

1. **서비스** 페이지에서 **새 서비스**를 클릭하세요.
2. 이미지를 넣으려면 **서비스 이미지**를 업로드하세요(SVG, PNG, JPG, GIF, 800 x 600 px).
3. **서비스 이름**을 입력하세요.
4. **색상**을 고르세요. 이 색상은 일정에서 서비스를 구분하는 데 쓰여요.
5. **카테고리**를 선택하세요. 다른 카테고리를 고르지 않으면 새 서비스는 **기본**에 들어가요.
6. **Booking link**(예약 링크)를 확인하세요. 고객이 이 링크로 이 서비스를 바로 예약할 수 있어요. 링크의 마지막 부분은 수정할 수 있어요.
7. **설명**을 입력하세요. 글 서식을 지정하고 링크를 넣을 수 있어요.
8. **서비스 세부 정보**에서 이 서비스를 수행할 **직원**을 선택하세요.
9. **가격**과 **소요 시간**을 입력하세요.
10. **서비스 추가**를 클릭하세요.

![새 서비스 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084162848/original/i1b8WQJqMZF6houf_BhBNba2eAXoxmrlVg.jpg?1792999542)

{% hint style="info" %}
모든 서비스에 직원을 한 명 이상 배정하세요. 직원이 없는 서비스는 온라인으로 예약할 수 없어요.
{% endhint %}

## 서비스 고급 설정

**새 서비스** 창에서 **고급 설정**을 클릭하거나 기존 서비스를 편집하면 전체 서비스 편집 화면이 열려요. 왼쪽에는 **서비스 세부 정보**와 **애드온** 두 탭이 있고, 아래 섹션으로 구성돼요.

| 섹션 | 할 수 있는 일 |
| --- | --- |
| **기본 세부 정보** | 이미지, 이름, 색상, 카테고리, 예약 링크, 설명을 설정해요. |
| **서비스 세부 정보** | 서비스의 **소요 시간**을 설정해요. |
| **결제** | **가격**을 설정하고 **이 서비스의 세금 구성**을 클릭해 세금을 설정해요. 연결된 결제 제공업체가 없으면 *기본 결제 제공업체를 찾을 수 없습니다*라는 문구와 함께 **결제 제공업체 관리** 링크가 보여요. 결제 제공업체를 설정하면 **부분 결제 허용**을 쓸 수 있어요. |
| **서비스 단위 폼** | 서비스를 단독으로 예약할 때 사용할 폼을 지정해요. 고객이 여러 서비스를 함께 예약하면 예약 페이지 설정의 폼이 대신 쓰여요. |
| **배리언트** | 크기나 단계처럼 같은 서비스의 다른 옵션을 제공해요. 배리언트마다 이름, 소요 시간, 가격을 따로 정할 수 있어요. |

작업을 마치면 **변경사항 저장**을 클릭하세요.

## 서비스 관리하기

서비스 행 오른쪽 끝의 점 세 개를 클릭하면 아래 메뉴가 나와요.

| 메뉴 | 기능 |
| --- | --- |
| **편집** | 서비스 편집 화면을 열어요. |
| **중복** | 서비스를 복사해 새로 만들어요. 복사본을 시작점으로 쓸 수 있어요. |
| **예약 링크 공유** | 해당 서비스의 직접 예약 링크를 복사해요. |
| **삭제** | 서비스를 지워요. |

## 애드온

애드온은 방문 한 번의 가치를 높여 주는 선택형 추가 항목이에요. 아래 순서로 관리하세요.

1. **현장 서비스 > 서비스 및 직원 > 애드온**으로 이동하세요.
2. **새 부가 기능**을 클릭하고, 적용할 서비스를 포함해 세부 정보를 입력하세요.

**애드온** 목록에는 애드온마다 이름, 소요 시간, 가격, 연결된 서비스가 표시돼요. 서비스를 전체 편집 화면에서 열고 **애드온** 탭에서 해당 서비스에 애드온을 연결할 수도 있어요.

## 자주 묻는 질문

### 이미 가지고 있는 서비스를 가져올 수 있나요?
네, 가능해요. [현장 서비스로 서비스 가져오기](importing-services-into-field-services.md)를 참고하세요.

### 통화(화폐 단위)는 어떻게 바꾸나요?
통화는 **현장 서비스 설정 > 결제**에서 정해요. 통화를 바꾼 뒤에는 새 통화에 맞게 서비스별 가격을 다시 수정하세요.

### 고객이 서비스 비용을 온라인으로 결제할 수 없어요.
온라인 결제를 받으려면 결제 제공업체가 연결되어 있어야 해요. 연결하기 전까지는 결제 설정에서 **현장 결제**를 사용하세요.

### 현장 서비스의 서비스가 다른 서비스 목록에도 나타나나요?
아니요. 두 카탈로그는 서로 별개예요. 서비스를 옮기려면 가져오기 기능으로 복사하세요.
