# 현장 서비스의 요청

요청은 새 작업이 시작되는 곳이에요. 고객이 필요한 일을 아직 아무것도 합의하기 전에 기록해 두면, 팀이 내용을 검토하고 필요하면 현장을 방문한 뒤 클릭 한 번으로 견적서나 작업으로 전환할 수 있어요.

{% hint style="info" %}
현장 서비스는 현재 비공개 베타 단계이며 선정된 계정에서만 쓸 수 있어요. 기능과 화면은 개선되면서 바뀔 수 있어요.
{% endhint %}

## 요청이란?

요청은 어떤 작업도 합의하기 전에 연락처가 도움이 필요한 내용을 기록한 것이에요. 설명, 사진, 서비스와 상품을 넣을 수 있고, 직원이 먼저 작업 내용을 확인할 수 있도록 현장 방문 일정도 추가할 수 있어요.

## 요청 켜기와 끄기

**요청** 토글은 **Field Services Settings**(현장 서비스 설정) **> 글로벌 설정 > Preferences and features**(환경설정 및 기능)에 있어요. 이 토글을 켜면 연락처가 요청을 제출할 수 있고, 직원이 요청을 검토할 수 있어요.

고객이 예약 페이지로 예약할 때는 시간을 바로 정하게 할지, 요청을 보내게 할지도 선택할 수 있어요. 자세한 내용은 [현장 서비스 설정: 온라인 예약](field-services-settings-online-booking.md)과 [현장 서비스 설정: 작업, 방문 및 환경설정](field-services-settings-jobs-visits-and-preferences.md)을 참고하세요.

---

## 요청은 어디에서 볼 수 있나요?

1. 왼쪽 메뉴에서 **현장 서비스**를 클릭하세요.
2. **요청**을 클릭하세요.

목록에는 요청 번호, 연락처, 요청 제목, 현장 방문 날짜와 시간, 생성 시각, 상태가 표시돼요.

---

## 요청 만들기

1. **요청** 페이지에서 **New request**(새 요청)를 클릭하세요. **캘린더 보기**에서 **신규 > Create request**(요청 만들기)를 클릭해도 돼요.
2. **연락처**에서 이름, 이메일 또는 전화번호로 검색해 연락처를 선택하세요. 새 연락처를 만들 수도 있어요.
3. **Service address**(서비스 주소)를 확인하세요. 연락처에 저장된 주소를 선택하거나 새 주소를 추가하세요.
4. **Request details**(요청 상세)에서 **Request title**(요청 제목)을 확인하세요. 최대 100자까지 쓸 수 있고, 기본값은 연락처의 전체 이름이에요. **Request description**(요청 설명)에는 연락처가 필요로 하는 내용을 적으세요.
5. **Supporting photos**(첨부 사진)를 추가하세요. 이미지를 최대 10장까지 올리거나 끌어다 놓을 수 있어요.
6. **서비스 추가**와 **상품 추가**를 클릭해 요청에 포함할 항목을 넣으세요. 수량, 단가, 합계도 함께 입력해요.
7. 요청을 전환하기 전에 직원이 연락처를 방문하게 하려면 **Schedule site visit**(현장 방문 예약)을 켜고, 날짜와 시간과 담당 직원을 선택하세요.
8. 오른쪽의 **Request notes**(요청 메모)에 내부 메모를 남기세요. 메모는 직원에게만 보이고, 이 요청으로 예약한 방문에도 표시돼요.
9. **Create request**(요청 만들기)를 클릭하세요.

## 요청 검토하기

요청을 열면 고객, 주소, 설명, 사진, 서비스, 상품, 메모, 현장 방문 일정을 한 화면에서 볼 수 있어요. 이 화면에서 요청을 전환하거나 상세 내용을 수정할 수 있어요.

## 요청 관리와 전환

요청 줄 끝의 점 세 개를 클릭하면 아래 작업을 쓸 수 있어요.

| 작업 | 하는 일 |
| --- | --- |
| **편집** | 요청 상세 내용을 바꿔요. |
| **중복** | 요청을 복사해요. |
| **Convert to estimate**(견적서로 전환) | 요청 내용으로 고객에게 보낼 견적서를 만들어요. [현장 서비스의 견적서와 인보이스](estimates-and-invoices-in-field-services.md)를 참고하세요. |
| **Convert to job**(작업으로 전환) | 요청으로 작업을 만들어 일정을 잡을 수 있어요. [현장 서비스의 작업](jobs-in-field-services.md)을 참고하세요. |
| **삭제** | 요청을 지워요. |

## 요청 상태

**상태** 필터로 요청을 찾을 수 있어요.

| 상태 | 의미 |
| --- | --- |
| **All requests**(전체 요청) | 모든 요청이에요. |
| **신규** | 아직 검토하지 않은 요청이에요. |
| **예약됨** | 요청에 현장 방문이 예약되어 있어요. |
| **조치 필요** | 직원의 처리를 기다리는 요청이에요. |
| **Converted**(전환됨) | 견적서나 작업으로 전환된 요청이에요. |
| **보관됨** | 전환하지 않고 종료한 요청이에요. |

요청을 전환하지 않고 보관할 때는 직원이 사유를 선택해요. 사유 목록은 **Field Services Settings > Jobs, visits and requests**(작업, 방문 및 요청) **> 일반 > Request archive reasons**(요청 보관 사유)에서 관리해요.

---

## 알림과 제목

요청이 제출됐을 때, 방문이 예약됐을 때, 요청 방문 전 리마인더로 연락처와 팀에게 메시지를 보낼 수 있어요. [현장 서비스의 알림](notifications-in-field-services.md)을 참고하세요.

새 요청 제목이 만들어지는 방식은 **Field Services Settings > Jobs, visits and requests > 일반 > Titles**(제목)에서 바꿀 수 있어요.

---

## 모바일 앱에서 사용하기

팀은 모바일 앱에서 이동 중에도 요청을 관리할 수 있어요. 직원이 고객과 함께 있을 때 새 요청을 만들고, 현장에서 계속 작업할 수 있어요. 모바일 앱과 웹의 변경 사항은 동기화되어 사무실과 현장에서 항상 같은 정보를 볼 수 있어요.

---

## 자주 묻는 질문

### 서비스 없이도 요청을 만들 수 있나요?
네. 요청은 문제에 대한 설명만으로도 만들 수 있어요. 서비스와 상품은 나중에 추가하거나 요청을 전환할 때 추가하면 돼요.

### 요청 방문과 작업 방문은 어떻게 다른가요?
요청 방문은 작업을 합의하기 전에 작업 내용을 확인하러 가는 현장 방문이에요. 작업 방문은 작업에 대해 예약된 실제 작업 일정이에요. 둘은 별개이고, 요청 방문을 예약해도 작업이 만들어지지는 않아요.

### 고객이 꼭 요청을 제출해야 하나요?
아니요. 고객이 시간을 바로 예약하게 할 수도 있고, 직원이 직접 요청과 작업을 만들 수도 있어요. [현장 서비스 설정: 온라인 예약](field-services-settings-online-booking.md)을 참고하세요.
