# Calendar Setup Assistant(캘린더 설정 도우미)로 예약 캘린더 만들기

**Calendar Setup Assistant**(캘린더 설정 도우미)는 복잡한 폼이나 캘린더 유형 선택 없이, 대화하듯 질문에 답하면서 예약 캘린더를 만드는 기능이에요. 필요한 일정 방식을 평소 말투로 설명하거나 추천 옵션을 고르면 됩니다. 이 문서에서는 대화를 시작하는 방법, 설정 중 예약 페이지를 미리 보는 방법, 테스트 예약을 하는 방법, 캘린더를 만든 뒤 수정하는 방법을 안내해요.

## Calendar Setup Assistant란?

**Calendar Setup Assistant**는 하이퍼클래스 **캘린더**(Calendars) 안에서 AI가 도와주는 설정 기능이에요. 캘린더 유형을 고르고 설정을 하나하나 직접 입력하는 대신, 일정 방식을 평소 말투로 설명하거나 추천 옵션을 선택하면 도우미가 캘린더를 만들어 줘요.

도우미는 캘린더 용도, **캘린더 이름**, **팀원**, 예약 배정 방식, **미팅 장소**, 예약 가능 시간 등 핵심 설정을 차례로 물어봐요. 대화로 진행하기 때문에 설정이 헷갈릴 일이 줄고, 쓸 수 있는 캘린더를 더 빨리 만들 수 있어요.

캘린더를 만든 뒤에는 생성된 예약 링크를 확인하고, 예약 페이지를 미리 보고, 테스트 예약을 해 볼 수 있어요. 추가로 바꿀 내용이 있으면 캘린더 설정을 열어서 수정하면 됩니다. 이 기능은 단계적으로 제공되는 중이라 일부 사용자나 계정에서만 보일 수 있어요.

## 이런 점이 좋아요

처음부터 정해야 하는 항목을 줄이고, 필요한 질문만 순서대로 해 주기 때문에 설정에서 예약 받기까지 더 빨리 넘어갈 수 있어요. 첫 캘린더를 만들 때나 흔한 예약 용도를 설정할 때 특히 편해요.

- 빠른 캘린더 생성: 모든 설정을 직접 입력하지 않고, 대화만으로 쓸 수 있는 캘린더를 만들 수 있어요.
- 간편한 설정: 용도를 평소 말투로 설명하거나 추천 옵션을 골라서 시작할 수 있어요.
- 상황에 맞는 안내: 캘린더 설정에 꼭 필요한 질문에만 답하면 돼요.
- 예약 페이지 미리보기: 캘린더를 설정하는 동안 예약 페이지가 어떻게 보이는지 확인할 수 있어요.
- 테스트 예약: 설정을 마친 뒤 테스트 예약을 해서 고객이 보게 될 화면을 확인할 수 있어요.
- 쉬운 수동 편집: 캘린더를 만든 뒤 캘린더 설정을 열어 **가용성**, **팀원**, **미팅 장소** 등을 세부 조정할 수 있어요.

## Calendar Setup Assistant 위치

**Calendar Setup Assistant**는 사용할 수 있는 사용자에게 **캘린더** 화면 안에 표시돼요. 사이드 패널로 열리기 때문에 캘린더 화면을 벗어나지 않고 캘린더를 만들거나 기능을 알아볼 수 있어요.

1. 하이퍼클래스에서 **캘린더**로 이동하세요.
2. 캘린더 화면을 여세요.
3. **Calendar Setup Assistant** 패널에서 아래 옵션 중 하나를 선택하세요.
   - **새 캘린더 만들기**
   - **캘린더로 할 수 있는 일 알아보기**

{% hint style="info" %}
도우미가 보이지 않으면 현재 단계적 제공 기간에 계정이 대상이 아니거나, 필요한 캘린더 권한이 없을 수 있어요.
{% endhint %}

## 캘린더 설정 대화 시작하기

안내된 옵션으로 시작할 수도 있고, 원하는 내용을 직접 입력해서 시작할 수도 있어요. 원하는 캘린더가 분명한 분도, 어떤 구조가 좋을지 고민되는 분도 편하게 쓸 수 있어요.

다음 중 한 가지 방법으로 시작하세요.

- **새 캘린더 만들기** 클릭
- **캘린더로 할 수 있는 일 알아보기** 클릭
- 추천 사용 사례 버튼 선택
- 원하는 내용을 직접 입력

입력 예시예요.

- "온보딩 상담 전화용 캘린더를 만들어 줘."
- "나와 동료가 함께 쓸 캘린더를 만들어 줘."
- "수업 예약용 캘린더가 필요해요."
- "1:1 예약 캘린더 만드는 걸 도와줘."

## 설정 질문에 답하기

도우미는 캘린더 용도에 맞춰 필요한 질문을 해요. 모든 캘린더 설정을 미리 알지 못해도, 쓸 수 있는 캘린더를 만드는 데 필요한 정보만 모을 수 있어요.

도우미가 물어볼 수 있는 항목은 다음과 같아요.

- 캘린더 용도
- **캘린더 이름**
- **팀원**
- 예약 배정 방식
- **미팅 장소**
- **사용 가능한 요일**과 시간
- **예약 소요 시간**
- 버퍼 설정
- 날짜 범위
- 그 밖의 관련 캘린더 설정

팀 캘린더라면 예약을 어떻게 배정할지도 물어봐요. 예를 들어 가능한 팀원에게 자동으로 배정하거나, 고객이 직접 담당자를 고르게 할 수 있어요.

## 예약 페이지 미리보기

미리보기에서는 고객에게 예약 페이지가 어떻게 보일지 확인할 수 있어요. 설정 정보가 쌓일수록 캘린더 이름, 예약 소요 시간, 날짜, 시간대, 예약 가능한 시간대 같은 예약 정보가 미리보기에 나타나요.

미리보기에서 아래 항목을 확인해 보세요.

- **캘린더 이름**
- **예약 소요 시간**
- 선택한 날짜
- 시간대
- **예약 가능한 시간대**
- **예약 페이지 레이아웃**

## 캘린더 만들기

도우미는 정보가 충분히 모이면 추천 캘린더 설정을 요약해서 보여 줘요. 캘린더를 만들기 전에 주요 내용을 확인할 수 있어요.

요약에는 다음 내용이 들어갈 수 있어요.

- **캘린더 이름**
- **예약 소요 시간**
- **미팅 장소**
- **팀원**
- 가용성
- 예약 배정 방식

요약을 확인한 뒤 캘린더를 만들거나, 고치고 싶은 부분이 있으면 변경을 요청하세요.

## 테스트 예약하기

캘린더를 만든 뒤에는 테스트 예약으로 예약 과정이 제대로 동작하는지 확인할 수 있어요. 고객이 예약할 때와 똑같은 화면을 직접 경험해 볼 수 있어요.

테스트 예약으로 아래 내용을 확인하세요.

- 예약 페이지가 정상적으로 열리는지
- 예약 가능한 시간대가 예상대로 나타나는지
- 예약을 끝까지 완료할 수 있는지
- 예약이 캘린더에 표시되는지
- 연결된 캘린더나 미팅 장소가 예상대로 동작하는지

## 만든 뒤 캘린더 수정하기

Calendar Setup Assistant로 만든 캘린더는 캘린더 설정에서 확인하고 수정할 수 있어요. 도우미가 만든 첫 캘린더를 세부적으로 다듬고 싶을 때 유용해요.

캘린더를 만든 뒤 캘린더 설정을 열어 다음 항목을 조정할 수 있어요.

- **캘린더 이름**
- **설명**
- **가용성**
- **팀원**
- **미팅 장소**
- **예약 소요 시간**
- 버퍼
- 날짜 범위
- 알림
- 예약 페이지 사용자 지정 설정

**캘린더 설정으로 이동**이 보이면 그 버튼을 쓰세요. 보이지 않으면 **캘린더 설정**에서 캘린더를 직접 열어도 돼요.

## 권한과 접근

Calendar Setup Assistant는 기존 하이퍼클래스 캘린더 권한을 그대로 따라요. 캘린더를 만들거나 관리하려면 필요한 권한이 있어야 해요.

도우미로 캘린더를 만들 수 없다면 다음을 확인하세요.

- 사용자의 캘린더 권한
- 사용자의 역할과 접근 수준
- 계정이 Calendar Setup Assistant 대상인지
- 사용자가 **캘린더** 화면에 접근할 수 있는지

## Calendar Setup Assistant로 캘린더 만드는 순서

용도를 먼저 설명하고 도우미의 질문에 답하면, 주요 내용은 직접 정하면서도 쓸 수 있는 캘린더를 빠르게 만들 수 있어요.

1. 하이퍼클래스에서 **캘린더**로 이동하세요.
2. **Calendar Setup Assistant**를 여세요.
3. **새 캘린더 만들기**를 클릭하세요.
4. 추천 사용 사례를 선택하거나 필요한 내용을 직접 입력하세요.
5. 도우미의 설정 질문에 답하세요.
6. 도우미가 **팀 멤버 추가**를 요청하면, 필요한 경우 팀 멤버를 추가하세요.
7. 해당하는 경우 예약 배정 방식을 선택하세요.
8. **미팅 장소**를 선택하세요.
9. **사용 가능한 요일**과 시간을 설정하세요.
10. 도우미가 제안한 캘린더 설정을 확인하세요.
11. 설정이 맞으면 **Create it**(만들기)을 클릭하세요.
12. 생성된 예약 링크를 확인하세요.
13. **테스트 예약하기**를 클릭해 예약 과정이 잘 동작하는지 확인하세요.
14. 추가로 바꿀 내용이 있으면 **캘린더 설정으로 이동**을 클릭하세요.

{% hint style="info" %}
이제 캘린더를 바로 쓸 수 있어요. 캘린더는 **캘린더 설정**에 표시되고, 모든 기본 설정 옵션을 직접 조정할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### Calendar Setup Assistant가 뭔가요?
Calendar Setup Assistant는 사용할 수 있는 사용자가 대화를 통해 예약 캘린더를 만들 수 있도록 안내하는 설정 기능이에요.

### Calendar Setup Assistant는 어디에서 찾나요?
사용할 수 있는 사용자에게는 **캘린더** 화면 안에 Calendar Setup Assistant가 표시돼요. 보이지 않는다면 현재 계정에 접근 권한이 없거나, 사용자 역할에 필요한 캘린더 권한이 없을 수 있어요.

### 추천 옵션을 쓰지 않고 직접 입력해도 되나요?
네. 캘린더 사용 사례를 평소 말투로 설명해도 되고, 추천 옵션 중에서 골라도 돼요.

### 도우미가 만든 캘린더를 나중에 수정할 수 있나요?
네. Calendar Setup Assistant로 만든 캘린더도 다른 캘린더처럼 **캘린더 설정**에서 수정할 수 있어요.

### 설정을 마친 뒤 테스트 예약을 할 수 있나요?
네. 사용할 수 있는 경우 테스트 예약 옵션으로 고객 입장에서 예약 과정을 확인해 보세요.

### Calendar Setup Assistant가 직접 캘린더를 설정하는 방법을 대신하나요?
아니요. Calendar Setup Assistant는 안내형 설정 방법을 하나 더 제공하는 기능이에요. 캘린더를 직접 만들고 수정하는 방법도 그대로 쓸 수 있어요.

### Calendar Setup Assistant가 보이지 않아요.
Calendar Setup Assistant는 단계적 제공 기간에는 대상 사용자나 계정에만 표시될 수 있어요. 올바른 캘린더 권한이 필요할 수도 있어요.
