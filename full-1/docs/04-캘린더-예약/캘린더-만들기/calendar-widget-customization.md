## 캘린더 위젯 사용자 지정이란?

캘린더 위젯의 모양과 동작을 원하는 대로 바꿀 수 있는 기능이에요. 위젯을 내 취향에 맞게 꾸며서 나만의 예약 화면을 만들 수 있어요.

## 위젯 사용자 지정 방법

1. **캘린더 > 캘린더 설정**으로 이동하세요.
2. 사용자 지정할 캘린더에서 **편집**을 클릭하세요.
3. **고급 설정 > Widget appearance**(위젯 모양)를 열어 사용자 지정 옵션을 바꾸세요.

{% hint style="info" %}
위젯 사용자 지정은 NEO 위젯에서만 적용돼요.
{% endhint %}

## 사용자 지정 옵션 알아보기

캘린더 위젯을 원하는 대로 꾸밀 수 있는 옵션은 다음과 같아요.

- **Primary Colour**(기본 색상): 버튼, 날짜, 시간대와 위젯 안의 여러 동작(예: **Staff Selection**(직원 선택), **Add Guests**(게스트 추가))에 적용돼요.

- **배경 색상**: 날짜·시간 선택 화면과 폼의 배경 분위기를 정해요. 커스텀 폼을 쓰고 있다면 폼 배경에도 선택한 배경 색상이 적용돼요. 다만 폼 안의 필드는 커스텀 폼에서 설정한 대로 표시돼요.

![기본 색상과 배경 색상을 적용한 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014006095/original/NJAVE46q85aAL4fkmXnC4ppgKsH9vmx5XA.png?1701335069)

{% hint style="info" %}
커스텀 폼을 사용할 때는 폼의 테마가 위젯 사용자 지정과 자연스럽게 어울리는지 확인하세요.
{% endhint %}

커스텀 폼을 적용한 위젯 예시예요.

- **버튼 텍스트**: 예약할 때 버튼에 표시되는 문구를 바꿔요. 이 문구는 예약의 마지막 단계에 표시돼요. 예: 지금 예약, 미팅 예약, 예약하기

![버튼 텍스트를 바꾼 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014007583/original/aDiDCOr27lN0jT77qxYPGn_v9_Wz3Bc1Bw.png?1701335595)

- **Hide Calendar Details**(캘린더 상세 숨기기): 왼쪽 패널에서 캘린더 이름, 설명, 소요 시간, 날짜·시간, 반복 정보, 시간대 같은 상세 정보를 숨길 수 있어요.

{% hint style="info" %}
로고도 표시하고 싶지 않다면 **Meeting details**(미팅 상세) 탭에서 로고를 삭제하세요.
{% endhint %}

![캘린더 상세 정보를 숨긴 위젯 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155014398556/original/SsBTXgr3tI0qRumH1PL4AdbJNGSDBnrWIQ.png?1701774492)

- **Preview Widget**(위젯 미리보기): 바꾼 내용이 예약 과정에서 어떻게 보이는지 미리 확인해요. 설정을 새로 바꿀 때마다 **Preview Widget**을 클릭해야 바뀐 모습을 볼 수 있어요.

- **기본값으로 재설정**: 모든 사용자 지정을 되돌려 기본값인 파란색과 흰색 캘린더 위젯으로 돌아가요.

## Services 예약 흐름 화면 개선

작은 개선만으로도 고객이 예약 과정을 더 분명하고 쉽게 느낄 수 있어요. 이번 업데이트는 핵심 예약 흐름은 그대로 두고, 이동 방법과 화면 품질, 예약 안내를 개선했어요.

최근 Services 예약 화면에서 달라진 점은 다음과 같아요.

- 예약 과정을 오갈 때 쓰는 **뒤로** 버튼이 생겼어요.
- 서비스 이미지가 고해상도로 바뀌어 더 선명하게 보여요.
- 회사 이름이나 로고를 설정하지 않으면 머리글이 자동으로 숨겨져요. 웹사이트에 임베드한 예약 화면에서 특히 유용해요.
- 시간대 선택 화면에 시간대가 더 분명하게 표시돼서, 고객이 어느 시간대 기준으로 예약하는지 알 수 있어요.

이런 변화로 단독 예약 페이지와 임베드한 예약 화면 모두에서 더 매끄럽고 깔끔한 예약 경험을 제공할 수 있어요.

## 자주 묻는 질문

### 어떤 캘린더에서 사용자 지정을 할 수 있나요?

**Event**(이벤트), **Round Robin**(라운드 로빈), **Class Booking**(클래스 예약), **Collective**(콜렉티브), **Service**(서비스) 캘린더를 포함해 모든 캘린더 유형에서 사용할 수 있어요.

{% hint style="info" %}
**Service Menu**(서비스 메뉴)에서는 사용자 지정이 적용되지 않아요.
{% endhint %}

### 커스텀 폼을 함께 쓸 수 있나요?

네, 커스텀 폼을 추가할 수 있어요. 다만 커스텀 폼의 테마가 위젯 사용자 지정과 잘 어울리는지 확인하세요.

### CSS로 사용자 지정한 내용이 있으면 어떻게 되나요?

CSS 사용자 지정이 위젯 설정보다 우선해요. 직접 만든 스타일이 먼저 적용되므로, 원하는 디자인이 캘린더 위젯에 그대로 반영돼요.

### 왼쪽 패널을 모두 끄고 싶은데, 설정을 꺼도 계속 보여요. 어떻게 하나요?

왼쪽 패널 전체를 숨기려면 아래 설정을 모두 확인하세요.

캘린더 상세 설정:

- **캘린더 이름**을 끄세요.
- **캘린더 설명**을 끄세요.
- **Calendar Details**(캘린더 상세)를 끄세요.

로고 삭제:

- 캘린더에 연결된 로고를 삭제하세요.

**Customizations**(사용자 지정) 탭:

- **Allow Select Staff**(직원 선택 허용) 옵션을 끄세요.
