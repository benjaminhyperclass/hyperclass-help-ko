# 캘린더·예약을 원하는 시간대로 보기

예약 시간이 화면에 표시되는 시간대를 사용자마다 원하는 대로 고를 수 있어요. 이 설정은 **캘린더 보기**, **예약 목록 보기**, **연락처**, **대화**에 보이는 예약 시간에만 적용돼요. 가용 시간, 예약 방식, 일정 로직에는 영향을 주지 않아요.

## 개요

**View Appointments In**(다음 시간대로 예약 보기) 설정에서는 사용자가 예약을 표시할 시간대를 직접 고를 수 있어요.

이 설정은 다음과 같아요.

- 로그인한 본인에게만 적용돼요.
- 예약 시간이 표시되는 방식만 바꿔요.
- 가용 시간 설정에는 영향을 주지 않아요.
- 예약 링크나 확인 메시지에는 영향을 주지 않아요.
- 일정 로직은 바꾸지 않아요.

이제 **User Timezone**(사용자 시간대)이나 **비즈니스 시간대** 두 가지 중에서만 고르지 않아도 돼요. 원하는 시간대를 자유롭게 선택할 수 있어요.

## 설정이 적용되는 곳

선택한 시간대는 아래 화면의 예약 시간에 적용돼요.

- **캘린더 보기**
- **예약 목록 보기**
- **연락처**의 예약 섹션
- **대화**

## 예약을 보는 시간대 바꾸기

1. **캘린더 설정**으로 이동하세요.
2. **환경설정**을 여세요.
3. **View Appointments In**을 찾으세요.
4. 원하는 시간대를 선택하세요.
5. **환경설정 저장**을 클릭하세요.

이 설정은 언제든 바꿀 수 있어요.

## 플랫폼의 시간대 표시

### 캘린더 보기

지금 선택된 시간대가 캘린더 화면에 표시돼요. 어떤 시간대가 적용 중인지 바로 확인할 수 있어요.

### 예약 목록 보기

**예약 목록 보기**에서는 페이지 맨 아래에 적용 중인 시간대가 표시돼요.

## 기존 설정과의 호환

예전에는 **실험실**의 플래그 하나로 예약이 표시되는 방식을 정했어요.

- 플래그가 켜져 있으면 예약이 **User Timezone**으로 표시됐어요.
- 플래그가 꺼져 있으면 예약이 **비즈니스 시간대**로 표시됐어요.

이 **실험실** 플래그는 없어졌고, **View Appointments In** 설정으로 대체됐어요.

기존 사용자는 다음과 같이 자동으로 설정돼요.

- 플래그가 켜져 있었다면 **User Timezone**으로 설정돼요.
- 플래그가 꺼져 있었다면 **비즈니스 시간대**로 설정돼요.

이 설정은 언제든 바꿀 수 있어요.

## 가용 시간과 시간대 설정

이 기능은 예약이 표시되는 방식만 바꿔요.

아래 항목은 바뀌지 않아요.

- 사용자 가용 시간
- **미팅 시간**
- **일정 규칙**
- 예약 링크
- 확인·리마인더 로직

가용 시간은 계속 아래 경로에서 설정해요.

**설정 > 내 프로필 > 사용자 가용성**

## 예시

비즈니스는 뉴욕(EST)에서 운영하고, 나는 런던(GMT)에 있다고 해볼게요.

- 현지 시간으로 보기 편하게 GMT로 예약을 볼 수 있어요.
- 다른 사용자는 비즈니스 운영 시간에 맞춰 EST를 선택할 수도 있어요.
- 예약 시간은 사용자마다 선택한 시간대에 맞춰 표시돼요.

직접 시간을 계산해서 바꿀 필요는 없어요.

## 자주 묻는 질문

### 예약을 보는 시간대를 바꾸면 내 가용 시간도 바뀌나요?

아니요. 나에게 보이는 예약 시간의 표시 방식만 바뀌어요.

### 다른 사용자도 내가 고른 시간대로 예약을 보게 되나요?

아니요. 이 설정은 사용자별로 적용돼요.

### 어떤 시간대든 선택할 수 있나요?

네. 선택 가능한 시간대 중에서 자유롭게 고를 수 있어요.

### 예약을 비즈니스 시간대로 보려면 어떻게 하나요?

**캘린더 설정 > 환경설정 > View Appointments In**으로 이동해서, 서브 계정에 설정된 비즈니스 시간대를 선택하세요.
