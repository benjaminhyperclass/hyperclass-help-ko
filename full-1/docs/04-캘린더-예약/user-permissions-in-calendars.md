# 캘린더 사용자 권한

캘린더 모듈에서 사용자별로 권한을 세분화해 설정하는 방법을 설명해요. 사용자가 맡은 역할에 필요한 데이터와 기능만 쓸 수 있도록 제한하고 싶을 때 참고하세요.

## 권한 종류

권한은 크게 두 가지예요.

- **권한 보기**: 캘린더 모듈 안의 특정 항목을 볼 수 있는 권한이에요.
- **권한 관리**: 캘린더 모듈 안의 항목을 만들고, 편집하고, 삭제할 수 있는 권한이에요.

### 배정된 데이터 접근

일반 권한과 별개로, 사용자마다 **Assigned Data**(배정된 데이터)를 켜거나 끌 수 있어요.

- **Assigned Data**를 켜면 사용자는 자신에게 배정된 예약과 캘린더를 볼 수 있어요. 필요한 캘린더 권한이 있으면 자신이 팔로우하는 연락처의 예약도 볼 수 있어요.
- **Assigned Data**를 끄면 배정 여부와 상관없이, 사용자에게 부여된 접근 권한대로 적용돼요.

## 세부 권한 옵션

권한 보기와 권한 관리를 항목별로 나누어 지정할 수 있어요.

### 권한 보기

아래 항목에 대해 볼 수 있는 권한을 줄 수 있어요.

- **캘린더**
- **예약**
- **그룹**

이 권한 중 하나라도 켜면 사용자가 캘린더 모듈에 들어갈 수 있어요.

### 권한 관리

아래 항목에 대해 관리 권한을 줄 수 있어요.

- **캘린더**
- **예약**
- **그룹**

이렇게 세분화하면 다음을 정할 수 있어요.

- 어떤 사용자가 캘린더 모듈에 들어올 수 있는지
- 각 사용자가 캘린더의 어떤 부분을 관리할 수 있는지

## 설정 예시

1. **캘린더에 대한 권한 보기만 있고 권한 관리는 없는 사용자**

   - 모든 캘린더를 볼 수 있지만 만들거나 편집하거나 삭제할 수는 없어요.
2. **예약에 대한 권한 관리만 있는 사용자**

   - 예약을 만들고, 편집하고, 삭제할 수 있어요. 캘린더나 그룹은 수정할 수 없어요.
3. **Assigned Data를 켜고 예약에 대한 권한 보기가 있는 사용자**

   - 자신에게 배정된 예약만 볼 수 있어요.
4. **Assigned Data를 켜고 연락처를 팔로우하는 사용자**

- **View appointments, calendars & groups**(예약, 캘린더, 그룹 보기) 권한이 있으면, 자신에게 배정된 예약에 더해 팔로우하는 연락처의 예약도 볼 수 있어요.
- **Manage appointments**(예약 관리) 권한이 없으면 예약을 볼 수만 있고 편집하거나 삭제할 수 없어요.
- **Manage appointments** 권한이 있으면 캘린더 접근 권한 범위 안에서 예약을 편집하고 관리할 수 있어요.
