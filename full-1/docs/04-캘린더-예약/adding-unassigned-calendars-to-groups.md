# 미배정 캘린더를 그룹에 추가하기

이제 **Unassigned Calendar**(미배정 캘린더) 유형의 캘린더도 그룹에 넣을 수 있어요. 기존처럼 **Round-robin**(라운드 로빈) 캘린더도 그룹에 넣을 수 있어요. 이 문서에서는 캘린더를 그룹으로 옮기는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/yN1yhrhrmMA?&wmode=opaque)

1. **설정 > 캘린더**로 이동하세요.

   ![설정의 캘린더 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48275919878/original/gUC1FoTf1TkFGD4EjVwNtoSiNONwucJNGw.png?1673969124)

2. 그룹에 넣을 캘린더의 오른쪽 끝에 있는 점 3개 아이콘을 클릭한 다음 **그룹으로 이동**을 클릭하세요.

   ![점 3개 메뉴에서 그룹으로 이동을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48275920143/original/IaGc2orq1dFPZYTiaRHLr7vXXpmjMra8hA.png?1673969175)

3. 팝업 창이 열리면 캘린더를 넣을 그룹을 고르세요.
4. **선택**을 클릭하세요.

   ![그룹을 고르고 선택을 클릭하는 팝업 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48275920666/original/1F0J1bCyUySo4ajbnqGnMjKzfasxNqZjOw.png?1673969263)
