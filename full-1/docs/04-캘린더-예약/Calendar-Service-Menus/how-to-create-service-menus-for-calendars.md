# 캘린더 서비스 메뉴 만들기

서비스 메뉴를 만들면 캘린더별 서비스를 한 페이지에 모아 보여 줄 수 있어요. 고객은 이 페이지에서 원하는 서비스를 빠르고 편하게 예약할 수 있어요.

[동영상](https://www.youtube.com/embed/hVFDsVSSczg?&wmode=opaque)

## 서비스 메뉴란?

서비스 메뉴는 여러 서비스를 하나의 브랜드 화면에 나열해서, 고객이 한 번의 흐름으로 여러 예약을 잡을 수 있게 해 줘요. 서비스마다 별도의 서비스 캘린더가 연결돼요. 그래서 가용 시간, 직원 배정, 가격, 소요 시간을 서비스별로 직접 정할 수 있어요. 서비스가 여러 개이거나 여러 담당자와 일하는 사업장에 특히 유용해요.

![서비스 메뉴 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045150402/original/Ddot4O6nQ4eap8ZLOgnE3VVsTIKHdIngnA.jpeg?1744737613)

## 서비스 메뉴의 주요 장점

서비스 메뉴는 예약 과정의 번거로움을 줄여 줘요. 서비스를 보여 주고 예약받는 방식도 자유롭게 정할 수 있어요.

- 한 곳에서 예약: 모든 서비스를 한 화면에 모아서, 고객이 한곳에서 둘러보고 예약할 수 있어요.
- 직원 선택(선택 사항): 이 기능을 켜면 고객이 원하는 담당자를 직접 고를 수 있어요.
- 서비스 분류: 캘린더 그룹으로 관련 서비스를 묶어 정리하고 보여 줄 수 있어요.
- 캘린더별 독립 설정: 서비스마다 자기 캘린더가 있어서 설정, 직원, 가용 시간, 소요 시간을 따로 정할 수 있어요.
- 유연한 예약 방식: 설정에 따라 고객이 한 번에 서비스를 하나만 예약하거나 여러 개 예약할 수 있어요.

## 시작하기 전에 준비할 것

- 서비스 캘린더 만들기: 제공하는 서비스마다 전용 캘린더를 만들고, 각 캘린더를 해당 그룹에 배정하세요.

  ```
  서비스 캘린더 만드는 방법은 여기를 클릭해 자세히 알아보세요
  ```

- 캘린더 그룹 만들기: 관련 서비스 캘린더를 하나의 카테고리로 묶으려면 캘린더 그룹이 필요해요. 그룹에 배정된 캘린더만 서비스 메뉴에 넣을 수 있어요.

  ```
  캘린더 그룹 만드는 방법은 여기를 클릭해 자세히 알아보세요
  ```

## 서비스 메뉴 설정하기

설정을 제대로 해 두면 메뉴에 알맞은 서비스가 표시되고, 가용 시간이 반영되며, 예약이 올바르게 연결돼요.

### 1단계: 서비스 메뉴 기능 켜기

서비스 메뉴 기능을 켜는 방법이에요.

1. 왼쪽 메뉴에서 **캘린더**로 이동하세요.
2. **캘린더 설정**을 클릭한 다음, 보조 메뉴에서 **환경설정** 탭으로 이동하세요.
3. 환경설정 아래에 있는 **계정** 탭으로 이동하세요.
4. **서비스** 섹션을 찾아 **서비스 메뉴** 파란색 토글을 켜세요.

![서비스 메뉴 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045137111/original/gI17UrNq8kNHSbTSuGFw-WMjEarMsW7m9g.png?1744727407)

### 2단계: 서비스 메뉴 만들기

기능을 켰고 서비스 캘린더도 준비됐다면, 서비스 메뉴를 만들어요.

1. 왼쪽 메뉴에서 **설정 > 캘린더**로 이동하세요.
2. **캘린더 설정** 아래의 **서비스 메뉴** 탭으로 이동하세요.
3. 오른쪽 위의 파란색 **Create Service Menu**(서비스 메뉴 만들기) 버튼을 클릭하세요.
4. 다음 항목을 입력하세요.
   - **이름**: 메뉴 제목으로 표시돼요.
   - **설명**: 고객에게 보여 줄 요약이에요. 입력은 선택 사항이에요.
   - **Slug URL**(슬러그 URL): 메뉴의 맞춤 URL이 돼요.
   - **폼**: 이 캘린더로 예약하는 고객에게 기본 항목(이름, 성, 이메일, 전화번호) 외에 더 많은 정보를 받고 싶다면 커스텀 폼을 선택하세요.

![서비스 메뉴 정보를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045149968/original/u08a5TLsPzmJf4hb85RVG-XPjEwzNQRf7g.png?1744737103)

### 3단계: 서비스 선택하기

메뉴 정보를 입력했다면, 메뉴에 표시할 서비스(캘린더)를 고르세요.

1. 서비스 메뉴 편집 화면에서 **Select Services**(서비스 선택) 탭으로 이동하세요.
2. 체크박스로 서비스 메뉴에 표시할 서비스(캘린더)를 선택하세요.

![서비스를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045150070/original/rnYbEfRpkgUiieAwaTRGK7Uz36bT7fkMEQ.png?1744737257)

### 4단계: 서비스 순서 정하기

1. 서비스를 드래그 앤 드롭해서 표시 순서를 정하세요.
2. 변경사항을 저장하세요.

## 제한 사항

현재 서비스 메뉴에는 다음과 같은 제한이 있어요.

1. Stripe만 지원: 서비스 메뉴에서는 Stripe로만 결제를 받을 수 있어요.
2. 카드 저장 불가: 서비스 메뉴로 예약할 때는 고객 카드가 다음 결제를 위해 저장되지 않아요.
3. 앱 내 결제 불가: 모바일 앱 안에서 결제를 받는 기능은 지원하지 않아요.
4. 쿠폰 코드 불가: 결제할 때 할인이나 쿠폰 코드를 적용할 수 없어요.

### **서비스 (v2)** 로 업그레이드

여러 결제 수단, 카드 저장, 앱 내 결제, 쿠폰 코드 지원 같은 기능을 모두 쓰려면 새로운 **서비스 (v2)** 로 옮길 수 있어요.

## 자주 묻는 질문

### 서비스 메뉴를 여러 개 만들 수 있나요?
네, 캘린더 그룹을 다르게 해서 메뉴를 여러 개 만들 수 있어요.

### 서비스 메뉴는 모바일에서도 잘 보이나요?
네. 화면 크기에 맞게 자동으로 조정되고 모바일 기기에 맞게 최적화돼 있어요.

### 고객이 서비스를 두 개 이상 선택할 수 있나요?
네, 단 **Limit to One Service**(한 가지 서비스로 제한) 옵션을 켜지 않았을 때만 가능해요.

### 서비스 순서를 바꾸려면 어떻게 하나요?
서비스 메뉴를 만들거나 편집하는 중에 서비스를 드래그 앤 드롭하세요.

### 전환을 추적하거나 분석 도구를 추가할 수 있나요?
네. 커스텀 코드 입력란에 추적 픽셀이나 스크립트를 추가하면 돼요.
