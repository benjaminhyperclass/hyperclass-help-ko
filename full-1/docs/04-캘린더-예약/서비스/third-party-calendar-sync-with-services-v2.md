# Services(v2) 외부 캘린더 동기화

Google Calendar, Outlook, iCal 동기화가 Services(v2) 예약에서 지금 어떻게 동작하는지 설명해요. 서비스가 여러 개 담긴 예약도 함께 다뤄요. 직원이 연결한 캘린더를 직접 수정하면 어떻게 되는지도 확인할 수 있어요.

## 서비스 예약과 예약의 관계

고객이 한 번의 결제로 서비스를 하나 이상 예약하면, 플랫폼에는 **서비스 예약** 하나가 만들어져요.

서비스가 여러 개 담긴 경우도 있어요. 예를 들어 헤어컷 다음에 다른 직원이 하는 헤어 스파를 예약할 수 있어요. 이때 각 서비스는 같은 방문 안에서 이어서 진행되도록 일정이 잡혀요. **서비스 예약** 아래에는 서비스(직원)마다 **예약** 기록이 하나씩 생겨요.

**서비스 예약**에는 방문 하나에 공통으로 적용되는 정보가 담겨요.

- 고객 정보
- 커스텀 값
- 전체 상태
- 모든 서비스를 한 번에 처리하는 결제

## 캘린더 동기화는 지금 이렇게 동작해요

직원이 Google, Outlook, iCal 캘린더를 연결해 두었다면 **서비스 예약**의 예약을 그 캘린더에 동기화할 수 있어요.

- 서비스가 하나인 예약: 외부 캘린더 동기화를 모두 지원해요. 하이퍼클래스에서 바꾼 내용은 연결된 캘린더에 반영돼요. 연결된 캘린더에서 바꾼 내용 중 지원되는 변경은 하이퍼클래스에도 반영돼요.
- 서비스가 여러 개인 예약: 서비스마다 담당 직원의 캘린더에 별도 일정으로 등록돼요. 하지만 양방향 동기화는 지원하지 않아요. 이런 예약은 항상 하이퍼클래스 안에서 변경하세요.

## 제한 사항: 서비스가 여러 개인 예약은 외부 캘린더에서 바꿔도 반영되지 않아요

서비스가 여러 개 담긴 **서비스 예약**은 연결된 외부 캘린더에서 직접 바꿔도 하이퍼클래스에 반영되지 않아요.

예를 들면 이래요.

- Google Calendar에서 서비스 일정의 시간을 옮겨도 하이퍼클래스의 해당 서비스 일정은 바뀌지 않아요.
- 연결된 캘린더에서 서비스 일정 하나를 삭제하거나 수정해도 하이퍼클래스의 **서비스 예약**은 바뀌지 않아요.
- 서비스마다 캘린더 일정이 따로 생길 수 있어요. 그래서 일정 하나를 외부에서 바꾸면, 외부 캘린더에 보이는 정보가 하이퍼클래스의 **서비스 예약**과 달라질 수 있어요.

하이퍼클래스에는 플랫폼 안에 저장된 예약 정보가 그대로 유지돼요. 예약 시간과 고객에게 보내는 확인·리마인더에 쓰이는 정보도 여기에 포함돼요.

서비스가 여러 개인 예약의 일정 변경, 취소 등 모든 변경은 하이퍼클래스 안에서 직접 하세요.

## 상태 변경은 서비스 예약 전체에 적용돼요

**서비스 예약**의 상태는 하나만 있어요. 서비스가 여러 개 담긴 예약에서 연결된 예약 중 하나의 상태를 바꾸면(예: **예약 목록 보기**에서), 그 변경이 해당 **서비스 예약**에 연결된 모든 서비스에 적용된다는 확인 창이 나타나요. 지금은 나머지 서비스의 상태를 그대로 둔 채 서비스 하나에만 다른 상태를 지정할 수 없어요.

## 서비스가 여러 개인 예약에서 서비스 하나만 일정 변경하거나 취소하기

서비스가 여러 개인 예약에서 서비스 하나만 바꾸려면 하이퍼클래스에서 직접 변경하세요.

- 서비스 하나만 취소하려면: 예약을 열고 해당 서비스를 제거한 뒤 저장하세요. 나머지 서비스는 계속 예약에 남아 있어요.
- 서비스 하나만 다른 시간으로 옮기려면: 기존 예약에서 그 서비스를 제거하고, 원하는 시간으로 새 예약을 만드세요.

연결된 외부 캘린더에서 서비스 일정을 직접 바꿔도 하이퍼클래스의 서비스가 여러 개인 예약은 업데이트되지 않아요.

## 자주 묻는 질문

### Google Calendar에서 예약 시간을 옮겼어요. 하이퍼클래스에도 반영되나요?
서비스가 하나인 예약은 연결된 외부 캘린더에서 바꾼 내용 중 지원되는 변경이 하이퍼클래스에 다시 반영돼요. 서비스가 여러 개인 예약은 외부 캘린더에서 바꾼 내용이 반영되지 않아요. 예약 정보와 고객 안내가 정확하게 유지되도록, 서비스가 여러 개인 예약은 모든 변경을 하이퍼클래스에서 직접 하세요.

### 서비스 하나의 상태를 바꿨는데 왜 예약 전체의 상태가 바뀌나요?
상태는 서비스별이 아니라 **서비스 예약** 단위로 관리돼요. 서비스가 여러 개인 예약에 연결된 모든 예약은 같은 상태를 가져요.

### 전체 예약을 취소하지 않고 서비스 하나만 취소할 수 있나요?
네, 할 수 있어요. **서비스 예약**을 열어 해당 서비스를 제거하고 저장하세요. 나머지 서비스는 계속 예약에 남아 있어요.

### 서비스마다 만들어지는 캘린더 일정에 고객도 추가되나요?
담당 직원의 캘린더에 만들어지는 일정에 고객이 게스트로 표시될 수 있어요.

### 하이퍼클래스와 Google Calendar에서 서비스 시간이 다르게 보여요. 왜 그런가요?
서비스가 여러 개인 예약에서 서비스 일정 중 하나를 연결된 캘린더에서 직접 수정했을 때 이런 일이 생길 수 있어요. 이런 변경은 하이퍼클래스에 반영되지 않아요. 그래서 **서비스 예약**과 고객 안내에는 계속 하이퍼클래스에 저장된 정보가 쓰여요. 두 캘린더의 내용을 맞추려면 서비스가 여러 개인 예약은 하이퍼클래스에서 직접 변경하세요.
