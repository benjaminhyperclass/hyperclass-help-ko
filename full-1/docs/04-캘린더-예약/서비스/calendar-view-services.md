# 캘린더 보기에서 서비스 예약 확인하기

**캘린더 보기**는 예약을 한곳에서 관리하는 화면이에요. 사용하는 예약 유형에 따라 화면이 달라져서, 미팅과 서비스 예약 중 필요한 쪽만 집중해서 볼 수 있어요. 이 문서에서는 예약 유형별 차이와 필터, 보기 설정, 외부 캘린더 사용 시 제한 사항을 안내해요.

## 캘린더 보기의 예약 유형

현재 예약 유형은 **미팅**과 **서비스** 두 가지예요.

### 미팅

- 영업 캘린더, 개인 예약, 공동 캘린더, 클래스, 라운드 로빈 예약에 알맞아요.
- 기존 캘린더 유형을 모두 포함해요. 개인, 라운드 로빈, 공동, 클래스, 서비스 캘린더 v1, 서비스 메뉴가 해당돼요.
- 내부 미팅이나 고객 대상 미팅을 관리하는 분들을 위한 유형이에요.

### 서비스

- 서비스 업종을 위해 만든 유형이에요.
- 변형 옵션, 애드온, 복수 서비스, 직원별 가격 같은 고급 옵션을 지원해요.
- 직원, 서비스 종류, 여러 지점이 얽힌 예약을 관리할 때 도움이 돼요.

## 예약 유형 켜고 끄기

- 예약 유형은 **에이전시 설정**에서 켜거나 끌 수 있어요. 에이전시 관리자만 쓸 수 있어요.
- 한 가지 유형만 켜져 있으면 **캘린더 보기**가 그 유형을 자동으로 불러오고, 상단 드롭다운 메뉴는 나타나지 않아요.
- **미팅**과 **서비스**가 모두 켜져 있으면 **캘린더 보기** 상단에 드롭다운 메뉴가 나타나요. 여기서 두 유형을 전환할 수 있어요.

## 유형을 선택하면 화면이 이렇게 바뀌어요

**캘린더 보기** 상단 드롭다운에서 예약 유형을 선택하면 다음과 같이 바뀌어요.

- 오른쪽 패널의 레이아웃과 필터가 선택한 유형에 맞게 자동으로 바뀌어요.
- 캘린더에 표시되는 이벤트와 차단된 시간대는 선택한 예약 유형의 것만 보여요.
- 그래서 다른 유형의 정보가 섞이지 않고, 필요한 정보만 볼 수 있어요.

## 예약 유형별 필터

### 미팅 보기 필터

- **사용자**: 특정 사용자에 연결된 캘린더를 보여 줘요.
- **캘린더**: 개인, 라운드 로빈, 공동, 클래스 등 원하는 캘린더만 켜고 끌 수 있어요.
- **그룹**: 캘린더 그룹별로 이벤트를 걸러 봐요.

![미팅 보기의 필터 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054926294/original/Ou1jjReCWZgNmZr6ZYXILvLTvJZgw2JpbQ.png?1759237547)

### 서비스 보기 필터

- **직원**: 배정된 직원별로 이벤트를 보여 줘요.
- **서비스**: 특정 서비스에 연결된 예약을 보여 줘요.
- **카테고리**: 서비스 카테고리로 결과를 좁혀요.
- **Unified Service Booking View**(통합 서비스 예약 보기)
  - 이 옵션을 켜면 각 **서비스 예약**이 캘린더에 하나의 블록으로 표시되고, 그 안에 해당 예약의 모든 예약 건이 묶여 보여요.
  - 이 보기에서는 모든 예약 건이 함께 표시되므로 **직원**, **서비스**, **카테고리** 필터는 사용할 수 없어요.

    {% hint style="info" %}
    **직원**, **서비스**, **카테고리** 필터는 이 보기에서 사용할 수 없어요.
    {% endhint %}

  - 대신 **Location Filter**(위치 필터)를 쓸 수 있어요. 예약한 위치를 기준으로 예약 건을 걸러 봐요.

## 그 밖의 캘린더 조작

- 월 보기 미니 캘린더: 메인 날짜 아래에 있어요. 날짜를 클릭하면 펼쳐져요.
- 필터 숨기기/표시: 오른쪽 위의 **Manage View**(보기 관리) 버튼을 사용해요. 오른쪽 필터 패널을 **숨기기**로 넣어 화면을 더 넓게 쓰고, 필요할 때 다시 표시할 수 있어요.

## 활용 팁

{% hint style="info" %}
- **Unified Service Booking View**를 켜면 직원과 카테고리에 걸친 서비스 예약을 더 간단하게 한눈에 볼 수 있어요.
- 서비스 보기에서 위치 필터를 쓰면 특정 지점의 예약만 모아 볼 수 있어요.
- 예약이 많은 캘린더를 발표하거나 검토할 때는 오른쪽 패널을 숨기면 편해요.
- 미니 월 보기를 쓰면 날짜 사이를 빠르게 이동할 수 있어요.
{% endhint %}

## 제한 사항: 외부 캘린더 변경 내용

서비스 보기에서는 Google Calendar, Outlook, iCal 같은 외부 캘린더에서 직접 바꾼 내용이 하이퍼클래스에 반영되지 않아요.

{% hint style="warning" %}
캘린더를 정확하게 유지하려면 일정 변경, 취소, 수정 같은 모든 업데이트를 하이퍼클래스 안에서 해야 해요.
{% endhint %}
