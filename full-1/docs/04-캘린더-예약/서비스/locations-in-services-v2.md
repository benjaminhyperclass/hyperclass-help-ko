# 서비스(v2)에서 위치 설정하기

서비스가 진행되는 장소를 '위치'로 등록하고 관리하는 방법을 안내해요. 지점이 여러 곳이면 위치를 추가하고, 직원별로 위치와 근무 시간을 연결하세요.

## 위치란?

위치는 서비스가 이루어지는 장소예요. 쉽게 말해 나와 고객이 만나는 곳이에요. 사무실, 매장 같은 실제 주소가 될 수 있어요.

계정을 처음 설정하면 **설정 > 비즈니스 프로필**에 입력한 사업장 주소로 기본 위치가 자동으로 만들어져요.

- 한 곳에서만 영업하는 비즈니스에 알맞아요.
- 기본 위치의 정보는 **캘린더 설정 > 서비스 > Locations**(위치) 탭에서 **편집**을 클릭해 언제든 수정할 수 있어요.

![서비스의 위치 탭에서 기본 위치를 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054380527/original/aNY37RfgPKImI9iTUSwxkHuRiGHyVdJAWg.png?1758628384)

## 여러 위치 관리하기

지점이나 사무실이 두 곳 이상이면 여러 위치를 쓰도록 설정할 수 있어요. 지점이 여러 곳인 비즈니스를 위한 기능이에요.

설정 방법은 다음과 같아요.

1. **캘린더 설정 > 서비스**로 이동하세요.
2. **글로벌 설정** 아래에서 **Enable Multiple Locations**(여러 위치 사용) 토글을 켜세요.
3. 켠 뒤에는 **Locations** 탭에서 위치를 더 추가할 수 있어요.

![글로벌 설정에서 여러 위치 사용 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054380709/original/D81sA1XuUhH-V0APmqA3W3e-23N1Rz935Q.png?1758628479)

## 모바일 서비스 v2 예약에서 위치 정보가 보이는 방식

설정해 둔 위치 정보는 모바일 예약 화면을 포함해 예약 과정 전체에서 쓰여요. 예약이 실제 주소나 온라인 미팅 링크와 연결되어 있으면, 위치가 분명하게 보여서 직원과 고객이 더 빨리 움직일 수 있어요.

모바일 서비스 v2 예약에서는 위치 정보가 다음 중 하나로 표시돼요.

- 전체 실제 주소
- 온라인 미팅 URL
- 전체 주소가 없을 때는 위치 이름

예약 유형에 따라 모바일 사용자는 표시된 위치 값을 복사할 수 있어요. **View Location**(위치 보기), **Join Meeting**(미팅 참여) 같은 빠른 작업도 쓸 수 있어요.

모바일 예약 작업 과정은 '모바일 앱에서 서비스 v2 예약 관리하기' 문서를 참고하세요.

## 새 위치 추가하기

여러 위치를 쓰도록 설정했다면 다음 순서로 위치를 추가하세요.

1. **Locations** 탭으로 이동하세요.
2. **새로 추가**를 클릭하세요.
3. 위치 이미지를 업로드하세요. 이 이미지는 예약 페이지에 표시돼요.
4. 위치 이름, 전화번호, 주소를 입력하세요.
5. **Save Location**(위치 저장)을 클릭하세요.

{% hint style="info" %}
Zoom, Google Meet 같은 온라인 위치는 아직 바로 지원하지 않아요. 대신 고정된 화상회의 링크를 만들어 **주소** 필드에 입력하면 돼요.
{% endhint %}

## 위치별 직원 가용 시간 설정하기

위치를 만든 뒤에는 직원의 가용 시간을 설정해야 해요. 그래야 서비스가 알맞은 위치에 제대로 배정돼요.

설정 방법은 다음과 같아요.

1. **캘린더 설정 > 서비스 > 직원**으로 이동한 뒤, 직원 한 명의 **편집**을 클릭하세요.
2. **Assign Services**(서비스 지정) 탭으로 이동해 필요한 서비스를 지정하세요.
3. **Weekly Working Hours**(주간 근무 시간) 탭으로 이동하세요.
4. 특정 위치에서 특정 서비스를 맡을 수 있는 시간에 맞춰 직원의 근무 시간을 추가하세요.

직원 한 명을 여러 위치에 배정하고 위치마다 다른 일정을 줄 수 있어요. 그래서 서비스를 더 유연하게 운영할 수 있어요.

{% hint style="warning" %}
예약 과정에서 위치가 표시되려면, 그 위치가 **Staff Settings**(직원 설정)의 직원 가용 시간과 연결되어 있어야 해요.
{% endhint %}

![직원 편집 화면에서 서비스와 근무 시간을 설정하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054381772/original/cKgg8nUEREa8Qq0qvgDCIKlq0laRrKd2DQ.png?1758629005)

## 자주 묻는 질문

### 한 곳에서만 영업하는데도 위치를 만들어야 하나요?
아니요. **비즈니스 프로필**에 있는 주소로 기본 위치가 자동으로 만들어져요. 여러 곳에서 영업할 때만 새 위치를 만들면 돼요.

### 기본 위치를 수정할 수 있나요?
네. **캘린더 설정 > 서비스 > Locations** 탭에서 **편집**을 클릭한 뒤 정보를 수정하세요.

### Zoom이나 Google Meet 같은 온라인 위치를 쓸 수 있나요?
온라인 위치는 아직 바로 지원하지 않아요. 대신 Zoom, Google Meet 같은 고정 화상회의 링크를 **주소** 필드에 붙여 넣으면 돼요.

### 위치에 직원 가용 시간을 지정하지 않으면 어떻게 되나요?
직원의 가용 시간이 위치와 연결되어 있지 않으면, 예약 과정에서 그 위치가 선택지로 나타나지 않아요.

### 직원이 여러 위치에서 일할 수 있나요?
네. 직원을 두 곳 이상의 위치에 배정하고 위치마다 다른 일정을 줄 수 있어요. 지점이 여러 곳이어도 유연하게 운영할 수 있어요.

### 고객은 위치 정보를 어디에서 볼 수 있나요?
고객은 예약 페이지와 예약 확인 화면에서 선택한 위치의 이미지, 이름, 주소를 볼 수 있어요.

### 위치를 삭제할 수 있나요?
네. 계정에 추가로 만든 위치는 삭제할 수 있어요. 다만 기본 위치는 삭제할 수 없어요. 필요하면 기본 위치의 정보만 편집할 수 있어요.
