# 서비스 v2 모바일 예약에서 Ask the Booker 위치 사용하기

모바일 앱에서 서비스 v2 예약을 만들 때 고객의 서비스 주소를 직접 받을 수 있어요. Ask the Booker 위치를 선택하면 주소 입력란이 나타나고, 입력한 주소는 예약 상세 화면에 저장돼요. 예약을 편집하거나 복제할 때도 그 주소가 미리 채워져요.

## Ask the Booker 위치 지원이란?

Ask the Booker 위치 지원을 쓰면 서비스 캘린더 v2 예약 중에 고객이 알려 준 서비스 주소를 받을 수 있어요. 방문 미용, 수리 기사, 청소, 컨설턴트, 트레이너처럼 고객을 직접 찾아가는 비즈니스에 잘 맞아요.

위치 유형은 웹에서 설정해요. 설정을 마치면 모바일 앱의 서비스 v2 예약 화면에서 별도 작업 없이 쓸 수 있어요. 모바일 앱에서 Ask the Booker 위치를 선택하면 주소 입력란이 필수로 나타나서, 예약에 정확한 서비스 위치가 담겨요.

![Ask the Booker 위치를 선택하면 주소 입력란이 나타나는 예약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071321756/original/9dGW0RwfC_jhe9_rfz9IZPabXRaPIqRi6w.png?1778757303)

## Ask the Booker 위치 지원의 장점

예약할 때 서비스 주소를 받아 두면 방문 전에 따로 확인할 일이 줄어요. 주소가 예약에 바로 저장되어, 직원이 예약 화면에서 필요한 정보를 볼 수 있어요.

- 서비스 주소를 미리 받아요: 예약할 때 고객의 집, 사업장 등 원하는 서비스 주소를 받아 둘 수 있어요.
- 확인 연락이 줄어요: 서비스 장소를 확인하려고 따로 전화, 문자, 이메일을 보낼 필요가 없어요.
- 위치 정보가 비지 않아요: 필수 입력 검사 덕분에 서비스 주소 없이는 예약을 등록할 수 없어요.
- 모바일 서비스 팀을 도와요: 직원이 모바일 앱으로 일하면서 고객이 입력한 주소를 볼 수 있어요.
- 예약 편집·복제에도 주소를 활용해요: 예약을 편집하거나 복제할 때 저장된 주소가 미리 채워져요.
- 길 찾기가 빨라요: 예약 화면에서 주소를 복사하거나 지도 앱으로 위치를 열 수 있어요.

## 사용 가능한 환경과 요구 사항

Ask the Booker 위치 지원은 서비스 캘린더 v2 예약에서 쓸 수 있어요. 설정과 앱 조건을 확인해 두면 모바일 예약 화면에 주소 입력란이 제대로 나타나요.

이 기능을 쓸 수 있는 환경은 다음과 같아요.

- 서비스 캘린더 v2 예약만 해당해요
- 하이퍼클래스 모바일 앱
- 화이트라벨 모바일 앱
- 모바일 앱 버전 4.10.0 (810) 이상
- 웹과 모바일의 서비스 v2 예약 흐름

Ask the Booker 위치 유형은 웹의 **캘린더 설정 > 서비스(v2) > 위치**에서 설정해요. 설정을 마치면 해당 위치를 선택할 때 모바일 앱에 서비스 주소 입력란이 자동으로 나타나요.

## 웹에서 Ask the Booker 위치 설정하기

Ask the Booker 위치는 웹 앱에서 만들고 관리해요. 이 설정으로 서비스 v2 예약 화면이 언제 고객의 서비스 주소를 물어볼지 정해져요.

위치를 설정하려면 다음과 같이 하세요.

1. **캘린더 설정 > 서비스(v2) > 위치**로 이동하세요.
   ![캘린더 설정의 서비스(v2) 위치 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077026147/original/FicfTGTCaN7ZHN2fPnQyhB3JQIzkz8gg_A.png?1785240655)
2. 새 위치를 만들거나 기존 위치를 편집하세요.
3. **Let bookers enter their own service address**(예약자가 직접 서비스 주소 입력)를 켜세요.
4. 필요하면 직원 가용 시간에 이 위치를 지정하세요.
   ![직원 가용 시간에 위치를 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077026401/original/CAPwLWfqL0yXmgyhXrzTAat8j8cjrm8YRA.png?1785240783)
5. 위치 설정을 저장하세요.

설정이 끝나면 모바일 앱에서 서비스 v2 예약을 만들 때 이 위치를 선택할 수 있어요.

## 모바일 앱에서 Ask the Booker 위치 선택하기

모바일 예약 화면은 선택한 위치 유형에 따라 달라져요. Ask the Booker 위치를 선택하면 주소 입력란이 하나 더 나타나서, 예약을 잡기 전에 서비스 주소를 받을 수 있어요.

위치를 선택하려면 다음과 같이 하세요.

1. 모바일 앱을 여세요.
2. **캘린더**로 이동하세요.

   ![모바일 앱의 캘린더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077026899/original/YXUfn2tvREPJXqWPPwk75J4eu7Lgv09ejw.png?1785241131)
3. **+ New Service Appointment**(+ 새 서비스 예약)를 탭하세요. **연락처**, **대화**, **기회 관리**에서 서비스 v2 예약을 시작해도 돼요.

   ![서비스 예약을 시작하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077027446/original/VUlZlBhPBVytZkTxFhufNByQ_97BhGV15w.png?1785241427)
4. **Location Details**(위치 상세정보)에서 위치 드롭다운을 탭하세요.
   ![위치 드롭다운을 탭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077028409/original/iaRPauC4qyycPQKUywjpz6w2QbmEc_sXHg.png?1785241827)
5. 예약자에게 주소를 묻도록 설정한 위치를 선택하세요. 예를 들어 **Enter manual**(직접 입력) 같은 위치예요.

![Ask the Booker 위치를 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077028630/original/iarEk1hp2deFF2a9i1vzZ9xR61Eq3R-OCg.png?1785241901)

## 필수 서비스 주소 입력란

Ask the Booker 위치를 선택하면 서비스 주소 입력란은 필수예요. 그래서 직원이 서비스를 마치는 데 필요한 주소 없이 예약이 잡히는 일을 막아 줘요.

Ask the Booker 위치를 선택한 뒤 주소 입력란에 고객의 서비스 주소를 입력하세요. 입력란을 비워 두면 **위치를 입력해주세요** 같은 안내가 입력란 아래에 표시돼요. 주소를 입력하기 전에는 예약을 등록할 수 없어요.

![주소를 비워 두었을 때 검사 메시지가 나타난 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071322053/original/ZRjesKACBrIZYqRWMW0xw43LC7Z_r408nw.png?1778757507)

## 예약에 저장된 주소 확인하기

예약을 만들고 나면 저장된 서비스 주소가 예약 상세 화면에 바로 표시돼요. 직원이 메모나 메시지를 뒤지지 않아도 필요한 주소를 빠르게 볼 수 있어요.

예약 상세 화면에서는 주소가 **Location Details** 아래에 나타나요. 복사 아이콘으로 주소를 복사하거나 **View Location**(위치 보기)을 탭해 지도로 길 안내를 열 수 있어요.

![예약 상세 화면에 저장된 서비스 주소](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071322186/original/3vV9PoUZRWF-ZOMw1VYwvO32pGOPJgeOcA.png?1778757578)

## Ask the Booker 위치가 있는 예약 편집·복제하기

Ask the Booker 주소 정보는 예약을 편집하거나 복제할 때도 예약과 계속 연결돼 있어요. 이미 받은 정보를 다시 입력하지 않고 바로 고칠 수 있어요.

서비스 v2 예약을 편집하거나 복제할 때는 다음과 같이 동작해요.

- 앞서 입력한 서비스 주소가 미리 채워져요.
- 기존 주소를 그대로 두거나 수정할 수 있어요.
- 선택한 위치가 여전히 Ask the Booker 위치라면 주소는 계속 필수예요.
- 변경을 마치면 수정하거나 복사한 주소가 예약에 저장돼요.

단골 고객을 다시 예약하거나, 기존 서비스 주소를 유지한 채 예약을 조정할 때 유용해요.

---

## 위치 유형이 여러 개일 때의 동작

위치에 따라 위치 유형이 둘 이상일 수 있어요. 예약 화면은 예약 중에 선택한 위치 유형에 따라 동작해요.

선택한 위치가 예약자에게 서비스 주소를 묻도록 설정되어 있으면 주소 입력란이 나타나고 필수가 돼요. 다른 위치 유형을 선택하면, 그 위치 유형의 동작을 따라요.

## 모바일 앱에서 Ask the Booker 위치 지원 사용하기

모바일 앱에서 서비스 v2 예약을 만들 때 고객의 서비스 주소를 직접 입력할 수 있어요. 웹 앱에서 위치를 설정해 두면, 모바일 예약 중 그 위치를 선택할 때 필수 주소 입력란이 나타나요.

시작하기 전에 모바일 앱 버전이 4.10.0 (810) 이상인지 확인하세요.

1. 웹 앱의 **캘린더 설정 > 서비스(v2) > 위치**에 Ask the Booker 위치가 설정되어 있는지 확인하세요.
   ![웹 앱에서 설정된 Ask the Booker 위치 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077066827/original/4SMIHcGetcD_0NmTJFbdPym9-zcmv4wnkg.jpeg?1785259791)
2. 하이퍼클래스 모바일 앱이나 화이트라벨 모바일 앱을 여세요.
3. **캘린더**로 이동하세요.
4. **+ New Service Appointment**(+ 새 서비스 예약)를 탭하세요.

   **연락처**, **대화**, **기회 관리**에서 서비스 v2 예약을 시작할 수도 있어요.
   ![서비스 예약 시작 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077067412/original/V0HWAif66RpbFl85vxt1xMGsjSd5iuq_cg.jpeg?1785260383)
5. 연락처를 검색해 선택하세요.
6. **Location Details** 아래의 위치 드롭다운을 탭하세요.
7. 예약자의 서비스 주소를 받도록 설정한 위치를 선택하세요.
   ![서비스 주소를 받는 위치 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077067467/original/dhRUasc0gz-KjlvNt2WIaukXGrFzwYKIew.png?1785260442)
8. 필수 주소 입력란에 고객의 서비스 주소를 입력하세요.

   서비스 주소를 입력하기 전에는 예약을 등록할 수 없어요.
9. 해당하는 서비스, 직원, 날짜, 시간, 예약 상태를 추가하세요.
10. 예약 정보를 확인한 뒤 **Schedule Booking**(예약 일정 잡기)을 탭하세요.
11. 예약 상세 화면을 열어 저장된 주소가 **Location Details** 아래에 표시되는지 확인하세요.

![예약 상세 화면에서 저장된 주소 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077067502/original/B4n4kNnC9nFPlh73Se0s5h8KSPdnghfzig.png?1785260494)

예약 상세 화면에서 주소를 복사하거나 **View Location**을 탭해 기기의 지도 앱에서 열 수 있어요.

## 자주 묻는 질문

### Ask the Booker 위치 지원은 모든 캘린더 유형에서 쓸 수 있나요?
아니요. 서비스 캘린더 v2 예약에서만 쓸 수 있어요.

### Ask the Booker 위치는 어디에서 설정하나요?
웹의 **캘린더 설정 > 서비스(v2) > 위치**에서 설정해요.

### 서비스 주소는 꼭 입력해야 하나요?
네. Ask the Booker 위치를 선택하면 주소 입력란이 필수예요. 주소를 입력해야 예약을 등록할 수 있어요.

### 예약이 등록되지 않아요.
선택한 위치가 예약자에게 서비스 주소를 입력하도록 설정되어 있으면, 주소 입력란을 채우기 전에는 예약을 등록할 수 없어요.

### 저장된 주소는 어디에서 볼 수 있나요?
예약 상세 화면의 **Location Details** 아래에서 볼 수 있어요.

### 예약을 편집하거나 복제할 때 주소가 미리 채워지나요?
네. 서비스 v2 예약을 편집하거나 복제할 때 앞서 입력한 서비스 주소가 미리 채워져요.

### 직원이 주소를 복사하거나 지도 앱에서 열 수 있나요?
네. 예약 상세 화면에서 저장된 주소를 복사하거나 **View Location**으로 열 수 있어요.

### 어떤 모바일 앱에서 이 기능을 쓸 수 있나요?
하이퍼클래스 모바일 앱과 화이트라벨 모바일 앱에서 쓸 수 있어요.

### 앱 버전은 어떤 것이 필요한가요?
모바일 앱 버전 4.10.0 (810) 이상이 필요해요.
