# 서비스(v2) 리포팅 가이드: 이전 위젯에서 옮기기

서비스 관련 리포트를 한곳에서 볼 수 있는 **서비스 (v2)** 모듈이 새로 생겼어요. 이전 서비스 위젯을 대시보드에 추가해 두었다면 새 위젯으로 바꿔야 해요. 이 문서에서 바꾸는 방법을 안내해요.

{% hint style="info" %}
이 업데이트는 이미 적용되었어요.
{% endhint %}

## 개요

**Reporting Dashboard**(리포팅 대시보드)에 서비스 관련 지표만 모아 보여 주는 **서비스 (v2)** 모듈이 추가되었어요. 이 모듈은 **캘린더**/**미팅** 모듈에 있던 서비스 관련 위젯을 대체해요.

새 모듈은 보라색 아이콘으로 구분할 수 있어요. 예약, 매출, 직원 성과 등을 더 체계적으로 확인할 수 있고, 규모가 커져도 관리하기 편해요.

---

## 서비스 (v2)에서 달라진 점

**서비스 (v2)** 모듈에는 다음과 같은 위젯이 있어요.

- **서비스별 예약 수**
- **서비스 카테고리별 예약 수**
- **서비스 예약으로부터의 총 수익**
- **서비스별 매출**
- **서비스 카테고리별 매출**
- **Average order value (services)**(평균 주문 금액(서비스))
- **Top grossing staff (services)**(매출 상위 직원(서비스))
- **상위 성과 서비스 지점**
- **취소된 서비스 매출**
- **쿠폰 사용**(서비스)
- **Revenue from coupons (services)**(쿠폰 매출(서비스))
- **Top coupon codes (services)**(상위 쿠폰 코드(서비스))

이 위젯으로 서비스별 성과와 매출 추이를 더 자세히 볼 수 있어요.

---

## 이전 설정과 달라진 점

이전에는 **캘린더**/**미팅** 모듈에 서비스 관련 위젯이 두 개 있었어요.

- **서비스별 예약 수**
- **서비스 카테고리별 예약 수**

일반 캘린더 아이콘으로 표시되던 이 위젯들은 **서비스 (v2)** 로 옮겨졌어요. 업데이트 이후에는 지금 형태로 더 이상 작동하지 않아요.

## 조치 필요

이전 서비스 위젯을 대시보드에 추가해 두었다면 새 위젯으로 바꿔야 해요.

### 위젯 바꾸는 순서

1. **Reporting Dashboard**로 이동해요.
2. 아래 위젯을 찾아 삭제해요.
   - **서비스별 예약 수** (이전)
   - **서비스 카테고리별 예약 수** (이전)
3. **Add Widget**(위젯 추가)을 클릭해요.
4. **서비스 (v2)** 모듈(보라색 아이콘 섹션)로 이동해요.
5. 필요한 새 위젯을 추가해요.
6. 대시보드를 저장해요.

---

## 중요 안내

{% hint style="warning" %}
- 이전 위젯은 업데이트 이후 데이터 표시가 중단돼요.
- 기존 데이터는 영향을 받지 않아요.
- 서비스 관련 리포트를 계속 보려면 새 **서비스 (v2)** 위젯을 사용해야 해요.
{% endhint %}
