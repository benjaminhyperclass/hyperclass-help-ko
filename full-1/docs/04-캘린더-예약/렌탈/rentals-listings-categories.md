# 대여 리스팅과 카테고리 알아보기

**대여**(Rentals)에서 쓰는 리스팅과 카테고리가 무엇인지, 대여 화면은 어디서 여는지, 둘을 어떻게 함께 써서 대여 상품을 정리하는지 설명해요.

## 리스팅과 카테고리란?

리스팅은 대여로 제공하는 개별 상품을 말해요. 부동산, 차량, 객실, 장비 등이 해당돼요. 리스팅마다 이미지, 설명, 가격, 재고(선택), 상태가 들어 있어요. 대여 설정은 리스팅을 바탕으로 이루어져요.

카테고리는 비슷한 리스팅을 묶어 두는 그룹이에요. 내부 사용자와 고객 모두 리스팅을 더 쉽게 찾을 수 있어요.

예시:

- 부동산 관리 업체라면 비치 하우스, 도심 로프트, 산장 같은 카테고리를 만들 수 있어요.
- 장비 대여 업체라면 카메라, 조명 장비 같은 카테고리로 장비별 리스팅을 정리할 수 있어요.

---

## 리스팅과 카테고리를 쓰면 좋은 점

- 정리: 대여 리스팅이 많아도 카테고리로 쉽게 찾고 관리할 수 있어요.
- 고객에게 보이는 구성 관리: 카테고리 순서를 바꾸면 다른 설정은 건드리지 않아도 예약 페이지의 그룹과 순서가 바뀌어요.
- 간편한 공유: 리스팅이나 카테고리의 공유 링크를 보내면 고객을 원하는 화면으로 바로 안내할 수 있어요. 고객이 더 빨리 결정하고 문의도 줄어요.
- 맞춤 설정: 가격, 예약 설정, 캘린더 동기화 같은 세부 구성을 설정할 수 있어요.

## 리스팅 화면 살펴보기

리스팅 화면에서는 모든 대여 리스팅과 세부 정보를 한눈에 볼 수 있어요.

#### 리스팅 목록

- **이미지**: 리스팅의 썸네일이 표시돼요.
- **이름**: 리스팅 제목이에요.
- **상태**: 활성 또는 비활성으로 표시돼요.
- **Base Price**(기본 가격): 시간, 일, 주, 월 단위의 대여 가격이 표시돼요.
- **재고**: 사용 가능한 수량이에요.
- **작업**: 리스팅을 편집, 중복, 공유, 삭제할 수 있어요.

![리스팅 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487135/original/DxaSA9sKi0wSLYBlTPK8h2_45ui-aoGx7A.png?1761055859)

#### 도구 모음

- **Search Bar**(검색창): 이름이나 키워드로 리스팅을 빠르게 찾아요.
- **Sort by**(정렬 기준) 드롭다운: 이름 기준으로 오름차순 또는 내림차순 정렬해요.

![검색창과 정렬 기준 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487165/original/r633n8KLcFwQr5qJD2tnpv3llKvpFR-7MQ.png?1761055896)

#### 카테고리 패널

- 화면 왼쪽에 있으며, 만들어 둔 모든 카테고리가 표시돼요.
- 카테고리를 선택하면 해당 그룹의 리스팅만 걸러서 볼 수 있어요.
- 각 카테고리 옆의 **⋮** 메뉴에서 카테고리를 **편집**, **공유**, **삭제**할 수 있어요.

{% hint style="info" %}
왼쪽에서 카테고리 순서를 바꾸면 고객용 예약 페이지의 순서도 함께 바뀌어요.
{% endhint %}

![왼쪽 카테고리 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487240/original/Mhov4eOv9CvshH-B0RZJIwGiC0Dbxtf0nw.png?1761055928)

#### 행별 작업

- **편집**: 리스팅 편집 화면을 열어 설정을 수정해요.
- **중복**: 리스팅을 복제해 기존 설정을 그대로 다시 쓸 수 있어요.
- **공유**: 해당 리스팅의 공개 예약 URL을 복사해요.
- **삭제**: 리스팅을 영구적으로 삭제해요.

![리스팅 행별 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487372/original/FlT-xRB29EzvGZfA2KZxDnI5_zgB1xFiOg.png?1761056003)

## 새 카테고리 만들기

만든 카테고리는 사이드바에 표시돼서 빠르게 이동할 수 있고, 카테고리 하나에 여러 리스팅을 담을 수 있어요.

{% hint style="info" %}
카테고리 이름은 짧고 분명하게 지으면 화면이 깔끔해요. 예: 고급 차량, 경제형 차량
{% endhint %}

1. **대여 > 리스팅**으로 이동하세요.

   ![대여 아래의 리스팅 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487452/original/YHPTOA9pKNXeVtkA4TqF4CSyXopk2bHsog.jpeg?1761056062)
2. 카테고리 패널 아래의 **+ 새 카테고리**를 클릭하세요.

   ![카테고리 패널의 새 카테고리 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487518/original/Z7K5zP8lvbPuNmKSgeZoRUNg7gvX1nHJnw.png?1761056088)
3. **Add New Category**(새 카테고리 추가) 창에서 **Category Name**(카테고리 이름)을 입력하세요. 필수 항목이에요. **Custom URL Slug**(사용자 지정 URL 슬러그)도 입력하세요. 이 값이 공유 링크의 일부가 돼요.

   ![새 카테고리 추가 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487614/original/JV8KLvcCXSwqTL3vpBWapRlrThoBs39bBQ.png?1761056147)
4. **카테고리 만들기**를 클릭하세요.

   ![카테고리 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487673/original/s2Mc3vnTNSZvNSGz1o7HFj6pZDchaNzMnQ.png?1761056170)

## 카테고리 관리와 공유

#### 카테고리 편집

1. 카테고리 이름 옆의 **⋮** 메뉴를 클릭한 뒤 **편집**을 선택하세요.

   ![카테고리 ⋮ 메뉴의 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487908/original/CXjnUrumMvwhjItBj2RjorBVjMaIKbL6yg.png?1761056315)
2. 카테고리 이름이나 슬러그를 수정하고 변경 내용을 저장하세요.

   ![카테고리 이름과 슬러그 수정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056487985/original/tyLR4jFlNQUFyz0fIs5pp8L28mimWxOmhA.png?1761056347)

#### 카테고리 공유

- **Share Category**(카테고리 공유)를 사용하면 해당 카테고리의 리스팅만 보여 주는 공개 예약 링크를 공유할 수 있어요.

  ![카테고리 공유 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056488859/original/IhpHMRdkbvPW7GCy_a5qhIbyLGjNAe_kQg.png?1761056731)

#### 카테고리 삭제

- **⋮**를 클릭한 뒤 **삭제**를 선택하세요.
- 카테고리를 삭제하면 그 카테고리에 속해 있던 리스팅은 기본 카테고리로 연결돼요.

  ![카테고리 ⋮ 메뉴의 삭제](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056488929/original/ohpTqp667rObEtSTNgksOt-bJGn6dGhs2A.png?1761056792)

#### 카테고리 순서 바꾸기

- 왼쪽 패널에서 카테고리를 끌어서 놓으면 순서가 바뀌어요. 이 순서는 고객이 예약 페이지에서 보는 순서와 같아요.

  ![카테고리를 끌어서 순서 바꾸기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056489089/original/dtnXS4Qrmco6nBqunk_SDxjm9V6Ir_gP8A.png?1761056872)

## 카테고리가 리스팅에 미치는 영향

- 리스팅은 반드시 카테고리 하나에 속해야 해요. 카테고리를 따로 지정하지 않으면 **Default Category**(기본 카테고리)에 들어가요.
- 카테고리 순서에 따라 공개 화면에서 리스팅이 표시되는 순서가 정해져요.

---

## 자주 묻는 질문

### 리스팅 하나를 여러 카테고리에 넣을 수 있나요?
아니요. 리스팅은 카테고리 하나에만 지정할 수 있어요.

### 카테고리 페이지를 공개로 공유할 수 있나요?
네. **Share Category**를 사용하면 해당 그룹의 예약 링크를 바로 복사할 수 있어요.

### 카테고리를 삭제하면 어떻게 되나요?
카테고리를 삭제하면 그 카테고리에 속해 있던 리스팅은 기본 카테고리로 연결돼요.

### 카테고리는 몇 개까지 만들 수 있나요?
계정당 최대 50개까지 만들 수 있어요.

### 카테고리가 가격이나 캘린더 가용성에도 영향을 주나요?
아니요. 가격과 가용성은 리스팅이나 변형 단위로 설정해요.
