# 대여 예약 개요 — 예약 목록 보기

**대여**의 **예약**에서 쓰는 예약 목록 보기를 설명해요. 예약된 리스팅을 한곳에서 확인하고, 각 리스팅의 상태와 결제를 관리할 수 있어요. 시간대가 표시 시간에 미치는 영향, 필터·정렬·빠른 작업을 쓰는 방법도 함께 다뤄요.

## 예약 목록 보기란?

예약 목록 보기에서는 예약된 모든 대여 리스팅을 한눈에 볼 수 있어요. 목록의 각 행은 예약 전체가 아니라 예약에 포함된 **리스팅 하나**를 뜻해요.

한 예약에 리스팅이 세 개 들어 있으면, 예약 표에 리스팅별로 행이 세 개 생겨요. 덕분에 리스팅마다 시간, 결제, 완료 여부를 따로 확인할 수 있어요.

## 예약 목록 보기의 주요 이점

- 변형과 재고를 지원하는 맞춤 리스팅: 대여 상품마다 리스팅을 만들고, 대여 기간, 수량, 가격, 변형(예: 사이즈, 장비 유형)을 정할 수 있어요.
- 시간·일·주·월 단위 대여 지원: 시간, 일, 주, 월 단위로 요금이 부과되도록 예약을 설정할 수 있어요. 유연한 대여 방식이 필요한 비즈니스에 알맞아요.
- 재고 추적과 가용 수량 관리: 단일 상품이든 대량 재고든, 특정 시점에 리스팅별로 몇 개를 빌릴 수 있는지 관리할 수 있어요.
- 유연한 가격 모델: 고정 기간/유동 기간 가격, 시즌별 가격, 기간과 수량에 따른 단계별 할인, 보증금 옵션 등을 지원해요.
- 복수 상품 예약: 고객이 한 번의 결제로 리스팅을 두 개 이상 예약할 수 있어요. 이벤트, 콤보, 묶음 대여 상품에 잘 맞아요.
- 내장 결제 및 인보이스: 예약 과정에서 바로 결제를 받고, 예약마다 인보이스를 자동으로 만들 수 있어요. 보증금도 비즈니스에 맞게 설정할 수 있어요.
- 고객용 예약 페이지: 리스팅, 카테고리, 가격, 이용 가능 현황을 실시간으로 보여 주는 공개 예약 페이지를 고객에게 제공해 간편한 예약 경험을 줄 수 있어요.

## 예약 표 살펴보기

예약 표에는 모든 고객과 예약에서 예약된 리스팅이 전부 표시돼요. 진행 중인 대여, 예정된 대여, 완료된 대여를 자세히 나눠서 볼 수 있어요.

#### 열 설명

- **#**: 참고용 일련번호예요.
- **연락처**: 예약에 연결된 고객 이름과 이메일 주소예요.
- **목록**: 예약된 리스팅의 이름이에요. 리스팅이 여러 개인 예약은 리스팅마다 행이 따로 표시돼요.
- **시작 시간** / **종료 시간**: 해당 리스팅의 대여 기간이에요.
- **상태**: 해당 리스팅의 현재 예약 상태예요.

  - **미확인**: 예약은 접수됐지만 아직 확인되지 않았어요.
  - **예약됨**: 확인되어 일정이 잡혔지만 아직 시작되지 않았어요.
  - **활성**: 현재 진행 중이에요.
  - **완료**: 성공적으로 끝났어요.
  - **취소됨**: 예약이 취소됐어요.
- **결제 상태**: 해당 리스팅 항목의 결제 상태예요.

  - **대기 중**: 아직 결제를 받지 못했어요.
  - **유료**: 결제가 전액 수금됐어요.

{% hint style="info" %}
예약 전체 기준으로는 일부 리스팅만 결제된 경우 결제 상태가 **부분 결제됨**으로 표시될 수 있어요.
{% endhint %}

#### 작업

빠르게 쓸 수 있는 아이콘이에요.

- **보기**: 모든 리스팅과 관련 정보가 담긴 **예약 전체**를 열어요.
- **편집**: 리스팅을 추가·수정하고 결제와 메모를 관리할 수 있는 예약 편집 화면을 열어요.

{% hint style="warning" %}
각 리스팅이 별도의 행으로 보여도 **보기**나 **편집**을 클릭하면, 연결된 모든 리스팅, 결제, 메모를 포함한 예약 전체가 열려요.
{% endhint %}

## 툴바와 필터

툴바에서 예약을 정리하고 빠르게 찾을 수 있어요.

#### 1. 필터 탭

- **예정**: 앞으로 일정이 잡힌 예약을 보여 줘요.
- **활성**: 현재 진행 중인 대여를 보여 줘요.
- **완료**: 끝난 예약을 보여 줘요.
- **전체**: 상태와 관계없이 모든 예약을 보여 줘요.

#### 2. 상세 필터

**상세 필터**로 다음 기준을 설정해 목록을 좁혀 보세요.

- 상태(미확인, 예약됨, 활성, 완료, 취소됨)
- 결제 상태(유료, 대기 중)
- 등록 정보 이름 또는 카테고리
- 기간(시작 시간, 종료 시간)
- 고객 이름 또는 이메일

#### 3. 정렬

다음 기준으로 예약을 정렬할 수 있어요.

- **시작 시간**
- **종료 시간**
- **추가일**

#### 4. 검색

**등록 정보 이름** 또는 **고객 이름**으로 예약을 빠르게 찾을 수 있어요.

#### 5. 열 관리

**열 관리**에서 표의 열을 표시하거나 숨기고, 순서를 바꿔 원하는 대로 구성할 수 있어요.

{% hint style="info" %}
예약을 만들 때마다 대여 인보이스가 고객에게 자동으로 발송되지는 않아요. 연락처/대화 페이지에 다르게 안내되는 부분은 바로잡는 작업을 진행하고 있어요.
{% endhint %}

## 자주 묻는 질문

### 예약 하나인데 왜 행이 여러 개로 보이나요?

각 행은 예약에 포함된 리스팅 하나를 뜻해요. 리스팅이 여러 개인 예약은 행도 여러 개 생겨요.

### 예약의 "부분 결제됨"은 무슨 뜻인가요?

그 예약에 포함된 리스팅 중 일부는 **유료**이고, 나머지는 **대기 중**이라는 뜻이에요.

### 행에서 바로 예약을 편집할 수 있나요?

네. **작업**에서 **보기** 또는 **편집**을 클릭하면, 모든 리스팅, 결제, 메모가 담긴 예약 전체가 열려요.

### 취소나 일정 변경은 목록에 어떻게 표시되나요?

취소된 리스팅은 **상태**에 **취소됨**으로 표시되고, **전체** 탭에서 계속 볼 수 있어요. 일정을 변경하면 **시작 시간**과 **종료 시간**이 바뀌어요.
