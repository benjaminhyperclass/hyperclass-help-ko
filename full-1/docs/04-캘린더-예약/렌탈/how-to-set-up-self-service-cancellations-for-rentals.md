# 대여 예약, 고객이 직접 취소하도록 설정하기

고객이 취소 링크로 예정된 대여 예약을 직접 취소하게 할 수 있어요. 환불, 결제, 보증금 처리는 운영자가 그대로 결정해요. 이 문서에서는 셀프 취소가 어떻게 동작하는지, 링크 만료 시점은 어떻게 정하는지, 취소 후 결제와 보증금은 어떻게 되는지 알려 드려요.

## 배우게 될 내용

하이퍼클래스 대여에서는 고객에게 셀프 취소 링크를 줄 수 있어요. 고객은 팀에 먼저 연락하지 않고도 예정된 예약을 취소할 수 있어요. 예약 시작 시간에 얼마나 가까울 때까지 이 링크를 쓰게 할지도 정할 수 있어요.

이 문서에서 다루는 내용은 다음과 같아요.

- 셀프 취소의 동작 방식
- 취소 링크 만료 시점(선택 사항) 설정
- 고객이 취소를 완료하는 과정
- 여러 리스팅이 포함된 예약의 처리
- 예약 취소 후 결제와 보증금 처리

## 셀프 취소는 이렇게 동작해요

고객은 예약에 연결된 취소 링크에서 예정된 대여 예약을 직접 취소할 수 있어요. 전화나 이메일로 요청하거나 팀이 처리해 주기를 기다릴 필요가 없어요. 링크를 열어 예약을 확인하고 바로 취소하면 돼요.

승인 단계는 없어요. 고객이 취소를 마치면 예약이 취소되고, 잡혀 있던 예약 가능 시간도 다시 풀려요. 고객은 더 빠르게 취소할 수 있고, 팀은 일상적인 취소 요청을 직접 처리하는 일이 줄어요.

{% hint style="info" %}
**기본 취소 흐름에는 추가 설정이 필요 없어요.**
셀프 취소는 취소 가능한 예정된 대여 예약에서 쓸 수 있어요. 링크 만료 시점을 정하거나 링크를 직접 만든 안내 메시지에 넣고 싶을 때만 추가 설정이 필요해요.
{% endhint %}

{% hint style="warning" %}
**취소해도 환불이 자동으로 진행되지 않아요.**
셀프 취소는 예약만 취소해요. 환불 결정, 결제 처리, 보증금 처리는 운영자가 직접 해요.
{% endhint %}

## 취소 가능 기간 설정하기

기본적으로 고객은 예약이 시작되기 전이면 언제든 취소 링크를 쓸 수 있어요. 더 일찍 셀프 취소를 막고 싶다면 취소 마감 시점을 켜 두세요. 직전 취소는 팀이 직접 관리하고, 그보다 이른 요청은 고객이 직접 처리하게 할 수 있어요.

1. **캘린더 > 대여 > 글로벌 설정**으로 이동한 다음 **예약 설정**을 열어요.
2. **취소 링크 만료 설정**을 켜요. 예약 시작 시간에 너무 가까워지면 고객이 셀프 취소 링크를 쓰지 못해요.
3. 예약 시작 몇 분 전, 몇 시간 전, 며칠 전에 링크가 만료될지 입력해요. 단위는 **분, 시간, 일** 중에서 고를 수 있어요. 예를 들어 3시간으로 설정하면 고객은 예약 시작 3시간 전까지 직접 취소할 수 있어요.
4. **변경사항 저장**을 선택해 대여 예약에 취소 링크 만료 설정을 적용해요.

![대여 글로벌 설정의 예약 설정에서 취소 링크 만료 설정을 켠 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080994737/original/NacceeTaC4UugxQb4WXU3IbpVXj9NqJfrA.png?1789485724)

{% hint style="info" %}
**이 설정을 꺼 두면 어떻게 되나요?**
고객은 예약이 시작될 때까지 셀프 취소 링크를 계속 쓸 수 있어요. 예약이 시작된 뒤에는 셀프 취소를 쓸 수 없어요.
{% endhint %}

## 고객 안내 메시지에 취소 링크 넣기

취소 링크를 쓰면 고객이 자기 예약의 셀프 취소 페이지로 바로 들어갈 수 있어요. 지원되는 고객 알림이나 확인 화면을 꾸밀 때 대여 취소 링크 **커스텀 값**을 원하는 위치에 넣을 수 있어요.

**취소 링크 커스텀 값**

대여 취소 링크는 다음 값을 사용해요.

`{{rentalBooking.cancellation_link}}`

고객이 취소 페이지로 바로 들어가길 원하는 곳에 이 커스텀 값을 넣으세요. 예를 들어 예약 확인 메시지나 리마인더 메시지에 넣을 수 있어요. 해당 예약에 대한 메시지가 발송되면 하이퍼클래스가 이 값을 그 예약의 취소 링크로 바꿔 줘요.

{% hint style="info" %}
**링크의 용도를 분명하게 알려 주세요.**
메시지에 링크를 넣을 때는 "예약 취소하기"처럼 분명한 문구를 쓰세요. 그래야 고객이 예약 관리 페이지가 아니라 예약을 취소하는 링크라는 것을 알 수 있어요.
{% endhint %}

{% hint style="info" %}
**고객 셀프 서비스**
고객이 예약 취소는 직접 처리하고, 환불·결제 조정·보증금 결정은 팀이 계속 맡을 수 있어요. 금전 관련 결정은 자동으로 처리되지 않아요.
{% endhint %}

## 고객이 취소할 때 보는 화면

고객이 유효한 취소 링크를 열면 고객용 취소 페이지가 나타나요. 이 페이지에는 예약 정보가 표시돼요. 고객은 취소하려는 예약이 맞는지 확인한 뒤 진행해요.

1. 고객이 페이지에 표시된 리스팅 정보, 예약 날짜, 그 밖의 예약 세부 정보를 확인해요.
2. 필요하면 취소 이유를 적어요. **취소 사유** 필드에 취소하는 이유를 적을 수 있어요. 이 필드는 선택 사항이라 비워 두고 진행해도 돼요.
3. **예약 취소**를 선택해 셀프 취소를 완료해요.

![고객용 취소 페이지에서 취소 사유를 입력하고 예약 취소를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080994936/original/tYRlkDrWaUbbsJo0QevpPe3Wn35sFcFVKw.png?1789485839)

{% hint style="info" %}
**취소 사유는 왜 받나요?**
필수는 아니지만 사유가 있으면 고객에게 따로 연락하지 않고도 취소 배경을 파악하는 데 도움이 돼요.
{% endhint %}

## 여러 리스팅이 포함된 예약은 어떻게 처리하나요?

대여 예약 하나에 리스팅이 여러 개 포함될 수 있어요. 고객이 여러 리스팅이 포함된 예약의 취소 페이지를 열면 **예약 세부 정보** 영역에 그 예약에 속한 리스팅이 표시돼요. 각 항목의 날짜도 함께 보여요.

셀프 취소는 예약 전체에 적용돼요. 고객이 리스팅 하나만 빼고 나머지는 유지할 수는 없어요. **예약 취소**를 선택하면 예약이 통째로 취소돼요.

{% hint style="warning" %}
**여러 리스팅 예약은 전부 취소되거나 전부 유지돼요.**
셀프 취소는 선택한 리스팅 하나가 아니라 예약 전체에 적용돼요. 고객은 진행하기 전에 **예약 세부 정보**에 표시된 리스팅을 모두 확인해야 해요.
{% endhint %}

## 취소 후에는 어떻게 되나요?

고객이 취소를 마치면 예약이 취소되고 확인 페이지가 나타나요. 요청이 제대로 처리됐는지, 예약이 아직 유효한지 헷갈리지 않도록 고객이 바로 확인할 수 있어요.

![예약 취소 완료 후 고객에게 보이는 확인 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080995195/original/HBRlM0CByYe_BPVtXrg03CfvQMktul9nzw.png?1789485928)

취소된 예약은 더 이상 대여 가능 시간을 차지하지 않아요. 이후 팀이 예약을 검토하고, 비즈니스와 취소 정책에 맞는 금전 관련 조치를 따로 진행하면 돼요.

{% hint style="warning" %}
**예약 취소와 금전 처리는 별개예요.**
예약을 취소해도 돈을 돌려줄지는 자동으로 정해지지 않아요. 환불 금액, 결제 변경, 보증금 결정은 운영자가 직접 해요.
{% endhint %}

예를 들어 예약을 얼마나 일찍 취소했는지에 따라 취소 정책이 다를 수 있어요. 셀프 취소로 고객은 예약을 풀 수 있고, 팀은 환불 관련 조치를 하기 전에 비즈니스의 금전 정책을 적용할 수 있어요.

## 만료된 링크와 이미 사용한 링크

취소 링크는 예약이 아직 셀프 취소 대상일 때만 쓸 수 있어요. 예약이 이미 취소되었거나, 설정한 취소 가능 기간이 지났거나, 예약이 이미 시작되었거나 끝났다면 그 링크로 다시 취소할 수 없어요.

고객이 더 이상 취소할 수 없는 링크를 열면, 하이퍼클래스는 기술적인 오류 대신 알기 쉬운 안내 메시지를 보여 줘요. 고객은 이 링크로는 취소를 완료할 수 없다는 것을 이해할 수 있어요.

{% hint style="info" %}
**셀프 취소는 취소 가능한 예정된 예약에만 쓸 수 있어요.**
예약이 시작되었거나 완료된 뒤, 또는 설정한 취소 마감 시점이 지난 뒤에는 고객이 추가 도움이 필요하면 비즈니스에 직접 연락해야 해요.
{% endhint %}

## 자주 묻는 질문

### 고객이 취소하려면 취소 링크 만료 설정을 꼭 켜야 하나요?
아니요. 만료 설정은 선택 사항이에요. 꺼 두면 취소할 수 있는 고객은 예약이 시작될 때까지 취소 링크를 쓸 수 있어요.

### 예약 직전에는 고객이 취소하지 못하게 하려면 어떻게 하나요?
**글로벌 설정**의 **예약 설정**에서 **취소 링크 만료 설정**을 켜세요. 예약 시작 몇 분 전, 몇 시간 전, 며칠 전까지 취소를 허용할지 정할 수 있어요.

### 취소 사유는 꼭 입력해야 하나요?
아니요. 고객이 원하면 취소 이유를 적을 수 있지만, 입력하지 않아도 취소를 완료할 수 있어요.

### 고객이 취소하면 자동으로 환불되나요?
아니요. 셀프 취소는 예약만 취소해요. 환불과 결제 처리는 별도로, 비즈니스 절차에 맞게 직접 해야 해요.

### 고객이 취소하면 보증금은 어떻게 되나요?
셀프 취소는 보증금을 어떻게 처리할지 자동으로 정하지 않아요. 보증금 처리는 운영자가 직접 해야 해요.

### 여러 리스팅이 포함된 예약에서 리스팅 하나만 취소할 수 있나요?
아니요. 셀프 취소는 예약 전체에 적용돼요. 그 예약에 포함된 모든 리스팅이 함께 처리돼요.

### 예약이 시작된 뒤에도 고객이 취소할 수 있나요?
아니요. 셀프 취소는 예약이 시작되기 전에만 쓸 수 있어요. 예약이 진행 중이거나 끝난 뒤에는 취소 링크로 취소할 수 없어요.

### 대여 취소 링크에는 어떤 커스텀 값을 쓰나요?
지원되는 고객 메시지에 예약별 취소 링크를 넣을 때는 `{{rentalBooking.cancellation_link}}`를 사용하세요.
