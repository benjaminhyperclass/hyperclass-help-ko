# 캘린더에서 커스텀 값 사용하기

**캘린더** 설정에서 커스텀 값을 바로 쓸 수 있어요. 머지 필드로 미팅 링크, 영업 담당자 이름, 내부 메모 같은 내 데이터를 예약 정보와 알림에 넣어 보세요.

## 새로 추가된 기능

이제 아래 메뉴의 머지 필드 선택 창에서 커스텀 값을 쓸 수 있어요.

- **캘린더**
- **서비스**
- **대여**

머지 필드를 추가하면 선택 창에 **커스텀 값** 섹션이 보여요. 여기서 내 데이터를 쉽게 넣을 수 있어요.

## 커스텀 값을 쓸 수 있는 곳

머지 필드를 지원하는 캘린더 필드라면 어디서든 커스텀 값을 쓸 수 있어요. 예를 들면 다음과 같아요.

- **예약 제목**
- **미팅 장소**(사용자 지정)
- **이메일 알림**
- SMS 알림
- 예약으로 시작되는 워크플로우 메시지

예약 후 화면에서는 배정된 사용자 값도 쓸 수 있어요.

- 캘린더 확인 페이지의 **감사 메시지**
- 캘린더 예약 뒤에 이어지는 퍼널 단계 (캘린더 요소의 리디렉션 동작을 **Go to next step**(다음 단계로 이동)으로 설정한 경우)

배정된 사용자 값은 연락처나 예약에 연결된 사용자의 정보로 채워져요. 예약이 끝난 뒤 배정된 사용자의 이름, 이메일, 전화번호 등 지원되는 정보를 보여 줄 수 있어요.

## 시작하기 전에

먼저 커스텀 값을 만들어 두세요.

1. **설정 > 커스텀 값**으로 이동하세요.
2. **New Custom Value**(새 커스텀 값 추가)를 클릭하세요.
3. 이름과 값을 입력하세요.
4. **저장**을 클릭하세요.

이제 만든 커스텀 값이 머지 필드 선택 창에 나타나요.

## 캘린더에서 커스텀 값 사용하기

1. **캘린더**로 이동하세요.
2. 기존 캘린더를 열거나 새 캘린더를 만드세요.
3. **캘린더 설정**으로 이동하세요.
4. 텍스트 필드를 클릭하세요. 예를 들어 **예약 제목**이나 알림 입력란이 있어요.
5. **{ }** 머지 필드 아이콘을 클릭하세요.
6. 선택 창에서 **커스텀 값** 섹션까지 스크롤하세요. 검색창에서 값을 찾아도 돼요.
7. 사용할 커스텀 값을 선택하세요. `{{custom_values.your_key}}` 같은 토큰 형태로 입력돼요.
8. **저장**을 클릭하세요.
9. (권장) **테스트 예약하기**로 값이 제대로 표시되는지 확인하세요.

### 퍼널에서 캘린더 예약 후 배정된 사용자 값 사용하기

퍼널에 캘린더 요소를 넣고 리디렉션 동작을 **Go to next step**(다음 단계로 이동)으로 설정하면, 예약이 끝난 뒤 다음 퍼널 단계에 배정된 사용자 값이 표시돼요.

1. 퍼널 단계에 캘린더 요소를 추가하세요.
2. 캘린더 요소의 리디렉션 동작을 **Go to next step**으로 설정하세요.
3. 다음 퍼널 단계에 배정된 사용자 머지 필드를 추가하세요.
4. 테스트 예약을 진행하세요.
5. 다음 퍼널 단계에 배정된 사용자 값이 채워지는지 확인하세요.

캘린더 확인 페이지의 **감사 메시지**에도 배정된 사용자 값을 넣을 수 있어요.

## 이럴 때 유용해요

캘린더에서 커스텀 값을 쓰면 다음과 같은 점이 좋아요.

- 확인 메시지와 알림을 개인에게 맞게 보낼 수 있어요.
- 예약마다 일관된 메시지를 유지할 수 있어요.
- 복사해서 붙여 넣는 수작업이 줄어요.
- 일정 예약 워크플로우를 더 효율적으로 확장할 수 있어요.

## 자주 묻는 질문

### 이 기능을 쓰려면 따로 설정을 켜야 하나요?
아니요. 이 기능은 기본으로 사용할 수 있어요.

### 워크플로우에서도 커스텀 값을 쓸 수 있나요?
네. 예약 트리거와 연결된 이메일·SMS 액션에서 쓸 수 있어요.

### 커스텀 값을 다른 머지 필드와 함께 쓸 수 있나요?
네. 한 필드에 머지 필드를 여러 개 넣을 수 있어요.

### 커스텀 값을 수정하면 어떻게 되나요?
앞으로 보내는 메시지에는 수정한 값이 쓰여요. 이미 보낸 메시지는 바뀌지 않아요.

### 모바일에서도 커스텀 값을 쓸 수 있나요?
네. 캘린더 관련 필드에서 지원돼요.
