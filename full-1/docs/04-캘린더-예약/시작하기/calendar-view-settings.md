# 캘린더 보기 설정

**Calendar view settings**(캘린더 보기 설정)에서 통합 캘린더에 예약, 직원 일정, 이벤트가 어떻게 보일지 정할 수 있어요. 시간대, 그리드 간격, 이벤트 색상, 표시 옵션을 한 곳에서 바꾸고, 지금 보고 있는 캘린더 화면을 PDF나 CSV로 내보낼 수도 있어요. 이 설정은 캘린더 화면 표시에만 적용돼요. 예약 가능 시간, 일정 규칙, 고객용 예약 페이지는 바뀌지 않아요.

**Calendar view settings**는 두 개의 탭으로 나뉘어 있어요.

- **일반**: 시간대, 그리드 간격, 이벤트 색상, 근무 시간 음영, 빈 행과 열, 버퍼 표시를 관리해요.
- **Staff colors**(직원 색상): 관리자가 모든 사용자에게 적용되는 직원별 색상을 정해요.

---

## 캘린더 보기 설정의 장점

예약 구성을 건드리지 않고도 예약을 관리하고, 직원 일정을 구분하고, 중요한 예약 정보에 집중할 수 있어요.

- 한곳에서 설정: 설정 패널 하나에서 캘린더 표시 방식을 바꿔요.
- 나에게 맞는 시간대: 내가 원하는 시간대로 예약을 봐요.
- 유연한 캘린더 그리드: 15분, 30분, 60분 간격 중에서 골라요.
- 일정 확인이 쉬워짐: 근무하지 않는 시간과 예약 버퍼를 눈에 띄게 표시해요.
- 깔끔한 레이아웃: 일정이 없는 직원이나 리소스의 행과 열을 숨겨요.
- 사용자 지정 이벤트 색상: 직원, 캘린더, 서비스를 빠르게 구분해요.
- 간편한 내보내기: 현재 필터가 적용된 캘린더 화면을 PDF나 CSV로 내보내요.

## 캘린더 표시 설정

**일반** 탭에서 일정 정보가 어떻게 보일지 정할 수 있어요. 각 사용자는 자신의 설정을 저장하며, 다른 팀원에게는 영향을 주지 않아요.

| 설정 | 설명 |
| --- | --- |
| **예약 보기** | 선택한 시간대로 예약을 표시해요. |
| **Default grid interval**(기본 그리드 간격) | 그리드 간격을 15분, 30분, 60분 중에서 골라요. |
| **Color events by**(이벤트 색상 기준) | 캘린더/서비스 색상이나 직원 색상 중 하나를 이벤트의 기본 색상으로 표시해요. |
| **Grey out hours outside working time**(근무 시간 외 시간 회색 처리) | 직원 근무 일정 밖의 시간에 음영을 넣어요. |
| **Hide empty rows and columns**(빈 행과 열 숨기기) | **일간 보기**에서 예정된 이벤트가 없는 직원이나 리소스를 숨겨요. |
| **버퍼 시간 표시** | 설정해 둔 예약 버퍼를 **일간 보기**와 **주간 보기**에 표시해요. |

### 기본 그리드 간격

**Default grid interval**은 **일간 보기**와 **주간 보기**에서 한 시간을 몇 칸으로 나눌지 정해요.

- **15분**: 한 시간에 4행이에요. 세밀하게 일정을 볼 때 좋아요.
- **30분**: 한 시간에 2행이에요.
- **60 minutes**(60분): 한 시간에 1행이에요. 간단하게 훑어볼 때 좋아요.

그리드 간격을 바꿔도 예약 시간이나 예약 규칙은 바뀌지 않아요.

### 근무 시간 외 시간 회색 처리

**Grey out hours outside working time**을 켜면 직원이 근무하지 않는 시간에 음영이 들어가요. 근무 가능한 시간대를 한눈에 확인할 수 있어요. 하이퍼클래스는 직원의 캘린더에 연결된 활성 일정과, 적용되는 활성 사용자 지정 일정을 합쳐서 계산해요.

예를 들어 한 일정이 오전 9시~오후 1시이고 다른 일정이 오후 12시~5시라면, 합친 근무 시간은 오전 9시~오후 5시예요.

지원하는 보기는 다음과 같아요.

- **일간 보기**: 직원을 한 명 또는 여러 명 선택했을 때 사용할 수 있어요.
- **주간 보기**: 직원을 한 명만 선택했을 때 사용할 수 있어요.
- 필터 조건: **사용자** 필터(직원)를 사용할 때 쓸 수 있어요.

캘린더에 지정되지 않은 일정은 이 계산에서 비활성으로 봐요. 단, 적용되는 사용자 지정 일정으로 활성화되어 있으면 포함돼요.

{% hint style="info" %}
음영은 화면 표시용이에요. 예약 가능 시간은 바뀌지 않아요.
{% endhint %}

### 빈 행과 열 숨기기

**Hide empty rows and columns**를 켜면 일정이 없는 직원이나 리소스의 행과 열이 사라져서, 필요한 예약에 집중할 수 있어요.

- **일간 보기**에서만 작동해요.
- 예정된 이벤트가 없는 직원과 대여 리스팅을 숨겨요.
- 연결된 캘린더의 예약, 차단된 시간, 바쁨 이벤트도 일정으로 보고 계산해요.
- 숨겨진 행이나 열도 다른 날짜에 이벤트가 있으면 그 날짜에는 자동으로 표시돼요.

선택한 직원 중 예정된 일정이 있는 사람이 없으면 모든 열이 숨겨질 수 있어요.

### 버퍼 시간 표시

**버퍼 시간 표시**를 켜면 직원 예약의 앞뒤로 확보해 둔 시간이 **일간 보기**와 **주간 보기**에 표시돼요. 이 옵션을 켜고 끄는 것은 버퍼 블록이 보이는지만 바꿔요. 설정해 둔 버퍼나 예약 가능 시간은 바뀌지 않아요.

버퍼 시간을 설정하려면 [사전 및 사후 버퍼](../캘린더-만들기/pre-and-post-buffers.md) 문서를 참고하세요.

![캘린더 보기 설정의 버퍼 시간 표시 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084911464/original/F1NLhRCf9a3z-Xmu4WxwoX4vXADblmWhYQ.png?1793782720)

## 시간대 설정

**예약 보기** 설정을 쓰면 고객의 예약 방식에는 영향을 주지 않고, 내가 원하는 시간대로 예약을 볼 수 있어요. 선택할 수 있는 항목은 다음과 같아요.

- **추천 시간대**
- **비즈니스 시간대**
- **모든 시간대**

**비즈니스 시간대**를 선택하면 비즈니스 시간대가 바뀌어도 내 보기 시간대가 자동으로 맞춰져요. 선택한 시간대는 하이퍼클래스에서 지원하는 화면의 예약 시간과 예약 관련 이메일에 적용돼요.

{% hint style="warning" %}
**중요:** 시간대 설정은 사용자별 설정이에요. 예약 가능 시간, 다른 팀원, 고객 예약에는 영향을 주지 않아요.
{% endhint %}

이 설정은 예전에 **Meetings Preferences**(미팅 환경설정)와 서비스·대여의 **글로벌 설정**에 있었어요. 기존에 저장해 둔 시간대 설정은 **Calendar view settings**로 자동으로 옮겨져요.

자세한 내용은 [사용자 시간대로 캘린더와 예약 보기](../캘린더-만들기/view-calendar-appointments-in-user-timezone.md) 문서를 참고하세요.

## 직원 색상과 이벤트 색상 표시

직원 색상과 이벤트 색상을 쓰면 예약을 열어 보지 않고도 누구의 예약인지 알 수 있어요. 사용자는 예약 타일에 색상이 어떻게 보일지 정하고, 관리자는 직원별 색상을 지정해요.

### 이벤트 색상 기준

각 예약 타일에는 기본 배경색과 왼쪽의 더 넓은 색상 띠가 표시돼요.

| 설정값 | 타일 기본 색상 | 왼쪽 색상 띠 |
| --- | --- | --- |
| **Calendar/Service colors**(캘린더/서비스 색상) | 캘린더 또는 서비스 색상 | 직원 색상 |
| **Staff colors**(직원 색상) | 직원 색상 | 캘린더 또는 서비스 색상 |

캘린더 상황에 따라 항목 이름이 캘린더 색상 또는 서비스 색상으로 표시될 수 있어요.

{% hint style="info" %}
대여 예약은 이 설정과 상관없이 상태별 색상을 그대로 유지해요.
{% endhint %}

### 직원 색상 지정하기 (관리자만 쓸 수 있어요)

관리자는 직원마다 색상을 지정해서 그 직원의 예약을 쉽게 알아볼 수 있게 해요.

1. **Calendar view settings**를 열어요.
2. **Staff colors** 탭을 선택해요.
3. 직원을 검색하거나 목록을 스크롤해서 찾아요.
4. 색상 견본을 클릭하고, 색상 선택기, 프리셋, HEX 값 중 하나로 색상을 골라요.
5. **변경사항 저장**을 클릭해요.

관리자가 지정한 직원 색상은 모든 사용자에게 적용돼요.

## 캘린더 보기를 PDF 또는 CSV로 내보내기

캘린더를 내보내면 일정을 공유하거나 하이퍼클래스 밖에서 예약 데이터를 활용할 수 있어요. 두 형식 모두 현재 적용된 필터와 선택한 날짜 범위가 그대로 반영돼요.

### PDF로 내보내기

PDF는 현재 캘린더 화면을 그림처럼 보여 줘요.

1. **캘린더 > 캘린더 보기**로 이동해요.
2. 원하는 날짜 범위와 필터를 선택해요.
3. **Manage view**(보기 관리) 옆의 **더 보기**(⋮)를 클릭해요.
4. **Export to PDF**(PDF로 내보내기)를 선택해요.

   ![더 보기 메뉴에서 PDF로 내보내기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084910750/original/67y1nhcWkI7U-4lR7NSlRfj-pnMtaEdcwQ.png?1793782393)

{% hint style="info" %}
**일간 보기**에서 PDF로 내보낼 때는 가독성을 위해 리소스를 최대 7개까지만 선택할 수 있어요.
{% endhint %}

### CSV로 내보내기

CSV는 스프레드시트나 외부 분석에 쓸 수 있는 예약 정보를 제공해요.

1. **캘린더 > 캘린더 보기**를 열어요.
2. 원하는 날짜 범위와 필터를 적용해요.
3. **더 보기**(⋮)를 클릭해요.
4. **Export to CSV**(CSV로 내보내기)를 선택해요.

{% hint style="warning" %}
**중요:**

- CSV에는 예약이 포함되지만 차단된 시간대는 포함되지 않아요.
- 현재 보기에 예약이 없으면 **Export to CSV**를 쓸 수 없어요.
- 두 형식 모두 현재 보기에 적용된 필터와 날짜 범위가 반영돼요.
{% endhint %}

## 캘린더 보기 설정 방법

표시 설정을 저장해 두면 **캘린더 보기**로 돌아올 때마다 같은 레이아웃으로 볼 수 있어요. 이 설정은 사용자마다 따로 적용돼요. 관리자가 지정하는 직원 색상만 모든 사용자에게 적용돼요.

1. **캘린더 > 캘린더 보기**로 이동해요.
2. **Manage view** 옆의 **더 보기**(⋮)를 클릭해요.
3. **Calendar view settings**를 선택해요.

   ![더 보기 메뉴에서 캘린더 보기 설정 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084910186/original/vDJnSf-288JCoQyfOGwVyBqd9W3hTdGLbA.png?1793782120)
4. **일반** 탭에서 시간대와 그리드 간격을 골라요.

   ![일반 탭에서 시간대와 그리드 간격 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084910236/original/9znuFpyabblE2agk8mL1stM_tdHVXmsnBg.png?1793782144)
5. 이벤트 색상을 어떻게 표시할지 선택해요.

   ![이벤트 색상 표시 방식 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084911029/original/0BAJcoRb3eAMk8Kmc5c-rTNUKbKBvS09rQ.png?1793782518)
6. 근무 시간 음영, 빈 행과 열, 버퍼 표시를 켜거나 꺼요.

   ![근무 시간 음영, 빈 행과 열, 버퍼 표시 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084911091/original/oBi_h0aSCGezzoK8Rg1p_q9PmWvRQRTboA.png?1793782546)
7. **변경사항 저장**을 클릭해요.

저장한 설정은 다음에 **캘린더 보기**를 열 때도 그대로 유지돼요.

{% hint style="info" %}
**변경사항 저장**은 설정을 하나라도 바꿔야 사용할 수 있어요. 저장하지 않고 **닫기**를 클릭하면 변경한 내용이 사라져요. 관리자는 **Staff colors** 탭에서 직원 색상을 따로 설정할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 캘린더 보기 설정을 바꾸면 예약 가능 시간도 바뀌나요?

아니요. 캘린더 정보가 화면에 보이는 방식만 바뀌어요. 예약 규칙, 예약 가능 시간, 설정해 둔 버퍼는 그대로예요.

### Staff colors 탭이 안 보여요.

**Staff colors** 탭은 관리자에게만 표시돼요.

### 근무하지 않는 시간에 음영이 안 보여요.

음영 설정이 켜져 있는지, **사용자** 필터를 사용 중인지 확인하세요. **일간 보기**는 직원을 여러 명 선택할 수 있지만, **주간 보기**는 직원을 한 명만 선택해야 해요.

### 일부 직원 열이 안 보여요.

**Hide empty rows and columns**가 켜져 있을 수 있어요. 이 설정은 **일간 보기**에서 예정된 이벤트가 없는 직원을 숨겨요.

### 버퍼 시간 표시를 끄면 예약 버퍼가 없어지나요?

아니요. 버퍼 블록만 숨겨질 뿐이에요. 설정해 둔 버퍼는 계속 예약 가능 시간에 영향을 줘요.

### Export to CSV를 쓸 수 없어요.

현재 캘린더 보기에 내보낼 예약이 없으면 CSV로 내보낼 수 없어요.

### CSV로 내보내면 차단된 시간대가 빠져 있어요.

CSV에는 예약만 포함되고 차단된 시간대는 포함되지 않아요.

### 설정이 옮겨진 뒤에 시간대를 다시 설정해야 하나요?

아니요. 이전에 저장한 보기 시간대 설정은 자동으로 옮겨져요.
