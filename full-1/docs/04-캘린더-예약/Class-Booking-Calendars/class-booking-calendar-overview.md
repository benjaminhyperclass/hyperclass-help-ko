# 클래스 예약 캘린더 개요

클래스 캘린더는 한 번의 예약에 여러 명이 참석하는 일대다 이벤트를 관리하는 캘린더예요. 웨비나, 워크숍, 교육, 스포츠 행사처럼 여러 사람이 한 일정에 함께하는 경우에 알맞아요.

클래스 캘린더에는 예약 담당자를 한 명만 지정할 수 있어요. 보통 강사나 진행자가 담당자예요. 시간대(슬롯)당 자리 수를 정할 수 있고, 최대 9,999명까지 설정할 수 있어요. 다만 미팅 장소에 따른 제한은 적용돼요.

## 클래스 예약이란?

클래스 예약은 한 번의 예약으로 여러 참석자를 받는 일대다 방식의 캘린더 예약이에요. 여러 사람이 한 이벤트에 동시에 참석해야 할 때 유용해요. 예를 들면 다음과 같아요.

1. 웨비나/워크숍
2. 교육
3. 스포츠 행사

## 클래스 예약 캘린더를 쓰면 좋은 점

여러 참석자가 있는 이벤트를 관리할 때 클래스 캘린더를 쓰면 이런 점이 좋아요.

- 효율적인 운영: 예약 하나로 여러 참석자를 받을 수 있어서 일정 관리가 간단해져요.
- 정원 설정: 시간대당 자리 수를 정해서 클래스 규모를 조절할 수 있어요. 수업이나 참여 환경에 맞는 인원으로 운영할 수 있어요.
- 한곳에서 관리: 예약, 취소, 일정 변경을 한 화면에서 관리할 수 있어요. 예약 담당자가 이벤트 전체를 한눈에 챙기기 쉬워요.
- 원활한 소통: 날짜, 시간, 장소 같은 이벤트 정보를 참석자에게 분명하게 보여 줄 수 있어요. 혼선과 노쇼(불참)를 줄이는 데 도움이 돼요.
- 시간 절약: 예약 과정이 자동으로 처리되고, 참석자가 직접 예약을 취소하거나 일정을 바꿀 수도 있어요. 운영자와 참석자 모두 시간을 아낄 수 있어요.

{% hint style="info" %}
클래스 예약 캘린더 링크를 공유하면 이벤트가 있는 달이 아니라 항상 현재 달이 먼저 열려요. 클래스가 다른 달에 있으면 기본적으로 **No available time slots**(예약 가능한 시간대 없음)라고 보일 수 있어요. 이때는 화살표를 눌러 이벤트가 있는 달로 이동해야 해요.
{% endhint %}

## 자주 묻는 질문

### 클래스에 등록한 참가자 모두에게 급하게 이메일을 보내려면 어떻게 하나요?

클래스 세션에 등록한 참석자 모두에게 이메일을 한 번 보내려면 **연락처**로 이동해서 해당 클래스 예약으로 연락처를 걸러 내세요. **상세 필터**나 예약 기준 필터를 쓰면 돼요. 등록한 참가자 목록이 나오면 연락처를 선택하고 **일괄 작업**으로 이메일을 보내세요. 같은 그룹에 여러 번 연락할 계획이라면 해당 클래스 예약으로 거른 스마트 리스트를 만들어 두세요.

### 참석자 한 명의 클래스 예약만 취소하거나 일정을 바꿀 수 있나요?

네, 할 수 있어요. 참석자 이름 옆의 옵션 메뉴에서 그 참석자의 예약만 취소하거나 일정을 바꿀 수 있고, 나머지 참석자에게는 영향이 없어요. 하이퍼클래스 모바일 앱 4.20.0 버전 이상에서는 **참석자** 탭에서도 참석자의 상태 변경, 예약 일정 변경, 연락처 정보 보기, 예약 취소를 할 수 있어요.

### 연락처에서 직접 클래스 예약을 잡을 수 있나요?

네, 할 수 있어요. **Book Appointment**(예약 등록) 버튼을 누르고 예약할 연락처를 선택하세요. 그다음 캘린더에서 클래스 예약 캘린더를 고르고 시간대를 선택한 뒤 예약을 진행하면 돼요.

### 참석자가 클래스 예약을 직접 취소하거나 일정을 바꿀 수 있나요?

참석자가 직접 취소하거나 일정을 바꾸게 하려면 **캘린더 설정**의 **Confirmation**(확인) 탭에서 **Allow Cancellation**(취소 허용)과 **Allow Reschedule**(일정 변경 허용) 옵션을 켜세요.

### 클래스 세션 전체를 모든 참석자와 함께 취소하려면 어떻게 하나요?

등록한 참석자를 포함해 클래스 세션 전체를 취소하려면 **캘린더**로 이동하세요. **캘린더 보기** 또는 **예약 목록 보기**에서 클래스 예약을 열고 **삭제**(휴지통 아이콘)를 클릭하세요. 확인 창이 나오면 삭제를 확인해 주세요. 그러면 해당 시간대의 클래스 세션과 연결된 참석자가 모두 함께 삭제돼요.
