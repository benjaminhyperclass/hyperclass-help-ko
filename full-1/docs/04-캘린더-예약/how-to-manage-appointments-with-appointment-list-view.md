# 예약 목록 보기로 예약 관리하기

**예약 목록 보기**는 예약을 날짜별 캘린더 대신 목록으로 보여 주는 화면이에요. **스마트 리스트**를 이용해 예약을 필터링하고, 정렬하고, 열을 조정하고, 바로 처리할 수 있어요. 여러 캘린더와 여러 사용자의 예약을 한곳에서 관리해야 하는 관리자, 영업팀, 지원팀에 알맞아요.

[동영상](https://www.youtube.com/embed/qtLzv\_150Zw?&wmode=opaque)

## 예약 목록 보기란?

**예약 목록 보기**는 하이퍼클래스의 캘린더 화면 중 하나예요. 날짜 기준 캘린더 격자 대신 예약을 목록으로 보여 줘요. 예약이 많을 때 관리하기 좋도록 만들어졌고, 필터·정렬·열 설정을 묶어 저장한 **스마트 리스트**로 작업할 수 있어요.

**스마트 리스트**를 쓰면 **예약 목록 보기**가 보기만 하는 화면이 아니라 실제 업무를 처리하는 작업 공간이 돼요. 목록에서 바로 예약을 만들고, 수정하고, 관리할 수 있어요. 그래서 처리할 일의 우선순위를 정하고, 결과를 추적하고, 팀 전체가 같은 방식으로 일하기 쉬워져요.

## 예약 목록 보기의 주요 장점

**예약 목록 보기**를 쓰면 예약을 잡는 데서 그치지 않고, 반복해서 쓸 수 있는 업무 흐름으로 예약을 관리할 수 있어요.

- 한곳에서 관리: 날짜별 화면을 하나씩 넘기지 않고 여러 캘린더의 예약을 한 번에 보고 관리해요.
- **스마트 리스트**: 필터, 정렬, 열 설정을 함께 저장해 두고 다시 쓸 수 있어요.
- 상세 필터링: 상태, 담당자, 캘린더, 기간 등으로 예약 목록을 좁혀요.
- 열 사용자 지정: 역할이나 작업에 맞게 보일 예약 정보를 직접 정해요.
- 바로 처리: 목록에서 상태 변경, 편집, 일정 변경, 새 예약 만들기를 할 수 있어요.

## 예약 목록 보기 사용 방법

### 예약 목록 보기 열기

**예약 목록 보기**는 **캘린더** 메뉴에서 바로 열어요. **캘린더 보기**와 함께 쓰는 주요 작업 공간이에요.

1. 왼쪽 메뉴에서 **캘린더**로 이동하세요.
2. 맨 위의 **예약 목록 보기** 탭을 선택하세요.

![예약 목록 보기 탭이 선택된 캘린더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063057237/original/dmswuRIbFPYkVfbnQqeT0gayY0E1Jsgmpg.png?1768911244)

### 예약 유형

예약 유형은 예약할 때 사용한 캘린더에 따라 자동으로 정해져요. 캘린더는 각각 **미팅**, **서비스**, **대여** 중 하나로 설정되어 있고, 예약은 예약 시점에 그 유형을 이어받아요.

**예약 목록 보기**는 선택한 유형에 해당하는 예약을 보여 줘요. 그러니 보려는 예약이 맞게 나오도록 올바른 예약 유형을 선택하세요.

![예약 유형을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063058293/original/rtkXUL9kLwwAXfCzaV9R7IwRwnzsV-kD6w.png?1768911686)

### 새 예약 만들기

**New Appointment**(새 예약) 버튼을 누르면 **예약 목록 보기**에서 바로 예약을 직접 잡을 수 있어요. 통화 후나 내부 조율 중에 연락처를 대신해 예약을 잡을 때 편해요.

**New Appointment**를 누르면 직접 예약 화면이 열려요. 여기서 캘린더를 고르고 날짜와 시간을 정한 다음, 기존 연락처를 연결하거나 필요하면 새 연락처를 만들 수 있어요. 예약은 선택한 예약 유형과 스마트 리스트 조건에 맞춰 목록에 추가돼요.

![새 예약 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063172569/original/LbV-tEXJnJPQknsUYa3GCE3Sey8RtPdStQ.png?1769007722)

### 예약 목록과 스마트 리스트 만들기

기본 목록인 **Upcoming**(예정), **취소됨**, **전체**를 누르면 자주 쓰는 예약 보기를 바로 열 수 있어요.

더 구체적인 보기가 필요하면 **+ Smart list**(스마트 리스트 추가)를 눌러 직접 만들어요. 필터, 정렬, 열 설정을 저장해 두면 예약을 관리하는 방식을 바꿀 때마다 목록을 다시 설정하지 않아도 돼요.

![기본 목록과 스마트 리스트 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063133539/original/IzFgl4V1gz7ogAFZrG1XzIY_MpvDAj3knA.png?1768987933)

### 목록 사용자 지정

어떤 예약을 보여 줄지, 어떤 순서로 보여 줄지, 어떤 정보를 보여 줄지 정할 수 있어요.

#### 목록 사용자 지정 열기

1. **목록 사용자 지정**을 눌러 설정 패널을 여세요.

이 패널이 스마트 리스트를 설정하는 중심 화면이에요.

![목록 사용자 지정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063134494/original/8mt4CRcdBR-eteAWy-Y6H4llLpqaADi-dQ.png?1768988523)

### 목록 사용자 지정 패널

**목록 사용자 지정** 패널에서는 예약 목록을 어떻게 구성하고 저장할지 정해요. 현재 목록의 이름을 바꾸고, **상세 필터**로 보여 줄 예약을 좁히고, 정렬 방식을 고르고, 목록에 표시할 열을 관리할 수 있어요.

이 패널에서 바꾼 내용은 현재 목록 보기에 적용되고, 스마트 리스트로 저장할 수 있어요. 저장해 두면 **예약 목록 보기**로 돌아올 때마다 같은 설정을 다시 쓸 수 있어요.

![목록 사용자 지정 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063134521/original/02Hz6Czn7NRNKNGSBoBdavBmUhkMzf2d-w.png?1768988550)

### 상세 필터 적용

**상세 필터**는 **예약 목록 보기**에 어떤 예약이 나올지 정해요. 업무에 필요한 예약만 보이도록 목록을 좁힐 수 있어요. 조건은 하나만 쓰거나 여러 개를 함께 쓸 수 있고, 담당자·상태·시간·캘린더 같은 기준으로 원하는 예약에 집중할 수 있어요.

자주 쓰는 필터 옵션은 다음과 같아요.

- **예약 상태**: 예를 들어 확정, 취소됨, 노쇼
- **배정된 사용자**: 특정 팀원의 예약을 볼 때
- **캘린더**: 결과를 하나 이상의 캘린더로 제한할 때
- 예약 날짜 또는 시간: 특정 기간에 집중할 때
- **연락처 세부정보**: 연결된 연락처로 필터링할 때

필터는 AND 조건으로 결합돼요. 선택한 조건을 모두 만족하는 예약만 목록에 나온다는 뜻이에요. 그래서 "특정 사용자의 정해진 기간 내 예정된 예약"처럼 정확한 보기를 만들 수 있고, 이를 스마트 리스트로 저장해 계속 관리할 수 있어요.

![상세 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063162282/original/n5yfK0FWjh7V_nzweKjbV-n0BnZmzlvIDg.png?1769003306)

### 필터 추가

**필터 추가**를 눌러 조건을 더하면 목록을 더 좁힐 수 있어요. 필터는 AND 조건으로 결합되므로, 선택한 기준을 모두 만족하는 예약만 나와요. 스마트 리스트로 저장하기 전에 아주 구체적인 예약 묶음으로 좁힐 수 있어요.

![필터 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063161743/original/3ZAopkZU4qNn4w9dNQtHYjIxucH56tYSTg.png?1769003041)

### 정렬 적용

정렬은 예약이 목록에 나오는 순서를 정해요. 정렬 설정은 스마트 리스트에 함께 저장돼요.

자주 쓰는 정렬 옵션은 다음과 같아요.

- **Appointment Time**(예약 시간): 오름차순 또는 내림차순
- **Date Added**(추가한 날짜): 오름차순 또는 내림차순

정렬을 활용하면 급한 정도나 업무 흐름에 맞게 예약의 우선순위를 정할 수 있어요.

![정렬 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063178709/original/nRcDp84VWorKBeMImysCEOVXOm3NQuZ6Bg.png?1769010359)

### 열 관리

열은 목록에 어떤 예약 정보를 보여 줄지 정해요. **열 관리**에서 할 수 있는 일은 다음과 같아요.

- 열 표시 또는 숨기기
- 끌어서 놓기로 열 순서 바꾸기
- 제거할 수 없는 시스템 고정 열 확인

열 설정은 스마트 리스트에 함께 저장돼요.

![열 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063170813/original/jYXjCD5QH6yIjo_P12lUoJdrL4PartU6pg.png?1769006923)

### 예약 상태 변경

**예약 목록 보기**에서는 예약을 열지 않고 목록에서 바로 상태를 바꿀 수 있어요. 예약 행의 **상태** 드롭다운을 눌러 **확정**, **참석**, **노쇼**, **취소됨**, **무효** 중에서 알맞은 상태를 선택하세요.

여기서 바꾼 내용은 바로 저장되고 하이퍼클래스 전체에 반영돼요. 예약이 많아도 예약 결과를 정확하게 관리할 수 있어요.

{% hint style="info" %}
예약을 **참석** 또는 **노쇼**로 바꾸면 하이퍼클래스 안의 상태는 바뀌지만, 연결된 외부 캘린더에는 이벤트 업데이트가 전달되지 않아요.
{% endhint %}

![상태 드롭다운으로 예약 상태를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063174660/original/Dn-Lq5L7zdqI7cukzbuuEwrGotppKOycpw.png?1769008626)

### 행 작업으로 예약 관리

**예약 목록 보기**의 각 예약에는 **점 세 개(⋮) 메뉴**가 있어요. 이 메뉴에서 예약 상세 보기, 예약 편집, 일정 변경, 필요할 때 삭제 같은 작업을 빠르게 할 수 있어요. 동의 추적을 켜 두었다면 **View Consent**(동의 내역 보기) 옵션도 보일 수 있어요.

- **상세 보기**: 예약 전체 기록을 열어 모든 예약 정보와 활동을 확인해요.
- **View Consent**: 동의 추적을 켜 두었을 때, 예약과 관련된 동의 내역을 보여 줘요.
- **편집**: 연락처, 메모, 배정된 캘린더 같은 예약 정보를 수정해요.
- **일정 변경**: 같은 예약 기록을 유지한 채 예약 날짜와 시간을 바꿔요.
- **삭제**: 캘린더와 **예약 목록 보기**에서 예약을 영구적으로 제거해요.

## 자주 묻는 질문

### 예약 목록 보기와 캘린더 보기는 어떻게 다른가요?
**캘린더 보기**는 날짜와 가능한 시간을 기준으로 예약을 잡는 데 알맞아요. **예약 목록 보기**는 목록, 필터, 작업 기능으로 많은 예약을 관리하는 데 알맞아요.

### 예약 목록 보기의 스마트 리스트는 무엇인가요?
스마트 리스트는 필터, 정렬, 열 설정을 함께 저장해 둔 예약 보기예요. 같은 설정을 반복해서 쓸 수 있어요.

### 상세 필터와 스마트 리스트는 어떻게 다른가요?
**상세 필터**는 보이는 예약을 일시적으로 좁혀요. 스마트 리스트는 그 필터를 정렬, 열 설정과 함께 저장해 나중에 다시 쓸 수 있게 해 줘요.

### 내 예약이 전부 보이지 않아요.
선택한 예약 유형, 적용 중인 필터, 현재 선택한 스마트 리스트 때문에 일부 예약이 숨겨져 있을 수 있어요.

### 스마트 리스트를 다른 사용자와 공유할 수 있나요?
스마트 리스트의 공개 범위는 사용자 권한과 계정 설정에 따라 달라요.
