# 모바일 앱에서 서비스(v2) 예약 만들기

하이퍼클래스 모바일 앱에서 서비스(v2) 예약을 만드는 방법을 안내해요. 지점, 서비스, 변형, 애드온, 쿠폰, 예약 가능 시간을 한 번의 흐름으로 선택해 복잡한 서비스 예약을 휴대폰에서 바로 잡을 수 있어요.

## 모바일 앱의 서비스(v2) 예약이란?

서비스(v2) 예약은 하이퍼클래스 서비스(v2) 엔진의 기능을 iOS와 Android 기기에서 그대로 쓸 수 있게 해 줘요. 직원이 모바일 앱에서 서비스 기반 예약을 직접 만들 수 있어요. **캘린더**에서 하나 이상의 서비스를 담아 예약을 만들 수 있고, 서비스마다 소요 시간, 담당 직원, 변형, 애드온, 직원별 가격을 설정할 수 있어요. 실시간 예약 가능 시간 규칙도 자동으로 적용돼요.

데스크톱에서 벗어나 예약을 잡거나 관리해야 할 때 쓰기 좋아요. 예를 들어 프런트 데스크, 현장 작업, 이동 중 일정 조율 같은 상황이에요. 웹과 같은 서비스(v2) 로직을 쓰기 때문에 모바일 예약도 기기와 상관없이 정확하고 일관돼요. 가격 오류, 예약 가능 시간 충돌, 수동 수정을 줄일 수 있어요.

---

## 서비스(v2) 모바일 예약의 장점

- **어디서든 예약:** 데스크톱으로 옮기지 않고 모바일 앱에서 서비스 예약을 만들거나 수정할 수 있어요.
- **여러 서비스를 한 번에 결제 단계로:** 여러 서비스를 하나의 예약으로 묶고, 통합 요약으로 확인할 수 있어요.
- **정확한 가격:** 변형 가격과 직원별 가격 규칙이 자동으로 적용돼요.
- **애드온과 추가 판매:** 서비스에 선택 애드온을 붙일 수 있고, 수량 기반 추가 항목도 지원해요.
- **실시간 예약 가능 시간:** 시간대는 직원 근무 시간, 날짜별 예외 설정, 리소스 가용성을 반영해요.
- **더 깔끔한 캘린더 보기:** 월, 주, 목록 보기에서 여러 서비스를 기준으로 필터링해 필요한 예약만 볼 수 있어요.

## 지원하는 예약 기능

### 다중 지점 지원

실제 지점이 여러 곳이면 예약 흐름에는 예약 가능한 직원이 있는 지점만 표시돼요. 그래서 예약이 실제로 가능한 지점에만 잡혀요.

### 서비스 변형

변형을 쓰면 하나의 서비스를 소요 시간이나 가격이 다른 여러 옵션으로 제공할 수 있어요. 설정된 변형은 모바일 예약 중에 모두 선택할 수 있어요.

### 애드온

애드온은 예약 중에 선택 항목으로 표시돼요. 수량 기반 애드온도 지원하기 때문에 한 서비스에 여러 개를 추가할 수 있어요.

### 직원별 가격

직원별 가격을 설정해 두었다면, 선택한 직원에 맞는 가격이 모바일 앱에서 자동으로 적용돼요.

### 날짜별 직원 근무 시간

직원에게 설정한 특별 근무 시간, 휴일, 일회성 가용 시간 변경이 시간 선택 화면에 반영돼요. 중복 예약을 막는 데 도움이 돼요.

### 다중 서비스 결제

하나의 예약에 여러 서비스를 추가할 수 있어요. 후속 자동화는 **Service Booking**(서비스 예약) 워크플로우 트리거를 사용해 예약 한 건당 한 번만 실행되도록 설정할 수 있어요.

### 다중 서비스 캘린더

**캘린더 보기**에서 여러 서비스를 한 번에 필터링할 수 있어요. 서비스를 여러 개 운영하는 팀의 일정을 확인하기 쉬워요.

## 서비스 예약하는 방법

### 캘린더 열기

1. 모바일 앱에서 **캘린더** 탭으로 이동해요.
2. + (플러스) 버튼을 탭해요.
3. **서비스 예약**을 선택해요.

![캘린더에서 새 서비스 예약 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062828226/original/6KgbNDcSRb0OTbsjeYYgn_OKcmuqBgnWlg.png?1768567942)

### 연락처와 지점 선택

**서비스 예약**을 선택하면 먼저 예약할 연락처(고객)를 검색해서 선택해요.

서비스를 여러 지점에서 운영한다면 다음 단계에서 예약할 지점을 선택하라는 안내가 나와요.

같은 서비스를 지점 두 곳 이상에서 제공할 때 유용해요(예: 뉴욕 지점과 뉴저지 지점).

![연락처와 지점 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062827823/original/JRPrIzZJ3Q2qoJFVwJlXkwtSvpVwi8lOPQ.png?1768567643)

### 서비스 선택

예약 가능한 서비스를 둘러보거나 검색해서, 예약할 서비스를 선택해요.

![서비스 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062827983/original/25xeM0jh_GaqFNTnQC_C7qBy-0rVLutDTA.png?1768567727)

### 변형과 애드온 선택

변형을 선택해요(예: 30분, 45분, 60분). 가격과 수량이 표시되는 선택 **애드온**을 추가할 수 있어요.

![변형과 애드온 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062827304/original/rMg5LukxJ-yrfjWn3s7E78W840Vi4Cehfw.png?1768567397)

### 직원 지정

서비스마다 담당 팀원을 선택해요. 직원별 가격이 설정되어 있으면 가격이 자동으로 바뀌어요.

![서비스별 직원 지정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062828617/original/PaD7bHf9Y3wmrmnBQ2iKSTHF84P5ueugzw.png?1768568255)

### 쿠폰 적용(선택)

유효한 프로모션 코드나 쿠폰 코드를 입력하면 할인이 적용돼요.

![쿠폰 코드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062830555/original/S_rpT48Wjp_dHFKZHTuBv9gOYQMCp6_IjA.png?1768569473)

### 시간대 선택

직원과 서비스별 실시간 예약 가능 시간을 확인하고 시간대를 선택해요. 활성화되어 있다면 **Custom Time**(사용자 지정 시간)도 선택할 수 있어요.

### 예약 확인 및 확정

서비스, 직원, 가격, 할인 내용을 확인한 뒤 **Schedule Booking**(예약 확정)을 탭하면 예약이 끝나요.

### 예약 요약 보기

**고객 세부 정보**, 서비스별 내역, 소요 시간, 가격, 할인 정보가 담긴 전체 요약을 볼 수 있어요.

![예약 요약 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059239962/original/tuCIE75JunWX4rMjGtbznRh9qi5raI0atA.png?1764145913)![예약 요약 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059239961/original/WtY6Jk_4Cx7aMZHanauZXMnh8w7_uOIoFA.png?1764145913)

## 기존 서비스 예약 확인하기

서비스별로 필터링해서 기존 서비스 예약을 보려면 다음과 같이 하세요.

1. 모바일 앱에서 **캘린더** 탭으로 이동해요.
2. 캘린더 맨 위에 선택된 서비스를 나타내는 색상 라벨이 보여요.
3. 이 라벨을 탭해요. **사용자**, **캘린더**, **그룹** 탭이 있는 필터 창이 열려요.
4. **캘린더** 아래에서 **서비스**를 탭해요.
5. 예약 가능한 모든 서비스 목록이 나와요. 필요하면 검색창을 사용하세요.
6. 필터링할 서비스를 하나 이상 선택해요.
7. 선택하면 캘린더 보기에 선택한 서비스와 관련된 예약만 표시돼요.

![서비스별로 캘린더 필터링](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059241391/original/6n9F8O6StvpZ0xzluHwCxVZt5alxM1fgJw.png?1764146387)

## 예약 제목이 서비스 글로벌 설정에서 자동으로 채워져요

**예약 제목** 필드가 서비스의 **글로벌 설정**에서 값을 가져와요. 덕분에 모바일 예약도 웹과 같은 이름 규칙을 따라요. 예약할 때 시간이 절약되고, 팀원마다 제목이 달라지는 일도 줄어요.

모바일 앱에서 새 서비스(v2) 예약을 만들면 **예약 제목** 필드가 **글로벌 설정**에 설정한 **서비스 예약 제목**으로 자동으로 채워져요.

**서비스 예약 제목**을 따로 설정하지 않았다면 **연락처 이름**으로 채워져요.

{% hint style="warning" %}
- 새 서비스 예약에만 적용돼요.
- 편집, 일정 변경, 복제 흐름에는 영향이 없어요.
- 기존 예약을 편집하는 흐름에서는 원래 예약의 제목이 그대로 채워져요.
{% endhint %}

## 자주 묻는 질문

### 모바일 앱에서 결제를 받을 수 있나요?

모바일 서비스 예약에서는 아직 결제 수납을 지원하지 않아요.

### 방이나 장비 같은 리소스도 예약 가능 시간에 반영되나요?

네. 리소스가 겹치면 예약할 수 없는 시간대는 표시되지 않아요.

### **결제**에서 만든 쿠폰도 적용할 수 있나요?

활성 상태인 캘린더 쿠폰이면 모바일 예약 중에 적용할 수 있어요.

### 예약 편집과 일정 변경은 어떻게 다른가요?

편집은 예약 세부 정보를 수정하는 것이고, 일정 변경은 날짜나 시간을 바꾸는 것이에요.

### 직원별 가격을 끌 수 있나요?

직원별 서비스 배정에서 사용자 지정 가격 필드를 비워 두면 서비스의 기본 가격이 적용돼요.

### 여러 서비스를 예약하면 워크플로우가 여러 번 실행되나요?

아니요. **Service Booking** 트리거는 서비스가 여러 개 포함되어 있어도 예약 한 건당 한 번만 실행돼요.

### 모바일 예약 흐름에서 온라인 위치도 지원하나요?

실제 지점만 표시돼요. 필요하면 주소 필드에 온라인 링크를 직접 입력할 수 있어요.

### 어떤 앱 버전에서 이 기능을 지원하나요?

하이퍼클래스 모바일 앱과 화이트라벨 앱 v4.2.0.789 이상에서 지원해요.
