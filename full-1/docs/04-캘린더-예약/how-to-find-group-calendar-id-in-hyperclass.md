# 그룹 캘린더 ID 찾기

그룹 캘린더 ID는 하이퍼클래스에서 특정 그룹 캘린더를 구분하는 고유 값이에요. 연동이나 API 설정처럼 기술 설정에서 그룹 캘린더 ID를 요구할 때 필요해요. 이 문서에서는 **영구 링크**로 ID를 찾는 방법과, 대안으로 **임베드 코드**에서 찾는 방법을 안내해요.

## 하이퍼클래스의 그룹 캘린더 ID란?

그룹 캘린더는 여러 개의 개별 캘린더를 하나의 예약 화면으로 묶은 캘린더예요. 그룹 캘린더 ID는 그룹 자체를 구분하는 값이고, 그룹 안에 있는 개별 캘린더의 ID와는 달라요.

{% hint style="warning" %}
연동이나 기술 설정에서 "Calendar ID"를 입력하라고 하면, 개별 캘린더 ID를 요구하는지 그룹 캘린더 ID를 요구하는지 먼저 확인한 뒤에 값을 입력하세요.
{% endhint %}

## 그룹 캘린더 ID 위치를 알아 두면 좋은 점

그룹 캘린더 ID를 어디서 찾는지 알면 특정 캘린더 그룹을 지정하는 기술 설정을 더 쉽게 마칠 수 있어요. 그룹 캘린더와 개별 캘린더는 ID가 서로 달라서, 올바른 값을 찾아 두면 설정 오류도 줄일 수 있어요.

- 정확한 식별: 기술 설정에 필요한 그룹 캘린더의 ID를 정확히 사용할 수 있어요.
- 연동 설정: 지원되는 외부 서비스 연동에서 그룹 캘린더 ID를 명시적으로 요구하면 그 값을 입력할 수 있어요.
- 기술적 유연성: API나 별도의 맞춤 구현에서 그룹 캘린더 ID가 필요할 때 값을 확인할 수 있어요.
- 설정 오류 감소: 그룹 캘린더 ID와 개별 캘린더 ID를 구분할 수 있어요.

## 그룹 캘린더 ID가 필요한 경우

하이퍼클래스에서 평소 캘린더를 설정할 때는 그룹 캘린더 ID를 직접 복사할 일이 거의 없어요. 특정 연동이나 기술 구현에서 ID를 입력하라고 요구할 때만 필요해요.

다음과 같은 경우에 그룹 캘린더 ID가 필요할 수 있어요.

- 외부 서비스 연동에서 그룹 캘린더의 ID를 요구할 때
- API나 맞춤 기술 설정에서 그룹 캘린더 ID가 필요할 때
- 기술 구현 안내에서 캘린더 그룹의 ID를 입력하라고 명시할 때

{% hint style="info" %}
표준 하이퍼클래스 워크플로우 필터에서는 캘린더 그룹을 바로 선택할 수 있어요. 워크플로우를 캘린더 그룹으로 필터링할 때는 보통 그룹 캘린더 ID를 직접 찾아서 붙여 넣지 않아도 돼요.
{% endhint %}

## 그룹 캘린더 ID 찾는 방법

그룹 캘린더의 공유 옵션에서 **영구 링크**를 확인하면 ID를 가장 간단하게 찾을 수 있어요. ID는 영구 링크의 맨 끝 값이라서, 임베드 코드를 살펴보지 않아도 바로 복사할 수 있어요.

1. 하이퍼클래스 서브 계정에서 **설정**으로 이동하세요.

   ![설정 메뉴로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080977806/original/z9kFdb7bhGSMAVVuuJdWSvgGOsgFaeLpmA.png?1789478063)

2. **캘린더**로 이동한 다음 **그룹** 영역을 여세요.

   ![캘린더 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080977602/original/w3CnbBFrOiWj6o_OcjotuKpLu3oAdYe6LQ.jpeg?1789477952)

   ![그룹 영역 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080977686/original/M0Cfhhc0rYVv7hwv6y9OhCDoN9kyXSdOqQ.jpeg?1789478005)

3. ID가 필요한 그룹 캘린더를 찾으세요.
4. 해당 그룹 캘린더의 공유 옵션을 여세요.

   ![그룹 캘린더의 공유 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080978011/original/zYdRsj0kGB6nXH6a6s5xN28qUbZ_aNuZ7g.png?1789478144)

5. 공유 옵션에서 **Scheduling Link**(일정 예약 링크)를 선택하세요.
6. 그룹 캘린더의 **영구 링크**를 찾으세요.

   ![영구 링크 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080978146/original/Ef9TfIosuJDcifVqA8fTuwytGeF6iVm4Lg.png?1789478196)

7. **영구 링크**에서 마지막 `/` 뒤에 있는 값을 확인하세요.
8. 그 마지막 값을 복사해서, **그룹 캘린더 ID**를 요구하는 연동이나 기술 설정에 붙여 넣으세요.

{% hint style="warning" %}
ID만 복사하세요. 입력란에서 그룹 캘린더 ID를 요구하면 **영구 링크** 전체를 복사하지 마세요.
{% endhint %}

## 대안: 임베드 코드에서 그룹 캘린더 ID 찾기

**영구 링크**를 쓸 수 없거나 쓰고 싶지 않을 때는 그룹 캘린더의 **임베드 코드**에서도 ID를 찾을 수 있어요. 임베드 값에는 다른 문자가 함께 들어 있을 수 있으니, 그룹 캘린더 ID에 해당하는 부분만 복사하세요.

1. **설정 > 캘린더 > 그룹**으로 이동하세요.
2. 해당 그룹 캘린더를 찾아 공유 옵션을 여세요.
3. **임베드 코드**를 선택하세요.

   ![임베드 코드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080978499/original/5FYDFTC5vfDRcxJU0kOaKxaJEcE5apOU7w.png?1789478343)

{% hint style="info" %}
가능하면 **영구 링크** 방법을 쓰세요. 값을 더 간단히 찾을 수 있어요. **임베드 코드** 방법은 대안으로 쓰면 좋아요.
{% endhint %}

## 자주 묻는 질문

### 그룹 캘린더 ID와 개별 캘린더 ID는 같은가요?
아니요. 그룹 캘린더는 여러 캘린더를 묶은 그룹을 가리키고, 개별 캘린더는 각각 자기만의 ID가 있어요. 연동이나 기술 설정에서 ID를 요구하면 어떤 종류의 캘린더 ID가 필요한지 먼저 확인하세요.

### 하이퍼클래스 워크플로우를 설정하려면 그룹 캘린더 ID가 필요한가요?
표준 캘린더 그룹 필터링에는 필요하지 않아요. 하이퍼클래스 워크플로우 필터에서는 ID를 직접 입력하지 않고, 보이는 옵션에서 캘린더 그룹을 바로 선택할 수 있어요. 다만 별도의 맞춤 설정이나 기술 설정에서 그룹 캘린더 ID를 명시적으로 요구하면 필요할 수 있어요.

### 같은 그룹 캘린더 ID를 여러 연동에 사용해도 되나요?
ID는 항상 같은 그룹 캘린더를 가리켜요. 하지만 특정 연동에서 쓸 수 있는지는 그 연동의 입력란이 어떤 값을 요구하는지에 따라 달라요. 각 연동에서 그룹 캘린더 ID를 요구하는지 확인한 뒤에 사용하세요.

### 그룹 캘린더 이름을 바꾸면 그룹 캘린더 ID도 바뀌나요?
이름을 바꿔도 그룹 캘린더 ID는 바뀌지 않아요. 외부 설정이 캘린더 표시 이름이 아니라 ID를 참조하고 있다면, ID는 계속 그 그룹과 연결돼 있어요.

### 그룹 캘린더 ID는 어떤 방법으로 찾는 게 좋나요?
가능하면 **영구 링크** 방법을 쓰세요. 마지막 `/` 뒤의 값이 바로 ID예요. **임베드 코드** 방법은 같은 ID를 찾는 대안이에요.

### 연동에서 "Calendar ID"를 입력하라고 하면 어떻게 하나요?
해당 연동의 문서를 확인해서 **개별 캘린더 ID**를 요구하는지 **그룹 캘린더 ID**를 요구하는지 알아보세요. 두 ID가 서로 바꿔 쓸 수 있는 값이라고 생각하면 안 돼요.
