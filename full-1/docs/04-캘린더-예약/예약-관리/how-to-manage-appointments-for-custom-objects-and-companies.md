# 사용자 지정 객체와 회사 레코드에서 예약 관리하기

사용자 지정 객체 레코드와 회사 레코드 화면에서 바로 예약을 관리할 수 있어요. 예정된 예약과 지난 예약을 확인하고, 새 미팅을 잡거나 이미 만든 예약을 레코드에 연결해 보세요. 부동산 매물 방문, 보험 갱신 미팅, 회사 계정 점검 미팅처럼 레코드와 관련된 일정을 그 레코드에 모아 둘 수 있어요.

{% hint style="info" %}
이 기능은 비공개 베타에 참여 중인 서브 계정에서만 쓸 수 있어요.
{% endhint %}

## 사용자 지정 객체·회사 레코드의 예약이란?

레코드 단위 예약은 사용자 지정 객체나 회사에 연결된 미팅을 관리하는 기능이에요. 예를 들어 부동산 매물 레코드에는 잡혀 있는 매물 방문 일정을, 회사 레코드에는 계정 점검 미팅을 보여 줄 수 있어요.

**예약** 탭에는 선택한 레코드에 연결된 **예정**, **지난 이벤트** 예약이 나와요. 이 탭에서 예약을 확인하고, 새 미팅을 만들고, 같은 서브 계정의 다른 곳에서 잡은 예약을 연결할 수 있어요.

---

## 레코드 단위 예약의 장점

예약을 CRM 레코드에 연결하면 미팅 이력과 일정 관련 작업을 한곳에서 볼 수 있어요.

- 레코드별 예정 예약과 지난 예약을 한 번에 확인할 수 있어요.
- 사용자 지정 객체나 회사 레코드에서 바로 미팅을 잡을 수 있어요.
- 레코드에서 미팅을 시작하면 그 레코드가 **연결된 객체**에 미리 선택돼요.
- 이미 잡아 둔 예약은 중복으로 만들지 않고 연결할 수 있어요.
- **빠른 검색**: 캘린더 이름으로 예약 목록을 좁혀 볼 수 있어요.
- 미팅을 확정하기 전에 연결 가능한 다른 레코드를 확인하고 추가로 선택할 수 있어요.

---

## 사용 전 확인할 것

이 기능은 비공개 베타에 참여 중인 서브 계정에서만 쓸 수 있어요. 또한 해당 사용자 지정 객체나 회사 레코드에 접근할 권한이 있어야 해요.

- 서브 계정에서 **예약** 탭이 활성화되어 있어야 해요.
- 미팅을 예약하려면 캘린더, 날짜, 시간, 연락처가 필요해요.
- 같은 서브 계정에 있는 기존 예약만 연결할 수 있어요.
- 레코드에서 미팅을 시작하면 그 레코드가 **연결된 객체**에 미리 선택돼요.
- **추가** 메뉴에서 **서비스**도 고를 수 있지만, 이후 예약 단계는 **미팅**과 다를 수 있어요.

---

## 레코드 단위 예약 관리하는 방법

미팅이 필요한 사용자 지정 객체 레코드나 회사 레코드에서 시작하세요. 레코드의 **예약** 탭에서 예약을 확인하고, 새로 만들고, 기존 미팅을 연결할 수 있어요.

### 사용자 지정 객체 레코드에서 예약 열기

사용자 지정 객체 레코드에는 그 레코드와 연결된 예약이 표시돼요. **예정**과 **지난 이벤트**를 번갈아 보면서 일정 이력을 확인해 보세요.

1. 서브 계정 화면을 열어요.
2. 왼쪽 메뉴에서 확인할 사용자 지정 객체 유형을 선택해요. 예를 들면 부동산 매물이나 보험 계약 같은 객체예요.
3. 확인할 레코드를 열어요.
4. 레코드의 오른쪽 패널에서 **예약**을 선택해요.
5. **예정**과 **지난 이벤트**를 오가며 연결된 예약을 확인해요.
6. **캘린더 이름** 검색란을 사용하면 목록을 걸러 볼 수 있어요.

![오른쪽 패널에 예약 탭이 보이는 사용자 지정 객체 레코드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084173375/original/zvjwA5FCeSThXH_qQ0KVHd3ZZDXzxBx72w.png?1793005205)

{% hint style="info" %}
**예약** 탭에는 선택한 레코드와 연결된 예약만 나와요. 서브 계정의 다른 예약은 먼저 연결해야 이곳에 보일 수 있어요.
{% endhint %}

사용자 지정 객체 레코드를 만들고 수정하는 방법은 [사용자 지정 객체 레코드 만들기와 업데이트](../../36-기타/리커버리/creating-and-updating-custom-object-records.md)에서 확인하세요.

### 회사 레코드에서 예약 열기

회사 레코드에서도 같은 방식으로 예약을 관리할 수 있어요. 계정 점검 미팅 같은 일정을 해당 회사에 연결해 둘 수 있어요. 회사 기능이 처음이라면 [회사 기능 시작하기](../../02-연락처/getting-started-with-companies-feature.md)를 먼저 읽어 보세요.

1. 서브 계정 화면을 열어요.
2. 왼쪽 메뉴에서 **연락처**를 선택해요.
3. **회사** 탭을 선택해요.
4. 확인할 회사 레코드를 찾아 열어요.

![열어야 할 레코드가 보이는 회사 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084258313/original/wqWupyGegqTLZVPb8n7Bv7p3gzVEmtRqAQ.png?1793066597)

5. 회사의 오른쪽 패널에서 세로로 늘어선 탭 목록을 찾아요.
6. 캘린더 아이콘을 선택해 **예약**을 열어요.
7. 회사에 연결된 **예정**, **지난 이벤트** 예약을 확인해요.
8. 필요하면 **캘린더 이름** 검색란으로 목록을 좁혀요.

### 새 미팅 예약하기

레코드에서 미팅을 시작하면 일정을 잡는 동안 그 레코드가 선택된 상태로 유지돼요. 예약을 확정하기 전에 다른 연결 항목도 확인할 수 있어요.

1. 서브 계정 화면에서 해당 사용자 지정 객체 레코드를 열어요. 회사 레코드라면 **연락처 > 회사**로 가서 회사 레코드를 열어요.
2. 오른쪽 패널에서 **예약**을 선택해요.
3. **추가**를 클릭해요.
4. **미팅**을 선택해요.

![예약 가능한 옵션이 보이는 예약 탭의 추가 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084258414/original/E2sAT7zUnaNoTSIPtw5_vbY9OBmLk9jKGA.png?1793067060)

5. 미팅에 사용할 캘린더를 선택해요.
6. 예약 날짜와 시간을 선택해요.
7. 미팅에 참석할 **연락처**를 선택해요.
8. 예약 제목, 미팅 장소, 상태 등 필수 정보를 확인해요.

![캘린더, 미팅 정보, 연락처, 연결된 객체가 보이는 예약하기 폼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084173379/original/Rtp8O30K6DSkKpqQkWVsZY8S9x8UY_32wQ.png?1793005205)

캘린더에서 예약을 직접 등록하는 방법은 [캘린더 예약 직접 등록하기](../manually-booking-calendar-appointments.md)에서도 볼 수 있어요.

### 연결된 객체 확인하고 예약 완료하기

**연결된 객체** 선택 항목에서 미팅에 연결할 CRM 레코드를 정해요. 처음 열었던 레코드는 미리 선택되어 있어요.

9. 예약 폼에서 **연결된 객체**를 열어요.
10. 현재 사용자 지정 객체 또는 회사 레코드가 선택되어 있는지 확인해요.
11. 필요하면 레코드 유형 옵션과 검색을 이용해 연결 가능한 다른 레코드를 추가로 선택해요.
12. 선택한 연결 항목을 확인해요.
13. **예약하기**를 클릭해 예약을 확정해요.

![예약에 연결된 레코드가 보이는 연결된 객체 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084173378/original/3aYdMDD-f5KEf5EcxGuQF7Om5bOsKvaSiQ.png?1793005206)

레코드 간 연결에 대해 더 알고 싶다면 [기회, 회사, 사용자 지정 객체 간 연결](../../36-기타/리커버리/associations-between-opportunities-companies-custom-objects.md)을 참고하세요.

### 서비스 예약 시작하기

같은 **추가** 메뉴에서 사용자 지정 객체나 회사 레코드의 서비스 예약도 시작할 수 있어요.

1. 서브 계정 화면을 열어요.
2. 해당 사용자 지정 객체 레코드를 열어요. 회사 레코드라면 **연락처 > 회사**로 가서 회사 레코드를 열어요.
3. 오른쪽 패널에서 **예약**을 선택해요.
4. **추가**를 클릭해요.
5. **서비스**를 선택해요.

![서비스 예약 옵션이 보이는 레코드 단위 예약 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084258386/original/O17P7IK7LR_Bx3imObC4kyUdh8QObCJYKA.png?1793066970)

### 기존 예약 연결하기

이미 잡힌 미팅이 있다면 새로 만들지 말고 그 예약을 레코드에 연결하세요. 검색 범위는 현재 서브 계정에 있는 예약이에요.

1. 서브 계정 화면에서 해당 사용자 지정 객체 레코드를 열어요. 회사 레코드라면 **연락처 > 회사**로 가서 회사 레코드를 열어요.
2. 레코드의 오른쪽 패널에서 **예약**을 선택해요.
3. **추가**를 클릭해요.
4. **기존 항목 연결**을 선택해요.
5. 현재 서브 계정에서 연결할 예약을 검색해요.
6. 맞는 예약을 찾아 **링크**를 클릭해요.

![예약 검색과 링크 버튼이 보이는 기존 예약 연결 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084258195/original/i7dtfu7O42kKgTTBTnse6RDQ3aRWbBiLcg.png?1793065926)

목록 형태로 예약을 관리하고 싶다면 [예약 목록 보기로 예약 관리하기](../how-to-manage-appointments-with-appointment-list-view.md)를 참고하세요.

## 자주 묻는 질문

### 예약 탭이 비어 있어요. 왜 그런가요?
**예약** 탭에는 현재 레코드와 연결된 예약만 표시돼요. **예정**과 **지난 이벤트**를 모두 확인하고, 캘린더 이름 검색어가 입력되어 있다면 지워 보세요. 예약은 있는데 연결되어 있지 않다면 **기존 항목 연결**을 사용하세요.

### 같은 서브 계정의 다른 곳에서 잡은 예약도 연결할 수 있나요?
네, 연결할 수 있어요. **추가** > **기존 항목 연결**을 선택하면 같은 서브 계정의 예약을 새로 만들지 않고 연결할 수 있어요.

### 미팅을 예약할 때 현재 레코드가 자동으로 연결되나요?
현재 사용자 지정 객체나 회사 레코드가 **연결된 객체**에 미리 선택돼요. 예약을 확정하기 전에 선택 내용을 확인하세요.

### 미팅 하나를 여러 레코드 유형에 연결할 수 있나요?
네, 가능해요. **연결된 객체** 선택 항목에서 회사, 사용자 지정 객체 레코드, 그 밖에 선택할 수 있는 레코드 유형을 고를 수 있어요.

### 예약 탭이 보이지 않아요.
이 기능은 비공개 베타로 제공돼요. 서브 계정이 베타에 등록되어 있는지, 기능이 활성화되어 있는지 확인하세요.
