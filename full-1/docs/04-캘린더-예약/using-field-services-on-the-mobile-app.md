# 모바일 앱에서 현장 서비스 사용하기

현장 직원은 하루 대부분을 책상이 아니라 현장에서 보냅니다. 하이퍼클래스 모바일 앱을 쓰면 휴대폰으로 **현장 서비스**(Field Services)를 이용할 수 있어요. **작업**을 열고, 일정을 확인하고, 요청과 견적서를 만들고, 방문 상태를 바꾸면 사무실과 바로 동기화됩니다.

이 문서에서는 앱을 받는 방법, 모바일에서 **현장 서비스**를 여는 방법, 자주 하는 작업을 알려 드려요.

{% hint style="info" %}
**현장 서비스**는 현재 비공개 베타이고, 선택된 계정에서만 쓸 수 있어요. 기능과 화면은 개선 과정에서 바뀔 수 있어요. 웹에서 먼저 **현장 서비스**를 셋업해야 모바일에도 나타나요.
{% endhint %}

---

## 시작하기 전에

1. 서브 계정에서 **현장 서비스**를 쓸 수 있어야 해요. 웹 왼쪽 메뉴에 **베타** 태그가 붙은 **현장 서비스**가 보여야 합니다. 자세한 내용은 [현장 서비스 개요 및 시작 가이드](Field-Services/field-services-overview-how-to-get-started.md)를 참고하세요.
2. 웹에서 기본 셋업(직원, 서비스 지역, 서비스)을 마쳐 주세요. 그래야 현장 팀이 열어 볼 작업이 생겨요. 자세한 내용은 [현장 서비스 홈 개요](Field-Services/field-services-home-overview.md)를 참고하세요.
3. 웹에서 쓰는 **같은 로그인 정보**로 모바일 앱에 로그인한 뒤, 알맞은 로케이션을 선택하세요.

{% hint style="info" %}
모바일에서는 **현장 서비스**라는 별도 이름이 보이지 않아요. 웹에서 셋업을 마치면 **작업**으로 나타납니다.
{% endhint %}

---

## 모바일 앱 받기

**앱이 설치되어 있지 않은 경우**

1. 웹에서 **현장 서비스 > 홈**을 여세요.
2. **Setup guide**(설정 가이드)를 여세요. 새 계정은 환영 페이지에서도 설치 옵션이 보일 수 있어요.
3. **Get the mobile app**(모바일 앱 받기) 아래에서 **앱 스토어** 또는 **Google Play** QR 코드를 스캔하세요.
4. 앱을 설치하고, 웹에서 쓰는 것과 같은 로그인 정보로 로그인하세요.
5. **현장 서비스**를 셋업한 로케이션을 선택하세요.

앱 스토어나 Google Play에서 하이퍼클래스 앱을 직접 검색해 설치한 뒤 로그인해도 돼요.

---

## 모바일에서 현장 서비스 열기 (작업)

**앱이 이미 설치되어 있는 경우**

1. 앱을 열고 **현장 서비스**를 셋업한 로케이션을 선택하세요.
2. 하단 메뉴에서 **앱**을 탭하세요.
3. **Sales & Operations**(영업 및 운영) 아래에서 **작업**을 탭하세요.
4. **작업** 화면이 열려요. 하단 메뉴가 **작업**, **일정**, **검색**으로 바뀝니다.

![모바일 앱에서 작업 화면을 연 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085126280/original/LfM5DPK5d1BcwWj-y46k2gEtgnVv4UsJOA.png?1793965414)

{% hint style="info" %}
**앱**에 **작업**이 보이지 않으면, 웹에서 해당 로케이션에 **현장 서비스**를 쓸 수 있는지 확인하세요. 그런 다음 화면을 아래로 당겨 새로고침하거나, 로그아웃 후 다시 로그인하세요.
{% endhint %}

## 모바일 메뉴 살펴보기

**작업**을 열면 아래 탭을 쓸 수 있어요.

| 탭 | 볼 수 있는 내용 |
| --- | --- |
| **작업** | 작업 목록이 나와요. 목록이 비어 있으면 **Schedule a job**(작업 일정 잡기)을 탭하거나 **+** 버튼으로 새 작업을 만들 수 있어요. |
| **일정** | 방문을 **목록**, **주**, **지도** 보기로 볼 수 있어요. 상태, 시간, 주소, 서비스 정보도 함께 나와요. |
| **검색** | 필터를 사용해 **작업**, **요청**, **견적서**, **인보이스**를 찾을 수 있어요. |

모바일에서 바꾼 내용은 웹과 동기화돼요. 그래서 사무실과 현장이 같은 정보를 볼 수 있어요.

## 요청, 작업, 견적 만들기

1. **작업**, **일정**, **검색** 화면 중 하나에서 파란색 **+** 버튼을 탭하세요.![+ 버튼을 탭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085124273/original/EeYBt6eW6KiLEkfir3870pkkrW4NaanNJw.png?1793964521)
2. **새로 만들기** 아래에서 다음 중 하나를 선택하세요.
   - **요청** — 고객이 요청한 작업 내용을 기록해요.
   - **작업** — 서비스 주소가 있는 고객의 작업을 만들어요.
   - **예상 수익** — 견적을 만들어요.

![새로 만들기 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085124563/original/MVbR2rLISDT_lHOnZfLMzDRZ--wf3JjIbw.png?1793964679)![작업 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085125427/original/mOXxJmGfCDKNeH4aC7MwlaVJaU2RbtY_IA.png?1793965012)

## 작업 만들고 관리하기

1. **+** 를 탭한 뒤 **작업**을 선택하세요. 작업 목록이 비어 있다면 **Schedule a job**을 탭해도 돼요.
2. **Job for**(작업 대상)에서 기존 연락처를 선택하세요.
3. **service address**(서비스 주소)를 추가하세요. 주소를 추가하기 전에는 작업을 저장할 수 없어요.
4. **서비스**와 선택 사항인 **상품**을 추가하세요. 소요 시간과 가격은 카탈로그에서 가져와요. 수정할 수 있는 항목이라면 수량과 단가를 조정할 수 있어요.
5. **직책**을 입력하거나 확인하고, 필요하면 메모를 추가하세요.
6. **Schedule visit**(방문 일정)에서 날짜와 시간을 고르세요. 아니면 **Schedule later**(나중에 일정 잡기)를 켜거나, **Find a time**(시간 찾기) 또는 **수동** 일정 잡기를 사용하세요. 직원을 배정하고 방문 상태(예: **시작 안 함**, **On my way**(이동 중))도 정할 수 있어요.
7. 필요하면 체크리스트를 추가하고 **Create job**(작업 만들기)을 탭하세요.

{% hint style="info" %}
방문에는 서비스가 하나 이상 있어야 해요. 그래야 **현장 서비스**가 소요 시간과 작업할 수 있는 직원을 계산할 수 있어요. 현장 서비스의 작업 문서를 참고하세요.
{% endhint %}

이미 만든 작업이나 방문에서는 직원이 상태를 바꾸고, 체크리스트를 진행하고, 메모를 추가할 수 있어요. **타임시트**가 켜져 있으면 타이머도 시작하고 멈출 수 있어요.

## 모바일에서 일정 사용하기

1. **작업**을 열고 **일정**을 탭하세요.  
   ![모바일 일정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085125472/original/C1pC7lQjOGK5iTyzpFxZRQMG6yXt_tXzBw.png?1793965073)
2. **목록**, **주**, **지도** 보기를 오가며 확인하세요.
3. 방문 카드를 탭하면 상세 정보가 열려요. 카드에는 상태(예: **시작 안 함**), 시간 또는 **Anytime**(시간 지정 없음), 주소, 서비스, 배정된 직원이 표시돼요.

**일정**에서 하루 일정을 확인하고, 방문 사이를 이동하고, 현장에서 상태를 최신으로 유지하세요. 자세한 내용은 [현장 서비스에서 방문 일정 잡기와 가능 시간 찾기](Field-Services/scheduling-visits-and-finding-availability-in-field-services.md)와 [현장 서비스의 방문 상태](Field-Services/visit-statuses-in-field-services.md)를 참고하세요.

## 작업, 요청, 견적서, 인보이스 검색하기

1. **작업** 화면에서 **검색**을 탭하세요.
2. **작업**, **요청**, **견적서**, **인보이스** 필터를 사용하세요.
3. 결과를 탭하면 열려요.

## 자주 묻는 질문

### 앱에서 현장 서비스가 보이지 않아요.
모바일에서는 **앱 > Sales & Operations** 아래에 **작업**으로 나타나요. **작업**이 없으면 웹에서 해당 로케이션에 **현장 서비스**를 쓸 수 있는지 확인하세요. 그런 다음 앱을 새로고침하거나 로그아웃 후 다시 로그인하세요.

### 웹에서만 일하는데도 앱이 필요한가요?
아니요. 사무실 직원은 웹에서 **현장 서비스**를 모두 이용할 수 있어요. 모바일 앱은 현장 직원이나 이동 중에 **작업**과 **일정**이 필요한 분을 위한 거예요.

### 화이트라벨 앱에서도 모바일이 동작하나요?
앱 빌드와 로케이션 설정에 따라 다를 수 있어요. 화이트라벨 앱에서 **작업**이 보이지 않으면, 웹에서 해당 로케이션에 **현장 서비스**가 켜져 있는지 확인하세요. 앱 버전에 **현장 서비스**가 포함되어 있는지도 확인하세요. 그래도 나타나지 않으면 하이퍼클래스 고객지원이나 에이전시 관리자에게 문의하세요.

### 작업을 만들 수 없어요.
흔한 원인은 연락처를 선택하지 않았거나, 서비스 주소가 없거나, 방문 일정을 잡으려는데 서비스가 없는 경우예요. 이럴 때 앱에 안내 메시지가 나와요. 예를 들면 "Add a service address before saving"(저장하기 전에 서비스 주소를 추가하세요) 같은 메시지예요.

### 모바일에서 바꾼 내용이 웹에도 반영되나요?
네. 모바일 앱과 웹이 동기화되어 현장과 사무실이 같은 정보를 볼 수 있어요.
