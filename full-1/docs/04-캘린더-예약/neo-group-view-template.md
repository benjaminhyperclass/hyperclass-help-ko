# Neo 그룹 보기 템플릿 사용하기

Neo 그룹 보기 템플릿은 그룹 페이지를 더 깔끔하고 보기 좋게 보여 주는 템플릿이에요. 이 문서에서는 Neo 템플릿의 특징과 그룹 생성 방법, 캘린더 커버 이미지 올리는 방법을 안내해요.

## 그룹 템플릿 소개

이제 그룹 페이지가 고객에게 어떻게 보일지 직접 고를 수 있어요. 그룹 템플릿은 클래식과 Neo 두 가지가 있고, **템플릿** 드롭다운에서 선택해요.

## Neo 템플릿 알아보기

### 그룹 화면 새롭게 바꾸기

Neo 템플릿은 그룹을 현대적이고 산뜻하게 보여 주도록 만들었어요. 이 템플릿을 쓰면 그룹이 표시되는 방식이 달라져서 화면이 더 깔끔해지고 보기 좋아져요.

### 주요 기능

- **직원 선택**: 특정 서비스를 예약할 때 직원을 고르는 화면이 더 좋아졌어요. 캘린더 설정에서 해당 캘린더의 **직원 선택**을 켜 둔 경우에 쓸 수 있어요.
- 세련된 디자인: Neo는 깔끔하고 세련된 디자인으로 그룹을 돋보이게 해요. 보기 좋을 뿐 아니라 쓰기에도 편해요.
- 캘린더별 이미지: Neo 템플릿에서는 캘린더마다 다른 이미지를 보여 줄 수 있어요. 그룹 안의 각 캘린더에 개성을 더할 수 있어요.
- 간결한 흐름: 정보가 보이는 순서를 다듬어서, 사용자가 필요한 내용을 빠르게 찾아갈 수 있어요.

## Neo 그룹 템플릿으로 그룹 만들기

1. 캘린더 설정으로 이동해요. 보통 캘린더 메뉴나 설정 영역에서 찾을 수 있어요.
2. **캘린더 설정**에서 **그룹**을 선택해요. 이곳에서 그룹을 관리하고 새로 만들 수 있어요.
3. **그룹 생성** 버튼을 눌러 그룹 만들기를 시작해요.
4. 그룹 생성 화면에 **템플릿** 필드가 있어요. 기본값은 Neo로, 현대적인 그룹 보기를 보여 줘요. 이전 방식인 **클래식** 그룹 보기를 쓰려면 **클래식**으로 바꾸세요.
5. 템플릿 아래에서 그룹 정보를 입력해요.
   1. **그룹 이름**: 그룹 이름을 입력해요.
   2. **그룹 설명**: 그룹의 목적을 간단히 적어요.
   3. **그룹 URL**: 그룹과 관련된 URL이나 링크를 필요하면 추가해요.
6. 필요한 정보를 입력하고 원하는 템플릿(Neo 또는 **클래식**)을 고른 뒤 **만들기** 버튼을 눌러 그룹 만들기를 마쳐요.

## 템플릿 사용 순서

1. 상단 메뉴에서 **캘린더 > 캘린더 설정**으로 이동해요.
2. **그룹** 탭을 선택해요.
3. **그룹 생성** 버튼을 눌러요.

   ![그룹 생성 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155007788443/original/m7m0UCsxN5ifVb4S7oZtIUtIEldg2578QA.jpeg?1694786768)
4. 그룹 생성 팝업에서 **템플릿** 필드를 확인해요. 기본 선택은 Neo이고, 원하면 **클래식**으로 바꿀 수 있어요. 다만 Neo는 사용자 지정 범위가 훨씬 넓고 기능도 더 많아서 Neo를 권장해요.
5. **그룹 이름**, **그룹 설명**, **그룹 URL**을 입력해요.
6. **만들기**를 눌러 그룹 만들기를 마쳐요.

### 캘린더 커버 이미지 올리기

1. 캘린더 설정으로 이동해요. 보통 캘린더 메뉴나 설정 영역에서 찾을 수 있어요.
2. 기존 캘린더를 편집하거나 새 캘린더를 만들어요.
   1. 기존 캘린더에 커버 이미지를 올리려면 해당 캘린더의 **캘린더 편집**을 눌러요.
   2. 새 캘린더를 만드는 중이라면 만드는 과정에서 **고급 설정** 섹션으로 가요.
3. 사용자 지정 옵션을 열어요.
   1. **캘린더 편집** 또는 **고급 설정** 화면에서 **사용자 지정** 탭을 찾아 눌러요.
4. 캘린더 커버 이미지를 올려요.
   1. **사용자 지정** 탭에서 캘린더 커버 이미지를 올리는 옵션을 찾아요.
   2. 이 옵션을 눌러 **이미지 업로드**를 시작해요.

      ![사용자 지정 탭의 커버 이미지 업로드 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155007791989/original/8N9Jl650un5qtQiTbtJ2GmOiqjzblUIwgQ.png?1694788502)
5. 이미지를 가져올 방법을 골라요. 방법은 두 가지예요.
   1. 내 기기에서 업로드: 컴퓨터나 기기에 이미 이미지가 있다면 이 옵션으로 파일을 찾아 선택해요.
   2. Unsplash 사용: 적당한 이미지가 없다면 Unsplash 옵션으로 방대한 라이브러리에서 이미지를 검색해 고를 수 있어요.

      ![이미지 가져올 방법 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155007792056/original/U90gGm4RFXKQ3Ddq_S4VDY_n9g-Sc1trKA.png?1694788542)
6. 이미지를 고르고 올려요.
   1. 앞 단계에서 고른 방법에 따라, 기기에서 이미지를 선택하거나 Unsplash에서 이미지를 검색해요.

      ![이미지 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155007792206/original/LQgFuxbwSezrvzA75QUoGC5HJEkuKczxsg.png?1694788616)
7. 이미지를 골랐으면 **업로드** 또는 **선택** 버튼을 눌러 캘린더 커버 이미지로 추가해요.

#### Neo 템플릿 사용 시 권장 사항

Neo 템플릿을 쓸 계획이라면 캘린더 커버 이미지를 추가하는 것을 권장해요. 커버 이미지가 있으면 캘린더가 더 보기 좋고 전문적으로 보여요.

#### 그룹 캘린더를 페이지에 넣거나 링크로 보내려면 어떻게 하나요?

**캘린더 설정**으로 가서 **그룹**을 눌러요. 원하는 그룹 캘린더를 찾아 오른쪽의 점 3개 아이콘(작업 드롭다운)을 눌러요.

![그룹 캘린더의 작업 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155019265267/original/ESLOU3CpWQByoY37FeVUMsafOAIX8ewOBg.jpg?1706723359)

고객에게 보낼 때는 **예약 링크**를, 내 페이지에 캘린더를 넣을 때는 **삽입 코드**를 선택하세요.

![예약 링크와 삽입 코드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155019265330/original/5FtdaSgn1748R8zDeKkn05Bs7ao9miIPDQ.png?1706723476)

### 자주 묻는 질문

### Neo 그룹 보기 템플릿은 무엇이고, 그룹 관리에 어떤 도움이 되나요?
Neo 그룹 보기 템플릿은 캘린더 위젯을 한 단계 발전시킨 버전으로, 그룹 관리를 더 쉽게 해 줘요. 그룹 보기가 더 깔끔하고 보기 좋아져서 관리자와 고객 모두 더 편하게 쓸 수 있어요.

### 캘린더 설정에서 Neo 그룹 보기 템플릿은 어디서 선택하나요?
**캘린더 설정**에서 **템플릿** 드롭다운을 선택하세요. 여기서 그룹에 쓸 **클래식** 템플릿과 Neo 템플릿 중에 고를 수 있어요.

### Neo 그룹 보기 템플릿의 주요 기능은 무엇인가요?
서비스별 직원 선택, 세련된 디자인, 캘린더별 이미지, 간결한 정보 흐름이 주요 기능이에요. 이런 기능으로 그룹 이용 경험 전반을 개선했어요.

### Neo 그룹 보기 템플릿으로 그룹을 만들려면 어떻게 하나요?
**캘린더 설정**에서 **그룹**을 선택하고 **그룹 생성**을 눌러요. 그다음 **템플릿**에서 Neo를 고르고, 그룹 정보를 입력한 뒤 **만들기**를 누르세요.

### 그룹을 만든 뒤에도 클래식과 Neo 템플릿을 바꿀 수 있나요?
네, 그룹을 만든 뒤에도 템플릿을 바꿀 수 있어요. 그룹 설정으로 들어가서 원하는 템플릿을 선택하세요.

### Neo 템플릿에서 캘린더 커버 이미지는 어떻게 올리나요?
**캘린더 설정**으로 이동해요. 기존 캘린더라면 **캘린더 편집**을 누르고, 새 캘린더를 만드는 중이라면 **고급 설정**으로 가세요. **사용자 지정** 탭에 캘린더 커버 이미지를 올리는 옵션이 있어요.

### Neo 템플릿을 쓸 때 캘린더 커버 이미지를 추가하라고 권장하는 이유는 무엇인가요?
커버 이미지를 추가하면 캘린더가 더 보기 좋고 전문적으로 보여서 사용자의 관심을 끌 수 있어요. Neo 템플릿의 현대적이고 세련된 디자인과도 잘 어울려요.
