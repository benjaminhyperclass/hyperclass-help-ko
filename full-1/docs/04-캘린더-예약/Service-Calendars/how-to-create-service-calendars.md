# 서비스 캘린더 만들기

서비스 캘린더는 서비스업 비즈니스가 예약을 쉽게 받을 수 있도록 만든 캘린더 유형이에요. 제공하는 서비스를 카테고리별 그룹으로 묶어서, 예약 링크 하나(서비스 메뉴)에 모두 보여 줄 수 있어요.

[동영상](https://www.youtube.com/embed/09GMButNLI8?&wmode=opaque)

서비스 캘린더는 직원의 가용성과 연결돼요. 팀원을 설정하고, 서비스를 특정 그룹에 배정하고, 서비스 소요 시간을 정하고, 예약 과정에서 고객에게 결제를 받을 수 있어요.

## 서비스 캘린더 켜기

1. **캘린더 설정**으로 이동하세요.
2. **환경설정**을 클릭하세요.
3. **In-App Preferences**(앱 내 환경설정) 아래에서 **Service Menu**(서비스 메뉴) 토글을 켜세요.
4. 이제 **Create New Calendar**(새 캘린더 만들기)에 **Service Calendar**(서비스 캘린더)가 보여요.

![서비스 메뉴 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033091453/original/FqaE8bMTXyi6lqgX9uT7V25nQNKoSPi19A.jpg?1726662778)

{% hint style="info" %}
에이전시 관리자만 이 설정에 접근할 수 있어요.
{% endhint %}

## 서비스 캘린더 만드는 순서

### 1단계: 캘린더 설정으로 이동해 기본 정보 입력하기

1. 서브 계정에 로그인한 뒤 **캘린더 > 캘린더 설정**으로 이동하세요.
2. **캘린더** 탭에서 **Create Calendar**(캘린더 만들기)를 클릭하고 **Service Calendar**(서비스 캘린더)를 선택하세요.

![캘린더 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033091551/original/HDAsdcSQ3dOu9sdFP7ignfVfVADJE9sZgA.jpg?1726662868)

![서비스 캘린더 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033092938/original/5FWfiG3mXYn626AJPSaNW0OJwTZ5FZzrJg.png?1726663686)

이제 서비스 캘린더에 필요한 기본 정보를 입력해요.

- 기본 정보 입력
  - **서비스 이름**: 캘린더를 알아보기 쉬운 이름으로 지어 주세요.
  - **서비스 설명**: 캘린더가 어떤 용도인지 짧게 적어 주세요.
  - **Staff Assignment and Location**(직원 배정 및 장소): 이 서비스를 맡을 직원을 선택하세요. 직원을 선택하면 **고급 설정**에서 직원별로 원하는 미팅 장소를 설정할 수 있어요. 선택할 수 있는 **미팅 장소**는 다음과 같아요.
    - **전화번호**: 기본값은 서브 계정의 전화번호예요. 원하는 번호로 바꿀 수 있어요.
    - **주소**: 기본값은 서브 계정의 사업장 주소예요. 필요하면 다른 주소로 바꿀 수 있어요.
    - **사용자 지정**: 매장 주소, 고객에게 전할 메시지, 고정된 Zoom 링크 등 원하는 내용을 직접 입력해요.
    - **Zoom**: Zoom 연동이 되어 있으면 예약마다 고유한 Zoom 링크가 자동으로 만들어져요. **내 프로필 > 캘린더 설정 > Video Conferencing**(화상 회의)에서 Zoom이 연동되어 있는지 확인하세요.
    - **Google Meet**: Google 연동이 되어 있고 **내 프로필 > 캘린더 설정**에서 연결된 캘린더로 Google Calendar를 선택했다면, 예약마다 고유한 Google Meet 링크가 자동으로 만들어져요.

![미팅 장소 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033095010/original/mZpey4plMBvaArCKJ7OWIT6HuofvN60BvA.png?1726664808)

- **URL / Slug**(URL / 슬러그): 캘린더 링크가 될 슬러그 또는 URL을 정하세요.
- **소요 시간**: 서비스에 걸리는 시간을 지정하세요.
- **가용성**: 캘린더의 가용 시간을 설정하세요.

![소요 시간과 가용성 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033095159/original/eTd7s9WhG3rgfO21WS4R8tQaDsKTP85zBQ.jpg?1726664904)

**고급 설정** 버튼을 클릭하면 **고급 옵션**으로 서비스 캘린더를 더 세부적으로 설정할 수 있어요.

### 2단계: 서비스 상세 정보 설정하기

- **Service Logo**(서비스 로고)를 올리세요. 서비스 캘린더의 **예약 부킹** 위젯에 표시되는 이미지예요.

{% hint style="info" %}
서비스 로고는 서비스 캘린더 하나만 있는 예약 위젯에서만 보여요. 서비스 메뉴나 그룹에서는 **Service Cover Image**(서비스 커버 이미지)를 사용하세요.
{% endhint %}

![서비스 로고 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033095572/original/5LcNzaSfG6AaBEOPXClUSRxDZzPKrD3Zog.png?1726665091)

- **Link to Service Menu**(서비스 메뉴 연결): 이 서비스 캘린더를 서비스 메뉴(모든 서비스를 한 페이지에 보여 주는 화면)에 넣으려면 캘린더의 그룹을 선택하세요. 그룹은 비슷한 서비스를 묶는 카테고리라고 생각하면 돼요. 예를 들어 "헤어" 그룹을 만들고 "커트", "헤어 스파", "염색" 서비스 캘린더를 배정할 수 있어요.

{% hint style="info" %}
서비스 캘린더는 서비스 메뉴에서도, 그룹에서도 사용할 수 있어요.
{% endhint %}

![서비스 메뉴 연결과 그룹 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033095860/original/YwfWrtxRq4jH9pFrQN7YF6EVo3PCwtrRCw.png?1726665308)

- **Appointment Invite Title**(예약 초대 제목)을 직접 정할 수 있어요. Google Calendar, Outlook, Apple 캘린더 등에 표시되는 캘린더 이벤트의 제목이에요.
- **Event Color**(이벤트 색상): 이 캘린더로 만든 예약에 쓸 색상을 선택하세요. 이 색상은 하이퍼클래스 안에서만 쓰이고, Google Calendar의 이벤트에는 반영되지 않아요.

![예약 초대 제목과 이벤트 색상 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033097763/original/2oP5JpxRkPcW7ubFvgeUI2zw5i6dNLdifw.png?1726666447)

{% hint style="info" %}
서비스 캘린더는 주로 오프라인 서비스를 위해 만들어졌어요. 그래서 서비스 캘린더에는 Zoom / Google Meet을 포함한 **미팅 장소**를 추가할 수 없어요.
{% endhint %}

### 3단계: 가용성 설정하기

- **근무 시간**: 매주 반복되는 기본 근무 시간을 설정해요. 주마다 똑같이 반복되는 기본 일정을 만들 때 유용해요.
- **특정 날짜 시간**: 특정 날짜의 가용 또는 불가용 시간을 따로 정해요. 날짜를 추가하고, 그 날짜에만 적용될 시간을 지정할 수 있어요.

![근무 시간과 특정 날짜 시간 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033097990/original/_BHEdx42rSxA0g2SxkxMdaZOYaGsqGLZgg.png?1726666576)

- **소요 시간**: 예약 한 건의 길이를 설정해요.
- **서비스 간격**: 서비스 간격을 지정해요.
- **Post Buffer time**(사후 버퍼 시간): 예약이 끝난 뒤 준비나 정리를 위한 여유 시간을 추가해요.
- **최소 예약 안내 기간**: 예약 시작 몇 시간 또는 며칠 전에 예약을 마감할지 정해요.
- **날짜 범위**: 오늘부터 며칠 뒤까지 예약을 받을지 정해요.

![서비스 간격과 날짜 범위 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033098211/original/wp-_MHY5WFl4I43EAevwFHFx8rr9NHKYPQ.png?1726666731)

{% hint style="info" %}
서비스 캘린더의 슬롯 간격은 기본 15분이고, 바꿀 수 없어요.
{% endhint %}

### 4단계: 폼과 결제 설정하기

- **폼**: 고객 정보를 받는 방식을 고를 수 있어요. 이름, 이메일, 전화번호 같은 기본 정보를 받는 기본 폼을 쓰거나, 필요에 맞게 직접 만든 폼을 쓸 수 있어요. 직접 만든 폼을 쓰려면 **사이트 > 폼 > 빌더**에서 폼을 만든 뒤 캘린더의 드롭다운 메뉴에서 선택하세요. 다음 설정도 할 수 있어요.
  - 동의 체크박스를 켜거나 끌 수 있어요.
  - 동의 메시지를 원하는 문구로 바꿀 수 있어요.

{% hint style="info" %}
직접 만든 폼은 서비스 캘린더에서 바로 예약할 때만 적용돼요. 서비스 메뉴를 통한 예약에는 기본 폼이 사용돼요.
{% endhint %}

![폼 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033098469/original/_zUV3XJjjUfzDzxTyaHh_ZsTMR977KTaeg.png?1726666924)

- **Confirmation Page**(확인 페이지): 예약이 끝난 뒤 고객에게 어떻게 안내할지 정해요. 같은 페이지에 감사 메시지를 보여 주거나, 원하는 URL로 이동시킬 수 있어요.

![확인 페이지 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033098676/original/xt0pa3mm08qtUeznIyvYKYkHRhHLIiG1-Q.png?1726667018)

- **결제**: 예약 시 결제를 받으려면 결제 게이트웨이가 연동되어 있어야 해요. 연동한 뒤 결제 금액을 지정하면 결제를 받을 수 있어요. 결제는 주 참석자에게만 적용되고, 게스트에게는 적용되지 않아요.

![결제 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033098846/original/PS0Yf9pewhBAwNQjQE86b9tWrhPz7g4Rdw.png?1726667144)

### 5단계: 알림, 추가 옵션, 사용자 지정 설정하기

- **알림**: 예약 알림을 받을 사람을 선택해요. Google이 참석자에게 초대나 업데이트 이메일을 보내도록 허용할지도 정할 수 있어요. 예약이 잡힐 때마다 연락처를 해당 직원에게 배정할지도 정할 수 있어요.

![알림 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033096963/original/2ZfA1_WD1iB7_8kGksFdPqKLpw7K0rM2Eg.png?1726665961)

- **추가 메모**: 여기에 입력한 내용은 Google 초대에 포함돼요. 이 기능을 쓰려면 **알림** 설정에서 **Allow Google Calendar to Send Invitations**(Google Calendar의 초대 발송 허용)가 켜져 있어야 해요.

![추가 메모 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033097089/original/m0i1xYN9YSEZng78YCp7vwUrCnPe1pY2Eg.png?1726666049)

- **Customizations**(사용자 지정) > **Service Cover Image**(서비스 커버 이미지): 서비스 메뉴에 표시할 커버 이미지를 올려요. 이 이미지는 **Neo Group Widget**(네오 그룹 위젯)에 보여요.

![서비스 커버 이미지 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033096556/original/D3PfZA_FICm01NhsEGy5Bo9qGGSKWtk_dg.png?1726665730)

- **Staff Selection**(직원 선택): 예약하는 사람이 캘린더 위젯에서 직원을 직접 고를 수 있게 할지 켜거나 꺼요.

![직원 선택 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033096718/original/3LFpRwhqGqcq5OjQs5tvhlovTanGfZNVqQ.png?1726665821)

### 6단계: 룸과 장비 설정하기

미리 만들어 둔 룸과 장비 목록에서 선택할 수 있어요. 선택한 룸과 장비는 이 서비스 캘린더와 연결되어, 이 캘린더로 예약할 때 함께 예약돼요.

마지막으로 **저장**을 클릭하면 서비스 캘린더가 완성돼요. 이제 예약을 받을 수 있어요.

![저장 후 완성된 서비스 캘린더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033096246/original/XTBxHb8B5ZhImQPZC3--Axvyy8MVqF032A.jpg?1726665538)

## 핵심 정리

1. 이 캘린더에서는 연락처가 여러 서비스를 예약할 수 있어요. 본인이 예약하거나, 본인과 게스트 등 여러 참석자를 위해 서비스를 함께 예약할 수도 있어요.

2. 캘린더는 기본 15분 슬롯 간격으로 운영돼요. 이 간격은 고정이지만, 예약 사이에 버퍼 시간을 추가할 수 있어서 직원이 다음 고객을 준비할 시간을 확보할 수 있어요.

3. 서비스 캘린더의 가용성은 배정된 직원의 일정과 직접 연결돼요. 그래서 캘린더 가용성을 따로 설정하는 옵션은 없어요. 캘린더는 배정된 직원의 가용성만 반영해요. 직원이 특정 시간에 일할 수 없으면 캘린더에도 그 시간이 불가용으로 표시돼요. <!-- 검토 필요: 원문 내용이 서로 다름 (3단계에서는 가용성을 설정하라고 안내하고, 핵심 정리에서는 캘린더 가용성을 설정하는 옵션이 없다고 안내함) -->

4. 여러 서비스를 예약 링크 하나(서비스 메뉴)에 보여 주려면 순서가 중요해요. 먼저 원하는 그룹을 만들고, 서비스 캘린더를 만들어 각 그룹에 배정한 다음, 마지막으로 서비스 메뉴를 만드세요.

5. 서비스 메뉴는 미팅 장소를 지원하지 않아요. 서비스 캘린더에 추가한 미팅 장소는 서비스 메뉴에 적용되지 않아요.
