# 미할당 캘린더에 사용자 지정 URL 설정하기

미할당 캘린더의 공개 예약 링크에 사람이 읽기 쉬운 주소를 직접 정하는 방법을 안내해요. 링크를 공유하거나 브랜드에 맞게 관리할 때 쓰세요.

## [동영상](https://www.youtube.com/embed/Iq3eAbvZqIE?&wmode=opaque)

---

## 미할당 캘린더의 사용자 지정 URL이란?

사용자 지정 캘린더 URL을 쓰면 미할당 캘린더(Unassigned Calendar)의 공개 예약 링크에 읽기 쉬운 슬러그(URL 끝에 붙는 이름)를 직접 정할 수 있어요. 링크를 공유하고 브랜드에 맞추기 쉬워지고, 캘린더와 지점이 여러 개여도 팀이 이름을 일관되게 관리할 수 있어요.

미할당 캘린더는 예약을 특정 사용자가 아니라 담당자 풀(pool)로 배분해요. 그래서 알아보기 쉽고 기억하기 쉬운 URL은 리드의 혼란을 줄이고 예약 전환을 높이는 데 도움이 돼요.

---

## 사용자 지정 URL의 장점

사용자 지정 URL의 장점을 알아 두면 오픈 전에 이름 규칙을 정하고, 나중에 링크가 끊기는 일을 줄이고, 웹사이트·퍼널·위젯 전체에서 브랜드 경험을 일정하게 유지할 수 있어요.

- 브랜드 일관성: `/demo-call`처럼 읽기 쉽고 브랜드에 맞는 슬러그를 만들 수 있어요. 공유 링크나 임베드에서도 깔끔하게 보여요.
- 기억하기 쉬움: 짧은 슬러그는 기억하고 입력하기 쉬워서 예약 완료율을 높일 수 있어요.
- 체계적인 관리: 이름 규칙을 정해 두면 상품·지점·팀별로 여러 캘린더를 구분하기 쉬워요.
- 배분 방식 안내: 미할당 캘린더는 예약을 담당자 풀로 나눠 주기 때문에, 설명이 되는 슬러그를 쓰면 예비 고객이 어떤 예약인지 미리 알 수 있어요.
- 운영 관리: 슬러그를 미리 정해 두면 이름이 겹치는 일을 피하고, 퍼널과 자동화에서 다시 작업하는 일을 줄일 수 있어요.

---

## 미할당 캘린더 vs. 할당된 사용자 캘린더 vs. 그룹 캘린더

예약 링크가 우리 팀의 운영 방식에 맞도록 캘린더 유형을 고르세요. 아래 구분을 보고 사용자 지정 URL을 캘린더 개별 링크에 둘지, 그룹 링크에 둘지 정하면 돼요.

- 미할당 캘린더(Unassigned Calendar): 예약을 담당자 풀(라운드 로빈 등)로 배분해요. 캘린더마다 사용자 지정 URL을 정할 수 있어요.
- 할당된 사용자 캘린더(Assigned Calendar): 예약이 특정 사용자 한 명에게 바로 배정돼요. 사용자 지정 URL 옵션은 캘린더 유형에 따라 다를 수 있어요.
- 그룹 캘린더(Group Calendar): 여러 캘린더를 하나의 그룹 예약 링크로 보여 줘요. 그룹 링크는 각 캘린더의 개별 링크와 별개이고, 개별 슬러그 대신 그룹 링크를 공유할 수도 있어요.

{% hint style="info" %}
그룹 예약 페이지를 공유할 계획이라면 개별 캘린더 슬러그도 단순하고 일관되게 만드세요. 개별 슬러그가 임베드나 직접 링크에 여전히 나타날 수 있어요.
{% endhint %}

---

## 사용자 지정 URL이 나타나는 곳

슬러그가 어디에 나타나는지 알아 두면 게시 전에 확인할 곳을 정하고 팀에 변경 사항을 알리기 쉬워요.

- 단독 예약 링크: 캘린더 설정에서 복사하는 링크예요.
- 웹사이트·퍼널 임베드: 하이퍼클래스 웹사이트·퍼널이나 외부 사이트에 넣은 예약 위젯이에요.
- 버튼, 이메일, SMS: 캘린더로 바로 연결되는 모든 버튼과 링크예요.
- 그룹 페이지(사용하는 경우): 그룹 링크를 공유해도 개별 슬러그는 직접 공유하거나 테스트하는 용도로 계속 쓸 수 있어요.

## API 도메인과 브랜드 링크 (링크가 외부에 보이는 모습)

고객에게 보이는 예약 링크는 시스템이 만드는 링크에 쓰는 도메인(**API Domain**, API 도메인)과 캘린더에 정한 사용자 지정 슬러그가 합쳐진 모습이에요. 나중에 링크를 바꾸는 일이 없도록 브랜딩을 먼저 설정하세요.

- **API Domain**을 설정하면 캘린더 링크를 포함한 시스템 링크가 브랜드 도메인으로 표시돼요.
- 사용자 지정 슬러그는 해당 도메인 아래 캘린더 경로 뒤에 붙어요.
- **API Domain**을 나중에 설정하거나 바꾸면 캘린더 링크를 다시 테스트하고, 공유해 둔 링크도 수정하세요.

{% hint style="info" %}
고객에게 캘린더 링크를 배포하기 전에 **API Domain**을 먼저 확정하세요.
{% endhint %}

## 슬러그 관리와 이름 짓기 권장 사항

미리 조금만 계획해 두면 이름이 겹치거나 링크가 끊기는 일을 막을 수 있어요. 팀이 늘어도 쓸 수 있는 슬러그 체계를 아래 기준으로 만드세요.

- 슬러그는 짧게, 소문자로, 하이픈으로 연결해서 쓰세요(예: `demo-call`, `consultation`).
- 특수문자, 공백, 너무 긴 문자열은 피하세요.
- 지점이 여러 곳이거나 상품 라인이 여러 개라면 접두사를 붙이세요(예: `nyc-demo`, `plus-plan-onboarding`).
- 캘린더와 지점 전체에서 예약해 둔 슬러그를 간단한 스프레드시트나 문서로 정리해 두세요.
- 시크릿(incognito) 창에서 공개 링크가 제대로 열리는지 확인하세요.

---

## 변경 시 주의할 점과 리디렉션

슬러그를 공유한 뒤에 수정하면 이메일, 퍼널, 광고, SMS에 넣어 둔 링크가 끊길 수 있어요. 변경은 신중하게 계획하고, 사용 중인 모든 곳을 확인하세요.

- 사용자 지정 URL을 바꾸면 보통 새 공개 링크가 만들어져요. 이전에 공유한 링크는 더 이상 열리지 않을 수 있어요.
- 이름을 바꾸기 전에 링크가 쓰인 곳(웹사이트, 퍼널, 자동화, 이메일, SMS, 광고)을 모두 확인하고 전부 새 링크로 바꾸세요.
- 수정한 뒤에는 시크릿 창에서 새 링크를 테스트하고, 팀원에게도 확인을 부탁하세요.

---

## 권한과 사용 조건

필요한 권한이 있는지 먼저 확인하면 설정이 늦어지지 않아요. 누가 캘린더를 편집할 수 있는지, 그리고 우리 워크스페이스에서 브랜드 링크를 쓰는지 확인하세요.

- 서브 계정에서 **캘린더**를 보고 편집할 수 있는 권한이 있어야 해요.
- 조직에서 브랜드 **API Domain**을 쓴다면, 링크를 공유하기 전에 관리자가 설정을 마쳤는지 확인하세요.

## 미할당 캘린더에 사용자 지정 URL 설정하기

미할당 캘린더에서 사용자 지정 슬러그를 만들거나 편집하는 방법이에요. 순서대로 진행하고, 저장하기 전에 사용 가능한 URL인지 확인하세요.

1. 서브 계정에서 **설정 > 캘린더**로 이동하세요.

   ![설정 > 캘린더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063212631/original/OjCptXo8bg2F-SYBMJm-ygWVSSxwIdCHkg.png?1769067058)
2. **Create Calendar**(캘린더 만들기)를 클릭하세요. 기존 미할당 캘린더를 편집하려면 해당 캘린더를 여세요.
3. **Calendar Type**(캘린더 유형)에서 **Unassigned Booking**(할당되지 않은 예약)을 선택하세요.

   ![캘린더 유형에서 Unassigned Booking 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063212682/original/JTRXmQrpg9azhewqEsPA7joZvZkqcAP1og.png?1769067087)
4. **Team & Event Setup**(팀 및 이벤트 설정)에서 **사용자 지정 URL** 필드를 찾으세요.
5. **캘린더 URL** 앞에 있는 입력란을 클릭하고, 캘린더 링크에 쓰고 싶은 사용자 지정 캘린더 URL을 입력하세요. <!-- 검토 필요: 원문 내용이 서로 다름 (4단계는 '사용자 지정 URL' 필드, 5단계는 '캘린더 URL' 입력란으로 표기) -->

   ![사용자 지정 캘린더 URL 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033268058/original/bBNn3wrUnf3ZBJnGDEYnsdMH3FwSuhjjvg.png?1726847577)
6. URL을 입력하면 시스템이 사용할 수 있는 URL인지 확인해요. 사용할 수 있으면 체크 표시가 나타나고, 이때 저장하면 돼요.

   ![사용 가능한 URL에 나타나는 체크 표시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033268054/original/HfdADm2PoHijorPEvGt_okFCYIeodKFR6A.png?1726847576)
7. 간혹 엑스 표시가 나타날 수 있어요. 이미 사용 중인 URL이라는 뜻이에요. 다른 URL과 겹치지 않게 수정해서 다시 입력하세요.

   ![사용할 수 없는 URL에 나타나는 엑스 표시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033268055/original/cno95_6wtgZS0_7HSd2syNWZj8_nAc17nA.png?1726847576)
8. 캘린더를 저장하세요. 캘린더 URL이 설정한 대로 저장돼요.

## 예약 링크 확인하고 공유하기

공유하기 전에 간단히 확인하면 잘못되었거나 끊어진 링크를 공유하는 일을 막고, 브랜딩이 의도한 대로 보이는지 확인할 수 있어요.

- 복사한 링크를 시크릿(incognito)·비공개 모드에서 열어 보세요.
- 링크가 브랜드 **API Domain**(설정했다면) 아래에 표시되는지 확인하세요.
- 테스트 예약을 하나 만들어 페이지가 잘 열리고 배분이 제대로 되는지 확인하세요.
- 필요하면 웹사이트·퍼널, 이메일·SMS, 광고, 챗봇에 넣은 링크를 모두 새 링크로 바꾸세요.

## 문제 해결

관리자에게 문의하기 전에 아래 내용으로 흔한 문제를 해결해 보세요.

- **URL not available**(사용할 수 없는 URL): 다른 슬러그를 고르거나 이름 규칙을 적용하세요(예: 지점이나 상품 접두사 추가).
- 유효성 검사가 실패해요: 공백과 특수문자를 지우고 소문자와 하이픈만 쓰세요.
- 브랜드 도메인으로 링크가 열리지 않아요: **API Domain**이 설정되어 적용됐는지 확인하세요. 설정이 끝난 뒤에 링크를 다시 복사하세요.
- 사용자가 편집할 수 없어요: 해당 사용자에게 서브 계정의 **캘린더** 관리 권한이 있는지 확인하세요.

## 자주 묻는 질문

### 사용자 지정 URL은 에이전시 전체에서 고유해야 하나요, 아니면 이 서브 계정 안에서만 고유하면 되나요?
캘린더가 있는 범위 안에서 슬러그가 겹치지 않아야 한다고 생각하세요. 슬러그가 사용할 수 없다고 나오면 다른 이름으로 바꿔 입력하세요.

### 슬러그에 어떤 문자를 쓸 수 있나요?
소문자와 하이픈을 쓰세요. 공백, 특수문자, 너무 긴 문자열은 피하는 것이 좋아요.

### 서로 다른 캘린더에 같은 슬러그를 쓸 수 있나요?
캘린더를 만드는 위치에서 이미 쓰고 있는 슬러그라면 사용할 수 없다는 표시가 나타나요. `-team`이나 지점 접두사를 붙이는 식으로 다른 이름을 쓰세요.

### 나중에 슬러그를 바꾸면 어떻게 되나요?
이전에 공유한 링크가 열리지 않을 수 있어요. 이메일, SMS, 퍼널, 웹사이트, 광고에 넣은 링크를 모두 바꾸고, 새 링크를 시크릿 창에서 테스트하세요.

### 사용자 지정 URL에 브랜드 도메인이 자동으로 적용되나요?
**API Domain**을 설정했다면 캘린더 링크에도 그 도메인이 반영돼요. 링크를 배포하기 전에 브랜딩을 먼저 설정하면 일관된 경험을 줄 수 있어요.

### 그룹 캘린더에서는 어떻게 되나요?
그룹 캘린더에는 별도의 그룹 예약 링크가 있어요. 미할당 캘린더의 개별 링크도 쓸 수 있지만, 많은 팀이 외부에는 그룹 링크를 공유해요.

### 공유할 링크는 어디에서 찾나요?
캘린더를 열고 **링크 복사**를 클릭하세요. 공유하기 전에 시크릿 창에서 테스트하세요.

### 사용자 지정 URL을 적용한 캘린더를 내 웹사이트에 임베드할 수 있나요?
네. 하이퍼클래스 웹사이트·퍼널에서 캘린더 임베드 위젯을 쓰거나, 임베드를 지원하는 외부 사이트에 링크를 붙여 넣으세요.
