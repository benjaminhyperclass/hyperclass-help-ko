# 모바일에서 사용자 이름(username)으로 WhatsApp 연락처에 메시지 보내기

하이퍼클래스 모바일 앱에서 전화번호가 저장되어 있지 않아도, 이미 등록된 WhatsApp 사용자 이름(username) 연락처에 바로 메시지를 보낼 수 있어요. 모바일 앱 4.23.0 버전 이상에서 사용할 수 있어요.

## 이 기능으로 할 수 있는 일

저장된 전화번호가 없어도 WhatsApp 연락처를 **@username**으로 선택해 메시지를 보낼 수 있어요. 한 연락처에 일치하는 WhatsApp 사용자 이름과 전화번호가 모두 있으면, 모바일 앱이 이 둘을 하나의 받는 사람으로 묶어서 보여 줘요. 같은 사람이 두 번 나오지 않아요.

모바일 앱은 WhatsApp의 24시간 메시징 창과 예약 발송 제한도 올바른 사용자 이름 수신처를 기준으로 확인해요. 그래서 모바일과 웹에서 WhatsApp를 비슷하게 쓸 수 있어요.

## 사용 가능 여부

- 모바일 앱 4.23.0 버전 이상에서 사용할 수 있어요.
- 상태는 프로덕션이에요.
- 하이퍼클래스 모바일 앱과 화이트라벨 모바일 앱에서 지원해요.

## 모바일의 WhatsApp 사용자 이름 메시지란?

모바일의 WhatsApp 사용자 이름 메시지는, 하이퍼클래스에 전화번호가 저장되어 있지 않은 기존 WhatsApp 연락처도 **@username**으로 선택해 메시지를 보낼 수 있게 해 주는 기능이에요. WhatsApp의 사용자 이름 기반 연락 방식을 지원하면서, 받는 사람을 고르는 방법과 메시지 동작을 모바일과 웹에서 같게 맞췄어요.

이전에는 사용자 이름만 있는 연락처가 모바일 앱에서 사용할 수 없는 것처럼 보일 수 있었어요. 전화번호와 일치하는 WhatsApp 사용자 이름이 모두 있는 연락처도 **받는사람** 선택기에서 서로 다른 받는 사람으로 나뉘어 보일 수 있었어요.

- 사용자 이름만 있는 WhatsApp 연락처도 받는 사람으로 선택할 수 있어요.
- 일치하는 전화번호와 사용자 이름은 하나의 받는 사람 항목으로 합쳐져요.
- @username이 기본 수신처로 표시돼요.
- 전화번호가 있으면 그 아래에 함께 표시돼요.
- 메시징 창과 예약 발송 규칙은 올바른 사용자 이름 수신처를 기준으로 확인해요.

{% hint style="warning" %}
이 기능으로 임의의 WhatsApp 사용자 이름을 검색할 수는 없어요. 계정에서 이미 알고 있거나 수집된 WhatsApp 사용자 이름 연락처에만 메시지를 보낼 수 있어요.
{% endhint %}

## 이런 점이 좋아요

전화번호를 공유하지 않는 연락처에도 모바일에서 메시지를 보낼 수 있어요. 한 연락처에 WhatsApp 식별자가 여러 개 있을 때도 받는 사람을 더 쉽게 고를 수 있어요.

- 더 많은 연락처에 도달: 전화번호 없이 사용자 이름만 있는 기존 WhatsApp 연락처에도 메시지를 보낼 수 있어요.
- 헷갈리지 않는 선택: 일치하는 사용자 이름과 전화번호가 중복 항목 없이 하나의 받는 사람으로 나와요.
- 선택 실수 감소: 합쳐진 받는 사람 정보를 보고 올바른 WhatsApp 수신처를 고르기 쉬워요.
- 정확한 시점 판단: WhatsApp의 24시간 메시징 창을 올바른 사용자 이름 수신처 기준으로 확인해요.
- 정확한 예약 발송: WhatsApp 예약 발송 제한이 선택한 사용자 이름 수신처에 적용돼요.
- 일관된 사용 경험: 모바일의 사용자 이름 처리와 병합 방식이 지원되는 웹 동작과 같아요.
- 막히는 상황 감소: 이미 아는 연락처가 전화번호가 없다는 이유만으로 모바일에서 사용할 수 없던 문제가 없어졌어요.

## WhatsApp 사용자 이름 연락처의 동작 방식

WhatsApp 사용자 이름을 쓰면 화면에 보이는 전화번호에만 의존하지 않고도 연락처와 대화할 수 있어요. 하이퍼클래스가 연락처의 사용자 이름 기반 WhatsApp 식별 정보를 알고 있으면, 지원되는 범위에서 그 정보를 메시지 수신처로 쓸 수 있어요.

WhatsApp 사용자 이름 연락처는 다음 중 하나일 수 있어요.

- 전화번호 없이 WhatsApp 사용자 이름만 있는 경우
- WhatsApp 사용자 이름과 일치하는 전화번호가 함께 있는 경우
- 사용자 이름 수신처와 연결된 기존 WhatsApp 대화 기록이 있는 경우

이 스크린샷은 WhatsApp 사용자 이름을 식별하는 배경 설명용이에요. 이번 릴리스에서 받는 사람 선택은 지원되는 모바일 앱에서 이루어져요.
{% endhint %}

## 모바일에서 WhatsApp 사용자 이름 연락처가 보이는 방식

모바일의 **받는사람** 선택기는 연락처에 저장된 WhatsApp 정보에 맞춰 받는 사람 표시를 바꿔요. 그래서 사용자 이름만 있는 연락처에도 메시지를 보낼 수 있고, 식별자가 여러 개인 연락처의 중복 선택지는 줄어들어요.

### 사용자 이름만 있는 연락처

이미 알고 있는 WhatsApp 연락처에 사용자 이름만 있고 전화번호가 없으면, 모바일 앱이 @username을 받는 사람으로 보여 줘요. 이제 전화번호가 없다는 이유만으로 알고 있는 사용자 이름 연락처를 사용할 수 없는 상태가 되지 않아요.

### 사용자 이름과 전화번호가 일치하는 연락처

WhatsApp 사용자 이름과 전화번호가 같은 연락처의 수신처를 나타내면, 모바일 앱이 이 둘을 하나의 받는 사람 행으로 합쳐요.

- @username이 기본 식별자로 표시돼요.
- 일치하는 전화번호는 그 아래에 표시돼요.

{% hint style="info" %}
받는 사람을 합치면 **받는사람** 선택기에 수신처가 표시되는 방식만 바뀌어요. 연락처에 저장된 전화번호는 삭제되지 않아요.
{% endhint %}

## WhatsApp 메시징 창, 템플릿, 예약 발송

사용자 이름으로 보내는 메시지도 다른 WhatsApp 대화와 같은 WhatsApp 커뮤니케이션 규칙을 따라요. 사용자 이름은 받는 사람을 식별하는 방식만 바꿀 뿐, 고객 서비스 창, 템플릿 요건, 예약 발송 제한을 건너뛰게 해 주지는 않아요.

### 24시간 고객 서비스 창

24시간 고객 서비스 창은 자유 형식의 WhatsApp 답장을 언제 보낼 수 있는지 정해요. 이번 모바일 업데이트로 이 창을 올바른 사용자 이름 수신처 기준으로 확인해요.

### WhatsApp 템플릿

고객 서비스 창이 닫혀서 자유 형식 메시지를 보낼 수 없으면, 해당하는 경우 승인된 WhatsApp 템플릿이 필요해요. @username을 선택해도 템플릿 승인이나 메시지 전송 요건은 면제되지 않아요.

### 예약 발송 메시지

예약 발송도 이제 올바른 사용자 이름 수신처를 기준으로 확인해요. 자유 형식 WhatsApp 메시지는 예약한 발송 시각에도 해당 고객 서비스 창이 열려 있어야 해요. 발송 시각이 자유 형식 메시지를 보낼 수 있는 창을 벗어나면, 필요한 경우 승인된 WhatsApp 템플릿을 사용하세요.

## 사용자 이름 연락처 수집과 모바일 사용자 이름 메시지의 차이

사용자 이름 연락처 수집과 모바일 사용자 이름 메시지는 WhatsApp 연락처 흐름에서 서로 다른 부분을 맡아요. 연락처 수집은 사용자 이름 기반 연락처를 만들거나 식별하고, 모바일 사용자 이름 메시지는 앱에서 대화할 때 그렇게 알려진 수신처를 선택할 수 있게 해 줘요.

| 기능 | 용도 |
| --- | --- |
| 사용자 이름 연락처 수집 | 지원되는 WhatsApp 활동을 통해 사용자 이름 기반 연락처를 만들거나 식별해요. |
| 모바일 사용자 이름 메시지 | 모바일에서 알려진 사용자 이름 연락처를 WhatsApp 받는 사람으로 선택할 수 있어요. |
| 받는 사람 병합 | 일치하는 사용자 이름과 전화번호를 하나의 받는 사람 옵션으로 합쳐요. |
| 창 확인 | WhatsApp 메시징 규칙을 올바른 사용자 이름 수신처에 적용해요. |

### 아무 WhatsApp 사용자 이름에나 메시지를 보낼 수 있나요?

아니요. 이번 릴리스에서는 임의의 WhatsApp 사용자 이름을 조회하거나, 사용자 이름만으로 먼저 연락하는 기능을 제공하지 않아요. @username은 지원되는 WhatsApp 활동을 통해 계정이 이미 알고 있는 WhatsApp 연락처여야 해요.

## 사용 가능 여부와 요건

먼저 모바일 앱 버전과 받는 사람 요건을 확인하세요. 오래된 앱 동작을 WhatsApp나 연락처 설정 문제로 오해하는 일을 막을 수 있어요.

| 요건 | 세부 내용 |
| --- | --- |
| 최소 모바일 버전 | 4.23.0 이상 |
| 상태 | 프로덕션 |
| 하이퍼클래스 모바일 앱 | 지원 |
| 화이트라벨 모바일 앱 | 지원 |
| 받는 사람 요건 | 계정이 이미 알고 있는 기존 WhatsApp 사용자 이름 연락처 |
| 전화번호 필요 여부 | 알려진 사용자 이름만 있는 연락처는 필요 없어요 |
| 메시지 규칙 | 일반 WhatsApp 메시징 창과 템플릿 요건이 그대로 적용돼요 |

## 모바일에서 사용자 이름으로 WhatsApp 연락처에 메시지 보내기

사용자 이름 메시지를 위해 따로 설정할 것은 없어요. 지원되는 모바일 버전이 설치되어 있고 WhatsApp 사용자 이름 연락처를 계정이 이미 알고 있다면, **대화**에서 바로 수신처를 선택할 수 있어요.

### 1단계: 모바일 앱 버전 확인하기

4.23.0 버전 이상에 이번 릴리스에서 추가된 사용자 이름 받는 사람 처리가 들어 있어요. 먼저 버전을 확인하면 오래된 앱 때문에 생기는 문제인지 가려낼 수 있어요.

1. 설치된 모바일 앱 버전을 확인하세요.
2. 앱 버전이 **4.23.0**보다 낮으면 앱을 업데이트하세요.
3. 업데이트한 뒤 앱을 다시 여세요.

### 2단계: 대화 열기

**대화**에서 WhatsApp 받는 사람 선택기와 연락처의 기존 메시지 기록을 확인할 수 있어요.

1. 모바일 앱에서 해당하는 서브 계정을 여세요.
2. **대화**로 이동하세요.
3. 기존 대화를 열거나 새 메시지를 시작하세요.

### 3단계: 받는사람 선택기 열기

**받는사람** 선택기에는 그 연락처에 사용할 수 있는 알려진 수신처가 표시돼요. 사용자 이름을 인식하는 받는 사람 처리 덕분에, 전화번호가 저장되어 있지 않아도 기존 WhatsApp 사용자 이름을 선택할 수 있어요.

1. **받는사람** 선택기를 탭하세요.
2. 연락처를 검색하세요.
3. 해당하는 @username을 찾으세요.

일치하는 전화번호도 알려져 있다면 별도의 중복 항목이 아니라 사용자 이름 아래에 함께 표시돼요.

### 4단계: 사용자 이름 수신처 선택하기

사용자 이름을 선택하면 모바일 앱은 어떤 WhatsApp 수신처로 메시지를 보낼지, 어떤 메시징 창 상태를 확인할지 알 수 있어요.

1. 알맞은 @username을 탭하세요.
2. 의도한 연락처가 선택되었는지 확인하세요.
3. 표시되는 메시지 작성창을 확인하세요.

### 5단계: 메시지 작성하기

보낼 수 있는 메시지 유형은 연락처의 현재 WhatsApp 메시징 창 상태에 따라 달라져요. 사용자 이름을 지원하더라도 WhatsApp의 기본 커뮤니케이션 요건은 바뀌지 않아요.

- 고객 서비스 창이 열려 있는 동안에는 보낼 수 있는 자유 형식 메시지를 사용하세요.
- 템플릿이 필요한 경우에는 승인된 WhatsApp 템플릿을 사용하세요.

### 6단계: 메시지 보내기 또는 예약하기

메시지를 보내거나 예약하면 선택한 사용자 이름 수신처와 그에 해당하는 WhatsApp 시간 상태가 적용돼요.

1. 선택한 받는 사람을 다시 확인하세요.
2. 메시지를 바로 보내거나, 사용할 수 있으면 예약 발송을 사용하세요.
3. 자유 형식 메시지를 예약한다면 발송 시각이 허용된 WhatsApp 메시징 창 안에 있는지 확인하세요.

## 문제 해결

사용자 이름 메시지 문제는 대부분 모바일 버전을 확인하고, 연락처가 이미 WhatsApp 사용자 이름 연락처로 알려져 있는지 확인하고, 일반 WhatsApp 메시징 창 요건을 살펴보면 원인을 좁힐 수 있어요.

| 문제 | 확인할 내용 |
| --- | --- |
| 사용자 이름만 있는 연락처를 사용할 수 없는 것처럼 보여요 | 모바일 앱이 4.23.0 버전 이상인지, 그리고 연락처가 이미 WhatsApp 사용자 이름 연락처로 인식되어 있는지 확인하세요. |
| **받는사람** 선택기에 사용자 이름이 나타나지 않아요 | 지원되는 WhatsApp 활동으로 해당 연락처의 사용자 이름이 이전에 수집되었거나 식별되었는지 확인하세요. |

## 자주 묻는 질문

### 전화번호 없이 사용자 이름만 있는 WhatsApp 연락처에도 메시지를 보낼 수 있나요?

네. 모바일 앱 4.23.0 버전 이상에서는 기존 WhatsApp 사용자 이름 연락처를 전화번호 없이 받는 사람으로 선택할 수 있어요.

### 아무 WhatsApp 사용자 이름이나 검색해서 대화를 시작할 수 있나요?

아니요. 이 기능은 임의의 WhatsApp 사용자 이름 조회를 제공하지 않아요. 사용자 이름은 계정이 이미 알고 있는 WhatsApp 연락처의 것이어야 해요.

### 연락처에 사용자 이름과 전화번호가 모두 있는데 받는 사람이 하나만 보여요. 왜 그런가요?

사용자 이름과 전화번호가 같은 WhatsApp 연락처에 해당하면, 모바일이 이 둘을 하나의 @username 행으로 합치고 그 아래에 전화번호를 표시해요.

### 받는 사람 항목을 합치면 연락처에서 전화번호가 삭제되나요?

아니요. 합치면 **받는사람** 선택기에서 받는 사람 옵션이 표시되는 방식만 바뀌어요. 저장된 전화번호는 삭제되지 않아요.

### 사용자 이름으로 보내면 WhatsApp 24시간 고객 서비스 창을 건너뛸 수 있나요?

아니요. 사용자 이름 기반 연락처도 해당되는 WhatsApp 메시징 창 요건을 똑같이 따라요.

### 사용자 이름 연락처에도 승인된 WhatsApp 템플릿을 쓸 수 있나요?

네. 선택한 사용자 이름 수신처에도 일반 WhatsApp 템플릿 요건이 그대로 적용돼요.

### 사용자 이름 연락처에 WhatsApp 메시지를 예약해 보낼 수 있나요?

네, 예약 발송이 허용되는 경우에는 가능해요. 자유 형식 예약 메시지에는 메시징 창 제한이 그대로 적용돼요.

### 화이트라벨 모바일 앱에서도 이 기능을 쓸 수 있나요?

네. 해당 버전의 하이퍼클래스 모바일 앱과 화이트라벨 모바일 앱에서 지원해요.
