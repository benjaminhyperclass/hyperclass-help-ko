# 한 서브 계정에서 여러 지점의 리스팅 관리하기

여러 지점의 온라인 리스팅을 한곳에서 관리하고 한꺼번에 수정하는 기능을 소개해요. 에이전시나 지점이 많은 비즈니스가 지점별 리스팅을 빠르고 일관되게 관리할 때 쓰면 좋아요.

[동영상](https://www.youtube.com/embed/gnwM1An854U?&wmode=opaque)

**온라인 리스팅**에서 여러 지점의 리스팅을 한 화면에서 모아 보고, 한 번에 제어하고, 효율적으로 살펴볼 수 있어요.

## 주요 기능과 장점

1. 엔티티 통합 관리: 비즈니스 하나에 딸린 여러 리스팅을 쉽게 관리해요. 다중 엔티티 대시보드에서는 모든 지점이 기본 정보를 공유하면서도, 지점마다 다른 항목은 따로 설정할 수 있어요.
2. 일괄 수정: 주소, 업종, 서비스 같은 지점 정보를 한 번에 업데이트해요. 공통 항목은 한꺼번에, 지점별 항목은 따로 고쳐서 변경 작업을 빠르게 끝낼 수 있어요.
3. 여러 지점의 실시간 성과 확인: 모든 지점의 성과를 한 번에 볼 수 있어요. 통합 성과 지표로 지점별 상황을 살펴보고, 신경 써야 할 부분을 빠르게 찾아보세요.

## 사용 방법

### 1. 리스팅 만들기

1. **Create Listing**(리스팅 만들기)을 클릭해요.
2. 지점별로 수정할 수 있는 항목이 미리 채워진 폼이 나타나요. 엔티티 정보를 지점에 맞게 고쳐 주세요.
3. 새로 만든 리스팅은 대시보드에 바로 표시돼서 곧바로 확인할 수 있어요.

### 2. 통합 대시보드

- 모든 리스팅을 한 화면에서: 모든 지점을 한곳에서 관리해요. 리스팅 카드마다 수정, 구독 해지 같은 빠른 작업 버튼이 있어요.
- 개별 수정과 일괄 수정: 리스팅을 하나씩 수정할 수도 있고, 여러 개를 선택해 공통 항목을 한꺼번에 고칠 수도 있어요.

### 3. 일괄 수정 흐름

1. **엔티티 선택**: 업데이트가 필요한 지점을 여러 개 선택해요.
2. 수정할 항목 선택: 선택한 리스팅에서 바꿀 항목을 골라요.
3. 변경 내용 미리보기와 **변경사항 확인**: 변경 내용을 살펴본 뒤 **변경사항 확인**을 선택해 한 번에 마무리해요. 작업이 끝나면 알림으로 알려 줘요.

## 이 기능의 장점

1. 높은 효율: 같은 작업을 반복하지 않고도 여러 리스팅을 관리하고, 업데이트하고, 추적할 수 있어요.
2. 일관된 브랜딩과 데이터: 모든 리스팅을 같은 기준으로 맞추면서, 지점별로 다르게 설정할 여지도 남겨 둘 수 있어요.
3. 활용도 높은 분석: 모든 지점의 성과 지표를 보고 데이터에 근거해 의사결정하고, 전략을 더 잘 맞출 수 있어요.
