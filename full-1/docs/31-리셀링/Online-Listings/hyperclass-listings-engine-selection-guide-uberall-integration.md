# 리스팅 엔진 선택 가이드: Uberall 연동

Uberall은 하이퍼클래스의 모든 에이전시에서 쓸 수 있는 로컬 리스팅 관리 플랫폼이에요. 이 문서에서는 Uberall과 Yext 중 리스팅 엔진을 고르고 설정하는 방법을 안내해요. 에이전시 관리자만 설정할 수 있어요.

[동영상](https://www.youtube.com/embed/yy7KVNxj7c0?&wmode=opaque)

---

## Uberall이란?

Uberall은 여러 지점을 운영하는 비즈니스를 위한 글로벌 리스팅 관리 엔진이에요. 검색 엔진, 디렉터리, 지도, 앱 전반에서 비즈니스 정보를 정확하게 실시간으로 노출하도록 도와줘요. 고객사 전체의 로컬 SEO를 한곳에서 관리하는 도구라고 생각하면 돼요.

## Uberall의 주요 장점

- 퍼블리셔 범위: Google, Bing, Facebook, Apple Maps, TomTom 등이 포함된 폭넓은 [퍼블리셔 네트워크](https://uberall.com/en-us/directories/products)를 지원해요.
- 지원 지역: 47개국에서 리스팅을 관리할 수 있어요.
- 대규모 중복 방지: 중복 콘텐츠를 자동으로 찾아서 차단해요.
- 낮은 엔티티 충돌: 기존 시스템에 비해 게시 충돌이 생길 가능성이 크게 줄어요.
- GDPR, ISO, PCI 준수: 글로벌 보안·개인정보 보호 기준에 맞게 만들어졌어요. [자세히 알아보기](https://uberall.helpjuice.com/en_US/userrights/security-and-compliance-at-uberall)
- 작업 관리 및 데이터 정리 도구: 여러 플랫폼에 걸친 지점 정보 업데이트를 표준화하고 간소화해 줘요.

## Yext와 Uberall 중 무엇을 고를까요?

| 항목 | Uberall | Yext |
| --- | --- | --- |
| 엔티티 충돌 위험 | 낮음 | 중간 |
| 중복 방지 | 자동 | 수동 |
| 작업 관리 및 데이터 정리 도구 | 있음 | 일부 지원 |
| 지역 범위(47개국) | 지원 | 지원 |
| 50개 미만 지점의 중소기업 지원 | 지원 | 지원 |
| 보안 및 규정 준수 | GDPR, ISO, PCI | HIPAA, ISO |
| 고객 지원 | 밀착 지원 | 밀착 지원 |

{% hint style="info" %}
수작업을 줄이고, 글로벌 디렉터리를 폭넓게 지원받고, 자동화로 더 빠르게 확장하는 것이 중요하다면 Uberall을 선택하세요.
{% endhint %}

## 가격

에이전시가 Uberall을 선택하든 Yext를 선택하든 가격은 같아요. 리스팅 상품은 아래 요금으로 구독할 수 있어요.

- 1개월 $30
- 6개월 $150
- 12개월(1년) $300

가격 때문에 제약받지 않고, 고객사에 가장 잘 맞는 엔진을 자유롭게 고를 수 있어요.

## 이미 구독 중인 엔티티는 어떻게 되나요?

이미 리스팅을 구독 중인 비즈니스 엔티티가 있다면 다음과 같아요.

- 기존 엔티티는 지금 쓰는 엔진(Yext 또는 Uberall)에서 그대로 작동해요.
- 엔진 선택은 선택한 이후에 새로 만드는 엔티티에만 적용돼요.
- 기존 엔티티를 다른 엔진으로 옮기려면 다음 순서로 진행하세요.
  1. 현재 엔진에서 **구독 취소**를 해요.
  2. 에이전시 수준의 엔진을 바꾼 뒤 다시 구독해요.

## 시작하기

### 엔진 선택 (에이전시 수준 설정)

리스팅에 처음 들어가면 Uberall과 Yext 중 리스팅 관리 엔진을 고르는 선택 창이 나타나요.

{% hint style="warning" %}
선택한 엔진은 에이전시의 모든 서브 계정과 그 서브 계정이 관리하는 비즈니스 엔티티에 적용돼요. 같은 에이전시에서 두 엔진을 동시에 쓸 수는 없어요.
{% endhint %}

### 체크박스로 확인하기

엔진을 선택하면 아래 문구에 체크해서 확인해야 해요.

*"I understand that this engine will be the default for all new entities my subaccounts create, and agree to move forward with this selection"*
(이 엔진이 서브 계정에서 새로 만드는 모든 엔티티의 기본 엔진이 된다는 점을 이해하며, 이 선택으로 진행하는 데 동의합니다.)

## 리스팅 엔진 선택 방법 (에이전시 수준 설정)

{% hint style="info" %}
엔진 선택은 에이전시 수준에서만 할 수 있어요. 에이전시 아래에 새로 만드는 서브 계정과 비즈니스 엔티티는 이 엔진을 자동으로 따라가요.
{% endhint %}

아래 순서대로 리스팅 엔진을 설정하세요.

#### 1단계: **재판매** 열기

1. 하이퍼클래스에 로그인해서 에이전시 대시보드로 이동하세요.
2. 왼쪽 메뉴에서 **재판매**를 클릭하세요.

![재판매 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050909949/original/6G2a7vkphBRq_j_nts3Oea9ddmvJOxrcAw.png?1754331013)

#### 2단계: 선택 창 열기

1. 아래로 스크롤해서 **리스팅** 카드를 찾으세요.
2. **Change Engine**(엔진 변경)을 클릭해서 선택 창을 여세요.

![리스팅 카드의 엔진 변경 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050910010/original/RqG6H1Jc5eovWK4mYdx4bzhNVD04yq2d1g.png?1754331131)

#### 3단계: 사용할 엔진 선택

1. Uberall과 Yext의 주요 장점과 차이점을 나란히 비교한 화면이 보여요.
2. 사용할 엔진을 선택하세요.
3. 안내 문구를 읽고 체크박스에 체크해서 확인하세요.

{% hint style="warning" %}
서브 계정에는 항상 화이트라벨 버전의 리스팅이 보여요. 그래서 서브 계정 사용자는 어떤 엔진을 쓰는지 알 수 없고, 에이전시가 선택한 엔진으로 운영되는 리스팅 화면만 보게 돼요.
{% endhint %}

#### 4단계: 리스팅 엔진 확인

확인을 마치면 **리스팅** 카드에 선택한 엔진이 **Powered by Uberall**(Uberall 제공) 또는 **Powered by Yext**(Yext 제공)로 표시돼요.

![선택한 엔진이 표시된 리스팅 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050910088/original/S8zfrWmqH_OB_ePgMEwtMzCPJaD2k9YKZg.png?1754331271)

## 나중에 엔진 바꾸기

엔진은 처음 선택하면 고정되지만, 같은 엔진 선택 창에서 새 엔티티에 적용할 엔진을 변경 요청할 수 있어요. 다음 내용을 참고하세요.

- 기존 엔티티는 모두 지금 쓰는 엔진에서 계속 활성 상태로 유지돼요. 새 엔진으로 바꾸려면 한 엔진의 구독을 취소하고 다른 엔진에서 다시 활성화해야 하는데, 이 과정에서 퍼블리셔 데이터 동기화가 늦어질 수 있기 때문이에요.
- 새로 선택한 엔진은 이후 새로 구독하는 모든 엔티티에 적용돼요.

## 자주 묻는 질문

### 일부 서브 계정은 Uberall을 쓰고 다른 서브 계정은 Yext를 쓸 수 있나요?
아니요. 같은 에이전시에서 두 엔진을 동시에 쓸 수 없어요. 나중에 엔진을 바꿀 수는 있지만, 서브 계정별이 아니라 에이전시 수준에서 바뀌어요.

### 엔진을 바꾸면 지금 쓰는 리스팅은 어떻게 되나요?
기존 리스팅은 지금 쓰는 엔진(Yext 또는 Uberall)에서 그대로 작동해요. 엔진 선택은 선택한 이후에 새로 만드는 엔티티에만 적용돼요.

### 고객사에 Uberall이나 Yext 브랜드가 보이나요?
서브 계정에는 항상 화이트라벨 버전의 리스팅이 보여요. 그래서 어떤 엔진을 쓰는지 이름이 노출되지 않아요.
