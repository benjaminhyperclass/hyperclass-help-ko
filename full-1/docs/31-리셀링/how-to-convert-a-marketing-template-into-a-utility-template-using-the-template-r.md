# 마케팅 템플릿을 유틸리티 템플릿으로 바꾸기

**Template Rewriter**(템플릿 재작성 도구)를 쓰면 템플릿 내용을 고쳐서 다른 카테고리로 다시 제출할 수 있어요. 이 문서에서는 마케팅 템플릿을 유틸리티 템플릿으로 바꿔 다시 제출하는 방법을 영상으로 안내해요.

## FAQ

### 템플릿 카테고리를 마케팅에서 유틸리티로 바로 바꿀 수 있나요?
아니요. WhatsApp에서는 카테고리를 바로 바꿀 수 없어요. **Template Rewriter**로 템플릿을 수정해서 다시 제출해야 해요.

### 유틸리티로 바꾼 템플릿에도 기존과 같은 이름을 쓸 수 있나요?
이미 마케팅 템플릿으로 승인된 템플릿이라면, 수정한 유틸리티 템플릿에는 다른 이름을 써야 해요.

### Meta가 다시 쓴 템플릿을 승인하는 데 얼마나 걸리나요?
승인까지 최대 24~48시간이 걸릴 수 있어요. 내용이 규정에 맞는 것이 분명하면 보통 더 빨리 끝나요.

### 템플릿이 또 거절되면 어떻게 하나요?
WhatsApp 템플릿 대시보드에서 거절 사유를 확인하세요. 내용을 더 다듬은 뒤 다시 제출하면 돼요.

### 유틸리티 템플릿은 비용이 더 적게 들거나 발송 규칙이 다른가요?
네. 24시간 서비스 창 안에서 보내는 유틸리티 템플릿은 무료인 경우가 많아요. 또 마케팅 메시지에 적용되는 사용자 수신거부 제한도 받지 않아요.
