# WhatsAppV2 액션으로 WhatsApp 대화 자동화하기

WhatsAppV2 액션은 워크플로우 안에서 WhatsApp 메시지를 보내고 관리하는 자동화 도구예요. 코드나 조건을 직접 만들지 않아도 고객 답장에 맞춰 흐름이 알아서 나뉘는 챗봇과 워크플로우를 만들 수 있어요.

## WhatsAppV2 액션이란?

WhatsAppV2 액션은 기존 WhatsAppV1을 개선한 새 버전이에요. 스마트 분기, 시간 초과 시 응답, 미디어 변경, 답장에 따른 흐름 설정을 지원해요. 덕분에 전환율 높은 대화 흐름을 쉽게 만들 수 있어요.

![WhatsAppV2 액션 개요](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048740981/original/jYobniW8X2ifwLBGNSxtw-n2iGXIIegdkw.png?1750703487)

## WhatsAppV2 액션의 주요 장점

WhatsAppV2를 쓰면 고객과의 대화를 더 똑똑하게 자동화하고 세밀하게 관리할 수 있어요.

- 스마트 분기: 빠른 답장 버튼을 누른 응답에 따라 분기를 자동으로 만들어 줘요.
- 미디어 유연성: 액션 설정에서 PDF, 동영상, 이미지 URL을 바로 바꿀 수 있어요.
- 다양한 메시지 유형: 자유 형식 메시지, 템플릿, WhatsApp Flows 중에서 고를 수 있어요.
- 분기 토글: 답장 기반 분기가 필요 없으면 꺼서 워크플로우를 단순하게 유지할 수 있어요.
- 시간 초과 액션: 고객이 제때 답하지 않을 때 어떻게 할지 정할 수 있어요.
- 답장 대기: 답장이 올 때까지 워크플로우를 멈춰 둘 수 있어요(메시지가 전달된 뒤에만 해당).
- 자동 전달 확인: 전달 여부를 확인하려고 if 조건을 따로 쓸 필요가 없어요. V2가 알아서 처리해요.

## 워크플로우에서 WhatsAppV2 사용하기

몇 번의 클릭만으로 똑똑한 WhatsApp 흐름을 만들 수 있어요.

### 1. WhatsApp 템플릿 만들기

1. **메시지 > 템플릿**에서 템플릿을 새로 만들거나 기존 템플릿을 선택하세요.
2. 목적에 맞게 버튼, 미디어, Meta Flow를 추가하세요.

### 2. 워크플로우에 WhatsAppV2 추가하기

1. 워크플로우 빌더에서 **WhatsAppV2** 액션을 추가하세요.
2. 메시지 유형(템플릿, 자유 형식, Flow 사용)을 선택하세요.

### 3. 스마트 로직 설정하기

1. 답장 버튼이 있다면 선택하세요. 그러면 분기가 자동으로 만들어져요.
2. 시간 초과 기간과 대체 경로를 추가하세요.
3. **Wait-for-Reply**(답장 대기) 옵션을 켜거나 끄세요.

### 4. 로그 확인하기

로그를 보면 연락처마다 어떤 경로로 진행됐는지 알 수 있어요(예: 전달됨, 답장함, 시간 초과).

## 버튼 답장에 따른 스마트 분기

복잡한 작업은 시스템에 맡기세요.

WhatsApp 템플릿에 답장 버튼이 있으면 WhatsAppV2가 응답마다 워크플로우 분기를 자동으로 만들어요. 조건이나 필터를 직접 만들 필요가 없어요.

## 시간 초과와 답장 대기

무응답이나 답장에 맞춰 정확하게 대응할 수 있어요.

- **시간 초과**: 정해 둔 시간 동안 응답이 없으면 후속 액션이나 대체 액션을 실행해요.
- **Wait-for-Reply**(답장 대기): 고객이 답할 때까지 워크플로우를 완전히 멈춰요. 참여도가 높은 흐름에 유용해요.

## 미디어 즉시 변경하기

템플릿을 다시 만들지 않고 미디어 링크를 바꿀 수 있어요.

WhatsAppV2에서는 메시지 설정 안에서 이미지, PDF, 동영상의 URL을 수정할 수 있어요. 이미 승인된 템플릿에 들어 있는 미디어도 마찬가지예요. 그래서 추가 승인 없이 템플릿을 재사용하고 상황에 맞게 바꾸기가 쉬워요.

## 자주 묻는 질문

### 메시지가 전달되지 않으면 어떻게 되나요?
WhatsAppV2가 전달 여부를 추적해서 알맞은 분기로 연락처를 보내 줘요. 따로 설정할 필요는 없어요.

### 한 워크플로우에서 V1과 V2를 같이 써도 되나요?
새 워크플로우에는 WhatsAppV2만 쓰기를 권장해요. 활용도가 가장 높아요.

### 템플릿을 쓰려면 Meta Flow 설정이 꼭 필요한가요?
템플릿에 Flow가 포함된 경우에만 필요해요. Flow가 없는 기본 템플릿이나 자유 형식 메시지도 보낼 수 있어요.

### 스마트 분기를 끄려면 어떻게 하나요?
액션 설정에서 **Branch Replies**(답장별 분기) 토글을 끄세요. 그러면 WhatsAppV2를 단순한 알림 발송 용도로 쓸 수 있어요.

## 다음 단계

- 버튼과 시간 초과 로직을 넣은 WhatsAppV2 워크플로우를 만들어 보세요.
- 로그로 메시지 성과를 분석하고 후속 메시지를 개선하세요.
- 기존 워크플로우를 WhatsAppV2로 바꿔서 고객 반응을 더 빠르게 처리하세요.
