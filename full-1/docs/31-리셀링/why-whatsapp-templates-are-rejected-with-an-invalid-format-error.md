# WhatsApp 템플릿이 Invalid Format 오류로 거절되는 이유

WhatsApp 템플릿을 만들 때 하이퍼클래스가 입력 중에 잡아 주는 변수 형식 오류와 고치는 방법을 안내해요. 제출한 뒤에도 Meta에서 거절될 수 있는 경우도 함께 정리했어요.

WhatsApp 템플릿은 승인을 받으려면 정해진 형식과 내용 요건을 지켜야 해요. 하이퍼클래스는 자주 생기는 변수 형식 문제를 템플릿 빌더에서 바로 확인해 줘요. 그래서 제출한 뒤에야 문제를 알게 되는 일 없이, 저장하기 전에 미리 고칠 수 있어요.

## Invalid Format 오류란?

**Invalid Format**(형식 오류)은 WhatsApp 메시지 템플릿의 일부가 WhatsApp이 요구하는 형식에 맞지 않다는 뜻이에요. 흔한 원인은 다음과 같아요.

- 잘못 작성된 변수
- 플레이스홀더 안에 들어간 지원되지 않는 문자
- 변수를 잘못된 위치에 넣은 경우
- 그 밖의 템플릿 형식 문제

하이퍼클래스는 **Create WhatsApp Template**(WhatsApp 템플릿 만들기) 빌더에서 자주 생기는 변수 문제 몇 가지를 직접 확인해요. 이런 문제가 발견되면 해당 **머리글** 또는 **본문** 필드에 오류가 바로 표시돼요. 문제를 고치기 전에는 템플릿을 저장할 수 없어요.

## 입력 중 변수 검사의 장점

템플릿을 만드는 중에 변수 오류를 잡으면 확인 시간이 짧아져요. 피할 수 있는 형식 오류가 제출 단계까지 가는 일도 줄어요.

- 바로 확인: 변수 문제가 템플릿을 만드는 중에 표시돼요.
- 빠른 수정: 거절된 뒤가 아니라 저장하기 전에 형식 실수를 고칠 수 있어요.
- 명확한 기준: 화면에 표시되는 안내 덕분에 번호형 플레이스홀더 문법과 **본문**에 변수를 넣을 수 있는 위치 규칙을 쉽게 알 수 있어요.

## 저장 전에 잡아 주는 오류

템플릿 빌더는 저장하기 전에 변수 형식과 위치 문제를 확인해요. Meta가 나중에 문제를 알려 주기를 기다리지 않고, 작성하는 중에 검사해요.

| 검사 항목 | 예시 | 어떻게 되나요? |
| --- | --- | --- |
| 변수 안에 지원되지 않는 문자가 있음 | `{{1$}}` | 해당 필드에 오류가 표시되고, 고쳐야 해요. |
| 중괄호가 없거나 짝이 맞지 않음 | `{{1` | **머리글** 또는 **본문**에 검사 오류가 표시돼요. |
| 중괄호가 하나 더 있음 | `{{1}}}` | 저장하기 전에 잘못된 변수를 고쳐야 해요. |
| **본문**이 변수로 시작하거나 끝남 | `{{1}} your order is ready.` | 변수 앞뒤에 일반 텍스트를 넣을 때까지 **본문**에 오류가 표시돼요. |

{% hint style="warning" %}
잘못된 변수 문법은 **머리글**과 **본문** 모두에서 검사해요. 맨 앞이나 맨 끝에 변수를 둘 수 없다는 규칙은 템플릿 **본문**에만 적용돼요.
{% endhint %}

## WhatsApp 변수 작성 규칙

번호형 플레이스홀더 구조를 지키면 템플릿 빌더와 WhatsApp 모두 변수 내용을 제대로 인식해요.

- 올바른 예: `{{1}}`, `{{2}}`, `{{3}}`
- 잘못된 예: `{{1$}}`, `{{1`, `{{1}}}`
- **본문**에서 올바른 위치: `Hi {{1}}, your appointment is confirmed.`
- **본문**에서 잘못된 위치: `{{1}} your appointment is confirmed.` 또는 `Your appointment is with {{1}}`
- 함께 확인할 점: 플레이스홀더를 여러 개 쓸 때는 번호가 순서대로 이어져야 해요. 예를 들어 `{{3}}`을 빼고 `{{1}}`, `{{2}}`, `{{4}}`만 쓰지 마세요.

## Meta에서 여전히 거절될 수 있는 경우

하이퍼클래스의 변수 검사를 통과했다는 것은 지원되는 변수 검사를 통과했다는 뜻일 뿐이에요. 승인을 보장하지는 않아요. Meta는 형식, 내용, 카테고리, 정책 요건까지 템플릿 전체를 따로 심사하기 때문이에요.

|  |
| --- |
| 번호가 이어지지 않거나 너무 많은 플레이스홀더: 변수 번호나 플레이스홀더 개수가 WhatsApp의 형식 기준에 맞지 않을 수 있어요. |
| 내용 또는 정책 위반: 템플릿에 지원되지 않거나 민감하거나 악의적이거나 오해를 부르는 내용 등, 정책에 맞지 않는 내용이 있을 수 있어요. |
| 글자 수 또는 텍스트 서식 문제: 해당 구성 요소의 제한을 넘거나 지원되지 않는 서식이 있을 수 있어요. |
| 중복 콘텐츠: 이미 있는 템플릿과 내용이 같으면 거절될 수 있어요. |
| 카테고리 불일치: 선택한 **마케팅**, **Utility**(유틸리티), **Authentication**(인증) 카테고리와 내용이 맞지 않으면 수정하거나 카테고리를 다시 분류해야 할 수 있어요. |

하이퍼클래스 검사와 Meta 심사는 달라요. 하이퍼클래스는 위에서 설명한 변수 형식 오류를 저장하기 전에 잡아 줘요. Meta는 템플릿 전체를 심사하므로 다른 이유로 거절할 수도 있어요.

## 평판 관리 리뷰 요청 프리셋 업데이트

**평판 관리**(Reputation)에서 새로 만드는 리뷰 요청 템플릿은 업데이트된 기본 프리셋을 써요. 이 프리셋은 **본문**이 변수로 끝나지 않아요. 그래서 새로 만든 리뷰 요청 템플릿은 **본문** 위치 규칙을 따로 고치지 않아도 충족해요.

## Invalid Format 오류 해결 순서

먼저 화면에 표시된 검사 메시지를 확인하세요. 저장하기 전에 지원되는 변수 문제를 알려 줘요. 템플릿이 이미 Meta 심사까지 갔다면 형식과 내용 요건도 함께 살펴보세요.

1. 강조 표시된 **머리글** 또는 **본문**을 확인해요. 템플릿 빌더에 표시된 오류를 보고 문제가 있는 변수를 찾으세요.
2. 변수 문법을 고쳐요. `{{1}}`, `{{2}}`처럼 번호형 플레이스홀더를 쓰세요. 지원되지 않는 문자는 지우고, 빠졌거나 많은 중괄호를 바로잡으세요.
3. **본문**에서 변수 위치를 확인해요. 메시지의 맨 앞이나 맨 끝에 오는 변수는 앞뒤에 일반 텍스트가 있어야 해요.
4. 나머지 형식을 점검해요. 제출하기 전에 변수 순서, 샘플 값, 템플릿 길이, 카테고리, 버튼, 다른 템플릿 구성 요소를 확인하세요.
5. 저장하고 제출해요. 지원되는 검사 오류가 모두 없어지면 템플릿을 저장하고 Meta 심사를 위해 제출하세요.

## 자주 묻는 질문

### 하이퍼클래스에서 템플릿이 저장되지 않아요.
빌더가 잘못된 변수, 짝이 맞지 않는 중괄호, 지원되지 않는 문자, 또는 변수로 시작하거나 끝나는 **본문**을 발견했을 수 있어요. 강조 표시된 문제를 고친 뒤 저장하세요.

### WhatsApp 변수는 어떤 형식으로 써야 하나요?
`{{1}}`, `{{2}}`, `{{3}}`처럼 번호형 플레이스홀더를 쓰세요.

### WhatsApp 템플릿 본문을 변수로 시작하거나 끝낼 수 있나요?
아니요. 변수 앞뒤에 일반 텍스트를 넣으세요. 하이퍼클래스는 이 위치 문제가 있으면 템플릿을 저장하기 전에 표시해 줘요.

### 하이퍼클래스의 변수 검사를 통과하면 Meta 승인이 보장되나요?
아니요. 입력 중 검사는 지원되는 변수 형식과 위치 오류만 잡아 줘요. Meta는 내용, 카테고리, 정책, 중복 여부 등 다른 형식 요건으로 템플릿을 거절할 수 있어요.

### 새로 만드는 평판 관리 리뷰 요청 템플릿을 직접 고쳐야 하나요?
변수로 끝나는 **본문** 문제는 고치지 않아도 돼요. 업데이트된 리뷰 요청 프리셋은 **본문**이 변수로 끝나지 않아요.
