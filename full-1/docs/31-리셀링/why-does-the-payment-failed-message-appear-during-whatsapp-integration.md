# WhatsApp 연동 중 "결제 실패" 메시지가 나타날 때

서브 계정에서 WhatsApp을 연동하다가 **결제 실패** 메시지가 나타날 때 원인과 해결 방법을 안내해요. 에이전시 계정의 결제 실패가 서브 계정의 WhatsApp 설정을 막고 있는 경우에 확인해 보세요.

## WhatsApp 연동 중 "결제 실패" 메시지가 나타나는 이유

서브 계정에서 WhatsApp을 연동할 때 **결제 실패** 메시지가 나타난다면, 대부분 **에이전시 계정의 결제 실패** 때문이에요. 서브 계정의 WhatsApp 구독은 에이전시의 결제 수단으로 결제돼요. 그래서 에이전시 쪽에 결제 문제가 있으면 연동이 진행되지 않아요.

{% hint style="info" %}
이 문제는 에이전시 계정에서 해결해야 해요. 에이전시 관리자만 처리할 수 있어요.
{% endhint %}

## 실패한 결제 다시 시도하기

에이전시 계정에서 실패한 결제를 다시 시도하려면 다음 단계를 따르세요.

1. 에이전시 대시보드에서 **설정**으로 이동하세요.
2. **청구/결제**를 클릭하세요.
3. **결제** 탭으로 이동하세요.
4. **인보이스**를 클릭하세요.
5. 실패한 인보이스를 찾아 **결제 재시도**를 클릭하세요.

![결제 재시도 버튼이 보이는 인보이스 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045912026/original/hB7pxqEBwv5ykoC4_bn1FBKidpQRZJCY6g.png?1746014901)

결제가 정상적으로 처리되면 서브 계정에서 WhatsApp 연동을 이어서 진행할 수 있어요.

## FAQ

### 서브 계정에서 WhatsApp을 연동하려는데 "결제 실패" 메시지가 나타나요. 왜 그런가요?

보통 에이전시의 결제 수단으로 결제가 실패했기 때문이에요. 서브 계정의 WhatsApp 구독은 에이전시의 결제 수단으로 결제돼요. 에이전시 쪽에 결제 문제가 있으면 연동 과정이 막혀요.

### 결제 실패 문제를 해결하려면 어떻게 하나요?

실패한 결제를 다시 시도하려면 다음 단계를 따르세요.

1. 에이전시 대시보드에서 **설정**으로 이동하세요.
2. **청구/결제**를 클릭하세요.
3. **결제** 탭으로 이동하세요.
4. **인보이스**를 선택하세요.
5. 실패한 인보이스를 찾아 **결제 재시도**를 클릭하세요.

### 서브 계정에서 따로 바꿔야 할 설정이 있나요?

서브 계정에서 해야 할 일은 없어요. 에이전시의 결제가 정상적으로 처리되면 서브 계정에서 WhatsApp 연동을 평소처럼 진행할 수 있어요.
