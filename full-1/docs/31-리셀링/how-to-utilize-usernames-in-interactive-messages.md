# 인터랙티브 메시지로 WhatsApp 사용자 이름 연락처의 전화번호 요청하기

WhatsApp 사용자 이름(username)을 쓰는 고객은 전화번호를 알리지 않고도 비즈니스에 메시지를 보낼 수 있어요. 연락처 정보 요청 기능을 쓰면 WhatsApp 템플릿이나 워크플로우 자동 메시지로 고객에게 전화번호를 물어볼 수 있고, 공유 여부는 고객이 직접 정해요.

하이퍼클래스는 고객이 공유한 번호를 추가하기 전에 다른 연락처가 이미 그 번호를 쓰고 있는지 확인해요. 그래서 같은 전화번호가 여러 연락처에 중복으로 들어가는 일을 줄일 수 있어요. 이 문서에서는 두 가지 요청 방법을 설정하는 방법과, 고객이 정보를 공유한 뒤 어떻게 처리되는지 안내해요.

---

## 사용자 이름 연락처에 연락처 정보 요청이란?

연락처 정보 요청(Request Contact Info)은 WhatsApp 사용자 이름을 쓰는 연락처에게 전화번호를 직접 공유해 달라고 요청하는 기능이에요.

WhatsApp 사용자 이름을 쓰면 고객이 전화번호를 밝히지 않고도 비즈니스와 대화할 수 있어요. 하이퍼클래스는 WhatsApp이 제공하는 사용자 이름 기반 신원으로 연락처와 대화를 계속 관리해요. 사용자 이름 연락처가 하이퍼클래스에 어떻게 저장되는지는 [WhatsApp 사용자 이름: 전화번호 없이 연락처 수집](whatsapp-usernames-contact-capture-without-phone-numbers.md)에서 볼 수 있어요.

고객의 전화번호가 필요할 때는 아래 두 가지 중 하나로 요청할 수 있어요.

- 지원되는 WhatsApp 템플릿
- **WhatsApp Interactive Messages**(WhatsApp 인터랙티브 메시지) 워크플로우 액션

어떤 정보를 공유할지는 고객이 직접 정해요.

---

## 연락처 정보 요청의 장점

연락처 정보 요청을 쓰면 고객의 선택을 존중하면서, WhatsApp 사용자 이름 연락처에 비어 있는 전화번호를 모을 수 있어요.

- 고객이 직접 공유: 연락처 정보를 줄지 말지는 고객이 정해요.
- 한 번의 탭으로 요청: 고객이 전화번호를 직접 입력하지 않아도 WhatsApp에서 바로 정보를 공유할 수 있어요.
- 템플릿 지원: 지원되는 **마케팅**, **유틸리티** WhatsApp 템플릿에 **Share contact info**(연락처 정보 공유)를 추가할 수 있어요.
- 워크플로우 자동화: 워크플로우의 알맞은 시점에 연락처 정보를 자동으로 요청해요.
- 중복 방지 수집: 공유된 전화번호를 추가하기 전에 다른 연락처가 이미 쓰고 있는지 확인해요.
- 더 완성된 연락처 기록: 수집한 전화번호는 전화번호를 기준으로 동작하는 하이퍼클래스 워크플로우에 활용할 수 있어요.
- 사용자 이름 통화 지원: WhatsApp 통화도 WhatsApp 사용자 이름을 쓰는 연락처를 지원해요.

## 사전 조건과 제한 사항

WhatsApp의 메시지 가능 시간(고객 서비스 창)과 템플릿 요건을 알아 두면 알맞은 요청 방법을 고르기 쉬워요.

연락처 정보 요청을 쓰기 전에 확인하세요.

- 서브 계정에 WhatsApp이 연결되고 설정되어 있어야 해요. 설정은 [WhatsApp 설정](../11-설정/서브어카운트-설정/whatsapp-settings.md)에서 확인할 수 있어요.
- 사용자 이름 연락처가 이미 하이퍼클래스 계정에 등록되어 있어야 해요.
- 워크플로우 기반 WhatsApp 인터랙티브 메시지는 24시간 고객 서비스 창(Customer Service Window)이 열려 있어야 보낼 수 있어요.
- 고객 서비스 창이 닫혀 있을 때는, 필요한 경우 승인된 WhatsApp 템플릿을 사용하세요.
- WhatsApp 템플릿은 사용하기 전에 Meta의 표준 승인 절차를 거쳐야 해요.

아래 제한 사항도 기억해 두세요.

- 연락처 정보 요청이 고객의 전화번호를 자동으로 알려 주지는 않아요.
- 어떤 연락처 정보를 공유할지는 고객이 정해요.
- 고객이 공유한 번호를 이미 다른 하이퍼클래스 연락처가 쓰고 있으면, 그 번호를 사용자 이름 연락처에 추가하지 않아요.
- 공유된 번호가 이미 있어도 연락처를 자동으로 병합하지 않아요.
- WhatsApp 사용자 이름은 Meta의 사용자 이름 도입 일정에 따라 사용할 수 있어요.
- WhatsApp 통화는 별도의 사용 가능 지역과 자격 요건이 있어요.

## 연락처 정보 요청 설정하기

하이퍼클래스에서는 WhatsApp 사용자 이름 연락처에게 전화번호를 요청하는 방법이 두 가지 있어요. 템플릿으로 요청하려면 WhatsApp 템플릿을 쓰고, 고객 서비스 창이 열려 있는 동안 자동으로 요청하려면 워크플로우를 쓰세요.

### 방법 1: WhatsApp 템플릿에 Share contact info 추가하기

지원되는 WhatsApp 템플릿에 **Share contact info**(연락처 정보 공유)를 추가하면, 고객이 한 번의 탭으로 연락처 정보를 보낼 수 있어요. 템플릿을 처음 만든다면 [WhatsApp 템플릿 만드는 방법](WhatsApp/how-to-create-a-whatsapp-template.md)도 함께 참고하세요.

1. **서브 계정 보기**에서 **설정**을 선택하세요.
2. **WhatsApp**을 선택하세요.
3. **템플릿**을 선택하세요.
4. **새 템플릿 만들기**를 선택하거나, 해당하는 기존 템플릿을 편집하세요.

![WhatsApp 템플릿 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082904757/original/nF5nULIUIey-RoPFUh6QuwCYr3HpSEpoIg.png?1791523994)

5. 지원되는 템플릿 카테고리를 선택하세요.
   - **마케팅**
   - **유틸리티**
6. 템플릿 내용을 입력하세요.
7. **버튼 (선택 사항)** 을 여세요.
8. **Share contact info**를 선택하세요.
9. 나머지 템플릿 설정을 마무리하세요.
10. 표준 WhatsApp 템플릿 승인 절차에 따라 템플릿을 제출하세요.
11. 승인이 끝나면 해당 WhatsApp 연락처에게 템플릿을 사용하세요.

고객이 템플릿을 받으면, WhatsApp에서 연락처 정보를 공유할지 직접 선택할 수 있어요.

![고객에게 표시되는 연락처 정보 공유 템플릿](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082904815/original/it3iNnZrr5Pv38nQla9t8duPD2VIdc7QSg.png?1791524116)

### 방법 2: 워크플로우에서 연락처 정보 요청하기

워크플로우 자동화를 쓰면 고객 여정의 알맞은 시점에 연락처 정보를 자동으로 요청할 수 있어요. 인터랙티브 메시지에 대한 자세한 내용은 [WhatsApp 인터랙티브 메시지](interactive-whatsapp-messages.md)를 참고하세요.

{% hint style="info" %}
인터랙티브 요청을 보내기 전에, 해당 연락처의 24시간 WhatsApp 고객 서비스 창이 열려 있는지 확인하세요.
{% endhint %}

1. **서브 계정 보기**에서 **자동화**를 선택하세요.
2. 해당하는 워크플로우를 여세요.
3. **Add Action (+)**(액션 추가)를 클릭하세요.
4. **WhatsApp Interactive Messages**를 선택하세요.
5. 알맞은 **From Phone Number**(발신 전화번호)를 선택하세요.
6. **Interactive Message Type**(인터랙티브 메시지 유형)을 여세요.
7. **Request Contact Info**(연락처 정보 요청)를 선택하세요.
8. 고객의 정보를 요청하는 이유를 설명하는 메시지 본문을 입력하세요.
9. 액션을 저장하세요.
10. 나머지 워크플로우 설정을 마무리하세요.
11. 워크플로우를 게시하고 테스트하세요.

![워크플로우의 WhatsApp Interactive Messages 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082905102/original/YykqoOVjaVhlhrvRH1F2IkMYgT0SF5edBA.png?1791524524)

고객이 왜 전화번호를 요청받는지 알 수 있도록 메시지를 분명하게 쓰세요.

고객이 응답하면 WhatsApp의 기본 연락처 공유 화면이 열려요. 고객은 공유할 수 있는 연락처 정보 중에서 원하는 것을 골라 보내요.

## 중복 방지 전화번호 수집

중복 방지 수집은 같은 전화번호가 여러 하이퍼클래스 연락처에 배정되지 않도록 도와줘요.

WhatsApp 사용자 이름 연락처가 전화번호를 공유하면, 하이퍼클래스는 다른 연락처가 이미 그 번호를 쓰고 있는지 확인해요.

- 그 번호를 쓰는 연락처가 없을 때: 하이퍼클래스가 사용자 이름 연락처에 번호를 추가할 수 있어요.
- 다른 연락처가 이미 그 번호를 쓰고 있을 때: 하이퍼클래스는 같은 번호를 사용자 이름 연락처에 추가하지 않아요.

{% hint style="info" %}
연락처 정보 요청은 두 연락처 기록을 자동으로 병합하지 않아요.
{% endhint %}

따로 만들어진 기록이 같은 사람의 것이라고 판단되면, 하이퍼클래스의 기본 중복 연락처 관리 기능으로 확인하고 병합하세요. 자세한 방법은 [중복 연락처 관리 및 병합 방법](../02-연락처/스마트-리스트/how-to-manage-and-merge-duplicate-contacts.md)을 참고하세요.

## 사용자 이름 연락처와 WhatsApp 통화

WhatsApp 통화가 사용자 이름 연락처를 지원하면, 연락처가 사용자 이름을 쓰는 경우에도 지원되는 WhatsApp 음성 통화를 이용할 수 있어요.

연락처 정보 요청과 WhatsApp 통화는 쓰임새가 달라요. 사용자 이름 기반 WhatsApp 통화를 쓰려고, 단지 연락처가 WhatsApp 사용자 이름을 쓴다는 이유로 전화번호를 먼저 모을 필요는 없어요.

비즈니스에서 다른 지원 용도로 고객의 실제 전화번호가 필요할 때는 연락처 정보 요청이 여전히 유용해요.

WhatsApp 통화의 사용 가능 여부와 설정 요건은 계정에 적용되는 WhatsApp 통화 규정을 그대로 따라요. 자세한 내용은 [하이퍼클래스의 WhatsApp 통화](whatsapp-calling-in-hyperclass.md)를 참고하세요.

## 자주 묻는 질문

### 하이퍼클래스가 WhatsApp 사용자 이름에 연결된 전화번호를 자동으로 알려 주나요?
아니요. 고객이 WhatsApp에서 직접 연락처 정보를 공유하기로 선택해야 해요.

### 어떤 WhatsApp 템플릿에서 Share contact info를 쓸 수 있나요?
**Share contact info**는 **마케팅**과 **유틸리티** WhatsApp 템플릿에서 지원돼요.

### 연락처 정보 요청을 자동화할 수 있나요?
네. 워크플로우에 **WhatsApp Interactive Messages**를 추가하고, **Interactive Message Type**에서 **Request Contact Info**를 선택하세요.

### 24시간 고객 서비스 창이 닫혀 있을 때도 워크플로우로 연락처 정보 요청 메시지를 보낼 수 있나요?
WhatsApp 인터랙티브 메시지는 고객 서비스 창이 열려 있어야 보낼 수 있어요. 창이 닫혀 있을 때는, 필요한 경우 승인된 **마케팅** 또는 **유틸리티** 템플릿을 사용하세요.

### 고객이 이미 다른 연락처가 쓰는 번호를 공유하면 어떻게 되나요?
하이퍼클래스는 그 전화번호를 사용자 이름 연락처에 추가하지 않아요.

### 연락처 정보 요청이 중복 연락처를 자동으로 병합하나요?
아니요. 이 기능에는 자동 병합이 문서에 나와 있지 않아요. 필요하면 중복 기록을 따로 확인해서 병합하세요.

### Share contact info가 들어간 WhatsApp 템플릿도 Meta 승인을 받아야 하나요?
네. WhatsApp 템플릿은 표준 템플릿 생성 절차와 Meta 승인 절차를 그대로 따라요.
