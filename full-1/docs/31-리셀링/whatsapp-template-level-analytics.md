# WhatsApp 템플릿별 성과 확인하기

WhatsApp 템플릿마다 발송·전달·읽음 수와 버튼 클릭 수를 확인할 수 있어요. 템플릿별 성과를 보고 메시지 전략을 개선할 때 활용하세요.

## WhatsApp 템플릿 인사이트 보기

{% hint style="info" %}
템플릿 분석에서는 템플릿이 발송·전달·읽힌 횟수와, 템플릿에 들어 있는 URL 버튼이나 빠른 답장(Quick Reply) 버튼이 클릭된 횟수를 볼 수 있어요. Coex 연동에서는 이 리포트를 쓸 수 없어요.
{% endhint %}

1. **설정 > WhatsApp > 템플릿**으로 이동하세요.

   ![설정 > WhatsApp > 템플릿 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034279043/original/XkJX_4JnB0qp4KzDt6adAdaqSaOF-0XFnw.png?1728371385)

2. 템플릿을 검색한 뒤 **Reports**(리포트)를 클릭하세요.

   ![템플릿의 Reports 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034279173/original/B79VtQLcqP2DTb2uCUBd7N6_fshManl3Gg.png?1728371494)

3. **전달률** 탭을 클릭하세요.

   ![전달률 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034279302/original/DjQBt07teasQrwzZCz8IlPCdw3SVxSfzPg.png?1728371578)

4. **시작일**과 **종료일**을 선택하세요.

   ![시작일과 종료일 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034279992/original/iJmmR1tGFbcDss5w3JZhZJH5jsomWmw5dw.png?1728372099)

### 표시되는 지표

- **발송됨**: 메시지가 발송됨(회색 체크 1개)
- **전달됨**: 메시지가 전달됨(회색 체크 2개)
- **읽기**: 메시지를 열어 봄(파란색 체크)

## WhatsApp 템플릿 버튼 클릭 보기

{% hint style="info" %}
버튼 클릭 분석은 카테고리가 MARKETING 또는 UTILITY인 템플릿에서만 볼 수 있어요.
{% endhint %}

1. **설정 > WhatsApp > 템플릿**으로 이동하세요.

   ![설정 > WhatsApp > 템플릿 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034279043/original/XkJX_4JnB0qp4KzDt6adAdaqSaOF-0XFnw.png?1728371385)

2. 템플릿을 검색한 뒤 **Reports**(리포트)를 클릭하세요.

   ![템플릿의 Reports 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034279173/original/B79VtQLcqP2DTb2uCUBd7N6_fshManl3Gg.png?1728371494)

3. **버튼 클릭**을 클릭하세요.

{% hint style="info" %}
URL 버튼: 앱 사용자가 URL 버튼을 누르면 기기의 기본 웹 브라우저에서 지정한 URL이 열려요. 템플릿에는 URL 버튼을 2개까지 넣을 수 있어요.
{% endhint %}

![버튼 클릭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034280847/original/YeU3rRykCkczLkqTy79z6DM4D5aOt1oExw.png?1728372758)

{% hint style="info" %}
유럽연합, 영국, 일본의 Meta Business Account가 소유했거나 공유받은 WABA, 또는 이 국가·지역의 국가 번호를 쓰는 비즈니스 전화번호가 있는 WABA는 지원되지 않아요.
{% endhint %}

### URL 버튼 알아보기

- 사용자의 웹 브라우저에서 지정한 URL을 열어요.
- 템플릿당 최대 **URL 버튼 2개**까지 넣을 수 있어요.

## 자주 묻는 질문

### 템플릿별 분석 기능은 무엇인가요?

개별 WhatsApp 템플릿의 성과를 자세히 보여 주는 기능이에요. 발송·전달·읽음 수 같은 주요 지표를 확인할 수 있고, URL 버튼이나 빠른 답장 버튼처럼 상호작용 요소가 들어 있는 템플릿은 버튼 클릭 수도 확인할 수 있어요.

### WhatsApp 템플릿 인사이트는 어떻게 보나요?

**설정 > WhatsApp > 템플릿**으로 이동해 원하는 템플릿을 검색하고 **Reports**(리포트)를 클릭하세요. **전달률** 탭에서 해당 템플릿의 발송·전달·읽음 수를 볼 수 있어요.

### 빠른 답장 버튼이 무엇인가요?

빠른 답장(Quick Reply) 버튼은 텍스트만 있는 사용자 지정 버튼이에요. 앱 사용자가 누르면 지정한 문구가 바로 메시지로 전송돼요. 고객이 마케팅 메시지 수신을 간편하게 거부하는 버튼이 대표적인 예예요.

템플릿에는 빠른 답장 버튼을 10개까지 넣을 수 있어요. 다른 버튼과 함께 쓸 때는 빠른 답장 버튼과 빠른 답장이 아닌 버튼, 이렇게 두 그룹으로 나눠서 배치해야 해요. 그룹을 잘못 나누면 API가 잘못된 조합이라는 오류를 반환해요.

**올바른 배치:**

- 빠른 답장, 빠른 답장
- 빠른 답장, 빠른 답장, URL, 전화
- URL, 전화, 빠른 답장, 빠른 답장

**잘못된 배치:**

- 빠른 답장, URL, 빠른 답장
- URL, 빠른 답장, URL

### 어떤 버튼 클릭 데이터를 볼 수 있나요?

카테고리가 MARKETING 또는 UTILITY인 템플릿에서 버튼 클릭 분석을 볼 수 있어요. 사용자가 URL 버튼이나 빠른 답장 버튼 같은 상호작용 버튼을 몇 번 눌렀는지 추적해, 사용자 참여도를 실시간 데이터로 보여 줘요.

### 템플릿에 버튼을 몇 개까지 넣을 수 있나요?

URL 버튼은 2개까지, 빠른 답장 버튼은 최대 10개까지 넣을 수 있어요. 버튼은 올바르게 그룹으로 나눠야 해요. 빠른 답장 버튼은 URL 버튼 같은 다른 유형의 버튼과 같은 그룹에 섞을 수 없어요.

### 유럽연합, 영국, 일본에서 쓰는 템플릿도 버튼 클릭을 확인할 수 있나요?

아니요. 유럽연합, 영국, 일본의 Meta Business Account가 소유했거나 공유받은 WhatsApp Business Account(WABA)는 버튼 클릭 분석을 지원하지 않아요. 비즈니스 전화번호가 이 지역의 번호인 경우에도 마찬가지예요.

### 템플릿 분석은 어떤 단위로 볼 수 있나요?

템플릿 분석은 일 단위로 볼 수 있어요. 시작일과 종료일을 설정해 일별, 주별 등 원하는 기간의 성과 데이터를 확인할 수 있어요.

### WhatsApp 템플릿의 URL 버튼 클릭도 추적할 수 있나요?

네, URL 버튼이 들어 있는 템플릿은 분석에서 URL 버튼 클릭도 추적돼요. URL 버튼을 누르면 사용자의 기본 웹 브라우저에서 지정한 링크가 열려요. 이런 템플릿에는 URL 버튼을 2개까지 넣을 수 있어요.

### 템플릿별 분석을 쓰면 어떤 점이 좋은가요?

메시지 성과를 바탕으로 커뮤니케이션 전략을 개선하는 데 도움이 돼요. 어떤 템플릿이 참여를 이끄는지, 사용자가 어떤 버튼을 누르는지 파악할 수 있고, 메시지의 전달률과 읽음률도 확인할 수 있어요. 이 데이터로 템플릿을 다듬어 고객 참여율과 전환율을 높일 수 있어요.
