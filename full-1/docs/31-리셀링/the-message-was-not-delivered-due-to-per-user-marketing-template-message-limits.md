# '사용자당 마케팅 템플릿 메시지 한도' 오류가 나올 때

메시지를 보냈는데 "The message was not delivered due to per-user marketing template message limits error"(사용자당 마케팅 템플릿 메시지 한도 오류로 메시지가 전달되지 않았습니다)라는 오류가 나오는 경우가 있어요. 이 문서에서는 오류가 나오는 이유와 앞으로 어떻게 되는지 알려 드려요.

![사용자당 마케팅 템플릿 메시지 한도 오류 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043380330/original/chCN0Ga4xJ3Yl4YqfZs47KtdziTW6BVUIA.png?1742194317)

---

## 해결 방법

이 오류는 받는 사람의 전화번호가 다른 비즈니스 플랫폼에서도 마케팅 메시지를 최대 한도까지 받았을 때 나타나요. 정상적으로 나타나는 현상이에요.

```
이 오류는 24시간 동안 유지되며, 이후에는 사라져서 유틸리티 템플릿을 보낼 수 있습니다.
