# WhatsApp 미디어 템플릿

WhatsApp 미디어 템플릿을 쓰면 이미지, 동영상, 문서, 위치 정보를 보낼 수 있어요. 이 문서에서는 미디어 템플릿을 만드는 방법과 보내는 방법을 안내해요. 소통을 풍부하게 하고 마케팅에 활용해 보세요.

[동영상](https://www.youtube.com/embed/NlWYiphUv\_8?&wmode=opaque)

---

## WhatsApp 미디어 템플릿이란?

WhatsApp 미디어 템플릿으로 이미지, 동영상, 문서, 위치 정보 같은 다양한 미디어를 연락처나 고객에게 보낼 수 있어요. 덕분에 WhatsApp에서 더 눈길을 끄는 메시지를 만들 수 있어요.

---

## 활용 사례

미디어 템플릿으로 WhatsApp 마케팅 캠페인을 한 단계 더 끌어올려 보세요.

- 신상품 출시: 이미지와 눈길을 끄는 동영상으로 새 상품을 소개해요.
- 프로모션과 혜택: 할인 코드나 특별 혜택을 눈에 띄는 이미지와 함께 공유해요.
- 이벤트 안내: 위치 공유와 이미지로 이벤트를 알려요.
- 고객 응대: 유용한 튜토리얼이나 가이드를 문서 형식으로 제공해요.

## WhatsApp 미디어 템플릿 만들기

1. **설정 > WhatsApp > 템플릿 > 템플릿 만들기**로 이동해요.

   ![템플릿 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025237169/original/CijuA5Ux_0BnU1Nrj5gh-e62i_X1ZHxUjQ.png?1714394949)

2. **Template name**(템플릿 이름), **카테고리**, **언어**를 입력해요.
3. **Show header**(헤더 표시)를 선택하고 **미디어**를 클릭한 뒤 **Upload Media**(미디어 업로드)를 클릭해요.

   ![헤더에 미디어 업로드하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025237423/original/Fc1WILQS2I7KVbmPiTuv03mgH9DQJbyGVw.png?1714395054)

4. **만들기**를 클릭해요. 템플릿이 Meta에 승인 요청으로 전송돼요.

   ![템플릿 만들기 후 승인 요청 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025237581/original/viICB0j-AIQVIaVcuZCaqp3xS6lvkTFTKw.png?1714395178)

{% hint style="info" %}
WhatsApp 템플릿 상태와 모범 사례에 관한 안내 문서도 확인해 보세요.
{% endhint %}

## 위치 WhatsApp 템플릿 만들기

1. **설정 > WhatsApp > 템플릿 > 템플릿 만들기**로 이동해요.

   ![템플릿 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025237169/original/CijuA5Ux_0BnU1Nrj5gh-e62i_X1ZHxUjQ.png?1714394949)

2. **Location**(위치)을 선택하고 **Latitude**(위도)와 **Longitude**(경도)를 입력해요.
3. **위치 이름**과 **Address**(주소)를 입력해요.

   ![위치 정보를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025357835/original/fJ9DeOFC5SpbdLUGLojy753XxdclmLmxVQ.png?1714564066)

{% hint style="info" %}
위도와 경도는 Google Maps에서 지도의 장소나 지역을 마우스 오른쪽 버튼으로 클릭하면 확인할 수 있어요.
{% endhint %}

![위치 템플릿 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025357928/original/r3hyUUixnEHIswO2PmoOQPysqCEaYNP6kw.png?1714564202)

## 일괄 작업으로 WhatsApp 미디어 템플릿 보내기

1. **연락처**로 이동해 WhatsApp 메시지를 일괄 발송할 **스마트 리스트**를 선택해요.

   ![스마트 리스트 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025237996/original/POcC4G2Axs2WSgFglEyfEQcRCcpA9tJgqg.png?1714395526)

2. 연락처를 모두 선택해요.
3. WhatsApp 아이콘을 클릭해요.
4. **템플릿 선택**에서 보낼 템플릿을 고르고 작업 이름을 입력해요.

   ![일괄 작업에서 템플릿을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025285340/original/hRh15nKutjoHCwCrlo6ESGUqZM6yiJcXWw.png?1714468175)

5. **Show Stats**(통계 보기)를 선택하고 **Processed**(처리됨)를 클릭한 뒤 **View Bulk Action Statistics**(일괄 작업 통계 보기)를 클릭해요.

   ![일괄 작업 통계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025287528/original/PxY-nT91cfGzaHO9pr7wjev7-2CTe8LMjw.png?1714469588)

## 워크플로우로 WhatsApp 미디어 템플릿 보내기

1. **자동화**로 이동해 **Create Workflow**(워크플로우 만들기)를 클릭해요.
2. **처음부터 시작**을 선택하고 **Select Trigger**(트리거 선택)에서 트리거를 골라요.

   ![워크플로우를 처음부터 시작하고 트리거를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025287890/original/1N3LfnTtW9sp1FTUm852Lv5E92gZ56T6cg.png?1714469742)

3. **WhatsApp** 액션을 선택해요.

   ![WhatsApp 액션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025287985/original/eKc8ZUh4cKVc1mxFxvJmJaLTsfOos38OLw.png?1714469804)

4. **Select WhatsApp Template**(WhatsApp 템플릿 선택)에서 템플릿을 고르고 **Save Action**(액션 저장)을 클릭해요.
5. 워크플로우를 저장해요.

   ![WhatsApp 템플릿을 선택하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025288160/original/iHjxbz4XLwtkXhUd6NEvaQFmwm4_gFPpXw.png?1714469956)

{% hint style="info" %}
워크플로우 아래 미리보기에는 미디어 URL이 표시돼요. WhatsApp 메시지가 실제로 전송되면 미디어가 나타나요.
{% endhint %}

## 미디어 제한

| 유형 | 지원 형식 | 최대 크기 |
| --- | --- | --- |
| **문서** | `application/pdf` | 100MB |
| **이미지** | `image/jpeg`, `image/png` (이미지는 8비트, RGB 또는 RGBA여야 해요) | 5MB |
| **동영상** | `video/mp4` | 16MB |

{% hint style="info" %}
크기 제한을 넘는 미디어 파일을 업로드하려고 하면 오류가 표시돼요.
{% endhint %}

## 자주 묻는 질문

### WhatsApp 미디어 템플릿에 쓸 수 있는 미디어 제한은 어떻게 되나요?

지원하는 형식과 크기 제한은 다음과 같아요.

- **문서**: application/pdf, 100MB
- **이미지**: image/jpeg, image/png (8비트, RGB 또는 RGBA여야 해요), 5MB
- **동영상**: video/mp4, 16MB

크기 제한을 넘는 미디어 파일을 업로드하면 오류가 표시돼요. 예를 들어 이미지 템플릿에 동영상 파일을 추가하려고 하면 오류 메시지가 나와요.

### WhatsApp 미디어 템플릿이 무엇인가요?

미리 승인받은 메시지 형식으로, WhatsApp 메시지에 이미지, 동영상, 문서, 위치 정보를 넣을 수 있어요. 마케팅, 고객 지원, 인증 등에서 고객과 더 수월하게 소통할 수 있어요.

### 가이드라인에 맞지 않는 미디어를 쓰면 어떻게 되나요?

오류 메시지가 표시될 가능성이 높고, 템플릿이 전송되지 않을 수 있어요. 미디어가 [WhatsApp 템플릿 가이드라인](https://developers.facebook.com/docs/whatsapp/message-templates/guidelines/)에 맞는지 확인하세요.

### WhatsApp 메시지 템플릿을 쓰려면 승인을 받아야 하나요?

네. 모든 템플릿은 WhatsApp(Meta)의 승인 절차를 거쳐야 해요. 정해진 가이드라인에 맞는지 확인하기 위해서예요.

### 템플릿이 반려되는 이유는 무엇인가요?

자주 있는 반려 사유는 다음과 같아요.

- 변수 형식이 없거나 잘못된 경우
- 내용이 [WhatsApp 비즈니스 또는 커머스 정책](https://developers.facebook.com/docs/whatsapp/overview/policy-enforcement/violations/)을 위반하는 경우
- 민감한 정보를 요구하는 경우 (예: 카드 번호 전체)
- 욕설이나 위협적인 표현이 있는 경우
- 이미 있는 템플릿과 중복되는 경우

### 템플릿이 **일시 중지** 상태라는 건 무슨 뜻인가요?

고객 피드백이 부정적이거나 참여율이 낮아서 템플릿이 일시 중지된 상태예요. 일시 중지된 템플릿은 상태가 다시 **활성**으로 바뀌기 전까지 보낼 수 없어요.
