# 오류 131053 — 미디어 업로드 오류 해결하기

WhatsApp으로 이미지나 동영상 같은 미디어 메시지를 보냈는데 오류 131053이 나올 때 원인과 해결 방법을 안내해요. 지원하는 파일 형식과 용량도 함께 정리했어요.

## 오류 131053이란?

오류 131053은 WhatsApp Cloud API 오류예요. 공식 이름은 "Media Upload Error"(미디어 업로드 오류)예요. 보내려는 미디어 파일을 WhatsApp API가 업로드하지 못할 때 발생해요. 이미지, 동영상, 오디오, 문서, 스티커가 모두 해당돼요. 이 오류가 나면 메시지가 전달되지 않고 미디어도 전송되지 않아요.

API 응답에서는 오류가 아래처럼 보여요.

```
"errors": [
  {
    "code": 131053,
    "title": "Media upload error",
    "message": "Media upload error",
    "error_data": {
      "details": "Unable to upload the media used in the message."
    }
  }
]
```

웹훅 응답의 `error_data.details` 필드에는 실패 이유가 더 구체적으로 담겨 있는 경우가 많아요. 지원하지 않는 MIME 타입이 정확히 무엇인지 알려 주기도 해요. 원인을 찾을 때는 이 필드부터 확인하세요.

```
Example of a specific detail message:
"Unsupported Image mime type image/webp. Please use one of image/png, image/jpeg."
```

## 지원하는 미디어 형식과 용량

WhatsApp Business API는 정해진 파일 형식과 용량만 지원해요. 이 기준을 벗어나는 파일은 오류 131053이 발생해요. 미디어를 올리기 전에 아래 표를 확인하세요.

| 유형 | 최대 용량 | 지원 형식 |
| --- | --- | --- |
| 이미지 | 5 MB | `image/jpeg`, `image/png` — 8비트 RGB 또는 RGBA여야 해요. 일반 이미지 메시지에서는 WebP를 지원하지 않아요. |
| 동영상 | 16 MB | `video/mp4`, `video/3gpp` — 비디오 코덱은 H.264, 오디오 코덱은 AAC여야 해요. 오디오 스트림은 하나만 있거나 없어야 해요. |
| 오디오 | 16 MB | `audio/aac`, `audio/mp4`, `audio/mpeg`, `audio/amr`, `audio/ogg`(OPUS 코덱만 가능) |
| 문서 | 100 MB | PDF, Word(.docx), Excel(.xlsx), PowerPoint(.pptx) 등 대부분의 일반 문서 형식이에요. 다른 미디어 유형으로 지원되지 않는 파일은 문서로 보낼 수 있어요. |
| 스티커 | 100 KB | `image/webp`만 가능해요. 정적 WebP(발신용)여야 하고, 정확히 512 x 512 픽셀에 투명 배경이어야 해요. |

{% hint style="warning" %}
WebP 이미지(image/webp)는 스티커로만 지원해요. WebP 파일을 일반 이미지 메시지로 보내면 항상 오류 131053이 나와요. 이미지로 보내려면 먼저 JPEG나 PNG로 변환하세요.
{% endhint %}

## 원인

아래는 Meta 문서를 기준으로 확인된 오류 131053의 원인이에요.

### 1. 지원하지 않는 파일 형식 또는 MIME 타입

가장 흔한 원인이에요. 파일 형식이 WhatsApp의 지원 목록에 없는 경우예요. 예를 들면 `.webp`를 일반 이미지로 보내거나, `.tiff`나 `.gif`를 보내거나, 잘못된 코덱의 동영상을 보내는 경우예요. 확장자가 맞아 보여도 실제 MIME 타입이 중요해요. `.jpg`로 이름을 바꿨어도 내부적으로 WebP로 인코딩된 파일은 실패해요.

### 2. 파일 용량 초과

파일이 해당 유형의 최대 용량보다 커요. WhatsApp은 암호화한 뒤의 용량으로 제한을 적용해요. 그래서 WhatsApp 쪽에서 보는 파일 크기는 원본보다 조금 클 수 있어요. 제한보다 넉넉하게 작은 파일을 쓰세요. 이미지는 5 MB, 동영상과 오디오는 16 MB, 문서는 100 MB, 스티커는 100 KB 미만이어야 해요.

### 3. 손상되었거나 올바르지 않은 미디어 파일

파일이 손상되었거나 일부만 저장되었어요. 또는 WhatsApp의 미디어 처리기가 거부하는 숨은 메타데이터나 속성이 들어 있어요. 일반적이지 않은 방식으로 편집하거나 내보낸 이미지에서 가끔 생겨요.

### 4. 스티커 규격 불일치

스티커는 요구 조건이 매우 까다로워요. WebP 형식에 정확히 512 x 512 픽셀, 투명 배경, 100 KB 미만이어야 해요. 크기가 다르거나, 투명하지 않거나, 용량이 크거나, 형식이 다르면 오류 131053이 나와요.

### 5. 지원하지 않는 동영상 코덱

동영상은 H.264 비디오 코덱과 AAC 오디오 코덱을 써야 해요. H.265(HEVC), VP9, AV1 등 다른 코덱으로 인코딩한 동영상은 실패해요. 오디오 스트림도 하나만 있거나 없어야 해요. 오디오 트랙이 여러 개인 동영상은 지원하지 않아요.

### 6. 미디어 URL에 공개 접근이 불가능한 경우

URL(링크) 방식으로 미디어를 보낼 때는 URL이 HTTPS로 누구나 접근할 수 있어야 해요. 인증이 필요하거나, 방화벽 안에 있거나, HTTPS가 아닌 HTTP를 쓰거나, 리디렉션(302)을 반환하거나, Meta 서버에서 접근할 수 없으면 업로드가 실패하고 오류 131053이 나와요.

### 7. URL이 인식 가능한 파일 확장자로 끝나지 않는 경우

URL로 미디어를 보낼 때는 URL이 올바른 파일 확장자(예: `.jpg`, `.mp4`, `.pdf`)로 끝나야 해요. 확장자가 분명하지 않은 동적 URL은 Meta의 미디어 처리기가 제대로 인식하지 못할 수 있어요.

## 해결 방법

아래 순서대로 미디어 문제를 찾아 해결하세요.

1. 웹훅 응답의 `error_data.details` 필드를 확인하세요.

   실패한 메시지에서 발생한 웹훅에는 구체적인 이유가 `error_data.details` 필드에 담겨 있어요. 이 값을 가장 먼저 확인하세요. 지원하지 않는 MIME 타입이나 파일을 처리하지 못한 이유처럼 문제를 정확히 알려 주는 경우가 많아요.

2. 위의 지원 형식 표와 비교해 파일 형식을 확인하세요.

   파일 확장자만 보지 말고 실제 형식을 확인하세요. 지원하지 않는 형식이라면 아래 표를 참고해 변환하세요.

   | 지원하지 않는 형식 | 변환할 형식 | 참고 |
   | --- | --- | --- |
   | WebP(이미지로 보낼 때) | JPEG 또는 PNG | WebP는 스티커로만 보낼 수 있고, 일반 이미지로는 보낼 수 없어요 |
   | GIF | MP4 동영상 | 움직이는 GIF는 지원하지 않아요. 짧은 MP4로 변환하세요 |
   | TIFF / BMP / HEIC | JPEG 또는 PNG | 아무 이미지 편집기로 변환할 수 있어요 |
   | MOV / AVI / MKV | MP4(H.264 + AAC) | HandBrake나 ffmpeg로 올바른 코덱을 지정해 다시 인코딩하세요 |
   | WAV / FLAC / WMA | AAC 또는 MP3 | 오디오를 지원하는 형식으로 변환하세요 |
   | 용량 제한을 넘는 큰 파일 | 압축하거나 문서로 전송 | 문서는 최대 100 MB까지 보낼 수 있어서 큰 파일에 유용해요 |

3. 파일 용량이 제한 안에 들어오는지 확인하세요.

   파일이 해당 유형의 최대 용량보다 작은지 확인하세요. 너무 크면 압축한 뒤 다시 올리세요. 이미지는 TinyPNG, 동영상은 HandBrake 같은 도구를 쓰세요. 문서는 PDF로 내보내면 용량을 줄일 수 있어요. 용량은 암호화 후 기준으로 계산되어 실제 크기가 조금 늘어날 수 있으니, 제한보다 넉넉히 작게 맞추세요.

4. URL로 보낸다면 미디어 URL이 올바르고 공개 접근이 가능한지 확인하세요.

   - URL은 `https://`로 시작해야 해요. HTTP URL은 받지 않아요.
   - 인증이나 로그인 없이 누구나 접근할 수 있어야 해요. 시크릿 브라우저 창에 붙여 넣어 테스트해 보세요.
   - URL은 올바른 파일 확장자로 끝나야 해요. 예: `.jpg`, `.mp4`, `.pdf`
   - URL이 리디렉션(302 응답)을 반환하면 안 돼요. Meta 서버는 리디렉션을 따라가지 않아요. 최종 직접 URL을 쓰세요.

5. 파일을 다시 내보내거나 다시 저장해 숨은 속성을 제거하세요.

   파일 형식과 용량이 맞는데도 업로드가 실패한다면, 숨은 메타데이터나 속성이 원인일 수 있어요. 원래 쓰던 프로그램에서 파일을 다시 저장하거나 내보내세요. 이미지는 imagecompressor.com 같은 도구로 숨은 속성을 정리할 수 있어요. 동영상은 HandBrake나 ffmpeg로 다시 인코딩하면 깨끗한 파일로 새로 만들어져요.

6. 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.

   파일이 모든 형식·용량 조건을 충족하는데도 업로드가 실패한다면 고객지원에 문의하세요. 문의할 때 아래 내용을 함께 알려 주세요.

   - 파일 유형, 형식, 용량
   - `error_data.details` 값을 포함한 전체 오류 응답
   - URL로 보냈는지, 파일을 직접 업로드했는지
   - URL 방식이라면 미디어 파일의 URL(공개 접근이 가능한지 확인한 URL)

## 예방 방법

미디어 업로드 실패를 막으려면 아래 방법을 지키세요.

- 이미지는 항상 JPEG나 PNG를 쓰세요. 가장 안전하고 폭넓게 지원되는 형식이에요. 일반 이미지 메시지에는 WebP, TIFF, BMP, HEIC를 쓰지 마세요.
- 업로드 전에 모든 동영상을 H.264 + AAC의 MP4로 인코딩하세요. 모든 기기와 WhatsApp 버전에서 가장 안전한 조합이에요.
- 파일 용량은 제한보다 넉넉히 작게 유지하세요. 제한은 암호화 후 기준으로 적용되므로, 이미지는 4 MB, 동영상은 15 MB, 스티커는 80 KB 미만으로 맞추면 안전해요.
- 미디어는 안정적이고 공개 접근이 가능한 HTTPS 서버에 두세요. 임시 링크, 만료되는 서명 URL, 쿠키나 인증이 필요한 URL은 피하세요.
- 메시지에 쓰기 전에 미디어 URL을 테스트하세요. 시크릿 브라우저 창에서 URL을 열어 공개 접근이 가능한지, 올바른 파일이 바로 열리는지 확인하세요.
- 잘 모르겠다면 문서로 보내세요. 형식이 특이하거나 용량 제한에 가까운 파일은 문서 유형으로 보내면 돼요. 문서는 더 다양한 형식을 받고 최대 100 MB까지 지원해요.

## 관련 오류 코드

미디어와 관련해 함께 마주칠 수 있는 오류예요.

| 오류 코드 | 제목 | 설명 |
| --- | --- | --- |
| 131052 | 미디어 다운로드 오류(Media Download Error) | 제공한 URL에서 WhatsApp이 미디어를 내려받지 못했어요. 깨진 링크, 느린 서버, 접근할 수 없는 파일이 원인이에요. |
| 131051 | 지원하지 않는 메시지 유형(Unsupported Message Type) | 메시지 유형 자체를 WhatsApp Business API가 지원하지 않아요. |
| 100 | 잘못된 파라미터(Invalid Parameter) | 요청에 포함된 API 파라미터가 하나 이상 잘못되었거나 형식이 올바르지 않아요. |
| 131026 | 메시지 전달 불가(Message Undeliverable) | 메시지가 전달되지 않았어요. 유효하지 않은 번호, 차단된 연락처, 마케팅 메시지 빈도 제한이 원인이에요. |

## 자주 묻는 질문

### 이미지가 JPEG인데도 오류 131053이 나와요. 왜 그런가요?
파일 확장자가 실제 인코딩과 항상 같지는 않아요. `.jpg`로 저장된 파일도 내부적으로는 WebP 등 다른 형식일 수 있어요. `error_data.details` 필드에서 감지된 정확한 MIME 타입을 확인하세요. 그리고 이미지 편집기에서 JPEG로 다시 내보내 올바르게 인코딩하세요.

### WhatsApp Business API로 GIF 애니메이션을 보낼 수 있나요?
아니요. WhatsApp Business API는 움직이는 GIF를 지원하지 않아요. 애니메이션을 보내야 한다면 H.264와 AAC 코덱의 짧은 MP4 동영상으로 변환하세요. 대화에서 WhatsApp이 바로 재생해 줘요.

### 동영상이 16 MB 미만이고 MP4인데도 계속 실패해요. 왜 그런가요?
MP4는 올바른 컨테이너 형식이지만, 코덱도 맞아야 해요. 비디오는 H.264, 오디오는 AAC여야 해요. 많은 MP4 파일이 H.265(HEVC) 등 WhatsApp이 지원하지 않는 코덱을 써요. HandBrake나 ffmpeg로 H.264 + AAC로 다시 인코딩하면 호환돼요.

### WhatsApp Business API로 WebP 이미지를 보낼 수 있나요?
네, 하지만 스티커로만 보낼 수 있어요. WebP 파일을 일반 이미지 메시지로 보내면 항상 오류 131053이 나와요. 일반 이미지로 보내려면 먼저 JPEG나 PNG로 변환하세요. 스티커로 보내려면 정확히 512x512 픽셀에 투명 배경이어야 하고, 100 KB 미만이어야 해요.

### 오류 131052와 오류 131053은 어떻게 다른가요?
오류 131052(미디어 다운로드 오류)는 제공한 URL에서 WhatsApp이 미디어를 내려받지 못할 때 발생해요. URL이 깨졌거나, 느리거나, 접근할 수 없는 경우예요. 오류 131053(미디어 업로드 오류)은 WhatsApp이 파일에는 접근했지만 처리하거나 업로드하지 못할 때 발생해요. 대개 지원하지 않는 형식, 잘못된 코덱, 손상된 파일이 원인이에요.

## 요약

오류 131053은 WhatsApp이 미디어 파일을 업로드하지 못했다는 뜻이에요. 먼저 `error_data.details` 필드에서 정확한 이유를 확인하세요. 대부분 지원하지 않는 형식, 잘못된 코덱, 용량 초과가 원인이에요. 이미지는 JPEG나 PNG로, 동영상은 H.264와 AAC의 MP4로 변환하고, 파일 용량은 제한보다 넉넉히 작게 유지하세요. URL을 쓴다면 HTTPS이고, 공개 접근이 가능하며, 올바른 파일 확장자로 끝나는지 확인하세요.
