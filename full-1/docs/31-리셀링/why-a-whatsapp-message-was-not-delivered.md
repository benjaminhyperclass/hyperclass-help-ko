# WhatsApp 메시지가 전달되지 않는 이유

WhatsApp 메시지가 "발송됨(sent)"으로만 표시되고 "전달됨(delivered)"으로 바뀌지 않을 때 확인할 만한 대표적인 원인과 해결 방법을 정리했어요.

## 메시지가 전달되지 않는 주요 원인

### 수신자가 30일 넘게 오프라인이었어요

WhatsApp은 오프라인 상태인 사용자의 메시지를 최대 30일까지 보관해요. 이 기간 안에 수신자가 접속하지 않으면 메시지는 전달되지 않아요.

### 수신자가 내 번호를 차단했어요

수신자가 내 비즈니스 번호(또는 같은 계정의 다른 비즈니스 번호)를 차단했다면 메시지가 전달되지 않아요.

### 지역 제한

다음 지역의 사용자나 비즈니스는 WhatsApp Business Platform을 사용할 수 없어요.

- 쿠바
- 이란
- 북한
- 시리아
- 크림반도, 도네츠크, 루한스크(우크라이나)

{% hint style="info" %}
2024년 5월 15일부터 튀르키예(Türkiye)에서도 Cloud API 메시지를 사용할 수 있어요.
{% endhint %}

### 앱 버전이 오래됐거나 약관에 동의하지 않았어요

수신자가 다음에 해당하면 메시지 전달에 실패할 수 있어요.

- 오래된 버전의 WhatsApp을 쓰고 있어요.
- 최신 서비스 이용약관에 동의하지 않았어요.

해결하려면 수신자에게 앱을 업데이트하고, 아래 링크에서 최신 약관에 동의해 달라고 요청하세요: <https://wa.me/tos/20210210>

### 메시지 품질 유지를 위한 제한

WhatsApp은 메시지 품질을 지키기 위해 사용자 한 명이 받을 수 있는 마케팅 메시지 수를 제한해요. 한 사용자가 마케팅 메시지를 너무 많이 받으면(보통 하루 5~6건) 이후 마케팅 메시지가 일시적으로 차단될 수 있어요.

### 유효하지 않거나 등록되지 않은 전화번호

전화번호가 WhatsApp에 등록되어 있지 않거나 잘못 입력했다면 메시지가 전달되지 않아요.

### API 오류 또는 잘못된 파라미터

API 요청에 빠지거나 잘못된 필드가 있으면 요청이 거부될 수 있어요. 예를 들어 변수 형식이 올바르지 않은 경우예요.

### "전달됨"과 "실패"가 함께 표시돼요

수신자가 여러 기기에서 WhatsApp에 로그인해 있으면 한 메시지에 "전달됨"과 "실패" 상태가 함께 보일 수 있어요. 기기 한 대에라도 전달됐다면 정상적으로 전달된 것으로 봐요.

## 고객에게 요청할 수 있는 조치

전달 실패의 원인이 분명하지 않다면, 고객에게 아래 내용을 부탁해 보세요. 원인을 찾거나 문제를 해결하는 데 도움이 돼요.

- 내 WhatsApp 번호를 차단하지 않았는지 확인해 달라고 요청하세요.
- 고객이 먼저 내 비즈니스로 메시지를 보내게 하세요. 이렇게 하면 24시간 고객 서비스 창이 다시 열려요.
- WhatsApp의 최신 서비스 이용약관에 동의했는지 확인해 달라고 요청하세요.
- 기기에 맞는 최신 버전의 WhatsApp으로 업데이트해 달라고 요청하세요.
- 제한된 버전이나 지원되지 않는 지역에서 사용하고 있지 않은지 확인하세요.

## 기술적인 문제와 해결 방법

### 인증 및 권한 오류

액세스 토큰이 유효하지 않거나 필요한 권한이 없을 때 생기는 오류예요.

해결 방법:

- [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken/)로 토큰 권한을 확인하세요.
- 토큰에 다음 권한 범위(scope)가 있는지 확인하세요.
  - `whatsapp_business_management`
  - `whatsapp_business_messaging`
- 없다면 올바른 권한으로 토큰을 다시 생성하세요.

### Meta API 서비스 중단 (오류 코드 2)

Meta가 API를 업데이트할 때 최대 5분 정도 짧은 중단이 생길 수 있어요.

해결 방법:

- 5분 기다린 뒤 API 호출을 다시 시도하세요.

## 자주 묻는 질문

### WhatsApp 메시지가 "발송됨"으로만 표시되고 전달되지 않아요. 왜 그런가요?

다음과 같은 원인이 있을 수 있어요.

- 수신자가 30일 넘게 오프라인이에요.
- 수신자가 내 번호를 차단했어요.
- 수신자가 최신 WhatsApp 서비스 이용약관에 동의하지 않았어요.
- 수신자가 오래된 버전의 WhatsApp을 쓰고 있어요.
- 수신자의 번호가 유효하지 않거나 WhatsApp에 연결되어 있지 않아요.
- 마케팅 메시지 품질 제한 때문에 메시지가 걸러졌어요.
- 수신자가 WhatsApp Business Platform 사용이 제한된 지역에 있어요.

### "Message Undeliverable"은 무슨 뜻인가요?

보통 메시지가 내 시스템에서는 발송됐지만 수신자의 기기에는 전달되지 못했다는 뜻이에요. 수신자가 내 번호를 차단했거나, 오프라인 기간이 너무 길거나, Meta 쪽의 기술적·정책적 제한이 있을 때 생길 수 있어요.

### 수신자가 내 번호를 차단했는지 어떻게 확인하나요?

개인정보 보호 정책 때문에 차단 여부를 직접 알려 주지는 않아요. 다만 같은 수신자에게 보낸 다른 메시지가 전달되는데도 오랫동안 반응이 없다면 차단했을 가능성이 있어요.

### 24시간 고객 서비스 창이란 무엇인가요?

사용자가 내 비즈니스로 메시지를 보내면, 그때부터 24시간 동안은 자유 형식 메시지로 답할 수 있어요. 이 시간이 지나면 미리 승인된 템플릿으로만 대화를 다시 시작할 수 있어요.

### "High-Quality User Experience" 오류는 무엇인가요?

사용자가 마케팅 메시지를 너무 많이(예: 하루 5~6건) 받으면, WhatsApp이 메시지 품질을 지키기 위해 이후 마케팅 메시지를 제한할 수 있어요. 유틸리티 템플릿은 이 제한의 영향을 받지 않아요.

### "High-Quality User Experience" 전달 문제는 어떻게 해결하나요?

다음 방법을 시도해 보세요.

- 고객이 먼저 메시지를 보내게 하세요. 24시간 창이 다시 열려요.
- 마케팅 템플릿 대신 유틸리티 템플릿을 사용하세요.
- 잠시 기다린 뒤 메시지를 다시 보내세요.

### 수신자의 WhatsApp 버전이 오래됐는지 어떻게 알 수 있나요?

수신자에게 WhatsApp을 아래 버전 이상으로 업데이트해 달라고 요청하세요.

- Android: 2.21.15.15 이상
- iOS: 2.21.170.4 이상
- Web: 2.2132.6 이상

이보다 오래된 버전은 새 API 기능을 지원하지 않아 메시지 전달이 막힐 수 있어요.

### 모든 국가의 사용자가 WhatsApp Business 메시지를 받을 수 있나요?

아니요. 다음을 포함한 일부 국가에서는 WhatsApp Business Platform 사용이 제한돼요.

- 쿠바
- 이란
- 북한
- 시리아
- 크림반도, 도네츠크, 루한스크(우크라이나)

### 같은 메시지에 "전달됨"과 "실패"가 함께 보여요. 무슨 뜻인가요?

수신자가 여러 기기에서 로그인해 있을 때 생길 수 있어요. 메시지가 기기 한 대 이상에는 전달됐지만, 다른 기기에서는 실패했을 수 있어요.

### 메시지를 보낼 때 인증 또는 권한 오류가 나면 어떻게 하나요?

- [Meta Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken/)로 토큰이 유효한지 확인하세요.
- 토큰에 다음 권한이 포함되어 있는지 확인하세요.
  - `whatsapp_business_management`
  - `whatsapp_business_messaging`

권한이 없다면 올바른 권한으로 액세스 토큰을 다시 생성하세요.
