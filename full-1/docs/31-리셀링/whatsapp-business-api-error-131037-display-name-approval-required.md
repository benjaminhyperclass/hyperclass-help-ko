# WhatsApp Business API 오류 #131037 — 표시 이름 승인 필요

WhatsApp 번호로 메시지를 보낼 때 오류 #131037이 나타나면, Meta가 번호의 표시 이름을 아직 승인하지 않았다는 뜻이에요. 이 문서에서 원인과 해결 방법을 확인하세요.

오류 메시지는 다음과 같아요.

```
(#131037) WhatsApp provided number needs display name approval before message can be sent
```

하이퍼클래스에서 WhatsApp 비즈니스 계정(WABA)으로 메시지를 보낼 때 이 오류가 보이면, 번호의 표시 이름이 아직 Meta의 승인을 받지 못한 상태예요. 승인이 나기 전에는 이 번호로 플랫폼에서 메시지를 보내거나 받을 수 없어요.

{% hint style="info" %}
Meta 문서로 확인이 필요한 내용이에요. 최근 자료 여러 곳에서 오류 131037은 대부분 WhatsApp이 제공하는 무료 테스트 번호(+1-555 번호)와 관련 있다고 설명해요. 또 Meta는 직접 준비한 일반 Cloud API 번호에서는 메시지를 시작할 때 표시 이름 검토를 더 이상 필수 단계로 요구하지 않는다고 해요. 고객이 직접 등록한 비즈니스 번호에서 이 오류가 나면, 처음 받는 승인 절차 때문인지 아래에서 설명하는 이름 변경 재검토나 BSP 이전 때문인지 먼저 확인하세요. 상황마다 원인이 조금씩 달라요.
{% endhint %}

## 오류가 발생하는 이유

모든 WhatsApp 비즈니스 전화번호는 메시지를 보내기 전에 Meta가 승인한 표시 이름이 있어야 해요. WhatsApp 비즈니스 계정에 새 번호를 등록하면, Meta가 표시 이름이 WhatsApp의 이름 규정과 비즈니스 정책에 맞는지 검토해요.

{% hint style="warning" %}
표시 이름이 **검토 대기 중**이거나 **거절됨** 상태이면 보내는 메시지와 받는 메시지가 모두 막혀요. 이때 오류 #131037이 나타나요.
{% endhint %}

보통 다음 두 가지 경우에 발생해요.

- 시나리오 1: WABA에 새 전화번호를 추가했는데, 표시 이름이 아직 Meta의 검토를 기다리고 있어요.
- 시나리오 2: 번호를 새 비즈니스 솔루션 제공업체(BSP)로 이전했어요. 이전하면 표시 이름을 처음부터 다시 검토할 수 있어요.

## 오류 해결 방법

1. Meta Business Manager에 로그인하세요.
   - `business.facebook.com`에 접속해 WABA와 연결된 계정으로 로그인해요.
2. WhatsApp 계정으로 이동하세요.
   - **Business Settings**(비즈니스 설정) **> 계정 > WhatsApp Accounts**(WhatsApp 계정)를 열고 해당 WABA를 선택해요.
3. **전화번호** 탭을 여세요.
   - 오류가 나는 전화번호를 찾아요. 표시 이름의 현재 상태는 **검토 대기 중**, **Approved**(승인됨), **거절됨** 중 하나로 보여요.
4. 현재 상태에 맞게 조치하세요.
   - 상태가 **검토 대기 중**이면 따로 할 일은 없어요. Meta의 검토가 끝날 때까지 기다리세요. 보통 24~48시간이 걸리고, 승인되면 오류는 자동으로 해결돼요.
   - 상태가 **거절됨**이면 Meta Business Manager에서 **Edit Display Name**(표시 이름 편집)을 클릭해 다시 제출하세요. 이름이 비즈니스를 분명하게 나타내고 WhatsApp의 표시 이름 가이드라인을 지키는지 확인하세요.
5. 승인을 기다리거나 확인하세요.
   - 승인되면 오류가 자동으로 해결되고, 하이퍼클래스에서 메시지가 정상적으로 오가요.

## 표시 이름 작성 시 참고할 점

거절된 표시 이름을 다시 제출할 때는 [Meta의 가이드라인](https://www.facebook.com/business/help/757569725593362)을 확인하세요. 다음 사항을 지키면 다시 거절되는 일을 줄일 수 있어요.

- 실제 비즈니스 이름이나 브랜드 이름을 쓰세요. 일반적이거나 오해를 줄 수 있는 이름은 쓰지 마세요.
- 다른 비즈니스나 개인을 사칭하는 이름은 피하세요.
- 표시 이름은 등록한 비즈니스 정보나 웹사이트와 일치해야 해요.
- 표시 이름에 URL, 전화번호, 홍보 문구를 넣지 마세요.

{% hint style="info" %}
다른 BSP에서 옮겨 오셨나요? 다른 비즈니스 솔루션 제공업체에서 하이퍼클래스로 번호를 옮겼다면, 새 Business Manager에서 표시 이름 검토가 다시 시작될 수 있어요. 번호를 옮긴 뒤 메시지를 보내기 전에는 항상 Meta에서 승인 상태를 먼저 확인하세요.
{% endhint %}
