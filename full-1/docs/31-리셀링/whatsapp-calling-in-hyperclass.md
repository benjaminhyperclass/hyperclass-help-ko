# 하이퍼클래스에서 WhatsApp 통화 사용하기

WhatsApp 통화를 켜면 하이퍼클래스 안의 WhatsApp 대화에서 바로 음성 통화를 걸고 받을 수 있어요. 외부 전화 앱이나 개인 전화번호를 쓰지 않아도 돼요. 이 문서에서는 WhatsApp 통화를 설정하는 방법, 통화 권한을 관리하는 방법, 웹과 모바일에서 사용하는 방법을 안내해요.

이 문서에서 배울 내용은 다음과 같아요.

- WhatsApp 통화가 무엇인지
- 통화를 켜고 설정하는 방법
- 통화 권한을 설정하는 방법
- 통화를 걸고 받는 방법

## WhatsApp 통화란?

메시지와 음성 통화를 한곳에서 쓸 수 있어요. 앱을 오갈 필요가 없어요.

{% hint style="info" %}
**WhatsApp 통화 사용 신청 (베타)**

WhatsApp 통화는 현재 베타 단계라서 모든 사용자에게 열려 있지 않아요. 사용하려면 아래 베타 신청 폼을 작성해 주세요.

`https://api.leadconnectorhq.com/widget/form/xpGWoA9VnKVWRqr4oibs`
{% endhint %}

WhatsApp 통화를 쓰면 기존 WhatsApp 대화 안에서 메시지 상담을 음성 통화로 바로 이어 갈 수 있어요. 통화가 같은 대화 안에 남기 때문에 맥락이 유지되고, 통화 기록도 메시지와 함께 자동으로 쌓여요.

고객이 건 수신 통화와, 비즈니스가 먼저 거는 발신 통화(Meta에서 지원하는 경우)를 모두 쓸 수 있어요. 영업팀과 지원팀이 다른 앱이나 외부 전화 시스템 없이 소통할 수 있어요.

**주요 기능**

- 하이퍼클래스 안에서 WhatsApp 음성 통화를 걸고 받기
- 웹과 하이퍼클래스 모바일 앱에서 WhatsApp 통화 사용하기
- 영업시간과 일시적으로 통화할 수 없는 시간 설정하기
- 수신 통화를 여러 사용자에게 연결하기
- 비즈니스가 먼저 전화하기 전에 고객에게 허락 요청하기
- 모든 WhatsApp 통화를 일반 전화 통화와 함께 확인하기
- 통화가 끝나면 통화 처리 결과(disposition) 직접 지정하기
- 통화 결과에 따라 자동화 실행하기

## WhatsApp 통화의 장점

복잡한 문의는 메시지를 길게 주고받는 것보다 음성 통화로 풀면 더 빨리 해결되는 경우가 많아요. WhatsApp 통화는 메시지와 음성을 하나의 고객 경험으로 묶고, 관리자가 모든 상담 내용을 볼 수 있게 해 줘요.

- **대화를 한곳에 모아요:** 통화와 메시지가 같은 WhatsApp 대화에 남아서 고객 상황을 한눈에 볼 수 있어요.
- **문제를 더 빨리 해결해요:** 메시지로는 비효율적일 때 클릭 한 번으로 채팅에서 음성 통화로 넘어갈 수 있어요.
- **영업 전환율을 높여요:** 구매 의사가 높은 리드와 관심이 있는 바로 그 순간에 통화할 수 있어요.
- **통화 가능 시간을 직접 정해요:** 영업시간과 일시적으로 통화할 수 없는 일정을 설정해 고객이 전화할 수 있는 시간을 조절해요.
- **통화를 똑똑하게 연결해요:** 수신 WhatsApp 통화를 지정한 팀원이나 연락처의 담당 사용자에게 연결해요.
- **자동화와 연결돼요:** 통화가 끝날 때마다 지정한 통화 처리 결과에 따라 워크플로우를 실행할 수 있어요.
- **리포팅을 한곳에서 봐요:** **통화 리포팅**에서 WhatsApp 통화 성과를 다른 음성 활동과 함께 확인해요.
- **웹과 모바일에서 모두 써요:** 데스크톱에서든 모바일 기기에서든 통화를 받고 걸 수 있어요.

## 사전 준비 사항

필수 조건을 갖춰야 WhatsApp 통화가 제대로 작동하고 Meta의 사용 조건에도 맞아요. 기능을 켜기 전에 아래 조건을 하나씩 확인하세요.

서브 계정이 다음 조건을 모두 충족해야 해요.

- WhatsApp 전화번호가 연결되어 있고 **연결됨** 상태예요.
- WhatsApp 비즈니스 계정(WABA)의 메시지 한도가 **2,000개 대화 이상**이에요.
- 해당 전화번호가 **WhatsApp Coexistence를 사용하지 않아요**.
- 사용자에게 연결된 WhatsApp 번호에 접근할 권한이 있어요.
- 모바일에서 통화하려면 하이퍼클래스 모바일 앱 **4.18 버전 이상**이 설치되어 있어요.
  - 화이트라벨 모바일 앱도 WhatsApp 통화를 지원하는 버전으로 업데이트해야 해요.

## WhatsApp 통화 켜기

서브 계정에서 통화를 사용할 수 있게 켜는 방법이에요.

제공된 신청 링크를 눌러 필요한 정보를 입력하고 신청 폼을 제출하세요. 제출하면 **24시간 안에** 서브 계정에서 WhatsApp 통화를 쓸 수 있게 돼요.

{% hint style="info" %}
**사용 전 확인할 요건**

- WhatsApp 번호가 Meta의 WhatsApp Business API에서 지원하는 번호여야 해요.
- WhatsApp 통화는 Coexistence(한 번호에서 WhatsApp 앱과 API를 함께 쓰는 방식)를 지원하지 않아요.
- 비즈니스의 메시지 한도가 24시간 기준으로 비즈니스가 먼저 시작하는 대화 2,000건 이상이어야 해요. 계정 기능 확장에 대한 상세 정보도 확인할 수 있어요.
{% endhint %}

## 국가별 사용 가능 여부

WhatsApp 통화는 대부분의 국가에서 쓸 수 있어요. 다만 비즈니스가 먼저 거는 통화(BIC)는 현재 아래 국가에서 **지원되지 않아요**.

- 미국
- 캐나다
- 튀르키예
- 이집트
- 베트남
- 나이지리아

비즈니스나 고객이 이 국가에 있다면 지금은 비즈니스가 먼저 거는 통화(BIC)를 쓸 수 없어요.

## WhatsApp 수신 통화 (고객이 먼저 거는 통화)

고객이 WhatsApp으로 비즈니스에 직접 전화를 거는 경우예요. 이런 통화는 다른 알림처럼 CRM 안에 나타나요. 전화를 받거나 거절할 수 있고, 설정해 두었다면 음성사서함으로 넘길 수도 있어요.

**CRM에서의 작동 방식**

- 고객이 전화하면 CRM의 메시지 또는 통화 화면에 알림이 나타나요.
- CRM 안에서 **바로 통화를 받을 수** 있어요. WhatsApp을 따로 열 필요가 없어요.
- 통화가 끝나면 통화 시간, 길이, 결과 같은 상세 내용이 고객 대화에 연결되어 저장되고, 나중에 다시 확인할 수 있어요.

[동영상](https://watchclueso.com/embed/nr66jh4pyn0my1pz)

## WhatsApp 통화 설정하기

전화번호를 설정하고 통화를 처리할 사용자를 지정하는 방법이에요.

1. **WhatsApp**을 열고 **설정**으로 이동하세요.

   ![WhatsApp 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597360/original/bLs9rRGI73eKFGnEbBlIdQLz1ZGzhC7UyQ.png?1776768958)

2. 메뉴에서 **전화 거는 중**을 선택하세요.

   ![메뉴에서 전화 거는 중 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597830/original/Uy52qjpXwlZx3meYlEa8ctfNLGNQt-yaDw.png?1776769266)

3. **연결됨**으로 표시된 전화번호 목록이 보여요. 통화용으로 설정할 번호를 찾으세요.
4. 설정할 번호 옆의 **관리**를 클릭하세요.
5. 워크스페이스 어디서나 쉽게 알아볼 수 있도록 **친숙한 이름**(예: *영업팀*)을 지정하세요.

   ![친숙한 이름 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069594284/original/3KQ8jnEyfOd6YZU7mPo-_NK5FjcfgRpcvQ.png?1776767351)

6. **WhatsApp 통화 수신 대상**에서 수신 통화를 받을 사용자를 추가하세요. 먼저 울릴 **주 담당 사용자**를 정하고, 필요하면 대기용 사용자를 더 추가하세요.

   ![WhatsApp 통화 수신 대상 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069594793/original/dCUjG_mi_C1a9rPlaFcEylRgHT0yufXEGA.png?1776767564)

7. **음성 통화 허용**을 켜면 이 번호에서 WhatsApp 통화를 쓸 수 있어요. **Allow People to Request Callback for Missed Calls**(부재중 통화 시 콜백 요청 허용)를 켜면 전화를 받지 못했을 때 고객이 다시 전화해 달라고 요청할 수 있어요.
8. **Display Call Button**(통화 버튼 표시)을 켜면 고객이 WhatsApp 비즈니스 프로필에서 바로 통화 옵션을 볼 수 있어요.

   ![통화 버튼 표시 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597841/original/psv8jkMyktJMlIftbzOGpEcKVr5qTDSpfQ.png?1776769284)

9. 팀의 일정과 근무 상황에 맞게 **Available Callers**(통화 가능 담당자)와 **Temporarily Unavailable Callers**(일시적으로 통화할 수 없는 담당자)를 설정하세요.

   ![통화 가능 담당자 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069593579/original/gah6QaPHDW3Kxa4l3ND_VcpVDtFjW2r_vQ.png?1776767005)

{% hint style="info" %}
통화 가능 담당자를 최신 상태로 유지하세요. 수신 통화가 항상 알맞은 사람에게 연결되고, 놓치는 통화도 줄어요.
{% endhint %}

## WhatsApp 통화 권한 설정하기

고객에게 통화 권한을 요청하고 관리하는 방법이에요.

{% hint style="warning" %}
WhatsApp에서는 연락처에 통화를 걸려면 고객의 명시적인 승인이 있어야 해요. 통화를 시작하기 전에 항상 권한이 활성 상태인지 확인하세요.
{% endhint %}

1. **설정** > **WhatsApp Templates**(WhatsApp 템플릿)로 이동하세요.
2. **새 템플릿 만들기**로 고객에게 통화 권한을 요청하는 템플릿을 만드세요.
3. **Call-to-Action Buttons**(행동 유도 버튼)에서 **WhatsApp Call Permissions**(WhatsApp 통화 권한)를 선택하세요. 고객이 눌러서 통화 권한을 허용할 수 있는 버튼이 템플릿에 추가돼요.

   ![WhatsApp 통화 권한 버튼 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597849/original/76RQlsjsLAzwb5ORzWLmPRM0JMS8nO22Pw.png?1776769302)

4. 고객이 이 메시지를 받으면 버튼을 눌러 **일시적** 또는 **무제한** 기간으로 권한을 허용해요.
5. 템플릿에 통화 버튼을 바로 넣을 수도 있어요. 사용 목적에 따라 권한 기간을 **1일, 7일, 15일, 30일** 중에서 정할 수 있어요.
   <!-- 검토 필요: 원문 내용이 서로 다름 (아래 '임시 권한' 설명에서는 임시 권한이 7일간 유지된다고 안내) -->

   ![권한 기간 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069593581/original/xbgjUIRB8nes2eipsg9DVpFbSttovJNkBw.png?1776767005)

고객이 권한을 허용하면 통화를 처리할 준비가 끝나요.

## WhatsApp 통화 걸고 받기

**대화** 화면에서 통화를 시작하고 받는 방법이에요.

1. **대화**로 이동해 연락처를 연 다음, 메시지 채널로 **WhatsApp**을 선택하세요.

   ![대화에서 WhatsApp 채널 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069596270/original/0vqB4nOQXe5QNuBGSfNU5ZXnXahIi88hrw.png?1776768237)

2. 통화 권한을 요청하는 메시지 템플릿을 선택해 고객에게 보내세요.
3. 고객이 권한을 허용하면 상태가 **"Call permissions active indefinitely"**(통화 권한이 무기한 활성)로 바뀌어요. 고객이 기간을 정했다면 그 기간이 표시돼요.

   ![통화 권한 활성 상태](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597879/original/lKp8lQfL53xVS6OAK_pnVUFs8-v_SzL6wQ.png?1776769328)

4. 통화를 걸거나 받는 중에는 통화 종료 옵션과, 결과를 기록하는 통화 처리 결과(disposition) 추가 옵션이 보여요.

   ![통화 종료 및 통화 처리 결과 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069596524/original/MbloHKJEuLMX6vhcJo60Apetv944ciqscw.png?1776768349)

5. 수신 통화의 경우 고객이 WhatsApp 비즈니스 프로필의 **통화 버튼**을 눌러 바로 전화할 수 있어요. 통화는 통화 설정에서 지정한 사용자에게 울려요.

{% hint style="info" %}
통화가 끝날 때마다 통화 처리 결과를 추가하세요. 팀의 기록이 정확해지고 후속 연락도 쉬워져요.
{% endhint %}

## 직원별 통화 설정하기

직원마다 WhatsApp 통화를 받을 기본 채널을 정하는 방법이에요.

1. **설정** > **스태프 관리**로 이동하세요.
2. 지정한 직원을 검색하고 **편집**을 클릭하세요.
3. **Calling & Voicemail**(통화 및 음성사서함) 탭을 여세요.
4. **Default Channel for WhatsApp Calls**(WhatsApp 통화 기본 채널)를 **모바일 앱** 또는 **웹 앱**으로 설정하세요.

   ![WhatsApp 통화 기본 채널 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062503358/original/zdRC0vWcpOawO9-QNwpr2x_6CcFMP-TtVA.png?1768283146)

- **모바일 앱**: 직원의 모바일 기기에서 통화가 울려요.
- **웹 앱**: CRM 브라우저 화면에서 통화가 울려요.

모든 준비가 끝났어요. WhatsApp 통화를 쓰면 기존 메시지 업무 흐름 안에서 빠르고 안정적으로 음성 소통을 할 수 있어요. 통화 가능 설정을 최신으로 유지하고, 권한 요청에 빠르게 응답하고, 통화 처리 결과로 기록을 정리해 보세요. 팀은 언제든 연락이 닿고, 고객은 계속 소통할 수 있어요.

## WhatsApp 사용자 통화 권한 안내

비즈니스가 WhatsApp 음성 통화를 걸려면 먼저 고객이 권한을 허용해야 해요. 이 안내에서는 권한이 어떻게 작동하는지, 어떻게 요청하는지, 만료되거나 철회되면 어떻게 되는지 설명해요.

이 안내에서 배울 내용은 다음과 같아요.

- 권한이 작동하는 방식
- 임시 권한과 영구 권한의 차이
- 권한 한도와 규칙
- 만료와 받지 않은 통화

### 개요

통화 권한은 항상 사용자가 정해요.

WhatsApp 사용자에게 전화하려면 비즈니스가 먼저 그 사용자의 허락을 받아야 해요. 비즈니스는 이를 조절할 수 없어요. 권한은 사용자만 언제든 허용하거나 철회할 수 있어요.

**고객이 통화 권한을 허용하는 방법은 세 가지예요.**

- **권한 요청 메시지:** 통화 권한을 요청하는 자유 형식 메시지나 템플릿 메시지를 고객에게 보내요.
- **고객이 먼저 전화하는 경우:** 사용자가 비즈니스에 전화하면 임시 권한이 자동으로 허용돼요. 이때 콜백 설정이 켜져 있어야 해요.
- **비즈니스 프로필을 통한 방법:** 사용자가 WhatsApp **비즈니스 프로필**에서 언제든 직접 통화 권한을 허용하거나 바꿀 수 있어요.

### 임시 권한과 영구 권한

영구 권한은 2025년 11월 3일부터 쓸 수 있어요.

고객이 통화 권한 요청을 승인할 때는 두 가지 중에서 선택해요.

**임시 권한**

- 사용자가 승인한 순간부터 **7일(168시간)** 동안 유지돼요.
- 자동으로 만료되고, 만료될 때 알림은 가지 않아요.
- 연결된 통화 한도가 적용돼요.
- 만료된 후에는 다시 요청할 수 있어요.

**영구 권한**

- **만료되지 않아요.**
- 사용자가 직접 철회할 때까지 유지돼요.
- 같은 연결된 통화 한도가 적용돼요.
- 사용자는 **비즈니스 프로필**에서 언제든 철회할 수 있어요.

고객의 WhatsApp 앱에서는 권한 옵션이 **Allow Calls**(통화 허용, 영구 권한)와 **Temporarily Allow Calls**(일시적으로 통화 허용)로 보여요.

### 권한 한도

사용자를 보호하기 위해 WhatsApp이 자동으로 적용하는 한도예요.

| 한도 | 값 |
| --- | --- |
| 연락처당 하루 권한 요청 수 | 24시간에 최대 1회 |
| 7일 동안의 권한 요청 수 | 최대 2회 |
| 비즈니스 전화번호당 연결된 통화 수 | 24시간에 최대 100건 |
| 임시 권한 유지 기간 | 7일(168시간) |
| 한도가 초기화되는 때 | 비즈니스와 사용자 사이에 연결된 통화가 한 번이라도 이루어질 때 |

### 통화 권한 요청하기

고객에게 권한 요청 메시지를 먼저 보내 통화 권한을 요청할 수 있어요. 고객은 **승인(임시 또는 영구)**하거나 **거절**하거나, 응답하지 않을 수 있어요.

{% hint style="warning" %}
고객이 권한을 승인해도 언제든 철회할 수 있어요. 반대로 고객이 거절했더라도 요청이 만료되기 전이라면 나중에 권한을 허용할 수 있어요.
{% endhint %}

### 자유 형식 메시지와 템플릿 메시지

대화 기록에 따라 알맞은 메시지 유형을 고르세요.

**자유 형식 메시지**

**사용 시점:** 연락처와 열려 있는 고객 서비스 창이 있을 때예요.

- 본문 텍스트는 선택이지만 넣는 것을 권장해요.
- 머리글과 바닥글은 **지원되지 않아요**.
- 새 대화 창이 필요하지 않아요.

**템플릿 메시지**

**사용 시점:** 연락처와 최근에 나눈 대화가 없을 때예요.

- 본문 텍스트가 **필수**예요.
- 머리글과 바닥글을 쓸 수 있어요.
- WhatsApp의 사전 승인이 필요해요.

### 연속으로 받지 않은 통화

비즈니스가 고객에게 계속 전화했는데 받지 않으면 WhatsApp이 자동으로 사용자를 보호해요.

- **연속 2회 받지 않은 경우:** WhatsApp이 사용자에게 **시스템 메시지**를 보내, 이 비즈니스의 통화를 계속 허용할지 다시 생각해 보도록 안내해요.
- **연속 4회 받지 않은 경우:** WhatsApp이 통화 권한을 **자동으로 철회**해요. 사용자가 다시 허용할 수 있지만, 사용자 본인이 직접 해야 해요.

{% hint style="info" %}
분명하고 관련 있는 이유가 있을 때만 고객에게 전화하세요. 받지 않은 통화가 반복되면 신뢰가 떨어지고, 자동 경고가 나가고, 권한이 영구적으로 철회될 수 있어요.
{% endhint %}

### 권한 요청 만료 시나리오

권한 요청은 다음 세 가지 경우에 만료돼요.

| 상황 | 결과 |
| --- | --- |
| 사용자가 요청을 승인하거나 거절한 경우 | 사용자가 응답한 때로부터 7일 후 요청이 만료돼요 |
| 사용자가 응답하지 않은 경우 | 요청이 전달된 때로부터 7일 후 만료돼요 |
| 새 권한 요청을 보낸 경우 | 이전 요청이 **즉시** 만료돼요 |

**만료 시나리오 화면 예시**

- 7일 후 만료(사용자가 응답한 경우)
- 7일 후 만료(응답 없음)
- 이전 요청 만료, 새 요청 수신
- 이전 요청 만료, 사용자가 새 요청 승인

{% hint style="info" %}
임시 권한이 만료될 때는 웹훅 알림이 가지 않아요. 연락처의 현재 권한 상태를 확인하려면 WhatsApp Business API의 `Get Current Call Permission State` 엔드포인트를 조회하세요.
{% endhint %}

### 핵심 정리

통화 권한은 항상 사용자가 정해요. 요청은 할 수 있지만 강제할 수는 없어요. 메시지는 분명하고 관련 있게 쓰고, 요청 한도를 지키고, 정말 필요할 때만 전화하고, 받지 않은 통화는 신중하게 다루세요. 그러면 고객의 신뢰를 얻고 권한 상태도 건강하게 유지할 수 있어요.

## 자주 묻는 질문

### 데스크톱 브라우저에서도 WhatsApp 통화를 할 수 있나요?
네. 직원 설정에서 **Default Channel for WhatsApp Calls**를 **웹 앱**으로 정하면 CRM 브라우저 화면에서 바로 통화를 처리할 수 있어요.

### 전화하기 전에 고객의 허락을 받아야 하나요?
네. WhatsApp은 비즈니스가 먼저 거는 통화에 **고객의 명시적인 승인**을 요구해요. 고객이 먼저 거는 수신 통화는 미리 권한을 받지 않아도 돼요.

### 통화 권한은 얼마나 유지되나요?
임시 권한은 **7일(168시간)** 동안 유지돼요. 영구 권한은 만료되지 않아요. 고객이 요청에 응답하지 않으면 **7일** 후에 만료돼요.

### 같은 고객에게 권한 요청을 몇 번 보낼 수 있나요?
**24시간에 1회**, **7일 동안 최대 2회**까지 보낼 수 있어요. 이 한도는 비즈니스와 사용자 사이에 연결된 통화가 이루어지면 초기화돼요.

### 내가 있는 나라에서 WhatsApp 통화를 쓸 수 있나요?
WhatsApp 통화는 대부분의 국가에서 쓸 수 있어요. 현재 미국, 캐나다, 튀르키예, 이집트, 베트남, 나이지리아에서는 **지원되지 않아요**.
<!-- 검토 필요: 원문 내용이 서로 다름 (본문에서는 비즈니스가 먼저 거는 통화만 해당 국가에서 지원되지 않는다고 안내) -->

### WhatsApp 수신 통화를 놓치면 어떻게 되나요?
통화를 받지 못했을 때 **Allow People to Request Callback for Missed Calls**를 켜 두었다면 고객이 콜백을 요청할 수 있어요. 부재중 통화도 고객 대화에 기록돼요.

### 여러 팀원이 같은 수신 통화를 받을 수 있나요?
네. **WhatsApp 통화 수신 대상**에서 먼저 울릴 **주 담당 사용자**를 정하고, 대기용 팀원을 더 추가할 수 있어요. 주 담당 사용자가 받지 않으면 다음으로 지정된 사용자에게 통화가 연결돼요.

### 고객이 통화 권한을 철회할 수 있나요?
네. 고객은 WhatsApp 채팅을 열고 비즈니스 프로필 이름을 눌러 **Business Calling Permissions**(비즈니스 통화 권한)로 들어가 통화 접근을 끄면 언제든 권한을 철회할 수 있어요.

### 통화 처리 결과(disposition)가 무엇이고 왜 써야 하나요?
통화 처리 결과는 통화가 끝난 뒤 추가하는 **결과 태그**예요. 예를 들면 *해결됨*, *후속 연락 필요*, *부재중* 같은 거예요. 기록이 정확해지고 후속 연락을 추적하기 쉬워져요.

### 연속으로 4번 받지 않으면 어떻게 되나요?
**2번 받지 않으면** WhatsApp이 사용자에게 다시 생각해 보도록 안내하는 시스템 메시지를 보내요. **4번 받지 않으면** WhatsApp이 통화 권한을 **자동으로 철회**해요.

### 권한이 자동으로 철회되면 어떻게 하나요?
고객이 비즈니스의 발신 통화를 연속 4번 받지 않으면 WhatsApp이 통화 권한을 자동으로 철회해요. 이후에 전화를 걸려면 권한을 다시 요청해야 해요.
