# WhatsApp 플로우로 폼 보내기

WhatsApp 플로우를 쓰면 하이퍼클래스 폼의 지원되는 필드를 WhatsApp 안에서 바로 보낼 수 있어요. 고객은 외부 페이지로 이동하지 않고도 정보를 입력하고 제출할 수 있어요. 기존 폼을 쓰거나 새 폼을 만들 수 있어요. WhatsApp 미리보기를 확인하고 메시지 템플릿을 설정해 플로우를 게시한 뒤, **대화**, 워크플로우, **일괄 작업**으로 보내면 돼요.

---

## WhatsApp 플로우란?

WhatsApp 플로우는 WhatsApp 안에서 바로 진행되는 대화형 기능이에요. 고객이 WhatsApp 메시지의 버튼을 누르면 안내형 폼이 열려요. 고객은 앱을 벗어나지 않고 질문에 답하고 정보를 제출해요.

하이퍼클래스는 폼에서 지원되는 필드만 가져와 WhatsApp용 화면을 만들어요. 웹사이트에 보이는 웹 폼 전체가 그대로 들어가는 것은 아니에요.

WhatsApp 플로우의 폼은 리드 자격 검증, 신규 고객 온보딩, 피드백 수집, 등록 신청 등 정보를 모으는 여러 작업에 쓸 수 있어요. 제출이 끝난 내용은 하이퍼클래스의 해당 연락처와 연결돼요.

---

## WhatsApp 플로우에서 폼을 쓰면 좋은 점

WhatsApp 플로우의 폼을 쓰면 고객이 WhatsApp 대화 안에 머무른 채로 정보를 남길 수 있어요.

- 앱 안에서 폼 작성: 고객은 외부 페이지를 열지 않고 지원되는 폼 질문에 답하고 제출해요.
- 기존 폼 재사용: 이미 있는 하이퍼클래스 폼을 고르거나, 플로우용 새 폼을 만들 수 있어요.
- **실시간 미리보기**: 게시하기 전에 지원되는 필드가 WhatsApp 안에서 어떻게 보일지 확인해요.
- 연락처 연결: 제출이 끝난 내용은 해당 연락처와 연결돼요.
- 다양한 발송 방법: 승인된 템플릿을 **대화**, 워크플로우, **일괄 작업**으로 보낼 수 있어요.

---

## 사전 준비와 제한 사항

폼 기반 WhatsApp 플로우를 만들기 전에 WhatsApp 연결, 권한, 폼 내용이 준비됐는지 확인하세요.

- 해당 서브 계정에 WhatsApp 계정이 연결되어 있는지 확인하세요. 자세한 내용은 [WhatsApp 설정](../11-설정/서브어카운트-설정/whatsapp-settings.md) 문서를 참고하세요.
- 내 사용자 계정이 **WhatsApp**과 **폼** 설정에 접근할 수 있는지 확인하세요.
- 폼을 고르기 전에 어떤 정보를 받을지 미리 정리해 두세요.
- 지원되지 않는 폼 필드는 WhatsApp 플로우에서 빠져요.
- 비즈니스가 먼저 보내는 WhatsApp 메시지라면, 수신자에게 연락해도 된다는 적절한 허락을 받았는지 확인하세요.

{% hint style="info" %}
게시하기 전에 WhatsApp 미리보기를 꼭 확인해서 고객에게 어떤 폼 필드가 보이는지 확인하세요.
{% endhint %}

## 하이퍼클래스 폼을 WhatsApp 플로우로 보내기

아래 순서대로 폼을 고르고, WhatsApp 화면을 확인하고, 연결된 템플릿을 설정한 뒤, 게시한 플로우를 보내 보세요.

### 1단계: WhatsApp 플로우 열기

1. 해당 **서브 계정**에서 **설정 > WhatsApp > 플로우**로 이동하세요.
2. **플로 만들기**를 클릭하세요.
3. 플로우 이름을 알아보기 쉽게 입력하세요. 예를 들어 '신규 고객 문의'나 '리드 자격 검증'처럼 쓰면 돼요.
4. 폼 선택 단계로 넘어가세요.

![플로우 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084110993/original/xGJYRHNLuopx4ZXhtgN0sgRh0ALk-VV7gQ.png?1792825223)

### 2단계: 폼 선택 또는 새로 만들기

WhatsApp 플로우를 설정할 때 **폼 제출**을 선택하세요. 기존 하이퍼클래스 폼을 쓰거나, 플로우 설정 화면에서 새 폼을 만들 수 있어요.

### 기존 폼 사용하기

사용할 하이퍼클래스 폼을 선택하세요. 플로우 빌더가 폼 필드를 확인한 뒤, 지원되는 내용을 WhatsApp 미리보기에 보여 줘요.

### 새 폼 만들기

새 폼이 필요하면 플로우 화면에서 폼 만들기 옵션을 사용하세요. 폼을 만든 뒤 플로우에 연결할 폼으로 선택하고 미리보기 단계로 넘어가세요.

![폼 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083375146/original/0esj886t_Q7gFHbk_bc2N-U49__YoxxRcQ.png?1792050843)

{% hint style="info" %}
실제로 받아야 하는 정보를 기준으로 폼을 구성하세요. 플로우를 게시하기 전에 WhatsApp 미리보기를 꼭 확인하세요.
{% endhint %}

### 3단계: WhatsApp 미리보기 확인

WhatsApp 미리보기에서는 지원되는 폼 내용이 고객에게 어떻게 보이는지 확인할 수 있어요. 게시하기 전에 질문과 입력 항목을 살펴보세요.

지원되지 않는 필드 유형은 플로우를 만들 때 제외돼요. 고객이 업무에 필요한 정보를 모두 입력할 수 있는지 미리보기로 확인하세요.

![WhatsApp 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083375849/original/sDyfzDHB0Gidq95G4vnB8GIC9051Hfg7Tg.png?1792051243)

{% hint style="warning" %}
하이퍼클래스 폼 빌더에 있는 필드라고 해서 WhatsApp 플로우에도 나타나는 것은 아니에요. 게시하기 전에 WhatsApp 미리보기를 확인하세요.
{% endhint %}

### 4단계: WhatsApp 템플릿 설정 후 게시

지원되는 폼 필드와 WhatsApp 미리보기를 확인했다면, 고객이 폼을 여는 데 쓸 WhatsApp 메시지를 설정하세요.

1. 플로우 빌더에서 WhatsApp 메시지 템플릿 설정 단계로 이동하세요.
2. 메시지 내용을 입력하세요. 사용할 수 있는 경우 **머리글**, **본문**, **푸터**를 함께 입력하세요.
3. 고객이 폼을 열기 위해 누를 **Flow button**(플로우 버튼)을 설정하세요.
4. 입력 창이 나타나면 **버튼 텍스트**를 입력하세요.
5. 메시지를 검토하고, 버튼을 누르면 의도한 폼 기반 WhatsApp 플로우가 열리는지 확인하세요.
6. 플로우가 준비되면 **게시**를 선택하세요.

![플로우 버튼이 있는 WhatsApp 템플릿 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084110934/original/TuuLwTITezmYBNLNmpygLwYi6vvYqvR86A.png?1792825127)

{% hint style="warning" %}
WhatsApp 플로우를 게시해도 연락처에게 자동으로 발송되지는 않아요. 연결된 WhatsApp 메시지 템플릿이 Meta 승인 절차를 마쳐야 승인된 템플릿 메시지로 사용할 수 있어요.
{% endhint %}

### 5단계: 템플릿으로 폼 보내기

플로우를 게시하고 연결된 WhatsApp 템플릿이 승인되면 **대화**, 워크플로우, **일괄 작업**으로 폼을 보낼 수 있어요. 고객은 메시지의 플로우 버튼을 눌러 WhatsApp 안에서 폼을 작성하고 제출해요. 템플릿에 대한 자세한 내용은 [WhatsApp 메시지 템플릿(스니펫) 보내기](WhatsApp/whatsapp-send-message-templates-snippets.md) 문서를 참고하세요.

### 대화에서 보내기

승인된 WhatsApp 템플릿을 연락처 한 명에게 보내고 싶을 때 사용하세요.

1. 서브 계정에서 **대화**를 여세요.
2. 메시지를 보낼 연락처의 대화를 여세요.
3. 메시지 채널로 WhatsApp을 선택하세요.
4. 메시지 작성창에서 **WhatsApp 템플릿 선택**을 선택하세요.
5. 게시한 플로우와 연결된 승인된 템플릿을 선택하세요.
6. 템플릿을 검토하세요.
7. **보내기**를 클릭하세요.

![대화에서 WhatsApp 템플릿 보내기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084111374/original/LHEyESdRLSXqPmZjHZtaq4RcilreY6P6Gw.png?1792825888)

### 워크플로우로 보내기

정해 둔 트리거나 조건에 따라 승인된 WhatsApp 템플릿을 자동으로 보내고 싶을 때 사용하세요.

1. **자동화**로 이동하세요.
2. 새 워크플로우를 만들거나 기존 워크플로우를 여세요.
3. WhatsApp 메시지를 보낼 시점을 정하는 트리거를 설정하세요.
4. 알맞은 **WhatsApp** 액션을 추가하세요. 워크플로우 빌더는 영어 화면으로 표시돼요.
5. 메시지 유형으로 **WhatsApp Template**(WhatsApp 템플릿)을 선택하세요.
6. 게시한 플로우와 연결된 승인된 템플릿을 선택하세요.
7. 액션 설정을 검토하세요.
8. 액션을 저장하고, 준비되면 워크플로우를 게시하세요.

![워크플로우에서 WhatsApp 템플릿 액션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084111705/original/K5kl_IDeSWc114qmbfocG0YjizSBZvERaw.png?1792826539)

### 일괄 작업으로 보내기

승인된 WhatsApp 템플릿을 선택한 연락처 여러 명에게 한꺼번에 보내고 싶을 때 사용하세요.

1. **연락처**로 이동하세요.
2. 메시지를 보낼 연락처를 선택하세요.
3. **일괄 액션 > WhatsApp 보내기**를 선택하세요.
4. **WhatsApp 템플릿 선택**을 선택하세요.
5. 게시한 플로우와 연결된 승인된 템플릿을 고르세요.
6. 템플릿과 발송 정보를 검토하세요.
7. 일괄 발송을 확정하세요.

![일괄 작업으로 WhatsApp 템플릿 보내기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084111855/original/3LQQASMEXChQJlDs7lqaQZxyzYyb8uBQ_A.png?1792826927)

{% hint style="info" %}
고객에게 보내기 전에 내부 테스트용 연락처에게 먼저 플로우를 보내세요. 폼을 작성해서 제출한 내용이 예상한 폼과 연락처 아래에 나타나는지 확인하세요.
{% endhint %}

{% hint style="info" %}
WhatsApp 플로우로 예약을 받고 싶다면 [WhatsApp 플로우: 앱 안에서 예약 부킹](whatsapp-flows-in-app-appointment-booking.md) 문서를 참고하세요.
{% endhint %}

## 폼 제출 내용 확인하기

WhatsApp 플로우로 제출된 내용은 하이퍼클래스의 다른 폼 제출 내용과 함께 저장되고, 해당 연락처와 연결돼요.

1. **사이트 > 폼 > 제출**로 이동하세요.
2. 해당 폼을 찾으세요.
3. 제출 내용을 열어 입력된 정보를 확인하세요.

그 제출로는 WhatsApp 플로우에 포함된 필드만 수집돼요.

![폼 제출 내용 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084111955/original/Rr7nTKNuwsHkSHkJr8AEIn9Je7Qf0i8EvA.png?1792827231)

## 원본 폼을 수정하면 어떻게 되나요?

원본 하이퍼클래스 폼을 수정해도 이미 게시한 WhatsApp 플로우는 자동으로 바뀌지 않아요.

원본 폼을 수정했다면, 이후 메시지에 플로우를 쓰기 전에 플로우를 다시 확인해서 고객에게 의도한 질문이 나가는지 살펴보세요.

---

## 문제 해결

플로우, 미리보기, 템플릿, 제출 내용이 예상대로 동작하지 않을 때 아래 내용을 확인하세요.

| 문제 | 확인할 내용 |
| --- | --- |
| 미리보기에서 일부 폼 필드가 보이지 않아요 | WhatsApp 미리보기를 확인하세요. 지원되지 않는 필드는 플로우에서 빠져요. |
| 플로우를 게시할 수 없어요 | 설정을 검토하고, 플로우 빌더에 표시된 유효성 오류를 해결하세요. |
| WhatsApp 템플릿을 보낼 수 없어요 | 템플릿이 Meta 승인 절차를 마쳤는지 확인하세요. |
| 원본 폼의 변경 내용이 반영되지 않아요 | 원본 폼을 바꿔도 이미 게시한 플로우는 자동으로 업데이트되지 않아요. 플로우를 다시 사용하기 전에 설정을 검토하세요. |
| 제출 내용을 찾을 수 없어요 | 고객이 마지막 제출 단계까지 마쳤는지 확인한 뒤, 올바른 서브 계정의 **사이트 > 폼 > 제출**을 확인하세요. |

## 자주 묻는 질문

### 기존 하이퍼클래스 폼을 다시 만들어야 하나요?

아니요. WhatsApp 플로우를 만들 때 기존 하이퍼클래스 폼을 선택하면 돼요. 플로우 설정 화면에서 새 폼을 만들 수도 있어요.

### 폼이 외부 웹사이트에서 열리나요?

아니요. 고객은 별도의 랜딩 페이지로 이동하지 않고 WhatsApp 안에서 바로 지원되는 폼 질문에 답해요.

### 내 폼의 일부 필드가 WhatsApp에서 보이지 않는 이유는 뭔가요?

WhatsApp 플로우에는 연동에서 지원하는 필드만 들어가요. 지원되지 않는 필드는 플로우를 만들 때 제외돼요. 게시하기 전에 WhatsApp 미리보기로 고객에게 보일 내용을 확인하세요.

### WhatsApp 플로우 폼 제출 내용은 어디에 저장되나요?

제출이 끝난 응답은 **사이트 > 폼 > 제출**에서 볼 수 있고, 해당 연락처와 연결돼요.

### 원본 폼을 수정하면 이미 게시한 WhatsApp 플로우도 바뀌나요?

아니요. 원본 하이퍼클래스 폼을 바꿔도 이미 게시한 WhatsApp 플로우는 자동으로 업데이트되지 않아요. 원본 폼을 수정한 뒤에는 플로우를 다시 확인하세요.

### 폼 기반 WhatsApp 플로우는 어떻게 보내나요?

플로우를 게시하고 연결된 WhatsApp 템플릿이 승인되면 **대화**, 워크플로우, **일괄 작업**으로 보낼 수 있어요.

### 플로우를 게시하면 고객에게 자동으로 발송되나요?

아니요. 게시하면 플로우를 사용할 수 있는 상태가 될 뿐이에요. 지원되는 발송 방법 중 하나로 승인된 WhatsApp 템플릿을 직접 보내야 해요.
