# WhatsApp Coexistence 연결 직후 채팅 기록이 동기화되지 않을 때

WhatsApp 번호를 Coexistence(Coex)에 연결했는데 이전 채팅 기록이 아직 보이지 않을 때 확인할 사항을 안내해요.

## 왜 이런 일이 생기나요?

Coexistence(Coex)에 WhatsApp 번호를 막 연결했는데 이전 채팅 기록이 보이지 않는다면, 아직 채팅 기록 동기화가 끝나지 않았을 가능성이 커요.

연결이 끝나면 WhatsApp은 휴대폰 앱에 있는 기존 메시지를 하이퍼클래스로 동기화해요. 이 과정에는 WhatsApp이 계속 연결되어 있어야 해요.

## 채팅 기록을 문제없이 동기화하는 방법

1. 데이터 연결을 켜 두세요.
   - 휴대폰이 Wi-Fi 또는 모바일 데이터에 안정적으로 연결되어 있는지 확인하세요.
   - 동기화하는 동안에는 데이터를 끄지 마세요.
2. WhatsApp 모바일 앱을 열어 두세요.
   - 휴대폰에서 WhatsApp을 열고, 가능하면 화면에 계속 띄워 두세요.
   - 그러면 동기화가 끊기지 않고 진행돼요.
3. 모바일 앱에서 동기화를 확인하세요.
   - WhatsApp 모바일 앱에 채팅 기록 동기화를 시작할지 묻는 확인 팝업이 나타나요.
   - **확인**을 눌러 동기화를 시작하세요.
4. 동기화가 끝날 때까지 기다리세요.
   - 이전 채팅이 얼마나 많은지에 따라 동기화에 몇 분에서 몇 시간까지 걸릴 수 있어요.
   - 동기화가 끝나기 전에는 WhatsApp에서 로그아웃하거나 휴대폰을 끄지 마세요.

```
원활한 동기화를 위한 팁:
- 휴대폰을 충전해 두고, 안정적인 네트워크에 연결해 두세요.
- 동기화하는 동안 WhatsApp 앱을 강제 종료하지 마세요.
- 확인 팝업을 놓쳤다면 WhatsApp 앱을 다시 시작하면 팝업이 다시 나타나요.
```

## 도움이 필요하다면

위 방법을 따라 했는데도 채팅 기록이 동기화되지 않으면 하이퍼클래스 고객지원에 문의하세요. 문의할 때 아래 내용을 함께 알려 주세요.

- WhatsApp 번호
- 연결(온보딩)을 시작한 시간
- 오류 화면이나 누락된 채팅의 스크린샷

확인한 뒤 동기화를 마칠 수 있도록 도와 드릴게요.
