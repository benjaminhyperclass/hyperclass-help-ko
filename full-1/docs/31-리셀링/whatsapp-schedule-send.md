# WhatsApp 메시지 예약 발송

WhatsApp 템플릿 메시지와 자유 형식 메시지를 원하는 시간에 맞춰 예약해서 보낼 수 있어요. 이 문서에서는 두 가지 메시지를 예약하는 방법을 안내해요.

## WhatsApp 템플릿 메시지 예약하기

1. **대화**(Conversations)로 이동해 연락처를 선택하세요.
2. **WhatsApp**을 선택한 다음, 보낼 템플릿을 선택하세요.

   ![WhatsApp 템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032618474/original/9u2fSMMjmSe11ksqtgSbLBGhMZDEzGCg2A.png?1725984136)

3. **보내기** 옆에 있는 버튼을 클릭하세요.

   ![보내기 옆 예약 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032618529/original/jnFzzlVqlbvY-hNx4hCEVOrD-kftsz8ZdQ.png?1725984205)

4. **날짜 및 시간**에서 WhatsApp 템플릿을 보낼 날짜와 시간을 선택하세요.
5. **Send Schedule**(예약 보내기)을 클릭하세요. <!-- 검토 필요: 원문 내용이 서로 다름 (버튼 이름이 'Send Schedule'과 'Schedule Send'로 다르게 표기됨) -->

   ![날짜와 시간을 선택하고 예약하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032618621/original/p_9RgVNbqwdWY7PJb7hkwK0tRCg3PKH5BA.png?1725984262)

{% hint style="info" %}
날짜와 시간은 현재보다 이후로 선택해야 해요.
{% endhint %}

## 자유 형식 WhatsApp 메시지 예약하기

{% hint style="info" %}
자유 형식 WhatsApp 메시지를 보내려면 고객과 열려 있는 고객 서비스 창(Customer Service Window)이 있어야 해요.
{% endhint %}

1. **대화**로 이동해 연락처를 선택하세요.
2. **WhatsApp**을 선택한 다음, 자유 형식 메시지를 입력하세요.

   ![자유 형식 메시지 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032619943/original/-geYGRhmreNjBWPrlWV8OZfU6Njp6mCJ3Q.png?1725985371)

3. **보내기** 옆에 있는 버튼을 클릭하세요.
4. **날짜 및 시간**을 선택하세요.

   {% hint style="info" %}
   고객에게서 마지막으로 받은 메시지를 기준으로 최대 24시간 안까지 예약할 수 있어요.
   {% endhint %}

   ![자유 형식 메시지 예약 날짜와 시간 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043818134/original/_ktR7BKMo89aK8cCYpv8aKqkjEHD5aPW7A.png?1742804841)

5. **Schedule Send**(예약 보내기)를 클릭하세요.

   ![예약 보내기 버튼 클릭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032620046/original/vpUsKzMY_UAxUzM6h2jHSyAfflstLp_TRA.png?1725985514)

## 자주 묻는 질문

### WhatsApp 템플릿 메시지를 나중에 보내도록 예약할 수 있나요?
네, 할 수 있어요. **대화** 탭에서 템플릿을 선택하고 **보내기** 옆의 캘린더 아이콘을 클릭한 다음, 원하는 미래의 날짜와 시간을 선택하면 돼요.

### 자유 형식 WhatsApp 메시지도 예약할 수 있나요?
네, 단 열려 있는 고객 서비스 창 안에서만 가능해요. 고객이 마지막으로 보낸 메시지를 기준으로 24시간 안까지 예약할 수 있어요.

### 고객 서비스 창(Customer Service Window)이 뭔가요?
고객이 메시지를 보낸 시점부터 시작되는 24시간을 말해요. 이 시간 동안에는 사전 승인된 템플릿 없이도 자유 형식으로 답장할 수 있어요.

### 24시간이 지난 뒤로 자유 형식 메시지를 예약하려고 하면 어떻게 되나요?
창이 열려 있는 시간을 벗어나면 예약할 수 없어요. 이 경우에는 WhatsApp 템플릿을 대신 사용해야 해요.

### 메시지가 제대로 예약됐는지 어떻게 확인하나요?
발송 날짜와 시간을 선택한 뒤 **Schedule Send**를 클릭하세요. 채팅 화면에 예약된 메시지가 시간 정보와 함께 표시돼요.

### 예약한 메시지를 수정하거나 취소할 수 있나요?
현재는 예약한 메시지를 수정할 수 없어요. 내용을 바꾸려면 예약된 메시지를 삭제하고 새로 예약하세요.
