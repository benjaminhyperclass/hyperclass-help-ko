# AI 스튜디오 미리보기에서 바로 고치기 (Visual Edits)

**AI 스튜디오**에서 만든 프로젝트를 라이브 미리보기 화면에서 바로 다듬는 방법을 안내해요. 시각 편집 모드에 들어가는 방법과 편집할 요소를 고르는 방법을 알 수 있어요. 텍스트, 이미지, 아이콘, 색상, 간격, 레이아웃을 바꾸는 방법도 함께 다뤄요.

## AI 스튜디오의 시각 편집이란

시각 편집(**Visual Edits**)을 쓰면 AI가 프로젝트를 만든 뒤에 라이브 미리보기에서 바로 수정할 수 있어요. 텍스트를 직접 눌러 고치거나, 페이지 요소를 골라 스타일을 바꾸거나, 특정 부분만 프롬프트로 요청할 수 있어요.

AI가 만든 사이트가 거의 완성됐지만 문구, 간격, 색상, 버튼, 이미지, 아이콘, 레이아웃을 조금 더 다듬고 싶을 때 쓰면 좋아요. 변경 내용은 먼저 라이브 미리보기에만 보이고, 저장하기 전에는 프로젝트에 적용되지 않아요.

{% hint style="info" %}
AI 모델은 프롬프트를 직접 보낼 때만 실행돼요. 편집 컨트롤로 직접 바꾸는 변경은 AI 생성이 필요 없고 토큰도 쓰지 않아요.
{% endhint %}

## 시각 편집의 장점

- 직접 페이지 편집: 미리보기에서 요소를 클릭해 바로 수정해요. **Code Editor**(코드 편집기)를 열거나 AI를 쓰지 않아도 돼요.
- 빠른 문구 수정: 텍스트를 더블클릭하고 페이지에서 바로 입력해 내용을 빠르게 바꿔요.
- 원하는 부분만 프롬프트로 수정: 요소를 하나 또는 여러 개 선택하고 바꾸고 싶은 내용을 설명해요.
- 직접 편집은 토큰 미사용: 시각 컨트롤로 직접 바꾸는 변경에는 AI 토큰이 들지 않아요.
- 저장 전 미리보기: 프로젝트에 적용하기 전에 라이브 미리보기에서 변경 내용을 확인해요.

## 편집할 수 있는 요소

시각 편집은 사이트를 다듬을 때 가장 많이 쓰는 요소를 지원해요. 선택한 요소에 따라 컨트롤이 달라지므로, 편집 패널에는 클릭한 요소와 관련된 옵션만 표시돼요.

편집할 수 있는 요소는 다음과 같아요.

- 제목과 텍스트: 문구, 타이포그래피, 정렬, 텍스트 색상, 스타일을 바꿔요.
- 버튼: 레이블, 버튼 스타일, 버튼 유형, 간격, 색상을 바꿔요.
- 이미지: 이미지 소스, 이미지 맞춤 방식, 대체 텍스트를 바꿔요.
- 아이콘: 아이콘을 교체하고 크기나 스타일을 조정해요.
- 컨테이너와 섹션: 간격, 테두리, 그림자, 배경, 레이아웃 스타일을 조정해요.

## 시각 편집 모드로 들어가기

시각 편집 모드는 **AI 스튜디오** 빌더에서 켜요. 모드를 켜면 미리보기가 상호작용 가능한 상태로 바뀌어서 텍스트, 이미지, 버튼, 아이콘, 컨테이너 같은 지원 요소를 선택할 수 있어요.

1. **AI 스튜디오**를 열고 수정할 프로젝트를 클릭하세요.

   ![AI 스튜디오에서 프로젝트를 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071166037/original/PrLWPJTeZi0l-r8Srt8bubtSkqphKWT5pA.png?1778601593)
2. 빌더 왼쪽 아래 프롬프트 영역에서 **Visual Edits**(시각 편집)를 클릭하세요.

   ![프롬프트 영역의 Visual Edits 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071076182/original/BG6YNVnT9sGnUxel8EPr4w35md37TEFgeA.png?1778533737)
3. 미리보기에서 요소를 클릭하면 편집을 시작할 수 있어요.

   ![미리보기에서 요소를 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071076231/original/dx7yrGfelbjDzbEWDYl4uMy2zBT40_LXhQ.png?1778533864)

## 시각 편집으로 수정하기

시각 편집 모드에 들어가면 여러 방법으로 페이지를 수정할 수 있어요. 요소를 선택해 해당 요소에 맞는 컨트롤을 열 수 있어요. 페이지에서 텍스트를 바로 고치거나 아이콘을 바꿀 수도 있어요. 색상과 간격, 이미지 레이아웃, 아이콘 크기도 조정할 수 있어요. 요소를 여러 개 선택해 한꺼번에 프롬프트로 요청하는 것도 가능해요.

### 요소를 클릭해 시각 컨트롤 열기

미리보기에서 요소를 클릭하면 **Visual Edits** 패널이 열려요. 텍스트, 버튼, 이미지, 아이콘, 컨테이너, 레이아웃 요소 등 선택한 요소에 맞게 컨트롤이 자동으로 바뀌어요. 프로젝트 코드를 뒤지지 않고도 원하는 부분만 바로 고칠 수 있어요.

선택한 요소에 해당하면 **Visual Edits** 패널에서 색상과 간격 컨트롤도 쓸 수 있어요. 프로젝트의 테마 색상이 전체 Tailwind 팔레트와 함께 표시돼요. 마진과 패딩 컨트롤도 나타나서 간격을 조절할 수 있어요.

![요소를 클릭해 시각 컨트롤을 여는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071077162/original/5YxK8hdINcvyHnvpkzogWdc1AcmaeR-wKQ.gif?1778535897)

### 텍스트 바로 수정하기

문구를 빠르게 바꿀 때는 페이지에서 바로 수정하는 방법이 가장 편해요. 텍스트 요소를 더블클릭한 다음 페이지에서 바로 입력하세요.

![텍스트를 더블클릭해 바로 수정하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071077039/original/Wol11BgpA9NTtbgW0xnCGm8cQf9MLteydA.gif?1778535584)

### 아이콘 바꾸기

아이콘 컨트롤을 쓰면 코드를 고치지 않고도 Lucide 아이콘을 교체하거나 크기를 바꿀 수 있어요. Lucide 아이콘을 선택하면 1,600개 이상의 아이콘이 있는 검색 가능한 라이브러리가 열려요. 여기서 바꿀 아이콘을 고르면 새로고침 없이 바로 교체돼요. 선택한 Lucide 아이콘의 크기도 조절할 수 있어요.

![Lucide 아이콘을 검색해 교체하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071077296/original/pOJ4Ik5h7qGMRlSZo7WNXBZ0qZCmulwGvw.gif?1778536394)

### 이미지 레이아웃 조정하기

**이미지 컨트롤**에서는 사용할 이미지와, 그 이미지가 지정된 영역 안에 보이는 방식을 함께 바꿀 수 있어요. 이미지를 선택하면 이미지 URL을 바꿔 이미지를 교체하고 **대체 텍스트**를 수정할 수 있어요. **레이아웃** 드롭다운에서는 원하는 모양을 고를 수 있어요.

![이미지 URL, 대체 텍스트, 레이아웃을 바꾸는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071077375/original/TEBxIMgIgBLRUqbMS9GvAdlSBLboRrrpIw.gif?1778536779)

### 선택한 요소에 프롬프트 사용하기

프롬프트 편집은 요소를 하나 이상 선택하고 바꾸고 싶은 내용을 일상적인 말로 설명하는 방식이에요. 특정 요소만 바꾸거나, 여러 요소를 한꺼번에 맞춰 바꾸고 싶을 때 쓰세요.

요소 하나에는 이런 변경에 쓰면 좋아요.

- 선택한 섹션을 더 현대적으로 바꾸기
- 컨테이너 안쪽 간격 개선하기
- 버튼 스타일을 부드럽게 만들기
- 한 구성 요소를 페이지의 나머지 부분과 더 잘 어울리게 맞추기

요소 여러 개에는 반복되는 구성 요소의 스타일을 통일할 때 유용해요.

- 버튼 스타일 맞추기
- 컨테이너 사이 간격 맞추기
- 반복되는 카드나 열 업데이트하기
- 선택한 요소 그룹에 같은 색상 적용하기

![여러 요소를 선택해 프롬프트로 수정하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071077149/original/-Y0W4Z5lnYZ2_uF_rbJIRgkRLj4QlDO7JQ.gif?1778535863)

## 시각 편집 저장하기 또는 삭제하기

시각 편집은 미리보기를 먼저 보여 주는 방식이라, 프로젝트에 적용하기 전에 변경 내용을 확인할 수 있어요. 실수로 업데이트되는 일을 막아 주고, 다양한 스타일이나 내용을 부담 없이 시험해 볼 수 있어요.

**저장**을 클릭하면 편집 내용이 프로젝트에 적용돼요. 저장하지 않고 시각 편집 모드를 나가면 변경 내용이 삭제돼요.

엉뚱한 요소가 바뀌었거나 원하지 않는 스타일이 생겼거나 의도한 디자인과 다르면 **삭제**를 클릭하세요. 저장하지 않은 변경 내용이 지워지고 이전 버전으로 돌아가요.

![저장과 삭제 버튼이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071076894/original/ogrDC2iFFwJHF-uRZYLB9itN4jruoWoHXg.png?1778535219)

## 자주 묻는 질문

### 시각 편집을 쓰려면 먼저 설정을 켜야 하나요?
아니요. **AI 스튜디오** 프로젝트를 열고 빌더 왼쪽 아래 프롬프트 영역에서 **Visual Edits**를 클릭하면 바로 편집을 시작할 수 있어요.

### 시각 편집은 AI 토큰을 쓰나요?
직접 하는 시각 편집은 AI 토큰을 쓰지 않아요. AI가 생성하는 프롬프트가 아니라 편집 컨트롤로 변경하기 때문이에요.

### 선택한 특정 요소에만 프롬프트를 쓸 수 있나요?
네. 바꾸려는 요소를 선택하고 **Visual Edits** 프롬프트 영역에 원하는 지시를 입력하세요.

### 요소를 한 번에 여러 개 편집할 수 있나요?
네. 여러 요소를 선택해서 편집하면 간격을 일관되게 맞추거나, 스타일을 공유하거나, 반복되는 레이아웃을 다듬는 등 한꺼번에 조정할 수 있어요.
