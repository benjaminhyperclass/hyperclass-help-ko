# 대화 AI 봇 설정하기

대화 AI를 쓰면 하이퍼클래스에서 지원하는 채널의 고객 대화를 자동화할 수 있어요. 이 문서에서는 간단한 설정 흐름에 따라 대화 AI 봇을 만들고, 설정하고, 테스트하고, 실제로 켜는 방법을 안내해요. 대화 AI 봇은 리드 정보 수집, 자주 나오는 질문 답변, 예약 부킹 지원, 대화 분배에 활용할 수 있어요.

## 대화 AI란?

대화 AI는 하이퍼클래스에서 지원하는 채널에서 연락처와 나누는 대화를 자동화해 주는 AI 기반 소통 도구예요. 봇을 어떻게 설정했는지에 따라 들어오는 메시지에 답하고, 정보를 수집하고, 질문에 답하고, 예약 부킹을 돕고, 워크플로우와 함께 동작해요.

대화 AI 봇은 일반 Q&A, 리드 수집, 예약 부킹, 여러 단계로 이어지는 복잡한 대화 흐름 등 비즈니스 목적에 맞게 만들 수 있어요. 설정을 제대로 해 두면 봇이 알맞은 채널에서 응답하고, 비즈니스 목표에 맞게 동작하며, 고객에게 일관된 경험을 줄 수 있어요.

## 대화 AI의 주요 장점

- 멀티채널 소통: SMS, 이메일, Facebook, Instagram, WhatsApp, 채팅 위젯/SMS 채팅, 실시간 채팅 등 지원하는 채널에 봇을 연결할 수 있어요.
- 리드 수집: 이름, 이메일, 전화번호, 주소, 맞춤 질문 답변 같은 핵심 연락처 정보를 모을 수 있어요.
- 예약 부킹: 설정에 따라 봇이 연락처의 예약 부킹, 일정 변경, 취소를 도와줘요.
- 빠른 응답 처리: 대기 시간 설정과 응답 모드로 봇이 언제, 어떻게 답할지 조절할 수 있어요.
- 주 봇 관리: 주 봇 하나를 지정해서 선택한 채널로 들어오는 일반 메시지를 맡길 수 있어요.
- 켜기 전 테스트: 봇을 **제안형**이나 **오토 파일럿** 모드로 켜기 전에 설정 패널에서 먼저 테스트할 수 있어요.
- 세밀한 맞춤 설정: **봇 학습**, **브랜드 보이스**, **고급 설정**, 응답 설정, 워크플로우를 활용해 봇의 동작을 다듬을 수 있어요.

## 대화 AI 봇 설정 방식

대화 AI에는 사용 목적과 맞춤 설정 수준에 따라 고를 수 있는 설정 방식이 여러 가지 있어요. 단순한 봇은 가이드 폼으로 만들 수 있고, 더 복잡한 용도에는 프롬프트 기반 설정이나 시각적 빌더를 쓸 수 있어요.

하이퍼클래스는 현재 세 가지 설정 방식을 제공해요.

### 가이드 폼 설정

**가이드 폼 설정**은 리드 수집, 예약 부킹, 일반 Q&A처럼 단순한 용도에 알맞아요. 자세한 프롬프트를 처음부터 쓰지 않고, 정해진 순서에 따라 설정하고 싶을 때 좋아요.

**가이드 폼 설정**은 이럴 때 쓰세요.

- 간단한 리드 수집
- 예약 부킹
- 일반 Q&A
- 기본적인 목표 설정과 정보 수집
- 처음 만드는 사용자도 쉽게 따라 할 수 있는 봇 설정

가이드 폼 봇을 만드는 방법은 다음과 같아요.

{% hint style="info" %}
더 자세한 설명은 '대화 AI 가이드 폼 기반 설정(Guided Form Based Setup for Conversation AI)' 문서를 참고하세요.
{% endhint %}

1. **AI 에이전트 > 대화 AI > + Create Bot**(봇 만들기)으로 이동해요.
2. **가이드 폼 설정**을 선택해요.
3. **새 봇 만들기**를 클릭해요.
4. 봇 유형을 선택해요.
   - **일반 Q&A**
   - **예약 부킹**
5. **브랜드 보이스**를 선택하거나 새로 만들어요.
6. **봇 설정**을 구성해요.
7. **봇 목표**를 구성해요.
8. **저장**을 클릭해 봇을 저장해요.
9. 봇을 **끔** 상태로 둘지, **제안형** 모드로 쓸지, **오토 파일럿**으로 쓸지 선택해요.
10. 또는 **고급 설정으로 이동**을 클릭해 봇 설정을 이어서 진행해요.

### 프롬프트 기반 봇

**프롬프트 기반 봇**은 자세한 프롬프트를 직접 쓸 수 있고, 봇의 성격·목표·액션·동작을 더 세밀하게 제어하고 싶은 사용자에게 알맞아요.

{% hint style="warning" %}
봇을 만들 때 **Bot Template**(봇 템플릿)을 선택하면 대화 AI 봇의 **Prompts**(프롬프트) 영역에만 영향을 줘요.

선택한 템플릿에서 채워진 내용은 언제든 덮어쓸 수 있어요. 템플릿을 선택하면 하이퍼클래스가 기본 봇 프롬프트를 만들 수 있도록 해당 영역을 채워 줘요.
{% endhint %}

**프롬프트 기반 봇**은 이럴 때 쓰세요.

- 더 개인화된 봇 동작이 필요할 때
- 직접 작성한 지침과 프롬프트를 쓰고 싶을 때
- LLM 모델을 선택하고 싶을 때
- 봇의 성격과 목표를 직접 정하고 싶을 때
- 예약 부킹, 워크플로우 트리거, 상담원 연결, 봇 중지, 봇 전환, 자동 후속 조치, 대화 요약 같은 액션이 필요할 때

프롬프트 기반 봇을 만드는 방법은 다음과 같아요.

{% hint style="info" %}
프롬프트의 품질은 봇의 성능에 바로 영향을 줘요. 프롬프트를 더 잘 쓰는 방법은 'AI Prompting 101'과 '프롬프트로 AI 응답 맞춤 설정하기(Customize your AI responses using Prompts)' 문서를 참고하세요.
{% endhint %}

1. **AI 에이전트 > 대화 AI > + Create Bot**(봇 만들기)으로 이동해요.
2. **프롬프트 기반 봇**을 선택해요.
3. 다음 중 하나를 선택해요.
   - **일반 Q&A**
   - **예약 부킹**
   - **Marketplace Template**(마켓플레이스 템플릿)
   - **처음부터 시작**
4. 봇 편집 화면으로 이동해요.
5. **봇 설정**을 구성해요.
6. **봇 학습**을 구성해요.
7. 프롬프트, 모델 설정, 액션을 사용해 **봇 목표**를 구성해요.

![프롬프트 기반 봇을 만드는 화면 녹화](https://jumpshare.com/share/oqJ6o7bnzYQSqoHRlYze+/GIF+Recording+2026-06-03+at+20.12.45.gif)

### 플로우 기반 빌더

**플로우 기반 빌더**는 시각적인 로직, 분기, 여러 단계의 대화 경로가 필요한 고급 사용자에게 알맞아요. 복잡한 리드 선별, 육성, 예약 흐름에 잘 맞아요.

{% hint style="info" %}
자세한 설정 방법은 '대화 AI 플로 빌더(Conversation AI Flow Builder)' 문서를 참고하세요.
{% endhint %}

**플로우 기반 빌더**는 이럴 때 쓰세요.

- 시각적인 플로우 방식으로 설정하고 싶을 때
- 고급 리드 선별이 필요할 때
- 여러 단계의 목표가 필요할 때
- 복잡한 로직과 분기가 필요할 때
- 고급 예약 부킹 흐름이 필요할 때
- 연락처가 대화 안에서 이동하는 경로를 더 세밀하게 제어하고 싶을 때

플로우 기반 빌더 봇을 만드는 방법은 다음과 같아요.

1. **AI 에이전트 > 대화 AI > + Create Bot**(봇 만들기)으로 이동해요.
2. **플로우 기반 빌더**를 선택해요.
3. **새 봇 만들기**를 클릭해요.
4. 봇 편집 화면으로 이동해요.
5. **봇 설정**을 구성해요.
6. **봇 학습**을 구성해요.
7. **봇 목표**를 열어요.
8. **플로우 빌더 실행**을 클릭해 시각적인 대화 플로우를 만들어요.
9. 봇 전체에 적용되는 동작을 구성해요.
   - 톤
   - 성격과 스타일
   - 대화 의도
   - 추가 비즈니스 정보
   - 비즈니스 맥락
10. 사용할 액션을 구성해요.
    - 봇 중지
    - 상담원 연결
    - 자동 후속 조치
11. 필요하면 예약 관련 옵션을 구성해요.
12. 필요하면 대화 요약을 켜요.

## 자주 묻는 질문

### 새 봇을 만들어야 하나요, 기존 봇을 편집해도 되나요?
둘 다 가능해요. 기존 봇을 편집하려면 **AI 에이전트 > 대화 AI > 에이전트 목록**으로 이동한 다음, 봇 이름을 클릭하거나 점 세 개 메뉴에서 **편집**을 선택하세요.

### 어떤 설정 방식을 골라야 하나요?
리드 수집, 예약 부킹, 일반 Q&A처럼 단순한 용도라면 **가이드 폼 설정**을 쓰세요. 자세한 프롬프트를 직접 쓸 수 있다면 **프롬프트 기반 봇**을 쓰세요. 고급 로직, 분기, 여러 단계의 대화 경로가 필요하면 **플로우 기반 빌더**를 쓰세요.

### 봇을 저장하면 바로 응답하나요?
꼭 그렇지는 않아요. 새 봇은 기본적으로 **끔** 상태일 수 있어요. 봇 상태를 확인하고, 준비되면 **제안형** 또는 **오토 파일럿**으로 바꾸세요.

### 제안형과 오토 파일럿은 뭐가 다른가요?
**제안 모드**에서는 봇이 답장 초안을 만들고, 팀이 검토한 뒤 직접 보내요. **오토 파일럿**은 봇 설정에 따라 답장을 자동으로 보내요.

### 오토 파일럿을 쓰기 전에 봇을 테스트해야 하나요?
네. **오토 파일럿**을 켜기 전에 리드 수집, 자주 묻는 질문, 예약 부킹, 봇이 모르는 질문, 워크플로우와 관련된 동작을 테스트해 보세요.

### 봇이 연락처 정보를 수집할 수 있나요?
네. 설정에 따라 이름, 이메일, 전화번호, 도로명 주소, 도시, 맞춤 질문 답변 같은 정보를 수집할 수 있어요.

### 대화 AI가 예약을 잡아 줄 수 있나요?
네. 예약 부킹을 켜 두면, 설정에서 사용할 수 있는 캘린더 구성에 따라 봇이 연락처의 예약을 도와줘요.

### 봇이 답을 모르면 어떻게 되나요?
봇이 질문에 답하지 못할 때 선택한 사용자에게 알림이 가도록 이메일 알림을 설정할 수 있어요.

### 봇의 말투를 바꿀 수 있나요?
네. **브랜드 보이스**를 선택하거나 새로 만들고, 지침을 추가하고, 봇 목표를 설정하고, 응답 설정을 조정해서 비즈니스의 톤에 맞출 수 있어요.
