# 지식 베이스에 문서와 리치 텍스트 추가하기

이미 가지고 있는 파일이나 직접 쓴 글을 지식 베이스에 넣어 하이퍼클래스 AI 도구가 검색해서 답변에 쓰게 할 수 있어요. DOC, DOCX, PDF 파일을 올리거나 리치 텍스트 편집기에서 바로 내용을 쓰면 돼요. 하이퍼클래스가 텍스트를 추출하고 제목을 인식해 검색하기 좋은 섹션으로 나눈 뒤 색인까지 만들어 줘요. 그래서 연결된 AI가 질문에 맞는 답을 찾을 수 있어요.

## 문서 지원이란?

지식 베이스를 채우는 방법에는 파일 업로드와 리치 텍스트 입력, 두 가지가 있어요. 파일 업로드는 기존 Word 문서나 PDF를 그대로 다시 쓸 때 편해요. 리치 텍스트는 하이퍼클래스 안에서 지식 베이스 내용을 직접 쓰거나 고칠 때 써요.

올린 문서에서는 텍스트를 추출하고 제목을 인식해 내용을 검색 가능한 섹션으로 정리해요. 덕분에 AI 도구가 고객이나 내부 구성원의 질문에 답할 때 관련 내용을 잘 찾아내요.

## 문서 지원의 장점

파일을 올릴지 편집기에서 직접 쓸지 고르는 데 도움이 되는 장점이에요. 속도, 정확도, 관리 편의성 면에서 팀이 안심하고 내용을 업데이트할 수 있어요.

- 다양한 형식: 업계에서 많이 쓰는 파일 형식(DOC, DOCX, PDF)을 지원해서 이미 관리 중인 콘텐츠를 그대로 쓸 수 있어요.
- 시간 절약: 섹션을 일일이 복사해 붙여 넣지 않고 문서 전체를 한 번에 넣을 수 있어요.
- 바로 편집: 리치 텍스트 편집기에서 하이퍼클래스를 벗어나지 않고 내용을 빠르게 고치거나 새로 만들 수 있어요.
- 답변 품질 향상: 제목과 섹션에 맞춰 내용이 검색하기 좋은 조각으로 자동 구성돼요.
- 기존 소스와 함께 사용: 문서와 리치 텍스트를 URL, 자주 묻는 질문과 함께 쓰면 학습 데이터를 더 탄탄하게 만들 수 있어요.

## 지원 파일 형식과 처리 방식

어떤 내용이 추출되고 어떻게 처리되는지 알아 두면 문서를 깔끔하게 준비할 수 있어요.

{% hint style="info" %}
올리기 전에 민감한 내용은 지우고, 제목이 문서 구조를 정확히 나타내는지 확인하세요. 제목이 분명할수록 내용이 더 잘 나뉘고 답변도 좋아져요.
{% endhint %}

- 지원 형식: DOC, DOCX, PDF
- 텍스트만 처리: 텍스트만 가져와요. 문서에 들어 있는 이미지는 건너뛰어요. 지식 베이스를 가볍게 유지하고 검색할 수 있는 내용에 집중하기 위해서예요.
- 제목 인식: H1~H4 같은 제목 계층을 인식해서 내용을 나누고 검색하는 정확도를 높여요.
- 빠른 색인: 새 내용은 바로 또는 약 1분 안에 사용할 수 있어요. 파일 크기와 색인 상황에 따라 달라요.

## 자동 분석과 구조화

긴 문서는 섹션과 제목에 맞춰 다루기 쉬운 조각으로 바뀌어요. 덕분에 에이전트가 답변할 때 정확하게 찾고 출처를 인용할 수 있어요.

- 텍스트를 추출하고 제목을 인식해 논리적인 계층을 만들어요.
- 큰 파일은 검색이 빠르고 정확하도록 최적화된 조각으로 나눠요.
- 처리가 끝나면 내용을 색인해서 봇이 최신 정보를 쓸 수 있게 해요.
- 문서 전체의 맥락을 유지해서 검색할 때도 관련 섹션이 이어져 있어요.

## 지식 베이스에 문서 올리고 사용하기

설정을 제대로 하면 문서가 깔끔하게 처리되고 AI 에이전트가 빠르게 검색할 수 있어요.

1. 서브 계정에서 **AI 에이전트**로 이동하세요.
2. **지식 베이스** 탭을 클릭하세요.

   ![지식 베이스 탭 화면](https://jumpshare.com/share/s08lZnvGFCuaWND1fh5S+/Screen+Shot+2025-10-13+at+7.34.33+PM.png)
3. 기존 지식 베이스를 쓰려면 **편집**을 클릭하세요.
4. 새로 만들려면 **만들기** > **신규**를 클릭하고 이름과 설명을 입력하세요.

   ![새 지식 베이스를 만드는 모습](https://jumpshare.com/share/rl6Si4GgSsXRSp3mIfcB+/GIF+Recording+2025-10-13+at+7.36.42+PM.gif)
5. **소스 추가** > **파일 업로드**를 클릭하세요.

   ![소스 추가에서 파일 업로드를 선택하는 화면](https://jumpshare.com/share/xqx6xqMDPjU6dndjlp9A+/Screen+Shot+2025-10-13+at+7.39.50+PM.png)
6. DOC, DOCX, PDF 파일을 끌어다 놓거나 찾아서 선택하세요.
7. **파일 업로드**를 클릭하세요.

   ![파일을 선택하고 업로드하는 화면](https://jumpshare.com/share/LZvgpjZTWaNHkVa0ax1N+/Screen+Shot+2025-10-13+at+7.41.20+PM.png)
8. 분석이 끝나면 상태가 **처리됨**으로 바뀌어요.
9. 화살표 아이콘을 클릭하면 올린 파일을 새 탭에서 열 수 있고, 휴지통 아이콘을 클릭하면 파일을 삭제할 수 있어요.

   ![올린 파일을 열거나 삭제하는 모습](https://jumpshare.com/share/O8im9ddFWHXC5kZnm2I6+/GIF+Recording+2025-10-13+at+7.50.37+PM.gif)
10. 편집기에서 내용을 직접 쓰거나 고치려면 **Rich-Text**(리치 텍스트)를 추가하세요.
11. **저장**을 클릭하면 리치 텍스트가 지식 베이스에 추가돼요.

    ![리치 텍스트를 작성하고 저장하는 모습](https://jumpshare.com/share/zdeoHcHdw2HmvP32EUvJ+/GIF+Recording+2025-10-13+at+7.53.59+PM.gif)

## 문제 해결

문서나 리치 텍스트 문제는 대부분 지원하지 않는 파일 형식, 불분명한 서식, 처리 미완료, 이미지로만 된 내용, 중복 소스 때문에 생겨요. 소스 상태를 확인하고 검색이 제대로 되는지 테스트해 보면 원인을 찾기 쉬워요.

### 파일 업로드가 실패해요

- 파일 형식이 DOC, DOCX, PDF인지 확인하세요.
- 파일을 다시 올려 보세요.
- 파일이 손상됐거나 비밀번호로 보호된 건 아닌지 확인하세요.
- 문서를 지원하는 형식으로 내보낸 뒤 다시 올려 보세요.

### 올린 파일이 계속 처리 중이에요

- 처리와 색인이 끝날 때까지 기다리세요.
- **지식 베이스** 소스 탭을 새로고침하세요.
- 처리가 끝나지 않으면 더 작거나 더 깔끔하게 정리한 파일로 시도해 보세요.
- 필요하면 문서를 다시 올리세요.

### 문서 내용이 빠져 있어요

- 문서에 선택할 수 있는 텍스트가 들어 있는지 확인하세요.
- PDF가 스캔본이거나 이미지로만 되어 있지는 않은지 확인하세요.
- 문서의 제목과 구조를 점검하세요.
- 검색할 수 있는 텍스트가 들어 있는 깔끔한 버전을 다시 올리세요.

### 문서 안의 이미지를 쓸 수 없어요

- 정상적인 동작이에요. 문서에 들어 있는 이미지는 처리할 때 건너뛰어요.
- 중요한 이미지 정보는 문서에 글로 적거나 리치 텍스트로 추가하세요.

### 리치 텍스트를 고쳐도 올린 파일은 바뀌지 않아요

- 정상적인 동작이에요. 파일 업로드와 리치 텍스트는 따로 저장돼요.
- 리치 텍스트는 직접 수정하세요. 원본 파일이 바뀌었다면 수정한 문서를 새로 올리세요.

### AI가 엉뚱한 소스를 가져와요

- 중복되거나 서로 충돌하는 내용이 있는지 확인하세요.
- 오래된 소스는 삭제하세요.
- 제목을 더 분명하게 쓰고 답을 바로 적어 주세요.
- **Retrieval Tester**(검색 테스터)로 어떤 소스가 검색되는지 확인하세요.

### AI가 문서 내용을 찾지 못해요

- 소스 상태가 **처리됨**인지 확인하세요.
- 사용자가 묻는 용어가 문서에 들어 있는지 확인하세요.
- 고객이 쓰는 표현이나 비슷한 말을 추가하세요.
- 크고 불분명한 문서는 주제별로 작은 파일로 나누세요.
- 내용을 고친 뒤 다시 테스트하세요.

### 올린 문서에 오래된 정보가 있어요

- 오래된 파일 소스를 삭제하세요.
- 수정한 버전을 올리세요.
- 중요한 질문으로 다시 테스트해서 새 소스가 검색되는지 확인하세요.

## 자주 묻는 질문

### 어떤 문서 형식을 지원하나요?
DOC, DOCX, PDF 파일을 지원해요.

### Word 문서나 PDF 안의 이미지도 가져오나요?
아니요. 텍스트만 가져와요. 문서에 들어 있는 이미지는 건너뛰어서 지식 베이스가 검색할 수 있는 내용에 집중하도록 해요.

### PDF가 스캔본이거나 이미지로만 되어 있으면 어떻게 하나요?
올리기 전에 PDF를 선택할 수 있는 텍스트로 변환하세요. 아니면 중요한 정보를 리치 텍스트로 추가하세요.

### 새로 올린 파일은 얼마나 빨리 AI 도구에서 쓸 수 있나요?
보통 바로 쓸 수 있거나 약 1분 안에 쓸 수 있어요. 파일 크기와 색인 상황에 따라 달라요.

### Google Docs 문서를 바로 올릴 수 있나요?
Google Docs 문서를 DOCX나 PDF 파일로 내보낸 다음 그 파일을 올리세요.

### 올린 문서를 하이퍼클래스 안에서 편집할 수 있나요?
올린 파일은 파일 그대로 관리돼요. 문서 내용을 바꾸려면 원본 파일을 고친 뒤 수정한 버전을 올리세요. 하이퍼클래스에서 직접 쓰고 편집하고 싶다면 리치 텍스트를 사용하세요.

### 리치 텍스트를 고치면 올린 파일이 덮어쓰이나요?
아니요. 파일 기반 소스와 리치 텍스트는 따로 저장돼요.

### 문서를 올리면 기존 지식 베이스 항목이 덮어쓰이나요?
아니요. 올린 파일은 매번 새 소스로 추가돼요. 파일 소스, 리치 텍스트, URL, 자주 묻는 질문, 표 같은 지원하는 소스를 함께 둘 수 있어요.

### 문서 지원이 URL, 자주 묻는 질문, 표 소스를 대체하나요?
아니요. 문서와 리치 텍스트는 다른 지식 베이스 소스를 보완해요. 함께 사용할 수 있어요.

### 올린 내용이 검색되는지 어떻게 테스트하나요?
지식 베이스의 **Retrieval Tester**를 열어 고객이 물을 법한 질문을 입력하고 어떤 소스가 나오는지 확인하세요.

### 엉뚱한 소스가 검색되는 이유는 뭔가요?
중복되거나 오래됐거나 겹치는 내용이 올바른 소스와 경쟁하고 있을 수 있어요. 검색된 소스를 확인하고 제목을 고치고 오래된 내용을 삭제한 다음 다시 테스트하세요.
