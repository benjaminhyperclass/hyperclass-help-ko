# 지식 베이스 학습 링크 자동 새로고침

지식 베이스에 추가한 웹 URL을 매일, 매주, 매월 중 원하는 주기로 하이퍼클래스가 자동으로 다시 크롤링하고 학습하게 하는 기능이에요. 한 번만 설정해 두면 대화 AI 봇이 최신 내용으로 답변해요. 상태와 로그도 표 한 곳에서 확인할 수 있어요.

[동영상](https://www.youtube.com/embed/FBbSIexn6G8?&wmode=opaque)

## 지식 베이스 학습 링크 자동 새로고침이란?

자동 새로고침은 지식 베이스에 추가한 웹 URL을 정해 둔 일정에 맞춰 자동으로 다시 학습시키는 기능이에요. URL마다 **새로고침**을 직접 누를 필요가 없어요. 하이퍼클래스가 주기적으로 페이지를 다시 크롤링해서 표의 데이터를 갱신하고, 봇이 참고하는 새 콘텐츠를 다시 색인해요. 덕분에 봇이 최신 상품 페이지, 도움말 문서, 블로그 글을 참고해 답할 수 있어요.

정기적으로 직접 업데이트하지 않아도 되고, 오래된 정보로 답할 위험도 줄어요. 지식 베이스 URL을 일정에 따라 계속 동기화하므로 봇이 가장 최근 자료를 바탕으로 일관되고 믿을 수 있는 답변을 해요.

## 자동 새로고침의 장점

장점을 알면 알맞은 주기와 적용 범위를 정하기 쉬워요. 특히 여러 서브 계정에서 많은 링크를 관리하는 팀에 도움이 돼요.

- 항상 최신 답변: 봇이 최신 콘텐츠를 사용해서 답변이 더 정확하고 믿을 만해져요.
- 대량 작업 시간 절약: 여러 서브 계정에서 많은 URL을 관리할 때 직접 새로고침하는 일이 줄어요.
- 오래된 답변 감소: 예전 안내, 가격, 정책이 고객에게 전달되는 일을 막아 줘요.
- 사람의 실수 감소: 반복되는 새로고침을 자동으로 처리해서, 한 번 클릭을 놓쳐도 자료가 오래된 채로 남지 않아요.
- 예측 가능한 일정: 콘텐츠가 바뀌는 주기에 맞춰 **매일**, **매주**, **매월** 중에서 고를 수 있어요.
- 부하 분산: 새로고침 시점을 나눠서 트래픽이 몰리는 시간대의 크롤링을 피하고, 규모가 큰 사이트의 성능을 관리할 수 있어요.

## 새로고침 빈도 정하기

새로고침 빈도는 하이퍼클래스가 URL을 얼마나 자주 다시 크롤링할지 정해요. 원본 콘텐츠가 바뀌는 빈도와 URL 라이브러리의 크기를 고려해서 정하세요.

**Auto Refresh**(자동 새로고침) 아이콘(순환 화살표 모양)을 클릭하고 원하는 일정을 선택하세요.

- **매일**: 약 24시간마다 새로고침해요.
- **매주**: 선택한 요일마다 새로고침해요.
- **매월**: 매월 같은 날짜에 새로고침해요.

## 새로고침 상태와 로그 확인하기

크롤링 주기마다 상태를 확인하면 새로고침이 잘 되는지 알 수 있어요. 오류가 있으면 빨리 해결해서 오래된 콘텐츠가 남지 않게 할 수 있어요.

**상태** 열에는 URL별 현재 상태가 표시돼요.

- **데이터 가져오는 중**: 하이퍼클래스가 페이지를 다시 크롤링하고 있어요.
- **학습됨**: 최신 데이터가 저장됐어요. 저장 시각은 **Last data refreshed at**(마지막 데이터 새로고침 시각)에서 확인하세요.
- **실패**: 크롤링 중 오류가 발생했어요. 새로고침을 다시 시도하거나 페이지에 접근할 수 있는지 확인하세요.

## 자동 새로고침 설정하기

아래 단계를 순서대로 따라 하면 새로고침이 일정대로 실행돼요.

1. **서브 계정**에서 **AI 에이전트 > 지식 베이스**로 이동하세요.

   ![AI 에이전트 > 지식 베이스 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055725754/original/PSVZrFEy8yFUbFvJzLXMef6rvJljZrSlWA.png?1760104326)
2. 설정할 지식 베이스를 선택하고 **웹 크롤러**를 클릭하세요.

   ![웹 크롤러 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055725883/original/G7hLoJ_WBVxmgUC_743_FGos-hF3o1y03Q.png?1760104413)
3. **Auto Refresh** 아이콘(순환 화살표 모양)을 클릭하고 새로고침 빈도로 **매일**, **매주**, **매월** 중 하나를 선택하세요.
4. **저장**을 클릭하세요.

   ![자동 새로고침 빈도를 선택하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055726984/original/91Cm-4EmYWejUMIRDHTKzEuZNOyHHKyTvw.gif?1760105055)

## 지식 베이스를 건강하게 관리하는 방법

아래 내용을 지키면 크롤링이 안정적으로 동작하고 실패가 줄어요. 봇도 더 정확하게 답변할 수 있어요.

- 안정적인 URL 사용: 자주 리디렉션되거나 로그인해야 내용을 볼 수 있는 주소는 피하세요.
- 가벼운 페이지 유지: 내용이 지나치게 길거나 스크립트가 많은 페이지는 크롤링이 느려지고 시간 초과가 날 수 있어요.
- 매주 실패 점검: **실패** 상태에 머물러 있는 행을 확인하고, 깨진 링크를 고친 뒤 다시 시도하세요.
- 규모가 큰 사이트는 분산: 라이브러리가 크면 **매주**나 **매월**을 선택해서 부하를 시간에 걸쳐 나누세요.
- 중요한 페이지 우선: 자주 바뀌고 고객에게 바로 영향을 주는 페이지는 **매일**로 설정하세요.

## 자주 묻는 질문

### 자동 새로고침을 쓰면 크레딧이 추가로 들어가나요?
아니요. URL 재크롤링은 기존 대화 AI 사용량에 포함돼요.

### 새로고침이 실패하면 어떻게 되나요?
**상태**가 **실패**로 바뀌고, 이전에 학습한 콘텐츠는 그대로 사용돼요. URL을 고치거나 직접 다시 새로고침하세요.

### 자동 새로고침이 커스텀 FAQ 질문·답변도 업데이트하나요?
아니요. 직접 입력한 질문·답변은 고정된 내용이에요. 필요할 때 직접 수정하세요.

### 단일 URL뿐 아니라 도메인 크롤링에도 자동 새로고침을 쓸 수 있나요?
네. **Web URLs**(웹 URL) 표에 URL이 있으면 어디에나 자동 새로고침을 적용할 수 있어요. 새로고침 주기와 성능은 페이지 깊이와 크기에 따라 달라요.

### 자동 새로고침을 잠시 멈출 수 있나요?
네. **자동화 관리**를 클릭하고 자동 새로고침을 **비활성화**하세요. 나중에 다시 켜도 데이터는 그대로 남아 있어요.

### Google Docs나 PDF도 지원하나요?
현재 자동 새로고침은 누구나 접근할 수 있는 웹 페이지를 대상으로 해요. 문서는 웹에서 접근할 수 있는 페이지로 변환하거나 게시해 주세요.
