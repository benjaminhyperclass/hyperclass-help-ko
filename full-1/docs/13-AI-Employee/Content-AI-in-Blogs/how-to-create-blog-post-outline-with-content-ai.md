# 콘텐츠 AI로 블로그 글 목차 만들기

**콘텐츠 AI**(Content AI)는 블로그 목차, 글 도입부, 특정 섹션을 몇 분 만에 만들어 주는 글쓰기 도우미예요. 이 문서에서는 콘텐츠 AI를 켜는 방법, 가격, 블로그 편집기에서 목차를 만드는 방법을 안내해요.

## 콘텐츠 AI를 쓰면 좋은 점

- 몇 달 치 콘텐츠를 더 짧은 시간에 만들 수 있어요.
- 비즈니스에 필요한 내용에 맞게 콘텐츠를 조정할 수 있어요.
- 아낀 시간을 다른 일에 쓸 수 있어요.

## 콘텐츠 AI 켜기

에이전시 관리자만 쓸 수 있어요. 에이전시 계정의 **설정 > 회사** 탭에서 콘텐츠 AI를 켤 수 있어요. 모든 요금제에서 사용할 수 있어요.

월 497 또는 연 4,970 SaaS 요금제를 쓰고 있다면 **SaaS 구성기**에서 재청구를 설정할 수 있어요. **서브 계정 > Manage Clients**(클라이언트 관리)에서도 설정할 수 있어요.

자세한 내용은 '콘텐츠 AI 활성화 및 재청구 방법' 문서를 참고하세요.

![에이전시 설정의 콘텐츠 AI 활성화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289089503/original/DEd43nc_1weu9fydIyDKL6jIXyk5VVBE5A.png?1679652097)

## 가격

콘텐츠 AI는 사용한 단어 수만큼 요금이 부과되는 사용량 기반 요금제예요. 1,000단어당 $0.09\*예요. 자세한 내용은 '콘텐츠 AI 활성화 및 재청구 방법' 문서의 가격 부분을 참고하세요.

{% hint style="info" %}
각 서브 계정마다 처음 500단어는 무료예요.
{% endhint %}

## 블로그에서 콘텐츠 AI 시작하기

1. **사이트 > 블로그 > 새 게시물 만들기**로 이동하세요.

![새 게시물 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289092707/original/u-xPHdj-h9xErqJl9CTa1_WTJ-NaAxZe-Q.png?1679652801)

{% hint style="info" %}
서브 계정에서 콘텐츠 AI를 쓰려면 사용자 권한을 활성화해야 해요.
{% endhint %}

2. 새 게시글을 만든 뒤 메타 설명을 추가하세요.

![메타 설명 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289093439/original/r5c95Qv__ZHOgbxfPZ513v30bdPa2JuSAg.png?1679652968)

3. 블로그 게시글 편집기로 이동하세요. 여기에서 콘텐츠 AI를 쓸 수 있어요.
4. **콘텐츠 AI**를 클릭하세요. 만들 콘텐츠 유형으로 **목차**, **Introduction**(도입부), **Specific Section**(특정 섹션) 중 하나를 고르는 화면이 나와요. 이어서 게시글 제목, 게시글 설명, 키워드, 콘텐츠 어조, 변형 개수를 입력해요.

{% hint style="info" %}
- **목차**: 블로그의 구조를 잡아 주고 글의 전체 흐름을 보여 주는 글머리 기호 목록이에요.
- **Introduction**: 블로그의 첫 문단이에요. 글의 핵심 개념을 전해요.
- **Specific Section**: 블로그가 5개 섹션으로 이루어져 있다면, 그중 한 섹션의 콘텐츠만 만들 때 써요.
{% endhint %}

![콘텐츠 AI 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289100842/original/jiB9VS9Z4WMQ2nCdpEe11hRfZN9wA7Xiqw.png?1679654737)

입력 항목은 다음과 같아요.

- **게시글 제목**: 콘텐츠의 주제나 카테고리 이름을 입력해요. 예: "콘텐츠 마케팅"
- **Provide a brief description of the post**(게시글 간단 설명): 게시글을 짧게 설명해요. 예: "콘텐츠 마케팅 채널 TOP 5"
- **키워드 추가**: 키워드를 입력하고 Enter 키를 눌러요. 예: "콘텐츠, 마케팅, 전략, 콘텐츠 생성"
- **Writing tone**(글쓰기 어조): 제공되는 옵션에서 어조를 골라요.

예를 들어 콘텐츠를 만들 때는 이렇게 설정해요.

- **Type of Content**(콘텐츠 유형): **목차**를 선택해요.
- 변형 개수는 1개에서 5개 중에서 골라요.

5. 입력을 마치면 제안된 프롬프트의 변형이 만들어져요. 변형 내용을 복사하면 편집기 오른쪽에 나타나요.
6. 게시글 내용이 마음에 들면 **Continue**(계속)를 클릭해 게시글을 만드세요. 콘텐츠가 캡션 영역에 추가돼요.

## 자주 묻는 질문

### 콘텐츠에 어떤 어조를 쓸 수 있나요?
콘텐츠 AI는 재미있는, 캐주얼한, 들뜬, 전문적인, 재치 있는, 비꼬는, 여성스러운, 남성적인, 대담한, 극적인, 투덜대는, 비밀스러운, 정중한, 설득력 있는 어조를 제공해요.

### 예전에 만든 콘텐츠는 어디에서 확인하나요?
**자동화 > 콘텐츠 AI**로 이동하면 이미 만든 콘텐츠를 확인할 수 있어요. 자세한 내용은 [이 문서](../how-to-find-past-records-of-content-generated-by-content-ai.md)를 참고하세요.

### 콘텐츠 AI에서 언어를 선택할 수 있나요?
지금은 언어를 선택하는 옵션이 없어요. 콘텐츠 변형을 만들 때 언어를 고를 수 있도록 기능 범위를 넓혀 갈 계획이에요.

### 콘텐츠 AI로 블로그에 긴 글을 만들 수 있나요?
지금은 긴 글을 만들 수 없어요. 블로그에서 긴 글도 만들 수 있도록 기능 범위를 넓혀 갈 계획이에요.
