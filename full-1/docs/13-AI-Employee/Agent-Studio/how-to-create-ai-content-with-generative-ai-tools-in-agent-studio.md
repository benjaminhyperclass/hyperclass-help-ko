# 에이전트 스튜디오에서 생성형 AI 도구로 AI 콘텐츠 만들기

**에이전트 스튜디오**의 생성형 AI 도구를 쓰면 에이전트 흐름 안에서 텍스트, 오디오, 이미지, 동영상을 AI로 만들 수 있어요. 이 도구는 처리 노드로 추가하며, 프롬프트와 브랜드 보이스, **Brand Kit**(브랜드 키트) 설정, 변수를 활용해 대화나 워크플로우가 진행되는 중에 콘텐츠를 만들어 줘요. 생성된 결과물은 변수에 저장되므로 에이전트 흐름의 뒷부분에서 다시 쓸 수 있어요.

{% hint style="info" %}
이 문서는 **에이전트 스튜디오** 안의 생성형 AI 도구를 다룹니다. **에이전트 스튜디오**와 **AI 스튜디오**는 서로 다른 기능이에요.

에이전트 스튜디오 전반은 [에이전트 스튜디오 사용 방법](../agent-studio-overview.md)과 [에이전트 스튜디오 개요](how-to-setup-flow-agents-in-agent-studio.md)에서 볼 수 있어요.
{% endhint %}

## 생성형 AI 도구란?

생성형 AI 도구는 에이전트가 실행되는 동안 콘텐츠를 만들어 주는 처리 노드예요. 메시지, 이미지, 오디오, 동영상을 에이전트 밖에서 일일이 만들 필요 없이, 여러분이 입력한 프롬프트와 설정에 따라 에이전트가 직접 만들어요.

사용할 수 있는 생성형 AI 도구는 다음과 같아요.

- **텍스트 생성:** 요약, 답변, 설명, 캡션, 추천 문구, 구조화된 텍스트 같은 글을 만들어요.
- **오디오 생성:** 프롬프트로 오디오를 만들고, 생성된 오디오 URL을 변수에 저장해요.
- **이미지 생성:** 프롬프트로 이미지를 만들고, 생성된 이미지 URL을 변수에 저장해요.
- **동영상 생성:** 자세한 동영상 프롬프트로 동영상을 만들고, 설정에 따라 결과물을 저장하거나 사용해요.

## 생성형 AI 도구의 장점

생성형 AI 도구를 쓰면 응답이나 자료를 모두 미리 준비하지 않아도 에이전트가 상황에 맞는 콘텐츠를 만들 수 있어요. 그래서 대화, 캠페인, 자동화에서 에이전트 흐름을 더 유연하고 개인화되게 구성할 수 있어요.

- 자동 콘텐츠 제작: 에이전트 흐름 안에서 바로 텍스트, 오디오, 이미지, 동영상을 만들어요.
- 결과물 재사용: AI가 만든 콘텐츠를 변수에 저장해 두었다가 에이전트의 뒷부분에서 써요.
- 브랜드 일관성: 브랜드 보이스와 **Brand Kit** 설정을 활용해 생성된 콘텐츠가 비즈니스의 말투와 시각적 정체성을 따르도록 해요.
- 유연한 에이전트 흐름: 에이전트가 콘텐츠를 만들어야 하는 지점마다 생성 단계를 추가해요.
- 개인화 강화: 앞 단계에서 받은 변수를 사용해 더 알맞은 결과물을 만들어요.

## 에이전트 스튜디오에서 생성형 AI 도구 추가하기

생성형 AI 도구는 에이전트 빌더에서 처리 노드로 추가해요. 흐름에서 알맞은 위치에 추가해야 원하는 시점에 콘텐츠가 만들어지고, 나중에 쓸 수 있도록 저장돼요.

에이전트에 생성형 AI 도구를 추가하려면 다음과 같이 하세요.

1. 왼쪽 메뉴에서 **AI 에이전트**로 이동하세요.
2. **에이전트 스튜디오** 탭을 여세요.
3. 설정할 에이전트를 선택하세요.
4. 에이전트 빌더 캔버스에서 생성형 AI 액션을 추가할 노드를 찾으세요.

![에이전트 빌더 캔버스에서 노드를 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070612483/original/j7_ZERt278_8nhYrrPBcPDiAuzwTmzLoLg.jpeg?1777985694)

5. **처리 노드 추가**를 클릭하세요.
6. **노드 추가** 패널에서 **생성형 AI** 섹션으로 이동하세요.
7. 추가할 도구를 선택하세요.
   - **오디오 생성**
   - **이미지 생성**
   - **텍스트 생성**
   - **동영상 생성**
8. 오른쪽 패널에서 노드 설정을 입력하세요.
9. 필수 항목을 모두 입력한 뒤 **저장**을 클릭하세요.

선택한 생성형 AI 도구가 노드 안에 처리 단계로 추가돼요. 생성된 결과물은 변수에 저장해 에이전트 흐름의 뒷부분에서 쓸 수 있어요.

![생성형 AI 도구를 선택하는 노드 추가 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070610983/original/dyE3bKxciH6JOMlIQbGbhC0lnYkCk2kF5Q.png?1777984909)

## 텍스트 생성 설정하기

**텍스트 생성**은 노드에 입력한 지시문을 바탕으로 글을 만들어요. 에이전트가 답변, 요약, 캡션, 설명, 추천 문구, 다시 쓴 글, 구조화된 글을 만들어야 할 때 쓰세요.

### **노드 이름**

**노드 이름**은 에이전트 빌더에서 이 텍스트 생성 단계를 구분하는 이름이에요. 필수 입력 항목이며 기본값은 `text_generation`이에요.

에이전트에 처리 단계가 여러 개라면, 나중에 용도를 알아보기 쉽도록 노드 이름을 바꿔 두세요.

예시:

- `generate_summary`
- `create_response`
- `write_product_description`

### **브랜드 보이스**

**브랜드 보이스** 드롭다운에서는 저장해 둔 커뮤니케이션 스타일을 생성할 텍스트에 적용할 수 있어요.

드롭다운에서 다음 중 하나를 할 수 있어요.

- **없음** 선택
- 이미 만들어 둔 브랜드 보이스 선택
- **새로 추가 +** 를 클릭해 새 브랜드 보이스 만들기

특정 브랜드 보이스가 필요 없으면 **없음**으로 두세요. 브랜드 보이스에 대한 자세한 내용은 [에이전트 스튜디오에서 브랜드 보이스와 Brand Kit 사용하기](how-to-use-brand-voice-and-brand-kit-in-agent-studio.md)를 참고하세요.

### **Text Prompt**(텍스트 프롬프트)

**Text Prompt** 필드는 AI가 어떤 글을 만들지 알려 주는 곳이에요. 필수 입력 항목이에요.

완성된 글을 직접 쓸 필요는 없어요. 대신 AI가 무엇을 만들어야 하는지, 어떤 정보를 써야 하는지, 응답을 어떤 형식으로 써야 하는지 지시문으로 적어 주세요. 노드가 실행되면 AI가 이 지시문을 바탕으로 글을 자동으로 만들어요.

**Text Prompt**로 AI에게 이런 일을 시킬 수 있어요.

- 고객 메시지 요약하기
- 답변 만들기
- 짧은 캡션 만들기
- 구조화된 응답 쓰기
- 특정 말투로 글 다시 쓰기

**Text Prompt** 필드 안의 변수 선택기를 사용하면 프롬프트에 동적인 값을 넣을 수 있어요. 검색창으로 넣고 싶은 변수나 값을 빠르게 찾을 수 있어요.

드롭다운에 표시되는 변수 카테고리는 다음과 같아요.

- **전역 설정:** 에이전트의 전역 설정에 있는 값을 넣어요.
- **입력 변수:** 에이전트가 시작되거나 호출될 때 전달된 값을 넣어요.
- **런타임 변수:** 에이전트가 실행되는 동안 만들어지거나 수집된 값을 넣어요.
- **계정:** 계정 단위의 값을 넣어요.
- **커스텀 값:** 계정에 저장된 커스텀 값을 넣어요.
- **지금:** 현재 날짜나 시간과 관련된 값을 넣어요.
- **연락처:** 연락처 정보 같은 연락처별 값을 넣어요.

**프롬프트 개선** 버튼을 누르면 저장하기 전에 프롬프트를 다듬거나 보강할 수 있어요. 긴 지시문을 쓸 때는 프롬프트 필드의 확장 아이콘을 눌러 더 큰 입력 창을 여세요.

"뭐든 써 줘"처럼 모호한 프롬프트는 피하세요. 목표, 대상, 말투, 원하는 형식을 구체적으로 적어 주세요.

### **변수 이름**

**변수 이름** 필드는 생성된 텍스트를 저장할 변수의 이름이에요. 필수 입력 항목이에요.

생성된 텍스트가 무엇인지 알 수 있는 이름을 쓰세요.

- `generatedSummary`
- `generatedReply`
- `productDescription`

### **모델**

**모델** 드롭다운에서는 텍스트를 만들 AI 모델을 정해요. 필수 입력 항목이에요.

화면에 표시되는 모델 옵션은 다음과 같아요.

- **gpt-4.1**
- **gpt-5-mini**

만들고 싶은 결과물에 가장 알맞은 모델을 선택하세요. 일반적인 텍스트 응답, 요약, 구조화된 콘텐츠라면 다른 모델이 필요한 경우가 아닌 한 기본값이나 권장 모델을 쓰세요.

### **Text Length**(텍스트 길이)

**Text Length** 필드는 생성할 텍스트의 최대 길이를 정해요. 필수 입력 항목이에요.

안내 문구에 따르면 미리 정해진 옵션을 고르거나, 5자에서 20,000자 사이의 최대 글자 수를 직접 입력할 수 있어요.

화면에 표시되는 **Text Length** 옵션은 다음과 같아요.

- **작게:** 빠른 답변, 캡션, 짧은 요약처럼 짧은 응답을 만들어요.
- **Big**(크게): 더 자세한 글에 알맞은 긴 응답을 만들어요.
- **사용자 지정:** 최대 글자 수를 직접 정해요.

![텍스트 생성 노드를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070611927/original/FvjSwTESzzYMgQlvhorytstCV6zuUrBYmA.gif?1777985401)

## 오디오 생성 설정하기

**오디오 생성**은 노드에 입력한 지시문을 바탕으로 오디오 파일을 만들어요. 에이전트가 음성 콘텐츠, 음성 응답, 오디오 메시지, 내레이션을 만들어야 할 때 쓰세요.

### **노드 이름**

**노드 이름**은 에이전트 빌더에서 이 오디오 생성 단계를 구분하는 이름이에요. 필수 입력 항목이며 기본값은 `audio_generation`이에요.

나중에 생성된 오디오의 용도를 알아보기 쉽도록 노드 이름을 바꿔 두세요.

예시:

- `generate_voice_response`
- `create_audio_message`
- `audio_summary`

### **브랜드 보이스**

**브랜드 보이스** 드롭다운은 텍스트 생성에서와 똑같이 작동해요. 저장해 둔 커뮤니케이션 스타일을 오디오 프롬프트에 적용할 때 쓰세요.

드롭다운에서 **없음**을 선택하거나, 이미 만들어 둔 브랜드 보이스를 고르거나, **새로 추가 +** 를 클릭해 새 브랜드 보이스를 만들 수 있어요.

### **프롬프트**

**프롬프트** 필드는 AI가 어떤 오디오를 만들지 알려 주는 곳이에요. 필수 입력 항목이에요.

오디오 파일을 직접 만들 필요는 없어요. 대신 오디오가 어떤 내용을 말해야 하는지, 무엇을 표현해야 하는지 지시문으로 적어 주세요. 읽어야 할 문장을 그대로 적어도 되고, 필요한 오디오 콘텐츠의 종류를 설명해도 돼요.

좋은 오디오 프롬프트에는 다음 내용이 들어갈 수 있어요.

- 말할 메시지
- 말투
- 스타일
- 속도
- 대상 오디언스

**프롬프트** 필드 안의 변수 선택기를 사용하면 연락처 정보나 앞에서 수집한 정보처럼 에이전트 흐름의 값을 넣을 수 있어요.

**프롬프트 개선** 버튼을 누르면 저장하기 전에 프롬프트를 다듬거나 보강할 수 있어요. 오디오 지시문이 길면 프롬프트 필드의 확장 아이콘을 눌러 더 큰 입력 창을 여세요.

### **변수 이름**

**변수 이름** 필드는 생성된 오디오 URL을 저장할 변수의 이름이에요. 필수 입력 항목이에요.

내용을 알 수 있는 변수 이름을 쓰세요.

- `generatedAudioUrl`
- `voiceMessageUrl`
- `audioResponseUrl`

### **모델**

**모델** 드롭다운에서는 오디오를 만들 텍스트 음성 변환(TTS) 모델을 정해요. 필수 입력 항목이에요.

사용할 수 있는 모델은 다음과 같아요.

- **gpt-4o-mini-tts**

다른 모델이 필요하거나 선택할 수 있는 경우가 아니라면 선택된 모델을 그대로 쓰세요.

### **음성 이름**

**음성 이름** 드롭다운에서는 생성할 오디오에 쓸 음성을 정해요. 필수 입력 항목이에요.

선택할 수 있는 음성은 다음과 같아요.

- **Alloy:** 균형 잡힌 음성으로, 범용 오디오에 알맞아요.
- **Ash:** 이 음성의 분위기가 메시지와 어울릴 때 쓸 수 있어요.
- **Ballad:** 더 부드럽거나 표현력 있는 오디오 스타일에 쓸 수 있어요.
- **Coral:** 이 음성의 소리가 원하는 브랜드 분위기와 맞을 때 쓸 수 있어요.
- **Echo:** 대화체나 음성 응답 오디오에 쓸 수 있어요.
- **Fable:** 이야기하는 듯한 스타일이나 표현력 있는 오디오에 쓸 수 있어요.
- **Nova:** 또렷하고 세련된 음성 콘텐츠에 쓸 수 있어요.

따뜻함, 전문적임, 활기참, 차분함, 대화체 등 오디오에서 원하는 분위기와 가장 잘 맞는 음성을 고르세요.

## 이미지 생성 설정하기

**이미지 생성**은 노드에 입력한 지시문을 바탕으로 이미지를 만들어요. 에이전트가 캠페인, 소셜 콘텐츠, 상품 콘셉트 등에 쓸 이미지 자료를 만들어야 할 때 쓰세요.

### **노드 이름**

**노드 이름**은 에이전트 빌더에서 이 이미지 생성 단계를 구분하는 이름이에요. 필수 입력 항목이며 기본값은 `image_generation`이에요.

나중에 생성된 이미지의 용도를 알아보기 쉽도록 노드 이름을 바꿔 두세요.

예시:

- `generate_product_image`
- `create_social_image`
- `image_for_campaign`

### **브랜드 보이스**

**브랜드 보이스** 드롭다운은 텍스트 생성에서와 똑같이 작동해요. 이미지 프롬프트가 특정 캠페인의 말투, 대상, 크리에이티브 방향을 따라야 할 때 쓰세요.

드롭다운에서 **없음**을 선택하거나, 이미 만들어 둔 브랜드 보이스를 고르거나, **새로 추가 +** 를 클릭해 새 브랜드 보이스를 만들 수 있어요.

### **디자인 키트**

**디자인 키트** 드롭다운에서는 저장해 둔 시각적 브랜딩을 생성할 이미지에 적용할 수 있어요.

드롭다운에서 다음 중 하나를 할 수 있어요.

- **없음** 선택
- 이미 만들어 둔 디자인 키트 선택
- **새로 추가 +** 를 클릭해 새 디자인 키트 만들기

생성된 이미지가 비즈니스의 시각적 정체성과 맞아야 한다면 디자인 키트를 쓰세요. 사용 가능한 설정에 따라 브랜드 색상, 글꼴, 로고 사용 방식 등 저장해 둔 시각 요소가 반영될 수 있어요.

### **Image Prompt**(이미지 프롬프트)

**Image Prompt** 필드는 AI가 어떤 이미지를 만들지 알려 주는 곳이에요. 필수 입력 항목이에요.

이미지를 직접 만들 필요는 없어요. 대신 AI가 만들 이미지를 지시문으로 설명해 주세요. AI가 피사체, 스타일, 시각적 방향을 이해할 수 있도록 충분히 자세히 적는 것이 좋아요.

좋은 **Image Prompt**에는 다음 내용이 들어갈 수 있어요.

- 피사체
- 배경과 장소
- 스타일
- 색상
- 구도
- 분위기
- 이미지에 꼭 나와야 하는 세부 요소

예시:

"따뜻한 조명 아래 신선한 음식이 놓여 있고 아늑한 분위기가 느껴지는 현대적인 레스토랑 테이블 세팅을, 전문 사진 스타일로 만들어 주세요."

**Image Prompt** 필드 안의 변수 선택기를 사용하면 상품 이름, 캠페인 주제, 연락처 정보, 수집한 응답처럼 에이전트 흐름의 값을 넣을 수 있어요.

**프롬프트 개선** 버튼을 누르면 저장하기 전에 프롬프트를 다듬거나 보강할 수 있어요. 이미지 지시문이 길면 **Image Prompt** 필드의 확장 아이콘을 눌러 더 큰 입력 창을 여세요.

### **변수 이름**

**변수 이름** 필드는 생성된 이미지 URL을 저장할 변수의 이름이에요. 필수 입력 항목이에요.

내용을 알 수 있는 변수 이름을 쓰세요.

- `generatedImageUrl`
- `campaignImageUrl`
- `productImageUrl`

### **모델**

**모델** 드롭다운에서는 이미지를 만들 AI 이미지 생성 모델을 정해요. 필수 입력 항목이에요.

화면에 표시되는 모델 옵션은 다음과 같아요.

- **GPT Image 1:** GPT Image 모델로 이미지를 만들어요.
- **DALL·E 3:** DALL·E 3 모델로 이미지를 만들어요.
- **Gemini 2.5 Flash Image Preview:** Gemini 이미지 미리보기 모델로 이미지를 만들어요.

만들고 싶은 이미지 결과물에 맞는 모델을 선택하세요. 기본 모델이 이미 선택되어 있다면, 워크플로우에 다른 모델이 필요한 경우가 아닌 한 그대로 쓰세요.

### **Image Size**(이미지 크기)

**Image Size** 드롭다운에서는 생성할 이미지의 크기를 정해요. 필수 입력 항목이에요.

선택할 수 있는 **Image Size** 옵션은 다음과 같아요.

- **1024x1024:** 정사각형 이미지를 만들어요. 일반 크리에이티브 자료, 썸네일, 소셜 게시물에 알맞아요.
- **1024x1792:** 세로로 긴 이미지를 만들어요. 세로형 지면에 알맞아요.
- **1792x1024:** 가로로 긴 이미지를 만들어요. 넓은 지면에 알맞아요.

### **Image Quality**(이미지 품질)

**Image Quality** 드롭다운에서는 생성할 이미지의 품질 수준을 정해요. 필수 입력 항목이에요.

선택할 수 있는 **Image Quality** 옵션은 다음과 같아요.

- **표준:** 범용 이미지 결과물을 만들어요.
- **Hd:** 더 완성도 높은 크리에이티브 자료를 위한 고품질 이미지를 만들어요.

![이미지 생성 노드를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070611575/original/4U5K-aLS-fv_9CZ1Ow39nzuzN-oVC2DXOQ.gif?1777985265)

## 동영상 생성 설정하기

**동영상 생성**은 노드에 입력한 지시문을 바탕으로 동영상을 만들어요. 에이전트가 캠페인, 크리에이티브 자료, 소셜 미디어 등에 쓸 짧은 동영상을 만들어야 할 때 쓰세요.

텍스트 생성, 오디오 생성, 이미지 생성과 달리, 여기에 표시된 동영상 생성 화면에는 **변수 이름** 필드가 없어요. 패널에 보이는 동영상 설정을 입력하고, 결과물이 어떻게 처리되는지는 에이전트 설정에서 확인하세요.

### **노드 이름**

**노드 이름**은 에이전트 빌더에서 이 동영상 생성 단계를 구분하는 이름이에요. 필수 입력 항목이며 기본값은 `video_generation`이에요.

나중에 생성된 동영상의 용도를 알아보기 쉽도록 노드 이름을 바꿔 두세요.

예시:

- `generate_promo_video`
- `create_product_video`
- `video_for_social_post`

### **브랜드 보이스**

**브랜드 보이스** 드롭다운은 텍스트 생성에서와 똑같이 작동해요. 동영상 프롬프트가 비즈니스의 말투, 메시지 스타일, 캠페인 방향과 맞아야 할 때 쓰세요.

드롭다운에서 **없음**을 선택하거나, 이미 만들어 둔 브랜드 보이스를 고르거나, **새로 추가 +** 를 클릭해 새 브랜드 보이스를 만들 수 있어요.

### **디자인 키트**

**디자인 키트** 드롭다운은 이미지 생성에서와 똑같이 작동해요. 생성된 동영상이 특정 브랜드 스타일이나 시각적 정체성을 따라야 할 때 쓰세요.

드롭다운에서 **없음**을 선택하거나, 이미 만들어 둔 디자인 키트를 고르거나, **새로 추가 +** 를 클릭해 새 디자인 키트를 만들 수 있어요.

### **Video prompt**(동영상 프롬프트)

**Video prompt** 필드는 AI가 어떤 동영상을 만들지 알려 주는 곳이에요. 필수 입력 항목이에요.

동영상을 직접 만들 필요는 없어요. 대신 동영상에서 무슨 일이 일어나야 하고 어떻게 보여야 하는지 지시문으로 적어 주세요. 입력란의 안내 문구도 동작, 카메라 앵글, 조명, 스타일을 구체적으로 적으라고 권해요.

좋은 **Video prompt**에는 다음 내용이 들어갈 수 있어요.

- 피사체
- 동작
- 장면이나 배경
- 카메라 앵글
- 조명
- 시각적 스타일
- 움직임
- 분위기

예시:

"햇살 가득한 초원을 달리는 골든 리트리버, 슬로 모션, 영화 같은 조명, 따뜻한 색감."

**Video prompt** 필드 안의 변수 선택기를 사용하면 캠페인 정보, 상품 이름, 앞에서 수집한 응답처럼 에이전트 흐름의 값을 넣을 수 있어요.

**프롬프트 개선** 버튼을 누르면 저장하기 전에 프롬프트를 다듬거나 보강할 수 있어요. 동영상 지시문이 길면 확장 아이콘을 눌러 더 큰 입력 창을 여세요.

### **AI 모델**

**AI 모델** 드롭다운에서는 동영상을 만들 생성 모델을 정해요. 필수 입력 항목이에요.

선택할 수 있는 **AI 모델** 옵션은 다음과 같아요.

- **Veo3.1:** 표준 Veo3.1 모델로 동영상을 만들어요.
- **Veo3.1 Fast:** 더 빠른 Veo3.1 옵션으로 동영상을 만들어요.

만들고 싶은 동영상에 가장 잘 맞는 모델을 선택하세요. 속도가 더 중요하다면 선택할 수 있을 때 빠른 옵션을 고르세요. 기본 모델이 선택되어 있다면, 워크플로우에 다른 모델이 필요한 경우가 아닌 한 그대로 두세요.

### **가로세로 비율**

**가로세로 비율** 드롭다운에서는 생성할 동영상의 모양을 정해요. 필수 입력 항목이에요.

선택할 수 있는 **가로세로 비율** 옵션은 다음과 같아요.

- **16:9:** 가로형 동영상을 만들어요. 웹사이트 콘텐츠, YouTube 스타일 동영상, 프레젠테이션 등 넓은 지면에 알맞아요.
- **9:16:** 세로형 동영상을 만들어요. 숏폼 소셜 콘텐츠나 모바일 중심 지면에 알맞아요.

### **해상도**

**해상도** 드롭다운에서는 생성할 동영상의 출력 해상도를 정해요. 필수 입력 항목이에요.

선택할 수 있는 **해상도** 옵션은 다음과 같아요.

- **720p:** 720p 해상도로 동영상을 만들어요.

동영상의 품질과 사용 목적에 맞는 해상도를 선택하세요. 필드가 비어 있다면 저장하기 전에 해상도를 선택하세요.

### **AI Model Data Use Notice**(AI 모델 데이터 사용 안내)

**AI Model Data Use Notice** 체크박스는 동영상 생성에서 외부 AI 모델이 프롬프트와 생성된 콘텐츠를 어떻게 다루는지 설명해요.

안내에 따르면 에이전트 스튜디오는 외부 AI 모델을 사용하며, 이 모델은 안전 모니터링과 서비스 제공을 위해 프롬프트와 생성된 콘텐츠를 최대 **30일** 동안 임시로 보관할 수 있어요. 또한 여러분의 데이터는 모델 학습에 사용되지 않으며, 데이터 처리 방식은 AI 제공업체마다 다르다고 안내해요.

노드를 저장하기 전에 안내를 읽어 보세요. 계속하려면 체크박스를 선택해 안내를 확인했음을 표시하세요.

**저장** 버튼은 필수 항목을 모두 입력하고 이 안내를 확인해야 활성화돼요.

## 생성형 AI 도구에서 변수 사용하기

변수를 활용하면 생성형 AI 도구가 더 알맞은 결과물을 만들고, 생성된 콘텐츠를 뒷 단계에서 쓸 수 있어요. 입력 변수와 출력 변수의 차이를 알아 두면 프롬프트를 설정하고 생성된 콘텐츠를 다시 쓰기 쉬워요. 변수에 대한 자세한 내용은 [에이전트 스튜디오에서 커스텀 값과 변수 사용하기](how-to-use-custom-values-and-variables-in-agent-studio.md)를 참고하세요.

생성형 AI 도구에서 변수는 보통 두 가지 방식으로 쓰여요.

- 프롬프트에 넣는 입력 변수: 이미 있는 변수를 프롬프트에 넣으면, AI가 연락처 정보, 수집한 응답, 앞 단계의 에이전트 결과물을 활용해 콘텐츠를 만들어요.
- 노드가 만드는 출력 변수: 텍스트 생성, 오디오 생성, 이미지 생성은 **변수 이름** 필드에 새로 만든 결과물을 저장해요.

예를 들어 프롬프트에는 `{{contact.first_name}}` 같은 기존 변수나, 에이전트 흐름 앞부분에서 수집한 다른 값을 넣을 수 있어요.

생성된 출력 변수에는 다음과 같은 것들이 있어요.

- 생성된 글을 저장하는 텍스트 생성 노드
- 생성된 오디오 URL을 저장하는 오디오 생성 노드
- 생성된 이미지 URL을 저장하는 이미지 생성 노드

뒷 단계에서 결과물을 쉽게 알아볼 수 있도록 명확하고 설명적인 변수 이름을 쓰세요.

좋은 변수 이름의 예:

- `generatedReply`
- `generatedAudioUrl`
- `generatedImageUrl`
- `campaignCaption`
- `summaryText`

특히 에이전트에 AI 생성 단계가 여러 개라면, 결과물이 무엇인지 알 수 없는 이름은 피하세요.

생성형 AI 도구로 텍스트, 오디오, 이미지, 동영상을 만들 수 있어요.

### 모든 생성형 AI 도구가 결과물을 변수 이름 필드에 저장하나요?
텍스트 생성, 오디오 생성, 이미지 생성에는 생성된 결과물을 저장하는 **변수 이름** 필드가 있어요. 여기에 표시된 동영상 생성 화면에는 **변수 이름** 필드가 없어요.

### 변수 이름 필드는 어떤 역할을 하나요?
**변수 이름** 필드는 생성된 결과물을 저장해서 에이전트 흐름의 뒷부분에서 참조할 수 있게 해 줘요. 텍스트 생성은 생성된 텍스트를, 오디오 생성은 생성된 오디오 URL을, 이미지 생성은 생성된 이미지 URL을 저장해요.

### 프롬프트 안에 변수를 쓸 수 있나요?
네. 프롬프트 필드에는 변수 선택기가 있어서 앞 단계의 값, 연락처 필드, 그 밖에 사용할 수 있는 변수를 넣을 수 있어요.

### 프롬프트 필드에 최종 콘텐츠를 직접 써야 하나요?
아니요. 프롬프트 필드는 AI가 무엇을 만들어야 하는지 지시하는 곳이에요. 노드가 실행되면 AI가 최종 텍스트, 오디오, 이미지, 동영상 결과물을 만들어요.

### 브랜드 보이스는 어디에 쓰나요?
브랜드 보이스는 생성된 콘텐츠가 비즈니스가 선호하는 말투, 커뮤니케이션 스타일, 메시지 가이드라인과 맞도록 도와줘요.

### 디자인 키트는 어디에 쓰나요?
디자인 키트는 이미지나 동영상 같은 시각적 결과물이 비즈니스의 시각적 정체성과 맞도록 도와줘요. 사용할 수 있는 키트가 있을 때 적용돼요.

### 브랜드 보이스나 디자인 키트 옵션이 보이지 않아요.
먼저 브랜드 보이스나 디자인 키트를 만들거나 추가해야 할 수 있어요. 드롭다운에 있는 **새로 추가 +** 를 누르면 노드 설정 화면에서 바로 새 옵션을 만들 수 있어요.

### 동영상 생성에 AI Model Data Use Notice가 표시되는 이유는 무엇인가요?
동영상 생성은 외부 AI 모델을 사용하기 때문이에요. 이 안내에는 안전 모니터링과 서비스 제공을 위해 프롬프트와 생성된 콘텐츠가 최대 30일 동안 임시로 보관될 수 있다는 점, 데이터가 모델 학습에 사용되지 않는다는 점, 데이터 처리 방식이 제공업체마다 다르다는 점이 설명돼 있어요.

### 저장 버튼이 비활성화되어 있어요.
필수 항목이 비어 있으면 **저장** 버튼이 비활성화된 채로 있어요. 동영상 생성은 AI Model Data Use Notice를 확인하기 전까지도 비활성화된 상태로 남아요.
