# 관리형 에이전트 파일 첨부 지원

**파일 첨부**를 쓰면 관리형 에이전트가 채팅에 입력한 글뿐 아니라 업무 문서와 PNG 이미지도 직접 읽을 수 있어요. 지원하는 파일을 첨부해 내용을 분석하고, **이미지 생성**이 켜져 있으면 PNG 이미지를 편집할 수도 있어요. 같은 대화 안에서 이어서 추가 요청도 할 수 있어요. 이 문서에서는 지원하는 파일 형식, 채팅에서 사용하는 방법, 이미지 편집, 첨부 제한, 알아 두면 좋은 한계를 안내해요.

## 관리형 에이전트 파일 지원이란?

관리형 에이전트 파일 지원은 지원하는 문서와 PNG 이미지를 관리형 에이전트 대화에 바로 첨부하는 기능이에요. 에이전트는 첨부 파일을 읽고, 그 내용을 참고 자료로 삼아 찾아낸 정보에 대한 질문에 답해요.

**이미지 생성**이 켜져 있으면 첨부한 PNG 이미지를 편집해 달라고 요청할 수도 있어요. 원하는 변경 사항을 설명한 뒤, 같은 대화에서 추가 지시로 결과물을 계속 다듬으면 돼요.

문서를 여러 개 첨부해서 문서 전체를 아우르는 작업을 요청할 수도 있어요. 긴 문서는 내용을 직접 대화창에 복사해 넣지 않아도, 관리형 에이전트가 관련 부분을 찾아서 사용해요.

## 관리형 에이전트 파일 지원의 장점

파일을 첨부하면 관리형 에이전트가 요청의 바탕이 되는 원본 자료를 직접 볼 수 있어요. 일일이 복사하는 수고가 줄고, 문서 기반 작업을 같은 대화 안에서 끝내기 쉬워져요.

- 원본 파일로 작업해요: 내용을 메시지 입력란에 복사하는 대신 업무 문서와 이미지를 그대로 첨부하세요.
- 추가 질문을 할 수 있어요: 대화하는 동안 첨부 파일에 대해 계속 물어볼 수 있어요.
- 여러 문서를 함께 분석해요: 지원하는 문서를 여러 개 첨부하고, 둘 이상의 파일에서 정보를 찾아야 하는 질문을 할 수 있어요.
- 긴 문서도 다뤄요: 관리형 에이전트가 긴 파일에서 관련 부분을 찾아 답변에 활용해요.
- 자주 쓰는 업무 파일 형식을 지원해요: 문서 형식은 PDF, DOCX, TXT, Markdown, CSV, JSON을 지원해요.
- 필요하면 바로잡을 수 있어요: 에이전트가 내용을 잘못 해석했다면 추가 메시지로 정정하거나 설명해 주세요.
- 대화로 PNG 이미지를 편집해요: PNG 이미지를 첨부하고 원하는 변경 사항을 말하면 돼요. 별도의 이미지 편집 도구로 옮겨 갈 필요가 없고, 같은 대화에서 추가 지시로 결과를 계속 다듬을 수 있어요.

## 사전 준비 및 제한 사항

지원 형식과 현재 제한을 알아 두면 분석할 파일을 준비하기 쉬워요. 결과는 문서를 얼마나 읽기 좋게 만들었는지, 파일 구조, 관리형 에이전트에 설정한 지침에 따라 달라질 수 있어요.

- 문서 하나당 최대 5MB까지 첨부할 수 있어요.
- 첨부 파일은 대화가 이어지는 동안 계속 사용할 수 있어요.
- 문서 형식은 PDF, DOCX, TXT, Markdown, CSV, JSON을 지원해요.
- PNG 이미지를 지원해요.
- 첨부한 PNG 이미지를 편집하려면 관리형 에이전트에서 **이미지 생성**이 켜져 있어야 해요.
- 기술적으로 올바른 PDF라도 교차 참조 데이터가 인코딩된 방식에 따라 거부될 수 있어요.
- 이전에 첨부한 파일이 같은 대화의 이후 답변에 영향을 줄 수 있어요. 서로 관련 없는 문서를 분석할 때는 새 대화를 시작하세요.
- 에이전트의 개인정보 또는 안전 관련 지침 때문에, 에이전트가 추출한 값 중 일부를 알려 주지 않을 수 있어요.
- 텍스트 추출은 Word 고유의 서식, 댓글, 변경 내용 추적, 머리글, 삽입된 개체가 그대로 유지된다는 뜻이 아니에요.
- 모델이 사소한 실수를 할 수 있어요. 추출된 중요한 값은 후속 업무에 쓰기 전에 직접 확인하세요.

{% hint style="info" %}
결과는 문서를 얼마나 읽기 좋게 만들었는지와 에이전트의 지침에 따라 달라질 수 있어요.
{% endhint %}

## 지원하는 파일 형식

관리형 에이전트는 자주 쓰는 문서 형식 몇 가지와 PNG 이미지를 지원해요. 아래 표는 파일을 직접 첨부할 때 현재 호환되는 형식을 정리한 거예요.

| 파일 유형 | 확장자 | 지원 여부 |
| --- | --- | --- |
| PDF | `.pdf` | 지원 |
| Microsoft Word | `.docx` | 지원 |
| 일반 텍스트 | `.txt` | 지원 |
| Markdown | `.md` | 지원 |
| CSV | `.csv` | 지원 |
| JSON | `.json` | 지원 |
| 이미지 | `.png` | 지원 |

PDF, DOCX, TXT, Markdown, CSV, JSON은 출시 자료에 명시된 형식이에요. PNG 지원은 제품 팀이 확인했고 테스트에서도 검증됐어요.

XLS, XLSX, DOC, RTF, PPTX 같은 형식은 제공된 출시 자료에 지원한다고 나와 있지 않아요. 되는 것으로 가정하지 마세요.

지식 베이스의 문서 지원이 궁금하다면 [AI 에이전트용 지식 베이스 문서 지원](../knowledge-base-document-rich-text-support.md) 문서를 참고하세요.

## 관리형 에이전트로 파일 첨부하고 작업하기

관리형 에이전트를 게시한 뒤에는 에이전트 메인 페이지로 돌아가 바로 채팅할 수 있어요. 거기서 지원하는 파일이나 PNG 이미지를 첨부하고 분석을 요청하세요. 관리형 에이전트 설정이 필요하다면 [에이전트 스튜디오에서 관리형 에이전트 설정하고 사용하기](setup-and-use-managed-agents-in-agent-studio.md) 문서를 참고하세요.

1. **서브 계정**에서 **AI 에이전트**를 선택하세요.
2. **에이전트 스튜디오**를 선택하세요.
3. **관리형 에이전트**를 선택하세요.
4. 사용할 관리형 에이전트를 선택하세요.
5. 필요한 내용을 에이전트에 수정하세요.
6. **게시**를 클릭하세요.
7. **뒤로**를 클릭해 에이전트 메인 페이지로 돌아가세요.
8. 채팅 화면에서 메시지 입력란 옆의 **+** 첨부 버튼을 클릭하세요.
9. 사용할 지원 문서나 PNG 이미지를 선택하세요.
10. 첨부 파일에 대한 질문이나 지시를 입력하세요.
11. PNG 이미지를 편집하려면 관리형 에이전트가 어떻게 바꿔 주길 원하는지 구체적으로 설명하세요. 에이전트에서 **이미지 생성**이 켜져 있어야 해요.
12. 메시지를 보내고 답변이나 편집된 이미지를 확인하세요.
13. 필요하면 추가 질문, 정정, 이미지 편집 지시를 이어서 보내세요.

![관리형 에이전트 채팅 화면의 파일 첨부](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082422012/original/rYGT-Le5zKPj2qFPq-7Pa5NXiSMOdVLQ2Q.png?1790971905)

1. 분석할 지원 파일이나 PNG 이미지를 선택하세요.
2. 첨부 파일에 대한 질문이나 지시를 입력하세요.
3. 메시지를 보내세요.
4. 답변을 확인하고, 필요하면 추가 질문이나 정정을 이어서 보내세요.

이런 질문을 해 볼 수 있어요.

- "이 계약서의 핵심 의무 사항을 요약해 줘."
- "이 파일에 있는 모든 인보이스 번호, 고객, 합계를 나열해 줘."
- "이 이미지에는 어떤 정보가 있어?"
- "이 CSV에서 상태가 Pending인 행은 어떤 거야?"

에이전트가 값을 잘못 해석했거나 중요한 맥락을 놓쳤다면, 추가 메시지로 정보를 바로잡아 주고 파일을 다시 살펴보라고 요청하세요.

## 한 대화에서 여러 파일 분석하기

여러 파일을 한꺼번에 분석하면 관리형 에이전트가 파일을 하나씩 따로 처리하지 않아도 여러 문서의 정보를 비교하거나 합칠 수 있어요. 관련된 정보가 여러 파일에 나뉘어 있을 때 유용해요.

예를 들면 이렇게 요청할 수 있어요.

> "이 문서들을 비교해서, 둘 이상의 파일에 나오는 고객 이름, 날짜, 금액, 조건을 찾아 줘."

첨부 파일은 대화가 이어지는 동안 계속 사용할 수 있어요. 같은 파일을 다시 첨부하지 않고도 추가 질문을 할 수 있어요.

PNG 이미지를 다룰 때도 같은 대화에서 편집 결과를 계속 다듬을 수 있어요. 추가 편집 지시는 가장 최근 이미지를 바탕으로 이어지므로 원본 PNG를 다시 첨부하지 않아도 돼요.

서로 관련 없는 문서를 분석할 때는 새 대화를 시작하세요. 이전 첨부 파일이 대화 맥락에 남아 있으면 이후 답변에 영향을 줄 수 있어요.

## 자주 묻는 질문

### 관리형 에이전트에 어떤 문서 형식을 첨부할 수 있나요?
문서 형식은 PDF, DOCX, TXT, Markdown, CSV, JSON을 지원해요. PNG 이미지도 지원해요.

### 문서 하나의 크기는 얼마까지 가능한가요?
문서 하나당 최대 5MB까지 가능해요.

### 관리형 에이전트가 파일 여러 개를 참고해서 질문에 답할 수 있나요?
네. 관리형 에이전트는 같은 요청에서 첨부된 여러 문서의 정보를 활용할 수 있어요.

### 추가 질문을 할 때마다 파일을 다시 첨부해야 하나요?
아니요. 첨부 파일은 대화가 이어지는 동안 계속 사용할 수 있어요.

### 에이전트가 파일의 정보를 잘못 파악하면 어떻게 하나요?
추가 메시지로 정보를 바로잡거나 설명하고, 에이전트에게 파일을 다시 살펴보라고 요청하세요. 추출된 중요한 값은 사용하기 전에 직접 확인하세요.

### 지원하는 파일인데 실패하거나 결과가 불완전한 이유는 뭔가요?
결과는 파일을 얼마나 읽기 좋게 만들었는지, 문서 인코딩, 구조, 에이전트의 지침에 따라 달라질 수 있어요. 기술적으로 올바른 PDF라도 교차 참조 데이터가 인코딩된 방식 때문에 거부될 수 있어요.

### DOCX를 지원하면 Microsoft Word의 모든 내용과 서식이 그대로 유지되나요?
꼭 그렇지는 않아요. 텍스트 추출은 Word 서식, 댓글, 변경 내용 추적, 머리글, 삽입된 개체가 유지된다는 뜻이 아니에요.

### 관리형 에이전트에 첨부한 PNG 이미지를 편집할 수 있나요?
네. **이미지 생성**이 켜져 있으면 PNG 이미지를 첨부하고 관리형 에이전트가 어떻게 바꿔 주길 원하는지 설명하세요. 같은 대화에서 추가 지시로 편집 결과를 계속 다듬을 수 있어요.
