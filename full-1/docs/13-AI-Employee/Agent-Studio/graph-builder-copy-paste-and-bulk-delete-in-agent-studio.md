# 에이전트 스튜디오에서 노드 복사, 붙여넣기, 일괄 삭제

**에이전트 스튜디오**의 **Graph Builder**(그래프 빌더) 캔버스에서 선택한 노드를 복사하고, 붙여넣고, 한꺼번에 삭제하는 방법을 안내해요. 검증된 노드 묶음을 재사용하거나 오래된 분기를 정리할 때 쓰면 매번 처음부터 다시 만들지 않아도 돼요.

이 기능은 선택한 노드나 플로우 일부를 대상으로 해요. 에이전트 전체를 복제하는 용도가 아니에요.

## Graph Builder 복사, 붙여넣기, 일괄 삭제란?

**Graph Builder**의 복사, 붙여넣기, 일괄 삭제는 에이전트 스튜디오 캔버스에서 쓰는 편집 도구예요. 선택한 노드를 복사해 같은 캔버스나 다른 에이전트 스튜디오 탭에 붙여넣을 수 있어요. 복사한 노드끼리의 연결은 그대로 유지돼요. 선택한 노드 여러 개를 한 번에 삭제할 수도 있어요.

붙여넣은 노드에는 새 ID가 부여돼요. 그래서 원본과는 별개의 노드로 동작해요. 플로우 일부를 재사용하면서도 에이전트 그래프를 깔끔하게 관리할 수 있어요.

## 이럴 때 편해요

에이전트 플로우를 만들거나 관리하다 보면 같은 편집을 반복하게 돼요. 이 도구는 노드 묶음, 테스트 분기, 재사용할 수 있는 플로우 일부를 다룰 때 가장 잘 맞아요.

- 그래프를 더 빠르게 만들 수 있어요. 기존 노드를 복사하면 처음부터 다시 만들 필요가 없어요.
- 플로우를 쉽게 재사용할 수 있어요. 복사한 노드 묶음을 다른 에이전트 스튜디오 탭에 붙여넣어 여러 에이전트에서 같은 로직을 쓸 수 있어요.
- 내부 연결이 유지돼요. 연결된 노드를 여러 개 복사하면 붙여넣을 때 노드 사이의 연결이 자동으로 다시 만들어져요.
- 그래프 정리가 쉬워져요. 일괄 삭제로 필요 없는 노드를 한 번에 지울 수 있어요.
- 캔버스가 정돈돼요. 붙여넣은 노드는 원래 선택 영역 위에 겹치지 않고 조금 어긋나게 나타나요.
- 복제가 안정적이에요. 붙여넣은 노드마다 고유한 ID가 생겨서 그래프 안에서 충돌하는 일을 줄여 줘요.
- 키보드로 빠르게 편집할 수 있어요. 익숙한 단축키로 자주 쓰는 작업을 빠르게 할 수 있어요.

이런 경우에 쓰세요.

- 검증된 노드 묶음을 재사용할 때
- 테스트용으로 플로우 일부를 복제할 때
- 비슷한 분기를 처음부터 만들지 않고 다시 구성할 때
- 로직 패턴을 다른 에이전트 스튜디오 탭으로 가져올 때
- 쓰지 않거나 오래된 노드 묶음을 지울 때
- 디버깅이 끝난 테스트 분기를 정리할 때
- 반복되는 그래프 편집 작업을 빨리 끝내고 싶을 때

## 권한과 중요 참고 사항

그래프 편집 작업은 사용자 권한과 현재 에이전트 스튜디오의 편집 상태에 따라 달라져요. 복사, 붙여넣기, 삭제하기 전에 아래 내용을 확인해 두면 에이전트 플로우가 실수로 바뀌는 일을 막을 수 있어요.

**중요 참고 사항**

- 에이전트 스튜디오에 접근할 수 있고 해당 에이전트를 편집할 권한이 있어야 해요.
- 복사, 붙여넣기, 일괄 삭제는 **Graph Builder** 캔버스 안에서 작동해요.
- 복사한 노드는 새 ID로 붙여넣어져요.
- 복사한 노드끼리의 연결은 연결된 노드가 모두 선택 영역에 포함되어 있을 때 유지돼요.
- 복사한 선택 영역 밖에 있는 노드와의 연결은 직접 다시 이어야 할 수 있어요.
- 붙여넣은 노드는 원본 노드와 겹치지 않도록 위치가 어긋나게 나타날 수 있어요.
- 게시하기 전에 붙여넣은 노드를 검토하세요.
- 에이전트 전체 구조를 복제, 공유, 설치할 때는 [스냅샷](how-to-clone-and-share-agent-studio-agents-using-snapshots.md)이나 템플릿을 사용하세요.

## 지원하는 작업과 동작 방식

각 편집 작업은 **Graph Builder** 캔버스를 더 쉽게 관리하도록 만들어졌어요. 복사, 붙여넣기, 연결 유지, 일괄 삭제가 어떻게 동작하는지 알아 두면 마음 놓고 수정할 수 있어요.

### 노드 하나 이상 복사하기

**Graph Builder** 캔버스에서 노드를 하나 이상 선택하세요. 그다음 복사 기능이나 키보드 단축키로 선택한 노드를 복사해요.

![노드를 선택해 복사하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071006220/original/4ooccAlU34FPP0lPA1C3E2f_6jQExqhWEg.png?1778490885)

### 복사한 노드를 같은 그래프에 붙여넣기

복사한 노드를 현재 **Graph Builder** 캔버스나 지원되는 다른 에이전트 스튜디오 탭에 붙여넣을 수 있어요. 붙여넣은 노드는 새 ID를 가진 별도의 노드로 나타나요.

![복사한 노드를 같은 그래프에 붙여넣은 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071005962/original/F1inb8ccRyYpNSf3cIWAjgBXmHeEO2gumA.png?1778490732)

### 복사한 노드를 다른 에이전트 스튜디오 탭에 붙여넣기

복사한 노드는 열려 있는 다른 에이전트 스튜디오 탭에도 붙여넣을 수 있어요. 구조를 처음부터 다시 만들지 않고도 서로 다른 에이전트 사이에서 플로우 일부를 재사용할 수 있어요.

![복사한 노드를 다른 에이전트 스튜디오 탭에 붙여넣은 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071008797/original/IpCwxa2w_VPOjSJtF1Ic7mtwLtgODiliHQ.png?1778491782)

### 복사한 연결 유지

연결된 노드를 모두 복사 선택 영역에 포함하면 노드 사이의 연결이 유지돼요. 선택 영역 밖에 있는 노드와의 연결은 유지되지 않을 수 있으니, 붙여넣은 뒤에 확인하세요.

### 붙여넣은 노드에 새 ID 부여

붙여넣은 노드마다 새로운 고유 ID가 생겨요. 그래서 그래프가 안정적으로 유지되고 원본 노드와 충돌하지 않아요.

### 선택한 노드 여러 개 삭제

일괄 삭제를 쓰면 선택한 노드 여러 개를 한 번에 지울 수 있어요. 테스트 분기, 오래된 로직, 더 이상 필요 없는 복사 노드를 정리할 때 편해요.

![선택한 노드를 일괄 삭제하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071009103/original/e1mGvI7u44qrzAFYX_zMk9YegKNYIJWnlA.gif?1778491905)

### 키보드 단축키 사용

익숙한 키보드 단축키로 자주 쓰는 그래프 편집 작업을 빠르게 할 수 있어요. 화면에서 **키보드 단축키** 안내도 볼 수 있어요.

## 복사, 붙여넣기, 일괄 삭제 사용 순서

이 도구를 제대로 쓰면 에이전트 플로우를 만들고 고치는 시간을 많이 줄일 수 있어요. 아래 순서를 따르면 필요한 노드를 정확히 복제하고, 유용한 연결을 유지하고, 나중에 정리할 일을 줄일 수 있어요.

1. **에이전트 스튜디오**를 열고 편집할 그래프로 이동하세요.
2. 복사할 노드를 선택하세요. 더 큰 플로우 일부를 복제하려면 노드를 여러 개 선택하세요.
3. 키보드 단축키로 선택한 노드를 복사하세요.

   - Windows: `Ctrl + C`
   - Mac: `Cmd + C`
4. 복사한 내용을 원하는 곳에 붙여넣으세요.

   - 같은 그래프에 붙여넣으려면 현재 캔버스에서 붙여넣기 단축키를 사용하세요.
   - 다른 그래프에 붙여넣으려면 대상 에이전트를 다른 **에이전트 스튜디오** 탭에서 열고 그곳에서 붙여넣기 단축키를 사용하세요.
   - Windows: `Ctrl + V`
   - Mac: `Cmd + V`
5. 캔버스에서 붙여넣은 노드를 확인하세요. 원래 위치에서 조금 어긋나게 나타나므로 쉽게 찾을 수 있어요.
6. 복사한 노드와 유지된 내부 연결이 의도한 플로우와 맞는지 확인하세요.
7. 복제한 플로우를 원본과 다르게 동작시키려면 노드별 설정이나 경로를 수정하세요.
8. 필요 없는 노드를 지우려면 노드를 하나 이상 선택하고 **Graph Builder**에서 지원하는 삭제 단축키를 사용하세요.
9. 그래프가 의도대로 동작하는지 확인한 뒤 **저장 및 게시**를 눌러 변경 사항을 적용하세요.

## 단축키 정리

키보드 단축키를 알아 두면 노드 패턴이 크거나 반복될 때 그래프 편집이 훨씬 빨라져요. 기본 단축키만 익혀도 그래프를 만들고 정리하는 클릭 수를 줄일 수 있어요.

- 선택한 노드 복사
  - Windows: `Ctrl + C`
  - Mac: `Cmd + C`
- 복사한 노드 붙여넣기
  - Windows: `Ctrl + V`
  - Mac: `Cmd + V`
- 선택한 노드 일괄 삭제
  - 사용 중인 기기에서 **Graph Builder**가 지원하는 삭제 단축키를 사용하세요.

```
하이퍼클래스에는 에이전트 스튜디오에서 작업하는 동안 지원되는 단축키를 확인할 수 있는 키보드 단축키 안내도 있어요.
```

## 노드 묶음을 재사용하는 요령

구조를 잘 잡아 두면 복사와 붙여넣기가 더 빛나요. 깔끔하게 정리된 노드 묶음을 재사용하면 여러 에이전트에서 일관성을 유지하기 쉽고, 비슷한 용도의 설정 시간도 줄어요.

- 검증된 경로를 재사용하려면 노드를 하나씩 다시 만들지 말고 로직 블록 전체를 복사하세요.
- 게시하기 전에 붙여넣은 노드를 검토해서 복제한 플로우가 의도한 용도와 맞는지 확인하세요.
- 변형을 테스트할 때는 복제한 노드의 이름을 바꾸거나 조정해서 그래프를 읽기 쉽게 유지하세요.
- 오래된 분기, 테스트 노드, 필요 없는 복사본은 일괄 삭제로 지우세요.
- 에이전트 전체를 복제하거나 더 넓은 환경에 공유할 때는 노드 단위 복사·붙여넣기 대신 스냅샷을 사용하세요.

## 자주 묻는 질문

### 노드를 한 번에 여러 개 복사할 수 있나요?
네. **Graph Builder**에서는 노드 하나 또는 선택한 여러 노드를 한꺼번에 복사할 수 있어요.

### 복사한 노드 사이의 연결은 어떻게 되나요?
연결된 노드를 함께 복사하면 붙여넣을 때 그 노드들 사이의 연결이 자동으로 다시 만들어져요.

### 복사한 노드를 다른 에이전트 스튜디오 탭에 붙여넣을 수 있나요?
네. 에이전트 스튜디오 탭 사이에서도 붙여넣을 수 있어요.

### 붙여넣은 노드가 원본 노드에서 조금 벗어난 위치에 나타나는 이유가 뭔가요?
붙여넣은 노드가 원본 노드 바로 위에 겹쳐 쌓이지 않도록 위치를 어긋나게 배치해서, 노드를 쉽게 찾고 편집할 수 있어요.

### 붙여넣은 노드는 원본 노드와 같은 ID를 유지하나요?
아니요. 붙여넣은 노드마다 새로운 고유 ID가 부여돼요.

### 여러 노드를 동시에 삭제할 수 있나요?
네. 일괄 삭제를 쓰면 선택한 여러 노드를 한 번에 지울 수 있어요.

### 에이전트 전체를 복제할 때 스냅샷 대신 이 기능을 써도 되나요?
아니요. 복사와 붙여넣기는 **Graph Builder** 안에서 노드 단위로 재사용할 때 쓰기 좋고, 에이전트 전체 구조를 복제하거나 공유할 때는 스냅샷이 더 알맞아요.

### 화면에서 단축키 안내를 볼 수 있나요?
네. 하이퍼클래스에는 에이전트 스튜디오를 사용하는 동안 지원되는 단축키를 확인할 수 있는 **키보드 단축키** 안내가 있어요.
