# 관리형 에이전트의 연락처·기회 트리거 설정

관리형 에이전트(예전 이름: Super Agents)는 연락처나 기회가 만들어질 때, 또는 기회 상태가 바뀔 때 자동으로 실행할 수 있어요. 이 CRM 트리거를 쓰면 리드 선별, 영업 후속 조치, 고객 온보딩을 직접 챙기지 않아도 자동으로 처리할 수 있어요.

## 연락처·기회 트리거란?

연락처·기회 트리거는 특정 CRM 이벤트가 일어날 때 관리형 에이전트를 자동으로 실행해요. 기존 트리거인 **Chat**(채팅), **폼 제출**, **Tag Changed**(태그 변경), **Appointment**(예약), **Schedule**(일정)에 더해 쓸 수 있어요. 예약 트리거와 일정 트리거는 각각 [관리형 에이전트 예약 트리거](appointment-triggers-in-managed-agents.md)와 [관리형 에이전트 일정 트리거](scheduled-triggers-for-managed-agents-in-hyperclass.md) 문서에서 볼 수 있어요.

사용할 수 있는 트리거는 세 가지예요.

- **Contact Created**(연락처 생성): 새 CRM 연락처가 만들어지면 에이전트를 실행해요.
- **Opportunity Created**(기회 생성): 새 기회가 만들어지면 에이전트를 실행해요. 파이프라인과 기회 단계 필터를 쓸 수 있어요.
- **Opportunity Status Changed**(기회 상태 변경): 기회의 상태가 바뀌면 에이전트를 실행해요. 파이프라인, 기회 단계, 기회 상태 필터를 쓸 수 있어요.

## 연락처·기회 트리거를 쓰면 좋은 점

CRM 트리거를 쓰면 관리형 에이전트가 고객 단계별 이벤트에 자동으로 반응해요. 반복 업무가 줄고 영업 과정도 매끄러워져요.

- CRM 워크플로우 자동화: 연락처나 기회가 만들어지거나 업데이트될 때 에이전트를 실행해요.
- 빠른 리드 응대: 리드 선별, 환영 메시지 흐름, 온보딩을 바로 시작할 수 있어요.
- 원하는 대상만 자동화: 파이프라인, 기회 단계, 기회 상태 필터로 에이전트가 실행될 조건을 정해요.
- 수작업 감소: 후속 조치 같은 반복적인 CRM 작업을 자동화해요.
- 영업 프로세스 개선: 영업 인계, 이탈 고객 재공략 캠페인, 판매 후 활동을 지원해요.

## Contact Created 트리거

**Contact Created** 트리거는 CRM에 새 연락처가 만들어질 때마다 관리형 에이전트를 자동으로 실행해요. 이 트리거에만 필요한 추가 설정은 없어요.

주로 이런 때 써요.

- 환영 메시지 흐름
- 리드 정보 보강 및 선별
- 고객 온보딩

## Opportunity Created 트리거

**Opportunity Created** 트리거는 새 기회가 만들어지면 관리형 에이전트를 실행해요. 파이프라인과 기회 단계 필터로, 영업 프로세스에 맞는 기회만 골라 실행할 수 있어요.

사용할 수 있는 필터는 다음과 같아요.

- **파이프라인**: 해당하는 영업 파이프라인을 선택해요.
- **기회 단계**: 해당하는 단계를 선택해요.

주로 이런 때 써요.

- 새 기회 선별
- 영업 알림
- 파이프라인별 후속 조치

## Opportunity Status Changed 트리거

**Opportunity Status Changed** 트리거는 기회의 상태가 바뀌면 관리형 에이전트를 실행해요. 필터를 쓰면 특정 영업 결과에 맞춰 작업을 자동화할 수 있어요.

사용할 수 있는 필터는 다음과 같아요.

- **파이프라인**: 해당하는 파이프라인을 선택해요.
- **기회 단계**: 해당하는 단계를 선택해요.
- **기회 상태**: **Open**(진행 중), **고객전환성공**, **고객전환실패**, **Abandoned**(포기) 중에서 선택해요.

주로 이런 때 써요.

- 기회가 고객전환성공이 되었을 때 판매 후 온보딩
- 고객전환실패 기회에 대한 후속 조치
- 영업 인계 및 CRM 업데이트

## 연락처·기회 트리거 설정하기

알맞은 트리거를 설정해야 관리형 에이전트가 원하는 CRM 이벤트에 반응해요. 기회 필터를 쓰면 에이전트가 실행되는 시점을 더 세밀하게 정할 수 있어요.

1. 하이퍼클래스 서브 계정에서 **AI 에이전트 > 에이전트 스튜디오**로 이동하세요. 에이전트 스튜디오 사용법이 궁금하면 [에이전트 스튜디오에서 관리형 에이전트 설정하고 사용하기](setup-and-use-managed-agents-in-agent-studio.md)를 참고하세요.
2. 기존 **관리형 에이전트**를 열거나 새로 만드세요.
3. **Trigger Picker**(트리거 선택기)를 여세요.
4. **Contact Created**, **Opportunity Created**, **Opportunity Status Changed** 중 하나를 선택하세요.

   ![트리거 선택기에서 트리거를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083882748/original/VCCn1klXx4k44kylG8q3T8k5JKerDnzUuw.gif?1792593619)
5. 선택한 트리거에 맞게 설정하세요.

   - **Contact Created**: 이 트리거에만 필요한 추가 설정은 없어요.
   - **Opportunity Created**: **파이프라인**과 **기회 단계** 필터를 설정하세요.
   - **Opportunity Status Changed**: **파이프라인**, **기회 단계**, **기회 상태** 필터를 설정하세요.
6. 에이전트의 지침과 필요한 도구를 설정하세요.
7. **변경사항 저장**을 누르고, 샘플 연락처나 기회로 트리거를 테스트하세요.
8. 에이전트를 **게시**하고 **활동** 탭에서 실행 내역을 확인하세요. 활동 피드 보는 법은 [관리형 에이전트 활동 피드](managed-agent-activity-feed-monitor-debug-ai-agents.md)에서 자세히 볼 수 있어요.

{% hint style="info" %}
기회 필터 항목은 지원되는 옵션이에요. 에이전트 스튜디오에 표시되는 필수 입력 표시를 따라 주세요.
{% endhint %}

관리형 에이전트, **대화 AI**, **AI에게 문의**의 차이가 궁금하다면 [관리형 에이전트, 대화 AI, AI에게 문의: 무엇이 다른가요?](managed-agents-conversation-ai-ask-ai-what-s-the-difference.md)를 참고하세요.

## 자주 묻는 질문

### Contact Created 트리거는 추가 설정이 필요한가요?

아니요. **Contact Created** 트리거에는 이 트리거에만 필요한 추가 설정이 없어요.

### 에이전트를 실행할 기회를 걸러낼 수 있나요?

네. **Opportunity Created** 트리거는 파이프라인과 기회 단계 필터를 지원해요. **Opportunity Status Changed** 트리거는 기회 상태 필터도 지원해요.

### 어떤 기회 상태를 쓸 수 있나요?

**Open**(진행 중), **고객전환성공**, **고객전환실패**, **Abandoned**(포기)를 쓸 수 있어요.

### 이 트리거가 기존 관리형 에이전트 트리거를 대체하나요?

아니요. **Chat**, **폼 제출**, **Tag Changed**, **Appointment**, **Schedule** 같은 기존 옵션에 더해 쓸 수 있는 트리거예요.

### 에이전트가 실행됐는지 어떻게 확인하나요?

관리형 에이전트의 **활동** 탭에서 실행 내역을 확인하세요. 에이전트가 실행되지 않았다면 게시 상태와 설정한 트리거 필터를 확인하세요.
