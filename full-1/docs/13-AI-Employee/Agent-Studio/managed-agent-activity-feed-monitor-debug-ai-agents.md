# 관리형 에이전트 활동 피드로 실행 내역 확인하고 문제 해결하기

활동 피드(Activity Feed)에서는 **관리형 에이전트**의 실시간 대화와 자동 실행을 한곳에서 볼 수 있어요. 활동을 모니터링하고, 실행 상세 내용을 확인하고, 에이전트가 이상하게 동작할 때 원인을 찾는 데 쓰세요. 대화를 검토하면서 관리형 에이전트의 답변 하나하나에 **좋아요** 또는 **싫어요**를 남길 수도 있어요. 잘한 답변과 개선이 필요한 답변에 바로 피드백을 연결할 수 있어요.

이 문서에서는 활동 피드 사용법, 실행 데이터 확인, 관리형 에이전트 실행 디버깅, 개별 답변 평가 방법을 안내해요.

## 관리형 에이전트 활동 피드란?

활동 피드는 지원되는 관리형 에이전트마다 들어 있는 통합 타임라인이에요. 최근 실행과 활동을 최신순으로 보여 줘요.

실시간 채팅 대화와 자동 트리거 실행을 한 화면에 모아 보여 줘요. 자동 실행에는 폼 제출, 태그 변경, Facebook 리드 폼 제출, 설문 제출, 그 밖에 지원되는 트리거 이벤트가 포함돼요.

Facebook 리드 폼 실행은 **Facebook Lead Form Submitted**(Facebook 리드 폼 제출)로, 설문으로 시작된 실행은 **Survey Submitted**(설문 제출)로 표시돼요. 각 실행에는 상태와 시간 정보가 있어서 이벤트가 관리형 에이전트를 제대로 시작했는지 확인할 수 있어요.

활동 피드의 각 행에는 다음 정보가 표시될 수 있어요.

- 실행 유형을 나타내는 아이콘
- 실행 상태
- **타임스탬프**
- **트리거 유형**
- 에이전트를 시작한 계기를 설명하는 컨텍스트

실행을 열면 실행 로그를 볼 수 있어요. 완료된 단계, 사용한 스킬과 도구, 입력과 출력, 최종 응답이 들어 있어요.

![관리형 에이전트 활동 피드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077994388/original/zBpudjiUap0DKoXbY7__DQg-Q2tA7kmNaw.png?1786351169)

## 활동 피드를 쓰면 좋은 점

활동 피드에서는 관리형 에이전트가 무엇을 했는지, 왜 실행됐는지, 어떻게 응답했는지 볼 수 있어요.

- 전체 확인: 실시간 대화와 자동 실행을 시간순으로 한 화면에서 볼 수 있어요.
- 빠른 디버깅: 실행 단계, 스킬, 도구 호출을 살펴보면 문제를 더 빨리 찾을 수 있어요.
- 신뢰와 투명성: 자동 실행 중에 무슨 일이 있었는지 상세 실행 데이터로 확인할 수 있어요.
- 간편한 모니터링: 대화와 자동화 활동을 화면을 오가지 않고 볼 수 있어요.
- 성능 추적: 소요 시간과 토큰 사용량 지표로 느린 단계나 사용량이 많은 실행을 찾을 수 있어요.
- 피드백 기반 개선: 관리형 에이전트의 답변을 하나씩 평가하면 잘한 응답과 놓친 응답이 실제 대화 사례와 함께 남아요.

## 활동 피드 사용하기

활동 피드에서 최근 관리형 에이전트 실행을 확인하고, 실행 상세를 살펴보고, 개별 답변을 평가할 수 있어요.

### 1단계. 관리형 에이전트 열기

**서브 계정**에서 **AI 에이전트 > 에이전트 스튜디오 > 관리형 에이전트**로 이동한 다음, 확인하려는 관리형 에이전트를 선택하세요.

### 2단계. 활동 탭 열기

관리형 에이전트 페이지에서 **활동**을 선택하세요. 최근 실행이 최신순으로 표시돼요.

각 행에는 실행 상태, **타임스탬프**, **트리거 유형**, 에이전트를 시작한 계기를 설명하는 컨텍스트가 표시될 수 있어요.

![활동 탭의 실행 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082898774/original/j6df6zqkjfrYcWq9c8Z8cHaG_X4BfE9qRA.png?1791503438)

### 3단계. 실행 또는 대화 선택하기

활동 피드에서 확인하려는 실행이나 대화를 열어요.

전체 이동 경로는 다음과 같아요.

**서브 계정 > AI 에이전트 > 에이전트 스튜디오 > 관리형 에이전트** > 관리형 에이전트 선택 > **활동** > 해당 실행 또는 대화 열기

### 4단계. 실행 로그 확인하기

실행 로그에는 **Agent Conversation View**(에이전트 대화 보기)와 **실행 타임라인**이 표시돼요. 대화 내용, 완료된 단계, 도구, 소요 시간 같은 실행 상세를 보면 실행 중에 무슨 일이 있었는지 알 수 있어요.

대화를 검토하면서 관리형 에이전트의 답변마다 **좋아요** 또는 **싫어요**를 남길 수도 있어요.

![실행 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082898740/original/20u98c0JNjRl7KmSxVyDeopnfXDIzKpDqg.png?1791503323)

{% hint style="info" %}
테스트할 때 활동 피드로 관리형 에이전트의 스킬과 트리거가 의도대로 동작하는지 확인해 보세요. 문제를 찾을 때는 **실행 타임라인**을 보면 어느 단계에서 문제가 생겼는지 알 수 있어요.

## 활동 피드 데이터 이해하기

활동 피드의 각 행은 관리형 에이전트의 실행 한 건에 대한 정보를 보여 줘요. 이 정보로 실행이 어떻게 시작됐고 정상적으로 끝났는지 알 수 있어요.

### 실행 아이콘

아이콘은 활동 유형을 알려 줘요. 예를 들어 자동 트리거 실행에는 번개 아이콘이, 실시간 대화에는 채팅 아이콘이 쓰일 수 있어요.

### 실행 상태

상태에서 실행이 정상적으로 끝났는지, 실패했는지, 아직 진행 중인지 알 수 있어요.

### 타임스탬프

각 실행이 언제 시작됐는지 표시돼요. 관리형 에이전트 활동을 사용자 행동, 제출, 자동화 이벤트와 맞춰 볼 때 도움이 돼요.

### 트리거 유형

실행이 트리거로 시작됐는지 대화로 시작됐는지 알려 주는 레이블이에요.

### 컨텍스트 설명

자동 실행이라면 에이전트를 시작한 폼, 태그 이벤트, 설문, 그 밖의 이벤트가 표시될 수 있어요. 대화 실행이라면 사용자 메시지 미리보기가 표시될 수 있어요.

Facebook 리드 폼과 설문으로 시작된 실행은 활동 이벤트 이름으로도 구분할 수 있어요. 이벤트 이름, 상태, **타임스탬프**를 보면 제출이 관리형 에이전트를 시작했는지 확인할 수 있어요.

![활동 피드 행의 상세 정보](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077994838/original/U3jVirAqF6aovKrejrjEM9Fff8vVzk7Umg.png?1786351361)

## 실행 로그 보기

활동 피드에서 실행을 열면 실행 로그가 나와요. 로그에서 관리형 에이전트의 대화, 완료된 단계, 도구 사용, 소요 시간, 결과를 확인할 수 있어요.

### Agent Conversation View

**Agent Conversation View**(에이전트 대화 보기)에는 해당 실행의 대화와 관리형 에이전트의 응답이 표시돼요. 대화 맥락을 파악하고 응답을 하나씩 검토할 때 쓰세요.

### 관리형 에이전트 답변 평가하기

관리형 에이전트 대화를 검토할 때 **Agent Conversation View**에서 에이전트의 답변을 바로 평가할 수 있어요.

- **좋아요**: 답변이 유용하고 정확하며 대화에 알맞았을 때 눌러요.
- **싫어요**: 답변에 잘못된 정보가 있었거나, 중요한 맥락을 놓쳤거나, 부적절한 동작을 했거나, 그 밖에 빗나갔을 때 눌러요.

![관리형 에이전트 답변 평가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082898805/original/iDAexrckXaN4orbihnUkwvrDw1SYcCDBKA.png?1791503546)

**싫어요**를 선택하면 무엇이 잘못됐는지 적을 수 있는 짧은 후속 입력창이 열려요. 맥락을 더 알려 주면 도움이 될 때는 추가 설명을 선택 사항으로 남길 수 있어요.

피드백은 평가한 **관리형 에이전트 답변 하나**에 붙어요. 검토 중인 바로 그 응답에 피드백이 연결돼요.

평가를 제출한 뒤에는 다음과 같아요.

- 선택한 평가가 대화로 돌아와도 그대로 표시돼요.
- 이미 평가한 답변이 다시 미평가 상태로 나타나지 않아요.
- 이전 평가를 다시 열어 제출한 피드백을 확인할 수 있어요.

좋은 평가는 잘 동작하는 답변을 보여 주고, 나쁜 평가는 놓친 부분의 구체적인 사례가 돼요. 팀에서는 이 사례를 프롬프트, 지침, 지식 범위, 에이전트의 전반적인 동작을 점검할 때 쓸 수 있어요.

### 실행 타임라인

**실행 타임라인**에는 관리형 에이전트가 실행 중에 완료한 단계가 순서대로 표시돼요. 가능한 경우 소요 시간과 토큰 사용량도 함께 보여 줘요.

타임라인에서 어떤 스킬이나 도구를 썼는지 확인하고, 실행이 기대와 다르게 동작한 지점을 찾아보세요.

### 실행 제어와 메타데이터

실행 로그 맨 위에는 대화 제목과 함께 새로고침, 소요 시간 지표, 토큰 사용량, **ID 복사**, **에이전트 로그에서 보기** 같은 기능이 표시될 수 있어요.

## 자주 묻는 질문

### 관리형 에이전트 활동 피드는 어디에서 볼 수 있나요?
**서브 계정 > AI 에이전트 > 에이전트 스튜디오 > 관리형 에이전트**로 이동해 관리형 에이전트를 선택한 다음 **활동** 탭을 여세요.

### 활동 피드에는 어떤 실행이 표시되나요?
실시간 대화와 자동 트리거 실행이 표시돼요. 지원되는 폼 제출, 태그 이벤트, Facebook 리드 폼 제출, 설문 제출, 그 밖의 관리형 에이전트 트리거 이벤트가 포함돼요.

### 실패한 관리형 에이전트 실행은 어떻게 디버깅하나요?
활동 피드에서 실패한 실행을 열고 **Agent Conversation View**와 **실행 타임라인**을 확인해 어느 단계에서 문제가 생겼는지 찾아보세요.

### 여러 관리형 에이전트의 활동을 한 활동 피드에서 볼 수 있나요?
활동 피드는 관리형 에이전트마다 따로 있어요. 각 에이전트의 **활동** 탭을 열어 실행 내역을 확인하세요.

### 소요 시간과 토큰 지표는 무엇을 보여 주나요?
소요 시간 지표는 한 단계나 한 번의 실행이 처리되는 데 걸린 시간을 보여 줘요. 토큰 사용량 지표는 지원되는 실행 단계 또는 전체 실행에서 사용한 토큰 수를 보여 줘요.
