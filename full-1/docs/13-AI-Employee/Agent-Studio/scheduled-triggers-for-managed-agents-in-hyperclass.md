# 관리형 에이전트의 예약 트리거 설정하기

예약 트리거(Scheduled Triggers)를 쓰면 관리형 에이전트(이전 이름: 슈퍼 에이전트)가 정해진 시간이나 반복 일정에 맞춰 자동으로 실행돼요. 한 번만 실행하거나, 일정한 간격으로 반복하거나, Cron 표현식으로 더 세밀하게 시간을 정할 수 있어요. 관리형 에이전트를 게시하면 직접 시작하지 않아도 하이퍼클래스가 지침, 스킬, CRM 작업을 포함한 에이전트 전체를 실행해요.

## 관리형 에이전트의 예약 트리거란?

예약 트리거는 관리형 에이전트가 시간을 기준으로 시작되게 해 줘요. 사용자가 에이전트를 직접 실행하기를 기다리지 않고, 설정한 일정에 따라 하이퍼클래스가 에이전트를 시작해요. 정기적인 운영 업무, 점검, 알림, 요약처럼 정해진 시간에 해야 하는 작업에 쓰기 좋아요.

예약 트리거로 관리형 에이전트를 이렇게 시작할 수 있어요.

- 특정 날짜와 시간에 한 번
- 정해진 간격으로 반복
- 직접 작성한 Cron 표현식에 따라
- 빌더에게 일상적인 말로 설명한 일정에 따라

예약 실행은 매번 관리형 에이전트 전체를 실행해요. 지침, 설정한 스킬, CRM 작업이 모두 포함돼요.

## 예약 트리거의 장점

예약 트리거를 쓰면 반복 업무를 자동화하면서도 관리형 에이전트가 언제 실행되고 무엇을 하는지 확인할 수 있어요.

- 자동 실행: 누군가 직접 시작하지 않아도 관리형 에이전트가 알아서 실행돼요.
- 유연한 일정: 한 번 실행, 반복 간격, 고급 Cron 표현식 중에서 고를 수 있어요.
- 반복 일정 제어: 반복 실행을 특정 요일로 제한하고, 일정이 끝나는 시점도 정할 수 있어요.
- 여러 개의 일정: 실행 주기가 서로 다르면 같은 관리형 에이전트에 일정을 여러 개 추가할 수 있어요.
- 에이전트 전체 실행: 예약 실행마다 에이전트의 지침, 스킬, CRM 작업이 모두 실행돼요.
- 현지 시간대 지원: 서브 계정의 현지 시간대에 맞춰 일정이 실행돼요.
- 실행 내역 확인: 에이전트의 **Activity**(활동) 피드에서 예약된 실행 내역을 볼 수 있어요.
- 자연어 설정: 모든 항목을 직접 설정하는 대신 빌더에게 일정을 말로 설명할 수 있어요.

## 일정 모드

일정 모드마다 맞는 상황이 달라요. 알맞은 모드를 고르면 관리형 에이전트가 원하는 시간과 주기에 실행돼요.

### 한 번

관리형 에이전트를 특정 날짜와 시간에 딱 한 번 실행하려면 **한 번**을 선택하세요.

이런 경우에 쓸 수 있어요.

- 월말 점검 실행
- 일회성 알림 발송
- 예정된 미팅 전에 리포트 준비
- 예약된 CRM 업데이트 수행

한 번 실행 일정은 설정한 실행이 끝나면 반복되지 않아요.

### 반복 간격

관리형 에이전트를 일정한 주기로 반복 실행하려면 **반복 간격**을 선택하세요.

간격 단위는 다음 중에서 고를 수 있어요.

- 분
- 시간
- 일
- 주
- 개월

반복 일정에는 다음 항목도 설정할 수 있어요.

- 특정 요일
- 종료일 없음
- 종료일
- 최대 실행 횟수

예를 들어 관리형 에이전트가 월말까지 매주 화·수·목요일 오전 9시에 실행되게 할 수 있어요.

### Cron 표현식

일반적인 간격으로는 맞출 수 없는 세밀한 일정이 필요하면 **Cron 표현식**을 선택하세요. Cron 방식의 일정에 이미 익숙한 사용자에게 가장 잘 맞아요.

{% hint style="info" %}
관리형 에이전트를 게시하기 전에 표현식이 원하는 일정과 맞는지 꼼꼼히 확인하세요.
{% endhint %}

## 반복 일정의 종료 조건

종료 조건은 반복 일정이 얼마나 오래 유지될지 정해요. 알맞은 종료 조건을 고르면 필요한 기간이 지난 뒤에도 관리형 에이전트가 계속 실행되는 일을 막을 수 있어요.

반복 일정은 이렇게 끝나도록 설정할 수 있어요.

- **없음**: 일정을 바꾸거나 삭제할 때까지 계속돼요.
- **On a Specific Date**(특정 날짜): 선택한 날짜가 지나면 일정이 멈춰요.
- **After a Set Number of Runs**(정해진 횟수 이후): 지정한 횟수만큼 실행한 뒤 일정이 멈춰요.

월간 캠페인처럼 기간이 정해진 활동에는 날짜 기준 종료 조건이 알맞아요. 예약 실행을 몇 번 할지 정해져 있다면 실행 횟수 기준 종료 조건을 쓰세요.

## 한 관리형 에이전트에 여러 일정 추가하기

일정을 여러 개 추가하면 관리형 에이전트 하나로 여러 실행 주기를 처리할 수 있어요. 지침, 스킬, CRM 작업이 같다면 에이전트를 복제해서 만들 필요가 줄어요.

예를 들어 관리형 에이전트 하나를 이렇게 설정할 수 있어요.

- 매일 계정 점검 수행
- 매주 요약 생성
- 월말에 추가로 한 번 점검 실행

일정은 관리형 에이전트의 **트리거** 영역에서 하나씩 따로 설정해요.

## 자연어로 일정 설정하기

자연어 설정을 쓰면 일상적인 말로 요청해서 빌더가 예약 트리거를 설정하게 할 수 있어요. 복잡한 반복 일정도 더 빠르게 만들고 쉽게 이해할 수 있어요.

{% hint style="info" %}
예를 들어 빌더에게 이렇게 말할 수 있어요.

"매주 화요일, 수요일, 목요일 오전 9시에 실행해 줘. 이번 달 말까지만."
{% endhint %}

빌더가 요청한 주기를 해석해서 트리거를 설정해 줘요. 관리형 에이전트를 게시하기 전에 날짜, 시간, 요일, 종료 조건이 의도와 맞는지 확인하세요.

## 예약 트리거의 시간대

예약 트리거는 서브 계정의 현지 시간대를 기준으로 해요. 게시하기 전에 시간대를 확인하면 관리형 에이전트가 예상보다 일찍 또는 늦게 실행되는 일을 막을 수 있어요.

선택한 날짜와 시간은 서브 계정에 설정된 시간대로 해석돼요. 특히 이런 경우에 중요해요.

- 팀원들이 서로 다른 지역에서 일할 때
- 관리형 에이전트가 여러 시간대에 있는 연락처를 담당할 때
- 일정을 영업시간에 맞춰야 할 때
- 리포트나 캠페인 마감 시각이 정확해야 할 때

새 일정을 켜기 전에 서브 계정의 시간대를 확인하세요.

## 예약 실행과 활동 내역 확인

**Activity** 피드에서 관리형 에이전트의 예약 실행 내역을 볼 수 있어요. 에이전트가 실제로 실행됐는지 확인하거나, 예상한 작업이 일어나지 않은 이유를 찾을 때 도움이 돼요.

예약 실행은 관리형 에이전트가 실행된 뒤마다 기록돼요. 이 기록으로 반복 작업을 점검하고 예약된 활동이 제대로 이뤄지고 있는지 확인하세요.

에이전트 실행 내역을 더 자세히 보려면 에이전트 로그(Agent Logs) 문서를 참고하세요.

## 예약 트리거와 워크플로우 스케줄러 비교

예약 트리거와 워크플로우 스케줄러는 둘 다 시간을 기준으로 자동화를 실행하지만, 시작하는 대상이 달라요.

- 예약 트리거는 관리형 에이전트를 시작해서 지침, 스킬, CRM 작업을 실행해요.
- 워크플로우 스케줄러는 하이퍼클래스 워크플로우를 시작해요.

관리형 에이전트가 작업을 처리하게 하려면 예약 트리거를 쓰세요. 워크플로우 액션과 워크플로우 로직으로 처리하고 싶다면 워크플로우 스케줄러를 쓰세요.

자세한 내용은 **워크플로우 트리거** 문서의 "Workflow Trigger - Scheduler"를 참고하세요.

## 관리형 에이전트에 예약 트리거 설정하기

일정을 제대로 만들려면 트리거 모드, 시간, 반복 설정, 게시 상태를 모두 맞춰야 해요. 게시하기 전에 각 설정을 확인하면 관리형 에이전트가 원하는 때에 실행돼요.

1. 해당 서브 계정에서 **에이전트 스튜디오**를 열고, 일정을 설정할 관리형 에이전트를 여세요.

2. **에이전트 편집**을 클릭한 뒤 **Add trigger**(트리거 추가)를 클릭하세요.

   ![에이전트 편집에서 트리거 추가하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076392981/original/U7jGOj5AOFWX9enXqYtwjK7Nx9XE2zcu_w.gif?1784551642)
3. **일정**을 선택하세요.

   ![일정 트리거 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076403761/original/f6szdYmolXoEozZpDRA8iifRdEOV_S0a4g.png?1784556707)
4. 일정 모드를 선택하세요.

   - **한 번**
   - **반복 간격**
   - **Cron 표현식**

   ![일정 모드 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076403818/original/4THdwQ2ymAhU2CA3wW-S3NRIDS5NZ6eRCw.png?1784556738)
5. 필요한 시간 설정을 입력하세요.

   한 번 실행 일정이라면 이렇게 설정해요.

   - 날짜를 선택하세요.
   - 시간을 선택하세요.

   ![한 번 실행 일정의 날짜와 시간 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076404802/original/TxOSkB5BiZH11INepPHWL_OENfB52WgHxA.png?1784557262)
6. 반복 간격 일정이라면 이렇게 설정해요.

   - 간격을 입력하세요.
   - 분, 시간, 일, 주, 개월 중에서 단위를 선택하세요.
   - 필요하면 실행할 요일을 선택하세요.
   - 종료 조건을 선택하세요.

   ![반복 간격 일정 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076404878/original/aZ5C0gv8adZLHMp0UIoeRYv2XPvktF9QLQ.png?1784557302)
7. Cron 일정이라면 이렇게 설정해요.

   - 원하는 일정에 맞는 Cron 표현식을 입력하세요.

   ![Cron 표현식 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076404932/original/uOeAGhvJqXR_vaxZiwEKTqWG4xim8doCRQ.png?1784557351)
8. 서브 계정의 현지 시간대를 기준으로 일정을 확인하세요.
9. 관리형 에이전트에 실행 주기가 하나 더 필요하면 일정을 추가하세요.
10. 관리형 에이전트를 **게시**하세요.

관리형 에이전트를 게시하면 일정이 활성화돼요. 활성화한 뒤에는 직접 시작하지 않아도 돼요.

## 자주 묻는 질문

### 예약 트리거를 쓰면 관리형 에이전트 전체가 실행되나요?
네. 예약 실행마다 관리형 에이전트의 지침, 스킬, CRM 작업이 모두 실행돼요. 실제 실행 중에 에이전트 전체가 실행되는 것과 같아요.

### 관리형 에이전트를 꼭 게시해야 하나요?
네. 관리형 에이전트를 게시해야 설정한 일정이 활성화돼요.

### 일정은 어느 시간대를 기준으로 하나요?
예약 트리거는 서브 계정의 현지 시간대를 기준으로 해요.

### 관리형 에이전트 하나에 일정을 여러 개 넣을 수 있나요?
네. 서로 다른 주기로 실행해야 하면 관리형 에이전트 하나에 일정을 여러 개 추가할 수 있어요.

### 반복 일정을 특정 요일에만 실행할 수 있나요?
네. 반복 일정은 특정 요일로 제한할 수 있어요.

### 반복 일정을 자동으로 멈추게 할 수 있나요?
네. 반복 일정은 계속 이어지게 하거나, 특정 날짜에 끝나게 하거나, 정해진 횟수만큼 실행한 뒤 멈추게 설정할 수 있어요.
