# 에이전트 스튜디오에서 AI 대화 테스트하고 디버깅하기

**에이전트 스튜디오**의 실행 타임라인과 채팅 에뮬레이터로 AI 대화의 모든 단계를 확인할 수 있어요. 문제를 빠르게 찾고, 느려지는 구간을 파악한 뒤, 안심하고 에이전트를 배포해 보세요.

[동영상](https://www.youtube.com/embed/R46SSEd_29M?&wmode=opaque)

## 실행 타임라인과 채팅 에뮬레이터란?

**실행 타임라인**(Message Execution Timeline)과 **Chat Emulator**(채팅 에뮬레이터)는 에이전트 스튜디오에 들어 있는 테스트·디버깅 도구예요.

- 실행 타임라인은 에이전트가 처리한 모든 이벤트, 도구 호출, 판단을 모델 지표와 함께 기록해요.
- 채팅 에뮬레이터에서는 대화를 직접 시뮬레이션하고, 세션을 초기화하고, 응답을 만든 노드로 바로 이동할 수 있어요.

두 도구를 함께 쓰면 에이전트가 어떻게 움직이는지 한눈에 볼 수 있어요. 문제를 찾고, 로직이 맞는지 확인하고, 성능을 개선하는 데 도움이 돼요.

AI 워크플로우는 안에서 무슨 일이 일어나는지 알기 어려운 '블랙박스'처럼 느껴지기 쉬워요. 이 도구들은 실행의 각 단계를 그대로 보여 줘서, 로직을 따라가고 입력과 출력을 살펴본 뒤 실제 데이터를 바탕으로 필요한 부분만 고칠 수 있게 해 줘요.

## AI 대화를 테스트하고 디버깅하면 좋은 점

에이전트 스튜디오에서 AI 대화를 테스트하고 디버깅하면 에이전트가 어떻게 판단하고, 응답하고, 동작하는지 전부 확인할 수 있어요. 실시간 실행 로그와 실제 환경과 비슷한 테스트 환경을 함께 쓰면, 라이브로 전환하기 전에 로직을 검증하고 병목 구간을 찾아 성능을 다듬을 수 있어요.

- 실행 과정을 투명하게 확인해요: 노드 전환과 도구 호출을 실제 발생한 순서대로 따라갈 수 있어서 추측할 필요가 없어요.
- 단계별 성능을 파악해요: 느린 프롬프트, API 호출, 도구 단계를 바로 찾아 더 빠르게 최적화할 수 있어요.
- 모델과 비용을 확인해요: 모델 정보, 토큰 사용량, temperature 같은 실행 설정을 각 메시지 옆에서 바로 볼 수 있어요.
- 문제를 바로 해결해요: 로그 항목에서 캔버스의 해당 노드로 곧장 이동해 필요한 부분만 빠르게 고칠 수 있어요.
- 실제와 비슷한 환경에서 테스트해요: 최종 사용자가 보는 화면과 같은 채팅 화면에서 대화를 검증하므로 QA가 정확해져요.

## 실행 타임라인

실행 타임라인은 채팅 에뮬레이터 옆에 나타나고, 에이전트가 실행되는 동안 실시간으로 업데이트돼요.

- 이벤트 카드에 노드 이름, 모델, 입력/출력 토큰, 실행 시간이 표시돼요.
- 색깔이 있는 지연 시간 배지로 병목 구간을 알려 줘요. 빨간색은 느림, 초록색은 빠름이에요.
- 마우스를 올리면 원본 JSON 입력/출력을 자세히 볼 수 있어요.

```
Todo Manager(할 일 관리자)로 작업 추적하기:

에이전트 스튜디오는 이제 Todo Manager로 여러 단계에 걸친 에이전트 작업을 추적해요. 작업에는 설명이 담긴 레이블과 동적으로 바뀌는 상태가 표시되므로, 테스트를 실행하는 동안 진행 상황을 더 정확하게 따라갈 수 있어요.

- 작업 전환은 숫자 인덱스 대신 레이블을 기준으로 해요.
- 상태 업데이트를 보면 어떤 작업이 진행 중이고 어떤 작업이 끝났는지 알 수 있어요.
- 덕분에 여러 단계로 된 계획을 타임라인에서 검토하기 쉽고, 단계 순서가 바뀌거나 새 작업이 추가돼도 헷갈리지 않아요.

노드 전환과 함께, 여러 단계로 된 작업의 진행 상황도 레이블이 붙은 작업으로 추적해요. 에이전트가 긴 순서를 진행하는 중에 지금 어떤 작업을 하고 있는지 확인할 수 있어요.
```

## 전환 노드 버튼

**실행 타임라인**에서는 각 단계에 보라색 라벨이 표시돼요. 이 라벨은 클릭할 수 있는 전환 라벨(Transition label)로, 실행 중에 대화가 이동한 노드를 정확히 알려 줘요.

라벨을 클릭하면 캔버스에서 해당 노드가 자동으로 선택되고 강조돼요. 플로우를 일일이 뒤질 필요 없이 바로 로직을 확인하거나 수정할 수 있어요.

실행 로그가 시각적인 빌더와 바로 연결되므로 디버깅이 빨라져요.

## 성능 지표 패널

각 메시지 아래의 지표 영역에는 다음 정보가 표시돼요.

- 모델과 버전(예: gpt-4-turbo)
- 입력/출력 토큰 수
- temperature, max tokens, top-p, frequency/presence penalty
- 총 예상 비용(결제가 활성화된 경우)

이 정보로 테스트 중에 성능과 효율을 함께 평가할 수 있어요.

## 채팅 에뮬레이터

채팅 에뮬레이터는 AI 대화를 안전하게 테스트하는 시뮬레이션 채팅 화면이에요. 실제 배포 환경과 비슷하게 구성된 간결한 테스트 환경이에요.

- 아바타를 지원하는 깔끔한 모바일 대응 채팅 창
- 실행 사이에 맥락을 지우는 **Reset**(초기화) 버튼
- 타임라인과 나란히 놓여 한 번에 비교할 수 있는 레이아웃

## 에이전트 스튜디오에서 AI 대화 테스트하고 디버깅하는 방법

에이전트를 게시하기 전에 실행 타임라인과 채팅 에뮬레이터를 함께 사용해 실행 단계를 살피고, 문제를 찾고, 성능을 개선하는 방법을 안내해요.

### 테스트 환경 열기

1. **AI 에이전트 > 에이전트 스튜디오**로 이동해 테스트할 에이전트를 열어요.
2. 오른쪽 위의 **테스트** 탭을 클릭해요. 채팅 에뮬레이터와 실행 화면이 열려요.

**테스트** 패널이 열리면 에이전트 스튜디오가 에이전트에 비어 있는 필수 항목이 있는지 확인해요.

```
필수 항목이 비어 있으면 화면 맨 위에 주황색 경고가 나타나고, 채워야 하는 노드와 항목이 정확히 표시돼요. 이 경고가 있어도 테스트는 할 수 있어요. 다만 비어 있는 항목을 채워 두면 실행 중에 헷갈리는 오류가 생기는 것을 막을 수 있어요.
```

![테스트 패널을 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074782477/original/yYKd-a9MbCgRK4NqMHbsZ-AezlgcL3RIfQ.png?1782768609)

### 테스트 세션 시작하기

1. **Start**(시작)를 클릭해 채팅 에뮬레이터를 실행해요. 채팅 창 옆에 실행 타임라인이 자동으로 나타나요.
2. 에뮬레이터에서 테스트 메시지를 보내거나 API로 에이전트를 실행해요.

에이전트가 요청을 처리하는 동안 노드 전환, 도구 호출, 모델 실행 단계가 타임라인 패널에 실시간으로 기록돼요.

![테스트 세션을 시작한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074782489/original/L_5601X-jbju2IgEegXUQ_baqwICylST7g.png?1782768656)

### 실행 로그 확인하기

타임라인의 이벤트 카드를 보면서 에이전트가 대화를 어떻게 처리했는지 살펴보세요. 노드 이름, 도구 활동, 토큰 사용량, 실행 시간, 느린 단계를 알려 주는 지연 시간 배지를 확인해 보세요.

![이벤트 카드가 표시된 실행 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074782508/original/cYU7k2d1qIT-MA1ZUDZvUQo1oZLpjg6Yhw.png?1782768718)

### 성능 지표 살펴보기

각 로그 항목을 클릭하면 모델 버전, 입력/출력 토큰, temperature, 예상 비용(활성화된 경우) 같은 자세한 지표를 볼 수 있어요. 이 정보를 바탕으로 효율을 평가하고 프롬프트나 도구 설정을 다듬어 보세요.

![로그 항목의 상세 지표 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074782517/original/Qkqm_Cyge11usX3Cly-9P66aAnASFBE22w.png?1782768747)

### 원인 노드로 이동하기

로그 카드를 클릭하면 빌더에서 해당 노드가 자동으로 강조돼요. 캔버스를 직접 찾지 않고도 로직, 프롬프트, 변수를 빠르게 수정할 수 있어요.

![로그 카드를 눌러 해당 노드가 강조된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074782546/original/6M00qv_SOUXxe3XoNpo-YSVZ6ZcaGF_esA.png?1782768775)

### 초기화하고 다시 테스트하기

채팅 에뮬레이터의 **Reset** 버튼을 누르면 대화와 실행 로그가 지워져요. 대화를 다시 실행해서 수정한 내용으로 문제가 해결됐는지 확인하세요.

![Reset 버튼으로 대화를 초기화하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074782574/original/qlx5CNgSjFQqPkrEnmX451I8RIYtkY-72w.png?1782768803)

### 안심하고 게시하기

테스트에서 대화가 기대대로 동작하고 성능도 충분히 최적화된 것을 확인했다면, 평소처럼 에이전트를 **Staging**(스테이징) 또는 **Production**(프로덕션)으로 옮기세요.

에이전트 스튜디오의 기본 사용법은 [에이전트 스튜디오 사용 방법](../agent-studio-overview.md)을 참고하세요.

## 자주 묻는 질문

### 음성 AI 에이전트에서도 타임라인을 쓸 수 있나요?

네. 음성 AI 에이전트에서 **테스트** 탭을 열면, 테스트 통화가 끝난 뒤에 같은 로그 화면이 나타나요.

### 타임라인을 쓰면 토큰 사용량이나 비용이 늘어나나요?

아니요. 타임라인은 모델과 도구 노드가 이미 반환한 메타데이터를 기록할 뿐이에요.

### 타임라인 로그를 내보낼 수 있나요?

타임라인 오른쪽 위의 다운로드 아이콘을 클릭하면 전체 실행 내용이 담긴 JSON 파일로 저장할 수 있어요.

### **Go to Node**(노드로 이동) 버튼이 안 보여요

이 버튼은 에이전트를 한 번 이상 저장한 뒤에 나타나요. 저장하지 않은 초안(Draft)을 보고 있는 것은 아닌지 확인해 보세요.

### 채팅 에뮬레이터를 초기화하면 타임라인도 지워지나요?

네. **Reset**을 누르면 채팅 맥락과 그에 해당하는 실행 로그가 모두 지워져서 새 세션으로 시작해요.

### 이 기능은 특정 요금제에서만 쓸 수 있나요?

실행 타임라인과 채팅 에뮬레이터는 Unlimited AI Employee 요금제에 포함돼 있어요. 에이전트 스튜디오를 쓰는 데 필요한 요금제와 같아요.

### **테스트**를 클릭했더니 "Missing Required Fields"(필수 항목 누락) 경고가 떠요

에이전트 스튜디오가 필수 항목이 비어 있는 노드를 하나 이상 찾았다는 뜻이에요. 목록에 표시된 노드를 열어 필수 항목을 채우고 저장하면 경고 아이콘이 사라져요. 테스트 중에 설정 오류가 생기는 것도 막을 수 있어요.
