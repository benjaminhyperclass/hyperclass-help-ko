# 대화 AI에서 Claude와 Gemini 모델 사용하기

하이퍼클래스 대화 AI에서는 기존 OpenAI 모델 외에 Anthropic Claude와 Google Gemini 모델도 쓸 수 있어요. 에이전트마다 기본 모델을 고르고, 필요하면 보조 모델을 예비용으로 설정할 수 있어요. 모델을 바꿔도 기존 프롬프트, 액션, 지식 베이스, 에이전트 설정은 그대로 유지돼요. 이 문서에서는 새 제공업체를 켜는 방법, 모델을 고르는 방법, 에이전트를 테스트하는 방법을 안내해요.

## Claude·Gemini 모델 지원이란?

**대화 AI** 에이전트 편집 화면에서 Anthropic, Google, OpenAI의 모델 중 원하는 모델을 바로 고를 수 있는 기능이에요. 에이전트마다 다른 모델을 쓸 수 있어요. 보조 모델을 설정해 두면 기본 모델을 쓸 수 없을 때 보조 모델이 자동으로 대신해요.

## Claude·Gemini 모델 지원의 장점

기존 에이전트를 다시 만들지 않고도 다양한 AI 모델 중에서 고를 수 있어요.

- 더 많은 모델 선택: Claude, Gemini, 지원되는 OpenAI 모델 중에서 고를 수 있어요.
- 에이전트별 설정: 에이전트의 용도, 속도, 상대적인 비용에 맞춰 모델을 고를 수 있어요.
- 자동 대체: 기본 모델을 쓸 수 없을 때 보조 모델이 대신하도록 설정할 수 있어요.
- 기존 설정 유지: 지금 쓰는 프롬프트, 액션, 지식 베이스, 채널을 그대로 쓸 수 있어요.
- 비용 확인: 모델 드롭다운에서 모델별 상대 비용($~$$$$)을 바로 비교할 수 있어요.

## 사전 준비와 제한 사항

추가 모델이 **대화 AI**에 나타나려면 먼저 **실험실**에서 Claude와 Gemini 지원을 켜야 해요. 설정을 저장하기 전에 에이전트를 쓸 수 있는 상태인지 확인하고, 선택한 모델의 비용도 살펴보세요.

- **설정 > 실험실**에서 **대화 AI Provider Support**(대화 AI 제공업체 지원)를 켜세요.
- **대화 AI** 에이전트를 새로 만들거나 기존 에이전트를 선택하세요.
- 보조 모델은 선택 사항이고, 기본 모델과 다른 모델이어야 해요.
- 모델마다 비용이 달라요. 화면에 표시되는 비용 표시와 [AI 상품 요금 안내](ai-product-pricing-update.md) 문서를 참고하세요.

## Claude·Gemini 모델 설정하기

추가 AI 제공업체를 켜고, 에이전트에 쓸 모델을 고른 뒤, 필요하면 보조 모델을 설정해요. 실제 대화에 에이전트를 쓰기 전에 바뀐 응답을 꼭 테스트해 보세요.

### 1단계: Claude와 Gemini 지원 켜기

실험실에서 기능을 켜면 새 제공업체를 쓸 수 있어요.

1. **서브 계정** 화면의 왼쪽 메뉴에서 **설정**을 클릭하세요.
2. **실험실**을 선택하세요.
3. **대화 AI Provider Support**를 찾으세요.
4. 기능을 켜세요.

![실험실에서 대화 AI 제공업체 지원을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084691186/original/0SNFThHCbBhEUlQsxO4W_3wHODPGCq7i-w.png?1793576613)

### 2단계: 기본 모델 선택하기

에이전트가 응답을 만들 때 쓸 AI 모델을 골라요.

1. **서브 계정** 화면에서 **AI 에이전트 > 대화 AI > 에이전트 목록**으로 이동하세요.
2. 설정할 에이전트를 선택하세요.
3. **빌드** 탭을 여세요.
4. **모델** 드롭다운을 클릭하세요.
5. 원하는 Claude, Gemini, OpenAI 모델을 선택하세요.

![빌드 탭에서 모델 드롭다운으로 기본 모델을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084691249/original/X8wg5aaGCkFFtbGOe1S1ZmaoAa6Pqc79rA.png?1793577000)

### 3단계: 보조 모델 설정하기 (선택 사항)

보조 모델은 기본 모델을 쓸 수 없을 때 자동으로 대신해요. 기본 모델과 같은 제공업체의 모델이어도 되고, 다른 제공업체의 모델이어도 돼요.

1. **모델** 드롭다운 옆의 **설정**(톱니바퀴) 아이콘을 클릭하세요.
2. 선택한 **기본 모델**을 확인하세요.
3. **보조 모델** 드롭다운을 여세요.
4. 선택할 수 있는 모델 중에서 기본 모델과 다른 모델을 고르세요.

![설정 아이콘을 눌러 보조 모델을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084691265/original/oblxwnHFW7zJ426q9aAeww3ZW6L1_4qnCg.png?1793577068)

### 4단계: 에이전트 테스트하고 저장하기

변경 사항을 저장하기 전에 선택한 모델로 에이전트가 제대로 응답하는지 테스트해요.

1. **에이전트 테스트하기** 패널에 고객이 할 만한 질문을 입력하거나, 추천 메시지를 선택하세요.
2. 에이전트의 응답을 살펴보고, 설정한 액션이 의도대로 동작하는지 확인하세요.
3. 필요하면 예약 요청이나 비즈니스 관련 질문 같은 다른 상황도 테스트하세요.
4. **저장**을 클릭해 설정을 적용하세요.

![에이전트 테스트하기 패널에서 응답을 확인하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084691329/original/gaHgFtdGZd-_MiocTLEjwIrjxwHYh81DcA.png?1793577454)

## 지원되는 Claude·Gemini 모델

**대화 AI**에는 두 제공업체의 모델 7개가 추가돼요. 기존에 지원하던 OpenAI 모델도 같은 모델 드롭다운에서 그대로 쓸 수 있어요. 모델 제공 현황과 요금은 바뀔 수 있으니, 에이전트의 **모델** 메뉴에서 선택 가능한 목록을 확인하세요.

### Anthropic Claude

- Claude Opus 5.5
- Claude Sonnet 5.5
- Claude Haiku 5.5
- Claude Haiku 4.5

### Google Gemini

- Gemini 3.8 Flash
- Gemini 3.7 Flash
- Gemini 3.5 Flash Lite

## 자주 묻는 질문

### 대화 AI 에이전트마다 다른 AI 제공업체를 쓸 수 있나요?

네. 에이전트마다 모델 설정이 따로 있어서, 같은 서브 계정 안에서도 에이전트별로 다른 제공업체를 쓸 수 있어요.

### AI로 빌드하기로 기본 모델을 바꿀 수 있나요?

네. **AI로 빌드하기**에 "모델을 Claude로 바꿔 줘"처럼 일상 말투로 요청하면 모델을 바꿀 수 있어요.

### 테스트하면 실제 연락처에게 메시지가 가나요?

아니요. **에이전트 테스트하기** 패널은 실제 연락처에게 메시지를 보내지 않고 대화를 시뮬레이션해요.

### 모델을 저장하면 에이전트가 자동으로 켜지나요?

아니요. 저장하면 모델 설정만 유지돼요. 에이전트 활성화와 채널 설정은 **배포** 탭에서 따로 관리해요.
