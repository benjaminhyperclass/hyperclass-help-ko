# 음성 대 음성(S2S) 음성 AI 에이전트 설정

음성 대 음성(Speech-to-Speech, S2S) 음성 AI는 음성을 글자로 바꿨다가 다시 음성으로 만들지 않고, 오디오를 바로 처리해서 더 빠르고 자연스럽게 대화해요. 이 문서에서는 S2S 모델을 고르고, 에이전트를 설정하고, 작업을 연결하고, 대화를 테스트하는 방법을 안내해요.

하이퍼클래스는 실시간 S2S 모델을 지원해요. 음성 품질, 추론, 도구 처리가 좋아진 Gemini 3.8 Live도 그중 하나예요.

## 음성 대 음성(S2S) 음성 AI란?

S2S 음성 AI를 쓰면 AI 에이전트가 오디오로 직접 듣고 답해요. 처리 단계가 줄어서 응답이 빨라지고, 발신자의 말투와 감정, 대화 맥락도 더 잘 살려요.

기존 음성 에이전트는 여러 단계를 거쳐요.

음성 → 음성 인식(Speech-to-Text) → 언어 모델 → 음성 합성(Text-to-Speech) → 오디오 응답

S2S 에이전트는 더 직접적인 방식으로 작동해요.

음성 → 실시간 음성 모델 → 오디오 응답

모델 하나로 처리하기 때문에 지연이 줄어요. 또한 더 자연스러운 응답과 끼어들기, 언어 전환(지원되는 경우)도 가능해요.

## S2S 음성 AI의 주요 장점

S2S를 쓰면 에이전트가 일반적인 고객 요청을 더 자연스럽게 처리해요. 통화 흐름이 좋아지고, 발신자도 더 매끄럽게 대화할 수 있어요.

- 빠른 응답: 처리 단계와 대화 지연을 줄여 더 매끄럽게 대화해요.
- 자연스러운 대화: 말투, 강세, 감정 같은 음성 단서를 살려 사람처럼 답해요.
- 다국어 지원: 지원되는 언어로 대화하고, 대화 중 언어가 바뀌어도 대응해요.
- 자동 작업: 예약 잡기, 통화 전환, SMS 보내기, 워크플로우 실행, 연락처 정보 업데이트를 할 수 있어요.
- 유연한 배포: 전화번호, 사용 가능한 아웃바운드 통화, 지원되는 [음성 AI 채팅 위젯](../../06-사이트/채팅-위젯/how-to-set-up-and-use-the-voice-ai-chat-widget.md)에 에이전트를 연결할 수 있어요.
- 간편한 요금: 지원되는 처리 비용과 인프라 비용이 포함된 모델별 분당 요금을 적용해요.

## 사용할 수 있는 S2S 모델

어떤 S2S 모델을 고르느냐에 따라 에이전트가 오디오를 처리하고 응답하는 방식이 달라져요. 하이퍼클래스는 기능이 서로 다른 여러 실시간 음성 모델을 지원해요.

Gemini 3.8 Live는 정식 출시(GA) 모델이에요. 고객 대화에서 음성 품질, 추론, 도구 처리가 더 좋아졌어요.

모델 선택기에서 볼 수 있는 S2S 모델의 예는 다음과 같아요.

| 제공업체 | 모델 | 설명 |
| --- | --- | --- |
| Google | **Gemini 3.8 Live** | 정식 출시된 실시간 음성 대 음성 모델이에요. 더 자연스러운 대화, 강화된 추론과 도구 처리, 더 큰 컨텍스트 윈도우를 갖춰 길고 맥락이 풍부한 대화에 알맞아요. |
| OpenAI | GPT Realtime 2.1 | 들어오는 음성을 처리하고, 실시간 오디오 모델로 음성 응답을 만들어요. |
| OpenAI | GPT Realtime 2 | GPT Realtime 2.x 아키텍처로 음성 기반 대화를 직접 지원해요. |
| Google | Gemini 3.1 Flash Live Preview | 2026년 11월 2일에 종료될 예정인 이전 세대 실시간 음성 모델이에요. 기존 에이전트는 Gemini 3.8 Live로 자동 전환돼요. |

모델 선택기에서 음성을 직접 처리하는 모델에는 **실시간** 라벨이 붙어 있어요. 일부 모델에는 **베타** 라벨도 표시돼요. 모델별 출시 상태를 나타내는 표시예요.

{% endhint %}

{% endhint %}

## 에이전트 동작 설정

**에이전트 동작** 설정은 S2S 에이전트가 발신자의 요청을 처리하는 방식과 대화 타이밍을 정해요. 이 설정을 조정하면 응답 속도, 추론, 자연스러운 말 주고받기의 균형을 맞출 수 있어요.

| 설정 | 설명 |
| --- | --- |
| **사고 모드** | 에이전트가 요청을 처리할 때 쓰는 추론의 깊이를 조절해요. 선택할 수 있는 값은 선택한 모델에 따라 달라요. |
| **적극성** | 에이전트가 발신자의 말이 끝났다고 판단하고 답하기 시작하는 시점에 영향을 줘요. |

### 사고 모드

**사고 모드** 드롭다운에는 지원되는 모델에서 **Minimal**(최소) 옵션이 있어요. 선택한 모델에서 쓸 수 있는 옵션을 확인하고, 에이전트가 맡은 작업의 복잡도에 맞는 값을 고르세요.

### 적극성

**적극성**은 대화의 속도감에 영향을 줘요. 발신자가 말을 마치기 전에 에이전트가 먼저 답하거나, 답하기까지 너무 오래 멈춘다면 이 설정을 확인하고 다른 옵션으로 테스트해 보세요.

{% hint style="info" %}
설정은 한 번에 하나씩만 바꾸고, 바꿀 때마다 에이전트를 테스트하세요. 그러면 설정이 대화 흐름에 어떤 영향을 주는지 알 수 있어요.
{% endhint %}

![에이전트 동작 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083556563/original/Ms4IwGKyOh0_OUiY1CR5ZKhtKJwwzeM7qw.png?1792190361)

## 언어 설정

S2S 모델은 들어오는 음성을 직접 처리하기 때문에 다국어 대화를 지원할 수 있어요. 언어 설정을 알맞게 고르면 에이전트가 지원되는 언어로 답하고, 서로 다른 언어를 쓰는 발신자에게도 대응할 수 있어요.

S2S는 OpenAI Realtime과 Gemini Live 아키텍처 전반에서 90개가 넘는 언어를 지원해요. 사용할 수 있는 언어와 언어 전환 방식은 선택한 모델과 설정에 따라 달라요.

| 설정 | 설명 |
| --- | --- |
| **다국어** | 지원되는 자동 언어 감지와 응답 동작을 켜요. |
| **언어** | 설정한 에이전트에서 사용할 언어를 선택해요. |
| **Selected Languages**(선택한 언어) | 영어, 스페인어처럼 설정한 언어를 보여 줘요. 확인하거나 제거할 수 있어요. |

언어를 설정하려면 에이전트의 **언어** 설정을 열고, **다국어** 옵션을 확인하세요. 그다음 사용할 언어를 선택하고 변경 사항을 저장하세요.

![언어 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083556615/original/LLB3fTAF2sKCV8B3WgkCEu2YwBQ0kciv1Q.png?1792190429)

{% hint style="warning" %}
표준 **다국어** 음성 설정은 영어와 스페인어를 지원해요. 개별 S2S 모델이 지원하는 더 넓은 언어 기능과는 달라요. 자세한 내용은 [음성 AI 에이전트의 다국어 지원](multi-language-support-for-voice-ai-agents-004683.md)을 참고하세요.
{% endhint %}

## S2S 음성 AI 에이전트 설정하기

S2S 에이전트를 설정하려면 실시간 모델을 고르고, 대화 설정을 하고, 필요한 작업을 연결해요. Gemini 3.8 Live 같은 모델을 고른 뒤 배포 전에 동작을 테스트하면 대화가 자연스럽고 안정적으로 이어져요.

1. 에이전트 만들기 또는 열기: **AI 에이전트 > 음성 AI > 에이전트 목록**으로 이동해서 새 에이전트를 [만들거나](../how-to-create-voice-ai-agents.md) 기존 에이전트를 여세요. 모델을 바꾸기 전에 기존 에이전트를 복제해 두는 것도 좋아요.

   ![에이전트 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083557006/original/XMM1r1ZqjdycCq0iE1Bnrho-4B0u1-dtqg.png?1792190781)
2. 음성과 S2S 모델 고르기: 원하는 음성을 고른 다음 **모델** 드롭다운을 열고 실시간 모델을 선택하세요. 예를 들면 **GPT Realtime 2.1**이나 **Gemini 3.1 Flash Live Preview**가 있어요.

   ![모델 드롭다운에서 실시간 모델을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084524322/original/7L9x0c6ayHh9nf4CFsqMJS3S-CS7LiO_Rg.png?1793286407)

다음 에이전트 설정을 진행하세요.

- **Conversation Instructions**(대화 지침): 에이전트의 프롬프트를 입력하고, 역할과 목표를 정하세요. **환영 메시지**도 원하는 대로 바꿀 수 있어요.
- 언어와 에이전트 동작: 지원할 언어와 **다국어** 설정을 정하세요. 그다음 **사고 모드**와 **적극성**을 확인해서 대화 반응 속도를 조정하세요.
- 지식 베이스와 작업: **지식 베이스**에 업무 관련 정보를 추가하고, **작업 > + New Action**(새 작업 추가)에서 필요한 작업을 설정하세요. 통화 중 작업과 통화 후 작업을 나누는 방법은 [음성 AI의 통화 중 작업과 통화 후 작업 구분](separate-during-and-post-call-actions.md)을 참고하세요.

3. 저장하고 에이전트 테스트하기: **저장**을 클릭하고 **오디오 테스트**를 연 다음 **웹 통화 > 웹 통화 시작**을 선택하세요. 실시간 트랜스크립트로 응답, 언어 처리, 작업 실행을 확인하세요. 통화 전환은 전화 통화 테스트로 확인하세요.

   ![오디오 테스트에서 웹 통화를 시작하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083557040/original/70H3ahXkyhnuV08FcZce_BvVM_xP__1Imw.png?1792190880)
4. 에이전트 배포하기: **배포**를 열어 사용 가능한 전화번호나 지원되는 [음성 AI 채팅 위젯](../../06-사이트/채팅-위젯/how-to-set-up-and-use-the-voice-ai-chat-widget.md)을 연결하세요. 해당하는 라우팅 설정을 마치고 저장하세요. 테스트 전화를 걸어 실제 환경에서 어떻게 동작하는지 확인하세요.

{% hint style="info" %}
아웃바운드 통화를 쓰려면 알맞은 아웃바운드 설정, 사용 자격, 규정 준수 설정이 필요해요. 자세한 내용은 [음성 AI 에이전트 테스트하기](how-to-test-voice-ai-agents.md)를 참고하세요.
{% endhint %}

{% hint style="info" %}
기존 에이전트를 Gemini 3.8 Live로 바꿀 때는 대표적인 고객 대화, 긴 대화, 설정해 둔 작업을 테스트해 보세요. 새 모델이 기존 지침에서 어떻게 동작하는지 확인할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 모델 드롭다운에 GPT Realtime이나 Gemini Live가 안 보여요.

모델 제공 여부는 계정 설정과 사용할 수 있는 음성 AI 환경에 따라 달라질 수 있어요. 계정 권한을 확인해 보세요. 찾는 모델이 그래도 없으면 하이퍼클래스 고객지원에 문의하세요.

### S2S 에이전트로 아웃바운드 통화를 할 수 있나요?

네. S2S 에이전트도 아웃바운드 통화로 설정할 수 있어요. 단, 해당 사용 자격, 인증, 규정 준수 요건을 충족해야 해요.

### 기존 에이전트를 S2S로 바꾸면 모든 대화가 자동으로 좋아지나요?

꼭 그렇지는 않아요. 기존 프롬프트, 음성, 작업 조건, **지식 베이스** 설정은 조정이 필요할 수 있어요. 운영 중인 에이전트를 바꾸기 전에 복사본으로 먼저 테스트하세요.

### 웹 통화 테스트에서 통화 전환이 안 돼요.

**통화 전환**은 브라우저 기반 **웹 통화** 테스트에서 지원되지 않아요. 전환이 잘 되는지 확인하려면 전화 통화 테스트나 배포된 전화번호를 사용하세요.

### 에이전트 프롬프트가 15,000토큰을 넘으면 어떻게 되나요?

GPT Realtime 2.x와 Gemini 3.1 Flash Live Preview에는 에이전트 프롬프트 15,000토큰 제한이 있어요. 프롬프트를 줄이고, 참고용 내용은 **지식 베이스**로 옮기세요.

### S2S가 음성을 직접 처리해도 트랜스크립트를 볼 수 있나요?

네. 사용 가능한 트랜스크립트와 통화 로그를 보면서 대화를 평가하고 에이전트 동작의 문제를 살펴볼 수 있어요.

### S2S가 모든 언어와 감정 톤을 자동으로 알아듣나요?
