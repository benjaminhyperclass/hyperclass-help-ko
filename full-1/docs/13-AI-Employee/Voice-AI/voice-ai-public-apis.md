# 음성 AI 공개 API

음성 AI 공개 API를 쓰면 코드로 에이전트와 액션을 관리하고, 통화 로그와 녹취록을 가져오고, 실시간 웹훅을 워크플로우에 연결할 수 있어요. 이 문서는 전체 내용을 간단히 소개하고, 자세한 기술 정보는 공식 API 문서에서 확인하도록 안내해요.

## 음성 AI 공개 API란?

음성 AI 공개 API로 에이전트 설정, 액션 관리, 통화 데이터 조회, 웹훅 연동을 직접 할 수 있어요. 음성 AI를 앱 안에서만 쓰는 기능에서 한 단계 넓혀, 워크플로우와 애플리케이션에 직접 연결해서 쓸 수 있어요.

앱 화면에서 하는 설정에만 머물지 않고 이렇게 활용할 수 있어요.

- 에이전트와 액션 관리: API로 에이전트와 에이전트의 동작을 만들고, 수정하고, 정리해요.
- 통화 데이터 조회: 리포트, 컴플라이언스, 분석에 쓸 로그와 녹취록을 가져와요.
- 웹훅 활용: 통화 결과, 녹취록, 요약을 우리 시스템에서 실시간으로 받아요.

## 음성 AI 공개 API의 주요 장점

- 데이터 접근: 통화 결과, 녹취록, 지표를 가져와 상세하게 추적하고 리포트를 만들 수 있어요.
- 워크플로우 연동: 설정을 자동화하고, 음성 AI를 우리 애플리케이션과 운영 방식에 맞게 조정할 수 있어요.
- 확장성: 공개 API 덕분에 음성 AI를 그냥 쓰는 데서 그치지 않고 직접 만들어 확장할 수 있어요.

## 음성 AI API 문서

음성 AI 공개 API 문서에는 통화 로그, 에이전트, 액션에 대한 내용이 들어 있어요. 접근 요건, 환경, 인증 방식은 바뀔 수 있어요. 최신 내용은 항상 API 문서에서 확인하세요.

API 문서 주소는 하이퍼클래스 고객지원에 문의하세요.

## 음성 목록 API (카탈로그 API)

공개 API로 음성 AI의 음성 카탈로그를 둘러볼 수 있어요.

- `Get Voices`(음성 목록 조회): 페이지를 나눠 필터링할 수 있는 음성 목록을 가져와요. 언어로 필터링할 수 있고, `agentId`를 함께 보내면 그 에이전트와 호환되는 음성만 돌려줘요.
- `Fetch Voice Details`(음성 상세 조회): 특정 음성의 상세 메타데이터를 가져와요. 테스트용 미리 듣기 URL도 들어 있어요.

기술 정보는 개발자 포털의 음성 AI API 문서를 참고하세요.

## 통화 로그 API

통화 로그 API로 음성 AI가 처리한 통화에 접근할 수 있어요. 분석, 품질 검토, 컴플라이언스에 활용해요. 필터로 통화를 목록으로 조회하거나, 통화 한 건의 상세 정보를 가져올 수 있어요. 녹취록이 있으면 함께 가져와요. 자세한 내용은 API 레퍼런스 문서를 참고하세요.

- `List Call Logs`(통화 로그 목록 조회): 서브 계정 단위로 음성 AI 에이전트의 통화 로그를 돌려줘요. 에이전트, 연락처, 통화 유형, 액션 유형, 날짜 범위로 필터링할 수 있어요. 날짜 범위는 지정한 IANA 시간대를 기준으로 해석해요. 정렬과 1부터 시작하는 페이지 나누기도 지원해요.
- `Get Call Log`(통화 로그 조회): 통화 ID로 통화 로그 한 건을 돌려줘요.

## 에이전트 API

에이전트 API로 음성 AI 에이전트를 코드로 만들고, 조회하고, 읽고, 수정하고, 삭제할 수 있어요. 여러 서브 계정과 환경에 같은 구성을 일관되게 적용할 수 있어요. 자세한 내용은 API 레퍼런스 문서를 참고하세요.

- `Create Agent`(에이전트 생성): 새 음성 AI 에이전트의 구성과 설정을 만들어요.
- `Patch Agent`(에이전트 일부 수정): 기존 음성 AI 에이전트의 일부 항목만 수정해요.
- `List Agents`(에이전트 목록 조회): 지정한 서브 계정의 에이전트 목록을 페이지를 나눠 가져와요.
- `Get Agent`(에이전트 조회): 특정 음성 AI 에이전트의 상세 구성과 설정을 가져와요.
- `Delete Agent`(에이전트 삭제): 음성 AI 에이전트와 그 에이전트의 모든 구성을 삭제해요.

## 액션 API

액션은 에이전트가 할 수 있는 일을 정해요. 예를 들어 웹훅을 호출하거나, 데이터를 가져오거나, 결과를 전송할 수 있어요. 액션 API로 이런 동작을 코드로 만들고 수정해서 우리 시스템과 맞춰 둘 수 있어요. 자세한 내용은 API 레퍼런스 문서를 참고하세요.

- `Create Agent Action`(에이전트 액션 생성): 음성 AI 에이전트의 새 액션을 만들어요. 액션은 통화 중 에이전트가 하는 구체적인 동작과 기능을 정해요.
- `Update Agent Action`(에이전트 액션 수정): 음성 AI 에이전트의 기존 액션을 수정해요. 액션의 동작과 구성이 바뀌어요.
- `Get Agent Action`(에이전트 액션 조회): ID로 특정 액션의 상세 정보를 가져와요. `actionParameters`를 포함한 액션 구성을 돌려줘요.
- `Delete Agent Action`(에이전트 액션 삭제): 음성 AI 에이전트의 기존 액션을 삭제해요. 액션과 액션의 구성이 완전히 지워져요.

## 자주 묻는 질문

### API로 음성도 관리할 수 있나요?

네, 할 수 있어요. 음성 API로 사용할 수 있는 음성 목록과 미리 듣기 URL을 포함한 상세 메타데이터를 가져올 수 있어요. 에이전트에 맞는 음성을 고를 때 도움이 돼요.

### 이 API를 쓰려면 특별한 권한이 필요한가요?

음성 AI를 관리하고 통화 데이터를 읽을 수 있는 권한이 하이퍼클래스 계정에 있어야 해요. 일부 리소스에 접근할 수 없다면 계정 관리자에게 문의하세요.

### 최신 엔드포인트와 요청·응답 스키마는 어디서 확인하나요?

항상 공식 API 문서를 사용하세요. 문서 주소는 하이퍼클래스 고객지원에 문의하세요.
