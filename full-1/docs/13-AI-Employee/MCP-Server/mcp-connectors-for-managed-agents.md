# 관리형 에이전트에 MCP 앱 커넥터 연결하기

MCP(Model Context Protocol) 커넥터를 쓰면 관리형 에이전트가 HubSpot, Notion, Make, Calendly 같은 외부 앱과 함께 일할 수 있어요. 에이전트는 연결된 앱에 로그인하고, 도구를 사용하고, 워크플로우 트리거에 따라 작업을 실행해요.

이 문서에서는 MCP 커넥터가 무엇인지, 어떤 앱을 지원하는지, **에이전트 스튜디오**(Agent Studio)에서 어떻게 설정하는지 알려 드려요. 자주 묻는 질문도 함께 정리했어요.

## MCP 앱 커넥터란?

MCP(Model Context Protocol) 앱 커넥터를 쓰면 하이퍼클래스 관리형 에이전트가 외부 앱에 안전하게 로그인하고 앱과 상호작용할 수 있어요. 연결이 끝나면 에이전트는 자동화 워크플로우의 일부로 앱의 도구를 사용하고 작업을 실행해요.

예를 들어 Notion MCP를 연결한 관리형 에이전트는 Notion 워크스페이스에서 페이지를 만들고, 콘텐츠를 검색하고, 데이터베이스를 업데이트할 수 있어요. HubSpot MCP를 연결하면 HubSpot에서 연락처를 만들고, 딜을 업데이트하고, 활동을 기록할 수 있어요.

MCP 커넥터는 보안이 적용된 OAuth 인증이나 직접 로그인 방식을 써요. 그래서 로그인 정보를 노출하지 않고도 에이전트에게 필요한 권한을 줄 수 있어요. 연결된 앱에서 에이전트가 어떤 도구를 쓸 수 있는지는 직접 정해요.

## 주요 장점

MCP 앱 커넥터는 하이퍼클래스 워크플로우와 외부 플랫폼을 이어 줘서 관리형 에이전트가 할 수 있는 일을 넓혀 줘요.

- 에이전트 스튜디오에서 앱 찾아 연결하기: **에이전트 스튜디오** 화면에서 바로 MCP 앱을 추가해요. 연동을 설정하려고 플랫폼을 벗어날 필요가 없어요.
- 안전한 인증: OAuth나 보안 로그인 방식으로 연결해요. 로그인 정보는 안전하게 처리되고, 에이전트는 직접 허용한 권한만 받아요.
- 도구 단위 선택: 연결된 앱에서 에이전트별로 쓸 도구를 골라요. 에이전트에게 꼭 필요한 기능만 열어 줄 수 있어요.
- 트리거 기반 실행: 에이전트가 워크플로우 트리거에 따라 연결된 앱에서 작업을 실행해요. 레코드 생성, 상태 업데이트, 정보 조회 같은 일을 자동으로 처리해요.
- 계속 늘어나는 커넥터: 새로운 MCP 커넥터가 꾸준히 추가돼요. 에이전트가 연동할 수 있는 외부 서비스도 점점 늘어나요.

## 관리형 에이전트에 MCP 앱 연결하기

다음 순서대로 **에이전트 스튜디오**에서 관리형 에이전트에 MCP 앱 커넥터를 추가하세요.

1. 하이퍼클래스 계정에서 **에이전트 스튜디오**로 이동하세요.

   ![에이전트 스튜디오 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077351998/original/PmwPnqyDU8s4O4H14iDIzc29dFr7HAHI9A.png?1785506605)

2. 새 관리형 에이전트를 만들거나 기존 에이전트를 여세요. 에이전트를 만드는 중에 에이전트 빌더에게 MCP 앱을 추가해 달라고 요청할 수도 있어요.

   ![관리형 에이전트 만들기 또는 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082678840/original/jEEzwqFFZq7oMujIknuPkkxuIbO3gldJIA.png?1791308714)

3. 에이전트 설정의 **Apps**(앱) 섹션에서 **+ Add app**(앱 추가)을 클릭하세요. 연동할 MCP 커넥터(예: Notion, HubSpot, Make)를 선택하세요.

   ![MCP 앱 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077352212/original/X7W8p_kjwiN3ItIJ_9IFHcJuZAI-1BuIVg.png?1785506759)

4. MCP 앱 옆의 **+ Connect**(연결)를 클릭하세요. OAuth 또는 보안 로그인 화면이 나타나면 로그인하고, 에이전트가 앱에 접근하는 데 필요한 권한을 허용하세요.

   ![MCP 앱 계정 인증](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077156026/original/_sia11EHfqV04YB9T-asTfn86VNZpPqdMA.png?1785336258)

5. 인증이 끝나면 해당 MCP 앱에서 쓸 수 있는 도구 목록이 나타나요. 에이전트가 사용할 도구의 체크박스를 선택하세요. 예를 들어 Notion은 `notion-create-pages`, `notion-search`, Monday.com은 `get_board_items_page` 같은 도구가 있어요.

   ![사용할 도구 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077352359/original/ESa-D6ymUTPpEB4uFLN4kNXKi8G75ovBEA.png?1785506878)

6. **저장**을 클릭하세요. MCP 앱 연결과 선택한 도구가 관리형 에이전트에 적용돼요.

7. 설정해 둔 트리거(예: 리드 생성 폼 제출)로 에이전트를 실행하세요. 에이전트가 워크플로우의 일부로 연결된 MCP 앱에서 작업을 실행해요.

{% hint style="info" %}
관리형 에이전트 하나에 MCP 앱을 여러 개 연결할 수 있어요. 에이전트는 상황과 사용자가 준 지침에 맞춰 알맞은 도구를 사용해요.
{% endhint %}

## 자주 묻는 질문

### MCP(Model Context Protocol)가 뭔가요?
MCP는 AI 에이전트가 외부 애플리케이션에 안전하게 연결되어 상호작용할 수 있게 해 주는 표준 프로토콜이에요. 에이전트가 플랫폼마다 어떻게 인증하고, 도구에 접근하고, 작업을 실행하는지를 정해 두었어요.

### 관리형 에이전트 하나에 MCP 앱을 여러 개 연결할 수 있나요?
네. 관리형 에이전트 하나에 MCP 앱을 여러 개 연결할 수 있어요. 에이전트는 지침과 작업 상황에 맞는 도구를 사용해요.

### MCP 앱을 연결할 때 로그인 정보는 안전한가요?
네. MCP 커넥터는 OAuth나 보안 로그인 방식을 써요. 로그인 정보는 하이퍼클래스에 저장되지 않고, 에이전트는 인증할 때 직접 허용한 권한만 받아요.

### MCP 커넥터는 어떤 하이퍼클래스 기능에서 쓸 수 있나요?
현재는 **에이전트 스튜디오**의 관리형 에이전트와 **AI에게 문의**(Ask AI)에서 MCP 커넥터를 쓸 수 있어요. **음성 AI**와 **대화 AI**는 이후 출시에서 지원할 예정이에요.

### 직접 만든 MCP 커넥터를 쓸 수 있나요?
네. 관리형 에이전트는 **에이전트 스튜디오**에서 사용자 지정 MCP 커넥터를 지원해요. 호환되는 외부 MCP 서버나 자체 MCP 서버를 연결하고, 필요하면 인증을 설정하고, 관리형 에이전트가 쓸 도구를 고르면 돼요.

### 에이전트가 쓸 도구는 어떻게 고르나요?
MCP 앱을 연결하면 쓸 수 있는 도구 목록이 나타나요. 에이전트가 사용할 도구의 체크박스를 선택하세요. 선택은 에이전트 설정을 편집해서 언제든 바꿀 수 있어요.

### MCP 앱 연결이 실패하면 어떻게 되나요?
인증에 실패하거나 권한이 취소되면 에이전트는 그 앱에서 작업을 실행할 수 없어요. **에이전트 스튜디오**의 **Apps**(앱) 섹션에서 계정을 다시 인증하면 MCP 앱을 다시 연결할 수 있어요.

### 앞으로 MCP 앱이 더 추가되나요?
네. 하이퍼클래스는 새로운 MCP 커넥터를 계속 추가하고 있어요. 하이퍼클래스 커뮤니티의 MCP 앱 트래커에서 예정된 연동을 확인하고 새 커넥터를 요청할 수 있어요.
