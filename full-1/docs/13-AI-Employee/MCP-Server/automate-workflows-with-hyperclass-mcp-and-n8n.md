# 하이퍼클래스 MCP와 N8N으로 워크플로우 자동화하기

하이퍼클래스 MCP를 N8N과 바로 연결해 쓸 수 있어요. 별도의 맞춤 플러그인 없이 하이퍼클래스와 N8N 워크플로우를 이어서, 설정 시간과 번거로움을 줄이고 더 빠르게 자동화할 수 있어요.

## 새로워진 점

- 하이퍼클래스 MCP와 N8N이 기본으로 호환돼요.
- 맞춤 플러그인이 필요 없어요.
- 연동 설정이 더 빠르고 간단해요.

## 이렇게 작동해요

하이퍼클래스 MCP를 N8N에 바로 연결하면 곧바로 워크플로우 자동화를 시작할 수 있어요.

연결하면 다음과 같은 작업을 할 수 있어요.

- 하이퍼클래스 데이터를 N8N 워크플로우와 연결해요.
- 두 플랫폼에 걸친 업무 과정을 자동화해요.
- 추가 개발이나 플러그인 없이 연동을 만들어요.

## 시작하는 방법

1. 하이퍼클래스 MCP 계정에 로그인하세요.
2. 사용 중인 에이전트 또는 클라이언트 안에서 MCP 연결을 설정하세요.
3. MCP 엔드포인트와 인증 헤더를 추가하세요.
4. N8N에서 워크플로우를 설정하세요.
5. 워크플로우를 테스트해서 데이터가 제대로 오가는지 확인하세요.

## 예시: MCP 설정

에이전트 또는 클라이언트 안에서 MCP 엔드포인트와 인증 헤더를 설정하는 예시예요.

```
{  "mcpServers": {    "ghl-mcp": {      "url": "https://services.leadconnectorhq.com/mcp/",      "headers": {        "Authorization": "Bearer <your-token>",        "locationId": "<your-location-id>"      }    }  } }
```

이 설정에는 다음 내용이 들어 있어요.

- MCP 서버 엔드포인트
- Authorization 헤더(Bearer 토큰)
- 범위를 지정한 요청에 쓰는 선택 항목인 locationId

## 자주 묻는 질문

### N8N과 하이퍼클래스 MCP를 쓰려면 맞춤 플러그인이 필요한가요?
아니요. 맞춤 플러그인 없이 바로 연동해서 쓸 수 있어요.

### 기존에 만든 N8N 워크플로우를 그대로 쓸 수 있나요?
네. 기존 N8N 워크플로우를 하이퍼클래스 MCP와 함께 쓸 수 있어요.

### 추가로 해야 하는 설정이 있나요?
아니요. 두 시스템을 연결하고 워크플로우를 설정하는 것 외에 고급 설정은 필요 없어요.

### 이 연동의 가장 큰 장점은 무엇인가요?
맞춤 개발이나 플러그인 없이 하이퍼클래스와 N8N 사이의 워크플로우를 빠르게 자동화할 수 있어요.
