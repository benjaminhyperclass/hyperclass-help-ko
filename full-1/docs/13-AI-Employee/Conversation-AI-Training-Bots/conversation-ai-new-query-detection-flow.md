# 대화 AI의 새 질문 감지 흐름

대화 AI의 새 질문 감지 흐름은 진행 중인 대화에서 연락처가 무엇을 묻는지 하이퍼클래스가 더 정확히 이해하도록 돕는 개선 기능이에요. 메시지를 하나씩 따로 보지 않고 최근 대화 맥락을 살펴서, 새 질문인지, 앞선 주제의 연장인지, 지원 요청인지, 상품·서비스·가격·비즈니스 정보에 대한 질문인지 구분해요.

[동영상](https://www.youtube.com/embed/ClMO3Inox2w?&wmode=opaque)

## 새 질문 감지 흐름이란?

이 개선 기능은 대화 AI가 봇 학습 데이터, **지식 소스**, 대화 기록, 설정해 둔 지침을 활용해 더 알맞은 답변을 하도록 도와요. 자동으로 적용되므로 새 설정을 켜거나 기존 대화 AI 설정을 다시 만들 필요가 없어요.

대화 AI는 이미 대화 기록과 학습 데이터를 활용해 답변 정확도를 높이고 있어요. 관련 설정은 기존 대화 AI 설정 화면에서 관리해요.

## 새 질문 감지 흐름의 주요 이점

새 질문 감지 흐름은 실제 대화에서 고객의 의도를 이해하는 방식을 개선해요. 그래서 엉뚱한 답변이 줄고, 대화가 더 자연스럽게 이어지며, 봇이 답하기 전에 가장 관련 있는 정보를 활용할 수 있어요.

- 대화 이해도 향상: 연락처가 기존 주제를 이어 가는지, 완전히 새로운 질문을 하는지, 대화 방향을 바꾸는지 더 잘 알아봐요.
- 더 정확한 질문 파악: 고객의 의도를 더 분명하게 파악해서, 후속 질문인지, 지원 요청인지, 영업 관련 질문인지, 예약 문의인지, 비즈니스 정보 요청인지 판단해요.
- 학습 데이터 활용 개선: 고객의 요청을 더 정확히 파악하면 알맞은 학습 데이터, **지식 소스**, **자주 묻는 질문**, 설정해 둔 봇 지침을 더 잘 참고해요.
- 더 매끄러운 고객 경험: 특히 후속 질문을 하거나 주제를 바꿀 때, 연락처는 대화와 더 잘 이어지는 답변을 받아요.
- 추가 설정 불필요: 기존 대화 AI 사용자는 새 기능을 켜거나 봇을 다시 만들지 않아도 자동으로 혜택을 받아요.

## 대화 AI가 새 질문을 감지하는 방식

대화 AI는 최근 대화 맥락을 활용해 고객의 최신 메시지와 이전 메시지의 관계를 파악해요. 이를 바탕으로 봇은 현재 대화를 이어 갈지, 새 질문에 답할지, 다른 유형의 요청으로 넘어갈지 판단해요.

질문 감지는 보통 아래 순서로 진행돼요.

1. 최근 대화 맥락을 살펴봐요. 대화 AI가 최신 메시지를 이전 메시지와 함께 평가해요.
2. 고객의 의도를 파악해요. 새 질문인지, 앞선 주제의 후속 질문인지, 지원 요청인지, 비즈니스 정보 요청인지 판단해요.
3. 요청에 맞는 정보를 찾아요. 관련 학습 데이터, **지식 소스**, 봇 지침, 대화 기록을 활용해 가장 알맞은 답변을 준비해요.
4. 맥락에 맞는 답변을 만들어요. 감지한 의도와 가장 관련 있는 정보를 바탕으로 최종 답변을 만들어요.

### 예시: 후속 질문

연락처가 "어떤 패키지가 있나요?"라고 묻고 답변을 받은 뒤 "두 번째 패키지에는 지원이 포함되나요?"라고 물어요.

대화 AI는 두 번째 메시지를 관련 없는 별도 질문이 아니라 패키지 대화의 후속 질문으로 볼 수 있어요.

### 예시: 주제 변경

연락처가 예약 가능 시간을 묻다가 나중에 "취소 정책이 어떻게 되나요?"라고 물어요.

대화 AI는 연락처가 예약 가능 시간에서 정책 정보로 주제를 바꾼 것을 감지하고, 관련 비즈니스 정보나 **지식 소스** 콘텐츠로 답할 수 있어요.

### 예시: 이전 대화 이후의 새 문의

연락처가 앞서 가격에 대해 이야기했다가 나중에 다시 돌아와 "상업용 건물 서비스도 하시나요?"라고 물어요.

대화 AI는 이 메시지를 새로운 비즈니스 관련 질문으로 보면서, 필요한 경우 도움이 되는 이전 대화 기록도 함께 참고할 수 있어요.

## 학습 데이터와 지식 소스가 질문 감지를 돕는 방식

질문 감지가 정확해지면 대화 AI가 고객이 무엇을 묻는지 더 잘 이해해요. 하지만 답변 품질은 봇이 쓸 수 있는 정보에도 달려 있어요. 깔끔하고 최신이며 잘 정리된 학습 데이터가 있어야 대화 AI가 답변을 만들 때 참고할 자료가 좋아져요.

하이퍼클래스에서는 **Web Crawler**(웹 크롤러), **Custom Bot Responses**(맞춤 봇 응답) 같은 도구로 대화 AI를 학습시킬 수 있어요. **지식 소스**에는 표, 서식 있는 텍스트, 파일 업로드, **자주 묻는 질문**, 웹 크롤러 소스, 웹 검색 소스 같은 콘텐츠를 넣을 수 있어요. 이런 소스는 대화 AI가 답변을 만들기 전에 관련 정보를 찾아오는 데 쓰여요.

더 나은 답변을 위해 아래 항목을 주기적으로 점검하세요.

- 봇 학습 콘텐츠
- **Custom Bot Responses** 또는 **자주 묻는 질문**
- **지식 소스**
- 웹사이트 크롤러 소스
- 업로드한 파일 또는 서식 있는 텍스트로 작성한 **지식 베이스** 콘텐츠
- 봇의 목표, 성격, 추가 지침
- 중복되거나 오래됐거나 서로 충돌하는 정보

## 새 질문 감지 흐름 설정 방법

새 질문 감지 흐름은 자동으로 적용되므로 직접 설정할 필요가 없어요. 기존 대화 AI 봇은 새 토글을 켜거나 마이그레이션하거나 별도로 구성하지 않아도 개선된 감지 흐름의 혜택을 받을 수 있어요.

더 좋은 결과를 얻으려면 아래 순서로 현재 대화 AI 설정을 점검해 보세요.

1. 대화 AI 설정을 열어요. 사용 중인 봇 구성, 배정된 채널, 응답 방식을 확인하세요.
2. 봇 지침이 명확한지 확인해요. 봇의 목표, 성격, 추가 지침이 대화 AI가 응답하길 바라는 방식과 맞는지 살펴보세요.
3. 학습 데이터를 점검해요. **Web Crawler** 콘텐츠, **Custom Bot Responses**, **자주 묻는 질문** 등 다른 학습 자료가 정확하고 최신인지 확인하세요.
4. **지식 소스**를 점검해요. 최신 정보가 담겨 있고 구조가 명확해서 대화 AI가 알맞은 콘텐츠를 찾을 수 있는지 확인하세요.
5. 자주 나오는 고객 질문으로 테스트해요. 후속 질문, 주제 변경, 새 문의가 담긴 샘플 메시지를 보내 봇이 의도대로 답하는지 확인하세요.
6. 필요하면 AI 응답 정보를 확인해요. 답변이 부정확해 보이면 그 답변과 연결된 응답 정보나 소스 콘텐츠를 살펴보고, 필요에 따라 학습 데이터나 **지식 소스** 콘텐츠를 업데이트하세요.

## 자주 묻는 질문

### 새 질문 감지 흐름을 직접 켜야 하나요?

아니요. 이 개선 기능은 자동으로 적용되며, 새 설정을 켤 필요가 없어요.

### 기존 대화 AI 봇 설정이 바뀌나요?

아니요. 이번 업데이트는 대화 AI가 고객 메시지를 이해하는 방식을 개선할 뿐, 기존 봇 구성, 학습 데이터, 목표, 지침, 워크플로우를 대체하지 않아요.

### 봇을 다시 학습시켜야 하나요?

기능이 작동하는 데 재학습은 필요 없어요. 다만 학습 데이터를 점검하고 업데이트하면 답변 품질을 높일 수 있어요.

### 기존 학습 데이터와 지식 소스에서도 작동하나요?

네. 대화 AI는 답변을 만들 때 기존 학습 데이터와 **지식 소스**를 활용할 수 있어요. 콘텐츠가 더 잘 정리되어 있고 최신일수록 결과가 좋아질 수 있어요.

### 대화 AI가 부정확하게 답하면 어떻게 하나요?

봇의 학습 데이터, **지식 소스**, **자주 묻는 질문**, 지침을 점검하세요. 대화에서 AI 응답 정보를 볼 수 있다면, 어떤 콘텐츠가 답변에 영향을 줬는지 확인해 보세요.

### 대화 AI 워크플로우 액션에도 영향이 있나요?

대화 AI 워크플로우 액션은 답변을 만들 때 봇 프롬프트 설정, 학습 데이터, 대화 기록을 사용해요. 워크플로우 안에서 대화 AI를 쓰고 있다면 워크플로우 액션 설정은 따로 점검하세요.

### **지식 베이스 트리거**를 대체하나요?

아니요. 질문 감지는 대화 AI가 고객의 메시지를 이해하도록 돕는 기능이에요. **지식 베이스 트리거**는 대화 중 특정 **지식 베이스** 콘텐츠를 언제 사용할지 직접 정하는 기능이에요.

### 특정 연락처에 대한 대화 AI 응답 여부를 제어할 수 있나요?

네. 봇의 응답 방식은 지금처럼 대화 AI에서 제공하는 설정으로 관리할 수 있어요. 새 질문 감지 흐름은 이해도를 높여 줄 뿐, 기존 봇 상태나 설정 옵션을 없애지 않아요.
