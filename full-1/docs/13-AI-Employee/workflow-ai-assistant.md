# 워크플로우 AI 어시스턴트

워크플로우 AI는 워크플로우를 처음부터 끝까지 만들도록 도와주는 AI 어시스턴트예요. 워크플로우 빌더 안에서 새 워크플로우를 만들 때도, 기존 워크플로우를 다듬을 때도 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/LAsdCqd5hZE?&wmode=opaque)

워크플로우 AI는 워크플로우를 만들고, 최적화하고, 관리하는 동안 곁에서 안내해 주는 도우미예요. 단계별로 안내하고, 목적에 맞는 액션을 추천하고, 워크플로우를 개선할 방법도 알려 줘요.

만들고 싶은 내용을 입력하기만 하면 돼요. 그러면 필요한 액션과 트리거 목록, 그리고 각각 어떻게 설정하는지 알려 줘요.

{% hint style="info" %}
워크플로우 AI는 이제 AI 크레딧을 사용하지 않아요. **AI로 생성**(SMS, 이메일, 코드 등) 같은 워크플로우 AI 기능을 크레딧 사용량 걱정 없이 쓸 수 있어요.

모든 사용자가 빠르게 쓸 수 있도록 공정 사용 한도를 적용할 수 있어요. 일일 한도에 도달하면 24시간 뒤에 초기화돼요.
{% endhint %}

## 워크플로우 AI로 할 수 있는 일

1. 첫 워크플로우 만들기
   - 워크플로우가 처음이라면 이루고 싶은 목표만 말해 보세요. 워크플로우 AI가 추가해야 할 액션과 트리거를 알려 주고 설정도 도와줘요. **AI 어시스턴트**는 워크플로우가 무엇이고 어떻게 쓰는지도 설명해 줘요.
2. 워크플로우 내용 풀어서 설명받기
   - 워크플로우의 어떤 부분이 헷갈리면 바로 물어보세요. 워크플로우 AI가 무슨 일이 일어나는지 설명해 줘서 복잡한 워크플로우도 이해하기 쉬워져요.
3. 워크플로우를 더 효율적으로 만들기
   - 워크플로우 AI가 워크플로우를 살펴보고 개선할 점을 찾아 줘요. 과정을 간소화하는 방법과 그러기 위해 추가할 수 있는 액션도 알려 줘요.
4. 단계별 안내
   - 워크플로우 설정이 막막하다면 워크플로우 AI가 각 단계를 설명하며 안내해 줘요. 지금 만드는 내용을 확신을 갖고 진행할 수 있어요.
5. 질문에 답변
   - 워크플로우를 만들다가 궁금한 점이 생기면 물어보세요. 특정 액션에 관한 질문도, 일반적인 활용 방법에 관한 질문도 괜찮아요.
6. 워크플로우에 액션 추가
   - SMS 알림 보내기, 확인 응답 기다리기, 예약 상태 업데이트하기, 활동에 따라 연락처에 태그 지정하기 같은 액션을 직접 추가하도록 도와줘요.
7. 다음 단계 제안
   - 다음에 무엇을 해야 할지 모르겠다면 워크플로우 AI가 이어서 할 일을 제안해 줘요.
8. 워크플로우 설정과 이름 관리
   - 워크플로우 AI에게 일상적인 말로 요청하면 워크플로우 이름을 바꾸고 설정을 수정해 줘요. 재진입, 여러 기회, 응답 시 중단, 시간대/시간 범위, 발신자 정보, 대화 읽음 처리 같은 설정을 다룰 수 있어요.

## 워크플로우 AI 사용하기

워크플로우 빌더를 열면 왼쪽 아래에 워크플로우 AI가 있어요. AI 아이콘을 클릭하면 채팅 창이 열려요.

워크플로우 AI와 대화하는 방법은 4가지예요.

1. 워크플로우 분석: **Describe this Workflow**(이 워크플로우 설명) 버튼을 클릭하면 워크플로우 AI가 워크플로우를 분석해 줘요.
2. 만들기 도움 받기: **Assist with Building**(만들기 지원) 버튼을 클릭하면 워크플로우 AI가 워크플로우에 대한 제안을 해 줘요.
3. 일반 대화: 입력창에 궁금한 내용을 자유롭게 입력하세요.
4. 스냅샷으로 가져온 워크플로우 설명 듣기: 스냅샷으로 가져온 워크플로우를 열면 워크플로우 상단에 **Explain This Workflow**(이 워크플로우 설명) 버튼이 나타나요.

## 워크플로우에 대해 더 알아보기

워크플로우 AI는 워크플로우를 만들거나 지금 구조를 분석할 때만 쓰는 도구가 아니에요. 워크플로우에 관해 궁금한 점을 무엇이든 물어볼 수 있어요. 여러 액션이나 트리거에 대해 더 알고 싶을 때, 액션과 트리거가 뭔지조차 모를 때도 워크플로우 AI에게 물어보면 돼요.

예를 들어 아래 화면에서는 워크플로우 AI에게 "트리거가 뭐야?"라고 물었어요. 그러자 트리거가 무엇인지 자세한 설명과 함께 여러 워크플로우 트리거 예시를 알려 줬어요.

## 채팅 지우고 새로 시작하기

워크플로우 AI와 새 채팅을 시작하려면 워크플로우 AI 채팅 창 오른쪽 위의 **Clear Chat**(채팅 지우기) 버튼을 클릭하세요. **Clear Chat**을 클릭하면 이전 채팅이 사라지고, 워크플로우 AI에게 무엇을 시킬지 고르는 첫 화면으로 돌아가요.

## 현재 채팅 내보내기

대화 내용을 기록으로 남기고 싶다면 **Export Chat**(채팅 내보내기) 버튼을 클릭하세요. 전체 대화 내용이 복사본으로 다운로드돼요.

{% hint style="warning" %}
채팅 내보내기는 현재 대화만 내보내요. 이전에 워크플로우 AI와 나눈 대화는 내보내지지 않아요.
{% endhint %}

## 워크플로우 전체 분석하기

워크플로우 AI가 워크플로우를 분석해서 나 또는 팀에게 설명해 주길 원한다면 **Describe This Workflow** 버튼을 클릭하세요.

워크플로우 AI가 워크플로우를 처음부터 끝까지 개괄해 주고, 각 단계에 대한 세부 내용도 알려 줘요.

이런 상황에서 특히 유용해요.

1. 워크플로우를 왜 만들었는지 잊어버렸을 때
2. 우리 업무 방식을 배워야 하는 새 팀원이 있을 때
3. 고객이 내 스냅샷에 들어 있는 워크플로우를 더 알고 싶어 할 때
4. 그 밖에 특정 워크플로우를 더 잘 이해하면 설명하는 과정이 한결 쉬워지는 여러 상황

### 스냅샷으로 가져온 워크플로우 설명받기

스냅샷으로 가져온 워크플로우에는 상단에 **Explain This Workflow** 버튼이 있어요. 내가 직접 만들지 않은 워크플로우의 내용을 파악해야 할 때 사용하세요.

스냅샷 워크플로우의 설명을 받는 방법은 다음과 같아요.

1. 스냅샷으로 가져온 워크플로우를 엽니다.
2. 워크플로우 상단의 **Explain This Workflow**를 클릭합니다.
3. **AI 어시스턴트**가 열리고 워크플로우의 트리거, 액션, 분기 로직을 설명해 줘요.
4. 이어서 대화하며 워크플로우의 특정 부분에 대해 추가로 질문하세요.

설명을 확인한 뒤에 AI에게 워크플로우를 수정해 달라고 요청할 수도 있어요.

![스냅샷으로 가져온 워크플로우 상단의 이 워크플로우 설명 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077919281/original/4Yrui_TXaDkGXfFlwwtXDiWTsTKjb5mVbw.png?1786120999)

## AI로 워크플로우 만들기

워크플로우 만들기가 어렵거나, 내 상황에 가장 알맞은 워크플로우를 AI의 도움으로 빠르고 쉽게 만들고 싶다면 워크플로우 AI를 사용해 보세요.

### 1단계: 워크플로우 AI에게 도움 요청하기

채팅 입력창에 워크플로우를 만드는 데 도움이 필요하다고 입력하면 시작할 수 있어요.

이루고 싶은 사용 사례를 말해 주세요. 그러면 워크플로우 AI가 그 사례에 가장 알맞은 액션과 트리거를 자세히 설명하고, 원하는 워크플로우를 설정하는 방법을 단계별로 안내해 줘요.

### 2단계: 제안 중에서 선택하기

워크플로우 AI가 제안을 보여 주면 그중에서 가장 알맞은 옵션을 고르세요.

## 자주 묻는 질문

### 워크플로우 AI를 왜 써야 하나요?

워크플로우 AI를 쓰면 워크플로우를 훨씬 빠르고 쉽게 만들고 개선할 수 있어요. 실시간으로 제안을 해 주기 때문에 고민하는 시간이 줄고, 워크플로우가 효율적이고 오류 없이 만들어지도록 도와줘요.

### 워크플로우 AI가 복잡한 워크플로우도 다룰 수 있나요?

네, 가능해요. 워크플로우 AI는 단순한 워크플로우와 복잡한 워크플로우 모두 도와주도록 만들어졌어요. 한 단계짜리 과정이든 여러 층으로 이루어진 자동화든 도움을 받을 수 있어요.

### 워크플로우에 액션을 추가하려면 어떻게 하나요?

워크플로우 AI는 만들고 있는 내용에 맞춰 액션을 제안해 줘요. SMS 보내기나 상태 업데이트 같은 액션 옆의 **+** 버튼을 클릭하면 워크플로우에 추가돼요.

### 워크플로우 AI와 나눈 대화를 기록으로 남길 수 있나요?

네, 가능해요. **Export Chat** 버튼을 클릭하면 대화 복사본이 다운로드돼요. 필요할 때 언제든 다시 확인할 수 있어요.

### 워크플로우 AI는 누구나 사용할 수 있나요?

네, 워크플로우를 사용할 수 있다면 워크플로우 AI도 사용할 수 있어요.
