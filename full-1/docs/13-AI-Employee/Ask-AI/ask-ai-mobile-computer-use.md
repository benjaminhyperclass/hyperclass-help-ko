# 모바일 앱에서 AI에게 문의 컴퓨터 사용하기

하이퍼클래스 모바일 앱에서 **AI에게 문의**(Ask AI)의 **컴퓨터** 기능을 쓸 수 있어요. 휴대폰으로 작업을 시작하고, 브라우저가 움직이는 모습을 지켜보다가 필요할 때 직접 제어할 수 있어요. 작업 승인, 안전한 로그인, 파일 관리, 기기 간 이어서 작업하기도 가능해요. 이 문서에서는 모바일에서 쓸 수 있는 기능과 제어 방법을 안내해요.

웹에서 쓰는 방법은 [하이퍼클래스에서 AI에게 문의 컴퓨터 사용하기](../../44-신기능-2026/how-to-use-ask-ai-computer-in-hyperclass.md)를 참고하세요.

## 모바일에서 쓰는 컴퓨터란?

컴퓨터는 **AI에게 문의**가 개인 전용 클라우드 컴퓨터를 쓸 수 있게 해 주는 기능이에요. 이 클라우드 컴퓨터에는 Chrome 브라우저, 터미널, 파일 관리자가 있어요. 컴퓨터는 웹사이트 탐색, 폼 작성, 코드 실행, 파일 생성을 대신 해 줘요.

모바일은 웹에서 쓰는 것과 같은 클라우드 컴퓨터에 연결돼요. 휴대폰에서 바로 작업을 확인하고, 데스크톱 화면을 조작하고, 작업을 관리할 수 있어요.

### 모바일에서 쓰면 좋은 점

자리를 지키지 않아도 브라우저 기반 작업을 처리할 수 있어요.

- 어디서든 작업: 휴대폰에서 컴퓨터 작업을 시작하고 진행 상황을 확인해요.
- 직접 제어: 실시간 브라우저를 직접 조작하고, 끝나면 제어권을 AI에게 돌려줘요.
- 안전한 접근: 채팅에 비밀번호를 알리지 않고 작업을 승인하고 로그인해요.
- 파일 관리: 파일을 첨부하고, 결과물을 내려받고, 컴퓨터 활동을 확인해요.
- 기기 간 이어서 작업: 웹에서 시작한 컴퓨터 대화를 이어서 해요.

### 사용 전에 알아 둘 점

모바일의 컴퓨터는 기존 에이전시·서브 계정 접근 권한을 그대로 따라요. 모바일용으로 따로 설정할 것은 없어요.

- 액세스: 컴퓨터를 쓰려면 사용 가능한 서브 계정에서 Ask AI Level Up이 필요하고, 에이전시·서브 계정·사용자 수준의 해당 권한도 있어야 해요.
- 저장 공간: 사용자 한 명당 서브 계정 전체를 합쳐 컴퓨터 저장 공간 15GB를 쓸 수 있고, 파일 하나는 25MB까지 가능해요.
- 네트워크: 컴퓨터는 공용 인터넷에만 접속해요. 사설 네트워크에는 접속할 수 없어요.
- 앱 활동: 컴퓨터가 작업하는 동안에는 **AI에게 문의** 화면을 열어 두세요. 모바일 앱을 벗어나면 작업이 일시 중지돼요.

## 모바일에서 컴퓨터 시작하기

새 **AI에게 문의** 채팅에서 컴퓨터를 시작해요. 이미 있는 컴퓨터 대화는 **기록**에서 볼 수 있어요.

1. 하이퍼클래스 모바일 앱의 **서브 계정**에서 **App Drawer**(앱 서랍) > **AI에게 문의**를 열어요. 모바일 앱 전반의 사용법은 [하이퍼클래스 모바일 앱 사용 경험](../../30-모바일-데스크톱/hyperclass-mobile-app-experience.md)에서 볼 수 있어요.
2. **새 채팅 시작**을 탭해요.
3. **Ask anything...**(무엇이든 물어보세요) 메시지 입력란 위에 있는 **컴퓨터**를 탭해요.
4. 컴퓨터가 절전 상태이면 **켜기**를 탭해요.
5. 작업 내용을 입력하고 메시지를 보내요.

![모바일에서 컴퓨터를 시작하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084696658/original/w2gAqu_V0XJxCEvc32D44pY52mHHgmy-Kw.png?1793595630)

컴퓨터가 작업을 시작하면 대화 안에 진행 상황이 표시돼요. 작업을 다시 열려면 **AI에게 문의 > 기록 > 컴퓨터**로 이동하세요.

AI 어시스턴트에 대한 기본 설명은 [AI 어시스턴트 소개](../introduction-to-ask-ai-assistant.md)를 참고하세요.

## 컴퓨터 지켜보기와 직접 제어하기

컴퓨터는 실시간 데스크톱 미리보기와 현재 상태를 보여 줘요. 상태는 **작업 중**, **대기 중**, **완료**, **확인 필요**, **직접 제어 중** 중 하나로 표시돼요.

### 브라우저 보기와 제어하기

실시간 브라우저로 컴퓨터의 진행 상황을 지켜보다가, 직접 입력해야 하는 단계에서 개입할 수 있어요. 작업을 마치면 제어권을 AI에게 돌려줘야 작업이 이어져요.

1. **컴퓨터** 대화를 열고 **브라우저 열기**를 탭해요.
2. 데스크톱을 직접 조작해야 할 때 **제어권 가져오기**를 탭해요.
3. 화면을 탭해서 클릭하고, 두 손가락으로 끌어서 스크롤하고, 휴대폰 키보드로 입력해요.
4. 끝나면 **제어권 반환**을 탭해요.

그러면 AI가 직접 제어하기 직전 상태부터 이어서 작업해요.

![브라우저를 직접 제어하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084697033/original/sJojGOKOCGbpDE08GE0HyIey3Y68x92GqQ.png?1793596351)

### 컴퓨터가 작업하는 동안 다른 채팅 쓰기

컴퓨터가 실행되는 중에도 다른 **AI에게 문의** 채팅으로 옮겨 다닐 수 있어요. 실시간 상태 알림이 채팅을 옮겨 다녀도 따라와요.

알림을 탭하면 컴퓨터 대화로 돌아가요. 여러 작업을 동시에 실행하는 방법은 [AI에게 문의 멀티스레딩: 여러 작업을 한 번에 실행하기](ask-ai-multi-threading-run-multiple-tasks-at-once.md)를 참고하세요.

## 작업 승인과 비공개 로그인 관리

컴퓨터는 특정 작업을 하기 전에 먼저 사용자의 허락을 구해요. 웹사이트 로그인은 비공개 폼으로 진행돼서 로그인 정보가 **AI에게 문의** 대화에 남지 않아요.

### 컴퓨터 작업 승인하기

컴퓨터가 승인을 기다리며 멈추면 작업 카드를 확인하고 아래 중에서 선택해요.

- **승인**: 요청한 작업을 허용해요.
- **이 채팅에서 허용**: 화면에 표시된 권한을 30일 동안 저장해요.
- **거부**: 작업을 거절해요.

저장된 권한은 **설정 > 컴퓨터 사용 > Allowed actions**(허용된 작업)에서 확인하거나 취소할 수 있어요.

![승인, 이 채팅에서 허용, 거부 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084697090/original/yYimK0B3F5RkRC-O-Jm47cLEfPtn-Ev2ZQ.png?1793596440)

승인, 이 채팅에서 허용, 거부 옵션이에요.

### 안전하게 로그인하기

웹사이트에서 로그인 정보를 요구하면 이렇게 해요.

1. 비공개 로그인 폼에서 웹사이트 주소를 확인해요.
2. **이메일 또는 사용자명**과 **비밀번호**를 입력해요.
3. 원하면 **Save to Secure Store**(보안 저장소에 저장)를 켜요.
4. **로그인**을 탭해요.

**Take over to sign in**(직접 로그인하기)이나 **나중에**를 선택할 수도 있어요.

비공개 폼에 입력한 로그인 정보는 웹사이트로 바로 전달돼요. AI는 채팅에서 비밀번호를 볼 수 없어요.

![비공개 로그인 폼과 보안 저장소 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084697327/original/nnvpOon9yGWsdPToZG1-suAL2sZDWWH-NQ.png?1793596887)

비공개 로그인 폼과 **Save to Secure Store**(보안 저장소에 저장) 옵션이에요.

## 보안 저장소와 컴퓨터 설정 관리

하이퍼클래스 모바일 앱에서 **설정 > 컴퓨터 사용**을 열면 저장된 로그인 정보, 권한, 브라우징 데이터, 저장 공간을 관리할 수 있어요.

### 저장된 로그인 정보 관리하기

저장된 로그인 정보를 쓰면 로그인 정보를 **AI에게 문의** 채팅에 입력하지 않아도 컴퓨터가 웹사이트에 접속할 수 있어요. AI가 저장된 로그인 정보를 어떻게 쓸지에 맞춰 권한 수준을 정하세요.

**Let Ask AI use saved logins**(AI가 저장된 로그인 정보를 사용하도록 허용)에서 아래 중 하나를 선택해요.

- **없음**: 저장된 로그인 정보를 쓰지 않아요.
- **Ask**(확인 후 사용): 저장된 로그인 정보를 쓰기 전에 승인을 요청해요.
- **Allow on matching sites**(일치하는 사이트에서 허용): 주소가 일치하는 웹사이트에서 저장된 로그인 정보를 써요.

이 설정은 모든 서브 계정에 똑같이 적용돼요. 저장된 로그인 정보는 서브 계정마다 따로 관리되고, 비슷하게 생긴 가짜 사이트에는 비밀번호가 자동으로 채워지지 않아요.

로그인 정보를 추가하려면 이렇게 해요.

1. **저장된 로그인 정보** 아래에서 **Manage saved logins**(저장된 로그인 관리)를 탭해요.
2. 로그인 정보를 추가하는 옵션을 선택해요.
3. **URL**을 입력해요. **사용자명**은 선택 사항이고, **비밀번호**도 입력해요.
4. **저장**을 탭해요.

이미 저장된 로그인 정보는 편집하거나 삭제할 수도 있어요.

![로그인 정보 추가 폼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084697364/original/HUZe0Ct0WK0w7cTOTHocjBBmjkde67jhGA.png?1793596955)

로그인 정보 추가 폼이에요.

### 권한, 저장 공간, 브라우저 데이터 관리하기

컴퓨터 설정에서 저장된 데이터를 확인하고, 이전에 허용한 권한을 필요에 따라 취소할 수 있어요.

**컴퓨터 사용** 설정 화면에는 아래 항목도 있어요.

- **Clear browsing data**(브라우징 데이터 삭제): 브라우저 쿠키, 캐시, 방문 기록을 지워요.
- **Allowed actions**(허용된 작업) > **리뷰**: 저장된 권한을 하나씩 또는 한꺼번에 취소해요.
- **저장 공간**: 15GB 저장 공간 중 사용량을 확인해요.
- **프로필 초기화**: 선택한 서브 계정의 컴퓨터 데이터를 모두 지워요. 파일, 브라우저 기록, 저장된 로그인 정보, 터미널 기록, 활동이 포함돼요.

한 서브 계정의 컴퓨터 프로필을 초기화해도 다른 서브 계정에는 영향이 없어요.

![컴퓨터 사용 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084697473/original/AYXr36DCInNyi0M7GfbNGXSox83wXogtEw.png?1793597139)

**컴퓨터 사용** 설정 화면이에요.

## 파일 다루기와 활동 확인하기

컴퓨터는 첨부한 파일을 활용하고, 결과물을 만들고, 작업 중에 한 행동을 기록해요.

### 파일과 결과물

컴퓨터에 작업에 쓸 파일을 보내고, 완성된 결과물은 대화에서 받을 수 있어요. **파일** 시트에서 최근 파일을 찾고 저장 공간 사용량을 확인할 수 있어요.

컴퓨터 채팅에서 클립 아이콘(**파일 첨부**)을 탭하면 파일을 요청에 함께 보낼 수 있어요.

컴퓨터가 만든 스프레드시트, 문서, PDF는 파일 카드로 나타나요. 카드를 탭하면 결과물을 열거나 내려받을 수 있어요.

**파일** 시트에는 최근 파일 목록과 저장 공간 사용량 표시줄이 나와요.

![컴퓨터 채팅에 표시된 생성 파일 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084697833/original/llKFyPq4xzKFyr58mLmAOlvpjiF6Uqfxow.png?1793597706)

컴퓨터 채팅에 표시된 생성 파일 카드예요.

### 컴퓨터 활동

**활동** 시트에는 방문한 웹사이트, 실행한 명령어, 브라우저 제어권 변경 같은 컴퓨터의 행동이 시간순으로 기록돼요.

![컴퓨터 활동 기록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084697734/original/hWQWYi_JqvhZaUN8Mok5AO-oXfm2zoHPDA.png?1793597534)

컴퓨터 활동 기록이에요.

## 기기를 바꿔 가며 작업 이어가기

컴퓨터 대화는 웹과 모바일에서 함께 쓰여요. 이전 메시지를 확인하고, 열려 있는 데스크톱으로 돌아가고, 중단된 작업을 다시 시작할 수 있어요.

1. **AI에게 문의 > 기록 > 컴퓨터**를 열어요.
2. 웹에서 시작한 작업을 확인하려면 기존 대화를 선택해요.
3. 다른 기기에서 이미 데스크톱이 열려 있으면 **여기에 표시**를 탭해서 실시간 화면을 휴대폰으로 가져와요.

![컴퓨터 데스크톱을 기기 간에 전환하는 여기에 표시 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084698120/original/WdEc-wHei8cE2CrJJOWhv-Cw0J_fCXtpzQ.png?1793598169)

컴퓨터 데스크톱 화면을 기기 간에 옮기는 **여기에 표시** 버튼이에요.

컴퓨터는 작업 복구도 지원해요.

- **켜기**: 절전 중인 컴퓨터를 깨워요. 기존 파일과 저장된 로그인 정보는 그대로 유지돼요.
- 자동 재연결: 연결이 끊기면 컴퓨터가 다시 연결해요.
- **다시 시작**: 중단된 작업을 이어서 해요. 이 옵션은 나타날 때만 쓸 수 있어요.

## 자주 묻는 질문

### 컴퓨터가 내 휴대폰에 설치된 브라우저를 쓸 수 있나요?

아니요. 컴퓨터는 개인 전용 클라우드 데스크톱에서 Chrome을 실행해요. 휴대폰에서는 그 데스크톱을 보고 제어하는 거예요.

### 웹사이트에서 일회용 인증 코드를 요구하면 어떻게 하나요?

**브라우저 열기**를 탭하고 **제어권 가져오기**를 눌러요. 웹사이트에 코드를 직접 입력한 다음, 제어권을 AI에게 돌려주세요.

### 컴퓨터가 소프트웨어를 설치하거나 명령어를 실행할 수 있나요?

네. 컴퓨터는 명령어를 실행하고 지원되는 도구를 설치할 수 있어요. 소프트웨어를 설치할 때는 승인이 필요할 수 있어요.

### 컴퓨터를 한동안 쓰지 않으면 어떻게 되나요?

15분 동안 활동이 없으면 컴퓨터는 절전 상태가 돼요. 필요할 때 다시 깨울 수 있어요.
