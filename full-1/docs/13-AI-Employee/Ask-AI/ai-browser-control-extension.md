# AI에게 문의 브라우저 제어 확장 프로그램

**AI에게 문의** 어시스턴트가 내 브라우저를 직접 조작해서 페이지 열기, 클릭, 텍스트 입력, 폼 작성을 대신해 줘요. Chrome 기반 브라우저에서 안전하게 쓸 수 있어요. 이 문서에서는 **브라우저 제어**(Browser Control) 확장 프로그램이 하는 일, 보안 방식, 설치와 사용 방법을 설명해요.

## 브라우저 제어란?

**브라우저 제어**는 **AI에게 문의**가 웹 브라우저를 스스로 조작하도록 해 주는 확장 프로그램이에요. 방법만 알려 주는 대신, **AI에게 문의** 어시스턴트가 페이지 이동, 버튼 클릭, 폼 작성, 내용 읽기를 직접 해요. 이 모든 작업은 분리된 안전한 환경에서 이루어져요.

Chrome, Edge, Brave 같은 Chrome 기반 브라우저에서 쓸 수 있어요. 텍스트 대화와 음성 대화 모두에서 **AI에게 문의** 어시스턴트와 연결되며, 말로 요청한 내용을 브라우저 작업으로 실행해요.

모든 자동화 작업은 전용 탭 그룹에서 실행돼요. 이 탭 그룹은 내 개인 탭과 완전히 분리되어 있어서, 이미 열어 둔 세션과 데이터에는 영향이 없어요.

## 주요 장점

- 손 안 대고 작업 완료: 단순한 페이지 이동부터 복잡한 폼 제출까지, 여러 단계로 된 작업을 직접 개입하지 않아도 실행해요.
- 눈으로 보듯 상호작용: AI가 스크린샷으로 페이지를 읽고, 사람이 브라우저를 쓰듯 움직이는 커서로 좌표를 클릭해 조작해요.
- 전체 탐색 제어: 페이지 열기, 이동, 새로고침, 탭 전환, 페이지 닫기를 자동으로 해요. 동작마다 새 스크린샷이 돌아와서 결과를 확인할 수 있어요.
- 꼼꼼한 페이지 읽기: 페이지 텍스트, 콘솔 로그, 네트워크 요청을 확인해서 결과를 파악하고 다음 동작을 조정해요.
- 어디서나 동일하게 작동: 텍스트 채팅과 음성 대화에서 똑같이 작동해요.
- 실시간 활동 미리보기: 각 단계의 스크린샷이 미리보기 패널에 표시되어, AI가 일하는 모습을 실시간으로 볼 수 있어요.

## 브라우저 제어는 이렇게 작동해요

확장 프로그램은 좌표 기반 상호작용 방식으로, 사람이 쓰듯 웹페이지를 읽고 조작해요.

### 스크린샷으로 페이지 이해하기

**AI에게 문의** 어시스턴트가 웹페이지 스크린샷을 찍어 분석해요. 클릭할 수 있는 요소, 입력 필드, 버튼, 이동 옵션을 찾아서 사람처럼 페이지 구성을 파악해요.

### 여러 동작을 묶어서 실행하기

AI는 좌표 클릭, 텍스트 입력, 스크롤, 요소 드래그, 키보드 명령 전송 같은 동작을 묶어서 실행해요. 움직이는 커서가 AI가 어디를 조작하는지 보여 줘요.

### 자동 탐색

확장 프로그램이 브라우저 탐색을 모두 처리해요. 새 페이지 열기, 뒤로 가기와 앞으로 가기, 새로고침, 탭 전환, 끝난 작업 닫기를 해요. 탐색 동작마다 새 스크린샷이 자동으로 저장돼요.

### 결과 확인

**AI에게 문의** 어시스턴트는 페이지 텍스트를 읽고, 브라우저 콘솔 로그를 살피고, 네트워크 요청을 추적해요. 이렇게 동작이 제대로 끝났는지 확인하고, 복잡한 작업에서 다음에 할 일을 정해요.

### 실행되는 시점

텍스트 채팅에서 입력하든 음성 대화에서 말하든 **브라우저 제어**는 똑같이 작동해요. 원하는 작업을 말해 주기만 하면, **AI에게 문의** 어시스턴트가 브라우저 자동화가 필요한 때를 판단해요.

## 보안과 개인정보

**브라우저 제어** 확장 프로그램은 작업을 자동화하는 동안 데이터, 인증 정보, 브라우징 개인정보를 지키기 위해 여러 겹의 보안을 적용해요.

### 탭 분리

모든 자동화는 관리되는 세션 탭 그룹에서 실행되고, 내 개인 탭과 완전히 분리돼요. AI는 기존에 열려 있는 브라우저 탭, 창, 세션을 보거나 접근하거나 조작할 수 없어요.

### 안전한 폼 입력

폼에 인증 정보, 결제 정보, 개인정보가 필요하면 확장 프로그램이 내 기기에서 직접 입력을 요청해요. 입력한 값은 브라우저에 바로 채워지고, 백엔드로 전송되거나 AI 모델에 노출되지 않아요.

### 다시 로그인하지 않아도 되는 인증

확장 프로그램은 이미 로그인한 하이퍼클래스 세션으로 인증해요. 명령을 실행하기 전에 백엔드에서 확인하므로, 두 번 로그인하거나 인증 정보를 따로 관리할 필요가 없어요.

### 필요할 때만 연결

소켓 연결은 브라우저 작업이 실제로 실행되는 동안에만 열리고, 작업이 끝나면 바로 닫혀요. 작업 중에 연결이 끊어져도 자동 복구 기능이 데이터 손실 없이 세션을 되살려요.

### 개인정보를 우선하는 설계

브라우징 데이터, 개인 탭, 민감한 인증 정보는 내 기기에 남아 있어요. AI는 요청한 작업을 끝내는 데 필요한 정보만 받아요.

### 작업이 저절로 끝나는 모습 보기

실시간 스크린샷 미리보기로 **AI에게 문의** 어시스턴트가 내 브라우저에서 무엇을 하는지 그대로 볼 수 있어요.

## 설치하고 사용하기

확장 프로그램을 설치하고 **AI에게 문의** 어시스턴트와 연결하면 몇 분 안에 시작할 수 있어요.

1. 확장 프로그램을 설치해요.
   - Chrome 웹 스토어 또는 사용 중인 브라우저의 확장 프로그램 마켓에서 "Ask AI Browser Control"을 검색하세요.
   - **Add to Chrome**(Chrome에 추가) 버튼을 클릭해 설치하세요. 다른 브라우저에서는 그에 해당하는 버튼을 누르세요.
2. 브라우저에서 하이퍼클래스를 열어요. 하이퍼클래스 계정에 접속해서 로그인한 상태인지 확인하세요. 확장 프로그램이 현재 로그인한 세션으로 자동 인증하므로 별도의 인증 정보는 필요 없어요.
3. 확장 프로그램을 연결해요.
   1. 브라우저 도구 모음에서 **브라우저 제어** 확장 프로그램 아이콘을 클릭하세요.
   2. 팝업에 연결 상태가 표시돼요. 하이퍼클래스에 로그인한 상태라면 **연결 대상** 문구가 나타나요.

   ![브라우저 제어 확장 프로그램 팝업에서 연결 상태를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077601282/original/WSA3ukt1zZaWucTG3cY520MtNks1WSz-fQ.png?1785851795)

4. **AI에게 문의**에 브라우저 작업을 요청해요.
   1. **AI에게 문의**를 텍스트 채팅으로 열거나 음성 대화를 시작하세요.
   2. 원하는 작업을 설명하세요. 예를 들어 "곧 열릴 웨비나용 이벤트 사이트를 새로 만들어 줘", "호스팅 가입 폼을 대신 작성해 줘"처럼 말하면 돼요.
   3. 브라우저 자동화가 필요하다고 판단되면 **AI에게 문의** 어시스턴트가 단계를 자동으로 실행해요.

   ![AI에게 문의에 브라우저 작업을 요청한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077601372/original/7wIxHwkhtZP_21T4qjcquOEOTez0zHat4g.png?1785851836)

5. 진행 상황을 실시간으로 확인해요. **AI에게 문의** 어시스턴트가 일하는 동안 각 단계의 스크린샷이 채팅 미리보기 패널에 표시돼요. AI가 페이지를 이동하고, 요소를 클릭하고, 폼을 채우는 모습을 볼 수 있어요. 움직이는 커서는 각 페이지에서 AI가 어디를 조작하는지 보여 줘요.

{% hint style="info" %}
확장 프로그램은 작업을 실행하는 동안에만 연결을 열어요. 작업이 끝나면 네트워크 노출과 브라우저 리소스 사용을 줄이기 위해 연결이 자동으로 닫혀요.
{% endhint %}

## 자주 묻는 질문

### 브라우저 제어는 어떤 브라우저를 지원하나요?
**브라우저 제어** 확장 프로그램은 Google Chrome, Microsoft Edge, Brave를 포함한 모든 Chromium 기반 브라우저를 지원해요. Firefox와 Safari는 현재 지원하지 않아요.

### AI에게 문의가 내 개인 탭에 접근할 수 있나요?
아니요. **브라우저 제어**는 관리되는 세션 탭 그룹에서만 작동하고, 이 탭 그룹은 내 개인 탭과 분리되어 있어요. AI는 이 전용 자동화 환경 밖의 탭을 보거나 접근하거나 조작할 수 없어요.

### 비밀번호나 결제 정보 같은 민감한 정보는 어떻게 처리하나요?
**AI에게 문의** 어시스턴트가 인증 정보나 결제 정보가 필요한 폼을 만나면, 확장 프로그램이 내 기기에 보안 입력창을 표시해요. 정보는 내 기기에서 직접 입력하고, 폼에 바로 채워져요. 백엔드로 전송되거나 AI 모델에 노출되지 않고, 이 값은 내 기기에만 남아요.

### 브라우저 제어를 음성 대화에서도 쓸 수 있나요?
네. **브라우저 제어**는 **AI에게 문의**의 텍스트 채팅과 음성 대화에서 똑같이 작동해요. 작업을 말로 설명하면 AI가 브라우저 자동화가 필요한 때를 판단해서 단계를 자동으로 실행해요.

### 브라우저 작업 중에 인터넷 연결이 끊기면 어떻게 되나요?
확장 프로그램에는 자동 복구 기능이 있어요. 작업 중에 연결이 끊기면 세션을 복원하고, 마지막으로 끝난 단계부터 이어서 하려고 시도해요. 복구에 실패하면 **AI에게 문의** 어시스턴트가 알려 주고, 작업을 처음부터 다시 시작할 수 있어요.

### AI에게 문의가 브라우저를 조작하는 동안 무엇을 하는지 볼 수 있나요?
네. 동작마다 스크린샷이 만들어져 채팅 미리보기 패널에 표시돼요. **AI에게 문의** 어시스턴트가 페이지를 이동하고, 요소를 클릭하고, 폼을 채우는 모습을 실시간으로 볼 수 있어요. 움직이는 커서가 각 페이지에서 AI가 조작하는 위치를 정확히 알려 줘요.

### 브라우저 제어 확장 프로그램 아이콘을 도구 모음에 계속 보이게 해 둬야 하나요?
아이콘이 도구 모음에 고정되어 있든 확장 프로그램 메뉴에 숨겨져 있든 확장 프로그램은 작동해요. 다만 아이콘이 보이면 필요할 때 연결 상태를 바로 확인하고 확장 프로그램이 켜져 있는지 점검하기 쉬워요.

### 쓰지 않을 때 확장 프로그램이 브라우저를 느리게 만드나요?
아니요. **브라우저 제어** 확장 프로그램은 **AI에게 문의**로 요청한 작업을 실행하는 동안에만 연결을 열고 리소스를 사용해요. 작업이 끝나면 연결이 닫히고, 리소스를 거의 쓰지 않는 대기 상태로 돌아가요.
