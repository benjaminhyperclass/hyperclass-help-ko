# AI에게 문의에서 페이지 맥락 활용하기

**AI에게 문의**(Ask AI)는 지금 보고 있는 하이퍼클래스 화면의 정보를 활용해서 질문과 지시를 더 정확하게 이해해요. 화면에 보이는 내용을 자연스럽게 물어보고, 특정 요소를 직접 가리키고, 화면 위에서 시각 안내를 받을 수 있어요.

## 페이지 맥락이란?

페이지 맥락은 **AI에게 문의**가 지금 작업 중인 하이퍼클래스 화면의 정보를 이해하는 기능이에요. 하이퍼클래스 화면과 함께 **AI에게 문의**를 열어 두면, 요청이 현재 화면에 달려 있을 때 그 화면의 관련 정보를 활용해요. 페이지 맥락을 따로 켤 필요는 없어요.

카드, 필드, 행, 설정, 섹션을 일일이 설명하지 않아도 돼요. 화면에 이미 보이는 내용을 바탕으로 질문하면, **AI에게 문의**가 현재 화면을 보고 질문이 무엇을 가리키는지 파악한 뒤 답해요.

예를 들면 이렇게 물어볼 수 있어요.

- *"이게 뭐예요?"*
- *"이것들은 왜 목록에 있나요?"*
- *"이게 무슨 뜻이에요?"*
- *"여기서 도와주세요."*
- *"이 섹션을 설명해 주세요."*

특정 부분에 집중하게 하고 싶다면 화면 요소를 직접 선택해서 메시지에 붙일 수도 있어요.

{% hint style="info" %}
**AI에게 문의**를 플로팅 패널로 열었을 때도, **Split View**(분할 보기)로 열었을 때도 페이지 맥락을 쓸 수 있어요. 하이퍼클래스 화면이 함께 열려 있어야 하므로, 전체 화면 **AI에게 문의**에서는 쓸 수 없어요.
{% endhint %}

## 페이지 맥락의 장점

- 자연스럽게 질문하기: 보고 있는 내용을 하나하나 설명하지 않고 바로 물어볼 수 있어요.
- 설명 대신 가리키기: **AI에게 문의**가 살펴봤으면 하는 카드, 행, 필드, 설정, 섹션을 정확히 선택할 수 있어요.
- 더 정확한 도움 받기: 비슷한 요소가 여러 개 있는 화면에서도 **AI에게 문의**에 직접 맥락을 줄 수 있어요.
- 시각 안내 따라가기: 지원되는 안내에서는 **AI에게 문의**가 화면의 관련 영역을 강조해 줘요.
- 음성 요청에도 페이지 맥락 유지하기: 화면에서 요소를 선택한 뒤 **Voice Mode**(음성 모드)로 원하는 내용을 말하면 돼요.
- 민감한 정보 보호하기: 자격 증명과 민감한 필드는 화면 내용이 **AI에게 문의**로 전달되기 전에 가려져요.

## 페이지 요소 선택하기

페이지 요소 선택을 쓰면 **AI에게 문의**가 살펴봤으면 하는 부분을 정확히 가리킬 수 있어요. 카드, 행, 필드, 설정처럼 비슷한 요소가 많아서 일반적인 요청으로는 무엇을 말하는지 애매할 때 유용해요.

**페이지 요소 선택**은 전체 화면 **AI에게 문의** 화면과 전체 화면으로 확장한 사이드바에서는 쓸 수 없어요. 가리킬 하이퍼클래스 화면이 없기 때문이에요.

페이지 요소를 선택하려면 아래 순서대로 하세요.

1. **AI에게 문의** 입력창에서 **페이지 요소 선택**을 클릭하세요. Windows는 Ctrl + Shift + E, Mac은 Command + Shift + E를 눌러도 돼요.
   - 선택 모드가 켜져 있는 동안 Shift를 누르고 있으면 잠시 화면을 직접 조작할 수 있어요. 드롭다운을 열거나, 목록을 스크롤하거나, 모달 창에 들어갈 때 쓰면 돼요.
2. 포인터를 화면 위로 움직이면 선택할 수 있는 영역이 강조돼요. **AI에게 문의**가 살펴봤으면 하는 영역을 클릭하세요.
3. 필요하면 요소를 더 선택하세요. 메시지 하나에 화면 섹션을 최대 20개까지 붙일 수 있어요.
4. 입력창 위에 표시된 페이지 맥락 카드를 확인하세요.
5. 질문이나 요청을 입력하고 **AI에게 문의**에 보내세요.

선택한 항목은 입력창 위에 페이지 맥락 카드로 표시돼요. 카드를 클릭하면 화면에서 해당 위치가 다시 강조돼요. 선택한 항목을 하나씩 제거할 수도 있고, **전체 해제**를 클릭해 붙인 페이지 맥락을 모두 제거할 수도 있어요.

{% hint style="info" %}
붙인 선택 항목은 음성이 문자로 변환될 때까지 대기 상태로 남아 있어요. 그래서 요소를 가리킨 뒤 원하는 내용을 말하기만 하면 돼요. **AI에게 문의** 음성 컨트롤은 'AI에게 문의 음성 모드 사용 방법' 문서를 참고하세요.
{% endhint %}

## 강조 표시 안내 따라가기

**AI에게 문의**는 위치를 말로만 설명하지 않고 화면에서 직접 보여 줄 수 있어요. 시각 안내를 쓸 수 있을 때는 현재 하이퍼클래스 화면의 해당 위치를 바로 강조해 줘요.

여러 단계로 된 안내에는 다음이 포함될 수 있어요.

- 단계 카운터
- **이전**, **다음** 컨트롤
- 방향키 이동
- 끌어서 옮길 수 있는 안내 바

안내 바가 봐야 할 내용을 가리면 위치를 옮기세요. 화면이 바뀌어서 이전에 안내한 위치를 더 이상 정확히 찾을 수 없으면, **AI에게 문의**는 지난 화면 내용으로 안내하지 않고 해당 강조 표시가 오래되었다고 알려 줘요. 이때 관련 영역을 다시 선택해 달라고 요청할 수 있어요.

![강조 표시 안내를 따라가는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080910048/original/rCWY8zNxpe73gJgv_xaz_p-l46fdOZzcFw.gif?1789415219)

## 페이지 맥락과 음성 모드

페이지 요소 선택은 **AI에게 문의**의 **Voice Mode**와 함께 쓸 수 있어요. 요소를 선택한 다음 **Voice Mode**를 시작하고 **AI에게 문의**가 해 줬으면 하는 일을 말하세요. 말한 내용이 문자로 변환되는 동안 선택한 페이지 항목이 대기 상태로 남아서, 선택한 정보가 음성 요청과 함께 전달돼요.

예를 들어 필드나 섹션을 선택한 뒤 이렇게 물어보면 돼요.

*"이건 무슨 역할을 하나요?"*

음성 컨트롤은 'AI에게 문의 음성 모드 사용 방법' 문서를 참고하세요.

## AI에게 문의가 변경하기 전에 받는 승인

**AI에게 문의**는 페이지 맥락으로 요청의 뜻을 이해하지만, 그 맥락만 보고 지원되는 변경 작업을 자동으로 실행하지는 않아요. 만들거나, 업데이트하거나, 삭제하거나, 취소하거나, 일정을 변경하거나, 보내거나, 게시하거나, 지원되는 일괄 작업을 수행하는 요청은 실행 전에 반드시 직접 승인하는 단계에서 멈춰요.

요청이 변경 작업으로 이어지면 **AI에게 문의**는 실행하려는 작업을 정확히 보여 줘요. 이때 **승인**해서 계속 진행하거나, 실행 전에 제안된 계획을 **편집**하거나, 작업을 **거절**하고 **AI에게 문의**로 되돌릴 수 있어요.

화면 내용만으로는 해석이 여러 가지일 수 있어요. 그럴 때는 승인 요청을 보여 주기 전에 의도한 항목을 먼저 선택해 달라고 물어볼 수 있어요.

질문, 설명, 시각 안내는 승인이 필요 없어요.

## 개인정보와 페이지 맥락

하이퍼클래스는 화면 정보를 **AI에게 문의**의 맥락으로 쓰기 전에 보호 장치를 적용해요.

- 민감한 필드 가림: 자격 증명과 민감한 필드는 화면 내용이 **AI에게 문의**로 전달되기 전에 가려져요.
- 가림 표시 안내: 민감한 정보를 가렸을 때는 **AI에게 문의**가 그 사실을 알려 줘요.
- 큰 화면 내용: 화면 내용이 지원되는 맥락 한도를 넘으면 **AI에게 문의**가 추출한 정보를 잘라 낼 수 있어요. 잘라 냈을 때도 그 사실을 알려 줘요.

## 활용 사례

#### 대시보드 지표 분석하기

지금 살펴보는 대시보드 지표에 대해 **AI에게 문의**로 쉽게 물어볼 수 있어요.

일반적인 질문은 페이지 맥락에 맡기고, 대시보드의 한 부분에 집중하게 하고 싶다면 특정 지표를 선택하세요.

예를 들어 이렇게 요청할 수 있어요.

- *"내 비즈니스를 개선할 방법을 설명해 주세요."*
- *"이 지표는 무슨 뜻인가요?"*

#### 캘린더와 예약 배정 관리하기

캘린더 작업에서는 예약, 필터, 설정, 예약 세부 정보를 한꺼번에 다룰 때가 많아요. **AI에게 문의**는 보고 있는 정보를 이해한 상태에서 도와줘요. 화면의 한 부분에 집중하게 하고 싶다면 특정 예약, 필터, 설정, 섹션을 선택하세요.

예를 들어 이렇게 요청할 수 있어요.

- *"오후 2시부터 4시까지 내 캘린더를 막아 줘."*
- *"John Smith와 새 미팅을 만들어 줘."*

#### 플랫폼 설정 빠르게 마치기

**AI에게 문의**는 지금 작업 중인 설정과 옵션을 설명해서 셋업과 구성 작업을 도와줘요.

예를 들어 이렇게 요청할 수 있어요.

- *"이 설정은 어떤 역할을 하나요?"*
- *"여기서 도와주세요."*
- *"이 화면에서 선택한 요소를 설명해 주세요."*
- *"바꾸기 전에 이 옵션을 설명해 주세요."*

더 정확한 설명이 필요하면 특정 필드를 선택하세요. 시각 안내를 쓸 수 있을 때는 강조 표시 안내를 따라가도 돼요.

## 자주 묻는 질문

### 페이지 맥락을 따로 켜야 하나요?
아니요. 지원되는 하이퍼클래스 화면과 함께 **AI에게 문의**를 열어 두면, 요청이 현재 화면에 달려 있을 때 **AI에게 문의**가 화면 정보를 활용해요.

### 페이지 맥락을 쓰려면 AI에게 문의를 Split View로 열어야 하나요?
아니요. 플로팅 패널로 열었을 때도 페이지 맥락을 쓸 수 있어요. **Split View**는 패널 배치를 바꿀 뿐 페이지 맥락에 꼭 필요하지 않아요. 전체 화면 **AI에게 문의** 모드에서는 맥락을 가져올 화면이 없어서 페이지 맥락이 적용되지 않아요.

### 페이지 요소는 언제 직접 선택하면 좋나요?
넓은 화면 맥락에 맡기는 대신 특정 카드, 행, 필드, 설정, 섹션에 **AI에게 문의**가 집중하게 하고 싶을 때 페이지 요소 선택을 쓰세요.

### 페이지 요소를 몇 개까지 선택할 수 있나요?
메시지 하나에 화면 섹션을 최대 20개까지 붙일 수 있어요.

### 전체 화면 AI에게 문의에서도 페이지 맥락을 쓸 수 있나요?
아니요. 페이지 맥락에는 하이퍼클래스 화면이 필요해요. 전체 화면 **AI에게 문의**와 **AI에게 문의**를 전체 화면으로 확장했을 때는 쓸 수 없어요.
