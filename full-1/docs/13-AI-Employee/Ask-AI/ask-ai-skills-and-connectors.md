# Ask AI 스킬과 커넥터

**AI에게 문의**(Ask AI)를 자주 쓰는 앱과 연결하고, 내가 일하는 방식을 가르치는 방법을 안내해요. 어떤 도구를 쓸지, 어떤 지침을 따를지 모두 직접 정할 수 있어요.

## 이 문서에서 배울 내용

Ask AI 커넥터를 쓰면 Notion, Canva, GitHub, HubSpot 같은 앱이나 Model Context Protocol(MCP) 앱을 Ask AI에 바로 연결할 수 있어요. 인증은 한 번만 하면 돼요. 앱별 또는 도구별로 권한을 정하면 Ask AI가 내 계정 안에서 작업해요. 로그인 정보는 노출되지 않아요.

Ask AI 스킬은 내가 원하는 작업 방식을 지침으로 저장해 두는 기능이에요. 직접 지침을 쓰거나 이미 있는 플레이북·SOP를 업로드할 수 있어요. 요청이 스킬과 맞으면 Ask AI가 자동으로 적용해요. 텍스트 대화와 음성 대화에서 `/` 명령어로 직접 불러올 수도 있어요.

## 커넥터란?

커넥터를 연결하면 Ask AI가 이미 쓰고 있는 앱 안에서 작업할 수 있어요. Notion, Canva, GitHub, HubSpot은 물론 Model Context Protocol(MCP) 마켓플레이스에 있는 앱도 연결할 수 있어요. 인증은 서브 계정이 아니라 내 로그인으로 해요. 연결된 서비스에서 Ask AI가 나 대신 읽고, 만들고, 수정하고, 검색해요.

커넥터는 회사 안의 내 사용자 계정에 연결돼요. 그래서 로그인 정보와 도구 선택이 에이전시나 서브 계정의 경계를 넘어 다른 곳으로 새지 않아요.

- **Ask AI 안의 마켓플레이스 탐색**: **커스터마이징 > 커넥터 > 커넥터 관리**를 열면 Ask AI를 나가지 않고도 MCP 앱을 찾아 연결할 수 있어요.
- **앱별·도구별 제어**: 커넥터 전체를 켜고 끌 수 있어요. AI가 쓸 수 있는 도구도 골라 정할 수 있어요(예: "페이지 만들기", "데이터베이스 검색").
- **마켓플레이스와 양방향 동기화**: 하이퍼클래스 어디에서든 앱을 연결하면 Ask AI에도 나타나서 바로 쓸 수 있어요. 이름이 바뀌거나 아이콘이 새로 바뀌어도 자동으로 반영돼요. 내가 정한 활성화 상태와 도구 선택은 그대로 유지돼요.
- **브라우저 제어 커넥터**: **브라우저 제어** 커넥터를 켜면 Ask AI가 Chrome, Edge, Brave, Arc에서 페이지를 열고, 클릭하고, 폼을 채우고, 여러 단계로 된 작업을 처리해요. Ask AI Chrome 확장 프로그램이 필요해요.

## 스킬이란?

스킬은 Ask AI에게 내가 원하는 작업 방식을 알려 주는 기능이에요. 스킬은 이름이 붙은 지침 모음이에요. 요청이 스킬과 맞으면 Ask AI가 적용해요. 입력창에 `/스킬이름`을 입력해서 직접 불러올 수도 있어요. 스킬은 텍스트 대화와 음성 대화 모두에서 작동해요.

스킬은 처음부터 직접 쓸 수 있어요. 이미 있는 마크다운 플레이북을 업로드하거나, 대화하다가 Ask AI에게 만들어 달라고 할 수도 있어요. 저장하면 스킬이 내 개인 라이브러리에 추가되고, 관련 요청이 들어올 때 자동으로 연결돼요.

- **스킬 작성**: **커스터마이징 > 스킬**에서 이름, 한 줄짜리 "사용 시점(use when…)" 트리거, Ask AI가 따라야 할 과정을 적은 마크다운 본문을 입력해요.
- **스킬 업로드**: .md 파일을 올리면 Ask AI가 파일을 읽고 이름을 붙인 뒤 요약해 줘요. 같은 파일을 두 번 올리면 기존 스킬을 덮어쓰지 않고 버전이 붙은 사본(예: "PDF Processing 2")을 만들어요.
- **필요할 때 직접 호출**: 입력창에 `/`를 입력하면 내 스킬 라이브러리가 보여요. 스킬을 하나 골라 메시지에 고정하면 자동 매칭 없이 그 스킬이 적용돼요.
- **활성화, 비활성화, 삭제**: 비활성화한 스킬은 라이브러리에 남아 있지만, 다시 활성화하기 전까지 Ask AI에게 보이지 않아요. 스킬을 영구 삭제할 수도 있어요.
- **스스로 관리되는 스킬**: "이걸 스킬로 저장해 줘"라고 하면 Ask AI가 스킬을 만들어요. 대화 도중 스킬이 잘못된 것으로 드러나면 Ask AI가 단계적으로 고쳐요. 이렇게 스스로 학습하는 워크플로우가 만들어져요.

![스킬 라이브러리 화면 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078134848/original/mrXn_a9G2sj22MNNiAXDOLxo-aITnquJyg.png?1786454006)

{% hint style="info" %}
**보안이 최우선이에요.** 로그인 정보는 저장되지 않고 AI에게도 보이지 않아요. Ask AI는 연결된 계정에 대한 참조 정보만 저장해요. 액세스 토큰은 호출할 때마다 새로 만들어지고, 저장되거나 기록되지 않아요.
{% endhint %}

## 앱 연결하기

새 커넥터를 Ask AI에 연결하고, 쓸 도구를 정하는 방법이에요.

1. Ask AI 사이드바의 **+** 아이콘을 클릭하고 **커넥터**를 선택해요.
2. **커넥터 관리**를 클릭해 MCP 앱 목록을 열어요. 검색하거나 스크롤해서 원하는 앱을 찾아요. Notion, GitHub, Canva, HubSpot, Cal.com 등이 있어요.

   ![MCP 앱 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078135225/original/uoppXEf_H2yu9SZRU6NEiNtT2TvUV5T30g.png?1786454111)

3. 앱을 선택하고 **연결**을 클릭해요. 해당 서비스의 인증 화면으로 이동해요. 인증이 끝나면 앱이 **연결된 앱** 목록에 나타나요.

   ![연결된 앱 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078135464/original/WZA1XBtJp0VYHaI2S68yrWpxrbZa1qn8NA.png?1786454187)

4. (선택) **연결된 앱**에서 앱 이름을 클릭하면 그 앱이 제공하는 도구 목록이 전부 보여요. **모든 도구**를 끄면 Ask AI가 쓸 동작만 하나씩 켤 수 있어요(예: **notion-search**, **notion-create-page**).
5. 앱 이름 옆의 토글을 **활성화됨**으로 바꿔요. 이제부터 Ask AI가 요청을 처리할 때 이 커넥터를 사용해요.

   ![커넥터를 활성화한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078135619/original/jZg98NjxdE8oXFmlYxn7DY4vTlDWhoAUgA.png?1786454246)

{% hint style="info" %}
**팁:** Ask AI 대화 화면 아래쪽 입력창의 **+** 메뉴에서도 커넥터 토글을 켜고 끌 수 있어요.
{% endhint %}

## 스킬 만들기와 업로드

스킬은 세 가지 방법으로 만들 수 있어요. Ask AI가 대신 써 주게 하거나, 이미 있는 문서를 업로드하거나, 직접 작성해요. 스킬은 만든 뒤에도 언제든 활성화, 비활성화, 삭제할 수 있어요.

### 방법 1: Ask AI로 만들기

1. 대화를 시작해서 내 작업 방식을 설명해요. 예를 들어 "이걸 스킬로 저장해 줘: PDF 보고서를 만들어 달라고 하면 다음 단계를 따라 줘…"라고 말해요. 그러면 Ask AI가 스킬 초안을 작성해요.
2. Ask AI가 보여 주는 스킬을 확인해요. 괜찮으면 확정해서 라이브러리에 추가하고, 더 다듬고 싶으면 자세한 내용을 알려 주세요.

### 방법 2: 스킬 파일 업로드

1. Ask AI 사이드바에서 **커스터마이징 > 스킬**을 클릭해요.
2. **스킬 업로드**를 클릭하고 마크다운 파일을 선택해요. Ask AI가 파일을 읽고 이름과 한 줄 요약을 제안한 뒤 라이브러리에 추가해요. 같은 파일을 두 번 올리면 버전이 붙은 사본(예: "Report Generation 2")이 만들어져요.

   ![스킬 파일 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078135891/original/of7La46H-Ro1D3Itya7x3xA14-4sJaVaiw.png?1786454353)

### 방법 3: 직접 작성

1. **커스터마이징 > 스킬**에서 **스킬 지침 작성**을 클릭해요.
2. 양식을 채워요. **이름**, 한 줄로 쓰는 **Use when…**(사용 시점) 트리거 설명, Ask AI가 따라야 할 전체 과정을 담은 **Markdown body**(마크다운 본문)를 입력해요.
3. **저장**을 클릭해요. 새 스킬이 라이브러리에 나타나고 기본으로 활성화돼 있어요.

### 스킬 관리

- **필요할 때 직접 호출**: Ask AI 입력창에 `/`를 입력하고 드롭다운에서 스킬을 선택해요. 선택한 스킬이 메시지에 고정되고 자동 매칭은 건너뛰어요.
- **비활성화 또는 삭제**: **커스터마이징 > 스킬**에서 스킬의 토글을 끄면 삭제하지 않고 Ask AI에게만 보이지 않게 할 수 있어요. 휴지통 아이콘을 클릭하면 영구 삭제돼요.
- **단계적 수정**: 대화 도중 스킬이 잘못된 결과를 내면 Ask AI가 그 자리에서 고칠 수 있어요. "작동하지 않았어요. 스킬을 이렇게 바꿔 줘…"처럼 피드백을 주면 Ask AI가 스킬 지침을 단계적으로 수정해요.

![스킬을 단계적으로 수정하는 대화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078135971/original/Euz__p9EYFw5K8T4VTeD4Yc0ZD44P8tqJQ.png?1786454401)

## 보안과 안정성

Ask AI 커넥터와 스킬은 기본적으로 안전하게 쓰도록, 흔히 생기는 오류에도 잘 버티도록 설계돼 있어요. 로그인 정보, 도구, 지침은 내 사용자 계정 범위 안에서만 쓰이고 조직 경계를 넘어 공유되지 않아요.

- **내 라이브러리는 나만의 것**: 스킬과 커넥터 설정은 회사 안의 내 사용자 계정 기준으로 저장돼요. 에이전시 범위와 서브 계정 범위는 서로 섞이지 않아요.
- **Ask AI에 로그인 정보가 없어요**: Ask AI는 연결된 계정에 대한 참조 정보만 저장해요. 액세스 토큰은 호출할 때마다 새로 만들어져요. 저장되지 않고, AI에게 보이지 않고, 기록되지도 않아요.
- **커넥터를 따로 실행해요**: 앱마다 분리되어 실행돼요. 연동 하나가 실패해도 그 차례에서만 제외되고, 나머지는 그대로 작동해요. 커넥터 하나가 고장 나도 대화는 멈추지 않아요.
- **연결을 스스로 복구해요**: 연결된 계정이 교체되거나 하이퍼클래스의 다른 곳에서 다시 연결되면, Ask AI가 정상적인 참조 정보를 찾아 저장된 설정을 알아서 고쳐요.
- **설계 단계부터 개인정보를 고려했어요**: 커넥터와 스킬 데이터는 다른 사용자, 서브 계정, 에이전시와 공유되지 않아요. 내 연결과 지침은 나만 볼 수 있어요.

## 자주 묻는 질문

### 커넥터와 스킬은 하이퍼클래스 모든 요금제에서 쓸 수 있나요?
커넥터와 스킬은 Ask AI에 포함된 기능이고, Ask AI는 하이퍼클래스의 모든 사용자가 쓸 수 있어요. 다만 마켓플레이스의 일부 MCP 앱은 자체 인증이나 구독 조건이 있을 수 있어요.

### 같은 앱을 여러 하이퍼클래스 계정에 연결할 수 있나요?
네. 커넥터는 사용자 단위라서 하이퍼클래스의 서브 계정이나 에이전시마다 다른 앱 계정을 연결할 수 있어요. 각 연결은 서로 독립적으로 분리돼 있어요.

### 커넥터 접근 권한을 해제하려면 어떻게 하나요?
**커스터마이징 > 커넥터**에서 커넥터를 끄거나 **커넥터 관리**에서 연결을 해제하세요. 타사 앱의 설정(예: Notion의 연동 페이지)에서도 접근 권한을 해제할 수 있어요.

### 스킬 파일을 두 번 업로드하면 어떻게 되나요?
Ask AI가 원본을 덮어쓰지 않고 숫자가 붙은 사본(예: "Report Generation 2")을 만들어요. 이후 어느 버전이든 활성화, 비활성화, 삭제할 수 있어요.

### 스킬을 팀과 공유할 수 있나요?
현재 스킬은 사용자 단위로 저장돼요. 공유하려면 스킬을 .md 파일로 내보내(마크다운 본문을 복사해서) 팀원이 자기 Ask AI 라이브러리에 업로드하게 하세요.

### Ask AI가 내 커넥터 로그인 정보를 학습에 사용하나요?
아니요. 커넥터 로그인 정보와 액세스 토큰은 기록되지 않고, AI 모델에게 보이지 않고, 학습에도 쓰이지 않아요. Ask AI는 도구 호출 결과로 돌아온 데이터만 보고, 그 데이터를 요청을 처리하는 데 사용해요.

### 브라우저 제어 커넥터가 무엇인가요?
**브라우저 제어**는 Ask AI가 지원되는 Chromium 기반 브라우저(Chrome, Edge, Brave, Arc)에서 페이지를 열고, 클릭하고, 폼을 채우고, 여러 단계로 된 작업을 처리하게 해 주는 커넥터예요. 이 커넥터를 켜려면 Ask AI Chrome 확장 프로그램을 설치해야 해요.

### Ask AI는 어떤 스킬을 쓸지 어떻게 정하나요?
Ask AI는 내 요청을 활성화된 모든 스킬의 "사용 시점(use when…)" 트리거와 비교해요. 여러 스킬이 맞으면 가장 잘 맞는 스킬을 골라요. `/스킬이름`으로 스킬을 직접 호출하면 자동 매칭 대신 그 스킬을 쓸 수 있어요.
