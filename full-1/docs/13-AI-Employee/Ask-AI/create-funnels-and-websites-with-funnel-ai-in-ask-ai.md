# AI에게 문의에서 퍼널 AI로 퍼널·웹사이트 만들기

**AI에게 문의**(Ask AI)의 퍼널 AI를 쓰면 대화하듯 요청을 입력해 퍼널, 웹사이트, 랜딩 페이지를 만들 수 있어요. 빈 페이지에서 시작하거나 섹션을 하나씩 설정하지 않아도 돼요. 비즈니스와 목표를 알려 주면 페이지가 대화 화면 안에서 만들어지는 모습을 바로 볼 수 있어요. 요청 내용이 부족하면 **AI에게 문의**가 먼저 계획을 보여 주고, 확인을 받은 뒤에 만들기 시작해요.

## 퍼널 AI란?

퍼널 AI는 대화형 안내와 하이퍼클래스의 페이지 생성 도구를 합친 기능이에요. 아이디어를 편집 가능한 결과물로 더 빠르게 바꿀 수 있어요. 생성이 끝나면 결과물을 퍼널 빌더 또는 **웹사이트 빌더**에서 열어 추가로 수정하고, 도메인을 연결하고, 게시하고, 트래킹을 설정하고, 워크플로우를 쓸 수 있어요. 평소에 쓰던 방식 그대로예요.

예를 들어 이렇게 요청할 수 있어요.

> 우리 치과를 위한 리드 확보 퍼널을 만들어 줘.

요청에 정보가 충분하지 않으면 **AI에게 문의**가 생성을 시작하기 전에 비즈니스 유형이나 목표 같은 내용을 물어봐요.

## 퍼널 AI의 장점

퍼널 AI를 쓰면 아이디어를 쓸 수 있는 퍼널이나 웹사이트로 만드는 수고가 줄어요. 자연어로 요청하기 때문에 처음 페이지 구조를 직접 짜는 대신 원하는 비즈니스 성과에 집중할 수 있어요.

- 한 번의 요청으로 만들기: 필요한 퍼널, 웹사이트, 랜딩 페이지를 **AI에게 문의**에 바로 설명하면 돼요.
- 부족한 정보 안내받기: 처음 요청이 너무 포괄적이면 **AI에게 문의**가 빠진 정보를 물어봐요.
- 생성 전에 방향 확인하기: 추가 정보가 필요한 경우 **AI에게 문의**가 만들려는 내용을 짧은 계획으로 보여 줘요.
- 생성 과정을 실시간으로 보기: 라이브 미리보기 패널에 페이지가 만들어지는 모습이 나와요.
- 진행 상황 확인하기: 대화창의 체크리스트에 생성 단계가 끝나는 대로 표시돼요.
- 빌더에서 계속 편집하기: **Edit in Builder**(빌더에서 편집)를 선택하면 생성된 결과물을 열어 추가로 수정할 수 있어요.
- 하이퍼클래스 기본 기능 그대로 쓰기: 생성된 결과물은 일반 퍼널·웹사이트와 똑같이 동작해요. 게시, 도메인, 트래킹, 워크플로우 기능을 평소처럼 쓸 수 있어요.

## 사용 조건과 권한

퍼널 AI는 적절한 권한이 있고, 이 기능이 켜진 서브 계정에서 작업하는 사용자만 쓸 수 있어요. 이 조건을 알아 두면 접근 문제인지 생성 문제인지 구분하기 쉬워요.

**AI에게 문의**에서 퍼널 AI를 쓰려면 다음이 필요해요.

- 사용자에게 **Funnel & website AI**(퍼널 & 웹사이트 AI) 권한이 있어야 해요.
- 해당 서브 계정에서 퍼널 AI가 켜져 있어야 해요.

권한이 없으면 **AI에게 문의**는 생성을 시도하다 실패하는 대신, 이 기능을 쓸 수 없다는 안내 메시지를 보여 줘요.

사용자 권한에 대한 자세한 내용은 [서브 계정: 사용자 역할, 권한 및 배정 데이터](../../11-설정/사용자-설정/user-roles-permissions-and-assigned-data-subaccount.md)를 참고하세요.

## 퍼널 AI가 요청을 처리하는 방식

퍼널 AI는 **AI에게 문의**에 입력한 메시지의 정보를 바탕으로 무엇을 만들지 정해요. 비즈니스 유형과 목표를 분명하게 적으면 추가 질문이 줄고, 결과물도 의도한 용도에 더 잘 맞아요.

이런 결과물을 요청할 수 있어요.

- 리드 확보 퍼널
- 비즈니스 웹사이트
- 캠페인 랜딩 페이지
- 특정 서비스를 소개하는 페이지
- 프로모션 또는 전환 중심 퍼널

요청을 더 자세히 쓰려면 다음 내용을 넣어 보세요.

- 비즈니스 유형
- 타겟 고객
- 주요 목표
- 제공하는 오퍼 또는 서비스
- 원하는 전환 행동

예를 들면 이렇게 쓸 수 있어요.

> 주택 지붕 시공 업체를 위한 랜딩 페이지를 만들어 줘. 집주인이 무료 지붕 점검을 신청하게 하는 게 목표야.

요청이 너무 막연하면 **AI에게 문의**가 비즈니스 유형과 페이지 목표 같은 추가 정보를 물어볼 수 있어요.

## 계획 검토와 승인

제안된 계획을 먼저 확인하면 퍼널 AI가 원하는 내용을 제대로 이해했는지 생성 전에 확인할 수 있어요. 처음 요청에 추가 설명이 필요한 경우에 특히 유용해요.

**AI에게 문의**에 정보가 더 필요할 때는 이렇게 진행돼요.

1. **AI에게 문의**가 빠진 비즈니스 또는 목표 정보를 물어봐요.
2. 요청받은 정보를 입력해요.
3. **AI에게 문의**가 짧은 생성 계획을 보여 줘요.
4. 계획을 확인한 뒤 생성을 진행해요.

계획을 보면 페이지 유형, 비즈니스 맥락, 의도한 전환 목표를 퍼널 AI가 제대로 파악했는지 확인할 수 있어요.

## 라이브 생성 미리보기와 진행 체크리스트

생성하는 동안 퍼널 AI가 무엇을 하는지 직접 볼 수 있어요. 요청만 보내 놓고 아무 반응 없이 기다리지 않고, **AI에게 문의** 대화 안에서 만드는 과정을 따라갈 수 있어요.

생성 중에는 이렇게 보여요.

- 라이브 미리보기 패널에 만들어지는 페이지가 나타나요.
- 대화창의 체크리스트가 생성 단계를 하나씩 보여 줘요.
- 끝난 단계는 진행에 맞춰 표시돼요.
- 생성이 끝나면 완성된 결과물이 나타나요.

생성에는 보통 약 2~4분이 걸려요. 요청 내용에 따라 달라질 수 있어요.

## 생성된 퍼널·웹사이트 편집

**AI에게 문의**의 퍼널 AI는 처음 결과물을 만드는 역할을 하고, 생성 이후 편집은 퍼널 빌더 또는 **웹사이트 빌더**에서 해요. **AI에게 문의**가 첫 제작을 맡고, 하이퍼클래스의 모든 편집 기능은 그대로 쓸 수 있도록 역할을 나눈 거예요.

생성이 끝나면 **Edit in Builder**를 선택해 결과물을 열어요.

빌더에서는 이런 작업을 할 수 있어요.

- 텍스트와 이미지 수정
- 페이지 섹션 조정
- 레이아웃과 스타일 변경
- 폼이나 콜투액션 설정
- 페이지 설정 수정
- 게시 준비

**AI에게 문의**의 퍼널 AI는 현재 만들기만 할 수 있어요. 생성한 결과물을 수정하려면 빌더에서 열어야 해요.

하이퍼클래스의 AI 기반 페이지 제작 도구에 대한 자세한 내용은 [퍼널 & 웹사이트 AI](../../06-사이트/퍼널-웹사이트/funnel-website-ai.md)를 참고하세요.

## 게시, 도메인, 트래킹, 워크플로우

퍼널 AI로 만든 결과물은 일반 하이퍼클래스 퍼널이나 웹사이트가 돼요. 직접 만든 결과물과 같은 도구로 계속 설정할 수 있다는 뜻이에요. 생성은 처음 화면을 만들어 줄 뿐이고, 게시를 비롯한 운영 설정은 평소 하이퍼클래스 작업 방식 그대로 해요.

상황에 따라 이런 작업을 할 수 있어요.

- 알맞은 도메인 연결 또는 지정
- 퍼널이나 웹사이트 게시
- 트래킹 설정
- 폼과 전환 행동 연결
- 생성된 결과물과 연결된 워크플로우와 자동화 사용

**AI에게 문의**로 페이지를 만들었다고 해서 연결된 도메인에 자동으로 게시되는 것은 아니에요. 결과물을 외부에 공개하기 전에 게시 설정과 도메인 설정을 확인하세요.

자세한 내용은 다음 문서를 참고하세요.

- [퍼널과 웹사이트 저장, 초안, 게시](../../06-사이트/기타/save-draft-and-publish-funnels-and-websites.md)
- [하이퍼클래스 사이트의 루트 도메인 또는 서브도메인 설정](../../06-사이트/트러블슈팅/how-to-set-up-root-domain-subdomain-for-funnels-websites.md)

## 현재 제한 사항

현재 제한 사항을 알아 두면 알맞은 방법을 고르고, 결과물이 예상과 다르게 동작하는 상황을 피할 수 있어요.

**AI에게 문의**의 퍼널 AI에는 현재 다음 제한이 있어요.

- 만들기만 가능: **AI에게 문의**로 처음 퍼널, 웹사이트, 랜딩 페이지를 만들 수 있어요. 추가 수정은 퍼널 빌더 또는 **웹사이트 빌더**에서 해야 해요.
- WhatsApp 알려진 문제: WhatsApp으로 **AI에게 문의**를 이용해 만든 퍼널이 현재 빈 화면으로 생성될 수 있어요. 수정 작업이 진행 중이에요.
- 웹의 **AI에게 문의**는 영향 없음: WhatsApp 문제가 해결될 때까지는 웹에서 **AI에게 문의**를 사용해 퍼널을 만드세요.

## AI에게 문의에서 퍼널·웹사이트·랜딩 페이지 만들기

요청을 분명하게 쓰고 생성된 계획을 간단히 확인하면, 퍼널 AI가 비즈니스 목표에 맞는 결과물을 만들기 쉬워요. 만든 뒤에는 빌더에서 페이지를 다듬고 게시 관련 설정을 마무리하세요.

1. 하이퍼클래스에서 **AI에게 문의**를 열어요.
2. **메시지 입력**란에 만들고 싶은 내용을 설명해요.

   예시:

   > 우리 치과를 위한 리드 확보 퍼널을 만들어 줘.
3. **AI에게 문의**가 추가 정보를 요청하면 비즈니스 유형이나 목표 같은 내용을 알려 줘요.
4. **AI에게 문의**가 계획을 보여 주면 내용을 확인해요.
5. 계획을 승인해 생성을 시작해요.
6. 퍼널 AI가 결과물을 만드는 동안 진행 체크리스트를 확인해요.
7. 라이브 미리보기 패널로 생성되는 페이지를 살펴봐요.
8. 생성이 끝나면 완성된 결과물을 확인해요.
9. **Edit in Builder**를 선택해 알맞은 빌더에서 퍼널이나 웹사이트를 열어요.

   ![Edit in Builder 버튼이 표시된 생성 완료 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082621945/original/FqFpoRwjC9k9mFmgntkCk3Qg_h3ARpvAAQ.png?1791284057)
10. 필요에 따라 추가로 수정하고, 게시·도메인·트래킹·폼·워크플로우를 설정해요.

## 자주 묻는 질문

### AI에게 문의 대화에서 기존 퍼널을 수정해 달라고 할 수 있나요?

현재는 안 돼요. **AI에게 문의**의 퍼널 AI는 만들기만 할 수 있어요. 변경하려면 생성된 결과물이나 기존 결과물을 퍼널 빌더 또는 **웹사이트 빌더**에서 여세요.

### AI에게 문의에서 퍼널 AI가 보이지 않아요.

**Funnel & website AI** 권한이 있는지, 지금 사용하는 서브 계정에서 퍼널 AI가 켜져 있는지 확인하세요.

### 요청에 정보가 충분하지 않으면 어떻게 되나요?

**AI에게 문의**가 생성 계획을 보여 주기 전에 비즈니스 유형이나 페이지 목표 같은 추가 정보를 물어볼 수 있어요.

### 생성된 페이지를 직접 게시해야 하나요?

네. 생성된 결과물은 일반 하이퍼클래스 퍼널이나 웹사이트처럼 동작해요. 외부에 공개하기 전에 도메인과 게시 설정을 확인하세요.

### AI로 생성한 퍼널에도 워크플로우를 연결할 수 있나요?

네. 결과물이 일반 하이퍼클래스 결과물과 같기 때문에, 생성 후에 지원되는 트래킹, 폼, 워크플로우 같은 기본 기능을 쓸 수 있어요.

### WhatsApp으로 만들면 퍼널이 빈 화면이에요.

WhatsApp으로 **AI에게 문의**를 이용한 퍼널 생성에 알려진 문제가 있어요. 문제가 해결될 때까지는 웹에서 **AI에게 문의**를 사용하세요.
