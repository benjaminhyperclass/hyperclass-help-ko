# AI에게 문의 예약 작업으로 프롬프트 자동 실행하기

**AI에게 문의**의 예약 작업(Task Scheduler)을 쓰면 정해 둔 시간에 프롬프트가 자동으로 실행돼요. 매일 같은 질문을 입력하는 대신, 편한 때에 결과만 확인하면 됩니다.

## 예약 작업이란?

예약 작업(Task Scheduler)은 **AI에게 문의** 안에서 "무엇을, 언제 실행할지"를 정해 두는 기능이에요. 시간별, 매일, 매주, 평일에만, 또는 원하는 cron 시간으로 실행하도록 설정할 수 있어요. 작업을 예약해 두면 **AI에게 문의**가 백그라운드에서 프롬프트를 실행하고 결과를 실행 기록에 저장해요. 채팅 창을 열어 두지 않아도 나중에 결과를 확인할 수 있어요.

**AI에게 문의**는 하이퍼클래스 안에 있는 AI 작업 공간이에요. 자연어 프롬프트나 음성으로 콘텐츠를 만들고, 질문에 답을 얻고, 지원되는 작업을 바로 실행할 수 있어요. 예약 작업은 여기에 시간 기반 자동화를 더해서, 자주 쓰는 프롬프트를 항상 켜져 있는 어시스턴트처럼 쓰게 해 줘요.

---

## 예약 작업의 장점

반복되는 질문과 점검을 자동화해서 일상 업무에 수작업을 늘리지 않고도 필요한 정보를 받아볼 수 있어요.

- 매주 몇 시간씩 아낄 수 있어요: **AI에게 문의**에서 매번 직접 실행하던 일일 요약, 주간 파이프라인 리포트, 후속 조치 알림, 정기 점검을 자동화하세요.
- 필요한 시점에 인사이트를 받아요: "어제 새로 들어온 연락처를 요약해 줘"는 이른 아침으로, "주간 파이프라인 리포트를 보내 줘"는 팀 미팅 전 월요일로, "오늘 예약을 정리해 줘"는 퇴근 무렵으로 예약할 수 있어요.
- 손을 쓰지 않고도 일할 수 있어요(음성 포함): 출퇴근 중이나 미팅 사이처럼 키보드에서 떨어져 있을 때도 말로 지시해서 작업을 예약할 수 있어요. **AI에게 문의**는 이미 음성 입력을 지원해요.
- 여러 서브 계정을 한눈에 살펴볼 수 있어요: 에이전시는 지점별로 일일·주간 점검을 설정해 놓치거나 중단된 예약, 이탈, 정체된 기회를 리포트를 하나하나 뽑지 않고도 파악할 수 있어요.
- 새 팀원이 더 빨리 적응해요: 신규 직원은 첫날부터 예약된 AI 요약과 리포트를 받아, 숙련된 팀원과 같은 인사이트를 얻을 수 있어요. 모든 리포트와 화면을 다 익힐 필요가 없어요.
- 이미 쓰고 있는 AI를 더 활용해요: 같은 **AI에게 문의** 구독으로 예약된 인사이트가 24시간 돌아가서, 이미 비용을 내고 있는 AI의 성과를 더 높일 수 있어요.

## 예약 작업 작업 공간

예약 작업 작업 공간에서는 일정에 따라 실행되는 **AI에게 문의** 작업을 모두 만들고, 확인하고, 관리해요. 다음에 무엇이 실행되는지, 새 결과가 있는 작업이 어느 것인지 한눈에 볼 수 있어요.

**AI에게 문의** 작업 공간(에이전시 또는 서브 계정, 접근 권한에 따라 달라요)에는 보통 다음을 포함하는 **Scheduled Tasks**(예약 작업) 영역이 있어요.

- 작업 목록
  - 한 행이 예약 작업 하나예요.
  - 주요 열은 다음과 같아요.
    - **이름**: 예) "일일 신규 연락처 요약"
    - **발송 주기**: 예) **시간별**, **매일**, **평일**, **매주**, **Cron**, **One-time**(1회)
    - **Next run**(다음 실행): 다음 실행 날짜와 시간이에요. 내 지역 시간대로 표시돼요.
    - **상태**: **활성**, **일시 중지**, **취소됨** 중 하나예요.
    - **new result**(새 결과) 표시: 실행이 끝났지만 아직 열어 보지 않은 결과가 있을 때 나타나는 배지나 표시예요.

- 작업 액션
  - 각 작업에서 다음과 같은 **빠른 작업**을 쓸 수 있어요.
    - **지금 실행**
    - **일시정지** / **다시 시작**
    - **편집**
    - **삭제**

## 작업 주기

일정을 알맞게 고르면 아침 스탠드업 전, 고객 통화 전, 업무 시간 직후처럼 가장 유용한 때에 AI가 인사이트를 전달해 줘요.

예약 작업을 만들거나 편집할 때 다음 옵션 중에서 선택해요.

- **시간별**
  - 프롬프트를 한 시간마다 실행해요.
  - 거의 실시간에 가까운 모니터링에 좋아요. 예) "지난 한 시간 동안 실패한 예약을 확인해 줘."

- **매일**
  - 선택한 시간과 시간대에 하루에 한 번 실행해요.
  - "어제" 생성된 신규 연락처, 예약, 작업 같은 일일 대시보드에 알맞아요.

- **평일**
  - 선택한 시간에 월요일부터 금요일까지 실행해요.
  - 평일 파이프라인이나 리드 리포트처럼 업무일에만 필요한 요약에 알맞아요.

- **매주**
  - 선택한 요일과 시간에 실행해요. 예) 매주 월요일 오전 10:00
  - 주간 성과 점검, 캠페인 요약, 계정 상태 리포트에 알맞아요.

## 실행 기록과 결과 표시

실행 기록에는 **AI에게 문의**가 한 일이 모두 남아요. 성공한 실행, 실패, 건너뜀, 수동 실행이 모두 기록돼요.

각 작업은 시간순으로 정리된 **Run history**(실행 기록)를 보관해요. 여기서 할 수 있는 일은 다음과 같아요.

- 작업이 실행된 모든 시점 확인

- **성공**: 프롬프트가 실행되어 결과가 나왔어요.

- **실패**: **AI에게 문의**가 실행을 끝내지 못했어요. 예를 들어 권한이 없거나 일시적인 오류가 있을 때예요.

- **건너뜀**: 예약된 실행을 의도적으로 넘겼어요. 예) 예약 시각에 작업이 일시 중지 상태였던 경우

- 완료된 실행 열기

- 완료된 항목을 클릭하면 해당 실행에 연결된 **AI에게 문의** 세션 전체가 열려요.

- 요약, 리포트, 후속 작업(예: 보낸 이메일, 업데이트된 기회)을 다른 **AI에게 문의** 채팅과 똑같이 확인할 수 있어요.

- 새 결과 확인

- 실행이 끝났지만 아직 열어 보지 않았다면 **new result** 표시가 나타나요.

- 실행을 열면 자동으로 읽음 처리되고 배지가 사라져요. 새로 들어온 결과를 놓치지 않을 수 있어요.

이 기록을 보면 "어제 파이프라인 리포트가 실행됐나?", "지난 주간 점검에서 **AI에게 문의**가 정확히 무엇을 했지?" 같은 질문에 바로 답할 수 있어요.

## 작업 수명 주기: 활성, 일시 중지, 취소됨

작업 상태는 각 예약 작업이 어느 단계에 있는지 보여 줘요. 중요한 기록을 잃지 않고 작업을 안전하게 멈추거나 정리할 수 있어요.

- **활성**
  - 작업이 예약된 주기(**시간별**, **매일** 등)에 맞춰 실행돼요.
  - 새 실행이 기록에 추가되고, 열어 보기 전까지 **new result** 배지가 표시될 수 있어요.

- **일시 중지**
  - 작업이 예약된 시간에 실행되지 않고 잠시 멈춰요.
  - 일시 중지 중에 실행될 예정이던 것은 **건너뜀** 처리되고, 이 건너뜀 기록도 실행 기록에 표시돼요.
  - 일정을 다시 시작하려면 **다시 시작**을 누르세요.

- **취소됨** / **삭제됨**
  - 작업을 취소하거나 삭제하면 활성 목록에서 사라지고 앞으로의 실행이 모두 중단돼요.
  - 과거 실행 기록은 지원되는 범위에서 그대로 남아 있어요. 작업을 정리한 뒤에도 지난 결과를 확인할 수 있어요.

이런 구조 덕분에 부담 없이 써 볼 수 있어요. 시즌 캠페인용 작업을 만들고, 필요 없을 때 잠시 꺼 두고, 오래된 작업을 지워도 지난 인사이트는 남아요.

## **지금 실행**으로 수동 실행하기

다음 예약 시간까지 기다리고 싶지 않을 때가 있어요. **지금 실행**을 쓰면 기존 일정은 그대로 두고 원하는 때에 바로 실행할 수 있어요.

주요 동작은 다음과 같아요.

- 언제든 실행해요
  - 작업이 **활성**이든 **일시 중지**든 **지금 실행**을 클릭할 수 있어요.

- 새 **AI에게 문의** 세션으로 실행해요
  - 수동 실행은 새 세션을 사용하므로 이전 예약 실행과 결과가 독립적이에요.
  - 기록에는 수동 실행이 구분되어 표시돼서 예약 실행과 쉽게 구별할 수 있어요.

- 일정은 그대로예요
  - 반복 일정이 밀리거나 초기화되지 **않아요**.
  - 다음 예약 실행은 원래 정해진 시간에 그대로 이루어져요.

리포트 프롬프트를 방금 수정해서 새 결과를 바로 보고 싶을 때, 또는 예약된 리포트 시간 전에 경영진이 최신 데이터를 요청할 때 유용해요.

## 채팅과 음성으로 예약 작업 만들기

대화를 떠나지 않고도 예약 작업을 만들 수 있어요. 입력하거나 말한 자연어 프롬프트를 그대로 예약 작업으로 바꿀 수 있어요.

**AI에게 문의** 작업 공간은 이미 텍스트와 음성 프롬프트를 지원하므로, 자연어만으로 작업을 쉽게 만들고 관리할 수 있어요.

**AI에게 문의 채팅에서**

**AI에게 문의**와 대화하다가 한 번만 물어본 질문을 반복 작업으로 바꾸고 싶으면 그렇게 요청하면 돼요.

- 프롬프트 예시:
  - "평일 오전 9시마다 신규 연락처 요약을 실행해 줘."
  - "매주 월요일 오전 10시에 파이프라인 리포트를 보내 줘."
  - "6월 1일 오전 9시에 Sarah에게 체크인 알림 이메일을 보내 줘."

**AI에게 문의**가 요청을 해석해서 일정을 만들고 **Scheduled Tasks**에 자동으로 저장해요.

**음성 모드에서**

계정에서 음성 모드를 쓸 수 있다면 다음과 같이 해요.

1. **AI에게 문의**와 음성 대화를 시작해요.
2. 일정을 말로 요청해요. 예를 들면 다음과 같아요.
   - "평일 오전 9시마다 신규 연락처 요약을 줘."
3. **AI에게 문의**가 다음 실행 시간을 포함한 일정을 소리 내어 확인해 주고 **Scheduled Tasks**에 저장해요.

이동 중이거나 여러 일을 동시에 하느라 폼을 직접 설정하기 어려울 때 특히 편해요.

## 예약 작업 설정하기

설정을 제대로 해 두면 예약 작업이 안정적으로 실행되고, 프롬프트가 명확하며, 시간대도 알맞게 적용돼요. 아래에서 **Scheduled Tasks** 폼, 채팅, 음성으로 작업을 만드는 방법을 차례로 안내해요.

### 1. Scheduled Tasks 탭에서 작업 만들기

처음부터 일정과 프롬프트를 세부적으로 직접 정하고 싶을 때 쓰세요.

1. 상단 메뉴나 왼쪽 사이드바에서 **AI에게 문의**를 엽니다.
2. **Scheduled Tasks**로 이동합니다.
3. **+ 새 작업**을 클릭합니다.
4. 폼을 채웁니다.
   - **이름**
     - 작업을 알아보기 쉽게 설명하는 이름이에요. 예) "일일 신규 연락처 요약", "월요일 파이프라인 점검"
   - **프롬프트**
     - **AI에게 문의**가 실행할 지시문이에요. 예를 들면 다음과 같아요.
       - "어제 추가된 모든 신규 연락처를 요약하고, 유입 경로, 상태, 다음 단계를 강조해 줘."
       - "파이프라인에서 7일 동안 움직이지 않은 기회를 나열하고 다음 조치를 제안해 줘."
   - **발송 주기**
     - **Manually**(수동), **시간별**, **매일**, **평일**, **매주** 중에서 선택해요.
     <!-- 검토 필요: 원문 내용이 서로 다름 (소개·FAQ에는 Cron, One-time 옵션이 나오지만 폼 설명에는 없음) -->
5. **저장**을 클릭합니다.
   - 작업이 목록에 나타나고, **Next run** 시간이 내 지역 시간대로 표시돼요.

![새 작업 만들기 폼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071486978/original/ns_ZZIxFKvbgMI9PdOOKtWkyCw_ZId7atQ.png?1778950181)

### 2. AI에게 문의 채팅에서 작업 만들기

한 번 물어본 질문이 유용했다면, 대화를 떠나지 않고 예약 작업으로 바꿀 수 있어요.

1. **AI에게 문의**를 열고 채팅을 시작합니다.
2. 원하는 내용과 실행 주기를 함께 입력합니다. 예를 들면 다음과 같아요.
   - "평일 오전 9시마다 신규 연락처 요약을 실행해 줘."
   - "매주 월요일 오전 10시에 파이프라인 리포트를 보내 줘."
3. **AI에게 문의**가 일정을 해석하고 세부 내용을 확인한 뒤 **Scheduled Tasks**에 저장합니다.
4. **Scheduled Tasks**를 열어 새 항목을 확인합니다. 필요하면 이름이나 프롬프트를 수정하고, **Next run** 시간이 맞는지 확인하세요.

![채팅으로 작업 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071487174/original/mHxj3OpSdnnDzZz_LIsshHMqVdkgdErIWw.gif?1778950669)

### 3. 음성으로 작업 만들기

계정에서 음성 입력을 쓸 수 있다면 손을 쓰지 않고 작업을 설정할 수 있어요.

1. **AI에게 문의**와 음성 대화를 시작합니다.
2. 일정을 자연어로 말합니다. 예) "평일 오전 9시마다 신규 연락처 요약을 줘."
3. **AI에게 문의**가 일정과 다음 실행 시간을 다시 말해 주면 맞는지 확인합니다.
4. 나중에 **Scheduled Tasks**에서 프롬프트나 일정을 필요한 만큼 다듬습니다.

![음성으로 작업 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071487667/original/fWqhVMnVI_AtCU_W8lqBeE0RHC449cOpEQ.gif?1778951950)

### 4. 기존 작업 관리하기

작업을 만든 뒤에는 업무 흐름에 맞게 계속 조정하세요.

- **일시정지** / **다시 시작**
  - 휴일이나 캠페인 사이처럼 리포트가 필요 없을 때 **일시정지**하세요.
  - **다시 시작**을 누르면 일정이 다시 시작돼요. 이후 예정된 실행은 평소대로 이루어져요.

- **편집**
  - **이름**, **프롬프트**, **발송 주기**를 언제든 수정할 수 있어요.
  - 다음 예약 실행부터 새 값이 자동으로 적용돼요.
  - 수정 전에 만들어진 백그라운드 작업 중 충돌할 수 있는 것은 문제없이 건너뛰므로, 변경하는 동안 중복 실행이 일어나지 않아요.

- **지금 실행**
  - 기본 일정을 바꾸지 않고 즉시 한 번만 실행하고 싶을 때 쓰세요.

- 실행 기록 보기
  - 과거 실행을 열어 점검하거나, 문제를 해결하거나, 시간에 따른 결과를 비교할 수 있어요.

- **삭제**
  - 더 이상 필요 없는 작업을 제거해요.
  - 앞으로의 실행은 취소되고, 작업은 활성 목록에서 사라져요.

## 자주 묻는 질문

### 예약 작업을 쓰려면 특정 요금제나 애드온이 필요한가요?
**AI에게 문의**는 에이전시 관리자/사용자와, Unlimited AI 직원 플랜을 쓰는 서브 계정 관리자/사용자가 사용할 수 있어요. 예약 작업도 **AI에게 문의**와 같은 기준으로 제공돼요. 해당 계정에서 **AI에게 문의**를 열 수 있고 **Scheduled Tasks** 영역이 보이면 예약 작업을 쓸 수 있어요.

### 예약 작업의 결과는 어디에서 보나요?
모든 결과는 **AI에게 문의 > Scheduled Tasks**의 작업별 **Run history**에 저장돼요. 완료된 실행을 클릭하면 연결된 **AI에게 문의** 세션이 열려서 전체 결과를 확인할 수 있어요.

### 작업이 실행되면 이메일이나 알림이 자동으로 오나요?
기본적으로 예약 작업은 프롬프트를 실행하고 결과를 저장하는 일만 해요. 프롬프트에서 **AI에게 문의**에 알림이나 이메일 발송을 직접 지시하고, 계정에 필요한 메시지 기능이 설정되어 있을 때만 알림이나 이메일이 나가요.

### 예약된 실행도 AI 사용량과 요금에 포함되나요?
네, 포함돼요. 예약 실행 하나하나가 내부적으로는 **AI에게 문의** 세션이어서, 직접 요청했을 때와 똑같이 AI 사용량에 반영돼요. 세션이 어떻게 집계되고 비용이 계산되는지는 AI에게 문의 세션 요금 개요 문서를 참고하세요.

### 예약된 실행이 실패하거나 건너뛰어지면 어떻게 되나요?
해당 실행이 **Run history**에 **실패** 또는 **건너뜀**으로 표시돼요. 세부 정보가 있으면 항목을 열어서 무슨 일이 있었는지 확인하세요. 문제를 해결하거나 프롬프트를 조정한 뒤에 **지금 실행**을 사용하면 돼요.

### 여러 팀원이 같은 예약 작업을 관리할 수 있나요?
확인하고 관리할 수 있는 범위는 **AI에게 문의**와 서브 계정의 기본 권한을 따라요. **AI에게 문의**와 해당 계정에 접근할 수 있는 팀원은 보통 예약 작업을 보고 관리할 수 있어요. 단, 하이퍼클래스에서 각 팀원의 역할과 권한 설정에 따라 달라져요.

### 작업을 다시 만들지 않고도 시간대나 일정을 바꿀 수 있나요?
네, 바꿀 수 있어요. **편집**에서 주기, 시간, 시간대를 수정하세요. 다음 예약 실행부터 새 설정이 자동으로 적용되고, 편집하는 순간에 같은 작업이 두 번 실행되지 않도록 백그라운드 작업도 처리돼요.

### 꼭 Cron을 써야 하나요? 간단한 일정만 쓸 수도 있나요?
Cron은 선택 사항이고, 복잡한 시간 패턴이 필요할 때 쓰는 고급 옵션이에요. 대부분은 일반적인 업무 일정에 맞는 기본 옵션인 **시간별**, **매일**, **평일**, **매주**, **One-time**(1회)만으로 충분해요.
