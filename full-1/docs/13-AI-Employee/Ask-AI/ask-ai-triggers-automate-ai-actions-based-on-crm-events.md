# AI에게 문의 트리거로 CRM 이벤트에 맞춰 AI 작업 자동화하기

**AI에게 문의**(Ask AI)의 커스텀 스킬을 CRM에서 특정 이벤트가 생길 때 자동으로 실행되게 설정하는 방법을 설명해요. 직접 실행하지 않아도 연락처 생성, 폼 제출, 태그 추가, 예약 완료, 기회 상태 변경 같은 상황에서 스킬이 알아서 돌아가요.

이 문서에서는 트리거를 설정하는 방법, **AI에게 문의** 채팅에서 스킬을 바로 만드는 방법, **Trigger History**(트리거 기록)로 자동 실행 결과를 확인하는 방법을 다뤄요.

## AI에게 문의 트리거란?

트리거를 설정하면 CRM에서 특정 이벤트가 생길 때 커스텀 스킬이 자동으로 실행돼요. 사용자가 **AI에게 문의**에서 대화를 직접 시작하지 않아도, 새 연락처 생성·폼 제출·기회 상태 변경처럼 데이터가 바뀌는 순간 스킬이 시작돼요.

트리거가 작동하면 **AI에게 문의** 기능이 해당 이벤트의 CRM 정보(연락처 상세 정보, 폼 응답, 기회 데이터 등)를 바탕으로 연결된 스킬을 실행해요. 고객의 행동이나 파이프라인 변화에 바로 반응하는 자동화를 만들 수 있어요.

트리거는 정해진 시간이나 주기에 실행되는 예약 스킬과 함께 쓰면 좋아요. 두 가지를 합치면 시간 기반 상황과 이벤트 기반 상황을 모두 자동화할 수 있어요.

## 트리거로 얻는 이점

- 반복 업무 자동화 — 이벤트가 생길 때 스킬이 자동으로 실행되게 해서 수작업을 줄여요. 팀은 더 가치 있는 일에 집중할 수 있어요.
- 실시간 대응 — 연락처가 생성되거나 폼이 제출되거나 기회 상태가 바뀌면 바로 조치해서 후속 연락과 소통이 늦어지지 않게 해요.
- 한곳에서 모니터링 — 실행 상세 정보, 실행 상태, 그 결과로 생긴 **AI에게 문의** 세션까지 모든 자동 실행을 **Trigger History**(트리거 기록)에서 확인해요.
- 간단한 설정 — **AI에게 문의** 채팅에서 자동화 목표를 일상적인 말로 설명하면 스킬과 트리거를 바로 만들 수 있어요.
- 상황에 맞는 실행 — 트리거가 작동할 때 연락처 필드, 폼 응답, 기회 상세 정보 같은 관련 CRM 데이터가 스킬에 자동으로 전달돼요.

## 지원하는 트리거 이벤트

연락처, 폼, 설문, 태그, 예약, 기회, 리드 소스에서 생기는 다양한 CRM 이벤트를 트리거로 쓸 수 있어요.

- **Contact Created**(연락처 생성): 새 연락처가 CRM에 추가될 때 스킬을 실행해요. 환영 메시지를 보내거나, 온보딩 시퀀스를 시작하거나, 연락처 데이터를 자동으로 보강할 때 써요.
- **폼 제출**: 특정 폼이 제출될 때 스킬을 실행해요. 리드 수집 폼 처리, 후속 일정 잡기, 제출 내용을 알맞은 팀에 전달하는 일에 잘 맞아요.
- **Survey Submitted**(설문 제출): 설문이 완료될 때 스킬을 실행해요. 설문 응답을 분석하거나, 만족도 점수를 계산하거나, 피드백에 따라 후속 작업을 시작할 때 써요.
- **Tag Added or Removed**(태그 추가 또는 제거): 연락처에 특정 태그가 추가되거나 제거될 때 스킬을 실행해요. 연락처 속성이나 라이프사이클 단계별로 워크플로우를 나누기에 좋아요.
- **예약 완료** 또는 예약 상태 변경(Appointment Booked or Status Changed): 예약이 완료되거나 상태가 바뀔 때(확정, 취소, 일정 변경) 스킬을 실행해요. 알림 보내기, 기회 기록 업데이트, 팀원에게 알리기에 써요.
- **Opportunity Created or Status Changed**(기회 생성 또는 상태 변경): 새 기회가 만들어지거나 기회 상태가 바뀔 때(예: 새 파이프라인 단계로 이동) 스킬을 실행해요. 영업 워크플로우와 알림을 자동화하기에 좋아요.
- **Facebook Lead Received**(Facebook 리드 수신): Facebook Lead Ads에서 리드가 들어오면 스킬을 실행해요. 리드 데이터를 보강하거나, 바로 후속 메시지를 보내거나, 알맞은 팀원에게 리드를 배정할 때 써요.
- **Scheduled Execution**(예약 실행): 스킬을 일정에 맞춰 실행할 수도 있어요. 특정 날짜·시간, 주기, cron 표현식으로 지정하면 이벤트 기반 트리거와 함께 시간 기반 자동화도 만들 수 있어요.

## 트리거 설정하기

커스텀 스킬에 트리거를 설정하면, 지정한 CRM 이벤트가 생길 때 스킬이 자동으로 실행돼요.

1. 하이퍼클래스 계정에서 **AI에게 문의 > 커스터마이징 > 스킬**로 이동하세요. 계정에 설정된 커스텀 스킬이 모두 보여요.

   ![AI에게 문의 커스터마이징의 스킬 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080725637/original/iAmcunXejrzzaEWlObvU7dXnMNRx_K-uzg.png?1789135558)

2. 자동으로 실행하려는 커스텀 스킬을 클릭하세요. 아직 스킬이 없다면 **+ Add Skill**(스킬 추가)을 클릭해 목적, 지침, 동작을 정해서 새로 만드세요.

   ![자동 실행할 스킬을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080725710/original/_qByjNLE4Wyxjs1Q-oTKvJDmnEtmrgiZqQ.png?1789135601)

3. 스킬 설정에서 **트리거** 섹션을 찾아 **+ Add Trigger**(트리거 추가)를 클릭하세요.
4. 스킬을 시작할 이벤트 유형을 고르세요(예: **Contact Created**, **폼 제출**, **Tag Added or Removed**).

   ![스킬에 트리거를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080694873/original/idPd3dR00Wzv6FhBU00EAQApvNOKveuCKw.png?1789122469)

5. 이벤트 유형에 따라 추가 조건을 설정하세요. 예를 들어 **폼 제출**을 골랐다면 스킬을 실행할 폼을 지정하고, **Tag Added or Removed**를 골랐다면 태그 이름을 지정해요.
6. 트리거 토글을 **활성화됨**으로 바꾸세요. 활성화하면 설정한 이벤트가 생길 때마다 스킬이 자동으로 실행돼요.

{% hint style="info" %}
트리거가 켜졌어요. 이벤트가 생길 때마다 **AI에게 문의** 기능이 관련 CRM 정보를 사용해 스킬을 실행해요.
{% endhint %}

## AI에게 문의 채팅에서 스킬과 트리거 만들기

**커스터마이징** 메뉴로 이동하지 않고도 **AI에게 문의** 채팅에서 스킬과 트리거 설정을 한 번에 만들 수 있어요. 자동화 설정 과정이 더 간단해져요.

1. **AI에게 문의** 채팅을 열고 만들고 싶은 자동화를 일상적인 말로 설명하세요. 예: "새 연락처가 추가되면 환영 이메일을 보내는 스킬을 만들어 줘."
2. **AI에게 문의** 기능이 요청을 해석해서 스킬과 트리거 설정을 만들어요. 알맞은 이벤트 유형, 트리거 조건, 스킬 지침도 함께 제안해요.
3. 제안된 스킬과 트리거 설정을 확인하세요. 마무리하기 전에 지침을 다듬거나, 트리거 조건을 바꾸거나, 스킬 동작을 수정할 수 있어요.
4. 설정이 마음에 들면 확정하세요. 스킬이 저장되고 트리거가 활성화되어 바로 작동해요.

{% hint style="info" %}
**팁:** 안내를 받으며 설정하고 싶은 분께 잘 맞는 방법이에요. 나중에 **커스터마이징**에서 언제든 스킬과 트리거를 다듬을 수 있어요.
{% endhint %}

## 트리거 실행 확인하기

**Trigger History**(트리거 기록)에서 자동으로 실행된 스킬을 모두 확인할 수 있어요. 어떤 이벤트가 트리거를 작동시켰는지, 성공했는지, 그 결과로 생긴 **AI에게 문의** 세션이 무엇인지 볼 수 있어요.

**AI에게 문의 > Trigger History**로 이동하세요. 각 항목에는 다음 정보가 표시돼요.

- **Trigger Event**(트리거 이벤트): 스킬 실행을 시작시킨 CRM 이벤트예요(예: **Contact Created**, **폼 제출**).
- **Run Status**(실행 상태): 스킬 실행이 성공했는지, 실패했는지, 진행 중인지 보여 줘요.
- **Execution Details**(실행 상세 정보): 실행된 스킬, 전달된 정보, 수행된 작업에 관한 내용이에요.
- **Resulting Ask AI Session**(결과 AI에게 문의 세션): 스킬 실행으로 생긴 **AI에게 문의** 대화 로그로 가는 링크예요.

{% hint style="info" %}
**팁:** **Trigger History**에서 실패한 실행의 원인을 찾고, 트리거가 의도대로 작동하는지 확인하고, 자동화 워크플로우가 어떻게 돌아가는지 살펴보세요.
{% endhint %}

## 자주 묻는 질문

### 스킬 하나에 트리거를 여러 개 추가할 수 있나요?
네, 가능해요. 예를 들어 연락처가 생성되거나 특정 태그가 추가될 때 둘 중 하나만 일어나도 실행되는 스킬을 만들 수 있어요. 트리거는 각각 따로 작동해요.

### 트리거가 작동하면 스킬에 어떤 CRM 데이터가 전달되나요?
트리거가 작동하면 **AI에게 문의** 기능이 그 이벤트와 관련된 정보를 스킬에 전달해요. 예를 들어 **Contact Created** 트리거에는 연락처 필드가, **폼 제출** 트리거에는 폼 응답이 포함돼요. 스킬은 이 데이터를 바탕으로 작업해요.

### 트리거를 삭제하지 않고 잠시 꺼 둘 수 있나요?
네, 가능해요. 스킬 설정에서 트리거 토글을 꺼서 자동 실행을 멈출 수 있어요. 트리거 설정은 그대로 저장되어 있어서 언제든 다시 켤 수 있어요.

### 트리거 실행이 실패했는지 어떻게 알 수 있나요?
**Trigger History**에서 실행마다 실행 상태를 확인하세요. 실패한 실행은 오류 내용과 함께 기록돼서, 원인을 찾아 트리거나 스킬 설정을 고칠 수 있어요.

### 커스텀 스킬과 기본 스킬 모두 트리거를 쓸 수 있나요?
현재는 커스텀 스킬에서만 트리거를 쓸 수 있어요. **AI에게 문의**의 기본 스킬은 트리거 기반 자동화를 지원하지 않아요.

### 에이전시 계정의 모든 서브 계정에서 트리거가 함께 적용되나요?
트리거는 서브 계정 단위로 설정돼요. 서브 계정마다 스킬과 트리거가 따로 작동해요. 여러 서브 계정에서 같은 자동화를 쓰고 싶다면 각 서브 계정에서 트리거를 설정해야 해요.

### 트리거를 실제로 켜기 전에 테스트해 볼 수 있나요?
네, 가능해요. 계정에서 테스트 연락처를 만들거나, 테스트 폼을 제출하거나, 트리거가 되는 이벤트를 직접 일으켜서 스킬이 의도대로 실행되는지 확인할 수 있어요. 모든 이벤트에 트리거를 켜기 전에 **Trigger History**에서 실행 결과가 성공인지 확인하세요.

### 만들 수 있는 트리거 개수에 제한이 있나요?
설정할 수 있는 트리거 개수에 엄격한 제한은 없어요. 다만 **Trigger History**를 살펴보면서 자동화가 원활하게 돌아가고 워크플로우 요구 사항에 맞는지 확인하세요.
