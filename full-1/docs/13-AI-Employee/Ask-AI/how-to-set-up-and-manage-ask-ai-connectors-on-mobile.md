# 모바일에서 'AI에게 문의' 커넥터 설정하고 관리하기

하이퍼클래스 모바일 앱에서 외부 앱을 **AI에게 문의**에 바로 연결하는 방법을 안내해요. 연결된 계정 관리, **AI에게 문의**가 쓸 수 있는 도구 선택, 사용자 지정 MCP 서버 추가를 모두 컴퓨터 없이 할 수 있어요. 모바일과 웹의 연결 상태는 항상 같게 유지돼요.

## 모바일 커넥터란?

커넥터를 쓰면 **AI에게 문의**가 Model Context Protocol(MCP)로 지원되는 외부 앱과 연동돼요. 휴대폰에서 앱 연결, 계정 관리, **AI에게 문의**가 사용할 도구 선택까지 할 수 있어요. 자세한 소개는 [AI 어시스턴트 소개](../introduction-to-ask-ai-assistant.md)를 참고하세요.

커넥터는 **4.27.0 버전 이상**의 하이퍼클래스 모바일 앱(화이트라벨 모바일 앱 포함)에서, **'AI에게 문의' 액세스** 권한이 있는 사용자에게 제공돼요. 모바일 앱에 대한 설명은 [하이퍼클래스 모바일 앱 사용 가이드](../../30-모바일-데스크톱/hyperclass-mobile-app-experience.md)에서 볼 수 있어요.

## 모바일 커넥터의 장점

자리를 떠나 있어도 연결된 계정과 권한을 직접 관리할 수 있어요.

- **어디서나 연결:** 휴대폰에서 외부 앱을 추가하고 관리할 수 있어요.
- **권한 관리:** 앱마다 **AI에게 문의**가 쓸 수 있는 도구를 직접 골라요.
- **간편한 재연결:** 만료된 연결을 컴퓨터 없이 다시 연결할 수 있어요.
- **동기화:** 모바일과 웹에서 같은 연결을 쓸 수 있어요.
- **개인 정보 보호:** 연결한 계정은 연결한 사용자에게만 보여요.
- **사용자 지정 연동:** 호환되는 MCP 서버를 추가해 **AI에게 문의**의 기능을 넓힐 수 있어요.

## 연결됨 탭과 찾아보기 탭

**커넥터** 화면에는 탭이 두 개 있어요. 이미 연결한 앱을 관리하고, 새 앱을 찾을 때 써요.

- **연결됨:** 연결된 앱, 연결된 계정 수, 사용 설정된 도구를 보여 줘요.
- **찾아보기:** 연결할 수 있는 앱을 검색하고 **AI에게 문의**에 연결해요.

## 커넥터 계정과 도구 권한

커넥터마다 도구가 있고, 이 도구가 **AI에게 문의**가 연결된 앱에서 할 수 있는 작업을 정해요. 필요한 도구만 선택하면 연동을 더 안전하게 관리할 수 있어요.

- 앱 하나에 지원되는 계정을 하나 이상 연결해요.
- 도구를 하나씩 선택하거나 **전체 선택**을 탭해요.
- **Connector enabled**(커넥터 활성화) 토글을 켜 둬요.
- **저장**을 탭해 변경 사항을 적용해요.

{% hint style="warning" %}
- 커넥터를 활성화하려면 연결된 계정이 1개 이상, 선택한 도구가 1개 이상 있어야 해요.
- 도구 선택은 어떤 계정을 쓰든 앱 전체에 적용돼요.
- 연결된 계정은 비공개예요. 같은 서브 계정의 다른 사용자는 볼 수 없어요.
{% endhint %}

## 사용자 지정 MCP 서버

사용자 지정 MCP 서버를 쓰면 커넥터 목록에 없는 외부 서비스도 연결할 수 있어요. **AI에게 문의**가 쓸 수 있는 도구와 연동이 그만큼 늘어나요. 자세한 내용은 [새로운 MCP 커넥터](../../19-에이전시-뷰/new-mcp-connectors.md)를 참고하세요. 사용자 지정 서버를 설정할 때는 아래 정보를 입력해요.

- **Server Name**(서버 이름): 알아보기 쉬운 연결 이름이에요.
- **Server URL**(서버 URL): `https://` 또는 `http://`로 시작하는 URL이에요.
- **Authentication Details**(인증 정보): 필요한 경우 Client ID(클라이언트 ID)와 **클라이언트 시크릿**을 입력해요.
- **리다이렉트 URL**: 필요한 서비스에서 쓸 수 있도록 복사할 수 있는 URL이에요.

{% hint style="warning" %}
사용자 지정 MCP 서버를 삭제하면, 그 서버로 연결한 모든 계정도 영구적으로 삭제돼요.
{% endhint %}

## 모바일에서 커넥터 설정하기

앱을 선택하고, 계정을 인증하고, **AI에게 문의**가 쓸 도구를 켜면 설정이 끝나요.

1. 하이퍼클래스 모바일 앱을 열고 **AI에게 문의**로 이동하세요.
2. 오른쪽 위의 **채팅 기록** 아이콘을 탭하세요.
3. **커스터마이징 > 커넥터**를 탭하세요.

   ![커스터마이징 메뉴에서 커넥터를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084739663/original/b1iWHu9CoYXq92vkgUrKIw6sKLWj8q824g.png?1793622769)
4. **찾아보기** 탭을 열고 앱을 선택하세요.
5. **연결**을 탭하고 인증을 완료하세요.

   ![앱 연결 후 인증하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084745065/original/X93S6ZyTZUhWOnG-YluWegcE5SUuySEDiw.png?1793625813)
6. 연결된 계정을 선택하고, **AI에게 문의**가 쓸 도구를 고르세요.
7. **Connector enabled** 토글이 켜져 있는지 확인하세요.
8. **저장**을 탭해 설정을 마치세요.

연결이 끝나면 **AI에게 문의**로 돌아가 해당 앱의 도구로 가능한 요청을 보내 보세요.

{% hint style="warning" %}
- 커넥터는 서브 계정 단위로 설정돼요.
- 저장하지 않고 **뒤로**를 탭하면 경고 없이 변경 사항이 사라져요.
- 일부 앱은 앱 안의 보안 브라우저에서 인증해야 해요.
- 커넥터 변경 사항은 모바일과 웹 사이에서 동기화돼요.
- '**AI에게 문의**' 스킬은 웹에서 사용할 수 있지만, 4.27.0 버전의 모바일 **커스터마이징**에는 없어요. 자세한 내용은 [AI에게 문의 스킬과 커넥터](ask-ai-skills-and-connectors.md)에서 볼 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 모바일에서 커넥터가 안 보여요.
앱이 4.27.0 버전 이상으로 업데이트되어 있는지, **'AI에게 문의' 액세스** 권한이 있는지, 서브 계정 안에서 작업 중인지 확인하세요.

### 앱 하나에 계정을 여러 개 연결할 수 있나요?
지원되는 경우에는 연결할 수 있어요. 다만 도구 선택은 계정마다 따로가 아니라 앱 전체에 적용돼요.

### 다른 사용자가 제가 연결한 계정을 볼 수 있나요?
아니요. 연결된 계정은 설정한 사용자에게만 보여요.

### 연결이 만료되면 어떻게 하나요?
해당 커넥터를 열어 나타나는 재연결 또는 인증 절차를 완료하세요.

### 오프라인에서도 커넥터를 관리할 수 있나요?
마지막으로 불러온 목록은 볼 수 있지만 새로고침은 안 돼요. 온라인으로 돌아오면 **다시 시도**를 탭하세요.

### 모바일과 웹의 커넥터는 동기화되나요?
네. 한쪽에서 연결한 앱은 다른 쪽에서도 쓸 수 있어요.

### 사용자 지정 MCP 서버를 삭제하면 어떻게 되나요?
그 서버로 연결한 모든 계정이 영구적으로 삭제돼요.
