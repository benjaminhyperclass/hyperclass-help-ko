# AI에게 문의에서 MCP 서버 사용하기

**AI에게 문의**(Ask AI)는 질문에 답하는 데서 그치지 않고 작업까지 실행해 줘요. 이 문서에서는 채팅으로 연락처 만들기, 예약 변경, 기회 일괄 수정 같은 작업을 시키는 방법을 안내해요. 채팅창에 명령을 입력하면 하이퍼클래스의 마스터 컨트롤 패널(MCP)이 바로 작업을 처리해요. 메뉴를 하나하나 찾아 들어가거나 탭을 오갈 필요가 없어요.

## MCP로 작동하는 AI에게 문의의 장점

채팅이 작업 실행 도구가 되면, 여러 번 클릭해야 했던 일을 문장 하나로 끝낼 수 있어요.

- 클릭 없는 워크플로우: "Jane Smith를 'NY 리드' 파이프라인에 추가해 줘"라고 입력하면 바로 처리돼요.
- 조회와 실행을 한 대화에서: 데이터를 먼저 물어본 뒤 같은 대화에서 바로 작업할 수 있어요("그 연락처들에 '핫' 태그를 달아 줘").
- 폭넓은 지원 범위: MCP API가 지원하는 작업은 연락처, 결제, 자동화 등 무엇이든 채팅에서 실행돼요.
- 역할에 맞춘 안전장치: 사용자 역할의 권한과 똑같이 적용돼서, 자기 권한을 넘어서는 작업은 할 수 없어요.
- 기록과 되돌리기: 모든 작업은 **Activity Feed**(활동 피드)에 기록돼요. 삭제처럼 되돌릴 수 없는 명령은 실행 전에 확인을 물어봐요.

## 작동 방식

1. 의도 파악: AI가 동사(만들기, 수정, 삭제)와 대상(연락처, 인보이스)을 알아내요.
2. 요청 데이터 생성: 입력한 내용을 MCP 필드(예: firstName, pipelineId)에 맞춰요.
3. 권한 확인: 시스템이 이 작업을 실행할 권한이 있는지 확인해요.
4. 확인(되돌릴 수 없는 작업만): 삭제나 일괄 수정이면 AI에게 문의가 작업 요약을 보여 주고 "진행할까요?"라고 물어봐요.
5. 실행 및 응답: MCP가 작업을 실행해요. 성공 또는 오류 내용이 채팅창에 바로 표시되고 **Audit Feed**(감사 피드)에도 기록돼요. <!-- 검토 필요: 원문 내용이 서로 다름 (Activity Feed와 Audit Feed, 기록 위치 표기 불일치) -->

## 명령 형식과 예시

|  |  |  |
| --- | --- | --- |
| 액션 유형 | 자연어 예시 | 내부에서 실행되는 MCP 호출 |
| 만들기 | "서브 계정 A에 John Doe라는 이름으로 전화번호 555-1234인 연락처를 만들어 줘." | `createContact()` |
| 수정 | "기회 #456의 파이프라인 단계를 '고객전환성공'으로 바꿔 줘." | `updateOpportunity()` |
| 조회 | "내일 예약된 일정을 보여 줘." | `listAppointments()` |
| 삭제 | "쿠폰 코드 SUMMER25를 삭제해 줘." | `deleteCoupon()` (확인 필요) |
| 일괄 작업 | "지난주 웨비나에 참석한 연락처 전체에 'Webinar-2025' 태그를 달아 줘." | `updateContact()`를 반복 실행 |

{% hint style="info" %}
명령 끝에 "결과도 보여 줘"를 붙이면 JSON 일부가 함께 표시돼서 결과를 빠르게 확인할 수 있어요.
{% endhint %}

## 안전과 권한

- 역할 적용: 채팅에서 쓸 수 있는 권한은 화면 권한과 같아요. 숨겨진 우회 경로는 없어요.
- 확인 요청: 되돌릴 수 없는 변경은 사람이 직접 **예** / **아니오**를 선택하는 단계를 거쳐요.
- 감사 로그: AI가 실행한 모든 작업은 **설정 > 감사 로그 > AI Chat**(AI 채팅)에서 확인할 수 있어요.
- 크레딧 사용: MCP 명령이 성공할 때마다 AI 크레딧이 1개 사용돼요. 미리보기나 거부된 명령은 무료예요.

## 프롬프트 활용 예시

1. 단일 작업 명령

   - "john@demo.com 연락처에 299달러 인보이스를 만들어 줘. 결제 기한은 30일 뒤야."
2. 조회 후 실행 (2단계)

   - "이번 주에 고객전환실패가 된 기회를 목록으로 보여 주고, '재참여' 단계로 옮겨 줘."
3. 조건 포함 명령

   - "'체험 종료 임박' 태그가 있는 연락처 중에서 마지막 로그인이 14일보다 오래된 연락처는 '이탈 위험' 파이프라인으로 옮겨 줘."

## 자주 묻는 질문

### AI가 서버에 실제로 무엇을 보냈는지 어떻게 확인하나요?
채팅 답변의 타임스탬프를 클릭하면 **감사 로그** 사이드바에서 원본 JSON 페이로드가 열려요.

### 잘못 실행한 작업을 되돌릴 수 있나요?
5분 안에 "마지막 액션 되돌리기"(Undo last action)를 사용하거나, 백업(연락처 CSV 등)에서 복원할 수 있어요.

### 일괄 작업에 처리 속도 제한이 있나요?
네. 시스템 성능을 보호하기 위해 1분에 1,000건까지만 처리해요.

### 모바일에서도 쓸 수 있나요?
현재는 읽기 전용이에요. MCP 작업은 2025년 4분기에 iOS와 Android에서 출시될 예정이에요.

### 삭제 같은 특정 명령을 제한할 수 있나요?
관리자는 **설정 > Security**(보안) > **AI Controls**(AI 제어)에서 역할별로 **Allow AI Deletes**(AI 삭제 허용)를 켜거나 끌 수 있어요.

### AI가 제 요청을 잘못 이해하면 어떻게 되나요?
AI가 되묻는 질문을 보내요. 확인하기 전에는 어떤 작업도 실행되지 않아요.

## 다음 단계

1. 아무 서브 계정에서 **AI에게 문의**를 열고 "Demo Bot이라는 이름의 테스트 연락처를 만들어 줘"라고 입력해 보세요.
2. **감사 로그**에서 JSON 페이로드를 확인하세요.
3. 안전한 일괄 명령("최근 연락처 5명에게 'Test' 태그를 달아 줘")을 실행해 보고, 처리 속도 제한이 어떻게 적용되는지 살펴보세요.
4. **AI Controls**를 검토해서 삭제 같은 명령이 우리 회사의 보안 정책에 맞게 설정되어 있는지 확인하세요.
