# AI에게 문의 멀티스레딩과 백그라운드 세션으로 여러 작업 동시에 실행하기

**AI에게 문의**에서 AI 대화를 최대 10개까지 동시에 실행할 수 있어요. 작업은 백그라운드에서 계속 진행되고, 대화가 끝나거나 내 입력이 필요하면 알림이 와요. 다른 계정으로 자유롭게 전환해도 돼요.

모바일의 **AI에게 문의**에서도 병렬 채팅을 쓸 수 있어요. 앞선 답변이 처리되는 동안 다른 질문을 시작하고, 각 세션을 **채팅 기록**에서 확인하세요.

## 이 문서에서 알 수 있는 것

**AI에게 문의**의 멀티스레딩(여러 대화를 동시에 처리하는 기능)으로 작업 방식이 어떻게 달라지는지 설명해요. 대화를 여러 개 동시에 열고, 백그라운드에서 처리하고, 하던 일을 방해받지 않으면서 알림으로 상황을 확인할 수 있어요.

다음 내용을 알려 드려요.

- 병렬 작업을 실행하는 방법
- 상태 표시로 진행 상황을 확인하는 방법
- 입력 요청에 응답하는 방법
- 계정을 전환하면서도 대화를 계정별로 분리해 두는 방법

## AI에게 문의 멀티스레딩이란?

멀티스레딩을 쓰면 하이퍼클래스의 AI 어시스턴트가 대화를 병렬로 처리해요. 한 작업이 끝나기를 기다렸다가 다음 작업을 시작할 필요가 없어요. 서로 독립적으로 실행되는 대화를 최대 10개까지 동시에 시작할 수 있어요.

대화마다 자체 맥락, 스크롤 위치, 기록을 따로 유지해요. 한 대화에서 블로그 글 초안을 쓰고, 다른 대화에서 리포트를 만들고, 또 다른 대화에서 예약을 잡는 일을 한꺼번에 진행할 수 있어요. **AI에게 문의** 패널을 닫거나 다른 도구로 이동해도 대화는 백그라운드에서 계속 처리돼요.

완료된 대화는 자동으로 저장돼요. 대화가 끝나거나 내 입력이 필요해지면 알림이 오니까 작업이 사라지거나 조용히 실패하는 일이 없어요.

## 주요 기능

- **병렬 대화 실행**: 순서대로 끝나기를 기다리지 않고 대화를 최대 10개까지 동시에 실행해요. 대화마다 맥락과 상태가 따로 처리돼요.
- **백그라운드 처리**: **AI에게 문의** 패널을 닫거나, 다른 도구로 이동하거나, 계정을 전환해도 대화는 계속 실행돼요. 끝난 작업은 자동으로 저장되어 돌아왔을 때 바로 볼 수 있어요.
- **완료 알림**: 백그라운드 대화가 끝나면 토스트 알림(화면에 잠깐 나타나는 알림)이 떠요. 알림에는 대화 제목과 **Open to view**(열어서 보기)가 표시되고, 클릭하면 완료된 채팅으로 바로 이동해요.
- **오류 알림**: 세션이 실패하면 조용히 넘어가지 않고 **백그라운드 세션에 실패했습니다** 알림이 와요. 처리 문제를 바로 알 수 있어요.
- **상태 유지**: 대화마다 스크롤 위치, 기록, 맥락이 그대로 남아요. 백그라운드에서 실행 중이거나 계정을 전환한 뒤에도 마찬가지예요.

## 백그라운드 알림 이해하기

**AI에게 문의**의 백그라운드 알림은 대화별 알림이에요. 일반 플랫폼 알림과는 다음 점이 달라요.

### 대화로 바로 이동

알림을 클릭하면 알림을 보낸 해당 대화로 바로 이동해요. 예를 들어 "**완료** • 출시 블로그 글 작성" 알림을 클릭하면 완료된 그 대화가 열려요.

### 계정별 알림

알림은 작업을 시작한 계정에만 연결돼요. 한 서브 계정에서 실행 중인 대화의 알림은, 다른 서브 계정을 보고 있을 때는 오지 않아요.

### 알림 다시 보여 주기

**AI에게 문의** 밖에 있을 때 대화가 끝나면 알림이 사라지지 않고 기다렸다가, 돌아왔을 때 다시 보여 줘요. 완료된 작업을 놓치지 않아요.

### 상황에 맞춘 표시

알림은 **AI에게 문의** 밖에서 작업할 때만 나타나요. 이미 **AI에게 문의** 패널을 보고 있다면 중복 알림을 피하려고 알림이 뜨지 않아요.

### 알림이 나타나는 방식

백그라운드 대화가 정상적으로 끝나면 "**완료** • 출시 블로그 글 작성" 같은 토스트 알림과 **Open to view** 링크가 나타나요. 세션에 오류가 생기면 대신 **백그라운드 세션에 실패했습니다** 메시지가 와요. 대화 상태를 항상 정확히 알 수 있어요.

## 입력 필요 알림

**AI에게 문의**가 대화 도중 추가 정보나 결정을 필요로 할 때가 있어요. 이때는 조용히 멈추지 않고 **입력 필요** 알림을 보여 줘요.

예를 들어 파이프라인 단계를 업데이트하다가 단계 이름이나 설정을 확인해야 하면 "파이프라인 단계 업데이트에 대한 답변이 필요해요. 열어 보세요." 같은 알림이 와요. 알림을 클릭하면 답을 기다리는 대화로 바로 이동하고, 거기서 필요한 내용을 입력하면 돼요.

### 우선 처리

**입력 필요** 알림은 일반 완료 알림보다 먼저 표시돼요. 내가 응답해야 하는 대화가 저절로 끝난 대화보다 먼저 눈에 띄어요.

### 다른 계정에서도 알림

**입력 필요** 알림은 대화를 시작한 곳과 다른 서브 계정을 보고 있을 때도 와요. 어느 계정에서 작업 중이든 **AI에게 문의**가 입력을 기다린다는 것을 알 수 있어요.

요청한 정보를 입력하면 **AI에게 문의**가 멈췄던 지점부터 자동으로 이어서 처리해요.

## 실시간 상태 표시

**AI에게 문의** 패널을 열어 두지 않아도 활동을 확인할 수 있도록, 화면 곳곳에 상태 표시가 나타나요. 상단 내비게이션 바와 사이드바의 표시를 보면 진행 중인 대화와 끝난 작업을 알 수 있어요.

### 상단 내비게이션 바의 깜빡임

대화가 하나라도 처리 중이면 상단 내비게이션 바의 **AI에게 문의** 버튼이 은은하게 깜빡여요. 작업이 진행 중이라는 것을 바로 알 수 있어요.

### 빨간 완료 점

하이퍼클래스의 다른 곳에서 작업하는 동안 백그라운드 대화가 끝나면, 상단 내비게이션의 **AI에게 문의** 버튼에 빨간 점이 나타나요. 확인할 수 있는 완료된 작업이 있다는 표시예요.

### 사이드바의 파란 아이콘

대화가 실행되는 동안 사이드바의 **AI에게 문의** 아이콘이 파랗게 바뀌어요. 어떤 내비게이션을 쓰든 볼 수 있는 보조 표시예요.

### 사이드바의 파란 점

백그라운드 세션이 끝났는데 아직 확인하지 않았다면, 사이드바 **AI에게 문의** 아이콘 옆에 작은 파란 점이 나타나요. **AI에게 문의**를 열면 점이 사라져요.

### 모바일 채팅 기록 표시

모바일의 **채팅 기록**에서는 아직 처리 중인 대화와, 다른 채팅을 보는 동안 끝난 대화를 구분해서 보여 줘요.

- 스피너: 채팅이 아직 답변을 처리하는 중이에요.
- 점: 다른 곳에 있는 동안 답변이 끝났고, 확인할 수 있어요.

### 계정별 상태

모든 상태 표시는 계정별로 나타나요. 지금 보고 있는 서브 계정 또는 에이전시 화면의 상태만 표시돼요. 계정을 전환하면 표시가 바로 그 계정의 상태로 바뀌어요.

{% hint style="info" %}
이미 **AI에게 문의** 화면을 보고 있을 때는 상태 점이 숨겨져요. 이미 그 맥락 안에 있기 때문이에요. 다른 곳으로 이동하면 새 활동이 있을 때 점이 다시 나타나요.
{% endhint %}

## 계정 전환과 대화 분리

**AI에게 문의**는 계정마다 대화를 완전히 분리해서 관리해요. 서브 계정과 에이전시 화면 사이를 자유롭게 오가도 작업이 섞이거나 맥락을 잃지 않아요.

계정마다 대화, 기록, 스크롤 위치, 오류 상태를 독립적으로 가지고 있어요. 계정을 전환하면 이전 계정에서 실행 중이던 대화는 백그라운드에서 계속 실행되고 그 계정에서 끝나요.

- **대화 기록 분리**: 계정마다 대화 목록이 따로 있어요. 다른 서브 계정으로 전환하면 그 계정의 대화만 보여요.
- **스크롤 위치 유지**: 계정으로 돌아오면 다른 계정에서 작업했더라도 각 대화가 떠났던 스크롤 위치에서 다시 시작돼요.
- **계정별 오류**: 오류 메시지와 실패한 세션 알림은 대화를 시작한 계정에만 연결돼요. 한 계정의 오류는 다른 계정을 볼 때 나타나지 않아요.
- **독립적인 백그라운드 처리**: 서브 계정 A에서 시작한 대화는 서브 계정 B로 전환해도 계속 실행돼요. 완료 알림은 시작한 계정으로 돌아왔을 때만 나타나요.

여러 고객사 계정을 동시에 관리해도 대화와 결과가 다른 계정으로 넘어가지 않아요. 계정마다 완전히 독립된 작업 공간으로 동작해요.

## 음성 모드 개선 사항

음성 모드에서 글로 입력하는 경우와 말로 입력하는 경우를 섞어 써도 더 일관되고 유연하게 쓸 수 있도록 개선됐어요.

### 입력한 메시지도 소리로 읽어 줘요

음성 모드에서 말하는 대신 글로 메시지를 입력하면, **AI에게 문의**가 답변을 소리 내어 읽어 줘요. 입력 방식과 관계없이 대화 전체에서 음성 답변이 일관돼요.

### 답변을 끝까지 읽어 줘요

**AI에게 문의**가 음성으로 답변하는 중에 다른 대화로 전환하면, 문장 중간에 끊지 않고 답변이 자연스럽게 끝날 때까지 기다려요.

### 세션 종료 확인

이제 실시간 음성 세션을 끝내기 전에 **AI에게 문의**가 확인을 물어요. 실수로 연결이 끊기는 것을 막고, 필요하면 대화를 계속할 수 있어요.

### 텍스트 모드는 그대로 조용해요

음성 모드가 아닌 일반 텍스트 대화는 이전처럼 소리가 나지 않아요. 음성 모드가 켜져 있을 때만 음성 답변이 나오니, 텍스트로만 작업할 때는 조용히 쓸 수 있어요.

## 멀티스레딩 사용하기

다음 순서로 **AI에게 문의**의 멀티스레딩을 사용해 보세요.

1. **AI에게 문의** 열기

   상단 내비게이션 바나 사이드바의 **AI에게 문의** 버튼을 클릭해 패널을 열어요.

   ![AI에게 문의 패널 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078114363/original/7e74V4GL_B5OxFdiJvcQKJt0SRX8AeKUWA.png?1786444621)

2. 첫 번째 대화 시작하기

   첫 요청을 입력하거나 말해 보세요. 예를 들어 "이메일 마케팅 모범 사례에 관한 블로그 글 초안을 작성해 줘"라고 요청해요. **AI에게 문의**가 바로 처리를 시작해요.

   ![첫 번째 대화 시작하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078132400/original/_Q6AyTx40N119cvPAQLCYYsWZuvJ-YEvYw.png?1786453190)

3. 대화 추가로 만들기

   **새 대화** 버튼을 클릭하거나 단축키를 눌러 새 대화를 시작해요. 대화는 각각 독립적으로 실행되고, 병렬 대화는 최대 10개까지 만들 수 있어요.

   ![새 대화 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078132773/original/uw4BVagyrmGhNPHzXtylRauIdzGRDRVYpw.png?1786453292)

4. 하던 일 계속하기

   **AI에게 문의** 패널을 닫거나, 하이퍼클래스의 다른 도구로 이동하거나, 다른 계정으로 전환해요. 대화는 백그라운드에서 계속 처리돼요.

5. 상태 표시 확인하기

   내비게이션 바에서 깜빡이는 **AI에게 문의** 버튼(처리 중)과 빨간 점(완료된 작업)을 확인해요. 사이드바 아이콘은 처리 중에 파랗게 바뀌고, 대화가 끝나면 파란 점이 나타나요.

   ![상태 표시 확인하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078133477/original/fB_scniDWC-GUO75RIgmtMwiDZreyAVC-A.png?1786453618)

6. 알림에 응답하기

   **완료** 또는 **입력 필요** 알림이 보이면 **Open to view**를 클릭해 해당 대화로 바로 이동해요. **입력 필요** 알림이라면 요청받은 정보를 입력해서 **AI에게 문의**가 이어서 작업하게 해 주세요.

   ![알림에 응답하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078134115/original/YWxFKWhaLP2ysrclBRNGQYeScr4AF0q51g.png?1786453776)

7. 완료된 작업 확인하기

   **AI에게 문의**를 열어 끝난 대화를 확인해요. 대화마다 전체 기록과 스크롤 위치가 그대로 남아 있어서, 스크롤하거나 검색하지 않아도 결과를 바로 볼 수 있어요.

## 모바일 AI에게 문의의 병렬 세션

병렬 세션을 쓰면 현재 답변이 끝나기를 기다리지 않고 **AI에게 문의**에 다른 요청을 보낼 수 있어요. 채팅은 각각 독립적으로 실행되기 때문에, 대화를 전환해도 이미 처리 중인 작업이 취소되지 않아요.

모바일 병렬 세션은 하이퍼클래스 앱과 WL 앱의 **4.23.0 버전 이상**에서 사용할 수 있어요.

### 모바일에서 AI에게 문의 채팅 여러 개 실행하기

새 대화를 시작하면 앞선 요청이 처리되는 동안에도 계속 질문할 수 있어요.

1. 모바일 앱을 열어요.
2. **App Drawer**(앱 드로어)에서 **AI에게 문의**를 열어요.
3. 첫 번째 질문을 보내요.
4. **채팅 기록**을 열어요.
5. **새 채팅**을 탭해요.
6. 다른 질문을 보내요. 첫 번째 채팅은 독립적으로 계속 처리돼요.
7. 대화 사이를 이동하고 싶을 때마다 **채팅 기록**을 열어요.
8. 스피너가 보이면 아직 처리 중인 채팅이고, 점이 보이면 다른 곳에 있는 동안 답변이 끝난 채팅이에요.

## 자주 묻는 질문

### 대화를 몇 개까지 동시에 실행할 수 있나요?
**AI에게 문의**는 병렬 대화를 한 번에 최대 10개까지 지원해요. 대화마다 맥락, 기록, 상태가 독립적으로 유지돼요. 대화 사이를 자유롭게 전환하거나, **AI에게 문의** 패널을 닫거나, 다른 곳으로 이동해도 실행 중인 모든 대화는 계속 처리돼요.

### AI에게 문의 패널을 닫으면 대화는 어떻게 되나요?
패널을 닫아도 실행 중인 대화는 모두 백그라운드에서 계속 진행돼요. 완료된 작업은 자동으로 저장되어 돌아왔을 때 기다리고 있어요. 대화가 끝나면 토스트 알림이 오고, 내비게이션 바와 사이드바의 상태 표시로 진행 중인 활동과 완료된 작업을 확인할 수 있어요.

### 대화에 내 입력이 필요한지 어떻게 알 수 있나요?
**AI에게 문의**가 진행하려면 추가 정보가 필요할 때 대화 제목과 열기 안내가 담긴 **입력 필요** 알림이 와요. 이 알림은 완료 알림보다 먼저 표시되고, 다른 서브 계정을 보고 있을 때도 와요. 알림을 클릭하면 해당 대화로 바로 이동하니, 요청받은 정보를 입력하세요.

### 서브 계정을 전환하면 대화가 섞이나요?
아니요. 대화는 계정별로 완전히 분리돼요. 서브 계정마다, 그리고 에이전시 화면마다 대화 기록, 스크롤 위치, 백그라운드 세션이 따로 유지돼요. 한 계정에서 시작한 작업은 그 계정에서 계속 실행되고 끝나요. 알림도 대화를 시작한 계정을 보고 있을 때만 나타나요.

### 상태 표시는 각각 무슨 뜻인가요?
상단 내비게이션의 **AI에게 문의** 버튼이 깜빡이면 처리 중이라는 뜻이에요. 이 버튼에 빨간 점이 있으면 백그라운드 작업이 끝나서 확인을 기다리고 있다는 뜻이에요. 사이드바의 **AI에게 문의** 아이콘은 처리 중에 파랗게 바뀌고, 백그라운드 세션이 끝나면 파란 점이 나타나요. 모든 표시는 계정별이고, 계정을 전환하면 바로 업데이트돼요.

### 음성 모드에서 글로 입력하면 어떻게 되나요?
음성 모드가 켜져 있을 때 말하는 대신 글로 입력하면, **AI에게 문의**가 음성 답변의 일관성을 위해 답변을 소리 내어 읽어 줘요. 음성 모드는 대화를 전환하기 전에 답변이 끝나기를 기다리고, 실시간 음성 세션을 끝내기 전에 확인도 물어요. 음성 모드가 아닌 텍스트 대화는 소리가 나지 않아요.

### 백그라운드 대화가 실패하면 어떻게 되나요?
일반 완료 알림 대신 **백그라운드 세션에 실패했습니다** 알림이 와요. 오류가 조용히 지나가지 않아요. 알림을 클릭하면 대화를 열어 오류 내용을 확인할 수 있고, 필요에 따라 요청을 다시 보내거나 방법을 바꿔 보세요.

### 이미 AI에게 문의를 보고 있어도 알림이 오나요?
아니요. **AI에게 문의** 패널을 보고 있을 때는 중복 알림을 피하려고 알림이 뜨지 않아요. 이미 그 맥락 안에 있기 때문에 **AI에게 문의** 화면에서는 상태 표시도 숨겨져요. 다른 곳으로 이동하면 새 활동이 있을 때 알림과 표시가 다시 나타나요.
