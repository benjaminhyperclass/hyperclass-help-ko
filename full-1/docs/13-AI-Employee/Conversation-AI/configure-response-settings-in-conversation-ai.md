# 대화 AI에서 응답 스타일 설정하기

대화 AI 봇이 답변을 얼마나 길고 자세하게 쓸지 정하는 방법을 안내해요. **간결하게**, **균형 잡힘**, **상세** 중에서 고르면 브랜드 말투와 답변하는 채널에 맞게 응답 길이를 맞출 수 있어요.

[동영상](https://www.youtube.com/embed/J3RwzIpEWzc?&wmode=opaque)

## 응답 스타일 설정이란?

응답 스타일 설정은 대화 AI 봇이 선호하는 답변 길이를 정하는 기능이에요. 빠른 확인 답변이 필요한지, 맥락을 곁들인 설명이 필요한지, 더 꼼꼼한 답변이 필요한지에 따라 스타일을 고르면 돼요. 프롬프트를 다시 쓰거나 플로를 새로 만들 필요가 없어요.

## 응답 스타일 설정의 장점

응답 길이를 조절하면 채널과 상황이 달라져도 일관된 경험을 줄 수 있어요. 알맞은 분량으로 답하면 혼란이 줄고, 고객 반응이 좋아지고, 브랜드 이미지도 유지돼요.

- 채널에 맞는 답변: SMS, 웹 채팅, 소셜 DM 등에 맞게 답변 길이를 맞출 수 있어요.
- 더 명확한 안내: 적당한 분량으로 설명해서 고객이 되묻는 일을 줄여요.
- 일관된 브랜드 경험: 원하는 말투와 설명 깊이를 유지할 수 있어요.
- 봇별 설정: 봇의 용도에 따라 서로 다른 스타일을 쓸 수 있어요.
- 쉬운 변경: 기존 플로나 프롬프트를 바꾸지 않고 언제든 스타일을 바꿀 수 있어요.

## 지원하는 봇 유형

응답 스타일 설정은 아래 봇 유형에서 쓸 수 있어요. 여러 유형의 봇을 운영한다면 알맞은 봇에서 설정을 켜세요.

- **Form-Based Bots**(폼 기반 봇)
- **Prompt-Based Bots**(프롬프트 기반 봇)
- **Flow-Based Bots**(플로 기반 봇)

## 응답 스타일 켜기와 끄기

응답 스타일 설정을 켜거나 끄면 봇이 선택한 스타일을 따를지 정할 수 있어요. 새 동작을 시험해 보거나, 봇을 현재 기본 응답 방식으로 되돌릴 때 유용해요.

- 켰을 때: **봇 설정**에 **응답 설정** 섹션이 나타나고, 여기서 **간결하게**, **균형 잡힘**, **상세** 중 하나를 고를 수 있어요.
- 껐을 때: 봇이 지금처럼 그대로 응답해요. 선택한 응답 스타일은 적용되지 않아요.

| 응답 스타일 | 대략적인 길이 | 추천 용도 | 기대할 수 있는 답변 |
| --- | --- | --- | --- |
| 간결하게 | 약 30단어 | 빠른 확인 답변, 간단한 Q&A, SMS용 답변 | 군더더기 없이 바로 답해요 |
| 균형 잡힘 | 약 80단어 | 일반적인 대화 대부분, 자격 확인 질문, 기본 지원 | 명확한 답에 간단한 맥락이나 안내를 곁들여요 |
| 상세 | 약 200단어 | 자주 묻는 질문, 문제 해결, 온보딩, 단계별 안내 | 더 꼼꼼하고 구조적으로 설명해요 |

{% hint style="info" %}
응답 스타일의 단어 수는 기준일 뿐 엄격한 상한이 아니에요. 대화에 따라 답변이 목표 길이보다 조금 짧거나 길 수 있어요.

프롬프트에 길이 지시가 충돌하게 들어 있으면(예: “항상 20단어로 답하세요”) 결과를 예측하기 어려울 수 있어요. 응답 스타일 설정을 쓸 때는 사용자 지정 프롬프트에 단어 수 규칙을 따로 넣지 않는 것이 좋아요.
{% endhint %}

## 봇별 설정

응답 스타일 설정은 봇마다 따로 적용돼요. 영업, 고객 지원, 플랫폼별로 봇을 나눠 운영한다면 각 봇에 맞는 경험을 만들 수 있어요.

응답 스타일 설정은 현재 봇에만 적용되므로 이렇게 쓸 수 있어요.

- 한 봇은 SMS용으로 **간결하게**로 운영해요.
- 다른 봇은 웹 채팅이나 Messenger처럼 지원 문의가 많은 채널용으로 **상세**로 운영해요.

## 응답 스타일 설정 방법

한 번 켜 두면 선택한 스타일이 이후 새 답변부터 자동으로 적용돼요. 봇을 다시 설계하지 않아도 응답 길이를 통일할 수 있어요.

1. **AI 에이전트 > 대화 AI > Agents list**(에이전트 목록)로 이동해요. 새 봇을 만들거나 기존 봇을 열어요.

   ![에이전트 목록에서 봇 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066020326/original/m93Fm1vU81P9CZxYHTEyJQE8sNlsXW-wew.png?1772464643)

2. **응답 설정**까지 스크롤해서 **응답 설정** 토글을 켜요.
3. 드롭다운에서 **간결하게**, **균형 잡힘**, **상세** 중 하나를 선택해요.

   ![응답 스타일 선택하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066020465/original/KmsOBDpYB2CzMZZUGhp4dM7tN0lo42CbrA.gif?1772464720)

4. **저장**을 눌러 변경 사항을 적용해요.

## 자주 묻는 질문

### 한 봇에서 응답 스타일 설정을 켜면 모든 봇이 바뀌나요?
아니요. 응답 스타일 설정은 봇마다 저장돼요. 그래서 봇마다 다른 스타일을 쓸 수 있어요.

### 단어 수는 엄격한 제한인가요?
아니요. 단어 수는 느슨한 기준이에요. 맥락에 따라 답변 길이가 조금씩 달라질 수 있어요.

### 응답 스타일 설정을 끄면 어떻게 되나요?
봇이 지금처럼 그대로 응답해요. 선택한 응답 스타일은 적용되지 않아요.

### 프롬프트 지시가 선택한 응답 스타일보다 우선하나요?
서로 충돌할 수 있어요. 결과를 가장 예측하기 쉽게 하려면, 응답 스타일 설정을 쓸 때 프롬프트에 단어 수나 길이 규칙을 따로 넣지 마세요.
