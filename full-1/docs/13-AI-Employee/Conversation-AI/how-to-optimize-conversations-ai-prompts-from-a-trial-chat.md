# 테스트 채팅에서 대화 AI 프롬프트 최적화하기

테스트 채팅 프롬프트 최적화 도구를 쓰면 테스트 대화에서 바로 대화 AI 에이전트를 개선할 수 있어요. 테스트 채팅과 현재 프롬프트로 테스트 시나리오를 만들고, 성능을 평가한 뒤 개선안을 제안해요. 결과를 확인하고 가장 좋은 버전을 적용한 다음, 준비가 되면 에이전트를 저장하세요.

## 테스트 채팅 프롬프트 최적화 도구란?

대화 AI 빌더의 **에이전트 테스트하기** 패널에서 바로 프롬프트 최적화를 시작할 수 있어요. 테스트 메시지를 보내고 에이전트의 답변을 받은 뒤 **프롬프트 최적화**를 클릭하면 최적화가 실행돼요. 저장하지 않은 수정 내용을 포함해 빌더에 표시된 현재 프롬프트와 테스트 대화로 에이전트를 테스트하고, 필요하면 개선된 버전을 만들어 줘요.

## 주요 장점

실제 테스트 대화를 개선 기회로 바꿔 주기 때문에, 실제 적용 전에 답변을 다듬을 수 있어요.

- 테스트 채팅에서 최적화하기: 끝난 테스트 대화에서 바로 최적화를 시작해요.
- 저장하지 않은 변경 포함하기: 수정 내용을 저장하지 않고도 현재 프롬프트를 테스트해요.
- 테스트 자동화하기: 시나리오 생성, 답변 평가, 개선 버전 테스트를 자동으로 진행해요.
- 상세 결과 확인하기: 정확도, 채팅 대화록, 평가, 평가 근거, 프롬프트 차이를 비교해요.
- 진행 상황 추적하기: 빌더에서 실행 상태를 확인하거나 **프롬프트 최적화 도구**를 열어 볼 수 있어요.
- 업데이트 직접 관리하기: 에이전트를 저장하기 전에 개선된 프롬프트를 검토하고 적용해요.

## 사용 조건

필요한 기능과 권한이 켜져 있어야 최적화 옵션이 보여요. 시작하기 전에 아래 조건을 확인하세요.

- **대화 AI 프롬프트 최적화 도구** 실험실(Labs) 기능이 켜져 있어야 해요.
- 대화 AI 에이전트를 관리할 권한이 있어야 해요.
- 테스트 채팅에 사용자 메시지와 에이전트 답변이 각각 하나 이상 있어야 해요.

{% hint style="info" %}
**프롬프트 최적화** 버튼은 에이전트가 답변한 뒤에야 나타나요.
{% endhint %}

자세한 내용은 [실험실 기능 전체 개요](../../19-에이전시-뷰/Agency-Settings/labs-features-complete-overview.md)를 참고하세요.

## 테스트 채팅 프롬프트 최적화가 동작하는 방식

최적화 도구는 테스트 대화와 빌더의 현재 프롬프트로 시나리오를 만들고, 답변을 테스트해 개선할 부분을 찾아요. 테스트는 에이전트의 평가용 사본에서 실행돼요. 그래서 운영 중인 설정을 바꾸기 전에 여러 버전을 먼저 살펴볼 수 있어요.

진행 상황은 빌더에서 확인하거나, **프롬프트 최적화 도구**에서 해당 실행을 열어 볼 수 있어요. 완료된 버전에는 다음 정보가 포함돼요.

- **정확도**: 평가 테스트에서 해당 버전이 얼마나 잘 수행했는지 보여 줘요.
- 시나리오: 에이전트의 동작을 테스트하는 데 쓴 상황이에요.
- 채팅 대화록: 테스트 중에 생성된 대화예요.
- 평가 및 근거: 에이전트 성능에 대한 결과와 설명이에요.
- 프롬프트 차이: 원래 프롬프트와 개선된 프롬프트 사이의 변경 내용이에요.

{% hint style="warning" %}
설정해 둔 액션이 테스트 중에 실행될 수 있어요. 최적화를 시작하기 전에 연결된 워크플로우, 캘린더 등 다른 리소스를 확인하세요.
{% endhint %}

## 테스트 채팅에서 프롬프트 최적화하기

테스트 채팅에서 바로 최적화를 시작하고, 추천된 개선안을 검토한 뒤 선택한 프롬프트를 에이전트에 적용할 수 있어요. 아래 순서대로 진행하세요.

### 1단계: 테스트 채팅 시작하기

실제 고객이 보낼 법한 메시지로 테스트하면 개선이 필요한 답변을 찾는 데 도움이 돼요.

1. **AI 에이전트 > 대화 AI**로 이동하세요.
2. 최적화할 에이전트를 여세요.
3. 에이전트 빌더에서 **에이전트 테스트하기**를 찾으세요.

   ![에이전트 테스트하기 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083965227/original/x7cwnGOOC9dNrEDy3iLekjmIlbr396I7pg.png?1792671874)
4. 테스트 메시지를 보내고 에이전트가 답변할 때까지 기다리세요.
5. 답변을 확인한 뒤 **프롬프트 최적화**를 클릭하세요.

   ![프롬프트 최적화 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083964987/original/rVe3x1k2aQUxNCNcx6hY-SAA9IZKn8g_Xw.png?1792671800)

### 2단계: 최적화 실행하기

최적화 도구는 테스트 대화와 저장하지 않은 수정 내용을 포함한 현재 프롬프트로 에이전트의 동작을 평가하고, 가능한 개선안을 테스트해요.

1. 최적화 사용량 정보를 확인하세요.
2. 최적화 실행을 시작하세요.
3. 빌더에서 진행 상황을 확인하거나, **프롬프트 최적화 도구**를 열어 자세한 내용을 확인하세요.
4. 최적화 도구가 시나리오를 만들고 프롬프트 버전을 평가할 때까지 기다리세요.

남은 최적화 작업을 중지해도 이미 완료된 결과는 그대로 남아요.

![최적화 진행 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083969527/original/Xwy7ewuh6eNOJr2kNuyQPPknY8h9Rrm-BA.png?1792673426)

{% hint style="warning" %}
테스트는 에이전트의 평가용 사본에서 진행되지만, 설정해 둔 액션은 실행될 수 있어요. 가능하면 테스트용 리소스를 사용하세요.
{% endhint %}

### 3단계: 최적화 결과 검토하기

완료된 버전을 꼼꼼히 살펴보면 원래 문제는 해결하면서 원치 않는 변화는 생기지 않는 프롬프트를 고를 수 있어요.

1. 최적화 결과를 여세요.
2. 완료된 버전 중 가장 좋은 버전을 확인하세요.
3. **정확도**, 시나리오, 채팅 대화록, 평가를 확인하세요.
4. 평가 근거와 프롬프트 차이를 확인하세요.
5. 제안된 변경 내용이 요구 사항과 맞는지 확인하세요.

{% hint style="info" %}
**정확도** 점수가 높다고 해서 완벽하게 동작한다는 뜻은 아니에요. 변경 내용을 적용하기 전에 뒷받침하는 결과를 함께 확인하세요.
{% endhint %}

![최적화 결과 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083969960/original/PREAwRot3cYkSW7vNQksiN7B4daD0AaxLw.png?1792673706)

### 4단계: 최적화된 프롬프트 적용하고 저장하기

최적화된 버전을 적용하면 빌더의 프롬프트가 바뀌어요. 실제로 반영하기 전에 한 번 더 검토할 수 있어요.

1. 원하는 프롬프트 버전을 선택하세요.
2. 대화 AI 빌더에 해당 프롬프트를 적용하세요.
3. 업데이트된 지침을 검토하세요.
4. **저장**을 클릭해 변경 내용을 실제로 반영하세요.
5. 에이전트를 다시 테스트해 원하는 대로 동작하는지 확인하세요.

   ![프롬프트 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083970032/original/QN1tltzV2R4LE5pSJSns8lkFHME-i9zwtQ.png?1792673753)

## 최적화 실행 관리하기

처음 테스트 대화를 지워도 최적화 실행은 계속 열어 볼 수 있어요. 그래서 결과를 다시 보고 프롬프트 개선안을 계속 검토할 수 있어요.

- 진행 중인 실행: 빌더에서 바로 진행 상황을 확인해요.
- **실행 기록**: 테스트 채팅을 초기화하거나 새로 불러온 뒤에도 최적화 실행을 확인할 수 있어요.
- 중지된 실행: 남은 최적화 작업을 중지했더라도 완료된 결과를 확인할 수 있어요.
- **저장되지 않은 변경사항**: 최적화에는 빌더의 현재 프롬프트가 포함되지만, 에이전트를 저장하기 전에는 변경 내용이 실제로 반영되지 않아요.

## 자주 묻는 질문

### **프롬프트 최적화** 버튼이 안 보여요.
**대화 AI 프롬프트 최적화 도구** 실험실 기능이 켜져 있는지, 에이전트를 관리할 권한이 있는지 확인하세요. 테스트 채팅에 사용자 메시지와 에이전트 답변이 각각 하나 이상 있어야 해요.

### 최신 수정 내용을 저장하지 않고도 프롬프트를 최적화할 수 있나요?
네, 할 수 있어요. 최적화 도구는 저장하지 않은 변경 내용을 포함해 빌더에 표시된 프롬프트를 사용해요.

### 테스트 채팅을 초기화하면 어떻게 되나요?
테스트 대화는 지워질 수 있지만, 최적화 실행은 **실행 기록**에서 계속 확인할 수 있어요.

### 최적화 실행을 중지할 수 있나요?
네, 남은 작업을 중지할 수 있어요. 이미 완료된 결과는 그대로 남아요.

### 최적화 테스트가 실제 액션을 실행할 수도 있나요?
네, 그럴 수 있어요. 테스트는 에이전트의 평가용 사본에서 진행되지만, 설정해 둔 액션은 실행될 수 있어요. 시작하기 전에 연결된 리소스를 확인하세요.

### 최적화된 프롬프트를 적용하면 바로 실제로 반영되나요?
아니요. 해당 버전을 적용하면 빌더의 프롬프트만 바뀌어요. 변경 내용을 실제로 반영하려면 에이전트를 저장해야 해요.
