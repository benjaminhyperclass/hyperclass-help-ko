# 프롬프트 최적화 도구로 대화 AI 에이전트 테스트하고 개선하기

실제 고객을 만나기 전에 대화 AI 에이전트를 점검하고 개선하는 방법을 안내해요. 현실적인 채팅 시나리오를 만들고, 실시간으로 테스트하고, AI 평가를 확인한 뒤, 내가 승인한 프롬프트 개선안만 적용할 수 있어요.

## 이 문서에서 배우는 내용

프롬프트 최적화 도구를 쓰면 실제 운영 중인 프롬프트를 바꾸지 않고도, 다양한 고객 시나리오에서 대화 AI 에이전트가 어떻게 행동하는지 테스트할 수 있어요. 채팅 전체 내용을 확인하고, 설정한 액션이 제대로 실행되는지 검증하고, 테스트가 통과하거나 실패한 이유를 파악하고, AI가 만든 프롬프트 버전을 서로 비교할 수 있어요.

테스트 실행을 구성하는 방법, 사용량을 확인하는 방법, 수동·자동 최적화를 쓰는 방법, 변경 내용을 검토한 뒤 개선된 프롬프트를 적용하는 방법도 함께 다뤄요.

{% hint style="info" %}
대화 AI의 프롬프트 최적화 도구는 **실험실** 기능으로 제공돼요. 실험실 기능은 고객 의견에 따라 계속 개선되며 시간이 지나면서 바뀔 수 있어요.
{% endhint %}

## 대화 AI의 프롬프트 최적화 도구란?

프롬프트 최적화 도구는 대화 AI 에이전트가 실제 고객을 만나기 전에 프롬프트의 약한 부분을 찾아 줘요. 현실적인 고객 시나리오를 만들고, 에이전트를 복제한 버전과 실시간 채팅 대화를 진행하고, 결과를 평가한 뒤, 테스트에서 나타난 내용을 바탕으로 프롬프트 개선안을 제안해요.

작업은 **구성**, **테스트**, **즉흥 대응**의 세 단계로 진행돼요. 이 세 단계를 거치며 테스트 계획을 세우고, 에이전트가 실제로 어떻게 행동하는지 살펴보고, 실패 원인을 파악하고, 편집 가능한 프롬프트를 개선할 수 있어요. 운영 프롬프트는 내가 직접 한 버전을 적용하기 전까지 바뀌지 않아요.

{% hint style="warning" %}
프롬프트 최적화 도구는 에이전트를 복제한 버전으로 테스트하지만, 설정해 둔 대화 AI 액션은 테스트 중에도 실행될 수 있어요. 가능하면 테스트 전용 캘린더, 워크플로우, 전달 대상 등 별도의 테스트용 리소스를 쓰세요.
{% endhint %}

## 프롬프트 최적화 도구의 장점

직접 이것저것 시도해 보던 테스트에서 벗어나, 에이전트의 행동을 검증하고 프롬프트 품질을 높이는 과정을 반복해서 진행할 수 있어요.

- 시나리오 자동 생성: 프롬프트, 설정한 액션, 지식 베이스, 예약 설정, 비즈니스 맥락을 바탕으로 현실적인 고객 시나리오를 만들어요.
- 실시간 채팅 테스트: 정적인 프롬프트 미리보기가 아니라 실제 대화 AI 채팅을 실행해요.
- 액션 검증: 설정한 액션이 대화 중 기대한 시점에 실행되는지 추적해요.
- AI 기반 평가: 각 채팅이 기대한 결과를 충족했는지, 무엇이 통과하고 무엇이 실패했는지, 그 이유가 무엇인지 설명해요.
- 프롬프트 최적화: 실패한 대화를 바탕으로 개선된 프롬프트 버전을 만들고, 선택한 시나리오로 그 버전을 테스트해요.
- 프롬프트 비교: **프롬프트 비교**로 최적화된 버전을 적용하기 전에 무엇이 바뀌었는지 정확히 보여 줘요.
- 운영 환경 보호: **프롬프트 사용**을 선택하기 전까지 운영 프롬프트는 그대로 유지돼요.
- 다국어 테스트: 생성된 시나리오, 고객 메시지, 평가, 최적화된 프롬프트가 에이전트에 설정한 언어에 맞춰져요.
- 시나리오 재사용: 이전 실행의 시나리오를 다시 사용해, 프롬프트나 설정을 바꾼 뒤 성능이 어떻게 달라졌는지 비교할 수 있어요.

## 3단계 워크플로우

**구성**, **테스트**, **즉흥 대응**은 계속 이어지는 테스트 주기예요. 단계마다 목적은 다르지만, 프롬프트 변경을 운영 환경에 적용하기 전에 고객이 겪을 만한 경험을 미리 검증하는 데 함께 도움이 돼요.

1. **구성**: 고객 시나리오를 만들거나 다시 사용하고, 채팅 실행 횟수를 정하고, 테스트 전에 사용량을 확인해요.
2. **테스트**: 실시간 채팅 대화를 실행하고, 채팅 내용을 확인하고, 액션 실행 여부를 검증하고, AI가 매긴 결과를 살펴봐요.
3. **즉흥 대응**: 실패한 채팅을 분석하고, 프롬프트 버전을 만들고, 변경 내용을 비교한 뒤, 쓰고 싶은 버전을 적용해요.

## 구성

좋은 테스트는 의미 있는 시나리오에서 시작해요. 프롬프트 최적화 도구는 에이전트의 기존 설정을 바탕으로 시나리오를 만들어서, 프롬프트·지식·예약 설정·사용 가능한 액션이 반영된 행동을 테스트할 수 있게 해 줘요.

### 테스트 시나리오 생성

프롬프트 최적화 도구는 에이전트 설정을 바탕으로 상황에 맞는 시나리오를 만들 수 있어요. 시나리오마다 고객 페르소나, 첫 메시지, 에이전트에게 기대하는 행동, 우선순위가 들어갈 수 있어요.

시나리오는 다음 내용을 바탕으로 만들어져요.

- 프롬프트와 설정된 언어
- 지식 베이스 콘텐츠
- 예약 설정
- 설정된 대화 AI 액션
- 비즈니스 맥락

![시나리오 생성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078246509/original/YhVLptu1ZcKBi9gEXGBb3wAsWDwxbA9pUg.png?1786541413)

### 이전 시나리오 재사용

완전히 새로운 테스트 세트로 시작하지 않고, 프롬프트나 설정을 바꾼 뒤 같은 고객 상황에서 결과가 나아졌는지 확인하고 싶을 때는 이전 실행의 시나리오를 다시 사용하세요.

### 채팅 실행 횟수 설정

시나리오 하나를 한 번 이상 실행하면 에이전트가 일관되지 않게 행동하는 부분을 찾는 데 도움이 돼요. 테스트를 시작하기 전에 시나리오당 몇 번 실행할지 정하세요.

### 테스트 전에 사용량 확인

실행을 시작하기 전에 프롬프트 최적화 도구가 사용량 정보와 실행 전 검토 화면을 보여 줘요. 여기서 선택한 시나리오, 예상 메시지 사용량, 임시 연락처 처리 방식을 확인할 수 있어요.

![실행 전 사용량 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078246564/original/vluIToGpYSZfTjWOxKdBuXW7_85DFlKfFg.png?1786541455)

### 임시 테스트 연락처

프롬프트 최적화 도구는 채팅 실행을 위해 임시 연락처를 만들고, 테스트가 끝나면 정리해요. 덕분에 테스트 대화가 일반 고객 기록과 섞이지 않아요.

{% hint style="warning" %}
임시 테스트 연락처를 쓰더라도 설정된 액션은 그대로 실행될 수 있어요. **예약 부킹**, **워크플로우 트리거**, **상담원 전환**, **봇 전환**, **자동 후속 조치** 같은 액션은 가능하면 테스트용 리소스를 사용하세요.
{% endhint %}

## 테스트: 실제 채팅, 실제 액션

**테스트** 단계에서는 복제한 에이전트가 대화에서 실제로 어떻게 행동하는지 볼 수 있어요. 프롬프트 최적화 도구가 고객처럼 메시지를 보내고, 에이전트의 답변을 기다리고, 관련 액션 기록을 추적하고, 끝난 채팅을 시나리오에서 기대한 행동과 비교해 평가해요.

### 실시간 채팅 실행

정적인 미리보기가 아니라 실제 대화 AI 실행이에요. 실행할 때마다 고객 메시지, 에이전트 답변, 대화 타임라인, 확인 가능한 액션 기록이 저장돼요.

실행 상태는 **대기 중**, **진행 중**, **평가 중**, **완료**, **실패** 등으로 바뀌어요.

### 액션 실행 추적

프롬프트 최적화 도구는 테스트 중에 다음 액션을 추적할 수 있어요.

- **예약 부킹**
- **상담원 전환**
- **워크플로우 트리거**
- **봇 전환**
- **Stop Bot**(봇 중지)
- **자동 후속 조치**
- **Contact Field Update**(연락처 필드 업데이트)
- **Knowledge Base Query**(지식 베이스 조회)

{% hint style="warning" %}
테스트 중에 실제 액션이 실행될 수 있어요. 운영 환경과 연결된 액션을 대상으로 시나리오를 실행하기 전에, 연결된 캘린더, 워크플로우, 전달 대상, 필드 업데이트 등 설정된 리소스를 확인하세요.
{% endhint %}

### 채팅 내용 확인

개별 실행을 열면 고객 메시지, 에이전트 응답, 액션 기록을 살펴볼 수 있어요. 실패가 프롬프트 지침 때문인지, 지식 부족 때문인지, 액션 설정 때문인지 가려야 할 때 채팅 내용을 확인하면 특히 도움이 돼요.

![채팅 내용 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078246609/original/_Nk9_28SAsqasMbxozRHQXYOK_s44ctDqQ.png?1786541486)

### AI 평가와 점수

각 채팅은 시나리오에 정의된 기대 행동을 기준으로 평가돼요. 프롬프트 최적화 도구는 통과·실패 결과와 함께, 채팅이 기대한 결과를 충족했는지 여부와 그 이유를 설명하는 **AI 추론**을 보여 줘요.

대규모 언어 모델은 확률적으로 동작하기 때문에, 같은 시나리오를 여러 번 실행해도 결과가 똑같지 않을 수 있어요. 점수는 방향을 가늠하는 참고 자료로 쓰고, 근거가 되는 채팅 내용과 추론도 함께 확인하세요.

### 전체 결과

실행이 끝나면 전체 정확도, 통과·실패한 채팅 수, 시나리오별 결과, 개별 실행 상세를 확인할 수 있어요. 이를 바탕으로 프롬프트를 더 개선해야 할지 판단하세요.

## 즉흥 대응: AI가 이끄는 프롬프트 최적화

**즉흥 대응** 단계에서는 테스트에서 실패한 내용을 프롬프트 개선의 기회로 바꿔요. 프롬프트 최적화 도구가 실패한 대화와 평가 추론을 바탕으로 수정된 편집 가능 프롬프트를 만들고, 그 버전이 더 잘 동작하는지 테스트해요.

### 수동 즉흥 대응

최적화된 버전을 한 번에 하나씩 만들고 싶을 때 **즉흥 대응**을 사용하세요.

1. 실패한 채팅과 **AI 추론**을 검토하세요.
2. **즉흥 대응**을 클릭하세요.
3. 프롬프트 최적화 도구가 수정된 프롬프트 버전을 만들어요.
4. 선택한 시나리오로 그 버전을 테스트해요.
5. 업데이트된 정확도, 채팅, 추론, **프롬프트 비교**를 확인하세요.

### 자동 최적화

여러 번의 최적화 시도를 자동으로 실행하려면 **자동**을 사용하세요. 자동 최적화는 설정한 한도 안에서, 목표 정확도에 도달하거나, 최대 버전 수에 도달하거나, 그 밖에 지원되는 이유로 실행이 멈출 때까지 계속돼요.

### AI 실패 분석

최적화 도구는 실패한 채팅을 검토하고 다음과 같은 문제를 찾아낼 수 있어요.

- 빠져 있는 액션 트리거
- 약한 확인 질문 로직
- 지식 베이스로 뒷받침되지 않는 답변
- 끝까지 이어지지 않는 예약 흐름
- 미흡한 상담원 인계 동작
- 빠졌거나 모호한 프롬프트 지침

### 프롬프트 다시 쓰기

프롬프트 최적화 도구는 찾아낸 약점을 보완하도록 편집 가능한 프롬프트를 다시 써요. 이때 대화 AI 프롬프트에 필요한 구조는 그대로 유지해요.

### 프롬프트 비교

운영 환경에 적용하기 전에 **프롬프트 비교**로 원래 프롬프트와 최적화된 버전을 비교하세요. 바뀐 지침을 살펴보고, 내가 의도한 고객 경험과 여전히 맞는지 확인하세요.

### 최적 버전과 버전 기록

버전이 여러 개 있으면, 프롬프트 최적화 도구가 가장 성능이 좋은 버전에 **최적 버전** 라벨을 표시해요. 버전 기록에는 정확도, 테스트 결과, **AI 추론**, 프롬프트 차이가 저장돼서 각 버전을 서로 비교할 수 있어요.

### 최적화된 프롬프트 적용

1. 쓰고 싶은 버전을 선택하세요.
2. **프롬프트 비교**와 **AI 추론**을 확인하세요.
3. 새 지침이 내 요구 사항과 맞는지 확인하세요.
4. **프롬프트 사용**을 클릭해 선택한 프롬프트를 운영 중인 에이전트에 적용하세요.

## 알아 둘 점

프롬프트 최적화 도구는 에이전트의 행동을 개선하도록 도와주지만, 테스트 결과와 액션은 사람이 직접 검토해야 해요. 아래 내용을 참고해서 결과를 올바르게 해석하고, 의도하지 않은 운영 환경 활동을 줄이세요.

{% hint style="info" %}
대규모 언어 모델의 평가와 프롬프트 재작성은 실행할 때마다 달라질 수 있어요. 정확도는 운영 환경에서의 행동을 보장하는 절대적인 수치가 아니라, 방향을 가늠하는 참고 자료로 보세요.
{% endhint %}

{% hint style="info" %}
자동 최적화는 설정한 버전 수 한도 안에서 실행되며, 목표 정확도에 도달하기 전에 멈출 수 있어요.
{% endhint %}

{% hint style="info" %}
채팅 실행에는 시간 초과 보호 기능이 있어서, 길어지거나 멈춘 대화가 있어도 전체 실행은 끝까지 완료돼요.
{% endhint %}

{% hint style="info" %}
평가가 실패로 나온 이유는 엄격한 채점 기준, 모호한 기대 행동, 부족한 지식, 액션 설정, 프롬프트 표현 등 다양할 수 있어요. 프롬프트를 바꾸기 전에 채팅 내용과 추론을 먼저 확인하세요.
{% endhint %}

{% hint style="warning" %}
설정된 대화 AI 액션은 테스트 중에도 실행될 수 있어요. 가능하면 테스트용 캘린더, 워크플로우, 전달 대상 등 분리된 리소스를 사용하세요.
{% endhint %}

{% hint style="info" %}
문제 해결: 프롬프트 최적화로 개선되는 것은 편집 가능한 프롬프트예요. 실패 원인이 캘린더, 워크플로우, 상담원 전환 대상, 지식 베이스 소스, 필드 매핑에 있다면 프롬프트를 다시 쓰는 것에만 기대지 말고 해당 설정을 바로잡으세요.
{% endhint %}

## 자주 묻는 질문

### 프롬프트 최적화 도구가 운영 중인 대화 AI 에이전트를 자동으로 바꾸나요?
아니요. 테스트와 최적화는 복제한 에이전트에서 진행돼요. 한 버전을 검토하고 **프롬프트 사용**을 클릭하기 전까지는 운영 프롬프트가 그대로 유지돼요.

### 같은 시나리오를 여러 번 테스트할 수 있나요?
네. 같은 시나리오로 채팅을 여러 번 실행하면, 에이전트가 일관되게 행동하는지 아니면 가끔씩만 실패하는지 알 수 있어요.

### 이전 실행의 시나리오를 다시 사용할 수 있나요?
네. 프롬프트, 지식, 액션, 예약 설정을 바꾼 뒤 성능을 비교하고 싶을 때 이전 시나리오를 다시 사용하면 편해요.

### 채팅이 실패하면 어떻게 해야 하나요?
먼저 채팅 내용, 액션 기록, **AI 추론**을 확인하세요. 프롬프트, 부족하거나 뒷받침되지 않는 지식 베이스 콘텐츠, 액션 설정 문제, 엄격한 평가 기준 등이 원인일 수 있어요.

### 같은 테스트를 반복했는데 결과가 왜 다르게 나오나요?
대규모 언어 모델은 확률적으로 동작하기 때문에 고객 시뮬레이션, 에이전트 응답, 평가가 달라질 수 있어요. 한 번의 채팅보다는 여러 번 실행한 결과를 봐야 일관성을 더 잘 알 수 있어요.

### 프롬프트 최적화 도구는 여러 언어를 지원하나요?
네. 시나리오, 고객 메시지, 평가, 최적화된 프롬프트가 대화 AI 에이전트에 설정한 언어에 맞춰져요.

### 프롬프트 최적화 도구로 대화 AI 액션도 테스트할 수 있나요?
네. 액션이 설정되어 있으면 **예약 부킹**, **상담원 전환**, **워크플로우 트리거**, **봇 전환**, **Stop Bot**, **자동 후속 조치**, **Contact Field Update**, **Knowledge Base Query** 같은 액션을 추적할 수 있어요.

### 테스트할 때 운영용 캘린더와 워크플로우를 써도 되나요?
가능하면 테스트 전용 리소스를 쓰세요. 에이전트 프롬프트는 복제한 에이전트로 테스트하지만, 프롬프트 최적화 도구를 실행하는 동안 실제 액션은 실행될 수 있어요.

### 프롬프트 최적화 도구는 언제 실행하면 좋나요?
프롬프트, 지식 베이스, 액션, 예약 동작 등 고객이 대화에서 겪는 경험을 바꿀 수 있는 에이전트 설정을 크게 바꾼 뒤에 실행하세요.
