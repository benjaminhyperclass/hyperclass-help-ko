# 웹 디자이너 스냅샷

웹 디자이너용 서브 계정을 만들 때 기본 틀로 쓰는 스냅샷이에요. 이 문서에서는 스냅샷에 무엇이 들어 있는지, 설정 가이드와 설치 안내는 어디서 받는지 알려 드려요.

## 설정 가이드

웹 디자이너 스냅샷(Web Designer Snapshot)은 웹 디자이너에게 맞춘 서브 계정을 만들 때 쓰는 기본 템플릿이에요. 리드를 확보하고, 관리하고, 계약까지 이어 가는 데 필요한 도구가 한 번에 들어 있어요.

- 웹사이트
- 폼
- 캘린더
- 워크플로우
- 이메일 캠페인
- 온라인 광고
- 소셜 게시물

설정 가이드는 하이퍼클래스 고객지원에 문의하세요.

## 스냅샷 설치하기

스냅샷을 계정에 설치하려면 설치 링크와 안내를 먼저 받아야 해요. 하이퍼클래스 고객지원에 문의하세요.
