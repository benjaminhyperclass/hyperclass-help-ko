# 손해보험 스냅샷

손해보험 대리점에 맞춰 서브 계정을 빠르게 구성할 수 있는 스냅샷이에요. 이 문서에서는 스냅샷에 무엇이 들어 있는지, 설정 가이드와 설치 방법은 어디서 확인하는지 안내해요.

## 설정 가이드

손해보험 스냅샷은 손해보험 대리점용 서브 계정을 만들 때 바탕이 되는 템플릿이에요. 리드를 모으고, 관리하고, 계약으로 이어가는 데 필요한 도구가 한꺼번에 들어 있어요. 구성은 다음과 같아요.

- 웹사이트
- 폼
- 캘린더
- 워크플로우
- 이메일 캠페인
- 온라인 광고
- 소셜 게시물

설정 가이드 링크는 하이퍼클래스 고객지원에 문의하세요.

## 스냅샷 설치하기

스냅샷을 내 계정에 설치하는 방법과 다운로드 링크는 하이퍼클래스 고객지원에 문의하세요.
