# 스냅샷에 기회 스마트 리스트와 스마트 태그 추가하기

스냅샷에 기회 스마트 리스트와 스마트 태그를 포함하면, 저장해 둔 파이프라인 보기와 색상 태그를 다른 서브 계정에 그대로 복사할 수 있어요. 서브 계정마다 같은 보기와 태그를 직접 다시 만들 필요가 없어요. 관리자가 계정 스냅샷에 담아 여러 계정에서 재사용하면 되고, 에이전시 관리자가 사용하는 기능이에요. 영업, 온보딩, 고객 리포팅처럼 기회 보기를 통일하고 싶을 때 특히 유용해요.

## 스냅샷에서 기회 스마트 리스트와 스마트 태그란?

[기회 스마트 리스트](../05-기회-파이프라인/기회-관리/smart-lists-in-opportunities.md)는 필터, 정렬, 표시할 필드, 파이프라인 표시 여부를 저장해 둔 기회 보기예요. [기회 스마트 태그](../05-기회-파이프라인/기회-관리/how-to-color-code-opportunity-pipelines-smart-tags.md)는 기회 카드에 표시되는 규칙 기반 색상 칩이에요. 스냅샷에서 지원하므로, 관리자가 이 둘을 계정 스냅샷에 담아 다른 서브 계정으로 복사할 수 있어요.

원본 서브 계정에서 만든 스마트 리스트와 스마트 태그는 스냅샷을 만들거나 업데이트할 때 선택할 수 있어요. 스냅샷에 포함하면 다른 서브 계정으로 푸시하거나 불러올 수 있어요. 그러면 같은 설정을 반복하지 않고도 같은 기회 보기와 태그를 쓸 수 있어요.

## 주요 장점

- **빠른 설정:** 기회 보기와 태그를 직접 다시 만들지 않고 다른 서브 계정으로 복사해요.
- **일관된 파이프라인 검토:** 고객사 계정이나 지점마다 같은 저장 보기와 태그 규칙을 유지해요.
- **표준화된 딜 관리:** 오래 정체된 딜, 고액 딜, 후속 조치가 필요한 딜을 볼 수 있는 같은 보기를 모든 서브 계정에 제공해요.
- **수작업 감소:** 새 서브 계정을 시작할 때마다 반복하던 설정을 줄여요.
- **손쉬운 확장:** 에이전시에 서브 계정이 늘어나도 같은 기회 설정을 재사용해요.

## 스냅샷의 기회 스마트 리스트·스마트 태그 지원

![스냅샷 자산 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081638935/original/hFhCuuDcKsKznQzxzqh5uq20l8k39t6-TA.png?1790158015)

**Opportunity Smart Lists**(기회 스마트 리스트)와 **Opportunity Smart Tags**(기회 스마트 태그)는 스냅샷을 만들 때 선택할 수 있는 자산 유형이에요. 어떤 저장 보기와 태그를 포함해 서브 계정에서 재사용할지 관리자가 직접 정할 수 있어요.

이런 경우에 활용해 보세요.

- 새 고객사 서브 계정마다 표준 기회 보기를 한 번에 배포할 때
- 여러 지점의 파이프라인에 같은 색상 규칙을 적용할 때
- 영업팀이 어느 서브 계정에서 일하든 같은 보기를 쓰게 할 때
- 새 서브 계정을 시작할 때 설정 시간을 줄일 때

## 파이프라인 종속성

기회 스마트 리스트와 스마트 태그는 종속 자산이에요. 만들 때 기준이 된 파이프라인에 연결되어 있어서, 관련 파이프라인을 같은 스냅샷에 포함해야 해요.

파이프라인을 선택하지 않으면 대상 서브 계정에 스마트 리스트와 스마트 태그가 만들어지지 않아요. 자산을 선택할 때는 스마트 리스트와 스마트 태그에 해당하는 파이프라인도 함께 선택하세요.

## 서브 계정 간 복사

스냅샷을 이용하면 한 서브 계정의 기회 스마트 리스트와 스마트 태그를 다른 서브 계정으로 옮길 수 있어요. 다시 쓰고 싶은 보기와 태그가 이미 있는 서브 계정에서 스냅샷을 만들고, 파이프라인과 함께 선택하세요. 그다음 스냅샷을 대상 서브 계정에 적용하거나 푸시하면 돼요. 같은 기회 구조가 필요한 여러 계정을 관리하는 에이전시에 잘 맞는 방법이에요.

## 스냅샷에 기회 스마트 리스트와 스마트 태그 추가하기

시작하기 전에 두 가지를 확인하세요. 원본 서브 계정에 재사용할 스마트 리스트와 스마트 태그가 있어야 해요. 또 **Subaccount Labs**(서브 계정 실험실)에서 **Opportunity Smart Lists**가 켜져 있어야 해요.

1. **에이전시 보기**로 이동해 **계정 스냅샷**을 클릭하세요.
2. **새 스냅샷 생성**을 클릭하세요.
3. 스냅샷 이름을 입력하세요.
4. 복사할 스마트 리스트와 스마트 태그가 있는 원본 서브 계정을 선택하세요.
5. 자산 선택 목록에서 **파이프라인**을 찾아, 스마트 리스트와 스마트 태그가 속한 파이프라인을 선택하세요.
6. 자산 선택 목록에서 **Opportunity Smart Lists**와 **Opportunity Smart Tags**를 찾으세요.
7. 포함할 스마트 리스트와 스마트 태그를 선택하세요.

   ![포함할 스마트 리스트와 스마트 태그 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081639081/original/BXJ2ulZfUHxzvafJWqaGGBNaS9N2MeoFTw.png?1790158078)
8. **만들기**를 클릭하세요.
9. 연결된 서브 계정에 업데이트를 푸시하거나, 대상 서브 계정에 스냅샷을 적용하세요.

   ![서브 계정에 업데이트 푸시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081639127/original/UOn0W90x754ZvSo17jfpHTQ6KPIcsFImBg.png?1790158095)
10. 대상 서브 계정을 열고 **기회 관리**로 이동해, 스마트 리스트와 스마트 태그가 있는지 확인하세요.

    ![대상 서브 계정에서 복사된 스마트 리스트 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081639170/original/J4AwsgdrHd6xxtAXg-yJ5UEe3DjM_ZXPDg.png?1790158104)

## 함께 옮겨지는 항목

| 자산 | 옮겨지는 항목 | 옮겨지지 않는 항목 |
| --- | --- | --- |
| 기회 스마트 리스트 | 필터, 정렬 순서, **필드 관리** 설정, 목록 또는 보드 유형, 파이프라인 표시 여부 | 커스텀 오브젝트 연결, 공유 및 권한 설정 |
| 기회 스마트 태그 | 태그 이름, 색상, 규칙 조건, 연결된 파이프라인 | 푸시에 포함되지 않은 자산과의 연결 |

커스텀 오브젝트 연결은 커스텀 필드와 마찬가지로 대상 서브 계정으로 옮겨지지 않아요. 같은 스냅샷에 커스텀 오브젝트가 포함되어 있어도 마찬가지예요.

## 자주 묻는 질문

### 기회 스마트 리스트와 스마트 태그를 다른 서브 계정으로 복사할 수 있나요?
네. 둘 다 스냅샷에 포함해서 다른 서브 계정으로 복사할 수 있어요.

### 스냅샷을 만들 때 어디서 선택하나요?
스냅샷 자산 선택 화면에 **Opportunity Smart Lists**와 **Opportunity Smart Tags**로 표시돼요.

### 대상 서브 계정에 스마트 리스트와 스마트 태그가 나타나지 않아요.
관련 파이프라인이 푸시에 포함되지 않았을 가능성이 커요. 스마트 리스트와 스마트 태그는 종속 자산이에요. 스냅샷에 파이프라인을 추가한 뒤 다시 푸시하세요.

### 파이프라인을 매번 포함해야 하나요?
네. 스마트 리스트나 스마트 태그가 속한 파이프라인은 같은 스냅샷에 포함되어야 해요.

### 스마트 리스트는 옮겨졌는데 필터 하나가 없어요.
대상 서브 계정에 없는 자산을 가리키는 필터는 옮겨지지 않아요. 커스텀 오브젝트 연결이 그 예예요. 대상 서브 계정에서 해당 필터를 다시 추가하세요.

### 대상 서브 계정에 기회 스마트 리스트가 아예 보이지 않아요.
해당 서브 계정의 **Subaccount Labs**에서 **Opportunity Smart Lists**가 켜져 있는지 확인하세요.

### 기존 스냅샷에 스마트 리스트와 스마트 태그를 추가할 수 있나요?
네. 원본 서브 계정에서 스냅샷을 새로 고치거나 업데이트하고, 자산을 선택한 뒤 업데이트를 푸시하세요.

### 스마트 리스트의 공유 및 권한 설정도 함께 옮겨지나요?
아니요. 공유와 권한은 서브 계정마다 따로 적용되는 설정이라서, 대상 서브 계정에서 다시 설정해야 해요.
