# 장부 관리 업종용 스냅샷 (Bookkeeper Snapshot)

장부 관리(Bookkeeper) 업종에 맞춰 서브 계정을 만들 때 쓰는 기본 스냅샷이에요. 리드를 모으고 관리하고 계약으로 이어 가는 데 필요한 구성이 한 번에 들어 있어요.

## 설정 가이드

이 스냅샷에는 리드를 확보하고 관리하며 계약까지 이어 가는 데 필요한 도구가 모두 들어 있어요.

- 웹사이트
- 폼
- 캘린더
- 워크플로우
- 이메일 캠페인
- 온라인 광고
- 소셜 게시물

## 스냅샷 설치하기

스냅샷을 내 계정에 설치하는 방법과 설정 가이드가 필요하면 하이퍼클래스 고객지원에 문의하세요.

{% hint style="info" %}
원문에는 설정 가이드와 스냅샷 다운로드 링크가 있어요. 이 매뉴얼에서는 외부 링크를 제공하지 않으니, 하이퍼클래스 고객지원에 문의해 안내를 받으세요.
{% endhint %}
