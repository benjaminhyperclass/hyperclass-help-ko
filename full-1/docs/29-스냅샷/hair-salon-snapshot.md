# 헤어 살롱 스냅샷 설정 및 설치 가이드

헤어 살롱 스냅샷은 미용실 서브 계정을 만들 때 바로 쓸 수 있는 시작 템플릿이에요. 캘린더, 커스텀 필드, 폼, 퍼널, 파이프라인, 템플릿, 리뷰 설정, 워크플로우가 들어 있어서 런칭 전에 미용실에 맞게 바꿔 쓰면 돼요. 이 문서에서는 스냅샷에 무엇이 들어 있는지, 어떻게 가져와 설치하는지, 무엇이 옮겨지지 않는지, 어떤 설정을 직접 바꿔야 하는지, 런칭 전에 어떻게 테스트하는지 알려 드려요.

에이전시는 이 스냅샷으로 미용실에 필요한 계정 자산을 한 번에 가져와 반복 설정을 줄일 수 있어요. 새 서브 계정을 만들 때 쓰거나, 이미 있는 서브 계정에 불러올 수도 있어요.

스냅샷은 설정 템플릿이지 완성된 운영 계정이 아니에요. 사업 세부 정보, 직원, 캘린더, 도메인, 커뮤니케이션, 연동, 워크플로우, 고객에게 보이는 페이지는 활성화하기 전에 꼭 검토하고 테스트하세요.

{% hint style="warning" %}
설치 직후에 페이지를 게시하거나, 워크플로우를 활성화하거나, 메시지를 보내거나, 실제 전화 트래픽을 연결하지 마세요. 가져온 자산을 모두 검토하고 테스트한 뒤에 진행하세요. 스냅샷을 불러오는 것은 계정 백업이 아니고, 한 번에 되돌리는 기능도 아니에요.
{% endhint %}

## 헤어 살롱 스냅샷이란?

헤어 살롱 스냅샷은 미용실 서브 계정 설정을 빠르게 해 주는 재사용 가능한 계정 템플릿이에요. 캘린더, 필드, 페이지, 템플릿, 파이프라인, 워크플로우를 하나하나 새로 만들 필요 없이, 미용실에 맞춰진 기본 구조에서 시작할 수 있어요.

현재 이 스냅샷은 에이전시 스냅샷 라이브러리에 **V2 Industry - Beauty & Fashion - Hair Salon**이라는 이름으로 보여요. 설치한 뒤에는 가져온 자산을 미용실의 서비스, 직원, 브랜딩, 예약 규칙, 커뮤니케이션, 운영 방식에 맞게 바꿔 주세요.

### 헤어 살롱 스냅샷을 쓰면 좋은 점

반복 설정을 줄이면서, 미용실마다 서비스와 고객 여정에 맞게 바꿔 쓸 수 있는 일관된 기본 틀을 얻을 수 있어요.

- 빠른 계정 설정: 서브 계정을 처음부터 만들지 않고, 미용실용으로 준비된 자산에서 시작해요.
- 일관된 고객 온보딩: 여러 미용실 고객에게 같은 구조를 쓰고, 매장별 정보만 바꿔요.
- 준비된 예약 기반: 서비스별 캘린더와 캘린더 그룹으로 시작해요. 직원에게 배정하고 미용실 서비스에 맞게 수정하면 돼요.
- 리드 수집과 후속 관리: 포함된 폼, 퍼널, 파이프라인, 템플릿, 워크플로우를 미용실 리드 확보의 출발점으로 쓸 수 있어요.
- 재사용 가능한 마케팅 자산: 가져온 이메일 템플릿, 메시지 템플릿, 오퍼 페이지, 육성 자동화를 매장에 맞게 바꿔 써요.
- 유연한 적용: 스냅샷으로 새 서브 계정을 만들거나, 기존 계정에 필요한 자산만 불러올 수 있어요.

### 포함된 자산

설치하기 전에 자산 목록을 살펴보면 무엇이 추가되고 어떤 부분을 직접 바꿔야 하는지 알 수 있어요. 현재 V2 Industry Beauty & Fashion 스냅샷에는 11개 카테고리에 걸쳐 자산 60개가 들어 있어요.

### 설정 가이드에 함께 들어 있는 참고 자료

헤어 살롱 설정 가이드에는 스냅샷 자산 목록에 없는 구현 안내도 들어 있어요. 이 자료는 가져온 계정을 설정할 때 도움이 되지만, 스냅샷으로 자동 설치되는 자산은 아니에요.

- 계정 설정 안내: **비즈니스 프로필**, 사용자, 전화, 이메일, 도메인, 소셜 연결, 결제, 평판 설정
- 미용실 광고 예시: 미용실 오퍼를 홍보하는 광고 목업과 캠페인 안내
- Voice AI 안내: 자주 나오는 미용실 질문, 리드 선별, 예약을 위한 프롬프트 제안
- 빠르게 효과를 내는 추천 설정: 모바일 앱, 채팅 위젯, 부재중 전화 문자 회신, 결제 요청, 스니펫, 리뷰 요청
- 런칭 체크리스트: 폼, 퍼널, 웹사이트, 캘린더, 파이프라인, 워크플로우, 이메일 템플릿, Link-in-Bio 페이지를 업데이트하는 안내

헤어 살롱 설정 가이드가 필요하면 하이퍼클래스 고객지원에 문의하세요.

![헤어 살롱 설정 가이드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081027732/original/Wr-ZGJn8KkyuhFiahDu7J-1CeSjdx3-Dxg.png?1789532561)

참고 자료에 대한 안내: 현재 스냅샷 자산 목록에는 가져오는 광고 캠페인, 소셜 플래너 게시물, Voice AI 에이전트 카테고리가 없어요. 광고 목업, 소셜 안내, Voice AI 프롬프트는 설정을 돕는 참고 자료로 보세요. 이런 자산이 실제로 있는지는 대상 계정에서 직접 확인해야 해요.

## 포함되지 않는 항목

스냅샷은 재사용할 수 있는 설정 자산만 옮겨요. 미용실의 실제 고객 이력이나 인증이 필요한 외부 서비스는 옮기지 않아요. 아래 항목이 빠진다는 점을 알아 두면, 가져온 계정이 모든 연결이 끝난 운영 계정이라고 오해하지 않아요.

- 연락처와 가져온 고객 데이터베이스
- 대화, 메시지, 이메일, 대화 기록
- 예약과 지난 캘린더 활동
- 실제 평판 데이터와 기존 고객 리뷰
- Stripe 연결 등 결제 제공업체 인증
- 전화번호 소유권, 라우팅, 통신사 등록
- 이메일 도메인 인증과 DNS 레코드
- Facebook, Instagram, Google 비즈니스 프로필 등 외부 연동
- 직원 로그인 정보와 연결된 외부 캘린더
- 게시된 웹사이트 도메인과 실제 운영 중인 퍼널

## 설치하기 전에 준비할 것

설치 전에 에이전시와 대상 계정을 준비해 두면 가져오기 오류, 중복 자산, 기존 설정이 실수로 바뀌는 일을 줄일 수 있어요.

- **에이전시 관리자** 권한이나 필요한 스냅샷 권한이 있는지 확인하세요.
- 스냅샷으로 새 서브 계정을 만들지, 기존 서브 계정에 불러올지 정하세요.
- 무엇을 설치할지 고르기 전에 스냅샷의 자산 60개 목록을 살펴보세요.
- 대상 서브 계정이 이미 운영 중이면 기존 자산을 먼저 살펴보세요.
- 충돌하는 항목을 덮어쓰기 전에, 중요한 기존 설정을 내보내거나 따로 정리해 두세요.
- 미용실의 상호, 로고, 연락처, 주소, 웹사이트, 시간대, 통화, 서비스, 직원, 가격, 운영 시간을 모아 두세요.
- 필요한 도메인, 이메일 DNS, 전화 서비스, 소셜 계정, Google 비즈니스 프로필, 결제 제공업체에 접근할 수 있는지 확인하세요.
- 가져온 자산을 실제 고객에게 활성화하기 전에 테스트 기간을 잡아 두세요.

## 설치와 설정 방법

대상에 맞는 설치 방법을 고르세요. 공유 스냅샷을 가져오면 에이전시 라이브러리에 추가되고, 새로 만들거나 불러오면 자산이 특정 서브 계정에 적용돼요.

### 1단계: 공유 스냅샷 가져오기

스냅샷 공유 링크로 헤어 살롱 스냅샷을 에이전시 스냅샷 라이브러리에 추가해요. 공유 링크가 필요하면 하이퍼클래스 고객지원에 문의하세요.

1. 스냅샷을 받을 에이전시 계정에 로그인하세요.
2. 스냅샷 공유 링크를 여세요.
3. 스냅샷 정보를 확인하고, 필요하면 이름을 바꾸세요.
4. 스냅샷을 가져오세요.
5. **에이전시 보기 > 계정 스냅샷 > 가져온 스냅샷**으로 이동하세요.
6. 가져오기가 끝날 때까지 기다린 뒤에 스냅샷을 불러오세요.

{% hint style="info" %}
공유 링크를 열었을 때 로그인 화면이나 계정 선택 화면이 먼저 나오면, 사용할 에이전시에 로그인한 뒤 링크를 다시 여세요.
{% endhint %}

### 방법 A: 스냅샷으로 새 서브 계정 만들기

미용실에 중요한 자산이 든 활성 서브 계정이 아직 없다면, 새 계정을 만드는 방법이 가장 깔끔해요.

1. **에이전시 보기**에서 **계정 스냅샷**을 여세요.
2. 스냅샷이 있는 위치에 따라 **내 스냅샷** 또는 **가져온 스냅샷**을 여세요.
3. **V2 Industry - Beauty & Fashion - Hair Salon**을 검색하세요.
4. **Create new account**(새 계정 만들기)라고 적힌 파란색 **+** 아이콘을 클릭하세요.

![새 계정 만들기 아이콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081027751/original/jg18FgVq2UG3cyAmJGvzgj5i66iVvnZmHg.png?1789532634)

5. 미용실의 사업 정보를 입력하고 맞는지 확인하세요.
6. 서브 계정을 만드세요.
7. 스냅샷 자산이 모두 불러와질 때까지 기다리세요.
8. 새 서브 계정을 열고 아래 맞춤 설정 체크리스트를 시작하세요.

### 방법 B: 기존 서브 계정에 스냅샷 불러오기

기존 계정에 불러오면 실제 고객 데이터는 그대로 두고, 선택한 스냅샷 자산을 추가하거나 업데이트해요. 이 방법은 충돌 항목을 꼼꼼히 확인해야 해요.

{% hint style="warning" %}
충돌이 나는 항목을 모두 자동으로 덮어쓰지 마세요. **Override**(덮어쓰기)와 **건너뛰기** 중에서 고르기 전에 현재 자산과 가져올 버전을 비교해 보세요. 같은 스냅샷을 두 번 이상 불러오면 충돌이나 중복 자산이 생길 수 있어요.
{% endhint %}

1. **에이전시 보기**에서 **서브 계정**을 여세요.
2. 대상 서브 계정을 찾으세요.
3. **작업** 열의 점 세 개 메뉴를 열고 **고객 관리**를 선택하세요.

![서브 계정 작업 메뉴에서 고객 관리 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081027741/original/deZALAP_N8zARsOfYJiZ4gDPqoOOUkGCUg.png?1789532604)

4. **고객 관리** 화면에서 **작업**을 클릭한 뒤 **Load Snapshot**(스냅샷 불러오기)을 선택하세요.
5. 헤어 살롱 스냅샷을 선택하세요.
6. 모든 자산을 선택하거나, 계정에 필요한 카테고리만 선택하세요.
7. 감지된 충돌을 모두 확인하세요.
8. 충돌하는 자산마다 건너뛸지 덮어쓸지 고르세요.
9. 불러오기를 확인하세요.
10. 불러오기가 끝날 때까지 기다린 뒤에 가져온 자산을 편집하세요.

## 설치 후 맞춤 설정

맞춤 설정을 하면 가져온 템플릿이 해당 미용실에 맞는 계정으로 바뀌어요. 영향이 큰 계정 설정부터 먼저 끝내야 이후의 페이지, 캘린더, 메시지, 워크플로우에 정확한 정보가 반영돼요.

### 1순위: 비즈니스 프로필과 커스텀 값

- 상호와 법적 명칭
- 로고와 브랜드 아이덴티티
- 전화번호, 이메일 주소, 실제 주소, 시간대, 언어, 통화
- 웹사이트와 브랜드 링크
- 프로모션 이름
- 웹사이트 예약 페이지 URL
- 예약 완료 감사 페이지 URL

### 2순위: 직원과 캘린더

- 미용실 직원의 사용자 프로필을 만들거나 검토하세요.
- 직원을 알맞은 서비스 캘린더에 배정하세요.
- 서비스 이름, 설명, 소요 시간, 가격, 버퍼, 가용 시간, 예약 규칙을 업데이트하세요.
- 직원별로 지원되는 외부 캘린더를 연결하세요.
- 연결 캘린더와 충돌 캘린더를 설정해 중복 예약을 막으세요.
- 데스크톱과 모바일에서 예약 과정을 테스트하세요.

### 3순위: 폼, 퍼널, 웹사이트, Link-in-Bio 페이지

- 미용실 이름, 로고, 색상, 글꼴, 이미지, 연락처를 업데이트하세요.
- 임시로 들어 있는 서비스, 설명, 가격, 오퍼, 자주 묻는 질문을 바꾸세요.
- 오퍼 신청 폼과 동의 문구를 검토하세요.
- 모든 버튼, 메뉴 항목, 캘린더 링크, 전화 링크, 소셜 링크를 업데이트하세요.
- 페이지 제목, 설명, SEO 메타데이터를 검토하세요.
- 사용할 도메인을 연결하세요.
- 게시하기 전에 각 페이지를 미리보기로 확인하세요.

### 4순위: 파이프라인, 템플릿, 워크플로우

- 파이프라인 2개를 모두 검토하고, 미용실의 업무 방식에 맞게 단계를 수정하세요.
- **이메일 빌더 템플릿** 5개를 모두 검토하세요.
- **문자 & 이메일 템플릿** 2개를 모두 검토하세요.
- 가져온 워크플로우 7개를 모두 검토하세요.
- 각 트리거, 필터, 발신자, 액션, 링크, 대기 시간, 분기, 내부 알림을 확인하세요.
- 테스트하는 동안 워크플로우는 초안 상태로 두세요.
- 미용실이 쓸 준비가 된 워크플로우만 게시하세요.

### 5순위: 커뮤니케이션과 연동

- 알맞은 전화번호를 구매하거나 연결하고 라우팅을 설정하세요.
- 필요한 곳에서 메시지 발송 등록을 완료하세요.
- 전용 발송 도메인과 브랜드 링크를 설정하세요.
- 필요에 따라 Facebook, Instagram, Google 비즈니스 프로필, **소셜 플래너**를 연결하세요.
- 결제를 받기 전에 Stripe 또는 지원되는 다른 결제 제공업체를 연결하세요.
- 리뷰 요청을 보낼 위치와 메시지 템플릿을 설정하세요.
- 알맞은 채팅 위젯을 골라 설정하세요.
- 선택 사항으로 **Voice AI 에이전트**를 만들고, 실제 전화 트래픽을 연결하기 전에 테스트하세요.

## 런칭 전 테스트

처음부터 끝까지 테스트해 보면, 가져온 자산이 서로 잘 연결되고 미용실 정보가 맞게 쓰이는지 실제 리드와 고객이 들어오기 전에 확인할 수 있어요.

1. 내부 테스트용 연락처를 만드세요.
2. 가져온 미용실 오퍼 폼을 제출해 보세요.
3. 연락처 레코드에 예상한 커스텀 필드 데이터가 들어 있는지 확인하세요.
4. 의도한 파이프라인과 단계에 올바른 기회가 만들어졌는지 확인하세요.
5. 관련 캘린더나 **Service Menu**(서비스 메뉴)마다 테스트 예약하기를 진행하세요.
6. 워크플로우 등록 내역과 실행 기록을 확인하세요.
7. 모든 이메일, SMS, 내부 알림, 링크, 커스텀 값이 맞는지 확인하세요.
8. 웹사이트, 퍼널, Link-in-Bio의 버튼을 데스크톱과 모바일에서 테스트하세요.
9. 연결한 도메인과 게시한 페이지가 제대로 열리는지 확인하세요.
10. 결제 수금 테스트는 결제 제공업체를 설정한 뒤에만 하세요.
11. 채팅 위젯과 대화 라우팅을 테스트하세요.
12. Voice AI 에이전트를 쓴다면, 실제 업무용 번호를 연결하기 전에 테스트하세요.

## 문제 해결

스냅샷 문제는 대부분 권한, 가져오기 미완료, 자산 충돌, 계정별 설정 누락, 게시하지 않은 자산 중 하나가 원인이에요.

| 문제 | 확인할 내용 |
| --- | --- |
| 공유 링크를 열어도 가져오기 화면이 나오지 않아요 | 사용할 에이전시에 로그인한 뒤 링크를 다시 열고, 사용자에게 스냅샷 권한이 있는지 확인하세요. |
| 스냅샷이 회색으로 표시되거나 아직 가져오는 중이에요 | 가져오기 상태가 완료될 때까지 기다리세요. 오류가 표시되면 내용을 확인하고 필요하면 다시 시도하세요. |
| **Load Snapshot**(스냅샷 불러오기)이 보이지 않아요 | 에이전시 사용자에게 스냅샷 권한이 켜져 있는지 확인하세요. |
| 자산이 중복으로 생겼어요 | 스냅샷을 두 번 이상 불러왔는지, 충돌 항목을 건너뛰지 않고 가져왔는지 확인하세요. |
| 웹사이트나 퍼널이 공개되지 않아요 | 가져온 페이지는 초안 상태예요. 도메인을 연결하고 내용을 검토한 뒤 게시하세요. |
| 캘린더에 예약 가능한 시간이 없어요 | 배정된 직원, 스케줄, 서비스 설정, 충돌 캘린더를 확인하세요. |
| 워크플로우가 실행되지 않아요 | 게시 상태, 트리거, 필터, 발신자, 커스텀 값, 실행 기록을 확인하세요. |
| 페이지나 메시지에 임시 정보가 그대로 나와요 | **비즈니스 프로필**, 커스텀 값, 페이지 내용, 템플릿, 워크플로우 액션을 업데이트하세요. |

## 자주 묻는 질문

### 자산이 몇 개 들어 있나요?
현재 V2 Industry Beauty & Fashion 스냅샷에는 11개 카테고리에 걸쳐 자산 60개가 들어 있어요. 워크플로우는 7개예요.

### 스냅샷을 가져오는 것과 불러오는 것은 같은 건가요?
아니요. 가져오기는 공유 스냅샷을 에이전시 라이브러리에 추가하는 것이고, 불러오기는 선택한 자산을 특정 서브 계정에 적용하는 것이에요.

### 기존 서브 계정에도 불러올 수 있나요?
네. 필요한 카테고리만 선택하고, 불러오기를 확인하기 전에 모든 충돌 항목을 검토하세요.

### 스냅샷에 연락처나 예약도 포함되나요?
아니요. 스냅샷을 설치하면 선택한 설정 자산만 옮겨져요. 실제 연락처, 대화, 예약, 지난 고객 데이터는 옮겨지지 않아요.

### 가져온 페이지는 자동으로 게시되나요?
아니요. 가져온 웹사이트와 퍼널은 내용 검토, 도메인 설정, 경로 설정, 테스트, 게시를 거쳐야 해요.

### 스냅샷이 전화, 이메일, 소셜, Google, Stripe 계정을 연결해 주나요?
아니요. 외부 서비스와 인증이 필요한 연동은 따로 연결해야 해요.

### 광고 캠페인이나 Voice AI 에이전트도 설정되어 있나요?
확인된 자산 목록에는 해당 카테고리가 없어요. 설정 가이드에 광고 예시와 Voice AI 프롬프트 안내가 있으니, 이를 참고해 따로 설정하세요.

### 불러온 스냅샷을 통째로 제거할 수 있나요?
불러온 스냅샷은 하나의 패키지로 되돌릴 수 없어요. 가져온 자산은 하나씩 편집하거나 비활성화하거나 삭제할 수 있어요.
