# 카이로프랙틱 병원을 위한 올인원 성장 시스템 시작 가이드

카이로프랙틱 병원이 하이퍼클래스를 처음 쓸 때 갖춰야 할 기본 설정을 단계별로 정리했어요. CRM 설정, 예약 캘린더, Google 비즈니스 프로필, 필수 연동까지 차례대로 따라 해 보세요.

카이로프랙틱 병원을 운영하는 일은 쉽지 않아요. 환자 진료, 갑작스러운 예약 취소, 직원 관리, 놓친 전화 확인, 병원 성장까지 한꺼번에 챙겨야 하죠. 대부분의 날이 체계적이고 수익성 있는 운영을 만들기보다 눈앞의 불을 끄는 데 쓰이기도 해요.

병원이 이런 시스템으로 돌아간다면 어떨까요? 단순 업무는 자동으로 처리되고, 리드는 한곳에 정리되고, 놓치는 기회가 없는 시스템이에요. 하이퍼클래스가 바로 이 일을 도와줘요.

---

## 첫날 준비할 것

### 1. CRM과 환자 파이프라인 설정하기

CRM은 디지털 서류함이라고 생각하면 돼요. 다만 훨씬 똑똑해요. 종이 파일이나 스프레드시트를 뒤질 필요 없이, 모든 정보가 한곳에 모이고 자동으로 업데이트돼요.

- 기존 환자와 리드를 모두 하이퍼클래스에 업로드하세요.
- "신규 리드", "상담 예약됨", "현재 환자", "30일 비활성" 같은 태그를 만들어 데이터베이스를 정리하세요.
- 환자 파이프라인을 명확하게 만드세요. 신규 리드 → 상담 예약 → 케어 플랜 진행 중 → 노쇼/후속 관리 → 재활성화 순서로 구성할 수 있어요.

{% hint style="info" %}
연락처는 직접 추가하거나 스프레드시트로 가져올 수 있어요. 접수 폼과 리드 수집 퍼널을 통해 하이퍼클래스가 자동으로 채워 주게 할 수도 있어요.
{% endhint %}

[연락처 만들기](../../01-시작하기/기본-설정/getting-started-create-and-manage-contacts.md)

### 2. 온라인 예약 캘린더 켜기

요즘 환자들은 전화하기보다 온라인으로 몇 초 만에 예약하길 원해요.

- 하이퍼클래스 안에 캘린더를 만들어 환자가 직접 예약할 수 있게 하세요.
- 버퍼 시간, 가용 시간, 자동 확인 이메일, 리마인더를 추가하세요.
- 이 캘린더를 병원 웹사이트, Google 프로필, 소셜 미디어에 링크로 걸어 두세요.

{% hint style="info" %}
신규 환자 상담, 교정 치료, 후속 방문처럼 예약 종류가 여러 가지라면 캘린더를 여러 개 만들어 쓰세요.
{% endhint %}

[하이퍼클래스로 개인 예약 캘린더 설정하기](../../04-캘린더-예약/기타/how-to-set-up-a-personal-booking-calendar-with-hyperclass.md)

### 3. 기본 환자 자동화 시작하기

아무리 신경 써도 바쁠 때는 후속 연락이 빠지기 쉬워요. 자동화를 켜 두면 아무도 놓치지 않아요.

다음 세 가지 워크플로우로 시작해 보세요.

- 환자가 예약하면 SMS와 이메일로 확인 메시지 보내기
- 예약 24시간 전에 친절한 리마인더 보내기
- 방문 후 감사 메시지와 함께 리뷰 요청 보내기

{% hint style="info" %}
리마인더를 사용하는 병원은 노쇼가 30% 넘게 줄어요.
{% endhint %}

[자동화 설정하기](../../07-워크플로우/introduction-to-workflows-and-automations.md)

---

### 4. Google 비즈니스 프로필 설정하고 최적화하기

Google 비즈니스 프로필은 병원의 디지털 간판이에요. 신규 환자 대부분이 웹사이트를 클릭하기도 전에 이 프로필로 병원을 찾아요.

- 주소, 전화번호, 진료 시간, 웹사이트가 정확한지 확인하세요.
- 병원 내부, 직원, 만족한 환자의 사진을 추가하세요.
- 프로필에 하이퍼클래스 예약 링크를 넣으세요.
- 메시지 기능을 켜서 환자가 검색 결과에서 바로 문자를 보낼 수 있게 하세요.

{% hint style="info" %}
환자의 92%는 온라인 리뷰를 지인 추천만큼 신뢰해요. Google 프로필을 빠짐없이 채우고 꾸준히 관리하면 검색 순위가 오르고, 검색한 사람이 예약으로 이어질 확률도 높아져요.
{% endhint %}

---

### 5. 부재중 전화 문자 회신 켜기

환자나 리드가 전화했는데 아무도 받지 못하면 그 사람을 영영 놓칠 수 있어요. **부재중 전화 문자 회신** 기능 하나로 이 문제를 해결할 수 있어요.

- **부재중 전화 문자 회신**을 켜 두면 전화를 놓칠 때마다 하이퍼클래스가 자동으로 이런 메시지를 보내요.

  "안녕하세요! 전화를 받지 못해 죄송해요. [병원 이름]입니다. 무엇을 도와드릴까요?"
- 신규 리드, 기존 환자 등 대상에 따라 메시지를 다르게 설정할 수 있어요. **AI 리셉셔니스트**로 메시지를 연결할 수도 있어요.

  관련 문서: **통화 연결** & **부재중 전화 문자 회신**

---

### 6. 하이퍼클래스 계정 설정 마무리하기

백엔드 설정까지 마쳐야 준비가 끝나요. 사소해 보여도 시스템이 뒤에서 돌아가게 하는 중요한 설정이에요.

- **비즈니스 프로필**에서 사업체 이름, 연락처, 시간대, 병원 로고를 설정하세요.
- **Google My Business**, **Facebook**, **Instagram** 계정을 연결해 모든 리드와 대화를 한곳에서 관리하세요.
- 병원의 진료 흐름에 맞게 파이프라인 단계를 고르거나 직접 수정하세요.
- 기본 캘린더, 알림, 리드 소스를 설정하세요.
- 예약이나 후속 연락을 맡는 팀원이 있다면 사용자 권한을 설정하세요.

{% hint style="warning" %}
이 설정은 모든 것이 매끄럽게 흘러가게 하는 배관 같은 역할을 해요. 건너뛰면 나중에 혼란이 생길 수 있어요.
{% endhint %}

## 기대 효과: 행정 업무는 줄고 예약은 늘어요

설정을 마치면 하루 일과가 이렇게 달라져요.

- 접수 담당자가 전화기에 매달리지 않아도 돼요. 환자가 직접 예약해요.
- 놓친 후속 연락이나 잊힌 리드를 걱정하지 않아도 돼요.
- 모든 연락처가 도구 세 개나 포스트잇에 흩어지지 않고 한 시스템에 모여요.
- Google을 통한 리뷰, 소개, 방문 환자가 늘기 시작해요.

한마디로, 일이 잘 풀리기를 바라기만 하는 게 아니라 잘 풀리게 만드는 시스템이 생기는 거예요.
