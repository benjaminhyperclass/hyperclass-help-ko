# 배관업체를 위한 소셜 미디어 플레이북: 게시물로 예약과 수익 늘리기

배관업체가 소셜 미디어로 신뢰를 쌓고, 광고로 예약을 늘리고, 하이퍼클래스로 게시와 응대를 자동화하는 방법을 4단계로 안내해요. 소셜 미디어를 어떻게 운영해야 할지 막막할 때 참고하세요.

## 이 플레이북이 필요한 이유

누수를 고치고, 온수기를 교체하고, 긴급 출동도 하시죠. 그런데 새 고객이 계속 들어오게 하려고 어떤 노력을 하고 계신가요?

대부분의 배관업체는 입소문이나 일회성 전화에 의존해요. 하지만 지금은 상황이 달라요.

### 업계 지표

- ✅ 고객의 76%는 전화하기 전에 소셜 미디어에서 배관 서비스를 알아봐요.
- ✅ 주택 소유자의 47%는 온라인에서 최근 게시물이나 후기가 있는 배관업체를 처음 발견하면 그곳을 예약해요.
- ✅ 일주일에 3회 이상 게시하는 업체는 리드가 2.5배 더 많이 생겨요.

그런데도 대부분의 배관업체는 이렇게 하고 있어요.

- 꾸준히 게시하지 않아요.
- 문의에 충분히 빨리 답하지 않아요.
- 어떤 콘텐츠가 예약으로 이어지는지 몰라요.

> 소셜 미디어는 신뢰, 노출, 더 많은 작업으로 이어져요. 제대로 운영했을 때의 이야기예요.

```
하이퍼클래스로 자동화하고, 광고하고, 시장을 선점해 보세요
```

## 이 플레이북에서 배울 내용

✅ Facebook과 Instagram을 예약이 들어오는 창구로 만드는 방법  
✅ 배관 리드를 모으는 데 좋은 콘텐츠와 올리면 안 되는 콘텐츠  
✅ 주택 소유자, 건물 관리자, 상업 고객을 타깃팅하는 방법  
✅ 콘텐츠 게시, 답글, 리드 후속 연락을 자동화하는 방법  
✅ 적은 비용으로 단가 높은 배관 작업을 끌어오는 광고 운영 방법

## 1단계: 탄탄한 소셜 미디어 기반 만들기

### 왜 중요한가요?

고객이 온라인에서 업체를 찾지 못하거나 믿지 못하면 다른 업체를 선택해요.

### 1.1 배관업에 맞는 플랫폼 고르기

| 플랫폼 | 이럴 때 좋아요 |
| --- | --- |
| Facebook | 지역 내 신뢰 쌓기, 동네 그룹, 주택 소유자 대상 홍보 |
| Instagram | 시공 전후 사진, 누수 피해 사진, 릴스 |
| LinkedIn | 시설 관리자, 기업 간(B2B) 배관 계약 |
| YouTube | 배관 팁, 제품 설치, "배수구 막힘 예방법" 같은 영상 |
| GBP | 리뷰, 연락처, 지역 검색 순위 |

사용 사례: 텍사스의 한 배관업체가 Instagram에 "10분 안에 막힌 배수구를 뚫은 방법" 같은 짧은 영상을 올리기 시작했어요. 그 결과 2주 만에 새 작업 21건을 따냈어요.

## 2단계: 반응을 얻는 배관 콘텐츠 만들기

### 왜 중요한가요?

하루 종일 배관만 보고 싶은 사람은 없어요. 하지만 잘 만든 콘텐츠는 고객을 이해시키고, 신뢰를 쌓고, 예약까지 이끌어요.

### 2.1 결과를 만드는 콘텐츠

| 콘텐츠 유형 | 예시 |
| --- | --- |
| 시공 전/후 | "15년 된 녹슨 배관을 교체했어요. 과정을 보여 드릴게요." |
| 고객 후기 | "온수기가 터져서 연락 주신 존 님. 4시간 만에 다시 쓸 수 있게 해 드렸어요!" |
| 짧은 팁 | "온수기 물을 1년에 한 번 빼 줘야 하는 이유" |
| 긴급 상황 설명 | "변기가 넘칠 때 이렇게 하세요" |
| 서비스 프로모션 | "이번 주만 배수구 청소 75달러 할인!" |
| 현장 비하인드 | "상업용 보일러 교체 현장에서!" |

콘텐츠 원칙:  
80%는 도움이 되고 흥미로운 내용  
20%는 직접적인 홍보

#### [기존 템플릿으로 광고 캠페인 만드는 방법](../../10-마케팅/Ad-Campaign-Creation-and-Management/ad-manager-create-ad-campaigns-using-templates.md)

### 2.2 알맞은 해시태그와 태그 쓰기

- Instagram/Facebook: `#EmergencyPlumber`, `#DrainCleaning`, `#WaterHeaterRepair`
- LinkedIn: `#CommercialPlumbing`, `#FacilityMaintenance`, `#PlumbingPros`
- Google 게시물: 지역 키워드를 쓰세요. `Plumber in Chicago`, `Water Line Replacement Dallas`

## 3단계: 적은 비용으로 전환되는 광고 운영하기

### 왜 중요한가요?

광고 없이 게시물을 보는 팔로워는 5~10%뿐이에요. 광고를 쓰면 일정이 금방 채워져요.

### 3.1 배관업에 맞는 광고 전략

- Facebook 리드 광고: "배수구 청소 특가 99달러 – 지금 온라인으로 예약하세요"
- 리타기팅 광고: 사이트를 방문했지만 예약하지 않은 사람에게 광고를 보여 줘요.
- YouTube 광고: "누수 찾는 법" 영상을 보여 주고, 영상 끝에서 내 서비스를 홍보해요.
- Google 로컬 서비스 광고(LSA): "Emergency Plumber Near Me" 검색 결과 맨 위에 나타나요.

#### 청소 업체를 위한 Facebook 광고 운영 방법

### 3.2 알맞은 타깃 정하기

- 우편번호 + 반경 타기팅(10~20마일)
- 연령: 30~65세 이상 주택 소유자
- 관심사: 집 수리, 부동산 소유, 시설 관리

### 3.3 배관 광고 예산 가이드

| 업체 규모 | 권장 광고비 |
| --- | --- |
| 1인 배관업체 | Facebook·Instagram 리드 광고에 하루 10달러(월 300달러) |
| 소규모 팀 | 여러 플랫폼 전략에 하루 25달러(월 750달러) |
| 프랜차이즈 | 브랜드 인지도 + 리드 확보에 하루 50달러 이상(월 1,500달러 이상) |

## 4단계: 하이퍼클래스로 자동화하고 확장하기

### 왜 중요한가요?

현장에서 일하는 동안에는 온라인을 계속 볼 수 없어요. 일하는 사이에는 하이퍼클래스가 마케팅을 맡아 줘요.

### 4.1 모든 게시물을 미리 예약하기

- 하이퍼클래스의 **소셜 플래너**를 쓰면 주 5회 게시를 자동으로 할 수 있어요.

### 4.2 리드에게 24시간 자동으로 답하기

- 하이퍼클래스의 **대화 AI**가 DM과 댓글에 바로 답해요.
- 트리거 예시: "'LEAK'라고 DM 보내 주시면 무료 점검을 받으실 수 있어요."

### 4.3 성과 확인하기

- 어떤 콘텐츠가 리드를 만드는지 확인해요.
- 소셜 미디어에서 예약된 작업으로 이어지는 전환율을 살펴봐요.
