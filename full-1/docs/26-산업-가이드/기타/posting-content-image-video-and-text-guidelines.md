# 소셜 플래너 콘텐츠 가이드라인: 이미지, 동영상, 글 길이

**소셜 플래너**로 SNS에 게시할 때 플랫폼별로 지원되는 이미지·동영상 조건, 글자 수 제한, 게시 속도 제한을 정리한 문서예요. 게시하기 전에 파일과 글이 조건에 맞는지 확인할 때 참고하세요.

{% hint style="info" %}
참고

1. 멀티미디어 형식: 이미지와 동영상을 한 게시물에 함께 올리는 방식이에요.
2. 여러 종류의 이미지를 올려 보면 우리 브랜드에 어떤 이미지가 잘 맞는지 알게 돼요. 기본적으로는 아래 두 가지 크기가 가장 좋아요.

   1. 가로형(landscape): 1,024픽셀 x 512픽셀
   2. 세로형(portrait): 800픽셀 x 1,200픽셀
{% endhint %}

## 자주 묻는 질문

### 소셜 네트워크에서는 지원하는 파일인데 소셜 플래너에서는 왜 거부되나요?

소셜 플래너는 하이퍼클래스와 연결된 플랫폼 API가 지원하는 요구 사항을 따라요. 그래서 소셜 네트워크의 웹사이트나 앱에서 직접 게시할 때 허용되는 제한과 다를 수 있어요.

### 소셜 플래너가 미디어를 자동으로 최적화해 주나요?

소셜 플래너는 지원되는 미디어를 소셜 게시에 맞게 최적화할 수 있어요. 그래도 게시하기 전에 해당 파일 크기, 길이, 가로세로 비율, 게시물 유형별 요구 사항을 직접 확인하세요.

### 이미지와 동영상을 한 게시물에 함께 올릴 수 있나요?

소셜 네트워크와 게시물 유형에 따라 달라요. 멀티미디어 지원 여부는 이 문서의 추가 소셜 게시 가이드라인 섹션에서 확인하세요.

### 모든 동영상에 사용자 지정 썸네일을 추가할 수 있나요?

아니요. 사용자 지정 썸네일은 플랫폼과 게시물 유형에 따라 지원 여부가 달라요. 게시하기 전에 동영상 가이드라인 표의 **썸네일 지원** 열을 확인하세요.

### 소셜 플래너의 YouTube 제한이 YouTube 자체 제한과 왜 다른가요?

이 문서는 하이퍼클래스 소셜 플래너로 게시할 때 지원되는 제한을 정리한 거예요. YouTube에 직접 업로드할 때 쓸 수 있는 제한과는 다를 수 있어요.
