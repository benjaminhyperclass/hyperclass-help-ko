# 레스토랑 웹사이트 꾸미고 게시하기

**레스토랑 웹사이트**를 만들면 손님이 픽업·배달을 주문하고 테이블을 예약할 수 있는 우리 가게만의 웹사이트를 운영할 수 있어요. 이 문서에서는 페이지 편집, 웹사이트 설정, 방문자 활동 추적, 게시하는 방법을 안내해요.

## 레스토랑 웹사이트란?

**레스토랑 웹사이트**(Restaurant Website)는 하이퍼클래스에 들어 있는 웹사이트 기능이에요. 웹사이트를 처음부터 만들지 않아도 온라인에서 가게를 알릴 수 있어요. 메뉴, 가게 정보, 주문 방식, 예약을 하나의 웹사이트에 연결해 줘요.

웹사이트에는 탭이 세 개 있어요.

| 탭 | 설명 |
| --- | --- |
| **대시보드** | 픽업·배달·예약이 준비됐는지 확인해요. 웹사이트 현황을 보고, 미리보기와 게시도 할 수 있어요. |
| **Restaurant pages**(레스토랑 페이지) | 손님이 보는 모든 페이지를 라이브 미리보기를 보면서 편집해요. 템플릿, 색상, 글꼴도 여기서 정해요. |
| **Setup and sharing**(셋업 및 공유) | 웹 주소를 열 때 처음 보일 페이지, 손님 로그인 방식, 연락처 정보, 웹 주소, 공유할 때 링크가 보이는 모양, 트래킹을 설정해요. |

---

## 레스토랑 웹사이트의 장점

하이퍼클래스에서 이미 관리하는 정보를 그대로 쓰면서, 일관된 온라인 경험을 만들 수 있어요.

- 바로 시작할 수 있어요: 이미 등록한 메뉴, 영업시간, 주소, 브랜드를 그대로 쓰기 때문에 셋업이 끝나면 바로 미리보기를 볼 수 있어요.
- 주문과 예약을 한곳에서 받아요: 손님이 같은 웹사이트에서 픽업·배달을 주문하고 테이블도 예약해요.
- 라이브 미리보기로 편집해요: 섹션을 켜고 끄고, 순서를 바꾸고, 문구를 고치면 바뀐 모습이 바로 보여요.
- 우리 브랜드에 맞게 꾸며요: 템플릿, 색상, 라이트·다크 모드, 간격, 모서리, 글꼴을 고를 수 있어요.
- 나만의 도메인을 쓸 수 있어요: 무료 웹 주소를 쓰거나, 가지고 있는 도메인을 연결해요.

## 레스토랑 웹사이트와 대시보드 열기

대시보드에서는 웹사이트가 얼마나 준비됐는지, 성과는 어떤지 한눈에 볼 수 있어요. 대시보드를 열기 전에 **Restaurant Setup**(레스토랑 셋업)을 먼저 끝내세요. 가게 정보, 메뉴, 결제 제공업체, 픽업·배달·예약 설정이 모두 포함돼요.

1. 왼쪽 메뉴에서 **레스토랑**을 클릭하세요.
2. **레스토랑 웹사이트**를 선택하세요.
3. **대시보드** 탭이 자동으로 열려요.

![레스토랑을 클릭한 다음 레스토랑 웹사이트를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084913168/original/Rwcf6XfNjw85jRVbUde6B9-kl1c5oyyQ1A.png?1793783552)

대시보드에서는 다음 내용을 볼 수 있어요.

- **Setup complete**(셋업 완료): **Preview website**(웹사이트 미리보기)를 클릭하면 웹사이트를 확인할 수 있어요. **Publish website**(웹사이트 게시)를 클릭하면 웹사이트가 공개돼요.
- 손님이 주문하고 예약하는 방법: **Pickup**(픽업), **Delivery**(배달), **예약**마다 준비 여부가 표시돼요. **Pickup settings**(픽업 설정), **Delivery settings**(배달 설정), **Reservation settings**(예약 설정)를 클릭하면 각각 변경할 수 있어요.
- 웹사이트 현황: **Today**(오늘), **Last 7 days**(최근 7일), **최근 30일**, **사용자 지정** 중에서 기간을 고르세요. 온라인 **주문**, **Net sales**(순매출), **Online reservations**(온라인 예약)을 일별 차트와 함께 볼 수 있어요.

![셋업을 마친 뒤의 대시보드. 손님이 주문하고 예약하는 방법과 웹사이트 현황이 보인다.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084913192/original/_VAwrmim6YQUfJ96z2JFVb3em9ArH4T2bA.png?1793783566)

{% hint style="info" %}
탐색 패널에서 **레스토랑 웹사이트** 옆의 화살표를 선택하면 각 탭으로 바로 이동할 수 있어요. **Restaurant Setup**을 마치면 대시보드도 자동으로 열려요.
{% endhint %}

## 레스토랑 웹사이트 페이지 편집하기

**Restaurant pages** 편집기에서는 방문자가 웹사이트에서 보는 내용을 관리해요. 바뀐 내용이 라이브 미리보기에 바로 나타나기 때문에 레이아웃을 확인하면서 페이지를 꾸밀 수 있어요.

웹사이트에는 다음 페이지가 있어요.

| 페이지 | 용도 |
| --- | --- |
| **홈** | 손님이 처음 도착하는 페이지예요. 대표 메뉴, 카테고리, 사진, 영업시간, 위치를 보여 줄 수 있어요. |
| **Menu page**(메뉴 페이지), **Cart drawer**(장바구니), **Checkout**(체크아웃), **Order confirmation**(주문 확인) | 손님이 메뉴를 둘러보고, 장바구니에 담고, 주문을 확인한 뒤 결제해요. 마지막으로 주문 확인 화면을 봐요. |
| **Reservations page**(예약 페이지), **예약 페이지**, **Booking confirmation**(예약 확인), **Manage reservation**(예약 관리) | 시간을 선택해 테이블을 예약하고, 확인 화면을 봐요. 나중에 예약을 변경하거나 취소할 수도 있어요. |
| **Sign-in page**(로그인 페이지) | 손님이 이메일과 6자리 코드로 로그인해요. |
| **Dine-in menu**(매장 식사 메뉴) | 손님이 테이블에 있는 코드를 스캔해서 메뉴를 봐요. 주문은 직원이 받아요. |

![레스토랑 웹사이트의 페이지 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084913707/original/SxYB_6NaBS4QDWUB4zW9XhPVxIWdKcVE9w.png?1793783778)

### 웹사이트 페이지 편집하기

페이지 편집기는 콘텐츠 편집 영역과 라이브 미리보기가 나뉘어 있어요. 그래서 가게의 메뉴 설정은 건드리지 않고 각 페이지만 수정할 수 있어요.

1. **Restaurant pages** 탭을 클릭하세요.
2. 왼쪽 목록에서 편집할 페이지를 클릭하세요. 예를 들어 **홈**을 클릭해요.
3. 내용을 수정하세요. 오른쪽 미리보기에 수정한 내용이 바로 나타나요.

![Restaurant pages 화면. 왼쪽에서 페이지를 고르고, 가운데에서 섹션을 편집하고, 오른쪽에서 라이브 미리보기를 확인한다.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084913816/original/QvU97weLi3yq78rzbAVHzKxKmscaUW4Vyg.png?1793783811)

**홈** 페이지에서는 다음 섹션을 꾸밀 수 있어요.

- **Hero banner**(히어로 배너): 손님이 가장 먼저 보는 영역이에요. 가게 이름, 짧은 문구, 버튼, 사진이 들어가요.
- **Featured items**(대표 메뉴)와 **Featured categories**(대표 카테고리): 메뉴에 있는 음식과 카테고리를 보여 줘요.
- **Text and image**(텍스트와 이미지)와 **Image gallery**(이미지 갤러리): 가게 이야기와 사진을 보여 줘요.
- **Order Now band**(지금 주문 띠): 손님을 주문으로 이끄는 띠 영역이에요.
- **Hours and location**(영업시간 및 위치): 주소, 전화번호, 영업시간, 길 안내를 보여 줘요.

편집할 섹션을 선택하면 내용을 수정할 수 있어요. 다음 작업도 할 수 있어요.

- 섹션을 끌어서 순서를 바꿔요.
- 섹션 토글을 켜거나 꺼서 표시 여부를 정해요.
- **Add section**(섹션 추가)을 클릭해 콘텐츠를 더해요.
- **Remove section**(섹션 삭제)을 선택해 기존 섹션을 지워요.

**Hero banner**에서는 제목, 문구, **Order**(주문)와 **Book**(예약) 버튼, 이미지를 수정할 수 있어요. **Book** 버튼 입력란을 비워 두면 그 버튼이 숨겨져요.

이미지는 PNG, JPG, GIF, WEBP 형식을 쓸 수 있고, 파일 크기는 최대 5MB예요. 해상도는 2160 × 1080 픽셀을 권장해요.

![편집을 위해 열어 둔 Hero banner 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084913948/original/ycSyabHQk1AfNv8VQyek5EhXUYNAMAvcSQ.png?1793783863)

다른 페이지에도 각각 편집할 수 있는 옵션이 있어요. 예를 들어 **Sign-in page**의 제목이나 **Checkout** 페이지의 문구와 팁 설정을 바꿀 수 있어요.

웹사이트 전체에 공통으로 들어가는 요소는 **Every page**(모든 페이지) 아래의 **Header & navigation**(헤더 및 내비게이션)과 **Footer**(푸터)에서 수정해요.

{% hint style="info" %}
메뉴 항목, 가격, 카테고리는 **레스토랑 > 메뉴**에서 따로 관리해요. 자세한 방법은 [레스토랑 메뉴 관리 및 꾸미기](how-to-manage-and-customize-a-restaurant-menu-in-hyperclass.md)를 참고하세요. 메뉴가 웹사이트에 보이는지는 메뉴 이용 가능 여부와 주문 채널 설정에 따라 달라질 수 있어요.
{% endhint %}

## 웹사이트 디자인 꾸미기

웹사이트 스타일은 페이지의 겉모습을 결정해요. 디자인을 일관되게 정해 두면 주문과 예약 과정 내내 가게의 브랜드가 눈에 잘 띄어요.

**Restaurant pages > 디자인 > 스타일**로 이동해 다음 항목을 설정하세요.

| 설정 | 선택할 수 있는 옵션 |
| --- | --- |
| **템플릿** | **Classic**, **Modern**, **Bold** |
| **기본 색상** | 브랜드의 기본 색상을 골라요. 처음에는 로고에서 가져온 색이 들어가 있어요. |
| **Page mode**(페이지 모드) | **라이트**, **Dark**(다크), **자동** |
| **Density**(밀도) | **Compact**(촘촘하게), **Comfortable**(적당하게), **Spacious**(넓게) |
| **Corners**(모서리) | **Sharp**(각지게), **Soft**(부드럽게), **Rounded**(둥글게) |
| **글꼴** | **Modern sans**, **Editorial**, **Classic** 같은 글꼴 조합 프리셋을 고르거나, 제목 글꼴과 본문 글꼴을 따로 고를 수 있어요. |

템플릿마다 레이아웃이 달라요. **Classic**은 이미지를 제목 옆에 두고, **Modern**은 제목을 이미지 위에 올려요. **Bold**는 더 큰 글자와 안쪽으로 들어간 이미지를 써요.

![스타일 화면. 템플릿, 기본 색상, 페이지 모드를 고른다. 밀도, 모서리, 글꼴은 더 아래에 있다.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084914077/original/EuoWCFkMzwyNNYcs4N_vCHg-QIPmWIu-fA.png?1793783918)

## 웹사이트 셋업, 도메인, 트래킹 설정하기

**Setup and sharing** 탭에서는 손님이 웹사이트에 들어오는 방식, 웹사이트를 공유했을 때 보이는 모양, 방문자 행동을 추적하는 방식을 설정해요.

### 랜딩 페이지, 손님 로그인, 연락처 정보

손님이 처음 보는 페이지, 체크아웃할 때의 로그인 방식, 가게의 지원 정보를 확인할 수 있는 위치를 정해요.

1. **Setup and sharing > 셋업**으로 이동하세요.
2. **랜딩 페이지**에서 웹사이트 주소를 열었을 때 방문자가 볼 페이지를 선택하세요.
3. **Sign-in settings**(로그인 설정)를 확인하세요. 손님은 이메일로 받은 일회용 코드로 로그인해요. 저장된 정보 덕분에 다음 체크아웃이 더 빨라져요.
4. **Contact and footer**(연락처 및 푸터)에서 **지원 이메일**과 **Copyright line**(저작권 문구)을 입력하세요.
5. **변경사항 저장**을 클릭하세요.

저작권 문구에 `{{name}}`과 `{{year}}`를 쓰면 가게 이름과 연도가 자동으로 바뀌어요.

{% hint style="info" %}
**When guests check out**(손님이 체크아웃할 때)에서는 지금 **Require it**(필수)만 선택할 수 있어요. **Never ask**(묻지 않음)와 **Offer it**(선택 제공)은 **출시 예정**으로 표시돼 있어요.
{% endhint %}

![셋업 화면. 랜딩 페이지, 손님 로그인 방식, 연락처 정보를 설정한다.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084938898/original/z2fglsIbiwLXTw752YVnJAo9jFsS57_Uxg.png?1793795600)

### 도메인과 SEO 설정

도메인과 SEO 설정에서는 웹사이트 주소와, 브라우저 탭과 공유 링크에 웹사이트가 보이는 모양을 정해요.

1. **Setup and sharing > Link and SEO**(링크 및 SEO)로 이동하세요.
2. **Web Address**(웹 주소)에서 다음 중 하나를 설정하세요.
   - **Subdomain**(서브도메인): 무료 웹사이트 주소의 앞부분을 수정해요. 주소는 `.app.clientclub.net`으로 끝나요. 복사 아이콘을 누르면 전체 주소를 복사할 수 있어요.
   - **Custom domain**(내 도메인): 가지고 있는 도메인을 입력하고 **도메인 추가**를 클릭해요.
3. **Search and Sharing**(검색 및 공유)에서 다음을 설정하세요.
   - **Website title**(웹사이트 제목): 브라우저 탭과 공유 링크에 표시되는 제목이에요. 최대 70자까지 쓸 수 있어요.
   - **Share image**(공유 이미지): 웹사이트 링크를 공유할 때 보이는 이미지예요. 바꾸기 전까지는 로고가 기본으로 쓰여요.
   - **Favicon**(파비콘): 브라우저 탭에 표시되는 아이콘이에요. 로고가 기본으로 쓰여요.
4. **변경사항 저장**을 클릭하세요.

### Meta Pixel 트래킹

Meta Pixel 트래킹을 쓰면 게시된 레스토랑 웹사이트에서 일어나는 방문자 행동 중 지원되는 것을 측정할 수 있어요. 이벤트 매핑은 웹사이트에서 일어나는 행동을 Meta 이벤트에 연결해서, 리포팅과 캠페인 성과 측정에 쓰게 해 줘요.

트래킹을 설정하는 방법은 다음과 같아요.

1. **Setup and sharing** 탭을 클릭한 다음 **Tracking**(트래킹)을 클릭하세요.
2. Meta Pixel ID를 입력하세요. Meta Events Manager의 **Data sources**(데이터 소스)에서 확인할 수 있어요.
3. **Event mapping**(이벤트 매핑)을 확인하세요. 손님이 아래와 같이 행동할 때 어떤 Meta 이벤트가 전송되는지 보여 줘요.
   - 페이지 보기
   - 메뉴 보기 또는 담기
   - 체크아웃 시작
   - 결제 정보 입력
   - 주문 완료
   - 예약 시작
   - 보증금 결제
   - 예약 완료
4. **변경사항 저장**을 클릭하세요.

![Meta Pixel ID를 입력하는 화면. 이벤트 매핑에서 손님의 행동마다 어떤 Meta 이벤트가 전송되는지 볼 수 있다.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084939337/original/eLz_H3maaKVhidzPlgkreuLlrCyw0DRUtw.png?1793795762)

{% hint style="warning" %}
중복 트래킹을 막으려면 Pixel ID는 전용 **Tracking** 설정에만 입력하고, **Custom code**(커스텀 코드)에는 입력하지 마세요. 이벤트는 편집기가 아니라 게시된 웹사이트에서 전송돼요.
{% endhint %}

## 레스토랑 웹사이트 미리보기와 게시

게시하기 전에 미리 보면 손님이 페이지를 둘러보고, 메뉴를 보고, 설정해 둔 주문·예약 옵션을 이용할 수 있는지 확인할 수 있어요.

1. **Restaurant pages**에서는 **미리보기**를, 대시보드에서는 **Preview website**를 클릭하세요. 그리고 손님이 되어 모든 페이지를 확인하세요.
2. 변경한 내용이 있으면 먼저 저장하세요. **Publish website**를 클릭하면 게시하기 전에 변경사항을 저장하라고 안내해요.
3. **Publish website**를 클릭하세요.

게시하면 손님이 웹사이트에서 픽업·배달 주문을 하거나 예약할 수 있어요. 설정해 둔 서비스에 따라 이용할 수 있는 기능이 달라져요.

게시하면 **Restaurant Orders**(레스토랑 주문)의 **Ordering off** 상태도 해제되고, 웹사이트에서 온라인 예약을 받을 수 있게 돼요. 주문과 결제 관리는 [레스토랑 주문: 주문과 결제 관리하기](restaurant-orders-how-to-manage-orders-and-payments.md)를 참고하세요.

{% hint style="warning" %}
게시하기 전에 **레스토랑 설정 > Checkout and payments**(체크아웃 및 결제)를 확인하세요. 실제 주문과 결제를 받으려면 **Live mode**(라이브 모드)가 켜져 있어야 해요.
{% endhint %}

## 자주 묻는 질문

### 주문을 받으려면 웹사이트가 꼭 필요한가요?
픽업·배달 주문과 온라인 테이블 예약에는 웹사이트가 필요해요. 매장 식사 주문과 테이블 예약은 웹사이트 없이 직원이 받을 수 있어요.

### 웹사이트는 메뉴와 영업시간을 어디에서 가져오나요?
**메뉴**와 **레스토랑 설정 > Restaurant details**(레스토랑 정보)에서 가져와요. 그곳에서 내용을 바꾸면 웹사이트에도 바뀐 내용이 반영돼요. 메뉴를 만드는 방법은 [레스토랑 메뉴 만들기](how-to-create-a-restaurant-menu-in-hyperclass.md)를 참고하세요.

### 내 도메인을 쓸 수 있나요?
네. **Setup and sharing > Link and SEO**의 **Custom domain**에 도메인을 입력하고 **도메인 추가**를 클릭하세요.

### 손님은 어떻게 로그인하나요?
이메일로 로그인해요. 일회용 6자리 코드를 받아서 입력하면 되고, 입력한 정보는 저장돼서 다음 체크아웃이 더 빨라져요.

### 홈 페이지의 섹션을 숨기려면 어떻게 하나요?
**Restaurant pages > 홈**에서 해당 섹션의 토글을 끄세요.

### Publish website를 누르면 먼저 저장하라고 나와요. 왜 그런가요?
아직 저장하지 않은 변경사항이 있다는 뜻이에요. 변경사항을 저장한 다음 게시하세요.
