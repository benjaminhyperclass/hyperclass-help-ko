# 수료증 사용자 권한 설정과 실행 취소·다시 실행 기능

서브 계정 권한에서 사용자에게 수료증 모듈 접근 권한을 줄 수 있어요. 수료증 빌더에서는 실행 취소·다시 실행과 키보드 단축키도 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/BtbE1ihWLno?&wmode=opaque)

## 수료증 사용자 권한

이제 서브 계정(로케이션) 수준 권한에서 사용자에게 수료증 모듈 접근 권한을 줄 수 있어요.

## 수료증 빌더의 실행 취소·다시 실행

- 수료증 빌더에서 실행 취소·다시 실행 기능을 쓸 수 있어요.
- 편집한 내용을 자유롭게 되돌리거나 다시 적용할 수 있어요. 필요하면 이전 상태로 돌아갈 수 있으니 부담 없이 여러 가지를 시도해 보세요.

## 수료증 빌더의 키보드 단축키

- 수료증 빌더에서 미리보기, 저장, 실행 취소·다시 실행 같은 작업을 키보드 단축키로 빠르게 할 수 있어요.
- 다음 단축키를 쓰면 작업이 더 빨라져요.
  - 실행 취소: CTRL / ⌘ + Z
  - 저장: CTRL / ⌘ + S
