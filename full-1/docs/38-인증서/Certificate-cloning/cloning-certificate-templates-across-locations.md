# 수료증 템플릿을 다른 서브 계정으로 복제하기

수료증 템플릿을 한 서브 계정에서 다른 서브 계정으로 복제하는 방법을 안내해요. 이미 만든 디자인을 다른 서브 계정에서 그대로 다시 쓰고 싶을 때 사용하세요.

## 개요

이제 수료증 템플릿을 한 서브 계정에서 다른 서브 계정으로 복제할 수 있어요. 한 번에 최대 **3개 서브 계정**까지 복제할 수 있고, 템플릿에 연결된 요소도 함께 옮겨져요.

### 주요 내용

- 여러 서브 계정에 수료증 템플릿을 복제할 수 있어요(한 번에 최대 3개).
- 템플릿에 연결된 미디어 파일과 이미지가 모두 자동으로 옮겨져요.
- 템플릿 설정과 버전 기록이 그대로 유지돼요.
- 같은 서브 계정 안에서도 복제할 수 있어요.

## 수료증 템플릿 복제하기

1. 템플릿 목록으로 이동해요.
   - **멤버십 > 수료증**으로 이동하세요.
2. 복제를 시작해요.
   - 복제할 템플릿 옆의 점 세 개(⋮)를 클릭하세요.
   - 메뉴에서 **복제**를 선택하세요.
3. 복제 설정을 입력해요.
   - 필요하면 **템플릿 이름**을 수정하세요.
   - **서브 계정 선택**에서 템플릿을 복제할 서브 계정을 고르세요(최대 3개).
4. 복제를 마무리해요.
   - 선택한 내용을 확인하면 템플릿이 미디어 파일, 설정, 버전 기록과 함께 복제돼요.

{% hint style="info" %}
필요하면 같은 서브 계정 안에서 수료증 템플릿을 복제할 수도 있어요.
{% endhint %}
