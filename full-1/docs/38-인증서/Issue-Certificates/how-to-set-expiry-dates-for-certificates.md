# 수료증·배지 만료일과 만료 알림 이메일 설정

수료증과 배지가 얼마 동안 유효한지 정하고, 만료가 다가오면 받는 사람에게 알림 이메일을 보낼 수 있어요. 만료 기간과 만료 전 알림 이메일은 **자격 증명** 대시보드에서 바로 설정해요.

## 수료증·배지 만료란?

만료를 설정하면 수료증이나 배지가 발급된 뒤 얼마 동안 유효한지 정할 수 있어요. 정기적으로 갱신해야 하는 자격에 쓰면 편해요. 알림 이메일을 함께 설정하면 만료되기 전에 받는 사람에게 미리 알릴 수 있어요.

만료와 알림 설정은 **자격 증명** 대시보드에서 수료증·배지 템플릿의 **만료 설정**으로 관리해요.

## 만료 설정과 알림 이메일의 장점

- 유연한 만료 기간: 미리 정해 둔 기간 중에서 고르거나, 사용자 지정 기간을 정하거나, 만료 없이 계속 유효하게 둘 수 있어요.
- 자동 만료 알림: 수료증이나 배지가 만료되면 받는 사람에게 자동으로 알려요.
- 알림 시점 지정: 만료 며칠 전에 알림 이메일을 보낼지 직접 정할 수 있어요.
- 만료 전 알림 여러 번: 만료 전에 알림 이메일을 최대 두 번까지 설정할 수 있어요.
- 한곳에서 관리: 만료일과 알림 설정을 **자격 증명** 대시보드에서 바로 관리해요.

## 수료증·배지 만료일 설정하기

만료 기간은 수료증이나 배지 템플릿으로 만든 자격이 얼마 동안 유효한지를 정해요. 인증, 교육, 컴플라이언스, 갱신 주기에 맞는 기간을 고르세요.

{% hint style="info" %}
**없음**을 선택하면 해당 템플릿으로 만든 자격은 계속 유효해요. 단, 발급된 개별 수료증·배지에 만료 설정을 따로 적용한 경우는 예외예요.
{% endhint %}

1. **멤버십 > 자격 증명 > 대시보드**로 이동하세요.
2. **템플릿/발급된 수료증/배지** 섹션을 찾으세요.

   ![대시보드의 템플릿, 발급된 수료증, 배지 섹션](https://jumpshare.com/share/C7QL7oVOirtC1aeJ4FjK+/Screenshot+2026-09-17+at+14.38.29.png)
3. 만료를 설정할 수료증 또는 배지 템플릿을 찾으세요.
4. 템플릿 옆의 점 3개 메뉴를 클릭하세요.
5. **만료 설정**을 선택하세요.

   ![점 3개 메뉴에서 만료 설정 선택](https://jumpshare.com/share/rlp80jzHlsYcZY2O2zio+/Screen+Shot+2026-09-17+at+14.43.17.png)
6. 원하는 만료 옵션을 선택하세요. 선택할 수 있는 옵션은 다음과 같아요.

   - **없음**: 만료되지 않고 계속 유효해요.
   - **3개월**
   - **6개월**
   - **9개월**
   - **1년**
   - **2년**
   - **3년**
   - **4년**
   - **5 Years**(5년)
   - **사용자 지정**: 필요에 맞게 만료 기간을 직접 정해요.
7. **저장**을 클릭하세요.

   ![만료 옵션을 고르고 저장하는 화면](https://jumpshare.com/share/vLA9RWTwzGbY9or6FX0R+/Screen+Shot+2026-09-17+at+14.45.01.png)

## 만료 알림 이메일 설정하기

만료 알림 이메일은 받는 사람이 만료에 대비할 수 있게 도와줘요. 하이퍼클래스는 만료일 당일에 이메일을 보내요. 여기에 더해 수료증이나 배지가 만료되기 전에 보낼 알림을 최대 두 번까지 설정할 수 있어요.

{% hint style="warning" %}
만료 알림 이메일은 자격이 만료되는 당일에 발송돼요. 만료일 당일 이메일의 발송 시점은 바꿀 수 없어요.
{% endhint %}

{% hint style="info" %}
**Reminder Email 1**(첫 번째 알림 이메일)과 **Reminder Email 2**(두 번째 알림 이메일)는 선택 사항이에요. 알림을 켜면 만료 며칠 전에 보낼지 함께 입력하세요.
{% endhint %}

**만료 설정** 창에서 만료 기간을 선택한 뒤 다음 순서로 진행하세요.

1. 만료 알림 이메일 설정 영역을 찾으세요.
2. 만료 전에 첫 번째 알림을 보내려면 **Reminder Email 1**을 켜세요.
3. 자격이 만료되기 며칠 전에 알림을 보낼지 일수를 입력하세요.
4. 알림을 한 번 더 보내려면 **Reminder Email 2**를 켜세요.
5. 두 번째 알림을 만료 며칠 전에 보낼지 일수를 입력하세요.
6. 보내고 싶지 않은 알림은 꺼 두세요.
7. **저장**을 클릭하면 만료 설정과 알림 설정이 적용돼요.

## 자주 묻는 질문

### 수료증이나 배지가 만료되지 않게 설정할 수 있나요?
네. 만료 설정에서 **없음**을 선택하면 계속 유효해요.

### 만료 전에 알림 이메일을 몇 번 보낼 수 있나요?
만료 전 알림 이메일은 최대 두 개까지 설정할 수 있어요. 각 알림을 만료 며칠 전에 보낼지도 정할 수 있어요.

### 만료 전 알림 이메일 중 하나만 끌 수 있나요?
네. 만료 전 알림은 각각 따로 켜거나 끌 수 있어요.

### 만료일 당일에 가는 이메일의 발송 시점을 바꿀 수 있나요?
아니요. 만료 알림은 자격이 만료되는 날 발송되고, 발송 시점은 바꿀 수 없어요.

### 발급된 수료증마다 템플릿과 다른 만료 설정을 쓸 수 있나요?
네. 하이퍼클래스에서는 템플릿과 발급된 수료증 각각에 만료 설정을 할 수 있어요. 둘이 다르면 발급된 수료증의 만료 설정이 템플릿의 만료 설정보다 우선해요.
