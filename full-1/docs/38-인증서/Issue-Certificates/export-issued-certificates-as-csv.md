# 발급된 수료증을 CSV 파일로 내보내기

발급된 수료증 기록을 CSV 파일로 내보내는 방법을 안내해요. 날짜 범위를 직접 정해서 내보낼 수 있고, 수료증이 500개 이하이면 바로 내려받을 수 있어요. 500개를 넘으면 이메일로 받아요. 감사(audit)나 다른 도구와의 수료증 데이터 동기화에 쓰기 좋아요.

## 수료증 내보내기란?

수료증 내보내기는 발급된 수료증 기록을 한꺼번에 CSV 파일로 내려받는 기능이에요. 수신자 이름, 이메일, 발급일, 수료증 ID 같은 정보가 함께 들어 있어요. 교육 이수 현황, 코스 수료증, 감사 자료를 관리하는 팀에 알맞아요.

## 발급된 수료증을 내보내면 좋은 점

수료증 데이터를 CSV로 내보내면 쉽게 확인하고 관리할 수 있어요.

- 앱에서 바로 내려받는 방식으로 최대 500개까지 즉시 내보낼 수 있어요.
- 수료증이 500개를 넘으면 CSV 파일을 이메일로 자동으로 받아요.
- 날짜 범위를 직접 정해 결과를 좁힐 수 있어요.
- 규정 준수, 분석, 다른 서비스와의 연동에 내보낸 파일을 쓸 수 있어요.
- CSV는 어디서나 열 수 있고 편집하기 쉬운 형식이에요.
- 보고서 작성이나 외부 LMS 도구와의 동기화를 간편하게 할 수 있어요.

## 수료증을 CSV 파일로 내보내는 방법

1. **수료증** 앱의 **발급된 수료증** 섹션으로 이동하세요.
2. 오른쪽 위에 있는 **CSV 내보내기** 버튼을 클릭하세요.
3. 날짜 범위 필터가 나타나면 내보낼 수료증의 기간을 선택하세요.
4. **Confirm Export**(내보내기 확인)를 클릭해 내보내기를 시작하세요.

- 내보낼 수료증이 **500개 미만**이면 CSV 파일이 기기로 바로 다운로드돼요.
- 내보낼 수료증이 **500개를 넘으면** 파일이 준비되었을 때 **로그인 이메일 주소**로 보내 준다는 안내 메시지가 나타나요.

## 내보내기 기준과 전달 방식

내보내기가 어떻게 동작하는지 알아 두면 많은 양의 데이터를 다룰 때도 헷갈리지 않아요.

- 500개 미만: 브라우저에서 CSV가 바로 다운로드돼요.
- 500개 초과: 로그인한 사용자의 이메일로 CSV가 전송돼요.
- 이메일 제목: “Your Certificate Export is Ready”(수료증 내보내기 파일이 준비되었어요)
- 링크 만료: 이메일에 담긴 다운로드 링크는 **24시간** 동안만 유효해요.
- 날짜 범위 필수: 내보내기 범위를 정하기 위해 내보내기 전에 날짜 범위를 선택해야 해요.

## 자주 묻는 질문

### 날짜로 거르지 않고 수료증을 내보낼 수 있나요?

아니요. 데이터 양을 제한하고 성능을 최적화하기 위해 날짜 범위를 꼭 선택해야 해요.

### CSV 파일은 어디로 전송되나요?

내보낼 수료증이 500개를 넘으면 하이퍼클래스 계정에 연결된 이메일 주소로 CSV 파일이 전송돼요.

### CSV 다운로드 링크는 얼마나 오래 유효한가요?

이메일로 받은 다운로드 링크는 **24시간** 동안 유효해요.

### CSV 파일에는 어떤 데이터가 들어 있나요?

이름(Full Name), **이메일 주소**, 수료증 ID(Certificate ID), 발급일(Date Issued)이 들어 있어요. 설정한 경우에는 코스 이름이나 태그도 포함돼요.

### 이전에 내보낸 파일을 다시 내려받을 수 있나요?

아니요. 처음 받은 링크가 만료되었다면 같은 날짜 범위로 다시 내보내야 해요.

## 다음 단계

- 아직 수료증을 발급하지 않았다면 수료증 발급 방법을 확인해 보세요.
- 수료증 전달을 자동화하고 싶다면 수료증 관련 워크플로우 트리거를 살펴보세요.
- 브랜드에 맞게 꾸미고 싶다면 SmartDocs로 스타일을 적용한 수료증 템플릿을 만들어 보세요.
