# 코스 기본 수료증과 카테고리 수료증

새 코스에는 코스 수료증이 기본으로 들어 있어요. 코스 안의 특정 카테고리를 마친 학습자에게는 카테고리 수료증을 줄 수도 있어요. 이 문서에서는 두 수료증을 설정하는 방법을 안내해요.

## [동영상](https://www.youtube.com/embed/i5eIVqYcV4A?&wmode=opaque)

## 개요

이번 업데이트로 수료증 설정이 더 간단해졌어요. 새 코스를 만들면 코스 수료증이 기본으로 포함되어, 학습자가 코스를 마치면 수료증을 받아요. 새로 생긴 카테고리 수료증을 쓰면 코스의 특정 구간을 마쳤을 때도 수료증을 줄 수 있어요.

## 주요 장점

✅ 코스 수료증 자동 추가 – 새 코스마다 기본 수료증이 포함되어 직접 설정하는 수고가 줄어요.  
✅ 유연한 수료증 관리 – 필요 없는 기본 코스 수료증은 삭제하거나 초안으로 바꿀 수 있어요.  
✅ 간편한 연결 – 기본 수료증과 직접 만든 수료증을 코스 빌더에서 바로 연결할 수 있어요.  
✅ 카테고리 단위 인정 – 코스 안의 카테고리 하나를 모두 마친 학습자에게 수료증을 줄 수 있어요.

## 기본 코스 수료증 사용하기

### 기본 수료증 확인하기

1. 계정에 로그인해요.
2. **멤버십 > 코스**로 이동해 새 상품을 만들어요.
3. 코스 수료증이 기본으로 들어 있는지 확인해요.

### 기본 수료증 관리하기

- 수료증 템플릿 연결하기

  1. **Course Completion Certificate**(코스 수료증) 섹션 아래의 설정 아이콘(점 세 개)을 클릭해요.
  2. **수료증 편집** 또는 **Choose Certificate**(수료증 선택)를 선택해요.
  3. 사용할 템플릿을 코스에 연결해요.
- 기본 수료증 삭제하거나 초안으로 바꾸기

  1. 설정 아이콘(점 세 개)을 클릭해 **삭제**를 선택하거나, **Published**(게시됨) 아이콘을 클릭해 **Draft**(초안)를 선택해요.

## 카테고리 수료증 사용하기

### 카테고리 수료증 켜기

1. 코스를 열어요.
2. 수료증을 연결할 카테고리를 선택해요.
3. 더하기(+) 아이콘을 클릭해 카테고리에 수료증을 연결해요.

### 작동 방식

- 카테고리 수료증은 카테고리 **미리보기**에서 마지막 강의로 표시돼요.
- 카테고리 안의 필수 강의를 모두 마치면 수료증이 자동으로 지급돼요.
- 카테고리 수료증은 위치를 옮길 수 없어요. 항상 카테고리의 맨 끝에 있어요.
