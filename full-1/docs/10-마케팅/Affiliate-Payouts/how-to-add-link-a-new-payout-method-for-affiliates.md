# 제휴 파트너의 새 지급 방법 추가하기

관리자와 제휴 파트너 모두 PayPal이나 은행 계좌를 지급 방법으로 추가할 수 있어요. 이 문서에서는 관리자가 추가하는 방법과 제휴 파트너가 직접 추가하는 방법을 차례로 안내해요.

[동영상](https://www.youtube.com/embed/35YiADsH8O8?&wmode=opaque)

{% hint style="warning" %}
**중요: 제휴 파트너에게 보여 줄 지급 방법 설정하기**

이제 제휴 파트너가 사용할 수 있는 지급 방법(PayPal, **계좌 이체**)을 직접 정할 수 있어요.

설정 방법은 다음과 같아요.

1. **제휴 관리자 > 설정**으로 이동하세요.
2. **Affiliate Portal Settings**(제휴 포털 설정) > **Configure Payout Methods**(지급 방법 구성)를 클릭하세요.
3. 사용할 지급 방법을 선택하세요.
4. **변경사항 저장**을 클릭하세요.

제휴 파트너에게는 켜 둔 지급 방법만 보여요. 그래서 지급 과정이 더 간단해져요.

{% endhint %}

## 관리자가 추가하는 방법

### 1단계: 제휴 파트너 프로필 페이지로 이동하기

1. **제휴 관리자**에서 해당 제휴 파트너의 프로필 페이지를 여세요.

### 2단계: 지급 방법 탭으로 이동하기

1. 아래로 스크롤해서 **Payout Methods**(지급 방법) 탭으로 이동하세요.

### 3단계: 지급 방법 추가하기

1. **Add Payout Method**(지급 방법 추가)를 클릭하세요.

![지급 방법 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025232191/original/3RowXIU6AnU3FrHbZeCakFkUTLz3YQ70FA.png?1714391840)

### 4단계: 지급 방법을 고르고 필수 항목 입력하기

- PayPal: 제휴 파트너의 PayPal 이메일 주소를 입력하세요.

  ![PayPal 이메일 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025232235/original/E_I9HKVWL-7IYo9_Gwo3zi2HW1Cn1CPIGw.png?1714391851)
- 은행 계좌: 국가를 선택하고 필요한 정보를 입력하세요.

### 5단계: 완료 클릭하기

1. 정보를 모두 입력했으면 **완료**를 클릭해 지급 방법을 저장하세요.

   ![완료 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025232272/original/sIM3G6KiYqr8k9gsPeSTaH4IafASAow9Cw.png?1714391880)

제휴 파트너 한 명에게 지급 방법을 여러 개 추가할 수 있어요. 그중 하나를 기본 지급 방법으로 선택하세요.

![기본 지급 방법 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044056952/original/1M-5szwAbsiGGhN10kOjfbF3pruZQQZXeA.png?1743051536)

## 제휴 파트너가 직접 추가하는 방법

### 1단계: 제휴 포털 접속하기

1. 전달받은 매직 링크로 **제휴 포털**에 로그인하세요.

### 2단계: 지급 방법 탭으로 이동하기

<!-- 검토 필요: 원문 내용이 서로 다름 (제목은 Commissions 탭인데 본문은 Payout Methods 탭으로 이동하라고 안내함) -->

1. 포털에서 **Payout Methods**(지급 방법) 탭으로 이동하세요.

![제휴 포털의 지급 방법 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044057041/original/NM0Ruzh1JcYkhfqgODg4ORyQBUnqHuYlGA.png?1743051690)

### 3단계: 지급 방법 추가하기

1. **Add Payout Method**를 클릭하세요.

### 4단계: 지급 방법을 고르고 필수 항목 입력하기

- PayPal: 본인의 PayPal 이메일 주소를 입력하세요.

  ![PayPal 이메일 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155025232378/original/0KYFgdyfAWlaNP3f3iY03_ImJq56d34JSw.png?1714391935)
- 은행 계좌: 국가를 선택하고 필요한 정보를 입력하세요.

### 5단계: 완료 클릭하기

1. 정보를 모두 입력했으면 **완료**를 클릭해 지급 방법을 저장하세요.

{% hint style="info" %}
현재 PayPal API는 계정 유효성 검증을 지원하지 않아요. 제휴 파트너의 PayPal 이메일 주소를 추가할 때는 올바른 주소인지 꼼꼼히 확인하세요.
{% endhint %}
