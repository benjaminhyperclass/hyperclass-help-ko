# 소셜 플래너에서 Pinterest 핀 만들고 게시하기

**소셜 플래너**(Social Planner)에서 Pinterest 핀을 바로 만들고, 예약하고, 게시할 수 있어요. Pinterest 콘텐츠를 한곳에서 꾸준히 관리하고 싶을 때 쓰세요.

[동영상](https://www.youtube.com/embed/Ki9goPj0mPQ?&wmode=opaque)

## 개요

소셜 플래너에서 Pinterest 핀을 만들고 게시할 수 있어요. 하이퍼클래스와 Pinterest를 오가며 게시물을 만들 필요가 없어요. Pinterest 비즈니스 계정을 연결하면 이미지나 동영상을 올리고, 핀 제목과 설명을 쓰고, 연결할 링크를 넣고, 핀을 게시할 Pinterest 보드를 고를 수 있어요.

핀 하나에는 이미지 1개 또는 동영상 1개가 필요해요. 핀을 게시·예약·저장하거나 승인 요청을 보내려면 Pinterest 보드를 하나 이상 선택해야 해요.

같은 게시물에 보드를 최대 25개까지 선택하면 핀을 여러 개 한꺼번에 만들 수도 있어요. 선택한 보드마다 핀이 따로 게시돼요. 같은 콘텐츠를 여러 Pinterest 보드에 올릴 때 게시물을 일일이 다시 만들지 않아도 돼요.

## 주요 장점

- 여러 보드에 게시: 게시물 작성 화면 하나에서 같은 Pinterest 핀을 선택한 여러 보드에 게시할 수 있어요.
- 한곳에서 예약: 소셜 플래너에서 Pinterest 핀을 만들고, 예약하고, 저장하고, 게시할 수 있어요.
- 보드 선택의 유연성: 기존 Pinterest 보드를 고르거나, 핀을 만드는 중에 새 보드를 만들 수 있어요.
- **게시물 미리보기**: 게시하거나 예약하기 전에 Pinterest 핀이 어떻게 보일지 확인할 수 있어요.
- 미디어 지원: 올린 파일이 Pinterest 요건을 충족하면 이미지 핀과 동영상 핀을 모두 게시할 수 있어요.

## Pinterest 미디어 요건

Pinterest 핀에는 이미지 1개 또는 동영상 1개가 필요해요.

- 이미지: 크기는 10MB 이하여야 하고, PNG와 JPG를 지원해요.
- 동영상: 크기는 1GB 이하여야 하고, MOV, MP4, WEBP를 지원해요. 길이는 최소 4초, 최대 5분이에요. 권장 화면 비율은 9:16(화면 가득 채우는 동영상), 1:2, 2:3, 3:4, 4:5, 1:1이고, 권장 인코딩은 H.264 또는 H.265예요.

## Pinterest 계정 연결하기

1. **마케팅** > **소셜 플래너** > **+ Socials**(소셜 계정 추가)로 이동하세요.

   ![소셜 플래너에서 소셜 계정 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071941362/original/uMjjpzBSTeTtNK0FM-4FSweoMGM4rcg1fg.png?1779384112)
2. **Connect Pinterest**(Pinterest 연결)를 클릭하세요.

   ![Pinterest 연결 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071941427/original/WRDKcerfgXTY6mKQLGdWLPExrA8x2-bu5g.png?1779384149)
3. Pinterest 계정에 로그인하세요. 이 계정의 관리자(admin)인지 확인하세요.

   ![Pinterest 계정 로그인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071941473/original/LUnO0KG5XuRc5OiXJi6sGCeRtFhxu8WRSQ.png?1779384208)

## 핀 만들고 게시하기

1. **소셜 플래너**에서 **+ 새 게시물**을 클릭하세요.

   ![새 게시물 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071941578/original/Ik4RI9e_hW1YhigyZiCb0Te-ywDiKTY68g.png?1779384311)
2. **게시 대상** 필드에서 **Pinterest 계정**을 선택하세요.

   ![게시 대상에서 Pinterest 계정 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071942447/original/_cdmZ1E3JxOgLtooKodpG59ozerjMbCCUA.png?1779385305)
3. 게시물 내용이나 설명을 쓰고, 지원하는 이미지나 동영상을 올리세요.

   ![게시물 내용 입력과 미디어 업로드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071942465/original/7_CQ-9RLJHQtuCWqpfAHei3opoJ6hBbjow.png?1779385333)
4. **Title**(제목)과 **Link**(링크)를 입력하세요.

   ![핀 제목과 링크 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071942482/original/5wLDe20eVNoQGOUIw3gW4cgQYY_uNoisHw.png?1779385357)
5. **하나 이상 선택** 드롭다운에서 Pinterest 보드를 하나 이상 선택하세요. 보드는 최대 25개까지 선택할 수 있어요. 여러 보드에 게시하면 선택한 보드마다 핀이 따로 게시돼요.

   비공개 보드에는 **잠금** 아이콘이 표시돼요.

   보드가 하나도 없다면 보드 선택 드롭다운의 **Add board**(보드 추가) 옵션으로 새로 만들 수 있어요.

   ![Pinterest 보드 선택 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071942501/original/Od_PJcJHSfQ3QQsx8Svh65mJEYV6ODEZUA.png?1779385392)
6. 게시 방법을 선택하세요.

   - **나중을 위해 저장**
   - **Post now**(지금 게시)
   - **게시물 예약**
   - **반복 게시물**
   - **승인 요청 보내기**

## 자주 묻는 질문

### Pinterest 핀 하나를 여러 보드에 게시할 수 있나요?
네. 소셜 플래너 작성 화면 하나에서 Pinterest 계정당 최대 25개 보드에 핀 하나를 게시할 수 있어요. 선택한 보드마다 핀이 자동으로 따로 게시돼요. 보드마다 같은 게시물을 직접 복제하지 않아도 돼요.

### 선택한 보드마다 핀이 따로 만들어지나요?
네. 선택한 보드마다 핀이 따로 게시돼요. 덕분에 보드별로 트래킹과 분석을 나눠서 볼 수 있어요.

### 보드 하나에서 게시에 실패하면 어떻게 되나요?
한 보드의 게시가 실패해도 선택한 다른 보드의 게시는 막히지 않아요. 보드마다 따로 처리돼요.

### Pinterest 보드를 꼭 선택해야 하는 이유가 뭔가요?
Pinterest에서는 핀을 보드에 저장해야 해요. 선택한 보드에 따라 핀이 Pinterest에서 보이는 위치가 정해져요.

### 핀을 만드는 중에 새 Pinterest 보드를 만들 수 있나요?
네. 보드 드롭다운의 **New board**(새 보드) 또는 **Add board**(보드 추가) 옵션으로 게시물을 만드는 중에 보드를 만들 수 있어요.

### Pinterest 보드가 목록에 보이지 않아요.
올바른 Pinterest 비즈니스 계정이 연결되어 있는지, 관리자 권한이 있는지, 연결한 Pinterest 계정에 해당 보드가 있는지 확인하세요. 계정을 최근에 바꿨다면 소셜 계정을 다시 연결하거나 새로 고치면 도움이 될 수 있어요.

### 미디어가 Pinterest 요건에 맞지 않으면 어떻게 되나요?
핀 게시에 실패하거나, 예약하기 전에 파일을 수정해야 할 수 있어요. 게시하기 전에 파일 형식, 파일 크기, 길이, 화면 비율을 확인하세요.
