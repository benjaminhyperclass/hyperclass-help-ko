# 제휴 캠페인 추천 링크 클릭 추적

제휴 캠페인에서 추천 링크가 클릭된 횟수를 확인할 수 있는 클릭 추적 기능이 새로 추가되었어요. 운영자와 제휴 파트너 모두 링크 성과를 볼 수 있어요.

[동영상](https://www.youtube.com/embed/9gzU0o3Oeuk?&wmode=opaque)

## 새로운 기능

이제 추천 링크 클릭을 추적해서 캠페인 성과를 더 자세히 파악할 수 있어요. 클릭 수는 다음 화면에 표시돼요.

- **제휴 관리자**(Affiliate Manager) 대시보드
- **제휴 목록**
- **Affiliate Profile Page**(제휴 프로필 페이지)
- **제휴 포털**: 제휴 파트너가 자신의 클릭 성과를 직접 확인할 수 있어요.

## 작동 방식

**제휴 관리자** 대시보드, **제휴 목록**, **Affiliate Profile Page**에서 클릭 수를 실시간으로 확인할 수 있어요. 제휴 파트너는 **제휴 포털**에서 자신의 클릭 데이터를 직접 볼 수 있어요.

{% hint style="info" %}
고유 링크 클릭(Unique Link Clicks)만 추적해요.
{% endhint %}

## 이 기능이 중요한 이유

제휴 파트너의 추천 링크가 얼마나 효과가 있는지 더 분명하게 알 수 있어요. 그 결과를 바탕으로 캠페인을 더 잘 개선할 수 있어요. 제휴 파트너도 클릭 지표를 보면서 홍보 방식을 다듬고 성과를 높일 수 있어요.
