# 다단계 커미션 설정

**제휴 관리자** 캠페인에서 최대 7개 티어까지 커미션을 설정하고, 티어마다 기본 커미션 또는 상품별 커미션을 지정하는 방법을 안내해요. 다단계 커미션을 쓰면 판매를 만든 제휴 파트너뿐 아니라 그 위의 제휴 계층에도 커미션을 나눠 줄 수 있어요.

## 다단계 커미션이란?

다단계 커미션은 캠페인의 커미션을 제휴 계층의 여러 단계에 나눠 지급하는 방식이에요. 조건을 충족하는 판매를 만든 제휴 파트너는 1티어 커미션을 받고, 자격이 있는 상위 제휴 파트너는 더 높은 티어에 설정된 커미션을 받을 수 있어요.

캠페인 하나에 티어를 최대 7개까지 둘 수 있어요. 티어마다 커미션율을 따로 정할 수 있어서, 계층이 올라갈수록 보상 구조를 다르게 만들 수 있어요.

- 1티어 (판매를 만든 제휴 파트너): 조건을 충족하는 판매를 만든 제휴 파트너가 해당 1티어 커미션을 받아요.
- 2티어 (상위 제휴 파트너): 자격이 있는 상위 제휴 파트너가 설정된 2티어 커미션을 받을 수 있어요.
- 3티어 (그다음 상위 제휴 파트너): 계층에서 그다음 자격이 있는 상위 제휴 파트너가 설정된 3티어 커미션을 받을 수 있어요.

### 예시 1: 5개 티어로 커미션 나누기

커미션 구조를 다음과 같이 설정했다고 가정해 볼게요.

- 1티어: 20%
- 2티어: 10%
- 3티어: 5%
- 4티어: 3%
- 5티어: 2%

판매를 만든 제휴 파트너는 1티어 커미션을 받아요. 나머지 커미션은 위쪽 계층에서 자격이 있는 추천 제휴 파트너에게 각 티어에 설정된 비율대로 지급돼요.

![5개 티어 제휴 커미션 분배 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081346043/original/Dg7nq_zncnIujoV3L7mBqMWbUx4CyGKGyw.jpeg?1789781243)

Jan이 100달러 판매를 만들면 이렇게 지급돼요.

1. Jan(1티어 제휴 파트너)은 20달러를 받아요.
2. Toby(Jan을 영입한 2티어 제휴 파트너)는 10달러를 받아요.
3. Ryan(Toby를 영입한 3티어 제휴 파트너)은 5달러를 받아요.
4. Jim(Ryan을 영입한 4티어 제휴 파트너)은 3달러를 받아요.
5. Michael(Jim을 영입한 5티어 제휴 파트너)은 2달러를 받아요.

제휴 파트너에게 지급한 총액: 40달러

20달러 + 10달러 + 5달러 + 3달러 + 2달러

이 예시에서는 설정한 5개 티어가 모두 제휴 체인에 있으므로, 5개 단계 모두에 커미션이 지급돼요.

### 예시 2: 제휴 체인이 짧은 경우

같은 커미션 구조에서 Stanley가 100달러 판매를 만들었는데, 추천 체인에 제휴 단계가 3개뿐이라고 가정해 볼게요.

![3단계 제휴 커미션 분배 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081346045/original/cmC3MVEikYQy97Sy-4u5fozYCdB9fYj3yQ.jpeg?1789781253)

Stanley가 100달러 판매를 만들면 이렇게 지급돼요.

1. Stanley(1티어 제휴 파트너)는 20달러를 받아요.
2. Dwight(Stanley를 영입한 2티어 제휴 파트너)는 10달러를 받아요.
3. Michael(Dwight를 영입한 3티어 제휴 파트너)은 5달러를 받아요.

제휴 파트너에게 지급한 총액: 30달러

20달러 + 10달러 + 5달러

이 예시에서는 추천 체인에 제휴 단계가 3개뿐이므로, 그 3개 티어에만 커미션이 지급돼요.

## 다단계 커미션의 장점

다단계 커미션을 쓰면 캠페인 안에서 제휴 파트너와 그 추천 네트워크에 보상하는 방식을 더 세밀하게 정할 수 있어요.

- 유연한 커미션 구조: 제휴 캠페인 하나에 티어를 최대 7개까지 설정할 수 있어요.
- 티어별 보상: 제휴 계층의 단계마다 커미션 값을 다르게 정할 수 있어요.
- 상품별 관리: 상품마다 지급률이 다르면 상품별 커미션을 쓸 수 있어요.
- 하위 제휴 네트워크 지원: 하위 제휴 파트너가 조건을 충족하는 판매를 만들면, 자격이 있는 상위 제휴 파트너에게도 보상할 수 있어요.

## 사전 준비와 제한 사항

하이퍼클래스가 하위 제휴 계층에 커미션을 나눠 주려면, 캠페인과 커미션 설정이 먼저 맞게 되어 있어야 해요.

- **제휴 관리자** 캠페인을 만들거나 선택하세요.
- 캠페인에서 하위 제휴 파트너를 쓸 거라면 티어를 **2개 이상** 설정하세요.
- 하이퍼클래스는 캠페인당 커미션 티어를 최대 **7개**까지 지원해요.
- 상품별 커미션을 쓴다면, 해당 상품이 캠페인 상품 목록에 들어 있는지 확인하세요.
- 캠페인 단위 티어 구조: 커미션 티어 수는 캠페인에서 정해요. 제휴 파트너별 커미션 설정으로 커미션율은 바꿀 수 있지만, 캠페인의 티어 수는 바뀌지 않아요.

---

## 커미션 티어 한도를 넘는 제휴 파트너 영입

제휴 파트너는 캠페인에 설정된 커미션 티어를 넘어서도 하위 제휴 파트너를 계속 영입할 수 있어요. 커미션 티어 수는 커미션 지급 범위만 제한하고, 영입 깊이는 제한하지 않아요.

제휴 파트너가 판매를 만들면, 판매를 만든 제휴 파트너부터 거꾸로 거슬러 올라가며 커미션 자격을 계산해요. 설정된 커미션 티어 한도 안에 있고 자격이 있는 제휴 파트너만 커미션을 받아요.

이 동작은 자동으로 적용되며 따로 설정할 필요가 없어요. 설정된 티어 한도 안에서 기존 커미션 동작은 그대로 유지돼요.

---

## 커미션 티어와 제휴 영입 깊이의 차이

커미션 티어 수는 조건을 충족하는 판매 한 건에 대해 몇 단계의 제휴 파트너가 커미션을 받을 수 있는지를 정해요. 하위 제휴 파트너가 영입 네트워크에 몇 단계까지 참여할 수 있는지는 제한하지 않아요.

- 제휴 파트너는 마지막으로 설정한 커미션 티어를 넘어서도 계속 영입할 수 있어요.
- 판매가 발생하면, 판매를 만든 제휴 파트너부터 거꾸로 거슬러 올라가며 커미션 자격을 계산해요.
- 설정된 티어 한도 안에서 자격이 있는 제휴 파트너만 커미션을 받아요.
- 이 동작은 자동으로 적용되며 따로 설정할 필요가 없어요.

## 다단계 커미션 설정하기

다단계 커미션은 제휴 캠페인을 만드는 과정의 **Commissions**(커미션) 단계에서 설정해요. 캠페인 소스, 상품, 티어 수, 커미션 값을 순서대로 맞게 설정하려면 서브 계정 화면에서 시작하세요.

### 1단계: 제휴 캠페인 생성 시작하기

1. 서브 계정 화면의 왼쪽 메뉴에서 **마케팅**을 선택하세요.
2. **제휴 관리자**를 선택하세요.
3. **캠페인**을 선택하세요.
4. **+ 추가**를 클릭해 캠페인을 만드세요.

![+ 추가 버튼이 표시된 제휴 관리자 캠페인 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081345917/original/tPzMf1pMMkjhVsLDlvxbjn1WzaS1exG-8Q.png?1789780142)

### 2단계: 캠페인 상세 정보 설정하기

캠페인 소스에 따라 캠페인이 추적하는 대상과 커미션을 설정할 수 있는 상품이 정해져요.

1. **캠페인 상세 정보**에서 캠페인 소스를 선택하세요.
2. 해당하는 소스 세부 항목을 선택하세요.
3. 선택한 소스에 표시되는 캠페인 링크나 랜딩 대상을 설정하세요.
4. 캠페인에 연결된 상품 목록을 확인하세요.
5. 커미션 대상이 되는 상품만 목록에 남도록 상품을 추가하거나 제거하세요.
6. **Commissions**(커미션) 단계로 넘어가세요.

![소스 설정과 상품 목록이 있는 캠페인 상세 정보 단계](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081345960/original/l5UM4sz1QWOKhWNTF1e4tLnTo6FNXa1O1w.png?1789780334)

### 3단계: 캠페인 기본 커미션 설정하기

기본 커미션은 티어를 추가로 설정하기 전에 캠페인 전체에 적용되는 기본 값이에요.

1. **Commissions** 단계에서 기본 커미션을 입력하세요.
2. 커미션을 상품 가격의 비율로 줄지, 정액으로 줄지 선택하세요.
3. 상품마다 커미션율이 다르다면, 상품별 커미션 설정으로 해당 상품을 따로 설정하세요.

![기본 커미션과 상품별 커미션 설정이 있는 Commissions 단계](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081345965/original/udEvWWSri_kbZPmySYUoy7loU75Guhcp_Q.png?1789780439)

### 4단계: 고급 커미션 설정 열기

고급 커미션 설정에서 캠페인의 다단계 구조를 정해요.

1. **Commissions** 단계에서 **Advanced commission settings**(고급 커미션 설정)를 선택하세요.
2. **Number of tiers**(티어 수)를 찾으세요.
3. 캠페인에 필요한 커미션 티어 수를 선택하세요.

{% hint style="info" %}
티어 수: 하이퍼클래스는 티어를 최대 7개까지 지원해요. 캠페인에 다단계 커미션 구조가 필요 없다면 티어 수를 **1**로 그대로 두세요.
{% endhint %}

![티어 수 설정이 보이는 고급 커미션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081345966/original/oqLIRT7EMlGTpm2QohjXEYpH4TFLG6Ws_A.png?1789780488)

### 5단계: 티어별 커미션 설정하기

추가한 티어마다 기본 커미션이나 상품별 커미션 값을 따로 정할 수 있어요.

1. 티어 수를 선택한 뒤, **Tier 2**처럼 다음 티어를 여세요.
2. 해당 티어의 **Default commission for all products**(전체 상품 기본 커미션)를 입력하세요.
3. 필요하면 **Customize commission by products**(상품별 커미션 지정)를 사용해 상품마다 다른 커미션율을 지정하세요.
4. 추가한 티어마다 같은 방법으로 반복하세요.
5. 계속 진행하기 전에 설정한 모든 티어의 커미션율을 검토하세요.

{% hint style="info" %}
선택 커미션 설정: **Commission Length**(커미션 기간)와 **Variable Commissions**(변동 커미션)는 반복 결제 상품의 커미션을 더 세밀하게 관리할 때 쓰는 기능이에요. 캠페인의 다단계 구조와는 별개예요.
{% endhint %}

![기본 커미션과 상품별 커미션 옵션이 있는 Tier 2 커미션 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081346018/original/uWjzhF7US5ZRhHdI_Q7y-88rF4UKD5Ailg.png?1789780917)

### 6단계: 캠페인 설정 완료하기

커미션 설정을 마쳤다면, 캠페인을 제휴 파트너에게 공개하기 전에 나머지 캠페인 설정을 마무리하세요.

1. **완료** 단계로 넘어가세요.
2. 필요하면 캠페인 설명을 추가하세요.
3. 캠페인을 만드는 중에 제휴 파트너를 배정하려면 **Assign Affiliate**(제휴 파트너 배정)를 선택하세요.
4. 나머지 캠페인 설정을 검토하세요.
5. 캠페인이 준비되면 **완료**를 선택하세요.

![제휴 파트너 배정과 캠페인 완료 옵션이 있는 완료 단계](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081346030/original/MLqn1rRm24EAUOCxGJs2XeAt6-AgiEd6RA.png?1789781003)
