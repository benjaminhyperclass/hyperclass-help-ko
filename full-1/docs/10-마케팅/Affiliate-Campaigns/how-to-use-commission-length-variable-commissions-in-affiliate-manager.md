# 제휴 관리자에서 커미션 기간과 변동 커미션 설정하기

제휴 관리자의 정기 결제 상품에서 제휴 파트너에게 커미션을 얼마나 오래, 어떤 비율로 줄지 정하는 방법을 안내해요. 커미션 지급 횟수를 제한하거나, 결제 횟수에 따라 커미션 비율을 다르게 설정할 때 쓰세요.

## [동영상](https://www.youtube.com/embed/vyRTiw8nfRM?&wmode=opaque)

## 개요

**Commission Length**(커미션 기간)와 **Variable Commissions**(변동 커미션) 기능을 쓰면, 정기 결제 상품 판매에 대해 제휴 파트너에게 커미션을 어떻게, 얼마 동안 줄지 직접 정할 수 있어요.

1. **Commission Length**(커미션 기간): 기간을 정하지 않고 계속 지급하는 대신, 정해진 결제 횟수까지만 커미션을 지급해요.
2. **Variable Commissions**(변동 커미션): 결제 횟수에 따라 커미션 비율을 다르게 정해요.

---

### 1단계: 제휴 캠페인 만들기 또는 편집하기

- 제휴 캠페인을 처음 만든다면 캠페인 만드는 방법 안내 문서를 먼저 확인하세요.

### 2단계: 기본 커미션 설정하기

- 캠페인 설정의 2단계에서 제휴 파트너가 기본으로 받을 커미션 값을 입력하세요.

### 3단계: 커미션 기간 켜기

- **Commission Length**를 클릭하세요.
- 기본값은 고객이 구독을 취소할 때까지 커미션을 계속 지급하는 방식이에요.![커미션 기간 기본 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038550542/original/coBmKW38xPbyR3OYFUahlZjEm6Bd0GcabA.png?1734524683)
- 결제 횟수를 제한하려면 **By Count**(횟수 기준)를 선택하세요.![횟수 기준 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038550567/original/n42CUg0zPRRto8uFVNh791gAB_Gmme9Hxg.png?1734524698)
- 예를 들어 한도를 3으로 설정하면, 제휴 파트너는 처음 3번의 결제에 대해서만 커미션을 받아요.![한도를 3으로 설정한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038550601/original/kIdwb6ZK6zIDkqGxZQssvfpwlJcisBurdA.png?1734524719)

{% hint style="info" %}
한도는 기간이 아니라 결제 횟수를 기준으로 적용돼요. 구독이 월간이든 연간이든, 성공한 결제 횟수에 따라 커미션이 계산돼요.
{% endhint %}

### 4단계: 변동 커미션 설정하기

- **Variable Commissions** 토글을 켜세요.
- **Two Levels**(2단계)를 선택하면 특정 결제 횟수 구간마다 다른 비율을 정할 수 있어요.![2단계 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038550631/original/jXSHTfCxN8EIEZ5udCJNAcZ9r4iOvw14UQ.png?1734524783)
- 예를 들어 "처음 3번(이 숫자는 직접 설정할 수 있어요)의 결제에는 커미션이 33%(이 숫자도 직접 설정할 수 있어요)이고, 그 이후에는 23%(기본 커미션)예요."처럼 설정할 수 있어요.![변동 커미션 설정 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155038550677/original/tjAOqL0hHnt7WHIfKeJU4OAOfNzT00he_A.png?1734524807)
- 더 세밀하게 조정하고 싶다면 구간을 추가로 설정하세요.

### 5단계: 캠페인 게시하기

- 캠페인을 저장하면 바꾼 커미션 설정이 적용돼요.

---

{% hint style="info" %}
**커미션 적용 우선순위**

1. 상품별 커미션
2. 변동 커미션
3. 기본 커미션

이 순서에 따라 구체적인 커미션 설정이 일반 설정보다 먼저 적용돼요.
{% endhint %}
