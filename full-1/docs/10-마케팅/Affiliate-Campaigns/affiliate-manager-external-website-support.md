# 제휴 관리자 외부 웹사이트 지원

이제 **제휴 관리자**(Affiliate Manager)에서 하이퍼클래스 웹사이트와 퍼널뿐 아니라 어떤 외부 웹사이트에서도 제휴 캠페인을 운영할 수 있어요. 제휴 파트너가 웹 어디에서든 상품을 홍보하고 판매할 수 있어서 더 넓게 마케팅할 수 있습니다.

[동영상](https://www.youtube.com/embed/wW8c4A-iZEs?&wmode=opaque)

## 새로워진 점

- 외부 웹사이트 지원: 외부 웹사이트 URL만 추가하면 몇 분 안에 제휴 파트너가 활동을 시작할 수 있어요.
- 통합 트래킹: 제휴 링크 하나로 서브도메인을 포함한 웹사이트 전체의 판매를 추적할 수 있어요.
- 상품별 수수료: 특정 상품에 맞춤 수수료를 정할 수 있어요. 따로 정하지 않은 상품은 Stripe 계정으로 판매하는 모든 상품에 적용되는 기본 설정을 따릅니다.
- 반복 구독: 업그레이드, 다운그레이드, 반복 결제를 자동으로 추적해요. 수수료 대상 거래라면 제휴 파트너가 매번 수수료를 받을 수 있습니다.

## 설정 방법

1. **제휴 관리자**로 이동해 **캠페인** 탭을 엽니다.
2. **+ 추가**를 클릭해 새 캠페인을 만듭니다.
3. 소스로 **External Website**(외부 웹사이트)를 선택합니다.
4. 웹사이트 URL을 입력해 제휴 트래킹 링크를 만듭니다.
5. 기본 수수료나 상품별 수수료를 설정합니다. 필요하면 티어 레벨도 설정하세요.
6. 외부 웹사이트에 트래킹 스크립트를 추가합니다.
7. 캠페인을 **게시**하면 제휴 파트너가 판매를 시작할 수 있어요.

## 이 기능이 도움이 되는 이유

제휴 파트너가 어떤 웹사이트에서든 상품을 판매할 수 있어서 마케팅 범위가 넓어져요. 도메인 전체 트래킹과 통합 링크를 쓰면 제휴 캠페인을 간편하게 운영하고, 판매를 늘리고, 제휴 파트너에게 쉽게 보상할 수 있습니다.

## 중요 사항

- 지금은 Stripe로 판매하는 상품만 지원해요.
- 일회성 상품은 항상 기본 수수료 설정을 따라요.
- 반복 결제 상품은 수수료율을 따로 정할 수 있어요. 상품별 수수료를 설정하려면 첫 번째 단계에서 해당 상품을 추가하세요.
- 수수료 대상에서 제외할 상품이 있다면 그 상품을 추가하고 수수료를 0%로 설정하세요.
