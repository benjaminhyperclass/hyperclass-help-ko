# Email AI로 다른 플랫폼의 이메일 가져오기

Email AI를 쓰면 이미 가지고 있는 이메일을 처음부터 다시 만들지 않고, 편집할 수 있는 하이퍼클래스 템플릿으로 바꿀 수 있어요. 받은편지함이나 이전에 쓰던 마케팅 플랫폼의 이메일을 가져오고, 편집기를 고른 뒤, 변환된 템플릿을 캠페인에 쓰기 전에 확인하는 방법을 안내해요.

## Email AI로 이메일 템플릿 가져오기란?

Email AI는 가져오기 전용 고유 이메일 주소로 보낸 이메일을 읽어서 다시 쓸 수 있는 하이퍼클래스 템플릿으로 바꿔 줘요. 이메일이 도착하면 하이퍼클래스가 AI로 이메일 구조를 다시 만들어요. 그러면 **디자인 에디터**나 **코드 편집기**에서 바로 이어서 편집할 수 있어요.

Mailchimp, Active Campaign, Kajabi, HubSpot 같은 도구나 다른 이메일 플랫폼의 캠페인을 하이퍼클래스로 옮길 때 유용해요. 레이아웃을 직접 다시 짜고, 문구를 복사하고, 버튼을 새로 만들 필요 없이 원본 이메일을 가져와 변환된 버전부터 편집하면 돼요.

## 이럴 때 좋아요

- 특정 서비스에 얽매이지 않아요. 받은편지함이나 이전 마케팅 플랫폼에서 이메일을 가져올 수 있어요.
- 고객 온보딩이 빨라져요. 고객이 이미 쓰고 있는 반응 좋은 이메일을 몇 분 만에 하이퍼클래스로 옮길 수 있어요.
- 수작업이 줄어요. 레이아웃을 처음부터 다시 만들지 않고, 기존 이메일을 편집 가능한 템플릿으로 바꿔요.
- 가져온 뒤에 Email AI로 이메일을 더 다듬을 수 있어요.
- 가져온 이메일을 템플릿으로 편집하고 저장해 두었다가 이후 캠페인에 다시 쓸 수 있어요.
- 가져온 템플릿을 시각적으로 편집하려면 **디자인 에디터**로, HTML을 직접 다루려면 **코드 편집기**로 열 수 있어요.

## 가져오기 옵션

가져오기 드롭다운에서 이메일이 어디서 왔는지에 맞는 항목을 고르세요. 알맞은 항목을 고르면 Email AI가 이메일을 변환할 때 하이퍼클래스가 더 정확하게 참고할 수 있어요.

드롭다운에는 다음 항목이 있어요.

- **AI로 모든 플랫폼에서 가져오기**
- Mailchimp
- Active Campaign
- Kajabi

받은편지함에서 가져오는 이메일이거나, 드롭다운에 없는 서비스나 일반 외부 출처의 이메일이면 **AI로 모든 플랫폼에서 가져오기**를 선택하세요. 목록에 있는 도구에서 만든 이메일이면 해당 플랫폼 항목을 선택하세요.

## Email AI로 이메일 템플릿 가져오는 순서

먼저 하이퍼클래스 화면에 표시된 고유 이메일 주소로 이메일을 보내거나 전달해요. 이메일이 도착하면 하이퍼클래스가 편집 가능한 템플릿으로 변환하고, 그 템플릿을 확인·수정한 뒤 저장해 두고 쓰면 돼요.

{% hint style="warning" %}
Email AI는 실수할 수 있어요. 가져온 템플릿은 실제 캠페인에 쓰기 전에 꼭 확인하세요. 레이아웃, 이미지, 버튼, 링크, 여백, 문구, 개인화 항목, 모바일 화면을 살펴보세요.
{% endhint %}

1. 왼쪽 메뉴에서 **마케팅**으로 이동해요.
2. 상단 메뉴에서 **이메일**을 클릭해요.
3. **템플릿**을 열어요.

   ![이메일 템플릿 화면](https://jumpshare.com/share/2KznD8JuUKPfHFHNEeiQ+/Screen+Shot+2026-04-29+at+17.13.03.png)
4. **+ 신규**를 클릭해요.
5. **Import Email with AI**(AI로 이메일 가져오기)를 선택해요.

   ![AI로 이메일 가져오기 선택 화면](https://jumpshare.com/share/D1clLTm2wh9NG53aq1CQ+/Screen+Shot+2026-04-29+at+17.14.43.png)
6. **Import Email Templates**(이메일 템플릿 가져오기) 창에서 이메일을 어디서 가져오는지 선택해요.

   - 받은편지함이나 지원하지 않는 플랫폼의 이메일이면 **AI로 모든 플랫폼에서 가져오기**를 선택하세요.
   - 해당하는 경우에는 **Mailchimp**, **Active Campaign**, **Kajabi** 같은 목록의 플랫폼을 선택하세요.

     ![가져올 플랫폼 선택 화면](https://jumpshare.com/share/Iv8H0gTuCCjVayEILnJQ+/Screenshot+2026-04-29+at+16.59.07.png)
7. **다음 주소로 이메일 보내기** 아래에 표시된 동적 이메일 ID를 **복사**해요.
8. 받은편지함이나 이전 마케팅 플랫폼에서 테스트 이메일을 보내거나, 해당 이메일을 복사한 가져오기 이메일 주소로 전달해요.

   ![이메일을 가져오기 주소로 보내는 과정](https://jumpshare.com/share/yyhbY8e7iB2kVSRqE1BY+/GIF+Recording+2026-04-29+at+17.22.57.gif)
9. 이메일을 보낸 뒤 **이메일 가져오기** 화면으로 돌아와요.
10. 변환된 템플릿을 **디자인 에디터**와 **코드 편집기** 중 어느 쪽으로 열지 선택해요.
11. **계속**을 클릭해요.
12. 가져온 이메일을 확인하고, 필요한 부분을 수정한 뒤 저장하거나 캠페인에 사용하세요.

    ![가져온 이메일을 확인하고 편집하는 과정](https://jumpshare.com/share/8ESTjpBZph9XjEfUNe40+/GIF+Recording+2026-04-29+at+17.24.56.gif)

## 디자인 에디터와 코드 편집기 중 무엇을 고를까요?

Email AI가 이메일을 변환한 뒤 어떤 편집기를 쓰느냐에 따라 편집 방식이 달라져요. **디자인 에디터**는 화면을 보면서 편집하기 좋고, **코드 편집기**는 이메일 HTML을 직접 다뤄야 할 때 알맞아요.

다음과 같은 경우에는 **디자인 에디터**를 선택하세요.

- 드래그 앤 드롭 방식 컨트롤로 템플릿을 시각적으로 편집하고 싶을 때
- 코드를 다루지 않고 텍스트, 버튼, 이미지, 레이아웃을 조정하고 싶을 때
- 이메일을 가져온 뒤 마케팅 내용을 빠르게 수정하고 싶을 때
- 시각적 편집기를 선호하는 사용자에게 템플릿을 넘기려는 때

다음과 같은 경우에는 **코드 편집기**를 선택하세요.

- 이메일 HTML을 직접 확인하거나 수정하고 싶을 때
- 맞춤 레이아웃을 위해 코드 기반 작업 방식을 유지하고 싶을 때
- HTML 지식이 필요한 기술적인 변경을 하려는 때
- 처음부터 맞춤 HTML로 만든 템플릿을 계속 작업하려는 때

![디자인 에디터와 코드 편집기 선택 화면](https://jumpshare.com/share/U89ciCFmIY9dfh1hqcEA+/Screen+Shot+2026-04-29+at+17.44.19.png)

## 자주 묻는 질문

### 어떤 플랫폼의 템플릿을 가져올 수 있나요?
테스트 이메일이나 캠페인을 보낼 수 있는 이메일 플랫폼이라면 모두 가져올 수 있어요. Mailchimp, Klaviyo, ConvertKit, ActiveCampaign, Constant Contact 등이 해당돼요. 드롭다운에 없는 서비스라면 **AI로 모든 플랫폼에서 가져오기**를 선택하세요.

### 다른 플랫폼에서 테스트 이메일을 보내는 대신, 받은편지함에 있는 이메일을 전달해도 되나요?
네, 가능해요. 받은편지함에 있는 이메일을 하이퍼클래스에 표시된 동적 가져오기 이메일 주소로 전달하면 돼요.

### 원본 이메일의 서식과 이미지가 그대로 유지되나요?
Email AI는 가져오는 동안 이메일의 구조, HTML, 이미지, 디자인 요소를 그대로 유지하도록 만들어졌어요. 다만 일부 요소는 조금 손봐야 할 수 있으니, 실제 캠페인에 쓰기 전에 변환된 템플릿을 꼭 확인하세요.

### 가져온 템플릿을 바로 캠페인에 쓸 수 있나요?
네, 가능해요. 가져온 템플릿을 확인하고 편집해 저장하면 이메일 캠페인이나 자동화에 쓸 수 있어요.

### 다른 플랫폼에서 원본 템플릿을 수정했어요. 어떻게 하나요?
수정한 이메일을 하이퍼클래스에 표시된 시스템 생성 가져오기 주소로 보내거나 전달해서 다시 가져오세요.

### 일반 텍스트 이메일도 가져올 수 있나요?
네, 가져올 수 있어요. 다만 **코드 편집기**는 구조화된 콘텐츠가 있는 HTML 기반 이메일에 가장 잘 맞아요.

### 가져온 템플릿은 하이퍼클래스 어디에 표시되나요?
직접 만든 템플릿과 마찬가지로 **마케팅 > 이메일 > 템플릿**에 표시돼요.

### 디자인 에디터와 코드 편집기 중 어떤 걸 써야 하나요?
코드 없이 화면을 보며 이메일을 편집하려면 **디자인 에디터**를 쓰세요. HTML을 직접 다뤄야 하거나 맞춤 코드로 만든 이메일이라면 **코드 편집기**를 쓰세요.

### 템플릿을 가져온 뒤에 무엇을 확인해야 하나요?
이메일을 저장하거나 보내기 전에 레이아웃, 이미지, 버튼, 링크, 여백, 브랜딩, 문구, 병합 필드, 모바일 화면을 확인하세요.

### 경쟁사 이메일이나 다른 발신자에게서 받은 이메일도 가져올 수 있나요?
받은편지함의 이메일을 전달하면 새 편집 가능 템플릿의 시작점으로 쓸 수 있어요. 보내기 전에 최종 템플릿이 회원님의 브랜딩, 콘텐츠, 링크, 규정에 맞는 메시지를 담고 있는지 확인하세요.
