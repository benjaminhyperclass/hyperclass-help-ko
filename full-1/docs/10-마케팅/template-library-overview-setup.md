# 템플릿 라이브러리 개요 및 설정

**템플릿 라이브러리**는 웹사이트, 퍼널, 소셜 미디어 게시물, 이메일 캠페인 등에 쓸 수 있는 전문가 디자인 템플릿 모음이에요. 템플릿마다 고품질 스톡 이미지와 콘텐츠가 들어 있어서 완성도 높은 마케팅 자료를 빠르게 만들 수 있어요. 이 문서에서는 템플릿 라이브러리를 켜는 방법과 영역별 사용 위치를 안내해요.

[동영상](https://www.youtube.com/embed/uBVyg2TZbGc?&wmode=opaque)

## 템플릿 라이브러리가 도움이 되는 사람

- 소규모 사업자: 디자이너를 고용하지 않아도 전문적인 마케팅 자료를 만들 수 있어요.
- 마케팅 에이전시: 고객 프로젝트에 미리 디자인된 템플릿을 활용해 시간을 아낄 수 있어요.
- 프리랜서: 디자인 경험이 많지 않아도 마케팅 서비스를 제공할 수 있어요.
- 기업 마케팅 팀: 디자인 작업 과정을 간소화하고 브랜드의 일관성을 유지할 수 있어요.

## 템플릿 라이브러리의 장점

- 시간과 노력 절약: 미리 디자인된 템플릿으로 마케팅 자료를 빠르게 만들 수 있어요.
- 높은 디자인 품질: 프리미엄 스톡 이미지와 콘텐츠가 들어 있는 템플릿으로 일관된 브랜드 이미지를 유지할 수 있어요.
- 쉬운 사용: 필터와 미리보기로 비즈니스에 맞는 템플릿을 쉽게 찾을 수 있어요.
- 사용자 지정: 이미지, 색상, 콘텐츠를 바꿔서 브랜드에 맞게 수정할 수 있어요.
- 비용 절감: 맞춤 디자인이나 디자이너 고용에 드는 비용을 줄일 수 있어요.
- 접근성: 추가 요금이나 구독 없이 모든 사용자가 쓸 수 있어요.

## 템플릿 라이브러리 새 기능

1. **문서 & 계약**
   - 법률 문서와 계약서 템플릿을 만들고, 업로드하고, 관리할 수 있어요.
   - 미리 만들어진 템플릿을 수정하거나 직접 만들어서 서류 작업을 간소화하세요.
2. **광고 관리자**
   - 다양한 광고 목적에 맞춘 80개 이상의 템플릿을 쓸 수 있어요.
   - 실시간 미리보기와 기본 제공 설정으로 광고를 더 빠르게 만들 수 있어요.
3. **리포팅 및 대시보드**
   - 리포트와 대시보드용 사용자 지정 템플릿을 업로드하고 관리할 수 있어요.
   - 업로드할 때 민감한 데이터를 가려서 보호할 수 있어요.
   - 미리보기 이미지를 추가하면 라이브러리에서 템플릿을 한눈에 알아볼 수 있어요.

## 템플릿 라이브러리 켜고 끄기

에이전시 관리자만 쓸 수 있어요.

1. **에이전시 설정 > 회사**로 이동하세요.
2. 오른쪽으로 스크롤해서 **템플릿 라이브러리** 옵션을 찾으세요.
3. **Make Templates visible to clients**(클라이언트에게 템플릿 표시)를 켜세요.

![에이전시 설정 > 회사에서 템플릿 표시 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036518605/original/VY_WTpc2ggBTh5o1uG-7ksDqcZ-jnd7HOA.png?1731520941)

## 퍼널 및 웹사이트 템플릿 라이브러리

1. 서브 계정으로 이동하세요.
2. **사이트 > 퍼널**(또는 **웹사이트**)로 이동하세요.
3. **New Funnel**(새 퍼널)(또는 **New Website**(새 웹사이트))을 클릭하세요.
4. **Go to Template Library**(템플릿 라이브러리로 이동)를 선택하세요.
5. 비즈니스에 맞는 템플릿을 찾아서 선택하세요.

![퍼널 템플릿 라이브러리로 이동하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036518684/original/824jAbISW-HWKRK-W5uQt_rSV1U66ZZqiw.gif?1731521065)

## 소셜 플래너 템플릿 라이브러리

1. 서브 계정에서 **마케팅 > 소셜 플래너**로 이동하세요.
2. **+ New Post**(새 게시물) 버튼을 클릭하세요.
3. **Choose Social Planner Templates**(소셜 플래너 템플릿 선택)를 선택하세요.
4. 템플릿을 살펴보고 하나를 선택하세요.
5. 내용을 수정한 뒤 게시물을 예약하세요.

{% hint style="info" %}
**Type**(유형) 필터를 사용하면 원하는 소셜 플래너 형식(예: 게시물, 스토리/릴스)을 빠르게 찾을 수 있어요.
{% endhint %}

![소셜 플래너에서 템플릿을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036518705/original/Hyg6zNgnS04OMNGxa3Ym6Y5-JSWMGaa8bA.png?1731521144)

## 템플릿 검색하고 찾아보기

검색창을 사용하면 템플릿 라이브러리 전체에서 원하는 템플릿을 더 빠르게 찾을 수 있어요.

- 검색창을 클릭하면 최근 검색어, 추천 검색어, 인기 주제가 보여요.
- 키워드를 여러 개 입력하면 결과를 더 정확하게 좁힐 수 있어요.
- 검색창이나 **색상** 필터로 색상별 템플릿을 찾을 수 있어요.
- 검색 결과에서 일치하는 키워드가 강조되어 보여요.
- **필터 초기화**를 누르면 현재 검색어와 필터가 모두 초기화돼요.

**이번 주 인기 트렌드**, **최근 추가됨** 같은 섹션에서도 템플릿을 둘러볼 수 있어요.

### 템플릿 둘러보기, 미리보기, 비교하기

템플릿을 더 빠르게 살펴볼 수 있도록 탐색 화면이 개선되었어요.

- 썸네일이 커져서 세부 내용을 한눈에 볼 수 있어요.
- 향상된 미리보기에서 더 적은 클릭으로 모바일과 태블릿 보기를 전환할 수 있어요.
- 다운로드 수 같은 추가 정보로 템플릿을 빠르게 비교할 수 있어요.
- 그리드/목록 전환 버튼으로 시각 중심 보기와 간결한 목록 보기를 바꿀 수 있어요.

## 이메일 빌더 템플릿 라이브러리

1. 서브 계정에서 **마케팅 > 이메일 > 템플릿**으로 이동하세요.
2. **+ 신규** 버튼을 클릭해서 이메일 템플릿을 만드세요.
3. **템플릿 라이브러리**를 선택하세요.
4. 마음에 드는 템플릿을 찾아서 선택하세요.
5. 브랜드에 맞게 템플릿을 수정하세요.

## 문서 및 계약 템플릿 라이브러리

1. **Documents**(문서) 탭으로 이동하세요.
2. **Create New**(새로 만들기)를 선택한 뒤 **템플릿 라이브러리**에 접속하세요.
3. 계약서 템플릿을 업로드하거나 수정하세요.

![문서 탭에서 템플릿 라이브러리에 접속하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036518686/original/DbZN5FWVEXIGUPvhgYntSNFCWDd7W5XXkg.gif?1731521092)

## 자주 묻는 질문

### 에이전시도 템플릿 라이브러리에 자체 템플릿을 추가할 수 있나요?

네, 에이전시는 템플릿 라이브러리에 자체 템플릿을 추가할 수 있어요. 이 기능은 $497 요금제 이상에서 쓸 수 있어요. (자체 템플릿을 추가하는 방법은 별도 문서를 참고하세요.)

### 템플릿 라이브러리를 쓰려면 비용이 드나요?

아니요, 템플릿 라이브러리는 추가 요금 없이 모든 사용자가 쓸 수 있어요.

### 앞으로 하이퍼클래스의 다른 영역에도 템플릿이 추가되나요?

하이퍼클래스는 사용자 의견과 수요를 바탕으로 템플릿 라이브러리를 다른 영역까지 넓히는 방안을 검토하고 있어요.

### 에이전시가 특정 템플릿을 서브 계정에서 숨기고 에이전시에서만 보이게 할 수 있나요?

직접 숨길 수는 없지만 방법이 있어요. 에이전시는 **카테고리**를 만들고 숨김으로 설정할 수 있어요. 템플릿이 숨김 카테고리에만 들어 있고 보이는 카테고리에는 들어 있지 않으면, 그 템플릿은 서브 계정에 나타나지 않아요. 자세한 내용은 "서브 계정에서 개별 템플릿 숨기기" 문서를 참고하세요.
