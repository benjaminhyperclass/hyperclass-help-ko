# 트리거 링크 개요

**트리거 링크**를 쓰면 SMS, 이메일, GMB, Facebook/Instagram DM, WhatsApp 메시지에서 링크를 클릭한 사용자를 원하는 페이지로 보낼 수 있어요. 클릭 기록은 연락처의 활동 타임라인에 남고, 워크플로우에서 미리 정해 둔 동작이 실행돼요.

[동영상](https://www.youtube.com/embed/H6HGq43ljiE?&wmode=opaque)

사용자가 트리거 링크를 클릭하면 시스템이 클릭을 기록하고 워크플로우의 정해진 동작을 실행해요. 워크플로우 안에는 트리거 링크 클릭으로 실행할 수 있는 트리거와 액션이 있어요.

{% hint style="info" %}
트리거 링크는 SMS, 이메일, GMB, Facebook/Instagram/WhatsApp DM에서만 쓸 수 있어요.
{% endhint %}

## 트리거 링크 활용 사례

### 이메일 캠페인에서 URL 자동으로 바꾸기

트리거 링크를 쓰면 이메일 캠페인의 URL을 자동으로 바꿀 수 있어요. 예를 들어 매달 또는 분기마다 프로모션을 하면서 같은 이메일 템플릿을 쓰고 싶다고 해 볼게요. 이때 현재 프로모션 URL을 가리키는 커스텀 값으로 트리거 링크를 설정해 두면 돼요. 연락처가 이 링크를 클릭하면 가장 최근 프로모션 페이지로 이동해요. 그러면 링크를 매번 직접 고치지 않고 이메일 템플릿을 다시 쓸 수 있어요.

### 트리거 링크 클릭에 따른 워크플로우 자동화

트리거 링크 클릭에 반응하는 워크플로우를 만들 수 있어요. 예를 들어 예약 확인 메시지와 리마인더를 보내는 워크플로우를 만들어 볼게요. 연락처가 예약 리마인더 이메일의 트리거 링크를 클릭하면 시스템이 클릭을 기록하고, 설문이나 리뷰 요청 보내기 같은 다음 단계를 실행해요.

### 커뮤니케이션 채널별 구독 해지 링크

SMS, 이메일, Google My Business(GMB), Facebook, Instagram 등 여러 커뮤니케이션 채널에 구독 해지용 트리거 링크를 설정할 수 있어요. 이 링크를 클릭한 연락처는 해당 채널의 구독이 해지돼요. 이렇게 하면 수신 거부 규정을 지키고 수신 환경설정을 효과적으로 관리할 수 있어요.

### 트리거 링크 브랜딩

트리거 링크가 에이전시 브랜딩과 어울리도록 모양을 바꿀 수 있어요. API 도메인을 설정하면([아래 자주 묻는 질문](trigger-links-overview.md) 참고) 트리거 링크에 에이전시 도메인이 표시돼요. 사용자에게 더 전문적이고 브랜드가 살아 있는 경험을 줄 수 있어요.

### 연락처 활동 추적

트리거 링크로 SMS와 이메일 캠페인에서 연락처가 어떻게 반응하고 행동하는지 추적할 수 있어요. 연락처가 트리거 링크를 클릭하면 그 활동이 연락처의 활동 타임라인에 기록돼요. 이 정보는 연락처의 행동과 캠페인 성과를 살펴보는 데 도움이 돼요.

### 캠페인에서 교육 자료 제공

이메일 캠페인에 트리거 링크를 넣어 교육 자료를 제공할 수 있어요. 예를 들어 상품이나 서비스와 관련된 튜토리얼, 사용법 영상, 글로 가는 링크를 넣을 수 있어요. 이 링크를 클릭하면 자동 후속 동작을 실행하거나, 연락처가 특정 주제에 관심이 있는지 추적할 수 있어요.

### 이벤트 등록과 안내

이벤트를 진행한다면 이메일 초대장에 트리거 링크를 넣어 보세요. 수신자가 참석 여부를 알리거나 이벤트 소식을 받으려고 트리거 링크를 클릭하면, 참석 확인, 이벤트 상세 정보 발송, 추가 정보 수집을 자동으로 처리할 수 있어요.

### 상품 추천과 맞춤 안내

이메일 마케팅에서 연락처의 선호도와 지난 활동을 바탕으로 한 맞춤 상품 추천 페이지로 연결되는 트리거 링크를 쓸 수 있어요. 이 링크가 클릭되면 이후 커뮤니케이션과 상품 제안을 맞춤화하는 자동 프로세스를 시작할 수 있어요.

## 트리거 링크 사용 방법

### 커스텀 값과 트리거 링크로 URL 자동으로 바꾸기

**커스텀 값**(Custom Values)과 트리거 링크를 함께 쓰면 URL을 자동으로 바꿀 수 있어요. 매달 또는 분기마다 프로모션을 하면서 같은 워크플로우를 쓰고 싶을 때 좋아요. **커스텀 값**의 URL을 새 '오퍼 URL'로 바꿔 두면, 시스템이 트리거 링크를 자동으로 업데이트해요.

{% hint style="info" %}
- 이전 캠페인에서 이미 보낸 링크 URL에는 소급 적용되지 않아요.
- 워크플로우를 설정할 때 SMS나 이메일 본문에 '트리거 링크'를 넣어야 해요. 본문에 '커스텀 값'을 넣으면 링크를 클릭해도 트리거 링크가 실행되지 않아요.

커스텀 값을 트리거 링크와 함께 올바르게 쓰려면 다음 순서로 진행하세요.

1. 먼저 플랫폼에서 트리거 링크를 만들어요.
2. 그 트리거 링크에 동적 URL(커스텀 값)을 지정해요.
3. 메시지 본문에는 커스텀 값 자체가 아니라 실제 트리거 링크를 넣어요.
{% endhint %}

[동영상](https://www.loom.com/embed/0a0f620c999e49e6960676e33879acdc)

### 워크플로우 대기 단계에서 트리거 링크 클릭 활용하기

이 동영상에서는 워크플로우의 **Wait**(대기) 액션을 써서 트리거 링크 클릭에 따라 다음 단계를 실행하는 방법을 보여 드려요. 이 워크플로우는 워크플로우 라이브러리에서 **Recipe - Appointment Confirmation + Reminder + Survey + Review Request**라는 이름으로 찾을 수 있어요.

[동영상](https://www.loom.com/embed/f3b40f2aa8cc4c3980b372dd3a90eeb4)

### 커뮤니케이션 채널별 구독 해지 트리거 링크 설정하기

SMS, 이메일, GMB, Facebook/Instagram DM 채널별로 구독 해지 트리거 링크를 설정하는 방법이에요.

[동영상](https://www.loom.com/embed/5aa346eb45f749d6ba98d1cccaf568ec)

{% hint style="info" %}
SMS 통신사에는 기본적으로 'STOP', 'STOPALL', 'UNSUBSCRIBE', 'CANCEL', 'END', 'QUIT' 같은 수신 거부 키워드가 미리 만들어져 있어요. 이 키워드를 보내면 리드/연락처의 구독이 자동으로 해지돼요.

다시 구독하려면 리드/연락처가 "Start"라고 답장해야 해요.
{% endhint %}

## 자주 묻는 질문

### 트리거 링크에 브랜딩을 적용하려면 어떻게 하나요?

에이전시 도메인이 보이도록 API 도메인을 설정하세요. 설정 방법은 '에이전시 API 도메인 설정하기' 문서를 참고하세요.

현재는 서브 계정마다 별도의 API 도메인을 지정할 수 없어요. 도메인 하나를 추가하면 모든 서브 계정이 그 도메인을 함께 써요.

### 연락처의 활동 타임라인은 어디서 볼 수 있나요?

**연락처 > 스마트 리스트**로 이동해 연락처를 검색한 다음 **연락처 활동**을 클릭하세요.

![연락처 활동 타임라인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48278188001/original/tQiXvIBFQTalUwiuOZ5oGLSS_7cfaUvxJA.png?1674834637)

### Wait 액션의 Timeout 토글은 어떤 기능인가요?

**Timeout**(시간 초과) 토글을 켜면, 토글 아래 입력란에 정한 시간이 지난 뒤 **Wait** 액션(단계)을 건너뛰어요. 이 입력란은 토글을 켰을 때만 보여요.

![Wait 액션의 Timeout 토글 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155018392858/original/mEXMmc4R78gXadRH3AY69KJugOmbEzavsQ.gif?1705957179)
