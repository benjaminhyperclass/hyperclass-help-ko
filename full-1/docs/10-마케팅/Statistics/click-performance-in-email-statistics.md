# 이메일 통계의 클릭 성과 리포트 보기

**클릭 성과** 리포트에서는 수신자가 이메일 캠페인 속 링크를 어떻게 눌렀는지 볼 수 있어요. 총 클릭 수, 고유 클릭 수, 링크별 성과를 비교하면 어떤 콜투액션(CTA)이 반응을 가장 많이 얻는지 알 수 있어요. 이 결과를 바탕으로 이메일 콘텐츠와 링크 위치를 개선하고, 다음 캠페인을 데이터에 근거해 결정할 수 있어요.

## 이메일 통계의 클릭 성과란?

**클릭 성과**는 하이퍼클래스 이메일 통계 안에서, 발송한 이메일 캠페인의 링크 반응을 자세히 보여 주는 리포트예요. 오픈율이나 일반적인 참여 지표만 보지 않고, 어떤 링크가 몇 번 클릭됐는지, 몇 명이 클릭했는지까지 확인할 수 있어요.

이 리포트는 발송 전에 클릭 트래킹을 켜 둔 개별 캠페인의 링크 활동을 집계해요. 버튼, 이미지 링크, 텍스트 링크 등 지원되는 URL의 효과를 평가할 수 있어요.

{% hint style="warning" %}
**클릭 성과** 데이터는 클릭 트래킹을 켜고 발송한 캠페인에서만 볼 수 있어요. 임시 저장 상태이거나 예약된 이메일은 발송 전에는 클릭 통계가 표시되지 않아요.
{% endhint %}

## 클릭 성과를 쓰면 좋은 점

어떤 링크에 반응이 모이는지 알면 더 효과적인 이메일 캠페인을 만들 수 있어요. 링크 단위 데이터는 메시지, 이메일 디자인, 콜투액션을 개선하는 데 도움이 돼요.

- **반응이 좋은 링크 찾기:** 클릭을 가장 많이 받은 링크를 확인하고, 수신자가 어떤 콘텐츠에 관심을 보이는지 파악해요.
- **수신자 참여도 측정:** 총 클릭 수와 고유 클릭 수를 비교해서, 같은 사람이 반복해서 누른 경우와 실제로 반응한 수신자 수를 구분해요.
- **콜투액션 효과 평가:** 어떤 버튼, 텍스트 링크, 이미지 링크가 행동을 이끄는지 확인해요.
- **이메일 콘텐츠와 레이아웃 개선:** 링크 반응 패턴을 보고 CTA 위치, 문구, 이메일 디자인을 다듬어요.
- **캠페인 성과 비교:** 캠페인별 클릭 활동을 살펴보고 반응이 더 좋은 방식을 찾아요.
- **데이터 기반 마케팅 결정:** 오픈 수나 짐작에만 기대지 않고, 기록된 반응으로 이메일 마케팅 전략을 다듬어요.

## 클릭 성과 지표 이해하기

**클릭 성과**에는 전체 링크 활동과 수신자 단위 반응을 구분해 보여 주는 지표가 여러 개 있어요. 같은 사람의 반복 클릭과 서로 다른 수신자의 반응은 캠페인 성과에서 다른 의미라서, 각 지표의 뜻을 알아 두면 좋아요.

**총 클릭 수**

**총 클릭 수**는 이메일 캠페인의 트래킹된 링크 전체에서 기록된 클릭의 합계예요. 같은 수신자가 여러 번 누른 클릭도 모두 포함돼요.

예시: 한 수신자가 같은 링크를 세 번 클릭하면 **총 클릭 수**에 3번이 더해져요.

**총 클릭 수**를 보면 캠페인이 만들어 낸 링크 반응의 전체 규모를 알 수 있어요.

**Total Unique Clicks**(고유 클릭 총수)

**Total Unique Clicks**는 이메일 캠페인에서 트래킹된 링크를 한 번 이상 클릭한 수신자 수예요. 캠페인 단위로는 클릭 횟수와 상관없이 수신자 한 명을 1로 세요.

예시: 한 수신자가 버튼을 다섯 번, 다른 수신자가 두 번 클릭했다면 캠페인에는 총 클릭 7회, 클릭한 고유 수신자 2명으로 기록돼요. 이 지표는 서로 다른 몇 명이 이메일에 반응했는지 볼 때 유용해요.

**Unique Engagements**(고유 참여 수)

**Unique Engagements**는 이메일 캠페인에서 트래킹된 링크를 한 번 이상 누른 수신자를 뜻해요. 반복된 클릭을 모두 세지 않고, 수신자를 기준으로 참여 현황을 보여 줘요.

**Clicks per Unique Open**(고유 오픈당 클릭 수)

**Clicks per Unique Open**은 이메일을 연 수신자 대비 클릭 반응이 어느 정도인지 보여 주는 퍼센트예요. 이메일을 연 뒤에 콘텐츠와 콜투액션이 실제 클릭으로 이어졌는지 판단할 때 참고할 수 있어요.

이 수치가 높을수록 고유 오픈 대비 기록된 클릭 반응이 더 강하다고 볼 수 있어요.

{% hint style="warning" %}
**Clicks per Unique Open**은 총 클릭 수, 고유 클릭 수, 고유 오픈 수와 함께 살펴보세요. 기록된 이메일 오픈은 트래킹 신호일 뿐이라서, 실제로 이메일을 본 모든 경우를 나타내지는 않을 수 있어요.
{% endhint %}

**Links in This Email**(이메일 내 링크)

**Links in This Email** 표에서는 캠페인에 들어 있는 트래킹 URL을 하나씩 나눠서 볼 수 있어요. 어떤 링크가 수신자의 눈길을 끄는지 확인할 수 있어요.

| 항목 | 설명 |
| --- | --- |
| **URL** | 트래킹된 링크가 연결되는 주소예요. |
| **Source**(출처) | 링크가 들어 있는 이메일 요소예요. 텍스트, 버튼, 이미지 등이 있어요. |
| **총 클릭 수** | 해당 링크에서 기록된 전체 클릭 수예요. 반복 클릭도 포함돼요. |
| **Total Unique Clicks** | 해당 링크를 클릭한 서로 다른 수신자 수예요. |

예시: 이메일에 "지금 예약하기" 버튼과 "자세히 보기" 텍스트 링크가 있다면, 두 링크의 **총 클릭 수**와 **Total Unique Clicks**를 비교해서 어느 쪽이 더 많은 반응을 얻었는지 알 수 있어요.

{% hint style="info" %}
어떤 링크 성과가 좋은지 정하기 전에 총 클릭 수와 고유 클릭 수를 함께 비교해 보세요. 적은 수의 수신자가 반복해서 누른 링크는 총 클릭 수가 높아도 많은 수신자에게 닿지 않았을 수 있어요.
{% endhint %}

## 클릭 성과 리포트를 쓰면 좋은 때

이메일 안에서 수신자가 한 특정 행동을 평가하고 싶을 때 **클릭 성과** 리포트가 특히 도움이 돼요. 이메일 반응을 캠페인 목표와 연결해 보고, 개선할 부분을 찾을 수 있어요.

대표적인 활용 사례는 다음과 같아요.

- **프로모션 캠페인 평가:** "지금 구매", "혜택 받기", "특가 보기" 같은 버튼을 얼마나 자주 누르는지 확인해요.
- **예약 캠페인 개선:** 예약 페이지로 연결되는 링크의 반응을 측정해요.
- **CTA 위치 테스트:** 이메일 앞부분, 중간, 끝부분에 둔 링크의 클릭 수를 비교해요.
- **콘텐츠 선호도 파악:** 어떤 상품 페이지, 자료, 안내 링크에 관심이 모이는지 확인해요.
- **이메일 디자인 최적화:** 텍스트 링크, 이미지 링크, 버튼의 반응을 비교해요.
- **캠페인 결과 분석:** 여러 캠페인의 트래킹된 클릭 활동을 비교해서 반응이 좋았던 메시지와 콘텐츠 방식을 찾아요.

{% hint style="info" %}
클릭은 트래킹된 링크를 눌렀다는 뜻이지, 전환이 완료됐다는 뜻은 아니에요. 구매나 매출 결과는 전환 리포트와 어트리뷰션 리포트에서 확인하세요.
{% endhint %}

## 클릭 트래킹 조건과 제한 사항

**클릭 성과**는 이메일 캠페인을 발송할 때의 트래킹 설정에 따라 달라져요. 아래 조건을 알아 두면 데이터가 빠지는 일을 막고 결과를 정확하게 해석할 수 있어요.

**발송 전에 클릭 트래킹 켜기**

캠페인을 발송하기 전에 **Track Clicks**(클릭 트래킹) 설정을 켜야 해요. 이메일을 보낼 때 클릭 트래킹이 꺼져 있으면, 이 문서에서 설명하는 **클릭 성과** 데이터가 수집되지 않아요. 이후 발송부터 트래킹을 켜더라도, 이미 보낸 이메일의 클릭을 거꾸로 수집하지는 못해요.

**지원되는 링크 형식 사용하기**

클릭 트래킹 가이드에는 이 기능으로 트래킹되는 웹 링크와 트래킹되지 않는 링크 유형이 안내되어 있어요.

클릭 트래킹이 안정적으로 되려면 다음을 지켜 주세요.

- `https://` 또는 `http://`로 시작하는 전체 URL을 사용하세요.
- URL에 오타나 잘못된 목적지가 없는지 확인하세요.
- `mailto:` 이메일 링크와 페이지 내부 앵커 링크는 일반 웹 링크처럼 트래킹되지 않아요.
- 수신거부 링크 같은 시스템 생성 링크는 문서에 안내된 트래킹 대상에서 제외돼요.

클릭 트래킹 가이드에는 테스트 이메일, 트리거 링크, 커스텀 값이 들어간 일부 링크의 특별한 처리 방식도 나와 있어요. 자세한 제한 사항과 예시는 [이메일 캠페인 클릭 트래킹 가이드](guide-to-click-tracking-in-email-campaigns.md)를 참고하세요.

## 클릭 성과 트래킹 설정하기

이메일을 보내기 전에 클릭 트래킹을 제대로 설정해야 지원되는 링크 반응이 기록돼요. 트래킹을 켜고 캠페인을 발송한 뒤, 수신자가 링크를 누르는 대로 **클릭 성과** 리포트에서 확인할 수 있어요.

**1단계: 이메일 캠페인 열기**

1. 하이퍼클래스 서브 계정에 로그인하세요.
2. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
3. 임시 저장된 캠페인을 선택하거나 새 이메일 캠페인을 만드세요.
4. 이메일 콘텐츠를 준비하고, 수신자가 눌렀으면 하는 링크를 추가하세요.

   ![이메일 캠페인 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083305391/original/5CDEFzcwIisIbXsl3MPB8dDwgU8qGHR3hg.png?1791980222)

**2단계: Track Clicks 켜기**

1. **Send and Schedule**(발송 및 예약) 페이지로 이동하세요.

   ![발송 및 예약 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083305683/original/dmGNaMZ89Ex9UNEP5owHqJcq922t5eOX8Q.png?1791980310)
2. 아래로 스크롤해서 **추가 설정**을 찾으세요.
3. **Track Clicks** 토글을 찾으세요.
4. **Track Clicks**를 켜세요.

   ![Track Clicks 토글을 켠 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083305918/original/fhN2GH3AJmTKmzOz8EydQL766_Kbfm1jTQ.png?1791980414)

이 설정을 켜면 캠페인에서 지원되는 링크 반응이 기록돼요.

{% hint style="warning" %}
캠페인을 발송하거나 예약하기 전에 항상 **Track Clicks**를 먼저 켜세요. 캠페인을 보낼 때 트래킹이 꺼져 있었다면 **클릭 성과** 정보는 나중에 복구할 수 없어요.
{% endhint %}

**3단계: UTM 트래킹 설정하기 (선택)**

UTM 트래킹을 쓰면 지원되는 외부 분석 도구에서 트래픽 출처와 캠페인 정보를 구분하는 데 도움이 돼요.

1. 캠페인 설정에서 **UTM 트래킹**을 찾으세요.
2. 지원되는 링크에 캠페인 정보를 태그로 붙이고 싶다면 켜세요.
3. 발송 전에 설정 내용을 확인하세요.

**UTM 트래킹**은 선택 사항이에요. **클릭 성과** 리포트에 필요한 **Track Clicks** 설정을 대신하지는 않아요.

![UTM 트래킹 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083306191/original/Ja1uB5aKuW07K2CSiMxAssiO_rgmwLoxow.png?1791980502)

**4단계: 캠페인 발송 또는 예약하기**

1. 이메일 콘텐츠, 링크, 수신자, 캠페인 설정을 확인하세요.
2. **Track Clicks**가 켜져 있는지 확인하세요.
3. 캠페인을 바로 보내거나 나중으로 예약하세요.

캠페인이 발송되고 수신자가 지원되는 링크를 누르기 시작하면, 그 반응이 리포트용으로 기록돼요.

![캠페인 발송 또는 예약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083306323/original/GHEcXcTLDEz2BaNp3OAQmi5dcHY8bePRWA.png?1791980571)

## 클릭 성과 데이터 확인하기

트래킹을 켜고 보낸 이메일 캠페인은 캠페인별 통계 페이지에서 **클릭 성과** 리포트를 볼 수 있어요. 여러 캠페인이 합쳐진 통계와 섞이지 않고, 특정 발송 건의 링크 반응만 따로 살펴볼 수 있어요.

1. 하이퍼클래스 서브 계정에서 **마케팅 > 이메일**로 이동하세요.
2. **캠페인** 탭을 선택하세요.
3. 분석할 발송 완료 캠페인을 찾으세요.
4. 캠페인 옆의 점 세 개 메뉴(⋮)를 클릭하세요.
5. **통계**를 선택하세요.
6. 캠페인 통계 사이드 패널이 열릴 때까지 기다리세요.
7. 사이드 패널에서 **Load More Statistics**(통계 더 보기)를 찾으세요.
8. **Load More Statistics**를 클릭해서 확장된 캠페인 리포트 페이지를 여세요.
9. 확장된 통계 페이지에서 **클릭 성과** 탭을 선택하세요.
10. **총 클릭 수**, **Total Unique Clicks**, **Unique Engagements**, **Clicks per Unique Open** 같은 요약 지표를 확인하세요.
11. 아래로 스크롤해서 **Links in This Email**에서 URL별 성과를 확인하세요.

## 자주 묻는 질문

### 이메일 오픈은 있는데 클릭이 하나도 없는 이유가 뭐예요?

수신자가 이메일을 열었지만 트래킹된 링크를 누르지 않았을 수 있어요. 클릭이 있을 거라고 예상했다면, 발송 전에 **Track Clicks**를 켰는지, 링크가 지원되는 형식인지 확인하세요.

### 이메일 주소 링크나 수신거부 링크 클릭도 집계되나요?

클릭 트래킹 가이드에 따르면 `mailto:` 링크와 수신거부 링크 같은 일부 시스템 생성 링크는 이 트래킹 대상에서 제외돼요. **클릭 성과**를 평가할 때는 지원되는 웹 URL을 사용하세요.

### 클릭 성과로 구매나 예약 완료를 측정할 수 있나요?

**클릭 성과**는 지원되는 링크를 눌렀다는 사실을 기록해요. 클릭한 수신자가 실제로 구매했는지, 예약했는지, 다른 행동을 했는지는 이 리포트만으로 확인할 수 없어요. 이런 결과는 전환 리포트나 예약 리포트로 확인하세요.

### 링크별 고유 클릭 수를 더한 값이 캠페인 전체 고유 클릭 수와 달라요. 왜 그런가요?

한 수신자가 여러 URL을 클릭할 수 있기 때문이에요. 링크마다 그 수신자를 각각 고유 클릭으로 세지만, 캠페인 전체의 **Total Unique Clicks**에서는 그 수신자를 한 번만 세요. 그래서 링크별 고유 클릭 수를 모두 더하면 캠페인 전체 값보다 커질 수 있어요.

### 테스트 이메일의 클릭 성과 데이터도 볼 수 있나요?

클릭 트래킹 가이드에 따르면 테스트 이메일은 이 트래킹 기능의 대상이 아니에요. 클릭 리포트를 확인해 보려면 트래킹을 켠 상태로 선택한 테스트 연락처에게 실제 캠페인을 발송하세요.

### 워크플로우 이메일의 클릭 데이터는 캠페인의 클릭 성과 통계와 같은가요?

꼭 그렇지는 않아요. 하이퍼클래스는 지원되는 워크플로우 이메일 액션에 대해서도 클릭 관련 리포트를 제공해요. 하지만 그 이메일이 개별 마케팅 캠페인의 **클릭 성과** 탭과 똑같은 화면을 쓴다는 뜻은 아니에요. 해당 화면은 워크플로우 리포트 문서를 참고하세요.
