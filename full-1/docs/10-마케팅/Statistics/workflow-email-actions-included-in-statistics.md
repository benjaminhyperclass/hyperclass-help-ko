# 워크플로우 이메일 액션 통계를 이메일 마케팅에서 확인하기

워크플로우로 보낸 이메일과 이메일 캠페인으로 보낸 이메일의 통계를 비슷한 방식으로 볼 수 있게 됐어요. 이메일 통계를 한곳에서 정리해서 분석할 때 활용하세요.

[동영상](https://www.youtube.com/embed/L1jvQyAMl7g?&wmode=opaque)

## 달라진 점

- 워크플로우 이메일 통계를 **이메일 마케팅**(Email Marketing)에서 볼 수 있어요.
- 워크플로우 하나의 전체 이메일 통계와 이메일 액션별 통계를 볼 수 있어요.
- 같은 화면에서 워크플로우를 바로 편집할 수 있어요.

## 사용 방법

1. **이메일 마케팅 > 캠페인 > Workflow Campaigns**(워크플로우 캠페인)로 이동해요.
2. **Edit Workflow**(워크플로우 편집)를 클릭하면 빌더로 이동해요.
3. **Statistics**(통계)를 클릭하면 워크플로우 통계를 볼 수 있어요.
4. 드롭다운 메뉴에서 이메일 액션을 선택하면 해당 액션의 통계를 볼 수 있어요.

{% hint style="info" %}
이메일 액션을 만드는 방법, 템플릿과 동기화하는 방법, 새 템플릿을 만드는 방법은 달라지지 않았어요.
{% endhint %}
