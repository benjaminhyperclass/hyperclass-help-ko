# 이메일 마케팅 올인원 대시보드

캠페인, 워크플로우, 일괄 작업으로 보낸 이메일의 성과를 이메일 통계 대시보드 한 곳에서 확인하는 방법을 안내해요.

하이퍼클래스의 이메일 마케팅 올인원 대시보드는 **캠페인**, **워크플로우**, **일괄 작업**의 성과 데이터를 이메일 통계 화면 하나에 모아 보여 줘요. 여러 메뉴를 오가며 데이터를 모으지 않아도 돼요. 이 화면에서는 다음 작업을 할 수 있어요.

- 참여도 비교
- 이메일 발송 방식별 필터링
- 성과가 좋은 이메일 확인
- 통계 내보내기

요약 차트에서 시작해 자세한 성과 추이까지 차례로 살펴볼 수도 있어요. 이 문서에서는 다음 내용을 다뤄요.

- 대시보드를 여는 방법
- 각 리포트 영역을 읽는 방법
- 필터와 샘플 데이터 사용법
- 워크플로우 리포트의 특징
- 통계 내보내기
- 자주 겪는 리포트 문제 해결

{% hint style="info" %}
**이메일 통계 대시보드와 이메일 위젯의 차이**

올인원 이메일 마케팅 대시보드는 **마케팅 > 이메일 > 통계**에서 열리는 이메일 통계 화면이에요. 서브 계정 **대시보드**나 **사용자 지정 리포트**에 추가하는 [이메일 위젯](../../12-대시보드/email-widgets-for-dashboards-and-reporting.md)과는 별개예요.
{% endhint %}

## 이메일 마케팅 올인원 대시보드란?

올인원 이메일 마케팅 대시보드는 캠페인, 워크플로우, 일괄 작업의 이메일 통계를 한곳에 모은 리포트 화면이에요. 발송 방식마다 따로 확인하지 않고, 이메일 통계 대시보드 하나에서 전체 성과를 보고 발송 방식별 참여도를 비교할 수 있어요.

대시보드는 **마케팅 > 이메일 > 통계**에 있어요. 다음 기능을 제공해요.

- **Engagement Summary**(참여 요약) 리포트
- 성과 분석
- 이메일 발송 방식별 필터
- **Top Performing Emails**(성과 상위 이메일)
- 날짜 설정
- 관련 리포트 도구

### 올인원 대시보드의 주요 장점

리포트를 한 화면에서 보면 캠페인, 워크플로우, 일괄 작업의 리포트 화면을 오가지 않고도 이메일 성과를 비교하고 추세를 파악할 수 있어요. 리포트를 확인하는 번거로움이 줄고, 성과가 좋은 이메일 활동도 더 빨리 찾을 수 있어요.

- 통합 이메일 리포트: 캠페인, 워크플로우, 일괄 작업의 이메일 통계를 한곳에서 확인해요.
- 발송 방식별 필터: 더 집중해서 보고 싶을 때 특정 발송 방식만 골라 볼 수 있어요.
- 성과 가시성: 요약과 성과 리포트로 발송 완료 및 참여도 추이를 확인해요.
- 상위 성과 인사이트: 열람이나 클릭 참여가 높은 이메일을 찾아요.
- 워크플로우 세부 확인: 워크플로우 전체를 이메일 하나로 보지 않고, 워크플로우 안의 이메일 액션을 하나씩 확인해요.
- 샘플 리포트: 샘플 데이터 옵션이 보이면 샘플 데이터로 리포트 화면을 미리 볼 수 있어요.
- CSV 내보내기: 이메일 통계 데이터를 내보내 외부 분석, 보고, 공유에 사용해요.

### 대시보드에 포함되는 데이터

이메일 통계는 지원하는 이메일 발송 방식을 하나의 리포트 화면에 모아 보여 줘요. 자동으로 나가는 워크플로우 이메일과 한 번에 보내는 캠페인·일괄 작업 이메일을 비교할 때는 각 발송 방식이 어떻게 표시되는지 알아 두는 것이 중요해요.

| 대시보드 필터 | 의미 |
| --- | --- |
| **All Campaigns**(전체 캠페인) | 이메일 통계에서 지원하는 모든 발송 방식을 합친 리포트예요. |
| **이메일 캠페인** | 이메일 마케팅 캠페인으로 보낸 이메일이에요. |
| **Workflow Campaigns**(워크플로우 캠페인) | 워크플로우의 이메일 액션으로 보낸 이메일이에요. |
| **Bulk Action Campaigns**(일괄 작업 캠페인) | **연락처 > 일괄 작업**으로 보낸 이메일이에요. |

올인원 대시보드는 이메일 활동만 다뤄요. SMS 등 다른 메시지 채널의 통계는 이 이메일 통계 화면에 포함되지 않아요.

## 대시보드 지표와 성과 영역 이해하기

대시보드는 리포트를 요약 영역과 성과 영역으로 나눠 보여 줘요. 이메일 활동의 전체 모습에서 시작해 더 자세한 참여 추이까지 볼 수 있어요. 두 영역을 함께 보면 전반적인 발송 성과와 시간에 따른 수신자 참여 변화를 구분해서 파악할 수 있어요.

### Engagement Summary(참여 요약)

**Engagement Summary**는 선택한 리포트 범위에서 수신자가 이메일에 어떻게 반응했는지 하나의 차트로 보여 줘요. 여러 발송 방식이 포함되어 있으면 이메일 캠페인, 워크플로우 캠페인, 일괄 작업 캠페인이 전체 결과에 각각 얼마나 기여했는지 차트에서 확인할 수 있어요.

![참여 요약 차트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080535170/original/2vU78YnhZ4MK_XcRSTZUwY_mCAomaPpH-Q.png?1788980889)

### Performance Analysis(성과 분석)

**Performance Analysis**에서는 발송 완료 및 참여 지표로 시간에 따른 이메일 추이를 평가해요. 제공되는 설정으로 선택한 기간의 지표를 확인하고, 현재 화면에 포함된 발송 방식끼리 성과를 비교할 수 있어요.

![성과 분석 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080535211/original/kj19Psipu3y7NXb91vgk5gMxNOh41O1xfA.png?1788980983)

{% hint style="info" %}
**데이터 반영 시간:** 대부분의 이메일 통계는 거의 실시간으로 업데이트돼요. 수신자 활동이나 제공업체 지연에 따라 일부 참여 이벤트는 반영되는 데 몇 분 걸릴 수 있어요.
{% endhint %}

개별 이메일 지표의 정의는 [이메일 통계](email-statistics.md) 문서를 참고하세요.

## 발송 방식별로 이메일 통계 필터링하기

발송 방식별 필터를 쓰면 보고 싶은 이메일 활동만 따로 볼 수 있어요. 전체 리포트가 너무 광범위할 때, 이메일 캠페인, 워크플로우 캠페인, 일괄 작업 캠페인을 각각 분석하는 데 유용해요.

1. **마케팅 > 이메일 > 통계**로 이동하세요.
2. 대시보드 왼쪽 위에 있는 발송 방식 드롭다운을 여세요.
3. 전체를 합쳐서 보려면 **All Campaigns**를 선택하세요.
4. 특정 발송 방식만 보려면 **이메일 캠페인**, **Workflow Campaigns**, **Bulk Action Campaigns** 중에서 선택하세요.

![발송 방식 드롭다운 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080535335/original/BRXSn_xipM-iblt7yjEJ0Dviq-oWJwcCvg.png?1788981181)

## 샘플 데이터 사용하기

실제 이메일 활동이 충분하지 않아 대시보드가 비어 있을 때, 샘플 데이터로 이메일 통계 리포트 화면을 미리 볼 수 있어요. 이 옵션이 보이면 대시보드 구성을 이해할 수 있도록 데모용 값이 표시돼요. 이 값은 실제 성과가 아니에요.

대시보드에 **샘플 데이터 사용해 보기**가 보이면 클릭해서 리포트 화면을 미리 확인하세요.

![샘플 데이터 사용해 보기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080535390/original/2RBKOeJLRPYUGdqdv-xIAEfoIHjAKmbRtg.png?1788981276)

### 샘플 데이터가 켜져 있는지 확인하기

샘플 통계가 켜져 있으면 대시보드에 샘플 데이터라는 안내가 표시돼요. 데모용 값을 없애려면 **샘플 데이터 지우기**를 사용하세요.

![샘플 데이터 안내와 샘플 데이터 지우기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080535410/original/N6z6KtPPrDU8YQo3K7f8mVoazKEAxS03Xw.png?1788981315)

샘플 데이터가 켜진 상태의 이메일 통계 화면이에요. 샘플 데이터 안내와 **샘플 데이터 지우기** 버튼이 보여요.

{% hint style="warning" %}
샘플 통계는 데모용 데이터예요. 실제 캠페인, 워크플로우, 일괄 작업의 성과로 해석하지 마세요.
{% endhint %}

## Top Performing Emails(성과 상위 이메일) 이해하기

**Top Performing Emails**는 참여도가 높은 이메일 콘텐츠를 찾는 데 도움이 돼요. 열람률이나 클릭률 같은 참여 지표로 결과를 평가할 수 있어요. 다만 이메일을 캠페인, 일괄 작업, 워크플로우 중 어디서 보냈는지에 따라 항목이 표시되는 방식이 달라요.

{% hint style="warning" %}
**워크플로우 리포트 관련 중요 사항**

**워크플로우**의 경우 **Top Performing Emails**는 워크플로우 전체를 이메일 하나로 보지 않고, **개별 이메일 액션**의 성과를 보여 줘요.
{% endhint %}

| 발송 방식 | Top Performing Emails에 표시되는 단위 |
| --- | --- |
| **이메일 캠페인** | 개별 캠페인 이메일 발송이에요. |
| **Bulk Action Campaigns** | 개별 일괄 작업 이메일 발송이에요. |
| **Workflow Campaigns** | 워크플로우 안의 각 이메일 액션이에요. |

## 이메일 마케팅 올인원 대시보드 사용 순서

서브 계정에서 이메일 통계를 쓸 수 있다면 따로 설정할 것은 없어요. 알맞은 리포트 화면을 열고, 발송 방식과 날짜 범위를 고른 뒤, 이메일을 어떻게 보냈는지에 맞춰 요약과 성과 영역을 읽으면 돼요.

1. **마케팅 > 이메일 > 통계**로 이동하세요.
2. 지원하는 모든 발송 방식을 합쳐서 보려면 **All Campaigns**를 사용하세요.
3. 필요하면 발송 방식 드롭다운에서 **이메일 캠페인**, **Workflow Campaigns**, **Bulk Action Campaigns** 중 하나를 골라 집중해서 보세요.
4. 분석하려는 이메일 활동에 맞는 날짜 범위를 선택하세요.
5. **Engagement Summary**에서 전체 현황을 확인하세요.
6. 아래로 스크롤해 **Performance Analysis**에서 추이와 성과 지표를 확인하세요.
7. **Top Performing Emails**로 이동해 성과가 좋은 개별 발송이나 워크플로우 이메일 액션을 찾으세요.

{% hint style="info" %}
**일괄 작업에서 바로 가기:** **연락처 > 일괄 작업**에서 시작했다면 해당 발송의 통계를 열고 **Load More Stats**(통계 더 보기)를 사용해 전체 이메일 통계 대시보드로 이동할 수 있어요.
{% endhint %}

## 이메일 통계 내보내기

CSV로 내보내면 하이퍼클래스 밖에서 이메일 통계를 분석하거나 관계자와 성과 데이터를 공유할 수 있어요. 전체 이메일 활동을 내보내거나, 이메일 마케팅 캠페인·워크플로우·일괄 작업 중 특정 발송 방식만 내보낼 수 있어요.

1. **마케팅 > 이메일 > 통계**로 이동하세요.
2. 내보낼 리포트 유형을 선택하세요.
3. **내보내기**를 클릭하세요.
4. 내보내기 파일을 받을 이메일 주소를 하나 이상 입력하세요.
5. 받은 이메일을 열어 다운로드 링크로 CSV 파일을 내려받으세요.

| 내보내기 유형 | 리포트 범위 |
| --- | --- |
| **All Campaigns** | 이메일 통계에 표시되는 모든 이메일 활동이에요. 캠페인, 워크플로우, 일괄 작업이 포함돼요. |
| 이메일 마케팅 캠페인만 | **마케팅 > 이메일 > 캠페인**의 이메일 캠페인 성과예요. |
| 워크플로우만 | 워크플로우의 개별 이메일 액션 성과예요. |
| 일괄 작업만 | **연락처 > 일괄 작업**으로 보낸 이메일이에요. |

내보내기 다운로드 링크는 이메일로 전달되며, 제한된 기간 동안만 사용할 수 있어요. 최근 내보내기 기록은 이메일 캠페인 설정 영역에서도 확인할 수 있어요.

자세한 방법과 내보내기 파일 보관 기간은 [이메일 캠페인 데이터 내보내기](../이메일-마케팅/exporting-email-campaign-data.md) 문서를 참고하세요.

## 이메일 마케팅 대시보드 리포트 문제 해결

대시보드 데이터가 예상과 다르면 이메일을 어떻게 보냈는지, 어떤 발송 방식과 날짜 범위를 선택했는지, 이벤트가 아직 처리 중은 아닌지 확인하세요. 설정된 발송 제공업체에 따라 리포트에서 볼 수 있는 발송 완료 및 참여 이벤트가 달라질 수도 있어요.

| 문제 | 확인할 내용 |
| --- | --- |
| 예상한 이메일 활동이 보이지 않아요 | 이메일을 어떻게 보냈는지 확인하고, 올바른 발송 방식과 날짜 범위가 선택되어 있는지 확인하세요. |
| 워크플로우 하나가 이메일 여러 개로 보여요 | **Top Performing Emails**에서는 워크플로우의 이메일 액션을 하나씩 따로 집계하기 때문에 정상이에요. |
| 최근 참여 기록이 아직 보이지 않아요 | 해당 참여 이벤트가 반영될 때까지 몇 분 기다려 주세요. |
| 일괄 작업 이메일을 찾기 어려워요 | 발송 방식 필터에서 **Bulk Action Campaigns**를 선택하거나, 일괄 작업의 통계를 열어 **Load More Stats**를 사용하세요. |
| 일부 통계가 없어요 | 설정된 이메일 제공업체를 확인하고 전용 문제 해결 안내를 참고하세요. 하이퍼클래스에서 받을 수 있는 이벤트는 제공업체마다 다를 수 있어요. |
| 대시보드에 데모 값이 표시돼요 | 샘플 데이터 안내가 있는지 확인하고, 샘플 데이터를 지운 뒤에 실제 이메일 성과로 해석하세요. |

더 자세한 진단 방법은 [이메일 통계 문제 해결](../../09-이메일/트러블슈팅/troubleshooting-email-statistics.md) 문서를 참고하세요.

## 자주 묻는 질문

### 이메일 마케팅 올인원 대시보드는 어디에 있나요?
**마케팅 > 이메일 > 통계**로 이동하세요. 통합 이메일 통계 대시보드가 열려요.

### 어떤 발송 방식의 이메일이 포함되나요?
이메일 캠페인, 워크플로우 캠페인, 일괄 작업 캠페인의 이메일 통계를 한곳에 모아 보여 줘요.

### Top Performing Emails에 워크플로우 이메일이 따로 표시되는 이유는 무엇인가요?
워크플로우 리포트는 워크플로우 안의 개별 이메일 액션을 하나씩 집계해요. 그래서 **Top Performing Emails**도 워크플로우 전체를 이메일 하나로 보지 않고, 각 액션을 따로 평가해요.

### 이메일 통계 데이터를 내보낼 수 있나요?
네. 이메일 통계는 전체 이메일 활동은 물론, 이메일 마케팅 캠페인·워크플로우·일괄 작업 같은 특정 발송 방식의 CSV 내보내기도 지원해요.

### 이메일 통계는 얼마나 빨리 업데이트되나요?
대부분의 이메일 통계는 거의 실시간으로 업데이트돼요. 수신자 활동이나 제공업체 지연에 따라 일부 이벤트는 반영되는 데 몇 분 걸릴 수 있어요.

### 왜 샘플 데이터가 보이나요?
샘플 데이터가 켜져 있으면 리포트 화면을 미리 볼 수 있도록 데모용 값이 표시돼요. 이 값을 없애려면 **샘플 데이터 지우기**를 사용하세요.

### 대시보드에 이메일 위젯을 추가하는 것과 같은 기능인가요?
아니요. 이메일 통계는 **마케팅 > 이메일** 아래에 있는 통합 리포트 화면이에요. [이메일 위젯](../../12-대시보드/email-widgets-for-dashboards-and-reporting.md)은 서브 계정의 대시보드와 사용자 지정 리포트에 추가할 수 있는 별도의 리포트 구성 요소예요.
