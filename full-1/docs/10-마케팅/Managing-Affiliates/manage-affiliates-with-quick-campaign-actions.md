# 빠른 캠페인 액션으로 제휴 관리하기

**제휴 목록**에서 빠른 캠페인 액션을 쓰면 제휴 프로필을 열지 않고도 제휴 파트너를 캠페인에 추가하거나 제거하고, 정지하거나 다른 캠페인으로 옮길 수 있어요.

## 빠른 캠페인 액션이란?

빠른 캠페인 액션을 쓰면 **제휴 목록** 페이지에서 바로 제휴 관리를 할 수 있어요. 제휴 파트너마다 프로필을 열 필요 없이, 점 세 개 메뉴를 클릭해서 원하는 작업을 고르면 돼요. 캠페인 배정과 변경을 빠르고 간단하게 처리할 수 있어요.

{% hint style="warning" %}
모든 빠른 캠페인 액션은 첫 단계가 같아요. **제휴** 페이지에서 관리할 제휴 파트너를 찾아 이름 옆의 점 세 개 메뉴를 클릭하세요. 그다음 **Manage Affiliate**(제휴 관리)를 선택하면 **Suspend**(정지), **Unsuspend**(정지 해제), **Add to Campaign**(캠페인에 추가), **Remove from Campaign**(캠페인에서 제거), **Move to Campaign**(캠페인으로 이동) 같은 작업이 나타나요.
{% endhint %}

## 빠른 캠페인 액션의 장점

이 기능으로 제휴 관리가 어떻게 간편해지는지 정리했어요. 시간을 아끼고 직접 처리하는 단계를 줄일 수 있어요.

- 제휴 파트너를 몇 초 만에 캠페인에 추가하거나 제거할 수 있어요.
- 몇 번의 클릭만으로 제휴 파트너를 정지하거나 정지 해제할 수 있어요.
- 기존 고객을 어떻게 처리할지 선택하면서 제휴 파트너를 캠페인 사이에서 옮길 수 있어요.
- 제휴 프로그램이 커져도 체계적으로 관리할 수 있어요.

## 제휴 파트너를 캠페인에 추가하기

### 1단계: Campaign Actions > Add to Campaign 클릭

## 제휴 파트너를 캠페인에서 제거하기

### 1단계: Campaign Actions > Remove from Campaign 선택

**Campaign Actions**에서 **Remove from Campaign**을 선택하세요.

### 2단계: 제거할 캠페인 선택

제휴 파트너를 제거할 캠페인을 고르세요.

## 제휴 파트너를 캠페인에서 정지하기

### 1단계: Campaign Actions > Suspend Affiliate 클릭

**Campaign Actions**에서 **Suspend Affiliate**(제휴 정지)를 클릭하세요.

### 2단계: 정지할 캠페인 선택

제휴 파트너를 정지할 캠페인을 선택하세요.

{% hint style="warning" %}
정지를 해제하려면(**Unsuspend**) 같은 순서로 진행하세요. 정지된 동안에는 해당 제휴 파트너에 대해 리드를 수동으로 추가하거나, 커미션을 배정하거나, 과거 활동을 가져올 수 없어요.

정지를 해제하면 제휴 파트너의 기존 링크가 자동으로 다시 작동해요.
{% endhint %}

## 제휴 파트너를 다른 캠페인으로 이동하기

### 1단계: Move to Campaign 선택

**Campaign Actions** 메뉴에서 **Move to Campaign**을 선택하세요.

### 2단계: 이동할 캠페인 선택

제휴 파트너를 옮길 캠페인을 선택하세요.

### 3단계: 기존 고객 처리 방법 선택

기존 고객을 어떻게 할지 정하세요.

{% hint style="warning" %}
선택할 수 있는 옵션은 두 가지예요.

1. 이전 캠페인에 그대로 두기: 기존 고객과 그 고객의 반복 커미션은 현재 캠페인에 남아요.
2. 새 캠페인으로 옮기기: 기존 고객에게서 앞으로 발생하는 커미션은 새 캠페인의 규칙을 따라요.
{% endhint %}

### 4단계: 환영 이메일 발송 여부 선택

이동할 캠페인에서 환영 이메일을 꺼 둔 경우에는, 이 옵션을 켜 두어도 이메일이 발송되지 않아요. 캠페인에서 환영 이메일을 켜 둔 경우에는 이 옵션을 꺼서 해당 제휴 파트너에게만 발송하지 않을 수 있어요.

선택을 마쳤으면 **Move Affiliate**(제휴 이동)를 클릭해 작업을 끝내세요.

## 자주 묻는 질문

### "Move to Campaign" 작업을 취소할 수 있나요?

취소 기능은 없어요. 대신 원래 캠페인으로 다시 이동해서 직접 되돌릴 수 있어요.

### 제휴 파트너를 이동하거나 정지하면 이메일 알림이 가나요?

환영 이메일은 캠페인 설정과, 이동 과정에서 선택하는 옵션에 따라 달라져요.

### 빠른 캠페인 액션을 여러 제휴 파트너에게 한꺼번에 적용할 수 있나요?

**빠른 액션**으로는 할 수 없어요. 대신 워크플로우를 쓰거나 수동으로 일괄 처리하세요.

### 제휴 파트너를 정지하면 추천 링크에도 영향이 있나요?

네, 정지된 동안에는 링크가 추적되지 않아요. 정지를 해제하면 링크가 자동으로 다시 활성화돼요.
