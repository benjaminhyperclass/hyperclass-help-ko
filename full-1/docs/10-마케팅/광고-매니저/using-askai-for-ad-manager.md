# 광고 관리자에서 AI에게 문의 활용하기

**AI에게 문의**(AskAI)에 원하는 내용을 말하듯 입력하면 광고 캠페인을 만들고, 관리하고, 개선할 수 있어요. 이 문서에서는 Meta와 Google Ads 광고 작업을 **AI에게 문의**로 처리하는 방법을 안내해요.

## 이 문서에서 배울 내용

- 대화로 캠페인 만들기
- 기존 캠페인 관리하기
- 잠재고객(오디언스) 만들기
- 캠페인 리소스 불러오기
- 성과 데이터 확인하기
- 광고 계정 연결하기

**AI에게 문의**에서는 **광고 관리자**(Ad Manager) 기능을 대화로 쓸 수 있어요. 광고 목표를 말하면 여러 화면을 오가지 않고도 캠페인 추천안을 받을 수 있어요.

## 광고 관리자용 AI에게 문의란?

**AI에게 문의**는 하이퍼클래스의 대화형 AI 화면에서 광고 기능을 쓸 수 있게 해 줘요. 원하는 내용을 평소 말투로 입력하면 Meta와 Google Ads에서 캠페인 생성, 오디언스 설정, 성과 분석, 계정 관리를 안내해 줘요.

여러 화면과 메뉴를 찾아다닐 필요가 없어요. **AI에게 문의**가 필요한 정보를 물어보고, 지원하는 설정을 구성해요. 변경 사항을 게시하기 전에는 초안이나 추천안을 보여 주고 검토를 받아요.

이 기능은 앞으로 출시될 광고 관리자 서브 에이전트의 기반이에요. 서브 에이전트는 더 복잡하고 능동적인 광고 작업을 지원할 예정이에요.

## 주요 장점

- 빠른 캠페인 생성: 광고 목표를 말하면 대화를 따라가는 것만으로 캠페인 초안까지 만들 수 있어요. 여러 설정 화면을 직접 오가지 않아도 돼요.
- 간단한 설정: 리소스 ID를 외우거나 화면을 바꿔 가며 찾지 않아도 오디언스, 전환, 타기팅, 소재를 설정할 수 있어요.
- 통합 지원: 캠페인 생성, 관리, 리포트 확인, 개선을 별도 도구 없이 한 곳에서 할 수 있어요.
- 안전한 실행: 초안을 먼저 만들고, 승인을 받은 뒤에 실행해요. 게시와 삭제처럼 되돌리기 어려운 작업은 항상 명시적인 확인을 거쳐요.
- 에이전트형 광고의 기반: 더 폭넓은 광고 성과를 지원할 전문 광고 관리자 서브 에이전트에 필요한 기능을 갖추고 있어요.

## AI에게 문의로 캠페인 만들기

**AI에게 문의**가 캠페인에 필요한 정보를 모으고, 지원하는 설정을 구성한 뒤 검토용 캠페인을 만들어 줘요. 모든 캠페인은 초안으로 저장되고, 직접 승인해야만 게시돼요.

### 캠페인 생성을 안내하는 방식

**AI에게 문의**는 정해진 질문 순서로 캠페인에 필요한 정보를 모아요. 목표를 말하면 필요한 질문을 이어서 하고, 파악한 내용을 체크 표시와 함께 보여 줘요. 초안을 만들기 전에 내용을 한 번 더 확인해요.

### 예시: Google 검색 캠페인

피트니스 웹사이트용 캠페인을 만드는 예시예요.

- 사용자 요청: "내일부터 다음 주 토요일까지 하루 예산 10달러로 내 웹사이트 https://www.anytimefitness.com/en-in/locations/mumbai-maharashtra-in-1221 의 Google 검색 캠페인을 만들고 싶어요. 성별은 전체, 언어는 힌디어·마라티어·영어, 연령대는 20~45세로 해 주세요."
- 연동 확인: "광고 관리자가 활성화되어 있어요. Google 연동을 확인하고 캠페인 설정 단계를 준비할게요."
- 연결 확인: "Google이 연결되어 있어요. 이 단계를 완료로 표시하고 작업 1 — 캠페인 기본 설정을 시작할게요."
- 파악한 내용 표시: 랜딩 URL(carra.co.in), 네트워크(검색만), 일 예산(하루 $10), 일정(2026년 8월 1일 → 8월 8일), 성별(전체), 언어(힌디어, 마라티어, 영어), 연령대(20~45세) <!-- 검토 필요: 원문 내용이 서로 다름 (사용자 요청의 URL은 anytimefitness.com인데 파악한 랜딩 URL은 carra.co.in으로 표시됨) -->
- 추가 질문: "이 캠페인 이름을 무엇으로 할까요?" → 사용자: "Anytime fitness mumbai"
- 입찰 전략 질문: "어떤 입찰 전략을 사용할까요?" → 사용자: "클릭수 최대화(추천)"
- 타기팅 확인 질문: "광고를 인도 마하라슈트라주 뭄바이(도시, 도달 범위 130만)에 노출할까요?" → 사용자가 지역을 확인해 줘요.

### 예시: 광고 문구가 있는 캠페인 만들기

광고 제목과 설명을 함께 입력해서 캠페인을 만드는 예시예요. 원문에서는 이 예시가 Meta 리드 생성 캠페인이라는 제목 아래 있지만, 내용은 Google 검색 캠페인이에요. <!-- 검토 필요: 원문 내용이 서로 다름 (제목은 Meta 리드 생성 캠페인인데 예시는 Google 검색 캠페인) -->

- 승인 확인: "모두 좋아 보여요! 캠페인을 만들기 전에 검토할 수 있도록 요약본을 정리할게요."

- 초안 생성 확인: "위 내용을 검토하고 승인하면 캠페인을 초안으로 저장해요. 이후 Google Ads에 게시할 수 있어요!"
- 초안 저장 완료: "캠페인 초안이 저장되었어요!"라는 메시지와 함께 요약 표가 나와요. 표에는 캠페인 이름, 상태(초안), 일 예산(하루 $10), 지역(Thane, Bandra West)이 표시돼요.

### 지원하는 캠페인 유형

#### Meta 캠페인

리드 생성, 웹사이트 트래픽, 참여, 판매

**AI에게 문의**는 Meta의 주요 캠페인 목표를 지원해요. 광고 목표를 말하면 필요한 설정 단계를 안내해 줘요.

![Meta 캠페인 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077600585/original/lr1gshXZFj1-QrElAUeoh9fy912XZ3qvgA.png?1785851584)

#### Google 캠페인

검색, 디맨드젠(Demand Gen)

검색 결과에 광고를 노출하려면 Google 검색 캠페인을, YouTube·Discover·Gmail에서 사용자에게 도달하려면 디맨드젠 캠페인을 만들 수 있어요.

![Google 캠페인 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077600674/original/C_intYr1qRrjbGbCe3-rQJ-CW_FiNYqNaA.png?1785851626)

#### 초안 우선 생성

**AI에게 문의**로 만든 캠페인은 모두 초안으로 저장돼요. 게시하려면 명시적인 승인이 필요해서, 캠페인이 언제 라이브로 전환될지 직접 정할 수 있어요.

## 기존 캠페인 관리하기

이미 만든 캠페인도 **AI에게 문의**로 관리할 수 있어요. 말하듯 요청해서 캠페인 목록을 보고, 상세 내용을 확인하고, 설정을 수정하고, 캠페인 작업을 실행해요.

### 사용할 수 있는 캠페인 관리 작업

- 캠페인 목록 보기와 필터링: Meta와 Google Ads 캠페인을 플랫폼, 상태, 성과 기준으로 필터링해서 볼 수 있어요.
- 캠페인 상세 확인: 캠페인 구성, 타기팅 설정, 현재 성과 지표를 대화로 물어보고 확인할 수 있어요.
- 캠페인 설정 수정: 예산, 타기팅 매개변수, 최적화 목표 같은 지원 설정을 바꿀 수 있어요.
- 캠페인 복제: 기존 캠페인을 복제한 뒤 설정을 바꿔서 비슷한 캠페인을 만들 수 있어요.
- 일시중지, 재개, 삭제: 캠페인 상태를 바꾸거나 캠페인을 완전히 삭제할 수 있어요. 실행 전에 확인이 필요해요.
- 변경 후 다시 게시: 제안된 변경 사항을 검토한 뒤 수정한 캠페인을 다시 게시할 수 있어요.

{% hint style="info" %}
캠페인 게시와 삭제 같은 되돌리기 어려운 작업(캠페인 삭제, 계정 연결 해제 등)에는 확인이 필요해요. **AI에게 문의**가 실행 전에 승인을 요청해요.
{% endhint %}

## 오디언스 만들고 관리하기

**AI에게 문의**는 Meta와 Google Ads의 주요 오디언스 작업을 지원해요. 리소스 ID를 직접 찾거나 오디언스 설정 화면을 열지 않아도 맞춤 잠재고객, 유사 오디언스, 플랫폼별 오디언스를 만들 수 있어요.

### Meta 오디언스 유형

**AI에게 문의**는 Meta 캠페인용으로 다음 오디언스를 만들 수 있어요.

- 맞춤 잠재고객
- 유사 오디언스
- 웹사이트 오디언스
- 페이지 참여 오디언스
- 리드 폼 오디언스
- 스마트 리스트 기반 오디언스

### Google 오디언스 유형

Google Ads에서는 다음 오디언스 세그먼트를 지원해요.

- 고객 일치(Customer Match) 오디언스
- 웹사이트 방문자 오디언스
- 유사 오디언스
- 관심분야 오디언스
- 맞춤 잠재고객
- 디맨드젠 오디언스 세그먼트

### 간단해진 오디언스 설정

**AI에게 문의**가 사용할 수 있는 오디언스 소스를 불러와서, ID를 직접 찾지 않아도 알맞은 옵션을 고르도록 도와줘요. 만들고 싶은 오디언스를 말하면 설정 과정을 안내해 줘요.

### 대화로 하는 광고

자연어로 캠페인 만들고 최적화하기

**AI에게 문의**는 **광고 관리자** 기능을 대화형 화면으로 제공해요. 화면을 직접 찾아다니지 않아도 되어서 광고 작업이 더 간편해져요.

## 캠페인 리소스 불러오기

캠페인을 설정할 때 필요한 리소스도 **AI에게 문의**가 대신 불러와요. **광고 관리자** 여러 곳을 돌아다니며 리소스 ID를 찾는 대신, **AI에게 문의**에 요청하면 돼요.

### Meta 리소스

- Meta 페이지와 Instagram 계정: 캠페인 홍보에 쓸 수 있는 연결된 페이지와 Instagram 계정을 불러와요.
- 트래킹 리소스: Meta 광고 계정에 설정된 데이터세트, 픽셀, 리드 폼, 대화 폼을 불러와요.

### Google 리소스

- 전환 트래킹: Google Ads에 설정된 전환 액션과 전환 목표를 불러와요.
- 캠페인 소재: 캠페인에 쓸 수 있는 이미지, 동영상 등 크리에이티브 소재를 불러와요.

### 타기팅 옵션

- 키워드와 관심분야: 타기팅 설정에 쓸 수 있는 키워드와 관심분야 카테고리를 검색해요.
- 지역과 언어: 지역 타기팅 옵션과 언어 설정을 불러와요.
- 인구 통계: 연령대, 성별, 가구 소득 같은 인구 통계 타기팅 옵션을 불러와요.

## 캠페인 성과 확인하기

**AI에게 문의**는 캠페인, 광고 그룹(또는 광고 세트), 광고, 키워드의 성과 데이터를 불러와서 보여 줘요. 원하는 기간을 지정할 수 있고, 추세 차트를 포함한 여러 형식으로 결과를 받아요.

### 예시: Meta 클릭 분석

기간별 캠페인 성과를 분석하는 예시예요.

- 사용자 요청: "지난 1년간 Meta 광고 관리자 플랫폼의 클릭수를 꺾은선 그래프로 만들어 줄래요?"
- 구독 확인: "구독을 확인했어요. 12개월 전체의 월별 클릭 데이터를 한꺼번에 가져올게요."
- 월별 내역 표시: 월별 클릭 합계를 보여 줘요(2025년 8월: 48, 2025년 9월: 7, 2025년 10월~2026년 5월: 0, 2026년 6월: 0, 2026년 7월: 16).
- 추세 차트 표시: Meta 광고 관리자 월별 클릭수(2025년 8월~2026년 7월)를 꺾은선 그래프로 만들어, 시간에 따른 클릭 추세를 한눈에 보여 줘요.

### 성과 데이터 단위

캠페인, 광고 그룹, 광고 세트, 광고, 키워드

지원하는 모든 단위로 성과 데이터를 요청할 수 있어요. 캠페인 전체 결과를 볼 수도 있고, 개별 광고와 키워드까지 자세히 볼 수도 있어요.

### 결과를 보여 주는 형식

- 성과 요약: 노출수, 클릭수, 전환수, 비용 같은 핵심 지표를 한눈에 보여 줘요.
- 지표별 분석: 캠페인, 광고 세트, 기간별 성과를 비교해서 자세히 분석해 줘요.
- 추세 그래프: 선택한 기간의 성과 추세를 월별 또는 일별 꺾은선 차트로 보여 줘요.
- 캠페인 개선 제안: 현재 데이터를 바탕으로 캠페인 성과를 높일 방법을 추천해 줘요.

### 기간 직접 지정

성과 데이터를 요청할 때 원하는 기간을 정할 수 있어요. "최근 7일", "이번 달", "최근 30일", "지난 1년"처럼 말하거나 시작일과 종료일을 직접 지정해도 돼요.

## 광고 계정 연결하기

**AI에게 문의**가 Meta와 Google Ads의 **광고 관리자** 계정 연결과 인증 과정을 안내해 줘요. **AI에게 문의**로 연결해도 **광고 관리자**에서 직접 연결할 때와 같은 보안·규정 준수 요건이 적용돼요.

**광고 관리자**의 기존 권한, 구독 규칙, 계정 접근 제어, 플랫폼 규정 준수 요건도 **AI에게 문의**로 계정을 연결할 때 그대로 적용돼요.

{% hint style="info" %}
광고 계정 연결을 해제하려면 실행 전에 확인이 필요해요. 실수로 연결이 끊기지 않도록 **AI에게 문의**가 승인을 요청해요.
{% endhint %}

## 사용자 제어와 안전장치

**AI에게 문의**는 중요한 광고 결정을 대신 내리지 않고 사용자를 돕도록 설계되어 있어요. 여러 안전장치가 있어서 광고 활동을 직접 통제할 수 있어요.

### 기본 안전장치

- 초안 우선 생성: 모든 캠페인은 기본적으로 초안으로 저장돼요. 게시하려면 사용자의 명시적인 승인이 필요해요.
- 승인 기반 게시: 캠페인 게시는 항상 명시적인 승인이 필요해서, 실수로 또는 너무 일찍 시작되는 일을 막아 줘요.
- 삭제 등 되돌리기 어려운 작업 확인: 캠페인 삭제, 페이지 제거, 계정 연결 해제는 실행 전에 확인이 필요해요.
- Meta 특별 광고 카테고리 적용: 주택, 고용, 신용, 사회 이슈를 대상으로 하는 캠페인을 만들 때 Meta의 특별 광고 카테고리 요건이 적용돼요.
- 기존 권한 확인: **광고 관리자**의 모든 역할·권한 확인이 그대로 적용돼요. **AI에게 문의**는 기존 계정 접근 제어를 따라요.
- 미지원 작업은 안내 화면으로 이동: **AI에게 문의**가 아직 지원하지 않는 작업을 요청하면 해당 **광고 관리자** 화면으로 안내해요.

### 사용자 제어 우선

**AI에게 문의**는 보조 도구예요. 모든 광고 결정, 캠페인 시작, 계정 수준 작업은 사용자가 직접 통제해요. 사용자의 명시적인 승인 없이는 중요한 광고 작업이 실행되지 않아요.

## 광고 관리자에서 AI에게 문의 사용하기

다음 단계를 따라 **AI에게 문의**로 캠페인을 만들거나 관리하세요.

1. **AI에게 문의**를 열어요. 하이퍼클래스 계정의 기본 메뉴나 빠른 실행 메뉴에서 열 수 있어요.
2. 하고 싶은 광고 작업을 말하듯 입력해요. 예를 들어 "Meta 리드 생성 캠페인을 만들어 줘", "진행 중인 캠페인을 보여 줘", "내 웹사이트로 Google 검색 캠페인을 만들어 줘"처럼 입력해요.
3. **AI에게 문의**가 추가로 묻는 내용에 답해요. 캠페인을 만들 때는 예산, 타기팅 선호, 전환 목표, 소재 선택 등을 물어볼 수 있어요.
4. **AI에게 문의**가 보여 주는 캠페인 초안이나 작업 요약을 검토해요. 진행하기 전에 모든 설정, 타기팅 매개변수, 구성 내용을 확인하세요.
5. 안내가 나오면 명시적으로 승인해서 캠페인을 게시하거나 요청한 작업을 실행해요. 사용자의 확인 없이는 캠페인을 게시하거나 되돌리기 어려운 작업을 하지 않아요.
