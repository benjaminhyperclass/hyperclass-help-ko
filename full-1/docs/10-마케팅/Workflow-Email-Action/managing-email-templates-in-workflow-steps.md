# 워크플로우 이메일 템플릿 관리

저장해 둔 이메일 템플릿을 워크플로우의 이메일 단계에서 쓰는 방법을 안내해요. 템플릿을 쓰면 일관된 메시지를 여러 워크플로우에서 재사용하면서, 필요할 때는 워크플로우별로 내용을 고칠 수 있어요. **Send Email**(이메일 보내기) 액션에서 기존 템플릿을 쓰면 세 가지 중 하나를 고를 수 있어요.

- 워크플로우 이메일을 원본 템플릿과 별개로 유지해요.
- 원본 템플릿과 계속 동기화해요.
- **1회 동기화**로 한 번만 최신 내용으로 바꿔요.

이 문서에서 각 옵션을 안전하게 쓰는 방법을 설명해요.

## 워크플로우에서 쓰는 이메일 템플릿이란?

[**Send Email** 워크플로우 액션](../../07-워크플로우/Communication-Workflow-Actions/workflow-action-send-email.md)은 저장해 둔 이메일 템플릿을 자동 발송 메시지의 시작점으로 쓸 수 있어요. 승인된 레이아웃과 내용을 그대로 쓰면서, 특정 자동화에 맞게 워크플로우 이메일만 따로 고칠 수 있어요.

**Sync Edits to Template**(템플릿에 편집 내용 동기화) 설정에 따라 수정 내용이 독립적으로 남을지, 연결된 원본 템플릿과 계속 동기화될지 정해져요. 자세한 내용은 [워크플로우 이메일 액션의 템플릿 동기화 설정](../how-to-use-sync-edits-to-template-in-hyperclass-workflows.md)을 참고하세요.

## 워크플로우에서 이메일 템플릿을 관리하면 좋은 점

이메일 템플릿을 제대로 관리하면 승인된 내용을 재사용하면서, 어떤 수정은 해당 워크플로우에만 적용하고 어떤 수정은 공유 템플릿에 반영할지 구분할 수 있어요.

- 안전한 맞춤 수정: 지속 동기화를 끄면 워크플로우에만 해당하는 수정이 독립적으로 유지돼요.
- 콘텐츠 재사용: 저장한 템플릿 하나를 여러 워크플로우에서 쓸 수 있어요.
- 지속적인 동기화: 동기화를 켜면 워크플로우 이메일과 원본 템플릿이 항상 같은 내용으로 유지돼요.
- 선택적 업데이트: **1회 동기화**를 쓰면 지속 동기화를 켜지 않고도 원하는 워크플로우 이메일만 새로 고칠 수 있어요.

## 이메일 템플릿 동기화 방식

공유 템플릿을 쓰는 워크플로우 이메일을 고치기 전에 현재 **Sync Edits to Template** 설정부터 확인하세요.

| 설정 | 동작 |
| --- | --- |
| 동기화 켜짐 | 워크플로우 이메일을 고치면 원본 템플릿이 바뀔 수 있고, 원본 템플릿을 고치면 워크플로우 이메일이 바뀔 수 있어요. |
| 동기화 꺼짐 | 워크플로우 이메일과 원본 템플릿이 서로 독립적으로 유지돼요. 한쪽을 나중에 고쳐도 다른 쪽은 자동으로 바뀌지 않아요. |
| **1회 동기화** | 지속 동기화를 켜지 않고, 원본 템플릿의 현재 내용을 선택한 워크플로우 이메일에 한 번만 복사해요. |

기존 템플릿으로 새로 만든 **Send Email** 액션은 기본적으로 지속 동기화가 꺼져 있어요. 이미 만들어 둔 액션은 설정이 다를 수 있어요.

지속 동기화를 켜려면 **Sync Edits to Template**을 선택하고 **Turn On Sync**(동기화 켜기)로 확인하세요. 끄려면 체크박스를 해제하고 **Turn Off Sync**(동기화 끄기)로 확인하세요. 설정을 바꾼 뒤에는 이메일 액션을 저장하세요.

{% hint style="warning" %}
**Sync Edits to Template**이 켜져 있으면 워크플로우 이메일을 고칠 때 공유 원본 템플릿도 바뀔 수 있어요. 재사용 템플릿을 쓰는 이메일을 수정하기 전에 동기화 설정을 먼저 확인하세요.
{% endhint %}

## 워크플로우에서 템플릿 사용하고 편집하기

**Send Email** 액션에서 기존 템플릿을 추가한 뒤, 수정 내용을 해당 워크플로우에만 적용할지 재사용 원본 템플릿과 동기화할지 정하세요.

1. **자동화 > 워크플로우**로 이동해 워크플로우를 열거나 새로 만드세요. (워크플로우 편집 화면은 [워크플로우 빌더 둘러보기](../../07-워크플로우/기타/workflow-builder-walkthrough.md)를 참고하세요.)
2. **Send Email** 액션을 추가하거나 편집하세요.
3. 보내는 사람 정보를 설정하세요. **From Name**(보내는 사람)과 **From Email**(보내는 이메일)을 입력해요.
4. **Select Existing Template**(기존 템플릿 선택)을 선택하고 사용할 저장된 템플릿을 고르세요.
5. **Sync Edits to Template** 설정을 확인하세요.
6. 이 워크플로우 이메일만 수정하려면 동기화를 끈 상태로 두고, 템플릿 미리보기에서 제공하는 편집 옵션을 사용하세요.
7. 재사용 템플릿과 수정 내용을 계속 맞추려면 동기화를 켜고 **Turn On Sync**로 확인하세요.

![Send Email 워크플로우 액션에서 기존 이메일 템플릿을 선택한 화면과 Sync Edits to Template 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058570516/original/GfPYykLPV6LC4NnPr0-u9Bl5y5yLyCMuyA.png?1763394673)

재사용 원본 템플릿을 직접 고치려면 **마케팅 > 이메일 > 템플릿**으로 이동해 해당 템플릿을 열고 그곳에서 수정하세요. 템플릿 편집 방법은 [이메일 템플릿 편집하기](../Templates/how-to-edit-an-email-template.md)에서 볼 수 있어요.

## 수정한 이메일을 새 템플릿으로 저장하기

워크플로우 이메일을 수정한 뒤 그 버전을 다른 곳에서도 쓰고 싶다면, 원본을 덮어쓰지 말고 별도의 템플릿으로 저장하세요.

{% hint style="warning" %}
별도 템플릿으로 저장할 이메일을 수정하기 전에 **Sync Edits to Template**이 꺼져 있는지 확인하세요. 그래야 수정 내용이 원본 템플릿에 실수로 반영되지 않아요.
{% endhint %}

1. 이메일 편집기에서 워크플로우 이메일을 여세요.
2. **Sync Edits to Template**이 꺼져 있는지 확인하세요.
3. 필요에 맞게 내용을 수정하세요.
4. 이메일을 새 템플릿으로 저장하는 옵션을 선택하세요.
5. 이름을 입력하고 저장을 마치세요.
6. **마케팅 > 이메일 > 템플릿**에서 새 템플릿을 확인하세요.

![수정한 워크플로우 이메일을 새 템플릿으로 저장하는 이메일 편집기 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083361919/original/jwAcTOXw40YenVL4RkXcYCA-vkygyh2nOg.png?1792035124)

새 재사용 템플릿으로 저장하는 것과 현재 워크플로우 이메일의 변경 사항을 저장하는 것은 서로 달라요.

## 1회 동기화 사용하기

지속 동기화를 켜지 않고, 원본 템플릿의 최신 내용을 선택한 워크플로우 이메일에만 적용하고 싶을 때 **1회 동기화**를 쓰세요.

1. **마케팅 > 이메일 > 템플릿**으로 이동하세요.
2. 원본 템플릿을 찾으세요.
3. 템플릿의 점 세 개 메뉴(…)를 열고 **변경 사항 동기화**를 선택하세요.
4. 연결된 워크플로우 이메일 액션과 각 액션의 **지속 동기화** 상태를 확인하세요.
5. 지속 동기화가 꺼져 있는 액션 중 적용할 액션을 선택하세요.
6. **1회 동기화**를 클릭하세요.
7. 업데이트된 워크플로우 이메일 액션을 확인하세요.

![연결된 워크플로우 이메일 액션과 1회 동기화 옵션이 보이는 변경 사항 동기화 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083362005/original/V6EsxlJ99aKe-OmgU8706CjNTd7PQkUaEQ.png?1792035428)

{% hint style="warning" %}
**1회 동기화**는 원본 템플릿의 현재 내용을 선택한 워크플로우 이메일에 적용해요. 이때 워크플로우에만 적용해 둔 수정 내용이 바뀔 수 있어요. 동기화하기 전에 두 버전을 모두 확인하세요.
{% endhint %}

## 워크플로우 이메일 테스트하고 저장하기

워크플로우를 게시하기 전에 테스트 이메일을 보내 최종 내용, 서식, 개인화 항목, 링크, 보내는 사람 정보를 확인하세요.

1. 해당 **Send Email** 액션을 여세요.
2. **Test Emails**(테스트 이메일)에 주소를 하나 이상 입력하세요.
3. **Send Test Mail**(테스트 메일 보내기)을 클릭하세요.
4. 받은 메시지를 확인하고 고칠 부분이 있으면 수정하세요.
5. **Save Action**(액션 저장)을 클릭하세요.
6. 자동화 준비가 끝나면 워크플로우를 저장하고 게시하세요.

![워크플로우 이메일 액션의 Test Emails 입력란과 Send Test Mail 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083362080/original/-kz1FgyusbiJUaBvjxBHNtnW5AL4bCC8UQ.png?1792035746)

{% hint style="info" %}
**Save Action**은 **Send Email** 액션 설정만 저장해요. 초안 상태의 워크플로우를 자동으로 게시하지는 않아요.
{% endhint %}

## 자주 묻는 질문

### 같은 템플릿을 쓰는 워크플로우 이메일끼리 동기화 설정이 달라도 되나요?

네. 워크플로우 이메일 액션마다 지속 동기화 설정을 따로 가질 수 있어요. 이메일을 고치기 전에 현재 **Sync Edits to Template** 상태를 확인하세요.

### 1회 동기화를 쓰기 전에 무엇을 확인해야 하나요?

먼저 원본 템플릿과 선택한 워크플로우 이메일을 비교해 보세요. **1회 동기화**는 원본 템플릿의 현재 내용을 적용하기 때문에 워크플로우에만 적용해 둔 수정 내용이 바뀔 수 있어요.

### 템플릿에 연결된 워크플로우 이메일 액션을 볼 수 있나요?

네. 템플릿의 **변경 사항 동기화** 창을 열면 연결된 워크플로우 이메일 액션과 각각의 지속 동기화 상태를 확인할 수 있어요.

### 재사용 원본 템플릿을 업데이트하려면 어디에서 수정하나요?

**마케팅 > 이메일 > 템플릿**으로 이동해 저장된 원본 템플릿을 그곳에서 수정하세요. 지속 동기화가 켜져 있는 워크플로우 이메일은 이 수정 내용을 그대로 받을 수 있다는 점을 기억하세요.

### Save Action을 누르면 워크플로우가 게시되나요?

아니요. **Save Action**은 이메일 액션 설정만 저장해요. 워크플로우를 실행할 준비가 되면 워크플로우를 따로 저장하고 게시하세요.
