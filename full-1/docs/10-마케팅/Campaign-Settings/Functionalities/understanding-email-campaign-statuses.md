# 이메일 캠페인 상태 이해하기

**이메일 마케팅**(Email Marketing)에서는 캠페인 상태를 보고 이메일 발송의 진행 상황과 성과를 확인할 수 있어요. **이메일 캠페인**, **Workflow Campaigns**(워크플로우 캠페인), **Bulk Action Campaigns**(일괄 작업 캠페인)마다 상태 표시가 따로 있어요. 이 표시로 캠페인이 초안인지, 진행 중인지, 발송됐는지, 완료됐는지 바로 알 수 있어요.

## 이메일 캠페인 상태란?

이메일 캠페인 상태는 이메일 캠페인이나 발송 작업이 지금 어느 단계에 있는지 보여 주는 표시예요. 하이퍼클래스는 이메일 캠페인, 워크플로우 캠페인, 일괄 작업 캠페인마다 다른 상태를 제공해요.

상태를 알면 준비 중인 캠페인, 처리 중인 캠페인, 완료된 캠페인, 중단된 캠페인을 구분할 수 있어요.

일반 이메일 캠페인을 보내든, 워크플로우로 자동 이메일을 보내든, 일괄 작업을 쓰든, 상태를 보면 이메일에 어떤 일이 일어나고 있는지, 언제 조치가 필요한지 파악할 수 있어요.

---

## 이메일 캠페인 상태

이메일 캠페인은 **마케팅 > 이메일 > 캠페인**에서 만들고 관리하는 이메일이에요. 상태를 보면 캠페인이 준비, 예약, 발송 중 어느 단계인지 알 수 있어요.

![이메일 캠페인 상태 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083869177/original/J8FvCv6pc0J7E57xcN6B_rXLvqEwUY_sXA.png?1792587972)

| 상태 | 설명 |
| --- | --- |
| **Draft**(초안) | 캠페인을 만들었지만 아직 예약하거나 발송하지 않았어요. |
| **Scheduled**(예약됨) | 앞으로 정해진 날짜나 시간에 발송되도록 설정된 캠페인이에요. |
| **Paused**(일시중지됨) | 예약된 캠페인을 잠시 멈춘 상태예요. 다시 시작할 수 있어요. |
| **Canceled**(취소됨) | 예약된 캠페인을 중단한 상태예요. 다시 시작할 수 없어요. |
| **Sent**(발송됨) | 캠페인의 발송 과정이 끝났어요. 모든 수신자에게 전달됐다는 뜻은 아니에요. |
| **Failed**(실패) | 오류나 설정 문제로 캠페인을 보내지 못했어요. |
| **Archived**(보관됨) | 캠페인을 삭제하지 않고 보관해서 활성 목록에서 숨긴 상태예요. |

{% hint style="info" %}
**All**(전체) 필터는 모든 상태의 캠페인을 한꺼번에 보여 줘요. 별도의 캠페인 상태가 아니에요. 사용할 수 있는 상태와 작업은 캠페인 유형과 발송 방식에 따라 달라질 수 있어요.
{% endhint %}

예약된 캠페인을 관리하려면 [예약된 이메일 캠페인 일시중지, 재개, 취소하기](how-to-pause-or-cancel-a-scheduled-email-campaign.md)를 참고하세요.

## 워크플로우 캠페인 상태

워크플로우 캠페인은 워크플로우 액션으로 보내는 자동 이메일이에요. 이 캠페인의 게시 상태는 연결된 자동화가 초안인지 게시됐는지를 나타내요. 이메일 한 통 한 통이 전달됐는지를 나타내는 것은 아니에요.

| 상태 | 설명 |
| --- | --- |
| **Draft**(초안) | 워크플로우를 게시하지 않아서 활성화되지 않은 상태예요. |
| **Published**(게시됨) | 워크플로우가 게시되어, 설정한 트리거와 조건에 따라 실행될 수 있어요. |

![워크플로우 캠페인 상태 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083869647/original/fBAe8SA57c6Oh5XAF6tqxrAtwwFu7ggmOw.gif?1792588115)

{% hint style="info" %}
**Published**는 워크플로우 이메일이 모두 발송됐거나 전달됐다는 뜻이 아니에요. 이메일별 성과는 워크플로우 이메일 통계에서 확인할 수 있어요.
{% endhint %}

## 일괄 작업 캠페인 상태

일괄 작업 캠페인은 **연락처 > 일괄 작업**으로 선택한 연락처에게 보내는 이메일이에요. 상태를 보면 일괄 이메일 작업이 대기 중인지, 진행 중인지, 중단됐는지, 완료됐는지 알 수 있어요.

| 상태 | 설명 |
| --- | --- |
| **Draft**(초안) | 일괄 캠페인을 아직 발송용으로 제출하지 않았어요. |
| **Queued**(대기 중) | 작업이 처리되기를 기다리고 있어요. |
| **Processing**(처리 중) | 일괄 작업이 이메일을 처리하고 있어요. |
| **Paused**(일시중지됨) | 작업을 잠시 멈춘 상태예요. 다시 시작할 수 있는지는 작업에서 제공하는 제어 기능에 따라 달라요. |
| **Complete**(완료) | 일괄 작업의 처리가 끝났어요. 개별 이메일은 전달에 실패했을 수 있어요. |
| **Cancelled**(취소됨) | 작업이 완료되기 전에 중단됐어요. 이미 처리된 이메일은 되돌릴 수 없어요. |

{% hint style="info" %}
사용할 수 있는 작업은 일괄 작업의 유형과 현재 상태에 따라 달라요. 일시중지, 재개, 취소를 하기 전에 해당 작업에서 쓸 수 있는 제어 기능을 먼저 확인하세요.
{% endhint %}

![일괄 작업 캠페인 상태 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083869910/original/Q41w6_pWT8javJlIYsGooAR5CsG4jpgpHA.png?1792588230)

## 자주 묻는 질문

### **Sent** 또는 **Complete** 상태이면 모든 수신자가 이메일을 받았다는 뜻인가요?

아니에요. 이 상태는 발송이나 처리가 끝났다는 뜻이에요. 실제 전달 결과는 **Email Statistics**(이메일 통계)에서 전달, 반송, 실패 지표를 확인하세요.

### 취소된 이메일 캠페인을 다시 시작할 수 있나요?

아니요. 취소된 예약 캠페인은 다시 시작할 수 없어요. 일시중지된 예약 캠페인은 다시 시작할 수 있어요.

### 워크플로우가 **Published** 상태인데 이메일이 발송되지 않아요

게시된 워크플로우는 연락처가 설정한 트리거와 조건을 충족할 때만 이메일을 보내요. 워크플로우의 등록 활동과 이메일 액션을 확인해 보세요.

### 예약한 캠페인을 수정할 수 있나요?

수정할 수 있는 옵션은 캠페인의 현재 상태에 따라 달라요. 변경하기 전에 사용할 수 있는 캠페인 작업을 먼저 확인하세요.

### 일괄 이메일 발송이 실패한 이유는 어디에서 확인하나요?

**연락처 > 일괄 작업**으로 이동해 해당 작업을 찾은 뒤 **통계 보기**를 선택하세요. 확인할 수 있는 오류 정보와 처리 결과를 살펴보세요.
