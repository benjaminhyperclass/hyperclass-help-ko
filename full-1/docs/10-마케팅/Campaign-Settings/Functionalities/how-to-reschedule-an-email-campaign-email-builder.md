# 이메일 캠페인 일정 변경하기 (이메일 빌더)

아직 발송되지 않은 이메일 캠페인의 발송 날짜나 시간을 바꾸는 방법을 알려 드려요. 새 캠페인을 만들지 않고 기존 캠페인의 일정만 수정할 수 있어요. 하이퍼클래스에서는 **Simple Schedule**(단순 일정), **배치 일정**, **RSS Schedule**(RSS 일정) 캠페인의 일정을 바꿀 수 있어요.

```
요약: 일정이 잡혀 있고 아직 발송되지 않은 캠페인이라면, 마케팅 > 이메일 > 캠페인 > 이메일 캠페인으로 이동해 캠페인의 작업 메뉴를 열고 일정 변경을 선택하세요. 일정을 수정한 뒤 저장을 클릭하고, 이어서 일정을 클릭해 일괄 작업을 만드세요. 예정된 발송 시간보다 최소 60분 전에 완료해야 해요.
```

## 이메일 캠페인 일정 변경이란?

아직 발송되지 않은 캠페인의 예정 발송 날짜나 시간을 바꾸는 기능이에요. **이메일 캠페인** 페이지에서 바로 일정 변경을 선택할 수도 있고, 캠페인을 편집하다가 일정 설정 단계로 돌아갈 수도 있어요.

일정 변경은 다음 캠페인에서 쓸 수 있어요.

- **Simple Schedule** 캠페인
- **배치 일정** 캠페인
- **RSS Schedule** 캠페인

## 일정 변경이 도움이 되는 경우

처음 정한 발송 시간이 더는 맞지 않을 때 예정된 캠페인을 직접 조정할 수 있어요.

- 예정된 발송 바꾸기: 예정된 캠페인을 다른 미래의 날짜나 시간으로 옮길 수 있어요.
- 기존 캠페인 유지하기: 대체할 캠페인을 새로 만들지 않고 발송 일정만 조정할 수 있어요.
- 일정 화면으로 바로 이동하기: 캠페인의 작업 메뉴에서 일정 설정 단계를 바로 열 수 있어요.

## 시작하기 전에 확인하세요

일정을 변경하기 전에 캠페인이 아직 예약 상태인지, 발송 시간까지 충분한 시간이 남았는지 확인하세요.

- 캠페인에 이미 일정이 잡혀 있어야 작업 메뉴에 **일정 변경**이 나타나요.
- 캠페인 실행 시간보다 최소 60분 전에 일정 변경을 끝내세요.
- 시스템이 변경된 일정을 처리할 시간이 필요해요. 발송 직전의 일정 변경에 기대지 마세요.

{% hint style="warning" %}
**저장**만 클릭해서는 일정 변경이 끝나지 않아요. 변경된 일정에 맞는 새 일괄 작업이 만들어지도록 **일정**도 반드시 클릭하세요.
{% endhint %}

## 이메일 캠페인 일정 변경하기

이미 일정이 잡힌 캠페인의 발송 일정을 바꿀 때는 **이메일 캠페인** 페이지를 사용하세요.

1. 서브 계정 화면의 왼쪽 메뉴에서 **마케팅**을 선택하세요.
2. **이메일**을 선택하세요.
3. **캠페인**을 선택하세요.
4. **이메일 캠페인**을 여세요.
5. 일정을 바꾸려는 캠페인을 찾으세요.
6. 해당 캠페인의 작업 메뉴를 여세요.
7. **일정 변경**을 선택하세요.

![이메일 캠페인 작업 메뉴에서 일정 변경 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082416312/original/j-Z0FCXafkVC8ux8J50u38-xMm6BIJ22iQ.png?1790962842)

8. 캠페인 편집 화면이 일정 설정 단계로 바로 열려요.
9. 필요에 맞게 캠페인 일정을 수정하세요.

![캠페인 일정 수정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082416725/original/99lyKcxm_2UEs56P3O9Km-ZGRhwmaUC1fw.png?1790963240)

10. **저장**을 클릭해 변경 내용을 저장하세요.
11. **일정**을 클릭해 일정 변경을 마치고 새 일괄 작업을 만드세요.

![일정 버튼으로 일정 변경 완료](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082416807/original/6WtDEKBKXTky_n39l9pCqGb2-B8oOKXNCw.png?1790963298)

{% hint style="warning" %}
**저장**을 클릭한 뒤에 멈추지 마세요. 변경 내용은 저장되어도, **일정**까지 클릭해야 새 일괄 작업이 만들어져요.
{% endhint %}

## 캠페인 편집 화면에서 일정 변경하기

이미 캠페인을 편집하고 있다면 **이메일 캠페인** 목록으로 돌아가지 않고 일정 설정으로 바로 갈 수 있어요.

1. 캠페인 편집 화면에서 **Send or Schedule**(보내기 또는 일정 설정)을 클릭하세요.
2. 캠페인의 일정 설정을 수정하세요.
3. **저장**을 클릭하세요.
4. **일정**을 클릭해 일정 변경을 마치고 새 일괄 작업을 만드세요.

캠페인 실행 시간보다 최소 60분 전에 변경을 끝내고, 시스템이 변경된 일정을 처리할 시간을 충분히 두세요.

## 자주 묻는 질문

### 발송 시간 얼마 전까지 이메일 캠페인 일정을 변경할 수 있나요?
캠페인 실행 시간보다 최소 60분 전에 일정 변경을 끝내야 해요. 시스템이 변경된 일정을 처리할 시간이 필요하니 마지막 순간까지 미루지 마세요.

### 저장을 클릭했는데 새 일정이 적용되지 않아요.
**저장**은 변경 내용을 보관할 뿐, 일정 변경을 마무리하지는 않아요. 저장한 뒤에 **일정**을 클릭해야 변경된 일정에 맞는 새 일괄 작업이 만들어져요.

### 캠페인을 편집하는 중에도 일정을 변경할 수 있나요?
네, 가능해요. 캠페인 편집 화면에서 **Send or Schedule**을 클릭하고 일정 설정을 수정한 다음, **저장**과 **일정**을 차례로 클릭하세요.

### 어떤 유형의 예약 캠페인에서 일정을 변경할 수 있나요?
**Simple Schedule**, **배치 일정**, **RSS Schedule** 캠페인에서 일정 변경을 지원해요.
