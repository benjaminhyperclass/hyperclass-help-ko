# 광고 관리자에서 템플릿으로 광고 캠페인 만들기

**광고 관리자**(Ad Manager) 템플릿을 쓰면 Google, Meta, LinkedIn 캠페인을 처음부터 만들지 않고, 저장해 둔 캠페인 구성으로 시작할 수 있어요. 템플릿을 둘러보고, 미리 보고, 새 캠페인에 적용한 뒤 게시하기 전에 지원되는 설정을 바꿀 수 있어요.

이미 만든 광고 관리자 캠페인 중 지원되는 캠페인은 **템플릿 라이브러리**에 업로드해서 다시 쓸 수도 있어요. 이 문서에서는 광고 관리자 템플릿을 쓰는 방법과, 조건에 맞는 캠페인을 재사용 템플릿으로 만드는 방법을 안내해요.

## 광고 관리자 템플릿이란?

광고 관리자 템플릿은 하이퍼클래스의 **템플릿 라이브러리**에서 쓸 수 있는, 재사용 가능한 캠페인 구성이에요. 지원되는 템플릿으로 Google, Meta, LinkedIn 캠페인을 시작하면 캠페인 설정을 하나하나 다시 만들지 않아도 돼요.

템플릿을 적용한 뒤에는 캠페인을 검토하고 광고 문구, 크리에이티브, URL, 타기팅, 계정별 선택 항목, 그 밖에 광고 플랫폼에서 요구하는 설정을 업데이트하세요.

템플릿이 모든 캠페인 설정을 그대로 옮겨 주는 것은 아니에요. 어떤 내용이 템플릿에 담기는지는 플랫폼, 캠페인 유형, 지원되는 구성에 따라 달라요.

## 템플릿 라이브러리에서 광고 관리자는 어디에 있나요?

**Agency View**(에이전시 보기)에서 **템플릿 라이브러리 > 광고 관리자**로 이동하면 Google, Meta, LinkedIn 등 지원되는 광고 플랫폼의 템플릿을 볼 수 있어요.

현재 사용할 수 있는 필터는 다음과 같아요.

- **카테고리**
- **Objectives**(목표)
  - **Engagement**(참여)
  - **리드 생성**
  - **Sales**(판매)
  - **Web Traffic**(웹 트래픽)
- **태그**

![템플릿 라이브러리의 광고 관리자 템플릿 목록과 필터](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079537243/original/-6kCsfPluSCblCGWln0fOy33qXnSOqlY4w.png?1787914997)

## 광고 관리자 템플릿의 장점

광고 관리자 템플릿을 쓰면 캠페인 구성을 재사용하면서도, 게시하기 전에 캠페인별로 필요한 내용을 바꿀 수 있어요.

- 빠른 설정: 기존 캠페인 구조로 시작하므로 지원되는 설정을 하나하나 직접 구성하지 않아도 돼요.
- 재사용 가능한 캠페인 구조: 지원되는 템플릿 구성을 조건에 맞는 Google, Meta, LinkedIn 캠페인에 적용할 수 있어요.
- 템플릿 필터링: 카테고리, 목표, 태그로 알맞은 템플릿을 찾을 수 있어요.
- 사용 전 미리보기: 템플릿을 적용하기 전에 템플릿 상세 정보와 지원되는 게재 위치별 미리보기를 확인할 수 있어요.
- 사용자 지정: 게시하기 전에 캠페인 문구, 크리에이티브, URL, 타기팅 등 지원되는 설정을 바꿀 수 있어요.
- 에이전시 일관성: 조건에 맞는 **서브 계정**이 **템플릿 라이브러리**에서 쓸 수 있는 재사용 템플릿을 만들 수 있어요.

## 템플릿으로 광고 캠페인 만들기

템플릿 라이브러리에 있는 광고 관리자 템플릿으로 캠페인을 만드는 순서예요.

### 1단계: 광고 관리자 열기

1. 서브 계정 화면에서 **마케팅**을 선택하세요.
2. **광고 관리자**를 선택하세요.
3. **+ 캠페인 만들기**를 클릭하세요.

### 2단계: 광고 플랫폼 선택

1. Google, Meta, LinkedIn 중 하나를 선택하세요.
2. **다음**을 클릭하세요.

![광고 플랫폼 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079537716/original/UePImnvc6_9GuMkJCEOSlqwBveuEhnEs6w.png?1787915277)

### 3단계: 광고 관리자 템플릿 선택

1. **Choose how you want to start creating the campaign**(캠페인을 어떻게 시작할지 선택) 화면에서 **광고 관리자 템플릿**을 선택하세요.
2. **다음**을 클릭하세요.

{% hint style="info" %}
서브 계정의 템플릿 라이브러리 접근이 제한되어 있으면 서브 계정 사용자에게는 **광고 관리자 템플릿**이 보이지 않아요. 이 경우 광고 플랫폼을 선택한 뒤 바로 **처음부터 만들기**로 이어져요.
{% endhint %}

![캠페인 시작 방법 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081754154/original/X5s7tRXQ-FNWPDZsboN-nGyW_e2hvXIw6Q.png?1790249777)

### 4단계: 템플릿 찾고 미리보기

1. 사용할 수 있는 템플릿을 둘러보세요.
2. 필요하면 **카테고리**, **Objectives**(목표), **태그**로 결과를 좁히세요.
3. 눈 모양 아이콘을 클릭하면 지원되는 게재 위치에서 템플릿이 어떻게 보이는지 미리 볼 수 있어요.
4. 템플릿을 선택해 미리보기와 상세 정보를 확인하세요.
5. 선택한 템플릿을 쓰려면 **계속**을 클릭하세요.

![템플릿 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033403727/original/gJSt4hxJtApLJ0IgM--L3zEAAzk9-Le9Iw.png?1727120613)

템플릿 중 하나를 선택하면 미리보기가 나타나요. **계속**을 클릭하면 템플릿을 적용하는 과정이 시작돼요.

![선택한 템플릿 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033403812/original/0zqfUZ2Fm15S5_kxb0Q7YtVL2ElEAHhokg.png?1727120756)
![템플릿 적용 진행 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033403863/original/03qGyK7b9S2oqVluV3vc-kUY5G6z8dPBZw.png?1727120850)

{% hint style="info" %}
템플릿으로 캠페인을 만들면 아래 항목이 캠페인에 연결되지 않아요. 캠페인을 게시하기 전에 직접 입력해야 해요.

1. 새로 만든 캠페인에는 연결된 페이지가 없어요. 캠페인을 편집하면 기본 페이지로 설정된 페이지가 이 캠페인에 지정되고, 원하면 바꿀 수 있어요.
2. 캠페인에 지정된 페이지가 없으므로, 목표가 **리드 생성**일 때 쓸 폼을 직접 선택해야 해요.
{% endhint %}

## 기존 캠페인으로 템플릿 만들기

성과가 특히 좋아서 이후 캠페인을 만들 때 템플릿으로 저장해 두고 싶은 캠페인이 있을 수 있어요. 다른 서브 계정의 사용자도 이 캠페인 형식을 쓰게 하고 싶을 때도 있고요. 이럴 때 아래 순서로 캠페인을 템플릿으로 만들 수 있어요.

{% hint style="info" %}
기존 LinkedIn 캠페인은 **템플릿 라이브러리**에 업로드해서 여러 계정에서 다시 쓸 수 있어요.
캠페인 목록에서 LinkedIn 캠페인을 찾아 점 세 개(⋮) 메뉴를 열고 **Upload to Template Library**(템플릿 라이브러리에 업로드)를 선택하세요. 템플릿 이름과 카테고리를 입력한 뒤 **업로드**를 클릭하면 돼요.

템플릿은 초안으로 저장돼요. 템플릿을 편집하거나, 초안 상태로 두거나, 재사용할 수 있도록 게시할 수 있어요.
{% endhint %}

{% hint style="info" %}
Google Demand Gen 캠페인도 다른 지원 캠페인 유형과 같은 **템플릿 라이브러리** 업로드 과정을 따라요. 업로드한 캠페인은 게시하기 전까지 초안 템플릿으로 만들어져요.
{% endhint %}

{% hint style="info" %}
아래 템플릿 작업 과정은 **템플릿 라이브러리** 접근 권한이 있는 사용자만 쓸 수 있어요. 접근이 제한된 서브 계정 사용자에게는 **광고 관리자 템플릿**이 보이지 않아요. 이 사용자는 광고 플랫폼을 선택한 뒤 **처음부터 만들기**로 바로 캠페인 빌더로 이동해요.
{% endhint %}

1. 기존 캠페인 목록에서 템플릿으로 쓸 캠페인의 점 세 개(⋮) 메뉴를 클릭하고 **Upload to Template Library**(템플릿 라이브러리에 업로드)를 선택하세요.

   ![캠페인 점 세 개 메뉴에서 템플릿 라이브러리에 업로드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033404707/original/0HH9mr8LFFvBtCGSc6O6IjwlIpWgmgFwbQ.png?1727122599)
2. 대화상자가 열리면 템플릿 이름을 입력하고, 이 템플릿이 속할 카테고리를 선택하세요. 카테고리는 템플릿을 구분하는 데 중요해요. 원하는 카테고리가 없으면 **Template Library settings**(템플릿 라이브러리 설정)에서 만들 수 있어요.

   ![템플릿 이름과 카테고리 입력 대화상자](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033404749/original/jVF-wgZopFCtmNJH9C045Y-ZktDkzbd_TA.png?1727122710)
3. **업로드**를 클릭하면 캠페인이 초안 템플릿으로 저장돼요.
4. **업로드**를 클릭하면 초안 템플릿 화면이 열려요. 필요하면 내용을 수정한 뒤 초안으로 저장하거나 템플릿으로 게시할 수 있어요.

   ![초안 템플릿 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033404765/original/eqMR3T2bKpP8_bCEdaapLKQxJVWPDNnjng.png?1727122770)

{% hint style="info" %}
**에이전시 관리자** 화면에서 템플릿을 만들고 관리하는 방법은 「How to Manage and Create Templates from the Admin Screen」 도움말을 참고하세요.
{% endhint %}

## 자주 묻는 질문

### 어떤 광고 플랫폼에서 광고 관리자 템플릿을 쓸 수 있나요?
현재 광고 관리자 템플릿은 Google, Meta, LinkedIn을 지원해요.

### 캠페인을 만들 때 광고 관리자 템플릿은 어디에서 선택하나요?
서브 계정에서 **마케팅 > 광고 관리자 > + 캠페인 만들기**로 이동해 광고 플랫폼을 선택하고 **다음**을 클릭하세요. 그다음 **광고 관리자 템플릿**을 선택하면 돼요.

### 광고 관리자 템플릿이 보이지 않아요.
서브 계정의 템플릿 라이브러리 접근이 제한되어 있을 수 있어요. 접근이 제한되면 서브 계정 사용자는 템플릿 선택 단계를 건너뛰고 **처음부터 만들기**로 이어져요.

### 템플릿을 적용한 뒤에도 캠페인을 수정할 수 있나요?
네. 게시하기 전에 지원되는 캠페인 문구, 크리에이티브, URL, 타기팅 등 설정을 검토하고 업데이트할 수 있어요.

### 기존 광고 관리자 캠페인을 템플릿으로 업로드할 수 있나요?
지원되는 캠페인은 캠페인의 점 세 개 메뉴에 **Upload to Template Library**(템플릿 라이브러리에 업로드)가 나타나요. 캠페인이나 상품 유형에 따라 쓸 수 있는지가 다를 수 있어요.

### 캠페인을 템플릿 라이브러리에 업로드하면 어떻게 되나요?
업로드한 캠페인은 초안 템플릿으로 만들어져요. 조건에 맞는 **에이전시 관리자**가 내용을 검토한 뒤 초안으로 두거나, 준비가 되면 게시할 수 있어요.

### 템플릿이 캠페인 설정을 모두 복사하나요?
모든 설정이 옮겨진다고 생각하지 마세요. 템플릿으로 만든 캠페인을 게시하기 전에 계정별·플랫폼별 항목을 모두 검토하세요.
