# 브랜드 보드 만들기

브랜드 보드에는 회사의 로고, 색상 팔레트, 글꼴을 모아 두고 관리할 수 있어요. 한 번 정리해 두면 이메일, 퍼널, 웹사이트 등에 일관된 브랜딩을 적용할 수 있어요. 브랜드 보드는 처음부터 직접 만들 수도 있고, 템플릿을 고르거나 웹사이트 URL로 생성할 수도 있어요.

[동영상](https://www.youtube.com/embed/EbIZBfZ5Nrw?&wmode=opaque)

## 브랜드 보드란?

하이퍼클래스의 브랜드 보드는 브랜드의 시각적 아이덴티티를 한곳에서 정하고 관리하는 공간이에요. 브랜드 보드마다 디자인 키트가 하나씩 들어 있고, 디자인 키트에는 로고, 브랜드 색상, 타이포그래피 설정이 담겨요. 이렇게 설정해 두면 계정 곳곳에 같은 브랜드 스타일을 쉽게 적용할 수 있어요.

## 브랜드 보드의 장점

- 브랜드 일관성: 시각 요소를 한곳에 모아 두니 어디서나 같은 로고, 색상, 글꼴을 쓸 수 있어요. 웹사이트, 이메일, 소셜 미디어 어디에서든 브랜드가 똑같이 보여요.
- 시간 절약: 로고 파일을 찾아 헤매거나 브랜드 색상 코드를 떠올릴 필요 없이 필요한 요소를 바로 꺼내 쓸 수 있어요. 새 자료를 더 빠르고 간단하게 만들 수 있어요.
- 쉬운 관리: 로고, 색상, 글꼴을 빠르게 찾아 쓸 수 있어서 모든 자료를 브랜드에 맞게 유지하기 쉬워요.

## 브랜드 보드를 만드는 방법

브랜드에 대해 이미 정해 둔 내용이 얼마나 되는지에 따라 만드는 방법을 고를 수 있어요. 모든 요소를 직접 넣거나, 미리 준비된 스타일에서 시작하거나, 웹사이트 URL에서 브랜드 요소를 자동으로 가져와 빠르게 설정할 수 있어요.

- 빈 상태에서 시작해 로고, 색상, 글꼴을 직접 추가해요.
- 미리 준비된 템플릿을 시작점으로 골라요.
- 웹사이트나 랜딩 페이지 URL을 입력하면 이미 쓰고 있는 브랜드 요소로 브랜드 보드가 자동 생성돼요.

### 1단계: 새 디자인 키트 만들기

1. 왼쪽 메뉴에서 **마케팅**을 클릭하세요.
2. 상단 메뉴에서 **브랜드 보드**를 클릭하세요.
3. 파란색 **+ Add a Design Kit**(디자인 키트 추가) 버튼을 클릭하세요.

![디자인 키트 추가 버튼이 있는 브랜드 보드 화면](https://jumpshare.com/share/a1QzAjhN7S2Ci3NpiuFP+/Screen+Shot+2026-09-22+at+20.11.56.png)

### 2단계: 시작 방식 고르기

- 다음 중 하나를 선택하세요.

  - **빈 상태로 시작**
  - **템플릿 선택**
  - **Website URL import**(웹사이트 URL 가져오기)
- 웹사이트 URL 가져오기를 선택했다면 웹사이트나 랜딩 페이지 URL을 붙여 넣고 **브랜드 키트 가져오기**를 클릭하세요.

![시작 방식을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069535198/original/UkG6eedGk_uqEggjtHynuapI9cClCuNLDQ.png?1776700721)

### 3단계: 로고 추가하기

1. **로고** 탭을 클릭하세요.
2. 기본 로고와 보조 로고를 모두 업로드하세요.

![로고 탭에서 로고를 업로드하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031808815/original/3-ZbnX79zRSh0u54hry_3dxo87Vj6MbC3Q.png?1724842846)

### 4단계: 브랜드 색상 추가하기

1. **색상** 탭을 클릭하세요.
2. HEX 또는 RGB 색상 선택기로 브랜드 색상을 **추가**하세요.
3. 나중에 쉽게 찾을 수 있도록 각 색상의 **이름 변경**을 눌러 이름을 정하세요.
4. 색상은 최소 2개를 넣어야 하고, 최대 10개까지 추가할 수 있어요.

![색상 탭에서 브랜드 색상을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031803023/original/zfT8II7UQbeyo_TLgDwCdNZ15aXF8-cy0g.png?1724839684)

### 5단계: 글꼴 설정하기

1. **타이포그래피** 탭을 클릭하세요.
2. 드롭다운 필드에서 글꼴을 **추가**하세요.
3. 글꼴은 1개에서 5개까지 추가할 수 있어요.

![타이포그래피 탭에서 글꼴을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031803568/original/xp2G_W4VEmMk3sybFy9CYXnELxTuJ_Lx7g.png?1724839922)

이제 브랜드 보드가 완성됐어요. 브랜딩 요소가 깔끔하게 정리되어 있어서 브랜드의 분위기를 일관되게 유지하기 쉬워요. 이메일, 웹사이트, 퍼널에서 브랜드 보드를 쓰는 방법은 별도 도움말에서 확인할 수 있어요.

## 개발자 API

외부 도구에서 브랜드 보드를 만들거나 관리해야 한다면 개발자 포털의 브랜드 보드 공개 API를 사용할 수 있어요.

- Brand Boards API 개요
- 엔드포인트 목록(생성, 조회, 수정, 삭제)

API 문서 주소는 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 브랜드 보드의 색상을 바꾸면 이미 만든 이메일이나 퍼널의 색상도 바뀌나요?

아니요. 브랜드 보드의 색상을 바꿔도 이미 만든 이메일이나 퍼널의 색상은 바뀌지 않아요. 브랜드 보드의 색상 섹션은 빠르게 불러 쓰기 위한 곳이라서, 바꾼 색상은 앞으로 색상 선택기를 쓸 때만 반영돼요. 기존 디자인과 콘텐츠는 그대로 유지돼요.

### 브랜드 보드를 새 프로젝트의 기본값으로 정하려면 어떻게 하나요?

점 세 개 메뉴를 열고 **기본값으로 설정**을 클릭하세요.

### 웹사이트 URL로 가져오면 하이퍼클래스는 무엇을 가져오나요?

웹사이트 URL 가져오기는 입력한 페이지에서 로고, 색상, 타이포그래피 같은 시각적 브랜드 요소를 찾아 브랜드 보드를 생성하도록 돕는 기능이에요.

### 브랜드 보드를 나중에 수정할 수 있나요?

네. 브랜드 보드 옆의 점 세 개 메뉴를 열고 **편집**을 선택하세요.

### 브랜드 보드를 삭제할 수 있나요?

네. 점 세 개 메뉴를 열고 **삭제**를 선택하세요. 삭제하면 되돌릴 수 없으니 주의하세요.

### 디자인 키트에 추가할 수 있는 색상, 로고, 글꼴 수에 제한이 있나요?

브랜드 보드 하나에 글꼴 5개, 색상 10개, 로고 2개까지 추가할 수 있어요.

### 추가한 로고는 어디에서 볼 수 있나요?

미디어 라이브러리에 브랜드 보드 이름으로 된 폴더가 생겨요. 이 폴더에서 로고를 빠르게 찾아 쓸 수 있어요. 필요하면 미디어 라이브러리에서 예전 로고를 삭제해도 돼요.
