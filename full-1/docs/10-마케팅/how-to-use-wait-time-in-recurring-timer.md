# 카운트다운 타이머 — 반복 타이머에 대기 시간 설정하기

반복 카운트다운 타이머의 주기와 주기 사이에 원하는 대기 시간을 넣는 방법을 안내해요. "매주 금요일" 반짝 세일, 매주 웨비나 카운트다운, 매월 신상품 공개처럼 타이머가 끝날 때마다 새로 만들지 않아도 되는 반복 일정에 쓸 수 있어요.

## 반복 타이머의 사용자 지정 대기 시간이란?

사용자 지정 대기 시간을 설정하면 반복 타이머가 00 : 00 : 00에 도달한 뒤 정해 둔 시간 동안 멈췄다가 다음 주기를 자동으로 시작해요. 멈춰 있는 동안(대기 상태)에 퍼널에서는 타이머를 0으로 보이게 둘지, 아예 숨길지 고를 수 있어요. 이메일에서는 만료 페이지로 연결되는 0 상태 배너가 표시돼요.

## 사용자 지정 대기 시간의 장점

- "매주 금요일 세일"이나 주간 챌린지 같은 반복 프로모션을 자동으로 운영할 수 있어요.
- 매주 다음 세션까지 카운트다운하는 상시 웨비나를 운영할 수 있어요.
- 노출 여부를 조절할 수 있어요. 퍼널에서는 운영하지 않는 시간대에 타이머를 숨겨 페이지를 깔끔하게 유지하세요.
- 타이머를 복제하지 않고 하나의 타이머를 이메일과 퍼널에서 함께 쓸 수 있어요.
- 이메일과 페이지에서 0 상태 표시와 리디렉션 동작을 똑같이 맞출 수 있어요.

## 대기 시간이 있는 반복 타이머 설정하기

한 번만 설정하면 타이머가 매 주기를 알아서 관리해요.

1. **마케팅 > 카운트다운 타이머 > + 신규**로 이동해 새 타이머를 만드세요.

   ![신규 타이머 만들기 화면](https://jumpshare.com/share/vVN2qaPqMfjLghi21of3+/Screen+Shot+2026-09-22+at+19.28.03.png)
2. 타이머 템플릿을 선택하고 **Continue with this template**(이 템플릿으로 계속)을 클릭하세요.

   ![타이머 템플릿 선택 화면](https://jumpshare.com/share/GLfzBBLVwIuAt7H3QANk+/Screen+Shot+2026-09-22+at+19.29.27.png)
3. **Time Type**(시간 유형)에서 **반복**을 선택하세요.
4. **Start Offset**(시작 오프셋)과 **End Offset**(종료 오프셋)을 설정하세요.
5. **Loop Events**(반복 이벤트)에 주기가 반복되는 총 횟수를 입력하세요.
6. **Custom Wait Time**(사용자 지정 대기 시간)에 대기 시간을 입력하세요. 예: 5일 12시간
7. (선택) 대기하는 동안 퍼널에서 타이머를 숨기려면 **Hide Timer in Wait State**(대기 상태에서 타이머 숨기기)를 켜세요. 이 토글은 퍼널에만 적용돼요. 이메일은 항상 0 상태로 표시돼요.
8. **Expiry Page / URL**(만료 페이지 / URL)에서 방문자가 대기 중에 타이머를 클릭하거나 퍼널을 새로고침했을 때 보여 줄 페이지를 선택하세요.
9. **저장**을 클릭한 뒤 타이머 블록을 퍼널이나 이메일에 삽입하세요.

   ![타이머 블록을 삽입한 화면](https://jumpshare.com/share/R5UxLe8j9CEXDCH04ZYJ+/Screen+Shot+2026-09-22+at+19.32.59.png)

## 타이머 진행 과정

단계마다 연락처에게 무엇이 보이는지 알아 두면 흐름을 매끄럽게 설계할 수 있어요.

```
활성 주기 ─┐

           │ 00:00 도달

           ▼

     대기 상태 (사용자 지정 시간)

           │ 자동 재시작

           ▼

     다음 활성 주기 → … (반복)
```

| 상태 | 이메일 동작 | 퍼널 동작 |
| --- | --- | --- |
| 활성 | 실시간으로 줄어드는 카운트다운 | 실시간으로 줄어드는 카운트다운 |
| 대기 | 타이머에 00 : 00 : 00이 표시되고, 클릭하면 만료 페이지로 이동해요 | • 토글 설정에 따라 타이머가 숨겨지거나 00 : 00 : 00으로 표시돼요<br>• 대기 중에 페이지를 새로고침하면 만료 페이지로 이동해요 |
| 재시작 | 새 주기가 자동으로 시작돼요 | 새 주기가 자동으로 시작돼요 |

## 활용 예시

바로 적용해 볼 수 있는 설정 값이에요.

| 시나리오 | 시작 → 종료 | 대기 시간 | 결과 |
| --- | --- | --- | --- |
| 매주 금요일 세일 | 금 00:00 → 금 23:59 | 6일 1분 | 다음 금요일 자정에 타이머가 다시 시작돼요 |
| 주간 웨비나 | 월 09:00 → 목 17:00 | 3일 16시간 | 매주 월요일 아침에 카운트다운이 다시 시작돼요 |
| 월간 신상품 공개 | 1일 00:00 → 3일 23:59 | 27일 | 매월 1일부터 3일까지 진행돼요 |

## 알아 두면 좋은 동작과 팁

예외 상황의 동작을 미리 알아 두면 당황하지 않아요.

- 이메일의 0 상태는 스타일이 없는 "00 : 00 : 00"으로 표시돼요. 대기 중에는 사용자 지정 CSS나 스타일이 적용되지 않아요.
- **Hide Timer in Wait State** 토글은 퍼널에만 적용돼요. 이메일은 항상 0 상태로 표시돼요.
- 방문자가 새로고침 없이 활성 주기에서 대기 상태로 넘어가면, 퍼널 페이지에 그대로 머물러요. 자동으로 이동하지 않아요.
- 최대 대기 시간은 365일, 최소 대기 시간은 1분이에요.
- 대기가 시작되는 순간 분석에 **Timer Expired**(타이머 만료) 이벤트가 기록돼요. 이 이벤트로 프로모션 종료 후 자동화를 시작할 수 있어요.

## 자주 묻는 질문

### 대기 기간이 일광 절약 시간제(DST) 변경 시점을 지나도 되나요?

네, 괜찮아요. 타이머는 고정된 날짜가 아니라 기간을 저장해요. DST가 바뀌면 오프셋을 다시 계산해요.

### 나중에 대기 시간을 수정하면 어떻게 되나요?

새 대기 시간은 타이머가 다음에 대기 상태로 들어갈 때부터 적용돼요. 진행 중인 주기는 영향을 받지 않아요.

### 이메일의 0 상태에 스타일을 적용할 수 있나요?

아직은 안 돼요. 0 상태에는 수신율을 일정하게 유지하기 위해 기본 타이머 글꼴과 색상이 쓰여요.

### **Hide Timer in Wait State**를 꺼도 퍼널에서 리디렉션되나요?

네. 대기 중에 페이지를 새로고침하면 타이머가 보이든 안 보이든 항상 리디렉션돼요.

### 타이머 하나가 몇 번의 주기를 실행할 수 있나요?

제한이 없어요. 타이머를 보관하거나 삭제할 때까지 주기가 계속돼요. <!-- 검토 필요: 원문 내용이 서로 다름 --> (설정 단계에서는 **Loop Events**에 주기가 반복되는 총 횟수를 입력한다고 안내해요.)

### 캐시된 이메일에서 연락처마다 시간이 다르게 보이나요?

이메일 타이머는 열 때 실시간 데이터로 새로 고쳐져요. 캐시된 이미지는 서버에서 교체돼요.

### 반복이 아닌 타이머에도 대기 기간을 추가할 수 있나요?

아니요. 대기 시간은 **반복** 유형의 타이머에서만 쓸 수 있어요.
