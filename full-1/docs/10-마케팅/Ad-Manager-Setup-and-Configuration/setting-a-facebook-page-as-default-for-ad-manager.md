# Facebook 페이지를 광고 관리자 기본 페이지로 설정하기

**광고 관리자**(Ad Manager)에 연결된 Facebook 페이지 중 하나를 기본 페이지로 지정하는 방법을 안내해요. 기본 페이지는 새 광고 캠페인을 게시할 때 우선 선택되는 페이지예요.

[동영상](https://www.youtube.com/embed/W53eOJR5GcM?&wmode=opaque)

{% hint style="info" %}
캠페인을 만드는 과정에서 광고를 게시할 페이지를 직접 고를 수 있어요. 기본 페이지는 캠페인 빌더에서 처음부터 선택되어 있는 페이지일 뿐이라서, 필요할 때 언제든 다른 페이지로 바꿀 수 있어요.
{% endhint %}

---

## 연결된 Facebook 페이지를 기본값으로 설정하려면 어떻게 하나요?

**광고 관리자**에 연결된 Facebook 페이지는 모두 **광고 관리자 설정 > Pages** 탭에 표시돼요. **광고 관리자** 홈 오른쪽 위에 있는 톱니바퀴(설정) 버튼을 클릭하면 들어갈 수 있어요.

![광고 관리자 홈 화면의 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031780362/original/2T5jgX_6ZyoIKK2_28qaQhsSkInEsbFgrA.png?1724824290)

![광고 관리자 설정의 Pages 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031780463/original/xxu2GeoPT0r9vN6HPSKPMIdVDe0f0wx8Aw.png?1724824438)

연결된 Facebook 페이지는 어느 것이든 기본 페이지로 지정할 수 있어요. 각 페이지 행의 오른쪽 끝에 있는 점 세 개(⋯) 아이콘을 클릭하면 **기본값으로 설정** 버튼이 나타나요.

![페이지 행의 점 세 개 메뉴에 있는 기본값으로 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031780643/original/NZNWMjjFdKnHMS_hUaArAx9mOwo7QgqdJA.png?1724824702)

**기본값으로 설정**을 클릭하면 해당 페이지가 기본 페이지로 바뀌어요. 이전에 기본이던 페이지는 더 이상 새 광고 캠페인의 기본 게시 페이지가 아니에요.

기본 페이지를 설정할 때 알아 둘 점이에요.

1. 온보딩 과정에서 **광고 관리자**에 처음 연결한 Facebook 페이지가 기본 페이지가 돼요.
2. 기본으로 설정된 페이지의 연결을 삭제하면 다음 페이지가 자동으로 기본 페이지가 돼요.
3. 연결된 Facebook 페이지 중 기본 페이지는 하나만 지정할 수 있어요.

{% hint style="info" %}
캠페인을 만드는 과정에서 광고를 게시할 페이지를 직접 고를 수 있어요. 기본 페이지는 캠페인 빌더에서 처음부터 선택되어 있는 페이지일 뿐이라서, 필요할 때 언제든 다른 페이지로 바꿀 수 있어요.
{% endhint %}
