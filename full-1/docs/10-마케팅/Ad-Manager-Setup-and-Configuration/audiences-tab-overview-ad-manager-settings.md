# 오디언스 탭 살펴보기 - 광고 관리자 설정

**광고 관리자**(Ad Manager) 설정의 **오디언스** 탭에서 기존 사용자 지정·유사 타겟 오디언스를 찾고, 새 오디언스 만들기, 이름과 설명 편집, 삭제를 하는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/dzxnBv_FJuI?&wmode=opaque)

## 광고 관리자에서 오디언스 목록은 어디서 볼 수 있나요?

**광고 관리자** 홈에서 설정 아이콘(아래 스크린샷에서 강조된 아이콘)을 클릭하면 **광고 관리자 설정**으로 이동해요.

![광고 관리자 홈의 설정 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035978259/original/CAPm8iRNDuRFQLIovIC7dQ7dZkaF0zdpgQ.jpg?1730753002)

![광고 관리자 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035978306/original/KOe2_FWDcRwPjuWtxA9gRF99T2XYRaEo5w.jpg?1730753038)

**광고 관리자 설정**에는 **연동**, **페이지**, **전환**, **오디언스** 탭이 있고, 탭마다 담당하는 기능과 정보가 달라요. 이 문서에서는 **오디언스** 탭을 다뤄요.

**오디언스** 탭을 클릭하면 **광고 관리자**에서 만든 오디언스와, Meta에서 이미 만들어 연결된 광고 계정에서 가져온 오디언스를 한 목록에서 볼 수 있어요.

![오디언스 탭의 오디언스 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035978330/original/J-O8nEzQ6liiE_ZdV1gCX6qvWKNLqhfKxg.jpg?1730753084)

## 새 오디언스는 어떻게 만드나요?

유사 타겟 오디언스와 사용자 지정 오디언스는 두 가지 방법으로 만들 수 있어요.

1. 캠페인을 만드는 과정에서 사용자 지정·유사 타겟 오디언스를 만들 수 있어요. 자세한 방법은 [광고 관리자에서 유사 타겟 오디언스 만들기](../Ad-Campaign-Creation-and-Management/create-lookalike-audiences-in-ad-manager.md)와 [광고 관리자에서 사용자 지정 오디언스 만들기](../Ad-Campaign-Creation-and-Management/create-custom-audiences-in-ad-manager.md) 문서를 참고하세요.
2. **광고 관리자 설정** > **오디언스** 탭에서 **새 오디언스 만들기** 버튼을 클릭하면 **유사 타겟**과 **사용자 지정** 두 가지 옵션이 나와요. 둘 중 하나를 클릭하면 해당 오디언스를 만드는 과정이 시작돼요. 오디언스를 만들고 나면 아래 목록에 표시돼요. 자세한 단계는 1번에 안내한 문서를 참고하세요.

   ![새 오디언스 만들기 버튼과 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032740430/original/wyrtDpcE8JWcQZx8QvkpsHBdf01ZMtVdJA.png?1726135595)

## 기존 오디언스에는 어떤 작업을 할 수 있나요?

새 오디언스를 만드는 것 외에, 기존 오디언스에는 다음 작업을 할 수 있어요.

1. **search for audience**(오디언스 검색) 상자에 오디언스 이름을 입력하면 목록에서 원하는 오디언스를 찾을 수 있어요.
2. 검색 상자 옆 선택 상자에서 **전체**, **사용자 지정**, **유사 타겟**을 고를 수 있어요. 선택한 항목에 따라 목록에 보이는 오디언스가 달라져요.

   **전체** - 유형과 관계없이 **광고 관리자**에 있는 모든 오디언스를 보여 줘요.
   **사용자 지정** - **광고 관리자**에 있는 사용자 지정 오디언스만 보여 줘요.
   **유사 타겟** - **광고 관리자**에 있는 유사 타겟 오디언스만 보여 줘요.

   ![전체, 사용자 지정, 유사 타겟 필터 선택 상자](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032784474/original/VMTytMoat9ZGxkzFP6Rq9ObWNX3aKRCadw.png?1726163181)
3. 각 오디언스 줄에 있는 점 세 개(…) 아이콘을 클릭하고 **편집**을 클릭하면 기존 오디언스의 이름과 설명을 수정할 수 있어요.

   ![점 세 개 메뉴의 편집 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032784630/original/T2QxEyAGsj0NJGvXkeFiF1XIkKgfi2-eSQ.png?1726163467)

   - 대화상자가 나타나면 선택한 오디언스의 이름과 설명을 수정해요.

   ![오디언스 이름과 설명 편집 대화상자](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032784692/original/AmpWfxONa0fJrBpzibLKZM1gO2TawRr5fA.png?1726163565)

## 오디언스는 어떻게 삭제하나요?

각 오디언스 줄의 점 세 개(…) 메뉴에 **삭제** 옵션이 있어요. **삭제**를 클릭하면 초안 상태와 일시중지된 모든 캠페인에서 해당 오디언스가 제거돼요. 단, 활성 캠페인에 연결된 오디언스가 아니어야 해요.

![점 세 개 메뉴의 삭제 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032785180/original/-lM5NaElLyE2SbTvnizthA6h2vAcCgEATg.png?1726164316)

1. 활성 캠페인 하나 이상에 연결된 오디언스를 삭제하려고 하면, 활성 캠페인에 포함되어 있어 삭제할 수 없다는 안내 메시지가 나타나요.

   ![활성 캠페인에 연결된 오디언스 삭제 시 안내 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032785790/original/Qcbt7HgUZ5a4l5mXrajXzGISTOV6pIuiVA.png?1726165337)

   {% hint style="info" %}
   오디언스를 삭제하려면 그 오디언스에 연결된 활성 캠페인을 먼저 모두 일시중지해야 해요.
   {% endhint %}

2. 유사 타겟 오디언스를 만드는 데 사용한 사용자 지정 오디언스를 삭제하려고 하면 오류 메시지가 나타나요. 연결된 유사 타겟 오디언스를 먼저 삭제해야 삭제할 수 있어요.

   ![유사 타겟 오디언스에 사용된 사용자 지정 오디언스 삭제 시 오류 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032806025/original/f0NXTcOFTImTgPb8HLulRjiSRgJlSwGgQw.png?1726214415)

## 자주 묻는 질문

### 만들 수 있는 오디언스 개수에 제한이 있나요?
따로 안내된 제한은 없어요. 다만 오디언스 목록을 잘 정리해 두면 관리하고 활용하기 좋아요. 오디언스가 너무 많으면 캠페인 전략이 복잡해질 수 있어요.

### 오디언스 조건은 얼마나 자주 바꿀 수 있나요?
필요할 때마다 바꿀 수 있어요. 다만 자주 바꾸면 오디언스 타겟팅의 성과와 효과에 영향을 줄 수 있어요.

### 오디언스를 삭제하면 어떻게 되나요?
삭제한 오디언스는 복구할 수 없어요. 그 오디언스를 사용하던 캠페인도 영향을 받으니, 삭제하기 전에 꼭 확인하세요.

### 하나의 광고 캠페인에 오디언스를 여러 개 사용할 수 있나요?
네, 할 수 있어요. 오디언스를 여러 개 사용하면 더 세밀한 타겟 광고 전략을 세울 수 있어요. 다만 오디언스별 성과를 살펴보면서 결과를 최적화하세요.
