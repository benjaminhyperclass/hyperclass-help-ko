# 템플릿 라이브러리에 사용자 지정 템플릿 추가하기

자주 쓰는 자산을 템플릿으로 만들어 **템플릿 라이브러리**(Template Library)에 올려 두면, 지원되는 서브 계정과 제품 영역에서 함께 쓸 수 있어요. 이 문서에서는 사용자 지정 템플릿을 만들고, 업로드하고, 정보를 채워 게시하고, 서브 계정별 공개 범위를 조정하는 방법을 안내해요.

하이퍼클래스의 템플릿 라이브러리를 쓰면 에이전시가 재사용할 자산을 템플릿으로 만들어 지원되는 서브 계정과 제품 영역에 공유할 수 있어요. 에이전시 관리자는 **에이전시 보기**에서 템플릿을 한곳에서 만들 수도 있고, 각 제품에서 지원되는 자산을 바로 업로드할 수도 있어요. 템플릿에는 카테고리, 태그, 설명, 미리보기, 커버 이미지, 사전 준비 사항을 넣어서 다른 사용자가 쉽게 찾고 이해하도록 도울 수 있어요.

## 이 문서에서 다루는 내용

- 사용자 지정 템플릿을 만들기 위한 조건
- 에이전시 보기에서 템플릿을 한곳에서 만드는 방법
- 각 제품에서 자산을 업로드하는 방법
- 템플릿 정보 설정 방법
- **임시 저장** 상태와 게시된 템플릿의 차이
- 서브 계정에 보이는 템플릿 라이브러리 범위 조정 방법

{% hint style="warning" %}
새 사용자 지정 템플릿을 만들려면 월 $497 Pro 요금제를 쓰는 에이전시 관리자여야 해요. $97 Starter, $297 Unlimited 요금제의 에이전시 관리자는 에이전시 템플릿 라이브러리를 둘러보고, 지원되는 공개 범위 관리 기능을 쓸 수 있어요. 하지만 새 사용자 지정 템플릿은 만들 수 없어요.
{% endhint %}

## 템플릿 라이브러리의 사용자 지정 템플릿이란?

사용자 지정 템플릿은 에이전시가 하이퍼클래스 템플릿 라이브러리에 추가한 재사용 자산이에요. 게시한 템플릿은 서브 계정에 공개할 수 있어요. 그러면 사용자가 같은 자산을 처음부터 다시 만들지 않고, 에이전시가 승인한 콘텐츠나 설정에서 시작할 수 있어요.

템플릿 라이브러리는 여러 제품 영역을 지원해요. 템플릿 종류와 만들기 옵션은 제품마다 달라요. 어떤 자산이 지원되는지는 내 계정에 보이는 제품 선택지와 업로드 메뉴로 확인하세요.

### 사용자 지정 템플릿의 장점

사용자 지정 템플릿을 쓰면 에이전시가 재사용 자산을 통일하고, 반복 설정을 줄이고, 검증된 콘텐츠를 서브 계정 사용자가 쉽게 찾게 할 수 있어요.

- 검증된 자산 재사용: 지원되는 제품 영역에서 기존 에이전시 콘텐츠를 재사용 템플릿으로 바꿀 수 있어요.
- 한곳에서 만들기: 서브 계정을 계속 오가지 않고 **에이전시 보기**에서 바로 템플릿 라이브러리 항목을 만들 수 있어요.
- 일관성 유지: 서브 계정에 에이전시가 승인한 디자인, 콘텐츠, 설정을 제공할 수 있어요.
- 찾기 쉽게 정리: 카테고리, 태그, 설명, 미리보기, 커버 이미지, 사전 준비 사항을 추가해 템플릿을 이해하고 찾기 쉽게 만들 수 있어요.
- 게시 시점 관리: 준비하는 동안은 **임시 저장** 상태로 두었다가, 쓸 준비가 되면 게시할 수 있어요.
- 공개 범위 관리: 서브 계정에 보이는 템플릿과 카테고리를 조정할 수 있어요.

## 시작하기 전에 확인할 사항

템플릿을 만들기 전에 요금제, 권한, 템플릿 라이브러리 공개 여부, 원본 자산을 확인해 두면 나중에 메뉴가 안 보이거나 템플릿에 접근할 수 없는 문제를 줄일 수 있어요.

- 새 사용자 지정 템플릿을 만들려면 에이전시가 월 $497 Pro 요금제를 쓰고 있어야 해요.
- 에이전시 관리자 역할로 로그인해야 해요.
- 서브 계정 사용자가 게시된 템플릿을 둘러보게 하려면 템플릿 라이브러리 접근이 켜져 있어야 해요.
- 기존 서브 계정의 자산으로 템플릿을 만들려면 원본 자산이 이미 있어야 해요.

### 고객에게 템플릿 라이브러리 공개하기

에이전시 단위의 템플릿 라이브러리 설정이 고객의 라이브러리 접근 여부를 정해요. 게시한 템플릿이 지원되는 서브 계정 화면에 보이게 하려면 먼저 이 설정을 켜세요.

1. **에이전시 보기**에서 **설정**을 열어요.
2. **회사**를 선택해요.
3. **Template Library for Clients**(고객용 템플릿 라이브러리)까지 스크롤해요.
4. 서브 계정 사용자가 템플릿에 접근하게 하려면 토글을 켜요.

![고객용 템플릿 라이브러리 토글 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081372038/original/xyhUsYPGBBAbYNmeZ6GMDskbtMSs1uU5qA.png?1789851933)

97달러·297달러 요금제: 이 요금제의 에이전시 관리자는 에이전시 템플릿 라이브러리를 둘러보고, 템플릿이나 카테고리 숨기기 같은 공개 범위 관리 기능을 쓸 수 있어요. 새 사용자 지정 템플릿을 만들려면 여전히 $497 Pro 요금제가 필요해요.

### 원본 자산을 고쳐도 템플릿은 바뀌지 않아요

이미 게시된 템플릿 라이브러리 템플릿은 원본 자산을 수정해도 자동으로 업데이트되지 않아요. 게시된 템플릿은 별도의 재사용 자산으로 보고, 원본 내용이 바뀌면 따로 검토하세요.

## 에이전시 보기에서 사용자 지정 템플릿 만들기

에이전시 보기에서 만들면 원본 제품을 거치지 않고도 서브 계정의 기존 자산을 골라 미리 보고, 이름을 바꾸고, 템플릿 라이브러리 항목으로 만들 수 있어요.

### 1단계: 템플릿 만들기 시작

에이전시 템플릿 라이브러리에서 시작하면 한 흐름 안에서 원본 서브 계정과 제품을 고를 수 있어요.

1. **에이전시 보기**에서 **템플릿 라이브러리**를 열어요.
2. **+ 템플릿 만들기**를 클릭해요.

![템플릿 라이브러리의 템플릿 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081372045/original/SnWRzTygzTJ-3XFH4sxBu5q2-gfQhv-cOA.png?1789851971)

### 2단계: 원본 자산 선택

원본 서브 계정과 제품 종류를 고르면, 새 템플릿으로 쓸 수 있는 기존 자산 목록이 나타나요.

1. 원본 자산이 있는 서브 계정을 선택해요.
2. 해당하는 제품을 선택해요.
3. 템플릿 또는 원본 자산을 선택해요.
4. **계속**을 클릭해요.

### 3단계: 미리 보고, 이름 바꾸고, 만들기

템플릿 라이브러리 항목을 만들기 전에 미리보기로 올바른 템플릿을 골랐는지 마지막으로 확인할 수 있어요.

1. 템플릿 미리보기를 확인해요.
2. 자산을 더 자세히 보려면 미리보기를 열어요.
3. 필요하면 템플릿 이름을 바꿔요.
4. **만들기**를 클릭해요.

![템플릿 미리보기와 이름 변경 후 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081372051/original/HO0Mjh0rkhg5xoA_d3Kh5Y5XjzmTbSCL-g.png?1789852010)

템플릿이 만들어지면 템플릿 라이브러리 관리 화면이 열려요. 여기서 템플릿 정보를 수정하고, **임시 저장** 상태로 저장하거나, 재사용할 수 있게 게시할 수 있어요.

## 제품에서 바로 템플릿 업로드하기

지원되는 제품에서는 기존 자산을 템플릿 라이브러리로 바로 보낼 수 있어요. 업로드 메뉴 이름은 제품마다 달라요. 보통은 자산의 점 3개 메뉴에서 시작해 템플릿 라이브러리 관리자 모드에서 마무리해요.

| 제품 | 시작 위치 | 업로드 메뉴 |
| --- | --- | --- |
| **이메일 템플릿** | **마케팅 > 이메일 > 템플릿** | **이메일 템플릿에 업로드** |
| **소셜 플래너** | **마케팅 > 소셜 플래너 > 콘텐츠 > CSV** | **소셜 템플릿에 업로드** |
| **워크플로우** | **자동화 > 워크플로우** | **Upload to Template Library**(템플릿 라이브러리에 업로드) |
| 지원되는 사이트 자산 | **사이트** > 지원되는 제품 선택 | **Upload to [product] templates**([제품] 템플릿에 업로드) |
| **광고 관리자** | **마케팅 > 광고 관리자** | **Upload to Template Library** |
| **사용자 지정 리포트** | **리포팅 > 사용자 지정 리포트** | **Upload Report Template**(리포트 템플릿 업로드) |

### 이메일 템플릿 업로드하기

**이메일 마케팅**의 템플릿 목록에서 바로 업로드하면, 이미 만들어 둔 디자인을 템플릿 라이브러리 자산으로 쓸 수 있어요.

1. 서브 계정에서 **마케팅 > 이메일 > 템플릿**으로 이동해요.
2. 재사용할 이메일 템플릿을 찾아요.
3. 템플릿의 점 3개 메뉴(⋮)를 열어요.
4. **이메일 템플릿에 업로드**를 선택해요.
5. 표시 이름을 입력해요.
6. 카테고리를 선택해요.
7. **업로드**를 클릭해요.

### 소셜 플래너 콘텐츠 업로드하기

에이전시 관리자는 소셜 플래너의 콘텐츠 영역에서 지원되는 재사용 콘텐츠를 바로 템플릿 라이브러리에 올릴 수 있어요.

1. 서브 계정에서 **마케팅 > 소셜 플래너**로 이동해요.
2. **콘텐츠**를 열어요.
3. **CSV** 탭이나 템플릿 라이브러리를 지원하는 다른 콘텐츠 영역을 열어요.
4. 재사용할 콘텐츠를 찾아요.
5. 해당 콘텐츠의 점 3개 메뉴를 열어요.
6. **소셜 템플릿에 업로드**를 선택해요.
7. 템플릿 이름을 입력하고 카테고리를 선택해요.
8. 템플릿 라이브러리 관리자 모드로 이동해 템플릿 정보를 마무리해요.

![소셜 플래너 콘텐츠의 소셜 템플릿에 업로드 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081372055/original/3GVRwpcSvBc8D8Wj1bgRXVxz5G0gCf83og.png?1789852060)

### 광고 관리자 캠페인 업로드하기

지원되는 광고 관리자 캠페인은 재사용 템플릿으로 저장할 수 있어요. 업로드하면 캠페인이 **임시 저장** 템플릿으로 만들어져요. 게시하기 전에 정보를 검토할 수 있어요.

1. 서브 계정에서 **마케팅 > 광고 관리자**로 이동해요.
2. 캠페인 목록을 열어요.
3. 재사용할 지원 캠페인을 찾아요.
4. 캠페인의 줄임표(⋮) 메뉴를 열어요.
5. **Upload to Template Library**를 선택해요.
6. 템플릿 이름을 입력해요.
7. 카테고리를 선택해요.
8. **업로드**를 클릭해요.

![광고 관리자 캠페인의 템플릿 라이브러리에 업로드 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081372106/original/hec53v-VpSfuCv2wWD8tQZqhSUZuDLp7yA.png?1789852526)

광고 관리자 임시 저장: 업로드한 지원 캠페인은 **임시 저장** 템플릿으로 저장돼요. 템플릿을 편집하거나, **임시 저장** 상태로 두거나, 재사용할 수 있게 게시할 수 있어요.

### 사용자 지정 리포트 업로드하기

사용자 지정 리포트는 업로드하기 전에 권한 설정과 내용 정리가 한 번 더 필요해요. 그래야 고객별 정보가 드러나지 않고 여러 서브 계정에서 쓸 수 있는 리포트가 돼요.

1. 서브 계정에서 **리포팅 > 사용자 지정 리포트**로 이동해요.
2. **Reports Overview**(리포트 개요)에서 완성된 리포트를 찾아요.
3. 리포트의 점 3개 메뉴를 열어요.
4. **권한 관리**를 선택해요.
5. **에이전시 사용자**, **계정 관리자**, **계정 사용자**에게 최소한 읽기 권한을 부여해요.
6. 재사용할 레이아웃, 브랜딩, 페이지 순서, 날짜 범위, 위젯 설정을 확정해요.
7. 고객별 텍스트, 스크린샷 등 고객 정보를 재사용 가능한 내용으로 바꿔요.
8. 리포트의 점 3개 메뉴로 다시 돌아와요.
9. **Upload Report Template**을 선택해요.

![사용자 지정 리포트의 리포트 템플릿 업로드 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081372104/original/kSGhT6HNq5U1tqq-dQ3UH0ozuluIWbu77A.png?1789852505)

### 그 밖의 지원 제품 업로드

다른 지원 제품 영역에서도 재사용 자산을 템플릿 라이브러리에 올릴 수 있어요. 메뉴 이름은 제품에 따라 달라요.

- 워크플로우: **자동화 > 워크플로우**로 이동해 워크플로우의 점 3개 메뉴를 열고 **Upload to Template Library**를 선택해요.
- 사이트 제품: 지원되는 퍼널, 웹사이트, 스토어, 블로그, 이메일, 폼, 설문, 퀴즈는 자산의 점 3개 메뉴에서 **Upload to [product] templates** 메뉴를 사용해요.

## 템플릿 설정하고 게시하기

템플릿 정보는 서브 계정 사용자가 자산에 무엇이 들어 있는지, 쓰기 전에 무엇이 필요한지, 어떤 상황에 맞는지 이해하도록 도와줘요. 게시하기 전에 가능한 정보를 모두 채워 두세요.

### 템플릿 정보 입력하기

입력 항목은 제품마다 다를 수 있어요. 템플릿 라이브러리 관리자 모드에는 보통 아래 정보가 있어요.

| 항목 | 용도 |
| --- | --- |
| **이름** | 템플릿 라이브러리에 표시되는 이름이에요. |
| **카테고리** | 관련 콘텐츠끼리 묶어 줘요. |
| **미리보기** | 사용자가 쓰기 전에 템플릿을 살펴볼 수 있어요. |
| **커버 이미지** | 템플릿을 대표하는 썸네일이나 이미지예요. |
| **태그** | 검색에 쓰이는 단어를 추가해 템플릿을 찾기 쉽게 해요. |
| **Prerequisites**(사전 준비 사항) | 템플릿을 적용하기 전에 필요한 설정을 알려 줘요. |
| **Short Description**(짧은 설명) | 템플릿과 함께 표시되는 간단한 요약이에요. |
| **Long About**(상세 소개) | 활용 사례, 설정 안내, 콘텐츠 팁, 기능 정보 등 자세한 내용을 담아요. |

### 임시 저장 상태로 저장하기

**임시 저장** 상태에서는 관리자가 템플릿을 계속 편집할 수 있고, 일반 서브 계정에서는 아직 쓸 수 없어요.

1. 템플릿 정보를 검토해요.
2. 넣고 싶은 정보를 모두 입력해요.
3. 변경사항을 저장해요.
4. 사용자에게 공개할 준비가 될 때까지 템플릿을 **임시 저장** 상태로 둬요.

### 템플릿 게시하기

게시하면 완성된 템플릿이 접근 권한이 있는 서브 계정 사용자의 템플릿 라이브러리에 나타나요.

1. 템플릿 이름, 카테고리, 미리보기, 사전 준비 사항, 설명 등 입력한 정보를 검토해요.
2. 저장하지 않은 변경사항이 있으면 저장해요.
3. **Publish Template**(템플릿 게시)을 클릭해요.
4. 확인 창이 나타나면 게시를 확인해요.

### 서브 계정별로 템플릿 라이브러리 공개 범위 조정하기

에이전시 관리자는 서브 계정마다 보이는 템플릿과 카테고리를 다르게 설정할 수 있어요. 고객의 요구, 업종, 요금제에 맞는 자산만 보여 줄 때 유용해요.

1. **에이전시 보기**에서 **템플릿 라이브러리**를 열어요.
2. **설정**을 열어요.
3. **Customize for Subaccounts**(서브 계정별 사용자 지정)를 선택해요.
4. 관리할 서브 계정을 찾아 **편집**을 클릭해요.
5. 필요에 따라 템플릿과 카테고리를 숨기거나 표시해요.
6. **저장**을 클릭해요.

## 자주 묻는 질문

### 사용자 지정 템플릿은 누가 만들 수 있나요?
에이전시 관리자 역할이고, 에이전시가 월 $497 Pro 요금제를 쓰고 있어야 만들 수 있어요.

### $97이나 $297 요금제의 에이전시 관리자도 사용자 지정 템플릿을 만들 수 있나요?
아니요. 이 요금제의 에이전시 관리자는 템플릿 라이브러리를 둘러보고 지원되는 공개 범위 관리 기능을 쓸 수 있어요. 하지만 새 사용자 지정 템플릿을 만들려면 $497 Pro 요금제가 필요해요.

### 원본 제품을 먼저 열지 않고도 템플릿을 만들 수 있나요?
네. **에이전시 보기 > 템플릿 라이브러리 > + 템플릿 만들기**로 이동한 다음, 원본 서브 계정, 제품, 원본 템플릿을 차례로 선택하세요.

### 템플릿을 바로 게시해야 하나요?
아니요. 지원되는 템플릿은 **임시 저장** 상태로 두고, 정보를 검토하고 채운 뒤에 서브 계정 사용자에게 공개할 수 있어요.

### 원본 자산을 수정하면 게시된 템플릿도 자동으로 바뀌나요?
아니요. 원본 자산을 수정해도 이에 해당하는 게시된 템플릿 라이브러리 템플릿에는 자동으로 반영되지 않아요.

### 어떤 서브 계정에 템플릿이 보일지 정할 수 있나요?
네. 에이전시 관리자는 서브 계정별로 템플릿 라이브러리 접근을 조정하고, 필요에 따라 템플릿과 카테고리를 숨기거나 표시할 수 있어요.

### 하이퍼클래스의 모든 제품에서 사용자 지정 템플릿을 만들 수 있나요?
아니요. 템플릿 지원 여부와 업로드 옵션은 제품마다 달라요. 내 계정에 보이는 제품 선택지와 업로드 메뉴로 해당 자산 종류가 지원되는지 확인하세요.

### 사용자 지정 템플릿을 판매할 수 있나요?
조건에 맞는 템플릿은 연결된 템플릿 라이브러리 마켓플레이스 절차를 통해 제출할 수 있어요. 템플릿 미리보기에서 **Sell Template On The Marketplace**(마켓플레이스에서 템플릿 판매)를 선택하고 **Seller Portal**(판매자 포털)로 이동하세요. 그다음 필요한 등록, 지원, 가격 정보를 입력하고 검토를 요청하면 돼요.
