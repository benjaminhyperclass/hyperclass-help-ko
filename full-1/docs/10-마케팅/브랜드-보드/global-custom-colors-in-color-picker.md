# 색상 선택기에서 전역 사용자 지정 색상 사용하기

**전역 사용자 지정 색상**을 쓰면 브랜드 색상을 한 번만 저장해 두고 하이퍼클래스 곳곳에서 다시 쓸 수 있어요. **브랜드 보드**에 색상 팔레트를 추가하면 이메일, 퍼널, 폼의 색상 선택기에 그대로 나타나요. 저장한 색상을 바꾸면 그 색상을 쓴 디자인도 자동으로 바뀌어요. 양방향으로 동기화되기 때문이에요.

[동영상](https://www.youtube.com/embed/wy42TQRUn80?&wmode=opaque)

## 전역 사용자 지정 색상이란?

전역 사용자 지정 색상은 **브랜드 보드 > 글로벌 설정**에서 만들어 두는, 재사용할 수 있는 색상 견본이에요. 빌더의 **Color Picker**(색상 선택기)에 표시돼요. 팀원 모두가 똑같은 브랜드 색상을 적용하고, 디자인을 일관되게 유지할 수 있어요. 색상이 바뀌면 한곳에서 수정하면 돼요.

**Design Kit**(디자인 키트) 색상과는 이렇게 달라요. 디자인 키트 색상은 브랜드 보드 안에 있고, 색상 선택기에도 나타나요. 전역 사용자 지정 색상은 따로 중앙에서 관리하는 팔레트예요. 빠르게 다시 쓰고, 적용된 곳과 양방향으로 동기화하도록 만들어졌어요. 두 가지 모두 색상 선택기에 나타날 수 있어요. 다만 **전역 사용자 지정 색상**은 색상을 하나 이상 추가한 뒤에만 표시돼요.

## 동기화 방식과 사용 요령

- **적용된 곳과 양방향 동기화**: 저장한 전역 색상을 수정하면, 그 견본을 쓴 디자인도 함께 바뀌어요.
- **색상을 하나 이상 추가하세요**: 색상을 하나라도 만들어야 색상 선택기에 **전역 사용자 지정 색상** 섹션이 나타나요. 그래서 디자인 키트 색상과 구분하기 쉬워요.
- **이름은 알아보기 쉽게 지으세요**: 기본, 보조, 강조처럼 쓰임새가 드러나는 이름을 쓰면 팀원이 어떤 견본을 써야 할지 알 수 있어요.
- **리브랜딩은 미리 계획하세요**: 크게 바꿀 때는 필요하면 디자인을 먼저 복제해 두세요. 그다음 전역 색상을 수정하면 변경 내용이 일관되게 반영돼요.

## 글로벌 설정에서 전역 색상 추가·편집·삭제하기

**글로벌 설정**에서 팀이 빌더 곳곳에서 재사용할 색상을 추가하고, 이름을 붙이고, 관리할 수 있어요. 색상을 하나 이상 만들어야 색상 선택기 안에 **전역 사용자 지정 색상** 섹션이 나타나요.

### 새 전역 색상 추가하기

1. **마케팅 > 브랜드 보드 > 글로벌 설정**으로 이동하세요.

   ![글로벌 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055025570/original/ZqO6b_vTELt36zUV3riYrSNJyxDzEDsn7w.png?1759335619)
2. **+ 추가**를 클릭한 뒤 **새로 추가**를 클릭하세요.

   ![추가 버튼과 새로 추가 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055025622/original/ljAkjeA_CznVSIP8CCRWd0Eih8UqpNQCsA.png?1759335661)
3. **이름**을 입력하세요(예: 기본, 강조, 배경). 그다음 HEX/RGB 값(예: `#1A73E8`)을 입력하거나, 색상 선택기에서 색상을 고르세요.

   ![이름과 색상 값 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055025696/original/Qwq4yLXAk7k9YXbgD-mVfihglAHWQy-8rQ.png?1759335736)
4. **저장**을 클릭하세요.

   ![저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055025720/original/BvuBURcJZypMtOWvbFQx7FLmuOkajIEbNw.png?1759335765)

### 전역 색상 편집·이름 변경·삭제하기

브랜드 보드의 **글로벌 설정**에서 기존 전역 색상을 편집하고, 이름을 바꾸고, 삭제할 수 있어요.

{% hint style="warning" %}
삭제하면 색상 선택기에서 해당 색상이 사라져요. 빌더가 색상 견본을 저장하는 방식에 따라, 그 색상을 쓴 디자인에도 삭제가 반영될 수 있어요.
{% endhint %}

- 전역 색상을 삭제하려면 **휴지통 아이콘**을 클릭하세요.

  ![휴지통 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055025839/original/i6jhTZ6JpItE7uYcazq_eSQ4ygDiLW4CqQ.png?1759335938)

- 전역 색상을 편집하거나 이름을 바꾸려면 **편집(연필) 아이콘**을 클릭하세요. 색상 선택기가 열리면 필요한 내용을 수정하세요.

  ![편집 아이콘과 색상 선택기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055025927/original/__NFp1Xhgh5mNBbfNk5piCMMN-scZ7PdsQ.png?1759336024)

## 커스텀 값에서 전역 사용자 지정 색상 가져오기

브랜드 색상을 이미 **커스텀 값**으로 저장해 두었다면, 가져와서 **전역 사용자 지정 색상** 팔레트를 빠르게 채울 수 있어요. **가져오기**를 하면 조건에 맞는 값이 **글로벌 설정**으로 복사되고, 그 뒤로는 한곳에서 관리할 수 있어요.

### 가져오기 전에 확인하세요

- 커스텀 값에 올바른 색상 값이 들어 있는지 확인하세요. 보통 `#000000` 같은 HEX 코드예요.
- `Primary_Color`, `Button_BG`처럼 알아보기 쉬운 이름을 쓰세요. 가져올 때 어떤 색상인지 구분하기 쉬워요.

### 가져오는 순서

1. **마케팅 > 브랜드 보드 > 글로벌 설정**으로 이동하세요.

   ![글로벌 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055026094/original/GlDDTugnVQsfCsd2OUR-J3isPueA_G8TEw.jpeg?1759336218)
2. **+ 추가**를 클릭한 뒤 **가져오기**를 클릭하세요.

   ![추가 버튼과 가져오기 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055026139/original/Hfe6C7a42US4Dt-a9vQclDI3CdaV7w4VdQ.png?1759336291)
3. 색상을 나타내는 커스텀 값을 선택하고 **가져오기**를 클릭하세요. 선택한 값 중 올바른 색상이 아닌 것(예: HEX 코드가 아닌 값)이 있으면, 선택에서 빼거나 고친 뒤에 가져오세요.

   ![가져올 커스텀 값 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055026205/original/oBHz1P0lH9irGCccU6Qn_3cJk7Bz3kQP3w.png?1759336350)

## 빌더의 색상 선택기에서 전역 사용자 지정 색상 사용하기

전역 사용자 지정 색상을 하나 이상 저장하면, 지원하는 빌더의 **Color Picker**에 **전역 사용자 지정 색상** 그룹이 나타나요. 승인된 색상 견본을 어디서든 그대로 적용할 수 있어요.

### 표시되는 곳

- 이메일(드래그 앤 드롭 빌더)
- 퍼널 & 웹사이트(페이지 빌더)
- 폼 & 설문
- **카운트다운 타이머**

### 편집기에서 전역 색상 적용하기

1. 빌더(예: 이메일, 퍼널 페이지, 카운트다운 타이머, 폼)를 열고, 색상 설정이 있는 요소(텍스트, 버튼, 배경, 테두리)를 선택하세요.
2. **Color Picker**를 여세요.
3. **전역 사용자 지정 색상** 아래의 견본을 클릭하면 적용돼요.

![색상 선택기의 전역 사용자 지정 색상 그룹](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055027781/original/vP4OO7Vv4okDp9mvz9Wsl3GiiJuocBAy1g.png?1759338087)

### 색상 선택기에서 바로 관리하기

색상 선택기에서 **관리**를 클릭하면 **글로벌 설정**으로 바로 이동해요(이동할 수 있는 경우). 이곳에서 색상을 추가하거나 수정할 수 있어요.

![색상 선택기의 관리 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055027806/original/ll37T6ttin2ZOxIq-AUbNMEfMnkev8rTuw.png?1759338117)

## 자주 묻는 질문

### 전역 색상을 바꾸면 이미 만든 디자인도 바뀌나요?
네. 전역 사용자 지정 색상은 양방향으로 동기화돼요. 색상을 바꾸면 그 색상을 적용한 모든 디자인에 바로 반영돼요.

### 색상 선택기에 전역 색상이 보이지 않아요.
**글로벌 설정**에서 색상을 하나 이상 추가해야 이 섹션이 나타나요.

### 커스텀 값으로 저장해 둔 색상을 가져올 수 있나요?
네. **커스텀 값**에서 **글로벌 설정**으로 가져올 수 있어요. 가져오면 복사본만 만들어지고, 기존 커스텀 값 기반 색상이 옮겨지거나 사라지지는 않아요.

### 디자인 키트 색상과는 뭐가 다른가요?
디자인 키트 색상은 빠르게 꺼내 쓰기 위한 용도이고 동기화되지 않아요. 전역 사용자 지정 색상은 모든 자산에 걸쳐 동기화돼요.

### 에이전시가 신규 고객사 온보딩에 쓸 수도 있나요?
네. 에이전시는 퍼널이나 이메일을 복제한 뒤 전역 색상만 수정하면, 새 고객사에 맞게 바로 리브랜딩할 수 있어요.
