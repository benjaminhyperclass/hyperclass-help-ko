# 폼, 설문, 퀴즈 빌더에서 브랜드 보드 색상 사용하기

저장해 둔 브랜드 보드 색상을 폼, 설문, 퀴즈 빌더 안에서 바로 쓸 수 있어요. 이 문서에서는 **브랜드 색상**을 활용하는 새 색상 선택기로 모든 폼의 색을 브랜드에 맞게 유지하는 방법을 안내해요.

## 브랜드 보드 색상이란?

폼, 설문, 퀴즈 빌더에서 요소의 스타일을 꾸밀 때 색상 선택기에서 저장해 둔 브랜드 색상을 바로 고를 수 있어요. 버튼, 입력란, 레이블 같은 디자인 요소를 브랜드에 맞게 유지하면서 색상 코드를 복사해 붙여넣지 않아도 돼요.

**브랜드 색상**은 저장해 둔 브랜드 보드 설정에 따라 표시돼요. 보이지 않는다면 브랜드 보드에 색상이 설정되어 있는지, 올바른 기본 브랜드 보드가 지정되어 있는지 확인하세요.

브랜드 보드 만드는 방법은 '브랜드 보드 만들기' 문서에서 더 알아볼 수 있어요.

## 브랜드 보드 색상을 쓰면 좋은 점

- 빠른 스타일 적용: 매번 16진수 색상 코드를 입력하지 않고 저장된 브랜드 색상을 적용할 수 있어요.
- 일관된 브랜드 유지: 버튼, 입력란, 레이블 등 모든 디자인 요소를 승인된 색상 팔레트에 맞출 수 있어요.
- 손쉬운 협업: 폼, 설문, 퀴즈에서 팀이 같은 색상 세트를 함께 쓸 수 있어요.
- 간편한 색상 관리: 색상 선택기에서 **Brand Settings**(브랜드 설정)를 열어 재사용할 사용자 지정 색상을 추가하고 관리할 수 있어요.

## 빌더에서 브랜드 보드 색상 사용하기

이 기능은 저장해 둔 브랜드 팔레트를 빌더와 연결해서, 작업 흐름을 끊지 않고 승인된 색상을 적용하게 해 줘요. 폼과 다른 자료에서 색을 일일이 맞추는 수고도 줄어들어요.

빌더에서 색상 필드를 열면 다음과 같이 동작해요.

1. 색상 선택기에 **브랜드 색상**, **전역 사용자 지정 색상**, **기본 색상** 섹션이 표시돼요.
2. 저장된 브랜드 색상을 선택하면 고른 요소에 그 색상이 적용돼요. 선택하면 빌더에 해당 색상이 미리 보기로 바로 표시돼요.
3. 새 사용자 지정 브랜드 색상을 추가하려면 색상 선택기에서 **관리**를 클릭해 **Brand Settings**(브랜드 설정)를 여세요.

{% hint style="info" %}
기본 브랜드 보드를 바꿔도 이미 만든 폼, 설문, 퀴즈의 스타일은 자동으로 바뀌지 않아요. 기존 자료는 직접 업데이트하기 전까지 현재 스타일을 그대로 유지해요.
{% endhint %}

## 자주 묻는 질문

### 색상 선택기에 브랜드 색상이 보이지 않아요.
브랜드 보드에 저장된 색상이 있는지, 올바른 기본 브랜드 보드가 지정되어 있는지 확인하세요.

### 브랜드 색상과 전역 사용자 지정 색상은 어떻게 다른가요?
**브랜드 색상**은 브랜드 보드에서 승인된 팔레트의 색상이에요. **전역 사용자 지정 색상**은 저장해 두고 다시 쓸 수 있는 색상으로, **Brand Settings**(브랜드 설정)에서 관리하며 지원되는 색상 선택기 어디에서나 쓸 수 있어요.

### 기본 브랜드 보드를 바꾸면 이미 만든 폼도 자동으로 바뀌나요?
아니요. 기존 폼, 설문, 퀴즈는 직접 업데이트하기 전까지 현재 스타일을 그대로 유지해요.
