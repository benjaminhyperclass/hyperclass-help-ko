# 전역 사용자 지정 색상으로 브랜드 색상 한 번에 관리하기

브랜드 색상을 한 번만 등록해 두면 모든 디자인에서 가져다 쓸 수 있어요. 등록한 색상을 수정하면 그 색상을 쓴 모든 곳에 바로 반영돼요. 디자인마다 색상을 일일이 맞추는 수고를 덜 수 있어요.

## 전역 사용자 지정 색상이란?

**전역 사용자 지정 색상**은 **브랜드 보드**의 **글로벌 설정**에 저장되는 브랜드 색상이에요.

- 양방향으로 동기화돼요. 색상을 수정하면 그 색상을 쓴 모든 곳(이메일, 퍼널, 폼, 페이지 등)에 자동으로 반영돼요.
- 기본적으로 하이퍼클래스 전체의 모든 **Color Picker**(색상 선택기)에 표시돼요.

### Design Kit 색상과는 어떻게 다른가요?

- **Design Kit**(디자인 키트) 색상: 디자인 빌더에서 빠르게 꺼내 쓰는 색상이에요. 동기화되지 않기 때문에 수정해도 이미 만든 디자인은 바뀌지 않아요.
- **전역 사용자 지정 색상**: 브랜드 단위로 저장되고 양방향으로 동기화돼요. 한 번만 수정하면 그 색상을 쓰는 모든 곳에 적용돼요.

정리하면, Design Kit 색상은 바뀌지 않는 빠른 선택용이고, 전역 사용자 지정 색상은 변경 내용이 함께 반영되어 브랜드 일관성을 지켜 주는 색상이에요.

### 전역 사용자 지정 색상의 장점

1. 모든 자산에서 일관성을 유지해요. 어떤 디자인이든 같은 분위기를 낼 수 있어요.
2. 시간을 아껴요. 색상을 한 번만 수정하면 모든 곳에 반영돼요.
3. 리브랜딩이 쉬워요. 에이전시는 퍼널과 이메일을 복제하거나 공유한 뒤, 전역 사용자 지정 색상만 바꿔 새 서브 계정의 브랜드를 빠르게 바꿀 수 있어요.
4. 언제든 쓸 수 있어요. 전역 색상은 모든 색상 선택기에 표시돼요.
5. 빠르게 가져올 수 있어요. 이미 만들어 둔 커스텀 값을 가져와 빠르게 설정할 수 있어요.

## 전역 사용자 지정 색상 사용하기

#### 1단계: 글로벌 설정 열기

**마케팅 > 브랜드 보드 > 글로벌 설정**으로 이동하세요.

![마케팅 메뉴에서 브랜드 보드로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055821242/original/erfzT83DFBq_By7xAic1N3H5xfUdUxgmIA.jpeg?1760341226)

![브랜드 보드의 글로벌 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055821247/original/gNyoVFKy3wgGu0tUjcow78fzLc68GEPE1A.jpeg?1760341226)

#### 2단계: 색상 추가 및 관리

- **Add New Color**(새 색상 추가): 색상 이름과 헥스 코드를 입력해 새 색상을 추가해요.

  ![새 색상의 이름과 헥스 코드를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055821243/original/1Ogy8jwZJvPGxTUD2VXOJ699T1Qohutwjw.jpeg?1760341226)

- **편집**: 색상 정보를 언제든 수정할 수 있어요.

  ![색상 정보를 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055821241/original/wahMx1uOrGjxPhGCWZsLJRnWUkM-mnkhKA.jpeg?1760341226)

- **삭제**: 쓰지 않는 색상을 제거해요.

#### 3단계: 색상 가져오기

1. **신규**를 클릭한 다음 **가져오기**를 선택하세요.
2. 가져올 색상을 선택하고 이어서 진행하세요.

   ![가져올 색상을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055821249/original/NddzdvgG86xnUBbCI9_7y9BvoPhMcy9cbA.jpeg?1760341226)

#### 4단계: 빌더에서 사용하기

1. 이메일, 퍼널, 폼, 타이머, 페이지에서 **Color Picker**를 여세요.
2. 전역 사용자 지정 색상이 자동으로 표시돼요.
3. 색상 선택기 안의 **관리**를 누르면 작업 중에 바로 색상을 추가하거나 편집할 수 있어요.

   ![색상 선택기 안의 관리 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055821244/original/3lKw7nGwmrJgczkizZ9LELsytTffanC0lA.jpeg?1760341226)

## 자주 묻는 질문

### 전역 색상을 바꾸면 이미 만든 자산에도 반영되나요?

네. 전역 사용자 지정 색상은 양방향으로 동기화돼요. 색상을 바꾸면 그 색상을 쓴 모든 디자인에 바로 반영돼요.

### 색상 선택기에 전역 색상이 보이지 않아요.

**글로벌 설정**에 색상을 하나 이상 추가해야 해당 영역이 표시돼요.

### 커스텀 값으로 만든 기존 색상을 가져올 수 있나요?

네. **커스텀 값** 섹션에서 **글로벌 설정**으로 가져올 수 있어요. 가져오면 복사본만 만들어지고, 기존 커스텀 값 기반 색상을 옮기지는 않아요.

### Design Kit 색상과는 무엇이 다른가요?

Design Kit 색상은 빠른 선택용이라 동기화되지 않아요. 전역 사용자 지정 색상은 모든 자산에 걸쳐 동기화돼요.

### 에이전시가 신규 고객 온보딩에 쓸 수 있나요?

네. 에이전시는 퍼널이나 이메일을 복제한 뒤 전역 색상만 수정해서 새 고객사의 브랜드로 바로 바꿀 수 있어요.
