# 제휴 관리자에서 실패한 PayPal 지급 확인하고 다시 시도하기

**제휴 관리자**(Affiliate Manager)가 실패하거나 거부된 PayPal 지급을 자동으로 찾아 **지급** 페이지의 전용 탭에 보여 줘요. 계정 소유자는 지급이 실패한 이유를 확인하고, 하이퍼클래스 고객지원이나 개발팀이 지급 상태를 바꿔 줄 때까지 기다리지 않고 직접 다시 지급 단계로 돌려보낼 수 있어요.

## 주요 기능

- 자동 감지: 제휴 관리자가 PayPal 지급을 제출한 뒤 각 지급의 상태를 다시 확인해요. 그래서 실패하거나 거부된 지급을 따로 찾지 않아도 돼요.
- **처리 중** 탭: PayPal이 아직 처리를 끝내지 않은 지급이 표시돼요.
- **실패** 탭: 실패했거나 거부된 지급이 표시돼요. PayPal이 실패 사유를 알려 준 경우에는 사유도 함께 보여요.
- **결제 재시도**: 실패한 지급을 **Approved for Payout**(지급 승인됨)으로 되돌려, 다시 지급할 수 있게 해요.

## 사용할 수 있는 사람

제휴 관리자에서 제휴 지급을 관리하는 계정 소유자와 관리자예요.

## 실패한 PayPal 지급 확인하기

1. **마케팅 > 제휴 관리자 > 지급**으로 이동하세요.
2. **처리 중** 탭을 선택하면 PayPal이 아직 확인 중인 지급을 볼 수 있어요. 이 탭의 지급은 따로 할 일이 없어요. PayPal에서 최종 상태를 받으면 **Paid**(지급 완료) 또는 **실패**로 옮겨져요.
3. **실패** 탭을 선택하면 PayPal이 거절했거나 완료하지 못한 지급을 볼 수 있어요. 각 행에 **결제 실패** 상태가 표시되고, 사유가 있으면 사유도 함께 보여요.
4. 지급의 상세 내용을 확인하려면 해당 행의 점 3개 메뉴를 클릭한 뒤 **연락처 보기**, **View Commission**(커미션 보기), **결제 상태 보기** 중 하나를 선택하세요.

{% hint style="info" %}
**처리 중** 탭과 **실패** 탭은 해당 상태의 지급이 하나 이상 있을 때만 나타나요. 탭이 보이지 않는다면 진행 중이거나 실패한 지급이 없다는 뜻이에요.
{% endhint %}

## 실패한 지급 다시 시도하기

1. **마케팅 > 제휴 관리자 > 지급 > 실패**로 이동하세요.
2. 실패 사유를 확인하고, 해결할 수 있으면 먼저 해결하세요. 예를 들어 제휴 파트너의 PayPal 지급 정보가 정확한지 확인해 보세요.
3. 해당 지급 행의 점 3개 메뉴를 클릭하고 **결제 재시도**를 선택하세요.
4. 지급이 **Approved for Payout** 탭으로 이동해요.
5. **Approved for Payout** 탭에서 평소 지급하던 방법대로 제휴 파트너에게 다시 지급하세요.

{% hint style="warning" %}
**결제 재시도**를 눌러도 결제가 바로 전송되지는 않아요. 지급을 **Approved for Payout**으로 되돌려 다시 지급할 수 있게 할 뿐이에요.
{% endhint %}

## 실패한 지급과 거부된 지급의 차이

**실패** 탭은 기존의 **Denied Payout**(지급 거부) 탭과 따로 구분돼요.

- **실패**: 승인한 뒤 지급을 시도했지만 PayPal이 거절했거나 완료하지 못한 지급이에요.
- **Denied Payout**: 제휴 관리자 안에서 직접 거부한 지급이에요.

## 자주 묻는 질문

### 실패 탭이나 처리 중 탭이 보이지 않아요. 왜 그런가요?
해당 상태의 지급이 하나 이상 있을 때만 이 탭들이 표시돼요. 필요할 때 자동으로 나타나요.

### PayPal이 지급을 거절한 이유도 제휴 관리자에서 볼 수 있나요?
네, PayPal이 사유를 알려 주면 **실패** 탭과 지급 상세 정보에 표시돼요. PayPal이 사유를 주지 않으면 아무것도 표시되지 않아요.

### 지급을 다시 시도하면 제휴 파트너에게 두 번 지급되나요?
아니요. **결제 재시도**는 선택한 실패 지급에만 적용되고, 그 지급을 **Approved for Payout**으로 되돌려요. 다시 지급하기 전까지는 결제가 전송되지 않아요.
