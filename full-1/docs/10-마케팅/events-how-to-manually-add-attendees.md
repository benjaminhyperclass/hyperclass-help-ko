# 이벤트 참석자 수동 등록

공개 등록 폼 없이 대시보드에서 참석자를 직접 등록하는 방법을 안내해요. 현장 등록, 전화 예약, 오프라인 판매, 무료 티켓 발급이 필요할 때 쓰세요.

이 문서에서는 참석자가 공개 등록 폼을 작성하지 않아도 하이퍼클래스 이벤트에 직접 등록하는 방법을 설명해요. 등록 만들기, 티켓 지정, 결제 처리, 확인 메일 발송까지 한 번에 할 수 있어요.

현장 방문 등록, 전화 예약, 오프라인 판매, 무료 티켓, 파트너 배정을 처리하면서도 이벤트 티켓 재고와 참석자 데이터를 최신 상태로 유지할 수 있어요.

## 참석자 수동 등록이란?

참석자 수동 등록은 하이퍼클래스의 **등록** 페이지에서 이벤트 등록을 직접 만드는 기능이에요. 공개 등록 폼을 거치지 않고 주최자가 참석자 대신 등록해 줘요.

참석자가 온라인으로 등록할 수 없거나 원하지 않는 상황에서 쓰도록 만든 기능이에요. 예를 들면 다음과 같아요.

- 행사장 현장 등록
- 전화 예약
- 파트너를 통한 오프라인 판매
- 무료 티켓 배정
- 기업 단체 등록

수동으로 만든 등록도 이벤트 관리 시스템과 완전히 연결돼요. 티켓은 바로 발급되고, 확인 이메일은 자동으로 발송돼요. 등록 데이터는 참석자 대시보드와 티켓 재고에 실시간으로 반영돼요.

## 참석자 수동 등록의 장점

- 다양한 등록 채널: 현장 방문, 전화, 이메일 요청, 파트너 소개, 오프라인 판매 등 어떤 경로로 들어온 등록이든 받을 수 있어요. 참석자가 온라인 폼을 쓰지 않아도 돼요.
- 정원 초과 등록: 티켓 정원이 다 찬 뒤에도 참석자를 등록할 수 있어요. 막판 요청이나 VIP 배정을 유연하게 처리할 수 있어요.
- 간소한 작업 흐름: 여러 도구를 오가지 않고 한 화면에서 등록 만들기, 티켓 지정, 결제 처리를 모두 할 수 있어요.
- 연락처 연동: 등록하는 중에 CRM의 기존 연락처를 고르거나 새 연락처를 만들 수 있어요. 참석자 데이터베이스를 하나로 관리할 수 있어요.
- 다양한 결제 방법: 연결된 결제 제공업체로 결제를 받거나, 현금·수표·계좌 이체 등으로 받은 오프라인 결제를 기록할 수 있어요.
- 즉시 티켓 발급: 등록이 끝나면 티켓이 바로 발급되고, 확인 이메일이 참석자에게 자동 발송돼요.
- 실시간 동기화: 수동 등록은 감사 기록과 결제 기록이 함께 **등록** 대시보드에 바로 나타나요.

## 참석자를 수동으로 등록하는 방법

다음 단계에 따라 참석자의 수동 등록을 만드세요.

### 1단계. 등록 페이지로 이동하기

**이벤트 > 등록**으로 이동하세요. 이벤트를 새로 **만들거나** 기존 이벤트를 **편집**한 뒤, **Add Attendee**(참석자 추가) 버튼을 눌러 수동 등록 화면을 여세요.

![등록 페이지에서 참석자 추가 버튼을 누르는 화면](https://jumpshare.com/share/N3QrXafmnP3qJROQZoQn+/GIF+Recording+2026-08-10+at+18.56.10.gif)

### 2단계. 티켓 유형과 수량 선택하기

이벤트에서 제공하는 티켓 유형을 하나 또는 여러 개 고르세요. 티켓 유형별로 수량을 입력한 다음 **계속**을 누르세요.

![티켓 유형과 수량을 선택하는 화면](https://jumpshare.com/share/gGbxadIOU0XgFxRzuC0o+/Screen+Shot+2026-08-10+at+18.57.31.png)

### 3단계. 참석자 정보 지정하기

티켓마다 CRM의 기존 연락처를 선택하거나 새 연락처를 만드세요. 그런 다음 필수 참석자 정보를 입력하세요.

한 사람이 티켓을 여러 장 구매하는 경우에는 참석자 정보를 다른 티켓에 복사할 수 있어요. 입력 시간을 줄일 수 있어요.

![참석자 정보를 입력하는 화면](https://jumpshare.com/share/hQ5751ZFGu0AD6Ey4pEi+/Screenshot+2026-08-10+at+18.59.58.png)

{% hint style="info" %}
등록 중에 새 연락처를 만들면 그 연락처는 CRM에 추가되고, 이벤트 등록과 바로 연결돼요. 연락처 정보는 이후 캠페인과 이벤트 초대에도 사용할 수 있어요.
{% endhint %}

### 4단계. 결제 처리하기

**결제 수집** 방법을 고르고 결제를 마무리하세요. 연결된 결제 제공업체로 **카드로 청구**하거나 **결제 기록**으로 오프라인 결제를 기록할 수 있어요. 마친 뒤 **Add & Record Payment**(추가 및 결제 기록)를 누르세요.

![결제 방법을 선택하고 결제를 기록하는 화면](https://jumpshare.com/share/3kiAn1xLoHex9Lzu6oSb+/GIF+Recording+2026-08-10+at+19.03.20.gif)

### 5단계. 등록 확인하기

티켓이 바로 발급되고, 등록된 모든 참석자에게 확인 이메일이 자동으로 발송돼요.

![등록이 완료된 화면](https://jumpshare.com/share/xeOQlckTU5hOIwJl6JWg+/Screen+Shot+2026-08-10+at+19.06.02.png)

{% hint style="info" %}
등록 내용은 **등록** 대시보드에 바로 나타나요. 참석자 정보, 티켓 지정 내역, 결제 기록도 함께 확인할 수 있어요.
{% endhint %}

{% hint style="info" %}
온라인으로 등록했든 팀이 직접 등록했든, 모든 등록은 추적되고 티켓이 발급되며 자동으로 확인돼요. 등록 채널이 달라도 한곳에서 관리할 수 있어요.
{% endhint %}

## 결제 수집 옵션

참석자 수동 등록에서는 두 가지 결제 수집 방법을 쓸 수 있어요. 거래 상황에 맞게 골라 쓰세요.

### 옵션 1. 카드로 청구

연결된 결제 제공업체(Stripe, Authorize.net, PayPal, NMI)로 바로 결제를 처리해요. 참석자의 신용카드나 체크카드로 실시간 청구하고, 결제 확인도 즉시 생성돼요.

### 옵션 2. 오프라인 결제 기록

시스템 밖에서 받은 결제를 기록해요. 사용할 수 있는 방법은 **Cash**(현금), **Card**(카드), **Check**(수표), **계좌 이체**, **Other**(기타)예요. 결제 제공업체를 통해 거래를 처리하지 않고 결제 기록만 만들어요.

{% hint style="info" %}
두 결제 방법 모두 **등록** 대시보드에 감사 기록을 남겨요. 온라인으로 처리했든 오프라인으로 기록했든, 모든 거래에 시간, 결제 방법, 금액이 남아서 정확한 재무 리포팅에 활용할 수 있어요.
{% endhint %}

## 티켓 발급과 확인 메일

수동 등록을 마치면 하이퍼클래스가 티켓 발급과 참석자 안내를 자동으로 처리해요.

- 즉시 티켓 생성: 등록이 끝나는 즉시 티켓이 만들어져요. 고유한 티켓 ID와 행사 체크인용 QR 코드가 포함돼요.
- 확인 이메일 자동 발송: 티켓 정보, 이벤트 정보, 캘린더 초대가 담긴 확인 이메일이 등록된 모든 참석자에게 자동으로 발송돼요.
- 대시보드 동기화: 참석자 데이터, 티켓 지정 내역, 결제 정보가 **등록** 대시보드에 바로 나타나요.
- 재고 업데이트: 티켓 재고가 실시간으로 갱신돼요. 모든 등록 채널에서 정확한 잔여 수량을 확인할 수 있어요.

![티켓 발급과 확인 메일 화면](https://jumpshare.com/share/eFRtx1N638foRFnyXeYq+/Screen+Shot+2026-08-10+at+19.03.58.png)

{% hint style="info" %}
확인 이메일은 이벤트에 설정된 이메일 템플릿을 사용해요. 이벤트 설정에서 이 템플릿을 브랜딩에 맞게 바꾸고, 참석자에게 보낼 맞춤 문구도 넣을 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 티켓 정원이 다 찬 뒤에도 참석자를 등록할 수 있나요?

네, 할 수 있어요. 수동 등록에서는 티켓이 매진으로 표시되어도 등록을 만들 수 있어요. 티켓 설정을 바꾸지 않고도 VIP 손님, 막판 요청, 정원 조정에 대응할 수 있어요.

### 수동으로 등록한 참석자도 온라인 등록과 같은 확인 이메일을 받나요?

네, 같아요. 수동으로 등록한 참석자도 티켓 정보, 이벤트 정보, 캘린더 초대가 담긴 확인 이메일을 자동으로 받아요. 공개 폼으로 등록한 참석자가 받는 메일과 동일해요.

### 한 번에 여러 참석자를 등록할 수 있나요?

네, 할 수 있어요. 한 번의 등록에서 여러 티켓 유형과 수량을 선택할 수 있어요. 티켓마다 참석자 정보가 필요하지만, 한 사람이 티켓을 여러 장 구매하는 경우에는 정보를 다른 티켓에 복사해서 입력 시간을 줄일 수 있어요.

### 오프라인 결제에는 어떤 결제 방법을 쓸 수 있나요?

**Cash**, **Card**(하이퍼클래스 밖에서 처리한 경우), **Check**, **계좌 이체**, **Other**로 오프라인 결제를 기록할 수 있어요. 이 방법들은 연결된 결제 제공업체로 거래를 처리하지 않고 결제 기록만 만들어요.

### CRM에 있는 기존 연락처로 수동 등록을 만들 수 있나요?

네, 할 수 있어요. 등록 과정에서 CRM 데이터베이스의 기존 연락처를 선택할 수 있어요. 이벤트 등록과 티켓 정보는 그 연락처의 기록에 자동으로 추가돼요.

### 수동 등록으로 무료 티켓을 발급할 수 있나요?

네, 할 수 있어요. 이벤트에 무료 티켓 유형이 있다면 수동 등록 중에 그 티켓을 선택하면 돼요. 유료 티켓은 금액을 0으로 입력해 오프라인 결제를 기록하거나, 사용자 지정 결제 방법을 사용해 무료 배정 내역을 남길 수 있어요.
