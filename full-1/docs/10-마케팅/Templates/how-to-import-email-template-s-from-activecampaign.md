# ActiveCampaign에서 이메일 템플릿 가져오기

ActiveCampaign에서 만든 이메일 템플릿이나 캠페인을 하이퍼클래스로 가져오는 방법을 안내해요. 먼저 ActiveCampaign에서 공유 링크를 복사한 다음, 하이퍼클래스에서 그 링크로 템플릿을 만들어요.

## 개요

ActiveCampaign처럼 이메일 캠페인과 템플릿을 제공하는 외부 서비스의 이메일을 하이퍼클래스로 가져올 수 있어요.

{% hint style="info" %}
이렇게 만들어진 템플릿은 **Code Editor**(코드 에디터) - HTML 유형의 이메일이에요.
{% endhint %}

## ActiveCampaign에서 공유 링크 복사하기

템플릿을 가져오기 전에 먼저 ActiveCampaign 계정에 로그인하세요. 로그인한 뒤 아래 순서를 따라 하세요. ([ActiveCampaign 도움말](https://help.activecampaign.com/hc/en-us/articles/115000754050-How-to-share-a-campaign-template))

1. 왼쪽 메뉴에서 **Campaigns**(캠페인) > **Campaign Templates**(캠페인 템플릿)를 클릭하세요.
2. **Manage Templates**(템플릿 관리) 페이지가 열리면 직접 만든 템플릿 목록이 보여요. 공유할 템플릿을 찾으세요.
3. 템플릿 위에 마우스를 올리면 나타나는 톱니바퀴 아이콘을 클릭하세요.
4. **Share**(공유)를 클릭하세요.
5. **Share this template**(이 템플릿 공유) 창이 열리고 공유 링크가 보여요. 링크 아이콘을 클릭해 링크를 복사하세요.
6. **X**를 클릭해 창을 닫으세요.

## 이메일 캠페인/템플릿 가져오기 화면 열기

1. **이메일** > **이메일 템플릿**으로 이동하세요.
2. **Create New Templates**(새 템플릿 만들기)를 클릭한 뒤 **템플릿 가져오기**를 선택하세요.

## ActiveCampaign에서 가져올 링크 준비하기

### Campaign Templates

- ActiveCampaign에서 **Campaign Templates**로 이동하세요.
- 가져오려는 템플릿 위에 마우스를 올리세요.
- 설정(톱니바퀴) 아이콘을 클릭한 뒤 **Share**를 클릭하고 캠페인 URL을 복사하세요.

### 이메일 캠페인

- **캠페인 만들기**를 클릭한 다음, **Continue**(계속) 옆의 드롭다운 버튼에서 **템플릿으로 저장**을 클릭하세요.

![ActiveCampaign에서 템플릿으로 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48254450309/original/dlUbFEVk4ZV-XddiE9eXNSvKBw34XvghyQ.png?1664799814)

## 하이퍼클래스에서 가져오기

1. ActiveCampaign의 캠페인 템플릿 또는 캠페인 URL을 복사해 붙여넣으세요.
2. ActiveCampaign 캠페인의 미리보기를 확인하세요.
3. **템플릿 만들기**를 클릭하면 ActiveCampaign 이메일을 가져와요.

# FAQ

### ActiveCampaign 가져오기에도 드래그 앤 드롭 방식의 이메일이 필요한가요?

사용자가 직접 써 보고 의견을 보내 주도록 시험 삼아 선보이는 기능이에요.

### 가져온 이메일 템플릿의 이름은 어떻게 정해지나요?

**템플릿 만들기**를 클릭한 뒤 템플릿 이름을 직접 입력해야 해요.
