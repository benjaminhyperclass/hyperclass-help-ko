# 에이전시 간 이메일 템플릿 공유하기

공유 링크를 만들어 이메일 템플릿을 다른 에이전시나 서브 계정에 전달하고, 받는 사람이 자기 계정으로 복제해 쓰게 할 수 있어요. 이 문서에서는 이메일 템플릿을 공유하고, 공유받은 템플릿을 가져와서 수정하는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/YMUxhb8JeNA?&wmode=opaque)

잘 만든 이메일 디자인을 처음부터 다시 만들지 않고 여러 에이전시와 서브 계정에서 재사용할 수 있어요. 팀의 브랜딩을 일관되게 유지하고 캠페인 제작 시간도 줄일 수 있어요.

## 이메일 템플릿 공유란?

이메일 템플릿 공유는 권한이 있는 사용자가 공유 링크로 재사용할 수 있는 이메일 디자인을 전달하는 기능이에요. HTML 파일을 내보내거나 레이아웃을 직접 다시 만들 필요 없이, 받는 사람이 공유된 템플릿의 사본을 원하는 서브 계정으로 가져올 수 있어요.

공유된 템플릿은 재사용 가능한 디자인 구조를 그대로 유지하고, 가져온 계정에서 자유롭게 수정할 수 있어요. 여러 고객사 계정을 관리하는 에이전시, 다른 팀과 협업하는 에이전시, 표준 이메일 디자인을 배포하는 에이전시에 특히 유용해요.

과정은 세 가지 동작으로 이루어져요.

1. **공유**: 기존 이메일 템플릿의 링크를 만들어요.
2. **가져오기**: 공유 링크를 열고 템플릿을 선택한 서브 계정으로 복제해요.
3. **커스터마이징**: 가져온 템플릿을 열어 내용, 디자인, 브랜딩을 필요에 맞게 수정해요.

{% hint style="warning" %}
이메일 마케팅 템플릿 공유는 에이전시의 **템플릿 라이브러리**로 자산을 공유하는 방식과 달라요. **템플릿 라이브러리**를 쓰는 별도 절차는 [에이전시 A가 에이전시 B에 템플릿을 효과적으로 공유하는 방법](../steps-for-agency-a-to-share-templates-effectively-with-agency-b.md)을 참고하세요.
{% endhint %}

## 이메일 템플릿 공유의 장점

템플릿을 재사용하면 시간을 아끼면서 고객사 계정 전체에 일관된 메시지를 유지할 수 있어요. 같은 이메일을 반복해서 디자인하지 않고, 기존 디자인을 전달해 대상이나 업무에 맞게 수정하면 돼요.

- 빠른 템플릿 배포: 여러 계정에서 직접 다시 만들지 않고 링크로 기존 이메일 디자인을 공유해요.
- 일관된 브랜딩: 에이전시 팀과 고객사 로케이션 전반에 표준 레이아웃, 디자인 요소, 메시지를 유지해요.
- 수정 가능한 템플릿: HTML 파일을 내려받지 않고 하이퍼클래스 이메일 편집기에서 가져온 템플릿을 바로 수정해요.
- 협업 개선: 승인된 이메일 디자인을 권한이 있는 사용자와 팀에 전달해요.
- 간편한 템플릿 관리: 재사용할 이메일 디자인을 두고 고객마다 가져와 맞춰 써요.
- 설정 시간 단축: 이메일 캠페인을 만들 때 바로 시작할 수 있는 기본 틀을 팀에 제공해요.

## 이메일 템플릿 공유 권한

공유 권한에 따라 누가 템플릿을 배포하고, 누가 공유 링크로 템플릿에 접근할 수 있는지가 정해져요. 권한을 알아 두면 의도하지 않은 배포를 막고, 받는 사람이 템플릿을 문제없이 쓸 수 있어요.

기존 이메일 템플릿 공유 안내에 따르면 에이전시 관리자와 에이전시 사용자가 공유를 시작할 수 있어요.

역할별 권한은 다음과 같아요.

- **에이전시 관리자**: 안내된 공유 절차로 이메일 템플릿을 공유할 수 있어요.
- **에이전시 사용자**: 안내된 공유 절차로 이메일 템플릿을 공유할 수 있어요.
- **계정 관리자**: 하이퍼클래스의 화이트라벨 이메일 템플릿 공유 안내에서 공유 가능한 역할로 나와 있어요.
- **Account/Location User**(계정/로케이션 사용자): 화이트라벨 공유 가이드에는 이 역할에게 **공유** 기능이 제공되지 않는다고 나와 있어요.

{% hint style="warning" %}
공유 링크를 만들 수 있는 권한과, 공유 링크를 열어 템플릿을 가져올 수 있는 권한은 서로 달라요. 가져오기 권한은 받는 사람의 역할, 가져올 계정에 대한 접근 권한, 공유 설정에 따라 달라질 수 있어요. **공유** 옵션이 보이지 않으면 사용자의 역할과 접근 권한을 확인하세요.
{% endhint %}

## 이메일 템플릿 공유 옵션

이메일 템플릿을 어떻게 공유할지는 접근 설정으로 정해요. 대상에 맞는 옵션을 고르면 의도한 사람에게만 템플릿을 전달할 수 있어요.

공유 절차에는 두 가지 접근 옵션이 있어요.

- **다음 범위 내 모든 사람**: 에이전시 안의 사용자와 공유할 때 쓰는 옵션이에요. 각 사용자의 접근 권한이 함께 적용돼요.
- **링크가 있는 모든 사람**: 링크로 배포할 때 쓰는 옵션이에요. 자격이 있는 받는 사람이 URL로 공유된 템플릿에 접근할 수 있어요.

받는 대상에 맞게 접근 옵션을 고르세요. 내부 배포라면 에이전시로 범위가 제한되는 옵션이 알맞아요. 외부 협업이라면 받는 사람에게 적합할 때 링크 기반 옵션을 선택하세요.

## 이메일 템플릿 공유하기

공유는 **이메일 마케팅**에 있는 기존 템플릿에서 시작해요. 알맞은 템플릿을 고르고 접근 설정을 정하면 받는 사람이 의도한 디자인을 받고 링크도 문제없이 열 수 있어요.

다음 단계로 이메일 템플릿 공유 링크를 만들어 전달하세요.

1. 하이퍼클래스에서 해당 계정을 열고 **마케팅 > 이메일 > 템플릿**으로 이동하세요.
2. 공유할 이메일 템플릿을 찾으세요.

   ![이메일 템플릿 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083515702/original/ip-DjDt4rFdv4Kn2t3jrvoL5AhvRahpKzw.png?1792155177)
3. 배포할 템플릿 옆의 점 세 개 메뉴(⋮)를 클릭하고 **공유**를 선택하세요.

   ![템플릿 옆 메뉴에서 공유 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083515935/original/WqMuoGvYwGs0VumJ8baWQ5ODkdu-j6875Q.png?1792155226)
4. 공유 접근 권한을 설정하세요. 공유 창의 설정을 확인하고, 받는 대상에 맞는 옵션을 고르세요.

   - **다음 범위 내 모든 사람**
   - **링크가 있는 모든 사람**

   ![공유 창의 접근 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083516044/original/in-rQkXIfy_Gkrn9VPmuib1OhJxpL8FHkw.png?1792155262)
5. 공유 설정을 마쳤으면 만들어진 템플릿 링크를 복사하세요.

   ![생성된 공유 링크 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083516159/original/VMRsKdVe7gn28uhbbtqEvWwSXHsuK8QH_Q.png?1792155293)
6. 이메일, 메신저 등 편한 방법으로 받는 사람에게 링크를 보내세요. 받는 사람은 이 링크로 공유된 템플릿에 접근해 가져오기를 시작할 수 있어요.

{% hint style="info" %}
링크를 보낼 때 템플릿 이름과 간단한 설명을 함께 적어 주세요. 같은 팀에 여러 템플릿을 공유할 때 특히 도움이 돼요.
{% endhint %}

## 공유받은 이메일 템플릿 가져오기

가져오면 공유된 이메일 디자인의 사본이 선택한 서브 계정에 만들어져요. 가져온 템플릿은 그 계정의 템플릿 목록에 표시되므로, 가져올 계정을 정확히 고르는 것이 중요해요.

다음 단계로 공유 링크에서 이메일 템플릿을 가져오세요.

1. 보낸 사람이 알려 준 이메일 템플릿 공유 URL을 복사해 브라우저에 붙여 넣고 여세요. 로그인 안내가 나오면 필요한 접근 권한이 있는 계정으로 하이퍼클래스에 로그인하세요.
2. 공유된 템플릿 화면에 템플릿을 가져오는 옵션이 나와요. **템플릿 추가**를 클릭해 진행하세요.

   ![공유된 템플릿 화면의 템플릿 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083516396/original/1Q0hs3i3eVrI0gixiUKFv_ig6UBp7Y_vHw.png?1792155369)
3. 복제 창에서 템플릿 이름을 확인하거나 바꾸세요. 가져온 뒤에 알아보기 쉬운 이름이 좋아요. 예를 들어 "웰컴 이메일"이라는 기본 이름은 "신규 고객 웰컴 이메일"로 바꿀 수 있어요.

   ![복제 창에서 템플릿 이름 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083516499/original/V7_OKfo0I87gxtjWF6FKi2YWHoROLiKxyw.png?1792155407)
4. 템플릿을 복제할 로케이션 또는 서브 계정을 선택하세요. 복제할 때 최대 3개의 로케이션을 선택할 수 있다고 안내돼 있어요.

   {% hint style="info" %}
   최대 3개라는 한도는 기존 안내 문서에 나온 내용이에요. 현재 화면에서 한도가 같은지 확인해 보세요.
   {% endhint %}
   <!-- 검토 필요: 3개 로케이션 한도를 현재 제품 화면에서 확인 후 게시 -->
5. 복제가 끝나면 처음 선택한 로케이션의 **템플릿** 화면으로 이동해요. 가져온 계정의 템플릿 목록에서 가져온 이메일 템플릿을 찾아보세요.

   {% hint style="info" %}
   여러 로케이션으로 가져왔다면 선택한 계정을 하나씩 열어 템플릿이 제대로 들어왔는지 확인하세요.
   {% endhint %}

## 자주 묻는 질문

### 이메일 템플릿에 공유 옵션이 보이지 않아요.
사용자 역할이나 계정 접근 권한 때문에 **공유** 옵션이 보이지 않을 수 있어요. 기존 공유 안내에는 에이전시 관리자와 에이전시 사용자가 템플릿을 공유할 수 있다고 나와 있어요. 옵션이 보이지 않으면 에이전시 관리자에게 권한을 확인해 달라고 요청하세요.

### 에이전시 밖의 사람에게도 이메일 템플릿을 공유할 수 있나요?
하이퍼클래스에는 링크 기반 접근 옵션이 있고, 별도로 **템플릿 라이브러리**를 통해 에이전시 간에 공유하는 방법도 있어요. 이메일 마케팅 템플릿은 사용할 수 있는 공유 설정을 확인하고, 받는 사람이 알맞은 접근 권한을 가지고 있는지 확인하세요.

### 누군가 제 이메일 템플릿 공유 링크를 다른 사람에게 전달하면 어떻게 되나요?
URL을 받은 사람은 누구나 링크를 열어 볼 수 있어요. 템플릿을 실제로 쓸 수 있는지는 링크에 설정된 접근 옵션과 해당 권한에 따라 달라져요. 알맞은 공유 옵션을 선택하고 링크는 신중하게 전달하세요.

### 공유받은 템플릿 하나를 여러 서브 계정으로 가져올 수 있나요?
복제할 때 여러 로케이션을 선택할 수 있고, 한 번에 최대 3개까지라고 안내돼 있어요. 현재 한도는 화면에서 확인하세요.

### 가져온 템플릿을 수정하면 원본 템플릿도 바뀌나요?
공유하면 사본이 복제되는 방식이에요. 서브 계정으로 복제된 템플릿끼리 계속 동기화된다는 내용은 기존 안내에 없어요. 그래서 가져온 사본을 수정해도 원본이 자동으로 바뀐다고 기대하면 안 돼요.

### HTML 파일을 내보내지 않고도 이메일 템플릿을 공유할 수 있나요?
네. 하이퍼클래스의 이메일 템플릿 공유 기능은 공유 링크를 쓰고, 받는 사람이 자기 계정으로 디자인을 가져올 수 있게 해 줘요. 이 방식에서는 HTML 파일을 내보낼 필요가 없어요.

### 에이전시의 브랜드 도메인으로 이메일 템플릿 공유 링크를 만들 수 있나요?
네. 템플릿 공유 ID(Share ID)와 에이전시의 화이트라벨 도메인을 쓰는 화이트라벨 공유 방법이 있어요. 설정 방법은 [화이트라벨 이메일 템플릿 공유 단계별 가이드](whitelabel-email-template-sharing-step-by-step-guide.md)를 참고하세요.
