# 제휴 관리자 미디어 라이브러리 개선

계정 관리자는 **제휴 관리자**(Affiliate Manager)의 **미디어 라이브러리**에 제휴 회원이 쓸 미디어 파일을 올리고 정리할 수 있어요. 미디어는 특정 제휴 캠페인에 연결할 수도 있고, 모든 캠페인에서 쓰게 할 수도 있어요. 그래서 제휴 회원은 자신이 홍보하는 캠페인에 필요한 자료를 바로 찾을 수 있어요.

[동영상](https://www.youtube.com/embed/dJWvXKPOu9s?&wmode=opaque)

## 주요 기능

- 미디어 한곳에서 관리: **제휴 관리자**의 **미디어** 메뉴에서 제휴 캠페인 자료를 올리고 관리해요.
- 캠페인별 미디어: 미디어 파일을 특정 제휴 캠페인에 연결하거나, 모든 캠페인에서 쓸 수 있게 설정해요. 제휴 회원은 자신이 배정된 캠페인에서 쓸 수 있는 미디어를 볼 수 있어요.
- 미디어 복사 및 다운로드: 제휴 회원은 **제휴 포털**의 **미디어** 메뉴에서 자신에게 열린 캠페인 미디어를 확인해요. 파일에 따라 지원되는 복사나 다운로드 기능도 쓸 수 있어요.

## 사용 방법

1. 서브 계정에서 **제휴 관리자**를 열고 **미디어**를 선택하세요.
2. **Add File**(파일 추가)을 클릭해 새 미디어 파일을 올리세요.
3. 이 미디어를 특정 캠페인에 연결할지, 모든 캠페인에서 쓰게 할지 선택하세요.
4. **저장**을 클릭하세요. 해당 캠페인에 접근할 수 있는 제휴 회원은 **제휴 포털**의 **미디어** 메뉴에서 이 파일을 볼 수 있어요.

## 관리자와 제휴 회원이 보는 화면

계정 관리자는 **제휴 관리자**에서 미디어를 관리하고, 어떤 캠페인 자료를 열어 줄지 정해요.

제휴 회원은 **제휴 포털**의 **미디어** 메뉴에서 자료를 확인해요. 볼 수 있는 파일은 배정된 캠페인과 그 캠페인에 열어 둔 미디어에 따라 달라요.

{% hint style="info" %}
제휴 회원이 **제휴 포털**에서 특정 캠페인 전용 자료를 보려면 먼저 해당 캠페인에 배정되어 있어야 해요.
{% endhint %}

## 이럴 때 도움이 돼요

- 작업이 더 효율적이에요: 이제 미디어 파일을 더 빠르고 간단하게 관리할 수 있어요. 파일 정리에 쓰는 시간이 줄고, 제휴 회원은 필요한 자료를 빨리 받을 수 있어요.
- 필요한 미디어만 보여 줄 수 있어요: 미디어를 특정 캠페인에 연결하면 제휴 회원에게는 자신의 캠페인과 관련된 파일만 보여요. 혼란을 줄이고 업무 효율을 높일 수 있어요.
- 제휴 회원이 더 편하게 써요: 다운로드와 복사 기능으로 미디어를 쉽게 가져와 공유할 수 있어서 작업 흐름이 더 매끄러워져요.

## 자주 묻는 질문

### 제휴 회원은 캠페인 미디어를 어디에서 찾을 수 있나요?
**제휴 포털**의 **미디어** 메뉴에서 볼 수 있어요. 어떤 파일이 보이는지는 제휴 회원이 배정된 캠페인과 계정 관리자가 열어 둔 미디어에 따라 달라요.

### 미디어를 여러 제휴 캠페인에서 함께 쓸 수 있나요?
네, 할 수 있어요. 파일을 어떻게 설정하느냐에 따라 특정 제휴 캠페인에 연결하거나 모든 캠페인에서 쓸 수 있게 만들 수 있어요.
