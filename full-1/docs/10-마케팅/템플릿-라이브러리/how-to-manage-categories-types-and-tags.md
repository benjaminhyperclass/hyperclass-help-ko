# 카테고리, 유형, 태그 관리

**템플릿 라이브러리**의 카테고리와 유형을 만들고 편집하고 삭제하는 방법, 그리고 태그를 편집하고 삭제하는 방법을 안내해요. 에이전시 관리자만 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/-KMJWRe3700?&wmode=opaque)

카테고리, 유형, 태그를 더 쉽고 빠르게 관리할 수 있도록 관리자 기능을 개선했어요.

## 템플릿 라이브러리 설정 열기

1. **에이전시 보기로 전환**을 클릭해 **에이전시 보기**로 이동하세요.
2. **템플릿 라이브러리**로 이동하세요.
3. **설정**을 클릭하면 카테고리, 유형, 태그를 관리할 수 있어요.

### 쓸 수 있는 기능

1. 카테고리 만들기, 편집, 삭제

   - 카테고리를 만들고, 편집하고, 삭제해서 템플릿을 더 체계적으로 정리할 수 있어요. 카테고리를 삭제하기 전에 필요하면 템플릿을 다른 카테고리로 옮겨 두세요.
2. 유형과 태그 관리

   - 템플릿을 일일이 찾아보지 않아도, 한 화면에서 유형과 태그를 편집하고 삭제할 수 있어요.

### 사용 방법

1. 템플릿 라이브러리 관리 화면 열기

   - 서브 계정 보기에서 **에이전시 보기**로 전환한 뒤 **템플릿 라이브러리**를 찾으세요. 이곳에서 기존 템플릿과 카테고리, 상태, 태그 등을 확인하고 관리할 수 있어요.

     ![템플릿 라이브러리 관리 화면 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048212778/original/S8xH5LSEQlVlwT4DIsqomD0OgHI9QyyN5g.gif?1749814744)
2. 카테고리 관리

   - **설정**을 클릭하세요.
   - **만들기**: 카테고리 만들기를 클릭하고 세부 정보를 입력한 뒤, 유형은 **카테고리**를 선택하세요.

     ![카테고리 만들기 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031429115/original/HHfSae5Qlnu6kyamiBIIlkO8-Vf_gFvA_Q.png?1724247718)![카테고리 만들기 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031429194/original/5p8w8_qSHAmIR9qzb_XCM3NCzi2m0LnRbQ.png?1724247768)

   - **편집**: **편집** 버튼을 클릭하면 카테고리 이름이나 설명을 바꿀 수 있어요.

     ![카테고리 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031429240/original/EOdh427wJu_rbewL5th_9mda64xdILajfw.png?1724247785)
   - **삭제**: **삭제** 버튼을 클릭하면 삭제 확인 창이 나와요. 템플릿을 남겨 두려면 삭제를 확인하기 전에 다른 카테고리로 옮기세요.

## 자주 묻는 질문

### 이 기능은 누가 사용할 수 있나요?
에이전시 관리자만 관리 화면과 **설정** 페이지에 접근할 수 있어요.

### 하이퍼클래스 팀이 추가한 카테고리, 태그, 유형도 편집할 수 있나요?
하이퍼클래스 팀이 추가한 카테고리는 숨기기만 할 수 있어요.

### 카테고리를 삭제하면 템플릿도 삭제되나요?
삭제될 위험이 있는 템플릿 목록을 미리 알려 드려요. 이 템플릿들은 숨겨진 카테고리로 옮겨 두는 것을 권장해요.
