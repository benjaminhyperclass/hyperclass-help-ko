# 광고 관리자 템플릿 라이브러리로 광고 캠페인 빠르게 만들기

**광고 관리자**의 **템플릿 라이브러리**에 있는 템플릿을 쓰면 광고 캠페인을 더 쉽고 빠르게 만들 수 있어요. 이 문서에서는 템플릿을 쓰는 이유와 템플릿으로 캠페인을 시작하는 절차를 안내해요.

## 템플릿을 쓰면 좋은 점

템플릿을 쓰면 캠페인을 더 빠르고 효과적으로 만들 수 있어요.

- 시간 절약: 미리 만들어진 레이아웃으로 몇 분 만에 광고를 시작할 수 있어요.
- 성과 향상: 검증된 광고 전략을 바탕으로 만들어 광고 성과를 높이는 데 도움이 돼요.
- 브랜드 일관성: 모든 캠페인에서 메시지와 디자인을 일관되게 유지할 수 있어요.
- 쉬운 수정: 구조는 그대로 두고 문구, 이미지, 타기팅만 바꿀 수 있어요.
- 팀 협업: 여러 브랜드를 관리하는 팀과 에이전시의 작업 과정이 단순해져요.

## 광고 관리자 템플릿 사용 절차

### 1단계: 광고 관리자로 이동하기

1. 계정에서 **마케팅**을 클릭하세요.
2. **광고 관리자** 탭을 클릭하세요.

![마케팅 메뉴에서 광고 관리자 탭으로 이동하는 화면](https://jumpshare.com/v/UMX7xWJS4edmpepgwCdk+/Screen+Shot+2025-07-02+at+5.34.20+PM.png)

### 2단계: 캠페인 만들기

1. **+ 캠페인 만들기** 버튼을 클릭하세요.
2. 광고 캠페인을 운영할 플랫폼으로 **Google** 또는 **Meta or Linkedin**을 선택하세요.
3. **다음**을 클릭하세요.

![광고 플랫폼을 선택하고 다음을 클릭하는 과정](https://jumpshare.com/v/3JTOOgVzFMRvE4oDPD5V+/GIF+Recording+2025-07-02+at+5.39.57+PM.gif)

### 3단계: 템플릿 고르기, 미리 보기, 선택하기

{% hint style="info" %}
이 단계는 템플릿 라이브러리에서 광고 관리자 템플릿을 쓸 수 있는 사용자에게만 해당해요. 서브 계정에서 템플릿 라이브러리 접근이 제한되어 있으면 **광고 관리자 템플릿**이 보이지 않아요. 이 경우 광고 플랫폼을 선택한 뒤 **처음부터 만들기**로 바로 캠페인 빌더로 넘어가요.
{% endhint %}

1. **Choose how you want to start creating the campaign**(캠페인을 시작하는 방법 선택) 화면에서 **광고 관리자 템플릿**을 선택하세요.
2. **다음**을 클릭하세요.
3. 캠페인에 맞는 광고 템플릿을 둘러보고 고르세요. 아래 기준으로 템플릿을 걸러서 볼 수도 있어요.
   - **카테고리** (예: 자동차, 법률, 마케팅 에이전시, 금융)
   - **Objectives**(목표) (예: 참여, 리드 생성, 판매, 웹 트래픽)
   - **태그**
4. 템플릿의 눈 모양 아이콘을 클릭하면 여러 게재 위치에서 광고가 어떻게 보이는지 미리 볼 수 있어요.
5. 템플릿을 클릭하면 **미리보기**를 보고 **상세 정보**도 확인할 수 있어요.
6. **계속**을 클릭해 템플릿을 추가하세요.
7. 필요에 따라 광고 문구, 이미지, URL, 설정을 수정한 뒤 광고를 게시하세요.

![템플릿을 고르고 미리 본 뒤 추가하는 과정](https://jumpshare.com/v/HdwDQdjswxZbUX99dkrd+/GIF+Recording+2025-07-02+at+6.05.53+PM.gif)

## 자주 묻는 질문

### Facebook 광고와 Google 광고에 같은 템플릿을 쓸 수 있나요?
라이브러리의 템플릿은 플랫폼별로 연결되어 있어요.

### 템플릿을 즐겨찾기에 추가할 수 있나요?
네, 템플릿을 즐겨찾기로 표시해 두면 빠르게 찾을 수 있어요.
