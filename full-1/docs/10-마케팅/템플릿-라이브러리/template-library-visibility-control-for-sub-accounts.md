# 서브 계정별 템플릿 라이브러리 표시 설정

특정 서브 계정에서 **템플릿 라이브러리**를 숨기거나, 상품별로 보이는 범위를 제한하는 방법을 안내해요. 서브 계정 사용자가 필요한 것만 보게 하고, 템플릿이 잘못 쓰이는 일을 줄일 수 있어요. 이 설정은 에이전시 관리자만 쓸 수 있어요.

## 템플릿 라이브러리 표시 설정이란?

이 설정을 쓰면 에이전시 관리자가 서브 계정에서 **템플릿 라이브러리**를 쓸 수 있게 할지 정할 수 있어요. 쓸 수 있게 한다면 어떤 상품(모듈)의 템플릿을 둘러볼 수 있게 할지도 정해요. 서브 계정 사용자가 다른 곳에 한눈팔지 않게 하고, 에이전시가 계정마다 템플릿을 일관되게 쓰도록 맞추는 데 도움이 돼요.

- 에이전시 화면에서 서브 계정별로 설정해요.
- **숨기기**, **표시**, **특정 상품에 대해 숨기기** 중에서 고를 수 있어요.
- 변경 내용은 바로 적용되며, 서브 계정 사용자에게만 영향을 줘요.

## 이 설정으로 할 수 있는 것

- 세밀한 제어: 라이브러리 전체를 숨기거나, 전체를 보여 주거나, 선택한 상품만 서브 계정에 보여 줄 수 있어요.
- 깔끔한 화면: 필요 없는 템플릿을 없애서 서브 계정 사용자가 필요한 것만 보게 할 수 있어요.
- 정책 준수: 특정 모듈에서 잘못 쓰이거나 정책에 맞지 않는 템플릿이 쓰이지 않게 막을 수 있어요.
- 빠른 적응: 승인된 템플릿으로 사용자를 안내해서 사용법 문의를 줄일 수 있어요.
- 즉시 적용: 저장하면 바로 반영돼요.

## 권한과 적용 범위

표시 설정을 바꾸려면 알맞은 권한이 필요해요. 역할에 따라 보이는 범위도 달라요.

- 서브 계정의 템플릿 라이브러리 표시 설정은 에이전시 관리자만 바꿀 수 있어요.
- 에이전시 사용자와 관리자는 모든 서브 계정에서 항상 **템플릿 라이브러리**를 볼 수 있어요. 제한은 서브 계정 사용자에게만 적용돼요.
- **시스템 이메일** 템플릿은 표시 설정과 상관없이 항상 사용자에게 보여요.
- 서브 계정의 템플릿 라이브러리 접근이 제한되어 있으면, 서브 계정 사용자가 광고 캠페인을 만들 때 **Ad Manager Templates**(광고 관리자 템플릿) 옵션이 보이지 않아요.
- 제한된 사용자는 광고 플랫폼을 선택한 뒤 템플릿 선택 단계를 건너뛰고, **처음부터 만들기**로 바로 캠페인 빌더로 이동해요. 템플릿 라이브러리를 쓸 수 있는 서브 계정 사용자는 기존처럼 광고 관리자 템플릿 선택 과정을 거쳐요.

## 서브 계정별 템플릿 라이브러리 표시 설정하기

아래 순서대로 따라 하면 특정 서브 계정의 템플릿 라이브러리 표시 여부를 설정할 수 있어요.

1. 에이전시 관리자로 로그인해요. **에이전시 대시보드**의 왼쪽 메뉴에서 **템플릿 라이브러리**를 선택해요.

   ![에이전시 대시보드 메뉴에서 템플릿 라이브러리 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058795466/original/Dnbj9BmT0DsttQbtyEdfak38ELI5x9Y5_Q.png?1763586922)

2. **템플릿 라이브러리** 화면 오른쪽 위에 있는 **설정**(톱니바퀴 아이콘) 버튼을 클릭해요.

   ![템플릿 라이브러리 오른쪽 위 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058795510/original/HbAaszvZb3_T2hlGNTj84MyYXqtAv40Ohw.png?1763587016)

3. 왼쪽 탐색 메뉴에서 **Customize for Sub-Account Settings**(서브 계정 설정 맞춤) 탭을 선택해요.

   ![왼쪽 메뉴의 서브 계정 설정 맞춤 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058795563/original/vf3wvRWTrcg3LaEIIp17wzFwjDQgl8izUA.png?1763587168)

4. 검색창에서 설정을 바꿀 서브 계정을 찾아요. 해당 서브 계정 옆의 **편집** 버튼을 클릭해요.

   ![서브 계정을 검색하고 편집 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058881203/original/sPP_1x6iIIAPK6rRXIhx_EuxIEKcotlngg.png?1763657676)

5. **일반 설정** 탭에서 다음 중 하나를 골라요.

   - **숨기기**: 해당 서브 계정에서 **템플릿 라이브러리** 전체를 숨겨요.
   - **표시**: **템플릿 라이브러리** 전체를 보여 줘요.
   - **특정 상품에 대해 숨기기**: 선택 창이 열려요. 퍼널, 웹사이트, 스토어, 폼 등 모듈별로 보이는 범위를 제한할 수 있어요.

   ![일반 설정 탭에서 표시 방식 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058881555/original/PmMdOhHtn1gLIUvNyEXZp1Dg8K4vyWSD3w.png?1763657902)

6. 카테고리별로 편집하려면 **카테고리** 탭을 클릭해요. 상품 드롭다운(예: **웹사이트**, **퍼널**, **이메일**)에서 표시 설정을 바꿀 상품을 골라요. 그런 다음 아래 방법을 쓸 수 있어요.

   - **Hide all Categories**(모든 카테고리 숨기기)를 켜면 선택한 상품의 카테고리를 모두 숨겨요.
   - 카테고리별 **숨기기** 슬라이더를 켜면 해당 상품의 특정 카테고리만 숨겨요.

   ![카테고리 탭에서 상품별 카테고리 숨기기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058885559/original/f4FbJQ_x2nRg-1z2hFn8FqsmHwXZyLImmA.png?1763661950)

## 자주 묻는 질문

### 라이브러리를 숨기면 에이전시 사용자도 접근할 수 없나요?
아니요. 에이전시 사용자와 관리자는 모든 서브 계정에서 항상 **템플릿 라이브러리**를 볼 수 있어요.

### 이 설정이 시스템 이메일 템플릿에도 영향을 주나요?
아니요. **시스템 이메일** 템플릿은 항상 보여요.

### 여러 서브 계정에 같은 표시 설정을 한 번에 적용할 수 있나요?
지금은 할 수 없어요. 서브 계정마다 따로 설정해 주세요.

### 이미 템플릿으로 만든 자산에도 영향이 있나요?
아니요. 라이브러리를 숨기면 새 템플릿을 둘러보거나 가져오는 것만 제한돼요. 서브 계정에서 이미 템플릿으로 만든 자산은 계속 편집할 수 있어요.
