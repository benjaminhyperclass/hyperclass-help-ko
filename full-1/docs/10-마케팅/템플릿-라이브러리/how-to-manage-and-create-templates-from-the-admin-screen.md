# 관리자 화면에서 템플릿 만들고 관리하기

에이전시 관리자는 서브 계정을 오가지 않고도 에이전시 화면의 **템플릿 라이브러리**에서 바로 커스텀 템플릿을 만들 수 있어요. 템플릿을 만들려면 원본 서브 계정과 상품을 고르고, 미리 본 뒤 필요하면 이름을 바꿔요. 그다음 초안으로 저장하거나 게시하세요.

[동영상](https://www.youtube.com/embed/P2cVU4Htx7A?&wmode=opaque)

{% hint style="info" %}
커스텀 템플릿 만들기는 Pro 플랜을 쓰는 에이전시 관리자 계정만 쓸 수 있어요.
{% endhint %}

전체 단계별 안내는 [커스텀 템플릿을 템플릿 라이브러리에 추가하기](../add-custom-templates-to-template-library.md)를 참고하세요.

## 달라진 점

- 바로 만들기: 이제 관리자 화면에서 템플릿을 바로 가져오거나 만들 수 있어요.
- 간단해진 과정: 서브 계정을 고르고, 템플릿을 미리 보고, 이름을 바꾸는 일을 한 화면에서 할 수 있어요.

## 장점

- 효율: 템플릿 관리를 한 화면에 모아서 시간을 아낄 수 있어요.
- 간편한 작업: 여러 화면과 서브 계정을 오가는 번거로움이 없어요.

## 진행 방법

1. **템플릿 라이브러리** 관리자 화면으로 이동하세요.
2. 오른쪽 위의 **만들기**를 클릭하세요.

   ![템플릿 라이브러리 관리자 화면의 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030317569/original/cl39u1YDs1XNvVqRCHgUzyGjrC-3p-gWuA.jpeg?1722539011)

3. 서브 계정, 상품, 템플릿 이름을 선택하거나 입력하세요.

   ![서브 계정, 상품, 템플릿 이름 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030317573/original/cbK-2fEL55cWRy2i37gxmYgUlTRbgWhCYg.jpeg?1722539011)

4. **계속**을 클릭해 템플릿 썸네일을 미리 확인하세요. 썸네일을 클릭하면 다른 화면에서 전체 미리보기를 볼 수 있어요.

   ![템플릿 썸네일 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030317571/original/f_VZCjc8kiolD4eGLbc278z4V0xo2iKVxQ.jpeg?1722539011)

5. 필요하면 템플릿 이름을 바꾸세요.

   ![템플릿 이름 변경 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030317572/original/L_z9YVzXBkSin-Fs7zAowrMnDtTMNfcw6Q.jpeg?1722539011)

6. **만들기**를 클릭해 마무리하세요.
7. 설명과 카테고리 같은 상세 정보를 업데이트하세요.

   ![설명과 카테고리 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030317570/original/zFh8rKDhWlM-ZjPYUiVfFgFjbPg9Q0hECQ.jpeg?1722539011)

8. **게시**하거나 **초안으로 저장**하세요.
