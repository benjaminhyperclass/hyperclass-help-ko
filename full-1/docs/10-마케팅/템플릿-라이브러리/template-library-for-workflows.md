# 워크플로우 템플릿 라이브러리 사용하기

미리 만들어진 템플릿으로 워크플로우를 빠르게 시작하는 방법을 안내해요. 처음부터 만들지 않고 필요에 맞는 템플릿을 골라 구성을 확인한 뒤 원하는 대로 고쳐 쓸 수 있어요.

## 템플릿 라이브러리란?

워크플로우용 **템플릿 라이브러리**(Template Library)는 전문가가 설계한 워크플로우 템플릿으로 자동화를 시작하게 해 주는 기능이에요. 필요에 맞는 템플릿을 고르고, 구조를 살펴본 다음 원하는 대로 수정하면 돼요. 검증된 방식 위에서 시작하므로 더 빠르게 자동화를 만들 수 있어요.

---

## 템플릿으로 워크플로우를 만들면 좋은 점

- 빠른 워크플로우 만들기: 준비된 템플릿을 활용해 몇 분 만에 새 자동화를 시작할 수 있어요.
- 검증된 모범 사례: 전문가가 설계한 템플릿을 쓰므로 오류나 비효율이 생길 위험이 줄어요.
- 꾸준한 업데이트: 새롭고 유용한 템플릿이 정기적으로 추가돼요.
- 자유로운 사용자 지정: 우리 비즈니스 방식에 맞게 템플릿을 고쳐 쓸 수 있어요.
- 낮은 학습 부담: 처음 쓰는 사용자나 워크플로우 만드는 방식을 통일하려는 팀에 알맞아요.
- 시간 절약: 반복되는 설정 작업을 줄이고 더 중요한 일에 집중할 수 있어요.

---

## 템플릿 라이브러리 사용 방법

아래 순서대로 따라 하면 템플릿 라이브러리를 제대로 활용하고, 설정 중 흔한 문제도 피할 수 있어요.

### 1단계: 템플릿 라이브러리 열기

**템플릿 라이브러리** 창에는 미리 보고 수정해 쓸 수 있는 워크플로우 템플릿이 모여 있어요.

1. 왼쪽 메뉴에서 **자동화**(Automation)를 클릭하세요.
2. **워크플로우** 탭으로 이동하세요.
3. **Create Workflow**(워크플로우 만들기)를 클릭하세요.
4. **Select from Template**(템플릿에서 선택)을 선택하세요.

![템플릿 라이브러리를 여는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048998068/original/kHL7BwDSKtkObJ3-wevhRnvnnmfgO3EMOA.gif?1751034241)

### 2단계: 템플릿 둘러보고 필터링하기

카테고리를 둘러보거나 필터를 적용하거나 키워드로 검색해 알맞은 워크플로우를 빠르게 찾을 수 있어요. **필터** 패널에서 카테고리(예: 리드 육성, 온보딩)별로 범위를 좁혀 보세요. 키워드로 검색하거나 인기순으로 정렬할 수도 있어요. 템플릿 카드 위에 마우스를 올리면 간단한 설명이 보여요.

![템플릿을 둘러보고 필터링하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048998356/original/7BpKXc4Dg3lmt8YFjtaYNFHsipVJQCLPfA.gif?1751034449)

### 3단계: 템플릿 미리 보고 선택하기

워크플로우를 불러오기 전에 설명, 사전 요구 사항, 전체 캔버스를 살펴보고 내게 맞는지 확인하세요.

1. **눈 모양 아이콘**이나 템플릿 카드를 클릭해 미리보기를 여세요.
2. **About this Template**(템플릿 소개) 설명을 읽고 **Prerequisites**(사전 요구 사항)가 있는지 확인하세요.
3. 트리거와 액션이 모두 담긴 캔버스 전체를 살펴보며 흐름을 이해하세요.
4. 준비가 되면 **계속**을 클릭해 워크플로우 편집기로 불러오세요.

![템플릿을 미리 보고 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048998600/original/YUZWWgRWeY7UfmSlFZj7wgEUVnBzcd0ipQ.gif?1751034683)

{% hint style="info" %}
워크플로우 편집기에서 트리거, 액션, 대기 시간, 조건을 업무 방식에 맞게 수정하세요. 샘플 연락처나 태그로 테스트해 제대로 동작하는지 확인한 뒤 저장하고 워크플로우를 활성화하세요.
{% endhint %}

## 활용 팁과 모범 사례

1. 템플릿 관리와 업데이트

- 최신 상태 유지: 새로 추가되거나 개선된 템플릿이 있는지 라이브러리를 정기적으로 확인하세요.
- 의견 보내기: 아이디어나 개선 사항은 하이퍼클래스 고객지원을 통해 보내 주세요.

2. 우리 비즈니스에 맞게 수정하기

- 로직 조정: 단계를 추가하거나 빼고, 메시지를 바꾸고, 타이밍을 조정하세요.
- 충분히 테스트: 전체를 활성화하기 전에 **임시 저장** 상태에서 일부 대상으로 먼저 실행해 보세요.

3. 팀과 함께 쓰기

- 템플릿 공유: 자주 쓰는 템플릿을 즐겨찾기하거나 링크를 공유하면 팀원이 표준화된 워크플로우를 다시 쓸 수 있어요.
- 교육 도구: 새 직원에게 자동화 모범 사례를 알려 줄 때 템플릿을 활용하세요.

## 자주 묻는 질문

### 직접 템플릿을 만들 수 있나요?

아직은 이 기능을 사용할 수 없어요.

### 템플릿을 선택한 뒤에도 수정할 수 있나요?

네. 워크플로우 편집기로 불러온 뒤에는 모든 항목을 수정할 수 있어요.

### 새 템플릿도 추가되나요?

네. 사용자 의견과 업계 모범 사례를 바탕으로 라이브러리를 계속 늘려 가고 있어요.

### 템플릿 라이브러리를 사용하면 기존 워크플로우에 영향이 있나요?

아니요. 지금 쓰고 있는 자동화는 그대로 유지돼요.

### 수정한 내용을 되돌릴 수 있나요?

처음부터 다시 시작하려면 원래 템플릿을 다시 선택하세요.
