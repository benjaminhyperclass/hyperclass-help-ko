# SMS 키워드 옵트인 캠페인 만들기

고객이 키워드를 문자로 보내면 원하는 혜택이나 정보를 받을 수 있는 SMS 키워드 캠페인을 만드는 방법을 안내해요. 하이퍼클래스에서는 워크플로우가 키워드를 알아보고 자동으로 SMS 답장을 보내요. 요청 내역을 태그로 추적하고, 같은 연락처가 워크플로우를 다시 실행할 수 있는지도 정할 수 있어요. 설정 방법, 동의 관련 유의 사항, 테스트 방법, 자주 겪는 문제를 함께 다뤄요.

## SMS 옵트인 캠페인이란?

SMS 키워드 캠페인은 문자 보내기(text-in) 캠페인이라고도 해요. 연락처가 `COUPON` 같은 특정 단어를 비즈니스의 SMS 사용 번호로 보내는 방식이에요. 하이퍼클래스는 **Customer Replied**(고객 답장) 워크플로우 트리거와 SMS 키워드 필터로 조건에 맞는 수신 메시지를 찾아내고, 설정해 둔 액션을 실행해요. 트리거 자체가 궁금하다면 [워크플로우 트리거 — Customer Replied(고객 답장)](../../07-워크플로우/Events-Workflow-Triggers/workflow-trigger-customer-replied.md)를 참고하세요.

키워드 요청은 관련 있는 답장을 시작하게 할 수는 있지만, 관련 없는 마케팅 문자나 지속적인 마케팅 문자에 대한 동의로 자동으로 인정되지는 않아요. 화면에 보여 주는 옵트인 문구와 기록된 동의 내용은 메시징 프로그램과 일치해야 해요.

## SMS 키워드 캠페인의 장점

키워드 기반 SMS 자동화를 쓰면 고객은 혜택에 바로 응답할 수 있고, 팀은 조건에 맞는 요청을 일관되게 처리할 수 있어요.

- 간편한 참여: 인쇄물이나 디지털 혜택 안내를 본 고객이 짧은 키워드로 응답할 수 있어요.
- 빠른 응답: **Send SMS**(SMS 전송) 액션으로 요청받은 정보를 자동으로 보내요.
- 정확한 매칭: 의도한 키워드가 들어 있는 SMS에만 워크플로우가 실행되도록 제한해요.
- 요청 추적: 필요하면 연락처에 태그를 붙여 키워드 활동을 정리할 수 있어요.

## SMS 키워드 캠페인의 작동 방식

워크플로우는 수신 문자와 특정 응답을 연결해 줘요. 예를 들어 고객이 혜택 안내를 보고 안내된 번호로 `COUPON`을 보내면, 워크플로우가 키워드를 확인한 뒤 쿠폰 정보를 보내요.

다른 채널의 답장을 제외하려면 **Reply Channel**(답장 채널)을 **SMS**로 설정하세요. 수신 메시지에 키워드만 들어 있어야 한다면 **Exact Match Phrase**(정확히 일치하는 문구)를 쓰세요. **Contains Phrase**(문구 포함)는 더 긴 메시지에도 일치할 수 있어서, 의도하지 않은 문자에 실행될 수 있어요.

{% hint style="warning" %}
STOP이나 HELP처럼 표준 메시지 관리용 단어는 프로모션 키워드로 쓰지 마세요.
{% endhint %}

## SMS 키워드 캠페인 요구 사항

워크플로우를 만들기 전에 수신 번호와 동의 절차를 확인하세요. 키워드 메시지 누락, 답장 차단, 메시징 정책 문제를 미리 막을 수 있어요.

- SMS 사용 번호: 하이퍼클래스 서브 계정에 할당되어 있고, SMS 수신과 발신을 모두 지원하는 전화번호를 쓰세요.
- 메시징 등록: 번호와 대상 국가에 해당하는 등록 또는 인증을 마치세요. 미국에서 10자리 로컬 번호로 비즈니스 메시지를 보낸다면, 그 번호가 승인된 A2P 캠페인에 연결되어 있는지 확인하세요. 자세한 내용은 [2026년 전화번호 A2P 승인받기](../../15-전화-시스템/how-to-get-your-phone-number-a2p-approved-in-2026.md)를 참고하세요.
- 명확한 행동 유도 문구: 비즈니스 이름, 키워드를 보내면 무엇을 요청하는 것인지, 메시지 발송 빈도·요금·도움말·옵트아웃·정책 안내를 프로그램에 맞게 밝히세요.
- 동의 및 옵트아웃 처리: 연락처의 동의 범위와 등록한 사용 목적에서 허용하는 메시지만 보내세요. STOP 요청과 기존 SMS 수신거부(DND) 제한을 지켜야 해요. SMS 규정 준수 설정은 [SMS 규정 준수 설정 구성하기](../../15-전화-시스템/LC-Phone/how-to-configure-sms-compliance-settings.md)에서 확인하세요.

1회성 혜택 초대 문구 예시예요. 실제 메시징 프로그램과 관련 요건에 맞게 고쳐 쓰세요.

```
[비즈니스 번호]로 COUPON을 보내 주시면 [비즈니스명]의 1회 한정 혜택을 안내해 드려요. 메시지 및 데이터 요금이 부과될 수 있어요. 도움말은 HELP, 수신 중단은 STOP을 보내 주세요. [이용약관/개인정보 링크]
```

{% hint style="warning" %}
연락처 태그를 붙이거나 수신 키워드를 받았다고 해서 추가 마케팅 캠페인에 대한 동의가 성립하는 것은 아니에요. 보내려는 메시지별로 동의를 확인하고 기록하세요. 옵트아웃한 연락처의 SMS 수신거부(DND)를 자동으로 해제하지 마세요.
{% endhint %}

## SMS 키워드 캠페인 설정하기

필터를 건 **Customer Replied** 트리거를 쓰면 원하는 SMS 키워드에만 워크플로우가 응답해요. 짧은 답장을 연결하고, 메시지 내용과 동의 요건을 확인한 뒤에 워크플로우를 게시하세요.

1. **자동화 > 워크플로우**로 이동해 워크플로우를 만들고 **처음부터 시작**을 선택하세요.
2. **Add New Trigger**(새 트리거 추가)를 선택하고 **Customer Replied**(고객 답장)를 고른 뒤, 트리거에 알아보기 쉬운 이름을 붙이세요.
3. **Add Filters**(필터 추가)를 클릭하고 **Reply Channel**(답장 채널)을 **SMS**로 설정하세요.
4. **Exact Match Phrase**(정확히 일치하는 문구)를 추가하고 캠페인 키워드(예: `COUPON`)를 입력한 뒤 **Save Trigger**(트리거 저장)를 선택하세요.

![트리거에 SMS 답장 채널과 정확히 일치하는 키워드 필터를 설정한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083460610/original/1jRO3uI-3DRnAenWnqqwxydGsNA3d7o6ww.png?1792109697)

5. 트리거 아래에 **Send SMS** 액션을 추가하세요. 요청에 맞는 답장을 입력하고 비즈니스 이름도 넣으세요. 예: "COUPON 문자를 보내 주셔서 감사해요! 요청하신 혜택을 안내해 드려요: [혜택 내용] — [비즈니스명]. 수신 중단은 STOP을 보내 주세요." 입력을 마치면 **Save Action**(액션 저장)을 클릭하세요. 액션 설정은 [워크플로우 액션 — Send SMS(SMS 전송)](../../07-워크플로우/Communication-Workflow-Actions/workflow-action-send-sms.md)에서 자세히 볼 수 있어요.
6. (선택) 요청을 추적하려면 `coupon-requested`처럼 설명이 되는 태그로 **Add Contact Tag**(연락처 태그 추가) 액션을 추가하세요. 이 태그는 활동 기록용이고, 마케팅 동의의 증거는 아니에요. 자세한 내용은 [워크플로우 액션 — Add Contact Tag(연락처 태그 추가)](../../07-워크플로우/Contact-Workflow-Actions/workflow-action-add-contact-tag.md)를 참고하세요.
7. 워크플로우 설정에서 **Allow Re-entry**(재진입 허용)를 확인하세요. 같은 연락처가 이전 실행을 마친 뒤에 워크플로우를 다시 실행할 수 있어야 할 때만 켜세요.
8. 테스트와 사용 준비가 끝나면 워크플로우를 저장하고 **Publish**(게시)를 클릭하세요.

![워크플로우에 Send SMS 액션과 선택 태그 액션을 추가하고 게시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083460687/original/EUOHZM9oezZhvfIHMMzI65OoNdqEVuF7nQ.png?1792109905)

## SMS 키워드 워크플로우 테스트하기

**Send SMS** 액션만 테스트하면 발송되는 메시지만 확인할 수 있어요. 트리거, 매칭 필터, 전체 자동화가 함께 제대로 작동하는지는 실제로 키워드를 보내 봐야 알 수 있어요.

1. 본인이 쓰는 전화번호로 비즈니스 SMS 번호에 정확한 키워드를 문자로 보내세요. 신규 연락처를 대상으로 한 혜택이라면, 비즈니스와 대화한 적이 없는 전화번호로도 테스트하세요.
2. **대화**에서 수신 SMS가 도착했는지 확인하세요. 수신 문자를 알림으로 받고 싶다면 [워크플로우로 수신 SMS 알림 보내기](../../15-전화-시스템/메시징/how-to-send-inbound-sms-notifications-via-a-workflow.md)를 참고하세요.
3. 워크플로우의 **Execution Logs**(실행 로그)에서 해당 연락처의 실행 내역과 건너뛰거나 실패한 단계가 있는지 확인하세요.
4. 예상한 자동 답장이 도착하는지, 선택 사항인 추적 태그가 적용됐는지 확인하세요.
5. 다른 키워드를 보내서 관련 없는 메시지에는 워크플로우가 응답하지 않는지 확인하세요. 해당하는 경우 반복 진입 동작도 확인하세요.

## SMS 키워드 캠페인 문제 해결

캠페인이 기대대로 응답하지 않으면 수신 전달, 트리거 대상 여부, 발신 전달을 따로 점검해서 원인을 찾으세요.

- **대화**에 수신 SMS가 보이지 않아요: 고객이 올바른 SMS 사용 비즈니스 번호로 문자를 보냈는지, 수신 메시징이 활성 상태인지 확인하세요.
- SMS는 도착했는데 워크플로우가 실행되지 않아요: 워크플로우가 게시되어 있는지, **Reply Channel**이 SMS인지, 키워드가 **Exact Match Phrase** 필터와 일치하는지, 연락처가 다시 진입할 수 있는 상태인지 확인하세요.
- 워크플로우는 실행됐는데 답장이 오지 않아요: **Send SMS** 액션, 워크플로우 실행 오류, SMS 수신거부(DND) 또는 옵트아웃 상태, 해당 메시징 등록과 발송 제한을 확인하세요.
- 답장이 두 번 이상 가요: 같은 키워드를 쓰는 다른 게시된 워크플로우가 있는지, 반복 진입 설정이 어떻게 되어 있는지 확인하세요.

## 자주 묻는 질문

### "COUPON please"라고 보내도 "COUPON"과 정확히 일치하도록 필터를 건 워크플로우가 실행되나요?

아니요. **Exact Match Phrase**는 지정한 문구와 일치하는 답장을 대상으로 해요. 더 긴 메시지도 대상에 포함하려면 **Contains Phrase**를 쓰고, 의도하지 않은 문자에 일치하지 않는지 테스트하세요.

### 키워드를 다르게 해서 혜택을 따로 운영할 수 있나요?

네. 필터를 건 워크플로우 경로나 워크플로우를 따로 만들어 각각 알맞은 키워드와 응답 액션을 설정하세요. 그러면 요청마다 맞는 답장이 가요.

### 쿠폰을 요청한 모든 사람에게 앞으로 프로모션 문자를 보내도 되나요?

자동으로 되는 것은 아니에요. 지속적인 마케팅 프로그램에 대한 유효한 동의가 있어야 하고, 적절한 고지와 옵트아웃 처리도 갖춰야 해요. 1회성 키워드 요청은 관련 없는 메시지를 모두 보내도 된다는 포괄적인 허락이 아니에요.

### 다시 찾아온 고객에게 두 번째 응답이 가지 않는 이유는 무엇인가요?

**Allow Re-entry** 설정과, 해당 연락처가 이전 워크플로우 실행을 마쳤는지 확인하세요. 같은 실행에 아직 진행 중인 연락처는 다시 진입할 수 없어요.

### 이 워크플로우에 연락처를 추가하기만 하면 SMS 옵트아웃이 해제되나요?

아니요. 태그나 워크플로우 설정으로 SMS 수신거부(DND)나 옵트아웃 제한을 우회하지 마세요. 연락처가 해당하는 유효한 재옵트인 절차를 거친 뒤에야 발신 메시지를 다시 보낼 수 있어요.
