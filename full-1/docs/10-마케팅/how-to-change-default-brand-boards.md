# 기본 브랜드 보드 변경

기본 브랜드 보드는 이메일과 퍼널에서 브랜드의 시각적 정체성을 관리할 때 핵심이 되는 설정이에요. 색상 선택기와 글꼴 선택기에 어떤 색상과 글꼴 세트가 나타날지 정하기 때문에, 브랜드 요소를 바로 찾아 쓸 수 있어요. 이 문서에서 기본 브랜드 보드의 개념과 변경 방법을 알아보세요.

## 기본 브랜드 보드란?

브랜드 보드에는 색상, 글꼴, 로고 같은 핵심 시각 요소가 저장돼 있어요. 덕분에 일관된 스타일을 적용할 수 있어요. 브랜드 보드 하나를 기본으로 지정하면 편집기와 선택기에 어떤 브랜드 가이드라인을 보여 줄지 정해져요. 디자인 작업이 빨라지고 실수도 줄어요. 처음 만든 브랜드 보드는 자동으로 기본 브랜드 보드가 돼요.

아래는 사이트 편집기 안에 표시된 기본 브랜드 보드 색상의 예시예요. 브랜드 가이드라인에 맞춰 사이트 디자인을 쉽게 유지할 수 있어요.

## 기본 브랜드 보드를 바꿔야 할 때

- 가이드라인이 바뀌었을 때: 새 색상이나 로고 등 브랜드 가이드라인이 크게 바뀌면 기본 보드를 바꾸세요. 그래야 모든 자료와 커뮤니케이션이 최신 브랜딩에 맞춰져요.
- 특별한 시기나 주제가 있을 때: 크리스마스용 빨간색 테마처럼 시즌이나 행사에 맞는 브랜딩을 적용하고 싶을 때도 기본 보드를 바꿀 수 있어요. 다만 이런 경우에는 기본 보드를 바꾸기보다 별도의 테마나 템플릿을 만드는 편이 더 효과적일 수 있어요. 그러면 기본 보드와 테마 보드를 필요할 때 쉽게 오갈 수 있어요.

## 기본 브랜드 보드 변경하기

기본 브랜드 보드는 간단하게 바꿀 수 있어요.

#### 1단계: 브랜드 보드로 이동

1. 왼쪽 메뉴에서 **마케팅**(Marketing)을 선택하세요.
2. 상단 메뉴에서 **브랜드 보드** 탭을 선택하세요.

![마케팅 메뉴의 브랜드 보드 탭](https://jumpshare.com/share/M5pxOaj2p2LLhF8C5MHQ+/Screen+Shot+2026-09-23+at+19.47.48.png)

#### 2단계: 보드를 기본으로 설정

1. 기본으로 지정할 브랜드 보드를 찾으세요.
2. 해당 브랜드 보드 옆의 점 세 개 아이콘을 클릭하세요.
3. **기본값으로 설정**을 선택하세요.

![브랜드 보드 옆 메뉴에서 기본값으로 설정 선택](https://jumpshare.com/share/xJKPWkCThN9mEsBsyRce+/Screen+Shot+2026-09-23+at+19.49.56.png)

#### 3단계: 편집 화면에서 설정

브랜드 보드를 편집하는 중에도 기본으로 지정할 수 있어요.

- 기본으로 지정할 브랜드 보드를 클릭해 편집기를 여세요.
- 오른쪽 위의 **기본값으로 설정** 버튼을 클릭하세요.

![편집기 오른쪽 위의 기본값으로 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031779794/original/as0Wtkew_62Vg8xEbrCI1rQQDXI_oQ8yUA.png?1724823372)

#### 4단계: 기본 보드 확인

- 기본으로 지정된 브랜드 보드에는 상태로 **기본**이 표시돼요.
- 편집기를 열어 선택한 브랜드 색상이 나타나는지 확인할 수도 있어요.

![기본 상태가 표시된 브랜드 보드와 편집기의 브랜드 색상](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053030180/original/LtcdBbmOvxbrp0bFlkK8y5H7gGy3NW9Fjw.jpeg?1756913959)

## 자주 묻는 질문

### 나중에 기본 브랜드 보드를 다시 바꿀 수 있나요?

네, 가능해요. 다른 브랜드 보드에서 같은 순서를 반복해 그 보드를 기본으로 설정하면 돼요. 기본 브랜드 보드는 언제나 하나만 지정할 수 있다는 점에 유의하세요.

### 아직 브랜드 보드가 하나도 없어요. 어떻게 하나요?

먼저 브랜드 보드를 하나 만드세요. 만든 보드는 자동으로 기본 브랜드 보드가 돼요. 브랜드 보드를 만드는 방법은 '브랜드 보드 만들기' 문서를 참고하세요.

### 기본 브랜드 보드를 바꾸면 기존 이메일과 페이지도 자동으로 바뀌나요?

아니요. 앞으로 새로 편집하거나 이후에 편집할 때 선택기에 가장 먼저 표시되는 항목만 바뀌어요. 기존 자산은 직접 편집하기 전까지 현재 스타일을 그대로 유지해요. 기본 브랜드 보드를 바꿔도 자산은 변경되지 않아요.
