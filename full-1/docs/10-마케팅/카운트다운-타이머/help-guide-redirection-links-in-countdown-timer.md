# 카운트다운 타이머의 리디렉션 링크

카운트다운 타이머의 리디렉션 링크를 쓰면 타이머가 진행 중인지 만료됐는지에 따라 연락처가 가는 페이지를 나눌 수 있어요. **Active Link**(활성 링크)와 **Expired Link**(만료 링크)를 설정하고 타이머의 **Redirection Link**(리디렉션 링크)를 버튼이나 이미지에 연결하면, 오퍼가 유효한지 여부에 맞춰 CTA가 자동으로 안내해 줘요. 기간 한정 오퍼, 등록 마감, 예약 프로모션처럼 만료 후 접근 경로가 달라져야 하는 캠페인에 유용해요.

## 카운트다운 타이머 리디렉션 링크란?

리디렉션 링크는 카운트다운의 현재 상태에 따라 이동할 곳이 달라지는 조건부 링크예요. 오퍼가 끝날 때마다 캠페인 링크를 직접 바꿀 필요가 없어요. 하이퍼클래스가 타이머 상태를 확인해서 연락처를 알맞은 **Active Link** 또는 **Expired Link** 주소로 보내 줘요.

세 가지 링크가 함께 동작해요.

- **Active Link**(활성 링크): 카운트다운이 진행 중일 때 연락처가 가야 할 주소예요.
- **Expired Link**(만료 링크): 타이머가 만료된 뒤 연락처가 가야 할 주소예요.
- **Redirection Link**(리디렉션 링크): 타이머의 현재 상태를 확인한 뒤 연락처를 **Active Link** 또는 **Expired Link**로 보내는 조건부 링크예요.

예를 들어 프로모션 이메일의 "오퍼 받기" 버튼에 **Redirection Link**를 연결해 볼게요. 타이머가 진행 중이면 이 버튼은 오퍼 페이지로 연결돼요. 만료된 뒤에는 같은 버튼이 오퍼 종료 안내 페이지나 대기자 명단 페이지로 연결될 수 있어요.

### 리디렉션 링크를 쓰면 좋은 점

타이머가 만료될 때 링크를 직접 교체하지 않아도 캠페인의 이동 경로가 카운트다운 상태와 맞아요.

- **자동 연결**: 타이머가 진행 중인지 만료됐는지에 따라 연락처가 알맞은 주소로 이동해요.
- **일관된 캠페인 경험**: 버튼, 이미지, 텍스트 링크가 카운트다운과 같은 기준으로 동작해요.
- **수동 수정 감소**: 같은 **Redirection Link**를 만료 전후에 그대로 쓸 수 있어서 CTA 주소를 직접 바꿀 필요가 없어요.
- **만료 후 대응**: 마감 뒤에 클릭한 연락처를 대기자 명단, 오퍼 종료 안내 페이지, 다른 프로모션 등 적절한 곳으로 보낼 수 있어요.
- **유연한 배치**: 타이머 상태에 맞춘 이동이 필요한 CTA 중 지원되는 곳에 자유롭게 쓸 수 있어요.

## Active Link, Expired Link, Redirection Link의 동작 방식

**Active Link**와 **Expired Link**는 타이머에 연결된 이동 주소를 정하고, **Redirection Link**는 연락처가 그중 어느 주소로 갈지 결정해요. 이 관계를 이해해 두면 연락처가 캠페인 CTA를 통해 이미 끝난 오퍼에 들어가는 일을 막을 수 있어요.

### Active Link

**Active Link**는 카운트다운이 진행되는 동안 사용하는 이동 주소예요.

주로 이런 페이지를 연결해요.

- 기간 한정 오퍼 페이지
- 등록 페이지
- 결제 페이지
- 예약 페이지
- 프로모션 퍼널 단계

예를 들어 타이머가 끝나면 등록이 마감되는 오퍼라면, **Active Link**에 등록 페이지 주소를 넣을 수 있어요.

### Expired Link

**Expired Link**는 카운트다운이 만료된 뒤에 사용하는 이동 주소예요.

주로 이런 페이지를 연결해요.

- 오퍼 종료 안내 페이지
- 대기자 명단 페이지
- 다른 프로모션 페이지
- 일반 안내 페이지
- 다음 이벤트 등록 페이지

**Expired Link**를 설정해 두면 마감 후에 돌아온 연락처가 더 이상 유효하지 않은 오퍼로 이동하지 않아요.

### Redirection Link

**Redirection Link**는 연락처와 설정해 둔 이동 주소 사이에서 조건에 따라 길을 나누는 URL이에요.

연락처가 **Redirection Link**를 클릭하면 이렇게 동작해요.

1. 하이퍼클래스가 연결된 타이머의 상태를 확인해요.
2. 타이머가 진행 중이면 연락처를 **Active Link**로 보내요.
3. 타이머가 만료됐으면 연락처를 **Expired Link**로 보내요.

타이머 상태에 따라 최종 이동 주소는 달라지지만, **Redirection Link** 자체는 그대로 둘 수 있어요.

## 링크 복사, Redirection Link, 코드 복사

하이퍼클래스에는 타이머와 관련된 공유 옵션이 여러 가지 있고, 각각 용도가 달라요. 이동 경로를 제어할지, 카운트다운 자체를 보여 줄지에 따라 알맞은 옵션을 고르세요.

### Redirection Link

버튼, 이미지, 텍스트 CTA가 타이머의 현재 상태에 따라 다른 주소로 연락처를 보내야 할 때 **Redirection Link**를 사용하세요.

이런 경우에 쓸 수 있어요.

- 이메일의 "오퍼 받기" 버튼
- 링크를 건 프로모션 이미지
- "지금 등록하기" 같은 텍스트 링크
- 시간이 중요한 캠페인에 연결된 CTA

### 링크 복사

타이머 유형과 타이머를 사용하는 위치에 따라 하이퍼클래스가 타이머와 관련된 **링크 복사** 기능을 제공할 수 있어요.

사용할 수 있는 링크 옵션은 타이머 유형과 배치 위치에 따라 달라요. 이메일 안에서 동적 카운트다운 타이머를 쓴다면 **이메일 빌더**의 타이머 설정에서 알맞은 리디렉션 링크를 가져오세요.

### 코드 복사

**코드 복사**는 카운트다운 타이머 자체를 외부 웹사이트나 플랫폼에 삽입해서 보여 줄 때 써요.

**코드 복사**와 **Redirection Link**는 용도가 달라요.

- **코드 복사**: 카운트다운을 화면에 보여 줘요.
- **Redirection Link**: 연락처가 CTA를 클릭했을 때 카운트다운 상태에 따라 어디로 갈지 정해요.

동적 카운트다운 타이머를 하이퍼클래스 밖에 삽입할 때는 추가 설정값이 필요할 수 있어요. 외부에 적용하기 전에 [카운트다운 타이머의 코드 복사 기능 사용하기](how-to-use-the-copy-code-feature-in-countdown-timers.md) 문서를 먼저 확인하세요.

## 리디렉션 링크를 쓸 수 있는 곳

CTA가 카운트다운과 같은 마감 기한을 따라야 하는 곳이라면 어디서든 리디렉션 링크가 유용해요. 이메일, 퍼널, 웹사이트 등 사용하는 채널에 따라 적용 방법은 조금씩 달라요.

### 이메일

이메일 안의 다음과 같은 CTA에 **Redirection Link**를 적용할 수 있어요.

- 버튼
- 이미지
- 링크를 건 텍스트

흔히 쓰는 방식은 이메일에 카운트다운 타이머를 넣고, 핵심 CTA에 해당 타이머의 **Redirection Link**를 연결하는 거예요.

예를 들면 이래요.

- 타이머 진행 중 → "지금 구매하기" 버튼이 연락처를 세일 페이지로 보내요.
- 타이머 만료 → 같은 "지금 구매하기" 버튼이 연락처를 오퍼 종료 안내 페이지로 보내요.

### 퍼널과 웹사이트

퍼널과 웹사이트에서는 페이지에 카운트다운 타이머 요소를 직접 넣을 수 있어요. 타이머가 만료됐을 때의 동작도 페이지 설정에서 정할 수 있어요.

이메일과 도착 페이지를 함께 운영한다면, 가능한 경우 같은 타이머 설정을 사용하세요. 그러면 이메일과 도착 페이지에 표시되는 마감 시간이 서로 맞아요.

페이지에 표시되는 타이머와 CTA의 **Redirection Link**는 관련은 있지만 역할이 달라요.

- 타이머는 카운트다운 상태를 보여 주거나 추적해요.
- **Redirection Link**는 연락처가 링크가 걸린 CTA를 클릭했을 때 알맞은 이동 주소를 정해요.

페이지별 자세한 설정은 [퍼널에서 카운트다운 타이머 사용하기](how-to-use-countdown-timers-in-funnels.md) 문서를 참고하세요.

### 외부 플랫폼

하이퍼클래스 밖에서 카운트다운을 보여 줘야 한다면, 지원되는 곳에서 타이머의 **코드 복사** 기능을 사용하세요.

외부 캠페인에서도 타이머 상태에 따른 CTA 이동이 필요하다면, 삽입 코드와는 별도로 알맞은 **Redirection Link**를 사용해야 해요.

## 동적 카운트다운 타이머에서 리디렉션 링크 사용하기

동적 카운트다운 타이머는 연락처마다 다른 카운트다운을 보여 주기 때문에, 링크도 각 타이머의 상태에 맞게 동작해야 해요. 이메일을 열거나 클릭한 시점부터 타이머가 시작될 때 특히 중요해요.

이메일에서 동적 카운트다운 타이머를 쓰는 순서는 이래요.

1. 이메일에 동적 카운트다운 타이머를 추가해요.
2. **이메일 빌더**에서 타이머 설정을 열어요.
3. 사용할 수 있는 **Redirection Link**를 복사해요.
4. 복사한 링크를 알맞은 버튼, 이미지, 텍스트 CTA에 적용해요.
5. 캠페인을 보내기 전에 진행 중일 때와 만료됐을 때의 이동 주소를 각각 테스트해요.

동적 카운트다운 타이머의 **Redirection Link**를 외부에 삽입할 때 쓰는 **코드 복사** 옵션과 헷갈리지 마세요.

## 반복 카운트다운 타이머에서 리디렉션 링크 사용하기

반복 카운트다운 타이머는 카운트다운이 진행되는 기간과 대기 기간을 번갈아 가며 반복해요. 그래서 이동 주소를 설정하고 캠페인 링크를 테스트할 때 만료 시 동작을 따로 고려해야 해요.

반복 타이머가 대기 상태인 동안에는 다음 카운트다운이 시작될 때까지 연락처가 만료 상태로 처리될 수 있어요.

그래서 이렇게 해 주세요.

- 알맞은 **Expired Link**를 설정하세요.
- 진행 중일 때와 대기 중일 때 모두 타이머를 테스트하세요.
- 캠페인을 공개하기 전에 연락처가 예상한 주소로 이동하는지 확인하세요.

대기 상태의 동작에 대한 자세한 내용은 Recurring Timer Wait Time 문서를 참고하세요.

## 카운트다운 타이머 리디렉션 설정하기

설정을 제대로 해 두면 카운트다운이 끝나기 전에도, 끝난 뒤에도 캠페인 CTA가 연락처를 올바른 곳으로 안내해요. 두 가지 상태의 이동 주소를 모두 설정하고, 캠페인을 시작하기 전에 생성된 **Redirection Link**를 테스트하세요.

1. **마케팅 > 카운트다운 타이머**로 이동해요.
2. 새 타이머를 만들거나 기존 타이머를 열어요.
3. 타이머 유형, 기간, 만료 시 동작 등 필요한 설정을 해요.
4. **Active Link**를 입력해요.

   타이머가 진행되는 동안 연락처가 접속해야 할 URL을 넣으세요.

   예시:

   `https://yourdomain.com/offer`
5. **Expired Link**를 입력해요.

   타이머가 만료된 뒤 연락처가 접속해야 할 URL을 넣으세요.

   예시:

   `https://yourdomain.com/offer-expired`

   ![Active Link와 Expired Link 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082137544/original/M4DzLcLJNz2lbzJU7LLFGrsA8cWb4hCJRQ.png?1790700536)
6. 타이머를 저장해요.
7. 타이머를 알맞은 이메일, 퍼널, 웹사이트 또는 지원되는 캠페인에 추가해요.
8. 해당 타이머 또는 빌더 설정에서 사용할 수 있는 **Redirection Link**를 복사해요.
9. 복사한 **Redirection Link**를 해당 CTA에 적용해요.

   다음과 같은 요소에 적용할 수 있어요.

   - 버튼
   - 이미지
   - 텍스트 링크
   - 그 밖에 지원되는 클릭 가능한 요소
10. 타이머가 진행 중일 때 CTA를 테스트해요.

    **Active Link**로 이동하는지 확인하세요.
11. 만료된 상태에서도 테스트해요.

    카운트다운이 만료된 뒤 같은 CTA가 **Expired Link**로 이동하는지 확인하세요.

## 카운트다운 타이머 리디렉션 테스트하기

타이머의 두 가지 상태를 모두 테스트하면 연락처가 이미 끝난 오퍼나 잘못된 페이지로 가는 일을 막을 수 있어요. 타이머가 제대로 표시되더라도 **Active Link**나 **Expired Link**가 잘못 설정되어 있으면 캠페인 경험이 나빠질 수 있어요.

캠페인을 게시하거나 보내기 전에 아래 항목을 확인하세요.

- **Active Link**가 의도한 오퍼나 페이지로 열려요.
- **Expired Link**가 만료 후에 보여 줄 올바른 페이지로 열려요.
- 의도한 CTA에 **Redirection Link**를 사용했어요.
- **Redirection Link**를 쓴 버튼, 이미지, 텍스트 링크가 모두 올바르게 이동해요.
- 타이머와 도착 페이지의 만료 시 동작이 서로 일치해요.
- 동적 카운트다운 타이머는 의도한 트리거로 테스트했어요.
- 반복 카운트다운 타이머는 진행 중일 때와 대기 중일 때 모두 테스트했어요.
- 외부에 적용할 때는 **코드 복사**를 **Redirection Link** 설정과 별도로 사용했어요.

## 자주 묻는 질문

### Active Link와 Redirection Link는 뭐가 다른가요?

**Active Link**는 타이머가 진행 중일 때 연락처가 도착하는 주소예요. **Redirection Link**는 연락처가 클릭하는 조건부 URL이에요. 하이퍼클래스가 타이머 상태를 확인해서 연락처를 **Active Link** 또는 **Expired Link**로 보내 줘요.

### 타이머가 만료되면 Redirection Link도 바뀌나요?

**Redirection Link**는 그대로 둘 수 있어요. 타이머가 진행 중인지 만료됐는지에 따라 연락처가 이동하는 주소만 달라져요.

### 같은 Redirection Link를 여러 CTA에 써도 되나요?

네, 같은 타이머 상태와 이동 규칙을 따라야 하는 요소라면 지원되는 여러 CTA에 같은 **Redirection Link**를 쓸 수 있어요.

### 동적 카운트다운 타이머에도 Redirection Link를 쓸 수 있나요?

네. 이메일에서 동적 카운트다운 타이머를 쓸 때는 **이메일 빌더**의 타이머 설정에서 사용할 수 있는 **Redirection Link**를 가져와서 해당 CTA에 적용하세요.

### 코드 복사와 Redirection Link는 같은 건가요?

아니요. **코드 복사**는 카운트다운 타이머 자체를 보여 주거나 삽입할 때 써요. **Redirection Link**는 타이머 상태에 따라 연락처를 **Active Link** 또는 **Expired Link**로 보낼 때 써요.

### 타이머가 만료된 뒤에 연락처가 클릭하면 어떻게 되나요?

**Expired Link**가 올바르게 설정되어 있고 CTA에 타이머의 **Redirection Link**를 사용했다면, 연락처는 만료 후 주소로 이동해요.

### Expired Link에는 어떤 주소를 넣는 게 좋나요?

원래 오퍼가 끝난 뒤에도 쓸모 있는 페이지를 연결하세요. 오퍼 종료 안내 페이지, 대기자 명단, 다른 프로모션, 다가오는 이벤트 페이지 등이 대표적이에요.

### 반복 카운트다운 타이머는 만료된 뒤에 다르게 동작하나요?

반복 카운트다운 타이머는 카운트다운 주기 사이에 대기 상태가 될 수 있어요. 이 기간에는 다음 진행 주기가 시작될 때까지 만료 상태의 동작이 적용될 수 있어요.
