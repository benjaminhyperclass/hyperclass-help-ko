# 카운트다운 타이머 시작하기

카운트다운 타이머는 마감 시간까지 남은 시간을 보여 줘서 전환율을 높이는 데 도움이 돼요. 이 문서에서는 타이머의 종류와 쓰임새, 만드는 순서를 안내해요.

## 카운트다운 타이머란?

카운트다운 타이머는 정해진 마감 시점까지 남은 시간을 눈에 보이게 줄여 가며 보여 줘요. 시간이 끝나기 전에 행동하도록 긴박감을 만들어 주기 때문에 세일, 출시, 기간 한정 오퍼에 자주 써요.

## 카운트다운 타이머의 장점

- 긴박감을 만들어요: 시간이 줄어드는 모습을 보여 줘서 바로 행동하도록 유도해요.
- 전환율을 높여요: VWO에 따르면 타이머로 전환율이 최대 27%까지 오를 수 있어요.
- 특별함을 살려요: 기간 한정 오퍼를 강조해서 혜택이 더 특별하게 느껴져요.
- 참여도를 높여요: 방문자가 페이지에 더 오래 머물면서 더 많이 반응해요.

## 타이머는 언제 넣으면 좋을까요?

카운트다운 타이머는 활용도가 높아서 여러 종류의 이메일에 쓸 수 있어요.

1. 소매: 특별 프로모션의 남은 시간이나 배송 마감 시간을 알릴 때 자주 써요. 예를 들면 "익일 배송까지 2시간 남았어요" 같은 문구예요.
2. 패션: 신상품 컬렉션, 행사, 패션쇼에 대한 기대감을 키울 때 써요.
3. 여행: 출발까지 남은 시간을 보여 줄 수 있어요.
4. 미디어: 구독이 끝나기까지 남은 시간을 구독자에게 알릴 때 써요.
5. 이벤트: 행사 시작이나 티켓 사전 판매 종료까지 카운트다운할 때 효과적이에요.
6. 비영리 단체: 기부금 매칭 기회에 타이머로 긴박감을 줄 수 있어요.
7. 거래 관련 이메일: 다가오는 행사에 대한 기대감을 키울 때 써요. Litmus Live 2022 참석자에게 보낸 이메일이 그런 예예요.

어느 경우든 카운트다운 타이머는 상황에 따라 행동을 이끌어 내고, 긴박감을 주고, 기대감을 키워 줘요.

## 카운트다운 타이머의 종류

1. 고정형 타이머(Fixed Timer)

   - 설명: 정해 둔 날짜와 시간까지 카운트다운해요. 블랙 프라이데이 세일이나 제품 출시 같은 행사에 알맞아요.
   - 사용 예: "블랙 프라이데이 세일 종료까지 2일 남았어요!"
2. 반복형 타이머(Recurring Timer)

   - 설명: 0이 되면 다시 처음으로 돌아가요. 계속 이어지는 프로모션에 유용해요.
   - 사용 예: "정기 수업 카운트다운" (매주 다음 수업을 기준으로 다시 시작해요.)
3. 동적 타이머(Dynamic Timer)

   - 설명: 이메일 열람 같은 사용자 행동에 따라 사람마다 다르게 보여 줘요.
   - 사용 예: "특별 오퍼가 1시간 뒤에 끝나요" (사용자 행동 기준)

## 알아 둘 점

1. 디자인과 스타일: 타이머가 브랜드의 분위기와 어울리게 맞추세요.
2. 위치: 이메일이나 랜딩 페이지의 맨 위처럼 눈에 잘 띄는 곳에 두세요.
3. 리디렉션: 타이머가 진행 중일 때와 만료됐을 때 이동할 링크를 모두 제대로 설정하세요.
4. 일관성: 이메일과 웹사이트에서 타이머를 같은 모습으로 유지하면 더 믿음이 가요.
5. 만료 이미지: 타이머가 끝났을 때 보여 줄 이미지나 메시지를 준비하세요.

## 카운트다운 타이머 동적 링크

- 활성 타이머 링크: 진행 중인 오퍼를 이용할 수 있는 페이지로 보내는 링크예요. 오퍼 페이지나 결제 페이지가 대표적이에요. 이 페이지에도 같은 카운트다운 타이머를 넣어 두는 게 좋아요. 그러면 타이머가 끝날 때 사용자가 만료 페이지로 자동으로 이동해요.
- 만료 타이머 링크: 타이머가 끝났다는 걸 알리는 페이지로 보내는 링크예요. 이메일에서는 사용자에게 만료 이미지가 보이고, 이 이미지를 누르면 만료 페이지로 이동해요. 퍼널에서는 타이머가 끝나면 만료 페이지가 자동으로 나타나요.

동적 링크가 제대로 작동하려면 저장하기 전에 두 링크를 모두 추가하세요.

## 카운트다운 타이머 만드는 순서

1. **마케팅 > 카운트다운 타이머**로 이동하세요.
![마케팅 메뉴에서 카운트다운 타이머 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031337258/original/zV5txsC5m2hg65VMXt2tI6V_4Yk0hHItoA.png?1724150329)
2. **신규** 버튼을 클릭해 타이머 만들기를 시작하세요.
![신규 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031337343/original/XjDFqVhejxQWHaeOqyfrE9ypFhKUiMTTUg.png?1724150378)
3. **템플릿 선택** 화면에서 디자인 템플릿을 고르고 **Continue with this template**(이 템플릿으로 계속)을 클릭하세요.
![템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031337585/original/uvwAYBuvT1CvoLJCf8QA1emvvzUhSidoww.png?1724150546)
4. 원하는 타이머 유형을 **Fixed**(고정형), **Recurring**(반복형), **Dynamic**(동적형) 중에서 선택하세요.  
   ![타이머 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031337821/original/8x18eyi1PnHs7SjJu0M6sNQ-Ax7aa944og.png?1724150681)
5. 타이머 세부 정보를 설정하세요.

   - 고정형 타이머: 종료 날짜와 시간을 정해요.
   - 반복형 타이머: 카운트다운 시간과 반복 횟수를 정해요.
6. 링크를 추가하세요.

   - **Active Link**(활성 링크): 타이머가 진행되는 동안 사용자가 이동할 URL을 입력해요.
   - **Expired Link**(만료 링크): 타이머가 끝난 뒤 사용자가 도착할 URL을 입력해요.
   ![활성 링크와 만료 링크 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031337968/original/e4SnFLU5se3mR6nYeq0RCQICIX2fEmgnOw.png?1724150756)
7. 색상, 글꼴, 만료 이미지, 시간 표시 형식 등 타이머의 모양을 원하는 대로 바꾸세요.
![타이머 스타일 설정 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031338064/original/xRfLAe-LTV63XhGIdwTpqIRZpvJZuoBuIw.png?1724150803)
![타이머 스타일 설정 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031338193/original/7vG6I1JB-KJHIQh1UWhSCqFjFQgLn08qfw.png?1724150877)
8. 화면 맨 위를 클릭해 알아보기 쉬운 이름을 지어 주세요.
![타이머 이름 변경](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031338323/original/-CxkoTh_RDNQmaXGAChFBlNxgANuqClDBg.png?1724150947)
9. **저장**을 클릭하면 카운트다운 타이머가 완성되고 활성화돼요.  
   ![저장 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155031338406/original/EZo12Y7CE8QYHbxxLIUk-wCPFEvxoaGGzw.png?1724150981)
