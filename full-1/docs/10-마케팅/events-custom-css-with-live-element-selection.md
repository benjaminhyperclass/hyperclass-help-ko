# 이벤트 페이지에 사용자 지정 CSS 적용하기 (요소 클릭 선택)

실시간 CSS 편집기에서 요소를 클릭해 선택하고, 빠른 스타일 프리셋을 넣고, 바뀐 모습을 바로 미리 볼 수 있어요. HTML 구조를 따로 살펴볼 필요가 없어요.

## 이 문서에서 알 수 있는 내용

하이퍼클래스에서 **사용자 지정 CSS** 편집기로 이벤트 페이지를 꾸밀 수 있어요. 요소를 직접 선택하고 바로 미리 볼 수 있어서, 색상·글꼴·여백 같은 디자인 요소를 브랜드에 맞게 바꾸기 쉬워요. 이 문서는 사용자 지정 CSS를 적용하는 방법, 빠른 스타일 프리셋을 쓰는 방법, 이벤트 페이지별로 변경 사항을 미리 보는 방법을 안내해요.

## 사용자 지정 CSS 편집기란?

**사용자 지정 CSS** 편집기에서는 하이퍼클래스 안에서 공개 이벤트 페이지의 모양을 직접 바꿀 수 있어요. 요소 선택 기능을 쓰면 페이지의 HTML을 따로 확인하지 않고도 CSS 선택자를 찾고, 시작용 코드를 넣고, 스타일 변경을 미리 볼 수 있어요.

## 주요 기능

이 편집기로 이벤트 페이지를 꾸미고, 참석자가 보는 모든 화면에서 브랜드 느낌을 일정하게 유지할 수 있어요.

- **실시간 CSS 편집기**: 모든 공개 이벤트 페이지에 적용되는 CSS를 추가하고, 변경 사항을 바로 미리 볼 수 있어요.
- **클릭으로 요소 선택**: 페이지 미리보기에서 원하는 요소를 클릭하면 그 요소의 CSS 선택자를 알 수 있어요. 선택자를 복사하거나, 클릭 한 번으로 시작용 CSS 규칙을 넣을 수 있어요.
- **빠른 스타일 프리셋**: 테두리, 배경, 텍스트 색상, 버튼 색상, 모서리 둥글기, 여백, 그림자, 글꼴처럼 자주 바꾸는 속성의 시작용 CSS를 만들어 줘요.
- **모든 공개 페이지 지원**: **상세 정보**, **일정**, **결제**(Checkout), **결제**(Payment), **확인**, **Leave Checkout**(결제 이탈), **Online Event**(온라인 이벤트) 등 모든 공개 이벤트 페이지 유형에 사용자 지정 CSS가 적용돼요. <!-- 검토 필요: 화면 이름표에서 Checkout과 Payment가 모두 '결제'로 표시돼요. 실제 화면에서 구분 방법을 확인해 주세요. -->
- **복제·복사 지원**: 이벤트를 복제하거나 다른 이벤트의 설정을 복사하면 사용자 지정 CSS도 자동으로 함께 유지돼요.

## 사용자 지정 CSS 편집기 사용하기

페이지 요소를 선택하고 스타일을 적용한 뒤, 저장하기 전에 미리 볼 수 있어요.

1. **Client Apps**(클라이언트 앱) **> 이벤트**로 이동해서 꾸미려는 이벤트를 열어요.
2. **Pages & design**(페이지 및 디자인)을 선택해요.
3. 왼쪽 도구 모음에서 **사용자 지정 CSS** 아이콘을 클릭해요.

   ![이벤트 페이지 왼쪽 도구 모음의 사용자 지정 CSS 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084963339/original/2xr1Hth_l22fqbcKZaPBOQQF2BcSsM-OcQ.png?1793806999)

4. 페이지 미리보기에서 원하는 요소를 클릭해요. 팝업에 그 요소의 CSS 선택자가 나타나요. 팝업에서 선택자를 복사하거나, 시작용 CSS 규칙을 편집기에 넣을 수 있어요.

   ![요소의 CSS 선택자와 복사·삽입 옵션이 표시된 클릭 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077493862/original/T7IiPd7lu0ABME81PjZ1yh7KpvzAZJ-d1A.gif?1785765413)

5. 편집기에 사용자 지정 CSS 규칙을 추가해요. CSS를 직접 쓸 수도 있고, 빠른 스타일 프리셋(다음 섹션 참고)으로 자주 쓰는 속성의 시작용 코드를 만들 수도 있어요. 바꾼 내용은 미리보기 창에 바로 나타나요.

   ![사용자 지정 CSS 편집기에 CSS를 입력한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077494146/original/YoTBZk4UMKPJn_R1SUWm1ZegAs2I45FKZw.png?1785765605)

6. 미리보기 창에서 변경 사항을 실시간으로 확인해요.
7. 마음에 들면 사용자 지정 CSS를 저장해요. 스타일이 모든 공개 이벤트 페이지에 자동으로 적용돼요.

{% hint style="info" %}
요소 선택 기능을 쓰면 여러 겹으로 중첩된 요소도 DOM을 직접 살펴보지 않고 빠르게 찾을 수 있어요.
{% endhint %}

## 빠른 스타일 프리셋

빠른 스타일 프리셋을 쓰면 CSS를 처음부터 쓰지 않고도 자주 바꾸는 속성의 시작용 CSS 코드를 만들 수 있어요. 요소를 선택한 다음 프리셋을 고르면, 미리 구성된 CSS 규칙이 편집기에 들어가요.

사용할 수 있는 프리셋은 다음과 같아요.

1. **Border**(테두리): 선택한 요소의 테두리 두께, 스타일, 색상을 바꾸는 CSS 규칙을 넣어요.
2. **배경**: 선택한 요소의 배경 색상이나 이미지를 바꾸는 CSS를 만들어요.
3. **Text Color**(텍스트 색상): 선택한 요소의 텍스트 색상을 바꾸는 CSS 규칙을 넣어요.
4. **버튼 색상**: 버튼의 배경 색상과 텍스트 색상을 바꾸는 CSS를 만들어요.
5. **모서리 둥글기**: 선택한 요소의 모서리 둥글기를 조절하는 CSS를 넣어요.
6. **Spacing**(여백): 선택한 요소의 안쪽 여백(padding)과 바깥 여백(margin)을 바꾸는 CSS 규칙을 만들어요.
7. **Shadow**(그림자): 선택한 요소에 박스 그림자 효과를 추가하거나 바꾸는 CSS 규칙을 넣어요.
8. **타이포그래피**: 선택한 텍스트 요소의 글꼴, 크기, 굵기, 줄 간격을 바꾸는 CSS를 만들어요.

![테두리, 배경, 텍스트 색상, 타이포그래피 등이 보이는 빠른 스타일 프리셋 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077494267/original/xH10J7a4tgfF0etYaGqBrsqjxg3wjLxpdg.png?1785765663)

{% hint style="info" %}
프리셋을 넣은 뒤에는 만들어진 CSS 값을 브랜드 가이드라인에 맞게 바꿔 보세요. 시작용 코드는 바로 동작하는 기본 틀이라, 여기서부터 다듬으면 돼요.
{% endhint %}

## 공개 페이지 적용 범위

사용자 지정 CSS는 참석자에게 보이는 모든 공개 이벤트 페이지에 일괄 적용돼요. 그래서 참석자가 보는 화면 전체에서 브랜드와 스타일이 일정하게 유지돼요.

사용자 지정 CSS를 지원하는 이벤트 페이지 유형은 다음과 같아요.

- **상세 정보**: 참석자가 이벤트 정보를 보는 페이지예요.
- **일정**: 이벤트 일정과 세션 시간을 보여 주는 페이지예요.
- **결제**(Checkout): 참석자가 등록하거나 티켓을 구매하는 결제 페이지예요.
- **결제**(Payment): 유료 이벤트의 결제를 처리하는 페이지예요.
- **확인**: 등록이나 구매가 끝난 뒤 보여 주는 확인 페이지예요.
- **Leave Checkout**(결제 이탈): 참석자가 결제 과정에서 나갈 때 보여 주는 페이지예요.
- **Online Event**(온라인 이벤트): 참석자가 온라인 이벤트에 접속하는 페이지예요.

## 유의 사항

사용자 지정 CSS가 어떻게 적용되는지 알아 두면 의도하지 않은 스타일 변경을 막고, 이벤트 디자인을 다시 쓰기도 쉬워요.

- **이벤트별 스타일**: 사용자 지정 CSS는 선택한 이벤트의 지원 공개 페이지에만 적용돼요.
- **반응형 디자인**: CSS는 데스크톱과 모바일 레이아웃에 모두 영향을 줘요. 기기별로 따로 조정해야 하면 미디어 쿼리를 사용하세요.
- **CSS 충돌**: 스타일이 적용되지 않으면, 다른 재정의를 추가하기 전에 선택자의 우선순위(specificity)부터 확인하세요.
- **이벤트 복제**: 이벤트를 복제하거나 **Copy from another event**(다른 이벤트에서 복사)를 쓸 때, 디자인 옵션 중 **사용자 지정 CSS**를 선택해야 스타일이 그대로 유지돼요.
- **스타일 제거**: 사용자 지정 CSS 규칙을 삭제하고 저장하면, 영향받은 요소가 기본 모양으로 돌아가요.

복제 방법은 [이벤트 복제하고 다시 사용하기](how-to-duplicate-and-reuse-events.md)에서 자세히 볼 수 있어요.

## 사용자 지정 CSS가 포함된 이벤트 복제·복사

이벤트를 복제하거나 다른 이벤트의 설정을 복사하면 사용자 지정 CSS가 자동으로 유지돼요. CSS 코드를 다시 입력하지 않고도 여러 이벤트에 같은 스타일을 빠르게 적용할 수 있어요.

사용자 지정 CSS를 유지하는 방법은 두 가지예요.

1. **이벤트 복제**: 이벤트를 복제하면 원본 이벤트의 사용자 지정 CSS가 모두 새 이벤트로 복사돼요. 복제된 이벤트는 처음부터 원본과 똑같은 스타일이에요.
2. **다른 이벤트에서 설정 복사**: 한 이벤트의 설정을 다른 이벤트로 복사하면 사용자 지정 CSS도 함께 복사돼요. 기존 이벤트의 디자인을 새 이벤트나 다른 이벤트에 적용할 수 있어요.

{% hint style="info" %}
복제하거나 설정을 복사한 뒤에는 새 이벤트의 사용자 지정 CSS를 바꿔도 원본 이벤트의 스타일에는 영향이 없어요.
{% endhint %}

## 자주 묻는 질문

### 사용자 지정 CSS가 내 계정의 모든 이벤트에 적용되나요?
아니요. 사용자 지정 CSS는 이벤트별로 설정돼요. 이벤트마다 자기만의 사용자 지정 CSS 설정이 있어요. 여러 이벤트에 같은 CSS를 적용하려면 복제 기능이나 설정 복사 기능을 사용하세요.

### 저장하기 전에 변경 사항을 미리 볼 수 있나요?
네. **사용자 지정 CSS** 편집기에는 CSS를 쓰는 즉시 반영되는 실시간 미리보기 창이 있어요. 저장하기 전에 변경 결과를 확인할 수 있어요.

### 이 기능을 쓰려면 CSS를 알아야 하나요?
CSS를 조금 알면 도움이 되지만 꼭 필요하지는 않아요. 빠른 스타일 프리셋이 시작용 CSS를 만들어 주거든요. 요소를 클릭해서 선택자를 확인하고, 프리셋으로 자주 쓰는 속성을 CSS를 처음부터 쓰지 않고도 바꿀 수 있어요.

### 사용자 지정 CSS가 하이퍼클래스 기본 스타일과 충돌하면 어떻게 되나요?
사용자 지정 CSS는 하이퍼클래스 기본 스타일 다음에 적용돼요. 대부분은 직접 쓴 규칙이 기본 스타일보다 우선해요. 스타일이 기대한 대로 적용되지 않으면 더 구체적인 CSS 선택자를 쓰거나 `!important`를 붙여 규칙의 우선순위를 높이세요.

### 적용한 사용자 지정 CSS를 없애거나 초기화할 수 있나요?
네. 편집기에서 CSS 코드를 삭제하고 저장하면 사용자 지정 스타일이 모두 사라져요. 이벤트 페이지는 하이퍼클래스 기본 스타일로 돌아가요.

### 빠른 스타일 프리셋은 모든 요소에서 쓸 수 있나요?
빠른 스타일 프리셋은 선택한 요소를 기준으로 CSS를 만들어요. 타이포그래피처럼 텍스트 요소에 가장 잘 맞는 프리셋도 있고, **Border**(테두리)나 **배경**처럼 대부분의 컨테이너 요소에서 잘 동작하는 프리셋도 있어요. 만들어진 CSS는 필요에 맞게 언제든 편집할 수 있어요.

### 사용자 지정 CSS가 모바일 기기의 이벤트 페이지에도 영향을 주나요?
네. 사용자 지정 CSS는 모든 화면 크기에 적용돼요. 모바일에만 적용할 스타일이 필요하면 사용자 지정 CSS에 CSS 미디어 쿼리(예: `@media (max-width: 768px)`)를 써서 작은 화면을 지정하세요.

### 이벤트를 통째로 복제하지 않고 이벤트 간에 사용자 지정 CSS만 공유할 수 있나요?
현재는 이벤트 복제 기능이나 설정 복사 기능을 쓸 때 사용자 지정 CSS가 함께 유지돼요. 직접 공유하려면 한 이벤트의 **사용자 지정 CSS** 편집기에서 CSS 코드를 복사해, 다른 이벤트의 **사용자 지정 CSS** 편집기에 붙여 넣으세요.
