# 카운트다운 타이머 레이블 직접 바꾸기

카운트다운 타이머의 각 칸 아래에 표시되는 "일, 시간, 분, 초" 문구를 원하는 말로 바꿀 수 있어요. 캠페인 분위기나 사용하는 언어에 맞춰 문구를 정하고 싶을 때 이 문서를 참고하세요.

## 카운트다운 타이머 레이블이란?

카운트다운 타이머 레이블은 타이머 각 칸 아래에 표시되는 "일 / 시간 / 분 / 초" 문구예요. 기본 문구 대신 원하는 문구를 넣을 수 있어요.

계정의 언어 설정(로케일)을 자동으로 감지해서, 레이블을 해당 언어로 미리 채워 주기도 해요. 설정 시간을 아끼고, 사용자에게 익숙한 타이머를 보여 줄 수 있어요.

## 레이블을 바꾸면 좋은 점

- 바로 현지화돼요: 기본 문구가 서브 계정의 언어 설정에 맞춰 표시돼요.
- 브랜드 말투를 맞출 수 있어요: 예를 들어 "시간"을 "시"나 "Heures"로 바꿔 브랜드 문체에 맞출 수 있어요.
- 의미를 더 분명하게 전할 수 있어요: "쇼핑 가능 일수"처럼 캠페인에 맞는 표현을 쓸 수 있어요.
- 디자인 작업이 줄어요: 언어마다 이미지를 따로 만들 필요가 없어요.
- 전환율을 높일 수 있어요: 타이머가 익숙하고 이해하기 쉬우면 방문자가 더 잘 반응해요.

## 기본 레이블

**카운트다운 타이머**는 계정의 로케일을 기준으로 시작 레이블을 자동으로 정해요. 그대로 써도 되고, 줄임말이나 구어체 표현, 완전히 새로운 문구로 고쳐도 돼요.

## 레이블 바꾸는 방법

자동으로 채워진 문구는 언제든 바꿀 수 있어요.

1. **마케팅 > 카운트다운 타이머**로 이동하세요.

   ![마케팅 메뉴에서 카운트다운 타이머로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054946989/original/R1W119Y7lHgX3dakzp8m_Gjx5lZDibrN1A.png?1759245904)
2. 기존 타이머는 이름을 클릭해서 열고, 새 타이머는 **+ 신규**를 클릭해서 만드세요.

   ![기존 타이머를 열거나 새 타이머 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054947190/original/YIDtgDmw0Fh3drZG8eHC_Bkr2m3FC-EwCw.png?1759245950)
3. 왼쪽 사이드바에서 **Styling**(스타일링) 탭으로 이동하세요.

   ![왼쪽 사이드바의 스타일링 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054947351/original/Em9nTFP8qlNpybPoH5uEFDFccpK_FzQnZA.png?1759246019)
4. **Labels**(레이블) 아래의 드롭다운에서 각 레이블을 **표시됨** 또는 **Hidden**(숨김)으로 설정하세요.

   ![레이블 표시 여부를 고르는 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054949482/original/nmgmRV7yz0B-oDnl6xpmlf7VMw4x8fPKPw.png?1759247191)
5. 각 칸(**일**, **시간**, **분**, **초**)에 새 문구를 입력해서 사용자 지정 레이블을 만드세요.

   ![각 칸에 새 레이블 문구 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054949518/original/qwdBxCYHs9afPhbzjjr67Y_zPxx7GZzTmA.png?1759247222)
6. **저장**을 클릭해 변경 사항을 저장하세요.

   ![저장 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054949584/original/-zlx-2KSLguzGFv56MHjU0tCrBte8JqyuQ.png?1759247262)

## 자주 묻는 질문

### 레이블을 바꾸면 이미 사용 중인 타이머에도 적용되나요?
네. 레이블 문구를 수정하면 해당 타이머를 사용 중인 모든 곳에 바뀐 문구가 반영돼요.

### 이메일과 퍼널에서 서로 다른 레이블을 쓸 수 있나요?
타이머 하나에는 레이블 한 세트만 지정할 수 있어요. 문구를 따로 쓰고 싶다면 타이머를 복제해서 새로 만드세요.

### 모든 언어에서 자동 번역이 되나요?
시스템은 서브 계정의 언어를 기준으로 기본 문구를 채워 줘요. 다만 지역별 말투나 뉘앙스에 맞추려면 직접 고쳐야 할 수도 있어요.

### 레이블을 바꾸면 동적 링크나 만료 시 동작에도 영향이 있나요?
아니요. 레이블 수정은 화면에 보이는 문구만 바꿔요. 리디렉션과 로직은 그대로예요.
