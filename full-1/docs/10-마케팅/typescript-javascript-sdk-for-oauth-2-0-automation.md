# OAuth 2.0 자동화를 위한 TypeScript/JavaScript SDK

하이퍼클래스 API Center of Excellence 팀이 만든 TypeScript/JavaScript SDK를 소개해요. 이 SDK는 앱 설치, 토큰 갱신, 설치 해제 같은 OAuth 2.0 작업을 대신 처리해 줘요. 앱을 개발할 때 인증 관리 부담을 줄이고 싶다면 이 문서를 참고하세요.

## 이 문서에서 알 수 있는 내용

- SDK의 핵심 기능과 연동 방법
- 데이터베이스에 얽매이지 않는 구조, 내장 샘플 코드, SDK 자동 생성이 개발을 어떻게 쉽게 해 주는지
- 지원 티켓을 줄이면서 API 업데이트에 맞춰 앱을 최신 상태로 유지하는 방법

## TypeScript/JavaScript SDK란?

TypeScript/JavaScript SDK는 개발자가 OAuth 2.0을 더 쉽게 연동하도록 만든 SDK예요. 앱 설치, 매일 이뤄지는 토큰 갱신, 설치 해제 같은 OAuth 작업을 자동으로 처리해요. 인증을 직접 관리하지 않아도 되니 앱을 만드는 데 집중할 수 있어요.

SDK는 NPM에 `@gohighlevel/api-client`라는 이름으로 올라와 있어요. 모든 공개 API를 지원하고, 구현을 빠르게 시작할 수 있도록 샘플 코드도 들어 있어요. 어떤 데이터베이스와도 함께 쓸 수 있는 구조라 지금 쓰는 인프라에 그대로 붙일 수 있어요. SDK는 자동으로 생성되기 때문에 API가 업데이트되어도 최신 상태를 유지해요.

## 주요 장점

인증 관리를 자동화하고 안전하게 확장할 수 있어서, 개발이 단순해지고 출시까지 걸리는 시간도 줄어들어요.

- OAuth 2.0 전체 자동화: 서브 계정 설치, 에이전시 일괄 설치, 앞으로 추가될 자동 설치까지 모든 앱 설치 상황을 사람이 개입하지 않아도 처리해요.
- 자동 토큰 갱신: 토큰이 만료되면 매일 갱신해서 API 연결과 인증이 끊기지 않게 해 줘요.
- 데이터베이스에 구애받지 않는 설계: 원하는 토큰 관리 방식과 연동되어 기존 인프라와 잘 맞아요.
- 내장 샘플 코드: 모든 공개 API에 쓸 수 있는 코드 예시가 있어서 시행착오를 줄여 줘요.
- 자동 SDK 업데이트: SDK가 완전 자동으로 생성되기 때문에 API 업데이트와 기능 개선에 맞춰 계속 변해요.
- 지원 티켓 감소: 복잡한 OAuth 2.0 과정을 SDK가 감싸 주어서 구현 문제와 지원 요청이 줄어들어요.

## OAuth 2.0 자동 관리

SDK는 복잡한 OAuth 2.0 과정을 앱 설치부터 토큰 유지, 설치 해제까지 모두 처리해요. 인증을 수동으로 관리할 필요가 없고, API에 안전하고 안정적으로 접근할 수 있어요.

- 모든 설치 상황: 서브 계정 설치, 에이전시 일괄 설치, 앞으로 추가될 자동 설치 과정을 관리해요.
- 토큰 만료 처리: 토큰이 만료되면 자동으로 갱신해서 API 접근이 끊기지 않게 해요.
- 설치 해제 과정: 앱을 제거하는 과정을 간소화해서 보안을 높이고 정리가 제대로 되도록 도와요.

## 데이터베이스에 구애받지 않는 토큰 관리

SDK는 유연하게 설계되어 있어서 토큰 저장과 관리에 어떤 데이터베이스든 쓸 수 있어요. 기존 인프라나 개발 방식과 자연스럽게 맞아요.

- 모든 데이터베이스 지원: 특정 저장 방식을 요구하지 않고, 원하는 데이터베이스와 쉽게 연결돼요.
- 일관된 토큰 처리: 저장소 기술이 달라도 토큰을 안정적으로 관리해요.
- 확장 가능한 구성: 앱의 요구 사항과 규모에 맞게 조정할 수 있는 옵션을 제공해요.

## 공개 API 연동과 내장 샘플

SDK는 하이퍼클래스의 모든 공개 API 엔드포인트를 지원해요. API 문서 안에 코드 예시가 바로 들어 있어서 구현 속도가 빨라지고 설정도 간단해져요.

- 전체 API 지원: 모든 공개 엔드포인트를 바로 연동할 수 있어요.
- 내장 샘플 코드: 바로 쓸 수 있는 코드 예시로 설정 시간을 줄이고 올바른 사용 방법을 알려 줘요.
- 쉬운 시작: 하이퍼클래스 API가 처음인 개발자도 빠르게 익힐 수 있어요.

## SDK 자동 생성

SDK는 하이퍼클래스 API가 바뀔 때마다 자동으로 새로 생성돼요. 개발자가 직접 업데이트하지 않아도 새 기능과 변경 사항이 반영돼요.

- 자동 업데이트: API가 수정되거나 새 엔드포인트가 나오면 SDK가 알아서 다시 생성돼요.
- 최소한의 유지 관리: 수동 업데이트가 거의 필요 없어서 개발 환경을 별도 작업 없이 최신으로 유지할 수 있어요.
- 최신 개선 사항: 새 API 기능과 개선 사항을 나오는 즉시 쓸 수 있어요.

## 시작하기

OAuth 2.0 작업을 자동화하고 싶다면 아래 순서대로 SDK를 TypeScript 또는 JavaScript 프로젝트에 연동해 보세요.

## SDK 설정 방법

아래 순서를 따르면 OAuth 2.0 처리를 프로젝트에 빠르게 연동할 수 있어요.

1. NPM으로 SDK를 설치하세요. 터미널에서 아래 명령어를 실행해요.

   ```
   npm install @gohighlevel/api-client
   ```

2. SDK를 프로젝트로 가져오세요. TypeScript 또는 JavaScript 파일에 아래 import 문을 추가해요.

   ```
   import { HighLevel } from '@gohighlevel/api-client';
   ```

3. OAuth 2.0 자격 증명을 설정하세요. 앱의 자격 증명과 리디렉션 URI를 입력하고, 앱에 맞는 권한을 지정해요.

4. 사용할 데이터베이스를 연동하세요. 원하는 데이터베이스를 연결해 토큰 저장 방식을 설정해요. SDK의 데이터베이스 독립 설계 덕분에 어떤 데이터베이스든 쓸 수 있어요. 시작할 때 참고할 수 있도록 MongoDB와 Redis 샘플 구현도 들어 있어요.

   ![토큰 저장용 데이터베이스 연동 이미지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077935115/original/ca62O3Au8a0TSl3RWm7JJT-8T7jvSQEGsg.png?1786167714)

5. API 연결을 테스트하세요. 문서에 있는 샘플 코드로 테스트 API 호출을 실행해, 토큰 관리와 API 연결이 문제없이 동작하는지 확인해요.

## 추가 자료

고급 설정, 문제 해결, 자세한 구현 예시는 SDK 전용 저장소의 문서와 SDK 시작 가이드(Getting Started with SDKs)를 참고하세요. 저장소와 가이드 위치가 궁금하면 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### SDK가 자동으로 처리해 주는 작업은 무엇인가요?
SDK는 OAuth 2.0 작업을 자동화해요. 모든 설치 상황(서브 계정, 에이전시 일괄 설치, 앞으로 추가될 자동 설치), 토큰 만료 시 예약된 토큰 갱신, 설치 해제 절차가 여기에 포함돼요.

### 토큰 갱신은 어떻게 이뤄지나요?
토큰이 만료되면 SDK가 자동으로 갱신해서, 사람이 개입하지 않아도 인증이 계속 유지돼요. 이 갱신은 매일 이뤄지고, API 연결이 끊기지 않게 해 줘요.

### 지금 쓰는 데이터베이스를 SDK와 함께 쓸 수 있나요?
네, 쓸 수 있어요. SDK는 데이터베이스에 얽매이지 않는 구조라서 원하는 데이터베이스로 토큰을 관리할 수 있고, 기존 인프라와 개발 환경에도 잘 맞아요.

### 자세한 문서와 샘플 프로젝트는 어디서 볼 수 있나요?
자세한 문서, 샘플 코드, 예제 프로젝트는 SDK 전용 저장소와 SDK 시작 가이드(Getting Started with SDKs)에서 볼 수 있어요. 저장소와 가이드 위치가 궁금하면 하이퍼클래스 고객지원에 문의하세요.

### 다른 프로그래밍 언어용 SDK도 나올 예정인가요?
하이퍼클래스는 개발자 커뮤니티의 의견을 반영해 PHP와 Python SDK를 출시할 계획이에요. 이 SDK들도 같은 방식으로 OAuth 2.0 관리를 자동화해요.

### 의견을 전달하거나 문제를 신고하려면 어떻게 하나요?
SDK 문서에 안내된 하이퍼클래스 커뮤니티 채널로 의견을 보내거나 문제를 알릴 수 있어요. GitHub 저장소에 이슈를 등록해도 돼요.

### SDK가 모든 하이퍼클래스 API 엔드포인트를 지원하나요?
네, 하이퍼클래스 플랫폼의 모든 공개 API를 지원해요. 문서에는 엔드포인트마다 샘플 코드가 들어 있어서 구현을 빠르게 시작할 수 있어요.

### SDK 자동 생성은 개발자에게 어떤 도움이 되나요?
SDK 자동 생성 덕분에 SDK가 API 업데이트에 맞춰 계속 바뀌어요. 개발자가 직접 업데이트하거나 유지 관리하지 않아도 새 기능과 변경 사항을 바로 쓸 수 있어요.
