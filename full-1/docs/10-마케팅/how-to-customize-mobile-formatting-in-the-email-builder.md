# 이메일 빌더에서 모바일 서식 설정하기

이메일 빌더의 모바일 보기 설정을 쓰면 데스크톱 디자인은 그대로 두고 모바일에서 보이는 모습만 따로 바꿀 수 있어요. 여백, 버튼 글꼴, 이미지·동영상 크기, 소셜 아이콘을 모바일용으로 조정할 수 있어요. 모바일 스타일은 직접 덮어쓰기 전까지 데스크톱 값을 그대로 따라가요. 이 문서에서는 모바일 서식을 설정하고 미리보기와 테스트로 확인하는 방법을 안내해요.

## 모바일 보기 설정이란?

모바일 보기 설정을 쓰면 지원되는 섹션과 요소가 데스크톱과 다른 스타일을 모바일에서 사용할 수 있어요. 지원되는 스타일 설정 안에서 **데스크톱**과 **모바일**을 전환하면서 레이아웃 여백, 버튼, 이미지, 로고, 동영상, 소셜 아이콘을 각각 조정할 수 있어요.

모바일 스타일은 기본적으로 데스크톱 설정을 따라가요. 직접 덮어쓴 설정만 별도의 모바일 값을 사용해요.

### 모바일 보기 설정의 장점

작은 화면에서 이메일이 보이는 모습을 개선하면서 데스크톱 디자인은 그대로 유지할 수 있어요.

- 모바일 스타일을 따로 설정해요. 데스크톱 스타일을 바꾸지 않고 지원되는 모바일 설정을 조정할 수 있어요.
- 레이아웃 간격을 유연하게 조정해요. 지원되는 섹션과 요소의 여백과 마진을 바꿀 수 있어요.
- 모바일 버튼을 더 보기 좋게 만들어요. 정렬, 전체 너비 적용, 간격, 버튼 글꼴을 조정할 수 있어요.
- 미디어를 모바일에 맞춰요. 지원되는 이미지, 로고, 동영상의 정렬과 크기를 바꿀 수 있어요.
- 소셜 아이콘을 조정해요. 지원되는 **소셜** 요소의 아이콘 정렬, 크기, 간격을 바꿀 수 있어요.
- 기존 디자인은 그대로 유지돼요. 모바일 전용 스타일을 바꾸기 전까지 기존 이메일은 지금 모습을 유지해요.

### 사전 준비와 제한 사항

하이퍼클래스의 **디자인 에디터**에서 이메일 템플릿이나 캠페인을 열고 시작하세요. 모바일 설정은 지원되는 스타일 영역에 나타나고, 선택한 요소에 따라 쓸 수 있는 옵션이 달라요.

- 모바일 스타일은 값을 바꾸기 전까지 데스크톱 값을 따라가요.
- 모든 요소에서 모든 모바일 설정을 쓸 수 있는 건 아니에요.
- 기존 템플릿과 캠페인은 모바일 전용 스타일을 수정하지 않는 한 현재 모습을 유지해요.
- 일부 이메일 클라이언트는 특정 모바일 덮어쓰기 대신 기본 스타일을 보여 줄 수 있어요.
- **모바일 서식**은 콘텐츠가 어떻게 보이는지를 바꿔요. **Device Visibility**(기기별 표시 설정)는 콘텐츠를 보여 줄지 말지를 따로 정해요.

{% hint style="info" %}
섹션과 요소에 따라 쓸 수 있는 모바일 보기 설정이 달라요. 편집하려는 콘텐츠에서 어떤 스타일 옵션을 제공하는지 확인하세요.
{% endhint %}

## 데스크톱 스타일과 모바일 스타일의 관계

데스크톱 스타일이 이메일의 기본 모습을 정해요. 지원되는 모바일 보기 설정으로 작은 화면에 맞게 개별 설정을 덮어쓸 수 있어요.

- 모바일 덮어쓰기를 하지 않으면: 해당 설정은 데스크톱 값이나 기본값을 그대로 써요.
- 모바일 덮어쓰기를 적용하면: 지원되는 이메일 클라이언트에서 선택한 설정이 모바일 전용 값을 써요.
- 데스크톱 스타일: 모바일 전용으로 바꿔도 데스크톱 디자인은 달라지지 않아요.

예를 들어 버튼은 데스크톱에서 원래 너비로 두고, 같은 버튼을 모바일에서만 전체 너비로 만들 수 있어요.

이메일 디자인은 하나만 관리하면서 작은 화면에 필요한 부분만 조정할 수 있어요.

## 모바일 서식 설정 항목

섹션과 요소마다 제공하는 모바일 보기 설정이 달라요. 편집할 콘텐츠를 선택한 뒤 지원되는 스타일 설정을 확인하세요.

### 레이아웃과 간격

지원되는 섹션과 콘텐츠 요소의 모바일 여백과 마진을 바꿀 수 있어요. 데스크톱 레이아웃은 그대로 두고 작은 화면에 알맞은 간격을 만들 수 있어요.

불필요한 좌우 간격을 줄이면 좁은 화면에서 콘텐츠가 더 자연스럽게 들어가요.

### 버튼 스타일

모바일 버튼 설정에서는 다음 항목을 조정할 수 있어요.

- 정렬
- 전체 너비 적용
- 간격과 여백
- 글꼴 크기
- 글꼴 굵기
- 글꼴 스타일
- 텍스트 장식

작은 화면에서도 행동 유도 버튼을 읽기 쉽고 누르기 편하게 만들 때 사용하세요.

### 이미지, 로고, 동영상

지원되는 모바일 미디어 설정에서는 이미지, 로고, 동영상의 정렬, 크기, 여백을 데스크톱 스타일과 별개로 조정할 수 있어요.

지원되는 크기 조정에서는 가로세로 비율이 자동으로 고정되어 이미지와 동영상의 비율이 유지돼요.

### 소셜 아이콘

지원되는 **소셜** 요소에서는 다음 모바일 전용 설정을 바꿀 수 있어요.

- 정렬
- 아이콘 크기
- 아이콘 사이 간격

## 모바일 덮어쓰기 토글

일부 모바일 설정은 덮어쓰기 토글을 켜야 별도의 값을 쓸 수 있어요. 덮어쓰기가 꺼져 있으면 해당 설정은 데스크톱 값이나 기본값을 따라가요.

덮어쓰기 토글이 있으면 켜고, 모바일 전용 값을 입력한 뒤, 저장하기 전에 결과를 확인하세요.

예를 들어 데스크톱 제목이 기본 글꼴 크기를 쓰고 모바일 덮어쓰기가 꺼져 있으면, 모바일에서도 그 값을 그대로 써요. 모바일 글꼴 크기 덮어쓰기를 켜면 지원되는 모바일 이메일 클라이언트에서 다른 크기를 지정할 수 있어요.

## 모바일 서식과 Device Visibility의 차이

모바일 서식은 콘텐츠가 어떻게 보이는지를 바꾸고, **Device Visibility**는 콘텐츠를 보여 줄지 말지를 정해요. 두 기능은 서로 다른 모바일 디자인 문제를 해결해요.

**모바일 서식**은 이럴 때 사용해요.

- 글꼴 크기를 바꾸고 싶을 때
- 정렬을 조정하고 싶을 때
- 간격을 수정하고 싶을 때
- 지원되는 요소의 모바일 스타일을 바꾸고 싶을 때

**Device Visibility**는 이럴 때 사용해요.

- 모바일에서 요소를 숨기고 싶을 때
- 모바일에서만 요소를 보여 주고 싶을 때
- 데스크톱 전용 콘텐츠를 숨기고 싶을 때
- 데스크톱용과 모바일용 콘텐츠 블록을 따로 만들고 싶을 때

예를 들어 큰 이미지를 모바일에서 아예 보여 주지 않으려면, 모바일 서식만으로 해결하려 하지 말고 표시 설정을 사용하세요.

## 모바일·데스크톱 레이아웃 표시 설정

하이퍼클래스는 이메일 레이아웃 전체에 대한 기기별 표시 설정도 지원해요. 섹션 전체를 모바일에서 다르게 보여 주거나 숨기고 싶을 때 유용해요.

레이아웃 단위 표시 설정은 이럴 때 쓸 수 있어요.

- 데스크톱 섹션이 복잡한 다단 디자인일 때
- 단순하게 만든 모바일 섹션이 읽기 더 쉬울 때
- 데스크톱용과 모바일용 콘텐츠를 따로 만들어야 할 때
- 프로모션 블록 전체를 한 기기에서 숨기고 싶을 때

이렇게 모바일을 세 단계로 조정할 수 있어요.

1. 스타일 덮어쓰기는 **모바일 서식**으로 해요.
2. 개별 콘텐츠 요소는 **Element Visibility**(요소 표시 설정)로 조정해요.
3. 레이아웃 블록 전체는 **Layout Visibility**(레이아웃 표시 설정)로 조정해요.

## 이메일 클라이언트와 미디어 쿼리의 제한

모바일 전용 이메일 스타일은 이메일 클라이언트가 반응형 이메일을 지원하는지에 따라 달라요. 일부 모바일 서식 설정은 미디어 쿼리를 사용하는데, 모든 이메일 클라이언트가 이를 똑같이 처리하지는 않아요.

그래서 이런 일이 생길 수 있어요.

- 지원되는 클라이언트에서는 모바일 덮어쓰기가 표시돼요.
- 지원되지 않는 클라이언트에서는 기본 스타일이 대신 쓰일 수 있어요.
- 미리보기 화면이 실제로 받은 이메일과 정확히 같지 않을 수 있어요.

모바일 덮어쓰기가 무시되더라도 기본 이메일 디자인은 읽고 쓰는 데 문제가 없어야 해요.

{% hint style="warning" %}
받는 쪽 이메일 클라이언트가 모바일 덮어쓰기를 무시하면 이메일을 쓸 수 없게 되는 심각한 레이아웃 문제는, 모바일 덮어쓰기로만 해결하려 하지 마세요.
{% endhint %}

## 반응형 디자인 모범 사례

타이포그래피만이 아니라 이메일 전체를 좁은 화면에 맞춰 설계하면 모바일 최적화가 가장 잘돼요.

- 확대하지 않아도 본문 텍스트를 읽을 수 있게 하세요.
- 한 줄이 너무 긴 텍스트는 피하세요.
- 섹션 사이에 간격을 충분히 두세요.
- 버튼은 편하게 누를 수 있는 크기로 만드세요.
- 좁은 영역에 행동 유도 버튼을 여러 개 몰아넣지 마세요.
- 이미지가 화면에 맞게 줄어드는지 확인하세요.
- 다단 섹션은 꼼꼼히 살펴보세요.
- 필요하면 모바일 레이아웃을 더 단순하게 만드세요.
- 중요한 정보는 이메일 위쪽에 두세요.

하이퍼클래스 이메일 요소는 기본적으로 반응형이에요. 디자인이 실제로 나아지는 곳에만 모바일 덮어쓰기를 사용하세요.

## 이메일 빌더에서 모바일 보기 설정하기

먼저 데스크톱 디자인을 완성한 뒤, 필요한 곳에만 모바일 전용 스타일을 적용하세요. 기존 이메일 템플릿과 캠페인, 새로 만드는 템플릿과 캠페인 모두에서 지원되는 섹션과 요소에 모바일 보기 설정을 쓸 수 있어요.

### 1단계: 이메일 빌더 열기

1. 하이퍼클래스 **서브 계정**에서 **마케팅**을 선택하세요.
2. **이메일**을 선택하세요.
3. **템플릿** 또는 **캠페인**을 여세요.
4. 기존 이메일을 열거나 새로 만드세요.
5. **디자인 에디터**로 이동하세요.

![이메일 템플릿 또는 캠페인에서 디자인 에디터를 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084251690/original/3YS__GaMkXuQ2bp15XKNNjbSBK9GrBlQuQ.png?1793047395)

### 2단계: 데스크톱·모바일 스타일 선택하기

지원되는 섹션과 요소에서는 데스크톱과 모바일 스타일 옵션을 제공해서 모바일 모습을 따로 조정할 수 있어요.

1. 설정을 바꿀 섹션이나 요소를 선택하세요.
2. 해당 요소의 스타일 설정을 여세요.
3. **데스크톱**과 **모바일** 옵션이 있는지 찾아보세요.
4. **모바일**을 선택하세요.
5. 필요하면 해당 모바일 덮어쓰기를 켜세요.
6. 모바일 전용 스타일 값을 입력하세요.
7. **데스크톱**으로 돌아가 원래 데스크톱 디자인이 그대로인지 확인하세요.

![데스크톱과 모바일 스타일 옵션을 전환하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084252302/original/u0X5PeLfLQZ2nESG4wdaEyfdVMi1r_ch8w.png?1793047880)

### 선택: 모바일 텍스트 서식 조정하기

**화면 스타일** 영역에서도 기본 **모바일 서식** 설정을 쓸 수 있어요. 이 타이포그래피 설정으로 제목과 본문 텍스트가 작은 화면에서도 읽기 좋게 만들 수 있어요.

1. 이메일 빌더에서 **화면 스타일**을 선택하세요.

![이메일 빌더의 화면 스타일 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082219040/original/EjflYtt8N41b6UsYon814b23WADhhE3QzQ.png?1790777490)

2. **모바일 서식**을 찾으세요.

![화면 스타일 설정 안의 모바일 서식 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082219181/original/yM7NDYbFq7ikUGtq8GusKg_ru3necHtDhQ.png?1790777532)

3. 사용할 수 있는 텍스트 서식 설정을 확인하세요.
4. 필요하면 해당 모바일 덮어쓰기를 켜세요.
5. 지원되는 글꼴 크기, 줄 간격, 정렬 설정을 조정하세요.

![이메일 빌더의 모바일 전용 서식 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082219312/original/EX3OIdtwNT4aHr-gNNwULb-MzyBeY52rdA.png?1790777582)

6. 모바일 미리보기를 열어 결과를 확인하세요.
7. 저장하기 전에 데스크톱 버전도 확인하세요.

### 3단계: 모바일 여백과 마진 조정하기

데스크톱 간격이 작은 화면에 너무 넓을 때, 모바일 간격을 따로 설정하면 읽기가 편해져요.

1. 조정할 섹션이나 지원되는 요소를 선택하세요.
2. **스타일** 설정을 여세요.
3. **바깥 여백 및 안쪽 여백**을 펼치세요.
4. 기기 선택기를 열고 **모바일**을 선택하세요.

![바깥 여백 및 안쪽 여백에서 모바일을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084252440/original/x2fbgRBVFWum3c6QO8OYMVRfkUUv2wZqrg.png?1793048073)

5. 사용할 수 있는 **여백** 값을 조정하세요.
6. 사용할 수 있는 **마진** 값을 조정하세요.
7. 모바일 보기에서 간격을 확인하세요.
8. **데스크톱**으로 돌아가 원래 데스크톱 간격이 그대로인지 확인하세요.

### 4단계: 모바일 버튼 설정하기

모바일 버튼 스타일을 설정하면 데스크톱 버튼 디자인은 그대로 두고, 작은 화면에서 읽기 쉽고 누르기 편한 행동 유도 버튼을 만들 수 있어요.

1. 이메일에서 **버튼** 요소를 선택하세요.
2. **스타일** 탭을 여세요.
3. **정렬**을 펼치세요.
4. 기기 선택기를 열고 **모바일**을 선택하세요.
5. 지원되는 모바일 정렬을 선택하세요.

![버튼의 모바일 정렬 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084255295/original/qxjXOUQa5kqI2YkQ7fzvFHn6TIAUGvg6zg.png?1793053812)

버튼 타이포그래피도 모바일용으로 따로 설정할 수 있어요.

6. **타이포그래피**를 펼치세요.
7. 기기 선택기를 열고 **모바일**을 선택하세요.
8. 사용할 수 있는 타이포그래피 설정을 조정하세요.
   - **글꼴**
   - **크기**
   - **굵게**
   - **기울임**
   - **밑줄**

![버튼의 모바일 타이포그래피 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084255262/original/9CPhjVNFgabbctTN69670lTj8dH56aD6Pg.png?1793053671)

9. 간격, 여백, 전체 너비 적용처럼 지원되는 다른 모바일 버튼 설정이 있으면 함께 조정하세요.
10. **모바일**과 **데스크톱** 보기에서 모두 버튼을 확인하세요.

### 5단계: 이미지, 로고, 동영상 조정하기

모바일 미디어 설정을 쓰면 데스크톱 설정은 그대로 두고, 지원되는 시각 요소의 위치와 크기를 조정할 수 있어요.

1. **이미지**, **로고**, **동영상** 요소 중 하나를 선택하세요.
2. 해당 요소의 스타일 설정을 여세요.
3. **모바일**을 선택하세요. 옵션이 있는 경우에만 나타나요.
4. 지원되는 정렬을 조정하세요.
5. 사용할 수 있는 크기를 조정하세요.
6. 사용할 수 있는 여백 설정을 수정하세요.
7. 모바일 보기와 데스크톱 보기에서 모두 미디어를 확인하세요.

지원되는 크기 조정에서는 가로세로 비율이 자동으로 고정되어 이미지와 동영상의 비율이 유지돼요.

![이미지, 로고, 동영상의 모바일 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084255666/original/qwA5fHpjWLYVI6s_oeIBgcs20whSUTcGbg.png?1793054926)

### 6단계: 소셜 아이콘 설정하기

소셜 아이콘 설정을 쓰면 모바일 기기에서도 프로필 링크가 균형 있고 읽기 쉽게 보여요.

1. **소셜** 요소를 선택하세요.
2. 해당 요소의 스타일 설정을 여세요.
3. **모바일**을 선택하세요. 옵션이 있는 경우에만 나타나요.
4. 아이콘 정렬을 조정하세요.
5. 지원되는 아이콘 크기를 바꾸세요.
6. 아이콘 사이 간격을 조정하세요.
7. 모바일 보기와 데스크톱 보기에서 모두 **소셜** 요소를 확인하세요.

![소셜 요소의 모바일 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084255867/original/ZUnMi7kxhW3pEhGkHoa32GB24rFn-FxZ4g.png?1793055514)

### 7단계: 변경 사항 저장하기

모바일 전용 스타일을 적용한 뒤에는 데스크톱 보기와 모바일 보기를 모두 확인해서 레이아웃이 의도한 대로 보이는지 확인하세요.

1. 모바일 디자인을 확인하세요.
2. **데스크톱**으로 전환해 스타일이 그대로인지 확인하세요.
3. 에디터에서 제공하는 저장 버튼으로 이메일을 저장하세요.
4. 발송하기 전에 미리보기와 테스트로 넘어가세요.

## 모바일 이메일 미리보기와 테스트하기

미리보기는 빌더 안에서 시각적인 문제를 찾는 데 도움이 되고, 테스트 발송은 실제 받은편지함에서 이메일이 어떻게 보이는지 알려 줘요. 이메일 클라이언트마다 반응형 스타일을 다르게 표시할 수 있어서 두 단계 모두 중요해요.

### 모바일 버전 미리보기

1. 하이퍼클래스 **서브 계정**에서 **마케팅**을 선택하세요.
2. **이메일**을 선택하세요.
3. **템플릿** 또는 **캠페인**을 여세요.
4. **디자인 에디터**에서 이메일을 여세요.
5. 오른쪽 위에서 **미리보기**를 클릭하세요.

![이메일 빌더의 미리보기 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082206946/original/MPuFxaqnUsOUUkyD86dXp1_5REFFMO-BcA.png?1790771937)

6. 기기 미리보기 옵션에서 **모바일**을 선택하세요.

![이메일 빌더의 모바일 기기 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082207011/original/DOo9JkoOqRAWMtmqcxpEZh_44g5mc0roGQ.png?1790771963)

7. 간격, 텍스트, 버튼, 이미지, 동영상, 소셜 아이콘을 확인하세요.
8. **데스크톱**으로 전환해 원래 디자인을 확인하세요.

### 모바일 미리보기에서 확인할 항목

- 섹션 여백과 마진
- 버튼 정렬, 너비, 텍스트 가독성
- 이미지와 동영상의 크기와 비율
- 로고 크기와 정렬
- 소셜 아이콘의 정렬, 크기, 간격
- 제목과 본문 텍스트 크기
- 줄 바꿈과 요소 사이 간격
- 이미지 크기 조절
- 숨겨진 콘텐츠와 보이는 콘텐츠
- 모바일 덮어쓰기를 적용한 뒤의 데스크톱 스타일

### 테스트 이메일 보내기

1. **디자인 에디터**에서 **미리보기**를 찾으세요.
2. **미리보기** 옆의 **점 세 개 메뉴**를 클릭하세요.
3. **테스트 이메일**을 선택하세요.

![미리보기 메뉴에서 테스트 이메일을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082207145/original/ooEyAAyeafZy2hn8UyWoaB7ew-4T4g_mQg.png?1790772033)

4. **발신자 이메일**, **발신자 이름**, **Receiver Email**(수신자 이메일), **Preview Text**(미리보기 텍스트), **이메일 제목** 필드를 입력하세요.

![테스트 이메일 입력 필드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082207221/original/2JRepZk8PSW_QNji7OO-j-DY148DTkf3Ag.png?1790772066)

5. **테스트 이메일 전송**을 클릭하세요.
6. 받은 이메일을 실제 받은편지함에서 여세요.
7. 받는 사람이 주로 쓰는 기기와 이메일 클라이언트에서 모습을 확인하세요.

{% hint style="info" %}
빌더 미리보기와 실제 테스트 이메일을 함께 사용하는 것을 권장해요. 반응형 스타일은 이메일 클라이언트마다 다르게 표시될 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 모바일 글꼴 크기가 바뀌지 않아요.
지원되는 모바일 글꼴 크기 덮어쓰기가 켜져 있는지 확인하세요. 모바일 전용 스타일은 받는 쪽 이메일 클라이언트가 반응형 CSS와 미디어 쿼리를 지원하는지에도 영향을 받아요.

### 모바일 설정이 데스크톱 버전에도 영향을 주나요?
아니요. 모바일 전용 덮어쓰기는 모바일 모습만 바꾸도록 만들어져 있어서 데스크톱 스타일이나 기본 스타일은 그대로 유지돼요.

### 버튼을 모바일에서만 전체 너비로 만들 수 있나요?
네. 지원되는 모바일 **버튼** 설정에서 데스크톱 버튼 디자인은 그대로 두고 전체 너비 스타일을 적용할 수 있어요.

### 소셜 아이콘도 모바일에서 다르게 설정할 수 있나요?
네. 지원되는 **소셜** 요소에서는 모바일 전용 정렬, 아이콘 크기, 간격 설정을 제공해요.

### 기존 템플릿이나 캠페인이 자동으로 바뀌나요?
아니요. 기존 이메일은 모바일 전용 스타일을 수정하지 않는 한 현재 모습을 유지해요.

### 이미지나 동영상 크기를 바꾸면 비율도 달라지나요?
지원되는 크기 조정에서는 가로세로 비율이 자동으로 고정되어 이미지와 동영상의 비율이 유지돼요.

### 받은 이메일이 모바일 미리보기와 다르게 보여요.
이메일 클라이언트마다 렌더링 엔진이 달라서 반응형 CSS를 다르게 처리할 수 있어요. 실제 받은편지함에서 어떻게 보이는지 확인하려면 항상 테스트 이메일을 보내 보세요.
