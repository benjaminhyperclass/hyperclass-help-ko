# 소셜 플래너에서 Facebook 릴 게시하기

**소셜 플래너**에서 Facebook 릴을 바로 만들고 예약할 수 있어요. 영상을 올리고, 캡션과 후속 댓글을 쓰고, 게시 시점도 정할 수 있어요. 이 문서에서는 설정 순서, 영상 조건, 게시 옵션을 안내해요.

[동영상](https://www.youtube.com/embed/WQ4kiJK9wLo?&wmode=opaque)

## Facebook 릴이란?

Facebook 릴은 짧은 세로형 영상이에요. **소셜 플래너**를 쓰면 연결해 둔 Facebook 페이지에 릴을 게시할 수 있어요. 게시물 작성 화면에서 릴 콘텐츠를 준비하고 영상을 미리 확인한 뒤, 바로 게시하거나 나중으로 예약해요.

## Facebook 릴 조건

영상이 지원 범위 안에 있어야 업로드 오류와 게시 실패를 줄일 수 있어요. Facebook 릴을 올리려면 연결된 Facebook 페이지와 호환되는 영상 1개가 필요해요.

| 항목 | 조건 |
| --- | --- |
| Facebook 계정 | 연결된 Facebook 페이지 |
| 영상 파일 크기 | 최대 1 GB |
| 영상 길이 | 3~90초 |
| 영상 첨부 | 릴 1개당 영상 1개 |
| 권장 해상도 | 1080 × 1920 픽셀 |
| 최소 해상도 | 540 × 960 픽셀 |
| 권장 가로세로 비율 | 9:16 |
| 맞춤 썸네일 | 지원되지 않음 |

{% hint style="info" %}
MP4, MOV처럼 호환되는 영상 파일을 사용하세요. 최신 형식 조건은 [소셜 플래너 콘텐츠 가이드라인 – 이미지, 영상, 텍스트](../../26-산업-가이드/기타/posting-content-image-video-and-text-guidelines.md)를 참고하세요.
{% endhint %}

## Facebook 릴 만드는 순서

1. **Facebook 페이지를 연결해요.** **마케팅 > 소셜 플래너**로 이동해 Facebook을 연결하고 인증 안내를 따라가세요. 관리할 Facebook 페이지를 선택하고, 요청하는 권한을 허용하세요.
2. **새 게시물을 만들어요.** **새 게시물 > 새 게시물 만들기**를 클릭해 게시물 작성 화면을 여세요.
3. **Facebook 페이지와 릴을 선택해요.** **게시 대상**에서 연결해 둔 Facebook 페이지를 선택하세요. **Facebook Options**(Facebook 옵션)에서는 **Feed**(피드)나 **Story**(스토리)가 아닌 **릴**을 선택하세요.
4. **영상을 올리고 캡션을 입력해요.** 영상 아이콘을 클릭해 영상을 선택하거나 업로드하세요. **캡션 추가**에 캡션, 해시태그, 이모지를 필요한 만큼 넣으세요. 그다음 **릴스 미리보기**를 확인하세요.
5. **후속 댓글을 추가해요(선택).** **후속 댓글**을 클릭하고, 게시된 릴에 댓글로 달 내용을 입력하세요. 웹사이트 링크, 혜택, 행동 유도 문구를 넣을 수 있어요.
6. **고급 옵션을 설정해요(선택).** **고급 옵션**을 펼쳐 카테고리나 태그를 지정하면 콘텐츠를 정리하기 쉬워요.
7. **릴을 게시하거나 예약해요.** **게시글** 드롭다운을 열고 원하는 동작을 선택하세요.

   - **지금 게시**: 릴을 바로 게시해요.
   - **게시물 예약**: 앞으로의 날짜와 시간을 선택해요.
   - **승인을 위해 게시물 보내기**: 게시 전에 검토를 받도록 릴을 제출해요.
   - **반복 게시물 예약**: 상황에 맞게 반복 게시를 설정해요.

## 자주 묻는 질문

### Facebook 그룹에도 릴을 게시할 수 있나요?
아니요. 소셜 플래너의 Facebook 릴 게시는 Facebook 페이지 기준으로 안내하고 있어요. 그룹 게시물은 일반 피드 게시물로 처리돼요.

### 릴 하나에 영상을 여러 개 올릴 수 있나요?
아니요. 소셜 플래너는 Facebook 릴 하나에 영상 1개만 지원해요.

### Facebook 릴에 웹사이트 링크를 넣을 수 있나요?
캡션에 관련 링크를 넣을 수 있어요. 또는 선택 항목인 **후속 댓글**을 써서 댓글에 링크를 달 수도 있어요.

### Facebook 릴에 맞춤 썸네일을 넣을 수 있나요?
아니요. 현재 소셜 플래너에서는 Facebook 릴에 맞춤 썸네일을 지원하지 않아요.

### Facebook 릴이 게시되지 않아요. 어떻게 하나요?
게시물 상태를 확인하세요. Facebook 페이지가 연결되어 있는지도 확인하세요. 영상이 지원하는 파일 크기, 길이, 해상도 조건을 충족하는지도 살펴보세요.
