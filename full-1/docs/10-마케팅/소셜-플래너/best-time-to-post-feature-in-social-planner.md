# 소셜 플래너의 게시 최적 시간 기능 사용하기

**게시 최적 시간**은 팔로워의 참여 데이터를 분석해 게시물 예약 시간을 추천해 주는 **소셜 플래너** 기능이에요. 반응이 가장 좋은 시간에 게시물이 올라가도록 맞추면 도달 범위와 참여를 더 높일 수 있어요.

## 게시 최적 시간 기능이란?

**게시 최적 시간**은 팔로워의 참여 패턴을 분석해 소셜 미디어에 게시하기 좋은 시간을 알려 주는 데이터 기반 기능이에요. 참여가 가장 활발한 시간에 게시물을 올려 더 많은 사람에게 닿도록 콘텐츠를 계획할 수 있어요.

## 게시 최적 시간 기능의 주요 이점

- **최적화된 게시:** 팔로워 참여 데이터를 바탕으로 한 추천 덕분에 콘텐츠가 더 잘 노출돼요.
- **간편한 사용:** 지금 쓰는 게시물 작성 과정에서 **일정** 옵션만 고르면 바로 쓸 수 있어요.
- **여러 플랫폼 지원:** **소셜 플래너**에 연결된 모든 소셜 계정에서 쓸 수 있어요.
- **참여율 향상:** 참여가 가장 활발한 시간에 게시하면 더 많은 사람에게 닿을 가능성이 높아져요.

## 게시 최적 시간 기능 사용 방법

세 단계로 나누어 설명해요. 순서대로 따라 하면 **게시 최적 시간**을 적용해 게시물을 예약할 수 있어요.

### 1단계: 새 게시물 만들기

1. 서브 계정에서 **마케팅**으로 이동하세요.
2. **소셜 플래너** 탭을 클릭하세요.
3. **+ New Post**(새 게시물) 버튼을 클릭하세요.

   ![+ New Post 버튼](https://jumpshare.com/v/Vn3OO6VDp5h2JBo1VvWD+/Screen+Shot+2025-07-22+at+10.29.13+PM.png)
4. **새 게시물 만들기** 또는 **Upload From CSV**(CSV에서 업로드)를 선택하세요.

   ![새 게시물 만들기와 CSV 업로드 선택](https://jumpshare.com/v/NYAharnGzhlvmbsGWWgC+/Screen+Shot+2025-07-22+at+10.31.52+PM.png)
5. **게시 대상** 섹션에서 게시할 소셜 플랫폼을 선택하세요.

   ![게시 대상 섹션에서 플랫폼 선택](https://jumpshare.com/v/k6JOOu2cvrT3UqRd3XAn+/Screen+Shot+2025-07-22+at+10.34.08+PM.png)

### 2단계: 게시물 내용 입력하기

1. 아래 내용을 넣어 게시물을 만드세요.

   - 텍스트
   - 이미지 또는 미디어
   - 해시태그, 멘션 등

![게시물 내용 입력 화면](https://jumpshare.com/v/yaXnFXZ89cH3ZwiPtNwA+/Screen+Shot+2025-07-23+at+12.02.51+AM.png)

### 3단계: 게시 최적 시간으로 예약하기

1. 게시 버튼 옆의 아래 화살표를 클릭하고, 나타나는 팝업에서 **게시물 예약**을 선택하세요.
2. 팔로워의 참여 추세를 바탕으로 표시되는 **게시 최적 시간** 추천 항목을 확인하세요.
3. 추천 시간대 중 하나를 선택하세요.
4. **게시물 예약** 버튼을 클릭하세요.

![게시 최적 시간으로 게시물을 예약하는 과정](https://jumpshare.com/v/M5hFexFIqNcgAiZ6Iec3+/GIF+Recording+2025-07-23+at+12.05.52+AM.gif)

## 기능 지원 범위와 플랫폼

**게시 최적 시간**을 어디에서 쓸 수 있는지 미리 알아 두면 좋아요. **소셜 플래너**에서 지원하는 화면은 다음과 같아요.

- 게시물 작성 화면과 CSV 일괄 작업에서 쓸 수 있어요. 기본 예약과 고급 예약 모두 지원해요.
- 모바일 앱에서는 쓸 수 없어요. 자세한 계획은 데스크톱에서 세우도록 만든 기능이에요.

## 자주 묻는 질문

### 게시 최적 시간 기능은 정확히 무엇을 하나요?
팔로워의 참여 데이터를 분석해, 선택한 소셜 플랫폼에서 게시하기 좋은 시간을 추천해 줘요.

### 게시 최적 시간 기능을 모바일 앱에서도 쓸 수 있나요?
아니요. 지금은 데스크톱 버전의 게시물 작성 화면과 CSV 일괄 작업 화면에서만 쓸 수 있어요.

### 추천된 게시 시간을 직접 바꿀 수 있나요?
네. 추천 시간이 표시된 뒤에 게시 전략에 맞게 시간을 조정할 수 있어요.

### 어떤 소셜 플랫폼을 지원하나요?
하이퍼클래스를 통해 **소셜 플래너**에 연결한 모든 소셜 미디어 계정에서 쓸 수 있어요.

### 다른 게시 형식도 지원할 예정인가요?
네. 앞으로의 업데이트에서 반복 게시물(Recurring Posts), 리뷰, RSS 피드, 카테고리 대기열(Category Queue) 형식까지 지원이 확대될 예정이에요.
