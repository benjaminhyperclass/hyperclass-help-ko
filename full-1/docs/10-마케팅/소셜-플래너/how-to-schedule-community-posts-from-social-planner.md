# 소셜 플래너에서 커뮤니티 게시물 예약하기

커뮤니티 그룹과 채널에 올릴 게시물을 **소셜 플래너**에서 미리 예약할 수 있어요. 이 문서에서는 커뮤니티 그룹을 연결하고 게시물을 예약하는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/c7U9uDXDLjQ?&wmode=opaque)

## 소셜 플래너에서 커뮤니티 게시물 예약하기

**소셜 플래너**(Social Planner)에서 커뮤니티 게시물을 예약하면 콘텐츠를 미리 만들어 두었다가 원하는 시간에 선택한 커뮤니티 채널에 게시할 수 있어요. 커뮤니티 채널마다 직접 들어가 올릴 필요 없이, 한곳에서 게시물을 준비하고 지원되는 미디어를 첨부하고 게시할 사용자를 고른 뒤 예약하면 돼요.

공지, 주간 참여 유도 글, 코스 업데이트, 이벤트 알림처럼 미리 계획한 콘텐츠를 정해진 시간에 직접 올리지 않고도 커뮤니티에 노출할 때 유용해요.

## 소셜 플래너에서 커뮤니티 게시물을 예약하면 좋은 점

- 한곳에서 계획해요: 다른 예약 게시물과 함께 커뮤니티 콘텐츠도 소셜 플래너에서 예약할 수 있어요.
- 미리 예약해요: 콘텐츠를 미리 계획하고 예약해 두면 각 커뮤니티에 가장 알맞은 시간에 게시물이 올라가요. 참여를 꾸준히 유지하고, 멤버에게 메시지가 가장 잘 닿는 시간에 전달할 수 있어요.
- 콘텐츠를 통합 관리해요: 지난 게시물과 앞으로 올라갈 게시물을 한 화면에서 확인하고 관리할 수 있어요. 모든 커뮤니티의 게시 기록, 예약된 게시물, 현재 상태를 한눈에 보고 빠르게 수정할 수 있어요.

## 소셜 플래너에서 커뮤니티 그룹 연결하기

소셜 플래너에 커뮤니티 그룹과 채널을 연결하는 방법이에요.

1. **마케팅 > 소셜 플래너 > 설정**으로 이동하세요.

   ![마케팅 > 소셜 플래너 > 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084528847/original/vkdqD6VYE3vvOQ0r9haVLDH2bWkUJa2ryQ.png?1793288734)
2. **커뮤니티**를 선택한 다음 **커뮤니티 연결**을 클릭하세요.

   ![커뮤니티 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084844136/original/BvnNJG3c5XguT5Ike4RIlWVhdByN25guiQ.png?1793711588)

   ![커뮤니티 연결 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084844159/original/JJ09sD4mi4PzIQhI9RZoBN-Dtm6NJKkDSw.png?1793711611)
3. 소셜 플래너에서 사용할 커뮤니티 그룹을 선택하세요.

   ![연결할 커뮤니티 그룹 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071931511/original/KsKTaRddOpuQbVPJ9_KabzSTHP9OCy5dvg.png?1779378493)

{% hint style="info" %}
커뮤니티는 해당 서브 계정의 소셜 플래너 안에서만 연결돼요.
{% endhint %}

## 커뮤니티 게시물 만들고 예약하기

1. 소셜 플래너에서 **+ 새 게시물**을 클릭하세요.

   ![새 게시물 버튼 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084844224/original/25EJscAe8wyWKUCpwTulmvhO7QcN5rqQXA.png?1793711667)
2. 채널 또는 계정 선택 영역에서 게시물을 올릴 연결된 **커뮤니티** 채널을 선택하세요. 필요하면 커뮤니티 채널을 하나 또는 여러 개 선택할 수 있어요.

   ![커뮤니티 채널 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084844319/original/jxnZKk7t2fbuMlBKyXnWVc0hvfTVnRCNUQ.png?1793711723)
3. 서식 있는 텍스트와 미디어로 콘텐츠를 작성하세요.

   - **둘 다** 형식: 이미지와 동영상을 모두 사용할 수 있고, 이미지 또는 동영상을 10개까지 올릴 수 있어요.
   - 이미지: 최대 크기는 10MB예요.
   - 동영상: 최대 크기는 1GB이고, 길이는 최소 4초여야 해요.

   ![콘텐츠 작성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071932491/original/Ztuzl56rHv1A0rR54p2Y--qYpD9O65Teyw.jpeg?1779378992)
4. 필수 항목인 **제목**을 입력하고, 게시할 **사용자**를 선택하세요.

   ![제목 입력과 사용자 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035587541/original/TDUPwcTXnQV-9z15t6a70tcmegJ_JJT60Q.png?1730148455)
5. 게시물 정보를 모두 입력했다면 **게시글**을 클릭한 다음 **게시물 예약** 옵션을 선택하세요.

   ![게시글 메뉴에서 게시물 예약 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071933674/original/JzU8vmBRv-_q_wnC4uoYdWxVGj0EV8gwzg.png?1779379530)
6. 원하는 날짜와 시간을 선택하고 **게시물 예약**을 클릭하세요.

   ![날짜와 시간 선택 후 게시물 예약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071933471/original/l8f97xK2EAa0ivYT7LXwmXBi-CreMWe7Qg.png?1779379474)

{% hint style="info" %}
CSV 및 다른 유형의 게시물에서도 커뮤니티 게시가 허용돼요.
{% endhint %}

## 공개 API로 커뮤니티 게시물 예약하기

소셜 플래너 공개 API로도 커뮤니티 게시물을 만들고 예약할 수 있어요. 마켓플레이스 앱이나 비공개 연동에서 커뮤니티 게시를 자동화할 수 있어서, 사용자가 게시물을 하나씩 직접 만들 필요가 없어요.

개발자는 API로 다음 작업을 할 수 있어요.

- 연결된 커뮤니티 채널에서 게시할 수 있는 멤버 목록을 가져와요.
- 게시물을 올릴 커뮤니티 멤버를 선택해요.
- 선택한 멤버가 해당 커뮤니티 그룹에 계속 게시할 수 있는지 확인해요.
- 커뮤니티 게시물을 만들고 예약해요.
- 게시 멤버 정보가 없거나 올바르지 않으면 검증 오류를 받아요.

하이퍼클래스는 게시하기 전에 선택한 멤버의 자격도 확인해요. 멤버에게 더 이상 게시 권한이 없으면 다른 사람 이름으로 게시되지 않고 게시물이 실패해요.

구현 방법은 공식 API 문서에서 확인할 수 있어요. 문서 링크가 필요하면 하이퍼클래스 고객지원에 문의하세요.

- Get Community Members
- Validate Community Member

## 소셜 플래너에서 댓글 관리하기

소셜 플래너에서 커뮤니티 게시물의 댓글을 보고 답글을 달 수 있어요. 자세한 내용은 소셜 플래너 댓글 관리(**댓글 관리**) 문서를 참고하세요.

![소셜 플래너 댓글 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071932921/original/a63m1zCLRNG8hflrwRr0XNDZbMv-C2dCzg.png?1779379170)

## 알아 두세요

- 새 채널이 생기거나 그룹·채널 정보가 바뀌어도 소셜 플래너에 자동으로 반영되지 않아요. **소셜 플래너 설정 > 커뮤니티**로 이동해 그룹과 채널을 다시 동기화하세요.
- **Post Composer**(게시물 작성 영역)에서 게시물을 올릴 사용자를 추가할 수 있어요. **소셜 플래너 > 설정 > 커뮤니티**에서는 새 소셜 게시물을 만들 때 기본으로 사용할 사용자를 선택할 수 있어요.
