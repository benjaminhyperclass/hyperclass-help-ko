# 소셜 플래너 Bluesky 연동

Bluesky 계정을 **소셜 플래너**에 연결하면 앱을 오가지 않고 게시물을 작성, 예약, 게시할 수 있어요. 이 문서에서는 Bluesky 앱 비밀번호를 만들고 계정을 연결하는 방법, 게시 규격과 작성 가이드를 안내해요.

[동영상](https://www.youtube.com/embed/HtvgYE15M08?&wmode=opaque)

Bluesky는 텍스트, 이미지, 동영상을 공유하는 분산형 소셜 네트워크예요. 하이퍼클래스 **소셜 플래너**에서 Bluesky 계정을 연결해 한곳에서 게시할 수 있어요.

---

## Bluesky 연동이란?

Bluesky 연동은 빠르게 성장하는 Bluesky 네트워크를 **소셜 플래너**가 지원하는 채널에 추가해 줘요. 앱 비밀번호로 Bluesky 핸들을 인증하면, Facebook, Instagram, LinkedIn, Google Business Profile, TikTok 등을 관리하던 같은 캘린더에서 Bluesky 게시물을 만들고, 예약하고, 성과를 확인할 수 있어요.

---

## Bluesky 연동의 장점

- 화면 전환 없이 작업: 다른 채널과 함께 **소셜 플래너**에서 Bluesky 게시물을 기획하고, 초안을 쓰고, 게시해요.
- 빠른 고객 승인: 팀이 이미 쓰고 있는 검토·승인 흐름에 Bluesky 게시물도 똑같이 태울 수 있어요. 승인 없이 게시되는 일이 없어요.
- 게시 실패 방지: Bluesky 제한(300자, 이미지 최대 4장 또는 동영상 1개)에 맞춰 작성하면 막판 오류나 게시 실패를 줄일 수 있어요.
- 꾸준한 게시: 한 주 분량의 게시물을 몇 분 만에 한꺼번에 예약할 수 있어서, 팀이 바빠도 Bluesky 계정을 꾸준히 운영할 수 있어요.
- 도구 절약, 비용 절감: 별도의 Bluesky 예약 도구 없이 하이퍼클래스에서 모두 관리해 비용과 관리 부담을 줄여요.

## Bluesky 게시 규격

| 항목 | 이미지 | 동영상 |
| --- | --- | --- |
| 파일 형식 | JPEG, PNG | MP4, MOV |
| 최대 파일 크기 | 1MB | 50MB |
| 게시물당 최대 업로드 수 | 이미지 최대 4장 | 동영상 1개 (이미지와 함께 올릴 수 없어요) |
| 크기 / 해상도 | 일반 웹 해상도 | 480p~720p 권장 |
| 가로세로 비율 | – | 16:9 또는 1:1 |
| 길이 | – | 최대 3분 |
| 프레임 레이트 | – | 30~60FPS |
| 코덱 | – | H.264(영상), AAC(오디오) |
| 기타 | - | 사용자 지정 썸네일 불가 |

## Bluesky 게시 가이드

- 멘션: 전체 핸들로 사용자를 태그해요(예: @name.bsky.social). 자동 완성이 되지 않으니 정확히 입력하거나 복사해서 붙여 넣으세요.
- 해시태그: #해시태그를 쓰면 게시물이 검색에 잘 노출돼요. 문자, 숫자, 밑줄을 쓸 수 있지만 숫자만으로는 만들 수 없어요.
- 글자 수 제한: 게시물당 300자예요.
- 이모지: 사용할 수 있어요.
- 링크:
  - http:// 또는 https://로 시작해야 해요.
  - 길이와 상관없이 23자로 계산돼요.
  - 링크 단축 서비스는 권장하지 않아요.
- 하루 게시 한도: 24시간에 100개예요.

## Bluesky에서 앱 비밀번호 만들기

{% hint style="warning" %}
앱 비밀번호는 한 번만 표시돼요. 놓쳤다면 삭제하고 새로 만들어야 해요.
{% endhint %}

1. 새 탭에서 Bluesky 계정에 로그인하세요.
2. **Settings**(설정) > **Privacy & security**(개인정보 및 보안) > **App Passwords**(앱 비밀번호)로 이동하세요.
3. **+ Add App Password**(앱 비밀번호 추가)를 클릭하세요.
4. 팝업 창에서 앱 비밀번호의 이름을 입력한 뒤 **Next**(다음)를 클릭하세요.

   ![앱 비밀번호 이름 입력 화면](https://jumpshare.com/share/cxIyMvPNAfVEkNLs0Ftl+/GIF+Recording+2025-10-07+at+9.41.50+PM.gif)
5. 앱 비밀번호를 복사하세요. Bluesky를 소셜 플래너에 연결할 때 필요해요.

   ![생성된 앱 비밀번호 화면](https://jumpshare.com/share/zX0FcCl6gvM5BtpzDQ4h+/Screen+Shot+2025-10-07+at+9.43.54+PM.png)

## Bluesky를 소셜 플래너에 연결하기

1. 서브 계정에서 **마케팅**을 클릭하세요.
2. **소셜 플래너**를 클릭하세요.

   ![마케팅 메뉴에서 소셜 플래너 선택](https://jumpshare.com/share/D2dWJYvAFh71XjD4OSt4+/Screen+Shot+2025-10-07+at+6.39.14+PM.png)
3. **+ Socials**(소셜 추가) 버튼을 클릭하세요.

   ![+ Socials 버튼](https://jumpshare.com/share/07mefuMdgHokroabJTpQ+/Screen+Shot+2025-10-07+at+6.43.09+PM.png)
4. **Connect Bluesky**(Bluesky 연결) 옵션을 클릭하세요.

   ![Connect Bluesky 옵션](https://jumpshare.com/share/1XiFShZrjExdwKVZwVx3+/Screen+Shot+2025-10-07+at+8.58.27+PM.png)
5. **Bluesky Username**(Bluesky 사용자 이름)에 @ 없이 입력하세요(예: username.bsky.social).
6. 앞에서 복사한 앱 비밀번호를 붙여 넣으세요. 계정의 원래 비밀번호가 아니에요.

   ![사용자 이름과 앱 비밀번호 입력 화면](https://jumpshare.com/share/5tdnij8BKnmbaRxZSEAM+/Screen+Shot+2025-10-07+at+9.31.22+PM.png)
7. **연결** 버튼을 클릭하세요.

   ![연결 버튼](https://jumpshare.com/share/kGYgMBjmPhBS1Dfyq2Ng+/Screen+Shot+2025-10-07+at+9.56.36+PM.png)
8. 프로필 옆의 **추가** 버튼을 클릭해 소셜 플래너에 추가하세요.

   ![프로필 옆 추가 버튼](https://jumpshare.com/share/JcEUENcTtIpR5uHebyx3+/Screen+Shot+2025-10-07+at+9.58.50+PM.png)
9. 연결이 끝나면 소셜 플래너의 **모든 계정** 드롭다운에 Bluesky 계정이 표시돼요.

   ![모든 계정 드롭다운에 표시된 Bluesky 계정](https://jumpshare.com/share/NdLMYK5jJVIBnJeGFAvi+/Screen+Shot+2025-10-07+at+10.21.34+PM.png)

## Bluesky 댓글 관리

**소셜 플래너**에서 Bluesky 게시물의 댓글을 확인하고, 텍스트와 이모지로 답글을 달 수 있어요. 스레드 형태의 답글로 대화 맥락도 이어 갈 수 있어요(최대 3단계까지 표시).

## 자주 묻는 질문

### Bluesky 로그인 비밀번호 대신 앱 비밀번호가 필요한 이유는 무엇인가요?
보안 때문이에요. Bluesky는 외부 도구가 앱 비밀번호를 쓰도록 요구해서, 원래 계정 정보가 안전하게 보호돼요.

### 앱 비밀번호를 잃어버렸어요. 어떻게 하나요?
Bluesky에서 기존 앱 비밀번호를 삭제하고 새로 만든 다음, 소셜 플래너에서 다시 연결하세요.

### 앱 비밀번호가 만료되면 어떻게 되나요?
Bluesky에서 새 앱 비밀번호를 만들고, 소셜 플래너에서 계정을 다시 연결하세요.

### Bluesky 계정(핸들)을 여러 개 연결할 수 있나요?
네. 계정마다 따로 연결하고, 계정마다 앱 비밀번호가 필요해요.

### Bluesky에서 로그아웃하면 다시 연결해야 하나요?
아니요. 앱 비밀번호로 한 번 연결하면, 계정을 제거하거나 비밀번호를 재설정하기 전까지 연결이 유지돼요.

### 소셜 플래너에서 Bluesky는 어떤 분석 지표를 볼 수 있나요?
게시물, 좋아요, 댓글, 노출, 참여율을 확인할 수 있어요.
