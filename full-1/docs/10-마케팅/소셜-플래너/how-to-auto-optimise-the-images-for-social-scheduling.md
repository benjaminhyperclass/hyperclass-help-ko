# 소셜 플래너에서 이미지 자동 최적화하기

**소셜 플래너**(Social Planner)에 **Media Optimization**(미디어 최적화) 기능이 추가됐어요. 예약할 이미지를 각 소셜 미디어 플랫폼의 요건에 맞게 자동으로 조정해서, 이미지 문제 없이 게시물을 예약할 수 있어요.

## 이 기능의 장점

- **이미지 크기 자동 조정**: 플랫폼별 요건에 맞게 이미지가 바로 조정돼요. 직접 크기를 줄이거나 늘릴 필요가 없어요.
- **품질 유지**: 화질은 그대로 두고 이미지의 시각적 완성도를 지켜요.
- **호환성 향상**: 자동으로 형식이 맞춰져서 각 플랫폼의 기술 요건을 충족해요.
- **빠른 업로드**: 최적화된 이미지는 용량이 작아서 업로드 시간이 줄어요.
- **오류 예방**: 잘못된 가로세로 크기, 너무 큰 파일 용량, 지원하지 않는 형식 같은 흔한 문제가 자동으로 해결돼요.

## 최적화하는 항목

플랫폼별로 생기는 문제를 다음 기준에 따라 해결해요.

- 형식
- 용량
- 가로세로 비율
- 가로세로 크기

## 자동으로 해결되는 플랫폼별 오류

아래 메시지는 이미지가 플랫폼 요건에 맞지 않을 때 나타나는 오류예요. `{format}`, `{size}` 같은 부분에는 실제 이미지 정보가 들어가요.

### Facebook 게시물

- Facebook은 JPEG, PNG, GIF 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- Facebook은 10MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.

### Facebook 스토리

- Facebook 스토리는 JPEG, PNG, GIF 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- Facebook 스토리는 4MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.

### Instagram 게시물

- Instagram은 JPEG, PNG, GIF 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- Instagram은 8MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.
- Instagram Professional은 가로세로 비율이 4:5에서 1.91:1 사이인 이미지를 지원해요. 현재 이미지 비율은 {aspectRatio}예요.

### Instagram 스토리

- Instagram 스토리는 JPEG 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- Instagram 스토리는 8MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.

### Google My Business

- Google My Business는 JPEG, PNG 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- Google My Business는 5MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.
- Google My Business는 최소 720x720, 최대 3000x3000 크기를 지원해요. 현재 이미지 크기는 {width}x{height}예요.

### LinkedIn

- LinkedIn은 JPEG, PNG, GIF 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- LinkedIn은 8MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.
- LinkedIn은 최소 250x250, 최대 6012x6012 크기를 지원해요. 현재 이미지 크기는 {width}x{height}예요.

### Pinterest

- Pinterest는 JPEG, PNG 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- Pinterest는 10MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.

### 커뮤니티

- 커뮤니티는 JPEG, PNG, SVG, GIF, WEBP 이미지 형식을 지원해요. 현재 이미지 형식은 {format}이에요.
- 커뮤니티는 10MB까지의 이미지를 지원해요. 현재 이미지는 {size}MB예요.

## 이 기능이 필요한 이유

![전구 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040503125/original/R0by3CeAhKtQMQ4UW4VUM5bT-hKZuA1hRw.png?1737977262) 소셜 콘텐츠를 예약하다가 이미지 오류가 나면 번거롭죠. **이미지 최적화**를 쓰면 기술적인 부분은 하이퍼클래스가 처리해요. 게시물 만드는 데만 집중하세요.
