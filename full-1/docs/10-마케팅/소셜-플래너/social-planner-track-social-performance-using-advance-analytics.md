# 소셜 플래너 — 고급 분석으로 소셜 미디어 성과 확인하기

하이퍼클래스 **소셜 플래너**의 고급 분석(Advanced Analytics)에서는 연결한 소셜 계정의 참여도, 도달, 노출수, 게시물 성과를 한 화면에서 볼 수 있어요. 이 문서에서는 분석 화면을 여는 방법, 리포트 보는 방법, 반응이 좋은 콘텐츠를 찾는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/vP91D7Ck8z8?&wmode=opaque)

---

## 고급 분석이란?

고급 분석은 지원하는 플랫폼 전반의 소셜 미디어 성과를 한곳에 모아 보여 줘요. 참여도를 확인하고 계정별 성과를 비교할 수 있어요. 리포트에서 얻은 인사이트로 소셜 미디어 전략도 개선할 수 있어요.

---

## 고급 분석의 주요 장점

고급 분석을 쓰면 오디언스의 반응을 파악하고 소셜 미디어 콘텐츠를 개선할 부분을 찾을 수 있어요.

- 종합 인사이트: 여러 소셜 미디어 플랫폼의 게시물 수, 좋아요, 댓글, 팔로워, 노출수, 도달을 한 대시보드에서 확인해요.
- 게시물 성과 시각화: 인터랙티브 그래프로 게시 추이와 주간 성과를 볼 수 있어요.
- 참여도 상세 보기: 총 좋아요, 댓글, 공유 같은 참여도 지표를 플랫폼별로 나누어 볼 수 있어요.
- 플랫폼 비교: 어느 플랫폼에서 반응이 더 좋은지 확인하고 콘텐츠 전략에 반영할 수 있어요.
- 노출수와 게시물 도달: 도달(Reach)과 노출수로 콘텐츠가 얼마나 노출되는지 측정해요.
- 성별·연령 분포: 오디언스를 연령대와 성별로 나누어 보고, 콘텐츠를 알맞은 대상에 맞추는 데 활용할 수 있어요.

---

## 고급 분석 위치

분석 대시보드는 **마케팅 > 소셜 플래너 > 통계**에서 열 수 있어요.

---

## 지원 플랫폼과 제한 사항

플랫폼마다 볼 수 있는 지표가 달라요. 아래 내용을 확인해 두면 분석 데이터가 끊기지 않고 들어오는 데 도움이 돼요.

#### 지원 플랫폼

Facebook, Instagram, LinkedIn, YouTube, Pinterest, TikTok, Google Business Profile(GBP), Threads, Bluesky

#### 권한 및 재인증 알림

연결한 계정이 분석 데이터에 접근하려고 재인증이 필요하면 실시간으로 알림을 받아요. 덕분에 최신 인사이트를 끊김 없이 볼 수 있어요. 다음 날부터, 또는 권한을 업그레이드해 계정을 다시 연결한 시점부터 통계를 볼 수 있어요.

#### 게시물별 통계

게시물별 통계는 게시물 상세 창(플래너 > **목록 보기**)에 표시돼요.

- 지원하는 플랫폼: Facebook, Instagram, TikTok 개인 계정, LinkedIn 페이지
- 지원 예정 플랫폼: YouTube, Pinterest
- 지원하지 않는 플랫폼: Google Business Profile, TikTok 비즈니스 계정, LinkedIn 프로필, 커뮤니티

#### 플랫폼별 참고 사항

TikTok

- 비즈니스 프로필만 지원해요.
- TikTok API 제공 상황 때문에 데이터가 반영되기까지 1~2일 걸릴 수 있어요.

Pinterest

- 정확한 데이터가 반영되기까지 n-2일이 걸려요(n은 오늘). API 제약 때문에 Hootsuite 같은 다른 포털에서도 비슷하게 나타나요.

LinkedIn

- API 제약 때문에 LinkedIn 페이지만 지원하고, LinkedIn 프로필은 지원하지 않아요.
- **총 팔로워 수**를 확인할 때 참고하세요. 팔로워 데이터는 n-2일까지만 볼 수 있어요(n은 오늘).

Threads

- 노출수와 게시물 도달은 지원하지 않아요. <!-- 검토 필요: 원문 내용이 서로 다름 -->
- 팔로워 수, 성별 데이터, 고급 참여도 지표는 지원하지 않아요. <!-- 검토 필요: 원문 내용이 서로 다름 -->
- 게시물 수를 제외한 지표는 T-1일 지연돼요.

Bluesky

- 노출수를 지원해요. <!-- 검토 필요: 원문 내용이 서로 다름 -->
- 팔로워 지표, 인구통계, 고급 참여도 세부 지표는 지원하지 않아요. <!-- 검토 필요: 원문 내용이 서로 다름 -->
- 게시물 수를 제외한 지표는 T-1일 지연돼요.

{% hint style="info" %}
새로 추가된 플랫폼은 인구통계를 지원하지 않아요.
{% endhint %}

## 리포트와 지표 살펴보기

{% hint style="info" %}
각 지표 옆의 툴팁 아이콘(i)에 마우스를 올리면 지표 정의, 지원 플랫폼, 기간 정보를 볼 수 있어요.
{% endhint %}

### KPI Overview(KPI 개요)

모든 플랫폼의 게시물 수, 좋아요, 팔로워, 노출수, 댓글을 한눈에 확인해요.

- **게시물 수**: 선택한 모든 소셜 계정에 게시된 전체 게시물 수예요.
- **Total Likes**(총 좋아요 수): 선택한 모든 계정에 게시된 게시물이 받은 전체 좋아요 수예요.
- **총 팔로워 수**: 선택한 모든 소셜 계정에서 새로 팔로우한 고유 팔로워의 총합이에요.
- **노출수**: 선택한 모든 소셜 계정에 게시된 게시물의 고유 노출수 합계예요.
- **댓글**: 선택한 모든 소셜 계정에 게시된 게시물의 전체 댓글 수예요.

![KPI 개요](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084839714/original/wLrZEi2E8xAyBCRth27fWXwu4QwAUQf2MA.png?1793709752)

### Social Post Performance(소셜 게시물 성과)

인터랙티브 그래프로 소셜 게시물 성과를 볼 수 있어요. 막대는 게시된 게시물 수를, 선은 노출수·좋아요·댓글의 일별 합계를 나타내요. 게시 추이와 주간 성과를 한눈에 확인할 수 있어요.

- 막대 그래프(주간 게시물): 선택한 모든 소셜 미디어 플랫폼에서 주마다 게시한 게시물 수를 보여 줘요.
- 선 그래프(참여도): 게시 시점과 상관없이 하루 동안 발생한 전체 상호작용(댓글, 좋아요, 공유) 수를 보여 줘요.

![소셜 게시물 성과 그래프](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840015/original/PTx7sABmWqAAJsC9bAC6-tTx6jsJX9qRaQ.png?1793709790)

### Link Clicks by Socials(소셜별 링크 클릭)

선택한 모든 소셜 계정에 게시한 게시물의 링크 클릭 수를 소셜 플랫폼별로 보여 줘요.

{% hint style="warning" %}
소셜 플래너에서 만든 축약 링크만 추적할 수 있어요. 링크 축약기에 대한 자세한 내용은 **링크 축약기** 문서를 참고하세요.
{% endhint %}

![소셜별 링크 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064028648/original/MsUUFrK6GBBUjaPUJrpm4n38saHa7jkRlw.png?1770062729)

### Link Performance(링크 성과)

모든 소셜 플랫폼에서 축약 링크의 성과를 확인해요. 캠페인에 속한 링크별 총 클릭 수도 볼 수 있어요.

{% hint style="warning" %}
소셜 플래너에서 만든 축약 링크만 추적할 수 있어요. 링크 축약기에 대한 자세한 내용은 **링크 축약기** 문서를 참고하세요.
{% endhint %}

### 게시물 수

선택한 모든 소셜 계정에 게시한 전체 게시물 수를 플랫폼별로 보여 줘요. 이번 주 게시물 수를 지난주와 비교해서 볼 수 있어요.

![게시물 수](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840127/original/GdYAGWJynCT2WpPyrETa4vCy7LwjQvPAyQ.png?1793709830)

### 참여도

게시된 게시물이 받은 고유 좋아요, 댓글, 공유 수를 플랫폼별로 나누어 보여 줘요. 참여도 퍼센트는 이번 주 데이터가 지난주와 비교해 얼마나 달라졌는지를 나타내요.

![참여도](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840147/original/_F7xe4KMbum7tVZaSsIB0R1YbR38iwDRPg.png?1793709855)

### 노출수

게시된 게시물이 사람들의 화면에 표시된 횟수를 보여 줘요. 노출수 퍼센트는 이번 주 데이터가 지난주와 비교해 얼마나 달라졌는지를 나타내요.

![노출수](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840223/original/QIIwpe8vLoQW_NvdXtgh42RZxPeg409Gow.png?1793709899)

### Post Reach(게시물 도달)

내 페이지나 계정의 콘텐츠, 또는 내 페이지에 관한 콘텐츠를 화면에서 본 사람이 몇 명인지 확인해요. 게시물, 체크인, 광고, 페이지와 상호작용한 사람들의 소셜 정보 등이 포함돼요. 게시물 도달 퍼센트는 이번 주 데이터가 지난주와 비교해 얼마나 달라졌는지를 나타내요.

Google Business Profile에서는 통화 클릭, 웹사이트 클릭, 음식 주문, 예약, 음식 메뉴 클릭, 길찾기 요청의 합계가 표시돼요.

![게시물 도달](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840468/original/PwEb0P7gmjs4GvI1PCOy59O-ieD3Bcmc6A.png?1793710012)

### Top Performing Posts(인기 게시물)

이 리포트에서는 지금까지 가장 반응이 좋았던 게시물을 볼 수 있어요. 소셜 플래너에서 게시한 소셜 게시물 중 좋아요가 가장 많은 게시물이 인기 게시물이에요. 게시물 옆의 눈 모양 아이콘을 클릭하면 해당 소셜 미디어 플랫폼에서 그 게시물을 볼 수 있어요.

![인기 게시물](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840467/original/CO7vy53LNMNkU94j78Z5t6t7rZzxsJMpGw.png?1793710012)

### Engagement Stats(참여도 통계)

총 좋아요, 댓글, 공유 같은 참여도 지표를 플랫폼별로 나누어 자세히 볼 수 있어요. 선택 리본에서 **Total Engagement**(총 참여도), **총 팔로워 수**, **Total Likes**(총 좋아요 수)를 전환해 볼 수 있어요. 이 리포트로 어떤 플랫폼에서 참여도가 높은지 확인하고 콘텐츠 전략에 반영하세요.

![참여도 통계](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840558/original/VN1J9-T1vQZIJS4eqFN8XfgH1JSCZwyBAg.png?1793710050)

### Gender Demography(성별 분포)

성별 분포(남성, 여성, 알 수 없음)와 연령대 같은 인구통계 데이터를 자세히 볼 수 있어요. 인구통계 데이터는 해당 소셜 미디어 플랫폼에 계산용 데이터 공유를 허용한 사용자의 데이터만 집계돼요.

![성별 분포](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084840703/original/KhXv3fsP34kidrmc5y27-Y8jD9EwMKjKsg.png?1793710096)

{% hint style="warning" %}
팔로워가 100명 미만인 Instagram 사용자는 이 지표를 볼 수 없어요.
{% endhint %}

## 알아 둘 점

리포트의 한계를 알아 두면 성과 데이터를 더 정확하게 해석할 수 있어요.

- 지표 지원 여부: 플랫폼 API 제한 때문에 일부 지표는 볼 수 없어요.
- 보고 지연: 플랫폼과 지표에 따라 분석 데이터가 업데이트되기까지 하루 이상 걸릴 수 있어요.
- 계정 요건: 대시보드 분석에는 LinkedIn은 페이지가, TikTok은 비즈니스 계정이 필요해요. 게시물별 통계는 요건이 다를 수 있어요.
- Instagram 인구통계: 인구통계 인사이트는 팔로워가 100명 이상이어야 볼 수 있어요.
- 계정 권한: 일부 계정은 분석 데이터를 계속 표시하려면 다시 연결하거나 권한을 업데이트해야 할 수 있어요.
- 게시물 동기화: 동기화되는 지원 게시물의 참여도 인사이트는 약 24시간마다 새로 고쳐져요.

## 자주 묻는 질문

### 소셜 플래너 분석에서 어떤 지표를 확인할 수 있나요?
참여도, 게시물 도달, 노출수, 클릭 수, 소셜 미디어 콘텐츠의 전반적인 성과 등 다양한 지표를 확인할 수 있어요. 이 데이터로 전략이 얼마나 효과적인지 평가할 수 있어요.

### 게시물별로 성과를 비교할 수 있나요?
네, 분석 대시보드에서 개별 게시물의 성과를 시간 흐름에 따라 비교할 수 있어요. 추세를 파악하고 어떤 유형의 콘텐츠가 오디언스에게 반응이 좋은지 확인하는 데 도움이 돼요.

### 분석 데이터를 리포트용으로 내보낼 수 있나요?
아니요, 소셜 플래너는 현재 분석 데이터 내보내기를 지원하지 않아요. 앞으로 몇 분기 안에 여러 형식으로 내보낼 수 있도록 지원할 계획이에요. 그러면 리포트를 만들고 팀이나 이해관계자와 인사이트를 쉽게 공유할 수 있어요.

### 분석 데이터는 얼마나 자주 업데이트되나요?
분석 데이터는 보통 실시간으로 업데이트돼서 소셜 미디어 성과를 계속 확인하고 전략을 바로바로 조정할 수 있어요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

### 분석 데이터를 효과적으로 해석하는 팁이 있나요?
목표에 맞는 핵심 성과 지표(KPI)에 집중하세요. 시간에 따른 패턴을 살펴보고, 비슷한 게시물끼리 비교하고, 참여도에 영향을 줄 수 있는 외부 요인도 함께 고려하세요.

### 소셜 플래너 분석에서는 어떤 기간을 볼 수 있나요?
현재는 주 단위 분석 데이터만 볼 수 있어요.
