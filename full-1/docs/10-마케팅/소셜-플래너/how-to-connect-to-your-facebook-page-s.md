# Facebook 페이지 연결하기

**소셜 플래너**(Social Planner)에 Facebook 페이지를 연결하는 방법을 안내해요. 페이지를 연결하면 게시물을 올리고 Facebook 팔로워와 소통할 수 있어요.

소셜 플래너에는 보유한 팬 페이지를 모두 추가할 수 있어요. 추가한 Facebook 페이지로 게시물을 발행하고, Facebook 사용자와 소통하세요.

---

## Facebook 페이지 게시 설정 가이드

아래 순서대로 따라 하면 Facebook 페이지를 하이퍼클래스에 연결할 수 있어요.

1. 이전에 어떤 프로필에서든 Facebook 페이지를 연결한 적이 있고 새 페이지를 추가하려면, 먼저 Facebook 계정의 **Settings**(설정) > **Business Integration**(비즈니스 통합) 섹션에서 하이퍼클래스 앱을 **Remove**(제거)하세요. 그다음 아래 단계를 처음부터 다시 진행하세요. 아래 이미지를 참고하세요.
2. Facebook 페이지를 모두 추가하려면 해당 페이지의 관리자 권한이 있어야 해요. 관리자로 지정된 페이지가 모두 들어 있는 프로필로 반드시 로그인하세요.

{% hint style="warning" %}
Facebook이 최근 API를 변경하면서 Facebook 개인 프로필에 게시하는 것은 더 이상 권장하지 않아요. 다만 여러 프로필의 페이지를 소셜 플래너에 추가할 수는 있어요.
{% endhint %}

---

## Facebook 페이지 연결 방법

### 1단계. 소셜 계정 연결 열기

먼저 **소셜 플래너**로 이동하세요. 소셜 플래너 오른쪽 위에 설정 옵션(톱니바퀴 아이콘)이 있어요. 이 아이콘을 클릭해 **설정**으로 이동하세요.

```
소셜 플래너에서는 세 가지 방법으로 소셜 계정을 연결하거나 관리할 수 있어요.

• + Socials를 클릭하면 소셜 계정 연결 창이 바로 열려요.
• 톱니바퀴 아이콘을 클릭하면 소셜 플래너 설정이 열려요.
• 설정 탭을 클릭해 소셜 플래너 설정을 연 다음, + 소셜 연결을 클릭하세요.
```

![소셜 플래너에서 설정을 여는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084924900/original/lbhw-1vlH0RIHdJsIqRyG18HbDofIDJirw.gif?1793788800)

### 2단계. 소셜 플랫폼으로 Facebook 선택하기

Facebook 옵션을 클릭하세요. Facebook 로그인 페이지로 이동하면 로그인 정보를 입력하세요.

![Facebook 옵션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084925873/original/NdbQFFsWnlm47q-43x0GkrF42Kam5AIKPg.png?1793789258)

### 3단계. Facebook 페이지를 불러올 권한 허용하기

프로필을 처음 연결하는 경우에는 모든 권한을 허용해야 해요. **Continue**(계속)를 클릭해 Facebook 페이지를 불러오는 승인 과정을 마치세요.

![Facebook 권한 승인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48194300294/original/M5aicg2aO0Jt7HmivVYhOCtO7ICrCZ87jQ.png?1645733508)

### 4단계. 연결할 Facebook 페이지 선택하기

이 프로필에 있는 Facebook 페이지가 모두 나타나요. 소셜 플래너에 연결할 페이지를 선택하세요.

![연결할 Facebook 페이지 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48194300386/original/idLMJiroiLrnkf5XRoC2wWENqdOKYQrWmg.png?1645733550)

### 5단계. 연결 확인하기

마지막으로, 앞 단계에서 선택한 페이지가 목록에 모두 표시되고 연결에 성공했다는 것을 확인하세요. 아래 이미지를 참고하세요.

같은 방법으로 하나의 Facebook 프로필이든 서로 다른 프로필이든 원하는 만큼 페이지를 추가할 수 있어요.

![연결된 Facebook 페이지 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48194300958/original/FEF-VoEtHe7LRXy1V2qhhno8eLueDCTqqw.png?1645733750)

## 자주 묻는 질문

### Facebook 페이지를 소셜 플래너에 여러 개 연결할 수 있나요?

네, 여러 개 연결할 수 있어요. 승인할 때 사용하는 Facebook 계정에 연결하려는 각 페이지에 대한 필요한 권한이 있어야 해요.

### 서로 다른 Facebook 프로필의 페이지도 연결할 수 있나요?

네, 연결할 수 있어요. 페이지를 연결할 때는 그 페이지에 필요한 권한이 있는 Facebook 프로필로 로그인하고 승인 과정을 마치세요.

### 연결하려는 Facebook 페이지가 목록에 나타나지 않아요

Facebook 계정에 해당 페이지에 대한 필요한 권한이 없거나, Facebook 승인 과정에서 그 페이지가 포함되지 않았을 때 이런 일이 생길 수 있어요. Facebook에서 페이지 권한을 확인한 다음, 필요하면 계정을 다시 연결하세요.
