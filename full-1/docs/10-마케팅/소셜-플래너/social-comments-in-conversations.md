# 대화에서 소셜 댓글 확인하고 답하기

소셜 미디어 게시물에 달린 댓글을 **대화**(Conversations) 인박스에서 바로 확인하고 답할 수 있어요. 이 문서에서는 댓글 동기화를 켜고 끄는 방법, 댓글 설정, 댓글에 답하는 방법을 안내해요.

**소셜 플래너**와 각 소셜 플랫폼을 오가지 않아도 돼요. SMS, 이메일, DM을 관리하던 곳에서 댓글도 함께 처리할 수 있어요.

댓글 동기화를 켜면 댓글을 단 사람이 연락처로 저장되고, 댓글은 원본 게시물과 함께 대화 스레드로 표시돼요. 팀은 공개 답글을 달거나, 비공개 DM으로 대화를 이어 가거나, 워크플로우로 잠재 리드에게 자동으로 후속 조치를 할 수 있어요.

{% hint style="warning" %}
소셜 댓글을 켜면 새로 댓글을 다는 모든 사람의 연락처도 함께 만들어져요. 댓글 동기화가 켜져 있는 동안에는 연락처 생성만 따로 끌 수 없어요.
{% endhint %}

---

## 이런 분께 유용해요

- 여러 고객사의 소셜 미디어를 관리하는 **에이전시 관리자**
- 소셜에서 들어오는 문의를 처리하는 영업팀과 담당자
- **소셜 플래너**로 소셜 콘텐츠를 게시하는 비즈니스
- 소셜 반응을 대화, 리드, 기회로 이어 가고 싶은 팀

---

## 소셜 댓글은 이렇게 동작해요

댓글 동기화를 켜면 연결된 소셜 계정의 댓글이 **대화 > 팀 인박스**로 자동으로 들어와요.

댓글 하나마다 다음과 같이 처리돼요.

1. 댓글을 단 사람이 새 연락처로 만들어져요.
2. 댓글이 팀 인박스에 대화로 표시돼요.
3. 대화 맨 위에 원본 게시물이 함께 표시돼 맥락을 알 수 있어요.
4. 팀은 댓글에 공개 답글을 달거나 비공개 DM을 보낼 수 있어요.
5. 기존 워크플로우가 댓글을 기준으로 후속 액션을 실행할 수도 있어요.

{% hint style="info" %}
**소셜 플래너**로 게시한 글의 댓글만 동기화돼요. Facebook, Instagram 등 소셜 플랫폼에서 직접 게시한 글의 댓글은 동기화되지 않아요. 플랫폼의 제한 때문이에요.
{% endhint %}

---

## 시작하기 전에

소셜 댓글을 켜기 전에 아래를 확인하세요.

- **에이전시 관리자**이거나, 해당 서브 계정의 관리자 권한이 있어야 해요.
- **소셜 플래너**에 지원되는 소셜 계정이 한 개 이상 연결되어 있어야 해요.
- 서브 계정에서 **대화**가 활성화되어 있어야 해요.

## Step 1: 댓글 동기화 관리하기

대상이 되는 서브 계정에서는 댓글 동기화가 기본으로 켜져 있어요. 소셜 댓글이 대화 인박스에 나타나지 않게 하려면 에이전시 또는 서브 계정 수준에서 댓글 동기화를 끌 수 있어요.

### 서브 계정 하나의 댓글 동기화 끄기

1. **에이전시 설정 > 소셜 댓글**로 이동하세요.
2. 댓글 동기화를 끄려는 서브 계정을 찾으세요.

![에이전시 설정의 소셜 댓글 서브 계정 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082807489/original/YQeLcek55qYkaijv0s9X-LJEY07SN92IyQ.png?1791441914)

3. **Comment Sync**(댓글 동기화)를 끄세요.

![Comment Sync를 끄는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082807511/original/OuY6ur4LhmqATe8DK-CG7pm-A3ZskleVJw.png?1791441941)

4. 확인 안내 문구를 읽어 보세요.
5. **확인**을 눌러 변경을 적용하세요.

![확인 창에서 확인을 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082807525/original/OS8kO5QjDIxfnFSvbwbgoHvhfe7137mhmw.png?1791441957)

끄고 나면 해당 서브 계정의 **새 소셜 댓글은 더 이상 대화로 동기화되지 않아요.**

{% hint style="info" %}
댓글 동기화를 꺼도 그 전에 만들어진 연락처와 대화는 삭제되지 않아요. 기존 대화는 **대화**에 그대로 남아 있어요.
{% endhint %}

### 여러 서브 계정의 댓글 동기화 한 번에 끄기

에이전시 관리자는 댓글 동기화를 일괄로 끌 수도 있어요.

1. **에이전시 설정 > 소셜 댓글**로 이동하세요.
2. 댓글 동기화를 끄려는 서브 계정을 선택하세요.
3. 일괄 작업 바에서 **Disable Comment Sync**(댓글 동기화 비활성화)를 선택하세요.

![일괄 작업 바에서 Disable Comment Sync를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082807653/original/k5AQCOc1n4rYMLm1RnrPSg8qfQrodm7-mQ.png?1791442037)

4. 확인 창의 내용을 읽어 보세요.
5. **확인**을 누르세요.
6. 설정이 변경된 서브 계정을 알려 주는 성공 알림이 나타나요.

### 서브 계정에서 직접 댓글 동기화 끄기

서브 계정 권한이 있는 사용자는 아래 경로에서도 이 설정을 관리할 수 있어요.

**마케팅 > 소셜 플래너 > 설정 > 댓글**

**댓글을 대화로 동기화** 토글을 끄면 새 소셜 댓글이 대화에 나타나지 않아요.

![서브 계정의 댓글 설정에서 댓글을 대화로 동기화 토글을 끄는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082812495/original/b3BGPrX94A6J9aa3dMQf1e2T5LULLdPBPw.png?1791445314)

### 댓글 동기화를 끄면 어떻게 되나요?

댓글 동기화를 끄면 다음과 같이 돼요.

- 새 소셜 댓글이 더 이상 대화로 동기화되지 않아요.
- 이미 만들어진 소셜 댓글 대화는 인박스에 남아 있어요.
- 소셜 댓글로 만들어진 기존 연락처는 **삭제되지 않아요**.
- 기존 워크플로우 자동화는 삭제되거나 바뀌지 않아요.
- **소셜 플래너**에서의 댓글 관리는 계속 쓸 수 있어요.
- 원할 때 댓글 동기화를 다시 켤 수 있어요.

## Step 2: 서브 계정에서 댓글 설정하기

댓글 설정은 **마케팅 > 소셜 플래너 > 설정 > 댓글**에서 할 수 있어요. 아래 항목을 설정할 수 있어요.

### 1. Sync These Channels(동기화할 채널)

채널별 토글로 어떤 소셜 플랫폼의 댓글을 대화로 보낼지 정해요.

연결된 계정이 없는 플랫폼에는 토글 대신 **계정 연결**이 표시돼요.

![채널별 댓글 동기화 토글과 계정 연결 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082812687/original/p2z8FcWKC5uo-HNq8t-mbAKjVMNR9bCpkg.png?1791445445)

출시 시점에는 Facebook, Instagram, TikTok을 지원해요. 다른 플랫폼은 곧 지원할 예정이에요.

### 2. Identify Social Leads(소셜 리드 찾기)

구매 의사를 보이는 키워드를 추가하세요. 예를 들면 다음과 같아요.

- `가격`
- `관심 있어요`
- `구매 가능`
- `얼마예요`

이 키워드가 들어간 댓글은 해당 정렬 옵션을 사용할 때 인박스 맨 위에 표시될 수 있어요. 키워드는 개수 제한 없이 추가할 수 있어요.

### Comments With Questions(질문이 포함된 댓글)

이 옵션을 켜면 물음표가 들어간 댓글이 우선 표시돼요.

예를 들면 이런 댓글이에요.

> "이거 얼마예요?"

> "텍사스로도 배송되나요?"

질문 형태의 댓글은 구매 의사가 더 높을 수 있어서 맨 위에 표시될 수 있어요.

![질문이 포함된 댓글 옵션과 키워드 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082812793/original/BToW7H0WmBKjLIL-hC894GX_ipF4_70h7A.png?1791445519)

## Step 3: 대화에서 처음 설정 마치기

댓글 동기화를 켠 뒤 **대화**를 처음 열면 기능을 설명하는 안내 창이 한 번 나타나요.

이 창에서 **댓글 동기화 설정**을 클릭하면 **소셜 플래너 > 설정**으로 이동해요. 거기서 필요한 대로 설정하세요.

![대화를 처음 열 때 나타나는 댓글 동기화 설정 안내 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082812848/original/BUBTf-8Y4zx5UbUTf2JFDyQGO0efLjhyZA.png?1791445560)

## 대화에서 소셜 댓글 확인하기

댓글 동기화를 켜면 소셜 댓글이 **팀 인박스**에 다른 대화와 함께 바로 표시돼요. 별도의 인박스나 탭이 따로 생기지는 않아요.

소셜 댓글 항목에는 다음 정보가 표시될 수 있어요.

- 댓글 작성자의 이름 또는 소셜 계정 아이디
- 댓글 미리보기
- 댓글이 달린 게시물
- 소셜 플랫폼 아이콘
- 시간

![팀 인박스에 표시된 소셜 댓글 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082813108/original/yOGuArqA8VTsetHzRedXfIXlCo4ETkCscg.png?1791445710)

### 소셜 댓글만 보기

소셜 댓글 대화만 보려면 다음과 같이 하세요.

1. **팀 인박스**를 여세요.
2. **소셜 댓글** 필터를 클릭하세요.
3. 인박스에 소셜 댓글 스레드만 표시돼요.

![소셜 댓글 필터를 적용한 팀 인박스](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082813248/original/JfyeNfwqfSZfNmtfpawcGcv6I_Eu7sxdOg.png?1791445790)

## 소셜 댓글 열기

**팀 인박스**에서 소셜 댓글을 클릭하면 대화 스레드가 열려요. 대화 화면에는 원본 게시물과 댓글이 함께 표시돼요.

### 게시물 카드

대화 맨 위의 게시물 카드에는 다음 정보가 표시될 수 있어요.

- 게시물 썸네일
- 게시물 캡션
- **소셜 계정** 이름
- 소셜 플랫폼
- 소셜 플랫폼에서 원본 게시물을 여는 **View Post ↗**(게시물 보기) 링크

![대화 맨 위의 게시물 카드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082813420/original/Md-PKSxrIFRFDLI57q2EKrjEdWKDZ2UI4A.png?1791445875)

### 연락처 세부정보

오른쪽 **연락처 세부정보** 패널에는 댓글 작성자로 새로 만들어졌거나 기존 연락처와 연결된 정보가 표시돼요. 확인할 수 있는 항목은 다음과 같아요.

- 이름
- 소셜 플랫폼
- **태그**
- **연락처 소스**
- **제안 액션**

## 소셜 댓글에 답하기

대화 화면에서 바로 답할 수 있어요. 답하는 방법은 두 가지예요.

### Public Reply(공개 답글)

1. **Public Reply**를 사용하면 소셜 플랫폼에서 원본 댓글 아래에 공개로 답글을 달 수 있어요.
2. 답글은 원본 게시물과 댓글을 볼 수 있는 다른 사용자에게도 보여요.
3. 플랫폼별 글자 수와 미디어 제한이 적용돼요.

### Send DM(DM 보내기)

1. **Send DM**을 사용하면 댓글 작성자와 비공개로 대화를 이어 갈 수 있어요.
2. 비공개 대화는 메인 인박스에 일반 DM 스레드로 옮겨지고, 원본 댓글 스레드에는 **Continued in DM**(DM으로 이어짐) 표시가 나타나요.

![Send DM으로 비공개 대화를 이어 가는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082813704/original/Awr9dugT4OP3kKBz-fIww5GuYdJAIzwesg.png?1791445989)

## 구매 의사가 높은 소셜 리드 찾아 우선 처리하기

게시물 하나에 댓글이 많이 달리면 필터와 정렬 도구로 인박스를 정리해 보세요.

다음과 같이 할 수 있어요.

1. **소셜 댓글** 필터로 소셜 댓글 스레드만 보세요.

이렇게 하면 다른 반응을 놓치지 않으면서 잠재 리드에 집중할 수 있어요.

![소셜 댓글 필터로 소셜 댓글 스레드만 표시한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082814704/original/FQx8gEtW_9brE2BYVON6_KEwZLY53vSXTg.png?1791446431)

- 구매 의사를 나타내는 키워드를 추가해 관련 댓글을 우선 표시하세요.
- **Comments With Questions**를 켜서 질문이 포함된 댓글을 먼저 표시하세요.

![키워드 추가와 질문이 포함된 댓글 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082814588/original/NLNV-GplkZ8EeIgUYLPM3JL3dJTNWmMu-w.png?1791446344)

- **정렬** 옵션을 사용해 구매 의사가 높은 댓글을 맨 위로 올리세요.

- TikTok: Instagram을 직접 연결할 때와 같아요. 계정은 **연동**에 동기화되지만, 메시지는 기본으로 꺼져 있어요. 켜면 직접 수신·발신은 되지만, TikTok은 비공개 DM을 지원하지 않아요.
- **소셜 플래너**로 연결한 Facebook은 DM 옵션이 기본으로 꺼져 있고, **연동**에서도 연결된 것으로 표시되지 않아요.
- **소셜 플래너**로 연결한 계정에서 DM을 쓰려면 설정에서 켜야 해요.

## 자주 묻는 질문

### 소셜 플래너로 게시하지 않은 글의 댓글도 동기화되나요?

아니요. **소셜 플래너**로 게시한 글의 댓글만 동기화돼요. Facebook, Instagram 등 다른 플랫폼에서 직접 게시한 글의 댓글은 포함되지 않아요.

### 댓글 동기화를 끄면 어떻게 되나요?

새 댓글은 더 이상 동기화되지 않아요. 동기화를 끄기 전에 만들어진 연락처와 대화는 그대로 남고 삭제되지 않아요.

### 기존 Facebook, Instagram, TikTok 댓글 워크플로우는 계속 작동하나요?

네. 기존 워크플로우 트리거는 이전처럼 계속 작동해요. 댓글 동기화를 켜도 기존 워크플로우의 동작이 바뀌거나 깨지지 않아요.

### 같은 사람이 여러 번 댓글을 달 수 있나요?

네. 댓글마다 인박스에 각각 항목이 생기지만, 같은 사람의 댓글은 같은 연락처 기록에 연결돼요. 중복 연락처는 만들어지지 않아요.

### 소셜 계정 연결이 만료됐어요. 어떻게 하나요?

**소셜 플래너** 설정에서 해당 소셜 계정을 다시 연결하세요. 계정이 정상적으로 다시 연결되면 댓글 동기화가 재개될 수 있어요.

### 소셜 플래너에서도 댓글을 계속 관리할 수 있나요?

네. 대화의 소셜 댓글은 댓글을 보고 답하는 방법을 하나 더 추가하는 기능이에요. **소셜 플래너**의 기존 댓글 관리 기능도 계속 쓸 수 있어요.
