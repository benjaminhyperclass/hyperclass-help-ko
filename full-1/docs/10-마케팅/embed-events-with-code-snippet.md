# 코드 스니펫으로 이벤트 페이지를 내 사이트에 삽입하기

공개 이벤트 페이지를 퍼널, 웹사이트, 외부 플랫폼에 그대로 띄워 방문자가 사이트를 벗어나지 않고 등록할 수 있게 해요. 이 문서에서는 임베드 코드를 만들고, 한 번에 복사하고, 웹 페이지에 붙여 넣는 방법을 안내해요.

이벤트를 삽입하면 방문자가 등록을 마칠 때까지 내 사이트에 머물러요. 다른 주소로 넘어가지 않아서 훨씬 매끄러운 경험을 줄 수 있어요.

## 이벤트 삽입이란?

이벤트 삽입은 공개 이벤트 페이지를 내 웹사이트, 퍼널, 외부 플랫폼 안에 직접 보여 주는 기능이에요. 방문자를 별도의 이벤트 주소로 보내지 않아요. 이벤트 상세 정보, 일정, 등록 폼까지 모두 내 페이지 안에 나타나요.

이 기능은 iframe 방식의 임베드 코드를 만들어 줘요. 코드를 한 번에 복사해서 HTML 편집기, 웹사이트 빌더, 콘텐츠 관리 시스템(CMS) 어디에든 붙여 넣을 수 있어요. 참석자는 내 사이트를 떠나지 않고 이벤트 정보를 확인하고 등록을 마칠 수 있어요.

## 이런 점이 좋아요

이벤트 페이지를 내 디지털 채널에 삽입하면 브랜드 분위기를 유지한 채 등록 경험을 이어 갈 수 있어요.

- 매끄러운 사용자 경험: 참석자가 사이트를 벗어나지 않고 이벤트 정보를 보고 등록할 수 있어요. 등록 과정에서 불편함과 이탈이 줄어요.
- 브랜드 일관성: 이벤트를 찾고 등록하는 전 과정이 내 브랜드 환경 안에서 이뤄져서 브랜드 이미지를 계속 보여 줄 수 있어요.
- 원클릭 적용: 임베드 코드를 한 번에 복사해 HTML을 지원하는 플랫폼에 붙여 넣으면 돼요. 하이퍼클래스 퍼널과 웹사이트, WordPress, Wix, Squarespace 등에서 쓸 수 있어요.
- 전체 등록 흐름 제공: 삽입한 페이지에 이벤트 정보, 일정, 등록 폼이 모두 들어 있어요. 내 사이트 안에서 완전한 이벤트 페이지로 쓸 수 있어요.
- 유연한 연동: 랜딩 페이지, 퍼널 단계, 블로그 글 등 이벤트를 알리고 등록을 받고 싶은 웹 페이지 어디에나 삽입할 수 있어요.

## 이벤트 페이지 삽입하기

다음 단계를 따라 이벤트 페이지의 임베드 코드를 만들고 적용하세요.

1. 삽입할 이벤트로 이동해요.

   하이퍼클래스 계정에서 **이벤트**로 이동한 뒤, 삽입할 공개 이벤트를 선택하세요.

   ![이벤트 목록에서 공개 이벤트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077521728/original/6Hipm3hQ-eSwR93TgV93gygoe8HQjwywEQ.png?1785783732)

2. 공유 창을 열어요.

   **Share Event**(이벤트 공유) 버튼을 클릭하면 공유 옵션 창이 열려요.

   ![이벤트 공유 버튼을 눌러 공유 창 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077521755/original/45p1VwPssCDCux5qadaNpDWFiZEbdLyO0w.png?1785783748)

3. 임베드 코드를 복사해요.

   **Share Event** 창에서 **Embed Code**(임베드 코드)를 선택하세요. 이벤트 페이지용 iframe 방식 임베드 코드가 만들어져요. **Copy**(복사) 버튼을 클릭하면 코드가 한 번에 클립보드에 복사돼요.

   ![임베드 코드를 선택하고 복사 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077521769/original/dAQSYSt9q9m8jE028aK2qye4uEzPtTNECQ.png?1785783772)

4. 코드를 내 사이트에 붙여 넣어요.

   웹사이트, 퍼널 또는 사용 중인 플랫폼의 **Custom code**(커스텀 코드) 영역을 열고, 이벤트 페이지를 보여 줄 위치에 임베드 코드를 붙여 넣으세요. 그런 다음 **저장 및 게시**를 클릭해 변경 사항을 적용해요.

   ![커스텀 코드 영역에 임베드 코드 붙여 넣기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077522852/original/l14sHOn5NJsrLE9GPsXms0QgUhRoLofsdg.gif?1785784514)

   ![붙여 넣은 뒤 저장하고 게시하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077522913/original/319N9Ix3gZNvjqFfdq1YWbUgBxPjxPhV6w.gif?1785784583)

{% hint style="info" %}
이제 이벤트 페이지가 삽입되어, 내 웹사이트에서 바로 등록을 받을 수 있어요.
{% endhint %}

## 삽입한 이벤트 페이지를 쓸 수 있는 곳

사용자 지정 HTML 코드를 지원하는 플랫폼이나 환경이라면 어디든 이벤트 페이지를 삽입할 수 있어요.

### 하이퍼클래스 퍼널과 웹사이트

하이퍼클래스로 만든 퍼널, 랜딩 페이지, 웹사이트에 이벤트를 바로 삽입하세요. 마케팅 캠페인 안에서 판매와 등록이 하나의 흐름으로 이어져요.

### 외부 웹사이트 빌더

WordPress, Wix, Squarespace, Webflow 등 사용자 지정 HTML이나 iframe 요소를 허용하는 웹사이트 플랫폼에 임베드 코드를 붙여 넣으세요.

### 블로그 글과 콘텐츠 페이지

관련 블로그 글이나 교육 콘텐츠 안에 이벤트를 삽입하세요. 내 콘텐츠를 이미 읽고 있는 독자의 등록을 이끌어 낼 수 있어요.

### 랜딩 페이지와 세일즈 페이지

이벤트 전용 랜딩 페이지에 이벤트 페이지를 삽입하세요. 방문자가 페이지를 벗어나지 않아도 되어서 등록 전환율이 높은 페이지를 만들 수 있어요.
