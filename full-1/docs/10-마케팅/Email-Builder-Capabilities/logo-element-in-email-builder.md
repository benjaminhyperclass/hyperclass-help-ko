# 이메일 빌더에서 로고 요소 사용하기

**Logo Element**(로고 요소)를 쓰면 이메일 템플릿에 브랜드 로고를 쉽게 넣을 수 있어요. 로고를 올리고, 크기와 정렬을 조절해서 데스크톱과 모바일에서 모두 선명하게 보이게 할 수 있어요.

## 이메일 빌더의 로고 요소란?

**Logo Element**는 끌어다 놓는 방식의 블록이에요. 이메일 레이아웃에 회사나 브랜드 로고를 넣을 때 써요. 로고가 들어가면 브랜드를 바로 알아볼 수 있고, 메시지도 전문적인 인상을 줘요.

로고 이미지를 직접 올리거나, 웹에 올려 둔 이미지 링크를 쓸 수 있어요. 크기 조절, 정렬, 링크 연결 같은 옵션으로 디자인 안에서 로고가 어떻게 보일지 정할 수 있어요.

{% hint style="info" %}
투명 PNG나 고화질 JPG 파일을 쓰면 가장 좋은 결과를 얻을 수 있어요.
{% endhint %}

## 로고 요소의 장점

이메일 디자인에 **Logo Element**를 넣으면 다음과 같은 장점이 있어요.

- 브랜드 인지도와 일관성을 높여 줘요.
- 끌어다 놓기만 하면 돼서 로고를 쉽게 배치할 수 있어요.
- 크기 조절, 정렬, 링크 연결을 지원해서 레이아웃을 유연하게 짤 수 있어요.
- 여러 기기와 화면 크기에서 선명하게 보여요.
- 로고에 홈페이지나 랜딩 페이지 링크를 걸어 쉽게 이동할 수 있어요.

## 로고 요소 설정하기

이메일 템플릿에 **Logo Element**를 추가하고 설정하는 방법이에요.

1. 서브 계정 대시보드에서 **마케팅 > 이메일 > 템플릿**으로 이동하세요.  
   ![마케팅 > 이메일 > 템플릿 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057292426/original/nY0mLhEspoXmlh8ONd6mp1_qOkY6f_LksQ.png?1761905787)
2. 기존 이메일 템플릿을 열거나 **+ 신규** 버튼을 눌러 새로 만드세요.  
   ![기존 템플릿 열기 또는 신규 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057292443/original/le0YDia2NBkLckdHWNxoaTclVpmJ6r7PFg.jpeg?1761905801)
3. **이메일 빌더**에서 왼쪽 사이드바의 **요소 추가**(+) 아이콘을 클릭하세요.  
   ![왼쪽 사이드바의 요소 추가 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057292646/original/lnAEEIGI4tn3rtF4xB6TEkTSlEpQWX3KdA.png?1761905897)
4. **요소** 섹션에서 **Logo Element**를 찾으세요.
5. **Logo Element**를 원하는 위치로 끌어다 놓으세요. 보통 레이아웃 맨 위에 둬요.
6. 놓은 **Logo Element**를 클릭하면 왼쪽 패널에 **편집** 탭이 열려요. 여기서 다음 설정을 할 수 있어요.

   - **Upload a Logo**(로고 업로드): 내 기기에서 이미지를 선택해요.
   - **Use an Image URL**(이미지 URL 사용): 웹에 올려 둔 로고 이미지의 직접 링크를 붙여 넣어요.
   - **Adjust Size**(크기 조정): 가로·세로 크기를 직접 정해서 알맞게 맞춰요.
   - **Set Alignment**(정렬 설정): 이메일 레이아웃에서 로고를 왼쪽, 가운데, 오른쪽 중 한 곳에 맞춰요.
   - **Add a Link**(링크 추가): 로고에 내 웹사이트나 원하는 페이지를 연결해요.
   - **Control Padding**(여백 조정): 로고 주변에 여백을 줘서 균형 있게 배치해요.  
     ![로고 요소 편집 탭의 설정 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057292733/original/JrDkfi5fHuPTT0lGwAL3gmFeBKwQRHjL2w.png?1761905940)
7. 필요하면 **공개 범위** 탭을 클릭해서 **Device-Based Visibility**(기기별 표시 설정)나 **조건부 발송** 설정을 하세요.  
   ![공개 범위 탭의 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057293818/original/IEWCCbhwhzO2_R3DwcIiwTcW4i-pJyIa-w.png?1761906349)
8. 데스크톱과 모바일 두 화면에서 이메일을 미리 보고 로고가 제대로 보이는지 확인하세요.

## 자주 묻는 질문

### 로고에 쓸 수 있는 파일 형식은 무엇인가요?
PNG, JPG, GIF 파일을 쓸 수 있어요. 배경을 투명하게 하려면 PNG를 추천해요.

### 로고에 내 웹사이트 링크를 걸 수 있나요?
네, 설정에서 링크를 추가하면 로고를 클릭할 수 있게 돼요.

### 모바일에서 로고 크기가 자동으로 줄어드나요?
네, **Logo Element**는 반응형이라 작은 화면에 맞게 자동으로 조정돼요.
