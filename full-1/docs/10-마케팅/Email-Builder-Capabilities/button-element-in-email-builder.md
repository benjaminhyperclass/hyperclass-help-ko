# 이메일 빌더의 버튼 요소

버튼 요소를 쓰면 이메일 템플릿에 클릭할 수 있는 버튼을 넣을 수 있어요. 눈에 잘 띄는 콜투액션(CTA) 버튼으로 수신자의 반응을 이끌어 낼 수 있고, 버튼의 문구·색상·크기·연결 주소는 이메일 디자인과 브랜드 스타일에 맞게 자유롭게 바꿀 수 있어요.

## 버튼 요소란?

버튼 요소는 끌어다 놓아서 쓰는 블록이에요. 이메일 레이아웃에 CTA 버튼을 넣을 수 있어요. 디자인, 정렬, 연결 주소를 목적에 맞게 조정해 보세요. 수신자를 랜딩 페이지, 상품 페이지, 이벤트 등록 페이지로 안내하는 용도로 쓸 수 있어요.

버튼은 수신자의 행동을 이끌고 클릭률을 높이는 데 꼭 필요한 요소예요. 이 요소로 버튼을 눈에 띄게 꾸미면서도 모든 기기에서 일관된 모양을 유지할 수 있어요.

{% hint style="info" %}
버튼은 HTML로 만들어져서 대부분의 이메일 클라이언트에서 안정적으로 표시돼요. 디자인이 제대로 보이는지 항상 데스크톱과 모바일에서 미리 확인하세요.
{% endhint %}

## 버튼 요소의 장점

이메일 디자인에 버튼 요소를 넣으면 이런 점이 좋아요.

- 명확하고 효과적인 콜투액션을 쉽게 만들 수 있어요.
- 버튼 텍스트, 색상, 크기를 디자인 테마에 맞게 바꿀 수 있어요.
- 링크를 넣어 특정 페이지나 행동으로 안내할 수 있어요.
- 버튼의 정렬과 간격을 세밀하게 조정해 시각적 균형을 맞출 수 있어요.
- 모바일과 데스크톱 기기에 맞게 자동으로 반응형으로 표시돼요.

## 버튼 요소 설정하기

이메일 템플릿에 버튼 요소를 추가하고 설정하려면 다음 단계를 따르세요.

1. 서브 계정 대시보드에서 **마케팅 > 이메일 > 템플릿**으로 이동하세요.  
   ![마케팅 > 이메일 > 템플릿 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057291260/original/1f-e9HKDiWzRQTo2Us0e6x8K72CPFJX2zA.png?1761905322)
2. 기존 이메일 템플릿을 열거나 **+ 신규** 버튼을 눌러 새로 만드세요.  
   ![기존 템플릿을 열거나 새 템플릿을 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057291290/original/7j2FCVwZ0mtT27Epo-p8XQj1MHzBLvoStQ.jpeg?1761905332)
3. **이메일 빌더**에서 왼쪽 사이드바의 **요소 추가**(+) 아이콘을 클릭하세요.  
   ![이메일 빌더 왼쪽 사이드바의 요소 추가 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057291114/original/PFr33EZ0nJkTqlMdEUXDYMpGFwPqrdqQng.png?1761905223)
4. **요소** 섹션에서 **Button Element**(버튼 요소)를 찾으세요.
5. 버튼 요소를 레이아웃에서 원하는 위치로 끌어다 놓으세요.
6. 추가한 **Button Element**를 클릭하면 왼쪽 패널에 **편집** 탭이 열려요. 여기서 다음 항목을 설정할 수 있어요.

   - 버튼 텍스트 수정: 원하는 행동이 드러나도록 문구를 바꾸세요(예: *지금 구매하기*, *자세히 보기*, *통화 예약하기*).
   - 링크 추가: 버튼을 눌렀을 때 이동할 주소(URL)를 입력하세요.
   - 스타일 설정: 버튼 색상, 텍스트 색상, 글꼴, 모서리 둥글기, 배경을 조정하세요.
   - 크기 및 정렬 조정: 너비, 패딩, 정렬(왼쪽, 가운데, 오른쪽)을 조정하세요.
   - 패딩 추가: 레이아웃 균형을 맞추도록 버튼 주변에 여백을 주세요.

   ![버튼 편집 패널의 설정 항목](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082958829/original/O0DA5FgnPpkzZfQEedzFlseAxT_wzMuERQ.png?1791553195)

   ![버튼 편집 패널의 스타일 및 크기 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082958957/original/zlOD4EZemgG1SEZRQ3OchpJdGlEOgWe9Aw.png?1791553279)
7. **공개 범위** 탭을 클릭해 **Device-Based Visibility**(기기별 표시 설정) 또는 **조건부 발송** 옵션을 설정하세요.  
   ![공개 범위 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082959040/original/VwuUYM9g3nBmUnvN1u3TBJzvRgCxm1LBgg.png?1791553340)
8. 데스크톱 모드와 모바일 모드에서 각각 이메일을 미리 보고, 버튼이 제대로 보이고 작동하는지 확인하세요.  
   ![데스크톱과 모바일 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082959159/original/L2vCRT68ZuwgxGGauJHL-ALhOA0hDFgcLg.png?1791553407)

## 자주 묻는 질문

### 이메일 하나에 버튼을 여러 개 넣을 수 있나요?
네, 필요한 만큼 버튼 요소를 추가할 수 있어요. 버튼마다 스타일과 링크를 다르게 설정할 수 있어요.

### 버튼을 전체 너비로 만들려면 어떻게 하나요?
편집 패널에서 **Full Width**(전체 너비) 토글을 켜서 버튼 너비를 100%로 설정하세요. 패딩과 정렬 설정으로 직접 조정할 수도 있어요.

### 버튼은 모바일에서도 잘 보이나요?
네, 버튼은 모바일 기기에서 보기 좋게 크기와 위치가 자동으로 조정돼요.

### 레이아웃에서 버튼을 지우려면 어떻게 하나요?
버튼 요소를 선택한 다음 휴지통(삭제) 아이콘을 클릭하면 이메일 디자인에서 버튼이 제거돼요.
