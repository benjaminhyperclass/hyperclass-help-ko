# 이메일 빌더의 텍스트 요소 사용하기

이메일 빌더의 텍스트 요소로 제목과 본문 같은 글을 넣고 꾸밀 수 있어요. 서식을 다양하게 바꿀 수 있어서, 브랜드의 말투와 메시지에 맞는 읽기 쉬운 이메일을 만들 수 있어요.

## 텍스트 요소란?

텍스트 요소는 이메일 빌더에서 끌어다 놓는 블록이에요. 이메일 레이아웃 어디에나 글을 넣을 수 있어요. 글꼴 변경, 색상 선택, 정렬, 하이퍼링크, 글머리 기호 같은 서식을 쓸 수 있어요.

시선을 끄는 제목을 만들거나, 내용을 설명하는 본문을 넣을 때 쓰면 돼요. 텍스트 요소는 유연하게 쓸 수 있고, 모바일 화면에 맞게 자동으로 조정돼서 어떤 기기에서도 보기 좋아요.

{% hint style="info" %}
이메일을 보내기 전에 꼭 미리보기로 확인하세요. 이메일 클라이언트마다 글이 다르게 보일 수 있어요.
{% endhint %}

## 텍스트 요소의 장점

텍스트 요소를 쓰면 다음과 같은 점이 좋아요.

- 제목, 본문 등 다양한 글을 쉽게 넣고 꾸밀 수 있어요.
- 글꼴, 색상, 서식을 직접 조절해서 브랜드의 일관성을 지킬 수 있어요.
- 글에 링크를 바로 넣어 클릭할 수 있는 CTA를 만들 수 있어요.
- 간격과 정렬을 조절해서 화면 균형을 맞출 수 있어요.
- 데스크톱과 모바일 화면에 맞게 자동으로 최적화돼요.

## 텍스트 요소 설정하기

이메일 템플릿에 텍스트 요소를 추가하고 설정하는 순서예요.

1. 하이퍼클래스 서브 계정 대시보드에서 **마케팅 > 이메일 > 템플릿**으로 이동하세요.

   ![마케팅 > 이메일 > 템플릿 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057287040/original/43B9eCV3aospbAtnUHY0B-yy_ftVb4KuKA.png?1761903242)
2. 기존 이메일 템플릿을 열거나, **신규** 버튼을 눌러 새 템플릿을 만드세요.

   ![템플릿 열기 또는 새로 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057287266/original/DfagherlOOXP4wKdJ4DIyxPgUYle7fBu9A.jpeg?1761903319)
3. **이메일 빌더**에서 왼쪽 사이드바의 **요소 추가**(+) 아이콘을 클릭하세요.

   ![왼쪽 사이드바의 요소 추가 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057287484/original/S6qzvG1P3orkHi3yyeB5keO3WZtYJPTJew.png?1761903417)
4. **Text Element**(텍스트 요소)를 찾아서 레이아웃의 원하는 위치로 끌어다 놓으세요.
5. 놓아 둔 **Text Element**를 클릭하면 **편집** 탭이 열려요. 여기서 다음 작업을 할 수 있어요.

   - 글 영역에 내용을 직접 입력하거나 붙여 넣어요.
   - 도구 모음으로 글에 서식을 적용해요(굵게, 기울임, 밑줄, 목록, 정렬 등).
   - 글에 제목 스타일(H1~H4)을 적용해요. 인라인 도구 모음의 **굵게(B)** 버튼을 누르면 제목 수준은 그대로 두고 굵게를 켜거나 끌 수 있어요.
   - 글꼴 크기, 색상, 간격을 조절해서 읽기 편하게 만들어요.
   - 특정 문구에 하이퍼링크를 넣어 이동 링크나 CTA로 써요.

     ![편집 탭에서 텍스트 서식 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082959714/original/N7mNc_g6HTc6VukIIloZI9gQbi2b8PNutQ.png?1791553771)
6. **여백** 옵션으로 글 주변 간격을 조절하세요.

   ![여백 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082959774/original/sPoKyT4_gLcIJ_UNZpJ9teXCWcf8twNstA.png?1791553829)
7. **공개 범위** 탭을 클릭해서 **Device-Based Visibility**(기기별 공개 범위)나 **조건부 발송** 옵션을 조정하세요.

   ![공개 범위 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082959999/original/aD_DrbawI1m79uehTpIIu_c2fDaVeToWlA.png?1791553922)
8. 데스크톱 모드와 모바일 모드에서 각각 미리보기를 하고 서식이 제대로 보이는지 확인하세요.

## 자주 묻는 질문

### 글의 부분마다 다른 글꼴이나 크기를 쓸 수 있나요?
네, 가능해요. 바꾸고 싶은 부분을 드래그해서 선택한 뒤, 인라인 텍스트 도구 모음에서 글꼴, 크기, 색상을 각각 바꿀 수 있어요.

### 글에 하이퍼링크는 어떻게 넣나요?
링크를 걸 글을 선택하고, 도구 모음의 링크 아이콘을 클릭한 뒤 원하는 URL을 입력하세요.

### 텍스트 요소에서 글머리 기호와 번호 목록을 쓸 수 있나요?
네, 서식 도구 모음에서 글머리 기호 목록과 번호 목록을 바로 만들 수 있어요.

### 텍스트 요소는 모바일 화면에도 맞게 보이나요?
네. 텍스트 요소는 작은 화면에 맞게 자동으로 조정돼서 어떤 기기에서도 읽기 편해요.

### 레이아웃에서 텍스트 요소를 지우려면 어떻게 하나요?
텍스트 요소를 클릭한 뒤 휴지통(삭제) 아이콘을 선택하면 이메일에서 제거돼요.

### 제목(H1~H4) 글의 굵게를 해제할 수 있나요?
네. 텍스트 요소 안에서 제목(H1~H4) 글을 선택하고, 인라인 도구 모음의 **B**를 클릭해 굵게를 켜거나 끌 수 있어요.
