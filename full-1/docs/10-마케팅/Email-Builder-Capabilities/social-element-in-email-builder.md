# 이메일 빌더의 소셜 요소로 소셜 링크 추가하기

이메일 빌더의 **소셜** 요소(Social Element)를 쓰면 이메일에 클릭할 수 있는 소셜 링크를 바로 넣을 수 있어요. 뉴스레터나 프로모션 이메일처럼 브랜드를 알리는 이메일에서 수신자가 내 소셜 프로필로 이동하도록 안내할 때 쓰세요. 링크 모양, 표시 조건, 배치를 이메일 디자인에 맞게 조정할 수 있어요. 이메일 클라이언트마다 반응형 스타일이 다르게 보일 수 있으니, 발송 전에 꼭 미리보기와 테스트를 해 보세요.

## 소셜 요소란?

소셜 요소는 **이메일 빌더**에서 끌어다 놓아 쓰는 블록이에요. 소셜 프로필 링크를 이메일에 넣을 수 있어요. 각 항목은 직접 설정한 프로필 URL이나 지원되는 핸들로 수신자를 연결해 줘요.

아이콘을 하나씩 직접 만들고 정렬하지 않아도, 소셜 링크가 어떻게 보일지 한 곳에서 조정할 수 있어요.

## 소셜 요소의 장점

소셜 요소를 쓰면 이메일 디자인과 어울리는 소셜 링크를 일관되게 넣고 다시 쓸 수 있어요.

- 바로가기 링크: 수신자가 이메일에서 바로 내 소셜 프로필로 이동할 수 있어요.
- 유연한 표시 방식: 제공되는 표시 옵션 중에서 아이콘, 텍스트 레이블, 또는 둘 다 보이도록 고를 수 있어요.
- 디자인 조정: 지원되는 스타일, 크기, 정렬, 간격, 여백을 조정할 수 있어요.
- 표시 조건 설정: 기기별 표시 설정이나 지원되는 **조건부 발송** 규칙으로 소셜 요소가 보이는 때를 정할 수 있어요.
- 재사용: 지원되는 요소나 레이아웃을 저장해 두면 같은 서브 계정의 다른 이메일 템플릿에서 다시 쓸 수 있어요.

## 소셜 요소 설정 옵션

**디자인 에디터**에서 소셜 요소를 선택하면 소셜 프로필을 설정하고 이메일에서 보이는 모양을 조정할 수 있어요.

- **소셜 프로필**: 표시할 소셜 플랫폼을 추가하고, 각 플랫폼에 맞는 프로필 URL이나 지원되는 핸들을 입력해요.
- **Display Type**(표시 유형): **아이콘**, **문자**, **Icon and Text**(아이콘과 문자) 같은 옵션 중에서 골라요.
- **Icon Appearance**(아이콘 모양): 에디터에서 현재 제공하는 아이콘 스타일과 모양 옵션 중에서 골라요.
- **Text Settings**(텍스트 설정): 텍스트 레이블을 표시할 때 쓸 수 있는 글꼴과 텍스트 색상 설정을 조정해요.
- **Icon Size**(아이콘 크기): 소셜 아이콘의 크기를 조정해요.
- **정렬**: 소셜 요소를 왼쪽, 가운데, 오른쪽 중 한 곳에 맞춰요.
- **간격**: 소셜 항목 사이의 간격을 조정해요.
- **여백**: 이메일 레이아웃 안에서 소셜 요소 주변의 여백을 조정해요.

{% hint style="info" %}
이메일 빌더가 업데이트되면서 제공되는 소셜 플랫폼, 아이콘 스타일, 모양 설정이 달라질 수 있어요. 요소를 설정할 때는 에디터에 현재 표시되는 옵션을 확인하세요.
{% endhint %}

필요한 소셜 플랫폼이 소셜 요소에 없다면, 알맞은 이미지와 이동할 URL을 연결한 **Image Element**(이미지 요소)를 대신 쓸 수 있어요.

## 표시 조건과 조건부 발송

소셜 링크를 특정 기기에서만 보이게 하거나, 특정 조건을 만족하는 수신자에게만 보이게 하려면 소셜 요소의 표시 설정을 쓰세요.

- **Device-Based Visibility**(기기별 표시): 지원되는 데스크톱 화면과 모바일 화면에서 요소를 보일지 정해요.
- **조건부 발송**: 지원되는 연락처 관련 조건에 따라 요소를 보이거나 숨겨요. 자세한 내용은 [조건부 요소로 캠페인 개인화하기](how-to-personalize-your-campaigns-with-conditional-elements.md)를 참고하세요.

조건부 발송에서는 **다음과 같음**, **다음과 같지 않음**, **비어 있음**, **Is Present**(값이 있음) 같은 연산자를 쓸 수 있어요. 사용할 수 있는 연산자는 선택한 필드에 따라 달라질 수 있어요.

{% hint style="warning" %}
상위 레이아웃이 숨김 상태이면 그 안에 있는 소셜 요소도 함께 숨겨져요. 소셜 링크가 보이지 않으면 요소 자체의 표시 설정과 상위 레이아웃의 표시 설정을 모두 확인하세요. 레이아웃 표시 설정은 [이메일 빌더 레이아웃의 표시 설정](../visibility-section-for-layouts-in-email-builder.md)에서 볼 수 있어요.
{% endhint %}

## 모바일과 이메일 클라이언트에서의 표시

기기별 표시 설정은 소셜 요소가 보이는지를 정해요. **모바일 서식**은 지원되는 콘텐츠가 작은 화면에서 어떤 스타일로 보일지를 정해요. 이 두 설정은 서로 별개예요. 모바일 서식은 [이메일 빌더에서 모바일 서식 설정하기](../how-to-customize-mobile-formatting-in-the-email-builder.md)에서 자세히 볼 수 있어요.

**이메일 클라이언트**마다 반응형 스타일을 다르게 해석할 수 있어요. 그래서 받은 이메일이 에디터 미리보기와 똑같이 보이지 않을 수도 있어요.

데스크톱, 태블릿, 모바일 화면에서 이메일을 미리보기한 뒤, 실제 테스트 이메일을 보내서 각 소셜 링크가 의도한 프로필로 열리는지 확인하세요. 미리보기와 테스트 방법은 [이메일 캠페인/템플릿 미리보기 및 테스트](../../09-이메일/기타/preview-and-test-your-email-campaign-templates.md)에서 볼 수 있어요.

## 소셜 요소 추가하고 테스트하기

**디자인 에디터**에서 소셜 요소를 추가하고 링크와 모양을 설정한 뒤, 템플릿을 쓰기 전에 모든 링크를 테스트하세요.

1. **마케팅 > 이메일 > 템플릿**으로 이동해 기존 템플릿을 열거나, **디자인 에디터**로 새 템플릿을 만드세요.
2. **요소 추가 (+)** 를 열고 **소셜** 요소를 찾아, 이메일에서 원하는 위치로 끌어다 놓으세요.

   ![이메일 빌더에서 소셜 요소를 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083365026/original/mDHqzfk7LblKSscbYMPzY3PubamYM3fGiQ.png?1792042506)

3. 소셜 요소를 선택해 설정 창을 여세요.
4. 표시할 소셜 프로필을 추가하고, 각 프로필마다 이동할 URL이나 지원되는 핸들을 정확하게 입력하세요.
5. 표시 유형, 아이콘 모양, 텍스트 설정, 크기, 정렬, 간격, 여백을 설정하세요.
6. 필요하면 **Device-Based Visibility** 또는 **조건부 발송**을 설정하세요. 이 요소가 들어 있는 레이아웃의 표시 설정도 함께 확인하세요.

   ![소셜 요소의 표시 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083365181/original/rOuDJfHJH0akCO-i4JJmdbywZssdjfdMqw.png?1792042810)

7. 데스크톱, 태블릿, 모바일 화면으로 이메일을 미리보기하세요.
8. **미리보기** 옆의 점 세 개 메뉴를 열고 **테스트 이메일**을 선택하세요.
9. 발신자, 수신자, 제목, 미리보기 텍스트 등 테스트 이메일에 필요한 정보를 입력하고 테스트를 보내세요.
10. 받은 이메일을 열어 소셜 링크를 하나씩 모두 클릭하세요. 각 링크가 의도한 소셜 프로필로 열리는지 확인하세요.
11. 문제가 있으면 템플릿으로 돌아가 고친 뒤 변경 사항을 저장하세요.

    ![템플릿에서 소셜 요소를 수정하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083365815/original/PGr8-iG_8LRMdqYKZ5guyeT6kkdB5Nw5qg.png?1792043253)

## 자주 묻는 질문

### 쓰고 싶은 소셜 플랫폼이 소셜 요소에 없어요. 어떻게 하나요?
소셜 요소에 없는 플랫폼은 알맞은 이미지와 이동할 URL을 연결한 **Image Element**(이미지 요소)로 대신 넣을 수 있어요.

### 소셜 링크 디자인을 다른 이메일 템플릿에서 다시 쓸 수 있나요?
네, 쓸 수 있어요. 지원되는 요소와 레이아웃은 **디자인 에디터**에서 **Saved Items**(저장된 항목)로 저장해 두면 같은 서브 계정 안에서 다시 쓸 수 있어요. 다만 **AI Editor**(AI 에디터)에서는 아직 저장된 항목을 지원하지 않아요. 자세한 방법은 [이메일 빌더에서 항목 저장하고 빠르게 쓰기](how-to-save-items-in-email-builder-for-quick-access.md)를 참고하세요.

### 소셜 아이콘을 눌렀는데 엉뚱한 페이지가 열려요.
해당 소셜 항목에 설정한 이동 주소를 확인하세요. URL이나 지원되는 핸들이 의도한 프로필을 가리키는지 확인한 뒤, 테스트 이메일을 다시 보내 링크를 확인하세요.

### 어떤 수신자에게는 소셜 링크가 보이고 어떤 수신자에게는 안 보여요.
소셜 요소의 **Device-Based Visibility**, **조건부 발송** 규칙, 그리고 상위 레이아웃의 표시 설정을 확인하세요. 조건부 규칙은 선택한 조건을 만족하지 않는 수신자에게 요소를 숨길 수 있어요.

### 받은 이메일의 소셜 아이콘이 미리보기와 다르게 보여요.
이메일 클라이언트마다 반응형 스타일을 다르게 표시할 수 있어요. 미리보기로는 디자인을 검토할 수 있지만, 실제 받은 편지함에서 소셜 링크가 어떻게 보일지는 테스트 이메일로 확인하는 것이 가장 정확해요.

### 소셜 요소로 이메일 푸터나 수신 거부 링크를 대신할 수 있나요?
아니요. 소셜 요소는 소셜 프로필로 가는 링크만 제공해요. 필수 푸터 내용, 발신자 정보, 수신 거부 기능을 대신하지는 않아요.
