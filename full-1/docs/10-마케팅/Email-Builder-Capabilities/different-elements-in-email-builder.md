# 이메일 빌더의 요소 종류와 쓰임

**이메일 빌더**에서는 **요소**를 끌어다 놓는 방식으로 이메일을 디자인할 수 있어요. 문자, 버튼, 이미지, 동영상, 카운트다운 타이머까지 코딩 없이 이메일을 꾸미고 기능을 넣을 수 있어요.

## 요소란?

요소는 미리 만들어 둔 콘텐츠 구성 블록이에요. 코드를 쓰지 않고도 이메일의 레이아웃과 내용을 쉽게 바꿀 수 있어요. 요소마다 문자, 이미지, 소셜 링크, 동적 콘텐츠 추가처럼 맡은 역할이 정해져 있어요.

## 요소 종류와 쓰임

| **요소** | **설명** | **주요 사용 예** |
| --- | --- | --- |
| **문자** | 이메일에 글을 추가해요. 글꼴, 색상, 정렬을 지정할 수 있어요. | 제목, 설명, CTA, 본문을 넣어요. |
| **이미지** | 이미지나 배너를 넣어 이메일을 보기 좋게 만들어요. | 상품, 로고, 공지를 보여 줘요. |
| **버튼** | 클릭할 수 있는 CTA(행동 유도) 버튼을 추가해요. | *지금 예약*, *지금 구매*, *더 알아보기*처럼 행동을 유도해요. |
| **로고** | 브랜드 로고를 넣어요. | 이메일 상단이나 하단에서 브랜드 이미지를 강조해요. |
| **구분선** | 섹션 사이를 시각적으로 나눠요. | 읽기 쉽고 구조가 잡힌 이메일을 만들어요. |
| **소셜** | 내 프로필로 연결되는 소셜 미디어 아이콘을 추가해요. | 소셜 채널로 방문을 유도해요. |
| **푸터** | 연락처 정보, 수신 거부 링크, 법적 고지 문구를 넣어요. | 필수 규정 준수 정보를 제공해요. |
| **코드** | 사용자 지정 HTML이나 코드 조각을 넣어요. | 트래킹 픽셀, 동적 콘텐츠, 맞춤 디자인을 추가해요. |
| **동영상** | YouTube나 Vimeo 동영상 미리보기와 재생 버튼을 넣어요. | 튜토리얼, 공지, 고객 후기를 공유해요. |
| **Shopping Cart**(장바구니) | 연결된 이커머스 스토어의 상품을 보여 줘요. | 고객이 장바구니에 담아 둔 상품을 보여 줘요. |
| **RSS Header / RSS Items**(RSS 헤더/RSS 항목) | RSS 피드의 최신 게시글을 자동으로 보여 줘요. | 뉴스레터나 블로그 소식에 잘 맞아요. |
| **자주 묻는 질문** | 펼치고 접을 수 있는 질문·답변 섹션을 추가해요. | 도움말 콘텐츠를 공유하거나 자주 받는 질문에 답해요. |
| **상품** | 이미지, 가격, 구매 버튼이 있는 상품 목록을 보여 줘요. | 추천 상품이나 신상품을 소개해요. |
| **Image Slider**(이미지 슬라이더) | 여러 이미지를 넘겨 볼 수 있는 캐러셀을 만들어요. | 여러 상품이나 이벤트를 한꺼번에 소개해요. |
| **미리보기 URL** | 웹사이트 내용을 요약해 보여 주는 링크 미리보기 상자를 추가해요. | 블로그 글이나 외부 콘텐츠를 홍보해요. |
| **카운트다운 타이머** | 실시간으로 줄어드는 타이머를 넣어 긴박감을 줘요. | 기간 한정 프로모션이나 이벤트에 알맞아요. |
| **여백** | 요소 사이에 빈 공간을 추가해요. | 이메일의 간격을 세밀하게 조정해요. |
| **리뷰 링크** | 수신자에게 의견이나 리뷰를 요청하는 링크를 넣어요. | 고객 후기나 만족도 데이터를 모아요. |
| **폼** | 이메일 안에 폼을 바로 넣어요(이메일 클라이언트에서 지원하는 경우). | 설문 응답이나 등록 정보 같은 입력을 받아요. |

## 요소 추가하기

#### 1단계: 이메일로 이동

1. 대시보드에서 왼쪽 메뉴의 **마케팅**을 선택하세요.
2. 상단 메뉴에서 **이메일**을 클릭하세요.

![마케팅 메뉴에서 이메일 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055816469/original/XmDxoPvoq8tTprWM9h9fmOneek1GUunxnQ.jpeg?1760337642)

#### 2단계: 새 이메일 만들기

1. 새 이메일을 만들 시작 유형을 선택하세요.

![새 이메일 시작 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055816736/original/owoiLxXMaWjljXCSNvnxAWZdjI4Dl3ImZA.png?1760337847)

#### 3단계: 요소 추가

1. **요소** 탭에서 원하는 요소를 이메일 캔버스로 끌어다 놓으세요.
2. 추가한 요소를 클릭해 내용, 스타일, 설정을 바꾸세요.

![요소 탭에서 요소를 끌어다 놓기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055817040/original/2_HQNC8k9k96x2sv6ZIU2dRa8eeMovY4EQ.png?1760338221)

## 자주 묻는 질문

### 요소를 추가한 뒤에 순서를 바꿀 수 있나요?

네, 이메일 레이아웃 안에서 요소를 원하는 위치로 끌어다 놓을 수 있어요.

### 모든 요소가 모바일에서도 화면에 맞게 보이나요?

네, 모든 요소는 기본적으로 반응형이에요. **Mobile View**(모바일 보기) 탭에서 모바일 화면을 미리 보고 간격이나 정렬을 조정할 수 있어요.

### **문자** 요소와 **코드** 요소는 어떻게 다른가요?

**문자** 요소는 화면에서 보면서 내용을 입력하고 서식을 지정할 수 있어요. **코드** 요소는 사용자 지정 HTML을 넣어서 고급 디자인이나 연동에 쓸 수 있어요.

### **여백**과 **구분선**은 어떻게 다른가요?

**여백**은 세로로 빈 공간만 추가해요. **구분선**은 섹션 사이에 눈에 보이는 선을 그려서 영역을 나눠 줘요.
