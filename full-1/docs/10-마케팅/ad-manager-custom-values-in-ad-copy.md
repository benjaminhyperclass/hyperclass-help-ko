# 광고 관리자에서 광고 문구에 커스텀 값 사용하기

회사명 같은 사업 정보를 광고 문구에 재사용하면 Meta, Google, LinkedIn 캠페인을 더 빠르고 일관되게 만들 수 있어요. 이 문서에서는 하이퍼클래스 **광고 관리자**(Ad Manager)의 광고 문구에 커스텀 값을 넣고 매핑하는 방법을 안내해요.

## 이 문서에서 알 수 있는 내용

커스텀 값을 쓰면 회사명, 도시, 전화번호, 오퍼 이름처럼 계정 단위로 저장해 둔 값을 지원되는 텍스트 필드에 바로 넣을 수 있어요. Meta, Google, LinkedIn 캠페인 모두에서 쓸 수 있어요. 넣어 둔 값은 캠페인 미리보기에서 실제 값으로 바뀌어 보이기 때문에, 게시하기 전에 최종 광고 문구를 확인할 수 있어요.

이 문서에서는 기능의 개념, 사용할 수 있는 곳, 커스텀 값을 삽입하고 매핑하는 방법을 차례로 다뤄요.

## 광고 문구의 커스텀 값이란?

광고 문구에 커스텀 값을 쓰면 계정 단위로 저장해 둔 "키:값" 자리표시자를 지원되는 텍스트 필드에 직접 넣을 수 있어요. 기본 텍스트, 헤드라인, 설명, 소개 텍스트 같은 필드가 해당돼요. 이 자리표시자는 캠페인 미리보기와 검토 화면에서 실제 저장된 값으로 바뀌어 보여요. 그래서 게시하기 전에 최종 광고 문구를 확인할 수 있어요.

커스텀 값은 **설정 > 커스텀 값**에서 키:값 쌍으로 만들어요. 예를 들어 키는 `custom_values.business_name`, 값은 "Summit Dental Studio"처럼 만들 수 있어요. 한 번 만든 키는 커스텀 값 선택 기능이 있는 곳이라면 어디서든 다시 쓸 수 있어요. 광고 관리자도 마찬가지예요. 같은 정보를 매번 직접 입력하지 않아도 돼요.

커스텀 값으로 저장해 두면 좋은 정보는 다음과 같아요.

- 회사명
- 도시 또는 서비스 지역
- 지원 이메일
- 전화번호
- 오퍼 또는 프로모션 이름
- 기본 보증 문구나 CTA 문구

## 광고 문구에 커스텀 값을 쓰면 좋은 점

- 캠페인을 더 빠르게 만들 수 있어요. 회사명, 도시, 전화번호, 오퍼 이름처럼 미리 저장해 둔 정보를 광고마다 다시 입력하지 않고 넣을 수 있어요.
- 반복해서 문구를 입력하지 않아도 돼요. 같은 커스텀 값을 여러 캠페인 유형과 플랫폼에서 쓰고, 값만 한 번 수정하면 돼요. 단, 커스텀 값을 수정해도 이미 게시된 광고는 자동으로 바뀌지 않아요.
- 광고 문구를 일관되게 유지할 수 있어요. 전화번호, 이메일, 브랜드 문구가 모든 광고와 채널에서 똑같이 나와요.
- 서브 계정 간에 템플릿을 재사용할 수 있어요. 캠페인을 템플릿으로 저장하면 커스텀 값 키가 그대로 남아요. 문구를 처음부터 다시 만들 필요 없이 서브 계정마다 고객사별 값만 매핑하면 돼요.
- 게시 전에 최종 문구를 미리 볼 수 있어요. 미리보기와 검토 화면에서 자리표시자가 아니라 실제 텍스트가 보여요. 오타나 자리표시자 코드가 실제 광고에 섞여 나가는 일을 줄일 수 있어요.
- 게시 문제를 미리 막을 수 있어요. 커스텀 값이 없거나, 비어 있거나, 올바르지 않을 때, 또는 문구가 플랫폼 글자 수 제한을 넘을 때 경고가 표시돼요. 게시하기 전에 문제를 고칠 수 있어요.

## 광고 문구에서 커스텀 값이 동작하는 방식

이 기능은 이미 쓰고 있는 하이퍼클래스 커스텀 값을 광고 관리자 캠페인의 광고 문구 필드에 바로 쓰는 기능이에요. "Summit Dental Studio"를 직접 입력하는 대신 **Insert Custom Values**(커스텀 값 삽입) 선택 창에서 값을 고르면 돼요. 광고를 미리 볼 때와 게시할 때 저장된 텍스트로 바뀌어요.

알아 두면 좋은 점은 다음과 같아요.

- 전역 커스텀 값을 사용해요. 광고 관리자는 **설정 > 커스텀 값**에서 설정한 커스텀 값을 그대로 써요. 각 값은 키와 값으로 정의돼요(예: `custom_values.city` → "Austin").
- 여러 플랫폼에서 쓸 수 있어요. 하이퍼클래스 광고 관리자에서 만드는 Meta(Facebook/Instagram), Google, LinkedIn 캠페인의 광고 문구에 쓸 수 있어요.
- 미리보기에서 실제 텍스트로 바뀌어요. 캠페인 빌더와 검토 화면에서 커스텀 값이 최종 텍스트로 표시돼요. 타깃 고객에게 보이는 내용을 정확히 확인할 수 있어요.
- 지원되지 않는 영역은 직접 입력해요. 커스텀 값은 문구를 넣는 텍스트 필드에서만 쓸 수 있어요. URL, CTA, 미디어, 예산은 직접 설정해야 해요.

### 참고 자료

플랫폼 전반에서 커스텀 값이 어떻게 동작하는지(광고 관리자 밖)는 "How to use Custom Values"와 "Custom Values Settings" 문서를 참고하세요.

## 지원되는 광고 문구 필드와 제한 사항

커스텀 값을 쓸 수 있는 곳을 정확히 알아 두면 **Insert Custom Values** 선택 창이 보이지 않거나 머지 필드가 입력되지 않을 때 헷갈리지 않아요. 광고 관리자에서 커스텀 값을 쓸 수 있는 곳과 쓸 수 없는 곳을 정리했어요.

### 지원되는 필드

Meta, Google, LinkedIn 캠페인에서는 다음과 같은 텍스트 기반 광고 문구 필드에 커스텀 값을 쓸 수 있어요.

| 플랫폼 | 지원되는 필드 |
| --- | --- |
| Meta | **Primary Text**(기본 텍스트), **Headline**(헤드라인), **설명** |
| Google Ads | **Headline**, **설명** |
| LinkedIn | **Intro/Primary Text**(소개/기본 텍스트), **Headline**(지원되는 경우) |

### 지원되지 않음

다음 영역에서는 커스텀 값을 쓸 수 없어요.

- URL 필드(최종 URL, 표시 URL, 트래킹 템플릿)
- CTA 드롭다운(예: **자세히 보기**, **Book Now**(지금 예약하기))
- 리드 폼 선택 항목
- 미디어 업로드 필드(이미지, 동영상, 캐러셀)
- 타기팅 설정(지역, 관심사, 인구통계)
- 예산 또는 입찰 전략 필드

{% hint style="info" %}
필드에 **Insert Custom Values** 아이콘이나 머지 필드 선택 창이 보이지 않으면, 그 영역에서는 커스텀 값을 쓸 수 없다고 보고 직접 입력하세요.
{% endhint %}

## 광고 문구에 커스텀 값 사용하기

이 기능을 쓰려면 먼저 알맞은 커스텀 값을 준비하고, 평소 쓰던 광고 관리자 작업 중에 **Insert Custom Values** 선택 창으로 삽입하면 돼요. 처음에 몇 분만 들여 값을 깔끔하게 정리하고 이름도 알아보기 쉽게 지어 두면, 캠페인을 새로 만들거나 복제할 때마다 시간이 절약돼요.

### 1단계. 커스텀 값으로 둘 정보 정하기

캠페인을 만들기 전에 여러 광고와 계정에서 반복해서 쓰는 정보가 무엇인지 정해요. 보통 다음 정보를 많이 써요.

- 사업자명(예: "Summit Dental Studio")
- 주요 도시 또는 서비스 지역
- 지원 이메일(예: "support@yourdomain.com")
- 대표 전화번호
- 오퍼 이름(예: "$47 신규 환자 스페셜")
- 보증 문구 또는 차별점(예: "30일 안에 결과가 없으면 무료로 진행해 드립니다")

이런 정보를 커스텀 값으로 두면 나중에 한곳에서 수정할 수 있고(앞으로 만들 캠페인에 적용돼요), 템플릿도 더 깔끔하게 관리할 수 있어요.

### 2단계. 설정에서 커스텀 값 만들기 또는 확인하기

1. 서브 계정에서 **설정 > 커스텀 값**으로 이동하세요.
2. **커스텀 값 추가**를 클릭하세요.
3. 알아보기 쉬운 **이름**을 입력하세요. 이 이름이 키가 돼요(예: `custom_values.business_name`).
4. **값**에 광고에 보이게 할 내용을 그대로 입력하세요(예: "Summit Dental Studio – Downtown").
5. 필요하면 커스텀 값을 "광고 관리자 – 고객 기본 정보" 같은 폴더에 지정해 정리하세요.
6. **만들기**를 클릭하세요.

광고 문구에 쓸 사업 정보마다 같은 방법으로 반복하세요.

![커스텀 값 만들기 화면 녹화](https://jumpshare.com/share/P1KhIvHvSzxyOH3u3Btg+/GIF+Recording+2026-08-07+at+18.54.24.gif)

### 3단계. 광고 관리자 캠페인 만들기 또는 편집하기

1. **마케팅 > 광고 관리자**로 이동하세요.
2. Meta, Google, LinkedIn 중 하나에서 새 캠페인을 만들거나 기존 캠페인을 편집하세요.
3. 광고 단계의 **Text & Media**(텍스트 및 미디어), 즉 광고 문구를 입력하는 단계까지 진행하세요. 단계 이름은 플랫폼마다 조금씩 달라요. 이 단계에서 **Primary Text**, **Headline**, **설명**, 미디어를 설정해요.

![광고 문구 입력 단계로 이동하는 화면 녹화](https://jumpshare.com/share/NZLwqq8cSyEQddDJYXEh+/GIF+Recording+2026-08-07+at+19.02.47.gif)

### 4단계. 광고 문구에 커스텀 값 삽입하기

1. 지원되는 문구 필드(예: **Primary Text**)를 클릭하세요.
2. 필드 옆의 **Insert Custom Values** 아이콘을 클릭하세요.
3. 만들어 둔 값을 검색하거나 목록에서 찾으세요(예: "사업자명", "도시", "주요 오퍼").
4. 값을 클릭해 삽입하면 머지 토큰이 필드에 추가돼요.
5. 토큰 앞뒤에 문구를 덧붙이세요. 예를 들면 다음과 같아요.
   - "`{{custom_values.business_name}}`에서 `{{custom_values.city}}` 신규 환자를 받고 있어요!"
   - "`{{custom_values.phone}}`로 전화하고 `{{custom_values.offer_name}}` 혜택을 받아 가세요."
6. 값을 동적으로 넣고 싶은 헤드라인, 설명, 소개 텍스트에도 같은 방법으로 반복하세요.

![광고 문구에 커스텀 값을 삽입하는 화면 녹화](https://jumpshare.com/share/Xj947k7ZMzmSwgcM7Wd8+/GIF+Recording+2026-08-07+at+19.14.15.gif)

### 5단계. 커스텀 값 매핑하고 문제 고치기

1. 문구 작성이 끝나면 **커스텀 값 매핑**을 클릭하세요. 보통 **리뷰** 단계 가까이에 있어요.
2. 감지된 커스텀 값 키와 현재 값을 확인하세요.
3. 없거나 비어 있거나 자리표시자로 남은 값을 채우거나 고치세요.
4. **저장**을 클릭하고 캠페인 빌더로 돌아가세요.

![커스텀 값 매핑 화면 녹화](https://jumpshare.com/share/AKeHXZBC8bcIJkX2NMUo+/GIF+Recording+2026-08-07+at+19.17.16.gif)

### 6단계. 실제 값으로 바뀐 광고 문구 미리 보기

1. **리뷰** 버튼을 클릭하세요.
2. 모든 커스텀 값이 실제 텍스트로 바뀌었는지 확인하세요. 예를 들어 `{{custom_values.city}}` 대신 "Austin"이 보여야 해요.
3. 문구가 자연스럽게 읽히는지, 글자 수 제한을 넘지 않는지 확인하세요.
4. 필요하면 문구나 값을 마지막으로 조정하세요.

![리뷰 화면에서 최종 광고 문구를 확인하는 화면 녹화](https://jumpshare.com/share/ga961hZsa15yo619IDtA+/GIF+Recording+2026-08-07+at+19.19.50.gif)

### 7단계. 캠페인 게시하기

1. 미리보기가 올바르고 모든 검증을 통과하면 **Publish Campaign Now**(캠페인 지금 게시)를 클릭하세요.
2. 하이퍼클래스가 커스텀 값을 실제 값으로 바꾼 최종 광고 문구를 광고 플랫폼에 보내요.
3. 올바른 사업 정보가 자동으로 들어간 광고가 게시돼요.

## 자주 묻는 질문

### URL 필드나 CTA에도 커스텀 값을 쓸 수 있나요?

쓸 수 없어요. 커스텀 값은 기본 텍스트, 헤드라인, 설명 같은 텍스트 기반 광고 문구 필드에서만 쓸 수 있어요. URL 필드, CTA 드롭다운, 리드 폼 선택 항목, 미디어 업로드, 타기팅 설정, 예산 필드에서는 쓸 수 없어요.

### 게시하기 전에 커스텀 값 매핑을 깜빡하면 어떻게 되나요?

커스텀 값이 없거나, 비어 있거나, 올바르지 않으면 경고가 표시돼요. 모든 커스텀 값이 제대로 매핑되고 실제 값으로 바뀔 때까지 캠페인 빌더에서 게시할 수 없어요. 그래서 자리표시자 텍스트가 실제 광고에 나갈 위험이 줄어요.

### 캠페인이 게시된 뒤에 커스텀 값을 바꿀 수 있나요?

**설정**에서 커스텀 값을 수정하면 앞으로 만드는 캠페인에만 적용돼요. 이미 게시된 캠페인에는 게시할 때 바뀐 값이 그대로 쓰여요. 진행 중인 캠페인의 광고 문구를 바꾸려면 캠페인을 직접 편집한 뒤 다시 게시해야 해요.

### Meta, Google, LinkedIn 모두에서 커스텀 값이 동작하나요?

네. 세 플랫폼의 광고 문구에서 같은 커스텀 값을 쓸 수 있어요. 지원되는 필드는 플랫폼마다 조금 달라요(Meta는 기본 텍스트와 헤드라인, Google은 헤드라인과 설명, LinkedIn은 소개 텍스트). 하지만 커스텀 값이 동작하는 방식은 모두 같아요. <!-- 검토 필요: 원문 내용이 서로 다름 (위 표에서는 Meta 지원 필드에 설명이 포함되어 있음) -->

### 광고 문구에 커스텀 값을 넣으면 글자 수 제한을 넘을 수 있나요?

플랫폼은 커스텀 값이 실제 텍스트로 바뀐 뒤에 글자 수 제한을 검사해요. 바뀐 문구가 플랫폼 제한을 넘으면 검증 경고가 표시돼요. 게시하기 전에 문구나 커스텀 값을 줄여야 해요.

### 커스텀 값이 들어간 캠페인을 서브 계정 간 템플릿으로 재사용할 수 있나요?

네. 캠페인을 템플릿으로 저장하면 커스텀 값 키가 그대로 남아요. 광고 문구 구조를 처음부터 다시 만들 필요 없이 서브 계정마다 고객사별 값만 매핑하면 돼요.

### 게시하기 전에 최종 광고 문구는 어디서 볼 수 있나요?

미리보기와 검토 화면에서 커스텀 값이 실제 텍스트로 바뀐 최종 광고 문구를 볼 수 있어요. 캠페인이 게시되기 전에 타깃 고객에게 보일 내용을 정확히 확인할 수 있어요.
