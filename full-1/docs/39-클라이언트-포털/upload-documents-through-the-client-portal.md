# 클라이언트 포탈에서 문서 업로드하기

하이퍼클래스 **클라이언트 포탈**에서는 고객이 파일을 안전하게 올려 CRM의 연락처 기록에 바로 저장할 수 있어요. 파일 공유가 간단해지고, 고객이 보낸 문서를 한곳에서 정리해 관리할 수 있어요. 이 문서에서는 고객이 문서를 업로드하는 방법과 업로드할 수 있는 파일 형식을 안내해요.

## 클라이언트 포탈의 문서 업로드란?

**클라이언트 포탈**에는 **문서 업로드** 기능이 있어요. 고객이 포탈에서 파일을 직접 보낼 수 있어요.

문서를 업로드하면 다음과 같이 처리돼요.

- 고객의 연락처 기록에 연결돼요.
- CRM 사용자가 문서를 보고, 다운로드하고, 관리할 수 있어요.
- 업로드한 파일은 **연락처 > 문서 > 수신됨 > 클라이언트 포탈**에 저장돼요.

{% hint style="info" %}
**클라이언트 포탈**에서는 문서 업로드만 지원해요. 동영상 파일은 올릴 수 없어요.
{% endhint %}

## 업로드할 수 있는 파일 형식

고객은 아래 문서·이미지 형식의 파일을 올릴 수 있어요.

문서

- PDF (.pdf)
- Microsoft Word (.doc, .docx)
- Microsoft Excel (.xls, .xlsx)
- Microsoft PowerPoint (.ppt, .pptx)
- 일반 텍스트 (.txt)
- 서식 있는 텍스트 형식 (.rtf)

이미지

- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)

{% hint style="info" %}
.mp4, .mov, .avi, .mkv, .wmv 같은 동영상 파일 형식은 **클라이언트 포탈**에서 업로드할 수 없어요.
{% endhint %}

## 문서 업로드의 장점

**클라이언트 포탈**로 문서를 받으면 다음과 같은 점이 좋아요.

- 고객에게서 문서를 안전하게 받을 수 있어요.
- 고객 파일을 CRM 연락처 기록 안에 정리해 둘 수 있어요.
- 이메일 첨부파일을 주고받지 않아도 돼요.
- 비즈니스와 고객이 더 빠르게 협업할 수 있어요.
- 업로드된 문서를 한곳에서 관리할 수 있어요.

## 문서를 업로드하는 방법

### 1단계: 클라이언트 포탈 접근 권한 부여하기

연락처에 **클라이언트 포탈** 접근 권한을 부여하세요.

### 2단계: 클라이언트 포탈 공유하기

고객을 초대해서 **클라이언트 포탈**에 접속할 수 있게 하세요.

### 3단계: 문서 업로드하기

1. **클라이언트 포탈**에 로그인하세요.
2. **문서** 섹션으로 이동하세요.
3. **문서 업로드**를 클릭하세요.
4. 기기에서 지원하는 문서 또는 이미지 파일을 선택하세요.
5. 업로드가 끝날 때까지 기다리세요.

### 4단계: 업로드된 문서 확인하기

CRM 사용자는 아래 경로에서 업로드된 문서를 확인할 수 있어요.

**연락처 > 연락처 선택 > 문서 > 수신됨 > 클라이언트 포탈**

## 자주 묻는 질문

### 고객이 클라이언트 포탈에서 문서를 업로드할 수 있나요?

네. 고객은 **문서 업로드** 기능으로 지원하는 문서와 이미지 파일을 올릴 수 있어요.

### 고객이 동영상 파일도 업로드할 수 있나요?

아니요. 현재 **클라이언트 포탈**은 문서와 이미지 업로드만 지원해요. 동영상 파일 형식은 지원하지 않아요.

### 고객이 업로드한 문서를 삭제할 수 있나요?

포탈 권한에 따라 고객이 자신이 올린 문서를 관리하거나 삭제할 수도 있어요.

### 파일이 업로드되지 않아요.

아래 내용을 확인해 보세요.

- 지원하는 형식의 파일인지 확인하세요.
- 파일이 손상되지 않았는지 확인하세요.
- 업로드가 정상적으로 끝났는지 확인하세요.
- 인터넷 연결이 안정적인지 확인하세요.
