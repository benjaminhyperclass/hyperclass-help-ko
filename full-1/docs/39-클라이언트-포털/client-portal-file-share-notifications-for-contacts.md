# 클라이언트 포탈 파일 공유 알림 (연락처용)

클라이언트 포탈로 연락처에게 새 파일을 공유하면, 하이퍼클래스가 연락처에게 자동으로 알림을 보내요. 연락처는 사업자가 따로 메시지를 보내지 않아도 문서, 계약서, 인보이스 등 공유된 파일을 쉽게 찾을 수 있어요. 연락처는 지원되는 클라이언트 포탈 화면에서 알림을 확인하고, 원하는 방식에 맞게 알림 설정을 바꿀 수 있어요.

## 파일 공유 알림이란?

클라이언트 포탈 관리자가 클라이언트 포탈로 파일을 공유하면, 연락처에게 알림이 가요. 사업자는 고객에게 새 소식을 알리고, 고객은 새로 공유된 문서를 바로 찾아 열 수 있어요.

사용자가 연락처 상세 화면에서 파일을 공유하면서 클라이언트 포탈에 업로드(공유)하는 옵션을 켜면, 하이퍼클래스가 해당 연락처에게 알림을 만들어요.

연락처의 알림 설정에 따라 다음 알림을 받을 수 있어요.

- 클라이언트 포탈의 **앱 내 알림**
- 지원되는 화이트라벨 모바일 앱의 **푸시 알림** (푸시 알림은 기기 권한에 따라 달라져요. 푸시 알림이 꺼져 있어도 연락처는 클라이언트 포탈에서 알림을 확인할 수 있어요.)

기본 파일 공유 알림을 보내기 위해 별도의 워크플로우를 만들 필요는 없어요.

## 클라이언트 포탈 파일 공유 알림의 장점

- 자동 고객 안내: 클라이언트 포탈로 파일이 공유되면 연락처에게 알림이 가요.
- 파일 확인이 쉬워짐: 업로드한 중요한 문서를 놓치는 일이 줄어요.
- 수동 안내 감소: 파일을 공유할 때마다 따로 메시지를 보내지 않아도 돼요.
- 여러 환경에서 확인 가능: 클라이언트 포탈 웹 화면과 화이트라벨 모바일 앱에서 알림을 받을 수 있어요.
- 연락처가 직접 설정: 연락처가 사용 가능한 앱 내 알림과 푸시 알림을 받을지 직접 정할 수 있어요.
- 더 나은 고객 경험: 제때 알림이 가면 문서 공유가 더 체계적이고 믿음직하게 느껴져요.

## 연락처에게 파일 공유하기

지원되는 클라이언트 포탈 방식으로 파일을 공유하면, 연락처가 문서에 접근하고 알림도 받을 수 있어요.

1. 하이퍼클래스 왼쪽 메뉴에서 **연락처**로 이동하세요.
2. 파일을 받을 연락처를 여세요.

   ![연락처 상세 화면](https://jumpshare.com/share/xxYKwvlIDYSJzQAj1gog+/Screen+Shot+2026-08-14+at+13.37.57.png)
3. 오른쪽 탐색 패널에서 **파일**/**문서** 영역을 여세요.
4. 새 파일을 **업로드**하거나 기존 파일을 선택하세요.
5. **Upload to Client Portal**(클라이언트 포탈에 업로드)을 활성화하세요.
6. 파일이 저장되고 공유되면, 하이퍼클래스가 연락처에게 앱 내 알림을 보내요. 푸시 알림이 켜져 있으면 푸시 알림도 보내요.

   ![파일 공유 후 알림이 전송되는 화면 녹화](https://jumpshare.com/share/fc0aGaqbNK8k31TGh2iT+/GIF+Recording+2026-08-14+at+13.41.02.gif)

## 연락처가 알림 설정 관리하기

연락처는 알림 설정에서 파일 관련 소식을 어떤 방식으로 받을지 정할 수 있어요. 설정을 최신 상태로 유지하면 원하지 않는 알림은 줄이고, 중요한 알림은 선호하는 채널로 계속 받을 수 있어요.

{% hint style="info" %}
알림을 꺼도 이미 공유된 파일에 접근하는 권한은 사라지지 않아요. 지원되는 활동에 대해 알림을 받는 방식만 바뀌어요.
{% endhint %}

1. 클라이언트 포탈에 로그인하세요.
2. **설정**으로 이동하세요.
3. **알림 설정**을 여세요.
4. **In-app Notifications**(앱 내 알림)와 **Push Notifications**(푸시 알림)를 켜거나 끄세요.

![클라이언트 포탈에서 알림 설정을 바꾸는 화면 녹화](https://jumpshare.com/share/C5hFfRCOWm3Nmq3yyZj8+/GIF+Recording+2026-08-14+at+13.48.19.gif)

## 자주 묻는 질문

### 파일 공유 알림을 보내려면 워크플로우를 만들어야 하나요?

아니요. 지원되는 클라이언트 포탈 파일 공유 과정으로 파일을 공유하면, 하이퍼클래스가 알림을 자동으로 만들어요.

### 어떤 알림 채널을 지원하나요?

파일 공유 알림은 앱 내 알림과 푸시 알림을 지원해요. 푸시 알림은 연락처가 직접 켜 두어야 해요.

### 연락처가 파일 공유 알림을 끌 수 있나요?

연락처는 클라이언트 포탈의 알림 설정에서 사용 가능한 앱 내 알림과 푸시 알림 설정을 관리할 수 있어요.

### 알림을 끄면 공유된 파일을 볼 수 없게 되나요?

아니요. 알림 설정은 알림만 조절해요. 이미 공유된 파일에 접근하는 권한과는 관계가 없어요.

### 연락처가 앱 내 알림은 받았는데 푸시 알림은 못 받았어요. 왜 그런가요?

클라이언트 포탈 환경설정, 모바일 앱, 또는 연락처 기기 설정에서 푸시 알림이 꺼져 있을 수 있어요.
