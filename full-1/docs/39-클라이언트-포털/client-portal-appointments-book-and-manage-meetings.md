# 클라이언트 포탈 예약 — 미팅 예약하고 관리하기

클라이언트가 하이퍼클래스 클라이언트 포탈에서 바로 예약하고, 예약 내용을 확인하고, 일정을 변경하거나 취소할 수 있게 해 주는 기능이에요. 이 문서에서는 기능 설명과 설정 방법을 안내해요.

클라이언트 포탈 예약을 쓰면 클라이언트는 포탈을 벗어나지 않고 미팅을 예약하고 관리할 수 있어요. **오늘**, **예정**, **지난 이벤트** 보기로 예약을 확인하고, 캘린더 보기로 날짜별 예약을 찾을 수 있어요. 여러분이 열어 둔 캘린더 한 개 또는 여러 개에서 예약도 할 수 있고요.

예약할 때 클라이언트의 연락처 정보는 가능한 범위에서 자동으로 채워져요. 어떤 캘린더에서 클라이언트 포탈 예약을 받을지, 포탈에 예약 앱을 보여 줄지는 비즈니스 쪽에서 정해요.

{% hint style="info" %}
**현재 제공 범위**
예약은 현재 새 클라이언트 포탈 화면에서만 쓸 수 있어요. 브랜드 앱 지원은 출시 예정이에요.
{% endhint %}

{% hint style="info" %}
**출시 범위**
이 문서는 현재 출시된 캘린더 기반 예약 기능을 다뤄요. 서비스 메뉴 예약과, 앞으로 추가될 예정인 예약 관련 이벤트 관리 기능은 아래 설정에 포함되지 않아요.
{% endhint %}

## 클라이언트 포탈 예약이란?

클라이언트 포탈 예약은 일정 예약 기능을 클라이언트 포탈 안으로 가져와요. 클라이언트는 다른 비즈니스 자료를 보는 곳에서 미팅과 예약 옵션도 함께 볼 수 있어요. 예약 링크나 확인 이메일, 별도의 일정 도구를 따로 찾아다닐 필요가 줄어들어요.

**예약**과 사용할 수 있는 캘린더가 하나 이상 켜져 있으면 클라이언트는 다음을 할 수 있어요.

- **오늘**, **예정**, **지난 이벤트**에서 예약 보기
- 캘린더 보기로 날짜별 예약 찾기
- 클라이언트 포탈을 떠나지 않고 새 예약하기
- 클라이언트 포탈 예약이 켜진 캘린더 중에서 하나 또는 여러 개 선택하기
- 예약 세부 정보 확인하기
- 변경·취소할 수 있는 예약의 일정 변경 또는 취소하기
- 예약이 끝난 뒤 새 예약 시작하기

### 클라이언트 포탈 예약의 장점

예약 확인과 예약 기능을 클라이언트 포탈에 넣으면 클라이언트가 일정을 더 직접 관리할 수 있어요. 한편 비즈니스는 어떤 예약 옵션을 열어 둘지 정확히 정할 수 있어요. 가용 시간을 관리하는 캘린더 규칙은 그대로예요.

- 한곳에서 예약 확인: 클라이언트가 이메일이나 별도 예약 링크에만 의존하지 않고 클라이언트 포탈에서 예약을 확인하고 관리해요.
- 간편한 예약: 클라이언트가 포탈을 벗어나지 않고 캘린더, 날짜, 시간을 골라요.
- 여러 캘린더 선택: 선택할 수 있는 캘린더를 한 개 또는 여러 개 열어 둘 수 있어요.
- 반복 입력 감소: 예약할 때 기존 연락처 정보가 있으면 자동으로 채워져요.
- 예약 셀프 관리: 캘린더 정책에서 허용하면 클라이언트가 예약을 취소하거나 일정을 변경할 수 있어요.
- 빠른 재예약: 예약이 끝난 뒤 바로 새 예약을 시작할 수 있어요.
- 관리자 통제: 예약 앱을 보여 줄지, 어떤 캘린더에서 클라이언트 포탈 예약을 받을지 비즈니스가 정해요.

### 사용 조건과 설정 요건

클라이언트 포탈 예약은 포탈 화면과 캘린더별 설정이 모두 갖춰져야 해요. 요건을 알아 두면 예약 앱은 보이는데 캘린더를 고르거나 예약을 마칠 수 없는 상황을 막을 수 있어요.

| 요건 | 하는 역할 | 필수 여부 |
| --- | --- | --- |
| 새 클라이언트 포탈 화면 | 현재 지원되는 클라이언트 포탈 예약 환경을 제공해요. | 필수 |
| 예약 앱 권한 | 클라이언트 포탈 메뉴에 **예약**을 보여 줄지 정해요. | 필수 |
| 캘린더의 **Client Portal booking**(클라이언트 포탈 예약) | 해당 캘린더를 예약 옵션으로 보여 줄지 정해요. | 필수 (캘린더마다) |
| **브랜드 클라이언트 포털 앱** | 이번 출시에는 브랜드 앱 지원이 포함되어 있지 않아요. | 현재 지원 안 됨 |

{% hint style="warning" %}
**설정은 두 부분이에요**
예약 하위 앱을 켠다고 캘린더 예약이 자동으로 켜지지는 않아요. 개별 캘린더 중 하나 이상에서 **Client Portal booking**도 켜야 해요.
{% endhint %}

## 예약 확인하고 관리하기

예약 보기를 쓰면 클라이언트가 지금 진행 중인 일정, 다음 일정, 이미 끝난 일정을 한눈에 알 수 있어요. 예약을 열어 미팅 정보를 확인하고, 캘린더 정책에서 허용한 관리 작업도 할 수 있어요.

클라이언트 포탈의 **예약**에서 **오늘**, **예정**, **지난 이벤트**로 미팅을 나눠 볼 수 있어요. 캘린더 보기를 쓰면 날짜로도 예약을 찾을 수 있어요.

![클라이언트 포탈 예약 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525228/original/qqq_9YFew4gq9Hy6BelIW4UDfXtTSHBHVQ.png?1788971394)

스크린샷: 캘린더 보기, 오늘/예정/지난 이벤트 탭, 예약 카드, 상세 정보 링크가 보이는 클라이언트 포탈 예약 페이지

### 예약 세부 정보와 가능한 작업 확인하기

예약을 열면 미팅 정보와 지금 할 수 있는 작업이 한 화면에 보여요. 취소와 일정 변경 옵션은 캘린더에 설정된 정책상 해당 예약이 아직 변경·취소 가능할 때만 나타나요.

1. 클라이언트 포탈 메뉴에서 **예약**을 엽니다.
2. 확인할 예약을 찾습니다.
3. **상세 정보**를 클릭합니다.
4. 예약 정보를 확인합니다.
5. 가능하면 **취소** 또는 **일정 변경**을 선택합니다.

![예약 세부 정보 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525282/original/0cGLDz1m9ov8FthhQR4r6J4Xm9409PAvdg.png?1788971421)

예약을 취소하거나 일정을 변경할 수 있는지는 해당 캘린더에 설정된 취소·일정 변경 규칙에 따라 달라요. 자세한 내용은 [취소 및 일정 변경 정책(예약 위젯)](../04-캘린더-예약/캘린더-만들기/cancellation-reschedule-policy-booking-widget.md)을 참고하세요.

## 클라이언트 포탈에서 예약하기

클라이언트는 여러분이 열어 둔 캘린더 중에서 하나를 고르고, 예약 가능한 날짜와 시간을 선택할 수 있어요. 포탈을 벗어날 필요가 없어요. 기존 연락처 정보는 가능한 범위에서 자동으로 채워지고, 예약할 수 있는 날짜와 시간은 선택한 캘린더가 계속 결정해요.

1. 클라이언트 포탈에서 **예약**을 엽니다.
2. **예약하기**를 클릭합니다.
3. 예약 가능한 캘린더를 선택합니다.
4. 예약 가능한 날짜를 선택합니다.
5. 예약 가능한 시간을 고릅니다.
6. 예약을 완료합니다.

![클라이언트 포탈 예약 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525340/original/Z0DyFwUzuPOCTxVAfPeXD1S7Z8DeRPbJxA.png?1788971442)

클라이언트에게 보이는 날짜와 시간은 선택한 캘린더의 가용성 및 일정 규칙으로 정해져요. 업무 시간, 시간대 길이, 최소 예약 사전 알림 시간, 버퍼, 예약 한도, 기존 예약, 연결된 캘린더와의 일정 충돌이 어떤 시간대가 보일지에 영향을 줄 수 있어요.

자세한 내용은 [개별 캘린더의 가용성 설정 조정하기](../04-캘린더-예약/Calendar-Availability-Settings/adjusting-availability-settings-for-individual-calendars.md)를 참고하세요.

## 여러 캘린더로 클라이언트 포탈 예약 받기

캘린더를 여러 개 켜 두면 클라이언트가 예약 옵션을 골라 쓸 수 있어요. 클라이언트 포탈에 보일 캘린더는 여러분이 정확히 정할 수 있어요. 예약 유형, 부서, 위치, 팀원별로 캘린더를 나눠 쓴다면 유용해요.

클라이언트 포탈 예약은 캘린더마다 따로 켜요. 캘린더 하나만 켤 수도 있고, 클라이언트가 선택할 수 있게 하려는 캘린더마다 같은 설정을 반복할 수도 있어요.

| 옵션 | 용도 | 클라이언트 포탈에서 여러 캘린더를 쓰려면 필요한가요? |
| --- | --- | --- |
| **Client Portal Calendar Selector**(클라이언트 포탈 캘린더 선택기) | 클라이언트 포탈 예약이 켜진 개별 캘린더를 보여 줘요. | 필요해요 |
| **Group Calendar**(그룹 캘린더) | 캘린더를 묶어 하나의 공유 링크로 별도의 그룹 예약 환경을 제공해요. | 필요하지 않아요 |

개별 캘린더 여러 개를 클라이언트 포탈 예약에 보여 주려고 그룹 캘린더를 만들 필요는 없어요. 그룹 캘린더에 대한 자세한 내용은 [하이퍼클래스 그룹 캘린더 개요 및 설정 가이드](../04-캘린더-예약/hyperclass-group-calendar-overview-and-setup-guide.md)를 참고하세요.

## 클라이언트 포탈 예약 설정하기

클라이언트 포탈 예약은 캘린더 설정과 클라이언트 포탈의 **앱 권한**에서 모두 설정해야 해요. **앱 권한**은 클라이언트가 예약 앱에 접근할 수 있는지 정하고, 개별 캘린더 설정은 새 예약에서 어떤 캘린더를 고를 수 있는지 정해요.

두 단계를 모두 완료하세요. 예약 하위 앱만 켜면 캘린더가 열리지 않고, 캘린더만 켜면 예약 앱이 보이지 않아요.

### 1단계: 캘린더에서 클라이언트 포탈 예약 켜기

클라이언트가 캘린더를 고르려면 먼저 캘린더마다 클라이언트 포탈 예약을 직접 켜야 해요. 이렇게 하면 클라이언트 포탈 사용자에게 알맞은 캘린더만 열고, 나머지 캘린더는 이 예약 경로로 쓸 수 없게 둘 수 있어요.

1. **캘린더**로 이동해 **캘린더 설정**을 엽니다.

![캘린더 설정 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525360/original/4Hlu9qVu7dSx77OJiiSz-RvgWFTC-6XgbA.gif?1788971461)

2. **미팅 > 캘린더**에서 열어 둘 캘린더를 찾습니다.
3. **캘린더 편집** 아이콘을 클릭합니다.

![캘린더 편집 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525458/original/zcXDyWkEXx7ZFxkRVdyCFFJVft_HPAINZQ.png?1788971548)

4. 캘린더 편집 화면에서 **고급 설정**을 펼칩니다.
5. **Booking channels**(예약 채널)를 선택합니다.
6. **Client Portal booking**(클라이언트 포탈 예약)을 켭니다.
7. **변경사항 저장**을 클릭합니다.

![클라이언트 포탈 예약 켜기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525528/original/lG-JMQVf0wBx0UvHA0frdE19Y7KrTQ3WDw.png?1788971589)

클라이언트가 클라이언트 포탈에서 예약할 때 선택할 수 있게 하려는 캘린더마다 같은 순서를 반복하세요.

### 2단계: 앱 권한에서 예약 켜기

예약 하위 앱을 켜면 클라이언트 포탈 안에 예약 기능이 보여요. **앱 권한**은 서브 계정 단위로 설정돼요. 그래서 선택한 하위 앱 표시 여부는 해당 서브 계정의 클라이언트 포탈을 쓰는 연락처 모두에게 적용돼요.

1. **멤버십**으로 이동합니다.
2. **클라이언트 포탈**을 엽니다.
3. **설정**을 선택합니다.
4. **앱 권한**을 엽니다.

![앱 권한 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525542/original/mnjZJ-E2lap5gbw2NVQ0GtQrcXyXIBOK0A.png?1788971616)

5. 하위 앱 목록에서 **예약**을 찾습니다.
6. **예약**을 켭니다.
7. **설정 저장**을 클릭합니다.

![앱 권한에서 예약 켜기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080525579/original/hVk_lHQtBAVXmfKv_RUaaUq9spsP5zs9FQ.png?1788971652)

{% hint style="warning" %}
**중요:** 앱 권한에서 **예약**을 켜도 모든 캘린더가 자동으로 예약 가능해지지는 않아요. 클라이언트가 선택할 수 있게 하려는 캘린더마다 **Booking channels** 설정에서 **Client Portal booking**도 켜야 해요.
{% endhint %}

클라이언트 포탈 앱을 관리하는 방법은 [클라이언트 포탈의 앱 권한: 하위 앱 켜기/끄기 및 인증](Client-Portal/app-permissions-in-client-portal-enabling-disabling-a-child-app.md)을 참고하세요.

## 클라이언트 포탈 예약 문제 해결

클라이언트 포탈 예약 문제는 대부분 필수 권한 두 가지 중 하나, 개별 캘린더 규칙, 또는 지원되지 않는 포탈 환경을 쓰고 있기 때문에 생겨요. 캘린더를 바꾸거나 예약을 다시 만들기 전에 클라이언트가 보는 화면과 아래 확인 사항을 비교해 보세요.

| 문제 | 확인할 사항 |
| --- | --- |
| 포탈에 **예약**이 보이지 않아요 | 클라이언트가 새 클라이언트 포탈을 쓰고 있는지, **앱 권한**에서 **예약**이 켜져 있는지, 변경사항을 저장했는지 확인하세요. |
| **예약**은 보이는데 선택할 수 있는 캘린더가 없어요 | 개별 캘린더 하나 이상에서 **고급 설정 > Booking channels**의 클라이언트 포탈 예약을 켜세요. |
| 캘린더는 보이는데 특정 시간대가 없어요 | 가용성, 예약 사전 알림 시간, 버퍼, 예약 한도, 기존 예약, 연결된 캘린더와의 일정 충돌을 확인하세요. |
| **취소** 또는 **일정 변경**을 할 수 없어요 | 해당 캘린더에서 그 작업을 허용하는지, 취소·일정 변경 제한 기간이 지났는지 확인하세요. |
| 시간대 선택기가 보이지 않아요 | 서브 계정에서 **연락처 시간대 비활성화**가 켜져 있는지 확인하세요. |
| 최근에 바꾼 권한이 반영되지 않아요 | 변경사항을 저장했는지 확인한 뒤, 클라이언트에게 포탈을 새로고침하거나 로그아웃 후 다시 로그인하도록 안내하세요. |

## 자주 묻는 질문

### 예약을 켜면 모든 캘린더가 자동으로 예약 가능해지나요?

아니요. **예약**을 켜면 앱이 보이게 될 뿐이에요. 캘린더마다 **고급 설정 > Booking channels**에서 **Client Portal booking**을 따로 켜야 해요.

### 클라이언트 포탈에 일부 캘린더만 열어 둘 수 있나요?

네. 클라이언트 포탈 예약은 캘린더마다 따로 켜기 때문에 클라이언트가 고를 수 있는 캘린더를 정확히 정할 수 있어요.

### 여러 캘린더를 보여 주려면 그룹 캘린더를 만들어야 하나요?

아니요. 클라이언트 포탈은 개별적으로 켜 둔 여러 캘린더를 캘린더 선택기로 보여 줄 수 있어요. 그룹 캘린더는 별도의 그룹 예약 기능이에요.

### 캘린더에 설정한 기존 가용성 규칙도 그대로 적용되나요?

네. 클라이언트 포탈 예약에서도 선택한 캘린더의 가용성 및 일정 규칙으로 클라이언트가 예약할 수 있는 날짜와 시간을 정해요.

### 특정 클라이언트 한 명에게만 예약을 켤 수 있나요?

**앱 권한**은 서브 계정 단위로 설정돼요. **예약**을 켜거나 끄면 연락처 한 명이 아니라 해당 서브 계정의 클라이언트 포탈을 쓰는 연락처에게 보이는 여부가 바뀌어요.

### 예약 하위 앱을 나중에 끄면 어떻게 되나요?

클라이언트 포탈에서 **예약**이 사라져요. 하지만 하이퍼클래스의 다른 곳에 설정된 캘린더와 예약 기록은 삭제되지 않아요. 나중에 앱을 다시 켤 수 있어요.

### 브랜드 앱에서도 클라이언트 포탈 예약을 쓸 수 있나요?

현재 출시 버전에서는 쓸 수 없어요. 클라이언트 포탈 예약은 현재 새 클라이언트 포탈 화면에서만 쓸 수 있어요.

### 이 화면에서 서비스를 예약하거나 추가 이벤트 관리 기능을 쓸 수 있나요?

현재 출시 버전은 표준 캘린더 기반 예약을 다뤄요. 서비스 메뉴 예약과 예약 관련 이벤트 관리 기능은 이 문서에서 설명하는 작업 범위에 포함되지 않아요.
