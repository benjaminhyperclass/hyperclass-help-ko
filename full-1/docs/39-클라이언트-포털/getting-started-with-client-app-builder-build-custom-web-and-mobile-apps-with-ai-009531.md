# Client App Builder 시작하기: AI로 웹 앱과 모바일 앱 만들기

**Client App Builder**(클라이언트 앱 빌더)는 코드를 쓰지 않고 AI로 브랜드에 맞는 웹 포탈과 Android 모바일 앱을 만드는 기능이에요. 이 문서에서는 기능을 켜는 방법부터 앱 만들기, 미리보기, 게시, 관리까지 한 번에 안내해요.

비즈니스와 원하는 경험을 설명하기만 하면 돼요. AI가 앱을 기획하고 페이지를 디자인하고, 이미 쓰고 있는 하이퍼클래스 기능을 연결해 작동하는 앱을 만들어 줘요. 만든 앱은 미리 보고, 수정하고, 게시할 수 있어요.

학습 포탈, 코칭 플랫폼, 멤버십, 브랜드 모바일 앱 등 어떤 앱이든 하이퍼클래스의 기존 도구와 데이터를 그대로 활용할 수 있어요.

제공 위치: Client App Builder는 서브 계정의 **실험실**(Labs)에서 사용할 수 있어요.

## 1. Client App Builder란?

Client App Builder는 클라이언트와 멤버를 위한 맞춤 경험을 만들어 주는 AI 앱 빌더예요.

요소를 하나하나 직접 배치하는 일반 웹사이트 빌더와 달리, 원하는 내용을 일상적인 말로 설명하면 돼요. 디자인, 페이지, 내비게이션, 지원되는 기능은 AI가 만들어 줘요.

### 무엇을 만들 수 있나요?

웹 앱

브라우저에서 쓰는 클라이언트 포탈을 원하는 대로 꾸밀 수 있어요. 멤버가 코스를 보고, 커뮤니티에 참여하고, 예약을 관리하고, **공유된 파일**을 열어 보고, 비즈니스와 소통할 수 있어요.

모바일 앱

내비게이션, 레이아웃, 색상, 모바일 기본 기능을 갖춘 브랜드 Android 앱을 만들 수 있어요. 빌더에서 바로 설치용 Android APK를 만들 수도 있어요.

### 작동 방식

Client App Builder는 다음 순서로 진행돼요.

1. 설명: 비즈니스와 원하는 경험을 AI에게 알려 주세요.
2. 맞춤 설정: 설정 질문에 답하고 브랜딩과 디자인 취향을 고르세요.
3. 제작: AI가 앱의 페이지, 화면, 지원되는 기능을 만들어요.
4. 수정: 대화나 시각적 편집 도구로 앱을 다듬어요.
5. 미리보기: 게시하기 전에 앱을 살펴봐요.
6. 게시: 웹 앱을 공개하거나 설치용 Android 앱을 만들어요.

만든 앱은 하이퍼클래스 클라이언트 포탈의 기존 기반을 그대로 써요. 멤버 계정, 코스, 커뮤니티, 지원되는 CRM 데이터가 모두 포함돼요.

## 2. Client App Builder 켜기

Client App Builder는 현재 **실험실**에서 제공돼요.

### 1단계: 기능 켜기

1. 하이퍼클래스 계정을 엽니다.
2. **실험실**로 이동합니다.
3. **Client App Builder**를 찾습니다.
4. 서브 계정에서 이 기능을 켭니다.

![실험실의 Client App Builder 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618262/original/MJVKp03aX1qvEO1p5EnMU2_56B0I-bcZ6A.jpeg?1793372091)

### 2단계: Client App Builder 열기

기능을 켜면 **멤버십 > Client App Builder**를 열어요.

계정의 내비게이션 구성에 따라 **Client Apps**(클라이언트 앱) **> Client App Builder** 경로로 보일 수도 있어요.

![Client Apps 메뉴의 Client App Builder](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618257/original/TK-nOP8Dp9FehN9hEU9Q_jqWEskCplr4dQ.jpeg?1793372090)

{% hint style="info" %}
Client App Builder는 서브 계정 단위로 작동해요. 한 서브 계정에서 만든 앱이 다른 서브 계정에 자동으로 생기지는 않아요.
{% endhint %}

## 3. 첫 번째 앱 만들기

Client App Builder를 열면 만들고 싶은 앱을 설명하는 입력창이 보여요.

자세한 설명으로 시작해도 되고, 예약, 이벤트, 에이전시 클라이언트 포탈 같은 추천 아이디어 중에서 골라도 돼요.

![Client App Builder 홈 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618256/original/Bkve0netv8TdhODEOgPE2Yk1RalT6X6D9Q.jpeg?1793372090)

### 1단계: 앱 설명하기

예를 들면 이렇게 쓸 수 있어요.

"피트니스 스튜디오용 멤버 포탈을 만들어 줘. 멤버가 코스를 둘러보고 구매하고, 커뮤니티에 참여하고, 예약하고, 자료를 볼 수 있어야 해. 우리 브랜드 색상을 쓴 깔끔하고 현대적인 디자인으로 부탁해."

비즈니스, 대상 고객, 원하는 기능을 자세히 알려 줄수록 첫 앱이 더 잘 맞게 만들어져요.

![앱 설명 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618270/original/aqfhJRkzvfwwgIOvTkxITB-QBhdZfarvWg.jpeg?1793372091)

### 2단계: 웹 또는 모바일 선택하기

만들 앱의 종류를 고르세요.

- **Web**(웹): 브라우저에서 쓰는 클라이언트 포탈이에요.
- **Mobile**(모바일): 브랜드를 입힌 Android 모바일 앱이에요.

입력한 설명을 보고 AI가 앱 종류를 추천할 수도 있어요. 앱을 만들기 전에는 바꿀 수 있어요.

{% hint style="warning" %}
앱을 한 번 만들고 나면 웹과 모바일 사이에서 바꿀 수 없어요. 다른 형식이 필요하면 앱을 따로 만드세요.
{% endhint %}

![웹 또는 모바일과 시작 방식 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618269/original/akAx0TzBnppC27ltcB6_I4uArnYrS_Lg_Q.jpeg?1793372091)

### 3단계: 설정 질문에 답하기

AI가 비즈니스, 앱 이름, 대상 고객, 필요한 기능, 앱에 접근할 수 있는 사람 등을 물어볼 수 있어요.

이 답변을 바탕으로 앱이 내 상황에 맞게 만들어져요.

![설정 질문](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618271/original/kqxti-7e8IG26hizpesQkPu3JnEMrJYmcg.jpeg?1793372091)

### 4단계: 디자인 선택하기

앱 종류와 시작 방식에 따라 추천 디자인 시스템, 색상, 글꼴, 기존 브랜드 보드 중에서 고를 수 있어요.

지원되는 웹 앱에서는 디자인 시스템을 더 둘러보고, 이미지를 첨부해 원하는 분위기를 알려 줄 수도 있어요.

![색상 팔레트와 글꼴 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618272/original/noXBaBQ2wmREZBfaw3NU4unxEV_t9QfVBw.jpeg?1793372091)

### 5단계: 검토하고 만들기

지원되는 웹 앱은 앱을 만들기 전에 AI가 먼저 계획을 보여 줘요.

![제작 계획 검토](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618273/original/F22Mm8Q8AystHFDNrTtL4FHlUNlB-t9QdQ.jpeg?1793372091)

다음 중에서 고를 수 있어요.

- **Approve & build**(승인 후 만들기): 제안된 계획 그대로 진행해요.
- **Refine**(수정 요청): 만들기 전에 변경을 요청해요.
- **Reject**(거절): 제안된 계획을 받아들이지 않아요.

제작이 시작되면 진행 상황을 지켜볼 수 있고, 준비가 끝나면 미리보기를 열 수 있어요.

![제작 진행 상황](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618266/original/cZynRK6xZrjc6BjuOeo_mU8SI0h0dbSsdQ.jpeg?1793372091)

## 4. 시작 방식 고르기

앱을 만드는 방식은 두 가지예요.

### 옵션 A: Describe It Instead(직접 설명해서 만들기, Vibe Coding)

설명한 내용을 바탕으로 AI가 맞춤 경험을 만들어 주길 원할 때 고르세요.

AI가 비즈니스 요구 사항과 디자인 취향에 맞춰 페이지, 레이아웃, 내비게이션을 만들어 줘요.

기본 클라이언트 포탈 레이아웃이 아니라 나만의 개성 있는 경험을 원할 때 알맞아요.

예를 들면 이렇게 요청할 수 있어요.

"개인 맞춤 환영 대시보드, 예정된 세션, 이용할 수 있는 프로그램, 멤버 커뮤니티가 있는 코칭 포탈을 만들어 줘."

지원되는 웹 앱에서는 비주얼 편집, AI가 제안하는 다음 단계, 페이지 제작 프롬프트로 계속 다듬을 수 있어요.

### 옵션 B: ClientPortal Standard

익숙한 하이퍼클래스 클라이언트 포탈 경험에서 시작해 모양과 내비게이션만 바꾸고 싶을 때 고르세요.

전체를 처음부터 다시 만들지 않고도 지원되는 기본 페이지를 꾸미고, 브랜딩을 조정하고, 레이아웃을 설정할 수 있어요.

표준 웹 앱에서는 대시보드, 상품, 강의, 커뮤니티, 인보이스를 기본 기능으로 시작할 수 있어요. 모바일 앱은 제공 기능이 다를 수 있어요.

![ClientPortal Standard 시작 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618278/original/c2ya_vwItseOF6-Bh2bVIi5tYlYqoz-GmA.jpeg?1793372092)

어떤 방식을 골라야 할까요?

AI가 만든 더 개성 있는 경험을 원하면 **Describe It Instead**를 고르세요. 익숙한 포탈 구조는 유지하면서 디자인과 내비게이션만 바꾸고 싶다면 **ClientPortal Standard**를 고르세요.

## 5. AI로 앱 꾸미기

처음 만든 앱은 시작일 뿐이에요.

Client App Builder에서는 대화로 계속 앱을 다듬을 수 있어요.

### 채팅으로 변경하기

메시지 입력창에 이런 식으로 요청해 보세요.

- "홈페이지를 더 현대적이고 미니멀하게 바꿔 줘."
- "내비게이션 맨 위로 코스를 옮겨 줘."
- "예정된 워크숍 페이지를 추가해 줘."
- "기본 색상을 우리 브랜드에 맞게 바꿔 줘."
- "코스 카드를 더 눈에 띄게 해 줘."

디자인을 새로 바꿔 달라고 따로 요청하지 않으면, 이어지는 요청에서는 보통 기존 디자인이 유지돼요.

![채팅으로 앱 다듬기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618259/original/Ntwwvai3BO0SuidKWoQr-WGr__P5t4-1oQ.jpeg?1793372091)

### 비주얼 편집 사용하기

**Describe It Instead**로 만든 웹 앱에서는 미리보기에서 요소를 직접 골라 **비주얼 편집**을 쓸 수 있어요.

바꾸고 싶은 요소를 선택한 뒤 원하는 변경 내용을 설명하세요.

비주얼 편집 요청 한 번에 최대 20개의 요소를 선택할 수 있어요.

### 빠진 페이지 만들기

생성된 웹 앱에 아직 만들지 않은 페이지로 가는 링크가 있으면 **Build this page**(이 페이지 만들기) 옵션이 보일 수 있어요.

이 옵션을 누르면 빠진 페이지를 AI에게 만들어 달라는 요청이 준비돼요.

### 레이아웃과 테마 꾸미기

**ClientPortal Standard** 앱은 미리보기가 준비되면 **Customizer**(커스터마이저)에서 더 많은 설정을 쓸 수 있어요.

앱 종류에 따라 다음을 바꿀 수 있어요.

- 브랜드 색상, 글꼴, 로고, 앱 아이덴티티
- 내비게이션 항목, 아이콘, 순서
- 기본 페이지와 첫 화면
- 모바일 하단 탭, 헤더 스타일, 계정 위치
- 사용자 지정 내비게이션 링크와 지원되는 페이지

모바일 앱은 처음 열 때 라이트 모드로 열지 다크 모드로 열지도 설정할 수 있어요.

![레이아웃 커스터마이저 - 내비게이션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618274/original/bwXrdcuTezHrd8RXCzr6I5OWw8CPWtgjmA.jpeg?1793372091)

![테마 커스터마이저](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618281/original/BYqhU346oxTUfcbijtRbO-5Zuq90WUM2VQ.jpeg?1793372092)

{% hint style="info" %}
레이아웃·테마 **Customizer**는 **ClientPortal Standard** 앱에서 쓸 수 있어요. **Describe It Instead**로 만든 앱은 주로 AI 프롬프트와 지원되는 편집 도구로 꾸며요.
{% endhint %}

## 6. 하이퍼클래스 기능 연결하기

Client App Builder의 큰 장점은 앱에서 하이퍼클래스의 기존 기능을 그대로 쓸 수 있다는 점이에요.

멤버십 기반을 다시 만들거나 멤버 계정을 따로 관리할 필요가 없어요.

### 지원되는 기능

코스

멤버가 코스를 둘러보고, 판매 중인 콘텐츠를 구매하고, 강의를 보고, 학습 진행률을 확인하고, 지원되는 라이브 세션에 참여할 수 있어요.

커뮤니티

커뮤니티 그룹, 피드, 초대, 지원되는 탐색 기능에 접근하게 할 수 있어요.

예약

지원되는 클라이언트 포탈 기능을 통해 멤버가 예약 관련 경험을 이용할 수 있어요.

공유된 파일

자료와 파일을 앱에서 멤버에게 제공할 수 있어요.

멤버 계정

기존 클라이언트 포탈 인증을 그대로 써요. 로그인, 회원가입, 비밀번호 찾기가 포함돼요.

CRM 데이터

지원되는 CRM 정보와 사용자 지정 객체를 활용해 데이터 기반의 상호작용형 멤버 경험을 만들 수 있어요.

이 기능들은 하이퍼클래스의 기존 시스템으로 작동하기 때문에 멤버 경험이 내 비즈니스와 계속 연결돼요.

## 7. 앱에서 사용자 지정 객체 쓰기

사용자 지정 객체를 쓰면 정보를 보여 주는 데서 한 걸음 더 나아가, 멤버가 하이퍼클래스 CRM에 저장된 레코드를 제출하고 다룰 수 있어요.

예를 들어 멤버가 코칭 신청서, 부동산 문의, 서비스 요청을 제출하는 포탈을 만들 수 있어요.

### 사용자 지정 객체 작동 방식

1. 멤버가 제출하거나 관리할 정보를 설명합니다.
2. 요청에 CRM 데이터 저장이 필요하면, AI가 사용자 지정 객체를 쓸지 물어봅니다.
3. AI가 필드, 드롭다운 옵션, 지원되는 관계를 포함한 데이터 구조를 제안합니다.
4. 제안된 구조, 샘플 레코드, 멤버에게 보이는 범위를 검토합니다.
5. 계획을 승인하거나 변경을 요청합니다.
6. AI가 승인된 객체와 연결된 앱 경험을 만듭니다.

![제안된 사용자 지정 객체 구조](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618277/original/oDE3lPOpumGBnwupg78KLZmrxG875g3icw.jpeg?1793372092)

### 멤버에게 보이는 범위

설정에 따라 멤버가 볼 수 있는 레코드를 다음 중에서 정할 수 있어요.

- 본인의 레코드
- 본인 회사와 연결된 레코드
- 모든 레코드(읽기 전용)

![멤버에게 보이는 범위 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618264/original/VooI4Su1_P3b2bsd0iJVFTSRdCjaYQ_lVg.jpeg?1793372091)

### 결제와 레코드

지원되는 웹 앱은 결제 제공업체가 연결되어 있으면 하이퍼클래스 인보이스를 이용한 결제 액션도 넣을 수 있어요.

사용자 지정 객체는 한 번의 변경에 최대 3개까지 지원돼요. 단, CRM 전체 한도인 서브 계정당 사용자 지정 객체 10개를 넘을 수 없어요.

{% hint style="warning" %}
사용자 지정 객체는 웹과 모바일 모두에서 지원되지만, 레코드 기반 결제와 미디어 첨부 같은 일부 기능은 현재 웹에서만 쓸 수 있어요.
{% endhint %}

## 8. 웹 앱 미리보기와 게시

### 앱 미리보기

Client App Builder는 만드는 동안 실시간 미리보기를 보여 줘서 경험을 바로 살펴볼 수 있어요.

웹 앱의 미리보기 컨트롤은 다음과 같아요.

- 데스크톱, 태블릿, 모바일 화면 크기
- 뒤로 가기, 앞으로 가기
- 새로 고침
- **새 탭에서 열기**
- 미리보기 URL 복사

![웹 앱 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618276/original/7lbvaJ1mR9FFTgIL6K0xgb5jAJcAn5cLrg.jpeg?1793372092)

미리보기를 오랫동안 쓰지 않으면 리소스를 아끼기 위해 일시 중지될 수 있어요. 빌더로 돌아오면 다시 시작돼요.

게시된 앱은 미리보기가 쉬고 있어도 영향을 받지 않아요.

### 웹 앱 게시하기

앱이 마음에 들면 다음 순서로 게시하세요.

1. 게시 컨트롤을 엽니다.
2. app.clientclub.net에서 사용할 수 있는 주소를 고릅니다.
3. 아직 만들지 않은 연결 페이지가 있다는 경고가 있으면 확인합니다.
4. 빠진 페이지를 만들거나, 해당 페이지가 미완성인 채로 게시하기를 선택합니다.
5. 앱을 게시합니다.

![게시 창 - 앱 주소와 사용자 지정 도메인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618267/original/OZypRGh2URDlC20adzFDInZucAlSgjJDsg.jpeg?1793372091)

이후에 변경 사항을 추가로 게시할 수 있고, 필요하면 앱 게시를 취소할 수도 있어요.

### 사용자 지정 도메인 연결하기

게시된 웹 앱에는 내 도메인도 연결할 수 있어요.

Client App Builder가 도메인 연결을 단계별로 안내하고, 필요하면 DNS를 직접 설정할 수도 있어요.

웹 앱 하나에 사용자 지정 도메인을 최대 10개까지 연결할 수 있어요.

{% hint style="info" %}
서브 계정의 현재 클라이언트 포탈 도메인으로 이미 지정된 도메인은 쓸 수 없어요.
{% endhint %}

## 9. Android 앱 만들기와 게시

Client App Builder로 브랜드 Android 모바일 앱도 만들 수 있어요.

### 모바일 경험 꾸미기

시작 방식에 따라 다음과 같은 모바일 기능을 설정할 수 있어요.

- 앱 이름, 브랜딩, 색상, 글꼴
- 하단 내비게이션 탭과 헤더 레이아웃
- 로그인 후 처음 보이는 화면
- 커뮤니티와 코스 내비게이션
- 사용자 지정 페이지와 외부 모듈
- 카메라, 사진 접근 같은 기기 기능

신규 멤버는 가입 코드로 가입할 수 있어요.

### 모바일 앱 미리보기

빌더가 휴대폰 화면 틀 안에 모바일 경험을 보여 줘요. 설치용 앱을 만들기 전에 디자인과 내비게이션을 확인할 수 있어요.

### Android APK 만들기

준비가 끝나면 다음 순서로 진행하세요.

1. 모바일 앱의 게시 컨트롤을 엽니다.
2. 필요한 앱 아이덴티티와 브랜딩 자산을 입력합니다.
3. Android APK 빌드를 시작합니다.
4. 빌드 상태를 확인합니다.
5. 서명된 APK가 준비되면 다운로드합니다.

![Android APK 게시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618263/original/za0xZUL9D8-lHSFs6XcbqT9dHICJZSxgEQ.jpeg?1793372091)

APK 빌드는 보통 15~25분 정도 걸려요.

![Android APK 자산과 서명된 APK 빌드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618268/original/yQDgxkWxhsCdyACdH7aU8vVUu0cr1mhakw.jpeg?1793372091)

### 필요한 Android 자산

| 자산 | 요구 사항 |
| --- | --- |
| 앱 이름 | 1~30자 |
| 앱 아이콘 | PNG, 1024 × 1024 픽셀, 최대 5MB |
| 스플래시 화면 | PNG, 1080 × 1920 픽셀, 최대 5MB |
| Firebase 설정 | 선택 사항. 패키지 ID와 일치하는 google-services.json, 최대 5MB |

### 모바일 게시 시 알아 둘 제한 사항

현재 Client App Builder는 Android APK 다운로드만 지원해요. Google Play나 Apple App Store에 직접 게시하는 기능은 아직 없어요.

지금은 앱 하나당 서명된 APK를 하나만 만들 수 있어요.

**ClientPortal Standard** 모바일 앱은 지원되는 디자인·설정 변경을 이미 설치된 앱에 게시할 수 있어요. **Describe It Instead**로 만든 앱에서 AI가 새로 만든 화면을 쓰려면 새 APK가 필요한데, 이 기능은 아직 지원되지 않아요.

서명된 APK를 만들기 전에 Android 경험을 꼼꼼히 계획하고 테스트하세요.

iOS 앱 생성은 아직 지원되지 않아요.

## 10. 앱 관리하기

Client App Builder에는 앱을 확인하고 관리하는 프로젝트 대시보드가 있어요.

홈 화면에서 최근 프로젝트를 보거나 **모든 프로젝트**를 열 수 있어요.

사용할 수 있는 관리 기능은 다음과 같아요.

- 기존 앱 검색
- 최근 프로젝트와 즐겨찾기 프로젝트 보기
- 앱 즐겨찾기 지정과 해제
- 앱 이름 변경
- 앱 삭제
- 웹·모바일 프로젝트와 상태 확인

![프로젝트 옵션 - 즐겨찾기, 이름 변경, 삭제](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618265/original/bOqmnIOtqHKG1NZo3FpD62FLagZQuC5m5g.jpeg?1793372091)

### 앱 개수 제한

서브 계정 하나에서 웹 프로젝트와 모바일 프로젝트를 합쳐 최대 5개의 앱을 만들 수 있어요.

한도에 도달했다면 기존 앱을 삭제해야 다른 앱을 만들 수 있어요.

{% hint style="warning" %}
사용자 화면에서 앱을 삭제하면 되돌릴 수 없어요. 확인을 누르기 전에 신중하게 결정하세요.
{% endhint %}

### 누가 앱에 접근할 수 있나요?

접근 권한은 하이퍼클래스 서브 계정에서의 역할에 따라 달라요.

- 관리자는 서브 계정 안에서 만든 앱을 보고, 편집하고, 삭제할 수 있어요.
- 일반 사용자는 앱을 만들 수 있고 본인이 만든 앱을 관리할 수 있어요. 다른 사용자의 앱은 볼 수 없어요.
- 앱을 열 수 있는 사용자는 해당 앱의 게시 컨트롤에도 접근할 수 있어요.

## 11. 외부 AI 도구로 만들기(MCP)

고급 사용자는 호환되는 외부 AI 개발 도구에서 하이퍼클래스의 Model Context Protocol(MCP) 연동으로 웹 앱을 만들 수도 있어요.

지원되는 설정 옵션은 Claude, Claude Code, ChatGPT, Codex, Cursor, VS Code예요.

### 작동 방식

1. Client App Builder에서 **Build from your editor**(에디터에서 만들기) 섹션을 엽니다.
2. 사용할 지원 AI 도구를 고릅니다.
3. 화면에 나오는 MCP 연결 안내를 따릅니다.
4. 하이퍼클래스에 로그인합니다.
5. 작업할 서브 계정을 선택합니다.
6. 요청된 접근 권한을 승인합니다.

![에디터에서 만들기(MCP)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084618261/original/pR7z2nPg-E3b3lO5C909ffdjq_03sMyC2w.jpeg?1793372091)

연결하고 나면 지원되는 도구로 앱 생성, 빌드 시작, 진행 상황 확인, 설정 질문 답변, 앱 파일 편집을 할 수 있어요.

{% hint style="warning" %}
MCP 접근은 현재 앱 게시와 게시 취소, 시크릿 관리, 프로덕션 모바일 앱 빌드를 지원하지 않아요.
{% endhint %}

## 12. 현재 제한 사항

Client App Builder는 계속 발전하고 있어요. 앱을 계획할 때 아래 제한 사항을 참고하세요.

| 기능 | 현재 지원 상황 |
| --- | --- |
| 웹 앱 만들기 | 지원 |
| Android 앱 만들기 | 지원 |
| iOS 앱 만들기 | 아직 없음 |
| Google Play / App Store 게시 | 아직 없음 |
| 웹 사용자 지정 도메인 | 지원(최대 10개) |
| 서브 계정당 앱 개수 | 5개 |
| AI가 만드는 사용자 지정 객체 | 지원(CRM 한도 적용) |
| 업종별 기성 템플릿 | 출시 예정 |
| 웹 앱 복제 | 현재 지원되지 않음 |
| 웹 버전 기록과 복원 | 현재 지원되지 않음 |
| 사용자 지정 서버 사이드 코드와 데이터베이스 | 지원되지 않음 |
| 외부 npm 패키지 설치 | 지원되지 않음 |
| 사용자 지정 결제 체크아웃 | 지원되지 않음. 지원되는 결제는 하이퍼클래스 인보이스를 사용 |
| 데스크톱 앱과 PWA 생성 | 아직 없음 |
| 빌더 화면 언어 | 영어 |

Client App Builder는 지원되는 하이퍼클래스 기능 위에 경험을 만드는 도구예요. 범용 백엔드 개발 환경은 아니에요.

## 13. 자주 묻는 질문

### Client App Builder를 쓰려면 코딩 경험이 필요한가요?

아니요. 원하는 경험을 일상적인 말로 설명하면 AI가 만들어 줘요. 이후에도 대화와 사용할 수 있는 커스터마이징 도구로 앱을 계속 다듬을 수 있어요.

### 기존 하이퍼클래스 코스와 커뮤니티를 그대로 쓸 수 있나요?

네. Client App Builder는 코스, 커뮤니티, **공유된 파일**, 예약, 멤버 계정 등 지원되는 클라이언트 포탈 기능과 연동돼요.

### 웹 앱과 모바일 앱을 둘 다 만들 수 있나요?

네. 같은 서브 계정에서 두 종류를 모두 만들 수 있어요. 단, 합쳐서 5개까지만 만들 수 있고, 앱마다 웹이나 모바일 중 하나로 만들어야 해요.

### 웹 앱을 나중에 모바일 앱으로 바꿀 수 있나요?

아니요. 앱 종류는 만든 뒤에 바꿀 수 없어요. 다른 플랫폼이 필요하면 앱을 따로 만들어야 해요.

### 내 도메인을 쓸 수 있나요?

웹 앱에서는 쓸 수 있어요. 도메인 요건을 충족하면 앱 하나에 사용자 지정 도메인을 최대 10개까지 연결할 수 있어요.

### 앱을 Apple App Store나 Google Play에 게시할 수 있나요?

지금은 할 수 없어요. Android APK 생성은 지원하지만, 앱 스토어에 직접 게시하는 기능과 iOS 앱 생성은 아직 지원되지 않아요.

### 게시한 뒤에도 수정할 수 있나요?

네. 프로젝트를 계속 편집할 수 있고, 웹 앱은 변경 사항을 반영해 다시 게시할 수 있어요.

모바일 앱은 시작 방식에 따라 달라요. **ClientPortal Standard**는 일부 변경 사항을 설치된 앱에 게시할 수 있어요. **Describe It Instead**에서 AI가 새로 만든 화면은 APK를 다시 빌드해야 하는데, 이 기능은 아직 없어요.

### 멤버가 앱에서 정보를 제출할 수 있나요?

네. 사용자 지정 객체를 쓰면 지원되는 폼과 레코드 기반 경험을 만들 수 있고, 제출된 정보는 하이퍼클래스 CRM에 저장돼요.

### 앱에 결제를 넣을 수 있나요?

지원되는 웹 앱에서는 하이퍼클래스 인보이스 기반 결제 액션을 쓸 수 있어요. 사용자 지정 장바구니, 쿠폰, 독립 체크아웃 시스템은 현재 지원되지 않아요.

### 외부 AI 코딩 도구를 쓸 수 있나요?

네. 지원되는 MCP 연동으로 호환되는 외부 AI 도구가 웹 앱 프로젝트를 작업할 수 있어요. 게시는 반드시 Client App Builder에서 해야 해요.

### AI 빌드가 멈추거나 실패하면 어떻게 하나요?

빌드 상태나 오류 내용을 확인한 뒤, 프롬프트를 한 번 더 보내 이어서 진행하거나 문제를 고치도록 요청하세요.

빌드가 중단되면 빌더가 새 메시지로 이어서 진행할 수 있는 옵션을 보여 줘요. 모바일 빌드 점검에서는 문제가 생긴 파일과 위치를 알려 줄 수도 있어요.

### 미리보기가 느리게 열려요.

한동안 쓰지 않으면 미리보기가 일시 중지될 수 있어요. 빌더로 돌아오면 미리보기 환경이 다시 시작돼요. 게시된 앱에는 영향이 없어요.

### 삭제한 앱을 복원할 수 있나요?

삭제한 앱은 현재 Client App Builder 화면에서 복원할 수 없어요. 삭제하기 전에 더 이상 필요하지 않은지 꼭 확인하세요.
