# 연락처에서 커뮤니티 그룹 접근 권한 부여하기

클라이언트 포탈의 **연락처** 섹션에서 **커뮤니티 그룹**과 코스 오퍼를 바로 보고 관리하는 방법을 안내해요. 연락처를 정리하고, 오퍼를 지정하고, 비밀번호를 재설정할 때 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/qG_VYO7Ta9c?&wmode=opaque)

## 개요

**연락처** 섹션에서 **커뮤니티 그룹**과 코스 오퍼를 직접 보고 관리할 수 있어요. 연락처 정리, 오퍼 관리, 비밀번호 재설정을 한 곳에서 처리할 수 있어서 편리해요.

## 주요 기능

### 1. 연락처에 오퍼 바로 추가하기

- **연락처** 페이지에서 연락처마다 코스나 커뮤니티 그룹 같은 오퍼를 지정할 수 있어요. 페이지를 벗어나지 않고 딜, 프로모션, 코스 등록을 관리할 수 있어서 시간이 절약돼요.

### 2. 그룹 관리

- **연락처** 페이지에서 연락처를 알맞은 **커뮤니티 그룹**에 바로 추가할 수 있어요. 타깃 캠페인을 위해 대상을 나누거나 커뮤니티 그룹을 관리할 때 한곳에서 처리할 수 있어요.

### 3. 사용자 비밀번호 관리

- 관리자는 **연락처** 페이지에서 비밀번호를 직접 관리할 수 있어요. 아래 두 가지 중에서 고르세요.

  - 연락처의 새 비밀번호 설정하기

  - 사용자에게 비밀번호 재설정 링크 보내기

  계정 복구와 보안 관리가 더 빠르고 쉬워져요.

## 단계별 안내

### 1. 연락처로 이동하기

1. 클라이언트 포탈 안의 **연락처** 섹션으로 이동해요.
2. 관리할 연락처를 선택해요.

### 2. 클라이언트 포탈 또는 코스 확인하기

- 해당 위치(location)의 설정에 따라 보이는 섹션이 달라요.

  - 코스를 켜 둔 경우에는 **코스** 섹션이 나타나고, **클라이언트 포탈** 섹션은 보이지 않아요.

  - 클라이언트 포탈을 켜 둔 경우에는 **커뮤니티 그룹**을 포함한 **클라이언트 포탈** 섹션이 보여요.

### 3. 오퍼 지정하기

1. 연락처를 선택하면 오퍼(코스 또는 커뮤니티 그룹)를 지정하는 옵션이 보여요.
2. 사용 가능한 오퍼 목록에서 지정할 항목을 선택해요.
3. 변경 사항을 확인해요.

### 4. 그룹 관리하기

1. **커뮤니티 그룹** 옵션에서 선택한 연락처를 알맞은 그룹에 추가해요.

이렇게 하면 타깃 캠페인이나 그룹별 알림처럼 목적에 따라 커뮤니티 분류별로 연락처를 쉽게 관리할 수 있어요.

### 5. 비밀번호 관리하기

**연락처** 페이지에서 아래 중 하나를 선택할 수 있어요.

- **Set a new password**(새 비밀번호 설정): 연락처의 비밀번호를 직접 바꿔요.
- **Send a reset password link**(비밀번호 재설정 링크 보내기): 사용자에게 비밀번호 재설정 링크를 이메일로 보내요. 사용자는 이 링크로 안전하게 비밀번호를 다시 설정할 수 있어요.

{% hint style="info" %}
- 특정 위치에서 코스를 켜 두면 **연락처** 페이지에 **클라이언트 포탈** 대신 **코스** 섹션이 표시돼요.
- 클라이언트 포탈을 켜 두면 **연락처** 페이지에 **클라이언트 포탈** 섹션이 표시되고, 여기에 커뮤니티 그룹이 포함되어 관리하기 쉬워요.
{% endhint %}

```
연락처를 통해 부여한 그룹 접근 권한은 그룹 가입을 위한 추가 질문이나 그룹 결제 요구 사항을 건너뛰어요.
즉, 멤버는 그룹에 바로 접근할 수 있어요.
