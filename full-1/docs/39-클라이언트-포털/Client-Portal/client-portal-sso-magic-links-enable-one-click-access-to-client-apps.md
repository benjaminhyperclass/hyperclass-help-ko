# 클라이언트 포탈 SSO 매직 링크로 앱에 한 번에 접속하기

SSO(Single Sign-On) 매직 링크를 만들어서, 클라이언트가 로그인 정보 없이 **코스**, **커뮤니티**, **제휴** 같은 클라이언트 포탈 앱에 바로 들어가게 하는 방법을 안내해요. 이 링크를 클라이언트 포탈의 사용자 정의 메뉴 항목으로 넣고, 누가 볼 수 있는지 정하는 방법도 함께 알아봐요.

---

# SSO 매직 링크란?

SSO 매직 링크는 인증 정보가 담긴 고유 URL이에요. 이 링크를 쓰면 로그인 정보를 입력하지 않고도 클라이언트 포탈 앱에 바로 들어갈 수 있어요. 클라이언트가 자신에게 발급된 링크를 클릭하면 바로 로그인되고, 코스 대시보드·커뮤니티 영역·제휴 포털 등 해당 앱으로 이동해요.

링크는 앱별, 연락처별로 만들어져요. 그래서 각 사용자는 자신에게 허용된 포탈 화면에만 안전하게 접속해요.

---

## SSO 매직 링크의 장점

SSO 매직 링크는 로그인 과정의 불편을 줄이고, 시간을 아끼고, 클라이언트 만족도를 높이도록 만들어졌어요.

- 원클릭 로그인: 아이디와 비밀번호를 입력하지 않아도 바로 접속해요.
- 빠른 온보딩: 클라이언트가 곧바로 앱을 쓰기 시작할 수 있어요.
- 지원 티켓 감소: 비밀번호 분실 같은 로그인 문제가 없어져요.
- 편리한 이동: 더 매끄럽고 직접적인 로그인 환경을 제공해요.
- 여러 앱을 한 번에: 코스 + 커뮤니티 + 제휴처럼 앱이 여러 개인 구성에 알맞아요.
- 참여도 향상: 접속이 쉬워서 다시 방문하고 계속 이용하게 돼요.

## 매직 링크 생성하고 사용하기

클라이언트 포탈 대시보드에서 매직 링크를 만들고, 연락처에게 공유하면 특정 앱에 바로 접속하게 할 수 있어요.

### 사이트 대시보드 열기

왼쪽 메뉴에서 **사이트** 탭을 클릭해 클라이언트 포탈 대시보드로 들어가세요. 여기서 클라이언트용 앱을 관리하고 안전한 로그인 환경을 만들 수 있어요.

![왼쪽 메뉴의 사이트 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050728644/original/QwcVGFD8E9HS47bLH5NfFM_Q8M_2iarrwg.png?1753961509)

### 클라이언트 포탈 열기

**사이트** 메뉴 상단의 **클라이언트 포탈** 드롭다운을 클릭하고 **대시보드**를 선택하세요. 매직 링크 생성, 앱 설정 같은 클라이언트 포탈 관리 도구를 쓸 수 있어요.

![클라이언트 포탈 드롭다운에서 대시보드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050728791/original/Cn3Kztkto9dJKAMAwRmhihuvouQy-fg6eA.png?1753961576)

### 매직 링크 '생성' 클릭

**작업** 패널에서 **매직 링크 생성** 옆의 **생성** 버튼을 클릭하세요. 특정 연락처와 앱을 위한 안전한 원클릭 로그인 링크를 만드는 과정이 시작돼요.

```
클라이언트 포탈에서 생성한 매직 링크는 15분 후 만료됩니다.

매직 링크를 생성하면 링크가 만료되기까지 남은 시간이 카운트다운 타이머로 표시됩니다.

현재 링크가 만료되면 매직 링크 생성 버튼을 다시 사용할 수 있어서 새 링크를 만들 수 있습니다.
```

![작업 패널의 매직 링크 생성 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729026/original/7RdLEyS0IepSQCqkcIAesQXxtNWZbxNEDQ.png?1753961741)

### 매직 링크 유형 선택

**매직 링크 유형 선택**에서 **사용자 지정 메뉴**를 고르세요. 클라이언트 포탈 탐색용으로 반복해서 쓸 수 있는 매직 링크가 만들어져요. 포탈 사이드바에 바로 넣기에 알맞은 유형이에요.

![매직 링크 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729114/original/RGZhCO315eahK9CuvUxUxDtq_a4R-kzBug.png?1753961860)

### 앱 선택

**앱 선택** 아래 드롭다운에서 매직 링크가 열 클라이언트 포탈 앱을 고르세요. **코스**, **제휴**, **커뮤니티** 중에서 선택할 수 있어요. 여기서 고른 앱이 링크를 눌렀을 때 도착하는 곳이 돼요.

![앱 선택 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729176/original/aiLwGjt_kEl898qQef_RT2IWNTZPIEWngQ.png?1753961925)

### 매직 링크 생성하기

앱을 골랐다면 **생성** 버튼을 클릭하세요. 삽입하거나 공유할 수 있는 안전한 원클릭 로그인 URL이 바로 만들어져요.

![생성 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729267/original/au6OxawdM0mQP0A4JztT_lqP5rWhywZ8jA.png?1753961997)

### 매직 링크 복사하기

링크가 만들어지면 복사 아이콘을 클릭해 클립보드에 저장하세요. 이제 이메일이나 사용자 정의 메뉴 항목 등 필요한 곳에 붙여 넣으면 클라이언트가 편하게 접속할 수 있어요.

![복사 아이콘으로 매직 링크 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729400/original/wtBufc4AaGmWKi4-RSAZuiwv5rXWxrPUYA.png?1753962096)

## 매직 링크를 사용자 정의 메뉴 링크로 쓰기

매직 링크를 클라이언트 포탈 안에 사용자 정의 메뉴 항목으로 넣으면 더 빠르게 접속할 수 있어요.

{% hint style="info" %}
이 설정은 에이전시 보기에서 하므로 에이전시 관리자만 쓸 수 있어요.
{% endhint %}

매직 링크를 메뉴 항목으로 추가하는 순서는 다음과 같아요.

### 에이전시 보기로 전환

서브 계정 대시보드에서 계정 이름 옆의 드롭다운을 클릭하고 **에이전시 보기로 전환**을 선택하세요. 모든 서브 계정에 적용되는 사용자 정의 메뉴 링크 같은 전체 설정을 관리할 수 있어요.

![에이전시 보기로 전환 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729573/original/I53tUsI43Rfc2aAhDAV7E0xPTKCJjsGNTA.png?1753962224)

### 에이전시 설정 열기

에이전시 보기로 들어왔다면, 왼쪽 사이드바 맨 아래로 스크롤해서 **설정**을 클릭하세요. 사용자 정의 메뉴 링크 추가를 포함해 플랫폼 전체 환경 설정을 하는 곳이에요.

![왼쪽 사이드바 아래쪽의 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729712/original/Ib3m497jMk0ErzzdxpRTbkeuQL7uFAVOWQ.png?1753962303)

### 사용자 정의 메뉴 링크로 이동

**설정** 패널에서 아래로 스크롤해 **사용자 정의 메뉴 링크**를 클릭하세요. 기존 메뉴 링크가 모두 표시되고, 에이전시와 서브 계정용 사용자 정의 링크를 관리하거나 새로 만들 수 있어요.

![설정 패널의 사용자 정의 메뉴 링크](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729770/original/ELclgWfbIwfzJREkp0sn_PEX1wPD45eQAA.png?1753962348)

### 새 사용자 정의 링크 만들기

**사용자 정의 메뉴 링크** 화면 오른쪽 위의 **+ Create New**(새로 만들기) 버튼을 클릭해 새 메뉴 링크를 만드세요.

![+ Create New 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050729905/original/8DQLlsuy97Bq7M99CoswTFmnP2JE1xa67g.png?1753962464)

### 링크 정보 입력

필수 항목을 입력하세요.

- **Link Icon**(링크 아이콘): 아이콘 식별자를 고르세요(예: vr-cardboard).
- **Link Title**(링크 제목): 메뉴 항목의 이름을 입력하세요(예: "Test Link").
- **URL**: 앞에서 만든 매직 링크 전체를 붙여 넣으세요.

![링크 아이콘, 제목, URL 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050730145/original/piM2e1feZmZTFZEULHCiFh41q6bfKfAMjg.png?1753962675)

### 링크 동작 선택

**링크 동작**에서 링크를 눌렀을 때 열리는 방식을 고르세요. 현재 창 안에 iFrame으로 임베드해서 보여 주거나, 새 탭에서 열거나, 같은 창에서 불러올 수 있어요.

![링크 동작 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050730280/original/_LgCu09DXrA4iiUykNgX9S05HBEMGKdZrQ.png?1753962777)

### 사이드바 표시 위치 설정

사용자 정의 메뉴 링크가 나타날 위치를 고르세요. 에이전시 사이드바, 서브 계정 사이드바, 또는 둘 다에 표시할 수 있어요. 사용자 수준별로 편하게 이동하도록 필요에 맞게 선택하세요.

![사이드바 표시 위치 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050730378/original/Ma9e_IcpAQK7K0zWOtuPS73yt9JGlSsYjQ.png?1753962848)

### 서브 계정 선택

사용자 정의 메뉴 링크를 서브 계정 한 곳 이상에 지정하세요. 선택한 계정만 탐색 사이드바에 이 링크가 표시돼요.

![서브 계정 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050730522/original/ZTeeKMtDLvg0tkkjFuVFqHLPFgGdWyQ72w.png?1753962931)

### 역할별 공개 범위 설정

사용자 역할에 따라 이 링크에 접근할 수 있는 사람을 정하세요. 관리자만 보게 하거나, 사용자만 보게 하거나, 지정한 서브 계정의 모든 사용자에게 보이게 할 수 있어요.

![역할별 공개 범위 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050730664/original/QOrfQw-iCiso42qnsJOC6pFc4K53DbNM_w.png?1753963033)

### 권한 허용하기(선택)

임베드한 콘텐츠에 필요하면 사용자 정의 메뉴 링크에 마이크와 카메라 접근 권한을 줄 수 있어요. 화상 회의나 녹화 도구에 알맞아요.

![마이크와 카메라 권한 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050730751/original/OAb5ZI1qj9mWMSnECaG1Q4p-IBdSUuUHiQ.png?1753963110)

### 메뉴 링크 저장

URL, 사이드바 표시 위치, 선택한 계정, 역할별 공개 범위, 필요한 권한까지 모두 설정했다면 **저장**을 클릭해 사용자 정의 메뉴 링크를 완성하세요. 지정한 사이드바에 매직 링크가 추가되고, 설정한 규칙에 따라 사용자가 쉽게 접속할 수 있어요.

![저장 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050730957/original/dJn2dDIJ31gpRR3O_Yci8ueDjFykuxWJFg.png?1753963266)

## 자주 묻는 질문

### 매직 링크는 모든 클라이언트 포탈 앱에서 쓸 수 있나요?
**코스**, **커뮤니티**, **제휴**에서 쓸 수 있어요.

### 매직 링크는 안전한가요?
네. 각 링크는 연락처와 앱마다 고유해서 꼭 필요한 접근 권한만 제공해요.

### 자동화나 이메일에서 매직 링크를 쓸 수 있나요?
네. 자동 발송 메시지, 온보딩 이메일, 사용자 지정 버튼에 링크를 넣을 수 있어요.

### 사용자가 먼저 포탈에 로그인해 있어야 하나요?
아니요. 매직 링크를 클릭하면 로그인되고 자동으로 해당 앱으로 이동해요.

### 매직 링크를 다시 생성할 수 있나요?
네. 생성 과정을 그대로 반복하면 새 링크가 만들어져요.
