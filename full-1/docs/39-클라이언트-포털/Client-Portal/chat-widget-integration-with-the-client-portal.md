# 클라이언트 포탈에 채팅 위젯 연결하기

클라이언트 포탈에 **채팅 위젯**을 연결하면 고객이 포탈 안에서 바로 실시간 지원을 받을 수 있어요. 클라이언트 포탈의 하위 앱마다 위젯을 켜고 끌 수 있어서, 필요한 곳에만 채팅 지원을 보여 줄 수 있어요.

## 클라이언트 포탈 채팅 위젯 연동이란?

하이퍼클래스 채팅 위젯 하나를 클라이언트 포탈에 연결하고, 어떤 하위 앱에 보여 줄지 직접 정하는 기능이에요. 코드를 삽입하거나 위젯을 여러 개 관리할 필요가 없어요. 이미 만들어 둔 위젯을 하나 고른 다음, **커뮤니티**, **코스**, **제휴**별로 표시 여부를 정하면 돼요. 대화는 다른 웹챗과 똑같이 하이퍼클래스 수신함으로 들어와요.

### 이 기능의 장점

- 실시간 지원: 고객이 **커뮤니티**, **코스**, **제휴**에서 작업하다가 탭을 옮기지 않고 바로 도움을 받을 수 있어요.
- 세밀한 제어: 비즈니스 목표에 맞게 위젯을 보여 줄 하위 앱을 직접 고를 수 있어요.
- 대화 통합 관리: 모든 채팅이 하이퍼클래스로 모여서 기록을 한곳에서 보고, 후속 응대와 리포팅도 더 빨라져요.
- 간편한 설정: 포탈에는 코드를 삽입하지 않아요. 클라이언트 포탈 설정 안에서 선택하면 끝나요.
- 참여도 향상: 제때 지원하면 코스 수료, 커뮤니티 참여, 제휴 성과를 높이는 데 도움이 돼요.

## 클라이언트 포탈에 채팅 위젯 설정하기

아래 순서대로 기존 채팅 위젯을 클라이언트 포탈에 연결하고, 위젯이 나타날 위치를 정해요.

1. 서브 계정에서 **멤버십 > 클라이언트 포탈 > 설정 > 채팅 위젯**으로 이동하세요.

   ![멤버십 > 클라이언트 포탈 > 설정 > 채팅 위젯으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051812720/original/7N256pP56TDZeXDqnNwXVmHUVPksxVk-8Q.gif?1755520196)
2. **채팅 위젯 선택** 드롭다운을 열고, 클라이언트 포탈 전체에서 쓸 채팅 위젯을 하나 고르세요.

   ![채팅 위젯 선택 드롭다운에서 위젯을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051812809/original/WEIcAZG_9ViPF6DNzRkIz-mO-CXJhrkOuw.gif?1755520233)
3. **페이지 선택**에서 **커뮤니티**, **코스**, **제휴**, **Home & Account settings**(홈 및 계정 설정)의 표시 여부를 필요에 맞게 켜거나 끄세요. 그런 다음 **설정 저장**을 클릭하세요.

   ![페이지 선택에서 표시 여부를 켜고 설정 저장을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051812893/original/JXb6KVrhrtGhbD20mf9CYbyYe_-TMOuI8A.gif?1755520261)
4. 클라이언트 포탈에서 위젯이 잘 보이는지 확인하세요.

   ![클라이언트 포탈에 채팅 위젯이 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051507159/original/XtEPYFRrnD7N2bRkyo774KcM85Pojs4-vw.png?1755077959)

{% hint style="info" %}
위젯의 모양이나 채널(라이브, SMS / 이메일, WhatsApp)을 바꾸려면 **사이트 > 채팅 위젯**에서 위젯을 직접 편집하세요. 그다음 클라이언트 포탈 페이지를 새로고침하면 변경 내용이 보여요.
{% endhint %}

## 하위 앱별 위젯 표시 설정

표시 설정을 이용하면 대상과 상황에 맞게 지원 방식을 조절할 수 있어요. 실시간 도움이 필요한 앱에서는 위젯을 켜 두고, 필요 없는 앱에서는 꺼 두세요.

- **커뮤니티**, **코스**, **제휴**의 표시 여부를 각각 따로 켜고 끌 수 있어요.
- 조합은 자유예요. 예를 들어 **코스**와 **제휴**는 켜고 **커뮤니티**는 끌 수 있어요.
- 변경 내용은 저장한 뒤에 적용돼요. 포탈 페이지를 새로고침해서 확인하세요.

## 사전 준비와 권한

나중에 "위젯이 안 보여요" 같은 문제가 생기지 않도록, 설정하기 전에 아래 내용을 먼저 확인하세요.

- 서브 계정에 채팅 위젯을 하나 이상 이미 만들어 두었어야 해요. 자세한 방법은 [채팅 위젯 시작하기](../../06-사이트/getting-started-with-chat-widget.md)와 [올인원 채팅 위젯 사용하기](../../06-사이트/채팅-위젯/how-to-use-the-all-in-one-chat-widget.md)를 참고하세요.
- 서브 계정에서 **클라이언트 포털 설정**에 접근할 수 있어야 해요.
- (선택) 채널별 요건을 갖춰야 해요. 예를 들어 위젯에서 WhatsApp을 쓰려면 WhatsApp 번호가 필요해요.

## 제한 사항과 요건

- 클라이언트 포탈에는 위젯 하나만: 클라이언트 포탈에는 채팅 위젯을 하나만 선택할 수 있어요.
- 하위 앱별 표시 여부만 설정 가능: 하위 앱마다 위젯을 보이거나 숨길 수는 있지만, 하위 앱마다 서로 다른 위젯을 지정할 수는 없어요.
- 위젯 내용은 전체에 공통 적용: 선택한 위젯의 설정(브랜딩, 인사말, 채널)은 포탈 안에서 위젯이 나타나는 모든 곳에 똑같이 적용돼요.
- 웹사이트와 클라이언트 포탈은 달라요: 웹사이트·퍼널에서 쓰는 다중 위젯 설정은 클라이언트 포탈 안에서는 적용되지 않아요.

## 자주 묻는 질문

### 하위 앱마다 다른 위젯을 지정할 수 있나요?
아직은 안 돼요. 클라이언트 포탈에서는 위젯을 하나만 선택할 수 있고, 하위 앱별로는 표시 여부만 정할 수 있어요.

### 클라이언트 포탈에서 위젯을 쓰려면 코드를 붙여 넣어야 하나요?
아니요. **클라이언트 포탈 > 설정 > 채팅 위젯**에서 위젯을 선택하면 돼요. 포탈에는 삽입 코드가 필요 없어요.

### 하위 앱 안의 모든 페이지에 위젯이 나타나나요?
해당 하위 앱에서 지원하는 화면에 나타나요. 위젯이 보이지 않으면 페이지를 새로고침하고, 해당 하위 앱의 표시 설정이 켜져 있는지 확인하세요.

### 공개 웹사이트나 퍼널에서는 여전히 위젯을 여러 개 쓸 수 있나요?
네, 웹사이트와 퍼널에서는 다중 위젯 설정을 쓸 수 있어요. 클라이언트 포탈 안에서는 적용되지 않아요.

### 위젯의 인사말, 색상, 채널은 어떻게 바꾸나요?
**사이트 > 채팅 위젯**에서 선택한 위젯을 편집하세요. 저장한 뒤 포탈을 새로고침하면 변경 내용이 클라이언트 포탈에 반영돼요.

### WhatsApp은 추가 설정이 필요한가요?
네. 위젯에서 WhatsApp 채널을 켜기 전에 WhatsApp 번호를 올바르게 설정해 두어야 해요.
