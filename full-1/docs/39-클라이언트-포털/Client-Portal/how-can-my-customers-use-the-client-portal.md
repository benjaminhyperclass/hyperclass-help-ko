# 고객의 클라이언트 포탈 가입과 로그인

**클라이언트 포탈**은 고객이 내 비즈니스와 쉽고 편하게 소통하는 한 곳짜리 디지털 공간이에요. 이 글에서는 고객이 클라이언트 포탈에 가입하고 로그인하는 과정과, 가입 후 이용할 수 있는 기능을 안내해요.

## 클라이언트 포탈이란?

클라이언트 포탈은 고객이 내 비즈니스와 소통하고 여러 기능을 이용하는 통합 공간이에요. 고객은 나와 주고받은 지난 이력과 현재 진행 중인 내용을 한눈에 볼 수 있어요. 그래서 더 개인화되고 세련된 경험을 줄 수 있어요.

고객은 클라이언트 포탈에서 다음을 할 수 있어요.

- 제휴 수수료와 지급 내역 확인
- 멤버십 코스 이용
- 커뮤니티 그룹 참여

## 가입 절차

### 1단계: 클라이언트 포탈 가입이 필요한 고객

고객이 하위 앱(멤버십 코스, **제휴 관리자**, **커뮤니티 > 예정**)에 접근할 수 없을 때만 클라이언트 포탈에 가입하면 돼요.

이미 하위 앱 접근 권한을 받은 적이 있다면 가입 없이 바로 클라이언트 포탈에 로그인할 수 있어요. 멤버십 포털에 로그인할 때 쓰는 계정 정보를 그대로 쓰면 돼요.

{% hint style="info" %}
여러 번 가입하지 않아도 되도록 만든 방식이에요.
{% endhint %}

### 2단계: 계정 생성과 CRM 제한

**비즈니스 프로필** 설정에서 중복 연락처를 허용하면, 고객은 같은 이메일 주소로 여러 번 가입할 수 있어요. 가입할 때마다 별도의 사용자 계정이 만들어져요.

![클라이언트 포탈 가입 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001373478/original/9hNOZyipTNiZgda5grayaRcSRi6cKKShRQ.png?1687251157)

CRM에서 중복 연락처를 허용하지 않으면, 같은 이메일로는 한 번만 가입할 수 있어요. 데이터가 꼬이거나 중복되지 않도록, 이메일 하나에 사용자 계정이 여러 개 만들어지지 않게 막아요.

{% hint style="info" %}
CRM 설정에 따라 클라이언트 포탈 계정 생성이 어떻게 달라지는지 미리 확인해 두세요.
{% endhint %}

### 3단계: 가입하기

클라이언트 포탈에 가입하려면 고객이 전체 이름과 이메일 주소를 입력하고 비밀번호를 정해야 해요.

![이름, 이메일, 비밀번호를 입력하는 가입 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001373833/original/fPDRPuSLl9A0kz0JWAbtiEk7iL5RhzGC2A.png?1687251362)

가입 정보를 제출하면 입력한 이메일 주소로 인증 코드가 발송돼요.

![이메일로 받은 인증 코드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001374081/original/aaHb9tejxIo7aWCIYopHrqMB9GvyQsRuzA.png?1687251486)

{% hint style="info" %}
고객에게 이메일(스팸·정크 메일함 포함)에서 인증 코드를 확인하도록 안내하세요. 인증 코드는 15분 후에 만료돼요.
{% endhint %}

### 4단계: 계정 인증

고객은 이메일로 받은 인증 코드를 입력해 계정을 인증해야 해요.

![인증 코드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001374201/original/utZ765KAlXfGD_vDjCxGKwD3NWTdFM2dZA.png?1687251560)

인증이 끝나면 가입할 때 정한 비밀번호로 클라이언트 포탈에 로그인할 수 있어요.

{% hint style="info" %}
인증 과정은 고객 계정의 보안과 진위를 지키는 데 꼭 필요해요.
{% endhint %}

{% hint style="info" %}
팁: 고객에게 로그인 정보를 안전하게 보관하고 다른 사람과 공유하지 않도록 안내하세요.
{% endhint %}

## 로그인

고객은 두 가지 방법 중 하나로 클라이언트 포탈에 로그인할 수 있어요.

- 비밀번호 로그인: 이미 비밀번호가 있는 고객은 비밀번호로 바로 로그인해요.
- **이메일 검증**: 가입한 이메일 주소로 받은 보안 코드로 본인을 확인해요. 이 방법을 선택하면 고유한 보안 코드가 담긴 이메일이 고객에게 발송돼요. 코드에는 유효 시간이 있어요. 고객이 로그인 페이지에서 이 코드를 입력하면 본인 확인이 끝나고 클라이언트 포탈에 들어갈 수 있어요.

![로그인 방법 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001375704/original/s_cKEBsV4eBao4Hh16Msq5lQ27rz8Lk6Ig.png?1687252386)

같은 이메일 ID에 계정이 여러 개 연결되어 있으면, 올바른 계정으로 들어가도록 로그인할 때 해당 이메일에 연결된 사용자 계정 목록이 나와요. 그중에서 계정을 선택하면 돼요. 이렇게 하면 헷갈리지 않고 맞는 계정에 접속할 수 있어요.

![여러 계정 중 하나를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001375932/original/BTBILfORaHuC87gK_T-gzjp6Zgwu05wBzw.png?1687252474)

{% hint style="info" %}
한 이메일에 계정이 여러 개 연결되어 있다면, 선택한 계정이 맞는지 한 번 더 확인하세요.
{% endhint %}

## 클라이언트 포탈 이용하기

클라이언트 포탈은 리드와 고객이 여러 하위 앱을 통해 내 비즈니스와 소통하는 통합 공간이에요. 멤버십 코스 이용, 커뮤니티 그룹 참여, 제휴 관리를 할 수 있어요.

이 서비스를 모두 이용하려면 리드와 고객이 프로필 정보를 입력해야 해요. 이 정보는 개인별 경험을 맞추고, 모든 하위 앱이 매끄럽게 동작하도록 도와줘요. 프로필에는 이름, 이메일 주소, 연락처 정보, 선호 사항 등을 입력해요.

![프로필 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001376972/original/YNjfygs1SGjPQydn2zbpVYnEB7RV7O72sw.png?1687252933)

{% hint style="info" %}
새로 만든 서브 계정에서는 아직 클라이언트 포탈의 매직 링크를 쓸 수 없어요. 이 기능은 개발 중이며 곧 지원될 예정이에요. 기존 서브 계정에서는 지금처럼 매직 링크를 계속 쓸 수 있어요.
{% endhint %}

프로필을 완성하고 하위 앱에 접근할 수 있게 되면, 리드와 고객은 앱 사이를 자유롭게 오가며 내 비즈니스를 이용할 수 있어요. 상단 바 오른쪽 위에 있는 앱 전환 메뉴를 쓰면 돼요. 앱 전환 메뉴를 클릭하면 이용할 수 있는 앱 목록이 드롭다운으로 나타나고, 원하는 앱을 한 번 클릭해 이동할 수 있어요.

![상단 바 오른쪽 위의 앱 전환 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001376996/original/8yXuJSi747gVbqdAqfb3TrfovvN1-jxo7Q.png?1687252946)

{% hint style="info" %}
- 최상의 사용 경험과 모든 앱의 원활한 동작을 위해 프로필 정보는 꼭 입력해야 해요.
- 프로필 정보는 모든 하위 앱에서의 이용에 영향을 주므로 항상 최신 상태로 정확하게 유지하세요.
- 앱 사이를 빠르고 쉽게 오가려면 앱 전환 메뉴를 활용하세요.
{% endhint %}

## 자주 묻는 질문

### 계정이 여러 개인 고객은 클라이언트 포탈에서 계정을 바꿀 수 있나요?

같은 이메일에 계정이 여러 개 연결되어 있으면, 로그인할 때 들어갈 계정을 선택하라는 안내가 나와요. 이후 필요에 따라 계정을 바꿀 수 있어요.

### 고객이 프로필 정보를 꼭 입력해야 하나요?

네, 꼭 입력해야 해요. 프로필 정보는 모든 하위 앱에서 쓰이기 때문이에요. 입력해 두면 모든 플랫폼에서 매끄럽고 개인에게 맞춘 경험을 줄 수 있어요.

### 고객이 클라이언트 포탈에서 멤버십 코스, 커뮤니티 그룹, 제휴 같은 하위 앱으로 바로 이동할 수 있나요?

네, 클라이언트 포탈의 상단 바 오른쪽 위에 앱 전환 메뉴가 있어요. 이 메뉴로 여러 앱 사이를 쉽게 오갈 수 있어요.

![앱 전환 메뉴로 하위 앱 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001379836/original/dCtTYHoe0wWFuJHRzfT-pWom77wNhsW55Q.png?1687254410)

### 고객이 비밀번호를 잊어버렸어요. 그래도 클라이언트 포탈에 들어갈 수 있나요?

네, 이메일로 받은 보안 코드로 계정에 들어갈 수 있어요. 이 방법을 쓰면 비밀번호를 기억하지 못해도 로그인할 수 있어요.
