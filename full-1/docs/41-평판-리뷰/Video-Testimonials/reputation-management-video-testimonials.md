# 평판 관리 — 비디오 후기로 고객 영상 리뷰 받기

[동영상](https://www.youtube.com/embed/VJj-cvYVlGs?&wmode=opaque)

**비디오 후기**(Video Testimonials)를 쓰면 고객이 직접 찍은 영상 리뷰를 모아 웹사이트에 게시할 수 있어요. 모두 하이퍼클래스 안에서 할 수 있어요. 브랜드에 맞춘 비디오 수집기를 만들고, 이메일·SMS·WhatsApp으로 요청을 보내고, 응답을 관리하고, 리뷰 위젯에 보여 주세요. 이 문서에서는 설정, 발송, 관리, 노출 방법을 안내해요.

---

## 평판 관리의 비디오 후기란?

**비디오 후기**는 **평판 관리**(Reputation) 안의 기능이에요. 공유할 수 있는 브랜드 맞춤 "비디오 수집기"로 고객의 영상 리뷰를 모아요. 연락처는 컴퓨터나 모바일에서 앱 설치 없이 영상을 녹화하거나 업로드할 수 있어요. 모인 영상은 내부에서 검토한 뒤 리뷰 위젯으로 사이트에 보여 줄 수 있어요.

---

## 비디오 후기의 장점

- 진정성: 실제 얼굴과 목소리는 글로만 된 리뷰보다 훨씬 빠르게 신뢰를 줘요.
- 간편한 수집: 연락처가 최신 기기라면 어디서든 앱 없이 녹화하거나 업로드할 수 있어요.
- 브랜드 관리: 수집기의 로고, 배경, 텍스트, 강조, 버튼 색상을 브랜드 이미지에 맞게 바꿀 수 있어요.
- 한곳에서 관리: 제출된 비디오 후기를 검토하고, 위젯 노출 여부를 **응답** 탭에서 관리할 수 있어요.
- 유연한 노출: 리뷰 위젯에 비디오 후기를 보여 주고, 수집기별로 걸러 내고, 후기마다 공개 여부를 정할 수 있어요.
- 쉬운 노출: 지금 쓰는 리뷰 위젯에 영상을 추가할 수 있어요. 레이아웃 옵션과 수집기별 필터도 쓸 수 있어요.
- 길이 제한: 영상은 파일이 가볍고 끝까지 보기 좋도록 한 편당 2분 30초까지만 가능해요.

## 비디오 수집기 만들기

아래 단계에 따라 비디오 수집기를 만들어요.

### 1단계: 비디오 수집기 만들기

1. 서브 계정에 로그인하세요.
2. **평판 관리 > 비디오 후기**로 이동하세요.

   ![평판 관리의 비디오 후기 메뉴](https://jumpshare.com/share/VqgfyloSbiBdNL11RcZz+/Screen+Shot+2025-11-27+at+7.32.45+PM.png)
3. **+ 수집기 만들기** 또는 **수집기 만들기** 버튼을 클릭하세요.

   ![수집기 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155059385390/original/a5Bwg2mIkgGRZqYNdJCy7NyAU9PY0NlKMQ.jpeg?1764252759)

### 2단계: 웰컴 페이지 설정

1. **공개 수집기 제목**을 입력하세요.

   ![공개 수집기 제목 입력 화면](https://jumpshare.com/share/fwLsUTx7DFKNM8vu61q5+/Screen+Shot+2025-11-27+at+7.50.19+PM.png)
2. **대변인 이미지**를 켜거나 끄세요. 회사의 친근한 얼굴을 보여 주면 수집기가 더 가깝게 느껴져요. 본인이나 동료 누구든 괜찮아요.
3. **대변인** 정보를 입력하세요.

   ![대변인 정보 입력 화면](https://jumpshare.com/share/hX0EPT7tDzFcttU03uqA+/Screen+Shot+2025-11-27+at+7.51.26+PM.png)
4. **How it Works**(작동 방식) 섹션을 입력하세요. 전체 진행 방식을 짧게 설명하는 글이에요.

   ![작동 방식 섹션 입력 화면](https://jumpshare.com/share/1Ch6ZE8LQPzaONtWHEbk+/Screen+Shot+2025-11-27+at+7.52.46+PM.png)
5. **환영 메시지**를 입력하세요. 수집기 대변인이 전하는 짧은 메시지예요.

   ![환영 메시지 입력 화면](https://jumpshare.com/share/fLTUjohlT2TIdYQTrNBG+/Screen+Shot+2025-11-27+at+7.53.47+PM.png)

### 3단계: 질문 페이지 설정

1. 질문을 최대 3개까지 추가하세요.
2. 질문 순서를 정해 안내 흐름을 만드세요.

   ![질문 페이지 설정 화면](https://jumpshare.com/share/hnMRa0ybKAaOGKTR3hkM+/Screen+Shot+2025-11-27+at+8.05.48+PM.png)

### 4단계: 어트리뷰션 페이지 설정

질문이 끝나면 응답자에게 본인 정보를 입력하도록 안내해요. 맞춤 링크로 정보가 미리 채워져 있으면 그 정보를 확인하게 해요.

1. **헤드라인**을 입력하세요.
2. **메시지**를 입력하세요.

   ![어트리뷰션 페이지 설정 화면](https://jumpshare.com/share/8W7duvySYxPLj8eVrKm8+/Screen+Shot+2025-11-27+at+8.09.19+PM.png)

### 5단계: 감사 페이지 설정

1. **헤드라인**을 입력하세요.
2. **메시지**를 입력하세요.
3. **대변인 이메일**을 입력하세요.

   ![감사 페이지 설정 화면](https://jumpshare.com/share/z9pJtDx1qCqfEebwiBkR+/Screen+Shot+2025-11-27+at+8.14.31+PM.png)

### 6단계: 로고와 색상 설정

1. **로고 추가**를 활성화하고 로고를 추가하세요.
2. **로고 뒤 흰색 배경**을 활성화하거나 비활성화하세요.
3. **배경**, **Text**(텍스트), **Secondary Text**(보조 텍스트), **Accent**(강조), **버튼 색상**을 설정하세요.
4. **저장**을 클릭하세요.

   ![로고와 색상 설정 화면](https://jumpshare.com/share/CXsWO5GWj4Qt9oEbecNf+/Screen+Shot+2025-11-27+at+8.25.04+PM.png)
5. **미리보기**를 클릭하면 고객이 수집기를 열어 영상 리뷰를 녹화할 때 보게 될 화면을 그대로 확인할 수 있어요.

   ![수집기 미리보기 화면](https://jumpshare.com/share/cSGrkW7hCcD6hnMiwCoT+/Screen+Shot+2025-11-27+at+9.00.42+PM.png)

## 비디오 후기 공유하고 관리하기

### 1. 링크로 공유하기

1. **비디오 후기** 화면의 **Collectors**(수집기) 탭에서 해당 수집기를 찾으세요.
2. **링크 복사**를 클릭한 뒤 이메일, 채팅, 소셜 미디어, QR 코드 등으로 공유하세요.

   ![수집기 링크 복사 동작 화면](https://jumpshare.com/share/0XyIYWbhUeZvpNnjiIR4+/GIF+Recording+2025-11-27+at+9.41.51+PM.gif)

### 2. 영상 리뷰 요청 보내기 (이메일/SMS/WhatsApp)

1. **리뷰 요청 보내기**를 클릭하거나, 수집기의 공유 아이콘을 클릭하세요.

   ![리뷰 요청 보내기 버튼](https://jumpshare.com/share/T9DURcaVubhhe1bwin4T+/Screen+Shot+2025-11-27+at+9.43.15+PM.png)
2. **연락처 선택**에서 연락처를 고르세요.
3. **이메일**, SMS, WhatsApp 중 하나를 선택하세요.
4. **Override Video Link**(동영상 링크 덮어쓰기)에서 포함할 수집기를 선택하세요.
5. 기본 이메일/SMS/WhatsApp 템플릿이나 미리 만들어 둔 사용자 지정 템플릿을 선택하세요.
6. **리뷰 요청 보내기**를 클릭하세요.

   ![리뷰 요청 보내기 설정 화면](https://jumpshare.com/share/lWRSNbGGsMwhqaikRmEv+/Screen+Shot+2025-11-27+at+9.51.38+PM.png)

## 응답 관리하고 다운로드하기

제출된 비디오 후기를 검토하고 관리하려면 **평판 관리 > 비디오 후기 > 응답**으로 이동하세요.

**응답** 페이지에서는 다음을 할 수 있어요.

- 아직 검토하지 않은 새 후기를 확인해요.
- 후기가 지금 리뷰 위젯에 표시되고 있는지 확인해요.
- 후기마다 위젯에 표시하거나 숨겨요.
- 제출된 항목을 열어 영상을 확인해요.
- 원본 영상 파일을 다운로드해요.

### 후기 노출 관리

**응답** 페이지의 노출 설정으로 비디오 후기 하나하나를 리뷰 위젯에 표시할지 정할 수 있어요.

위젯 설정을 매번 고치지 않아도 후기를 표시하거나 숨길 수 있어요.

![후기 노출 설정 동작 화면](https://jumpshare.com/share/5MaLuBcvjHZ4kGMdJ2n5+/GIF+Recording+2025-11-27+at+9.56.04+PM.gif)

## 리뷰 위젯에 영상 표시하기

1. **평판 관리 > 위젯**으로 이동하세요.
2. 리뷰 위젯을 **만들기**하거나 **편집**하세요.
3. **리뷰 유형**을 **비디오 후기**로 선택하세요.
4. **비디오 후기 출처**에서 보여 줄 수집기를 고르세요.
5. **위젯 유형**, **리뷰 수**, **동영상 링크 덮어쓰기**(Override Video Link)를 정하고, **Powered by** 표시를 활성화하거나 비활성화하세요.
6. **저장**을 클릭하세요.

   ![리뷰 위젯에 비디오 후기 설정 화면](https://jumpshare.com/share/MajrGgax40XeaxAopVog+/GIF+Recording+2025-11-27+at+9.58.58+PM.gif)

### 새 비디오 후기 게시 방식 선택

리뷰 위젯에서 비디오 후기를 설정할 때 새로 제출된 후기를 어떻게 처리할지 고를 수 있어요.

- **새 비디오 후기 자동 게시**: 새 비디오 후기가 위젯에 자동으로 나타나요. 기본값이에요.
- **게시 전 수동 승인 필요**: 새 비디오 후기를 검토해 승인해야 위젯에 나타나요.

새 후기가 자동으로 보여도 괜찮다면 자동 게시를 쓰세요. 팀이 후기를 하나씩 검토한 뒤 공개해야 한다면 수동 승인을 쓰세요.

## 자주 묻는 질문

### 영상을 녹화하려면 고객이 앱을 설치해야 하나요?

아니요. 수집기 링크로 컴퓨터나 모바일에서 바로 녹화하거나 업로드할 수 있어요.

### 영상은 최대 몇 분까지 가능한가요?

제출 한 건당 최대 2분 30초예요.

### 수집기에 질문을 몇 개까지 추가할 수 있나요?

질문 단계에서 최대 3개까지 추가할 수 있어요.

### 수집기를 여러 개 만들 수 있나요?

네. 서브 계정마다 수집기를 제한 없이 만들 수 있고, 기존 수집기를 복제할 수도 있어요.

### 제출된 영상은 어디에서 볼 수 있나요?

**평판 관리 > 비디오 후기 > 응답**으로 이동하면 영상을 보고 다운로드할 수 있어요.

### 사이트에 특정 영상만 보여 줄 수 있나요?

네. 리뷰 위젯의 수집기별 필터를 쓰면 특정 비디오 수집기의 후기만 보여 줄 수 있어요. **평판 관리 > 비디오 후기 > 응답**에서 비디오 후기를 하나씩 표시하거나 숨길 수도 있어요.

### 수집기 링크는 어떤 채널로 보낼 수 있나요?

**리뷰 요청 보내기**를 통해 이메일, SMS, WhatsApp으로 보낼 수 있어요.
