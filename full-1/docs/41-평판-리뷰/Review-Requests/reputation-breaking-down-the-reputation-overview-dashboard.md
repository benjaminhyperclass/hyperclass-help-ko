# 평판 관리 개요 대시보드 살펴보기

평판 관리 개요 대시보드의 각 섹션이 무엇을 보여 주는지 설명해요. 서브 계정의 **평판 관리 > 개요** 탭에서 볼 수 있어요.

![평판 관리 개요 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48253416166/original/rDjZx_HPxxQ4-dgJfa2zjALHki7yVAaUgQ.png?1664285895)

## 시작하기 전에 알아두세요

각 섹션의 점 3개를 클릭하면 조회할 기간을 필터링할 수 있어요.

![점 3개를 클릭해 기간을 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48253245654/original/sGDDdeNj8bzv-P4kXrnt6gmULy087MhanA.gif?1664222118)

## Invite Goals(초대 목표)

**Invite Goals**(초대 목표)는 미리 정해진 단계별 수치예요. 직접 편집할 수 없고, 목표를 달성할 때마다 다음 수치로 올라가요.

## 받은 리뷰

**받은 리뷰**에 표시되는 리뷰 수는 선택한 기간을 기준으로 해요. 시스템이 Google과 Facebook에서 새 리뷰와 이전 리뷰를 모두 가져와요. 리뷰 출처는 이 타일의 왼쪽 아래에 표시돼요.

![받은 리뷰 타일](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48253431991/original/8DXMtoP951Om23lbtIjF5cxU7_q38RaFjQ.png?1664288803)

Google이나 Facebook 리뷰를 가져오려면 서브 계정의 **설정 > 연동**에서 각 채널을 먼저 연동해 두세요.

---

## 온라인 리스팅 (해당하는 경우)

Yext가 활성화되어 있고 해당 위치가 구독 중이면 **온라인 리스팅** 섹션에 등록 정보 개요가 표시돼요. 자세한 내용을 보려면 오른쪽 위의 **View Status**(상태 보기)를 클릭하세요.

![온라인 리스팅 섹션과 View Status](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48253432156/original/CpZ4BwKrPj6s8eroG7FFJf3XeujTecu05A.png?1664288834)

서브 계정의 등록 정보를 관리하려면 **등록 정보 관리** 버튼을 클릭하세요. **등록 정보 관리** 옵션은 에이전시 사용자에게만 보여요.

![등록 정보 관리 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48253248037/original/MLwLJ3LakKaR8dCMPUgB75FFB0_LOLtJ0g.png?1664223208)

## Sentiment(감성)

**Sentiment**(감성)를 보면 고객이 내 비즈니스나 서비스를 어떻게 느끼는지 알 수 있어요. 하이퍼클래스는 대규모 언어 모델을 사용해 글로 작성된 리뷰를 긍정, 중립, 부정으로 분류해요.

글 없이 별점만 남긴 리뷰는 별점으로 판단해요.

- 별 4개 또는 5개: 긍정
- 별 3개: 중립
- 별 1개 또는 2개: 부정

이전 리뷰도 다시 점수를 매겼어요. 그래서 감성 추세, 히트맵, 세부 분석에는 과거 리뷰와 새 리뷰 모두 개선된 점수가 반영돼요.

![감성 분석 타일](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48253432501/original/C2wZteezDfJ2eK7IANtCwI7whaouxX0xlQ.png?1664288901)

**초대 트렌드**는 선택한 기간에 서브 계정이 SMS와 이메일 채널로 보낸 리뷰 요청의 총수를 보여 줘요.
