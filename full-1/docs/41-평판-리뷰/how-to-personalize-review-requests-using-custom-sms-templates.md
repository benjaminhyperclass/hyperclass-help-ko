# 맞춤 SMS 템플릿으로 반복 리뷰 요청 개인화하기

**평판 관리**(Reputation Management)에서 맞춤 SMS 템플릿을 만들어 반복 리뷰 요청에 쓰는 방법을 안내해요. 맞춤 토큰으로 메시지를 개인화하고, 동적 이미지를 넣고, 여러 템플릿을 브랜드 스타일에 맞게 관리할 수 있어요. 이렇게 하면 일관되고 눈길을 끄는 요청을 보내 고객 응답을 높이고 리뷰를 늘릴 수 있어요.

## 맞춤 SMS 템플릿이란?

맞춤 SMS 템플릿은 하이퍼클래스 **평판 관리**에서 반복 리뷰 요청으로 나가는 메시지를 직접 만들고 관리하는 기능이에요. 메시지마다 맞춤 토큰, 원하는 문구, 동적 이미지 링크를 넣을 수 있어서 받는 사람마다 자신에게 맞춘 메시지처럼 느낄 수 있어요. 이렇게 맞춤 설정을 하면 참여율이 올라가고 더 많은 고객이 리뷰를 남기도록 이끌 수 있어요.

맞춤 SMS 템플릿을 쓰면 브랜딩을 일관되게 유지하고, 우리 비즈니스의 어투로 메시지를 보내고, 눈에 띄는 시각 요소를 더할 수 있어요. 사전 제작 디자인을 고르든 처음부터 직접 만들든, 리뷰 요청의 내용과 표현을 마음대로 정할 수 있어요.

## 반복 리뷰 요청에 맞춤 SMS 템플릿을 쓰면 좋은 점

맞춤 SMS 템플릿으로 리뷰 요청의 모양, 느낌, 개인화 수준을 직접 정할 수 있어요. 다음과 같은 일을 할 수 있어요.

- 개인화된 메시지: 맞춤 토큰과 브랜드에 맞는 표현으로 SMS마다 개인화해요.
- 동적 이미지 개인화: 연락처별 데이터에 따라 바뀌는 동적 이미지 URL을 넣어요. NiftyImages와 호환되어, 개인화된 이미지로 요청을 더 눈에 띄게 만들 수 있어요.
- 유연한 디자인 선택: 사전 제작 템플릿에서 고르거나 처음부터 만들어요.
- 간편한 템플릿 관리: 이름, 메시지, 토큰, 이미지 URL을 바꿔 가며 템플릿을 빠르게 만들고, 수정하고, 지정해요. 후속 메시지도 브랜드에 맞게 일관되게 유지할 수 있어요.
- 간소화된 캠페인: 원하는 반복 SMS 템플릿을 후속 캠페인에 자동으로 지정해요.

## 리뷰 요청 캠페인용 맞춤 SMS 템플릿 설정하기

다음 단계를 따라 맞춤 SMS 템플릿을 설정해 보세요.

### 1. 평판 관리 설정 열기

왼쪽 메뉴에서 **평판 관리**를 선택하고, 페이지 위쪽의 **설정** 탭을 클릭하세요. SMS 리뷰 요청 템플릿을 관리하고 맞춤 설정하는 화면이 열려요.

![평판 관리 설정 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051455822/original/eUXZPVyU27fX_1z7NgM7wT01wUP1Pu9G1A.png?1755009716)

### 2. SMS 요청 열기

설정 화면의 왼쪽 메뉴에서 **SMS 요청**을 선택하세요. 반복 SMS 리뷰 요청 템플릿의 일정, 맞춤 설정, 관리와 관련된 모든 옵션이 이곳에 있어요.

![SMS 요청 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051455847/original/t3Z2uDHEsy_61-bTl9eswugt6j0COu00Mw.png?1755009731)

### 3. SMS 리뷰 요청 켜기

**SMS 리뷰 요청** 토글을 켜세요. 그래야 템플릿을 관리할 수 있어요. 이 설정으로 반복 리뷰 요청용 SMS 템플릿을 만들고 맞춤 설정할 수 있어요. 토글이 꺼져 있으면 템플릿을 만들거나 수정할 수 없어요.

![SMS 리뷰 요청 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051455874/original/aeMjGSNlUdBOISACYMXyMDJ_zer_ZGLKBw.png?1755009745)

### 4. SMS 발송 시점 정하기

**발송 시점** 드롭다운에서 고객이 체크인한 뒤 얼마 만에 리뷰 요청을 보낼지 정하세요. 즉시, 1시간, 2시간, 4시간 중에서 고르거나 **사용자 지정**을 선택해 후속 전략에 맞는 간격을 직접 정할 수 있어요.

![SMS 발송 시점 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051455986/original/F7F2Cejvkrx5yX4RGLaqzYQhVRsDQ8dsEw.png?1755009794)

### 5. 반복 주기 정하기

**클릭할 때까지 다음 주기로 반복** 드롭다운에서 받는 사람이 반응할 때까지 SMS 리뷰 요청을 얼마나 자주 다시 보낼지 고르세요. 3일, 1주, 1개월 같은 고정 간격이 있고, 더 자유롭게 정하고 싶다면 **사용자 지정**을 선택하면 돼요.

![반복 주기 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456002/original/cA7rasFJl4Yg1SNPfdJ4r7uxDopKNv6rIA.png?1755009814)

### 6. 반복 간격 직접 설정하기

반복 주기에서 **사용자 지정**을 선택했다면 여기서 정확한 숫자와 시간 단위를 정하세요. 더하기/빼기 버튼으로 숫자를 조절하고, 후속 메시지를 보내려는 주기에 맞게 **시간** 또는 **일** 중에서 선택하세요.

![반복 간격 사용자 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456027/original/9cJThKIoIq0OL5dsdbHlK6B8YcJXER_8HQ.png?1755009838)

### 7. 최대 재시도 횟수 정하기

**최대 재시도 횟수** 드롭다운에서 반응이 없을 때 SMS 리뷰 요청을 몇 번까지 다시 보낼지 고르세요. 후속 발송을 얼마나 끈질기게 하고 싶은지에 따라 1회에서 5회 사이로 선택할 수 있어요.

![최대 재시도 횟수 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456037/original/dXaVVUyPta9bIpgtqT8gUff1iw8wXWoQ_w.png?1755009855)

### 8. 템플릿 설정 열기

**SMS 템플릿 설정**을 클릭하세요. 반복 리뷰 요청의 각 단계에서 어떤 템플릿을 쓸지 지정하는 곳이에요. 재시도 시점마다 나가는 메시지를 여기서 정해요.

![SMS 템플릿 설정 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456050/original/090hcvJqjTYcm0VrM3EEPE8WEBMkKd7r6Q.png?1755009876)

### 9. 재시도마다 템플릿 지정하기

**SMS 템플릿 설정** 창에서 반복 순서의 재시도 단계마다 템플릿을 고르세요. 여러 재시도에 같은 템플릿을 지정해도 되고, 서로 다른 템플릿을 지정해 후속 메시지를 다양하게 보낼 수도 있어요. 선택을 마쳤으면 **저장**을 클릭해 변경 사항을 적용하세요.

![재시도별 템플릿 지정 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456124/original/Yyo61UKjohz7In32Kv0wedEPEi2fkmwWgA.png?1755009908)

### 10. 새 템플릿 만들기 시작하기

**새로 만들기**를 클릭해 새 SMS 템플릿을 만들기 시작하세요. 메시지를 처음부터 직접 쓰거나 사전 제작 템플릿을 바탕으로 만들 수 있어서, 내용과 개인화를 원하는 대로 정할 수 있어요.

![새로 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456134/original/D9V78FE1WH-5lINSnjgAAvkem3S8_3RomA.png?1755009926)

### 11. 템플릿 유형 고르기

**새 SMS 템플릿 만들기** 창에서 **처음부터 새로 만들기** 또는 **사전 제작 템플릿에서 선택** 중 하나를 선택하세요. 메시지를 완전히 직접 꾸미려면 **처음부터 새로 만들기**를, 기존 디자인에서 시작하려면 **사전 제작 템플릿에서 선택**을 고르면 돼요. 이 선택에 따라 템플릿을 만드는 시작점이 달라져요.

![템플릿 유형 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456138/original/3O2IB2BAoK55mhy0_dfHHFvwKRaGxexbdQ.png?1755009943)

### 12. 처음부터 템플릿 만들기

**처음부터 새로 만들기**를 선택하면 **SMS 템플릿 빌더**가 열려요. 여기서 메시지의 모든 부분을 직접 꾸밀 수 있어요.

1. 템플릿 이름 입력: 나중에 쉽게 찾을 수 있도록 알아보기 쉬운 이름을 입력하세요.
2. 이미지 옵션 켜기: 메시지에 이미지를 넣으려면 **이미지로 요청**을 켜세요.
3. 이미지 업로드: **클릭하여 업로드**를 눌러 SVG, PNG, JPG 파일을 올리면 요청을 시각적으로 돋보이게 할 수 있어요.
4. 맞춤 이미지 URL 추가: 필요하면 **Add Custom Image URL**(사용자 지정 이미지 URL 추가) 항목에 NiftyImages 같은 동적 이미지 링크를 붙여 넣어 이미지를 개인화하세요.
5. 메시지 작성: SMS 내용을 쓰고, `{{contact.first_name}}` 같은 맞춤 토큰으로 문구를 개인화하세요.
6. 템플릿 저장: 마음에 들면 **저장**을 클릭해 다음에도 쓸 수 있게 보관하세요.

![SMS 템플릿 빌더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456158/original/1uTQ6yNz2BabHDrEuYF4vVopLooqGKgGWg.png?1755009959)

### 13. 사전 제작 템플릿 선택하고 수정하기

**사전 제작 템플릿에서 선택**을 고르면 **SMS 템플릿 라이브러리**가 열리고 바로 쓸 수 있는 템플릿이 나와요.

1. **템플릿 검색**: 검색창에 이름이나 키워드를 입력해 원하는 템플릿을 빠르게 찾으세요.
2. 미리 보고 선택: 사용할 수 있는 사전 제작 템플릿을 살펴보고, 내 메시지 스타일에 가장 잘 맞는 것을 고르세요.
3. 필요하면 수정: **템플릿 수정**을 클릭해 저장하기 전에 선택한 템플릿의 내용, 어투, 개인화 설정을 바꾸세요.

![SMS 템플릿 라이브러리](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456190/original/1KHjKaa64tycxIDL-z6rQzIRkOvOpfEXjA.png?1755009976)

### 14. 기존 템플릿 관리하기

**SMS 템플릿 관리** 영역에서 저장해 둔 템플릿을 다룰 수 있어요.

1. 템플릿 복제: 복사 아이콘을 클릭하면 기존 템플릿의 복제본이 만들어져요. 원본은 그대로 두고 복제본을 다듬거나 바꿀 수 있어요.
2. 템플릿 수정: 연필 아이콘을 클릭하면 편집기에서 템플릿이 열려요. 내용, 이미지, 개인화 설정을 수정할 수 있어요.

![SMS 템플릿 관리](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051456205/original/FJwTulGiXfLiiXPzavbCcZR2fx93cBnWWQ.png?1755009994)

## 자주 묻는 질문

### 반복 리뷰 요청에서 재시도마다 다른 SMS 템플릿을 쓸 수 있나요?

네, 쓸 수 있어요. **SMS 템플릿 설정** 창에서 재시도 단계(재시도 1, 재시도 2 등)마다 원하는 템플릿을 지정할 수 있어요. 후속 메시지를 다양하게 보내 참여를 높이면서, 모든 메시지를 같은 반복 순서 안에서 유지할 수 있어요.

### SMS 템플릿 빌더에서 "이미지로 요청"과 "Add Custom Image URL"은 무엇이 다른가요?

**이미지로 요청**은 SMS에 표시할 고정 이미지 파일(SVG, PNG, JPG)을 업로드하는 기능이에요. **Add Custom Image URL**은 호스팅된 이미지 링크를 넣는 항목이에요. NiftyImages 같은 동적 이미지 URL을 넣으면 연락처별 데이터에 따라 이미지가 바뀌어서 더 개인화된 이미지를 보낼 수 있어요.

### 반복 주기에서 "사용자 지정"을 고르면 일 대신 시간 단위로 설정할 수 있나요?

네, 할 수 있어요. **클릭할 때까지 다음 주기로 반복** 설정에서 **사용자 지정**을 선택하면 메시지 사이의 **시간** 또는 **일**을 정확한 숫자로 정할 수 있어요. 더하기/빼기 버튼으로 숫자를 정한 다음, 드롭다운에서 원하는 시간 단위를 고르세요.

### 기존 템플릿을 복제해서 원본에 영향 없이 수정할 수 있나요?

네, 할 수 있어요. **SMS 템플릿 관리** 영역에서 템플릿 옆의 복사 아이콘을 클릭하면 복제본이 만들어져요. 복제본은 원본과 별개라서, 수정해도 원본 템플릿의 내용이나 설정에는 영향이 없어요.
