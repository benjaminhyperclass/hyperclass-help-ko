# 이메일 AI(베타 2.0)로 브랜드에 맞는 이메일 빠르게 만들기

이메일 AI(베타 2.0)는 안내에 따라 프롬프트를 입력하고, 브랜드 보드의 스타일을 적용해 이메일 초안을 만들어 주는 기능이에요. 만든 초안은 대화하듯 수정할 수 있어요.

{% hint style="info" %}
이 기능은 현재 실험실 기능이에요. 사용하려면 **설정 > 실험실**로 이동해 원하는 서브 계정에서 **이메일 AI (베타 2.0)** 토글을 켜세요.
{% endhint %}

## 개요

이메일 AI는 **이메일 마케팅**의 빌더 안에서 이메일을 기획하고, 초안을 쓰고, 디자인하도록 도와주는 기능이에요. 브랜드 보드에 저장된 글꼴과 색상을 가져와 쓰고, 알맞은 레이아웃을 추천해요. 내용은 대화하듯 다듬을 수 있어서, 수정 횟수를 줄이고 더 빠르게 이메일을 발송할 수 있어요.

## 주요 장점

빠르게 만들고, 브랜드를 일관되게 유지하고, 안전하게 수정할 수 있도록 개선했어요. 문구와 레이아웃은 계속 직접 조절할 수 있어요.

- 첫 초안을 빠르게: 구조를 갖춘 완성형 이메일을 몇 분 안에 만들어요.
- 기본으로 브랜드에 맞게: 브랜드 보드의 색상과 타이포그래피가 생성할 때마다 자동으로 적용돼요.
- 프롬프트 작성 안내: **Assist Mode**(어시스트 모드)가 더 나은 프롬프트를 쓰도록 도와줘서 다시 시도하는 횟수가 줄어요.
- 참고 자료 기반 생성: URL이나 이미지로 마음에 드는 이메일을 다시 만든 뒤, 내 브랜드에 맞게 바꿀 수 있어요.
- 더 나은 레이아웃: 개선된 모델이 더 깔끔한 섹션, CTA, 반응형 구조를 만들어요.
- 대화형 편집: 쉬운 말로 AI에게 다시 쓰기, 줄이기, 번역, 섹션 추가를 요청할 수 있어요.
- 버전 안전장치: 실행 취소/다시 실행과 버전 기록에 생성 내역이 모두 남아서 쉽게 되돌릴 수 있어요.
- 수작업 감소: 서식 작업 대신 전략에 더 많은 시간을 쓸 수 있어요.

## 제한 사항 및 알려진 동작 (베타)

- 참고 자료의 재현 수준: 참고 자료에 있는 복잡한 커스텀 코드, 트래킹 픽셀, 스크립트는 가져오지 않아요. 대신 AI가 편집할 수 있는 레이아웃으로 다시 만들어요.
- 에셋: 생성한 뒤에는 샘플 이미지를 사용 권한이 있는 이미지로 바꾸고, 링크 대상도 확인하세요.
- 브랜드 보드 변경: 기본 브랜드 보드를 바꾸면 이후에 생성하는 이메일에만 적용돼요. 이미 만든 초안은 직접 편집하기 전까지 그대로예요.

{% hint style="info" %}
외부에서 받은 HTML을 그대로 쓰거나 고급 커스텀 코드가 필요하면, 먼저 **코드 편집기**로 가져오세요. 그다음 비주얼 빌더에서 이메일 AI를 사용해 브랜드에 맞는 새 버전을 만들면 돼요.
{% endhint %}

## 이메일 AI 설정하고 사용하기

아래 순서대로 이메일 AI를 켜고, 브랜드 스타일을 준비하고, 첫 초안을 만들어 보세요.

### 사전 준비

- **이메일 마케팅**이 활성화된 계정이 필요해요.
- 브랜드 보드를 미리 설정해 두면 스타일이 가장 잘 적용돼요. (권장)
- 계정에 따라 실험실 기능을 켤 수 있는 역할 권한이 필요할 수 있어요.

### 이메일 AI로 만들기

빈 프롬프트에서 브랜드에 맞는 초안까지, 몇 번의 클릭이면 돼요.

### 1단계. 이메일 마케팅 템플릿 열기

**이메일 마케팅 > 이메일**로 이동한 뒤 **템플릿** 탭을 클릭하세요.

### 2단계. 이메일 AI 실행하기

**AI로 빌드하기**를 클릭하세요. 기존 캠페인이나 템플릿을 열고, 편집 모드에서 AI 옵션을 선택해도 돼요.

![템플릿 탭의 AI로 빌드하기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065199293/original/uZ2rtDWlz88D37xMqkjNzT4nX5I2Jv-oHA.png?1771430121)

### 3단계. Assist Mode 켜고 브랜드 보드 확인하기

**Assist Mode**를 클릭하고, 올바른 브랜드 보드가 선택됐는지 확인하세요. 그래야 생성되는 이메일에 내 브랜드의 색상과 타이포그래피가 적용돼요.

![Assist Mode와 브랜드 보드 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065199586/original/t2TUFxyNHgWnoFnRNXD0PwHQAA9T__J88w.png?1771430247)

### 4단계. 시작 방법 선택하기

두 가지 방법 중 하나를 고르세요.

- **From a Reference**(참고 자료로 시작): 파일이나 이미지를 올려서 마음에 드는 레이아웃을 다시 만들어요.
- **From a Prompt**(프롬프트로 시작): 대상 고객, 목표, 오퍼, 말투, 원하는 섹션을 설명해요.

![시작 방법 선택 화면 — 참고 자료로 시작 또는 프롬프트로 시작](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065199758/original/_dvFllT1fusI0CweyYDWy4JeEYeZAWhaYw.png?1771430359)

### 5단계. 초안을 만들고 대화하듯 수정하기

초안이 만들어지면 쉬운 말로 명령해서 다듬으세요. 사용할 수 있는 명령은 **다시 쓰기**, **줄이기**, **번역**, **섹션 추가**, **Change Theme**(테마 변경)이에요.

![이메일 AI의 대화형 편집 명령](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065200495/original/3nQJp7nPGNFj5SajHPLmcSUNDYQwBJCpYw.gif?1771430724)

#### 이메일 AI로 이전 버전 복원하기

이전 변경 내용을 직접 다시 만들지 않아도, 이메일 AI 채팅에서 바로 저장된 버전을 복원할 수 있어요. 템플릿과 캠페인 이메일 모두 가능해요.

1. **이메일 빌더** 또는 **Vibe Editor**(바이브 에디터)에서 **이메일 AI**를 여세요.
2. 복원하고 싶은 버전을 이메일 AI에게 요청하세요. 예를 들면 이렇게 말할 수 있어요.
   - "이전 버전으로 되돌려 줘."
   - "버전 2로 바꿔 줘."
   - "색상을 바꾸기 전으로 돌아가 줘."
3. 복원된 버전을 캔버스에서 바로 확인하세요.

![이메일 AI 채팅에서 버전을 복원하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080149524/original/pxoAQU6tObM5mbQRjvlFxYw1eLglc1M9Cw.png?1788547772)

### 6단계. 미리보기로 마무리하기

모든 링크, 이미지, 규정 준수 관련 내용을 미리보기로 확인하세요. 마지막 수정은 빌더에서 직접 하면 돼요.

![빌더에서 이메일 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065200657/original/p5-0gqFVVt2itTSV1uOrWfyT3IiQx0jZjQ.gif?1771430847)

### 7단계. 버전 기록 확인하고 저장하기

**Kebab Menu**(점 세 개 메뉴)에서 **버전 기록**을 열면 이전에 생성한 버전을 비교하고 복원할 수 있어요. 준비가 끝나면 **Save Template**(템플릿 저장)을 클릭하세요. 이후 캠페인 과정에서 예약하거나 보낼 수 있어요.

![Kebab 메뉴의 버전 기록 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065200808/original/xiuVrEIyVQNWxhKkVp4bu2nE6D8X9eXFFw.png?1771430935)
![이전 생성 내역을 보여 주는 버전 기록 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065201302/original/9qhM17o_Mjif7lyUvpmlBLWd68ZRhDlApw.gif?1771431283)

### 설정 완료

이제 이메일을 예약하거나 보낼 수 있어요. 이전 버전으로 돌아가려면 **버전 기록**을 쓰거나, 채팅에서 이메일 AI에게 해당 버전을 복원해 달라고 요청하세요.

## 자주 묻는 질문

### 이메일 AI는 모든 사용자가 쓸 수 있나요, 특정 역할만 쓸 수 있나요?
관리자가 실험실에서 사용 여부를 관리해요. 이메일 AI가 보이지 않으면 에이전시 관리자에게 **설정 > 실험실**에서 해당 서브 계정의 **이메일 AI (베타 2.0)** 토글을 켜 달라고 요청하세요.

### "참고 자료로 시작"에는 어떤 참고 자료가 가장 좋나요?
공개된 미리보기 URL이나 페이지 전체가 선명하게 나온 스크린샷(PNG/JPG)이 구조를 가장 잘 만들어 줘요. 일부만 잘라 낸 이미지나 커스텀 스크립트가 많은 페이지는 피하세요.

### 이메일 AI가 참고한 이메일의 HTML/CSS를 그대로 복사하나요?
아니요. 내 브랜드에 맞춰 편집할 수 있는 레이아웃으로 다시 만들어요. 픽셀 단위까지 똑같이 재현해야 한다면 **코드 편집기**로 가져오는 방법을 쓰세요.

### 브랜드 보드는 생성되는 이메일에 어떤 영향을 주나요?
브랜드 색상, 타이포그래피, 공통 스타일 값이 제목, 본문, 버튼, 링크에 적용돼요. 스타일은 편집 화면이나 AI 명령으로 언제든 바꿀 수 있어요.

### 이메일 AI로 이메일을 번역할 수 있나요?
네. "스페인어로 번역해 줘"처럼 대화하듯 명령하면 돼요. 보내기 전에 해당 언어를 모국어로 쓰는 사람이 뉘앙스를 항상 검토하도록 하세요.

### 생성한 이메일의 이전 버전은 어디에서 볼 수 있나요?
이메일 편집 화면의 **Kebab Menu**에서 **버전 기록**을 열어 이전 생성 내역을 확인하고, 비교하고, 복원할 수 있어요. 이메일 AI에게 이전 버전, 번호로 지정한 버전, 앞서 변경한 시점의 버전을 복원해 달라고 요청해도 돼요. 이메일 AI는 선택한 버전을 캔버스에 바로 복원해요.

### 기본 브랜드 보드를 바꾸면 기존 이메일의 스타일도 바뀌나요?
아니요. 브랜드 보드 변경은 새로 생성하는 이메일에만 적용돼요. 기존 템플릿에 새 브랜딩을 적용하려면 직접 편집하세요.

### 이메일 AI와 워크플로우의 AI는 무엇이 다른가요?
이메일 AI는 **이메일 마케팅 > 템플릿**과 편집 화면에서 쓰며, 이메일 메시지 전체를 만들고 디자인하는 데 쓰는 기능이에요. 워크플로우 AI는 자동화 단계(**Send Email** 액션) 안에서 문구를 생성해요. 사용하는 환경과 할 수 있는 일이 서로 달라요.
