# 봇 감지로 통계 증가와 자동화 실행 막기

이메일 열람·클릭 통계가 실제 사람의 반응만 반영하도록, 봇 활동을 가려내는 기능이에요. 봇이 만든 열람과 클릭은 통계에 잡히지 않고, 자동화도 실행하지 않아요.

{% hint style="info" %}
하이퍼클래스 이메일 또는 Mailgun을 쓰는 서브 계정에서만 사용할 수 있어요. 다른 SMTP 제공업체는 지원하지 않아요.
{% endhint %}

## 개요

이메일 마케팅에서는 고객이 얼마나 반응하는지, 캠페인이 얼마나 효과적인지를 정확한 수치로 파악하는 것이 중요해요. 그런데 봇이 열람률과 클릭률을 실제보다 부풀릴 수 있어요. 이렇게 되면 잘못된 데이터 때문에 판단이 흐려지고 자동화도 엉뚱하게 동작해요.

이를 막기 위해 하이퍼클래스에서 **Bot Detection – Preventing Statistics Increment and Automation Execution**(봇 감지 – 통계 증가 및 자동화 실행 방지) 기능을 도입했어요. 사람이 아닌 활동을 조용히 걸러 내서 분석 데이터와 워크플로우를 믿고 쓸 수 있게 해 줘요.

## 이 기능이 하는 일

봇이 이메일을 열거나 클릭한 것으로 감지되면 다음 조치가 자동으로 적용돼요.

### 통계 증가 방지

봇 활동은 이메일 열람 수와 클릭 수에 더해지지 않아요. 그래서 참여 지표에는 실제 사용자의 반응만 남아요.

### 자동화 실행 방지

이메일 열람이나 클릭으로 시작되는 자동화 이벤트가 봇 활동일 때는 실행되지 않아요. 워크플로우가 의도한 대로만 동작해요.

## 봇 감지 설정 켜고 끄기

봇 감지 방지 기능은 기본적으로 꺼져 있어요. **비즈니스 프로필** 설정에서 직접 켜야 해요.

1. **설정 > 비즈니스 프로필**로 이동하세요.
2. **일반** 섹션까지 스크롤하세요. 이곳에 **Bot Detection Prevention**(봇 감지 방지) 관련 체크박스가 있어요.
3. 켜려면 체크박스를 선택하고, 끄려면 선택을 해제하세요. 변경 내용은 앞으로 보내는 이메일에 바로 적용돼요.
