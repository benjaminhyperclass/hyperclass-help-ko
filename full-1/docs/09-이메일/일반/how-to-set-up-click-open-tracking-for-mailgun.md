# Mailgun 클릭·열람 추적 설정

Mailgun으로 보낸 이메일의 클릭률과 열람률을 하이퍼클래스 대시보드에서 정확하게 보려면 설정이 두 가지 필요해요. 모든 이메일 이벤트를 하이퍼클래스로 전달하는 웹훅을 추가하고, Mailgun 도메인에서 클릭·열람 추적을 켜면 돼요.

두 단계를 모두 마치면 Mailgun으로 보낸 모든 이메일의 클릭률, 열람률, 수신 거부, 반송, 스팸 신고가 하이퍼클래스 대시보드에 정확하게 표시돼요.

## 시작하기 전에

다음 조건을 먼저 확인하세요.

- 인증된 발송 도메인이 하나 이상 있는 Mailgun 계정이 활성 상태여야 해요.
- 웹훅과 도메인 설정을 관리할 수 있도록 Mailgun 계정의 관리자 권한이 있어야 해요.
- 발송 도메인이 이미 하이퍼클래스에 연결되어 있고, 하이퍼클래스를 통해 이메일을 보내고 있어야 해요.

## Mailgun에서 웹훅 추가하기

Mailgun 웹훅은 이메일 이벤트 데이터를 실시간으로 하이퍼클래스에 보내 줘요. 사용하는 발송 도메인마다 모든 이벤트 유형을 대상으로 하는 **도메인 수준 웹훅**을 추가해야 해요.

### 1. 웹훅 화면 열기

1. Mailgun 계정에 로그인해요.
2. 왼쪽 사이드바에서 **보내기 > 웹훅**으로 이동해요.
3. **Domain-level**(도메인 수준) 탭을 클릭해요.
4. 드롭다운에서 발송 도메인을 선택해요.

### 2. 새 웹훅 추가하기

1. 오른쪽 위의 **Add webhook**(웹훅 추가)을 클릭해요.
2. 나타나는 창에서 다음 항목을 입력해요.
   - **설명**: 알아보기 쉬운 이름을 입력해요. 예: 하이퍼클래스 이벤트 추적
   - **HTTP post URL**(HTTP POST 주소): 아래 URL을 그대로 붙여 넣어요.
   - **도메인**: 드롭다운에서 발송 도메인을 선택해요.

   ![Mailgun 웹훅 추가 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073681879/original/UppMnlqmIll4mYTmtqAzerD-asKtY3uXJw.png?1781527644)

웹훅 URL:

```
https://services.leadconnectorhq.com/email-isv/provider/mailgun/webhook/event
```

### 3. 모든 이벤트 선택하기

**이벤트**에서 **전체 선택**을 체크하면 모든 이벤트 유형이 켜져요. 그러면 하이퍼클래스가 다음 이벤트의 데이터를 모두 받을 수 있어요.

- **Accepted**(수락됨)
- **Delivered**(전달됨)
- **Opens**(열람)
- **Clicked**(클릭)
- **Permanent failure**(영구 실패)
- **Temporary failure**(일시 실패)
- **스팸 신고**
- **Unsubscribes**(수신 거부)

### 4. 테스트하고 저장하기

1. 필요하면 URL 입력란 옆의 **테스트**를 클릭해 주소에 연결되는지 확인해요.
2. 확인되면 **저장**을 클릭해요.

저장하면 도메인 수준 웹훅 목록에 방금 만든 웹훅이 나타나요.

{% hint style="info" %}
Mailgun에 있는 **발송 도메인마다** 이 과정을 반복하세요. 웹훅은 도메인별로 적용돼서, 한 도메인에 추가한 웹훅이 다른 도메인에 자동으로 적용되지 않아요.
{% endhint %}

## 도메인에서 클릭·열람 추적 켜기

웹훅과 별개로, Mailgun이 이메일에 추적 링크와 열람 추적 픽셀을 넣도록 설정해야 해요. 이 설정은 도메인의 **설정** 탭에서 해요.

### 1. 도메인 설정 열기

1. Mailgun에서 **보내기 > 도메인**으로 이동해요.
2. 발송 도메인을 클릭해요.
3. **설정** 탭을 선택해요.

### 2. 클릭 추적 켜기

1. **추적** 섹션까지 스크롤해요.
2. **Click tracking**(클릭 추적) 옆의 **편집**을 클릭해요.
3. 설정을 **On**(켜짐)으로 바꿔요.
4. 변경 내용을 저장해요.

### 3. 열람 추적 켜기

1. 같은 **추적** 섹션에서 **Open tracking**(열람 추적) 옆의 **편집**을 클릭해요.
2. 설정을 **On**(켜짐)으로 바꿔요.
3. 변경 내용을 저장해요.

![Mailgun 도메인 추적 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073681991/original/GUKo4XHM1Oq_5o0t0MrdFBVr1hsEOdb2WA.png?1781527675)

두 설정을 모두 켜면 도메인 추적 설정이 다음과 같이 보여야 해요.

| 설정 | 필요한 값 |
| --- | --- |
| Click tracking | 켜짐(On) |
| Open tracking | 켜짐(On) |
| Tracking protocol | https |
| Tracking certificate | 활성(Active) |

{% hint style="info" %}
클릭 추적이 제대로 동작하려면 도메인 DNS에 **추적용 CNAME 레코드**를 추가해야 해요. 필요한 CNAME은 Mailgun의 **설정 > DNS 레코드**에서 확인할 수 있어요. 추적 인증서가 비활성으로 표시되면 CNAME이 없거나 아직 반영되지 않은 거예요.
{% endhint %}

## 설정 완료

웹훅을 저장하고 추적을 켜면 클릭, 열람, 반송, 수신 거부, 스팸 신고 이벤트가 하이퍼클래스로 실시간 전달돼요. 이 Mailgun 도메인으로 보낸 모든 이메일의 참여 데이터가 이메일 분석 대시보드에 정확하게 반영돼요.

## 자주 묻는 질문

### 웹훅을 추가했는데도 하이퍼클래스에 클릭·열람 데이터가 보이지 않아요.
가장 흔한 원인은 두 가지예요. 첫째, **설정 > 추적**에서 클릭 추적이나 열람 추적을 켜지 않은 경우예요. 둘째, 웹훅을 도메인 수준이 아니라 계정 수준으로 추가한 경우예요. 두 가지를 확인한 뒤 테스트 이메일을 보내서 이벤트가 나타나는지 확인하세요.

### 웹훅을 모든 도메인에 추가해야 하나요, 한 번만 추가하면 되나요?
발송 도메인마다 따로 추가해야 해요. Mailgun 도메인 수준 웹훅은 도메인 하나에만 적용되고, 계정의 다른 도메인에는 적용되지 않아요.

### 클릭 추적을 켜면 이메일 전송률에 영향이 있나요?
올바르게 설정하면 영향이 거의 없어요. 클릭 추적은 링크를 추적용 서브도메인(예: email.yourdomain.com)을 거쳐 연결해요. Mailgun이 공용으로 제공하는 CNAME 대신 내 도메인의 추적용 CNAME을 쓰면 리디렉션이 내 도메인에서 처리돼서, 공유 평판 때문에 생기는 문제를 피할 수 있어요. 링크가 깨지지 않도록 추적 인증서가 활성 상태인지 확인하세요.

### 웹훅에서 **테스트**를 눌렀더니 오류가 나요. 무엇을 확인해야 하나요?
웹훅 URL이 **https://services.leadconnectorhq.com/email-isv/provider/mailgun/webhook/event** 와 정확히 같은지 확인하세요. 끝에 슬래시나 다른 문자가 붙으면 안 돼요. 계정의 네트워크 접근 설정이 외부 주소로 나가는 호출을 허용하는지도 확인하세요. 자세한 오류 내용은 Mailgun 웹훅 화면의 **Failure logs**(실패 로그) 탭에서 볼 수 있어요.

### 이미 도메인 수준 웹훅이 있어요. 수정해야 하나요, 새로 만들어야 하나요?
기존 웹훅이 올바른 URL을 가리키고 모든 이벤트가 선택되어 있다면 바꿀 필요가 없어요. URL이 다르거나 빠진 이벤트가 있다면 새로 만들지 말고, 웹훅 옆의 점 3개 메뉴에서 **편집**을 선택해 수정하세요. 그래야 같은 웹훅이 중복되지 않아요.

### 이 설정은 모든 캠페인의 이메일을 추적하나요, 특정 캠페인만 추적하나요?
설정한 Mailgun 도메인으로 보낸 모든 이메일의 이벤트가 하이퍼클래스로 전달돼요. 하이퍼클래스는 발송 시점에 이메일 헤더에 넣은 메타데이터를 바탕으로 각 이벤트를 해당 연락처와 캠페인에 연결해요.

### 추적용 CNAME 레코드가 없으면 어떻게 되나요?
CNAME이 없으면 추적 인증서가 비활성으로 표시되고, 이메일 속 클릭 추적 링크가 깨지거나 엉뚱한 곳으로 이동할 수 있어요. 열람 추적 픽셀도 불러오지 못할 수 있어요. Mailgun의 **설정 > DNS 레코드**에 나온 CNAME 레코드를 추가하고, DNS에 반영될 때까지 기다리세요. 최대 48시간이 걸릴 수 있어요.
