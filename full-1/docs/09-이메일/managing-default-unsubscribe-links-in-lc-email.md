# 하이퍼클래스 이메일의 기본 수신 거부 링크 관리

기본 수신 거부 링크를 켜거나 끄는 방법과, 태그로 수신 거부 링크를 직접 넣는 방법을 안내해요. 이 설정으로 CAN-SPAM과 GDPR 기준에 맞게 이메일을 보낼 수 있어요.

{% hint style="warning" %}
이 문서는 하이퍼클래스 이메일의 **기본 수신 거부 링크**만 다뤄요. 수신 거부 화면이나 링크를 직접 만들고 싶다면 "사용자 지정 수신 거부 링크 만들기 및 관리" 문서를 참고하세요.
{% endhint %}

## 수신 거부 링크란?

수신 거부 링크를 누르면 연락처가 앞으로 이메일을 받지 않도록 설정할 수 있어요. CAN-SPAM Act와 GDPR 같은 이메일 관련 법에서 요구하는 필수 항목이에요. 하이퍼클래스 이메일은 이메일 하단에 수신 거부 링크를 자동으로 넣어 주고, 이 기능을 끄면 넣지 않아요.

## 수신 거부 링크를 넣어야 하는 이유 (법적 준수)

수신 거부 링크는 단순한 권장 사항이 아니라 여러 국가의 법에서 요구하는 사항이에요. 넣지 않으면 큰 금전적 제재를 받을 수 있어요. 나라마다 법이 다르지만, 대부분의 나라는 마케팅 이메일에 수신 거부 방법을 분명하게 넣도록 해요.

### 미국 — CAN-SPAM Act

CAN-SPAM Act(Controlling the Assault of Non-Solicited Pornography And Marketing)는 연방거래위원회(FTC)가 집행해요. 모든 상업용 이메일에 수신자가 수신 거부할 수 있는 방법을 분명하게 넣어야 해요.

### 유럽연합 — GDPR

GDPR(General Data Protection Regulation)은 2018년 5월부터 의무로 적용돼요. 17조에 삭제권(Right to Erasure)이 들어 있어요. 구독자는 자신의 개인정보를 삭제해 달라고 요청할 수 있고, 발송자는 이 요청을 따라야 할 법적 의무가 있어요.

{% hint style="warning" %}
**GDPR 삭제권**

연락처가 이메일 목록에서 수신 거부하면 삭제권을 행사한 거예요. 이메일을 보내는 사람은 정보 처리 책임자(data controller)로서 이 요청을 따라야 하고, 그 연락처의 데이터 처리와 보관을 멈춰야 해요.

GDPR을 지키지 않으면 2,000만 유로 또는 회사 연간 전 세계 매출의 4% 중 더 큰 금액이 벌금으로 부과될 수 있어요.
{% endhint %}

수신 거부 링크를 넣으면 다음과 같은 효과가 있어요.

- 사용자의 동의를 존중할 수 있어요.
- 국내외 법을 지킬 수 있어요.
- 비용이 큰 법적 문제로부터 비즈니스를 보호할 수 있어요.
- 수신자가 받는 메일을 직접 관리할 수 있어 신뢰를 쌓을 수 있어요.
- 반응이 있는 연락처 위주로 목록을 깔끔하게 유지할 수 있어요.
- 규정에 맞지 않는 발송 때문에 계정이 정지되는 일을 막을 수 있어요.

## 기본 수신 거부 링크 켜기·끄기

하이퍼클래스는 모든 이메일에 기본으로 수신 거부 링크를 넣어요. 직접 링크를 넣고 싶다면 기본 링크를 끌 수 있어요. 이때는 모든 이메일에 `{{email.unsubscribe_link}}` 태그를 직접 넣어야 해요.

1. **서브 계정 설정 > 비즈니스 프로필**로 이동해요.

   ![서브 계정 설정에서 비즈니스 프로필로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044100029/original/jPgWkvjShX9JZwTacRfVwdZi-Fl8mwG30Q.png?1743083285)

2. **일반 설정**이 보일 때까지 아래로 스크롤해요.

   ![비즈니스 프로필의 일반 설정에서 수신 거부 링크 설정을 보여 주는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044100189/original/CfTkTKvr4DtFzTfisOmVp9OTuVUC_bhSqw.png?1743083377)

3. **Include Unsubscribe Link**(수신 거부 링크 포함) 토글을 켜요. 끄려면 같은 토글을 꺼요.

   이 설정의 내용은 이 서브 계정에서 보내는 모든 이메일 하단에 자동으로 들어가요. 링크의 문구나 연결되는 곳을 바꿔서 수신 거부 화면을 원하는 대로 꾸밀 수도 있어요.

   ![비즈니스 프로필 일반 설정에서 Include Unsubscribe Link 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044100498/original/_RCWSNzTAdH2audMXJAVTC7oNhavLjklWQ.gif?1743083598)

{% hint style="warning" %}
기본 수신 거부 링크를 끄면 이메일 규정을 지키기 위해 모든 이메일에 `{{email.unsubscribe_link}}` 태그를 **반드시** 직접 넣어야 해요.
{% endhint %}

## 수신 거부 링크 직접 넣기

링크 위치와 모양을 직접 정하고 싶다면 기본 제공 태그로 이메일 안에 수신 거부 링크를 넣을 수 있어요.

### 태그 사용하기

1. **대화**, 또는 **마케팅** 아래의 **이메일 캠페인**이나 **이메일 템플릿**에서 하이퍼클래스 이메일의 **이메일 빌더**를 열어요.
2. 링크를 넣고 싶은 곳에 커서를 두고 아래 태그를 입력하거나 붙여 넣어요.

   ```
   {{email.unsubscribe_link}}
   ```

   태그 대신 커스텀 값을 써도 돼요. **이메일** 커스텀 값 섹션에 있는 **수신 거부 링크**를 선택하세요.

   ![하이퍼클래스 이메일 빌더에서 수신 거부 태그를 이메일에 넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044102505/original/4ten5iXcnoVcQ3IAmA-JQWkblQdKsg-H0g.gif?1743084767)

{% hint style="info" %}
이메일이 발송될 때 `{{email.unsubscribe_link}}` 태그는 연락처가 수신 거부할 수 있는 클릭 가능한 링크로 자동 변환돼요.
{% endhint %}

## 두 방법을 함께 쓰면 어떻게 되나요?

수신 거부 링크가 두 개 이상 들어가면 수신자가 헷갈리고 브랜드 이미지에도 영향을 줄 수 있어요. 같은 이메일에서 두 방법이 모두 켜져 있으면 다음과 같이 돼요.

- 기본 수신 거부 링크: **비즈니스 프로필** 설정에서 켜 두면 이메일 하단에 자동으로 들어가요.
- 직접 넣은 `{{email.unsubscribe_link}}` 태그: 이메일 템플릿의 원하는 위치에 직접 넣어요.

### 같은 이메일에서 두 방법이 모두 켜져 있을 때

- 직접 넣은 태그의 링크와 하단에 자동으로 들어가는 링크, 이렇게 수신 거부 링크가 두 개 나타나요.
- 이메일 디자인이 복잡해 보여서 클릭률이나 전환율이 떨어질 수 있어요.
- 두 링크의 모양이 다르거나 연결되는 곳이 다르면 연락처가 헷갈릴 수 있어요.

### 권장 방법: 이메일마다 한 가지 방법만 쓰세요

- 링크 위치와 모양을 정확히 정하고 싶다면 `{{email.unsubscribe_link}}` 태그를 직접 넣고, 기본 하단 링크는 **끄세요**.
- 하단 위치로 충분하다면 기본 설정을 그대로 두고 직접 넣는 태그는 쓰지 마세요.

## 자주 묻는 질문

### 모든 이메일에 수신 거부 링크가 꼭 있어야 하나요?

네, 법적으로 필요해요. 모든 하이퍼클래스 이메일 메시지에 기본 하단 링크나 `{{email.unsubscribe_link}}` 태그 중 하나가 있어야 해요.

### 수신 거부 링크에 표시되는 문구를 바꿀 수 있나요?

`{{email.unsubscribe_link}}` 태그가 만드는 기본 문구는 수정할 수 없어요. 대신 링크 주변의 문구를 바꾸거나, 브랜드에 맞춘 수신 거부 페이지를 만들 수 있어요. 완전히 사용자 지정한 화면이 필요하다면 "사용자 지정 수신 거부 링크 만들기 및 관리" 문서를 참고하세요.

### 기본 링크를 끄고 직접 넣는 태그를 깜빡하면 어떻게 되나요?

수신 거부 링크 없이 이메일이 발송돼요. 이는 이메일 규정 위반이며 발송 기능이 정지될 수 있어요. 발송하기 전에 두 방법 중 하나가 들어 있는지 항상 확인하세요.

### 누가 수신 거부했는지 확인할 수 있나요?

네, 연락처 목록에서 **구독취소** 상태로 필터링하면 수신 거부한 연락처를 볼 수 있어요.
