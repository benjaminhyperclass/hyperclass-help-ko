# 이메일 캠페인 바로 보내기 또는 예약하기

일반 이메일 캠페인은 자동화 없이 선택한 연락처에게 한 번 보내는 이메일이에요. 이 문서에서는 캠페인을 바로 보내는 방법과 나중에 보내도록 예약하는 방법을 안내해요.

## 일반 이메일 캠페인이란?

일반 이메일 캠페인은 **이메일 마케팅**(Email Marketing) 화면에서 직접 디자인해 선택한 대상에게 한 번 보내는 이메일이에요. 기간이 정해진 공지, 프로모션, 뉴스레터처럼 워크플로우 자동화가 필요 없는 발송에 알맞아요.

{% hint style="info" %}
이메일을 보내려면 발송에 쓸 인증된 도메인이 있어야 해요.
{% endhint %}

## 일반 이메일 캠페인의 장점

- 속도: 자동화를 만들지 않고도 특정 대상 그룹에 바로 소식을 보낼 수 있어요.
- 제어: **Simple Schedule**(단순 예약) 또는 **Batch**(분할 발송)로 발송 시각이나 발송 속도를 정할 수 있어요.
- 타기팅: 세그먼트나 스마트 리스트로 알맞은 대상에게 보낼 수 있어요.
- 전달률: 대량 발송은 **Batch (Drip)**(분할 발송)로 나눠 보내 트래픽이 한꺼번에 몰리는 것을 줄일 수 있어요.
- 유연성: RSS, **Smart Send**(스마트 발송)/**AI Schedule**(AI 일정)과 함께 쓰면 발송 시점을 더 잘 맞출 수 있어요.

## 이메일 캠페인 보내기 또는 예약하기

설정을 꼼꼼히 하면 오류가 줄고 전달률이 좋아져요. 아래 순서대로 캠페인을 준비하고, 보내고, 관리해 보세요.

{% hint style="info" %}
자동으로 후속 이메일을 보내고 싶다면 별도 가이드를 참고하세요.
{% endhint %}

### 1단계: 이메일 캠페인 만들기

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. **신규** 캠페인을 만들거나, 기존 캠페인을 **편집**하세요.

   ![이메일 캠페인 만들기 화면](https://jumpshare.com/share/4ksctHv7u96lC8oWPfe5+/GIF+Recording+2026-09-21+at+16.17.03.gif)

### 2단계: 이메일 디자인하기

{% hint style="info" %}
이메일 빌더와 인라인 편집기 사용법은 별도 문서에서 자세히 확인하세요.
{% endhint %}

1. 템플릿을 만들거나 선택하세요.
2. 내용, 이미지, 링크를 추가하세요.
3. [미리보기와 테스트 이메일](preview-and-test-your-email-campaign-templates.md)로 데스크톱과 모바일에서 레이아웃이 제대로 보이는지 확인하세요.

   ![이메일 미리보기 확인](https://jumpshare.com/share/hq3gcuzenGCjNaxaiTsE+/Screen+Shot+2026-01-20+at+8.49.33+PM.png)

### 3단계: 발송 방법 선택하기(지금 전송 또는 일정)

1. **보내기** 또는 **일정** 버튼을 클릭하세요.

   ![보내기 또는 일정 버튼](https://jumpshare.com/share/ZmI4gwhpzMUoWCyLodlk+/Screen+Shot+2026-01-20+at+8.52.46+PM.png)
2. 선택 사항: 이메일에 파일 첨부하기

   1. **보내기** 또는 **일정** 화면에서 **파일 첨부**를 클릭하세요.
   2. 포함할 파일을 선택하세요. (최대 첨부 파일 크기 제한: 10MB 이내)
   3. 캠페인을 보내거나 예약하기 전에 첨부 파일이 목록에 표시되는지 확인하세요.

      ![파일 첨부 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065470502/original/syIt8nu7hUQkGC56sBQDCbdfm0FEFrzs9w.gif?1771838884)
3. 바로 보내려면 **지금 전송**을 선택하세요.

   1. **발신자 이름**을 입력하세요.
   2. **발신 도메인**을 확인하거나 도메인 설정을 점검하세요.
   3. **발신자 이메일**을 입력하세요.
   4. **제목 줄**을 입력하세요.
   5. **수신자**를 추가하세요.
   6. 필요하면 **추가 설정**에서 **링크 추적**, **UTM 추적**, **태그**를 설정하세요.
   7. **보내기** 버튼을 클릭하세요.

      ![지금 전송으로 이메일 보내기](https://jumpshare.com/share/vBQdeUvyJ47EjprfXzG5+/GIF+Recording+2026-01-20+at+9.00.53+PM.gif)
4. 나중에 보내려면 **일정**을 선택해 날짜와 시간을 정하세요.

   1. **날짜**와 **시간**을 설정하세요. (이메일은 서브 계정의 시간대에 맞춰 발송되고, 해당 시간대는 일정 설정 아래에 표시돼요.)
   2. **발신자 이름**을 입력하세요.
   3. **발신 도메인**을 확인하거나 도메인 설정을 점검하세요.
   4. **발신자 이메일**을 입력하세요.
   5. **제목 줄**을 입력하세요.
   6. **수신자**를 추가하세요.
   7. 필요하면 **추가 설정**에서 **링크 추적**, **UTM 추적**, **태그**를 설정하세요.
   8. **일정** 버튼을 클릭하세요.

      ![일정으로 이메일 예약하기](https://jumpshare.com/share/xcYZ30xSVGLUEGF1Nwhp+/GIF+Recording+2026-01-20+at+9.05.00+PM.gif)

## 자주 묻는 질문

### 이메일 캠페인을 다시 예약할 수 있나요?
네, 예약한 캠페인은 발송 예정 날짜·시간 1시간 전까지 다시 예약할 수 있어요.

### 이메일을 보낼 때 캠페인과 워크플로우는 뭐가 다른가요?
캠페인은 한 번 보내는 일회성 발송이에요. 워크플로우는 여러 단계로 이어지는 흐름을 자동화하고, 트리거나 조건에 따라 이메일을 보낼 수 있어요.

### 발송하기 전에 테스트해 볼 수 있나요?
네. 편집기에서 **미리보기**와 **테스트 이메일**을 사용한 다음, 검토 단계에서 내용을 최종 확인하세요.

### 캠페인을 URL과 이메일로 보낼 수 있나요?
<!-- 검토 필요: 원문 내용이 서로 다름 (질문과 답변이 맞지 않음) -->
네, **Statistics**(통계)에서 미리보기를 볼 수 있고, 테스트 이메일을 보내 미리보기를 확인할 수도 있어요. 테스트 이메일이나 미리보기 이메일에서는 구독 취소를 할 수 없어요.

### 캠페인을 삭제했거나 잘못 처리해서 이전 버전으로 되돌리고 싶어요.
캠페인 편집기에서 점 세 개 메뉴를 열고 **버전 기록 보기**를 선택하면 이전 버전으로 복원할 수 있어요.

**이메일 AI**를 열어서 이전 버전, 번호가 붙은 버전, 이전 변경 사항과 연결된 버전으로 복원해 달라고 요청할 수도 있어요. 복원한 버전은 캔버스에서 확인한 다음 계속 진행하세요.

### 이메일 캠페인에 파일을 첨부할 수 있나요?
네. **보내기** 또는 **일정** 화면 상단의 **파일 첨부** 버튼을 클릭해 파일을 업로드하고 이메일 캠페인에 추가하세요.
