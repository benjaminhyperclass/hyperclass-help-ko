# 서브 계정 신규 사용자에게 가는 온보딩 이메일 맞춤 설정하기

새로 추가된 서브 계정 사용자에게 자동으로 가는 온보딩 이메일을 직접 꾸미는 방법을 안내해요. SaaS 에이전시 관리자가 쓸 수 있는 기능이에요.

[동영상](https://www.youtube.com/embed/Mv_tcDhWiDI?&wmode=opaque)

## 1단계: 웰컴 이메일 맞춤 설정 화면 열기

1. **SaaS 구성기**(SaaS Configurator)로 이동해요.
2. **고급 설정**을 클릭해요.
3. **Customize Welcome Email**(웰컴 이메일 맞춤 설정)에서 **Customize Now**(지금 맞춤 설정)를 클릭해요.

## 2단계: 템플릿을 저장할 서브 계정 선택하기

1. **서브 계정 선택**에서 이메일 템플릿을 저장할 서브 계정을 골라요.
2. **이메일 맞춤 설정**을 클릭해요.

![서브 계정을 선택하고 이메일 맞춤 설정을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010862023/original/MPTW3THxwde8x6WPhdfrxfq0f_7fcmBmog.png?1698095718)

## 3단계: 이메일 빌더에서 템플릿 꾸미기

이메일 빌더가 열리면 레이아웃을 바꾸고, 커스텀 값을 넣고, 브랜드 테마를 적용하는 등 원하는 대로 꾸며요.

![이메일 빌더에서 템플릿을 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010862034/original/UJbnmO8pagPFSlUcUo43RHA1shW9O5G-mQ.png?1698095771)

## 4단계: 저장하기

**저장**을 클릭해요.

![저장 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027049303/original/Ror13rlvAbVRrW8F5_0s44pFbzc6FKGtOw.png?1717482842)

{% hint style="warning" %}
위에서 설명한 것처럼, 템플릿은 처음 만들 때 선택한 서브 계정에 저장돼요. 원래 저장된 위치에서 이메일 템플릿을 삭제하지 마세요. 삭제하면 맞춤 설정이 사라지고, 이후 발송되는 모든 이메일에 기본 이메일 템플릿이 쓰여요.
{% endhint %}
