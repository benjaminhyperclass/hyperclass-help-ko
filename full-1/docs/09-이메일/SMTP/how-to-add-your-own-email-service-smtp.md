# 내 이메일 서비스(SMTP) 추가하기

Gmail, SendGrid, Mailgun, Amazon SES 같은 외부 이메일 발송 서비스를 서브 계정에 직접 연결하는 방법을 안내해요. 이미 쓰던 발송 서비스가 있거나 발송 한도를 늘려야 할 때 활용하세요.

## 개요

하이퍼클래스에서는 기본 하이퍼클래스 이메일 대신 외부 이메일 발송 서비스(SMTP)를 연결해 쓸 수 있어요. 이미 쌓아 둔 발송 평판이 있거나, 더 많은 발송량이 필요하거나, 이메일 발송 환경을 직접 관리하고 싶을 때 유용해요.

이 문서에서는 서브 계정에서 사용자 SMTP 서비스를 추가하고, 설정하고, 활성화하는 과정을 설명해요.

## 이메일 서비스 위치

아래 순서로 **이메일 서비스** 설정 화면을 열어 보세요.

1. 서브 계정에 로그인하세요.
2. 왼쪽 사이드바에서 **설정**을 클릭하세요.
3. **이메일 서비스**를 선택하세요.
4. **SMTP 서비스** 탭으로 이동하세요. 인터페이스 버전에 따라 **고급 설정** 탭으로 보일 수도 있어요.

{% hint style="info" %}
화면에 **SMTP 서비스** 탭이나 **고급 설정** 탭이 보일 수 있어요. 두 탭 모두 같은 SMTP 설정 화면으로 연결돼요.
{% endhint %}

## 기본 이메일 서비스와 사용자 SMTP 비교

내 비즈니스에 어떤 방식이 맞는지 아래 표로 비교해 보세요.

| 하이퍼클래스 이메일(기본) | 사용자 SMTP(외부 서비스) |
| --- | --- |
| 플랫폼에서 관리해요 | 내가 직접, 또는 이메일 제공업체가 관리해요 |
| 기본 제공되는 전달률 도구를 모두 쓸 수 있어요 | 일부 기본 도구는 쓸 수 없어요(제한 사항 참고) |
| 별도 설정이 필요 없어요 | 제공업체에서 받은 SMTP 인증 정보가 필요해요 |
| 대부분의 사용자에게 권장해요 | 이미 발송 환경을 갖춘 사용자에게 알맞아요 |

## 지원하는 SMTP 제공업체

**+ Add Service**(서비스 추가)를 클릭하면 아래 제공업체 중에서 고를 수 있어요.

- **Gmail**: Google Workspace 또는 개인 Gmail
- **Yahoo Mail**
- **SendGrid**
- **기타**: Mailgun, Amazon SES, Postmark, Zoho 등 SMTP를 지원하는 모든 서비스

## 사용자 SMTP 서비스 추가하기

아래 5단계를 따라 외부 이메일 서비스를 연결하세요.

### 1단계. 이메일 서비스 열기

**설정 > 이메일 서비스 > SMTP 서비스** 탭으로 이동하세요.

### 2단계. + Add Service 클릭

페이지 오른쪽 위에서 **+ Add Service** 버튼을 클릭하세요. **Add your own email service**(나만의 이메일 서비스 추가) 팝업이 나타나요.

![Add Service를 클릭해 SMTP 설정 팝업 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069981836/original/bajlYiGnuLKVa_nG4mR8iX7i8b3voPsfgg.png?1777263794)

### 3단계. SMTP 제공업체 선택

**SMTP 제공업체** 드롭다운에서 사용하는 제공업체를 선택하세요.

- **Gmail**
- **Yahoo Mail**
- **SendGrid**
- **기타** (Mailgun, Amazon SES, Postmark 등)

![드롭다운에서 SMTP 제공업체 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069981801/original/WRn4tN6qIe17oF2bB2eVYO_GugVC8Dp2MQ.png?1777263715)

### 4단계. SMTP 인증 정보 입력

필수 항목을 입력하세요. 입력할 값은 이메일 제공업체의 대시보드에서 확인할 수 있어요.

| 필드 | 설명 |
| --- | --- |
| **SMTP Host**(SMTP 호스트) | 발송 메일 서버 주소예요. 예: smtp.sendgrid.net |
| **Port**(포트) | 보통 587(TLS) 또는 465(SSL)을 써요 |
| **Username**(사용자 이름) | SMTP 로그인 사용자 이름 또는 API 키 식별자예요 |
| **Password / API Key**(비밀번호 / API 키) | 제공업체에서 받은 SMTP 비밀번호 또는 API 키예요 |
| **보내는 사람** | 받는 사람에게 보이는 표시 이름이에요 |
| **보내는 이메일** | 이메일을 보낼 주소예요 |

![SMTP 인증 정보 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069981857/original/TydsvLo8_i1wRWr6NR-Lt0CYdi0xk9_CLg.png?1777263854)

### 5단계. 저장하고 활성으로 설정

저장하면 새 SMTP 서비스가 제공업체 목록에 나타나요. 이 서비스로 발송하려면 아래 순서로 진행하세요.

1. 목록에서 새로 추가한 서비스를 찾으세요.
2. **Set as active**(활성으로 설정)를 클릭하세요.
3. 선택을 확인하세요.

{% hint style="info" %}
SMTP 서비스를 여러 개 저장해 두고 언제든 바꿔 쓸 수 있어요. 단, 한 번에 하나만 활성 상태로 둘 수 있어요.
{% endhint %}

## 주요 제공업체 SMTP 설정 참고

자주 쓰는 제공업체의 설정값이에요. 붙여 넣기 전에 제공업체 대시보드에서 값을 한 번 더 확인하세요.

| 제공업체 | SMTP 호스트 | 포트 | 참고 |
| --- | --- | --- | --- |
| Gmail | smtp.gmail.com | 587 / 465 | 2단계 인증을 쓰는 경우 앱 비밀번호가 필요해요 |
| SendGrid | smtp.sendgrid.net | 587 | 사용자 이름으로 'apikey'를 입력하세요 |
| Mailgun | smtp.mailgun.org | 587 | Mailgun SMTP 인증 정보를 사용하세요 |
| Amazon SES | email-smtp.[region].amazonaws.com | 587 | IAM SMTP 인증 정보가 필요해요 |
| Postmark | smtp.postmarkapp.com | 587 | 서버 API 토큰을 인증 정보로 사용하세요 |
| Yahoo Mail | smtp.mail.yahoo.com | 587 | 앱 비밀번호가 필요해요 |
| Zoho Mail | smtp.zoho.com | 587 | Zoho 계정 인증 정보를 사용하세요 |

## 외부 SMTP 사용 시 제한 사항

하이퍼클래스 이메일 대신 사용자 SMTP 서비스를 쓰면 일부 플랫폼 기능을 쓸 수 없어요. 전환하기 전에 아래 제한 사항을 확인하세요.

외부 SMTP에서 사용할 수 없는 기능:

- 앱에서 전용 발송 도메인 만들기
- Google Postmaster 도구 연동
- Microsoft Postmaster 도구 연동
- 위험 평가
- 반송 분류
- 받은편지함 배치 테스트
- 스팸 점수 검사기
- 블랙리스트 모니터
- 관리형 도메인 및 IP

{% hint style="warning" %}
이메일 전략에 이 기능들이 중요하다면 **하이퍼클래스 이메일**을 그대로 쓰는 것을 고려해 보세요. 기본 제공되는 전달률 도구를 모두 쓸 수 있어요.
{% endhint %}

## SMTP 답장 받기 설정

활성 상태의 SMTP 서비스를 열면 **Enable reply**(답장 활성화) 체크박스가 보여요. 이 옵션을 켜면 SMTP로 보낸 이메일에 대한 답장이 하이퍼클래스 대화에 수신되고 기록돼요.

{% hint style="info" %}
연락처와 이메일을 주고받아야 한다면 활성 SMTP 서비스의 **Enable reply**를 꼭 체크하세요.
{% endhint %}

## 하이퍼클래스 이메일로 되돌리기

기본 하이퍼클래스 이메일로 언제든 다시 전환할 수 있어요.

1. **설정 > 이메일 서비스 > SMTP 서비스**로 이동하세요.
2. **하이퍼클래스 이메일**을 클릭하세요.
3. **Set as active**를 클릭하세요(또는 기본값으로 선택하세요).

{% hint style="info" %}
추가해 둔 사용자 SMTP 서비스는 모두 그대로 저장돼 있어서, 나중에 다시 활성화할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### SMTP 서비스를 여러 개 저장해 둘 수 있나요?

네, 원하는 만큼 저장할 수 있어요. 다만 발송 이메일에는 한 번에 하나만 활성 상태로 쓸 수 있어요.

### 연락처에게 SMTP 제공업체 정보가 보이나요?

아니요. 연락처에게는 내가 설정한 **보내는 사람**과 **보내는 이메일**만 보여요. SMTP 제공업체 정보는 보이지 않아요.

### 제공업체를 바꾸면 이미 보낸 이메일은 어떻게 되나요?

제공업체를 바꾸면 앞으로 보내는 이메일에만 적용돼요. 이미 보낸 이메일에는 영향이 없어요.

### SMTP 연결이 계속 실패해요. 무엇을 확인해야 하나요?

아래 항목을 확인해 보세요.

- SMTP 호스트, 포트, 사용자 이름, 비밀번호가 맞는지 확인하세요.
- 이메일 제공업체에서 587번이나 465번 포트를 막고 있지 않은지 확인하세요.
- Gmail에서 2단계 인증을 쓰고 있다면 일반 로그인 비밀번호가 아니라 앱 비밀번호를 쓰고 있는지 확인하세요.
- SendGrid를 쓴다면 SendGrid 계정에서 발송 도메인이 인증됐는지 확인하세요.
- 발송 이메일 주소가 SMTP 제공업체 계정에서 사용 승인된 주소인지 확인하세요.

### 사용자 SMTP를 쓰면 기본 이메일 전달률 도구에 영향이 있나요?

네. 외부 SMTP로 전환하면 여러 기본 전달률 도구를 쓸 수 없어요. Postmaster 연동, 위험 평가, 반송 분류, 받은편지함 배치 테스트, 스팸 점수 검사기, 블랙리스트 모니터, 관리형 도메인 및 IP가 해당돼요. 위의 제한 사항을 참고하세요.

### SMTP 포트는 587과 465 중 어느 것을 써야 하나요?

TLS를 쓰는 587번 포트(요즘 대부분의 제공업체가 권장해요)나 SSL을 쓰는 465번 포트를 쓰세요. 네트워크에서 한쪽 포트가 막혀 있다면 다른 포트를 써 보세요.

### 내가 보낸 이메일의 답장이 하이퍼클래스로 들어오나요?

활성 SMTP 서비스에서 **Enable reply** 옵션을 체크한 경우에만 들어와요. 이 옵션을 켜면 답장이 하이퍼클래스 대화에 수신되고 기록돼요.
