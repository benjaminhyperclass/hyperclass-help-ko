# 블랙리스트 등록으로 이메일이 차단될 때: 해제 요청과 발송 복구

이메일이 반송(바운스)되는 원인을 찾고, 공개 블랙리스트에서 해제를 요청하고, 같은 문제가 다시 생기지 않게 막는 방법을 안내해요. 바운스 메시지에 블랙리스트, RBL, DBL이 언급될 때 이 문서를 참고하세요.

## 무슨 일이 일어난 걸까요?

이메일 캠페인의 구성 요소 중 하나 이상이 공개 블랙리스트(RBL/DBL)에 올라서 이메일이 차단되고 있어요. 발송 IP 주소, 도메인, 이메일 본문에 들어간 URL 중 어느 것이든 원인일 수 있어요.

이메일 서비스 업체는 스팸을 막는 1차 방어선으로 이 블랙리스트를 활용해요. 블랙리스트에 오르면 여러 플랫폼에서 이메일 전달률이 크게 떨어질 수 있어요. 이 문서에서는 원인 진단, 블랙리스트 해제, 복구 일정, 재발 방지 방법을 차례로 설명해요.

### 바운스 메시지 예시

```
Email blocked due to listed URLs or IPs/domains on public blacklists (RBLs/DBLs).
```

## 빠른 진단: 블랙리스트 문제인지 확인하기

바운스가 갑자기 늘었거나 전달률이 떨어졌다면, 먼저 바운스 메시지에 블랙리스트, RBL, DBL을 언급하는 표현이 있는지 확인하세요. 그런 표현이 있다면 아래 「단계별 해결 방법」 순서대로 전체 진단을 진행하세요.

{% hint style="warning" %}
블랙리스트 차단은 문제가 된 캠페인 하나에만 적용되지 않아요. 등록된 IP, 도메인, URL에서 나가는 모든 이메일에 영향을 줘요. 블랙리스트 관련 바운스 메시지는 다른 사실이 확인되기 전까지 계정 전체의 문제로 보세요.
{% endhint %}

## 블랙리스트 차단 이해하기

### 핵심 개념

- 블랙리스트는 의심스러운 IP, 도메인, URL을 추적하는 외부 데이터베이스예요.
- Gmail, Outlook, Yahoo 같은 주요 이메일 서비스는 이메일을 받기 전에 여러 블랙리스트를 확인해요.
- 블랙리스트에 오르면 특정 캠페인만이 아니라 계정에서 나가는 전체 이메일에 영향이 있어요.
- 원인을 해결한 뒤에도 블랙리스트에서 빠지는 데 24~72시간이 걸릴 수 있어요.
- 일부 블랙리스트는 일정 기간 정상적으로 발송하면 자동으로 항목을 삭제해요.

### 주요 블랙리스트 종류

| 유형 | 블랙리스트 | 특징 |
| --- | --- | --- |
| IP 기반(RBL) | Spamhaus SBL/CSS/XBL/PBL | 가장 널리 쓰이는 IP 평판 목록 |
| IP 기반(RBL) | Barracuda Reputation Block List | IP 평판 점수 평가 |
| IP 기반(RBL) | SpamCop | 사용자 신고 기반 |
| 도메인/URL 기반(DBL) | Spamhaus DBL | 도메인 평판 |
| 도메인/URL 기반(DBL) | URIBL / SURBL | URL 평판 및 스팸 URL 추적 |
| 도메인/URL 기반(DBL) | Google Safe Browsing | 악성코드·피싱 차단 |

## 단계별 해결 방법

### 1단계. 블랙리스트에 오른 대상 확인하기

먼저 발송 IP를 확인해요.

1. **설정 > 이메일 서비스 > Sending Domain and IP**(발신 도메인 및 IP)로 이동하세요.
2. 설정된 발신 도메인과 화면에 표시된 IP 정보를 메모해 두세요.
3. 공유 인프라를 쓰고 있다면 IP 정보는 하이퍼클래스 고객지원에 문의하세요.

그다음 외부 블랙리스트 검사 도구를 사용해요.

1. MXToolbox.com > Blacklist Check로 이동하세요.
2. 발송 IP 주소를 입력해 검사하세요.
3. 발신 도메인도 따로 검사하세요.
4. 캠페인에 자주 넣는 URL도 각각 검사하세요.

### 2단계. 이메일 내용 분석하기

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. 최근 7~14일 동안 발송한 캠페인을 살펴보고, 새로 들어간 URL, 도메인, 단축 링크가 있는지 확인하세요.

아래와 같은 내용이 있는지 확인하세요.

- 단축 URL(bit.ly, tinyurl 등)
- 새로 등록한 도메인
- 의심스러운 확장자(.tk, .ml, .ga)가 붙은 URL
- 파일 공유 서비스로 연결되는 링크

### 3단계. 블랙리스트 해제 요청하기

Spamhaus에 등록된 경우에는 이렇게 진행해요.

1. spamhaus.org > SBL/CSS/PBL Removal로 이동하세요.
2. IP 또는 도메인을 입력하세요.
3. 안내에 따라 해제 절차를 진행하고, 어떤 조치를 했는지 자세히 설명하세요.

다른 주요 블랙리스트도 각각 해제 요청 양식이 따로 있어요.

- Barracuda: barracudacentral.org/rbl/removal-request
- SpamCop: spamcop.net > Reporting > Remove
- SURBL: surbl.org > Whitelist Request

### 4단계. 재발 방지 조치하기

이메일 템플릿을 정리해요.

1. **마케팅 > 이메일 > 템플릿**으로 이동하세요.
2. 문제가 된 URL이나 도메인을 제거하세요.
3. 단축 URL은 전체 주소를 쓴 신뢰할 만한 링크로 바꾸세요.
4. 수신거부 링크와 실제 주소를 분명하게 넣으세요.

연락처 목록도 관리해요.

1. **연락처 > 스마트 리스트**로 이동하세요.
2. 이메일에 반응하는 구독자만 모은 세그먼트를 만드세요.
3. 바운스된 연락처와 반응이 없는 연락처는 주기적으로 제거하세요.

### 해제에 성공했는지 확인하는 방법

- 블랙리스트 검사 도구에 "Not Listed" 상태가 표시돼요.
- 테스트 이메일이 반송되지 않고 받은편지함에 도착해요.
- 바운스율이 정상 수준(2% 미만)으로 돌아와요.
- 이메일 전달 리포트에서 수신 성공률이 좋아진 것이 보여요.

## 복구 일정과 예상 결과

### 1단계 · 0~24시간: 즉시 조치

- 할 일: 블랙리스트에 오른 구성 요소를 확인하고 해제를 요청하세요.
- 예상 결과: 블랙리스트 등록 상태를 확인하고, 해제 요청이 접수돼요.

### 2단계 · 24~72시간: 해제 진행

- 할 일: 블랙리스트 상태를 모니터링하고 해제 요청의 진행 상황을 확인하세요.
- 예상 결과: 블랙리스트에서 차츰 빠지고 전달률이 좋아져요.

### 3단계 · 1~4주: 평판 회복

- 할 일: 깨끗한 발송 습관을 유지하고 전달률을 계속 모니터링하세요.
- 예상 결과: 이메일 전달률과 발신자 평판이 완전히 회복돼요.

## 지속적인 모니터링과 예방

### 매주 확인할 것

- MXToolbox.com으로 매주 블랙리스트 등록 여부를 확인하고, 새로 등록되면 알림을 받도록 설정하세요. senderscore.org에서 Sender Score도 확인하세요.
- **리포팅 > Email Analytics**(이메일 분석)에서 지표를 확인하세요. 바운스율은 2% 미만으로 유지하고, 전달률이 갑자기 떨어지는지 살펴보세요.

### 예방을 위한 권장 사항

- 가능하면 모든 링크에 내 도메인을 사용하세요.
- 꼭 필요한 경우가 아니면 URL 단축 서비스를 쓰지 마세요.
- 캠페인에 넣기 전에 모든 URL을 테스트하세요.
- 발송 패턴과 발송량을 일정하게 유지하세요.
- 발신자 정보와 수신거부 옵션을 분명하게 넣으세요.

## 문제가 계속될 때

블랙리스트와 관련된 전달 문제가 계속된다면 아래를 시도해 보세요.

- 모든 내용을 기록하세요. 해제 요청과 그에 대한 답변을 모두 남겨 두세요.
- 전용 IP를 검토하세요. 이용할 수 있다면 전용 IP 옵션을 알아보세요.
- 발송 방식을 점검하세요. 이메일 전략 전체에서 규정 준수 문제가 없는지 살펴보세요.
- 전문가의 도움을 받으세요. 복잡한 블랙리스트 문제는 전문가의 개입이 필요한 경우가 많아요. 기록해 둔 자료를 준비해서 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 블랙리스트에 올랐는지, 다른 바운스 문제인지 어떻게 알 수 있나요?

바운스 메시지 문구를 정확히 확인하세요. 블랙리스트와 관련된 바운스에는 RBL, DBL 또는 Spamhaus 같은 특정 목록 이름이 나와요. 대신 인증(SPF/DKIM/DMARC)이나 메일함 용량 초과 오류가 나온다면 다른 문제예요.

### 블랙리스트 해제 요청은 무료인가요?

네, 무료예요. 이 문서에 나온 Spamhaus, Barracuda, SpamCop, SURBL 모두 무료로 해제 요청을 받아요.

### 복구 후 바운스율은 어느 정도가 좋은가요?

바운스율은 2% 미만으로 유지하세요. 이 수준을 넘는 상태가 계속되면 다시 블랙리스트에 오르기 쉬워요. 평판이 회복된 뒤에도 계속 지켜보는 것이 좋아요.

### 전용 IP로 바꾸면 블랙리스트 문제가 해결되나요?

전용 IP를 쓰면 발송 평판을 직접 관리할 수 있어요. 그래서 공유 인프라의 다른 발신자 때문에 블랙리스트에 오르는 일을 막는 데 도움이 돼요. 하지만 이미 등록된 도메인이나 URL이 자동으로 해제되지는 않아요. 그 항목은 해제 요청을 따로 제출해야 해요.

### 블랙리스트 항목이 저절로 없어지기도 하나요?

그런 경우도 있어요. 일부 블랙리스트는 일정 기간 정상적으로 발송하면 항목을 자동으로 삭제해요. 다만 직접 해제 요청을 하는 것보다 오래 걸릴 수 있어요. 발송을 빨리 복구해야 한다면 자동 삭제만 기다리지 마세요.

### 문제가 된 URL 하나가 왜 전체 발송 평판에 영향을 주나요?

블랙리스트는 이메일의 모든 구성 요소를 평가해요. 발송 IP, 발신 도메인, 본문에 든 URL이 모두 대상이에요. 문제가 된 링크 하나만으로도 도메인이나 IP 단위로 차단될 수 있어요. 그러면 그 링크가 들어 있는 캠페인뿐 아니라 같은 인프라에서 나가는 모든 캠페인에 영향을 줘요.
