# Mailgun 개요 — 요금과 도메인 설정 방법 비교

Mailgun은 하이퍼클래스에서 대량 이메일을 보낼 때 쓰는 이메일 발송 서비스예요. 이 문서에서는 Mailgun이 무엇인지, 요금은 어떻게 되는지, 어떤 도메인이나 서브도메인을 써야 하는지, 설정 방법별 장단점은 무엇인지 알려 드려요. 에이전시와 고객사에 맞는 구성을 고를 때 참고하세요.

## Mailgun이란?

Mailgun은 이메일을 대량으로 보내는 외부 서비스예요. 문자와 전화를 보낼 때 Twilio를 쓰는 것과 비슷해요. 새로 시작하는 에이전시는 기본적으로 하이퍼클래스 이메일을 사용해요.

{% hint style="info" %}
Mailgun이 꼭 필요한지 잘 모르겠나요? 먼저 하이퍼클래스 이메일이 무엇인지 확인해 보세요. 새로 시작하는 에이전시 대부분은 Mailgun을 따로 설정할 필요가 없어요.
{% endhint %}

## Mailgun을 쓰면 좋은 점

- 안정적인 대량 발송: 전용 이메일 인프라로 많은 양의 이메일을 안정적으로 보낼 수 있어요.
- 브랜드 발송 도메인: 내 도메인이나 서브도메인으로 보내서 이메일이 전문적이고 브랜드에 맞게 보여요.
- 유연한 설정: 공유 서브도메인 하나를 쓰거나, 고객사별 서브도메인을 여러 개 만들어 쓸 수 있어요.
- 전달률 관리: DNS와 MX 레코드를 최적화해서 받은편지함 도달률을 높이고, 품질이 낮은 리스트 때문에 생기는 문제를 줄일 수 있어요.

## Mailgun 요금은 얼마인가요?

{% hint style="info" %}
요금제와 가격은 언제든 바뀔 수 있어요. 최신 정보는 Mailgun 사이트의 [요금 페이지](https://www.mailgun.com/pricing/)에서 확인하세요.
{% endhint %}

- Basic 요금제: 월 $15부터 시작해요.
- Foundation 요금제: 월 $35부터 시작해요.
- Scale 요금제: 월 $90부터 시작해요.

## 어떤 도메인을 써야 하나요?

Mailgun에서는 `mg.mydomain.com`처럼 서브도메인을 쓰는 것을 권장해요. 서브도메인을 써도 `you@mydomain.com`처럼 루트 도메인 주소로 이메일을 보낼 수 있어요.

{% hint style="warning" %}
서브도메인을 쓴다면 전달률을 높이기 위해 해당 서브도메인의 MX 레코드를 꼭 설정하세요. MX 레코드는 Mailgun 계정 안에서 설정해요.
{% endhint %}

{% hint style="warning" %}
내가 소유한 도메인만 추가할 수 있어요. 해당 도메인의 정식 소유자 또는 발신자임을 인증하려면 도메인의 DNS 레코드를 업데이트해야 해요.
{% endhint %}

Mailgun을 설정하는 방법은 두 가지예요.

### 방법 1: 서브도메인 하나 사용

에이전시 도메인용 서브도메인을 Mailgun에 하나 만들고, 모든 고객사 서브 계정에서 그 서브도메인으로 이메일을 보내요.

### 방법 2: 서브도메인 여러 개 사용

고객사 도메인마다 Mailgun에 서브도메인을 만들고, 각 고객사 계정에서 해당 서브도메인으로 이메일을 보내요. 서브 계정마다 고유한 도메인이나 서브도메인을 설정해서 콜드 인바운드 이메일을 받을 수도 있어요. 자세한 내용은 [콜드 이메일 인바운드 설정](메일건/cold-email-inbound-setup-mailgun.md)을 참고하세요.

| 설정 방법 | 장점 | 단점 |
| --- | --- | --- |
| 서브도메인 하나 사용 | 설정이 쉬워요. 이미 보유한 도메인에 서브도메인 하나만 설정하면 돼요. 이메일에 에이전시 도메인 브랜딩이 적용돼요. 에이전시 브랜딩을 보여 주고 싶지 않다면 일반 도메인을 쓸 수도 있어요. | 반송률 때문에 점수가 나빠져 도메인이 비활성화되면, 모든 계정이 같은 도메인을 쓰기 때문에 모든 고객사의 이메일 발송이 멈춰요. 해결책은 품질이 낮은 리스트에 스팸성 이메일을 보내지 않는 거예요. |
| 서브도메인 여러 개 사용 | 고객사 도메인별로 브랜딩이 적용돼요. 한 고객사의 도메인이 비활성화돼도 그 고객사 계정의 이메일만 멈춰요. | 설정이 어려워요. 고객사마다 서브도메인을 설정하고 각 고객사 도메인에 접근 권한을 받아야 해서 시간이 오래 걸려요. |

## 자주 묻는 질문

### 이미 하이퍼클래스 이메일을 쓰고 있는데 Mailgun도 필요한가요?

아니요. 새로 시작하는 에이전시는 기본적으로 하이퍼클래스 이메일을 쓰고, 이 경우 Mailgun을 따로 설정하지 않아도 돼요. Mailgun은 보통 자체 대량 발송 인프라가 필요한 에이전시가 사용해요.

### 공유 서브도메인 하나를 쓰다가 나중에 고객사별 서브도메인으로 바꿀 수 있나요?

네, 바꿀 수 있어요. 언제든 고객사를 각자의 전용 서브도메인으로 옮길 수 있어요. 다만 새 DNS 레코드를 설정하고 도메인마다 다시 인증해야 해요.

### 공유 Mailgun 도메인이 정지되면 어떻게 되나요?

공유 서브도메인 하나를 쓰고 있다면 그 도메인을 쓰는 모든 고객사가 영향을 받아요. 리스트 품질을 높게 유지하고 스팸성 발송을 피하는 것이 가장 좋은 예방법이에요.

### Mailgun에서 쓰려는 도메인을 이미 소유하고 있어야 하나요?

네. 소유한 도메인만 추가할 수 있어요. 해당 도메인으로 이메일을 보내려면 먼저 도메인의 DNS 레코드를 업데이트해서 소유권을 인증해야 해요.

### 루트 도메인과 서브도메인 중 어느 것을 써야 하나요?

서브도메인(예: `mg.mydomain.com`)을 권장해요. 대량 발송이 루트 도메인의 평판과 분리되고, `you@mydomain.com` 같은 주소로 이메일을 보낼 수도 있어요.

### 이메일을 보내는 고객사가 늘어나면 Mailgun 요금도 올라가나요?

Mailgun 요금제(Basic, Foundation, Scale)는 고객사 도메인 수가 아니라 발송량에 따라 책정돼요. 같은 요금제에서 고객사를 더 추가해도 요금이 자동으로 오르지 않고, 발송량이 늘어날 때 요금이 올라가요.
