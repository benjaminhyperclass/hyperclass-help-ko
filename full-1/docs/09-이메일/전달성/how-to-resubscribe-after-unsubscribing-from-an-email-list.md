# 구독을 취소한 수신자가 이메일을 다시 구독하게 하기

구독을 취소한 연락처가 마케팅 이메일을 한 번에 다시 받도록 설정할 수 있는 기능을 설명해요. 동작 방식, **수신거부**와 리포트에 미치는 영향, 연락처 기록에서 변경 내용을 확인하는 방법을 알려 드려요.

[동영상](https://www.youtube.com/embed/l7tpEiedGmg?&wmode=opaque)

다시 구독 기능을 쓰면, 구독을 취소한 연락처가 간단하게 마케팅 이메일 수신을 다시 시작할 수 있어요.

구독을 취소한 연락처는 피드백 설문에서 **Unsubscribed by mistake, subscribe again**(실수로 구독을 취소했어요. 다시 구독할게요)을 선택하고 **제출**을 누르면 돼요. 그러면 하이퍼클래스가 이메일 구독 상태를 되돌려요.

## 다시 구독 기능이란?

다시 구독은 구독 취소 피드백 설문에 들어 있는 기본 옵션이에요. 연락처가 실수로 구독을 취소했을 때 이를 되돌릴 수 있어요.

구독을 취소한 연락처가 **Unsubscribed by mistake, subscribe again**을 선택하고 피드백 폼을 제출하면, 하이퍼클래스가 해당 연락처의 이메일 구독 상태를 복원해요.

## 다시 구독 기능의 장점

- 간편한 동의 복구: 연락처가 구독 취소 피드백 폼에서 바로 "실수로 취소했다"고 알리고 다시 구독할 수 있어요.
- 깔끔한 CRM 상태: 연락처의 이메일 수신 가능 여부가 갱신되어서 **수신거부**를 직접 켜고 끌 필요가 없어요.
- 캠페인 연속성: 연락처가 다시 수신에 동의하면 재참여 시퀀스를 깔끔하게 이어 갈 수 있어요.
- 규정 준수에 도움이 되는 흐름: 연락처가 직접 한 긍정적인 행동이 기록되어 동의 기록을 뒷받침해요.
- 운영 효율: "다시 추가해 주세요" 같은 문의가 줄어요.

## 다시 구독 옵션이 나타나는 위치

연락처가 이메일에서 구독을 취소하면, 구독 취소 피드백 설문에 **Unsubscribed by mistake, subscribe again** 옵션이 함께 나와요.

연락처가 이 옵션을 선택하고 폼을 제출하면, 이메일을 다시 받겠다는 뜻이 전달돼요.

![구독 취소 후 피드백 설문에 나타나는 다시 구독 옵션](https://jumpshare.com/share/U6iP3gqVpJo85sB0hO9O+/Screen+Shot+2026-09-15+at+17.15.53.png)

## 수신거부와 동의 상태 변경

다시 구독하면 연락처의 이메일 수신 가능 여부가 바뀌어요. 변경 내용을 확인하고 동의 기록을 명확하게 남기려면 아래를 살펴보세요.

- **Unsubscribed by mistake, subscribe again**을 선택하고 피드백 폼을 제출하면 연락처가 다시 구독돼요.
- 폼을 제출한 뒤에 연락처 기록에서 변경 내용을 확인하세요.
- 팀이 나중에 확인할 수 있도록 메모나 태그(예: `Resubscribed - {date}`)를 남겨 두세요.

{% hint style="info" %}
연락처 기록을 변경 전(이메일 = 구독 취소/차단됨)과 변경 후(이메일 = 수신 가능/수신거부 아님)로 비교해 보면 업데이트가 제대로 적용됐는지 확인할 수 있어요.
{% endhint %}

## 리포트 관련 참고 사항

캠페인 분석에서는 구독 취소와 다시 구독 이벤트가 바로 맞춰지지 않을 수 있어요. 팀과 미리 공유하고, 지표를 확인할 때는 알맞은 리포트를 고르세요.

- 다시 구독한 뒤에도 한동안 일부 캠페인 통계에는 해당 연락처가 구독 취소 상태로 표시될 수 있어요.
- 성과를 확인할 때는 메시지 단위 데이터와 연락처 단위 데이터를 비교하고, 이메일 리포트 문서에 안내된 집계 시점과 방식도 함께 확인하세요.
- 앞으로 발송할 대상을 정확히 파악하려면 현재 수신 가능 여부를 기준으로 리포트를 나눠 보세요.

## 자동화 아이디어 (선택)

기본 다시 구독 흐름 위에 워크플로우를 더하면 경험을 더 매끄럽게 만들 수 있어요.

- 다시 구독 확인 이메일: 짧은 "다시 오신 걸 환영해요" 이메일을 보내서 선택을 확인해 주고, 환경설정 링크도 함께 안내해요.
- 감사 기록용 자동 태그: `Resubscribed` 같은 태그에 날짜를 붙이면 동의 감사가 쉬워져요.
- 부담 없는 재참여 시퀀스: 새로 받은 동의를 존중해서, 바로 대량 발송 대상에 넣지 말고 발송량이 적은 시리즈를 천천히 보내세요.
- 내부 팀 알림: 한동안 연락이 없던 리드가 다시 구독하면 Slack이나 사내 이메일로 담당자에게 알려요.

## 다시 구독 설정하고 테스트하기

간단히 테스트해 보면 구독 취소 흐름이 잘 동작하는지, 다시 구독 옵션이 나타나는지, 연락처 기록이 바뀌는지 실제 운영 전에 확인할 수 있어요.

### 1단계. 테스트 연락처 준비하기

- 연락처를 만들거나, 이메일을 보낼 수 있는 기존 연락처를 고르세요.
- 해당 연락처가 이메일을 받을 수 있는 상태인지 확인하세요(현재 차단되어 있지 않아야 해요).

### 2단계. 간단한 테스트 이메일 보내기

- 이메일 하단에 기본 구독 취소 링크(또는 직접 설정한 구독 취소 방식)를 넣으세요.
- 테스트 연락처에게 이메일을 보내세요.

### 3단계. 이메일에서 구독 취소하기

- 이메일을 열고 **구독 취소**를 클릭하세요.
- 구독 취소 과정을 끝내고 완료 페이지까지 이동하세요.

### 4단계. 피드백 폼에서 다시 구독하기

1. 구독을 취소한 뒤 피드백 설문을 찾으세요.

2. **Unsubscribed by mistake, subscribe again**을 선택하세요.

3. **제출**을 클릭하세요.

![피드백 설문에서 다시 구독을 선택하고 제출하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080966609/original/Wau6If9LCIlxabntoV95CoIBKe8hPlII_Q.png?1789473037)

### 5단계. 연락처 기록 확인하기

- 테스트 연락처를 열고 이메일 수신 가능 여부가 복원됐는지 확인하세요(**수신거부**와 최근 **활동** 항목을 살펴보세요).
- 내부 추적을 위해 `Resubscribed - {date}` 같은 태그나 메모를 남기세요.

![연락처 기록에서 다시 구독 결과를 확인하는 화면](https://jumpshare.com/share/ySeHHozfIvYYoJv3uT4q+/Screen+Shot+2026-09-15+at+17.22.32.png)

### 준비 끝

다시 구독 기능은 수신자에게 정중하게 돌아올 길을 열어 주고, 팀의 수작업 없이도 깔끔한 감사 기록을 남겨 줘요. 한 번 테스트해 보고, 확인 워크플로우를 더하면 나머지는 이 흐름이 처리해 줄 거예요.

## 자주 묻는 질문

### 연락처가 다시 구독했다가 또 구독을 취소하면 어떻게 되나요?
가장 최근에 한 행동이 수신 가능 여부를 결정해요. 과거 분석에는 이전 상태가 남아 있을 수 있으니, 앞으로 발송할 대상을 정할 때는 연락처의 현재 상태를 기준으로 하세요.

### 누군가 다시 구독하면 워크플로우를 실행할 수 있나요?
네. 연락처 수신거부 상태 변경 트리거나 비슷한 트리거를 사용하면 확인 이메일 발송과 태그 추가 시퀀스를 시작할 수 있어요.

### 다시 구독하면 SMS나 다른 채널에도 영향이 있나요?
다시 구독은 이메일 수신 가능 여부만 복원하도록 만들어진 기능이에요. 채널별 환경설정은 **수신거부** 설정에 따라 따로 관리하세요.

### 다시 구독한 뒤 리포트에는 얼마나 빨리 반영되나요?
한동안 일부 통계에는 연락처가 계속 구독 취소 상태로 보일 수 있어요. 맞춰 볼 때는 연락처 단위 상태와 최근 활동을 기준으로 확인하세요.

### 구독 취소 방식을 직접 설정했는데도 다시 구독 옵션이 나오나요?
구독 취소 화면을 직접 설정했다면, 간단히 테스트해서 완료 페이지에 다시 구독 옵션이 포함되어 있는지 확인하세요.

### 여러 연락처를 한꺼번에 다시 구독시킬 수 있나요?
다시 구독은 연락처가 구독 취소 완료 페이지에서 직접 하는 행동이에요. 수동으로 예외를 처리해야 한다면 회사의 규정 준수 및 동의 절차를 따르세요.

### 다시 구독한 뒤에는 어떻게 하는 게 좋은가요?
짧은 확인 메시지를 보내고, 환경설정 링크를 안내하세요. 그리고 바로 대량 발송 대상에 넣지 말고 부담 없는 재참여 시퀀스를 시작하세요.

### 다시 구독 링크가 유효한 기간이 정해져 있나요?
링크는 연락처와 완료 페이지에 연결되어 있어요. 구독 취소 완료 페이지에 접근할 수 있는 동안에는 동작해요. 페이지를 직접 수정할 때는 다시 구독 요소를 그대로 두세요.

### 다시 구독하면 이전 동의 기록이 덮어써지나요?
아니요. 다시 구독은 기존 기록 위에 새로운 긍정적 동의 이벤트로 추가돼요. 이전 행동은 감사용으로 **활동**과 동의 기록(Consent log)에 그대로 남아 있어요.
