# 코스 강의에 미디어 저장소 파일 가져오기

이미 올려 둔 오디오·비디오 파일을 코스 강의에 다시 올리지 않고 바로 가져다 쓰는 방법을 안내해요. 하이퍼클래스 코스에서 **미디어 저장소에서 가져오기** 기능으로 강의에 미디어를 넣을 때 참고하세요.

## 코스에서 미디어 저장소 가져오기란?

**미디어 저장소에서 가져오기**를 쓰면 **미디어 저장소**에 있는 오디오·비디오 파일을 코스 강의에 붙일 수 있어요. 같은 파일을 다시 올리지 않고, **미디어 저장소**에서 골라 강의로 가져오면 돼요.

같은 영상이나 오디오를 여러 강의·코스에서 쓸 때 특히 편해요. 콘텐츠 라이브러리도 깔끔하게 유지되고 반복 작업도 줄어요.

## 주요 장점

- 중복 업로드가 없어요: 같은 파일을 여러 번 올리지 않고, 이미 있는 오디오·비디오를 가져와요.
- 코스를 더 빨리 만들 수 있어요: **미디어 저장소**에 있는 콘텐츠로 몇 번만 클릭하면 강의 미디어를 넣을 수 있어요.
- 콘텐츠를 한곳에서 관리해요: 코스 미디어를 **미디어 저장소**에 모아 두면 다시 쓰기 쉬워요.
- 관리가 더 깔끔해져요: 같은 파일의 중복 버전이 줄고, 여러 코스의 미디어를 업데이트하기 쉬워져요.

## 코스 강의에 미디어 저장소 파일 가져오기

**미디어 저장소**에서 바로 가져오면 강의를 더 빨리 만들 수 있고, 미디어도 한곳에 모아 두고 다시 쓸 수 있어요.

1. **멤버십 > 코스 > 상품**으로 이동하세요.

   ![멤버십 > 코스 > 상품 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155065595345/original/8GurbWjMl4MAEI78EI3yKRscaYG1lvIM-Q.png?1771941100)
2. 편집할 코스를 클릭해서 열어요.
3. 수정할 강의로 이동하세요.
4. 새 강의를 만들거나 기존 강의를 편집하세요.

   ![강의를 만들거나 편집하는 화면 녹화](https://jumpshare.com/share/6Bg2KiruBEo2dVgCeyjd+/GIF+Recording+2026-02-24+at+19.24.24.gif)
5. **미디어 저장소에서 가져오기** 버튼을 클릭하세요.
6. **클릭하여 미디어 저장소에서 선택** 버튼을 클릭하세요. **미디어 저장소** 라이브러리가 열리면 사용할 오디오·비디오 파일을 찾아 보세요.

   ![클릭하여 미디어 저장소에서 선택 버튼 화면](https://jumpshare.com/share/3eYw0OSVaABgmNZBnSmA+/Screen+Shot+2026-02-24+at+19.26.00.png)
7. 오디오·비디오 파일을 선택한 다음 **Insert Media**(미디어 삽입)를 클릭하세요.

   ![오디오·비디오 파일을 선택하고 미디어 삽입을 클릭하는 화면](https://jumpshare.com/share/4D9sfLPklAD0JIMjXMYH+/Screen+Shot+2026-02-24+at+19.29.19.png)

## 자주 묻는 질문

### 이미지도 가져올 수 있나요?
아니요, 오디오와 비디오만 가져올 수 있어요.

### 미디어 저장소에서 가져오면 파일이 새로 업로드되나요?
아니요. **미디어 저장소**에 있는 오디오·비디오를 그대로 쓰기 때문에 다시 올릴 필요가 없어요.

### 강의에 "Import via Media Library"가 보이지 않아요. 무엇을 확인해야 하나요?
<!-- 검토 필요: 원문 내용이 서로 다름 (본문 버튼은 '미디어 저장소에서 가져오기', FAQ는 'Import via Media Library') -->
강의 편집 화면(만들기·편집)에 들어와 있는지 확인하세요. 그리고 내 사용자 권한에 **미디어**와 **멤버십**/**코스** 접근 권한이 있는지도 확인하세요.

### 같은 영상을 여러 강의나 코스에서 다시 쓸 수 있나요?
네. 가져오기는 다시 쓰도록 만들어진 기능이에요. 필요한 만큼 여러 강의에서 같은 **미디어 저장소** 파일을 선택하면 돼요.

### 강의를 게시하지 않으면 수강생에게 가져온 미디어가 보이나요?
수강생에게는 게시된 콘텐츠만 보여요. **저장**을 누르면 변경 내용이 저장되고, 게시하면 코스 공개 설정에 따라 수강생이 볼 수 있어요.
