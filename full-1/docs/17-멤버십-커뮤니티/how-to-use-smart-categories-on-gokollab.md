# GoKollab 스마트 카테고리 사용하기

GoKollab의 스마트 카테고리는 AI가 코스와 커뮤니티에 가장 알맞은 카테고리를 자동으로 지정해 주는 기능이에요. 콘텐츠 설명만 분명하게 써 두면, 직접 설정하지 않아도 상품이 더 잘 노출되고 참여도 높아져요.

## 스마트 카테고리란?

스마트 카테고리는 AI가 코스와 커뮤니티에 가장 관련 있는 카테고리를 자동으로 붙여 주는 기능이에요. 특정 주제를 찾는 학습자와 커뮤니티 멤버가 내 콘텐츠를 쉽게 찾을 수 있어요.

![스마트 카테고리 개요 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049542773/original/Vy_nCotKN1OoG5xFmjYQZwY2zYdVmkx5fg.png?1751992379)

## 스마트 카테고리의 장점

별도 작업 없이 콘텐츠를 정리하고 더 많은 사람에게 보여 줄 수 있어요.

- 검색 결과와 카테고리 필터에서 더 잘 보여요.
- 직접 설정할 필요가 없어요. 카테고리를 일일이 고르지 않아도 돼요.
- 콘텐츠가 바뀌면 카테고리도 자동으로 업데이트되어 항상 정확하게 유지돼요.
- 상품이 눈에 더 잘 띄고, 더 매력적으로 보여요.
- 사람이 실수할 일이 줄어서 모든 상품의 분류가 일관돼요.
- 시간이 절약되니 좋은 콘텐츠를 만드는 데 집중할 수 있어요.

## 스마트 카테고리는 어떻게 작동하나요?

스마트 카테고리는 고급 AI 모델로 코스나 커뮤니티의 다음 항목을 분석해요.

- 제목
- **설명**
- **소개** 섹션

시스템은 이 정보를 바탕으로 가장 알맞은 카테고리를 제안하고 적용해요. 콘텐츠가 바뀌면 카테고리도 자동으로 따라 바뀌어요. 태그를 다시 지정할 필요가 없어요.

![스마트 카테고리 작동 방식 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049542772/original/5fDJ7s74Nq3yzDtds4Njij0kAnTHO4RWcA.png?1751992379)

## 카테고리가 더 정확해지도록 콘텐츠 다듬기

내용이 분명하고 초점이 뚜렷할수록 AI가 알맞은 카테고리를 지정하기 쉬워요. 다음 방법을 참고하세요.

- 주제가 분명히 드러나는 구체적인 제목을 쓰세요. 예를 들어 "마케팅 기초"보다 "코치를 위한 디지털 마케팅"이 좋아요.
- 콘텐츠의 목적, 대상, 범위를 설명하는 키워드 중심의 **설명**을 추가하세요.
- **소개** 섹션에 관련 정보를 채워 정확한 분류를 도우세요.
- "이것저것 조금씩", "일반 정보"처럼 모호한 표현은 피하세요. AI가 헷갈릴 수 있어요.

## 중요 참고 사항

카테고리는 모든 코스와 커뮤니티 썸네일에 표시돼요. 그래서 콘텐츠를 정확하고 구체적으로 써 두는 것이 특히 중요해요.

AI 카테고리 덕분에 사용자가 원하는 콘텐츠를 더 빨리 찾을 수 있어요. 상품 콘텐츠가 내용을 분명히 전달하고, 의도한 주제와 맞는지 항상 확인하세요.

## 자주 묻는 질문

### 카테고리를 직접 바꿀 수 있나요?
지금은 바꿀 수 없어요. 스마트 카테고리는 자동으로 작동하도록 만들어졌어요. 직접 입력할 일을 줄이고, 플랫폼 전체에서 분류를 일관되게 유지하기 위해서예요.

### 카테고리는 얼마나 자주 업데이트되나요?
코스나 커뮤니티의 제목, **설명**, **소개**를 수정할 때마다 카테고리가 자동으로 새로 바뀌어요.

### 상품에 엉뚱한 카테고리가 표시돼요. 어떻게 하나요?
제목과 **설명**에 주제가 분명하게 담겨 있는지 확인해 보세요. 그래도 문제가 계속되면 하이퍼클래스 고객지원에 문의해 검토를 요청할 수 있어요.

### 스마트 카테고리가 상품 노출 빈도에 영향을 주나요?
네. 카테고리가 더 정확하면 검색 결과와 필터에서 더 좋은 위치에 노출돼요. 그만큼 사용자가 내 콘텐츠를 찾고 참여할 가능성도 커져요.

## 다음 단계

- 기존 코스와 커뮤니티의 제목과 설명이 분명한지 점검하세요.
- 상품 썸네일에서 지정된 카테고리를 확인하세요.
- 상품 설명을 최신으로 유지해서 카테고리가 계속 알맞게 지정되도록 하세요.
- 검색과 필터에서 상품이 어떻게 노출되는지 살펴보고 효과를 확인하세요.
