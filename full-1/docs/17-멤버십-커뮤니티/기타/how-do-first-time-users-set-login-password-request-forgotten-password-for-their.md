# 멤버십 포털에서 처음 비밀번호 설정하기와 비밀번호 재설정

이 문서는 매직 링크로 비밀번호를 처음 설정하거나, 잊어버린 비밀번호를 다시 설정하는 과정을 안내해요. 결제 후에 접근 권한을 받든 자동화로 받든, 멤버가 안전하게 로그인하고 비밀번호를 관리하는 방법을 알 수 있어요. 코스와 클라이언트 포탈 접근에 모두 똑같이 적용돼요.

[동영상](https://www.youtube.com/embed/PxGq36rdQyM?&wmode=opaque)

---

## 비밀번호 설정 과정이란?

사용자가 코스나 멤버십 영역에 접근하게 되면 시스템이 만든 비밀번호는 더 이상 발송되지 않아요. 대신 사용자가 직접 비밀번호를 만들 수 있도록 안전한 매직 링크가 담긴 이메일을 받아요.

이 방식은 보안을 높이고 사용자 경험을 좋게 해요. 관리자가 비밀번호를 일일이 관리하지 않아도 돼요. 처음 로그인할 때와 비밀번호 재설정을 요청할 때 모두 같은 흐름으로 진행돼요.

---

## 사용자가 비밀번호를 설정하거나 재설정하는 방법

사용자가 코스에 접근하게 되는 여러 경로와, 각 경로에서 비밀번호를 만들거나 재설정하는 방법을 소개해요.

### 결제 후 (오퍼 구매)

새 사용자는 결제 과정을 마치면 코스나 멤버십에 접근할 수 있어요. 사용자가 이메일과 이름(성 포함)을 입력하고 **Proceed to checkout**(결제 진행하기)을 클릭하면 해당 오퍼에 등록돼요. 이때 매직 로그인 링크가 담긴 이메일이 자동으로 발송돼요. 사용자는 이 링크로 직접 비밀번호를 설정하고 코스에 들어갈 수 있어요.

![결제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044610969/original/LS1lS3ZpmrhnyklrnjDPQyU2w76p64Ugog.png?1743991978)

### 관리자가 직접 등록

관리자는 연락처의 프로필 화면에서 드롭다운 메뉴로 오퍼를 선택해 사용자를 코스에 직접 등록할 수 있어요. 이 경우에도 같은 매직 링크 이메일이 발송돼요. 사용자는 비밀번호를 설정하고 코스에 접근할 수 있어요.

### 자동화된 워크플로우 또는 스마트 리스트 액션

**Offer Access Granted**(오퍼 접근 권한 부여됨)나 **Membership New Signup**(멤버십 신규 가입) 같은 트리거를 쓰면 워크플로우나 스마트 리스트 액션으로 사용자를 코스에 자동 등록할 수 있어요. 이런 자동화는 매직 링크가 담긴 시스템 이메일을 보내요. 사용자가 링크를 클릭하면 비밀번호를 설정하라는 안내가 나오고, 설정 후 바로 접근할 수 있어요.

![워크플로우 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044612928/original/4eZko-NSaJjo3mwadVL8xHDY9L0e9TIosw.png?1743998486)

### 가입 완료 페이지

가입을 마치면 사용자에게 확인 메시지와 **View Dashboard**(대시보드 보기) 버튼이 보여요. 이 버튼을 클릭하면 새 비밀번호를 설정하는 페이지로 이동해요. 비밀번호를 설정해야 코스에 들어갈 수 있어요.

![가입 완료 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044611001/original/jFqID9jOzIA6xusuFatf-pRXPGcd6cCbCw.png?1743992158)

### 비밀번호 설정

버튼을 클릭하면 새 비밀번호를 설정하는 화면이 나와요. 비밀번호를 설정하고 나면 코스 또는 멤버십 대시보드로 이동해요.

![비밀번호 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044612758/original/oBR8RMEtAb1yJfxinKsaPPMKAW5izf2pjA.png?1743998098)

### 비밀번호 재설정

사용자가 비밀번호를 잊어버리면 로그인 페이지에서 **비밀번호 찾기**를 클릭해요. 이메일을 입력하면 비밀번호 재설정 링크를 받을 수 있어요. 이 링크를 클릭하면 새 비밀번호를 설정하는 화면으로 이동하고, 재설정이 끝나면 코스나 포털에 자동으로 로그인돼요. 아래 이미지는 **비밀번호 찾기**로 재설정 링크를 요청했을 때 사용자가 받는 이메일 예시예요.

```
비밀번호 재설정 링크는 2시간 후에 만료돼요. 정해진 시간 안에 비밀번호를 재설정하세요.
```

![비밀번호 재설정 이메일 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044613562/original/74YDK23_UOpCXiG4ntAYbfK7pABJzrOsEA.png?1744000459)

```
선택 보안 단계: 비밀번호를 재설정하거나 변경할 때 모든 기기의 활성 세션을 무효화하도록 선택할 수 있어요. 다른 기기에 계정이 로그인되어 있다고 의심될 때 사용하세요.
```

## 자주 묻는 질문

### 새 사용자가 비밀번호 설정 이메일을 받게 하려면 어떻게 해야 하나요?

사용자의 이메일 주소가 정확한지 확인하세요. 시스템이 만드는 **Courses Login URL**(코스 로그인 URL) 이메일이 켜져 있는지도 확인하세요. 이메일 발송 로그에서 이메일이 제대로 발송됐는지 확인할 수 있어요.

### 사용자가 비밀번호 재설정 이메일을 받지 못했다고 하면 어떻게 하나요?

시스템에 등록된 사용자의 이메일 주소를 확인하고, 이메일 발송 로그도 살펴보세요. 이메일이 스팸으로 분류되지 않도록 이메일 도메인이 SPF, DKIM 등으로 올바르게 인증되어 있는지도 확인하세요. 필요하면 이메일을 직접 다시 보낼 수 있어요.

### 관리자가 사용자 대신 비밀번호를 재설정할 수 있나요?

아니요. 보안상 관리자는 사용자의 비밀번호를 직접 재설정할 수 없어요. 대신 사용자에게 **비밀번호 찾기** 기능을 쓰도록 안내하거나, 시스템에서 비밀번호 설정 이메일을 다시 보내 주세요.

### 사용자의 비밀번호 설정 문제는 어떻게 확인하고 해결하나요?

CRM에서 사용자의 계정 상태를 확인해 멤버십 포털에 제대로 추가되어 있는지 보세요. 이메일 발송 로그에서 반송이나 스팸 필터링 같은 문제가 있는지도 살펴보세요. 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.
