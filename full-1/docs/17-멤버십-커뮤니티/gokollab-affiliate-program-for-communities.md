# GoKollab 커뮤니티 제휴 프로그램

GoKollab의 커뮤니티 제휴(Community Affiliates)를 쓰면 열성적인 멤버를 커뮤니티 성장의 동력으로 만들 수 있어요. 이 문서에서는 프로그램이 어떻게 운영되는지, 누가 참여할 수 있는지, 소유자와 멤버가 각자 어디에서 제휴 도구를 여는지 안내해요. 커미션 비율(%)을 설정하는 곳, 대시보드에 추적 내역이 표시되는 방식, 소유자가 지급을 직접 처리하는 방법도 알려 드려요. 지급은 Kollab이 아니라 소유자가 직접 처리해요.

## 커뮤니티 제휴란?

커뮤니티 제휴는 GoKollab 커뮤니티 안에서 운영하는 추천 프로그램이에요. 프로그램을 켜면 유료 멤버에게 개인 초대 링크가 주어져요. 초대받은 사람이 커뮤니티에 가입해 멤버십 비용을 결제하면, 추천한 멤버는 커뮤니티 소유자가 정한 비율만큼 커미션을 받아요. 멤버의 진짜 추천으로 커뮤니티가 성장하도록 돕는 구조예요.

커뮤니티 제휴는 GoKollab에서만 쓸 수 있어요. 설정은 간단하고, 소유자가 커미션과 지급을 직접 관리할 수 있어요.

## 커뮤니티 제휴의 주요 장점

장점을 알아 두면 팀과 멤버에게 프로그램을 소개하기 쉬워요. 추천이 어떻게 매출과 보상으로 이어지는지 모두가 이해할 수 있어요.

- 입소문 성장: 신뢰하는 멤버의 추천으로 더 좋은 품질의 가입자가 들어와요.
- 낮은 고객 확보 비용: 광고에 쓰던 비용을 소유자가 직접 정하는 성과 기반 커미션으로 돌릴 수 있어요.
- 멤버 충성도: 커뮤니티 성장에 기여한 열성 멤버에게 보상할 수 있어요.
- 소유자 직접 관리: 커미션 비율을 설정하고, 성과를 확인하고, 지급을 직접 처리해요.
- 명확한 귀속: 개인 초대 링크로 유료 가입이 어느 추천인의 성과인지 정확히 구분돼요.

## 멤버 추천 커미션

커미션이 생기는 기준이 분명하면 분쟁을 줄이고 운영하기도 쉬워요.

- 새 멤버가 추천인의 초대 링크로 들어와 유료 멤버십 결제를 마치면 커미션이 적립돼요.
- 커미션 비율(%)은 커뮤니티 소유자가 정하고, 조건에 맞는 추천에 적용돼요.
- 수익은 계속 쌓이고, 소유자가 지급을 처리할 때 지급돼요.

## 자동 생성되는 추천 링크

초대 링크가 쓰기 쉬워야 멤버가 더 많이 참여해요. 멤버가 자기 링크를 어디에서 찾는지, 추천이 어떻게 추적되는지 알려 주세요.

- 유료 멤버라면 누구나 내 커뮤니티용 고유 초대 링크를 쓸 수 있어요.
- 멤버는 링크를 복사해서 소셜 채널, 이메일, 다이렉트 메시지 등으로 공유할 수 있어요.
- 고정 게시글과 온보딩 이메일로 프로그램을 알리면 초반 참여를 끌어올리기 좋아요.

## 커미션 설정과 지급 책임

소유자가 보상 구조를 정하고, 지급 시기와 방법도 직접 관리해요. 그래서 각자의 업무 방식에 맞게 운영할 수 있어요.

- 커미션 비율(Commission %): 유료 멤버십 가입으로 이어진 추천에 적용되는 전체 커미션 비율을 소유자가 설정해요.
- 지급은 소유자가 직접 처리: 지급은 Kollab이 아니라 커뮤니티 소유자가 직접 관리해요. 지급 방법(예: 계좌 이체)과 시기는 내부 처리 방식에 맞게 정하세요.
- 상태 업데이트: 소유자가 지급 상태를 **완료** 또는 **실패**로 직접 표시해요. 그러면 추천인이 대시보드에서 정확한 상태를 볼 수 있어요.

## 커뮤니티 소유자용 화면

제휴 메뉴 위치, 커미션 비율 설정, 추천 성과 확인 방법을 안내해요. 이 내용을 알면 지급을 차분하게 처리할 수 있어요.

### 커미션 비율 설정하기

1. **Kollab Studio**(Kollab 스튜디오)로 이동해요.
2. 내 커뮤니티 옆의 케밥 메뉴(점 세 개)를 클릭해요.
3. **제휴**를 선택해요.
4. 오른쪽 위에서 **Commission %**(추천 한 건당 지급하는 보상 비율)를 입력하고 저장해요.

![커뮤니티 옆 케밥 메뉴에서 제휴를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056054086/original/W8zf1uzK3cgEyEgIlmFTlHisLvg4bPQaeg.png?1760532214)

![오른쪽 위에서 Commission %를 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056054217/original/kTwXykd9KepgNUewf858N_gJJDGyIVG1Hg.png?1760532237)

### 대시보드 살펴보기 (소유자)

- **Revenue from affiliates**(제휴 매출): 추천으로 생긴 추가 멤버십 매출이에요.
- **Total payouts**(총 지급액): 지금까지 제휴 멤버에게 이미 지급한 커미션의 합계예요.

### 추천 표 항목

- **Invitee name**(초대받은 사람 이름): 초대받은 새 멤버예요.
- **Referred by**(추천인): 초대를 보낸 기존 커뮤니티 멤버예요.
- **Joining status**(가입 상태): 초대받은 사람이 결제하기 전에는 **초대됨**으로 표시돼요. 결제하면 **Joined**(가입 완료)로 바뀌어요.
- **Total Payouts**(지급 완료 금액): 해당 추천에 대해 지금까지 지급한 금액이에요.
- **Pending Payouts**(지급 대기 금액): 해당 추천에 대해 아직 지급하지 않은 금액이에요.

### 지급 상태

- **완료**: 소유자가 지급을 마친 것으로 표시했어요.
- **대기 중**: 아직 지급하지 않았거나 지급을 처리하는 중이에요.
- **실패**: 이체가 되지 않았어요(예: 은행 정보가 잘못된 경우).

![추천 표와 지급 상태가 보이는 소유자 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056056137/original/4EkiYAtHeh9QnBsK0pYcKurd_HZ87DS_ow.png?1760533121)

### 작업

**작업** 열에서 체크 표시(완료) 또는 X 표시(실패)를 클릭해 지급 상태를 직접 바꿀 수 있어요. 추천인의 대시보드에도 바뀐 상태가 반영돼요.

### 멤버의 은행 정보 받기

추천 표 오른쪽 위에서 **CSV 다운로드**를 클릭하면 지급 처리에 필요한 은행 정보를 받을 수 있어요.

## 추천인(커뮤니티 멤버)용 화면

멤버는 자신의 추천 성과와 지급 상태를 확인할 수 있어요. 얼마를 벌었고 얼마가 대기 중인지 한눈에 알 수 있어요.

### 내 제휴 대시보드 열기

1. 오른쪽 위의 **Profile Icon**(프로필 아이콘)을 클릭해 계정 메뉴를 열어요.
2. **제휴**를 클릭해요.
3. 제휴 커미션을 제공하는 커뮤니티만 표시돼요.

![프로필 아이콘을 눌러 계정 메뉴에서 제휴를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056059503/original/anzEYz5n41wbm_mle2DtMygRiZMalokz2A.png?1760534679)

![제휴 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056054680/original/3zNV9jTX7mZE55DwW2BxEvQHNd0-FoJf7g.png?1760532402)

### 대시보드에 표시되는 정보

- **Account Balance**(계정 잔액): 아직 받지 못한 금액이에요.
- **수익**: 이미 받은 금액의 합계예요.

{% hint style="warning" %}
수익을 지급받으려면 추천을 시작하기 전에 은행 정보를 입력하세요.
{% endhint %}

### 추천 표 항목 (멤버)

- **Invitee name**(초대받은 사람 이름): 내가 초대한 멤버예요.
- **Joined Status**(가입 상태): 구매하지 않았으면 **초대됨**, 결제했으면 **Joined**로 표시돼요.
- **수익**: 해당 추천으로 번 커미션의 합계예요.
- **Pending Payouts**(지급 대기 금액): 커뮤니티 소유자가 아직 지급하지 않은 커미션이에요.

### 지급 상태

- **완료**: 지급을 받았어요.
- **대기 중**: 아직 지급이 처리되지 않았어요.
- **실패**: 지급이 되지 않았어요. 자세한 내용은 커뮤니티 소유자에게 문의하세요.

## 자주 묻는 질문

### 초대 링크는 누가 받을 수 있나요?
커뮤니티의 유료 멤버에게 개인 초대 링크가 주어져요.

### 커미션은 언제 생기나요?
초대받은 사람이 멤버의 링크로 가입해 유료 멤버십 결제를 마치면 생겨요.

### 커미션 비율(%)은 어디에서 설정하거나 바꾸나요?
소유자는 **Kollab Studio** > 케밥 메뉴(점 세 개) > **제휴** > **Commission %**(오른쪽 위)에서 설정해요.

### 지급은 누가 처리하나요?
지급은 Kollab이 아니라 커뮤니티 소유자가 직접 처리해요.

### 소유자는 지급 상태를 어떻게 바꾸나요?
추천 표에서 체크 표시를 클릭하면 **완료**, X 표시를 클릭하면 **실패**로 바뀌어요.

### 추천인도 지급 상태가 바뀐 것을 볼 수 있나요?
네. 추천인은 제휴 대시보드에서 **완료**, **대기 중**, **실패** 상태를 볼 수 있어요.

### 소유자는 지급에 필요한 멤버의 은행 정보를 어떻게 받나요?
추천 표 오른쪽 위에서 **CSV 다운로드**를 클릭하세요.
