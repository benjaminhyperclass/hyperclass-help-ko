# 오퍼 기간 설정: 이용 만료일과 시작일 지정

오퍼에 이용 기간이나 이용 시작일을 정해 두면, 기간이 끝났을 때 멤버의 코스 이용 권한이 자동으로 사라져요. 이 문서에서는 이용 기간(만료)과 이용 시작일을 설정하는 방법을 안내해요.

## [[동영상](https://www.youtube.com/embed/86eJxE6fq3Y?&wmode=opaque)](https://youtu.be/86eJxE6fq3Y)

## 개요

코스 제작자는 멤버가 가입한 날부터 정해진 기간 동안만 코스를 이용하도록 설정할 수 있어요. 가입일부터 6개월, 2개월, 1주, 하루처럼 원하는 기간을 정할 수 있어요. 기간이 끝나면 이용 권한이 자동으로 회수되므로 멤버십을 관리하기 쉬워요.

이용 시작일도 따로 지정할 수 있어요. 오퍼가 정해 둔 날짜에 맞춰 시작되도록 할 때 쓰세요.

## 이용 기간 설정

### 1단계: 오퍼 이용 기간 정하기

1. 수정할 오퍼를 선택하거나 새 오퍼를 만드세요.
2. 오퍼 상세 페이지에서 **오퍼 접근 권한** 섹션을 찾으세요.
3. **Restrict access to specific amount of days**(특정 일수로 접근 제한) 체크박스를 선택하세요.
4. 이용 기간을 일 단위로 입력하세요.
   - 6개월: `180` (한 달을 30일로 계산)
   - 2개월: `60`
   - 1주: `7`
   - 하루: `1`

   ![오퍼 접근 권한 섹션의 이용 기간 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155024128447/original/H-fYxR7ANC7R9msJ7KCoLff8ZAwYoTPpmg.png?1712569701)

### 2단계: 저장 및 적용

1. 설정한 이용 기간이 맞는지 확인하세요.
2. 맞으면 **변경사항 저장**을 클릭하세요. 이 기간은 멤버의 가입일부터 오퍼에 적용돼요.
3. 저장한 뒤에는 오퍼를 게시하세요.

미리 정해 둔 만료일이 되면 시스템이 멤버의 코스 콘텐츠 이용 권한을 자동으로 회수해요.

## 이용 시작일 지정

### 1단계: 오퍼 시작일 정하기

1. 수정할 오퍼를 선택하거나 새 오퍼를 만드세요.
2. 오퍼 상세 페이지에서 **오퍼 접근 권한** 섹션을 찾으세요.
3. **특정 날짜부터 이용 시작** 체크박스를 선택하세요.
4. **날짜 입력**에서 원하는 날짜를 입력하세요. 오퍼는 이 날짜에 시작돼요.

정해 둔 날짜에 맞춰 멤버에게 콘텐츠를 공개하면 제품 출시나 사전 판매에 잘 맞아요.

### 시작일 이전에 가입하면

오퍼 시작일 전에 가입한 멤버는 코스 페이지로 이동하지만, 코스를 시작하거나 강의와 콘텐츠를 볼 수 없어요. 개요 페이지만 볼 수 있어요.

![시작일 전에 가입한 멤버에게 보이는 코스 개요 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155024132834/original/OlHy32AhjPlbgKwZWvEL2P3e9gqAVmketw.png?1712572484)

{% hint style="info" %}
코스 제작자는 이용 시작일이나 만료일 중 하나만 선택할 수 있고, 둘 다 함께 설정할 수도 있어요.
{% endhint %}

## 자주 묻는 질문

### 학습자가 이미 이용 중인 구독이 있는데 같은 코스의 오퍼를 추가로 구매하면 어떻게 되나요?

새 오퍼의 유효 기간이 기존 이용 권한과 자동으로 합쳐져요. 가장 최근 구매를 기준으로 끊김 없이 이용할 수 있어요.

### 멤버가 같은 코스의 다른 오퍼로 업그레이드하거나 변경하면 어떻게 되나요?

새 오퍼의 유효 기간에 맞춰 코스 이용 기간이 연장돼요. 새 오퍼의 유효 기간이 우선 적용되므로, 멤버는 가장 유리한 이용 조건을 받을 수 있어요.
