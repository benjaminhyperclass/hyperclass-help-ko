# 워크플로우로 그룹 가입 요청 자동 처리

멤버십 질문에 대한 답변을 바탕으로 그룹 가입 요청을 자동으로 검토하고 처리하는 워크플로우를 만들 수 있어요. 가입 요청을 하나하나 직접 확인하는 시간을 줄이고 싶을 때 이 문서를 참고하세요.

## 이 문서에서 알아볼 내용

이 문서에서는 하이퍼클래스 커뮤니티의 **Requested to Join Group**(그룹 가입 요청) 워크플로우 트리거를 사용해 가입 요청을 자동으로 처리하는 방법을 설명해요. 그룹과 멤버십 질문 답변으로 요청을 걸러 내는 방법, 답변에 따라 사용자를 승인하거나 거절하는 워크플로우를 만드는 방법을 알려 드려요.

끝까지 읽으면 수동 검토 작업을 줄이고, AI로 스팸 제출을 걸러내고, 커뮤니티 그룹에 맞는 멤버십 자동화를 만들 수 있어요.

## Requested to Join Group 트리거란?

**Requested to Join Group**(그룹 가입 요청)은 하이퍼클래스 커뮤니티에서 쓸 수 있는 워크플로우 트리거예요. 사용자가 커뮤니티 그룹에 가입을 요청할 때마다 실행돼요. 관리자는 이 트리거로 가입 요청의 검토, 분류, 승인 과정을 자동화할 수 있어요.

가입 요청을 일일이 검토하는 대신, 정해 둔 기준에 따라 워크플로우가 요청을 처리하게 만들 수 있어요. 사용자가 접근을 요청한 순간 멤버십 질문에 대한 답변을 포함한 관련 데이터가 모두 워크플로우에서 쓸 수 있는 상태가 돼요.

그래서 커뮤니티가 커져도 누가 들어오는지 품질을 관리하면서, 그룹 멤버십을 효율적으로 운영할 수 있어요.

## 주요 장점

그룹 가입 요청을 자동화하면 관리자의 업무 부담이 줄고 멤버의 경험도 좋아져요. 이 트리거의 핵심 장점은 다음과 같아요.

- 더 똑똑한 멤버십 자동화: 가입 요청을 하나씩 검토하지 않아도 자동으로 처리해요. 관리 업무가 줄고 승인도 빨라져요.
- 답변에 따른 동적 필터링: 사용자가 가입을 요청하면서 입력한 실제 답변을 기준으로 워크플로우를 만들 수 있어요. 요청마다 상황에 맞게 자동화가 동작해요.
- AI를 활용한 검토: 멤버십 답변을 GPT 프롬프트에 넣어 스팸, 성의 없는 답변, 의심스러운 제출을 가려낼 수 있어요. 승인 과정에 AI 검토 단계를 더하는 셈이에요.
- 관리자의 수고 감소: 커뮤니티가 커져도 누가 들어올지 직접 관리하면서 더 빠르게 운영할 수 있어요. 그만큼 중요한 커뮤니티 업무에 시간을 쓸 수 있어요.
- 커뮤니티와 워크플로우의 더 나은 연결: 가입 요청으로 더 유연하고 똑똑한 워크플로우 흐름을 만들 수 있어요. 커뮤니티와 자동화 시스템이 더 긴밀하게 이어져요.

## 사용할 수 있는 필터

**Requested to Join Group** 트리거에는 두 가지 필터가 있어요. 이 필터가 워크플로우가 실행되는 시점과 자동화에 쓸 수 있는 데이터를 정해요. 정확하게 원하는 요청만 처리하려면 두 필터를 이해해 두는 게 좋아요.

1. **Group**(그룹)
   - 워크플로우가 지켜볼 커뮤니티 그룹을 선택해요. 사용자가 선택한 그룹에 가입을 요청하면 워크플로우 트리거가 실행돼요.
   - 커뮤니티 안의 그룹마다 다른 자동화 규칙을 만들 수 있어요.
2. **Membership Question Responses**(멤버십 질문 응답)
   - 그룹을 선택하면 그 그룹에 설정된 멤버십 질문이 모두 동적 필터로 나타나요.
   - 질문마다 별도의 필터 옵션이 생겨요. 가입 요청 과정에서 사용자가 특정 질문에 어떻게 답했는지에 따라 조건을 만들 수 있어요.

## 워크플로우에서 멤버십 질문 응답 활용하기

멤버십 질문 응답은 트리거 필터뿐 아니라 워크플로우 전체에서 쓸 수 있어요. 사용자가 접근을 요청하며 제출한 내용을 바탕으로 상황에 맞는 자동화를 만들 수 있어요.

워크플로우의 여러 곳에서 이렇게 활용할 수 있어요.

1. **If/Else**(조건 분기) 조건
   - 사용자의 응답을 판단하는 **If/Else** 단계를 추가해요.
   - 예를 들어 "가입하려는 이유가 무엇인가요?"에 대한 답변에 특정 키워드가 들어 있는지 확인하고, 결과에 따라 서로 다른 승인 경로로 보낼 수 있어요.
2. 스팸 감지를 위한 GPT 프롬프트
   - 멤버십 질문 응답을 GPT 워크플로우 액션에 넘겨 제출 내용의 품질과 의도를 분석해요.
   - 예를 들어 사용자의 답변을 GPT 프롬프트로 보내 "이 응답이 스팸처럼 보이나요, 정상적인 요청처럼 보이나요?"라고 물을 수 있어요.
   - AI의 평가에 따라 워크플로우가 정상 요청은 자동으로 승인하고, 의심스러운 요청은 수동 검토용으로 표시하고, 명백한 스팸은 거절할 수 있어요. 이 모든 과정에 관리자가 개입하지 않아도 돼요.

{% hint style="info" %}
더 똑똑한 멤버십 워크플로우 만들기: 그룹 필터, 멤버십 질문 응답, AI 기반 로직을 함께 쓰면 커뮤니티 규모에 맞춰 확장되는 승인 시스템을 만들 수 있어요.
{% endhint %}

## 그룹 가입 요청 자동화 설정하기

멤버십 질문에 대한 사용자 답변을 바탕으로 그룹 가입 요청을 자동 처리하는 워크플로우는 다음 단계를 따라 만들어요.

1. 새 워크플로우를 만들어요.
   1. 왼쪽 메뉴에서 **자동화 > 워크플로우**로 이동하세요.
   2. **워크플로우 추가**를 클릭하세요.
   3. "프리미엄 그룹 가입 자동 승인"처럼 알아보기 쉬운 이름을 붙이세요.

   ![Requested to Join Group 트리거를 선택한 워크플로우 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078274697/original/8ObdGBXWKea-ZZpM6_0k20e-99TOh88vqg.png?1786557978)

2. 워크플로우 빌더에서 **Requested to Join Group**(그룹 가입 요청)을 트리거로 선택하세요. 사용자가 커뮤니티 그룹에 가입 요청을 제출할 때마다 워크플로우가 시작돼요.

   ![워크플로우 트리거 설정에서 그룹 필터 선택 드롭다운이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078274744/original/Ty3O25UeIQ6jV3n9E3vu85PY7gRRGlSs_w.png?1786558056)

3. **Group**(그룹) 필터에서 이 워크플로우가 지켜볼 커뮤니티 그룹을 선택하세요. 그룹을 선택하면 그 그룹에 설정된 멤버십 질문이 자동으로 불러와져요.

   ![선택한 그룹에 따라 멤버십 질문 응답 필터가 채워진 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078274753/original/KbtEtn6eSnCfM7zQhdJdckNHj7E8974kSQ.png?1786558088)

4. (선택) 멤버십 질문 응답으로 필터를 추가하세요.
   1. 사용자가 특정 답변을 입력했을 때만 워크플로우가 실행되게 하려면 **Membership Question Responses**(멤버십 질문 응답) 필터를 사용하세요.
   2. 선택한 그룹에 설정된 질문이 필터 옵션으로 나타나요.
   3. "산업 = 마케팅", "경험 수준 = 고급"처럼 조건을 설정하면 워크플로우가 실행되는 경우를 좁힐 수 있어요.

5. 워크플로우 로직을 만들어요. 트리거가 실행됐을 때 일어날 일을 정하는 워크플로우 액션을 추가하세요. 자주 쓰는 액션은 다음과 같아요.
   - 멤버십 질문 응답을 판단하는 **If/Else** 조건 추가
   - 스팸 감지나 품질 확인을 위해 응답을 GPT 프롬프트로 전송
   - 조건에 맞으면 요청을 자동으로 승인하고 사용자를 그룹에 추가
   - 제출 내용이 의심스러우면 관리자에게 수동 검토용 알림 이메일 발송
   - 스팸이 감지되면 요청을 자동으로 거절

   ![If/Else 로직과 GPT 연동으로 가입 요청을 처리하는 완성된 워크플로우 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078274836/original/R6Bn6vR8OryqQTE3eZsoTlhi5uTk8BvgiA.png?1786558198)

6. 워크플로우를 활성화하세요. 워크플로우 구성이 끝나면 **Publish**(게시) 토글을 켜세요. 선택한 그룹의 가입 요청을 지켜보다가 설정한 액션을 자동으로 실행해요.

## 자주 묻는 질문

### 그룹마다 다른 워크플로우를 만들 수 있나요?
네. 워크플로우를 여러 개 만들고, 각각 **Group** 필터로 특정 그룹을 지정할 수 있어요. 그룹마다 승인 로직, 분류 규칙, 자동화 액션을 다르게 설정할 수 있어요.

### 그룹에 멤버십 질문이 하나도 없으면 어떻게 되나요?
멤버십 질문이 없는 그룹이면 워크플로우 트리거 설정에 **Membership Question Responses** 필터가 나타나지 않아요. 사용자가 그 그룹에 가입을 요청하면 워크플로우는 그대로 실행돼요. 다만 답변이 없으니 답변으로 필터링하거나 판단할 수는 없어요.

### 멤버십 질문 응답을 GPT 프롬프트에 넣어 스팸을 감지할 수 있나요?
네. 멤버십 질문 응답을 커스텀 변수로 GPT 워크플로우 액션에 넘길 수 있어요. 예를 들어 "이 응답이 스팸처럼 보이나요?"라고 묻는 GPT 프롬프트를 만들고, 사용자의 답변을 입력값으로 넣어 보세요. AI의 평가에 따라 요청을 승인하거나 거절하거나 수동 검토용으로 표시하도록 워크플로우를 나눌 수 있어요.

### 특정 답변을 기준으로 가입 요청을 자동 승인할 수 있나요?
네. 트리거의 **Membership Question Responses** 필터를 쓰거나 워크플로우에 **If/Else** 조건을 추가해 특정 답변을 확인하세요. 조건이 맞으면 요청을 승인하고 사용자를 그룹에 자동으로 추가하는 워크플로우 액션을 더하면 돼요.

### 모든 종류의 멤버십 질문에서 이 트리거를 쓸 수 있나요?
네. 선택한 그룹에 설정된 모든 유형의 멤버십 질문 응답을 가져와요. 텍스트 입력, 객관식, 그 밖의 입력 형식도 포함돼요. 그룹을 선택하면 각 질문을 필터와 워크플로우 변수로 쓸 수 있어요.

### 특정 조건이 충족되면 관리자에게 알림을 보낼 수 있나요?
네. 워크플로우에 이메일, SMS, 내부 알림 액션을 추가하세요. 예를 들어 멤버십 질문 응답이 VIP 여부처럼 특정 조건에 해당하면 관리자 팀에 알림을 보내, 가치가 높은 멤버를 직접 환영하게 할 수 있어요.

### 가입 요청이 제출된 뒤 어떤 액션을 자동화할 수 있나요?
하이퍼클래스에서 쓸 수 있는 워크플로우 액션은 모두 쓸 수 있어요. 요청 승인 또는 거절, 다른 그룹에 추가하거나 태그 추가, 환영 이메일 발송, CRM 레코드 생성, 다른 워크플로우 실행, 응답 데이터에 따라 요청을 다른 승인 경로로 보내기 등이 가능해요.

### 이 자동화를 설정하려면 코딩을 할 줄 알아야 하나요?
아니요. 설정은 모두 하이퍼클래스의 워크플로우 빌더에서 해요. 트리거를 고르고, 드롭다운 메뉴로 필터를 설정하고, 워크플로우 단계를 끌어다 놓아 액션을 추가하면 돼요. 코딩은 필요 없어요.
