# 코스 강의에 오디오 업로드하기

코스 강의에 오디오 파일을 바로 추가할 수 있어요. 이 문서에서는 오디오 강의를 추가하는 방법과, 지원하는 파일 형식, 수강생이 쓸 수 있는 재생 옵션을 안내해요.

## 코스에 오디오 강의 추가하기

### 1. 오디오 업로드하기

한 번의 클릭으로 강의에 오디오 파일을 업로드할 수 있어요. 오디오 강의를 만들 수 있어서 콘텐츠를 더 다양한 방식으로 전달할 수 있어요.

1. **멤버십 > 코스 > 강의**로 이동해요.
2. 강의에 추가할 항목으로 **audio**(오디오)를 선택해요.
3. 오디오 파일을 업로드해요. 오디오만으로 강의를 만들어도 되고, 텍스트 콘텐츠와 함께 써도 돼요.
4. 오디오를 업로드한 뒤에는 강의를 게시해야 수강생이 볼 수 있어요.

![강의에 오디오를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033398964/original/o9i0dgkFhxaEKsEYV7qX1vKfgIgF_Nbdcg.png?1727112559)

### 2. 지원하는 오디오 형식

여러 기기에서 문제없이 재생되도록 다양한 오디오 파일 형식을 지원해요. 아래 형식의 파일을 업로드하고 관리할 수 있어요.

- MP3
- AAC
- WAV

업로드한 오디오 콘텐츠는 다음 기기에 맞게 최적화돼요.

- 데스크톱
- 태블릿
- 휴대폰

수강생이 어떤 기기에서든 오디오 강의를 들을 수 있어서, 코스를 더 편하게 이용할 수 있어요.

### 3. 오디오 썸네일 자동 설정

오디오 강의의 썸네일은 강의 썸네일을 그대로 가져와요. 그래서 모든 코스 콘텐츠에서 브랜딩과 화면 구성을 일관되게 유지할 수 있어요.

### 4. 수강생을 위한 재생 옵션

수강생은 오디오를 들을 때 다음과 같은 옵션을 쓸 수 있어요.

- 재생 속도 조절
- 재생 속도 설정

![수강생 화면의 오디오 재생 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033366878/original/3KJAtpfXFT46grN9wD6rPfid3mH5WL42tg.png?1727091830)

{% hint style="info" %}
오디오 파일은 아직 스냅샷과 복제를 지원하지 않아요. 곧 지원될 예정이에요.
{% endhint %}
