# 멤버십 코스에 평가·퀴즈 만들기

멤버십 코스에 퀴즈(평가)를 넣는 방법을 안내해요. 질문을 만들고 합격 기준을 정하는 방법, 수강생의 성적을 확인하고 퀴즈 결과를 분석하는 방법을 알 수 있어요.

## 멤버십 평가·퀴즈란?

평가(퀴즈)는 멤버십 코스 상품에 넣을 수 있는 짧은 시험이에요. 수강생이 얼마나 배웠는지 확인할 때 써요. 여러 가지 질문 유형을 쓸 수 있고, 원하면 합격·불합격 기준도 정할 수 있어요. 퀴즈로 시험과 피드백을 더하면 코스를 더 알차게 운영할 수 있어요.

## 멤버십 평가의 장점

평가를 쓰면 학습 진행 정도를 측정하고, 배운 내용을 기억에 남기고, 수강생에게 맞춤 피드백을 줄 수 있어요. 수료증이 있는 코스나 모듈이 여러 개인 커리큘럼에 특히 유용해요.

- 강의, 카테고리, 상품 어디에든 상호작용 학습 요소를 넣을 수 있어요.
- 합격 점수를 정해 학습 기준을 만들 수 있어요.
- 수강생에게 바로 피드백을 줄 수 있어요.
- 여러 번 응시하고 답안을 다시 볼 수 있게 할 수 있어요.
- 분석에서 성적과 제출 내역을 확인할 수 있어요.
- 코스 내용을 복습하게 하고 참여도를 높일 수 있어요.

## 멤버십 코스에서 평가 설정하기

다음 단계를 따라 코스에 평가를 만들고 게시하세요. 퀴즈를 넣을 위치를 고르고, 질문과 채점 규칙을 직접 설정할 수 있어요.

### 멤버십의 상품 탭으로 이동하기

평가나 퀴즈를 만들려면 먼저 왼쪽 메뉴에서 **멤버십**을 클릭하세요. 그다음 상단의 **코스** 드롭다운에서 **상품**을 선택하세요. 상품(코스) 라이브러리가 열리고, 여기서 멤버십 코스를 새로 만들거나 기존 코스를 편집할 수 있어요.

![멤버십 메뉴에서 코스 드롭다운의 상품 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044472064/original/mN49xCR0iNOcxuMjERDJQ6Q5GHGRf6N8JQ.png?1743681780)

### 멤버십 상품 확인하기

**상품** 탭에 들어가면 기존 코스가 갤러리 형태로 보여요. 각 상품 타일에는 코스 제목과 멤버 수가 표시돼요. 편집하거나 평가를 추가할 상품을 클릭하세요.

![멤버십 상품 갤러리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044472100/original/mjnDZruUymxlD_fBvHy18DQU01b4ODzFVQ.png?1743681805)

### 카테고리를 펼쳐 콘텐츠 추가하기

코스 안에서는 **상품 구성**에서 강의와 평가를 정리할 수 있어요. 평가를 추가하려면 카테고리 옆의 **+ Add Content**(콘텐츠 추가)를 클릭하거나 오른쪽 위에 있는 같은 버튼을 클릭하세요.

![상품 구성에서 콘텐츠 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062788363/original/DbtzNguMHxat0r5dldzuPFzgd3uBeYOUpA.png?1768546474)

### 평가(과제·퀴즈) 추가하기

플러스 아이콘을 클릭하면 콘텐츠 드롭다운이 열려요. **과제 추가** 또는 **Add Quiz**(퀴즈 추가)를 선택하면 선택한 카테고리 안에 새 과제나 퀴즈가 만들어져요.

![콘텐츠 드롭다운에서 과제 추가 또는 퀴즈 추가 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062788392/original/zqo6sBnSVNsHf2k2egWH5I-KnVmsmCvdtw.png?1768546522)

### 평가 설정과 공개 상태 관리하기

평가를 만들면 콘텐츠 목록에 나타나요. 제목 옆의 아이콘으로 상태를 **Published**(게시됨), **Draft**(초안), **Locked**(잠김) 중에서 바꾸거나, 편집하거나, 삭제할 수 있어요.

![콘텐츠 목록에서 평가 상태 변경, 편집, 삭제 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062788626/original/DEevFLsgJtKwGE_1K91TevUVSgXUvF0gbQ.png?1768546727)

### 과제 편집기: 안내와 템플릿 업로드

작은 연필 아이콘(편집 버튼)을 클릭하면 과제 편집기가 열려요. 여기서 내용과 설정을 정할 수 있어요.

1. 과제 제목을 입력하세요. 이 제목이 수강생에게 보여요.
2. 채점이 필요 없는 과제라면 **미채점 과제** 체크박스를 켜세요. 평가 없이 제출만 받을 수 있어요.
3. 과제를 보여 주는 썸네일 이미지를 올릴 수 있어요. 브랜딩을 하거나 과제를 한눈에 알아보게 할 때 도움이 돼요.
4. **안내** 섹션에 수강생이 무엇을 제출해야 하는지 알려 주는 설명을 쓰세요. 서식 도구로 중요한 내용을 강조하거나 관련 자료 링크를 넣을 수 있어요.
5. **템플릿 업로드** 영역에는 수강생이 과제를 할 때 쓸 참고 문서나 시작 파일(.docx, .pdf, .pptx 등)을 올릴 수 있어요.
6. **확인 메시지** 필드에는 수강생이 과제를 제출한 뒤 보게 될 메시지를 쓰세요. 격려의 말, 다음 할 일, 간단한 감사 인사 등 원하는 내용을 쓸 수 있어요.

![과제 편집기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062788739/original/WxF-fn5hOfyeiV6UaCUTGbQDlwyULjmfLA.png?1768546803)

### 퀴즈 편집기: 설정과 사용자 지정 옵션

평가 유형으로 **Add Quiz**(퀴즈 추가)를 선택하면 퀴즈 설정 편집기가 열려요. 여기서 퀴즈 전체를 만들고 꾸밀 수 있어요.

1. **퀴즈 제목**을 입력하세요. 수강생에게 보이는 제목이에요.
2. 수강생의 성적을 평가하려면 **이 퀴즈에 합격 점수 적용** 체크박스를 켜고, 합격으로 인정할 **합격 점수** 비율을 입력하세요.
3. **퀴즈 썸네일** 이미지를 올릴 수 있어요. 수강생이 퀴즈를 한눈에 알아볼 수 있는 브랜드 이미지나 테마 이미지를 쓰면 좋아요.
4. **합격 확인 메시지**와 **불합격 확인 메시지** 필드에 결과에 따라 수강생에게 보여 줄 피드백을 쓰세요. 이 편집기에서는 텍스트 서식, 링크, 임베드 콘텐츠를 쓸 수 있어서 자세한 안내, 격려 문구, 참고 자료 링크도 넣을 수 있어요.
5. 설정을 마쳤으면 **질문 추가** 버튼을 클릭해 퀴즈를 만들기 시작하세요. 단일 선택과 복수 선택 질문을 추가할 수 있고, 질문마다 정답과 해설(선택)을 설정할 수 있어요.

이 편집기에서 수강생 화면과 성적 추적 방식이 모두 정해져요. 효과적인 평가를 만들 때 꼭 거쳐야 하는 단계예요.

![퀴즈 편집기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062788771/original/O3sfwqlf8qAhmD_vciNcUIMzGCaRm2uwRw.png?1768546859)

### 저장, 초안, 게시 옵션

편집을 마치면 오른쪽 위의 **Draft**, **미리보기**, **저장**, **삭제** 버튼으로 과제나 퀴즈의 공개 상태를 관리하세요. 나가기 전에 변경 사항을 꼭 **저장**하세요.

![편집기 오른쪽 위의 초안, 미리보기, 저장, 삭제 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062789017/original/Wh4pNKmQTa0Cnv3BMJuGede9PTBA8sSHrg.png?1768547087)

## 퀴즈를 제출하면 어떻게 되나요?

제출 후 어떤 화면이 나오는지 알아 두면 수강생 경험을 관리하기 쉬워요. 퀴즈를 어떻게 설정했는지에 따라 수강생이 받는 피드백이 달라져요.

**합격 점수를 켠 경우:** 수강생은 자기 점수와 문제별 정답·오답 여부를 볼 수 있어요. 정답 자체는 볼 수 없어요.

**합격 점수를 끈 경우:** 정답과 추가해 둔 해설도 함께 볼 수 있어요.

수강생은 이전 제출 내용을 다시 보고, 필요하면 퀴즈를 다시 풀 수 있어요. 복습하거나 성적을 높이는 데 도움이 돼요.

## 평가 결과 분석하기

CSV로 내보내면 퀴즈 원본 데이터를 오프라인에서 더 깊이 분석하거나 공유하고, 직접 리포트를 만들 수 있어요. 내보내기에는 적용해 둔 필터가 그대로 반영돼요. 다운로드하기 전에 기간, 상품 필터, 합격·불합격 상태를 먼저 설정하세요. 평가 결과를 내려받으려면 다음 단계를 따르세요.

#### 1단계: 분석으로 이동하기

왼쪽 메뉴에서 **멤버십**을 선택하세요. 그다음 상단 메뉴에서 **코스** 드롭다운을 클릭하고 **분석**을 선택하세요.

![멤버십의 코스 드롭다운에서 분석 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058581526/original/JnoS2_htzsSv4cweD09FjEwvc2XW4tRB6Q.png?1763402236)

#### 2단계: 평가 선택하기

**평가**를 선택하면 평가 결과를 볼 수 있어요.

![분석에서 평가 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058581587/original/Jt7LheIrN4WD8_oQTI_Pdkv_J-YpaBuJxQ.png?1763402316)

#### 3단계: 필터 적용

**상품** 또는 **Assessment Result**(평가 결과: **Processing**(처리 중), **Passed**(합격), **Failed**(불합격))를 기준으로 필터를 적용하세요.

각 행 옆의 눈 모양 아이콘을 클릭하면 개별 답안과 점수를 볼 수 있어요.

![상품과 평가 결과 필터를 적용한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058581845/original/eelOZovVgCmpf7Nj8_zmBOFo_FG8G28sbw.png?1763402580)

#### 4단계: 리포트 내보내기

오른쪽 위의 **내보내기** 버튼을 클릭해 리포트를 내보내세요. 선택한 필터가 내보내는 리포트에 적용돼요. 데이터 크기에 따라 리포트를 받는 방법이 2가지예요.

- 데이터가 적을 때(500행 이하)는 브라우저에서 바로 다운로드돼요.
- 데이터가 많을 때(500행 초과)는 브라우저 시간 초과를 막기 위해 평가 내보내기 파일이 준비되었다는 제목의 이메일이 오고, 이메일 안에 24시간 동안 쓸 수 있는 보안 링크가 들어 있어요. 보안을 위해 링크는 24시간이 지나면 만료돼요.

{% hint style="info" %}
관리자(Admin) 또는 강사(Instructor) 역할을 가진 사용자만 **내보내기** 버튼을 볼 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 같은 평가를 다른 상품이나 강의에서 다시 쓸 수 있나요?
아니요. 평가는 만든 상품과 위치에만 연결돼요.

### 수강생이 같은 퀴즈를 다시 풀 수 있나요?
네. 수강생은 평가를 다시 풀 수 있고, 가장 최근 결과를 볼 수 있어요.

### 수강생이 퀴즈를 제출하면 정답을 볼 수 있나요?
합격 점수를 켜지 않은 경우에만 볼 수 있어요. 합격 점수를 켠 경우에는 자기 답이 맞았는지만 볼 수 있어요.

### 평가 결과를 다운로드할 수 있나요?
네. **멤버십 > 분석 > 평가**에서 **내보내기**를 클릭하세요. 파일에는 제출 날짜, 수강생 이메일, 퀴즈 제목, 점수, 합격·불합격 상태, 질문별 응답이 들어 있어요. 데이터가 많으면 보안 이메일 링크로 받아요.
