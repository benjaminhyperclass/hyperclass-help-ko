# 커뮤니티 코스 필터 사용하기

커뮤니티 멤버가 **학습** 탭에서 코스를 **주제**, **난이도**, **언어**로 걸러 보고 **제목**, **최신순**, **오래된 순**으로 정렬하는 방법을 안내해요. 코스를 운영하는 분이 필터에 쓰이는 값을 설정하는 방법도 함께 설명해요.

하이퍼클래스 커뮤니티에서는 멤버가 **학습** 페이지에서 바로 코스를 **주제**, **난이도**, **언어**로 필터링할 수 있어요. 코스는 **제목**, **최신순**, **오래된 순**으로 정렬할 수도 있어요.

이 필터는 코스 빌더에서 설정한 코스 정보(메타데이터)를 바탕으로 작동해요. 이 문서에서 필터가 어떻게 작동하는지, 필요한 값은 어떻게 설정하는지, 멤버는 커뮤니티에서 어떻게 쓰는지 알아봐요.

{% hint style="info" %}
코스 접근 권한과 코스 필터는 달라요. 필터는 멤버가 이미 볼 수 있는 코스를 정리하고 찾는 데 도움을 줄 뿐이에요. 접근이 제한된 코스를 열어 주거나, 커뮤니티·코스·오퍼·수강 등록 권한을 바꾸지 않아요. 비공개 채널 기반 접근은 [비공개 채널 기반 코스 접근 권한](../커뮤니티/communities-private-channel-based-course-access.md)에서, 유료 코스는 [커뮤니티 안의 유료 코스](../커뮤니티/paid-courses-inside-communities.md)에서 확인하세요.
{% endhint %}

## 커뮤니티 코스 필터란?

커뮤니티 코스 필터는 코스에 지정된 **언어**, **난이도**, **주제** 값을 이용해 커뮤니티 **학습** 탭에 보이는 코스를 좁혀 주는 기능이에요.

코스가 많아져도 일일이 훑어볼 필요가 없어요. 원하는 주제, 수준, 언어에 맞게 필터를 조합하고, 결과를 정렬해서 더 빠르게 코스를 찾을 수 있어요.

## 코스 필터의 장점

코스가 많아지고 종류가 다양해질수록 필터가 있으면 학습 라이브러리를 훨씬 편하게 둘러볼 수 있어요. 코스 정보를 정확하게 입력해 두면 코스를 운영하는 분도 학습 콘텐츠를 일관되게 정리할 수 있어요.

- 빠른 코스 탐색: 코스가 많아도 내게 필요한 콘텐츠로 좁혀 볼 수 있어요.
- 더 알맞은 학습: **주제**, **난이도**, **언어**에 맞는 코스를 찾을 수 있어요.
- 유연한 필터링: 여러 조건을 함께 선택해 목록을 더 좁힐 수 있어요.
- 체계적인 코스 관리: 코스를 운영하는 분이 코스 설정에서 탐색용 정보를 직접 관리해요.
- 유연한 정렬: **제목**, **최신순**, **오래된 순**으로 코스를 정리할 수 있어요.
- 간편한 초기화: 적용한 필터를 모두 해제하고 전체 코스 목록으로 돌아갈 수 있어요.

## 사용할 수 있는 필터와 정렬 옵션

**학습** 페이지는 코스에 지정된 정보를 보고 멤버에게 보여 줄 필터 선택지를 정해요. 값을 명확하고 정확하게 지정해 두면 멤버가 알맞은 학습 콘텐츠를 이해하고 찾기 쉬워요.

| 항목 | 용도 |
| --- | --- |
| **주제** | 코스에 지정된 주제나 카테고리로 코스를 걸러 줘요. |
| **난이도** | 멤버가 자신의 경험 수준에 맞는 코스를 찾도록 도와줘요. |
| **언어** | 코스에 지정된 언어로 코스를 걸러 줘요. |
| **제목** | 볼 수 있는 코스를 코스 제목 순으로 정렬해요. |
| **최신순** | 정렬 결과에서 더 새로운 코스를 앞에 보여 줘요. |
| **오래된 순** | 정렬 결과에서 더 오래된 코스를 앞에 보여 줘요. |

## 커뮤니티에서 코스 필터가 작동하는 방식

커뮤니티 멤버는 **학습** 탭에서 자신이 볼 수 있는 코스를 둘러봐요. 필터는 각 코스에 지정된 정보를 기준으로 그 코스들을 좁혀 줘요. 학습 탭에 대한 자세한 내용은 [학습 탭(코스)](../커뮤니티/learning-tab-courses.md)을 참고하세요.

1. 멤버가 커뮤니티의 **학습** 탭을 열어요.
2. 멤버가 **주제**, **난이도**, **언어** 값을 하나 이상 선택해요.
3. 선택한 조건에 맞는 코스만 결과에 남아요.
4. 멤버가 정렬 옵션을 적용해 결과를 정리할 수 있어요.
5. 멤버가 **모두 초기화**를 선택하면 적용된 필터가 모두 해제돼요.

![커뮤니티 학습 탭의 코스 필터](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080661261/original/O1q9OeA50p18b0azyhbaPR39tnUwgVHQiQ.png?1789101962)

## 코스 태그와 커뮤니티 필터

커뮤니티 필터는 각 코스에 지정된 정보에 따라 작동해요. **언어**, **난이도**, **주제**는 코스를 찾을 때 쓰는 값이고, **학습** 페이지에서 코스를 어떻게 좁힐 수 있는지 결정해요. 코스 태그에 대해서는 [코스 태그](tags-in-courses.md) 문서도 참고하세요.

### 언어

**언어**는 코스에서 주로 쓰는 언어를 나타내요. 올바른 언어를 지정해 두면 멤버가 편하게 따라갈 수 있는 콘텐츠를 찾기 쉬워요.

### 난이도

**난이도**는 코스가 대상으로 하는 학습자의 경험 수준을 나타내요. 학습자에게 기대하는 지식이나 숙련도에 가장 가까운 옵션을 고르세요.

### 주제

**주제**는 코스를 주된 소재별로 정리해 줘요. 여러 학습 분야의 코스를 제공하는 커뮤니티라면 **주제** 값을 일관되게 쓰는 것이 특히 도움이 돼요.

![코스 필터 값이 지정된 코스 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080661450/original/0KYThUzgRf2lPmDwtk7RBri-k0M766V3kg.png?1789102277)

## 커뮤니티 코스 필터 설정하기

코스 정보가 정확해야 멤버가 알맞은 커뮤니티 필터로 코스를 찾을 수 있어요. 먼저 코스 값을 설정하고 저장한 뒤, 멤버에게 보이는 **학습** 화면을 확인하세요. 코스를 아직 만들지 않았다면 [시작하기 - 코스 출시하기](../../01-시작하기/커머스/getting-started-launch-a-course.md)를 먼저 참고하세요.

### 1단계: 코스 열기

탐색용 설정은 코스별 설정에서 관리해요. 커뮤니티 필터로 멤버가 찾았으면 하는 코스부터 열어 주세요.

1. **멤버십 > 코스**로 이동하세요.
2. 설정할 코스를 여세요.
3. **설정**을 선택하세요.

### 2단계: 코스 태그 찾기

**Course tags**(코스 태그) 영역에 코스 라이브러리 필터에서 쓰는 탐색용 정보가 있어요.

- **언어**
- **난이도**
- **주제**

### 3단계: 코스 값 지정하기

코스를 정확하게 나타내는 값을 고르세요. 정보를 일관되게 지정해야 필터가 더 유용하고, 코스가 엉뚱한 조건에 묶이는 일을 막을 수 있어요.

1. 알맞은 **언어**를 선택하세요.
2. 알맞은 **난이도**를 선택하세요.
3. 알맞은 **주제**를 선택하세요.
4. 저장하기 전에 값을 다시 확인하세요.

![코스 설정에서 언어, 난이도, 주제를 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080661435/original/afktLBTT1aJ1q6sEUybaGkJcrnlBWDlDcw.png?1789102244)

### 4단계: 코스 저장하기

**저장**을 선택하면 지정한 탐색용 정보가 코스에 적용돼요. 관련된 코스끼리는 가능한 한 같은 기준으로 값을 지정하세요. 그래야 멤버가 예측하기 쉬운 필터 결과를 받아요.

### 5단계: 커뮤니티에서 코스 확인하기

멤버에게 보이는 **학습** 페이지에서 직접 테스트해 보면 코스가 의도한 필터에 나타나는지, 코스 접근 규칙이 올바르게 적용되는지 확인할 수 있어요.

1. 해당 커뮤니티를 여세요.
2. **학습**을 선택하세요.
3. 접근 권한이 있어야 하는 멤버에게 코스가 보이는지 확인하세요.
4. 해당하는 **주제**, **난이도**, **언어** 필터를 적용하세요.
5. 기대한 결과에 코스가 나타나는지 확인하세요.
6. 필요하면 사용할 수 있는 정렬 옵션도 테스트하세요.

커뮤니티 자체를 설정하고 관리하는 방법은 [커뮤니티 설정, 맞춤 설정, 관리 방법](../how-to-setup-customize-and-manage-your-communities.md)을 참고하세요.

## 커뮤니티 멤버로 코스 필터링하기

필터를 쓰면 수강 등록이나 권한은 그대로 두고, 볼 수 있는 학습 콘텐츠를 원하는 방식으로 둘러볼 수 있어요. 여러 조건을 함께 선택해 코스 목록을 차근차근 좁힐 수 있어요.

1. 해당 커뮤니티를 여세요.
2. **학습**을 클릭하세요.
3. **주제**, **난이도**, **언어** 값을 하나 이상 선택하세요.
4. 조건에 맞는 코스를 확인하세요.
5. **정렬**에서 **제목**, **최신순**, **오래된 순** 중 하나를 골라 결과를 정리하세요.
6. 적용한 필터를 해제하려면 **모두 초기화**를 선택하세요.

## 커뮤니티 코스 필터 문제 해결

필터 문제는 대부분 코스 정보가 비어 있거나, 코스 접근이 제한되어 있거나, 여러 필터를 함께 적용해서 생겨요. 코스를 수정하기 전에 먼저 이 부분들을 확인하세요.

| 증상 | 확인할 점 |
| --- | --- |
| 필터에 기대한 코스가 나타나지 않아요 | 코스 **설정**을 열어 올바른 **언어**, **난이도**, **주제** 값이 지정되고 저장되어 있는지 확인하세요. |
| 멤버에게 코스가 아예 보이지 않아요 | 코스의 커뮤니티 공개 범위와 접근 설정을 확인하세요. 필터는 접근 제한을 우회하지 않아요. |
| 표시되는 코스가 너무 적어요 | 적용된 필터를 모두 살펴보세요. 여러 조건을 함께 쓰면 결과가 크게 줄어들 수 있어요. |
| 코스가 엉뚱한 필터에 나타나요 | 코스에 지정된 정보를 확인하고, 잘못된 값이 있으면 고치세요. |
| 멤버가 전체 코스를 다시 보고 싶어 해요 | **모두 초기화**를 선택해 적용된 필터를 해제하세요. |
| 새로 설정한 값이 반영되지 않아요 | 코스를 저장하고 커뮤니티 **학습** 페이지를 새로고침한 뒤, 올바른 코스와 커뮤니티에서 테스트하고 있는지 확인하세요. |

## 자주 묻는 질문

### 커뮤니티 코스에는 어떤 필터를 쓸 수 있나요?

멤버는 볼 수 있는 코스를 **주제**, **난이도**, **언어**로 필터링할 수 있어요.

### 커뮤니티 코스는 어떻게 정렬하나요?

**제목**, **최신순**, **오래된 순** 정렬 옵션을 사용할 수 있어요.

### 필터를 두 개 이상 함께 쓸 수 있나요?

네. 사용할 수 있는 필터 조건을 함께 선택해 코스 목록을 더 좁힐 수 있어요.

### 필터 값은 어디에서 설정하나요?

코스를 운영하는 분이 각 코스의 **설정** 영역에서 **언어**, **난이도**, **주제** 값을 지정해요.

### 코스 필터가 코스 접근 권한을 바꾸나요?

아니요. 필터는 멤버가 이미 볼 수 있는 코스를 정리해 줄 뿐이에요. 코스 접근 권한과 공개 범위는 따로 관리해요.

### 코스에 필터 값이 하나 지정되어 있지 않으면 어떻게 되나요?

멤버가 그 조건으로 필터링하면 해당 코스가 나타나지 않을 수 있어요. 코스가 그 필터에 포함되길 원한다면 정확한 값을 지정해 주세요.

### 선택한 필터를 한 번에 모두 해제할 수 있나요?

네. **모두 초기화**를 선택하면 적용된 필터가 모두 해제되고 전체 코스 목록으로 돌아가요.
