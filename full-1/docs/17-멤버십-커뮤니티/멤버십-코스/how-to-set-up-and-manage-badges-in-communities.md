# 커뮤니티 배지 설정하고 관리하기

커뮤니티 배지는 멤버가 가입하거나 활동하는 등 정해진 조건을 달성하면 자동으로 주어지는 보상이에요. 이 문서에서는 배지 종류와 설정 방법, 멤버가 배지를 확인하고 표시하는 방법, 배지로 멤버를 필터링하는 방법, 배지 디자인을 만드는 방법을 안내해요.

## 커뮤니티 배지란?

커뮤니티 배지는 멤버가 설정된 목표나 참여 기준을 달성하면 자동으로 주어지는 인정 도구예요. 관리자는 어떤 배지 트리거를 켤지 정하고, 배지를 받을 조건을 설정해요. 멤버는 자기 프로필에서 받은 배지를 확인하고, 다른 배지까지 얼마나 남았는지도 볼 수 있어요.

배지는 크게 두 가지로 나뉘어요.

- 1회성 배지: 커뮤니티의 특정 이정표나 멤버십 이벤트를 인정해요.
- 참여 배지: 게시, 댓글, 반응, 좋아요 받기처럼 꾸준한 활동을 인정해요.

## 커뮤니티 배지의 장점

배지는 의미 있는 참여에 눈에 보이는 보상을 주고, 관리자가 멤버의 꾸준한 참여를 이끌어 내도록 도와줘요.

- 자동 인정: 멤버가 설정된 목표나 활동 기준을 달성하면 자동으로 보상해요.
- 눈에 보이는 성과: 멤버가 받은 배지를 커뮤니티 곳곳에서 이름 옆에 표시할 수 있어요.
- 지속적인 참여: 참여 배지로 꾸준한 활동을 유도할 수 있어요.
- 진행 상황 확인: 멤버가 받은 배지와 앞으로 달성할 배지의 진행 상황을 볼 수 있어요.
- 유연한 설정: 트리거를 하나씩 켜고, 기준을 정하고, 트리거마다 줄 배지를 고를 수 있어요.
- 멤버 파악: 배지로 커뮤니티 멤버를 필터링하고 배지 보유자 정보를 확인할 수 있어요.

## 사전 준비와 제한 사항

배지를 주는 설정은 커뮤니티 그룹 안에서 하고, 배지 디자인은 하이퍼클래스의 **자격 증명**에서 만들고 관리해요.

- 설정하려는 **서브 계정**과 커뮤니티 그룹에 접근할 수 있어야 해요.
- 커뮤니티 설정과 배지 트리거를 관리할 수 있는 권한이 필요해요.
- 멤버는 받은 배지 중 하나만 이름 옆에 표시할 수 있어요.
- 참여 배지는 분기마다 갱신되도록 되어 있어요.
- 배지 디자인은 커뮤니티 배지 트리거와 따로 관리해요.

{% hint style="info" %}
사용할 수 있는 배지 설정과 기능은 계정 권한과 현재 커뮤니티 화면에 따라 다를 수 있어요.
{% endhint %}

## 커뮤니티 배지 설정하기

커뮤니티 관리자는 1회성 이정표와 꾸준한 참여 활동에 대해 배지를 자동으로 주도록 설정할 수 있어요. 트리거마다 배지를 받을 조건과 받을 배지를 연결해요.

1. 하이퍼클래스 **서브 계정**의 왼쪽 메뉴에서 **멤버십**을 선택하세요.
2. **커뮤니티**를 선택한 다음 **그룹**을 선택하세요.
3. 설정할 커뮤니티 그룹을 여세요.
4. 그룹 안에서 **설정**을 선택하세요.
5. **배지**를 선택하세요.

![커뮤니티 그룹 설정의 배지 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084098992/original/qL3VvwjVpq_yJhe4DC7zwAoYFLxemSe2KA.png?1792783410)

6. 설정할 1회성 배지 또는 참여 배지 트리거를 찾으세요.
7. 트리거를 켜세요.
8. 트리거에 기준이 있으면 필요한 활동 횟수나 일수를 설정하세요.
9. 조건을 달성한 멤버가 받을 배지를 선택하세요.
10. 화면에 보이는 적용 또는 저장 버튼으로 설정을 저장하세요.

![배지 트리거 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084099419/original/efQE6FKowFAL7tk8ZWLHjv5vZorwUMfABA.png?1792784241)

## 배지 종류와 부여 조건

배지는 커뮤니티의 이정표와 멤버의 꾸준한 기여를 모두 인정해요.

### 1회성 배지

| 배지 | 부여 조건 |
| --- | --- |
| **Group Admin**(그룹 관리자) | 커뮤니티 관리자가 된 멤버를 인정해요. |
| **Newbie**(새내기) | 커뮤니티에 가입한 멤버를 인정해요. |
| **Founding Member**(창립 멤버) | 커뮤니티에 가장 먼저 가입한 멤버에 해당하는 멤버를 인정해요. |

### 참여 배지

| 배지 | 부여 조건 |
| --- | --- |
| **Always On**(항상 활동 중) | 설정한 일수만큼 연속으로 게시하거나, 댓글을 달거나, 반응해요. |
| **Top Contributor**(최고 기여자) | 설정한 개수만큼 댓글을 작성해요. |
| **Power User**(파워 유저) | 설정한 개수만큼 게시글을 올려요. |
| **Crowd Favourite**(모두의 인기인) | 자신이 올린 게시글에서 설정한 개수만큼 좋아요를 받아요. |

참여 배지의 기준은 관리자가 설정해요. 참여 배지는 분기마다 갱신돼요.

## 멤버가 배지를 확인하고 표시하는 방법

멤버 프로필에서 받은 배지와 다음 성과까지의 진행 상황을 한곳에서 볼 수 있어요. 받은 배지 중 하나를 골라 이름 옆에 표시할 수도 있어요.

1. 배지를 받은 커뮤니티에 들어가세요.
2. 내 멤버 프로필을 여세요.
3. **배지** 탭을 선택하세요.
4. 받은 배지와 앞으로 달성할 배지의 진행 상황을 확인하세요.
5. 배지 선택 기능을 사용해 이름 옆에 표시할 배지를 고르세요.

![멤버 프로필의 배지 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084099850/original/VzjBaIGcr4ePjx5G9Li2Gjq5Y3S34ehFQA.png?1792784696)

선택한 배지는 커뮤니티 피드, 멤버 목록, 댓글 등에서 멤버 이름 옆에 나타날 수 있어요.

![이름 옆에 표시된 배지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084100253/original/fnLf2Qh9IAg6a6KLRHWgY1QNagzkBQ9O8A.png?1792785755)

멤버는 배지를 받았을 때 알림을 받을 수 있고, 배지 달성이 가까워지면 진행 상황 알림도 받을 수 있어요.

## 배지로 멤버 필터링하기

배지로 필터링하면 관리자가 특정 배지를 가진 멤버를 찾고 커뮤니티 참여 현황을 살펴볼 수 있어요.

1. 하이퍼클래스 **서브 계정**에서 **멤버십**을 선택하세요.
2. **커뮤니티**를 선택한 다음 **그룹**을 선택하세요.
3. 확인할 커뮤니티 그룹을 여세요.
4. **멤버** 탭을 선택하세요.
5. 배지 필터를 사용해 멤버 목록을 배지별로 좁히세요.
6. 조건에 맞는 멤버와 배지 보유자 정보를 확인하세요.

![배지로 멤버 목록 필터링](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084102356/original/8AMb-3LEN4llCLLsOgAYcnq6iDXEURwJow.png?1792790456)

## 배지 템플릿 만들고 꾸미기

하이퍼클래스의 **자격 증명** 메뉴에서 배지 템플릿을 디자인할 수 있어요. 배지를 만들고 나면 커뮤니티 배지 트리거를 설정할 때 그 배지를 선택할 수 있어요.

1. 하이퍼클래스 **서브 계정**의 왼쪽 메뉴에서 **멤버십**을 선택하세요.
2. **자격 증명**을 선택하세요.
3. 오른쪽 위의 **+ 만들기**를 클릭하세요.
4. **배지 만들기**를 선택하세요.

![배지 만들기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084101548/original/7q6_AYHl5aWd2iEHUuxGGk33icQfQDaP8Q.png?1792788285)

5. 사용할 수 있는 템플릿을 고르거나 빈 디자인으로 시작하세요.
6. 템플릿을 선택했다면 **만들기**를 클릭해 빌더를 여세요.
7. **문자**와 **요소** 도구로 배지를 꾸미세요.

![배지 빌더의 문자와 요소 도구](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084102253/original/kqp5JTRxHR07oiSrLWVXxO_otRM6nrtwHQ.png?1792790171)

8. **미리보기**를 클릭해 배지를 확인하세요.
9. **저장**을 클릭해 배지 템플릿을 저장하세요.

![배지 템플릿 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084101859/original/vQmlHcokUx53GICylkG0BmeYB-G9z_ZqXA.png?1792789219)

만든 배지를 커뮤니티 트리거에 연결하려면 **멤버십 > 커뮤니티 > 그룹**으로 돌아가 그룹을 열고 **설정 > 배지**를 선택하세요. 트리거를 설정할 때 알맞은 배지를 고르면 돼요.

## 자주 묻는 질문

### 트리거를 켰을 때 이미 조건을 달성한 멤버도 배지를 받나요?

네. 이미 조건을 충족한 멤버는 해당 트리거를 켜면 배지를 받을 수 있어요.

### 배지 트리거를 하나씩 켜고 끌 수 있나요?

네. 배지 트리거는 각각 따로 설정할 수 있어서, 사용하려는 배지만 골라서 켤 수 있어요.

### 멤버가 이름 옆에 표시할 배지를 직접 고를 수 있나요?

네. 멤버는 받은 배지 중 하나를 골라 이름 옆에 표시할 수 있어요.

### 참여 배지는 갱신되나요?

네. 참여 배지는 꾸준한 참여를 이끌도록 분기마다 갱신돼요.

### 진행 상황 알림은 언제 받나요?

배지에 필요한 진행도의 80%에 도달하면 "거의 다 왔어요"(almost there) 알림을 받을 수 있어요.
