# 커뮤니티 세금 지원

하이퍼클래스 커뮤니티에서는 유료 구매에 세금을 받을 수 있어요. 하이퍼클래스 결제에 설정한 세금 설정을 그대로 써서, 유료 멤버십·코스·유료 이벤트·이벤트 구독에 해당 세금을 적용해요. 이 문서에서는 커뮤니티 세금 지원이 어떻게 동작하는지, 어떤 설정을 확인해야 하는지, 판매 전에 세금이 제대로 적용되는지 테스트하는 방법을 안내해요.

## 커뮤니티 세금 지원이란?

커뮤니티 세금 지원은 대상이 되는 커뮤니티 결제에 하이퍼클래스 결제의 세금 설정을 그대로 적용하는 기능이에요. 커뮤니티용 세금 설정을 따로 만들 필요 없이, 이미 설정해 둔 결제 세금 설정을 지원되는 유료 커뮤니티 구매에 쓸 수 있어요.

하이퍼클래스 결제에 세금을 설정해 두면, 커뮤니티 체크아웃에서 다음 항목에 해당 세금을 적용할 수 있어요.

- 유료 커뮤니티 멤버십
- 커뮤니티를 통해 구매하는 코스
- 유료 커뮤니티 이벤트
- 이벤트 구독

고객 정보와 Nexus 정보를 바탕으로 계산하는 자동 세금과, 해당되는 경우 연결해 둔 수동 세율을 모두 지원해요.

## 커뮤니티 세금 지원의 장점

세금을 반영한 커뮤니티 체크아웃을 쓰면 가격을 더 분명하게 보여 줄 수 있고, 세금을 수작업으로 처리하는 일도 줄어요. 멤버는 결제를 마치기 전에 적용되는 세금을 확인할 수 있고, 관리자는 다른 결제 흐름과 같은 하이퍼클래스 결제 설정에서 세금을 관리할 수 있어요.

- 투명한 가격: 멤버가 체크아웃에서 적용되는 세금을 미리 볼 수 있어요.
- 세금 누락 방지: 세금을 처음부터 포함해, 구매 시점에 정확한 총액을 청구할 수 있어요.
- 한곳에서 관리하는 세금 설정: 커뮤니티 전용 세금 설정을 따로 만들 필요 없이 하이퍼클래스 결제의 세금 설정을 써요.
- 다양한 수익화 흐름 지원: 유료 멤버십, 커뮤니티를 통해 구매하는 코스, 유료 이벤트, 이벤트 구독에 사업장의 세금 설정을 따라 적용할 수 있어요.
- 유연한 세금 처리: 해당되는 경우 자동 세금, 수동 세율, 또는 둘을 함께 쓸 수 있어요.
- 지역별 판매 지원: 자동 세금은 고객 주소와 Nexus 설정을 바탕으로 적용할 세금을 판단해요.

## 지원하는 커뮤니티 결제 유형

커뮤니티 세금 지원은 커뮤니티에서 수익을 내는 주요 방식에 적용돼요. 멤버가 접근 권한을 사거나, 이벤트에 등록하거나, 유료 학습 콘텐츠를 수강하기 전에 유형별로 올바른 세금 설정이 적용되는지 확인해 보세요.

지원하는 커뮤니티 결제 유형은 다음과 같아요.

- 유료 커뮤니티 멤버십 / 유료 그룹: 관리자와 소유자가 공개 또는 비공개 커뮤니티 그룹에 접근하는 사용자에게 요금을 받을 수 있어요. 유료 그룹으로 접근 권한을 유료화할 수 있어요.
- 커뮤니티를 통해 구매하는 코스: 커뮤니티 소유자와 관리자가 유료 코스 옵션으로 커뮤니티 안에서 코스를 직접 판매할 수 있어요.
- 유료 커뮤니티 이벤트: 커뮤니티 이벤트는 무료 또는 유료로 운영할 수 있고, 워크숍·런칭·모임·Q&A 세션 같은 이벤트에 쓸 수 있어요.
- 이벤트 구독 / 반복 이벤트 접근: 유료 이벤트가 반복 접근을 지원하는 경우, 설정해 둔 결제 세금 설정에 따라 세금이 적용될 수 있어요.

## 커뮤니티 체크아웃의 자동 세금

자동 세금은 고객 주소와 사업장에 설정한 세금 설정을 바탕으로 적용할 세금을 계산해요. 고객 위치와 사업장에 설정한 Nexus를 함께 고려해서 계산하므로, 여러 지역에 판매하는 사업장에 유용해요.

하이퍼클래스 결제에서 자동 세금을 켜 두면 커뮤니티도 그 설정을 따라요. 하이퍼클래스에서 자동 세금은 **결제 > 설정 > 세금**에서 설정하고, Nexus 주소, 고객 위치, 세금 카테고리, 세금 포함 또는 별도 방식을 사용할 수 있어요.

자동 세금이 고려할 수 있는 정보는 다음과 같아요.

- 고객 청구 주소
- 사업장 Nexus 주소
- 해당되는 경우 상품의 세금 카테고리 또는 세금 코드
- 세금 포함 가격 또는 세금 별도 가격 같은 전체 세금 방식
- 결제에 설정한 관련 세금 ID나 등록 정보

## 커뮤니티 결제의 수동 세율

수동 세율은 미리 정한 세율을 적용해야 하거나, 자동 세금 계산이 다루지 않는 경우를 직접 관리해야 할 때 유용해요. 수동 세율은 하이퍼클래스 결제에서 만들고, 해당되는 경우 상품에 연결할 수 있어요.

수동 세율은 **결제 > 설정 > 세금**에서 만들어요. 세금 이름, 세율, 설명, 세금 ID, 세무 기관을 필요에 따라 입력할 수 있어요. 만든 수동 세율은 상품에서 **Attach Tax Rates**(세율 연결) 옵션으로 연결할 수 있어요.

수동 세율이 도움이 되는 경우는 다음과 같아요.

- 특정 고정 세율을 적용해야 할 때
- 특정 지역이나 상황에 자동 세금이 적용되지 않을 때
- 상품 단위의 세금 처리를 더 직접 제어하고 싶을 때
- 상품에 수동 세율을 하나 이상 연결해야 할 때

![수동 세율 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072995536/original/rihONtNm_gohtatiHl0mgf8XeQCZsrJmAQ.png?1780657122)

{% hint style="info" %}
자동 세금과 수동 세율을 모두 설정하면, 자동 세금이 적용되지 않는 경우를 수동 세율로 보완할 수 있어요. 하이퍼클래스의 여러 결제 흐름에서 동작을 확인할 때는 인보이스에만 적용되는 예외가 있을 수 있다는 점을 염두에 두세요.
{% endhint %}

## 확인해야 할 결제·상품 설정

커뮤니티 세금 지원은 하이퍼클래스 결제를 올바르게 설정해 두었다는 전제에서 동작해요. 결제 설정, 세금 규칙, 주소, 상품 설정을 확인해 두면 체크아웃에서 세금이 기대한 대로 계산돼요.

| 설정 | 확인할 내용 |
| --- | --- |
| **결제 제공업체** 연결 | **결제**가 연결되어 있고 커뮤니티 구매를 처리할 준비가 되었는지 확인해요. |
| **자동 세금** | **결제 > 설정 > 세금**에서 자동 세금을 켤지 확인해요. |
| **Nexus 주소** | 사업장에서 세금을 받는 지역을 추가하거나 확인해요. |
| **사업장 주소** | 로케이션의 사업장 주소가 정확한지 확인해요. |
| **세금 카테고리** | 해당되는 경우 상품의 세금 카테고리나 세금 코드를 확인해요. 하이퍼클래스 세금 카테고리는 상품, 구독, 거래 전반에서 더 정확하게 세금을 계산하는 데 도움이 돼요. |
| 수동 세율 | 관련 상품에 수동 세율을 연결해야 하는지 확인해요. |
| 세금 포함 / 세금 별도 방식 | 표시 가격에 세금을 포함할지, 체크아웃에서 별도로 더할지 확인해요. |

유료 커뮤니티 항목마다 상품 설정 경로가 똑같다고 단정하지 마세요. 해당되는 경우 각 유료 커뮤니티 항목에 연결된 결제·상품 설정을 따로 확인하세요.

## 커뮤니티 세금 지원 설정하기

멤버가 유료 커뮤니티 접근 권한, 코스, 이벤트를 구매하기 전에 세금이 제대로 적용되도록 설정해 두세요. 결제 세금 설정을 확인한 다음, 체크아웃을 테스트해서 예상한 총액이 나오는지 확인해요.

1. **결제 > 연동**으로 이동해 결제 제공업체가 연결되어 있는지 확인하세요.
2. **결제 > 설정 > 세금**으로 이동해 필요하면 **자동 세금**을 켜세요.
3. **Nexus 주소**, **사업장 주소**, 세금 포함 또는 세금 별도 가격 설정을 추가하거나 확인하세요.
4. 미리 정한 세율을 쓰는 사업장이라면 수동 세율을 만들거나 확인하세요.
5. 유료 멤버십, 코스, 이벤트, 이벤트 구독 같은 유료 커뮤니티 항목을 확인하세요.
6. 해당되는 경우 세금 카테고리와 연결된 수동 세율 등, 관련 상품이나 결제 설정을 확인하세요.
7. 커뮤니티 체크아웃을 테스트로 진행해서 소계, 세금, 최종 총액이 예상대로 나오는지 확인하세요.

## 자주 묻는 질문

### 커뮤니티용 세금 설정을 따로 만들어야 하나요?
아니요. 커뮤니티 세금 지원은 대상이 되는 유료 커뮤니티 구매에 하이퍼클래스 결제에 설정한 세금 설정을 사용해요.

### 어떤 커뮤니티 구매에 세금을 적용할 수 있나요?
유료 커뮤니티 멤버십, 커뮤니티를 통해 구매하는 코스, 유료 커뮤니티 이벤트, 이벤트 구독을 지원해요.

### 결제에 세금을 설정하지 않았는데도 세금이 자동으로 적용되나요?
아니요. 대상이 되는 커뮤니티 체크아웃에 세금을 적용하려면 먼저 하이퍼클래스 결제에 세금을 설정해야 해요.

### 자동 세금과 수동 세율을 함께 쓸 수 있나요?
네. 해당되는 경우 자동 세금과 수동 세율을 함께 쓸 수 있어요. 자동 세금이 적용되지 않는 경우를 수동 세율로 보완할 수 있어요.

### 자동 세금 계산에는 어떤 주소가 쓰이나요?
자동 세금은 일반적으로 고객 주소와 사업장에 설정한 Nexus 주소, 세금 설정을 함께 사용해요.

### 체크아웃에서 세금이 표시되지 않아요. 왜 그런가요?
자동 세금이 꺼져 있거나, Nexus 주소가 없거나, 고객 주소가 불완전하거나, 필요한 곳에 수동 세율이 연결되지 않았거나, 유료 항목의 세금 설정을 아직 확인하지 않았다면 세금이 표시되지 않을 수 있어요.

### 표시 가격에 세금을 포함할 수 있나요?
네. 지원되는 경우 하이퍼클래스 결제에서 세금 포함 가격을 설정할 수 있어요. 유료 커뮤니티 오퍼를 시작하기 전에 세금 포함 또는 세금 별도 설정을 확인하세요.
