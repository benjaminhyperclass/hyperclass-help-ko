# Kollab Studio로 커뮤니티와 코스 한곳에서 관리하기

**Kollab Studio**(커뮤니티와 코스를 한곳에서 관리하는 크리에이터 허브)는 하이퍼클래스에서 커뮤니티와 코스를 운영하는 분들을 위한 화면이에요. 콘텐츠를 고치거나 가격을 바꾸거나 새 상품을 내놓을 때, 하나의 대시보드에서 모두 정리할 수 있어요.

[동영상](https://www.youtube.com/embed/CYbBBfTtIgs?&wmode=opaque)

## Kollab Studio란?

**Kollab Studio**는 하이퍼클래스 안에서 내 커뮤니티와 코스를 한 작업 공간에 모아 보여 주는 관리 화면이에요. 여러 페이지를 오가며 상품을 확인하거나 수정할 필요 없이, 직관적인 대시보드 하나에서 모두 처리할 수 있어요. 흩어져 있던 설정이 한곳에 모이니 디지털 상품을 한눈에 관리할 수 있어요.

이런 분들께 잘 맞아요.

- 커뮤니티 운영자
- 코스 제작자
- GoKollab으로 디지털 상품을 판매하는 모든 분

따로 옮길 필요는 없어요. 기존 커뮤니티와 코스는 **Kollab Studio**에 자동으로 나타나요.

## Kollab Studio의 주요 장점

가장 큰 장점은 효율성이에요. 내가 가진 모든 상품에 빠르게 접근할 수 있어서, 상품을 최신 상태로 유지하고 멤버들의 참여도 이어 가기 쉬워요.

- 한곳에서 모두 관리: 하나의 대시보드에서 모든 커뮤니티와 코스에 접근해요.
- 더 빠르게 작업: 접근 권한, 가격, 콘텐츠를 몇 초 만에 편집해요.
- 활발하게, 내 뜻대로 운영: 필요할 때 게시하거나 게시를 취소하고 콘텐츠를 손쉽게 고쳐요.
- 유지율과 매출 향상: 더 나은 도구로 더 좋은 상품을 만들면 멤버들의 참여도 높아져요.
- 게시 전에 미리 확인: 개선된 판매 페이지를 공개 전에 확인해요. 커뮤니티 판매 페이지에는 미디어 캐러셀이, 코스 판매 페이지에는 구조화된 커리큘럼 미리보기가 표시돼요.

## 커뮤니티 판매 페이지의 미디어 미리보기

커뮤니티 판매 페이지에서 이미지와 동영상을 보여 주는 미디어 캐러셀을 쓸 수 있어요. YouTube, Loom, Vimeo 동영상도 지원해요. 커뮤니티 소개(About) 페이지에 추가한 미디어는 판매 페이지와 자동으로 동기화돼요. 그래서 리스팅을 따로 업데이트하지 않아도 돼요.

캐러셀은 등록된 미디어를 자동으로 넘겨 가며 보여 줘요. 방문자는 가입하기 전에 커뮤니티를 더 생생하게 미리 볼 수 있어요.

## 코스 판매 페이지의 구조화된 미리보기

코스 판매 페이지에는 구조화된 커리큘럼 미리보기가 표시돼요. 방문자는 수강 신청 전에 모듈, 강의, 썸네일을 정돈된 형태로 확인할 수 있어요.

방문자가 코스 내용을 더 분명하게 파악하고, 가입 후 어떤 내용을 볼 수 있는지 이해하는 데 도움이 돼요.

## Kollab Studio에 접속하는 방법

하이퍼클래스에서 몇 번만 클릭하면 **Kollab Studio**에 들어갈 수 있어요. 들어가면 커뮤니티와 코스를 각각 관리하는 탭이 따로 있어요.

### 1단계: 멤버십 > Gokollab Marketplace로 이동하기

**멤버십 > Gokollab Marketplace**(GoKollab 마켓플레이스)로 이동하세요. 여기에서 GoKollab 주소를 확인할 수 있어요. 이 주소가 바로 GoKollab 마켓플레이스 대시보드예요.

![멤버십 메뉴의 Gokollab Marketplace 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051213939/original/63T6gI6LOaC9EKA_ohT0iSRyt6VboQoETA.png?1754656174)

{% hint style="warning" %}
하이퍼클래스 대시보드와 GoKollab에 로그인할 때 쓰는 이메일이 같아야 해요. 그래야 내 커뮤니티와 코스가 프로필에 제대로 연결되고 **Kollab Studio**에 표시돼요. 이메일이 서로 다르면 상품이 나타나지 않을 수 있어요.
{% endhint %}

### 2단계: Kollab Studio 열기

GoKollab 대시보드에 로그인한 뒤, 오른쪽 위의 프로필 아이콘을 클릭하세요. 드롭다운 메뉴에서 **Kollab Studio**를 선택하세요.

![프로필 아이콘 드롭다운 메뉴에서 Kollab Studio 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051214836/original/CoFVGAwV6E9YLK8_AAr2zwLDEa2ozWHxUQ.png?1754656491)

### 3단계: 커뮤니티와 코스 관리하기

이제 하나의 대시보드에서 커뮤니티와 코스를 더 효율적으로 관리할 수 있어요.

![Kollab Studio 통합 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051215664/original/OjLDbKVYEHonHIbp6Ok4mHsEdF1-fl3JuA.png?1754656750)

## 커뮤니티 탭

**커뮤니티** 탭은 내가 만든 모든 커뮤니티를 관리하는 곳이에요. 대시보드를 벗어나지 않고 미리보기, 설정 조정, 공개 여부 관리를 빠르게 할 수 있어요.

커뮤니티 판매 페이지에서 더 풍부한 미디어를 보여 줄 수 있어요. 커뮤니티 소개(About) 페이지의 이미지와 동영상이 판매 페이지에 자동으로 동기화되므로, 같은 미디어를 여러 곳에서 따로 업데이트하지 않아도 돼요. 판매 페이지는 이 미디어를 자동으로 넘어가는 캐러셀로 보여 줘서, 방문자가 가입 전에 커뮤니티를 이해하는 데 도움이 돼요.

지원하는 동영상 출처는 YouTube, Loom, Vimeo예요.

이런 일을 할 수 있어요.

- 커뮤니티별로 개선된 판매 페이지를 미리 봐요.
- 판매 페이지 캐러셀에 이미지와 동영상을 표시해요.
- 즉시 게시하거나 게시를 취소해요.
- 메뉴에서 커뮤니티 설정에 바로 들어가요.
- 채널별로 읽지 않은 게시글 수를 보면서 활동을 놓치지 않아요.

![커뮤니티 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051216024/original/vgdRFr9_uL8HM6V_KxTwynNOmqb3piL6kA.png?1754656900)

{% hint style="warning" %}
내가 직접 만든 커뮤니티만 **Kollab Studio**에 표시돼요. 다른 사람이 만든 커뮤니티의 멤버이거나 관리자라면 여기에 나타나지 않아요.
{% endhint %}

## 코스 탭

**코스** 탭에서는 모든 교육 콘텐츠를 한곳에서 볼 수 있어요. 게시 상태를 관리하고, 코스별 판매 페이지를 미리 보고, 수강 신청 전에 방문자에게 코스가 어떻게 보이는지 확인할 수 있어요.

코스 판매 페이지에는 구조화된 커리큘럼 미리보기가 들어 있어요. 방문자는 모듈, 강의, 썸네일을 깔끔한 형태로 볼 수 있어서 수강 신청 전에 코스 내용을 이해하기 쉬워요.

이런 일을 할 수 있어요.

- 모든 코스를 하나의 목록에서 확인해요.
- 개선된 코스 판매 페이지를 미리 봐요.
- 코스 판매 페이지에 모듈, 강의, 썸네일을 표시해요.
- 클릭 한 번으로 게시 상태를 바꿔요.

![코스 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051216541/original/pYehW4oZ_24GB08hCYouYiaRxrxk6APguQ.png?1754657034)

{% hint style="warning" %}
**멤버십**에서 직접 만든 코스만 여기에 표시돼요. 코스를 GoKollab 마켓플레이스에 추가했다면 **Kollab Studio**에도 나타나요. 내가 만들지 않은 코스는 표시되지 않아요. 자세한 내용은 '시작하기 - 코스 출시하기' 문서도 참고하세요.
{% endhint %}

## Kollab Studio를 잘 쓰는 방법

**Kollab Studio**를 잘 활용하면 멤버 참여도와 상품 성과를 높이는 데 도움이 돼요. 아래 방법을 참고하세요.

- 판매 페이지를 새로운 콘텐츠와 최신 오퍼로 계속 업데이트하세요.
- 커뮤니티 소개(About) 페이지에 잘 만든 이미지와 동영상을 추가하세요. 이 미디어는 커뮤니티 판매 페이지 캐러셀에 자동으로 표시될 수 있어요.
- 방문자가 수강 신청 전에 코스를 분명히 이해할 수 있도록 코스 모듈, 강의, 썸네일을 정돈해 두세요.
- 멤버의 관심이 이어지도록 코스와 커뮤니티 콘텐츠를 주기적으로 새로 고치세요.
- 활동이 없는 상품은 게시를 취소해서 대시보드를 깔끔하게 유지하세요.
- 지원하는 미디어는 커뮤니티 판매 페이지에 표시될 수 있으니, 커뮤니티 소개(About) 페이지의 미디어를 최신 상태로 유지하세요.
- 코스 모듈, 강의 제목, 썸네일을 명확하게 만들어 코스 판매 페이지 미리보기를 개선하세요.

## 자주 묻는 질문

### Kollab Studio가 무엇인가요?
**Kollab Studio**는 하이퍼클래스에서 커뮤니티와 코스를 한곳에서 관리할 수 있는 통합 대시보드예요.

### 커뮤니티를 게시하거나 게시 취소하려면 어떻게 하나요?
**커뮤니티** 탭에서 판매 페이지를 미리 본 뒤, 토글을 사용해 게시 상태를 바로 바꿀 수 있어요.

### Kollab Studio에서 코스 정보를 편집할 수 있나요?
네, **코스** 탭에서 게시 상태를 조정하고 코스별 판매 페이지를 미리 볼 수 있어요.

### 커뮤니티 판매 페이지에는 무엇이 표시되나요?
커뮤니티 판매 페이지에는 이미지와 동영상이 자동으로 넘어가는 미디어 캐러셀로 표시될 수 있어요. 커뮤니티 소개(About) 페이지에 추가한 미디어는 판매 페이지에 자동으로 동기화돼요.

### 커뮤니티 판매 페이지 미디어에는 어떤 동영상 출처를 쓸 수 있나요?
YouTube, Loom, Vimeo 동영상을 쓸 수 있어요.

### 코스 판매 페이지에는 무엇이 표시되나요?
코스 판매 페이지에는 모듈, 강의, 썸네일이 담긴 구조화된 커리큘럼 미리보기가 표시될 수 있어요. 방문자가 수강 신청 전에 코스를 이해하는 데 도움이 돼요.

### 코스 편집 기능이 더 추가되나요?
코스 편집 옵션을 더 추가할 계획이 있고, 이후 업데이트에서 제공될 예정이에요.

### Kollab Studio를 쓰려면 기존 데이터를 옮겨야 하나요?
아니요, 옮길 필요 없어요. 현재 가지고 있는 디지털 상품 데이터는 새 대시보드에 자동으로 연동돼요.

### Kollab Studio에 내 코스나 커뮤니티가 보이지 않아요.
**Kollab Studio**에는 내가 만든 상품만 표시돼요. 코스는 **멤버십**에서 직접 만든 것이어야 하고, 커뮤니티는 내가 처음 만든 사람이어야 해요. GoKollab 마켓플레이스에 추가한 코스도 함께 표시돼요.
