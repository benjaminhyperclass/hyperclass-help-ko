# 커뮤니티 비공개 채널과 채널 이모지 설정

하이퍼클래스 커뮤니티에서 비공개 채널을 만들어 멤버 전용 대화를 운영하고, 채널 이모지로 채널을 한눈에 알아보게 만드는 방법을 안내해요. 비공개 채널을 만들고 전환하는 방법, 멤버를 관리하는 방법, 이모지를 설정하는 방법, 비공개 채널을 다시 공개로 바꾸는 방법을 다룹니다.

[동영상](https://www.youtube.com/embed/u94QVLF\_iAA?&wmode=opaque)

## 비공개 채널과 채널 이모지란?

비공개 채널은 승인된 멤버만 채널을 보고 참여할 수 있게 제한하는 기능이에요. 접근을 제한한 코호트나 프리미엄 그룹을 운영할 때 쓰면 좋아요. 채널 이모지는 목록과 헤더에서 채널명 옆에 표시되는 작은 표식으로, 채널을 쉽게 알아보게 도와줘요. 두 기능은 모바일과 웹 버전 모두에서 쓸 수 있고, 커뮤니티의 개인정보 보호와 사용자 지정 옵션을 높여 줘요.

## 비공개 채널과 이모지의 장점

- 멤버 관리: 채널을 보고 글을 쓸 수 있는 사람을 직접 정할 수 있어요.
- 집중된 대화: 민감한 내용이나 유료 콘텐츠를 공개 대화와 분리할 수 있어요.
- 유연한 공개 설정: 필요에 따라 채널을 공개와 비공개로 바꿀 수 있어요.
- 빠른 구분: 이모지가 목록과 알림에서 채널을 더 쉽게 알아보게 해 줘요.

## 비공개 채널 만들기

처음부터 접근을 제한해야 한다면 새 채널을 비공개로 만드세요.

{% hint style="warning" %}
중요

1. 그룹 소유자와 채널을 만든 사람은 자동으로 채널 매니저가 돼요.
2. 채널 매니저는 해당 채널의 관리자 역할을 해요. 그룹 소유자나 그룹 관리자 같은 그룹 역할은 비공개 채널 안에서는 의미가 없어요.
3. 그룹 소유자는 비공개 채널에서 나갈 수 없어요.
4. 비공개 채널은 참여하지 않은 사용자의 채널 목록에 보이지 않아요.
{% endhint %}

1. 서브 계정에서 **멤버십**을 클릭하세요.
2. **커뮤니티**로 이동하세요.
3. 드롭다운에서 **그룹**을 클릭하세요.

   ![그룹 메뉴 선택 화면](https://jumpshare.com/share/F7VQklFSnqf9q7s8Sp8l+/Screenshot+2026-02-10+at+12.45.46%E2%80%AFAM.png)
4. 그룹에서 **진행 중** 또는 **로그인**을 클릭해 그룹에 들어가세요.

   ![그룹 진입 화면](https://jumpshare.com/share/E57Y9g9gMoqiDrCtMJPT+/Screen+Shot+2026-02-10+at+12.49.05+AM.png)
5. **+ Add Channel**(채널 추가) 버튼을 클릭하세요.

   ![채널 추가 버튼](https://jumpshare.com/share/RIZ3PJO6Iq7pfIxh0C76+/Screen+Shot+2026-02-10+at+12.50.33+AM.png)
6. **채널명**을 입력하세요. 원하면 채널 설명을 쓰고 채널 아이콘도 고를 수 있어요.
7. **Make this Channel Private**(이 채널을 비공개로 설정) 옵션을 **켜짐**으로 바꾸세요.
8. **Create Channel**(채널 만들기)을 클릭하세요.

   ![비공개 채널 만들기 화면](https://jumpshare.com/share/Gz1C38rPmRLipKWmbhcM+/Screen+Shot+2026-02-10+at+12.52.30+AM.png)

## 공개 채널을 비공개로 바꾸기

이미 있는 공개 채널을 비공개로 바꾸면 앞으로 채널을 보고 참여할 수 있는 사람이 제한돼요.

{% hint style="info" %}
채널을 바꾸면 멤버가 아닌 사용자의 채널 목록에서 해당 채널이 더 이상 보이지 않아요.
{% endhint %}

1. 채널을 클릭해 여세요.
2. **설정**(톱니바퀴) 아이콘을 클릭하세요.
3. **설정** 탭을 여세요.
4. **Make Channel Private**(채널을 비공개로 설정)를 클릭하세요.
5. 확인 안내 팝업을 읽고 **확인**을 클릭하세요.

![공개 채널을 비공개로 바꾸는 과정](https://jumpshare.com/share/h4pdDItaYmSjrMlkLRnE+/GIF+Recording+2026-02-10+at+1.00.09+AM.gif)

## 비공개 채널을 다시 공개로 바꾸기

그룹의 누구나 채널을 찾아 참여할 수 있게 하려면 다시 공개로 바꾸세요.

{% hint style="warning" %}
중요: 공개로 바꾸면 채널이 모든 그룹 멤버에게 보여요. 기존 게시글 기록은 채널에 그대로 남아요.
{% endhint %}

1. 채널을 여세요.
2. **설정**(톱니바퀴) 아이콘을 클릭하세요.
3. **설정** 탭을 여세요.
4. **Make Channel Public**(채널을 공개로 설정)을 클릭하세요.
5. 확인 안내 팝업을 읽고 **확인**을 클릭하세요.

![비공개 채널을 공개로 바꾸는 과정](https://jumpshare.com/share/vAh4ZgRnGFIqzcihVJqg+/GIF+Recording+2026-02-10+at+12.56.14+AM.gif)

## 비공개 채널의 멤버 추가·제거하기

비공개 채널은 멤버를 추가하거나 제거해서 접근 권한을 관리할 수 있어요. 언제든 바꿀 수 있어요.

1. 채널을 여세요.
2. **설정**(톱니바퀴) 아이콘을 클릭하세요.
3. **멤버** 탭을 여세요.
4. 멤버를 추가하려면 사용자를 검색해서 추가하세요.
5. 멤버를 제거하려면 해당 사용자를 찾아 이름 옆의 점 세 개를 클릭한 다음 **Remove from Channel**(채널에서 제거)을 클릭하세요.

![비공개 채널 멤버 관리 과정](https://jumpshare.com/share/y6BNiMxVpDZtAhfkrbFg+/GIF+Recording+2026-02-10+at+1.04.42+AM.gif)

## 채널 이모지·아이콘 설정하거나 바꾸기

이모지를 지정하면 멤버가 목록과 알림에서 채널을 빠르게 알아볼 수 있어요.

1. 채널을 여세요.
2. **설정**(톱니바퀴) 아이콘을 클릭하세요.
3. **채널명** 옆의 **편집** 버튼을 클릭하세요.
4. **Channel Icon**(채널 아이콘) 옵션을 클릭하고 **Emoji**(이모지)나 **아이콘** 중 원하는 것을 고르세요.
5. **저장**을 클릭하세요.

![채널 이모지 설정 과정](https://jumpshare.com/share/DUt50fbROAdD8x0OTBkW+/GIF+Recording+2026-02-10+at+1.11.40+AM.gif)

## 자주 묻는 질문

### 비공개 채널이 있다는 사실은 누가 볼 수 있나요?
승인된 멤버와 해당 채널에 대한 충분한 권한이 있는 사용자만 볼 수 있어요.

### 비공개 채널을 공개로 바꾸면 이전 게시글은 어떻게 되나요?
채널을 누구나 찾을 수 있게 되고, 기존 콘텐츠도 모든 그룹 멤버에게 보여요.

### 접근 권한을 워크플로우로 회수해야 하나요, 아니면 채널을 공개로 바꿔야 하나요?
멤버별 접근 권한은 워크플로우로 관리하세요. 채널 전체를 그룹에 열어 두고 싶을 때는 채널을 공개로 바꾸세요.

### 채널 이모지는 누가 바꿀 수 있나요?
채널 소유자나 채널 단위 관리 권한이 있는 사용자가 바꿀 수 있어요.
