# 커뮤니티 편집기 개선: 서식 도구 모음과 운영 도구

하이퍼클래스 커뮤니티 편집기가 개선되어 게시글을 더 보기 좋게 꾸미고, 커뮤니티를 더 효율적으로 운영하고, 녹음·녹화 파일을 더 적은 클릭으로 관리할 수 있어요. 이 문서에서는 플로팅 서식 도구 모음, 게시글에서 바로 사용자 차단하기, 녹음·녹화 파일 다운로드, 댓글 편집기의 키보드 단축키 변경 사항을 안내해요.

## 서식 도구 모음

편집기에서 텍스트를 선택하면 자주 쓰는 서식 옵션이 담긴 도구 모음이 나타나요. 키보드 단축키를 외우거나 다른 화면으로 이동하지 않고도, 게시글과 댓글을 보기 좋게 꾸밀 수 있어요.

도구 모음에서 다음 서식을 바로 쓸 수 있어요.

- **굵게**: 중요한 단어나 문구를 강조해요.
- **기울임**: 은은하게 강조하거나 제목을 표시해요.
- **밑줄**: 핵심 정보를 눈에 띄게 해요.
- **취소선**: 삭제하거나 바뀐 내용을 표시해요.
- **Insert Links**(링크 삽입): 텍스트에 하이퍼링크를 넣어요.

![텍스트를 선택하면 나타나는 서식 도구 모음](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077267147/original/8R8bGN3JP87oNyc0vehGDGlFFVZdyd6bew.png?1785426049)

{% hint style="info" %}
팁: 커서로 텍스트를 드래그해 선택하면 서식 도구 모음이 자동으로 나타나요. 기존 키보드 단축키도 그대로 쓸 수 있어요.
{% endhint %}

## 게시글에서 바로 스팸 사용자 차단하기

커뮤니티 운영자는 대화 피드를 떠나지 않고, **Members**(멤버) 탭으로 이동하지 않고도 바로 사용자를 차단할 수 있어요. 스팸이나 부적절한 콘텐츠에 빠르게 대응할 수 있어요.

사용자를 차단할 때 그 사용자가 작성한 콘텐츠를 모두 삭제하도록 선택할 수 있어요. 스팸이나 정책 위반 콘텐츠를 한 번에 정리할 수 있어요.

1. 차단하려는 사용자의 게시글을 찾아 게시글 오른쪽 위의 점 세 개 메뉴(⋮)를 클릭하세요.
2. 드롭다운 메뉴에서 **Ban User**(사용자 차단)를 선택하세요. 해당 사용자의 프로필과 사용자 이름이 표시된 확인 창이 나타나요.
3. 해당 사용자의 게시글, 댓글, 녹음·녹화 파일을 모두 삭제하려면 **Delete all content created by this user**(이 사용자가 작성한 모든 콘텐츠 삭제) 체크박스를 선택하세요.
4. **Yes, Ban**(예, 차단)을 클릭하면 차단이 완료돼요.

{% endhint %}

## 게시글에서 녹음·녹화 파일 다운로드하기

커뮤니티 게시글에 올라온 동영상·오디오 녹음·녹화 파일은 게시글 메뉴에서 바로 다운로드할 수 있어요. 오프라인 시청, 보관, 콘텐츠 재활용을 위해 별도 단계 없이 파일을 저장할 수 있어요.

1. 다운로드하려는 녹음·녹화 파일이 있는 게시글로 이동하세요.
2. 게시글 오른쪽 위의 점 세 개 메뉴(⋮)를 클릭하세요.
3. 드롭다운 메뉴에서 **Download Recording**(녹음·녹화 다운로드)을 선택하세요. 파일이 바로 내 기기에 다운로드돼요.

![게시글 메뉴에서 녹음·녹화 다운로드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077267396/original/JV0EWDfwufDXnRO_Twu-bc32Hzs-j4R0rQ.png?1785426168)

{% hint style="info" %}
팁: 동영상 게시글과 오디오 게시글 모두 다운로드할 수 있어요. 파일 형식은 원래 녹음·녹화 형식에 따라 달라져요.
{% endhint %}

## 댓글 편집기 키보드 단축키 개선

사용자 의견을 반영해 댓글 편집기의 키보드 단축키를 일반적인 텍스트 편집 방식에 맞게 바꿨어요. 댓글을 쓸 때 더 직관적이고 헷갈리지 않아요.

- Enter: 새 문단을 시작해요. 문서 편집기처럼 문단 사이에 세로 간격이 생겨요.
- Shift + Enter: 줄바꿈을 넣어요. 새 문단을 만들지 않고 같은 문단 안에서 줄만 나눌 수 있어요.
- Ctrl + Enter: 댓글을 게시해요. Mac에서는 Cmd + Enter를 사용해요. **게시글** 버튼을 클릭하는 대신 키보드로 바로 댓글을 올릴 수 있어요.

{% hint style="info" %}
달라진 단축키는 익숙한 텍스트 편집기 방식과 같아서 쉽게 적응할 수 있어요. 실수로 댓글이 올라가는 일도 줄어요.
{% endhint %}

## 자주 묻는 질문

### 서식 도구 모음 대신 키보드 단축키를 쓸 수 있나요?
네. 플로팅 도구 모음은 기존 키보드 단축키를 보완하는 기능이에요. 원하면 기존 단축키(예: **굵게**는 Ctrl+B, **기울임**은 Ctrl+I)를 계속 쓸 수 있어요.

### 사용자를 차단하면 그 사용자의 콘텐츠는 어떻게 되나요?
사용자를 차단할 때 그 사용자가 작성한 모든 콘텐츠를 삭제할지 선택할 수 있어요. **Delete all content created by this user**(이 사용자가 작성한 모든 콘텐츠 삭제) 체크박스를 선택하면 해당 사용자의 게시글, 댓글, 녹음·녹화 파일이 영구적으로 삭제돼요. 선택하지 않으면 콘텐츠는 커뮤니티에 그대로 보여요.

### 차단한 사용자를 다시 해제할 수 있나요?
네. **Members**(멤버) 탭에서 차단된 사용자를 찾아 프로필 메뉴의 **Unban User**(차단 해제)를 선택하세요. 차단할 때 콘텐츠를 삭제했다면 그 콘텐츠는 복구할 수 없어요.

### 다운로드한 녹음·녹화 파일은 어떤 형식인가요?
커뮤니티에 업로드된 원본 파일의 형식 그대로 다운로드돼요. 대부분 동영상은 MP4, 오디오는 MP3로 저장되지만, 녹음·녹화 방식에 따라 형식이 다를 수 있어요.

### 개선된 키보드 단축키가 게시글 편집기에서도 작동하나요?
<!-- 검토 필요: 원문 내용이 서로 다름 -->
네. 달라진 단축키(Enter는 새 문단, Shift+Enter는 줄바꿈, Ctrl+Enter는 게시)는 댓글 편집기와 게시글 편집기 모두에 적용돼요. 커뮤니티의 모든 글쓰기 화면에서 같은 방식으로 쓸 수 있어요.

### 내가 작성하지 않은 게시글의 녹음·녹화 파일도 다운로드할 수 있나요?
네. 커뮤니티에서 게시글이 내게 보이면 다운로드할 수 있어요. 게시글 작성자뿐 아니라 해당 게시글에 접근할 수 있는 모든 커뮤니티 멤버가 녹음·녹화 파일을 다운로드할 수 있어요.

### 모바일 브라우저에서도 서식 도구 모음이 나타나나요?
플로팅 서식 도구 모음은 데스크톱 브라우저에 맞춰 만들어졌어요. 모바일 기기에서는 기기와 브라우저에 따라 다른 화면에서 서식 옵션을 쓸 수 있어요. 도구 모음은 데스크톱에서 가장 편하게 쓰도록 설계되었고, 모든 플랫폼에서 기능은 그대로 쓸 수 있어요.
