# 미팅룸에서 소회의실 사용하기

소회의실(**Breakout Rooms**)을 쓰면 미팅룸 세션을 작은 그룹으로 나눠 워크숍, 교육, 코칭, 팀 토론을 진행할 수 있어요. 이 문서에서는 소회의실을 만드는 방법, 참가자 권한 설정, 진행 중인 세션 관리, 룸별 녹음과 실시간 받아쓰기 제어 방법을 안내해요.

```
요약: 진행 중인 미팅룸에서 Breakout Rooms를 클릭하고, 룸 개수와 배정 방식을 고른 뒤 Create rooms를 클릭하세요. 배정 내용과 선택지를 확인하고 Open all rooms를 클릭하면 시작돼요. 모두 돌아오게 하려면 Close all rooms를 사용하세요.
```

## 소회의실이란?

소회의실은 미팅룸 세션 안에 만드는 작은 토론 공간이에요. 모든 사람이 한 대화에 모여 있는 대신, 호스트가 참가자를 그룹으로 나누면 각 그룹이 따로 활동한 뒤 메인 미팅으로 돌아와요.

예를 들어 강사는 참석자를 실습 그룹으로 나누고, 팀 리더는 브레인스토밍 토론을 따로 진행하고, 코치는 집중 대화를 위한 소그룹을 만들 수 있어요.

호스트는 미팅 화면에서 참가자 배정, 룸 입장, 전체 공지, 타이머, 녹음, 실시간 받아쓰기를 관리해요.

![소회의실 패널이 열린 미팅룸 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084152632/original/cPl1tL6GaYRnFfFcbEKCdb5Zj2fQ51TWhQ.png?1792975983)

## 소회의실의 장점

호스트는 참가자를 같은 미팅 안에 두면서 그룹 활동을 운영할 수 있어요.

- 유연한 그룹 구성: 참가자를 자동으로 배정하거나, 룸을 직접 지정하거나, 참가자가 룸을 고르게 할 수 있어요.
- 한곳에서 세션 관리: 토론에 들어가고, 참가자를 룸 사이로 옮기고, 모든 룸에 메시지를 보낼 수 있어요.
- 세션 시간 조절: 진행 시간을 정하고, 필요하면 연장하고, 돌아오기 전에 카운트다운을 보여 줄 수 있어요.
- 룸별 녹음과 받아쓰기: 녹음과 실시간 받아쓰기를 룸마다 따로 관리해요.

## 참가자 배정 방식

소회의실을 만들 때 참가자를 어떻게 배정할지 고르세요. 활동 종류와 호스트가 직접 관여하는 정도에 따라 방식을 선택하면 돼요.

| 배정 방식 | 작동 방식 | 이럴 때 유용해요 |
| --- | --- | --- |
| **Automatically**(자동 배정) | 참가자를 룸에 자동으로 배정해요. | 미팅을 빠르게 작은 그룹으로 나눌 때 |
| **Manually**(직접 배정) | 호스트가 참가자별 룸을 직접 정해요. | 특정 팀, 코칭 그룹, 워크숍 그룹을 만들 때 |
| **Let participants choose**(참가자가 직접 선택) | 참가자가 참여할 룸을 직접 골라요. | 주제별 토론처럼 참석자가 그룹을 고르는 활동 |

```
자동 배정과 자동 이동은 서로 다른 설정이에요.
Automatically는 참가자가 어느 룸에 배정되는지를 정해요.
선택지에 있는 Auto-move people to rooms는 룸이 열릴 때 배정된 참가자가 자동으로 룸에 들어갈지를 정해요.
```

## 소회의실 설정

소회의실 패널에서 **선택지**를 클릭하면 참가자가 룸 사이를 이동하는 방식과 소회의실 세션이 끝나는 방식을 설정할 수 있어요.

| 설정 | 설정 내용 |
| --- | --- |
| **Auto-move people to rooms**(참가자를 룸으로 자동 이동) | 룸이 열릴 때 배정된 참가자를 소회의실로 자동으로 옮겨요. |
| **Let people switch rooms**(룸 전환 허용) | 참가자가 소회의실 사이를 이동할 수 있어요. |
| **Allow return to main room**(메인 룸 복귀 허용) | 소회의실이 진행되는 동안 참가자가 메인 미팅으로 돌아올 수 있어요. |
| **Close after**(자동 종료 시간) | 소회의실이 자동으로 닫히기까지의 시간을 정해요. |
| **Countdown**(카운트다운) | 룸이 완전히 닫히고 참가자가 메인 미팅으로 돌아오기 전에 보여 줄 카운트다운 시간을 정해요. |

활동에 맞는 참가자 경험을 만들려면 룸을 열기 전에 이 설정을 끝내 두세요. 예를 들어 체계적인 교육 세션이라면 룸을 배정하고 자동 이동을 쓰는 편이 좋고, 자유 토론이라면 참가자가 룸을 고르고 옮길 수 있게 하는 편이 좋아요.

## 소회의실 만들고 열기

아래 단계는 호스트로서 진행 중인 미팅룸 세션 안에서 시작해요. 커뮤니티에서 미팅룸을 시작하는 방법은 '커뮤니티 – Go Live로 미팅과 방송 진행하기(Communities – Use Go Live to Host Meetings & Broadcasts)' 문서를 참고하세요.

1. 미팅 도구 모음에서 네모 네 개 모양 아이콘인 **Breakout Rooms**를 클릭하세요. 미팅 오른쪽에 소회의실 패널이 열려요.
2. 만들 룸 개수를 입력하세요. 한 세션에서 최대 **100개**까지 만들 수 있어요.
3. **Assign people**(인원 배정)에서 **Automatically**, **Manually**, **Let participants choose** 중 하나를 고르세요.
4. **Create rooms**(룸 만들기)를 클릭하세요.
5. 룸 목록과 참가자 배정을 확인하세요. 소회의실을 준비하는 동안 패널에 **임시 저장** 표시가 나타나요.
6. 룸을 펼쳐 참가자를 확인하세요. 필요하면 룸 이름을 바꾸거나 배정을 조정하세요. 룸을 더 만들려면 **Add room**(룸 추가)을 클릭하세요.
7. **미지정** 섹션에서 아직 룸이 없는 참가자를 확인하세요.

   ```
   룸을 만든다고 소회의실 세션이 시작되는 것은 아니에요. 임시 저장 상태로 계획을 준비하는 동안에는 참가자가 룸으로 이동하지 않아요.
   ```

8. **선택지**를 클릭해 이동 권한, 자동 종료 시간, 카운트다운 설정을 확인하세요.
9. 설정을 마쳤으면 룸 목록으로 돌아가세요.
10. **Open all rooms**(모든 룸 열기)를 클릭하면 소회의실 세션이 시작돼요.

배정된 참가자는 설정에 따라 룸 참여 초대를 받거나 자동으로 이동해요. 참가자가 직접 고르는 방식이면 참석자가 참여할 룸을 선택할 수 있어요.

![소회의실을 열기 전 룸 계획 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084152661/original/Ac3hxXTA_uR1W5jRW4avmA2oy4DwJimYTA.png?1792976145)

## 진행 중인 소회의실 관리하기

룸이 열린 뒤에는 소회의실 패널에서 그룹을 살펴보고, 참가자를 돕고, 세션을 관리해요.

### 룸 확인하고 참여하기

**Rooms** 탭(룸 목록)에서 룸 목록을 확인하세요. 룸을 펼치면 참가자를 볼 수 있어요. 특정 사용자나 룸을 찾으려면 **사용자 검색**을 사용하세요.

룸 옆의 **참여**를 클릭하면 그 토론에 들어가요. 필요하면 참가자를 다른 룸으로 옮길 수도 있어요.

![진행 중인 소회의실 목록과 참여 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084152662/original/6dhx-4rL-epWPB4fZPgieFwzIgYFplSJ4A.png?1792976145)

### 모든 룸에 메시지 보내기

각 토론에 들어가지 않아도 모든 소회의실에 안내나 알림을 전할 수 있어요.

1. 소회의실 패널 아래쪽의 **Broadcast**(전체 공지)를 클릭하세요.
2. **Message to all rooms**(모든 룸에 보낼 메시지)에 내용을 입력하세요.
3. **보내기**를 클릭하세요.

예를 들어 "발표자를 한 명 정하세요", "돌아올 때 공유할 아이디어를 하나씩 준비하세요" 같은 안내를 보낼 수 있어요.

### 타이머 관리하고 룸 닫기

**Close after**로 자동 종료 시간을 설정하세요. 시간이 정해진 세션에서는 호스트 패널에 남은 시간이 표시돼요. 그룹에 시간이 더 필요하면 세션을 연장할 수도 있어요.

소회의실 하나만 끝내려면 해당 룸의 점 세 개 메뉴를 열고 **Close room**(룸 닫기)을 선택하세요. 모든 그룹을 돌아오게 하려면 **Close all rooms**(모든 룸 닫기)를 클릭하세요.

종료 카운트다운을 켜 두었다면 참가자는 메인 미팅으로 돌아오기 전에 카운트다운을 보게 돼요.

### 룸별로 녹음하고 받아쓰기

녹음과 실시간 받아쓰기는 소회의실마다 따로 관리해요. 룸의 점 세 개 메뉴에서 제어할 수 있어요.

| 작업 | 사용 방법 |
| --- | --- |
| 녹음 시작 또는 중지 | 룸의 녹음 컨트롤로 그 룸의 녹음을 관리하세요. 녹음 중에는 메뉴에 **녹음 중지**가 나타나요. |
| 실시간 받아쓰기 시작 | 룸 메뉴에서 **Transcribe this room**(이 룸 받아쓰기)을 선택하세요. |
| 실시간 받아쓰기 중지 | 해당 룸의 받아쓰기 컨트롤로 녹음과 별개로 받아쓰기를 중지하세요. |
| 진행 상태 확인 | 룸의 녹음·받아쓰기 표시를 확인하세요. 녹음 중인 룸 옆에는 **REC** 표시가 나타나요. |

```
녹음과 받아쓰기는 룸마다 따로 관리하세요. 두 기능은 별도 컨트롤이므로, 녹음하거나 받아쓰려는 룸의 상태를 각각 확인하세요.
```

## 참가자가 룸에 참여하고 옮기는 방법

참가자가 겪는 화면은 호스트가 정한 배정 방식과 이동 설정에 따라 달라져요.

### 배정된 룸에 참여하기

배정된 룸에 초대되면 참가자에게 룸 이름이 적힌 **Join breakout room**(소회의실 참여) 창이 나타나요.

**참여**를 클릭하면 룸에 들어가요. 지금은 들어가지 않고 초대 창만 닫으려면 **나중에**를 클릭하세요.

**Auto-move people to rooms**를 켜 두었다면 배정된 참가자는 초대를 수락하지 않아도 자동으로 이동해요.

![배정된 룸 참여 초대 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084152663/original/EIhMV4sIuQ3Fqeggq28t63AD5icQDCT-TA.png?1792976178)

### 룸 선택하고 옮기기

호스트가 참가자에게 룸 선택을 허용하면, 미팅 도구 모음에서 **Breakout Rooms**를 열어 **Choose a room**(룸 선택) 창을 볼 수 있어요.

참여할 수 있는 룸을 확인하고, 룸을 펼쳐 참가자를 살펴본 뒤, 들어가려는 룸 옆의 **참여**를 클릭하세요.

호스트가 룸 전환을 허용하면 참가자는 룸을 옮길 수 있어요.

![참가자가 룸을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084152672/original/uaYN41kkazp_iQ7rm-c_fyzx3AVcII5xzw.png?1792976194)

### 메인 미팅으로 돌아가기

호스트가 **Allow return to main room**을 켜 두면 소회의실이 진행되는 동안에도 참가자가 메인 미팅으로 돌아올 수 있어요.

룸이 닫히는 중에는 참가자에게 종료 카운트다운이 보여요. 카운트다운이 끝나기 전에 돌아가려면 **Return now**(지금 돌아가기)를 클릭하세요. 클릭하지 않아도 룸이 닫히면 자동으로 돌아와요.

## 알아 두세요

- 룸 개수 제한: 한 세션에서 최대 **100개**까지 소회의실을 만들 수 있어요. 이 숫자는 소회의실의 개수이고, 참가자 수 제한을 뜻하지 않아요.
- 임시 저장과 열린 룸의 차이: **Create rooms**는 룸 계획만 준비해요. **Open all rooms**를 클릭해야 소회의실 세션이 시작돼요.
- 참가자 권한: 룸 선택, 룸 전환, 메인 미팅 복귀는 호스트의 설정에 따라 달라져요.
- 룸별 녹음·받아쓰기: 녹음과 실시간 받아쓰기는 룸마다 따로 관리해요. 모든 룸에 같은 설정이 적용된다고 생각하지 말고, 해당 룸의 상태 표시를 확인하세요.

## 자주 묻는 질문

### 소회의실은 몇 개까지 만들 수 있나요?
한 세션에서 최대 **100개**까지 만들 수 있어요.

### 룸을 만들면 참가자가 바로 메인 미팅에서 이동하나요?
아니요. **Open all rooms**를 클릭하기 전까지 룸은 임시 저장 상태로 남아요. 룸이 열린 뒤에는 설정에 따라 참가자가 초대를 통해 참여하거나, 자동으로 이동하거나, 룸을 직접 골라요.

### 자동 배정과 자동 이동은 무엇이 다른가요?
자동 배정은 참가자가 어느 룸에 배정될지를 정해요. 자동 이동은 배정된 참가자가 **참여**를 클릭하지 않아도 그 룸으로 이동할지를 정해요.

### 일부 참가자가 미지정에 표시돼요. 왜 그런가요?
이 참가자들은 아직 배정된 소회의실이 없어요. **미지정** 섹션을 확인하고, 특정 그룹에 들어가야 하는 참가자를 배정하세요.

### 참가자가 룸을 직접 고르거나 옮길 수 있나요?
네. 룸을 만들 때 **Let participants choose**를 선택하면 참가자가 룸을 고를 수 있어요. 룸 사이를 이동하게 하려면 **선택지**에서 **Let people switch rooms**를 켜세요.

### 모든 룸에 같은 안내를 보낼 수 있나요?
네. **Broadcast**를 클릭해 메시지를 입력하고 **보내기**를 클릭하면 모든 소회의실에 전달돼요.

### 모든 룸이 아니라 한 룸만 녹음할 수 있나요?
네. 녹음은 소회의실마다 따로 관리해요. 실시간 받아쓰기도 룸마다 따로 제어해요.

### 소회의실 세션이 끝나기 전에 참가자가 돌아올 수 있나요?
호스트가 **Allow return to main room**을 켜 두었다면 가능해요. 종료 카운트다운 중에는 참가자가 **Return now**를 클릭해 돌아올 수도 있어요.
