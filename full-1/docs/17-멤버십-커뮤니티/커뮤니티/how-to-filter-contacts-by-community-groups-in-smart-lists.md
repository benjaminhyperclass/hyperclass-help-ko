# 스마트 리스트에서 커뮤니티 그룹별로 연락처 필터링하기

**스마트 리스트**의 **그룹** 필터를 쓰면 연락처가 속한 커뮤니티 그룹을 기준으로 연락처를 나눌 수 있어요. 그룹별로 맞춤 캠페인을 보내거나 연락처 목록을 커뮤니티 중심으로 정리할 때 활용해 보세요.

## 스마트 리스트의 그룹 필터란?

**그룹** 필터는 **스마트 리스트**에 새로 추가된 필터예요. 연락처가 속한 커뮤니티 그룹을 기준으로 연락처를 나누고 관리할 수 있어요.

연락처에 태그를 하나씩 달거나 직접 분류하지 않아도 돼요. 커뮤니티 멤버십을 기준으로 연락처를 정확히 걸러 내고, 클릭 몇 번으로 대상이 분명한 목록을 만들 수 있어요.

## 그룹 필터를 쓰면 좋은 점

- 연락처를 소속된 커뮤니티 그룹별로 쉽게 나눌 수 있어요.
- 그룹마다 다른 캠페인과 맞춤 커뮤니케이션을 보낼 수 있어요.
- 직접 분류하지 않고 커뮤니티 기준 분류를 자동으로 처리해 시간을 아낄 수 있어요.
- 연락처 목록을 커뮤니티 전략에 맞게 정리해 둘 수 있어요.
- 커뮤니티에 맞춘 소통으로 참여도와 전환율을 높일 수 있어요.

## 그룹 필터 사용 방법

**스마트 리스트**에서 커뮤니티 그룹별로 연락처를 거르는 방법은 간단해요. 다음 단계를 따르세요.

1. **연락처 > 스마트 리스트**로 이동하세요.
2. **필터**를 클릭하세요.

   ![필터 버튼을 클릭한 화면](https://jumpshare.com/share/kV8LKuxegglnn7spd0a2+/Screen+Shot+2026-09-16+at+15.52.51.png)

3. **그룹** 필터를 찾으세요.
   - 아래로 스크롤해서 **클라이언트 포탈** 섹션에서 찾거나,
   - 검색창에 "그룹" 또는 "클라이언트 포탈"을 입력하면 새로 생긴 **그룹** 필터를 빠르게 찾을 수 있어요.
4. **그룹**을 클릭한 뒤 다음 중 하나를 선택하세요.
   - **그룹** = **is empty**(비어 있음): 어느 그룹에도 속하지 않은 연락처
   - **그룹** = **is not empty**(비어 있지 않음): 어느 그룹에든 속한 연락처
   - **그룹** = **is**(다음과 같음): 필터링하려는 특정 그룹
5. **적용**을 클릭하세요.

   ![필터를 적용하는 과정을 보여 주는 화면 녹화](https://jumpshare.com/share/nUUlVjbeW57jECADXrNX+/GIF+Recording+2026-09-16+at+15.58.18.gif)

6. 이제 **스마트 리스트**에 선택한 그룹에 속한 연락처만 표시돼요. 해당 연락처를 관리하고 직접 소통하기 쉬워져요.

   ![선택한 그룹의 연락처만 표시된 스마트 리스트](https://jumpshare.com/share/wwe8b7hnxKJBDgGgSyui+/Screen+Shot+2026-09-16+at+15.59.45.png)

## 자주 묻는 질문

### 필터에서 여러 그룹을 한 번에 선택할 수 있나요?
네, 커뮤니티 그룹을 하나 또는 여러 개 선택해서 원하는 대로 세밀하게 연락처를 나눌 수 있어요.

### 이 필터를 스마트 리스트의 다른 필터와 함께 쓸 수 있나요?
네, 가능해요. **그룹** 필터를 태그, 커스텀 필드, 활동 같은 다른 필터와 함께 쓰면 더 정교한 목록을 만들 수 있어요.

### 이 필터를 쓰려면 연락처에 태그를 직접 달아야 하나요?
아니요. 필터가 커뮤니티 그룹의 멤버십 데이터를 자동으로 불러오기 때문에 따로 태그를 달 필요가 없어요.

### 커뮤니티 그룹은 어디에서 관리하나요?
**클라이언트 포탈** 설정의 **커뮤니티**에서 커뮤니티 그룹을 만들고 관리할 수 있어요.
