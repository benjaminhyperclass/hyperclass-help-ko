# 커뮤니티 라이브 세션 개선 사항: 개인 미팅 링크, 녹화 허브, 노이즈 캔슬링

커뮤니티 **라이브 세션**에 **Personal Meeting Link**(개인 미팅 링크), **Recordings Hub**(녹화 허브), 향상된 노이즈 캔슬링이 추가되었어요. 커뮤니티 운영자, 코치, 교육자, 이벤트 진행자는 세션을 더 효율적으로 운영할 수 있고, 참석자는 더 선명하고 몰입감 있는 세션을 경험할 수 있어요. 정기 모임, 교육 세션, 라이브 커뮤니티 이벤트를 진행할 때 하이퍼클래스 안에서 더 쉽게 진행하고, 공유하고, 확장할 수 있어요.

## 커뮤니티 라이브 세션 개선 사항이란?

하이퍼클래스 커뮤니티에서 라이브 콘텐츠를 진행하고, 관리하고, 다시 활용하는 과정을 단순하게 만들어 주는 새 도구예요. 재사용할 수 있는 개인 미팅 링크, 한곳에 모인 녹화본, 더 선명해진 음질 덕분에 호스트는 일관되고 깔끔한 경험을 제공할 수 있어요. 미팅을 준비하고 관리하는 수작업도 줄어요.

일관성과 접근 편의성이 중요한 정기 코칭 콜, 온보딩 세션, 워크숍, 오피스 아워, 커뮤니티 주도 토론에 특히 유용해요.

## 주요 장점

이번 개선으로 라이브 세션 전, 중, 후의 불편이 줄어서 호스트와 참석자 모두 더 편해져요.

- 개인 미팅 링크: 미팅룸 링크 하나를 만들어 정기 미팅, 이벤트, 1:1 세션에 계속 공유할 수 있어요.
- 전문적인 브랜딩: 전용 미팅 URL로 더 일관되고 깔끔한 경험을 제공해요.
- 한곳에 모인 녹화 허브: 녹화본을 한곳에서 확인하고, 관리하고, 다시 재생하고, 다운로드하고, 삭제할 수 있어요.
- 콘텐츠 재활용: 라이브 세션을 교육, 온보딩, 학습 콘텐츠로 다시 활용할 수 있어요.
- 향상된 노이즈 캔슬링: 배경 소음을 줄여 세션 중 음성이 더 또렷하게 들려요.
- 빨라진 작업 흐름: 새 링크를 만들거나 녹화본을 찾는 시간이 줄어요.
- 참석자 경험 개선: 참석자가 세션에 빠르게 입장하고 더 선명하게 대화할 수 있어요.

## Personal Meeting Link

**Personal Meeting Link**(개인 미팅 링크)는 호스트 전용으로 계속 쓸 수 있는 미팅룸이에요. 세션을 열 때마다 새 링크를 만들 필요 없이, 링크 하나를 정기 미팅, 오피스 아워, 코칭 콜, 워크숍, 커뮤니티 토론에 계속 공유하면 돼요.

## Recordings Hub

**Recordings Hub**(녹화 허브)는 모든 세션 녹화본을 한곳에 모아 둔 공간이에요. 호스트는 지난 세션을 빠르게 살펴보고, 중요한 논의를 다시 재생하고, 외부에서 쓰려고 녹화본을 다운로드하고, 더 이상 필요 없는 녹화본을 삭제할 수 있어요.

## 향상된 노이즈 캔슬링

향상된 노이즈 캔슬링은 원치 않는 배경 소리와 방해 요소를 줄여서 라이브 세션의 음질을 높여요. 환경이 조용하지 않아도 호스트와 참석자가 더 또렷하게 대화할 수 있어요.

음질이 좋아지면 더 전문적인 세션이 되고, 미팅과 이벤트 내내 참석자의 집중도도 유지돼요.

## 개인 미팅 링크 설정하기

개인 미팅 링크를 잘 설정해 두면 참석자가 매끄럽게 입장할 수 있고, 세션마다 새 링크를 만들 필요도 없어요.

### 1단계: 커뮤니티 라이브 세션 설정으로 이동하기

1. 하이퍼클래스에 로그인하세요.
2. **커뮤니티** 대시보드를 여세요.
3. **라이브 세션** 또는 **Meeting Settings**(미팅 설정) 영역으로 이동하세요.
4. **Personal Meeting Link** 섹션을 찾으세요.

### 2단계: 개인 미팅 링크 설정하기

1. 미팅 URL을 만들거나 원하는 대로 바꾸세요.

   ![개인 미팅 링크 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072839593/original/BYUumf4Snt9r1j49dMdxlVnHP0XxtoIndQ.png?1780502190)

   ![미팅 URL 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072838611/original/Mw4oOTUgLPUisRLKR1isKISeQG5cLSNddw.png?1780501652)
2. **변경사항 저장**을 선택하세요.
3. 공유할 미팅 링크를 복사하세요.

### 3단계: 미팅 링크 공유하기

개인 미팅 링크는 다음과 같은 곳에서 공유할 수 있어요.

- 커뮤니티 게시글
- 이벤트 페이지
- 이메일 캠페인
- 캘린더 초대
- 다이렉트 메시지

이렇게 하면 참석자는 늘 같은 미팅 URL로 세션에 입장할 수 있어요.

## 녹화본 확인하고 관리하기

녹화본을 한곳에서 관리하면 콘텐츠를 정리하기 쉽고, 커뮤니티 멤버에게 꾸준히 가치를 줄 수 있어요.

![녹화 허브 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072838794/original/w2ntRiHvO8ZqydfqrDAsZhpNw3kldwHQEQ.png?1780501767)

### 1단계: 녹화 허브 열기

1. **커뮤니티**로 이동하세요.
2. **라이브 세션** 또는 **Recordings**(녹화) 영역을 여세요.
3. **Recordings Hub**를 선택하세요.

### 2단계: 녹화본 확인하기

**Recordings Hub**에서는 다음 작업을 할 수 있어요.

- 이전 녹화본 둘러보기
- 특정 세션 검색하기
- 녹화본을 열어 재생하기

![녹화본 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072838822/original/LZn9y_nM42vPaGsN11bHIaRDQM-SScF0kw.png?1780501790)

### 3단계: 녹화본 다운로드 또는 삭제하기

녹화본을 선택하면 다음 작업을 할 수 있어요.

- 파일 다운로드
- 녹화본 다시 재생
- 필요 없어진 녹화본 삭제

## 자주 묻는 질문

### 정기 세션에 같은 개인 미팅 링크를 계속 써도 되나요?

네. 개인 미팅 링크는 정기 미팅, 이벤트, 코칭 콜, 라이브 세션에 계속 재사용할 수 있도록 만들어졌어요.

### 세션 녹화본은 어디에서 찾나요?

사용할 수 있는 모든 녹화본은 **Recordings Hub**에서 확인할 수 있어요.

### 녹화 허브에서 녹화본을 다운로드할 수 있나요?

네. 호스트는 외부 보관, 공유, 재활용을 위해 녹화본을 다운로드할 수 있어요.

### 녹화본을 삭제할 수 있나요?

네. 더 이상 필요 없는 녹화본은 **Recordings Hub**에서 바로 삭제할 수 있어요.

### 향상된 노이즈 캔슬링은 자동으로 작동하나요?

노이즈 캔슬링 개선은 라이브 세션의 음질을 높이기 위한 기능이에요. 미팅 환경과 설정에 따라 자동으로 켜질 수도 있어요.

### 참석자가 매번 같은 개인 미팅 링크로 입장할 수 있나요?

네. 재사용할 수 있는 같은 미팅 링크를 참석자에게 공유하면 이후 세션에도 계속 쓸 수 있어요.

### 개인 미팅 링크를 1:1 미팅에도 쓸 수 있나요?

네. 개인 미팅 링크는 정기 고객 미팅, 오피스 아워, 상담, 코칭 세션에 잘 맞아요.

### 녹화본을 온보딩이나 교육에 활용할 수 있나요?

네. 많은 호스트가 세션 녹화본으로 학습 라이브러리, 온보딩 자료, 멤버 교육 콘텐츠를 만들어요.
