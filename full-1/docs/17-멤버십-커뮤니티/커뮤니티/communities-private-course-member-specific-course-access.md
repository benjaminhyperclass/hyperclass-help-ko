# 커뮤니티 비공개 코스와 멤버별 코스 접근 권한 설정

커뮤니티 관리자는 **멤버** 탭에서 멤버 한 명 한 명에게 코스 접근 권한을 직접 부여하거나 회수할 수 있어요. 관리자가 권한을 부여해야만 들어갈 수 있는 비공개 코스도 만들 수 있어요. 이 문서에서는 비공개 코스를 만드는 방법과 특정 멤버의 코스 접근 권한을 부여·회수하는 방법을 안내해요.

## 멤버별 코스 접근 권한과 비공개 코스란?

멤버별 코스 접근 권한을 쓰면 커뮤니티 관리자가 커뮤니티 안의 특정 코스에 누가 들어올 수 있는지 직접 정할 수 있어요. 레벨, 시간, 유료 결제, 전체 공개 같은 자동 잠금 해제 기준에만 의존하지 않고, 멤버 개인에게 접근 권한을 부여하거나 회수할 수 있어요. 비공개 코스는 여기서 한 걸음 더 나아가, 관리자가 직접 승인해야만 접근할 수 있게 해 줘요.

## 멤버별 코스 접근 권한과 비공개 코스의 장점

- 직접 관리: 특정 멤버에게 원하는 코스의 접근 권한을 언제든 부여하거나 회수할 수 있어요.
- 비공개 코스 유형: 자동으로 잠금이 해제되지 않고 관리자 승인이 필요한 코스를 만들 수 있어요.
- 즉시 접근: 레벨, 결제, 시간 기준을 바꾸지 않아도 코스를 바로 열어 줄 수 있어요.
- 기존 기준 유지: 자동 잠금 해제 기준은 그대로 유지되며, 부적절하게 덮어쓸 수 없어요.

## 비공개 코스 공개 범위

비공개 코스는 특정 멤버에게만 열어 주거나 접근을 엄격히 관리하고 싶은 학습 환경에 알맞아요. 코스를 비공개로 설정하면 멤버는 레벨 상승, 구매, 시간 경과로 코스를 자동으로 열 수 없어요. 접근 권한은 관리자만 부여할 수 있어요.

비공개 코스는 이런 경우에 잘 맞아요.

- VIP 또는 프리미엄 콘텐츠
- 사내 팀 교육
- 초대 전용 프로그램

## 비공개 코스를 학습 탭에 추가하기

비공개 접근을 쓰려면 먼저 커뮤니티 **학습** 탭에 코스를 비공개로 추가해야 해요. 이렇게 하면 관리자가 직접 권한을 부여하기 전까지 코스가 잠긴 상태로 보여요.

1. 서브 계정에서 **멤버십**을 클릭하세요.
2. **커뮤니티**로 이동하세요.
3. 드롭다운에서 **그룹**을 클릭하세요.

   ![그룹 드롭다운 메뉴](https://jumpshare.com/share/F7VQklFSnqf9q7s8Sp8l+/Screenshot+2026-02-10+at+12.45.46%E2%80%AFAM.png)
4. 그룹에서 **진행 중** 또는 **로그인**을 클릭해 들어가세요.

   ![그룹 열기 또는 로그인](https://jumpshare.com/share/E57Y9g9gMoqiDrCtMJPT+/Screen+Shot+2026-02-10+at+12.49.05+AM.png)
5. **학습** 탭을 클릭하세요.

   ![학습 탭](https://jumpshare.com/share/MCTFvms6R8SiYDqEHUMC+/Screen+Shot+2026-02-23+at+18.19.49.png)
6. **코스 추가**를 클릭하세요.
7. 이미 만들어 둔 코스를 선택하세요.
8. **Course Visibility**(코스 공개 범위)에서 **Private – Access granted by admin only**(비공개 – 관리자가 승인한 경우에만 접근 가능)를 선택하세요.
9. **코스 추가**를 클릭하세요.

   ![비공개 코스 추가 과정](https://jumpshare.com/share/DeaC2N6gyPD9N2WDxpKh+/GIF+Recording+2026-02-23+at+18.21.16.gif)

## 멤버에게 코스 접근 권한 부여하기

관리자는 커뮤니티의 **멤버** 탭에서 어떤 코스든 접근 권한을 바로 부여할 수 있어요. 코스의 잠금 해제 설정을 바꾸지 않아도 돼요. 코스가 열리면 멤버에게 이메일 알림이 가요.

1. 그룹의 **멤버** 탭으로 이동하세요.

   ![멤버 탭](https://jumpshare.com/share/DnV9szq6hILXZabUq2LI+/Screen+Shot+2026-02-23+at+18.26.36.png)
2. 멤버 옆의 점 3개(⋮) 메뉴를 클릭하세요.
3. **Manage Courses**(코스 관리)를 선택하세요.

   ![코스 관리 메뉴 선택](https://jumpshare.com/share/mSuBev62B8o9ur70qaQ1+/Screen+Shot+2026-02-23+at+18.28.34.png)
4. **Grant Courses**(코스 부여) 버튼을 클릭하세요.

   ![코스 부여 버튼](https://jumpshare.com/share/d1jh401IapMjLMzRrjE5+/Screen+Shot+2026-02-23+at+18.30.47.png)
5. 코스를 하나 이상 선택하세요.
6. **Grant**(부여)를 클릭하세요.

   ![코스 선택 후 부여](https://jumpshare.com/share/dwBcR0ADkKmN5ksoXNjk+/Screen+Shot+2026-02-23+at+18.43.29.png)

## 멤버의 코스 접근 권한 회수하기

{% hint style="info" %}
멤버가 이미 코스의 잠금 해제 기준(예: 전체 멤버, 레벨 잠금 해제, 유료, 시간 잠금 해제)을 충족했다면 접근 권한을 회수할 수 없어요.
{% endhint %}

부여할 때와 같은 **Manage Courses** 화면에서 코스 접근 권한을 회수할 수 있어요. 방법은 다음과 같아요.

1. 그룹의 **멤버** 탭으로 이동하세요.

   ![멤버 탭](https://jumpshare.com/share/DnV9szq6hILXZabUq2LI+/Screen+Shot+2026-02-23+at+18.26.36.png)
2. 멤버 옆의 점 3개(⋮) 메뉴를 클릭하세요.
3. **Manage Courses**를 선택하세요.

   ![코스 관리 메뉴 선택](https://jumpshare.com/share/mSuBev62B8o9ur70qaQ1+/Screen+Shot+2026-02-23+at+18.28.34.png)
4. 코스 옆의 빨간색 X 아이콘을 클릭하세요.

   ![코스 옆 빨간색 X 아이콘](https://jumpshare.com/share/qNC3dAO7tWUoxpMzZPnr+/Screen+Shot+2026-02-23+at+18.48.20.png)
5. **확인**을 클릭하세요.

   ![회수 확인](https://jumpshare.com/share/4368EIoABsEheWzIdEy5+/Screen+Shot+2026-02-23+at+18.49.58.png)

## 자주 묻는 질문

### 비공개가 아닌 코스에도 접근 권한을 부여할 수 있나요?
네. 관리자는 모든 유형의 코스에 접근 권한을 직접 부여할 수 있어요.

### 멤버의 접근 권한을 회수할 수 없어요.
멤버가 이미 코스의 잠금 해제 기준(전체 멤버, 레벨 잠금 해제, 시간 잠금 해제, 유료 등)을 충족했다면 접근 권한을 회수할 수 없어요.

### 접근 권한을 부여하면 멤버에게 알림이 가나요?
네. 코스를 직접 열어 주면 이메일 알림이 전송돼요.

### 비공개 코스도 자동으로 잠금이 해제될 수 있나요?
아니요. 비공개 코스는 관리자가 직접 승인해야 하며, 자동화로는 잠금을 해제할 수 없어요.
