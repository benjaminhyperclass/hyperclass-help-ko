# 커뮤니티에서 멤버 차단하기, 콘텐츠 신고 처리하기

그룹 관리자와 소유자는 멤버를 그룹에서 차단할 수 있고, 멤버가 신고한 게시글과 댓글을 확인해 처리할 수 있어요. 이 문서에서는 두 기능의 쓰임새와 웹·모바일에서 찾는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/m3pQscoyu28?&wmode=opaque)

## 멤버 차단

그룹 관리자와 소유자는 멤버를 그룹에서 차단할 수 있어요. 차단된 멤버는 그룹에서 제거되고, 그 그룹에 다시 가입할 수 없어요. 일반 멤버가 할 수 있는 활동도 모두 할 수 없게 돼요.

## 콘텐츠 신고

사용자는 게시글과 댓글을 신고할 수 있어요. 그룹 관리자는 신고된 콘텐츠 목록을 보고, 해당 게시글이나 댓글을 유지할지 제거할지 정할 수 있어요. 콘텐츠가 신고되면 그룹 관리자에게 이메일, 앱 내 알림, 푸시 알림이 전송돼요.

{% hint style="info" %}
신고된 콘텐츠는 커뮤니티 사용자가 게시글이나 댓글을 직접 신고하면 검토 대상으로 접수돼요. 이는 자동 커뮤니티 검토와 달라요. 자동 검토는 관리자가 설정한 키워드, 문구, 도메인과 일치하는 콘텐츠를 게시 전에 보류해요. 자세한 내용은 "커뮤니티에서 게시글과 댓글을 자동으로 검토하는 방법" 문서를 참고하세요.
{% endhint %}

## 기능 찾는 방법

### 멤버 차단하기 (웹)

1. **Members**(멤버) 탭으로 이동하세요.
2. 차단하려는 멤버의 **더 보기** 아이콘(점 세 개 아이콘)을 클릭하세요.
3. **Ban from group**(그룹에서 차단)을 클릭하세요.

### 멤버 차단하기 (모바일)

1. 커뮤니티 홈에서 **관리** 버튼을 누르세요. 관리자에게만 보이는 버튼이에요.
2. 커뮤니티 설정 페이지에서 **Members**(멤버)를 누르세요.
3. 차단하려는 멤버의 **더 보기** 아이콘(점 세 개 아이콘)을 누르세요.
4. **Ban from group**(그룹에서 차단)을 누르세요.

### 신고된 콘텐츠 확인하기 (웹)

1. 커뮤니티 홈에서 **설정**을 클릭하세요.
2. **Reported content**(리포트된 콘텐츠) 탭을 선택하세요.
3. 신고된 콘텐츠가 있으면 목록에 표시돼요. 각 항목의 **유지** 또는 **제거**를 선택해 처리하세요.

### 신고된 콘텐츠 확인하기 (모바일)

1. 커뮤니티 홈에서 **관리** 버튼을 누르세요. 관리자에게만 보이는 버튼이에요.
2. 커뮤니티 설정 페이지에서 **To Review**(검토 대기)를 누르세요.
3. 신고된 콘텐츠가 있으면 목록에 표시돼요. 각 항목의 **유지** 또는 **제거**를 선택해 처리하세요.

### 콘텐츠 신고하기

1. 신고하려는 게시글이나 댓글의 **더 보기** 아이콘(점 세 개 아이콘)을 클릭하세요.
2. **리포트**를 클릭하세요.

신고가 접수되면 콘텐츠가 신고되었다는 토스트 알림이 멤버에게 표시돼요.
