# 미팅: 일회성·반복 통화에 쓰는 재사용 링크

링크 하나를 모든 세션에 계속 쓸 수 있어요. 새 URL을 만들거나 초대장을 다시 보내거나 만료된 링크를 관리할 필요가 없어요. 이 문서에서는 재사용 링크의 원리와 장점, 그리고 개인 미팅 URL을 확인하고 공유하는 방법을 안내해요.

미팅은 재사용 링크를 기반으로 한, 하이퍼클래스 자체 화상 미팅 기능이에요. 통화할 때마다 새 URL을 만드는 대신 링크를 하나 만들어 두고 여러 세션에 계속 쓸 수 있어요. 한 번뿐인 상담이든 1년 동안 이어지는 코칭이든 마찬가지예요.

## 미팅이란?

미팅은 하이퍼클래스에 내장된 링크 기반 미팅 기능이에요. 실시간 화상 세션용 URL을 한 번 만들어 두고 계속 재사용해요. 코칭 통화, 고객 점검 미팅, 팀 회의처럼 사람들이 쉽고 일관되게 참여해야 하는 정기 모임에 알맞아요.

내부적으로는 하이퍼클래스의 실시간 화상 기술을 사용해요. 인터랙티브 비디오 룸 등 다른 라이브 기능과 같은 기반이에요. 그래서 호스트와 참석자는 별도 소프트웨어 없이 브라우저에서 서로 보고 듣고 함께 작업할 수 있어요.

## 미팅의 주요 장점

장점을 알아 두면 일반 캘린더 초대나 외부 도구 대신 미팅을 쓸 때를 판단하기 쉬워요.

- 늘 같은 링크: 고객이나 팀원에게 미팅 URL을 한 번만 공유하고 모든 세션에 다시 써요. 링크가 계속 바뀌어서 생기는 혼란이 없어요.
- 일회성과 반복 세션 모두 지원: 한 번뿐인 전략 통화든 매주 열리는 코칭 프로그램이든 같은 방식으로 써요. 미팅마다 링크를 바꾸지 않아도 돼요.
- 필요할 때 바로 시작: 호스트는 원하는 때 미팅을 시작할 수 있어요. 참석자는 같은 링크로 들어오면 되고, 추가 설정이나 다시 만들기는 필요 없어요.
- 간편한 참석 경험: 참석자는 링크를 클릭하고, 일찍 들어왔다면 호스트가 시작할 때까지 기다려요. 룸이 열리면 바로 참여해요.
- 한눈에 보는 미팅 기록: 지난 세션이 한곳에 기록돼요. 언제 만났는지, 세션이 얼마나 진행됐는지, 누가 참석했는지 확인할 수 있어서 후속 조치와 기록 관리에 도움이 돼요.
- 관리할 도구 감소: 미팅은 하이퍼클래스의 화상 기능에 내장되어 있어요. 외부 미팅 서비스에 덜 의존하고 업무를 한 시스템에서 처리할 수 있어요.

## 재사용 미팅 링크

재사용 미팅 링크는 통화마다 새 URL을 만들지 않고 원하는 만큼 열고 닫을 수 있는 고정된 "룸"이에요. "어떤 링크로 들어가야 하지?" 하는 혼선을 줄여 줘요.

미팅을 만들면 이렇게 돼요.

- 하이퍼클래스가 계속 재사용할 수 있는 URL을 하나 만들어 줘요.
- 고객, 수강생, 내부 팀에 한 번만 공유하면 돼요.
- 같은 링크로 오늘 통화, 다음 주 후속 미팅, 이후의 점검 미팅이나 오피스 아워에 모두 참여할 수 있어요. 해당 미팅 공간을 계속 사용하는 동안에는 그래요.

반면 캘린더 기반 도구 중에는 반복 일정의 회차마다 기본적으로 새 미팅 URL을 만드는 경우가 많아요. 그러면 시간이 지나면서 서로 다른 링크가 여러 개 쓰이게 돼요. 미팅은 고정된 룸처럼 동작하도록 설계했어요. 주소는 하나이고 세션은 여러 번이에요.

### 재사용 링크 활용 예시

- 코치가 "A 고객 – 주간 코칭룸"을 만들고 온보딩 때 링크 하나만 보내요.
- 에이전시가 "디자인팀 스탠드업"을 만들고 Slack이나 커뮤니티에 링크를 고정해 둬요.
- 컨설턴트가 같은 링크를 여러 리마인더 이메일, 퍼널, 자동화에 넣어요.

[스크린샷: 미팅 이름과 재사용 링크, URL 복사 아이콘이 표시된 미팅 목록 예시]

## 일회성 미팅과 반복 미팅

일회성과 반복 옵션 중에서 실제 업무 방식에 맞게 고를 수 있어요. 한 번뿐인 전략 세션이든 같은 그룹과 이어 가는 장기 시리즈든 괜찮아요. 하이퍼클래스가 반복 캘린더와 웨비나에 적용하는 방식을 실시간 통화에도 똑같이 적용해요.

### 일회성 미팅

단일 세션 또는 이벤트에 알맞아요.

일회성 상담, 온보딩 통화, 진단, 특별 이벤트에 좋아요. 나중에 다시 만나기로 하면 깔끔한 재사용 링크를 그대로 쓸 수 있어요. 다만 일정은 한 번의 세션으로 구성해요.

### 반복 미팅

하나의 링크로 이어 가는 시리즈에 알맞아요.

주간 동기화 미팅, 기수별 코칭, 마스터마인드 그룹, 지속 계약 고객 미팅에 좋아요. 시리즈의 모든 세션이 같은 미팅 링크를 써요. 그래서 참석자는 늘 같은 곳으로 들어오면 돼요. 반복 웨비나가 시리즈 전체에 하나의 방송 URL을 쓰는 것과 비슷해요.

링크와 일정이 분리되어 있어서, 핵심 URL을 새로 만들거나 바꾸지 않고도 예약 시간, 반복 주기, 리마인더를 수정할 수 있어요.

[스크린샷: 미팅 이름, 유형(일회성/반복), 일정 세부 정보를 설정하는 새 미팅 설정 패널]

## 언제든 시작하고 바로 참여하기

미팅은 깨지기 쉬운 캘린더 초대보다는, 필요할 때 늘 준비되어 있는 전용 "룸"에 가까워요.

- 호스트는 원하는 때 시작할 수 있어요: 하이퍼클래스에서 선택한 진입 경로로 미팅을 열어요. 룸을 쓰기 전에 캘린더 시작 시간이 되어야 하는 것은 아니에요.
- 참석자는 같은 링크로 참여해요: URL을 클릭하면 라이브 미팅 화면으로 안내돼요. 내부 화상 룸은 하이퍼클래스의 실시간 화상 엔진을 쓰기 때문에 여러 참가자가 음성, 영상, 채팅 등 다양한 기능으로 함께할 수 있어요.
- 반복 설정이 필요 없어요: 만날 때마다 호스트 제어 기능을 다시 설정하거나 룸을 다시 구성하지 않아도 돼요. 인터랙티브 비디오 룸처럼 같은 환경을 통화마다 그대로 재사용해요.

이런 유연함은 다음 상황에서 특히 유용해요.

- 즉석 점검 미팅(예: "늘 쓰던 미팅 링크로 들어올 수 있을까요?")
- 호스트가 조금 일찍 또는 늦게 시작할 수 있는 오피스 아워
- 상시 "워룸"이나 매일 스탠드업 링크가 필요한 내부 팀

## 간단하고 부담 없는 참여

기술에 익숙한 사용자도, 그렇지 않은 사용자도 최소한의 노력으로 룸에 들어올 수 있게 만들었어요.

- 참석자에게 필요한 건 링크뿐이에요: 외부 도구에 계정을 만들 필요가 없어요. 최신 브라우저에서는 앱을 내려받지 않아도 돼요. 다른 하이퍼클래스 라이브 화상 기능과 비슷해요.
- 호스트가 오기 전에도 상태가 분명해요: 참석자가 일찍 링크를 클릭하면, 오류나 만료 메시지 대신 미팅이 아직 시작되지 않았다는 안내가 나와요. 호스트가 미팅을 시작하면 같은 페이지에서 바로 참여할 수 있어요.
- 일관된 기대: 세션마다 링크가 바뀌지 않으니, 참석자는 링크를 북마크하거나 메모에 저장하거나 공유 채널에 고정해 둘 수 있어요.

{% hint style="info" %}
미팅 링크는 하이퍼클래스의 다른 도구와 함께 쓸 수 있어요. 예를 들어 이메일·SMS 캠페인으로 링크를 보내거나, 라이브 세션이 열리는 멤버십 영역과 커뮤니티 게시글에 링크를 넣을 수 있어요.
{% endhint %}

## 미팅 기록 확인하기

미팅 기록을 보면 이미 진행된 일을 파악할 수 있어요. 후속 조치, 참여도 분석, 필요할 때의 감사 기록에 활용해요.

- 지난 세션을 한곳에서 확인: 특정 미팅 링크에 연결된 완료 세션 목록을 볼 수 있어요. 어느 날 만났고 어떤 세션이 일정대로 진행됐는지 빠르게 훑어볼 수 있어요.
- 세션 세부 정보 검토: 세션 진행 시간과 참여 현황 같은 주요 정보를 확인해요. 이 데이터를 메모, CRM 상호작용, 청구 기록과 맞춰 볼 수 있어요.
- 분석과 컴플라이언스 지원: 하이퍼클래스의 라이브 화상 인프라는 참가자 수, 입장·퇴장 시각 같은 지표를 기록해요. 이 지표는 라이브 화상 기능 전반의 리포팅과 리소스 보호에 쓰여요. 미팅도 이 기능을 활용해 시간이 지날수록 더 정확한 사용량과 참여 정보를 제공할 수 있어요.

이런 가시성은 진행 증빙이 필요한 반복 프로그램에서 특히 중요해요. 정해진 횟수의 세션을 약속하는 코칭 패키지나 참석 기록이 필요한 사내 교육 미팅이 그 예예요.

## 별다른 관리 없이 잘 작동해요

미팅의 목표는 매끄러운 통화를 방해하는 보이지 않는 "링크 관리" 작업을 없애는 거예요.

### 링크가 자동으로 만료되지 않아요

한 번만 쓰고 비활성화되도록 만든 일회용 링크와 달리, 미팅 링크는 그 미팅을 계속 쓰는 한 이후 세션에도 사용할 수 있어요.

### 반복 미팅을 오래 유지할 수 있어요

같은 URL을 여러 세션에 쓰기 때문에 매주나 매달 미팅 링크를 새로 만들거나 바꿀 필요가 없어요.

### 깨지거나 오래된 URL이 줄어요

링크가 고정되어 있어서, 이미 유효하지 않은 예전 캘린더 초대의 URL을 누르거나 지난 회차 때문에 오류 페이지로 가는 일이 훨씬 적어요.

### 캘린더, 정책과 잘 어울려요

하이퍼클래스 캘린더, 취소·일정 변경 규칙, 알림을 그대로 써서 만나는 시점을 관리하면서, 모든 리마인더가 하나의 미팅 링크를 가리키게 할 수 있어요. 고정 링크와 하이퍼클래스의 일정 도구를 함께 쓰면 룸이 늘 작동한다는 안정성과, 누가 언제 예약할 수 있는지 직접 정하는 통제력을 모두 얻어요.

## 내 개인 미팅 URL 확인하기

하이퍼클래스의 모든 사용자는 고객이나 팀원에게 공유할 수 있는 개인 미팅 URL을 자동으로 받아요. 이 재사용 링크로 다른 사람들이 세션마다 새 URL을 만들지 않고도 내 미팅에 참여할 수 있어요.

### 1단계. 계정 설정으로 이동하기

<!-- 검토 필요: 원문 내용이 서로 다름 -->

1. 왼쪽 메뉴에서 **멤버십**을 클릭하세요.
2. 페이지 위쪽의 **커뮤니티** 탭을 클릭하세요.
3. 미팅 설정에 들어가려는 커뮤니티를 선택하세요.

![커뮤니티 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077811158/original/9xH0ead1vvTwZw_lJxgrXRdTKjSiPRtQsg.png?1786026294)

4. 프로필 아이콘(보통 왼쪽 아래)을 클릭한 뒤 **프로필 설정**을 선택하세요.

![프로필 설정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077811505/original/fKyIn56UoIoHbwpSZTR2-MOSWpvTI6bf9w.png?1786026399)

### 2단계. 미팅 섹션으로 이동하기

1. **계정 설정** 사이드바에서 **미팅**을 클릭하세요.
2. **Your Meeting URL**(내 미팅 URL)이라는 섹션에 개인 재사용 미팅 링크가 보여요.

![내 미팅 URL 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077811620/original/aPMdq8fGuDSGUMLaPytyzeiXEl6atdIdag.png?1786026453)

### 3단계. 미팅 링크 복사하고 공유하기

1. 미팅 URL 옆의 **복사** 아이콘을 클릭해 클립보드에 복사하세요.
2. 이 링크를 고객, 팀원 등 만나려는 사람에게 공유하세요.
3. 앞으로의 모든 미팅에 같은 링크를 쓸 수 있어요. 세션마다 새 URL을 만들 필요가 없어요.

{% hint style="info" %}
개인 미팅 URL을 이메일 서명, 캘린더 초대, 자동화된 워크플로우에 넣어 두세요. 고객이 늘 쉽게 미팅에 참여할 수 있어요.
{% endhint %}

### 4단계. 미팅 녹화본 확인하고 관리하기

1. 같은 **미팅** 섹션에서 **녹화본** 카드를 찾으세요.
2. **View recordings**(녹화본 보기)를 클릭해 내 개인 미팅의 녹화본을 확인하고 관리하세요.
3. 지난 세션을 다시 보거나, 참석자에게 다시보기를 공유하거나, 컴플라이언스·교육 목적으로 기록을 보관할 때 유용해요.
