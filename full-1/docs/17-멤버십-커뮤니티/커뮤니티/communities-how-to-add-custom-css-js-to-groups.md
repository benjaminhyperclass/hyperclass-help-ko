# 커뮤니티 그룹에 사용자 지정 CSS/JS 추가하기

커뮤니티 **그룹**에 직접 만든 CSS와 JavaScript를 추가하면 브랜딩, 레이아웃, 동작 방식을 세밀하게 조정할 수 있어요. 이 문서에서는 코드를 어디에 붙여 넣는지 알려 드려요.

{% hint style="info" %}
하이퍼클래스는 사용자 지정 코드(작성, 디버깅, 유지 관리 포함)에 대한 안내, 권장, 지원을 제공하지 않아요.
{% endhint %}

---

## 그룹에 사용자 지정 CSS/JS를 추가한다는 것은?

그룹 단위로 CSS와 JavaScript를 추가하면 커뮤니티의 다른 부분은 그대로 두고 해당 그룹의 모양과 동작만 바꿀 수 있어요. 코드를 바로 붙여 넣고, 안전하게 테스트한 다음 안심하고 멤버에게 공개할 수 있어요.

---

## 사용자 지정 CSS/JS를 추가하면 좋은 점

- 정밀한 브랜딩: 글꼴, 간격, 구성 요소를 브랜드 가이드라인에 맞출 수 있어요.
- 필요한 곳만 변경: CSS/JS를 한 그룹에만 적용하므로 다른 그룹에는 영향이 없어요.
- 단계적 공개: **라이브 모드**를 켜기 전에 **Test Preview**(테스트 미리보기)로 먼저 확인할 수 있어요.
- 더 나은 사용 경험: 짧은 JS 코드로 탐색이나 작은 인터랙션을 개선할 수 있어요.
- 모바일 대응: 휴대폰과 태블릿에 맞는 반응형 규칙을 따로 만들 수 있어요.

## 그룹에 사용자 지정 CSS/JS 추가하기

다음 단계를 따라 그룹에 코드를 추가하세요.

1. 서브 계정에 로그인하세요.
2. **멤버십 > 커뮤니티 > 그룹**으로 이동하세요.

   ![멤버십, 커뮤니티, 그룹 메뉴로 이동한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061246022/original/zfEW7dJceNSM4tNRzkZM1Bbv6otwOID3JA.png?1766501351)
3. 사용자 지정할 **그룹**에 로그인하세요.

   ![사용자 지정할 그룹에 로그인하는 화면](https://jumpshare.com/share/WEmixhUQ0ro5XQi8XOS0+/Screen+Shot+2025-12-23+at+8.21.16+PM.png)
4. 그룹 안에서 **설정**을 클릭하세요.

   ![그룹 안의 설정 메뉴](https://jumpshare.com/share/5G9662alBgx3HMphI0Ar+/Screen+Shot+2025-12-23+at+8.24.17+PM.png)
5. **브랜딩** 탭을 클릭하고 아래로 스크롤해 **고급 옵션**을 클릭해 펼치세요.

   ![브랜딩 탭의 고급 옵션 영역](https://jumpshare.com/share/z9vpc1V1LeAWqJ35ZTqu+/Screen+Shot+2025-12-23+at+8.33.17+PM.png)
6. **사용자 지정 CSS**와 **Custom JavaScript**(사용자 지정 JavaScript) 필드까지 스크롤해서 코드를 붙여 넣으세요.

   ![사용자 지정 CSS와 JavaScript 입력 필드](https://jumpshare.com/share/KW2JPZ0zRZQ1YYu7HWyA+/Screen+Shot+2025-12-23+at+8.34.57+PM.png)
7. **Test Preview**를 클릭해 변경 내용을 확인하세요.
8. 결과가 마음에 들면 **라이브 모드**를 켜세요. 마음에 들지 않으면 코드를 수정한 뒤 다시 테스트하세요.
9. **저장**을 클릭해 마무리하세요.

   ![저장 버튼을 클릭하는 화면](https://jumpshare.com/share/YhxRqrwpECkyaPRqyIzG+/Screen+Shot+2025-12-23+at+8.36.24+PM.png)

## 자주 묻는 질문

### 문제를 확인하려고 사용자 지정 코드를 빠르게 끄려면 어떻게 하나요?

**라이브 모드**를 끄세요.

### 사용자 지정 코드를 적용한 뒤 커뮤니티에 문제가 생겼어요. 어떻게 하나요?

사용자 지정 HTML, CSS, JavaScript를 적용한 커뮤니티에서 문제가 생기면, 먼저 그 코드가 원인인지 확인해야 해요. 사용자 지정 코드를 잠시 꺼 두고 같은 문제가 생기는지 보면 돼요.

브라우저 주소창에서 커뮤니티 URL 맨 끝에 `customCode=false`를 붙이고 Enter를 누르세요. 현재 세션에서만 사용자 지정 코드가 꺼지므로, 코드 없이도 문제가 계속되는지 확인할 수 있어요. 사용자 지정 코드를 끄고 문제가 사라진다면 코드를 수정해야 한다는 뜻이에요.

### 커뮤니티 포털에서 다크 모드와 라이트 모드의 스타일을 다르게 적용하려면 어떻게 하나요?

야간 모드(다크 테마) 스타일만 따로 지정하려면 CSS에서 `.dark` 클래스를 사용하세요. 야간 모드가 켜져 있으면 이 클래스가 루트 요소에 자동으로 적용돼요.

`div:nth-of-type(2)`처럼 범위가 너무 넓은 선택자는 페이지의 다른 부분에 영향을 주지 않는다고 확실할 때만 쓰세요. 두 모드를 모두 미리 보고 테스트해서 화면이 일관되게 보이는지 꼭 확인하세요.
