# 커뮤니티 그룹 테마 바꾸기

커뮤니티 그룹 화면의 모양을 취향에 맞게 바꾸는 방법을 안내해요. 라이트 모드와 다크 모드 각각에 기본 제공 테마를 고르거나, 직접 색을 정해 나만의 테마를 만들 수 있어요.

[동영상](https://www.youtube.com/embed/lXz5MC1kdtI?&wmode=opaque)

---

## 관리자/소유자 화면: 테마 설정 열기

이 기능은 **실험실**에서 켜 두어야 해요.

1. 커뮤니티 그룹 안에서 오른쪽 사이드바를 열고, 맨 아래의 **설정**을 클릭하세요.
2. 사이드바에서 **테마**를 선택하세요.

## 새 테마 고르기

여러 그룹을 운영한다면 그룹마다 다른 테마를 골라 보세요. 그룹을 구분하기 쉬워져요. 새 테마는 브라우저에 표시돼요.

- 라이트 모드 또는 다크 모드 선택

  **테마** 화면 위쪽의 버튼으로 **Light Mode**(라이트 모드)와 **Dark Mode**(다크 모드)를 바꿀 수 있어요.

- 기본 제공 테마 선택

  **Communities theme**(커뮤니티 테마) 탭을 선택한 뒤 목록을 스크롤하며 테마를 둘러보세요. 테마를 클릭하면 미리 볼 수 있어요. 마음에 드는 테마를 고르면 커뮤니티 화면에 자동으로 적용돼요.

{% hint style="info" %}
테마는 웹에서만 적용되고, 모바일에서는 적용되지 않아요.
{% endhint %}

## 사용자 지정 테마 만들기

그룹 소유자나 **관리자**는 **Custom Themes**(사용자 지정 테마) 탭에서 그룹 화면의 여러 요소를 직접 바꿀 수 있어요. 라이트 모드와 다크 모드는 각각 따로 설정하고 저장해야 해요.

항목 목록을 스크롤하며 바꿀 요소를 찾아보세요.

| 항목 | 그룹 화면에서 바뀌는 부분 |
| --- | --- |
| **Sidebar Background**(사이드바 배경) | 상단 바를 포함한 사이드바의 배경색 |
| **Primary**(주 색상) | 버튼 색상 |
| **배경** | 화면 요소의 표면과 모달 |
| **Tertiary**(보조 강조 색상) | 링크, 선택 요소(라디오 버튼·체크박스) |
| **Surface**(표면) | 화면의 바탕 |
| **기본 글꼴** | 주요 콘텐츠 |
| **보조 글꼴** | 선택된 콘텐츠 |
| **Fill colour**(채움 색상) | 마우스를 올렸을 때의 색상 |
| **Borders**(테두리) | 모든 테두리 |
| **Error**(오류) | 상호작용 중 오류가 났을 때의 색상 |

색상 견본을 클릭하면 색상 선택기가 열려요. 색상 코드(hex 코드)를 직접 입력해도 돼요.

## 멤버 화면

그룹 멤버에게는 **관리자**가 사용자 지정했거나 선택한 테마가 보여요. 멤버는 **설정**에서 **Light Mode**(라이트 모드)와 **Dark Mode**(다크 모드)를 바꿀 수도 있어요.

![멤버 화면에서 라이트·다크 모드를 바꾸는 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155026481389/original/vl4U1OUENVXb26Y-E2oq7LpbdU789Wd6Lw.png?1716460941)
