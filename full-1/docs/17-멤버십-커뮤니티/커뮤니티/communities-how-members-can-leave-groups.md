# 커뮤니티 그룹에서 멤버가 직접 나가기

멤버는 관리자의 도움 없이 스스로 커뮤니티를 나갈 수 있어요. 이 문서에서는 커뮤니티를 나가는 방법, 나간 뒤에 일어나는 일, 멤버가 나갈 때 관리자에게 어떻게 알림이 가는지 안내해요.

[동영상](https://www.youtube.com/embed/RJks3otuHbU?&wmode=opaque)

## 멤버 셀프 나가기란?

하이퍼클래스의 커뮤니티 나가기는 멤버가 언제든 스스로 그룹에서 빠질 수 있는 셀프 서비스 기능이에요. 관리자가 대신 처리할 필요가 없고, 멤버가 참여 여부를 직접 정해요. 멤버가 나가면 코스, 이벤트, 유료 콘텐츠 같은 연결된 모든 자료에 대한 접근 권한이 바로 사라져요.

## 멤버 셀프 나가기의 장점

멤버가 자기 접근 권한을 직접 관리하면 관리자의 운영 부담이 줄고, 멤버도 커뮤니티 이용 상황을 더 명확하게 알 수 있어요.

- 셀프 서비스 방식: 멤버가 관리자의 처리를 기다리지 않고 언제든 커뮤니티를 나갈 수 있어요.
- 즉시 접근 해제: 코스, 이벤트, 유료 콘텐츠에 대한 접근 권한이 바로 사라져요.
- 깔끔한 계정 관리: 멤버가 나간 뒤에도 시스템 상태가 일관되게 유지돼요.
- 관리자 확인: 멤버가 나가면 관리자에게 실시간으로 알림이 가요.

## 그룹에서 나가는 방법

그룹에서 나가는 방법을 알아 두면 원치 않는 알림이나 콘텐츠를 받지 않도록 접근 권한을 빠르게 정리할 수 있어요. 아래 순서대로 진행하면 바로 처리돼요.

1. 멤버로 가입한 그룹에 로그인하세요.
2. 웹에서 **소개** 탭을 클릭하세요.
3. **점 세 개(⋮) 메뉴**를 클릭하세요.
4. **Leave Group**(그룹 나가기)을 선택하세요.

   ![그룹 메뉴에서 Leave Group 선택](https://jumpshare.com/share/oBuzToCe4Z9CQyUr419p+/Screen+Shot+2026-04-17+at+19.39.49.png)
5. 확인 창에서 **Leave Group** 버튼을 클릭해 나가기를 확정하세요.

   ![Leave Group 버튼으로 나가기 확인](https://jumpshare.com/share/TIe1NtrcGHGxK2gsnKEK+/Screen+Shot+2026-04-17+at+19.40.34.png)

## 자주 묻는 질문

### 멤버가 커뮤니티를 나가면 바로 어떻게 되나요?
커뮤니티에 대한 접근 권한이 바로 사라져요. 코스, 이벤트, 유료 콘텐츠도 모두 볼 수 없게 돼요.

### 멤버가 커뮤니티를 나가면 관리자도 알 수 있나요?
네. 멤버가 나가면 관리자에게 이메일, 앱 내 알림, 푸시 알림이 가요.

### 나간 뒤에 커뮤니티에 다시 들어올 수 있나요?
네, 다시 들어올 수 있어요. 다만 커뮤니티 설정에 따라 다시 초대를 받거나 접근 권한을 새로 얻어야 해요.

### 커뮤니티를 나가면 멤버의 구독도 취소되나요?
커뮤니티를 나가면 멤버의 접근 권한은 사라지지만, 구독이나 결제가 어떻게 처리되는지는 커뮤니티 설정에 따라 달라져요.
