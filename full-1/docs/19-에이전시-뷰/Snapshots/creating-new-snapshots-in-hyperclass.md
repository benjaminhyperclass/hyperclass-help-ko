# 새 스냅샷 만들기

서브 계정의 설정을 통째로 복제해 두었다가 다른 서브 계정에서 다시 쓰고 싶을 때 스냅샷을 만들어요. 이 문서에서는 하이퍼클래스에서 새 스냅샷을 만드는 순서를 설명해요.

## 스냅샷이란?

스냅샷은 서브 계정의 설정을 담아 두고 다시 쓸 수 있는 템플릿이에요. 워크플로우, 퍼널, 캘린더, 폼, 캠페인, 커스텀 필드 등 서브 계정의 설정이 모두 담겨요. 잘 만든 설정을 다른 고객사 계정에 그대로 복제할 수 있어요.

{% hint style="info" %}
스냅샷을 직접 "만드는" 것은 아니에요. 먼저 서브 계정을 만든 다음, 그 계정으로 스냅샷을 만들어요.
{% endhint %}

## 스냅샷의 장점

- 시간 절약: 반복해서 쓰는 설정을 빠르게 적용할 수 있어요.
- 일관성 유지: 여러 고객사나 업종에 같은 설정을 똑같이 적용할 수 있어요.
- SaaS 상품 구성: SaaS 요금제에 쓸 미리 만들어 둔 계정 템플릿으로 활용할 수 있어요.
- 자산 선택: 모든 자산을 포함하거나 필요한 것만 골라서 담을 수 있어요.

## 스냅샷 만드는 순서

에이전시 관리자가 쓰는 기능이에요.

#### 1단계: 계정 스냅샷 열기

1. 에이전시 뷰에서 **계정 스냅샷**을 클릭하세요.
2. 오른쪽 위의 파란색 **새 스냅샷 생성** 버튼을 클릭하세요.

![계정 스냅샷 화면에서 새 스냅샷 생성 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047025974/original/DW1Rr3rRfBF2NrEltZ0SI9Ns4hW_ARDqlg.png?1747854752)

#### 2단계: 스냅샷 이름 입력하고 서브 계정 선택하기

사용 목적이 드러나는 이름을 입력하세요(예: "스파 퍼널 설정"). 그런 다음 **서브 계정 선택**에서 담고 싶은 자산이 들어 있는 서브 계정을 선택하세요.

![스냅샷 이름 입력과 서브 계정 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047025912/original/H_cf0KyL_NHYsA1wmfa4KC2LCTv2niPhog.png?1747854618)

#### 3단계: 포함할 자산 고르기

선택한 서브 계정에 있는 모든 자산이 목록으로 나타나요. 전부 담으려면 **전체 선택**을 클릭하세요. 일부만 담으려면 카테고리를 펼쳐서 자산을 하나씩 고르세요.

이제 원본 서브 계정의 **회사 커스텀 필드**도 스냅샷에 담을 수 있어요. 대상 서브 계정에서 다시 쓰고 싶은 회사 커스텀 필드를 다른 필요한 자산과 함께 선택하세요. 선택을 마쳤으면 **만들기**를 클릭하세요.

지원하는 커스텀 필드도 스냅샷에 담을 수 있어요. **URL**, **날짜 및 시간**, **리치 텍스트**, **사용자**, 이미지가 있는 체크박스 필드, 이미지가 있는 라디오 버튼 필드가 해당돼요. URL 도메인 제한, 날짜 제한처럼 지원하는 필드 설정도 스냅샷과 함께 넘어가요.

![포함할 자산을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083470703/original/8MGdGAbKO1X0FJYWkG2M7Kdu7Kwunz-m4Q.png?1792133334)

{% hint style="info" %}
이 단계에서 일부 자산을 불러오지 못하면 **재시도** 옵션이 나타나요. **재시도**를 클릭하면 스냅샷 만들기를 처음부터 다시 시작하지 않고도 불러오지 못한 카테고리만 다시 가져와요. 자산이 아주 많거나 불러오기가 간헐적으로 느려질 때 특히 유용해요.
{% endhint %}

![자산 불러오기 실패 시 재시도하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067734786/original/hXnUfhnxf05CUg6KwF6M6YZGwth81gWuVg.gif?1774455890)

#### 광고 캠페인 – LinkedIn (마케팅 자산)

LinkedIn 캠페인 구조도 스냅샷에 담을 수 있어요.

1. **마케팅 자산 > 광고 캠페인 – LinkedIn**으로 이동하세요.
2. 담을 캠페인을 하나씩 선택하거나 **전체 선택**을 클릭하세요. 선택한 수와 전체 수가 함께 표시돼요.

하이퍼클래스는 캠페인 그룹 → 캠페인 → 광고의 계층 구조를 그대로 유지해요.

{% hint style="info" %}
리드 생성 폼은 스냅샷에 포함되지 않아요.
{% endhint %}

{% hint style="info" %}
CRM 오브젝트 간 연관 관계는 관계에 속한 두 오브젝트를 모두 선택하면 스냅샷에 자동으로 포함돼요. 연락처 간 연관 관계는 현재 지원하지 않아요.
{% endhint %}

![LinkedIn 광고 캠페인 자산 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067811354/original/-k1WfJbzO3PpR3Uc5tDMNX9FxCiQSOi9bA.png?1774530177)

## 자주 묻는 질문

### 스냅샷은 어디서 만드나요?
스냅샷 자체를 만드는 것이 아니라 서브 계정을 만들어요. 그런 다음 스냅샷 기능으로 그 서브 계정을 담아요.

### 스냅샷에는 무엇이 포함되나요?
**포함됨:** 워크플로우, 퍼널, 캘린더, 폼, 이메일, 트리거, 커스텀 필드, 커스텀 값, 멤버십 콘텐츠, 서비스, 웨비나, AI 스튜디오 프로젝트 등이에요. 커스텀 필드에는 회사 커스텀 필드, URL, 날짜 및 시간, 리치 텍스트, 사용자, 이미지가 있는 체크박스 필드, 이미지가 있는 라디오 버튼 필드가 포함돼요.

**포함되지 않음:** 연락처, 예약, 대화, 평판 데이터, Stripe 연결, 연동이에요.

### 스냅샷을 여러 번 쓸 수 있나요?
네. 필요한 만큼 많은 서브 계정에 스냅샷을 적용할 수 있어요.

### 나중에 스냅샷을 업데이트할 수 있나요?
네. **Refresh**(새로고침) 옵션을 쓰면 기존 스냅샷에 새 자산을 추가하거나 자산을 뺄 수 있어요.
