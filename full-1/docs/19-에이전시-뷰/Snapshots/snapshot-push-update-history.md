# 스냅샷 푸시 업데이트 히스토리 확인하기

스냅샷 업데이트를 서브 계정에 푸시한 기록을 한곳에서 볼 수 있어요. 에이전시 관리자만 쓸 수 있어요. 처리된 서브 계정, 대기 중인 서브 계정, 실패한 서브 계정을 확인할 수 있고, 서브 계정마다 불러온 자산의 상세 내역도 볼 수 있어요.

[동영상](https://www.youtube.com/embed/lQcijPbuqGc?&wmode=opaque)

```
2024년 11월 12일 기준으로, 자산 단위 상세 내역에는 불러온 자산이 100%가 아니어도 Completed(완료)로 표시될 수 있습니다(예: 퍼널 10개 중 5개만 불러온 경우). 이 부분은 개선 중입니다.
```

## 스냅샷 푸시 히스토리 보기

1. **계정 스냅샷 > 내 스냅샷**으로 이동하세요.
2. 히스토리를 확인할 스냅샷에서 점 세 개 메뉴를 클릭한 다음 **히스토리 보기**를 클릭하세요.
3. 히스토리 표에서 성공, 실패, 대기 중인 서브 계정을 확인하세요.
4. 푸시 내역을 자세히 보려면 해당 행 오른쪽 끝의 세부 정보 아이콘을 클릭하세요.
5. 서브 계정을 클릭하면 자산별 상세 목록을 볼 수 있어요.
6. 행을 클릭해 펼치면 푸시된 자산을 하나씩 확인할 수 있어요.
