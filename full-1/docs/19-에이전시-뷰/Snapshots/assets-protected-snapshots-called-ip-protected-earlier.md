# 자산 보호 스냅샷 (예전 이름: IP Protected)

자산 보호 스냅샷은 스냅샷에 담긴 자산이 외부로 재배포되는 것을 막으면서, 같은 에이전시 안에서는 서브 계정과 스냅샷 사이에서 자산을 다시 쓸 수 있게 해 주는 기능이에요. 이 문서에서는 보호된 자산이 어떻게 동작하는지 설명해요.

이 문서에서 다루는 내용은 다음과 같아요.

- 보호된 자산을 서브 계정에 불러올 때
- 스냅샷을 만들거나 새로고침할 때
- 혼합 스냅샷에 포함될 때
- 외부로 공유하기 전에 확인할 때

{% hint style="warning" %}
보호의 기준선은 에이전시예요. 에이전시 안에서는 보호된 자산을 다시 쓸 수 있어요. 외부 공유나 재판매로 보호된 자산이 에이전시 밖으로 나가는 경우에는 계속 제한돼요.
{% endhint %}

## 자산 보호 스냅샷이란?

자산 보호 스냅샷은 스냅샷 제작자가 자산을 무단 외부 재배포로부터 지킬 수 있게 해 줘요. 자산을 받은 에이전시는 평소처럼 내부 스냅샷 작업에서 그 자산을 쓸 수 있어요. 보호된 자산이라고 해서 다른 보호 스냅샷에서 왔다는 이유만으로 재사용이 막히지는 않아요. 그래서 보호가 어디에 적용되는지 알아 두는 게 중요해요.

스냅샷에 자산 보호를 적용하면 보호 상태는 해당 자산에 계속 따라다녀요. 자산을 받은 에이전시는 그 자산을 자기 서브 계정에서 불러와 다시 쓸 수 있어요. 내부용 스냅샷을 만들거나 새로고침할 때도 포함할 수 있어요.

제한은 보호된 자산이 그 에이전시 밖으로 나갈 때 적용돼요. 보호된 자산은 다른 에이전시에 재배포하거나 재판매할 수 없어요. 보호되지 않은 자산 중 공유할 수 있는 것은 그대로 공유할 수 있어요.

자산 보호 스냅샷을 가져오려면 [스냅샷 가져오기](how-to-import-snapshots.md)에서 전체 과정을 확인하세요.

### 자산 보호의 장점

자산 보호를 쓰면 에이전시가 정당하게 받은 자산으로 자유롭게 작업할 수 있어요. 원래 제작자가 걸어 둔 보호 장치도 그대로 유지돼요. 내부 스냅샷 작업은 평소처럼 하고, 외부 재배포는 계속 막을 수 있어요.

- 내부 재사용: 같은 에이전시 안의 서브 계정과 스냅샷에서 보호된 자산을 다시 쓸 수 있어요.
- 유연한 스냅샷 구성: 내부용 스냅샷을 만들거나 새로고침할 때 보호된 자산을 포함할 수 있어요.
- 제작자 보호: 보호된 자산이 다른 에이전시로 공유되거나 재판매되지 않게 막아요.
- 혼합 스냅샷 공유: 같은 스냅샷에 보호된 자산이 있어도, 공유할 수 있는 보호되지 않은 자산은 공유할 수 있어요.
- 공유 전 확인: 외부 공유를 끝내기 전에 공유할 수 있는 자산과 제외될 자산을 확인할 수 있어요.
- 지속되는 보호: 자산이 내부 스냅샷 작업을 거쳐도 보호 상태가 그대로 유지돼요.

### 자산 보호가 동작하는 방식

자산 보호는 내부 재사용과 외부 재배포를 구분해요. 기준은 에이전시예요. 보호된 자산은 에이전시 안의 스냅샷 작업에서는 자유롭게 오갈 수 있어요. 하지만 보호 상태 때문에 에이전시 밖으로는 재배포할 수 없어요.

| 상황 | 보호된 자산의 동작 |
| --- | --- |
| 같은 에이전시의 다른 서브 계정에 불러오기 | 허용 |
| 다른 내부 스냅샷에서 다시 사용하기 | 허용 |
| 보호된 자산으로 스냅샷 만들기 또는 새로고침 | 에이전시 안에서 허용 |
| 다른 에이전시에 스냅샷 공유 | 보호된 자산은 제외 |
| 에이전시 밖으로 스냅샷 재판매 | 보호된 자산은 계속 제한 |
| 혼합 스냅샷 공유 | 보호되지 않은 자산은 공유 가능, 보호된 자산은 제외 |

{% hint style="warning" %}
에이전시 안에서 보호된 자산을 다시 써도 보호 상태가 없어지거나 바뀌지 않아요. 보호는 자산을 계속 따라다녀요.
{% endhint %}

## 에이전시 안에서 보호된 자산 재사용하기

보호된 자산은 같은 에이전시 안의 일반 스냅샷 작업에 쓸 수 있어요. 예전에 있던 내부 사용 제한은 없어졌어요. 자산이 외부로 재배포될 때 적용되는 보호는 그대로예요.

보호된 자산으로 할 수 있는 일은 다음과 같아요.

- 보호된 스냅샷을 에이전시의 서브 계정에 불러오기
- 같은 에이전시의 여러 서브 계정에서 보호된 자산 재사용하기
- 보호된 자산이 있는 서브 계정에서 다른 스냅샷 만들기
- 기존 스냅샷을 새로고침할 때 보호된 자산 포함하기
- 보호된 자산과 보호되지 않은 자산이 함께 들어 있는 내부 스냅샷 만들기

이런 내부 작업을 거쳐도 보호 상태는 그대로 유지돼요. 서브 계정에서 다른 스냅샷을 만들었다고 해서 보호된 자산을 외부에 재배포할 수 있게 되지는 않아요.

![보호된 자산이 포함된 스냅샷에 표시가 붙은 스냅샷 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079639457/original/SayeIS7KD2v9iLiKcpL_pBNxONlmmWLmhA.png?1788099028=)

## 혼합 스냅샷의 보호된 자산

혼합 스냅샷은 보호된 자산과 보호되지 않은 자산이 함께 들어 있는 스냅샷이에요. 하이퍼클래스는 자산마다 보호 상태를 따로 확인해요. 그래서 보호된 콘텐츠가 있어도 공유할 수 있는 콘텐츠는 공유할 수 있어요.

- 에이전시 안: 보호된 자산과 보호되지 않은 자산 모두 내부 스냅샷 작업에 계속 쓸 수 있어요.
- 에이전시 밖: 외부 공유에서는 보호된 자산이 제외되고, 공유할 수 있는 보호되지 않은 자산은 그대로 공유돼요.

결과: 보호된 자산이 하나 이상 들어 있다는 이유만으로 스냅샷 전체를 공유할 수 없게 되지는 않아요.

## 공유 전에 보호된 자산 확인하기

스냅샷이 에이전시 밖으로 나가기 전에 확인하면 외부 공유에 어떤 자산이 포함될지 알 수 있어요. 하이퍼클래스는 공유를 계속 진행하기 전에 보호된 콘텐츠를 알려 줘서 무엇이 제외되는지 볼 수 있어요.

보호된 자산이 있으면 공유 화면에 공유할 수 없는 보호된 자산과 계속 진행할 수 있는 자산이 나뉘어 표시돼요. 자산 그룹을 펼쳐서 개별 항목을 확인한 뒤 진행할 수 있어요.

## 자산 보호 스냅샷 설정하기

자산 보호를 제대로 켜 두면 받는 쪽은 보호된 콘텐츠를 자기 에이전시 안에서 쓸 수 있어요. 대신 그 콘텐츠를 외부로 재배포할 수는 없어요. 나중에 내부에서 스냅샷을 만들거나 새로고침할 때도 같은 보호가 유지돼요.

### 스냅샷을 공유할 때 자산 보호 켜기

자산 보호는 스냅샷 공유 과정에서 보호된 공유 링크를 만들 때 적용돼요. 스냅샷을 배포하기 전에 켜 두면, 받는 에이전시가 가져온 뒤에도 자산에 보호가 따라가요. 에이전시 관리자만 쓸 수 있어요.

1. **에이전시 보기**에서 **계정 스냅샷 > 내 스냅샷**으로 이동하세요.
2. 공유할 스냅샷을 찾으세요.
3. 스냅샷의 작업 메뉴를 열고 **스냅샷 공유**를 선택하세요.
4. 받는 사람에게 맞는 공유 옵션을 선택하세요.
5. **Assets Protected**(자산 보호)를 켜세요.
6. 공유 링크를 만드세요.
7. 받을 사람에게 링크를 보내세요.

![스냅샷 공유 화면에서 자산 보호를 켜는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080790014/original/J98dDhBlRFMrf3IRwqjvrl0I4uXCbmdd9Q.png?1789242364)

스냅샷 공유 링크와 공유 옵션에 대한 자세한 내용은 [스냅샷 공유하기](how-to-share-snapshots.md)를 참고하세요.

### 보호된 자산으로 스냅샷 만들기 또는 새로고침

에이전시 안에서 쓸 스냅샷을 만들거나 새로고침할 때 이제 보호된 자산을 뺄 필요가 없어요. 자산 선택 화면에는 보호된 콘텐츠가 표시되지만, 내부용 스냅샷에 선택해서 넣을 수 있어요.

1. **에이전시 보기**에서 **계정 스냅샷**으로 이동하세요.
2. 새 스냅샷을 만들거나, 새로고침할 기존 스냅샷을 고르세요.
3. 원본 서브 계정을 선택하거나, 자산 선택 단계로 넘어가세요.
4. 선택할 수 있는 자산을 확인하세요. 보호된 자산에는 방패 표시가 붙어 있어요.
5. 내부용으로 포함할 보호된 자산과 보호되지 않은 자산을 선택하세요.
6. **만들기** 또는 **새로고침**을 완료하세요.

새로 만들었거나 새로고침한 스냅샷에 포함된 뒤에도 보호된 자산은 계속 보호돼요.

![내부 재사용이 가능한 보호된 자산이 보이는 스냅샷 만들기 자산 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079639340/original/jMp8PxMz9PzXRkG8mdI878WGVK59b5stOw.png?1788098876=)
![내부 재사용이 가능한 보호된 자산이 보이는 스냅샷 새로고침 자산 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079639377/original/Ya9bCehwbJKeozSoXune6xDecnPI_ZKwtw.png?1788098897=)

스냅샷을 만들고 새로고침하는 전체 방법은 [하이퍼클래스에서 새 스냅샷 만들기](creating-new-snapshots-in-hyperclass.md)와 [스냅샷 새로고침 및 업데이트](refresh-or-update-snapshots.md)를 참고하세요.

### 보호된 자산이 있는 스냅샷 공유하기

보호된 콘텐츠가 있다고 해서 스냅샷 전체를 공유할 수 없게 되지는 않아요. 혼합 스냅샷을 에이전시 밖으로 공유하면, 하이퍼클래스가 공유를 마치기 전에 보호된 자산과 공유할 수 있는 자산을 나눠 줘요.

1. 스냅샷 공유 화면을 여세요.
2. 사용할 외부 공유 옵션을 선택하세요.
3. 계속하기 전에 화면에 표시된 보호된 자산과 공유 가능한 자산을 확인하세요.
4. 외부 공유에서 제외될 자산을 확인하세요.
5. 공유를 계속 진행하세요.

보호된 자산은 남겨지고 다른 에이전시로 재배포되지 않아요. 공유할 수 있는 보호되지 않은 자산은 외부 공유에 포함돼요.

{% hint style="info" %}
직접 정리할 필요는 없어요. 혼합 스냅샷을 외부로 공유하기 전에 보호된 자산을 모두 직접 지우지 않아도 돼요.
{% endhint %}

## 자주 묻는 질문

### 보호된 자산을 다른 서브 계정으로 복사하면 보호가 풀리나요?
아니요. 에이전시 안에서 서브 계정과 스냅샷 사이를 오가도 보호는 자산을 계속 따라가요.

### 가져온 보호 스냅샷의 자산이 들어 있는 서브 계정에서 새 스냅샷을 만들 수 있나요?
네. 에이전시 안에서 쓸 새 스냅샷을 만들 때 보호된 자산을 포함할 수 있어요. 보호 상태는 그대로 유지돼요.

### 보호된 자산이 들어 있는 기존 스냅샷을 새로고침할 수 있나요?
네. 내부용으로 스냅샷을 새로고침할 때 보호된 자산을 선택할 수 있어요. 새로고침해도 보호는 없어지지 않아요.

### 보호된 자산과 보호되지 않은 자산이 함께 들어 있는 스냅샷을 공유하면 어떻게 되나요?
스냅샷은 외부로 공유할 수 있어요. 보호된 자산은 제외되고, 공유할 수 있는 보호되지 않은 자산은 공유에 포함돼요.

### 혼합 스냅샷을 외부로 공유하기 전에 보호된 자산을 직접 지워야 하나요?
아니요. 하이퍼클래스가 공유 과정에서 보호된 자산을 찾아 외부 공유에서 제외해요.

### 보호된 자산을 받은 에이전시가 자기 서브 계정 여러 곳에서 쓸 수 있나요?
네. 보호 스냅샷을 정당하게 가져온 뒤에는, 받은 에이전시 안의 서브 계정과 스냅샷에서 보호된 자산을 다시 쓸 수 있어요.

### 받은 에이전시가 보호된 자산을 재판매하거나 다른 에이전시에 공유할 수 있나요?
아니요. 보호된 자산이 받은 에이전시 밖으로 나갈 때 제한이 적용돼요. 보호된 자산은 다른 에이전시에 재배포하거나 재판매할 수 없어요.

### 스냅샷을 공유하기 전에 어떤 자산이 제외되는지 어떻게 알 수 있나요?
외부 공유 중에 보호된 자산이 감지되면, 검토 화면에 제한된 자산과 포함할 수 있는 자산이 구분되어 표시돼요. 공유를 계속하기 전에 이 목록을 확인하세요.
