# 기존 서브 계정에 스냅샷 불러오기

이미 사용 중인 서브 계정에 스냅샷을 불러오는 방법을 안내해요. 불러올 자산을 직접 고르고, 기존 자산과 겹치는 항목을 확인한 뒤 최종 확인까지 하는 과정을 다뤄요. 에이전시 관리자만 쓸 수 있어요.

스냅샷을 기존 서브 계정에 불러오면 미리 만들어 둔 자산을 일일이 다시 만들지 않아도 돼요. 가져올 스냅샷 자산을 직접 고를 수 있고, 기존 항목을 교체하기 전에 겹치는 항목을 확인할 수 있어요. 변경 사항은 최종 확인 후에 적용돼요. 대시보드를 포함했다면, 선택한 대시보드 중 어느 것을 대상 서브 계정의 기본 대시보드로 쓸지도 정할 수 있어요.

이 문서에서는 활성 상태인 서브 계정에 스냅샷을 불러오는 방법, 특정 자산만 선택하는 방법, 대시보드를 포함했을 때 기본 대시보드를 지정하는 방법, 자산 충돌을 해결하는 방법, 마지막 가져오기를 확인하는 방법을 알려 드려요.

## 기존 서브 계정에 스냅샷을 불러온다는 건 무슨 뜻인가요?

스냅샷을 기존 서브 계정에 불러오면 워크플로우, 퍼널, 이메일 등 지원되는 자산이 이미 사용 중인 계정으로 들어가요. 표준화된 시스템을 다시 만들지 않고 바로 적용할 수 있어요. 불러오는 도중 겹치는 자산을 일부러 덮어쓰지 않는 한, 기존 고객 데이터는 그대로 유지돼요.

### 기존 서브 계정에 스냅샷을 불러올 때의 장점

검증된 자산을 재사용하면서, 무엇을 가져올지와 대상 서브 계정에 비슷한 콘텐츠가 있을 때 어떻게 처리할지를 직접 정할 수 있어요.

- 효율성: 워크플로우, 폼, 퍼널 같은 자산을 새로 만들지 않고 재사용해요.
- 일관성: 여러 고객 서브 계정에 같은 구조와 프로세스를 적용해요.
- 유연성: 가져올 자산과 덮어쓸 기존 자산을 직접 선택해요.
- 충돌 경고: 기존 콘텐츠를 교체할지 정하기 전에 겹치는 항목을 확인해요.

### 스냅샷 불러오기와 스냅샷 업데이트 푸시의 차이

불러오기와 푸시는 쓰임새가 달라요. 처음 자산을 가져올 때와, 이미 스냅샷을 받은 계정을 업데이트할 때를 구분해서 알맞은 방법을 고르세요.

| 구분 | 사용 시점 |
| --- | --- |
| **Load Snapshot**(스냅샷 불러오기) | 스냅샷에서 선택한 자산을 기존 서브 계정에 추가해요. 템플릿을 처음 배포하거나 계정에 스냅샷 콘텐츠를 추가할 때 주로 써요. |
| **Push Update**(업데이트 푸시) | 새로 고친 스냅샷에서 선택한 변경 사항을, 이전에 그 스냅샷을 받은 서브 계정에 보내요. |

이미 스냅샷을 쓰고 있는 계정을 업데이트해야 한다면 Refresh or Update Snapshots 문서를 참고하세요.

## 기존 서브 계정에 스냅샷 불러오는 순서

아래 순서대로 진행하면 대상 계정을 정확히 고르고, 필요한 자산만 선택하고, 충돌을 꼼꼼히 확인한 뒤 가져오기를 확정할 수 있어요.

### 1단계. 고객 관리로 이동하기

스냅샷을 불러올 서브 계정에서 시작해야 의도한 고객 계정에 스냅샷이 들어가요.

1. **에이전시 대시보드**의 왼쪽 메뉴에서 **서브 계정**을 선택하세요.
2. 목록이나 검색창에서 서브 계정을 찾으세요.
3. 서브 계정 옆의 **점 세 개 메뉴**를 클릭하고 **고객 관리**를 선택하세요.

![서브 계정 목록에서 점 세 개 메뉴와 고객 관리 옵션이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047309772/original/yA2ym7DzLDFboqlwe9N7FLe4fsS03Yi0-A.png?1748362317)

### 2단계. 스냅샷 불러오기 선택하기

**작업** 메뉴에서 선택한 서브 계정의 스냅샷 불러오기 과정을 시작할 수 있어요.

1. 오른쪽 위의 **작업**을 클릭하세요.
2. **Load Snapshot**을 선택하세요.

{% hint style="info" %}
**Load Snapshot**이 보이지 않으면 에이전시 대시보드의 **사용자 > Roles and Permissions**(역할 및 권한)에서 스냅샷 접근 권한이 켜져 있는지 확인하세요.
{% endhint %}

![고객 관리 화면의 작업 메뉴에 Load Snapshot 옵션이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047310271/original/dEt-CxBAyDMY49OqA-VBjOTsSFahomz7Ig.png?1748362867)

### 3단계. 스냅샷 고르기

어떤 스냅샷을 고르느냐에 따라 대상 서브 계정에 쓸 수 있는 자산이 달라져요.

1. **Load Snapshot** 팝업에서 **스냅샷 선택**을 여세요.
2. 불러올 스냅샷을 선택하세요.
3. **계속하기**를 클릭하세요.

![스냅샷 선택 드롭다운과 계속하기 버튼이 보이는 Load Snapshot 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047310396/original/_QPoTUXoOthgaiTP_RQYOdMZC1636crwAA.png?1748363022)

### 4단계. 자산 선택하기

스냅샷에서 가져올 부분을 정확히 고를 수 있어요. 대시보드를 포함하면 대시보드 전용 기본값 설정도 쓸 수 있어요.

- 체크박스로 가져올 자산을 선택하세요.
- 사용할 수 있는 자산을 모두 가져오려면 **전체 선택**을 클릭하세요.
- 카테고리별로 가져오려면 필요한 카테고리만 선택하세요.
- **+ 아이콘**을 클릭하면 카테고리가 펼쳐지고, 개별 자산을 선택할 수 있어요.
- 자산 선택을 마쳤으면 **계속하기**를 클릭하세요.

**대시보드**: 대시보드를 선택했다면, 대상 서브 계정의 기본 대시보드로 쓸 대시보드에서 **기본값으로 설정**을 클릭하세요. 한 번에 하나만 지정할 수 있어요. 기본 대시보드를 바꾸려면 선택한 다른 대시보드에서 **기본값으로 설정**을 클릭하세요. 지정을 해제하려면 현재 지정된 대시보드를 다시 클릭하세요. 지정한 대시보드가 없으면 하이퍼클래스는 스냅샷에 원래 설정된 기본 대시보드를 사용해요.

대시보드 관련 요구 사항과 제한 사항은 [대시보드가 포함된 스냅샷 불러오기](../../12-대시보드/시작하기/how-to-load-snapshots-with-dashboards.md) 문서를 참고하세요.

**웨비나**: 스냅샷에 웨비나가 포함되어 있으면, 가져올 때 웨비나 페이지가 복제되고 해당하는 웨비나 세션이 자동으로 만들어져요. 웨비나와 관련된 데이터도 가져오는 과정에서 복원돼요.

![가져오기 전에 개별 자산을 고르는 스냅샷 자산 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047310630/original/oNBseK_rnYitl1-Cs9Z2M2UdKGWyBesoHA.png?1748363231)

#### LinkedIn 광고 캠페인(마케팅 자산)

스냅샷을 불러올 때 LinkedIn 캠페인 자산도 선택할 수 있어요. 다만 대상 서브 계정에서는 다음과 같이 따로 처리돼요.

- 자산 목록에서 **Ad Campaigns – LinkedIn**(광고 캠페인 – LinkedIn)을 선택하세요.
- 충돌 확인 단계로 넘어가 일반적인 충돌을 확인한 뒤 가져오세요.

- 가져온 LinkedIn 캠페인은 항상 **임시 저장** 상태로 만들어져요.
- 대상 서브 계정에 LinkedIn이 연결되어 있지 않아도 가져오기는 완료되고, 캠페인은 **임시 저장** 상태로 만들어져요.
- 리드 생성 폼(Lead Gen Forms)은 가져오지 않아요.

![마케팅 자산으로 LinkedIn 광고 캠페인이 보이는 스냅샷 자산 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067812094/original/9XBFQOV39r2KLgmZan4wsUlkpBmV6py5RQ.png?1774530447)

### 5단계. 충돌 해결하기

스냅샷 불러오기를 이어 가기 전에, 서브 계정의 기존 자산을 교체할지 그대로 둘지 정할 수 있어요.

- **Override**(덮어쓰기): 서브 계정의 기존 항목을 스냅샷 버전으로 교체해요.
- **건너뛰기**: 현재 버전을 그대로 두고, 충돌하는 스냅샷 항목은 가져오지 않아요.
- 충돌 항목을 확인한 뒤 **계속하기**를 클릭하세요.

{% hint style="info" %}
웨비나도 다른 자산과 똑같이 충돌을 해결해요. 기존 웨비나 자산을 교체하려면 **Override**를, 현재 버전을 유지하려면 **건너뛰기**를 선택하세요.
{% endhint %}

![Override와 건너뛰기 옵션이 보이는 스냅샷 충돌 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047310944/original/tB_gDphi0N9_RBN0qHqvTOTvtbEKn36U9g.png?1748363508)

### 6단계. 가져오기 확인하기

선택한 변경 사항을 직접 승인해야만 스냅샷이 불러와져요.

1. 안내가 나오면 `confirm`을 입력하세요.
2. **계속하기**를 클릭하세요.
3. 스냅샷을 불러오는 중이라는 성공 알림이 표시돼요. 정보 전송이 끝나면 이메일로 알림이 와요.

![진행하기 전에 confirm을 입력해야 하는 스냅샷 가져오기 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047311036/original/pJu4UOgflq4e4RbBobEBNPFi7nn1St_fiQ.png?1748363608)

## 자주 묻는 질문

### 스냅샷을 불러오면 현재 데이터가 삭제되나요?
아니요. 충돌 확인 단계에서 기존 자산을 덮어쓰기로 선택한 경우에만 데이터가 교체돼요.

### 스냅샷에 무엇이 들어 있는지 미리 볼 수 있나요?
직접 미리 볼 수는 없어요. 대신 필요한 자산만 골라서 불러오거나, 진행 중에 일부 자산을 건너뛸 수 있어요.

### 실수로 자산을 덮어썼어요. 어떻게 하나요?
스냅샷 불러오기에서는 덮어쓰기를 되돌릴 수 없어요. 계속하기 전에 충돌 목록을 꼼꼼히 확인하세요.

### 같은 서브 계정에 스냅샷을 여러 개 불러올 수 있나요?
네, 가능해요. 스냅샷마다 같은 불러오기 과정을 거쳐요. 자산이 겹치면 의도하지 않게 덮어쓰는 일이 없도록 충돌 옵션을 꼼꼼히 확인하세요.
