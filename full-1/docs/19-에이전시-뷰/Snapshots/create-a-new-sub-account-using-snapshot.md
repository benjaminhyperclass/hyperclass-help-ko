# 스냅샷으로 새 서브 계정 만들기

스냅샷을 선택해 새 서브 계정을 바로 만드는 방법을 안내해요. 퍼널, 워크플로우, 설정 같은 자산이 새 계정에 자동으로 불러와지므로 설정 시간을 줄이고 서브 계정마다 같은 구성을 유지할 수 있어요.

## 개요

에이전시는 스냅샷을 골라 새 서브 계정을 만들 수 있어요. 스냅샷에 담긴 도구, 워크플로우, 설정, 자산이 모두 새 계정에 포함돼요. 서브 계정을 만들면 스냅샷이 자동으로 불러와져요. 계정을 만든 뒤에 스냅샷을 따로 불러올 필요가 없어요. 덕분에 온보딩이 간단해지고, 새 계정이 미리 준비된 일관된 구성으로 시작해요.

## 스냅샷으로 서브 계정을 만들면 좋은 점

스냅샷을 쓰면 표준화된 서브 계정을 더 빠르게 만들 수 있어요.

- 빠른 온보딩: 필요한 자산과 설정이 미리 불러와져서 직접 설정할 일이 줄어요.
- 계정 간 일관성: 원하는 계정에 같은 자산과 설정이 들어가요.
- 시간 절약: 서브 계정을 만들 때마다 같은 설정을 반복하지 않아도 돼요.
- 오류 감소: 설정을 잘못하거나 자산이 빠지는 실수가 줄어요.

## 사전 준비

아래 조건을 먼저 확인하면 처음부터 순조롭게 진행할 수 있어요.

- **에이전시 관리자** 권한이 있어야 해요.
- 사용할 스냅샷이 이미 내 계정에 있어야 해요.
- 복제하고 싶은 주요 자산(퍼널, 트리거, 캘린더 등)이 스냅샷에 들어 있어야 해요.
- 필요하면 스냅샷을 미리 가져오거나 만들어 두세요.

  - 스냅샷 가져오기
  - 스냅샷 만들기

## 스냅샷으로 새 서브 계정 만들기

원하는 스냅샷을 기준으로 새 서브 계정을 만드는 단계예요.

### 1단계: 계정 스냅샷으로 이동

1. **에이전시 대시보드**의 왼쪽 메뉴에서 **계정 스냅샷**을 클릭하세요.

![에이전시 대시보드 왼쪽 메뉴의 계정 스냅샷](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049966392/original/uHmwc-IKJ0-JgoaXVruZL5RLaXtK_qnveA.png?1752695024)

### 2단계: 스냅샷 선택

1. 새 서브 계정의 기반으로 쓸 스냅샷을 찾으세요.
2. 스냅샷 옆의 파란색 **Create New Account (+)**(새 계정 만들기) 버튼을 클릭하세요.

![스냅샷 옆의 새 계정 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049966457/original/mHW513SBk2GVrKrvd5IshTz5MDVOXGyJnA.png?1752695169)

### 3단계: 서브 계정 만들기

1. 새 창이 열리면 새 서브 계정 정보를 입력하세요.
2. 정보를 모두 입력했으면 **서브 계정 추가**를 클릭하세요.

![서브 계정 정보 입력 창과 서브 계정 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049966494/original/NI-WY8pXakXgcO7ipkMbHwE57UlMXkMgIg.png?1752695281)

## 자주 묻는 질문

### 서브 계정을 만든 뒤에 적용된 스냅샷을 삭제할 수 있나요?

아니요. 한 번 적용한 스냅샷은 "해제"하거나 "삭제"할 수 없어요. 대신 특정 항목을 직접 삭제하거나 수정할 수 있어요.

### 스냅샷으로 서브 계정을 만들려면 어떤 권한이 필요한가요?

에이전시 관리자 권한이 있는 사용자만 할 수 있어요.

### 스냅샷에는 어떤 자산이 포함되나요?

스냅샷에 저장한 내용에 따라 퍼널, 폼, 워크플로우, 캘린더, 설정 등이 포함돼요. 자세한 내용은 스냅샷 개요 문서를 참고하세요.

### 스냅샷이 새 서브 계정의 기존 내용을 덮어쓰나요?

아니요. 서브 계정을 새로 만드는 것이라 덮어쓸 내용이 없어요. 스냅샷은 계정을 만들 때 적용되고, 그 내용이 계정의 초기 설정이 돼요.

### 새 서브 계정에 스냅샷을 두 개 이상 적용할 수 있나요?

서브 계정을 만드는 중에는 안 돼요. 만들 때는 스냅샷을 하나만 선택할 수 있어요. 다만 서브 계정을 만든 뒤에 다른 스냅샷을 직접 추가로 적용할 수는 있어요.

### 스냅샷을 불러온 뒤 퍼널과 웹사이트는 어떻게 되나요?

스냅샷을 서브 계정에 불러오면 포함된 퍼널과 웹사이트가 모두 초안 상태로 복사돼요. 커스텀 도메인을 연결하고 게시하기 전에는 공개되지 않아요.
