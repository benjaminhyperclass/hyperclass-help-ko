# 스냅샷 삭제 및 이름 변경

더 이상 필요 없는 스냅샷을 지우거나, 스냅샷 이름을 바꾸는 방법을 안내해요. 에이전시 관리자만 쓸 수 있어요.

[동영상](https://www.loom.com/embed/dc8a4bb3fe2d47a49239cb744d5f4013)

## 스냅샷 삭제

1. 에이전시 보기에서 **설정**을 클릭하세요.
2. **계정 스냅샷**을 클릭하세요.
3. **내 스냅샷**, **가져온 스냅샷**, **기본 스냅샷** 탭 중 한 곳에서 삭제할 스냅샷을 찾으세요.
4. 삭제할 스냅샷 옆의 휴지통 아이콘을 클릭하세요.
5. **Ok**(확인)를 클릭하세요.

## 스냅샷 이름 변경

1. 에이전시 보기에서 **설정**을 클릭하세요.
2. **계정 스냅샷**을 클릭하세요.
3. **내 스냅샷**, **가져온 스냅샷**, **기본 스냅샷** 탭 중 한 곳에서 이름을 바꿀 스냅샷을 찾으세요.
4. 이름을 바꿀 스냅샷 옆의 연필 아이콘을 클릭하세요.
5. **스냅샷 이름** 필드에 새 이름을 입력하세요.
6. **저장**을 클릭하세요.
