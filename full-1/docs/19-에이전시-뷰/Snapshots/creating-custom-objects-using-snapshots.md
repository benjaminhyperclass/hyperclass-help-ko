# 스냅샷으로 사용자 지정 객체 복사하기

스냅샷을 이용해 사용자 지정 객체를 서브 계정 간에 복사하는 방법을 안내해요. 사용자 지정 객체의 커스텀 필드와 연결 관계(Association)도 함께 복사할 수 있어요. <!-- 검토 필요: 원문 내용이 서로 다름 (도입부는 '데이터'를 복사한다고 하지만, 본문은 레코드는 스냅샷으로 옮기지 않는다고 설명함) -->

이 문서에서는 기능의 장점, 사용 방법, 꼭 알아 둘 제한 사항을 설명해요. 이 내용을 따라 하면 여러 서브 계정에 같은 사용자 지정 객체 구성을 쉽게 적용할 수 있어요.

## 스냅샷에 포함되는 항목

스냅샷에는 다음 항목을 담을 수 있어요.

- 사용자 지정 객체
- 해당 객체에 연결된 커스텀 필드
- CRM 객체 간에 지원되는 연결 관계

연결 관계는 관계에 속한 두 객체를 모두 스냅샷에 선택하면 자동으로 포함돼요. 연락처와 연락처 사이의 연결 관계는 스냅샷에서 지원하지 않아요.

{% hint style="warning" %}
스냅샷은 다시 쓸 수 있는 구성 자산을 복사하는 기능이에요. 실제 고객 레코드나 계정 이력을 서브 계정 간에 옮기는 용도로는 쓸 수 없어요.
{% endhint %}

---

## 시작하기 전에

다음을 확인하세요.

- 복사할 사용자 지정 객체가 원본 서브 계정에 있어야 해요.
- 내 사용자 역할에 스냅샷 접근 권한이 있어야 해요.
- 대상 서브 계정에 사용자 지정 객체를 추가할 여유 공간이 있어야 해요.

하이퍼클래스의 모든 현재 요금제에서는 서브 계정당 사용자 지정 객체를 최대 10개까지 만들 수 있어요. 스냅샷을 가져올 때도 대상 계정의 사용자 지정 객체 한도가 그대로 적용돼요.

**Load Snapshot**(스냅샷 불러오기)을 쓸 수 없다면, **에이전시 대시보드**에서 **사용자 > Roles and Permissions**(역할 및 권한)로 이동해 스냅샷 접근 권한이 켜져 있는지 확인하세요.

### 스냅샷의 사용자 지정 객체 지원

이제 스냅샷에 사용자 지정 객체와 연결된 커스텀 필드를 **모두** 담을 수 있어요. 기본 필드만 담을 수 있는 것이 아니에요. 덕분에 여러 서브 계정에 사용자 지정 객체 데이터를 손쉽게 복사할 수 있어요.

```
사용자 지정 객체는 서브 계정 간에만 복사할 수 있습니다. 사용자 지정 객체를 직접 내보내는 기능은 지원하지 않습니다.
```

---

### 사용자 지정 객체의 연결 관계

스냅샷을 만드는 동안 사용자 지정 객체는 다른 사용자 지정 객체나 연락처와 자동으로 연결돼요. 연결 관계는 기본으로 포함되며, 스냅샷을 만드는 중에는 수정하거나 선택을 해제할 수 **없어요**.

```
사용자 지정 객체와 다른 객체(연락처 포함) 사이의 연결 관계는 자동으로 만들어지거나 업데이트됩니다. 스냅샷 과정에서는 이 연결 관계를 직접 수정할 수 없습니다.
```

---

### 서브 계정 간에 사용자 지정 객체 복사하기

스냅샷을 쓰면 사용자 지정 객체 구성을 직접 다시 만들지 않고도 여러 서브 계정에서 재사용할 수 있어요.

스냅샷에 사용자 지정 객체를 포함하면, 하이퍼클래스가 선택한 객체와 커스텀 필드, 지원되는 연결 관계를 다른 서브 계정으로 복사해 줘요.

사용자 지정 객체 레코드는 스냅샷 자산으로 안내되어 있지 않아요. 그래서 이 문서에서도 레코드 데이터를 옮길 수 있다고 보지 않아요.

1. **에이전시 > 계정 스냅샷 > 스냅샷 만들기**로 이동하세요.

2. 스냅샷에 포함할 **사용자 지정 개체**를 선택하세요.

![스냅샷에 포함할 사용자 지정 개체 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044030767/original/n7iRDBYfiTyYb3DoXpfDSxrIyGPW_4o0ZA.jpeg?1743003209)

3. 선택한 사용자 지정 개체의 필드와 연결 관계(다른 사용자 지정 개체나 연락처와의 관계)가 자동으로 포함돼요.

4. **원본 서브 계정과 대상 서브 계정**을 선택해 스냅샷 전송을 마무리하세요.

---

### 스냅샷에 사용자 지정 객체 스마트 리스트 포함하기

계정 스냅샷에는 회사 스마트 리스트와 사용자 지정 객체 스마트 리스트도 포함할 수 있어요.

자주 쓰는 세그먼트를 한 번만 만들어 두면, 고객사마다 필터와 보기를 다시 만들 필요 없이 여러 서브 계정에서 같은 스마트 리스트 구성을 재사용할 수 있어요.

예를 들어 다음과 같은 스마트 리스트를 재사용할 수 있어요.

- 업종, 라이프사이클 단계, 계정 등급, 담당자별 회사
- 도시, 가격, 상태, 매물 유형별 부동산
- 갱신이 다가오는 보험 계약
- 만료가 임박한 멤버십
- 회사 필드나 사용자 지정 객체 필드로 만든 그 밖의 모든 세그먼트

### 스냅샷에 스마트 리스트 추가하기

1. 원본 서브 계정에서 스마트 리스트를 만들고 테스트하세요.
2. **에이전시 > 계정 스냅샷**으로 이동하세요.
3. 새 스냅샷을 만들거나 기존 스냅샷을 새로 고치세요.
4. 필요한 **Company Smart Lists**(회사 스마트 리스트)와 **Custom Object Smart Lists**(사용자 지정 객체 스마트 리스트)를 선택하세요.
5. 해당 스마트 리스트가 사용하는 사용자 지정 객체와 필드도 함께 포함하세요.
6. 스냅샷을 저장하거나 새로 고치세요.
7. 스냅샷을 대상 서브 계정에 불러오거나 푸시하세요.
8. 대상 계정에서 회사 목록 또는 사용자 지정 객체 목록을 열고 스마트 리스트가 제대로 들어왔는지 확인하세요.

![스냅샷에 스마트 리스트를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082115638/original/05bu-UcD3aTX2ybItnL5UzwX82vWjGF5uw.png?1790689444)

{% hint style="warning" %}
스냅샷이 복사하는 것은 스마트 리스트 구성이에요. 스마트 리스트에 표시되던 레코드는 복사되지 않아요.

스마트 리스트는 대상 서브 계정에 있는 레코드를 기준으로 결과를 보여 줘요. 예를 들어 스마트 리스트가 `Policy Status = Active` 조건으로 필터링한다면, 대상 계정에서 그 조건에 맞는 Policy 레코드가 표시돼요.

스마트 리스트가 참조하는 사용자 지정 객체와 필드도 반드시 스냅샷에 포함하세요.
{% endhint %}

### 제한 사항

**스냅샷당 사용자 지정 객체 한도:**

스냅샷에는 서브 계정당 사용자 지정 객체를 최대 **10개**까지 담을 수 있어요. 스냅샷을 가져왔을 때 이 한도를 넘게 되면 대상 서브 계정에는 **사용자 지정 객체가 하나도 만들어지지 않아요**.

![사용자 지정 객체 한도 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055149731/original/axSlH5U9mEucSAV8qY5uHSwlQJRt-u8XkQ.png?1759477372)

스냅샷을 쓰면 사용자 지정 객체 구성을 직접 다시 만들지 않고도 여러 서브 계정에서 재사용할 수 있어요.

스냅샷에 사용자 지정 객체를 포함하면, 하이퍼클래스가 선택한 객체와 커스텀 필드, 지원되는 연결 관계를 다른 서브 계정으로 복사해 줘요. 사용자 지정 객체 레코드는 스냅샷 자산으로 안내되어 있지 않아서, 이 문서에서도 레코드 데이터를 옮길 수 있다고 보지 않아요.

## 자주 묻는 질문

### 서브 계정 간에 사용자 지정 객체를 복사할 수 있나요?

네, 할 수 있어요. 사용자 지정 객체를 스냅샷에 포함한 다음, 그 스냅샷을 대상 서브 계정에 불러오세요. 커스텀 필드와 지원되는 연결 관계도 객체와 함께 포함할 수 있어요.

### 사용자 지정 객체를 쓰려면 Pro 요금제가 필요한가요?

아니요. 현재 Starter, Unlimited, Pro 요금제 모두 서브 계정당 사용자 지정 객체를 최대 10개까지 지원해요.

### 사용자 지정 객체 레코드도 스냅샷으로 함께 옮겨지나요?

현재 스냅샷 문서에서는 스냅샷을 실제 계정 레코드가 아니라 구성 자산을 복사하는 도구로 설명하고 있어요. 사용자 지정 객체 레코드 데이터가 스냅샷 전송에 포함된다고 생각하지 마세요.

### 연결 관계도 자동으로 포함되나요?

관계에 속한 두 객체를 모두 선택하면, 지원되는 CRM 연결 관계가 자동으로 포함돼요. 연락처와 연락처 사이의 연결 관계는 지원하지 않아요.

### 한 서브 계정에 스냅샷을 두 개 이상 불러올 수 있나요?

네, 할 수 있어요. 하이퍼클래스에서는 같은 서브 계정에 여러 스냅샷을 불러올 수 있어요. 자산이 서로 겹치면 충돌 여부를 꼼꼼히 확인하세요.
