# 스냅샷에서 연결된 에셋 관리

스냅샷을 적용할 때 어떤 에셋이 포함될지 직접 정할 수 있어요. 각 스냅샷 안에서 에셋을 확인하고, 연결하고, 연결 해제할 수 있어서 스냅샷 관리가 더 쉽고 빠르고 유연해져요.

## 스냅샷 에셋 연결이란?

스냅샷 에셋 연결은 스냅샷을 적용(푸시)할 때 포함할 에셋(워크플로우, 퍼널, 폼 등)을 직접 고르는 기능이에요. 모든 에셋이 자동으로 포함되지 않아요. 연결된 에셋과 연결되지 않은 에셋을 한눈에 보고, 스냅샷을 적용할 때 어떤 에셋을 함께 보낼지 정확하게 정할 수 있어요.

## 스냅샷 에셋 연결의 장점

포함할 에셋을 관리하면 스냅샷을 더 깔끔하게 다듬을 수 있고, 서브 계정에 불필요한 에셋이 쌓이는 것도 막을 수 있어요.

- 적용할 에셋만 골라서 보낼 수 있어요.
- 오래되었거나 쓰지 않거나 관련 없는 에셋이 복사되는 것을 막을 수 있어요.
- 켜진(연결된) 에셋과 꺼진(연결 해제된) 에셋을 한눈에 확인할 수 있어요.
- 더 깔끔하게 적용할 수 있어서 수동으로 정리할 일이 줄어요.
- 스냅샷 관리를 더 규모 있게, 반복해서 운영할 수 있어요.
- 고객사 계정이나 내부 계정에 무엇이 적용되는지 더 확신할 수 있어요.

## 스냅샷에서 연결된 에셋 관리하기

바뀐 스냅샷 화면에서 포함할 에셋을 정하는 방법이에요.

1. **계정 스냅샷**으로 이동하세요.
2. **내 스냅샷**을 클릭하세요.
3. 관리할 스냅샷을 찾아 점 세 개 메뉴(**추가 작업**)를 클릭하세요.
4. **Edit Snapshot**(스냅샷 편집)을 선택하세요.
5. 새 화면에서 에셋을 확인하고 켜거나 끄세요.
   - 켜진 에셋은 적용될 때 함께 보내져요.
   - 꺼진 에셋은 포함되지 않아요.
6. 선택을 마쳤으면 **저장**을 클릭하세요.

## 기능 위치

아래 경로로 에셋 관리 화면에 바로 들어갈 수 있어요.

> **경로**: **계정 스냅샷 > 내 스냅샷 > 추가 작업**(점 세 개) **> Edit Snapshot**(스냅샷 편집)

## 이 기능이 필요한 이유

이번 업데이트 전에는 스냅샷을 적용하면 전부 보내거나 아무것도 보내지 않는 방식인 경우가 많았어요. 그래서 실수하기 쉬웠고, 나중에 정리할 일도 따로 생겼어요. 이제는 필요한 에셋만 정확하게 적용할 수 있어요. 시간이 절약되고 혼란이 줄고, 여러 계정이나 템플릿을 운영하는 에이전시는 정확도도 높일 수 있어요.

새 고객을 시작할 때나 템플릿 라이브러리를 관리할 때도, 스냅샷을 필요한 만큼만 간결하게 유지할 수 있어요.

## 자주 묻는 질문

### 스냅샷을 적용한 뒤에도 에셋을 편집할 수 있나요?
적용된 스냅샷을 직접 편집할 수는 없어요. 대신 새 버전을 만들거나 변경 내용을 반영해 업데이트할 수 있어요.

### 에셋을 연결 해제하면 기존 서브 계정에서도 삭제되나요?
아니요. 연결 해제는 앞으로 적용할 스냅샷에 포함될 에셋에만 영향을 줘요. 이미 적용된 에셋에는 영향이 없어요.

### 시스템에서 제공하는 스냅샷에도 쓸 수 있나요?
지금은 사용자가 만든 스냅샷에서만 쓸 수 있어요. 시스템 스냅샷은 편집할 수 없어요.

### 연결된 에셋을 편집한 뒤에 변경 내용을 저장해야 하나요?
네. 에셋 선택을 확정하려면 **저장**을 클릭하세요.

### 편집할 때 특정 에셋을 필터링하거나 검색할 수 있나요?
네. 화면에 필터와 검색 도구가 있어서 필요한 에셋을 빠르게 찾을 수 있어요.

## 다음 단계

- 스냅샷 목록에서 현재 연결된 에셋을 확인해 보세요.
- 다음에 적용할 때 포함하고 싶지 않은 에셋은 연결을 해제하세요.
- 테스트 적용을 해서 새 설정이 잘 작동하는지 확인하세요.
- 스냅샷 버전 관리로 여러 고객사의 업데이트를 관리하는 방법을 알아보세요.
