# 서브 계정 태그 만들기와 관리

서브 계정 태그는 에이전시가 고객사 계정을 직접 정한 이름표로 분류하는 기능이에요. 한 계정에 태그를 여러 개 붙이고, 태그로 계정을 걸러 보거나 묶어 볼 수 있어요. 걸러 본 화면은 스마트 리스트로 저장할 수 있어요. 이 문서에서는 **에이전시 보기**에서 태그를 만들고, 붙이고, 관리하는 방법을 안내해요.

## 서브 계정 태그란?

서브 계정 태그는 에이전시가 관리하는 고객사 계정을 분류하는 이름표예요. 서브 계정이 무엇인지 궁금하면 [하이퍼클래스의 에이전시 서브 계정이란?](what-is-an-agency-sub-account-in-hyperclass.md)을 참고하세요.

예를 들어 서브 계정 하나에 치과, 온보딩, VIP 태그를 함께 붙일 수 있어요. 그러면 이 태그로 관련 있는 계정을 쉽게 찾고 정리할 수 있어요.

서브 계정 태그는 연락처 태그와 달라요. 서브 계정 태그는 **에이전시 보기**에서 계정을 분류하고, 연락처 태그는 서브 계정 안에서 개별 연락처를 분류해요.

**이용 가능 여부:** 서브 계정 태그는 에이전시 요금제와 사용자 권한에 따라 사용할 수 있는지가 달라질 수 있어요. 정확한 요금제 조건과 태그 관리 권한은 확인이 필요해요. 사용자 권한은 [에이전시 사용자 역할 및 권한 관리](../11-설정/사용자-설정/agency-managing-user-roles-permissions.md)에서 볼 수 있어요.

<!-- 검토 필요: 원문에 요금제 조건과 권한이 확인 필요로 표시되어 있음 -->

## 서브 계정 태그의 장점

태그를 쓰면 계정 하나에 카테고리 하나만 붙이지 않고 유연하게 고객사를 정리할 수 있어요.

- **원하는 대로 분류:** 업종, 서비스 수준, 진행 단계, 담당 팀 등으로 계정을 나눌 수 있어요.
- **태그 여러 개 적용:** 같은 계정에 여러 태그를 붙일 수 있어요.
- **빠른 필터링:** 선택한 태그에 맞는 계정만 찾을 수 있어요.
- **그룹별 보기:** 태그별로 묶고 계정 수를 확인할 수 있어요.
- **스마트 리스트로 재사용:** 걸러 본 계정 화면을 저장해 두고 다시 쓸 수 있어요.
- **간편한 관리:** 지원되는 기능으로 태그를 수정, 재할당, 삭제하거나 일괄 적용할 수 있어요.

## 서브 계정 태그 만들고 관리하기

태그를 일관되게 쓰면 계정을 정리하고 저장한 화면을 다시 쓰기 쉬워요. 아래 순서대로 주요 작업을 따라 해 보세요.

### 1단계: 서브 계정 열기

**서브 계정** 목록에는 에이전시 고객사 계정을 정리하고 관리하는 기능이 모여 있어요. 목록 화면에 대한 자세한 내용은 [무제한 및 파운더 요금제용 새 서브 계정 목록 화면](new-sub-accounts-list-ui-for-unlimited-founder-plans.md)을 참고하세요.

1. **에이전시 보기**로 전환하세요.
2. **서브 계정**을 여세요.
3. 도구 모음에서 **태그**를 찾으세요.

![서브 계정 목록 도구 모음의 태그 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084508360/original/fFpx8pC0LAK12QGgcuVdCKk5oZmEIqB0iw.png?1793279015)

### 2단계: 태그 만들기

태그를 만들어 두면 고객사 계정에 반복해서 쓸 수 있어요.

1. **태그**를 클릭하세요.
2. 태그 이름을 검색하세요.
3. 새 태그를 만드는 옵션을 선택하세요.
4. **온보딩** 같은 이름을 입력하세요.
5. 색상을 고르라는 안내가 나오면 색상을 선택하세요.
6. 만들기를 완료하세요.

![새 태그를 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084528446/original/c9ETOSgJKFlueX_V4FapTSHUeCiKYDVWEA.png?1793288516)

### 3단계: 계정에 태그 붙이기

태그를 여러 개 붙이면 고객사 계정을 여러 기준으로 설명할 수 있어요.

1. 목록에서 서브 계정을 찾으세요.
2. 계정 이름 위에 마우스를 올리고 **태그 추가**를 선택하세요. 해당하는 **태그** 컨트롤을 써도 돼요.
3. **온보딩**을 선택하세요.
4. **치과** 같은 태그를 하나 더 추가하세요.
5. 두 태그가 계정 옆에 모두 표시되는지 확인하세요.

![서브 계정에 태그를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084529118/original/im2KRlUF7I8RFo1I_CBrFdns9vfy1GMkrw.png?1793288854)

### 4단계: 태그 일괄 적용하기

여러 계정에 같은 태그를 붙여야 할 때는 일괄 적용이 편해요. 일괄 작업 기록과 기능은 [서브 계정 일괄 작업 및 기록](sub-account-bulk-actions-history.md)에서 더 볼 수 있어요.

1. 대상 서브 계정 옆의 체크박스를 선택하세요.
2. 사용할 수 있는 일괄 작업 기능을 여세요.
3. 태그를 지정하는 옵션을 선택하세요.
4. 태그를 선택하세요.
5. 내용을 확인하고 변경을 적용하세요.

{% hint style="info" %}
일괄 작업 기능의 정확한 구성, 지원되는 태그 제거 작업, 필요한 권한은 확인이 필요해요.
{% endhint %}

### 5단계: 태그로 서브 계정 걸러 보기

태그 필터를 쓰면 특정 그룹의 고객사 계정만 찾을 수 있어요.

1. **태그**를 클릭하세요.
2. **온보딩** 같은 태그를 선택하세요.
3. 조건에 맞는 계정을 확인하세요.
4. 필요하면 지원되는 다른 필터도 함께 적용하세요.

### 6단계: 태그별로 서브 계정 묶어 보기

그룹으로 묶으면 계정 카테고리와 계정 수를 한눈에 볼 수 있어요.

1. **그룹화 기준**을 클릭하세요.
2. **태그**를 선택하세요.
3. 만들어진 그룹을 확인하세요.
4. 필요에 따라 그룹을 펼치거나 접으세요.

### 7단계: 스마트 리스트 저장하기

걸러 본 화면을 저장해 두면 같은 계정 그룹을 쉽게 다시 볼 수 있어요. 스마트 리스트에 대한 기본 내용은 [스마트 리스트 만들고 관리하기](../02-연락처/스마트-리스트/how-to-create-manage-smart-lists.md)를 참고하세요.

1. 원하는 태그와 계정 필터를 적용하세요.
2. **스마트 리스트 추가** 또는 해당하는 저장 버튼을 클릭하세요.
3. **설명이 되는 이름 입력** 칸에 알아보기 쉬운 이름을 입력하세요.
4. 스마트 리스트를 저장하세요.
5. 스마트 리스트 탭에서 다시 열 수 있어요.

### 8단계: 태그 수정, 재할당, 삭제하기

이미 만든 태그를 관리하면 계정 카테고리를 정확하고 일관되게 유지할 수 있어요.

1. **태그**를 여세요.
2. 관리할 태그를 찾으세요.
3. 해당 태그의 관리 옵션을 여세요.
4. 이름이나 색상을 바꾸거나, **Reassign to...**(다른 태그로 재할당) 또는 **태그 삭제**를 선택하세요.
5. 확인 안내가 나오면 내용을 살펴본 뒤 작업을 완료하세요.

{% hint style="warning" %}
재할당과 삭제는 신중하게 확인하세요. 특히 많은 계정에 쓰이는 태그라면 더 주의하세요.
{% endhint %}

## 태그 만들기와 붙이기

태그를 쓰면 에이전시에서 정한 카테고리 기준으로 계정을 구분할 수 있어요.

자주 쓰는 예시는 다음과 같아요.

| 카테고리 | 태그 예시 |
| --- | --- |
| 진행 단계 | 온보딩, 활성, 이탈 위험 |
| 업종 | 치과, 지붕 공사, 부동산 |
| 서비스 수준 | 직접 운영(DIY), 대행 운영(Done-for-you) |
| 계정 유형 | VIP, 테스트, 내부용 |
| 계정 담당자 | Sarah, Dev, Priya |

서브 계정 하나에 태그를 여러 개 붙일 수 있고, 같은 태그를 여러 서브 계정에 쓸 수도 있어요.

{% hint style="info" %}
태그는 정리를 위한 이름표예요. 담당자 이름을 태그로 추가해도 그 사용자에게 계정이 배정되거나 접근 권한이 생기지는 않아요. 접근 권한은 [사용자 접근 권한](../11-설정/user-access.md)에서 확인하세요.
{% endhint %}

## 태그 관리하기

태그 이름과 카테고리를 일관되게 유지하면 필터링과 그룹화가 더 유용해져요.

**태그** 메뉴에서 태그를 검색하고, 이미 만든 태그를 관리할 수 있어요.

이번 업데이트에서 볼 수 있는 관리 옵션은 다음과 같아요.

- **이름 수정:** 기존 태그의 이름을 바꿔요.
- **색상 변경:** 카테고리를 더 쉽게 알아볼 수 있게 해요.
- **Reassign to...**(다른 태그로 재할당): 기존 태그를 다른 태그로 재할당해요.
- **태그 삭제:** 더 이상 필요 없는 태그를 지워요.

{% hint style="warning" %}
재할당과 삭제가 기존 서브 계정 배정에 어떤 영향을 주는지 확인한 뒤에 변경하세요. 이 작업은 여러 계정에 영향을 줄 수 있어요.
{% endhint %}

## 서브 계정 필터링과 그룹화

필터링과 그룹화는 태그가 붙은 계정을 다루는 서로 다른 방법이에요.

필터링은 선택한 조건에 맞는 계정만 남겨서 목록을 좁혀요. 그룹화는 보이는 계정을 구역별로 묶어 보여 줘요.

| 옵션 | 용도 |
| --- | --- |
| **태그** | 선택한 태그로 서브 계정을 걸러요 |
| **필터 / 상세 필터** | 지원되는 다른 계정 조건으로 결과를 더 좁혀요 |
| **그룹화 기준 > 태그** | 계정을 접고 펼 수 있는 태그별 그룹으로 정리해요 |
| **Untagged**(태그 없음) | 태그가 없는 계정을 찾아요(사용 가능한 경우) |

예를 들어 **온보딩**으로 걸러 보면 그 단계에 있는 고객사를 확인할 수 있어요. 태그로 그룹화하면 여러 고객사 카테고리를 비교해 볼 수 있어요.

{% hint style="info" %}
여러 태그를 선택했을 때의 일치 규칙과, 태그가 여러 개인 계정이 그룹화 결과에 표시되는 방식은 확인이 필요해요.
{% endhint %}

## 태그 기반 스마트 리스트 저장하기

스마트 리스트로 자주 쓰는 서브 계정 화면을 저장해 두면 같은 필터를 다시 설정하지 않고 바로 열 수 있어요.

예를 들어 에이전시에서 **치과 온보딩 고객사**라는 이름으로 화면을 저장해 두고 정기적으로 확인할 수 있어요.

서브 계정 화면에서 **스마트 리스트 추가** 또는 해당하는 저장 버튼을 사용하세요.

{% hint style="warning" %}
에이전시 수준의 서브 계정 스마트 리스트는 개별 서브 계정 안의 연락처 스마트 리스트와 별개예요. 저장된 그룹화와 정렬이 어떻게 동작하는지, 태그 배정이 바뀌면 스마트 리스트가 어떻게 업데이트되는지는 확인이 필요해요.
{% endhint %}

## 자주 묻는 질문

### 서브 계정 하나에 태그를 여러 개 붙일 수 있나요?
네. 같은 계정에 태그를 여러 개 붙일 수 있어요.

### 서브 계정 태그와 연락처 태그는 같은 건가요?
아니요. 서브 계정 태그는 에이전시 고객사 계정을 분류하고, 연락처 태그는 개별 서브 계정 안의 연락처를 분류해요.

### 태그 이름이나 색상을 바꿀 수 있나요?
네. 태그 관리 메뉴에서 이름을 수정하고 색상을 고를 수 있어요.

### 여러 서브 계정에 태그를 한꺼번에 붙일 수 있나요?
네. 이번 업데이트에 태그 일괄 적용이 포함되어 있어요. 정확한 기능 구성과 필요한 권한은 확인이 필요해요.

### 필터링과 그룹화는 어떻게 달라요?
필터링은 계정 목록을 좁혀 주고, 그룹화는 보이는 계정을 태그별 구역으로 묶어 줘요.

### 태그가 없는 서브 계정은 어떻게 찾나요?
**태그** 메뉴에 **Untagged**(태그 없음) 옵션이 있어서 태그가 없는 계정을 찾을 수 있어요.

### 태그로 걸러 본 화면을 저장할 수 있나요?
네. 태그로 걸러 본 서브 계정 화면을 에이전시 수준의 스마트 리스트로 저장할 수 있어요.

### 태그를 재할당하거나 삭제하면 어떻게 되나요?
화면에서 두 작업을 모두 쓸 수 있지만, 기존 배정에 미치는 정확한 영향은 사용하기 전에 확인이 필요해요.

### 팀원 이름을 태그로 추가하면 그 팀원에게 계정이 배정되나요?
아니요. 태그는 실제 계정 배정이나 사용자 권한을 대신하지 않아요.
