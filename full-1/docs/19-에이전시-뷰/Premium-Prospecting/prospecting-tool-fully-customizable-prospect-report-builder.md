# 잠재고객 발굴 리포트를 내 브랜드에 맞게 꾸미기 (Report Builder)

**잠재고객 발굴** 리포트의 웹 리포트 화면이 새롭게 바뀌었고, 리포트의 모양을 직접 정할 수 있는 **Report Builder**(리포트 빌더)가 추가되었어요. 이 문서에서는 Report Builder를 여는 방법과 브랜드 테마, 헤더, 소개, 푸터를 꾸미는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/cai2kWBAOWM?&wmode=opaque)

브랜드 이야기를 담은 리포트로 첫인상을 높이고, 더 많은 계약으로 이어지도록 도와줘요.

{% hint style="info" %}
이 기능은 프리미엄 잠재고객 발굴 구독이 필요해요. 미리보기 모드는 에이전시와 서브 계정 모두 무료예요.
{% endhint %}

## Report Builder란?

Report Builder는 잠재고객 리포트의 모양과 내용을 직접 정할 수 있는 프리미엄 기능이에요. 에이전시와 서브 계정은 리포트의 브랜드 테마, 헤더, 소개 메시지, 푸터를 사용자 지정해서 모든 리포트에 브랜드의 개성을 담을 수 있어요. 사용하기 쉬운 화면에서 실시간 미리보기를 보며 리포트를 다듬을 수 있어요. 보기에 좋을 뿐 아니라 고객의 반응도 끌어내는 리포트를 만들 수 있어요.

### UI 개선 사항

- 헤더 개선
  1. 공간을 많이 차지하던 기존 고정 헤더 문제를 개선했어요.
  2. 이제 스크롤할 때 헤더가 내용을 가리지 않아요.

- 레이아웃 최적화
  1. 양쪽의 빈 흰색 여백을 없앴어요.
  2. 리포트가 더 깔끔하고 간결해져서 탐색하기 쉽고, 내용도 더 잘 보여요.

{% hint style="info" %}
새 UI는 현재 웹 리포트에서만 쓸 수 있어요.
{% endhint %}

## 주요 장점

Report Builder를 쓰면 고객에게 보내는 리포트의 디자인과 기능을 모두 높일 수 있어요.

- 브랜드가 담긴 전문적인 리포트: 일관된 브랜드 경험으로 고객의 신뢰를 높여요.
- 전환에 맞춘 레이아웃: 중요한 CTA(행동 유도 버튼)와 연락처 정보를 눈에 잘 띄게 보여 줘요.
- 맞춤 메시지: 업종에 맞는 정보로 내용을 구성해서 대상 고객의 공감을 얻어요.
- 실시간 미리보기: 바꾼 내용을 바로 확인하고, 지체 없이 안심하고 게시할 수 있어요.

## Report Builder 여는 방법

Report Builder는 프리미엄 잠재고객 발굴 구독을 쓰는 사용자라면 에이전시와 서브 계정 모두에서 쓸 수 있어요. 기본(Basic) 잠재고객 발굴을 쓰고 있다면 Report Builder를 둘러볼 수는 있지만, 변경 내용은 저장할 수 없어요.

### 에이전시에서 열기

1. **에이전시** 계정에 로그인하세요.
2. 메인 메뉴에서 **잠재고객 발굴** 탭을 클릭하세요.
3. **Report Builder** 탭을 선택하면 리포트를 꾸밀 수 있어요.

![에이전시에서 Report Builder 탭 위치](https://jumpshare.com/v/8pGNdQIymy3P4VACl5iU+/Screen+Shot+2025-07-07+at+9.42.04+PM.png)

### 서브 계정에서 열기

1. 서브 계정에 로그인하세요.
2. **마케팅** 탭을 클릭하세요.
3. **잠재고객 발굴**을 클릭하세요.
4. **Report Builder** 탭을 클릭하면 리포트를 만들 수 있어요.

![서브 계정에서 Report Builder 탭 위치](https://jumpshare.com/v/q2r18oyQVX3NUdA3iAiB+/Screen+Shot+2025-07-07+at+9.46.07+PM.png)

## Report Builder로 리포트 꾸미기

Report Builder는 4개의 탭으로 나뉘어 있어요. 탭을 클릭해서 바로 편집하면 되고, 오른쪽에서 실시간 미리보기를 볼 수 있어요.

### Brand Theme(브랜드 테마)

리포트 전체에 적용할 브랜드의 시각적 정체성을 정하는 곳이에요. 브랜드 웹사이트, 로고, 마케팅 자료와 어울리게 리포트를 맞출 때 사용하세요.

다음 항목을 사용자 지정할 수 있어요.

- **기본 색상**: 리포트 전반에 쓰이는 주된 배경색 또는 바탕색이에요(예: 각 섹션의 배경).
- **보조 색상**: 기본 색상을 은은하게 보완하는 강조색이에요.
- **Report Text Color**(리포트 텍스트 색상): 리포트 본문 텍스트의 색상이에요.
- **Header Link Color**(헤더 링크 색상): 헤더에 있는 클릭 가능한 링크(예: 웹사이트 URL)의 색상이에요.
- **CTA Background Color**(CTA 배경 색상): **지금 연결**이나 **Contact Now**(지금 문의) 같은 CTA(행동 유도) 버튼의 색상이에요.
- **CTA Text Color**(CTA 텍스트 색상): CTA 버튼 안에 표시되는 글자의 색상이에요.

![브랜드 테마 색상 설정](https://jumpshare.com/v/9iQKsrm0nQSlAV5aJiRT+/Screen+Shot+2025-07-07+at+10.53.16+PM.png)

### Header Customization(헤더 사용자 지정)

리포트 헤더에 어떤 요소를 보여 줄지 정하는 곳이에요.

#### 1. 헤더 표시 옵션

헤더에 보일 요소를 정해요.

- **Show Header Logo**(헤더 로고 표시): 비즈니스 로고를 표시하거나 숨겨요.
- **Show Header Website**(헤더 웹사이트 표시): 비즈니스 웹사이트 링크를 표시하거나 숨겨요.
- **Show Header Description**(헤더 설명 표시): 슬로건이나 안내 문구 같은 짧은 한 줄을 표시해요(예: "감사 결과에 대해 도움이 필요하신가요?").
- **Show Header Email / Contact**(헤더 이메일/연락처 표시): 연락처 이메일과 전화번호를 표시할지 정해요.
- **Show Header CTA Button**(헤더 CTA 버튼 표시): "지금 문의" 같은 대표 행동 버튼을 표시하거나 숨겨요.

![헤더 표시 옵션 설정](https://jumpshare.com/v/4EgCMVTaFvbagAkrIOMn+/GIF+Recording+2025-07-07+at+11.16.57+PM.gif)

#### 2. 헤더 디자인 옵션

- **폰트**: 글꼴 종류를 골라요(예: Arial, Roboto).
- **글꼴 굵기**: 글자 굵기를 정해요(보통, 미디엄, 굵게).
- **Font Style**(글꼴 스타일): 일반 또는 이탤릭을 골라요.

  ![글꼴 옵션 설정](https://jumpshare.com/v/FAwJnuZp9bRgowJ51l4X+/GIF+Recording+2025-07-07+at+11.38.30+PM.gif)
- **로고 업로드**: 권장 크기는 80x80px이에요.
- **Header Title**(헤더 제목): 로고 옆에 표시할 제목 텍스트예요.
- **Header Description**(헤더 설명): 제목을 보충하는 한 줄이에요.
- **Header Website**(헤더 웹사이트): 클릭 가능한 링크로 표시할 URL이에요.
- **Header Email**(헤더 이메일): 연락처 이메일 주소예요.
- **Header Phone Number**(헤더 전화번호): 비즈니스 연락 전화번호예요.
- **CTA Text**(CTA 텍스트): 버튼에 표시할 문구예요(예: "지금 예약").
- **CTA Action**(CTA 동작): 버튼을 클릭했을 때 일어날 동작을 골라요.

  - **URL**: 예약 페이지나 웹사이트로 이동해요.
  - **이메일**: 연락처로 보낼 이메일 초안이 열려요.
  - **통화**: 전화번호로 전화를 걸어요(모바일 기기).

![헤더 디자인 옵션 설정](https://jumpshare.com/v/SI7C3Ji7xUlXvjBLzvcj+/GIF+Recording+2025-07-07+at+11.42.43+PM.gif)

#### 3. 헤더 스타일

세 가지 헤더 스타일 중에서 골라요.

- **Left Top Wave**(왼쪽 위 물결)
- **Full Background**(전체 배경)
- **Double Wave Left**(왼쪽 이중 물결)

![헤더 스타일 선택](https://jumpshare.com/v/zfneT7kAeyFgSrzdFIzP+/GIF+Recording+2025-07-07+at+11.54.32+PM.gif)

### Introduction Customization(소개 사용자 지정)

헤더 아래에 보이는 소개 내용을 설정하는 곳이에요. 이 공간에서 감사(audit)의 가치와, 발견된 부족한 부분을 어떻게 도울 수 있는지 설명해 보세요.

- **Show Introduction Description**(소개 설명 표시): 소개 블록 전체를 표시하거나 숨겨요.
- **Introduction Font Family, Weight, and Style**(소개 글꼴, 굵기, 스타일): 소개 문단 텍스트의 모양을 정해요.
- **Introduction Title**(소개 제목): 이 섹션이 무엇에 관한 것인지 알려 주는 짧은 제목이에요.
- **Introduction Description**(소개 설명): 배경을 설명하는 텍스트예요. 리포트가 어떤 내용을 다루고 왜 중요한지 잠재고객에게 알려 주기 좋아요.

![소개 사용자 지정 설정](https://jumpshare.com/v/sQRVe8xkviwufGCAuMHI+/GIF+Recording+2025-07-08+at+12.00.17+AM.gif)

### Footer Customization(푸터 사용자 지정)

리포트 푸터에 어떤 요소를 보여 줄지 정하는 곳이에요.

#### 1. 푸터 표시 옵션

푸터에 보일 요소를 정해요.

- **Show Footer Description**(푸터 설명 표시): 푸터 소개 블록을 표시하거나 숨겨요.
- **Show Footer CTA Button**(푸터 CTA 버튼 표시): 푸터의 CTA 버튼을 표시하거나 숨겨요.

![푸터 표시 옵션 설정](https://jumpshare.com/v/fDXXJLVRiq1rQr48L7Od+/GIF+Recording+2025-07-08+at+12.12.52+AM.gif)

#### 2. 푸터 디자인 옵션

- **폰트**: 글꼴 종류를 골라요(예: Arial, Roboto).
- **글꼴 굵기**: 글자 굵기를 정해요(보통, 미디엄, 굵게).
- **Font Style**(글꼴 스타일): 일반 또는 이탤릭을 골라요.
- **Footer Title**(푸터 제목): 푸터에 들어갈 제목 텍스트예요.
- **Footer Description**(푸터 설명): 제목 아래에 들어갈 보충 텍스트예요.
- **Footer CTA Text**(푸터 CTA 텍스트): 버튼에 표시할 문구예요(예: "전문가와 상담하기").
- **Footer CTA Action**(푸터 CTA 동작):

  - **URL**: 예약 페이지나 웹사이트로 이동해요.
  - **이메일**: 연락처로 보낼 이메일 초안이 열려요.
  - **통화**: 전화번호로 전화를 걸어요(모바일 기기).

![푸터 디자인 옵션 설정](https://jumpshare.com/v/3vOef6fiN7jVV8oFgKqW+/GIF+Recording+2025-07-08+at+12.22.28+AM.gif)

#### 3. 푸터 스타일

세 가지 푸터 스타일 중에서 골라요.

- **Right Curve Wave**(오른쪽 곡선 물결)
- **Flat Bottom Border**(평평한 하단 테두리)
- **Full Background**

![푸터 스타일 선택](https://jumpshare.com/v/FjjYF7ZDwbmk5h5Oy9pw+/GIF+Recording+2025-07-08+at+12.25.44+AM.gif)

### 미리보기와 저장

- **미리보기**를 클릭하면 아직 저장하지 않은 가장 최근 버전의 전체 리포트가 새 탭에서 열려요.
- **저장**을 클릭하면 과거와 앞으로 만들 모든 리포트에 변경 내용이 적용돼요.
- **기본값으로 재설정**을 사용하면 사용자 지정한 내용을 되돌릴 수 있어요.

![미리보기, 저장, 기본값으로 재설정 버튼](https://jumpshare.com/v/cSz87r15oCIKRZFnDva2+/Screen+Shot+2025-07-08+at+12.28.45+AM.png)

## 자주 묻는 질문

### 잠재고객 리포트 빌더는 누가 쓸 수 있나요?
프리미엄 이용 권한이 있으면 모든 에이전시와 서브 계정이 쓸 수 있어요. 미리보기 모드는 둘 다 무료예요.

### 프리미엄 구독에는 무엇이 포함되나요?
프리미엄 구독을 쓰면 브랜드 테마, 헤더, 소개, 푸터 설정을 포함한 모든 사용자 지정 옵션과 외부 리포트 UI 개편을 쓸 수 있어요.

### 변경한 내용을 바로 볼 수 있나요?
네. 실시간 미리보기가 제공되어서, 게시하기 전에 바꾼 내용을 바로 확인할 수 있어요.

### 외부 UI 개편으로 무엇이 좋아졌나요?
더 깔끔하고 현대적인 레이아웃에 아이콘이 통일되고 텍스트 스타일도 좋아져서, 리포트가 시각적으로 더 매력적이에요.
