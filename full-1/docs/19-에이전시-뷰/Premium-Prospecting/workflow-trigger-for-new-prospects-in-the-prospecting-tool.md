# 워크플로우 트리거 — Prospect Generated(잠재고객 생성됨)

**잠재고객 발굴**에서 새 잠재고객이 생길 때 자동화를 실행하는 트리거예요. 앱에서 직접 만든 잠재고객과 임베드 위젯으로 들어온 잠재고객 모두에 쓸 수 있어요. 잠재고객 정보에 따라 작업을 자동화하면 리드를 더 효과적으로 정리하고 응대할 수 있어요.

## 개요

**Prospect Generated**(잠재고객 생성됨) 트리거는 **잠재고객 발굴**에서 직접 만든 잠재고객이나 웹사이트에 삽입한 임베드 위젯으로 들어온 잠재고객에 대해 자동화를 실행해요. 리드를 정리하고, 후속 관리 전략을 개선하고, 세일즈 퍼널을 최적화하는 데 도움이 돼요.

이 트리거로 할 수 있는 일은 다음과 같아요.

- 새 잠재고객을 자동으로 저장하고 분류해요.
- **Source**(출처)가 **In-App**(인앱)인지 **Widget**(위젯)인지, 그리고 **Conversion Rate**(전환율)를 기준으로 잠재고객을 필터링해요.
- 환영 이메일 보내기, 영업 파이프라인에 잠재고객 배정, 팀원에게 알림 같은 작업을 자동으로 실행해요.

## 트리거 설명

**Prospect Generated** 트리거는 **잠재고객 발굴**에서 새 잠재고객이 만들어질 때 자동화 워크플로우를 실행해요. 잠재고객이 만들어지는 경로는 세 가지예요.

1. **In-App:** 도구 안에서 잠재고객을 직접 만들었을 때
2. **Widget:** 웹사이트에 삽입한 임베드 위젯으로 잠재고객이 생성되었을 때
3. **Prospect AI**(AI가 자동으로 생성한 잠재고객): Prospect AI가 잠재고객을 자동으로 생성했을 때

이 트리거로 잠재고객을 다음 기준에 따라 걸러서 정리할 수 있어요.

- **Source:** 잠재고객이 앱 안에서 만들어졌는지, 위젯을 통해 들어왔는지, AI가 만들었는지 구분해요.
- **Conversion Rate:** 전환 가능성에 따라 잠재고객을 나눠서 맞춤형으로 응대해요.

이메일에 병합 필드를 사용해 커스텀 값을 넣을 수도 있어요.

이렇게 설정하면 가능성이 높은 리드를 우선 관리하고 영업 과정을 간소화할 수 있어요.

---

## 설정 방법

#### 1단계: 워크플로우 트리거 설정하기

1. **워크플로우 만들기 또는 편집하기:**

   - **Create Workflow**(워크플로우 만들기)를 클릭하거나, 기존 워크플로우를 선택해 편집해요.
2. **트리거 선택하기:**

   - 트리거 영역에서 워크플로우 트리거로 **Prospect Generated**를 선택해요.
   - 이 트리거를 쓰면 새 잠재고객에 대한 작업을 자동화하고, 잠재고객을 필터링하고 정리해 영업 대상을 더 효과적으로 정할 수 있어요.

---

#### 2단계: 잠재고객 필터 추가하기

워크플로우를 더 정확하게 만들려면 잠재고객 정보에 따라 특정 작업만 실행되도록 필터를 적용하세요.

1. **Source 필터:**

   - **In-App:** **잠재고객 발굴**에서 직접 만든 잠재고객에 대해 작업을 실행해요.
   - **Widget:** 웹사이트에 삽입한 임베드 위젯으로 생성된 잠재고객에 대해 작업을 실행해요.
   - **Prospect AI:** Prospect AI가 자동으로 생성한 잠재고객에 대해 작업을 실행해요.
   - 이 필터로 리드 출처를 구분할 수 있어서 출처별로 맞춤형 후속 전략을 세울 수 있어요.
2. **Conversion Rate 필터:**

   - 전환율을 기준으로 잠재고객을 필터링해요.
   - 다음과 같이 워크플로우를 따로 만들 수 있어요.
     - **전환율이 높은 잠재고객:** 맞춤형 아웃리치나 영업팀의 직접 후속 연락을 실행해요.
     - **전환율이 낮은 잠재고객:** 참여를 높이는 육성 캠페인을 설정해요.
   - 이렇게 나누면 전략적으로 응대해 영업 성과를 높일 수 있어요.

![Prospect Generated 트리거에 Source와 Conversion Rate 필터를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049068387/original/VHH3ra6k19va_c7eZctZZ6gmyf_AuQN5mw.png?1751275982)

#### 3단계: 잠재고객 정보를 자동 작업에 연결하기

트리거를 설정하고 필터를 적용했다면, 다음은 잠재고객 정보를 자동 작업에 연결할 차례예요. 이렇게 하면 **잠재고객 발굴**에서 고급 워크플로우 자동화를 활용할 수 있어요.

**설정할 수 있는 자동 작업:**

- 영업 파이프라인에 잠재고객 배정: 잠재고객을 영업 파이프라인의 알맞은 단계에 자동으로 정리해요.
- 환영 이메일이나 SMS 보내기: 새로 생성된 잠재고객에게 맞춤형 메시지를 먼저 보내요.
- 팀원에게 알림: 전환율이 높은 잠재고객이 생기면 영업팀에 실시간으로 알려요.
- 잠재고객에 태그 지정 및 분류: 태그, 카테고리, 분야별로 잠재고객을 자동으로 정리해 세분화해요.

![잠재고객 정보를 자동 작업에 연결하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049068267/original/ciPMPvtaGZ1AR26cLqPGmfKMIk2PzWv-pQ.jpeg?1751275910)

---

#### 4단계: 워크플로우 저장하고 테스트하기

설정과 연결을 모두 마쳤다면 다음을 진행하세요.

- **Save**(저장)를 클릭해요. 워크플로우가 완성돼요.
- 워크플로우를 테스트해요. 앱에서 직접 만든 경우와 위젯으로 생성된 경우 모두 새 잠재고객이 만들어지는 상황을 시험해서 자동화가 예상대로 실행되는지 확인해요.
- 필요하면 수정해요. 워크플로우가 의도대로 작동하지 않으면 조건이나 작업을 세밀하게 조정하세요.

## 예시

**시나리오:** 임베드 위젯으로 생성된 모든 새 잠재고객에게 맞춤형 환영 이메일을 보내고, 전환율이 높은 잠재고객이 생기면 영업팀에 알리고 싶어요.

1. **트리거 설정:**

   - 트리거를 **Prospect Generated**로 설정해요.
   - **Source = Widget**, **Conversion Rate > 70%** 조건으로 필터링해요.
2. **자동 작업:**

   - **Send Welcome Email**(환영 이메일 보내기): 맞춤형 이메일이 새 잠재고객에게 자동으로 발송돼요.
   - **Notify Team**(팀에 알림): 전환율이 높은 리드가 생겼다고 영업팀에 알려서 바로 후속 연락을 할 수 있어요.
3. **결과:**

   - 위젯으로 들어온 새 잠재고객은 즉시 환영 이메일을 받아요.
   - 전환율이 높은 잠재고객이 표시되어 영업팀이 우선적으로 응대할 수 있어요.

### 마무리

**잠재고객 발굴**에서 생성된 새 잠재고객에 워크플로우 트리거를 설정하면 리드 관리를 자동화하고, 영업 대상을 더 정확하게 정하고, 전체 전환율을 높일 수 있어요. 출처와 전환율 같은 필터로 워크플로우를 맞춤 설정해 잠재고객을 전략적으로 응대하고, 세일즈 퍼널을 간소화하며, 팀 생산성을 높여 보세요.

궁금한 점이 있으면 하이퍼클래스 고객지원에 문의하세요.
