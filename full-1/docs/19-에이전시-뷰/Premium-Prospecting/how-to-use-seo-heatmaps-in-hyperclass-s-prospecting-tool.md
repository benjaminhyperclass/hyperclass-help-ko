# SEO 히트맵으로 잠재고객의 검색 순위 확인하기

잠재고객 발굴 도구의 SEO 히트맵은 잠재고객의 검색 순위를 지도 위에 보여 줘요. 특정 키워드와 지역에서 웹사이트가 검색 결과 어디쯤 있는지 한눈에 파악해, 노출도를 높이고 SEO 작업을 개선하는 데 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/PYUWNDAzLmk?&wmode=opaque)

{% hint style="info" %}
이 기능을 쓰려면 에이전시와 서브 계정 모두 프리미엄 잠재고객 발굴을 구독해야 해요.
{% endhint %}

## SEO 히트맵이란?

SEO 히트맵은 지도 위 9개 주요 지점에서 검색 순위를 표시하는 도구예요. 웹사이트가 지역별로 얼마나 잘 노출되는지 지리적으로 볼 수 있어요. 히트맵의 각 지점은 잠재고객 업체 주변의 특정 위치를 나타내요. 그래서 노출이 강한 지역과 개선이 필요한 지역을 구분할 수 있어요.

## SEO 히트맵 도구의 주요 장점

- 지역별 인사이트: 지역마다 순위가 어떤지 시각적으로 볼 수 있어요. SEO 작업이 잘 되고 있는 곳과 개선이 필요한 곳이 분명하게 드러나요.
- 맞춤형 최적화: 노출이 부족한 지역을 찾아내고, 그 지역의 순위를 높이도록 SEO 전략을 다듬을 수 있어요.
- 로컬 검색 전략 개선: 로컬 검색에 의존하는 업체라면 주변 지역에서 순위가 어떤지 확인하고, 그에 맞춰 로컬 SEO 전략을 조정할 수 있어요.

## SEO 히트맵 도구는 어떻게 작동하나요?

SEO 히트맵은 여러 지점의 순위를 바탕으로 검색 노출도를 평가해요.

1. 중심 지점(가중치 20%): 업체가 있는 중심 위치예요. 전체 점수에서 가중치가 가장 높고, 업체 바로 주변 지역에서의 노출도를 나타내요.
2. 외곽 지점(각 10%): 주변 지역을 나타내는 8개 지점이에요. 인접 지역에서 업체의 순위가 어떤지 알 수 있어요.

각 지점에는 선택한 키워드(또는 키워드 묶음)로 검색했을 때 업체가 나타나는 순위가 매겨져요. 지점의 순위가 높을수록 그 지역에서 노출이 잘 되고, 전체 SEO 성과도 좋다는 뜻이에요.

## SEO 히트맵 사용 방법

{% hint style="info" %}
SEO 히트맵의 카테고리 데이터가 이제 잠재고객의 Google 비즈니스 프로필 카테고리와 더 가깝게 맞춰져요. 그래서 히트맵이 Google에 등록된 업체 정보를 더 정확하게 반영해요.

이전에 만든 리포트를 확인한다면, 먼저 새로고침해서 최신 히트맵 데이터를 불러오세요.
{% endhint %}

### 에이전시 계정에서 사용하기

#### 1단계: 잠재고객 발굴 열기

1. 하이퍼클래스 에이전시 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **잠재고객 발굴** 탭을 클릭하세요.

![에이전시 왼쪽 메뉴의 잠재고객 발굴 탭](https://jumpshare.com/v/D937XgjrDjqUgounid1F+/Screen+Shot+2025-07-14+at+9.52.11+PM.png)

#### 2단계: 잠재고객 리포트 열기

1. **Add Prospect**(잠재고객 추가)를 클릭해 새 잠재고객을 만들거나, 기존 잠재고객을 선택하세요.
2. **View Report**(리포트 보기) 버튼을 클릭하세요.

![잠재고객 추가와 리포트 보기 버튼](https://jumpshare.com/v/R8oNO3OXorB0reTmke87+/Screen+Shot+2025-07-14+at+9.53.53+PM.png)

#### 3단계: SEO 히트맵 확인하기

1. 리포트가 열리면 왼쪽 사이드바에서 **SEO Analysis**(SEO 분석) 탭을 클릭하세요.
2. 아래로 스크롤해 키워드 성과가 표시된 **히트맵**을 확인하세요.
3. 지도의 각 점은 주변의 서로 다른 위치에서 검색했을 때의 로컬 검색 결과를 나타내요.
4. 가운데 점은 업체가 있는 바로 주변 지역을 나타내요.
5. 설정한 키워드의 순위가 표시돼요. 예를 들어 “내 주변 아시안 식당” 같은 키워드예요.
6. 상위 3개 로컬 경쟁업체도 함께 표시돼요.

![SEO 히트맵 화면(에이전시)](https://jumpshare.com/v/R8rJJidTaLQ1y7VOvY9j+/Screen+Shot+2025-07-14+at+10.01.37+PM.png)

### 서브 계정에서 사용하기

#### 1단계: 잠재고객 발굴로 이동하기

1. 프리미엄 잠재고객 발굴이 켜져 있는 서브 계정에 로그인하세요.
2. 왼쪽 메뉴에서 **마케팅**을 클릭하세요.
3. 상단 메뉴에서 **잠재고객 발굴** 탭을 선택하세요.

![마케팅 메뉴의 잠재고객 발굴 탭](https://jumpshare.com/v/KAa88cQaRU2Fu3lnxwbx+/Screen+Shot+2025-07-14+at+10.09.19+PM.png)

#### 2단계: 잠재고객 리포트 열기

1. **Add Prospect**(잠재고객 추가)를 클릭해 새 잠재고객을 만들거나, 기존 잠재고객을 선택하세요.
2. **View Report**(리포트 보기) 버튼을 클릭하세요.

![잠재고객 추가와 리포트 보기 버튼](https://jumpshare.com/v/iS9HtNB4SuQhqjUrv53E+/Screen+Shot+2025-07-14+at+11.30.47+PM.png)

#### 3단계: SEO 히트맵 확인하기

1. 리포트가 열리면 왼쪽 사이드바에서 **SEO Analysis**(SEO 분석) 탭을 클릭하세요.
2. 아래로 스크롤해 키워드 성과가 표시된 **히트맵**을 확인하세요.
3. 지도의 각 점은 주변의 서로 다른 위치에서 검색했을 때의 로컬 검색 결과를 나타내요.
4. 가운데 점은 업체가 있는 바로 주변 지역을 나타내요.
5. 설정한 키워드의 순위가 표시돼요. 예를 들어 “내 주변 법률 사무소” 같은 키워드예요.
6. 상위 3개 로컬 경쟁업체도 함께 표시돼요.

## 활용 팁

- SEO 히트맵을 정기적으로 확인해 검색 순위가 어떻게 바뀌는지 살펴보세요.
- 노출이 낮은 지역의 순위를 높이는 데 이 데이터를 활용하세요.
- 히트맵에서 얻은 인사이트를 다른 SEO 도구와 함께 활용하면 전략을 다듬고 온라인 입지를 넓히는 데 도움이 돼요.
