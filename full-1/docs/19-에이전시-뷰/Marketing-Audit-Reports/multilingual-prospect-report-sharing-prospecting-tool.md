# 마케팅 감사 리포트를 다국어로 공유하기 (잠재고객 발굴)

잠재 고객이 원하는 언어로 마케팅 감사 리포트를 보내면 신뢰를 쌓는 데 도움이 돼요. 이 문서에서는 공유할 때 리포트 언어를 고르는 방법과, 리포트를 받은 사람이 직접 언어를 바꾸는 방법을 안내해요.

## 다국어 잠재고객 리포트 공유란?

다국어 잠재고객 리포트 공유는 잠재고객 발굴 도구에서 만든 마케팅 감사 리포트의 웹 버전을 여러 언어로 보여 주는 기능이에요. 에이전시와 서브 계정 모두 링크를 만들 때나 이메일·SMS로 보낼 때 언어를 고를 수 있어요. 받는 사람도 리포트 페이지의 드롭다운에서 언어를 바꿀 수 있어요.

영어를 쓰지 않는 잠재 고객도 내용을 더 쉽게 이해하고 관심을 가질 수 있어요. 에이전시와 서브 계정 어느 쪽에서든 사용할 수 있어요.

{% hint style="info" %}
다국어 잠재고객 리포트 공유는 웹 리포트에서만 쓸 수 있어요. PDF로 내보낸 파일에는 적용되지 않아요.
{% endhint %}

## 이럴 때 도움이 돼요

다국어 리포트가 잠재고객 영업 과정의 어느 단계에 맞는지 판단할 때 참고하세요.

- 빠른 이해: 잠재 고객이 핵심 내용을 자기 언어로 읽을 수 있어서 헷갈리거나 다시 물어보는 일이 줄어요.
- 높은 전환율: 현지 언어로 된 리포트는 신뢰도를 높이고 응답률을 올려 줘요.
- 유연한 공유: 공유할 때 언어를 고르고, 받는 사람이 필요하면 페이지에서 직접 바꿀 수도 있어요.
- 채널 상관없이 사용 가능: 이메일이나 SMS로 보낸 링크는 내가 고른 언어로 열려요.
- 문의 감소: 영어를 쓰지 않는 잠재 고객의 확인 요청이 줄어서 영업팀과 지원팀의 시간이 절약돼요.

## 지원 언어

어떤 언어를 쓸 수 있는지 알면 특정 시장에 맞춰 아웃리치를 계획하고, 고객이나 영업팀과 기대치를 맞추기 쉬워요. 지원 언어는 다음과 같아요.

- 영어
- 독일어
- 스페인어
- 프랑스어
- 프랑스어(캐나다)
- 이탈리아어
- 네덜란드어
- 덴마크어
- 노르웨이어
- 핀란드어
- 스웨덴어
- 포르투갈어(브라질)
- 포르투갈어(포르투갈)

## 공유할 때 언어 선택하기

공유하기 전에 언어를 고르면 받는 사람이 처음부터 알맞은 언어의 웹 리포트를 볼 수 있어요. 받는 사람이 나중에 언어를 바꾸는 것도 가능해요.

1. **마케팅 > 잠재고객 발굴**로 이동해 해당 잠재 고객의 마케팅 감사 리포트를 찾거나 새로 만들어요.
2. **Share Report**(리포트 공유)를 클릭해요.
3. 보낼 방법으로 **이메일**, **SMS**, **링크 공유** 중 하나를 선택해요.
4. **언어 선택**에서 받는 사람이 처음 볼 언어를 골라요.
5. 발송 정보를 입력하고 리포트를 보내거나, 링크를 복사해서 공유해요.

## 받는 사람이 직접 언어 바꾸기

받는 사람이 웹 리포트에서 직접 언어를 바꿀 수 있어서, 팀원마다 선호하는 언어가 달라도 편하게 볼 수 있어요.

1. 공유받은 웹 리포트 링크를 열어요.
2. 페이지 오른쪽 위의 드롭다운에서 언어를 선택해요.
3. 리포트가 선택한 언어로 바로 바뀌어요.

![리포트 페이지 오른쪽 위의 언어 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053908162/original/7ayjUHRp5m665j400ia_g42VzHbu_oIO8Q.png?1758061110)

## 자주 묻는 질문

### PDF로 내보낸 파일에서도 다국어가 적용되나요?
아직은 아니에요. 현재 다국어 지원은 웹 리포트에만 적용돼요. PDF의 다국어 지원은 계획 중이에요.

### 링크를 이미 보낸 뒤에도 언어를 바꿀 수 있나요?
받는 사람이 공개 리포트의 언어 드롭다운에서 직접 언어를 바꿀 수 있어요. 새 링크를 만들 필요는 없어요.

### 리포트의 어떤 부분이 번역되나요?
시스템 레이블과 화면 문구가 해당 언어로 바뀌어요. 이름, 주소, 직접 쓴 메모처럼 내가 입력한 비즈니스 데이터는 입력한 그대로 보여요.

### 이메일이나 SMS 메시지도 자동으로 번역되나요?
아니요. 리포트만 해당 언어로 바뀌고, 이메일·SMS 본문은 번역되지 않아요. 받는 사람이 선호하는 언어로 직접 작성하세요.

### 에이전시와 서브 계정 모두에서 쓸 수 있나요?
네. 어느 쪽에서 공유하든 리포트 언어를 선택할 수 있어요.

### 받는 사람이 어떤 언어를 쓰는지 잘 모르겠어요. 어떻게 하나요?
공유할 때 가장 가능성이 높은 언어를 고르세요. 받는 사람이 리포트 페이지에서 언어를 바꿀 수 있다는 점도 함께 알려 주세요.
