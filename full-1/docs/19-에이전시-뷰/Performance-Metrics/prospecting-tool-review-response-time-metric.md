# 잠재고객 발굴 도구: 리뷰 응답 시간 지표 추가

**잠재고객 발굴 도구**의 마케팅 감사 리포트에서 잠재고객의 평균 리뷰 응답 시간을 확인할 수 있어요. 리뷰에 답글이 달린 경우 응답 시간을 계산해 리포트에 보여 줘요.

[동영상](https://www.youtube.com/embed/xqlpCFn1h8Q?&wmode=opaque)

## 새로운 소식

**잠재고객 발굴 도구**가 개선되었어요. 답글이 달린 리뷰의 응답 시간을 계산해서 감사 리포트에 표시해 줘요.

## 주요 기능

이제 **잠재고객 발굴 도구**의 감사 리포트에 **Average Review Response Time**(평균 리뷰 응답 시간) 지표가 포함돼요. 잠재고객이 Google과 Facebook에서 받은 리뷰가 대상이에요. 이 정보는 마케팅 감사 리포트 안에 함께 들어가므로, 잠재고객이 리뷰를 어떻게 관리하는지 한눈에 파악할 수 있어요.

## 사용자에게 좋은 점

1. 에이전시는 잠재고객이 이미 리뷰 응답 자동화를 갖추고 있는지 확인할 수 있어요.
2. 에이전시는 이 데이터를 마케팅·영업 과정에서 강력한 셀링 포인트로 활용해 자사의 솔루션이나 서비스를 제안할 수 있어요.

{% hint style="info" %}
- 이전에 추가한 잠재고객은 리포트를 새로고침하면 이 정보를 확인할 수 있어요.
- 마케팅 감사 리포트에서 확인할 수 있는 정보가 그만큼 늘어났어요.
{% endhint %}
