# 템플릿 라이브러리 – 마켓플레이스 연동

템플릿 라이브러리 마켓플레이스 연동을 쓰면 하이퍼클래스 안에서 템플릿을 찾고, 미리 보고, 설치하고, 판매까지 할 수 있어요. 무료·유료 템플릿을 둘러보고 플랫폼을 벗어나지 않고 설치할 수 있으며, 마켓플레이스 도구로 내 템플릿을 판매할 수도 있어요.

## 템플릿 라이브러리 마켓플레이스 연동이란?

템플릿 라이브러리 마켓플레이스 연동은 **템플릿 라이브러리**와 **하이퍼클래스 마켓플레이스**를 이어 줘요. 한곳에서 템플릿을 찾고, 미리 보고, 설치하고, 판매할 수 있어요. 마켓플레이스 템플릿을 **템플릿 라이브러리**에서 바로 열 수 있어서, 둘러보다가 설치까지 빠르게 이어져요. 알맞은 템플릿을 고르고, 쓰기 전에 살펴보고, 템플릿 판매도 하이퍼클래스 안에서 관리할 수 있어요.

## 주요 장점

- 한곳에서 찾기: **템플릿 라이브러리**에서 마켓플레이스 템플릿을 바로 둘러볼 수 있어요.
- 빠른 설정: 하이퍼클래스를 떠나지 않고 템플릿을 설치할 수 있어요.
- 다양한 선택지: 무료·유료 템플릿을 한곳에서 볼 수 있어요.
- 판매 수익: 내 템플릿을 마켓플레이스에 등록해 판매할 수 있어요.
- 간단한 작업 흐름: 미리보기, 구매, 설치, 관리를 연결된 화면에서 할 수 있어요.

## 템플릿 미리 보고 설치하기

1. **에이전시 보기**의 **템플릿 라이브러리**로 이동하세요.
2. **마켓플레이스**를 클릭하세요.
3. 템플릿을 둘러보거나 **검색**과 **필터**를 사용하세요.
4. 템플릿의 미리보기를 여세요.
5. 템플릿 상세 내용과 지원 정보를 확인하세요.

   ![템플릿 미리보기에서 상세 정보를 확인하는 화면](https://jumpshare.com/share/HxEsF5CSUvnwPlvHP3cb+/GIF+Recording+2026-07-20+at+20.25.20.gif)
6. 유료 템플릿이라면 요금제를 선택하세요.
7. **확인**을 클릭하고 안내에 따라 마무리하세요.

   ![설치를 확인하는 화면](https://jumpshare.com/share/cKWDgRYTHtBq1kxlFS06+/IeC8b42uyfphaaxZ_mYq07Pc2sCdlXS_CA.jpeg)

## 마켓플레이스에서 템플릿 판매하기

마켓플레이스에서 템플릿을 판매하면 내 작업물을 직접 배포하고 수익을 낼 수 있어요. 판매 절차를 시작하면 템플릿 정보가 마켓플레이스 셀러 포털로 넘어가고, 나머지 등록 정보만 채우면 돼요.

1. 에이전시 계정에 로그인한 뒤 **템플릿 라이브러리**를 클릭하세요.

   ![템플릿 라이브러리 화면](https://jumpshare.com/share/uqo4KLlwqx8uE58chBwC+/Screen+Shot+2026-06-29+at+19.54.09.png)
2. **+ 템플릿 만들기**를 클릭하세요.
3. 템플릿을 만들 서브 계정을 선택하세요.
4. **상품 유형**을 선택하세요.
5. **템플릿 선택**에서 템플릿을 고른 뒤 **Continue**(계속)를 클릭하세요.

   ![템플릿을 선택하고 계속하는 화면](https://jumpshare.com/share/EIzOn2qOypMHTZt5qOpc+/GIF+Recording+2026-06-29+at+20.07.15.gif)
6. **템플릿 이름 변경** 창에서 이름을 입력하고 **만들기**를 클릭하세요.

   ![템플릿 이름을 변경하는 화면](https://jumpshare.com/share/H5EhN9CsaWoH2Zp5ihAE+/Screen+Shot+2026-06-29+at+20.13.38.png)
7. **템플릿 수정** 화면의 **정보**를 편집한 뒤 **저장**을 클릭하세요.

   ![템플릿 정보를 편집하는 화면](https://jumpshare.com/share/bZOOYMiGa4CzUYnThGHo+/Screen+Shot+2026-06-29+at+20.16.58.png)
8. 템플릿 미리보기에서 점 세 개 메뉴를 클릭하세요.
9. **Sell Template On The Marketplace**(마켓플레이스에서 템플릿 판매)를 선택하세요.
10. 확인 창에서 **셀러 포털로 이동**을 클릭하세요.
11. 마켓플레이스 등록에 필요한 정보를 입력하세요.
12. 검토를 위해 템플릿을 **제출**하세요.

    ![검토를 위해 템플릿을 제출하는 화면](https://jumpshare.com/share/VukgOIVXvreP7gk4gMK1+/GIF+Recording+2026-07-20+at+20.19.23.gif)

## 마켓플레이스 셀러 포털 설정

셀러 포털 설정을 마치면 구매자가 구매·설치 전에 알아야 할 정보가 템플릿 등록에 모두 담겨요. 등록 정보, 지원 세부 정보, 가격을 정확히 적어 두면 구매자가 헷갈리지 않고 더 편하게 이용할 수 있어요.

### 템플릿 등록 정보

템플릿 등록 정보는 구매자가 템플릿에 무엇이 들어 있고 어떻게 쓰는지 이해하는 데 도움이 돼요. 등록 정보를 잘 채워 두면 마켓플레이스에서 템플릿이 더 잘 검색돼요.

셀러 포털에서 다음 정보를 입력하거나 확인하세요.

- 템플릿 링크
- **템플릿 이름**
- 소개 정보
- 사전 준비 사항
- 템플릿 설명
- **상품 유형**
- 템플릿 카테고리
- **태그**
- 템플릿 유형
- 맞춤 설정 정보
- 커버 이미지

![템플릿 등록 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074516930/original/X0q3posEYtBcMZ6OxCTExs3oX9P8plai7g.png?1782403675)

### 지원 세부 정보

지원 정보는 구매자가 판매자에게 어떻게 연락하고, 설치나 구매 후 어떤 도움을 받을 수 있는지 알려 줘요. 지원 정보가 분명하면 구매자의 신뢰가 높아지고 구매 후 불편이 줄어요.

다음 지원 정보를 입력하거나 확인하세요.

- **지원 이메일**
- **문서 URL**
- **지원 웹사이트 URL**
- **지원 전화번호**
- **이용약관 URL**
- **개인정보처리방침 URL**

![지원 세부 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074517243/original/k6aRR4SinrLfXKWC1WDfgrTXxTvZMG87rA.png?1782403791)

구매자는 템플릿을 설치하기 전에 템플릿 상세 정보 패널에서 지원 정보를 볼 수도 있어요.

![템플릿 상세 정보 패널에서 지원 정보를 보는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074517586/original/vo5MixFW7CMfbxTYVZOKi9fJctpYtxw0OA.png?1782403914)

### 가격 정보

가격 설정은 유료 템플릿이 설치 단계에서 구매자에게 어떻게 보일지 정해요. 요금제 이름과 가격 정보가 분명하면 구매자가 무엇을 사는지 알고 진행할 수 있어요.

가격을 설정할 때 다음 정보를 입력하세요.

- 가격 유형
- 금액
- 요금제 이름
- 요금제 기능(선택)

![가격 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074517692/original/VNPoAHujscP8Fuvj1labJJyC7bdgMF_I2g.png?1782403997)

## 자주 묻는 질문

### 템플릿 결제는 일회성인가요, 정기 결제인가요?
템플릿은 일회성 결제로 제공돼요. 한 번 구매하면 추가 요금 없이 템플릿을 쓸 수 있어요.

### 템플릿을 설치하면 어떻게 되나요?
설치한 템플릿은 **내 템플릿**에서 볼 수 있어요. 편집한 뒤 빌더에서 사용할 수 있어요.

### 템플릿을 등록한 뒤에도 업데이트할 수 있나요?
네. 템플릿을 새로 고치고, **What's New**(새로운 소식) 섹션으로 사용자에게 변경 내용을 알릴 수 있어요.

### 템플릿 라이브러리에서 무료 템플릿과 유료 템플릿을 모두 설치할 수 있나요?
네. **마켓플레이스**에서 무료·유료 템플릿을 둘러보고, 필요한 설치 또는 구매 절차를 마치면 돼요.

### 설치하기 전에 마켓플레이스 템플릿을 필터로 거를 수 있나요?
네. 가격, 설치 상태 같은 항목으로 템플릿을 좁혀 볼 수 있어요.

### 설치한 템플릿은 어디에서 볼 수 있나요?
해당 빌더의 **내 템플릿**에서 볼 수 있어요.

### 템플릿을 검토에 제출하기 전에 어떤 정보를 준비해야 하나요?
필수 등록 정보와 지원 세부정보를 입력해야 해요. 유료 템플릿이라면 가격 정보도 입력해야 해요.

### 구매자가 설치하기 전에 판매자의 지원 정보를 볼 수 있나요?
네. 템플릿 상세 화면에서 지원 세부정보를 볼 수 있어요.
