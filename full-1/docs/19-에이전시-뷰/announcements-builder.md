# 공지 빌더로 인앱 배너 만들기

공지 빌더(Announcements Builder)로 중요한 업데이트, 프로모션, 온보딩 안내 같은 메시지를 인앱 배너로 만들 수 있어요. 배너가 나타날 위치, 볼 수 있는 사용자, 표시 시간, 작업 버튼 포함 여부를 직접 정해요.

이 문서에서는 공지 빌더가 하는 일과 에이전시·계정 수준으로 공개 범위를 설정하는 방법을 안내해요.

## 공지 빌더란?

공지 빌더는 하이퍼클래스 안에 표시되는 알림 배너를 만드는 기능이에요. 공지마다 텍스트, 공개 범위, 일정, 오디언스, 선택 사항인 작업 버튼을 설정할 수 있어요.

상세 필터를 쓰면 지원되는 속성을 기준으로 특정 사용자나 서브 계정으로 오디언스를 더 좁힐 수 있어요.

## 공지 만들기

1. **에이전시 보기**에서 **설정 > 공지**로 이동하세요.
2. 오른쪽 위의 **+ Add Custom Announcement**(+ 커스텀 공지 추가)를 클릭하세요.

   ![공지 목록에서 커스텀 공지 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082671655/original/sWTB8RbCulNXuZiUusFX8h7mk7Jac18SFA.png?1791304149)
3. 공지 이름을 입력하세요.
4. **콘텐츠** 탭에서 공지 이름과 본문 텍스트를 입력하세요. 그런 다음 **우선순위**를 고르세요. 필요하면 **작업 버튼**, **버튼 텍스트**, **Action**(동작), **URL**을 설정해 버튼을 추가하세요.

   ![콘텐츠 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082671702/original/lvsNqmeWCxlCoyK4x1Ofs9Zv-LelGZPqjw.png?1791304185)
5. **스타일** 탭을 열고 색상 설정으로 배너 모양을 꾸미세요. **배경 색상**, **Text color**(텍스트 색상), **버튼 배경**, **Button text color**(버튼 텍스트 색상)을 설정할 수 있어요.

   ![스타일 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082671768/original/T_psxMgOKGe_2OzuR3gDNXxaZGhgjCt9zA.png?1791304214)
6. **오디언스** 탭을 열고 공지가 나타날 수준을 고르세요. **Agency Level**(에이전시 레벨), **Account Level**(계정 레벨), **Both**(둘 다) 중에서 선택해요. 오디언스를 더 좁히려면 **상세 필터**를 사용하세요.

   ![오디언스 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082671805/original/h5ErBeGKF8N2Nrmuj6UR8Nw47Ph3WfDadA.png?1791304245)
7. **일정** 탭을 열고 공지를 표시할 시기를 설정하세요.

   ![일정 탭 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082671851/original/62pHX9yQWvDF54pUsmsuWnTZvLZDn3P36w.png?1791304272)
8. 공지 내용과 미리보기를 확인하세요. **Draft**(초안)와 **게시** 중에서 고른 뒤 **저장**을 클릭하세요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

{% hint style="info" %}
하이퍼클래스 도움말에서는 배너 관리를 **에이전시 설정** 안에서 다루며, 에이전시 쪽에서 인앱 배너를 관리하는 용도라고 안내해요. 관련 설정에 접근할 수 있는지는 에이전시 역할과 권한에 따라 다를 수 있어요. 접근 권한 관리를 더 자세히 알고 싶다면 하이퍼클래스의 사용자 접근 및 권한 문서를 확인하세요.
{% endhint %}

## 배너 콘텐츠와 기본 설정

배너 내용이 분명하면 공지를 이해하기 쉽고 사용자의 행동도 이끌어 내기 쉬워요. 핵심 요소를 명확하게 정해 두면 서브 계정 전반에서 메시지를 간결하고 일관되게 유지할 수 있어요.

공지를 만들 때 다음 기본 항목을 설정하세요.

- **제목**: 공지가 무엇에 관한 것인지 알려 주는 짧은 헤드라인
- **메시지 내용**: 업데이트, 알림, 필요한 조치를 설명하는 본문 텍스트
- **우선순위**: 배너 수준을 **심각**, **Warning**(경고), **일반** 중에서 선택
- **빈도 설정**: 대상 사용자에게 배너를 얼마나 자주 보여 줄지 선택
- **상태**: 준비 중에는 **Draft**(초안)로 저장하고, 표시할 준비가 되면 **Active**(활성)로 변경

## 공개 범위와 오디언스

공개 범위를 알맞게 정하면 불필요한 안내를 줄이면서 꼭 필요한 사용자에게만 소식을 전할 수 있어요. 공지가 에이전시 사용자에게만, 서브 계정에만, 또는 양쪽 모두에 해당할 때 특히 중요해요.

공지 빌더에서는 다음 범위로 배너를 표시할 수 있어요.

- **Agency Level**: 에이전시 화면에서 일하는 사용자에게 보여 줄 공지일 때 사용해요.
- **Account Level**: 서브 계정 사용자에게 보여 줄 공지일 때 사용해요.
- **Both**: 에이전시와 계정 화면 모두에 해당하는 메시지일 때 사용해요.

### 상세 필터

더 정확하게 대상을 정하려면 **상세 필터**를 사용하세요. 특정 조건을 만족할 때만 배너가 표시돼요. 필터 항목은 두 가지로 나뉘어요.

**사용자 항목:** **Email**(이메일), **First name**(이름), **Last name**(성), **User**(사용자, 검색), **Role**(역할), **플랫폼 언어**, **Type**(유형)

**서브 계정 항목:** **Sub-account**(서브 계정, 검색), **상태**, **Suspended reason**(정지 사유), **Address**(주소), **City**(도시), **Country**(국가), **Currency**(통화), **State**(주/도), **Postal code**(우편번호), **Phone**(전화번호), **웹사이트**, **Timezone**(시간대), **Locale**(로케일), **Niche**(업종), **HIPAA compliance**(HIPAA 준수), **Agency account**(에이전시 계정), **하이퍼클래스 이메일 보유**, **하이퍼클래스 이메일 영구 잠금**, **SaaS mode**(SaaS 모드), **스냅샷**

조건은 다음 규칙으로 결합돼요.

- 같은 필터 그룹 안의 조건은 AND로 결합돼요. 배너가 표시되려면 모두 참이어야 해요.
- **+ Add filter**(+ 필터 추가)를 클릭하면 새 그룹이 만들어져요. 그룹끼리는 OR로 결합돼요. 어느 한 그룹의 조건만 맞아도 배너가 표시돼요.

*예: "서브 계정이 [이름]이다" AND "국가가 Australia 중 하나이다" — OR — "하이퍼클래스 이메일 보유가 True이다"*

## 공지 일정 설정

일정을 설정하면 소식을 미리 계획하고, 배너가 표시되는 시기를 자동으로 조절할 수 있어요. 프로모션, 점검 안내, 온보딩 안내, 정책 알림, 기간 한정 소식에 쓰면 좋아요.

일정 설정으로 다음을 정해요.

- **시작일**: 공지가 표시 대상이 되는 날짜
- **종료일**: 공지 표시를 멈출 날짜

공지를 공개하거나 내릴 때마다 직접 수정하지 않아도 배너 표시 기간을 관리할 수 있어요.

## 작업 버튼과 리디렉션 동작

작업 버튼(CTA)을 넣으면 공지가 일방적인 안내에서 다음 행동으로 이어지는 안내가 돼요. 사용자가 페이지를 열거나, 기능을 살펴보거나, 설정 작업을 마치거나, 자세한 정보를 읽어야 할 때 유용해요.

공지에는 선택 사항으로 작업 버튼을 넣을 수 있고, 다음 항목을 설정해요.

- **버튼 텍스트**
- **대상 URL**
- 리디렉션 동작

배너가 사용자를 특정 페이지, 자료, 워크플로우로 안내해야 할 때 작업 버튼을 사용하세요. 대상은 공지 내용과 관련 있는 곳으로 정해야 사용자가 바로 행동할 수 있어요.

리디렉션 동작에서는 **새 탭에서 열기**를 선택할 수 있어요. 연결된 페이지가 따로 열리므로 사용자는 플랫폼에 그대로 머물러요.

## 우선순위와 표시 빈도

우선순위와 빈도를 설정하면 배너가 보이는 방식을 의도에 맞게 관리할 수 있어요. 한꺼번에 여러 배너가 활성 상태일 때 특히 유용해요. 중요한 메시지가 덜 급한 메시지에 묻히지 않아요.

우선순위로 공지를 중요도별로 나눠요.

- **심각**: 긴급하거나 영향이 큰 공지에 적합해요.
- **Warning**(경고): 눈에 띄어야 하지만 심각 수준만큼 급하지는 않은 중요한 알림에 적합해요.
- **일반**: 일반적인 안내 메시지에 적합해요.

## 자주 묻는 질문

### 공지 빌더와 인앱 배너 관리는 어떻게 다른가요?
공지 빌더는 공지를 만들고 설정하는 기능이에요. 인앱 배너 관리는 에이전시와 연결된 서브 계정 전체의 인앱 배너를 검토하고, 우선순위를 정하고, 켜고 끄는 에이전시 수준의 영역이라고 문서에 나와 있어요.

### 공지를 게시하기 전에 저장해 둘 수 있나요?
네. 공지는 **Draft**(초안)와 **Active**(활성) 상태를 지원해요. 먼저 저장해 두었다가 준비되면 공개할 수 있어요.

### 공지를 미리 예약할 수 있나요?
네. **시작일**과 **종료일**로 공지를 예약할 수 있어요. 배너가 표시될 수 있는 기간을 정하는 데 도움이 돼요.

### 공지에 버튼을 넣을 수 있나요?
네. 선택 사항으로 작업 버튼을 넣을 수 있어요. 대상 URL과 리디렉션 동작을 설정해요.

### 공지를 에이전시와 서브 계정 화면 모두에 표시할 수 있나요?
네. 배너 공개 범위를 에이전시 레벨, 계정 레벨, 또는 둘 다로 설정할 수 있어요.

### 여러 배너가 동시에 활성 상태이면 어떻게 되나요?
우선순위 설정이 표시 방식을 정하는 데 쓰여요. **심각**, **Warning**(경고), **일반**으로 긴급도와 중요도에 따라 메시지를 나눠 보세요.

### 하이퍼클래스에서 공지는 누가 관리하면 좋나요?
커뮤니케이션과 플랫폼 운영을 맡은 에이전시 쪽 사용자가 관리하는 것이 좋아요. 하이퍼클래스 도움말은 관련 배너 관리 설정을 **에이전시 설정**에 두고 있고, 접근은 보통 에이전시 역할과 권한에 따라 정해져요.

### 특정 서브 계정이나 사용자에게만 배너를 보여 줄 수 있나요?
네. **오디언스** 탭의 **상세 필터**로 서브 계정이나 사용자 속성을 기준으로 조건을 만들 수 있어요. 같은 그룹 안의 조건은 AND로 결합하고, 새 그룹을 추가하면 OR 조건이 돼요.

### 작업 버튼을 눌렀을 때 링크가 새 탭에서 열리게 할 수 있나요?
네. 작업 버튼의 리디렉션 동작을 설정할 때 **새 탭에서 열기**를 선택하면 하이퍼클래스를 벗어나지 않고 외부 페이지로 안내할 수 있어요.
