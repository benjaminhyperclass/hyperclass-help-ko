# 전화 연동에서 서브 계정 필터로 찾기

**전화 연동**의 **서브 계정 설정**에서 필터를 쓰면 전화 시스템, 리빌링 상태, 메시지 설정, A2P 인증 상태에 따라 서브 계정을 빠르게 찾을 수 있어요. 에이전시 소유자와 관리자가 쓸 수 있고, 계정을 하나씩 열어 보지 않아도 확인이 필요한 서브 계정을 쉽게 골라낼 수 있어요.

## 서브 계정 설정 필터란?

서브 계정 설정 필터는 **전화 연동**에 표시되는 서브 계정 목록을 전화·메시지 설정 기준으로 좁혀 주는 기능이에요. 서브 계정을 하나씩 열지 않고도 특정 설정을 가진 계정을 찾을 수 있어요.

필터는 **에이전시 보기 > 설정 > 전화 연동 > 서브 계정 설정**에서 쓸 수 있어요. **필터** 패널에서는 다음 기준으로 서브 계정을 찾을 수 있어요.

- 전화 시스템 제공업체
- 리빌링 상태
- 번호 인텔리전스 설정
- 메시징 램프
- 전화번호 보유 여부
- A2P 인증 상태

처음에는 모든 필터 옵션이 선택되어 있어서 서브 계정 전체 목록이 표시돼요. 기준을 바꿔 결과를 좁히거나, 여러 필터를 조합해 더 세밀하게 찾을 수 있어요. **필터 초기화**를 누르면 기본 화면으로 돌아가요.

---

## 서브 계정 설정 필터의 장점

여러 서브 계정의 전화·메시지 설정을 관리하다 보면 확인할 일이 자주 생겨요. 필터를 쓰면 조건에 맞는 계정을 더 빨리 찾아서 설정을 관리하고, 문제가 될 만한 계정을 확인하고, 계정 업데이트를 계획할 수 있어요.

- **빠른 계정 찾기:** 서브 계정을 하나씩 확인하지 않아도 특정 전화 설정을 가진 계정을 찾을 수 있어요.
- **전화 관리 간소화:** **기본 전화 시스템**, Twilio, 타사 설정을 쓰는 서브 계정을 한눈에 구분할 수 있어요.
- **리빌링 점검 용이:** 해당 에이전시 플랜을 쓰는 경우 리빌링이 켜져 있거나 꺼져 있는 서브 계정을 찾을 수 있어요.
- **메시지 현황 파악:** **번호 인텔리전스**와 **메시징 램프** 설정 기준으로 계정을 구분할 수 있어요.
- **A2P 상태 점검 간소화:** A2P 인증 상태를 기준으로 서브 계정을 찾아 추가로 확인할 수 있어요.
- **유연한 필터링:** 업무에 맞게 여러 필터 기준을 조합해 결과를 좁힐 수 있어요.
- **효율적인 계정 점검:** 에이전시의 서브 계정 전반에서 전화번호 보유 여부와 메시지 설정을 살펴볼 수 있어요.

---

## 필터 항목 살펴보기

**필터** 패널은 서브 계정을 전화 시스템과 메시지 관련 속성별로 묶어 보여 줘요. 각 항목이 무엇을 뜻하는지 알아 두면 계정 점검, 전환 준비, 일상 관리에 맞는 기준을 고르기 쉬워요.

| 필터 항목 | 선택 옵션 | 설명 |
| --- | --- | --- |
| **관리자** | **기본 전화 시스템**, Twilio, None / Third Party(없음 / 타사) | 서브 계정에 연결된 전화 시스템을 구분해요. |
| **Rebilling Status**(리빌링 상태) | Enabled(활성화), Disabled(비활성화) | 서브 계정의 리빌링이 켜져 있는지 구분해요. 해당 에이전시 플랜에서만 보여요. |
| **번호 인텔리전스** | Enabled(활성화), Disabled(비활성화) | 서브 계정에서 번호 인텔리전스가 켜져 있는지 구분해요. |
| **메시징 램프** | Yes(예), **아니오** | 서브 계정의 메시징 램프 상태를 기준으로 구분해요. |
| **전화번호 보유** | Yes(예), **아니오** | 서브 계정에 전화번호가 있는지 구분해요. |
| **A2P 인증됨** | Yes(예), **아니오** | 서브 계정의 A2P 인증 여부를 기준으로 구분해요. |

{% hint style="info" %}
필터는 특정 설정을 가진 서브 계정을 찾는 데 쓰는 기능이에요. 필터로 해당 설정을 직접 켜거나 끄거나 바꿀 수는 없어요.
{% endhint %}

## 전화 시스템 (관리자)

**관리자** 필터를 쓰면 서브 계정마다 어떤 전화 시스템이 연결되어 있는지 알 수 있어요. 전화 제공업체 설정을 점검하거나 전화 시스템 전환을 준비하기 전에 대상 계정을 찾을 때 특히 유용해요.

제공업체 설정과 전환 시 알아 둘 점은 [하이퍼클래스의 에이전시 관리형 Twilio 및 전화 리빌링](../16-SaaS-설정/what-is-agency-managed-twilio-and-phone-rebilling-in-hyperclass.md) 문서를 참고하세요.

## 리빌링 상태 필터와 이용 가능한 플랜

**Rebilling Status** 필터를 쓰면 전화 리빌링이 켜져 있거나 꺼져 있는 서브 계정을 찾을 수 있어요. 계정을 하나씩 열지 않고도 여러 서브 계정의 결제 설정을 점검할 수 있어요.

**이용 가능한 플랜**

**Rebilling Status** 필터는 아래 플랜을 쓰는 에이전시에서만 보여요.

- $297 에이전시 플랜
- $497 에이전시 플랜

다른 플랜을 쓰는 에이전시는 **필터** 패널에서 **Rebilling Status** 항목이 보이지 않아요.

{% hint style="warning" %}
**Rebilling Status** 필터를 쓸 수 있는지와 전화 리빌링을 설정하기 위한 요건은 별개예요. 필터는 현재 상태를 확인할 뿐 리빌링 설정을 바꾸지 않아요.
{% endhint %}

자세한 내용은 [SaaS 모드 활성화, 결제 요청, 전화 리빌링 설정](../16-SaaS-설정/Saas-Mode/activate-saas-mode-request-payment-and-configure-phone-rebilling.md) 문서를 참고하세요.

## 번호 인텔리전스와 메시징 램프 필터

**번호 인텔리전스**와 **메시징 램프**는 전화·메시지 운영의 서로 다른 부분에 영향을 주는 설정이에요. 이 기준으로 필터링하면 각 기능을 쓰는 서브 계정을 찾을 수 있고, 추가로 설정을 확인해야 할 계정도 가려낼 수 있어요.

자세한 내용은 [번호 인텔리전스 — 번호 유효성 검사, 스팸 탐지, 발신자 불명 처리](../15-전화-시스템/number-intelligence-spam-detection-caller-id-sms-validation.md) 문서를 참고하세요.

### 메시징 램프

**메시징 램프**는 레벨 기반 메시징 시스템이에요. 계정이 메시지 활동 레벨을 올라가는 동안 SMS 발송 한도를 관리하도록 만들어졌어요.

예를 들어 메시지 설정을 점검하는 에이전시는 **메시징 램프**와 **번호 인텔리전스**를 함께 선택해 특정 메시지 설정을 가진 서브 계정을 찾을 수 있어요.

자세한 내용은 [메시징 램프 진행 카드](../15-전화-시스템/메시징/messaging-ramp-progress-card.md) 문서를 참고하세요.

## 전화번호 보유 및 A2P 인증 필터

전화번호 보유 여부와 A2P 인증 상태는 서브 계정이 통화와 메시지를 보낼 준비가 되었는지 살펴볼 때 중요한 기준이에요. 이 필터로 전화 설정이나 인증 확인이 더 필요한 계정을 찾을 수 있어요.

{% hint style="warning" %}
**A2P 인증됨** 필터는 점검이 필요한 계정을 찾는 데 유용해요. 메시지를 보내기 전에 해당하는 등록, 캠페인, 전화번호 요건을 확인하는 일을 대신해 주지는 않아요.
{% endhint %}

자세한 안내는 [미국 전화번호 등록](../15-전화-시스템/A2P-등록/what-is-a2p-10-dlc-brand-and-campaign-registration.md) 문서를 참고하세요.

## 전화 연동에서 서브 계정 필터링하기

**필터** 패널은 에이전시 보기의 **서브 계정 설정** 탭 안에 있어요. 알맞은 기준을 선택하면 원하는 전화·메시지 설정을 가진 서브 계정을 찾을 수 있고, 실제 설정은 그대로 유지돼요.

### 1단계: 에이전시 보기에서 전화 연동 열기

1. 하이퍼클래스 에이전시 계정에 로그인해요.
2. 필요하면 **에이전시 보기로 전환**을 선택해 **에이전시 보기**로 이동해요.
3. **설정**으로 이동해요.
4. **전화 연동**을 선택해요.
5. **서브 계정 설정** 탭을 열어요.

**Phone Settings for Sub-Accounts**(서브 계정별 전화 설정) 표에 에이전시의 서브 계정과 각 계정의 전화 설정이 표시돼요.

### 2단계: 필터 패널 열기

![필터 버튼이 표시된 서브 계정 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082861874/original/qsS0xK1UEMjG_CdRQ1HkNvcQ5R2aUJoqEA.png?1791468723)

1. **Phone Settings for Sub-Accounts** 표 오른쪽 위에서 **필터** 버튼을 찾아요.
2. **필터**를 클릭해 필터 패널을 열어요.
3. 선택할 수 있는 필터 항목을 확인해요.

처음에는 모든 필터 옵션이 선택되어 있어서 서브 계정 전체 목록이 그대로 보여요. **Rebilling Status** 항목은 해당하는 $297, $497 플랜을 쓰는 에이전시에게만 표시돼요.

### 3단계: 필터 기준 선택하기

1. 사용할 필터 항목을 찾아요.
2. 보고 싶은 서브 계정에 맞는 값을 선택해요.
3. 바뀐 서브 계정 목록을 확인해요.

예를 들어 Twilio를 쓰는 서브 계정을 찾으려면 **관리자** 항목에서 **Twilio**를 선택하고, 나머지 필터 선택은 필요에 맞게 조정하세요. 필터 기준을 바꾸면 서브 계정 목록이 자동으로 바뀌어요.

![관리자 항목에서 Twilio를 선택한 필터 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082875048/original/UU5v-NJq3eAv9iF-P2YoVfxGTeQ6JCx7gQ.png?1791474601)

### 4단계: 여러 필터 기준 조합하기

1. **필터** 패널을 열어 둔 채로 유지해요.
2. 다른 필터 항목에서 기준을 더 선택해요.
3. 선택한 기준이 바뀔 때마다 목록이 어떻게 달라지는지 확인해요.
4. 결과를 더 좁히려면 선택을 조정해요.

예를 들어 특정 전화 시스템 설정을 쓰는 계정의 메시지 준비 상태를 점검할 때는 **관리자**, **번호 인텔리전스**, **A2P 인증됨** 필터를 함께 쓸 수 있어요.

### 5단계: 필터를 초기화해 전체 목록으로 돌아가기

1. **필터** 패널이 닫혀 있으면 열어요.
2. **필터 초기화**를 찾아요.
3. **필터 초기화**를 클릭해요.

![필터 초기화 버튼이 표시된 필터 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082875099/original/CW5CLz3nN8HDdZnyZXJsZfi1-6vPRwRNgQ.png?1791474661)

모든 필터 옵션이 기본으로 선택된 상태로 돌아가고, 서브 계정 전체 목록이 다시 표시돼요.

{% hint style="info" %}
**필터 초기화**를 누르면 모든 옵션이 해제되는 것이 아니라 기본 선택 상태로 돌아가요.
{% endhint %}

## 자주 묻는 질문

### 서브 계정 설정 필터로 전화 설정을 바꿀 수 있나요?
아니요. 필터는 설정을 기준으로 서브 계정을 찾는 기능이에요. 실제 전화 시스템이나 메시지 설정을 바꾸려면 해당 설정 화면에서 변경해야 해요.

### Rebilling Status 필터가 보이지 않아요.
**Rebilling Status** 필터는 $297, $497 플랜을 쓰는 에이전시에게만 제공돼요. 다른 플랜을 쓰는 에이전시에는 이 항목이 보이지 않아요.

### 필터를 직접 저장하거나 적용해야 하나요?
아니요. 별도로 적용하는 동작은 안내되어 있지 않아요. 필터 기준을 바꾸면 서브 계정 목록이 바로 갱신돼요.

### A2P 인증이 필요할 수 있는 계정을 필터로 찾을 수 있나요?
네. **A2P 인증됨**에서 **아니오**를 선택하면 인증된 것으로 표시되지 않은 서브 계정을 찾을 수 있어요. 다음 조치를 정하기 전에 해당하는 A2P 등록과 캠페인 내용을 꼭 확인하세요.

### 기본 전화 시스템으로 옮길 계정을 필터로 찾을 수 있나요?
네. **관리자** 필터에서 Twilio를 쓰거나 None / Third Party(없음 / 타사)로 분류된 서브 계정을 찾을 수 있어요. 다만 전환이 가능한지와 필요한 요건은 변경하기 전에 따로 확인해야 해요.

### 필터를 초기화하면 서브 계정의 설정이 바뀌나요?
아니요. **필터 초기화**는 필터 선택을 기본 상태로 되돌리고 서브 계정 전체 목록을 보여 줄 뿐이에요. 각 서브 계정의 전화·메시지 설정은 바뀌지 않아요.

### 필터로 SMS를 보낼 준비가 된 계정인지 알 수 있나요?
필터로 **메시징 램프**, A2P 인증, 전화번호 보유 여부 같은 메시지 관련 속성을 살펴볼 수 있어요. 하지만 이 결과만으로 계정이 메시지를 보낼 준비가 되었다고 판단할 수는 없어요. 추가로 등록, 설정, 메시지 관련 요건이 적용될 수 있어요.

### 전화번호가 없는 서브 계정을 필터로 찾을 수 있나요?
네. **전화번호 보유**에서 **아니오**를 선택하면 전화번호가 없는 것으로 분류된 서브 계정을 찾을 수 있어요. 찾은 계정에서 전화 설정이 더 필요한지 확인해 보세요.
