# 잠재고객 발굴: 카테고리로 잠재고객 분류하기

**잠재고객 발굴**에 **Prospect Categories**(잠재고객 카테고리) 기능이 새로 생겼어요. 카테고리를 직접 만들어 잠재고객에게 지정하고, 카테고리별로 걸러서 볼 수 있어요.

[동영상](https://www.youtube.com/embed/sGLQTBhFihU?&wmode=opaque)

잠재고객 목록이 점점 늘어나도 더 쉽게 정리하고 관리할 수 있어요. 비슷한 잠재고객을 묶거나, 우선순위가 높은 리드에 표시하거나, 일괄 업데이트를 간편하게 할 수 있어요. 특히 리드를 많이 다루는 에이전시에 도움이 돼요.

## 새로운 소식

**잠재고객 발굴**에서 잠재고객용 카테고리를 추가하고 관리할 수 있게 됐어요. 새 카테고리를 만들고, 잠재고객에 지정하고, 같은 카테고리로 잠재고객을 걸러서 볼 수 있어요.

## 주요 기능

- **잠재고객 발굴** 안에서 사용자 지정 카테고리를 새로 만들 수 있어요.
- 만든 카테고리를 잠재고객에게 지정하면 각 잠재고객을 구분하기 쉬워요.
- 특정 카테고리가 지정된 잠재고객만 찾아주는 필터가 추가됐어요.
- 여러 잠재고객을 한꺼번에 분류할 수도 있어서, 기존 고객에게도 쉽게 적용할 수 있어요.

## 에이전시에 좋은 점

- 잠재고객이 늘어날수록 효과적으로 관리하기 어려워져요.
- 카테고리를 쓰면 여러 잠재고객을 묶거나, 특정 잠재고객을 따로 구분할 수 있어요.
- 우선순위, 세부 시장(니치), 사용자 유형, 업종 등 다양한 기준으로 활용할 수 있어요.
