# 대량 잠재고객 발굴(Bulk Prospecting)으로 여러 리드 한 번에 저장하기

Google Maps에서 지역 업체를 한꺼번에 찾아 평가하고, 여러 곳을 한 번에 저장하는 기능이에요. 키워드, 위치("near me" 포함), 반경으로 검색하면 한 번에 최대 60개의 리드를 볼 수 있어요. 중복 여부는 자동으로 확인되고, 한 번에 최대 15개까지 저장할 수 있어요. 이 문서에서는 검색 방법, 화면 구성 바꾸기, 저장 후 영업 활동을 시작하는 방법을 안내해요.

## 대량 잠재고객 발굴이란?

하이퍼클래스의 **잠재고객 발굴** 도구에서 Google Maps 업체를 찾아 저장하는 과정을 더 편하게 만든 기능이에요. 한 번에 더 많은 결과를 보고, 여러 행을 선택해 저장하고, 중복을 확인하고, 결과 화면을 내 방식대로 꾸릴 수 있어요. 스프레드시트나 복사·붙여넣기 없이도 잠재고객 발굴 규모를 키울 수 있어요.

## 주요 이점

각 이점을 알아 두면 영업 과정 중 어디에 이 기능을 쓰면 좋을지 판단하기 쉬워요.

- **더 정교한 검색 조건:** 업종이나 브랜드를 키워드로 검색하고, 위치(주소 또는 "near me")와 반경(최대 약 30마일/49km)을 함께 지정해 결과를 좁힐 수 있어요.
- **더 많은 결과:** 한 번의 검색으로 최대 60개의 리드를 볼 수 있어요. 이 상한은 Google이 정한 거예요. 기존의 20개 제한보다 훨씬 넓게 찾을 수 있어요.
- **한 번에 여러 개 저장:** 한 번에 최대 15개까지 선택해 추가할 수 있어요. 페이지를 넘겨도 선택이 유지돼서 적은 클릭으로 더 많이 담을 수 있어요.
- **중복 확인 기능:** **상태** 열에서 이미 저장된 잠재고객인지 확인할 수 있어서 같은 작업을 반복하지 않아도 돼요.
- **우선순위 정렬:** **Prospect Score**(잠재고객 점수), Google 평점, 웹사이트/GBP 여부로 정렬해서 가치가 높은 리드부터 볼 수 있어요.
- **화면 사용자 지정:** 필요한 열만 고르고 페이지당 행 수를 정해서 더 빠르게 훑어볼 수 있어요.

## 더 정교한 검색

검색 조건에 따라 결과가 달라져요. 키워드, 위치, 반경을 알맞게 맞추면 관련성 높은 업체만 볼 수 있어서 훑어보는 시간이 줄어요.

- **키워드 / 사업자명:** 업종(예: "치과", "지붕공사업체")이나 특정 브랜드(예: "KFC")를 입력해요.
- **위치:** 전체 주소, 도시, 우편번호를 입력하거나 `near me`를 입력하면 IP 기반 위치 정보를 사용해요. VPN이나 공유 사무실 IP를 쓰면 정확도가 떨어질 수 있어요.
- **반경:** 검색 범위를 최대 약 30마일(49km)까지 지정해요. 반경을 넓히면 결과는 늘지만 지역 관련성은 낮아질 수 있어요.

## 확장된 검색 결과

한 번의 검색으로 더 많은 업체를 찾을 수 있어서, 같은 검색을 여러 번 반복하지 않아도 돼요.

- **검색 한 번에 최대 60개 리드.** 더 필요하면 키워드나 위치를 바꿔 다시 검색하세요.
- **지도 + 표 보기:** 지도로 위치를 파악하면서 목록도 빠르게 훑어볼 수 있어요.
- **상태 표시:** 결과가 저장되었거나 처리 중이면 상태가 표시돼요.

![지도와 표로 보는 검색 결과](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055131413/original/Z-iYzSes_q63DIlxxfTu64eEUULm2ntu3Q.png?1759436187)

## 여러 개 선택해서 저장하기

여러 행을 한 번에 선택해 저장하면 클릭이 줄고 목록을 더 빨리 만들 수 있어요. 한도와 선택 유지 방식을 알아 두면 작업 계획을 세우기 쉬워요.

- **한 번에 최대 15개 행을 선택**하고 **Add Multiple Prospects**(여러 잠재고객 추가)를 클릭하면 한꺼번에 저장돼요.
- **페이지를 넘겨도 선택이 유지돼요.** 결과를 넘겨 보면서 행을 선택한 뒤 한 번에 저장할 수 있어요.
- 현재 페이지에서는 **전체 선택** / **전체 선택 해제**를 사용하면 더 빠르게 작업할 수 있어요. 이 컨트롤은 현재 페이지에만 적용되기 때문에, 다른 페이지의 선택이 실수로 모두 해제되는 일을 피할 수 있어요.

![여러 행을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055131069/original/hadOJPP2B5IRd6ROVTVEwfMYZ6I2einR-w.png?1759435686)

## 정렬과 필터

정렬과 필터를 쓰면 가치가 높은 잠재고객을 먼저 확인하고, 영업하기 좋은 업체를 빠르게 찾을 수 있어요.

- **Prospect Score**, **온라인 존재감**/GBP, **웹사이트**(예/**아니오**), Google 평점/리뷰 기준으로 정렬할 수 있어요.
- **열 관리** 옆의 **필터** 아이콘을 클릭하면 조건에 맞는 잠재고객만 골라 볼 수 있어요.

![정렬과 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055131142/original/Lu6OZVk6jtjTDtLzr_gveRK37lCB2z-VYA.png?1759435810)

## 검색 화면 사용자 지정

열과 한 페이지에 보이는 행 수를 내게 맞게 바꾸면, 한 번에 많은 리드를 검토할 때 더 깔끔하고 빠르게 작업할 수 있어요.

- **열 관리**를 클릭하면 **Prospect Score**, **온라인 존재감**, **웹사이트**, **상태** 같은 열을 표시하거나 숨기고 순서를 바꿀 수 있어요.
- **페이지당 행 수**는 5, 10, 15 중에서 고를 수 있어요. 처리 속도와 가독성에 맞게 선택하세요.

![열 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055130842/original/KkGy1x-dOGq3XBKkt51WRcyC0l2-7yLv0g.png?1759435228)

## 중복 확인과 상태

상태 표시를 보면 중복 저장을 피하고, 저장 후 진행 상황도 알 수 있어요.

- **Not Added**(추가 안 됨): 아직 저장하지 않은 잠재고객이에요.
- **추가됨**: 이전에 저장했거나 방금 추가된 잠재고객이에요.
- **Generating Prospect (xx%)**(잠재고객 생성 중): 시스템이 해당 기록과 마케팅 감사를 준비하고 있어요. 퍼센트는 처리 진행률이에요.
- **상태** 열과 **보기** 버튼으로 해당 업체가 이미 저장되어 있는지 확인할 수 있어서 중복 추가를 막을 수 있어요.

![상태 열 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055131846/original/hn8nuwfJrrMBiWMfHuNQewDWn-_UwtdFOA.png?1759436606)

## 저장한 잠재고객은 어디에 있나요?

저장된 기록이 어디에 있는지 알면 팀이 데이터를 찾느라 시간을 쓰지 않고 바로 영업과 추적을 시작할 수 있어요.

- 저장한 기록은 **Prospect Accounts**(잠재고객 계정, 에이전시 보기)에 표시돼요. 서브 계정에서 작업하는 경우에는 **마케팅 > 잠재고객 발굴**에 표시되고, **잠재고객 발굴** 도구에서 확인할 수 있어요.
- **Prospecting Premium**(잠재고객 발굴 프리미엄)을 켜고 서브 계정에 연결해 두었다면, 그 서브 계정에 일치하는 **연락처**가 만들어져요. 이 연락처로 자동화와 영업 활동을 진행할 수 있어요.
- 잠재고객 행(또는 잠재고객 프로필)에서 **Marketing Audit Report**(마케팅 감사 리포트)를 열면 웹사이트/GBP 성과를 확인하고 다음 단계를 계획할 수 있어요.

![저장된 잠재고객 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055132230/original/VTeYdnp2LN-Ej0ZGO43TCiOvM-FY0RaqnQ.png?1759437819)

{% hint style="info" %}
팁: 연락처가 만들어지면 서브 계정에서 육성 캠페인을 시작해 보세요. "잠재고객 발굴 도구로 만든 리드에게 연락하는 방법(How to Reach Out to Prospect Leads Generated via the Prospecting Tool)" 문서를 참고하세요.
{% endhint %}

## 대량 잠재고객 발굴 사용 방법

아래 순서를 따라 첫 검색을 실행하고, 결과를 살펴본 뒤, 여러 잠재고객을 한 번에 저장해 보세요.

### 1단계: 서브 계정에서 **마케팅 > 잠재고객 발굴**로 이동한 뒤 **Add Prospect**(잠재고객 추가)를 클릭하세요.

![잠재고객 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055132370/original/9N0kz28YEIFa9Aqm_7Vyne3pfHrdSCrpkw.png?1759438288)

### 2단계: **키워드 / 사업자명**에 업종이나 브랜드(예: Dominos)를 입력하세요. **위치**에 도시나 우편번호를 입력하고 **반경**(최대 약 30마일/49km)을 정한 뒤 **검색**을 클릭하세요.

![검색 조건을 입력한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055132415/original/PT0gz_iY6BaycJ405NPgVG14RFFeJ7gviA.png?1759438385)

### 3단계: 결과 목록과 지도를 확인하세요. 열 머리글을 클릭하면 Prospect Score, 웹사이트, 평점 기준으로 정렬할 수 있어요.

![결과 목록과 지도](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055132467/original/curO4Ef9Q63gN5QPgc6pi7_k29sHrvn8xg.png?1759438495)

{% hint style="info" %}
팁: **열 관리**를 클릭해 열을 표시하거나 숨길 수 있어요. **페이지당 행 수**를 15로 설정하면 더 빠르게 묶어서 저장할 수 있어요.
{% endhint %}

### 4단계: 행을 최대 15개까지 선택하세요. 페이지를 넘겨도 선택은 유지돼요.

![행을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055132545/original/kdX0XmGnC8zlyHzz43bld6uh7UAJmlqC1A.png?1759438688)

### 5단계: **Add Multiple Prospects**(여러 잠재고객 추가)를 클릭하세요.

![여러 잠재고객 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055132568/original/eneWFZnqLxnmnZFPl2nZ9s8FOZz_NFNJ5g.png?1759438749)

{% hint style="warning" %}
중요: **상태** 열에서 **Generating Prospect (xx%)**가 표시되다가 **추가됨**으로 바뀌는지 확인하세요. **보기**를 클릭하면 해당 기록과 Marketing Audit Report를 열 수 있어요. 또 Prospecting Premium을 서브 계정에 연결해서 쓰고 있다면 **연락처**를 열어 동기화가 되었는지 확인하고 영업 워크플로우를 시작하세요.
{% endhint %}

{% hint style="info" %}
팁:

1. 60개 상한에 도달했다면 반경을 넓히거나, 키워드를 바꾸거나("roofer"와 "roofing contractor"처럼), 중심 위치를 옮겨 새 지역을 검색해 보세요.
2. "near me" 결과가 이상하면 VPN과 위치 설정을 확인하거나 위치를 직접 입력하세요.
{% endhint %}

## 자주 묻는 질문

### 검색 한 번에 왜 최대 60개 결과만 보이나요?
이 상한은 Google이 정한 거예요. 키워드나 위치를 바꿔 추가로 검색하면 더 넓게 찾을 수 있어요.

### 한 번에 몇 개까지 저장할 수 있나요?
한 번에 최대 15개까지 저장할 수 있어요. 추가하기 전까지는 페이지를 넘겨도 선택이 유지돼요.

### "Generating Prospect (xx%)"는 무슨 뜻인가요?
하이퍼클래스가 잠재고객 기록을 만들고 마케팅 감사를 준비하고 있다는 뜻이에요. 완료되면 **추가됨**으로 바뀌어요.

### 중복 확인은 어떻게 작동하나요?
이미 내 계정에 저장된 업체라면 **상태**에 **추가됨**이 표시돼요. 다시 추가하지 말고 **보기**를 클릭해 기존 기록을 여세요.

### 웹사이트가 없는 업체만 걸러서 볼 수 있나요?
네. **웹사이트** 열 기준으로 정렬하거나 필터링한 뒤, **아니오**로 표시된 업체에 영업을 집중하세요.

### 보이는 열은 어디서 바꾸나요?
**열 관리**를 클릭하면 Prospect Score, 온라인 존재감, 웹사이트, 상태 같은 열을 표시하거나 숨기고 순서를 바꿀 수 있어요.

### "near me"는 항상 내 정확한 위치를 사용하나요?
아니요. IP 기반 위치 정보를 사용해서 VPN이나 사무실 네트워크 경로의 영향을 받을 수 있어요. 정확한 위치가 중요하면 위치를 직접 입력하세요.
