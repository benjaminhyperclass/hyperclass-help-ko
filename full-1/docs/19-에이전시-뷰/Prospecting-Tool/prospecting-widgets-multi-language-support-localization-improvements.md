# 잠재고객 발굴 위젯의 다국어 지원

잠재고객 발굴 위젯이 이제 여러 언어를 완전히 지원해요. 필드 레이블, 유효성 검사 메시지, 제출 버튼, 이메일, PDF 리포트 링크 같은 시스템 문구가 사용자가 쓰는 플랫폼 언어에 맞게 자동으로 바뀌어요. 그래서 웹사이트에 삽입한 위젯, 이메일, 내보낸 리포트에서 같은 언어로 일관되게 보여요.

## 개요

잠재고객 발굴 도구 전반에서 현지화(i18n) 지원을 강화했어요.

이전에는 백엔드에서 만들어지는 일부 문구가 사용자의 언어 설정에 따라 바뀌지 않았어요. 이번 업데이트로 달라진 점은 다음과 같아요.

- 잠재고객 발굴 위젯이 방문자가 선호하는 플랫폼 언어로 표시돼요.
- 이메일이 사용자의 언어 설정을 따라요.
- PDF 리포트 링크와 내보낸 콘텐츠가 플랫폼 언어 설정을 따라요.
- 따로 설정할 필요가 없어요.

고객에게 보이는 모든 화면에서 다국어가 일관되게 동작해요.

## 잠재고객 발굴 위젯 열기

에이전시 관리자만 쓸 수 있어요. 아래 경로로 이동하세요.

**Agency View**(에이전시 뷰) > **잠재고객 발굴** > **위젯**

여기에서 위젯을 만들고 관리할 수 있어요.

![잠재고객 발굴 위젯 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064814687/original/PawKpUsQ2loETU0h17F4Q_TaAexiEgrm2A.jpeg?1770920759)

## 업그레이드 필요 사항

잠재고객 발굴 위젯은 잠재고객 발굴 도구의 유료 버전에서 쓸 수 있어요.

계정을 업그레이드하지 않았다면 업그레이드 안내가 표시돼요.

![업그레이드 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064814688/original/VY2h0HRG2zmSQjdHE4nexMOrd3lL9bcC2g.jpeg?1770920759)

## 위젯 만들기와 사용자 지정

업그레이드한 뒤에는 다음 순서로 진행하세요.

1. **위젯 만들기**를 클릭하세요.
2. 필드를 설정하세요.
3. 스타일과 브랜딩을 조정하세요.
4. 위젯을 저장하세요.

![위젯 만들기와 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064814685/original/qhAeagPKuWEGbgWhK2Hs9twkJqXSRShYDA.jpeg?1770920758)

## 테마 사용자 지정

위젯은 라이트 테마와 다크 테마를 지원해요.

![위젯 테마 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064814686/original/TkgZ9TQfE_onIqI7xDSsqQBO7VRaXKF3pw.jpeg?1770920759)

## 다국어 지원

잠재고객 발굴 위젯이 이제 여러 언어를 완전히 지원해요.

시스템이 만들어 내는 모든 문구는 사용자가 선호하는 플랫폼 언어에 맞게 자동으로 바뀌어요.

적용되는 문구는 다음과 같아요.

- 필드 레이블
- 유효성 검사 메시지
- 시스템 안내 문구
- 제출 버튼 텍스트
- 오류 메시지
- 확인 메시지

번역을 직접 설정할 필요는 없어요.

## 위젯을 웹사이트에 삽입하기

1. 위젯 안의 **설정** 탭으로 이동하세요.
2. 삽입 코드를 복사하세요.
3. 웹사이트 백엔드에 붙여넣으세요.

![위젯 삽입 코드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064814684/original/quLJyQfDfNRN9i5ycN2uIPqyBmNDLxr4EA.jpeg?1770920758)

삽입한 뒤에는 다음을 확인하세요.

- 위젯이 제대로 로드되는지
- 레이아웃이 알맞게 표시되는지
- 모든 필드가 기대한 대로 동작하는지

## 워크플로우와 자동화

잠재고객이 위젯을 제출하면 다음과 같이 처리돼요.

- 연락처가 자동으로 저장돼요.
- 리드에 태그가 지정돼요.
- 워크플로우를 실행할 수 있어요.

![위젯 제출 후 워크플로우 연결 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064814690/original/ppCD79tKN9ZXaa3QZ43ORN4Bs55lNyaPrA.jpeg?1770920759)

이를 활용하면 다음을 자동화할 수 있어요.

- 환영 이메일
- 파이프라인 배정
- 육성(너처링) 시퀀스

## PDF 리포트 언어 적용

내보낸 PDF 리포트도 사용자가 선호하는 플랫폼 언어로 표시돼요.

적용되는 항목은 다음과 같아요.

- 리포트 버튼
- 링크 레이블
- 시스템이 만든 문구
- 내보내기 안내 문구

![PDF 리포트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064814689/original/cygW_XGzUqgQOfn_f_y6tgYaojQ1vwv5vw.jpeg?1770920759)

## 이메일의 언어 지원

잠재고객 발굴 위젯과 관련해 시스템이 보내는 이메일은 이제 받는 사람의 플랫폼 언어에 맞게 자동으로 바뀌어요.

적용되는 항목은 다음과 같아요.

- 제목
- 행동 유도(CTA) 버튼
- 시스템 안내 문구

따로 설정할 필요는 없어요.

## 자주 묻는 질문

### 위젯에서 여러 언어를 직접 켜야 하나요?
아니요. 위젯은 플랫폼 언어에 맞게 자동으로 바뀌어요.

### 제가 직접 입력한 텍스트도 바뀌나요?
아니요. 시스템이 만든 문구만 현지화돼요.

### 이메일 알림도 이제 다국어로 오나요?
네. 시스템이 보내는 이메일은 사용자가 선호하는 플랫폼 언어를 따라요.

### 내보낸 PDF 리포트도 언어가 자동으로 바뀌나요?
네. PDF 리포트 링크와 시스템 문구가 플랫폼 언어 설정을 따라요.

### 잠재고객 발굴 도구를 업그레이드해야 하나요?
네. 위젯은 유료 버전에서 쓸 수 있어요.
