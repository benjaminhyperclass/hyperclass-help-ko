# 잠재고객 발굴 리포트 섹션 선택하고 순서 바꾸기

**잠재고객 발굴**(Prospecting)에서 만든 리포트에 어떤 섹션을 넣을지 고르고, 섹션 순서를 원하는 대로 바꿀 수 있어요. 리포트 구성을 직접 정하고 싶을 때 쓰세요.

## 주요 기능

- **원하는 섹션만 선택**: 리포트에 넣을 섹션을 직접 고를 수 있어요. 보는 사람에게 꼭 필요한 정보만 보여 줄 수 있어요.
- **쉬운 순서 변경**: 드래그 앤 드롭으로 섹션 순서를 바꿀 수 있어요. 전달하려는 내용과 목적에 맞게 흐름을 정해 보세요.
- **세부 맞춤 설정**: 핵심 지표와 인사이트를 앞쪽에 배치해서, 이해관계자가 중요한 내용을 먼저 파악하게 할 수 있어요.
- **간편한 리포트 작성**: 원하는 구조로 리포트를 짜면 시간을 아끼고 내용도 더 또렷하게 전달할 수 있어요. 발표나 논의 자리에서도 도움이 돼요.

## 리포트 섹션 선택하고 순서 바꾸기

1. **잠재고객 발굴** 탭으로 이동하세요.
2. 원하는 잠재고객을 클릭한 뒤 **View Report**(리포트 보기)로 이동하세요.
3. **섹션** 옵션에서 리포트에 넣을 섹션을 선택하고 순서를 바꾸세요.
4. **적용**을 클릭하면 변경 내용이 저장되어 리포트에 반영돼요.

{% hint style="info" %}
변경 내용은 외부 리포트와 PDF에 모두 적용돼요.
{% endhint %}

## 이런 점이 좋아요

이 기능을 쓰면 목표와 우선순위에 맞는 섹션을 앞세워 리포트를 구성할 수 있어요. 고객, 이해관계자, 팀 누구에게 발표하든 데이터를 한눈에 이해하기 쉽게 보여 줄 수 있어요.
