# 서브 계정에 여러 Facebook 페이지 연결하기

하나의 서브 계정에 Facebook 페이지를 여러 개 연결할 수 있어요. 이 문서에서는 새로 쓸 수 있게 된 기능과 아직 지원하지 않는 기능, 페이지가 목록에 보이지 않을 때 확인할 내용을 안내해요.

[동영상](https://www.youtube.com/embed/vlO\_UxAqfRM?&wmode=opaque)

## 새로 추가된 기능

- 리드 동기화: 여러 페이지의 Facebook Lead Ads에서 들어온 리드를 자동으로 동기화해요. 어느 페이지에서 왔는지 출처도 분명하게 확인할 수 있어요.
- 대화: Facebook과 Instagram 채팅 연동으로 여러 Facebook 페이지의 고객과 대화할 수 있어요.
- 자동화: 여러 Facebook 페이지에서 이뤄지는 고객 소통을 워크플로우로 자동화할 수 있어요.
- 평판: 여러 Facebook 페이지의 리뷰와 리뷰 답변을 한곳에서 관리할 수 있어요.

## 이 기능이 중요한 이유

이 기능은 Canny에서 800표 이상을 받은, 연동 기능 중 가장 요청이 많았던 기능이에요. 여러 매장을 운영하는 소규모 사업자부터 여러 팬 페이지를 운영하는 인플루언서까지, 다양한 상황에서 쓸 수 있어요.

## 출시 예정

- 모바일 앱: 하이퍼클래스 모바일 앱은 아직 여러 Facebook 페이지의 대화를 지원하지 않아요.
- **대화 AI**: 대화 AI는 아직 여러 Facebook 페이지로 들어온 메시지에 자동으로 응답하지 않아요.

## 문제 해결: Facebook 페이지가 보이지 않아요

연결하려는 Facebook 페이지가 설정 중 목록에 나타나지 않는다면 대개 권한이나 접근 문제 때문이에요.

{% hint style="warning" %}
중요: Facebook 페이지는 연결한 Facebook 사용자 계정의 권한에 따라 표시돼요. 하이퍼클래스는 Facebook Business Manager나 광고 계정에 직접 연결되지 않아요.
{% endhint %}

아래 내용을 확인해 보세요.

- Facebook 페이지의 관리자 권한이 있는지 확인하세요. 편집자 권한이나 일부 권한만으로는 부족해요.
- 연결하려는 Facebook 프로필로 올바르게 로그인했는지 확인하세요.
- 연결 단계에서 요청하는 권한을 모두 허용했는지 확인하세요.
- 최근에 접근 권한이 바뀌었다면 **설정 > 연동**에서 Facebook 연결을 해제한 뒤 다시 연결해 보세요.

하이퍼클래스 권한, Business Manager 설정, 리드 접근 문제까지 포함한 자세한 단계별 안내는 [Facebook 멀티 페이지 문제 해결](../기타/facebook-multi-page-troubleshoot.md) 문서를 참고하세요.
