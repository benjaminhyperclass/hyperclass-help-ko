# 개편된 연동 페이지 안내

연동 페이지가 카드 형태의 새 화면으로 바뀌었어요. 더 빠르고 깔끔해져서 연동을 연결하고, 관리하고, 문제를 해결하기 쉬워요. 이 문서에서 달라진 점과 쓰는 방법을 확인해 보세요.

이번 개편으로 모든 연동의 화면 구성이 같아졌고, 연동이 늘어나도 일관되게 쓸 수 있어요. 달라진 점을 알아 두면 작업 흐름을 정리하고 시스템 성능을 높이는 데 도움이 돼요.

## 개편된 연동 페이지란?

개편된 연동 페이지는 연동을 찾고, 연결하고, 관리하는 일을 한곳에 모은 새 화면이에요. 기존 레이아웃 대신 카드 형태로 정리해서 사용성, 일관성, 성능이 좋아졌고 앞으로 연동이 늘어나도 대응하기 쉬워요.

모든 연동이 같은 디자인과 같은 사용 방식을 따르기 때문에 화면을 둘러보고, 계정을 관리하고, 문제를 해결할 때 헷갈리지 않아요. 동작도 통일되고 오류 처리도 나아졌으며, 페이지가 열리는 속도도 빨라졌어요.

## 개편된 연동 페이지의 장점

새 화면은 사용성, 성능, 일관성에 초점을 맞췄어요. 덕분에 연동을 더 효율적이고 안정적으로 관리할 수 있어요.

- **사용 경험 개선:** 카드 형태의 깔끔한 레이아웃이라 연동을 훑어보고, 찾고, 관리하기 쉬워요.
- **더 빠른 성능:** 로딩 시간이 줄고 API가 최적화되어 더 매끄럽게 쓸 수 있어요.
- **간단해진 관리:** **Connect**(연결하기)와 **관리** 같은 통일된 동작으로 작업 흐름이 단순해져요.
- **더 나은 가시성:** 오류 표시와 알림으로 문제를 빠르게 찾아 해결할 수 있어요.
- **확장성 강화:** 표준화된 디자인 덕분에 앞으로 연동이 추가되어도 화면이 어긋나지 않아요.
- **보안 강화:** 백엔드가 개선되어 위험은 줄고 시스템 안정성은 높아졌어요.

## 카드 레이아웃과 화면 구성

연동마다 같은 형식의 카드가 보여요. 복잡한 메뉴를 거치지 않아도 쓸 수 있는 동작과 중요한 정보를 바로 확인할 수 있어요.

각 연동 카드에는 다음이 들어 있어요.

- 연동 이름과 로고
- 짧은 설명
- 주요 동작 버튼(**Connect** 또는 **관리**)
- 추가 옵션을 여는 점 3개(⋮) 메뉴

모든 연동의 레이아웃이 똑같이 표준화되어 있어서 어떤 연동이든 같은 방식으로 쓸 수 있어요.

## 주요 동작: Connect와 관리

**Connect**와 **관리**의 차이를 알면 연동 상태에 맞는 동작을 바로 고를 수 있어요.

- **Connect**
  - 연결된 계정이 없을 때 보여요.
  - 새 연동을 연결하는 과정을 시작해요.
- **관리**
  - 이미 연결된 연동에 보여요.
  - 설정 화면으로 이동하거나, 연결된 계정을 관리할 수 있어요.

![Connect와 관리 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070532400/original/5LXYm72H2m_EqdGFtuFdLatZ6h7B84ZxjQ.png?1777906709)

이 버튼은 연동이 이미 설정되어 있는지에 따라 자동으로 바뀌어요.

## 연동 옵션(점 3개 메뉴)

점 3개(⋮) 메뉴에서는 연동별 동작을 빠르게 열 수 있어요. 연동 페이지를 벗어나지 않고도 설정을 관리하고, 문제를 해결하고, 고급 설정을 할 수 있어요.

연동에 따라 다음과 같은 옵션이 나와요.

- 지원 문서
- 폼 매핑
- 문제 해결 도구
- 연결 해제 옵션(계정별 또는 연동별)
- **연동 설정**

## 검색과 탐색

내장된 검색 기능으로 연동을 빠르게 찾을 수 있어요. 연결된 서비스가 많은 계정에서 특히 편리해요.

- 검색창이 페이지 위쪽에 있어요.
- 입력하는 동안 연동 목록이 바로바로 걸러져요.
- 연동 목록을 스크롤하며 찾는 시간이 줄어요.

![연동 검색창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070532595/original/DxYSp14GidUnF7xN_9e1GdJjY3hucBnfXw.png?1777906835)

## 계정 관리(통합 팝업)

통합 계정 관리 팝업에는 한 연동에 연결된 계정이 모두 모여 있어요. 여러 계정을 한곳에서 관리할 수 있어요.

- 연결된 계정을 한 팝업에서 모두 볼 수 있어요.
- 대표 계정을 지정할 수 있어요.
- 계정을 추가로 연결할 수 있어요.
- 계정별 동작(설정, 재연결, 제거)을 할 수 있어요.
- 계정마다 오류 표시를 확인할 수 있어요.

![통합 계정 관리 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070703489/original/O5Re3nZPSW19Ne2fKpzOLW1rK6WeMGBTnA.png?1778070603)

## 폼 매핑과 연동 구성

폼 매핑은 외부 플랫폼의 폼 필드와 CRM 필드를 서로 맞춰 주는 기능이에요. 이렇게 하면 두 곳의 데이터가 정확하게 동기화돼요.

- 사용할 수 있는 폼을 목록으로 볼 수 있어요.
- 토글로 폼을 켜거나 끌 수 있어요.
- **필드 편집**에서 폼 필드를 CRM 필드에 매핑할 수 있어요.
- 팝업 안에서 바로 설정을 저장할 수 있어요.

![폼 매핑 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070703592/original/4y_ZHeRVLaxG-YJLHmW24O-jPUvkHq8hqg.png?1778070635)

## 오류 처리와 알림

오류 처리가 개선되어 복잡한 문제 해결 절차 없이도 문제를 빠르게 찾아 해결할 수 있어요.

- 연결 문제는 시각적 표시로 눈에 띄게 보여요.
- 다음 두 가지 오류를 모두 지원해요.
  - 연결 단위 오류(특정 계정의 문제)
  - 연동 단위 오류(더 넓은 범위의 문제)
- 화면에서 바로 원인을 파악하고 해결할 수 있어요.

## 성능과 안정성 개선

눈에 보이지 않는 부분도 개선되어 연동 페이지의 속도, 안정성, 확장성이 크게 좋아졌어요. 연동이 늘어나도 매끄럽게 쓸 수 있어요.

- 페이지 로딩이 빨라졌어요.
- 시스템 리소스 사용량이 줄었어요.
- 접근성과 사용성이 좋아졌어요.
- API 성능이 더 안정적이에요.
- 모든 연동에서 일관된 경험을 제공해요.

## 자주 묻는 질문

### 이번 업데이트로 기존 연동에 영향이 있나요?
아니요. 기존 연동은 지금처럼 계속 작동해요. 이번 업데이트는 화면과 관리 방식만 개선해요.

### 연동에 오류가 표시되면 어떻게 하나요?
연동 또는 계정 단위로 오류 표시가 나타나요. 이를 보고 계정을 다시 연결하는 등 필요한 조치를 할 수 있어요.

### 연동을 연결 해제하려면 어떻게 하나요?
점 3개(⋮) 메뉴나 계정 관리 팝업에서 연동 전체 또는 개별 계정을 연결 해제할 수 있어요. 안전을 위해 확인 창이 함께 나와요.

### **Connect** 대신 **관리**가 보이는 이유가 뭔가요?
이미 연결된 연동에는 **관리**가 표시돼요. **관리**에서 기존 설정을 구성하거나 업데이트할 수 있어요.

### 한 연동에 계정을 여러 개 연결할 수 있나요?
네, 지원하는 연동이라면 통합 계정 팝업에서 계정을 여러 개 추가하고 관리할 수 있어요.
