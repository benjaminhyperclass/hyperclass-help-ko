# 이메일 오류: 양방향 동기화 권한 부족 해결하기

"Email Failure: Insufficient Permission for 2-Way Sync" 오류가 나올 때 연결한 이메일 계정을 다시 연결해서 해결하는 방법을 안내해요.

이 오류는 하이퍼클래스가 연결된 이메일 계정(Gmail, Outlook 등)에 접근할 권한을 잃었을 때 나타나요. 보통 다음과 같은 경우에 생겨요.

- 이메일 계정의 권한이 해지된 경우
- 이메일 제공업체에서 연결을 다시 승인하라고 요구하는 경우
- 계정의 보안 설정이 바뀐 경우
- 연결된 메일함의 연결이 끊어졌거나 만료된 경우

이메일 계정을 다시 연결하면 필요한 권한이 복구되고, 양방향 이메일 동기화도 정상적으로 작동해요.

---

## 시작하기 전에: 오류 메시지 확인하기

이 문서는 아래 메시지 중 하나가 보일 때만 해당돼요.

- "Email Failure: Insufficient Permission for 2-Way Sync"
- "Insufficient Permission"
- 하이퍼클래스가 연결된 받은편지함에 접근할 권한이 없다는 내용의 오류

아래 오류에는 이 문서가 맞지 않아요.

| 오류 메시지 | 예상 원인 | 권장 조치 |
| --- | --- | --- |
| Insufficient funds to send email(이메일 발송 잔액 부족) | 이메일 발송 크레딧이나 지갑 잔액이 부족해요. | 이메일 크레딧 또는 결제 관련 문서를 참고하세요. |
| 인증 실패 | SMTP 인증 정보가 올바르지 않아요. | SMTP 설정을 확인하세요. |
| Email quota exceeded(이메일 한도 초과) | 발송 한도에 도달했어요. | 이메일 제공업체의 발송 한도를 확인하세요. |
| Domain not verified(도메인 미인증) | 이메일 인증 또는 DNS에 문제가 있어요. | 발송 도메인을 인증하세요. |

{% hint style="warning" %}
"Insufficient funds to send email" 오류라면 권한 문제가 아니에요. 받은편지함을 다시 연결해도 해결되지 않아요. 대신 이메일 크레딧, 지갑 잔액, 결제 설정을 확인하세요.
{% endhint %}

---

## 이 오류가 생기는 이유

하이퍼클래스가 연결된 이메일 제공업체에 대한 승인을 잃으면 이 오류가 나타나요.

주로 다음과 같은 이유예요.

- Google 또는 Microsoft 계정의 권한이 해지됐어요.
- 이메일 계정 비밀번호를 바꿨어요.
- 조직의 보안 정책 때문에 기존 OAuth 토큰이 무효화됐어요.
- 연결된 이메일 계정이 삭제됐거나 연결이 끊어졌어요.
- 보안 업데이트 이후 이메일 제공업체에서 권한을 다시 부여하라고 요구해요.

---

## 해결 방법

### 1단계: 이메일 서비스 열기

1. **설정**으로 이동하세요.
2. **이메일 서비스**를 선택하세요.
3. 연결된 이메일 계정을 찾으세요.

### 2단계: 이메일 계정 다시 연결하기

계정에 오류가 표시되거나 확인이 필요하다고 나오면 아래 순서로 진행하세요.

1. **Reconnect**(다시 연결)를 클릭하세요. 필요하면 메일함을 삭제한 뒤 다시 연결해도 돼요.
2. 올바른 이메일 계정으로 로그인하세요.
3. 요청하는 권한을 확인하세요.
4. **Allow**(허용)를 선택해 하이퍼클래스의 접근을 허용하세요.

{% hint style="info" %}
양방향 이메일 동기화가 제대로 작동하려면 요청하는 권한을 모두 허용해야 해요.
{% endhint %}

### 3단계: 연결 확인하기

다시 연결한 뒤에는 아래 내용을 확인하세요.

- 이메일 계정이 **Connected**(연결됨)로 표시되는지 확인하세요.
- **테스트 이메일 보내기**로 테스트 이메일을 보내 보세요.
- 다음 내용을 확인하세요.
  - 이메일이 정상적으로 발송돼요.
  - 답장이 **대화**에 표시돼요.
  - 이메일 동기화가 다시 정상적으로 작동해요.

### 문제가 계속될 때

계정을 다시 연결해도 해결되지 않으면 아래 방법을 시도해 보세요.

- 메일함 연결을 끊고 한 번 더 다시 연결하세요.
- 올바른 이메일 계정으로 로그인하고 있는지 확인하세요.
- Google Workspace 또는 Microsoft 365 관리자가 서드파티 앱의 권한을 제한하지 않았는지 확인하세요.
- 최근 보안 정책이 바뀌면서 하이퍼클래스의 접근 권한이 사라지지 않았는지 확인하세요.
- 시크릿 모드(프라이빗 브라우저 창)에서 다시 연결해 보세요.

### 위 방법으로도 해결되지 않으면 하이퍼클래스 고객지원에 다음 정보와 함께 문의하세요

- 문제가 생긴 이메일 주소
- 오류 화면 캡처
- 이메일 제공업체(Google Workspace, Gmail, Outlook, Microsoft 365 등)
- 오류가 처음 나타난 대략적인 시간

---

## 자주 묻는 질문

### 다시 연결하면 기존 이메일이 삭제되나요?

아니요. 다시 연결하면 하이퍼클래스와 이메일 제공업체 사이의 승인만 복구돼요. 기존 이메일은 그대로 남아 있어요.

### 전에는 잘 됐는데 왜 갑자기 이 오류가 나오나요?

이메일 제공업체는 비밀번호 변경, 보안 업데이트, 관리자 정책 변경, 권한 해지가 있으면 인증 토큰을 무효화하는 경우가 있어요.

### 이 오류가 이메일 발송과 수신에도 영향을 주나요?

네. 필요한 권한이 없으면 하이퍼클래스에서 이메일을 보내지 못하거나, 받은 메시지를 동기화하지 못하거나, **대화**에 답장이 표시되지 않을 수 있어요.

---

## 다른 오류가 나올 때

오류 메시지가 다르다면 해당하는 문제 해결 문서를 참고하세요.

- Insufficient funds to send email(이메일 발송 잔액 부족) — 이메일 오류: 양방향 동기화 권한 부족 <!-- 검토 필요: 원문 내용이 서로 다름 -->
- SMTP **인증 실패** — SMTP 제공업체 설정하기
- 도메인 **인증 실패** — 이메일 인증 및 DNS 설정

---

## 도움이 더 필요하세요?

위 단계를 모두 진행했는데도 "Insufficient Permission for 2-Way Sync" 오류가 계속 나온다면 하이퍼클래스 고객지원에 문의하세요. 문의할 때 아래 정보를 함께 알려 주세요.

- 오류 메시지 전문
- 사용 중인 이메일 제공업체
- 오류 화면 캡처
- 이미 시도해 본 방법

이 정보를 함께 보내 주시면 문제를 더 빨리 확인할 수 있어요.
