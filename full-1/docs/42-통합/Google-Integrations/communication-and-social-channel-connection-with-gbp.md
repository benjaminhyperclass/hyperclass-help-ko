# Google Business Profile에 메시지·소셜 채널 연결하기

Google Business Profile(GBP) 페이지에 메시지 채널(WhatsApp, 문자/SMS)과 소셜 채널(Facebook, Instagram, LinkedIn, YouTube, TikTok, X, Pinterest)을 연결할 수 있어요. 고객이 익숙한 방법으로 연락할 수 있고, 참여와 리드 확보 경로도 늘어나요.

{% hint style="warning" %}
**중요:** **대화** 메뉴는 하이퍼클래스를 통해 연동한 채널의 메시지만 지원해요.
{% endhint %}

## GBP에 소셜 채널 연결하기

1. 서브 계정 대시보드에서 **설정**을 클릭한 뒤 **연동**으로 이동하세요.
2. GBP 계정을 연결하고 페이지 선택 창으로 이동하세요.

{% hint style="info" %}
**팁:** 페이지 선택 창의 검색 드롭다운에서 **Page Name**(페이지 이름), **Store Code**(매장 코드), **Postal Code**(우편번호), **Locality**(지역)로 GBP 위치를 걸러 볼 수 있어요. 표시되는 위치가 없다면, 해당 GBP 위치에 접근할 수 있는 Google 계정을 연결하세요.
{% endhint %}

[![페이지 선택 창에서 GBP 위치를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058383236/original/4L9ue63Zn9HnKI7KSqhWpYJlGXeAw2vZcA.png?1763117832)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050129431/original/LUP0sRL2-E3CmPS-Uqbv8cJlun0MiKPj5Q.png?1753074330)

3. 메시지 채널을 연결하려면 **WhatsApp** 탭과 **문자 메시지** 탭을 클릭하세요. 또는 **Connect Channels**(채널 연결)를 클릭하세요.

[![WhatsApp 탭과 문자 메시지 탭, 채널 연결 버튼이 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058383239/original/Jd0KMiOkCTB_M89gqxDPHwg0ljpfVsQGEw.png?1763117831)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050129495/original/YsK2Uq_wKJZOANXWPYHqg4p8bZj7gqwqAQ.png?1753074411)

4. 드롭다운에서 하이퍼클래스에 연결된 하이퍼클래스 전화번호와 WhatsApp 번호를 선택하세요. 번호를 직접 입력해서 추가할 수도 있어요. 소셜 채널은 링크를 추가하면 돼요.

[![전화번호와 WhatsApp 번호를 선택하고 소셜 채널 링크를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155058383232/original/KsPdRMPxfRzLuY2pllo9ShUNrdkvwlnlQw.png?1763117831)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050129936/original/oVSNyVya9QVlTM8qePNYlOa3DLn9qdilHg.png?1753074846)

5. **Connect**(연결)를 클릭하세요.

## 연결한 채널은 어떻게 표시되나요?

WhatsApp과 문자 메시지를 둘 다 연결할 수 있지만, GBP 검색 결과에는 메시지 채널이 한 번에 하나만 표시돼요. 소셜 채널은 모두 GBP 페이지 검색 결과의 About 섹션 아래에 표시돼요.

{% hint style="warning" %}
**중요:** WhatsApp과 문자 메시지를 모두 추가하면 GBP 검색 결과에는 문자 메시지가 표시돼요.
{% endhint %}

## 문자/WhatsApp 메시지 옵션이 GBP 검색 결과에 보이지 않아요

문자와 WhatsApp 채널을 추가했는데 GBP 검색 결과에 보이지 않을 수 있어요. 대부분 Google이 추가한 번호를 하나씩 검증하기 때문이에요. 아래 순서로 확인해 보세요.

1. GBP 페이지 설정으로 이동하세요. 하이퍼클래스의 페이지 선택 화면에서 **Update GBP**(GBP 업데이트)를 클릭하거나, Google 콘솔에서 페이지 편집 화면으로 들어가면 돼요.
2. 수정 사항이 승인되었는지 확인하세요. 승인은 Google 팀이 처리하며 하이퍼클래스에서는 관여할 수 없어요. 승인되지 않았다면 Google에 직접 티켓을 등록하세요.
