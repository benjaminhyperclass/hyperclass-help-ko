# 제휴 가입 페이지에서 3DS 카드 인증 문제 해결하기

체험판 가입 중 결제 단계에서 실패한다면 3D Secure(3DS) 인증이 필요한 카드일 수 있어요. 이 문서에서는 3DS 인증을 지원하는 가입 링크로 가입을 완료하는 방법을 안내해요.

## 3D Secure(3DS) 카드 인증 문제란

일부 은행은 온라인에서 카드를 확인할 때 **3D Secure(3DS)** 인증(대개 OTP)을 요구해요. 인도에서 발급한 카드에서 흔히 볼 수 있어요. 체험판 가입 중 결제가 실패했다면 아래의 3DS 지원 가입 방법으로 인증 단계를 진행해 보세요.

## 3DS 지원 가입 링크 이용하기

1. 다음 주소를 열어요: <https://affiliates.gohighlevel.com>
2. 체험판 가입을 시작하고 카드 정보를 입력해요.
3. 안내가 나오면 은행의 **3DS/OTP 인증**을 완료해요.

![3DS 인증 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064182183/original/RZk1EvbEtcU7zWE5Fsdi7AI2m8wP-nBb1A.png?1770211459)

이 가입 방식은 필요할 때 3DS가 실행되도록 만들어졌고, 카드 확인도 안전하게 진행해요.

### 인증이 되면 이렇게 보여요

- 카드에 3DS가 필요하면 은행 인증 단계(OTP 또는 승인)가 나와요.
- 인증을 승인하면 가입이 완료돼요.

### 1달러 승인 요청에 대해

필요할 때 3DS를 실행하고 카드를 확인하기 위해, 가입 과정에서 카드에 **1달러 승인 요청**이 걸릴 수 있어요.

- 요금제나 구독 요금이 **결제된 것이 아니에요**.
- **임시**로 보류된 승인 내역으로 표시될 수 있고, 은행 처리 시간에 따라 사라져요.

### 인증이 계속 실패한다면

- 최신 버전 브라우저로 다시 시도해 보세요.
- 가입 페이지에서는 광고 차단 프로그램을 꺼 보세요.
- 브라우저가 은행 인증 페이지를 막으면 팝업과 리디렉션을 허용해 보세요.
- 은행이 카드 확인을 거절하면 다른 카드로 시도해 보세요.

{% hint style="info" %}
하이퍼클래스는 같은 3DS 지원 환경을 기본 가입 과정에서도 쓸 수 있도록 준비하고 있어요. 그때까지 3DS 관련 오류가 생기면 위의 가입 링크를 이용하세요.
{% endhint %}
