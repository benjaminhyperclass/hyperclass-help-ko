# 하이퍼클래스 랜딩 페이지로 제휴 링크 만들기

하이퍼클래스 랜딩 페이지를 제휴 링크로 만들고 싶을 때 참고하는 문서예요. **제휴 포털**에 이미 준비된 제휴 링크도 함께 안내해요.

{% hint style="info" %}
알림: 현재 **제휴 포털**을 업데이트하는 중이에요. 이 문서의 일부 영상과 이미지가 지금 보이는 화면과 조금 다를 수 있어요.

곧 최신 화면에 맞게 모두 바꿀 예정이에요. 그 전에 궁금한 점이 있으면 담당 [제휴 관리자](https://speakwith.us/affiliate)에게 문의하세요.
{% endhint %}

## 하이퍼클래스 랜딩 페이지를 제휴 링크로 만들고 싶으세요?

<!-- 검토 필요: 원문 안내 영상이 HighLevel 브랜드를 노출할 수 있어 영상 링크를 뺐어요 -->

하이퍼클래스 제휴 파트너로 활동하고 싶다면 하이퍼클래스 고객지원에 문의하세요.

리드 제너레이션 플레이북(Lead-Gen Playbook)에 참여하고 싶다면 하이퍼클래스 고객지원에 문의하세요.

{% hint style="info" %}
**제휴 포털**에는 이미 제휴 링크가 많이 있어요. Pro 플랜 추천 링크도 포함돼 있어요.

**제휴 포털**에 들어가는 방법과 사용법은 [제휴 포털 사용 방법](how-to-use-affiliate-portal.md) 문서를 참고하세요.
{% endhint %}
