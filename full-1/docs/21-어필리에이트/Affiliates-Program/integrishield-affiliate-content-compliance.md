# Integrishield와 제휴 콘텐츠 규정 준수

하이퍼클래스는 규정 준수 소프트웨어 Integrishield와 협력해, 제휴 파트너가 만든 콘텐츠가 하이퍼클래스 제휴 계약과 행동 강령을 지키는지 자동으로 확인해요. 이 문서에서는 확인 결과 이메일을 받았을 때 어떻게 해야 하는지, 어떤 내용이 문제가 될 수 있는지 안내해요.

이 협력은 더 좋은 콘텐츠를 만드는 데 도움이 돼요. 윤리적이고 법을 지키는 제휴 커뮤니티가 계속 성장하도록 돕는 역할도 해요.

## 이메일을 받았다면

`highlevel@integrishield.com` 또는 `legalcompliance@gohgihelvel.com`에서 콘텐츠 관련 이메일이 오면, 영업일 5일 이내에 콘텐츠를 필요한 대로 수정해야 해요.
<!-- 검토 필요: 원문 내용이 서로 다름 (두 번째 이메일 주소가 gohgihelvel.com과 gohighlevel.com으로 다르게 적혀 있음) -->

문의할 내용이 있거나 Integrishield가 콘텐츠를 잘못 지적했다고 생각되면, 받은 이메일에 바로 회신해 주세요. 확인하고 도와 드려요.

{% hint style="info" %}
`highlevel@integrishield.com`과 `legalcompliance@gohighlevel.com`을 연락처에 추가해 두세요. 중요한 알림을 놓치지 않을 수 있어요.
{% endhint %}

## 지적받을 수 있는 경우

다음과 같은 내용이 있으면 콘텐츠가 지적될 수 있어요.

- 하이퍼클래스와의 제휴 관계를 명확하고 눈에 띄게 밝히지 않은 경우
- 하이퍼클래스가 승인하지 않은 할인, 프로모션, 쿠폰 등
- 자극적이거나 선동적인 표현
- 경쟁사와의 비교
- 승인받지 않은 상표 사용
- 승인받지 않은 소프트웨어 성능 주장

{% hint style="warning" %}
이런 경고를 무시하면 제휴 정책에 따라 커미션을 계속 받을 수 없게 될 수 있어요. 이런 일이 생기지 않도록 궁금한 점은 담당 [제휴 관리자](https://speakwith.us/affiliate)에게 바로 문의하세요. 언제든 도와 드려요.
{% endhint %}
