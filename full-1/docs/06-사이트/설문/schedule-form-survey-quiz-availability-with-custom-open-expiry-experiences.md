# 폼·설문·퀴즈 공개 일정 설정과 오픈 전·마감 후 화면 꾸미기

폼, 설문, 퀴즈가 응답을 받는 시작 시각과 마감 시각을 정할 수 있어요. 응답 기간이 아닐 때 방문한 사람에게 보여 줄 페이지나 이동할 URL도 직접 정할 수 있어요.

하이퍼클래스에서는 시작·종료 시각을 지정하고, 하나의 시간대를 일정 전체에 적용해요. 이 문서에서는 일정 옵션, 방문자가 보게 되는 상태, 설정 순서, 활용 사례, 문제 해결 방법을 안내해요.

{% hint style="info" %}
일정 설정은 선택 사항이에요. **Schedule visibility**(공개 일정 설정)를 켜지 않은 기존 폼, 설문, 퀴즈는 지금까지처럼 그대로 동작해요.
{% endhint %}

## 폼·설문·퀴즈의 공개 일정이란?

공개 일정은 폼, 설문, 퀴즈가 응답을 받는 기간을 정하는 기능이에요. 게시한 뒤 나중에 직접 끌 필요 없이, 설정한 일정에 따라 **Not open yet**(아직 오픈 전), **Accepting responses**(응답 받는 중), **종료됨** 순서로 상태가 자동으로 바뀌어요.

오픈 시각 전이나 마감 시각 후에 방문한 사람에게는 직접 만든 페이지를 보여 주거나 다른 URL로 이동시킬 수 있어요. 그래서 이벤트, 프로모션, 웨비나, 콘테스트, 등록 기간처럼 시간이 정해진 캠페인에 같은 폼, 설문, 퀴즈를 맞춰 쓸 수 있어요.

## 공개 일정의 장점

공개 일정을 쓰면 캠페인을 손으로 관리하는 일이 줄고, 응답 기간의 각 단계마다 방문자에게 알맞은 화면을 보여 줄 수 있어요. 정해진 시각에 응답을 시작하거나 끝내야 할 때 특히 유용해요.

- 자동 오픈: 미리 게시해 두면 정해 둔 오픈 시각에 응답을 받기 시작해요.
- 자동 마감: 설정한 마감 시각이 되면 새 응답을 자동으로 받지 않아요.
- 유연한 일정: 바로 열거나 특정 날짜에 열 수 있고, 계속 열어 두거나 특정 시각에 닫을 수 있어요.
- 시간대 지정: 오픈 시각과 마감 시각에 같은 시간대를 적용해요.
- 오픈 전 화면 사용자 지정: 일찍 온 방문자에게 접근 불가 화면 대신 안내 내용을 보여 줘요.
- 마감 후 화면 사용자 지정: 응답이 마감되었음을 알리거나 다음 행동을 안내해요.
- 리디렉션 옵션: 오픈 전이나 마감 후에 다른 URL로 방문자를 보내요.
- 수작업 감소: 캠페인 마감 시각에 누군가 직접 비활성화하지 않아도 돼요.

## 일정 옵션과 상태

일정 설정에 따라 응답을 받는 시점이 정해지고, 현재 어느 단계인지도 확인할 수 있어요. 각 옵션을 알아 두면 의도보다 일찍 열리거나 마감 후에도 응답이 들어오는 실수를 막을 수 있어요.

| 설정 | 옵션 | 동작 |
| --- | --- | --- |
| **오픈** | **Right away**(즉시) | 게시되어 이용할 수 있게 되는 즉시 응답을 받아요. |
| **오픈** | **날짜 선택** | 선택한 날짜와 시각이 될 때까지 기다린 뒤 응답을 받아요. |
| **Closes**(마감) | **없음** | 마감 시각을 정하지 않아요. |
| **Closes**(마감) | **날짜 선택** | 선택한 날짜와 시각이 되면 새 응답을 받지 않아요. |
| **시간대** | 선택한 시간대 | 오픈 시각과 마감 시각 모두에 적용돼요. |

![공개 일정 옵션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080667002/original/NODEGm4pN5ZKhxMtO6XqmwZKyWZoadlnVg.png?1789108576)

### 가용성 타임라인 이해하기

날짜를 설정하면 타임라인이 표시돼요. 타임라인에서 현재 시각이 오픈 전인지, 응답 기간 중인지, 마감 후인지 확인할 수 있어요. 상태는 **Not open yet**, **Accepting responses**, **종료됨** 세 가지예요.

## 오픈 전·마감 후 화면 사용자 지정

일정은 응답을 받을지 말지만 정하지 않아요. 너무 일찍 오거나 너무 늦게 온 방문자에게 보여 줄 화면을 따로 정해서, 상황에 맞는 다음 행동을 안내할 수 있어요.

### 폼·설문·퀴즈가 열리기 전

캠페인 시작 전에 게시하거나 URL을 먼저 배포할 때 오픈 전 화면이 유용해요. 응답 입력란을 미리 보여 주지 않고, 오픈 안내 메시지나 이벤트 시작 시각, 이용 방법 같은 내용을 보여 줄 수 있어요.

![오픈 전 화면 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080666983/original/4mwTfeAcDrxk8_O74supGywgvB6tuSMhCg.png?1789108556)

### 폼·설문·퀴즈가 닫힌 후

설정한 마감 시각이 지나 새 응답을 받지 않을 때 마감 후 화면이 나타나요. 등록이 끝났다고 알리거나, 다른 오퍼를 소개하거나, 대기자 명단으로 안내하거나, 다음에 할 일을 알려 줄 때 쓸 수 있어요.

![마감 후 화면 설정 동작](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080666931/original/DYj-aH5SMzILfPTNwcuTDeGAHCjWJJfJSQ.gif?1789108534)

### 페이지 보여 주기와 링크 열기

응답을 받지 않는 상태마다 방문자를 안내하는 방법은 두 가지예요. 캠페인의 다음 단계에 맞는 방법을 고르세요.

| 옵션 | 이럴 때 좋아요 |
| --- | --- |
| **Show a page**(페이지 표시) | 기본 제공 리치 콘텐츠 편집기로 만든 맞춤 메시지를 방문자에게 바로 보여 줄 때 |
| **Open a link**(링크 열기) | 방문자를 다른 페이지, 오퍼, 대기자 명단, 이벤트 등 다른 URL로 보낼 때 |

{% hint style="info" %}
팁: 맞춤 페이지를 만들 때는 기본 제공 미리보기로 방문자에게 보이는 메시지가 분명한지 확인하세요. 응답 기간이 시작되거나 끝나기 전에 확인해 두면 좋아요.
{% endhint %}

## 공개 일정 활용 사례

응답 기간을 캠페인 마감일이나 오픈일에 맞춰야 할 때 공개 일정이 가장 유용해요. 시작과 끝에 직접 설정을 바꾸지 않아도 방문자 화면이 그 시점에 맞게 바뀌어요.

| 사례 | 공개 일정이 도와주는 점 |
| --- | --- |
| 이벤트 등록 | 이벤트나 웨비나 마감일이 지나면 등록을 자동으로 닫아요. |
| 플래시 세일 | 폼이나 설문을 프로모션 기간에만 열어 둬요. |
| 웨비나 런칭 | 미리 게시하고, 등록이 곧 시작된다는 화면을 보여 줘요. |
| 퀴즈·콘테스트 | 참여 기간을 정하고, 기간이 끝나면 새 참여를 자동으로 막아요. |
| 캠페인 종료 후 유입 | 늦게 온 방문자를 대기자 명단, 대체 오퍼, 랜딩 페이지, 다음 이벤트로 보내요. |
| 쿠폰 프로모션 | 프로모션 마감 후에는 새 제출을 막아요. |

## 폼·설문·퀴즈에 공개 일정 설정하기

완성된 일정에는 응답 기간, 올바른 시간대, 그 기간 밖에서 방문자에게 보여 줄 화면이 모두 들어 있어야 해요. 폼, 설문, 퀴즈를 공개하기 전에 세 가지를 모두 설정하고 미리보기로 확인하세요.

### 1단계: 폼·설문·퀴즈 열기

공개 일정은 항목마다 따로 설정해요. 그래서 폼, 설문, 퀴즈마다 다른 캠페인 기간을 쓸 수 있어요.

1. **사이트**로 이동하세요.
2. **폼**, **설문**, **퀴즈** 중 하나를 여세요.
3. 일정을 설정할 항목을 여세요.

### 2단계: Schedule visibility 켜기

**Schedule visibility**를 켜기 전에는 일정 설정이 비활성 상태예요. 그래서 일정을 쓰지 않는 기존 항목은 그대로 동작해요.

1. **설정** 탭을 여세요.
2. 폼, 설문, 퀴즈 설정 영역을 찾으세요.
3. **Schedule visibility**를 켜세요.

### 3단계: 오픈·마감 기간 설정하기

오픈과 마감 설정으로 방문자가 응답을 제출할 수 있는 기간이 정확히 정해져요.

1. 오픈 시각은 **Right away** 또는 **날짜 선택** 중에서 고르세요.
2. **날짜 선택**을 골랐다면 오픈 날짜와 시각을 선택하세요.
3. 마감 시각은 **없음** 또는 **날짜 선택** 중에서 고르세요.
4. **날짜 선택**을 골랐다면 마감 날짜와 시각을 선택하세요.

![오픈·마감 날짜 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080666909/original/eel12UZvbpBvjw11PqR44MsXD352qKcNKA.png?1789108505)

### 4단계: 시간대 선택하기

선택한 시간대는 오픈 시각과 마감 시각 모두에 적용돼요. 캠페인 담당 팀이 마감 시각을 안내할 때 기준으로 삼는 시간대와 같은 시간대를 고르세요.

1. **시간대** 선택 상자를 여세요.
2. 오픈·마감 일정의 기준이 될 시간대를 선택하세요.

### 5단계: 오픈 전 화면 설정하기

오픈 전 메시지를 분명하게 보여 주면 방문자가 폼이 고장 났거나 갑자기 닫혔다고 오해하지 않아요.

1. **Before the form opens**(폼이 열리기 전), **Before the survey opens**(설문이 열리기 전) 또는 퀴즈의 같은 항목을 펼치세요.
2. 맞춤 메시지를 만들려면 **Show a page**를, 방문자를 다른 곳으로 보내려면 **Open a link**를 선택하세요.
3. 페이지를 선택했다면 방문자에게 보여 줄 내용을 꾸미세요.
4. 미리보기로 결과를 확인하세요.

### 6단계: 마감 후 화면 설정하기

마감 후 화면은 새 응답이 자동으로 막힌 뒤 늦게 온 방문자에게 다음 행동을 알려 줘요.

1. **After the form closes**(폼이 닫힌 후), **After the survey closes**(설문이 닫힌 후) 또는 퀴즈의 같은 항목을 펼치세요.
2. **Show a page** 또는 **Open a link**를 선택하세요.
3. 메시지나 이동할 URL을 설정하세요.
4. 미리보기로 결과를 확인하세요.

### 7단계: 저장하고 테스트하기

전체 흐름을 테스트하면 응답 기간이 시작되기 전에 시간대 실수, 잘못된 날짜, 캠페인과 맞지 않는 안내 문구를 찾을 수 있어요.

1. **저장**을 클릭하세요.
2. 설정한 타임라인을 확인하세요.
3. 방문자 화면을 미리보기로 확인하세요.
4. 의도한 오픈·마감 날짜와 시간대가 맞는지 확인하세요.
5. 평소 캠페인 진행 방식대로 폼, 설문, 퀴즈를 게시하거나 배포하세요.

## 문제 해결

대부분의 일정 문제는 세 가지를 확인하면 원인을 찾을 수 있어요. 일정이 켜져 있는지, 선택한 시간대가 맞는지, 현재 시각이 설정한 응답 기간 안에 있는지 확인하세요.

| 문제 | 확인할 내용 |
| --- | --- |
| 예상보다 일찍 응답을 받아요 | 오픈 옵션이 **Right away**로 설정되어 있지 않은지 확인하고, 설정한 날짜·시각·시간대를 확인하세요. |
| 마감하려던 시각이 지나도 응답을 받아요 | 마감 옵션이 **없음**이 아니라 **날짜 선택**으로 설정되어 있는지 확인하고, 설정한 시간대를 확인하세요. |
| 열려 있어야 하는데 방문자에게 오픈 전 페이지가 보여요 | 현재 시각을 선택한 일정 시간대 기준의 오픈 시각과 비교해 보세요. |
| 방문자에게 마감 페이지가 너무 일찍 보여요 | 마감 날짜, 마감 시각, 시간대에 잘못된 값이 없는지 확인하세요. |
| 엉뚱한 안내 메시지가 보여요 | 오픈 전과 마감 후 중 알맞은 상태를 편집했는지 확인하세요. |
| 리디렉션이 의도한 곳으로 가지 않아요 | **Open a link**에 설정한 URL을 확인하고, 이동할 주소를 따로 열어서 테스트하세요. |
| 기존 폼, 설문, 퀴즈가 예상치 않게 바뀌었어요 | **Schedule visibility**를 켰는지 확인하세요. 일정을 켜지 않은 항목은 기존 동작을 그대로 유지해요. |

## 자주 묻는 질문

### 공개 일정은 폼, 설문, 퀴즈 모두에서 쓸 수 있나요?
네. **Schedule visibility**는 폼 빌더, **설문 빌더**, **퀴즈 빌더** 세 가지 모두에서 쓸 수 있어요.

### 오픈 날짜와 마감 날짜를 둘 다 설정해야 하나요?
아니요. 오픈은 **Right away**나 특정 날짜 중에서, 마감은 **없음**이나 특정 날짜 중에서 고를 수 있어요.

### 오픈과 마감에 같은 시간대가 적용되나요?
네. 선택한 일정 시간대가 설정한 두 시각 모두에 적용돼요.

### 마감 시각이 되면 어떻게 되나요?
새 제출이 자동으로 막히고, 방문자에게는 설정해 둔 마감 후 페이지가 보이거나 설정한 URL로 이동해요.

### 접근 불가 메시지를 보여 주는 대신 방문자를 다른 곳으로 보낼 수 있나요?
네. 오픈 전이나 마감 후 상태에서 **Open a link**를 선택하고 이동할 URL을 설정하세요.

### 오픈 전과 마감 후에 서로 다른 화면을 보여 줄 수 있나요?
네. 오픈 전과 마감 후 상태는 따로 설정하므로, 단계마다 각자의 페이지나 리디렉션을 정할 수 있어요.

### 마감 시각을 설정하면 이전 제출 내역이 삭제되나요?
아니요. 마감 일정은 마감 후 새 응답을 받을지만 정해요. 기존 제출 내역을 삭제하는 기능이 아니에요.

### Schedule visibility를 끄면 어떻게 되나요?
폼, 설문, 퀴즈가 오픈·마감 일정 없이 원래의 이용 방식대로 계속 동작해요.
