# 설문에서 주문 범프 설정하고 사용하기

설문 안에 추가 구매 제안(주문 범프, Order Bump)을 넣어 매출을 늘리는 방법을 안내해요. 응답자가 설문을 이어 가는 흐름을 끊지 않고 업셀 기회를 만들 수 있어요. 다양한 템플릿과 시각 요소를 쓸 수 있고, 범프 상품은 필요할 때 켜고 끌 수 있어요.

## 설문의 주문 범프란?

설문의 주문 범프는 설문 안에 업셀 옵션을 넣는 기능이에요. 주요 상품 옆에 범프 상품을 함께 보여 주면, 응답자가 부담 없이 추가 구매를 할 수 있어요. 범프 상품은 직접 꾸밀 수 있어요.

## 주문 범프의 주요 장점

설문에서 확장된 주문 범프 기능을 쓰면 다음과 같은 장점이 있어요.

- 클래식과 모던, 두 가지 범프 스타일 중에서 고를 수 있어 눈에 더 잘 띄어요.
- 시선을 끌고 전환율을 높이도록 만든 여러 템플릿 중에서 선택할 수 있어요.
- 색상, 아이콘, 강조 텍스트, 가격 표시 같은 시각 요소를 모두 직접 꾸밀 수 있어요.
- 범프 상품을 여러 개 넣어 업셀 전략을 넓힐 수 있어요.
- 설문 하나에는 반복 결제 상품이 하나만 설정되도록 규칙이 적용돼요.
- 범프 상품을 켜고 끄거나 순서를 바꾸는 일이 자유로워요.

## 설문에서 주문 범프 설정하고 사용하기

하이퍼클래스 설문 빌더에서는 주문 범프를 간단하게 설정할 수 있어요. 아래 순서대로 따라 해 보세요.

### 1단계: 설문 만들기

1. 서브 계정에 로그인하세요.
2. 왼쪽 사이드바에서 **사이트 > 설문 > 빌더**를 클릭하세요.
3. **+ Add Survey**(설문 추가)를 클릭하세요.
4. **처음부터 시작**을 선택하거나 **템플릿**을 선택한 다음 **만들기**를 클릭하세요.
5. **Element bar**(요소 모음)에서 **Sell Products**(상품 판매) 요소를 설문 캔버스로 끌어다 놓으세요.

![설문 캔버스에 상품 판매 요소를 끌어다 놓는 화면](https://jumpshare.com/v/Y5dypmurPaobZF4yKrQQ+/GIF+Recording+2025-07-24+at+8.40.36+PM.gif)

### 2단계: 주요 상품 추가하기

1. 캔버스에 놓은 **Sell Products** 요소를 클릭하세요.
2. 오른쪽 패널에서 **상품 추가**를 클릭하세요.
3. 아직 상품을 만들지 않았다면 **여기를 클릭** 링크를 눌러 상품 만들기 페이지를 열고 상품을 만드세요.
4. 이미 만들어 둔 상품이 있다면 **선택해 주세요** 드롭다운에서 상품을 고르세요.
5. **상품 유형**에서 **주요 상품**을 선택하세요.
6. **Show Options**(표시 옵션)에서 **설명**, **이미지**, **수량**을 각각 켜거나 꺼서 보여 줄 항목을 정하세요.
7. **상품 추가**를 클릭해 상품을 넣으세요.

### 3단계: 범프 상품 추가하기

1. **상품 추가**를 다시 클릭하세요.
2. 드롭다운에서 **새로 만들기**를 선택하거나 기존 상품을 선택하세요.
3. **상품 유형**에서 **범프 상품**을 선택하세요.
4. 눈길을 끄는 헤드라인을 입력하세요.
5. 이미지를 보여 줄지 정하세요. 새 이미지를 올릴 수도 있고, 상품에 등록된 이미지를 시스템이 가져오게 할 수도 있어요.

### 4단계: 범프 상품의 내용과 디자인 꾸미기

1. **Order Bump Style**(주문 범프 스타일)에서 **모던** 또는 **클래식**을 고르세요.
2. **템플릿 선택** 드롭다운에서 **템플릿 1**, **템플릿 2**, **템플릿 3** 중 하나를 고르세요.
3. **텍스트 강조**에 시선을 끄는 문구를 입력하세요. 예를 들어 "한 번의 클릭으로 혜택을 받아 보세요"처럼 쓸 수 있어요.
4. **아이콘**에서 강조 텍스트 옆에 보여 줄 아이콘을 고르세요.
5. **Show Price / Hide Price**(가격 표시/숨기기)로 범프 상품의 가격을 보여 줄지 정하세요.
6. **배경 색상**과 함께 강조 텍스트, 헤드라인, OTO 헤드라인, OTO 텍스트의 색상을 원하는 대로 바꾸세요.
7. **Layout Settings**(레이아웃 설정)에서 1열, 2열, 3열 중 하나를 고르세요.
8. **Product Selection**(상품 선택)에서 응답자가 상품을 하나만 고를 수 있게 할지, 여러 개 고를 수 있게 할지 정하세요.
9. 필요하면 **Footer Info**(푸터 정보)를 켜고 "100% 안전한 결제" 같은 문구를 넣으세요.
10. 플레이스홀더 텍스트를 숨길지, 그대로 둘지 선택하세요.

![범프 상품의 내용과 디자인을 설정하는 화면](https://jumpshare.com/v/cQiqgSyDmTJrOFPQyazT+/GIF+Recording+2025-07-24+at+9.47.48+PM.gif)

### 5단계: 설문 저장하기

1. 오른쪽 위의 **저장**을 클릭해 변경 내용을 저장하세요.

![오른쪽 위 저장 버튼 위치](https://jumpshare.com/v/nsXVDx4jYmDGelQt4pHQ+/Screen+Shot+2025-07-24+at+9.53.00+PM.png)

## 자주 묻는 질문

### 설문 하나에 범프 상품을 두 개 이상 넣을 수 있나요?
네, 같은 설문에 범프 상품을 여러 개 넣을 수 있어요. 주요 상품의 흐름을 방해하지 않고 업셀 기회를 여러 번 만들 수 있어요.

### 주요 상품과 범프 상품을 둘 다 반복 결제로 설정할 수 있나요?
아니요. 설문 하나에서 반복 결제로 설정할 수 있는 상품은 하나뿐이에요. 주요 상품이나 범프 상품 하나만 반복 결제로 할 수 있고, 둘 다는 안 돼요. 이렇게 해서 결제 방식이 서로 어긋나지 않게 해요.

### 주요 상품을 넣지 않으면 어떻게 되나요?
주요 상품이 없으면 범프 상품은 표시되지 않아요. 범프 상품이 보이게 하려면 먼저 주요 상품을 추가하세요.

### 범프 상품은 모든 결제 처리업체에서 쓸 수 있나요?
네. 주문 범프는 Stripe, PayPal, 그 밖에 하이퍼클래스에서 지원하는 결제 처리업체에서 모두 잘 작동해요.

### 설문의 나머지 부분에 영향을 주지 않고 범프 상품의 순서를 바꾸거나 잠시 끌 수 있나요?
네, 가능해요. 주요 상품 설정이나 설문 로직에는 영향 없이 범프 상품을 언제든 켜고 끄거나 순서를 바꿀 수 있어요.

### 어떤 설문에서 주문 범프를 쓸 수 있나요?
**Sell Products** 요소가 들어 있는 설문이라면 주문 범프 기능을 쓸 수 있어요.

### 범프 상품마다 디자인을 따로 꾸밀 수 있나요?
네, 범프 상품마다 색상, 아이콘, 강조 텍스트, 가격 표시를 각각 바꿀 수 있어요.

### 한 설문에 범프 상품을 몇 개까지 넣을 수 있나요?
범프 상품을 여러 개 넣을 수 있어서, 필요에 따라 업셀 전략을 넓혀 갈 수 있어요.

### 클래식과 모던 범프 스타일은 어떻게 바꾸나요?
설문에서 범프 기능을 켠 뒤 범프 상품 설정에서 스타일을 바꿀 수 있어요.
