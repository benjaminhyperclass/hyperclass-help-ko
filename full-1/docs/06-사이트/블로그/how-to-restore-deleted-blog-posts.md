# 삭제한 블로그 게시물 복원하기

하이퍼클래스 블로그에서 삭제한 게시물은 바로 사라지지 않고 **삭제됨** 상태로 옮겨져요. 이 문서에서는 삭제된 게시물을 찾아 30일 안에 복원하는 방법, 여러 게시물을 한 번에 복원하는 방법, 게시물을 영구 삭제하는 방법을 안내해요.

---

## 삭제된 블로그 게시물 복구란?

삭제된 블로그 게시물 복구는 하이퍼클래스 블로그에서 삭제한 게시물을 되돌리는 기능이에요. 블로그 게시물을 삭제하면 바로 영구 삭제되지 않고 복구할 수 있는 **삭제됨** 상태로 이동해요. 삭제된 게시물은 30일 동안 복원할 수 있어서, 고객지원에 문의하지 않고 직접 콘텐츠를 되살릴 수 있어요.

삭제된 게시물을 확인한 뒤 이전 상태 그대로 복원하거나, 더 이상 필요 없으면 영구 삭제할 수 있어요. 복원한 게시물은 삭제 전의 임시저장 또는 게시 상태로 블로그 게시물 목록에 돌아와요.

---

## 주요 장점

- 실수로 삭제해도 안심: 삭제된 게시물을 최대 30일 동안 **삭제됨** 필터에서 복원할 수 있어요.
- 직접 복구: 고객지원에 문의하지 않고 블로그 대시보드에서 바로 복원할 수 있어요.
- 깔끔한 블로그 관리: 삭제된 게시물이 사용 중인 게시물과 분리되어 메인 블로그 목록이 정돈돼요.
- 일괄 복구: 삭제된 게시물을 여러 개 선택해 한 번에 복원할 수 있어요.
- 안전한 콘텐츠 정리: 더 이상 필요 없다고 확신할 때만 게시물을 영구 삭제할 수 있어요.
- 상태 유지: 복원한 게시물은 이전의 임시저장 또는 게시 상태 그대로 돌아와요.

---

## 삭제된 블로그 게시물 복원 방법

블로그 대시보드에서 삭제된 게시물을 복원하면 콘텐츠를 빠르게 되살릴 수 있고, 고객지원을 거치지 않아도 게시 작업을 이어갈 수 있어요. 아래 순서에 따라 삭제된 게시물을 찾아 복원하거나, 더 이상 필요 없는 게시물을 영구 삭제하세요.

### 삭제된 블로그 게시물 1개 복원하기

1. **사이트 > 블로그**로 이동하세요.

   ![사이트 > 블로그 메뉴 화면](https://jumpshare.com/share/CaktdH4pYMYmXow5UDqG+/Screen+Shot+2026-05-14+at+21.07.29.png)
2. 삭제된 게시물이 있는 블로그를 여세요.
3. **상태** 필터를 클릭하세요.
4. **삭제됨**을 선택하세요.
5. 복원할 게시물을 찾으세요.
6. 삭제된 게시물의 액션 메뉴를 여세요.
7. **블로그 게시물 복원**을 선택하세요.
8. 복원 확인 창에서 **확인**을 클릭하세요.
9. 복원이 끝나면 게시물이 삭제 전의 임시저장 또는 게시 상태로 블로그 게시물 목록에 돌아와요.

   ![삭제된 블로그 게시물 1개를 복원하는 과정](https://jumpshare.com/share/LN8xPxqUNxyPrZ2NyDOS+/GIF+Recording+2026-05-14+at+21.10.14.gif)

### 삭제된 블로그 게시물 여러 개 복원하기

1. **사이트 > 블로그**로 이동하세요.

   ![사이트 > 블로그 메뉴 화면](https://jumpshare.com/share/CaktdH4pYMYmXow5UDqG+/Screen+Shot+2026-05-14+at+21.07.29.png)
2. 삭제된 게시물이 있는 블로그를 여세요.
3. **상태** 필터를 클릭하세요.
4. **삭제됨**을 선택하세요.
5. 복원할 게시물 옆의 체크박스를 선택하세요.
6. **일괄 액션**을 클릭하세요.
7. **블로그 게시물 복원**을 선택하세요.
8. 복원 확인 창에서 **확인**을 클릭하세요.
9. 선택한 게시물이 삭제 전의 임시저장 또는 게시 상태로 블로그 게시물 목록에 돌아와요.

   ![삭제된 블로그 게시물 여러 개를 일괄 복원하는 과정](https://jumpshare.com/share/G9ZWN9Kajvmxa3DyyE6g+/GIF+Recording+2026-05-14+at+21.12.12.gif)

### 블로그 게시물 영구 삭제하기

{% hint style="info" %}
영구 삭제한 게시물은 복원할 수 없어요. 콘텐츠가 더 이상 필요 없을 때만 이 기능을 사용하세요.
{% endhint %}

1. **사이트 > 블로그**로 이동하세요.

   ![사이트 > 블로그 메뉴 화면](https://jumpshare.com/share/CaktdH4pYMYmXow5UDqG+/Screen+Shot+2026-05-14+at+21.07.29.png)
2. 삭제된 게시물이 있는 블로그를 여세요.
3. **상태** 필터를 클릭하세요.
4. **삭제됨**을 선택하세요.
5. 영구 삭제할 게시물을 하나 또는 여러 개 선택하세요.
6. **일괄 액션**을 클릭하거나 게시물의 액션 메뉴를 여세요.
7. **영구 삭제**를 선택하세요.
8. 영구 삭제 확인 창에서 **확인**을 클릭하세요.

   ![삭제된 블로그 게시물을 영구 삭제하는 과정](https://jumpshare.com/share/QzhsMIfihmhukIXKtPR3+/GIF+Recording+2026-05-14+at+21.14.41.gif)

## 자주 묻는 질문

### 삭제된 블로그 게시물은 얼마 동안 복원할 수 있나요?
삭제된 블로그 게시물은 최대 30일 동안 복원할 수 있어요. 30일이 지나면 시스템에서 영구 삭제돼요.

### 삭제된 블로그 게시물을 복원하면 어떻게 되나요?
게시물이 삭제 전의 임시저장 또는 게시 상태 그대로 블로그 게시물 목록에 돌아와요.

### 게시물을 복원하면 자동으로 게시되나요?
아니요. 복원해도 이전 상태가 그대로 유지돼요. 임시저장 상태였던 게시물은 임시저장으로, 게시된 게시물은 게시 상태로 돌아와요.

### 삭제된 게시물을 여러 개 한 번에 복원할 수 있나요?
네, 할 수 있어요. **삭제됨** 필터에서 복구할 게시물을 선택한 다음 **일괄 액션** 메뉴에서 **블로그 게시물 복원**을 선택하세요.

### 영구 삭제한 게시물도 복원할 수 있나요?
아니요. 블로그 게시물을 영구 삭제하면 복원할 수 없어요.

### 이 복구 기능에 **버전 기록**도 포함되나요?
아니요. 이번 릴리스에는 **버전 기록**이 포함되어 있지 않아요.

### 삭제된 블로그 게시물은 어디에서 찾나요?
블로그 대시보드에서 **상태** 필터를 **삭제됨**으로 선택하면 삭제된 게시물을 볼 수 있어요.

### 삭제된 블로그 게시물을 복원하려면 고객지원에 문의해야 하나요?
아니요. 삭제된 블로그 게시물 복구는 블로그 대시보드에서 직접 할 수 있어요.
