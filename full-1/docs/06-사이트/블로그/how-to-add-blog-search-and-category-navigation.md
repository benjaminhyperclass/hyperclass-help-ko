# 블로그에 검색과 카테고리 내비게이션 추가하기

블로그에 검색과 카테고리 내비게이션을 추가하면 방문자가 글을 훑어보고 내용을 이해하기 쉬워져요. 콘텐츠 구조가 정리되어 SEO에도 도움이 돼요. 이 문서에서는 블로그 사이트 편집기에서 카테고리 내비게이션과 블로그 검색을 추가하는 방법을 안내해요.

## 블로그에 검색과 카테고리 내비게이션 추가하기

1. **사이트 > 블로그**로 이동하세요.
2. 목록에서 블로그 이름을 클릭하세요. 블로그 목록 화면에 **Edit the Site**(사이트 편집) 옵션이 있어요.
3. 해당 블로그의 사이트 편집기로 들어가면 **Elements**(요소)에서 **Category Navigation**(카테고리 내비게이션)을 찾을 수 있어요.
4. **Category Navigation** 요소를 원하는 위치로 끌어다 놓으세요.
5. 편집하면서 내비게이션에 카테고리를 더 추가할 수 있어요. 예를 들어 **Category 1**(카테고리 1)을 클릭하면 **카테고리 이름**과, 블로그 글에 연결된 카테고리 링크를 수정할 수 있어요. 다른 카테고리도 같은 방법으로 수정하세요.

- 블로그 검색을 추가할 때는 활성화하거나 비활성화하는 옵션이 있어요.
