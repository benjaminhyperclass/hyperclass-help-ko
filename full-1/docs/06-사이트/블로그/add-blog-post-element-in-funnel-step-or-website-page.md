# 퍼널 단계나 웹사이트 페이지에 블로그 게시물 요소 추가하기

**블로그 게시물** 요소를 쓰면 하이퍼클래스 퍼널이나 웹사이트 페이지에 블로그 글을 바로 보여 줄 수 있어요. 최근 글을 소개하거나, 카테고리·작성자별로 글을 묶어 보여 주고, 게시된 블로그 글로 페이지를 늘 새롭게 유지할 수 있어요.

[동영상](https://www.youtube.com/embed/8qa8p-0qmas?&wmode=opaque)

## 블로그 게시물 요소란?

**블로그 게시물** 요소는 게시된 블로그 글을 하이퍼클래스의 퍼널 단계나 웹사이트 페이지로 가져와 보여 줘요. 방문자를 메인 블로그 사이트로만 보내지 않고, 원하는 페이지 안에서 바로 블로그 글을 보여 줄 수 있어요. 검색 최적화(SEO)에 도움이 되고, 콘텐츠 노출도 늘어나며, 방문자가 더 목적에 맞게 글을 둘러볼 수 있어요.

이런 경우에 쓰면 좋아요.

- 최근 글을 소개하고 싶을 때
- 특정 카테고리의 글을 보여 주고 싶을 때
- 특정 작성자가 쓴 글을 보여 주고 싶을 때

이 요소는 하이퍼클래스에 블로그를 이미 만들어 두었고, 게시된 글이 1개 이상 있는 사용자를 위한 기능이에요. 페이지에 요소를 추가하면 선택한 정렬 또는 필터 옵션에 따라 블로그 글이 표시돼요.

## 블로그 게시물 요소 설정하기

1. **사이트**로 이동해 **퍼널** 또는 **웹사이트**를 엽니다. 편집할 퍼널 단계나 웹사이트 페이지를 선택하고 **편집**을 클릭하세요.

   ![사이트에서 퍼널 단계 또는 웹사이트 페이지를 선택해 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066833207/original/BfTDm0-B4YPaU1YUrrnxjgpf1yj_B2uTIQ.png?1773350814)

2. **요소 추가**를 클릭하세요.

   ![요소 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066833286/original/XsN-gV6uYpusoXcVjrwmh_wFa2G3cMabjA.png?1773350934)

3. **블로그 게시물** 요소를 찾아 페이지에서 원하는 위치로 끌어다 놓으세요.

   ![블로그 게시물 요소를 페이지로 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066833306/original/Io3NUVH61JwjCymDAL8r7vEOtYQWbjN0QA.png?1773350972)

4. 요소를 클릭해 요소 설정을 열고, 블로그 글을 어떻게 보여 줄지 정하세요.
   - **Display Style**(표시 스타일): 페이지에서 요소가 보이는 모양을 선택해요.
   - **Choose Blog Site**(블로그 사이트 선택): 글을 가져올 블로그를 선택해요.
   - **정렬 기준**: 어떤 글을 먼저 보여 줄지 선택해요. **최근 게시물**, **Recent Posts by Category**(카테고리별 최근 게시물), **Recent Posts by Author**(작성자별 최근 게시물) 중에서 고를 수 있어요.
   - **카테고리 선택**: 포함할 카테고리를 선택해요.
   - **페이지네이션**: 보여 줄 글의 개수를 선택해요.
   - **Button Options**(버튼 옵션): 버튼 텍스트와 색상을 원하는 대로 바꿔요.

   ![블로그 게시물 요소 설정 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066833446/original/ATLQYBI6-GZXcmhk_4XPqJkXxYJrRHw0Mg.png?1773351375)

5. **저장**을 클릭해 변경 내용을 저장한 다음, 사이트 또는 퍼널을 **게시**하세요.

   ![저장과 게시 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066833488/original/sM2MJLAVhL1vlTXuXU9elef5u8opLEBX8w.png?1773351441)

## 자주 묻는 질문

### 요소를 추가했는데 게시물이 나타나지 않아요. 어떻게 하나요?
블로그가 올바르게 만들어졌는지, 글이 게시된 상태인지 확인하세요. 선택한 카테고리나 작성자 필터에 맞는 글이 있는지도 확인해 보세요.

### 이 요소로 콘텐츠 중심의 랜딩 페이지를 만들 수 있나요?
네. 방문자가 전환하기 전에 블로그 글로 정보를 얻도록 하는 랜딩 페이지나 자료 페이지를 만들 때 이 요소를 활용할 수 있어요.
