# 스냅샷으로 서브 계정 간에 블로그 콘텐츠 공유하기

**스냅샷**을 이용하면 블로그, 블로그 게시물, 작성자, 카테고리를 에이전시 설정에서 원하는 서브 계정으로 공유할 수 있어요. 여러 서브 계정에서 같은 블로그 콘텐츠를 다시 쓸 때 활용하세요.

[동영상](https://www.youtube.com/embed/vsXMQqVZekY?&wmode=opaque)

## 부모 서브 계정에서는 어떻게 하나요?

```
부모 서브 계정은 스냅샷의 출처입니다. 스냅샷을 만들어 내는 기준이 되는 서브 계정이에요.
```

1. **사이트** 탭 > **블로그**로 이동해요.
2. **Create New Blog**(새 블로그 만들기)를 눌러요.
3. SEO 메타 정보로 **Blog Name**(블로그 이름), **이미지**, 간단한 **설명**을 입력하고 도메인을 연결해요.
4. 블로그의 디자인과 스타일을 원하는 대로 편집해요.
5. **새 블로그 게시물 만들기**를 눌러 카테고리, 작성자와 함께 게시물을 만들어요.
6. 다른 곳으로 옮기려면 블로그 게시물을 게시해요.

## 에이전시 설정 > 스냅샷에서는 어떻게 하나요?

1. 에이전시 화면에서 **스냅샷**으로 이동해요.
2. 스냅샷을 새로 고치거나(가이드 참고) 업로드해요(가이드 참고).
3. 스냅샷을 펼치면 모든 블로그 이름이 선택할 수 있는 항목으로 표시돼요.

## 자식 서브 계정에서는 어떻게 하나요?

```
자식 서브 계정은 스냅샷을 업로드해서 받는 서브 계정입니다.
```

1. **사이트 > 블로그**로 이동해요.
2. 블로그를 확인해요. 상태가 초안으로 표시돼요.

   {% hint style="info" %}
   초안 상태는 사용자가 도메인 정보를 추가해야 한다는 뜻이에요.
   {% endhint %}

3. 블로그의 도메인 정보를 모두 입력하면 블로그를 모두 게시할 수 있어요.
