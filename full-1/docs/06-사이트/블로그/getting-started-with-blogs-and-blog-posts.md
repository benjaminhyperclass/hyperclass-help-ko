# 블로그와 블로그 게시물 시작하기

하이퍼클래스 블로그로 콘텐츠 운영을 시작하는 방법을 안내해요. 블로그를 만들고, 게시물을 쓰고, 작성자와 카테고리를 추가하고, 검색에 노출되도록 SEO 정보를 입력하는 과정을 차례로 따라 할 수 있어요.

## 하이퍼클래스 블로그란?

하이퍼클래스 블로그는 웹사이트나 퍼널에 올릴 글을 쓰고 정리하는 기본 제공 게시 시스템이에요. 작성자, 카테고리, SEO, 디자인을 한곳에서 관리하면서 꾸준히 글을 게시하고, 방문자를 원하는 페이지로 연결할 수 있어요.

## 하이퍼클래스 블로그의 주요 장점

- 한곳에서 관리: 모든 게시물, 작성자, 카테고리, SEO를 한 화면에서 관리해요.
- 원하는 위치에 배치: **블로그 게시물 목록** 요소를 쓰면 웹사이트의 어느 페이지에나, 퍼널의 어느 단계에나 게시물을 보여 줄 수 있어요.
- 기본 제공 SEO 항목: 슬러그, 메타 데이터, 대표 URL(canonical URL)을 설정해서 검색 노출을 높여요.
- 디자인 선택: 목록과 게시물 화면에 **Standard**(표준) 또는 **Compact**(컴팩트) 레이아웃을 고를 수 있어요.
- 콘텐츠가 늘어도 문제없는 작업 방식: 임시 저장, 예약 게시, 즉시 게시, 대량 가져오기를 지원해요.

## 블로그 만드는 방법

블로그를 처음 시작하거나 어디서부터 해야 할지 모르겠다면 아래 순서대로 따라 해 보세요.

### 1단계: 블로그 사이트(콘텐츠를 담는 공간) 만들기

1. **사이트**(Sites)로 이동해요.
2. **블로그**를 클릭해요.
3. **Create Blog**(블로그 만들기)를 클릭해요. **처음부터 만들기**를 하거나 템플릿 중에서 골라요.

![블로그 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064779424/original/OiYF3mABKqw7rZqW5H23dRkDcSvWob6htg.jpeg?1770900245)

### 2단계: 블로그 사이트 세부 정보 입력하기

1. **블로그 사이트 제목**을 입력해요. 브라우저 탭 제목 표시줄과 검색 결과에 보이는 이름이에요.
2. **도메인**을 **선택**하거나 **추가**/**편집**해요. 선택 사항이라서 나중에 **Blog Settings**(블로그 설정)에서 연결해도 돼요.
3. 도메인 관리: 블로그를 만들 때 도메인을 연결할 수도 있고, 나중에 **Blog Settings**에서 연결할 수도 있어요. 도메인을 바꾸려면 **Blog Settings**에서 **도메인 삭제**를 선택한 뒤 새 도메인을 연결하세요.
4. **Slug**(슬러그, 페이지 주소의 마지막 부분)를 입력해요.
5. **Blog Meta Description**(블로그 메타 설명)을 입력해요. 필수는 아니지만 입력하기를 권장해요.

![블로그 사이트 세부 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064779485/original/M-l1QTgtlbe4xtiEOCEf57_wpanMIKzu1A.jpeg?1770900284)

### 3단계: 블로그 게시물 작성하기

1. **사이트 > 블로그**로 이동해요.
2. 목록에서 방금 만든 블로그 사이트를 클릭해요. 게시물을 추가할 다른 블로그 사이트를 클릭해도 돼요.

   ![블로그 사이트 선택 화면](https://jumpshare.com/share/W1ZseR5HZIB5gqCKFqVA+/GIF+Recording+2026-02-12+at+6.22.19+PM.gif)
3. **새 게시물**을 클릭해요.
4. **+ 새 게시물**을 클릭하면 처음부터 블로그 게시물을 작성할 수 있어요. URL에서 블로그 게시물 가져오기나 CSV에서 블로그 게시물 가져오기도 쓸 수 있어요.
5. 처음부터 게시물을 작성하거나 기존 게시물을 편집하는 방법은 '블로그 게시물 작성' 문서를 참고하세요.

   ![새 게시물 작성 화면](https://jumpshare.com/share/lauN1KBkpiMjO4w8pQju+/Screen+Shot+2026-02-12+at+6.23.44+PM.png)

### 4단계: 게시물 상세 정보 입력하기

1. 편집기에서 게시물 내용을 입력하고 서식 지정까지 마쳤다면 **계속**을 클릭해요.

   ![계속 버튼 클릭](https://jumpshare.com/share/ODj6plhHTcGJP049Rix9+/Screen+Shot+2026-02-12+at+6.33.01+PM.png)
2. 게시물의 **URL Slug**(URL 슬러그)를 입력해요.

   ![URL 슬러그 입력](https://jumpshare.com/share/2qSl2zO7wamgKp1EYRyN+/Screen+Shot+2026-02-12+at+6.38.18+PM.png)
3. **카테고리**와 **작성자**를 **선택**하거나 만들어요. 카테고리는 **카테고리 만들기**로 새로 만들 수 있어요.

   ![카테고리와 작성자 선택](https://jumpshare.com/share/TRJGa96erSfwYce2526S+/GIF+Recording+2026-02-12+at+6.40.37+PM.gif)
4. **Canonical Link**(대표 링크)를 편집하거나 그대로 둬요.
5. **키워드**를 추가해요.

   ![키워드 추가](https://jumpshare.com/share/yIPdQ9TzuhrBXv0OwOUn+/Screen+Shot+2026-02-12+at+6.43.37+PM.png)

### 5단계: SEO 정보 입력하기

1. **SEO 제목**을 입력해요.
2. **게시글 설명**을 입력해요.
3. **커버 이미지**와 **대체 텍스트**를 추가해요.

![SEO 정보 입력 화면](https://jumpshare.com/share/JAMVKS0xLVx9C9PIGEAX+/Screen+Shot+2026-02-12+at+6.47.35+PM.png)

### 6단계: 블로그 게시물 게시하기

1. 나중에 더 수정하려면 게시물을 **임시 저장** 상태로 둘 수 있어요.
2. 지금 바로 **게시**하거나, **일정**을 지정해서 원하는 시간에 게시할 수 있어요.

{% hint style="info" %}
퍼널이나 웹사이트에 블로그를 추가하는 방법은 별도의 자세한 안내 문서를 참고하세요.
{% endhint %}

![게시 또는 일정 설정 화면](https://jumpshare.com/share/NUDN2nvuLcneDX3T7hnt+/GIF+Recording+2026-02-12+at+6.51.58+PM.gif)

### 7단계: 블로그 레이아웃 꾸미기

블로그를 만들고 게시한 뒤에는 방문자에게 블로그와 게시물이 어떻게 보일지 꾸밀 수 있어요.

편집할 블로그를 열고, 제공되는 레이아웃과 스타일 옵션으로 디자인을 바꿔요.

아래 작업을 할 수 있어요.

- 블로그 레이아웃을 선택해요.

  ![블로그 레이아웃 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082986124/original/yy_1Ip0DhAGiymLWm-I7WFYTfNLPDUh7Kw.jpeg?1791571049)
- 블로그 카드의 모양을 바꿔요.
- 이미지, 태그, 제목, 설명, 작성자, 게시일의 스타일을 조정해요.

  ![이미지, 태그, 제목 등 스타일 조정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082986144/original/te_gTy2mSnTJRp2VkpOpf29WDSRPePg5UA.jpeg?1791571091)
- 블로그 홈과 개별 블로그 게시물에 쓰는 페이지를 관리해요.

  ![블로그 홈과 게시물 페이지 관리](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082986151/original/hKVlhSTUcADGIh-vfQGM0kI9tysAT4GA0A.jpeg?1791571106)

이 설정을 활용하면 블로그 디자인을 웹사이트 및 브랜드와 일관되게 맞출 수 있어요.

## 게시했거나 임시 저장한 블로그 게시물 수정하기

1. 블로그 게시물로 이동해서 게시물 옆의 점 세 개를 클릭한 다음 **게시물 업데이트**를 클릭해요.
2. 편집기에서 게시물 내용을 수정해요.
3. **작성자**, **카테고리**, 슬러그, SEO 같은 게시물 상세 정보를 바꾸려면 **Update Settings**(설정 업데이트) 버튼을 클릭해요.
4. 필요한 내용을 수정한 뒤 **게시**를 클릭해요.

![게시물 수정 화면](https://jumpshare.com/share/WwE17o2QD3KECvtgabk0+/GIF+Recording+2026-02-12+at+6.58.41+PM.gif)

## 자주 묻는 질문

### 블로그에서 도메인은 어떻게 적용되나요?

블로그 목록 요소를 추가한 퍼널이나 웹사이트에 도메인이 연결돼요.

블로그 URL 형식은 아래와 같아요.

| 도메인 | 블로그 게시물 슬러그 | 최종 URL |
| --- | --- | --- |
| abc.com | b/sample-now | abc.com/b/sample-now |
| abc.com/xyz | b/sample-now | abc.com/xyz/b/sample-now |
| blog.abc.com | b/sample-now | blog.abc.com/b/sample-now |

### 카테고리별로 블로그 페이지를 따로 만들 수 있나요?

현재는 지원하지 않아요. 앞으로 업데이트에서 카테고리 필터를 기준으로 슬러그와 SEO 정보를 지정해 퍼널/웹사이트 페이지를 만들 수 있게 될 예정이에요.

### 작성자, 카테고리, 키워드는 꼭 입력해야 하나요?

URL 슬러그, **카테고리**, **작성자**, **제목**, **게시글 설명**은 필수 항목이에요.

### 블로그 게시물에 커스텀 값을 쓸 수 있나요?

아니요, 현재는 블로그 게시물에서 **커스텀 값**을 지원하지 않아요. `{{contact. name}}`이나 `{{custom_values.xyz}}` 같은 값은 쓸 수 없어요.

### 블로그 게시물에 폼, 설문, 커스텀 코드를 추가하려면 어떻게 하나요?

현재는 블로그 게시물에 폼이나 설문을 추가할 수 없어요. 커스텀 코드를 추가하는 옵션은 곧 제공될 예정이에요.

### 블로그 게시물에 권장하는 이미지 크기가 있나요?

권장 크기는 따로 없어요. 다만 블로그 게시물 편집기 안의 페이지 너비는 736px이에요.
