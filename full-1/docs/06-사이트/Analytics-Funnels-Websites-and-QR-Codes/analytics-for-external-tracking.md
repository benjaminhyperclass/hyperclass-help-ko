# 외부 트래킹 분석으로 외부 웹사이트·폼 성과 확인하기

하이퍼클래스 밖에서 운영하는 웹사이트와 폼의 방문자 행동을 한 곳의 분석 대시보드에서 확인할 수 있어요. 페이지 조회수, 폼 제출 수, 완료율 같은 주요 지표를 타사 도구 없이 하이퍼클래스 안에서 볼 수 있어요.

## 외부 트래킹 분석이란?

외부 트래킹 분석은 하이퍼클래스 밖에서 운영하는 웹사이트와 폼의 방문자 활동을 추적하고 분석하는 기능이에요. 외부 페이지에 트래킹 스크립트를 설치하면, 하이퍼클래스가 주요 참여도 지표를 모아 전용 분석 대시보드에 보여 줘요. 여러 플랫폼을 오가지 않아도 성과를 측정하고, 추세를 파악하고, 데이터를 바탕으로 결정을 내릴 수 있어요.

## 외부 트래킹 분석의 주요 장점

방문자가 외부 페이지와 폼을 어떻게 쓰는지 알면 성과를 높이고 전환율을 개선할 수 있어요. 이 기능은 하이퍼클래스 안에서 바로 전체 현황과 활용할 만한 인사이트를 보여 줘요.

- 통합 분석 대시보드: 외부 페이지와 폼의 성과 데이터를 타사 도구 없이 한곳에서 확인해요.
- 전환 인사이트 개선: 폼 조회수, 응답 수, 완료율을 추적해 이탈 지점을 찾아요.
- 고급 필터링: 도메인, 페이지, 폼별로 성과를 분석해 더 정확한 인사이트를 얻어요.
- 방문자 파악: 유입 경로, 기기, 브라우저, 지역별 분포를 확인해요.
- 시간대별 분석: 기간 필터와 시각화 차트로 시간에 따른 추세를 살펴봐요.

## 분석 대시보드 둘러보기

**분석** 대시보드에서는 외부 트래킹 대상에서 사용자가 어떻게 행동하는지 한눈에 볼 수 있어요. 핵심 성과 지표를 모아 보여 주고 추세를 시각화해서, 성과를 빠르게 가늠할 수 있어요.

확인할 수 있는 지표:

- **총 페이지 조회수**
- **총 폼 조회수**
- **Responses**(응답 수)
- **Completion Rate**(완료율)

**참여도 지표**:

- **Average Time on Page**(페이지 평균 체류 시간)
- **Exit Before 30s**(30초 이내 이탈, 이탈률)

## 시간대별 인사이트

시간에 따른 성과를 추적하면 패턴, 참여가 몰리는 시기, 전환에 영향을 주는 문제를 찾을 수 있어요. 하이퍼클래스는 추세를 효율적으로 분석할 수 있는 시각 도구를 제공해요.

- 기간 선택기로 보고서 기간을 직접 정할 수 있어요.
- 다음 항목은 일별로 나눠 꺾은선형 차트로 볼 수 있어요.
  - **Page Views**(페이지 조회수)
  - **Form Views**(폼 조회수)
  - **Responses**
  - **Completion Rate**

필터를 쓰면 특정 데이터만 따로 보고 중요한 부분에 집중할 수 있어요. 불필요한 데이터가 줄어서 세부 단위로 성과를 분석하기 좋아요.

사용할 수 있는 필터:

- **도메인**
- **Pages**(페이지)
- **폼**

필터는 이럴 때 활용해 보세요.

- 특정 랜딩 페이지의 성과 평가
- 페이지별 폼 성과 비교
- 성과가 낮은 페이지나 폼 찾기

## 방문자·트래픽 분석

방문자를 이해하면 콘텐츠를 맞춤 구성하고 참여 전략을 개선할 수 있어요. 하이퍼클래스는 방문자 행동을 익명 처리한 집계 정보로 보여 줘요.

트래픽 분석에서 볼 수 있는 항목:

- 기기 유형(데스크톱, 태블릿, 모바일)
- **상위 브라우저**
- **상위 클라이언트 IP**(집계 기준)
- 지역 정보:
  - 국가
  - 시/도
  - 도시

## 폼별 분석

폼별 인사이트로 폼이 방문자를 리드로 얼마나 잘 전환하는지 평가할 수 있어요. 외부 폼과 HTML 기반 폼을 개선할 때 특히 유용해요.

폼별로 다음 데이터를 볼 수 있어요.

- **Total Views**(총 조회수)
- **Responses**
- **Completion Rate**

- 마지막 업데이트 시각이 함께 표시돼서 빠르게 점검할 수 있어요.

## 외부 트래킹 분석 설정하기

설정을 제대로 해야 데이터가 정확하게 수집되고 분석 대시보드가 정상적으로 동작해요. 트래킹 스크립트를 설치하지 않으면 분석 데이터를 볼 수 없어요.

### 1단계: 외부 트래킹 스크립트 설치

1. 하이퍼클래스에서 **사이트 > 외부 트래킹**으로 이동하세요.
2. 제공된 트래킹 스크립트를 복사하세요.
3. 외부 웹사이트 또는 퍼널 페이지의 `<head>` 섹션에 스크립트를 붙여 넣으세요.
4. 변경 내용을 저장하고 게시하세요. (**저장 및 게시**)

### 2단계: 분석 대시보드 열기

1. **사이트 > 분석**으로 이동하세요.
2. **분석** 드롭다운을 클릭하세요.
3. **외부 트래킹**을 선택하세요. 스크립트가 연결된 경우에만 보여요.

**다른 방법:**

- **외부 트래킹** 창을 여세요.
- **분석** 버튼을 클릭하면 자동으로 이동해요.

### 3단계: 데이터 추적 확인

1. 외부 사이트를 방문해서 활동을 만드세요.
2. **분석** 대시보드로 돌아오세요.
3. 페이지 조회수, 폼 조회수 같은 지표가 쌓이고 있는지 확인하세요.

## 자주 묻는 질문

### 분석에 외부 트래킹 옵션이 보이지 않아요.
트래킹 스크립트가 제대로 설치되고 연결된 경우에만 이 옵션이 나타나요.

### 데이터가 나타나기까지 얼마나 걸리나요?
활동이 발생한 뒤 대시보드에 반영되기까지 약간의 지연이 있을 수 있어요.

### Form Views와 Responses는 어떻게 다른가요?
**Form Views**는 폼이 노출된 횟수이고, **Responses**는 제출이 완료된 횟수예요.

### Completion Rate는 어떻게 계산하나요?
**Completion Rate**는 전체 폼 조회수 중 폼을 제출한 사용자의 비율이에요.

### Exit Before 30s는 무슨 뜻인가요?
페이지에 들어온 뒤 30초 안에 떠난 사용자를 뜻해요. 흔히 이탈률이라고 부르는 지표예요.

### 이전 데이터에는 Average Time on Page가 왜 없나요?
이 지표는 2026년 1월 20일부터 추적을 시작해서, 그 이전 데이터는 없어요.

### 여러 도메인을 추적할 수 있나요?
네, 각 도메인에 트래킹 스크립트를 설치하면 추적할 수 있어요.
