# 퍼널·웹사이트 분석의 파이 차트

퍼널 분석에 파이 차트가 추가됐어요. 퍼널, 웹사이트, 또는 특정 단계별로 페이지 조회수와 매출이 어떻게 나뉘는지 한눈에 볼 수 있고, 필터를 적용해 더 자세히 살펴볼 수도 있어요.

[동영상](https://www.youtube.com/embed/9BqC6THUUb8?&wmode=opaque)

파이 차트로 페이지 조회수와 매출을 눈으로 확인하면 성과를 추적하고 개선하기가 쉬워져요. 트래픽 전략과 전환 전략을 다듬는 데 활용해 보세요.

## 새로 생긴 기능

1. 파이 차트 보기
   - 페이지 조회수와 매출의 구성 비율을 파이 차트로 볼 수 있어요.
   - 날짜 범위, 특정 퍼널, 특정 웹사이트 같은 필터에 맞춰 차트가 바뀌어서 필요한 정보만 확인할 수 있어요.
2. 페이지 조회수와 매출 구성 보기
   - 퍼널이나 웹사이트별로 페이지 조회수와 매출이 어떻게 나뉘는지 빠르게 파악할 수 있어요.
   - 트래픽이 어디로 몰리고 매출이 어디서 나오는지 알 수 있어서, 전환율을 높이려면 어느 부분을 먼저 개선할지 정하기 좋아요.
3. 퍼널·웹사이트 비교
   - 여러 퍼널이나 웹사이트의 성과를 비교할 수 있어요.
   - 페이지 조회수와 매출이 가장 많은 곳을 확인하고, 효과가 큰 곳부터 개선할 수 있어요.
4. 단계별 분석
   - 퍼널이나 웹사이트 안의 개별 단계도 분석할 수 있어요.
   - 성과가 좋은 단계와 개선이 필요한 단계를 구분해서 전체 성과를 높이세요.

## 파이 차트 사용하기

1. 서브 계정 화면의 왼쪽 메뉴에서 **사이트**를 선택하세요.

   ![왼쪽 메뉴에서 사이트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036504989/original/BFIwn67QnnJLQP88LiXF4pKBP-lyVKOVyg.png?1731509292)

2. **분석** 탭을 선택하세요.

   ![분석 탭 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036505008/original/8-JbQArUTdAzNIUmY5GWhJOUOrZ9h1W0iw.png?1731509307)

3. **Page-View**(페이지 조회)와 **Sales**(매출) 섹션에서 꺾은선 그래프 아래의 파이 차트 카드를 찾으세요.

**날짜 범위**에서 기간을 지정하면 그 기간의 데이터만 분석할 수 있어요.
