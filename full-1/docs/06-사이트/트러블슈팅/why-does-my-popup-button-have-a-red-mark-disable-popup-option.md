# 팝업 버튼에 빨간 표시가 보일 때: 팝업 비활성화 옵션 끄기

퍼널이나 웹사이트의 팝업 버튼에 빨간 표시가 보이면 팝업 설정에서 **Disable Popup**(팝업 비활성화) 옵션이 켜져 있는지 확인하세요. 이 옵션을 끄고 저장하면 돼요.

## 해결 방법

1. 빨간 표시가 있는 팝업 버튼의 팝업 설정으로 이동해요.
2. **Disable Popup** 옵션을 꺼요.
3. 변경한 설정을 **저장**해요.
