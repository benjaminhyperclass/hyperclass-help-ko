# 사이트 프로젝트로 웹사이트 기술 SEO 점검하고 개선하기

**Site Projects**(사이트 프로젝트)는 웹사이트(도메인)의 상태와 성과를 한곳에서 확인하는 메뉴예요. 사이트의 권위도, 검색 유입, 백링크, 기술적 상태를 모아서 보여 줘요. 이 문서에서는 사이트 프로젝트를 만들고 쓰는 방법, 화면에 나오는 지표의 뜻, Google Search Console 데이터를 활용하는 방법, 사이트 모니터링과 감사에 크레딧이 쓰이는 방식을 안내해요.

---

## 사이트 프로젝트란?

사이트 프로젝트는 모니터링하고 최적화할 웹사이트(또는 특정 도메인·서브도메인) 하나를 뜻해요. 사이트 프로젝트를 추가하면 하이퍼클래스 SEO 도구가 아래 작업을 해요.

- 사이트의 도메인 파워(Domain Power)를 가져오거나 계산해요.
- 사이트의 백링크 수와 참조 도메인 수를 보여 줘요.
- 오가닉 트래픽 추이(검색을 통한 월 예상 방문 수)를 보여 줘요.
- 사이트 감사 결과를 요약한 사이트 상태(Site Health) 비율 또는 점수를 보여 줘요.
- 감사를 실행한 경우, 발견된 SEO 문제점 수를 보여 줘요.
- Google Search Console을 연결했다면 총 클릭 수나 키워드 같은 실제 검색 성과 데이터를 보여 줘요.

하이퍼클래스에서 **사이트 > SEO > Site Projects**로 이동하면 프로젝트가 위 항목을 열로 가진 행 하나씩으로 나열돼요. 모니터링 중인 각 사이트의 현황을 한눈에 볼 수 있어요.

**예시:**
"example.com"을 사이트 프로젝트로 추가하면 이런 값이 보일 수 있어요.
도메인 파워 45, 백링크 1.2K, 오가닉 트래픽 월 약 5,000, 사이트 상태 82%, 문제점 10.
이 사이트는 권위도가 보통이고 트래픽이 어느 정도 있으며, 기술 상태 점수도 괜찮지만 고칠 문제가 몇 가지 있다는 뜻이에요.

---

## 새 사이트 프로젝트 추가하기

1. 프로젝트를 만들어요. **Site Projects** 탭에서 **New Site Project**(새 사이트 프로젝트)를 클릭하세요. 버튼 이름이 **Add Site**(사이트 추가) 등으로 다를 수 있어요. 도메인 또는 URL을 묻는 폼이 나타나면 웹사이트의 홈페이지 URL(예: <https://www.example.com>)을 입력하세요.
2. Google Search Console(GSC)을 연결해요. 연결하면 좋지만 필수는 아니에요. GSC 데이터를 가져오려면 Google 계정을 연결해야 해요.
   1. 안내가 나타나면 **Google 연결**을 클릭하세요.
   2. Google 계정으로 로그인하고 접근을 허용하세요.
   3. 해당 도메인에 맞는 속성을 선택하세요. GSC에서 그 사이트의 소유권 인증이 끝나 있어야 해요.

   연결을 건너뛰어도 프로젝트는 추가할 수 있어요. 다만 GSC 성과 데이터는 볼 수 없어요. GSC는 나중에 **설정** 탭이나 고급 SEO 화면의 GSC 모듈에서 언제든 연결할 수 있어요.
3. 프로젝트를 초기화해요. 추가한 뒤에는 처음 데이터를 가져오는 데 시간이 조금 걸릴 수 있어요. 그다음 **Site Projects** 표에 새 사이트가 나타나요. 데이터를 아직 불러오는 중이거나 감사를 실행하지 않았다면 일부 지표가 "–"나 0으로 보일 수 있어요.
4. 사이트 세부 정보를 확인해요. 사이트 행을 클릭하거나 **보기**/**상세 정보** 버튼이 있으면 클릭하세요. 하이퍼클래스 화면에서는 최근 지표를 간단히 보여 주는 정도예요. 전체 기능과 자세한 분석은 **Launch Advanced SEO**(고급 SEO 실행)를 클릭하세요.
5. 사이트에 고급 도구를 사용해요. 고급 SEO 화면에서는 사이트 프로젝트가 상세 대시보드로 열려요. 사이트별로 여러 탭을 오가며 볼 수 있어요.

   - **개요**: 도메인 파워, 전체 키워드 수, 트래픽 추이 같은 핵심 지표를 보여 줘요.
   - **Organic Keywords**(오가닉 키워드): 사이트가 순위에 오른 키워드와 그 순위·검색량을 보여 줘요. GSC와 SearchAtlas 데이터로 채워져요.
   - **Backlinks**(백링크): 사이트의 백링크 구성을 보여 줘요. 참조 도메인 수, 앵커 텍스트, 주요 백링크가 나와요.
   - **Top Pages**(상위 페이지): 트래픽이 가장 많거나 가장 많은 키워드에서 순위에 오른 페이지를 보여 줘요.
   - **Site Audit**(사이트 감사) / **문제점**: 크롤 감사를 실행했다면 기술적 문제를 요약해 보여 줘요. 사이트 상태 점수와 문제 개수도 여기서 확인해요.
6. 지표를 해석해요. 데이터를 보고 사이트 상태를 파악하세요.
   - 도메인 파워가 높을수록 검색 순위에 유리한 사이트일 가능성이 커요.
   - 오가닉 트래픽 추이를 보면 SEO가 개선되고 있는지 가늠할 수 있어요.
   - 백링크 수와 품질은 오프페이지 SEO 수준을 짐작하게 해 줘요.
   - 사이트 상태와 문제점은 기술적으로 어디를 개선해야 하는지 알려 줘요.
   - GSC를 연결했다면 키워드별 실제 클릭 수, 노출 수, 평균 순위가 나와요. 어떤 검색어가 트래픽을 만드는지, 어떤 검색어를 챙겨야 하는지 찾는 데 큰 도움이 돼요.

## Google Search Console 연동 활용하기

하이퍼클래스 SEO 연동의 큰 장점은 Google Search Console(GSC) 성과 모듈이에요.
GSC를 연결하면 사이트가 순위에 오른 모든 키워드를 클릭 수, 노출 수, 클릭률(CTR), 평균 순위와 함께 자동으로 가져와요. 내 사이트의 키워드를 직접 입력할 필요가 없고, 데이터를 풍부하게 얻을 수 있어요.

- **순위에 오른 모든 키워드**: 직접 추적하지 않는 키워드라도 GSC에서 사이트당 상위 최대 10,000개까지 가져와요.
- **성과 지표**: 키워드마다 Google 검색에 얼마나 노출됐는지(노출 수), 클릭이 몇 번 발생했는지, 평균 순위가 몇 위인지 등을 볼 수 있어요.
- **페이지 데이터**: 페이지 단위 데이터도 가져와요. 노출 수가 많은 페이지부터 사이트당 최대 2,000개가 분석용으로 저장돼요.

**사용 방법:**
고급 SEO 화면에서 **Site Metrics > GSC Performance**(또는 비슷한 이름의 섹션)로 이동하세요. **Queries**(검색어), **Pages**(페이지), **Countries**(국가), **Devices**(기기) 등의 표와 차트가 있어요. 필터로 기간을 바꾸거나 특정 검색어를 찾을 수 있어요.

**예시:**
기간을 최근 3개월로 필터링하고 클릭 수 순으로 정렬하면 성과가 좋은 키워드를 볼 수 있어요. 순위로 필터링해서 5~15위에 있는 검색어를 찾을 수도 있어요. 이런 검색어는 개선해서 상위 3위 안으로 올릴 좋은 기회예요.

{% hint style="info" %}
**할당량 안내:** GSC 연동 자체는 다른 도구처럼 크레딧을 소모하지 않아요. 사이트를 연결하면 GSC 프로젝트 슬롯 1개를 쓰고(최대 4개 사이트), 연결 후 데이터는 자동으로 갱신돼요. 할당량 사용 방식은 [SEO 한눈에 보기: 검색 순위를 높이는 가이드](seo-a-guide-to-boosting-your-search-rankings.md)에서 확인하세요.
{% endhint %}

## 온페이지 SEO 감사 실행하기 (단일 페이지 분석)

사이트 프로젝트 안에서 웹사이트의 특정 페이지에 온페이지 감사를 실행할 수 있어요. 이 도구는 페이지 하나의 콘텐츠와 SEO 요소를 목표 키워드 기준으로 분석해서 콘텐츠 점수(Content Score)와 기술 점수(Technical Score)를 매기고 추천 사항을 알려 줘요. 랜딩 페이지나 블로그 글처럼 중요한 페이지를 최적화할 때 유용해요.

**온페이지 감사 사용 방법:**

1. 고급 SEO 화면에서 **콘텐츠 > On-Page Audit**(온페이지 감사)로 이동하세요. 하이퍼클래스의 사이트 프로젝트 화면에 페이지 감사로 바로 가는 링크가 있을 수도 있어요.
2. **URL 입력** 칸에 감사할 페이지의 URL을 입력하세요.
3. 그 페이지가 순위에 오르려는 목표 키워드를 하나 이상 입력하세요.
4. **Run Audit**(감사 실행)을 클릭하세요. 도구가 페이지를 크롤링한 뒤, 해당 키워드에서 상위에 오른 페이지들과 내 페이지의 콘텐츠와 HTML을 비교해요.
5. 잠시 처리한 뒤 아래 결과가 나타나요.

   - **Content Score**(콘텐츠 점수, 콘텐츠가 주제와 키워드를 얼마나 잘 다루는지)와 **Technical Score**(기술 점수, 온페이지 SEO의 기술 요소가 얼마나 잘 적용됐는지)
   - **콘텐츠**, **Technical**(기술), **Structure**(구조) 같은 카테고리로 나뉜 **추천 사항**
   - 내 페이지와 경쟁 페이지 평균의 비교
6. 필요한 부분을 페이지에서 수정하세요. 수정은 이 도구가 아니라 웹사이트나 CMS에서 해요. 그런 다음 감사를 다시 실행해서 점수가 올랐는지 확인하세요.

**할당량 사용:**
온페이지 감사는 분석한 페이지당 감사 크레딧 1개를 사용해요. 입력한 키워드 수와는 상관없어요. 감사 크레딧은 한 달에 최대 40개예요. 같은 페이지를 다시 감사하면 크레딧이 또 하나 쓰여요. 할당량 사용 방식은 [SEO 한눈에 보기: 검색 순위를 높이는 가이드](seo-a-guide-to-boosting-your-search-rankings.md)에서 확인하세요.

## 사이트 감사로 사이트 상태 모니터링하기

사이트 프로젝트에서는 단일 페이지 감사 외에 전체 사이트 감사도 할 수 있어요. 웹사이트 전체를 크롤링해서 기술적인 SEO 문제를 찾아 줘요.

**사이트 감사 실행 방법:**

1. 사이트 프로젝트를 방금 추가했다면 처음 크롤링이 자동으로 실행됐을 수 있어요.
2. **Launch Advanced SEO**를 클릭하고 **Site Audit**으로 이동하세요.
3. **New Audit Project**(새 감사 프로젝트)를 만드세요. 도메인을 입력하고 환경설정을 지정해요.

   - **Max Pages to Crawl**(크롤링할 최대 페이지 수): 예를 들어 5,000페이지
   - **Crawl Frequency**(크롤링 빈도): 수동 또는 예약
   - **제외 항목**: `/admin` 같은 폴더나 트래킹 URL을 건너뛰어요.
4. 감사를 시작하세요. 크롤러가 수십 가지 요소를 점검해요.
5. 감사가 끝나면 **Site Health Score**(사이트 상태 점수)와 유형별로 분류된 문제 목록이 나와요.

   - **오류**: 심각한 문제
   - **경고**: 중간 정도의 문제
   - **Notices**(알림): 가벼운 팁

**할당량 사용:**

- 페이지 1개를 크롤링하면 페이지 크레딧 1개가 쓰여요.
- 모든 사이트를 합쳐 한 달에 총 50,000페이지예요.
- 최대 4개 사이트까지 활성 상태로 감사할 수 있어요.
- 할당량 사용 방식은 [SEO 한눈에 보기: 검색 순위를 높이는 가이드](seo-a-guide-to-boosting-your-search-rankings.md)에서 확인하세요.

## AI 추천과 원클릭 수정

사이트 감사를 실행한 뒤에는 AI가 일부 온페이지 문제를 자동으로 수정해 줄 수 있어요.

**AI 추천 사용 방법:**

- 사이트 프로젝트를 추가한 뒤 **AI Recommendations**(AI 추천)로 이동하세요.
- 수정 제안 1건마다 크레딧 1개가 쓰여요. 한 달에 500개까지 쓸 수 있어요.
- 수정 대상에는 제목 업데이트, 대체 텍스트(alt 태그), 내부 링크 개선이 있어요.
- AI가 메타 설명을 만들어 주거나 본문 문단을 제안해 주기도 해요.

{% hint style="warning" %}
수정을 적용하기 전에 항상 내용을 검토하세요. 콘텐츠가 내 말투와 브랜드에 맞는지 확인해야 해요.
{% endhint %}

## 사이트 프로젝트와 감사 활용 팁

- 정기적으로 모니터링해요. 대시보드를 매주 확인하세요.
- GSC 데이터를 활용해요. 키워드 기회를 찾는 데 쓰세요.
- 크롤링 크레딧을 아껴요. 일정 예약과 제외 항목을 잘 활용하세요.
- AI 수정은 신중하게 써요. 승인된 사이트에만 적용하세요.
- 과거 진행 상황을 추적해요. 하이퍼클래스는 과거 SEO 데이터를 저장해 둬요.

## 문제 해결

- 사이트가 크롤링되지 않아요: robots.txt, 사이트맵, 최대 페이지 수 설정을 확인하세요.
- 데이터가 갱신되지 않아요: 고급 SEO 화면에서 새로고침해 보세요.
- GSC가 연결되지 않아요: 인증된 속성의 도메인과 정확히 같은 도메인인지 확인하세요.
- AI가 **사용 불가**로 표시돼요: 사이트 호환성과 슬롯 한도를 확인하세요.
- 지표가 다른 SEO 도구와 달라요: SEO 플랫폼마다 수치가 조금씩 다를 수 있어요.
