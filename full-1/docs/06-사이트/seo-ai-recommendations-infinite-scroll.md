# SEO AI Recommendations의 무한 스크롤

**AI Recommendations**(AI 추천)에서 표를 스크롤하면 다음 행이 계속 불러와져요. 적용 중인 필터와 정렬도 그대로 유지돼요. 규모가 큰 사이트에서 SEO 수정 항목을 검토할 때 시간을 줄일 수 있어요.

## 무한 스크롤이란?

AI Recommendations는 제목 태그, 메타 설명, 이미지 대체 텍스트 같은 페이지 내 문제를 찾아 한 번의 클릭으로 적용할 수 있는 수정안을 제안해요.

이번에 페이지를 넘기던 방식이 무한 스크롤로 바뀌었어요. 행이 필요할 때마다 불러와지기 때문에, 흐름이 끊기지 않고 한 화면에서 더 많은 제안을 검토할 수 있어요.

## 무한 스크롤의 장점

일상적인 SEO 점검에 바로 쓸지, 팀에 천천히 도입할지 정할 때 참고하세요.

- 쉬운 이동: **다음**·**이전** 버튼 없이 스크롤만으로 수정 항목을 훑어볼 수 있어요.
- 빠른 분류: 클릭을 줄이면서 많은 추천을 살펴보고 처리할 수 있어요.
- 정확한 개수: 문제 개수가 표, 필터 칩, 상세 패널에서 더 일관되게 표시돼요.
- 필터 반영: 새로 불러온 행에도 현재 필터와 정렬이 자동으로 적용돼요.
- 매끄러운 작업: 상세 패널을 열고 닫아도 보던 위치가 유지돼요.

## 문제 개수 표시 개선

여러 화면에서 진행 상황을 확인할 때 숫자가 서로 다르면 헷갈리기 쉬워요. 그래서 개수 표시를 다음과 같이 바꿨어요.

- 표 머리글, 필터 칩, 상세 패널에 표시되는 개수를 하나의 기준 데이터에서 가져와요.
- 필터를 적용하거나 정렬을 바꾸거나 스크롤해도 전체 개수가 현재 보고 있는 화면에 맞게 일관되게 표시돼요.

## 규모가 큰 사이트에서 빠르게 쓰는 팁

큰 감사 결과에서 수천 개의 수정 후보를 검토할 때는 아래 방법으로 화면 반응 속도를 유지하세요.

- 내용을 검토하지 않을 때는 오른쪽 미리보기/상세 패널을 닫아 두세요.
- 긴 목록을 처리하는 동안에는 무거운 브라우저 탭을 줄이세요.
- 화면이 버벅이면 필터로 보이는 결과 수를 줄이세요.

## 사용 조건

팀이 문제없이 기능을 쓸 수 있도록 아래 조건을 먼저 확인하세요.

- 서브 계정에서 하이퍼클래스 SEO가 켜져 있어야 해요.
- **Site Project**(사이트 프로젝트)가 추가되어 있어야 하고, 추천이 나타나려면 사이트 감사 결과가 있어야 해요.
- 호환성: WordPress 사이트와 외부 웹사이트에서는 AI Recommendations를 쓸 수 없어요.

## 무한 스크롤 사용하기

추천을 올바른 위치에서 필터와 정렬을 적용해 검토하는 순서예요.

1. 서브 계정에서 **사이트 > SEO > Site projects**(사이트 프로젝트 목록)로 이동한 뒤, 원하는 **Site Project**를 선택하세요.

   ![사이트 프로젝트 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055733741/original/F0iCFXopwmgyDrwTDCnedmjMx-TO-vj1AA.png?1760108260)
2. **AI Recommendations**를 여세요.
3. 아래로 스크롤하면 행이 계속 불러와져요. 필터와 정렬을 사용해 먼저 볼 항목을 좁히세요.

   ![스크롤하면 행이 이어서 불러와지는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055734702/original/l4vNn2Dv5k1GP6f5EntVUDU4eCrrOOsOcA.gif?1760108829)
4. 행을 클릭해 **Issue Details**(문제 상세)를 여세요.
5. 제안된 수정안을 확인한 뒤 **적용** 또는 **닫기**를 선택하세요.

## 자주 묻는 질문

### 무한 스크롤을 쓰려면 따로 켜야 하나요?
아니요. 무한 스크롤은 AI Recommendations에 기본으로 포함되어 있어요. 서브 계정에서 SEO가 켜져 있으면 자동으로 쓸 수 있어요.

### AI Recommendations는 크레딧이 어떻게 차감되나요?
수정 제안 1건당 크레딧 1개가 사용돼요. 월 최대 500개까지 사용할 수 있어요. 이미 있는 행을 보거나 스크롤하는 것만으로는 크레딧이 추가로 차감되지 않아요.

### 특정 페이지 번호로 바로 이동할 수 있나요?
무한 스크롤에는 페이지 번호가 없어요. 특정 URL이나 문제 유형을 찾으려면 필터나 검색창을 사용하세요.

### 아주 큰 감사 결과에서도 무한 스크롤이 잘 작동하나요?
행을 작은 단위로 나눠 불러오기 때문에 화면 반응 속도를 유지할 수 있어요. 느려지면 필터로 목록을 줄이고, 필요하지 않을 때는 상세 패널을 닫으세요.

### WordPress 사이트나 외부 웹사이트에서도 쓸 수 있나요?
아니요. AI Recommendations는 WordPress 사이트와 외부 웹사이트에서 쓸 수 없어요.
