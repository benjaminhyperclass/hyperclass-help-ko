# 채팅 위젯 사용자 지정 설정 한눈에 보기

위젯의 모양, 표시 위치, 방문자에게 보이는 내용, 동작 방식을 설정하는 방법을 정리한 문서예요. 채팅 위젯을 내 웹사이트에 맞게 꾸미고 싶을 때 참고하세요.

채팅 위젯 유형에 따라 쓸 수 있는 설정이 달라요. 예를 들어 라이브 채팅, SMS/이메일, WhatsApp, 올인원 채팅, Facebook, Instagram, 음성 AI는 사용자 지정 옵션이 서로 달라요.

[동영상](https://www.youtube.com/embed/HSyB5Fdwvrw?&wmode=opaque)

## 채팅 위젯 만들기 또는 열기

1. **사이트 > 채팅 위젯**으로 이동해요.
2. **신규**를 클릭해 채팅 위젯을 만들거나, 사용자 지정하려는 기존 위젯을 열어요.
3. 위젯 설정 화면을 열어요.
4. 새 위젯을 만든다면 설정하려는 채팅 위젯 유형을 선택해요. 선택한 유형에 따라 쓸 수 있는 사용자 지정 설정이 달라요.

   ![새 채팅 위젯 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079792929/original/B0f6IJvpCvC1lT12NwmHwC8avxxSF3oMWg.png?1788261529)

채팅 위젯 유형, 만들기, 설정, 설치 방법은 [채팅 위젯 시작하기](getting-started-with-chat-widget.md)와 [하이퍼클래스 채팅 위젯 설치하기](how-to-install-hyperclass-s-chat-widget.md)에서 자세히 확인할 수 있어요.

## 위젯

**위젯** 섹션에서는 채팅 위젯의 모양, 배치, 크기를 설정해요.

{% hint style="info" %}
채팅 위젯 유형에 따라 쓸 수 있는 설정이 달라요. 아래에서 설명하는 설정이 보이지 않으면 선택한 위젯 유형이 해당 설정을 지원하는지 확인하세요.
{% endhint %}

### 채팅 런처(Chat Launcher)

방문자가 위젯을 열 때 누르는 채팅 런처를 설정해요.

방문자가 대화를 시작하도록 유도하는 프롬프트 메시지를 함께 표시할 수도 있고, 런처만 표시할 수도 있어요.

**고정** 위젯은 방문자가 런처를 클릭해서 채팅을 여는 방식이에요. **임베드/인라인** 위젯은 페이지 콘텐츠 안에 바로 표시되기 때문에, 떠 있는 런처를 같은 방식으로 쓰지 않아요.

{% hint style="info" %}
**스타일 > 모양**에서 **동영상 아바타 활성화**를 켜면 **채팅 프롬프트**가 자동으로 꺼져요. 고정된 프롬프트 대신, 소리 없이 반복 재생되는 동영상 인사가 채팅 런처 옆에 나타나요. 채팅 런처와 기존 채팅 기능은 그대로 작동해요.
{% endhint %}

### 채팅 아이콘 선택

내 웹사이트와 브랜드에 가장 잘 어울리는 채팅 아이콘을 골라요.

![채팅 아이콘 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079790007/original/bG9QVMOa7jjrnw6APkeR5ZIKg90RIYQSog.jpeg?1788260425)

### 테마 사용자 지정

미리 정의된 테마를 고르거나, 위젯 색상과 스타일을 브랜드에 맞게 직접 바꿔요.

![테마 사용자 지정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079790042/original/_Xims96jGQVHus2-mPDIzZ-s003RMNy2CQ.png?1788260444)

### 첫 방문자와 재방문자 메시지

채팅 위젯을 처음 여는 방문자와 다시 찾아온 방문자에게 서로 다른 프롬프트 메시지를 보여 줄 수 있어요.

대화 라우팅은 그대로 두고, 방문자 상황에 맞는 인사말을 건넬 수 있어요.

### 아바타 이미지

상담원이나 지원팀의 아바타 이미지를 추가하면 방문자가 더 친근하고 알아보기 쉬운 상담을 경험해요.

{% hint style="info" %}
동영상 아바타는 **스타일 > 모양**에 있는 별도 설정이에요. 정지된 상담원·지원팀 아바타 이미지와 달리, 채팅 런처 옆에 짧은 동영상 인사를 반복 재생해요.
{% endhint %}

### 위젯 배치

채팅 위젯을 웹사이트의 어디에, 어떤 방식으로 표시할지 선택해요.

- **고정**: 페이지의 왼쪽 아래나 오른쪽 아래 같은 모서리에 위젯을 고정해요.
- **임베드/인라인**: 페이지 콘텐츠 안에 대화 화면 전체를 표시해요.

**임베드/인라인** 배치는 올인원 채팅, SMS/이메일, WhatsApp, Facebook, Instagram, 라이브 채팅, 음성 AI 위젯에서 쓸 수 있어요.

{% hint style="info" %}
동영상 아바타는 **고정** 배치에서만 지원돼요. **임베드/인라인** 위젯에서는 작동하지 않아요. 떠 있는 채팅 런처 옆에 동영상 아바타를 표시하려면 위젯이 **고정** 배치여야 해요.
{% endhint %}

![위젯 배치 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079790122/original/vieKQ1epIDSCV_MESgh9X2C20lpNrn4W2Q.png?1788260468)

### 동영상 아바타

동영상 아바타를 쓰면 채팅 런처 옆에 짧은 동영상 인사를 반복 재생해서 웹사이트 방문자를 더 친근하게 맞이할 수 있어요. 방문자는 재생을 조절하고, 동영상을 최소화하거나, 허용된 경우 닫을 수 있어요. 기존 채팅 런처, 채팅 창, 리드 수집 폼은 그대로 작동해요.

#### 동영상 요건

동영상 아바타를 켜기 전에 위젯과 동영상이 아래 요건을 충족하는지 확인하세요.

- **위젯 배치**: **고정**만 가능해요. 동영상 아바타는 **임베드/인라인** 배치를 지원하지 않아요.
- **지원 형식**: MP4, WebM
- 최대 동영상 길이: 60초
- 최대 파일 크기: 25MB
- **권장 해상도**: 약 480p

#### 동영상 아바타 켜고 설정하기

1. **위젯 배치**에서 **고정**을 선택해요.
2. **모양**에서 **동영상 아바타 활성화**를 켜요. 그러면 **채팅 프롬프트**가 자동으로 꺼져요.

   ![동영상 아바타 활성화 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083644619/original/5ukfjZNtv1QERMxljyPKgboakQ6PZIc93g.png?1792407236)
3. **동영상 선택**을 클릭하고, 지원하는 파일 크기와 길이 안에서 MP4 또는 WebM 동영상을 업로드해요.

   ![동영상 선택 및 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083644272/original/tsFUalVmyDa4xdhKR2iqlybS_7kWAQpaRQ.png?1792407090)
4. 업로드한 동영상의 길이, 파일 크기, 형식을 확인해요. 필요하면 화면의 컨트롤로 동영상을 교체하거나 삭제할 수 있어요.
5. **닫기 컨트롤 표시**를 설정해서 방문자가 동영상 아바타를 닫을 수 있게 해요.
6. **최소화 보기**에서 **환영 메시지 사용**을 설정해요. 최소화했을 때 위젯 환영 메시지 옆에 원형 동영상 썸네일이 표시돼요.
7. **다시 표시 시점**을 설정해요. 방문자가 동영상 아바타를 닫은 뒤 다시 나타나기까지 기다리는 시간이에요.
8. 채팅 위젯을 미리보기로 확인하고 **저장**을 클릭해요.

![동영상 아바타 설정 완료 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083644100/original/WFyBp7oap5h-kAKr91ZLD8YEenzwklwaUA.png?1792407008)

### 위젯 크기

**위젯 크기**를 **자동**으로 두거나, **사용자 지정**을 선택해 웹사이트 레이아웃에 맞는 너비와 높이를 설정해요.

사용자 지정 크기는 200px부터 설정할 수 있어요. 이전에 배치별로 정해져 있던 최소 크기 제한은 받지 않아요.

![위젯 크기 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079790174/original/OMnVzR6INPUwCUYa7havLbG95r1UVRQXYg.jpeg?1788260489)

**기본값으로 설정**을 누르면 현재 위젯 배치에 권장되는 크기로 되돌릴 수 있어요.

**고정**과 **Embedded Live Chat**(임베드 라이브 채팅) 사이를 전환하면, 사용자 지정 크기가 새로 선택한 배치의 권장 기본값으로 초기화돼요.

사용자 지정 크기 값이 비어 있거나 **자동**으로 되어 있으면 위젯은 기본 크기를 써요.

설정한 크기는 이전 최소값으로 자동으로 늘어나지 않고 그대로 적용돼요. 또한 위젯은 사용할 수 있는 컨테이너 공간을 넘지 않도록 표시가 조정돼요.

![위젯 크기 적용 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079790223/original/2kBoK6KUTGukutKs3zN5PRnuaCLvoFzf6Q.jpeg?1788260502)

## 채팅 창

**채팅 창** 설정에서는 방문자가 위젯을 열거나 사용할 때 보게 되는 정보를 설정해요.

선택한 채팅 위젯 유형에 따라 다음과 같은 설정을 쓸 수 있어요.

- 채팅 창 제목
- 인트로 메시지
- 문의 폼 필드
- 행동 유도 문구
- 이메일 또는 전화번호 수집 옵션
- 미리 입력된 메시지 내용
- 그 밖에 방문자에게 보이는 메시지

모든 옵션을 모든 채팅 위젯 유형에서 쓸 수 있는 것은 아니에요.

**채팅 창** 섹션에서는 방문자가 위젯을 열 때 보는 고정 콘텐츠를 설정해요. 채팅 위젯 유형에 따라 쓸 수 있는 필드가 달라요.

### 채팅 창 콘텐츠

일부 채팅 위젯 유형에서는 미리 입력된 **메시지** 필드를 쓸 수 있어요. 방문자가 보내기 전에 직접 고칠 수 있는 시작 메시지예요.

아래 위젯 유형에서 쓸 수 있어요.

- WhatsApp
- SMS/이메일
- 올인원 채팅
- 음성 AI

라이브 채팅은 기존처럼 자유롭게 입력하는 표준 메시지 방식을 그대로 써요.

자세한 설정 방법은 '채팅 위젯의 메시지 필드 사용자 지정' 문서를 참고하세요.

채팅 창 제목, 인트로 메시지, 이메일 옵션, 행동 유도 버튼처럼 방문자에게 보이는 콘텐츠를 설정해요.

![채팅 창 콘텐츠 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155030318955/original/PQYUAC5f8whizlJHA6l-5tn6yHkqvL0Qfw.jpeg?1722542586)

### 리디렉션 콜투액션

**리디렉션 콜투액션**을 켜면 채팅 안에 클릭할 수 있는 메시지가 표시되고, 방문자를 외부 웹사이트로 안내할 수 있어요.

이 옵션을 켜면 다음 두 가지를 입력해요.

- **리디렉션 텍스트**: 방문자에게 채팅에서 보여 줄 메시지를 입력해요.
- **웹사이트 리디렉션**: 이동할 웹사이트 URL을 입력해요.

**리디렉션 콜투액션**은 올인원 채팅 위젯에서 지원돼요.

![리디렉션 콜투액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081212964/original/Sr7RTDCLtv4OPA2CB5UTc-5WO4b4Z2y6kg.png?1789660440)

{% hint style="info" %}
대화 AI가 켜져 있을 때는 **리디렉션 콜투액션**을 권장하지 않아요. 방문자를 다른 곳으로 이동시키면 의도한 대화 흐름에 방해가 될 수 있어요.
{% endhint %}

### 사용자 상호작용 시 로드

**사용자 상호작용 시 로드**로 채팅 위젯이 웹사이트에서 언제 로드될지 정해요.

| **활성화됨** | **비활성화됨** |
| --- | --- |
| 방문자가 스크롤, 클릭, 터치 같은 상호작용을 하면 위젯이 로드돼요. 상호작용이 없으면 약 8초 뒤에 자동으로 로드돼요. | 위젯이 바로 로드돼요. |

### 규정 준수 고지 및 동의

**규정 준수 고지 및 동의**에서는 채팅 위젯 문의 폼과 함께 표시할 법적 고지와 동의 방식을 설정해요.

**채팅 위젯 > 채팅 창 > 추가 옵션 > 규정 준수 고지 및 동의**로 이동해요.

다음 옵션을 설정할 수 있어요.

- **법적 고지 표시**: 문의 폼 아래에 읽기 전용 고지를 표시해요. 방문자가 고지에 대해 따로 할 일은 없어요.
- **동의 체크박스 추가**: 방문자가 확인하거나 수신에 동의할 수 있도록, 원하는 동의 문구가 담긴 체크박스를 표시해요.
- **이 체크박스를 필수로 설정**: 방문자가 동의 체크박스를 선택해야 폼을 제출할 수 있어요. 동의를 선택 사항으로 두려면 이 설정을 꺼 두세요.
- **기본적으로 체크박스 미리 선택**: 폼이 열릴 때 동의 체크박스가 이미 선택된 상태로 표시돼요.

동의가 필수인데 방문자가 체크박스를 선택하지 않으면, 위젯에 "Please tick this box to continue."(계속하려면 이 상자에 체크해 주세요)라는 문구가 표시돼요.

설정을 바꾸면 실시간 미리보기에 바로 반영돼요. 설정을 마치면 **저장**을 클릭하세요.

고객 동의를 받고 개인정보 처리의 법적 근거를 기록하는 방법은 [고객 동의를 받고 개인정보 처리의 법적 근거를 기록하기](퍼널-웹사이트/how-to-get-customer-consent-or-track-legal-basis-to-process-your-lead-s-or-custo.md)에서 확인할 수 있어요.

![규정 준수 고지 및 동의 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079775159/original/Dz9SH29PgOBiwz7cauLT1Q0nKBM8hPUqyw.png?1788253887)

### 제출별 동의 내역 확인하기

채팅 위젯 폼을 제출하면 동의 정보가 연락처의 **활동 상세 정보**에 기록돼요.

**활동 상세 정보**에서 다음 내용을 볼 수 있어요.

- 방문자가 동의했는지 여부
- 동의가 필수였는지 여부
- 방문자에게 표시된 동의 문구

![연락처 활동 상세 정보의 동의 내역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079791918/original/3YCWCnhndHJlgdo_WbprnXXf6kje4IAz-g.png?1788261066)

### 기존 위젯과 기본 규정 준수 설정

- 기존 위젯은 빌더에서 열어 저장하기 전까지 현재의 모양과 동작을 그대로 유지해요.
- 기존 법적 문구는 해당하는 규정 준수 필드로 자동으로 옮겨져요.
- **A2P 등록**으로 만든 위젯은 기존 규정 준수 구성을 그대로 유지해요.
- 새 위젯은 법적 고지와 동의 체크박스가 켜진 상태로 시작해요. 필수 동의는 기본으로 꺼져 있어요.
- 기존 웹사이트에 넣은 설치 코드는 바꾸지 않아도 돼요.

{% hint style="info" %}
A2P로 생성된 채팅 위젯에는 잠긴 고지 문구, 필수 필드, 동의 설정이 포함될 수 있어요. 자세한 내용은 [채팅 위젯으로 사전 구성된 A2P 캠페인 등록하기](../15-전화-시스템/pre-built-a2p-campaign-widget-first-registration-flow.md)를 참고하세요.
{% endhint %}

## 자주 묻는 질문

### 채팅 위젯마다 다르게 설정할 수 있나요?

네. 채팅 위젯마다 지원하는 모양과 구성 설정을 각각 따로 정할 수 있어요.

### 모든 채팅 위젯 유형에서 사용자 지정 설정을 전부 쓸 수 있나요?

아니요. 선택한 채팅 위젯 유형에 따라 쓸 수 있는 옵션이 달라요.

### 떠 있는 위젯 대신 페이지 안에 삽입하는 위젯을 쓸 수 있나요?

네. 지원하는 채팅 위젯 유형에서는 **고정** 배치 외에 **임베드/인라인** 배치도 쓸 수 있어요.

### 위젯 디자인을 바꾸면 설치 코드도 새로 바꿔야 하나요?

일반적으로는 바꾸지 않아도 돼요. 저장한 구성 변경은 새 설치 코드 없이 기존 위젯에 반영돼요.

### 사용자 지정 크기가 초기화됐어요. 왜 그런가요?

**고정**과 **임베드/인라인** 배치를 바꾸면 새 배치에 권장되는 기본 크기로 되돌아갈 수 있어요.

### 방문자가 처음 보내는 메시지를 바꿀 수 있나요?

WhatsApp, SMS/이메일, 올인원 채팅, 음성 AI 위젯은 미리 입력해 두는 **메시지** 필드를 사용자 지정할 수 있어요. 라이브 채팅은 기존처럼 자유롭게 입력하는 메시지 상자를 써요.
