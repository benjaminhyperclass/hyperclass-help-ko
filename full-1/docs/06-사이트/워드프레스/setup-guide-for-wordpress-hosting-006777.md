# WordPress 호스팅 설정 가이드

WordPress 호스팅 설정 가이드는 사이트 만들기, 콘텐츠 가져오기, 도메인과 SSL 연결, 보안 로그 켜기, 사용자 관리, 리포트 확인까지 순서대로 안내해 주는 체크리스트예요. 새 계정이나 여러 지점의 온보딩을 같은 방식으로 맞추고 싶을 때 특히 유용해요.

## 설정 가이드란?

**Setup Guide**(설정 가이드)는 WordPress 호스팅을 구독하면 나타나는 기본 제공 체크리스트예요. 단계별 작업, 눈에 잘 띄는 버튼, 도움말 툴팁, 진행률 표시가 있어서 무엇을 끝냈고 다음에 무엇을 해야 하는지 바로 알 수 있어요.

선택 작업은 건너뛸 수 있어요. 모든 작업을 마치면 가이드가 자동으로 숨겨져서 대시보드가 깔끔하게 유지돼요.

## 주요 장점

- 일관성: 팀이 같은 방식으로 작업해서 더 빨리 성과를 낼 수 있어요.
- 명확성: 진행 상황을 쉽게 확인할 수 있어서 사용자가 헤매지 않아요.
- 빠른 시작: 사이트 게시와 성과 측정을 더 일찍 시작할 수 있어요.
- 맞춤 경험: 단계별로 안내하는 경험으로 신뢰를 쌓을 수 있어요.
- 안전한 마이그레이션: 기존 사이트를 매끄럽고 안전하게 옮길 수 있어요.

## 설정 가이드 진행 순서

사이트를 완전히 운영할 수 있도록 7단계를 차례로 안내해요.

### 1단계: 사이트 만들기

템플릿으로 시작하거나, 기존 설정을 복제하거나, 빈 상태로 설치할 수 있어요. 이 첫 선택이 사이트의 기반과 구조를 정해요.

![사이트 만들기 단계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075588013/original/AvmDthDVEGm7UGYLICHj9LCKYy-jwQA6Sw.png?1783584658)

### 2단계: 콘텐츠 가져오기 (사이트 마이그레이션)

이미 WordPress 사이트가 있다면 기존 콘텐츠, 미디어, 플러그인을 가져올 수 있어요.

![콘텐츠 가져오기 단계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075588014/original/ABwbswa9DgdcAeEIWPyqlnOxkAA4SrYwLA.png?1783584659)

### 3단계: 원클릭 WP 관리자 접속

하이퍼클래스 대시보드에서 WordPress 관리자 화면으로 바로 로그인할 수 있어요. 별도의 로그인 정보 없이 들어갈 수 있어서 관리가 더 빨라져요.

![WP 관리자 접속 단계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075588012/original/82QBrI3fafrfxmOmXGHjb4cmo6PXgcXZyA.png?1783584658)

### 4단계: 도메인 및 SSL 연결

대표 도메인을 연결하는 단계예요. Cloudflare를 통해 방문자에게 엔터프라이즈급 암호화와 보안을 제공해요.

![도메인 및 SSL 연결 단계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075588008/original/DsJ2UrcvtpYG9-DPPb9632DJwZZtrMGjkA.png?1783584658)

### 5단계: 보안 로그 켜기

로그를 켜고 확인하면 사이트의 변경 이력을 믿을 수 있게 기록하고 살펴볼 수 있어요. 문제를 일찍 찾아 해결하고 사이트를 안전하게 지키는 데 도움이 돼요.

![보안 로그 켜기 단계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075588011/original/2Su9gilRX3kW4JktdLROlITLJ_z6fpAd3Q.png?1783584658)

### 6단계: 사용자 권한 관리

역할과 책임에 맞게 보안을 유지하는 단계예요. 사이트 전체를 제어해야 하는 사람에게만 전체 관리자 권한을 주세요.

![사용자 권한 관리 단계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075588010/original/eCBUtM1i2cCD4OTOOAB96gT9yebh3urpSQ.png?1783584658)

### 7단계: 분석 보기

사이트를 공개한 뒤에는 **분석 > Visitors Report**(방문자 리포트)에서 **Uptime Monitoring**(가동 시간 모니터링)을 켜 보세요. 트래픽과 참여 분석을 확인할 수 있어요. 우선순위가 높은 데이터를 보여 주기 때문에 사이트를 최적화할 방향을 파악하기 쉬워요.

![분석 보기 단계 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075588009/original/S0OJTSUKvEdjndGv_RDcWpz1d47uMIiQQA.png?1783584658)

## 설정 가이드 사용 방법

1. 새로 만든 WordPress 사이트의 대시보드로 이동해요.
2. 가이드가 우선순위가 높은 작업을 알맞은 순서대로 자동으로 보여 줘요.
3. 현재 안내 창에서 **Continue**(계속)를 클릭해 남은 단계를 끝까지 진행하세요.

## 자주 묻는 질문

### 설정 가이드는 누가 볼 수 있나요?

에이전시 관리자와 WordPress 관리 권한이 있는 사용자가 가이드를 보고 사용할 수 있어요.

### 가이드를 마치거나 건너뛴 뒤에 다시 볼 수 있나요?

네, 다시 볼 수 있어요. 단계를 다시 확인하고 싶다면 대시보드에서 가이드를 켜거나 다시 열 수 있어요.

### DNS 전파 중에는 어떻게 해야 하나요?

DNS 변경 사항이 전 세계에 반영되는 데 몇 시간이 걸릴 수 있어요. 전파가 끝날 때까지 기다린 뒤에 SSL과 도메인 연결을 확인하세요.

### 마이그레이션을 하면 요금제 리소스(스토리지, 대역폭 등)가 사용되나요?

네, 가져온 콘텐츠는 요금제에 할당된 스토리지 한도에 포함돼요. 다만 대역폭은 제한이 없어서 사이트를 공개한 뒤에도 빠르고 안정적으로 운영할 수 있어요.
