# 하이퍼클래스 WordPress 플러그인 완벽 가이드

하이퍼클래스 플러그인을 WordPress 사이트에 연결하면 채팅 위젯, 퍼널, 커스텀 값을 WordPress 대시보드에서 바로 쓸 수 있어요. 이 문서에서는 플러그인을 설치하고 연결하는 방법과 주요 기능을 쓰는 방법을 안내해요.

복잡한 임베드 코드나 별도의 서드파티 연결 도구 없이도 하이퍼클래스 기능을 WordPress 사이트에 넣을 수 있어요.

## 연동 기능

이 플러그인을 쓰면 일반 WordPress 사이트에서 하이퍼클래스와 연결된 리드 확보 사이트를 운영할 수 있어요.

- 라이브 채팅 위젯 연동: 클릭 한 번으로 WordPress 사이트에서 하이퍼클래스의 **채팅 위젯**을 켤 수 있어요. 코드를 직접 넣지 않아도 돼요. 모든 채팅은 하이퍼클래스의 **대화** 탭으로 바로 들어와요.
- 퍼널 페이지 연동: 하이퍼클래스의 **퍼널**을 WordPress 도메인에서 운영할 수 있어요. 퍼널 단계를 WordPress 기본 페이지로 호스팅하므로 브랜드 경험이 하나로 이어지고 페이지도 더 빠르게 열려요.
- 동적 커스텀 값: 숏코드로 하이퍼클래스의 **커스텀 값**을 사이트 어디에서나 쓸 수 있어요. 하이퍼클래스에서 전화번호, 주소, 프로모션 내용을 바꾸면 WordPress 사이트 전체에 바로 반영돼요.
- 폼, 설문, 캘린더: 전용 WordPress 블록이나 간단한 숏코드로 하이퍼클래스의 폼, 설문, 캘린더를 페이지나 게시글에 넣을 수 있어요.

## 플러그인 설치 및 연결

설치 방법은 WordPress 사이트를 어디에서 호스팅하는지에 따라 달라요.

### 경우 A: 하이퍼클래스에서 호스팅하는 경우 (자동 설치)

하이퍼클래스 WordPress 호스팅을 쓰고 있다면 플러그인이 자동으로 설치되고 설정돼요.

1. WordPress 대시보드에 로그인하세요.
2. 왼쪽 메뉴에서 **하이퍼클래스** 탭을 찾으세요.

   ![WordPress 왼쪽 메뉴의 하이퍼클래스 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608242/original/NAtwxrxbNx8cROb3Bk9GIsYc6W3nsa25SQ.png?1783594105)

3. 연결 상태가 **Connected**(연결됨)로 표시되는지 확인하세요.

   ![연결 상태가 연결됨으로 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608244/original/xzW8SUfYK1OgZ34t5wr7C3QF_QgUAMrDMw.png?1783594105)

### 경우 B: 외부 WordPress 호스팅을 쓰는 경우

하이퍼클래스 밖에서 호스팅하는 WordPress 사이트라면 플러그인을 직접 설치하세요.

1. WordPress 대시보드에서 **플러그인 > 새로 추가**로 이동하세요.
2. 플러그인 저장소에서 "하이퍼클래스"를 검색하세요.

   ![플러그인 저장소에서 하이퍼클래스 검색](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608250/original/Wx1J9H7VBAvF0qYAtiNu621jJS0-8i2EDg.png?1783594106)

3. **Install Now**(지금 설치)를 클릭한 다음 **Activate**(활성화)를 클릭하세요.

   ![플러그인 설치 및 활성화 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608248/original/9tQo--37uUoyOndgqY_j6j_djfmTmx7GtQ.png?1783594106)

4. 하이퍼클래스 플러그인에서 **Sign in**(로그인)을 클릭하고 하이퍼클래스 계정으로 로그인하세요.

## 플러그인 기능 사용하기

플러그인을 연결하고 나면 WordPress 안에서 하이퍼클래스 기능을 쉽게 쓸 수 있어요.

### 1. 채팅 위젯 켜기

채팅 위젯을 쓰려고 HTML 스크립트를 사이트 헤더에 복사해 붙여넣지 않아도 돼요.

1. WordPress에서 하이퍼클래스 플러그인 설정으로 이동하세요.
2. **채팅 위젯** 설정을 찾으세요.
3. **Enable Chat Widget**(채팅 위젯 활성화) 체크박스를 선택하세요.
4. **저장**을 클릭하세요. 하이퍼클래스에서 설정해 둔 위젯이 사이트에 바로 나타나요.

### 2. WordPress 페이지에 퍼널 넣기

하이퍼클래스 퍼널을 WordPress 도메인에서 운영하면 URL 구조를 깔끔하게 유지할 수 있어요.

1. WordPress 메뉴에서 **하이퍼클래스 > 퍼널**로 이동하세요.
2. **새로 추가**를 클릭하세요.
3. 드롭다운 메뉴에서 하이퍼클래스의 퍼널과 퍼널 단계를 선택하세요.
4. WordPress 슬러그를 지정하세요. 예: yourdomain.com/special-offer
5. 변경사항을 저장하세요. 이제 퍼널이 WordPress 도메인에서 열려요.

### 3. 숏코드로 커스텀 값 사용하기

동적 숏코드를 쓰면 사이트의 데이터를 하이퍼클래스와 계속 똑같이 맞출 수 있어요.

- WordPress에서는 다음 형식의 숏코드를 쓸 수 있어요: `[lc_custom_value key="your_custom_value_key"]`
- 예시: 사업장 전화번호를 담은 **커스텀 값**의 키가 `{{custom_values.business_phone}}`이라면, WordPress 텍스트 편집기에 `[lc_custom_value key="business_phone"]`이라고 입력하세요.
- 하이퍼클래스에서 이 값을 바꾸면 WordPress 사이트의 텍스트도 자동으로 바뀌어요.

  ![WordPress 편집기에 입력한 커스텀 값 숏코드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075608241/original/gFIwHijk1IOGw51NPNsd8vLKKlgHLXVq8w.png?1783594105)

## 문제 해결 및 자주 묻는 질문

### 채팅 위젯을 켰는데 실제 사이트에 나타나지 않아요. 무엇이 문제일까요?

대부분 캐시 때문이에요. WP Rocket이나 W3 Total Cache 같은 WordPress 캐시 플러그인의 캐시를 지우세요. 호스팅 대시보드에서 서버 캐시도 지운 다음, 브라우저를 강력 새로고침(하드 리프레시)하세요.

### 커스텀 값 숏코드가 빈 텍스트로 나와요. 왜 그런가요?

다음 두 가지를 확인하세요. 먼저 하이퍼클래스의 **커스텀 값**에 실제로 데이터가 들어 있는지 확인하세요. 그다음 WordPress 숏코드에 중괄호 `{{ }}` 없이 키 이름을 정확하게 입력했는지 다시 확인하세요.

### 플러그인에 **연결 해제됨**으로 표시돼요. 어떻게 해결하나요?

최근에 하이퍼클래스에서 **API 키**를 다시 생성했다면 플러그인의 연결이 끊어져요. WordPress의 **하이퍼클래스** 탭으로 돌아가 이전 키를 지우고, 새로 생성한 **API 키**를 붙여넣은 다음 저장하세요.

{% hint style="info" %}
위 방법을 따라 해도 플러그인이 제대로 동기화되지 않으면 하이퍼클래스 고객지원에 문의하세요.
