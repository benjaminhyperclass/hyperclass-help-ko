# WordPress 플러그인 허브에서 하이퍼클래스 플러그인 받기

하이퍼클래스 WordPress 플러그인만 모아 둔 전용 허브를 소개해요. 허브에서 플러그인을 내려받는 방법, 받을 수 있는 플러그인, 허브를 쓰면 좋은 점을 알려 드려요.

하이퍼클래스 WordPress 플러그인은 [wordpress.leadconnectorhq.com](http://wordpress.leadconnectorhq.com)에서 받을 수 있어요. 최신 버전을 안정적으로 내려받고 다른 사람과 공유할 수 있는 전용 공간이에요. WordPress 공식 플러그인 디렉터리와 함께 쓸 수 있어요.

## WordPress 플러그인 허브란?

WordPress 플러그인 허브는 [wordpress.leadconnectorhq.com](https://wordpress.leadconnectorhq.com)에서 운영하는 전용 사이트예요. 하이퍼클래스 WordPress 플러그인의 최신 버전을 내려받아 쓰고 공유할 수 있어요. 기존 배포 경로를 대신할 수 있는, 늘 이용 가능한 또 하나의 경로예요.

허브는 WordPress 공식 플러그인 디렉터리와 나란히 운영돼요. 같은 플러그인 업데이트를 두 경로에서 모두 받을 수 있어서, 한쪽에 문제가 생겨도 이용이 끊길 위험이 줄어요.

현재 나와 있는 하이퍼클래스 WordPress 플러그인은 모두 허브에서 받을 수 있어요. 앞으로 플러그인이 더 추가될 예정이에요. 플러그인마다 바로 내려받는 링크와 버전 정보가 있어요.

## 허브를 쓰면 좋은 점

- 안정적인 접근: 모든 하이퍼클래스 WordPress 플러그인을 한곳에서 받을 수 있어요. 외부 플랫폼의 정책 변경이나 목록 삭제로 이용이 끊길 일이 없어요.
- 언제든 이용 가능: WordPress 공식 디렉터리에만 의존하지 않고 언제든 플러그인을 내려받을 수 있어요. 연동에 꼭 필요한 도구를 계속 쓸 수 있어요.
- 최신 버전 유지: 공식 디렉터리 업데이트에 맞춰 모든 플러그인의 최신 버전을 올려 둬요. 가장 최근 릴리스를 바로 받을 수 있어요.
- 쉬운 공유: 내려받는 링크를 고객이나 팀원에게 그대로 보낼 수 있어요. 여러 WordPress 사이트에 플러그인을 배포하기가 편해져요.
- 한곳에 모인 자료: 하이퍼클래스 WordPress 플러그인이 한 위치에 정리돼 있어요. WordPress 연동에 필요한 도구를 찾고 관리하기 쉬워요.

## 받을 수 있는 플러그인

허브에는 현재 하이퍼클래스 WordPress 플러그인 3개가 올라와 있어요. 앞으로 더 추가될 예정이에요.

- 플러그인 1: 하이퍼클래스
  - WordPress와 CRM을 이어 주는 핵심 플러그인이에요. 코드를 한 줄도 쓰지 않고 리드를 바로 동기화하고 커스텀 폼을 연동할 수 있어요.
- 플러그인 2: 하이퍼클래스 마이그레이터
  - 플랫폼 사이에서 데이터와 설정을 옮겨 줘요. 복잡한 이전 작업에서도 데이터를 잃지 않도록 만들어졌어요.
- 플러그인 3: Visibility
  - Visibility와 WordPress를 이어 주는 플러그인이에요. SEO 개선 제안과 AI 검색 최적화를 코드 없이 사이트에 반영할 수 있어요.

## 허브에서 플러그인 내려받기

다음 단계를 따르세요.

1. 브라우저에서 [**wordpress.leadconnectorhq.com**](https://wordpress.leadconnectorhq.com)에 접속하세요. 첫 화면에 받을 수 있는 플러그인과 버전 정보, 내려받기 버튼이 보여요.

   ![플러그인 허브 첫 화면](https://jumpshare.com/share/IbBzljKKwQu1Yg4i9NhZ+/Screen+Shot+2026-08-10+at+21.21.27.png)

2. 원하는 플러그인의 내려받기 버튼을 클릭하세요. 플러그인 파일이 .zip 파일로 컴퓨터의 기본 다운로드 위치에 저장돼요.

   ![플러그인 내려받기 버튼](https://jumpshare.com/share/Xt4l8lrrMJF4FKV4uiHj+/Screen+Shot+2026-08-10+at+21.39.15.png)

3. WordPress 관리자 화면에 로그인하세요.
4. **플러그인 > 새로 추가**로 이동하세요.
5. **Upload Plugin**(플러그인 업로드)을 클릭하세요.
6. 내려받은 .zip 파일을 선택하세요.
7. **Install Now**(지금 설치)를 클릭하세요.
8. 설치가 끝나면 **플러그인** 페이지에서 플러그인을 활성화하세요.

## 자주 묻는 질문

### WordPress 공식 디렉터리에서도 플러그인을 따로 받아야 하나요?

아니요. 허브에는 WordPress 공식 디렉터리와 같은 버전의 플러그인이 올라와 있어요. 어느 쪽에서 받아도 돼요. 허브는 공식 디렉터리와 나란히 운영하는 또 하나의 배포 경로예요.

### 허브에서 받은 플러그인도 자동으로 업데이트되나요?

업데이트 방식은 WordPress 사이트 설정에 따라 달라요. 허브에서 받은 플러그인은 WordPress 공식 디렉터리에서 설치한 플러그인과 똑같이 작동해요. 허브에서 최신 버전을 다시 받아 재설치해서 직접 업데이트할 수 있어요. WordPress의 기본 업데이트 방식으로 자동 업데이트를 설정할 수도 있어요.

### 허브에서 받은 플러그인을 고객에게 공유해도 되나요?

네. 플러그인 허브 주소(wordpress.leadconnectorhq.com)를 고객이나 팀원에게 공유하거나, 플러그인 파일을 내려받아 직접 전달할 수 있어요. 허브는 플러그인을 더 편하게 공유하고 배포하려고 만든 곳이에요.

### WordPress 공식 디렉터리에서 플러그인이 삭제되면 어떻게 되나요?

공식 디렉터리에서의 상태와 관계없이 허브에서는 모든 하이퍼클래스 플러그인을 계속 받을 수 있어요. WordPress 연동이 끊기는 일을 막고, 계속 이용할 수 있게 해 줘요.

### 허브의 플러그인은 WordPress 공식 디렉터리와 같은 버전인가요?

네. 허브는 공식 디렉터리와 나란히 운영돼서 두 곳에 같은 업데이트가 동시에 올라와요. 어느 쪽을 쓰든 최신 버전을 받을 수 있어요.

### 허브의 플러그인은 얼마나 자주 업데이트되나요?

허브는 WordPress 공식 디렉터리와 같은 시점에 업데이트돼요. 하이퍼클래스가 새 플러그인 버전을 출시하면 두 배포 경로에 동시에 올라와요.

### 앞으로 허브에 플러그인이 더 추가되나요?

네. 하이퍼클래스 WordPress 플러그인이 앞으로 더 추가될 예정이에요. 지금은 하이퍼클래스, 하이퍼클래스 마이그레이터, Visibility가 올라와 있고, 연동 플러그인이 더 나올 예정이에요.
