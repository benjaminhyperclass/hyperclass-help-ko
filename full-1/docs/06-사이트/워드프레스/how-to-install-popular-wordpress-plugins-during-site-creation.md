# WordPress 사이트를 만들 때 인기 플러그인 함께 설치하기

WordPress 사이트를 만드는 중에 많이 쓰는 플러그인을 골라 바로 설치할 수 있어요. 사이트를 만든 뒤 플러그인을 따로 찾아 설치하는 시간을 줄이고, 필요한 도구를 처음부터 갖춰 두세요.

[동영상](https://www.youtube.com/embed/YzuOv2HsCw4?&wmode=opaque)

---

## 플러그인 선택 기능이란?

사이트를 처음 만들 때 인기 있고 추천되는 WordPress 플러그인 목록에서 원하는 플러그인을 고르는 기능이에요. 이 목록은 하이퍼클래스에서 호스팅하는 WordPress 환경의 실제 사용 패턴을 바탕으로 골랐어요. 그래서 대부분의 사이트 제작에 바로 쓸 만한 플러그인이 담겨 있어요.

이 단계는 설정 마법사에 들어 있어요. 사이트를 만들면서 검증된 도구를 바로 설치할 수 있어서, 설정을 마친 뒤 플러그인을 찾아다니지 않아도 돼요.

---

## 플러그인 선택의 장점

유용하고 믿을 수 있는 플러그인으로 WordPress 사이트를 더 빠르게 꾸미고 최적화할 수 있어요.

- 실제 사이트의 사용 추세를 바탕으로 고른 플러그인 목록
- 자동 설치 및 활성화로 직접 할 일 없음
- 강제 설치 없음: 필요한 플러그인만 선택
- 설정을 마친 뒤에도 **플러그인** 화면에서 모든 플러그인을 직접 관리 가능
- 사이트를 공개한 뒤 플러그인을 찾을 필요가 없어 더 빠른 사이트 설정
- 선택 사항인 단계라서 고급 사용자와 초보자 모두에게 알맞음

---

## WordPress 사이트 설정 중 플러그인 선택하기

새 WordPress 사이트를 만들 때 아래 순서로 플러그인을 선택하세요.

1. 하이퍼클래스 계정에서 **사이트 > WordPress Dashboard**(WordPress 대시보드)로 이동하세요.
2. 작업 중인 사이트 옆에서 **Create Site**(사이트 만들기) 또는 **설정 완료**를 클릭하세요.
3. 설정 마법사를 따라 진행하다가 **Popular Plugins**(인기 플러그인) 단계에서 멈추세요.
4. 사용할 수 있는 플러그인 목록을 둘러보고, 포함하고 싶은 플러그인의 체크박스를 선택하세요.
5. **계속** 또는 **Finish Setup**(설정 마침)을 클릭해 사이트 만들기를 마치세요.

사이트 만들기가 끝나면 선택한 플러그인이 자동으로 설치되고 활성화돼요. 원하는 도구를 처음부터 바로 쓸 수 있어요.

---

## 설정 후 플러그인 관리하기

사이트를 공개한 뒤에도 플러그인 환경을 직접 관리할 수 있어요. WordPress 대시보드에서 필요에 따라 플러그인을 관리하고, 업데이트하고, 제거하세요.

플러그인을 관리하려면 이렇게 하세요.

- 하이퍼클래스의 **사이트** 페이지에서 **Open WordPress Dashboard**(WordPress 대시보드 열기)를 클릭하세요.
- WordPress 관리자 화면에서 **플러그인 > Installed Plugins**(설치된 플러그인)로 이동하세요.
- 여기서 다음 작업을 할 수 있어요.

  - 지금 쓰지 않는 플러그인은 **비활성화**하세요.
  - 필요 없거나 테스트용인 플러그인은 **삭제**하세요.
  - 추천 목록에 없는 다른 플러그인은 **설치**하세요.

설정 중에 플러그인 선택을 건너뛰었거나 나중에 바꾸고 싶어도, 이렇게 자유롭게 관리할 수 있어요.

## 자주 묻는 질문

### 기본으로 설치되는 플러그인이 있나요?

네. 하이퍼클래스 호스팅으로 새로 만든 WordPress 사이트에는 설정 중에 하이퍼클래스 플러그인이 자동으로 설치돼요. **Popular Plugins** 단계의 나머지 플러그인은 모두 선택 사항이며, 직접 선택한 경우에만 설치돼요.

### 사이트를 만든 뒤에 플러그인 선택을 바꿀 수 있나요?

네, 가능해요. WordPress **플러그인** 화면에서 언제든 플러그인을 설치하거나 제거할 수 있어요.

### 플러그인 목록은 어떤 기준으로 정하나요?

하이퍼클래스를 통해 호스팅되는 WordPress 사이트의 실제 사용 추세와 인기도를 바탕으로 정해요.

### 원하는 플러그인이 목록에 없어요. 어떻게 하나요?

설정을 마친 뒤 WordPress의 기본 플러그인 검색이나 업로드 기능으로 언제든 직접 설치할 수 있어요.

### 플러그인 선택 단계는 꼭 해야 하나요?

아니요. 이 단계는 완전히 선택 사항이에요. 건너뛰어도 아무것도 설치되지 않은 깨끗한 상태로 사이트 설정을 마칠 수 있어요.

## 다음 단계

- 설정을 마치면 WordPress 대시보드를 둘러보고, 설치한 플러그인을 사이트 목표에 맞게 설정하세요.
- 콘텐츠를 추가하고, 테마를 꾸미고, 성능을 최적화하세요.
- 하이퍼클래스에서 쓸 수 있는 고급 연동이나 자동화로 사이트 기능을 더 넓혀 보세요.
