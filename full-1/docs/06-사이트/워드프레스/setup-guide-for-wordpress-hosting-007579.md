# WordPress 호스팅 설치 가이드

하이퍼클래스에 기본으로 들어 있는 **설치 가이드**로 WordPress 호스팅을 더 빠르게 시작할 수 있어요. 사이트 만들기·가져오기, 도메인 연결, 보안에 도움이 되는 로그 켜기, 사용자 관리, 분석 확인까지 하나의 체크리스트로 안내해 줘요. 구독한 뒤 무엇부터 해야 할지 헤매는 시간을 줄여 주고, 설정부터 사이트 공개까지 차근차근 진행할 수 있어요.

## WordPress 호스팅 설치 가이드란?

**설치 가이드**는 WordPress 호스팅을 새로 구독하면 나타나는 앱 내 시작 체크리스트예요. 꼭 필요한 설정 작업을 알맞은 순서로 마칠 수 있게, 안내 버튼과 진행률 표시, 앱 내 안내를 함께 보여 줘요. 완전히 새로운 사이트를 만들 때도, 기존 WordPress 웹사이트를 옮겨 올 때도 다음에 무엇을 할지 쉽게 알 수 있어요.

**설치 가이드**는 사이트 생성, 마이그레이션, 도메인 연결, SSL 준비, 로그, 사용자 관리, 분석 같은 주요 설정 단계를 차례로 안내해요. 모든 설정 단계를 마치면 가이드는 자동으로 숨겨져요. 관련 메뉴는 **WordPress Dashboard**(WordPress 대시보드)에서 계속 열 수 있어요.

## 설치 가이드의 장점

설치 가이드를 쓰면 여러 메뉴를 일일이 찾아다니지 않고, 안내된 순서대로 따라가면서 놓치는 단계 없이 시작할 수 있어요. WordPress 사이트를 더 빨리 공개하고 쓰는 데 도움이 되는 작업을 먼저 보여 줘요.

- 단계별 안내: WordPress 호스팅을 구독한 뒤 설정 작업을 명확한 순서대로 따라갈 수 있어요.
- 빠른 시작: 다음에 할 일과 그 작업을 하는 위치를 보여 줘서 막막함을 줄여 줘요.
- 유연한 설정 흐름: 새 사이트 만들기와 기존 WordPress 사이트 가져오기를 모두 지원해요.
- 진행 상황 확인: 진행률 표시로 이미 마친 단계를 한눈에 볼 수 있어요.
- 한곳에서 다음 단계 이동: 도메인, 로그, 사용자, 리포트 같은 주요 설정 메뉴를 하나의 시작 화면에서 열 수 있어요.

## 설치 가이드 단계

설치 가이드의 각 단계는 WordPress 호스팅 설정에서 중요한 부분을 다음 할 일을 고민하지 않고 마치도록 도와줘요. 새 사이트를 시작하는 단계도 있고, 마이그레이션, 보안, 접근 관리, 성능 확인을 돕는 단계도 있어요.

### Create Site(사이트 만들기)

**Create Site**는 WordPress 호스팅에서 처음부터 시작하는 분이 가장 먼저 하는 단계예요. 웹사이트를 만들어 갈 공간이 생기고, 작업 방식에 따라 사이트 유형, 플러그인 선택, 서버 위치 같은 설정도 고를 수 있어요.

- 만들려는 사이트의 유형을 선택하세요.
- 안내에 따라 생성 과정을 계속 진행해서 WordPress 사이트를 만드세요.
- 사이트를 만드는 도중에 나오는 초기 설정 항목을 선택하세요.

### Import Your Existing Site(기존 사이트 가져오기)

**Import Your Existing Site**는 이미 WordPress 웹사이트가 있고 이를 하이퍼클래스 WordPress 호스팅으로 옮기고 싶을 때 쓰는 단계예요. 마이그레이션으로 시작하는 분을 위한 단계라서 기존 사이트를 직접 다시 만들지 않아도 돼요.

- 기존 WordPress 사이트를 옮기려면 가져오기 도구를 사용하세요.
- 마이그레이션 안내에 따라 현재 사이트를 하이퍼클래스로 옮기세요.
- 마이그레이션이 끝나면 가져온 사이트를 확인하세요.

관련 문서: "시작하기 - WordPress 사이트 마이그레이션"

### Log in to Your WP Admin Dashboard(WP 관리자 대시보드 로그인)

**Log in to Your WP Admin Dashboard**는 사이트 관리 작업을 하는 WordPress 관리자 화면으로 이동하는 단계예요. 콘텐츠 편집, 플러그인 관리, 설정 변경처럼 하이퍼클래스 호스팅과 연결된 WordPress 환경에서 하는 작업에 필요해요. 설정에 따라 싱글 사인온(SSO)으로 바로 접속할 수도 있어요.

- **설치 가이드**에서 WP 관리자 대시보드를 여세요.
- 관리자 권한으로 WordPress 사이트를 직접 관리하세요.
- **설치 가이드**로 돌아와 다음 단계를 이어가세요.

관련 문서: "WordPress: 싱글 사인온 관리자"

### Customize Your Domain and SSL(도메인 및 SSL 설정)

**Customize Your Domain and SSL**에서는 도메인 연결을 진행해요. 내 브랜드 도메인으로 WordPress 사이트를 공개하려면 꼭 필요한 단계예요. 도메인을 제대로 연결하고 인증하고 나면 SSL로 사이트를 안전하게 보호할 수 있어서, WordPress 호스팅에서는 도메인 설정과 SSL이 밀접하게 이어져 있어요.

- 사용자 지정 도메인을 추가하거나, 배정된 서브도메인 설정을 확인하세요.
- 도메인 연결에 필요한 DNS 변경을 마치세요.
- 도메인이 정상적으로 연결됐는지 확인하세요. 그래야 SSL이 발급되고 확인돼요.

관련 문서: "하이퍼클래스에서 WordPress 사이트에 도메인 추가하기", "WordPress: 도메인 커넥트 연동"

### Enable Access & Activity Logs(액세스 및 활동 로그 활성화)

**Enable Access & Activity Logs**를 켜면 WordPress 사이트에서 무슨 일이 일어나는지 더 잘 볼 수 있어요. 활동을 모니터링하고 문제를 찾아내며, 시간이 지나도 더 안전한 호스팅 환경을 유지하는 데 도움이 돼요.

- WordPress 사이트의 로그를 켜세요.
- 로그 화면에서 확인할 수 있는 활동 및 접속 정보를 살펴보세요.
- 로그로 중요한 작업을 모니터링하고, 예상치 못한 동작이 있으면 원인을 조사하세요.

관련 문서: "WordPress 액세스 및 활동 로그"

### Manage Users and Permissions(사용자 및 권한 관리)

**Manage Users and Permissions**에서는 사이트 접근 권한을 체계적이고 안전하게 관리해요. 알맞은 사용자에게 알맞은 권한을 주면 협업이 쉬워지고, 불필요한 권한을 주는 위험은 줄어들어요.

- 필요한 만큼 새 WordPress 사용자를 추가하세요.
- 편집자나 관리자처럼 알맞은 역할을 지정하세요.
- 사용자를 초대하거나 접근 수준을 바꾸기 전에 권한을 다시 확인하세요.

### 사이트 분석 및 리포트 살펴보기

**사이트 분석 및 리포트 살펴보기**에서는 설정을 마친 뒤 WordPress 사이트가 어떻게 운영되는지 확인할 수 있어요. 트래픽과 성능 데이터를 살펴보면 콘텐츠, 최적화, 사이트 운영에 관한 판단에 도움이 돼요. 더 자세한 리포트 내용은 WordPress 웹사이트 성능 리포트 문서에서도 확인할 수 있어요.

- **설치 가이드**에서 분석 또는 리포트 화면을 여세요.
- 확인할 수 있는 트래픽과 성능 인사이트를 살펴보세요.
- 리포트 데이터로 사이트 상태와 방문자 반응을 꾸준히 확인하세요.

관련 문서: "WordPress 웹사이트 성능 리포트"

## 설치 가이드 따라 하기

안내된 흐름은 어디서 시작하고 어떻게 진행하는지 알 때 가장 유용해요. 체크리스트를 순서대로 마치면 마이그레이션, 도메인 인증, SSL, 사용자 접근처럼 앞 단계에 의존하는 작업을 놓치지 않아요.

1. 하이퍼클래스에서 WordPress 호스팅을 구독하세요. 새로 구독하면 **설치 가이드**가 나타나요.
2. 가이드를 여세요.

   - 아직 만든 사이트가 없다면 **사이트 > WordPress Dashboard > 설치 가이드**로 이동하세요.
   - 이미 사이트가 있다면 **사이트 > WordPress Dashboard > Go to Site**(사이트로 이동) **> 설치 가이드**로 이동하세요.
3. 새 웹사이트를 만들 거라면 **Create Site**부터 시작하세요.
4. 기존 WordPress 웹사이트를 처음부터 다시 만들지 않고 옮기려면 **Import Your Existing Site**를 사용하세요.
5. **WP Admin Dashboard**를 열어 WordPress 사이트를 관리하세요.
6. **Domain and SSL**(도메인 및 SSL) 설정을 마치세요. 원하는 도메인과 보안 연결로 사이트를 쓸 수 있어요.
7. **Access & Activity Logs**를 켜서 작업과 사이트 활동을 확인할 수 있게 하세요.
8. 사용자를 추가하고 팀원에게 알맞은 권한 수준을 지정하세요.
9. **사이트 분석 및 리포트 살펴보기**에서 사이트 성능 모니터링을 시작하세요.
10. 체크리스트 항목을 모두 마칠 때까지 이어서 진행하세요. 모두 마치면 **설치 가이드**가 자동으로 숨겨져요. 주요 메뉴는 **WordPress Dashboard**에서 계속 열 수 있어요.

## 자주 묻는 질문

### WordPress 호스팅을 새로 구독할 때마다 설치 가이드가 나타나나요?
**설치 가이드**는 WordPress 호스팅을 새로 구독한 뒤 처음 설정을 마칠 수 있도록 나타나게 만들어졌어요.

### 모든 단계를 한 번에 끝내야 하나요?
아니요. 가이드에 진행률 표시가 있어서 여러 번에 나눠 진행해도 되고, 이미 마친 단계도 바로 확인할 수 있어요.

### 사이트 가져오기는 꼭 해야 하나요?
아니요. 가져오기는 하이퍼클래스로 옮기고 싶은 WordPress 사이트가 이미 있을 때만 필요해요. 완전히 새로운 사이트를 만든다면 **Create Site**로 시작하면 돼요.

### 가이드가 사라진 뒤에도 설정 메뉴를 열 수 있나요?
네. 가이드를 모두 마친 뒤에도 **도메인**, **사용자**, **분석** 같은 메뉴는 **WordPress Dashboard**에서 열 수 있어요.

### 도메인을 추가하면 SSL이 바로 적용되나요?
SSL은 도메인이 제대로 연결되고 인증돼야 적용돼요. 실제로는 DNS와 인증 상태에 따라 SSL이 발급되고 확인되는 시점이 달라져요.

### 액세스 및 활동 로그는 어떤 용도로 쓰나요?
사용자 작업과 접근 관련 활동을 추적해서 변경 사항을 모니터링하고, 문제를 조사하고, 사이트 보안을 높이는 데 쓰여요.

### 사이트를 함께 관리할 사용자를 더 추가할 수 있나요?
네. **설치 가이드**에 사용자 및 권한 단계가 있어서 WordPress 사용자를 추가하고 편집자나 관리자 같은 알맞은 역할을 지정할 수 있어요.

### 분석과 리포트에는 언제부터 쓸 만한 데이터가 보이나요?
시간이 지나 트래픽과 사이트 활동이 쌓일수록 리포트가 더 유용해져요. 설정을 마친 뒤에는 제공되는 분석을 정기적으로 확인하면서 성능 추세를 살펴보세요.
