# 한 서브 계정에서 WordPress 사이트 여러 개 운영하기

이제 서브 계정 하나에서 WordPress 사이트를 여러 개 추가하고 관리할 수 있어요. 사이트마다 서브 계정을 따로 만들 필요가 없어요. 이 문서에서는 새로 바뀐 내용과 시작하는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/B9btHNs7NXA?&wmode=opaque)

## 새로운 기능

### 1. 여러 사이트를 한곳에서 관리

- 통합 관리: 서브 계정 하나에 WordPress 사이트를 여러 개 추가하고 관리할 수 있어요. 서브 계정을 따로 만들지 않아도 되니, 모든 사이트를 한곳에서 효율적으로 관리할 수 있어요.

  ![서브 계정 하나에서 여러 WordPress 사이트를 관리하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033980247/original/BfjihHVkQKfuHOBRZPr1UWXjPIf8zLbxvw.jpeg?1727901362)

- 간편한 사이트 전환: 서브 계정 대시보드에서 WordPress 사이트 사이를 바로 오갈 수 있어요. 빠르고 직관적이에요.

  ![서브 계정 대시보드에서 사이트를 전환하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033980248/original/gtZvqz1FdDdlXwK6eDFgGjkRhlDxcY0BUw.jpeg?1727901362)

### 2. 청구·구독 추적 개선

- 정확한 청구: 청구·구독 시스템이 업그레이드되어, 서브 계정에 속한 웹사이트별로 요금을 따로 추적하고 관리해요. 청구 과정이 매끄럽고 투명해져요.
- 업셀 현황 확인: 에이전시 소유자는 서브 계정 안에서 업셀을 적용한 사이트와 적용하지 않은 사이트가 각각 몇 개인지 쉽게 볼 수 있어요. 수익을 늘릴 기회를 찾는 데 도움이 돼요.

![사이트별 청구·구독 추적 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033980246/original/1f3sgfjsJo4XVn6tf4fnctMJPn_UKOuzfA.jpeg?1727901362)

### 3. 더 편해진 화면 구성

- 서브 계정 대시보드를 새로 디자인해서 더 정돈되고 쓰기 쉬워졌어요.
- 사이트를 관리하고 주요 기능에 들어가는 과정이 더 간단해졌어요.

## 시작하는 방법

### 새 대시보드 열기

- **사이트 > WordPress > All Sites**(전체 사이트)로 이동하면 새 대시보드가 열려요.

### 사이트 만들고 관리하기

- 새 사이트 만들기: 필수 정보를 모두 입력하고 결제를 마치면 사이트가 만들어져요.
- 사이트 전환하기: 사이트 정보 화면에서 다른 사이트로 쉽게 바꿀 수 있어요.
