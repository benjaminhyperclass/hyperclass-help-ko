# 사용이 제한된 WordPress 플러그인 목록

하이퍼클래스에서 WordPress 사이트를 운영할 때 사용이 제한되는 플러그인 목록이에요. 플러그인을 설치하기 전에 이 목록에 있는지 확인해 보세요.

WordPress 사이트의 안정성, 성능, 보안을 높이기 위해 계속 노력하고 있어요. 그런데 일부 플러그인은 하이퍼클래스에 이미 있는 기능을 똑같이 만들려고 하거나, 하이퍼클래스 환경과 잘 맞지 않아요.

시스템 관리자가 플러그인에서 문제를 발견하면 해당 플러그인을 제한 플러그인으로 분류해요. 이런 플러그인은 성능 문제를 일으키거나 웹사이트가 원활하게 동작하는 것을 방해할 수 있기 때문이에요.

아래는 현재 하이퍼클래스에서 사용이 제한된 WordPress 플러그인 목록이에요. 플러그인에서 문제가 확인될 때마다 이 목록을 계속 업데이트해서, 웹사이트를 더 안전하고 안정적인 환경으로 유지하고 있어요.
