# 마이그레이션 화면 비교: 에이전시가 보는 화면과 서브 계정이 보는 화면

WordPress 호스팅 대시보드의 마이그레이션 옵션은 에이전시와 서브 계정에 서로 다르게 보여요. 이 문서에서는 각자 어떤 옵션이 보이는지, 왜 다른지 설명해요.

에이전시 관리자는 **WordPress Hosting**(WordPress 호스팅) 대시보드에서 마이그레이션 옵션을 전부 볼 수 있어요. 에이전시만 쓸 수 있는 프리미엄 서비스인 **White-Glove Migration Assistance**(전문가 마이그레이션 지원)도 여기에 포함돼요.

## 에이전시가 보는 화면

에이전시 관리자에게는 마이그레이션 옵션 3개가 모두 보여요.

1. **Effortless Migration with our Plugin**(플러그인으로 간편하게 마이그레이션)
   하이퍼클래스 플러그인으로 한 번의 클릭만으로 빠르게 마이그레이션해요.
2. **Manual Migration Made Simple**(간단한 수동 마이그레이션)
   All-in-One Migration 플러그인으로 `.wpress` 파일을 업로드해요.
3. **White-Glove Migration Assistance**(전문가 마이그레이션 지원) *(에이전시 전용)*
   **폼 제출**로 요청하면 WordPress 전문가가 마이그레이션을 대신 진행해 줘요.

✅ 이 옵션들은 에이전시 관리자에게만 보여요. 고객이나 고객의 서브 계정에는 보이지 않아요.

에이전시용 안내는 다음 문서와 창구에서 확인할 수 있어요.

- 에이전시용 마이그레이션 가이드: WordPress 호스팅 단계별 마이그레이션 가이드
- 에이전시용 고객지원 문의: 하이퍼클래스 고객지원

## 서브 계정이 보는 화면

서브 계정에는 기본 마이그레이션 옵션 2개만 보여요.

1. **Effortless Migration with our Plugin**
2. **Manual Migration Made Simple**

**White-Glove Migration Assistance** 옵션은 서브 계정에 보이지 않아요. 서브 계정에는 빠져 있는 기능이 있다는 표시나 안내 문구도 나오지 않아요.

덕분에 화이트라벨 환경이 그대로 유지돼요. 고객은 에이전시가 뒤에서 받는 지원이 있다는 사실을 알 수 없어요.

서브 계정용 안내는 다음 문서에서 확인할 수 있어요.

- 서브 계정용 마이그레이션 가이드: WordPress 호스팅 단계별 마이그레이션 가이드

## 옵션이 서로 다른 이유

**White-Glove Migration**은 에이전시 차원에서 관리하고 유연하게 운영하도록 만든 프리미엄 혜택이에요. 에이전시 관리자에게만 열어 두면 서브 계정이 헷갈리지 않고, 에이전시의 화이트라벨 서비스도 지킬 수 있어요.

## 서브 계정 사용자를 안내해야 할 때

고객이 마이그레이션하는 것을 도와야 한다면 이렇게 할 수 있어요.

- 간단하게 진행할 수 있는 **플러그인 방식 마이그레이션**을 추천해요.
- 또는 **White-Glove** 옵션을 사용해서 고객 대신 에이전시가 직접 마이그레이션을 맡아요.
