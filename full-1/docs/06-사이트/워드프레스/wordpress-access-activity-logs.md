# WordPress 접근 로그와 활동 로그 확인하기

WordPress 관리 패널의 **Access & Activity Logs**(접근 및 활동 로그) 기능을 소개하는 문서예요. 사용자 활동과 접근 요청을 추적하고 싶을 때 참고하세요.

[동영상](https://www.youtube.com/embed/Q4UQFi9ICtg?&wmode=opaque)

하이퍼클래스 플랫폼의 WordPress 관리 패널에서 **Access & Activity Logs** 기능을 쓸 수 있어요. 사용자 활동을 추적하고, 접근 요청을 살펴보고, 사이트 관리 내역을 투명하게 확인할 수 있어요. 이 로그는 보안 강화, 문제 해결, 책임 소재 확인에 도움이 되는 상세 정보를 담고 있어요.

# 주요 기능 개요

## 활동 로그(Activity Logs)

- 목적: 하이퍼클래스 WordPress 계정이나 특정 사이트에서 이루어진 모든 작업을 확인해요.
- 기록되는 정보
  - 사용자 식별: 누가 각 작업을 했는지 볼 수 있어요.
  - 타임스탬프: 작업이 언제 이루어졌는지 정확히 알 수 있어요.
  - 작업 상태: 작업이 성공했는지, 오류가 났는지 확인할 수 있어요.
- **사용 사례**: 사이트 설정이 바뀐 내역을 추적하거나 사용자 활동을 모니터링할 때 알맞아요.

### 활동 로그 사용 방법

1. **WordPress Dashboard**(WordPress 대시보드) > **Manage Site**(사이트 관리)로 이동하세요.
2. 하위 메뉴에서 **Activity Logs**(활동 로그)를 선택하세요.
3. **활성화**를 선택하세요.
4. **시간 범위 선택**에서 원하는 범위를 고르세요. 로그를 활성화한 뒤 선택한 시간이 지나면 로그가 표시되기 시작해요.

![활동 로그 활성화와 시간 범위 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036265511/original/GUpi6xqLctEvqluSbov8Uq8Z0t33y3ZLNQ.png?1731088535)

## 접근 로그(Access Logs)

- 목적: 서버로 들어온 모든 요청을 모니터링해서 트래픽 패턴과 사용자 행동을 파악해요.
- 기록되는 정보
  - 요청된 URL: 접근한 URL을 추적할 수 있어요.
  - 클라이언트 IP 주소: 요청이 어디에서 왔는지 확인할 수 있어요.
  - 타임스탬프: 각 요청의 정확한 시간을 알 수 있어요.
  - HTTP 상태 코드: 응답 상태를 확인할 수 있어요(예: 성공은 200, 찾을 수 없음은 404).
  - 응답 크기: 클라이언트에 전송된 데이터 크기를 알 수 있어요.
- **사용 사례**: 사이트 트래픽을 분석하고, 평소와 다른 접근 패턴을 찾고, 사이트 성능을 최적화할 때 좋아요.

### 접근 로그 사용 방법

1. **WordPress Dashboard**(WordPress 대시보드) > **Manage Site**(사이트 관리)로 이동하세요.
2. **분석** > **Visitors Report**(방문자 리포트)를 선택하세요.
3. 화면 맨 아래로 스크롤해서 **Access Logs**(접근 로그)를 확인하세요.

![방문자 리포트 하단의 접근 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036265527/original/0woR1jXOxQN6k1pinuFlN6wA9VAITwoeyQ.png?1731088560)

## 감사 로그

- 목적: WordPress 로그를 하이퍼클래스 플랫폼에 있는 기존 **감사 로그**와 통합해서 사용자 활동을 한곳에서 추적해요.
- 기록되는 정보
  - 사용자 작업: WordPress 구매, 구독 취소, 사이트 생성, 사이트 삭제 같은 중요한 작업을 한 사용자를 추적할 수 있어요.
- **사용 사례**: WordPress 계정에서 일어난 주요 이벤트의 감사 기록이 분명하게 남아서 책임 소재를 확인하기 쉬워요.

### 감사 로그 사용 방법

1. 왼쪽 메뉴에서 **설정**으로 이동하세요.
2. 맨 아래까지 스크롤한 다음 **감사 로그**를 선택하세요.

# 문제 해결과 활용 팁

- 로그가 보이지 않아요: 로그를 볼 수 있는 권한이 있는지 확인하세요.
- 의심스러운 활동이 발견됐어요: 즉시 비밀번호를 변경하고 서버 접근 제어를 검토하세요.
- 로그에 오류가 많이 보여요: 로그를 보고 오류를 일으키는 플러그인이나 잘못 설정된 항목을 찾아보세요.
