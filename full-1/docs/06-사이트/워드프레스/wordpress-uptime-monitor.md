# WordPress 업타임 모니터

WordPress 업타임 모니터는 하이퍼클래스의 WordPress 호스팅 화면에서 사이트가 열리는지, 응답 시간이 어떻게 변하는지, 장애가 언제 있었는지를 실시간으로 보여 주는 기능이에요. 이 문서에서는 기능의 역할, 켜는 방법, 데이터를 읽는 방법을 안내해요.

## WordPress 업타임 모니터란?

WordPress 업타임 모니터는 호스팅 중인 WordPress 사이트마다 주기적으로 점검해서 사이트가 열리는지 확인하고 응답 시간을 기록해요. 다운타임과 복구도 시각과 원인과 함께 기록해요. 그래서 하이퍼클래스를 벗어나지 않고도 팀이 원인을 조사하고, 문제를 해결하고, 안정성을 보고할 수 있어요.

- 호스팅 중인 WordPress 사이트의 접속 상태와 성능을 계속 점검해요.
- 상태/헬스 카드, 응답 시간 분석, **최근 이벤트**를 한 화면에서 보여 줘요.
- 호스팅, 백업, WordPress 도구를 관리하는 곳에서 모니터링까지 한 번에 할 수 있어요.

## 업타임 모니터의 장점

- 빠른 장애 대응: 시간순 이벤트 기록과 상태 표시로 장애를 바로 알아챌 수 있어요.
- 고객사와 투명한 소통: 업타임 이력과 성능 정보를 공유해 신뢰를 쌓고 안정성을 증명할 수 있어요.
- 원인 중심 대응: 접근 금지, 서버 제한 같은 이벤트 사유를 보고 어떤 문제부터 고칠지 정할 수 있어요.
- 한 곳에서 확인: 업타임, 성능, 복구 내역을 하이퍼클래스 호스팅 화면에서 모두 볼 수 있어요.
- 성능 파악: 최근 기간의 최소, 평균, 최대 응답 시간을 비교해 현재 상태를 가늠할 수 있어요.

## 상태 및 헬스 카드

상태 카드는 전체 상황을 한눈에 보여 줘요. 빠르게 확인하거나 매일 아침 팀 점검을 할 때 유용하고, 더 자세히 살펴볼지 판단하는 데 도움이 돼요.

- **Operational Status**(운영 상태): 사이트에 지금 접속할 수 있는지 보여 줘요.
- **Average Uptime**(평균 업타임): 선택한 기간 동안 사이트가 얼마나 열려 있었는지 요약해 보여 줘요.
- **Last Health Check**(마지막 상태 점검): 모니터가 실제로 점검하고 있는지, 마지막으로 점검한 시각이 언제인지 확인할 수 있어요.

## 응답 시간 분석

응답 시간 추이를 보면 사이트가 완전히 멈추기 전에 이상 징후를 알 수 있어요. 서버 응답 지연, 지역별 지연, 리소스 병목 같은 문제가 해당돼요.

- 최근 24시간의 최소, 평균, 최대 **응답 시간**을 확인할 수 있어요. 더 긴 기간을 선택할 수 있으면 바꿔서 성능을 비교해 보세요.
- 수치가 갑자기 튄 구간이 있으면 원인을 살펴보세요. 플러그인 업데이트, 테마 변경, 트래픽 급증, 서버 리소스 부족 등을 확인해 볼 수 있어요.
- 호스팅 지역 안내와 함께 보면 방문자 쪽 네트워크 지연을 줄이는 데 도움이 돼요.

![응답 시간 분석 그래프](https://jumpshare.com/share/a9GKL9Uc6RZeaG2J7Nn4+/image-2.jpg)

## 최근 이벤트

**최근 이벤트**는 다운타임과 복구 내역을 시간순으로 기록한 목록이에요. 시각과 사유가 함께 나와서 팀이 문제를 더 빨리 분류할 수 있어요.

- 다운타임과 자동 복구 기록을 실시간으로 볼 수 있어요. 각 기록에는 시각과 원인(예: 접근 금지, 서버 제한)이 함께 남아요.
- 문제가 언제 시작됐고, 언제 복구됐고, 무엇 때문일 가능성이 큰지 이벤트로 확인해 보세요.
- 업무 인수인계나 고객사 보고 때 유용해요. 시각과 메모를 복사해 티켓이나 리포트에 붙여 넣을 수 있어요.

## 업타임 모니터 사용 방법

아래 순서대로 따라 하면 업타임 모니터를 켜고 쓸 수 있어요.

1. **사이트 > WordPress**로 이동하세요.

   ![사이트 > WordPress 메뉴 화면](https://jumpshare.com/share/U6fCpCjcEj00CEMGMxRp+/Screen+Shot+2025-11-11+at+7.07.25+PM.png)

2. 모니터링할 사이트에서 **Manage Website**(웹사이트 관리)를 클릭하세요.

   ![Manage Website 버튼 화면](https://jumpshare.com/share/jB3ioQgJekLaaMnDKfWQ+/Screen+Shot+2025-11-11+at+7.11.31+PM.png)

3. **분석 > Visitors Report**(방문자 리포트)를 여세요.

   ![분석 > Visitors Report 화면](https://jumpshare.com/share/T8VS4coIPAHy0BsZmhOg+/Screen+Shot+2025-11-11+at+7.17.38+PM.png)

4. **Uptime Monitor**(업타임 모니터) 토글을 찾아 켜세요. 그러면 모니터링이 시작돼요.

   ![Uptime Monitor 토글을 켜는 화면](https://jumpshare.com/share/6q8j4MXzlxiJyBhNOcNI+/GIF+Recording+2025-11-11+at+7.19.58+PM.gif)

## 자주 묻는 질문

### 업타임 모니터가 이메일, SMS, 앱 알림으로 알려 주나요?
아니요. 첫 출시 버전은 앱 안에서 확인하는 데 초점을 맞췄어요.

### 어떤 URL을 점검하나요? 바꿀 수 있나요?
호스팅에 설정된 사이트의 기본 엔드포인트를 점검해요.

### 시각은 어느 시간대 기준인가요?
계정과 앱 설정을 따라요. 외부 도구의 기록과 비교하기 전에 서브 계정의 시간대를 먼저 확인하세요.
