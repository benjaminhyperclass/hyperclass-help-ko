# 템플릿으로 새 WordPress 사이트 만들기

WordPress 사이트는 처음부터 새로 만들 수도 있고, 기존 사이트를 복사해서 만들 수도 있어요. 템플릿에서 시작할 수도 있어요. 이 문서에서는 템플릿 라이브러리에서 템플릿을 골라 새 WordPress 사이트를 만드는 방법을 안내해요.

## WordPress 사이트 템플릿이란?

WordPress 사이트는 하이퍼클래스 웹사이트/퍼널을 대신해서 쓸 수 있는 방법이에요. 하이퍼클래스에 기본으로 들어 있는 사이트 빌더와 호스팅 대신, WordPress를 통째로 설치해서 쓸 수 있어요. 이렇게 쓰려면 하이퍼클래스의 WordPress 호스팅 요금제에 가입해야 해요. 가입하면 다른 WordPress 호스팅 사이트처럼 쓸 수 있어요.

새 WordPress 사이트를 만들 때 **템플릿 라이브러리**에서 미리 만들어 둔 WordPress 사이트 중 하나를 고를 수 있어요. 선택한 템플릿으로 사이트를 설정하는 동안에는 잠시 기다려야 해요.

## WordPress 사이트 템플릿을 쓰면 좋은 이유

WordPress 사이트 템플릿을 쓰면 보기 좋고 기능도 갖춘 WordPress 사이트를 거의 바로, 손이 거의 가지 않게 열 수 있어요. 내 사이트에 맞게 꾸미기만 하면 돼요.

## 템플릿으로 WordPress 사이트 설정하기

1. 서브 계정에서 **사이트 > WordPress**로 이동한 다음 **+ Create Site**(사이트 만들기)를 선택하세요.
2. **템플릿 선택**을 선택하세요.
3. 템플릿을 둘러보고 하나를 선택하세요.
4. 선택한 템플릿이 맞는지 다시 확인하고, 새 사이트의 이름을 입력하세요.
5. **진행률 표시줄**을 보면서 새 사이트가 라이브 상태가 될 때까지 기다리세요.
