# WordPress 사이트 메뉴 사용하기

WordPress 사이트의 모든 도구를 한곳에서 쓸 수 있어요. 이제 사이트를 열면 왼쪽 메뉴에 기능별로 묶인 도구가 나타나고, 사이트 목록 표에서는 모든 사이트의 주요 수치를 한눈에 볼 수 있어요. 이 문서에서는 사이트를 여는 방법, 메뉴 그룹별 구성, 사이트 전환 방법, 사이트 목록 사용법을 안내해요.

## WordPress 사이트 메뉴란?

사이트 메뉴는 WordPress 사이트 페이지 왼쪽에 있는 패널이에요. 맨 위에는 사이트 이름, 주소, Site ID, 리전이 나와요. 그 아래에는 사이트의 모든 도구가 섹션별로 묶여 있고, 맨 아래에는 **Open WordPress**(WordPress 열기)와 **Visit the site**(사이트 방문)가 있어요.

![WordPress 사이트 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084212236/original/sn2hlRa-wzev9SlSM4cH5KRUjOnSz0ndqQ.png?1793021566)

## 새 사이트 메뉴의 장점

- 모든 도구를 한곳에서: 같은 페이지에서 클릭 한 번으로 사이트의 모든 도구에 갈 수 있어요.
- 하고 싶은 작업별로 묶음: 분석, 사이트 관리, 백업, 보안, 고급 설정이 각각 별도 그룹으로 나뉘어 있어요.
- 사이트 빠른 전환: 목록으로 돌아가지 않고 메뉴 맨 위에서 다른 사이트로 바로 이동할 수 있어요.
- 모든 사이트를 한눈에: 사이트 목록에서 사이트별 상태, 위협, 업데이트, 가동률, 백업, 성과, 저장 공간을 볼 수 있어요.

## 사이트 여는 방법

1. **사이트**로 이동하세요.
2. **WordPress**를 클릭하세요.
3. 원하는 사이트를 찾아 **Manage site**(사이트 관리)를 클릭하세요. 사이트가 **정보** 화면으로 열려요.

{% hint style="info" %}
아직 설정을 마치지 않은 사이트에는 **Manage site** 대신 **Finish setup**(설정 완료)이 표시돼요.
{% endhint %}

## 메뉴 그룹별 구성

- **정보**: 사이트 현황을 한눈에 볼 수 있어요. 라이브 접속, 스테이징, 도메인도 여기에 있어요.
- **분석**: **Site**(사이트), **Visitor**(방문자), **성과**가 있어요.
- **WordPress Management**(WordPress 관리): **플러그인**, **테마**, **Core**(코어), **Pages**(페이지), **사용자**가 있어요.
- **백업**: 사이트 백업을 관리해요.
- **Antivirus**(바이러스 백신): **Shield**(실드), **Hardening**(보안 강화), **Troubleshooter**(문제 해결), **Activity Logs**(활동 로그)가 있어요.
- **고급 설정**: **FTP**, **File manager**(파일 관리자), **Cache management**(캐시 관리), **Search and replace**(검색 및 바꾸기), **WordPress debugging**(WordPress 디버깅), **Server settings**(서버 설정), **Delete site**(사이트 삭제)가 있어요.

![메뉴 그룹별 구성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084212248/original/un_kphZlFxJiTtn7gccX9TJBwhkr4VyQqw.png?1793021571)

{% hint style="info" %}
**Troubleshooter**와 **Activity Logs**는 이제 **Antivirus** 그룹에 있어요. 기능은 이전과 같아요.
{% endhint %}

그룹 이름 옆의 화살표를 누르면 그룹을 접거나 펼 수 있어요.

## 사이트 전환 방법

1. 메뉴 맨 위, 사이트 이름 옆의 화살표를 클릭하세요.
2. 사이트를 검색하거나 목록에서 선택하세요.
3. 선택한 사이트가 같은 페이지 구성으로 열려요.

![사이트 전환 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084212250/original/Rk-rfMM_JiICH_AzYL_3jjlHYF0u4NN25Q.png?1793021573)

전체 사이트 목록으로 돌아가려면 페이지 맨 위의 **All sites**(모든 사이트)를 클릭하세요.

## 사이트 목록 사용 방법

1. **사이트 > WordPress**로 이동하세요.
2. **Search sites**(사이트 검색)에서 사이트 이름으로 사이트를 찾으세요.
3. **목록**과 **카드**를 전환해 사이트가 표시되는 방식을 바꾸세요.
4. 사이트별 열을 확인하세요: **상태**, **Threats**(위협), **업데이트**, **Uptime %**(가동률), **백업**, **성과**, **저장 공간**.
5. 각 행의 액션 버튼을 사용하세요. 예를 들면 **Manage site** 또는 **Finish setup**이에요.
6. **이전**과 **다음**으로 페이지를 넘기세요.

![사이트 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084212123/original/VAYt385JjgCMTOgKJgW-A4M08K6GjfpcJA.png?1793021550)

### 카드 보기

**카드**를 클릭하면 사이트를 카드 형태로 볼 수 있어요. 각 카드에는 다음 내용이 표시돼요.

- 사이트 이름, 상태(예: **게시됨** 또는 **NOT LIVE**(게시 안 됨)), 주소
- **Threats**, **업데이트**, **Uptime %**, **백업**, **성과**, **저장 공간** 요약
- 액션 버튼 하나(예: **Manage site** 또는 **Finish setup**)

![카드 보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084270438/original/LDVVAUj9YNdDVckrRDdaIO96XxcPWIhaGA.png?1793086481)

표로 돌아가려면 **목록**을 클릭하세요.

### 사이트별 빠른 액션

어느 보기에서든 사이트의 점 세 개를 클릭하면 **빠른 액션**이 열려요.

- **WordPress admin**(WordPress 관리자): WordPress 대시보드를 열어요.
- **사이트 방문**: 라이브 사이트를 열어요.
- **Manage Website**(웹사이트 관리): 전체 메뉴가 있는 사이트 페이지를 열어요.
- **Change PHP Version**(PHP 버전 변경): 사이트가 실행되는 PHP 버전을 선택해요.
- **캐시 지우기**: 사이트 캐시를 지워요.
- **Copy site ID**(사이트 ID 복사): Site ID를 복사해요.
- **구독 취소**: 사이트 구독을 취소해요.

![사이트별 빠른 액션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084270435/original/LEk4elWwOIOyvger8vLHl4RyTC3cDnqAGg.png?1793086477)

## 자주 묻는 질문

### Troubleshooter와 Activity Logs는 어디로 갔나요?
사이트 메뉴의 **Antivirus** 그룹에 있어요. **Shield**, **Hardening** 옆에서 찾을 수 있어요.

### 사이트 페이지에서 WordPress 관리자 화면으로 가려면 어떻게 하나요?
사이트 메뉴 맨 아래의 **Open WordPress**를 클릭하세요.

### 라이브 사이트를 보려면 어떻게 하나요?
사이트 메뉴 맨 아래의 **Visit the site**를 클릭하세요.

### Site ID를 복사하려면 어떻게 하나요?
사이트 메뉴 맨 위, Site ID 옆의 복사 아이콘을 클릭하세요.

### 제 설정이 바뀌었나요?
아니요. 메뉴에서 항목의 위치만 바뀌었어요. 사이트와 설정은 그대로예요.
