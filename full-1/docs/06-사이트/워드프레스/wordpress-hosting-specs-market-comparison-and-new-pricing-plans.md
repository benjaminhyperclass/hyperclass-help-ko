# WordPress 호스팅 사양과 요금제

하이퍼클래스에는 WordPress 호스팅이 포함되어 있어요. 이 문서에서는 호스팅이 제공하는 기능, 플랜별 요금과 사양, 자주 묻는 질문을 안내해요. 처음 사이트를 만들 때나 여러 고객사의 사이트를 관리할 때 플랜을 고르는 기준으로 쓰세요.

## WordPress 호스팅이 제공하는 기능

- 빠른 속도: Cloudflare Enterprise CDN으로 전 세계 어디서나 빠르게 사이트를 보여 줘요.
- 안정적인 가동 시간과 보안: 매일 백업하고, 클릭 한 번으로 복원할 수 있어요. 엄격한 보안 프로토콜로 사이트를 안전하게 운영해요.
- 무료 SSL과 글로벌 CDN: Cloudflare의 엔터프라이즈급 안정성이 기본으로 제공돼요.
- 24시간 전담 지원 채널: 고급 지원팀에 하루 24시간 직접 문의할 수 있어요.

{% hint style="info" %}
모든 WordPress 호스팅 플랜은 하이퍼클래스 요금제와 별도로 결제해요.

예: 하이퍼클래스 Starter($97/월) + WordPress 스탠다드 플랜($10/월) = $107/월. 이 금액이면 하이퍼클래스의 마케팅 자동화 기능을 모두 쓰고, 전체 지원이 포함된 WordPress 사이트 1개를 운영할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 이 플랜을 쓰려면 따로 설정해야 하는 게 있나요?

아니요. 하이퍼클래스 계정에서 **에이전시 > 재판매**로 이동하면 바로 시작할 수 있어요. 플랜 혜택은 구독하는 즉시 적용돼요.

### "제한 없는 대역폭"은 무슨 뜻인가요?

엄격한 대역폭 한도가 없다는 뜻이에요. 데이터 사용량 한도 때문에 사이트가 느려지지 않아요. 다만 일반적인 공정 사용 정책은 그대로 적용돼요.

### 연 단위로 결제하면 할인이 있나요?

네. 세 플랜 모두 연 단위로 결제하면 할인된 가격이 적용돼요. 스탠다드 플랜은 $9/월, 유틸리티 플랜은 $208/월, **Unlimited Plan**은 $414/월이에요.

### 저장 용량 사용량은 어디서 확인하나요?

**Hosting Dashboard**(호스팅 대시보드)의 **사이트 세부 정보**에서 현재 저장 용량 사용량을 확인할 수 있어요.

도움이 필요하면 24시간 운영하는 하이퍼클래스 고객지원 팀에 문의하세요.
