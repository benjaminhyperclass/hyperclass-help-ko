# 폼·설문·퀴즈 설정 한 번에 관리하기

**설정** 페이지에서는 서브 계정 전체의 폼, 설문, 퀴즈 공통 설정을 한곳에서 관리할 수 있어요. 지원하는 설정을 한꺼번에 켜거나 끈 다음, 필요하면 항목별로 예외를 둘 수 있어요.

검색, 상태 필터, 항목 수, 변경 요약을 보면 저장하기 전에 어떤 영향이 있을지 미리 확인할 수 있어요. 이 문서에서는 서브 계정 전체 설정을 바꾸는 방법, 개별 예외를 지정하는 방법, 저장 전에 변경 내용을 검토하는 방법을 안내해요.

{% hint style="info" %}
폼, 설문, 퀴즈 메뉴 아래의 **설정** 페이지에서는 서브 계정 안의 여러 항목에 걸친 설정을 관리해요. 이 페이지는 개별 폼, 설문, 퀴즈의 빌더 안에 있는 설정과 달라요. 여러 항목을 한꺼번에 바꾸거나 개별 예외를 둘 때는 이 **설정** 페이지를 쓰고, 항목 하나를 편집하는 중이라면 **빌더 설정**을 쓰세요.
{% endhint %}

## 폼·설문·퀴즈 설정이란?

**설정** 페이지는 서브 계정의 폼, 설문, 퀴즈에 적용되는 설정을 한곳에서 관리하는 화면이에요.

설정마다 현재 몇 개 항목에서 켜져 있는지 보여 줘요. **모두 켜기** 또는 **모두 끄기**로 서브 계정 전체 변경을 대기 상태로 만든 뒤, 예외가 필요한 폼, 설문, 퀴즈만 따로 바꿀 수 있어요.

이 화면의 설정은 각 빌더 안에 있는 설정과 같은 설정이에요. 변경 내용은 **변경사항 저장**을 누르기 전까지 대기 상태로만 남아요.

{% hint style="warning" %}
이 문서에서 설명하는 **설정** 페이지는 **사이트 > 폼/설문/퀴즈 > 설정**으로 들어가요. 개별 폼, 설문, 퀴즈 빌더 안의 설정과는 달라요.
{% endhint %}

---

## 설정의 장점

반복 작업은 줄이고, 개별 예외는 그대로 관리할 수 있어요.

- 서브 계정 전체 제어: 해당하는 모든 항목의 설정을 한 번에 켜거나 끌 수 있어요.
- 항목별 예외: 나머지는 그대로 두고 특정 폼, 설문, 퀴즈만 다르게 설정할 수 있어요.
- 한눈에 보기: 설정마다 몇 개 항목에서 켜져 있는지 확인할 수 있어요.
- 빠른 찾기: 항목 이름으로 검색하고, 불러온 항목을 **전체**, **활성화됨**, **비활성화됨**으로 걸러 볼 수 있어요.
- 안전한 대량 변경: 변경을 적용하기 전에 영향을 먼저 확인할 수 있어요.
- 되돌리기 쉬운 대기 방식: **삭제**를 누르면 마지막 저장 이후에 대기 중인 변경을 모두 취소해요.
- 양방향 동기화: 여기서 바꾼 내용은 개별 빌더에 반영되고, 빌더에서 바꾼 내용은 **설정** 페이지에 반영돼요.
- 변경 이력 확인: 설정을 바꾸면 해당 항목의 **수정일**과 **업데이트한 사람** 정보가 갱신돼요.

## 폼·설문·퀴즈 설정 관리하기

폼, 설문, 퀴즈 모두 같은 방식으로 관리해요. 해당 메뉴의 **설정** 페이지로 들어가 설정을 고른 다음, 일괄로 적용하거나 개별 예외를 지정하세요.

### 설정 페이지 열기

개별 폼, 설문, 퀴즈 빌더를 열지 말고 아래 경로로 들어가세요.

| 종류 | 경로 |
| --- | --- |
| **폼** | **사이트 > 폼 > 설정** |
| **설문** | **사이트 > 설문 > 설정** |
| **퀴즈** | **사이트 > 퀴즈 > 설정** |

폼에는 지원하는 설정이 6개 있어요. **제출 시 대화 생성**은 폼에서만 쓸 수 있어서, 설문과 퀴즈에는 5개가 있어요.

### 설정 일괄 적용하기

선택한 종류의 해당 항목 전체에 같은 설정을 한꺼번에 적용할 수 있어요.

1. 해당하는 **설정** 페이지를 엽니다.
2. 왼쪽 메뉴에서 관리할 설정을 선택합니다.
3. 현재 몇 개 항목에서 이 설정이 켜져 있는지 확인합니다.
4. 해당하는 모든 항목을 켜려면 **모두 켜기**를 클릭합니다.
5. 해당하는 모든 항목을 끄려면 **모두 끄기**를 클릭합니다.
6. 저장하기 전에 대기 중인 변경 내용을 확인합니다.

대량 액션은 화면에 보이지 않는 항목을 포함해, 해당하는 모든 항목에 적용돼요.

![모두 켜기와 모두 끄기로 설정을 일괄 적용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083183877/original/gRQpyY3nuKZRhM8gOf4DLoDJeqVx3cqeng.png?1791888072)

### 개별 예외 지정하기

저장하기 전에 일부 항목만 일괄 설정과 다른 상태로 바꿀 수 있어요.

먼저 아래 메뉴로 개별 목록을 엽니다.

- 폼: **개별 폼 관리**
- 설문: **개별 설문 관리**
- 퀴즈: **개별 퀴즈 관리**

그다음 순서대로 진행하세요.

1. 필요하면 항목 이름으로 검색합니다.
2. **전체**, **활성화됨**, **비활성화됨**을 선택해 현재 불러온 항목을 걸러 봅니다.
3. 항목 옆의 토글을 눌러 개별 예외를 지정합니다.
4. 예외가 더 있으면 같은 방법으로 반복합니다.
5. **저장되지 않은 변경사항** 요약을 확인합니다.
6. **변경사항 저장**을 클릭해 대기 중인 변경을 적용합니다.

수정한 행에는 저장하기 전까지 **변경됨**이 표시될 수 있어요.

목록 아래의 숫자는 전체 항목 중 몇 개를 불러왔는지 보여 줘요. 대량 액션은 목록에 불러온 항목이 아니라 서브 계정의 해당하는 모든 항목에 적용돼요.

예: **221개 폼 중 10개 표시 중 — 대량 액션은 전체 221개에 적용됩니다.**

## 지원하는 설정

**설정** 페이지는 빌더에 있던 설정을 한곳에 모아 둔 화면이에요. 빌더를 하나씩 열지 않아도 해당 항목을 관리할 수 있어요.

| 설정 | 폼 | 설문 | 퀴즈 |
| --- | --- | --- | --- |
| **제출 시 대화 생성** | 예 | 아니요 | 아니요 |
| **제출 문서 생성** | 예 | 예 | 예 |
| **고정 연락처** | 예 | 예 | 예 |
| **진행 상황 저장** | 예 | 예 | 예 |
| **시간대 수집 활성화** | 예 | 예 | 예 |
| **GDPR 준수 폰트 사용** | 예 | 예 | 예 |

설정 사이드바에는 아래의 짧은 이름으로 표시돼요.

- **대화**
- **제출 PDF**
- **고정 연락처**
- **진행 상황 저장**
- **시간대**
- **GDPR 폰트**

설문과 퀴즈에는 **대화**가 없어요.

설정별 자세한 내용은 아래 문서에서 확인하세요.

- **제출 PDF**: [폼, 설문, 퀴즈의 제출 문서 생성하기](how-to-generate-submission-documents-for-forms-surveys-quizzes.md)
- **진행 상황 저장**: [폼, 설문, 퀴즈의 진행 상황 저장](../설문/save-progress-for-forms-surveys-quizzes.md)
- **대화**: [대화에서 폼 제출 내용 확인하기](../../03-대화/대화/how-to-access-form-submissions-in-conversations.md)
- **고정 연락처**: [폼, 설문, 캘린더의 고정 연락처](../sticky-contact-in-forms-surveys-and-calendars.md)

## 변경사항 검토하고 저장하기

**설정** 페이지는 변경 내용을 바로 반영하지 않고 먼저 대기 상태로 두어요. 일괄 변경과 개별 예외가 실제 항목에 적용되기 전에 검토할 수 있어요.

설정을 바꾸면 이렇게 표시돼요.

- 수정한 행에 **변경됨**이 표시될 수 있어요.
- 화면 아래쪽 바에 **저장되지 않은 변경사항**이 표시돼요.
- 저장 요약에 대기 중인 변경 결과가 나와요.
- **변경사항 저장**을 누르면 대기 중인 변경이 모두 적용돼요.
- **삭제**를 누르면 마지막 저장 이후에 대기 중인 변경이 모두 취소돼요.

저장 요약에는 아래와 같은 메시지가 나올 수 있어요.

- "3개 폼이 활성화됩니다"
- "모든 폼이 활성화됩니다, 2개 비활성화"

이 메시지는 요약이 표시되는 방식을 보여 주는 예시일 뿐이고, 나올 수 있는 메시지가 이것만 있는 것은 아니에요.

**변경사항 저장**을 누르기 전까지는 아무것도 저장되지 않아요.

## 자주 묻는 질문

### 모두 켜기는 지금 화면에 보이는 항목에만 적용되나요?
아니요. **모두 켜기**와 **모두 끄기**는 화면에 보이지 않는 항목까지 포함해, 서브 계정에서 해당하는 모든 항목에 적용돼요.

### 대부분의 항목은 켜고 몇 개만 끌 수 있나요?
네. 먼저 일괄 설정을 적용한 다음, **변경사항 저장**을 누르기 전에 개별 항목 컨트롤로 예외를 지정하세요.

### 토글을 누르면 바로 적용되나요?
아니요. **변경사항 저장**을 누르기 전까지 변경은 대기 상태로 남아 있어요.

### 활성화됨과 비활성화됨 필터는 서브 계정의 모든 항목을 검색하나요?
아니요. 이 필터는 지금까지 목록에 불러온 항목에만 적용돼요. 목록 아래의 숫자에서 현재 몇 개를 불러왔는지 확인할 수 있어요.

### 설정 페이지가 각 빌더의 설정을 대신하나요?
아니요. 서브 계정 단위의 **설정** 페이지와 개별 빌더는 같은 설정을 제어하고, 서로 동기화돼요.

### 설문이나 퀴즈에서도 제출 시 대화 생성을 쓸 수 있나요?
아니요. **제출 시 대화 생성**은 폼에서만 쓸 수 있어요.

### 설정 기능이 생기면 기존 폼, 설문, 퀴즈가 자동으로 바뀌나요?
아니요. 설정 변경을 대기 상태로 만들고 저장하기 전까지는 기존 항목이 그대로 유지돼요.
