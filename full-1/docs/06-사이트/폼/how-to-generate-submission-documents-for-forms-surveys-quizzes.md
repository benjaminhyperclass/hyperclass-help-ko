# 폼·설문·퀴즈 제출 내용을 PDF 문서로 자동 저장하기

폼, 설문, 퀴즈에 제출이 들어올 때마다 PDF 문서를 자동으로 만들어 연락처 기록에 저장하는 방법을 안내해요. 설정 방법, PDF 파일 이름 규칙, 생성된 문서를 찾는 방법을 알 수 있어요.

제출 문서는 응답 내용을 출력하기 좋은 형태로 정리한 기록이에요. 제출한 연락처에 자동으로 연결되어 저장되므로, CRM 작업 중 필요할 때 바로 꺼내 볼 수 있어요.

## 제출 문서 생성이란?

**Generate Submission Document**(제출 문서 생성) 설정을 켜면 폼, 설문, 퀴즈에 제출이 들어올 때마다 PDF 사본이 자동으로 만들어지고 저장돼요. 모든 질문과 응답, 제출 일시 같은 제출 정보가 보기 좋게 정리되어 들어 있어요.

PDF는 제출한 연락처에 자동으로 연결되어 해당 연락처의 **문서**에 저장돼요. 그래서 문서를 보고, 내려받고, 공유하고, CRM 작업에 활용하기 쉬워요. 이 기능은 폼, 설문, 퀴즈에서 쓸 수 있고, 데스크톱과 모바일 모두에서 동작해요.

## 제출 문서 생성의 장점

- 자동 PDF 생성: 제출이 들어올 때마다 출력하기 좋은 형식의 PDF가 직접 작업하지 않아도 만들어져요.
- 응답 전체 기록: PDF에 모든 질문, 제출된 응답, 제출 일시, 연락처 정보가 담겨요.
- 체계적인 보관: 문서는 제출 유형에 따라 **연락처 > 문서** 안의 전용 폴더(**폼**, **설문**, **퀴즈**)에 자동으로 저장돼요.
- 연락처 연결: PDF가 제출한 연락처에 자동으로 연결되어 쉽게 찾아볼 수 있어요.
- CRM 연동: PDF를 보고, 내려받고, 클라이언트 포탈로 공유하고, 인쇄할 수 있어요. 지원되는 CRM 워크플로우에서도 쓸 수 있어요.
- 모든 환경 지원: 데스크톱과 모바일에서 똑같이 쓸 수 있어요.

## 제출 문서 생성 켜는 방법

폼, 설문, 퀴즈 제출에 대해 PDF 자동 생성을 켜려면 다음 단계를 따르세요.

1. 하이퍼클래스 계정에 로그인한 뒤 메인 메뉴에서 **사이트**를 클릭하세요.

   ![사이트 메뉴](https://jumpshare.com/share/vbw047WbSRdzgJf8AswV+/Screen+Shot+2026-07-29+at+20.21.58.png)

2. 설정을 켤 대상이 폼, 설문, 퀴즈 중 무엇인지 정하고, **사이트** 메뉴에서 해당하는 항목을 선택하세요.

   ![사이트 메뉴에서 폼, 설문, 퀴즈 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077158124/original/iQWypJFqX9-vxgPLf2vf5MkCP7TXf9GnZA.png?1785337232)

3. 목록에서 기존 폼, 설문, 퀴즈를 선택하거나 **+ Create Form**(+ 폼 만들기) 버튼을 눌러 새로 만드세요. 설문과 퀴즈에서는 같은 역할의 버튼을 누르면 돼요. 처음부터 만들 수도 있고 템플릿으로 시작할 수도 있어요.

   ![폼 목록과 새로 만들기 버튼](https://jumpshare.com/share/lT6yevBQFuYPQy4Wug37+/Screen+Shot+2026-07-29+at+20.31.46.png)

4. 폼, 설문, 퀴즈 빌더가 열리면 상단 메뉴 또는 사이드 패널에서 **설정**을 클릭하세요.

   ![빌더의 설정 메뉴](https://jumpshare.com/share/LvfHKY6V4Cbd1nrkAffw+/Screen+Shot+2026-07-29+at+20.33.30.png)

5. 아래로 스크롤해 **Form Settings**(폼 설정) 섹션을 찾으세요. 설문과 퀴즈는 각각의 설정 섹션이에요. 그다음 **Generate Submission Document** 토글을 **켜짐**으로 바꾸세요.

   ![제출 문서 생성 토글을 켠 화면](https://jumpshare.com/share/en9QnvUJ9L6sYF3hJTZN+/Screen+Shot+2026-07-29+at+20.41.08.png)

6. **저장**을 클릭해 설정을 적용하세요. 이후 들어오는 새 제출부터 PDF 문서가 자동으로 만들어져요.

   ![저장 버튼](https://jumpshare.com/share/4Ed9IlYlI7Bs5xuh2t0S+/Screen+Shot+2026-07-29+at+20.42.40.png)

{% hint style="warning" %}
**Generate Submission Document** 설정은 폼, 설문, 퀴즈마다 따로 적용돼요. 하나에서 켜도 다른 곳은 자동으로 켜지지 않아요. 여러 폼에서 제출 문서가 필요하면 각각 설정을 켜야 해요.
{% endhint %}

## PDF 파일 이름 규칙

생성된 문서는 알아보고 정리하기 쉽도록 일정한 형식으로 이름이 붙어요. 폼·설문과 퀴즈는 이름 형식이 조금 달라요.

| 제출 유형 | PDF 파일 이름 형식 |
| --- | --- |
| 폼 & 설문 | [FormName]\_[ContactName]\_[YYYY-MM-DD\_HHMM] |
| 퀴즈 | Result\_[FormName]\_[ContactName]\_[YYYY-MM-DD\_HHMM] |

예시

- 폼/설문: `ContactForm_JohnDoe_2024-03-15_1430.pdf`
- 퀴즈: `Result_ProductKnowledgeQuiz_JaneSmith_2024-03-15_0920.pdf`

이름 규칙이 일정해서 연락처 기록이나 CRM 전반에서 PDF를 쉽게 검색하고 구분할 수 있어요.

## 생성된 문서 확인하기

제출이 처리되면 생성된 PDF는 해당 연락처의 **문서**에 자동으로 저장돼요. 문서를 찾아서 쓰는 방법은 다음과 같아요.

1. 하이퍼클래스 계정에서 **연락처**로 이동해, 폼·설문·퀴즈를 제출한 연락처를 찾으세요.

   ![연락처 목록](https://jumpshare.com/share/iLykACtQHdADOlCbgKiI+/Screen+Shot+2026-07-29+at+21.02.05.png)

2. 연락처 이름을 클릭해 상세 기록을 여세요.

   ![연락처 상세 기록](https://jumpshare.com/share/z0aPWtBbNgsGlxX5FltD+/Screen+Shot+2026-07-29+at+21.05.53.png)

3. 오른쪽 패널에서 **문서**를 찾아 클릭하세요. **폼**, **설문**, **퀴즈** 폴더가 정리되어 보여요.

   ![문서 폴더 목록](https://jumpshare.com/share/kPt3T0FPxshVo3LZkHU7+/Screen+Shot+2026-07-29+at+21.08.11.png)

4. 여기서 문서를 미리 보거나 내려받고, 인쇄하거나 클라이언트 포탈로 공유할 수 있어요.

   ![PDF 문서 보기 및 내려받기](https://jumpshare.com/share/hZj9I2uQj0eO560yrFY5+/Screen+Shot+2026-07-29+at+21.13.41.png)

{% hint style="info" %}
제출 문서는 하이퍼클래스 워크플로우에서도 쓸 수 있어요. 이메일 첨부, 워크플로우 트리거, 클라이언트 포탈 공유 등에 활용할 수 있고, 기존 CRM 작업 방식과 자연스럽게 이어져요.
{% endhint %}

## 자주 묻는 질문

### 설정을 켜면 이미 들어온 제출에 대해서도 PDF가 만들어지나요?

아니요. **Generate Submission Document** 설정은 켠 이후에 들어오는 새 제출에만 적용돼요. 설정을 켜기 전에 들어온 제출은 PDF가 자동으로 만들어지지 않아요.

### PDF 생성을 켠 뒤에 끌 수도 있나요?

네. **Generate Submission Document** 토글을 언제든 **꺼짐**으로 바꿀 수 있어요. 끄면 이후 새 제출에서는 PDF가 만들어지지 않아요. 이미 생성된 PDF는 연락처의 **문서**에 그대로 남아요.

### PDF는 어디에 저장되나요?

생성된 PDF는 **연락처 > 문서** 안에서 제출 유형별 폴더(**폼**, **설문**, **퀴즈**)에 자동으로 저장돼요. 각 PDF는 제출을 완료한 연락처에 연결돼요.

### 생성된 PDF에는 어떤 정보가 들어 있나요?

폼, 설문, 퀴즈의 모든 질문과 연락처가 제출한 응답, 제출 일시, 연락처 정보가 들어 있어요. 읽고 출력하기 쉽게 정리된 형식이에요.

### 폼, 설문, 퀴즈마다 모두 설정을 켜야 하나요?

네. **Generate Submission Document** 설정은 폼, 설문, 퀴즈마다 따로 적용돼요. 하나에서 켜도 다른 곳은 자동으로 켜지지 않아요. 덕분에 업무 방식에 맞춰 PDF를 만들 제출을 골라서 설정할 수 있어요.

### 생성된 PDF를 연락처와 공유할 수 있나요?

네. 생성된 PDF는 내려받거나, 클라이언트 포탈로 공유하거나, 이메일에 첨부하거나, 인쇄할 수 있어요. CRM 워크플로우와 연동되므로 제출 내용을 정리된 기록으로 쓰고 싶은 곳이면 어디서든 활용할 수 있어요.

### 한 연락처가 여러 번 제출하면 어떻게 되나요?

제출할 때마다 PDF가 하나씩 따로 만들어져요. 파일 이름에는 제출 시각이 들어가서 서로 구분돼요. 모든 PDF는 해당 연락처의 **문서** 안 알맞은 폴더(**폼**, **설문**, **퀴즈**)에 저장되므로, 그 연락처의 제출 이력을 한곳에서 확인할 수 있어요.
