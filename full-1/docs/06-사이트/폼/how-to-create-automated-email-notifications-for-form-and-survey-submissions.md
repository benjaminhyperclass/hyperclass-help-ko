# 폼·설문 제출 시 자동 이메일 알림 보내기

이 기능을 켜면 폼을 작성한 사람에게 자동 응답 이메일이 발송돼요. 내부 팀원에게 알림을 보내는 옵션도 함께 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/Z4jz-Kqm0Rs?&wmode=opaque)

[동영상](https://www.youtube.com/embed/UNjuLm1rf7E?&wmode=opaque)

{% hint style="info" %}
이 옵션과 설정은 설문에서도 똑같이 쓸 수 있어요.
{% endhint %}

## 이메일 알림 켜기

**서브 계정** > **사이트** > **폼** > **폼 빌더**로 이동하세요. 새 폼을 만들려면 **Add Form**(폼 추가)을 선택하고, 이미 있는 폼에 자동 응답을 설정하려면 목록에서 해당 폼을 선택하세요.

1. 왼쪽 위에 있는 종 모양 아이콘을 클릭하세요.

![폼 빌더 왼쪽 위의 종 모양 알림 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155020555297/original/KACnIMc4vTpL9bfpfoX_fkCehWQKcs6icg.png?1707925669)

2. 알림 옵션이 두 가지 나타나요. 첫 번째는 누군가 폼을 제출하면 나에게 이메일을 보내는 옵션이에요. 두 번째는 폼을 제출한 사람에게 자동 메시지를 보내는 **Auto-Responder**(자동 응답)예요. 사용할 옵션의 토글을 켜세요.

![알림 옵션과 Auto-Responder 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155020556370/original/ceE2uO_z4WMbqmMxGAaFGoXsmLZWlDjTiA.png?1707926154)

3. 자동으로 발송될 이메일의 **제목**을 입력하세요.
4. **reply to email**(회신 이메일)에 수신자가 이 자동 이메일에 답장할 때 답장을 받을 이메일 주소를 입력하세요.
5. **Sender name**(보낸 사람 이름)에 발송 이메일에 표시할 이름을 입력하세요. 비워 두면 서브 계정 이름이 기본으로 쓰여요.
6. **저장**을 클릭하세요.
7. 폼 자체에도 변경 내용을 반영하려면 오른쪽 위의 **저장**을 한 번 더 클릭하세요.

![제목, 회신 이메일, 보낸 사람 이름을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155020557134/original/fBT19UzAYz-_WhsO3XvBOJmlV0d4HvjiXQ.png?1707926428)

{% hint style="info" %}
**팁**: 새 설정과 폼을 저장한 뒤 오른쪽 위의 **미리보기**를 클릭하고 폼을 직접 작성해 보세요. 기능이 제대로 작동하는지 확인할 수 있어요.
{% endhint %}
