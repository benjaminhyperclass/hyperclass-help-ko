# 폼·설문·퀴즈: 첫 번째 오류로 자동 스크롤 및 오류 안내 개선

폼, 설문, 퀴즈를 제출할 때 빠진 항목이나 잘못 입력한 항목이 있으면, 화면이 첫 번째 오류로 자동으로 스크롤되고 해당 항목이 강조돼요. 설문에서는 오류 메시지가 항목 바로 옆에 표시돼요. 특히 모바일에서 입력 오류를 쉽게 고칠 수 있어서 제출 성공률을 높이는 데 도움이 돼요.

## 첫 번째 오류로 자동 스크롤 & 인라인 오류 처리란?

첫 번째 오류로 자동 스크롤은 제출에 실패했을 때 화면을 첫 번째 오류 항목으로 옮겨 주는 기능이에요. 방문자는 바로 그 자리에서 입력을 고칠 수 있어요.

인라인 오류 처리는 문제가 있는 항목 바로 아래나 옆에 상황에 맞는 안내를 보여 주는 기능이에요. 설문과 여러 단계로 된 화면에서 특히 유용해요.

두 기능이 함께 작동하면 어디를 고쳐야 할지 헤매지 않아도 돼서 입력 완료율이 올라가요.

**적용 범위**

- 적용 대상: 폼, 설문, 퀴즈예요. 항목이 많거나 여러 단계(슬라이드)로 구성된 경우에도 적용돼요.
- 사용 가능 여부: 새로 만든 자산과 기존 자산 모두 기본으로 켜져 있어요. 따로 설정할 필요가 없어요.
- 기기: 모바일과 데스크톱 모두에 맞게 최적화되어 있어요.

## 자동 스크롤과 인라인 오류의 장점

- 빠른 수정: 방문자가 문제가 있는 곳으로 바로 이동해요. 직접 찾아 헤맬 필요가 없어요.
- 모바일에 적합: 오류 위치를 찾기 어려운 작은 화면에서 특히 도움이 돼요.
- 항목 옆의 명확한 안내: 항목 옆에 안내가 표시돼서 혼란과 반복 시도가 줄어요.
- 이탈 감소: 오류를 고치는 과정이 매끄러워서 입력 완료율과 전환율이 높아져요.
- 설정 불필요: 기존 자산에도 바로 적용돼요.

## 첫 번째 오류로 자동 스크롤하는 방식

제출 시 입력 검증에 실패하면 다음과 같이 작동해요.

- 항목에 오류가 하나라도 있으면, 페이지가 위에서부터 세어 첫 번째 오류 항목으로 자동 스크롤하고 그 항목을 강조해요.
- 여러 단계로 된 설문과 퀴즈에서는 첫 번째 오류 항목이 있는 슬라이드로 이동한 뒤, 바로 고칠 수 있는 위치에 화면을 맞춰요.
- 한 줄 레이아웃, 두 줄 레이아웃, 한 줄에 모두 나열하는 레이아웃 같은 일반적인 레이아웃과, 입력 항목이 많은 긴 페이지에서도 작동해요.
- **Email Validation**(이메일 유효성 검사), **주소 자동완성** 같은 다른 입력 검증 기능과 함께 쓰도록 만들어졌어요.

## 인라인 오류 메시지

인라인 메시지는 입력 항목에서 멀리 떨어진 일반 목록 대신, 문제가 생긴 항목 바로 옆에 이유를 보여 줘요. 그래서 방문자가 따로 생각하고 찾는 수고가 줄어요.

- 이전에는 설문 오류가 슬라이드 맨 위에 목록으로 한꺼번에 표시될 수 있었어요. 방문자는 해당 항목을 직접 찾아야 했어요.
- 이제는 오류가 상황에 맞게 항목 바로 옆에 표시돼요. 자동 스크롤이 방문자를 알맞은 위치로 이동시켜 줘요.
- 모바일 화면이나 슬라이드가 긴 경우에 효과가 특히 커요.

## 자주 묻는 질문

### 자동 스크롤이나 인라인 오류를 쓰려면 토글을 켜야 하나요?
아니요. 새로 만든 폼, 설문, 퀴즈와 기존 폼, 설문, 퀴즈 모두 기본으로 켜져 있어요.

### 여러 단계로 된 설문과 퀴즈에서도 작동하나요?
네. 첫 번째 오류 항목이 있는 슬라이드로 이동하고, 바로 고칠 수 있는 위치에 화면을 맞춰 줘요.

### 조건부 로직을 쓰면 어떻게 되나요?
화면에 보이는 필수 항목만 검증해요. 답변을 바꿔서 새 필수 항목이 나타나면, 다시 제출할 때 첫 번째 오류 항목으로 자동 스크롤해요.

### 분석이나 전환 추적에 영향이 있나요?
안내가 더 명확해지기 때문에 이탈이 줄어드는 것을 볼 수 있을 거예요. 기존에 쓰던 폼·설문 분석 데이터로 적용 전후의 입력 완료율을 비교해 보세요.

### 웹사이트나 퍼널 페이지에 삽입한 폼에서도 작동하나요?
네, 작동해요.
