# 폼에서 주문 범프 설정하고 사용하기

하이퍼클래스 **폼**에 주문 범프(Order Bump)를 추가하는 방법을 안내해요. 사용자가 폼을 작성하는 흐름을 끊지 않고, 폼 안에서 바로 추가 상품을 제안해 매출을 늘릴 수 있어요. 다양한 시각 요소와 여러 템플릿으로 추가 상품을 꾸밀 수 있고, 활성화 여부도 필요에 따라 조정할 수 있어요.

## 폼의 주문 범프란?

주문 범프는 폼 안에 업셀 상품을 넣는 기능이에요. 주요 상품 옆에 범프 상품을 함께 보여 줘서, 구매자가 부담 없이 추가 상품을 담을 수 있어요. 디자인도 원하는 대로 바꿀 수 있어요.

## 주문 범프의 주요 장점

폼에서 주문 범프 기능을 쓰면 다음과 같은 장점이 있어요.

- 클래식, 모던 두 가지 범프 스타일 중에서 골라 눈에 잘 띄게 꾸밀 수 있어요.
- 시선을 끌고 전환율을 높이도록 만든 여러 템플릿을 고를 수 있어요.
- 색상, 아이콘, 강조 텍스트, 가격 표시 같은 시각 요소를 자유롭게 바꿀 수 있어요.
- 범프 상품을 여러 개 추가해 업셀 전략을 넓힐 수 있어요.
- 폼마다 반복 결제 상품이 하나만 설정되도록 자동으로 규칙이 적용돼요.
- 범프 상품을 쉽게 켜고 끄거나 순서를 바꿀 수 있어요.

## 폼에서 주문 범프 설정하고 사용하기

하이퍼클래스 폼 빌더에서 아래 순서대로 따라 하면 폼에 범프 상품을 넣을 수 있어요.

### 1단계: 폼 만들기

1. 서브 계정에 로그인해요.
2. 왼쪽 메뉴에서 **사이트 > 폼 > 빌더**를 차례로 클릭해요.
3. **+ Add Form**(폼 추가)을 클릭해요.
4. **처음부터 시작**을 선택하거나 **템플릿**을 고른 다음 **만들기**를 클릭해요.
5. **Element**(요소) 바에서 **Sell Products**(상품 판매) 요소를 폼 캔버스로 끌어다 놓아요.

![Sell Products 요소를 폼 캔버스에 끌어다 놓는 화면](https://jumpshare.com/v/p3QQH1HSXYd8jFSfBw4H+/GIF+Recording+2025-07-24+at+10.25.22+PM.gif)

### 2단계: 주요 상품 추가하기

1. **Sell Products** 요소를 클릭해요.
2. 오른쪽 패널에서 **상품 추가**를 클릭해요.
3. 아직 상품을 만들지 않았다면 **여기를 클릭** 링크를 눌러 상품 만들기 페이지를 열고 상품을 하나 만들어요.
4. 이미 만들어 둔 상품이 있다면 **선택해 주세요** 드롭다운에서 상품을 골라요.
5. **상품 유형**에서 **주요 상품**을 선택해요.
6. **Show Options**(표시 옵션)에서 **설명**, **이미지**, **수량**을 각각 켜거나 꺼서 보일지 숨길지 정해요.
7. **상품 추가**를 클릭해 폼에 넣어요.

![폼에 주요 상품을 추가하는 화면](https://jumpshare.com/v/Dq1tFE8ET6fvWzx6RprA+/GIF+Recording+2025-07-24+at+10.46.57+PM.gif)

### 3단계: 범프 상품 추가하기

1. **상품 추가**를 다시 클릭해요.
2. 드롭다운에서 **새로 만들기**를 선택하거나 이미 있는 상품을 골라요.
3. **상품 유형**에서 **범프 상품**을 선택해요.
4. 눈길을 끄는 **headline**(헤드라인)을 입력해요.
5. **이미지**를 켜거나 꺼요.
6. 새 이미지를 업로드하거나, 상품 정보에 등록된 이미지를 시스템이 가져오게 해요.

![폼에 범프 상품을 추가하는 화면](https://jumpshare.com/v/Zqg3P8WpfnP19UvrbYtg+/GIF+Recording+2025-07-24+at+10.48.45+PM.gif)

### 4단계: 범프 상품 내용과 디자인 꾸미기

1. **Order Bump Style**(주문 범프 스타일)에서 **모던** 또는 **클래식**을 골라요.
2. **템플릿 선택** 드롭다운에서 **템플릿 1**, **템플릿 2**, **템플릿 3** 중 하나를 골라요.
3. **텍스트 강조**에 시선을 끄는 문구를 입력해요(예: "한 번의 클릭으로 특가를 잡으세요").
4. **아이콘**에서 강조 텍스트 옆에 표시할 아이콘을 골라요.
5. **Show Price / Hide Price**(가격 표시/숨기기)를 켜거나 꺼서 범프 상품의 가격을 보일지 정해요.
6. **배경 색상**, **highlight text color**(강조 텍스트 색상), **headline color**(헤드라인 색상), **OTO headline**(OTO 헤드라인) 색상, **OTO text**(OTO 텍스트) 색상을 원하는 대로 바꿔요.
7. **Layout Settings**(레이아웃 설정)에서 **Single**(1열), **Two**(2열), **Three**(3열) 중 하나를 골라요.
8. **Product Selection**(상품 선택)에서 **single**(하나만 선택) 또는 **multiple**(여러 개 선택) 중 하나를 허용해요.
9. **Footer Info**(푸터 정보)를 켜면 "100% 안전한 결제" 같은 문구를 보여 줄 수 있어요.
10. **placeholder**(플레이스홀더) 텍스트를 숨길지, 그대로 둘지 골라요.

![범프 상품의 내용과 디자인을 설정하는 화면](https://jumpshare.com/v/WYvxIjCdOMOF3jO3rPJQ+/GIF+Recording+2025-07-24+at+10.52.34+PM.gif)

### 5단계: 폼 저장하기

1. 오른쪽 위에 있는 **저장**을 클릭해 변경 내용을 저장해요.

![폼 오른쪽 위의 저장 버튼](https://jumpshare.com/v/Kj2PPwK44XvmCGlYjQaA+/Screen+Shot+2025-07-24+at+10.55.27+PM.png)

## 자주 묻는 질문

### 폼 하나에 범프 상품을 여러 개 넣을 수 있나요?

네, 같은 폼에 범프 상품을 여러 개 넣을 수 있어요. 주요 상품의 구매 흐름을 방해하지 않으면서 업셀 기회를 여러 번 만들 수 있어요.

### 주요 상품과 범프 상품을 둘 다 반복 결제로 설정할 수 있나요?

아니요. 폼 하나에서 반복 결제 상품은 하나만 쓸 수 있어요. 주요 상품이나 범프 상품 중 하나만 반복 결제로 설정할 수 있고, 둘 다는 안 돼요. 이렇게 해서 결제 방식이 일관되게 유지돼요.

### 주요 상품 없이 범프 상품만 넣으면 어떻게 되나요?

주요 상품이 없으면 범프 상품이 표시되지 않아요. 범프 상품이 보이게 하려면 항상 주요 상품을 먼저 추가하세요.

### 범프 상품은 모든 결제 대행사에서 쓸 수 있나요?

네. 주문 범프는 Stripe, PayPal, 그 밖에 하이퍼클래스에서 지원하는 결제 대행사에서 문제없이 작동해요.

### 폼의 다른 부분에 영향을 주지 않고 범프 상품의 순서를 바꾸거나 잠시 꺼 둘 수 있나요?

네. 범프 상품을 켜고 끄거나 순서를 바꿔도, 주요 상품 설정이나 폼 로직에는 영향이 없어요. 필요할 때 언제든 할 수 있어요.

### 어떤 폼에서 주문 범프를 쓸 수 있나요?

**Sell Products** 요소가 들어 있는 폼이라면 모두 주문 범프 기능을 쓸 수 있어요.

### 범프 상품마다 디자인을 따로 꾸밀 수 있나요?

네. 범프 상품마다 색상, 아이콘, 강조 텍스트, 가격 표시를 각각 바꿀 수 있어요.

### 폼 하나에 범프 상품을 몇 개까지 추가할 수 있나요?

범프 상품을 여러 개 추가할 수 있어요. 필요에 따라 업셀 전략을 자유롭게 넓혀 보세요.

### 클래식과 모던 범프 스타일은 어떻게 바꾸나요?

폼에서 범프 기능을 켠 뒤, 범프 상품 설정에서 스타일을 바꿀 수 있어요.
