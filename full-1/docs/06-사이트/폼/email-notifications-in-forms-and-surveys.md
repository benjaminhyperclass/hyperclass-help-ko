# 폼과 설문의 이메일 알림 설정

폼이나 설문이 제출되면 팀원에게 이메일로 알려 주는 방법을 안내해요. **Auto Responder**(자동 응답)를 함께 쓰면 제출한 사람에게도 확인 이메일을 자동으로 보낼 수 있어요.

이 문서에서는 알림 받는 사람 설정, 이메일 내용 수정, 제출 내용을 PDF로 첨부하는 방법, 테스트 방법을 설명해요.

---

## 이메일 알림과 Auto Responder란?

**이메일 알림**은 폼이나 설문이 제출될 때마다 지정한 이메일 주소로 알림을 보내요.

**Auto Responder**는 폼이나 설문을 제출한 사람에게 자동으로 이메일을 보내요.

이 기능으로 할 수 있는 일이에요.

- 새 제출을 팀원에게 알려요.
- 제출한 사람에게 자동으로 확인 메일을 보내요.
- 이메일 제목, 발신자 이름, 회신 받을 이메일 주소를 직접 정해요.
- 지원되는 경우 제출 내용을 PDF로 첨부해요.

---

## 알림 설정 열기

1. **사이트 > 폼** 또는 **사이트 > 설문**으로 이동하세요.
2. 기존 폼이나 설문을 열거나 새로 만드세요.
3. 빌더에서 **알림** 탭을 선택하세요.

**알림** 패널에서 내부용 **이메일 알림**과 **Auto Responder** 이메일을 설정할 수 있어요.

---

## 이메일 알림 설정하기

1. **알림** 탭을 여세요.
2. **이메일 알림**을 켜세요.
3. 아래 필드를 설정하세요.

   - **제목**: 알림 이메일의 제목을 입력해요. 비워 두면 하이퍼클래스가 폼 또는 설문 이름을 제목으로 사용해요.
   - **Email (To)**(받는 사람 이메일): 알림을 받을 이메일 주소를 하나 이상 입력해요.
   - **Reply-to Email**(회신 받을 이메일): 알림 이메일에 대한 답장을 받을 이메일 주소를 입력해요.
   - **발신자 이름**: 보낸 사람으로 표시될 이름을 입력해요. 비워 두면 해당 서브 계정 또는 에이전시 이름을 사용해요.

4. **저장**을 클릭하세요.

{% hint style="info" %}
이메일 알림은 이메일 크레딧을 사용해요. 계정에 크레딧이 충분한지 확인하세요.
{% endhint %}

## 제출 내용을 PDF로 첨부하기

PDF 첨부 옵션을 켜면 제출된 응답이 담긴 PDF를 알림 이메일에 함께 보낼 수 있어요.

PDF는 이메일을 보낼 때 제출 기록을 바탕으로 만들어져요.

설정 방법은 다음과 같아요.

1. 폼이나 설문을 여세요.
2. **알림** 탭을 선택하세요.
3. 첨부 파일을 보내려는 위치에 맞게 **이메일 알림** 또는 **Auto Responder**를 켜세요.
4. 제출 내용을 PDF로 첨부하는 옵션을 켜세요.
5. 변경사항 저장을 클릭하세요.

{% hint style="info" %}
사용할 수 있는 PDF 옵션은 빌더와 제출 유형에 따라 달라질 수 있어요.
{% endhint %}

**단계**

1. 폼이나 설문 편집기를 열고 **알림** 탭을 클릭해 알림 설정을 여세요.

   ![알림 탭을 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076942482/original/sN5uVYaYGhWDzNb9aQIP4zjOKZ36KmL-hQ.png?1785160784)
2. **이메일 알림** 또는 **Auto Responder**를 켜세요.
3. **Auto Responder**는 폼을 제출한 사람에게 자동으로 이메일을 보내요. 이 이메일에는 제출자가 폼에 입력한 내용의 사본이 들어 있어요.
4. 변경사항 저장을 클릭하세요.

   ![변경사항을 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076942515/original/LI1ZKg19SaF6hafvDFiMGDNBZ_1CSZC-tA.png?1785160813)

## Auto Responder 설정하기

**Auto Responder**는 폼이나 설문을 제출한 사람에게 자동으로 이메일을 보내요.

1. **알림** 탭을 여세요.
2. **Auto Responder**를 켜세요.
3. 아래 필드를 설정하세요.

   - **제목**: 이메일 제목을 입력해요. 비워 두면 하이퍼클래스가 폼 또는 설문 이름을 제목으로 사용해요.
   - **Reply-to Email**(회신 받을 이메일): 제출자가 보낸 답장을 받을 이메일 주소를 입력해요.
   - **발신자 이름**: 발신자 이름을 입력해요. 비워 두면 서브 계정 이름을 사용해요.

4. 변경사항 저장을 클릭하세요.

{% hint style="info" %}
**Auto Responder**에 설정한 **Reply-to Email**은 제출자에게 가는 이메일에만 적용돼요. 내부용 **이메일 알림**의 **Reply-to Email**은 바뀌지 않아요.
{% endhint %}

{% hint style="info" %}
알림 설정 테스트: 폼이나 설문을 저장한 뒤 미리보기를 열어 테스트 응답을 제출해 보세요. 내부 알림과 **Auto Responder** 이메일이 의도한 받는 사람에게 도착하는지 확인하세요.
{% endhint %}

## 이메일 알림을 받은 뒤 설문 응답 확인하기

이메일 알림은 알림 역할만 해요. 설문 응답 전체는 이메일에 담기지 않아요. 응답은 아래 순서로 확인하세요.

**단계**

1. 왼쪽 메뉴에서 **사이트**로 이동하세요.
2. **설문** 탭을 선택한 다음 **제출**을 클릭하세요.
3. 제출 시각과 답변이 담긴 제출 목록을 확인하세요.
4. 항목을 클릭하면 모든 응답을 볼 수 있어요.

## 자주 묻는 질문

### 폼이나 설문의 답변에 따라 조건부로 이메일 알림을 보낼 수 있나요?

아니요. 폼 알림 사이드바의 기본 이메일 알림은 모든 제출에 똑같이 적용돼요. 답변에 따라 알림을 나누려면(예를 들어 답변이 "옵션 A"이면 한 팀원에게, "옵션 B"이면 다른 팀원에게 보내려면) **워크플로우**를 사용해야 해요. **Form Submitted**(폼 제출) 워크플로우 트리거에서 조건을 설정해 알림을 나눠 보낼 수 있어요.

### 팀원 여러 명에게 알림을 보낼 수 있나요?

네. **Email (To)** 필드에 유효한 이메일 주소를 여러 개 입력하세요.

### 이메일 알림과 Auto Responder는 어떻게 다른가요?

**이메일 알림**은 새 제출이 들어왔다는 사실을 팀원이나 지정한 받는 사람에게 알려요.

**Auto Responder**는 폼이나 설문을 제출한 사람에게 자동으로 이메일을 보내요.

### Auto Responder 이메일도 알림처럼 이메일 크레딧이 차감되나요?

네. 팀에 보내는 **이메일 알림**과 제출자에게 보내는 **Auto Responder** 이메일 모두 계정의 이메일 크레딧을 사용해요. 크레딧을 다 쓰면 크레딧을 추가할 때까지 두 가지 이메일 모두 발송되지 않아요. 크레딧 사용량은 계정의 이메일 리포팅이나 결제 영역에서 확인할 수 있어요.

### **Email (To)** 필드에 이메일을 여러 개 입력했는데 그중 하나가 잘못된 주소면 나머지는 알림을 받나요?

네. 유효한 주소에는 알림이 그대로 발송돼요. 잘못된 주소는 별도 오류 표시 없이 발송에 실패하고, 다른 받는 사람에게 가는 발송을 막지는 않아요. 다만 반복해서 발송에 실패하지 않도록 **Email (To)** 필드에 입력한 주소를 주기적으로 확인하는 것이 좋아요.

### **Email (To)** 필드에 {{user.email}}, {{contact.email}} 같은 동적 병합 필드를 쓸 수 있나요?

현재는 **Email (To)** 필드에서 병합 필드를 지원하지 않아요. 고정된 이메일 주소를 직접 입력해야 해요. 상황에 따라 받는 사람이 달라져야 한다면 폼 제출로 실행되는 **워크플로우**를 만들고, 워크플로우 액션으로 해당 연락처나 사용자에게 이메일을 보내세요.
