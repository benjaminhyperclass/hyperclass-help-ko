# 폼·설문 빌더의 오른쪽 사이드바

폼·설문 빌더의 오른쪽 사이드바에서는 폼이나 설문을 만들면서 스타일과 설정을 한곳에서 관리할 수 있어요. **스타일**, **테마**, **고급 설정**으로 레이아웃, 입력창 모양, 여백, 색상 등을 조정해 보세요.

## 오른쪽 사이드바 개요

오른쪽 사이드바는 폼·설문 빌더에서 화면 모양과 레이아웃을 설정하는 조작판이에요. **스타일**, **테마**, **고급** 탭이 있어서 폼이나 설문의 모양과 동작을 세밀하게 다듬을 수 있어요. 디자인 설정이 한곳에 모여 있어 변경 내용을 바로 미리보기로 확인하고 일관된 디자인을 유지하기 쉬워요.

오른쪽 사이드바에는 탭이 3개 있어요.

- **스타일**: 폼이나 설문의 레이아웃과 모양을 세밀하게 조정해요.
- **테마**: 미리 만들어 둔 프리셋을 적용해 브랜딩을 일관되게 맞춰요.
- **고급**: 특수한 용도에 필요한 추가 옵션을 사용해요.

## 오른쪽 사이드바 열기

폼 빌더나 설문 빌더에서 오른쪽 사이드바를 열려면 빌더 오른쪽 위에 있는 **Styles & Options**(스타일 및 옵션) 버튼을 클릭하세요. 사이드바를 접으려면 **Styles & Options** 버튼을 다시 클릭하세요.

## 스타일 탭

**스타일** 탭에서는 폼이나 설문의 기본 레이아웃을 설정해요. 이 탭에서 레이아웃, 색상 구성, 브랜딩을 조정할 수 있어요. **스타일** 탭에는 다음 항목이 있어요.

- **레이아웃**: 입력창과 라벨이 보이는 방식, 너비, 간격, **여백**, 폼이나 설문 위쪽 마진 등 전체 배치와 필드 표시 방식을 정해요. 위쪽 마진 설정을 쓰면 **사용자 지정 CSS** 없이도 간격을 조정할 수 있어요. 변경 내용은 미리보기에 바로 반영되고, 마진 칸을 비워 두면 기본 간격이 유지돼요. [자세한 정보를 보려면 여기를 클릭하세요](#요소별-라벨-정렬) — 요소별 라벨 정렬에 관한 내용이에요.
- 이제 위쪽과 아래쪽 **여백**을 0px로 설정해서 가장자리까지 꽉 차는 레이아웃을 만들 수 있어요. 이전에는 여백을 0으로 설정해도 게시된 결과물에 세로 간격이 더 남아 있을 수 있었어요.
- **Footer**(푸터, 설문 전용): 설문 푸터는 응답자가 설문을 진행하는 동안 보게 되는 이동 버튼과 진행 정보를 담당해요. 설문 디자인에 맞게 푸터의 동작, 모양, 이동 버튼을 설정하면서도 응답자가 단계를 쉽게 오갈 수 있게 할 수 있어요.

  푸터에서 설정할 수 있는 항목은 다음과 같아요.

  - **Footer Behavior**(푸터 동작): **Stick to card**(카드에 고정)나 **Stick to page**(페이지에 고정) 중에서 골라, 응답자가 설문을 진행할 때 푸터가 어떻게 움직일지 정해요.
  - **Background Fill**(배경 채우기): 푸터 배경을 꾸며요.
  - **Footer Height**(푸터 높이): 푸터 영역의 높이를 조정해요.
  - **타이포그래피**: 푸터에 쓰는 글꼴 패밀리, 글꼴 크기, 글꼴 굵기를 설정해요.
  - **진행률 표시줄**: 켜 두면 응답자가 설문을 얼마나 진행했는지 눈으로 볼 수 있어요.
  - **버튼 유형**: 설문 이동 버튼을 어떤 형태로 보여 줄지 골라요. 지원되는 텍스트와 화살표 옵션이 있어요.
  - **Button Position**(버튼 위치): 푸터 안에서 이동 버튼의 위치를 정해요.
  - **버튼 텍스트**: **Previous**(이전), **돌아가기**, **다음**, **제출** 버튼에 표시되는 문구를 직접 정해요.
  - **버튼 색상**: 설문 디자인에 맞게 이동 버튼과 텍스트 색상을 바꿔요.
- 푸터 설정을 바꾼 뒤에는 설문을 미리보기로 열어 이동 버튼, 진행 표시, 스타일이 응답자에게 의도한 대로 보이는지 확인하세요.
- **Colors & Background**(색상 및 배경): 글꼴 설정과 배경색을 정하고, 지원되는 곳에는 브랜드에 맞는 배경 이미지나 헤더 이미지를 넣어요.
- **Miscellaneous**(기타): 에이전시 브랜딩을 적용하거나 꺼요.

## 테마 탭

**테마** 탭에서는 프리셋을 이용해 전문적으로 보이는 폼과 설문을 빠르게 만들 수 있어요. 먼저 테마로 기본 설정을 빠르게 끝내고, 그다음 **스타일** 탭에서 간격과 너비를 세밀하게 다듬어 보세요.

폼이나 설문에 테마를 적용하려면 원하는 테마 위에 마우스를 올리고 **Use Theme**(테마 사용)을 선택하세요. 팝업이 나타나면 **계속하기**를 클릭해 선택을 확인하세요.

{% hint style="warning" %}
테마를 바꾸면 지금까지 적용한 스타일 변경 내용이 사라져요.
{% endhint %}

## 버튼 스타일 패널

버튼 스타일 패널에는 버튼 모양을 바꾸는 설정이 모두 모여 있어요. 코드를 쓰지 않고도 완성도 높고 일관된 스타일을 적용할 수 있어요. 프리셋으로 빠르게 시작한 뒤 **타이포그래피**, **여백**, **테두리**, 모서리 반경, **그림자**, 너비를 세밀하게 조정하세요.

{% hint style="info" %}
기존 버튼 설정은 이제 이 패널의 묶음 섹션 안에 모여 있어서 더 쉽고 빠르게 스타일을 바꿀 수 있어요.
{% endhint %}

### 버튼 스타일 패널 열기

1. 빌더에서 **폼**을 열어요.
2. 캔버스에서 버튼 요소를 클릭해요.
3. 오른쪽 사이드바에서 **버튼**(또는 **스타일 > 버튼**)을 펼쳐요.

### 버튼 테마 고르기 (갤러리 + 미리보기)

1. **Select Themes**(테마 선택)를 클릭해요.
2. **채워짐**, **테두리**, **Text Only**(텍스트만) 카테고리를 둘러봐요.
3. 테마 위에 마우스를 올리거나 테마를 선택하면 캔버스에서 바로 미리 볼 수 있어요.
4. **적용**을 클릭하면 선택한 버튼에 테마가 적용돼요.

### 버튼 스타일 맞춤 설정 (묶음별 설정)

목적: CSS 없이 테마를 브랜드 기준에 맞게 세밀하게 조정해요.

**Colors & Background**(색상 및 배경): 텍스트, 배경, 테두리 색상을 정해요.

**타이포그래피**: 글꼴 패밀리와 굵기를 고르고(사용자 지정 글꼴도 쓸 수 있어요), 크기, 자간, 텍스트 변환을 설정해요.

**Layout & Alignment**(레이아웃 및 정렬): 버튼을 **왼쪽** / **중앙** / **오른쪽**으로 정렬해요. **Full Width**(전체 너비)를 켜면 버튼이 컨테이너 너비를 가득 채워요.

**여백**: 위·아래 여백과 왼쪽·오른쪽 여백을 조정해요(값 연결/연결 해제 가능).

**Border & Corner Radius**(테두리 및 모서리 반경): 테두리 두께와 스타일을 정해요. **모서리 반경**을 조정해 버튼을 둥글게 하거나 각지게 만들 수 있어요.

**그림자**: 그림자를 켠 다음 흐림, 거리, 퍼짐 정도를 조정해요.

### 재설정 또는 되돌리기

스타일 변경을 취소하려면 **재설정** 또는 **되돌리기**를 클릭하세요. 다른 테마로 다시 시작하고 싶다면 **Select Themes**를 다시 열어 고르세요.

## 고급 탭

**고급** 탭에는 기본 레이아웃과 테마 설정으로는 부족한 특수한 용도를 위한 추가 옵션이 있어요. 더 세밀하게 조정해야 하지만 폼을 관리하기 쉽게 유지하고 싶을 때 쓰세요. **고급** 탭에서 설정할 수 있는 항목은 다음과 같아요.

- **폼**: 폼 컨테이너의 테두리, 모서리, 그림자를 조정해요.
- **Input Field**(입력 필드): 입력 요소 자체의 스타일을 정해요. 텍스트·포커스 색상, 테두리와 모서리, 너비, 여백, 그림자가 포함돼요.
- **라벨**: 라벨의 타이포그래피와 색상을 정해요.
- **Short Label**(짧은 라벨): 짧은 라벨의 타이포그래피와 색상을 설정해요.
- **플레이스홀더**: 플레이스홀더 텍스트의 모양을 바꿔요.
- **사용자 지정 CSS**: 사용자 지정 CSS를 추가해 정밀하게 제어해요.

{% hint style="warning" %}
**사용자 지정 CSS**는 **스타일**과 **테마**보다 우선 적용되므로 테마 스타일에 영향을 줄 수 있어요.
{% endhint %}

## 요소별 라벨 정렬

요소별 라벨 정렬(Element-Level Label Alignment)을 쓰면 폼이나 설문 전체에 하나의 정렬을 적용하는 대신 필드마다 라벨 위치를 다르게 정할 수 있어요. 특히 간격이 좁은 레이아웃에서 시각적인 리듬과 간격을 세밀하게 맞출 때 유용해요.

사용하기 전에 알아 둘 내용이에요.

- 폼, 설문, 퀴즈에서 쓸 수 있어요(폼은 **1단 레이아웃**일 때만 가능해요).
- 기존 폼은 필드 단위로 직접 바꾸기 전까지 전체 정렬 설정을 그대로 유지해요.
- 텍스트 입력, 드롭다운, 라디오 등 표준 필드에 적용돼요.
- 모바일에서는 데스크톱 설정과 상관없이 정렬이 자동으로 위쪽으로 지정돼요. 그래서 화면이 항상 보기 쉽게 유지돼요.

### 요소별 라벨 정렬 설정하기

1. 폼 빌더나 설문 빌더에서 필드 하나를 선택해요.
2. 오른쪽에 나타나는 사이드바에서 **Label Alignment**(라벨 정렬)를 찾아요.
3. 화살표로 해당 요소에 적용할 정렬을 골라요: **Top**(위쪽), **왼쪽**, **오른쪽**, **Form Default**(폼 기본값).

## 자주 묻는 질문

### 오른쪽 사이드바에서 바꾼 내용은 자동으로 저장되나요?
아니요. 변경 내용을 반영하려면 빌더에서 **저장**을 클릭하세요.

### 나중에 테마를 바꾸면 세밀하게 설정한 스타일이 덮어써지나요?
새 테마를 적용하면 시각 스타일 일부가 초기화될 수 있어요. 테마를 바꾼 뒤에는 **스타일** 탭을 다시 확인하세요. **사용자 지정 CSS**는 여전히 테마와 스타일보다 우선하므로, CSS가 충돌하는지 확인해 보세요.

### 지금 모양을 잃지 않고 여러 테마 프리셋을 빠르게 테스트하려면 어떻게 하나요?
폼이나 설문에 새 테마를 적용한 뒤에는 빌더 오른쪽 위의 **뒤로** 버튼을 눌러 이전 모양으로 돌아갈 수 있어요.

### 레이아웃을 2단이나 한 줄로 바꾸면 필드별 라벨 정렬은 어떻게 되나요?
요소별 라벨 정렬은 **1단 레이아웃**에서만 쓸 수 있어요. **Two Column**(2단 레이아웃)이나 **Single Line**(한 줄 레이아웃)으로 바꾸면 필드별 설정이 사라지고, 라벨은 기본 설정으로 돌아가요.

### 나중에 전체 라벨 정렬을 바꾸면, 이미 설정해 둔 필드는 어떻게 되나요?
**Form Default**(폼 기본값)로 설정된 필드는 새 전체 정렬 설정을 자동으로 따라가요. **왼쪽**, **오른쪽**, **Top**(위쪽)으로 직접 지정한 필드는 필드별로 정한 값을 그대로 유지해요.
