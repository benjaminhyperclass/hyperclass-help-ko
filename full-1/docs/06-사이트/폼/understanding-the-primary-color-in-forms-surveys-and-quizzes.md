# 폼, 설문, 퀴즈의 기본 색상 알아보기

**기본 색상**을 정해 두면 폼, 설문, 퀴즈에서 마우스를 올리거나 클릭하거나 선택할 때마다 브랜드 색상이 나타나요. 이 문서에서는 기본 색상이 어디에 적용되는지, 어떻게 바꾸는지 알려 드려요.

## 기본 색상으로 달라지는 폼 상호작용

**기본 색상** 설정은 방문자가 폼 요소를 다룰 때 어떻게 보일지 정해요. 입력 필드, 드롭다운, 체크박스 같은 요소에 선택한 브랜드 색상이 자동으로 적용돼서, 전체 모습이 브랜드와 일관되게 유지돼요.

디자인 경험이 없어도 폼을 깔끔하고 통일감 있게 꾸밀 수 있어요. 활성화되거나 선택된 요소가 더 잘 보여서 접근성도 좋아져요.

## 기본 색상의 장점

- 브랜드 일관성: 폼, 설문, 퀴즈 전체에 통일된 느낌을 줘요.
- 사용성과 명확성: 마우스를 올린 상태와 활성 상태가 강조돼서, 방문자가 어디에 입력하는지, 무엇을 선택했는지 바로 알 수 있어요.
- 신뢰감과 전문성: 다듬어진 반응형 상태 표시는 완성도를 높이고 폼 작성 완료율을 높이는 데 도움이 될 수 있어요.
- 적은 스타일 작업: 한 번만 설정하면 여러 상호작용 요소에 색상이 자동으로 적용돼요.
- 유연성: 원하면 기본 색상을 버튼 색상에도 똑같이 적용해 시각적으로 조화를 맞출 수 있어요.

## 요소별로 기본 색상이 나타나는 방식

**기본 색상**을 설정하면 여러 폼 상호작용의 모양이 바뀌어요. 방문자가 어디를 클릭하거나 입력하는지 쉽게 알 수 있고, 폼도 브랜드 색상과 맞춰져요. 기본 색상은 방문자가 폼을 다룰 때만 나타나요. 예를 들면 다음과 같은 경우예요.

- 필드 위에 마우스를 올릴 때
- 필드를 클릭하거나 입력할 때
- 체크박스나 라디오 버튼을 선택할 때
- 날짜나 옵션을 고를 때

기본 색상을 정하지 않으면 폼은 기본 중립 스타일로 보여요. 요소별로 어떻게 보이는지 살펴볼게요.

- **폼 필드**: 마우스를 올리거나 클릭하면 테두리가 기본 색상으로 강조돼요.

- **파일 업로드 & 서명 필드**: 테두리와 서명 선 색상에 기본 색상이 쓰여요.

## 기본 색상 바꾸기

1. 폼 빌더, 설문 빌더 또는 퀴즈 빌더에서 **Style and Options**(스타일 및 옵션) > **스타일**로 이동해요.

   ![스타일 및 옵션 메뉴에서 스타일을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055656658/original/vroEbb8ZUVqw7eFjEOQjtra2zD8f2Nr7cA.png?1760037668)
2. 아래로 스크롤해서 **Colors and Background**(색상 및 배경) 아래에 있는 **기본 색상** 필드를 찾아요.

   ![색상 및 배경 아래의 기본 색상 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055656689/original/7Mrihg8fVlZathpY1OEvgWptjbJ9uFpv0A.png?1760037753)
3. 색상을 고르거나 16진수 색상 코드(hex code)를 직접 입력해요.
4. 버튼도 같은 색상으로 맞추고 싶다면 **Map Primary color to Button color**(기본 색상을 버튼 색상에 적용) 토글을 켜요.
5. **저장**을 클릭해요. 폼의 모든 상호작용 요소에 새 색상이 자동으로 적용돼요.

   ![기본 색상을 선택하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055656749/original/QO6kwktyQzSUD6tE2f8gJiDl68etqLpyLg.png?1760037848)

## 자주 묻는 질문

### 기본 색상을 바꾸면 모든 폼에 적용되나요?
네. 기본 스타일을 쓰는 모든 폼이 기본 색상을 바꾸는 즉시 자동으로 업데이트돼요.

### 폼 하나에만 다른 색상을 설정할 수 있나요?
아니요, 지금은 할 수 없어요. 기본 색상은 계정 안의 모든 폼에 적용돼요.

### 마우스를 올릴 때나 포커스 효과를 끌 수 있나요?
아니요. 이 효과는 폼 방문자가 더 쉽고 편하게 쓸 수 있도록 기본으로 들어 있어요.

### 모바일 기기에서도 같은 효과가 보이나요?
네, 강조 효과가 모바일 기기에도 똑같이 적용돼요.

### 버튼은 기본 색상과 다른 색으로 유지할 수 있나요?
네. **Map Primary color to Button color** 토글을 끈 상태로 두고, 테마나 사용자 지정 스타일로 **버튼 색상**을 따로 정하세요.
