# 이전 블로그에서 새 블로그로 게시물 옮기기

퍼널이나 웹사이트에서 하이퍼클래스의 이전 블로그 기능으로 게시물을 만들었다면, **Default Blog**(기본 블로그)에서 새 블로그로 옮길 수 있어요. 이 문서에서는 옮기면 무엇이 달라지는지, 기존 게시물을 어떻게 옮기는지, 옮긴 뒤에 무엇을 확인해야 하는지 알려 드려요.

[동영상](https://www.youtube.com/embed/wDgjbh3TAgw?&wmode=opaque)

## 이전 블로그와 게시물은 어떻게 되나요?

하이퍼클래스의 이전 블로그 기능으로 만든 게시물은 **사이트 > 블로그**의 **Default Blog**에 있어요. 기존 블로그도 계속 쓸 수 있지만, 이전 방식의 블로그 설정을 사용해요. 그래서 새 블로그에 있는 URL 관리와 SEO 개선 기능 중 일부는 쓸 수 없어요.

게시물을 새 블로그로 옮기면 개선된 블로그 관리, URL 정리, 표준 URL(canonical URL) 설정, 사이트맵 기능을 쓸 수 있어요. 새 블로그를 만들고 관리하는 방법은 [블로그 및 블로그 게시물 시작하기](블로그/getting-started-with-blogs-and-blog-posts.md)를 참고하세요.

{% hint style="warning" %}
게시물을 옮기면 원래 URL이 바뀌어요. 이전하기 전에 게시된 글의 URL을 기록해 두면, 필요한 곳에 리다이렉트를 설정할 수 있어요.
{% endhint %}

블로그의 흐름은 중요해요. 글을 쓰는 사람은 독자의 관심을 끌고 붙잡을 수 있게 블로그를 구성할 수 있고, 독자는 글을 더 편하게 찾아 읽을 수 있어요. 아래 이미지는 새 블로그 흐름 설계도예요. 글을 쓰는 사람과 읽는 사람 모두를 위해 어떻게 개선했는지 한눈에 볼 수 있어요.

## 이전 블로그에서 새 블로그로 옮기기

1. **사이트 > 블로그**로 이동하세요.
2. **Default Blog**를 여세요. 이전 퍼널·웹사이트 블로그 기능으로 만든 게시물이 모여 있어요.
3. **Default Blog**에 있는 게시물을 살펴보세요.
4. 옮길 게시물 옆의 체크박스를 선택하세요.
5. **Move Blog**(블로그 이동)를 클릭하면 선택한 게시물이 새 블로그로 옮겨져요.

{% hint style="info" %}
URL이 바뀐 뒤에는 원래 블로그 게시물 URL이 옮겨진 게시물을 가리키지 않아요. 새 URL을 확인하고, 이전에 게시한 링크에는 필요하면 301 리다이렉트를 설정하세요.
{% endhint %}

## 이전 후 확인할 것

- 옮긴 게시물 확인: 옮긴 대상 블로그를 열어 게시물이 있는지, 제대로 표시되는지 확인하세요.
- 새 URL 확인: 옮긴 게시물을 각각 새 URL로 열어 보세요. 이전에 게시한 URL이 바뀌었다면 이전 경로에서 새 게시물 URL로 가는 301 리다이렉트를 만드세요. 자세한 방법은 [301 URL 리다이렉트 설정하기](퍼널-웹사이트/how-to-setup-301-url-redirects.md)를 참고하세요.
- 웹사이트·퍼널 페이지 확인: **블로그 게시물 목록** 요소를 쓴다면 새 블로그를 가리키는지, 페이지를 다시 게시했는지 확인하세요. 자세한 방법은 [퍼널 단계 또는 웹사이트 페이지에 블로그 게시물 요소 추가하기](블로그/add-blog-post-element-in-funnel-step-or-website-page.md)를 참고하세요.
