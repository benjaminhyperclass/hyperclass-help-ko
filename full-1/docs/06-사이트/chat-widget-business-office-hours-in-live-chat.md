# 채팅 위젯 실시간 채팅 영업시간 설정

**채팅 위젯**에서 실시간 채팅의 영업시간을 설정할 수 있어요. 영업시간 외에 방문자가 채팅을 열면 다른 메시지가 나가고, 연락처 정보를 남기는 폼이 표시돼요.

[동영상](https://www.youtube.com/embed/M6ijFTMIx04?&wmode=opaque)

## 어떻게 작동하나요?

1. **사이트 > 채팅 위젯**으로 이동하세요.
2. 채팅 위젯 유형으로 **Live chat**(실시간 채팅)을 선택하세요.

   ![채팅 위젯 유형에서 Live chat을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035806380/original/wVv7589BVJuYDlX8tYZwRzqs1jfWEF2Izg.png?1730390876)
3. 채팅 위젯 설정에서 **채팅 창** 탭을 열면 **실시간 채팅 영업시간 설정** 옵션이 있어요.

   ![채팅 창 탭의 실시간 채팅 영업시간 설정 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035806423/original/Q92B35L1eHyIX8gGWe7bFzxTk5C7c8d-pw.png?1730390915)
4. **영업시간 외 환영 메시지**에서 영업시간 외에 보여 줄 환영 메시지를 직접 바꿀 수 있어요. 기본 메시지는 "We are currently offline."이에요.

   ![영업시간 외 환영 메시지 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035806451/original/H4laTEHRPKXBWm00fYjwmwPI43B0Ih5RiQ.png?1730390947)
5. 일요일부터 토요일까지 요일마다 시간대를 여러 개 설정할 수 있어요. 시간대끼리 겹치면 안 돼요.
6. 설정한 시간을 원하는 요일로 복사할 수 있어요. 여러 요일을 한꺼번에 선택해도 돼요. 캘린더의 가용성 설정과 같은 방식으로 만들어졌어요.
7. 시간대는 비즈니스(로케이션)의 시간대를 기준으로 해요.
8. 방문자가 문의 폼을 제출하면 채팅이 자동으로 종료돼요.

영업시간 설정을 켜 두었고 방문자의 시간대가 설정한 영업시간에 해당하면 **환영 메시지**에 입력한 내용이 표시돼요. 영업시간 외에는 방문자에게 연락처 정보 폼이 전송돼요.

{% hint style="info" %}
위젯에서 **알림 소리**를 켜 두었다면, **영업시간 외 환영 메시지**가 나타날 때 방문자에게 소리가 들릴 수 있어요.
{% endhint %}
