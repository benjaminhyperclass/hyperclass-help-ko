# 임베드형 음성 AI 채팅 위젯 만들기

음성 AI 채팅 위젯을 웹사이트나 퍼널 콘텐츠 안에 직접 넣는 방법을 안내해요. 화면 구석에 떠 있는 위젯 대신, 페이지의 일부처럼 자연스럽게 대화를 시작하고 싶을 때 쓰세요. 하이퍼클래스의 **임베드/인라인** 배치를 쓰면 위젯이 나타나는 위치를 직접 정할 수 있어서, 레이아웃과 브랜딩, 전환 흐름에 맞추기 쉬워요.

## 임베드형 음성 AI 위젯이란?

임베드형 음성 AI 채팅 위젯은 화면 모서리에 떠 있지 않고 웹사이트나 퍼널 콘텐츠 안에 인라인으로 표시되는 음성 AI 위젯이에요. 랜딩 페이지, 리드 수집 페이지, 서비스 페이지, 오퍼 섹션처럼 중요한 페이지에서 음성 AI를 원하는 방식으로 보여 줄 수 있어요.

기본값인 **고정** 배치와 달리 **임베드/인라인** 배치에서는 위젯이 페이지 레이아웃의 일부가 돼요. 방문자는 주변 콘텐츠와 이어지는 자연스러운 대화 경험을 하게 돼요.

### 임베드형 음성 AI 채팅 위젯의 장점

방문자가 가장 많이 반응할 만한 자리에 대화창을 직접 놓을 수 있어요.

- 인라인 배치의 유연성: 떠 있는 채팅 버블에 의존하지 않고 페이지 섹션 안에 음성 AI 위젯을 바로 넣을 수 있어요.
- 더 자연스러운 사용자 경험: 별도의 오버레이가 아니라 웹사이트 콘텐츠의 일부처럼 대화가 느껴져요.
- 깔끔한 페이지 디자인: 퍼널이나 웹사이트 레이아웃에 맞춰 브랜드 느낌을 살릴 수 있어요.
- 모바일 지원: 임베드 위젯은 기본적으로 모바일 방문자에게 맞게 화면 크기에 반응해요.
- 유연한 배포 방식: 인라인 위젯을 여러 개 넣을 수 있고, 같은 웹사이트나 퍼널에서 임베드 위젯과 고정 위젯을 함께 쓸 수도 있어요.

### 임베드형 음성 AI 채팅이 잘 맞는 곳

임베드형 음성 AI 채팅은 아래 위치에서 쓸 수 있어요.

- 퍼널
- 웹사이트
- 랜딩 페이지
- 사용자 지정 HTML 사이트
- 그 밖에 채팅 위젯을 설치할 수 있는 지원 페이지

임베드 위젯은 기본적으로 모바일에 대응하기 때문에, 작은 화면에서는 크기가 자동으로 조정되고 페이지 콘텐츠의 일부로 유지돼요.

## 임베드형 음성 AI 채팅 위젯 만들기

설정을 제대로 해 두면 위젯이 원하는 위치에 나타나고, 웹사이트나 퍼널 어디서나 일관되게 동작해요.

#### 1단계. 새 채팅 위젯 만들기

**사이트 > 채팅 위젯**으로 이동한 뒤 **+ 신규**를 클릭하거나 기존 위젯을 열어요.

![채팅 위젯 화면에서 새 위젯 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069727496/original/9bw1eW0iksbWHLRoSKoBswB3hp0xJ826tA.png?1776872089)

#### 2단계. 음성 AI 채팅 선택하기

**음성 AI** 채팅 옵션을 선택해요.

![음성 AI 채팅 옵션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069727655/original/qXH-6HMXpq7qBhhDIuOeaqC1wHFeQWdTZQ.png?1776872176)

#### 3단계. 위젯 배치를 임베드로 설정하기

1. **스타일** 탭으로 이동해요.
2. **위젯 배치**에서 **임베드/인라인**(콘텐츠 안에 표시)을 선택해요.

이렇게 하면 위젯이 화면 위에 떠 있지 않고 **페이지 레이아웃 안에** 표시돼요.

![위젯 배치에서 임베드/인라인 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069727741/original/dj154NLfaKUa1PpzcyWzC93kWDQtWUakPQ.png?1776872225)

#### 4단계. 위젯 사용자 지정하기

페이지 디자인에 맞게 스타일 옵션을 조정해요.

임베드형 음성 AI 위젯에서는 아래 옵션을 설정해요.

1. **위젯 배치**에서 음성 AI 위젯이 웹사이트에 표시되는 방식을 선택해요.

   - **고정**: 위젯을 페이지 모서리에 고정해요.
   - **임베드/인라인**: 위젯을 페이지 콘텐츠 안에 인라인으로 표시해요.

2. **임베드/인라인** 위젯이라면 **표시 모드**를 설정해요.

   - **아바타**: 움직이지 않는 이미지로 보여 줘요.
   - **비주얼라이저**: 음성에 맞춰 움직이는 시각 효과를 보여 줘요. **비주얼라이저**를 선택하면 **인터페이스 크기**를 **작게**, **미디엄**, **길게** 중에서 골라요.

   ![표시 모드와 인터페이스 크기 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073729673/original/fQIvJqTTLwP5jMpWgi3CcgP0Ik1btvj9kw.gif?1781585870)

3. **채팅 창** 탭에서 **버튼 텍스트**를 수정해요. 인라인 레이아웃에서는 이 텍스트가 아바타 아래에 표시돼요.

   - 예: "여기서 전화하세요"를 "AI와 대화하기"나 "질문하기"로 바꿔요.

원한다면 **추가 옵션**을 열어 비즈니스 이름이나 규정 준수 푸터 같은 브랜딩 요소도 조정할 수 있어요. 오른쪽 미리보기에서는 임베드 위젯 디자인이 실시간으로 바뀌는 모습을 볼 수 있어요.

채팅 위젯 사용자 지정에 대한 자세한 내용은 채팅 위젯 사용자 지정 개요 문서를 참고하세요.

![임베드 위젯 디자인을 조정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073729682/original/QiZHVS1JXICxmOh_YgywBlIgO1QqePWucg.png?1781585894)

#### 5단계. 임베드 코드 만들기

위젯 디자인이 마음에 들면 오른쪽 위의 **코드 가져오기** 버튼을 클릭해요. 고유한 임베드 코드가 담긴 팝업 창이 나타나요. **복사**를 클릭해서 클립보드에 저장해요.

![코드 가져오기 팝업에서 임베드 코드 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818713/original/G_qn00fF8x7AfFOKqFHJOrz-YSSQH_AIEw.png?1762513569)

#### 6단계. 웹사이트나 퍼널에 위젯 넣기

코드 블록 요소를 사용하면 사이트나 퍼널의 원하는 위치에 위젯을 넣을 수 있어요.

퍼널에 넣으려면 이렇게 해요.

1. **사이트 > 퍼널**로 이동해 위젯을 넣을 퍼널 페이지를 열어요.
2. **페이지 편집**을 클릭해요.
3. 왼쪽 사이드바의 **Quick Add**(빠른 추가) > **사용자 지정**에서 "**코드**"를 검색하고, **코드** 요소를 페이지로 끌어다 놓아요.
   ![페이지에 코드 요소 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818772/original/sNKOu6GEeWooDycr2qTZDfJw3YQozJHCyw.png?1762513600)
4. **Open Code Editor**(코드 편집기 열기)를 클릭해요.

   ![코드 편집기 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818893/original/kr_T4sKxXSt9dgrUjDi9a4BaHUDnT4_j0w.png?1762513635)

5. 채팅 위젯 편집 화면에서 복사해 둔 임베드 코드를 붙여 넣어요.

   ![코드 편집기에 임베드 코드 붙여 넣기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818964/original/9ZvyZF_rvhmfWvpc282yCc28pFdaQ7NzXg.png?1762513656)
6. **저장**을 클릭한 뒤 페이지를 **게시**해요.

   ![저장 후 페이지 게시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155057818975/original/Y-Xg-ZENYtVB9JyQ4MCGgctMv8wyNEHKcQ.png?1762513671)

게시하면 음성 AI 위젯이 다른 콘텐츠 블록처럼 페이지 안에 인라인으로 나타나요.

## 알아 두면 좋은 동작

- 임베드 위젯은 모바일에 완전히 대응해요. 작은 화면에서는 크기가 자동으로 조정돼요.
- **임베드/인라인** 모드에서는 일부 사용자 지정 옵션이 비활성화돼요. 떠 있는 위젯에만 해당하는 옵션이기 때문이에요. 예를 들어 **위젯 위치**와 **문의 폼 활성화** 토글 설정이 있어요.
- **표시 모드** 옵션은 현재 음성 AI 환경에 맞춰져 있어요.
- 같은 사이트나 퍼널에 임베드 위젯을 여러 개 둘 수 있어요. 모두 같은 음성 AI 에이전트에 연결돼요.
- 섹션마다 임베드 위젯과 고정 위젯을 섞어 쓸 수도 있어요. 방문자의 참여를 최대한 끌어내는 데 도움이 돼요.

## 활용 팁

위젯을 알맞은 곳에 두면 페이지 흐름을 끊지 않고 전환을 도울 수 있어요. 방해되지 않으면서 필요한 순간에 도움이 되는 채팅을 목표로 하세요.

- 폼, 오퍼, 예약 영역, 문의 안내처럼 전환 의도가 높은 콘텐츠 근처에 위젯을 두세요.
- 위젯 브랜딩을 페이지와 맞추면 더 자연스러워 보여요.
- 좁은 섹션 안에서 위젯이 답답해 보이지 않도록 여백과 정렬을 확인하세요.
- 게시한 뒤에는 모바일 화면에서 읽기 편한지, 여백은 적절한지 확인하세요.
- 인트로 메시지와 확인 메시지는 분명하고, 행동을 이끄는 문구로 쓰세요.

## 자주 묻는 질문

### 임베드 위젯은 페이지의 어디에 두는 게 좋나요?
히어로 섹션, 오퍼 섹션, 리드 수집 영역, 서비스 페이지처럼 방문자가 반응할 가능성이 높은 곳이 좋아요.

### **임베드/인라인**을 선택했더니 일부 사용자 지정 설정이 사라졌어요.
떠 있는 위젯에만 해당하는 설정은 자동으로 숨겨져요. **임베드/인라인** 모드에서는 하이퍼클래스가 인라인 배치와 관련된 설정만 보여 줘요.

### 라이브 채팅 위젯에서도 **임베드/인라인** 배치를 쓸 수 있나요?
네, 라이브 채팅에서도 임베드/인라인을 지원해요. 자세한 내용은 라이브 채팅 임베드 문서를 참고하세요.

### 어떤 채팅 위젯 유형에서 **임베드/인라인** 배치를 쓸 수 있나요?
올인원 채팅, 이메일/SMS, WhatsApp, Facebook, Instagram, 라이브 채팅, 음성 AI에서 쓸 수 있어요.
