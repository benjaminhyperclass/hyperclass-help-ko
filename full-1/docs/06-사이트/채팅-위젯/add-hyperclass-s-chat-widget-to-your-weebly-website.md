# Weebly 웹사이트에 채팅 위젯 추가하기

하이퍼클래스 웹채팅을 Weebly 웹사이트에 붙이면 방문자와 바로 대화하고 고객으로 전환할 수 있어요. 이 문서에서는 임베드 코드를 가져오는 방법과 Weebly에 코드를 넣는 두 가지 방법을 안내해요.

## 채팅 위젯 임베드 코드 가져오기

**사이트 > 채팅 위젯 > 코드 가져오기**에서 임베드 코드를 복사하세요.

![채팅 위젯에서 코드 가져오기를 눌러 임베드 코드를 복사하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297287141/original/_OQtFli-JPFoV94EyOxp5SVBt35ozqrJ9w.gif?1683908337)

## Weebly 웹사이트에 채팅 위젯 추가하기

Weebly에 채팅 위젯을 넣는 방법은 두 가지예요. 한 가지를 골라 따라 하세요.

### 방법 1: Weebly의 헤더 코드 삽입 기능으로 추가하기

1. Weebly 계정에 로그인한 다음 웹사이트 편집기로 이동하세요.
2. **설정**을 클릭하세요.

   ![Weebly 편집기에서 설정을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297280726/original/_MAQaHtpb9-qXJ4aoqdEUsIuPy78wgX_jQ.jpeg?1683906475)

3. 왼쪽 메뉴에서 **SEO**를 선택하세요.

   ![설정 왼쪽 메뉴에서 SEO를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297280723/original/vgjwqVj1oZOeepZ0pIjTe4994G_T6EHb9g.jpeg?1683906474)

4. 아래로 스크롤해 **Header Code Injection**(헤더 코드 삽입) 섹션을 찾아 **편집**을 클릭하세요.
5. 복사해 둔 코드를 Weebly의 **Header Code Injection** 입력란에 붙여 넣으세요.

   ![Header Code Injection 입력란에 코드를 붙여 넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297280724/original/Dt2bkzxdUvhDnfiVfX39l2TcIUbKHsZq_Q.jpeg?1683906474)

6. **저장**을 클릭해 변경 사항을 저장하세요.

### 방법 2: Weebly의 사용자 지정 HTML/임베드 코드 요소로 추가하기

1. Weebly 계정에 로그인한 다음 웹사이트 편집기로 이동하세요.
2. 왼쪽 메뉴에서 **요소**를 클릭하고, 목록에서 **Custom HTML/Embed Code**(사용자 지정 HTML/임베드 코드)를 선택하세요.
3. Custom HTML 요소를 채팅 위젯이 나타나길 원하는 페이지 위치로 끌어다 놓으세요.

   ![Custom HTML 요소를 페이지에 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297280725/original/P8tKnHQ9CnrLaJr_ZYiWHjVZWplVlSVrtQ.jpeg?1683906474)

4. 복사해 둔 채팅 코드를 Weebly의 Custom HTML 요소에 붙여 넣으세요.
5. **게시**를 클릭해 변경 사항을 저장하세요.
