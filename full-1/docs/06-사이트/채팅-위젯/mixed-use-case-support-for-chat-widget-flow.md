# 채팅 위젯 흐름의 혼합 사용 사례 지원

미리 구성된 A2P 채팅 위젯 하나로 마케팅 문자와 정보성 문자의 수신 동의를 각각 따로 받는 방법을 안내해요. 홍보 문자와 정보성 문자를 함께 보내는 사업자가 A2P 캠페인을 등록할 때 쓰는 기능이에요. 새로 생긴 메시지 유형 **혼합**을 선택하면 **Low Volume Mixed**(소량 혼합) 캠페인 사용 사례가 자동으로 지정되고, 메시지 종류별로 동의를 따로 받는 위젯이 만들어져요.

{% hint style="warning" %}
메시지 프로그램에 홍보 메시지와 정보성·비마케팅 메시지가 실제로 모두 들어 있을 때만 **혼합**을 선택하세요. 캠페인 사용 사례, 설명, 샘플 메시지, 동의 절차, 실제 발송 내용이 서로 일치해야 해요.
{% endhint %}

## 혼합 사용 사례 지원이란?

하이퍼클래스의 미리 구성된(Pre-Built) A2P 채팅 위젯 등록 흐름에 메시지 유형 **혼합**이 추가됐어요. 하나의 메시지 프로그램에서 마케팅·홍보 메시지와 트랜잭션·정보성 메시지를 모두 보내는 경우를 위한 유형이에요.

이전에는 두 종류의 메시지가 모두 필요한 사업자가 이 시나리오에서 미리 구성된 채팅 위젯 방식을 쓸 수 없었어요. 더 수동적인 방식으로 등록해야 했죠. 이제 이 사용 사례도 위젯 우선(Widget-First) 안내 흐름에서 등록할 수 있어요.

**혼합**을 선택하면 하이퍼클래스가 캠페인 사용 사례를 **Low Volume Mixed**(소량 혼합)로 자동 지정해요. 그리고 마케팅 메시지와 정보성 메시지에 대해 각각 따로 동의를 받는 채팅 위젯을 만들어 줘요.

### 혼합 사용 사례 지원의 장점

홍보와 정보성 메시지를 함께 보내는 프로그램도 안내형 위젯 우선 등록 방식으로 진행할 수 있어요. 설정은 간단해지고, 동의 종류는 분명하게 나뉘어요.

- 하나의 안내 흐름: 혼합 메시지 프로그램을 미리 구성된 채팅 위젯 방식으로 등록해요.
- 동의 분리: 같은 위젯에서 마케팅 동의와 정보성·비마케팅 동의를 각각 받아요.
- 사용 사례 자동 지정: **혼합**을 선택하면 캠페인 사용 사례가 Low Volume Mixed로 자동 설정돼요.
- 직접 선택하는 수신 동의: 두 동의 체크박스 모두 미리 선택되어 있지 않아서, 연락처가 받고 싶은 메시지를 직접 골라요.
- 보호되는 규정 준수 콘텐츠: 필수 고지 문구와 규정 준수에 민감한 필드는 시스템이 관리하며 잠겨 있어요.
- 수동 설정 오류 감소: 직접 입력해야 하는 규정 준수 항목이 줄어들어요.

## 혼합 메시지 유형의 구분

메시지 유형은 캠페인에서 보낼 메시지의 성격을 나타내요. 같은 메시지 프로그램에서 홍보 콘텐츠와 트랜잭션·정보성 메시지를 실제로 함께 보낼 때 **혼합**을 선택하세요.

채팅 위젯 흐름에는 다음 유형이 있어요.

- **마케팅** / **홍보용**: 판매, 오퍼, 할인, 뉴스레터 등 홍보성 메시지예요.
- **트랜잭션** / **Non-Marketing**(비마케팅): 예약 알림, 주문 확인, 서비스 안내 등 정보성 메시지예요.
- **혼합**: 위 두 종류를 모두 포함하는 하나의 메시지 프로그램이에요.

**혼합**과 **Low Volume Mixed**의 차이: **혼합**은 안내 흐름에서 선택하는 메시지 유형이에요. **Low Volume Mixed**(소량 혼합)는 **혼합**을 선택하면 하이퍼클래스가 자동으로 지정하는 A2P 캠페인 사용 사례예요.

## 혼합 위젯의 마케팅·정보성 동의

혼합 채팅 위젯은 마케팅 동의와 정보성 동의를 분리해요. 연락처가 받을 메시지를 분명하게 직접 선택할 수 있어요. 이후 발송하는 메시지를 연락처가 실제로 준 동의에 맞추는 데 도움이 돼요.

생성되는 위젯에는 다음이 포함돼요.

- 정보성·트랜잭션 메시지용 동의 체크박스 1개
- 마케팅·홍보 메시지용 동의 체크박스 1개
- 각 동의 옵션에 연결된 별도의 고지 블록
- 미리 선택된 동의 체크박스 없음

연락처는 정보성 메시지만, 마케팅 메시지만, 또는 둘 다 받겠다고 선택할 수 있어요. 발송할 때는 해당 연락처에 저장된 동의 선택을 각각 지켜야 해요.

## 시스템이 관리하는 규정 준수 콘텐츠

미리 구성된 A2P 채팅 위젯은 규정 준수에 민감한 콘텐츠를 하이퍼클래스가 관리해요. 그래서 실제 수신 동의 화면이 심사를 위해 제출한 캠페인과 계속 일치해요. 혼합 위젯도 다른 위젯 우선 캠페인과 같은 보호 구조를 따라요.

시스템이 관리하는 요소에는 다음과 같은 필수 콘텐츠가 있어요.

- 동의 고지 문구
- STOP 및 HELP 안내
- 메시지 발송 빈도 안내
- 메시지 및 데이터 요금 안내
- 필수 동의 체크박스
- 등록 흐름에서 생성되는 그 밖의 규정 준수 민감 필드

이 필수 요소는 편집하거나 삭제할 수 없어요. 다만 모양 설정은 지원되는 범위에서 조정할 수 있어요.

## 꼭 확인할 규정 준수 사항

혼합 위젯은 동의 설정을 간편하게 해 주지만, 캠페인 승인 여부는 등록 내용 전체에 달려 있어요. 사업 내용, 메시지 목적, 동의 방식, 수신자가 받을 메시지가 정확하게 반영되어야 해요.

- 실제 메시지 프로그램과 일치시키기: 홍보 메시지와 정보성 메시지를 실제로 모두 보낼 때만 **혼합**을 선택하세요.
- 샘플 메시지 맞추기: 샘플 메시지에 혼합 캠페인에 포함된 메시지 종류가 드러나야 해요.
- 동의 범위 지키기: 마케팅 동의와 정보성 동의는 서로 독립된 선택이에요.
- 잠긴 고지 문구는 수정하지 않기: 미리 구성된 흐름에서 생성된 필수 규정 준수 콘텐츠는 의도적으로 보호돼요.
- 제출한 페이지 접근 가능하게 유지하기: 등록할 때 입력한 페이지에 채팅 위젯이 게시되어 있고, 누구나 볼 수 있어야 해요.
- 제출한 페이지에 다른 SMS 수신 동의 받지 않기: 제출한 페이지에서 SMS 동의를 받는 폼은 미리 구성된 채팅 위젯 하나뿐이어야 해요.
- 웹사이트 규정 준수 유지하기: 제출하기 전에 **개인정보처리방침**, 이용약관, 사업자 정보가 웹사이트에 있는지 확인하세요.

{% hint style="info" %}
승인 관련 참고: 안내형 혼합 흐름은 피할 수 있는 설정 오류를 줄여 주지만, 캠페인 승인을 보장하지는 않아요. 최종 승인은 등록 내용 전체와 해당 통신사 요건에 따라 결정돼요.
{% endhint %}

## 채팅 위젯 흐름에서 혼합 사용 사례 설정하기

혼합은 기존 미리 구성된 A2P 채팅 위젯 등록 절차를 그대로 사용해요. 새로 추가된 메시지 유형 선택에 따라 캠페인 분류와 이중 동의 위젯 구조가 정해져요. 아래의 혼합 전용 단계를 진행한 뒤, 일반 위젯 우선 등록 절차를 이어서 마무리하세요.

### 1단계: 캠페인 등록 열기

캠페인 등록은 A2P 브랜드 요건을 먼저 마친 뒤 **신뢰 센터**에서 진행해요.

1. 해당 서브 계정을 엽니다.
2. **설정 > 전화 시스템 > 신뢰 센터**로 이동합니다.
3. A2P 캠페인 등록 화면으로 이동합니다.
4. **Chat Widget Setup**(채팅 위젯 설정) 흐름을 선택합니다.

### 2단계: 혼합 선택하기

**혼합**을 선택하면 등록 흐름에 이 캠페인이 홍보 메시지와 정보성 메시지를 모두 보낸다는 사실이 전달돼요. 그러면 하이퍼클래스가 그에 맞는 Low Volume Mixed 사용 사례를 자동으로 지정해요.

1. **Messaging Use Case**(메시징 사용 사례) 단계로 이동합니다.
2. **혼합**을 선택합니다.
3. **캠페인 사용 사례**가 **Low Volume Mixed**(소량 혼합)로 자동 설정되었는지 확인합니다.
4. 안내에 따라 나머지 캠페인 질문을 이어서 진행합니다.

![혼합 메시지 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080734379/original/dOFPBjxJHMgPsl4iMkGeakQvOcv2LlND3w.png?1789140163)

### 3단계: 생성된 혼합 채팅 위젯 확인하기

위젯 미리보기에서 이중 동의 구조가 제대로 만들어졌는지 확인할 수 있어요. 제출할 웹사이트 페이지에 위젯을 설치하기 전에 꼭 살펴보세요.

생성된 위젯에 다음이 모두 있는지 확인하세요.

- 정보성·트랜잭션 메시지용 동의 체크박스가 따로 있는지
- 마케팅·홍보 메시지용 동의 체크박스가 따로 있는지
- 각 동의 유형별 고지 문구가 있는지
- 미리 선택된 동의 항목이 없는지

![생성된 혼합 채팅 위젯 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080734457/original/M7RLGjH-ASALiZplsDQN9UF-qrrXV2L2Vw.png?1789140188)

### 4단계: 나머지 위젯 우선 설정 마무리하기

**혼합** 옵션은 메시지 분류와 동의 구조만 바꿔요. 위젯 설치, 웹사이트 검토, 캠페인 제출, 상태 확인은 기존 미리 구성된 A2P 절차 그대로 진행해요.

1. 생성된 위젯을 검토합니다.
2. 허용되는 모양 사용자 지정이 있으면 적용합니다.
3. 제출한 웹사이트 페이지에 채팅 위젯을 설치합니다.
4. 제출한 페이지와 웹사이트가 해당 규정 준수 요건을 충족하는지 확인합니다.
5. **캠페인 상세 정보**와 샘플 메시지를 검토합니다.
6. 제출 전에 확인된 문제가 있으면 수정합니다.
7. 캠페인을 제출하고 **신뢰 센터**에서 상태를 확인합니다.

설치부터 캠페인 제출까지의 전체 절차는 [채팅 위젯으로 미리 구성된 A2P 캠페인 등록](../../15-전화-시스템/pre-built-a2p-campaign-widget-first-registration-flow.md)을 참고하세요.

## 자주 묻는 질문

### 혼합을 선택하면 어떻게 되나요?
하이퍼클래스가 캠페인 사용 사례를 Low Volume Mixed로 자동 지정해요. 그리고 정보성 동의와 마케팅 동의를 각각 따로 받는 채팅 위젯을 만들어 줘요.

### 연락처가 한 가지 유형의 메시지만 수신 동의할 수 있나요?
네. 두 체크박스는 서로 독립적이라서 연락처가 정보성 메시지, 홍보 메시지, 또는 둘 다 선택할 수 있어요.

### 혼합 위젯의 동의 체크박스는 미리 선택되어 있나요?
아니요. 어느 체크박스도 미리 선택되어 있지 않아요. 연락처가 제공할 동의를 직접 선택해야 해요.

### 생성된 동의 고지 문구를 편집할 수 있나요?
아니요. 미리 구성된 A2P 흐름에서 생성된 고지 문구, 필수 필드, 동의 컨트롤은 규정 준수에 민감한 요소라 잠겨 있어요.

### 혼합과 Low Volume Mixed는 같은 건가요?
정확히 같지는 않아요. **혼합**은 **Chat Widget Setup**(채팅 위젯 설정)에서 보이는 메시지 유형 선택 항목이에요. Low Volume Mixed(소량 혼합)는 **혼합**을 선택하면 지정되는 A2P 캠페인 사용 사례예요.

### 마케팅 메시지만 보내는데 혼합을 선택해도 되나요?
아니요. 사업자가 실제로 보낼 메시지를 정확하게 나타내는 메시지 유형을 선택하세요.

### 혼합 채팅 위젯을 쓰면 A2P 승인이 보장되나요?
아니요. 안내형 흐름은 피할 수 있는 설정 문제를 줄여 줄 뿐이에요. 캠페인 전체, 웹사이트, 동의 절차, 샘플 메시지가 해당 심사 요건을 충족해야 해요.

### 마케팅 메시지와 정보성 메시지를 둘 다 보낸다는 이유만으로 수동 설정을 해야 하나요?
아니요. 이제 혼합 지원 덕분에 이런 메시지 시나리오도 안내형 채팅 위젯 설정 흐름을 쓸 수 있어요. 다른 지원되는 동의 방식이 필요한 경우에는 **Manual Setup**(수동 설정)을 계속 쓸 수 있어요.
