# Duda 웹사이트에 채팅 위젯 추가하기

하이퍼클래스 채팅 위젯을 Duda 웹사이트에 붙이면 방문자와 바로 대화하고 고객으로 이어 갈 수 있어요. 이 문서에서는 임베드 코드를 복사하는 방법과, 이 코드를 Duda 웹사이트에 넣는 두 가지 방법을 안내해요.

## 임베드 코드 복사하기

**사이트 > 채팅 위젯 > 코드 가져오기**에서 임베드 코드를 복사하세요.

![사이트 > 채팅 위젯 > 코드 가져오기에서 임베드 코드를 복사하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297297829/original/oKtzhm7Qaeia1e1Pzl-q2_GbFteEF8ZoBw.gif?1683912268)

## Duda 웹사이트에 채팅 위젯 추가하기

{% hint style="info" %}
아래에 나오는 Duda 화면의 메뉴와 버튼 이름은 Duda에서 쓰는 영어 이름 그대로 적었어요.
{% endhint %}

### 방법 1: Head HTML에 붙여넣기

1. Duda 계정에 로그인한 뒤, 웹사이트 편집 화면을 열어요.
2. 채팅 위젯을 추가할 사이트로 이동해서 **Edit Site**(사이트 편집) 버튼을 클릭하세요.

![Duda에서 사이트 편집 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297320884/original/wBO0Ap0VVrjoUxrDNads9rKtzUtTk8IuFg.jpeg?1683922795)

3. 왼쪽 열에서 **Settings**(설정)를 클릭하세요.
4. **Head HTML**을 클릭하세요.
5. 복사해 둔 채팅 위젯 임베드 코드를 편집기에 붙여넣으세요.

![Head HTML 편집기에 임베드 코드를 붙여넣는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48297320881/original/hlGsehMfpbnRSL1HLQtvFzqWsVKnjg7edQ.jpeg?1683922795)

6. **Save**(저장) 버튼을 클릭해서 변경 내용을 저장하세요.
7. 사이트를 미리 보면서 채팅 위젯이 알맞은 위치에 나타나는지, 잘 작동하는지 확인하세요.

---

### 방법 2: HTML 요소로 추가하기

편집기에서 HTML 요소를 사용해 채팅 위젯을 추가할 수도 있어요.

1. 편집기에서 HTML 요소를 채팅 위젯을 표시하려는 페이지 위치로 끌어다 놓으세요.
2. 방금 추가한 HTML 요소를 더블클릭해서 HTML 편집기를 여세요.
3. 채팅 위젯 임베드 코드를 HTML 편집기에 붙여넣으세요.
4. **Save**(저장) 버튼을 클릭해서 변경 내용을 저장하세요.
