# 임베드형 라이브 채팅 위젯 만들기

떠 있는 채팅 말풍선만 쓰지 않고, 웹사이트나 퍼널 콘텐츠 안에 **라이브 채팅**을 직접 넣을 수 있어요. 방문자가 행동을 결정하는 바로 그 자리에 대화 창을 놓을 때 쓰세요.

## 임베드형 라이브 채팅 위젯이란?

임베드형 라이브 채팅 위젯은 채팅 위젯을 화면 모서리에 띄우지 않고 페이지 콘텐츠 안에 인라인으로 표시하는 배치 방식이에요. 채팅이 페이지 디자인의 일부처럼 보여서, 방문자가 고민하는 자리에 상담과 전환 기회를 놓을 수 있어요.

위젯은 기존과 같은 **라이브 채팅**에 연결돼요. 배치를 바꾸면 위젯이 보이는 모습만 달라질 뿐, 대화가 배정되고 관리되는 방식은 그대로예요.

---

## 임베드형 라이브 채팅 위젯의 장점

- 눈에 더 잘 띄어요: 메인 영역, 폼, 가격 안내, CTA처럼 방문자가 이미 관심을 두는 곳 가까이에 채팅을 놓을 수 있어요.
- 페이지에 자연스럽게 어울려요: 콘텐츠 위에 떠 있는 오버레이가 아니라 웹사이트 레이아웃의 일부로 채팅을 보여 줘요.
- 워크플로우를 바꿀 필요가 없어요: 대화 배정, 리드 수집, **라이브 채팅** 관리는 기존 채팅 시스템에서 그대로 이어져요.
- 어디에나 쓸 수 있어요: 퍼널, 웹사이트, 랜딩 페이지 등 지원되는 영역에서 사용할 수 있어요.

---

## 임베드형 라이브 채팅이 잘 맞는 곳

임베드형 라이브 채팅은 다음 위치에 쓸 수 있어요.

- 퍼널
- 웹사이트
- 랜딩 페이지
- 커스텀 HTML 사이트
- 그 밖에 **채팅 위젯**을 설치할 수 있는 지원 페이지

임베드 위젯은 기본적으로 모바일 반응형이에요. 작은 화면에서는 크기가 자동으로 맞춰지고, 계속 페이지 콘텐츠의 일부로 표시돼요.

---

## 임베드형 라이브 채팅 위젯 설정하기

설정을 제대로 해 두면 위젯이 원하는 위치에 나타나고, 웹사이트나 퍼널 어디서든 같은 모습으로 동작해요. 이 설정에서 달라지는 점은 **라이브 채팅** 기능이 아니라, 위젯이 페이지의 어디에 표시되는지예요.

### 1단계: 새 채팅 위젯 만들기

**사이트 > 채팅 위젯**으로 이동한 다음 **+ 신규**를 클릭하세요. 이미 만든 위젯을 열어도 돼요.

![사이트 > 채팅 위젯 화면에서 신규 위젯 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069624862/original/7JDG1uw1cw-3e96X-Ru7sTbty29v8EQNRA.png?1776782637)

### 2단계: 라이브 채팅 선택하기

**라이브 채팅** 옵션을 선택하세요.

![라이브 채팅 옵션 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069624893/original/86RXNhpWNITzbZCmEBblDBHG_OnWOXbv7A.jpeg?1776782650)

### 3단계: 위젯 배치를 임베드로 설정하기

1. **스타일** 탭으로 이동하세요.
2. **위젯 배치**에서 **임베드/인라인**(콘텐츠 안에 렌더링)을 선택하세요.

이렇게 하면 위젯이 화면 위에 떠 있지 않고 페이지 레이아웃 안에 표시돼요.

![스타일 탭에서 위젯 배치를 임베드/인라인으로 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069625188/original/xCXAEY7LTWDwQW12qVMnbDeyDnmDcEECtA.png?1776782775)

### 4단계: 위젯 꾸미기

필요에 맞게 위젯을 설정하세요.

1. 테마 및 모양
   - 색상 테마를 선택해요.
   - **브랜딩**(아바타, 헤더, 색상)을 조정해요.
   - 위젯 스타일을 웹사이트와 맞춰요.
2. 채팅 창 설정
   - **인트로 메시지**를 수정해요.
   - 문의 폼 필드(이름, 전화번호 등)를 설정해요.
   - 필수 입력 항목을 지정해요.
   - **버튼 텍스트**를 원하는 문구로 바꿔요.
3. 메시지 및 동작
   - 자동 응답을 설정해요.
   - 라이브 채팅 배정을 설정해요.
   - 영업시간을 정해요.
   - 채팅 종료 메시지를 원하는 문구로 바꿔요.

![위젯 테마, 채팅 창, 메시지 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069625383/original/WmZdl2ZsgcbRbquDm-74mTLpXa9eOlPM5w.png?1776782826)

### 5단계: 임베드 코드 가져오기

1. 오른쪽 위의 **코드 가져오기**를 클릭하세요.
2. 임베드 스크립트를 복사하세요.

![코드 가져오기에서 임베드 스크립트를 복사하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068321041/original/36lyRPWw9yD44_KFYXxkIIAsMuzh4cmDrg.png?1775117661)

### 6단계: 퍼널, 웹사이트 등에 위젯 추가하기

**방법 1: 퍼널**

1. **퍼널 빌더**를 여세요.
2. 채팅을 표시할 위치에 **코드 요소**를 추가하세요.
3. 복사한 임베드 코드를 붙여넣으세요.
4. **저장 및 게시**를 클릭하세요.

**방법 2: 웹사이트 / 외부 페이지**

1. 웹사이트 편집기나 HTML 파일을 여세요.
2. 원하는 위치에 임베드 코드를 붙여넣으세요.
3. 변경 사항을 게시하세요.

위젯은 코드를 붙여넣은 바로 그 위치에 표시돼요.

![코드 요소에 임베드 코드를 붙여넣은 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068321090/original/8KqrBesKmkvtG540ZYudLdjZa6F9PHvFiQ.png?1775117680)

## 동작 방식

위젯은 페이지 콘텐츠 안에 인라인으로 불러와져요. 채팅은 일반 라이브 채팅과 똑같이 동작해요(대화 배정, 자동화 등).

방문자는 다음과 같이 쓸 수 있어요.

- 대화를 시작해요.
- 연락처 정보를 제출해요.
- 실시간으로 채팅을 이어가요.

---

## 임베드형 라이브 채팅 활용 사례

방문자가 다음 행동으로 넘어가기 전에 망설이는 순간을 줄이거나, 특정 행동을 도와야 할 때 임베드 배치가 특히 효과적이에요. 위젯을 단순한 디자인 요소가 아니라 페이지 전략의 일부로 활용할 수 있어요.

대표적인 활용 사례는 다음과 같아요.

- 폼을 제출하기 전에 나오는 질문 받기
- 가격을 비교하는 방문자 돕기
- 예약이나 상담 페이지에서 도움 제공하기
- 퍼널 단계에서 나오는 망설임이나 반론에 답하기
- 서비스 페이지에서 더 안내가 잘 되는 상담 경험 만들기
- 문의 전용 영역 안에 눈에 띄는 대화 옵션 추가하기

---

## 사용 팁

위젯을 알맞은 곳에 두면 페이지 경험을 방해하지 않고 전환을 도울 수 있어요. 채팅이 방해가 아니라 적절한 순간에 도움이 되도록 만드는 것이 목표예요.

- 폼, 오퍼, 예약 영역, 지원 안내처럼 구매·문의 의도가 높은 콘텐츠 가까이에 위젯을 두세요.
- 위젯 브랜딩을 페이지와 맞추면 더 자연스러워 보여요.
- 좁은 영역 안에서 위젯이 답답해 보이지 않도록 여백과 정렬을 확인하세요.
- 게시한 뒤에는 모바일 레이아웃에서 글자가 잘 읽히는지, 여백이 알맞은지 확인하세요.
- 인트로 메시지와 확인 메시지는 명확하고 행동을 이끄는 문구로 쓰세요.

---

## 알아 둘 동작

- 임베드 위젯은 페이지 위에 떠 있지 않아요.
- 다른 페이지에서는 **고정** 위젯을 그대로 쓸 수 있어요.
- 채팅 배정, 자동화, CRM 데이터 수집은 달라지지 않아요.
- 위젯 크기를 직접 지정해 쓰다가 **고정**과 **임베드/인라인** 사이에서 배치를 바꾸면, 크기가 새로 선택한 배치의 권장 기본값으로 초기화돼요.

---

## 문제 해결

- 위젯이 보이지 않아요: 임베드 코드를 올바른 위치에 붙여넣었는지, 페이지가 게시되었는지 확인하세요.
- 레이아웃이 어긋나요: 페이지 빌더에서 컨테이너 너비를 확인하고, CSS 충돌이 없는지 살펴보세요.
- 채팅에 응답이 없어요: 라이브 채팅 배정 설정과 영업시간 설정을 확인하세요.

---

## 자주 묻는 질문

### 임베드 위젯과 고정 위젯을 같이 쓸 수 있나요?

네, 일부 페이지에는 임베드 위젯을, 다른 페이지에는 고정 위젯을 쓸 수 있어요.

### 채팅 성능에 영향이 있나요?

아니요, 채팅 기능은 그대로예요.

### 한 페이지에 임베드 위젯을 여러 개 넣어도 되나요?

권장하지 않아요. UX와 트래킹에서 충돌이 생길 수 있어요.
