# 채팅 위젯의 알림 소리 설정

올인원과 실시간 채팅 위젯에서 새 메시지가 오면 방문자에게 소리와 시각 알림으로 알려 주는 **알림 소리** 설정을 다룹니다. 방문자가 답장을 놓치지 않도록 돕는 설정이에요. 이 문서에서 설정의 기능, 설정 위치, 변경 방법을 안내해요.

## 채팅 위젯의 알림 소리 설정이란?

**알림 소리**는 채팅 위젯 빌더에서 설정하는 항목이에요. 웹사이트 방문자에게 새 메시지를 어떻게 알릴지 정해요. 올인원과 실시간 채팅 위젯에 적용되고, 기본값은 **켜짐**이에요.

**알림 소리**가 **켜짐**이면 위젯은 다음과 같이 동작해요.

- 방문자에게 지원되는 메시지가 표시될 때마다 소리를 재생해요. 채팅 메시지뿐 아니라 환영 메시지, 폼 관련 안내, 리디렉션 같은 다른 위젯 메시지도 포함돼요.
- 팝업, 알림 배지, 브라우저 탭 제목 변경 같은 시각 알림을 보여 줘요. 방문자가 새 메시지를 알아차리기 쉬워져요.

**끄기**로 바꾸면 채팅 위젯은 소리나 시각 알림 없이 조용히 메시지를 받아요.

## 알림 소리를 쓰면 좋은 점

- 방문자 인지: 새 메시지가 오면 방문자가 바로 알 수 있어서 답장을 놓치거나 중간에 이탈하는 일이 줄어요.
- 참여도 향상: 시기에 맞는 소리와 시각 알림이 대화를 이어 가는 데 도움이 돼요.
- 브랜드 분위기 반영: 소리 알림이 브랜드 분위기에 맞는지 보고 사용 여부를 정할 수 있어요.
- 코드 수정 불필요: 이 설정을 바꾸려고 임베드 코드를 고칠 필요가 없어요.

## 소리 알림이 재생되는 메시지

**알림 소리**가 **켜짐**이면 다음 시스템·진행 단계 메시지에서도 소리 알림이 재생될 수 있어요.

1. 실시간 채팅 및 세션 흐름
   - **Live chat intro message**(실시간 채팅 소개 메시지): 채팅을 시작할 때, 그리고 문의 폼을 성공적으로 제출한 뒤
   - **확인 메시지**: 채팅이 확인되거나 종료될 때
2. 운영시간 처리
   - **영업시간 외 환영 메시지**: **운영시간**이 비활성화되어 있을 때, 문의 폼이 표시될 때, 진행 중인 세션에서 메시지를 받을 때
3. 시스템 및 인사 메시지
   - **Subheading message**(부제목 메시지): 새 방문자에게 보내는 첫 인사, 이전 채팅이 없을 때, 인라인 모드가 시작될 때
4. 폼 및 리디렉션
   - **연락처 세부정보** 요청 메시지: 문의 폼이 표시될 때
   - **Redirect message**(리디렉션 메시지): 리디렉션을 사용 중일 때 폼을 제출한 뒤

## 알림 소리 설정 변경하기

지원되는 채팅 유형인 올인원과 실시간 채팅은 채팅 위젯 빌더에서 바로 **알림 소리**를 설정할 수 있어요. 지원되는 위젯은 기본값이 **켜짐**이고, 위젯마다 **끄기**로 바꿔서 더 조용하게 쓸 수 있어요. 아래 순서대로 설정 위치를 찾아 저장하세요.

1. **사이트 > 채팅 위젯**으로 이동해서 수정할 위젯을 여세요.

   ![사이트 > 채팅 위젯 화면에서 위젯 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355860/original/eWerku0Ofk7r0YQi96sOBxU5BMLVfRdVRw.png?1765403925)
2. 왼쪽 메뉴에서 **채팅 창** 탭을 선택하고 **추가 옵션** 드롭다운을 여세요.

   ![채팅 창 탭의 추가 옵션 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355890/original/zLaqIcthVzL5wlYWuLp78KKnrwrf8mSniw.png?1765404001)
3. **알림 소리**를 **켜짐**(권장) 또는 **끄기**로 바꾸세요. 페이지 운영 방식에 맞춰 고르면 돼요.

   ![알림 소리 토글 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355898/original/Bp_U16UuunuW2hEstOj-9UP4xt3zuyQGCw.png?1765404026)
4. 오른쪽 위의 **저장**을 클릭하세요. 임베드 코드가 이미 사이트에 있다면 페이지를 새로고침해서 변경 사항을 확인하세요.

   ![오른쪽 위의 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060355916/original/z6jx_WeugE9XdEws0fkHq66uJtpS3r3YGg.png?1765404057)

## 자주 묻는 질문

### 이 설정을 바꾸면 하이퍼클래스의 직원·운영자 알림도 달라지나요?
아니요. 이 설정은 웹사이트 위젯에서 방문자에게 보이는 알림만 조절해요. 팀 알림은 사용자 알림 설정에서 따로 관리해요.

### 사용자 지정 소리를 올리거나 볼륨을 바꿀 수 있나요?
아직은 안 돼요. 지금은 켜고 끄는 토글만 있어요.

### 사이트에 위젯이 여러 개 있으면 어떻게 되나요?
설정은 위젯마다 적용돼요. 각 위젯은 자기 토글(**켜짐**/**끄기**)을 따라요.

### 끄기로 바꾸면 배지나 팝업도 표시되나요?
아니요. **끄기**는 무음 모드라서 소리도, 시각적인 방해도 없어요.

### 어떤 위젯에서 알림 소리를 쓸 수 있나요?
올인원과 실시간 채팅 위젯에서만 쓸 수 있어요.
