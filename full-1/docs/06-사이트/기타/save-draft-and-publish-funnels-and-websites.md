# 퍼널과 웹사이트 임시 저장 및 게시

퍼널과 웹사이트를 임시 저장하고, 원하는 버전을 골라 게시하는 방법을 설명해요. 콘텐츠를 만들고 게시하는 과정에서 더 유연하게 작업 내용을 관리할 수 있어요.

## 임시 저장

![임시 저장 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155019480176/original/pB1Yp7vkO9_rR5z4YtmkTVN2pst9JAbtwg.png?1706886761)

퍼널이나 웹사이트를 게시하기 전에 임시 저장본을 만들 수 있어요. 여러 번 다듬거나 팀원과 함께 작업할 때 편해요. 작업 내용이 안전하게 저장되고, 운영 중인 사이트에는 영향을 주지 않아요.

**사용 방법**

1. 평소처럼 콘텐츠를 만들거나 편집해요.
2. **저장**을 선택해 작업 중인 내용을 새 버전으로 저장해요.

## 게시

![게시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155019480352/original/bT7JelbcikusUSQQbbvBjWSq802DwSjcaw.png?1706886803)

이제 퍼널이나 웹사이트의 어떤 버전을 운영 사이트에 게시할지 고를 수 있어요. 최종 확정되고 승인된 콘텐츠만 방문자에게 보여 줄 수 있어서, 오류 위험을 줄이고 게시 과정을 간단하게 만들 수 있어요.

**게시**를 클릭하면 선택한 버전이 사이트에 게시돼요.

{% hint style="info" %}
저장하지 않고 바로 게시하면, 마지막으로 게시한 버전 이후의 모든 변경 사항이 함께 게시돼요.
{% endhint %}

## 빌더에서 도메인 연결

![빌더에서 도메인 연결 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155019479764/original/BsvuQz1OUX-gVtIJma3z5NzP8Y2x8pM-eA.png?1706886642)

퍼널이 아직 어떤 도메인과도 연결되어 있지 않아도, 페이지를 게시할 때 도메인을 연결할 수 있어요.

도메인이 연결되지 않은 퍼널에서 **게시**를 클릭하면, 빌더에 새로 생긴 도메인 연결 팝업이 나타나요. 여기서 도메인을 연결하면 해당 버전이 게시돼요.

## 버전 목록에서 게시

![버전 목록 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155019480034/original/I8MU1alcR8Zmc_K1F8tO78rvXUW8SIehwQ.png?1706886698)

![버전 목록 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155019480057/original/qcjZlvk9yIzqxkdHeUn1FYpNPl-DJnDYLQ.png?1706886712)

**Versions**(버전) 탭에서 콘텐츠의 여러 버전을 보고 관리할 수 있어요.

페이지의 원하는 버전을 선택하면, 복원하지 않고 버전 목록에서 바로 게시할 수 있어요.

버전 목록에는 새로 **라이브** 태그가 표시돼요. 이 태그는 지금 운영 사이트에 보이는 게시 버전을 나타내요.

## 자주 묻는 질문

### 게시된 버전이 없는 기존 사이트는 어떻게 되나요?

기존 페이지는 변경 없이 그대로 작동해요. 게시된 버전(**라이브**)이 없으면 가장 최근 버전(**현재 버전**)이 사이트에 보여요.

### 스냅샷에서 퍼널을 복제하거나 가져오면 어떻게 되나요?

이 기능의 영향을 받지 않아요. 지금처럼 그대로 작동해요.

### 페이지 하나에 만들 수 있는 버전 수에 제한이 있나요?

네, 페이지 하나에는 최대 30개의 버전을 둘 수 있어요. 임시 저장본을 30개보다 더 많이 저장하면 오래된 버전부터 삭제돼요. 삭제될 차례인 오래된 버전이 **라이브** 버전이면, 그 다음 버전이 대신 삭제돼요.

### 이 기능으로 다른 팀원과 함께 작업할 수 있나요?

네, 할 수 있어요. 팀원들이 각자 임시 저장본을 저장해 두었다가, 준비가 되었을 때만 변경 사항을 게시할 수 있어요.

### 빌더에서 퍼널이나 웹사이트에 도메인을 연결하려면 어떻게 하나요?

퍼널이 어떤 도메인과도 연결되어 있지 않다면, **게시**를 클릭할 때 빌더에 도메인 연결 팝업이 나타나요. 여기서 도메인을 연결하면 해당 버전이 게시돼요.
