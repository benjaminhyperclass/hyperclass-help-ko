# 블로그 분석으로 블로그와 게시글 성과 확인하기

블로그 분석에서는 블로그 성과를 한 화면에서 볼 수 있어요. 페이지뷰와 참여 추이를 확인하고, 인기 게시글을 찾아 콘텐츠 전략을 다듬을 때 활용하세요. 이 문서에서는 하이퍼클래스에서 블로그 분석을 찾는 방법과 각 차트·지표를 보는 방법을 안내해요.

## 블로그 분석이란?

블로그 분석은 하이퍼클래스의 분석 기능이에요. 블로그와 게시글의 주요 성과 지표를 한곳에 모아 보여 줘요. 페이지뷰, 클릭, 사용 기기 같은 데이터를 바탕으로 독자의 행동을 이해하고, 참여도를 높이는 방향으로 콘텐츠 전략을 고칠 수 있어요.

## 블로그 분석의 장점

블로그 분석은 콘텐츠 제작자와 마케터가 데이터를 근거로 판단하도록 도와줘요.

- 한눈에 보기: 주요 지표로 블로그 전체 성과를 빠르게 확인해요.
- 잘되는 방식 반복하기: 성과가 좋은 게시글을 찾아 같은 방식으로 다시 시도해 보세요.
- 독자 파악하기: 기기와 카테고리별 정보로 독자의 행동을 이해해요.
- 참여도 확인하기: 링크 클릭 활동을 보며 독자의 관심도를 가늠해요.
- 콘텐츠 출처 비교하기: 가져온 게시글과 직접 만든 게시글의 성과를 구분해서 볼 수 있어요.

## 블로그 분석 찾아서 사용하기

{% hint style="info" %}
데이터는 2024년 8월 28일부터 수집돼요. 이 날짜 이전 데이터는 **알 수 없음**으로 표시돼요.
{% endhint %}

1. 서브 계정에 로그인하세요.
2. **사이트** 탭을 클릭하세요.
3. **분석** 탭을 클릭하세요.
4. 카테고리 선택 드롭다운을 클릭한 뒤 **블로그**를 선택하세요.
5. 대시보드가 불러와질 때까지 기다리세요. 블로그 성과 지표가 준비되면 표시돼요.
6. **date range selector**(날짜 범위 선택기)와 **blog site selector**(블로그 사이트 선택기)로 보고 싶은 데이터 범위를 정하세요.
7. **Quick Performance Overview**(빠른 성과 개요), **Trends Over Time**(기간별 추이) 같은 각 섹션을 살펴보며 블로그 활동을 자세히 확인하세요.

## Quick Performance Overview(빠른 성과 개요)

**Quick Performance Overview**는 블로그의 핵심 성과 지표를 한눈에 보여 줘요. 전체 페이지뷰, 게시된 블로그 사이트 수, 게시된 게시글 수를 확인할 수 있어서 블로그 상태를 빠르게 파악하기 좋아요.

- 전체 페이지뷰를 바로 확인해요.
- 게시된 블로그 사이트 수를 보여 줘요.
- 게시된 게시글 수를 집계해 보여 줘요.

![빠른 성과 개요 화면](https://jumpshare.com/share/5utcidcI7TheXSFw34d8+/Screen+Shot+2025-09-03+at+8.00.49+PM.png)

## Trends Over Time(기간별 추이)

**Trends Over Time**에서는 선택한 기간 동안 페이지뷰가 어떻게 달라지는지 볼 수 있어요. 인터랙티브 그래프로 시기별 흐름과 급증·급감을 확인하고, 필요하면 전략을 조정하세요.

- 시간에 따른 페이지뷰를 그래프로 보여 줘요.
- 기간을 자유롭게 골라 원하는 구간을 분석해요.
- 추세선으로 흐름을 빠르게 파악해요.

![기간별 페이지뷰 추이 그래프](https://jumpshare.com/share/gRDfrfR8NNRIUFr9PnHg+/GIF+Recording+2025-09-03+at+8.03.28+PM.gif)

## Top Performing Posts(인기 게시글)

**Top Performing Posts**는 조회수와 참여율이 가장 높은 게시글을 보여 줘요. 썸네일과 제목이 함께 표시되어서 독자에게 반응이 좋은 콘텐츠를 바로 찾을 수 있어요.

- 썸네일과 제목을 보여 줘서 게시글을 쉽게 알아볼 수 있어요.
- 조회수와 참여도 순으로 게시글 순위를 매겨요.
- 어떤 요소가 콘텐츠의 성공에 영향을 줬는지 파악하는 데 도움이 돼요.

![인기 게시글 목록 화면](https://jumpshare.com/share/bQR0X2gwp8JV1XI9msos+/Screen+Shot+2025-09-03+at+8.09.21+PM.png)

## Number of Link Clicks(링크 클릭 수)

링크 클릭 추적에서는 게시글 안의 어떤 링크가 클릭을 많이 받는지 정확한 데이터로 확인해요. 콜투액션과 하이퍼링크 배치가 얼마나 효과적인지 측정할 수 있어요.

- 삽입된 링크별 클릭 수를 자세히 보여 줘요.
- 독자가 반응하는 지점을 시각적으로 확인해요.
- 데이터를 바탕으로 콘텐츠를 개선할 수 있어요.

![링크 클릭 수 화면](https://jumpshare.com/share/Ryry2R8DiCsLkNLt6WgF+/Screenshot+2025-08-25+at+12.17.24%E2%80%AFPM.png)

## Device Breakdown(기기별 분석)

**Device Breakdown**은 독자가 데스크톱, 모바일, 태블릿 중 어떤 기기로 블로그에 접속하는지 알려 줘요. 기기마다 사용 환경을 최적화하고 접근성을 챙기는 데 중요한 정보예요.

- 기기별(데스크톱, 모바일, 태블릿)로 조회수를 나눠 보여 줘요.
- 기기 유형에 맞게 콘텐츠를 다듬는 데 참고할 수 있어요.
- 반응형 디자인과 플랫폼별 조정에 활용할 수 있어요.

![기기별 조회수 분석 화면](https://jumpshare.com/share/Nu2I8YYmyLfEHzZfT6ST+/Screen+Shot+2025-09-03+at+8.16.34+PM.png)

## Post Visits by Category(카테고리별 게시글 방문)

카테고리별 인사이트는 게시글 방문 수를 콘텐츠 카테고리별로 나눠 보여 줘요. 어떤 주제에 관심이 몰리는지 알 수 있어서 콘텐츠를 더 정확하게 기획할 수 있어요.

- 콘텐츠 카테고리별 방문 수를 보여 줘요.
- 독자에게 인기 있는 주제 영역을 찾을 수 있어요.
- 콘텐츠 타깃팅을 전략적으로 개선하는 데 도움이 돼요.

![카테고리별 게시글 방문 화면](https://jumpshare.com/share/ZFBiqFlSvfgP0P3q6Sa0+/Screen+Shot+2025-09-03+at+8.18.53+PM.png)

## Author Links Clicked(작성자 링크 클릭)

작성자 인사이트는 작성자 링크의 클릭을 추적해서 어떤 작성자가 참여를 이끄는지 보여 줘요. 성과가 좋은 작성자를 격려하거나 협업 콘텐츠 전략을 짤 때 활용하세요.

- 작성자 링크 클릭으로 참여도를 확인해요.
- 작성자 개개인의 성과를 파악할 수 있어요.
- 콘텐츠 협업에서 데이터를 근거로 판단할 수 있어요.

![작성자 링크 클릭 화면](https://jumpshare.com/share/ctzN9KN17zXbX7fnzMgS+/Screen+Shot+2025-09-03+at+8.19.56+PM.png)

## Import vs. Manual Tracking(가져오기 vs. 직접 작성 추적)

**Import vs. Manual Tracking**은 가져온 게시글과 직접 만든 게시글을 구분해서 보여 줘요. 두 방식의 성과 차이를 비교하며 게시 전략을 다듬을 수 있어요.

- 콘텐츠를 만든 방식별 성과를 확인해요.
- 가져온 게시글과 직접 만든 게시글의 성과 차이를 보여 줘요.
- 콘텐츠 운영 방식을 정할 때 참고할 수 있어요.

![가져온 게시글과 직접 만든 게시글 비교 화면](https://jumpshare.com/share/Ou9ueo77kPLMInI9FYE3+/Screen+Shot+2025-09-03+at+8.21.15+PM.png)

## 자주 묻는 질문

### 블로그 분석은 누가 사용할 수 있나요?

3개 요금제의 모든 사용자가 블로그 분석을 사용할 수 있어요.

### 데이터는 언제부터 볼 수 있나요?

블로그 분석 데이터는 2024년 8월 28일부터 수집돼요. 이 날짜 이전의 블로그 활동은 리포트에 **알 수 없음**으로 표시돼요.

### 날짜별로 데이터를 필터링하려면 어떻게 하나요?

**date range selector**(날짜 범위 선택기)로 보고 싶은 기간을 선택하세요.

### 참여도가 높은 게시글은 어떻게 찾나요?

**Top Performing Posts** 섹션에서 확인하세요. 썸네일과 제목이 함께 표시되어서 참여도가 가장 높은 게시글을 빠르게 찾을 수 있어요.

### 데이터가 실시간으로 업데이트되나요?

데이터는 정기적으로 갱신돼요. 다만 처리 주기 때문에 실시간 반영이 조금 늦어질 수 있어요.
