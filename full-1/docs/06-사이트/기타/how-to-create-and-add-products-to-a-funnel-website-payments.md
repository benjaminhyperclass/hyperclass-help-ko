# 퍼널·웹사이트에 상품 만들고 추가하기 (결제)

상품을 한곳에서 관리하는 방법을 알려 드려요. 아래 영상에서 일회성 상품과 구독 상품을 **결제** 메뉴에 추가하고, 퍼널에서 쓰는 방법을 볼 수 있어요.

[동영상](https://www.youtube.com/embed/yZs6jRxAnvA?&t=3s&wmode=opaque)

## 문제 해결

### 웹사이트를 쓰고 있는데 상품을 추가하는 곳이 안 보여요.

웹사이트에서는 주문 폼이 들어갈 페이지에서 점 3개 아이콘을 클릭하면 상품을 추가할 수 있어요.

![웹사이트 페이지의 점 3개 아이콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48184495294/original/QcPJSvHswqaoZ8TBWbRHuq22mZxkip1g8Q.png?1643404941)
