# 퍼널·웹사이트 페이지 가져오기 기능으로 새 단계 만들기

가져오기 기능을 쓰면 기존 웹사이트나 퍼널 페이지를 지금 만들고 있는 퍼널이나 웹사이트로 바로 가져올 수 있어요. 이 문서에서는 가져오는 순서와 알아 둘 점을 안내해요.

## 개요

만들고 있는 퍼널이나 웹사이트에 다른 웹사이트나 퍼널의 페이지를 옮겨 오고 싶었던 적이 있나요? 가져오기 기능을 쓰면 작업 중에 바로 가져올 수 있어요.

## 어떻게 작동하나요?

1. **+ Add New Step**(새 단계 추가) 버튼을 눌러 퍼널이나 웹사이트에 새 페이지를 추가하세요.
2. 팝업이 나타나면 페이지 이름과 경로를 입력하세요.
3. **Create Funnel Step**(퍼널 단계 만들기)을 눌러 팝업을 닫으세요.
4. 퍼널 미리보기 영역에 새 창이 나타나면 **가져오기** 버튼을 누르세요.
5. 가져올 페이지를 선택하고 **가져오기**를 누르세요.

{% hint style="info" %}
알아 둘 점

- 퍼널이나 웹사이트 페이지를 가져오려면 먼저 새 단계를 추가해야 해요.
- 퍼널/웹사이트 가져오기 기능으로는 퍼널 단계 또는 웹페이지를 **한 번에 하나만** 가져올 수 있어요.
- 하이퍼클래스 안에 있는 퍼널 단계나 웹사이트 페이지만 가져올 수 있어요.
- 다른 웹사이트나 퍼널 서비스에서는 가져올 수 없어요.
- 가져온 단계나 페이지를 수정해도 원본 단계나 페이지에는 영향이 없어요.
- 원본 퍼널 단계에 설정된 상품과 쌓인 통계는 가져오지 않아요. 가져온 뒤에 상품을 다시 설정해야 해요.
- \*\*퍼널의 컨트롤 단계나 베리에이션 단계도 가져올 수 있어요.
- \*\*웹사이트에서 스플릿 테스트를 하려면 해당 페이지를 퍼널로 가져온 뒤 퍼널에서 스플릿 테스트를 실행하세요.
  - 스플릿 테스트는 모든 요금제의 퍼널에서 쓸 수 있어요.
{% endhint %}
