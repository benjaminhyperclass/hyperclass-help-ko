# 퍼널·웹사이트에 전화·문자·이메일 바로 연결 링크와 버튼 추가하기 (Click-to-Call, Click-to-Text, Click-to-Email)

하이퍼클래스 퍼널과 웹사이트에 클릭 한 번으로 전화, 문자, 이메일을 보낼 수 있는 링크와 버튼을 추가하는 방법을 안내해요. 특히 모바일에서 리드가 탭 한 번으로 바로 연락할 수 있어 전환율을 높이는 데 도움이 돼요.

## 클릭 투 콜, 클릭 투 텍스트, 클릭 투 이메일이란?

전화, 문자, 이메일을 바로 시작할 수 있는 클릭형 링크예요. 올바르게 설정하면 링크를 누를 때 방문자의 전화 앱, 문자 앱, 기본 이메일 앱이 열리고 입력해 둔 정보가 미리 채워져요. 퍼널과 웹사이트에서 방문자 경험을 높이고 전환을 늘리려고 많이 써요.

## 클릭 투 액션을 쓰면 좋은 점

리드가 탭 한 번으로 연락할 수 있어서 소통이 쉬워져요.

- 한 번의 탭으로 소통: 방문자가 번호나 주소를 복사하거나 직접 입력하지 않아도 바로 전화, 문자, 이메일을 보낼 수 있어요.
- 모바일 참여율 상승: 모바일 사용자는 클릭해서 바로 실행되는 요소에 더 잘 반응해요.
- 리드의 시간 절약: 전화번호, 메시지 내용, 이메일 내용 같은 항목이 자동으로 채워져요.
- 자동화 연계: **트리거 링크**와 함께 쓰면 후속 워크플로우를 실행할 수 있어요.
- 유연한 CTA 디자인: 텍스트와 버튼 모두에 링크를 추가할 수 있어요.

## 클릭 투 콜 링크 추가하기

방문자가 누르면 전화가 걸리는 링크를 만들어요.

1. 퍼널이나 **웹사이트 빌더**에서 링크로 만들 텍스트를 드래그해 선택해요.
2. **링크 아이콘**을 클릭해요.
3. `tel:+1234567890` 형식으로 링크를 입력해요.
4. **저장**을 클릭한 뒤 모바일 기기에서 미리 보고 테스트해요.

## 클릭 투 이메일 링크 추가하기

방문자가 누르면 이메일 작성 화면이 열리는 링크를 만들어요.

1. 퍼널이나 **웹사이트 빌더**에서 링크로 만들 텍스트를 드래그해 선택해요.
2. **링크 아이콘**을 클릭해요.
3. `mailto:name@email.com` 형식으로 링크를 입력해요.
4. **저장**을 클릭한 뒤 링크를 미리 보고 테스트해요.

![클릭 투 이메일 링크 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050029871/original/v2PQzHv24vs46HFqKASjwnE_HzTXTUAAnA.gif?1752775769)

## 클릭 투 콜 버튼 추가하기

방문자가 누르면 전화가 걸리는 버튼을 만들어요.

1. 퍼널이나 **웹사이트 빌더**에서 버튼을 클릭해요.
2. 오른쪽의 **Button Actions**(버튼 액션) 아래에서 **링크 대상** 드롭다운을 열고 **통화**를 선택해요.
3. 전화번호를 입력해요.
4. **저장**을 클릭한 뒤 버튼을 미리 보고 테스트해요.

![클릭 투 콜 버튼 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050030228/original/C76eE2PcYZ6uxVNmCtCeCvnorMTlXReK5g.jpeg?1752776383)

## 자주 묻는 질문

### 이 링크의 클릭 수를 추적하려면 어떻게 하나요?
**트리거 링크**를 사용하면 클릭을 추적하고, 클릭에 따른 작업을 자동화할 수 있어요.

### 방문자의 기기가 클릭 투 링크를 지원하지 않으면 어떻게 되나요?
기기가 해당 프로토콜을 지원하지 않으면(예: 데스크톱에서 `sms:` 링크) 클릭해도 아무 일도 일어나지 않아요. 여러 기기에서 링크를 테스트해 보고, 대체 연락처 정보도 함께 넣어 두는 것을 권장해요.

### 링크 하나에 전화와 문자처럼 여러 동작을 넣을 수 있나요?
아니요. 링크 하나는 전화, 문자, 이메일 중 한 가지 동작만 할 수 있어요. 여러 방법을 제공하려면 동작마다 링크나 버튼을 따로 만드세요.

### 이미지나 아이콘에도 클릭 투 링크를 쓸 수 있나요?
네. 퍼널이나 **웹사이트 빌더**에서 이미지나 아이콘에 같은 형식으로 링크를 걸 수 있어요. 전화나 메시지 아이콘처럼 눈에 띄는 CTA를 만들 때 유용해요.
