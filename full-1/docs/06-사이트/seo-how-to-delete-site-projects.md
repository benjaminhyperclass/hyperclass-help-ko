# SEO 사이트 프로젝트 삭제

필요 없는 SEO 사이트 프로젝트를 삭제하면 사이트 프로젝트 할당량을 다시 확보할 수 있어요. 이 문서에서는 삭제하면 무엇이 되돌려지는지, 누가 삭제할 수 있는지, 삭제 후 할당량을 어떻게 확인하는지 안내해요.

## SEO 사이트 프로젝트 삭제란?

사이트 프로젝트를 삭제하면 그 프로젝트의 감사 결과가 영구적으로 삭제돼요. 해당 프로젝트를 통해 적용한 SEO 수정 사항도 자동으로 원래대로 돌아가요. 할당량은 바로 복구되므로 새 사이트를 추가할 수 있어요.

{% hint style="warning" %}
사이트 프로젝트 삭제는 영구적이며 되돌릴 수 없어요.
{% endhint %}

## 사이트 프로젝트를 삭제하면 좋은 점

- 할당량 확보: 사이트 4개 한도에 도달했을 때 바로 빈자리를 만들 수 있어요.
- 유연한 운영: 새 고객 사이트나 우선순위가 높은 사이트로 빠르게 교체할 수 있어요.
- 깔끔한 되돌리기: 프로젝트에서 자동으로 적용한 SEO 수정 사항이 원래대로 돌아가서 변경 내용이 남지 않아요.
- 명확한 관리: SEO 작업 공간을 현재 쓰는 도메인 위주로 정리할 수 있어요.

## SEO 사이트 프로젝트 삭제하기

아래 순서대로 하면 할당량이 바로 복구되고, 적용한 수정 사항도 자동으로 되돌려져요.

1. **사이트** > **SEO**로 이동하세요.

   ![사이트 > SEO 화면](https://jumpshare.com/share/v5ZeGdULNUEzEWWayMRx+/Screen+Shot+2026-01-28+at+7.32.45+PM.png)
2. **사이트 프로젝트** 목록을 열고 삭제할 프로젝트를 찾으세요.
3. 프로젝트 이름 옆의 점 세 개(⋯) 아이콘을 클릭한 다음 **프로젝트 삭제**를 클릭하세요.

   ![프로젝트 이름 옆 점 세 개 메뉴에서 프로젝트 삭제 선택](https://jumpshare.com/share/3gI7uM0eZc47hYsJg40N+/Screen+Shot+2026-01-28+at+7.35.23+PM.png)
4. 확인 창에 나오는 영향 요약을 읽어 보세요. 할당량 복구, 수정 사항 되돌리기, 영구 삭제라는 내용이 나와요.
5. **프로젝트 삭제** 버튼을 클릭하세요.

   ![확인 창에서 프로젝트 삭제 버튼 클릭](https://jumpshare.com/share/vRyz7Te7RVzLMHPhtumg+/Screen+Shot+2026-01-28+at+7.40.46+PM.png)

## SEO 수정 사항 되돌리기

무엇이 되돌려지는지 알아 두면 운영 중인 자산에 예상치 못한 변경이 생기는 것을 막을 수 있어요. 직접 다시 적용해야 할 항목이 무엇인지도 알 수 있어요.

사이트 프로젝트를 삭제하면 그 프로젝트를 통해 적용한 SEO 수정 사항이 원래대로 돌아가요. 되돌려지는 항목은 다음과 같아요.

- 퍼널 경로 수정
- 블로그 경로 수정
- 외부 수정(프로젝트로 인해 자동 실행된 조정)
- 프로젝트가 자동으로 적용한 수정과 관계없이 직접 편집한 내용은 대체로 그대로 유지돼요.

삭제한 뒤에도 필요한 항목이 있다면 리다이렉트, 사이트맵, Search Console 커버리지 같은 주요 항목을 다시 확인해 보세요.

## 자주 묻는 질문

### 하이퍼클래스 고객지원에서 삭제한 사이트 프로젝트를 복구할 수 있나요?

아니요. 삭제는 영구적이며 되돌릴 수 없어요.

### 직접 바꾼 메타 제목과 설명도 원래대로 돌아가나요?

사이트 프로젝트를 통해 적용한 수정 사항만 되돌려져요. 그 수정과 관계없이 직접 편집한 내용은 대체로 그대로 유지돼요.

### 사이트 프로젝트는 누가 삭제할 수 있나요?

권한이 충분한 사용자가 삭제할 수 있어요. 보통 관리자이거나 사이트/SEO 접근 권한이 있는 사용자예요.

### 삭제한 도메인을 다시 추가할 수 있나요?

네. 할당량이 복구되면 그 도메인을 새 사이트 프로젝트로 추가하고 새로 감사를 시작할 수 있어요.

### 프로젝트에서 적용한 수정 외에 운영 중인 퍼널이나 블로그에도 영향이 있나요?

프로젝트가 자동으로 적용한 수정 사항만 제거돼요. 그 밖의 다른 콘텐츠와 직접 편집한 내용은 그대로 유지돼요.

### 할당량은 어디에서 확인하나요?

**SEO** > **설정** > **Quota Usage**(할당량 사용량)에서 확인할 수 있어요.
