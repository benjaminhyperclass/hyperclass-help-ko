# 퍼널과 웹사이트에서 글꼴 두께 설정하기

퍼널이나 웹사이트의 각 구성 요소마다 글꼴 두께를 따로 정할 수 있어요. 데스크톱과 모바일에서 서로 다른 두께로 보이게 설정할 수도 있어요.

[동영상](https://www.youtube.com/embed/GlN3BqPQQcw?&wmode=opaque)

## 주요 기능과 장점

- 웹사이트나 퍼널 안의 구성 요소마다 글꼴 두께를 직접 고를 수 있어요.
- 글꼴 두께 옵션은 다음 구성 요소에서 쓸 수 있어요.
  - 텍스트 구성 요소
  - 버튼
  - 카테고리 내비게이션
  - FAQ
  - 카운트다운 구성 요소
  - 내비게이션 메뉴
  - 스토어 구성 요소
  - 이미지 기능 구성 요소
- 모바일 화면과 데스크톱 화면에 서로 다른 글꼴 두께를 적용할 수 있어요.
- 글꼴 크기 슬라이더의 민감도를 100으로 낮춰서 더 편하게 조절할 수 있어요.

## 사용 방법

1. 페이지 빌더 화면으로 이동하세요.
2. 위에서 안내한 구성 요소 중 하나를 선택하세요.
3. 글꼴 크기 설정 아래에 새로 생긴 글꼴 두께 드롭다운을 찾으세요.
4. 원하는 글꼴 두께를 선택하세요. 모바일과 데스크톱 버전에 서로 다른 두께를 지정할 수도 있어요.
5. 변경 내용을 저장하거나 게시하면 웹사이트나 퍼널에 새 글꼴 두께가 반영돼요.

{% hint style="info" %}
- 글꼴 패밀리마다 지원하는 두께가 달라요. 선택한 글꼴 패밀리가 해당 두께를 지원하지 않으면 글꼴 두께를 골라도 텍스트 스타일이 달라지지 않을 수 있어요.
- 텍스트 편집기에서 텍스트를 굵게 설정했다면 글꼴 두께 옵션은 적용되지 않아요. 텍스트 편집기의 굵게 옵션이 글꼴 두께 옵션보다 우선해요.
{% endhint %}
