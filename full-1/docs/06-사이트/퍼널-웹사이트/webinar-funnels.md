# 웨비나 퍼널

**사이트** 메뉴에서 라이브 웨비나, 온디맨드 웨비나, 반복 웨비나를 만들고 관리할 수 있어요. 등록자를 모으고, 웨비나 퍼널 페이지를 만들고, 웨비나 콘텐츠나 라이브 링크를 연결하세요. 워크플로우로 확인 메시지, 리마인더, 후속 안내도 보낼 수 있어요.

[동영상](https://www.youtube.com/embed/HtEAiQyhYlQ?&wmode=opaque)

## 주요 기능과 장점

웨비나 퍼널은 설정은 간단하게, 참여를 높이는 도구는 충분하게 갖췄어요.

- 온디맨드 웨비나: 미리 녹화한 콘텐츠를 언제든 볼 수 있어요. 상시 리드 확보에 알맞아요.
- 라이브 웨비나: 정해진 날짜와 시간에 실시간으로 진행하고, 참석자와 바로 소통해요.
- 템플릿 선택: 등록 페이지, 확인 페이지, 방송 페이지가 미리 만들어져 있어서 더 빨리 시작할 수 있어요.
- 자동화 워크플로우와 리마인더: 이메일·SMS 리마인더와 후속 안내용 자동화가 미리 구성되어 있어서 수작업이 줄어요.
- 반복 웨비나: **Daily**(매일), **Weekly**(매주), **Monthly**(매월), **No Fixed Time**(고정 시간 없음) 일정으로 웨비나를 반복해요.
- 웨비나 복제: 기존 웨비나 설정을 재사용하고, 웨비나 날짜·시간 같은 정보를 수정해요.
- 웨비나 분석: 라이브, 온디맨드, 반복 웨비나의 등록, 참석, 시청, 참여 데이터를 확인해요.

## 시작하기

### 웨비나 만들기 화면 열기

1. 하이퍼클래스 계정에 **로그인**하세요.
2. 왼쪽 사이드바에서 **사이트**로 이동하세요.
3. **웨비나**를 클릭하세요.
4. **New Webinar Funnel**(새 웨비나 퍼널)을 선택하세요.

### 웨비나 유형 선택

사용 목적에 맞는 웨비나 유형을 고르세요.

- **Live Webinar**(라이브 웨비나): 특정 날짜와 시간에 진행해요.
- **On-Demand Webinar**(온디맨드 웨비나): 미리 녹화한 콘텐츠를 사용해요. 참석자는 등록한 뒤에 볼 수 있어요.
- **반복 웨비나**: 설정한 일정에 따라 반복해요.

![웨비나 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052367881/original/8qh56KdQR3go-fc9rdOUAJxlWBTiCWehUg.png?1756201381)

## 라이브 웨비나

### 개요

라이브 웨비나는 참석자가 정해진 날짜와 시간에 접속해 실시간으로 참여하는 발표예요.

### 4단계로 만들기

#### 1단계: Webinar Details(웨비나 상세 정보)

- **Webinar Name**(웨비나 이름) (**필수**): 예) *디지털 마케팅 마스터 웨비나*
- **시간대** (**필수**): 기본값은 *America/New\_York*이고, 바꿀 수 있어요.
- **날짜** (**필수**): 오늘 이후의 날짜를 고르세요.
- **시간** (**필수**): 예) *오후 2:00*

![웨비나 상세 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052367939/original/hp4XU_1AFmpohZ4h7MtJTVirua_gY__9Kw.png?1756201432)

#### 2단계: Select Form(폼 선택)

참석자는 **사이트 > 폼**에서 만든 폼으로 등록해요.

- 드롭다운 목록: 사용할 수 있는 폼이 모두 표시돼요.
- 사용자 지정 폼: 이름, 이메일, 전화번호 같은 필드로 직접 만들 수 있어요.
- 리드 수집: 폼은 CRM과 연동되어 추적과 자동화에 쓰여요.
- 자동화 트리거: 폼 제출은 리마인더와 후속 안내 워크플로우도 시작해요. 자세한 내용은 [자동화 & 리마인더](../../07-워크플로우/기타/workflow-builder-walkthrough.md)를 참고하세요.

#### 3단계: Live Webinar Link(라이브 웨비나 링크)

스트리밍 링크를 입력하세요.

- Zoom: `https://zoom.us/j/123456789`
- YouTube Live: `https://youtube.com/watch?v=ABC123`
- 그 밖에 지원되는 웨비나 링크나 직접 만든 링크

![라이브 웨비나 링크 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052367985/original/cyq6X3jZMB7smAU4k7TOGVgvSjTIbpVvSw.png?1756201469)

#### 4단계: 템플릿

미리 디자인된 퍼널 템플릿 중에서 고르세요. 예를 들어 다음과 같은 템플릿이 있어요.

- **Blank Live**
- **E-Commerce Marketing Live**
- **Financial Planning Live**
- **DIY Home Remodel Live**

![퍼널 템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052368040/original/KAfVqwu684kieAboPhHVDM_XGbLXEfu_Wg.png?1756201489)

## 온디맨드 웨비나

### 개요

온디맨드 웨비나는 미리 녹화한 세션이에요. 참석자는 등록한 뒤 언제든 볼 수 있어요.

### 4단계로 만들기

#### 1단계: Webinar Details

- **Webinar Name** (**필수**): 예) *콘텐츠 마케팅 마스터 - 온디맨드*

{% hint style="info" %}
**시간대**, **날짜**, **시간**은 입력하지 않아도 돼요.
{% endhint %}

#### 2단계: Select Form

라이브 웨비나와 같아요.

- **사이트 > 폼**에서 폼을 고르세요.
- 기본 예시: *Marketing Form - Claim Offer*
- 필요한 데이터를 받도록 필드를 수정할 수 있어요.

#### 3단계: **동영상 선택**

미리 녹화한 동영상을 업로드하거나 선택하세요.

- 지원하는 동영상 형식은 다음과 같아요.

  - MP4
  - MOV
  - AVI
- 컴퓨터에서 업로드하거나 미디어 라이브러리에서 고를 수 있어요.
- **필수** 항목이에요. 동영상을 선택해야 다음 단계로 넘어갈 수 있어요.

![동영상 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052368189/original/6s3gS4K1ZLxmnBgxvLJJr8-WaH5I4-9W-Q.png?1756201512)

#### 4단계: 템플릿

라이브 웨비나와 같은 템플릿 라이브러리를 쓰며, 온디맨드 시청에 맞게 최적화되어 있어요.

## 자동화 & 리마인더

웨비나 퍼널의 가장 유용한 기능 중 하나가 자동화예요.

- 기본 제공 워크플로우 레시피: 웨비나 퍼널마다 리마인더와 후속 안내용 자동화 레시피가 들어 있어요.
- 트리거: 등록(폼 제출)이 들어오면 워크플로우가 자동으로 시작돼요.
- 리마인더: 라이브 웨비나에는 이메일·SMS 리마인더를 예약할 수 있어요. 예를 들면 24시간 전, 1시간 전, 10분 전에 보낼 수 있어요.
- 후속 안내: 웨비나가 끝난 뒤 감사 이메일, 다시보기 링크, 육성 캠페인을 보내요.
- 사용자 지정: 웨비나 퍼널의 점 세 개 메뉴에서 워크플로우를 편집해 발송 시점을 조정하거나, 메시지를 개인화하거나, 단계를 추가할 수 있어요.

{% hint style="info" %}
팁: 리마인더 시간은 대상 고객의 생활 패턴에 맞추세요. 예를 들어 B2B 고객은 오전 리마인더에, B2C 고객은 저녁 알림에 더 잘 반응할 수 있어요.
{% endhint %}

## 운영 팁

### 라이브 웨비나

- 행사 전에 설정을 테스트하세요.
- 참석자의 시간대를 고려해서 일정을 잡으세요.
- 일찍, 자주 홍보하세요.
- 기술 문제에 대비한 대안을 준비하세요.
- 채팅, 투표, Q&A로 참여를 유도하세요.

### 온디맨드 웨비나

- 화질과 음질이 좋은 녹화본을 쓰세요.
- 동영상은 간결하게 30~60분으로 유지하세요.
- 시청자가 자기 속도로 볼 수 있게 콘텐츠를 구성하세요.
- 미디어 라이브러리를 잘 정리해 두세요.
- 콘텐츠를 주기적으로 새로 고치세요.

## 문제 해결

### 라이브 웨비나

- 링크가 작동하지 않아요: 링크 형식을 확인하고, 행사 전에 직접 열어 보세요.
- 시간대가 헷갈린다는 문의가 와요: 등록 페이지와 확인 페이지에 시간대를 명확하게 표시하세요.

### 온디맨드 웨비나

- 업로드가 안 돼요: 파일 형식, 파일 크기, 인터넷 연결을 확인하세요.
- 화질이 좋지 않아요: 해상도가 높은 파일을 업로드하세요.

### 공통

- 폼이 리드를 수집하지 못해요: CRM과 폼 연동을 테스트하세요.
- 템플릿이 불러와지지 않아요: 새로고침하거나 연결 상태를 확인하세요.

## 반복 웨비나

<!-- 검토 필요: 원문에서는 반복 주기 옵션 설명이 문제 해결 섹션 안에 있었으나, 내용상 반복 웨비나 섹션으로 옮김 -->

```
반복 웨비나 설정을 쓰면 웨비나 회차를 하나하나 만들지 않고도 세션을 반복할 수 있어요.
```

선택할 수 있는 반복 주기는 다음과 같아요.

- **Daily**
- **Weekly**
- **Monthly**
- **No Fixed Time**

정해진 횟수가 지나거나 선택한 날짜가 되면 시리즈를 끝내도록 설정할 수도 있어요.

반복 웨비나를 설정하려면 다음 순서를 따르세요.

1. **사이트 > 웨비나**로 이동하세요.
2. 새 웨비나를 만들거나, 반복 설정이 가능한 기존 웨비나를 여세요.
3. **Webinar Details**를 입력하세요.
4. **반복 웨비나 활성화**를 켜세요.
5. 반복 주기를 선택하세요.
6. 반복 패턴을 설정하세요.
7. 웨비나 시리즈를 언제 끝낼지 선택하세요.

## 마무리

진행 방식에 맞는 웨비나 유형을 고른 다음, 웨비나를 홍보하기 전에 등록 폼, 웨비나 콘텐츠, 퍼널 페이지, 자동화를 테스트하세요.

- 라이브 웨비나: 실시간 참여와 소통
- 온디맨드 웨비나: 상시 운영, 확장, 유연한 시청

기본 템플릿과 자동화 워크플로우를 쓰면 웨비나를 빠르게 열 수 있어요. 참석자는 알맞은 때에 리마인더를, 확인 메시지와 맞춤 후속 안내를 받아요. 적은 노력으로 참여와 전환을 높이는 데 도움이 돼요.

## 자주 묻는 질문

### 기존 웨비나를 복제할 수 있나요?
네. 하이퍼클래스에서는 웨비나를 복제할 수 있어요. 기존 설정을 재사용하고 날짜와 시간 같은 정보를 수정하세요.

### 반복 웨비나를 만들 수 있나요?
네. 반복 웨비나는 **Daily**, **Weekly**, **Monthly**, **No Fixed Time** 일정으로 반복할 수 있어요.

### 웨비나 분석은 어디에서 볼 수 있나요?
**사이트 > 분석 > 웨비나**로 이동하세요.

### 온디맨드 웨비나에도 날짜와 시간을 정해야 하나요?
아니요. 온디맨드 웨비나에는 웨비나 콘텐츠가 필요하지만, 고정된 웨비나 날짜, 시간, 시간대는 필요하지 않아요.
