# ClickFunnels 퍼널 가져오기

ClickFunnels에서 하이퍼클래스로 옮기려는 분을 위한 가져오기 기능이에요. 기존 퍼널과 페이지를 처음부터 다시 만들지 않아도 돼서, 퍼널이나 페이지가 많을수록 시간과 수고를 아낄 수 있어요.

{% hint style="info" %}
- 이 가져오기 기능은 ClickFunnels 1.0 퍼널과 ClickFunnels 2.0 퍼널 모두에서 쓸 수 있어요.
- 공유용 ClickFunnels 링크가 아니라, 게시된(라이브) 링크를 사용하세요.
- 원활하게 가져오려면 ClickFunnels 퍼널 단계를 한 번에 하나씩 가져오세요.
{% endhint %}

![가져오기 안내](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48291012563/original/DCAJE_REAKL-wXJevJXVYo1Gr2w8a5m-Jg.png?1680615158)

{% hint style="warning" %}
ClickFunnels 멤버십 영역(Members Area)은 퍼널 공유 URL로 가져올 수 없어요. 하이퍼클래스 가져오기 기능은 옵트인 페이지, 세일즈 페이지, 감사 페이지 같은 일반 퍼널 페이지만 옮겨 와요. ClickFunnels 퍼널에 멤버십 영역이 있다면 왼쪽 메뉴의 **멤버십**에서 직접 다시 만들어야 해요.
{% endhint %}

## ClickFunnels 페이지를 하이퍼클래스 퍼널 빌더로 가져오기

### 1단계. 사이트 열기

1. 왼쪽 메뉴에서 **사이트**를 클릭하세요.

![사이트 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289216423/original/OivhDT_6IuQW2EVDbsPb30fQ7NTlLGrkkw.png?1679686298)

### 2단계. 퍼널 클릭

1. **퍼널**을 클릭하세요.

ClickFunnels 가져오기는 퍼널 안에서만 쓸 수 있어요.

![퍼널 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289216682/original/iOWp2cpEnnpq9rYsP2iG01ETRVnaf3VULQ.png?1679686407)

### 3단계. 새 퍼널 만들기

1. **New Funnel**(새 퍼널)을 클릭하세요.

![새 퍼널 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289219422/original/IBSWbGJ-9ByIK7rJYHcgy9EnFcfrKdZCfA.png?1679688087)

2. 퍼널 이름을 입력하고 **퍼널 만들기**를 클릭하세요.

![퍼널 이름 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289219827/original/4JH3l789TsOZRKLbTCf3mtaLjk94J4NvbQ.png?1679688297)

### 4단계. 새 단계 추가

1. **Add new step**(새 단계 추가)을 클릭하세요.

![새 단계 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289607259/original/IbqYzbx9uJQmEKWtEe0xPVFdiPmvFqNq2w.png?1679970162)

2. 페이지 이름, 경로(path), ClickFunnels 링크를 입력하세요.
3. **확인** 체크박스를 선택하세요.
4. **Create funnel step**(퍼널 단계 만들기)을 클릭하세요.

![퍼널 단계 정보 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48289606510/original/0HjQBz7MJUgsvnuQetG3wzih6UYolg9usQ.png?1679969620)
