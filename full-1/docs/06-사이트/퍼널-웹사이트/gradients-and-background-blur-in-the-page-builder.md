# 페이지 빌더에서 그라디언트와 배경 흐림 적용하기

하이퍼클래스 페이지 빌더에서 여러 색을 섞은 그라디언트와 배경 흐림 효과를 넣는 방법을 안내해요. 선형·방사형·각도형 그라디언트를 만들고, 색상 지점을 세밀하게 조정하고, 흐림 효과로 깊이감이나 유리처럼 비치는 느낌(글래스모피즘)을 낼 수 있어요.

## 그라디언트와 배경 흐림이란?

그라디언트는 두 가지 이상의 색을 부드럽게 섞어 시각적인 깊이를 만드는 기능이에요. 배경 흐림은 요소 뒤쪽 내용을 부드럽게 흐려서 대비를 높이고 글을 더 잘 읽히게 해 줘요. 이 두 기능을 쓰면 별도의 디자인 앱 없이 하이퍼클래스 안에서 바로 세련된 레이아웃을 만들 수 있어요.

## 그라디언트와 배경 흐림의 장점

- 여러 색 조절: 최대 10개의 색상 지점으로 은은하거나 선명한 그라디언트를 만들 수 있어요.
- 다양한 스타일: 레이아웃에 맞게 **Linear**(선형), **Radial**(방사형), **Angular**(각도형) 그라디언트 유형 중에서 고를 수 있어요.
- 정밀한 편집: 시각적인 슬라이더에서 색상 지점을 끌어 옮기고, 각도를 지정해 원하는 결과를 만들 수 있어요.
- 손쉬운 깊이감: **배경 흐림**을 켜고 강도를 조절하면 부드럽고 전문적인 유리 효과를 낼 수 있어요.
- 간편한 작업: **색상**, **이미지**, **동영상** 배경 탭을 오가며 가장 알맞은 배경 소스를 고를 수 있어요.

## 배경을 적용할 수 있는 곳

배경은 **섹션**, **행**, **컬럼** 단위에 적용해요. 어느 단위에 적용하느냐에 따라 효과가 이어지는 범위와 콘텐츠가 배경 위에 놓이는 방식이 달라져요.

- **섹션**에 그라디언트나 배경 흐림을 적용하면 가로 전체를 채우는 히어로 영역을 꾸밀 수 있어요.
- **행**을 쓰면 여러 컬럼에 걸쳐 띠 모양 배경을 만들 수 있어요.
- **컬럼**에 배경 흐림이나 은은한 그라디언트를 적용하면 특정 콘텐츠 블록의 글이 더 잘 읽혀요.

## 배경에 그라디언트 넣기

아래 순서대로 배경에 그라디언트를 넣어 보세요. 여러 색을 섞은 그라디언트도 만들 수 있어요.

### 1단계: 페이지 빌더 열기

1. **사이트 > 퍼널** 또는 **웹사이트**로 이동하세요.
2. 퍼널이나 웹사이트를 열고, 편집할 페이지를 선택하세요.

![사이트 메뉴에서 편집할 페이지 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056498084/original/-07IWdrFPik9GukGL_KiJLSbEJ6TAKLP1A.png?1761061062)

### 2단계: 색상 설정 열기

1. 섹션, 행, 컬럼 중 하나를 클릭하고, 오른쪽 사이드바에서 **배경**까지 스크롤하세요.
2. **배경**에서 **색상** 탭을 선택해 색상 설정을 여세요.

![배경 아래 색상 탭 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056498653/original/bAJnWmBs6E8D_lgLXrKpN1wRM87zpYehng.jpeg?1761061349)

### 3단계: 그라디언트 켜고 유형 선택하기

1. **색상**에서 **Gradient**(그라디언트) 토글을 켜세요.
2. **유형** 드롭다운에서 그라디언트 유형(**Linear**, **Angular**, **Radial**)을 선택하세요.

![그라디언트 토글과 유형 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056499246/original/Xq-MFEfqBA8V85Bx6gz8kkjTXsLkmqVvzw.png?1761061631)

### 4단계: 그라디언트 설정하기

1. **+ Add Color**(색상 추가)를 클릭하거나 그라디언트 슬라이더를 직접 클릭해서 그라디언트에 쓸 색을 선택하세요.
2. 색상 선택기로 색을 조정하세요.
3. 그라디언트 슬라이더로 그라디언트를 원하는 모양으로 다듬으세요.
4. **각도** 슬라이더로 그라디언트 각도를 조절하세요. 각도 슬라이더는 **Linear**와 **Angular** 유형에서만 쓸 수 있어요.

![그라디언트 색상과 각도 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056499858/original/fmC1mScg5JvNU21qHb882u3LH2ojLpZnAg.png?1761061891)

## 배경에 흐림 효과 넣기

아래 순서대로 흐림 효과로 배경을 부드럽게 만들어 보세요. 반투명한 색과 함께 쓰면 특히 잘 어울려요.

### 1단계: 페이지 빌더 열기

1. **사이트 > 퍼널** 또는 **웹사이트**로 이동하세요.
2. 퍼널이나 웹사이트를 열고, 편집할 페이지를 선택하세요.

![사이트 메뉴에서 편집할 페이지 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056498086/original/EX09QUqagcwyJ2rtJfiF6lI38DMKtg0Mbg.png?1761061065)

### 2단계: 배경 흐림 켜기

1. 섹션, 행, 컬럼 중 하나를 클릭하고, 오른쪽 사이드바에서 **배경**까지 스크롤하세요.
2. **배경**에서 **색상** 탭을 선택해 색상 설정을 여세요.
3. **색상**에서 **배경 흐림** 토글을 켜세요.

![색상 탭의 배경 흐림 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056502888/original/t8oLEAKTT74oTyXl5xbCmzfPlOZjJbP6_w.png?1761063136)

### 3단계: 흐림 정도 정하기

**Blur Intensity**(흐림 강도) 슬라이더로 원하는 흐림 정도를 정하세요.

![흐림 강도 슬라이더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056502931/original/A5lt_-_4gMvNOsiy0OJ879qMs7m4CL8qjg.png?1761063199)

## 자주 묻는 질문

### 그라디언트에 색을 몇 개까지 쓸 수 있나요?
색상 지점을 최대 10개까지 쓸 수 있어요.

### 기존에 넣어 둔 배경 이미지와 동영상이 바뀌나요?
아니요. 이전 설정은 그대로 유지돼요. 그라디언트와 배경 흐림은 추가로 쓸 수 있는 옵션이에요.

### 배경 흐림이 요소 안의 내용에도 영향을 주나요?
배경 흐림은 요소 뒤쪽을 부드럽게 만들어요. 요소 안의 내용(예: 글)은 선명하게 그대로 보여요.

### 그라디언트에 줄무늬가 보여요. 어떻게 해결하나요?
다음 방법을 하나 이상 시도해 보세요. 색이 급격하게 바뀌는 부분 근처에 중간 색상 지점을 하나 더 추가하거나, 밝기가 비슷한 색을 고르거나, **각도** 슬라이더를 조금 조정해 보세요.

### 색상 지점을 지우거나 단색으로 되돌리려면 어떻게 하나요?
지우려는 색상 지점 옆의 X를 클릭하면 삭제돼요. 단색으로 되돌리려면 **Gradient** 토글을 끄고 **색상** 탭에서 색을 하나만 고르세요.
