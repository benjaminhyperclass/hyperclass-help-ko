# 퍼널·웹사이트·스토어·웨비나에서 URL 파라미터 사용하기

페이지 주소(URL)에 담긴 값으로 페이지 내용을 방문자마다 다르게 보여 줄 수 있어요. 하이퍼클래스는 **Custom Value Picker**(커스텀 값 선택기)에서 URL 파라미터를 바로 넣을 수 있게 지원해요. 기본값, 텍스트 변환, 구분 기호 정리, 빌더 안의 시각적 토큰도 함께 쓸 수 있어요.

이 문서에서는 다음 내용을 안내해요.

- **Custom Value Picker**로 URL 파라미터 넣기
- 대체 텍스트(기본값) 설정하기
- 들어오는 값의 형식 바꾸기
- 지원되는 요소에서 같은 파라미터 다시 쓰기
- 링크로 동적 값 전달하기

새 동적 콘텐츠를 만들 때 URL 파라미터 문법을 직접 입력하지 않아도 돼요.

# URL 파라미터란?

URL 파라미터는 페이지 주소 뒤에 붙여서 페이지로 정보를 넘기는 키-값 쌍이에요. 하이퍼클래스는 이 값을 이용해 지원되는 페이지 콘텐츠를 방문자마다 다르게 보여 줄 수 있어요.

예를 들어 페이지를 아래 주소로 열었다고 해 볼게요.

`https://example.com/offer?city=Austin`

이름이 `city`인 URL 파라미터를 설정해 두면 페이지 콘텐츠에 `Austin`이 바로 표시돼요. **Custom Value Picker**에서 설정하므로 템플릿 문법을 직접 입력하지 않아도 돼요.

## URL 파라미터의 장점

URL 파라미터를 이 방식으로 설정하면 동적 텍스트를 만들기 쉬워요. URL 데이터가 비어 있거나 형식이 제각각이어도 방문자에게 보이는 내용을 직접 조절할 수 있어요.

- 코드 없이 설정: **Custom Value Picker**에서 바로 URL 파라미터를 넣고 설정해요.
- 기본값: 파라미터가 없거나 비어 있을 때 대신 보여 줄 내용을 정해요.
- 텍스트 형식 변환: 들어오는 값에 UPPERCASE, lowercase, Title Case, Sentence case를 적용해요.
- 깔끔한 표시: 들어오는 값의 하이픈(-)과 밑줄(_)이 자동으로 공백으로 바뀌어요.
- 넓은 적용 범위: 버튼 텍스트와 버튼 서브 텍스트를 포함해 지원되는 여러 텍스트 영역에서 쓸 수 있어요.
- 안전한 표시: 들어오는 파라미터 값은 페이지에 표시되기 전에 정제돼요.

## 지원되는 빌더와 요소

하이퍼클래스의 페이지 빌더에서 지원되는 텍스트 영역에 URL 파라미터를 넣을 수 있어요. 방문자에게 보이는 여러 종류의 페이지에서 같은 방식으로 개인화할 수 있어요.

| 지원되는 빌더 | 지원되는 텍스트 영역 |
| --- | --- |
| 퍼널<br>웹사이트<br>스토어<br>웨비나 | 버튼 텍스트<br>버튼 서브 텍스트<br>제목<br>단락<br>리치 텍스트<br>글머리 기호 목록<br>FAQ<br>팝업 |

## URL 파라미터 설정하기

**Custom Value Picker**로 설정하면 파라미터 이름, 대체 콘텐츠, 형식 규칙이 토큰 하나에 함께 저장돼요. URL 파라미터 문법을 직접 관리하지 않아도 동적 콘텐츠를 만들고 고칠 수 있어요.

1. 개인화할 퍼널, 웹사이트, 스토어 또는 웨비나 페이지를 열고, 지원되는 텍스트 요소나 버튼을 편집해요.
2. **Custom Value Picker**를 열고 **URL Parameter**(URL 파라미터)를 선택해요.

   ![Custom Value Picker에서 URL Parameter를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080759323/original/3uZbFKa-tDeY1ho2rzxX2_9-h18tPkPzSA.png?1789170429)

3. **parameter name**(파라미터 이름)을 입력해요. 필요하면 **기본값**을 설정하고, 원하면 **text transformation**(텍스트 변환)도 선택해요.
4. URL 파라미터를 요소에 넣어요. 편집기에는 템플릿 문법 대신 시각적 토큰으로 표시돼요. 설정을 바꾸고 싶을 때는 토큰을 선택하세요.

   ![편집기에 시각적 토큰으로 표시된 URL 파라미터](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080759248/original/RI1dElWE3eLWjixNkFS4vXRiqWVDIpmd8Q.png?1789170233)

5. **저장 및 게시**를 클릭한 다음, 해당 파라미터가 붙은 URL로 페이지를 열어 확인해요.

   예를 들어 `?city=Austin`으로 열면 `city`로 설정한 토큰에 `Austin`이 표시돼요.

   ![URL 파라미터 값이 페이지에 표시된 결과 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080759250/original/5SN33iyr6pgtjikSectG7Iy6bvK2JLqbnw.png?1789170252)

## 기본값 설정하기

**기본값**은 기대한 URL 파라미터가 없거나 값이 비어 있을 때 방문자에게 보여 줄 내용이에요. 동적 영역이 빈칸으로 보이지 않게 해 줘요.

예를 들어 `city` 토큰을 설정했다면 아래 중 하나에 해당할 때 기본값이 표시돼요.

- URL에 `city` 파라미터가 없을 때
- `?city=`처럼 파라미터는 있지만 값이 비어 있을 때

{% hint style="info" %}
기본값은 토큰마다 따로 설정해요. 대체 텍스트를 직접 입력해도 되고, 이미 만들어 둔 **커스텀 값**을 기본값으로 써도 돼요.
{% endhint %}

## URL 파라미터 텍스트 형식 바꾸기

텍스트 변환을 쓰면 파라미터 자체는 그대로 두고, 들어오는 값의 대소문자만 바꿔서 보여 줄 수 있어요. 구분 기호 정리 기능 덕분에 UTM 형태의 값도 읽기 쉬워져요.

| 변환 | 예시 |
| --- | --- |
| UPPERCASE | DALLAS NOW |
| lowercase | dallas now |
| Title Case | Dallas Now |
| Sentence case | Dallas now |

구분 기호 정리: 들어오는 값의 하이픈(-)과 밑줄(_)은 자동으로 공백으로 바뀌어요. 예를 들어 `emergency-plumber`는 `emergency plumber`로 표시돼요. 여기에 Title Case를 적용하면 `Emergency Plumber`로 표시돼요.

## URL 파라미터 동작 방식

URL 파라미터가 어떻게 인식되고 표시되는지 알아 두면 페이지와 캠페인 전반에서 예측 가능하게 개인화할 수 있어요.

- 대소문자 구분 없이 인식해요: 파라미터 이름은 대소문자를 구분하지 않고 매칭해요. 예를 들어 `?City=`와 `?city=`는 설정해 둔 같은 파라미터로 인식될 수 있어요.
- 토큰마다 독립적으로 설정해요: 같은 파라미터를 여러 요소에서 쓸 수 있고, 토큰마다 다른 텍스트 변환을 적용할 수 있어요.
- 값이 없거나 비어 있을 때: 설정한 파라미터가 없거나 값이 비어 있으면 토큰에 설정해 둔 기본값이 표시돼요.
- 안전하게 표시해요: 들어오는 URL 파라미터 값은 표시되기 전에 정제돼요. 방문자가 입력한 마크업이 페이지 마크업으로 처리되지 않아요.

## 링크에서 URL 파라미터 쓰기

링크로 URL 파라미터를 전달하는 것과 도착 페이지에서 그 값을 보여 주는 것은 한 흐름의 두 부분이에요. 링크는 값을 전달하고, URL 파라미터 토큰은 그 값이 어디에 어떤 형식으로 보일지 정해요.

URL에 고정된 값을 담아 전달할 수 있어요.

`https://example.com/page?city=Austin`

링크에 머지 필드를 넣으면 연락처마다 값이 달라지게 할 수도 있어요.

`https://example.com/page?first_name={{contact.first_name}}`

도착 페이지에서 그 값을 보여 줄 위치마다 이름이 `first_name`인 URL 파라미터 토큰을 설정하세요.

## 자주 묻는 질문

### URL 파라미터가 없으면 어떻게 표시되나요?
설정해 둔 기본값이 표시돼요. URL에 파라미터는 있지만 값이 비어 있을 때도 마찬가지예요.

### URL 파라미터 이름은 대소문자를 구분하나요?
아니요. 대소문자를 구분하지 않고 매칭해요. 그래서 `?City=Austin`과 `?city=Austin`은 설정해 둔 같은 파라미터로 인식될 수 있어요.

### 같은 URL 파라미터를 여러 번 쓸 수 있나요?
네. 같은 파라미터를 지원되는 여러 요소에 넣을 수 있고, 토큰마다 텍스트 변환을 따로 정할 수 있어요.

### 커스텀 값을 기본값으로 쓸 수 있나요?
네. URL 파라미터 토큰의 기본값으로 대체 텍스트를 쓰거나 이미 만들어 둔 **커스텀 값**을 쓸 수 있어요.

### URL 값의 하이픈과 밑줄은 어떻게 표시되나요?
파라미터 값을 표시할 때 하이픈과 밑줄이 자동으로 공백으로 바뀌어요. 대소문자 변환은 따로 적용할 수 있어요.

### 버튼 텍스트에도 URL 파라미터를 쓸 수 있나요?
네. 버튼 텍스트와 버튼 서브 텍스트를 포함해 지원되는 여러 텍스트 영역에서 쓸 수 있어요.
