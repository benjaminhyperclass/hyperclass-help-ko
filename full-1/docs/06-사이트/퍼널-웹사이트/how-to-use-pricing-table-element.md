# 가격표(Pricing Table) 요소 사용하기

**Pricing Table**(가격표) 요소는 요금제, 패키지, 서비스 등급을 한눈에 보여 주는 요소예요. 레이아웃과 가격 모델을 고르고, 배지나 이전 가격 취소선 같은 전환 유도 정보를 넣을 수 있어요. 버튼 동작과 모바일 화면도 함께 설정해서 방문자가 요금제를 비교하고 바로 행동하도록 도와줘요.

## 가격표 요소란?

가격표 요소는 요금제를 하나 또는 여러 개 깔끔하게 나란히 보여 줘요. 표시 모드는 **그리드**, **캐러셀**, **클래식** 표, **Comparison**(비교) 표를 쓸 수 있어요. 가격 모델도 여러 가지이고 버튼 동작도 설정할 수 있어서, 상품과 페이지 디자인, 방문자에 맞게 꾸밀 수 있어요.

- 사용할 수 있는 곳: 하이퍼클래스의 **퍼널**, **웹사이트**, **블로그**, 이커머스 스토어 빌더에서 쓸 수 있어요. 사이트 기능이 처음이라면 [사이트 개요](../기타/websites-overview.md)를 먼저 읽어 보세요.

---

## 가격표 요소의 장점

핵심 장점을 알아 두면 언제 어떻게 쓰면 좋을지 판단하기 쉬워요.

- 레이아웃 선택: **그리드**, **캐러셀**, **클래식**, **Comparison** 중에서 콘텐츠와 페이지 목적에 맞게 고를 수 있어요.
- 요금제 비교: 가로 스크롤, 화살표, 머리 열 고정(**Comparison** 모드)으로 기능 목록을 읽기 쉽게 유지해요.
- 다양한 가격 모델: 일회성, 반복, 단계별, 변동 가격을 별도 우회 방법 없이 표시할 수 있어요.
- 전환 유도 장치: 이전 가격(취소선), 할인 배지, 혜택을 강조하는 캡션을 넣을 수 있어요.
- 버튼 동작 설정: URL 열기, 팝업 열기, 섹션 이동, [파일 다운로드](how-to-use-the-download-file-action-for-buttons.md), 동작 없음 중에서 고를 수 있어요.
- 브랜드 일관성: 색상, 간격, 열 간격을 조정해 사이트 디자인과 어울리게 만들 수 있어요.
- 모바일 대응: 작은 화면에 맞게 열이 조정되면서도 비교하기 쉬운 상태를 유지해요.

## 가격표 요소 설정하기

아래 순서대로 설정하면 빠르게 만들 수 있고, 여러 페이지에서 가격을 일관되게 유지할 수 있어요.

1. 서브 계정 왼쪽 메뉴에서 **사이트**를 클릭하고, 가격표를 넣을 퍼널이나 웹사이트를 엽니다. 해당 페이지의 파란색 **편집** 버튼을 클릭해 페이지 빌더를 엽니다.

   ![사이트 메뉴에서 페이지 편집 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053691733/original/VC4L91-VZN3tIpoEPJMgWKHpxQ8pkP9ZQQ.png?1757698028)
2. **Elements**(요소) 패널에서 **Pricing Table**을 캔버스로 끌어다 놓습니다. 요소를 끌어다 놓는 방법은 [자동 계층 레이아웃으로 끌어다 놓기](drag-and-drop-with-auto-hierarchical-layout-in-funnel-website-builder.md)에서 더 볼 수 있어요.

   ![가격표 요소를 캔버스로 끌어다 놓는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053305519/original/zAldnKQPIgXaNRHEy6Fl20qX2yxJJYVtYA.gif?1757341448)
3. 오른쪽 설정 막대에서 **그리드**, **캐러셀**, **클래식**, **Comparison** 중 하나를 선택합니다.

   ![오른쪽 설정 막대에서 레이아웃을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053322294/original/JAGhBNsHYRyAvO5okG3-NgDyMkPs-GIwrw.png?1757352474)
4. **레이아웃**(가격, 기능, 버튼 등)과 **스타일**을 설정합니다.

   ![가격표 레이아웃과 스타일을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053691242/original/GigWLk63VmdwkkJ3AdSXGPi-IDMABBlU1w.png?1757697302)
5. **데스크톱**과 **모바일** 미리보기로 화면이 잘 맞는지 확인한 뒤 **저장**하고 **게시**합니다.

   ![데스크톱과 모바일 미리보기 후 저장하고 게시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053675368/original/abInH4Z6V5QvNPbtH7iusKr9t5iJojvC8Q.png?1757687698)

## 레이아웃 모드

레이아웃을 잘 고르면 방문자가 요금제 차이를 쉽게 이해하고 더 빨리 결정할 수 있어요.

| 모드 | 설명 / 이럴 때 좋아요 | 열과 간격 | 이동 / 조작 | 애니메이션과 옵션 |
| --- | --- | --- | --- | --- |
| **그리드** | 카드 형태로 요금제를 나란히 비교하는 깔끔한 레이아웃이에요. | **Column gap**(열 간격): 0~100px, **Columns per row**(행당 열 수): 최대 5개 | — | — |
| **캐러셀** | 슬라이드 방식으로 보여 주고, 자동 넘김을 설정할 수 있어요. | **Columns per slide**(슬라이드당 열 수): 1~5개 | 자동 넘김 간격, 마우스를 올리면 일시 정지, 무한 반복 | **Fade**(페이드) 또는 **슬라이드** 애니메이션 |
| **클래식** | 기능이 많을 때 넓은 표로 자세히 비교하는 전통적인 표예요. | 가로 너비를 모두 사용해요. 긴 기능 목록에 알맞아요. | 화살표로 가로 스크롤 | — |
| **Comparison** | 열이 많고 맥락이 중요한 깊이 있는 비교에 알맞아요. | 넓은 표예요. 머리 열이 고정되어 계속 보여요. | 화살표로 가로 스크롤, 맥락 유지를 위한 머리 열 고정 | — |

{% hint style="info" %}
- 요금제가 3~4개 정도로 단순하면 **그리드**가 잘 맞아요.
- 요금제를 한 묶음씩 보여 주거나 세로 공간을 아끼고 싶다면 **캐러셀**을 쓰세요.
- 기능 목록이 길어서 고정 너비 카드에 담기 어렵다면 **클래식**이나 **Comparison**을 고르세요.
{% endhint %}

## 가격 모델과 표시 방식

가격 모델을 알맞게 고르면 방문자가 비용을 미리 파악할 수 있어서 신뢰와 전환율을 높이는 데 도움이 돼요.

| 가격 모델 | 설명 |
| --- | --- |
| **고정** | 일회성 결제예요. |
| **구독** | 일, 주, 월, 연 단위로 반복 결제해요. |
| **Price From**(시작 가격) | 변동이 있는 서비스에 "~부터" 가격을 표시해요. |
| **Price Range**(가격 범위) | 맞춤형 서비스의 최소~최대 가격을 보여 줘요. |
| **Per Unit**(단위당 가격) | 항목, 시간, 일, 좌석, 인원 등 단위별로 가격을 매겨요. |
| **무료** | 무료 제공 상품을 강조해요. 이전 가격을 함께 표시할 수도 있어요. |
| **사용자 지정** | 특수한 경우에 가격 문구를 직접 입력해요. |

## 기능 목록

기능 목록이 명확하고 훑어보기 쉬우면 방문자가 포함 내용을 파악하고 요금제를 빠르게 비교할 수 있어요.

- 요금제마다 기능을 추가하고, 순서를 바꾸고, 삭제할 수 있어요(**Columns**(열) 설정).
- 관련 항목을 묶고, 요금제마다 표현을 통일하세요(**Columns** 설정).
- 목록이 길다면 가로 이동이 가능한 **클래식**이나 **Comparison** 레이아웃이 좋아요.

## 스마트 가격 표시

가격을 시각적으로 강조하면 방문자의 시선을 끌 수 있고, 혼란 없이 혜택이 기간 한정이거나 가치 있다는 느낌을 줄 수 있어요.

- **Previous Price Display**(이전 가격 표시): 취소선으로 할인 전 가격을 보여 줘요.
- **Discount Text Badges**(할인 문구 배지): 프로모션을 강조해요.
- **Optional Pricing Captions**(선택 가격 캡션): 결제 주기 안내, 세금, 유의 사항 등을 적을 수 있어요.

  ![이전 가격, 할인 배지, 가격 캡션을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053674324/original/4FutUIHlHQONWzmvGoMWMfnMhlLq8aezTQ.png?1757687057)

## 버튼과 동작

비교하던 방문자가 실제 행동으로 이어지는 지점이 행동 유도 버튼(CTA)이에요. 퍼널 전략에 맞는 동작을 설정하세요.

동작 유형은 다음과 같아요.

- **Open URL**(URL 열기): 외부 또는 내부 URL을 열어요.
- **Open Popup**(팝업 열기): 페이지에 만들어 둔 특정 팝업을 띄워요. 팝업 설정은 [퍼널/웹사이트 진입 시 팝업 표시](../기타/show-popup-on-entering-funnel-website.md)를 참고하세요.
- **Step/Anchor Navigation**(단계/앵커 이동): 페이지의 특정 섹션으로 이동해요.
- **No action**(동작 없음): 맛보기 요금제나 비활성 상태를 표현할 때 쓸 수 있어요.

### 버튼 내용

- **사용자 지정 텍스트**: 행동을 분명히 알려 주는 문구(예: "무료 체험 시작")로 맞춤 CTA 버튼을 만들 수 있어요.
- **Optional caption**(선택 캡션): **보조 텍스트 추가**로 버튼 아래에 안내 문구를 넣을 수 있어요.
- **표시**/**숨기기**: 버튼과 캡션을 보일지 숨길지 정해요.

  ![버튼 동작과 캡션을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053677278/original/1ggPubjroBVdI5A_hF5KlvXeqsb-CdXYVQ.png?1757688625)

## 모양과 스타일

스타일을 조정하면 가격표가 브랜드와 어울리면서도 읽기 쉽고 접근하기 쉬운 상태를 유지해요.

- **색상**, **타이포그래피**, 간격, 테두리, **Column gap**(0~100px)을 조정할 수 있어요.
- 텍스트, 배지, 버튼의 색 대비를 충분히 유지하세요.
- 카드 안쪽 여백을 일정하게 맞추면 요금제 사이에 시각적으로 들쭉날쭉한 느낌이 줄어요.

## 모바일과 반응형

작은 화면에 맞게 최적화하면 가독성이 유지되고, 방문자가 불편 없이 요금제를 비교하고 행동할 수 있어요.

- 여러 열로 된 레이아웃은 모바일에서 읽기 쉽도록 열 수가 줄어들 수 있어요.
- **클래식**과 **Comparison** 레이아웃은 내용이 화면 너비를 넘으면 **화살표**와 함께 가로 스크롤이 유지돼요.
- **Comparison** 모드에서는 머리 열이 계속 보여서 요금제 이름을 놓치지 않아요.
- **데스크톱**과 **모바일** 미리보기를 모두 확인하고, 필요하면 간격과 타이포그래피를 조정하세요.

  ![데스크톱과 모바일 미리보기를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053673363/original/S58ebKxxtuarpZzm39q4Wk3_oxEL92GJAA.png?1757686623)

## 자주 묻는 질문

### 가격표 요소는 어디에서 쓸 수 있나요?
**퍼널**, **웹사이트**, **블로그**, 이커머스 스토어 빌더에서 쓸 수 있어요.

### 한 번에 몇 개의 열을 보여 줄 수 있나요?
**그리드**는 한 행에 최대 5개 열을, **캐러셀**은 슬라이드당 1~5개 열을 보여 줄 수 있어요.

### 이전 가격과 새 가격을 함께 보여 줄 수 있나요?
네. **Previous price**(취소선)를 켜고, 필요하면 **Discount badge**도 추가하세요.

### 요금제 버튼으로 팝업 결제나 폼을 열 수 있나요?
네. 동작을 **Open Popup**으로 설정하고, 해당 페이지에 만들어 둔 팝업을 선택하세요.

### 모바일에서는 어떻게 보이나요?
열이 줄어들 수 있고, 표 레이아웃은 **화살표**와 함께 가로 스크롤이 가능해요. **Comparison** 모드에서는 머리 열이 계속 보여요.

### 어떤 가격 모델을 쓸 수 있나요?
**고정**, **구독**(일, 주, 월, 연), **Price From**, **Price Range**, **Per Unit**, **무료**, **사용자 지정**을 쓸 수 있어요.

### 버튼이나 캡션을 숨길 수 있나요?
네. 버튼 설정에서 **표시**/**숨기기** 컨트롤을 사용하세요.
