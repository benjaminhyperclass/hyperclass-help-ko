# 이미지 슬라이더 요소로 웹 디자인 꾸미기

퍼널/웹사이트 빌더에 **Image Slider**(이미지 슬라이더) 요소가 추가되었어요. 이 요소로 웹사이트와 퍼널 페이지에 이미지 슬라이더를 직접 만들어 넣을 수 있어요. 방문자가 눈길을 끄는 화면에서 더 오래 머물도록 도와줘요.

## 새로 추가된 요소

- **Image Slider**(이미지 슬라이더): 웹 페이지와 퍼널에 이미지 슬라이더를 넣을 수 있어요. 캐러셀, 애니메이션, 화살표, 페이지 번호(페이지네이션) 설정 등 다양한 사용자 지정 옵션이 있어요.
- **Margin Padding**(마진·패딩): 요소 주변의 간격을 세밀하게 조정해요.
- **Shadow**(그림자): 요소에 그림자를 넣어 입체감을 더해요.
- **Custom Class**(커스텀 클래스): 특정 요소에 사용자 지정 CSS 클래스를 적용해 더 자유롭게 스타일을 꾸밀 수 있어요.
- **공개 범위**(Visibility): 기기 종류 같은 조건에 따라 요소를 보이거나 숨겨요.

## 이미지 슬라이더 요소의 장점

- 사용자 경험 향상: 이미지 슬라이더가 화면에 움직임과 시각적 매력을 더해 방문자의 관심을 끌어요.
- 참여도 상승: 움직이는 이미지 슬라이더는 사용자의 참여와 상호작용을 높이는 것으로 알려져 있어요.
- 간편한 작업 흐름: 빌더에서 이미지 슬라이더를 직접 만들고 수정하므로 디자인과 기능을 모두 직접 조절할 수 있어요.
- 정교한 레이아웃 조정: **Margin Padding** 요소로 간격을 정확하게 맞춰 콘텐츠를 알맞은 위치에 배치할 수 있어요.
- 다양한 디자인 옵션: **Shadow**, **Custom Class**, **공개 범위** 요소로 디자인을 더 폭넓게 꾸밀 수 있어요.

## 이미지 슬라이더 요소 사용하기

1. 빌더에서 이미지 슬라이더를 넣을 섹션이나 페이지를 찾아요.
2. **Image Slider** 요소를 끌어다 놓아요.
3. 전환 효과, 페이지 번호 스타일, 자동 재생 설정 등을 원하는 대로 조정해요.

   ![이미지 슬라이더 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048111017/original/bLk4oom6IZuRgb9i-HC87d5Xq0mhOAKXNg.jpeg?1749675968)
4. **미디어 라이브러리**의 이미지로 슬라이더를 채워요. 1600x900 px, 1920x1080 px처럼 16:9 비율의 이미지를 쓰면 가장 좋아요. 이렇게 하면 어떤 화면 크기에서도 슬라이더가 선명하고 일관되게 보여요.

   ![슬라이더에 이미지를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048111004/original/3eZWOmqelJXfOpyuAEhh29hdV8u1K1wUWQ.jpeg?1749675934)
5. 변경 내용을 저장하면 웹사이트나 퍼널에 이미지 슬라이더가 표시돼요.

## 자주 묻는 질문

### 이미지 슬라이더 요소가 무엇인가요?
웹 페이지와 퍼널에 이미지 슬라이더를 넣을 수 있는 요소예요. 다양한 사용자 지정 옵션으로 시선을 끄는 화면을 만들 수 있어요.

### 웹사이트나 퍼널에 이미지 슬라이더를 추가하려면 어떻게 하나요?
빌더에서 슬라이더를 넣을 섹션이나 페이지로 이동해 **Image Slider** 요소를 끌어다 놓아요. 필요한 설정을 조정하고 이미지를 추가한 뒤 변경 내용을 저장하세요.

### 이미지 슬라이더와 함께 추가된 다른 요소도 있나요?
네, **Margin Padding**, **Shadow**, **Custom Class**, **공개 범위** 요소도 함께 추가되었어요. 디자인과 사용자 지정 범위가 더 넓어졌어요.

### 특정 조건에 따라 요소를 보이거나 숨길 수 있나요?
네, 가능해요. 새로 추가된 **공개 범위** 요소로 기기 종류 같은 조건에 따라 요소를 보이거나 숨길 수 있어요.

### 슬라이드를 몇 개까지 추가할 수 있나요?
원하는 만큼 추가할 수 있어요. 보통은 3~5개 정도로 구성해요.

### 방문자가 슬라이더의 이미지를 클릭하면 어떻게 되나요?
**General options**(일반 옵션)에서 URL 리다이렉트를 설정할 수 있어요. 링크를 새 탭에서 열지, 현재 탭에서 열지도 고를 수 있어요.

### 슬라이더의 이미지 크기를 바꿀 수 있나요?
네, **General options**에서 이미지 슬라이더의 이미지 크기를 바꿀 수 있어요.

### 모바일에서도 잘 작동하나요?
네, 이 요소는 반응형이라 데스크톱과 모바일 기기에서 모두 잘 보여요.

### 이미지 슬라이더에 버튼을 넣을 수 있나요?
버튼은 이미지 안에 넣을 수 있어요. 이미지를 클릭하면 특정 페이지로 이동하는데, 버튼도 같은 역할을 하기 때문이에요.
