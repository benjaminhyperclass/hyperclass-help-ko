# 후기 요소(Testimonial) 사용하기

하이퍼클래스의 퍼널·웹사이트 빌더에서 후기 요소를 쓰면 어떤 페이지에든 브랜드에 맞는 고객 후기를 깔끔하게 넣을 수 있어요. 이 문서에서는 후기 요소가 무엇인지, 브랜드에 맞게 어떻게 설정하는지 알려 드려요.

## 후기 요소란?

후기 요소는 고객 후기를 퍼널이나 웹사이트 페이지에 바로 보여 주는 요소예요. 레이아웃, 카드 모양, 내용을 자유롭게 조정할 수 있어요. 만족한 고객의 실제 경험을 보여 주면 신뢰를 쌓고 브랜드 이미지를 강화하는 데 도움이 돼요.

**리뷰 위젯**은 Google이나 Facebook 같은 외부 플랫폼의 리뷰를 자동으로 가져와요. 후기 요소는 이와 달리 직접 입력한 후기를 보여 주는 용도예요. 그래서 후기의 내용, 순서, 모양을 모두 직접 정할 수 있어요. 엄선한 인용문, 자세한 고객 이야기, 브랜드 맞춤 메시지를 넣을 때 알맞아요.

---

## 후기 요소의 장점

실제 고객 후기를 정돈된 형식으로 보여 줘서, 한눈에 신뢰감을 줄 수 있어요.

- 사회적 증거 강화: 실제 고객의 성과를 보여 줘서 신뢰를 높여요.
- 시간 절약: 미리 만들어 둔 레이아웃과 스타일로 디자인 시간을 줄여요.
- 브랜드 일관성 유지: 사용자 지정 글꼴, 색상, 스타일로 브랜드 정체성을 살려요.
- 깔끔하고 명확하게: 긴 후기는 **더 보기** 링크로 펼쳐 볼 수 있게 할 수 있어요.
- 가독성과 전달력 향상: 글꼴 크기, 카드 모양, 평점 아이콘을 조정해서 후기를 쉽게 훑어볼 수 있게 해요.

---

## 사용자 지정 옵션

스타일, 레이아웃, 내용 표시 설정으로 후기가 페이지에 보이는 모습을 세밀하게 조정할 수 있어요. 설정 패널은 크게 세 영역으로 나뉘어요. **Testimonial Settings**(후기 설정), **Layout Options**(레이아웃 옵션), **Card Style Options**(카드 스타일 옵션)이에요.

### 후기 설정

어떤 정보를 보여 줄지 정해서, 각 후기에서 가장 중요한 내용이 돋보이게 해 보세요.

- **Show Profile Picture**(프로필 사진 표시): 켜거나 꺼서 고객 사진을 보여 주거나 숨겨요.
- **Show Name, Caption, Date**(이름, 캡션, 날짜 표시): 후기 작성자의 세부 정보를 보여 주거나 숨겨요.
- **Show Logo**(로고 표시): 로고를 보여 줘서 고객 후기에 브랜드를 더해요.
- **Show Star Rating**(별점 표시): 1~5개의 별점을 보여 주거나 숨겨요.

![후기 설정 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051376451/original/VhXXlHf62VHvOfcpBDvZIah5xPFRUzRT6w.png?1754934819)

### 레이아웃 옵션

후기를 페이지에 어떻게 배치할지 정해요. 콘텐츠와 잘 어울리면서 사회적 증거가 눈에 띄는 배치를 골라 보세요.

레이아웃은 세 가지 중에서 선택할 수 있어요.

- **그리드**: 후기를 일정한 블록 형태로 가지런히 정렬해요.
- **Vertical Masonry**(세로 매슨리): 내용 높이에 따라 후기를 엇갈리게 배치해요.
- **캐러셀**: 후기를 슬라이드로 넘겨 가며 보여 줘요.

**Columns**(열 수, 0~4)와 **Spacing**(카드 사이 간격)은 슬라이더로 조정할 수 있어요.

![레이아웃 옵션 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051376378/original/S-7Ag12dys_7W6AjSpXIVGGToOaWKUKZ1A.png?1754934733)

### 카드 스타일 옵션

깔끔한 카드 템플릿을 고른 다음, 글꼴과 색상을 브랜드의 시각적 정체성에 맞게 조정해요.

카드 스타일은 네 가지 중에서 선택할 수 있어요.

- **기본**: 위쪽에 후기 내용, 아래쪽에 프로필/이미지가 와요.
- **Reverse Center**(역방향 중앙): 이미지가 텍스트 위쪽 가운데에 와요.
- **Vertical Center**(세로 중앙): 이미지가 텍스트 아래쪽 가운데에 와요.
- **Horizontal**(가로): 프로필과 후기가 나란히 놓여요.

다음과 같은 스타일도 추가로 조정할 수 있어요.

- 카드 테두리가 둥글게 보이도록 모서리 반경 조정
- 후기 내용과 작성자 텍스트의 글꼴 스타일과 크기 변경
- 배경, 카드, 이름, 캡션, 내용, 평점, 날짜, **더 보기** 링크의 색상 변경

## 후기 요소 설정하기

다음 단계를 따라 페이지 빌더에 후기 요소를 추가하고 설정해 보세요.

#### 1단계: 페이지 빌더로 이동하기

1. 서브 계정 대시보드의 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. 상단 탭에서 **퍼널** 또는 **웹사이트**를 선택하세요.
3. 사용할 퍼널이나 웹사이트를 열고, 파란색 **편집** 버튼을 클릭해 페이지 편집기를 여세요.

![사이트 메뉴에서 퍼널 또는 웹사이트를 열고 편집 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051374556/original/rie8MQkWsDtA6Vcj3JB-7gWXwLz4Fg3e7w.png?1754932691)

#### 2단계: 후기 요소 추가하기

1. 왼쪽 위의 **요소 추가 (+)** 버튼을 클릭하세요.
2. **Testimonial**(후기) 요소를 페이지 레이아웃으로 끌어다 놓으세요.

![요소 추가 버튼으로 후기 요소를 페이지에 끌어다 놓기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051374766/original/riq2d_PTn7ZeAZnUMwdGiTjGvjI50SVVDg.png?1754933033)

#### 3단계: 후기 추가하고 설정하기

1. 후기 요소를 클릭해 설정 패널을 여세요.
2. 후기 순서를 바꾸려면 핸들(**줄 두 개 모양** 아이콘)을 끌어서 옮기세요.
3. 새 후기를 만들려면 **+ Add Testimonial**(후기 추가)을 클릭하세요.
4. 후기를 수정하려면 **연필** 아이콘을, 삭제하려면 **휴지통** 아이콘을 클릭하세요.

![후기 목록에서 순서 변경, 추가, 수정, 삭제하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051375362/original/wG29VHp264pRj2fmHx6QCHLBUf6IXoQm-g.png?1754933829)

#### 4단계: 후기 편집하기

1. **연필** 아이콘을 클릭해 후기 편집기를 여세요.
2. 이름, 캡션, 날짜, 별점, 프로필 사진, 프로필 URL, 비즈니스 URL, 로고 등을 수정하세요.

![후기 편집기에서 후기 정보 수정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051375421/original/rpQ0MK9gyYIDlWAw5oOJ1mNEgk49H2uBFg.png?1754933889)

#### 5단계: 후기의 모양과 레이아웃 꾸미기

1. **Testimonial Settings**에서 프로필 사진, 이름, 날짜, 로고, 별점 중 보여 줄 항목을 고르세요.
2. **Layout Options**에서 후기를 그리드, 캐러셀, 매슨리 중 어떤 형태로 배치할지 고르고, 열 수와 간격을 조정하세요.
3. **Card Style Options**에서 카드 스타일을 고른 다음, 글꼴과 테두리 등 스타일을 꾸며 보세요.
4. **Size and Color Options**(크기 및 색상 옵션)에서 글꼴, 색상, 크기를 브랜드 분위기에 맞게 다듬으세요.

![크기 및 색상 옵션으로 후기 디자인 다듬기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051376882/original/umQMlKFX5cO79tEBBBj1Np4LKPXTiHkG1Q.png?1754935524)

## 자주 묻는 질문

### Google이나 Facebook 리뷰를 후기로 가져올 수 있나요?
아니요. 후기 요소는 직접 추가한 후기만 지원해요. 외부 리뷰를 보여 주려면 **리뷰 위젯**을 사용하세요.

### 후기 요소는 동적 콘텐츠를 지원하나요?
아니요. 후기 요소는 고정 콘텐츠 블록이에요. 후기를 직접 추가하고 업데이트해야 해요.

### 긴 후기를 **더 보기** 링크로 줄여서 보여 줄 수 있나요?
네. 긴 후기는 자동으로 줄어들고, 선택에 따라 **더 보기**로 펼쳐 볼 수 있어요.

### 후기 순서를 바꿀 수 있나요?
네. 드래그 핸들을 끌어서 후기 순서를 바꿀 수 있어요.

### 후기 내용에 글자 수 제한이 있나요?
정해진 제한은 없어요. 다만 긴 후기는 줄어들어 보이고, **더 보기** 링크로 펼쳐 볼 수 있어요.
