# 퍼널·웹사이트 포토 갤러리 요소

웹사이트와 퍼널 페이지에 사진 갤러리를 넣는 방법을 안내해요. 기술 지식이 없어도 보기 좋은 갤러리를 만들 수 있어요.

[동영상](https://www.youtube.com/embed/Oaun4Sye9yk?&wmode=opaque)

포토 갤러리 위젯을 쓰면 이미지를 깔끔하게 보여 줄 수 있어요. 라이트박스와 지연 로딩 기능이 있어서 방문자가 페이지를 더 편하게 둘러볼 수 있어요.

## 주요 기능

- 이미지 추가: 갤러리에 이미지를 넣어 페이지를 더 생동감 있게 꾸밀 수 있어요.
- 라이트박스: 이미지를 클릭하면 큰 화면에서 볼 수 있어요.
- 제목 옵션: 갤러리에 제목을 넣어 설명을 더하거나 브랜드를 보여 줄 수 있어요.

### 레이아웃 설정

- 그리드, 세로 메이슨리, 가로 메이슨리 레이아웃: 갤러리를 보여 줄 방식을 고를 수 있어요.
- 열 개수 조정: 디자인에 맞게 열 수를 정할 수 있어요.
- 이미지 간격: 갤러리 항목 사이의 간격을 조정할 수 있어요.
- 모바일 동작: 모바일 기기용 설정을 따로 지정해서 화면 크기에 맞게 보이도록 할 수 있어요.

### 이미지 정보 및 동작

- 캡션과 설명: 이미지마다 캡션이나 설명을 넣을 수 있어요.
- 클릭 동작: 이미지를 클릭했을 때 라이트박스로 열지, 지정한 URL로 이동할지 정할 수 있어요.
- **새 탭에서 링크 열기**: 클릭한 링크를 새 브라우저 탭에서 열 수 있어요.
- 워터마크: 브랜드를 알리거나 이미지를 보호하려고 워터마크를 넣을 수 있어요.

## 사용 방법

1. 웹사이트 또는 퍼널 빌더를 열고 왼쪽 사이드바에서 **Photo Gallery**(포토 갤러리) 위젯을 찾으세요.
2. 위젯을 페이지에서 원하는 섹션으로 끌어다 놓으세요.
3. 갤러리를 설정하세요.
   - **미디어 라이브러리**에서 파일을 골라 이미지를 추가하세요. 파일을 **미디어 라이브러리** 창으로 바로 끌어다 놓아 먼저 업로드한 뒤 갤러리에 추가할 수도 있어요.
   - 그리드나 메이슨리 중에서 갤러리 레이아웃을 고르고, 필요하면 열 개수와 간격을 조정하세요.
   - 모바일 동작을 설정하세요.
   - 이미지에 캡션이나 설명을 추가하고, 이미지를 클릭했을 때의 동작(라이트박스로 열기 또는 이동)을 고르세요.
   - 브랜드를 알리거나 이미지를 보호하고 싶다면 이미지에 워터마크를 적용하세요.
