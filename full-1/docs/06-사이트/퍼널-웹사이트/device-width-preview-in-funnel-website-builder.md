# 퍼널·웹사이트 빌더에서 기기 너비 미리보기

기기 너비 미리보기를 쓰면 하이퍼클래스 빌더에서 반응형 퍼널·웹사이트 페이지를 화면 크기별로 더 꼼꼼히 확인할 수 있어요. 픽셀 너비를 직접 입력하면, 선택한 데스크톱·태블릿·모바일 구간 안에서 페이지가 어떻게 보이는지 바로 볼 수 있어요. 이 미리보기는 빌더 캔버스에만 적용돼요. 저장된 스타일이나 게시된 페이지는 바뀌지 않아요.

## 기기 너비 미리보기란?

기기 너비 미리보기는 퍼널·웹사이트 빌더 캔버스의 너비를 픽셀 단위로 직접 입력해 보는 기능이에요.

정해진 캔버스 너비 하나로만 디자인을 확인하지 않아도 돼요. 선택한 **데스크톱**, **태블릿**, **모바일** 구간 안에서 여러 너비로 테스트할 수 있어요.

직접 입력한 너비는 캔버스 미리보기만 바꿔요. 어떤 반응형 스타일을 편집하고 저장할지는 지금 선택한 기기 모드가 정해요.

## 알아 둘 점과 제한 사항

기기 너비 미리보기는 빌더 안에서 반응형을 테스트하려고 만든 기능이에요. 기기 모드와 어떻게 연결되는지 알아 두면, 미리보기 변화를 반응형 스타일 변경으로 착각하지 않아요.

아래 내용을 기억해 두세요.

- 기기 너비 미리보기는 빌더 캔버스 미리보기만 바꿔요.
- 새로운 반응형 브레이크포인트(화면 크기 구간)를 만들지 않아요.
- 어떤 반응형 스타일을 편집하고 저장할지는 선택한 **데스크톱**, **태블릿**, **모바일** 모드가 정해요.
- 직접 입력한 미리보기 너비는 현재 빌더 세션에만 적용돼요.
- 빌더를 새로고침하거나 다른 페이지로 이동하면 입력한 너비가 초기화돼요.
- 미리보기 너비는 페이지 데이터에 저장되지 않아요.
- 미리보기 너비는 게시된 페이지에 영향을 주지 않아요.
- 미리보기 너비로 별도의 반응형 스타일이 만들어지거나 적용되지 않아요.
- 입력하는 너비는 선택한 기기 모드가 지원하는 범위 안에 있어야 해요.

## 기기 모드별 지원 너비

기기 모드마다 미리보기를 지원하는 너비 범위가 정해져 있어요. 너비를 입력하기 전에 알맞은 기기 모드를 먼저 선택하세요.

| 기기 모드 | 지원 너비 |
| --- | --- |
| **데스크톱** | 1025–3000 px |
| **태블릿** | 768–1024 px |
| **모바일** | 320–767 px |

선택한 기기 모드의 범위를 벗어난 너비를 입력하면 입력란에 바로 안내 메시지가 표시돼요.

## 기기 너비 미리보기 사용 방법

기기 너비 미리보기는 퍼널·웹사이트 빌더에서 바로 쓸 수 있어요. 확인할 페이지를 열고, 반응형 모드를 선택한 다음, 미리보려는 화면 너비를 입력하세요.

### 1단계: 퍼널 또는 웹사이트 페이지 열기

1. **서브 계정 보기**의 왼쪽 메뉴에서 **사이트**를 선택하세요.
2. **퍼널** 또는 **웹사이트**를 선택하세요.
3. 편집할 퍼널 또는 웹사이트를 여세요.
4. 빌더에서 해당 단계 또는 페이지를 여세요.

![퍼널·웹사이트 빌더에서 페이지를 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082802738/original/9ULOfP7ARHFztTMwon_KNmUrjWbEUbQP5A.png?1791435528)

### 2단계: 기기 모드 선택

확인하려는 반응형 구간을 선택하세요.

- **데스크톱**
- **태블릿**
- **모바일**

선택한 기기 모드에 따라 페이지를 편집할 때 활성화되는 반응형 스타일이 달라져요.

![기기 모드를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082802006/original/DnH8RQ2SR9krvXax36WGeudWLp3Sqz7Ubg.png?1791433954)

### 3단계: 기기 너비 직접 입력

기기 전환 버튼 옆에서 **Device Width**(기기 너비) 입력란을 찾으세요.

선택한 기기 모드의 지원 범위 안에서 픽셀 너비를 입력하세요.

예를 들어 **태블릿**을 선택했다면 768 px에서 1024 px 사이의 값을 입력해요.

![기기 너비를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082802136/original/jME6E4QR6ZRxDjz7dogmS5sPifkaRKHDiQ.png?1791434257)

### 4단계: 미리보기 너비 적용

아래 두 방법 중 하나로 입력한 너비를 적용하세요.

- **적용**을 클릭하세요.
- 키보드에서 Enter 키를 누르세요.

선택한 반응형 구간을 벗어나지 않는 범위에서 빌더 캔버스가 입력한 너비로 바뀌어요.

### 5단계: 페이지 레이아웃 확인

선택한 너비에서 섹션, 행, 열, 요소, 간격, 콘텐츠가 어떻게 보이는지 확인하세요.

캔버스가 빌더 작업 공간보다 넓어지면 가로로 스크롤해서 전체 레이아웃을 확인하세요.

![입력한 너비로 바뀐 캔버스 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082802548/original/4zz2T3KoFpBw4Xkgehsub1H8Fxv6X5yJnA.png?1791435089)

### 6단계: 다른 너비로 추가 테스트

지원 범위 안에서 다른 너비를 입력해 보면, 선택한 구간 전체에서 레이아웃이 어떻게 바뀌는지 알 수 있어요.

다른 구간을 테스트하려면 **데스크톱**, **태블릿**, **모바일** 중 하나로 전환한 다음, 그 모드가 지원하는 너비를 입력하세요.

![다른 너비로 추가 테스트하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082802466/original/cD6JieDvfPi_1RiDD0Vs-OTD8Dk_PK0Ngw.png?1791434930)

### 7단계: 미리보기 초기화

초기화 옵션을 사용하면 캔버스가 현재 기기 모드의 기본 미리보기 너비로 돌아가요.

미리보기 너비를 초기화해도 이미 편집하거나 저장한 반응형 스타일은 바뀌지 않아요.

## 데스크톱·태블릿 보기에서 행과 열 너비 조정

퍼널·웹사이트 빌더에서는 **데스크톱**과 **태블릿** 보기에서 행과 열의 너비를 따로 설정할 수 있어요. 별도로 설정하기 전까지는 태블릿이 데스크톱 너비를 그대로 따라가요.

### 행과 열 너비 조정

1. 빌더에서 퍼널 또는 웹사이트 페이지를 여세요.
2. 기기 전환 버튼에서 **데스크톱** 또는 **태블릿** 보기를 선택하세요.
3. 행을 선택하고 **너비** 설정으로 너비를 조정하세요.

   ![행 너비를 조정하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083128675/original/IEHJxYbUzEszKjpRUVxYicCoiBRTIwbAZw.gif?1791820022)
4. **태블릿** 보기에서 나란히 있는 열의 너비를 조정하려면, 열 사이의 핸들을 드래그하세요.

   ![열 사이 핸들을 드래그해 너비를 조정하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083128695/original/n_f1ZC0LS6mxcbypeIDubGGnnCVTMswJjA.gif?1791820042)
5. **데스크톱**과 **태블릿** 보기를 오가며 레이아웃을 확인한 다음, 변경 내용을 저장하세요.

{% hint style="info" %}
태블릿 너비를 바꿔도 데스크톱 레이아웃에는 영향이 없어요. 태블릿 전용 너비는 저장한 뒤 빌더를 다시 열어도 그대로 유지돼요.
{% endhint %}

{% hint style="warning" %}
**중요 사항**

- 너비 상속: 직접 설정하기 전까지 태블릿은 데스크톱의 행·열 너비를 그대로 따라가요.
- 태블릿 행 너비 초기화: 태블릿 행 너비를 데스크톱 값과 같게 설정하면 별도 설정이 해제되고 다시 데스크톱 너비를 따라가요.
- 모바일 보기: 행은 항상 전체 너비로 유지되고, 행 너비 설정은 표시되지 않아요. 열은 세로로 쌓여요.
- 기존 페이지: 태블릿 전용 너비가 없는 페이지는 그대로 유지돼요. 별도로 이전 작업을 할 필요는 없어요.
{% endhint %}

## 자주 묻는 질문

### 기기 너비를 직접 입력하면 새 브레이크포인트가 만들어지나요?

아니요. 기기 너비는 캔버스 미리보기만 바꿔요. 스타일을 편집하고 저장하는 반응형 구간은 계속 데스크톱, 태블릿, 모바일이에요.

### 직접 입력한 미리보기 너비가 게시된 페이지에도 영향을 주나요?

아니요. 미리보기 너비는 페이지 데이터에 저장되지 않아요. 게시된 페이지나 거기서 생성되는 스타일에도 영향을 주지 않아요.

### 입력한 기기 너비가 저장돼서 다음에 빌더를 열 때도 그대로 있나요?

아니요. 직접 입력한 미리보기 너비는 현재 세션에서만 적용돼요. 빌더를 새로고침하거나 다른 페이지로 이동하면 초기화돼요.

### 선택한 구간의 범위를 벗어난 너비를 입력하면 어떻게 되나요?

입력란에 바로 안내 메시지가 표시돼요. 선택한 기기 모드가 지원하는 범위 안의 너비를 입력하세요.

### 빌더 작업 공간보다 넓은 너비도 미리볼 수 있나요?

네. 캔버스가 작업 공간보다 넓어지면 가로로 스크롤해서 전체 미리보기를 확인할 수 있어요.

### 기기 너비를 바꾸면 편집 중인 반응형 스타일도 바뀌나요?

아니요. 어떤 반응형 스타일을 편집하고 저장할지는 선택한 데스크톱, 태블릿, 모바일 모드가 정해요.
