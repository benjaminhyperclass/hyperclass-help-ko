# 퍼널과 웹사이트에 트래킹 코드·스크립트 추가하기

트래킹 코드를 추가하면 분석, 광고, 전환 추적 도구를 하이퍼클래스 퍼널과 웹사이트에 연결할 수 있어요. 스크립트를 어디에서 실행할지에 따라 특정 페이지에만 넣거나, 퍼널 또는 웹사이트 전체에 넣을 수 있어요.

이 문서에서는 페이지별 추적과 사이트 전체 추적의 차이, 각 코드를 넣는 위치, 추적이 제대로 작동하는지 확인하는 방법을 설명해요.

## 트래킹 코드란?

트래킹 코드는 방문자가 퍼널이나 웹사이트에서 활동할 때 정보를 수집하거나 이벤트를 실행하는 스크립트예요.

대표적인 예는 다음과 같아요.

- Google Analytics
- Google Tag Manager
- Meta Pixel
- 분석 스크립트
- 광고 픽셀
- 전환 이벤트 스크립트

코드를 어디에 넣어야 하는지는 보통 스크립트를 제공한 서비스가 안내해요.

{% hint style="warning" %}
트래킹 스크립트를 만든 서비스가 안내하는 위치 지침을 반드시 따르세요.
{% endhint %}

## 페이지별 추적과 사이트 전체 추적

스크립트를 추가하기 전에, 한 페이지에서만 실행할지 퍼널이나 웹사이트 전체에서 실행할지 먼저 정하세요.

| 추적 유형 | 이럴 때 좋아요 | 추가하는 위치 |
| --- | --- | --- |
| 페이지별 추적 | 특정 퍼널 단계나 웹사이트 페이지에서만 실행해야 하는 스크립트나 이벤트 | 빌더에서 페이지를 열고 **추적 코드**를 선택한 뒤, **헤더 추적** 또는 **푸터 추적**에 스크립트를 넣어요. |
| 사이트 전체 추적 | 선택한 퍼널이나 웹사이트의 모든 페이지·단계에서 실행해야 하는 스크립트 | 퍼널이나 웹사이트의 **설정**을 열고 **헤드 트래킹 코드** 또는 **본문 추적 코드**에 스크립트를 넣어요. |

예를 들어 Google Analytics나 Meta Pixel 기본 스크립트를 모든 페이지에서 실행해야 한다면 사이트 전체 수준으로 추가해요. 확인 페이지에 도착했을 때만 실행해야 하는 전환 이벤트는 페이지별로 추가해요.

## 특정 페이지에 트래킹 코드 추가하기

스크립트를 퍼널 단계 하나 또는 웹사이트 페이지 하나에서만 실행해야 할 때 페이지별 추적을 사용하세요.

1. **사이트**로 이동한 뒤 **퍼널** 또는 **웹사이트**를 선택하세요.
2. 트래킹 코드를 추가할 페이지가 들어 있는 퍼널이나 웹사이트를 여세요.

   ![사이트 메뉴에서 퍼널 또는 웹사이트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082921977/original/T635P65jZHddUkQdOCls9ncGPRZ90OChog.png?1791535735)

3. 해당 페이지나 퍼널 단계를 선택해 빌더에서 여세요.

   ![빌더에서 페이지 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922042/original/k0pNxnPNkcQeA7b8L9e_Lc5bljmm5WypCA.png?1791535752)

4. 빌더에서 **추적 코드** 옵션을 클릭하세요.

   ![빌더의 추적 코드 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922090/original/Wvvn25l2h1vqIqCuS03qur4c9swQr7FukA.png?1791535767)

5. 스크립트를 아래 중 한 곳에 붙여 넣으세요. 추적 서비스가 안내한 위치에 넣으면 돼요.
   - **헤더 추적**
   - **푸터 추적**
6. **저장**을 클릭하세요.

   ![추적 코드에 스크립트를 붙여 넣고 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922200/original/gLXYLPfxBV7H5QB-P9U_aEWtx3Bu0W4Tdw.png?1791535793)

7. 게시된 페이지를 열어 트래킹 코드가 의도한 대로 작동하는지 확인하세요. 분석·광고 서비스에 테스트 도구가 있다면, 그 도구로 스크립트나 이벤트가 감지되는지 확인해요.

## 퍼널·웹사이트 전체에 트래킹 코드 추가하기

같은 스크립트를 퍼널이나 웹사이트의 모든 페이지·단계에서 실행해야 할 때 사이트 전체 추적을 사용하세요.

1. **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동한 뒤, 해당 퍼널이나 웹사이트를 여세요.

   ![사이트 > 퍼널 또는 웹사이트에서 퍼널·웹사이트 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922334/original/8lie1QAuuQcAk7MARd2ZUxK4Hj_AirAcOA.png?1791535832)

2. **설정** 탭을 클릭하세요.
3. 아래 트래킹 코드 입력란을 찾으세요.
   - **헤드 트래킹 코드**
   - **본문 추적 코드**
4. 추적 서비스가 안내한 위치에 스크립트를 붙여 넣으세요.

   ![헤드 트래킹 코드와 본문 추적 코드 입력란](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082922455/original/u9IIc1iu9GLtSfxniqamJ4p0fxIcfpEXKA.png?1791535886)

5. **저장**을 클릭해 트래킹 코드를 적용하세요.
6. 스크립트가 실행되어야 하는 게시된 페이지에서 작동하는지 확인하세요. 분석·광고 서비스에 테스트 도구가 있다면, 그 도구로 스크립트나 이벤트가 감지되는지 확인해요.

## 트래킹 코드는 어디에 넣어야 할까요?

스크립트를 넣을 위치를 정할 때 아래 표를 참고하세요.

| 요구 사항 | 권장 위치 |
| --- | --- |
| 특정 페이지 하나에서만 실행 | 페이지별 **헤더 추적** 또는 **푸터 추적** |
| 퍼널이나 웹사이트 전체에서 실행 | 사이트 전체 **헤드 트래킹 코드** 또는 **본문 추적 코드** |
| 모든 페이지에서 실행해야 하는 Google Analytics 또는 Meta Pixel 기본 스크립트 | 사이트 전체 추적 |
| 특정 페이지에서만 실행해야 하는 전환 이벤트 | 페이지별 추적 |
| 서비스에서 스크립트를 페이지 head에 넣으라고 안내한 경우 | **헤더 추적** 또는 **헤드 트래킹 코드** |

정확한 위치는 외부 서비스가 안내하는 요구 사항에 따라 달라져요.

## 트래킹 코드 확인하기

트래킹 코드를 추가한 뒤에는 제대로 작동하는지 테스트하세요.

1. 트래킹 코드를 저장하세요.
2. 추적이 실행되어야 하는 게시된 페이지를 여세요.
3. 추적하려는 동작을 직접 해 보세요. 예를 들어 페이지 열기, 폼 제출, 확인 페이지 도착 같은 동작이에요.
4. 분석·광고 서비스에 테스트 도구가 있다면, 그 도구로 스크립트나 이벤트가 감지되는지 확인하세요.
5. 의도한 페이지에서만 추적이 실행되는지 확인하세요.

{% hint style="info" %}
하이퍼클래스에서 추가한 트래킹 스크립트는 브라우저에서 동적으로 삽입될 수 있어서, 페이지 소스 보기(View Page Source)의 정적 결과에는 보이지 않을 수 있어요. 스크립트를 확인할 때는 브라우저 개발자 도구나 추적 서비스의 테스트 도구를 사용하세요.
{% endhint %}

## 알아 둘 점

### 같은 스크립트를 두 번 추가하지 마세요

페이지별 추적을 추가하기 전에, 같은 스크립트가 이미 퍼널이나 웹사이트 수준에 설정되어 있는지 확인하세요.

같은 트래킹 스크립트를 두 수준에 모두 추가하면 아래 항목이 중복으로 집계될 수 있어요.

- 페이지 조회
- 이벤트
- 전환
- 리포팅 데이터

스크립트를 실행할 위치에 맞춰 페이지별 추적과 사이트 전체 추적 중 하나만 사용하세요.

### 페이지를 복사하면 페이지별 추적은 복사되지 않아요

퍼널 단계나 웹사이트 페이지를 복사하면, 페이지별 트래킹 코드는 의도적으로 복사본에서 제외돼요.

페이지 전용 픽셀, 분석 스크립트, 전환 이벤트가 엉뚱한 페이지로 넘어가는 일을 막기 위해서예요.

사이트 전체 추적은 개별 페이지가 아니라 퍼널이나 웹사이트 수준에서 설정하므로 계속 적용돼요.

자세한 내용은 [페이지를 복제하면 트래킹 코드가 복사되지 않는 이유](why-tracking-code-doesn-t-get-copied-on-copying-a-page.md)를 참고하세요.

### 쿠키 동의 요건을 확인하세요

분석·광고 스크립트는 쿠키나 다른 추적 기술을 사용할 수 있어요.

하이퍼클래스는 퍼널과 웹사이트에서 쓸 수 있는 쿠키 동의 배너를 제공해요. 방문자 정보를 저장하거나 읽는 스크립트를 사용한다면, 추적 설정과 관련 개인정보 보호 요건을 검토하세요. 쿠키 동의 배너 사용법은 [퍼널·웹사이트에서 쿠키 동의 배너 사용하기](how-to-use-the-cookie-consent-banner-in-funnels-websites.md)에서 확인할 수 있어요.

## 자주 묻는 질문

### Google Analytics를 페이지마다 하나씩 추가해야 하나요?
Google Analytics 기본 스크립트를 퍼널이나 웹사이트 전체에서 실행해야 한다면, 페이지마다 같은 스크립트를 넣지 말고 사이트 전체 수준에 한 번만 추가하세요. GA4 페이지 조회 기록 방법은 [퍼널·웹사이트의 페이지 조회를 Google Analytics(GA4)에 기록하기](../../18-리포팅/추적-어트리뷰션/how-to-record-pageviews-into-google-analytics-for-funnels-websites-ga4.md)를 참고하세요.

### 감사 페이지에만 추적을 추가할 수 있나요?
네. 스크립트나 전환 이벤트를 특정 페이지에서만 실행해야 한다면 페이지별 추적을 사용하세요.

### 하이퍼클래스에서 Google Tag Manager를 쓸 수 있나요?
네. Google Tag Manager 같은 도구도 하이퍼클래스 트래킹 코드와 함께 쓸 수 있어요. 추적 서비스가 안내하는 위치 지침을 따르세요.

### 페이지 소스 보기(View Page Source)에 트래킹 코드가 보이지 않아요.
하이퍼클래스는 트래킹 코드를 브라우저에서 동적으로 삽입할 수 있어요. 스크립트가 실행되는지 확인하려면 브라우저 개발자 도구나 추적 서비스의 테스트 도구를 사용하세요.

### 이벤트가 두 번씩 실행돼요.
같은 트래킹 스크립트가 페이지별 추적과 퍼널·웹사이트 수준에 모두 설치되어 있는지 확인하세요. 중복 설치되면 같은 이벤트가 두 번 이상 실행될 수 있어요.

### 페이지를 복제하면 트래킹 코드도 복사되나요?
퍼널 단계나 웹사이트 페이지를 복제하면 페이지별 트래킹 코드는 복사되지 않아요. 복제한 페이지를 확인하고, 필요하면 그 페이지에 맞는 트래킹 코드를 추가하세요.

### 퍼널이나 웹사이트에 Meta Pixel을 추가할 수 있나요?
네. Meta Pixel을 실행할 위치에 따라 페이지별로 추가하거나 퍼널·웹사이트 전체에 추가할 수 있어요. Meta Pixel과 Conversions API 전체 설정 방법은 [Facebook Conversion API용 퍼널 이벤트 픽셀 설정하기](../../42-통합/Facebook-Integration/how-to-set-up-a-funnel-event-pixel-for-facebook-conversion-api.md)를 참고하세요.
