# 화이트라벨 도메인으로 퍼널 공유 링크 만들기

퍼널 공유 링크를 만들고, 에이전시의 화이트라벨 도메인 주소로 바꾸는 방법을 안내해요. 서브 계정 사용자는 이 링크로 퍼널을 자기 계정에 바로 가져올 수 있어요.

## 개요

퍼널 공유 링크를 만들면 서브 계정 사용자가 퍼널을 자기 계정으로 바로 가져올 수 있어요. 링크 주소를 조금만 고치면 에이전시의 화이트라벨 도메인으로 된 링크도 만들 수 있어요. 이렇게 하면 모든 과정에 에이전시 브랜드만 보여요.

---

## 퍼널 공유 링크 만드는 순서

### 1. 퍼널 공유 링크 만들기

1. **사이트 > 퍼널**로 이동하세요.
2. 공유할 퍼널 옆의 점 세 개 아이콘을 클릭하세요.
3. **공유**를 선택하세요.
4. 만들어진 공유 링크를 복사하세요. 링크는 아래와 같은 모양이에요.

   ```
   https://affiliates.gohighlevel.com/?fp_ref=xxxx&funnel_share=6438b5b145411d0ce4332f1b
   ```

### 2. 퍼널 ID 확인하기

1. 복사한 링크를 메모장 등에 붙여넣고, `funnel_share=` 뒤에 있는 부분을 찾으세요.
2. 예를 들어 링크에 아래 내용이 있다면:

   ```
   funnel_share=6438b5b145411d0ce4332f1b
   ```

3. 퍼널 ID는 다음 부분이에요.

   ```
   6438b5b145411d0ce4332f1b
   ```

### 3. 템플릿에 퍼널 ID 넣기

1. 아래 템플릿으로 사용자 지정 공유 링크를 만드세요.

   ```
   https://app.YOURDOMAIN.com/funnels/share/FUNNELID
   ```

2. `YOURDOMAIN.com`을 에이전시의 화이트라벨 도메인으로 바꾸세요.
3. `FUNNELID`를 앞에서 복사한 퍼널 ID로 바꾸세요.

예시:

```
https://app.whitelabel.com/funnels/share/6438b5b145411d0ce4332f1b
```

### 4. 사용자 지정 링크 공유하기

1. 완성한 링크를 서브 계정 사용자에게 공유하세요.
