# 텍스트 요소에 입장 애니메이션 넣기

퍼널과 웹사이트의 텍스트 요소에 입장 애니메이션을 넣는 방법을 안내해요. 제목, 부제목, 단락, 글머리 기호 목록에 쓸 수 있고, 방문자의 시선을 끌고 싶을 때 활용하면 좋아요.

[동영상](https://www.youtube.com/embed/HJ4XHb8s-k4?&wmode=opaque)

## 주요 기능

### 1. 텍스트 요소용 입장 애니메이션

텍스트 요소(**제목**, **Sub-heading**(부제목), **Paragraph**(단락), **Bullet list**(글머리 기호 목록))에 입장 애니메이션을 넣을 수 있어요.

- 방문자의 눈길을 끄는 입장 애니메이션을 텍스트에 넣을 수 있어요.
- 스크롤하다가 텍스트가 화면에 보이기 시작하면 애니메이션이 실행돼요.
- 편집하는 동안 빌더에서 애니메이션이 어떻게 보이는지 바로 확인할 수 있어요.

### 2. 다양한 애니메이션 효과

콘텐츠 분위기와 방문자 성향에 맞춰 효과를 고를 수 있어요. 효과는 다음 분류로 나뉘어요.

- **Fade**(페이드): 텍스트가 서서히 나타나 은은하고 세련된 느낌을 줘요.
- **Slide**(슬라이드): 텍스트가 여러 방향에서 미끄러지듯 들어와요.
- **Bounce**(바운스): 통통 튀는 효과로 시선을 끌고 활기를 더해요.
- **Rotate**(회전): 텍스트가 회전하며 나타나 독창적이고 눈에 띄는 느낌을 줘요.
- **Zoom**(줌): 텍스트가 커지거나 작아지며 나타나 중요한 정보를 강조해요.

### 3. 간편한 적용

- 직관적인 화면에서 쉽게 애니메이션을 추가할 수 있어요.
- 기기와 화면 크기에 관계없이 애니메이션이 일관되게 작동해요.

## 사용 방법

1. 빌더에서 퍼널 또는 웹사이트 편집기로 이동하세요.
2. 애니메이션을 넣을 텍스트를 선택하거나 새로 추가하세요.
3. 스타일 편집기에서 새로 생긴 **Animations**(애니메이션) 탭으로 이동하세요.
4. **Fade**, **Slide**, **Bounce**, **Rotate**, **Zoom** 등 원하는 입장 애니메이션을 고르세요.
5. 빌더 페이지에서 효과를 바로 확인하세요.
6. **변경사항 저장**을 누른 뒤 페이지를 **게시**하세요.
