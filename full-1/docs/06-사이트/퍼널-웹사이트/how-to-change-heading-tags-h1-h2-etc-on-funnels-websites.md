# 퍼널·웹사이트에서 제목 태그(H1, H2 등) 바꾸기

퍼널과 웹사이트 페이지에서 제목 태그(H1, H2, H3 등)를 바꾸는 방법을 안내해요. 제목 태그를 알맞게 쓰면 SEO, 접근성, 페이지의 시각적 구조를 개선하는 데 도움이 돼요.

## 제목 태그란?

제목 태그는 웹 페이지 안에서 텍스트의 구조와 중요도를 나타내요. 보통 H1은 페이지의 대표 제목에, H2와 H3는 섹션 제목과 하위 섹션 제목에 써요. 제목 태그를 쓰면 콘텐츠를 위계에 따라 정리할 수 있고, 방문자가 읽기 쉬워져요. 검색엔진도 페이지 구성을 파악하는 데 이 태그를 활용해요.

## 제목 태그를 쓰면 좋은 점

제목 태그를 알맞게 쓰는 일은 글자를 크게 만드는 것 이상의 의미가 있어요. 페이지 성능, 가독성, 검색 순위에도 영향을 줘요.

- 검색엔진에 콘텐츠의 위계를 알려 줘서 SEO에 도움이 돼요.
- 콘텐츠를 읽기 쉬운 구조로 정리할 수 있어요.
- 모바일과 데스크톱 레이아웃 모두에서 반응형으로 보여요.
- 방문자가 핵심 섹션을 빠르게 훑어보고 이해할 수 있어서 시각적으로 더 명확해요.

## 퍼널·웹사이트에서 제목 태그 바꾸기

요소 안의 제목 텍스트를 선택하면 서식 도구 모음이 나타나요. 여기서 제목 태그 버튼을 눌러 원하는 태그를 고르면 돼요. 아래 순서대로 따라 해 보세요.

### 1단계: 웹사이트 빌더에서 페이지 열기

1. 서브 계정에서 **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동하세요.
2. 퍼널 또는 웹사이트를 클릭한 다음, 편집할 단계/페이지를 선택하세요.
3. 파란색 **Edit Page**(페이지 편집) 버튼을 클릭해 편집기를 여세요.

![사이트 편집기를 여는 Edit Page 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047013576/original/rfJRkKw7wk7SLB9oC7Fsi6Bwd3yf-Hi23g.png?1747839791)

### 2단계: 제목 편집하기

1. 바꾸려는 제목 텍스트를 드래그해서 선택하세요. 선택한 텍스트 아래에 서식 도구 모음이 나타나요.
2. 도구 모음에서 제목 드롭다운을 클릭하고 원하는 제목 태그(H1, H2 등)를 고르세요.

![서식 도구 모음에서 제목 태그를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046959427/original/UtK-RSNcVXPd8gUpJOkTLPUenmQAX0o98w.png?1747777804)

## 자주 묻는 질문

### 제목 드롭다운이 보이지 않아요.
편집 중인 텍스트가 일반 텍스트가 아니라 제목인지 확인하세요. 드롭다운은 제목에서만 나타나요.

### H1 태그를 여러 개 써도 되나요?
쓸 수는 있지만 권장하지 않아요. 페이지당 H1을 하나만 쓰면 구조가 더 명확하고 SEO에도 유리해요.

### 제목 태그를 바꾸면 모양도 달라지나요?
항상 그렇지는 않아요. 제목 스타일은 CSS로 따로 꾸밀 수 있어요. SEO와 구조에 영향을 주는 것은 태그 자체(H1~H6)예요. 두 제목이 겉보기에 똑같더라도 태그를 다르게 쓰면(H1과 H2 등) 검색엔진과 스크린 리더가 콘텐츠의 위계를 이해하는 데 도움이 돼요.

### 제목 태그도 모바일 반응형으로 보이나요?
네. **웹사이트 빌더**에서 기기별로 제목을 미리 보고 스타일을 설정할 수 있어요.
