# 사용자 지정 404 오류 페이지 만들기

방문자가 사이트에 없는 주소로 들어왔을 때 보여 줄 나만의 404 페이지를 만들고 도메인에 연결하는 방법을 안내해요. 페이지를 만들고, 도메인에 지정하고, 테스트하고, 관리하는 과정을 차례로 설명해요.

방문자가 기본 오류 화면 대신 퍼널 또는 웹사이트 페이지를 보게 되면, 사이트의 다른 콘텐츠로 이어서 이동할 수 있어요. 하이퍼클래스는 기본 페이지나 기본 404/오류 페이지가 설정되지 않은 연결 도메인도 찾아서 알려 줘요.

## 사용자 지정 404 오류 페이지란?

사용자 지정 404 오류 페이지는 연결된 도메인에서 없는 주소나 잘못된 주소로 접속했을 때 보여 줄 페이지예요.

하이퍼클래스의 퍼널 빌더나 웹사이트 빌더로 페이지를 만든 다음, 도메인의 **Default 404/Error Page**(기본 404/오류 페이지)로 지정해요. 그러면 방문자가 없는 주소로 접속했을 때 기본 오류 화면 대신 내가 만든 페이지를 볼 수 있어요.

404 페이지에는 브랜드 이미지, 메뉴, 연락처, 사용 중인 콘텐츠로 돌아가는 링크 등을 넣을 수 있어요.

### 사용자 지정 404 오류 페이지의 장점

방문자가 요청한 주소를 찾을 수 없을 때 다음에 할 수 있는 일을 알려 주면, 사이트를 일관된 모습으로 유지하는 데 도움이 돼요.

- 브랜드 일관성: 기본 오류 화면 대신 직접 디자인한 페이지를 보여 줄 수 있어요.
- 방문자 이탈 방지: 사이트의 다른 영역으로 이동할 수 있는 링크나 메뉴를 넣을 수 있어요.
- 자유로운 페이지 디자인: 다른 콘텐츠를 만들 때 쓰는 퍼널·웹사이트 페이지 빌더 도구로 오류 페이지를 만들 수 있어요.
- 도메인별 설정: 연결된 도메인마다 기본 404/오류 페이지로 쓸 페이지를 고를 수 있어요.
- 설정 상태 확인: 기본 페이지 설정이 끝나지 않은 도메인에는 **조치 필요**가 표시될 수 있어요.

## 시작하기 전에

도메인 연결 상태를 확인하고 페이지를 미리 준비해 두면, 404 페이지를 설정할 때 올바른 콘텐츠를 바로 고를 수 있어요.

**시작하기 전에:**

- 도메인이나 서브도메인이 해당하는 하이퍼클래스 **사이트** 기능에 이미 연결되어 있어야 해요.
- 도메인을 관리하는 **서브 계정**에 접근할 수 있어야 해요.
- 방문자가 없는 주소로 접속했을 때 보여 줄 퍼널 또는 웹사이트 페이지를 만들어 두세요.
- 실제 404 화면을 테스트하기 전에 페이지를 완성하고 게시하세요.

**현재 제한 사항과 동작:**

- 기본 404/오류 페이지는 해당 도메인 연결 단위로 설정해요.
- **조치 필요** 알림은 필요한 기본 페이지 설정이 끝나지 않은 연결 상품 중 해당 조건에 맞는 경우에 표시돼요.
- 이 알림은 도메인을 처음 연결한 서브 계정에서 보여요.
- 지정할 수 있는 페이지 목록은 선택한 도메인 연결에서 사용할 수 있는 페이지에 따라 달라져요.

## 사용자 지정 404 페이지가 도움이 되는 경우

방문자가 없는 주소에 들어오는 이유를 알면, 안내용 오류 페이지가 필요한지 아니면 대체 페이지로 보내야 하는지 판단하기 쉬워요.

- 깨졌거나 오래된 링크: 방문자가 이미 없어진 페이지의 링크를 눌렀어요.
- 삭제된 페이지: 콘텐츠를 지웠는데 방문자가 이전 주소를 그대로 가지고 있어요.
- 잘못 입력한 주소: 방문자가 페이지 경로를 직접 입력하다가 오타를 냈어요.
- 바뀐 페이지 경로: 방문자가 더 이상 사용하지 않는 예전 경로로 접속했어요.

404 페이지와 301 리디렉션 중 무엇을 쓸까요? 요청한 주소를 대신할 특정 페이지가 없으면 사용자 지정 404 페이지를 쓰세요. 예전 주소가 새 주소로 영구 이동했다면 301 리디렉션을 설정하세요.

## 사용자 지정 404 오류 페이지 설정하기

사용자 지정 404 화면을 만들려면 게시된 퍼널 또는 웹사이트 페이지가 있어야 하고, 잘못된 주소를 그 페이지로 연결하는 도메인 설정이 필요해요.

### 1단계: 404 페이지 만들기

방문자가 없는 주소로 접속했을 때 보게 될 페이지를 만들어요. 사용 중인 콘텐츠로 돌아갈 수 있도록 메뉴나 링크도 넣어 주세요.

#### 방법 A: 웹사이트 페이지로 만들기

1. **서브 계정** 화면에서 **사이트 > 웹사이트**로 이동하세요.
2. 사용할 웹사이트를 여세요.
3. **새 페이지 추가**를 클릭하세요.
4. 페이지 이름(예: 404 오류 페이지)을 입력하고 페이지 경로를 설정하세요.
5. **Create New Page**(새 페이지 만들기)를 클릭하세요.
6. **Create From Blank**(빈 페이지에서 만들기)를 선택하세요. 상황에 따라 다른 시작 옵션을 써도 돼요.
7. **웹사이트 빌더**로 페이지를 만드세요.
8. 방문자가 다른 곳으로 이동할 수 있도록 브랜드 이미지, 메뉴, 연락처, 링크 등을 추가하세요.
9. **변경사항 저장**을 클릭하세요. 페이지를 공개할 준비가 되면 게시하세요.

![웹사이트 페이지 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081934854/original/rCIfB3zpFUGPmBGVEVer-CcNl296mRV4cw.png?1790494052)

#### 방법 B: 퍼널 단계로 만들기

1. **서브 계정** 화면에서 **사이트 > 퍼널**로 이동하세요.
2. 사용할 퍼널을 여세요.
3. **Add New Step**(새 단계 추가)을 클릭하세요.
4. 이름(예: 404 오류 페이지)을 입력하세요.
5. 페이지 경로를 입력하세요.
6. **Create Funnel Step**(퍼널 단계 만들기)을 클릭하세요.
7. 새로 만든 단계를 열고 **편집**을 클릭하세요.
8. 방문자가 없는 주소로 접속했을 때 보게 될 페이지를 만드세요.
9. 완성한 페이지를 **저장 및 게시**하세요.

![퍼널 단계 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081934877/original/CAwPOuMSEUFgmw7MiM2Hj5evSdIhD-7-dQ.png?1790494168)

### 2단계: 도메인에 기본 404/오류 페이지 지정하기

도메인 단위로 페이지를 지정하면, 해당 연결에서 없는 주소로 접속했을 때 어떤 페이지를 보여 줄지 하이퍼클래스가 알 수 있어요.

1. **서브 계정** 화면에서 **설정**을 클릭하세요.
2. **도메인 & URL 리다이렉트**를 선택하세요.
3. 해당하는 연결 도메인을 찾아 **관리**를 클릭하세요.
4. **연결된 상품** 화면에서 해당 도메인 연결을 찾으세요.
5. 그 연결의 점 세 개 메뉴를 여세요.
6. **편집**을 선택하세요.

![도메인 연결 편집 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081934817/original/xLK9CGrvAHLdb6Hun6qBjFjeJ-A1V86Y2w.png?1790493896)

7. **Set default 404/Error Page**(기본 404/오류 페이지 설정) 드롭다운을 여세요.
8. 404 화면용으로 만든 페이지를 선택하세요.
9. **저장**을 클릭하세요.

### 3단계: 사용자 지정 404 페이지 테스트하기

실제 방문자가 들어오기 전에, 없는 주소로 접속해서 도메인이 내가 만든 오류 페이지를 보여 주는지 확인하세요.

1. 브라우저에서 연결한 도메인을 여세요.
2. 사이트에 없는 페이지 경로를 뒤에 붙이세요.
3. 해당 주소를 불러오세요.
4. 사용자 지정 404/오류 페이지가 나타나는지 확인하세요.
5. 페이지에 넣은 메뉴, 버튼, 링크가 잘 동작하는지 확인하세요.

원하는 페이지가 나타나지 않으면: **설정 > 도메인 & URL 리다이렉트 > 관리**에서 점 세 개 메뉴를 열고 **편집**을 선택하세요. 그런 다음 **Set default 404/Error Page** 에 원하는 페이지가 선택되어 있는지 확인하세요.

## 조치 필요 도메인 알림 이해하기

**조치 필요** 알림이 있으면 도메인의 **연결된 상품** 화면에서 기본 페이지 설정이 덜 끝난 곳을 쉽게 찾을 수 있어요.

퍼널, 웹사이트, 스토어, 웨비나, 블로그에 연결된 도메인 중 조건에 맞는 도메인은 **Default Page**(기본 페이지)나 **Default 404/Error Page**(기본 404/오류 페이지)를 아직 설정하지 않았을 때 이 알림이 나타날 수 있어요.

1. **설정 > 도메인 & URL 리다이렉트**로 이동하세요.
2. 해당 도메인에서 **관리**를 클릭하세요.
3. **연결된 상품** 화면을 살펴보세요.
4. **조치 필요**가 보이면 클릭하세요.

![조치 필요 알림 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081934744/original/_qkSVFf9LAxoT1ai8gsPD_YL1fpvnm5buQ.png?1790493680)

**조치 필요** 창에는 다음 항목이 있어요.

- **Default Page**
- **Default 404/Error Page**

드롭다운에서 해당 도메인에 사용할 수 있는 페이지를 선택하세요.

{% hint style="info" %}
**조치 필요** 알림은 도메인을 처음 연결한 서브 계정에서 보여요. 점 세 개 메뉴의 **편집**으로 들어가 기본 페이지와 404/오류 페이지 설정을 직접 관리할 수도 있어요.
{% endhint %}

## 자주 묻는 질문

### 도메인이나 서브도메인마다 다른 404 페이지를 쓸 수 있나요?

네. 기본 404/오류 페이지는 해당 도메인 설정마다 선택해요. 따로 설정한 도메인이나 서브도메인에는 각각 다른 페이지를 쓸 수 있어요.

### 404 페이지에 이미지, 동영상, 메뉴 같은 요소를 넣을 수 있나요?

네. 사용자 지정 404 페이지는 퍼널 빌더나 웹사이트 빌더로 만들기 때문에, 그 페이지에서 지원하는 페이지 빌더 요소를 사용할 수 있어요.

### 404 페이지를 설정했는데도 예상과 다른 오류 페이지가 나와요.

올바른 도메인 연결의 **Set default 404/Error Page** 에서 원하는 페이지가 선택되어 있는지, 그 페이지가 게시되어 있는지 확인하세요. 그런 다음 다른 리디렉션이나 연결 대상이 설정되어 있지 않은 경로로 다시 테스트해 보세요.
