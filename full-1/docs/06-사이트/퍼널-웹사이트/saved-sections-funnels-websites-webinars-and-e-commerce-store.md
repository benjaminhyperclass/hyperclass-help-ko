# 저장된 섹션 사용하기 — 퍼널, 웹사이트, 웨비나, 이커머스 스토어

이 문서에서는 새로 바뀐 섹션 저장 방식과 Universal, 전역, 템플릿 섹션의 장점, 설정·관리 방법을 설명해요. 자주 쓰는 섹션을 저장해 두고 여러 곳에서 다시 쓰고 싶을 때 참고하세요.

## 저장된 섹션 템플릿이란?

저장된 섹션 템플릿은 콘텐츠 섹션을 만들어 저장해 두고 퍼널, 웹사이트, 웨비나, 이커머스 스토어 여러 곳에서 다시 쓰는 기능이에요. 저장할 때 세 가지 유형 중에서 고를 수 있어요. 수정 내용이 모든 곳에 반영되는 **Universal**(계정 전체 적용), 하나의 자산 안에서만 반영되는 **전역**, 수정해도 서로 영향을 주지 않는 **템플릿**이에요.

- **섹션 템플릿**: 복사본으로 저장해요. 어디서든 템플릿처럼 가져다 쓸 수 있어요.
- **전역** 섹션: 퍼널 단위로 저장해요. 한 곳에서 수정하면 이 퍼널 안에서만 반영돼요.
- **Universal** 섹션: 계정 단위로 저장해요. 한 곳에서 수정하면 계정 전체의 모든 사용처에 반영돼요.

이 방식을 쓰면 디자인을 일관되게 유지하고 시간을 아낄 수 있어요. 콘텐츠를 수정했을 때 어디까지 반영되는지도 헷갈리지 않아요.

```
Universal 섹션과 전역 섹션의 차이

Universal 섹션은 퍼널, 웹사이트, 웨비나, 이커머스 스토어를 가리지 않고 계정 안의 모든 사용처에 자동으로 업데이트돼요.

전역 섹션은 현재 퍼널/웹사이트 안에서만 업데이트돼요.
```

## 저장된 섹션 템플릿의 장점

저장된 섹션 템플릿을 쓰면 콘텐츠를 더 효율적으로 관리하고 브랜드를 일관되게 유지할 수 있어요.

- 한곳에서 업데이트: **Universal** 섹션을 수정하면 퍼널, 웹사이트, 웨비나, 이커머스 스토어의 모든 사용처에 자동으로 반영돼요.
- 유연한 재사용: 동기화가 필요한지, 고정된 콘텐츠가 필요한지에 따라 **Universal**, **전역**, **템플릿** 중에서 고를 수 있어요.
- 눈으로 확인하며 선택: 자동으로 만들어지는 스크린샷과 레이블 덕분에 저장된 섹션을 미리 보고 쉽게 고를 수 있어요.
- 안전한 복제: 복제한 섹션과 스냅샷에는 고유한 ID가 부여돼요. 복사본을 수정해도 원본은 바뀌지 않아요.
- 성능 개선: 백엔드 구조가 개선되어 동기화가 더 빠르고 안정적이며, 템플릿도 안전하게 관리돼요.
- 헷갈림 감소: 섹션 유형이 분명하고 시각적 단서가 있어서, 수정이 콘텐츠에 어떤 영향을 줄지 쉽게 알 수 있어요.
- 개인 데이터는 저장되지 않아요: 레이아웃 정보만 저장되기 때문에 개인정보가 보호돼요.

## 저장된 섹션 템플릿 설정하기

섹션을 제대로 저장해 두면 콘텐츠를 다시 쓰기 쉽고, 업데이트도 의도한 대로 반영돼요. 다음 단계를 따라 섹션을 저장하고 사용해 보세요.

### 1단계: 페이지 에디터 열기

하이퍼클래스에서 퍼널, 웹사이트, 웨비나 또는 이커머스 스토어로 이동한 뒤 페이지 에디터를 여세요.

### 2단계: 섹션 선택하기

다시 쓰려고 저장할 섹션을 선택하세요.

![저장할 섹션을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048210454/original/MKEgiX57icM5RPEVRk1SLuGZj_QkSp3w9Q.png?1749813072)

### 3단계: 섹션 저장하기

**Save Section**(섹션 저장) 옵션을 클릭하세요. 통합 저장 창이 나타나요.

![통합 저장 창이 나타난 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048210525/original/K_hW-WHaVTe7_rVTDJZ5F-sJ9lsYoKcBVA.png?1749813128)

### 4단계: 섹션 유형 선택하기

- **Universal**: 업데이트가 계정 안의 모든 자산에 동기화돼요.
- **전역**: 업데이트가 현재 퍼널 또는 웹사이트 안에서만 동기화돼요.
- **템플릿**: 다른 곳에서 수정해도 동기화되지 않는, 고정된 재사용 섹션을 만들어요.

## 섹션 관리 모범 사례

- 섹션 유형은 나중에 바꿀 수 없으니, 저장하기 전에 어떤 유형으로 쓸지 정하세요.
- 헤더, 푸터처럼 모든 곳에서 똑같이 유지해야 하는 콘텐츠에는 **Universal** 섹션을 쓰세요.
- 특정 퍼널이나 웹사이트에서만 쓰는 콘텐츠에는 **전역** 섹션을 쓰세요.
- 사용처마다 조금씩 수정해야 하는 재사용 블록에는 **템플릿**을 쓰세요.
- 섹션 유형을 바꾸려면 섹션을 복제한 뒤, 복제본을 원하는 유형으로 저장하세요.

## 저장된 섹션(Universal, 전역, 템플릿)에서 AI 사용하기

**AI Page Revisions**(AI 페이지 수정)는 수정할 대상 범위를 알맞게 고를 때 가장 잘 작동해요. 동기화될 수 있는 저장된 섹션이 페이지에 있을 때는 특히 그래요.

대상별 예상 동작은 다음과 같아요.

- 저장된 섹션 하나를 대상으로 지정한 경우: 페이지의 다른 영역은 바꾸지 않고 해당 섹션만 수정하는 것이 목적이에요.
- 페이지 전체 스타일을 대상으로 지정한 경우: AI가 무엇을 수정하느냐에 따라(예: 전체 타이포그래피, 색상) 저장된 섹션을 포함해 페이지의 여러 섹션이 바뀔 수 있어요.

동기화에 미치는 영향은 다음과 같아요.

- **Universal** / **전역** 섹션: 수정한 섹션이 연결되어 동기화되는 섹션이라면, 게시한 뒤 그 섹션의 다른 사용처에도 변경 내용이 반영될 수 있어요.
- **템플릿** 섹션: 템플릿 섹션은 다시 쓰기 위한 출발점이에요. 수정은 현재 페이지 안에만 적용돼야 해요.

권장 방법은 다음과 같아요.

- 이 페이지에서만 다르게 쓰고 싶다면 **템플릿** 섹션을 삽입하거나 섹션을 복제한 뒤, 그 복사본을 수정하세요.
- 수정을 마치면 변경 요약을 확인해서 수정 범위가 맞는지, 대상이 아닌 섹션이 바뀌지 않았는지 점검하세요.

## 자주 묻는 질문

### 저장한 섹션의 유형을 나중에 바꿀 수 있나요?
아니요. Universal, 전역, 템플릿 중 하나로 저장하고 나면 유형을 바꿀 수 없어요. 바꾸고 싶다면 섹션을 복제한 뒤 새 유형으로 저장하세요.

### 전역 또는 Universal 섹션의 이전 버전을 복원할 수 있나요?
아니요. 저장된 섹션에는 버전 기록이 없어요. 한 번 수정하면 이전 버전을 복원할 수 없어요.

### 이전 버전의 페이지인데 왜 최신 섹션 변경 내용이 보이나요?
전역 섹션과 Universal 섹션은 항상 마지막으로 저장된 버전으로 동기화돼요. 페이지를 복원해도 섹션은 이전 버전으로 돌아가지 않아요.

### Universal 섹션을 수정하면 모든 곳에 반영되나요?
네. 변경 내용이 모든 퍼널, 웹사이트, 블로그, 웨비나, 스토어에 동기화돼요.

### 전역 섹션과 Universal 섹션은 어떻게 다른가요?
Universal 섹션은 계정 전체에 동기화돼요.
전역 섹션은 섹션을 만든 퍼널 또는 웹사이트 안에서만 동기화돼요.

### 섹션을 복제하면 어떻게 되나요?
저장된 섹션을 복제하면 새로운 고유 ID가 만들어져요. 복제본은 더 이상 원본과 동기화되지 않아요.

### 전역 또는 Universal 섹션이 들어 있는 페이지를 복제하면 어떻게 되나요?
섹션 ID가 그대로 이어져요. 섹션 자체를 복제하지 않는 한, 수정 내용은 여전히 모든 곳에 동기화돼요.
