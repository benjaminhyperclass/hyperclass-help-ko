# 퍼널 빌더에서 내비게이션 메뉴 만들기

내비게이션 메뉴를 쓰면 웹사이트와 퍼널에 화면 크기에 맞춰 움직이는 메뉴를 만들 수 있어요. 링크, 드롭다운, 하위 항목을 추가하고 배치 방식도 조정할 수 있어요. 최근에는 메뉴 항목 줄바꿈 옵션이 새로 생겼고, 하위 메뉴 스타일도 개선되어 데스크톱과 모바일에서 더 매끄럽게 쓸 수 있어요.

## 내비게이션 메뉴란?

내비게이션 메뉴는 방문자가 퍼널이나 웹사이트 안에서 페이지 또는 섹션을 오갈 수 있게 해 주는 요소예요. 다음 기능을 지원해요.

- 페이지로 바로 가는 링크
- 외부 URL
- 드롭다운 메뉴
- 하위 메뉴 항목이 한 단계 들어가는 드롭다운 메뉴
- 앵커 기반 스크롤
- 모바일 반응형 동작

내비게이션 메뉴는 주로 머리글과 바닥글에 넣어요.

## 내비게이션 메뉴 추가하기

1. **사이트**로 이동해 편집할 퍼널이나 웹사이트를 열어요.
2. 빌더에서 페이지를 열어요.
3. **Elements**(요소)에서 **Navigation Menu**(내비게이션 메뉴)를 찾아요.
4. **Navigation Menu** 요소를 원하는 섹션이나 행으로 끌어다 놓아요.
5. 놓은 **Navigation Menu**를 선택하면 오른쪽 사이드바에 설정 옵션이 열려요.

## 메뉴 항목 설정하기

메뉴 항목은 다음 순서로 추가해요.

1. **Navigation Menu** 요소를 선택해요.
2. **Add Item**(항목 추가) > **New Menu Item**(새 메뉴 항목)을 클릭해요.
3. 메뉴 항목 이름과 이동할 곳을 입력해요.
4. 항목을 상위 항목으로 쓸 항목 아래로 끌어다 놓아요.
5. 들여쓰기가 된 것처럼 보일 때까지 오른쪽으로 살짝 밀어요.
6. 같은 상위 항목 아래에 항목을 더 넣으려면 같은 방법을 반복해요.

{% hint style="info" %}
기본 내비게이션 메뉴 드롭다운은 하위 메뉴 항목을 한 단계까지 지원해요.
{% endhint %}

드롭다운은 이렇게 만들어요.

1. 상위 메뉴 항목을 추가해요.
2. 그 항목 아래에서 **Add Sub Item**(하위 항목 추가)을 클릭해요.
3. 하위 링크를 설정해요.
4. 하위 항목을 더 넣으려면 같은 방법을 반복해요.

## 메뉴 항목 줄바꿈

**Wrap**(줄바꿈) 옵션을 켜면 한 줄에 메뉴 항목이 다 들어가지 않을 때 항목이 다음 줄로 넘어가요.

이 옵션을 켜면 가로 공간이 부족할 때 메뉴 항목이 자동으로 다음 줄로 내려가요. 레이아웃이 깨지지 않고, 화면 크기가 달라져도 메뉴가 잘 맞춰져요.

### 줄바꿈이 필요한 이유

- 메뉴가 화면 밖으로 넘치는 것을 막아요.
- 작은 화면에서 반응성이 좋아져요.
- 머리글 정렬이 깔끔하게 유지돼요.
- 레이아웃이 틀어지는 것을 줄여요.

특히 다음과 같은 경우에 유용해요.

- 메뉴 항목이 많을 때
- 메뉴 이름이 길 때
- 태블릿이나 중간 크기 화면일 때

## 하위 메뉴 스타일 개선

하위 메뉴의 모양과 사용성이 개선되었어요.

- 드롭다운이 더 안정적으로 표시돼요.
- 마우스를 올렸을 때 동작이 더 깔끔해요.
- 간격과 정렬이 좋아졌어요.
- 기기가 달라져도 하위 메뉴 스타일이 더 일관돼요.

이 업데이트로 화면이 어색하게 보이던 부분이 줄고, 메뉴를 쓰는 흐름도 더 자연스러워졌어요.

## 모바일에서의 동작

내비게이션 메뉴는 모바일 화면에 맞게 자동으로 바뀌어요. 설정에 따라 메뉴가 햄버거 메뉴 형태로 접힐 수도 있어요.

최근 개선으로 다음 부분도 좋아졌어요.

- 터치 반응이 더 좋아졌어요.
- 모바일에서 드롭다운을 쓰기 편해졌어요.
- 애니메이션 전환이 더 일관돼요.

## 스타일 옵션

다음 항목을 사용자 지정할 수 있어요.

- 글꼴 스타일
- 글꼴 크기
- 메뉴 정렬(왼쪽, 가운데, 오른쪽)
- 항목 사이 간격
- **배경 색상**
- 호버 효과
- 드롭다운 모양

요소 설정 패널의 **스타일** 탭에서 이 옵션을 설정해요.

## 내비게이션 메뉴에서 Scroll-to-Element 사용하기

내비게이션 메뉴 항목을 누르면 페이지 안의 특정 섹션으로 스크롤되도록 설정할 수 있어요.

최근 업데이트로 스크롤이 갑자기 이동하지 않고 부드럽게 움직여요. 페이지 안에서 이동할 때 전환이 더 자연스러워졌어요.

## 활용 팁

- 메뉴 이름은 짧게 써요.
- 복잡한 메뉴는 드롭다운으로 정리해요.
- 메뉴 항목이 많다면 **Wrap**을 켜요.
- 게시하기 전에 모바일 화면에서 확인해 봐요.
- 하위 메뉴 단계를 너무 많이 만들지 않아요.

## 자주 묻는 질문

### Wrap 옵션은 어떤 기능인가요?

**Wrap** 옵션을 켜면 메뉴 항목이 사용할 수 있는 너비를 넘을 때 새 줄로 넘어가요. 그래서 레이아웃이 화면 밖으로 넘치지 않아요.

### 하위 메뉴 개선을 적용하려면 설정을 바꿔야 하나요?

아니요. 스타일과 동작 개선은 자동으로 적용돼요.

### 부드러운 스크롤이 기본으로 켜져 있나요?

네. 이제 Scroll-to-element 동작은 자동으로 부드럽게 스크롤돼요.

### 이미 게시한 퍼널이나 웹사이트에도 영향이 있나요?

기존 메뉴에도 스타일과 부드러운 스크롤 개선이 자동으로 적용돼요. **Wrap** 옵션은 필요하면 직접 켜야 해요.

### 직접 설정한 스타일이 바뀌나요?

아니요. 기존 스타일 설정은 그대로 유지돼요.
