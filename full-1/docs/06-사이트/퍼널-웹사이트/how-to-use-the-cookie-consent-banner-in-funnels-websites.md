# 퍼널·웹사이트에서 쿠키 동의 배너 사용하기

퍼널과 웹사이트에 쿠키 동의 배너를 달면 방문자가 쿠키를 수락하거나 거부할 수 있어요. 이 문서에서는 배너를 켜고, 모양과 문구를 바꾸고, 쿠키 목록을 관리하는 방법을 안내해요. 개인정보 보호 규정을 지키려는 노력에 도움이 되지만, 이 기능을 쓴다고 특정 법을 준수한다는 보장은 없어요.

{% hint style="warning" %}
이 도구를 사용한다고 해서 특정 법률의 준수가 보장되는 것은 아니에요.
{% endhint %}

## 쿠키 동의 배너 설정하기

### 1. 배너 켜기

1. 퍼널·웹사이트 빌더에서 해당 퍼널이나 웹사이트를 열어요.
2. 배너를 켜려는 페이지로 이동해요.
3. **Cookie Consent Banner Settings**(쿠키 동의 배너 설정) 아이콘을 클릭해요.
4. 스위치를 켜거나 꺼서 배너를 사용하거나 사용하지 않도록 설정해요.

### 2. 버튼 동작 확인하기

- **Accept Essential**(필수 쿠키만 수락): 웹사이트 기능에 꼭 필요한 쿠키만 수락해요.
- **Accept All**(모두 수락): 추적·분석 쿠키를 포함한 모든 쿠키를 수락해요.

### 3. 쿠키 환경설정 알아보기

- **Reject**(거부): 필수 쿠키만 수락해요.
- **취소**: 팝업을 닫고 메인 배너를 다시 열어요.
- **환경설정 저장**: 방문자가 선택한 쿠키 설정을 저장해요.

## 쿠키 동의 배너 사용자 지정하기

### 일반 설정

**일반 설정**에서 다음을 할 수 있어요.

- 쿠키 목록을 켜거나 꺼요.
- 규정 준수 방식을 선택해요.
  - **Ask to Opt-In**(수신 동의 요청): **Accept Essential** 버튼과 **Accept All** 버튼을 보여 줘요.
  - **Don't Ask**(묻지 않음): **확인** 버튼만 보여 줘요.
- 안내 문구와 개인정보처리방침 링크를 추가해요.
- 색상, 글꼴, 글자 크기 등 배너의 모양을 바꿔요.

![배너 일반 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048119012/original/AAAWd9G3edH4Npxa6yglHfnPMKcJGuuHJQ.png?1749705539)

### 고급 설정

**고급 설정**에서 다음을 설정해요.

- **Consent Expiration**(동의 만료): 동의를 다시 묻기 전까지의 일수를 정해요.

### 레이아웃 옵션

사이트 레이아웃과 브랜드에 맞게 배너 표시 스타일을 고를 수 있어요.

### 버튼과 팝업 문구 바꾸기

배너와 환경설정 팝업에 있는 모든 버튼의 문구를 브랜드나 언어에 맞게 직접 수정할 수 있어요.

배너에서 수정할 수 있는 버튼은 다음과 같아요.

- **Accept All**
- **Accept Essential**
- **Customize**(사용자 지정)
- **확인**

팝업에서 수정할 수 있는 버튼은 다음과 같아요.

- **Reject**
- **환경설정 저장**
- **취소**

{% hint style="warning" %}
버튼 문구를 직접 수정하면 자동 번역(i18n)이 꺼져요. 여러 언어를 지원한다면 지원하는 모든 언어의 번역을 직접 추가해야 일관된 다국어 환경을 제공할 수 있어요.
{% endhint %}

## 새 기능: 지역별 표시 설정

방문자의 위치에 따라 쿠키 배너를 보여 줄 지역을 정할 수 있어요.

- **Worldwide**(전 세계): 모든 방문자에게 배너를 보여 줘요.
- **EU & UK**(EU 및 영국): 유럽 연합과 영국의 방문자에게만 배너를 보여 줘요.
- **Select Countries**(국가 선택): 배너를 보여 줄 국가를 직접 골라요.

{% hint style="info" %}
규제 지역 밖의 방문자에게 불필요한 안내가 뜨는 일을 줄여 줘요. 법적 준수는 유지하면서 사용자 경험도 좋아져요.
{% endhint %}

## 쿠키 목록 관리하기

**Cookie List**(쿠키 목록)를 켜면 방문자가 쿠키 종류별로 허용 여부를 직접 선택할 수 있어요.

![쿠키 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048119011/original/S81fnVUtZh7A51b2jYSsG6rQFQHpfl6tMA.png?1749705539)

### 기본 쿠키 카테고리

- **Essential**(필수): 웹사이트 기능에 꼭 필요한 쿠키예요. 항상 켜져 있어요.
- **Functional**(기능): 소셜 미디어 공유, 피드백 수집 같은 기능을 지원해요.
- **분석**: 페이지 조회수, 이탈률 등 방문자 행동을 추적해요.
- **Performance**(성능): 사이트 속도와 사용자 경험을 최적화해요.
- **Advertising**(광고): 타겟 광고와 마케팅에 쓰여요.
- **Uncategorized**(미분류): 위 카테고리에 속하지 않는 쿠키예요.

### 카테고리에 쿠키 추가하기

쿠키마다 다음 항목을 입력해요.

- **Cookie Key**(쿠키 키): 쿠키 이름이에요. 여러 쿠키를 한 번에 지정할 수 있도록 정규식 패턴을 지원해요.
- **Duration**(기간): 쿠키가 유지되는 기간이에요(예: 1일, 30일, 1년).
- **도메인**: 쿠키를 설정하는 도메인이에요.
- **설명**: 쿠키의 용도예요.

![쿠키 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048119008/original/ZswYHx3KvqTToOvPM9rdREX3AouL0ia2ng.jpeg?1749705538)

### 정규식 패턴 사용하기

정규식 패턴을 쓰면 여러 쿠키를 한 번에 지정할 수 있어요. 예를 들면 다음과 같아요.

- `ga-*`: "ga-"로 시작하는 모든 쿠키(예: ga-1234, ga-3241)
- `_fbp`: Meta Pixel 쿠키
- `_ga.*`: 모든 Google Analytics 쿠키

![정규식 패턴 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048119014/original/Ujey8BfAVY6J3GGNLeL0_d08vzSla36XMg.jpeg?1749705540)

### 내 웹사이트의 쿠키 스캔하기

1. 쿠키 동의 배너를 잠시 꺼요.
2. [CookieServe](https://www.cookieserve.com/) 같은 무료 도구로 웹사이트를 스캔해요.
3. 감지된 쿠키를 확인하고 알맞은 카테고리에 지정해요.

{% hint style="warning" %}
스캔하기 전에 반드시 배너를 꺼 주세요. 배너가 켜져 있으면 필수가 아닌 쿠키가 차단되어 전체 스캔이 되지 않아요.
{% endhint %}

## 마케팅 도구와 연동하기

추적이 제대로 되려면 쿠키를 알맞은 카테고리로 분류해야 해요.

- **Advertising**: Facebook Pixel(fbp, _fbc) 등 광고 플랫폼 쿠키
- **분석**: Google Analytics(ga, _gid), Google Tag Manager 등 추적 도구 쿠키

연동 방법은 "퍼널·웹사이트 쿠키 배너에서 사용할 마케팅 도구(Marketing Tools to Use in Funnel & Website Cookie Banner)" 문서를 참고하세요.

---

## 활용 팁

- 새로운 쿠키가 있는지 정기적으로 웹사이트를 스캔하세요.
- 쿠키마다 쉽고 명확한 설명을 적어 주세요.
- 비슷한 쿠키는 정규식 패턴으로 묶어 정리하세요.
- 마케팅 도구의 쿠키가 올바른 카테고리에 들어 있는지 확인하세요.
- 쿠키 만료 설정을 정확하게, 최신 상태로 유지하세요.

이렇게 관리하면 개인정보 보호법 요건에 대응하면서, 방문자가 자신의 데이터를 더 직접 관리할 수 있어요.

{% hint style="warning" %}
이 도구를 사용한다고 해서 특정 법률의 준수가 보장되는 것은 아니에요.
{% endhint %}

## 자주 묻는 질문

### 쿠키 동의 배너가 왜 필요한가요?
사용자 데이터를 수집하는 웹사이트가 GDPR, CCPA 같은 개인정보 보호법에 대응하는 데 도움이 되도록 만든 기능이에요.

### 방문자가 나중에 쿠키 환경설정을 바꿀 수 있나요?
아니요. 방문자는 나중에 환경설정을 업데이트할 수 없어요.

### 방문자가 모든 쿠키를 거부하면 어떻게 되나요?
필수 쿠키만 저장되고, 모든 추적·분석 쿠키는 비활성화돼요.

### 쿠키 동의 배너의 모양을 바꿀 수 있나요?
네. 설정에서 색상, 글꼴, 버튼 스타일, 텍스트 설명을 조정할 수 있어요.

### 쿠키 동의가 퍼널이나 웹사이트의 모든 페이지에 적용되나요?
네. 쿠키는 도메인 단위로 관리되기 때문에, 한 번 켜면 퍼널이나 웹사이트의 모든 단계와 페이지에 배너가 적용돼요.

{% hint style="info" %}
쿠키 동의 배너를 쓰면 웹사이트가 개인정보 보호법 요건에 대응하는 데 도움이 되고, 방문자도 쿠키 설정을 더 직접 관리할 수 있어요. 브랜드와 규정 준수 요건에 맞게 배너를 설정해 보세요. 웹사이트 전체가 관련 법률을 준수하는지 확인할 책임은 사용자에게 있어요.
{% endhint %}
