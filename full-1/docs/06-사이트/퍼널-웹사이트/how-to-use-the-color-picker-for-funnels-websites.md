# 퍼널·웹사이트에서 색상 선택기 사용하기

색상 선택기(Color Picker)에서는 브랜드 색상, 기본 색상, 사용자 지정 색상을 정해 페이지 어디에든 적용할 수 있어요. 단어 하나, 글자 하나까지 색을 따로 지정할 수도 있어요. 이 문서에서는 색상 선택기가 무엇인지, 어떤 점이 좋은지, 어떻게 쓰는지 알려 드려요.

## 색상 선택기란?

색상 선택기는 하이퍼클래스의 퍼널·웹사이트 빌더 안에서 색상을 정하는 도구예요. 섹션 배경부터 텍스트 강조까지 모든 색을 여기서 정해요. 브랜드 색상, 기본 색상, 사용자 지정 색상을 한 화면에 모아 보여 줘요. HEX, RGB, 커스텀 값 형식을 쓸 수 있고, 텍스트 인라인 도구 모음에서 글자 단위로 색을 지정할 수도 있어요.

{% hint style="info" %}
페이지 빌더의 기본 스타일이 새로 바뀌면 색상 선택기의 기본 색상도 달라질 수 있어요. 예를 들어 Cobalt, Smoke 같은 새 기본 팔레트 색상이 추가될 수 있어요. 브랜드 일관성이 꼭 필요하다면 **브랜드 보드** 색상이나 **전역 사용자 지정 색상**을 설정해 두고, 그 색상을 골라 쓰세요.
{% endhint %}

## 색상 선택기의 주요 장점

화면 하나에서 색을 고르고 관리할 수 있어서 페이지를 더 빠르고 일관되게 꾸밀 수 있어요.

- 통합 팔레트: 브랜드 색상, 기본 색상, 사용자 지정 색상을 한 패널에서 보여 줘요. 탭을 오갈 필요가 없어요.
- 글자 단위 색상 지정: 단어 하나, 글자 하나에만 색을 입혀 정확하게 강조할 수 있어요.
- 색상 이름 지정: 색에 "CTA Blue" 같은 이름을 붙여 두고 빠르게 다시 쓸 수 있어요.
- 다양한 색상 형식: HEX, RGB, 커스텀 값으로 색을 입력하고 확인할 수 있어요.
- 중복 방지: 같은 색이 실수로 중복 저장되지 않게 확인해 줘요.
- 간결한 화면: 공간을 적게 차지하고 빠르게 불러와져서 작업에 방해가 되지 않아요.

## 단어·글자 단위로 색상 지정하기

업데이트된 인라인 텍스트 편집기에서는 텍스트의 단어 하나, 심지어 글자 하나에도 색을 적용할 수 있어요. 특정 단어만 강조하거나 텍스트 일부의 색만 바꿀 수 있어서 디자인을 세밀하게 다듬을 수 있어요.

## 사용자 지정 색상 이름과 툴팁

이름을 붙여 두면 비슷한 색이 많아도 팔레트를 깔끔하게 관리할 수 있어요.

#### 색상에 이름 붙이기

색을 고른 뒤 사용자 지정 색상에 이름을 붙일 수 있어요. 예를 들면 "Warning Red"처럼요. 이름은 언제든 수정하거나 지울 수 있어요.

![사용자 지정 색상에 이름을 붙이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051160535/original/1Vggg2ZFsC6uWnIZYxzSucJ7DpyCCAUIhw.png?1754599413)

#### 색상 이름 툴팁

사용자 지정 색상 위에 마우스를 올리면 그 색의 이름이 툴팁으로 나타나요. 비슷한 색을 쉽게 구분할 수 있어서 팀원이 HEX 코드를 외우지 않아도 알맞은 색을 고를 수 있어요.

![마우스를 올렸을 때 색상 이름이 툴팁으로 표시되는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051160803/original/fRw8Wx4PUYBPpxQ4i8gol0BXRSZIoNwGRg.png?1754599942)

## 지원하는 색상 형식

색상 선택기에서는 여러 형식으로 색을 고르고 저장할 수 있어요. 드롭다운에서 형식을 바꿀 수 있어요.

- **HEX**: 색을 여섯 자리 코드로 나타내는 형식이에요(예: #1E90FF). 웹 디자인에서 가장 흔히 써요.
- **RGB**: 빨강, 초록, 파랑 값을 세 개의 숫자로 나타내는 형식이에요(예: rgb(30,144,255)). 색 혼합과 투명도를 세밀하게 조절할 때 편해요.
- **커스텀 값**: `{{ custom_values.primary_color }}` 같은 동적 토큰을 쓸 수 있어요. 커스텀 값에서 색을 가져오기 때문에 한 곳에서 바꾸면 쓰인 모든 곳에 반영돼요.

![색상 형식을 바꾸는 드롭다운 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051160736/original/WzlihryVhW-9lXTRM_CKo_iIC1a4kUwgcA.png?1754599810)

## 유효성 검사와 중복 색상 방지

#### 커스텀 값 유효성 검사

커스텀 값 토큰은 현재 서브 계정의 설정에 이미 있어야 저장할 수 있어요. 그래서 존재하지 않는 값을 참조하는 오류를 막아 줘요.

#### 중복 색상 방지

이미 팔레트에 있는 색을 저장하려고 하면 색상 선택기가 바로 알려 주고 값을 바꾸도록 안내해요. 그래서 일관성을 지키면서 실수를 줄일 수 있어요.

![이미 있는 색을 저장하려 할 때 중복 안내가 나타나는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051160685/original/xG5j-x_n8H9f4klkAp4FOKi_C0nPCvmvow.png?1754599744)

## 색상 선택기 사용 방법

#### 1단계: 색상 선택기 열기

1. 이미 만들어 둔 퍼널 또는 웹사이트 페이지를 열어요.
2. 섹션, 요소, 텍스트 블록 중 하나를 선택해요.
3. 스타일 패널의 **색상** 사각형을 클릭해요. 텍스트라면 인라인 도구 모음의 **A** 아이콘을 클릭해요.

![스타일 패널의 색상 사각형과 인라인 도구 모음의 A 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051160970/original/GRQNsgty6uvfl4_pBv7uhZO0J1LRERwEzg.png?1754600328)

#### 2단계: 색상 고르기

1. **기본 색상**, 브랜드 색상, 이미 만들어 둔 **사용자 지정 색상** 중에서 원하는 색을 골라요.
2. 새 사용자 지정 색상을 만들려면 **+ 추가**를 눌러요.

![기본 색상, 브랜드 색상, 사용자 지정 색상이 보이는 팔레트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051161016/original/DpGToqSkGDyadKxEm7yczG3RTXhsyWyzLg.png?1754600498)

#### 3단계: 사용자 지정 색상 만들기

1. 사용자 지정 색상 패널이 열리면 원하는 색을 선택해요.
2. 드롭다운에서 RGB, HEX, **커스텀 색상** 중 사용할 형식을 골라요.
3. 색상을 알아보기 쉬운 이름을 입력해요.
4. **저장**을 클릭해요. 새 색상 타일이 팔레트에 나타나요.

![사용자 지정 색상을 만들고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155051161075/original/cb6br_kB7TZXbbv4j8kOc0I8lFbjy5mkFQ.png?1754600645)

### 버튼 아이콘 색상 (페이지 빌더)

이제 버튼 아이콘의 색을 따로 지정할 수 있어요. 버튼 텍스트나 서브텍스트의 색은 그대로 두고, 아이콘이 잘 보이는지, 브랜드와 어울리는지만 세밀하게 맞출 수 있어요.

#### 작동 방식

- 별도 색상 지정: **Icon Color**(아이콘 색상)는 텍스트 색상, 서브텍스트 색상과 따로 설정해요.
- 색상 출처: 새 색상 선택기를 사용하므로 **브랜드 보드** 색상과 **사용자 지정 색상**도 고를 수 있어요.
- 디자인 유연성: 아이콘은 브랜드 포인트 색에 맞추고, 텍스트는 읽기 쉬운 색으로 유지할 수 있어요.

## 자주 묻는 질문

### 브랜드 색상을 수정하면 이미 만든 페이지도 바뀌나요?
아니요. 브랜드 색상을 수정하면 그 이후에 적용하는 색부터 바뀌어요. 이미 요소나 텍스트에 저장된 색은 그대로 유지돼요.

### 저장하려고 하면 "중복 색상" 메시지가 나타나요. 왜 그런가요?
입력한 값이 이미 팔레트에 있거나, 저장된 커스텀 값이 같은 값으로 연결되기 때문이에요. 값을 바꾸거나, 이미 있는 색상 타일을 대신 수정하세요.

### 사용자 지정 색상의 이름을 바꾸거나 삭제해도 페이지에 문제가 없나요?
네. 색상 타일의 이름을 바꾸거나 삭제해도 기존 페이지에 이미 적용된 색은 바뀌지 않아요.

### 브랜드 색상을 한꺼번에 가져올 수 있나요?
**브랜드 보드**에 추가하세요. 추가한 색상은 팔레트 맨 위에 자동으로 표시돼요.

### 커스텀 값 색상이 저장되지 않아요. 왜 그런가요?
토큰이 현재 서브 계정의 **커스텀 값**에 있어야 하고, 최종 값이 이미 있는 색상 타일과 같으면 안 돼요. 해당 커스텀 값이 계정에 있는지 확인하세요.

### 새 페이지가 예전 페이지와 다르게 보이는 이유는 뭔가요?
최신 디자인에 맞춰 페이지 빌더의 기본값(글꼴, 플레이스홀더, 기본 팔레트 색상)이 업데이트될 수 있어요. **브랜드 보드**나 저장해 둔 템플릿을 쓰면 모든 페이지의 스타일을 일관되게 유지할 수 있어요.
