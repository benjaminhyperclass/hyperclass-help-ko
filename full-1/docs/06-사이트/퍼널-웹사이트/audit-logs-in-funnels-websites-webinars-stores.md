# 퍼널·웹사이트·웨비나·스토어의 감사 로그 확인하기

**퍼널**, **웹사이트**, **웨비나**, **스토어**에서 누가 언제 무엇을 바꿨는지 **감사 로그**로 확인할 수 있어요. 이 문서에서는 감사 로그가 무엇인지, 어디서 보는지, 어떤 작업이 기록되는지 설명해요.

[동영상](https://www.youtube.com/embed/\_L2IIkLCLr0?&wmode=opaque)

## 감사 로그란?

감사 로그는 하이퍼클래스 자산에서 사용자가 한 작업의 기록이에요. 누가, 언제, 어디서, 무엇을 했는지 변경 내역을 처음부터 끝까지 볼 수 있어요. 문제의 원인을 찾거나 작업 방식을 개선하고, 규정을 지키는 데 도움이 돼요.

## 감사 로그를 쓰면 좋은 점

변경 내역이 명확하게 남아서 팀의 책임 소재가 분명해지고, 문제를 더 빨리 해결하고, 디지털 자산을 더 체계적으로 관리할 수 있어요.

- 수정과 삭제 내역을 모두 확인할 수 있어요.
- 누가 변경했는지 추적해서 팀의 책임감을 높일 수 있어요.
- 특정 작업의 이력을 살펴보며 오류의 원인을 찾을 수 있어요.
- 규제 대상 업종에서 규정 준수에 활용할 수 있어요.
- 모듈이나 작업 유형으로 필터링해서 문제를 좁혀 볼 수 있어요.
- 로그는 60일 동안 안전하게 보관돼요.

## 감사 로그 열기

**감사 로그**는 계정의 **설정** 영역에 있고, 모듈별로 나뉘어 있어요. 모듈마다 로그와 필터가 따로 있어서 **퍼널**, **웹사이트**, **웨비나**, **스토어**의 작업을 각각 확인할 수 있어요.

1. 왼쪽 메뉴에서 **설정 > 감사 로그**로 이동하세요.

   ![설정 메뉴의 감사 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066487592/original/l8AlLAodg9UCk_NDWaSgOqp0Hqx4ZrJfRQ.png?1773051824)

2. 탭이나 아이콘을 눌러 모듈을 바꿔 가며 보세요.
   - **퍼널**
   - **웹사이트**
   - **웨비나**
   - **스토어**(이커머스)
3. 선택한 모듈의 로그 목록을 확인하세요.

   ![모듈별 감사 로그 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066487837/original/rMwwraT4OXQat9Myi-I-95_-D2fWPS75Lw.png?1773051956)

## 모듈별로 기록되는 내용

모듈마다 로그와 필터가 따로 있어서, 지금 작업하는 자산 유형에 맞춰 볼 수 있어요.

- **퍼널**: 퍼널 설정 변경, 단계 편집, 스플릿 테스트, 삭제를 기록해요.
- **웹사이트**: 페이지, 구조, 콘텐츠의 업데이트를 추적해요.
- **웨비나**: 일정 설정, 편집, 웨비나 구성 변경을 기록해요.
- **스토어**: 스토어 설정과 상품 관리 같은 이커머스 변경을 기록해요.

이렇게 모듈별로 나누어 두어서 자산 유형마다 필요한 기록만 쉽게 볼 수 있어요.

## 기록되는 작업 유형

하이퍼클래스는 현재 지원하는 모듈에서 다음 작업을 기록해요.

- 폴더 삭제
- **폴더로 이동**
- 퍼널 삭제
- 퍼널 설정 변경
- 퍼널 설정 변경(도메인 제거 포함)
- 단계 편집
- 단계 순서 변경
- 단계 삭제
- 단계 변형 복원
- 단계 변형 삭제
- 단계 스플릿 테스트 우승안 선택
- 통계 초기화
- 페이지 편집

로그에는 시간, 사용자 ID, 작업 유형이 들어 있어서 어떤 일이 언제 있었는지 정확히 되짚어 볼 수 있어요.

## 삭제된 페이지 빌더 자산 확인하기

**퍼널**, **웹사이트**, **스토어**, **웨비나**에서 저장해 둔 주요 페이지 빌더 자산을 삭제하면 **감사 로그**에 **삭제됨** 항목이 남아요.

**기록되는 자산**

- 섹션 템플릿
- 글로벌 섹션
- 유니버설 섹션
- 요소 템플릿
- 유니버설 요소 템플릿

**로그에 담기는 정보**

- 자산 이름
- 자산 ID

![삭제된 페이지 빌더 자산이 기록된 감사 로그 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066487214/original/iyLuRdD_Saxb9J5lzzvCxxiwn1_R8C_DFw.png?1773051639)

## 필터와 탐색 팁

필터를 쓰면 원하는 이벤트나 작업을 쉽게 찾을 수 있어요. 모듈마다 필터가 따로 있어요.

다음 기준으로 로그를 필터링할 수 있어요.

- **모듈**: 퍼널, 웹사이트, 웨비나, 스토어
- **작업 유형**: 삭제됨, 업데이트됨, 생성됨 등
- **시간 범위**: 특정 기간의 작업을 볼 수 있어요(최근 60일까지만 가능해요).

탐색 팁이에요.

- 작업 유형 필터로 삭제, 편집, 구조 변경을 찾아보세요.
- 시간 범위로 캠페인을 시작한 시기의 이벤트만 좁혀 보세요.
- 화면 위쪽의 탭이나 아이콘으로 모듈을 빠르게 바꿀 수 있어요.

## 데이터 보관 정책

감사 로그는 최근 60일(롤링 방식) 동안 보관돼요. 그 이후의 기록은 영구 삭제되어 복구할 수 없어요.

{% hint style="warning" %}
- 60일이 지난 로그는 **가져올 수 없어요.**
- 장기간 규정 준수가 필요하다면 주요 작업을 내보내거나 따로 기록해 두세요.
- 로그가 만료되기 전에 확인할 수 있도록 내부 검토 절차를 마련하세요.
{% endhint %}

## 자주 묻는 질문

### 감사 로그를 내보낼 수 있나요?
네. 감사 로그 페이지의 **내보내기** 옵션으로 CSV 파일로 내보낼 수 있어요. 자세한 방법은 [감사 로그 내보내기](../../11-설정/감사-로그/exporting-audit-logs.md)를 참고하세요.

### 로그는 얼마 동안 보관되나요?
로그는 60일 동안 보관된 뒤 시스템에서 자동으로 삭제돼요.

### 사용자별로 로그를 검색할 수 있나요?
네, 사용자 이름으로 필터링할 수 있어요. 위쪽 필터 영역에서 **사용자 선택**을 클릭하세요.

### 삭제한 퍼널이나 단계도 감사 로그에 나오나요?
네, 퍼널 삭제와 단계 삭제를 포함한 삭제 이벤트가 기록돼요.

## 다음 단계

- 로그를 주기적으로 확인해서 디지털 자산의 변경 내역을 살펴보세요.
- 주요 업데이트 뒤에 로그를 검토하는 내부 절차를 만들어 보세요.
- 팀원에게 이 기능을 알려서 책임감을 높이세요.
- 앞으로 감사 추적 범위가 확대되는 소식도 확인해 보세요.
