# 이커머스 스토어 빌더에서 실제 상품 데이터로 미리보기

**실시간 미리보기**를 켜면 스토어를 게시하기 전에 실제 상품 데이터로 테스트할 수 있어요. 빌더 안에서 상품을 둘러보고, 옵션을 고르고, **Add to Cart**(장바구니 담기)를 누르고, 수량을 바꾸고, 지원되는 스토어 페이지를 오가며 확인해 보세요.

샘플 상품 데이터로 돌아가고 싶으면 **실시간 미리보기**를 끄면 돼요. 이 문서에서는 **실시간 미리보기**의 작동 방식, 테스트할 수 있는 항목, 페이지별로 달라지는 미리보기 동작을 안내해요.

## 이커머스 스토어 빌더의 실시간 미리보기란?

**실시간 미리보기**를 쓰면 스토어 빌더에서 이커머스 스토어를 디자인하고 검토하는 동안 실제 상품 데이터를 사용할 수 있어요.

켜 두면 지원되는 스토어 페이지와 상품 요소에 샘플 데이터 대신 실제 상품이 표시돼요. 빌더를 벗어나지 않고도 지원되는 상품, 페이지 이동, 장바구니 동작을 테스트할 수 있어요.

샘플 상품 데이터로 돌아가고 싶을 때는 **실시간 미리보기**를 끄세요.

## 실시간 미리보기의 장점

**실시간 미리보기**를 쓰면 게시하기 전에 실제 고객 경험에 가깝게 스토어를 확인할 수 있어요.

- **실제 상품 데이터:** 내 계정에 등록된 상품으로 스토어를 미리 볼 수 있어요.
- **상품 동작 테스트:** 상품 사이를 이동하고, 옵션을 고르고, 지원되는 **Add to Cart** 동작을 테스트할 수 있어요.
- **장바구니 테스트:** 상품을 담고, 수량을 바꾸고, 항목을 삭제할 수 있어요.
- **페이지 간 미리보기:** 미리보기 장바구니에 담은 상품이 **Cart**(장바구니), **Checkout**(결제), **Thank You**(감사) 페이지까지 이어져요.
- **자유로운 전환:** 디자인하는 중에 실제 상품 데이터와 샘플 상품 데이터를 오가며 볼 수 있어요.

## 사용 전 알아둘 점

**실시간 미리보기**의 동작은 계정에 상품이 있는지, 어떤 스토어 페이지를 편집하는지에 따라 달라져요.

- 계정에 상품이 있으면 **실시간 미리보기**가 기본으로 켜져 있어요.
- 계정에 상품이 없으면 **실시간 미리보기**가 기본으로 꺼져 있고, 샘플 상품이 표시돼요.
- 커스텀 상품 상세정보 페이지에는 **실시간 미리보기** 토글이 없고, 계속 샘플 미리보기 데이터를 사용해요.
- **실시간 미리보기** 안의 **Checkout**은 미리보기 용도로만 쓸 수 있어요.
- 현재 **Checkout** 미리보기에서는 실시간 배송비, 세금, 여러 결제 수단, 실제로 작동하는 결제 입력 필드를 지원하지 않아요.

{% hint style="info" %}
이 문서에 나온 **Checkout** 제한 사항은 스토어 빌더의 **실시간 미리보기**에만 해당해요. 게시된 이커머스 스토어의 결제 동작을 설명하는 내용이 아니에요.
{% endhint %}

## 실시간 미리보기 사용하기

**실시간 미리보기** 토글로 스토어를 검토하면서 실제 상품 데이터와 샘플 상품 데이터를 바꿔 볼 수 있어요.

1. **서브 계정 보기**에서 **사이트**로 이동하세요.
2. **스토어**를 선택하세요.
3. 편집할 이커머스 스토어를 여세요.
4. 검토할 스토어 페이지를 여세요.
5. 스토어 빌더에서 **실시간 미리보기** 토글을 찾으세요.
6. **실시간 미리보기**를 켜서 사용할 수 있는 실제 상품 데이터를 불러오세요.
7. 지원되는 상품, 옵션, 페이지 이동, 장바구니 동작을 테스트하세요.
8. 샘플 상품 데이터로 돌아가려면 **실시간 미리보기**를 끄세요.

## 상품과 스토어 동작 미리보기

**실시간 미리보기**를 쓰면 페이지마다 고정된 샘플 데이터를 보는 대신, 스토어 전체 흐름에서 지원되는 동작을 테스트할 수 있어요.

### 상품 목록 페이지와 상품 상세정보 페이지

상품 목록 페이지와 상품 상세정보 페이지에서 실제 상품이 빌더 안에서 어떻게 보이고 움직이는지 확인해 보세요.

**실시간 미리보기**를 켜면 다음을 할 수 있어요.

- 상품 목록 페이지(PLP)에서 상품 페이지로 이동할 수 있어요.
- 상품 상세정보 페이지(PDP)에서 실제 상품 데이터를 확인할 수 있어요.
- 선택 가능한 상품 옵션을 고를 수 있어요.
- 지원되는 **Add to Cart** 동작을 사용할 수 있어요.
- 지원되는 스토어 페이지 사이를 이동할 수 있어요.

![상품 목록에서 상품 상세정보로 이동하는 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082986800/original/iJauy84vygJsKroIGEjfhonTI153O4O0gg.gif?1791572057)

빌더에서 기본 PDP를 바로 열면 하이퍼클래스가 계정의 실제 상품 중 하나를 무작위로 보여 줘요.

{% hint style="info" %}
커스텀 상품 상세정보 페이지는 계속 샘플 미리보기로 동작하며, **실시간 미리보기** 토글이 없어요.
{% endhint %}

### 상품 위젯

스토어를 미리 보는 동안에도 상품 위젯은 설정해 둔 동작을 그대로 사용해요.

지원되는 위젯은 다음과 같아요.

- **Featured Product**(추천 상품)
- **Featured Products**(추천 상품 목록)
- **업셀**

위젯에 샘플 데이터가 보일지 실제 상품 데이터가 보일지는 **실시간 미리보기**의 켜짐·꺼짐 상태와 위젯에 지정한 상품에 따라 달라요.

### Cart, Checkout, Thank You

미리보기 장바구니는 지원되는 상품 데이터를 스토어 흐름 전체에 이어 줘요. 덕분에 여러 페이지를 실제와 비슷한 내용으로 검토할 수 있어요.

**실시간 미리보기**를 켜면 다음을 할 수 있어요.

- 장바구니에 상품을 담을 수 있어요.
- 수량을 바꿀 수 있어요.
- 항목을 삭제할 수 있어요.
- **Cart** 페이지에서 상품을 확인할 수 있어요.
- 미리보기 장바구니에 담긴 내용을 **Checkout**과 **Thank You** 페이지까지 이어서 볼 수 있어요.

미리보기 장바구니가 비어 있어도 **Checkout**과 **Thank You** 페이지에는 계정의 상품이 한두 개 표시돼요. 그래서 페이지 디자인을 확인할 수 있어요.

**Checkout**은 빌더 안에서 미리보기 용도로만 쓸 수 있어요. 현재 **실시간 미리보기**에는 실시간 배송비, 세금, 여러 결제 수단, 실제로 작동하는 결제 입력 필드가 포함되어 있지 않아요.

![장바구니, 결제, 감사 페이지로 이어지는 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082986935/original/QDwXige9QhkzUCT4rXkNiWYI6whcPhbTgw.gif?1791572232)

## 빌더에서 섹션 다루기

스토어 빌더에서는 편집할 섹션을 선택하는 동작과, 섹션 안의 동작 요소를 누르는 동작이 나뉘어 있어요.

섹션을 처음 클릭하면 편집할 섹션으로 선택돼요.

섹션을 선택한 뒤에는 지원되는 동작 요소가 미리보기에서 실제와 같게 작동해요. 다음 동작이 해당돼요.

- 상품 페이지 이동
- 리디렉션
- **Add to Cart**

이렇게 스토어를 편집하면서, 지원되는 고객 동작도 빌더 안에서 바로 테스트할 수 있어요.

![빌더에서 섹션을 선택한 뒤 동작 요소를 테스트하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082987137/original/ViwUOH86WmWJip2AMNsWH5VLz6Nnj8Rxqw.gif?1791572353)

## 자주 묻는 질문

### 실시간 미리보기를 켜면 어떻게 되나요?
지원되는 스토어 페이지와 상품 요소에 샘플 미리보기 데이터 대신 사용할 수 있는 실제 상품 데이터가 표시돼요.

### 실시간 미리보기가 자동으로 켜지나요?
계정에 상품이 있으면 자동으로 켜져요. 상품이 없으면 기본으로 꺼져 있고 샘플 상품이 표시돼요.

### 샘플 상품 데이터로 다시 바꿀 수 있나요?
네. **실시간 미리보기**를 끄면 돼요. 언제든 끌 수 있어요.

### 커스텀 상품 상세정보 페이지에서도 실시간 미리보기를 쓸 수 있나요?
아니요. 커스텀 PDP는 계속 샘플 미리보기로 동작하고, **실시간 미리보기** 토글이 없어요.

### 기본 상품 상세정보 페이지를 바로 열면 어떤 상품이 보이나요?
**실시간 미리보기**를 켠 상태라면 빌더가 계정의 실제 상품 중 하나를 무작위로 보여 줘요.

### 미리보기 장바구니가 비어 있으면 어떻게 되나요?
**Checkout**과 **Thank You** 페이지에는 계정의 상품이 한두 개 표시돼요. 페이지 디자인을 확인할 수 있어요.

### 실시간 미리보기에서 실제 결제를 끝까지 진행할 수 있나요?
아니요. **실시간 미리보기**의 **Checkout**은 스토어 경험을 검토하는 용도예요. 현재 **실시간 미리보기**에서는 작동하는 결제 입력 필드, 실시간 배송비, 세금, 여러 결제 수단을 지원하지 않아요.
