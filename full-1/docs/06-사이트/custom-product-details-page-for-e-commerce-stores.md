# 이커머스 스토어의 맞춤 상품 상세 페이지

맞춤 상품 상세 페이지(PDP)는 상품 하나하나에 맞춰 브랜드 느낌을 살려 만드는 전용 페이지예요. 이미 익숙한 빌더로 만들고 상품에 연결하면, 기본 상품 상세 페이지 대신 이 페이지가 보여요. 상품 목록 페이지(PLP)나 추천 섹션, 직접 링크에서 들어오는 방문자도 연결해 둔 대로 이동해요. 문제가 생기면 기본 상품 상세 페이지로 안전하게 돌아가요. 이 문서에서는 장점, 설정 방법, 활용 팁을 안내해요.

## 맞춤 상품 상세 페이지란?

맞춤 상품 상세 페이지는 하이퍼클래스의 사이트/스토어 빌더에서 만들어 특정 상품에 연결하는 상품 전용 페이지예요. **하나뿐인 기본 상품 상세 페이지**를 모든 상품에 쓰는 대신, 상품마다 다른 레이아웃과 메시지를 쓸 수 있어요. 스토어 내비게이션은 그대로 유지돼요.

맞춤 상품 상세 페이지가 있는 상품은 방문자가 상품 목록 페이지(PLP), 추천 섹션, 그 밖의 어떤 링크에서 클릭해도 그 맞춤 페이지로 이동해요.

상품 단위로 진열과 브랜드 표현을 더 세밀하게 다룰 수 있어요. 상품마다 고유한 장점, 업셀, 미디어를 보여 주면서도 스토어의 기본 흐름은 그대로 유지돼요.

## 맞춤 상품 상세 페이지의 장점

어떤 상품에 맞춤 페이지가 필요한지 판단할 때 참고하세요.

- **풍부한 스토리텔링:** 상품마다 혜택, 시연, 리뷰, 자주 묻는 질문 같은 콘텐츠를 알맞게 보여 줄 수 있어요.
- **나만의 디자인:** 맞춤 레이아웃, 미디어, 요소로 브랜드와 상품의 개성을 살릴 수 있어요.
- **정확한 이동:** 설정해 두면 상품 목록 페이지(PLP), 추천 섹션, 모든 상품 링크에서 맞춤 페이지로 연결돼요.
- **하나의 연결:** 상품 하나는 한 번에 맞춤 페이지 하나에만 연결돼요. 페이지를 바꾸면 연결도 자동으로 바뀌어요.
- **안전한 복귀:** 맞춤 페이지를 삭제하면 연결돼 있던 상품은 자동으로 기본 상품 상세 페이지로 돌아가요.
- **빠른 운영:** 만들기 창이나 페이지/편집기의 설정에서 상품을 빠르게 지정하고 다시 지정할 수 있어요.

## 맞춤 상품 상세 페이지 설정하기

아이디어를 게시와 테스트까지 이어 가는 순서예요. 설정을 제대로 해 두면 이동 경로나 노출이 예상과 다르게 되는 일을 막을 수 있어요.

```
사전 준비

결제 > 상품에서 만든 상품이 1개 이상 있고, 온라인 스토어에 포함되어 있어야 해요.

서브 계정에서 사이트/스토어 빌더를 사용할 수 있어야 해요.

어느 스토어/사이트를 편집하는지 확인하세요.
```

**설정 순서**

1. **사이트 > 스토어**로 이동해 해당 스토어를 선택한 다음 **새 페이지 추가**를 클릭하세요.

   ![사이트 > 스토어에서 새 페이지 추가를 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053144665/original/llJ4GfBjqkrY2MZ9hLy1-Ufh6W_nponsXA.png?1757032287)

2. **맞춤 상품 상세 페이지 만들기**를 켜세요. 나타나는 창에서 연결할 상품을 검색해 선택하세요.

   새 맞춤 상품 상세 페이지는 기본 상품 상세 페이지(PDP)를 한 번 복사해서 시작해요. 빈 페이지에서 시작하지 않고 기존 레이아웃을 편집할 수 있어요.

   복사되는 디자인에는 다음이 포함돼요.

   - 섹션 구조와 레이아웃
   - 스토어 요소(미디어, 제목, 가격, 옵션, CTA 등)
   - 스타일(글꼴, 색상, 간격, 테두리, 그림자)
   - 노출 규칙(데스크톱/모바일)

   {% hint style="info" %}
   이 복사는 한 번만 이루어져요. 기본 상품 상세 페이지를 나중에 바꿔도 이미 만든 맞춤 페이지에는 반영되지 않아요.
   {% endhint %}

   ![맞춤 상품 상세 페이지를 켜고 상품을 선택하는 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053144668/original/zpMUbxZ8zYJQuQS7-9kkmeVPIVLpLMoUOg.png?1757032318)

3. 상품 상세 페이지 요소(이미지, 상세 정보, CTA, **Related Products**(관련 상품))로 레이아웃을 구성하세요.

   편집기로 전환에 초점을 맞춘 상품 페이지를 만들 수 있어요. 상품 상세 페이지 요소와 전체 텍스트 설정이 그대로 적용되므로, 이미 쓰던 스토어 구성 요소를 맞춤 레이아웃에 함께 쓸 수 있어요.

   ![편집기에서 상품 상세 페이지 레이아웃을 구성하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053146469/original/BD4LdQXsYoSK6CzqiKWsEH3KzeuzKBnbPQ.png?1757040289)

   **디자인 팁**

   - 이미지, 동영상, 특징, 리뷰, **Related Products**(관련 상품)처럼 상품 페이지에 어울리는 요소를 끌어다 놓으세요. 관련 상품 요소는 [이커머스 스토어의 관련 상품 요소](../37-이커머스-스토어/E-Commerce-Store/related-product-element-for-ecommerce-stores.md)와 [상품 상세 페이지에 관련 상품 추천하기](../37-이커머스-스토어/E-Commerce-Store/how-to-suggest-related-product-s-in-your-product-details-page.md) 문서를 참고하세요.
   - **Text Customization**(텍스트 사용자 지정)으로 상품 페이지 요소의 레이블과 문구를 현지화하세요. 자세한 내용은 [이커머스 스토어의 텍스트 사용자 지정](../37-이커머스-스토어/text-customization-in-ecommerce-stores.md) 문서를 참고하세요.
   - **Add to Cart**(장바구니 담기)나 **Buy Now**(바로 구매) 같은 핵심 버튼은 스크롤하지 않아도 보이는 위치에 두세요. 페이지가 길면 CTA를 반복해서 넣으세요.
   - 블록/구성 요소를 상품 페이지 간에 재사용하면 일관성을 유지할 수 있어요.

4. **저장**을 클릭한 다음 **게시**를 클릭하세요.

   미리보기 예시:

   ![게시 전 맞춤 상품 상세 페이지 미리보기 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053146585/original/mPAAgo6go-xmtsKzt4yn13DV_Qw-rUwB8Q.png?1757040891)

## 상품 지정, 다시 지정, 관리하기

상품과 페이지의 연결에 따라 방문자가 도착하는 곳이 정해져요. 처음 연결하는 방법, 나중에 바꾸는 방법, 어떤 상품이 연결돼 있는지 확인하는 방법을 안내해요.

- **페이지를 만들 때:** 지정 창에서 새 맞춤 상품 상세 페이지에 연결할 상품을 선택하세요.

  ![페이지를 만들 때 상품을 지정하는 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053146646/original/KGJ3JqSQgbiH78xAaS-nwmCti7vCc_zlTw.png?1757041252)

- **만든 뒤에 다시 지정할 때:** 빌더에서 맞춤 상품 상세 페이지를 열고 해당 상품 요소나 페이지 설정을 선택하세요. 그런 다음 **설정** 패널에서 **상품 지정**을 바꾸세요.

  ![설정 패널에서 상품 지정을 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053146632/original/R6QcBXtgLnFx6jIYNarXQq8QO4zeDOD6Qw.png?1757041126)

- **하나의 연결 규칙:** 상품을 새 맞춤 상품 상세 페이지에 지정하면 이전 페이지에서는 자동으로 빠져요.
- **상품 목록 페이지(PLP)나 추천 섹션에서 이동할 때:** 상품 목록이나 추천 섹션에서 이동하면 항상 알맞은 상품 상세 페이지(맞춤 또는 기본)로 연결돼요.

## 상품 상세정보 요소의 데스크톱 미디어 설정

**상품 상세정보** 요소에는 데스크톱 미디어 설정이 있어요. 상품 이미지와 상품 정보가 페이지에서 배치되는 방식을 조정해 상품 상세 페이지를 스토어 디자인에 맞출 수 있어요.

**상품 상세정보** 요소에서 다음을 설정할 수 있어요.

- 데스크톱 미디어 너비
- 데스크톱 미디어 위치
- 상품 미디어 레이아웃 옵션

미디어 레이아웃 설정 방법은 상품 페이지의 상품 미디어 레이아웃 문서를 참고하세요.

![상품 상세정보 요소의 데스크톱 미디어 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074497990/original/_EHTL-aR4_sUPqrn4ayhatDoDJDXbMhKqQ.png?1782393722)

## 자주 묻는 질문

### 상품 하나를 맞춤 상품 상세 페이지 여러 개에 지정할 수 있나요?

아니요. 상품 하나는 한 번에 맞춤 상품 상세 페이지 하나에만 연결돼요. 새 맞춤 페이지에 지정하면 이전 연결은 사라져요.

### 맞춤 상품 상세 페이지를 삭제하면 어떻게 되나요?

연결돼 있던 모든 상품이 자동으로 기본 상품 상세 페이지로 돌아가요.

### 상품 목록 페이지(PLP)나 추천 섹션에서 클릭해도 맞춤 페이지로 연결되나요?

네. 맞춤 페이지를 설정해 두었다면 그 페이지로 이동하고, 그렇지 않으면 기본 상품 상세 페이지로 이동해요.

### 상품을 다른 맞춤 상품 상세 페이지로 바꾸려면 어떻게 하나요?

새 페이지를 열고, 지정 창이나 페이지/편집기의 **설정**에서 상품을 지정하세요. 그런 다음 **저장**과 **게시**를 클릭하세요. 이전 연결은 자동으로 사라져요.

### SEO나 기존 상품 링크가 바뀌나요?

맞춤 상품 상세 페이지는 자체 페이지 URL/슬러그를 사용해요. 상품을 연결해 두면 상품 목록 페이지(PLP), 추천 섹션, 링크로 들어온 방문자는 맞춤 페이지로 이동해요.

### 맞춤 상품 상세 페이지에서도 "Related Products"(관련 상품) 같은 요소를 쓸 수 있나요?

네. 상품 상세 페이지에 쓸 수 있는 요소와 **Text Customization**(텍스트 사용자 지정) 설정은 맞춤 페이지 레이아웃에서도 작동해요.

### 새 맞춤 상품 상세 페이지는 빈 페이지에서 시작하나요?

아니요. 현재 기본 상품 상세 페이지를 복사해서 시작하기 때문에, 완성된 레이아웃에서 출발해요.

### 기본 상품 상세 페이지를 나중에 수정하면 맞춤 페이지도 바뀌나요?

아니요. 기본 페이지의 디자인을 가져오는 일은 만들 때 한 번만 일어나요. 기본 페이지와 이미 만든 맞춤 페이지는 실시간으로 동기화되지 않아요.

### 맞춤 상품 상세 페이지를 만들면 기본 상품 상세 페이지가 바뀌나요?

아니요. 맞춤 페이지를 만들어도 기본 상품 상세 페이지는 수정되지 않아요.

### 이미 만들어 둔 맞춤 상품 상세 페이지도 영향을 받나요?

아니요. 기존 맞춤 페이지는 현재 디자인과 설정을 그대로 유지해요.

### ClickFunnels 플로우에서는 "맞춤 상품 상세 페이지 만들기" 옵션이 보이지 않아요.

ClickFunnels 플로우에서는 퍼널 중심의 단순한 사용 환경을 유지하기 위해 이 옵션을 숨겨 두었어요.
