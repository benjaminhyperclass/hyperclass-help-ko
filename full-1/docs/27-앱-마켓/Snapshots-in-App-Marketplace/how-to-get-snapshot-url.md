# 스냅샷 URL 가져오기

앱 마켓플레이스에서 판매할 스냅샷을 앱에 추가하려면 스냅샷 공유 링크가 필요해요. 이 문서에서는 공유 링크를 가져와 앱에 붙여넣는 방법을 안내해요.

1. 에이전시 보기에서 **계정 스냅샷**으로 이동해요. 앱 마켓플레이스에서 판매할 스냅샷을 선택하세요.

   ![계정 스냅샷 목록에서 스냅샷 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032499219/original/nczrNVQdHSDVNWj3uz18pCt-VvF1S2Td9g.png?1725876577)

2. 옵션에서 **스냅샷 공유**를 선택한 다음, 나타나는 항목 중 **Get Marketplace share link**(마켓플레이스 공유 링크 가져오기)를 선택하세요.

   ![스냅샷 공유 옵션에서 마켓플레이스 공유 링크 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032499357/original/fgI7LlW__l4LJ9lBjvoFLkyYzaGg7_Fabg.png?1725876673)

3. 가져온 스냅샷 링크를 앱에 붙여넣고, 스냅샷과 함께 앱을 출시하세요.

   ![앱에 스냅샷 링크 붙여넣기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032499482/original/fdPQHlAlTrfCE9kVxGpx-BQrdg0mZVrkBw.png?1725876732)
