# 앱 마켓플레이스에서 스냅샷 판매하기

**앱 마켓플레이스**(App Marketplace)에 스냅샷을 올려 다른 에이전시에 판매하는 방법을 안내해요. 에이전시 관리자는 이 기능으로 자신의 노하우를 수익으로 바꿀 수 있고, 스냅샷 제작자는 앱을 더 간단하게 만들 수 있어요.

[동영상](https://www.youtube.com/embed/jOPz7hAByMU?&wmode=opaque)

## 스냅샷용 앱 마켓플레이스란?

앱 마켓플레이스에서는 에이전시 관리자가 CRM 노하우를 수익화하고, 자신의 설정을 확장 가능한 상품으로 묶어 판매할 수 있어요. 에이전시 관리자는 다음을 할 수 있어요.

1. 스냅샷을 다른 하이퍼클래스 에이전시에 판매해요.
2. 일회성 결제, 월 구독, 연 구독 등 다양한 가격 모델을 사용해요.
3. IP 보호로 스냅샷 자산을 무단 재판매로부터 지켜요.

![앱 마켓플레이스에서 스냅샷을 판매하는 구조](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036369989/original/jqoDZmocTlUmapJynuPEo-rOlQAgZ4D2BQ.jpeg?1731353995)

## 하이퍼클래스에서 스냅샷을 판매하면 좋은 점

1. 전문성을 수익으로 바꿔요: CRM 설정을 다른 에이전시가 살 수 있는 상품으로 만들 수 있어요.
2. 더 많은 고객에게 알려요: 하이퍼클래스 앱 마켓플레이스에서 많은 고객에게 내 스냅샷을 보여 줄 수 있어요.
3. 자산을 안전하게 지켜요: IP 보호가 지식재산권을 무단 사용으로부터 보호해 줘요.

## 앱 마켓플레이스에서 스냅샷 판매하는 방법

[동영상](https://www.loom.com/embed/f6f296b24e83446799bb1b189bc7267d?sid=db39e95c-fd44-4234-88e8-082af4e70bff)

```
간소화된 스냅샷 등록 흐름 (마켓플레이스에서 판매)

에이전시 화면의 계정 스냅샷에서 "마켓플레이스에서 판매"를 선택하면 하이퍼클래스가 스냅샷 등록 과정을 바로 시작해요. Developer Portal의 스냅샷 등록 모듈로 곧장 이동해요.

이 모듈에서는 등록 흐름 초반에 스냅샷에 포함된 자산을 먼저 확인하고 다음으로 넘어갈 수 있어요. 스냅샷 전용 등록 경로를 사용하기 때문에 불필요한 단계와 화면도 줄어들어요.
```

### 1단계: Developer Portal 가입하기

- **Developer Portal**(개발자 포털)에 가입하고 가입 양식을 작성해요. 접속 주소는 하이퍼클래스 고객지원에 문의하세요.
- **이메일 인증**을 마치면 Developer Portal을 사용할 수 있어요.

```
Developer Portal을 처음 사용한다면 등록 중에 안내되는 설정 단계를 위 내용대로 완료하세요. 이미 판매 경험이 있는 판매자는 "마켓플레이스에서 판매"를 선택한 뒤 스냅샷 등록 모듈로 바로 이동할 수 있어요.
```

### 2단계: 앱 만들기

1. Developer Portal에 로그인한 뒤 **My Apps**(내 앱)로 이동해요.
2. **Create an App**(앱 만들기)을 클릭해요.
3. 앱을 설정해요.
   - **이름**: 앱을 알기 쉽게 설명하는 이름을 입력해요.
   - **앱 유형**: **Public**(공개)으로 설정해요.
   - **배분 유형**: 다음 중에서 선택해요.
   - **에이전시**: 에이전시에 직접 요금을 청구해요.
   - **서브 계정**: 스냅샷을 푸시할 때마다 서브 계정에 요금을 청구해요.
   - **목록 유형**: **표준** 또는 **화이트 라벨** 중에서 선택해요. 더 많은 고객에게 알리려면 **화이트 라벨**을 권장해요.

### 3단계: 앱 상세 정보 입력하기

- 앱의 로고, 한 줄 소개, 설명을 추가해요.
- 회사 이름과 웹사이트를 입력해 구매자에게 신뢰를 줘요.
- 미리보기 이미지나 데모 영상을 올려 앱의 가치를 보여 줘요.
- 구매자가 필요할 때 연락할 수 있도록 고객 지원 정보를 넣어요.

### 4단계: 가격 설정하기

- 앱을 무료로 할지 유료로 할지 정해요.
  - **무료**: 구매자에게 비용이 들지 않아요.
  - **프리미엄**: 무료로 쓸 수 있고, 프리미엄 기능은 유료로 제공해요.
  - **유료**: 일회성 요금, 월 구독, 연 구독 중에서 선택해 청구해요.
- 요금제 이름과 포함 내용을 정해요.

### 5단계: 스냅샷 추가하기

1. 하이퍼클래스 에이전시 계정에서 판매할 스냅샷을 선택해요.
2. 안내 창에서 **앱 이름**을 입력해요.
3. 미리 채워진 스냅샷 등록 설정을 확인해요. 스냅샷에 맞게 자동으로 설정돼요.
4. 안내 창에 표시된 마켓플레이스 링크를 복사해요. 이 링크로 바로 내 등록 상품을 공유할 수 있어요.
5. **마켓플레이스에서 판매**를 선택하면 Developer Portal의 스냅샷 등록 모듈로 이동해요.
6. 등록 흐름 초반에 스냅샷에 담긴 자산을 확인해요. 구매자가 무엇을 받게 되는지 미리 점검할 수 있어요.
7. 스냅샷 전용 등록 단계를 따라 진행해 게시해요. 화면 이동이 적어요.

![스냅샷 추가 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064695562/original/9z0vqjGO0IlvA3K7wQutrK1TE4ljU_ty_w.gif?1770819611)

### 6단계: 검토 제출하기

1. Developer Portal의 **Basic Info**(기본 정보) 페이지로 돌아가요.
2. 필요한 설정이 모두 끝났는지 확인해요.
3. **검토 제출**을 클릭해요. 하이퍼클래스 팀이 7~10일 이내에 앱의 화이트 라벨 호환 여부를 검토해요.

## 지식재산권(IP) 보호

**Get Marketplace Share Link**(마켓플레이스 공유 링크 받기)를 켜면 IP 보호가 자동으로 적용돼요. 그러면 다음과 같이 보호돼요.

1. 구매자는 내 스냅샷 자산을 다시 패키징하거나 재판매할 수 없어요.
2. 내 스냅샷은 원래 제작자만 독점적으로 갖게 돼요.

## 자주 묻는 질문

### 앱 하나에 스냅샷을 여러 개 등록할 수 있나요?

현재는 앱 하나에 스냅샷을 1개만 넣을 수 있어요. 스냅샷의 자산이 앱의 가치와 잘 맞는지 확인하세요.

### 화이트 라벨과 표준 목록 유형은 어떻게 다른가요?

- **화이트 라벨**: 브랜딩을 없애서 다양한 하이퍼클래스 고객에게 더 매력적인 앱이 돼요.
- **표준**: 브랜딩이 그대로 보여서 노출 범위가 제한될 수 있어요.

### 앱 제출이 반려되면 어떻게 하나요?

승인되지 않으면 하이퍼클래스 팀이 수정할 내용을 피드백으로 알려 줘요. 그 내용대로 앱을 고친 뒤 다시 제출하세요.

### 게시한 뒤에도 앱을 수정할 수 있나요?

아니요. 현재는 앱을 게시한 뒤에 스냅샷 링크를 수정할 수 없어요. 앱 업데이트 기능은 2025년 1분기에 출시될 예정이에요.
<!-- 검토 필요: 출시 예정 시점(2025년 1분기)이 이미 지났을 수 있음 -->

### 만들 수 있는 앱 개수에 제한이 있나요?

아니요. 앱 마켓플레이스에서 만들어 판매할 수 있는 앱 개수에는 제한이 없어요.

### 구매자는 스냅샷을 구매한 뒤 어떻게 사용하나요?

구매하면 구매자가 하이퍼클래스 대시보드에서 자신의 서브 계정으로 스냅샷을 바로 푸시할 수 있어요.

### 스냅샷마다 다른 가격 모델을 설정할 수 있나요?

현재는 가격 모델을 앱 단위로 설정해요. 스냅샷마다 가격을 다르게 하려면 앱을 따로 만들어야 해요.
