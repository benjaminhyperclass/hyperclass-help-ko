# API 보안: 마켓플레이스 앱 OAuth 동의 화면

마켓플레이스 앱을 설치할 때 보이는 새 OAuth 설치 화면을 설명하는 문서예요. 앱을 승인하기 전에 앱 소개와 요청하는 권한을 한눈에 볼 수 있어요. 비공개 앱이 사용자 생성·편집처럼 민감한 권한을 요청하면 경고도 함께 표시돼요.

## OAuth란 무엇인가요?

OAuth는 외부 앱이 하이퍼클래스 계정의 일부 영역에 접근하도록 허락받는 안전한 승인 방식이에요. 마켓플레이스에 등록된 앱이나 외부에서 연동하는 앱은 OAuth 링크로 설치를 시작해요. 그 뒤 연락처, 캘린더, 대화, 워크플로우 같은 데이터를 읽거나 수정할 권한을 받아요.

이전에는 OAuth 링크를 누르면 어떤 권한을 허용하는지 알 수 없는 채로 이동했어요. 이제는 요청하는 권한을 모두 보여 주기 때문에, 내용을 확인한 뒤 진행할지 결정할 수 있어요.

## 새 OAuth 화면의 장점

앱을 설치할 때 어떤 권한을 요청하는지 훤히 보여서, 무단 접근 위험을 줄이고 연동에 대한 신뢰를 높일 수 있어요.

- 설치를 확인하기 전에 앱 이름과 로고를 보여 줘요.
- 요청하는 권한(스코프)을 모두 나열해요.
- 각 권한으로 무엇을 할 수 있는지 알려 줘요.
- `users: write`처럼 민감한 권한에는 경고를 표시해요.
- 일반 마켓플레이스 링크와 그레이 라벨 마켓플레이스 링크 모두에서 똑같이 동작해요.
- 권한을 허용하기 전에 충분히 판단할 수 있어요.

## 달라진 OAuth 흐름

제3자 앱에 접근을 허용하기 전에 무엇을 승인하는지 정확히 확인하세요. 앱의 연동 페이지에서 OAuth 설치 링크를 누르면 새로 바뀐 확인 화면이 나타나요. 이 화면에는 다음 내용이 들어 있어요.

1. 앱 이름과 브랜딩
2. 요청하는 OAuth 스코프 전체 목록
3. 각 스코프가 필요한 이유에 대한 설명
4. 민감하거나 위험도가 높은 접근 요청에 대한 경고

## 그레이 라벨 OAuth 페이지

화이트라벨로 운영하는 마켓플레이스 설치에서도 권한 내용을 똑같이 확인할 수 있어요. 새 OAuth 화면은 아래와 같은 그레이 라벨 마켓플레이스 주소에서도 쓸 수 있어요.

```
https://marketplace.leadconnectorhq.com/oauth/chooselocation
```

하이퍼클래스 기본 도메인에서 설치하든 화이트라벨 도메인에서 설치하든, 권한 목록과 보안 경고는 똑같이 표시돼요.

## 앱 권한과 경고 이해하기

각 스코프가 무슨 뜻인지, 언제 조심해야 하는지 알아 두세요. OAuth 스코프는 앱이 어떤 종류의 접근을 요청하는지 나타내요. 예를 들면 다음과 같아요.

- **연락처**: readonly: 연락처 목록을 볼 수 있어요.
- **대화**: write: 회원님을 대신해 메시지를 보낼 수 있어요.
- **위치**: readonly: 계정의 위치 세부 정보를 볼 수 있어요.

`users: write`처럼 민감한 스코프를 요청하면 진행하기 전에 눈에 띄는 경고가 나타나요. `users: write`는 팀원 권한을 바꾸거나 새 사용자를 만들 수 있는 권한이에요.

이 경고는 깊은 수준의 접근을 요청하는 앱을 알려 줘요. 그래서 신중하게 판단해서 결정할 수 있어요.

## 앱 접근을 승인할 때 지켜야 할 것

제3자 앱을 쓰면서 데이터를 지키려면 다음 방법을 따르세요.

- 스코프를 꼼꼼히 확인하세요. 내용을 보지 않고 승인하지 마세요.
- 신뢰할 수 있는 개발자나 검증된 파트너의 앱만 승인하세요.
- 필요한 것보다 많은 접근을 요청하는 앱은 피하세요.
- 연결된 앱을 하이퍼클래스 설정에서 정기적으로 확인하세요.
- 사용하지 않거나 의심스러운 앱은 액세스를 취소하세요.

앱 접근을 관리하려면 하이퍼클래스 대시보드에서 **설정 > Connected Apps**(연결된 앱)로 이동하세요.

## 자주 묻는 질문

### OAuth 화면에서 접근을 거부하면 어떻게 되나요?
앱이 설치되거나 연결되지 않아요. 승인하기 전에는 어떤 데이터도 공유되지 않아요.

### OAuth의 '스코프'가 무엇인가요?
스코프는 앱이 접근할 수 있는 데이터나 기능의 범위예요. 제3자 앱이 계정에서 할 수 있는 일을 제어하고 제한하는 데 쓰여요.

### 민감한 스코프인지 어떻게 알 수 있나요?
`users: write`나 `locations: write` 같은 스코프를 요청하면 OAuth 화면에 별도의 경고가 표시돼요.

### 이미 설치한 앱에도 영향이 있나요?
아니요. 이 기능은 새로 설치하는 앱이나, 기존 앱을 OAuth로 다시 승인할 때만 적용돼요.

### 제가 만든 비공개 앱에도 이 화면을 쓸 수 있나요?
네. OAuth를 사용하는 비공개 앱도 새 페이지를 거치며, 똑같은 권한 정보가 표시돼요.

## 다음 단계

- 현재 연동된 앱 점검하기: **설정 > Connected Apps**(연결된 앱)로 이동하세요.
- 팀원 교육하기: 모든 사용자가 OAuth 권한 내용을 읽는 방법을 이해하도록 안내하세요.
- 앱 문서 업데이트하기: 개발자라면 앱이 무엇에 접근하고 왜 필요한지 분명하게 설명하세요.
- 그레이 라벨 링크 사용하기: 브랜드를 적용한 설치에는 `https://marketplace.leadconnectorhq.com/oauth/chooselocation` 주소를 쓰세요.
