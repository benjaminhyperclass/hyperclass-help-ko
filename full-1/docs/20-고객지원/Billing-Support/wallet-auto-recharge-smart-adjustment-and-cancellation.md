# 지갑 자동 충전과 스마트 조정 설정

지갑 잔액이 부족하면 SMS, 이메일, 전화처럼 지갑 잔액으로 쓰는 서비스가 중단될 수 있어요. 이 문서에서는 잔액이 기준 아래로 내려가면 자동으로 충전하는 자동 충전과, 충전이 자주 일어날 때 충전 금액을 올려 주는 스마트 조정을 설명해요. 설정 방법과 바꾸거나 끌 수 있는 항목도 함께 안내해요. 에이전시 계정에서 설정하는 기능이에요.

## 지갑 자동 충전과 스마트 조정이란?

자동 충전과 스마트 조정은 함께 에이전시 지갑에 충분한 잔액을 유지해 줘요. 자동 충전은 잔액을 언제 채울지 정해요. 스마트 조정은 필요할 때 충전 금액을 올려서 충전 횟수를 줄여 줘요.

자동 충전은 지갑 잔액이 설정한 기준 아래로 내려가면 에이전시 지갑에 금액을 채워요.

스마트 조정은 설정 메뉴에서 **자동 업데이트**(Auto-update)로 표시돼요. 같은 충전 금액이 얼마나 자주 실행되는지 살펴보다가, 7일 안에 3번을 넘기면 이후 충전부터 금액을 다음 충전 단계로 자동으로 올려요.

{% hint style="warning" %}
지갑 자동 충전은 끌 수 없어요. 하이퍼클래스가 충전 금액을 자동으로 올리는 게 싫다면 스마트 조정(자동 업데이트)만 끌 수 있어요. 스마트 조정을 꺼도 자동 충전은 꺼지지 않아요.
{% endhint %}

## 자동 충전과 스마트 조정을 쓰면 좋은 점

지갑 잔액이 충분하면 에이전시와 서브 계정이 쓰는 사용량 기반 하이퍼클래스 서비스가 중단될 위험이 줄어요.

- 서비스 중단 감소: SMS, 이메일, 전화 등 지갑 잔액으로 쓰는 서비스의 잔액을 유지하는 데 도움이 돼요.
- 자동 지갑 충전: 에이전시 지갑 잔액을 직접 확인하고 채우는 수고가 줄어요.
- 충전 횟수 감소: 자동 충전이 자주 일어나면 스마트 조정이 충전 금액을 올려 줘요.
- 충전 설정 조정: 에이전시 사용량에 맞는 충전 금액과 기준 잔액을 고를 수 있어요.
- 스마트 조정 제어: 충전 금액이 자동으로 올라가는 게 싫다면 자동 업데이트를 끌 수 있어요.

## 자동 충전

자동 충전은 두 가지 설정으로 얼마를 채울지, 언제 충전할지 정해요.

- 충전 금액: 자동 충전이 실행될 때마다 에이전시 결제 수단으로 결제되고 지갑에 채워지는 금액이에요.
- 기준 잔액: 지갑 잔액이 이 금액 아래로 내려가면 자동 충전이 실행돼요.

![자동 충전 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078267601/original/qrf_HLjWpHAH7XVfIUdxrRE2_4gOOuIeog.png?1786551336)

예를 들어 충전 금액이 50달러이고 기준 잔액이 25달러라면, 지갑 잔액이 25달러 아래로 내려갈 때 자동 충전이 실행돼요. 그러면 하이퍼클래스가 저장된 에이전시 결제 수단으로 50달러를 결제해 지갑에 채워요.

기준 잔액이 높을수록 자동 충전이 더 일찍 실행돼요. 지갑 사용량이 많은 에이전시라면 기준 잔액을 높게 잡는 게 좋아요. 추가 금액이 들어오기 전에 사용 가능한 잔액이 너무 낮아질 위험을 줄일 수 있어요.

## 스마트 조정

스마트 조정은 현재 충전 금액이 자주 실행될 때 자동 충전 금액을 자동으로 올려서, 지갑 충전이 잦아지는 것을 줄여 줘요.

같은 충전 금액이 7일 안에 3번을 넘게 실행되면, 하이퍼클래스는 지금 사용량에 비해 그 금액이 너무 적다고 판단해요. 그리고 이후 충전부터 금액을 다음 충전 단계로 자동으로 올려요.

![스마트 조정 설명 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078267687/original/1zsAl4dJlKfKHdSI5dGqIW1pM8DTJKSTVQ.png?1786551396)

예를 들어 현재 충전 금액이 200달러인데 7일 안에 3번을 넘게 실행되면, 스마트 조정이 충전 금액을 다음 단계인 500달러 등으로 올릴 수 있어요. 이후 자동 충전은 바뀐 금액으로 실행돼요.

스마트 조정을 끄면 이렇게 금액이 자동으로 올라가지 않아요. 단, 지갑 자동 충전은 꺼지지 않아요.

## 자동 충전 설정하기

충전 금액과 기준 잔액을 정하면 에이전시 지갑에 한 번에 얼마를 채울지, 잔액이 얼마까지 내려가면 자동 충전할지 직접 정할 수 있어요.

1. 에이전시 계정에 로그인한 뒤 **설정**을 클릭하세요.

   ![설정 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078268108/original/W0uLM9NEsPrA9xAZKASK0UbCjfGKmqy0Vw.png?1786551578)
2. **청구/결제**를 클릭한 다음 **지갑 및 거래 내역** 탭을 선택하세요.

   ![지갑 및 거래 내역 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078268137/original/IRU0Ecn0HXWi14OdDfuTlIHLd7NZsBIp_Q.png?1786551611)
3. 지갑 잔액 아래에서 **Auto Recharge**(자동 충전) 설정을 찾으세요.
4. **자동 충전 카드** 드롭다운에서 자동 충전이 실행될 때마다 하이퍼클래스가 채울 금액을 선택하세요.
5. **when balance is lower than**(잔액이 다음보다 낮을 때) 드롭다운에서 자동 충전을 실행할 기준 잔액을 선택하세요.

   ![충전 금액과 기준 잔액 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078268176/original/YdRJ4HtW-ZCvtlO39_RNp8UiseUYnWeefQ.gif?1786551641)

바꾼 설정은 이후 자동 충전의 충전 금액과 실행 시점에 적용돼요.

## 스마트 조정(자동 업데이트) 끄기

하이퍼클래스가 충전 빈도를 보고 충전 금액을 자동으로 올리지 않게 하려면 스마트 조정을 끄세요.

{% hint style="warning" %}
스마트 조정을 꺼도 에이전시 지갑 자동 충전은 꺼지지 않아요. 잔액이 설정한 기준 아래로 내려가면 지갑은 계속 충전돼요.
{% endhint %}

1. **설정 > 청구/결제 > 지갑 및 거래 내역**에서 자동 충전 설정을 찾아 오른쪽의 점 세 개 메뉴를 클릭하세요.

   ![점 세 개 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078268259/original/Vw5wVZ4eGuw6mIpN9XbUKNtz1GM1T5vasw.png?1786551681)
2. **자동 업데이트 비활성화**를 클릭하세요.

   ![자동 업데이트 비활성화 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078268301/original/AxlPlWOm5FqOovgj_Px40IxdPHEZlqR2fA.png?1786551696)
3. 확인 창에서 **예**를 클릭하세요.

   ![확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078268353/original/_1dztRdcDUioViVs2y9ZvBKI2Tl70_Me9A.png?1786551730)

이제 스마트 조정이 충전 금액을 자동으로 올리지 않아요. 자동 충전은 설정해 둔 충전 설정대로 계속 켜져 있어요.

## 자주 묻는 질문

### 자동 충전과 사용 요금은 같은 건가요?

아니요. 자동 충전은 선불 금액을 에이전시 지갑에 채우는 거예요. 이후 해당되는 사용량 기반 서비스를 쓰면 지갑의 사용 가능한 잔액에서 요금이 차감돼요.

### 에이전시 지갑으로 하이퍼클래스 기본 구독료를 내나요?

아니요. 에이전시 지갑은 해당되는 사용량 기반 서비스와 지갑 관련 요금에 쓰여요. 에이전시의 기본 하이퍼클래스 구독료는 지갑으로 결제되지 않아요.

### 에이전시 지갑이 자주 충전돼요. 왜 그런가요?

지갑 잔액으로 쓰는 서비스가 현재 충전 금액과 기준 잔액에 비해 잔액을 빠르게 쓰고 있다는 뜻인 경우가 많아요. **설정 > 청구/결제 > 지갑 및 거래 내역**에서 지갑 지출이 어디서 일어나는지 확인해 보세요. 스마트 조정이 켜져 있다면, 같은 금액이 7일 안에 3번을 넘게 실행될 때 하이퍼클래스가 충전 금액을 올릴 수도 있어요.

### 어떤 서비스가 지갑 잔액을 쓰고 있는지 어디서 확인하나요?

**설정 > 청구/결제 > 지갑 및 거래 내역**으로 이동하세요. **Summary**(요약)와 **상세 거래 내역** 보기에서 지갑 지출을 확인하고, 상품별·서브 계정별 사용량을 파악할 수 있어요.

### 이전 지갑 충전 내역은 어디서 확인하나요?

월별 지갑 충전 영수증에서 자동 충전을 포함한 지갑 충전 거래 내역을 볼 수 있어요. 이 영수증은 **청구 대시보드**에서 확인할 수 있고, 내역 대조와 기록 보관에 쓸 수 있어요.

### 자동 충전은 그대로 두고 스마트 조정만 끌 수 있나요?

네. **자동 업데이트 비활성화**를 사용하면 스마트 조정이 충전 금액을 자동으로 올리지 않아요. 지갑 자동 충전은 계속 켜져 있어요.
