# 통합 재판매 화면에서 구독·사용량·마켓플레이스 상품 한곳에서 관리하기

통합 재판매 화면은 구독 기반 상품, 사용량 기반 상품, 마켓플레이스 재판매를 한 페이지에 모아 놓은 화면이에요. 에이전시 관리자는 재판매와 재청구 화면을 오가지 않고도 재판매할 상품을 찾고, 설정하고, 관리할 수 있어요. 가격 설정, 마크업 적용, 서브 계정별 접근 관리를 모두 같은 화면에서 할 수 있어서 고객사 수익화를 넓혀 가기 편해요.

## 이 문서에서 배울 내용

통합 재판매 화면이 구독 기반 상품, 사용량 기반 상품, 마켓플레이스 재판매를 한곳에 모아 주는 방식을 설명해요. 더 이상 여러 페이지를 오갈 필요가 없어요.

이 문서에서는 다음 내용을 다뤄요.

- 글로벌 마크업 설정하기
- 서브 계정 단위로 상품 관리하기
- 일괄 작업으로 한꺼번에 변경하기
- 기존 설정이 자동으로 옮겨지는 방식

{% hint style="info" %}
**실험실 기능이에요.** 통합 재판매 화면은 현재 **실험실**(Labs)에서 쓸 수 있어요. 에이전시 대시보드에서 기능을 켜고 직접 써 본 뒤 의견을 남겨 주세요. 에이전시 관리자만 쓸 수 있어요.
{% endhint %}

## 통합 재판매 화면이란?

통합 재판매 화면은 에이전시가 고객에게 재판매하는 상품과 서비스를 관리하는, 새로워진 **재판매**(Reselling) 페이지예요. 예전에는 구독 재판매와 사용량 기반 재청구가 서로 다른 곳에 있었어요. 이제는 탭, 상품 분류, 설정 옵션이 더 명확해진 한 페이지에서 재판매 상품을 관리해요.

이 화면은 크게 세 영역으로 나뉘어요.

- **구독**: 구독 기반 상품을 관리하고, 고객에게 보이는 구독 가격을 정해요.
- **사용량**: 사용량 기반 상품을 관리하고, 사용량 마크업을 설정해요.
- **마켓플레이스**: 해당하는 경우 마켓플레이스 앱 재판매를 관리해요.

**재청구**(Rebilling)는 **사용량 기반 재판매**(Usage-based Reselling)로 이름이 바뀌었어요. 에이전시가 사용량 기반 상품 요금을 고객에게 청구하는 방식을 더 잘 나타내는 이름이에요. 이름만 바뀐 것이고, 기존 상품의 청구 방식이나 이미 설정해 둔 상품의 동작에는 영향이 없어요.

![통합 재판매 페이지 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077680785/original/q-eahGayPwhjwgOF4g1qmqZG5gYQnZGEQg.jpeg?1785926664)

## 주요 장점

재판매 페이지가 하나로 합쳐지면 설정 시간이 줄고, 헷갈리는 일이 줄고, 수익 기회를 더 일관되게 관리할 수 있어요. 여러 서브 계정에 하이퍼클래스 상품을 여러 개 판매하는 에이전시에 특히 도움이 돼요.

- 한곳에서 관리: 구독 기반, 사용량 기반, 마켓플레이스 재판매를 한 페이지에서 관리해요.
- 명확한 상품 분류: 상품이 청구 방식별로 묶여 있어서 지금 무엇을 설정하는지 알기 쉬워요.
- 빠른 상품 찾기: 검색, 그룹, 상품 섹션으로 재판매 상품을 더 빨리 찾을 수 있어요.
- 글로벌 사용량 마크업: 로케이션마다 일일이 설정하지 않고, 에이전시 단위로 기본 사용량 마크업을 정해요.
- 서브 계정 단위 제어: 필요할 때 특정 서브 계정에만 상품, 사용량 재판매, 마크업을 켤 수 있어요.
- 반복 설정 감소: 기존 설정이 자동으로 옮겨져서 다시 만들 필요가 줄어요.
- 더 쉬운 용어: 재청구가 사용량 기반 재판매로 바뀌어 이해하기 쉬워졌어요.

## 재판매 페이지의 탭

재판매 페이지는 탭으로 나뉘어 있어서 지금 어떤 종류의 상품을 설정하는지 바로 알 수 있어요. 탭마다 재판매 방식이 다르고, 구독 가격과 사용량 기반 마크업이 서로 구분돼요.

- **구독**: 구독 기반 애드온과 고객에게 보이는 가격을 설정해요.
- **사용량**: 사용량 기반 상품, 글로벌 마크업, 서브 계정별 사용량 재판매를 설정해요.
- **마켓플레이스**: 지원되는 마켓플레이스 상품의 재판매 옵션을 관리해요.

재판매 페이지 위쪽의 탭을 눌러 상품 유형을 오가세요. 재판매 화면을 벗어나지 않아도 돼요.

## 구독 기반 재판매

구독 기반 재판매를 쓰면 지원되는 상품을 정기 구독 가격으로 고객에게 제공할 수 있어요. 서브 계정에 상품을 켜기 전에 고객에게 보이는 가격을 정하고, 에이전시 원가를 확인하고, 실현 수익을 살펴볼 수 있어요.

구독 기반 상품 설정에는 다음 항목이 포함될 수 있어요.

- 에이전시 구독 가격
- 고객에게 보이는 가격
- 실현 수익
- 기능 활성화
- 서브 계정별 관리
- 상품별 작업

**구독** 탭에서 설정할 상품을 고르고 고객에게 보일 가격을 입력하세요. 그다음 **관리** 옵션으로 어떤 서브 계정이 그 상품을 쓸 수 있는지 정해요.

![구독 탭의 상품 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077677334/original/2xX0gbqz0BhgH87vxkFtAaPs0YoM9QW-lw.png?1785924624)

## 사용량 기반 재판매

**사용량 기반 재판매**(Usage-based Reselling)는 재청구의 새 이름이에요. 월렛으로 결제되는 지원 서비스처럼, 실제 사용량에 따라 고객에게 요금을 청구하는 상품에 적용돼요. 사용량 마크업을 설정하면 기본 원가에 에이전시가 원하는 마진을 얹어서 고객에게 청구할 수 있어요.

사용량 기반 상품에는 다음 설정이 있을 수 있어요.

- 사용량 기반 마크업
- 에이전시에 청구되는 기본 요율
- 글로벌 마크업 제어
- 서브 계정 관리
- 사용량 재판매 활성화
- 상품별 마크업 범위

**사용량** 탭에서 도메인 구매, 이메일, 전화 시스템 등 사용량 기반 서비스의 마크업을 설정해요. 상품마다 기본 요율이 표시되고, 마크업 비율을 입력하면 고객에게 청구되는 최종 금액이 정해져요.

![사용량 탭의 마크업 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077677659/original/7vma6noW8yrFl6XhbnLcW9Ddtl5c0UKOKQ.png?1785924818)

## 글로벌 사용량 기반 마크업

글로벌 사용량 기반 마크업은 에이전시 단위로 사용량 기반 상품의 기본 마크업을 정하는 기능이에요. 새로 만든 SaaS 로케이션과, **SaaS Mode**(SaaS 모드)가 켜진 기존 로케이션에 기본 마크업이 적용돼서 수작업이 줄어요.

글로벌 마크업을 쓰면 여러 로케이션의 사용량 기반 가격을 통일하면서도, 필요한 곳은 서브 계정 단위로 따로 관리할 수 있어요. 전화, 이메일, 도메인 같은 사용량 기반 서비스에서 마진을 일정하게 맞추고 싶을 때 유용해요.

{% hint style="warning" %}
재판매 페이지에서 조정한 값은 SaaS 요금제나 수동 설정으로 정해 둔 가격을 대신하지 않아요. 이미 SaaS 요금제나 수동 설정으로 가격을 관리하고 있다면, 변경하기 전에 그 설정을 먼저 확인하세요.
{% endhint %}

글로벌 마크업을 설정하면 하이퍼클래스는 그 비율을 모든 사용량 기반 상품의 기준으로 써요. 로케이션 단위로 따로 바꾸면 그 값이 우선해요. 에이전시 전체의 가격을 일관되게 유지하면서, 필요할 때 특정 고객만 마크업을 조정할 수 있어요.

## 서브 계정 단위 상품 관리

서브 계정 단위로 관리하면 어떤 고객이 어떤 재판매 상품을 쓸 수 있는지, 로케이션별로 사용량 재판매를 켤지 정할 수 있어요. 고객마다 필요한 상품, 가격, 마크업 규칙이 다를 때 유용해요.

상품 관리 화면에서는 다음 작업을 할 수 있어요.

- 특정 서브 계정 검색
- 상품 기능 켜기·끄기
- 사용량 재판매 켜기·끄기
- 사용량 마크업 확인·수정
- 페이지 이동으로 많은 계정 목록 확인
- 선택한 서브 계정에 일괄 작업 적용

서브 계정 단위 관리 화면을 열려면 **구독** 탭이나 **사용량** 탭에서 상품 옆의 **관리** 버튼을 누르세요. 서브 계정 관리 화면이 열리고, 로케이션별로 상품 사용 여부와 설정을 정할 수 있어요.

## 재판매 상품 일괄 작업

**일괄 작업**을 쓰면 여러 서브 계정에 상품과 마크업 변경을 한 번에 적용할 수 있어요. 사용량 기반 상품을 많은 SaaS 로케이션에 한꺼번에 열거나, 선택한 계정의 마크업 설정을 통일할 때 유용해요.

일괄 작업을 쓸 때는 변경을 적용하기 전에 확인 창을 꼼꼼히 살펴보세요. 일괄 업데이트는 선택한 서브 계정의 기능 설정과 현재 활동에 영향을 줄 수 있어요. 서브 계정이 많으면 변경 사항이 반영되는 데 몇 분이 걸릴 수 있어요.

{% hint style="warning" %}
진행하기 전에 일괄 작업 확인 창을 항상 확인하세요. 일괄 변경은 선택한 모든 서브 계정에 적용되고, 대상 로케이션 수에 따라 처리에 시간이 걸릴 수 있어요.
{% endhint %}

일괄 작업은 다음 순서로 해요.

1. 관리 표에서 서브 계정을 여러 개 선택해요.
2. **일괄 작업** 버튼을 눌러요.
3. 열린 창에서 원하는 설정을 지정해요.
4. 변경 내용을 확인해요.

![일괄 작업 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077680191/original/OaYWylgCESzC8WEpTII6_2vPQjL5IdqT5A.png?1785926326)

## 기존 재판매·재청구 설정

기존 설정은 통합 재판매 화면으로 자동으로 옮겨져요. 이번 업데이트 때문에 기존 구독 재판매나 사용량 기반 재청구 설정을 다시 만들 필요는 없어요.

**재청구**에서 **사용량 기반 재판매**로 바뀐 것은 용어 변경일 뿐이에요. 기존 상품의 청구 방식, 기존 마크업의 동작, 이미 설정한 상품의 동작은 그대로예요.

## 통합 재판매 설정하기

설정을 제대로 해 두면 한 페이지에서 재판매 상품을 관리하고 가격과 마크업을 일관되게 적용할 수 있어요. 변경하기 전에 기존 SaaS 요금제 가격, 수동 설정, 상품별 설정을 먼저 확인하세요.

1. 하이퍼클래스에서 **Agency View**(에이전시 보기)로 이동해요.
2. 통합 재판매 화면이 기본으로 켜져 있지 않다면 **실험실**을 열고 해당 기능을 켜요. 기능은 바로 활성화돼요.
3. 에이전시 보기의 왼쪽 메뉴에서 **재판매** 페이지를 열어요. 페이지 위쪽에 **구독**, **사용량**, **마켓플레이스** 탭이 보여요.
4. 구독 기반 상품은 **구독** 탭, 사용량 기반 상품과 마크업은 **사용량** 탭, 지원되는 마켓플레이스 상품은 **마켓플레이스** 탭을 눌러요.
5. 상품 목록에서 설정할 상품을 골라요.
6. 구독 기반 상품은 고객에게 보일 가격을 입력해요. 사용량 기반 상품은 사용량 기반 마크업 비율을 입력해요.
7. 서브 계정별 사용 여부를 설정하려면 상품 옆의 **관리** 버튼을 눌러요. 선택한 서브 계정에 대해 상품을 켜거나 꺼요.
8. 여러 서브 계정을 한 번에 바꿔야 하면 관리 표에서 계정을 선택하고 **일괄 작업**으로 변경 사항을 적용해요.
9. 설정을 확인한 뒤 **변경사항 저장**을 눌러요. 재판매 설정이 활성화되고, 설정한 서브 계정에 적용돼요.

{% hint style="info" %}
통합 화면을 켜면 기존 재판매·재청구 설정이 모두 자동으로 옮겨져요. 재청구에서 사용량 기반 재판매로 바뀐 것은 용어 변경일 뿐이고, 상품 청구 방식이나 기존 설정의 동작에는 영향이 없어요.

여기까지 마치면 재판매 업무를 하나의 통합 화면에서 같은 방식으로 관리할 수 있어요. 새로 만든 로케이션에는 마크업도 자동으로 적용돼요.

## 자주 묻는 질문

### 재판매 페이지에서 무엇이 바뀌었나요?
재판매 페이지에서 구독 기반 상품, 사용량 기반 상품, 마켓플레이스 재판매를 한 화면에서 관리해요. 모든 재판매 상품을 같은 방식으로, 분류가 명확한 한곳에서 관리할 수 있어요.

### 재청구는 어떻게 되었나요?
재청구는 **사용량 기반 재판매**로 이름이 바뀌었어요. 용어만 바뀐 것이고, 기존 청구 방식, 마크업 계산 방식, 이미 설정한 상품의 동작은 그대로예요.

### 기존 재판매 설정을 다시 만들어야 하나요?
아니요. 기존 설정은 자동으로 옮겨져요. 구독 재판매와 사용량 기반 재청구 설정이 모두 그대로 활성 상태로 유지되어서, 직접 다시 설정할 필요가 없어요.

### 구독과 사용량은 어떻게 다른가요?
**구독**은 에이전시가 월 또는 연 단위 고정 요금을 정하는, 정기 상품 가격이에요. **사용량**은 사용한 만큼 청구되는 상품이고, 기본 원가에 마크업을 더해 적용해요.

### 서브 계정별로도 상품을 관리할 수 있나요?
네. 상품의 **관리** 옵션에서 특정 서브 계정에 대해 기능을 켜고, 사용량 재판매를 설정하고, 설정을 수정할 수 있어요. 로케이션 단위로 상품 사용 여부와 마크업을 정할 수 있어요.

### 여러 서브 계정에 설정을 한 번에 적용할 수 있나요?
네. 서브 계정 관리 화면에서 **일괄 작업**을 쓰면 선택한 서브 계정에 변경 사항을 한꺼번에 적용할 수 있어요. 일괄 변경을 적용하기 전에 확인 창을 꼼꼼히 살펴보세요.

### 재판매 페이지가 SaaS 요금제 가격을 덮어쓰나요?
아니요. 재판매 페이지에서 조정한 값은 SaaS 요금제나 수동 설정으로 정해 둔 가격을 대신하지 않아요. 이미 SaaS 요금제나 수동 설정으로 가격을 관리하고 있다면, 변경하기 전에 그 설정을 먼저 확인하세요.

### 마켓플레이스 재판매는 계속 쓸 수 있나요?
네. 지원되는 경우 **마켓플레이스**는 통합 재판매 화면에서 계속 쓸 수 있어요. 재판매 페이지의 **마켓플레이스** 탭에서 확인하세요.

### 글로벌 사용량 기반 마크업이 뭔가요?
사용량 기반 상품에 에이전시 단위로 적용하는 기본 마크업이에요. 새로 만든 SaaS 로케이션과, SaaS Mode가 켜진 기존 로케이션에 자동으로 적용돼서 로케이션마다 따로 설정하는 수고를 줄여 줘요.

### 특정 로케이션에서는 글로벌 마크업을 바꿀 수 있나요?
네. 글로벌 마크업은 기본 기준이 되는 값이고, 로케이션 단위로 바꿀 수 있어요. 에이전시 전체의 가격을 일관되게 유지하면서, 필요할 때 특정 고객만 마크업을 조정할 수 있어요.

### 통합 재판매 화면을 모든 에이전시가 쓸 수 있나요?
현재는 **실험실**에서 쓸 수 있는 기능이에요. 에이전시 대시보드에서 기능을 켜고 직접 써 보세요. 실험실 기능은 테스트 중이고, 하이퍼클래스는 에이전시가 화면을 쓰면서 남기는 의견을 환영해요.
