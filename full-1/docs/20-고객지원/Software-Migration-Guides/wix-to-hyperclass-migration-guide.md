# Wix에서 하이퍼클래스로 이전하기 (마이그레이션 가이드)

Wix에서 쓰던 웹사이트 콘텐츠, 이커머스 데이터, 연락처, 폼, 자동화, 소셜 게시물을 하이퍼클래스로 옮기는 방법을 안내해요. 이 문서의 순서대로 따라 하면 이전 작업을 차근차근 마칠 수 있어요.

마케팅을 더 효율적으로 운영하고, 고객 관리를 한곳에서 하고, 하이퍼클래스의 다양한 기능을 활용하고 싶을 때 이 가이드를 참고하세요.

{% hint style="warning" %}
Wix에서 하이퍼클래스로 이전할 때는 아래 항목을 모두 확인하세요.

1. 연락처
2. 파이프라인
3. 상품
4. 폼
5. 웹사이트와 페이지
6. 소셜 게시물
7. AI 도구와 맞춤 연동
{% endhint %}

## 연락처 이전하기

리드가 문의 폼을 제출하거나, 뉴스레터를 구독하거나, 구매하거나, 사이트에서 다른 활동을 하면 Wix가 입력한 정보와 함께 자동으로 연락처 목록에 추가해요.

### 1단계: Wix에서 연락처 내보내기

1. Wix 계정에 로그인해 연락처 대시보드를 엽니다.
2. **추가 작업** 아이콘 ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032356820/original/-oQzpkEEDnopFmKp_b73C_8sNYNRkBYhGg.png?1725558142) 을 클릭한 뒤 **Export contacts**(연락처 내보내기)를 클릭합니다.
3. 연락처 그룹을 고르려면 **By Label**(라벨별) 옵션을, 전체를 내보내려면 **모든 연락처**를 선택합니다.
4. 나중에 하이퍼클래스로 가져올 수 있도록 CSV 파일을 저장합니다.

### 2단계: 하이퍼클래스로 가져올 CSV 파일 준비하기

1. **날짜 형식**을 확인하세요. CSV 안의 모든 날짜 필드는 YYYY-MM-DD 형식이어야 하이퍼클래스와 호환돼요.
2. 특수 문자와 악센트 문자가 깨지지 않도록 CSV 파일의 문자 인코딩을 UTF-8로 맞추세요.
3. 파일에서 줄바꿈, 이모지, 불필요한 특수 문자를 지우세요. 가져오기 오류를 막는 데 도움이 돼요.
4. 커스텀 필드를 다시 만드세요. 하이퍼클래스에 로그인해 **연락처 > 설정 > 커스텀 필드**로 이동한 뒤, Wix에서 저장하던 방식과 비슷하게 연락처 데이터를 담을 커스텀 필드를 추가하세요.

### 3단계: 하이퍼클래스로 연락처 가져오기

1. 하이퍼클래스에 로그인해 왼쪽 메뉴에서 **연락처**로 이동합니다.
2. **연락처 가져오기** 버튼을 클릭합니다.
3. **CSV 파일 업로드** 단계에서 준비한 CSV 파일을 선택해 올립니다.
4. **필드 매핑** 화면에서 CSV 파일의 필드를 하이퍼클래스의 해당 필드와 연결합니다. 예를 들어 CSV의 "First Name"을 하이퍼클래스의 **이름**과 연결하세요.
5. 가져오는 동안 특정 목록에 연락처를 넣고 태그를 지정할 수 있어요. "Imported from Wix"처럼 연락처의 출처를 알려 주는 태그를 붙여 두면 좋아요.
6. 모든 필드를 매핑하고 태그와 목록을 정했다면 **가져오기 시작**을 클릭합니다. 하이퍼클래스가 파일을 처리한 뒤 연락처가 계정에 추가돼요.

{% hint style="info" %}
필수 필드가 모두 올바르게 매핑되었는지 확인하세요. CSV의 필드에 맞는 하이퍼클래스 필드가 없다면, 진행하기 전에 커스텀 필드를 먼저 만들어야 할 수 있어요.
{% endhint %}

## 파이프라인 다시 만들기 (Wix 워크플로우)

Wix 워크플로우는 프로젝트의 모든 단계를 보드로 보여 주는 기능이에요. 열마다 연락처 카드를 한눈에 확인할 수 있어요. Wix 워크플로우는 내보낼 수 없어서 하이퍼클래스의 **기회 & 파이프라인**에서 다시 만들어야 해요.

{% hint style="warning" %}
파이프라인을 옮길 때는 용어가 조금 달라요.

- 워크플로우(Wix) ➡️ 파이프라인(하이퍼클래스)
- 열(Wix) ➡️ 파이프라인 단계(하이퍼클래스)
- 카드(Wix) ➡️ 기회 카드(하이퍼클래스)
{% endhint %}

### 1단계: Wix 워크플로우(파이프라인) 확인하기

1. Wix에 로그인해 사이트 대시보드에서 **워크플로우**로 이동합니다.
2. 모든 파이프라인과 각 열을 확인합니다.

### 2단계: 하이퍼클래스에서 파이프라인 다시 만들기

1. 하이퍼클래스에 로그인해 왼쪽 메뉴에서 **기회 관리**(Opportunities)로 이동한 뒤 **파이프라인**을 선택합니다.
2. **파이프라인 추가**를 클릭합니다.
3. Wix의 열과 똑같이 파이프라인 단계를 만듭니다.

![하이퍼클래스에서 파이프라인을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032356831/original/MHdG54L3CFbYsYT6arlRRAwrdd3oUGKGtg.png?1725558143)

## 상품 이전하기 (Wix Stores)

실물 상품은 최대 5,000개까지 CSV 파일로 내보낼 수 있어요. 각 상품의 미디어 파일은 Wix 미디어 매니저에 있어요.

### 1단계: Wix에서 상품 데이터 내보내기

1. Wix 계정에 로그인해 Wix Stores 대시보드를 엽니다.
2. **상품**으로 이동해 **추가 작업**을 클릭한 뒤 **내보내기**를 선택합니다.
3. 상품 목록을 CSV 파일로 저장하고, 내보낼 상품의 범위를 고릅니다.
4. 내보내기를 마치려면 **추가 작업**(드롭다운)을 클릭한 뒤 **내보내기**를 클릭합니다.

   - 전체 상품 내보내기: 왼쪽 위의 체크박스를 선택합니다.
   - 카테고리나 필터로 걸러낸 상품 내보내기: **필터**를 클릭하고 내보낼 상품 유형을 선택한 뒤 **완료**를 클릭합니다.
   - 선택한 상품만 내보내기: 내보낼 상품 옆의 체크박스를 선택합니다.

### 2단계: Wix에서 상품 미디어 내려받기

1. Wix에 로그인합니다.
2. [Wix Media Manager](https://support.wix.com/en/article/wix-media-accessing-the-media-manager)로 이동합니다.
3. 키보드의 Command / Control 키를 누른 채로 내려받을 파일을 클릭합니다.
4. Wix Media Manager 오른쪽 패널에서 **다운로드**를 클릭합니다. 필요한 상품 이미지를 빠짐없이 받아 두세요.

### 3단계: 가져오기용 Wix 상품 CSV 준비하기

Wix 상품 CSV의 헤더와 구성을 하이퍼클래스 샘플 CSV와 똑같이 맞춰 정리하세요. [샘플 상품 .csv 파일 내려받기](https://drive.google.com/file/d/13D3PS68wsWK-h2IBPWeelFD6Mko9meDo/view?usp=sharing)

{% hint style="warning" %}
CSV 파일의 열은 정확히 29개여야 해요.
{% endhint %}

### 4단계: 하이퍼클래스에 결제 게이트웨이 추가하기

하이퍼클래스에서 사용할 **결제 게이트웨이**를 연동하세요. 그리고 Wix 스토어 설정과 같아지도록 상품 가격, 세금, 배송 옵션을 설정하세요.

### 5단계: 하이퍼클래스로 상품 가져오기

1. 하이퍼클래스에 로그인해 **결제 > 상품**으로 이동한 뒤 **CSV로 가져오기**를 선택합니다.
2. 상품 정보를 직접 입력하거나, CSV 가져오기 기능을 쓸 수 있으면 **상품 가져오기**로 올립니다.
3. 상품 이미지를 다시 올리고 해당 상품에 연결합니다.

![하이퍼클래스에서 CSV로 상품을 가져오는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032356827/original/FTn3Q4qL0VOxZ7Aeb-U1N90z2f0k1sqIlg.png?1725558143)

## 폼과 제출 데이터 이전하기

Wix 폼은 사이트에 바로 넣어 방문자가 작성하게 하거나(예: 문의 폼, 견적 요청 폼), 고유 URL로 단독 폼을 공유하는 방식으로 쓸 수 있어요. 기본적으로 누군가 폼을 제출하면 사이트 소유자에게 제출 알림 이메일이 자동으로 가요.

### 1단계: Wix에서 폼 데이터 내보내기

1. Wix 계정에 로그인해 **폼 & 제출** 대시보드를 엽니다.
2. **폼 & 제출**에서 **추가 작업**을 클릭하고 **내보내기**를 선택합니다.
3. 나중에 쓸 수 있도록 폼 제출 데이터를 CSV 파일로 저장합니다.

### 2단계: 하이퍼클래스에서 폼 다시 만들기

1. 하이퍼클래스에 로그인해 **사이트 > 폼**으로 이동한 뒤 새 폼을 만듭니다. Wix 폼과 같은 커스텀 필드를 추가해 폼을 다시 구성하세요.
2. Wix에서 쓰던 기능을 그대로 쓸 수 있도록, 폼 알림이나 폼의 조건부 로직 같은 자동 동작을 하이퍼클래스에서 설정하세요.

## 웹사이트 다시 만들고 도메인 연결하기

Wix는 웹사이트 전체 콘텐츠를 바로 내보내는 기능을 제공하지 않아요. Wix 사이트는 Wix 서버에서 호스팅하고 운영해야 제대로 작동하기 때문이에요. 그래서 텍스트, 이미지, 기타 미디어 파일을 직접 복사해 하이퍼클래스에서 사이트와 온라인 스토어를 다시 만들어야 해요.

### 1단계: Wix에서 콘텐츠 내보내기

1. Wix 계정에 로그인해 Wix 대시보드를 엽니다.
2. 이전에 필요한 콘텐츠를 모두 확보하려면 Wix Media Manager에서 이미지, 동영상, 문서를 내려받으세요.
3. Wix 사이트에 사용자 지정 코드를 썼다면 HTML, CSS, 사용자 지정 스크립트를 복사해 두세요. 사이트의 디자인과 기능을 그대로 살릴 수 있어요.

### 2단계: 하이퍼클래스에서 웹사이트 다시 만들기

1. 하이퍼클래스 계정에 로그인해 웹사이트 구조에 맞게 **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동합니다.
2. 복사해 둔 콘텐츠를 붙여 넣고 미디어 파일을 다시 올려, 페이지를 하나씩 직접 만듭니다. 하이퍼클래스의 드래그 앤 드롭 편집기로 페이지를 디자인하고, Wix 사이트처럼 폼도 추가하세요.
3. Wix에서 사용자 지정 HTML/CSS를 썼다면, 하이퍼클래스의 해당 위치에 그 코드를 추가해 원래의 기능과 디자인을 유지할 수 있어요.

### 3단계: Wix에서 도메인 연결 해제하기

1. Wix에 로그인합니다.
2. **도메인** 페이지로 이동합니다.
3. 해당 도메인 옆의 **Show More**(더 보기) 아이콘 ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032356814/original/n0M0340akWZBxK7sbaydJwVPx8CplLxKXA.png?1725558141) 을 클릭하고 **Unassign from This Site**(이 사이트에서 연결 해제)를 선택합니다.

### 4단계: 하이퍼클래스에 도메인 연결하기

1. 하이퍼클래스에 로그인해 **설정 > 도메인 > 도메인 추가**로 이동합니다. 새로 만든 사이트에 쓸 도메인을 입력하세요.
2. Wix에 로그인해 **도메인** 페이지로 이동합니다. 해당 도메인 옆의 **액션 아이콘** ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032356813/original/OGYd87JQ6C9K08Z2Rs0m2LWzWmMT0sPF0A.png?1725558141) 을 클릭하고 **Manage DNS records**(DNS 레코드 관리)를 선택합니다.
3. 추가할 레코드 유형(예: CNAME, TXT)까지 스크롤해 **+ Add Record**(+ 레코드 추가)를 클릭합니다.

![Wix에서 DNS 레코드를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032356824/original/TjCxkG0luIyussaVXVEE-Ko8zQZAuVq78g.png?1725558143)

## Wix 자동화 다시 만들기

Wix는 자동화를 바로 내보내는 기능을 제공하지 않아요. Wix 자동화는 이메일 발송, 알림, 담당자 지정 같은 사이트 업무를 간소화해 줘요.

### 1단계: Wix 자동화 확인하기

1. Wix에 로그인해 사이트 대시보드에서 **자동화**로 이동합니다.
2. 아래로 스크롤해 **Your automations**(내 자동화) 섹션에서 두 개의 탭에 있는 모든 자동화를 확인합니다. 각 탭에서 **활성 자동화**만 걸러서 보세요.

   - **내가 만듦**: 이 화면에서 직접 만들었거나 앱을 통해 만든 활성 자동화예요.
   - **Installed for you**(나를 위해 설치됨): Wix 앱을 설치할 때 자동으로 만들어진 활성 자동화예요.

### 2단계: 하이퍼클래스에서 트리거와 액션 다시 만들기

1. 하이퍼클래스에 로그인해 **자동화 > 워크플로우**로 이동합니다.
2. 하이퍼클래스의 워크플로우 기능으로 비슷한 트리거와 액션을 설정하세요. 이메일 시퀀스나 업무 담당자 지정처럼 꼭 필요한 자동화는 빠짐없이 다시 만드세요. 워크플로우 만드는 방법은 하이퍼클래스 워크플로우 관련 도움말에서 더 자세히 볼 수 있어요.

## 소셜 게시물과 마케팅 다시 만들기

Wix는 소셜 게시물을 내보내는 기능을 제공하지 않아요. 소셜 계정을 하이퍼클래스의 **소셜 플래너**에 연결하고, 게시물은 Wix에서 직접 내려받아야 해요.

### 1단계: Wix에서 소셜 게시물 내려받기

1. Wix 계정에 로그인해 **소셜 미디어** 마케팅 대시보드를 열고 **Your Social Posts**(내 소셜 게시물)를 클릭합니다.
2. 하이퍼클래스에서 다시 만들 수 있도록 게시물의 예약 날짜와 시간, 캡션, 이미지, 링크 같은 내용을 직접 내려받거나 복사해 두세요.

### 2단계: 하이퍼클래스에서 소셜 게시물 다시 만들기

1. 하이퍼클래스에 로그인해 **마케팅 > 소셜 플래너**로 이동합니다. Wix에서 복사한 내용으로 소셜 게시물을 다시 만드세요.
2. 마케팅 일정에 맞춰 나중에 게시되도록 예약하거나, 바로 게시하세요.

## AI 도구와 콘텐츠 다시 만들기

### 1단계: AI로 만든 콘텐츠 다시 만들기

1. Wix에서 쓴 AI 도구를 살펴보세요. 텍스트, 이미지, SEO 태그처럼 AI로 만든 콘텐츠를 확인합니다.
2. 하이퍼클래스의 **콘텐츠 AI** 도구에 익숙해지세요. 하이퍼클래스 AI 도구로 텍스트와 이미지를 만들 수 있어요. Wix에서 만든 콘텐츠를 직접 복사하거나, 직접 쓰던 AI 프롬프트가 있다면 하이퍼클래스 AI에서 필요에 맞게 다시 만드세요.
