# Mailchimp에서 하이퍼클래스로 옮기기 (이전 가이드)

Mailchimp에서 하이퍼클래스로 옮길 때 이메일 캠페인, 연락처 목록, 폼, 자동화 워크플로우를 어떻게 이전하는지 단계별로 안내해요. 하이퍼클래스의 CRM과 마케팅 자동화 기능으로 끊김 없이 넘어가는 것이 목표예요.

## 이전 준비

### 1단계: 현재 Mailchimp 설정 살펴보기

- 옮길 항목 정리: 이전해야 할 오디언스, 이메일 캠페인, 자동화 워크플로우, 폼을 모두 목록으로 만드세요.
- 디자인과 내용 기록: 하이퍼클래스에서 똑같이 만들 수 있도록 이메일과 폼마다 디자인, 내용, 설정을 스크린샷이나 메모로 남겨 두세요.
- 데이터 규모 확인: 옮길 연락처와 캠페인이 얼마나 되는지 파악하세요.

### 2단계: 이전 목표 정하기

- 목표 분명히 하기: CRM 기능 통합, 더 나은 자동화, 비용 절감 등 하이퍼클래스로 옮기려는 이유를 정리하세요.
- 중요한 기능부터 우선순위 정하기: 업무가 끊기지 않도록 가장 중요한 기능부터 먼저 옮기세요.

### 3단계: 백업 준비하기

- Mailchimp 데이터 내보내기: 연락처 목록, 이메일 캠페인, 자동화 워크플로우 등 관련 데이터를 모두 내보내세요.
- 데이터 백업: 이전을 시작하기 전에 내보낸 데이터가 안전하게 백업되어 있는지 확인하세요.

## 연락처, 캠페인, 자동화 옮기기

### 1단계: Mailchimp에서 데이터 내보내기

- 연락처 내보내기: Mailchimp에서 **Audience > All contacts**(모든 연락처)로 이동하세요. 옮길 연락처를 선택한 뒤 CSV 파일로 내려받으면 돼요.
- 이메일 캠페인 내보내기: **Campaigns > All Campaigns**로 이동해서 다시 쓸 만한 콘텐츠나 HTML 템플릿을 내보내세요.
- 자동화 내보내기: 기존 자동화 워크플로우의 설정(트리거, 액션, 세그먼트)을 문서로 정리해 두세요.

### 2단계: 하이퍼클래스로 연락처 가져오기

- 연락처 가져오기: 하이퍼클래스에서 **연락처 > 가져오기**로 이동해 Mailchimp에서 내보낸 CSV 파일을 업로드하세요. 모든 데이터가 제대로 들어오도록 커스텀 필드를 매핑하세요.

## 폼과 랜딩 페이지 옮기기

### 1단계: 하이퍼클래스에서 폼 다시 만들기

- 폼 다시 만들기: **사이트 > 폼**에서 Mailchimp에 있던 폼을 다시 만드세요. 필드, 유효성 검사 규칙, 제출 후 동작이 Mailchimp와 같은지 확인하세요.
- 폼 삽입하기: 제공되는 임베드 코드로 다시 만든 폼을 웹사이트나 랜딩 페이지에 넣으세요.

### 2단계: 하이퍼클래스에서 랜딩 페이지 다시 만들기

- 랜딩 페이지 다시 만들기: 하이퍼클래스에서 **사이트 > 퍼널**로 이동해 Mailchimp에 있던 랜딩 페이지를 다시 만드세요. 하이퍼클래스 템플릿을 쓰거나 처음부터 만들어서 기존 페이지와 디자인을 맞추세요.
- 랜딩 페이지 게시하기: 필요하면 커스텀 도메인을 연결하고, 랜딩 페이지를 게시해서 공개하세요.

![랜딩 페이지 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033900416/original/gm-aZHyJaH7nofGK4y5fG6jV1UVyj1w0cQ.png?1727811017)

## 이메일 캠페인과 자동화 옮기기

### 3단계: 하이퍼클래스에서 이메일 캠페인 다시 만들기

<!-- 검토 필요: 원문 내용이 서로 다름 -->

- 템플릿 고르기: 하이퍼클래스에서 **마케팅 > 이메일 > 템플릿**으로 이동해 알맞은 템플릿을 고르거나 처음부터 시작하세요.
- 내용 다시 만들기: Mailchimp 이메일의 텍스트, 이미지, 링크를 하이퍼클래스 이메일 빌더로 옮기세요. 레이아웃과 디자인 요소가 기존 Mailchimp 캠페인과 같은지 확인하세요.
- 구독 취소 링크 설정하기: 이메일 관련 규정을 지키려면 하이퍼클래스에 기본으로 들어 있는 구독 취소용 머지 태그를 사용하세요.

### 4단계: 하이퍼클래스에서 자동화 다시 만들기

- 자동화 워크플로우 다시 만들기: 하이퍼클래스에서 **자동화 > 워크플로우**로 이동해 Mailchimp 자동화를 다시 만드세요. 트리거, 액션, 조건을 기존 Mailchimp 워크플로우와 같게 설정하세요.
- 미리 만들어진 레시피 활용하기: 기존 Mailchimp 자동화와 비슷한 하이퍼클래스 워크플로우 레시피가 있다면 사용해서 시간을 아끼세요.

![워크플로우 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033900357/original/CUGsNxOC_wZjF6-xdZjKd5Rv74RxnnbEvQ.png?1727810903)

## 연동 설정

### 1단계: 하이퍼클래스에서 연동 다시 연결하기

- 이메일 연동 다시 연결: 하이퍼클래스에서 **설정 > 연동**으로 이동해 필요한 외부 서비스(예: Zapier, 소셜 미디어 플랫폼)를 다시 연결하세요.
- 결제 처리 설정(해당하는 경우): Mailchimp의 이커머스 기능을 썼다면, 하이퍼클래스의 **설정 > 결제**에서 결제 게이트웨이를 설정하세요.

### 2단계: 분석 설정하기

- 트래킹 활성화: 하이퍼클래스에 기본으로 들어 있는 분석 기능으로 이메일 캠페인과 랜딩 페이지의 성과를 확인하세요.
- 외부 분석 도구 적용(필요한 경우): Mailchimp에서 쓰던 추적 코드(예: Google Analytics)가 있다면 **설정 > 추적**에서 다시 적용하세요.

![연동과 추적 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033900425/original/rdYcK6RFdDf2vzrdzx34wY2gK_ZGkrVtTQ.png?1727811050)

## 최종 점검과 팀 교육

### 1단계: 데이터 최종 검증하기

- 데이터 교차 확인: 모든 연락처, 이메일 캠페인, 자동화 워크플로우가 하이퍼클래스로 잘 옮겨졌고 제대로 작동하는지 확인하세요.
- 이메일 캠페인 테스트: 개인화 태그와 구독 취소 링크를 포함해 이메일이 올바르게 발송되는지 확인하세요.

### 2단계: 팀원 교육하기

- 하이퍼클래스 교육: 하이퍼클래스의 이메일 빌더, 워크플로우, CRM 기능 사용법을 팀원에게 교육하세요.
- 지원 자료 활용: 팀원이 계속 배우고 문제를 해결할 수 있도록 하이퍼클래스 고객지원과 도움말을 활용하게 하세요.

### 3단계: 모니터링하고 개선하기

- 성과 모니터링: 하이퍼클래스에서 캠페인과 워크플로우의 성과를 정기적으로 확인하고 필요한 부분을 조정하세요.
- 지속적인 개선: 하이퍼클래스의 새 기능과 업데이트를 꾸준히 확인해서 설정을 계속 개선하세요.

## Mailchimp 사용 종료

### 1단계: 전환 기간 두기

- 병행 운영: 원활하게 전환할 수 있도록 Mailchimp와 하이퍼클래스를 짧은 기간 동안 함께 운영해 보세요.
- 단계적 종료: 하이퍼클래스 기능에 확신이 생기면 Mailchimp 사용을 조금씩 줄이세요.

### 2단계: Mailchimp 구독 해지하기

- 최종 데이터 백업: Mailchimp 구독을 해지하기 전에 필요한 데이터가 모두 안전하게 백업되어 있는지 확인하세요.
- 공식 해지 절차: Mailchimp의 해지 절차에 따라 구독과 관련 서비스를 종료하세요.

### 3단계: 이전 후 점검하기

- 결과 검토: 이전이 잘 되었는지 평가하고, 겪은 어려움과 해결 방법을 기록하세요.
- 지속적인 모니터링: 이전 후에도 하이퍼클래스 설정을 지켜보면서 문제가 생기면 바로 해결하세요.
