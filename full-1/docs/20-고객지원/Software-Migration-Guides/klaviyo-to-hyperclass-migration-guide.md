# Klaviyo에서 하이퍼클래스로 옮기기 (마이그레이션 가이드)

Klaviyo에서 쓰던 연락처, 세그먼트, 자동화, 폼 같은 주요 자료를 하이퍼클래스로 옮기는 전체 과정을 안내해요. 순서대로 따라 하면 끊김 없이 전환하면서 하이퍼클래스의 마케팅·CRM 기능을 폭넓게 쓸 수 있어요.

## 마이그레이션 준비

### 1단계: 지금 쓰는 Klaviyo 환경 점검하기

- 핵심 자료 파악: Klaviyo에 있는 중요한 자료를 모두 적어 두세요. 연락처(프로필), 세그먼트, 자동화(플로우), 폼, 이메일/SMS 캠페인이 해당돼요.
- 워크플로우 기록: 운영에 꼭 필요한 자동화 워크플로우, 세그먼트, 캠페인은 화면을 캡처하거나 메모로 남겨 두세요.
- 데이터 규모 확인: 옮겨야 할 데이터(연락처, 커스텀 필드, 자동화)가 얼마나 되는지 가늠해 보세요.

### 2단계: 마이그레이션 목표 정하기

- 목표 명확히 하기: 하이퍼클래스로 옮기려는 이유를 정리하세요. 예를 들어 통합 CRM 기능, 강화된 자동화, 더 나은 가격 같은 이유가 있을 수 있어요.
- 우선순위 정하기: 운영이 끊기지 않도록 가장 중요한 기능부터 옮기세요.

### 3단계: 백업 준비하기

- Klaviyo 데이터 내보내기: 연락처 목록, 커스텀 필드, 세그먼트, 자동화 시퀀스 등 필요한 데이터를 모두 내보내세요.
- 데이터 백업: 마이그레이션을 시작하기 전에 내보낸 데이터를 안전한 곳에 백업해 두세요.

## 연락처 옮기기

### 1단계: Klaviyo에서 연락처(프로필) 내보내기

- 연락처 내보내기: Klaviyo의 **Profiles**(프로필) 메뉴로 이동해요. 내보낼 프로필을 선택하거나 전체 프로필 내보내기 옵션을 사용한 뒤, **Export profile data**(프로필 데이터 내보내기)를 클릭해 .zip 파일로 내려받으세요.
- 세그먼트 내보내기: Klaviyo의 세그먼트를 모두 문서로 정리하거나 내보내세요. 하이퍼클래스에서 다시 만들 수 있도록 세그먼트마다 사용한 조건을 적어 두세요.
- 자동화 플로우 기록: 모든 자동화 시퀀스, 트리거, 액션을 캡처하거나 직접 문서로 정리하세요.

### 2단계: 하이퍼클래스로 연락처 가져오기

- 연락처 가져오기: 하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동해요. Klaviyo에서 내보낸 CSV 파일을 업로드하고, 가져오는 중에 Klaviyo의 커스텀 필드를 하이퍼클래스 필드와 연결(매핑)하세요.
- 세그먼트 다시 만들기: 하이퍼클래스에서 **연락처 > 스마트 리스트**로 이동해 Klaviyo의 세그먼트를 다시 만드세요. Klaviyo에서 정리해 둔 조건을 그대로 사용하면 같은 대상이 정확하게 묶여요.

## 웹 폼 다시 만들기

### 1단계: 하이퍼클래스에서 폼 다시 만들기

- 폼 다시 만들기: **사이트 > 폼**에서 Klaviyo 폼을 다시 만드세요. 디자인과 필드를 기존 Klaviyo 폼과 최대한 비슷하게 맞추세요.
- 제출 후 동작 설정: Klaviyo에서처럼 폼이 제출되면 태그를 추가하거나 워크플로우를 실행하도록 설정하세요.

### 2단계: 웹사이트에 폼 삽입하기

- 웹사이트 연결: 하이퍼클래스에서 제공하는 임베드 코드로 웹사이트에 폼을 삽입하세요.
- 새 폼 테스트: 폼이 의도대로 동작하고 하이퍼클래스와 문제없이 연결되는지 직접 제출해 확인하세요.

## 자동화와 이메일 캠페인 다시 만들기

### 1단계: Klaviyo의 기존 자동화(플로우) 점검하기

- 활성 플로우 목록 작성: 사용 중인 플로우를 모두 찾아 이메일/SMS 시퀀스, 트리거, 조건을 정리하세요.
- 자동화 플로우 문서화: 하이퍼클래스에서 다시 만들 수 있도록 각 플로우를 자세히 메모하거나 캡처해 두세요.

### 2단계: 하이퍼클래스에서 자동화 다시 만들기

- 새 워크플로우 만들기: **자동화 > 워크플로우**로 이동해 Klaviyo 자동화를 다시 만드세요. 하이퍼클래스의 트리거, 조건, 액션을 조합하면 비슷한 결과를 낼 수 있어요.
- 워크플로우 테스트: 다시 만든 워크플로우를 모두 꼼꼼히 테스트하고, 필요하면 수정하세요.

### 3단계: 이메일·SMS 캠페인 다시 만들기

- 캠페인 설정: 하이퍼클래스에서 **마케팅 > 이메일 캠페인** 또는 **마케팅 > SMS Campaigns**(SMS 캠페인)로 이동해 캠페인을 다시 만드세요. 대상, 콘텐츠, 발송 일정은 Klaviyo와 똑같이 맞추세요.
- A/B 테스트: Klaviyo에서 A/B 테스트를 썼다면 하이퍼클래스의 캠페인 빌더에서도 같은 테스트를 만드세요.

## 분석·리포팅 설정

### 1단계: Klaviyo 분석 자료 확인하기

- 핵심 지표 기록: 오픈율, 클릭률, 전환 지표 등 Klaviyo의 주요 분석 수치를 기록해 두세요.
- 성과가 좋은 캠페인 파악: 성과가 좋았던 캠페인과 플로우를 적어 두세요. 하이퍼클래스에서도 같은 성과를 내도록 우선해서 옮기면 좋아요.

### 2단계: 하이퍼클래스에서 분석 설정하기

- 성과 대시보드: **대시보드 > Performance**(성과)로 이동해 마케팅 분석을 설정하고 확인하세요.
- 사용자 지정 리포트: 하이퍼클래스의 **사용자 지정 리포트** 기능으로 Klaviyo와 비슷한 리포트를 만드세요. 비즈니스에 가장 중요한 지표를 중심으로 구성하세요.

## 최종 점검과 교육

### 1단계: 데이터 최종 검증하기

- 데이터 교차 확인: 연락처, 세그먼트, 자동화, 폼을 포함해 모든 데이터가 제대로 옮겨졌는지 확인하세요.
- 워크플로우 검증: 하이퍼클래스의 모든 워크플로우와 자동화가 정상적으로 동작하는지 확인하세요.

### 2단계: 팀원 교육하기

- 하이퍼클래스 교육: 팀원이 하이퍼클래스의 CRM, 자동화, 마케팅 도구를 쓸 수 있도록 필요한 교육을 해 주세요.
- 지원 자료 활용: 하이퍼클래스의 지원 자료를 활용해 꾸준히 배우고 문제를 해결하도록 안내하세요.

### 3단계: 모니터링과 최적화

- 성과 모니터링: 하이퍼클래스 환경의 성과를 계속 살펴보고, 필요에 따라 조정해 운영을 개선하세요.
- 지속적인 개선: 비즈니스가 달라지는 만큼 설정이 잘 맞는지 주기적으로 점검하세요.

## Klaviyo 정리하기

### 1단계: 전환 기간 두기

- 병행 운영: 전환하는 동안 Klaviyo와 하이퍼클래스를 함께 운영하는 방법을 고려해 보세요. 운영이 끊기는 일을 막을 수 있어요.
- 단계적 축소: 하이퍼클래스에 익숙해지는 만큼 Klaviyo 사용을 조금씩 줄이세요.

### 2단계: Klaviyo 구독 해지하기

- 최종 데이터 백업: Klaviyo 구독을 해지하기 전에 필요한 데이터를 모두 안전하게 백업했는지 확인하세요.
- 공식 해지: Klaviyo의 해지 절차에 따라 구독과 관련 서비스를 종료하세요.

### 3단계: 마이그레이션 후 검토하기

- 성과 검토: 마이그레이션이 잘 끝났는지 평가하고, 겪은 어려움과 배운 점을 기록하세요.
- 지속적인 확인: 마이그레이션 후에도 하이퍼클래스 환경을 계속 살펴보고, 문제가 생기면 바로 해결하세요.
