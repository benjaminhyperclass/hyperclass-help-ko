# ActiveCampaign에서 하이퍼클래스로 옮기기 (마이그레이션 가이드)

ActiveCampaign에서 쓰던 주요 데이터와 설정을 하이퍼클래스로 옮기는 방법을 안내해요. 데이터 손실을 줄이면서 마케팅·영업 프로세스를 그대로 이어 갈 수 있도록 순서대로 따라 해 보세요.

{% hint style="warning" %}
**중요**: ActiveCampaign에서 하이퍼클래스로 전환할 때 아래 항목을 모두 옮겼는지 꼭 확인하세요.

1. 연락처
2. 딜(기회)
3. 이메일 템플릿
4. 랜딩 페이지
5. 폼
6. 자동화
{% endhint %}

---

## 연락처 옮기기

연락처는 마케팅과 CRM의 기본 데이터예요. ActiveCampaign에서 데이터를 내보낸 뒤 하이퍼클래스로 가져오면 돼요. 이때 데이터 형식이 맞는지 확인하고, 필드를 올바르게 매핑하고, 오류가 없는지 점검해야 해요.

### 1단계: ActiveCampaign에서 연락처 내보내기

1. ActiveCampaign에 로그인해 왼쪽 메뉴에서 **Contacts**(연락처)를 엽니다.
2. **Contacts** 페이지 오른쪽 위의 **Export** 버튼을 클릭합니다.
3. 내보내기 옵션에서 CSV 파일에 넣을 필드를 선택합니다. 보통 **Email**, **First Name**, **Last Name**, **Phone Number**, **Tags**와 필요한 커스텀 필드를 포함해요.
4. 내보내기 파일 이름을 입력합니다.
5. **Export**를 클릭합니다.
6. ActiveCampaign이 CSV 파일을 만들면 다운로드합니다. 이 파일에는 선택한 연락처 정보가 모두 들어 있어요.

{% hint style="warning" %}
파일 이름에 특수문자(예: !, #, $)를 쓰지 마세요. 하이퍼클래스로 가져올 때 문제가 생길 수 있어요.
{% endhint %}

### 2단계: 하이퍼클래스로 가져올 CSV 준비하기

- **날짜 형식 확인**: CSV의 모든 날짜 필드를 YYYY-MM-DD 형식으로 맞춥니다. 하이퍼클래스와 호환되려면 꼭 필요해요.
- **문자 인코딩 확인**: 특수 문자와 악센트 문자가 제대로 보이도록 CSV 파일을 UTF-8 인코딩으로 저장합니다.
- **데이터 정리**: 줄 바꿈, 이모지, 불필요한 특수문자를 지웁니다. 가져오기 오류를 막는 데 도움이 돼요.
- **이메일 주소 확인**: 하이퍼클래스로 가져오려면 이메일 주소가 필수예요. CSV의 모든 연락처에 올바른 이메일 주소가 있는지 확인합니다.

### 3단계: 하이퍼클래스로 연락처 가져오기

1. 하이퍼클래스에 로그인해 왼쪽 메뉴에서 **연락처**를 엽니다.
2. **Import Contacts**(연락처 가져오기) 버튼을 클릭합니다.
3. **CSV 파일 업로드**에서 준비한 CSV 파일을 선택해 업로드합니다.
4. **필드 매핑** 화면에서 CSV의 각 열을 하이퍼클래스의 해당 필드에 연결합니다. 예를 들어 CSV의 “First Name” 열은 하이퍼클래스의 **이름** 필드에 매핑해요.
5. 가져오는 동안 연락처를 특정 리스트에 넣고 태그를 지정할 수 있어요. 연락처의 출처를 알 수 있게 “ActiveCampaign에서 가져옴” 같은 태그를 붙이는 것도 좋아요.
6. 필드 매핑과 태그·리스트 설정을 마쳤으면 **가져오기**를 클릭합니다. 하이퍼클래스가 가져오기를 처리하면 연락처가 계정에 추가돼요.

### 4단계: 가져온 데이터 확인하기

가져오기가 끝나면 하이퍼클래스에서 모든 연락처와 관련 필드가 제대로 들어왔는지 확인합니다.

{% hint style="info" %}
**필드 매핑 팁**: 필수 필드가 모두 올바르게 매핑됐는지 확인하세요. CSV의 필드에 대응하는 하이퍼클래스 필드가 없다면, 진행하기 전에 하이퍼클래스에서 커스텀 필드를 먼저 만들어야 할 수 있어요.
{% endhint %}

## 딜(기회) 옮기기

딜은 잠재적인 판매나 거래를 뜻해요. 하이퍼클래스에서는 기회라고 부릅니다. ActiveCampaign에서 딜 데이터를 내보낸 뒤 하이퍼클래스의 알맞은 파이프라인으로 가져오면 돼요.

### 1단계: ActiveCampaign에서 딜 내보내기

1. ActiveCampaign의 왼쪽 메뉴에서 **Deals**(딜)를 엽니다.
2. **Deals** 페이지 위쪽의 필터로 내보낼 딜을 좁힙니다. 상태(Open, Won, Lost), 파이프라인 등 여러 조건으로 필터링할 수 있어요.
3. **Export** 버튼을 클릭합니다. 보통 오른쪽 위의 톱니바퀴 아이콘 메뉴에 있어요.
4. 시스템이 딜 데이터가 담긴 CSV 파일을 만들면 다운로드합니다. 이 파일을 하이퍼클래스에서 사용해요.

### 2단계: 하이퍼클래스로 가져올 CSV 준비하기

- **필수 항목 확인**: 각 딜에 해당하는 연락처가 하이퍼클래스에 있어야 해요. CSV에는 “Deal Title”, “Value”, “Pipeline”, “Stage”, “Contact Name”, “Deal Owner” 같은 항목이 있어야 합니다.
- **데이터 일관성 확인**: 특히 “Pipeline”과 “Stage” 항목이 하이퍼클래스의 파이프라인·단계 구성과 맞는지 확인합니다.

### 3단계: 하이퍼클래스로 딜 가져오기

1. 하이퍼클래스의 왼쪽 메뉴에서 **기회 관리**(Opportunities)로 이동합니다.
2. **Import Opportunities**(기회 가져오기) 버튼을 클릭합니다.
3. **CSV 파일 업로드**에서 CSV 파일을 선택해 업로드합니다.
4. **필드 매핑** 화면에서 CSV의 항목을 하이퍼클래스의 해당 필드에 연결합니다. 예를 들어 “Deal Title”은 “Opportunity Title”(기회 제목)에 매핑해요.
5. 각 딜이 하이퍼클래스의 올바른 파이프라인과 단계에 배정됐는지 확인합니다.
6. 필드 매핑을 마쳤으면 **가져오기**를 클릭합니다. 딜이 지정한 파이프라인에 추가돼요.

### 4단계: 가져온 뒤 확인하기

가져오기가 끝나면 하이퍼클래스에서 기회를 열어 모든 딜이 단계와 담당자까지 정확하게 들어왔는지 확인합니다.

## 이메일 템플릿 옮기기

이메일 템플릿은 캠페인과 자동화에 쓰는, 미리 디자인해 둔 이메일이에요. 공유 링크를 이용하면 ActiveCampaign에서 하이퍼클래스로 옮길 수 있어요.

### 1단계: ActiveCampaign에서 이메일 템플릿 공유하기

1. ActiveCampaign에서 **Campaigns > Campaign Templates**로 이동합니다.
2. 옮길 템플릿을 찾습니다.
3. 템플릿 위에 마우스를 올리고 톱니바퀴 아이콘을 클릭한 뒤 **Share**를 선택합니다.
4. 공유 링크가 담긴 창이 나타나면 링크를 복사합니다.

### 2단계: 하이퍼클래스로 이메일 템플릿 가져오기

1. 하이퍼클래스에서 **마케팅 > 이메일 > 이메일 템플릿**으로 이동합니다.
2. **새 템플릿 만들기**를 클릭하고 **템플릿 가져오기**를 선택합니다.
3. 입력란에 ActiveCampaign 템플릿의 공유 링크를 붙여 넣습니다.
4. 하이퍼클래스에서 쓸 템플릿 이름을 입력하고 **템플릿 만들기**를 클릭합니다.

### 3단계: 가져온 뒤 확인하기

가져온 템플릿을 열어 확인합니다. 브랜딩과 캠페인 목적에 맞게 필요한 부분을 수정하세요.

## 랜딩 페이지 다시 만들기

랜딩 페이지는 리드를 모으거나 특정 오퍼를 알리려고 만드는 독립 웹 페이지예요. 하이퍼클래스는 랜딩 페이지를 직접 가져오는 기능을 지원하지 않아요. 대신 하이퍼클래스의 페이지 빌더로 직접 다시 만들 수 있어요.

### 1단계: 랜딩 페이지 정보 기록하기

- **내용 정리**: ActiveCampaign의 랜딩 페이지를 보며 구조, 콘텐츠, 추적 코드(예: Google Analytics, Facebook Pixel)를 적어 둡니다.
- **스크린샷 저장**: 다시 만들 때 참고할 수 있게 랜딩 페이지 레이아웃을 스크린샷으로 남깁니다.

### 2단계: 하이퍼클래스에서 랜딩 페이지 다시 만들기

1. 하이퍼클래스에서 **사이트 > 퍼널/웹사이트**로 이동합니다.
2. **Create New Funnel/Website**(새 퍼널/웹사이트 만들기)를 선택하고, 템플릿을 고르거나 빈 페이지로 시작합니다.
3. 드래그 앤 드롭 빌더로 ActiveCampaign 랜딩 페이지의 구조를 다시 만듭니다. 필요한 콘텐츠, 이미지, 폼을 추가하세요.
4. **설정 > 추적 코드**로 이동해 필요한 추적 코드(예: Google Analytics ID, Facebook Pixel)를 추가합니다.
5. 페이지의 테마, 레이아웃, SEO 설정을 원하는 대로 바꿉니다.
6. 마음에 들면 **게시**를 클릭합니다.

### 3단계: 게시한 뒤 확인하기

게시된 페이지에서 모든 링크, 폼, 추적 코드가 제대로 작동하는지 확인합니다.

![랜딩 페이지 다시 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032267762/original/DqfHn9eSfHiVdxBL_j4S7crwIZF5GxhPIw.png?1725475823)

## 폼 옮기기

폼은 리드에게서 정보를 받고 자동화를 시작하는 데 쓰여요. ActiveCampaign의 폼은 하이퍼클래스의 폼 빌더에서 다시 만들어야 해요.

### 1단계: 폼 정보 기록하기

- **폼 필드 확인**: ActiveCampaign에서 폼 필드, 폼 액션(예: 리스트에 추가, 태그 적용), 연동 설정을 적어 둡니다.
- **폼 설정 기록**: 폼 공개 범위, 사용자 지정 CSS, 조건부 로직 같은 세부 설정도 적어 둡니다.

### 2단계: 하이퍼클래스에서 폼 다시 만들기

1. 하이퍼클래스에서 **사이트 > 폼**으로 이동합니다.
2. **새 폼 만들기**를 클릭하고 ActiveCampaign 폼과 같은 필드를 추가합니다.
3. 연락처를 리스트에 추가하기, 태그 적용하기, 워크플로우 시작하기 같은 폼 액션을 설정합니다.
4. 폼을 다 만들었으면 임베드 코드를 복사해 하이퍼클래스 랜딩 페이지나 웹사이트에 넣을 수 있어요.

### 3단계: 적용한 뒤 확인하기

- **폼 제출 테스트**: 폼으로 테스트 데이터를 제출해 모든 액션(예: 리스트 추가, 태그 적용)이 제대로 작동하는지 확인합니다.
- **데이터 수집 확인**: 커스텀 필드와 태그를 포함해 폼 데이터가 하이퍼클래스에 정확하게 저장됐는지 확인합니다.
- **임베드한 폼 확인**: 폼을 랜딩 페이지나 웹사이트에 임베드했다면 데스크톱, 태블릿, 모바일에서 모두 올바르게 보이는지 확인합니다.

## 자동화 다시 만들기

ActiveCampaign의 자동화는 폼 제출, 태그 적용 같은 특정 이벤트가 일어나면 실행되는 일련의 액션이에요. 이 자동화는 하이퍼클래스의 워크플로우 기능으로 직접 다시 만들어야 해요.

### 1단계: ActiveCampaign 자동화 기록하기

- **자동화 세부 정보 정리**: 가능하면 ActiveCampaign에서 각 자동화의 흐름도나 상세 내역을 내보냅니다. 내보낼 수 없다면 트리거, 액션, 조건, 최종 목표를 직접 적어 둡니다.
- **핵심 요소 파악**: 자동화마다 시작 트리거(예: 연락처가 리스트에 추가됨), 액션(예: 이메일 보내기, 태그 추가), 조건 분기(예: if/else)를 파악합니다.

### 2단계: 하이퍼클래스에서 자동화 다시 만들기

1. 하이퍼클래스에서 **자동화 > 워크플로우**로 이동합니다.
2. **Create New Workflow**(새 워크플로우 만들기)를 클릭하고, ActiveCampaign과 같은 시작 트리거(예: 폼 제출, 태그 추가)를 설정합니다.
3. ActiveCampaign 자동화의 액션 순서를 그대로 다시 만듭니다. 이메일 보내기, 태그 추가·제거, 연락처 정보 업데이트, 파이프라인에서 딜 이동하기 같은 액션이 포함될 수 있어요.
4. 조건 분기가 있다면 함께 설정합니다. 하이퍼클래스에서도 ActiveCampaign의 if/else 분기와 비슷한 조건부 로직을 추가할 수 있어요. 연락처의 행동이나 속성에 따라 서로 다른 경로로 안내되도록 조건을 정확히 설정하세요.
5. 대기 시간(예: 1일 기다리기)이 있는 자동화라면 하이퍼클래스에서도 정확하게 설정합니다.

### 3단계: 테스트하고 확인하기

- **테스트 연락처로 실행**: 테스트 연락처를 만들거나 기존 연락처 일부를 새 워크플로우에 넣어 봅니다. 진행 상황을 지켜보며 모든 액션이 제대로 실행되는지 확인하세요.
- **워크플로우 리포팅 확인**: 테스트가 끝나면 하이퍼클래스의 워크플로우 리포팅을 확인해 자동화가 의도대로 동작하는지 살펴봅니다.
- **필요하면 수정**: 의도와 다르게 동작하는 부분이 있으면 고친 뒤, 자동화가 매끄럽게 작동할 때까지 다시 테스트합니다.

## 옮길 때 함께 챙기면 좋은 것

### 교육과 문서화

- **내부 교육**: 팀원이 하이퍼클래스를 잘 쓸 수 있도록 교육하세요. 특히 ActiveCampaign과 다른 점을 중심으로 알려 주면 좋아요.
- **내부 SOP 만들기**: 하이퍼클래스로 옮기면서 바뀐 내부 업무 프로세스를 문서로 남깁니다.

### 데이터 정확성

- **데이터 재확인**: 모든 항목을 옮긴 뒤 연락처, 딜, 이메일 템플릿 등 모든 데이터가 빠짐없이 정확하게 옮겨졌는지 다시 확인합니다.
- **백업**: ActiveCampaign의 원본 데이터를 삭제하거나 보관하기 전에 백업해 두었는지 확인합니다.

### 고객 안내

- **연락처에 알리기**: 이메일 템플릿이나 폼 제출 방식 변경처럼 이번 전환이 고객이 접하는 프로세스에 영향을 준다면, 혼란이 없도록 연락처에 전환 사실을 알리는 것을 고려해 보세요.

### 지속적인 모니터링

- **성과 모니터링**: 하이퍼클래스의 워크플로우, 이메일 캠페인 등 자동화 프로세스가 의도대로 동작하는지 정기적으로 확인합니다.
- **최적화**: 전환 후에는 하이퍼클래스의 분석 및 리포팅 도구로 개선할 부분을 찾아 보세요.

## 자주 묻는 질문

### ActiveCampaign에서 연락처를 내보내려면 어떻게 하나요?

ActiveCampaign 계정에 로그인해 Contacts로 이동한 뒤 Export를 클릭하세요. 내보낼 필드(예: Email, First Name, Last Name)를 고르고, 특수문자를 피해 파일 이름을 입력한 다음 생성된 CSV 파일을 다운로드하면 돼요.

### 하이퍼클래스로 가져오기 전에 연락처 데이터를 어떻게 준비해야 하나요?

날짜를 YYYY-MM-DD 형식으로 맞추고, CSV를 UTF-8 인코딩으로 저장하세요. 줄 바꿈과 이모지는 지우고, 모든 연락처에 올바른 이메일 주소가 있는지 확인합니다.

### 하이퍼클래스로 연락처를 가져오고 필드를 올바르게 매핑하려면 어떻게 하나요?

하이퍼클래스에서 **연락처**로 이동해 Import Contacts를 클릭하세요. CSV를 업로드하고, 필드를 매핑한 뒤(예: “Email”은 **이메일**에 매핑), 태그나 리스트를 지정하고 **가져오기**를 클릭하면 돼요.

### ActiveCampaign의 딜(기회)을 하이퍼클래스로 옮기려면 어떻게 하나요?

ActiveCampaign에서 Deals > Export로 딜을 내보내세요. 이때 “Deal Title”, “Value”, “Stage” 같은 항목이 들어간 CSV를 준비합니다. 하이퍼클래스에서는 **기회 관리**로 이동해 Import Opportunities를 클릭하고, CSV를 업로드해 필드를 매핑한 뒤 올바른 파이프라인으로 가져오세요.

### ActiveCampaign의 이메일 템플릿을 하이퍼클래스로 바로 옮길 수 있나요?

네, 가능해요. ActiveCampaign에서 Campaigns > Campaign Templates로 이동해 템플릿을 고르고, 톱니바퀴 아이콘을 클릭해 Share를 선택한 뒤 링크를 복사하세요. 하이퍼클래스에서는 **마케팅 > 이메일 > 이메일 템플릿**으로 이동해 **템플릿 가져오기**를 선택하고, 링크를 붙여 넣어 만들면 돼요.

### 랜딩 페이지는 바로 가져올 수 없다는데, 하이퍼클래스에서 어떻게 다시 만드나요?

먼저 ActiveCampaign 랜딩 페이지의 레이아웃과 추적 코드를 기록해 두세요. 하이퍼클래스에서 **사이트 > 퍼널/웹사이트**로 이동해 새 페이지를 만들고, 드래그 앤 드롭 빌더로 다시 구성합니다. 그다음 **설정 > 추적 코드**에서 추적 코드를 추가하고 게시하세요.

### 폼을 하이퍼클래스로 옮기려면 어떻게 하나요?

ActiveCampaign 폼의 필드와 액션을 적어 두세요. 하이퍼클래스에서 **사이트 > 폼**으로 이동해 새 폼을 만들고, 같은 필드를 추가한 뒤 액션(예: 태그 적용)을 설정합니다. 그리고 만든 폼을 페이지에 임베드하면 돼요.

### ActiveCampaign의 자동화를 하이퍼클래스로 옮기려면 어떻게 하나요?

ActiveCampaign 자동화의 트리거와 액션을 기록해 두세요. 하이퍼클래스에서 **자동화 > 워크플로우**로 이동해 새 워크플로우를 만들고, 트리거를 설정한 뒤 액션과 조건을 추가해 테스트하면 돼요.

### ActiveCampaign 자동화와 하이퍼클래스 워크플로우는 어떤 점이 다른가요?

두 시스템 모두 비슷한 자동화 기능을 지원해요. 다만 하이퍼클래스의 워크플로우는 화면이 다르고, 고유한 트리거나 액션이 있을 수 있어요. 두 플랫폼의 문서를 함께 살펴보고 그에 맞게 자동화를 조정하세요.

### 옮기는 동안 데이터를 안전하게 지키려면 어떻게 해야 하나요?

SOP의 단계를 따르고, 데이터 형식과 매핑을 확인하세요. ActiveCampaign의 모든 데이터를 백업하고, 가져온 데이터가 정확한지 점검한 뒤, 전환 후에는 워크플로우를 계속 모니터링하면 돼요.
