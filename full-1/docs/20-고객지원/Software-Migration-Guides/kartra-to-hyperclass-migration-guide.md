# Kartra에서 하이퍼클래스로 옮기기 (마이그레이션 가이드)

Kartra에서 하이퍼클래스로 옮길 때 필요한 단계를 안내해요. 연락처, 코스, 웹사이트, 자동화 같은 주요 자산을 옮기고, 하이퍼클래스의 마케팅·CRM 기능을 온전히 쓸 수 있도록 준비하는 방법을 다뤄요.

## 마이그레이션 준비

### 1단계: 현재 Kartra 설정 검토

- 핵심 자산 파악: Kartra에 있는 필수 자산을 모두 적어 두세요. 리드/연락처, 자동화, 코스, 웹사이트가 여기에 해당해요.
- 워크플로우 기록: 운영에 꼭 필요한 자동화 규칙, 시퀀스, 커뮤니케이션 설정을 메모해 두세요.
- 데이터 규모 확인: 옮길 콘텐츠(동영상, 문서 등)와 데이터(연락처, 시퀀스)가 얼마나 되는지 파악하세요.

### 2단계: 마이그레이션 목표 정하기

- 명확한 목표 설정: 하이퍼클래스로 옮기는 이유를 정하세요. 예를 들어 자동화 기능 강화, CRM 통합, 더 나은 요금제가 있어요.
- 핵심 기능 우선순위 정하기: 가장 중요한 기능부터 옮겨서 운영이 끊기지 않게 하세요.

### 3단계: 백업 준비

- Kartra 데이터 내보내기: 연락처 목록, 이메일, 코스 자료 등 필요한 데이터를 모두 내보내세요.
- 데이터 백업: 마이그레이션을 시작하기 전에 내보낸 데이터를 안전하게 백업해 두세요.

## 연락처 내보내기

### 1단계: 연락처 내보내기

- Kartra 연락처로 이동: Kartra에서 **Communications > Leads**로 이동하세요.
- **연락처 선택**: 내보낼 리드/연락처를 체크박스로 선택하세요.
- **데이터 내보내기**: 드롭다운 메뉴에서 **Export**를 선택하면 연락처가 CSV 파일로 내려받아져요. 이메일 주소, 전화번호, 커스텀 필드 같은 중요한 필드가 내보내기에 포함됐는지 확인하세요.
- 파일 확인: CSV 파일을 열어서 커스텀 필드, 태그, 리스트를 포함한 필요한 연락처 데이터가 모두 들어 있는지 살펴보세요.

![Kartra에서 연락처를 선택해 내보내는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043767902/original/EqfxgqWyJueJbtG2YSUS2qlE7lsUi1HI5g.png?1742589236)

### 2단계: 하이퍼클래스로 가져올 CSV 준비

- 데이터 형식 확인: 하이퍼클래스와 호환되도록 모든 날짜 필드를 YYYY-MM-DD 형식으로 맞추세요.
- 특수 문자 인코딩: 특수 문자와 악센트 문자가 깨지지 않도록 파일을 UTF-8 인코딩으로 저장하세요.
- 데이터 정리: 가져오기 오류를 막으려면 줄바꿈, 이모지 같은 불필요한 문자와 빈 열을 지우세요.

### 3단계: 하이퍼클래스로 연락처 가져오기

- 하이퍼클래스에 로그인: **연락처 > 가져오기**로 이동하세요.
- **CSV 파일 업로드**: CSV 파일을 선택해 업로드하세요. 이름, 성, 이메일, 전화번호처럼 꼭 필요한 필드가 하이퍼클래스의 해당 필드와 올바르게 매핑됐는지 확인하세요.
- 커스텀 필드 매핑: Kartra에 커스텀 필드가 있다면, 데이터를 가져오기 전에 **연락처 > 설정 > 커스텀 필드**에서 하이퍼클래스에도 같은 필드를 만드세요.
- 태그와 리스트 지정: 하이퍼클래스의 태그와 리스트 기능으로 Kartra의 세분화 구조에 맞게 연락처를 정리하세요. 예를 들어 'Kartra Import' 태그를 쓸 수 있어요.

```
CSV로 대량 가져오기 문제를 해결하는 방법이 궁금하다면 여기를 클릭하세요
```

## 코스 옮기기

### 1단계: Kartra에서 코스 콘텐츠 내보내기

- Kartra 멤버십 섹션으로 이동: Kartra에서 **My Memberships**로 이동해 코스 콘텐츠를 찾으세요.
- 동영상과 PDF 내보내기: 옮길 때 필요한 콘텐츠를 빠짐없이 확보하도록 멤버십 섹션의 모든 동영상 강의와 문서를 내려받으세요. 이 파일들은 따로 백업해 두세요.
- 퀴즈와 설문 내보내기: 코스에 퀴즈나 평가가 있다면 하이퍼클래스에서 다시 만들 수 있도록 내용을 기록하거나 직접 내보내세요.

### 2단계: 하이퍼클래스용 코스 자료 준비

- 마이그레이션 계획 세우기: 수강생에게 미치는 영향을 줄이고 작업을 순조롭게 하려면 업무 시간 외에 시작하세요.
- 코스 콘텐츠 정리: 하이퍼클래스에서 다시 만들기 쉽도록 내보낸 콘텐츠를 모듈별로 묶으세요.
- 파일 호환성 확인: 미디어 파일(동영상은 MP4, 문서는 PDF 등)이 하이퍼클래스의 업로드 제한과 형식에 맞는지 확인하세요.

## 오퍼와 자동화 옮기기

### 1단계: Kartra의 기존 오퍼와 자동화 검토

- 진행 중인 오퍼 정리: 무료·유료를 포함해 현재 운영 중인 오퍼를 모두 파악하고, 가격 구조와 결제 게이트웨이도 함께 적어 두세요.
- 자동화 기록: 이메일 시퀀스, 태그, 트리거 기반 액션 같은 모든 자동화 규칙을 정확히 기록해 두세요.

### 2단계: 하이퍼클래스에서 오퍼 다시 만들기

- 오퍼 설정: 하이퍼클래스에서 **퍼널 & 웹사이트 > 상품**으로 이동해 Kartra의 오퍼에 맞는 오퍼를 만들고, 필요한 결제 게이트웨이와 가격을 설정하세요.
- 오퍼 접근 권한 부여: Kartra 설정과 똑같이, 하이퍼클래스에서 특정 연락처나 그룹에 오퍼를 지정해 접근 권한을 관리하세요.

## 캘린더 옮기기

### 1단계: 기존 캘린더 검토

- 모든 일정 정리: 현재 캘린더의 모든 일정을 빠짐없이 목록으로 만드세요. 아래 내용이 들어가야 해요.
  - 예약: 각 예약의 성격, 빈도, 참가자를 자세히 적어 두세요.
  - 예약(Bookings): 서비스나 상품과 관련된 예약이 있다면 시간대와 소요 시간을 함께 기록하세요.
  - 반복 일정: 반복되는 일정이 있다면 일정 주기와 관련 세부 정보를 적어 두세요.

### 2단계: 하이퍼클래스에서 캘린더 다시 만들기

- 하이퍼클래스 캘린더 만들기: 서브 계정의 **설정 > 캘린더**로 이동하세요. Kartra의 캘린더와 똑같이 하나씩 설정하고, 알림, 담당 사용자, 미팅 장소 등 이전 설정과 모두 맞는지 확인하세요.
- **캘린더 연동** 추가: **설정 > 캘린더 > 연결**로 이동해 Google 또는 Outlook 캘린더를 하이퍼클래스와 동기화하세요. 그러면 여러 플랫폼의 예약을 한곳에서 편하게 관리할 수 있어요.
- 반복 예약 설정: 반복되는 일정은 하이퍼클래스 캘린더 설정에서 반복 규칙을 직접 설정해 Kartra와 같게 맞추세요.
- 미리보기와 테스트: 새 캘린더를 기존 Kartra 설정과 비교해 보면서 모든 기능이 그대로 작동하는지 확인하세요.
- 기존 일정과 맞추기: 시간대와 가용 시간을 고려해 하이퍼클래스 캘린더에 일정 블록이 정확하게 표시되는지 확인하세요.
- 일정 세부 정보 추가: 각 일정에 아래와 같은 핵심 정보를 넣으세요.
  - **제목**: 한눈에 알아볼 수 있도록 분명하고 구체적인 이름을 쓰세요.
  - **설명**: 일정과 관련된 배경이나 메모를 적으세요.
  - **참가자**: 참석자나 관계자를 지정하세요.
  - **알림**: 모두가 일정을 놓치지 않도록 리마인더와 알림을 설정하세요.

### 3단계: 하이퍼클래스 캘린더 맞춤 설정

- 캘린더 스타일과 설정 살펴보기: 하이퍼클래스에는 필요에 맞게 캘린더를 조정할 수 있는 여러 설정이 있어요.
- 라운드 로빈 캘린더 만들기: 예약을 여러 팀원에게 나눠 배정하고 싶을 때 이 설정을 쓰세요.
- 수업 일정 설정: 그룹 세션이나 수업용 캘린더를 설정해 단체 예약을 효과적으로 관리하세요.
- 반복 예약: 정기 미팅이나 수업은 반복 세션으로 설정해 일정이 일관되게 유지되도록 하세요.
- 고급 사용자 지정: 색상, 가용 시간, 사용자 권한을 조직에 맞게 조정하세요.
- 추가 자료 확인: 이런 캘린더 유형의 설정 방법이 더 궁금하다면 하이퍼클래스 도움말 센터에서 "Calendars Setup"을 검색해 보세요. 자세한 안내와 팁을 볼 수 있어요.

## 연동 옮기기

<!-- 검토 필요: 원문 내용이 서로 다름 -->

### 1단계: Kartra의 기존 연동 검토

- **코스 콘텐츠 내보내기**: Kartra의 멤버십 또는 상품 섹션에서 동영상, PDF 등 코스 자료를 내려받으세요.

### 2단계: 하이퍼클래스에서 자동화 다시 만들기

- 새 워크플로우 만들기: 하이퍼클래스에서 **자동화 > 워크플로우**로 이동해 Kartra의 자동화를 다시 만드세요. 하이퍼클래스의 트리거, 조건, 액션을 활용하면 비슷한 결과를 낼 수 있어요.
- 워크플로우 테스트: 다시 만든 워크플로우가 모두 제대로 작동하는지 꼼꼼히 테스트하고, 필요하면 설정을 조정하세요.

## 웹사이트와 퍼널 옮기기

### 1단계: 하이퍼클래스에서 웹사이트 페이지 다시 만들기

- 웹사이트 페이지 다시 만들기: 하이퍼클래스의 **웹사이트 빌더**로 Kartra의 주요 페이지를 모두 다시 만드세요. 세일즈 페이지, 랜딩 페이지, 결제 페이지가 여기에 포함돼요. 디자인과 콘텐츠를 기존 페이지와 최대한 비슷하게 맞추세요.
- 콘텐츠 추가: 관련 텍스트, 이미지, 동영상 등 미디어를 하이퍼클래스 페이지로 가져와 Kartra 사이트를 그대로 재현하세요.

### 2단계: 퍼널 다시 만들기

- 새 퍼널 만들기: 하이퍼클래스에서 **사이트 > 퍼널**로 이동해 Kartra에서 쓰던 퍼널을 다시 만드세요. 랜딩 페이지, 수신 동의 폼, 이메일 시퀀스를 모두 포함하세요.
- 퍼널 페이지 사용자 지정: 하이퍼클래스의 드래그 앤 드롭 편집기로 퍼널 페이지를 꾸며서 Kartra에서 쓰던 설정과 맞추세요.

## 최종 점검과 교육

### 1단계: 최종 데이터 검증

- 데이터 교차 확인: 연락처, 코스 자료, 자동화를 포함한 모든 데이터가 제대로 옮겨졌는지 확인하세요.
- 워크플로우 검증: 하이퍼클래스에서 모든 워크플로우와 자동화가 정상적으로 작동하는지 확인하세요.

### 2단계: 팀원 교육

- 하이퍼클래스 교육: 팀원에게 하이퍼클래스의 CRM, 자동화, 코스 관리 도구 사용법을 교육하세요.
- 지원 자료 활용: 팀원이 하이퍼클래스 고객지원 자료로 꾸준히 배우고 문제도 직접 해결해 보도록 권장하세요.

### 3단계: 모니터링과 최적화

- 성과 모니터링: 하이퍼클래스 설정의 성과를 계속 지켜보면서, 필요할 때 조정해 운영을 최적화하세요.
- 지속적인 개선: 사업 환경이 바뀌어도 필요를 충족하도록 설정을 정기적으로 검토하세요.

## Kartra 종료

### 1단계: 전환 기간

- 병행 운영: 전환하는 동안 Kartra와 하이퍼클래스를 함께 운영해서 업무가 끊기지 않게 하는 방법을 고려해 보세요.
- 단계적 축소: 하이퍼클래스에 익숙해지는 만큼 Kartra에 대한 의존도를 천천히 줄이세요.

### 2단계: Kartra 구독 해지

- 최종 데이터 백업: Kartra 구독을 해지하기 전에 필요한 데이터를 모두 안전하게 백업했는지 확인하세요.
- 공식 해지: Kartra의 해지 절차에 따라 구독과 관련 서비스를 모두 종료하세요.

### 3단계: 마이그레이션 후 검토

- 성과 검토: 마이그레이션이 성공적이었는지 평가하고, 겪은 어려움과 배운 점을 기록해 두세요.
- 지속적인 모니터링: 마이그레이션이 끝난 뒤에도 하이퍼클래스 설정을 살펴서 문제가 생기면 바로 찾아 해결하세요.
