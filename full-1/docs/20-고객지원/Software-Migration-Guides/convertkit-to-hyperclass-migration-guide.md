# ConvertKit에서 하이퍼클래스로 옮기기 (마이그레이션 가이드)

ConvertKit에서 쓰던 이메일 마케팅, 구독자 관리, 자동화를 하이퍼클래스로 옮기는 방법을 안내해요. 하이퍼클래스의 CRM과 자동화 기능을 활용하면서 차근차근 전환할 수 있어요.

{% hint style="warning" %}
ConvertKit에서 하이퍼클래스로 옮길 때는 아래 항목을 모두 옮겼는지 확인하세요.

1. Visual Automations
2. 구독자(연락처)
3. 폼
4. 랜딩 페이지
5. 이메일 브로드캐스트
6. 커머스
7. 추가 데이터
{% endhint %}

## Visual Automations 옮기기

ConvertKit에서는 Visual Automations로 이메일 퍼널과 자동화 흐름을 만들어요. 하이퍼클래스에서는 **워크플로우**로 만들 수 있고, 기능도 비슷하거나 더 다양해요.

### 1단계: Visual Automations 정리하기

- 자동화 목록 만들기: ConvertKit에서 각 Visual Automation의 시작 조건(트리거), 액션, 이벤트, 조건을 정리해 두세요.
- 자동화 흐름 기록하기: 하이퍼클래스에서 똑같이 만들 수 있도록 각 자동화의 흐름을 스크린샷이나 메모로 남겨 두세요.

### 2단계: 하이퍼클래스에서 자동화 다시 만들기

- 워크플로우 열기: 하이퍼클래스에서 **자동화 > 워크플로우**로 이동하세요.
- 새 워크플로우 만들기: **Create New Workflow**(새 워크플로우 만들기)를 클릭하고, ConvertKit 자동화와 같은 흐름으로 설정을 시작하세요.
- 시작 조건(트리거) 설정하기: ConvertKit의 시작 조건과 맞는 하이퍼클래스 트리거를 고르세요. 예를 들어 폼 제출, 태그 추가, 구매 완료가 있어요.
- 액션과 조건 추가하기: 이메일 보내기, 대기 단계, 조건 분기(if/else) 같은 액션과 조건을 원래 자동화 흐름과 같게 다시 만드세요.
- 워크플로우 테스트하기: 다 만들었다면 모든 트리거, 액션, 조건이 의도대로 동작하는지 테스트하세요.

### 3단계: 옮긴 뒤 확인하기

- 테스트 실행하기: 테스트용 연락처를 만들어 워크플로우를 끝까지 통과시켜 보세요. 이메일 발송, 태그 지정, 조건 분기가 모두 제대로 동작하는지 확인하세요.

## 구독자(연락처) 옮기기

ConvertKit의 구독자는 하이퍼클래스의 연락처와 같은 개념이에요. ConvertKit에서 구독자를 내보낸 뒤 하이퍼클래스로 가져오면 되고, 태그와 세그먼트 정보도 함께 옮길 수 있어요.

### 1단계: ConvertKit에서 구독자 내보내기

- 구독자 화면으로 이동하기: ConvertKit에서 **Subscribers > Grow**로 이동하세요.
- 전체 구독자 선택하기: 맨 위 체크박스를 클릭해 모든 구독자를 선택하세요. 구독자가 30명보다 많다면, 나타나는 파란색 바의 링크를 클릭해 전체 선택을 확정하세요.
- 구독자 내보내기: **Bulk Actions > Export**를 선택해 내보내기를 시작하세요. 파일은 계정 소유자의 이메일로 전송되며, ConvertKit에서 직접 내려받을 수도 있어요.

### 2단계: 하이퍼클래스로 구독자 가져오기

- 연락처 화면으로 이동하기: 하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동하세요.
- CSV 파일 업로드하기: **CSV 파일 업로드**에서 ConvertKit에서 내보낸 CSV 파일을 올리세요.
- 필드 매핑하기: **필드 매핑**에서 CSV의 항목을 하이퍼클래스의 알맞은 필드에 연결하세요. 예를 들어 이름(First Name), 성(Last Name), 이메일(Email), 태그(Tags)가 있어요.
- 세그먼트와 태그 만들기: ConvertKit의 태그와 세그먼트 정보를 참고해 하이퍼클래스에서도 비슷한 세그먼트와 태그를 만드세요.

### 3단계: 옮긴 뒤 확인하기

- 가져온 결과 확인하기: 하이퍼클래스에서 가져온 연락처를 살펴보고, 모든 데이터가 제대로 매핑되고 분류되었는지 확인하세요.

![구독자 가져오기 과정 이미지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032540291/original/bIeKexEffmHndVknI8A-dHAYGJojOtaZDQ.png?1725900678)

## 폼 옮기기

ConvertKit의 폼은 리드를 모으고 구독자를 관리하는 데 쓰여요. 하이퍼클래스 **폼 빌더**로 같은 폼을 다시 만들 수 있고, CRM과 자동화 워크플로우에도 바로 연결할 수 있어요.

### 1단계: 폼 정보 정리하기

- 폼 목록 만들기: ConvertKit에서 만든 폼의 필드, 디자인, 설정을 정리해 두세요. 설정에는 리디렉션 URL, 인센티브 이메일, reCAPTCHA 등이 있어요.
- 커스텀 필드 기록하기: 데이터 수집에 쓴 커스텀 필드를 메모해 두세요.

### 2단계: 하이퍼클래스에서 폼 다시 만들기

- 폼 빌더 열기: 하이퍼클래스에서 **사이트 > 폼**으로 이동하세요.
- 새 폼 만들기: **새 폼 만들기**를 클릭하고, ConvertKit 폼에서 쓰던 필드부터 추가하세요.
- 디자인 맞추기: 배경색, 글꼴, 버튼 스타일 등을 원래 폼과 비슷하게 조정하세요.
- 폼 액션 설정하기: 제출 후 리디렉션, 확인 이메일 발송, 태그 적용 같은 폼 액션을 설정하세요.
- 워크플로우 연결하기: 폼이 워크플로우를 시작하는 구조였다면, 해당하는 하이퍼클래스 워크플로우와 연결되어 있는지 확인하세요.

### 3단계: 옮긴 뒤 확인하기

- 폼 제출 테스트하기: 각 폼으로 테스트 데이터를 제출해 보세요. 데이터가 제대로 저장되고 알맞은 워크플로우가 시작되는지 확인하세요.

## 랜딩 페이지 옮기기

ConvertKit의 랜딩 페이지는 리드 확보에 쓰는 독립 페이지예요. 하이퍼클래스에서 같은 랜딩 페이지를 다시 만들면 전체 마케팅 전략과 더 긴밀하게 연결할 수 있어요.

### 1단계: 랜딩 페이지 정보 정리하기

- 랜딩 페이지 목록 만들기: ConvertKit에서 각 랜딩 페이지의 사용 템플릿, 콘텐츠, 직접 넣은 이미지, 폼이나 자동화와의 연결 내용을 정리해 두세요.
- 도메인 설정 기록하기: 랜딩 페이지에 사용자 지정 도메인이나 서브도메인을 썼는지 메모해 두세요.

### 2단계: 하이퍼클래스에서 랜딩 페이지 다시 만들기

- 랜딩 페이지 빌더 열기: 하이퍼클래스에서 **사이트 > 퍼널/웹사이트**로 이동한 뒤 **Create New Landing Page**(새 랜딩 페이지 만들기)를 선택하세요.
- 템플릿 선택하기: **템플릿 선택**에서 ConvertKit 랜딩 페이지와 레이아웃과 스타일이 비슷한 템플릿을 고르세요.
- 콘텐츠 다시 만들기: 하이퍼클래스 랜딩 페이지에 콘텐츠, 이미지, 디자인 요소를 다시 구성하세요.
- 폼 연결하기: 하이퍼클래스에서 만든 폼을 랜딩 페이지에 삽입하고, 워크플로우와 연락처 목록에 제대로 연결되어 있는지 확인하세요.
- 도메인 설정하기: ConvertKit에서 사용자 지정 도메인을 썼다면, 같은 도메인이나 서브도메인을 하이퍼클래스에서도 설정하세요.

### 3단계: 옮긴 뒤 확인하기

- 미리보기와 테스트하기: 랜딩 페이지를 미리 보고 테스트해서 폼 제출과 리디렉션을 포함한 모든 요소가 의도대로 동작하는지 확인하세요.

![랜딩 페이지 이전 과정 이미지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032543028/original/1YS0_MevDN42ZwSkEInaDrtBpE32pICzvA.png?1725903831)

## 이메일 브로드캐스트 옮기기

ConvertKit의 이메일 브로드캐스트는 하이퍼클래스의 이메일 캠페인과 비슷해요. 하이퍼클래스에서 브로드캐스트를 다시 만들어 이메일 마케팅을 이어 갈 수 있어요.

### 1단계: 이메일 브로드캐스트 정리하기

- 브로드캐스트 목록 만들기: ConvertKit에서 보낸 이메일 브로드캐스트의 제목, 이메일 내용, 수신 대상 세그먼트를 정리해 두세요.
- 이메일 템플릿 보관하기: ConvertKit 브로드캐스트에 쓴 이메일 템플릿이 있다면 사본을 저장해 두세요.

### 2단계: 하이퍼클래스에서 이메일 브로드캐스트 다시 만들기

- 이메일 캠페인 열기: 하이퍼클래스에서 **마케팅 > 이메일 캠페인**으로 이동하세요.
- 새 캠페인 만들기: **새 캠페인 만들기**를 클릭하고, ConvertKit의 내용과 디자인을 그대로 살려 브로드캐스트를 설정하세요.
- 수신 대상 나누기: 가져온 태그와 세그먼트로 브로드캐스트를 받을 대상을 정하세요.
- 예약하거나 보내기: 바로 보낼지, 나중으로 예약할지 선택하세요.

### 3단계: 옮긴 뒤 확인하기

- 테스트 이메일 보내기: **테스트 이메일 전송**으로 디자인과 내용을 확인하세요. 여러 이메일 클라이언트에서 올바르게 표시되는지도 살펴보세요.

## 커머스 기능 옮기기

ConvertKit에는 디지털 상품과 구독 결제를 관리하는 도구가 있어요. 하이퍼클래스의 결제 연동 기능으로도 비슷하게 운영할 수 있고, 마케팅·CRM 기능과 함께 쓸 수 있어요.

### 1단계: 커머스 상품 정리하기

- 상품 목록 만들기: ConvertKit에 설정한 디지털 상품과 구독을 모두 정리해 두세요. 가격, 상품 전달 방식, 연결된 자동화를 함께 적어 두세요.
- 상품 상세 정보 기록하기: 각 상품의 URL, 사용자 지정 도메인, 설정을 기록해 두세요.

### 2단계: 하이퍼클래스에서 커머스 상품 다시 만들기

- 주문 폼 열기: 하이퍼클래스에서 **사이트 > Order Forms**(주문 폼)로 이동해 새 상품 페이지나 주문 폼을 만드세요.
- 상품 가격 설정하기: ConvertKit에서 쓰던 가격 방식을 그대로 설정하세요. 일회성 결제, 구독, 할부 결제가 있어요.
- 상품 전달 설정하기: 디지털 상품 전달이나 구독 관리를 설정해, 구매하면 고객이 상품을 자동으로 받도록 하세요.
- 워크플로우 연결하기: 상품 구매를 후속 이메일, 업셀, 고객 세분화 워크플로우와 연결하세요.

### 3단계: 옮긴 뒤 확인하기

- 구매 과정 테스트하기: 테스트 구매를 해서 결제가 제대로 처리되고 상품이 의도대로 전달되는지 확인하세요.

## ConvertKit 데이터 내보내기

완전히 전환하기 전에 ConvertKit의 중요한 데이터를 꼭 내보내 두세요. 구독자 목록과 참여 지표 같은 데이터는 참고용으로 보관하거나 하이퍼클래스로 가져올 수 있어요.

### 1단계: 구독자 목록 내보내기

- 내보내기 메뉴 찾기: ConvertKit에서 **Subscribers > Grow**로 이동해 **Bulk Actions** 메뉴 아래 **Export**를 선택하세요.
- 내보낸 파일 받기: 내보낸 파일은 이메일로 전송되며, ConvertKit 계정에서 직접 내려받을 수도 있어요.

### 2단계: 내보낸 데이터 검토하기

- 데이터 확인하기: 내보낸 CSV 파일을 열어, 구독자 정보, 태그, 참여 지표, 커스텀 필드 등 필요한 정보가 정확히 들어 있는지 확인하세요. 이 데이터는 하이퍼클래스에서 전략을 세우는 데 참고하거나 백업용으로 쓸 수 있어요.

### 3단계: 하이퍼클래스로 데이터 가져오기 (선택)

- 추가 데이터 가져오기: 필요하다면 구독자 외의 추가 데이터도 하이퍼클래스로 가져올 수 있어요. ConvertKit에서 내보낸 태그, 참여 점수, 커스텀 필드 데이터가 그 예예요.
- 추가 데이터 필드 설정하기: ConvertKit의 커스텀 필드나 고유한 데이터 유형이 하이퍼클래스에서 제대로 매핑되고 다시 만들어졌는지 확인하세요.

### 4단계: 옮긴 뒤 확인하기

- 데이터 대조하기: 가져온 뒤 하이퍼클래스의 데이터를 ConvertKit 데이터와 대조해, 모든 구독자 정보와 태그가 정확히 들어왔고 차이가 없는지 확인하세요.

## 추가로 고려할 점

### 교육과 지원

- 팀 내부 교육: ConvertKit와 다른 기능을 중심으로 팀원에게 하이퍼클래스 사용법을 교육하세요. 하이퍼클래스의 CRM 기능, 멀티채널 마케팅 옵션, 자동화 워크플로우 이해가 포함될 수 있어요.
- 지원 채널 안내: 이전 중이나 이후에 문제가 생겼을 때 하이퍼클래스 고객지원과 도움말 문서를 어떻게 이용하는지 팀원이 알고 있는지 확인하세요.

### 지속적인 모니터링

- 성과 모니터링: 하이퍼클래스에서 이메일 캠페인, 자동화, 랜딩 페이지의 성과를 정기적으로 확인하세요. 기대한 만큼, 혹은 ConvertKit에서보다 잘 나오는지 살펴보세요.
- 설정 최적화: 하이퍼클래스의 리포팅과 분석 도구로 개선할 부분을 찾으세요. 이메일 전달률, 자동화 효과, 리드 전환율 등이 해당돼요.

### 백업과 데이터 보관

- 백업 유지: 이전이 끝난 뒤에도 ConvertKit 데이터 백업을 보관하세요. 데이터에 차이가 생기거나 나중에 참고해야 할 때 과거 데이터를 볼 수 있어요.
- 데이터 보관 정책: 하이퍼클래스의 데이터 보관 정책이 비즈니스 요구와 규정 준수 요건에 맞는지 검토하세요.

## 자주 묻는 질문

### ConvertKit의 Visual Automations를 하이퍼클래스로 옮기려면 어떻게 하나요?

ConvertKit에서 각 Visual Automation의 시작 조건(트리거), 액션, 이벤트, 조건을 정리하고, 흐름을 스크린샷이나 메모로 남기세요. 하이퍼클래스에서 **자동화 > 워크플로우**로 이동해 ConvertKit 자동화와 같은 새 워크플로우를 만드세요. 같은 역할의 트리거를 설정하고 액션과 조건을 추가한 뒤, 모든 단계가 제대로 동작하는지 테스트하세요.

### ConvertKit에서 구독자를 내보내려면 어떻게 하나요?

ConvertKit에서 **Subscribers > Grow**로 이동해 맨 위 체크박스를 클릭하고 모든 구독자를 선택하세요. 구독자가 30명보다 많다면 파란색 바의 링크를 클릭해 확정하세요. 그다음 **Bulk Actions > Export**를 선택하세요. 파일은 계정 소유자의 이메일로 전송되며, ConvertKit에서 직접 내려받을 수도 있어요.

### ConvertKit 구독자를 하이퍼클래스로 가져오려면 어떻게 하나요?

하이퍼클래스에서 **연락처 > Import Contacts**(연락처 가져오기)로 이동해 ConvertKit에서 내보낸 CSV 파일을 올리세요. CSV의 항목을 하이퍼클래스의 알맞은 필드(예: 이름, 성, 이메일, 태그)에 매핑하고, 태그 정보를 활용해 비슷한 세그먼트를 만드세요. 가져온 뒤에는 모든 데이터가 제대로 매핑되고 분류되었는지 확인하세요.

### ConvertKit 폼을 하이퍼클래스에서 다시 만들려면 어떻게 하나요?

ConvertKit 폼의 필드, 디자인, 설정, 커스텀 필드를 먼저 정리하세요. 하이퍼클래스에서 **사이트 > 폼**으로 이동해 같은 필드로 새 폼을 만들고, 디자인을 원래 폼과 비슷하게 맞추세요. 리디렉션, 확인 이메일, 태그 같은 폼 액션을 설정하고 해당 워크플로우와 연결하세요. 각 폼을 테스트해 데이터가 저장되고 워크플로우가 시작되는지 확인하세요.

### ConvertKit 랜딩 페이지를 하이퍼클래스로 옮기려면 어떻게 하나요?

ConvertKit에서 각 랜딩 페이지의 템플릿, 콘텐츠, 이미지, 도메인 설정을 정리하세요. 하이퍼클래스에서 **사이트 > 퍼널/웹사이트**로 이동해 비슷한 템플릿으로 새 랜딩 페이지를 만들고, 콘텐츠와 디자인을 다시 구성하세요. 하이퍼클래스에서 만든 폼을 삽입하고 사용자 지정 도메인을 설정하세요. 각 랜딩 페이지를 미리 보고 테스트해 모든 요소가 제대로 동작하는지 확인하세요.

### 이메일 브로드캐스트를 하이퍼클래스에서 다시 만들려면 어떻게 하나요?

ConvertKit 이메일 브로드캐스트의 제목, 내용, 수신 대상 세그먼트를 정리하고 이메일 템플릿 사본을 저장하세요. 하이퍼클래스에서 **마케팅 > 이메일 캠페인**으로 이동해 내용과 디자인을 그대로 살린 새 캠페인을 만드세요. 가져온 태그로 수신 대상을 정한 뒤 바로 보내거나 예약하세요. 테스트 이메일을 보내 여러 이메일 클라이언트에서 올바르게 표시되는지 확인하세요.

### 디지털 상품과 커머스 기능을 옮기려면 어떻게 하나요?

ConvertKit의 모든 디지털 상품이나 구독을 가격, 상품 전달 방식, 연결된 자동화와 함께 정리하세요. 하이퍼클래스에서 **사이트 > Order Forms**(주문 폼)로 이동해 새 상품 페이지를 만들고, 가격 방식을 다시 설정하세요. 디지털 상품 전달이나 구독 관리를 설정하고, 상품 구매를 워크플로우와 연결하세요. 구매 과정을 테스트해 결제 처리와 상품 전달이 제대로 되는지 확인하세요.

### 이전을 마치기 전에 ConvertKit에서 어떤 데이터를 내보내야 하나요?

ConvertKit에서 전체 구독자 목록을 내보내세요(**Subscribers > Grow**에서 **Bulk Actions** 아래 **Export**). 내보낸 CSV에 구독자 정보, 태그, 참여 지표, 커스텀 필드가 모두 들어 있는지 확인하세요. 이 데이터는 하이퍼클래스 운영 전략에 참고하거나 백업용으로 쓸 수 있어요. 캠페인 성과 지표처럼 과거 기록으로 남기고 싶은 데이터가 있다면 함께 내보내 두는 것도 좋아요.

### 이전한 뒤 제대로 동작하는지 어떻게 확인하나요?

테스트 연락처를 워크플로우에 통과시켜 모든 자동화 단계가 제대로 동작하는지 확인하세요. 가져온 연락처는 데이터가 제대로 매핑되었는지 살펴보세요. 폼에 테스트 데이터를 제출해 데이터가 저장되는지 확인하세요. 랜딩 페이지는 미리 보고 기능을 테스트하세요. 테스트 이메일을 보내 표시 상태를 확인하세요. 테스트 구매로 결제 처리와 상품 전달이 제대로 되는지 확인하세요. 마지막으로 하이퍼클래스의 모든 데이터를 ConvertKit에서 내보낸 데이터와 대조하세요.

### 하이퍼클래스로 옮긴 뒤 계속 신경 써야 할 점은 무엇인가요?

팀원이 하이퍼클래스의 기능, 특히 ConvertKit와 다른 기능을 익힐 수 있도록 교육하세요. 하이퍼클래스 고객지원을 어떻게 이용하는지도 알려 주세요. 이메일, 자동화, 랜딩 페이지의 성과를 정기적으로 확인하고, 하이퍼클래스의 리포팅 도구로 개선할 부분을 찾으세요. ConvertKit 데이터 백업은 과거 기록용으로 보관하고, 하이퍼클래스의 데이터 보관 정책이 비즈니스 요구와 규정 준수 요건에 맞는지 검토하세요.
