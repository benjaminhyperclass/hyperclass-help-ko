# 하이퍼클래스 고객지원 통화에서 Zoom 문제 해결하기

하이퍼클래스 고객지원 팀과 Zoom으로 연결할 때 생기는 흔한 문제를 해결하는 방법을 안내해요. 소리가 안 들리거나, 카메라가 안 켜지거나, 화면 공유와 주석 기능이 안 될 때 확인해 보세요.

## Zoom 문제란?

Zoom 문제가 생기면 하이퍼클래스 고객지원 담당자와 대화하기 어렵거나, 도움이 필요한 문제를 제대로 보여 주기 어려워요.

자주 겪는 문제는 다음과 같아요.

- 마이크가 작동하지 않아요.
- 스피커나 오디오 출력에 문제가 있어요.
- 카메라가 작동하지 않아요.
- 화면 공유가 실패해요.
- 주석 도구를 사용할 수 없어요.

---

## 오디오·비디오 문제 해결하기

Zoom 오디오에 연결되지 않거나, 스피커 소리가 들리지 않거나, 비디오를 켤 수 없다면 아래 순서대로 해 보세요.

### 1. 소회의실로 이동하기

1. 회의 중에 문제가 생기면 현재 회의실에서 나와 소회의실로 이동해 보세요.
2. 소회의실에 들어간 뒤 메인 회의실에 다시 입장하세요. 이렇게 하면 오디오와 비디오 설정이 초기화되는 경우가 많아요.

![소회의실로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032253312/original/0VyVYcylOdMLCikLOW0iOMAN4uX4LYxoIQ.jpg?1725461782)

### 2. 마이크와 스피커 설정 확인하기

1. Zoom 앱 왼쪽 아래의 마이크 아이콘을 클릭하세요.
2. 마이크 아이콘에 줄이 그어져 있거나 음소거 상태라면 클릭해서 음소거를 해제하세요.
3. 마이크 아이콘 옆의 위쪽 화살표를 클릭해 오디오 설정을 열고, 올바른 마이크와 스피커가 선택되어 있는지 확인하세요.

![마이크 아이콘과 음소거 해제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032253408/original/858452rHn2UsgUKqPntr3Ntmb6FZr2rjrQ.jpg?1725461830)![마이크와 스피커 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032253480/original/GFkTM6xTv7wwWRQwqsLOGxYejyGXVWtn-Q.jpg?1725461892)

### 3. 오디오 연결을 끊었다가 다시 연결하기

1. 마이크 아이콘 옆의 위쪽 화살표를 클릭하세요.
2. **Leave Computer Audio**(컴퓨터 오디오 나가기)를 선택하세요.
3. 팝업이 나타나면 **Join Audio**(오디오 참가)를 다시 클릭해서 오디오 연결을 초기화하세요.

![컴퓨터 오디오 나가기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032253576/original/ub6DaSfxxFxMlZYM9fAXtoLHwZpE2-nX-Q.jpg?1725461933)

### 4. 마이크와 스피커 테스트하기

1. 마이크 옆의 위쪽 화살표를 클릭하고 **오디오 설정**을 선택하세요.
2. **Test Mic**(마이크 테스트)를 클릭하세요. 마이크에 대고 말하면서 오디오 미터가 움직이는지 확인하세요.
3. **Test Speaker**(스피커 테스트)를 클릭하세요. 테스트 소리가 나오면 스피커가 정상으로 작동하는 거예요.

![오디오 설정에서 마이크·스피커 테스트하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032253581/original/eT9aF1RegMQvybRfye-UcYtbJ3gEo8XfpQ.jpg?1725461941)

### 5. 기기 연결 상태 확인하기

1. 마이크나 스피커가 Bluetooth 헤드폰 같은 다른 기기에 연결되어 있지 않은지 확인하세요.
2. 컴퓨터 설정에서 Zoom에 맞는 입력·출력 장치가 선택되어 있는지 확인하세요.

### 6. Zoom 다시 시작하기

간단히 다시 시작하는 것만으로 일시적인 오류가 해결될 때가 있어요. Zoom을 완전히 종료한 뒤 다시 실행하세요.

### 7. Zoom 테스트 페이지 이용하기

Zoom 테스트 페이지에서 마이크, 스피커, 비디오 설정이 제대로 작동하는지 확인할 수 있어요. [Zoom 테스트 페이지 바로가기](https://zoom.us/test)

## 화면 공유 문제 해결하기

화면을 공유할 수 없거나 상대방이 내 화면을 볼 수 없다면 아래 방법을 차례로 시도해 보세요.

### 1. 소회의실로 이동하기

화면 공유 문제가 계속되면 소회의실로 이동했다가 메인 회의실로 돌아와 보세요. 세션이 새로 고쳐지면서 문제가 해결될 수 있어요.

![화면 공유 문제 시 소회의실로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032253644/original/gnGFsQqUuT3ZSP5QY0W8xu8xCoQX1zXTSQ.jpg?1725461983)

### 2. 화면 공유 설정 확인하기

1. Zoom 창 아래쪽의 **Share Screen**(화면 공유) 버튼을 클릭하세요.
2. 공유할 화면이나 애플리케이션 창을 올바르게 선택했는지 확인하세요.

![화면 공유 버튼과 공유할 화면 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032253928/original/xx_kipcKZiB74BFkWi8oXgeST6FOy_Aj4Q.jpg?1725462133)

### 3. 권한 확인하기

- Windows: Zoom 앱에 화면을 녹화하고 공유할 권한이 있는지 확인하세요.
- Mac: **System Preferences**(시스템 환경설정) > **Privacy & Security**(개인정보 보호 및 보안) > **Accessibility**(손쉬운 사용) 탭으로 이동해서 **Zoom**을 켜세요.

![Mac 손쉬운 사용에서 Zoom 권한을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032194104/original/aPWLHOr1baOR10YUN7EAQCoMrTpZKm7R6Q.png?1725406965)

### 4. 화면 공유 다시 시작하기

1. 화면 공유가 되지 않으면 화면 위쪽의 **Stop Share**(공유 중지)를 클릭하세요.
2. 몇 초 기다린 뒤 **Share Screen**(화면 공유)을 다시 클릭해서 처음부터 시작하세요.

### 5. TCP 연결 켜기

1. Zoom 데스크톱 클라이언트를 열고 **설정** > **Share Screen**(화면 공유)으로 이동하세요.
2. 아래로 스크롤해서 **고급** 섹션에서 **Enable TCP connection**(TCP 연결 사용)을 켜세요. 화면 공유가 더 안정적으로 작동해요.

![Zoom 설정에서 TCP 연결을 켜는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032194010/original/Z7qsEJQEB3TeVGayCgp6luTEcxggFggelA.gif?1725406587)

### 6. 네트워크 연결 확인하기

1. 인터넷 연결이 안정적인지 확인하세요. 연결이 불안정하거나 약하면 화면 공유가 끊기거나 실패할 수 있어요.
2. fast.com이나 speedtest.net에서 속도를 측정해 보세요. Zoom을 원활하게 쓰려면 최소 50mbps가 필요해요.

### 7. Zoom 업데이트하기

Zoom 애플리케이션을 최신 버전으로 업데이트하세요. 오래된 버전은 최신 기능을 지원하지 않거나 화면 공유에 영향을 주는 버그가 있을 수 있어요.

![Zoom 업데이트 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032193927/original/DrCZ9OOIj8qHFmhbm0-lCKaDu0RCg-8jHA.png?1725406340)

## 주석 기능 문제 해결하기

주석 기능은 고객지원 담당자가 공유된 화면에 표시를 그려서, 다음에 해야 할 단계를 안내할 때 쓰는 도구예요. 현재 Zoom은 회의에 참가할 때 데스크톱 앱(설치 후)에서만 주석 기능을 지원해요.

Zoom 데스크톱 앱을 열려면 **ALLOW**(허용)를 선택해서 zoom.us가 데스크톱 앱을 실행하도록 하세요. 그래야 Zoom 기능을 제대로 쓸 수 있어요.

![데스크톱 앱 실행을 허용하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155032257661/original/jrqQpTsxJsiPVQOAe_lMqTw4FLHXyyqSFw.png?1725464822)

브라우저에서 Zoom을 쓰다가 화면에 주석을 달 수 없다면 아래 방법을 시도해 보세요.

### Zoom 앱 다시 설치하기

1. Zoom 앱을 다운로드하세요: <https://zoom.us/download>
2. 설치가 끝나면 앱에서 Zoom 회의실에 다시 입장하세요.
3. 이 단계를 해도 문제가 계속되면 언제든 문의해 주세요.

## 자주 묻는 질문

### 문제를 해결하려면 왜 소회의실로 이동해야 하나요?

소회의실로 이동했다가 메인 세션으로 돌아오면 Zoom이 세션을 새로 고쳐요. 그래서 오디오, 비디오, 화면 공유 설정이 초기화될 수 있어요. Zoom을 다시 시작하지 않고도 세션 관련 오류를 빠르게 해결할 수 있는 방법이에요.

### 앞으로 회의에서 Zoom 오디오·비디오 문제가 반복되지 않게 하려면 어떻게 하나요?

Zoom 앱을 최신 버전으로 유지하고, 마이크와 카메라 연결을 자주 확인하세요. 회의를 시작하기 전에 Zoom 테스트 페이지에서 미리 테스트해 보면 좋아요. 안정적인 인터넷 연결도 문제를 막는 데 큰 역할을 해요.

### 회의 중에 화면 공유가 끊기거나 느려져요. 왜 그런가요?

인터넷 연결이 약하거나 불안정하면 화면 공유 성능에 영향을 줄 수 있어요. 특히 같은 네트워크의 다른 프로그램이나 다른 사람이 대역폭을 쓰고 있을 때 그래요. 인터넷 속도를 확인하고, Zoom 통화 중에는 대역폭을 많이 쓰는 다른 프로그램을 닫아 보세요.

### Mac과 Windows처럼 운영체제에 따라 Zoom 설정이 다른가요?

네, 달라요. 특히 화면 공유나 마이크·카메라 접근에 필요한 개인정보 및 보안 권한이 운영체제마다 조금씩 달라요. Zoom에 필요한 권한을 허용할 때는 항상 사용 중인 운영체제에 맞는 안내를 다시 확인하세요.

### Zoom은 왜 자주 업데이트해야 하나요? 업데이트하지 않으면 어떻게 되나요?

Zoom은 기능, 보안, 새 기능과의 호환성을 개선하려고 업데이트를 자주 내놓아요. 정기적으로 업데이트하지 않으면 중요한 수정 사항과 새 기능을 놓칠 수 있어요. 오디오, 비디오, 화면 공유 문제를 포함해 Zoom 성능이 떨어질 수도 있어요.

### Zoom을 다시 시작하면 왜 대부분의 문제가 해결되나요?

Zoom을 다시 시작하면 임시 캐시 파일이 삭제되고, 앱이 컴퓨터 하드웨어(마이크, 카메라 등)와 연결을 새로 맺어요. Zoom 서버와의 연결도 깨끗하게 다시 만들어져서, 일시적인 오류로 생긴 많은 문제가 해결될 수 있어요.

### 중요한 회의 전에 화면 공유가 잘 되는지 확인하려면 어떻게 하나요?

회의 전에 Zoom의 테스트 회의 기능으로 화면 공유를 미리 해 보세요. 모든 것이 원활하게 작동하는지 확인할 수 있어요. 또 화면 공유에 필요한 시스템 권한을 확인하고, 다른 애플리케이션이 카메라나 마이크를 쓰고 있지 않은지도 살펴보세요.

### Zoom을 다시 설치해도 문제가 해결되지 않으면 어떻게 하나요?

다시 설치해도 해결되지 않으면 시스템 호환성이나 네트워크 문제일 수 있고, Zoom 설정 자체에 더 깊은 문제가 있을 수도 있어요. 이럴 때는 Zoom 고객지원에 문의하거나, 하이퍼클래스의 에스컬레이션 절차에 따라 문제를 올리세요.

### 네트워크 연결이 Zoom 문제의 원인인지 어떻게 알 수 있나요?

[speedtest.net](http://www.speedtest.net) 같은 사이트에서 인터넷 속도를 측정해 보세요. 다운로드와 업로드 속도가 50mbps보다 낮거나 연결이 불안정하다면(속도가 자주 떨어진다면) 오디오, 비디오, 화면 공유 문제의 원인일 수 있어요.

### Zoom에서 화면에 주석을 달 수 없어요. 왜 그런가요?

브라우저 버전을 쓰고 있거나 앱이 오래된 버전이면 Zoom 주석 기능이 작동하지 않을 수 있어요. Zoom 데스크톱 앱을 최신 버전으로 설치했는지 확인하고, 회의 설정에서 주석이 켜져 있는지도 확인하세요.

### Zoom에서는 누구와 이야기할 수 있나요?

Zoom으로 하이퍼클래스 공식 고객지원 담당자와 이야기할 수 있어요.

- Zoom 세션은 실시간 도움이 필요한 인증된 고객이 이용할 수 있어요.
- 이 세션은 문제 해결, 설정 지원, 기술 안내를 위한 거예요.
