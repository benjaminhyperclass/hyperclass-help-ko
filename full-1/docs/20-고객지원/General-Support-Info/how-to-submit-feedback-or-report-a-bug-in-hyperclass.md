# 하이퍼클래스에 피드백 보내기·버그 신고하기

피드백을 보내거나 기술 문제를 신고할 때 **클릭하여 업로드**를 누르면, 전체 화면이 고해상도 이미지로 자동 캡처돼요. 고객지원팀이 문제 상황을 정확히 보고 더 빨리 원인을 찾을 수 있어요. 추가로 물어보는 일도 줄어들어요.

## 개요

하이퍼클래스에서는 플랫폼 안에서 바로 피드백을 보내거나 버그를 신고할 수 있어요. 문제를 더 정확히 파악할 수 있도록, 첨부파일을 추가하는 순간 전체 화면 이미지가 자동으로 캡처돼요.

덕분에 고객지원팀과 제품팀은 문제가 생겼을 때 화면에 무엇이 보였는지 그대로 확인할 수 있어요.

## 피드백·버그 신고 화면 여는 방법

피드백을 보내거나 기술 문제를 신고하려면 다음 순서대로 진행하세요.

1. 하이퍼클래스에서 아무 페이지나 엽니다.
2. 오른쪽 위에 있는 **도움말 및 지원** 아이콘을 클릭합니다.

   ![도움말 및 지원 아이콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067027237/original/F7g41M81EDDNU_z_lQcJgUtqU9oHnJnGwA.png?1773667862)
3. **티켓 생성**을 선택해 문의를 시작합니다.

   ![티켓 생성 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067027269/original/dYGTTAu4eOoZUbC3YiWLOUkmoEUStRGFUA.png?1773667878)

## 기술 지원으로 접수하기

티켓을 시작하면 요청을 알맞은 곳으로 전달하기 위해 간단한 질문이 몇 가지 나올 수 있어요.

1. **Technical Support**(기술 지원)를 선택합니다.
2. 범위를 묻는 화면이 나오면 해당하는 항목을 고릅니다. 예를 들면 **Within a Sub-Location**(서브 계정 안에서)이 있어요.
3. 문제와 관련된 제품 영역을 선택합니다. 예를 들면 캘린더, 자동화, 대화가 있어요.

이 과정이 끝나면 문제 접수 폼이 열려요.

## 업로드할 때 화면 자동 캡처

문제 접수 폼에서 **클릭하여 업로드**를 클릭하면 다음과 같이 동작해요.

- 전체 화면이 고해상도 이미지로 자동 캡처돼요.
- 업로드를 시작하는 즉시 캡처돼요.
- 따로 설정하거나 추가로 할 일은 없어요.

이 과정은 백그라운드에서 실행되고, 스크린샷은 신고 내용에 바로 첨부돼요.

### 화면 캡처 방식

- 캡처는 **클릭하여 업로드**를 선택했을 때만 실행돼요.
- 현재 창만이 아니라 전체 화면이 캡처돼요.
- 처음 사용할 때는 화면 접근을 허용하라는 브라우저 권한 창이 나올 수 있어요.

![화면 접근 권한을 묻는 브라우저 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064211407/original/jWw69h8oc7BI0x12C05zG3rxAX3aPKOVwQ.png?1770230544)

권한을 허용하면 캡처가 자동으로 완료돼요.

### 스크린샷 첨부 완료

화면 캡처가 끝나면 다음과 같이 표시돼요.

- 접수 폼에 캡처한 이미지가 첨부파일로 나타나요.
- 파일이 정상적으로 추가됐다는 표시가 보여요.
- 스크린샷은 피드백이나 버그 신고와 함께 전달돼요.

![스크린샷이 첨부된 접수 폼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064211417/original/dfK4Sq_6vS8c3jFUYPyxo9fz7xwDho7tJQ.png?1770230560)

### 전체 화면 캡처가 도움이 되는 이유

전체 화면을 자동으로 캡처하면 다음과 같은 점이 좋아요.

- 고객지원팀과 주고받는 문의가 줄어요.
- 원인을 조사하고 해결하는 속도가 빨라져요.
- 일부만 캡처했을 때 빠질 수 있는 화면 정보까지 담겨요.
- 복잡한 문제도 더 정확하게 진단할 수 있어요.

## 자주 묻는 질문

### 화면 캡처가 자동으로 되나요?

네. **클릭하여 업로드**를 클릭하면 자동으로 캡처돼요.

### 화면의 어느 부분이 캡처되나요?

전체 화면이 고해상도로 캡처돼요.

### 특정 창만 골라서 캡처할 수 있나요?

아니요. 문제를 진단하는 데 필요한 정보를 빠짐없이 담기 위해 전체 화면을 캡처해요.

### 버그 신고할 때만 쓰는 기능인가요?

아니요. 피드백을 보내거나 기술 문제를 신고할 때 **클릭하여 업로드**를 사용하면 적용돼요.
