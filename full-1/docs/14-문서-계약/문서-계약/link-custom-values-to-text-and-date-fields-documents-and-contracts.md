# 문서 & 계약에서 텍스트·날짜 필드를 커스텀 값에 연결하기

**문서 & 계약**에서 텍스트 필드와 날짜 필드를 커스텀 값에 연결하는 방법을 안내해요. 연결해 두면 문서에 서명이 끝나는 순간 입력된 값이 연락처나 문서 기록에 자동으로 반영돼요.

[동영상 보기](https://www.youtube.com/embed/kKWMflVSBlo?&wmode=opaque)

## 새로 추가된 기능

- 텍스트 필드와 날짜 필드 연결: **문서 & 계약**에서 텍스트 필드와 날짜 필드를 연락처 **커스텀 값**에 연결할 수 있어요.
- 유연한 연결: 문서 안의 필드를 연락처용 **커스텀 값**이나 문서용 **커스텀 값**에 연결할 수 있어요.
- 자동 업데이트: 문서에 서명이 끝나면 연결된 필드의 값이 연락처 또는 문서 기록에 자동으로 업데이트돼요.
- CSV 다운로드: 대시보드에서 입력된 필드 전체를 CSV로 내려받아 더 쉽게 확인하고 관리할 수 있어요.

## 사용 방법

1. 필드를 커스텀 값에 연결해요.
   - **문서 & 계약**에서 편집기를 열고 새 문서를 만드세요.
   - 텍스트 필드나 날짜 필드를 필요한 위치로 끌어다 놓으세요.
2. 수신자를 추가하고 필드를 연결해요.
   - 수신자를 추가한 뒤, 텍스트 필드와 날짜 필드 위쪽에 있는 링크 버튼을 선택하세요.
   - 필요하면 필드 하나를 여러 **커스텀 값**에 연결할 수도 있어요.
     ![필드 위쪽의 링크 버튼을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035132379/original/7OdiSIB72acguIpPpirraczLFYwIFuCOSg.jpeg?1729544008)
     ![필드에 연결할 커스텀 값을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035132400/original/iiTQSuWMQkifww3-yeNVmSEEsHEXNn3VTQ.png?1729544080)
     ![필드 하나를 여러 커스텀 값에 연결한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035132405/original/fY_EghSq-U8Wc75OzAOCCNdGRrpNgbOXlA.png?1729544095)
3. 서명이 끝나면 자동으로 업데이트돼요.
   - 수신자가 문서에 서명하면 연결된 필드의 값이 해당 기록(연락처 또는 문서)에 자동으로 업데이트돼요.
4. 입력된 필드 데이터를 내려받아요.
   - 문서에 입력된 필드를 한눈에 보려면 대시보드로 이동해 관련 데이터를 CSV로 다운로드하세요.

## 이 기능을 만든 이유

- 수동 업데이트 줄이기: 텍스트 필드와 날짜 필드를 **커스텀 값**에 연결해 두면, 서명 후에 값을 직접 고쳐 넣을 필요가 줄어요. 데이터가 연락처에 자동으로 동기화돼요.
- 편리한 데이터 관리: CSV로 내려받으면 입력된 필드의 데이터를 쉽게 관리하고 분석할 수 있어요. 문서 업무도 한결 간단해져요.

## 앞으로 추가될 기능

- 기회 커스텀 값 지원: 기회 **커스텀 값**까지 지원하도록 준비 중이에요.
