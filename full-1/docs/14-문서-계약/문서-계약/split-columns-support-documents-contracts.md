# 문서 & 계약에서 열 나누기 사용하기

문서 & 계약 편집기에서 요소를 나란히 놓아 열을 나누는 방법을 안내해요. 제안서나 계약서의 레이아웃을 더 깔끔하게 정리하고 싶을 때 쓰세요.

[동영상](https://www.youtube.com/embed/QyWJXWN3OK8?&wmode=opaque)

## 새로운 기능

- **문서 & 계약**에서 열 나누기 기능을 쓸 수 있어요.
- 요소를 끌어다 나란히 놓으면 열이 자동으로 만들어져요. 내용을 더 체계적으로 배치할 수 있어요.
- 정보가 보기 좋게 정리되어, 깔끔하고 전문적인 문서를 쉽게 만들 수 있어요.

## 사용 방법

문서 편집기에서 텍스트, 이미지, 표 같은 요소를 다른 요소 옆으로 끌어다 놓으세요. 열이 나뉜 레이아웃이 만들어져요.

![열 나누기 예시 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035132467/original/hW1vKYm1vAwkmOSnKjnQlo2B6c_Pc6L-MA.png?1729544179)![열 나누기 예시 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035132466/original/nORshbMzk0FJ-CjRzRA_l2wRUUcRI1RjZw.png?1729544178)

## 이 기능이 생긴 이유

- 문서를 디자인할 때 더 자유롭게 구성할 수 있도록 만든 기능이에요.
- 서식 옵션이 더 필요하다는 요구에 맞춰, 제안서와 계약서를 더 명확하고 체계적으로 만들 수 있게 했어요.
