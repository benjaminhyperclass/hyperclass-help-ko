# 같은 상위 계정의 서브 계정 간 전화번호 이동

**번호 이동** 도구를 쓰면 같은 상위 계정 아래 서브 계정끼리 이동 가능한 전화번호를 옮길 수 있어요. 고객이 이미 쓰는 번호를 그대로 유지한 채 관리하는 서브 계정만 바꿀 수 있어요.

## 개요

**번호 이동** 도구는 같은 상위 계정에 속한 서브 계정 사이에서 이동 가능한 전화번호를 옮겨 줘요. 호환되는 플랫폼 관리형 전화 환경끼리, 그리고 호환되는 연결 제공업체 환경끼리 이동할 수 있어요.

앱 안에서 쓰는 이동 기능은 현재 미국과 캐나다 번호만 지원해요. 다른 국가의 번호, 제공업체 전환, 지원하지 않는 제공업체 계정 구성은 별도의 이전 절차가 필요해요.

이 문서에서는 이동 가능 조건, 사전 준비, 이동 방법, 이동 후 달라지는 점과 확인할 내용을 안내해요.

{% hint style="warning" %}
전화번호를 옮겨도 서브 계정 단위의 메시지 등록, 연락처, 대화, 분석, 과거 통화 자료, 번호별 설정이 모두 함께 옮겨지지는 않아요. 이동이 끝나면 대상 서브 계정에서 규정 준수, 라우팅, 자동화, 배정 상태를 확인하세요.
{% endhint %}

## 번호 이동 도구란?

**번호 이동**은 같은 상위 계정 안에서 이동 가능한 전화번호의 담당을 **원본 서브 계정**에서 **대상 서브 계정**으로 바꿔 주는 계정 단위 도구예요. 번호를 다른 서브 계정에서 관리하고 싶을 때 새 번호를 구매하지 않아도 돼요.

플랫폼 관리형 번호는 호환되는 플랫폼 관리형 서브 계정끼리 이동할 수 있어요. 연결 제공업체 번호는 두 서브 계정이 같은 연결 제공업체 상위 계정에 속해 있을 때 이동할 수 있어요.

### 번호 이동 도구의 장점

같은 상위 계정 안에서 번호를 옮기면 기존 대표 번호를 바꾸지 않고도 번호 소유 구조를 빠르게 정리할 수 있어요. 시작하기 전에 이동 가능 조건을 확인하면 이동 실패나 잘못된 대상 지정을 막을 수 있어요.

- 기존 번호 유지: 고객이 이미 알고 있는 번호는 그대로 두고, 번호를 관리하는 서브 계정만 바꿔요.
- 앱 안에서 바로 이동: 같은 상위 계정 안에서 이동 가능한 번호는 별도 이전 요청 없이 직접 옮겨요.
- 여러 번호 한 번에 이동: 이동 가능한 번호 여러 개를 한 번에 옮길 수 있어요.
- 원본과 대상 직접 선택: 번호가 떠날 서브 계정과 도착할 서브 계정을 정확하게 고를 수 있어요.
- 이동 후 점검: 일반 트래픽을 다시 받기 전에 라우팅, 메시지 규정 준수, 워크플로우, 배정을 확인할 수 있어요.

### 이동 가능한 경우와 불가능한 경우

원본과 대상이 전화 시스템과 계정 조건을 충족해야만 **번호 이동**을 쓸 수 있어요. 앱에서 이동하기 전에 아래 표에서 내 상황을 먼저 확인하세요.

| 상황 | 앱에서 이동 | 해야 할 일 |
| --- | --- | --- |
| 플랫폼 관리형 → 플랫폼 관리형, 같은 상위 계정 | 가능 | **번호 이동**을 사용하세요. |
| 연결 제공업체 → 연결 제공업체, 같은 제공업체 상위 계정 | 가능 | **번호 이동**을 사용하세요. |
| 연결 제공업체 → 연결 제공업체, 서로 다른 제공업체 상위 계정 | 불가능 | 앱 도구로는 이동할 수 없어요. 연결 제공업체의 고객지원팀에 문의하세요. |
| 연결 제공업체 ↔ 플랫폼 관리형 전화 서비스 | 불가능 | 해당 제공업체 이전 절차를 이용하세요. |
| 미국·캐나다 번호 | 가능 (다른 조건을 충족할 때) | **번호 이동**을 사용하세요. |
| 미국·캐나다 외 번호 | 불가능 | 하이퍼클래스 고객지원에 문의하고, 해당하는 해외 번호 이전 절차를 따르세요. |
| 서로 다른 상위 계정의 서브 계정 | 불가능 | 계정 간 전화번호 이전 절차를 이용하세요. |

연결 제공업체와 플랫폼 관리형 전화 서비스 사이에서 번호를 바꾸는 것은 같은 계정 안의 이동이 아니에요. 이럴 때는 **번호 이동** 대신 해당 제공업체 이전 절차를 이용하세요.

## 번호를 옮기기 전에 준비할 것

계정 권한, 전화 시스템 호환 여부, 대상 서브 계정을 미리 확인하면 번호를 엉뚱한 서브 계정으로 옮기거나 지원하지 않는 구성을 만나는 일을 줄일 수 있어요.

- 원본과 대상 서브 계정 모두에 필요한 관리자 권한이 있어야 해요.
- 두 서브 계정이 같은 상위 계정에 속해 있는지 확인하세요.
- 번호가 플랫폼 관리형 전화 서비스인지 연결 제공업체인지 확인하세요.
- 연결 제공업체 번호라면 두 서브 계정이 같은 제공업체 상위 계정에 속해 있는지 확인하세요.
- 앱 안에서 이동하려면 번호가 미국 또는 캐나다 번호인지 확인하세요.
- 서브 계정 이름이 비슷하면 구분할 수 있도록 대상 서브 계정의 **위치 ID**를 미리 확인하세요.

### 대상 서브 계정의 위치 ID 확인하기

**위치 ID**는 서브 계정마다 고유한 값이라서 대상이 맞는지 확인할 때 도움이 돼요. 대상 서브 계정을 열고 **설정 > 비즈니스 프로필**로 이동하세요.

![위치 ID가 표시된 비즈니스 프로필 설정 화면](https://jumpshare.com/share/CXgGvlch4TfF6DNIAzet+/Screen+Shot+2026-08-14+at+18.07.40.png)

**위치 ID**는 해당 서브 계정의 **설정 > 비즈니스 프로필**에 표시돼요.

## 서브 계정 간 번호 이동 방법

먼저 원본과 대상 서브 계정을 고른 다음, 옮길 번호를 선택해요. 대상 서브 계정이 그 번호를 책임지게 되므로 선택한 내용을 꼼꼼히 확인하세요.

### 1단계: 번호 이동 도구 열기

**번호 이동**은 서브 계정의 전화 설정을 관리하는 계정 단위 전화 연동 설정에 있어요.

1. **설정**을 여세요.
2. **전화 연동**으로 이동하세요.
3. **서브 계정 설정** 탭을 여세요.
4. **번호 이동**을 클릭하세요.

![전화 연동의 서브 계정 설정 탭에서 번호 이동을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080069959/original/uIEXAa2LWuSqi63tMFiyBIBludQ3iuY1KA.png?1788504306)

**전화 연동 > 서브 계정 설정**을 열고 **번호 이동**을 선택하세요.

### 2단계: 원본과 대상 서브 계정 선택하기

원본은 지금 번호를 가지고 있는 서브 계정이고, 대상은 이동 후 번호를 가지게 될 서브 계정이에요.

1. **원본 서브 계정**을 선택하세요.
2. **대상 서브 계정**을 선택하세요.
3. 전화번호를 고르기 전에 두 선택이 맞는지 확인하세요.

### 3단계: 옮길 전화번호 선택하기

선택한 원본과 대상 구성에서 이동 가능한 번호만 목록에 나타나요. 현재 화면에서는 한 번에 최대 10개까지 전화번호를 선택할 수 있어요.

1. 옮기려는 전화번호 옆의 체크박스를 선택하세요.
2. 한 번에 최대 10개까지 선택하세요.
3. 선택한 번호와 대상 서브 계정을 다시 확인하세요.
4. **번호 이동**을 클릭하세요.

![원본·대상 서브 계정과 선택한 전화번호가 표시된 번호 이동 창](https://jumpshare.com/share/68hkKk2TK4agWb0yILt6+/Screen+Shot+2026-08-14+at+18.11.10.png)

원본, 대상, 이동 가능한 전화번호를 선택한 다음 **번호 이동**을 클릭하세요. 한 번에 최대 10개까지 선택할 수 있어요.

### 4단계: 대상 서브 계정에서 번호 확인하기

대상 서브 계정에 번호가 보이면 소유권이 바뀐 거예요. 그래도 일반 트래픽을 다시 받기 전에 라우팅, 메시지, 번호별 설정을 확인하세요.

1. 대상 서브 계정을 여세요.
2. 대상 서브 계정의 전화번호 목록에 해당 번호가 있는지 확인하세요.
3. 번호별 설정을 확인하세요.
4. 아래 이동 후 점검 목록을 따라 확인하세요.

## 번호를 옮기면 어떻게 되나요?

번호를 옮기면 번호를 관리하는 서브 계정이 바뀌어요. 하지만 모든 설정, 규정 준수 연결, 과거 자료가 대상 서브 계정에 자동으로 다시 만들어지지는 않아요. 부재중 전화나 메시지 발송 실패를 막으려면 이동 직후 대상 서브 계정을 확인하세요.

| 항목 | 예상 결과 | 해야 할 일 |
| --- | --- | --- |
| 전화번호 | 대상 서브 계정으로 이동해요. | 대상 서브 계정에 나타나는지 확인하세요. |
| A2P 10DLC | 등록 상태는 서브 계정에 연결되어 있어서 번호와 함께 이동하지 않아요. | 대상 서브 계정의 등록 상태를 확인하고, 번호를 승인된 적절한 캠페인에 연결하세요. |
| Toll-Free Verification(수신자 부담 번호 인증) | 번호와 함께 인증이 자동으로 옮겨진다고 가정하지 마세요. | 이동 후 번호의 인증 상태를 확인하세요. |
| 연락처, 대화, 분석 | 전화번호가 이동한다고 해서 함께 옮겨지지 않아요. | 필요하면 비즈니스 데이터를 따로 관리하거나 이전하세요. |
| 과거 녹음 및 음성 메시지 | 과거 자료는 전화번호와 함께 자동으로 이동하지 않아요. | 원본 서브 계정에 대한 접근 권한이 없어지기 전에 보관해야 할 자료를 내려받으세요. |

### 이동 후 점검 목록

간단히 점검해 보면 대상 서브 계정이 이동한 번호로 전화와 메시지를 받을 준비가 되었는지 알 수 있어요.

- 대상 서브 계정에 번호가 나타나는지 확인하세요.
- 착신 전환과 수신 전화 라우팅을 확인하세요.
- 통화 녹음, 음성 메시지, 콜 위스퍼 등 번호 관련 설정을 확인하세요.
- 사용자 배정을 확인하세요.
- 번호를 참조하는 워크플로우, 자동화, 캠페인 등을 확인하세요.
- 메시지를 쓴다면 A2P 10DLC 또는 Toll-Free Verification 상태를 확인하세요.
- 수신 및 발신 테스트 전화를 걸어 보세요.
- 메시지를 쓴다면 수신 및 발신 테스트 SMS를 보내 보세요.

## 문제 해결과 알려진 제한 사항

**번호 이동**이 보이지 않거나, 번호가 목록에 없거나, 이동에 실패하면 먼저 전화 환경, 제공업체 계정, 국가, 원본과 대상 구성을 확인하세요. 이 조건에 따라 앱 도구로 이동할 수 있는지가 정해져요.

### 연결 제공업체 상위 계정이 서로 다른 경우

서로 다른 연결 제공업체 상위 계정에 속한 번호는 앱의 **번호 이동** 도구로 옮길 수 없어요. 연결 제공업체의 고객지원팀에 문의하세요.

### 전화 환경이 맞지 않는 경우

연결 제공업체와 플랫폼 관리형 전화 서비스 사이를 전환하는 용도로 **번호 이동**을 쓰지 마세요. 해당하는 이전 절차를 이용하세요.

### 번호가 미국 또는 캐나다 외 지역인 경우

앱의 **번호 이동** 기능은 현재 미국과 캐나다 번호만 지원해요. 다른 국가의 번호는 하이퍼클래스 고객지원에 문의하세요.

### 해외 규정 구성이 없는 경우

해외 번호 이전에는 대상 서브 계정에 승인된 **규정 번들**과 Address SID가 필요할 수 있어요. 해당하는 해외 번호 이전 절차를 진행하기 전에 필요한 규정 설정을 먼저 완료하세요.

### 10개보다 많은 번호를 옮겨야 하는 경우

현재 화면에서는 한 번에 최대 10개까지만 선택할 수 있어요. 남은 번호는 이동 작업을 다시 진행하세요.

### 이동 가능한 번호인데도 계속 실패하는 경우

두 서브 계정이 같은 상위 계정에 있고, 호환되는 전화 환경을 쓰며, 번호가 다른 이동 조건도 충족하는데도 실패하면 하이퍼클래스 고객지원에 문의하세요. 문의할 때 원본 **위치 ID**, 대상 **위치 ID**, 해당 전화번호를 함께 알려 주세요.

## 자주 묻는 질문

### 한 번에 몇 개의 전화번호를 옮길 수 있나요?
현재 **번호 이동** 화면에서는 한 번에 최대 10개까지 옮길 수 있어요. 이동 가능한 번호가 더 있으면 이동 작업을 한 번 더 진행하세요.

### A2P 10DLC 등록도 전화번호와 함께 이동하나요?
아니요. A2P 상태는 전화번호뿐 아니라 서브 계정에 연결되어 있어요. 대상 서브 계정의 등록 상태를 확인하고, 이동한 번호를 승인된 적절한 캠페인에 연결하세요.

### Toll-Free Verification도 수신자 부담 번호와 함께 자동으로 이동하나요?
자동으로 이동한다고 가정하지 마세요. 이동 후 해당 번호의 인증 상태와 대상 서브 계정의 메시지 구성을 확인하세요.

### 연결 제공업체 번호도 서브 계정 간에 이동할 수 있나요?
네, 두 서브 계정이 같은 제공업체 상위 계정 아래 호환되는 연결 제공업체 번호를 쓰고, 나머지 **번호 이동** 조건도 충족하면 이동할 수 있어요.

### 서로 다른 제공업체 상위 계정 사이에서도 번호를 이동할 수 있나요?
앱의 **번호 이동** 도구로는 할 수 없어요. 서로 다른 제공업체 상위 계정 간 이동은 연결 제공업체의 고객지원팀에 문의하세요.

### 번호 이동으로 전화 제공업체를 바꿀 수 있나요?
아니요. 연결 제공업체와 플랫폼 관리형 전화 서비스 사이의 전환은 같은 제공업체 안에서 서브 계정만 바꾸는 이동이 아니라 제공업체 이전이에요.

### 연락처와 대화도 대상 서브 계정으로 함께 이동하나요?
아니요. 전화번호를 옮기면 번호의 배정만 바뀌어요. 연락처, 대화, 분석 데이터는 서브 계정 사이에서 이전되지 않아요.

### 앱의 번호 이동 도구는 어느 국가를 지원하나요?
현재는 미국과 캐나다 번호만 지원해요. 다른 국가의 번호는 하이퍼클래스 고객지원에 문의하세요.

## 도움이 필요하세요?

**번호 이동**이 보이지 않거나, 이동에 실패하거나, 옮긴 번호가 대상 서브 계정에서 제대로 작동하지 않으면 하이퍼클래스 고객지원에 문의하기 전에 아래 내용을 먼저 확인하세요.

### 문의하기 전에 확인할 것

- 원본과 대상 서브 계정이 같은 상위 계정 아래에 있는지 확인하세요.
- 두 서브 계정이 호환되는 전화 환경을 쓰는지 확인하세요.
- 연결 제공업체 번호라면 두 서브 계정이 같은 제공업체 상위 계정에 속해 있는지 확인하세요.
- 앱에서 이동하려는 번호가 미국 또는 캐나다 번호인지 확인하세요.
- 한 번에 10개 이하로 선택했는지 확인하세요.
- 이동 후 A2P 10DLC 또는 Toll-Free Verification 상태를 확인하세요.
- 통화 라우팅, 음성 메시지, 배정, 자동화를 확인하세요.
- 수신·발신 통화와 SMS를 테스트하세요.

### 그래도 해결되지 않을 때

이슈를 빠르게 확인할 수 있도록 하이퍼클래스 고객지원에 문의할 때 아래 정보를 함께 알려 주세요.

- 원본 위치 ID
- 대상 위치 ID
- 문제가 생긴 전화번호
- 번호가 플랫폼 관리형 전화 서비스인지 연결 제공업체인지
- 해당 번호의 국가
- 대상 서브 계정에 번호가 나타나는지 여부
- 수신·발신 통화가 되는지 여부
- 수신·발신 SMS가 되는지 여부
- 오류 메시지나 문제를 보여 주는 스크린샷
