# 하이퍼클래스 전화: 근무 시간에 따른 수신 전화 라우팅

근무 시간별 수신 전화 라우팅을 쓰면 사용자의 근무 일정 밖에는 업무 전화가 울리지 않아요. 이 문서에서 기능이 어떻게 동작하는지, 내 프로필과 팀원에게 어떻게 설정하는지, 근무 시간 외에 받은 전화를 하이퍼클래스가 어떻게 처리하는지 알아보세요.

## 근무 시간별 수신 전화 라우팅이란?

{% hint style="info" %}
이 설정은 기본적으로 꺼져 있어요. 직접 켜기 전에는 아무것도 달라지지 않아요.
{% endhint %}

이 기능은 선택한 근무 일정을 기준으로 수신 전화를 사용자에게 울릴지 정해요. 퇴근 후, 주말, 휴일, 자리를 비운 때에도 기기 설정을 바꾸거나 모바일 앱을 삭제하지 않고 업무 전화가 오지 않게 할 수 있어요.

**근무 시간에만 전화 울림**을 켜면, 선택한 일정 밖에 나에게 온 수신 전화는 나를 건너뛰고 전화번호에 설정된 기존 백업 처리로 넘어가요. 근무 시간에는 지금과 똑같이 전화가 울려요.

![근무 시간에만 전화 울림 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076517184/original/6hyNBeH53XiPEUxB3yiiJB5Q_rFEvmgHdA.png?1784648284)

## 이 기능의 장점

- 근무 시간 외 방해 방지: 선택한 근무 일정 밖에는 업무 전화가 울리지 않아요.
- 기존 가용성 일정 활용: 통화 설정을 직접 바꾸지 않고, 선택한 일정으로 수신 전화가 울리는 시간을 조절해요.
- 팀 단위 라우팅 지원: 지원되는 라우팅에서는 근무 시간 외인 사용자는 건너뛰고, 통화 가능한 다른 사용자에게는 계속 전화가 울려요.
- 휴일과 휴가 처리: 특정 날짜 항목을 일정에 넣으면 휴일이나 쉬는 날에 전화가 울리지 않아요.
- 기존 백업 라우팅 유지: 사용자가 근무 중이 아니면, 지원되는 통화는 전화번호의 기존 라우팅 또는 백업 설정으로 이어져요.

## 누가 설정할 수 있나요?

사용자가 자신의 가용성을 직접 설정하는지, 관리자가 다른 팀원의 가용성을 설정하는지에 따라 접근 권한이 달라요.

## 근무 시간 외 전화는 어떻게 라우팅되나요?

하이퍼클래스는 사용자에게 전화를 울리기 전에 선택한 일정을 확인해요. 결과는 수신 전화가 어떻게 라우팅되는지에 따라 달라요.

| 라우팅 상황 | 근무 시간 중 | 근무 시간 외 |
| --- | --- | --- |
| 배정된 사용자 또는 연락처 | 사용자에게 정상적으로 울려요 | 사용자를 건너뛰고, 통화는 기존 백업(음성사서함 또는 음성 AI)으로 이어져요 |
| **전체 호출** | 통화 가능한 모든 사용자에게 정상적으로 울려요 | 근무 시간 외인 사용자는 건너뛰고, 근무 중인 사용자에게는 계속 울려요 |
| 통화 메뉴 또는 IVR | 설정된 수신자에게 정상적으로 울려요 | 근무 시간 외인 사용자는 건너뛰고, 다른 수신자에게는 계속 울려요 |
| IVR 연결 단계의 유일한 수신자 | 사용자에게 정상적으로 울려요 | 연결되는 수신자가 없고, 통화 흐름이 다음 단계로 이어져요 |
| 전환된 통화 | 기존 전환 동작이 적용돼요 | 근무 시간 필터링은 현재 지원하지 않아요 |

## 근무 시간별 수신 전화 라우팅 설정하기

올바른 일정을 선택해야 하이퍼클래스가 언제 수신 전화를 연결할지 정확히 판단할 수 있어요. 근무 시간 외 라우팅에 쓰기 전에 그 일정의 주간 근무 시간, 특정 날짜 항목, 시간대를 확인하세요.

### 내 프로필에 설정하기

1. **설정**을 클릭하세요.

   ![설정 메뉴](https://jumpshare.com/share/Ku3XuD0iLcmYNkviMPjq+/Screen+Shot+2026-07-22+at+15.29.14.png)
2. **내 프로필**을 클릭하세요.
3. **수신 전화 라우팅** 카드까지 스크롤하세요.
4. **근무 시간에만 전화 울림**을 켜세요.
5. **전화 라우팅 일정** 드롭다운을 여세요.
6. 내 근무 시간을 정의한 일정을 **선택**하세요. 하이퍼클래스는 나에게 전화를 울리기 전에 여기서 선택한 일정을 확인해요. 선택한 내용은 자동으로 저장돼요.

   ![근무 일정 선택 과정](https://jumpshare.com/share/Sk5lEAcUmRHBZ1UPMwP6+/GIF+Recording+2026-07-22+at+15.32.47.gif)

### 팀원에게 설정하기

{% hint style="info" %}
아래 단계를 진행하는 관리자나 매니저에게는 **Manage calendars**(캘린더 관리) 권한이 있어야 해요.
{% endhint %}

1. **설정**을 클릭하세요.

   ![설정 메뉴](https://jumpshare.com/share/Ku3XuD0iLcmYNkviMPjq+/Screen+Shot+2026-07-22+at+15.29.14.png)
2. **스태프 관리**로 이동하세요.
3. 설정을 바꿀 팀원의 **편집 아이콘**을 클릭하세요.

   ![팀원 편집 아이콘](https://jumpshare.com/share/izl1zumovbJJ6KFVXVCc+/Screen+Shot+2026-07-22+at+15.41.57.png)
4. **사용자 가용성**을 선택하세요.
5. **수신 전화 라우팅** 카드를 찾으세요.
6. **근무 시간에만 전화 울림**을 켜세요.
7. 팀원의 근무 시간을 정의한 일정을 **선택**하세요.
8. 안내가 나오면 **저장**을 클릭해 팀원의 설정을 저장하세요.

   ![팀원 근무 일정 설정 과정](https://jumpshare.com/share/lHc2znfTkdwxxK2OzegU+/GIF+Recording+2026-07-22+at+15.43.43.gif)

## 착신 전환 번호는 어떻게 처리되나요?

사용자의 개인 번호가 설정된 착신 전환 번호 또는 업무용 전화번호와 같으면, 하이퍼클래스는 사용자의 근무 시간 외에 그 번호도 건너뛰어요. 이렇게 하면 다른 경로로 사용자에게 전화가 연결되는 일을 막고, 선택한 일정을 지킬 수 있어요.

## 알아 두어야 할 제한 사항

근무 시간 라우팅을 쓸 때 다음 제한 사항을 기억하세요.

- 전환된 통화는 현재 근무 시간으로 필터링하지 않아요. 통화가 사용자에게 전환되면 기존 전환 동작이 적용돼요.
- 근무 시간 라우팅은 근무 시간 외용 목적지를 따로 만들지 않아요. 사용자가 선택한 일정 밖에 받은 전화는 전화번호의 기존 라우팅 또는 백업 설정으로 이어져요.
- 이 설정은 사용자별로 적용돼요. 근무 시간 외에 전화를 받지 않아야 하는 사용자마다 알맞은 일정을 선택하고 설정을 켜야 해요.
- 일정 설정이 중요해요. 주간 근무 시간, 특정 날짜의 가용성, 일정의 시간대에 따라 하이퍼클래스가 사용자를 통화 가능한 상태로 볼지 정해져요.

## 자주 묻는 질문

### 설정을 켜지 않으면 달라지는 게 있나요?
아니요. 이 설정은 기본적으로 꺼져 있고, 켜기 전까지 통화 라우팅은 그대로예요.

### 하이퍼클래스는 어떤 일정을 사용하나요?
**전화 라우팅 일정** 드롭다운에서 선택한 일정을 사용해요. 선택한 일정은 언제든 바꿀 수 있어요.

### 휴일에 전화가 울리지 않게 하려면 어떻게 하나요?
선택한 일정에 해당 날짜의 특정 날짜 항목을 추가하고, 그 날짜에는 가능한 시간을 비워 두세요. 특정 날짜 항목은 그날 하루만 일반 주간 근무 시간보다 우선 적용돼요.

### 근무 시간 라우팅이 전환된 통화에도 적용되나요?
아직 적용되지 않아요. 이번 릴리스는 배정된 사용자, **전체 호출**, 통화 메뉴 또는 IVR 단계로 라우팅되는 수신 전화에 적용돼요. 전환된 통화는 현재 지원하지 않아요.

### 근무 시간 외 전화를 특정 팀원이나 내 개인 음성사서함으로 보낼 수 있나요?
이 버전에서는 안 돼요. 근무 시간 외에 받은 전화는 전화번호의 기존 백업 설정을 따라요.

### 설정을 켰는데도 근무 시간 외에 전화가 와요
다음을 확인해 보세요.

- 올바른 일정이 선택되어 있는지
- 현재 시간이 그 일정 밖인지
- 일정의 시간대가 맞는지
- 해당 사용자 프로필에서 토글이 켜져 있는지

휴일이나 쉬는 날을 테스트한다면, 특정 날짜 항목에 가능한 시간이 없는지도 확인하세요.

### 이 설정이 근무 시간 중 전화번호의 일반 라우팅도 바꾸나요?
아니요. 선택한 근무 시간 중에는 지원되는 수신 전화가 기존 라우팅 설정대로 이어져요.

### 전체 호출에서 일부 팀원이 근무 시간 외이면 어떻게 되나요?
선택한 근무 시간 밖에 있는 사용자는 건너뛰어요. 통화 가능한 다른 사용자는 계속 전화를 받을 수 있어요.
