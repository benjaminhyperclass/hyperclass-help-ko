# 음성 통화 사용자 지정 처리 결과

통화가 끝나면 후속 조치, 적격, 예약 요청처럼 일관된 이름표로 결과를 남길 수 있어요. 처리 결과를 쓰면 팀이 통화 결과를 같은 기준으로 기록할 수 있고, 이를 바탕으로 후속 작업을 자동화할 수도 있어요.

## 음성 통화 사용자 지정 처리 결과란?

사용자 지정 처리 결과는 통화 후 팀원이 고르는, 직접 정의한 통화 결과예요. 예를 들어 후속 조치, 적격, 예약 요청, 관심 없음 같은 처리 결과를 만들 수 있어요.

통화 하나에는 처리 결과를 하나만 지정할 수 있어요. 선택한 처리 결과는 통화와 함께 저장되고, 워크플로우에서 다음 단계를 자동으로 실행하는 데 쓸 수 있어요.

## 이럴 때 좋아요

- 통화 결과를 같은 기준으로 기록해요. 팀원이 통화에서 일어난 일을 정해진 선택지로 남길 수 있어요.
- 통화 후 작업이 빨라져요. 통화가 끝나자마자 결과를 고르면 되니, 다른 곳에 따로 기록하지 않아도 돼요.
- 후속 작업을 자동화해요. **Call Details**(통화 상세정보) 워크플로우 트리거와 함께 쓰면 메시지 보내기, 작업 만들기, 기회 업데이트 등을 자동으로 실행할 수 있어요.
- 웹과 모바일 팀 모두 쓸 수 있어요. 웹 앱과 모바일 앱 모두에서 지원되는 통화가 끝난 뒤 처리 결과를 고를 수 있어요.

## 사용자 지정 처리 결과 만들고 관리하기

서브 계정 관리자가 사용자에게 보여 줄 처리 결과를 정해요. 서브 계정마다 처리 결과를 최대 10개까지 만들 수 있어요.

1. **설정 > 전화 시스템 > 음성 > Call Dispositions**(통화 처리 결과)로 이동하세요.
2. 서브 계정에 이미 있는 처리 결과를 확인하세요.
3. 필요하면 새 처리 결과를 추가하거나 기존 처리 결과를 편집하세요.
4. 처리 결과의 순서를 바꿔 사용자에게 보이는 순서를 정하세요.
5. **변경사항 저장**을 클릭하세요.

이름은 통화 결과가 한눈에 들어오도록 짧고 행동이 드러나게 짓는 게 좋아요.

{% hint style="info" %}
처리 결과 이름을 바꿔도 이미 쓰고 있는 워크플로우는 깨지지 않아요. 하이퍼클래스가 처리 결과를 내부 ID로 구분하기 때문이에요. 워크플로우에서 쓰는 처리 결과를 삭제했다면, 워크플로우를 유효한 처리 결과로 바꿔 주세요.
{% endhint %}

## 통화 후 처리 결과 선택하기

지원되는 통화가 끝나면 통화 후 화면에 서브 계정에 설정된 처리 결과가 나타나요.

1. 통화를 마치세요.
2. 통화 결과를 가장 잘 나타내는 처리 결과를 선택하세요. 예를 들면 후속 조치나 예약 요청이에요.
3. 선택한 처리 결과가 통화와 함께 저장되고, 설정된 워크플로우에서 사용돼요.

통화 하나에는 처리 결과를 하나만 선택할 수 있어요. 처리 결과 선택은 필수가 아니에요. 그래도 꾸준히 선택하면 통화 기록과 자동화를 일관되게 유지하는 데 도움이 돼요.

## 모바일에서 사용하기

사용자 지정 처리 결과는 하이퍼클래스 모바일 앱과 화이트라벨 모바일 앱에서 쓸 수 있어요. iOS와 Android 모두 지원해요.

- 통화 후 선택: 통화 종료 화면이나 통화 후 화면에서 처리 결과를 고르세요.
- 통화당 하나: 통화 하나에는 처리 결과를 하나만 기록할 수 있어요.
- 워크플로우 연결: 선택한 처리 결과로 **Call Details**(통화 상세정보) 워크플로우 트리거에 설정한 후속 자동화를 실행할 수 있어요.

### 모바일 참고 사항

서브 계정이 일치해야 해요. 지금 열려 있는 서브 계정이 통화와 연결된 서브 계정과 같을 때만 처리 결과가 나타나요. 모바일 앱에서 여러 서브 계정의 통화를 받는다면, 처리 결과를 선택하기 전에 **전환**을 눌러 알맞은 서브 계정을 여세요.

## 워크플로우에서 사용하기

**Call Details**(통화 상세정보) 워크플로우 트리거와 함께 쓰면, 통화 후 선택한 처리 결과에 따라 작업을 자동으로 실행할 수 있어요.

예를 들어 워크플로우로 이런 일을 할 수 있어요.

- 후속 SMS나 이메일 보내기
- 작업 만들기
- 기회 업데이트 또는 만들기
- 태그 추가 또는 제거
- 파워 다이얼러에 연락처 다시 추가하기
- 선택한 처리 결과에 따라 그 밖의 후속 작업 실행하기

트리거와 **Custom Disposition**(사용자 지정 처리 상태) 필터 설정 방법은 [**워크플로우 트리거 — Call Details**](../통화/workflow-trigger-call-details-212511.md)에서 자세히 볼 수 있어요.

## 통화 상태와 사용자 지정 처리 결과의 차이

**Call Status**(통화 상태)와 **Custom Disposition**(사용자 지정 처리 상태)은 통화에 대해 서로 다른 정보를 나타내요.

| 필드 | 의미 | 예시 |
| --- | --- | --- |
| **Call Status**(통화 상태) | 통화 중 기술적으로 어떤 일이 있었는지를 시스템이 기록한 결과예요. | Busy(통화 중), Voicemail(음성사서함), No Answer(부재중), Completed(완료) |
| **Custom Disposition**(사용자 지정 처리 상태) | 통화 후 사용자가 선택해 업무상 결과를 분류한 값이에요. | 후속 조치, 적격, 콜백 요청 |

기술적인 통화 결과나 팀이 선택한 결과에 따라 자동화하고 싶다면, 둘 모두 **Call Details** 워크플로우 트리거의 필터로 쓸 수 있어요.

## 지원 범위와 제한 사항

| 지원 항목 | 제한 사항 |
| --- | --- |
| 하이퍼클래스 웹 앱으로 걸거나 받은 통화 | 통화 하나에 처리 결과를 하나만 선택할 수 있어요 |
| 지원되는 모바일 앱으로 걸거나 받은 통화 | 서브 계정당 처리 결과는 최대 10개예요 |
| 하이퍼클래스 전화와 Twilio 서브 계정 | 중첩 처리 결과나 하위 처리 결과는 지원하지 않아요 |
| 하이퍼클래스에서 건 WhatsApp 통화 중 지원되는 통화 | 개인 번호나 유선 전화기로 받은 통화는 처리 결과 선택을 지원하지 않아요 |

WhatsApp 통화의 처리 결과에 대한 내용은 [**하이퍼클래스에서 WhatsApp으로 통화하기**](../../31-리셀링/whatsapp-calling-in-hyperclass.md)를 참고하세요.

## 이전 통화 상태에서 옮겨 오기

이전에 **파워 다이얼러**의 **수동 작업**에서 **Call Status**(통화 상태)를 직접 선택했다면, 그 수동 분류는 **Call Disposition**(통화 처리 결과)으로 바뀌었어요.

- 통화 후 사용자가 직접 고르는 결과에는 사용자 지정 처리 결과를 쓰세요.
- 이전 통화 상태 기록은 그대로 볼 수 있어요.
- 직접 선택한 이전 통화 상태를 사용하던 워크플로우가 있다면 검토해 보세요. 필요하면 **Custom Disposition**(사용자 지정 처리 상태) 필터를 쓰도록 바꾸세요.

{% hint style="warning" %}
Busy, Voicemail, No Answer, Completed 같은 시스템이 만든 통화 상태 값은 **Call Details** 워크플로우 트리거에서 계속 지원돼요. 시스템이 기록한 통화 결과를 기준으로 자동화하고 있다면 그 필터를 바꾸지 마세요.
{% endhint %}

## 사용자 역할과 권한

| 역할 | 할 수 있는 작업 |
| --- | --- |
| 관리자 | 처리 결과 만들기, 편집, 삭제, 관리 |
| 사용자 | 지원되는 통화가 끝난 뒤 사용할 수 있는 처리 결과 선택 |

## 자주 묻는 질문

### 통화가 끝날 때마다 처리 결과를 꼭 선택해야 하나요?

아니요. 처리 결과 선택은 필수가 아니에요. 다만 꾸준히 선택하면 통화 결과를 같은 기준으로 기록할 수 있고, 처리 결과 기반 워크플로우도 설정된 대로 실행돼요.

### 워크플로우에서 쓰는 처리 결과의 이름을 바꾸면 어떻게 되나요?

워크플로우는 그 처리 결과를 계속 사용해요. 하이퍼클래스가 처리 결과를 내부 ID로 구분하기 때문이에요.

### 워크플로우에서 쓰는 처리 결과를 삭제하면 어떻게 되나요?

영향을 받는 워크플로우에서 삭제한 처리 결과를 제거하거나 다른 처리 결과로 바꾼 뒤, 워크플로우를 다시 테스트하세요.

### 통화 하나에 처리 결과를 여러 개 선택할 수 있나요?

아니요. 통화 하나에는 사용자 지정 처리 결과를 하나만 선택할 수 있어요.

### 통화 상태와 사용자 지정 처리 결과는 무엇이 다른가요?

**Call Status**(통화 상태)는 하이퍼클래스가 자동으로 기록하는 값이에요. Busy, Voicemail, No Answer, Completed처럼 기술적인 통화 결과를 나타내요. **Custom Disposition**(사용자 지정 처리 상태)은 통화 후 사용자가 직접 고르는 업무상 결과예요. 적격이나 후속 조치 같은 값이 있어요.

### 사용자 지정 처리 결과로 워크플로우를 시작할 수 있나요?

네. **Call Details** 워크플로우 트리거를 추가하고 **Custom Disposition** 필터를 쓰면, 특정 처리 결과가 기록될 때 워크플로우를 시작할 수 있어요.

### 이전 통화 상태 데이터도 계속 볼 수 있나요?

네. 이전 통화 상태 기록은 그대로 볼 수 있어요. 앞으로 통화 후 사용자가 직접 분류할 때는 사용자 지정 처리 결과를 쓰세요.
