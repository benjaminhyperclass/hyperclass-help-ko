# 하이퍼클래스 전화 시스템의 지역 번호 발신(Local Presence Dialing)

**지역 번호 발신**을 켜면 발신 통화를 할 때 연락처 지역과 가까운 발신자 ID가 자동으로 선택돼요. 하이퍼클래스는 위치 기반 매칭으로 사용 가능한 전화번호 중에서 번호를 골라요. 그래서 연락처가 전화를 받을 때 낯설지 않은 번호를 보게 돼요.

새로 바뀐 지역 번호 발신 기능은 미국, 캐나다, 영국, 호주에서 위치 기반 매칭을 지원해요. 같은 연락처에 다시 전화해도 같은 발신자 ID가 선택돼요. 또 **Web Dialer**(웹 다이얼러), 하이퍼클래스 모바일 앱, 데스크폰에서 거는 발신 통화에도 적용돼요.

## 지역 번호 발신이란?

지역 번호 발신은 연락처의 위치를 기준으로, 사용 가능한 발신자 ID 중 가장 알맞은 번호를 자동으로 선택하는 기능이에요.

하이퍼클래스는 위치 정보와 매칭 순서에 따라 사용 가능한 번호를 확인해요. 정확히 맞는 지역 번호가 없으면 다른 매칭 기준을 차례로 확인하고, 그래도 없으면 계정 기본값을 사용해요.

### 꼭 알아 두세요

- 위치 기반 매칭은 미국, 캐나다, 영국, 호주에서 사용할 수 있어요.
- 가까운 번호를 찾을 때 우편번호 간 거리 계산을 사용해요.
- 같은 연락처에 다시 전화하면 처음 선택된 같은 번호로 걸려요.
- 지역 번호 발신은 **Web Dialer**, 하이퍼클래스 모바일 앱, 데스크폰에서 모두 작동해요.
- 서브 계정마다 번호를 최대 50개까지 예약해 두면, 그 번호는 지역 번호 발신이 자동으로 고르지 않아요.
- 예약한 번호는 직접 선택해서 전화를 걸 때는 그대로 쓸 수 있어요.
- 알맞은 번호를 찾지 못하면 계정 기본값으로 전화가 걸려요.

---

## 지역 번호 발신의 장점

발신 통화를 할 때마다 번호를 직접 고르지 않아도 돼요.

- **자동 번호 선택:** 사용 가능한 발신자 ID 중 알맞은 번호를 자동으로 골라요.
- **일관된 발신자 ID:** 같은 연락처에 다시 전화해도 처음 선택된 번호를 써요.
- **위치 기반 매칭:** 우편번호, 지역번호, 오버레이 코드, 거리, 지역을 기준으로 번호를 골라요.
- **여러 국가 지원:** 미국, 캐나다, 영국, 호주에서 위치 기반 매칭을 쓸 수 있어요.
- **여러 발신 방법 지원:** 같은 지역 번호 발신 기능이 **Web Dialer**, 모바일 앱, 데스크폰에서 모두 작동해요.
- **예약 번호 관리:** 중요한 번호는 자동 선택에서 빼고, 직접 전화할 때만 쓸 수 있어요.
- **자동 대체:** 알맞은 지역 번호가 없으면 계정 기본값으로 계속 전화가 걸려요.

---

## 지역 번호 발신은 이렇게 작동해요

발신 통화를 하면 하이퍼클래스가 사용 가능한 번호를 확인하고, 매칭 순서에 따라 가장 알맞은 발신자 ID를 골라요.

### 발신자 ID 매칭 순서

하이퍼클래스는 아래 순서대로 알맞은 번호가 있는지 확인해요.

1. 리드의 우편번호
2. 지역번호
3. 오버레이 코드
4. 거리상 가장 가까운 사용 가능 번호
5. 같은 지역
6. 계정 기본값

이 순서에서 처음으로 알맞은 번호를 찾으면 그 번호를 사용해요.

### 같은 연락처에 다시 전화할 때

하이퍼클래스가 연락처에 쓸 번호를 한 번 고르면, 그 연락처에 다시 전화할 때도 같은 번호를 써요.

전화할 때마다 다른 번호가 선택되지 않고, 발신자 ID가 일정하게 유지돼요.

### 지원하는 발신 방법

지역 번호 발신은 다음과 같은 발신 방법에서 작동해요.

- **Web Dialer**
- 하이퍼클래스 모바일 앱
- 데스크폰

### 자동 대체

알맞은 지역 번호가 없어도 지역 번호 발신 때문에 발신 통화가 막히지는 않아요.

알맞은 지역 번호를 찾지 못했거나 필요한 위치 정보가 없으면 계정 기본값으로 전화가 걸려요.

### 지역 번호 발신에서 제외할 번호 예약하기

예를 들어 대표 사무실 번호는 직접 거는 전화에만 쓰고 싶을 수 있어요. 이럴 때 그 번호를 예약해 두면 지역 번호 발신이 자동으로 고르지 않아요.

## 예시: 하이퍼클래스가 번호를 고르는 과정

지역 번호 발신을 켜 둔 상태에서 연락처에 발신 통화를 한다고 해 볼게요. 하이퍼클래스는 먼저 연락처의 우편번호로 알맞은 번호가 있는지 확인해요.

알맞은 번호가 없으면 아래 순서로 계속 확인해요.

1. 지역번호
2. 오버레이 코드
3. 거리상 가장 가까운 사용 가능 번호
4. 같은 지역
5. 계정 기본값

이렇게 하면 정확히 맞는 지역 번호가 없어도 전화를 계속 걸 수 있어요.

## 자주 묻는 질문

### 연락처의 지역번호와 같은 번호가 없으면 어떻게 되나요?

바로 계정 기본값을 쓰지 않고, 지역 번호 발신의 매칭 순서를 계속 따라가요.

오버레이 코드, 거리상 가장 가까운 번호, 같은 지역 순으로 확인한 뒤에도 없으면 계정 기본값을 사용해요.

### 연락처에 위치 정보가 없으면 어떻게 되나요?

계정 기본값으로 발신 통화가 걸려요.

### 같은 연락처에 전화할 때마다 발신자 ID가 달라지나요?

아니요. 같은 연락처에 다시 전화하면 처음 선택된 같은 번호로 걸려요.

### 위치 기반 지역 번호 발신은 어느 나라에서 쓸 수 있나요?

위치 기반 매칭은 아래 국가에서 지원해요.

- 미국
- 캐나다
- 영국
- 호주

### 어떤 발신 방법에서 지역 번호 발신을 쓸 수 있나요?

**Web Dialer**, 하이퍼클래스 모바일 앱, 데스크폰에서 쓸 수 있어요.

### 지역 번호 발신이 특정 번호를 고르지 않게 할 수 있나요?

네. 서브 계정마다 번호를 최대 50개까지 예약할 수 있어요.

예약한 번호는 지역 번호 발신이 자동으로 고르지 않아요. 하지만 직접 전화를 걸 때는 쓸 수 있어요.

### 예약한 번호를 직접 선택해서 쓸 수 있나요?

네. 번호를 예약하면 지역 번호 발신이 그 번호를 자동으로 고르지 않을 뿐이에요. 직접 선택해서 쓰는 것은 막지 않아요.

### 알맞은 지역 번호를 찾지 못하면 어떻게 되나요?

하이퍼클래스가 계정 기본값을 사용해서 발신 통화가 계속 이어져요.

### 특정 통화에서 자동 선택된 번호를 바꿀 수 있나요?

네. 개별 통화마다 사용 가능한 다른 번호를 직접 선택할 수 있어요.

### 추가할 수 있는 번호 수에 제한이 있나요?

하이퍼클래스는 현재 서브 계정에 있는 사용 가능한 전화번호와 **인증된 발신자 ID**를, 지역 번호 발신용 번호 개수 제한 없이 지원해요. 50개 제한은 예약으로 표시한 번호에만 적용돼요.

### 지역 번호 발신에서 인증된 발신자 ID를 쓸 수 있나요?

네. 현재 지역 번호 발신에서 **인증된 발신자 ID**를 지원해요.

### 제 Twilio 계정을 연결해서 써도 지역 번호 발신이 작동하나요?

네. 현재 자체 Twilio 계정을 쓰는 서브 계정도 지역 번호 발신을 지원해요.

### 특정 사용자만 지역 번호 발신을 끌 수 있나요?

지역 번호 발신은 사용자별이 아니라 서브 계정 단위로 설정해요.

### 지역 번호 발신을 쓰면 전화 응답률이 확실히 올라가나요?

아니요. 지역 번호로 걸면 받는 사람이 번호를 더 친숙하게 느낄 수 있지만, 응답률이 높아진다고 보장할 수는 없어요.
