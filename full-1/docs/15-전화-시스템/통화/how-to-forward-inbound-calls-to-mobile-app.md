# 모바일 앱으로 인바운드 통화 착신 전환하기

하이퍼클래스 모바일 앱에서 인바운드 통화를 받도록 설정하는 방법을 안내해요. 몇 가지만 설정하면 걸려 온 전화가 모바일 기기로 바로 울려서, 언제 어디서나 리드와 고객의 연락을 받을 수 있어요.

## 모바일 앱의 인바운드 통화란?

모바일 앱의 인바운드 통화는 하이퍼클래스 전화번호로 걸려 온 비즈니스 전화를 하이퍼클래스 모바일 앱으로 바로 받는 기능이에요. 전화가 잘 연결되려면 웹 앱의 플랫폼 설정과 휴대폰의 기기 설정을 모두 맞게 해 두어야 해요.

[동영상](https://www.youtube.com/embed/Nym\_9Mv10hs?&wmode=opaque)

{% hint style="info" %}
인바운드 통화를 쓰려면 서브 계정에서 번호를 구매하고, 그 번호를 사용자에게 배정해야 해요.
{% endhint %}

## 모바일 앱으로 인바운드 통화를 받으면 좋은 점

모바일 앱으로 전화를 받으면 고객 연락에 더 빠르게 대응할 수 있어요.

- 컴퓨터 앞에 없을 때도 중요한 고객 전화를 놓치지 않아요.
- 모바일 기기에서 인바운드 통화를 바로 처리할 수 있어요.
- 원격 근무나 이동 중 소통을 지원해요.
- 여러 지점에 있는 직원의 통화 관리가 간편해져요.
- 전용 비즈니스 번호를 쓰기 때문에 비즈니스의 전문적인 이미지를 높일 수 있어요.
- **부재중 전화 문자 회신** 같은 자동화 기능과 연동해 고객 후속 연락을 더 잘 챙길 수 있어요.

## 모바일 앱에서 인바운드 통화 받도록 설정하기

웹 앱에서 직원 설정을 하고, 모바일 기기에서 권한을 업데이트해야 해요. 직원 프로필이 통화를 모바일 앱으로 전달하도록 설정되어 있어야 해요.

1. 왼쪽 메뉴에서 **설정**으로 이동하세요.
2. **스태프 관리**를 선택하세요.
3. 설정할 직원을 찾아 이름 옆의 **편집** 버튼을 클릭하세요.

   ![직원 이름 옆의 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079830197/original/AWHfnXr1TDl9C2c-PKJabKk6pf5LsiZn9Q.png?1788277312)
4. **Call and Voicemail Settings**(통화 및 음성 메일 설정) 탭을 클릭하세요.
5. **인바운드 번호**를 배정하세요. 이 사용자에게 직통 번호가 필요하면 드롭다운 목록에서 번호를 선택하세요. 번호를 배정하지 않으면 전체 통화 분배 설정에 따라 통화가 연결돼요.
6. **착신 전환 대상** 섹션에서 **모바일 앱** 체크박스를 선택하세요.
7. 오른쪽 아래의 파란색 **저장** 버튼을 클릭해 변경 사항을 적용하세요.

   ![착신 전환 대상에서 모바일 앱을 선택하고 저장 버튼을 누르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045796817/original/uIzgaB24-xW7J-XLD2zwYvZWKcKd-TjzHA.png?1745868902)

## 문제 해결 팁

인바운드 통화가 모바일 앱으로 오지 않으면 아래 항목을 확인해 보세요.

- 위에서 안내한 대로 해당 직원의 설정에서 **Send calls to mobile app**(모바일 앱으로 통화 보내기)이 켜져 있고 저장되어 있는지 확인하세요. <!-- 검토 필요: 원문 내용이 서로 다름 (설정 절차에서는 'Mobile app' 체크박스로 안내) -->
- 하이퍼클래스 모바일 앱에 필요한 권한이 기기에서 모두 허용되어 있는지 확인하세요.
- 앱의 배터리 최적화가 꺼져 있는지 확인하세요. (Android만 해당)
- 알림이 켜져 있고, 앱이 백그라운드에서 실행되도록 허용되어 있는지 확인하세요.

## 자주 묻는 질문

### **Send calls to mobile app**을 켜지 않으면 어떻게 되나요?
<!-- 검토 필요: 원문 내용이 서로 다름 (설정 절차의 'Mobile app' 체크박스와 이름이 다름) -->
해당 사용자는 모바일 앱에서 걸려 오는 전화를 받을 수 없어요. 통화가 모바일 앱으로 연결되려면 이 체크박스를 선택해야 해요.

### 전화를 받으려면 앱을 계속 열어 두어야 하나요?
아니요. 다만 앱이 백그라운드에서 실행될 수 있어야 하고, 알림이 켜져 있어야 해요.

### 부재중 전화가 오면 문자를 자동으로 보낼 수 있나요?
네. **부재중 전화 문자 회신** 기능을 쓰면 SMS로 리드에게 자동으로 후속 연락을 할 수 있어요.

### 설정을 마쳤는데도 전화가 오지 않아요.
직원 설정에서 **저장** 버튼을 클릭했는지 다시 확인하세요. 모바일 기기의 권한도 올바르게 허용되어 있는지 확인하세요.

### 여러 기기에 로그인하면 모든 기기에서 전화가 울리나요?
같은 사용자 계정으로 로그인한 최대 10개 기기에서 동시에 걸려 오는 전화를 받을 수 있어요.
한 기기에서 전화를 받으면 다른 모든 기기에서는 통화 연결이 자동으로 끊겨요. 이 기능은 같은 사용자 계정으로 여러 기기에 로그인한 경우에만 적용되며, 여러 사용자가 하나의 로그인을 함께 쓰는 경우는 지원하지 않아요.

### 여러 서브 계정에 속해 있고 인바운드 통화를 켜 두었다면 어떻게 되나요?
마지막으로 직접 전환한 서브 계정의 인바운드 통화만 받을 수 있어요. 모바일 앱을 완전히 종료했다가 다시 열어도 마지막 서브 계정을 기억해서 그 계정의 통화를 계속 연결해 줘요. 인바운드 통화를 켜 두지 않은 서브 계정으로 전환하면, 어느 서브 계정의 통화도 받을 수 없게 돼요.

### 전화 두 통이 동시에 오면 어떻게 되나요?
하나의 수신 전화에 여러 기기가 울릴 때 한 기기에서 전화를 받으면, 다른 모든 기기에서는 통화 연결 시도가 자동으로 끊겨요.
