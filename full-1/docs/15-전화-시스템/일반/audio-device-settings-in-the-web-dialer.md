# 웹 다이얼러 오디오 장치 설정

웹 다이얼러에서 통화할 때 쓸 스피커와 마이크를 직접 고를 수 있어요. 수신 전화가 올 때 장치 두 개를 동시에 울리게 할 수도 있어요.

이 문서에서는 오디오 장치 설정이 어떻게 동작하는지, 어떻게 설정하는지 알려 드려요. 헤드셋과 컴퓨터 스피커를 함께 울려서 수신 전화를 놓치지 않는 방법도 안내해요.

## 오디오 장치 설정이란?

하이퍼클래스 웹 다이얼러의 오디오 장치 설정에서는 통화 소리를 처리할 장치를 고를 수 있어요. 통화 소리를 들을 기본 스피커와 말할 때 쓸 마이크를 선택해요. 원하면 수신 전화가 올 때 울릴 두 번째 장치도 추가할 수 있어요.

헤드셋, 외부 스피커, 컴퓨터 내장 오디오 중 어떤 것을 쓰더라도 작업 환경에 맞게 맞출 수 있어요.

설정 패널은 다이얼러 화면에서 바로 열 수 있어요. 저장하기 전에 테스트 버튼으로 소리를 미리 확인할 수 있어요.

## 이럴 때 유용해요

- 수신 전화를 놓치지 않아요. 헤드셋과 컴퓨터 스피커를 동시에 울리면 자리를 잠깐 비웠을 때도 전화가 오는 걸 알 수 있어요.
- 작업 환경에 맞게 쓸 수 있어요. 사무실, 집, 원격 근무 공간 등 환경에 가장 잘 맞는 장치를 고르세요.
- 저장하기 전에 확인할 수 있어요. 스피커와 추가 벨소리 장치는 테스트 버튼으로 미리 들어 보세요. 마이크는 실시간 볼륨 미터로 소리가 잡히는지 확인할 수 있어요.
- 통화에 쓸 마이크와 스피커를 직접 고를 수 있어요. 사용 가능한 장치 중에서 웹 다이얼러가 사용할 장치를 선택하세요.

## 오디오 장치 옵션 알아보기

오디오 장치 설정 패널에서는 세 가지 옵션을 설정할 수 있어요.

### 옵션 1. Main Speaker(메인 스피커) — 필수

통화 소리가 나오는 기본 장치예요. 드롭다운 메뉴에서 원하는 출력 장치를 고르세요. 헤드폰, 외부 스피커, 컴퓨터 내장 스피커 모두 선택할 수 있어요. 웹 다이얼러로 통화하는 동안 상대방의 목소리가 **Main Speaker**로 나와요.

### 옵션 2. Additional Ring Device(추가 벨소리 장치) — 선택

수신 전화가 올 때 동시에 울릴 두 번째 장치를 고르는 옵션이에요. 헤드셋을 쓰고 있지 않을 때도 책상 스피커로 전화가 온 걸 알 수 있어서, 헤드셋과 책상 스피커 양쪽에서 전화를 듣고 싶을 때 유용해요. 이 장치는 수신 전화가 올 때만 울리고, 통화 중에는 소리가 나오지 않아요.

### 옵션 3. 마이크 — 필수

통화 중 말할 때 사용할 마이크를 선택해요. 마이크 선택 영역에는 실시간 볼륨 미터가 있어요. 설정을 저장하기 전에 마이크에 소리가 잡히는지 확인할 수 있고, 통화할 때마다 목소리가 또렷하게 전달돼요.

{% hint style="info" %}
스피커와 추가 장치 옆의 테스트 버튼을 누르면 저장하기 전에 소리를 미리 들어 볼 수 있어요. 마이크 볼륨 미터는 실시간으로 움직여서 테스트 전화를 걸지 않아도 장치가 잘 작동하는지 확인할 수 있어요.
{% endhint %}

## 오디오 장치 설정하기

웹 다이얼러에서 오디오 장치를 설정하는 순서는 다음과 같아요.

1. 웹 다이얼러 상단의 톱니바퀴 아이콘을 눌러 **오디오 설정** 패널을 엽니다.

   ![웹 다이얼러 상단의 톱니바퀴 아이콘으로 오디오 설정 패널 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077805701/original/x00f2Cy0siIwRHZMc9Rb2khhRFNLaaeP6Q.png?1786023585)

2. **Main Speaker** 드롭다운에서 기본 스피커를 선택합니다. 이 장치로 모든 통화 소리가 나와요. 드롭다운 옆의 테스트 버튼을 누르면 저장하기 전에 소리를 미리 확인할 수 있어요.
3. 수신 전화가 올 때 함께 울릴 장치가 있다면 **Additional Ring Device** 드롭다운에서 선택합니다. 예를 들어 컴퓨터 스피커를 고르면 헤드셋과 책상 스피커에서 동시에 전화가 울려요. 테스트 버튼을 눌러 장치가 제대로 울리는지 확인하세요.
4. **마이크** 드롭다운에서 사용할 마이크를 선택합니다. 볼륨 미터가 나타나면 마이크에 대고 말해 보세요. 미터가 움직이면 마이크가 정상적으로 작동하는 거예요.

   ![마이크 선택과 볼륨 미터 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077805813/original/FC1-FFMmZhm8jJ5hdIb7O6EHIcKrpUIpRw.png?1786023633)

5. 장치 설정과 테스트를 마쳤으면 **저장** 버튼을 눌러 변경 사항을 적용합니다. 이제 이 브라우저, 이 기기의 웹 다이얼러에 오디오 설정이 적용돼요.

{% hint style="info" %}
다른 브라우저나 다른 컴퓨터에서 하이퍼클래스를 사용한다면 오디오 장치를 다시 설정하세요.
{% endhint %}

{% hint style="info" %}
수신 전화를 놓치지 않으려면 **Main Speaker**는 헤드셋으로, **Additional Ring Device**는 컴퓨터 스피커로 설정해 보세요. 전화가 올 때 헤드셋을 쓰고 있지 않아도 두 장치에서 모두 벨소리가 들려요.
{% endhint %}
