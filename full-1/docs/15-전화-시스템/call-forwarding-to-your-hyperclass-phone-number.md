# 하이퍼클래스 전화번호로 착신 전환하기

휴대폰이나 유선 전화로 걸려 오는 전화를 하이퍼클래스 전화번호로 넘기는 방법을 안내해요. 명함, 웹사이트, 온라인 디렉터리에 적어 둔 기존 대표번호를 바꾸지 않고도 하이퍼클래스의 음성 AI를 쓸 수 있어요. 사용 중인 통신사에 맞는 단계를 따라 하세요.

## 하이퍼클래스로 전화를 착신 전환하는 이유

착신 전환을 쓰면 내 휴대폰이나 사업용 전화번호를 하이퍼클래스의 음성 AI와 자연스럽게 연결할 수 있어요. 걸려 오는 전화를 하이퍼클래스 전화번호로 넘기면 이런 점이 좋아요.

- 음성 AI 활용: AI가 통화를 응대하고 내용을 텍스트로 기록해 고객과의 소통을 도와요.
- 기존 번호 유지: 고객에게 보이는 번호가 그대로라서 홍보물이나 디렉터리의 번호를 고치지 않아도 돼요.
- 운영 간소화: 걸려 오는 모든 전화를 하이퍼클래스 계정에서 관리하므로 추적과 관리가 더 쉬워요.

## 착신 전환이 작동하는 방식

착신 전환을 켜면 내 번호(휴대폰 또는 유선 전화)로 걸려 오는 전화가 하이퍼클래스 전화번호로 자동으로 넘어가요. 그러면 하이퍼클래스가 음성 AI 기능으로 통화를 처리해요.

## 착신 전환 루프 피하기

착신 전환을 켜기 전에, 전화가 원래 번호로 다시 돌아가지 않도록 경로를 확인하세요.

{% hint style="warning" %}
통화 리디렉션 루프에 주의하세요.

번호 A가 번호 B로 전환되는데 번호 B가 다시 번호 A로 통화를 연결하거나 전환하도록 설정되어 있으면 리디렉션 루프가 생길 수 있어요. 이러면 두 번호 사이에서 통화가 계속 되돌아가요.

설정을 마치기 전에 하이퍼클래스 전화번호, 착신 전환 번호, 사용자 전화번호, **비즈니스 프로필**의 전화번호가 통화를 처음 전환한 번호로 되돌리는 경로를 만들지 않는지 확인하세요.
{% endhint %}

### 설정 테스트하기

착신 전환을 켠 다음에는 이렇게 테스트하세요.

1. 다른 전화기로, 착신 전환을 설정한 원래 번호에 전화를 걸어요.
2. 통화가 하이퍼클래스 전화번호로 잘 연결되고, 예상한 수신 통화 흐름대로 진행되는지 확인해요.
3. 통화가 계속 다시 연결되거나, 같은 음성이 반복 재생되거나, **대화**에 수신 통화가 여러 건 생기지 않는지 확인해요.
4. 통화가 반복되거나 예상과 다르게 연결되면 착신 전환을 끄고, 전화 설정을 점검한 뒤 다시 테스트하세요.

통화가 번호 사이에서 계속 되돌아간다면 'How To Fix - Phone Call Redirect Loop'(전화 통화 리디렉션 루프 해결 방법) 문서의 문제 해결 단계를 따라 하세요.

## 주요 통신사별 착신 전환 설정

사용 중인 통신사에 맞는 단계를 따라 하세요. 목록에 없는 통신사라면 해당 통신사의 고객지원 페이지에서 자세한 방법을 확인하세요.

### Verizon Wireless

1. Verizon Wireless 휴대폰에서 하이퍼클래스 전화번호로 착신 전환하는 방법은 두 가지예요.

   - 모든 통화를 전환하려면 `*72`를 누른 뒤 하이퍼클래스 전화번호를 이어서 입력하세요(예: `*72 555-555-5555`).
   - 부재중 통화(받지 않았거나 통화 중 신호를 받은 전화)를 전환하려면 `*71`을 누른 뒤 하이퍼클래스 전화번호를 이어서 입력하세요(예: `*71 555-555-5555`).
2. **통화**를 눌러요.
3. 확인음이나 안내 메시지가 나올 때까지 기다려요.
4. 착신 전환을 해제하려면 `*73`을 누르세요.

[Verizon Wireless 고객지원에서 더 알아보기](https://www.verizon.com/support/call-forwarding-faqs/)

### AT&T (모바일)

1. `*21`을 누른 뒤 하이퍼클래스 전화번호를 이어서 입력하세요(예: `*21 555-555-5555`).
2. **통화** 또는 **보내기**를 눌러요.
3. 확인음이 나올 때까지 기다려요.
4. 해제하려면 `#21#`을 누르세요.

[AT&T Wireless 고객지원에서 더 알아보기](https://www.att.com/device-support/article/wireless/KM1501781/ATT/WirelessHomePhoneWF721/)

### AT&T (비즈니스)

1. 유선 전화에서 `*72`를 누르고 발신음을 확인하세요.
2. 하이퍼클래스 전화번호를 입력하세요(예: `555-555-5555`).
3. 확인음이 나올 때까지 기다려요. 이어서 시스템이 전환 대상 번호로 전화를 걸어요. 전환 대상 번호에서 전화를 받으면 기능이 켜져요.
4. 착신 전환을 해제하려면 `*73`을 누르세요.

[AT&T Business 고객지원에서 더 알아보기](https://www.att.com/support/smallbusiness/article/smb-local-long-distance/KM1194925/)

### T-Mobile

1. T-Mobile 휴대폰에서 하이퍼클래스 전화번호로 착신 전환하는 방법은 두 가지예요.

   - 모든 통화를 전환하려면 `**21*1` + 하이퍼클래스 전화번호 + `#`을 누르세요(예: `**21*1555-555-5555#`).
   - 부재중 통화(받지 않았거나 통화 중 신호를 받은 전화)를 전환하려면 `**61*1` + 하이퍼클래스 전화번호 + `#`을 누르세요(예: `**61*1555-555-5555#`).
2. **통화**를 눌러요.
3. 착신 전환을 해제하려면 `##61#` 또는 `##21#`을 각각 누르세요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

[T-Mobile 고객지원에서 더 알아보기](https://www.t-mobile.com/support/plans-features/self-service-short-codes#secondheading)

### Xfinity Mobile

1. Xfinity Mobile 휴대폰에서 하이퍼클래스 전화번호로 착신 전환하는 방법은 두 가지예요.

   - 모든 통화를 전환하려면 `*72`를 누른 뒤 하이퍼클래스 전화번호를 이어서 입력하세요(예: `*72 555-555-5555`).
   - 부재중 통화(받지 않았거나 통화 중 신호를 받은 전화)를 전환하려면 `*71`을 누른 뒤 하이퍼클래스 전화번호를 이어서 입력하세요(예: `*71 555-555-5555`).
2. **통화**를 눌러요.
3. 확인음이 나오는지 들어 보세요.
4. 착신 전환을 끄려면 `*73`을 누르세요.

[Xfinity Mobile 고객지원에서 더 알아보기](https://www.xfinity.com/support/articles/how-to-use-call-forwarding)

### Spectrum Mobile

1. Spectrum Mobile 휴대폰에서 하이퍼클래스 전화번호로 착신 전환하는 방법은 두 가지예요.

   - 모든 통화를 전환하려면 `*72`를 누른 뒤 하이퍼클래스 전화번호를 이어서 입력하세요(예: `*72 555-555-5555`).
   - 부재중 통화(받지 않았거나 통화 중 신호를 받은 전화)를 전환하려면 `*71`을 누른 뒤 하이퍼클래스 전화번호를 이어서 입력하세요(예: `*71 555-555-5555`).
2. **통화**를 누르고 확인음이 나올 때까지 기다려요.
3. 해제하려면 `*73`을 누르세요.

[Spectrum Mobile 고객지원에서 더 알아보기](https://www.spectrum.net/support/mobile/spectrum-mobile-call-forwarding)

### 기타 통신사

위 목록에 없는 통신사라면 해당 통신사에 직접 문의하거나 아래 방법을 시도해 보세요.

1. 모든 통화를 전환하려면
   - 전화기에서 `*72`를 누르고 발신음을 확인하세요.
   - 하이퍼클래스 전화번호를 입력하세요(예: 555-555-5555).
   - 확인음이 나올 때까지 기다려요.
   - 착신 전환을 해제하려면 `*73`을 누르세요.
2. 부재중 통화(받지 않았거나 통화 중 신호를 받은 전화)를 전환하려면

   - 전화기에서 `*92`를 누르고 발신음을 확인하세요.
   - 하이퍼클래스 전화번호를 입력하세요(예: 555-555-5555).
   - 확인음이 나올 때까지 기다려요.
   - 착신 전환을 해제하려면 `*93`을 누르세요.

## 자주 묻는 질문

### 여러 번호의 전화를 하이퍼클래스로 전환할 수 있나요?

네. 각 번호가 착신 전환을 지원하면 여러 번호를 하이퍼클래스 전화번호로 전환할 수 있어요.

### 착신 전환 중이라는 사실을 발신자가 알 수 있나요?

아니요. 착신 전환은 자연스럽게 연결되고, 발신자에게 전환 안내는 나가지 않아요.

### 착신 전환을 설정한 뒤에도 내 번호로 전화를 걸 수 있나요?

네. 착신 전환은 걸려 오는 전화에만 적용돼요. 내 번호로 거는 전화는 영향을 받지 않아요.

### 착신 전환을 해외에서도 쓸 수 있나요?

통신사에 따라 달라요. 해외 착신 전환을 지원하는지 통신사에 문의하세요.

### 전환된 통화가 계속 반복되거나 루프에 걸려요. 어떻게 하나요?

통화가 계속 다시 연결되거나, 같은 음성이 반복 재생되거나, **대화**에 여러 건으로 나타난다면 통화 리디렉션 루프가 생겼을 수 있어요.

착신 전환을 잠시 끄고, 착신 전환 번호, 사용자 전화번호, **비즈니스 프로필**의 전화번호가 통화를 원래 번호로 되돌리지 않는지 확인하세요.
