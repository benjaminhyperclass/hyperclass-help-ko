# 계정 간 전화번호 마이그레이션(미국·해외)

하이퍼클래스 전화와 Twilio 사이, 또는 서로 다른 에이전시에 속한 하이퍼클래스 전화 서브 계정 사이에서 전화번호를 옮기는 방법을 안내해요. 하이퍼클래스 고객지원이 처음부터 끝까지 함께 진행해요.

## 개요

전화번호는 하이퍼클래스 전화와 Twilio 사이, 또는 서로 다른 에이전시에 속한 하이퍼클래스 전화 서브 계정 사이에서 옮길 수 있어요. 필요한 정보는 옮기는 방향과 미국 번호인지 해외 번호인지에 따라 달라요.

이 범위의 계정 간 마이그레이션은 하이퍼클래스 고객지원이 직접 조율해요. 그래서 Twilio 고객지원에 따로 티켓을 열 필요가 없어요. Account SID, 위치 ID, 전화번호, 해당하는 규정 정보를 미리 준비하면 처리가 늦어지는 일을 줄일 수 있어요.

이 문서에서는 어떤 경로를 선택해야 하는지, 무엇을 준비해야 하는지, 요청은 어떻게 제출하는지, 번호를 옮긴 뒤 무엇을 확인해야 하는지 설명해요.

{% hint style="warning" %}
마이그레이션이 진행되는 동안에는 하이퍼클래스 고객지원이 직접 안내하지 않는 한 전화번호를 수동으로 삭제, 해제, 비활성화, 연결 해제하지 마세요. 고객지원에서 이동 완료를 알려 주고, 옮겨 간 환경에서 번호를 테스트해 본 뒤에 진행하세요.
{% endhint %}

## 계정 간 전화번호 마이그레이션이란?

전화번호 마이그레이션은 이미 쓰고 있는 번호를 새 번호를 사지 않고 다른 전화 환경으로 옮기는 것을 말해요. 하이퍼클래스 고객지원은 하이퍼클래스 전화 → Twilio, Twilio → 하이퍼클래스 전화, 그리고 서로 다른 에이전시에 속한 하이퍼클래스 전화 서브 계정 간 이동(하이퍼클래스 전화 → 하이퍼클래스 전화)을 조율해요.

이 과정은 포팅(porting)과 달라요. 마이그레이션은 하이퍼클래스 전화나 Twilio에서 관리하는 번호를 호환되는 계정끼리 옮길 때 써요. 번호가 Twilio가 아닌 외부 통신사에 있다면 전화번호 포팅 절차를 이용하세요.

### 마이그레이션 절차의 장점

조율된 마이그레이션을 이용하면 번호를 관리하는 계정이나 전화 환경이 바뀌어도 기존 번호를 그대로 쓸 수 있어요. 요청을 제출하기 전에 필요한 정보를 준비해 두면 지연이 줄고, 이동 후 확인도 쉬워져요.

- 기존 번호 유지: 고객이 이미 알고 있는 번호를 바꾸지 않고, 옮길 수 있는 번호를 그대로 옮겨요.
- 한곳에서 조율: 하이퍼클래스 고객지원이 요청부터 전환까지 계정 간 이동을 조율해요.
- 명확한 마이그레이션 계획: 필요한 ID와 규정 정보를 요청을 제출하기 전에 준비할 수 있어요.
- 여러 번호 동시 처리: 옮길 수 있는 번호 여러 개를 한 요청에 담을 수 있어요.
- 이동 후 검증: 전환이 끝난 뒤 정상 트래픽이 다시 들어오기 전에 통화, SMS, 규정 준수, 라우팅, 번호 배정을 확인할 수 있어요.

## 지원하는 마이그레이션 유형

번호가 지금 어느 전화 시스템에 있고 어디로 가야 하는지에 따라 맞는 경로가 달라요. ID를 모으거나 요청을 제출하기 전에 아래 표에서 맞는 절차를 먼저 확인하세요.

| 마이그레이션 | 이럴 때 사용해요 | 진행 방식 |
| --- | --- | --- |
| 하이퍼클래스 전화 → Twilio | 하이퍼클래스 전화에서 관리하는 번호를 고객의 Twilio 계정으로 옮길 때 | 하이퍼클래스 고객지원이 마이그레이션을 조율해요. |
| Twilio → 하이퍼클래스 전화 | 고객의 Twilio 계정에 있는 번호를 하이퍼클래스 전화 서브 계정으로 옮길 때 | 하이퍼클래스 고객지원이 마이그레이션을 조율해요. |
| 하이퍼클래스 전화 → 하이퍼클래스 전화(다른 에이전시) | 서로 다른 하이퍼클래스 에이전시에 속한 서브 계정 사이에서 하이퍼클래스 전화 번호를 옮길 때 | 하이퍼클래스 고객지원이 에이전시 간 이동을 조율해요. |
| 하이퍼클래스 전화 → 하이퍼클래스 전화(같은 에이전시) | 같은 에이전시 아래의 두 하이퍼클래스 전화 서브 계정 사이에서 번호를 옮길 때 | 이 계정 간 절차 대신 앱 안의 **번호 이동** 도구를 사용해요. |
| 외부 통신사 → 하이퍼클래스 | 번호가 하이퍼클래스 전화/Twilio 마이그레이션 경로 밖의 통신사에 있을 때 | 전화번호 포팅 절차를 이용해요. |

이 문서에서 다루는 세 가지 계정 간 유형에서는 Twilio 티켓을 따로 열 필요가 없어요. 필요한 마이그레이션 정보를 하이퍼클래스 고객지원에 제출하면 고객지원이 마이그레이션을 조율해 줘요.

## 마이그레이션 전에 준비할 것

고객지원에 문의하기 전에 올바른 식별 정보를 모아 두면 불필요한 문의 왕복을 줄일 수 있어요. 필요한 정보는 마이그레이션 방향에 따라 달라지니, 요청을 제출하기 전에 출발지와 도착지를 확인하세요.

| 유형 | 준비할 것 |
| --- | --- |
| 하이퍼클래스 전화 → Twilio | 받는 쪽 Twilio Account SID, 해당 하이퍼클래스 전화 서브 계정의 하이퍼클래스 위치 ID, 전화번호, 희망 전환 시간대 |
| Twilio → 하이퍼클래스 전화 | 보내는 쪽 Twilio Account SID, 도착지 하이퍼클래스 위치 ID, 전화번호, 희망 전환 시간대 |
| 하이퍼클래스 전화 → 하이퍼클래스 전화(다른 에이전시) | 도착지 위치 ID, 전화번호, 희망 전환 시간대, 알고 있다면 출발지 위치 ID |
| 해외 번호 | 해당하는 규정 번들 SID, Address SID(주소 SID), 해당하는 경우 도착지 위치 ID, 전화번호, 국가, 번호 유형, 희망 전환 시간대 |

{% hint style="info" %}
전화번호는 가능하면 E.164 형식으로 입력하세요. 예를 들어 미국 번호는 +1XXXXXXXXXX 형식으로 제출해요.
{% endhint %}

{% hint style="warning" %}
보안: 하이퍼클래스 고객지원이 승인된 제출 방법을 따로 안내하지 않는 한, 일반 마이그레이션 티켓에는 Twilio Auth Token, 비밀번호, 결제 정보 등 인증 정보를 적지 마세요.
{% endhint %}

## 계정 간 전화번호 마이그레이션 요청하기

먼저 출발지와 도착지를 확인하고 필요한 계정 식별 정보를 모은 뒤, 하이퍼클래스 고객지원에 요청을 한 번에 제출해요. 처음 요청에 필요한 정보를 모두 담으면 마이그레이션 팀이 전환을 조율하는 데 필요한 내용을 바로 확인할 수 있어요.

### 1단계: 마이그레이션 방향 확인하기

번호를 하이퍼클래스 전화에서 Twilio로 옮기는지, Twilio에서 하이퍼클래스 전화로 옮기는지, 아니면 서로 다른 에이전시의 하이퍼클래스 전화 서브 계정끼리 옮기는지 확인하세요. 이에 따라 어떤 Account SID나 위치 ID를 포함해야 하는지가 정해져요.

### 2단계: 필요하면 Twilio Account SID 찾기

Twilio Account SID는 미국 하이퍼클래스 전화 ↔ Twilio 마이그레이션에 관련된 Twilio 계정을 구분하는 값이에요.

- 하이퍼클래스 전화 → Twilio: 번호를 받을 Twilio 계정의 받는 쪽 Account SID를 입력하세요.
- Twilio → 하이퍼클래스 전화: 번호가 지금 있는 Twilio 계정의 보내는 쪽 Account SID를 입력하세요.
- 서로 다른 에이전시 간 하이퍼클래스 전화 → 하이퍼클래스 전화: 이 경우에는 보통 Twilio Account SID가 필요하지 않아요.

Twilio에서 **Account Dashboard**(계정 대시보드)를 열고 **Account Info**(계정 정보)를 찾으세요. 해당 계정의 Account SID를 복사하면 돼요.

![Account Info 아래에 Account SID가 표시된 Twilio 계정 대시보드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054160307/original/o5oSPy13Wa2SCDElTiah8rlKOI8s74LdwQ.jpeg?1758293602)

Twilio Account SID는 계정 대시보드의 Account Info 아래에서 확인할 수 있어요. 일반 마이그레이션 요청에는 Account SID만 있으면 돼요.

### 3단계: 하이퍼클래스 위치 ID 찾기

**위치 ID**는 **서브 계정 ID**라고도 하며, 마이그레이션에 관련된 하이퍼클래스 서브 계정을 구분하는 값이에요. Twilio → 하이퍼클래스 전화나 에이전시 간 하이퍼클래스 전화 이동에서는 도착지 위치 ID가 특히 중요해요. 하이퍼클래스 전화 → Twilio에서는 고객지원이 출발지를 확인할 수 있도록 해당 하이퍼클래스 전화 서브 계정의 위치 ID를 함께 알려 주세요.

1. 해당 하이퍼클래스 서브 계정을 엽니다.
2. **설정 > 비즈니스 프로필**로 이동합니다.
3. **위치 ID**를 찾아 복사합니다.

![위치 ID가 표시된 하이퍼클래스 비즈니스 프로필 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054160913/original/MuHzpQF5_gS-jMkoIU47bJNg2hvRs4tLqA.png?1758293832)

위치 ID는 해당 하이퍼클래스 서브 계정의 **설정 > 비즈니스 프로필**에서 확인할 수 있어요.

### 4단계: 하이퍼클래스 고객지원에 마이그레이션 요청 제출하기

마이그레이션 정보를 모두 담아 하이퍼클래스 고객지원에 요청을 한 번만 제출하세요. 고객지원이 계정 간 마이그레이션을 조율하고, 번호를 검증할 준비가 되면 알려 줘요.

요청에 포함할 내용

- 마이그레이션 방향: 하이퍼클래스 전화 → Twilio, Twilio → 하이퍼클래스 전화, 또는 서로 다른 에이전시 간 하이퍼클래스 전화 → 하이퍼클래스 전화
- E.164 형식의 전화번호
- 미국 하이퍼클래스 전화 ↔ Twilio 이동일 때 해당하는 Twilio Account SID
- 해당하는 하이퍼클래스 위치 ID
- 해외 번호일 때 규정 번들 SID와 Address SID
- 해외 번호일 때 국가와 번호 유형
- 희망 전환 시간대

![마이그레이션 요청을 제출하는 하이퍼클래스 고객지원 화면 흐름](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045972735/original/ruMK9XOl0NIlCzM2UaF8MuauyxRqZpVpiw.gif?1746109415)

하이퍼클래스 고객지원에 문의해서 마이그레이션 정보를 한 번에 알려 주면, 전화 팀이 이동을 조율해요.

## 해외 전화번호 옮기기

해외 전화번호는 옮기기 전에 국가와 번호 유형별 규정 정보가 필요할 수 있어요. 마이그레이션 요청을 제출하기 전에 올바른 규정 번들과 주소 정보를 준비해 두면 규정 요건 때문에 이동이 막히는 일을 줄일 수 있어요.

준비할 것

- 번호의 국가와 번호 유형에 해당하는 규정 번들 SID
- Address SID
- 해당하는 경우 도착지 위치 ID
- 국가 코드를 포함한 전화번호
- 국가와 번호 유형(로컬, 모바일, 수신자 부담 등)
- 희망 전환 시간대

### 이동 전에 규정 승인 상태 확인하기

규정 요건은 국가와 번호 유형마다 달라요. 필요한 주소나 규정 번들이 최신 상태이고 승인되었는지, 제출한 서류가 도착지의 요건과 맞는지 확인하세요.

## 마이그레이션 후 확인할 것

번호를 성공적으로 옮겼더라도 옮겨 간 환경의 라우팅, 메시지, 규정 준수, 사용자 설정이 모두 이미 갖춰졌다고 볼 수는 없어요. 고객지원에서 마이그레이션 완료를 알려 주면 바로 번호를 검증해서, 정상 통화나 SMS 트래픽이 다시 들어오기 전에 문제를 찾아내세요.

1. 번호가 옮겨 간 환경에 표시되는지 확인합니다.
2. 다른 전화기에서 수신 테스트 통화를 겁니다.
3. 옮긴 번호로 발신 테스트 통화를 겁니다.
4. 메시지가 켜져 있다면 SMS 수신과 발신을 테스트합니다.
5. 통화 라우팅, 착신 전환, 음성 사서함, 사용자 배정, 워크플로우에서 해당 번호를 참조하는 부분을 검토합니다.
6. A2P 10DLC 상태를 확인합니다. A2P 등록은 번호가 아니라 계정/서브 계정 환경과 연결되어 있어서, 번호와 함께 옮겨진다고 가정하면 안 돼요. 옮겨 간 환경에서 등록을 완료하거나 확인하고, 해당 번호를 승인된 캠페인에 연결하세요.
7. 수신자 부담 번호(Toll-Free) 인증과 국가별 규정 준수 상태를 확인합니다. SMS를 쓰기 전에 옮긴 번호가 도착지 환경의 현재 규정 요건을 충족하는지 확인하세요.
8. 검증이 끝날 때까지 마이그레이션 티켓을 닫지 않고 열어 둡니다.

{% hint style="warning" %}
과거 녹음 파일과 음성 사서함: 전화번호를 옮겨도 과거 녹음 파일과 음성 사서함 자료는 새 전화 환경으로 옮겨지지 않아요. 보관해야 할 과거 자료는 출발지 환경에 접근할 수 없게 되기 전에 내려받으세요.
{% endhint %}

## 전화번호 마이그레이션 문제 해결

마이그레이션이 지연되는 이유는 대개 식별 정보 누락, 규정 요건, 잘못된 도착지 정보, 이동 후 설정 때문이에요. 먼저 마이그레이션 티켓을 열어 출발지, 도착지, 전화번호가 처음 요청한 내용과 같은지 확인하세요.

### 고객지원에서 추가 정보를 요청해요

티켓에 전화번호, 마이그레이션 방향, 해당하는 Twilio Account SID, 하이퍼클래스 위치 ID, 해외 번호의 규정 정보가 모두 들어 있는지 확인하세요.

### 해외 번호가 이동되지 않아요

해당 국가와 번호 유형에 맞는 규정 번들과 주소가 승인되었는지 확인하세요. 국가별 요건 때문에 규정 정보가 모두 갖춰질 때까지 이동이 늦어질 수 있어요.

### 번호는 옮겨졌는데 SMS가 안 돼요

도착지의 A2P 10DLC, 수신자 부담 번호 인증, SMS 권한 등 해당하는 규정 요건을 확인하세요. 전화번호를 옮겼다고 해서 도착지 계정에서 메시지 규정 준수가 자동으로 보장되지는 않아요.

### 번호는 옮겨졌는데 통화가 엉뚱하게 연결돼요

도착지 번호의 착신 전환 설정, 음성 사서함, 사용자 배정, 통화 라우팅, 그리고 해당 번호를 참조하는 워크플로우나 자동화를 확인하세요.

### 같은 에이전시 안에서 번호를 옮기려고 해요

옮길 수 있는 두 하이퍼클래스 전화 서브 계정이 같은 에이전시에 속해 있다면 계정 간 절차를 쓰지 마세요. **에이전시 설정 > 전화 연동**의 **번호 이동** 도구를 사용하세요.

## 자주 묻는 질문

### Twilio 고객지원에 티켓을 따로 열어야 하나요?

아니요. 이 문서에서 다루는 하이퍼클래스 전화 → Twilio, Twilio → 하이퍼클래스 전화, 서로 다른 에이전시 간 하이퍼클래스 전화 → 하이퍼클래스 전화 유형이라면 필요한 정보를 하이퍼클래스 고객지원에 제출하세요. 하이퍼클래스가 마이그레이션을 처음부터 끝까지 조율해요.

### 계정 간 마이그레이션에는 시간이 얼마나 걸리나요?

고객지원이 필요한 정보를 모두 받은 뒤 보통 영업일 기준 1~2일 정도 걸려요. 해외 번호이거나 추가 규정 검토가 필요한 마이그레이션은 더 오래 걸릴 수 있어요. 해당 전환 시간대는 고객지원이 알려 줘요.

### 한 번에 전화번호 여러 개를 마이그레이션할 수 있나요?

네. 해당하는 전화번호를 모두 하나의 목록에 담고, 출발지와 도착지를 명확히 표시하세요. 목록이 길다면 고객지원이 마이그레이션 중에 번호마다 검증할 수 있도록 번호를 정리해서 보내 주세요.

### A2P 10DLC 등록도 전화번호와 함께 옮겨지나요?

옮겨진다고 가정하지 마세요. A2P 상태는 전화번호만이 아니라 계정이나 서브 계정 환경과 연결되어 있어요. 마이그레이션 후에는 도착지에서 A2P 등록을 확인하거나 완료하고, 해당 번호가 승인된 캠페인에 연결되어 있는지 확인한 뒤에 A2P 메시지를 사용하세요.

### 과거 통화 녹음 파일과 음성 사서함도 함께 옮겨지나요?

아니요. 과거 녹음 파일과 음성 사서함 자료는 전화번호와 함께 자동으로 옮겨지지 않아요. 보관해야 할 과거 자료는 출발지 전화 환경에 접근할 수 없게 되기 전에 내려받으세요.

### 번호를 Twilio로 옮기기 전에 하이퍼클래스 전화를 비활성화하거나 삭제해야 하나요?

하이퍼클래스 고객지원이 안내하지 않는 한, 마이그레이션 중에는 번호를 수동으로 삭제, 해제, 비활성화하지 마세요. 마이그레이션 완료를 확인하고, 도착지 환경에서 번호를 테스트해 본 뒤에 진행하세요.

### 두 서브 계정이 같은 하이퍼클래스 에이전시에 있으면 어떻게 하나요?

옮길 수 있는 같은 에이전시 안의 하이퍼클래스 전화 → 하이퍼클래스 전화 이동은 이 문서의 고객지원 절차 대신 **에이전시 설정 > 전화 연동**의 기본 제공 **번호 이동** 도구를 사용하세요.

### 하이퍼클래스 전화나 Twilio 번호를 옮기는 것도 포팅과 같은가요?

아니요. 이 문서의 마이그레이션 절차는 옮길 수 있는 하이퍼클래스 전화나 Twilio 번호를 지원되는 계정 환경 사이에서 옮기는 것이에요. 번호가 다른 외부 통신사에 있다면 전화번호 포팅 절차를 이용하세요.
