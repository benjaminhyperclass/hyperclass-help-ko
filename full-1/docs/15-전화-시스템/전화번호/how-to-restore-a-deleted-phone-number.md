# 삭제한 전화번호 복구하기

실수로 삭제하거나 해제한 전화번호를 되살리는 방법을 안내해요. 하이퍼클래스 전화와 에이전시에 연결된 Twilio 계정을 기준으로 필요한 정보와 복구 후 확인할 사항까지 설명해요. 복구할 수 있는지는 사용 중인 전화 시스템, 번호를 삭제한 시점, 번호를 아직 쓸 수 있는지에 따라 달라요.

{% hint style="info" %}
이 문서는 사용 중인 계정에서 직접 삭제하거나 해제한 전화번호를 다뤄요. 하이퍼클래스 구독을 해지해서 삭제된 전화번호는 삭제 일정이 달라요.
{% endhint %}

---

## 삭제한 전화번호를 복구하면 좋은 점

- 고객 신뢰 유지: 번호를 저장해 둔 고객이 혼란스러워하지 않아요.
- 마케팅 일관성 유지: 광고, 랜딩 페이지, 인쇄물에 이미 실린 번호를 그대로 쓸 수 있어요.
- 리드 놓침 방지: 전화와 문자가 끊기지 않고 계속 들어와요.
- 번거로운 전환 방지: 새 번호를 설정하고 워크플로우를 다시 구성하는 시간과 수고를 아낄 수 있어요.
- 발신자 번호 이력 유지: 기존 연락처와 SMS 이력이 그대로 남아 평판을 지킬 수 있어요.

---

## 전화번호 복구 규칙과 유의 사항

- 10일 이내: 삭제한 날부터 10일 안에 번호를 복구해야 해요. 이 기간이 지나면 번호를 쓸 수 없어요.
- 되도록 빨리 진행하세요. 삭제하거나 해제한 번호는 제한된 기간에만 복구할 수 있고, 복구가 보장되지는 않아요. 번호가 아직 보관 중인지, 재고로 돌아갔거나 다른 곳에 다시 배정됐는지에 따라 달라요.
- 즉시 청구: 번호를 복구하면 Twilio가 바로 요금을 청구할 수 있어요.
- 번호를 더 이상 쓸 수 없으면 복구하지 못할 수 있어요.
- 번호를 복구해도 웹훅이나 통화 라우팅 설정은 자동으로 복원되지 않아요.
- Twilio는 삭제된 번호를 10일 동안 보관해요. 이 기간이 지나면 Twilio 고객지원에 직접 문의해서 복구를 요청해야 해요.
<!-- 검토 필요: 원문 내용이 서로 다름 -->
- 번호를 복구하면 복구 요금이 부과될 수 있어요.

{% hint style="warning" %}
하이퍼클래스 전화, Twilio, 서브 계정, 에이전시 사이에서 전화번호를 옮기려는 경우에는 번호를 먼저 삭제하거나 해제하지 마세요. 전화번호 이전은 별도 절차로 진행해요. 「계정 간 전화번호 이동(미국 및 해외)」 문서를 참고하세요.
{% endhint %}

## 하이퍼클래스 전화를 사용하는 경우

하이퍼클래스 전화(하이퍼클래스에서 제공하는 번호)를 쓰는 서브 계정에서 번호를 삭제했다면, 하이퍼클래스 고객지원이 복구해 줄 수 있어요. 단, 삭제한 지 10일 이내여야 해요. 하이퍼클래스 전화 번호는 하이퍼클래스가 관리하기 때문에, 번호가 배정돼 있던 **위치 ID**와 함께 고객지원에 문의해야 해요. 고객지원에서 번호를 아직 쓸 수 있는지 확인하고 복구를 대신 시도해 줘요.

하이퍼클래스 고객지원에 문의할 때 아래 정보를 준비하세요.

- 복구하려는 전화번호
- 번호가 배정돼 있던 서브 계정의 **위치 ID**
- 삭제한 날짜(대략적인 날짜)

그 다음에는 이렇게 진행돼요.

> 하이퍼클래스 고객지원이 번호를 아직 복구할 수 있는지 확인해요. 번호가 이미 해제됐거나 다른 곳에 다시 배정됐다면 복구가 보장되지 않아요.

![하이퍼클래스 전화 번호 복구 절차 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046032623/original/kGK3w-QWsllxiXq5FY0OAowiJZQedg3F7Q.gif?1746194333)

## 직접 만든 Twilio 계정을 사용하는 경우

하이퍼클래스 전화가 아니라 직접 만든 Twilio 계정을 쓴다면, 삭제한 지 10일 이내에 Twilio 콘솔에서 번호를 직접 복구해 볼 수 있어요. Twilio는 해제된 번호를 계정의 **Released Numbers**(해제된 번호) 섹션에 잠시 보관해요. 번호가 원래 배정돼 있던 Twilio 서브 계정을 찾아서 번호를 직접 다시 구매하면 돼요. 번호가 더 이상 보이지 않으면 Twilio 고객지원에 복구를 문의하세요.

### 1단계: 올바른 Twilio 서브 계정 찾기

Twilio에서 서브 계정으로 이동한 다음, 계정 이름을 클릭하세요.

![Twilio 서브 계정 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046033472/original/OsAMVfdE3xoi71alM_CNhIt0fUWuWqmKAg.gif?1746195040)

### 2단계: Twilio SID 찾기

Twilio 안에 서브 계정이 너무 많다면, 하이퍼클래스로 돌아가 해당 위치의 **계정 SID**를 복사해서 Twilio에서 검색할 수 있어요. 에이전시 관리자만 쓸 수 있어요. 하이퍼클래스의 **에이전시 보기**에서 **설정 > 전화 연동 > Subaccount Settings**(서브 계정 설정)로 이동해 서브 계정을 찾으세요.

![서브 계정 설정에서 서브 계정을 찾는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046320248/original/4h3AjdxYFQn_GxLNAcylGYWvFSXlUrnEEA.png?1746704591)

### 3단계: 계정 SID 복사하기

점 3개 아이콘을 클릭하고 **자격 증명 업데이트**를 선택한 다음, 서브 계정의 **계정 SID**를 복사하세요. 이 SID로 Twilio에서 서브 계정을 필터링하세요.

![자격 증명 업데이트에서 계정 SID를 복사하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046320445/original/NmMPnkB0lOJLNpQnHzb0z7wp6qPs3U7nCQ.png?1746704753)

### 4단계: Twilio 콘솔에서 해제된 번호를 찾아 다시 구매하기

왼쪽 메뉴에서 **전화번호** 탭을 펼치면 **관리** 섹션이 나와요. 여기서 **Released Numbers** 탭을 클릭하면 삭제한 전화번호를 찾을 수 있어요.

![Twilio 콘솔에서 Released Numbers 탭을 찾는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046321066/original/6yUlpWUmc_8nsSz6r7XWBqpTaJC__HX4TA.gif?1746705250)

{% hint style="info" %}
번호를 복구하려면 번호 옆의 **Repurchase**(다시 구매)를 클릭하세요(번호를 아직 쓸 수 있는 경우). 다시 구매하면 Twilio가 월 요금을 청구하기 시작해요.
전화번호를 찾을 수 없으면 계정 SID와 번호 정보를 준비해 Twilio 고객지원에 문의하세요.
{% endhint %}

| 전화 시스템 | 복구 방법 |
| --- | --- |
| 하이퍼클래스 전화 | 하이퍼클래스 고객지원에 문의하세요. 고객지원에서 번호를 복구할 수 있는지 확인해요. |
| 에이전시에 연결된 Twilio | 해당 Twilio 서브 계정의 **Released Numbers**에서 번호를 확인하고, 사용할 수 있으면 다시 구매하세요. |

## 번호를 복구한 뒤 확인할 사항

번호를 복구했다면 아래 항목을 확인하세요.

- 번호가 올바른 서브 계정에 표시되는지
- 수신 전화 라우팅이 올바르게 설정돼 있는지
- SMS와 통화가 정상적으로 작동하는지
- 해당하는 경우, 번호가 알맞은 사용자에게 배정돼 있는지
- 이 번호를 사용하는 워크플로우나 자동화가 여전히 올바르게 설정돼 있는지
- 해당되는 메시지·컴플라이언스 등록이 계속 유효한지

## 자주 묻는 질문

### 삭제한 Twilio 번호는 얼마 동안 복구할 수 있나요?

삭제한 날부터 최대 10일 안에 복구할 수 있어요. 이 기간이 지나면 Twilio가 번호를 영구적으로 해제할 수 있어요.

### 다른 사람이 제 예전 번호를 가져가면 어떻게 되나요?

번호가 이미 다른 곳에 다시 배정됐다면 복구할 수 없어요.

### 번호를 복구하면 요금이 다시 청구되나요?

네. 번호를 다시 구매하는 즉시 Twilio가 표준 월 요금을 청구하기 시작해요.

### 하이퍼클래스 전화 번호를 직접 복구할 수 있나요?

아니요. 하이퍼클래스 고객지원에 문의하고, 삭제된 전화번호와 번호가 배정돼 있던 서브 계정의 위치 ID를 알려 주세요.

### 직접 만든 Twilio 계정의 번호는 어떻게 복구하나요?

해당 Twilio 서브 계정을 열고 **전화번호 > 관리 > Released Numbers**에서 번호를 확인하세요. 번호를 아직 쓸 수 있으면 **Repurchase**를 사용하세요.

### 예전 워크플로우나 통화 설정도 자동으로 복원되나요?

아니요. 번호를 복구한 뒤 통화 라우팅, 웹훅, 자동화를 다시 설정해야 해요.

### 번호 풀에서 삭제한 번호도 이 방법으로 복구할 수 있나요?

번호 풀에서 삭제하는 경우는 동작 방식이 달라요. 풀에서 제거한 번호는 다시 배정할 수 있지만, 풀에서 삭제한 번호는 일반적인 재배정 절차로는 그 풀에 복구할 수 없어요. 「방문자 활동 추적을 위한 향상된 번호 풀 관리」 문서를 참고하세요.
