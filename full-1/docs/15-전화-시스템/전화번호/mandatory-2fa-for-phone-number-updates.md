# 전화번호 변경 시 2단계 인증 필수

하이퍼클래스에서 사용자의 전화번호를 바꿀 때는 2단계 인증(2FA)이 필요해요. 이 문서에서는 적용 방식과 대상, 그리고 이메일·문자 메시지(이미 인증된 번호로 수신)·인증 앱(TOTP) 중 하나로 인증을 마치는 방법을 안내해요.

## 전화번호 변경 시 2단계 인증이란?

프로필의 전화번호를 바꾸려고 하면 본인 확인 단계가 추가돼요. 이 확인은 **이미 인증된 수단**으로만 할 수 있어요. 기존 이메일, 인증된 기존 전화번호, 또는 사용 중인 TOTP 인증 앱이 해당돼요. 공격자가 번호를 바꿔 계정을 가로채는 일을 막기 위한 장치예요.

하이퍼클래스는 전화번호 변경을 저장하기 전에 2단계 인증을 확인해요. 인증 코드(OTP)는 신뢰할 수 있는 인증된 수단으로만 보내고, 새로 추가하려는 전화번호로는 절대 보내지 않아요.

## 2단계 인증의 장점

팀에서 이 변경을 이해하고 사용자에게 설명할 때 참고하세요. 관리자와 일반 사용자가 일상에서 체감하는 장점을 중심으로 정리했어요.

- **계정 보안:** 새 번호로는 OTP를 보내지 않으므로 전화번호 교체를 이용한 계정 탈취를 막아 줘요.
- **일관성:** 이메일 변경 시 2단계 인증을 거치는 방식과 같아서 프로필을 바꿀 때 헷갈리지 않아요.
- **컴플라이언스와 신뢰:** 중요한 프로필 정보에 대한 본인 확인이 강화돼요.
- **악용 방지:** 하루 시도 횟수를 제한해서 무차별 대입이나 스팸성 변경 요청을 줄여요.

## 사용 조건과 사전 준비

미리 인증된 수단이 하나라도 있어야 전화번호를 바꿀 때 2단계 인증을 통과할 수 있어요. 변경하기 전에 아래 항목을 확인하세요.

- 프로필에 **인증된 수단이 하나 이상** 있어야 해요.

  - 인증된 이메일(권장)
  - 인증된 전화번호(문자 메시지)
  - 인증 앱(TOTP) 사용 설정(선택, 권장)
- 변경하는 동안 선택한 수단을 직접 사용할 수 있어야 해요.
- 본인 프로필을 편집할 수 있는 역할과 권한이 있어야 해요. 관리자가 다른 팀원을 대신해 변경하려면 팀원 프로필을 편집할 수 있는 권한이 있어야 해요.

{% hint style="info" %}
지금 인증된 수단이 하나도 없다면, 전화번호를 바꾸다가 막히지 않도록 먼저 TOTP를 설정하거나 이메일을 인증하세요.
{% endhint %}

## 인증 수단과 표시 기준

하이퍼클래스는 내 계정에서 이미 신뢰할 수 있는 인증 수단만 보여 줘요. 어떤 수단이 왜 보이는지 알아 두세요.

- **이메일**(인증된 기존 이메일로 OTP 수신): 이메일이 인증되어 있으면 항상 표시돼요.
- **문자 메시지**(인증된 기존 전화번호로 OTP 수신): 현재 등록된 전화번호가 이미 인증된 경우에만 표시돼요.
- **인증 앱 사용**(TOTP): 인증 앱을 이전에 설정했다면 표시돼요.
- 사용할 수 없는 방식: 새로 추가하려는 전화번호로는 OTP를 보낼 수 없어요.

화면에는 사용할 수 있는 수단만 나열된 **인증 방법 선택** 창이 나타나요.

## 횟수 제한 규칙

횟수 제한은 계정이 악용되는 것을 막아 줘요. 제한을 알아 두면 변경 일정을 계획하고, 변경이 막혔을 때 원인을 찾기 쉬워요.

- 사용자 한 명당 하루에 전화번호·이메일 변경을 최대 5번까지 시도할 수 있어요.
- 하루 한도에 도달하면 횟수가 초기화될 때까지 추가 시도가 차단돼요.
- 한도에 도달하면 앱에서 한도에 도달했으니 나중에 다시 시도하라는 안내 메시지가 나와요.

{% hint style="info" %}
예상하지 못한 한도 안내가 나오면, 같은 날 다른 관리자나 자동화 작업이 나를 대신해 변경을 시도했는지 확인해 보세요.
{% endhint %}

## 관리자와 사용자의 변경 경로

진행 방식은 비슷하지만, 관리자는 팀원을 대신해 변경을 시작할 수 있어요. OTP를 누가 받는지, 어디서 시작하는지 알아 두면 헷갈리지 않아요.

- 본인이 직접 변경(사용자): 내 프로필에서 시작하고, 인증된 수단을 선택해 2단계 인증을 마쳐요.
- 관리자가 대신 변경(팀원): **설정 > 팀**(또는 팀 관리 페이지)에서 시작해요. OTP는 관리자가 아니라 **팀원의 인증된 수단**으로 전송돼요.

## 보안과 감사 관련 안내

아래 안전장치는 프로필 변경 과정을 안전하게 관리하고, 수상한 활동을 빠르게 알아채는 데 도움이 돼요.

- OTP는 새로 추가하는 전화번호로 절대 보내지 않아요.
- 인증된 수단으로만 OTP를 받을 수 있어요.
- 무차별 대입을 막기 위해 변경 시도에는 하루 횟수 제한이 있어요.
- (사용 중인 요금제에서 지원하는 경우) 감사 로그나 활동 로그에서 누가 언제 변경을 시작했는지 확인할 수 있어요.
- 문자 메시지를 받을 수 없을 때도 쓸 수 있도록 TOTP를 설정해 두는 것을 고려해 보세요.

## 전화번호 변경 시 2단계 인증 사용 방법

아래 순서대로 전화번호를 안전하게 변경하세요. 본인이 직접 변경하는 방법과 관리자가 변경하는 방법을 모두 안내해요.

### A) 내 전화번호 직접 변경하기

1. **설정 > 내 프로필**로 이동하세요(또는 사용자 프로필 페이지로 이동하세요).

   ![설정의 내 프로필 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080705808/original/cyvwBHYBGSz3ghTKfNhu_wEFDREyv-mdNA.png?1789126693)
2. **Personal Data**(개인 정보) 항목에서 전화번호를 편집하세요.

   ![개인 정보에서 전화번호 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080705833/original/GJZM91-nhhp6jhAmIzx2n7QyUKOvU84UVw.png?1789126711)
3. 새 전화번호를 입력하고 **프로필 업데이트**를 클릭하세요.

   ![새 전화번호 입력 후 프로필 업데이트](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063875949/original/MqSdAuPEh4N3lY-HWYJGtECKd54GTLj0Pw.png?1769787233)
4. **인증 방법 선택** 창이 열리면 사용할 수 있는 수단 중 하나를 선택하세요.

   - **이메일**: 인증된 이메일로 OTP가 전송돼요.
   - **문자 메시지**: 인증된 기존 전화번호로 OTP가 전송돼요.
   - **인증 앱 사용**: 인증 앱에 표시된 6자리 TOTP 코드를 입력해요.

     ![인증 방법 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063875835/original/8xe0SRVza2IFmPpZ6c_gY-s9ms24Eq4oFQ.png?1769787134)
5. **계속**을 클릭하세요. **이메일**이나 **문자 메시지**를 선택했다면 받은 OTP를 입력해 인증하세요.

   ![OTP 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063875883/original/FsQR5v4HSJPGwyLDFYxJYBOst07cKnPEsw.png?1769787167)
6. 인증에 성공하면 변경을 확인하세요. 성공 메시지가 나타나고, 프로필에 새 번호가 반영돼요.

{% hint style="warning" %}
**문자 메시지**가 선택지에 보이지 않으면 현재 등록된 전화번호가 인증되지 않은 상태예요. **이메일**이나 **인증 앱 사용**으로 진행하거나, 먼저 전화번호를 인증하세요.
{% endhint %}

### B) 팀원의 전화번호 변경하기 (관리자)

1. **설정 > 팀**으로 이동해 팀원의 프로필을 여세요.

   ![설정의 팀 화면에서 팀원 프로필 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080705888/original/sl4zLKmJLmR6pbR6gq2u7PhJyexS5Kkflg.png?1789126744)
2. **전화번호**를 **편집**하고 새 번호를 입력하세요.

   ![팀원 전화번호 편집](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080706898/original/cVCo8j598y4_8xHd9lQ1-hFImsv3dz_5bQ.png?1789127238)
3. **인증 방법 선택** 창에서 사용할 수 있는 수단을 선택하세요. 코드는 **팀원의** 인증된 이메일이나 전화번호로 전송돼요. 팀원이 자신의 인증 앱에 표시된 코드를 알려 줄 수도 있어요.

   ![팀원 인증 방법 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063876182/original/mDHi_zKqFVMHuS3Iilc6XCVGTH3Ic_6KQA.png?1769787441)
4. OTP를 입력하고(또는 팀원에게 안전한 방법으로 받아서 입력하고) **계속**을 클릭해 변경을 마치세요.

{% hint style="info" %}
보안 안내: OTP는 새로 추가하는 번호로는 전송되지 않아요.
{% endhint %}

## 문제 해결

오류가 나거나 인증을 마칠 수 없을 때 아래 내용을 확인해 보세요.

- 사용할 수 있는 인증 방법이 없어요: 먼저 TOTP를 설정하거나 이메일을 인증하세요. 진행하려면 인증된 수단이 하나 이상 있어야 해요.
- **문자 메시지**가 보이지 않아요: 현재 등록된 전화번호가 인증되지 않은 상태예요. 이메일이나 TOTP를 사용하거나, 기존 번호를 먼저 인증하세요.
- OTP가 오지 않아요: 스팸함이나 정크 메일함을 확인하세요. 문자라면 통신 신호가 잘 잡히는지 확인하고, 재전송 대기 시간이 지난 뒤 새 코드를 요청하세요.
- **일일 한도 도달**이 표시돼요: 하루 5번 시도 한도에 도달한 상태예요. 횟수가 초기화될 때까지 기다린 뒤 다시 시도하세요. 문자 메시지에 덜 의존하도록 TOTP 설정을 마쳐 두는 것도 방법이에요.
- 이메일과 전화번호 모두 사용할 수 없어요: (사용 설정을 했다면) 백업 코드를 사용하거나, 계정 소유자나 관리자에게 도움을 요청하세요.

## 자주 묻는 질문

### 새 전화번호로는 왜 OTP를 받을 수 없나요?
보안을 위해 OTP는 내 계정에서 이미 인증된 수단으로만 전송돼요. 공격자가 새 번호를 추가한 뒤 그 번호로 OTP를 받는 일을 막아 줘요.

### 인증 방법에 문자 메시지가 보이지 않아요. 어떻게 하나요?
**문자 메시지**는 **기존** 전화번호가 인증된 경우에만 표시돼요. **이메일**이나 **인증 앱 사용**(TOTP)으로 진행하거나, 먼저 현재 전화번호를 인증하세요.

### 하루에 몇 번까지 변경을 시도할 수 있나요?
사용자 한 명당 하루에 전화번호·이메일 변경을 최대 **5**번까지 시도할 수 있어요. 한도를 넘기면 횟수가 초기화될 때까지 일시적으로 차단돼요.

### 관리자가 사용자의 전화번호를 바꾸면 OTP는 누가 받나요?
편집 대상이 되는 **사용자**가 받아요. OTP는 관리자가 아니라 해당 사용자의 인증된 수단으로 전송돼요.

### 이메일이나 문자 메시지 대신 인증 앱을 사용할 수 있나요?
네, 계정에 **TOTP**를 설정해 두었다면 인증 단계에서 **인증 앱 사용**을 선택하고 현재 표시된 6자리 코드를 입력하면 돼요.

### 이메일과 전화번호 모두 사용할 수 없게 되면 어떻게 하나요?
(사용 가능한 경우) 백업 코드를 사용하거나, 계정 소유자나 관리자에게 본인 확인과 복구 지원을 요청하세요.

### 이메일 주소를 바꿀 때도 달라지는 점이 있나요?
이메일 변경에는 이미 2단계 인증이 적용되어 있어요. 이제 전화번호 변경도 같은 보안 기준을 따라요.
