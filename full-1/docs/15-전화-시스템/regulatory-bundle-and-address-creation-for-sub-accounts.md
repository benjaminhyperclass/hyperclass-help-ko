# 서브 계정에서 규정 번들과 주소 번들 만들기

일부 국가의 전화번호는 구매하거나 활성화하기 전에 신원, 주소, 규제 관련 정보를 확인받아야 해요. 이 문서에서는 서브 계정에서 주소 번들과 규정 번들을 만들어 제출하고, 심사 상태를 확인하고, 승인된 번들을 번호 구매에 연결하는 방법을 안내해요.

## 개요

일부 전화번호는 구매하거나 활성화하기 전에 신원, 주소, 규제 정보를 확인받아야 해요. 하이퍼클래스 전화 사용자는 서브 계정의 **전화 시스템 > 규정 번들/주소**에서 이 정보를 직접 만들고 관리할 수 있어요.

- **주소 번들**: 신원 정보와 실제 주소 정보를 저장해요.
- **규정 번들**: 국가와 번호 유형별로 현지 통신 규정이 요구하는 정보를 모아 저장해요.

이 문서에서는 번들이 각각 언제 필요한지, 번들을 어떻게 만들고 제출하는지, 상태를 어떻게 확인하는지, 승인된 번들을 번호 구매에 어떻게 쓰는지, 삭제 보호 장치가 어떻게 작동하는지 설명해요.

{% hint style="warning" %}
미국이나 캐나다에서 일반 전화번호를 구매할 때는 규정 번들이 필요하지 않아요. 다만 신원 확인이나 메시지 관련 등록 같은 다른 확인 절차는 적용될 수 있어요.

미국과 캐나다 외 지역의 요건은 국가, 번호 유형, 사용 목적, 현지 규정에 따라 달라요. 구매하려는 번호에 대해 하이퍼클래스에 표시되는 입력란과 서류 요건을 그대로 따르세요.
{% endhint %}

## 규정 번들이란?

규정 번들과 주소 번들은 일부 전화번호를 개통하는 데 필요한 신원, 위치, 규정 준수 정보를 제공해요. 규제 대상 번호를 쓰는 개인이나 사업자가 해당 국가와 번호 유형의 요건을 충족하는지 확인하는 데 쓰여요.

**주소 번들**에는 사업자나 개인의 신원 정보와 실제 주소 정보를 저장해요. **규정 번들**에는 특정 국가나 번호 유형에서 요구할 때 추가 규정 준수 정보와 증빙 서류를 저장해요.

이런 요건은 해외 전화번호를 구매할 때 가장 많이 만나요. 번호를 구매하는 과정에서 해당 요건이 하이퍼클래스에 표시되니, 안내에 따라 필요한 절차를 완료하세요.

### 주소 번들과 규정 번들의 장점

규제 대상 번호를 구매하기 전에 알맞은 번들을 만들어 두면 구매 실패를 줄일 수 있어요. 필요한 규정 준수 정보도 서브 계정 안에서 정리해 둘 수 있어요.

- 규정 준수: 규제 국가에서 전화번호를 개통하는 데 필요한 정보를 제공해요.
- 구매 준비: 해당 번호를 구매하기 전에 필요한 주소 확인과 규정 확인을 미리 마칠 수 있어요.
- 앱 안에서 관리: 번들 기록을 하이퍼클래스에서 바로 만들고, 제출하고, 확인하고, 관리해요.
- 자동 입력: 이미 저장된 위치 프로필 정보를 다시 활용해 주소를 반복해서 입력하지 않아도 돼요.
- 명확한 심사 상태: **규정 번들/주소** 목록에서 번들 진행 상황을 확인해요.
- 삭제 보호: 사용 중인 연결 항목이 있는 번들이나 주소는 삭제되지 않게 막아 줘요.

### 주소 번들과 규정 번들의 차이

알맞은 번들 유형을 고르면 불필요한 제출을 줄이고, 전화번호를 국가와 번호 유형에 맞는 규정 준수 정보에 연결할 수 있어요.

| 번들 유형 | 용도 | 필요한 경우 |
| --- | --- | --- |
| **주소 번들** | 사업자나 개인의 신원 정보와 실제 주소 정보를 저장해요. | 선택한 전화번호에 승인된 주소가 필요할 때 |
| **규정 번들** | 국가와 번호 유형별 규정 준수 정보와 증빙 서류를 저장해요. | 현지 통신 규정이 추가 신원 확인이나 사업 확인을 요구할 때 |

어떤 번들을 만들어야 하는지는 번호를 구매할 때 표시되는 요건을 기준으로 판단하세요. 해외 번호 중에는 주소 번들만 필요한 경우도, 규정 번들만 필요한 경우도, 둘 다 필요한 경우도 있어요.

## 사업 세부정보 자동 입력

하이퍼클래스는 서브 계정에 저장된 프로필 정보로 주소 번들 입력란을 미리 채울 수 있어요. 제출하기 전에 이 값을 확인하면 번들 내용과 사업자 확인에 쓰는 서류가 서로 달라지는 일을 막을 수 있어요.

프로필 정보로 다음과 같은 항목이 자동으로 채워질 수 있어요.

- 사업자 또는 고객 이름
- **주소 1**
- **주소 2**
- 시/군/구
- 시/도 또는 지역
- 우편번호
- **국가**

자동으로 채워진 항목도 수정할 수 있어요. 프로필에 없는 정보는 직접 입력하고, 제출하는 내용이 증빙 서류와 일치하는지 확인하세요.

## 주소 번들과 규정 번들 설정하기

번호를 쓸 서브 계정에서 번들을 만들면 규정 정보가 알맞은 위치에 연결돼요. 국가별 심사에서는 입력한 내용과 업로드한 서류가 정확히 일치해야 할 수 있으니, 요청하는 항목을 꼼꼼히 입력하세요.

### 1단계: 규정 번들/주소 열기

1. 전화번호를 사용할 서브 계정을 열어요.
2. **설정**을 클릭해요.
3. **비즈니스 서비스** 아래에서 **전화 시스템**을 열어요.
4. **규정 번들/주소**를 선택해요.

![서브 계정 대시보드에서 설정 메뉴를 강조한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080148462/original/pUaQH9xhC1uLd8eDEjEsyPLQRqrrpZju6Q.png?1788546551)

서브 계정 대시보드에서 **설정**을 강조한 화면이에요.

![전화 시스템의 규정 번들/주소 화면과 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080148485/original/rXXNOnnuMdMqGASh8B3NgMN0NVso9-Kkzw.png?1788546573)

**전화 시스템 > 규정 번들/주소** 화면과 **만들기** 버튼이에요.

### 2단계: 주소 번들 만들기

1. **+ 만들기**를 클릭해요.
2. **주소 번들**과 **규정 번들** 옵션을 확인해요.
3. **주소 번들**을 선택해요. 번들 선택 창에서는 기본으로 선택되어 있어요.
4. **다음**을 클릭해요.
5. 요청하는 사업자 정보와 주소 정보를 확인하거나 입력해요.
6. **제출**을 클릭해요.

![주소 번들이 선택된 번들 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080148489/original/EdnQh_KJ8LA6xPJRkr0mKteqiW_k3PLzaw.png?1788546586)

**주소 번들**이 선택된 번들 선택 창이에요.

![수정할 수 있는 주소 입력란과 제출 버튼이 있는 사업 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080148493/original/5m62UyWGIeVXosNSVzwyiZA6FM8aoRiZYg.png?1788546604)

**비즈니스 정보 입력** 화면에서는 주소 입력란을 수정할 수 있고 **제출** 버튼이 있어요.

### 3단계: 규정 번들 만들기

1. **전화 시스템 > 규정 번들/주소**로 돌아가요.
2. **+ 만들기**를 클릭해요.
3. **규정 번들**을 선택해요.
4. 필요한 **국가**를 선택해요.
5. 알맞은 **번호 유형**을 선택해요. 지역 번호(Local), 모바일(Mobile), 국가 번호(National), 수신자 부담 번호(Toll-Free) 등이 있고, 선택할 수 있는 유형은 국가에 따라 달라요.
6. 요청하는 사업자, 개인 또는 대표자 정보를 입력해요.
7. 양식에서 요청하는 증빙 서류를 각각 업로드해요.
8. 입력한 내용을 확인한 뒤 번들을 제출해 심사를 요청해요.

서류 요건은 국가와 번호 유형마다 달라요. 한 국가나 번호 유형의 요건이 다른 곳에도 똑같이 적용된다고 생각하지 마세요. 지금 만드는 번들에 표시되는 입력란과 업로드 안내를 따르세요.

### 4단계: 번들 상태 확인하기

**규정 번들/주소**로 돌아가 제출한 번들을 확인해요. 목록에는 국가, 번들 유형, **Bundle ID**(번들 ID), 번호 유형 또는 주소, 현재 상태가 표시돼요.

번들이 거부되면 안내된 사유를 확인하고, 요청받은 정보나 서류를 고쳐요. 화면에서 다시 제출할 수 있는 옵션이 나오면 그때 다시 제출하세요. 심사 요건은 국가와 제출 내용에 따라 다르니, 정해진 승인 시간이 있다고 기대하지 마세요.

![번들 ID와 심사 상태가 표시된 규정 번들/주소 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080148494/original/mkTHjvcHR80OGxjFRoOK1eiS5HeEGKbgQA.png?1788546618)

번들 ID와 심사 상태가 표시된 **규정 번들/주소** 목록이에요.

## 승인된 번들을 전화번호에 연결하기

번들을 만든다고 해서 모든 전화번호 구매가 자동으로 완료되지는 않아요. 선택한 번호에 규정 정보가 필요하면, 번호를 개통하기 전에 승인된 번들을 구매에 연결해야 해요.

1. 해당 서브 계정을 열어요.
2. **설정 > 전화 시스템**으로 이동해요.
3. **번호 관리**를 열어요.
4. **+ Add Number**(번호 추가)를 클릭하고 **전화번호 추가**를 선택해요.
5. 원하는 국가, 번호 유형, 구매 가능한 전화번호를 선택해요.
6. 구매 화면으로 이동해요.
7. 하이퍼클래스에서 규정 정보를 요구하면 승인된 **주소 번들** 또는 **규정 번들**을 선택해요.
8. 나머지 구매 절차를 완료해요.

![번호 관리에서 번호 추가를 거쳐 전화번호 추가를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080148508/original/klz2a1hnu6hTYbaBGuPFl8989bUaAvRTfw.png?1788546628)

**번호 관리** > **+ Add Number** > **전화번호 추가** 화면이에요.

## 번들과 주소 관리 및 삭제하기

번들을 관리할 때는 확인 창과 연결 항목 보호 장치가 작동해요. 전화번호나 개통 작업에서 아직 쓰고 있는 규정 정보가 실수로 삭제되지 않게 막아 주는 장치예요.

### 번들 또는 주소 삭제하기

1. **전화 시스템 > 규정 번들/주소**로 이동해요.
2. 삭제하려는 번들이나 주소를 찾아요.
3. 사용할 수 있는 작업 메뉴를 열고 삭제 옵션을 선택해요.
4. 확인 창의 내용을 살펴봐요.
5. 삭제를 확정하기 전에 표시된 **유형**, **국가**, **Bundle ID**(번들 ID)가 맞는지 확인해요.

![유형, 국가, 번들 ID가 표시된 규정 번들 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080148518/original/0Fk3CaNSjlDgwFboFfDTO3ZRaQSUiUIsNQ.png?1788546642)

**유형**, **국가**, **Bundle ID**가 표시된 규정 번들 삭제 확인 창이에요.

{% hint style="warning" %}
삭제하면 되돌릴 수 없어요. 번들이나 주소를 이미 사용 중이면, 사용 중인 연결 항목을 보호하기 위해 하이퍼클래스가 삭제 옵션을 비활성화할 수 있어요. 다른 번들이나 주소를 써야 한다면 먼저 연결된 항목을 제거하거나 변경하세요.
{% endhint %}

## 규정 번들 문제 해결

번들 문제는 대부분 규정 요건 누락, 사업 정보 불일치, 서류 미비, 또는 선택한 국가와 번호 유형에서 아직 승인되지 않은 번들을 쓰려는 경우에 생겨요.

### 전화번호를 구매할 수 없어요

선택한 번호에 주소 번들, 규정 번들, 신원 확인 또는 다른 규정 준수 절차가 필요한지 확인하세요. 구매 과정에 표시된 요건을 먼저 완료한 뒤 다시 시도하세요.

### 규정 번들이 거부됐어요

거부 사유를 확인하고, 제출한 이름, 주소, 등록 정보, 서류를 서로 비교해 보세요. 요청받은 항목을 고친 뒤, 번들 절차에서 허용하면 다시 제출하세요.

### 구매할 때 알맞은 번들이 보이지 않아요

번들을 올바른 서브 계정에서 만들었는지, 필요한 국가와 번호 유형에 맞는지, 필요한 심사를 마쳤는지 확인하세요.

### 삭제 옵션이 비활성화되어 있어요

번들이나 주소가 사용 중인 연결 항목과 이어져 있을 가능성이 커요. 하이퍼클래스에 표시되는 설명을 확인하고, 연결된 항목을 제거하거나 변경한 뒤 다시 삭제하세요.

### 알맞은 해외 번호가 나타나지 않아요

번호 재고는 국가, 번호 유형, 재고 상황, 규정 요건에 따라 바뀔 수 있어요. 필요한 번들을 모두 완료했는지 확인하고, 검색 필터를 넓혀 보세요. 그래도 재고가 없으면 구매할 수 없는 번호를 요청하는 절차를 따르세요.

## 자주 묻는 질문

### 미국이나 캐나다 전화번호에도 규정 번들이 필요한가요?

일반적인 미국·캐나다 번호 구매에는 규정 번들이 필요하지 않아요. 다만 번호와 사용 목적에 따라 신원 확인, A2P 10DLC 등록, 수신자 부담 번호 인증(Toll-Free Verification) 같은 별도 요건은 적용될 수 있어요.

### 모든 해외 전화번호에 같은 서류가 필요한가요?

아니요. 필요한 입력란과 서류는 국가, 번호 유형, 사업자 또는 개인 사용 여부, 현지 규정에 따라 달라요. 만들고 있는 번들에 표시된 요건을 따르세요.

### 규정 번들 승인에는 얼마나 걸리나요?

심사 시간은 국가, 번호 유형, 서류 상태, 해당 규제 심사에 따라 달라요. 정해진 승인 시간을 기대하지 말고, **규정 번들/주소**의 **Status**(상태) 열에서 진행 상황을 확인하세요.

### 승인된 규정 번들을 여러 전화번호에 쓸 수 있나요?

같은 규정 요건이 적용되는 다른 번호라면 승인된 번들을 다시 사용할 수 있어요. 선택한 번호에 그 번들을 쓸 수 있는지는 구매 과정에서 판단돼요.

### 사업 세부정보가 잘못 자동 입력됐어요. 어떻게 하나요?

주소 번들을 제출하기 전에 수정할 수 있는 입력란을 고치세요. 확인에 사용할 사업자 서류나 신원 서류와 같은 내용이어야 해요.

### 제출한 규정 번들을 수정할 수 있나요?

번들의 상태와 규정 절차에 따라 쓸 수 있는 작업이 달라요. 거부된 번들에 수정이나 재제출 옵션이 있으면 심사자의 안내를 따르세요. 제출한 기록을 수정할 수 없으면 올바른 정보로 새 번들을 만드세요.

### 주소 번들이나 규정 번들이 삭제되지 않아요

항목이 사용 중인 연결 항목과 이어져 있으면 하이퍼클래스가 삭제를 막아요. 화면에 표시된 메시지를 확인하고, 연결된 항목을 제거하거나 변경한 뒤 번들이나 주소를 삭제하세요.

### 번들 문제로 하이퍼클래스 고객지원에 문의할 때 어떤 정보를 보내야 하나요?

문제가 생긴 서브 계정, 국가, 번호 유형, Bundle ID 또는 주소 ID, 현재 상태, 거부 메시지, 문제 화면 스크린샷을 함께 보내 주세요. 구매 중에 문제가 생겼다면 구매하려는 전화번호나 번호 유형도 알려 주세요.
