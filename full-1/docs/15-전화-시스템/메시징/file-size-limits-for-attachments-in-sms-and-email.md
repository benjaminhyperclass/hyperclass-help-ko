# SMS·이메일 첨부 파일 용량 제한

하이퍼클래스에서 SMS/MMS와 이메일에 파일을 첨부할 때 적용되는 용량 제한을 설명해요. 파일을 직접 첨부해서 보낼 수 있는 경우와, 용량이 커서 **미디어 라이브러리**(Media Library) 링크로 보내는 경우의 차이를 알 수 있어요.

## 첨부 파일 용량 제한이란?

첨부 파일 용량 제한에 따라 파일을 MMS나 이메일에 직접 첨부해 보낼 수 있는지, 다른 방법으로 공유해야 하는지가 정해져요. 제한을 알아 두면 발송 실패를 줄일 수 있어요. 또 하이퍼클래스가 원본 파일 대신 **미디어 라이브러리** 링크를 보내는 때가 언제인지도 알 수 있어요.

### 용량 제한을 알면 좋은 점

- 발송 성공률 향상: 지원 한도를 넘는 첨부 파일 때문에 생기는 발송 문제를 줄일 수 있어요.
- 채널별 조건 파악: SMS/MMS와 이메일의 첨부 파일 처리 방식이 어떻게 다른지 알 수 있어요.
- 간편한 파일 처리: 직접 보낼 수 없는 파일은 **미디어 라이브러리**로 공유할 수 있어요.
- 수작업 감소: 파일을 압축하거나 외부 호스팅 서비스를 쓸 일이 줄어요.
- 더 높은 반응: 지원되는 동영상 썸네일과 파일 링크를 쓰면 받는 사람이 더 쉽게 파일을 열어 볼 수 있어요.

## SMS 첨부 파일 용량 제한

SMS는 텍스트만 지원해요. 지원되는 미디어를 문자 메시지와 함께 직접 보내면 MMS로 발송돼요. 용량, 파일 형식, 발송 조건 때문에 파일을 직접 보낼 수 없으면, 하이퍼클래스가 **미디어 라이브러리**를 이용해 클릭할 수 있는 링크로 파일을 공유할 수 있어요.

MMS로 직접 보낼 수 있는 대표적인 이미지 형식은 다음과 같아요.

- JPEG
- PNG
- GIF

{% hint style="info" %}
MP3, MP4, PDF 같은 다른 미디어 형식은 통신사, 기기, MMS로 직접 발송할 수 있는지에 따라 다르게 처리될 수 있어요. 직접 발송할 수 없는 파일은 **미디어 라이브러리** 링크로 공유할 수 있어요.
{% endhint %}

### 통신사별 MMS 파일 용량 제한

통신사와 번호 유형에 따라 제한이 달라질 수 있어요. 가장 폭넓게 호환되려면, 기술적으로 더 높은 한도가 지원되더라도 MMS 직접 첨부 파일을 500 KB 이하로 유지하는 것이 안전해요.

| 통신사 | Long Code MMS | Toll-Free MMS | Short Code MMS |
| --- | --- | --- | --- |
| AT&T\* | 1.0 MB | 0.6 MB | 0.6 MB |
| T-Mobile | 1.5 MB | 0.6 MB | 1.0 MB |
| Verizon | 1.0 MB | 0.6 MB | 1.2 MB |

### MMS용 Short Code, Toll-Free, Long Code 지원 현황

Long Code, Short Code, Toll-Free 번호 모두 MMS를 지원해요. 최대 용량은 통신사와 번호 유형에 따라 다를 수 있어요. 아래 값은 발송이 보장되는 기준이 아니라 상한선으로 봐 주세요.

| 메시지 유형 | MMS 지원 여부 | 최대 용량 참고값 |
| --- | --- | --- |
| Long Code (10DLC) | ✅ 지원 | 통신사별로 다름 |
| Short Code | ✅ 지원 | 최대 5 MB |
| Toll-Free | ✅ 지원 | 최대 5 MB |

## 이메일 첨부 파일 용량 제한

하이퍼클래스는 이메일 작성창에서 직접 첨부할 수 있는 파일 용량을 제한해요. 받는 쪽이나 보내는 쪽 이메일 서비스에도 각자의 제한이 있을 수 있어요. 첨부 파일을 하이퍼클래스 작성창의 제한 안에서 보내면 발송 문제를 줄일 수 있어요.

{% hint style="info" %}
하이퍼클래스 이메일 작성창에서는 최대 20 MB까지 직접 첨부할 수 있어요. 이보다 큰 파일은 **미디어 라이브러리**에 업로드되고, 직접 첨부 대신 클릭할 수 있는 링크로 공유돼요.
{% endhint %}

## 대화에서 첨부 파일 업로드하기

**대화**에서 SMS/MMS나 이메일을 작성할 때, 내 기기에서 파일을 직접 첨부하거나 **미디어 라이브러리**에 있는 파일을 선택할 수 있어요. 아래 순서대로 첨부 옵션을 찾아보세요.

1. **대화** 탭에서 대화를 열고, 메시지 입력창의 점 세 개 아이콘(•••)을 클릭하세요.

   ![메시지 입력창의 점 세 개 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044663694/original/VghkbqBAuqr7F9TfukAwR8BHZYkE5mrw0w.png?1744036309)

2. **파일 첨부**를 선택하세요. 두 가지 옵션이 보여요.

   ![파일 첨부 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044664243/original/e_BCXDXK9OyFh8A9HY6SbLrdGNs4rJ6OUg.png?1744036710)

   - **내 컴퓨터에서 업로드**: 내 기기에 있는 파일을 선택해요.
   - **미디어 라이브러리에서 선택**: 이전에 업로드한 파일을 선택해요.

### 직접 보낼 수 없는 파일은 자동으로 처리돼요

- 이메일: 20 MB를 넘는 파일은 **미디어 라이브러리**에 업로드되고, 메시지에 클릭할 수 있는 링크로 들어가요.
- SMS/MMS: 용량, 형식, 채널 조건 때문에 직접 발송할 수 없는 파일도 **미디어 라이브러리** 링크로 공유할 수 있어요.

{% hint style="warning" %}
동영상을 업로드하면 썸네일이 자동으로 만들어져요. 이메일에 쓰려고 **미디어 라이브러리**에 동영상 파일을 업로드하면, 하이퍼클래스가 **GIF 썸네일**을 만들 수 있어요. 받는 사람은 이 썸네일로 영상을 미리 보고, 클릭해서 열 수 있어요.
{% endhint %}

## 클립보드에서 첨부 파일 붙여넣기

클립보드 붙여넣기를 쓰면 첨부 메뉴를 열지 않고도 지원되는 파일이나 이미지를 빠르게 첨부할 수 있어요.

1. 컴퓨터에서 지원되는 파일이나 이미지를 복사하세요.
2. **대화**의 메시지 입력창 안을 클릭하세요.
3. `Ctrl + V`(Windows) 또는 `Cmd + V`(Mac)를 누르세요. 마우스 오른쪽 버튼을 눌러 **붙여넣기**를 선택해도 돼요.

붙여넣은 파일은 현재 메시지에 추가되고, 위에서 설명한 첨부 파일 용량 및 발송 규칙이 똑같이 적용돼요.

## 용량이 큰 파일 보내기

큰 파일이라고 해서 항상 압축하거나 하이퍼클래스 밖에 올려야 하는 것은 아니에요. 직접 첨부 한도를 넘는 파일은 **미디어 라이브러리**를 통해 링크로 공유할 수 있어요.

- 이메일 또는 SMS/MMS 작성창에서 파일을 업로드하세요.
- 20 MB가 넘는 이메일 파일은 **미디어 라이브러리**에 저장되고, 클릭할 수 있는 링크로 들어가요.
- 직접 발송할 수 없는 SMS/MMS 파일은 **미디어 라이브러리** 링크로 공유할 수 있어요.
- 하이퍼클래스 밖에서 파일을 관리해야 할 때만 외부 클라우드 호스팅을 사용하세요.
- 이메일에 보여 줄 썸네일을 하이퍼클래스가 만들어 주기를 원하면, **미디어 라이브러리**에 동영상을 업로드해서 사용하세요.

## 자주 묻는 질문

### 미디어 라이브러리에 업로드한 파일에도 MMS나 이메일 직접 첨부와 같은 용량 제한이 적용되나요?

아니요. **미디어 라이브러리**의 저장 용량 제한과 메시지 직접 발송 제한은 서로 달라요. 파일이 너무 크거나 다른 이유로 MMS나 이메일에 직접 첨부할 수 없어도 **미디어 라이브러리**에는 저장될 수 있어요.

### 하이퍼클래스가 파일을 직접 첨부하지 않고 호스팅하면 받는 사람에게는 어떻게 보이나요?

원본 파일을 직접 첨부하는 대신, 호스팅된 파일로 연결되는 링크가 메시지에 들어가요. 받는 사람은 그 링크를 클릭해서 파일을 열어요.

### 지원되는 미디어를 추가해도 항상 SMS로 발송되나요?

아니요. SMS는 텍스트만 지원해요. 지원되는 미디어를 직접 발송하면 메시지가 MMS로 바뀌어요.

### 하이퍼클래스에는 파일을 저장할 수 있는데, MMS 직접 첨부는 왜 실패하나요?

미디어 저장 용량 제한과 통신사의 발송 제한은 별개예요. 통신사는 MMS 직접 발송에 하이퍼클래스에 저장할 수 있는 파일 크기보다 낮은 제한을 둘 수 있어요.

### MMS 용량 제한은 모든 통신사에서 똑같이 보장되나요?

아니요. MMS 제한은 통신사와 번호 유형에 따라 달라질 수 있어요. MMS로 직접 보내는 미디어를 비교적 작게 유지하면 여러 통신망에서 호환성이 좋아져요.
