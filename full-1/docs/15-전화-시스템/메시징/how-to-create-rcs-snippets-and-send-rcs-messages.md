# RCS 스니펫 만들기와 RCS 메시지 보내기

RCS 스니펫(메시지 템플릿)을 만들고, 연락처에 보내는 방법을 안내해요. 일괄 작업, 1:1 대화, 워크플로우에서 RCS 메시지를 보내는 방법도 함께 다뤄요.

## 이 문서에서 다루는 내용

RCS 스니펫을 만드는 방법과 RCS 메시지를 보내는 방법을 설명해요. 워크플로우의 RCS 액션으로 풍부한 카드와 버튼이 있는 대화를 자동화하는 방법도 알아봐요. 온보딩 시퀀스, 프로모션 캠페인, 고객 지원 자동화 등에 활용할 수 있어요.

## 사용 가능 여부

이 기능은 현재 RCS 프라이빗 베타로 제공돼요.

먼저 써 보고 싶다면 고객 성공팀 담당자 또는 하이퍼클래스 고객지원에 문의하세요.

## 시작하기 전에

이 문서는 계정에서 RCS가 이미 켜져 있고 발신자 ID(Sender ID)가 승인된 상태라고 가정해요. 아직 설정하지 않았다면 전체 설정 과정을 안내하는 [하이퍼클래스의 RCS](rcs-in-hyperclass.md) 문서를 먼저 읽어 보세요.

준비가 끝났다면 할 일은 두 가지예요. 먼저 RCS 스니펫(메시지 템플릿)을 만들고, **일괄 작업**으로 연락처에 보내요. 이 문서는 이 순서대로 설명해요.

{% hint style="info" %}
스니펫을 먼저 만드는 이유: RCS 스니펫은 캠페인의 바탕이 되는 템플릿이에요. 한 번 만들어 두면 여러 번 재사용할 수 있어요. 스니펫 없이는 풍부한 RCS 캠페인을 보낼 수 없으니, 스니펫 만들기가 항상 첫 단계예요.
{% endhint %}

## 1부: RCS 스니펫 만들기

스니펫은 **대화** 안에 있어요. **대화 페이지**에서 왼쪽 패널의 **스니펫**을 선택한 다음, **RCS 스니펫 추가**를 클릭하면 템플릿 빌더가 열려요.

![대화 안의 RCS 스니펫 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070144531/original/RAN5qbb5uuvOau7f12C_30VrpHf4xn8pDg.png?1777388249)

템플릿 형식은 세 가지예요. 형식마다 어울리는 메시지가 다르니, 시작하기 전에 알맞은 형식을 고르면 시간을 아낄 수 있어요.

### 스니펫 형식 세 가지

![RCS 스니펫의 세 가지 형식: 일반 텍스트, 독립형 카드, 캐러셀](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070144545/original/xArws_745fxWj8cWtc2pxRMNfv4bpN5xJw.png?1777388268)

#### 형식 1: Plain Text(일반 텍스트)

**Plain Text**는 이미지, 미디어, 작업 버튼 없이 글만 보내는 간단한 문자 메시지예요. 내용을 입력하면 받는 사람의 기기에서 메시지가 어떻게 보이는지 실시간 미리보기로 확인할 수 있어요.

확인, 알림, 짧은 안내처럼 글만으로 충분할 때 쓰세요. 가장 가벼운 형식이고 일반 SMS와 느낌이 비슷해요. 그래도 RCS 브랜딩은 적용돼서 받은 편지함에 번호 대신 비즈니스 이름이 표시돼요.

![일반 텍스트 RCS 스니펫 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070144552/original/BxIO4wfW9DhMvRUE7LuNxxxNSz-W-SgOGg.png?1777388285)

{% hint style="info" %}
**Plain Text**를 고르는 경우: 메시지에 버튼이나 이미지가 꼭 필요하지 않다면 **Plain Text**가 알맞아요. 템플릿이 단순할수록 일부 기기에서 대체 발송 문제가 생길 가능성도 낮아요.
{% endhint %}

#### 형식 2: 독립형 카드

**독립형 카드**는 카드 한 장으로 이루어진 풍부한 메시지예요. 제목, 설명, 이미지나 미디어 파일, 그리고 최대 3개의 작업 버튼을 넣을 수 있어요. 프로모션 오퍼, 서비스 공지, "지금 예약하기" 버튼이 있는 예약 알림처럼 고급스러운 경험을 주고 싶을 때 알맞아요.

작업 버튼은 전화 걸기, URL 열기, 추천 답장 삽입 중에서 정할 수 있어요. 카드당 버튼은 최대 3개까지 추가할 수 있고, 제목과 설명 필드에는 이모지와 커스텀 태그를 쓸 수 있어요.

**독립형 카드**에는 대체 SMS 메시지가 꼭 필요해요. RCS를 받을 수 없는 연락처에게 전달되는 일반 텍스트 버전이에요. 플랫폼에서 필수로 요구하기 때문에, 대체 SMS 메시지 없이는 템플릿을 저장할 수 없어요.

![독립형 카드 RCS 스니펫 빌더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070144604/original/5yksqU5N7rFYFYdO5hukuKL7nVMd5v5lnw.png?1777388315)

{% hint style="info" %}
대체 메시지부터 쓰세요: 카드를 디자인하기 전에 대체 SMS 메시지를 먼저 써 보세요. 일반 텍스트만으로 핵심 내용이 분명히 전달되지 않는다면 카드도 아직 준비가 덜 된 거예요. 대체 문구가 탄탄하면 템플릿 전체가 좋아져요.
{% endhint %}

#### 형식 3: Carousel(캐러셀)

**Carousel**은 옆으로 넘겨 볼 수 있는 풍부한 카드 여러 장을 한 메시지에 담는 형식이에요. 카드는 최소 2장, 최대 10장까지 만들 수 있어요. 카드마다 제목, 설명, 미디어가 있고, 작업 버튼은 최대 2개까지 넣을 수 있어요.

상품 라인, 여러 서비스 패키지, 팀원 소개, 여러 매물처럼 선택지를 나란히 보여 줄 때 쓰세요. 받는 사람이 웹사이트로 이동하지 않아도 한 메시지에서 내용을 비교할 수 있어요.

**독립형 카드**와 마찬가지로 **Carousel**에도 대체 SMS 메시지가 필요해요. RCS를 받을 수 없는 연락처에는 넘겨 보는 카드 대신 대체 텍스트가 전달돼요.

![여러 장의 카드를 넘겨 볼 수 있는 캐러셀 RCS 스니펫](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070144616/original/_RV55iiYoAdNE6wej7RMY6QmWei8tXTxgg.png?1777388330)

{% hint style="info" %}
캐러셀 한도: 카드는 최소 2장, 최대 10장이에요. 카드마다 작업 버튼은 최대 2개로, 독립형 카드보다 1개 적어요. 카드 제목과 설명은 휴대폰 화면에서 잘 읽히도록 짧게 쓰세요.
{% endhint %}

### 스니펫 만드는 순서

아래 순서는 **독립형 카드**를 예로 들어요. 세 가지 형식 모두 같은 구조로 진행해요.

1. **대화 > 스니펫 > RCS 스니펫 추가**로 이동해요. 세 가지 형식 중에서 템플릿 형식을 선택해요. 미디어와 버튼이 있는 풍부한 카드를 만들려면 **독립형 카드**를 고르세요.
2. 템플릿 이름을 정해요. 나중에 캠페인을 설정할 때 드롭다운에서 고르게 되니, 다른 템플릿과 겹치지 않는 분명한 이름을 붙이세요. "봄 가구 프로모션 카드"처럼 구체적인 이름이 "템플릿 1" 같은 이름보다 찾기 쉬워요.
3. **카드 세부 정보**를 입력해요. 카드 제목, 설명, 프로모션 코드나 커스텀 태그를 넣어요. 이 필드에는 이모지를 쓸 수 있어요. 받는 사람이 가장 먼저 읽는 문구이니 설명은 핵심만 담으세요.
4. 카드에 이미지나 미디어 파일을 업로드해요. 오퍼나 메시지를 분명히 보여 주는 고화질 이미지를 쓰세요. 카드에서 가장 눈에 띄는 요소예요.
5. **작업 버튼**을 추가해요. 최대 3개까지 추가할 수 있고, **Carousel** 카드는 최대 2개예요. 버튼마다 전화 걸기, URL 열기, 추천 답장 삽입 중 하나로 설정해요. 다음 버튼으로 넘어가기 전에 각 작업을 저장하세요.
6. 대체 SMS 메시지를 입력해요. 기기가 RCS를 지원하지 않을 때 연락처가 받는 일반 텍스트 버전이에요. 버튼이나 이미지 없이 카드와 같은 핵심 정보를 분명한 문장으로 전달하세요.
7. **템플릿 만들기**를 클릭해 저장해요.

{% hint style="info" %}
스니펫 준비 완료: 저장하면 템플릿이 **스니펫** 라이브러리에 나타나요. 다시 만들 필요 없이 여러 캠페인에서 재사용할 수 있어요.
{% endhint %}

## 2부: 연락처에 RCS 메시지 보내기

스니펫이 준비되면 보내 볼 차례예요. RCS 스니펫은 **일괄 작업**으로 보내요. 현재 풍부한 RCS 템플릿을 대량으로 보내는 유일한 방법이에요. 전체 과정은 다음과 같아요.

### 연락처 선택하기

**연락처**로 이동해 **스마트 리스트**를 열어요. 보내려는 연락처를 선택해요. 연락처를 하나씩 고를 수도 있고, 스마트 리스트 전체를 선택할 수도 있어요. 선택한 다음 **더보기 > Send SMS & RCS**(SMS·RCS 보내기)를 클릭하면 캠페인 설정 화면이 열려요.

![스마트 리스트를 선택하고 Send SMS & RCS를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070143184/original/CC868lPmBedZkfXTov9WSPKMNKewkzZPog.png?1777387596)

### 캠페인 설정하기

설정 화면에는 필수 입력 항목이 몇 가지 있어요. 보내기 전에 정확히 채워 두면 나중에 문제를 찾느라 고생하지 않아요.

| 필드 | 설정 방법 |
| --- | --- |
| **Action Name**(작업 이름) | **일괄 작업** 추적 페이지에서 알아볼 수 있는 캠페인 이름을 입력해요. |
| **From**(보내는 사람, 발신자 ID) | 드롭다운에서 승인된 RCS 발신자 ID를 선택해요. 등록되고 승인된 ID만 표시돼요. 내 ID가 보이지 않으면 하이퍼클래스 고객지원에 문의하세요. |
| **RCS Template**(RCS 템플릿) | 방금 만든 스니펫을 선택해요. 저장된 스니펫만 이 목록에 나타나요. |
| **Send Mode**(발송 방식) | 캠페인에 맞게 **Send All at Once**(한 번에 모두 보내기), **Send at Scheduled Time**(예약한 시간에 보내기), **Send in Drip Mode**(드립 모드로 보내기) 중에서 선택해요. |
| **Consent Checkbox**(동의 체크박스) | 연락처가 수신에 동의했음을 확인하려면 체크해요. 필수 항목이에요. 체크하지 않으면 **보내기** 버튼이 활성화되지 않아요. |

### 미리보기 확인하고 보내기

![보내기 전 RCS 템플릿 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070143255/original/XDjU2MiTdRRXV8jwXqVtGNV2fjGEmjjejw.png?1777387635)

보내기 전에 템플릿 미리보기를 확인하세요. RCS를 받을 수 있는 수신자에게 메시지가 어떻게 보이는지 그대로 보여 줘요. 카드 제목, 설명, 버튼, 미디어가 모두 올바른지 확인하세요.

준비가 되면 **RCS 보내기**를 클릭하세요. 캠페인이 발송되고, **진행 상황 확인**을 클릭하면 **일괄 작업** 페이지에서 진행 상황을 볼 수 있어요.

{% hint style="info" %}
발송 현황 확인: 보낸 뒤에는 **일괄 작업** 페이지에서 전달 진행 상황을 확인하세요. 몇 건이 발송되고 전달됐는지, SMS로 대체 발송된 메시지가 있는지 볼 수 있어요.
{% endhint %}

![전달 진행 상황을 보여 주는 일괄 작업 추적 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070144323/original/MalCL1Mh5rGxVGiG2Vz0OOO443ekIznu7A.png?1777388151)

{% hint style="info" %}
현재 RCS 스니펫을 보내는 방법은 **일괄 작업**뿐이에요.
{% endhint %}

## 발송 후 메시지 확인하기

캠페인이 발송되면 **대화**에서 연락처의 대화 기록으로 메시지를 확인할 수 있어요. 메시지에는 **RCS** 라벨과 발송에 쓴 발신자 ID가 표시돼서, 올바른 프로필로 나갔는지 확인할 수 있어요.

메시지가 수신자에게 전달되는 동안 **발송됨**, **전달됨**, **열림** 같은 전송 상태가 대화 화면에 업데이트돼요. SMS로 대체 발송된 경우에는 SMS 전달 상태가 표시돼요.

{% hint style="info" %}
**열림**의 의미: **열림**은 수신자가 읽음 확인을 지원하는 기기에서 메시지를 봤다는 뜻이에요. 모든 기기가 읽음 확인을 지원하는 것은 아니고, 수신자가 이 기능을 끌 수도 있어요. 표시되면 긍정적인 신호지만, 전체 대상에 대한 지표로 삼기는 어려워요.
{% endhint %}

## 대화에서 RCS 보내기 (1:1 메시지)

스니펫이나 캠페인 없이 연락처 한 명에게 RCS 메시지를 바로 보내려면 **대화 페이지**에서 보낼 수 있어요.

연락처의 대화를 열고 메시지를 작성해요. 발신자 선택기에서 승인된 RCS 발신자 ID를 선택하고 보내세요. 연락처의 기기가 RCS를 지원하면 RCS로 전달되고, 지원하지 않으면 자동으로 SMS로 대체 발송돼요.

![연락처의 대화에서 1:1 RCS 메시지를 보내는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070143126/original/tsOq8vqK4hsg6EF6cvRAltP5MYYORo4VCg.png?1777387551)

## 대화에서 RCS 스니펫 보내기 (1:1)

**대화 페이지**를 벗어나지 않고, 일대일 대화에서 미리 만든 RCS 스니펫을 골라 보낼 수 있어요. 기존 스니펫을 선택하고, 수신자에게 어떻게 보일지 미리 본 다음, 대화 작성창에서 바로 보내면 돼요.

{% hint style="info" %}
대화 작성창에서 RCS 스니펫을 보내는 기능은 현재 RCS 프라이빗 베타로 제공되며, 일부 계정에서는 사용할 수 없을 수 있어요.
{% endhint %}

### RCS 스니펫 보내는 순서

1. **대화**로 이동해 보낼 연락처와의 대화를 열어요.
2. 메시지 작성창에서 **RCS Snippet**(RCS 스니펫) 옵션을 클릭해 **RCS 메시지 선택** 창을 열어요. 또한 **FROM**(보내는 번호)이 RCS 발신자 ID인지 확인하세요.

   ![RCS 메시지 선택 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078361005/original/xhFHf4tjgTiKUncqf2Sgcpa5OQOL0658oA.png?1786632379)
3. **템플릿 목록** 드롭다운에서 기존 RCS 스니펫을 선택해요.

   ![템플릿 목록에서 RCS 스니펫 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078361098/original/zJ0cVbeJo8qVYuet8gr3GD-m2_OwduH3eQ.png?1786632409)
4. 스니펫 세부 정보와 미리보기를 확인해 보내기 전에 내용을 점검해요.

   - 제목, 설명, 작업 버튼을 확인하세요.
   - 스니펫에 카드가 여러 장이면 카드를 하나씩 넘겨 보며 내용이 올바른지 확인하세요.
   - RCS를 지원하지 않는 수신자에게 전달될 대체 메시지도 확인하세요.

   ![스니펫 세부 정보와 미리보기 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078361160/original/elDnlszKeYI9xygK1BOr9Aabc-be0CQOUw.png?1786632435)
5. **보내기**를 클릭해 연락처에게 RCS 스니펫을 보내요.

{% hint style="warning" %}
이전에 만들어 둔 RCS 스니펫만 선택할 수 있어요. 새 스니펫이 필요하면 먼저 만든 다음 대화로 돌아오세요.
{% endhint %}

## 워크플로우에서 RCS 보내기

[동영상](https://watchclueso.com/embed/e28mwsm0zpwz33yk)

**워크플로우** 안에서 바로 RCS 메시지를 보내 더 풍부한 고객 여정을 만들 수 있어요. 새로 나온 **Send RCS**(RCS 보내기)와 **RCS Interactive Message**(RCS 인터랙티브 메시지) 워크플로우 액션으로 차세대 비즈니스 메시징 대화를 자동화해 보세요.

### 할 수 있는 일

새 워크플로우 액션으로 다음 작업을 할 수 있어요.

- 워크플로우에서 일반 RCS 메시지 보내기
- 풍부한 카드와 버튼으로 인터랙티브 RCS 경험 만들기
- 고객의 반응에 따라 워크플로우 경로 나누기
- RCS로 알림, 프로모션, 후속 연락, 고객 참여 자동화하기

### 사용 방법

1. **자동화 > 워크플로우**로 이동해요.
2. 새 워크플로우를 만들거나 기존 워크플로우를 편집해요.
3. **Send RCS** 또는 **RCS Interactive Message** 액션을 추가해요.
4. 메시지나 인터랙티브 경험을 설정해요.
5. 워크플로우를 게시해요.

### 이 기능을 쓰면 좋은 점

워크플로우에서 RCS를 사용하면 다음과 같은 장점이 있어요.

- 풍부하고 대화형인 고객 경험을 자동화할 수 있어요.
- 인터랙티브 RCS 메시지로 참여를 높일 수 있어요.
- 버튼 선택과 응답에 따라 연락처를 다른 경로로 보낼 수 있어요.
- 워크플로우 자동화에서 바로 더 현대적인 메시징 경험을 제공할 수 있어요.

## 보낼 준비가 됐어요

콘텐츠가 준비되어 있다면 RCS 스니펫은 몇 분이면 만들 수 있고, 연락처에 보내는 데도 몇 번의 클릭이면 충분해요. 연락처는 기본 메시지 앱에서 브랜드가 표시된 인터랙티브 카드를 받게 돼요.

스니펫 하나로 시작해 보세요. 적은 수의 리스트에 먼저 보내고, 대화 화면에서 메시지가 어떻게 도착했는지 확인한 다음 규모를 늘려 가세요.

{% hint style="info" %}
RCS 활성화, 발신자 ID 설정, 요금과 규정 준수가 궁금하다면 함께 보면 좋은 문서 [하이퍼클래스의 RCS](rcs-in-hyperclass.md)를 참고하세요.
{% endhint %}

## 자주 묻는 질문

### RCS 메시지를 보내려면 항상 RCS 스니펫이 있어야 하나요?

아니요. **독립형 카드**나 **Carousel** 같은 풍부한 형식에만 RCS 스니펫이 필요해요. 일반 텍스트 RCS 메시지는 스니펫을 만들지 않고 1:1 대화에서 바로 보낼 수 있어요.

---

### 독립형 카드나 캐러셀을 연락처 한 명에게만 보낼 수 있나요?

네. 이제 독립형 카드와 캐러셀을 포함해 지원되는 RCS 스니펫을 1:1 대화에서 바로 보낼 수 있어요. 대화 작성창에서 기존 RCS 스니펫을 선택하면 돼요. 이 기능은 현재 RCS 프라이빗 베타에 참여 중인 계정에서 사용할 수 있어요.

---

### RCS 스니펫을 보내기 전에 미리 볼 수 있나요?

네. 대화 작성창에서 RCS 스니펫을 선택하면 보내기 전에 콘텐츠, 미디어, 버튼, 대체 메시지를 미리 볼 수 있어요.

---

### 대화에서 바로 새 RCS 스니펫을 만들 수 있나요?

아니요. RCS 스니펫을 먼저 만들어서 저장해야 해요. 만들어 둔 뒤에 메시지를 보낼 때 대화 작성창에서 선택할 수 있어요.

---

### 선택한 RCS 스니펫을 보내기 전에 수정할 수 있나요?

아니요. 대화 작성창에서는 기존 RCS 스니펫을 선택하고 미리 볼 수만 있어요. 내용을 바꾸려면 스니펫을 먼저 편집한 다음, 대화로 돌아와 수정된 버전을 보내세요.

---

### 연락처의 기기가 RCS를 지원하지 않으면 어떻게 되나요?

수신자의 기기나 통신사가 RCS를 지원하지 않으면 설정해 둔 대체 메시지가 대신 전달돼요. 연락처가 메시지를 받지 못하는 일은 없어요.

---

### 형식별로 작업 버튼을 몇 개까지 추가할 수 있나요?

**독립형 카드**는 작업 버튼을 최대 3개, **Carousel**은 카드당 최대 2개까지 지원해요. **Plain Text** 스니펫은 작업 버튼을 지원하지 않아요.

---

### RCS 메시지를 직접 보내지 않고 자동으로 보낼 수 있나요?

네. **Send RCS**와 **RCS Interactive Message** 워크플로우 액션을 사용하면 RCS 메시지를 자동으로 보내고, 인터랙티브 경험과 자동화된 고객 여정을 만들 수 있어요.

---

### 발송됨, 전달됨, 열림은 어떻게 다른가요?

**발송됨**은 메시지가 플랫폼을 떠났다는 뜻이에요. **전달됨**은 수신자의 기기에 도착했다는 뜻이고요. **열림**은 읽음 확인을 지원하는 기기에서 수신자가 메시지를 봤다는 뜻이에요. 모든 기기가 읽음 확인을 지원하는 것은 아니라서, 이 상태가 항상 표시되지는 않을 수 있어요.

---

### 같은 RCS 스니펫을 여러 메시지나 캠페인에 재사용할 수 있나요?

네. RCS 스니펫을 한 번 저장하면 스니펫 라이브러리에 남아 있어요. 계정에서 해당 기능을 사용할 수 있다면 **일괄 작업**, **워크플로우**(지원되는 경우), 1:1 대화에서 재사용할 수 있어요.

---

### 대화에서 RCS 스니펫을 보내는 옵션이 보이지 않아요

대화 작성창에서 RCS 스니펫을 보내는 기능은 현재 RCS 프라이빗 베타에 참여 중인 계정에서만 사용할 수 있어요. 옵션이 보이지 않는다면 아직 계정에서 이 기능을 사용할 수 없는 거예요.
