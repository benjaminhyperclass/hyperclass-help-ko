# RCS 발신자 신청 심사 과정

RCS 발신자를 신청하면 내부 검토와 통신사 심사를 차례로 거쳐요. 이 문서에서는 각 단계에서 무엇을 확인하는지, 자주 생기는 문제는 어떻게 고치는지, 승인까지 보통 얼마나 걸리는지 안내해요.

## 개요

RCS(Rich Communication Services) 발신자를 승인받으려고 제출하면 심사가 진행돼요. 심사에서는 비즈니스, **메시징 사용 사례**, 발신자 정보가 관련 규정과 통신사 요건에 맞는지 확인해요. 심사는 크게 두 단계로 나뉘어요.

- 1단계 · 내부 검토: 하이퍼클래스 팀이 신청서가 빠짐없이 정확하게 작성되었는지, 규정에 맞는지 확인해요.
- 2단계 · 통신사 심사: 통신사와 관련 인증 업체가 브랜드, **메시징 사용 사례**, 규정 준수 여부를 확인한 뒤 발신자를 승인해요.

## 1단계 · 내부 검토

RCS 발신자를 제출하면 하이퍼클래스 팀의 RCS 온보딩 담당자가 신청서를 검토해요. 필요한 정보가 모두 입력되었는지, 메시징 정책에 맞는지 확인하는 과정이에요. 내부 검토에서는 다음 항목을 확인해요.

### 확인 항목 A · 비즈니스 및 브랜드 인증

실제로 존재하는 비즈니스의 발신자인지 확인해요. 다음 내용을 살펴봐요.

- **법인 비즈니스명**과 사업자 등록 정보
- 공식 **비즈니스 웹사이트**와 연락처 정보
- 권한이 있는 담당자 정보
- 브랜드명, 웹사이트, 발신자 이름이 서로 일치하는지 여부
- 필요한 경우 비즈니스 인증 서류나 확인서

### 확인 항목 B · 발신자 프로필 및 브랜딩

발신자 프로필이 비즈니스를 정확히 나타내는지 확인해요. 다음 내용이 포함돼요.

- 발신자 표시 이름
- 비즈니스 설명
- 브랜드 로고와 배너
- **비즈니스 웹사이트**
- **개인정보처리방침**과 **서비스 이용약관** URL

모든 브랜딩 정보가 같은 비즈니스를 일관되게 나타내야 하고, 필수 URL은 접속할 수 있어야 해요.

### 확인 항목 C · 옵트인·옵트아웃 준수

심사에서 가장 중요한 부분 중 하나는 고객이 RCS 메시지 수신에 어떻게 동의하는지 확인하는 일이에요. 다음 내용을 살펴봐요.

- 고객이 동의하는 방식
- 옵트인(수신 동의) 폼이 열려 있고 접속할 수 있는지
- 해당하는 경우 동의 체크박스가 기본으로 해제되어 있는지
- 동의 문구에 비즈니스가 분명히 밝혀져 있는지
- 고객이 받게 될 메시지 종류가 설명되어 있는지
- 고객이 STOP으로 답장해 수신을 해지(옵트아웃)할 수 있는지
- HELP와 옵트아웃 응답이 관련 요건에 맞는지
- **개인정보처리방침**과 **서비스 이용약관**을 볼 수 있는지

{% hint style="warning" %}
심사 담당자가 옵트인 과정을 직접 테스트할 수 있어요. 심사 기간에는 동의 절차가 정상적으로 작동하고 접속할 수 있는 상태여야 해요.
{% endhint %}

### 확인 항목 D · 메시징 사용 사례와 샘플 메시지

보내려는 메시지가 관련 정책에 맞는지 확인해요. 다음 내용을 살펴봐요.

- 메시징 캠페인의 목적
- 프로모션, 거래, 정보 안내 등 발송할 메시지 종류
- 메시지를 보내는 계기가 되는 이벤트
- 샘플 메시지
- 예상 발송 빈도
- 샘플 메시지가 제출한 사용 사례와 일치하는지 여부

### 확인 항목 E · 필요 서류

국가에 따라 추가 서류가 필요할 수 있어요. 예를 들면 다음과 같아요.

- 사업자 등록 서류
- 브랜드 인증서 또는 확인서
- 권한 위임 서류
- 동의 폼 스크린샷
- 옵트인과 메시징 과정을 보여 주는 시연 영상

{% hint style="info" %}
빠졌거나 잘못된 정보가 있으면 등록을 진행하기 전에 하이퍼클래스 팀이 수정을 요청할 수 있어요.
{% endhint %}

## 2단계 · 통신사 심사

내부 검토를 통과하면 신청서가 해당 통신사와 인증 업체에 제출돼요. 통신사는 자체 기준으로 발신자가 요건을 충족하는지 확인해요. 통신사 심사에서는 다음 항목을 확인해요.

### 확인 항목 A · 브랜드 적법성

비즈니스가 실제로 존재하고, 제출한 발신자 이름을 쓸 권한이 있는지 확인해요. 다음 절차가 포함될 수 있어요.

- 법인 비즈니스 정보 확인
- 발신자 이름이 비즈니스 브랜드와 일치하는지 확인
- 사업자 등록 서류 검토
- 브랜드 소유권 또는 사용 권한 확인

#### 미국 통신사 · Aegis 인증

미국 통신사에 등록할 때는 제3자 인증 업체인 Aegis가 비즈니스와 권한 있는 담당자를 추가로 확인할 수 있어요. 담당자는 회사 브랜드 이메일 주소를 사용하고, 인증 이메일이 오면 빠르게 답해 주세요.

### 확인 항목 B · 메시징 사용 사례

보내려는 메시지가 통신사 정책에서 허용되는지 확인해요. 다음 내용을 살펴볼 수 있어요.

- 캠페인 설명
- **대상 오디언스**
- 프로모션 또는 거래 메시지 등 발송 목적
- 메시지 발송 계기
- 샘플 메시지
- 예상 발송 빈도

제출한 정보는 비즈니스가 RCS 메시징을 실제로 쓰려는 방식을 정확히 반영해야 해요.

### 확인 항목 C · 옵트인·옵트아웃 확인

통신사는 고객이 메시지 수신에 명시적으로 동의했는지 확인하려고 옵트인 과정을 직접 테스트할 수 있어요. 다음 내용을 살펴봐요.

- 옵트인 과정이 정상적으로 작동하는지
- 동의 문구에 비즈니스가 분명히 밝혀져 있는지
- 메시지 목적이 설명되어 있는지
- 필수 고지 사항이 들어 있는지
- STOP과 HELP 안내가 지원되는지
- **개인정보처리방침**과 **서비스 이용약관** 링크에 접속할 수 있는지

미국 통신사의 경우 규정 준수 검토에서 CTIA 메시징 가이드라인도 함께 고려해요.

### 확인 항목 D · 예상 메시지 발송량

일부 통신사는 예상 메시지 트래픽 정보를 요청할 수 있어요. 다음 내용이 포함될 수 있어요.

- 월별 예상 RCS 메시지 발송량
- 현재 SMS 발송량
- 예상 발송 빈도
- 현재 운영 중인 메시징 캠페인
- 비즈니스 웹사이트 트래픽 정보

### 확인 항목 E · 통신사별 추가 요건

국가나 통신사에 따라 추가 인증이 필요할 수 있어요. 예를 들면 다음과 같아요.

- 에이전트 인증 폼(Agent Verification Forms)
- 브랜드 인증 이메일
- 추가 비즈니스 서류
- 권한 위임 또는 확인서
- 시연 영상
- 추가 캠페인 정보

{% hint style="info" %}
통신사는 발신자를 승인하기 전에 추가 설명을 요청할 수 있어요.
{% endhint %}

## 리뷰어가 문제를 발견하면 어떻게 되나요?

하이퍼클래스 팀이나 통신사가 빠진 정보나 규정 문제를 발견하면 승인 전에 수정이 필요할 수 있어요. 자주 생기는 문제는 다음과 같아요.

| 문제 | 해야 할 일 |
| --- | --- |
| 비즈니스 정보가 잘못됨 | **법인 비즈니스명** 등 법인 정보를 공식 기록과 같게 고치세요. |
| 발신자 이름이 브랜드와 다름 | 등록 정보와 웹사이트 전체에서 브랜딩을 일관되게 맞추세요. |
| 옵트인 폼에 접속할 수 없음 | 정상적으로 작동하는 옵트인 폼을 제공하세요. |
| 동의 문구가 불완전함 | 브랜드 표기, 메시지 목적, 옵트아웃 안내를 문구에 넣으세요. |
| **개인정보처리방침** 또는 **서비스 이용약관** 링크가 깨져 있음 | 유효하고 접속할 수 있는 링크를 입력하세요. |
| **메시징 사용 사례**가 불분명함 | 사용 사례를 자세히 쓰고, 실제와 비슷한 샘플 메시지를 제출하세요. |
| 브랜드 인증이 끝나지 않음 | 인증 절차를 완료하거나 필요한 서류를 제출하세요. |
| 통신사 추가 서류가 없음 | 요청받은 서류를 제출하세요. |

{% hint style="info" %}
필요한 수정을 마치면 신청서는 심사를 이어서 진행해요.
{% endhint %}

## 심사는 얼마나 걸리나요?

RCS 등록 기간은 대상 국가, 통신사, 신청서가 얼마나 빠짐없이 작성되었는지에 따라 달라요.

### 미국 소요 기간

미국에서 RCS를 온보딩할 때는 전체 과정에 약 4~6주 이상 걸린다고 보면 돼요.

다음 경우에는 심사가 더 길어질 수 있어요.

- 비즈니스 정보를 고쳐야 할 때
- 옵트인 과정이 인증에 실패할 때
- 추가 서류를 요청받을 때
- 브랜드 인증이 끝나지 않았을 때
- 통신사가 추가 설명을 요청할 때
- 통신사 네트워크 동결이나 주요 공휴일 때문에 처리가 늦어질 때

{% hint style="info" %}
정확하고 빠짐없는 정보를 제출하면 피할 수 있는 지연을 줄일 수 있어요. 다만 승인 기간을 보장하지는 않아요.
{% endhint %}

## RCS 발신자 제출 전 체크리스트

RCS 등록을 제출하기 전에 다음 항목을 확인하세요.

- ✓ **법인 비즈니스명**과 사업자 등록 정보가 정확해요.
- ✓ 권한 있는 담당자 정보가 올바라요.
- ✓ 발신자 이름, 로고, 웹사이트가 같은 비즈니스를 일관되게 나타내요.
- ✓ **개인정보처리방침**과 **서비스 이용약관** 링크가 정상적으로 열려요.
- ✓ 옵트인 폼이 열려 있고 접속할 수 있어요.
- ✓ 동의 문구에 고객이 받게 될 메시지 종류가 분명히 설명되어 있어요.
- ✓ STOP과 HELP 안내가 관련 요건에 맞아요.
- ✓ **메시징 사용 사례**와 샘플 메시지가 정확해요.
- ✓ 필요한 경우 예상 메시지 발송량을 제공했어요.
- ✓ 필요한 비즈니스 인증 서류를 모두 준비했어요.
- ✓ 국가별 추가 요건을 모두 완료했어요.

## 꼭 기억해 두세요

{% hint style="info" %}
- 하이퍼클래스 팀이 신청서를 먼저 검토한 뒤 해당 통신사의 승인을 위해 제출해요.
- 내부 검토를 통과했다고 해서 통신사 승인이 보장되지는 않아요.
- 통신사가 추가 정보나 서류를 요청할 수 있어요.
- 열려 있고 규정에 맞는 옵트인 과정이 꼭 필요해요.
- 승인 요건은 대상 국가와 통신사에 따라 달라요.
- Google RCS 승인을 받았다고 해서 모든 통신사나 국가의 승인이 자동으로 보장되지는 않아요.
{% endhint %}

{% hint style="info" %}
발신자가 필요한 승인을 모두 받고 활성화되면 지원되는 네트워크에서 **RCS 메시지**를 보낼 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 내부 검토와 통신사 심사는 어떻게 다른가요?

내부 검토는 하이퍼클래스의 RCS 온보딩 팀이 신청서가 빠짐없이 정확하고 규정에 맞는지 확인하는 단계예요. 통신사 심사는 통신사와 인증 업체가 직접 진행하고, 최종 승인 여부도 이 단계에서 결정돼요.

### 내부 검토를 통과하면 통신사 승인도 받나요?

꼭 그렇지는 않아요. 내부 검토를 통과했다는 것은 신청서를 통신사에 제출할 준비가 되었다는 뜻이에요. 통신사는 독립적으로 심사하고, 추가 정보를 요청하거나 발신자를 거절할 수도 있어요.

### 미국 RCS 승인은 보통 얼마나 걸리나요?

약 4~6주 이상 걸린다고 보면 돼요. 수정 요청, 추가 서류 요청, 통신사의 추가 설명 요청, 네트워크 동결, 공휴일 때문에 기간이 더 길어질 수 있어요.

### 심사 담당자가 옵트인 폼을 실제로 테스트하나요?

테스트할 수 있어요. 내부 검토 담당자와 통신사 모두 동의 절차를 테스트할 수 있으니, 심사 기간에는 옵트인 폼을 열어 두고 접속할 수 있게 유지하세요.

### Aegis 인증은 무엇인가요?

미국 통신사에 등록할 때 제3자 인증 업체인 Aegis가 비즈니스와 권한 있는 담당자를 확인할 수 있어요(이때 브랜드의 도메인 이메일을 사용해야 해요). 담당자는 서브 계정 브랜드 이메일을 사용하고, 인증 이메일이 오면 빠르게 답해 주세요. <!-- 검토 필요: 원문 내용이 서로 다름 (본문은 '회사 브랜드 이메일', FAQ는 '서브 계정 브랜드 이메일'과 '브랜드 도메인 이메일'로 표현) -->

### 통신사가 왜 메시지 발송량을 물어보나요?

일부 통신사는 예상 트래픽을 파악하고 발신자를 평가하려고 예상 RCS 발송량, 현재 SMS 발송량, 메시지 발송 빈도, 웹사이트 트래픽을 요청해요. 현실적인 추정치를 제공하세요.

### 신청서에 문제가 발견되면 어떻게 되나요?

수정하거나 추가 서류를 제출해 달라는 요청을 받게 돼요. 필요한 수정을 마치면 신청서는 심사를 이어서 진행해요. 자주 생기는 문제와 해결 방법은 [리뷰어가 문제를 발견하면 어떻게 되나요?](#리뷰어가-문제를-발견하면-어떻게-되나요)에서 확인하세요.

### Google RCS 승인을 받으면 모든 국가에 메시지를 보낼 수 있나요?

아니요. Google 승인이 모든 통신사나 국가의 승인을 자동으로 보장하지는 않아요. 국가별 또는 통신사별 추가 승인이 필요할 수 있어요.
