# A2P 10DLC 캠페인 반려 사유와 해결 방법

A2P 10DLC 캠페인 등록이 반려됐을 때 오류 코드별 사유와 수정 방법을 확인하는 문서예요. 재제출이 가능한 사유라면 내용을 고친 뒤 캠페인을 삭제하고 다시 제출하세요.

## 재제출할 수 있는 반려 유형

아래 반려 코드는 모두 재제출할 수 있어요. 표의 수정 방법대로 고친 뒤, 바뀐 정보로 캠페인 등록을 다시 요청하세요.

| 오류 코드 | 반려 분류 | 반려 사유 | 필요한 수정 |
| --- | --- | --- | --- |
| 30886 | 잘못된 캠페인 설명 | 캠페인 설명이 캠페인 목적을 충분히 설명하지 않거나, 설명이 사용 사례와 맞지 않아요. | 캠페인 설명이 정확하고 자세한지 확인하세요. ISV가 고객에게 직접 제공하는 서비스를 등록한다면 캠페인 설명에 그 사실을 밝혀 주세요. 그런 다음 캠페인을 다시 제출해 심사를 받으세요. |
| 30893 | 잘못된 샘플 메시지 사용 사례 | 샘플 메시지가 없거나 불분명하거나, 내용이 캠페인 사용 사례와 맞지 않아요. | 샘플 메시지가 정확하고 자세한지 확인하세요. 샘플 메시지는 이 캠페인으로 실제 보낼 메시지를 반영해야 하고, 템플릿 필드는 대괄호로 표시해야 해요. 샘플 메시지 중 하나 이상에는 비즈니스 이름이 들어가야 해요. 사용 사례와 캠페인 설명이 캠페인 설명과 일치해야 해요. <!-- 검토 필요: 원문 내용이 서로 다름 --> |
| 30892 | 잘못된 샘플 메시지 - 공개 URL 단축 서비스 | 공개 URL 단축 서비스는 허용되지 않아요. 샘플 메시지에 포함된 웹사이트 URL이 공개 URL 단축 서비스로 만든 주소이거나 보안이 적용되지 않은 주소예요. | 샘플 메시지에서 공개 URL 단축 서비스를 없애세요. 샘플 메시지나 캠페인 링크에 bit.ly, tinyurl 같은 공개 URL 단축 서비스가 쓰였어요. 해결 방법:<br>- 전체 웹 주소를 그대로 쓰세요.<br>- 내 도메인으로 만든 브랜드 단축 링크는 괜찮아요. |
| 30891 | 잘못된 웹사이트 URL | 등록에 잘못된 URL이 제공됐어요. 웹사이트는 정상 작동해야 해요. 출시 전 등록이라면 캠페인 설명에 그 사실을 밝혀야 해요. | 제공한 웹사이트가 정상 작동하는지 확인하세요. 출시 전 웹사이트로 등록한다면 그 내용을 자세히 적어 주세요.<br><br>**채팅 위젯(Quick Setup)**(빠른 설정) 캠페인: 등록한 웹사이트 주소가 심사 담당자에게 열리지 않았거나, 비즈니스 사이트가 아니라 폼 페이지를 가리키고 있어요. 해결 방법:<br>- 폼이 있는 페이지만이 아니라 메인 비즈니스 웹사이트를 제출하세요.<br>- 주소가 문제없이 열리는지, 브랜드 등록에 쓴 도메인과 같은지 확인하세요.<br>- 버튼과 링크가 잘 작동하는지, 소셜 아이콘이 소셜 네트워크 첫 화면이 아니라 내 페이지를 가리키는지 확인하세요.<br>- 아직 출시 전이라면 웹사이트가 공개될 때까지 기다린 뒤 다시 제출하세요.<br><br>**Manual (Self-Serve)**(직접 등록) 캠페인: 심사 담당자가 캠페인이나 브랜드에 등록된 웹사이트 URL을 열 수 없었어요. 해결 방법:<br>- 폼이 있는 페이지만이 아니라 메인 비즈니스 웹사이트를 제출하세요. 가장 흔한 원인이에요.<br>- 주소가 문제없이 열리는지, 브랜드 등록에 쓴 도메인과 같은지 확인하세요.<br>- 버튼과 링크가 잘 작동하는지, 소셜 아이콘이 소셜 네트워크 첫 화면이 아니라 내 페이지를 가리키는지 확인하세요.<br>- 아직 출시 전이라면 캠페인 설명에 그렇게 밝히고, 제작 중인 웹사이트의 스크린샷이나 목업을 올려 둔 URL을 추가하세요. |
| 30896 | 옵트인 오류 | 옵트인(수신 동의) 메시지 흐름이 캠페인 유형에 충분하지 않아요. 동의가 필요한데 없거나, 옵트인이 제3자와 공유돼요. | 옵트인이 CTIA 가이드라인을 충족하는지 확인하세요. 옵트인 방법을 모두 적어야 해요. 종이 양식이나 로그인이 필요한 화면에서 옵트인을 받는다면 옵트인 이미지를 호스팅한 링크를 제공하세요. 웹사이트에서 옵트인이 이뤄진다면 그 웹사이트 링크를 제공하세요. 웹사이트에는 개인정보처리방침과 서비스 이용약관이 있어야 해요. 옵트인이 제3자와 공유되지 않도록 하세요.<br><br>**채팅 위젯(Quick Setup)** 캠페인: 심사 담당자가 사이트에서 문자 메시지에 대한 명확하고 독립적인 동의를 확인하지 못했어요. 해결 방법:<br>- 전화번호나 SMS 동의를 받는 다른 폼이 사이트에 있다면 모두 없애세요.<br>- 위젯이 있는 페이지에서 공개된 개인정보처리방침과 이용약관으로 연결되는 링크를 거세요.<br>- 하위 페이지만이 아니라 브랜드 등록에 쓴 웹사이트 URL에서 위젯이 로드되는지 확인하세요.<br><br>**Manual (Self-Serve)** 캠페인: 제출한 옵트인에서 문자 메시지 수신에 특별히 동의한다는 점이 분명하게 드러나지 않아요. 해결 방법:<br>- 문자 메시지 전용 체크박스를 추가하세요. 체크가 해제된 상태여야 하고, 이메일 가입이나 이용약관 동의와 합칠 수 없어요.<br>- 체크박스 옆에 비즈니스 이름, 보낼 메시지 내용, 발송 빈도, 메시지 및 데이터 요금이 부과될 수 있다는 점, 수신을 중단하는 방법을 적으세요.<br>- 폼과 같은 페이지에서 공개된 개인정보처리방침과 SMS 이용약관으로 연결되는 링크를 거세요.<br>- 스크린샷과 캠페인의 옵트인 설명이, 심사 담당자가 내 URL에서 보게 될 폼과 같은지 확인하세요. |
| 30919 | 웹사이트에 비즈니스 정보 부족 | 심사 담당자가 브랜드 등록에 쓴 웹사이트를 열어 봤지만, 어떤 비즈니스인지, 문자 메시지를 보내는지 알 수 없었어요. | **채팅 위젯(Quick Setup)** 캠페인: 심사 담당자가 브랜드 등록에 쓴 웹사이트를 열어 봤지만 어떤 비즈니스인지, 문자 메시지를 보내는지 알 수 없었어요. 해결 방법:<br>- 회사 이름, 제공하는 상품·서비스에 대한 구체적인 설명, 연락처를 추가하세요.<br>- 페이지를 두 개 이상 만드세요. 소개 섹션도 없고 상품 설명도 없는 한 페이지짜리 사이트는 반려돼요.<br>- [company name] 같은 임시 문구가 남아 있다면 지우세요.<br>- 웹사이트에 개인정보처리방침과 서비스 이용약관 링크를 거세요.<br><br>**Manual (Self-Serve)** 캠페인: 심사 담당자가 캠페인에 등록된 웹사이트만으로는 어떤 비즈니스인지, 문자 메시지를 보내는지 알 수 없었어요. 해결 방법:<br>- 랜딩 페이지나 폼 페이지가 아니라 메인 비즈니스 웹사이트를 제출하세요.<br>- 회사 이름, 제공하는 상품·서비스에 대한 구체적인 설명, 연락처를 추가하세요. "컨설팅"만으로는 부족해요. 어떤 종류의 컨설팅이고 누구를 위한 것인지 적으세요.<br>- 페이지를 두 개 이상 만드세요. 소개 섹션도 없고 상품 설명도 없는 한 페이지짜리 사이트는 반려돼요.<br>- 이 캠페인에 등록한 비즈니스 이름을 사이트 어딘가에 표시하세요. 푸터, 이용약관, 개인정보처리방침에 넣어도 괜찮아요.<br>- 문자 메시지 프로그램을 소개하고 개인정보처리방침 링크를 거세요.<br>- [company name] 같은 임시 문구가 남아 있다면 지우세요. |
| 30887 | 옵트아웃 오류 | 캠페인에서 소비자의 옵트아웃(수신 중단)을 받아 처리한다고 했지만, 처리 흐름이 불분명하거나 옵트아웃 키워드나 옵트아웃 메시지가 빠져 있어요. | 옵트아웃 처리 흐름이 정확한지 확인하세요. 그리고 **Message Flow**(메시지 흐름, 제출할 때는 **How do end-users consent to receive messages**(최종 사용자가 메시지 수신에 어떻게 동의하나요?)로 표시돼요) 설명에 옵트아웃 절차를 적으세요. 옵트아웃을 직접 관리한다면 옵트아웃 키워드를 추가하고, 옵트아웃 메시지에 다음 내용을 넣으세요: 옵트아웃 요청을 접수했다는 안내, 앞으로 메시지를 보내지 않는다는 확인, 브랜드 이름.<br><br>캠페인에는 옵트아웃을 처리한다고 되어 있지만, 절차나 키워드, 확인 메시지에 빠진 부분이 있어요. 해결 방법:<br>- 캠페인에 옵트아웃 절차를 설명하세요.<br>- 옵트아웃 키워드를 추가하세요.<br>- STOP에 대한 답장에 요청을 접수했다는 내용, 더 이상 메시지를 보내지 않는다는 내용, 비즈니스 이름을 넣으세요. |
| 30890 | 가입자 도움말(HELP) | HELP 답장 메시지에 브랜드 이름, 전화번호, 이메일 주소가 없어요. | HELP 답장 메시지에 브랜드 이름, 전화번호, 이메일 주소가 들어 있는지 확인하세요. "HELP"라고 답장한 고객이 누구에게 연락하면 되는지 안내해야 해요.<br><br>누군가 HELP라고 답장했을 때, 답장에 누구에게 연락해야 하는지가 없어요. 해결 방법:<br>- HELP 답장에 비즈니스 이름과 함께 전화번호나 이메일 주소를 넣으세요. |
| 30889 | **Embedded Phone Number**(메시지에 포함된 전화번호) | 전화번호를 메시지에 포함하는 것으로 선택했지만, 샘플 메시지에는 반영되어 있지 않아요. | **Embedded Phone Number** 선택이 정확한지 확인하세요. 샘플 메시지에 전화번호를 포함하도록 고치거나, **Embedded Phone Number** 선택을 바꾸세요. |
| 30888 | 연령 확인(Age Gate) 없음 / 부적합 | 연령 확인 절차가 없어요. | 웹사이트나 옵트인 정책에 확실한 연령 확인 절차를 추가하세요.<br><br>사이트나 옵트인 흐름에 연령 확인이 없어요. 주류, 담배 등 연령 제한이 있는 상품을 판매한다면 필수예요. 해결 방법:<br>- 옵트인 흐름에서 생년월일을 물어보세요.<br>- 연령 확인은 사이트 어딘가가 아니라, 메시지 수신에 가입하는 흐름 안에 넣으세요. |
| 30881 | 잘못된 브랜드 지원 이메일 | **지원 이메일**이 브랜드와 연결되어 있지 않아요. 브랜드 **지원 이메일**이 유효하지 않거나 공용 도메인 이메일이에요. | 브랜드 **지원 이메일**이 유효하고 공용 도메인 이메일이 아닌지 확인하세요.<br><br>연락용 이메일이 Gmail, Yahoo 같은 무료 서비스 주소인데, 이동통신사는 이런 주소를 받아 주지 않아요. 해결 방법:<br>- 내 비즈니스 도메인의 이메일을 쓰세요. 웹사이트 도메인과 같으면 가장 좋아요.<br>- 이메일 도메인이 웹사이트 도메인과 실제로 다르다면 캠페인 설명에 그 이유를 적으세요.<br>- 자체 도메인이 없는 개인 사업자라면, 웹사이트나 문의 페이지에 공개돼 있는 무료 이메일 주소를 그대로 쓰세요. |

## 내 A2P 10DLC 캠페인 등록은 누가 반려했나요?

반려된 캠페인에 유효한 campaign_id가 있다면, 외부 심사 파트너가 반려한 것이고 심사 비용 15달러가 이미 청구된 상태예요. 반려된 캠페인을 다시 제출할 때는 이제 비용이 0달러예요.

반려가 실수 때문이었다면 이의 제기를 할 수 있어요. 캠페인 이의 제기를 요청하려면 하이퍼클래스 고객지원에 문의하세요.
