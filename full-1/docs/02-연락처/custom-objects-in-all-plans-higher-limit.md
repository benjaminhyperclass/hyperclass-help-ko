# 모든 요금제에서 쓰는 사용자 지정 객체 (최대 10개)

사용자 지정 객체(Custom Objects)를 쓰면 하이퍼클래스를 우리 비즈니스에 맞게 구성할 수 있어요. 2025년 10월 업데이트부터 모든 요금제(Starter, Unlimited, Pro)에서 위치(서브 계정)당 사용자 지정 객체를 **최대 10개**까지 만들 수 있어요.

## 사용자 지정 객체란?

사용자 지정 객체는 연락처나 기회처럼 기본으로 제공되는 CRM 항목 외에, 우리 비즈니스에 필요한 새로운 레코드 유형을 직접 정의하는 기능이에요. 예를 들면 부동산, 차량, 보험 증권, 환자 같은 항목을 만들 수 있어요.

객체마다 고유한 커스텀 필드, 관계, 자동화를 설정할 수 있어서 복잡한 데이터도 하이퍼클래스 안에서 자유롭게 구성할 수 있어요.

## 사용자 지정 객체의 장점

- 어떤 비즈니스 모델에도 맞출 수 있어요. 거의 모든 대상이나 업무 과정을 관리할 수 있어요.
- 객체를 연락처나 다른 객체와 다대다 연관으로 연결할 수 있어요.
- 객체에서 일어나는 이벤트를 기준으로 워크플로우, 이메일, 문자, 웹훅 등을 실행할 수 있어요.
- 스마트 리스트, 상세 필터, 목록 보기 설정으로 데이터를 원하는 대로 나눠 볼 수 있어요.
- 추가, 편집, 삭제 작업마다 **감사 로그**가 남아서 데이터를 정확하게 관리할 수 있어요.

## 요금제별 사용 범위와 한도

사용 범위와 한도는 다음과 같아요.

- 모든 요금제에서 위치당 사용자 지정 객체를 10개까지 만들 수 있어요.
- 객체 하나에 담을 수 있는 레코드는 30만 개까지예요.
- 어떤 두 객체 사이에서도 객체마다 고유 레이블을 최대 10개까지 쓸 수 있어요.

## 사용자 지정 객체 기능

### 연관

**연관**은 레코드끼리 어떻게 이어지는지 정하는 기능이에요. 예를 들어 "차량 → 소유자"처럼 관계를 만들 수 있어요. 일대일, 일대다, 다대다 연결을 만들 수 있고, 만든 연관은 필터, 스마트 리스트, 워크플로우에서 다시 쓸 수 있어요. 데이터 사이의 관계가 한눈에 보여요.

### 커스텀 필드

사용자 지정 객체마다 자체 **커스텀 필드**를 쓸 수 있어요. 텍스트, 숫자, 날짜, 드롭다운 등 다양한 필드로 비즈니스에 필요한 정보를 정확하게 담을 수 있어요.

### 워크플로우 자동화

사용자 지정 객체가 만들어지거나 업데이트되거나 삭제될 때마다 자동화를 실행할 수 있어요. 알림 보내기, 연관된 객체 업데이트, 웹훅 실행, Google Sheets에 행 추가 같은 작업을 자주 써요.

### 스마트 리스트 & 목록 보기

공유할 수 있는 스마트 리스트를 만들고, 열 너비를 조절하고, 저장해 둔 보기를 바꿔서 팀에 필요한 객체 데이터만 볼 수 있어요. 목록 보기의 정렬과 열 선택까지 함께 쓰면 사용자 지정 객체가 용도에 맞게 만든 데이터베이스처럼 느껴져요.

### 상세 필터 & 리포팅

모든 객체와 커스텀 필드에 AND/OR 조건을 적용해서 원하는 레코드만 정확하게 골라낼 수 있어요. 전문적인 리포팅이나 일회성 내보내기에 알맞아요.

### 감사 로그

생성, 업데이트, 삭제, 연관 변경 내역이 모두 **감사 로그**에 기록돼요. 데이터를 체계적으로 관리하고 책임 소재를 확인할 수 있어요.

## 사용자 지정 객체 지원 범위

### 사용자 지정 객체를 지원하는 곳

- 연락처, 기회 관리 (연관을 통해)
- 워크플로우 (트리거와 액션)
- 폼, 설문, 퀴즈
- 대시보드 & 리포팅
- API & 웹훅
- 커스텀 필드 (사용자 지정 객체 안에서 모든 필드 유형 지원)
- 작업

### 사용자 지정 객체를 지원하지 않는 곳

- 이메일 캠페인
- 일괄 이메일 / 일괄 SMS
- 대화 (아직 사용자 지정 객체 데이터를 보거나 쓸 수 없어요)
- 퍼널 & 웹사이트 (아직 사용자 지정 객체 데이터를 동적으로 표시할 수 없어요)
- 캘린더 & 일정 예약
- 평판 관리 / 리뷰
- 결제 & 인보이스
- 회사

### 지원 예정

- 메모
- 퍼널 & 웹사이트: 사용자 지정 객체 데이터를 동적으로 연결하고 표시하는 기능
- AI 지식 베이스: AI 에이전트가 사용자 지정 객체 데이터를 가져와 참고하는 기능
- 워크플로우를 통한 이메일: 사용자 지정 객체 레코드와 연관된 연락처에게 이메일 보내기

## 자주 묻는 질문

### 사용자 지정 객체를 쓰려면 Pro 요금제가 필요한가요?

아니요. 2025년 10월부터 모든 요금제(Starter, Unlimited, Pro)에서 사용자 지정 객체를 쓸 수 있어요.

### 객체는 몇 개까지 만들 수 있나요?

모든 요금제에서 서브 계정당 최대 10개까지 만들 수 있어요.

### 객체를 10개보다 더 만들 수 있나요?

현재는 10개가 최대예요. 더 많은 객체가 필요하면 하이퍼클래스 고객지원에 기능 요청을 남겨 주세요.

### 객체를 더 추가하면 기존 워크플로우가 멈추나요?

아니요. 워크플로우는 새 객체를 자동으로 인식해요. 필요한 트리거나 액션만 추가하면 돼요.

### 스냅샷으로 사용자 지정 객체를 가져오거나 내보낼 수 있나요?

네. 스냅샷을 만들거나 복원할 때 객체가 필드와 연관까지 함께 포함돼요. 다만 대상 계정의 객체 개수 한도가 적용돼요.

### 사용자 지정 객체용 API 엔드포인트가 있나요?

네. REST API로 객체와 레코드를 만들고, 조회하고, 수정하고, 삭제할 수 있어요. 스키마 같은 자세한 내용은 API 문서를 참고하세요.

### 사용자 지정 객체는 누가 편집하거나 삭제할 수 있나요?

위치(서브 계정) 수준의 관리자만 만들기, 업데이트, 삭제 권한이 있어요. 일반 사용자는 읽기만 할 수 있어요.

### 객체 데이터도 계정 저장 용량에 포함되나요?

네. 사용자 지정 객체 안에 저장한 레코드와 파일은 모두 계정의 전체 저장 용량에 포함돼요.
