# 커스텀 필드로 연락처에 파일 추가하기

**File Upload**(파일 업로드) 유형의 커스텀 필드를 만들면 연락처 기록 안에 계약서, 인보이스, 폼 같은 파일을 바로 보관할 수 있어요. 이 문서에서는 필드를 만들고 파일을 올려 관리하는 방법을 안내해요.

## 연락처에 파일을 추가하면 좋은 점

중요한 문서를 해당 연락처 기록에 함께 두면 팀원이 찾아보고 관리하기 쉬워요.

연락처의 **커스텀 필드** 섹션에서 파일을 올리려면 먼저 **File Upload** 유형으로 커스텀 필드를 만들어야 해요. 그러면 연락처 기록에서 이 필드로 파일을 올리고, 보고, 교체하고, 삭제할 수 있어요.

{% hint style="warning" %}
**File Upload** 커스텀 필드로 파일을 올리는 방식은 하이퍼클래스의 다른 파일·문서 기능과 달라요. 이 문서는 연락처의 커스텀 필드에 저장되는 파일만 다뤄요.
{% endhint %}

## 커스텀 필드를 만들기 전에 확인할 점

**File Upload** 커스텀 필드를 설정할 때는 올릴 수 있는 파일과 필드가 보이는 방식을 정할 수 있어요.

| 항목 | 역할 | 세부 내용 및 예시 |
| --- | --- | --- |
| **File Type**(파일 유형) | 이 필드로 올릴 수 있는 파일 유형을 정해요. | 필드에 맞는 지원 파일 유형을 선택하세요. |
| **File Restriction**(파일 제한) | 업로드할 수 있는 최대 파일 크기를 정해요. | 파일 하나당 최대 250MB예요. |
| **다중 파일 허용** | 필드에 파일을 하나만 올릴지, 여러 개 올릴지 정해요. | 파일 하나만 받거나, 허용할 파일 개수를 설정하세요. |
| **Object Type**(오브젝트 유형) | 커스텀 필드를 어디에 사용할지 정해요. | 올린 파일을 연락처 기록에 연결하려면 **연락처**를 선택하세요. |
| **Group Tab**(그룹 탭) | 정리하기 쉽도록 필드가 표시될 위치를 정해요. | 예: **연락처 정보**, **기본 정보**, **추가 정보** |
| 필드 저장 | 커스텀 필드를 사용할 수 있게 만들어요. | **저장**하면 해당 **커스텀 필드** 섹션에 필드가 나타나요. |

## 커스텀 필드로 연락처에 파일 올리기

**커스텀 필드** 섹션에서 파일을 올리려면 **File Upload** 유형의 커스텀 필드가 있어야 해요.

필드를 만든 뒤에는 연락처 프로필에서 해당 필드를 찾아 파일을 올리면 돼요.

### 1단계: File Upload 커스텀 필드 만들기

1. 왼쪽 메뉴에서 **설정**으로 이동하세요.
2. **커스텀 필드**를 선택하세요.
3. **Create Custom Field**(커스텀 필드 만들기)를 클릭하세요.

   ![커스텀 필드 만들기 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078254559/original/IWdXdnFhSG-7IEfVgMuFg5FNOhFESboBAQ.png?1786544809)
4. **File Upload** 필드 유형을 선택하세요.

   ![File Upload 필드 유형을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078254767/original/LQ98qclqWlGPNppdDf38WlNXpKxpqQ3Lpw.png?1786544883)
5. **설명이 되는 이름 입력** 필드에 필드 이름을 입력하세요. 예를 들면 '계약서 업로드', '고객 문서' 같은 이름이 좋아요.

   ![필드 이름을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078254827/original/06zi099n_eeujnL39CP6wI3EWp9mSjJ1Ug.png?1786544916)
6. 필요에 맞게 파일 설정과 필드 설정을 지정하세요.
7. 커스텀 필드를 **저장**하세요.

   ![커스텀 필드를 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078254916/original/_97G1OUXcSs_NKmRvrhi8vw8nasHmhJF9Q.png?1786544984)

이제 선택한 오브젝트에서 **File Upload** 필드를 사용할 수 있어요.

### 2단계: 연락처에서 File Upload 필드 찾기

1. **연락처**로 이동하세요.
2. 파일을 추가할 연락처를 선택하세요.
3. 연락처 프로필의 **커스텀 필드** 섹션으로 이동하세요.
4. 방금 만든 **File Upload** 커스텀 필드를 찾으세요.

![연락처 프로필에서 File Upload 커스텀 필드를 찾는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078568938/original/uS3W81z0gHYc7IZ30hNyEJk3Iix0k4f6lA.gif?1786958285)

커스텀 필드가 여러 개라면, 필드를 만들 때 선택한 **Group Tab**에서 찾아보세요.

### 3단계: 파일 올리기

1. 연락처에서 **File Upload** 커스텀 필드를 찾으세요.
2. **파일 업로드**를 클릭하세요.
3. 기기에서 파일을 선택하세요.
4. 업로드를 확인하세요.

![연락처에 파일을 업로드하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078569830/original/DfFbYSS2n5KrVGrdE0gbr2TquLFYno85bg.gif?1786958604)

파일을 올린 뒤에는 연락처 프로필에서 바로 관리할 수 있어요. 올린 파일을 보려면 커스텀 필드 안의 파일 링크를 선택하세요. 필드에서 파일을 삭제하거나 교체할 수도 있어요. 파일을 실수로 삭제했을 때 **Undo**(실행 취소) 옵션이 나타나면, 이를 선택해 파일을 복원하세요.

## 자주 묻는 질문

### 어떤 파일 형식을 올릴 수 있나요? 동영상도 올릴 수 있나요?
동영상은 지원하지 않아요. 지원하는 문서·이미지 형식은 PDF, DOCX, PNG, JPG, CSV, PPTX, XLSX예요.

### 파일 크기는 최대 얼마까지 가능한가요?
파일 하나당 최대 250MB까지 올릴 수 있어요.

### 연락처에 파일을 올리려면 커스텀 필드를 먼저 만들어야 하나요?
네, 이 문서에서 설명하는 방법으로는 먼저 만들어야 해요. 연락처의 **커스텀 필드** 섹션에 파일을 저장하려면 **File Upload** 유형으로 커스텀 필드를 먼저 만드세요. 필드를 만들면 연락처 기록에서 파일을 올리고 관리할 수 있어요.

### 올린 파일을 삭제하거나 교체할 수 있나요?
네. **File Upload** 커스텀 필드에 저장된 파일은 연락처 기록에서 삭제하거나 교체할 수 있어요.

### 파일을 여러 개 올릴 수 있나요?
**File Upload** 커스텀 필드를 만들 때 **다중 파일 허용** 설정을 필드에 받을 파일 개수에 맞게 지정하세요.

### 파일 업로드가 안 될 때는 어떻게 하나요?
파일 업로드가 실패하면 아래 순서로 확인해 보세요.

- 파일이 지원하는 파일 형식과 크기 조건에 맞는지 확인하세요.
- 인터넷 연결 상태를 확인하세요.
- 페이지를 새로 고친 뒤 다시 업로드해 보세요.
