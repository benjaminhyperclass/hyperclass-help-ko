# 하이퍼클래스에서 회사 필드 활용하기

표준 필드와 커스텀 필드를 포함한 회사 필드를 커스텀 값(병합 필드)으로 넣어 쓰는 방법을 안내해요. **워크플로우**, **이메일 빌더**, **이메일 캠페인**, **대화**, **문서 & 계약**, **일괄 작업**, **대화 AI**에서 쓸 수 있어요.

## 개요

회사 필드에는 회사 이름, 웹사이트, 주소, 업종 같은 비즈니스 정보나 회사 오브젝트에 직접 만든 속성이 저장돼요. 이 필드를 지원하는 도구에 커스텀 값으로 넣으면, 연락처에 연결된 회사에 맞춰 내용을 개인화할 수 있어요.

회사 필드는 **Custom Value Picker**(커스텀 값 선택기) 안의 **회사** 그룹에 모여 있어요.

## 회사 필드를 쓸 수 있는 곳

회사 필드는 다음 도구에서 쓸 수 있어요.

- **워크플로우**: 커스텀 값을 지원하는 모든 액션(**Send Email**(이메일 보내기), **Send SMS**(SMS 보내기), **Update Contact**(연락처 업데이트), **Internal Notification**(내부 알림) 등)
- **이메일 빌더**: 이메일 템플릿과 이메일 내용
- **이메일 캠페인**: 여러 수신자에게 보내는 캠페인 이메일
- **대화**: 1:1 메시지
- **문서 & 계약**: 계약서, 제안서, 합의서 템플릿
- **일괄 작업**: 일괄 발송 작업
- **대화 AI**: AI 에이전트의 응답

## 지원하는 필드

**Custom Value Picker**에서 회사의 표준 필드와 커스텀 필드를 모두 고를 수 있어요.

**표준 필드**

- **이름**
- **Email**(이메일)
- **Phone**(전화번호)
- **웹사이트**
- **Address**(주소)
- **City**(시/도시)
- **State**(주/도)
- **Country**(국가)
- **Postal Code**(우편번호)
- **설명**

**커스텀 필드**

- 회사 오브젝트에 만든 모든 커스텀 필드(텍스트, 숫자, 날짜, 드롭다운 등)

## 회사 필드 사용 방법

1. 회사 필드를 지원하는 도구를 열어요. 예를 들어 **이메일 빌더**, 워크플로우의 **Send Email** 액션, 문서 템플릿이 있어요.
2. 에디터 도구 모음에서 **Custom Value Picker** 아이콘을 클릭하세요.
3. 필드 그룹 목록에서 **회사**를 선택하세요.
4. 넣고 싶은 표준 필드나 커스텀 필드를 고르세요. 예를 들어 **이름**, **웹사이트**, 또는 **Industry**(업종) 같은 커스텀 필드를 고를 수 있어요.
5. 커서 위치에 커스텀 값 태그가 들어가요. 예: `{{business.name}}`
6. **변경사항 저장**을 클릭하세요. 실제로 사용될 때 이 태그는 연락처에 연결된 회사의 값으로 바뀌어요.

## 알아 두세요

- 회사 필드는 연락처에 연결된 회사를 기준으로 값이 채워져요.
- 연락처에 연결된 회사가 없으면 커스텀 값 태그는 빈칸으로 표시돼요.
- 회사의 표준 필드나 커스텀 필드가 비어 있으면 해당 태그도 빈칸으로 표시돼요. 대체 텍스트는 들어가지 않아요.
- 회사의 필드 값을 수정하면, 다음에 커스텀 값이 채워질 때 바뀐 값이 반영돼요.
- 회사 오브젝트에 새로 추가한 커스텀 필드는 **Custom Value Picker**에 자동으로 나타나요.
