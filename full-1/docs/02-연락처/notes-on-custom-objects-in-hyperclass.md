# 사용자 지정 객체에서 메모 사용하기

사용자 지정 객체 레코드에 직접 메모를 남기고, 검색·필터·정렬로 메모를 관리하는 방법을 안내해요. 연락처나 기회에 쓴 메모를 관련 사용자 지정 객체 레코드와 연결하는 기능도 함께 다뤄요.

[동영상](https://www.youtube.com/embed/2369hruUG88?&wmode=opaque)

## 사용자 지정 객체 메모란?

사용자 지정 객체 레코드에 중요한 내용을 바로 기록할 수 있는 기능이에요. 관련 정보가 연락처나 기회의 타임라인에만 묻혀 있지 않고, 해당 레코드 옆에 함께 저장돼요. 메모를 추가하고, 메모 기록을 검색하고, 필터와 정렬로 많은 메모를 관리할 수 있어요.

사용자 지정 객체 레코드에 직접 메모를 쓰는 것 외에, 연락처나 기회에서 만든 메모를 관련 사용자 지정 객체 레코드와 연결할 수도 있어요. 같은 메모가 연결된 여러 레코드에 나타나지만 복사본이 생기지는 않아요. 덕분에 함께 일하기 쉽고, 메모 하나만 원본으로 유지돼요.

## 사용자 지정 객체 메모의 장점

사용자 지정 객체 메모는 CRM에서 협업하는 경험을 넓혀 주고, 사용자 지정 객체를 일상 업무에서 더 유용하게 만들어 줘요.

- 레코드별 맥락: 사용자 지정 객체 레코드에 메모를 직접 저장하므로, 일하는 화면에서 중요한 정보를 바로 볼 수 있어요.
- 단일 정보 출처: 연락처, 기회, 객체마다 같은 내용을 복사하지 않고 메모 하나를 여러 레코드에 연결해요.
- 더 쉬운 협업: 여러 타임라인을 뒤지지 않아도 레코드의 전체 맥락을 빠르게 파악할 수 있어요.
- 빠른 정보 검색: 키워드로 메모를 검색해 중요한 업데이트나 지난 기록을 금방 찾을 수 있어요.
- 더 나은 정리: 필터와 정렬 옵션으로 긴 메모 기록을 관리하고 가장 필요한 업데이트를 찾을 수 있어요.

## 사용자 지정 객체에 메모 추가하기

메모를 알맞은 위치에 남기면 연결된 레코드 전체에서 내용을 한눈에 확인할 수 있어요.

1. 하이퍼클래스에서 **사용자 지정 객체**로 이동하세요.
2. 메모를 추가할 사용자 지정 객체 레코드를 여세요.

   ![사용자 지정 객체 레코드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066785035/original/szm3K_e-eHxC0u7SVBAUbglnOjztPYYFLA.png?1773317429)
3. 레코드 오른쪽에서 **Notes**(메모) 패널을 찾으세요.

   ![레코드 오른쪽의 메모 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066784832/original/U954EEmxUT9M1EdXMvsN9G9Jcyf9ovin_Q.png?1773317329)
4. **Add Note**(메모 추가)를 클릭하세요.
5. 메모 내용을 입력하세요.

   ![메모 내용을 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066785276/original/kdKnDiTd1Yf3heKLhzhNFNpGtX1k2l-yOA.gif?1773317530)
6. **저장**을 클릭하세요.

이제 메모가 원래 레코드와 연결된 사용자 지정 객체 레코드 양쪽에 모두 표시돼요.

## 워크플로우로 메모 자동 추가하기

워크플로우를 사용하면 사용자 지정 객체 레코드에 메모를 자동으로 추가할 수 있어요.

1. 사용자 지정 객체용 워크플로우를 여세요.
2. **Add to Note**(메모에 추가) 액션을 추가하세요.
3. 메모 내용을 입력한 뒤 **Save**(저장)하고 **Publish**(게시)하세요.

{% hint style="info" %}
사용자 지정 객체 워크플로우 메모에서는 메모 제목과 메모 색상을 아직 지원하지 않아요.
{% endhint %}

## 자주 묻는 질문

### 사용자 지정 객체에 연결한 메모는 복사본이 만들어지나요?
아니요. 연결된 메모는 하나의 메모로 유지되고, 연결된 모든 레코드에 표시돼요.

### 사용자 지정 객체 레코드에서 바로 메모를 만들 수 있나요?
네. 사용자 지정 객체 레코드의 **Notes** 패널에서 직접 만들 수 있어요.

### 사용자 지정 객체 레코드의 메모를 검색할 수 있나요?
네. **Notes** 패널의 검색 기능(**메모 검색**)으로 키워드를 입력해 메모를 찾을 수 있어요.

### 연락처나 기회의 메모를 사용자 지정 객체 레코드에서도 볼 수 있나요?
네. 관련 사용자 지정 객체 레코드와 연결되어 있으면 메모를 연결할 수 있어요.

### 메모를 수정하면 연결된 모든 곳에 반영되나요?
네. 연결된 메모는 복사되지 않고 공유되기 때문에, 수정하면 연결된 모든 레코드에 반영돼요.

### 메모를 삭제하지 않고 연결만 해제할 수 있나요?
네. 원본 메모는 그대로 두고 연결만 해제할 수 있어요.
