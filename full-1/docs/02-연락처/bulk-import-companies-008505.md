# 회사 일괄 가져오기

CSV 파일로 회사 데이터를 한꺼번에 만들거나 업데이트하는 방법을 안내해요. 4단계 가져오기 마법사를 따라가면 수백 건의 회사 데이터도 한 번에 옮길 수 있어요.

## 이 문서에서 알 수 있는 것

일괄 가져오기 기능으로 CSV 파일을 이용해 하이퍼클래스 CRM에 회사 데이터를 만들고 업데이트하는 방법을 설명해요. 가져오기 마법사를 쓰는 법, 필드를 올바르게 연결하는 법, 중복을 처리하는 법, 가져오기 결과를 확인하는 법을 다뤄요.

이 문서를 끝까지 따라 하면 데이터 정확성을 지키면서 많은 양의 데이터를 CRM으로 효율적으로 옮길 수 있고, 흔한 가져오기 오류도 피할 수 있어요.

{% hint style="info" %}
이 기능은 현재 **실험실**에서 제공돼요. 서브 계정의 **설정**에서 **실험실**을 선택하고 "Company and Custom Object Import"를 켠 다음 이 문서의 단계를 진행하세요.
{% endhint %}

## 회사 일괄 가져오기란?

회사 일괄 가져오기는 CSV 파일로 여러 회사 데이터를 한 번에 만들고 업데이트하는 도구예요. 4단계 마법사(**Start**(시작) → **업로드** → **지도** → **인증**)를 따라 파일을 올리고, 필드를 회사 속성에 연결하고, 중복을 찾고, 실행 전에 내용을 검토할 수 있어요.

마법사에는 다음 기능이 있어요.

- 미리보기 데이터를 보면서 필드를 연결하는 스마트 필드 매핑
- **회사 ID**를 기준으로 한 중복 감지
- 기존 필드 값을 빈 값으로 덮어쓰지 않게 하는 옵션

가져오기를 제출한 뒤에는 **일괄 작업** 페이지에서 진행 상황과 자세한 통계를 확인할 수 있어요.

이 기능은 많은 회사 데이터를 관리하는 에이전시와 비즈니스가 CRM을 대규모로 옮기고, 직접 입력하는 작업을 줄이도록 만들어졌어요.

## 주요 장점

회사 데이터를 대량으로 관리할 때 이런 점이 좋아요.

- 빠른 CRM 이전 — 수백 건의 회사 데이터를 하나씩 만들지 않고 몇 분 만에 가져올 수 있어요.
- 중복 관리 — **회사 ID**를 기준으로 중복된 회사를 자동으로 감지하고 처리해서 데이터를 깔끔하게 유지해요.
- 유연한 업데이트 옵션 — 한 번의 가져오기에서 새로 만들기만, 업데이트만, 또는 만들기와 업데이트를 함께 선택할 수 있어요.
- 데이터 보호 — **Don't update to empty value**(빈 값으로 업데이트하지 않기) 옵션을 켜면 기존 필드 데이터가 실수로 지워지는 일을 막을 수 있어요.
- 상세한 감사 통계 — 가져오기가 끝나면 성공·오류·경고 건수를 보고, 문제 해결용 상세 리포트를 내려받을 수 있어요.
- 운영 부담 감소 — 반복 입력 작업과 CRM 설정 중 수작업 실수를 줄여 줘요.

## 실험실에서 회사 및 사용자 지정 객체 가져오기 켜기

회사 데이터를 가져오려면 먼저 서브 계정 설정의 **실험실**에서 이 기능을 켜야 해요. 이 기능은 **실험실**에 있는 기능이라서 먼저 사용해 볼 수 있고, 사용자 의견에 따라 업데이트될 수 있어요.

1. 서브 계정의 **설정**으로 이동해 왼쪽 사이드바에서 **실험실** 탭을 선택하세요.
2. **Company and Custom Object Import**(회사 및 사용자 지정 객체 가져오기) 토글을 찾아 켜세요.
3. 켠 뒤에는 CRM의 **회사** 메뉴로 이동해 **가져오기** 버튼이 보이는지 확인하세요.

## 4단계 가져오기 마법사 이해하기

가져오기 마법사는 데이터를 정확하게 옮기도록 네 단계로 안내해요.

1. **Start**(시작): 객체 유형(회사)을 선택하고 가져오기 방식을 정해요. 새 데이터를 만들지, 기존 데이터를 업데이트할지, 둘 다 할지 선택해요.
2. **업로드**: CSV 파일을 올리고 중복을 찾을 기준을 선택해요. 보통은 **회사 ID**를 써요.
3. **지도**: 필드를 연결하는 단계예요. CSV의 각 열을 해당 회사 필드와 연결해요. 파일의 샘플 데이터가 함께 표시돼서 제대로 연결했는지 확인할 수 있어요.
4. **인증**: 제출하기 전에 모든 설정을 검토하는 단계예요. 이 화면에서 **빈 값 건너뛰기** 옵션을 켜면 CSV의 빈 칸이 기존 데이터를 덮어쓰지 않아요.

{% hint style="info" %}
**지도** 단계에서 필드 연결을 항상 꼼꼼히 확인하세요. 잘못 연결하면 데이터가 엉뚱한 필드에 들어가서 직접 정리하거나 다시 가져와야 할 수 있어요.
{% endhint %}

## 일괄 작업에서 가져오기 확인하기

가져오기를 제출하면 하이퍼클래스가 백그라운드에서 파일을 처리해요. **일괄 작업 – 회사** 대시보드에서 진행 상황과 자세한 결과를 확인할 수 있어요.

**일괄 작업** 페이지에는 가져오기마다 다음 통계가 표시돼요.

- **Success Count**(성공 건수): 성공적으로 만들었거나 업데이트한 회사 데이터 수예요.
- **Error Count**(오류 건수): 데이터 검증 문제나 시스템 오류로 가져오지 못한 데이터 수예요.
- **Warning Count**(경고 건수): 가져오기는 됐지만 검토가 필요할 수 있는 문제가 있는 데이터 수예요.

줄 단위 결과, 오류 설명, 경고가 담긴 상세 가져오기 리포트도 내려받을 수 있어요. 이 리포트는 감사나 실패한 데이터의 원인 확인, 대량 가져오기 후 데이터 정확성 점검에 유용해요.

{% hint style="info" %}
가져오기가 끝나면 바로 리포트를 내려받아 가져오기 기록을 보관하세요. 나중에 규정 준수, 감사, 문제 해결이 필요할 때 도움이 돼요.
{% endhint %}

## 회사 가져오기 모범 사례

회사 데이터를 매끄럽고 정확하게 가져오려면 다음 권장 사항을 따르세요.

1. CSV 파일을 꼼꼼히 준비하세요.
   열 제목은 명확하게, 데이터 형식은 일관되게 맞추고 불필요한 특수 문자는 넣지 마세요. 업로드하기 전에 중복된 행은 지우세요.

2. 필드 연결을 꼼꼼히 검토하세요.
   **지도** 단계에서 필드 연결을 꼭 두 번 확인하세요. CSV의 각 열 데이터가 하이퍼클래스의 올바른 회사 필드와 맞는지 확인해야 정보가 엉뚱한 속성에 들어가지 않아요.

3. **빈 값 건너뛰기**를 켜세요.
   기존 데이터를 업데이트할 때 이 옵션을 켜면 CSV의 빈 칸이 하이퍼클래스에 이미 입력된 필드를 덮어쓰지 않아요. 기존 데이터가 실수로 지워지는 일을 막을 수 있어요.

4. 먼저 작은 샘플로 테스트하세요.
   수천 건을 가져오기 전에 10~20행짜리 작은 CSV 파일로 먼저 테스트해 보세요. **일괄 작업**에서 결과를 확인해 필드 연결과 설정이 맞는지 점검하세요.

5. 감사용으로 가져오기 리포트를 내려받으세요.
   가져오기를 마칠 때마다 **일괄 작업** 페이지에서 상세 가져오기 리포트를 내려받으세요. 이 리포트는 기록 보관, 문제 해결, 규정 준수에 쓸 수 있도록 보관해 두세요.

{% hint style="info" %}
가져올 데이터가 500건 이상이라면 200~300행씩 나누어 가져오세요. 오류를 찾아 고치기 쉽고, 큰 파일을 다시 올리지 않아도 돼요.
{% endhint %}
