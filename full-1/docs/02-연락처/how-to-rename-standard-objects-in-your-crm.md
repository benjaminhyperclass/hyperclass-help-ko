# CRM 표준 오브젝트 이름 바꾸기

연락처, 기회, 회사 같은 표준 오브젝트의 이름을 우리 조직에서 쓰는 용어로 바꾸는 방법을 안내해요. 관리자가 이름을 한 번 바꾸면 하이퍼클래스 전체에 같은 이름이 보여요.

## 표준 오브젝트 이름 바꾸기 기능이란?

하이퍼클래스에서는 관리자가 CRM의 핵심 오브젝트 세 가지(연락처, 기회, 회사)의 이름을 조직에서 쓰는 말로 바꿀 수 있어요. 예를 들어 "클라이언트", "딜", "조직"처럼 바꿀 수 있어요.

화면에 보이는 이름만 바뀌고 내부 데이터 키는 그대로예요. 그래서 자동화, 리포트, API 호출은 지금처럼 계속 작동해요.

## 표준 오브젝트 이름을 바꾸면 좋은 점

- 업무에 맞는 용어: 팀에서 쓰는 말에 맞춰 오브젝트 이름을 바꿀 수 있어요.
- 빠른 적응: 익숙한 이름이면 팀원들이 매일 더 편하게 써요.
- 쉬운 온보딩: 새 팀원이 용어를 바로 알아보고 빨리 익숙해져요.
- 알아보기 쉬운 리포트: 대시보드와 필터가 우리 비즈니스에서 쓰는 말로 보여요.
- 시스템에 안전한 변경: 표시 이름만 바뀌고 내부 데이터와 키는 그대로예요.
- 어디서나 같은 이름: 한 번 바꾸면 탐색 메뉴, 필터, 워크플로우, 대시보드에 모두 반영돼요.
- 대화 AI에서도 같은 용어: **Conversation AI 봇**의 라벨과 참조에도 직접 정한 표준 오브젝트 이름이 쓰여서 용어가 서로 맞아요.

## 표준 오브젝트 이름 바꾸는 방법

{% hint style="info" %}
표준 오브젝트 이름은 **설정 > Custom Objects**(커스텀 오브젝트) 접근 권한이 있는 관리자만 바꿀 수 있어요. 다른 사용자는 바뀐 이름을 볼 수만 있고 편집할 수는 없어요.
{% endhint %}

<!-- 검토 필요: 원문 내용이 서로 다름 (본문은 Settings → Custom Objects 접근 권한, FAQ는 Settings → Objects 접근 권한이라고 되어 있음) -->

1. **설정**으로 이동하세요.

   ![설정 메뉴 화면](https://jumpshare.com/share/8XmvtzJD4LMOKLT7tXoN+/Screen+Shot+2025-10-16+at+7.08.07+PM.png)
2. **오브젝트**를 클릭하세요.
3. 이름을 바꿀 오브젝트(예: 연락처)에서 점 세 개 아이콘을 클릭하세요.

   <!-- 검토 필요: 원문에 'three bots'로 되어 있으나 'three dots'(점 세 개)의 오타로 보고 옮김 -->
4. **편집**을 클릭하세요.

   ![오브젝트 편집 화면](https://jumpshare.com/share/xBifngUkf5OIFjhibOYE+/Screen+Shot+2025-10-16+at+7.13.09+PM.png)
5. **Object Name**(오브젝트 이름) 섹션에서 다음 항목을 수정하세요.
   - **Singular Name**(단수 이름): 개별 레코드에 표시돼요.
   - **Plural Name**(복수 이름): 목록 보기와 필터에 표시돼요.
6. **변경사항 저장**을 클릭하세요.

   {% hint style="info" %}
   대화 AI는 현재 서브 계정의 **설정 > 오브젝트**에서 표준 오브젝트 별칭을 동적으로 가져와요. 변경 내용은 보통 저장한 직후 바로 나타나요.
   {% endhint %}

   ![변경사항 저장 화면](https://jumpshare.com/share/0ui64B1LA5bo3yFM9rAW+/Screen+Shot+2025-10-16+at+7.17.03+PM.png)
7. 새 이름은 다음 위치에 자동으로 반영돼요.
   - 탐색 메뉴

     ![새 이름이 반영된 탐색 메뉴](https://jumpshare.com/share/R5M6ctIrQcTL0FG7HcDx+/Screen+Shot+2025-10-16+at+7.21.58+PM.png)
   - 필터와 스마트 리스트
   - 리포트와 대시보드
   - 연관 모듈

     ![새 이름이 반영된 연관 모듈](https://jumpshare.com/share/0yC9Hk8Gljq8mhOXRiPO+/Screen+Shot+2025-10-16+at+7.38.43+PM.png)

## 이름 규칙과 제한 사항

- 표준 오브젝트(연락처, 기회, 회사)는 모두 이름을 바꿀 수 있어요.
- 단수 이름과 복수 이름 모두 최대 50자까지 입력할 수 있어요.
- 이름은 고유해야 해요. 두 오브젝트가 같은 단수 이름이나 복수 이름을 함께 쓸 수 없어요.
- 백엔드가 안정적으로 작동하도록 내부 오브젝트 키는 바뀌지 않아요.
- 이름을 바꾸면 표시 라벨만 바뀌어요. 내부 키와 API 필드는 그대로예요. **병합 필드** 이름도 바뀌지 않아요.

## 자주 묻는 질문

### 오브젝트 이름을 바꾸면 워크플로우나 API 연동이 깨지나요?
아니요. 내부 오브젝트 키는 그대로이고 화면에 보이는 라벨만 바뀌어요.

### 두 오브젝트가 같은 이름을 쓸 수 있나요?
아니요. 단수 이름과 복수 이름은 모두 플랫폼 전체에서 고유해야 해요.

### 누가 오브젝트 이름을 바꿀 수 있나요?
**설정 > 오브젝트**에 접근할 수 있는 관리자만 바꿀 수 있어요. 일반 사용자는 바뀐 이름을 볼 수만 있고 편집할 수는 없어요.
