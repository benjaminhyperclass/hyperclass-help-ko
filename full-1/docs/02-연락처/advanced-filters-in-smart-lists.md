# 스마트 리스트 상세 필터 사용하기

스마트 리스트에서 **상세 필터**를 쓰면 연락처를 더 정확하게 나눌 수 있어요. 이 문서에서는 상세 필터가 무엇인지, 어떻게 설정하는지, 필터 옵션이 각각 어떻게 동작하는지 설명해요. 스마트 리스트 전체 개요가 궁금하면 "스마트 리스트 만들고 관리하기" 문서를 참고하세요.

## 스마트 리스트의 상세 필터란?

**상세 필터**는 연락처 필드와 관련 데이터에 규칙을 적용해서 스마트 리스트 결과를 좁혀 주는 기능이에요. 연락처 정보, 참여도, 커뮤니케이션 설정, 기회 데이터 등을 기준으로 원하는 대상만 골라 리스트를 만들 수 있어요.

필터 하나는 필드, 연산자, 값 세 가지로 이루어져요. 연산자는 선택한 필드에 따라 달라져요. 예를 들어 날짜 필드에서는 날짜 기준 연산자를, 숫자 필드에서는 비교 연산자를 쓸 수 있어요.

![상세 필터 구성 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067238877/original/2MAhrzna8g6y0aqLrdchTLh9wgPWGgieiw.png?1773848221)

## 상세 필터의 장점

- 정밀한 세분화: 특정 필드 값, 연산자, 조건으로 연락처 리스트를 좁힐 수 있어요.
- 더 정확한 리스트: 필드 유형에 맞는 연산자를 골라 연락처를 더 정확하게 찾을 수 있어요.
- 빠른 리스트 작성: 검색 가능한 필터로 필요한 필드를 빠르게 찾을 수 있어요.
- 유연한 필터링: 날짜, 문자열, 숫자, 상태, 기회, 수신거부 관련 데이터를 다룰 수 있어요.
- 깔끔한 연락처 관리: 값이 없는 항목, 잘못된 상태 등 확인이 필요한 레코드를 찾을 수 있어요.
- 안전한 발송 대상 선정: 수신거부와 상태 기반 필터로 규정에 더 맞는 발송 리스트를 만들 수 있어요.

## 스마트 리스트에서 상세 필터 설정하기

필드, 연산자, 값을 알맞게 고르면 원하는 연락처만 정확하게 불러올 수 있고, 스마트 리스트도 관리하기 쉬워져요.

1. **연락처**로 이동한 다음 **스마트 리스트 추가**를 클릭하거나, 기존 스마트 리스트를 열어요.

   ![연락처 화면에서 스마트 리스트 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071633839/original/Clp4-CCdWz2BunkzxrRaKU7jmXGTz4CyUw.png?1779174768)
2. **상세 필터**를 클릭해요.

   ![상세 필터 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067252423/original/oAnRy_lp0f5vbb0euwFqrKkCjtjhZyJK1A.png?1773855045)
3. 사용할 필드를 검색해서 선택해요.

   ![필드 검색 및 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067252494/original/EEEl4VdL2r-4GLQRASjwamcyL-Klf61B8w.png?1773855089)
4. 원하는 세분화 방식에 맞는 연산자를 선택해요.

   ![연산자 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067252536/original/F5dFqWTMIr7py7AkXc9mc6wSkouElO4_ww.png?1773855152)
5. 값을 입력하거나 선택해요.

   ![값 입력 또는 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067252566/original/R3et-b6Kotvl9PZJd20cz8C7cA2gAqr5jw.png?1773855196)
6. **+ Add Nested Filter**(중첩 필터 추가)를 클릭하면 조건을 하나 더 추가할 수 있어요. 연락처가 스마트 리스트에 남으려면 이 조건도 함께 맞아야 해요. **그리고** 조건을 적용하고 싶을 때 사용하세요.

   ![중첩 필터 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067252789/original/yqDPCcGJgG1FdLWyBH6gmqqIc7zJLJq63A.png?1773855412)
7. **+ Add Filter**(필터 추가)를 클릭하면 연락처가 스마트 리스트에 포함될 수 있는 다른 조건을 추가할 수 있어요. **또는** 조건을 적용하고 싶을 때 사용하세요.

   ![필터 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067253135/original/ijwpGiCnf_zydnxJEIR_LHFBx9DHLI3E6g.png?1773855635)
8. **적용**을 클릭해요.

   ![적용 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067253339/original/YYqQ5F1dZ6DxzVb5g7xrujEjb7T16VctUw.png?1773855719)

## 날짜 필터

날짜 필터는 정확한 날짜, 상대적인 기간, 지금을 기준으로 움직이는 기간으로 연락처를 나눌 때 써요. 최근 활동, 앞으로 있을 일정, 반복되는 기념일처럼 날짜와 관련된 대상을 찾을 때 유용해요. 날짜 또는 날짜와 시간 값을 저장하는 필드에 날짜 필터를 쓸 수 있어요.

필터로 쓸 수 있는 날짜 필드 예시는 다음과 같아요.

- **최근 예약**(Last Appointment At)
- **생년월일**
- **Created On**(생성일)
- **최근 활동**(Last Activity On)
- **최근 수정**(Last Updated On)
- **Last Email Clicked Date**(마지막 이메일 클릭일)
- **Last Email Opened Date**(마지막 이메일 열람일)

날짜 연산자는 적용하려는 날짜 조건에 따라 달라져요. 아래에서 연산자를 묶음별로 나누어 설명하니, 표를 보기 전에 각 연산자가 어떤 용도인지 먼저 확인해 보세요.

### 상대 날짜 필터

오늘 날짜를 기준으로 어떤 일이 일어난 시점에 따라 연락처를 보여 줘요.

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Is**(일치) → **오늘** | 마지막 예약이 오늘인 연락처 | 오늘 = 2026년 3월 11일 | 2026년 3월 11일 예약 |
| **Is** → **내일** | 내일 예약이 잡혀 있음 | 오늘 = 2026년 3월 11일 | 2026년 3월 12일 예약 |
| **Is** → **어제** | 어제 예약이 있었음 | 오늘 = 2026년 3월 11일 | 2026년 3월 10일 예약 |
| **Is** → **이번 주** | 이번 주(달력 기준)에 있는 예약 | 주: 2026년 3월 9일~15일 | 2026년 3월 9일~15일 사이 예약 |
| **Is** → **이번 달** | 이번 달에 있는 예약 | 월: 2026년 3월 | 2026년 3월 1일~31일 사이 예약 |
| **Is** → **This Quarter**(이번 분기) | 이번 분기에 있는 예약 | 1분기 = 2026년 1월~3월 | 2026년 1월 1일~3월 31일 사이 예약 |
| **Is** → **올해** | 올해 안에 있는 예약 | 연도 = 2026년 | 2026년 1월 1일~12월 31일 사이 예약 |

### 정확한 날짜 필터

특정 날짜나 날짜 범위를 직접 지정해서 연락처를 찾아요.

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Is** → **날짜** | 특정 날짜의 예약 | 2026년 3월 5일 | 정확히 2026년 3월 5일 예약 |
| **Is** → **사이** | 날짜 범위 안의 예약 | 2026년 3월 1일~7일 | 2026년 3월 1일~7일 사이 예약 |

### 시간 차이 필터 (상대 기간)

오늘부터 지나간 시간 또는 앞으로 남은 시간을 기준으로 연락처를 찾아요.

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Is** → **More Than**(초과) | 지정한 기간보다 오래 전에 예약이 있었음 | 7일보다 더 전 | 3월 4일 이전 예약 |
| **Is** → **Less Than**(미만) | 지정한 기간 안에 예약이 있었음 | 7일 이내 | 2026년 3월 4일~11일 사이 예약 |
| **Is** → **In the Next**(앞으로 기간 내) | 앞으로 지정한 기간 안에 예약이 잡혀 있음 | 앞으로 3일 | 2026년 3월 11일~14일 사이 예약 |
| **Is** → **In the Last**(지난 기간 내) | 지난 지정 기간 안에 예약이 있었음 | 지난 3일 | 2026년 3월 8일~11일 사이 예약 |

### 날짜 비교 필터

기준이 되는 고정 날짜와 비교해서 연락처를 찾아요.

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Is** → **After Date**(날짜 이후) | 선택한 날짜 이후의 예약 | 2026년 3월 5일 이후 | 2026년 3월 6일부터의 예약 |
| **Is** → **Before Date**(날짜 이전) | 선택한 날짜 이전의 예약 | 2026년 3월 5일 이전 | 2026년 3월 4일 또는 그 이전 예약 |

### 제외 필터 (Is Not)

날짜 조건에 해당하는 연락처를 제외해요. 각 일반 필터의 반대 조건이에요.

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Is Not**(제외) → **오늘** | 오늘 있는 예약 제외 | 오늘 = 2026년 3월 11일 | 2026년 3월 11일을 제외한 모든 예약 |
| **Is Not** → **어제** | 어제 있었던 예약 제외 | 어제 = 2026년 3월 10일 | 2026년 3월 10일을 제외한 모든 예약 |
| **Is Not** → **이번 주** | 이번 주에 있는 예약 제외 | 주: 2026년 3월 9일~15일 | 이 범위 밖의 모든 예약 |
| **Is Not** → **날짜** | 특정 날짜 제외 | 2026년 3월 5일 제외 | 2026년 3월 5일을 제외한 모든 날짜 |
| **Is Not** → **사이** | 날짜 범위 제외 | 2026년 3월 1일~7일 제외 | 2026년 3월 1일 이전 또는 3월 7일 이후 날짜 |
| **Is Not** → **내일** | 내일을 제외한 모든 날짜 | 2026년 3월 12일 | 마지막 예약이 내일로 잡혀 있지 않은 모든 연락처 |
| **Is Not** → **이번 달** | 2026년 3월이 아닌 모든 달 | 3월 1일 이전 또는 3월 31일 이후 | 마지막 예약이 다른 달에 있었던 연락처 |
| **Is Not** → **This Quarter** | 이번 분기(2026년 1분기) 밖 | 1월 1일 이전 또는 3월 31일 이후 | 마지막 예약이 2026년 1분기 밖에 있는 연락처 |
| **Is Not** → **올해** | 2026년이 아님 | 1월 1일 이전 또는 12월 31일 이후 | 마지막 예약이 2026년이 아니었던 연락처 |
| **Is Not** → **More Than ... Ago**(~보다 오래 전) | 30일보다 오래 전이 아닌 예약 | 2026년 2월 9일 또는 그 이후 | 최근 30일 이내에 예약이 있었음 |
| **Is Not** → **After Date** | 선택한 날짜 당일 또는 그 이전 | 2026년 3월 1일 또는 그 이전 | **After Date**의 반대 |
| **Is Not** → **Less Than ... Ago**(~보다 최근) | 최근 7일 이내가 아님 | 2026년 3월 4일 또는 그 이전 | 마지막 예약이 7일 이상 전임 |
| **Is Not** → **Before Date** | 선택한 날짜 당일 또는 그 이후 | 2026년 1월 1일 또는 그 이후 | **Before Date**의 반대 |
| **Is Not** → **In the Next ...**(앞으로 ~ 이내) | 앞으로 7일 이내가 아님 | 2026년 3월 11일~18일 이내 아님 | 지난 예약과, 7일 범위를 넘어선 앞으로의 예약 |
| **Is Not** → **In the Last ...**(지난 ~ 이내) | 지난 14일 이내가 아님 | 2026년 2월 25일 이전 또는 3월 11일 이후 | 최근에 예약이 없었던 연락처 |

### 비어 있음 / 비어 있지 않음 필터

예약 기록이 있는 연락처와 없는 연락처를 구분해요.

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Is Empty**(**비어 있음**) | 예약 기록이 한 번도 없는 연락처 | - | 예약 이력이 없는 연락처 |
| **Is Not Empty**(**비어 있지 않음**) | 예약이 한 건 이상 있는 연락처 | - | 예약 기록이 하나라도 있는 연락처 |

### 날짜 필터 활용 팁

- 최근 참여한 연락처를 찾을 때는 **In the Last**를 쓰세요.
- 활동이 없는 연락처를 찾을 때는 **More Than**을 쓰세요.
- 과거 기록을 조회할 때는 **사이**를 쓰세요.
- 예약이 없는 리드를 찾을 때는 **비어 있음**을 쓰세요.

## 수신거부 필터

수신거부(DND, Do Not Disturb) 필터는 연락처에 커뮤니케이션 제한이 켜져 있는지 확인할 때 써요. 규정에 맞는 발송 리스트를 만들거나, 특정 채널에서 메시지를 받으면 안 되는 연락처를 제외할 때 특히 유용해요. 연락처의 커뮤니케이션 선호도와 관련된 예/아니요 값을 저장하는 필드에 수신거부 필터를 쓸 수 있어요.

필터로 쓸 수 있는 수신거부 및 예/아니요 필드 예시는 다음과 같아요.

- **DND all**(전체 수신거부)
- **SMS DND**(SMS 수신거부)
- **Email DND**(이메일 수신거부)
- **Calls & Voicemails DND**(통화 및 음성메일 수신거부)
- **WhatsApp 수신거부**
- **Inbound DND**(인바운드 수신거부)
- **FB Messenger DND**(Facebook Messenger 수신거부)
- **GMB Messenger DND**(Google 비즈니스 프로필 Messenger 수신거부)

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Enabled**(활성화) | 연락처에 수신거부가 켜져 있음 | - | 선택한 채널에서 수신을 거부한 연락처 |
| **Disabled**(비활성화) | 연락처에 수신거부가 켜져 있지 않음 | - | 선택한 채널에서 수신을 거부하지 않은 연락처 |

## 문자열 필터

문자열 필터는 이름, 레이블, ID, 어트리뷰션 값, 연락 정보 등 텍스트 기반 정보로 연락처를 찾을 때 써요. 정확히 일치하는 값, 일부만 일치하는 값, 드롭다운에서 고른 값, 쉼표로 구분한 목록, 비어 있는 필드를 찾을 때 유용해요.

문자열 필드는 종류에 따라 값을 입력하는 방식이 달라요. 어떤 필드는 값을 직접 입력하는 자유 입력 방식이고, 어떤 필드는 드롭다운이나 선택값 방식이라 제공되는 옵션 중에서 골라요. 쉼표로 구분한 여러 값을 쓸 수 있는 필드도 있고, 값을 하나만 선택할 수 있는 필드도 있어요. 선택한 필드에 어떤 연산자가 보이지 않으면 그 필드에서는 해당 연산자를 쓸 수 없어요.

필터로 쓸 수 있는 문자열 필드 예시는 다음과 같아요.

- **First name**(이름)
- **Last name**(성)
- **이메일 주소**
- **Address**(주소)
- **Timezone**(시간대)
- **최근 업데이트한 사람**
- **기회 파이프라인**
- **이메일 상태**
- **태그**

{% hint style="info" %}
새로 만든 커스텀 필드는 유형에 따라 다음 기준을 따라요.
1. **Single line**(한 줄), **Multi line text**(여러 줄 텍스트): 연락처 점수 기준을 따라요.
2. **Text Box list**(텍스트 상자 목록): 시간대(Time Zone) 기준을 따라요.
3. **Drop Down Single**(드롭다운 단일 선택), **Drop Down Multiple**(드롭다운 다중 선택), **Radio Button**(라디오 버튼), **Checkbox**(체크박스): 태그 기준을 따라요.
{% endhint %}

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Is**(일치) | 선택한 값 하나와 일치 | 시카고 | 시카고에 있는 연락처 |
| **Is Not**(제외) | 선택한 값 하나를 제외 | 시카고 | 시카고에 있지 않은 연락처 |
| **Contains**(포함) | 필드 값 어디에든 해당 텍스트가 들어 있는 경우 | 뉴욕 | 도시에 "뉴욕"이 들어간 연락처(예: 뉴욕시) |
| **Does Not Contain**(포함하지 않음) | 필드 값 어디에도 해당 텍스트가 들어 있지 않은 경우 | 뉴욕 | 도시에 "뉴욕"이 들어 있지 않은 연락처(예: 뉴욕시 제외) |
| **Is any of (comma separated)**(쉼표로 구분한 값 중 하나) | 나열한 값 중 하나 이상과 일치 | 시카고, 런던, 뉴욕시 | 시카고, 런던 또는 뉴욕시에 있는 연락처 |
| **Is None of (comma separated)**(쉼표로 구분한 값 중 해당 없음) | 쉼표로 구분한 목록의 모든 값을 제외 | 시카고, 런던, 뉴욕시 | 시카고, 런던, 뉴욕시 어디에도 있지 않은 연락처 |
| **비어 있음** | 필드에 저장된 값이 없는 연락처를 찾음 | - | 도시가 입력되지 않은 연락처 |
| **비어 있지 않음** | 필드에 값이 들어 있는 연락처를 찾음 | - | 도시가 입력된 모든 연락처 |

## 숫자 필터

숫자 필터는 점수, 횟수 등 측정할 수 있는 값으로 연락처를 나눌 때 써요. 값끼리 비교하거나, 범위나 기준값을 정하거나, 필드에 숫자 값이 있는지 확인할 때 유용해요. 측정 가능한 숫자 값을 저장하는 필드에 숫자 필터를 쓸 수 있어요.

필터로 쓸 수 있는 숫자 필드 예시는 다음과 같아요.

- **참여 점수**
- 퀴즈 점수(**커스텀 필드**)

{% hint style="info" %}
새로 만든 커스텀 필드는 유형에 따라 다음 기준을 따라요.
1. **Number**(숫자): 참여 점수 기준을 따라요.
2. **Phone**(전화): 전화번호 기준을 따라요.
3. **Monetary**(금액): 참여 점수 기준을 따라요.
{% endhint %}

| 필터 설정 | 의미 | 입력 예시 | 해당하는 연락처 |
| --- | --- | --- | --- |
| **Equal To**(같음) | 선택한 숫자 하나와 일치 | 100 | 100점을 받은 연락처 |
| **Does Not Equal**(같지 않음) | 선택한 숫자 하나를 제외 | 100 | 100점을 받지 않은 연락처 |
| **사이** | 숫자 범위와 일치 | 90 - 100 | 90점에서 100점 사이의 연락처 |
| **Greater Than**(초과) | 기준값보다 큰 값 | 90 | 90점을 넘은 연락처 |
| **Greater Than or Equal To**(이상) | 기준값 이상인 값 | 90 | 90점 이상인 연락처 |
| **Less Than**(미만) | 기준값보다 작은 값 | 90 | 90점 미만인 연락처 |
| **Less Than or Equal To**(이하) | 기준값 이하인 값 | 90 | 90점 이하인 연락처 |
| **비어 있음** | 필드에 값이 없는 연락처를 찾음 | - | 퀴즈를 완료하지 않은 연락처 |
| **비어 있지 않음** | 필드에 값이 있는 연락처를 찾음 | - | 퀴즈를 완료한 연락처 |

## 자주 묻는 질문

### 모든 필드가 같은 연산자를 지원하나요?

아니요. 선택한 필드에 따라 쓸 수 있는 연산자가 달라요.

### 필터를 한 번에 여러 개 쓸 수 있나요?

네. 여러 필터를 적용해서 스마트 리스트 결과를 더 좁힐 수 있어요.

### 기회 정보로 연락처를 필터링할 수 있나요?

네. 기회 관련 필터로 파이프라인, 단계, 상태에 따라 연락처를 나눌 수 있어요.

### 스마트 리스트에 대해 더 알아보려면 어디를 보면 되나요?

"스마트 리스트 만들고 관리하기" 문서에서 스마트 리스트의 전체 개요와 작동 방식을 확인할 수 있어요.
