# 사용자 지정 레이블로 연락처 연관 설정하기

하이퍼클래스의 연락처 연관을 쓰면 서로 관련된 연락처와 다른 CRM 레코드를 사용자 지정 레이블로 연결할 수 있어요. 배우자, 관리자, 직원, 구매자, 판매자처럼 관계를 표시할 수도 있고, 사용자 지정 객체와 연결된 연락처도 정리할 수 있어요. 연관 레이블은 워크플로우 자동화와 관계별 연결 개수 제한에도 쓸 수 있어요.

이 문서에서는 연관을 만들고, 단일 레이블과 레이블 쌍 중 하나를 고르고, 레코드를 연결하거나 해제하고, 연결 개수 제한을 설정하고, 지원되는 워크플로우에서 연관을 쓰는 방법을 안내해요.

## 연락처 연관이란?

연락처 연관은 CRM 레코드 사이에 구조화된 관계를 만들어 줘요. 관련된 연락처나 오브젝트를 따로 두지 않고 연결한 뒤, 레이블로 두 레코드가 어떤 관계인지 표시해요.

자주 쓰는 예시는 다음과 같아요.

- 배우자
- 동료
- 부모와 자녀
- 관리자와 직원
- 구매자와 판매자

연락처는 지원되는 사용자 지정 객체와도 연결할 수 있어요. 그래서 사람과 부동산, 차량, 보험 증권, 프로젝트처럼 비즈니스에 맞는 레코드를 이어 줄 수 있어요.

### 연관 레이블의 종류

연관 레이블은 연결된 레코드 사이의 관계를 나타내요. 양쪽이 같은 관계 이름을 쓸지, 서로 다른 역할 이름을 쓸지에 따라 종류가 나뉘어요.

- **Single Label**(단일 레이블): 양쪽에 같은 레이블을 써요. 예를 들면 동료예요.
- **Pair of Labels**(레이블 쌍): 양쪽에 서로 다른 레이블을 써요. 예를 들면 관리자 ↔ 직원이에요.

## 연락처 연관의 장점

연관을 쓰면 연결된 CRM 데이터를 정리하면서 레코드 사이의 업무 맥락도 남길 수 있어요.

- 관련 레코드 정리: 가족, 업무, 소유 관계 등을 CRM 안에서 연결해 둘 수 있어요.
- 관계 맥락 추가: 사용자 지정 레이블로 한 레코드가 다른 레코드와 어떤 관계인지 나타낼 수 있어요.
- 연락처와 사용자 지정 객체 연결: 연락처를 부동산, 차량, 프로젝트, 보험 증권 같은 레코드와 연결할 수 있어요.
- 자동화 지원: 연락처, 회사, 사용자 지정 객체에 걸쳐 동작하는 워크플로우에서 연관 레이블을 쓸 수 있어요.
- 관계 규모 관리: 제한을 설정해서 정해 둔 관계 규칙을 넘어 레코드가 연결되지 않게 할 수 있어요.

## 사전 준비와 제한 사항

레코드를 연결하거나 자동화에서 연관을 쓰기 전에, 팀에 필요한 레코드, 오브젝트, 연관 정의를 먼저 만들어 두세요.

- 연관 정의는 서브 계정의 **설정 > 오브젝트** 화면에서 관리해요.
- 연락처와 연락처 사이의 연관은 단일 레이블과 레이블 쌍을 모두 지원해요.
- 연락처는 지원되는 사용자 지정 객체나 사용할 수 있는 다른 CRM 오브젝트와 연결할 수 있어요.
- 선택할 수 있는 관계 유형은 연결하는 오브젝트와 레이블 설정에 따라 달라요.
- 설정한 연결 개수 제한은 레이블마다 적용돼요.
- 연관된 레코드를 대상으로 하는 워크플로우 액션은 해당 레코드와 연관이 이미 있어야 해요. 액션이 직접 연관을 만드는 경우는 예외예요.

## 연락처 연관을 확인하는 곳

연관 정의와 개별 연결 레코드는 서로 다른 곳에서 관리해요. 그래서 관계 규칙과 실제 레코드 연결을 따로 관리할 수 있어요.

- 연락처 레코드: 연락처를 열고 **연관** 또는 **Related Objects**(관련 오브젝트) 영역에서 연결된 레코드를 확인하고 관리해요.
- 오브젝트 설정: **설정 > 오브젝트**에서 연관 정의, 레이블, 관계 규칙을 만들고 관리해요.

![관련 오브젝트와 연관 영역이 보이는 연락처 레코드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042764672/original/JuQM4tlAWGX9Qg0L-DdsNiWVuJR1aIIVJg.png?1741255325=)

## 연락처 연관 설정하기

레코드를 연결하기 전에 연관 정의를 먼저 만들어요. 연관 정의에는 어떤 오브젝트끼리 연결할 수 있는지, 관계를 나타내는 레이블이 무엇인지, 연결 개수 제한이 어떻게 되는지가 들어가요.

### 1단계: 연락처 오브젝트 설정 열기

1. 해당 서브 계정을 열어요.
2. **설정 > 오브젝트**로 이동해요.
3. **연락처**를 찾아요.
4. 연락처 오브젝트 설정을 열고 **연관**을 선택해요.

![연락처 오브젝트가 보이는 설정 오브젝트 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042764435/original/icaJSGWvD4zLfPCra5H2p_QaMAz38Igvyw.png?1741255187=)

### 2단계: 연관 만들기

**Create Association**(연관 만들기)을 클릭해 새 관계를 정의해요.

![Create Association 버튼이 보이는 연관 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042764456/original/VYaJ46n1_FIxelROYwCJ47GWdG88V8Aw-A.png?1741255210=)

### 3단계: 연결된 오브젝트 선택

**연결된 오브젝트**에서 연락처와 연결할 레코드 종류를 선택해요. CRM 설정에 따라 다음과 같은 항목을 고를 수 있어요.

- 다른 연락처
- 회사
- 기회
- 사용할 수 있는 사용자 지정 객체

### 4단계: 레이블 유형 선택

관계를 가장 잘 나타내는 레이블 구조를 골라요.

- **Single Label**: 양쪽이 같은 관계 이름을 써야 할 때 선택해요. 예를 들면 동료예요.
- **Pair of Labels**: 양쪽이 서로 다른 관계 이름이 필요할 때 선택해요. 예를 들면 관리자 ↔ 직원이에요.

### 5단계: 관계 설정

**Configure Relationship**(관계 설정)에서 사용 목적에 맞는 관계 유형과 제한을 선택해요.

레이블 쌍과 지원되는 다중 레이블 관계에서는 다음 유형을 쓸 수 있어요.

- **One-to-One**(일대일)
- **One-to-N**(일대 N)
- **One-to-Many**(일대다)
- **N-to-Many**(N대다)
- **Many-to-Many**(다대다)

연락처와 연락처 사이의 단일 레이블 연관에서는 **One-to-One**, **Many-to-Many**, 그리고 설정할 수 있는 **N-to-N**(N대 N) 관계를 쓸 수 있어요.

{% hint style="info" %}
저장하기 전에 **미리보기**에서 관계를 확인하세요. 양쪽 레코드가 각각 몇 개까지 연결될 수 있는지 볼 수 있어요.
{% endhint %}

### 6단계: 연관 저장

연결된 오브젝트, 레이블, 관계 유형, 제한을 확인한 뒤 **저장**을 클릭해요. 이제 해당 레코드를 연결할 때 이 연관을 쓸 수 있어요.

## 연관으로 연락처 연결하기

연관 정의가 만들어졌다면 연락처 레코드에서 개별 레코드를 연결해요. 그러면 사용자가 CRM에서 관계를 바로 확인할 수 있어요.

1. **연락처**로 이동해 관리할 연락처를 열어요.
2. **연관** 또는 **Related Objects** 영역을 열어요.
3. 연결할 오브젝트 옆의 **추가**를 클릭해요.
4. 연결할 레코드를 검색해서 선택해요.
5. 알맞은 연관 레이블을 선택해요.
6. 연관을 확인해요.

![연락처 레코드에서 연관 레코드를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042766212/original/tYwGsSppQbUaxBLCknQ2qWxpUYzxxnWbNA.gif?1741256064=)

연결한 레코드는 연락처의 **연관** 또는 **Related Objects** 영역에 나타나요. 레이블 쌍을 쓴 관계에서는 상대 레코드에 짝이 되는 레이블이 표시돼요.

## 연관 관리하기

연관 정의는 관계 규칙을 정하고, 개별 레코드 연관은 실제로 어떤 레코드가 연결되는지를 정해요.

### 연관 정의 편집하기

1. **설정 > 오브젝트**로 이동해요.
2. 해당 오브젝트를 열어요.
3. **연관**을 선택해요.
4. 편집할 연관을 찾아요.
5. 점 세 개 아이콘(⋮)을 열어요.
6. 수정할 수 있는 설정을 편집해요.
7. **저장**을 클릭해요.

![연관 목록에서 점 세 개 메뉴가 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081375232/original/O5cIugis-SzJZVYn07-kAksfacmUfoRbkA.png?1789877213)

### 레코드 사이의 연관 해제하기

1. 해당 연락처나 오브젝트 레코드를 열어요.
2. **연관** 또는 **Related Objects** 영역을 열어요.
3. 연결된 레코드를 찾아요.
4. 연관을 해제하는 옵션을 선택해요.
5. 변경을 확인해요.

![연락처 레코드에서 연관을 해제하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042765305/original/2faMy4o40dghTlB4DnCg0DtRQgSPU_BUkg.gif?1741255625=)

{% hint style="warning" %}
연관을 해제하면 레코드 사이의 관계만 사라져요. 연락처나 오브젝트 레코드는 삭제되지 않아요.
{% endhint %}

## 연관 연결 개수 제한 설정하기

연결 개수 제한은 특정 레이블로 연결할 수 있는 레코드 수를 정해요. 제한을 두면 레코드가 지나치게 많이 연결되는 것을 막고, 비즈니스 규칙에 맞게 CRM 관계를 유지할 수 있어요.

1. 해당 서브 계정을 열어요.
2. **설정 > 오브젝트**로 이동해요.
3. **연락처** 또는 해당 사용자 지정 객체를 찾아요.
4. 오브젝트를 열고 **연관**을 선택해요.
5. 새 연관을 만들거나 기존 연관을 편집해요.
6. **Single Label** 또는 **Pair of Labels**를 선택해요.
7. **Configure Relationship**에서 관계 유형을 선택해요.
8. 적용할 제한을 정해요.
9. **미리보기** 영역에서 관계를 확인해요.
10. **저장**을 클릭해요.

제한에 도달하면 설정한 제한을 넘어서는 레코드는 더 연결되지 않고, 하이퍼클래스가 경고를 표시해요.

## 워크플로우에서 연관 사용하기

지원되는 워크플로우 액션은 이미 만들어 둔 연관 레이블을 사용해서 연락처, 회사, 사용자 지정 객체에 걸쳐 연관된 레코드를 등록하거나 제거하거나 자동으로 연결할 수 있어요. 워크플로우 빌더 화면은 영어로 표시돼요.

### 연관된 레코드를 다른 워크플로우에 추가하기

트리거 레코드와 연결된 레코드를 다른 워크플로우에 자동으로 들어가게 하려면 **Add Associated Records to Workflow**(연관된 레코드를 워크플로우에 추가)를 사용해요.

1. **자동화 > 워크플로우**로 이동해요.
2. 기존 워크플로우를 열거나 새로 만들어요.
3. **+** 아이콘을 클릭해 액션을 추가해요.
4. **Add Associated Records to Workflow**를 선택해요.
5. 연관된 오브젝트 유형을 선택해요.
6. 필요하면 해당하는 **Association Label**(연관 레이블)을 선택해요.
7. 연관된 레코드를 등록할 워크플로우를 선택해요.
8. 액션을 저장해요.

![오브젝트, 연관 레이블, 워크플로우 필드가 보이는 Add Associated Records to Workflow 액션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054809211/original/AsJo3DMQEwM_1N24PA3G-AYtaD1Dyxju5g.png?1759143523=)

### 워크플로우에서 연관된 레코드 제거하기

관련 레코드가 다른 자동화에 더 이상 참여하지 않게 하려면 **Remove Associated Records from Workflow**(워크플로우에서 연관된 레코드 제거)를 사용해요.

1. **Remove Associated Records from Workflow** 액션을 추가해요.
2. 연관된 오브젝트 유형을 선택해요.
3. 필요하면 해당하는 **Association Label**을 선택해요.
4. 레코드를 제거할 워크플로우를 선택해요.
5. 액션을 저장해요.

![Remove Associated Records from Workflow 액션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054812396/original/5fxj8Jwe5eWzFilNjCjFCjgaPgYdH7KDig.png?1759145373=)

### 레코드를 자동으로 연관 짓기

**Associate Records**(레코드 연결) 워크플로우 액션은 설정한 필터로 조건에 맞는 레코드를 찾고, 이미 만들어 둔 연관 레이블로 자동으로 연관을 만들어 줘요.

{% hint style="info" %}
**베타**: Associate Records는 현재 실험실 기능으로 제공돼요. 사용하기 전에 **설정 > 실험실**로 이동해서 **Associate Records - Workflow Action**(레코드 연결 - 워크플로우 액션)을 켜세요.
{% endhint %}

![Associate Records 액션이 보이는 워크플로우 빌더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077507058/original/vs-r6KzVQfT0SpaPnk8kdqGjhTfWzCaroQ.png?1785772549=)

매칭 필터, 매칭 방식, 자동 레코드 연결을 자세히 설정하려면 "Workflow Action: Associate Records" 문서를 참고하세요.

## 자주 묻는 질문

### 단일 레이블과 레이블 쌍은 뭐가 다른가요?
**Single Label**은 두 레코드에 같은 관계 이름을 써요. **Pair of Labels**는 관리자와 직원처럼 양쪽에 서로 다른 역할을 지정해요.

### 연락처 연관을 워크플로우에서 쓸 수 있나요?
네. 지원되는 워크플로우 액션으로 연관된 연락처, 회사, 사용자 지정 객체 레코드를 다른 워크플로우에 추가하거나 제거할 수 있어요. **Associate Records** 액션으로 지원되는 연관을 자동으로 만들 수도 있어요.

### 연락처를 사용자 지정 객체와 연결할 수 있나요?
네. 부동산, 차량, 보험 증권, 프로젝트처럼 지원되는 사용자 지정 객체나 비즈니스에 맞게 설정한 다른 오브젝트와 연결할 수 있어요.

### 연결할 수 있는 레코드 수를 제한할 수 있나요?
네. 연결 개수 제한으로 지원되는 관계 유형을 설정하고, 연관 레이블별로 제한을 적용할 수 있어요.

### 연결 개수 제한에 도달하면 어떻게 되나요?
설정한 제한을 넘어서는 레코드는 더 연결되지 않고, 하이퍼클래스가 경고를 표시해요.

### 연관을 해제하면 연락처나 오브젝트도 삭제되나요?
아니요. 연관을 해제하면 레코드 사이의 관계만 사라져요. 각 레코드는 CRM에 그대로 남아 있어요.

### 연관 레이블은 어디에서 관리하나요?
**설정 > 오브젝트**로 이동해서 해당 오브젝트를 열고 **연관**을 선택하세요.

### 연관을 자동으로 만들 수 있나요?
네. 지원되는 **Associate Records** 워크플로우 액션이 조건에 맞는 레코드를 찾아서 이미 만들어 둔 연관 레이블로 연관을 만들어 줘요. 이 액션은 현재 실험실에서 베타 기능으로 제공돼요.
