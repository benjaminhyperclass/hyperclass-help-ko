# 회사 도메인 이름 필드와 중복 방지

회사 하나에는 acme.com 같은 웹 도메인을 하나 넣을 수 있어요. 이 도메인 덕분에 비즈니스 하나당 회사 레코드를 하나만 유지할 수 있고, 새 연락처가 어느 회사에 속하는지 찾을 때도 이 도메인을 확인해요.

## 도메인 이름 필드는 어디에 쓰나요?

도메인 이름 필드는 두 가지 기능에 쓰여요.

- **중복 방지**: 중복 방지를 켜면, 서브 계정 안에서 같은 도메인을 가진 회사는 하나만 있을 수 있어요.
- **매칭**: 업무용 이메일을 가진 연락처가 들어오면, 소속 회사를 찾기 위해 그 이메일의 도메인을 가장 먼저 확인해요.

도메인이 없는 회사도 평소처럼 쓸 수 있어요. 다만 중복 방지가 적용되지 않고, 도메인을 추가하기 전에는 도메인으로 연락처와 매칭되지도 않아요.

이 필드는 세 곳에서 볼 수 있어요.

- 회사 레코드의 **Company Info**(회사 정보) 아래 **도메인 이름**
- 회사 목록의 열
- 가져오기, 스마트 리스트, API에서는 `companylogo` 옆에 `domainname`으로 표시돼요.

## 회사에 도메인 추가하기

1. 회사 레코드를 엽니다.
2. **Company Info** 아래 **도메인 이름**에 도메인을 입력합니다.
3. **저장**을 선택합니다.

도메인만 입력하세요. https://www.acme.com 이 아니라 acme.com 으로 쓰고, 이메일 주소는 넣지 않아요.

도메인은 다른 두 가지 방식으로도 자동으로 들어와요. 연락처의 이메일 도메인으로 회사를 만들 때, 또는 도메인이 없던 회사에 도메인을 추가할 때 시스템이 도메인을 저장해요. 이미 있는 회사에는 아래 설명처럼 한꺼번에 추가할 수도 있어요.

{% hint style="info" %}
직접 입력한 도메인은 매칭이나 다른 어떤 방식으로도 덮어쓰이지 않아요.
{% endhint %}

## 도메인당 회사 하나만 유지하기

**설정 > 오브젝트 > 회사**로 이동한 다음, **자동화** 아래에서 **Automatically prevent duplicate companies**(회사 중복 자동 방지)를 켜세요.

- **켬(권장)**: 도메인 하나당 회사 하나만 있을 수 있어요. 이미 쓰고 있는 도메인은 다른 회사가 가져갈 수 없어서, 매칭 결과가 항상 정확히 한 회사로 정해져요.
- **끔**: 여러 회사가 같은 도메인을 가질 수 있어요. 매칭은 똑같이 작동하지만, 고를 수 있는 회사가 둘 이상이 돼요.

![회사 중복 자동 방지 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081662490/original/Ram4oOqQjP_59DYDGTEO5NoW75mVD_dALw.png?1790168251)

**끔**으로 바꾸면 경고가 나타나요. 변경 내용은 기록되어 나중에 추적할 수 있어요.

{% hint style="info" %}
이 설정은 앞으로 도메인이 중복되는 것을 막아 줄 뿐이에요. 이미 있는 회사 레코드를 합치지는 않아요. 같은 비즈니스의 레코드가 이미 둘 있다면, 직접 정리하기 전까지는 따로 남아 있어요.
{% endhint %}

매칭은 정확히 일치할 때만 이루어져요. 그래서 acme.com 과 mail.acme.com 은 서로 다른 도메인으로 봐요.

## 이미 있는 회사에 도메인 채우기

도메인 매칭을 쓰기 전에 만든 회사에는 보통 도메인이 없어요. 도메인이 채워지기 전에는 도메인으로 연락처를 매칭할 수 없고, 중복 방지도 적용되지 않아요.

**Create companies from contact's email domain**(연락처 이메일 도메인으로 회사 만들기)을 켜면 **Fill in domains for existing companies**(기존 회사에 도메인 채우기)를 사용할 수 있어요. 이 기능은 이미 있는 회사를 차례로 살펴보면서, 안전하게 넣을 수 있는 곳에 도메인을 추가해요. 각 회사의 웹사이트를 기준으로 하고, 웹사이트가 없으면 회사 이름으로 도메인을 찾아봐요.

![기존 회사에 도메인 채우기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081662561/original/d6nUlI-8yz-fnJylH2mTpMBYUfyHtUVGVQ.png?1790168286)

**건너뛰는 경우**

- 직접 입력한 도메인: 절대 바꾸지 않아요.
- 무료 이메일 서비스: 예를 들어 웹사이트 필드에 gmail.com 이 들어 있는 회사가 해당돼요.
- 소셜 및 웹사이트 빌더 주소: Facebook, LinkedIn, Wix, Squarespace, Linktree 같은 주소는 건너뛰어요. 관련 없는 회사들이 모두 같은 주소를 갖게 되는 일을 막기 위해서예요.
- 도메인이 아닌 값: 웹사이트 필드에 전화번호를 입력한 경우 등이에요.
- 결과적으로 도메인이 겹치게 되는 회사: 여러 회사가 같은 웹사이트를 가리키면 그중 어느 회사도 업데이트하지 않아요. 어느 회사가 도메인을 가져야 할지 직접 정할 수 있어요.

예를 들어 지점 레코드 네 개가 모두 본사 웹사이트를 적어 두었다고 해 볼게요. 먼저 만들어진 레코드에 도메인을 주지 않고, 네 개 모두 그대로 두어 직접 정리할 수 있게 해요.

이 작업은 백그라운드에서 실행되고, 걸리는 시간은 회사 수에 따라 달라져요. 실행되는 동안에도 다른 작업을 계속할 수 있어요. 기존 연락처에도 매칭을 적용하도록 선택했다면 도메인을 먼저 채우기 때문에, 연락처가 이미 있는 회사에 연결돼요.

{% hint style="info" %}
이 작업은 워크플로우, 웹훅, 연동을 실행시키지 않아요. 평소처럼 만들거나 수정한 회사에 대해서는 자동화가 그대로 실행돼요.
{% endhint %}

나중에 추가하는 회사는 연락처가 매칭될 때 도메인이 들어가요. 레코드에서 직접 입력해도 돼요.

## 알아 두세요

- 도메인 매칭은 정확히 일치할 때만 이루어져요. 서브도메인은 같은 도메인으로 보지 않아요.
- 회사 하나에는 도메인을 하나만 넣을 수 있어요. 비즈니스가 도메인을 여러 개 쓴다면 주 도메인을 레코드에 두고, 나머지는 직접 관리하세요.
- 중복 방지는 이미 있는 회사를 합치지 않아요.
- 도메인 채우기는 되돌릴 수 없어요. 직접 입력한 도메인은 덮어쓰지 않아요.

## 자주 묻는 질문

### 도메인은 어떤 형식으로 입력해야 하나요?

acme.com 처럼 도메인만 입력하세요. https://, www, 경로는 빼고, 이메일 주소도 넣지 마세요.

### 두 회사가 같은 도메인을 가질 수 있나요?

중복 방지를 **끔**으로 바꿀 때만 가능해요. 이렇게 하면 매칭할 때 고를 수 있는 회사가 둘 이상이 되므로 권장하지 않아요.

### 중복 방지를 켜면 이미 있는 회사가 합쳐지나요?

아니요. 새로 생기는 중복 도메인만 막아요. 이미 있는 중복은 직접 정리해야 해요.

### 서브도메인도 주 도메인과 매칭되나요?

아니요. 매칭은 정확히 일치할 때만 이루어져서, acme.com 과 mail.acme.com 은 다른 도메인이에요.

### 도메인 채우기를 하면 직접 입력한 도메인이 덮어쓰이나요?

절대 덮어쓰지 않아요.
