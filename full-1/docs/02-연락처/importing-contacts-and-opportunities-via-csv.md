# CSV 파일로 연락처와 기회 가져오기

CSV 파일을 사용하면 연락처와 기회를 한꺼번에 가져올 수 있어요. 필드를 매핑하고, 새 레코드를 만들거나 기존 레코드를 업데이트하고, 진행 상황까지 확인할 수 있어요. 이 문서에서는 CSV 파일을 준비하는 단계부터 가져오기 진행 상황 확인, 오류 해결까지 차례대로 안내해요.

연락처만 가져오는 방법은 [연락처 가져오기](importing-contacts-using-a-csv-file.md) 문서에서도 볼 수 있어요.

## 가져오기 전에 확인할 것

가져오기를 시작하기 전에 아래 조건을 확인하세요.

- 사용자 권한: 관리자 권한이 있는 사용자만 연락처를 가져올 수 있어요.
- 파일 형식: 파일은 CSV(.csv) 형식이어야 해요.
- 파일 크기: CSV 파일은 30MB 미만이어야 해요. 더 크면 여러 개의 작은 파일로 나누세요.
- 시트 수: CSV 파일에는 시트(탭)가 하나만 있어야 해요.
- CSV 형식: 첫 번째 행을 비워 두면 안 돼요. 첫 행에는 헤더(열 이름)를 넣고, 열 이름 중 하나 이상은 시스템의 필드와 맞아야 해요.

## 흔한 실수

❌ 헤더가 맞지 않음: CSV의 헤더가 시스템 필드와 일치하는지 확인하세요.

❌ 필수 필드가 비어 있음: 모든 행에 필수 필드(이름, 이메일, 전화번호) 중 하나 이상이 있어야 해요.

❌ 전화번호에 특수 문자 사용: 공백, 대시(-), 문자는 지우세요.

❌ CSV 안에 중복된 레코드: 가져오기 전에 목록을 정리하세요.

## 연락처와 기회 가져오기

가져오기 기능은 두 곳에서 시작할 수 있어요.

1. **연락처** 메뉴에서 시작하기
   - 왼쪽 메뉴에서 **연락처**를 선택하고 **스마트 리스트** 탭을 연 다음 **Import Contacts**(연락처 가져오기) 버튼을 클릭하세요.

     ![연락처 메뉴의 스마트 리스트 탭에서 연락처 가져오기 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081121499/original/u8qJivlF2Yo7bM49FnUhzFYeTN30qPkJWA.png?1789586517)
2. **기회 관리**(Opportunities) 메뉴에서 시작하기
   - 왼쪽 메뉴에서 **기회 관리**를 선택하고 오른쪽 위의 **가져오기** 버튼을 클릭하세요.

     ![기회 관리 화면 오른쪽 위의 가져오기 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081120771/original/bcBfw6z_jM4csEn2r36WA7VXpGfgMOLEYw.png?1789585038)

1. 연락처

### CSV 파일 업로드

1단계: 연락처, 기회, 또는 둘 다를 선택한 뒤 **다음**을 클릭하세요. 이어서 **Upload File**(파일 업로드)을 클릭하고 컴퓨터에서 CSV 파일을 선택하세요.

![CSV 파일을 업로드하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040673232/original/U6Ezequ3JHtmkRbRUYlCdowbOAOFPlw1RA.gif?1738168901)

2단계: 파일을 업로드한 뒤 **가져오기 방법 선택**을 클릭하세요. 새로 만들지, 업데이트할지, 둘 다 할지 정할 수 있어요.

![가져오기 방법을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040673389/original/1wbH4t9zwC4jss4xrDWDyMQBGScc9oeYnw.png?1738169062)

{% hint style="info" %}
**Find existing contacts based on**(기존 연락처를 찾는 기준)의 기본값은 이메일, 그다음 전화번호예요. 먼저 이메일로 연락처/기회를 찾고, 이메일로 찾지 못하면 전화번호로 찾아요.
{% endhint %}

### 열을 필드에 매핑하기

파일의 각 열이 시스템의 해당 필드와 정확히 연결되었는지 확인하세요.

몇 가지 알아 둘 점이 있어요.

1. **Don't update Empty Values**(빈 값은 업데이트하지 않기) 체크박스를 선택하면, 가져오는 파일의 값이 비어 있고 기회의 해당 필드에는 이미 값이 있을 때 그 필드를 업데이트하지 않아요.
2. 가져오지 않을 필드는 매핑하지 않은 채로 둘 수 있어요. 이 경우 화면 아래쪽 체크박스를 선택해야 다음으로 넘어가요. 화면에는 "Please ensure all mandatory fields are mapped. To proceed, either map all fields or choose Don't import data for unmapped columns"(필수 필드가 모두 매핑되었는지 확인하세요. 계속하려면 모든 필드를 매핑하거나 **Don't import data for unmapped columns**(매핑하지 않은 열의 데이터는 가져오지 않기)를 선택하세요)라는 안내가 나와요.
3. 이메일 주소나 전화번호가 여러 개인 연락처도 만들 수 있어요. 이런 추가 정보는 가져오는 중에 자동으로 추가돼요.
4. CSV에서 연락처와 기회가 같은 줄에 있으면 서로 자동으로 연결돼요.

![열을 필드에 매핑하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040673955/original/qTkj_KxMtSIGVm4td90AiKIauWMgpKBRkg.png?1738169641)

### 검토하고 가져오기 완료

매핑을 검토한 뒤 확인하고 가져오기를 진행하세요. 이때 가져온 연락처로 **Create a Smart list**(스마트 리스트 만들기), **워크플로우**에 연락처 추가, 새 **태그** 추가도 함께 할 수 있어요.

![가져오기 검토 화면에서 스마트 리스트 만들기, 워크플로우 추가, 태그 추가 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040674777/original/UqeVsoGa1tluVwGM-OxyGzXk4dgiADAj_Q.png?1738170432)

가져올 모든 연락처/기회를 확인했다는 체크박스는 반드시 선택해야 해요.
{% endhint %}

## 가져오기 상태 확인

- 연락처와 기회의 **일괄 작업** 페이지에서 가져오기 진행 상황과 상태를 확인할 수 있어요.
- 연락처 가져오기와 기회 가져오기는 모두 **일괄 작업**의 같은 곳에 표시돼요.
- **통계 보기** 버튼을 클릭하면 가져오기 통계를 볼 수 있어요. **오류** 탭에서는 오류 로그를 내려받고, 오류 내용과 해결 방법도 자세히 확인할 수 있어요.

![일괄 작업 페이지에서 통계 보기와 오류 탭을 확인하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040675205/original/9137ojlvH-YH7-gdZ0MwQa2zapRtYwe4kg.gif?1738170977)

{% hint style="info" %}
Keap에서 내보낸 CSV의 전화번호 필드는 하이퍼클래스와 호환되지 않아요. 괄호 '()'와 대시 '-' 때문이에요. CSV 파일에서 전화번호 열 전체를 선택해 숫자 형식으로 지정하고, 괄호와 대시를 모두 지운 뒤 가져오세요. 그러면 CRM의 데이터가 깨지지 않아요.
{% endhint %}

## 자주 발생하는 CSV 가져오기 오류와 실패 상황

| 오류/상황 | 의미 | 다음 단계 |
| --- | --- | --- |
| 중복된 연락처 또는 식별자 | 같은 이메일, 전화번호, 연락처 ID 또는 고유 값이 두 번 이상 나와요. | 중복을 지우거나 합친 다음 다시 가져오세요. |
| 잘못된 이메일 또는 전화번호 | 하이퍼클래스가 값을 확인할 수 없어요. | 형식을 고친 뒤 해당 행만 다시 시도하세요. |
| 식별 정보 누락 | 하이퍼클래스가 연락처를 만들거나 기존 연락처와 맞출 수 없어요. | 올바른 이름, 이메일, 전화번호 또는 연락처 ID를 추가하세요. |
| 잘못된 필드 값 | 날짜, 드롭다운, 체크박스 또는 커스텀 필드의 값이 허용되지 않아요. | 값을 하이퍼클래스의 올바른 형식이나 옵션에 맞게 고치세요. |
| 담당자를 찾을 수 없음 | 지정한 담당자를 하이퍼클래스 사용자와 맞출 수 없어요. | 올바른 사용자 이름이나 이메일 주소를 사용하세요. |
| 연락처를 찾을 수 없거나 업데이트 실패 | 하이퍼클래스가 참조한 연락처를 찾거나 업데이트할 수 없어요. | 연락처 ID, 이메일 또는 전화번호를 확인한 뒤 다시 시도하세요. |
| 일부 또는 일괄 작업 실패 | 일부 행은 가져왔지만 나머지는 실패했어요. | 실패한 행만 고쳐서 다시 가져오세요. |
| 처리 오류 | 파일이나 처리 문제 때문에 하이퍼클래스가 가져오기를 완료하지 못했어요. | CSV 형식을 검토한 뒤 다시 시도하세요. |

## 자주 묻는 질문

### CSV 파일이 50MB를 넘으면 어떻게 되나요?

파일을 50MB 미만의 작은 파일로 나누고, 나눈 파일을 따로 가져오세요.

<!-- 검토 필요: 원문 내용이 서로 다름 -->

### 이메일이나 전화번호가 여러 개인 연락처도 가져올 수 있나요?

네, 가져올 수 있어요. 추가 이메일과 전화번호는 기존 기본 정보를 덮어쓰지 않고 보조 필드에 저장돼요.

### 중복된 연락처는 어떻게 처리되나요?

- 하이퍼클래스는 전화번호나 이메일을 기준으로 연락처를 자동으로 병합해요.
- 일치하는 연락처를 찾으면 새로 만들지 않고 기존 레코드를 업데이트해요.

자세한 내용은 [연락처 중복 허용](../11-설정/Business-Profile-Settings/allow-duplicate-contacts-contact-deduplication-preferences.md) 문서를 참고하세요.

### CSV로 기존 연락처를 업데이트할 수 있나요?

네, 가능해요. 가져오기 중에 **Update Only**(업데이트만) 또는 **Create & Update**(만들기 및 업데이트)를 선택하세요.

### 가져오기에 실패하면 어떻게 하나요?

- **Import Status Page**(가져오기 상태 페이지)에서 오류 메시지를 확인하세요.
- 오류 로그를 내려받아 문제를 고친 뒤, 수정한 CSV를 다시 가져오세요.

### 가져온 연락처가 모두 모든 채널에서 수신거부로 설정돼요. 특정 채널만 수신거부로 설정하려면 어떻게 하나요?

CSV에 수신거부(DND, Do Not Disturb) 열을 넣어 연락처를 가져오면, 하이퍼클래스는 모든 소통 채널(SMS, 이메일, 통화, 음성메일 등)에 수신거부를 자동으로 적용해요.

특정 채널만 수신거부로 설정하려면 수신거부 열 대신 **워크플로우**와 **태그**를 사용하세요.

### 메모가 포함된 CSV를 가져오는데 연락처 한 명당 메모를 하나밖에 만들 수 없어요.

연락처 메모를 가져올 때는 연락처 레코드 하나당 메모를 하나만 넣을 수 있어요. 글자 수는 5,000자까지예요.
