# 회사 기능 시작하기

**회사**(Companies) 기능을 쓰면 개별 연락처뿐 아니라 회사 단위로 비즈니스 관계를 관리할 수 있어요. 같은 회사의 연락처가 여러 명이거나, 한 회사와 주고받은 내용과 작업을 한눈에 모아 보고 싶을 때 특히 유용해요.

## 기능 1 - 회사 정보 만들기, 편집하기, 저장하기

![회사 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039543421/original/1CYCoUG1oplFfXsHm8YDSmL2LhWy-uE3NA.png?1736423608)

새 회사를 추가하거나 이미 등록한 회사의 정보를 수정할 수 있어요. 아래와 같은 정보를 저장할 수 있어요.

- **회사명**
- **전화번호**
- **이메일 주소**
- **웹사이트**
- 주소(**주/도**, **도시**, 우편번호, 국가 포함)
- 회사 설명

중요한 회사 정보를 한곳에 모아 두면 팀원이 필요할 때 바로 찾아볼 수 있어요.

## 기능 2 - 커스텀 필드 만들고 관리하기

![커스텀 필드 관리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039543564/original/VOhp6gYfLYrEahiAklK2n6nUrL6Hn07HCg.png?1736423698)

회사 기능에서는 비즈니스에 맞는 **커스텀 필드**를 만들 수 있어요. 기본 정보 외에 아래와 같은 항목도 따로 관리할 수 있어요.

- 업종
- 매출 범위
- 직원 수

커스텀 필드는 쉽게 만들고, 편집하고, 업데이트할 수 있어요. 회사마다 필요한 정보를 원하는 대로 추가해 보세요.

## 기능 3 - 목록 보기 사용자 지정하기

![회사 목록 보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039543724/original/MB6j8lCxnK_bi2UaJLVHpDauvDCv51FMIA.jpeg?1736423823)

목록 보기에서는 등록한 회사를 한눈에 볼 수 있어요. **필드 관리**를 눌러 목록에 보여 줄 열을 정할 수 있어요. 예를 들어 **웹사이트**나 **주/도** 같은 필드를 넣거나 뺄 수 있어요. 꼭 필요한 정보만 골라서 볼 수 있어요.

## 기능 4 - 상세 필터

![상세 필터 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039543922/original/sR78WBepgnSlv32r1jS8qc1rPP5tyR9cOw.png?1736423950)

**상세 필터**를 쓰면 원하는 조건에 맞는 회사만 골라 볼 수 있어요. **도시**, 이메일 같은 기본 필드와 직접 만든 **커스텀 필드**에 필터를 적용할 수 있어요. 특정 주에 있는 회사나 특정 업종의 회사를 찾을 때 편해요.

## 기능 5 - 정렬

회사 기록을 정렬해서 데이터를 정리할 수 있어요. **회사명**, **도시**, **주/도** 같은 여러 필드를 기준으로 정렬할 수 있어서, 지금 필요한 회사를 빠르게 찾을 수 있어요.

## 기능 6 - 기본 필드와 커스텀 필드에서 검색하기

![회사 검색 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155039544218/original/LU2rSgumOrNZb9yua5hiRT9b9w1iLqyoRw.png?1736424114)

**검색**에서는 기본 필드와 커스텀 필드 모두를 기준으로 회사를 찾을 수 있어요. 예를 들어 회사명이나 전화번호로 검색할 수 있고, 회사에 검색 가능하게 설정한 커스텀 필드 값으로도 검색할 수 있어요. 데이터가 많이 쌓여도 필요한 정보를 빠르게 찾을 수 있어요.

## 활용 사례

1. **영업팀:** 잠재 고객사와 상세 정보를 관리해서 영업 파이프라인을 효율적으로 운영해요.
2. **계정 관리:** 파트너와 협력업체의 연락처 정보를 최신 상태로 유지해요.
3. **마케팅팀:** 업종이나 지역별로 회사를 나눠서 타깃 캠페인에 활용해요.
