# HubSpot 데이터 가져오기

HubSpot CRM의 연락처, 딜, 커스텀 필드, 파이프라인 같은 데이터를 하이퍼클래스로 옮기는 방법을 안내해요. 가져오기가 끝난 뒤 결과를 확인하고 오류를 고치는 방법도 함께 다뤄요.

[동영상](https://www.youtube.com/embed/y3A9fqwqO7c?&wmode=opaque)

## HubSpot 가져오기란?

HubSpot 가져오기를 쓰면 HubSpot에서 하이퍼클래스로 더 쉽게 옮겨 올 수 있어요. CRM 설정을 손으로 다시 만들 필요 없이, HubSpot을 연결하고 가져올 항목을 고른 다음 하이퍼클래스 안에서 바로 시작하면 돼요.

연락처, 기회, 커스텀 필드, 파이프라인, 단계, 커스텀 폴더처럼 중요한 데이터와 구조를 함께 가져와서 초기 설정 시간을 줄여 줘요. 가져오기가 끝나면 리포트가 표시돼요. 무엇이 잘 가져와졌는지, 무엇이 실패했는지, 무엇을 확인해야 하는지 볼 수 있어요.

## HubSpot 가져오기의 장점

- 빠른 이전: 지원되는 HubSpot CRM 데이터를 CSV로 일일이 내보내지 않고 하이퍼클래스로 바로 가져올 수 있어요.
- 구조 유지: HubSpot 딜을 하이퍼클래스 기회로 가져오면서, 지원되는 파이프라인과 단계도 그대로 정리돼요.
- 커스텀 데이터 유지: 지원되는 HubSpot 연락처 속성과 딜 속성을 하이퍼클래스 커스텀 필드로 가져와요.
- 투명한 리포트: 가져오기가 끝나면 전체 건수, 성공한 레코드, 오류, 경고, 오브젝트별 결과, 레코드별 메시지를 확인할 수 있어요.
- 선택적 이전: 연락처, 딜, 회사, 작업을 HubSpot 생성일 또는 최종 수정일로 필터링해서 필요한 레코드만 가져올 수 있어요.

---

## 시작하기 전에

- 가능하면 깨끗한 계정을 쓰세요. 직접 만든 데이터가 없는 계정으로 가져오면 오류와 중복을 확인하기 쉬워요.
- 시작하기 전에 연락처와 기회 모두에서 **Allow duplicates**(중복 허용)를 켜세요. 가져오기가 끝나면 중복 방지를 다시 켤 수 있어요. 중복 차단을 켜 둔 채로 가져오면 피할 수 있는 오류가 많이 생겨요.
- 가져오기는 백그라운드에서 실행돼요. 창을 닫았다가 나중에 돌아와서 진행 상황을 확인해도 돼요.
- 계정 언어는 영어로 설정하는 것을 권장해요.
- 실제로 쓰고 있는 로케이션에 가져오기 전에, 새 로케이션이나 운영 중이 아닌 로케이션에서 먼저 테스트해 보길 권장해요.

## HubSpot에서 가져올 수 있는 데이터

현재 연락처, 기회(딜), 회사, 커스텀 필드(속성), 커스텀 폴더, 파이프라인, 단계, 이메일, 메모, 작업을 가져올 수 있어요.

딜을 기회로 가져올 때, 가져오기 기능이 지원하는 범위에서는 파이프라인과 단계 구조가 그대로 유지돼요. HubSpot에서 하이퍼클래스로 옮긴 뒤에도 영업 프로세스가 익숙하게 유지돼요.

| 이전 유형 | 하는 일 |
| --- | --- |
| 연락처 이전 | HubSpot 연락처 레코드를 하이퍼클래스로 가져와요. |
| 기회 이전 | HubSpot 딜을 하이퍼클래스 기회로 가져와요. |
| 회사 이전 | HubSpot 회사를 하이퍼클래스에 새 레코드로 가져와요. |
| 커스텀 필드 이전 | HubSpot 연락처 속성과 딜 속성을 하이퍼클래스 커스텀 필드에 매핑해요. |
| 파이프라인 및 단계 이전 | 단계를 포함한 전체 파이프라인 구조를 유지해요. |
| 커스텀 폴더 이전 | 지원되는 가져온 데이터의 폴더 구성을 그대로 옮겨요. |
| 이메일 이전 | HubSpot의 모든 이메일을 하이퍼클래스로 가져와요. |
| 작업 이전 | 리마인더와 할 일을 하이퍼클래스로 가져와요. |

지원하지 않는 오브젝트는 전체 이전 계획에 따라 처리하거나, HubSpot에서 하이퍼클래스로 이전하는 가이드의 수동 이전 단계를 따라 주세요.

## 제한 사항 및 유의할 점

- 파이프라인 및 기회: 파이프라인과 파이프라인 단계를 가져와요. 기회 하나에 추가 연락처를 최대 10명까지 연결할 수 있어요. 연결된 연락처가 없는 기회는 가져올 수 없어요.
- 커스텀 필드: 커스텀 필드 매핑은 필드 키를 기준으로 해요. 같은 필드 키가 이미 하이퍼클래스에 있으면 가져오기가 실패할 수 있어요. HubSpot 계산 필드는 **Single Line Text**(한 줄 텍스트) 필드로 가져와요.
- 파일 및 첨부: 연락처와 기회는 파일 첨부를 지원해요. <!-- 검토 필요: 원문 내용이 서로 다름 (문제 해결 섹션에서는 파일 첨부가 아직 지원되지 않아 오류가 난다고 설명) -->
- 연락처: 가져온 연락처를 하이퍼클래스에서 삭제한 뒤 가져오기를 다시 실행하면, 그 연락처를 다시 가져와요. 삭제한 연락처를 나중에 복원하면 중복 연락처가 생길 수 있어요.
- 메모: 메모는 오브젝트 유형마다 레코드 하나에만 연결할 수 있어요. 예를 들어 메모 하나를 연락처 1명, 기회 1건에 연결할 수 있어요. 현재는 메모를 회사에 연결할 수 없어요.
- 작업: 반복 작업은 지원하지 않아요. 작업 하나는 오브젝트 유형마다 레코드를 최대 10개까지 연결할 수 있어요. 예를 들어 연락처 10명, 기회 10건, 회사 10곳에 연결할 수 있어요.
- 연관: 플랫폼 제한 때문에 일부 연관은 가져오지 못할 수 있어요. 이전이 끝난 뒤 중요한 연관은 직접 확인해 주세요.
- 이메일: HubSpot에서 가져온 이메일은 읽기 전용이에요.

## HubSpot 가져오기 사용 방법

### 1단계: 데이터 가져오기 열기

**연락처**(또는 **회사**, **기회 관리**) 화면 오른쪽 위에서 **가져오기** 메뉴를 열고 **데이터 가져오기**를 선택하세요.

![가져오기 메뉴에서 데이터 가져오기를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071283631/original/mrGot9kMZ6vWQcy9ipDvtgU9TgFqcPNjfw.png?1778710020)

### 2단계: HubSpot 가져오기 선택

오른쪽 카드의 **HubSpot 연결**을 클릭해서 HubSpot 가져오기를 시작하세요.

![HubSpot 연결 카드가 있는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071283846/original/X7WVxhtleGKXmzVjV53-SfB2ZqcQm-yMqg.jpeg?1778710712)

### 3단계: HubSpot 계정 인증

HubSpot 계정에 로그인해서 인증하세요.

![HubSpot 계정 인증 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071283851/original/WdRVxYJ6SazmFNqAn7zPWklQKQ2pQ7mcMQ.png?1778710776)

### 4단계: 퀵 팁 확인

키 인증이 끝나면 가져오기 마법사가 **시작하기** 단계로 열려요. 이 단계에서는 간단한 안내 영상과 몇 가지 팁을 보여 줘요.

- 가져오기 전에 HubSpot에서 중복 데이터를 정리하세요.
- 가져오기 전에 현재 데이터를 백업하세요.
- 가져오기를 시작하기 전에 필드 매핑을 확인하세요.

준비가 되면 **계속**을 클릭하세요.

![가져오기 마법사의 시작하기 단계. 퀵 팁 영상, 가져오기 가이드 링크, 가져오기를 잘 끝내기 위한 팁이 보인다.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071278754/original/nb6rXC9j854J7if5BkHk9L-yeoEVgdIPEQ.png?1778701200)

### 5단계: 가져올 항목 선택

가져올 HubSpot 오브젝트를 고르세요.

- **연락처**: 관리하는 사람들(리드, 고객, 잠재 고객)이에요.
- **작업**: 레코드에 연결된 할 일, 후속 조치, 리마인더를 추적해요.
- **딜**: 파이프라인 금액과 상태를 추적해요. 딜은 **기회 관리**로 가져와요.
  딜을 가져오려면 연락처도 함께 가져와야 해요. 딜을 선택하면 연락처가 자동으로 선택돼요.
- **회사**: 회사 오브젝트 레코드를 회사로 가져와요.

가져올 항목의 체크박스를 선택한 뒤 **계속**을 클릭하세요.

![가져올 오브젝트를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078262193/original/9J14TQ92R36XCt6EAI5P7VvEAC6Sa_yM9w.png?1786548570)

### 6단계: 포함되는 항목 확인

레코드가 빠짐없이 서로 연결되도록, 마법사가 관련 데이터를 자동으로 함께 가져와요.

- 연락처: 모든 속성(기본 필드 + 커스텀 필드), 메모, 이메일
- 작업: 연관
- 딜: 모든 속성, 파이프라인, 메모, 연관
- 회사: 속성과 연관
  파이프라인 단계는 파이프라인과 함께 가져와요. 따로 만들 필요가 없어요.

커스텀 필드는 이 두 가지를 주의하세요.

- 커스텀 필드는 키로 매핑돼요. 같은 키의 커스텀 필드가 이미 계정에 있으면, 그 필드에서 가져오기 오류가 나요. 깔끔하게 매핑하려면 가져오기 전에 기존 필드의 이름을 바꾸거나 제거하세요.
- 이름과 레이블이 달라요. HubSpot에서 커스텀 필드의 내부 이름과 표시 레이블이 다르면 가져오는 중에 문제가 생길 수 있어요. 가져오기 전에 HubSpot 커스텀 필드를 살펴보고 이름과 레이블을 맞춰 두면 예상치 못한 문제를 피할 수 있어요.

**계속**을 클릭해서 다음으로 넘어가세요.

![가져오기에 포함되는 항목을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078261235/original/jpWs8pZkJ4ht6uPqRgZjg0UrNOZcQVo9UQ.png?1786547999)

### 7단계: 레코드 수 확인 및 필터 설정

**미리보기 및 가져오기** 단계에는 HubSpot 데이터 항목별로, 하이퍼클래스에서 어떤 형식이 되는지(**가져온 형식**)와 예상 레코드 수(**Est. Records**, 예상 레코드)가 나와요.

오브젝트의 일부 레코드만 가져오려면, 레코드 행(예: 연락처 – 레코드)의 편집(연필) 아이콘을 클릭하고 필터를 추가하세요. 자세한 방법은 아래 가져올 레코드 필터링을 참고하세요.

필터를 적용하면 **Est. Records**에 두 숫자가 함께 표시돼요. 예를 들어 301개 검색됨 • 157개 선택됨처럼요. 선택된 레코드만 가져와요.

연락처나 딜의 속성을 골라서 가져오려면 속성 행의 편집(연필) 아이콘을 클릭하세요.

**확인 후 가져오기 시작**을 클릭한 다음, 팝업에서 한 번 더 확인하세요.

- **HubSpot 데이터**: HubSpot에 있는 항목이에요(예: 연락처 – 레코드, 딜 – 파이프라인).
- **가져온 형식**: 내 계정에서 어떤 항목이 되는지 보여 줘요(예: 연락처 – 커스텀 필드, 기회 관리 – 파이프라인).
- **검색된 레코드**: 가져올 레코드 수예요.

{% hint style="info" %}
연관 수는 추정치예요. 각 쌍을 원본 레코드마다 한 번씩 세기 때문에, 연결할 대상이 없는 레코드가 있으면 최종 수가 더 적을 수 있어요.
{% endhint %}

### 가져올 레코드 필터링

필터를 쓰면 HubSpot 오브젝트를 전부 가져오지 않고 일부만 가져올 수 있어요. 필터는 선택 사항이에요. 필터를 비워 두면 해당 오브젝트의 모든 레코드를 가져와요.

필터링할 수 있는 오브젝트: 연락처, 딜, 회사, 작업

필터링할 수 있는 필드

| 필드 | 의미 |
| --- | --- |
| **HubSpot 생성일** | HubSpot에서 레코드가 생성된 시점 |
| **HubSpot 최종 수정일** | HubSpot에서 레코드가 마지막으로 업데이트된 시점 |

**조건**: **다음과 같음**, **다음이 아님**

![필터 조건을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083926615/original/PkjJbWZ8QPJidvl8A-3vScWcxFP_LZF3Cg.png?1792654367)

선택할 수 있는 값

| 유형 | 옵션 |
| --- | --- |
| 상대 날짜 | 어제, 오늘, 내일, 이번 주, 이번 달, **이번 분기**, 올해 |
| 정확한 날짜 | 지정일, 지정일 이전, 지정일 이후, 기간 사이 |
| 기간 범위 | **최근**, 향후, 초과, 미만 (숫자를 입력하고 일, 주, 월, 년 중에서 선택) |

필터를 추가하는 방법

1. **미리보기 및 가져오기** 단계에서 오브젝트 레코드 행의 **편집(연필)** 아이콘을 클릭하세요. **Filter [Object]**(오브젝트 필터) 패널이 열려요.
2. **필드 선택**을 클릭하고 **HubSpot 생성일** 또는 **HubSpot 최종 수정일**을 고르세요.
3. 조건으로 **다음과 같음** 또는 **다음이 아님**을 고르세요.
4. 값 유형을 고르고 값을 입력하세요. 기간 범위라면 숫자를 입력하고 단위를 고르세요.
   - 패널에 필터가 적용되는 정확한 날짜 범위가 표시돼요. 예: "2026년 4월 22일 오전 12:00 ~ 2026년 10월 21일 오후 11:59 시점의 레코드를 포함합니다."
5. *(선택)* **중첩 필터 추가**를 클릭해서 조건을 더하고, **그리고**(모든 조건에 맞는 레코드) 또는 **또는**(조건 중 하나라도 맞는 레코드)을 고르세요.
6. 이 오브젝트에만 적용하려면 **필터 적용**을, 선택한 모든 오브젝트에 같은 조건을 쓰려면 **모든 오브젝트에 필터 적용**을 클릭하세요.

![필터를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083926636/original/_evdpsPUH3SCabkblyhA7MLgk1PxZ4RIVg.png?1792654390)

필터를 바꾸거나 지우는 방법

- 조건을 바꾸려면 **편집(연필)** 아이콘을 다시 클릭하세요.
- 조건 옆의 **×**를 클릭하면 그 조건이 지워져요. 모두 지우려면 **필터 초기화**를 클릭하세요.
- 적용하지 않은 변경 사항이 있는 상태에서 패널을 닫으면, 계속 편집할지 변경 사항을 버릴지 물어봐요.

알아 두면 좋아요

- **최근**에는 오늘이 포함되지 않아요. 예를 들어 10월 22일에 *최근 6개월*을 선택하면 4월 22일부터 10월 21일까지가 포함돼요.
- 기간 범위의 값은 0보다 커야 해요. 0처럼 올바르지 않은 값을 입력하면 **유효하지 않은 값입니다**가 표시돼요. 모든 조건이 완전하고 올바르게 입력될 때까지 **필터 적용**은 비활성화된 채로 있어요.

HubSpot의 커스텀 필드 중 일부만 골라서 수정하고 가져올 수도 있어요.

![일부 커스텀 필드만 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078261390/original/5kwnilw8ChlaQMKJIKL0SjmR1fn7CSNS_A.png?1786548079)

### 8단계: 가져오기 실행 중

페이지 맨 위에 "HubSpot 가져오기가 시작되어 백그라운드에서 실행 중입니다."라는 확인 메시지가 표시돼요. 아래 **가져오기 기록** 표에는 진행 중인 실행이 **Processing %**(처리 중 %) 상태와 함께 실시간으로 나와요.

창을 닫거나 다른 페이지로 이동해도 가져오기는 계속 진행돼요. 언제든 이 페이지로 돌아와서 진행 상황을 확인하세요.

### 9단계: 가져오기 상세 열기(오브젝트 보기)

결과를 확인할 준비가 되면, 가져오기 행의 **작업** 열에서 **통계 아이콘**을 클릭하세요. **가져오기 상세** 창이 열려요.

위쪽 카드 네 개에서 핵심 수치를 볼 수 있어요.

- **전체 레코드**: 가져오기가 처리한 모든 레코드예요.
- **성공**: 문제없이 가져온 레코드예요(성공률 포함).
- **오류**: 가져오지 못한 레코드예요.
- **경고와 함께 가져옴**: 가져오기는 됐지만 확인해 볼 만한 내용이 있는 레코드예요.

기본 탭인 **오브젝트 보기**에서는 오브젝트별로 성공한 수, 오류가 난 수, 전체 상태를 요약해서 보여 줘요.

### 10단계: 개별 레코드 살펴보기

**레코드 보기** 탭으로 전환하면 모든 레코드를 한 줄씩 볼 수 있어요.

- **오브젝트**: 연락처, 연락처 – 커스텀 필드, 기회 관리 등으로 좁혀서 볼 수 있어요.

### 11단계: 오류 확인 및 수정

**상태** 필터를 **오류**로 바꾸면 실패한 레코드를 모두 볼 수 있어요. 각 행에서 어떤 오브젝트가 왜 실패했는지 확인할 수 있고, 메시지에 HubSpot 레코드 ID가 있어서 HubSpot에서 해당 레코드를 찾을 수 있어요.

왼쪽 아래의 **다운로드**를 클릭하면 전체 오류 목록을 CSV로 내려받을 수 있어요. HubSpot에서 데이터를 고친 뒤 가져오기를 다시 실행할 때 유용해요.

자주 나오는 오류 원인은 아래 문제 해결과 자주 묻는 질문에서 다뤄요.

## 문제 해결

### **검색된 레코드** 수가 HubSpot에 표시되는 수보다 적어요

마법사의 레코드 수에는 가져오기가 실제로 매핑해서 가져올 수 있는 필드만 포함돼요. 지원하지 않는 유형의 필드처럼 일부 HubSpot 필드는 제외되기 때문에, HubSpot 화면의 수와 가져오기 미리보기의 수가 조금 다를 수 있어요. 수에 포함되지 않은 레코드는 어차피 가져오기가 건너뛰었을 레코드예요.

### "Couldn't import contact with HubSpot record ID…" 오류가 보여요

이 메시지는 어떤 HubSpot 연락처가 실패했는지 정확히 알려 줘요. 흔한 원인은 다음과 같아요.

- 연락처에 필드에 첨부된 파일이 있어요. 파일 가져오기는 아직 지원하지 않아서, 파일이 첨부된 연락처(또는 딜)는 오류가 나요. 해결 방법: HubSpot에서 파일을 내려받고, 그 필드에서 첨부를 제거한 뒤 가져오기를 다시 실행하세요. 파일은 가져온 뒤에 직접 다시 첨부하면 돼요. <!-- 검토 필요: 원문 내용이 서로 다름 (제한 사항 섹션에서는 연락처와 기회의 파일 첨부를 지원한다고 설명) -->
- 커스텀 필드 키가 충돌해요. 커스텀 필드는 내부 키로 매핑돼요. 같은 키의 필드가 이미 있으면 그 필드에서 가져오기 오류가 나요. 가져오기 전에 기존 필드의 이름을 바꾸거나 삭제하세요.
- 커스텀 필드의 이름과 레이블이 달라요. HubSpot 필드의 이름과 레이블이 다르면 가져오기가 어느 쪽을 써야 할지 헷갈릴 수 있어요. 가져오기 전에 HubSpot에서 둘을 맞춰 두면 대체로 해결돼요.

## 자주 묻는 질문

### 다시 가져오거나 중단한 지점부터 이어서 가져올 수 있나요?

네, **데이터 가져오기** 페이지에서 새 가져오기를 시작하면 돼요. 실행할 때마다 **가져오기 기록**에 따로 기록되기 때문에, 이전 실행과 비교하거나 이전 시도의 오류 CSV를 확인한 뒤 다시 실행할 수 있어요.

### 가져오기를 하면 기존 레코드를 덮어쓰나요?

기본적으로는 덮어쓰지 않아요. 가져온 레코드는 계정에 이미 있는 데이터와 별도로 추가돼요. 그래서 깨끗한 계정으로 가져오길 권장하고, 가져오는 동안 **Allow duplicates**(중복 허용)를 켜 두라고 안내해요(시작하기 전에 참고).

### 전체 오류 목록은 어디에서 볼 수 있나요?

가져오기 행에서 **가져오기 상세**를 열고 **레코드 보기**로 전환한 뒤, **상태**를 **오류**로 설정하고 **다운로드**를 클릭하면 전체 목록을 CSV로 내려받을 수 있어요.

### HubSpot 레코드 중 일부만 가져올 수 있나요?

네. **미리보기 및 가져오기** 단계에서 오브젝트 레코드 행의 편집(연필) 아이콘을 클릭하고 **HubSpot 생성일** 또는 **HubSpot 최종 수정일**로 필터링하세요.

### 오브젝트마다 필터를 따로 설정해야 하나요?

아니요. 조건을 한 번 설정하고 **모든 오브젝트에 필터 적용**을 클릭하면 선택한 모든 오브젝트에 같은 조건이 적용돼요. 그 뒤에도 오브젝트별로 필터를 따로 편집할 수 있어요.

### "최근 7일"로 필터링하면 오늘 만든 레코드가 왜 빠지나요?

기간 범위는 어제부터 거꾸로 세고 오늘은 포함하지 않아요. 필터를 적용하기 전에 패널에서 정확한 날짜 범위를 확인할 수 있어요.

### 담당자, 라이프사이클 단계 같은 다른 속성으로도 필터링할 수 있나요?

아직은 안 돼요. 현재 필터는 **HubSpot 생성일**과 **HubSpot 최종 수정일**만 지원해요.
