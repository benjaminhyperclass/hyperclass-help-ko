# 여러 연락처에 태그 한 번에 추가하기

**태그 추가** 기능으로 여러 연락처에 태그를 한꺼번에 붙이는 방법을 안내해요. 리드를 단계별로 정리하거나, 캠페인 대상을 나누거나, 자동화를 위해 연락처에 표시해 둘 때 쓰면 수작업 시간을 줄일 수 있어요.

## 여러 연락처에 태그를 추가한다는 건

태그를 일괄로 추가하면 많은 연락처에 라벨을 한 번에 붙여 정리할 수 있어요. 태그는 공통된 특징, 행동, 고객 여정 단계를 기준으로 연락처를 분류하는 데 쓰여요. 대상 그룹을 나누거나, 자동화를 시작하거나, CRM 워크플로우를 대규모로 관리할 때 꼭 필요한 기능이에요.

## 여러 연락처에 태그 추가하는 방법

**연락처** 페이지에서 여러 연락처에 태그를 붙이는 과정이에요.

1. 왼쪽 메뉴에서 **연락처**를 클릭하세요.
2. 태그를 붙일 연락처를 왼쪽 체크박스로 선택하세요. 필요한 만큼 얼마든지 선택할 수 있어요.
3. 연락처를 선택하면 화면 위쪽에 작업 표시줄이 나타나요. 여기서 **태그 추가** 아이콘을 클릭하세요.
4. **태그 추가** 팝업 창이 열리면 **Action Name**(작업 이름) 필드에 이 작업의 이름을 입력하세요.
5. **태그** 필드의 드롭다운을 클릭하고, 목록에서 태그를 하나 이상 선택하세요.
6. 태그를 모두 선택했으면 **태그 추가** 버튼을 클릭하세요. 작업이 시작되고 확인 메시지가 나타나요.
7. 이 확인 팝업은 **태그 추가**를 클릭한 직후에 나타나요. 선택한 연락처에 태그를 붙이는 작업이 진행 중이라는 안내예요. 진행 상황을 보려면 **진행 상황 확인** 버튼을 클릭하세요. **일괄 작업** 탭으로 이동하고, 작업의 성공 여부를 실시간으로 확인할 수 있어요.
8. 일괄 태그 작업이 끝나면 **일괄 작업** 탭에서 완료된 것을 확인할 수 있어요. 작업 이름, 실행한 사람, 생성 시각이 표시되고, 결과를 확인할 수 있는 **통계 보기** 링크도 있어요. 태그가 의도대로 적용됐는지 여기서 확인해 보세요.

## 자주 묻는 질문

### 한 연락처에 여러 태그를 동시에 붙일 수 있나요?

네, 한 번의 일괄 작업으로 여러 태그를 동시에 선택해 적용할 수 있어요. 작업을 실행하기 전에 **태그** 필드에 원하는 태그를 모두 추가하세요.

### 기존 태그가 덮어써지나요?

아니요. 일괄로 태그를 추가하면 선택한 태그만 연락처의 기존 태그 목록에 덧붙여져요. 원래 있던 태그는 지워지지 않아요.

### 태그로 자동화를 시작할 수 있나요?

네, 가능해요. 하이퍼클래스 자동화에서는 태그를 워크플로우 트리거로 자주 써요. 태그가 추가되거나 제거될 때 워크플로우가 시작되도록 설정할 수 있어요. 자세한 내용은 [워크플로우 트리거 - 연락처 태그](../../07-워크플로우/workflow-trigger-contact-tag.md)를 참고하세요. 워크플로우 안에서 태그를 붙이는 방법은 [워크플로우 액션 - 연락처 태그 추가](../../07-워크플로우/Contact-Workflow-Actions/workflow-action-add-contact-tag.md)에서 볼 수 있어요.

### 일괄로 추가한 태그를 취소하거나 제거하려면 어떻게 하나요?

연락처에서 태그를 제거하려면 **태그 제거** 일괄 작업을 사용하세요. 특정 태그만 제거하거나, 선택한 연락처의 태그를 모두 지울 수 있어요. 자세한 방법은 [여러 연락처에서 태그 제거하기](../removing-contact-tags-from-multiple-contacts.md)에서 따로 안내하고 있어요.

### 태그가 제대로 붙은 연락처를 확인할 수 있나요?

네, 확인할 수 있어요. **일괄 작업** 탭에서 해당 작업 옆의 **통계 보기**를 클릭하세요. 태그가 붙은 각 항목의 성공 여부, 연락처 식별 정보, 시각이 표시돼요.
