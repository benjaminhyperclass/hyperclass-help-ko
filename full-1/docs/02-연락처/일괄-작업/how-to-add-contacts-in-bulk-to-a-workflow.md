# 연락처를 워크플로우에 한꺼번에 추가하기

연락처를 태그 같은 조건으로 걸러 낸 뒤, **Add to Automation**(자동화에 추가) 기능으로 워크플로우에 한꺼번에 추가하는 방법을 안내해요. 단계별 절차, 사용할 수 있는 예약 모드, 자주 묻는 질문도 함께 볼 수 있어요.

## 연락처를 워크플로우에 대량 추가한다는 건?

**Add to Automation** 기능을 쓰면 **연락처** 페이지에서 연락처를 골라 워크플로우에 한꺼번에 등록할 수 있어요. 트리거로 연락처가 워크플로우에 들어오기를 기다릴 필요가 없어요. 게시된 워크플로우라면 어디든 연락처 묶음을 직접 넣을 수 있고, 한 번에, 정해 둔 시간에, 또는 나누어서(드립 방식) 넣을 수 있어요.

가장 흔한 사용 방법은 연락처 목록을 태그 같은 특정 속성으로 필터링하고, 걸러진 결과를 선택해서 워크플로우에 추가하는 거예요. 타깃 발송, 재참여 유도, 일괄 처리에 쓰기 좋아요.

---

## 대량 추가의 장점

- **연락처를 빠르게 등록해요:** 연락처를 하나씩 등록하지 않고 한 번의 일괄 작업으로 여러 명을 워크플로우에 추가해요.
- **원하는 대상만 골라요:** **상세 필터**(태그, 필드, 기회 데이터 등)로 필요한 연락처만 등록해요.
- **등록 시점을 정해요:** 바로, 정해 둔 날짜·시간에, 또는 드립 모드로 나누어 등록할 수 있어요.
- **같은 대상을 다시 써요:** 필터링한 화면을 스마트 리스트로 저장해 두면 언제든 같은 대량 등록을 반복할 수 있어요.
- **진행 상황과 결과를 확인해요:** **일괄 작업** 페이지에서 상태, 시간 기록, 통계를 보고 어떤 연락처가 처리됐는지 확인해요.

---

## 연락처를 워크플로우에 한꺼번에 추가하는 방법

### 1단계: 연락처 필터링하기

{% hint style="info" %}
팁: 이메일, 도시, 연락처 소스, 기회 단계 등 다른 연락처 필드로도 필터링할 수 있어요. 필터를 여러 개 더하거나 중첩 필터를 써서, 등록할 연락처를 더 정확하게 좁혀 보세요.
{% endhint %}

1. **연락처 > 스마트 리스트**로 이동하세요.

   ![연락처 스마트 리스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068065636/original/-HJOc2qy7BANkUe-fSLsMPw9GG__fdZUFg.jpeg?1774884143)
2. **상세 필터**를 클릭해 필터 패널을 여세요.

   ![상세 필터 패널 열기](https://jumpshare.com/share/3ZPF44Y9Td1JFyQ0vA7D+/Screen+Shot+2026-03-30+at+20.53.26.png)
3. 태그로 필터링하려면 필터 검색창에 "**태그**"를 입력하고 선택하세요.
4. 연산자(예: **다음과 같음**)를 정하고, 필터링할 태그 값(예: "follow-up")을 고르세요. **적용**을 클릭하면 조건에 맞는 연락처만 목록에 표시돼요.

   ![태그 조건을 적용한 연락처 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068066391/original/U4_Jikxh6MB4X4MMC42l_pMGfPjal99vqg.png?1774884407)

### 2단계: 자동화에 추가하기

1. 워크플로우에 추가할 연락처를 선택하세요. 체크박스로 연락처를 하나씩 고르거나, 맨 위의 **전체 선택**을 클릭해 필터링된 목록의 연락처를 모두 선택할 수 있어요. 연락처를 한 명 이상 선택하면 일괄 작업 도구 모음이 나타나요.
2. 일괄 작업 도구 모음에서 **자동화 트리거**를 클릭하세요. **Add to Automation** 창이 열려요. 창 위쪽에는 선택한 연락처가, 아래쪽에는 설정 항목이 보여요.

   ![자동화 트리거 클릭 후 Add to Automation 창이 열리는 화면](https://jumpshare.com/share/KXkEwWAw3OPPq7NcEzVY+/GIF+Recording+2026-03-30+at+21.00.58.gif)

### 3단계: 자동화 설정하기

1. 아래 항목을 입력하세요.
   - **액션 이름:** 이 일괄 작업의 이름이에요. **일괄 작업** 페이지의 추적 리포트에 표시돼요. 예: "워크플로우 자동화 일괄 가져오기"
   - **자동화 유형:** 연락처를 워크플로우에 등록하려면 "**워크플로우**"를 선택하세요.
   - **워크플로우:** 연락처를 추가할 워크플로우를 고르세요. 드롭다운에는 계정에 게시된 워크플로우가 모두 표시돼요.
   - **모드:** 연락처를 언제, 어떤 방식으로 등록할지 정하세요. 자세한 내용은 아래 예약 모드를 참고하세요.
2. **Add to Automation**(자동화에 추가)을 클릭하세요. 처리 중인 연락처 수가 담긴 완료 메시지가 나타나요(예: "Add to Automation 10 Contacts is in progress/is scheduled").

   ![Add to Automation 완료 메시지](https://jumpshare.com/share/QKYX8WMvfTjw98iOGft1+/GIF+Recording+2026-03-30+at+23.01.41.gif)
3. **진행 상황 확인**을 클릭하면 **일괄 작업** 페이지로 이동해요. **Dismiss**(닫기)를 클릭하면 연락처 목록으로 돌아가요.

   ![진행 상황 확인과 Dismiss 버튼](https://jumpshare.com/share/eBZl9GB92Tm27rhOGW11+/Screen+Shot+2026-03-30+at+23.02.22.png)

## 예약 모드

**모드** 설정은 선택한 연락처를 워크플로우에 언제 등록할지 정해요. 선택지는 세 가지예요.

### Send All at Once(한 번에 모두 보내기)

선택한 연락처를 모두 바로 워크플로우에 추가해요. 기본 모드이고, 시점이 중요하지 않을 때 알맞아요.

**추가 입력 항목:** 없음

![Send All at Once 모드 화면](https://jumpshare.com/share/SImCkyIrTvzXvaQEBs3T+/Screen+Shot+2026-03-30+at+23.16.29.png)

### Send at Scheduled Time(예약 시간에 보내기)

선택한 연락처를 모두, 지정한 날짜와 시간에 워크플로우에 추가해요. 캠페인 시작이나 영업시간에 맞춰 등록할 때 유용해요.

**추가 입력 항목:**

| **필드** | **설명** |
| --- | --- |
| **시작 날짜 시간** | 모든 연락처를 등록할 날짜와 시간이에요. 계정의 시간대 기준으로 표시돼요. |

### Send in Drip Mode(드립 모드로 보내기)

연락처를 한꺼번에 등록하지 않고, 일정 기간에 걸쳐 나누어 등록해요. 연락처가 많을 때 등록 시점을 분산해서 워크플로우에 부담을 줄이거나 발송을 나누고 싶을 때 알맞아요.

추가 입력 항목:

| **필드** | **설명** |
| --- | --- |
| **시작 날짜 시간** | 첫 번째 묶음을 등록할 날짜와 시간이에요. |
| **Number of Messages per Batch**(묶음당 메시지 수) | 한 번에 등록할 연락처 수예요. |
| **반복 간격** | 묶음 사이의 간격이에요. 숫자와 단위(일, 시간, 분)를 정하세요. |

![Send in Drip Mode 모드 화면](https://jumpshare.com/share/edOlM7ALY7k6eenAT0J8+/Screen+Shot+2026-03-30+at+23.29.56.png)

## 진행 상황 확인하기

작업을 제출한 뒤에는 **일괄 작업** 페이지에서 진행 상황을 확인할 수 있어요. **연락처 > 일괄 작업**으로 이동하면 지금까지 요청한 일괄 작업이 모두 보여요.

**일괄 작업** 페이지에는 다음 정보가 표시돼요.

- **작업 라벨:** 작업을 만들 때 입력한 이름이에요.
- **작업 유형:** 자동화 유형이에요(예: 워크플로우).
- **상태:** 작업이 **In Progress**(진행 중), **Scheduled**(예약됨), **Complete**(완료) 중 어느 상태인지 보여요.
- **사용자:** 일괄 작업을 시작한 사람이에요.
- **생성일 / 완료:** 작업을 만든 시간과 끝난 시간이에요. 계정의 시간대 기준으로 표시돼요.
- **통계:** 통계 아이콘을 클릭하면 작업 결과를 자세히 볼 수 있어요.

**일괄 작업** 페이지는 기간, 상태, 작업 유형, 사용자로 필터링할 수 있어서 원하는 요청을 빠르게 찾을 수 있어요.

![일괄 작업 페이지](https://jumpshare.com/share/QN7nkdxf16ewjLGNWkrc+/Screen+Shot+2026-03-30+at+23.32.56.png)

## 자주 묻는 질문

### 태그 말고 다른 필드로도 연락처를 필터링할 수 있나요?

네. **상세 필터**에서는 이메일, 도시, 연락처 소스, 생성일, 기회 단계 등 모든 연락처 필드와 커스텀 필드로 필터링할 수 있어요. 필터를 여러 개 합치거나 중첩 필터를 써서 등록할 연락처를 정확하게 골라 보세요.

### 워크플로우가 게시되어 있어야 하나요?

네. **워크플로우** 드롭다운에는 게시된 워크플로우만 나와요. 이 기능을 쓰기 전에 워크플로우를 게시해 두세요.

### Send at Scheduled Time과 Send in Drip Mode는 어떻게 다른가요?

Send at Scheduled Time은 선택한 연락처를 모두 정해진 하나의 날짜와 시간에 등록해요. Send in Drip Mode는 일정한 간격으로 연락처를 나누어 등록해요. 며칠이나 몇 시간에 걸쳐 발송을 분산하고 싶을 때 유용해요.

### 일괄 작업의 진행 상황은 어디에서 확인하나요?

**연락처 > 일괄 작업**으로 이동하세요. 요청한 일괄 작업의 현재 상태, 시간 기록, 통계를 볼 수 있어요.

### 스마트 리스트 필터를 저장해 두고 다음 대량 등록에 다시 쓸 수 있나요?

네. **상세 필터**를 적용한 뒤 필터링한 화면을 스마트 리스트로 저장할 수 있어요. 같은 대상을 다시 등록해야 할 때는 그 스마트 리스트를 열고, 연락처를 선택한 다음 자동화를 트리거하면 돼요.
