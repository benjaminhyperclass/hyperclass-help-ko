# 연락처·스마트 리스트 일괄 작업 확인하기

**일괄 작업** 페이지에서 연락처 대량 작업의 진행 상태와 결과를 한곳에서 확인할 수 있어요. 하이퍼클래스의 통합 UX를 사용해 필터링이 빨라지고, 상태가 더 또렷하게 보여요. 작업별 통계와 오류 로그도 바로 열 수 있어서 결과를 점검하고, 문제를 해결하고, 삭제한 연락처를 복원할 수 있어요(복원이 가능한 경우).

## 일괄 작업 페이지란?

**일괄 작업** 페이지는 **연락처**에서 실행한 대량 작업을 모아 보여 주는 화면이에요. 가져오기, 태그 업데이트, 대량 메시지 발송, 삭제 같은 작업이 여기에 나와요. 실시간 상태와 결과 수치, 상세 로그를 볼 수 있어서 팀이 결과를 확인하고 문제를 빠르게 바로잡을 수 있어요.

각 일괄 작업은 표에 한 줄씩 표시돼요. 표에는 **Action Name**(작업 이름), **작업 유형**, **Created By**(생성한 사용자), **Created At**(생성 시각), **상태** 같은 열이 있어요. 여기서 **통계 보기**를 눌러 자세한 결과를 확인하거나, 각 행의 작업 메뉴에서 관리 옵션을 쓸 수 있어요. 일시정지와 취소는 해당 기능을 지원하는 작업에서만, 복원은 지원하는 삭제 작업에서만 쓸 수 있어요.

## 일괄 작업 페이지의 장점

이 페이지가 어떤 점에서 유용한지 알아 두면 CRM 업무에서 속도와 정확성을 높이고 책임 소재도 분명히 할 수 있어요.

- 통합 UX: 하이퍼클래스 전반과 일관된 화면이에요. 표가 깔끔하고 간격이 읽기 편하며, 조작 방식도 예측하기 쉬워요.
- 빠른 문제 해결: **통계 보기**를 열어 성공 건수와 오류 건수를 비교하고, 오류 로그를 내려받아 문제를 고칠 수 있어요.
- 안전한 운영: 지원하는 삭제 작업은 허용 기간 안에 **복원**을 요청해서 삭제한 연락처를 되살릴 수 있어요.
- 팀 단위 책임 확인: **상태**, **작업 유형**, **사용자**, **날짜**로 필터링하면 누가 언제 무엇을 했는지 볼 수 있어요.
- 이력 추적: 통계 화면에서 상세 오류 로그를 내보내 기록으로 남길 수 있어요.

## 일괄 작업 표 읽기

표를 읽는 방법과 상태 표시를 알아 두면 확인이 필요한 작업부터 살펴볼 수 있어요.

- 작업마다 한 줄씩 표시되고, **상태**가 함께 나와요. 예를 들어 **In Progress**(진행 중), **Completed**(완료), **Canceled**(취소됨)가 있어요.
- 상태 배지는 색으로 구분돼요. 마우스를 올리면 긴 작업 이름이나 건수가 툴팁으로 보일 수 있어요.
- 각 행의 점 세 개(⋮) 메뉴에서 쓸 수 있는 기능을 확인하세요. 예를 들어 대량 발송은 일시정지·취소를, 해당되는 작업은 복원을 쓸 수 있어요.

## 필터로 일괄 작업 빠르게 찾기

필터를 쓰면 원하는 작업만 골라 볼 수 있어요. 감사 업무를 하거나, 여러 팀원이 매일 작업을 실행할 때 특히 편해요.

- **상태**: **In Processing**(처리 중), **Complete**(완료), **Paused**(일시정지됨), **Queued**(대기 중), **Cancelled**(취소됨) 중에서 골라 볼 수 있어요.
- **작업 유형**: **가져오기**, **연락처 삭제**, **태그 추가**, **태그 제거**, **대량 SMS**, **Bulk Email**(대량 이메일)처럼 특정 작업만 볼 수 있어요.
- **사용자**: 특정 팀원이 실행한 작업을 볼 수 있어요.
- **날짜 범위**: 원하는 날짜를 직접 지정해요.

## 작업 통계 확인하고 오류 로그 내려받기

통계를 보면 일괄 작업에서 어떤 일이 있었는지 한눈에 알 수 있어요. 오류 로그를 내려받으면 문제를 고친 뒤 깔끔하게 다시 실행하기 쉬워요.

- 원하는 행에서 **통계 보기**를 클릭하면 상세 패널이 열려요. 전체 건수, 성공·오류 건수 같은 주요 수치가 나오고, 메시지 발송 작업이라면 발송 결과도 함께 볼 수 있어요.
- 통계 화면의 **다운로드**를 눌러 문제 해결용 오류 로그를 내보내세요. 로그에는 보통 실패한 항목을 구분하는 정보와, 조치할 수 있는 실패 사유가 담겨 있어요.

## 삭제한 연락처 복원하기 (일괄 삭제 작업)

**복원**은 실수로 삭제한 연락처를 되살리기 위한 기능이에요. 다른 종류의 일괄 작업을 되돌리는 용도는 아니에요.

- **연락처 삭제** 일괄 작업이 복원 대상이면 **복원** 옵션이 보여요. 선택하면 무엇이 되살아나는지 설명하는 확인 창이 열려요.
- 시점: 삭제한 연락처는 보통 삭제 후 약 60일 안에 복원할 수 있어요. 이 기간이 지나면 복구할 수 없어요.
- 확인 창에서 제출하면 새 복원 작업이 대기열에 추가돼요. 이 작업은 **일괄 작업** 표에 나타나고 끝까지 실행돼요.

{% hint style="info" %}
연락처 삭제에 대한 자세한 내용은 [연락처와 데이터 삭제하기](스마트-리스트/how-to-delete-contacts-and-their-data.md)를 참고하세요.
{% endhint %}

## 실행 중인 작업 관리하기 (일시정지·취소)

SMS 캠페인 같은 일부 대량 발송은 대기열에 올라간 뒤에도 일시정지하거나 취소할 수 있어요. 계획이 바뀌어도 대응할 수 있어요.

- 실행 중이고 해당 기능을 지원하는 작업의 점 세 개(⋮) 메뉴를 열면 **일시정지**, **편집**, **취소**가 보여요.
- **일시정지**는 처리를 잠시 멈춰요. **취소**는 남은 처리를 중단해요. **편집**은 해당 일괄 작업의 예약된 시간을 바꿀 수 있어요. 이미 처리된 항목은 그대로 유지돼요.
- 변경한 뒤에는 **일괄 작업** 표를 새로고침하고 **통계 보기**를 열어, 변경 전에 어디까지 처리됐는지 확인하세요.

## 일괄 작업 페이지 사용 순서

따로 설정할 항목은 없어요. 아래 순서대로 따라 하면 결과를 확인하고 이력을 깔끔하게 관리할 수 있어요.

1. 서브 계정에서 **연락처 > 일괄 작업**으로 이동하세요.

   ![연락처 일괄 작업 메뉴로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055926761/original/3-Du0RWU3CiZHcBJsynlBq5OjZrSwmKpmQ.png?1760432068)
2. **필터**(상태, 작업 유형, 사용자, 날짜)를 적용해 필요한 작업만 좁혀 보세요.

   ![필터 적용](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055926877/original/2t6HETPhrVr5fUaSRtAmxFDSM_jQONs0jw.png?1760432109)
3. 작업의 **통계 보기**를 클릭해 전체 건수와 오류 내역을 확인하세요. 오류 로그는 **다운로드**로 내보낼 수 있어요.

   ![통계 보기와 다운로드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055927337/original/051_vkAbZ_-LZy_5aL2avJEW05sj4dOP-Q.png?1760432291)

   ![삭제한 연락처 복원](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155055927617/original/oDpUpugETXOHHxduwaXw60K5dHlMRiVJxw.png?1760432477)

## 자주 묻는 질문

### 일괄 작업 페이지에는 어떤 작업이 표시되나요?
**연락처**에서 실행한 대부분의 대량 작업이 표시돼요. 예를 들어 **가져오기**, **연락처 삭제**, **대량 SMS**·**Bulk Email**, **태그 추가**·**태그 제거**가 있어요. 각 작업에는 상태와 **통계 보기** 링크가 함께 나와요.

### 삭제한 연락처는 얼마 동안 복원할 수 있나요?
삭제한 날부터 약 60일 동안 복원할 수 있어요. 그 이후에는 연락처가 완전히 삭제돼요.

### 작업이 시작된 뒤에도 취소할 수 있나요?
대기 중인 대량 SMS처럼 지원하는 작업 유형은 가능해요. 해당 행의 점 세 개(⋮) 메뉴에서 **일시정지**, **편집**, **취소**를 쓸 수 있어요. 취소하기 전에 이미 처리된 항목은 완료된 상태로 남아요.

### 상세 결과는 어디서 내려받나요?
해당 작업의 **통계 보기**를 열고 **다운로드**를 누르세요. 항목별 실패 사유가 담긴 오류 로그를 내보낼 수 있어요.

### 일괄 작업 페이지는 서브 계정마다 따로 보이나요?
네. 관리하려는 서브 계정으로 들어간 다음 **연락처 > 일괄 작업**을 여세요.

### 연락처를 가져올 때 연락처가 수신에 동의했는지 왜 확인해야 하나요?
연락처의 동의를 확인하면 좋은 이유는 크게 두 가지예요.

- 발송 평판 보호: 동의 없이 연락처를 대량으로 가져오면 반송률과 스팸 신고율이 높아져서 발송 평판에 나쁜 영향을 줄 수 있어요.
- 구매하거나 대여한 목록 문제 예방: 수신 동의를 받았다고 내세우는 목록이라도 마케팅 커뮤니케이션 도구에는 적합하지 않을 수 있어요. 구매하거나 대여한 목록의 연락처는 반송되거나, 수신을 거부하거나, 이메일을 스팸으로 신고할 가능성이 높아요. 차단 목록에 오를 수도 있어요.

### 복원할 수 없는 일괄 작업에는 어떤 것이 있나요?
다음 일괄 작업은 복원할 수 없어요.

- **Bulk Email**
- **Bulk Email Verification**(대량 이메일 검증)
- **Bulk Update Contacts to Company**(연락처 회사 일괄 업데이트)
- **Bulk Tag Add**(태그 일괄 추가)
- **대량 SMS**
