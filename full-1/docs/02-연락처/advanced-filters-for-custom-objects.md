# 커스텀 오브젝트 상세 필터 사용하기

**상세 필터**를 쓰면 커스텀 오브젝트의 기본 필드와 커스텀 필드를 조합해 원하는 데이터만 골라 볼 수 있어요. 이 문서에서는 상세 필터를 열고 조건을 설정하는 방법을 단계별로 안내해요.

[동영상](https://www.youtube.com/embed/E8-R7UKaBVk?&wmode=opaque)

## 1단계. 상세 필터 패널 열기

1. **Custom Objects**(커스텀 오브젝트) 페이지 오른쪽 위에서 **상세 필터**를 찾아 클릭하세요.

![커스텀 오브젝트 페이지 오른쪽 위의 상세 필터 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035093767/original/cir1YoqcUeKeVrFyxqGcWDL22yrhQdXWhA.png?1729511738)

## 2단계. 필터 조건 설정하기

1. **상세 필터** 패널에서 필터로 쓸 필드를 검색하거나 선택하세요. **그리고**/**또는** 조건을 사용하면 검색 범위를 더 좁힐 수 있어요.
   - 검색창을 사용하면 필드를 빠르게 찾을 수 있어요.
   - **Other Details**(기타 상세 정보), **Car Info**(차량 정보), **가격** 같은 카테고리를 펼쳐 필드를 선택하세요.
   - 기본 필드와 커스텀 오브젝트 필드 모두 필터로 쓸 수 있어요.

## 3단계. 필터 적용하기

1. 복잡한 조건이 필요하면 여러 필터를 **그리고** / **또는** 조건으로 묶으세요.
2. 패널에서 필터 순서를 바꿔 한눈에 보기 좋게 정리할 수 있어요.
3. 필터를 없애려면 선택을 해제하거나 **Reset**(초기화) 버튼을 클릭하세요.
