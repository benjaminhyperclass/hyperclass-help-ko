# 연락처 하나에 이메일 주소 여러 개 관리하기

하이퍼클래스에서는 연락처 하나에 이메일 주소를 여러 개 저장할 수 있어요. 개인용, 업무용, 보조 주소를 같은 사람의 연락처에 함께 보관할 수 있습니다. 이 문서에서는 추가 이메일 입력, 기본 이메일 지정, CSV 가져오기·내보내기, 연락처 병합 시 이메일 처리, 워크플로우의 **Find Contact**(연락처 찾기) 액션으로 추가 이메일 검색하기를 안내해요.

{% hint style="warning" %}
연락처 하나에는 기본 이메일 1개와 추가 이메일 최대 10개, 총 11개까지 저장할 수 있어요. 기본 이메일로 지정할 수 있는 주소는 한 번에 하나뿐이에요.
{% endhint %}

## 연락처의 여러 이메일 주소란?

같은 사람의 연락처를 따로 만들지 않고, 한 연락처에 여러 이메일 주소를 함께 보관하는 기능이에요. 개인 주소, 업무 주소, 결제용 주소 같은 보조 주소가 있는 연락처에 유용해요.

연락처 하나에는 다음 주소를 저장할 수 있어요.

- 기본 이메일 주소 1개
- 추가 이메일 주소 최대 10개
- 이메일 주소 총 11개

기본 이메일은 연락처의 표준 **이메일** 필드에 그대로 들어가요. 추가 이메일은 연락처에 함께 연결되고, 지원되는 가져오기·병합·내보내기·워크플로우 매칭에서 쓸 수 있어요.

## 여러 이메일 주소의 장점

보조 주소를 한 연락처에 모아 두면 고객 정보를 한곳에서 관리할 수 있고, 같은 사람의 중복 연락처를 따로 관리하지 않아도 돼요.

- 연락처 프로필 하나로 관리: 개인, 업무, 결제, 보조 주소를 같은 연락처에 저장해요.
- 기본 이메일 선택: 하이퍼클래스가 연락처의 표준 이메일로 취급할 주소를 지정해요.
- 추가 이메일 가져오기: CSV 가져오기로 보조 주소를 한꺼번에 추가해요.
- 연락처 데이터 내보내기: 내보내기 전에 표시할 열을 설정해 필요한 이메일 관련 필드를 포함해요.
- 병합 시 이메일 정보 보존: 중복 연락처를 합칠 때 이메일 값을 확인하고 알맞은 기본 이메일을 선택해요.
- 워크플로우 매칭 개선: 필요할 때 **Find Contact**(연락처 찾기)가 추가 이메일 주소까지 검색하도록 설정해요.
- 연락처 데이터 집중 관리: 한 고객의 여러 식별 정보를 중복 연락처로 흩어 두지 않고 하나의 레코드에 연결해 둬요.

## 알아 두면 좋은 제한 사항

기본 이메일과 추가 이메일이 어떻게 다뤄지는지 알아 두면 메시지 발송, 연락처 가져오기, 병합, 워크플로우 설정에서 예상치 못한 결과를 피할 수 있어요.

- 연락처 하나에는 기본 이메일 1개와 추가 이메일 최대 10개를 저장할 수 있어요.
- 기본 이메일로 지정할 수 있는 주소는 한 번에 하나뿐이에요.
- 기본 이메일이 연락처의 표준 **이메일** 필드예요.
- 표준 **이메일** 필드를 기준으로 동작하는 기능은 기본 이메일을 사용해요.
- CSV로 추가 이메일을 가져올 때는 **추가 이메일** 필드를 사용해요.
- 워크플로우의 **Find Contact**(연락처 찾기) 액션은 기본적으로 기본 이메일 필드만 검색해요. 추가 이메일 매칭은 따로 켜야 해요.
- 연락처 병합은 되돌릴 수 없어요. 확정하기 전에 마스터 레코드와 이메일 값을 꼼꼼히 확인하세요.

## 추가 이메일 주소 입력하기

같은 사람이 이메일 주소를 여러 개 쓴다면 연락처 화면에서 바로 보조 주소를 추가하세요. 한 프로필에 모아 두면 그 연락처의 정보를 한곳에서 확인할 수 있어요.

1. 해당 **서브 계정 보기**를 여세요.
2. **연락처**로 이동하세요.
3. 연락처를 검색해서 여세요.
4. 연락처 세부정보에서 **이메일 주소** 영역을 찾으세요.

![연락처 세부정보의 이메일 주소 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041472605/original/bITJP2mrbC1KvRmIx9oEuo5VqcykxkkzCA.png?1739369103)

5. **Add Another Email**(이메일 추가)을 클릭하세요.
6. 추가할 이메일 주소를 입력하세요.
7. 다른 보조 주소도 추가하려면 같은 방법으로 반복하세요.
8. **변경사항 저장**을 클릭하세요.

![연락처에 이메일 주소를 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041474004/original/XkRC0hrl8_tVBuzipZdeXfYDkV6efiJ9dQ.gif?1739369907)

**제한:** 추가 이메일은 최대 10개까지 입력할 수 있어요. 제한에 도달하면 이메일을 더 추가하는 옵션이 나타나지 않아요.

## 기본 이메일 주소 지정하기

기본 이메일은 연락처의 표준 **이메일** 필드에 저장되는 주소예요. 표준 연락처 이메일 필드를 기준으로 동작하는 하이퍼클래스 기능은 이 값을 사용하므로, 알맞은 주소를 기본 이메일로 지정하는 게 중요해요.

1. 해당 연락처를 여세요.
2. **이메일 주소** 영역을 찾으세요.
3. 기본 이메일로 바꿀 주소를 찾으세요.
4. 그 주소 옆의 **별 아이콘**을 클릭하세요.

![기본 이메일을 지정하는 별 아이콘이 보이는 여러 이메일 주소 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041473131/original/nRJ6dzLuZY5BO27LiNE94ki_egdsfIoIYw.jpeg?1739369439)

{% hint style="warning" %}
기본 이메일로 지정할 수 있는 주소는 한 번에 하나뿐이에요. 캠페인, 자동화 등 표준 **이메일** 필드를 기준으로 동작하는 기능에 연락처를 사용하기 전에 선택한 주소를 확인하세요.
{% endhint %}

## 추가 이메일 주소 가져오기

많은 연락처에 보조 이메일을 한꺼번에 추가할 때는 CSV 가져오기가 편해요. 형식을 맞추고 필드를 올바르게 매핑하면 기본 이메일은 그대로 두고 추가 이메일만 저장돼요.

### 1단계: CSV 파일 준비하기

업로드하기 전에 파일을 제대로 준비하면 필드 매핑 오류를 줄이고, 여러 이메일 주소가 알맞은 연락처에 연결돼요.

1. **추가 이메일** 열을 따로 만드세요.
2. 그 열에 보조 이메일 주소를 입력하세요.
3. 한 연락처에 추가 이메일이 여러 개라면 주소를 쉼표로 구분하세요.

예시

`billing@example.com, personal@example.com, assistant@example.com`

### 2단계: 연락처 가져오기 시작하기

하이퍼클래스가 연락처 필드를 읽고 보조 이메일 열을 매핑할 수 있도록 **연락처**에서 CSV 가져오기를 시작하세요.

1. **연락처**로 이동하세요.
2. **가져오기**를 클릭하세요.
3. **CSV에서 레코드 가져오기** 아래에서 **CSV 가져오기 시작**을 클릭하세요.

![CSV 가져오기 시작 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081375487/original/knHsDOLXzfYtTNxC8xKaD0IkTshMIC_33Q.png?1789878706)

### 3단계: 파일 업로드하고 추가 이메일 매핑하기

필드 매핑은 CSV의 어느 열에 보조 주소가 들어 있는지, 그 주소를 추가 이메일로 저장해야 한다는 것을 하이퍼클래스에 알려 주는 단계예요.

1. CSV 파일을 업로드하세요.
2. 필드 매핑 단계로 넘어가세요.
3. 보조 이메일 열을 **추가 이메일**에 매핑하세요.
4. 나머지 매핑을 확인하세요.
5. 가져오기를 완료하세요.

**기존 연락처를 업데이트하나요?** 하이퍼클래스가 의도한 레코드를 찾아 업데이트하도록, 시작하기 전에 가져오기 유형과 연락처 중복 제거 설정을 확인하세요. [CSV 파일로 연락처 가져오기](../importing-contacts-using-a-csv-file.md)와 [객체 가져오기용 CSV 파일 형식](csv-file-format-for-importing-objects.md)을 참고하세요.

## 연락처 이메일 데이터 내보내기

연락처를 내보내면 **연락처** 표에 현재 표시된 필드가 CSV에 담겨요. 필요한 이메일 정보가 포함되도록 내보내기 전에 표의 필드를 설정하세요.

1. **연락처 > 스마트 리스트**로 이동하세요.
2. 내보낼 연락처를 필터링하거나 선택하세요.
3. **필드 관리**를 여세요.
4. 필요한 이메일 관련 열이 **연락처** 표에 보이도록 설정하세요.
5. 연락처를 선택하세요.
6. **내보내기**를 클릭하거나 연락처 작업에서 해당하는 내보내기 옵션을 사용하세요.
7. 내보내기를 확인하세요.

하이퍼클래스는 연락처 내보내기를 백그라운드에서 처리해요. 완료된 일괄 작업은 **일괄 작업** 영역에서 확인할 수 있어요.

{% hint style="info" %}
내보내기를 시작하기 전에 **연락처** 표에 표시된 필드를 확인하세요. 그래야 CSV에 필요한 연락처 정보가 담겨요. [하이퍼클래스에서 연락처를 CSV로 내보내기](../일괄-작업/contacts-export-as-csv-upgrade.md)를 참고하세요.
{% endhint %}

## 연락처를 병합할 때 여러 이메일이 처리되는 방식

중복 연락처를 병합하면 지원되는 정보가 **마스터** 레코드 하나로 합쳐져요. 병합 화면에서 값이 서로 다른 항목을 확인하고, 합치기 전에 어떤 정보를 남길지 정할 수 있어요.

### 1단계: 중복 연락처 선택하기

**스마트 리스트**에서 시작하면 중복된 연락처를 선택하고 병합 작업을 열 수 있어요.

1. **연락처 > 스마트 리스트**로 이동하세요.
2. 중복 연락처를 찾으세요.
3. 합칠 연락처를 선택하세요.
4. **더보기**를 클릭하세요.
5. **병합**을 선택하세요.

![스마트 리스트에서 연락처를 선택하고 병합을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081375486/original/QGYmYA-FgtgGaogu1nS1SGK7-homOI-QBw.png?1789878692)

### 2단계: 병합 내용 검토하기

**연락처 병합** 화면에서 **마스터** 레코드를 고르고, 값이 서로 다른 필드를 확인한 뒤 병합을 완료하세요.

1. 어떤 연락처를 **마스터**로 남길지 선택하세요.
2. 값이 서로 다른 필드를 확인하세요.
3. 선택할 수 있는 **이메일 주소** 값을 확인하세요.
4. 병합된 레코드에 남길 값을 선택하세요.
5. 기본 이메일로 남길 주소를 확인하세요.

![병합할 연락처의 값을 비교하는 연락처 병합 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081375479/original/_AVrmC0lm6JfyYpYqooKEm1pEvAhkx5hlw.png?1789878678)

### 3단계: 병합 완료하기

알맞은 **마스터** 레코드와 필드 값을 선택했다면, 병합을 완료해서 지원되는 정보를 연락처 하나로 합치세요.

1. 선택한 내용을 마지막으로 한 번 더 확인하세요.
2. **연락처 병합**을 클릭하세요.

{% hint style="warning" %}
연락처 병합은 되돌릴 수 없어요. **연락처 병합**을 클릭하기 전에 **마스터** 레코드, 이메일 주소, 값이 서로 다른 필드를 꼼꼼히 확인하세요.
{% endhint %}

병합 전체 과정은 [중복 연락처 관리 및 병합하기](how-to-manage-and-merge-duplicate-contacts.md)를 참고하세요.

## 워크플로우에서 추가 이메일로 연락처 찾기

워크플로우의 **Find Contact**(연락처 찾기) 액션은 기본적으로 연락처의 기본 이메일 필드만 검색해요. 일치하는 이메일이 추가 이메일로 저장된 연락처까지 찾으려면 추가 이메일 매칭을 켜세요.

1. **자동화 > 워크플로우**로 이동하세요.
2. 기존 워크플로우를 열거나 새로 만드세요.
3. **Find Contact**(연락처 찾기) 액션을 추가하세요.
4. 매칭에 사용할 표준 필드에서 **Email**(이메일)을 선택하세요.
5. 추가 이메일을 검색에 포함하는 옵션을 켜세요.
6. 나머지 **Find Contact** 설정을 완료하세요.
7. 액션을 저장하세요.

이 옵션을 켜면 해당 이메일이 연락처의 기본 이메일이 아니라 추가 이메일로 저장되어 있어도 **Find Contact**가 일치하는 연락처를 찾아요. [워크플로우 액션 - Find Contact](../../07-워크플로우/Contact-Workflow-Actions/workflow-action-find-contact.md)를 참고하세요.

## 자주 묻는 질문

### 연락처 하나에 이메일 주소를 몇 개까지 저장할 수 있나요?
기본 이메일 1개와 추가 이메일 최대 10개, 총 11개까지 저장할 수 있어요.

### 기본 이메일을 바꿀 수 있나요?
네. 연락처의 **이메일 주소** 영역에서 기본 이메일로 바꿀 주소 옆의 별 아이콘을 클릭하세요.

### 표준 이메일 필드를 쓰는 기능은 어떤 이메일을 사용하나요?
기본 이메일이 연락처의 표준 **이메일** 필드에 저장돼요. 이 필드를 기준으로 동작하는 기능은 기본 이메일을 사용해요.

### 연락처 하나에 이메일 주소 여러 개를 가져올 수 있나요?
네. **추가 이메일** 열에 보조 주소를 입력하고, 여러 개라면 쉼표로 구분하세요. 그다음 가져오기 중에 그 열을 **추가 이메일**에 매핑하세요.

### 연락처의 이메일 정보를 내보낼 수 있나요?
네. 연락처를 내보내면 **연락처** 표에 포함된 필드가 담겨요. 필요한 이메일 정보가 들어 있는지 내보내기 전에 표시된 필드를 확인하세요.

### Find Contact로 추가 이메일 주소도 검색할 수 있나요?
네. **Find Contact**(연락처 찾기)는 기본적으로 기본 이메일 필드를 확인해요. 매칭 필드로 **Email**(이메일)을 선택했다면, 추가 이메일을 검색에 포함하는 옵션을 켜세요.

### 중복 연락처를 병합하면 이메일 주소는 어떻게 되나요?
**연락처 병합** 화면에서 레코드를 합치기 전에 서로 다른 값을 확인할 수 있어요. **마스터** 연락처를 고르고, 선택할 수 있는 이메일 주소를 확인한 뒤, 기본 이메일로 남길 주소를 확정하세요.

### 이메일을 잘못 선택했을 때 연락처 병합을 취소할 수 있나요?
아니요. 연락처 병합은 되돌릴 수 없어요. 확정하기 전에 **마스터** 연락처와 이메일 값을 꼼꼼히 확인하세요.
