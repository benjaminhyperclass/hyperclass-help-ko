# 연락처 생년월일 필드 활용하기

연락처의 생년월일 필드를 쓰면 메시지를 개인화하고, 생일을 기준으로 자동화 캠페인을 만들고, **스마트 리스트**에서 연령별로 연락처를 걸러 낼 수 있어요. 이 문서에서는 생년월일 필드를 효과적으로 사용하는 방법을 안내해요.

## 생년월일 필드란?

연락처의 생년월일 필드는 연락처 기록 안에 생일을 저장해 두는 필드예요. 값이 채워져 있으면 워크플로우, 스마트 리스트 등에서 이 값을 활용해 메시지를 개인화하고 연령 기준으로 연락처를 정리할 수 있어요.

생년월일 값은 다음 방법으로 채울 수 있어요.

- 직접 입력
- **폼 제출**
- CSV 가져오기
- API 연동

이 필드를 쓰면 생일을 기준으로 자동화 트리거를 실행하고, 연락처를 연령별로 나눌 수 있어요.

![연락처의 생년월일 필드 화면](https://jumpshare.com/share/YVNFnL3hzfETUryTwl5I+/Screen+Shot+2026-06-15+at+19.13.54.png)

---

## 생년월일 필드의 장점

- 개인화된 소통: 생일 축하 메시지와 특별 혜택을 자동으로 보낼 수 있어요.
- 워크플로우 자동화: 생일을 기준으로 알림과 캠페인을 실행할 수 있어요.
- 대상 세분화: 연령 기준 필터로 스마트 리스트를 만들 수 있어요.
- 더 나은 고객 경험: 시기에 맞는 메시지를 보낼 수 있어요.

---

## 생일 알림 캠페인 만들기

생일 워크플로우를 설정하면 생일 알림이나 혜택 발송을 자동화할 수 있어요.

### 1단계: 생일 트리거 설정

1. **워크플로우** > **Create New Workflow**(새 워크플로우 만들기)로 이동하세요.
2. **트리거**를 **Birthday Reminder**(생일 알림)로 설정하세요.
3. 트리거 조건을 선택하세요.

   - **After no. of days**(지정한 일수 후)
   - **Before no. of days**(지정한 일수 전)
   - **Day is**(일 지정)
   - **Month is**(월 지정)

![생일 알림 트리거 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047948330/original/A-EJmS-eU8slwJQO8xWd4wXGOcnUm1t4yg.gif?1749477876)

### 2단계: 액션 정하기

- **이메일 보내기**: 개인화된 생일 인사나 혜택을 보내요.
- **SMS 전송**: 짧은 생일 축하 문구나 쿠폰 코드를 보내요.
- **작업 할당**: 필요하면 내부 팀이 직접 후속 조치를 하도록 알려요.

![워크플로우 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047948420/original/dY-FvszUwlOsrnpiCsrWVS72Ety5D6TVsw.gif?1749478000)

### 워크플로우 구성 예시

| 단계 | 동작 |
| --- | --- |
| 1 | 생일에 트리거 실행 |
| 2 | 생일 SMS 보내기 |
| 3 | 생일 이메일 보내기 |
| 4 | (선택) 내부 팀에 알림 |

트리거 설정에 대한 자세한 내용은 [워크플로우 트리거 — Birthday Reminder(생일 알림)](../../07-워크플로우/Contact-Workflow-Triggers/workflow-trigger-birthday-reminder.md)를 참고하세요.

## 스마트 리스트에서 생년월일로 연락처 필터링하기

생년월일 필드를 사용하면 연락처를 생일 기준으로 나눠서 대상에 맞는 메시지를 보낼 수 있어요.

1. **연락처** > **스마트 리스트**로 이동하세요.
2. **상세 필터**를 클릭하세요.
3. 연락처 정보 항목에서 **생년월일** 필터를 선택하세요.
4. 알맞은 필터 조건을 선택하세요.

   - **Today**(오늘)
   - **Tomorrow**(내일)
   - **Yesterday**(어제)
   - **This week**(이번 주)
   - **This month**(이번 달)
   - **이번 분기**
   - **In month**(특정 월)
   - **This year**(올해)
   - **On**(특정 날짜)
   - **Between**(두 날짜 사이)
   - **More than**(초과)
   - **After date**(지정일 이후)
   - **Less than**(미만)
   - **Before date**(지정일 이전)
   - **In the next**(앞으로 지정 기간 이내)
   - **In the last**(지난 지정 기간 이내)

![생년월일 필터 조건 선택 화면](https://jumpshare.com/share/QdGpRnhsNDlSwzfEci1c+/GIF+Recording+2026-06-15+at+19.26.19.gif)

## 스마트 리스트에서 연령으로 연락처 필터링하기

연령 필드를 사용하면 연락처를 나이 기준으로 나눠서 대상에 맞는 메시지를 보낼 수 있어요.

1. **연락처** > **스마트 리스트**로 이동하세요.
2. **상세 필터**를 클릭하세요.

   ![상세 필터 클릭 화면](https://jumpshare.com/share/u3mx4bfTvGCFM0HM0XfA+/Screen+Shot+2026-06-15+at+19.45.08.png)
3. 연락처 정보 항목에서 **연령** 필터를 선택하세요.
4. 알맞은 필터 조건을 선택하세요.

   - **Equals to**(같음)
   - **Between**
   - **More than**
   - **Less than**
5. **저장**을 클릭하세요.

시스템은 현재 날짜와 저장된 생일을 기준으로 연령을 자동으로 계산해요.

![연령 필터 설정 화면](https://jumpshare.com/share/lag30Pty4c2vTehB76Tf+/GIF+Recording+2026-06-15+at+20.19.44.gif)

## 활용 팁

- 생일 정보는 미리 받아 두세요: 리드 수집 폼에 생년월일 필드를 넣어 처음부터 정보를 받아 두세요.
- 날짜 형식을 확인하세요: 자동화 트리거가 제대로 작동하도록 MM/DD/YYYY 형식을 사용하세요.
- 자동화를 테스트하세요: 생일 워크플로우를 실제로 켜기 전에 항상 샘플 연락처로 먼저 테스트하세요.
- 시간대를 고려하세요: 설정에 따라 워크플로우가 연락처별 시간대를 쓸 수 있어요.

## 자주 겪는 문제와 해결 방법

| 문제 | 해결 방법 |
| --- | --- |
| 생일 자동화가 실행되지 않아요 | 생년월일 필드에 올바른 형식의 날짜가 빠짐없이 입력되어 있는지 확인하세요. |
| 연령이 잘못 계산돼요 | 출생 연도가 올바르게 입력되어 있는지 확인하세요. 연도가 없거나 틀리면 오류가 생길 수 있어요. |
| 생일에 SMS나 이메일이 발송되지 않았어요 | 워크플로우 발송 시점, 트리거 설정, 연락처의 시간대 설정을 다시 확인하세요. |

## 자주 묻는 질문

### 생년월일 필드로 생일 메시지를 자동으로 보낼 수 있나요?

네. 워크플로우에서 생년월일 필드를 사용해 생일 관련 자동화를 실행할 수 있어요. 이메일이나 SMS 발송, 알림, 태그 추가 등이 가능해요.

### 생일 워크플로우가 작동하려면 연락처에 생년월일 값이 꼭 있어야 하나요?

네. 생일 기반 워크플로우에는 연락처 기록에 올바른 생년월일 값이 필요해요. 필드가 비어 있거나 값이 올바르지 않으면 워크플로우가 의도한 대로 실행되지 않아요.

### 연락처 연령을 기준으로 스마트 리스트를 만들 수 있나요?

네. 스마트 리스트 필터에서 생년월일 필드를 사용하면 연령대별 대상 그룹을 만들 수 있어요.

### 생일 워크플로우가 실행되지 않아요

연락처에 올바른 생년월일 값이 있는지 확인하세요. 워크플로우 트리거가 제대로 설정되어 있는지, 워크플로우가 활성 상태이고 게시되어 있는지도 확인하세요.

### 연령 기준 스마트 리스트 결과가 잘못 나와요

해당 연락처의 생년월일 값을 확인하고, 스마트 리스트 필터가 올바르게 설정되어 있는지 점검하세요. 가져온 데이터에 형식 문제가 없는지도 확인하세요.

### 생일이 포함된 연락처를 가져올 때 무엇을 주의해야 하나요?

일관된 날짜 형식을 사용하고, 생년월일 값이 올바르게 가져와졌는지 확인하세요. 데이터가 정확해야 워크플로우와 스마트 리스트 필터가 기대한 대로 작동해요.
