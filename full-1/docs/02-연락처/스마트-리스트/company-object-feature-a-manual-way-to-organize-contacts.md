# 회사 오브젝트로 연락처를 회사별로 직접 묶어 관리하기

회사 오브젝트(Company Object)를 쓰면 같은 회사에 속한 연락처를 하나의 회사 프로필 아래에 묶을 수 있어요. 같은 고객사를 여러 팀이 함께 상대할 때 관계 관리, 연락처 정리, 활동 추적이 더 쉬워져요.

## 회사 오브젝트란?

회사 오브젝트는 여러 연락처를 하나의 회사에 연결하는 기능이에요. 조직 단위로 고객 관계를 관리하기 쉬워져요. 같은 회사의 여러 사람과 소통하는 팀에 특히 유용해요. 연락처를 하나의 레코드로 묶으면 회사 전체의 참여 현황을 보고, 데이터를 한곳에 모으고, 접점마다 일관되게 소통할 수 있어요.

## 회사 오브젝트의 주요 장점

- 연락처 정리: 여러 연락처를 한 회사 아래에 쉽게 묶을 수 있어요.
- 활동 통합 추적: 회사와 관련된 상호작용과 활동을 한눈에 살펴볼 수 있어요.
- 관계 파악: 우리 팀이 한 조직과 어떻게 소통하고 있는지 전체 모습을 볼 수 있어요.
- 효율적인 소통: 회사에 연결된 모든 연락처와 쉽게 소통할 수 있어요.
- 데이터 정확도 향상: 같은 회사에 속한 연락처의 정보를 일관되고 최신으로 유지할 수 있어요.

## 회사 만들기

하이퍼클래스에서 새 회사를 만드는 방법이에요.

### 1단계: 회사 화면으로 이동하기

1. 왼쪽 메뉴에서 **연락처**를 클릭하세요.
2. 화면 위쪽 보조 메뉴에서 **회사** 탭을 클릭하세요.

![연락처 메뉴의 회사 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041969865/original/afPxEFXXuOBxnAqTaV3LFBqNvqJ_8oglww.png?1740065034)

### 2단계: 새 회사 추가하기

1. 오른쪽 위의 파란색 **+ New Company**(+ 새 회사) 버튼을 클릭하세요.

![새 회사 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041969989/original/h0xP2Ge9B26gWwWxU6549DHsoSBCwKFHVA.png?1740065114)

### 3단계: 회사 정보 입력하기

화면 오른쪽 입력창에 회사 정보를 입력하세요. 입력할 수 있는 항목은 다음과 같아요.

- **회사명** (필수)
- **전화번호**
- **이메일**
- **웹사이트**
- **설명**
- **주소 상세정보** (거리, 도시, 우편번호, 국가)

{% hint style="info" %}
필수 항목은 회사명뿐이에요. 다른 정보도 함께 입력해 두면 더 편하게 쓸 수 있어요.
{% endhint %}

![회사 정보를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155041970367/original/LbLWS8aCQVKZDC4wUpWeqzJFaU4RmCQzJg.gif?1740065352)

## 회사 정보 수정하기

1. 회사 목록으로 이동해요.
   - 왼쪽 메뉴에서 **연락처**를 클릭하세요.
   - 위쪽 메뉴에서 **회사** 탭을 선택하세요.
   - 수정할 회사 옆의 점 세 개(`...`) 아이콘을 클릭하고 **회사 수정**을 선택하세요.
2. 정보를 수정해요.
   - 바꿀 항목을 수정하세요.
3. 변경사항을 저장해요.
   - **저장**을 클릭하면 수정 내용이 적용돼요.

## 회사 삭제하기

1. 회사 목록으로 이동해요.
   - 왼쪽 메뉴에서 **연락처**를 클릭하세요.
   - 위쪽 메뉴에서 **회사** 탭을 선택하세요.
2. 삭제할 회사를 선택해요.
   - 삭제할 회사 옆의 점 세 개(`...`) 아이콘을 클릭하고 **회사 삭제**를 선택하세요.
3. 삭제를 확인해요.
   - **Yes**(예)를 클릭하면 삭제돼요.

{% hint style="info" %}
회사를 삭제하면 연결된 연락처의 **회사** 필드는 비워지지만, 연락처 자체는 삭제되지 않아요.
{% endhint %}

## 회사에 연락처 추가하기

1. 연락처 프로필로 이동해요.
   - 왼쪽 메뉴에서 **연락처**를 클릭하세요.
   - 회사에 추가할 연락처를 찾아 이름을 클릭하세요.
2. 회사를 지정해요.
   - 페이지 왼쪽 보조 메뉴에서 **회사** 탭을 선택하세요.
   - 회사를 검색해서 선택하세요.
3. 변경사항을 저장해요.
   - **저장**을 클릭하면 연락처와 회사의 연결이 업데이트돼요.

{% hint style="info" %}
여러 연락처를 한꺼번에 지정하려면, 연락처를 여러 개 선택한 뒤 한 번에 회사에 지정하세요.
{% endhint %}

![연락처 프로필에서 회사를 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155045226266/original/hB0MXzNuW4JiT_N6tcQE2IUWCEYF2s689Q.jpeg?1744827285)

## 회사에서 연락처 제거하기

1. 회사 프로필을 열어요.
   - 왼쪽 메뉴에서 **연락처**를 클릭하세요.
   - 위쪽 메뉴에서 **회사** 탭을 선택하세요.
   - 회사를 선택하세요.
2. 연결된 연락처를 확인해요.
   - **연락처** 탭으로 이동하세요.
3. 연락처를 제거해요.
   - 연락처 옆의 **Trash Bin**(휴지통) 아이콘을 클릭하세요.
4. 제거를 확인해요.
   - **Yes**(예)를 클릭하면 마무리돼요.

{% hint style="info" %}
회사에서 연락처를 제거해도 연락처는 삭제되지 않아요. 회사와의 연결만 해제돼요.
{% endhint %}

{% hint style="info" %}
회사 연결 자동화: 하이퍼클래스는 회사 지정을 간편하게 해 주는 자동화 기능을 제공해요. 자세한 내용은 [회사 오브젝트 자동화](../../11-설정/company-object-automation.md) 문서를 참고하세요.
{% endhint %}

## 연락처를 회사에 자동으로 연결하기

연락처의 **사업자명** 필드를 기준으로 이 과정을 자동화할 수 있어요.

켜는 방법은 다음과 같아요.

1. **설정 > 오브젝트 > 회사**로 이동하세요.
2. **Automatically Create and Associate Companies from Contact Business Names**(연락처 사업자명으로 회사를 자동 생성하고 연결) 토글을 켜세요.

{% hint style="info" %}
자세한 내용은 [회사 오브젝트 자동화](../../11-설정/company-object-automation.md) 문서를 참고하세요.
{% endhint %}

## 자주 묻는 질문

### 연락처 하나에 회사를 여러 개 지정할 수 있나요?
아니요. 연락처 하나는 한 번에 한 회사에만 연결할 수 있어요.

### 회사를 삭제하면 그 회사의 연락처도 모두 삭제되나요?
아니요. 회사와의 연결만 해제돼요. 연락처는 그대로 남아 있어요.

### 연락처를 여러 개 한꺼번에 회사에 지정할 수 있나요?
네. 연락처 목록에서 연락처를 여러 개 선택한 뒤 한 번에 회사에 지정할 수 있어요.

### 특정 회사에 연결된 연락처를 모두 보려면 어떻게 하나요?
**연락처 > 회사**로 이동해 회사를 선택한 다음 **연락처** 탭을 확인하세요.

### 직접 지정하지 않고 연락처와 회사를 자동으로 연결할 수 있나요?
네. **설정 > 오브젝트 > 회사**에서 **Automatically Create and Associate Companies from Contact Business Names**(연락처 사업자명으로 회사를 자동 생성하고 연결)를 켜세요.
