# 사용자 지정 객체 템플릿으로 CRM 한 번에 설정하기

사용자 지정 객체 템플릿을 쓰면 업종에 맞는 CRM 구조를 처음부터 만들지 않고 바로 시작할 수 있어요. 템플릿마다 바로 쓸 수 있는 사용자 지정 객체, 폴더로 묶인 필드, 연결(Association)이 들어 있어요. 템플릿은 **템플릿 라이브러리**에서 찾을 수 있고, 적용하기 전에 미리 볼 수 있어요.

## 사용자 지정 객체 템플릿이란?

사용자 지정 객체 템플릿은 자주 쓰는 업종과 용도에 맞춰 미리 만들어 둔 설정이에요. 어떤 오브젝트, 필드, 폴더, 연결을 만들지 직접 정하지 않아도 돼요. 준비된 구조로 시작한 다음, 내 비즈니스에 맞게 고치면 됩니다.

사용자 지정 객체는 연락처, 회사, 기회 같은 기본 CRM 레코드에 딱 맞지 않는 비즈니스 데이터를 관리할 때 써요. 템플릿은 업종별로 자주 쓰는 업무 흐름을 바탕으로 이 설정을 더 빠르게 할 수 있게 해 줘요.

사용자 지정 객체 템플릿은 하이퍼클래스의 다른 템플릿 모듈과 함께 **템플릿 라이브러리**에 있어요. 지원하는 업종을 둘러보고, 템플릿 상세 내용을 미리 확인한 뒤, 사용자 지정 객체를 만들 때 적용할 수 있어요.

## 사용자 지정 객체 템플릿의 장점

사용자 지정 객체 템플릿을 쓰면 업종별 업무 방식에 맞는 유연함은 그대로 두고, 구조화된 CRM을 더 빨리 시작할 수 있어요.

- 빠른 설정: 사용자 지정 객체, 필드, 폴더, 연결을 하나씩 만들 필요 없이 한 번에 만들 수 있어요.
- 업종별 시작점: 부동산, 보험, 자동차, SaaS, 이벤트, 반려동물, **홈 서비스** 등 흔한 업종에 맞춘 템플릿 중에서 고를 수 있어요.
- 쉬운 데이터 정리: 미리 정의된 필드와 폴더로 관련 정보를 한곳에 모아 둘 수 있어요.
- 기본 제공 관계 설정: 템플릿에 연결이 들어 있을 수 있어서, 회사·기회·사용자 지정 객체의 레코드를 서로 이어 줄 수 있어요.
- 적용 전 미리보기: 템플릿을 쓰기 전에 오브젝트, 필드, 연결, 설명, 태그, 사전 조건을 확인할 수 있어요.
- 에이전시의 공개 범위 관리: 에이전시 관리자는 템플릿 라이브러리 공개 범위 설정으로 서브 계정에 보여 줄 템플릿 모듈이나 카테고리를 정할 수 있어요.

## 에이전시의 사용자 지정 객체 템플릿 공개 범위 설정

이 기능은 에이전시 관리자만 쓸 수 있어요.

공개 범위 설정을 쓰면 서브 계정마다 **템플릿 라이브러리**를 필요한 내용 위주로 정리할 수 있어요. 에이전시가 특정 분야의 고객만 상대할 때, 고객이나 팀원에게 관련 있는 템플릿 카테고리만 보여 주고 싶다면 유용해요.

에이전시 관리자는 기존 **템플릿 라이브러리** 공개 범위 설정으로 사용자 지정 객체 템플릿의 공개 여부를 관리할 수 있어요.

이 설정으로 특정 서브 계정이나 제품 영역에서 템플릿 접근을 보이게 하거나 숨길 수 있어요. **템플릿 라이브러리** 접근을 숨기면 새 템플릿을 둘러보거나 가져올 수 없어요. 이미 템플릿으로 만든 자산은 계속 편집할 수 있어요.

## 사용자 지정 객체 템플릿 사용하기

사용자 지정 객체 템플릿을 적용하면 CRM 설정의 출발점이 될 오브젝트 구조가 계정에 만들어져요. 적용하기 전에 템플릿을 미리 보면 오브젝트, 필드, 연결이 내 업무 방식에 맞는지 확인할 수 있어요.

1. 서브 계정에서 **설정**으로 이동하세요.

   ![설정 메뉴로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070636537/original/sXcWd7eHIOiJoy8_znMI3EwAzEd2T5dmng.png?1777997853)
2. 왼쪽 메뉴에서 **오브젝트**를 선택하세요.

   ![왼쪽 메뉴에서 오브젝트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070636820/original/cJV3hneMHx-DSsJ8M7VFbvEIqaTW3l__lw.png?1777997897)
3. **사용자 지정 객체 추가**를 클릭해 새 사용자 지정 객체를 만드세요.

   ![사용자 지정 객체 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070636918/original/kmn_GITsAuxr05FWMymgktdzZXtkblrZvw.png?1777997966)
4. 템플릿으로 객체를 만들려면 **템플릿 사용**을 선택하세요.

   ![템플릿 사용 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070636989/original/OXeI7mUsVwJK2eLeMtVuQRkUZLZQLHmu_w.png?1777998028)
5. 사용할 수 있는 사용자 지정 객체 템플릿을 둘러보세요.

   ![사용 가능한 템플릿 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070637029/original/rU5U8NMIL0UICYNHFto_J7ElAcNokJBwZw.png?1777998092)
6. 내 업종이나 용도에 맞는 템플릿을 선택하세요.
7. 템플릿 미리보기에서 오브젝트, 필드, 연결, 설명, 태그, 사전 조건을 확인하세요.
8. **오브젝트 가져오기**를 클릭해 템플릿을 적용하세요.

   ![오브젝트 가져오기로 템플릿 적용](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070637228/original/jBrh_USg27JMXRjZuuyCyimWP3Wnr6F6jA.gif?1777998206)
9. 만들어진 사용자 지정 객체를 확인하고, 필요한 부분을 고치세요.

템플릿을 적용한 뒤에는 만들어진 오브젝트, 필드, 연결이 내 업무 흐름에 맞는지 확인하세요. 사용자 지정 객체는 **설정**의 **오브젝트** 화면에서 관리할 수 있고, 연결은 오브젝트의 연결 설정에서 확인할 수 있어요.

## 자주 묻는 질문

### 사용자 지정 객체 템플릿을 적용하면 레코드도 자동으로 만들어지나요?
사용자 지정 객체 템플릿은 사용자 지정 객체, 필드, 폴더, 연결 같은 CRM 구조를 만들어 줘요. 현재 릴리스 노트에는 고객 레코드나 샘플 레코드를 가져온다는 설명이 없어요.

### 템플릿을 적용한 뒤에 수정할 수 있나요?
**설정**의 **오브젝트** 화면에서 사용자 지정 객체를 관리할 수 있어요. 템플릿을 적용한 뒤 만들어진 오브젝트, 필드, 연결을 확인하고, 업무 방식에 맞게 고치세요.

### 사용자 지정 객체 템플릿을 적용하면 기존 사용자 지정 객체가 덮어써지나요?
릴리스 노트에는 템플릿이 기존 사용자 지정 객체를 덮어쓴다는 내용이 없어요. 적용하기 전에 템플릿 미리보기를 확인하고, 적용한 뒤에 만들어진 설정을 점검하세요.

### 에이전시 관리자가 서브 계정에 사용자 지정 객체 템플릿을 숨길 수 있나요?
네. 사용자 지정 객체 템플릿은 기존 **템플릿 라이브러리** 공개 범위 설정을 따르기 때문에, 에이전시 관리자가 서브 계정의 접근을 관리할 수 있어요.

### 이미 사용한 템플릿을 숨기면 어떻게 되나요?
템플릿으로 이미 만든 자산은 나중에 새 템플릿 둘러보기나 가져오기가 제한되더라도 계속 편집할 수 있어요.

### 사용자 지정 객체 템플릿에 연결도 들어 있나요?
네. 템플릿에 연결이 들어 있을 수 있어서, 회사·기회·사용자 지정 객체처럼 관련된 레코드를 서로 이을 수 있어요.

### 사용자 지정 객체 템플릿에 워크플로우나 샘플 데이터도 포함되나요?
현재 릴리스에는 포함되지 않아요. 제공된 릴리스 노트 기준으로 워크플로우와 샘플 데이터는 이후 단계에서 지원할 예정이에요.

### 직접 사용자 지정 객체 템플릿을 만들어 저장할 수 있나요?
현재 릴리스에서는 할 수 없어요. 제공된 릴리스 노트 기준으로 사용자가 만든 템플릿은 이후 단계에서 지원할 예정이에요.

### 현재 지원하는 업종은 무엇인가요?
현재 템플릿은 부동산, 보험, 자동차, SaaS, 이벤트, 반려동물, **홈 서비스** 업종을 지원해요.
