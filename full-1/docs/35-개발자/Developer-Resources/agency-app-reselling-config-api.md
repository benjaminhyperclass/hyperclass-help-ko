# 에이전시 앱 리셀링 설정 API

에이전시가 설정한 앱 판매 가격(마크업 적용 가격)을 맞춤 요금제 카드, 유료 전용 화면, 결제 흐름 안에 그대로 보여 주는 API예요. 하이퍼클래스가 서브 계정별로 저장한 리빌링 설정을 가져오면, 어디에서 판매하든 고객에게 항상 올바른 화이트라벨 가격을 보여 줄 수 있어요.

## 에이전시 앱 리셀링 설정 API란?

에이전시 앱 리셀링 설정 API의 정식 이름은 Get Rebilling Config for App 엔드포인트예요. 마켓플레이스 개발자가 쓰는 REST 엔드포인트로, 에이전시가 특정 앱에 정해 둔 고객용 최종 가격을 돌려줘요.

서브 계정 OAuth 토큰으로 호출하면 현재 유효한 구독, 일회성, 사용량 기반 요금을 모두 응답해요. 이 값으로 마켓플레이스 및 에이전시의 내부 청구 규칙과 같은 가격을 화면에 보여 줄 수 있어요.

## 이 API의 장점

- 직접 만든 화면과 하이퍼클래스 마켓플레이스의 가격이 서로 다르게 표시되는 문제를 막아 줘요.
- 내부 원가는 보호돼요. 에이전시가 정한 판매 가격만 반환돼요.
- 구독, 일회성, 사용량 기반 요금 모델을 한 번의 호출로 모두 지원해요.
- 결제 흐름이 화이트라벨로 유지돼요. 서브 계정에는 하이퍼클래스 브랜딩이 보이지 않아요.
- 플랜 ID나 마크업 금액을 코드에 직접 적어 둘 필요가 없어 관리가 쉬워요.

## 인증 요건

가격은 에이전시와 고객마다 다를 수 있어서, 유효한 서브 계정(로케이션) 액세스 토큰이 필요해요. 에이전시 토큰이나 개발자 토큰으로 호출하면 403 Forbidden이 반환돼요.

## 핵심 사항

- OAuth 2.0 인증 코드(Authorization Code) 방식 또는 리프레시 토큰(Refresh Token) 방식을 사용해요.
- 토큰 스코프에 `marketplace.app.read`가 포함되어야 해요.
- 호출 한도는 앱당 분당 60회예요(변경될 수 있어요).

## 응답 객체와 가격 유형

JSON 응답은 `subscriptionPlans`, `oneTimePlans`, `usageMeters` 세 가지로 나뉘어요. 각 배열에는 `planId`, `planName`, `currency`, `price`, `billingInterval`이 들어 있어요. 이 필드로 다음과 같은 화면 요소를 동적으로 만들 수 있어요.

- 월간/연간 전환 버튼(`billingInterval` 사용)
- 사용량 구간 차트(포함 단위와 초과 요금 사용)
- 기간 한정 프로모션(`planName` 또는 메타데이터 태그 사용)

## 가격을 보여 줄 때 권장 사항

다음 방법으로 신뢰를 높이고 결제 이탈을 줄일 수 있어요.

- 사용자가 플랜 수량이나 결제 주기를 바꾸면 가격을 바로 새로 불러와요.
- 응답을 5~10분 동안 캐시해서, 오래된 데이터를 보여 주지 않으면서 API 호출 횟수를 줄여요.
- 통화와 청구 주기를 분명하게 표시해서 헷갈리지 않게 해요.
- 에이전시의 색상과 글꼴을 사용해 화이트라벨 경험을 완전하게 유지해요.
- 에이전시가 플랜을 삭제하거나 가격을 0으로 설정한 경우도 테스트해요.

## 자주 묻는 질문

### API가 에이전시의 기본 통화로 가격을 반환하나요?

네. 각 객체에 `currency` 필드가 있어서 올바른 통화 기호를 표시할 수 있어요.

### 에이전시가 서브 계정에 리빌링을 켜지 않으면 어떻게 되나요?

엔드포인트는 그대로 응답해요. 다만 가격 값은 마켓플레이스 기본 가격(마크업 없음)과 같아요.

### 가격은 얼마나 자주 새로 불러와야 하나요?

페이지를 불러올 때, 그리고 고객이 플랜 옵션을 바꿀 때마다 불러오는 것이 좋아요. 호출 한도를 지키려면 서버에서 5~10분 동안 캐시하세요.

### 에이전시 수준 토큰으로 이 API를 호출할 수 있나요?

아니요. 서브 계정 토큰을 사용해야 해요. 에이전시 토큰으로 호출하면 403 Forbidden이 반환돼요.

### 응답에 쿠폰이나 프로모션 할인도 포함되나요?

지금은 포함되지 않아요. 할인은 직접 계산해서 표시해야 해요.

### 이 엔드포인트에 호출 한도가 있나요?

네. 현재 앱당 분당 60회예요(변경될 수 있어요). 429가 반환되면 한도를 초과했다는 뜻이에요.
