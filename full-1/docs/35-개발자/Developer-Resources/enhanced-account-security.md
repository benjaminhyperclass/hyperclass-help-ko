# 강화된 계정 보안

데이터를 더 안전하게 지키기 위한 보안 업데이트예요. 이 문서에서는 **강화된 보안**을 켜면 무엇이 달라지는지, 사용자 관리 권한을 API로 바꿔야 할 때는 어떻게 하는지 안내해요.

![강화된 계정 보안 안내 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034345888/original/4BHSSG3Nx3UB57D_SZGBk9bU54xXrf8SRA.jpeg?1728418263)

{% hint style="info" %}
강화된 보안 옵션을 켜도, 이전에 API 키 생성이 해지된 서브 계정(Location)에서는 API 키 생성이 다시 허용되지 않아요. 이 옵션은 아직 활성 API 키가 있는 서브 계정에만 적용돼요.
{% endhint %}

## 강화된 계정 보안을 켜면 달라지는 점

1. 서브 계정 API 키가 자동으로 생성되지 않아요. 계정 보안을 높이기 위해, API나 화면(UI)으로 새 서브 계정을 만들어도 API 키가 자동으로 만들어지지 않아요. 대신 화면에서 직접 API 키를 생성해야 해요.
2. Location CRUD API 응답에 API 키가 포함되지 않아요. 이전에는 Location CRUD API 응답으로 API 키를 확인할 수 있었어요. 앞으로는 로그인한 뒤 화면에서 직접 API 키를 확인해야 해요.
3. API v1의 사용자 API가 비활성화돼요. API v1(이전 버전 API)에서 사용자를 만들고, 수정하고, 삭제하는 API를 쓸 수 없게 돼요. 해커가 API 키를 손에 넣으면 이 API로 계정에 쉽게 침투할 수 있어서, 이전 버전 API는 계정에 보안 위험이 될 수 있어요.

---

## 사용자 관리 권한과 API 접근

**강화된 보안**이 켜져 있으면, API로 **사용자 관리** 권한을 바꾸는 일은 계속 제한돼요.

API로 **사용자 관리** 권한을 변경하려면 **설정 > 회사 > 고급 설정**에서 **강화된 보안**을 끄세요. 에이전시에서 API 기반 사용자 관리 워크플로우가 꼭 필요할 때만 끄세요. 이 설정을 끄면 보안 위험이 커질 수 있어요.

**강화된 보안**을 끄면 다음 **사용자 관리** 권한에서 API 기반 변경을 쓸 수 있어요.

- **View & Manage Users**(사용자 보기 및 관리): API로 사용자를 만들고 수정할 수 있어요.
- **사용자 보기**: API로 사용자를 조회할 수 있어요.

{% hint style="info" %}
미리 해제하지 않았다면, 강화된 계정 보안 설정은 모든 계정에 기본으로 적용돼요.
{% endhint %}

**설정**에서 이 옵션을 해제할 수도 있어요. 하지만 계정과 데이터가 위험해질 수 있으니 해제하지 않는 것을 강하게 권해요.
