# 관리형 에이전트에서 커스텀 API 호출 설정하기

커스텀 API 호출을 쓰면 관리형 에이전트가 대화 중에 외부 API에서 정보를 가져오고, 데이터를 보내고, 실시간 결과를 활용할 수 있어요. 요청 방식, 엔드포인트, 인증, 파라미터, 응답 필드를 설정하고, 에이전트가 쓰기 전에 요청을 테스트해 보세요. 이 문서에서는 커스텀 API 호출을 설정하는 방법과, 관리형 에이전트가 대화 중에 API 데이터를 사용하는 방식을 설명해요.

## 커스텀 API 호출이란?

커스텀 API 호출을 쓰면 관리형 에이전트가 대화를 처리하는 중에 외부 서비스와 연동할 수 있어요. API 호출이 필요한 상황이 되면 에이전트는 필요한 정보를 모으고, 설정된 요청을 보내고, 응답 데이터 중 선택한 값으로 대화를 이어 가요.

이런 때 쓸 수 있어요.

- 외부 시스템에서 최신 정보 가져오기
- 데이터 보내기 또는 업데이트하기
- 예약 가능 여부 확인하기
- 그 밖에 API로 처리할 수 있는 작업 수행하기

## 준비 사항과 지원 옵션

커스텀 API 호출을 설정하기 전에 API 문서와 필요한 인증 정보를 준비하세요. 아래 내용을 미리 알고 있어야 해요.

- 엔드포인트
- 요청 방식
- 필수 파라미터
- 헤더
- 요청 본문 필드
- 관리형 에이전트가 사용할 응답 데이터

### 지원하는 요청 방식

- GET
- POST
- PUT
- PATCH
- DELETE

### 지원하는 인증 방식

- API Key
- Bearer Token
- Basic Authentication(기본 인증)
- No Authentication(인증 없음)

## 커스텀 API 호출 설정하기

실제 대화에 쓰기 전에 API 요청을 먼저 설정하고 테스트하세요. 그래야 관리형 에이전트가 올바른 정보를 모으고 기대한 응답 필드를 사용할 수 있어요.

### 1단계: 관리형 에이전트 열기

1. **AI 에이전트 > 에이전트 스튜디오**로 이동하세요.
2. **관리형 에이전트**를 여세요.
3. 설정할 관리형 에이전트를 선택하세요.

![관리형 에이전트 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082676547/original/XpZJ4Vo3EfZJnD8hoeGlQoNBmwPiSAWI2w.png?1791306919)

### 2단계: API 요청 설정하기

커스텀 API 호출을 추가하거나 설정한 뒤, 아래 요청 정보를 입력하세요.

- 요청 방식
- **엔드포인트 URL**
- 경로 또는 쿼리 파라미터
- 헤더
- 요청 본문(필요한 경우)
- 인증
- 사용 지침

![API 요청 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082674862/original/9pKEE7P3HR7qK6-GlW7mDQcE3khr7BgDLg.gif?1791305940)

### 3단계: API를 사용할 시점 정하기

관리형 에이전트가 이 API 호출을 언제 써야 하는지 알 수 있도록 지침을 분명하게 적으세요. 에이전트가 API 호출이나 도구를 여러 개 쓸 수 있을 때는 지침을 구체적으로 적는 것이 특히 중요해요.

### 4단계: 요청 테스트하기

1. 필수 파라미터에 테스트 값을 입력하세요.
2. 테스트 요청을 실행하세요.
3. 요청 상태와 API 응답을 확인하세요.

테스트 화면에서는 참고나 문제 해결에 쓸 수 있는 cURL 미리보기도 볼 수 있어요.

![요청 테스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082675194/original/etHIB1aGbawm1C4EF0V8WL7RltT__R02Kg.png?1791306118)

### 5단계: 응답 필드 선택하기

API 응답 중 관리형 에이전트가 사용할 응답 필드를 선택하세요. 에이전트가 작업을 끝내거나 대화를 이어 가는 데 필요한 데이터만 포함하세요.

![응답 필드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082675140/original/zRt7LVYCP3u6FuhBUZVfVIQBXNMtR38dcw.png?1791306086)

### 6단계: 저장하고 관리형 에이전트 테스트하기

커스텀 API 호출을 저장한 다음, 실제 상황과 비슷한 요청으로 관리형 에이전트를 테스트하세요. 에이전트를 게시하기 전에 아래 내용을 확인하세요.

- 올바른 API가 선택되는지
- 필요한 값을 제대로 모으는지
- 요청이 성공하는지
- 기대한 응답 데이터를 사용하는지

![관리형 에이전트 테스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082676143/original/T6YGveuZsGTXkldoLppglEoI4XTeDRP2iA.png?1791306673)

## 관리형 에이전트가 API를 사용하는 방식

설정한 API 호출이 필요한 상황이 되면 관리형 에이전트는 다음 순서로 움직여요.

1. 필요한 정보가 이미 있는지 확인해요.
2. 빠진 필수 값이 있으면 사용자에게 물어봐요.
3. 받은 값을 설정된 요청에 넣어요.
4. 설정된 인증 방식으로 API 호출을 보내요.
5. 선택한 응답 필드를 활용해 대화를 이어 가요.

## 자주 묻는 질문

### 관리형 에이전트가 커스텀 API 호출을 여러 개 사용할 수 있나요?

네, API 호출을 여러 개 설정할 수 있어요. 관리형 에이전트가 각 호출을 언제 써야 하는지 판단할 수 있도록 호출마다 사용 지침을 분명하게 적어 주세요.

### API에 필요한 정보가 빠져 있으면 어떻게 되나요?

관리형 에이전트가 요청을 보내기 전에 대화 중에 빠진 정보를 물어볼 수 있어요.

### 파라미터 값을 바꿔 가며 테스트할 수 있나요?

네, 테스트 화면에 테스트 값을 입력하고, 돌아온 응답을 확인한 뒤에 실제 대화에 API 호출을 쓰세요.

### 어떤 인증 방식을 지원하나요?

커스텀 API 호출은 API Key, Bearer Token, Basic Authentication을 지원하고, 인증이 필요 없는 엔드포인트도 사용할 수 있어요.

### cURL 명령어를 직접 작성해야 하나요?

아니요, 관리형 에이전트 화면에서 API를 설정하면 돼요. 테스트 화면에서는 참고나 문제 해결용으로 cURL 미리보기를 볼 수 있어요.
