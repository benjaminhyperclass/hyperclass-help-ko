# 대화 첨부파일 보안 접근 안내

하이퍼클래스는 고객의 민감한 정보를 더 안전하게 지키기 위해 대화 첨부파일의 보안을 강화해요. 하이퍼클래스 밖에서 첨부파일에 접근하는 앱은 앞으로 파일 접근 권한과 인증된 접근이 필요해요. 이 문서에서는 바뀌는 내용과 개발자가 준비할 일을 안내해요.

{% hint style="info" %}
이번 업데이트는 먼저 이메일 대화 첨부파일에 적용돼요. 다른 채널은 이후 단계에서 적용할 예정이에요. 영향을 받는 개발자는 2026년 11월 30일까지 앱을 업데이트해야 해요.
{% endhint %}

---

## 대화 첨부파일 보안 접근이란?

대화 첨부파일 보안 접근은 외부 앱이 대화 파일을 가져오는 방식을 권한 기반으로 제어하는 보안 모델이에요. 첨부파일 링크를 누구나 바로 열 수 있던 방식 대신, 앱이 적절한 권한을 갖고 인증된 상태로 접근해야 해요.

이 변경으로 데이터 보호가 강화되고, 하이퍼클래스의 HIPAA 규정 준수와 보안 요구 사항도 더 탄탄하게 뒷받침돼요. 대부분의 사용자는 지금과 같은 방식으로 계속 사용할 수 있어요.

---

## 보안 접근의 주요 이점

새 보안 모델은 기밀 파일을 보호하면서 앱의 접근을 더 세밀하게 관리할 수 있게 해 줘요.

- 데이터 보안 강화: 민감한 대화 첨부파일을 무단 접근으로부터 보호해요.
- 권한 기반 접근: 적절한 권한을 받은 앱만 보호된 파일을 가져올 수 있어요.
- 규정 준수 지원 강화: HIPAA와 보안 요구 사항을 뒷받침하는 안전장치를 강화해요.
- 앱 접근 제어: 외부 앱이 첨부파일을 가져올 때 인증된 요청을 요구해요.
- 일관된 파일 보안: 앞으로 다른 채널까지 보안 접근을 넓힐 기반을 마련해요.

---

## 첨부파일 접근 방식이 어떻게 바뀌나요?

이번 업데이트로, 하이퍼클래스 밖에서 이메일 대화 첨부파일을 가져오는 앱에는 새로운 접근 요건이 생겨요.

| 현재 | 변경 후 |
| --- | --- |
| 첨부파일 링크로 바로 접근할 수 있어요. | 보호된 첨부파일에 접근하려면 인증이 필요해요. |
| 기존 첨부파일 URL 형식을 써요. | 더 안전한 새 첨부파일 URL 형식을 써요. |
| 기존 앱 권한을 써요. | 파일 접근 권한이 추가로 필요해요. |
| 전환 기간에는 기존 연동이 현재 링크를 계속 쓸 수 있어요. | 영향을 받는 연동은 2026년 11월 30일까지 업데이트해야 해요. |

{% hint style="warning" %}
기존 첨부파일 링크는 전환 기간이 끝나는 2026년 11월 30일까지만 계속 작동해요. 개발자는 이 기한 전에 전환을 마쳐야 해요.
{% endhint %}

첫 단계에서는 이메일 대화 첨부파일만 대상이에요. 다른 대화 채널과 파일 기반 커스텀 필드는 이후 단계에서 적용할 예정이에요.

---

## 누가 영향을 받나요?

이번 보안 강화는 주로 하이퍼클래스 밖에서 대화 첨부파일에 접근하거나 보여 주는 개발자와 앱에 영향을 줘요.

- 일반 하이퍼클래스 사용자: 하이퍼클래스 안에서 첨부파일을 열 때는 달라지는 점이 없어요.
- 마켓플레이스 개발자: 이메일 대화 첨부파일을 외부에서 가져오는 앱을 업데이트해야 해요.
- 영향을 받는 앱의 사용자: 추가 권한을 허용하려면 앱을 다시 승인해야 해요.
- 첨부파일에 접근하지 않는 앱: 별도 조치가 필요 없어요.

이 구분을 보면 전환 기한 전에 조치가 필요한지 판단할 수 있어요.

---

## 첨부파일 권한과 앱 재승인

외부 앱이 보호된 이메일 첨부파일을 가져오려면 먼저 파일 접근 권한이 있어야 해요. 기존 사용자는 영향을 받는 앱을 다시 승인해서 바뀐 권한을 허용해야 해요. 개발자는 앱의 권한 설정을 업데이트하고, 첨부파일을 가져올 때 인증된 요청을 쓰도록 해야 해요.

기존 권한만으로는 새 파일 접근 권한이 자동으로 부여되지 않기 때문에 재승인이 필요해요.

마켓플레이스 권한에 대한 자세한 내용은 [API 보안 – 마켓플레이스 앱의 OAuth 동의](../27-앱-마켓/Get-Started-w/App-Marketplace/api-security-oauth-consent-for-marketplace-apps.md) 문서를 참고하세요.

## 보안 접근 준비 방법

개발자는 기존 연동을 점검하고, 2026년 11월 30일 전에 필요한 업데이트를 마쳐야 해요. 미리 준비하면 새 접근 제어가 적용될 때 서비스가 끊기는 일을 막을 수 있어요.

1. 앱 검토: 앱이 하이퍼클래스 밖에서 이메일 대화 첨부파일을 가져오거나 보여 주는지 확인하세요.
2. 권한 업데이트: 마켓플레이스 앱에 필요한 파일 접근 권한을 추가하세요.
3. 첨부파일 가져오기 방식 수정: 인증된 접근과 새 첨부파일 형식을 쓰도록 연동을 수정하세요.
4. 재승인 요청: 기존 사용자에게 추가 권한으로 앱을 다시 승인해 달라고 요청하세요.
5. 접근 테스트: 권한이 있는 앱은 첨부파일을 가져올 수 있고, 권한이 없는 요청은 제대로 차단되는지 확인하세요.
6. 전환 완료: 2026년 11월 30일 전에 필요한 변경 사항을 배포하고 확인하세요.

기술적인 구현 방법은 대화 첨부파일 API 문서를 참고하세요. 문서 위치는 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 하이퍼클래스 안에서 보는 첨부파일도 영향을 받나요?
하이퍼클래스 안에서 첨부파일을 보는 사용자에게는 달라지는 점이 없어요.

### 어떤 대화 채널이 영향을 받나요?
첫 단계는 이메일 대화 첨부파일에 적용돼요. 다른 채널과 파일 기반 커스텀 필드는 이후 단계에서 적용할 예정이에요.

### 2026년 11월 30일 이후 기존 첨부파일 링크는 어떻게 되나요?
바로 접근할 수 있는 기존 첨부파일 링크는 이전 접근 방식으로는 더 이상 지원되지 않아요. 앱은 새로운 권한 기반 접근 절차를 써야 해요.

### 기존 마켓플레이스 앱도 재승인이 필요한가요?
영향을 받는 첨부파일에 접근하는 앱이라면 필요해요. 기존 사용자가 추가된 파일 접근 권한을 허용하려면 해당 앱을 다시 승인해야 해요.

### 개발자가 앱을 업데이트하지 않으면 어떻게 되나요?
이전 방식으로 첨부파일에 접근하는 앱은 전환 기간이 지난 뒤 보호된 이메일 첨부파일을 더 이상 가져오지 못할 수 있어요.

### 대화 첨부파일에 접근하지 않는 앱도 조치가 필요한가요?
아니요. 대화 첨부파일을 가져오거나 보여 주지 않는 앱은 영향을 받지 않아요.
