# 빈 페이지에서 시작해 웹사이트 게시하기

빈 화면에서 웹사이트를 시작하면 막막할 수 있지만, 아래 순서대로 따라 하면 아이디어를 웹사이트로 빠르게 게시할 수 있어요. 이 문서에서는 계획부터 페이지 제작, 내비게이션 추가, 미리보기, 게시까지 한 번에 안내해요.

## 준비와 계획

하이퍼클래스에 로그인하거나 첫 요소를 끌어다 놓기 전에 웹사이트를 먼저 계획해 두세요. 시간과 수고를 크게 아끼고, 더 효과적인 사이트를 만들 수 있어요.

1. 웹사이트의 목적을 정해요.
   1. 이 웹사이트의 가장 큰 목표는 무엇인가요? 리드 확보, 상품 판매, 정보 제공, 브랜드 인지도 높이기, 예약 받기 중 무엇인지 정하면 디자인과 콘텐츠를 결정하기 쉬워요.
   2. 주요 방문자는 누구인가요? 방문자가 필요로 하는 것, 선호하는 것, 불편해하는 점을 알면 그에 맞게 콘텐츠와 디자인을 만들 수 있어요.
2. 콘텐츠와 구조를 정리해요.
   1. 어떤 페이지가 필요한가요? 대부분의 비즈니스 웹사이트는 홈, 회사 소개, 서비스/상품, 문의 페이지로 시작해요. 목표에 따라 더 늘리거나 줄여도 돼요.
   2. 페이지마다 꼭 들어가야 할 핵심 정보나 행동 유도(CTA)는 무엇인가요? 각 페이지에서 방문자가 무엇을 하거나 알아 가길 바라는지 생각해 보세요.
   3. 사용할 자료를 모아 두세요. 로고, 브랜드 색상, 이미지, 영상, 글 내용(또는 대략적인 구상)이 준비되어 있나요?
3. 간단한 계획표를 만들어요. 표로 정리하면 한눈에 보기 좋아요. 예를 들면 이런 모양이에요.

| 페이지/요소 | 목적 | 섹션 및 내용 |
| --- | --- | --- |
| 홈 | 비즈니스를 소개하고, 핵심 제공 내용을 보여 주고, 주요 행동을 유도해요 | 메인 헤드라인(예: OO에 오신 것을 환영합니다)<br>서브 헤드라인(예: 우리는 OO를 도와드려요)<br>행동 유도 버튼(예: 전화 상담 예약)<br>소개 미디어(예: 히어로 이미지 또는 영상 세일즈 레터)<br>상품/서비스별 개요 |
| 회사 소개 | 신뢰를 쌓고, 이야기를 전하고, 팀을 소개해요 | 회사 연혁/미션<br>팀원 사진과 소개<br>가치관/차별점 |
| 문의 | 방문자가 연락할 수 있게 하고, 위치를 알려 줘요 | 문의 폼<br>전화번호, 이메일<br>주소<br>지도 |
| 서비스/상품 | 제공하는 내용을 자세히 알려 줘요 | 상품/서비스 목록과 설명<br>가격 정보<br>장점<br>사례 |
| 내비게이션 메뉴 | 사이트 전체를 쉽게 이동할 수 있게 해요 | 로고, 페이지 링크 |
| 푸터 | 주요 링크, 저작권, 연락처 정보를 보여 줘요 | 저작권 표시<br>개인정보처리방침<br>서비스 이용약관<br>연락처 정보<br>소셜 미디어 아이콘 |

## 빈 웹사이트 만들기

1. **사이트 > 웹사이트**로 이동해 **New Website**(새 웹사이트) > **From Blank**(빈 페이지에서 시작)를 선택하고 **만들기**를 클릭하세요.

   ![빈 웹사이트 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698235/original/ifjG4aDUFMTAtvjgGnrnDe1gj4kJNuY19g.png?1748997405)
2. **새 페이지 추가**를 클릭하고 페이지 이름(예: 홈)을 입력한 뒤 **Create New Page**(새 페이지 만들기)를 클릭하세요.

   ![새 페이지 이름 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698279/original/JJWbpt8NVcaPzzftQOe4-idhjuIaGw04tA.png?1748997618)

## 홈 페이지 만들기

1. **Create From Blank**(빈 페이지로 만들기)를 클릭하세요.

   ![빈 페이지로 만들기 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698353/original/UdEab0LhcqO5CmtXPxrMXPrKvEisQ-Jb4g.png?1748997941)
2. **웹사이트 빌더**를 여세요.

   ![웹사이트 빌더 열기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698356/original/-KYYzy_8kB1lOB_DMvuEuP8EV_vHpZCreQ.png?1748997970)
3. 편집 화면 구성을 먼저 살펴보세요.
   1. **Control Panel**(컨트롤 패널): **Left Panel**(왼쪽 패널)에 요소, 페이지, 메타데이터 중 무엇을 표시할지 정해요.
   2. **Device Switcher**(기기 전환): 데스크톱 보기와 모바일 보기를 오가며 화면 크기에 맞게 보이는지 확인해요.
   3. **Meta Controls**(메타 컨트롤): 기록, 실행 취소, 미리보기, 저장, 게시 등을 할 수 있어요.
   4. **Left Panel**: 페이지에 넣을 요소와 설정이 나와요.
   5. **Center Panel**(가운데 패널): 페이지를 실시간으로 보면서 직접 편집할 수 있어요.
   6. **Right Panel**(오른쪽 패널): 선택한 섹션, 행, 요소의 설정과 스타일 옵션이 나와요.
   7. **Breadcrumb Bar**(브레드크럼 바): 빌더 아래쪽에 선택한 요소의 계층 구조를 보여 줘요. 상위 항목에 마우스를 올리면 캔버스에서 해당 영역이 강조되고, 클릭하면 그 항목을 선택해 편집할 수 있어요.

      ![편집 화면 구성](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698398/original/QDiRTb63ytLpjq98Gt1sdpVAhq9Uh6Ok6w.png?1748998154)

      ![브레드크럼 바 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081120423/original/VWMmzo5_kE0JL045HkIvElK_yvhxXefe0Q.png?1789584510)
4. 섹션을 추가해요. 가운데 영역이 비어 있다면 거기서, 아니면 왼쪽 사이드바의 **+**(요소/섹션 추가) 아이콘을 클릭하세요. 그다음 **섹션**을 선택하고 섹션 너비(예: **Full Width**(전체 너비))를 고르세요.

   ![섹션 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698493/original/cGm1FC7mWXzX2SfeJVTEAiqXBsLfPDaCQw.png?1748998456)
5. 행을 추가해요. 초록색 테두리가 생긴 새 섹션 안에 **행**을 끌어다 놓고 **1 Column**(1열)을 선택하세요.

   ![행 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698531/original/6wVfOs8If9n6aO0h1i9B0qirKVd5q6yPzA.png?1748998544)
6. 헤드라인과 서브헤드라인을 추가해요. 1열 행 안에서 **요소 추가**를 클릭하세요.

   ![요소 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698576/original/UiIY-XU86f874ZalvNuPpixdwx8wWC1yxw.png?1748998710)
   1. **헤드라인** 요소를 행 안으로 끌어다 놓으세요. 텍스트를 클릭해 내용을 고치고(예: "환영합니다"), 오른쪽 패널에서 글꼴, 크기, 색상 등을 바꿀 수 있어요.
   2. **+ 요소 추가**를 다시 클릭하고 **Sub-Headline**(서브헤드라인) 요소를 메인 헤드라인 아래로 끌어다 놓으세요. 텍스트와 스타일을 편집하세요(예: 성장을 도와드려요).

      ![서브헤드라인 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698666/original/JJVlNXis0a_d4eIVKhuLgAVPG3y2ZINXUQ.png?1748998951)
7. 버튼을 추가해요. 서브헤드라인 아래에 버튼을 추가하고, 버튼 텍스트를 "지금 전화하기"로 바꾸세요.

   ![버튼 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698716/original/HkLKAh7sZ9skwbbsVJ7ndEn77OJLh1RoRQ.png?1748999107)
8. 버튼에 동작을 지정해요. 버튼 설정(오른쪽 패널)에서 아래로 스크롤해 **Button Actions**(버튼 액션)로 이동하고, **통화**를 선택한 뒤 전화번호를 입력하세요.

   ![버튼 액션 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047698771/original/W1YGOMCjH8d-43vYXTarzQmDe5LTuXOz-w.png?1748999331)
9. 같은 방법으로 섹션, 행, 요소를 계속 추가해 홈 페이지를 완성하세요.
10. 저장 아이콘을 클릭해 저장하세요.

    ![저장 아이콘 클릭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047837288/original/BxqzElKxlWxuGPZ4HioWk5P4OgNM3V4tbA.png?1749158065)

## 페이지 더 추가하기

1. **사이트 > 웹사이트 > 사이트 세부 정보**로 이동하세요. 아직 페이지 편집기 안에 있다면 **뒤로** 버튼을 클릭하세요.

   ![사이트 세부 정보 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047837334/original/pqUOdYOO67hcYinkakEn2C3wYzoHag_dZg.png?1749158183)
2. **새 페이지 추가** 버튼을 클릭하고, 페이지 이름(예: 회사 소개)을 입력한 뒤 **Create New Page**(새 페이지 만들기)를 클릭하세요.

   ![새 페이지 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047837365/original/ruKFpJyU3RewT1UUNYpvW6eXPRLtCWa6rg.png?1749158290)
3. 이번에도 **Create From Blank**(빈 페이지로 만들기) 버튼을 클릭하세요.

   ![빈 페이지로 만들기 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047837419/original/2G6lY1DtVJ4ig6NfhVbDtchrwB9WmH39hQ.png?1749158529)
4. 홈 페이지와 같은 방법으로 요소와 내용을 추가하세요. **Text**(텍스트) 요소와 **이미지** 요소를 넣어 볼 수 있어요. 마지막에 **저장**을 클릭한 다음 **뒤로**를 클릭하세요.

   ![텍스트와 이미지 요소를 추가한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839680/original/xvKmjTd2POp13ipuNNvn1Jvb7fDSeI0fPg.png?1749169525)

## 내비게이션 추가하기

1. **사이트 > 웹사이트 > 사이트 세부 정보**로 이동하세요. 아직 페이지 편집기 안에 있다면 **뒤로** 버튼을 클릭하세요.

   ![사이트 세부 정보 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839818/original/eofvlKtYnxl5ODFlMN4dNchnvOzqFMkmKw.png?1749170157)
2. 홈 페이지를 편집해요. "home"이라는 이름의 페이지 카드에서 **편집**을 클릭하세요.

   ![홈 페이지 카드의 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839828/original/s-5G36HpE0-yJ0790d9oJDrn1I3PnamSCQ.png?1749170223)
3. 맨 위에 전체 너비 섹션을 추가해요. 페이지 가장 위, 다른 섹션들보다 위에 새 전체 너비 섹션을 추가하세요.

   ![맨 위에 전체 너비 섹션을 추가한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839841/original/8vHXgHci7z2NollPbGl2ounXymJvoWFEFQ.png?1749170320)
4. 1열 행과 내비게이션 메뉴를 추가해요. 새로 만든 맨 위 섹션 안에 1열 행을 추가하고, **Navigation Menu**(내비게이션 메뉴) 요소를 넣으세요.

   ![내비게이션 메뉴 요소를 추가한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839852/original/6aK7AGNk7ykqWfBMnzL-ts5mmE3HSUbibA.png?1749170415)
5. 내비게이션 메뉴 설정을 편집해요. 내비게이션 메뉴를 클릭해 선택하고, 오른쪽 설정 영역에서 각 링크가 올바른 페이지로 연결되는지 확인하세요. 로고도 추가할 수 있어요.

   ![내비게이션 메뉴 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839868/original/odLao3e1VufSLSsrW8pl0saAwq9B2Me9_Q.png?1749170517)

   ![내비게이션 메뉴 링크 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839907/original/tkcnS-AEOcYBoVsheA3aLs9LJY4YE04aYg.png?1749170737)
6. 맨 아래에 전체 너비 섹션을 추가해요. 페이지 맨 아래, 다른 섹션들보다 아래에 새 전체 너비 섹션을 추가하세요.

   ![맨 아래에 전체 너비 섹션을 추가한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839947/original/vztXlKPm6YMHNi8rnIBmMeISSt5g-npYJw.png?1749170854)
7. 미리 만들어진 푸터를 추가해요. **Elements**(요소) > **Prebuilt Elements**(미리 만들어진 요소) > **Footer**(푸터)를 열고, 푸터를 맨 아래 섹션으로 끌어다 놓으세요.

   ![미리 만들어진 푸터 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047839959/original/D1xvDgvFF8BDwI0vuR-mOeffs5OE5ZGpmw.png?1749170949)
8. 내비게이션 메뉴와 푸터를 다듬어요. 각 요소를 선택해 삭제하거나 **Right Panel**(오른쪽 패널)에서 설정을 편집하세요. 끝나면 **저장**을 클릭한 다음 **뒤로**를 클릭하세요.

## 미리보기, 설정, 게시

1. **사이트 > 웹사이트 > 사이트 세부 정보**로 이동해 **미리보기** 버튼(상자에 화살표가 있는 아이콘)을 클릭하세요. 페이지 빌더 안에 있다면 **미리보기** 버튼(눈 모양 아이콘)을 클릭해도 돼요.

   ![미리보기 버튼 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047840048/original/nLKHQNFbWUf27WnN1zJWFw0tzv8hLwAQ3Q.png?1749171792)

## 웹사이트 게시 후 문제 해결

게시한 뒤 웹사이트가 기대와 다르게 보이거나 동작하면 아래 내용을 확인해 보세요.

### 실제 웹사이트에 예전 내용이 보여요

페이지를 저장한다고 해서 최신 버전이 항상 바로 공개되는 것은 아니에요.

1. **웹사이트 빌더**에서 해당 페이지를 여세요.
2. **저장**을 클릭하세요.
3. **게시**를 클릭하세요.
4. 시크릿 모드(비공개 브라우저 창)에서 실제 웹사이트 주소를 열어 페이지를 다시 확인하세요.

공개할 페이지는 모두 게시했는지 확인하세요.

### 도메인이 대기 중으로 표시되거나 연결되지 않아요

도메인 연결이 아직 끝나지 않았다면 다음을 확인하세요.

- DNS 레코드가 하이퍼클래스에서 안내한 값과 일치하는지 확인하세요.
- 레코드 유형, 호스트/이름, 값에 오타가 없는지 확인하세요.
- 충돌하는 DNS 레코드가 있으면 제거하세요.
- 최근에 바꾼 DNS 설정이 적용될 때까지 시간을 두고 기다리세요.

도메인 자동 연결을 사용할 수 없다면, 설정 과정에 안내되는 수동 DNS 설정 옵션을 사용하세요.

### 웹사이트에서 404 페이지가 열려요

다음을 확인하세요.

- 도메인이 올바른 웹사이트에 지정되어 있는지
- 보여 주려는 페이지가 게시되어 있는지
- 페이지 URL 경로가 올바르게 설정되어 있는지
- 올바른 페이지가 웹사이트의 기본 페이지(홈 페이지)로 설정되어 있는지

### 웹사이트에 SSL 또는 개인정보 보호 경고가 떠요

잘못되었거나 서로 충돌하는 DNS 레코드가 있는지 확인하세요.

Cloudflare를 사용한다면, 하이퍼클래스에서 안내한 경우 직접 DNS 확인이 필요한 레코드를 **DNS only**로 설정했는지 확인하세요.

DNS 레코드를 바로잡은 뒤에는 SSL 인증서가 발급될 때까지 시간을 두고 기다리세요.

### 내비게이션 링크가 엉뚱한 페이지로 연결돼요

**Navigation Menu**(내비게이션 메뉴) 요소를 열어 모든 메뉴 항목이 올바른 페이지나 URL로 연결되는지 확인하세요.

페이지를 추가하거나 이름을 바꾸거나 순서를 바꿨다면, 게시하기 전에 내비게이션 링크를 다시 살펴보세요.

### 모바일에서 웹사이트가 이상하게 보여요

**웹사이트 빌더**에서 페이지를 열고 모바일 보기로 전환하세요.

다음을 확인하세요.

- 요소 간격과 정렬
- 글꼴과 버튼 크기
- 섹션과 행의 너비
- 데스크톱 전용 또는 모바일 전용으로 설정한 요소

필요하면 모바일 레이아웃을 조정한 다음, 페이지를 다시 저장하고 게시하세요.

### 폼, 캘린더, 버튼이 작동하지 않아요

사이트를 공개하기 전에 다음을 확인하세요.

- 방문자가 된 것처럼 각 폼을 직접 제출해 보세요.
- 캘린더 예약 링크를 테스트하세요.
- 모든 버튼과 행동 유도(CTA)를 클릭해 보세요.
- 링크가 의도한 페이지나 목적지로 열리는지 확인하세요.
- 테스트로 제출한 내용이 기대한 기록이나 알림으로 생성되는지 확인하세요.

### 웹사이트 최종 점검

웹사이트를 공유하기 전에 다음을 확인하세요.

- 도메인이 연결되고 인증되었는지
- 웹사이트가 `https://`로 안전하게 열리는지
- 올바른 홈 페이지가 나타나는지
- 필요한 페이지가 모두 게시되었는지
- 내비게이션 링크가 작동하는지
- 폼과 버튼이 작동하는지
- 데스크톱과 모바일 레이아웃이 모두 올바르게 보이는지
- 최신으로 게시한 내용이 실제 사이트에 나타나는지
