# 시작하기: 파이프라인과 기회 설정

파이프라인과 기회를 쓰면 영업 과정을 정리하고, 첫 접점부터 계약 완료까지 잠재 거래를 한곳에서 추적할 수 있어요. 이 문서에서는 파이프라인, 단계, 연락처, 기회가 어떻게 연결되는지 알아보고, 첫 파이프라인을 만들어요. 기회는 직접 추가하거나 한꺼번에 가져올 수 있고, 원하면 워크플로우로 자동 생성하도록 설정할 수도 있어요.

이 문서를 끝까지 따라 하면 팀이 바로 추적하고 관리할 수 있는, 기회가 담긴 파이프라인이 완성돼요.

## 파이프라인과 기회 이해하기

첫 파이프라인을 만들기 전에 **기회 관리**(Opportunities)를 이루는 요소들이 어떻게 연결되는지 먼저 알아 두면 좋아요.

| 용어 | 설명 |
| --- | --- |
| 파이프라인 | 추적하려는 전체 영업 과정을 나타내요. |
| 단계 | 영업 과정 안의 한 단계를 나타내요. 예: 새 리드, 통화 예약, 종료 |
| 기회 | 파이프라인을 따라 이동하는 잠재 거래를 나타내요. |
| 연락처 | 기회와 연결된 사람이에요. |

### 함께 작동하는 방식

구조는 이렇게 생각하면 쉬워요.

연락처 → 기회 → 파이프라인 → 단계

예를 들어 연락처 John Smith 님의 기회가 "영업 파이프라인"의 "통화 예약" 단계에 있을 수 있어요.

{% hint style="info" %}
파이프라인 단계는 실제 영업 과정의 단계와 맞게 구성하세요. 이 문서의 예시는 참고용이고, 비즈니스에 맞게 바꿔서 쓰면 돼요.
{% endhint %}

## 시작하기 전에

기회 관리를 설정하기 전에 아래 내용을 생각해 보세요.

- 어떤 영업 과정을 추적할 건가요?
- 리드는 보통 어떤 단계를 거쳐 이동하나요?
- 기회를 직접 추가할지, 한꺼번에 가져올지, 자동으로 만들지 정했나요?
- 기회를 관리할 팀원은 누구인가요?

## 기회를 추가하는 방법 고르기

| 방법 | 이럴 때 좋아요 |
| --- | --- |
| **수동 생성** | 기회가 생길 때마다 하나씩 추가할 때 |
| **CSV 가져오기** | 기존 기회를 옮겨 오거나 한꺼번에 추가할 때 |
| **워크플로우 자동화** | 특정 이벤트가 발생했을 때 기회를 자동으로 만들거나 업데이트할 때 |

한 가지 방법만 써도 되고, 여러 방법을 함께 써도 돼요.

## 영업 파이프라인 만들기

새 파이프라인을 만들면 모든 리드가 영업 과정의 어디쯤 있는지 한눈에 볼 수 있어요. 아래 순서대로 시작해 보세요.

1. **기회 관리**로 이동해요.
2. **파이프라인**을 클릭해요.
3. **새 파이프라인 만들기**를 클릭해요.

   ![새 파이프라인 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582275/original/juyyLUC63RVJOoO-VFRQU5DmXJPyR1KiCw.png?1747185927)
4. 이름, 단계 등을 입력하고 **저장**을 클릭해요.

   ![파이프라인 정보를 입력하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582299/original/hosafNsbFiyMPIKTWvAwcYU_rpnev08erA.png?1747186085)

팀의 업무 방식에 맞게 단계를 직접 구성해 보세요. 예를 들면 이런 단계가 있어요.

- 새 리드
- 핫 리드
- 통화 예약
- 노쇼
- 지연
- 종료
- 무응답

## 연락처를 기회로 가져오기

행사나 다른 플랫폼에서 모은 연락처 목록이 있나요? 영업 파이프라인으로 바로 가져와서 리드를 기회로 바꿀 수 있어요.

1. **기회 관리**로 이동해요.
2. **가져오기**를 클릭해요.

   ![가져오기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582317/original/Zn1BtwdZenzYQukjv876FbzvC4VGCHqg5w.png?1747186171)
3. **기회 관리**를 선택해요.
4. **다음**을 클릭해요.

   ![가져올 대상을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582328/original/oC696YzN-yA3Ea80HnPh88ol08orcSJ36w.png?1747186223)
5. **파일 업로드**에서 파일을 올려요.
6. **다음**을 클릭해요.

   ![파일을 업로드하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582334/original/XPHcPeBRLndpPjjzXVsjVhpYlJ-h34zovw.png?1747186283)

8. **다음**을 클릭해요.

   ![파일 열을 기회 필드에 연결하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582343/original/M1E8UukqUVBCGW6oEBKRK5Pdqo_2pQZLRQ.png?1747186348)
9. 모든 정보를 확인한 뒤 **Start Bulk Import**(대량 가져오기 시작)를 클릭해요.

   ![가져오기 정보를 확인하고 시작하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582368/original/c6Ym2ups1E_UPGWwvQ54c8q_cCgepErDug.png?1747186449)

다음으로, 기회를 직접 추가해서 파이프라인을 다듬어 볼 수 있어요.

## 기회 직접 만들기

기회가 하나씩 들어올 때는 직접 추가하면 세밀하게 관리할 수 있어요. 방법도 간단해요.

1. **기회 관리**로 이동해요.
2. **기회 추가**를 클릭해요.
3. 기존 연락처를 선택하거나 새 연락처 정보를 입력해요.
4. **기회 세부정보**에서 **기회 파이프라인**, **파이프라인 단계**, **값** 등을 입력해요.
5. **만들기**를 클릭해요.

   ![기회 세부정보를 입력하고 만들기를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046582407/original/RcxPH_183Eo8JrU6o629m-oZD1Ug71KD8A.png?1747186618)

더 자세한 안내는 [단계별 가이드: 기회 만들기](../../05-기회-파이프라인/step-by-step-guide-to-creating-opportunities.md) 문서를 참고하세요.

## 자동화로 기회 만들기

기회 생성을 자동화하면 일일이 클릭하지 않아도 파이프라인이 깔끔하게 유지돼요. 아래는 누군가 폼을 제출할 때마다 기회를 만드는 예시예요. 뒤에서 다른 트리거로 바꿔 쓰는 방법도 소개해요.

워크플로우 빌더(자동화 편집 화면)는 영어 화면이라서, 빌더 안의 이름은 영어 그대로 적었어요.

1. 워크플로우 열기

   왼쪽 메뉴에서 **자동화 > 워크플로우**로 이동해요.

   ![자동화 > 워크플로우 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053481776/original/l1zU-0UMV4Uq7-LQOGr8pWzAQ3pNAdOWZw.png?1757510602)
2. 새 워크플로우 시작하기

   **+ Create Workflow**(워크플로우 만들기)를 클릭한 뒤 **처음부터 시작**을 선택해요. 사용하려는 템플릿이 있으면 템플릿을 골라도 돼요.
3. 트리거 추가: Form Submitted
   - **+ Add New Trigger**(새 트리거 추가)를 클릭하고 **Form Submitted**(폼 제출)를 선택해요.
   - 리드 정보를 받는 폼을 선택해요.
   - **Save Trigger**(트리거 저장)를 클릭해요.
4. 액션 추가: Create/Update Opportunity
   - 트리거 아래의 **+**(액션 추가 버튼)를 클릭하고 **Opportunity**(기회) > **Create/Update Opportunity**(기회 생성/업데이트)를 선택해요.
   - 폼으로 들어온 리드가 표시될 **Pipeline**(파이프라인)과 **Stage**(단계)를 선택해요.
   - **Status**(상태)를 *Open*(진행 중) 또는 다른 상태로 설정하고, 금액을 알고 있다면 **Value**(값)를 입력해요. 나중에 같은 연락처가 다시 들어왔을 때 기록을 업데이트하려면 **Allow Opportunity to Move**(기회 이동 허용)를 켜요.
   - **Save Action**(액션 저장)을 클릭해요.

     ![Create/Update Opportunity 액션을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155053482607/original/qohmxMv7OL6XTZvbXuPyKD1GpV389ALclA.gif?1757511004)
5. 저장 후 게시하기

   오른쪽 위에서 **Draft**(임시 저장)를 **Publish**(게시)로 전환해요. 이제부터 폼이 제출될 때마다 선택한 파이프라인 단계에 자동으로 기회가 들어와요.

### 자주 쓰는 다른 트리거와 활용 예

| 트리거 | 활용 예 |
| --- | --- |
| **Customer Booked Appointment**(고객 예약 완료) | 통화를 예약한 잠재고객을 "상담 예약됨" 단계에 자동으로 추가해요. |
| **Contact Tag**(연락처 태그) | "핫 리드" 태그가 붙는 순간 해당 연락처를 계약 진행 단계로 옮겨요. |
| **Facebook Lead Form Submitted**(Facebook 리드 폼 제출) | Facebook 광고로 들어온 리드를 "새 Facebook 리드" 단계에 넣어 빠르게 후속 연락해요. |
| **Payment Received**(결제 완료) | 구매가 이루어지면 "고객전환성공 – 온보딩 대기" 단계에 기회를 만들어요. |
| **Contact Created**(연락처 생성) | 새 연락처를 모두 "새 리드" 단계에서 시작해서 놓치는 연락처가 없게 해요. |
| **Call Status**(통화 상태) | 응답한 인바운드 통화를 후속 관리 단계에 넣어 담당자가 이어서 관리하게 해요. |
| **Survey Submitted**(설문 제출) | 완료된 설문을 자격 검토 단계로 보내 점수를 매겨요. |

{% hint style="info" %}
**Create/Update Opportunity**(기회 생성/업데이트) 액션은 어떤 워크플로우에서든 같아요. 바뀌는 건 트리거뿐이에요. 리드가 파이프라인에 언제, 어떻게 나타나야 하는지에 가장 잘 맞는 트리거를 고르세요.
{% endhint %}

## 자주 묻는 질문

### 파이프라인과 기회는 어떻게 다른가요?
파이프라인은 전체 영업 과정을 나타내고, 기회는 그 과정을 따라 이동하는 개별 잠재 거래를 나타내요.

### 파이프라인 단계가 뭔가요?
단계는 영업 과정 안의 구체적인 한 단계예요. 기회는 진행됨에 따라 단계 사이를 이동해요.

### 기회를 만들려면 꼭 워크플로우를 써야 하나요?
아니요. 기회는 직접 만들거나 한꺼번에 가져올 수 있고, 워크플로우로 자동 생성하거나 업데이트할 수도 있어요.

### 기회가 예상한 파이프라인에 보이지 않아요.
기회를 만들 때 올바른 파이프라인과 단계를 선택했는지 확인하세요. 워크플로우로 만든 기회라면 **Create/Update Opportunity** 액션 설정을 점검하세요.

### 워크플로우가 기회를 만들지 않았어요.
아래 내용을 확인하세요.

- 워크플로우가 게시되어 있는지
- 연락처가 워크플로우 트리거 조건을 충족했는지
- **Create/Update Opportunity** 액션이 설정되어 있는지
- 올바른 파이프라인과 단계가 선택되어 있는지

### 기회가 다른 단계로 이동하지 않았어요.
워크플로우로 기존 기회를 업데이트하고 있다면, **Create/Update Opportunity** 설정과 **Allow Opportunity to Move** 설정을 확인하세요.

### 여러 기회를 한 번에 가져올 수 있나요?
네. **기회 관리**의 **가져오기** 기능으로 CSV 파일의 기회 데이터를 업로드하고 열을 연결하면 돼요.

### 기존 연락처에 기회를 직접 만들 수 있나요?
네. 기회를 직접 만들 때 기존 연락처를 선택한 다음, 알맞은 파이프라인과 단계에 배정하면 돼요.
