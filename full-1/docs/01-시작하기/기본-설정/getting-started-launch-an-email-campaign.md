# 이메일 캠페인 시작하기

이메일 템플릿을 고르고 다듬은 뒤, 첫 이메일 캠페인을 발송하는 과정을 처음부터 끝까지 안내해요. 연락처에게 서비스를 알리거나 꾸준히 소식을 전하고 싶을 때 따라 해 보세요.

## 이메일 템플릿으로 시작하기

템플릿은 이메일 캠페인의 바탕이 되는 설계도예요. 한 번 만들어 두면 여러 메시지를 만들 때 계속 활용할 수 있어요.

1. **마케팅 > 이메일**로 이동하세요.
2. **템플릿** 탭을 클릭하세요.
3. **신규**를 클릭하세요.
4. **이메일 마케팅 템플릿**을 선택하세요.

   ![이메일 마케팅 템플릿 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064550947/original/eIvlbI2zvNz38rUz8GY9PxuWZfT4HGOmmw.png?1770712009)
5. **템플릿 라이브러리**에서 **찾아보기**나 검색으로 캠페인에 맞는 디자인을 찾아보세요. 처음부터 직접 만들 수도 있어요.

   ![템플릿 라이브러리에서 디자인 찾기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046412027/original/_6U2IlDsztiTyFlDsC-kwhUmgfREzU-_8A.png?1746824623)
6. 마음에 드는 템플릿은 **미리보기**로 어떻게 보이는지 확인하세요.
7. **템플릿 선택**을 클릭하면 이메일 빌더에서 템플릿이 열려요.
8. 템플릿이 만들어지고 **빌더**에서 열려요.

   ![템플릿이 빌더에서 열리는 모습](https://jumpshare.com/share/fW2LCXdhJMSf3yz06HNJ+/GIF+Recording+2026-08-17+at+19.56.12.gif)

{% hint style="info" %}
템플릿 라이브러리 검색에서는 추천 검색어, 최근 검색어, 색상 기반 탐색, 강조 표시된 키워드 일치 기능을 쓸 수 있어요. 원하는 이메일 템플릿을 더 빨리 찾을 수 있어요.
{% endhint %}

**자세히 보기**:

- 이메일 템플릿 vs 이메일 캠페인
- 템플릿 라이브러리에 이메일 템플릿 추가하는 방법

다음으로 템플릿을 내 브랜드에 맞게 꾸며 보세요.

## 이메일 템플릿 수정하기

이 단계에서 템플릿에 내 브랜드의 말투와 이미지를 담아 완성해요.

1. **마케팅 > 이메일 > 템플릿**으로 이동하세요.
2. 고른 템플릿을 이메일 빌더에서 여세요.

   ![이메일 빌더에서 템플릿을 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413330/original/72heU-1qnyfWQdKdgINv81Wr8X2GjUZIWA.png?1746832417)
3. 텍스트, 이미지, 레이아웃을 마음에 들 때까지 조정하세요.
4. **Save Template**(템플릿 저장)을 클릭해 변경 내용을 저장하세요.

   ![템플릿 저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413344/original/bLlCHGCsQj472PmWuIDMzfn60AbpuhwkWw.png?1746832471)
5. 발송 전에 확인하려면 점 3개 메뉴 > **테스트 이메일**을 클릭하세요.

   ![점 3개 메뉴에서 테스트 이메일 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413361/original/41PoXAa4QMAGJta5WxVNYkGVWVlSao6UIQ.png?1746832527)
6. 보내는 사람 정보와 받는 사람 등 필요한 내용을 입력하세요.
7. **테스트 이메일 전송**을 클릭하세요.

   ![테스트 이메일 전송 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413368/original/ScuDb80Q2QXi5oTGtn8O1glcHDVUzoHRtA.png?1746832601)
8. 결과가 마음에 들면 **뒤로**를 클릭해 이메일 캠페인 대시보드로 돌아가세요.

템플릿이 완성됐어요. 이제 이 템플릿으로 이메일 캠페인을 만들어 보세요.

## 편집 패널을 오른쪽에 두고 이메일 AI와 함께 작업하기

편집 패널을 **오른쪽**에 두면 **이메일 AI**와 나란히 보면서 더 빠르게 작업할 수 있어요.

1. 이메일 빌더에서 캠페인이나 템플릿을 여세요.
2. 초안 작성에 도움이 필요하면 **이메일 AI**를 켜세요.
3. 편집 화면의 패널 전환 스위치로 패널을 **오른쪽**으로 옮기세요. 다시 **왼쪽**으로 되돌릴 수도 있어요.
4. 평소처럼 편집하고, 미리보기로 확인하고, 게시하세요.

![편집 패널을 오른쪽에 둔 이메일 빌더 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064552634/original/Rhbkn0NIq7wRBrze20HteYr6r6ynhdwLug.png?1770713083)

## 템플릿으로 이메일 캠페인 만들기

다듬은 템플릿을 실제 캠페인으로 만들어 연락처에게 보내 보세요.

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. **신규 > 템플릿 선택**을 클릭하세요.

   ![신규 메뉴에서 템플릿 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413397/original/-GYDSE124zTfKDca_nqPAWXcpW-_yq83fA.png?1746832945)
3. 다른 방법도 있어요. **템플릿** 탭에서 고른 이메일 템플릿 옆의 점 3개 메뉴를 클릭하고 **캠페인 만들기**를 선택하세요.

   ![템플릿 옆 점 3개 메뉴에서 캠페인 만들기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413404/original/3ssKl7S0r4rWH06vcVo_JJi1Pb8Z-5-xog.png?1746833027)
4. 템플릿이 열린 상태에서 **Send or Schedule**(보내기 또는 예약)을 클릭하세요.

   ![보내기 또는 예약 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413419/original/9VEEpBfie_Ax-p702NjS__NYlkv8CTAmgg.png?1746833129)
5. 받는 사람 선택, 추적 사용 등 이메일 옵션을 구성하세요.
6. **Review and Send**(검토 후 보내기)를 클릭하세요.

   ![검토 후 보내기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413436/original/k_aMw4pciJECqPhoqHEhkTAGc4NVJdIWqg.png?1746833197)
7. 상태가 **Sending**(발송 중)에서 **Sent**(발송 완료)로 바뀌는 것을 확인하세요. 첫 캠페인 발송을 축하해요!

   ![캠페인 발송 중 상태](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413459/original/301v7Yeero16drImklqVHW2H4qWKqIfcBQ.png?1746833356)

   ![캠페인 발송 완료 상태](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046413473/original/EvbdaeOZNyKaBttt-H06d4q6qi-zL2G5KQ.png?1746833454)
