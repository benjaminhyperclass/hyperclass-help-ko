# 앱 안에서 번역 피드백 보내기

에이전시 관리자는 하이퍼클래스 화면에서 바로 잘못되었거나 이해하기 어려운 번역을 신고할 수 있어요. 별도의 외부 티켓은 필요 없어요. 이 문서에서는 기능의 용도, 사용할 수 있는 사람, 표시되는 위치, 스크린샷을 첨부해 피드백을 보내는 방법을 안내해요.

## 번역 피드백 기능이란?

번역 피드백 기능은 상단 바에 신고 아이콘을 보여 주는 기본 기능이에요. 사용 권한이 있는 사용자는 지금 보던 페이지를 벗어나지 않고 번역 문제를 제출할 수 있어요. 제출된 내용은 제품 팀이 검토가 필요한 문구를 빠르게 찾아 번역의 정확성과 일관성을 높이는 데 쓰여요.

{% hint style="info" %}
플랫폼 언어가 영어로 설정되어 있으면 이 기능이 보이지 않아요.
{% endhint %}

- 문제가 보이는 페이지에서 바로 피드백을 제출하세요.
- 스크린샷을 첨부해 해당 문구를 정확히 표시하세요.
- 제출한 내용은 검토 담당자에게 전달되고, 문제가 해결되면 알림을 받아요.

## 번역 피드백 기능의 장점

일반 고객지원 티켓을 열지, 앱 안에서 신고할지 고를 때 아래 장점을 참고하세요.

- 실시간 캡처: 지금 쓰고 있는 화면에서 바로 문제를 신고할 수 있어요.
- 적은 수고: 일상적인 번역 수정 때문에 외부 티켓을 열 필요가 없어요.
- 높은 품질: 스크린샷을 첨부하면 검토 담당자가 정확한 문구를 쉽게 찾을 수 있어요.
- 빠른 개선: 신고가 한곳에 모여 번역 개선이 더 빠르게 진행돼요.

## 번역 피드백 제출 단계

아래 순서대로 따라 하면 화면에서 바로 번역 피드백을 제출할 수 있어요.

1. **에이전시 소유자** 또는 **에이전시 관리자** 계정으로 로그인했는지, 언어가 영어가 아닌지 확인하세요.
2. 번역 문제가 있는 페이지를 여세요.
3. 상단 바의 **번역 문제 신고** 아이콘을 클릭하세요.

   ![상단 바의 번역 문제 신고 아이콘](https://jumpshare.com/share/HnGm7ViM2dA1ylQO2LjV+/Screen+Shot+2025-09-15+at+8.11.17+PM.png)
4. 패널의 내용은 선택한 플랫폼 언어로 표시돼요.
5. 문제가 있는 부분과 위치가 잘 보이는 스크린샷을 첨부하세요. 스크린샷은 필수예요.

   ![스크린샷 첨부 화면](https://jumpshare.com/share/dz0ne7Of1YemNPH5Emvj+/Screen+Shot+2025-09-15+at+8.15.27+PM.png)
6. 문제 유형을 선택하세요. 예를 들어 잘못된 번역, 문법, 잘못된 서식이 있어요.

   ![문제 유형 선택 화면](https://jumpshare.com/share/3B6FCm7pj5mk16opqtZu+/Screen+Shot+2025-09-15+at+8.18.33+PM.png)
7. 문제에 대한 간단한 설명을 입력하세요.

   ![간단한 설명 입력 화면](https://jumpshare.com/share/VEssGpFoVnqvkWLq2UXj+/Screen+Shot+2025-09-15+at+8.20.26+PM.png)
8. **Where Did You See This?**(어디에서 확인하셨나요?) 섹션에 문제를 본 경로를 입력하세요. 예: 대시보드 > 퍼널 > Step Builder

   ![문제를 확인한 경로 입력 화면](https://jumpshare.com/share/ko4QrRgXcpgczqq4QkGa+/Screen+Shot+2025-09-15+at+8.23.40+PM.png)
9. **Report Issue**(문제 신고) 버튼을 클릭하세요.
10. 문제가 해결되면 알림으로 알려 드려요.

    ![문제 해결 알림 화면](https://jumpshare.com/share/vUne13Vnw47OexaRpfCg+/Screen+Shot+2025-09-15+at+8.24.54+PM.png)

## 자주 묻는 질문

### 번역 피드백 기능은 누가 사용할 수 있나요?
**에이전시 소유자**와 **에이전시 관리자** 역할이 사용할 수 있어요.

### 아이콘이 보이지 않아요. 왜 그런가요?
언어를 영어로 설정하면 이 기능이 보이지 않아요. 또한 **에이전시 소유자**나 **관리자** 역할에만 표시돼요.

### 신고할 때 어떤 내용을 넣어야 하나요?
짧은 설명, 올바른 표현, 문제가 보이는 상황을 담은 스크린샷을 함께 넣어 주세요.

### 문제가 해결되었는지 어떻게 알 수 있나요?
신고한 번역이 해결되면 알림으로 알려 드려요.
