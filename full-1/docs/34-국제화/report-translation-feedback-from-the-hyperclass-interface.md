# 하이퍼클래스 화면에서 번역 문제 신고하기

에이전시 소유자와 에이전시 관리자는 하이퍼클래스 안에서 바로 번역 문제를 신고할 수 있어요. 잘못되었거나 어색하거나 빠진 번역을 페이지를 떠나지 않고 알릴 수 있고, 별도 문의를 따로 접수할 필요도 없어요. 신고는 하이퍼클래스 화면에서 접수되므로, 담당 팀이 상황을 더 정확히 파악하고 검토할 수 있어요.

## 화면에서 번역 피드백을 보내는 기능이란?

화면 내 번역 피드백은 하이퍼클래스를 쓰다가 번역 문제를 발견했을 때 바로 신고하는 기능이에요. 번역된 단어, 이름, 안내 문구, 메시지가 잘못되었거나 이해하기 어렵다면 상단 바에서 피드백을 보낼 수 있어요. 보낸 내용은 검토 후 수정돼요.

이 도구는 번역 문제 전용이에요. 번역을 고쳐야 할 때만 쓰세요. 제품 버그, 결제 문의, 로그인 문제, 일반 지원 요청에는 쓰지 않아요.

{% hint style="warning" %}
이 기능은 에이전시 소유자와 에이전시 관리자에게만 보여요. 에이전시 관리자가 서브 계정 안에서 작업하는 경우에도 서브 계정 사용자는 번역 피드백 아이콘을 보거나 쓸 수 없어요.
{% endhint %}

{% hint style="warning" %}
플랫폼 언어가 영어로 설정되어 있으면 번역 피드백 아이콘이 보이지 않아요. 서브 계정에 표시되는 언어는 하이퍼클래스의 플랫폼 언어 설정에 따라 정해져요.
{% endhint %}

## 번역 피드백의 장점

정확한 번역은 팀원들이 원하는 언어로 더 자신 있게 일하는 데 도움이 돼요. 화면에서 바로 신고하면, 번역이 어디에 나오고 무엇을 고쳐야 하는지 하이퍼클래스가 더 분명히 알 수 있어요.

- 빠른 신고: 지금 보고 있는 페이지를 떠나지 않고 번역 피드백을 보낼 수 있어요.
- 번역 품질 향상: 지원되는 영역에서 잘못되었거나, 불분명하거나, 빠졌거나, 일부만 번역된 부분을 찾는 데 도움이 돼요.
- 더 정확한 상황 전달: 스크린샷과 문제 설명을 함께 보내면 번역 문제가 나타난 위치를 하이퍼클래스가 이해하기 쉬워요.
- 지원 절차 간소화: 번역 문제는 일반 고객지원을 거치지 않고 전용 절차로 신고할 수 있어요.
- 에이전시 관리자 권한: 에이전시 소유자와 에이전시 관리자는 에이전시 화면에서도, 서브 계정 안에서도 번역 문제를 신고할 수 있어요.

## 누가 쓸 수 있나요?

번역 피드백 도구는 에이전시 수준의 관리자만 쓸 수 있어요. 해당 영역에 접근할 수 있는 관리자가 신고하므로 신고 내용에 충분한 상황 정보가 담기기 때문이에요.

번역 피드백 아이콘을 쓸 수 있는 사용자:

- 에이전시 소유자
- 에이전시 관리자

번역 피드백 아이콘을 쓸 수 없는 사용자:

- 서브 계정 사용자
- 로케이션 수준 사용자
- 영어로 하이퍼클래스를 보는 사용자
- 에이전시 수준 관리자 권한이 없는 사용자

에이전시 소유자와 에이전시 관리자는 서브 계정 안에서 작업할 때를 포함해 대부분의 하이퍼클래스 페이지에서 이 아이콘을 볼 수 있어요. 서브 계정 사용자에게는 아이콘이 보이지 않아요.

## 언제 쓰나요?

하이퍼클래스 화면에 표시되는 언어나 표현에 문제가 있을 때 번역 피드백을 보내세요. 문제가 잘못된 번역인지, 어색한 표현인지, 빠진 번역인지, 번역되지 않은 텍스트인지 알려 주면 현지화 팀이 이해하기 쉬워요.

번역 피드백 도구를 쓰는 경우:

- 잘못된 번역
- 불분명하거나 헷갈리는 번역 표현
- 빠진 번역
- 다른 언어를 선택했는데 영어로 표시되는 텍스트
- 선택한 언어로 읽었을 때 뜻이 통하지 않는 이름, 버튼, 메뉴 항목, 안내 문구
- 에이전시 화면이나 서브 계정에서 발견한 번역 문제

번역 피드백 도구를 쓰지 않는 경우:

- 제품 버그
- 기능 요청
- 결제 문제
- 로그인 또는 접근 문제
- 계정 설정 문의
- 워크플로우, 이메일, 전화, CRM 설정 문제

번역과 관련 없는 문제는 하이퍼클래스의 기본 피드백, 버그 신고, 고객지원 방법을 이용하세요. 일반 피드백이나 버그 신고는 별도 절차로 접수돼요.

## 번역 피드백 아이콘은 어디에 보이나요?

에이전시 수준 권한이 있고 플랫폼 언어가 영어가 아닌 언어로 설정되어 있으면, 대부분의 하이퍼클래스 페이지 상단 바에 번역 피드백 아이콘이 나타나요. 에이전시 소유자와 에이전시 관리자는 문제가 나타난 페이지에서 바로 신고할 수 있어요.

아이콘이 보일 수 있는 곳:

- 에이전시 화면
- 에이전시 소유자나 에이전시 관리자가 접속한 서브 계정 화면
- 번역된 화면 텍스트가 표시되는 대부분의 하이퍼클래스 페이지

서브 계정 사용자에게는 지원되는 영어 외 언어로 하이퍼클래스를 쓰더라도 아이콘이 보이지 않아요.

## 번역 피드백 보내기

문제가 나타난 페이지에서 바로 피드백을 보내면, 하이퍼클래스가 표현을 고쳐야 할 정확한 위치를 확인할 수 있어요. 문제 유형, 스크린샷, 짧은 설명을 함께 보내면 조사하고 해결하기가 쉬워요.

1. 에이전시 소유자 또는 에이전시 관리자로 하이퍼클래스에 로그인하세요.
2. 번역 문제가 나타난 페이지로 이동하세요.
3. 상단 바의 번역 신고 아이콘을 클릭하세요.
4. **번역 문제 신고** 패널이 열려요.

   ![번역 문제 신고 패널 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074518038/original/JnOUjF5v5tJmT29pc-LYESmG_w4CSzSX_w.png?1782404233)
5. 문제와 가장 비슷한 유형을 선택하세요. 잘못된 번역, 불분명한 번역, 빠진 번역, 번역되지 않은 텍스트 등이 있을 수 있어요.
6. 번역 문제가 보이는 화면의 스크린샷을 올리세요. 스크린샷이 있으면 문제가 있는 페이지, 필드, 버튼, 이름, 메시지를 하이퍼클래스가 눈으로 확인할 수 있어요.
7. 무엇이 잘못되었거나 불분명한지 도움이 될 내용을 적으세요. 어떻게 번역되어야 하는지 알고 있다면 원하는 표현도 함께 적어 주세요.
8. **피드백 제출**을 클릭하세요.

제출하면 신고가 하이퍼클래스로 전달되어 검토돼요. 신고한 번역 문제가 수정되면 해당 안내 채널로 고객에게 알려 드려요.

## 번역 피드백을 잘 보내는 방법

피드백이 구체적일수록 하이퍼클래스가 문제를 빨리 이해하고 알맞은 번역을 검토할 수 있어요. 신고 내용이 자세할수록 문제가 있는 페이지를 찾아 번역을 개선하기가 쉬워요.

신고할 때 이렇게 해 보세요.

- 잘못되었거나 불분명한 텍스트가 잘 보이는 스크린샷을 포함하세요.
- 가장 알맞은 문제 유형을 선택하세요.
- 사용 중인 언어를 적어 주세요.
- 현재 번역에서 무엇이 잘못되었는지 설명하세요.
- 가능하면 원하는 번역이나 의도한 뜻을 알려 주세요.
- 문제가 나타난 페이지에서 신고하세요.
- 일반 지원 문의는 번역 피드백 도구로 보내지 마세요.

## 자주 묻는 질문

### 번역 피드백 아이콘은 누가 볼 수 있나요?
플랫폼 언어가 지원되는 영어 외 언어로 설정되어 있을 때 에이전시 소유자와 에이전시 관리자에게 아이콘이 보여요.

### 에이전시 관리자가 서브 계정 안에서도 번역 문제를 신고할 수 있나요?
네. 에이전시 소유자와 에이전시 관리자는 서브 계정 안에서 작업할 때도, 해당 페이지에 아이콘이 있으면 번역 문제를 신고할 수 있어요.

### 번역 피드백 아이콘이 보이지 않아요.
에이전시 소유자나 에이전시 관리자가 아니거나, 플랫폼 언어가 영어로 설정되어 있거나, 현재 페이지가 번역 피드백 도구를 지원하지 않으면 아이콘이 보이지 않을 수 있어요.

### 스크린샷을 꼭 올려야 하나요?
신고할 때 스크린샷을 올려 주세요. 번역 문제가 있는 화면을 하이퍼클래스가 눈으로 확인할 수 있어요.

### 어떤 번역 문제를 신고해야 하나요?
잘못된 번역, 불분명한 표현, 빠진 번역, 번역되지 않은 텍스트, 의도한 뜻과 맞지 않는 번역된 이름이나 안내 문구를 신고하세요.

### 문제가 해결되면 알림을 받나요?
신고한 번역 문제가 해결되면 하이퍼클래스가 고객에게 알려 드려요.
