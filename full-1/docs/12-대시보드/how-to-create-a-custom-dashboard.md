# 커스텀 대시보드 만들기

대시보드를 여러 개 만들고 관련 위젯을 한 화면에 모아 두면, 내게 필요한 지표만 골라서 볼 수 있어요. 이 문서에서는 새 대시보드를 만들고 위젯을 추가하는 순서를 안내해요.

[동영상](https://www.youtube.com/embed/\_tCmp-nhkLQ?&wmode=opaque)

{% hint style="info" %}
커스텀 위젯과 리포트는 모든 요금제에서 쓸 수 있어요(커스텀 대시보드 개수 무제한).
{% endhint %}

## 커스텀 대시보드란?

커스텀 대시보드는 서브 계정마다 있는 분석 공간이에요. 연락처, 예약, 기회, 통화, 매출 등의 핵심 지표(KPI)를 이곳에서 확인할 수 있어요. 레이아웃, 추가할 위젯, 위젯이 사용할 지표는 물론 대시보드의 겉모습과 리포트 자동 발송까지 직접 정할 수 있어요.

## 커스텀 대시보드의 주요 장점

- 여러 대시보드: 영업, 마케팅, 재무 등 팀마다 전용 대시보드를 만들 수 있어요. 그중 하나를 기본 대시보드로 지정할 수도 있어요.
- 커스텀 위젯과 지표: 지표를 제한 없이 추가하고 편집하고 업데이트해서, 가장 중요한 인사이트를 바로 볼 수 있어요.
- 예약 리포트: 원하는 주기로 리포트를 예약해서 팀에 자동으로 보낼 수 있어요.
- 자유로운 꾸미기: 테마, 색상, 배경을 바꿔 브랜드에 맞게 대시보드를 꾸밀 수 있어요.
- 더 깊은 인사이트: 표를 비롯한 여러 형식으로 데이터를 보고 분석할 수 있어요.
- 범용 위젯: 범용 위젯을 추가하거나 제거해서 에이전시의 업무 방식에 맞는 대시보드를 만들 수 있어요.

## 커스텀 대시보드 만드는 순서

다음 단계를 따라 내게 맞는 대시보드를 만들어 보세요.

#### 1단계: 대시보드 영역으로 이동하기

서브 계정에서 **대시보드** 메뉴로 이동하세요.

![대시보드 메뉴로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044225708/original/c2DzFwVfMi2tICWSVmbrqzYVnAZgoFaiHA.png?1743298746)

#### 2단계: 새 대시보드 추가하기

**Dashboard Selection Menu**(대시보드 선택 메뉴)를 클릭하고, 펼쳐진 목록에서 **+ Add Dashboard**(대시보드 추가) 버튼을 클릭하세요.

{% hint style="info" %}
이 버튼이 보이지 않으면 대시보드 보기 모드인지 확인하세요.
{% endhint %}

![대시보드 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044353813/original/kR7TkjtsM2b7qeuqmuypFcq9mVp_3AlIPQ.png?1743545895)

#### 3단계: 대시보드 이름 입력하기

**Dashboard Name**(대시보드 이름) 필드에 이름을 입력하세요.

![대시보드 이름 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044353863/original/Zil6-u30DIU_lRTQhSZDJhWf5sEaZqZzKw.png?1743546127)

#### 4단계: 대시보드 권한 설정하기

**Private Dashboard**(비공개 대시보드) 토글로 공개 범위를 정해요. **켜짐**으로 설정하면 나만 볼 수 있고, **끄기**로 설정하면 팀원도 접근할 수 있어요.

**Private Dashboard**를 **끄기**로 설정했다면 **Agency User**(에이전시 사용자), **계정 관리자**, **계정 사용자**별로 접근 권한 수준을 정하세요.

{% hint style="info" %}
이 토글이 보이지 않으면 아직 **New Dashboard**(새 대시보드) 페이지에 있는지 확인하세요.
{% endhint %}

#### 5단계: 확인하고 대시보드 만들기

**확인** 버튼을 클릭하면 대시보드가 만들어져요. 비어 있는 새 대시보드가 열려요.

![확인 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044353921/original/mO8decxxk166CBFXYkMVHqq7IYTTik0zMw.png?1743546348)

#### 6단계: 위젯 추가 방법 고르기

대시보드를 만들면 **Quick Start Widgets**(빠른 시작 위젯) 페이지가 나와요. 위젯이 하나도 없는 대시보드에서는 항상 이 페이지가 기본으로 보여요. 여기서 아래 세 가지 방법 중 하나를 고르세요.

**방법 A: 추천 위젯 사용하기**

**What is your goal?**(목표가 무엇인가요?) 또는 **많이 사용된 위젯** 빠른 시작 옵션에서 인기 위젯을 하나 이상 선택하세요. 대시보드에 위젯이 없을 때마다 이 화면이 나와요.

**Confirm & Add**(확인 및 추가)를 클릭하면 많이 사용된 위젯이 바로 추가돼요.

그다음 9단계로 넘어가세요.

![추천 위젯 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044353940/original/93v7TUuBYpKB9b74ZV8QZu0Gy9dBl0qicw.png?1743546469)

**방법 B: 위젯 직접 추가하기**

**+ 위젯 수동으로 추가**를 클릭하면 **새 위젯 추가** 패널이 열려요.

7단계로 넘어가세요.

![위젯 수동으로 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044353962/original/fGrCtpdkC53BdmRMkUQphyEXqE_1wcKKJQ.png?1743546541)

**방법 C: 편집 모드에서 위젯 추가하기**

**편집** 버튼(연필 아이콘)을 클릭한 뒤, 편집 모드에서 **+ Add Widget**(위젯 추가)을 클릭하세요.

{% hint style="info" %}
이 버튼이 보이지 않으면 편집 모드에 들어왔는지 확인하세요.
{% endhint %}

7단계로 넘어가세요.

![편집 모드에서 위젯 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044353966/original/YjAZUQzh-9Siut7pCQGsuS2yy3cRkxfIHw.png?1743546583)

#### 7단계: 새 위젯 설정하기

**새 위젯 추가** 패널에서 위젯 설정을 정하세요.

자세한 내용은 "Subaccount Dashboard Page - Widgets Add or Edit" 문서를 참고하세요.

![새 위젯 추가 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044354006/original/NTqv3HbxTGH8pQ-8JNPnmknTN3zl42bjDw.png?1743546678)

#### 8단계: 위젯 저장하기

위젯 패널에서 **저장** 버튼을 클릭하세요.

![위젯 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044227004/original/qrQfZeuE1i03OEhJ78hoxVK1LP1a6I1LeA.png?1743309668)

#### 9단계: 대시보드 편집 내용 저장하기

**✓ 변경사항 저장** 버튼을 클릭하면 끝나요. 레이아웃이 저장되고 편집 모드가 종료돼요.

![변경사항 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044227016/original/Cuoneqt7gq0pL1dRLM9BCG7pKjJR9pIlOg.png?1743309746)

## 자주 묻는 질문

### 커스텀 대시보드와 커스텀 리포트는 어떤 요금제에서 쓸 수 있나요?
모든 요금제($97, $297, $497)에서 여러 대시보드와 커스텀 리포트를 쓸 수 있어요.

### 어떤 차트 유형을 쓸 수 있나요?
위젯에서는 스코어카드, 시계열, 막대/열, 도넛/파이, 표 같은 여러 차트 유형을 지원해요. 어떤 유형을 쓸 수 있는지는 위젯마다 달라요.

### 사용자가 아닌 사람(예: 고객)에게도 리포트를 보낼 수 있나요?
네. **수신자**에 유효한 이메일 주소를 추가하면 돼요.

### 대시보드를 복제할 수 있나요?
네. 대시보드 작업 메뉴에서 복제한 뒤 위젯, 필터, 테마를 원하는 대로 조정하세요.
