# 즐겨 찾는 대시보드 고정하기

자주 보는 대시보드를 고정해 두면 필요할 때 바로 찾아 열 수 있어요. 아래 단계를 따라 대시보드를 고정해 보세요.

## 대시보드 고정이란?

대시보드를 고정한다는 것은 즐겨찾기로 표시해 찾기 쉬운 위치에 항상 보이게 한다는 뜻이에요. 대시보드가 많을 때 자주 쓰는 대시보드를 목록 맨 위에 둘 수 있어요.

## 대시보드 고정하기

### 1단계: 대시보드 목록 열기

서브 계정에서 **대시보드**로 이동한 다음, 대시보드 선택 메뉴를 클릭하세요.

![대시보드 선택 메뉴를 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044573701/original/lGAZkOMsZlvikj4O4Uy8pMf_tqmFco1bGQ.png?1743805342)

### 2단계: 고정할 대시보드 찾기

대시보드 선택 메뉴에서 고정할 대시보드를 찾으세요. 목록에서 대시보드가 보일 때까지 검색하거나 스크롤하면 돼요.

![고정할 대시보드를 찾은 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044573721/original/kVf8YRqVT03MJ9mP5QMGdCMW-irh5NvP0A.png?1743805467)

### 3단계: 대시보드 고정하기

작은 핀 모양 버튼을 클릭해 회색에서 파란색으로 바꾸세요. 그러면 해당 대시보드가 속한 목록의 맨 위에 항상 표시돼요. 대시보드는 여러 개 고정할 수 있어요.

![핀 버튼을 눌러 대시보드를 고정한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044573734/original/D8mmo8iMYC5olH6lC3nzsRualL7nC6eItg.png?1743805601)
