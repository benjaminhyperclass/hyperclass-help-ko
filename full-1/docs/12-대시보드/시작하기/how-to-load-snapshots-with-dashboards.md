# 대시보드와 함께 스냅샷 불러오기

하이퍼클래스 스냅샷을 쓰면 에이전시가 대시보드 구성을 대상 서브 계정으로 복사할 수 있어요. 대시보드를 하나하나 다시 만들 필요가 없어요. 스냅샷을 불러올 때 복사할 대시보드를 고르고, 그중 하나를 대상 서브 계정의 기본 대시보드로 정할 수 있어요. 새 기본 대시보드를 고르지 않으면 하이퍼클래스는 스냅샷에 이미 지정된 기본 대시보드를 사용해요.

## 이 문서에서 알 수 있는 내용

스냅샷을 불러올 때 대시보드 자산을 선택하는 방법, 대상 서브 계정의 기본 대시보드를 정하는 방법, 대시보드 종속 항목과 권한을 확인하는 방법, 자산 충돌을 처리하는 방법, 불러오기가 끝난 뒤 가져온 대시보드를 확인하는 방법을 설명해요. 에이전시 관리자가 쓰는 기능이에요.

## 대시보드와 함께 스냅샷 불러오기란?

스냅샷으로 대시보드를 불러오면 선택한 대시보드 구성을 이미 있는 서브 계정에 복사할 수 있어요. 계정마다 대시보드를 직접 다시 만들지 않아도 에이전시가 일관된 리포팅 화면을 배포할 수 있어요.

스냅샷을 불러올 때 가져올 대시보드를 고르고, 원하면 선택한 대시보드 중 하나를 대상 서브 계정의 기본 대시보드로 표시할 수 있어요. 새 기본 대시보드를 표시하지 않으면 하이퍼클래스는 스냅샷에 이미 지정된 기본 대시보드를 사용해요.

### 이럴 때 편해요

스냅샷으로 대시보드를 불러오면 스냅샷 배포 후에 필요한 수작업이 줄어들어 리포팅 화면을 통일하기 쉬워요.

- 빠른 배포: 서브 계정마다 대시보드를 새로 만들지 않고 기존 대시보드 구성을 복사해요.
- 기본 대시보드 지정: 스냅샷을 불러오는 중에 대상 서브 계정의 기본 대시보드를 정해요.
- 수작업 감소: 기본 대시보드만 바꾸려고 불러온 뒤 대상 서브 계정을 다시 열 필요가 없어요.
- 유연한 기본값: 다른 대시보드를 고를 필요가 없으면 스냅샷의 기존 기본 대시보드를 그대로 써요.

### 사전 조건과 제한 사항

불러오기 전에 대시보드, 권한, 종속 항목을 미리 확인하면 대상 서브 계정에서 데이터가 빠지거나 접근이 안 되는 문제를 줄일 수 있어요.

- 불러오려는 대시보드가 스냅샷에 들어 있어야 해요.
- 비공개 대시보드는 스냅샷 자산 목록에 포함되지 않아요.
- 스냅샷을 불러오는 동안 기본 대시보드로 표시할 수 있는 대시보드는 선택한 것 중 하나뿐이에요.
- 기본 대시보드로 새로 표시한 대시보드가 없으면 하이퍼클래스는 스냅샷의 기존 기본 대시보드를 사용해요.
- 기본 대시보드를 열어야 하는 사용자는 해당 대시보드에 대해 최소 **보기** 권한이 있어야 해요.
- 대시보드 위젯이 참조하는 **커스텀 값**이나 **파이프라인** 같은 지원되는 자산은 필요하면 함께 포함하세요.

{% hint style="warning" %}
필요한 연결 자산이 대상 서브 계정에 없으면 대시보드 자체는 정상적으로 불러와져도 일부 위젯에 문제가 생길 수 있어요.
{% endhint %}

## 대시보드와 함께 스냅샷 불러오는 방법

스냅샷 불러오기 과정에서 대시보드 자산 선택, 대상 서브 계정의 기본 대시보드 지정, 필요한 지원 자산 포함, 충돌 확인을 할 수 있어요. 변경 사항이 적용되기 전에 마지막으로 가져오기를 확인하는 단계도 있어요.

1. **에이전시 보기**에서 왼쪽 메뉴의 **서브 계정**을 선택하세요. 대상 서브 계정을 찾아 점 3개 메뉴를 클릭한 다음 **고객 관리**를 선택하세요.
2. 오른쪽 위의 **작업**을 클릭하고 **Load Snapshot**(스냅샷 불러오기)을 선택하세요.
3. **스냅샷 선택**을 열어 불러올 스냅샷을 고르고 **계속하기**를 클릭하세요.
4. 자산 목록에서 **대시보드**를 찾아, 대상 서브 계정으로 불러올 대시보드 자산을 선택하세요.
5. 기본 대시보드를 정하려면 선택한 대시보드 중 하나에서 **기본값으로 설정**을 클릭하세요.
   - 선택한 다른 대시보드에서 **기본값으로 설정**을 클릭하면 기본 대시보드 선택이 그 대시보드로 옮겨져요.
   - 현재 기본으로 표시된 대시보드를 다시 클릭하면 선택이 해제돼요.
   - 표시된 대시보드가 없으면 하이퍼클래스는 스냅샷의 기존 기본 대시보드를 사용해요.

   ![기본값으로 설정을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081950016/original/Pk6EbhQ-9DIZwMZyeyTwHA0imFbbLmx1qQ.png?1790542342)

6. 대시보드에 필요한 다른 스냅샷 자산을 선택하세요. 예를 들어 대시보드 위젯이 참조하는 지원되는 **커스텀 값**이나 **파이프라인**이 있어요. 선택한 뒤 **계속하기**를 클릭하세요.
7. 대상 서브 계정에서 감지된 충돌을 확인하세요. 기존 자산을 바꾸려면 **Override**(덮어쓰기)를, 기존 버전을 유지하려면 **건너뛰기**를 선택하세요.
8. 충돌을 확인한 뒤 **계속하기**를 클릭하세요. 안내가 나타나면 `confirm`을 입력하고 **계속하기**를 클릭해 스냅샷 불러오기를 시작하세요.
9. **에이전시 보기**에서 **서브 계정**을 선택하고 대상 서브 계정을 연 다음, 왼쪽 메뉴에서 **대시보드**를 선택하세요. 원하는 대시보드가 기본으로 설정되어 있는지, 위젯이 제대로 표시되는지 확인하세요.

{% hint style="info" %}
불러온 뒤에는 기본 대시보드 선택과 대시보드 사용자 권한을 모두 확인하세요. 그래야 원하는 사용자가 대시보드를 문제없이 열 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 스냅샷을 불러온 뒤에 기본 대시보드를 바꿀 수 있나요?
네, 가능해요. 나중에 대상 서브 계정에서 기본 대시보드를 바꿀 수 있어요.

### 스냅샷을 불러온 뒤 기본 대시보드는 누가 직접 바꿀 수 있나요?
계정 관리자(Account Admin)와 해당 대시보드에 **FULL**(전체) 권한이 있는 에이전시 역할이 기본 대시보드로 설정할 수 있어요.

### 현재 기본 대시보드로 설정된 대시보드를 삭제할 수 있나요?
아니요. 현재 기본 대시보드를 삭제하려면 먼저 다른 대시보드를 기본으로 지정하세요.

### 기본 대시보드와 고정된 대시보드는 같은 건가요?
아니요. 기본 대시보드는 사용자가 **대시보드** 영역을 열 때 가장 먼저 보는 주요 대시보드예요. 고정된 대시보드는 사용자 개인이 즐겨 찾는 대시보드예요.
