# 대시보드 시간대 변경하기 (로그인한 사용자)

**대시보드**에서 시간대를 바꿔 내 시간대 기준으로 데이터를 볼 수 있어요. 시간대가 달라서 생기는 데이터 차이를 줄이고 싶을 때 사용하세요.

## 중요 사항

- 선택한 시간대는 내가 보는 모든 대시보드에 적용돼요.
- 시간대 변경은 내부 데이터 지표에만 적용돼요. 외부 서비스에 의존하는 위젯에는 적용되지 않아요.
- 커스텀 대시보드에 대한 자세한 내용은 별도 도움말을 참고하세요.

## 대시보드 시간대 변경 방법

아래 단계를 따라 로그인한 사용자 기준으로 대시보드에 표시되는 시간대를 변경해 보세요.

### 1단계: 대시보드 열기

내 개인 대시보드든 공유 대시보드든 상관없어요. 왼쪽 메뉴에서 **대시보드**를 선택한 다음, 시간대를 바꾸고 싶은 대시보드로 이동하세요.

![왼쪽 메뉴에서 대시보드를 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061627072/original/0rr6MBwvKjxpqsvZ5naROHsGBSlBqcqj0Q.png?1767115891)

### 2단계: 시간대 설정 열기

오른쪽 위에 있는 점 3개 메뉴 아이콘을 클릭하세요. 드롭다운에서 **대시보드 시간대 관리**를 선택하세요.

![점 3개 메뉴에서 대시보드 시간대 관리를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061627188/original/f3RDaBSAtTAd_vqHbGR7j2uu2yYU-SWiAw.png?1767115984)

### 3단계: 시간대 선택하기

드롭다운 메뉴에서 원하는 시간대를 선택하고 **저장**을 클릭하세요.

![시간대를 선택하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061627277/original/3NueyrIVMlAxD0OAbN6IWncXc9rRtofXUQ.png?1767116057)
