# 기본 대시보드 설정하기

기본 대시보드를 정해 두면 팀원 모두가 가장 중요한 지표를 같은 화면에서 확인할 수 있어요. 팀원이 **대시보드** 메뉴에 들어갈 때 가장 먼저 보이는 화면이 바로 기본 대시보드예요.

## 1단계: 대시보드로 이동하기

1. 기본으로 설정할 대시보드로 이동하세요. 팀에 가장 중요한 지표가 모여 있는 메인 대시보드를 고르면 좋아요.

## 2단계: 점 세 개 메뉴 클릭하기

1. 대시보드 오른쪽 위에 있는 점 세 개 메뉴를 클릭하세요.

![대시보드 오른쪽 위의 점 세 개 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155023276214/original/orM5y3E5pL2EWFTewRJqeaMrBCcXmcWtGQ.png?1711008631)

## 3단계: 기본값으로 설정 선택하기

1. 메뉴에서 **기본값으로 설정**을 선택하세요.

![메뉴에서 기본값으로 설정 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155023276234/original/U77W-OGZ7oM2SUZITpZqeERoI5S-QxCODQ.png?1711008660)

## 4단계: 확인하기

1. **확인**을 클릭하세요.

## 알아 두세요

1. 필요한 권한: 대시보드에 **FULL**(전체 권한) 권한이 있는 **계정 관리자** 또는 **에이전시** 역할의 사용자만 기본 대시보드를 설정할 수 있어요. 대시보드 권한에 대해 더 알고 싶다면 대시보드 권한 관리 문서를 참고하세요.
2. 보기 권한: 대시보드를 기본으로 설정하려면 모든 팀 멤버에게 최소한 **보기** 권한이 있어야 해요.
3. 삭제할 수 없는 기본 대시보드: 기본 대시보드로 설정한 대시보드는 다른 대시보드를 기본으로 지정하기 전까지 삭제할 수 없어요.
4. 기본 대시보드와 고정 대시보드의 차이: 기본 대시보드는 모든 사용자가 처음 보는 대표 화면이에요. 고정 대시보드는 사용자가 개인적으로 즐겨 찾는 대시보드로, 빠르게 열어 볼 수 있어요.

{% hint style="warning" %}
이번 릴리스 이후 기본 대시보드가 바뀌는 문제가 있다면, 위 안내대로 다시 설정해서 되돌릴 수 있어요. 기존 대시보드와 위젯에는 영향이 없어요. 릴리스 후 버그가 확인되어 수정 패치를 배포했어요. 그래도 문제가 계속되면 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}
