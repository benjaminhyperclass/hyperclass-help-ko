# 대시보드와 리포트에서 쓰는 연락처 위젯

연락처 위젯을 쓰면 연락처 데이터를 대시보드와 사용자 지정 리포트 안에서 바로 확인할 수 있어요. 이 문서에서는 위젯 종류, 차트 유형, 그룹 기준, 날짜 속성, 조건 필터를 설명해요.

## 개요

연락처 위젯으로 연락처 데이터를 대시보드와 사용자 지정 리포트 안에서 바로 시각화하고 분석할 수 있어요. 전체 연락처 수, 출처나 유형별 분포, 시간에 따른 추이를 한눈에 볼 수 있어요. 데이터를 내보내거나 스프레드시트에 옮길 필요가 없어요.

모든 연락처 위젯은 여러 차트 유형을 지원해요. **조건**으로 원하는 그룹의 연락처만 골라서 볼 수도 있어요.

---

## 사용할 수 있는 연락처 위젯

연락처 위젯은 모두 **17개**예요. 각 위젯은 기본 차트 유형으로 열리고, 위젯 설정에서 지원하는 다른 차트 유형으로 바꿀 수 있어요.

| 번호 | 위젯 이름 | 기본 차트 | 보여 주는 내용 | 기본 날짜 범위 |
| --- | --- | --- | --- | --- |
| 1 | **Contacts Count**(연락처 수) | 숫자 | 전체 연락처 수 | 대시보드 날짜 범위 |
| 2 | **Contacts Count (Logged in user)**(연락처 수, 로그인한 사용자 기준) | 숫자 | 현재 로그인한 사용자에게 할당된 연락처 수 | 대시보드 날짜 범위 |
| 3 | **Contacts Count Over Time**(기간별 연락처 수) | 줄 | 기간에 따라 연락처 추가가 어떻게 변하는지 | 대시보드 날짜 범위 |
| 4 | **Contacts Counts by Activity**(활동별 연락처 수) | 도넛형 | 날짜 범위 안에 특정 활동이 있는 연락처 수 | 대시보드 날짜 범위 |
| 5 | **Contacts Counts by Tags**(태그별 연락처 수) | 도넛형 | 태그별 연락처 분포 | 대시보드 날짜 범위 |
| 6 | **Contacts Counts by Type**(유형별 연락처 수) | 도넛형 | 연락처 유형별 분포 | 대시보드 날짜 범위 |
| 7 | **Contacts by Assigned User**(할당된 사용자별 연락처) | 도넛형 | 팀원별 연락처 배정 현황 | 대시보드 날짜 범위 |
| 8 | **Contacts by Company Name**(회사명별 연락처) | 도넛형 | 회사명별 연락처 분포 | 대시보드 날짜 범위 |
| 9 | **Contacts by Medium**(미디엄별 연락처) | 도넛형 | 어트리뷰션 미디엄별 연락처 분포 | 대시보드 날짜 범위 |
| 10 | **Contacts by Source**(출처별 연락처) | 도넛형 | 어트리뷰션 출처별 연락처 분포 | 대시보드 날짜 범위 |
| 11 | **Contacts with Email**(이메일이 있는 연락처) | 숫자 | 이메일 주소가 등록된 연락처 수 | 대시보드 날짜 범위 |
| 12 | **Contacts with Phone Number**(전화번호가 있는 연락처) | 숫자 | 전화번호가 등록된 연락처 수 | 대시보드 날짜 범위 |
| 13 | **Contacts without Email**(이메일이 없는 연락처) | 숫자 | 이메일 주소가 없는 연락처 수 | 대시보드 날짜 범위 |
| 14 | **Contacts without Phone Number**(전화번호가 없는 연락처) | 숫자 | 전화번호가 없는 연락처 수 | 대시보드 날짜 범위 |
| 15 | **Top Sources for Contacts Created**(연락처 생성 상위 출처) | 바 | 새 연락처를 가장 많이 만든 출처 순위 | 대시보드 날짜 범위 |
| 16 | **Total Contacts Count (This Month)**(전체 연락처 수, 이번 달) | 숫자 | 현재 달력 월에 생성된 전체 연락처 수 | 이번 달(고정) |
| 17 | **Total Contacts Count (Till Date)**(전체 연락처 수, 누적) | 숫자 | 처음부터 지금까지 생성된 누적 연락처 수 | 지금까지 누적(고정) |

{% hint style="info" %}
위젯 16번과 17번은 **고정 날짜 범위**를 써요. 그래서 대시보드의 전체 날짜 범위 선택기를 따르지 않아요.
{% endhint %}

{% hint style="info" %}
위젯 9번(**Contacts by Medium**), 10번(**Contacts by Source**), 15번(**Top Sources for Contacts Created**)에는 **최근 어트리뷰션** 필터가 기본으로 들어 있어요. 그래서 각 연락처의 가장 최근 접점을 기준으로 어트리뷰션 데이터를 보여 줘요.
{% endhint %}

### 지원하는 차트 유형

연락처 위젯 17개는 모두 위젯 설정에서 아래 차트 유형으로 바꿀 수 있어요.

| 차트 유형 | 이럴 때 좋아요 |
| --- | --- |
| **숫자** | 핵심 지표 하나, 빠른 수 확인 |
| **도넛형** | 카테고리별 분포 |
| **바** | 카테고리 간 값 비교 |
| **줄** | 시간에 따른 추이 |
| **Horizontal Bar**(가로 바) | 이름이 긴 카테고리가 많을 때 비교 |
| **테이블** | 행 단위로 자세히 보기 |

## 그룹 기준 옵션

데이터를 나누어 볼 기준을 지원하는 위젯(`has_group_by = TRUE`)은 아래 필드로 묶어 볼 수 있어요. **그룹 기준**은 위젯 3번~10번과 15번에서 쓸 수 있어요.

| 그룹 기준 옵션 | 묶는 기준 |
| --- | --- |
| **담당자** | 각 연락처에 할당된 사용자 |
| **출처** | 연락처가 생성된 출처 |
| **태그** | 연락처에 적용된 태그 |
| **팔로워** | 연락처를 팔로우하는 사용자 |
| **회사명** | 연락처가 연결된 회사 |
| **연락처 유형** | 연락처의 유형 분류 |
| **국가** | 연락처의 국가 |
| **활동** | 연락처와 관련된 활동 유형 |
| **세션 소스** | 세션 단위의 트래픽 출처(예: 자연 검색, 유료 소셜) |
| **미디엄** | 어트리뷰션 미디엄(예: 폼, Facebook, 캘린더) |

{% hint style="info" %}
**그룹 기준** 옵션은 적용된 **조건** 필터 위에서 작동해요. 먼저 조건으로 데이터를 좁히고, 그다음 기준을 골라 그 안의 분포를 확인해 보세요.
{% endhint %}

## 날짜 속성

연락처 위젯은 아래 날짜 필드를 기준으로 집계할 수 있어요. 날짜 속성은 대시보드 날짜 범위를 적용할 때 어떤 시점을 기준으로 삼을지 정해요.

| 날짜 속성 | 설명 |
| --- | --- |
| **생성일** | 연락처 레코드가 만들어진 시점(대부분의 위젯에서 기본값) |
| **업데이트됨** | 연락처 레코드가 마지막으로 수정된 시점 |
| **생년월일** | 연락처의 생년월일 |
| **최근 활동** | 연락처에 기록된 가장 최근 활동의 날짜 |

## 연락처 위젯 필터링하기 (조건)

모든 연락처 위젯은 위젯 설정 패널의 **조건**으로 필터링할 수 있어요. 조건을 쓰면 특정 국가의 연락처만, 또는 특정 어트리뷰션 출처의 연락처만 보는 식으로 위젯의 범위를 좁힐 수 있어요.

사용할 수 있는 조건 필드는 **24개**예요. 일반 필드와 어트리뷰션 필드로 나뉘어요.

### 어트리뷰션 필터

상위 필드인 **어트리뷰션**을 먼저 설정하면 추가 하위 필터를 쓸 수 있어요. 먼저 **첫 번째 어트리뷰션** 또는 **최근 어트리뷰션**을 선택하세요. 그러면 아래 하위 필드가 활성화돼요.

| 조건 필드 | 상위 필드 필요 | 사용할 수 있는 연산자 | 값 입력 방식 |
| --- | --- | --- | --- |
| **어트리뷰션** | — | **Is** | 첫 번째 어트리뷰션 / 최근 어트리뷰션 |
| **미디엄** | 어트리뷰션 | **Is** / **Is not** / **Is one of** / **Is none of** | 폼 / 설문 / 캘린더 / 채팅 위젯 / CSV Import(CSV 가져오기) / 수동 / API / Order Form(주문 폼) / 2단계 주문 폼 / Facebook / TikTok / 멤버십 / 대화 / Zapier / Other(기타) |
| **세션 소스** | 어트리뷰션 | **Is one of** / **Is none of** | Direct Traffic(직접 유입) / Organic Search(자연 검색) / Paid Search(유료 검색) / 소셜 미디어 / Paid Social(유료 소셜) / Referral(추천) / Third Party(서드파티) / CRM UI(CRM 화면) / 이메일 마케팅 / 트리거 링크 / Other(기타) |
| **UTM 매체** | 어트리뷰션 | **Contains**(포함) | 텍스트 입력 |
| **UTM 소스** | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Campaign**(UTM 캠페인) | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Campaign ID**(UTM 캠페인 ID) | 어트리뷰션 | **Is** / **Is not** | 텍스트 입력 |
| **UTM 키워드** | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM 콘텐츠** | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Matchtype**(UTM 매치 유형) | 어트리뷰션 | **Contains** | 텍스트 입력 |
| **UTM Ad ID**(UTM 광고 ID) | 어트리뷰션 | **Is** / **Is not** | 텍스트 입력 |
| **UTM Ad Group ID**(UTM 광고 그룹 ID) | 어트리뷰션 | **Is** / **Is not** | 텍스트 입력 |

{% hint style="info" %}
어트리뷰션 필터는 이렇게 작동해요.

1. 조건 패널에서 **어트리뷰션**을 **첫 번째 어트리뷰션** 또는 **최근 어트리뷰션**으로 설정해요.
2. 설정하고 나면 **미디엄**, **세션 소스**, 모든 UTM 필드를 쓸 수 있어요.
3. 하위 필드는 모두 선택한 어트리뷰션 접점(첫 번째 또는 최근)을 기준으로 적용돼요.
{% endhint %}

## 연락처 위젯을 쓸 수 있는 곳

연락처 위젯 17개는 모두 아래 두 곳에서 쓸 수 있어요.

- ✅ **대시보드** — 상시 모니터링과 매일 확인용
- ✅ **사용자 지정 리포트** — 예약 발송과 고객에게 바로 전달할 수 있는 내보내기용

{% hint style="info" %}
위젯 2번(**Contacts Count (Logged in user)**)은 현재 로그인한 사용자를 기준으로 집계해요. 이 위젯이 수신자에게 발송되는 예약 리포트에 들어 있으면, 수신자가 아니라 리포트를 소유한 사용자의 데이터가 표시돼요.
{% endhint %}

## 자주 묻는 질문

### **Contacts by Source**와 **Contacts by Medium** 위젯에 연락처 일부만 보여요. 왜 그런가요?

이 위젯에는 **최근 어트리뷰션** 필터가 기본으로 들어 있어요. 그래서 어트리뷰션 데이터가 기록된 연락처만 표시돼요. CSV 파일로 가져왔거나, 추적된 세션 없이 수동으로 만든 연락처는 가져올 때 어트리뷰션을 지정하지 않았다면 보이지 않을 수 있어요.

### **Contacts by Source**에서 기본으로 적용된 **최근 어트리뷰션** 필터를 뺄 수 있나요?

어트리뷰션 기본 필터는 위젯 정의에 포함되어 있어요. 이 필터가 없는 버전이 필요하면 **일반** 위젯 카테고리로 전환한 다음 **그룹 기준**을 써서 직접 연락처 분류를 만들 수 있어요.

### 연락처 위젯을 출처 기준으로 묶을 수 있나요?

네, 이제 연락처 위젯에서 **그룹 기준 > 출처** 옵션을 쓸 수 있어요. 연락처 위젯을 추가하거나 편집한 다음, 위젯 설정에서 **그룹 기준** 드롭다운을 열고 **출처**를 선택하세요. 연락처가 어디에서 왔는지에 따라 나누어 볼 수 있어요.

### **출처**(조건 필드)와 **세션 소스**(그룹 기준/조건)는 뭐가 다른가요?

- **출처**는 연락처 레코드의 `source` 필드 값 그대로예요. 보통 연락처가 만들어질 때 정해져요(예: "Facebook 리드 광고", "수동").
- **세션 소스**는 어트리뷰션 단위 필드(`attributions.utm_session_source`)예요. 전환을 일으킨 세션의 트래픽 채널을 나타내요(예: "유료 소셜", "자연 검색"). 상위 필터로 **어트리뷰션**을 먼저 설정해야 쓸 수 있어요.

### 연락처 위젯에도 대시보드의 **빠른 필터**가 적용되나요?

네. 대시보드 수준의 **빠른 필터**는 위젯 수준의 **조건** 위에 추가로 적용돼요. 위젯에 이미 조건이 있으면(예: **국가** = US), 빠른 필터는 그 범위 안에서 결과를 더 좁혀요.

### 대시보드 날짜 범위를 바꿔도 **Total Contacts Count (This Month)**는 왜 그대로인가요?

이 위젯은 **고정 날짜 범위(이번 달)**를 써요. 그래서 대시보드의 전체 날짜 범위로는 조절되지 않아요. 날짜 범위에 따라 달라지는 수가 필요하면 **Contacts Count**(위젯 1번)를 쓰세요.

### 연락처 위젯의 필터 조건으로 커스텀 필드를 쓸 수 있나요?

네. 위젯 설정 패널의 조건 옵션에 **커스텀 필드**가 나와요. 쓸 수 있는 연산자는 커스텀 필드 유형(텍스트, 숫자, 날짜, 드롭다운 등)에 따라 달라요.
