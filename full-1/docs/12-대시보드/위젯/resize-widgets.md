# 위젯 크기 조절하기

위젯의 모서리를 끌어서 크기를 늘리거나 줄일 수 있어요. 대시보드에서 위젯 크기를 원하는 대로 바꾸고 싶을 때 쓰세요.

[동영상](https://www.youtube.com/embed/t8y6F2D9Rek?&wmode=opaque)

## 1단계: 편집 모드로 전환하기

1. 대시보드에서 **편집** 버튼을 클릭하세요.

   ![대시보드에서 편집 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010312014/original/wuCiEW339qP1nJXuhe8nIIkWPExQpqPbEQ.jpeg?1697544454)

## 2단계: 위젯 모서리의 화살표 아이콘 끌기

1. 위젯 모서리에 있는 화살표 아이콘을 클릭한 채로 끌어서 크기를 조절하세요.

   ![위젯 모서리의 화살표 아이콘을 끌어 크기를 조절하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010312017/original/v-5n2Zkjlzfe7hpijadi1piM-0g9qBPrOg.png?1697544455)

## 3단계: 변경사항 저장하기

1. 크기 조절을 마쳤으면 잊지 말고 **변경사항 저장**을 클릭하세요.

   ![변경사항 저장 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155010312013/original/gOpwSLsBUP1OG_6CohEgt0kNP8LUCTphdQ.jpeg?1697544454)

2. 변경한 내용을 되돌리고 싶다면 **취소**를 클릭하세요. 위젯이 이전 상태로 돌아가요.

{% hint style="info" %}
어떤 요금제에서 맞춤 설정이 가능한 대시보드를 쓸 수 있는지 궁금하신가요?

현재는 $497 요금제 이상에서만 쓸 수 있어요. $97 또는 $297 요금제를 쓰고 있다면 요금제를 올려야 이 기능을 쓸 수 있어요.

$497 이상 요금제에서는 에이전시 관리자와 에이전시 사용자가 **맞춤 대시보드**를 사용할 수 있어요.

대시보드 권한 관리에 대한 자세한 내용도 확인해 보세요.
{% endhint %}
