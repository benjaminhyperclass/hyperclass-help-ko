# 서브 계정 대시보드 페이지 보기와 편집

서브 계정 대시보드의 화면 구성과 사용법을 설명해요. 대시보드를 보는 방법, 새로 만드는 방법, 편집 모드에서 위젯을 다루는 방법을 한 번에 확인할 수 있어요.

[동영상](https://www.youtube.com/embed/5bi1PmuYQy0?&wmode=opaque)

## 서브 계정 대시보드란?

대시보드는 서브 계정의 현황을 보여 주는 리포트예요. 원하는 대로 구성할 수 있고 항상 최신 상태로 유지돼요. 먼저 대시보드가 가질 수 있는 상태와 모드를 알아볼게요.

### 대시보드 상태

- **위젯이 있는 상태**(1개 이상): 대시보드의 일반적인 상태예요. 여러 위젯과 요소가 표시돼요.

  ![위젯이 있는 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079585437/original/fLrqkhfURbyOEilmkaRnKkgx1j48da4ZhA.png?1787945040)
- **위젯이 없는 상태**(0개): 빈 화면 대신 여러 가지 빠른 시작 옵션이 표시돼요. 위젯을 추가하거나 만들어서 시작하세요.

  ![위젯이 없는 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079585479/original/PM7r6ddqljiwIY0osUf9jPotNXFvx1ViHQ.png?1787945109)

### 대시보드 모드

- **보기 모드**: 필터와 함께 위젯 목록이 표시돼요. 날짜와 필터를 바꿔 가며 서브 계정의 활동을 확인하는 기본 상태예요.

  ![보기 모드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079585550/original/5r2Yc5_BcqdYkCexn_PXQZRpmycAxxUk0A.png?1787945233)
- **편집 모드**: 위젯 목록에 편집 옵션이 함께 표시돼요. 잠시 편집 모드로 바꾸면 위젯을 끌어서 배치를 바꾸고, 위젯과 요소를 추가하거나 삭제하고, 테마나 제목을 바꿀 수 있어요.

  ![편집 모드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079585585/original/BCTl8nb41xZscdLLSptdwNPsS3q1k6ztHA.png?1787945281)

## 대시보드 구성 요소 한눈에 보기

1. **대시보드 선택 메뉴**: 패널 아이콘과 아래쪽 화살표가 있는 파란색 버튼이에요. 클릭하면 대시보드 선택 메뉴가 펼쳐져요.
2. **날짜 선택**: 날짜 두 개 또는 기간이 표시된 달력이에요. 클릭해서 다른 기간을 선택하세요.

   대시보드는 선택한 기간을 사용자별로 저장해요. 대시보드 단위의 비교 기간도 적용할 수 있어요.
3. **편집 버튼**: 연필 아이콘이에요. 클릭하면 보기 모드에서 편집 모드로 바뀌어요.
4. **작업 메뉴**: 세로 점 세 개 아이콘이에요. 클릭하면 작업 메뉴가 열려요.
5. **빠른 필터 버튼**: 파란색 연필 아이콘과 **빠른 필터**가 표시된 버튼이에요. 클릭하면 빠른 필터 사이드 패널이 열려요.
6. **필터 알약**: 필터 이름과 아래쪽 화살표가 있는 흰색 알약 모양 버튼이에요. 클릭하면 필터를 조정하는 창이 열려요.
7. **위젯**: 대시보드에 들어 있는 위젯 목록이에요.
8. **Summarise with AI**(AI로 요약): AI가 선택한 대시보드의 전체 요약을 만들어 줘요.
9. **빠른 시작 옵션**: 대시보드에 위젯이 없을 때 표시돼요.

### 날짜 선택

**날짜 선택**에서는 현재 대시보드 전체에 적용되는 기간을 정할 수 있어요.

- 선택한 대시보드 기간은 사용자별로 자동 저장돼요.
- 페이지를 새로고침하거나 나중에 다시 들어와도 마지막으로 저장한 기간으로 대시보드가 열려요.
- 대시보드 단위의 비교 기간도 설정할 수 있어요.
- 일반 위젯은 위젯에 비교 설정이 따로 없으면 대시보드 단위의 비교 기간을 사용해요.
- 위젯에 비교 기간이 직접 지정되어 있으면 대시보드 단위 비교 기간보다 위젯 설정이 우선해요.

삭제된 파이프라인처럼 저장해 둔 필터 값을 더 이상 쓸 수 없으면, 하이퍼클래스가 사용할 수 있는 첫 번째 옵션을 자동으로 선택해요.

### 대시보드 선택 메뉴

1. **검색란**: **대시보드 검색**이라고 표시돼요. 입력하면 대시보드가 걸러져요.
2. **Add Dashboard**(대시보드 추가) 버튼: 파란색 "+ Add Dashboard" 버튼이에요. 클릭하면 대시보드 만들기 페이지가 열려요.
3. **My Dashboards**(내 대시보드) 목록: 내가 만든 대시보드가 나열돼요.
4. **나와 공유됨** 목록: 다른 사람이 공유해서 내가 접근할 수 있는 대시보드가 나열돼요.
5. **대시보드 열기 버튼**: 아이콘과 대시보드 이름이 있는 버튼이에요. 클릭하면 보기 모드로 대시보드가 열려요.
6. **고정 버튼**: 핀 아이콘이에요. 클릭하면 대시보드를 목록 맨 위에 고정하거나 고정을 풀어요. 고정하지 않은 대시보드는 보통 가나다·알파벳순으로 정렬돼요.

![대시보드 선택 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043696399/original/g6ikXcxk5KcX69vrk47Q-r0YlC2KGp_lmw.png?1742501210)

## 대시보드 추가·만들기

1. **뒤로** 버튼: "< 뒤로"로 표시돼요. 클릭하면 대시보드로 돌아가요.
2. **Create a Blank Dashboard**(빈 대시보드 만들기) 카드: "Create a Blank Dashboard. 깨끗하게 새로 시작하기. Select."라고 적힌 카드예요. 클릭하면 빈 대시보드 만들기가 시작돼요.
3. **템플릿으로 만들기** 카드: "From Template Library. Use a Readymade Template from Library or one of yours. Select."라고 적힌 카드예요. 클릭하면 템플릿으로 새 대시보드를 만들기 시작해요.
4. **Clone Existing Dashboard**(기존 대시보드 복제) 카드: "Clone Existing Dashboard. Make Clone of your Existing Dashboard. Select."라고 적힌 카드예요. 클릭하면 기존 대시보드를 복제하기 시작해요.

![대시보드 만들기 방법 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043958511/original/3UyApDwKSBdtKqDhPx71RW2EPMfVINC9qw.png?1742930300)

### 새 대시보드 만들기

1. **대시보드 이름 입력란**: "예: 기회 개요"처럼 예시 문구가 보이는 입력란이에요. 새 대시보드 이름을 입력하세요.
2. **Private Dashboard**(비공개 대시보드) 토글: "Set up this dashboard so only you can see it. It won't be visible to other team members."라는 설명이 붙은 토글이에요. 켜면(파란색, 오른쪽) 나만 볼 수 있는 비공개 대시보드가 돼요. 끄면(회색, 왼쪽) 접근 권한 설정이 나타나요.
3. **에이전시 사용자** 드롭다운: 에이전시 사용자의 접근 권한을 선택해요.
4. **계정 관리자** 드롭다운: 계정 관리자의 접근 권한을 선택해요.
5. **계정 사용자** 드롭다운: 계정 사용자의 접근 권한을 선택해요.
   - 접근 권한 옵션
     - **전체**: 전체 권한이에요.
     - **편집**: 편집만 할 수 있어요.
     - **보기**: 보기만 할 수 있어요.
     - **No Access**(접근 불가): 접근할 수 없어요.
6. **취소** 버튼: 흰색 버튼이에요. 클릭하면 새 대시보드 창을 닫고 설정을 버려요.
7. **확인** 버튼: 파란색 버튼이에요. 클릭하면 새 대시보드를 만들고 바로 열어요.

![새 대시보드 만들기 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043958849/original/eqKzv7TGekrNGrzWc35VVE5NuLTTTLCyOg.png?1742930902)

### 템플릿 라이브러리로 대시보드 만들기

1. **필터** 버튼: "필터 ="로 표시돼요. 클릭하면 필터 사이드바를 표시하거나 숨겨요.
2. **필터 초기화** 버튼: "X 필터 초기화"로 표시돼요. 클릭하면 모든 필터를 재설정해요.
3. **템플릿 검색** 입력란: 키워드를 입력하면 템플릿이 걸러져요.
4. **정렬 드롭다운**: 흰색 드롭다운이에요. 옵션을 선택하면 템플릿이 그 순서로 정렬돼요.
   - **인기 순**: 인기도 순으로 정렬해요.
   - **최신 순**: 최신 순으로 정렬해요.
5. **필터 목록 패널**: 왼쪽에 필터가 많이 있는 패널이에요. 필터를 켜거나 꺼서 결과를 좁혀 보세요.
   - **모든 템플릿** 버튼: 클릭하면 모든 필터를 재설정해요.
   - **내 템플릿** 버튼: 클릭하면 내가 만든 템플릿만 보여요.
   - **나와 공유됨** 버튼: 클릭하면 가져온 템플릿만 보여요.
   - **즐겨찾기** 버튼: 클릭하면 즐겨찾기한 템플릿만 보여요.
   - **카테고리 찾아보기** 버튼: 클릭하면 카테고리 체크박스를 표시하거나 숨겨요.
   - **태그** 버튼: 클릭하면 태그 체크박스를 표시하거나 숨겨요.
6. **템플릿 목록**: 템플릿 카드가 스크롤되는 목록이에요. 스크롤하면서 사용할 수 있는 템플릿을 살펴보세요.
7. **템플릿 카드**: 색상, 아이콘, 이름이 표시되거나 비어 있을 수 있어요. 마우스를 올리면 즐겨찾기 버튼과 열기 버튼이 보여요.
8. **즐겨찾기 버튼**: 별 아이콘이에요. 클릭하면 템플릿을 즐겨찾기로 표시해요.
9. **열기 버튼**: 눈 아이콘이에요. 클릭하면 템플릿 상세 정보가 열려요.

![템플릿 라이브러리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043961266/original/87aOh5iegtVJzBEcA1n0d4jGxRXT_Tn6YQ.png?1742935754)

#### 템플릿 상세 정보

1. **뒤로** 버튼: "< 뒤로"로 표시돼요. 클릭하면 템플릿 목록으로 돌아가요.
2. **즐겨찾기** 버튼: 별 아이콘과 **즐겨찾기**가 표시돼요. 클릭할 때마다 즐겨찾기 상태가 바뀌어요.
3. **계속** 버튼: "계속 >"로 표시돼요. 클릭하면 선택한 대시보드를 만들고 바로 열어요.
4. 카테고리 알약: 카테고리 이름이 표시돼요. 템플릿이 어떤 분류인지 확인하세요.
5. 미리보기 이미지: 템플릿 화면을 캡처한 이미지예요. 모양을 미리 확인하세요.
6. 미리보기 확대 버튼: 확대 아이콘이에요. 클릭하면 미리보기 이미지를 전체 화면으로 볼 수 있어요.
7. 태그 알약: 태그 이름이 표시돼요. 템플릿이 어떻게 분류되어 있는지 확인하세요.
8. 소개 텍스트: 템플릿에 대한 긴 설명이에요. 읽어 보면 템플릿을 더 잘 이해할 수 있어요.
9. 사전 요구 사항 텍스트: 필요한 조건을 짧게 설명한 글이에요. 서브 계정에 필요한 설정이 갖춰져 있는지 확인하세요.

![템플릿 상세 정보 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043961459/original/l1mxbQNsuBapOVgBIObdLMaEs8glcjiugw.png?1742936055)

### 기존 대시보드 복제

1. **대시보드 선택** 드롭다운: 복제할 기존 대시보드를 선택해요.
2. 새 대시보드 이름 입력란: 선택한 대시보드 이름 뒤에 " - clone"이 붙어서 표시돼요. 새 대시보드 이름으로 수정하세요.
3. **Private Dashboard**(비공개 대시보드) 토글: 앞에서 설명한 것과 같아요. 공개 설정을 바꿔요.
4. **에이전시 사용자** 드롭다운: 접근 권한을 선택해요.
5. **계정 관리자** 드롭다운: 접근 권한을 선택해요.
6. **계정 사용자** 드롭다운: 접근 권한을 선택해요.
7. 접근 권한 옵션
   - **전체**: 전체 권한이에요.
   - **편집**: 편집만 할 수 있어요.
   - **보기**: 보기만 할 수 있어요.
   - **No Access**: 접근할 수 없어요.
8. **취소** 버튼: 흰색 버튼이에요. 클릭하면 창을 닫고 변경 내용을 버려요.
9. **복제** 버튼: 파란색 버튼이에요. 클릭하면 복제한 대시보드를 만들고 바로 열어요.

### 위젯 추가(또는 편집) 패널

1. **위젯** 탭: 밑줄이 있는 탭이에요. 클릭하면 위젯 설정으로 바뀌어요.
2. **요소** 탭: 밑줄이 있는 탭이에요. 클릭하면 요소 설정으로 바뀌어요. 자세한 내용은 '서브 계정 대시보드 - 요소 추가 또는 편집' 문서를 참고하세요.
3. **테마** 탭: 밑줄이 있는 탭이에요. 클릭하면 테마 설정으로 바뀌어요. 자세한 내용은 '서브 계정 대시보드 - 테마 편집' 문서를 참고하세요.
4. **Search Widgets**(위젯 검색): 키워드를 입력하면 위젯이 걸러져요. 목록과 각 카테고리 옆의 초록색 위젯 수가 바뀌는 것을 볼 수 있어요.
5. 차트 유형별로 보기
   1. **전체** 버튼: 클릭하면 위젯 목록 필터를 모두 없애요.
   2. 숫자 차트 버튼: "#" 아이콘이에요. 클릭하면 숫자만 표시하는 위젯만 보여요.
   3. 도넛 차트 버튼: 도넛 아이콘이에요. 클릭하면 도넛(원형) 차트를 표시하는 위젯만 보여요.
   4. 선 차트 버튼: 선 아이콘이에요. 클릭하면 선 그래프를 표시하는 위젯만 보여요.
   5. 막대 차트 버튼: 막대 아이콘이에요. 클릭하면 세로 막대 그래프를 표시하는 위젯만 보여요.
   6. **가로 막대** 차트 버튼: 가로 막대 아이콘이에요. 클릭하면 가로 막대 그래프를 표시하는 위젯만 보여요.
   7. 표 차트 버튼: 데이터 표 아이콘이에요. 클릭하면 데이터를 표로 표시하는 위젯만 보여요.
6. 위젯 목록
   1. '서브 계정 대시보드 - 위젯 유형' 문서를 참고하세요.
   2. '서브 계정 대시보드 - 위젯 추가 또는 편집' 문서를 참고하세요.

### 필터 알약

1. **지우기** 버튼: 회색 버튼이에요. 데이터를 선택했을 때 클릭하면 선택한 데이터가 지워져요.
2. 조건 드롭다운: 현재 조건 옵션이 표시돼요. 클릭해서 알맞은 조건을 선택하세요.
   - **Is**(일치): 클릭하면 [데이터 소스]가 [하나 이상의 데이터]와 일치하는 조건으로 설정돼요.
   - **Is not**(일치하지 않음): 클릭하면 [데이터 소스]가 [하나 이상의 데이터]와 일치하지 않는 조건으로 설정돼요.
   - **Is one of**(다음 중 하나): 클릭하면 [데이터 소스]가 [하나 이상의 데이터] 중 하나인 조건으로 설정돼요.
   - **Is none of**(다음 중 어느 것도 아님): 클릭하면 [데이터 소스]가 [하나 이상의 데이터] 중 어느 것도 아닌 조건으로 설정돼요.
   - **Is empty**(비어 있음): 클릭하면 [데이터 소스]가 비어 있는 조건으로 설정돼요. 데이터 입력란은 사라져요.
   - **비어있지 않음**: 클릭하면 [데이터 소스]가 비어 있지 않은 조건으로 설정돼요. 데이터 입력란은 사라져요.
3. 데이터 값 다중 선택: 데이터 값 알약 목록이에요. 클릭해서 하나 이상의 데이터 값을 선택하고, "x"를 클릭하면 선택이 해제돼요. 표시되는 값은 데이터 소스에 따라 달라요.
4. **취소** 버튼: 흰색 버튼이에요. 클릭하면 창을 닫고 변경 내용을 버려요.
5. **적용** 버튼: 파란색 버튼이에요. 클릭하면 창을 닫고 변경 내용을 적용해요.

### What Is Your Goal 위젯 옵션 창

1. 위젯 미리보기: 위젯 카드 목록이에요. 스크롤하면서 알맞은 위젯을 찾아보세요.
2. 위젯 선택 체크박스: 체크하면 해당 위젯이 선택되고, 체크를 해제하면 선택이 취소돼요.
3. **Reset Selection**(선택 초기화) 버튼: 클릭하면 모든 위젯 카드의 체크박스 선택이 해제돼요.
4. **취소** 버튼: 흰색 버튼이에요. 클릭하면 창을 닫고 변경 내용을 버려요.
5. **확인** 버튼: 파란색 버튼이에요. 클릭하면 창을 닫고, 선택한 위젯을 추가 대상으로 남겨 둬요.

### Top Used Widgets

1. 위젯 미리보기: 위젯 미리보기가 들어 있는 카드예요. 위젯이 어떤 모양일지 확인하세요.
2. 위젯 선택: 체크박스예요. 체크하면 해당 위젯이 선택되고, 체크를 해제하면 선택이 취소돼요.
3. **재설정** 버튼: 흰색 버튼이에요. 클릭하면 선택한 위젯이 모두 해제돼요.
4. **Confirm & Add**(확인 후 추가) 버튼: 파란색 버튼이에요. 클릭하면 빠른 시작 페이지를 닫고 대시보드에 위젯이 추가돼요.

## 보기 모드의 위젯

1. 위젯(보기 모드): 숫자, 차트, 표로 데이터를 보여 주는 대시보드 카드예요. 숫자 카드와 대표 수치는 위젯 크기와 상관없이 글꼴 크기와 스타일이 일정하게 유지돼요. 위젯 모서리는 8px로 둥글어졌고 테두리는 더 연해져서 화면이 깔끔해졌어요. 이전에 대시보드 캔버스 뒤에 표시되던 흰색 컨테이너는 없어졌어요.
2. 소스 옵션 드롭다운: 클릭해서 특정 데이터 소스를 선택해요. 사용할 수 있는 옵션은 위젯마다 달라요. 파이프라인 같은 드롭다운은 이제 카드 헤더가 아니라 위젯 본문 안에 표시돼요.
3. 날짜 속성(일부 위젯에만 있어요): 소스 옵션의 하나예요. 클릭해서 기준이 되는 날짜를 선택해요.
   - **Status Change**(상태 변경) 버튼: 선택하면 데이터의 상태가 마지막으로 바뀐 시점을 기준으로 계산해요.
   - **생성일** 버튼: 선택하면 데이터가 생성된 시점을 기준으로 계산해요.
   - **업데이트됨** 버튼: 선택하면 데이터가 마지막으로 업데이트된 시점을 기준으로 계산해요.
4. 위젯 본문(위젯마다 달라요): 데이터를 시각적으로 보여 줘요. 보거나 마우스를 올리거나 클릭해서 데이터를 확인하세요.

### 레코드 상세 데이터

위젯의 본문을 클릭하면 위젯의 바탕이 된 상세 데이터를 표로 보여 주는 창이 열려요. **내보내기** 버튼을 누르면 데이터를 내보낼 수 있어요. 다운로드는 자동으로 시작돼요.

## 편집 모드의 위젯

1. 끌어서 놓기 핸들: 점 6개 아이콘이에요. 누른 채로 끌어서 위젯을 다른 위치로 옮겨요.
2. 작업 메뉴: 점 3개 아이콘이에요. 클릭하면 작은 작업 메뉴가 열려요.
   1. **편집** 버튼('서브 계정 대시보드 - 위젯 추가 또는 편집' 문서 참고): 클릭하면 위젯 편집 사이드 패널이 열려요.
   2. **중복** 버튼: 클릭하면 새 위젯이 만들어진 상태로 위젯 추가·편집 사이드 패널이 열려요.
   3. **삭제** 버튼: 클릭하면 대시보드에서 위젯을 제거해요.

```
위젯 헤더 편집: 위젯 헤더를 한 번 클릭하면 위젯 편집 패널이 열려서 위젯 설정에 바로 접근할 수 있어요.
```

3. 크기 조절 핸들: 접힌 모서리 아이콘이에요. 오른쪽 아래 모서리를 클릭한 채로 끌어서 위젯 크기를 조절해요.
