# 대시보드 템플릿 만들기

대시보드를 템플릿으로 저장해 두면 여러 서브 계정에 같은 대시보드를 빠르게 복제할 수 있어요. 이 문서에서는 대시보드 템플릿을 만드는 방법과, 만든 템플릿으로 새 대시보드를 만드는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/\_pen\_34GCRg?&wmode=opaque)

## 대시보드 템플릿이란?

대시보드 템플릿은 여러 서브 계정에 같은 대시보드를 복제할 때 쓰는 틀이에요. 이미 만들어 둔 대시보드를 템플릿으로 저장하면 모든 계정에서 같은 모습으로 쓸 수 있고, 설정 시간도 크게 줄어요. 리포트 형식을 통일하고, 모든 계정에서 핵심 지표와 시각화를 볼 수 있게 하기에 좋아요.

## 대시보드 템플릿을 쓰면 좋은 점

여러 계정의 대시보드를 관리할 때 생기는 어려움을 줄여 줘요.

- 시간 절약: 서브 계정마다 대시보드를 일일이 다시 만들지 않아도 돼요.
- 일관성: 모든 계정에서 데이터를 같은 방식으로 보여 줘요.
- 확장성: 여러 고객사를 관리하는 에이전시가 작업을 더 간단하게 처리할 수 있어요.
- 효율성: 대시보드 템플릿을 한곳에서 관리하므로 수정과 업데이트가 쉬워요.

## 대시보드 템플릿은 어디에 있나요?

{% hint style="info" %}
에이전시 관리자만 쓸 수 있어요.
{% endhint %}

1. **에이전시 보기로 전환**을 클릭해 에이전시 보기로 바꿔요.

   ![에이전시 보기로 전환](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036893465/original/zC-uteTZSrL6caX1j_IF7fksDNArS2Xgvg.jpeg?1732105688)

2. **템플릿 라이브러리**로 이동해요. 이 화면에서 대시보드 템플릿을 둘러보고, 만들고, 관리할 수 있어요.

   ![템플릿 라이브러리 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036893664/original/aSh44oIlB68E80eX5VpAVoPa09NR1gV55w.jpeg?1732105785)

## 대시보드 템플릿 만들기

다음 순서로 대시보드 템플릿을 만들어요.

1. **에이전시 보기로 전환**을 눌러 에이전시 보기에 들어가요.
2. 에이전시 보기의 메뉴에서 **템플릿 라이브러리**를 클릭해요.
3. **새 템플릿**을 클릭해 템플릿 만들기를 시작해요.

   ![새 템플릿 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036897041/original/B7pJ-TN9r0WNmxSZ028tB5lcK_DdlSDW0w.png?1732107773)

4. **소스 선택**에서 복제하려는 대시보드가 들어 있는 서브 계정을 골라요.

   ![소스 서브 계정 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036897716/original/9PRJ6YnqGpdzWyLw9FdVSh1pPj-3QtZsfA.png?1732108216)

5. **상품 유형** 드롭다운에서 **대시보드**를 선택해요.

   ![상품 유형에서 대시보드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036897834/original/pUuTYcRGcrXL1QBmLjMMzfqC6LJ2KC5KFg.png?1732108261)

6. 템플릿으로 만들 대시보드를 고르고 **Continue**(계속)를 클릭해요.

   ![대시보드 선택 후 계속](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036897857/original/FTNHAM7f2ygt_IufNCIuxSa5cnx9mtHbiQ.png?1732108278)

7. 템플릿 정보를 입력해요.
   - 정리하기 쉽도록 알맞은 카테고리를 지정해요.

     ![카테고리 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036899452/original/PlF760Xvbgz9C4vcgLis6EExy83K77P5sg.png?1732108902)

   - 검색하기 쉽도록 태그를 추가해요.

     ![태그 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036899471/original/JVRVbn1Oko7qh4nJ1d8VTQS90_53VCQbtA.png?1732108917)

   - 템플릿을 알아보기 쉽도록 설명과 커버 이미지를 넣어요.

     ![설명과 커버 이미지 입력](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036899485/original/b3lh7NEebELBRlHMDriPLVirt42ZK8hCHA.png?1732108931)

8. 설정을 확인한 뒤 **Publish Template**(템플릿 게시)을 클릭해요. 새 템플릿이 템플릿 목록에 나타나요.

   ![템플릿 게시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036899821/original/hLNDvYlWcHjYW9MOcYx6Il8QS-k-TPtGQw.png?1732109092)

{% hint style="info" %}
**빠른 팁:** 대시보드를 바로 템플릿으로 올리려면 대시보드 옆의 점 세 개를 클릭하고 **Upload as Template**(템플릿으로 업로드)을 선택하세요.

![대시보드를 템플릿으로 업로드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036900022/original/1hykCR5ZeYgTfSchJOLQCkR3vZFMsvgeXA.png?1732109241)
{% endhint %}

## 템플릿으로 새 대시보드 만들기

이미 만들어 둔 템플릿으로 새 대시보드를 만드는 순서예요.

1. 계정의 대시보드 페이지로 이동해요.

   ![대시보드 페이지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036911788/original/wuDnSQSmSOf1SSmhL-74-OqBwXimugW1qg.jpeg?1732116459)

2. 드롭다운이 있는 파란색 대시보드 아이콘을 클릭하고 **Add Dashboard**(대시보드 추가)를 선택해요.

   ![대시보드 추가 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036911822/original/KYi6Tj02T44UotbPFUOHlfuTZYYZIZVhuw.jpeg?1732116485)

3. 나타나는 옵션에서 **템플릿으로 만들기**를 선택하고, 아래쪽의 **Select**(선택)를 클릭해요.

   ![템플릿으로 만들기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036911837/original/BSvIJyNxIXChq5MasxFtT8g-TMMD-TXrmQ.png?1732116513)

4. 라이브러리를 둘러보고 사용할 템플릿을 선택해요. 다음 페이지에서 오른쪽 위에 있는 **Continue**(계속) 버튼을 클릭해요.

   ![사용할 템플릿 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036911959/original/7rjOdESaBxQOMwGvnMeWyuZpkuFy3hXGiw.jpeg?1732116557)

   ![오른쪽 위 계속 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036934283/original/kPaqe0LuAhFx4p8dWi9ql77xuKSFrzKlxw.jpeg?1732164073)

5. 템플릿이 대시보드에 추가될 때까지 잠시 기다려요. 추가가 끝나면 **편집**을 눌러 대시보드 레이아웃을 원하는 대로 바꿀 수 있어요.

   ![편집으로 레이아웃 사용자 지정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036934046/original/rUghA-9aglhaJkKB2lymqKwFpqiZWGvNRw.jpeg?1732163012)
