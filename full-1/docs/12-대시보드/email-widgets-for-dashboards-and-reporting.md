# 대시보드와 리포트에서 이메일 위젯 쓰기

팀이 보낸 이메일을 하이퍼클래스 안에서 한눈에 확인하는 방법을 안내해요. 이메일 위젯을 서브 계정 **대시보드**와 **사용자 지정 리포트**에 추가하면 전송 상태와 수신자 반응, 그리고 어떤 캠페인·워크플로우·템플릿에서 나온 결과인지 바로 볼 수 있어요. **마케팅 > 이메일 > 캠페인**에서 하나씩 열어 볼 필요가 없어요.

**[동영상](https://www.youtube.com/embed/GdiTV\_tTxwQ?&wmode=opaque)**

## 이메일 위젯이란?

이메일 위젯은 이메일 발송 데이터를 서브 계정 **대시보드**나 **사용자 지정 리포트**에 보여 주는 기본 제공 리포트 블록이에요. SMS 위젯과 똑같이 쓰면 돼요. 데이터를 직접 내보내거나, **마케팅 > 이메일 > 캠페인 > Workflow Campaigns**(워크플로우 캠페인)까지 들어가 이메일 하나의 수치를 확인할 필요가 없어요. 필요한 곳에서 실시간 이메일 분석을 바로 볼 수 있어요.

위젯은 11개예요. 전송 상태, 반응, 반송, 구독 취소, 도메인별 분류를 모두 다뤄요. 이 위젯으로 고객사용 이메일 현황 화면을 몇 분 만에 만들 수 있어요. 특정 캠페인이나 워크플로우 하나로 좁혀 볼 수도 있고, 일정에 맞춰 공유할 수도 있어요.

![이메일 위젯이 표시된 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155075154356/original/Ygn_TmcIMNRGynvS7ckV9paTyGHhrftBpQ.png?1783084309)

## 이메일 위젯의 주요 장점

- 전송 상태를 한눈에 확인해요. **Accepted**(수락됨), **Delivered**(전달됨), **Opened**(열림), **Clicked**(클릭됨), **Replied**(답장됨), **Soft Bounced**(일시 반송), **Hard Bounced**(영구 반송), **Failed**(실패), **Unsubscribed**(구독 취소) 수를 **대화**나 **캠페인** 탭을 열지 않고도 볼 수 있어요.
- 특정 캠페인이나 워크플로우 하나만 따로 볼 수 있어요. **출처**를 **Workflow**(워크플로우), **Email Marketing Campaign**(이메일 마케팅 캠페인), **캠페인**, **Bulk Action**(일괄 작업), **Template**(템플릿), **Other**(기타) 중에서 고른 뒤 이름으로 정확한 항목을 선택하면, 위젯에 그 발송 건의 수치만 표시돼요.
- 구독 취소 추이를 확인해요. **Unsubscribed Emails Daily**(일별 구독 취소 이메일)는 날짜별 추이를 보여 줘서 리스트 상태의 문제를 일찍 발견할 수 있어요.
- 전송 문제가 몰리는 곳을 찾아요. **Emails By Domain**(도메인별 이메일)은 결과를 수신자 도메인별로 묶어 줘요. 예를 들어 반송이 한 도메인에 몰리는 것처럼 특정 메일 서비스의 전송 문제를 찾을 수 있어요.
- 팀 활동을 확인해요. 어떤 위젯이든 **Sent By**(보낸 사람)로 필터링하면 팀원별 이메일 활동을 볼 수 있어요.
- AND/OR 조건으로 정확하게 걸러 내요. **Status**(상태), **출처**, **Sent By**, **Domain**(도메인), **Workflow**, **캠페인**, **Email Marketing Campaign**, **Template**, **Bulk Action** 필터를 겹쳐서 원하는 데이터만 볼 수 있어요.

## 사전 준비 및 권한

- 대시보드와 리포트 접근 권한이 필요해요. 대시보드를 보거나 편집하고, 사용자 지정 리포트를 만들거나 **일정**을 설정할 권한이 있는지 확인하세요.
- 따로 연동하거나 연결할 필요는 없어요. 이메일 데이터는 이미 하이퍼클래스 안에 있어요.

## 사용할 수 있는 이메일 위젯

이메일 위젯은 11개예요. 모든 위젯에서 차트 유형, 조건, 테마를 설정할 수 있어요.

| 위젯 | 보여 주는 데이터 |
| --- | --- |
| **Accepted Emails**(수락된 이메일) | 발송 시스템이 정상적으로 수락한 이메일 수 |
| **Delivered Emails**(전달된 이메일) | 수신자에게 전달된 이메일 수 |
| **Opened Emails**(열람된 이메일) | 수신자가 연 이메일 수 |
| **Clicked Emails**(클릭된 이메일) | 링크가 클릭된 이메일 수 |
| **Replied Emails**(답장받은 이메일) | 답장을 받은 이메일 수 |
| **Soft Bounced Emails**(일시 반송된 이메일) | 일시 반송된 이메일 수(일시적인 전송 실패) |
| **Hard Bounced Emails**(영구 반송된 이메일) | 영구 반송된 이메일 수(영구적인 전송 실패) |
| **Failed Emails**(발송 실패 이메일) | 발송에 실패한 이메일 수 |
| **Unsubscribed Emails**(구독 취소 이메일) | 구독을 취소한 수신자 수 |
| **Unsubscribed Emails Daily** | 구독 취소의 일별 추이. **그룹** 기준으로 **출처**, **Status**, **Sent By**, **Workflow**, **캠페인**, **Template**, **Email Marketing Campaign**, **Bulk Action**, **Domain**을 쓸 수 있어요. |
| **Emails By Domain** | 수신자 도메인별로 묶은 이메일. 위와 같은 **그룹** 기준을 쓸 수 있어요. |

{% hint style="info" %}
위 위젯은 대부분 처음에는 숫자 하나로 표시되지만, 도넛, 막대, 선, 가로 막대, 표 보기로 바꿀 수 있어요. **Emails By Domain**과 **Unsubscribed Emails Daily**는 처음부터 **그룹** 기준이 켜져 있는 위젯이에요. 나머지 위젯도 **조건**으로 캠페인, 워크플로우, 템플릿 하나로 좁혀 볼 수 있어요. **그룹**과 **조건**은 서로 다른 기능이에요. 자세한 내용은 아래 **구성** 탭과 **조건** 탭 설명을 참고하세요.
{% endhint %}

## 대시보드, 사용자 지정 리포트, 맞춤 지표에서 쓰기

세 곳 모두 같은 이메일 위젯 11개를 써요. 데이터를 보고, 계산하고, 공유하는 방식에 맞춰 고르세요.

1. **대시보드**: 항상 켜 두고 확인할 때 좋아요. 위젯이 서브 계정 대시보드에 놓이고 자동으로 업데이트돼요. SMS 위젯, 통화 위젯과 함께 이메일 현황 섹션을 만들면 메시지 전체 현황을 볼 수 있어요.
2. **사용자 지정 리포트**: 고객에게 정기적으로 보낼 때 좋아요. 리포트 레이아웃에 이메일 위젯을 넣고 매일, 매주, 매월 자동으로 이메일 발송을 예약할 수 있어요.
3. **맞춤 지표**: 이메일 지표만이 아니라 나만의 KPI를 만들 수 있어요. 이메일 데이터를 다른 모듈의 데이터와 함께 계산할 수도 있어요.

## 이메일 위젯 추가하기

### 대시보드에 추가하기

1. 서브 계정에서 **대시보드**로 이동해 편집할 대시보드를 열어요. 새 대시보드를 만들어도 돼요.
2. 오른쪽 위의 **Edit Dashboard**(대시보드 편집)를 클릭해요.
3. **+ Add Widget**(위젯 추가)을 클릭해요. 오른쪽에 위젯 패널이 열려요.
4. 아래로 스크롤해서 **이메일** 섹션을 찾아요. 이메일 위젯 11개가 모두 여기에 있어요.
5. 추가할 위젯을 클릭해요. 대시보드 캔버스에 위젯이 놓여요.
6. **구성**, **조건**, **테마** 탭에서 위젯을 설정해요. 자세한 내용은 아래를 참고하세요.
7. **변경사항 저장**을 클릭해 위젯을 대시보드에 게시해요.

{% hint style="info" %}
**팁:** **마케팅 > 이메일 > 캠페인 > Workflow Campaigns**에서 보던 캠페인별 화면을 대시보드에 만들려면 **Opened Emails**, **Clicked Emails**, **Delivered Emails** 위젯을 나란히 추가하세요. 세 위젯 모두 **출처** = **Workflow**로 두고, 같은 워크플로우를 선택해요. 그러면 그 캠페인의 반응 요약이 대시보드에 바로 표시돼요.
{% endhint %}

### 사용자 지정 리포트에 추가하기

1. 서브 계정에서 **리포팅 > 사용자 지정 리포트**로 이동해요. 기존 리포트를 열거나 **New Report**(새 리포트)를 클릭해요.
2. 빈 캔버스에서 시작할지, 템플릿을 쓸지, 기존 대시보드 레이아웃을 가져올지 선택해요.
3. 리포트 빌더 왼쪽 위의 **Add Widget / Element**(위젯/요소 추가)를 클릭해요.
4. 아래로 스크롤해서 **이메일** 섹션을 찾고, 리포트 레이아웃에 넣을 위젯을 끌어다 놓아요.
5. 각 위젯을 **구성**, **조건**, **테마** 탭에서 설정해요.
6. **저장**을 클릭해요.
7. **보내기** 또는 **일정**을 클릭해 리포트를 이메일로 자동 발송하도록 설정해요.

## 이메일 위젯 설정하기

각 이메일 위젯에는 **Edit Widget**(위젯 편집) 패널에 설정 탭이 세 개 있어요.

### 구성 탭

**구성** 탭에서는 위젯이 어떻게 보일지, 어떤 기준으로 데이터를 묶을지 정해요.

- **지표**: **Count of Emails**(이메일 수)
- **그룹**: 위젯 데이터를 어떤 기준으로 나눠서 보여 줄지 정해요. 기본 옵션은 **출처**, **Status**, **Sent By**, **Domain**이에요. 조건을 충족하면 **Workflow**, **캠페인**, **Template**, **Email Marketing Campaign**, **Bulk Action**도 쓸 수 있어요. 아래 안내를 참고하세요.

#### 그룹에서 Workflow, 캠페인, Template, Email Marketing Campaign, Bulk Action 활성화하기

이 다섯 옵션은 **그룹** 드롭다운에서 처음에는 회색으로 표시돼요. 다음 순서로 활성화하세요.

1. 먼저 **조건** 탭으로 이동해요.
2. **출처** 필터를 추가하고 값을 설정해요(예: **출처** = **Workflow**).
3. 모든 조건 묶음의 **출처** 값을 같게 맞춰요.
4. **구성** 탭으로 돌아와요. 해당하는 **그룹** 옵션이 활성화돼 있어요.

이렇게 하면 각 이메일을 발송시킨 워크플로우, 캠페인, 템플릿, 일괄 발송별로 위젯 데이터를 나눠 볼 수 있어요. 예를 들어 **조건** 탭에서 **출처** = **Workflow**로 설정한 뒤 **구성** 탭에서 **그룹**을 **Workflow**로 선택하면, 워크플로우별 이메일 발송량을 볼 수 있어요.

### 조건 탭

필터를 추가해서 위젯에 표시할 이메일 데이터를 정확하게 정해요. 조건에는 AND/OR 논리를 쓸 수 있어요. 필터를 여러 개 겹쳐서 데이터 범위를 좁히거나 넓혀 보세요.

| 조건 | 값 | 설명 |
| --- | --- | --- |
| **출처** | **Workflow**, **Email Marketing Campaign**, **캠페인**, **Bulk Action**, **Template**, **Other** | 이메일 발송을 일으킨 원인으로 걸러요. 값을 선택하면 아래에 연결된 필드가 나타나요. |
| **Status** | **Accepted**, **Delivered**, **Opened**, **Clicked**, **Replied**, **Soft Bounced**, **Hard Bounced**, **Failed**, **Unsubscribed** | 전송 결과나 반응으로 걸러요. |
| **Sent By** | 서브 계정의 모든 팀원 | 보낸 사람으로 이메일을 걸러요. |
| **Domain** | 수신자 이메일 도메인 | 수신자 이메일 도메인으로 걸러요. |
| **Workflow** (**출처** = **Workflow**일 때 표시) | 서브 계정의 모든 워크플로우 | 위젯을 워크플로우 하나로 좁혀요. **마케팅 > 이메일**의 "Workflow Campaigns" 화면에 해당하는 설정이에요. |
| **캠페인** (**출처** = **캠페인**일 때 표시) | 서브 계정의 모든 캠페인 | 위젯을 캠페인 하나로 좁혀요. |
| **Email Marketing Campaign** (**출처** = **Email Marketing Campaign**일 때 표시) | 서브 계정의 모든 이메일 마케팅 캠페인 | 위젯을 이메일 마케팅 캠페인 하나로 좁혀요. |
| **Template** (**출처** = **Template**일 때 표시) | 서브 계정의 모든 이메일 템플릿 | 특정 템플릿으로 보낸 이메일만 표시해요. |
| **Bulk Action** (**출처** = **Bulk Action**일 때 표시) | 서브 계정의 모든 일괄 발송 | 일괄 이메일 발송 하나로 좁혀요. |

### AND/OR 조건 사용법

- **+ AND**(AND 조건 추가)는 결과를 좁힐 때 써요. 한 묶음 안의 조건이 모두 맞아야 해요.
- **또는**은 별도의 조건 묶음을 추가할 때 써요. 두 묶음 중 하나만 맞아도 돼요.
- 예: **출처** = **Workflow** **+ AND** **Workflow** = "대면 행사 옵트인" **또는** **출처** = **캠페인**으로 설정하면, 특정 워크플로우 하나의 이메일과 모든 캠페인의 이메일을 함께 보여 줘요.

### 테마 탭

위젯 색상을 대시보드나 고객사 브랜드에 맞춰요. 기본 제공 테마를 고르거나 색상을 직접 바꿀 수 있어요.

## 맞춤 지표에서 이메일 쓰기

**맞춤 지표**에서 이메일 데이터를 바로 쓸 수 있어요. 수식 빌더에서 **Count of Emails**를 사용하면 이메일 데이터를 다른 지표와 합친 KPI를 만들 수 있어요.

**맞춤 지표에서 Count of Emails를 쓰는 방법:**

1. **대시보드 > 편집 > 맞춤 지표**로 이동해 **Create Custom Metric**(맞춤 지표 만들기)을 클릭해요.
2. 수식 빌더(**Formula builder**)에서 지표로 **Count of Emails**를 선택해요. 연산자로 최대 4개 지표를 조합할 수 있어요.
3. 수식에서 **Count of Emails**를 클릭하면 오른쪽에 구성 패널이 열려요.
4. **필터** 아래에서 조건을 추가해 집계할 이메일을 좁혀요. 쓸 수 있는 조건은 **Status**, **출처**, **Sent By**, **Domain**이에요. 해당 **출처**를 설정하면 **Workflow**, **캠페인**, **Template**, **Email Marketing Campaign**, **Bulk Action**도 쓸 수 있어요.
5. **+ AND**와 **또는**으로 여러 필터를 조합해요.
6. 지표 이름을 입력하고 **Data Type**(데이터 유형)을 설정한 뒤 **만들기**를 클릭해요.

**맞춤 지표로 만들 수 있는 KPI 예시:**

- 이메일 열람률: Count of Emails(Status = Opened) ÷ Count of Emails(Status = Delivered) × 100
- 특정 캠페인의 클릭률: Count of Emails(출처 = Workflow, Workflow = "X", Status = Clicked) ÷ Count of Emails(출처 = Workflow, Workflow = "X", Status = Delivered) × 100
- 반송률: [Count of Emails(Status = Soft Bounced) + Count of Emails(Status = Hard Bounced)] ÷ Count of Emails(Status = Accepted) × 100

## 자주 묻는 질문

### 대시보드에서 전체 캠페인을 합친 수치 대신 캠페인 하나의 통계만 보려면 어떻게 하나요?
이메일 위젯을 추가하고 **조건** 탭으로 이동해요. **출처**를 **Workflow**, **캠페인**, **Email Marketing Campaign**, **Template**, **Bulk Action** 중 이메일을 보낸 방식에 맞는 값으로 설정하세요. 그러면 연결된 필드가 나타나요. 여기서 해당 항목을 선택하면 그 캠페인이나 워크플로우의 데이터만 표시돼요.

### 출처 옵션의 "캠페인"과 "Email Marketing Campaign"은 어떻게 다른가요?
<!-- 검토 필요: 원문에 두 값의 차이에 대한 설명이 없음. 담당자(SME/PM) 확인 후 게시 필요 -->
두 값은 각각 별도의 **출처** 값이고, 값마다 연결되는 필드가 따로 있어요. 두 값의 차이를 쉬운 말로 풀어 설명한 내용은 아직 확인되지 않았어요. 자세한 내용은 하이퍼클래스 고객지원에 문의하세요.

### 우리 에이전시의 이메일이 Workflow Campaigns로 설정돼 있는데, 출처는 무엇을 골라야 하나요?
**출처**를 **Workflow**로 선택하고, 나타나는 필드에서 워크플로우를 이름으로 선택하세요. 해당 캠페인을 직접 열었을 때 보는 요약(**Delivered**, **Opened**, **Clicked**, 반송, **Unsubscribed**)을 대시보드에서 똑같이 볼 수 있어요.

### 선택할 수 있는 Status 값에는 무엇이 있나요?
**Accepted**, **Delivered**, **Opened**, **Clicked**, **Replied**, **Soft Bounced**, **Hard Bounced**, **Failed**, **Unsubscribed**예요.

### 선택할 수 있는 출처 옵션에는 무엇이 있나요?
**Workflow**, **Email Marketing Campaign**, **캠페인**, **Bulk Action**, **Template**, **Other**예요.

### 그룹 드롭다운에서 Workflow(또는 캠페인, Template, Email Marketing Campaign, Bulk Action)가 회색으로 나와요.
이 옵션들은 **조건** 탭에서 해당하는 **출처** 필터를 설정해야 **그룹**에서 활성화돼요. 전체 순서는 위의 **구성** 탭 설명을 참고하세요.

### 이메일 위젯에 데이터가 표시되지 않아요.
흔한 원인은 세 가지예요. 선택한 기간에 이메일 활동이 없거나, 필터가 너무 좁거나(예: **출처**와 특정 캠페인을 조합했는데 해당 기간에 발송이 없는 경우), 이 서브 계정에서 이메일을 쓴 적이 없는 경우예요. 조건을 지우거나 기간을 넓혀 보세요.

### 한 대시보드에서 이메일 위젯과 SMS, 통화 위젯을 함께 쓸 수 있나요?
네. 이메일, SMS, 통화 위젯을 모두 같은 대시보드에 놓을 수 있어요. 커뮤니케이션 현황을 한곳에서 확인할 수 있어요.

### 고객에게 이메일 리포트를 정기적으로 보낼 수 있나요?
네. **사용자 지정 리포트**에 이메일 위젯을 추가하고, 매일, 매주, 매월 자동으로 이메일을 발송하도록 설정하세요.

### 맞춤 지표에서도 이메일을 쓸 수 있나요?
네. **Count of Emails**를 **맞춤 지표**의 수식 빌더에서 바로 쓸 수 있어요. **Status**, **출처**, **Sent By**, **Domain**(그리고 연결된 캠페인·워크플로우 필드)으로 필터링하면 열람률이나 특정 캠페인의 클릭률 같은 KPI를 정확하게 만들 수 있어요.

### 이메일 위젯은 얼마나 자주 업데이트되나요?
위젯은 자동으로 업데이트돼요. 직접 새로고침할 필요가 없어요.
