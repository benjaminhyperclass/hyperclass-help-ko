# Facebook·Instagram 채팅 위젯 만들기

웹사이트에서 Messenger와 DM 대화를 실시간으로 이어 갈 수 있어요. Facebook 채팅과 Instagram 채팅 위젯 유형을 쓰면 방문자가 이미 쓰는 Meta 채널에서 먼저 인사를 건넬 수 있어요. 응답률을 높이고 후속 응대도 더 수월해져요.

## Facebook·Instagram 채팅 위젯이란?

Facebook 채팅과 Instagram 채팅은 하이퍼클래스 **채팅 위젯**에서 고를 수 있는 채널 전용 옵션이에요. 웹사이트 메신저를 여는 대신, 방문자를 선택한 Meta 채널(Messenger 또는 Instagram DM)로 이동시켜요. 그러면 Facebook이나 Instagram 앱에서 그대로 대화를 이어 갈 수 있어요.

빌더에는 유형마다 전용 설정 패널이 있어요. 여기서 알맞은 Facebook 페이지나 Instagram 비즈니스 계정을 선택하거나 연결할 수 있어요.

## Facebook·Instagram 채팅의 주요 장점

- 간편한 참여: 방문자가 사이트 안에 별도 채팅 스레드를 만들지 않고 Messenger나 Instagram DM에서 바로 대화를 이어 가요.
- 선호하는 채널: 고객이 평소 메시지를 주고받는 소셜 플랫폼에서 고객을 만날 수 있어요.
- 높은 이용률: 방문자가 이미 쓰는 Facebook·Instagram 로그인과 앱을 그대로 활용해요.
- 통합 받은편지함: 모든 Meta 대화를 SMS, 이메일, WhatsApp 대화와 함께 하이퍼클래스의 **대화** 받은편지함에서 관리해요.
- 기기 간 연속성: 대화가 사용자의 Messenger·Instagram 앱에 남아 있어서, 기기를 바꿔도 대화 기록이 그대로 이어져요.

## Facebook·Instagram 채팅 위젯 설정하기

아래 순서대로 따라 하면 웹사이트에 설치할 Facebook 또는 Instagram 채팅 위젯을 만들 수 있어요.

#### 1단계: 새 위젯 만들기

**사이트 > 채팅 위젯**으로 이동한 다음, 파란색 **+ 신규** 버튼을 선택하세요.

![사이트 > 채팅 위젯 화면에서 신규 버튼을 누르는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060348475/original/elOj_5dm-_s2o0sUdzfnGJj623Dq3ovuUw.png?1765388725)

#### 2단계: 채팅 유형 선택

**채팅 유형 선택** 팝업에서 **Facebook Chat**(Facebook 채팅) 또는 **Instagram Chat**(Instagram 채팅)을 선택하세요.

Facebook·Instagram 계정은 연결되어 있는데 선택된 페이지가 없으면, 위젯에 쓸 페이지를 고르는 창이 열려요.

![채팅 유형 선택 팝업에서 Facebook Chat 또는 Instagram Chat을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350088/original/yO7fZsVYCVXXsGVHatbDlcCq6bgQDfR5Vg.jpeg?1765390979)

{% hint style="warning" %}
서브 계정에 해당 계정이 먼저 연결되어 있어야 여기서 Facebook Chat이나 Instagram Chat을 선택할 수 있어요. 연결된 계정이 아직 없으면 창 안의 링크가 계정 연결을 안내해요(예: 연동에서 **Facebook 연결** 또는 **Instagram 연결**). 이 링크를 열어 계정을 연결한 뒤, 이 선택 화면으로 돌아와 채팅 유형을 고르세요.
{% endhint %}

![계정을 먼저 연결하도록 안내하는 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350092/original/jsVdwN__K5cjKScy1fhL_BpcM8DtY01HBQ.png?1765390994)

#### 3단계: 위젯 사용자 지정

**스타일**, **채팅 창**, **메시지** 탭에서 색상, 인사말, 런처 아이콘 등을 브랜드에 맞게 바꿔 보세요. 더 다양한 디자인 옵션은 채팅 위젯 사용자 지정 개요 문서를 참고하세요.

**채팅 창** 탭에서는 위젯에 연결된 Facebook·Instagram 계정을 바꿀 수 있어요. 페이지나 계정을 더 추가하려면 **연결된 Facebook 페이지 연결** 또는 **연결된 Instagram 계정 연결** 버튼을 눌러 새 연결 창을 여세요.

필요한 편집을 마쳤으면 위젯을 저장하세요.

![스타일, 채팅 창, 메시지 탭에서 위젯을 사용자 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350150/original/hCpviuit3NtfBrynsJe5_HGgO4PThscLtA.png?1765391093)

#### 4단계: 위젯 공유하기

외부 사이트에 이 위젯을 설치하려면 **코드 가져오기**를 클릭하세요. 그런 다음 위젯을 표시할 웹사이트나 퍼널에 코드 스니펫을 삽입하세요. WordPress 사이트에 설치한다면 **Get it for WordPress**(WordPress용으로 받기)를 클릭하세요. 이 위젯은 하이퍼클래스의 퍼널 빌더와 웹사이트 빌더 안에서 바로 설치할 수도 있어요.

자세한 방법은 하이퍼클래스 채팅 위젯 설치 방법 문서를 참고하세요.

![코드 가져오기로 위젯 설치 코드를 받는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060349629/original/tkuC8Q7A2ZfTxvzZkN4MegGTa8PChiaJaw.png?1765390165)

## 자주 묻는 질문

### 위젯 하나에 Facebook과 Instagram을 함께 켤 수 있나요?

아니요. 위젯 하나는 채널 하나에만 연결돼요. 여러 채널을 한 말풍선에 담으려면 **All-in-One Chat**(올인원 채팅) 위젯을 사용하세요.

### 대화가 하이퍼클래스의 대화 탭에 표시되나요?

네. Facebook·Instagram 연동과 권한이 올바르게 연결되어 있고 메시지 접근이 활성화되어 있으면 표시돼요.

### 들어오는 메시지에 자동화를 적용할 수 있나요?

네, 할 수 있어요. 워크플로우 트리거 **Facebook Message**(Facebook 메시지) 또는 **Instagram Message**(Instagram 메시지)를 사용해 채팅에 태그를 달거나, 담당자를 지정하거나, 알맞은 곳으로 보낼 수 있어요.

### 방문자가 Facebook이나 Instagram에 로그인되어 있어야 하나요?

네. 로그인되어 있지 않으면 Meta 로그인 화면이 먼저 열려요.

### Facebook·Instagram 위젯은 스타일과 메시지 설정이 다르게 동작하나요?

아니요. 스타일과 배치는 다른 채팅 유형과 똑같이 동작해요. 가장 큰 차이는 대화가 이루어지는 곳이 Meta냐 사이트 안이냐 하는 점이에요.
