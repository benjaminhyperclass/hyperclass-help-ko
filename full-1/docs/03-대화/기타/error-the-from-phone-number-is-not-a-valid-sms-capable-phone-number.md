# SMS 오류 해결 — "From number is not SMS-capable"(보낸 번호가 SMS를 지원하지 않음)

문자(SMS)를 보낼 때 "From number is not SMS-capable" 오류가 나타나면 이 문서를 참고하세요. 번호의 SMS 지원 여부, 소유·배정 상태, A2P 등록 상태, 번호 형식을 차례로 확인하고 해결하는 방법을 안내해요.

이 오류는 선택한 보낸 번호를 이번 메시지에 쓸 수 없다는 뜻이에요. 메시지가 발송 처리된 뒤에 통신사 오류나 전달 오류로 실패했다면, 이 문서 대신 일반 SMS 전달 문제 해결 안내를 참고하세요.

## 어떤 오류인가요?

하이퍼클래스나 연결된 전화 제공업체가 보낸 번호로는 문자를 보낼 수 없다고 판단하면 이 오류가 나타나요. 메시지가 통신사 네트워크로 넘어가기 전에 확인하는 단계에서 거부되는 거예요.

**대화**, 워크플로우의 메시지 발송 액션, **캠페인**의 메시지 로그, API 응답에서 이 오류를 볼 수 있어요. 원인은 보낸 번호 자체의 설정이나 기능 문제예요. 메시지를 받아들인 뒤에 통신사가 거부한 경우와는 달라요.

![오류 메시지 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079971452/original/0VwsyZ28FnI-EuizCVmk69mKcrCRGqcp1g.png?1788419464)

통신사 필터링, 스팸 감지, 수신 불가 같은 오류 코드가 보인다면 일반 SMS 전달 문제 해결 안내를 확인하세요. 이 오류와는 별개예요.

## 빠른 확인 체크리스트

하이퍼클래스나 전화 제공업체가 문자를 보내기 전에 보낸 번호를 거부하는 가장 흔한 이유를 모았어요. 전화 시스템 설정을 바꾸거나 번호를 새로 사기 전에 먼저 확인해 보세요.

- SMS 지원 여부 확인: 보낸 번호에 문자 기능이 있는지 확인하세요(음성 전용이 아닌지). 음성 통화는 되지만 SMS는 안 되는 번호도 있어서, 통화가 된다고 문자도 보낼 수 있는 것은 아니에요.
- 소유·배정 확인: 번호가 내 하이퍼클래스 위치 또는 연결된 전화 계정에 속해 있고, 메시지 설정에 올바르게 배정되어 있는지 확인하세요.
- 미국 10DLC 번호: A2P 등록과 캠페인 연결을 확인하세요.
  - 하이퍼클래스 전화: 번호가 하이퍼클래스에서 승인된 브랜드/캠페인에 연결되어 있는지 확인하세요.
  - Twilio/BYOT: 번호가 승인된 캠페인과 연결된 메시징 서비스에 붙어 있는지 확인하세요.
- 번호 형식 확인: 보낸 번호를 직접 입력했거나 연동·API 요청에서 번호를 지정한다면, +와 국가 번호가 들어간 E.164 형식을 쓰세요(예: `+15551234567`).
- 보낸 번호와 수신 국가의 호환 확인: 보낸 번호의 유형(일반 번호, 톨프리 번호, 숏코드, 영숫자 ID)이 수신자 국가에서 쓸 수 있는 유형인지 확인하세요.

## 주요 원인과 해결 방법

"From number is not SMS-capable" 오류가 생기는 대표적인 상황이에요. 하나씩 살펴보면서 설정 문제를 찾아 해결하세요.

### 원인 1. 번호가 SMS를 지원하지 않아요

일부 번호는 음성 전용으로 개통되어 문자를 보내거나 받을 수 없어요. 오래된 번호, 번호 이동(포팅) 과정에서 생긴 경우, 문자 기능 없이 구매한 번호에서 흔해요.

확인 방법:

- 하이퍼클래스 전화: **설정 > 전화번호**로 이동해 번호 상세 정보를 열고 **메시지**가 활성화되어 있는지 확인하세요.
- Twilio / BYOT: Twilio 콘솔에 로그인해 번호를 찾고, **기능**에 **SMS**가 포함되어 있는지 확인하세요.

![번호의 문자 기능 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079971441/original/EGwEG9AhihK13aLGVhV3vC446hJO1NQiLQ.png?1788419439)

해결 방법: 번호가 SMS를 지원하지 않으면, 문자 기능을 켤 수 있는 경우 켜세요. 켤 수 없다면 SMS를 지원하는 다른 번호를 선택하세요. 번호를 구매하거나 이동한 지 얼마 안 됐다면 통신사 개통이 끝날 때까지 24~48시간 기다려 보세요.

### 원인 2. 내 계정이나 수신 국가에서 쓸 수 없는 번호예요

보낸 번호는 현재 하이퍼클래스 위치 또는 연결된 전화 계정에서 문자용으로 개통되거나 호스팅되어 있어야 하고, 메시지를 받는 국가에서도 유효해야 해요. 다른 위치에 속한 번호, 연결이 끊긴 Twilio 계정의 번호, 수신 국가와 맞지 않는 유형의 번호를 쓰면 이 오류가 나타나요.

흔한 경우:

- 번호가 다른 하이퍼클래스 위치로 호스팅되어 현재 위치에서는 더 이상 쓸 수 없어요.
- 번호와 연결된 Twilio 계정이나 API 자격 증명의 연결이 끊어졌거나 바뀌었어요.
- 수신 국가에서 지원하지 않는 번호 유형이에요(예: 영숫자 발신자 ID가 필요한 해외 수신자에게 미국 일반 번호로 보내는 경우).
- 숏코드로 다른 나라의 수신자에게 보내고 있어요. 숏코드는 국가별로 쓰는 번호라서 보통 다른 나라로 보낼 수 없어요.

해결 방법: 현재 위치의 전화 시스템이나 연결된 Twilio 계정에 번호가 개통되어 있는지 확인하세요. 호스팅한 번호라면 현재 사용 중인 위치에 올바르게 배정되어 있는지 확인하세요. 해외로 보낼 때는 **보낸 사람** 값을 고르기 전에 수신 국가에서 요구하는 발신자 조건을 확인하세요.

### 원인 3. A2P 등록이나 번호 배정이 끝나지 않았을 수 있어요(미국 10DLC)

미국에서 앱 대 사용자(A2P) 메시지에 쓰는 10자리 일반 번호는 승인된 브랜드와 캠페인에 등록되어 있어야 해요. 번호가 활성 A2P 캠페인에 제대로 연결되어 있지 않으면 메시지 발송이 실패하거나 제한될 수 있어요.

확인 방법:

- 하이퍼클래스 전화: **설정 > 전화번호**로 이동해 번호를 선택하고, 승인된 브랜드와 캠페인에 연결되어 있는지 확인하세요. **캠페인 상태**가 대기 중이거나 거절됨이면 그 번호로는 A2P 메시지를 보낼 수 없어요.
- Twilio / BYOT: Twilio 콘솔에 로그인해 번호가 메시징 서비스에 붙어 있는지, 그 메시징 서비스가 승인된 A2P 캠페인과 연결되어 있는지 확인하세요. 캠페인 승인 상태는 Twilio Trust Hub에서 볼 수 있어요.

해결 방법: A2P 등록이 끝나지 않았다면 브랜드와 캠페인 등록을 마무리하세요. 캠페인은 승인됐지만 번호가 배정되지 않았다면, Twilio에서는 번호를 알맞은 메시징 서비스에 붙이고 하이퍼클래스 전화에서는 하이퍼클래스에서 번호를 캠페인에 배정하세요. A2P 등록 문제는 통신사 검증 결과에 따라 다른 오류 메시지로 나타날 수도 있어요. 위 확인을 모두 통과했는데도 오류가 계속되면, 표시된 메시지 오류 코드를 정확히 확인하세요.

### 원인 4. 번호를 최근에 옮기거나 다시 호스팅했어요

번호를 최근에 포팅했거나, 새 위치로 호스팅했거나, 전화 계정 사이에서 옮겼다면 하이퍼클래스가 이전 설정을 계속 참조할 수 있어요. 그러면 번호가 새 계정에서 활성 상태여도 보낸 번호 검증에 실패할 수 있어요.

해결 방법: 아래 위치에서 현재 사용 중인 번호를 다시 선택하세요.

- **대화**의 발신 번호 설정
- **캠페인**과 워크플로우의 발신 번호 설정
- 기본 메시지 설정
- 사용자에게 배정된 번호
- 발신 번호를 저장해 두는 외부 연동

발신 번호를 바꾼 뒤에는 테스트 메시지를 보내서 새 번호가 인식되는지 확인하세요.

### 원인 5. 보낸 번호 형식이 잘못됐어요

워크플로우, API 요청, 연동에서 보낸 번호를 직접 입력할 때는 E.164 국제 형식이어야 해요. + 기호, 국가 번호, 전체 전화번호를 공백이나 특수문자 없이 이어서 써야 해요(예: `+15551234567`).

해결 방법: 보낸 번호를 직접 입력하거나 동적으로 불러온다면 E.164 형식에 맞는지 확인하세요. 일반 **대화**나 **캠페인** 메시지에서는 **보낸 사람** 드롭다운이 번호를 자동으로 올바른 형식으로 바꿔 주므로 직접 맞출 필요가 없어요.

## 번호 유형별 특이 사항

일부 번호 유형은 추가 조건이나 제한이 있어서 "From number is not SMS-capable" 오류의 원인이 될 수 있어요. 톨프리 번호, 숏코드를 쓰거나 해외로 문자를 보낸다면 아래 내용을 확인하세요.

### 톨프리(Toll-Free) 번호(미국/캐나다)

안정적인 전송을 위한 인증 필요

SMS를 지원하는 톨프리 번호도 톨프리 인증(Toll-Free Verification)이 끝나지 않으면 전송이 제한될 수 있어요. 톨프리 번호는 인증 없이도 기술적으로 메시지를 보낼 수 있지만, 통신사가 인증되지 않은 톨프리 트래픽을 점점 더 많이 필터링하거나 차단하고 있어요. 번호가 기능 확인은 통과했는데도 메시지가 계속 실패한다면, 톨프리 인증 상태와 반환된 메시지 오류 코드를 확인하세요.

### 숏코드

국가별로 쓰는 번호 유형

숏코드는 국가별로 쓰는 번호라서 보통 다른 나라로 메시지를 보낼 수 없어요. 수신 국가에서 지원하는 번호 유형을 쓰세요. 미국 숏코드로 캐나다나 해외 수신자에게 보내려고 하면 보낸 번호 검증 오류로 메시지가 실패해요.

### 해외 메시지

국가마다 다른 발신자 조건

메시지를 보낼 때 요구하는 발신자 조건은 수신 국가마다 달라요. 등록된 발신자 ID, 승인된 번호 유형, 영숫자 발신자 ID(Alphanumeric Sender ID)를 요구하는 나라도 있어요. 예를 들어 일부 국가는 롱코드 A2P 메시지를 받지 않고, 승인된 영숫자 발신자나 숏코드만 허용해요. **보낸 사람** 값을 바꾸기 전에 수신 국가에서 지원하는 발신자 조건을 확인하세요. 수신 국가에서 지원하지 않는 발신자 유형이라면 그 나라에서 승인된 발신자를 새로 준비해야 해요.
