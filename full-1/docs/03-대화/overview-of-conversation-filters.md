# 대화 필터 알아보기

대화 필터를 켜고, 여러 대화를 한꺼번에 관리하고, 소통을 더 빠르게 해 주는 도구를 쓰는 방법을 알려 드려요.

## 대화 필터란?

대화 필터는 **대화** 받은편지함에서 조건에 맞는 대화만 골라 보여 주는 도구예요. 받은편지함을 일일이 뒤지지 않아도 대화를 정리하고, 우선순위를 정하고, 꼭 봐야 할 대화에 집중할 수 있어요.

대화 필터는 받은편지함 탭, 정렬 옵션, **일괄 작업**과 함께 쓰여요. 팀이 대화를 보고 관리하는 방식을 원하는 대로 조절할 수 있어요.

## 대화 필터를 쓰면 좋은 점

필터를 제대로 쓰면 대화를 훨씬 잘 볼 수 있고 관리하기도 쉬워져요.

- 필요한 대화만 보기: 담당자, 멘션, 태그처럼 정해 둔 조건에 맞는 대화만 볼 수 있어요.
- 팀 업무 효율 높이기: 노이즈 줄이기 효과가 있어서, 팀원이 조치가 필요한 대화에 집중할 수 있어요.
- 세밀한 조건 설정: **그리고**와 **또는**으로 여러 규칙을 묶어 정확하게 걸러 낼 수 있어요.
- 많은 대화도 거뜬하게: 대화가 많아도 직접 분류하지 않고 관리할 수 있어요.

## 필터 패널

필터 패널은 새로워진 필터 기능의 중심이에요. 여러 조건을 규칙으로 만들어 대화를 걸러 낼 수 있어요.

### 필터 패널 열기

필터 아이콘(가로선 3개)을 클릭하면 화면 오른쪽에 필터 패널이 열려요.

![필터 아이콘을 눌러 연 필터 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064171623/original/qZjh4Jvy_M8lbAHaeosxho8E6pc3uBiEJg.jpeg?1770205937)

## 필터 빌더

**Filter Builder**(필터 빌더)에서는 받은편지함에 보일 대화를 정하는 규칙을 자세히 만들 수 있어요. 고를 수 있는 필터 종류는 아래와 같아요. 종류는 **필터 기준**에서 선택해요.

### Assigned(담당자) 필터

대화 담당자로 지정된 사용자를 기준으로 대화를 걸러 줘요. 팀원은 자기가 맡은 대화를 바로 볼 수 있고, 담당자가 아직 없는 대화도 쉽게 찾을 수 있어요.

사용자 드롭다운에서 **Logged In User**(로그인한 사용자)를 고르면 지금 로그인한 팀원 기준으로 필터가 적용돼요. 공유하는 대화 뷰를 만들 때 유용해요.

![담당자 필터 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064856353/original/xIJzsYqUTQSP8rUFzxkaRjPfgvqzeYHFDA.png?1770979331)

### **팔로워** 필터

특정 사용자가 팔로워로 추가된 대화를 걸러 줘요. 팔로워는 주 담당자가 아니어도 대화를 볼 수 있어요. 그래서 협업하거나 진행 상황을 지켜볼 때 쓰기 좋아요.

사용자 드롭다운에서 **Logged In User**를 고르면 지금 로그인한 사용자가 팔로워인 대화만 자동으로 걸러 보여 줘요.

### **멘션** 필터

사용자가 @멘션으로 언급된 대화를 걸러 줘요. 확인이 필요한 대화나 특정 팀원에게 따로 표시해 둔 대화를 찾을 때 도움이 돼요.

### **마지막 메시지 방향** 필터

가장 최근 메시지가 **수신**(연락처가 보낸 메시지)인지 **발신**(사용자나 자동화가 보낸 메시지)인지로 대화를 걸러 줘요. 답장을 기다리는 대화와 이미 답장한 대화를 구분할 수 있어요.

### **마지막 발신 메시지 유형** 필터

가장 최근 발신 메시지를 사용자가 직접 보냈는지(**Manually**, 수동), 워크플로우나 캠페인으로 **자동화**해서 보냈는지로 대화를 걸러 줘요. 사람이 직접 응대한 대화와 자동화된 대화를 나눠서 볼 때 유용해요.

### **마지막 메시지 채널** 필터

가장 최근 메시지를 주고받은 채널을 기준으로 대화를 걸러 줘요. 채널은 SMS, 이메일, 통화, 음성 메일, 라이브 채팅, WhatsApp, Facebook, Instagram, GBP 중에서 고를 수 있어요. 특정 채널에만 집중하고 싶을 때 쓰세요.

### 태그 필터

특정 연락처 태그가 붙은 대화를 걸러 줘요. 태그로 연락처와 대화를 분류해 두면 나만의 기준에 따라 대화를 나누고 관리하기 쉬워요.

![태그 필터 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064171943/original/8WeIAwnrYwk-GMRn7d8BVV8Dl4CX5k3RvA.png?1770206025)

### 필터 조건

조건은 선택한 필터 종류를 어떻게 판단할지 정해요.

자주 쓰는 조건은 아래와 같아요.

- **다음과 같음**: 선택한 값과 일치하는 대화를 포함해요.
- **다음이 아님**: 선택한 값과 일치하는 대화를 제외해요.

### 필터 값

**Value**(값) 필드에서는 필터에 쓸 사용자, 태그, 채널, 속성을 구체적으로 정해요.

작동 방식:

- 검색할 수 있는 드롭다운을 지원해요.
- 필터 종류에 따라 값을 하나만 고르거나 여러 개 고를 수 있어요.

## 그리고 / 또는 조건

**그리고**와 **또는**은 여러 필터 규칙이 서로 어떻게 맞물릴지 정해요.

### 필터 그룹 안의 조건

같은 그룹 안에 규칙이 여러 개 있으면, 토글로 규칙을 어떻게 판단할지 정해요.

- **그리고**: 모든 규칙을 만족해야 해요.
- **또는**: 규칙 중 하나만 만족해도 돼요.

### 필터 그룹 사이의 조건

필터 그룹을 여러 개 만들면, 그룹 사이에도 **그리고**와 **또는** 토글이 나와요. 이 토글로 그룹끼리 어떻게 맞물릴지 정해요.

이렇게 하면 담당자, 멘션, 태그를 한 번에 묶는 것 같은 세밀한 조건도 만들 수 있어요.

![필터 그룹 사이의 그리고/또는 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064172486/original/2GmPzL_KRuym_pGBYgsRNJQes6LoZQNjVg.png?1770206235)

## 여러 대화 한꺼번에 관리하기

대화가 많이 쌓이면 관리하기 어렵죠. 여러 대화에 한 번에 쓰는 대화 액션을 활용하면 바쁜 상황에서도 대화를 체계적으로 관리할 수 있어요.

### 대화 선택 체크박스

받은편지함의 각 대화 맨 왼쪽에는 체크박스가 있어요. 체크박스를 하나 이상 선택하면 일괄 관리 기능을 쓸 수 있어요.

작동 방식:

- 대화를 하나만 선택하면 그 대화에만 작업이 적용돼요.
- 대화를 여러 개 선택하면 **일괄 작업**을 쓸 수 있어요.
- 대화가 여러 개 있으면 전체 선택 옵션이 나타나요.

### 일괄 작업 도구 모음

대화를 하나 이상 선택하면 **일괄 작업** 도구 모음이 자동으로 나타나요.

쓸 수 있는 작업은 아래와 같아요.

- **읽음으로 표시**: 선택한 대화를 읽은 상태로 바꿔요.
- **읽지 않음으로 표시**: 대화를 다시 읽지 않은 상태로 되돌려요.
- **Add Star**(별표 추가): 대화를 중요한 대화로 표시해요.
- **Remove Star**(별표 해제): 즐겨찾기 표시를 없애요.
- **삭제**: 선택한 대화를 영구적으로 삭제해요.

![일괄 작업 도구 모음](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064171207/original/7fSv7hrUaWcOLS6oPdByX5sY1081Sf8OKA.jpeg?1770205708)

## 즐겨찾기 대화

중요한 메시지에 별표를 달아 두면 나중에 쉽게 다시 찾을 수 있어요. 우선순위가 높은 대화를 놓치지 않고 챙기기 좋아요.

### 별표 아이콘

별표 아이콘은 대화 목록과 개별 대화 화면에 모두 나타나요.

작동 방식:

- 별표를 클릭하면 그 대화가 즐겨찾기로 표시돼요.
- 즐겨찾기한 대화는 받은편지함의 **즐겨찾기** 탭에서 볼 수 있어요.

![대화 목록의 별표 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064171557/original/tfM-9vvEfKEtKyOhFIGdZcKQi4e7sIlZUA.jpeg?1770205870)

## 대화 정렬하기

정렬 옵션을 쓰면 대화를 편한 순서로 배치할 수 있어요. 정렬 방법이 여러 가지라서 원하는 대화를 빠르게 찾을 수 있어요.

### 정렬 아이콘

정렬 아이콘(위아래 화살표)을 클릭하면 정렬 옵션이 담긴 드롭다운이 열려요.

고를 수 있는 정렬 옵션은 아래와 같아요.

- **Latest All Messages**(전체 메시지 최신순): 직접 보낸 메시지든 자동 메시지든 상관없이, 가장 최근에 보내거나 받은 메시지가 있는 대화를 맨 위에 보여 줘요.
- **Oldest All Messages**(전체 메시지 오래된순): 마지막 메시지가 가장 오래된 대화를 맨 위에 보여 줘요. 가장 오랫동안 움직임이 없던 대화를 찾는 데 도움이 돼요.
- **Latest Manual Messages**(수동 메시지 최신순): 사용자가 직접 보낸 메시지 중 가장 최근 메시지를 기준으로 정렬해요. 워크플로우나 캠페인에서 자동으로 보낸 메시지는 빠져요.
- **Oldest Manual Messages**(수동 메시지 오래된순): 직접 보낸 메시지가 가장 오래된 순서로 정렬해요. 최근에 사람이 응대하지 않은 대화를 찾기 쉬워요.
- **가장 오래된 SLA 초과**: SLA를 가장 오래 넘긴 대화를 먼저 보여 줘요. 가장 급한 응답 지연부터 처리할 수 있어요.
- **다음 SLA 목표**: SLA 마감이 가장 가까운 순서로 정렬해요. SLA를 어기기 전에 먼저 응답할 수 있어요.

## 자주 묻는 질문

### 대화 필터는 실시간으로 바뀌나요?

네, 필터를 적용하거나 해제하거나 수정하면 받은편지함이 바로 업데이트돼요.

### 필터 조합을 저장할 수 있나요?

현재는 필터가 세션 단위로만 유지돼요. 받은편지함에 다시 들어오면 필터를 다시 적용해야 해요.

### Assigned 필터와 팔로워 필터는 뭐가 다른가요?

Assigned는 대화의 주 담당자를 기준으로 하고, 팔로워는 대화를 보거나 협업하려고 추가된 사용자까지 포함해요.

### 필터 하나에 채널을 여러 개 쓸 수 있나요?

네, **마지막 메시지 채널** 필터에서는 채널을 여러 개 선택할 수 있어요.

### 일괄 작업으로 대화를 삭제하면 완전히 사라지나요?

네, 삭제한 대화는 복구할 수 없어요.
