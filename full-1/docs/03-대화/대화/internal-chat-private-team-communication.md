# 내부 채팅으로 팀원과 비공개로 대화하기

**대화**(Conversations)에서 같은 서브 계정의 사용자끼리 비공개로 대화하는 기능이에요. 이 문서에서는 내부 채팅을 시작하고, 사용자를 추가하고, 알림을 설정하는 방법과 접근 권한을 안내해요.

## 개요

내부 채팅을 쓰면 **대화** 안에서 서브 계정 사용자와 바로 이야기할 수 있어요. 팀 안의 논의가 빨라지고 협업도 쉬워져요. 연락처와 나누는 대화와 달리, 내부 채팅은 참여자에게만 보여서 대화 내용이 비공개로 유지돼요.

## 인박스 구성

실험실에서 **내부 채팅**을 켜면 **대화** 화면 왼쪽에 새 인박스 패널이 나타나요. 이 패널에는 대화를 정리해 주는 인박스가 두 개 있어요.

### 1. Team Inbox(팀 인박스)

**Team Inbox**는 내 접근 수준에 따라 서브 계정의 대화를 보여 줘요.

- **할당된 데이터만** 접근 권한이 있는 사용자(예: 서브 계정 사용자)는 자신이 연락처 담당자이거나 팔로워인 대화를 모두 볼 수 있어요.
- **All Access**(모든 데이터) 권한이 있는 사용자(예: 관리자)는 서브 계정의 모든 대화를 볼 수 있어요.

이렇게 하면 사용자는 자신과 관련된 대화만 보고, 관리자는 전체 대화를 계속 확인할 수 있어요.

### 2. 내 인박스

**내 인박스**는 내가 직접 관련된 대화를 모아 보여 주는 공간이에요. 폴더는 다음과 같아요.

- **Assigned to Me**(나에게 배정됨): 내가 연락처 담당자인 대화를 모두 보여 줘요. 내가 맡은 대화를 한눈에 확인할 수 있어요.
- **내부 채팅**: 내가 참여 중인 내부 전용 대화 스레드를 보여 줘요. 이 채팅은 비공개이고 팀 협업을 위한 것이라, 고객과 나누는 대화와 따로 관리돼요.

## 내부 채팅 시작하기

1. **대화**를 열고 **신규**를 클릭한 다음 **내부 채팅**을 선택하세요.

   ![대화에서 신규를 눌러 내부 채팅을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044723847/original/2K203g2mWgiS_OjXq832-SrBxfV_ad1AuA.png?1744112331)
2. 채팅에 추가할 사용자를 선택하고 **Start Chat**(채팅 시작)을 클릭하세요.

   ![채팅에 추가할 사용자를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044725105/original/y4sNWaPO5IORAhijfbNp-418Be90WonHMQ.png?1744113282)
3. 내부 채팅에서는 텍스트 메시지, 이모지, 첨부파일을 보낼 수 있어요.

   ![내부 채팅에서 메시지를 보내는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047695620/original/1dO66w89f9ur9E8JPXA9251fM-VgF1NvTQ.jpeg?1748988092)
4. 대화를 더 잘 정리하려면 가운데 상단 패널의 편집 아이콘을 클릭해 제목을 추가하세요. 제목을 추가하면 제목, 참여자 이름, 마지막으로 보낸 메시지로 내부 채팅을 검색할 수 있어요.

   ![편집 아이콘으로 내부 채팅 제목을 추가하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047695625/original/HHVF4Lr0RPvZSAR9g5xbGiTW03D9uJ4NxA.jpeg?1748988105)

## 기존 내부 채팅에 사용자 추가하기

1. 내부 채팅을 열고 오른쪽 패널에서 **사용자 추가**를 클릭하세요.

   ![오른쪽 패널의 사용자 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047695317/original/ebqN4tF-X-jxfHcmscRKXVWLKxjdADRvdw.jpeg?1748987401)
2. 추가할 팀원을 선택하고 **다음**을 클릭하세요.
3. 새로 추가한 사용자가 이전 채팅 기록을 볼 수 있게 할지 선택하세요.
4. **확인**을 클릭하세요.

   ![이전 채팅 기록 공개 여부를 선택하고 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044725977/original/4GvJRYQOoxn6-o7j81aVq6-ywdeCepscQQ.png?1744113893)

{% hint style="warning" %}
한 번 추가한 사용자는 채팅에서 제거할 수 없어요.
{% endhint %}

## 내부 채팅 알림 받기

알림은 **설정 > 내 프로필 > Notifications**(알림)에서 설정해요. 다음 중에서 선택할 수 있어요.

- 내가 참여 중인 내부 채팅의 모든 메시지에 대해 알림 받기
- 새 내부 채팅에 추가됐을 때만 알림 받기

## 접근 권한

### 만들기 권한

- **대화**를 사용할 수 있는 사용자는 누구나 내부 채팅을 만들 수 있어요.
- 에이전시 관리자와 에이전시 사용자는 서브 계정에 속해 있지 않아도 내부 채팅을 만들 수 있어요.

### 참여 권한

- 서브 계정 사용자만 내부 채팅에 추가할 수 있어요.

### 보기 권한

- 내부 채팅에 추가된 사용자만 대화를 볼 수 있어요.
- 다른 팀원은 직접 추가되지 않으면 내부 채팅을 볼 수 없어요.

## 내부 채팅을 쓰면 좋은 점

- 소통을 한곳에서: 내부 논의를 위해 Slack이나 이메일 같은 외부 앱을 쓸 필요가 없어요. 모든 내용이 CRM 안에 있어서 대화를 정리하고 찾기 쉬워요.
- 매끄러운 협업: **대화**를 벗어나지 않고 바로 소통할 수 있어서 의사결정이 빨라지고 팀 간 조율도 쉬워져요.
- 맥락 파악과 가시성: 내부 채팅이 CRM에 연결되어 있어서 리드, 딜, 지원 건을 논의할 때 팀원이 전체 맥락을 볼 수 있어요.
- 효율적인 팀워크: 고객 대화가 이뤄지는 같은 플랫폼에서 소식을 공유하고, 질문하고, 전략을 세울 수 있어요.
- 알림으로 빠른 대응: 새 내부 메시지 알림을 받을 수 있어서, 고객 대화를 처리하는 중에도 중요한 소식을 놓치지 않아요.

{% hint style="info" %}
1. 내부 채팅은 플랫폼에 기본으로 포함된 기능이라 추가 비용이 들지 않아요.
2. 다른 사용자로 **로그인**하면 내부 채팅이 비공개로 유지되도록 그 사용자의 내부 채팅은 볼 수 없어요.
{% endhint %}
