# 대화 SLA 성과 확인하기

**SLA 성과** 대시보드에서는 팀이 대화 SLA의 응답 시간 목표를 얼마나 잘 지키고 있는지 볼 수 있어요. 관리자는 SLA 준수 현황과 응답 속도, 사용자별·채널별 성과를 한눈에 확인할 수 있어요. 응답이 늦어지는 지점을 찾아 개선하고, 고객에게 더 빠르고 일관되게 답하는 데 도움이 돼요.

[동영상](https://www.youtube.com/embed/UoT9t10HaDo?&wmode=opaque)

## SLA 성과 대시보드란?

**SLA 성과** 대시보드는 **대화**(Conversations)에 있는 리포팅 화면이에요. 설정해 둔 대화 SLA를 팀이 얼마나 잘 지키고 있는지 보여 줘요. 주요 SLA 결과와 응답 흐름을 확인하고, 잘하고 있는 부분과 개선이 필요한 부분을 파악할 수 있어요.

개별 받은 편지함만 보지 않아도 돼요. 대시보드에서 SLA 성과를 한곳에 모아 볼 수 있어요. 관리자는 핵심 지표를 확인하고 사용자별·채널별 결과를 비교해서, 응답 범위와 팀 효율을 높이는 데 활용할 수 있어요.

## SLA 성과 대시보드의 장점

- **한곳에서 확인**: 대화를 하나씩 직접 확인하지 않아도 SLA 성과를 한 화면에서 볼 수 있어요.
- **문제를 빠르게 발견**: SLA 결과와 평균 응답 시간을 보면서 응답이 늦어지는 시점을 알아낼 수 있어요.
- **사용자별 책임 확인**: 팀원 개개인이 SLA 기준을 얼마나 지키는지 알 수 있어요.
- **채널별 비교**: 채널별 성과를 비교해서 지연이 가장 자주 생기는 곳을 찾을 수 있어요.
- **더 나은 의사결정**: 리포트 내용을 바탕으로 워크플로우, 응답 범위, 팀 성과를 개선할 수 있어요.

## SLA 지표 설명

각 지표가 어떻게 계산되는지 알면 대시보드 결과를 정확하게 읽을 수 있어요. 성과를 평가하고 팀 안에서 결과를 설명하거나, 시간에 따른 SLA 데이터를 비교할 때 헷갈리지 않아요.

| 지표 | 설명 |
| --- | --- |
| **SLA Met %**(SLA 충족률) | 정해진 SLA 시간 안에 응답한 메시지의 비율이에요. 예를 들어 SLA가 적용된 메시지가 100개이고 그중 60개가 SLA 만료 전에 응답을 받았다면 SLA Met %는 60%예요. SLA가 아직 진행 중이라 충족도 위반도 아닌 메시지는 계산에서 제외돼요. |
| **SLA Breached %**(SLA 위반율) | SLA 시간 안에 응답하지 못한 메시지의 비율이에요. SLA 결과가 충족 또는 위반으로 확정된 메시지만 포함돼요. |
| **평균 응답 시간** | 답장이 나간 메시지에 대해 응답하기까지 걸린 평균 시간이에요. SLA 평가가 끝난 메시지만 포함돼요. |
| **SLA Met Messages**(SLA 충족 메시지) | SLA 시간 안에 응답을 받은 메시지의 총 개수예요. |
| **SLA Breached Messages**(SLA 위반 메시지) | SLA 시간이 지나도록 응답을 받지 못한 메시지의 총 개수예요. |
| **SLA Tracked Messages**(SLA 추적 메시지) | SLA가 적용되고 결과가 확정된 메시지의 총 개수예요. SLA를 충족했거나 위반한 메시지만 포함하고, SLA가 아직 진행 중인 메시지는 포함하지 않아요. |

## 사용자별·채널별 성과

성과를 세부적으로 나눠 보면 전체 리포트에서 한 걸음 더 나아가 실제로 조치할 부분을 찾을 수 있어요. 사용자별, 채널별로 결과를 보면 지연이 어디서 생기는지, 어디에 지원이나 업무 방식 변경, 업무량 조정이 필요한지 알기 쉬워요.

대시보드에는 사용자별, 채널별 리포트가 있어요. 관리자는 팀원과 커뮤니케이션 채널의 성과를 비교할 수 있어요. 성과가 좋은 팀원을 찾고, 코칭이 필요한 부분을 발견하고, 더 많은 인력이나 빠른 후속 대응이 필요한 채널을 확인할 수 있어요.

사용자별·채널별 리포트로 이런 일을 할 수 있어요.

- SLA 기준을 꾸준히 지키는 팀원을 확인해요.
- 코칭이나 업무량 지원이 필요한 사용자를 찾아요.
- 채널별 응답 성과를 비교해요.
- 워크플로우나 인력 조정이 필요할 수 있는 패턴을 찾아요.

![사용자별·채널별 SLA 성과 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069114117/original/DI8Yp1uMB7dSOhhjSO7jRV3rRYlfRJ_Rbw.png?1776171776)

## SLA 리포트 집계 규칙과 접근 권한

SLA 데이터가 어떻게 집계되는지 알아야 대시보드를 정확하게 해석할 수 있어요. 아래 규칙은 어떤 메시지가 포함되는지, 담당자가 어떻게 정해지는지, 누가 리포트를 볼 수 있는지, 데이터를 언제부터 볼 수 있는지를 알려 줘요.

- SLA 평가가 끝나 **충족** 또는 **위반**으로 확정된 메시지만 리포트에 포함돼요.
- 답장 없이 읽음으로 표시한 대화는 제외돼요.
- SLA 성과는 평가 시점에 배정되어 있던 사용자의 성과로 집계돼요.
- 관리자만 SLA 성과 리포트를 볼 수 있어요.
- **SLA 성과** 대시보드 데이터는 2026년 5월 23일부터 볼 수 있어요.

## SLA 성과 대시보드 사용하기

전체 결과를 먼저 보고 세부 내용으로 들어가면, 전체 성과를 파악하고 조치가 필요한 부분을 찾기 쉬워요.

1. 하이퍼클래스 서브 계정으로 이동해서 대화 SLA가 이미 설정되어 있는지 확인하세요.
   들어오는 대화의 응답 시간 목표를 정하는 방법은 [대화 SLA 설정 문서](how-to-setup-conversation-slas.md)에서 확인할 수 있어요.
2. **대화 > 분석 > SLA 성과**로 이동해 대시보드를 여세요.

   ![SLA 성과 대시보드로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069113512/original/_vHFV5tBFfKuCyvQHY2-DJgCXSGWQYeZaA.png?1776171337)
3. 조회할 기간을 선택하고 개요 지표를 확인하세요.
   현재 성과와 전반적인 SLA 준수 현황을 평가할 수 있는 기간으로 설정하세요. **SLA Met %**, **SLA Breached %**, **평균 응답 시간**을 먼저 보면 전체 응답 수준을 파악할 수 있어요. 그다음에 세부 내용을 살펴보세요.

   ![기간을 선택하고 개요 지표를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069113880/original/6CLG4BSIyV-QaU2nGR7fdfcD0OQuEu5Veg.gif?1776171604)
4. 사용자별, 채널별 성과를 분석하세요. 지연이 어디서 생기는지, 어디에 운영 방식 변경이 필요한지 알 수 있어요.

   ![사용자별·채널별 성과를 분석하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069113901/original/mRqniSMyX_nGPuJxe21SeihZchOE14QyAw.png?1776171621)

## 나만의 SLA 대시보드와 리포트 만들기

**대화**의 **SLA 성과** 대시보드 외에도, **대시보드**와 **사용자 지정 리포트**에서 SLA 위젯으로 나만의 SLA 리포트 화면을 만들 수 있어요. SLA 위젯을 쓰면 대화 SLA 데이터를 내부 팀이나 고객 리포트에 맞게 보여 줄 수 있어요. 보여 줄 지표를 고르고 차트 유형을 바꾸고, 담당 사용자나 메시지 채널별로 결과를 묶을 수 있어요. 필터를 적용하거나 다른 대화 리포팅 위젯과 SLA 성과 데이터를 함께 넣을 수도 있어요.

SLA 상태를 한눈에 보는 맞춤 대시보드를 만들거나, 사용자·채널별 성과를 비교하거나, 고객에게 SLA 리포트를 예약 발송하고 싶을 때 유용해요. 맞춤 리포트 화면을 만들려면 **대시보드** 또는 **리포팅 > 사용자 지정 리포트**로 이동한 뒤 **대화** 위젯 섹션에서 SLA 위젯을 추가하세요. 자세한 설정 방법은 [대시보드 & 리포팅용 SLA 위젯 문서](../../12-대시보드/위젯/sla-widgets-for-dashboards-reporting.md)를 참고하세요.

![SLA 위젯을 추가한 맞춤 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155074914515/original/cU58mpPwAVjsezpEjyLYABRoDuwACN5GQw.png?1782894942)

## 자주 묻는 질문

### SLA 성과 대시보드에서는 무엇을 측정하나요?
팀이 대화 SLA의 응답 시간 목표를 얼마나 잘 지키는지 측정해요. SLA 결과와 응답 시간, 사용자별·채널별 성과를 보여 줘요.

### SLA 성과 대시보드는 누가 볼 수 있나요?
관리자만 SLA 성과 리포트를 볼 수 있어요.

### 모든 메시지가 대시보드에 포함되나요?
아니요. SLA 평가가 끝나 충족 또는 위반으로 확정된 메시지만 리포트에 포함돼요.

### 읽음으로 표시한 대화도 SLA 리포트에 집계되나요?
아니요. 답장 없이 읽음으로 표시한 대화는 제외돼요.

### 여러 사용자가 한 대화를 처리하면 SLA 성과는 누구에게 집계되나요?
평가 시점에 배정되어 있던 사용자의 성과로 집계돼요.

### SLA Tracked Messages는 무슨 뜻인가요?
SLA가 적용되고 결과가 충족 또는 위반으로 확정된 메시지의 총 개수예요.
