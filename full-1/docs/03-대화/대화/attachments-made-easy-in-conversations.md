# 대화에서 첨부파일 쉽게 보내기

**대화**(Conversations)에서 계약서, 상품 소개서, 안내 영상 같은 파일을 이메일이나 SMS로 보낼 때 쓰는 기능이에요. 파일을 첨부하고 업로드하는 방법과, 용량이 큰 파일이 어떻게 처리되는지 안내해요.

첨부파일을 쓰면 중요한 파일, 문서, 이미지, 영상을 주고받으며 정보를 효율적으로 전달할 수 있어요. 하이퍼클래스에서는 이메일, SMS, 미디어 라이브러리에서 첨부파일을 쓸 수 있어서 여러 소통 채널에서 파일을 매끄럽게 공유할 수 있어요.

## 첨부파일이란?

**대화**에서 파일을 주고받는 기능이에요. 고객에게 문서, 이미지, 영상을 쉽게 보낼 수 있어요. 첨부파일은 기기에서 바로 업로드하거나 **미디어 라이브러리**에서 골라 보낼 수 있어요.

SMS로 보내기에 너무 큰 파일이나 이메일 용량 제한(20MB)을 넘는 파일은 자동으로 **미디어 라이브러리**에 업로드되고, 링크로 공유돼요. 그래서 파일 크기와 상관없이 문제없이 전달돼요.

## 첨부파일의 장점

- 소통이 더 풍부해져요: 계약서, 이미지, 영상, PDF를 쉽게 공유해서 메시지를 더 알차게 만들 수 있어요.
- 업로드 방법을 고를 수 있어요: 기기에서 바로 올리거나 **미디어 라이브러리**에 저장된 파일을 선택할 수 있어서 파일 공유가 편해요.
- **미디어 라이브러리**로 자동 업로드돼요: 파일이 이메일 용량 제한(20MB)을 넘거나 SMS로 보내는 파일이면 자동으로 **미디어 라이브러리**에 올라가고 링크로 공유돼요.
- 이메일 썸네일로 눈길을 끌어요: **미디어 라이브러리**로 올린 영상은 자동으로 GIF 썸네일이 만들어져서 이메일이 더 생동감 있고 보기 좋아요.

## 첨부파일 사용하는 방법

몇 단계만 거치면 **대화**에서 첨부파일을 바로 추가할 수 있어요. 이미지, PDF, 영상 모두 기기에서 업로드하거나 **미디어 라이브러리**에서 선택해 보낼 수 있어요. 아래 순서대로 따라 해 보세요.

### 대화 화면 열기

하이퍼클래스에서 **대화**로 이동해요. 기존 대화를 선택하거나, 연락처에게 새 메시지를 시작하세요.

![대화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042894436/original/Eo-zE2F7q_BeGzYCBFb5wu1sS1YCHUQb5A.png?1741433091)

### 메시지에 파일 첨부하기

SMS 또는 이메일 작성창의 클립 아이콘을 클릭하면 첨부 옵션이 열려요. 기기에서 파일을 고르거나, 이전에 업로드한 파일이 있다면 **미디어 라이브러리**에서 선택하세요. 파일을 선택하면 메시지에 첨부되어 바로 보낼 수 있어요.

![클립 아이콘으로 파일 첨부하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042894575/original/T9w5u-URZK_4kvOJvydLp9z_5QGFikyFfw.png?1741433485)

### 클립보드에서 붙여넣어 첨부하기

메시지 작성창에 파일을 바로 붙여넣어 첨부할 수도 있어요.

1. 컴퓨터에서 지원하는 파일이나 이미지를 복사해요.
2. SMS, 이메일, WhatsApp 등 지원하는 채널의 메시지 작성창을 클릭해요.
3. `Ctrl + V`(Windows) 또는 `Cmd + V`(Mac)를 눌러요.
4. 붙여넣은 파일이 자동으로 첨부파일로 나타나요.

{% hint style="info" %}
클립보드로 붙여넣은 첨부파일도 **대화**의 다른 첨부파일과 같은 파일 형식·용량 제한을 따라요.
{% endhint %}

### 업로드 방법 선택하기

**기기에서 업로드**: 내 컴퓨터나 휴대폰에 저장된 이미지, PDF, 영상 등의 파일을 선택해요.

**미디어 라이브러리**에서 선택: 이전에 업로드한 파일이 있다면 라이브러리에서 골라 쓸 수 있어요. 같은 파일을 다시 올리지 않아도 돼요.

![업로드 방법 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042894577/original/e_8kewNhfTc5r1UWWN1-fPka2kFmBr2Jsg.png?1741433516)

### 미디어 라이브러리 자동 업로드

SMS 첨부파일이거나 20MB보다 큰 이메일 첨부파일을 올리면, 시스템이 파일을 자동으로 **미디어 라이브러리**로 옮겨요.

파일을 직접 첨부하는 대신 **미디어 라이브러리** 링크가 메시지에 들어가서, 용량 제한 없이 문제없이 전달돼요.

![미디어 라이브러리 자동 업로드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042894610/original/Ujfupsvnie7VKN6SqT8XXCoS-B8U48sXJQ.png?1741433629)

### 영상 GIF 썸네일

**미디어 라이브러리**로 올린 영상은 자동으로 GIF 썸네일 미리보기가 만들어져요.

움직이는 미리보기 덕분에 이메일이 더 눈에 띄고, 받는 사람이 콘텐츠를 눌러 볼 가능성이 높아져요.

![영상 GIF 썸네일 미리보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155042894654/original/ibYj_4GhpuFyVAAukhWh1Jh7qoWxx09jWg.png?1741433694)

## 자주 묻는 질문

### 어떤 파일을 첨부할 수 있나요?
이미지, 문서, PDF, 영상을 첨부할 수 있어요. 다만 이메일 첨부파일은 20MB까지만 가능해요. 이보다 큰 파일은 자동으로 **미디어 라이브러리**로 옮겨져 링크로 공유돼요.

### 업로드한 파일을 미디어 라이브러리에서 보려면 어떻게 하나요?
업로드한 파일은 모두 자동으로 **미디어 라이브러리**에 저장되고, **대화** 화면에서 접근할 수 있어요. 이전에 올린 파일을 다시 첨부하지 않고 바로 재사용할 수 있어요.

### 이메일 용량 제한을 넘는 파일을 보내면 어떻게 되나요?
20MB를 넘으면 파일이 자동으로 **미디어 라이브러리**에 업로드되고, 파일 링크가 이메일에 들어가요. 큰 파일도 전송 문제 없이 공유할 수 있어요.

### SMS로도 첨부파일을 보낼 수 있나요?
네, SMS로도 첨부파일을 보낼 수 있어요. 다만 SMS는 용량 제한이 있어서, 파일이 자동으로 **미디어 라이브러리** 링크로 바뀌어 전달돼요.

### 영상 GIF 썸네일은 어떻게 동작하나요?
**미디어 라이브러리**로 영상을 올리면 하이퍼클래스가 자동으로 GIF 썸네일 미리보기를 만들어요. 이메일이 더 보기 좋아지고, 받는 사람이 영상을 눌러 볼 가능성이 높아져요.
