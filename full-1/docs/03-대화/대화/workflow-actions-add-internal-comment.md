# 워크플로우 액션 — Add Internal Comment(내부 댓글 추가)

워크플로우가 연락처의 대화 스레드에 팀원만 볼 수 있는 내부 댓글을 자동으로 남기게 하는 액션이에요. 연락처에게 메시지를 보내지 않고, 팀에 참고할 내용을 남기고 싶을 때 쓰세요.

## Add Internal Comment 액션이란?

**Add Internal Comment**(내부 댓글 추가) 액션을 쓰면 워크플로우가 연락처의 대화 스레드에 비공개 내부 메모를 남길 수 있어요. 이 댓글은 **대화 페이지**에서 직접 쓴 내부 댓글과 똑같이 대화에 추가돼요. 연락처에게는 전송되지 않고, 연락처가 볼 수도 없어요.

연락처에게 메시지를 보내는 대신 팀에 맥락을 남기고 싶을 때 유용해요. 예를 들어 후속 연락이 필요한 핫 리드를 표시할 수 있어요.

댓글 안에서 팀원을 @멘션할 수도 있어요. 멘션된 사용자는 알림을 받고, 해당 연락처의 팔로워로 추가돼요.

---

## Add Internal Comment 액션 사용하기

1. 워크플로우 빌더를 열어요.

   **서브 계정 > 자동화**로 이동해서 기존 워크플로우를 열거나, 새로 만들거나, 레시피에서 만들어요.

2. 액션을 추가해요.

   워크플로우 빌더에서 더하기(+) 버튼을 눌러 액션 메뉴를 열어요. **Communication**(커뮤니케이션) 카테고리에서 **Add Internal Comments**를 검색하거나 스크롤해서 찾으세요.

   ![액션 메뉴의 Communication 카테고리에서 Add Internal Comments를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083159156/original/A4jEBMIE3eRw7hfeDO8CU3gM4P2_EhRzzQ.png?1791873178)

3. 댓글을 작성해요.

   팀원이 볼 댓글 내용을 텍스트 편집기에 입력하세요. 편집기에서는 다음 기능을 쓸 수 있어요.

   - **@**(멘션): 팀원을 멘션해요.
   - **Undo** / **Redo**(실행 취소 / 다시 실행): 작성하는 중에 마지막 편집을 되돌리거나 다시 적용해요.

   {% hint style="info" %}
   댓글 내용은 꼭 있어야 해요. 댓글에 텍스트가 없는 상태로 액션이 실행되면 그 액션은 건너뛰어요.
   {% endhint %}

4. 액션을 저장해요.

   **Save Action**(액션 저장)을 클릭해 워크플로우에 추가하세요. 워크플로우를 테스트해 본 뒤, 준비되면 게시하세요.

---

## 액션에서 @멘션이 동작하는 방식

편집기에서 **@** 아이콘을 클릭하면 멘션을 넣을 수 있어요. 선택할 수 있는 옵션은 두 가지예요.

| 옵션 | 동작 |
| --- | --- |
| **Assigned User**(할당된 사용자) | 액션이 실행되는 시점에 해당 연락처에 할당된 사용자를 그때그때 멘션해요. |
| **Specific user**(특정 사용자) | 서브 계정의 사용자 목록에서 직접 고른 사용자를 고정으로 멘션해요. 목록은 검색할 수 있고, 한 댓글에 멘션을 여러 개 넣을 수 있어요. |

댓글이 등록되면 다음과 같이 처리돼요.

- 멘션된 사용자는 각각 해당 연락처의 팔로워로 추가돼요. 팔로워는 대화를 보고 답글을 달 수 있어요.
- 멘션된 사용자는 각자의 알림 설정(**설정 > 내 프로필 > 알림**)에 따라 알림을 받아요.
- **Assigned User**를 썼는데 연락처에 할당된 사용자가 없으면 멘션은 적용되지 않아요. 나머지 텍스트는 그대로 댓글로 등록돼요.

{% hint style="info" %}
이전에 연락처에 접근 권한이 없던 사용자를 멘션하면, 그 사용자가 팔로워로 추가되면서 접근 권한이 생겨요. 이는 대화 페이지에서 내부 댓글로 사용자를 멘션할 때와 같은 동작이에요. 많은 연락처를 대상으로 실행되는 워크플로우에서 사용자를 멘션할 때는 이 점을 기억해 두세요.
{% endhint %}

## 댓글이 표시되는 위치

액션이 실행되면 내부 댓글이 연락처의 대화 스레드에 등록돼요.

- 대화 타임라인에서 다른 메시지와 함께 시간순으로 표시돼요.
- SMS, 이메일 등 어떤 채널로도 연락처에게 전달되지 않고, 메시지 크레딧도 쓰지 않아요.

![대화 타임라인에 표시된 내부 댓글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083257938/original/HPZBbIWrg3MU2OTFtKOaCcKYPrRyM_MBJg.png?1791957912)

대화에서 내부 댓글을 빠르게 찾으려면 다음 필터를 쓰세요.

- **Internal Comments**(내부 댓글) 필터: 대화 안에서 내부 댓글만 보여 줘요.
- **Mentions of Me**(나를 멘션한 대화) 필터: 내가 멘션된 대화를 보여 줘요.
- **Mentions of a Specific User**(특정 사용자를 멘션한 대화) 필터: 선택한 팀원이 멘션된 대화를 보여 줘요.

---

## 유의 사항

- 댓글 텍스트는 필수예요. 액션이 실행됐는데 댓글에 텍스트가 없으면 그 액션은 건너뛰고, 실행 로그에 *"There is no text added in this comment, so this action is skipped."*(이 댓글에 추가된 텍스트가 없어 이 액션을 건너뜁니다)라고 기록돼요. 예를 들어 댓글에 **Assigned User** 멘션만 있는데 연락처에 할당된 사용자가 없으면 이렇게 돼요.
- 내부 댓글은 등록한 뒤에는 편집하거나 삭제할 수 없어요. 워크플로우를 게시하기 전에 댓글 내용을 꼭 확인하세요.
- 내부 댓글에는 첨부파일을 넣을 수 없어요.
- 팔로워는 계속 누적돼요. 나중에 워크플로우 액션에서 멘션을 지워도, 이전 실행으로 이미 연락처에 추가된 팔로워는 제거되지 않아요.
- 게시하기 전에 테스트하세요. 테스트 연락처로 워크플로우를 실행해서 댓글 텍스트, 멘션, 알림이 모두 의도대로 동작하는지 확인하세요.

## 자주 묻는 질문

### 연락처가 내부 댓글을 볼 수 있나요?

아니요. 내부 댓글은 팀원만 볼 수 있어요. 어떤 채널로도 연락처에게 전송되지 않고, 연락처에게 보이지도 않아요.

### 이 액션은 SMS나 이메일 크레딧을 쓰나요?

아니요. 내부 댓글은 대화에만 등록되고 연락처에게 전달되지 않아서 메시지 크레딧을 쓰지 않아요. 멘션된 사용자에게 가는 알림은 그 사용자의 알림 설정을 따라요.

### 연락처에 할당된 사용자가 없는데 Assigned User 멘션을 쓰면 어떻게 되나요?

멘션되는 사용자가 없어요. 댓글에 다른 텍스트가 있으면 멘션 없이 댓글이 등록돼요. 댓글에 **Assigned User** 멘션만 있고 다른 텍스트가 없으면 액션을 건너뛰고, 이 내용이 실행 로그에 기록돼요.

### 한 댓글에서 여러 사용자를 멘션할 수 있나요?

네. 한 댓글에 멘션을 여러 개 넣을 수 있어요. 멘션된 사용자는 각각 알림을 받고 연락처의 팔로워로 추가돼요.

### 사용자를 멘션하면 그 사용자에게 연락처 접근 권한이 생기나요?

네. 멘션된 사용자는 연락처의 팔로워로 추가되고, 팔로워는 해당 대화를 보고 답글을 달 수 있어요. 대화 페이지에서 사용자를 멘션할 때와 같은 동작이에요.

### 액션이 실행됐는지 어디서 확인하나요?

워크플로우의 **Execution Logs**(실행 로그)를 열고 해당 연락처의 실행 내역을 찾으세요. Add Internal Comment 액션이 실행됐는지 건너뛰었는지와 그 이유가 로그에 나와요.

### 워크플로우가 아닌 곳에서도 내부 댓글을 추가할 수 있나요?

네. 대화 페이지에서 직접 내부 댓글을 추가할 수 있고, 내부 댓글을 프로그램으로 등록하는 공개 API 엔드포인트도 있어요. 자세한 내용은 [대화 - 내부 댓글 추가 및 사용자 멘션하기](conversations-how-to-add-internal-comments-mention-users.md) 문서를 참고하세요.
