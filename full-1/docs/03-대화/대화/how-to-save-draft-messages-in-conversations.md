# 대화에서 작성 중인 메시지 자동 저장

**대화**(Conversations)에서 보내지 않은 메시지는 자동으로 임시 저장돼요. 메시지를 쓰다가 다른 곳으로 이동해도 돌아오면 이어서 작성할 수 있어요.

[동영상](https://www.youtube.com/embed/o73IM7QbhY4?&wmode=opaque)

## 새로워진 점

- **대화**에서 작성 중인 메시지가 자동으로 저장돼요.
- 메시지를 쓰다가 보내지 않고 나가도, 돌아오면 작성하던 내용이 그대로 남아 있어요.
- **내부 댓글** 임시 저장본은 채널을 바꾸거나, 입력창을 접거나 펼치거나, 다른 대화로 이동해도 유지돼요.
- 입력창을 접으면 마지막으로 선택한 채널을 기억해요.
- 덕분에 작업을 더 빨리 이어 가고, 대화 흐름도 놓치지 않아요.
