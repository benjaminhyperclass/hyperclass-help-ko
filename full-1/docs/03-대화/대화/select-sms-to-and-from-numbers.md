# 대화에서 SMS 보낸 사람·받는사람 번호 선택하기

**대화**(Conversations)에서 SMS를 보낼 때, 메시지를 보내는 비즈니스 번호와 메시지를 받는 연락처 번호를 직접 고를 수 있어요. 서브 계정에 메시지용 번호가 여러 개 있거나 연락처에 전화번호가 여러 개 저장되어 있을 때 특히 유용해요. 보낸 사람 번호를 직접 고르지 않으면 하이퍼클래스가 발신 번호 우선순위에 따라 대화가 일관되게 이어지도록 번호를 정해요.

## 이 문서에서 배울 내용

하이퍼클래스가 SMS 발신 번호를 정하는 방법, **대화**에서 **보낸 사람** 번호와 **받는사람** 번호를 직접 고르는 방법, 연락처에 번호가 여러 개일 때의 동작, 메시지를 실제로 보낸 번호를 확인하는 방법을 알아봐요.

{% hint style="warning" %}
**보낸 사람** 번호를 직접 선택하면 자동 선택보다 우선해요. 단, 선택한 번호는 해당 서브 계정에 속해 있어야 하고, SMS를 지원해야 하며, 적용되는 메시지 등록 및 규정 준수 요건도 충족해야 해요.
{% endhint %}

## SMS 보낸 사람 번호와 받는사람 번호란?

보낸 사람 번호는 하이퍼클래스가 SMS를 보낼 때 쓰는 비즈니스 전화번호예요. 받는사람 번호는 메시지를 받는 연락처의 전화번호예요.

선택할 수 있는 번호가 여러 개면 **대화**의 메시지 작성창에서 보내기 전에 보낸 사람과 받는 사람을 고를 수 있어요.

보낸 사람 번호를 직접 고르지 않으면 하이퍼클래스가 발신 번호 우선순위 규칙에 따라 어느 비즈니스 번호로 보낼지 정해요.

## SMS 번호를 직접 선택하면 좋은 점

기업이나 연락처가 전화번호를 여러 개 쓸 때, 올바른 보낸 사람과 받는 사람을 고르면 SMS 대화를 정확하게 이어 갈 수 있어요.

- 알맞은 비즈니스 번호로 보내기: 서브 계정에 번호가 여러 개 있을 때 원하는 번호로 보낼 수 있어요.
- 대화 흐름 유지: 하이퍼클래스가 그 대화에 이미 연결된 번호를 계속 사용할 수 있어요.
- 사용자별 번호 지원: 메시지를 보내는 사용자에게 배정된 번호가 자동으로 선택될 수 있어요.
- 올바른 연락처 번호로 보내기: 연락처에 저장된 번호가 여러 개면 그중에서 고를 수 있어요.
- 자동 선택보다 우선 적용: **보낸 사람** 번호를 직접 고르면 자동 발신 번호 선택보다 우선해요.

## 사전 조건과 제한 사항

보낸 사람과 받는 사람 번호가 유효하고, 권한이 맞고, 메시지 규정 준수 요건을 충족해야 SMS 발송 실패나 예상과 다른 발신 번호 선택을 막을 수 있어요.

- 보낸 사람 번호는 해당 서브 계정에 속해 있어야 해요.
- 선택한 보낸 사람 번호는 SMS를 지원해야 해요.
- 연락처에 유효한 전화번호가 있어야 해요.
- 연락처에 전화번호가 여러 개면 어떤 번호가 **기본**으로 지정되어 있는지 확인하세요.
- 적용되는 메시지 등록, 규정 준수, 수신거부, 옵트아웃 요건은 그대로 적용돼요.

{% hint style="info" %}
워크플로우와 대량 SMS는 각자의 설정으로 발신 번호를 정해요. 이 문서에서 설명하는 발신 번호 동작은 주로 **대화**에서 직접 보내는 SMS를 기준으로 해요.
{% endhint %}

## 하이퍼클래스가 보낸 사람 번호를 정하는 방법

하이퍼클래스는 어느 비즈니스 번호로 SMS를 보낼지 정할 때 정해진 우선순위를 따라요. 이 순서를 알면 메시지가 예상과 다른 번호로 나간 이유를 이해하는 데 도움이 돼요.

발신 번호 우선순위: 직접 선택한 보낸 사람 번호 → 메시지를 보내는 사용자에게 배정된 번호 → 대화에 이미 연결된 번호 → 기본 발신 번호

### 1. 직접 선택한 보낸 사람 번호

메시지에 쓸 보낸 사람 번호를 직접 고르면 하이퍼클래스는 그 번호를 가장 먼저 써요. 특정 비즈니스, 부서, 팀 번호로 보내야 할 때 직접 정할 수 있어요.

### 2. 사용자에게 배정된 번호

직접 고른 번호가 없으면 하이퍼클래스는 메시지를 보내는 사용자에게 사용할 수 있는 전화번호가 배정되어 있는지 확인해요. 그 번호로 SMS를 보낼 수 없으면 적용 가능한 대체 번호를 대신 쓸 수 있어요.

### 3. 기존 대화에 연결된 번호

사용자에게 배정된 번호를 쓰지 않는 경우, 하이퍼클래스는 그 연락처의 SMS 대화에 이미 연결된 번호를 확인해요. 기존 번호를 계속 쓰면 대화 흐름이 끊기지 않아요.

### 4. 기본 발신 번호

위의 우선순위에 하나도 해당하지 않으면 하이퍼클래스는 서브 계정의 기본 발신 번호를 사용해요.

## 대화에서 보낸 사람 번호 선택하기

자동 선택에 맡기지 않고 특정 비즈니스 번호로 메시지를 보내야 할 때 보낸 사람 번호를 직접 선택하세요.

1. **서브 계정 보기**에서 **대화**를 클릭하세요.
2. 메시지를 보낼 연락처와의 대화를 여세요.
3. 메시지 작성창에서 **SMS**를 선택하세요.
4. **보낸 사람** 번호 선택기를 찾으세요.
5. **보낸 사람** 드롭다운을 클릭하세요.
6. 사용할 비즈니스 전화번호를 선택하세요.

![대화의 SMS 작성창에서 보낸 사람 번호 선택기가 보이는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081374865/original/jBVfOBBqyOw67_GQWTem7-_RqfzsOVbjOQ.png?1789872667)
![선택할 수 있는 발신 전화번호가 나열된 보낸 사람 드롭다운](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081374876/original/YAARto3KnFbWGmrrOztoAxcNfK6uCeJ5ag.png?1789872719)

7. SMS 내용을 작성하세요.
8. 선택한 **보낸 사람** 번호를 확인하세요.
9. **보내기**를 클릭하세요.

### 사용자는 어떤 발신 번호를 쓸 수 있나요?

선택할 수 있는 번호는 사용자의 역할과 번호 배정에 따라 달라질 수 있어요.

- **관리자**: 계정에 설정된 전화번호를 사용할 수 있어요.
- **사용자**: 자신에게 적용되는 기본 번호, 마지막으로 사용한 번호, 사용자에게 배정된 번호, 배정되지 않은 번호를 사용할 수 있어요.

## 연락처의 받는사람 번호 선택하기

연락처에 저장된 번호가 여러 개일 때 받는사람 번호를 직접 고르면 메시지가 알맞은 번호로 가요.

1. **서브 계정 보기**에서 **대화**를 클릭하세요.
2. 해당 연락처와의 대화를 여세요.
3. 메시지 작성창에서 **SMS**를 선택하세요.
4. **받는사람** 필드를 찾으세요.
5. 연락처에 전화번호가 여러 개면 **받는사람** 번호 드롭다운을 클릭하세요.
6. 메시지를 보낼 전화번호를 선택하세요.

![받는사람 번호 드롭다운에서 연락처의 전화번호를 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081374889/original/pJubPOtxZ_oBgG26ZtsedEV9fsAdDL_4-Q.png?1789872876)

7. 선택한 받는사람 번호를 확인하세요.
8. SMS를 작성하고 보내세요.

연락처 하나에는 전화번호를 최대 11개까지 저장할 수 있고, 그중 하나가 **기본**으로 지정돼요. 이전 대화가 없으면 기본 번호가 기본값으로 쓰여요.

## SMS를 어느 번호로 보냈는지 확인하기

SMS를 보낸 뒤에는 메시지 상세 정보에서 실제로 쓴 발신 번호를 확인할 수 있어요. 예상과 다른 번호로 나간 이유를 찾을 때 유용해요.

1. **서브 계정 보기**에서 **대화**를 클릭하세요.
2. 확인할 대화를 여세요.
3. 살펴볼 SMS를 찾으세요.
4. 메시지 위에 마우스를 올리세요.
5. **점 3개 메뉴(⋮)**를 클릭하세요.
6. **상세 정보**를 선택하세요.
7. **메시지 상세 정보**에 표시된 발신 전화번호를 확인하세요.

## 자주 묻는 질문

### 보낸 사람 번호를 직접 선택하면 어떻게 되나요?
직접 선택한 **보낸 사람** 번호가 사용자 배정 번호, 대화 이력, 기본 발신 번호보다 우선해요.

### 보낸 사람 번호를 선택하지 않으면 어떻게 되나요?
하이퍼클래스가 메시지를 보내는 사용자에게 배정된 번호를 먼저 확인하고, 그다음 기존 대화에 연결된 번호, 마지막으로 기본 발신 번호를 확인해요.

### 왜 SMS가 계속 예전 번호로 나가나요?
기존 대화가 아직 그 번호와 연결되어 있을 수 있어요. 발신 번호를 바꾸려면 원하는 **보낸 사람** 번호를 직접 선택하세요.

### 사용자에게 배정된 번호로 SMS를 보낼 수 없으면 어떻게 되나요?
배정된 번호가 SMS를 지원하지 않으면 하이퍼클래스가 적용 가능한 기본 발신 번호로 대체할 수 있어요.

### 아무 전화번호나 보낸 사람으로 선택할 수 있나요?
아니요. 선택한 번호는 해당 서브 계정에 속해 있어야 하고 SMS를 보낼 수 있는 번호여야 해요.

### 연락처에 전화번호가 여러 개면 어떻게 되나요?
**대화**의 **받는사람** 선택기에서 알맞은 번호를 고르세요. 연락처 정보에서도 저장된 번호 중 하나가 **기본**으로 표시돼요.

### 연락처에 전화번호를 몇 개까지 저장할 수 있나요?
현재 하이퍼클래스는 연락처 하나에 전화번호를 최대 11개까지 지원해요.

### 메시지를 실제로 어느 번호로 보냈는지 어떻게 알 수 있나요?
**대화**에서 SMS 위에 마우스를 올리고 **점 3개 메뉴(⋮) → 상세 정보**를 클릭한 다음, 발신 정보를 확인하세요.

### 워크플로우 SMS 메시지에서도 보낸 사람 번호를 고를 수 있나요?
네. 워크플로우의 발신 설정에서 보낸 사람 번호를 지정할 수 있어요. 워크플로우 설정은 **대화**의 직접 작성창과 별도로 관리돼요.

### 번호를 직접 선택하면 SMS 규정 준수 요건을 건너뛸 수 있나요?
아니요. 선택한 발신 번호도 적용되는 전화 기능, 등록, 규정 준수, 수신거부, 옵트아웃 요건을 충족해야 해요.
