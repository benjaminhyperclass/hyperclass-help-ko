# HiRise 디자인의 스니펫 이해하기

새로워진 HiRise 스니펫 페이지를 쓰면 하이퍼클래스에서 시간을 아끼고 팀과 더 빠르게 협업할 수 있어요. 화면이 더 깔끔해지고, 목록이 바로 열리고, 공유한 URL에 보던 화면 상태가 그대로 담겨요. 팀원도 내가 보던 스니펫 목록을 그대로 볼 수 있어요.

## HiRise 스니펫 페이지란?

HiRise 스니펫 페이지는 **대화**(Conversations) 안에 있는 문자·이메일 스니펫을 모아 둔 새 화면이에요. 하이퍼클래스의 HiRise 디자인 시스템으로 만들었어요. 기존 목록 화면을 대신해 더 빠르고 현대적인 레이아웃을 제공해요. URL에 필터와 페이지 위치가 저장되어서 보기 편하고 협업하기도 좋아요.

## HiRise 스니펫 페이지의 장점

- HiRise 인터페이스는 가독성이 좋고 화면이 덜 복잡해요.
- 스니펫이 많아도 거의 바로 열려요.
- 공유한 URL에 검색어, 페이지 번호, 페이지당 행 수가 담겨 있어서 팀원도 똑같은 화면을 볼 수 있어요.
- 반응형 레이아웃이라 어떤 화면 크기에서도 잘 맞아요.
- 업그레이드된 다른 모듈과 같은 HiRise 내비게이션을 써서 사용 경험이 일관돼요.

## HiRise 내비게이션과 레이아웃

새 스니펫 페이지는 목록을 한가운데에 두고, 표 하나로 간단하게 보여 줘요. 필터, 검색, 일괄 작업은 머리글 바에 모여 있어요. **새 폴더**와 **+ New Snippet**(+ 새 스니펫) 버튼은 오른쪽 위에 있어서 바로 누를 수 있어요. 컨텍스트 메뉴는 사이드 패널로 열려요. 그래서 스니펫을 편집하다가 목록에서 보던 위치를 잃지 않아요.

## HiRise 스니펫 페이지 사용하기

HiRise 스니펫은 모든 계정에 자동으로 적용돼요. 따로 설정할 필요가 없어요.

### 스니펫 페이지 열기

1. 왼쪽 메뉴에서 **대화**를 클릭하세요.
2. 페이지 위쪽의 **스니펫** 탭을 선택하세요.

스니펫 대시보드가 열려요. 여기서 대화에 바로 쓸 수 있는 미리 써 둔 메시지를 보고, 만들고, 정리할 수 있어요.

![스니펫 탭이 열린 대화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056243013/original/JzQF2aA7_kQzIhPmMG63Po_L64w-JHdCSg.png?1760702729)

### 스니펫 검색하기

스니펫 페이지 오른쪽의 **검색** 창에 이름이나 키워드를 입력하세요. 입력하는 동안 목록이 자동으로 걸러지고, 검색어와 맞는 스니펫만 보여요.

![스니펫 검색 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056243799/original/AEWXFR8jDzkV5YdQP0DvVRsk6QDEavtKnQ.png?1760702840)

### 새 스니펫 만들기

1. 오른쪽 위의 **+ New Snippet** 버튼을 클릭하세요.
2. **텍스트 스니펫 추가** 또는 **이메일 스니펫 추가**를 선택하세요.

새 창이 열려요. 여기서 반복해서 쓸 내용을 작성하고 저장하면, 더 빠르고 일관되게 소통할 수 있어요.

![새 스니펫 만들기 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056243868/original/sK2i8lnlVoluWHqwbM9WF7TbQVsjM5sfhQ.png?1760702857)

### 새 폴더 만들기

오른쪽 위의 **새 폴더** 버튼을 클릭하면 스니펫을 카테고리나 용도별로 정리할 수 있어요. 영업 후속 메시지나 고객 지원 답변처럼 관련 있는 메시지를 한 폴더에 모아 두면 찾고 관리하기 쉬워요.

![새 폴더 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056243903/original/3uhVp7fyoKI-iXetulmLzpZZpmVttsxrUg.png?1760702875)

### 기존 스니펫 관리하기

스니펫 옆의 **점 3개 메뉴(⋮)** 를 클릭하면 **폴더로 이동**, **스니펫 편집**, **스니펫 복제**, **스니펫 삭제** 같은 관리 옵션이 나와요. 이 빠른 메뉴로 목록 화면을 벗어나지 않고 스니펫을 정리하고, 수정하고, 삭제할 수 있어요.

![스니펫 관리 옵션 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056244426/original/2TgHlkN8RRXpisfv9d_6hL0I8w5CmgGUYQ.png?1760703060)

## 자주 묻는 질문

### 실험실이나 베타 토글을 켜야 하나요?

아니요. HiRise 스니펫 페이지는 이미 모든 서브 계정에 적용되어 있어요.

### 스니펫 기능이 바뀐 게 있나요?

아니요. 만들기, 편집, 폴더, 권한 기능은 모두 그대로예요. 디자인과 성능만 좋아졌어요.

### 예전 디자인으로 되돌릴 수 있나요?

기존 레이아웃은 플랫폼 전체의 일관성을 위해 없어졌어요.

### 나중에 스니펫을 추가하거나 삭제하면 공유한 URL이 안 열리나요?

아니요. 링크에는 검색, 필터, 페이지 위치 같은 보기 설정이 저장돼요. 그래서 다른 사람도 내가 걸러 둔 화면을 그대로 볼 수 있어요.

### 스니펫 권한에 영향이 있나요?

권한은 그대로예요. 스니펫을 쓰려면 지금처럼 **View & Manage Conversations**(대화 보기 및 관리) 권한이 필요해요.

### 저장된 URL을 다른 서브 계정에서도 쓸 수 있나요?

아니요. 공유한 URL은 같은 서브 계정 안에서만 작동해요. 권한이 없는 사용자는 권한 오류 화면을 보게 돼요.
