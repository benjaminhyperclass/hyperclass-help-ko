# 수동 SMS 액션 설정하기

수동 SMS 액션은 자동화된 워크플로우 중간에 팀원이 직접 SMS를 보내거나 확인하는 단계를 넣는 기능이에요. 자동 문자만으로는 부족한 개인화와 사람의 손길을 더하고 싶을 때 쓰세요.

자동 SMS 캠페인은 고객에게 빠르게 닿을 수 있지만, 고객이 원하는 맞춤 소통이 부족할 때가 있어요. 수동 SMS 액션을 넣으면 자동화와 사람의 대응을 함께 쓸 수 있어요.

## 수동 SMS 액션을 추가하는 이유

1. 고객과 직접 소통: 고객 응대에는 사람의 손길이 필요할 때가 있어요. 수동 SMS 액션을 넣으면 팀원이 고객 문의에 직접 답하도록 알릴 수 있어서, 더 맞춤화된 경험을 줄 수 있어요.
2. 승인 절차: 중요한 결정이나 민감한 정보가 오가는 워크플로우에서는 수동 SMS 액션을 승인 단계로 쓸 수 있어요. 지정한 담당자가 내용을 검토하고 승인한 뒤에 다음 단계로 넘어가요.
3. 확인과 검증: 정보를 확인하거나 검증할 때도 유용해요. 예를 들어 구독 확인이나 연락처 확인 링크가 담긴 자동 SMS를 고객에게 보내고, 받은 응답을 담당자가 검토해서 알맞게 조치할 수 있어요.
4. 복잡한 워크플로우: 여러 시스템이나 팀이 얽힌 워크플로우에서는 수동 SMS 액션이 점검 지점 역할을 해요. 사람이 개입해서 모든 것이 제대로 돌아가는지 확인하거나, 개별 대응이 필요한 예외 상황을 처리할 수 있어요.
5. 시간이 중요한 정보: 즉시 확인해야 하는 정보를 보낼 때 도움이 돼요. SMS를 직접 보내면 수신자에게 메시지가 바로 도착하고, 필요한 조치도 바로 이어서 할 수 있어요.

정리하면, 수동 SMS 액션은 자동화 과정에 사람의 판단과 개입을 더하는 방법이에요. 워크플로우에 개인화, 의사 결정, 유연성을 더해 고객 경험을 높이고 복잡한 상황을 더 효과적으로 관리할 수 있어요.

## 모바일 앱에서 수동 액션 사용하기

1. 햄버거 메뉴(≡)를 누르세요.

   ![모바일 앱의 햄버거 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001343864/original/yS2VEPUgqBFg5AeiJt0YvsPjWJ1N2vEJgQ.png?1687202730)

2. **수동 작업**을 누르세요.

   ![메뉴에서 수동 작업 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001343898/original/25zCJMAqFHzKt7tDxG7uYk2it31ZKPfEFA.png?1687202788)

3. 파란색 **PLAY**(재생) 버튼을 누르면 처리를 기다리는 수동 액션이 표시돼요.

   ![처리 대기 중인 수동 액션을 보여 주는 PLAY 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001500673/original/ZocmBGuMAI_5AFVS9l0zqdbm0roDhxmNJw.png?1687358275)

4. 수동 통화 액션이면 통화 팝업이 나타나요. 통화가 어떻게 진행됐는지에 맞는 옵션을 선택하세요. 선택한 내용은 통화 리포트에 반영돼요.

   ![수동 통화 결과를 선택하는 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155001345244/original/qeOqcz1xiU8td-IB9-aP0e2I5z2MQcDcyA.png?1687205381)

## 자주 묻는 질문

### 수동 액션은 어디에서 처리하나요?

**데스크톱 앱**

**대화** 탭 > **수동 작업**에서 수동 액션을 처리할 수 있어요.

**모바일 앱**

**대화** 탭 > **수동 작업**에서 수동 액션을 처리할 수 있어요. 자세한 내용은 [모바일 앱에서 수동 액션 사용하기](how-to-set-up-a-manual-sms-action.md)를 참고하세요.
