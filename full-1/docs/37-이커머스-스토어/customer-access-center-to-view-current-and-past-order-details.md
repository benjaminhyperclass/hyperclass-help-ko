# 고객 액세스 센터에서 현재·지난 주문 상세 확인하기

**Customer Access Center**(고객 액세스 센터, CAC)는 고객이 구매 후 현재 주문과 지난 주문을 안전하게 확인할 수 있는 페이지예요. 고객은 주문 확인 이메일의 **주문 보기** 버튼으로 들어와 OTP 인증으로 로그인해요. 시스템이 보내는 이메일과 고객 액세스 센터의 문구는 고객이 설정한 플랫폼 언어로 자동 표시돼요.

## 개요

고객 액세스 센터에서 고객이 확인할 수 있는 내용은 다음과 같아요.

- 현재 주문 상세
- 지난 주문
- 처리 현황 업데이트
- 추적 정보
- 디지털 다운로드 (해당하는 경우)

고객은 구매 후 발송되는 주문 확인 이메일을 통해 고객 액세스 센터에 들어가요.

시스템이 보내는 모든 이메일과 고객 액세스 센터 안내 문구는 고객이 설정한 플랫폼 언어에 맞춰 자동으로 바뀌어요.

## 주문 확인 이메일 켜기

고객이 이메일로 주문 내역에 접속하게 하려면 다음 순서로 설정하세요.

1. **결제 > 설정 > 알림**으로 이동하세요.
2. **Order Confirmation Email for Stores**(스토어 주문 확인 이메일)를 찾으세요.
3. **주문 확인 이메일 활성화** 토글을 켜세요.
4. **저장**을 클릭하세요.

![결제 > 설정 > 알림에 있는 주문 확인 이메일 활성화 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064812474/original/zWSoV6fpxLsuWjRd0cIdGLEyGiX1BXZvUg.png?1770918106)

(**결제 > 설정 > 알림**에서 **주문 확인 이메일 활성화**를 보여 주는 화면이에요.)

이 설정을 끄면 고객에게 접속 이메일이 발송되지 않아요.

## 고객 액세스 센터에 접속하는 방법

고객이 구매를 마치면 다음 순서로 진행돼요.

1. 고객이 주문 확인 이메일을 받아요.
2. 이메일에 **주문 보기** 버튼이 들어 있어요.
3. 버튼을 클릭하면 고객 액세스 센터가 열려요.
4. 고객은 결제할 때 입력한 이메일로 받은 OTP로 로그인해요.

![주문 확인 이메일의 주문 보기 버튼과 OTP 로그인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064812510/original/S2_Ym5yvxVnbZGLcFi-ACgv6AD299DKevw.png?1770918156)

고객은 결제할 때 사용한 이메일 주소를 그대로 입력해야 해요.

## 고객이 볼 수 있는 내용

### 현재 주문 상세

고객은 다음 내용을 확인할 수 있어요.

- 주문 상품
- 금액 내역
- **주문 상태**
- 세금 및 배송 정보

### 처리 상태

스토어 운영자가 처리 상태를 업데이트하면 고객은 다음 내용을 볼 수 있어요.

- 일부 처리 또는 전체 처리 상태
- **추적 번호**
- **추적 URL**
- 배송업체 이름

### 지난 주문

고객은 내비게이션 메뉴에서 **주문**을 선택해 이전 구매 내역을 볼 수 있어요.

### 직접 접속 URL

다음 주소로 고객 액세스 센터에 바로 접속할 수도 있어요.

```
<storeurl>/store/account/orders
```

예시:

```
myawesomestore.com/store/account/orders
```

## 디지털 다운로드 표시 방식 (업데이트된 로직)

디지털 상품은 다음과 같이 표시돼요.

- 유효한 디지털 파일이 1개 이상 업로드된 경우에만 **Download**(다운로드) 버튼이 나타나요.
- 업로드된 파일이 없으면 **Download** 버튼이 숨겨져요.
- 이때 고객 액세스 센터에는 **No downloads available yet**(아직 다운로드할 수 있는 파일이 없어요)이라는 문구가 표시돼요.

### 구매 후 파일을 업로드한 경우

구매 이후에 디지털 파일을 업로드하면 다음과 같이 반영돼요.

- 고객 액세스 센터가 자동으로 업데이트돼요.
- 다운로드를 바로 이용할 수 있어요.

### 파일을 삭제한 경우

디지털 파일을 모두 삭제하면 다음과 같이 반영돼요.

- **Download** 버튼이 바로 사라져요.

### 혼합 주문 (디지털 + 실물)

- 파일이 있는 디지털 상품 → **Download** 버튼 표시
- 파일이 없는 디지털 상품 → **No downloads available yet** 표시
- 실물 상품 → **Download** 버튼이 표시되지 않음

## 언어 지원 (i18n 업데이트)

시스템이 보내는 모든 안내는 이제 고객이 설정한 플랫폼 언어로 자동 표시돼요.

적용되는 항목은 다음과 같아요.

- 주문 확인 이메일
- **주문 보기** 버튼 레이블
- 고객 액세스 센터 시스템 메시지
- 다운로드 관련 메시지
- OTP 안내 문구

따로 설정할 필요는 없어요.

언어는 사용자의 플랫폼 언어 설정을 기준으로 정해져요.

## 참고 사항

- 같은 이메일을 쓰는 연락처가 여러 개면, 가장 먼저 만든 연락처로 로그인돼요.
- 스티키 연락처(sticky contact)를 켜면 브라우저 세션별로 모든 주문이 한곳에 모여요.
- 도메인이 연결되어 있고 올바르게 설정되어 있는지 확인하세요.
- 디지털 다운로드는 **Digital**(디지털)로 지정하고 파일을 업로드한 상품에서만 이용할 수 있어요.

## 자주 묻는 질문

### 고객이 주문 확인 이메일을 받지 못했어요. 왜 그럴까요?

**결제 > 설정 > 알림**에서 **주문 확인 이메일 활성화** 토글이 켜져 있는지 확인하세요.

### Download 버튼이 보이지 않아요.

상품 또는 옵션에 유효한 디지털 파일이 1개 이상 업로드된 경우에만 **Download** 버튼이 나타나요.

### 고객 액세스 센터에 "No downloads available yet"이 표시돼요.

구매한 디지털 상품에 업로드된 파일이 없을 때 나타나는 문구예요.

### 주문 확인 이메일이 다른 언어로도 발송되나요?

네. 이메일과 고객 액세스 센터 메시지는 고객이 설정한 플랫폼 언어로 자동 표시돼요.

### 구매한 뒤에 파일을 업로드하면 어떻게 되나요?

고객 액세스 센터가 자동으로 업데이트되고 다운로드를 이용할 수 있게 돼요.
