# 미완료 결제 관리·내보내기와 놓친 매출 되살리기

**미완료 결제** 페이지에서 고객 데이터를 내보내고, 필터로 기록을 찾고, 복구 알림을 설정하고, 결제 링크를 직접 보내 놓친 매출을 되살릴 수 있어요. 이 문서에서는 미완료 결제 기록을 검색·필터링·내보내기·관리하는 방법과, 고객이 구매를 마치도록 돕는 방법을 설명해요.

## 미완료 결제란?

고객이 상품을 장바구니에 담고 결제를 시작했지만, 구매를 끝내지 않고 나가는 경우가 있어요. 하이퍼클래스는 이렇게 끝나지 않은 결제를 저장해 둬요. 고객 정보와 장바구니 내용을 확인하고, 복구 진행 상황을 살피고, 고객이 돌아와 주문을 마치도록 안내할 수 있어요.

**미완료 결제** 페이지에서는 이런 기록을 한곳에서 검색, 필터링, 내보내기, 관리할 수 있어요. 결제 상세 정보를 확인하고, 미완료 장바구니 알림을 설정하고, 필요할 때 복구 링크를 복사해 고객에게 직접 보낼 수도 있어요.

## 미완료 결제 페이지의 주요 기능

**미완료 결제** 페이지에는 끝나지 않은 구매를 관리하고 되살리는 데 쓰는 기능이 있어요.

- **CSV 내보내기** — 현재 페이지에서 기록을 하나, 여러 개, 또는 전체 선택해서 고객 정보, 장바구니 내용, 상품 정보, 활동 로그, 복구 상태를 내보내요.
- 검색과 필터 — 고객 이름이나 이메일로 검색하고, **이메일 상태**, **복구 상태**, **Date Range**(날짜 범위)로 기록을 걸러 봐요.
- 알림 설정 — 페이지에서 바로 **Abandoned Cart Notification Settings**(미완료 장바구니 알림 설정)를 열어 자동 복구 이메일을 관리해요.
- 복구 링크 공유 — 결제 URL을 복사해 고객에게 직접 보내면, 고객이 바로 구매를 이어 갈 수 있어요.
- 개선된 사용 환경 — 로딩 화면, 페이지 나눔, 반응형 레이아웃, 빈 화면이 새로워져 더 빠르고 직관적으로 쓸 수 있어요.

## 미완료 결제 페이지 열기

다음 단계에 따라 하이퍼클래스 계정에서 미완료 결제를 확인하고 관리하세요. 경로는 **결제 > 주문 > 미완료 결제**예요.

1. 왼쪽 메뉴에서 **결제**를 클릭해요.

   ![왼쪽 메뉴에서 결제 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629461/original/jTasiPPeHkuq2Wk7Qk2VIyqGr1QtU4ARSQ.png?1785868124)

2. **주문**에 마우스를 올리고, 드롭다운에서 **미완료 결제**를 선택해요. 끝나지 않은 결제 기록이 모두 보여요.

   ![주문 메뉴에서 미완료 결제 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629472/original/cw1pOZvBJQlSqzv679NrvZJITgzAJ7CGSQ.png?1785868139)

## 기록 검색하고 필터링하기

검색과 필터를 쓰면 고객 정보나 복구 활동을 기준으로 미완료 결제를 빠르게 찾을 수 있어요. 검색어와 필터 조건에 맞는 기록만 표에 자동으로 표시돼요.

- 고객 검색 — 검색 필드에 고객 이름이나 이메일 주소를 입력해요.
- 필터 적용 — **Add Filter**(필터 추가)를 클릭하고 **이메일 상태**, **복구 상태**, **Date Range**(날짜 범위) 중 하나를 선택해요.

![검색 필드와 필터 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629490/original/_CXtvD-ie9fTdC6MdS4aEE7yQsYEiHDZfw.png?1785868161)

## 미완료 결제 기록 내보내기

미완료 결제 데이터를 CSV 파일로 내보내면 리포트, 분석, 기록 보관에 쓸 수 있어요. 내보낸 파일에는 고객 정보, 장바구니 내용, 상품 정보, 활동, 복구 정보가 들어 있어요.

1. 기록 옆의 체크박스로 내보낼 미완료 결제를 하나 이상 선택해요.

   ![내보낼 기록 체크박스 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629503/original/Vol0j1kWKpjnTvXR3r_aI1qzkevWcl02eA.png?1785868182)

2. 기록을 하나 이상 선택한 뒤 **CSV 내보내기**를 클릭해요.
   - 내보낼 기록이 5,000개 이하면 CSV 파일이 바로 다운로드돼요.
   - 5,000개를 넘으면 하이퍼클래스가 내보내기를 처리한 뒤 CSV 파일을 이메일로 보내 드려요.

   ![CSV 내보내기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629507/original/ldwkEjGko-W78ginf8aRJha8SqySYrk1cw.png?1785868191)

## 복구 알림 설정하기

자동 복구 이메일을 설정하면 장바구니를 두고 나간 고객에게 알림을 보내 구매를 마치도록 안내할 수 있어요.

1. **미완료 결제** 페이지에서 **Configure Notifications**(알림 구성)를 클릭해요.

   ![알림 구성 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629539/original/DnfSgMAV1-xmM2Rj2OK0Vu7yceHv86qSTA.png?1785868216)

2. **Abandoned Cart Notification Settings**(미완료 장바구니 알림 설정) 화면이 열려요. 여기서 복구 이메일을 관리할 수 있어요. 미완료 장바구니 알림의 이메일 템플릿, 제목, 발송 시점을 수정하고 변경 내용을 저장하세요.

   ![미완료 장바구니 알림 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629562/original/RG0-KI4L_n0hf4KhaicAgfqSZLKiqUrTSw.png?1785868234)

## 복구 링크 공유하기

복구 링크를 보내면 고객이 처음부터 다시 시작하지 않고 미완료 결제 화면으로 바로 돌아올 수 있어요.

1. 확인할 미완료 결제의 주문 이름을 클릭해 열어요.

   ![미완료 결제 주문 이름 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629578/original/s7Q75aEeFsj3e-mEhp__5BCr8SDXBykZiQ.png?1785868274)

2. 상세 페이지 위쪽에서 결제 URL을 찾아 **복사** 아이콘을 클릭해요. 복사한 복구 링크를 이메일, SMS 등 메시지에 붙여 넣어 보내세요. 고객이 바로 결제 화면으로 돌아와 구매를 마칠 수 있어요.

   ![결제 URL 옆 복사 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077629586/original/Xd_XgWg-Cax3kZMMq3L3zBWz08QUwglQIQ.png?1785868292)
