# 스토어 상품 목록 페이지에서 상품 순서 직접 정하기

하이퍼클래스 이커머스 스토어의 수동 상품 정렬 기능을 쓰면 상품 목록 페이지에 상품이 보이는 순서를 직접 정할 수 있어요. 가장 중요한 상품을 고객에게 먼저 보여 주고 싶을 때 사용하세요.

## 수동 상품 정렬이란?

수동 상품 정렬은 상품 목록 페이지에서 상품이 표시되는 순서를 스토어 운영자가 직접 정하는 기능이에요. 상품마다 표시 우선순위를 지정하면 베스트셀러, 신상품, 프로모션 상품을 고객에게 먼저 보여 줄 수 있어요. 상품 배치를 직접 조정할 수 있어서 스토어의 시각적 완성도와 판매 전략에 도움이 돼요.

## 수동 상품 정렬의 주요 장점

수동 상품 정렬을 쓰면 스토어 구성과 고객 경험을 더 세밀하게 관리할 수 있어요.

- 핵심 상품 강조: 우선순위가 높은 상품이나 시즌 상품을 목록 맨 위에 보여 줄 수 있어요.
- 맞춤 머천다이징: 마케팅 캠페인이나 재고 목표에 맞게 상품을 배치할 수 있어요.
- 동일 우선순위 자동 정렬: 우선순위가 같은 상품은 가나다·ABC순으로 자동 정렬돼서 순서가 일정하게 유지돼요.
- 간편한 조정: 숫자만 입력하면 상품 순서를 빠르게 바꾸고 결과도 바로 확인할 수 있어요.
- 새 스토어 기본값: 모든 새 스토어에는 **추천** 정렬 옵션이 기본으로 설정되어 있어서 설정이 간단해요.
- 입력 오류 방지: 정수만 입력할 수 있어서 실수나 혼동을 줄일 수 있어요.
- 즉시 확인: 변경 내용이 바로 반영되므로 상품 목록이 어떻게 보일지 바로 알 수 있어요.

## 수동 상품 정렬 설정하기

상품 목록이 비즈니스 목표와 프로모션에 맞게 보이도록 아래 순서대로 설정하세요.

### 1단계: 스토어 편집기 열기

1. 하이퍼클래스에 로그인하세요.
2. 왼쪽 메뉴에서 **사이트**를 클릭하세요.
3. **스토어**를 선택해 이커머스 스토어 목록을 열어요.
4. 아래 중 하나를 선택하세요.
   - **+ New Store**(새 스토어 추가)를 클릭해 새 스토어를 처음부터 만들어요.
   - 기존 스토어 이름이나 점 세 개 메뉴를 클릭한 다음 **편집**을 클릭해요.

![스토어 편집기를 여는 화면 녹화](https://jumpshare.com/v/YPlkVx7WX8eoXEOzH9Zi+/GIF+Recording+2025-06-16+at+10.00.41+PM.gif)

### 2단계: 상품 목록 열기

1. 스토어 편집기에서 **상품** 탭으로 이동하세요.
2. 해당 스토어에 연결된 모든 상품이 목록으로 표시돼요.

![스토어 편집기의 상품 탭 화면](https://jumpshare.com/v/ekdArpworhEtw2YVvmSh+/Screen+Shot+2025-06-16+at+10.02.44+PM.png)

### 3단계: 상품별 표시 우선순위 설정하기

1. 각 상품 옆의 **표시 우선순위** 열을 찾으세요.
2. 우선순위를 정하고 싶은 상품마다 입력란에 정수(예: 1, 2, 3)를 입력하세요.
   - 숫자가 낮을수록 상품 목록 페이지에서 더 위에 표시돼요.
     - 1이 가장 높은 우선순위예요.
     - 2, 3, … 순서로 뒤따라요.
3. **변경사항 저장** 버튼을 클릭해 설정을 적용하세요.

{% hint style="info" %}
정수만 입력할 수 있어요. 소수(예: 0.1, 1.5)나 문자(예: ABCD)를 입력하면 유효성 검사 오류가 나고 저장되지 않아요.
{% endhint %}

![표시 우선순위 열에 숫자를 입력한 화면](https://jumpshare.com/v/80h77BP7ZMvzDFJCn5Mh+/Screen+Shot+2025-06-16+at+10.29.00+PM.png)

### 4단계: 스토어 화면 미리보기

1. **페이지** 탭으로 이동하세요.
2. 상품 목록 페이지의 **미리보기 링크** 버튼을 클릭하세요.
3. 지정한 우선순위대로 상품이 배치된 것을 확인하세요. 숫자가 낮은 상품이 먼저 표시돼요.

![상품 목록 페이지 미리보기 화면 녹화](https://jumpshare.com/v/cmMRRm3DSmohmgOabjnz+/GIF+Recording+2025-06-16+at+11.25.57+PM.gif)

### 5단계: 빌더에서 정렬 방식 설정하기

1. 상품 목록 페이지의 **편집** 또는 **새 탭에서 편집**을 클릭하세요.
2. **Product List**(상품 목록) 요소를 선택하세요.
3. **Sort & Filter**(정렬 및 필터) 옵션 아래의 **Default Sorting Option**(기본 정렬 옵션)에서 **추천**을 선택하세요.
4. **저장**을 클릭해 정렬 순서를 적용하세요.

{% hint style="info" %}
같은 **Product List** 요소 설정의 **레이아웃**에서 페이지당 상품 수를 최대 100개까지 늘릴 수 있어요. 상품이 많은 스토어에서 페이지 넘김이 지나치게 많아지는 것을 줄일 수 있어요.
{% endhint %}

![빌더에서 기본 정렬 옵션을 추천으로 선택하는 화면 녹화](https://jumpshare.com/v/8I40EoHmQelp8kxjdmil+/GIF+Recording+2025-06-16+at+11.36.37+PM.gif)

### 모바일 정렬 동작

모바일 고객은 **정렬** 하단 시트에서 정렬 기준(예: 가격 낮은순)을 직접 골라 수동 정렬 순서를 바꿀 수 있어요.

직접 정한 순서로 상품을 보여 주려면 **Default Sorting Option**을 **추천**으로 유지하세요. 그러면 고객이 다른 정렬 기준을 고르기 전까지 상품 목록 페이지가 내가 정한 순서로 열려요.

## 자주 묻는 질문

### 여러 상품에 같은 표시 우선순위를 지정하면 어떻게 되나요?

우선순위가 같은 상품은 두 번째 기준으로 가나다·ABC(A-Z)순으로 정렬돼요.

### 표시 우선순위에 소수나 문자를 입력할 수 있나요?

아니요. 정수만 입력할 수 있어요. 잘못된 값을 입력하면 오류 메시지가 표시돼요.

### 이 정렬 방식이 기존 스토어에도 영향을 주나요?

아니요. 기존 스토어는 직접 **추천**으로 바꾸지 않는 한 현재 정렬 설정이 그대로 유지돼요.

### 상품이 품절되면 어떻게 되나요?

품절 상품은 표시 우선순위와 관계없이 상품 목록의 맨 끝에 자동으로 배치돼요.

### 추천 정렬 옵션은 모든 스토어에서 쓸 수 있나요?

네, 모든 스토어에서 쓸 수 있고 새 스토어의 기본값이기도 해요.

### 추천으로 바꾼 뒤 이전 정렬 방식으로 되돌릴 수 있나요?

네, 빌더의 **고급 설정**에서 언제든 정렬 방식을 바꿀 수 있어요.

### 이 기능이 상품 검색 결과에도 영향을 주나요?

아니요. 수동 정렬은 상품 목록 페이지에만 적용되고 검색 결과에는 적용되지 않아요.
