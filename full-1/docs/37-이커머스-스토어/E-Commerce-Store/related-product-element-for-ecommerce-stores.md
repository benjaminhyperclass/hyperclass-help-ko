# 스토어 상품 상세 페이지에 관련 상품 보여주기

하이퍼클래스에서는 스토어 상품 상세 페이지에 관련 상품을 추천해서 보여줄 수 있어요. 방문자가 다른 상품도 쉽게 찾을 수 있고, 함께 구매하도록 유도하는 교차 판매에도 도움이 돼요.

## 사용 방법

1. 페이지 빌더에서 스토어의 **상품 상세** 페이지를 열고, **Show related products**(관련 상품 표시) 토글을 켜세요. 아래 항목은 원하는 대로 바꿀 수 있어요.
   1. 보여줄 상품 수 (기본값: 6개)
   2. 상품당 열 수 (데스크톱, 모바일 각각 설정, 기본값: 데스크톱 3열, 모바일 2열)
   3. 관련 상품 섹션의 제목 (기본값: "You may also like"(함께 보면 좋은 상품))
      ![관련 상품 표시 설정 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029535856/original/jnPormYrpDPns23VMEx3bQFGVO1nDJVqvg.png?1721380312)![관련 상품 표시 설정 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029535866/original/chDlIV--fBj5PP859N_MS8t4kmYw55GcSA.png?1721380326)

2. **저장 및 게시**를 클릭해 페이지를 게시하세요.

온라인 스토어 미리보기:

![온라인 스토어에서 관련 상품이 표시된 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155029536015/original/EyVPWaHp4QnZFMHBz9-eqtg_hvqSKrXhcw.jpeg?1721380452)

{% hint style="info" %}
1. 같은 컬렉션에 들어 있는 상품끼리 서로의 상품 상세 페이지에 관련 상품으로 표시돼요. 예를 들어 볼게요.
   1. "iPhone 15"라는 상품이 "Apple" 컬렉션과 "Summer Sale" 컬렉션에 모두 추가되어 있어요.
   2. 이 경우 "Apple" 컬렉션과 "Summer Sale" 컬렉션에 추가된 모든 상품이 관련 상품 후보가 돼요.
   3. 먼저 "Apple" 컬렉션의 상품이 표시되고, 그다음 "Summer Sale" 컬렉션의 상품이 표시돼요. 단, 사용자가 설정한 관련 상품 수 한도 안에서만 표시되고, 이 한도는 최대 10개까지예요.

2. 이제 상품 목록 페이지의 이미지는 1:1 비율로 제한돼요. 이미지를 그 크기에 맞춰 채워서 모든 상품과 이미지가 일관되고 보기 좋게 나타나요.
{% endhint %}
