# 이커머스 스토어에 검색창 요소 추가하기

스토어 웹사이트에 검색창 요소를 추가하면 방문자가 상품 목록을 일일이 넘겨 보지 않고도 원하는 상품을 바로 찾을 수 있어요. 검색창은 내비게이션 메뉴에 넣거나, 웹사이트 페이지에 독립된 요소로 넣을 수 있어요.

[동영상](https://www.youtube.com/embed/7ONCf4QhN0w?&wmode=opaque)

상품이 많은 스토어에서는 방문자가 상품을 하나씩 훑어보기 어렵고, 보지 못하고 지나치는 상품도 많았어요. 검색창은 이런 불편을 줄이기 위해 새로 나온 스토어용 요소예요.

## 사용 방법

1. 스토어의 페이지 빌더에서 검색창 요소를 추가하세요. 요소 추가 목록의 **Store** 섹션에 있어요.
2. 내비게이션 메뉴에 검색창을 넣으려면 내비게이션 메뉴 설정에서 **Show Search bar**(검색창 표시) 토글을 켜세요.
3. 검색창의 속성을 설정하세요. 설정할 수 있는 속성은 다음과 같아요.
   - 검색 버튼 색상
   - 검색 입력 상자의 텍스트 색상과 배경 색상
   - 검색 드롭다운의 텍스트 색상과 배경 색상
   - 입력 필드와 드롭다운의 **테두리 색상**
   - 글꼴 크기와 굵기
4. **저장** 또는 **게시**를 눌러 사이트에서 변경 내용을 확인하세요.

{% hint style="info" %}
- 스토어가 있는 웹사이트에서만 이 요소를 페이지에 추가할 수 있어요. 스토어 페이지와 스토어가 아닌 페이지 모두 가능해요.
- 내비게이션 메뉴의 검색창은 사용자 지정할 수 있는 항목이 제한적이에요. 모든 사용자 지정 옵션은 독립된 요소로 추가한 검색창에서만 쓸 수 있어요.
- 검색 추천(드롭다운)은 상품의 제목과 이름을 기준으로 결과를 보여 줘요.
- 방문자가 검색을 누르면 검색 결과가 나오는 상품 목록 페이지로 이동해요. 이 결과는 제목뿐 아니라 설명까지 포함해서 검색해요.
{% endhint %}
