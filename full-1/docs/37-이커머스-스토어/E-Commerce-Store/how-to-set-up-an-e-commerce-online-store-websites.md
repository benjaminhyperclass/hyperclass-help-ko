# 이커머스 온라인 스토어 설정하기

하이퍼클래스 이커머스 스토어를 쓰면 웹사이트에서 바로 상품을 보여 주고, 결제를 받고, 주문을 관리할 수 있어요. 이 문서에서는 **AI에게 문의**로 안내를 받으며 스토어를 만드는 방법과 상품 등록, 스토어 페이지 꾸미기, 결제 흐름, 주문 처리, 스토어 삭제까지 차례로 설명해요.

## 이커머스 온라인 스토어란?

이커머스 온라인 스토어는 고객이 상품을 둘러보고, 상세 정보를 확인하고, 장바구니를 관리하고, 결제한 뒤 주문 확인까지 받을 수 있는 온라인 매장이에요.

스토어 운영자는 같은 서브 계정에서 아래 작업을 모두 할 수 있어요.

- **결제 > 상품**에서 상품 설정
- **웹사이트 빌더**에서 스토어 페이지 꾸미기
- 결제 제공업체 연결
- 주문과 거래 내역 관리
- 구매 건 처리

## 이커머스 스토어의 장점

이커머스 스토어는 상품 관리, 결제, 대금 수령, 주문 처리를 하나의 고객 여정으로 이어 줘요. 매장이 어떻게 보이고 운영되는지도 직접 정할 수 있어요.

- 상품 관리를 한곳에서: **결제**에서 상품, 가격, 옵션, 설명, 이미지, 동영상을 만들고 관리해요.
- 내 브랜드에 맞는 스토어: 스토어 페이지와 스토어 요소의 스타일을 웹사이트와 브랜드에 맞게 바꿀 수 있어요.
- 안내를 받는 설정: **AI에게 문의**로 지원되는 스토어 설정 작업을 하나씩 진행할 수 있어요.
- 유연한 결제: 필수 고객 정보를 받고, 적용 가능한 쿠폰을 쓰고, 이용 가능한 수령 방식을 제공하고, 결제를 받을 수 있어요.
- 주문 관리: **결제**에서 주문, 거래 내역, 환불, 주문 처리 정보를 확인해요.
- 자동화된 고객 여정: 스토어 구매를 지원되는 영수증, 결제 이벤트, 주문 관련 자동화와 연결할 수 있어요.

## 스토어 설정하기

스토어를 완성하려면 상품, 스토어 페이지, 도메인, 연결된 결제 제공업체가 필요해요. **AI에게 문의**가 지원되는 설정 작업은 안내해 주지만, 계정 단위 설정 중 일부는 직접 해야 해요.

### AI에게 문의로 첫 스토어 설정하기

계정에 스토어가 아직 없으면, **AI에게 문의**가 지금까지의 설정 진행 상황을 보고 다음에 할 만한 작업을 추천해 줘요.

1. 서브 계정 화면에서 **사이트**를 선택하세요.
2. 상단 메뉴에서 **스토어**를 선택하세요.
3. 스토어 설정 배너에서 **설정 완료**를 클릭하세요.
4. 진행할 설정 작업을 선택하거나, 스토어 설정 전체를 차례대로 진행하세요.
5. **AI에게 문의**가 묻는 질문에 답하세요.
6. **AI에게 문의**가 스토어 데이터를 만들거나 바꾸기 전에 나오는 확인 요청을 검토하세요.
7. 지원되는 설정 단계가 모두 끝날 때까지 추천 작업을 이어서 진행하세요.

![설정 완료 버튼이 보이는 스토어 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081286257/original/9csqGwK7ltx4Au5UvX02Cw3c7Sp4a2Algw.png?1789731589)

스토어 설정은 한 번에 끝내지 않아도 돼요. **사이트 > 스토어 > 설정 완료**로 돌아오면 남은 작업부터 이어서 할 수 있어요.

### 도메인과 결제 설정 마무리하기

도메인과 결제 설정은 **AI에게 문의** 밖에서 직접 해야 할 수 있어요. 스토어를 게시하기 전에 아래 항목을 확인하세요.

- **기존 도메인**: **AI에게 문의**가 계정에 있는 기존 도메인을 스토어에 연결하는 일을 도와줘요.
- **New Domain**(새 도메인): 새 도메인 설정은 직접 해야 해요.
- **결제 제공업체**: 결제 제공업체 연결은 직접 해야 해요. **AI에게 문의**는 결제 제공업체의 인증 정보를 받거나 설정하지 않아요.

### 스토어 상품 만들고 설정하기

상품 설정에 따라 고객이 스토어에서 보는 내용이 정해져요. 가격, 옵션, 미디어, 상품 소개에 필요한 정보도 여기서 입력해요.

1. **결제 > 상품**으로 이동하세요.
2. 상품을 새로 만들거나 기존 상품을 여세요.
3. 필요에 맞게 상품 이름, 설명, 미디어, 가격, 옵션을 설정하세요.
4. 스토어에 보여 줄 상품은 **Include in Online Store**(온라인 스토어에 포함)를 켜세요.
5. 상품을 저장하세요.

![상품을 온라인 스토어에 포함하는 옵션이 보이는 상품 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930510/original/vXnsZPHSsO7tzFsg2DDhV2vGVXUlJROE7w.png?1790464708)

### 웹사이트에 스토어 추가하기

웹사이트에 스토어 요소나 미리 만들어진 스토어 섹션을 처음 추가하면 스토어가 만들어지고, 필요한 스토어 페이지도 함께 생성돼요.

1. **웹사이트 빌더**에서 스토어를 추가할 웹사이트를 여세요.
2. **요소 추가**를 클릭하세요.
3. **Cart**(장바구니), **Collections List**(컬렉션 목록), **Featured Products**(추천 상품) 같은 스토어 요소를 페이지에 끌어다 놓으세요. 미리 만들어진 스토어 섹션을 써도 돼요.

![페이지에 추가할 수 있는 스토어 요소가 보이는 웹사이트 빌더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930613/original/A6-a8qm0gQwWDUjbYPrRmDto-AxzjSpnsQ.png?1790465344)

4. 가져오기 창이 나타나면 아래 중 하나를 선택하세요.
   - **Add Store**(스토어 추가): 스토어를 만들고, 현재 페이지의 디자인 설정 중 지원되는 항목을 가져와요.
   - **건너뛰기**: 현재 페이지의 테마 설정을 가져오지 않고 스토어를 만들어요.
5. 생성된 스토어 페이지와 스토어 요소를 계속 꾸미세요.

![스토어 추가와 건너뛰기 옵션이 보이는 스토어 생성 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930617/original/qoNOReSuP6t6bJaBgf18GXzVW5XXLbXnqA.png?1790465363)

## 스토어 페이지와 결제 흐름

하이퍼클래스는 스토어 페이지 5개를 만들어요. 이 페이지들이 이어져서 고객이 상품을 찾고, 결제하고, 주문 확인을 받는 과정을 이끌어요. 웹사이트 요소를 더 추가하고 스토어 전용 설정을 바꿔서 꾸밀 수 있어요.

- **Products List**(상품 목록 페이지): 고객이 둘러볼 수 있는 상품이나 서비스를 보여 줘요.
- **상품 상세정보** 페이지: 상품 정보, 미디어, 가격, 선택 가능한 옵션을 자세히 보여 줘서 고객이 구매를 결정하도록 도와요.
- **Cart**(장바구니 페이지): 구매하려는 상품을 요약해서 보여 주고, 결제 전에 장바구니를 수정할 수 있게 해 줘요.
- **결제 페이지**: 고객이 필수 연락처와 주소 정보를 입력하고, 이용 가능한 수령 방식을 고르고, 적용 가능한 쿠폰 코드를 쓰고, 결제를 완료하는 페이지예요. **Pickup in Store**(매장 픽업)를 선택할 수 있고 고객이 선택하면, 하이퍼클래스는 **Shipping Details**(배송 정보) 섹션을 숨기고 선택한 픽업 장소를 배송 주소로 사용해요.
- **감사 페이지**: 구매가 정상적으로 끝난 뒤 주문 확인 내용을 보여 줘요.

![고객 구매 여정에 쓰이는 이커머스 스토어 페이지가 보이는 웹사이트 빌더](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155009726192/original/GZwk9jvkFpikz-O_ZCXGIOxsZkxIz6IMIg.png?1696942645)

스토어 페이지 순서: 일반 페이지는 스토어의 **페이지** 목록에서 순서를 바꿔 스토어 페이지 묶음의 앞이나 뒤에 둘 수 있어요. 스토어 페이지 5개는 아래 순서로 항상 붙어 있어야 해요.

**Products List** → **상품 상세정보** → **Cart** → **결제** → **감사 페이지**

스토어 페이지 5개끼리는 순서를 바꿀 수 없고, 그 사이에 일반 페이지를 넣을 수도 없어요. 지원되지 않는 이동을 시도하면 페이지가 마지막으로 저장된 위치로 돌아가고, 하이퍼클래스가 제한 사유를 안내하는 메시지를 보여 줘요. 이렇게 거부된 이동은 저장된 페이지 순서에 영향을 주지 않아요.

스토어 요소는 각 요소의 **일반**과 **고급** 설정으로 꾸며서 웹사이트의 나머지 부분과 어울리게 만들 수 있어요.

## 주문과 주문 처리 관리하기

고객이 결제를 마친 뒤에는 주문과 결제 기록으로 구매 내역을 확인하고, 지원되는 환불을 처리하고, 주문 처리 상황을 추적할 수 있어요.

- 이커머스 스토어 주문은 **결제 > 주문**에서 확인하세요.
- 결제 내역은 **결제 > 거래 내역**에서 확인하세요.
- 처음에 주문 처리가 필요한 상태인 주문은 **주문 상세** 페이지에서 관리할 수 있어요.
- 해당하는 주문을 처리할 때는 운송장 번호, 배송업체, 배송 추적 URL 같은 배송 정보를 추가하세요.
- 주문을 처리 완료로 표시한 뒤에도 주문에서 처리 정보를 계속 볼 수 있어요.

![배송과 추적 정보가 보이는 이커머스 주문 처리 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930610/original/mWTUT32AzibJD-CsEEFnrwPi4cdMGO63rQ.png?1790465313)

## 스토어 삭제하기

스토어를 삭제하면 그 스토어에 속한 페이지만 지워지고, 스토어와 관계없는 웹사이트 페이지는 그대로 남아요.

1. **사이트 > 스토어**로 이동하세요.
2. 스토어의 점 세 개 메뉴를 열거나 **Store Settings**(스토어 설정)를 여세요.
3. **Delete Store**(스토어 삭제)를 선택하세요.
4. 확인 창에 **DELETE**를 입력하세요.
5. **삭제**를 클릭하세요.

![스토어 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930654/original/-M7m6pR8KdMrFg2SXJ9DsTJisJKs8RVHpA.png?1790465762)

{% hint style="warning" %}
**Products List**, **상품 상세정보**, **Cart**, **결제**, **감사 페이지** 같은 스토어 관련 페이지는 삭제돼요. 그 밖의 웹사이트 페이지는 그대로 유지돼요. 스토어 페이지 하나를 직접 삭제하면 그 스토어에 속한 다른 스토어 페이지도 함께 삭제될 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 상품이 이커머스 스토어에 보이지 않아요.
**결제 > 상품**에서 해당 상품을 열고 **Include in Online Store**가 켜져 있는지 확인하세요.

### AI에게 문의가 스토어 설정을 전부 대신해 주나요?
아니요. **AI에게 문의**는 지원되는 스토어 설정 작업을 안내해 주지만, 새 도메인 만들기와 결제 제공업체 연결은 직접 설정해야 해요.

### 고객이 Pickup in Store를 선택하면 Shipping Details는 어떻게 되나요?
하이퍼클래스가 **Shipping Details** 섹션을 숨기고, 고객이 선택한 픽업 장소를 배송 주소로 사용해요.

### 스토어 주문과 결제 내역은 어디에서 확인하나요?
주문 기록은 **결제 > 주문**에서, 결제 내역은 **결제 > 거래 내역**에서 확인하세요.

### 한 서브 계정에 스토어를 두 개 이상 만들 수 있나요?
네. 같은 서브 계정 안에 스토어를 여러 개 만들 수 있어요.

### 스토어를 삭제하면 웹사이트 전체가 삭제되나요?
아니요. 스토어를 삭제하면 스토어 관련 페이지만 삭제돼요. 홈이나 소개 같은 다른 웹사이트 페이지는 그대로 남아요.
