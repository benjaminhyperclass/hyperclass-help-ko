# 이커머스 스토어에서 상품 라벨과 리본 사용하기

상품에 라벨이나 리본을 달아 상품 목록과 상품 상세 페이지에서 눈에 띄게 보여 줄 수 있어요. 라벨이 표시되는 기간도 정할 수 있어요.

[동영상](https://www.youtube.com/embed/ntwmTxLPqZE?&wmode=opaque)

## 이 기능은 무엇인가요

스토어 운영자는 상품에 라벨(리본)을 직접 꾸며서 달 수 있어요. 라벨을 달면 상품 목록 페이지와 상품 상세 페이지에서 해당 상품을 다른 상품과 구별해 보여 줄 수 있어요. 라벨에 타이머를 설정하면 정해 둔 시간이 지난 뒤 라벨이 사라져요.

## 사용 방법

1. 이커머스 스토어의 상품에 라벨을 설정하려면 **결제 > 상품 > Enable Product label**(상품 라벨 활성화)로 이동하세요.
2. 필요하면 라벨의 시작 날짜·시간과 종료 날짜·시간을 설정하세요. 두 값은 선택 사항이에요. 상품마다 원하는 기간으로 라벨을 따로 설정할 수 있어요.

## 참고 사항

- 시작과 종료 날짜·시간은 서브 계정 위치의 시간대를 기준으로 설정돼요.
- 종료 날짜·시간은 시작 날짜·시간보다 늦어야 해요. 또 라벨이 표시되려면 종료 날짜·시간이 현재 날짜·시간보다 늦어야 해요.
