# 이커머스 스토어의 지역별 통화 형식 설정

스토어를 방문한 사람의 지역과 페이지 언어에 맞춰 가격 표시 형식을 자동으로 바꾸는 기능이에요. 이 문서에서 기능의 작동 방식, 켜는 방법, 스토어 어디에 적용되는지 알아봐요. 천 단위 구분 기호, 소수점, 통화 기호 위치가 자동으로 조정되어 방문자에게 익숙한 방식으로 가격이 보여요.

## 지역별 통화 형식이란?

방문자의 위치와 페이지 언어에 따라 하이퍼클래스 스토어의 가격 표시 방식을 자동으로 맞춰 주는 기능이에요. 숫자만 그대로 보여 주는 대신, 지역마다 쓰는 천 단위 구분 기호, 소수점 방식, 통화 기호 위치를 따라요. 방문자가 가격을 바로 이해할 수 있어서 둘러보고 결제하는 과정이 한결 편해져요.

## 이 기능의 장점

- 읽기 쉬워요: 익숙한 형식으로 가격이 보여서 한눈에 이해할 수 있어요.
- 신뢰도가 높아져요: 지역에 맞는 형식을 쓰면 더 전문적이고 현지화된 쇼핑 경험을 줄 수 있어요.
- 해외 방문자도 지원해요: 스토어를 여러 버전으로 만들지 않아도 해외 방문자에게 맞출 수 있어요.
- 자동으로 적용돼요: 구분 기호, 소수점, 기호 위치를 직접 입력하지 않아도 돼요.
- 일관된 경험을 줘요: 상품 페이지, 장바구니, 결제 화면에 모두 똑같이 적용돼요.

## 지역은 어떻게 감지하나요?

여러 정보를 조합해서 방문자에게 가장 알맞은 표시 형식을 정해요.

- 페이지 언어 우선: **SEO & AI Search Optimization**(SEO 및 AI 검색 최적화) 설정에서 고른 페이지 언어가 기본 형식에 영향을 줘요.
- 방문자 위치: 방문자의 지리적 위치에 따라 형식을 한 번 더 조정해요.
- 정보가 없을 때: 지역 정보를 확인할 수 없으면 en-US 형식을 기본으로 써요.
- 형식만 바뀌어요: 통화가 환산되지는 않고, 표시 형식만 달라져요.

## 적용되는 곳

스토어의 주요 구성 요소 전체에 똑같이 적용돼요.

- 상품 목록 페이지(PLP)
- 상품 상세 페이지(PDP)
- 장바구니
- 결제 화면
- 스토어의 모든 가격 표시 요소

## 설정 방법

방문자에게 가격이 알맞게 보이도록, 아래 순서대로 설정하세요.

1. 하이퍼클래스 계정에서 **사이트 > 스토어**로 이동하세요.
2. 스토어를 열고 **Store Settings**(스토어 설정)로 이동하세요.
3. **Locale-Based Currency Formatting**(지역 기반 통화 형식) 토글을 찾으세요.
4. 토글을 켜세요.
5. **저장**을 클릭하세요.

   ![스토어 설정에서 지역 기반 통화 형식 토글을 켜고 저장하는 화면](https://jumpshare.com/share/hYwX7aChZzHGoPqxEHCK+/GIF+Recording+2026-05-04+at+21.23.12.gif)
6. **빌더**에서 스토어를 여세요.
7. **SEO & AI Search Optimization**으로 이동하세요.
8. 알맞은 **Page Language**(페이지 언어)를 선택하세요.
9. 변경 사항을 저장하고 **게시**를 클릭하세요.

   ![빌더에서 페이지 언어를 설정하고 게시하는 화면](https://jumpshare.com/share/Hgy8aYLLGOynE8omQIJM+/GIF+Recording+2026-05-05+at+00.38.57.gif)

## 알아 두면 좋은 점

해외 고객을 대상으로 스토어를 운영한다면 아래 내용을 미리 알아 두세요.

- 통화는 환산되지 않아요. 가격은 같은 통화로 유지되고 표시 형식만 바뀌어요.
- 형식은 방문자의 위치를 기준으로 정해져요. 스토어가 있는 곳은 기준이 아니에요.
- 페이지 언어가 중요해요. 페이지 언어를 잘못 설정하면 예상과 다른 형식으로 보일 수 있어요.
- 지역 정보를 확인할 수 없으면 기본 형식인 en-US가 적용돼요.

## 자주 묻는 질문

### 이 기능을 켜면 통화가 자동으로 환산되나요?
아니요. 통화가 표시되는 방식만 바뀌고, 금액 자체는 바뀌지 않아요.

### 사용자마다 가격이 다르게 보이는 이유가 뭔가요?
방문자의 위치와 페이지 언어에 따라 표시 형식이 조정되기 때문이에요.

### 지역을 감지하지 못하면 어떻게 되나요?
en-US 형식이 기본으로 적용돼요.

### 지역마다 스토어를 따로 만들어야 하나요?
아니요. 스토어 하나로 여러 지역의 방문자에게 맞는 가격 형식을 보여 줄 수 있어요.

### 언어 설정은 어디에서 하나요?
**빌더**의 **SEO & AI Search Optimization**에서 설정해요.
