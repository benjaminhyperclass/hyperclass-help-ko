# 스토어 결제 페이지 사용자 지정

하이퍼클래스 스토어의 결제 페이지에서 입력란 표시 여부를 정하고, 결제 정보를 관리하고, 고객이 결제 전에 이용약관이나 개인정보처리방침에 동의하도록 설정하는 방법을 안내해요.

## 결제 페이지 사용자 지정이란

결제 페이지 사용자 지정을 쓰면 스토어 결제 화면에 보일 입력란을 직접 고를 수 있어요. 선택사항인 메모 입력란을 추가하고, 국가 선택 방식을 정하고, 주소 자동완성을 켤 수도 있어요. 이렇게 하면 구매 과정이 간단해지고, 주문 처리에 꼭 필요한 정보만 받을 수 있어요.

## 결제 페이지 사용자 지정의 장점

- 고객이 꼭 입력해야 하는 항목만 보여 주면 결제가 빨라져요.
- 주소 자동완성을 쓰면 오타나 빠진 주소가 줄어 정보가 더 정확해져요.
- 고객이 국가를 직접 고르게 하거나, 결제 가능한 국가를 특정 국가로 제한할 수 있어요.
- **추가 메모** 입력란으로 주문별 요청 사항을 받을 수 있어요.
- 고객이 결제를 마치기 전에 약관 문구에 동의하도록 할 수 있어요.

## 결제 페이지 사용자 지정 절차

1. 서브 계정에 로그인하세요.
2. **사이트 > 스토어**로 이동하세요.

   ![사이트 메뉴의 스토어 화면](https://jumpshare.com/share/EYwgplptOxKpWQM70lD3+/Screen+Shot+2025-12-30+at+7.22.45+PM.png)
3. 새 스토어를 만들거나 기존 스토어를 편집하세요.

   ![스토어를 만들거나 편집하는 화면](https://jumpshare.com/share/hEPBTJsRQRF0IH7CH9Ig+/Screen+Shot+2025-12-30+at+7.25.54+PM.png)
4. **결제 페이지** 편집기를 열고 **결제** 요소를 선택하세요.

   ![결제 요소를 선택하는 화면](https://jumpshare.com/share/JHDi2iOkZ9QrObvlDOGd+/GIF+Recording+2025-12-30+at+8.45.36+PM.gif)
5. **타이포그래피**를 설정하세요.
   - **Headline font**(헤드라인 글꼴)
   - **Card summary font**(카드 요약 글꼴)
   - **Headline font size**(헤드라인 글꼴 크기)
   - **Card summary font size**(카드 요약 글꼴 크기)
   - **Headline font weight**(헤드라인 글꼴 두께)
   - **Card summary font weight**(카드 요약 글꼴 두께)

   ![타이포그래피 설정 화면](https://jumpshare.com/share/odTNgGaGIi25ujApONxK+/Screen+Shot+2025-12-30+at+8.48.48+PM.png)
6. **Contact options**(연락처 옵션)를 설정하세요.
   - **고정 연락처** (켬/끔)
   - **New contact on every purchase**(구매할 때마다 새 연락처 생성) (켬/끔)
   - **Validate disposable email**(일회용 이메일 검증) (켬/끔)

   ![연락처 옵션 설정 화면](https://jumpshare.com/share/cIyt4A8Mujfu9kLALiHb+/Screen+Shot+2025-12-30+at+8.53.09+PM.png)
7. **Button actions**(버튼 액션, Sale actions)에서 액션이 끝난 뒤 어떻게 할지 고르세요.
   - **Go to website URL**(웹사이트 URL로 이동)
   - **페이지로 이동**
   - **기본** (그대로 두기)

   ![버튼 액션 설정 화면](https://jumpshare.com/share/JQO5Jmd6uuhRhyJZw9Vm+/GIF+Recording+2025-12-30+at+9.03.53+PM.gif)
8. **Text actions**(텍스트 액션)에서 결제 페이지 각 섹션에 보이는 문구를 바꾸세요.
   - **연락처 세부정보** 섹션 문구에서는 다음을 바꿀 수 있어요.
     1. **headline**(제목)
     2. **email** labels(이메일 레이블)
   - **Shipping details**(배송 세부정보) 섹션 문구에서는 다음 제목과 레이블을 바꿀 수 있어요.
     1. **이름**
     2. **전화번호**
     3. **Search box**(검색창)
     4. **전체 주소**
     5. **국가**
     6. 이름을 바꾸고 싶은 그 밖의 배송 관련 제목
   - **Billing details**(청구 세부정보) 섹션 문구에서는 다음을 바꿀 수 있어요.
     1. **Billing details headline**(청구 세부정보 제목)
     2. **Checkbox text**(체크박스 텍스트, 관련 체크박스 레이블 포함)
   - **Payment section**(결제 섹션) 문구에서는 다음을 바꿀 수 있어요.
     1. **Payment label/name**(결제 레이블/이름)
     2. **Checkout button name**(결제 버튼 이름)
     3. **Footer text**(푸터 문구, 예: "100 secure and save payments" 같은 문구)
   - **Cart summary**(장바구니 요약) 섹션 문구에서는 다음을 바꿀 수 있어요.
     1. **Cart headline**(장바구니 제목)
     2. **Quantity text**(수량 텍스트)
     3. **Coupon headline text**(쿠폰 제목 텍스트)
     4. **Mobile view coupon code placeholder**(모바일 화면 쿠폰 코드 플레이스홀더)
     5. **Apply coupon button text**(쿠폰 적용 버튼 텍스트)
     6. **Sub total amount text**(소계 금액 텍스트)
     7. **Discount text**(할인 텍스트)
     8. **Remove coupon button text**(쿠폰 제거 버튼 텍스트)
     9. **Shipping heading text**(배송 제목 텍스트)
     10. **Total amount text**(총 금액 텍스트)

     ![텍스트 액션으로 섹션별 문구를 바꾸는 화면](https://jumpshare.com/share/r91noIG0QS0uhPzv4Aod+/GIF+Recording+2025-12-30+at+9.19.08+PM.gif)
9. **Form options**(폼 옵션)를 설정하세요.
   - **Full name validation**(전체 이름 검증) (켬/끔)
   - **Enable billing address**(청구 주소 활성화) 또는 **Disable billing address**(청구 주소 비활성화)
   - **배송**: **show shipping**(배송 표시)과 **hide shipping**(배송 숨기기) 중에서 고르세요.

     ![폼 옵션에서 배송 표시 여부를 고르는 화면](https://jumpshare.com/share/sZaPeNus6t50bgHf77cg+/Screen+Shot+2025-12-30+at+9.35.06+PM.png)
   - **주소 자동완성**(Google 기반)을 활성화하거나 비활성화하세요.
     1. 주소 자동완성은 이런 기능이에요.
        1. Google 기반의 실시간 주소 추천을 보여 줘요.
        2. 오류가 적고 더 매끄러운 결제 경험을 만들어 줘요.
        3. 에이전시는 맞춤 가격과 계정 반복/재구축(repeating/rebuilds)도 설정할 수 있어서, 새로운 수익원이 될 수 있어요.
     2. 자동완성이 지원하는 주소 입력란은 다음과 같아요.
        1. **주소**
        2. **도시**
        3. **국가**
        4. **주/도**
        5. **우편번호**
     3. 요금은 다음과 같아요.
        - 검색 요청(고객이 입력을 시작할 때 발생) 1회당 $0.002972
        - API 호출(전체 주소 정보를 가져올 때) 1회당 $0.00525

        ![주소 자동완성 요금 안내 화면](https://jumpshare.com/share/hOHMYarhp03EdK3vTEPp+/Screen+Shot+2025-12-30+at+9.36.23+PM.png)
   - **우편번호**와 **국가** 표시를 활성화하거나 비활성화하세요. 이 설정은 결제 게이트웨이마다 달라요.
   - 결제 시 **추가 메모**를 활성화하거나 비활성화하세요.
     1. 켬: 고객이 추가 메모를 남길 수 있어요.
     2. 끔: 메모 입력란이 사라져요.

        메모를 켠 상태에서 고객이 결제 중 메모를 남기면, 그 메모는 포장 명세서의 Order Notes(주문 메모) 섹션에 나와요. 고객이 메모를 남기지 않으면 Order Notes 섹션은 보이지 않아요.

        ![결제 시 추가 메모 설정 화면](https://jumpshare.com/share/iap297BGhmZDvdQWg3eY+/Screen+Shot+2025-12-30+at+9.39.45+PM.png)
   - 다음 입력란을 **Mandatory**(필수), **선택사항**, **숨김** 중에서 정하세요.
     1. **전화번호**
     2. **주소**
     3. **국가** (국가/주 입력란을 숨기면 국가 선택 옵션이 나타나지 않아요.)
     4. **주/도**
     5. **도시**
     6. **우편번호**

     ![입력란별 필수, 선택사항, 숨김 설정 화면](https://jumpshare.com/share/0ZEb27zcQYVmwQRihDQg+/Screen+Shot+2025-12-30+at+9.53.22+PM.png)
   - **Country Selection at Checkout**(결제 시 국가 선택)을 설정하세요.

     이 기능으로 스토어 운영자는 결제 과정에서 배송 지역과 고객의 기본 위치를 관리할 수 있어요.
     - **Shipping Locations**(배송 지역)

       결제 시 배송할 수 있는 국가를 정해요.

       - **Ship to all locations**(모든 지역으로 배송): 모든 국가로 배송할 수 있어서 고객에게 글로벌 배송 옵션을 제공해요.
       - **Ship to specific countries**(특정 국가로 배송): 배송할 국가를 직접 골라요. 결제할 때 고른 국가만 선택할 수 있어요.

         ![배송 지역 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061623420/original/1wLZubq7RqHAWElbX2B8yTFq4GmdR9NAJQ.jpeg?1767112508)
     - **Default Customer Location**(고객 기본 위치)

       결제 시 고객의 위치를 어떻게 처리할지 정해요.

       - **No default location**(기본 위치 없음): 미리 선택된 국가가 없어요. 고객이 직접 위치를 골라야 해요.
       - **Geolocate**(위치 자동 감지): 고객의 IP 주소를 바탕으로 위치를 자동으로 감지해요.
       - **Show all countries**(모든 국가 표시): 선택할 수 있는 모든 국가를 보여 줘요.
       - **Ship to specific countries**를 켠 경우에는 고른 국가만 선택지로 보여요.
       - **Geolocate**를 쓰면 고객의 **IP 주소**를 바탕으로 위치가 자동으로 반영되어 더 편하게 결제할 수 있어요.

         ![고객 기본 위치 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155061623485/original/JDHs2wYKVTqCOW4P3BoH8SZxO_ryfiINSg.jpeg?1767112571)
   - **이용약관** 동의를 설정하세요.

     이용약관 설정을 쓰면 고객이 결제하기 전에 약관에 동의하도록 할 수 있어요.

     1. **결제** 요소를 선택하세요.
     2. 오른쪽 패널에서 **이용약관**까지 스크롤하세요.
     3. **Enable Terms and Conditions**(이용약관 활성화)를 켜세요.
     4. 체크박스 문구를 원하는 대로 바꾸세요.
     5. 필요하면 이용약관이나 **개인정보처리방침** 링크를 추가하세요. 개인정보처리방침 링크를 거는 방법은 [개인정보를 수집할 때 개인정보처리방침 링크 연결하기](../06-사이트/how-to-link-your-privacy-policy-when-collecting-personal-data.md)를 참고하세요.
     6. 스토어를 **저장 및 게시**하세요.

     이 설정을 켜면 다음과 같이 동작해요.

     - 동의 체크박스가 결제 버튼 앞에 나타나요.
     - 체크박스는 기본적으로 선택되지 않은 상태예요.
     - 고객은 체크박스를 선택해야 결제를 마칠 수 있어요.
     - 고객이 약관에 동의하지 않고 진행하려고 하면 입력란 옆에 안내 메시지가 나타나요.
     - 체크박스는 데스크톱과 모바일 결제 페이지에 모두 나타나요.

       ![결제 페이지에 표시되는 이용약관 동의 체크박스](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076280211/original/6rv4M514mLPisWC8d1RD2VxxQPHCTvJ8AQ.png?1784313080)
   - 쿠폰 코드를 **활성화** 또는 **비활성화**하세요.

     ![쿠폰 코드 활성화 설정 화면](https://jumpshare.com/share/IiQmi9cPhI5MCOQB2fyO+/Screen+Shot+2025-12-30+at+10.14.02+PM.png)
   - **Color options**(색상 옵션)로 브랜드 스타일을 설정하세요.
     1. **Headline text color**(헤드라인 텍스트 색상)
     2. **Card summary text color**(카드 요약 텍스트 색상)
     3. **배경 색상**
     4. **Payment button color**(결제 버튼 색상)
     5. **Payment button text color**(결제 버튼 텍스트 색상)
     6. **Subscription field text color**(구독 입력란 텍스트 색상)
     7. **Subscription field background color**(구독 입력란 배경 색상)

     ![색상 옵션 설정 화면](https://jumpshare.com/share/zgcrwrFQN3ynUVHoEu6W+/Screen+Shot+2025-12-30+at+10.15.16+PM.png)

## 자주 묻는 질문

### 결제 페이지에 국가 선택이 보이지 않아요.
**Shipping details**(배송 세부정보)에서 **국가**(또는 주/도/지역처럼 필수로 연결된 입력란)를 숨기면 국가 선택 옵션이 나타나지 않아요.

### 스토어 결제에 추가 요금이나 처리 요금을 붙이려면 어떻게 하나요?
자세한 안내는 '고객 결제에 처리 요금 또는 추가 요금 붙이기' 문서를 참고하세요.

### 결제 가능한 국가를 특정 국가로만 제한할 수 있나요?
네, 가능해요. 결제 설정의 **Country Selection**(국가 선택)에서 결제를 허용할 국가 목록을 고르고 저장하세요.

### "Ship to specific countries"에서 국가를 하나도 고르지 않으면 어떻게 되나요?
목록에서 고른 국가가 없으면 결제 시 모든 국가를 선택할 수 있어요.

### 결제 페이지의 Geolocate 기능은 어떤 역할을 하나요?
Geolocate는 고객의 IP 주소를 바탕으로 대략적인 위치를 감지해서, 국가를 더 편하게 선택할 수 있게 해 줘요.

### 어떤 입력란이 배송비 계산에 영향을 주나요?
일부 배송사는 **주소**, **도시**, **우편번호** 같은 정보로 배송비를 계산해요. 정확한 배송비가 필요하면 이 입력란을 **Mandatory**(필수)로 두세요.

### Shippo 같은 실시간 배송비 조회를 쓰려면 주소 입력란을 모두 받아야 하나요?
네. Shippo 같은 멀티 배송사 플랫폼을 쓰면, 고객이 필수 주소 입력란을 모두 입력해야 결제 화면에서 실시간 배송비를 조회할 수 있어요.

### 필수 입력란을 줄이면 결제가 더 빨라지나요?
필수 입력란 수를 줄이면 결제 과정이 간단해지고 전환율이 높아질 수 있어요.

### 고객이 이용약관에 동의하지 않으면 어떻게 되나요?
고객은 결제를 완료할 수 없어요. 고객이 동의 체크박스를 선택할 때까지 입력란 옆에 안내 메시지가 나타나요.

### 결제 중에 고객에게 인증 화면이 보이는 이유가 뭔가요?
지원되는 스토어 결제 제출은 Cloudflare Turnstile로 자동 보호돼요. 인증은 보통 백그라운드에서 진행되지만, 추가 인증이 필요하면 인증 화면이 보일 수 있어요. 고객은 인증을 완료하고, 이미 입력한 정보를 다시 입력하지 않고 결제를 이어 갈 수 있어요.
