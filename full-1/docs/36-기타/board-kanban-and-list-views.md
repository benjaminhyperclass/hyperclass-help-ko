# 보드(칸반 보기)와 목록 보기

**프로젝트 관리**(Project Management)에서는 같은 작업을 **칸반 보기**와 **목록 보기** 두 가지 방식으로 볼 수 있어요. 보기를 바꿔도 배치만 달라질 뿐, 작업 내용은 그대로예요. 이 문서에서는 두 보기의 특징과 전환 방법, 함께 쓰는 그룹화·필터 기능을 안내해요.

{% hint style="info" %}
프로젝트 관리는 $497 요금제를 쓰는 에이전시에서 사용할 수 있어요. 새 화면을 쓰려면 **에이전시 설정** 또는 **서브 계정 설정** > **실험실**에서 **프로젝트 관리**를 켜세요.
{% endhint %}

---

## 두 가지 보기

1. **칸반 보기**: 작업이 열별로 나뉜 카드로 보여요. 업무 흐름을 볼 때 좋아요. 각 작업이 어느 단계에 있는지, 어디에 일이 몰려 있는지 확인하고 작업을 앞으로 진행시킬 수 있어요.
2. **목록 보기**: 작업이 행으로 보여요. 세부 내용을 살펴볼 때 좋아요. 많은 작업을 한 번에 훑어보며 필드를 나란히 비교할 수 있어요.

어떤 보기를 선택해도 다른 사람의 화면에는 영향이 없고, 작업 데이터도 바뀌지 않아요.

---

## 칸반 보기 이해하기

**칸반 보기**에서는 각 열이 하나의 작업 상태예요. 열은 **Space**(스페이스)에 설정된 상태를 따라 나열돼요.

### 열 머리글

머리글에는 상태 이름과 그 열에 있는 작업 수가 표시돼요. 작업이 없는 열은 0으로, 작업이 많은 열은 그 숫자로 바로 알아볼 수 있어요.

### 카드

카드에는 작업 이름과 날짜(또는 기간)가 표시돼요. 하위 작업이 있으면 하위 작업 수도 함께 보여요. 카드는 요약 정보만 보여 주니, 전체 내용을 보려면 카드를 열어 보세요.

### 작업 진행시키기

카드를 다른 열로 끌어다 놓으면 그 작업의 상태가 바뀌어요.

### 열에서 바로 작업 추가하기

모든 열 맨 아래에 **+ Add Task**(+ 작업 추가)가 있어요. 여기서 작업을 만들면 그 열의 상태로 바로 시작돼서 한 단계를 줄일 수 있어요.

![칸반 보기에서 열별로 카드가 나열된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078464344/original/KY6C3zwFFKqq74JeLxnqZOeja2Gu5fxj_w.png?1786719297)

보드의 열이 화면에 다 들어가지 않으면 옆으로 스크롤해서 나머지 열을 확인하세요.

## 목록 보기 이해하기

**목록 보기**에서는 같은 작업이 카드 대신 행으로 보여요. 많은 작업을 한 번에 살펴볼 때 알맞아요. 예를 들어 리스트 전체에서 기한이 지난 작업을 확인하거나, 한 주를 계획하기 전에 우선순위를 비교할 수 있어요.

작업이 행으로, 항목이 열로 나열된 목록 보기 화면이에요.

![목록 보기에서 작업이 행으로 나열된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078464350/original/epp1uJZlsXjHN7kvy3s5pmOxMu9Cqlb__Q.png?1786719297)

열은 추가하거나 제거하고, 순서를 바꾸거나 크기를 조절할 수 있어요.

## 보기 전환하기

1. 메뉴에서 보기를 선택해요. 메뉴에는 **목록 보기**와 **칸반 보기** 두 가지가 있어요. 원하는 보기를 선택하세요.

   ![보기 선택 메뉴 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078464348/original/fhnQMIqpsX9wTY9Irbi4rTNt7YQJAqXlzw.png?1786719297)

2. 다시 바꾸고 싶으면 같은 메뉴에서 다른 보기를 선택하세요. 보기를 바꿔도 잃는 내용은 없어요.

## 작업 그룹화하기

도구 모음의 **그룹화 기준**에서 작업을 나누는 기준을 정해요. 선택할 수 있는 기준은 다음과 같아요.

<!-- 검토 필요: 원문 내용이 서로 다름 -->
1. **Status**(상태): 작업을 단계별로 묶어요. 칸반 보기의 기본값이고, 상태마다 열이 하나씩 만들어져요.
2. **Assignee**(담당자): 담당자별로 묶어요. 보드가 누가 어떤 일을 맡고 있는지 보여 주는 화면이 돼요. 작업이 많은 팀원이나 한 사람에게 일이 쏠린 경우를 찾을 때 유용해요.
3. **Status group**(상태 그룹): 작업을 상태 그룹(To do, Doing, Completed)별로 묶어요.
4. **우선순위**: 작업을 우선순위별로 묶어요.
5. **Custom field related**(커스텀 필드 관련): **커스텀 필드**에 정의한 여러 카테고리 아래로 작업을 묶어요.

아래는 우선순위별로 그룹화한 작업의 예시예요.

## 작업 필터링하기

필터는 도구 모음에서 **그룹화 기준** 옆에 칩 형태로 나타나요. **Assignee**, **Status**, **Due date**(마감일) 필터가 기본으로 보이고, 값은 **전체**로 설정돼 있어요. 창 오른쪽의 **필터** 버튼을 누르면 필터를 더 추가할 수 있어요.

필터는 화면에 보이는 작업만 좁혀 줄 뿐, 작업 자체는 바꾸지 않아요. 필터를 해제하면 모든 작업이 다시 보여요.

## 대량 액션

도구 모음에 있는 **대량 액션**을 쓰면 여러 작업을 하나씩 수정하지 않고 한 번에 바꿀 수 있어요.

첫 단계에서는 대량 액션 2가지만 지원해요.

1. **Move to**(이동): 선택한 작업의 상태를 원하는 상태로 옮겨요.
2. **삭제**: 선택한 작업을 한꺼번에 삭제해요.

대량 액션에 쓸 작업은 **목록 보기**에서 선택해요.

![목록 보기에서 작업을 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078464343/original/XMZg683HSagBj13h7p6CA88UgQHMfRO7vQ.png?1786719296)

여러 작업에 대량 액션을 실행하면 오른쪽 위의 **대량 액션** 버튼을 눌러 진행 상황을 확인할 수 있어요.

![대량 액션 진행 상황 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078464347/original/ocSsuz6cfLWwv-JGalI58xQNbG9FoOqS2w.png?1786719297)

## 자주 묻는 질문

### 보기는 몇 가지가 있나요?
**칸반 보기**와 **목록 보기**, 두 가지예요.

### 간트, 캘린더, 타임라인 보기도 있나요?
이번 릴리스에는 없어요. **View**(보기) 메뉴에는 **목록 보기**와 **칸반 보기**만 있어요.

### 보기를 바꾸면 작업이 바뀌나요?
아니요. 두 보기는 같은 작업을 보여 줘요. 보기를 바꾸면 배치만 달라져요.

### 제가 고른 보기가 팀원 화면에도 영향을 주나요?
아니요. 보기를 고르거나 필터를 적용해도 내 화면만 바뀌어요.

### 보드의 열 순서는 무엇으로 정해지나요?
**Space**에 설정된 상태와 각 상태가 속한 그룹으로 정해져요.

### 열 하나에 작업이 0개로 나와요.
**Space**에는 그 상태가 있지만, 지금 그 상태인 작업이 없다는 뜻이에요. 비어 있는 열도 그대로 표시되는 게 정상이고, 그 열로 작업을 끌어다 놓을 수도 있어요.

### 작업의 상태는 어떻게 바꾸나요?
**칸반 보기**에서 카드를 다른 열로 끌어다 놓으세요. 또는 작업을 열어서 **Status**(상태) 속성을 바꾸세요.
