# 이메일 빌더에서 테두리 색상·모서리 둥글기·두께 설정하기

하이퍼클래스 **이메일 빌더**에서 지원하는 섹션의 테두리 모양을 직접 바꿀 수 있어요. 섹션 설정에서 테두리 색상, 모서리 둥글기, 테두리 두께를 조정하면 별도 코드 없이 섹션의 경계를 뚜렷하게 나타낼 수 있어요. 이 문서에서는 **테두리 설정**을 여는 방법과 각 항목을 설정하는 방법을 안내해요.

## 테두리 설정이란?

**이메일 빌더**에서 지원하는 섹션의 테두리 모양을 바꾸는 기능이에요.

설정할 수 있는 항목은 테두리 색상, 모서리 둥글기, 테두리 두께예요. 이 항목들은 선택한 섹션의 **테두리 설정** 패널에서 찾을 수 있어요.

## 테두리 설정으로 할 수 있는 일

**테두리 설정**으로 지원하는 섹션의 윤곽을 직접 정할 수 있어요.

- **테두리 색상**: 섹션 테두리에 쓸 색을 고릅니다.
- **모서리 둥글기**: 섹션 모서리를 얼마나 둥글게 또는 각지게 보이게 할지 정합니다.
- **Border Thickness**(테두리 두께): 섹션 테두리가 눈에 보이는 굵기를 조정합니다.
- 빌더 안에서 바로 편집: 이메일을 편집하면서 테두리 변경 내용을 바로 확인할 수 있어요.
- 섹션별 적용: 선택한 이메일 섹션에 테두리 스타일을 바로 적용할 수 있어요.

## 테두리 설정 방법

스타일을 바꿀 이메일 섹션을 선택한 뒤, 해당 섹션의 **테두리 설정**에서 테두리 항목을 설정해요.

### 1단계: 이메일 빌더 열기

편집하려는 이메일 캠페인이나 템플릿이 있는 서브 계정에서 시작하세요.

1. 하이퍼클래스의 **서브 계정**에서 **마케팅**으로 이동하세요.
2. **이메일**을 선택하세요.
3. **캠페인** 또는 **템플릿**을 여세요.
4. 새 이메일을 만들거나 기존 이메일을 여세요.
5. 이메일을 **디자인 에디터**에서 여세요.

![이메일을 디자인 에디터에서 연 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082941822/original/8ty5p9i0v0DSF-B6566_JaqbGV-VLSF1eg.png?1791545240)

### 2단계: 이메일 섹션 선택하기

섹션을 선택하면 해당 섹션의 스타일 설정이 나타나요.

1. 꾸미려는 섹션을 선택하세요.
2. **Edit section**(섹션 편집) 패널을 찾으세요.
3. **테두리 설정**을 펼치세요.

## 테두리 색상 바꾸기

**테두리 색상**은 선택한 섹션의 테두리에 쓰이는 색을 정해요.

1. **테두리 설정**을 펼치세요.
2. **테두리 색상** 항목을 찾으세요.
3. 사용할 색상을 선택하세요.
4. **이메일 빌더** 화면에서 바로 결과를 확인하세요.

![테두리 색상을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082942060/original/P46cuUlK2uNBrP8dOQrYYNItzDgPH7FBEA.png?1791545388)

## 모서리 둥글기 조정하기

**모서리 둥글기**는 섹션 모서리가 얼마나 둥글게 또는 각지게 보일지 정해요.

1. **테두리 설정**을 여세요.
2. **모서리 둥글기** 항목을 찾으세요.
3. 제공되는 조절 항목으로 둥글기를 조정하세요.
4. **이메일 빌더** 화면에서 바뀐 모서리를 확인하세요.

![모서리 둥글기를 조정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082942170/original/NNyLXA9WSKPjlXMI4oYECsaybFQ97Nc2cw.png?1791545464)

## 테두리 두께 조정하기

**Border Thickness**(테두리 두께)는 섹션 테두리가 눈에 보이는 굵기를 정해요.

1. **테두리 설정**을 여세요.
2. **Border Thickness** 항목을 찾으세요.
3. 제공되는 조절 항목으로 테두리 굵기를 조정하세요.
4. 바뀐 섹션 테두리를 확인하세요.

![테두리 두께를 조정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082942398/original/ZJFazmmRXVheMVUCikJ_YfGkGnP4vgv1vA.png?1791545548)

## 테두리 변경 내용 미리 보고 테스트하기

캠페인이나 템플릿을 사용하기 전에 테두리 스타일을 확인해서 최종 레이아웃이 의도대로 나오는지 살펴보세요.

1. **이메일 빌더** 화면에서 테두리 변경 내용을 확인하세요.
2. 제공되는 데스크톱·모바일 보기로 레이아웃을 확인하세요.
3. 최종 테스트나 발송 전에 이메일을 저장하세요.
4. 실제 받은 편지함에서 어떻게 보이는지 확인하려면 **테스트 이메일 보내기**를 사용하세요.

이메일 레이아웃은 반응형으로 설계되어 있지만, 이메일 클라이언트에 따라 표시 방식이 다를 수 있어요. 최종 디자인을 확인할 때는 미리 보고 테스트해 보세요.

## 자주 묻는 질문

### 이메일 빌더에서 테두리 설정은 어디에 있나요?
지원하는 이메일 섹션을 선택한 뒤, **Edit section**(섹션 편집) 패널에서 **테두리 설정**을 펼치세요.

### 테두리 설정에서 무엇을 바꿀 수 있나요?
테두리 색상, 모서리 둥글기, 테두리 두께를 조정할 수 있어요.

### 이메일 빌더의 모든 요소에서 테두리 설정을 쓸 수 있나요?
이 문서는 지원하는 이메일 섹션에서 쓸 수 있는 **테두리 설정**을 다뤄요. 다른 **빌더 요소**에는 각각 별도의 스타일 설정이 있을 수 있어요.

### 이메일을 보내기 전에 테두리 변경 내용을 미리 볼 수 있나요?
네. **이메일 빌더**에서 변경 내용을 확인하고, 발송 전에 데스크톱·모바일 보기로도 살펴보세요.

### 테두리를 바꾼 뒤에 테스트 이메일을 보내야 하나요?
실제 받은 편지함이나 이메일 클라이언트에서 디자인이 어떻게 보이는지 확인해야 할 때 **테스트 이메일 보내기**가 도움이 돼요.
