# 구독 취소 흐름 설정하기 — 1단계, 2단계, 동적

구독 취소 흐름은 연락처가 이메일의 수신 거부 링크를 눌렀을 때 어떻게 처리할지 정하는 설정이에요. 1단계(One Step), 2단계(Two Step), 동적 흐름 중에서 고를 수 있어요. 이 문서에서는 세 흐름의 차이, 계정 단위로 설정하는 방법, 동적 흐름이 확인 단계를 요구하는 기준을 알려 드려요.

## 구독 취소 흐름이란?

구독 취소 흐름은 수신자가 수신 거부 링크를 누른 뒤 일어나는 일을 정해요. 선택한 흐름에 따라 연락처가 바로 구독 취소되거나, 확인 단계를 거쳐야 해요.

### 구독 취소 흐름 종류

흐름마다 구독 취소가 완료되는 시점과 확인 단계의 필요 여부가 달라요.

#### 1단계 흐름 (One Step)

연락처가 수신 거부 링크를 누르면 바로 구독 취소돼요. 그 뒤에 원하면 피드백을 남길 수 있어요.

#### 2단계 흐름 (Two Step)

연락처가 확인 단계를 완료해야 구독 취소가 확정돼요.

#### 동적 흐름 (Dynamic)

동적 흐름은 1단계와 2단계 방식을 함께 쓰는 흐름이에요. 기본적으로는 바로 구독 취소돼요. 다만 아래 두 경우에는 확인 단계가 필요해요.

- 이메일이 전달된 지 5분 이내에 수신 거부 링크를 누른 경우
- 연락처 레코드가 생성된 지 1시간이 안 된 경우

## 구독 취소 흐름 설정하는 방법

구독 취소 흐름은 계정 단위로 설정해요. 그래서 선택한 방식은 설정을 바꾸기 전까지 그 계정에서 보내는 모든 이메일에 적용돼요.

1. **마케팅 > 이메일 > 캠페인**으로 이동하세요.
2. **설정** 톱니바퀴 아이콘을 클릭하세요.

   ![설정 톱니바퀴 아이콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082338622/original/DJehf70mLtEzzRJMyXHO4eOBj252ZxDTmg.png?1790912184)
3. **구독 취소**를 선택하세요.
4. **One Step**(1단계), **Two Step**(2단계), **동적** 중 하나를 선택하세요.
5. **미리보기**를 눌러 수신자가 보게 될 구독 취소 화면을 확인하세요.
6. **저장**을 클릭하세요.

   ![구독 취소 흐름 선택 후 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082338637/original/rwoKthSGCA2Mk6WO6QqxSf-qFlf9SXC3cA.png?1790912317)

## 수신 거부 링크 관리하기

구독 취소 흐름은 연락처가 수신 거부 링크를 누른 뒤의 처리 방식만 정해요. 링크를 어디에 넣을지와 맞춤 구독 취소 화면은 따로 관리해요.

- 하이퍼클래스 기본 수신 거부 링크는 [하이퍼클래스 이메일의 기본 수신 거부 링크 관리](../../09-이메일/managing-default-unsubscribe-links-in-lc-email.md)를 참고하세요.
- 브랜드에 맞춘 구독 취소 화면을 만들려면 [맞춤 수신 거부 링크 만들기 단계별 가이드](../../05-기회-파이프라인/기타/step-by-step-guide-creating-opportunities.md)를 참고하세요.

## 자주 묻는 질문

### 구독 취소 흐름을 바꾸면 이미 구독을 취소한 연락처에도 영향이 있나요?
아니요. 기존 구독 취소 데이터는 바뀌지 않아요. 바꾼 흐름은 설정을 변경한 뒤에 보내는 이메일부터 적용돼요.

### 2단계 흐름에서 연락처가 확인하지 않고 나가면 어떻게 되나요?
연락처가 확인 단계를 마칠 때까지 구독 취소는 완료되지 않아요.

### 동적 흐름은 어떻게 테스트하나요?
테스트용 연락처에 이메일을 보낸 뒤, 전달된 지 5분 이내에 수신 거부 링크를 클릭해 보세요. 또는 생성된 지 1시간이 안 된 연락처로 테스트해도 돼요. 두 경우 모두 동적 흐름에서는 바로 구독 취소되지 않고 확인 단계가 나와야 해요.

### 선택한 흐름이 계정의 모든 이메일에 적용되나요?
네. 구독 취소 흐름은 계정 단위 설정이라서 직접 바꾸기 전까지 계속 적용돼요.

### 구독을 취소한 연락처가 다시 구독할 수 있나요?
네. 구독을 취소한 뒤 나오는 피드백 설문에서 **Unsubscribed by mistake, subscribe again**(실수로 구독 취소했어요, 다시 구독)을 선택하고 폼을 제출하면 돼요. 그러면 하이퍼클래스가 해당 연락처의 이메일 구독 상태를 복원해요.
