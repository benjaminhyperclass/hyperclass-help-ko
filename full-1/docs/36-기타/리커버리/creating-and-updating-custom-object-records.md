# 사용자 지정 객체 레코드 만들기와 업데이트

반려동물, 자동차 같은 사용자 지정 객체를 관리할 때 레코드를 만들고, 수정하고, 삭제하고, 가져오는 방법을 안내해요. 필요한 기능의 단계를 순서대로 따라 하세요.

## 새 사용자 지정 객체 레코드 만들기

![새 레코드 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035098979/original/CpnSpUFrXsTM17wkj2AjFgfRCy-w2U6kHw.png?1729514530)

1. 해당 사용자 지정 객체를 엽니다.

   - 왼쪽 메뉴에서 사용자 지정 객체 유형을 선택하세요(예: 반려동물, 자동차).
2. 새 레코드를 추가합니다.

   - 화면 오른쪽 위의 **추가** 버튼을 클릭하세요(예: "반려동물 추가").
3. 필수 항목을 입력합니다.

   - 나타나는 폼에서 해당 객체의 기본 필드 값을 입력하세요.

   ![기본 필드를 입력하는 폼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035098877/original/Mw-N7ZvPcqPCJ6HmfNwjKVFzghxghKg8Ng.png?1729514470)
4. 레코드를 저장합니다.

   - 필수 정보를 모두 입력했으면 **저장**을 클릭하세요.
   - 폼을 닫지 않고 레코드를 이어서 만들려면 **Save and Add Another**(저장 후 다른 레코드 추가)를 선택하세요.

{% hint style="info" %}
사용자 지정 객체 레코드를 만들 때는 기본 필드 값만 입력할 수 있어요.
{% endhint %}

## 기존 사용자 지정 객체 레코드 수정하기

![레코드 수정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035098927/original/cT6kEhWA5_G9IM3jlrqLwDkLbLdcpVKxRg.png?1729514489)

1. 수정할 레코드를 엽니다.

   - 사용자 지정 객체 목록에서 수정할 레코드를 찾으세요.
   - 레코드 이름을 클릭하면 상세 정보가 열려요.
2. 필요한 필드를 편집합니다.

   - **편집** 버튼을 클릭하세요.
   - 텍스트, 숫자, 드롭다운 등 바꾸려는 필드의 값을 수정하세요.
3. 변경 내용을 저장합니다.

   - 수정을 마쳤으면 **저장**을 클릭해 변경 내용을 적용하세요.
   - 저장하지 않으려면 **취소**를 클릭하세요.

## 관련 오브젝트 관리하기

![관련 오브젝트 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035098973/original/upM-aGA3vO9a6A1BE9cU6A8grLZ2PArEgg.png?1729514517)

연결에 대한 자세한 내용은 **연결에 대해 자세히 알아보기**를 참고하세요.

일부 사용자 지정 객체에는 연락처, 상품, 집 같은 다른 레코드를 연결할 수 있어요. 연결은 아래 순서로 관리해요.

1. **Related Objects**(관련 오브젝트) 섹션으로 이동합니다.

   - 객체 레코드를 열고 **Related Objects** 섹션을 찾으세요.
   - 연결하려는 객체(예: 연락처, 상품) 옆의 **추가**를 클릭하세요.
2. 새 레코드를 연결합니다.

   - 연결할 레코드(예: 연락처)를 검색한 뒤 **Associate**(연결)를 클릭하면 사용자 지정 객체에 연결돼요.

## 사용자 지정 객체 레코드 삭제하기

![레코드 삭제 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155035098951/original/lOMNqeNc5GsQzhD_5D7guIjDsgxdq8Cfpg.png?1729514504)

1. 삭제할 레코드를 엽니다.

   - 삭제할 레코드를 찾아 여세요.
2. 점 세 개 메뉴를 클릭합니다.

   - 레코드 상세 화면의 오른쪽 위에 있는 점 세 개 메뉴를 클릭하세요.
3. 삭제 항목을 선택합니다.

   - 드롭다운에서 **Delete Record**(레코드 삭제)를 클릭하면 레코드가 영구적으로 삭제돼요.
   - 이어서 나타나는 확인 창에서 삭제를 확인하세요.

{% hint style="warning" %}
사용자 지정 객체 레코드 삭제는 되돌릴 수 없어요. 한번 삭제한 레코드는 복원할 수 없어요.
{% endhint %}

## 사용자 지정 객체 레코드 가져오기

CSV 파일로 사용자 지정 객체 레코드를 가져오려면 아래 순서를 따르세요.

1. 서브 계정에서 **사용자 지정 객체**를 열고, 레코드를 가져올 사용자 지정 객체를 선택하세요.

   ![사용자 지정 객체 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065774/original/rURyE1iwWflD_PUpiaQse66Y64S2cOB6Pg.png?1772528385)
2. 오른쪽 위의 **가져오기**를 클릭하세요.

   ![가져오기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065600/original/UIMsXatm_JyFA7sfVL9VwolmksI0EKlQgQ.png?1772528322)
3. **오브젝트 선택**에서 가져올 대상을 선택하세요.

   ![오브젝트 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065232/original/zaZPN74OlyQ5g-HV8ifGUAEBsN0PLYQ4Gw.png?1772528144)
4. 가져오기 방식을 선택하세요: **만들기** & **업데이트**.

   ![가져오기 방식 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065429/original/5fGsoLWs8irXuFFaDil3tdUvPgkeKfSHww.png?1772528241)
5. **dedupe unique field**(중복 확인용 고유 필드)를 선택하라는 안내가 나오면 선택하세요. 고유 필드를 여러 개 매핑했을 때만 나타나요.

   ![중복 확인용 고유 필드 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066065098/original/T8NBcPtgyGTdyLgLJrTj_5Tu5A2vD4Yw8w.png?1772528085)
6. 필드를 매핑하세요.

   - **기본**/**필수 필드**를 먼저 매핑하세요.
   - 그다음 나머지 필드를 매핑하세요. 필요하면 **소유자**와 **팔로워**도 매핑할 수 있어요.

     ![필드 매핑 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066064856/original/KKUgprH5g-oxMfptQen1ATJ6REsMcsS47w.jpeg?1772527939)
7. 업데이트 가져오기에서 빈 값도 적용해야 한다면 **빈 값 업데이트**를 켜세요. 기본/필수 필드는 이 옵션에서 계속 제외돼요.

   ![빈 값 업데이트 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066066159/original/ehIpY0AMaOwb4bcZe_gW6Ydf9-QeB7ohbg.png?1772528616)
8. **가져오기 시작**을 클릭하세요.
