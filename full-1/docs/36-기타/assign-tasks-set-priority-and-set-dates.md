# 작업 담당자, 우선순위, 날짜 지정하기

작업에 담당자, 우선순위, 날짜를 지정하면 팀이 바로 일할 수 있는 목록이 돼요. 이 문서에서는 세 가지 설정 방법과, 여러 사람이 한 작업을 함께 할 때 담당자를 나누는 방법을 안내해요.

{% hint style="info" %}
**프로젝트 관리**는 이제 $497 요금제를 쓰는 에이전시에서 사용할 수 있어요. 사용하려면 에이전시 **설정** 또는 **서브 계정 설정** > **실험실**로 이동해서 **프로젝트 관리**를 켜세요.
{% endhint %}

## 세 가지 설정이 중요한 이유

이름만 있는 작업은 해야 할 일이 있다는 것만 알려 줘요. 누가 하는지, 중요한지, 언제까지인지는 알 수 없어요. **담당자**, **우선순위**, **날짜**를 지정하면 보드를 한눈에 확인할 수 있어요. 세 가지 모두 작업을 만들 때 바로 지정해도 되고, 나중에 추가해도 돼요.

## 작업 담당자 지정하기

**담당자**는 작업을 책임지는 사람을 기록하는 항목이에요. 한 명만 선택할 수 있어서, 작업 하나에 담당자는 한 명이에요. 담당자 선택 목록에서 담당자를 비워 두는 옵션도 고를 수 있어요. 이 경우 작업은 담당자 없이 남아요.

{% hint style="info" %}
현재는 작업 하나에 담당자를 한 명만 지정할 수 있어요. 여러 담당자 지원은 이후 업데이트에서 추가될 예정이에요.
{% endhint %}

작업에서 담당자 선택 목록을 열어 멤버 목록이 보이는 화면

![작업의 담당자 선택 목록에 멤버가 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078498291/original/tSv35k6RBDpKD1V9TOOrG3QN1cFkv3PAqQ.png?1786779167)

선택 목록에는 스페이스(Space)에 접근할 수 있는 사람만 나와요. 찾는 사람이 보이지 않으면 그 사람이 스페이스에 공유되어 있는지 확인하세요.

## 작업 담당자 지정 방법

### 방법 1 - 작업을 만들 때

작업을 만드는 입력란에 **담당자 추가**가 있어요. 담당자가 없는 작업은 아무도 챙기지 않게 되니, 만들 때 바로 지정하는 것이 좋아요.

### 방법 2 - 이미 만든 작업에서

1. 작업 카드를 클릭해서 상세 패널을 여세요.
2. **담당자** 항목을 찾으세요.
3. **담당자**를 클릭하고 목록에서 사람을 선택하세요.
4. 변경 사항을 저장하세요.

## 여러 사람이 나눠서 작업하기

작업 하나에는 담당자를 한 명만 지정할 수 있어요. 그래서 여러 사람이 일을 나눠 할 때는 하위 작업을 활용해요. 상위 작업은 전체 결과물로 두고, 사람마다 맡은 부분을 하위 작업으로 추가하세요.

예를 들어 '9월 뉴스레터 발송' 작업에 문구 작성, 헤더 디자인, 발송 예약이라는 하위 작업을 만들고 각각 다른 사람을 지정할 수 있어요. 상위 작업은 하나로 관리하면서 단계별 담당자도 분명해져요.

## 우선순위 설정하기

**우선순위**는 작업이 얼마나 급한지 나타내요. 네 단계가 있어요.

1. **Urgent**(긴급): 지금 바로 주의 필요. 다른 작업보다 먼저 처리해야 해요.
2. **High**(높음): 중요해서 곧 시작해야 하는 작업이에요.
3. **Normal**(보통): 평소 순서대로 진행하는 일반 작업이에요.
4. **Low**(낮음): 미뤄도 되거나, 여유가 있을 때 하면 되는 작업이에요.

우선순위를 지정하지 않고 비워 둘 수도 있어요. 일상적인 작업에는 비워 둬도 괜찮아요.

{% hint style="info" %}
우선순위는 아껴서 써야 도움이 돼요. 보드의 작업 대부분이 Urgent라면 이 항목은 아무 정보도 주지 못해요.
{% endhint %}

우선순위 선택 목록

![우선순위 선택 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078498290/original/PLkzpzWnNIy0O47yyEhfA2RxfcoTC6FFmQ.png?1786779167)

작업을 만들 때 설정하려면 입력란의 **우선순위**를 사용하세요. 나중에 설정하려면 작업을 열고 **우선순위** 항목에서 단계를 고른 다음 저장하세요.

## 날짜 설정하기

**날짜** 항목에는 날짜 하나를 입력해도 되고, 기간을 입력해도 돼요. 마감일만 기록할 수도 있고, 시작부터 끝까지의 기간을 기록할 수도 있어요. 날짜 옆에는 표시 기준 시간대가 함께 나와요. 팀이 여러 지역에서 일할 때 도움이 돼요.

특정 날짜에 하거나 그날까지 끝내야 하는 작업은 날짜 하나로 지정하세요. 2주간 진행하는 개발처럼 일정 기간이 걸리는 작업은 기간으로 지정하세요. 보드의 카드에는 지정한 날짜나 기간이 그대로 표시돼요.

작업에서 날짜 항목을 열어 기간을 선택하고 시간대가 표시된 화면

![작업의 날짜 항목에서 기간을 선택하고 시간대가 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078498293/original/ErHsmrWAzFgQunXzZi0mmuOjLoSlK7_LTg.png?1786779167)

작업을 만들 때 날짜를 설정하려면 입력란의 **날짜 선택**을 사용하세요. 나중에 설정하려면 아래 순서를 따르세요.

1. 작업을 여세요.
2. **날짜** 항목을 클릭하세요.
3. 날짜 하나를 고르거나, 시작일과 종료일을 골라 기간으로 지정하세요.
4. 날짜 옆에 표시된 시간대를 확인하세요.
5. 변경 사항을 저장하세요.

## 자주 묻는 질문

### 작업 하나에 담당자를 여러 명 지정할 수 있나요?

현재 버전에서는 안 돼요. 작업 하나에 담당자는 한 명이에요. 여러 사람이 나눠서 일할 때는 하위 작업을 사용하세요.

### 담당자 없이 작업을 둘 수 있나요?

네, 가능해요. 담당자 선택 목록에 담당자를 비우는 옵션이 있어요. 다만 담당자가 없으면 책임지는 사람이 없으니, 잠깐만 비워 두는 것이 좋아요.

### 담당자 목록에 동료가 보이지 않아요.

선택 목록에는 스페이스에 접근할 수 있는 사람만 나와요. 그 동료에게 스페이스가 공유되어 있는지 확인하세요.

### 담당자를 지정하면 그 사람에게 알림이 가나요?

네, 작업을 지정하면 해당 담당자에게 알림이 가요.

### 우선순위에는 어떤 단계가 있나요?

Low, Normal, High, Urgent가 있어요. 우선순위를 지정하지 않고 비워 둘 수도 있어요.

### 우선순위 단계를 직접 만들 수 있나요?

아니요. 네 단계는 고정되어 있어요. 긴급도를 다른 기준으로도 나누고 싶다면 스페이스에 커스텀 필드를 추가하는 방법이 좋아요.

### 같은 작업에 시작일과 마감일을 둘 다 지정할 수 있나요?

네, 가능해요. **날짜** 항목에서 기간을 지정하면 돼요.

### 날짜는 어느 시간대 기준으로 표시되나요?

작업의 날짜 옆에 표시되는 시간대는 서브 계정의 시간대를 따라요.
