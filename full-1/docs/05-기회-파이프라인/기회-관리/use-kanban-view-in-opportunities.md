# 기회 관리에서 칸반 보기 사용하기

**기회 관리**(Opportunities)의 **칸반 보기**에서는 파이프라인 단계별로 딜을 한눈에 볼 수 있어요. 단계를 접거나 열고, 열 너비를 조절하고, 중요한 값을 기준으로 정렬하는 방법을 안내해요. 일부 레이아웃 설정은 브라우저에 저장되기 때문에, 내가 일하는 방식대로 화면을 유지할 수 있어요.

## 기회 관리의 칸반 보기란?

**칸반 보기**에서는 단계별로 나뉜 파이프라인 안에서 바로 작업할 수 있어요. 단계 접기, 열 너비 조절, 기회 정렬 같은 보기 설정도 함께 쓸 수 있어요. 행과 열로 자세히 관리하기에는 [**목록 보기**](../list-view-for-opportunities.md)가 더 알맞고, **칸반 보기**는 더 시각적으로 작업하기에 좋아요.

## 칸반 보기의 장점

**칸반 보기**는 파이프라인의 흐름에 맞춰 기회를 정리해서 볼 수 있어요. 표를 훑어보는 것보다 단계별로 작업하는 쪽이 편한 분께 특히 유용해요.

- 시각적인 파이프라인 관리: 기회를 단계별로 보여 줘서 딜이 어디까지 진행됐는지 한눈에 알 수 있어요.
- 깔끔한 작업 공간: 사용하지 않는 단계를 접고 열 너비를 조절해서, 화면을 정리하고 주의가 필요한 부분에 집중할 수 있어요.
- 빠른 우선순위 정하기: 기본 필드나 지원되는 [커스텀 필드](../how-to-use-custom-fields-for-opportunities.md)로 기회를 정렬해서 우선순위가 높은 항목을 먼저 확인할 수 있어요.
- 나만의 레이아웃: 선호하는 열 레이아웃을 브라우저에 저장해요. 다른 사용자의 화면은 바뀌지 않아요.
- 유연한 작업 방식: 시각적인 보드가 필요하면 **칸반 보기**를, 더 자세한 표 형태가 필요하면 **목록 보기**를 골라 쓸 수 있어요.

## 단계 접기·펼치기

단계를 접고 펼치면 큰 파이프라인도 화면이 덜 복잡해져요. 거의 쓰지 않는 단계가 있거나, 진행 중인 단계에만 집중하고 싶을 때 유용해요.

1. **기회 관리**를 열고 **칸반 보기**인지 확인하세요.
2. 조절할 단계 열을 찾으세요.
3. 단계 머리글의 컨트롤을 클릭해서 해당 열을 접거나 펼치세요.

접어 둔 단계는 보드를 깔끔하게 유지해 주고, 펼친 단계에서는 해당 단계의 많은 기회를 더 쉽게 확인할 수 있어요.

![단계 열을 접고 펼치는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068383710/original/5H10T4VMgMjd4vyr_shdSBVyofPLzQQN6A.gif?1775149134)

## 단계 열 너비 조절

중요한 단계에 화면 공간을 더 넓게 줄 수 있어요. 자주 쓰는 단계를 살펴보기 쉬워지고, 기회 카드를 하나씩 열지 않고도 내용을 확인할 수 있어요.

1. **칸반 보기**에서 단계 열의 가장자리에 마우스를 올리세요.
2. 구분선을 왼쪽이나 오른쪽으로 끌어서 열 너비를 조절하세요.
3. 조절하고 싶은 다른 단계도 같은 방법으로 반복하세요.
4. 열 구분선을 더블클릭하면 해당 단계 열이 기본 크기로 돌아가요.

기회가 많은 단계는 넓게, 신경 쓸 일이 적은 단계는 좁게 설정하면 화면이 한결 깔끔해져요.

![단계 열 너비를 조절하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068383762/original/2FX0QXTBfFOYRIq-L4PQllN-GcZ8f8aDMQ.gif?1775149167)

## 기회 정렬

정렬을 쓰면 시기, 금액, 비즈니스 데이터를 기준으로 기회 카드의 우선순위를 빠르게 정할 수 있어요. 가장 최근 항목, 급한 항목, 금액이 큰 항목부터 보고 싶을 때 유용해요.

1. **기회 관리** 페이지 위쪽에서 **정렬**을 클릭하세요.

   ![정렬 버튼을 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068383790/original/fYMGzUekGSwbHUal0wO8g_wScR073GrzWw.png?1775149225)
2. 정렬 기준으로 사용할 필드를 선택하세요. 기본 필드와 지원되는 커스텀 필드를 선택할 수 있어요.
3. **오름차순** 또는 **내림차순**을 선택하세요.
4. 선택한 기준에 맞춰 기회가 자동으로 다시 정렬돼요.

   ![정렬 기준에 따라 기회가 정렬된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068383841/original/ZIPqBNgsPRf3AL6wSX2aC1LfYLRUZE4CHQ.png?1775149263)

정렬에 쓸 수 있는 필드는 다음과 같아요.

- **생성일**, **최근 수정** 같은 기본 필드
- **한 줄**, **Multi Line Text**(여러 줄 텍스트), **드롭다운**, **라디오 선택**, **숫자**, **금액**, **전화번호**, **날짜** 같은 커스텀 필드 유형

## 저장되는 레이아웃 설정

- 단계를 접거나 펼친 상태는 자동으로 저장돼요.
- 조절한 열 너비도 자동으로 저장돼요.
- 이 설정은 브라우저에 저장돼요.
- 변경한 내용은 내 화면에만 적용되고, 다른 사용자에게는 영향을 주지 않아요.

![저장된 레이아웃이 유지되는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068384317/original/-BoL7T2o0qVg5jxTq_A1VWyQ1s3O_j-eNQ.gif?1775149881)

## 칸반 보기 활용 팁

몇 가지 습관만 들여도 매일 파이프라인을 관리하기가 훨씬 편해져요. 보드를 읽기 쉽고 바로 행동하기 좋게 유지하는 방법이에요.

- 사용하지 않거나 거의 쓰지 않는 단계는 접어서 화면을 정리하세요.
- 진행 중인 단계는 펼치고 넓혀서 중요한 기회 카드를 쉽게 훑어볼 수 있게 하세요.
- 정렬을 활용해 우선순위가 높거나 최근에 수정된 기회를 위쪽에 두세요.
- 행 단위로 자세히 확인하거나 열 중심으로 정리해야 할 때는 **목록 보기**로 전환하세요.
