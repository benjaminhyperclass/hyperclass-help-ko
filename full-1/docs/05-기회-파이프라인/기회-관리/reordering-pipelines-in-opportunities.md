# 기회 관리에서 파이프라인 순서 바꾸기

**기회 관리**(Opportunities)의 파이프라인 화면에서 파이프라인을 원하는 순서로 정렬할 수 있어요. 끌어서 옮기거나, 정확한 위치를 지정해서 옮길 수 있어요. 바꾼 순서는 자동으로 저장되고, 페이지를 새로고침해도 그대로 유지돼요.

## 끌어서 순서 바꾸기

1. **기회 관리**로 이동한 뒤 **파이프라인** 탭을 열어요.
2. 순서를 바꿀 파이프라인 행의 왼쪽에 있는 드래그 핸들(점으로 된 아이콘) 위에 마우스를 올려요.
3. 파이프라인을 원하는 위치까지 위나 아래로 끌어서 놓아요.

![파이프라인 목록에서 파이프라인을 새 위치로 끌어서 옮기는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472806/original/Tqtv9kpzrPj2bm_NhWTCb__8RzjPP5th-w.png?1781185020)

핸들을 잡고 끌면 파이프라인 순서를 바꿀 수 있어요.

## 특정 위치로 파이프라인 옮기기

파이프라인을 정확히 원하는 자리에 두고 싶을 때 쓰세요. 다른 페이지에 있는 파이프라인도 옮길 수 있어서, 지금 보고 있는 페이지에 없어도 위치를 바꿀 수 있어요.

1. 옮길 파이프라인 행에서 **⋯(점 세 개) 작업** 메뉴를 클릭해요.
2. **위치로 이동**을 선택해요.

![점 세 개 작업 메뉴에서 위치로 이동 항목이 강조된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472807/original/86l1JNPREH6Z_oKFRXp_a2dBRDnblAOyYQ.png?1781185020)

작업 메뉴를 열고 **위치로 이동**을 선택하세요.

3. **Reorder Pipeline**(파이프라인 순서 변경) 창에서 원하는 위치 번호를 입력해요.
4. **적용**을 클릭해요.

![위치로 이동 입력란이 있는 파이프라인 순서 변경 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472805/original/ZJKnO2kbz68NbrraUQFV9vpX4eWGXsrRgw.png?1781185020)

옮길 위치 번호를 입력하고 **적용**을 클릭하세요.

파이프라인이 해당 위치로 이동하고, 목록 번호도 자동으로 다시 매겨져요.

![순서가 바뀐 파이프라인 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073472808/original/FQXvC1zo6VxUPQr2-2q84grr69VZxcraBw.png?1781185020)

목록에 새 순서가 바로 반영돼요.

## 알아 두세요

- 바꾼 순서는 자동으로 저장돼요. 따로 저장 버튼은 없어요.
- 페이지를 새로고침해도 순서가 유지돼요.
- **위치로 이동**은 페이지를 넘나들며 옮길 수 있어서 파이프라인이 많을 때 편해요.
- 이 기능은 관리자만 쓸 수 있고, 설정은 해당 로케이션의 모든 사용자에게 똑같이 저장돼요.
