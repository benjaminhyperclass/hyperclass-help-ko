# 기회 관리 자주 묻는 질문

**기회 관리**(Opportunities)를 쓰다가 자주 나오는 질문을 모았어요. 기회 내보내기와 공유, 활동 기록 확인, 추가 연락처, 커스텀 필드 관련 질문을 다뤄요.

## 일반 질문

### 하이퍼클래스에서 기회를 내보내려면 어떻게 하나요?

![기회 내보내기 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155049332407/original/F-Gf__4alVkhG-RNMAuJVbasTgnRiMqaOw.png?1751612397)

1. 왼쪽 사이드바에서 **기회 관리**로 이동하세요.
2. 오른쪽 위에 있는 케밥 메뉴(점 3개 메뉴)를 클릭하세요.
3. **Export Opportunities**(기회 내보내기)를 선택하세요.
4. 내보내기 파일이 만들어지면 브라우저의 기본 다운로드 폴더에 저장돼요.

### 특정 기회를 팀원과 공유하려면 어떻게 하나요?

1. 공유할 기회를 앱에서 여세요.
2. 브라우저 주소창의 URL을 복사하세요.
3. 복사한 링크를 팀원이나 관계자에게 전달하세요.

공유받은 사람이 링크를 열면 해당 기회의 상세 화면으로 바로 이동해요. 협업이 쉬워지고 시간도 아낄 수 있어요.

### 기회의 모든 활동을 추적하고 기회 ID를 확인하려면 어떻게 하나요?

1. 기회 카드를 클릭해 기회를 여세요.
2. 왼쪽 아래에 있는 **기회 ID**를 확인하고 클릭하세요.
3. 해당 기회의 **감사 로그**로 이동해요.
4. **감사 로그**에서는 최근 60일 동안 그 기회에서 일어난 모든 활동을 확인할 수 있어요.

### 기회 하나에 여러 연락처를 연결하는 기능은 어떻게 동작하나요?

1. 기회 카드를 클릭해 기회를 여세요.
2. **추가 연락처** 필드에서 기회에 연결할 연락처를 추가하세요.
3. 기회의 주 연락처로 추가된 연락처는 같은 기회의 추가 연락처 목록에 또 추가할 수 없어요.
4. **중복 기회 허용** 설정이 꺼져 있으면, 한 연락처를 서로 다른 두 기회의 주 연락처나 추가 연락처 목록에 동시에 추가할 수 없어요.
5. 한 기회에는 추가 연락처를 최대 10명까지 추가할 수 있어요.
6. 리스트와 워크플로우는 계속 주 연락처에만 적용되고, 주 연락처의 정보를 가져와요. [향후 업데이트에서 추가될 예정이에요]
7. 연락처에 연결된 기회는 연락처 레코드(오른쪽 패널)의 **기회 관리** 탭에서 볼 수 있어요.

### 고객전환실패 기회에 있는 연락처의 이름과 상세 정보를 찾으려면 어떻게 하나요?

1. 왼쪽 메뉴에서 **기회 관리**로 이동하세요.
2. **상세 필터** 버튼을 클릭하세요.
3. **상태**에서 **고객전환실패**를 선택하고 **적용**을 클릭하세요.
4. 목록에 고객전환실패 기회만 표시돼요.
5. 연락처의 상세 정보를 보려면 기회 카드를 클릭하세요.

## 커스텀 필드 질문

### 기회에서 커스텀 필드를 보려면 어떻게 하나요?

**기회 관리**로 이동해 기회를 선택하거나 새로 만들면 커스텀 필드 목록이 보여요. 기회를 편집하면 이 필드에 값을 입력할 수 있어요. 필드를 폴더로 정리해 두었다면 폴더가 차례대로 표시돼요.

### **hide empty fields**(빈 필드 숨기기) 기능은 어떤 역할을 하나요?

**hide empty fields**를 켜면 값이 없는 필드가 모두 숨겨져요. 꼭 필요한 필드만 남아서 기회 정보를 더 깔끔하게 볼 수 있어요.

### 기회 관리의 "lost reason" 필드 값을 수정하려면 어떻게 하나요?

1. **설정 > 커스텀 필드**로 이동하세요.
2. **Lost Reason**(고객전환실패 사유)을 선택하고 **일괄 작업 > 편집**을 클릭하세요.

   ![고객전환실패 사유 일괄 작업 편집 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027588180/original/e7mXlPtOYxPbCAK_kfpkpg1dHGwky25FxQ.png?1718273194)

3. 팝업 창에서 고객전환실패 사유 값을 수정하고 **저장**을 클릭하세요. 저장해야 변경 내용이 반영돼요.

   ![고객전환실패 사유 값 수정 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155027588275/original/oPwS_jwP0_nbvYCM2KInuuqJMxaPvTWCqA.png?1718273272)

```
고객전환실패 사유의 이름을 바꾸면, 그 사유가 쓰이던 모든 곳에 새 이름이 표시돼요.
