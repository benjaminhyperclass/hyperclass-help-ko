# 기회 파이프라인 색상으로 구분하기 (스마트 태그)

스마트 태그는 파이프라인 안의 기회를 색상 칩으로 보여 주는 기능이에요. 필터나 텍스트 라벨 대신, 정해 둔 규칙에 따라 오래된 딜, 높은 가치의 기회, 새 리드 등을 자동으로 강조할 수 있어요. 이 문서에서는 하이퍼클래스에서 스마트 태그를 만들고, 편집하고, 관리하는 방법을 안내해요.

## 스마트 태그란?

스마트 태그는 파이프라인의 각 기회 카드에 바로 표시되는, 규칙 기반의 색상 칩이에요. 간단한 조건 빌더로 규칙을 만들어 두면 모든 기회를 실시간으로 확인하고, 조건에 맞는 기회에 색상 라벨을 자동으로 붙여 줘요(예: 거래 가치 > $10,000). 한눈에 알아볼 수 있어서 필터를 따로 걸거나 카드를 하나씩 훑어볼 필요가 없어요.

## 스마트 태그의 장점

- **바로 우선순위 파악:** 중요한 딜이 화면에서 눈에 띄어요.
- **화면 전환 최소화:** 카드를 하나씩 열거나 여러 필터를 적용하지 않아도 돼요.
- **팀 전체가 같은 곳에 집중:** 모두가 같은 색상 신호를 보기 때문에 팀이 같은 방향으로 움직여요.
- **워크플로우에 맞게 설정:** 표준 기회 필드나 커스텀 기회 필드를 대상으로 AND/OR 조건을 자유롭게 조합할 수 있어요.

## 권한과 접근

- 스마트 태그를 만들거나 편집할 수 있는 사용자
  - 에이전시 관리자
  - 서브 계정 관리자
  - 파이프라인 편집 권한이 있는 사용자
- 스마트 태그를 볼 수 있는 사용자
  - 파이프라인 **보기 권한**이 있는 모든 사용자(편집 권한이 없어도 볼 수 있어요)

## 제한과 유효성 검사

- 파이프라인 하나에 활성 스마트 태그를 **최대 60개**까지 만들 수 있어요.
- 같은 파이프라인에서 색상과 규칙이 같은 태그는 중복으로 만들 수 없어요. 자동으로 차단돼요.
- 딜 데이터가 바뀌면 태그도 자동으로 업데이트돼요. 따로 새로고침하지 않아도 돼요.

## 스마트 태그 설정하고 사용하기

### 1단계: 스마트 태그 찾기

1. 서브 계정에서 **기회 관리**(Opportunities)로 이동하세요.
2. **파이프라인** 탭을 클릭하세요.

   ![파이프라인 탭](https://jumpshare.com/share/1lRYpa0DPkqgnn7vklNo+/Screen+Shot+2025-10-14+at+10.10.30+PM.png)
3. 스마트 태그를 추가할 파이프라인에서 **편집** 버튼을 클릭하세요.

   ![파이프라인 편집 버튼](https://jumpshare.com/share/SiYTF4MUiKdXMRW6q8zM+/Screen+Shot+2025-10-14+at+10.12.33+PM.png)
4. **Smart Tags**(스마트 태그) 탭을 여세요.

   ![스마트 태그 탭](https://jumpshare.com/share/QT0cNw8OUDULQHDTOQvA+/Screen+Shot+2025-10-14+at+10.18.05+PM.png)

### 2단계: 스마트 태그 만들기

1. **Add Smart Tag**(스마트 태그 추가)를 클릭하세요.

   ![스마트 태그 추가 버튼](https://jumpshare.com/share/xs6WW87OttyVfYr6Io9l+/Screen+Shot+2025-10-14+at+10.21.18+PM.png)
2. 둘 중 하나를 선택하세요.

   - **Create New Tag**(새 태그 만들기): 색상, 이름, 규칙 조건을 직접 정해요.
   - **Pre-Built Tag**(미리 만들어진 태그): 기본 템플릿을 사용해요(예: **새 리드**, **높은 가치**).

     ![새 태그 만들기 또는 미리 만들어진 태그 선택](https://jumpshare.com/share/YTAhZp8CjAr7fQedHxkK+/Screen+Shot+2025-10-14+at+10.23.28+PM.png)
3. **Label Name**(라벨 이름)을 입력하세요(예: "방치된 딜").
4. 알아보기 쉽게 **설명**을 입력하세요. 입력하지 않아도 돼요.
5. 태그의 **색상**을 고르세요.
6. 이 규칙을 모든 파이프라인에서 쓰려면 **모든 파이프라인에 적용**을 체크하세요.
7. **Next: Add Rule**(다음: 규칙 추가)을 클릭하세요.

   ![다음: 규칙 추가 버튼](https://jumpshare.com/share/Y24qhRMvGpdtEt8pRgOr+/Screen+Shot+2025-10-14+at+10.28.48+PM.png)

### 3단계: 규칙 정하기

1. 규칙 빌더에서 **태그가 언제 표시될지** 정하세요.
2. 스마트 태그는 모두 규칙 기반이에요. 예를 들면 다음과 같아요.

   - **생성일 ≤ 3일 전** → "새 리드"
   - **거래 가치 > $10,000** → "높은 가치"
3. 규칙 빌더에서는 다음을 할 수 있어요.

   1. 여러 조건을 **그리고**(AND) / **OR** 로 묶을 수 있어요.
   2. 복잡한 조건은 중첩 필터로 추가할 수 있어요.
   3. **Preview Tag**(태그 미리보기)로 샘플 카드에서 태그가 어떻게 보일지 확인할 수 있어요.
   4. 모두 마쳤으면 **저장**을 클릭하세요.
4. 스마트 태그 규칙은 기회 관리의 **상세 필터**와 같은 개선된 환경을 써요. 다음 기능이 포함돼요.

   - 필드를 폴더 형태의 섹션으로 묶어서 더 쉽게 찾을 수 있어요.
   - 더 정확하게 대상을 정할 수 있는 **단계** 필터가 있어요.
   - 날짜 연산자가 늘어났어요.
     - **Is not**(아님)
     - **In the next**(다음 기간 내)
     - **In the last**(지난 기간 내)
     - **More than**(초과)
     - **Less than**(미만)
   - **일, 주, 월, 년** 단위의 상대 시간으로 필터링할 수 있어요.
   - 더 복잡한 규칙 조건을 위한 **중첩** 필터링 로직을 쓸 수 있어요.

   ![규칙 빌더 사용 화면](https://jumpshare.com/share/f1pRboRnSNkFOLOc17cm+/GIF+Recording+2025-10-14+at+10.31.43+PM.gif)

## 소유자·팔로워 규칙에 "me" 사용하기

스마트 태그 규칙을 만들 때 **소유자**나 **팔로워** 필터의 값으로 **me**(나)를 선택할 수 있어요.

**me**는 기회 목록을 보고 있는 사용자를 뜻해요. 예를 들어 **소유자 = me** 규칙은 지금 보는 사람이 소유한 기회에 일치해요.

**me**는 보는 사람마다 다르게 적용돼요. 그래서 사용자마다 규칙을 따로 만들지 않아도, 스마트 태그 하나로 팀원마다 맞춤 결과를 볼 수 있어요.

## 추천 미리 만들어진 태그

| 태그 이름 | 색상 | 규칙 예시 | 용도 |
| --- | --- | --- | --- |
| **Stale Deal**(방치된 딜) (출시 예정) | 회색 | 최근 활동이 14일 전보다 이전 | 방치된 기회 강조 |
| **높은 가치** | 초록 | 기회 가치 > $10,000 | 고액 딜 표시 |
| **새 리드** | 파랑 | 생성일 ≤ 3일 전 | 새 기회 추적 |
| **At Risk**(위험) (출시 예정) | 빨강 | 마지막 단계 변경 > 30일 전, 상태 = "진행 중" | 식어 가는 딜 경고 |
| **인기 거래** | 주황 | 생성일 < 7일, 기회 가치 > $5,000 | 최근 생성된 고액 기회 강조 |
| **할당되지 않은 딜** | 보라 | 소유자가 비어 있습니다 | 소유자 없는 기회 찾기 |

## 활용 팁

✅ 가장 중요한 항목은 눈에 띄는 색상으로 구분하세요(예: 긴급은 빨강, 높은 가치는 초록).

✅ 태그 이름은 20자 미만으로 짧게 쓰세요.

✅ 규칙이 지금 상황에 맞는지 주기적으로 점검하세요.

## 문제 해결

- **카드에 스마트 태그가 보이지 않아요.**
  - **카드 맞춤 설정**에서 카드 레이아웃에 스마트 태그를 추가했는지 확인하세요.
  - 규칙 조건이 올바른지, 지금 보는 카드에 해당하는 조건인지 확인하세요.
  - 강력 새로고침(하드 리프레시)을 해서 파이프라인의 변경 사항을 동기화하세요.

- **스마트 태그 탭이 보이지 않아요.**
  - 관리자만 태그를 만들고 편집할 수 있어요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

## 자주 묻는 질문

### 스마트 태그는 모든 파이프라인에서 작동하나요?
네. **모든 파이프라인에 적용**을 선택하면 규칙 조건에 맞는 곳 어디에서나 태그가 표시돼요.

### 스마트 태그를 다른 파이프라인으로 복제할 수 있나요?
아직은 안 돼요. 다른 파이프라인에서 같은 규칙을 직접 다시 적용하면 돼요.

### 스마트 태그가 리포트에도 포함되나요?
현재는 파이프라인 보기에서만 시각적으로 표시돼요.

### 스마트 태그는 누가 만들거나 편집할 수 있나요?
파이프라인 설정을 편집할 권한이 있는 사용자는 누구나 스마트 태그를 관리할 수 있어요. 접근을 제한하려면 **파이프라인 권한**을 사용하세요.

### 스마트 태그는 실시간으로 확인되나요?
기회가 생성되거나 업데이트될 때, 그리고 단계나 상태가 바뀔 때마다 모든 태그 규칙을 다시 확인해요.

### 스마트 태그를 다른 서브 계정으로 복사할 수 있나요?
네. 기회 스마트 태그는 **계정 스냅샷**에 포함해서, 해당 파이프라인과 함께 다른 서브 계정으로 복사할 수 있어요. 자세한 내용은 "기회 스마트 리스트와 스마트 태그를 스냅샷에 추가하는 방법" 문서를 참고하세요.
