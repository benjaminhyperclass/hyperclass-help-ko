# 기회 카드 일괄 작업

하이퍼클래스 **기회 관리**의 칸반(카드) 화면에서 기회 카드를 여러 개 선택해 한 번에 관리하는 방법을 안내해요. 카드 화면을 벗어나지 않고 이동, 편집, 삭제 같은 작업을 한꺼번에 처리할 수 있어요.

## 기회 카드 일괄 작업이란?

**기회 관리**의 파이프라인 칸반 화면에서는 기회 카드를 여러 개 선택할 수 있어요. 각 카드에 체크박스가 있어서, 선택한 기회를 옮기거나 편집하거나 삭제하는 작업을 한 번에 할 수 있어요. 기회가 많은 파이프라인을 관리하는 팀의 작업 시간을 줄여 줘요.

## 기회 카드 일괄 작업의 장점

- 빠른 작업: 칸반(카드) 화면에서 바로 여러 기회를 업데이트할 수 있어요.
- 화면 전환 불필요: **목록 보기**로 옮기지 않고도 일괄 작업을 할 수 있어요.
- 전체 선택: 기회가 20개 이상이면 현재 페이지의 카드를 모두 선택할 수 있어요.
- 실수 방지: 선택 모드에서는 카드를 끌어다 놓거나 여는 기능이 꺼져요.
- 접근성: 원하는 보기 방식에서 누구나 파이프라인을 쉽게 관리할 수 있어요.
- 효율적인 관리: 많은 기회를 빠르고 간편하게 업데이트할 수 있어요.

## 사용 방법

### 기회 관리 열기

왼쪽 메뉴에서 **기회 관리**(Opportunities)를 선택하세요. 파이프라인의 모든 단계와 기회가 카드 형태로 표시돼요.

![기회 관리 메뉴를 선택한 카드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048890304/original/bzi32qGFBzcEO18XHeauDIaEyfB3oblS7A.png?1750905909)

### 파이프라인 선택하기

화면 위쪽의 드롭다운 메뉴에서 관리할 **파이프라인**을 선택하세요. 선택한 파이프라인의 기회만 보여서 일괄 업데이트하기가 더 편해요.

![파이프라인을 선택하는 드롭다운 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048890340/original/8PhClHpHMJ3mR-CkXFSQN4MiMRT_r5xqXA.png?1750906016)

### 보기 방식 선택하기

오른쪽 위의 전환 아이콘을 눌러 **카드** 보기와 **목록 보기** 중에서 고르세요. 두 보기 모두 일괄 작업을 지원해요.

- **카드** 보기: 파이프라인 단계별로 기회를 눈으로 훑어보며 선택하고 싶을 때 좋아요.
- **목록 보기**: 데이터가 많을 때 알맞아요. 빠르게 스크롤하고, 열 기준으로 정렬하고, 여러 건을 한꺼번에 선택해 일괄 편집할 수 있어요.

파이프라인 흐름을 보면서 작업할지, 많은 기록을 한꺼번에 관리할지에 따라 보기를 고르세요.

![카드 보기와 목록 보기를 전환하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048891240/original/IfVoINQnX9Aq0wXyZ0HawK4tii6-Bw6mOw.gif?1750910051)

### 여러 기회 선택하기

기회에 마우스를 올리면 카드 오른쪽 위에 체크박스가 나타나요. 이 체크박스를 눌러 기회를 선택하세요.

![기회 카드의 체크박스를 눌러 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048910865/original/OlcXQ14mgww3N3q5rC-9NJr8rqrmtOumpg.gif?1750930624)

### 기회 카드 편집하기

**카드** 보기나 **목록 보기**에서 기회를 여러 개 선택하면 화면 위쪽에 **편집** 버튼이 나타나요. 이 버튼을 누르면 선택한 기록 전체에 변경 사항을 한 번에 적용할 수 있어요.

![여러 기회를 선택하면 위쪽에 나타나는 편집 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048891457/original/J4DhvHgyW9xm4D5NgA6ZTRhU-KGoVe4sQg.png?1750910955)

### 편집할 필드 선택하기

**편집**을 누르면 **Bulk Edit**(일괄 편집) 패널이 열려요. 여기서 여러 기회에 한꺼번에 바꿀 필드를 선택하세요. 담당자 재배정, 정리, 캠페인 기준 업데이트에는 보통 **상태**, 금액, **파이프라인**, **소유자** 같은 필드를 써요. 아래에서 몇 가지 필드를 하나씩 살펴볼게요.

### 새 소유자 지정하기

**소유자** 필드를 선택하면 기회를 다른 팀원에게 재배정할 수 있어요. 팀 근무 일정이 바뀌거나, 휴가나 공백이 생겨서 리드를 다시 나눠야 할 때 특히 유용해요.

![소유자 필드를 선택해 새 소유자를 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048910137/original/ufcirshS3bxcjRrQVBERj2DqNJGlmdRXPg.png?1750930143)

### 파이프라인과 단계 바꾸기

**파이프라인**과 **단계** 필드를 사용하면 여러 기회를 다른 흐름으로 한꺼번에 옮길 수 있어요. 리드를 새로운 영업 프로세스나 캠페인 이후 단계로 다시 묶어야 할 때 도움이 돼요.

![파이프라인과 단계 필드를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048910204/original/3mYq9dZsizzr-oRhp1nb5AT5GkOSTVfMPw.png?1750930213)

### 기회 상태 업데이트하기

**상태**를 선택하면 선택한 기회를 **Open**(진행 중), **고객전환성공**, **고객전환실패**, **Abandoned**(중단) 중 하나로 한꺼번에 바꿀 수 있어요. 통화 검토, 아웃리치 시퀀스, 캠페인 후속 조치가 끝난 뒤 정리할 때 편해요.

![상태 필드를 선택해 기회 상태를 바꾸는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048910116/original/7IRjHGxKea0uOp3Rn_eSaJo3mFmfy2OZKA.png?1750930125)

### 전체 선택으로 일괄 업데이트하기

기회가 많을 때는 **Select all [number]**(전체 [숫자]개 선택)를 눌러 현재 파이프라인에 보이는 모든 기회를 선택할 수 있어요. 같은 변경 사항을 그룹 전체에 적용할 때 시간을 아껴 줘요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

![Select all 버튼으로 전체 기회를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155048910467/original/dOOpKx4yzUO1I1RPiipLQrRDnPzBMmpFyg.png?1750930360)

## 자주 묻는 질문

### 여러 페이지에 걸쳐 카드를 선택하려고 **Select All on Page**(현재 페이지 전체 선택)를 쓸 수 있나요?

아니요. 이 옵션은 현재 페이지의 카드만 선택해요.

### 카드를 잘못 선택했어요. 어떻게 하나요?

체크박스를 다시 눌러 선택을 해제하세요. 전체 선택을 해제하면 선택 모드에서 나갈 수 있어요.

### 선택 모드에서도 카드를 옮기거나 열 수 있나요?

아니요. 실수를 막기 위해 선택하는 동안에는 카드를 끌어다 놓거나 여는 기능이 멈춰요.

### 한 페이지에 기회가 20개 이상인지 어떻게 알 수 있나요?

20개에 도달하면 **Select All on Page** 버튼이 자동으로 나타나요.

### 일괄 작업을 되돌릴 수 있나요?

카드 이동처럼 되돌릴 수 있는 작업도 있어요. 그래도 선택한 항목을 꼼꼼히 확인하고 작업하는 것이 좋아요.

### 사용자 권한에 따라 쓸 수 있는 작업이 달라지나요?

네. 사용자 역할과 권한에 따라 쓸 수 있는 작업이 달라요.
