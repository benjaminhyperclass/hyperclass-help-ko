# 파이프라인 만들기와 단계 관리

파이프라인을 만들고, 단계를 추가·관리하고, 대시보드에 보이는 방식을 설정하는 방법을 안내해요. 기회가 어떤 단계에 있는지 한눈에 보면서 영업이나 서비스 업무를 정리하고 자동화할 때 사용해요.

## 개요

파이프라인으로 고객 여정의 각 단계를 나눠 둘 수 있어요. 리드를 확보하는 단계부터 계약 체결이나 온보딩까지 모두 담을 수 있어요. 파이프라인은 플랫폼 전반의 자동화, 리포팅, 기회 대시보드에 쓰여요.

{% hint style="info" %}
**파이프라인 화면 업데이트 (실험실)**

**파이프라인** 화면에 새 디자인 시스템이 적용되어 더 빠르고 쓰기 편해졌어요.

**서브 계정 > 실험실**에서 이 업데이트를 켤 수 있어요.
{% endhint %}

## 파이프라인 만들고 관리하기

### 1단계: 파이프라인 화면 열기

서브 계정에서 파이프라인 화면을 여는 방법이에요.

1. **서브 계정**으로 이동해요.
2. 왼쪽 사이드바에서 **기회 관리**(Opportunities)를 클릭해요.
3. 상단 메뉴에서 **파이프라인**을 선택해요.

![파이프라인 화면으로 이동하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064130713/original/B8seRPUvO12HmBstcfJYYLtRCYvSv5w2sg.png?1770164789)

### 2단계: 새 파이프라인 만들기

**파이프라인** 화면에서 다음 순서로 진행해요.

1. 오른쪽 위의 **새 파이프라인 만들기**를 클릭해요.
2. 알아보기 쉬운 **파이프라인 이름**을 입력해요.
3. **저장**을 클릭해요.

![새 파이프라인 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064130717/original/3BrXmQHJXVrtzOOSm8Ae9WfLVrdzP274qw.png?1770164811)

{% hint style="info" %}
파이프라인 이름은 중복될 수 없어요. 같은 서브 계정에 이미 있는 이름으로는 파이프라인을 만들거나 수정할 수 없어요.
{% endhint %}

### 3단계: 파이프라인 단계 추가하고 관리하기

파이프라인을 만들었다면 업무 흐름을 이루는 단계를 정해요.

단계를 추가하려면 다음과 같이 해요.

1. **단계 이름**을 입력해요.
2. **단계 추가**를 클릭해 단계를 더 만들어요.
3. 전체 흐름이 완성될 때까지 반복해요.

단계는 이렇게 관리해요.

- 위아래 화살표로 단계 순서를 바꿔요.
- 퍼널 차트 아이콘과 원형 차트 아이콘으로 리포팅에 보일지 정해요.
- 휴지통 아이콘으로 단계를 삭제해요.

![파이프라인 단계를 추가하고 관리하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064130722/original/lGp5tEhmVoybO8y8dy9ulhHUfmOHsVehGA.png?1770164833)

{% hint style="warning" %}
- 단계 이름은 같은 파이프라인 안에서 중복될 수 없어요.
- **고객전환성공**과 **고객전환실패** 단계는 자동으로 만들어져요. 직접 추가하지 않아도 돼요.
{% endhint %}

### 4단계: 단계 색상 지정하기

단계마다 색상을 지정하면 파이프라인에서 단계를 더 쉽게 구분할 수 있어요.

**단계 색상을 지정하려면**

1. 파이프라인을 열어요.
2. **단계** 탭으로 이동해요.
3. 단계마다 색상을 선택해요.

![단계별 색상을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067901862/original/rnzo2M3KVSmYhTnRwq3g_VcBNXDbnkTGzg.png?1774616013)

**색상이 보이는 방식 고르기**

- **기본**(색 없음)
- **Colored dot**(색 점)
- **배경 색조**

![색상 표시 방식을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067901969/original/klOm-AP3gA1AoYtf2EHKNIB84D_SMNXHVQ.png?1774616071)

**단계 색상은 다음 화면에 반영돼요.**

- 칸반 보기와 **목록 보기** ![칸반 보기와 목록 보기에 반영된 단계 색상](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067901922/original/Q_SxAZrlOedv0Pfbc-03HL7h5Z7KjMXC_Q.png?1774616049)
- 기회 카드
- **연락처 세부정보** 화면 ![연락처 세부정보 화면에 반영된 단계 색상](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067901944/original/ZJLh93qgFwtFkjZU25Ai5NV_IiibRplvoA.png?1774616060)

### 4단계: 파이프라인 단계 삭제하기

이제 단계를 삭제할 때 기존 기회를 잃지 않고 다른 단계로 옮길 수 있어요.

단계를 삭제하려면 다음과 같이 해요.

1. 수정할 파이프라인을 열어요.
2. 삭제할 단계 옆의 삭제 아이콘을 클릭해요.
3. 기존 기회를 옮길 단계를 선택해요.
4. 삭제를 확인해요.

삭제한 단계에 있던 기회는 모두 선택한 단계로 자동으로 이동해요.

### 5단계: 파이프라인 대시보드 표시 설정하기

파이프라인과 단계를 대시보드와 리포트에 보여 줄지 정할 수 있어요.

- 다음 차트에서 파이프라인 표시를 켜거나 꺼요.
  - 퍼널 차트
  - 원형 차트
- 각 단계 옆의 아이콘으로 단계별 표시를 설정해요.

이 설정에 따라 기회 대시보드에 파이프라인 데이터가 표시되는 방식이 달라져요.

## 자주 묻는 질문

### 고객전환성공·고객전환실패 단계를 직접 만들어야 하나요?

아니요. 하이퍼클래스가 모든 파이프라인에 **고객전환성공**과 **고객전환실패** 단계를 자동으로 추가해요.

### 단계를 삭제하면 기회는 어떻게 되나요?

삭제할 때 기존 기회를 모두 다른 단계로 옮길 수 있어서 데이터가 사라지지 않아요.

### 파이프라인을 만든 뒤에 이름을 바꿀 수 있나요?

네, 바꿀 수 있어요. 단, 새 이름이 같은 서브 계정 안에서 중복되지 않아야 해요.

### 업데이트된 파이프라인 화면에서 기능이 달라지나요?

아니요. 핵심 기능은 그대로예요. 화면 디자인이 개선되고 단계를 더 안전하게 관리할 수 있게 된 것이 이번 업데이트의 중심이에요.
