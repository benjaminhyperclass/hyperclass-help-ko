# 기회 검색하기

검색창을 쓰면 원하는 기회를 빠르게 찾을 수 있어요. 이 문서에서는 **기회 관리**에서 기회를 검색하는 방법을 안내해요.

## 1단계: 기회 관리 화면 열기

1. 하이퍼클래스에 로그인한 뒤 서브 계정을 엽니다.
2. 왼쪽 메뉴에서 **기회 관리**(Opportunities)를 선택하세요.

![기회 관리 화면으로 이동하는 왼쪽 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155021427877/original/pHaxiq16lJCxkIQKDac3zIwACAvtbBFZ6Q.png?1708707911)

## 2단계: 검색창 살펴보기

1. **기회 관리** 화면 맨 위에서 검색창을 찾으세요.
2. 검색창에 키워드나 문구를 입력하면 검색어와 일치하는 기회를 찾을 수 있어요.
3. 기회 이름, 전화번호, 이메일, 회사, 태그, **연락처 이름**으로 검색할 수 있어요.

## 3단계: 기본 검색하기

검색창에 찾으려는 기회와 관련된 키워드나 문구를 입력하세요. 입력하는 동안 검색 조건에 맞는 기회만 목록에 바로 표시돼요.

- 검색은 3글자 이상 입력해야 작동해요.
- 단어의 중간부터는 검색되지 않아요. 예를 들어 "Opportunity details"라는 이름이 있다면 'Oppor'로는 검색되지만 'tunity'로는 검색되지 않아요.
