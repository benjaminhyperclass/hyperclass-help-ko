# 기회 상태 변경하기

기회 상태의 종류와 차이를 알고 상태를 바꾸는 방법을 설명해요. 상태를 바꾸는 방법은 세 가지예요. 기회를 직접 열어서 바꾸거나, 카드를 끌어다 놓거나, 워크플로우로 자동 변경할 수 있어요.

## 기회 상태 이해하기

### 진행 중

- **진행 중** 상태의 기회는 지금 적극적으로 진행하고 있는 건이에요.
- 아직 고객전환성공, 고객전환실패, 중단됨 중 어디에도 해당하지 않고, 전환될 가능성이 남아 있는 거래예요.

### 고객전환성공

- **고객전환성공** 상태는 기회가 판매나 계약으로 성공적으로 이어졌다는 뜻이에요.
- 리드가 구매했거나 계약서에 서명해서 비즈니스에 매출이 생겼을 때 이 상태로 바꿔요.

### 고객전환실패

- **고객전환실패** 상태의 기회는 성사되지 못하고 끝난 거래예요.
- 리드가 구매를 진행하지 않기로 했거나 경쟁사의 상품을 선택했을 때 이 상태로 바꿔요.

### 중단됨

- **중단됨** 상태는 리드나 영업팀이 기회를 더 이상 챙기지 않고 방치했다는 뜻이에요.
- 이 기회에 대해 이어서 할 작업이나 후속 연락이 없어서 사실상 진행 대상에서 빠졌을 때 이 상태로 바꿔요.

{% hint style="info" %}
기회 상태의 유형과 이름은 바꿀 수 없어요. 정해진 4가지 상태 중에서만 고를 수 있어요.
{% endhint %}

## 기회 상태 바꾸기

기회 상태를 바꾸는 방법은 세 가지예요.

1. 기회를 직접 열어서 상태 바꾸기
2. 기회 카드를 끌어다 알맞은 상태에 놓기
3. 워크플로우로 상태 바꾸기

각 방법을 단계별로 설명해요.

## 옵션 1: 기회를 직접 열어서 상태 바꾸기

1. 하이퍼클래스에 로그인한 뒤 사이드바 메뉴에서 **자동화** 섹션으로 이동해요. <!-- 검토 필요: 원문 내용이 서로 다름 (제목은 Opportunities 섹션, 본문은 Automation 섹션으로 안내) -->

   ![사이드바 메뉴에서 자동화 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028659483/original/LkxOBL-tOpBAeTZx1X3D-uI76n7LsMxjMA.jpg?1720021611)

2. **기회 관리**(Opportunities) 섹션에서 상태를 바꿀 기회를 찾아요. 검색 필터를 쓰거나 기회 목록을 훑어보면 찾을 수 있어요.
3. 기회 카드를 클릭하면 상세 페이지가 열려요. 기회 옆의 **편집** 버튼을 눌러도 상세 페이지로 들어갈 수 있어요.

   ![기회 카드를 열거나 편집 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028660222/original/NoksvpTNSw_5QhZjVgNPvR8U6CR6nCNzDQ.jpg?1720022152)

4. 기회 상세 페이지에서 현재 상태가 표시된 **기회 상태** 필드를 찾아요.
5. 필드를 클릭해 드롭다운 메뉴를 열고 원하는 상태(**진행 중**, **고객전환성공**, **고객전환실패**, **중단됨**)를 골라요.
6. 상태 변경을 확인하면 영업 파이프라인에서 기회 상태가 바뀌어요.

   ![기회 상태 필드에서 상태 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028660389/original/KgVhPfs9obIf30vcqe5_bAi-qBXEPhyjPw.jpg?1720022274)

## 옵션 2: 기회 카드를 끌어다 알맞은 상태에 놓기

1. 하이퍼클래스에 로그인한 뒤 사이드바 메뉴에서 **자동화** 섹션으로 이동해요. <!-- 검토 필요: 원문 내용이 서로 다름 (제목은 Opportunities 섹션, 본문은 Automation 섹션으로 안내) -->

   ![사이드바 메뉴에서 자동화 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028659447/original/orKV6KAQJH00F_V8aVVJZVEQkTXVJbQdbw.jpg?1720021580)

2. **기회 관리** 섹션에서 상태를 바꿀 기회를 찾아요. 검색 필터를 쓰거나 기회 목록을 훑어보면 찾을 수 있어요.

   ![상태를 바꿀 기회 찾기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028660026/original/3s1BiEspJuEX10VIrvdkaECTSwyYYyWCOQ.jpg?1720022043)

3. 기회 카드를 끌면 상태 영역이 바로 나타나요. 바꾸려는 상태 위에 카드를 놓으세요. 카드의 상태가 바뀌고 카드에도 바로 반영돼요.

   ![기회 카드를 끌어 상태 영역에 놓기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028660045/original/hPs59qltVcRYj3xhlpsXwuDpXXJQcuH0yg.jpg?1720022053)

## 옵션 3: 워크플로우로 상태 바꾸기

1. 하이퍼클래스에 로그인한 뒤 사이드바 메뉴에서 **자동화** 섹션으로 이동해요.

   ![사이드바 메뉴에서 자동화 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028655629/original/clZajakW_OG_L5XE4LC6Qhz9XF9AC9KIag.jpg?1720018920)

2. 기회나 리드, 연락처를 관리하는 워크플로우 중에서 기회 상태를 바꾸는 데 쓸 워크플로우가 있다면 열어요. 없다면 새 워크플로우를 만들어요.

   ![기존 워크플로우 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028655648/original/n6P-We0flOadSKcm7ygK914HM84VEbBklw.jpg?1720018936)

3. 워크플로우 트리거를 만들어요. 트리거는 원하는 대로 정할 수 있어요. 어떤 트리거가 발생한 뒤에 기회 상태를 바꾸는 액션이 실행되도록 하는 거예요. 예를 들면 다음과 같아요. 워크플로우 편집 화면은 영어로 표시돼요.
   - **Form submitted**(폼 제출)
   - **Contact Tag Added or Removed**(연락처 태그 추가 또는 제거)
   - **Appointment Booked**(예약 완료)
   - 거래 발생
   - 인보이스 결제 완료
   - 계약서 서명 완료
   - 그 밖의 다양한 트리거

   ![워크플로우 트리거 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028655680/original/LnKZDSD9NXQEd4EhxJAKGLHVROEasAGRxQ.jpg?1720018988)

4. 트리거를 만들었으면 **Create/Update Opportunity**(기회 만들기/업데이트) 액션을 추가해요. 액션 목록에서 찾기 어려우면 검색창에 "opportunity"를 입력해 보세요.

   ![Create/Update Opportunity 액션 추가](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028658761/original/9VqaG7D4UZEpX7QSF58gU06RPVIUUVCMSA.jpg?1720021160)

5. 기회를 옮길 파이프라인과 파이프라인 단계를 골라요. 이 단계에서 기회의 이름, 소스, 리드 가치, 그리고 기회 상태 등 필요한 정보를 바꿀 수 있어요.

   ![액션에서 파이프라인, 단계, 기회 정보 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155028659008/original/Z2KvSjZKnlliUf18Kd-Hw3iB33G62vjVEQ.jpg?1720021241)

기회 상태를 바꿨다면 새 액션을 저장하고 워크플로우 전체도 저장하세요. 저장하지 않으면 지금까지 작업한 내용이 사라질 수 있어요.
