# 기회에 커스텀 필드 사용하기

기회 커스텀 필드를 만들고, 폴더로 정리하고, 필터와 기회 카드에 적용하는 방법을 안내해요. 영업 과정에 맞춰 예산, 마감일, 고객 선호처럼 꼭 필요한 정보를 기회마다 기록하고 싶을 때 사용하세요.

커스텀 필드는 필터링, 리포팅, 파이프라인 설정과도 함께 쓸 수 있어요. 팀이 중요한 기회에 집중하는 데 도움이 돼요.

[동영상](https://www.youtube.com/embed/Ti7BYY47ntM?&wmode=opaque)

---

# 기회 커스텀 필드란?

기회 커스텀 필드를 쓰면 하이퍼클래스가 기본으로 제공하는 필드 외에 영업 파이프라인에 필요한 데이터 항목을 추가하고 관리하고 정리할 수 있어요. 우리 비즈니스만의 영업 과정을 파이프라인에 그대로 담을 수 있어요.

텍스트, 드롭다운, 날짜, 금액 등 다양한 필드 유형을 만들 수 있고, 폴더로 나눠 정리할 수 있어요. 비어 있는 필드를 숨겨서 화면을 깔끔하게 볼 수도 있어요. 만든 필드는 필터링, 리포팅, 자동화에서 사용할 수 있어서 업무 흐름이 간단해져요.

---

# 기회 커스텀 필드의 장점

커스텀 필드를 쓰면 기회를 어떻게 기록하고 정리할지 직접 정할 수 있어요.

- 개인화: 예산, 선호 사항, 상품 정보처럼 우리 비즈니스에 맞는 정보를 기록해요.
- 정리: 필드를 폴더로 묶고 순서를 바꿔서 데이터를 쉽게 관리해요.
- 효율성: '빈 필드 숨기기' 옵션으로 파이프라인 화면을 깔끔하게 유지해요.
- 리포팅 강화: 대시보드, 위젯, 리포트에 커스텀 필드를 넣어 더 깊이 있게 분석해요.
- 필터링: 커스텀 기준으로 기회를 필터링하고 정렬해서 리드의 우선순위를 빠르게 정해요.
- 자동화: 워크플로우, 캠페인, 병합 필드에서 커스텀 필드를 사용해 시간을 아껴요.

# 커스텀 필드 만들고 관리하기

커스텀 필드를 만들고 관리하면 팀이 모든 기회에 꼭 필요한 정보를 빠짐없이 기록할 수 있어요.

### 커스텀 필드 화면 열기

하이퍼클래스에서 **커스텀 필드** 화면으로 가는 방법은 두 가지예요. 두 방법 모두 같은 화면으로 이동하니 편한 쪽을 쓰세요.

**설정에서 열기**

서브 계정 대시보드에서 **설정** 메뉴를 열고 아래로 스크롤해서 **커스텀 필드**를 선택하세요. **커스텀 필드** 화면으로 바로 이동해요.

![설정 메뉴에서 커스텀 필드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054373293/original/1GqOozmZr8R05rcBS02bYcwmABW5_Kvg-g.png?1758625175)

**기회에서 열기**

**기회 관리**(Opportunities)에서 기존 기회를 하나 선택하고 **Add/Manage Fields**(필드 추가/관리)를 클릭하세요. 같은 **커스텀 필드** 화면으로 이동해서, 기회를 보다가 바로 필드를 편집할 수 있어요.

![기회에서 필드 추가/관리 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054373315/original/GbQRrMA_9OgqCGYdKxEYDxnrdnGKI_MFTQ.png?1758625198)

## 새 커스텀 필드 만들기

커스텀 필드를 만들면 영업 과정에 필요한 고유한 정보를 기회 안에 바로 기록할 수 있어요. 고객 예산부터 후속 연락 날짜까지, 중요한 정보를 빠짐없이 관리할 수 있어요.

### 필드 추가

**커스텀 필드** 화면 오른쪽 위에 있는 **+ 필드 추가** 버튼을 클릭하세요. 기회나 다른 오브젝트에 쓸 새 커스텀 필드를 만드는 과정이 시작돼요.

![필드 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054374744/original/bS4xfntd-FcxoDXa0dTIyuGnQaFO1W7cJg.png?1758625895)

### 필드 유형 선택

기록할 데이터에 맞는 필드 유형을 고르세요. 선택할 수 있는 유형은 다음과 같아요.

- 텍스트 입력: **한 줄**, **여러 줄**, **텍스트 박스 목록**
- 값: **숫자**, **전화번호**, **금액**
- 선택: **드롭다운 (단일)**, **드롭다운 (다중)**, **라디오 선택**, **체크박스**
- 날짜/시간: **날짜 선택**
- 기타 입력: **파일 업로드**, **서명**

| **필드 유형** | **사용 예시** |
| --- | --- |
| **한 줄** | 프로젝트 이름이나 고객 회사 이름을 입력해요. |
| **여러 줄** | 고객 요구 사항을 자세히 적어 두어요. |
| **텍스트 박스 목록** | 기회와 연결된 여러 상품 SKU를 기록해요. |
| **숫자** | 전환 확률 점수를 기록해요(예: 80%). |
| **전화번호** | 다른 의사 결정자의 전화번호를 저장해요. |
| **금액** | 고객 예산이나 예상 딜 금액을 저장해요. |
| **드롭다운 (단일)** | 영업 단계를 선택해요(예: 협상, 마무리). |
| **드롭다운 (다중)** | 고객이 관심 있어 하는 상품/서비스를 모두 표시해요. |
| **라디오 선택** | “예산이 승인되었나요?”처럼 예/아니요로 답하는 항목을 기록해요. |
| **체크박스** | 계약서나 규정 준수 문서가 필요한지 표시해요. |
| **날짜 선택** | 후속 연락일, 예상 마감일 같은 주요 날짜를 기록해요. |
| **파일 업로드** | 제안서 파일이나 고객의 RFP 문서를 첨부해요. |
| **서명** | 기회 안에서 바로 서명된 승인을 받아요. |

필드 유형을 골랐다면 **다음**을 클릭해서 커스텀 필드 설정을 이어 가세요.

![필드 유형 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054375370/original/ZNUH2N7b69MRRigSqT6DyeW4Th65JVT_6Q.png?1758626138)

### 기회에 지정하기

필드 이름을 정한 뒤 **오브젝트**를 **기회**로 설정하세요. 그러면 필드가 기회 레코드에만 적용돼요. 모든 항목을 채웠다면 **저장**을 클릭해서 새 커스텀 필드를 만드세요.

**그 밖의 항목**

- **이름**: 커스텀 필드에 표시되는 레이블이에요(예: “고객 예산”).
- **그룹**: 필드를 정리해 둘 폴더나 카테고리예요(예: “예산 정보”).
- **플레이스홀더**: 필드가 비어 있을 때 안에 보이는 안내 문구예요(예: “예상 금액을 입력하세요”).
- **Additional Preferences**(추가 환경설정): 일부 필드 유형에서 쓰는 고급 옵션이에요(예: 기본값, 필수 여부 토글).

**저장** 버튼을 클릭하면 새 기회 커스텀 필드가 만들어져요. 저장한 필드는 파이프라인의 모든 기회 레코드에서 사용할 수 있어요.

{% hint style="info" %}
필드를 **기회**가 아닌 **연락처**로 잘못 지정하면 연락처 레코드에만 나타나고, 파이프라인의 기회에는 보이지 않아요.
{% endhint %}

![기회에 지정하고 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054376449/original/j9cabOyyj4J9ACZ1y84ZRvvPHq5ZpQhTFQ.png?1758626669)

## 폴더 만들기

폴더를 쓰면 여러 커스텀 필드를 비슷한 것끼리 묶어 정리할 수 있어요. 관련 있는 필드를 한곳에 모으면 화면이 덜 복잡해지고, 팀이 기회 안에서 필요한 정보를 더 쉽게 찾고 수정할 수 있어요.

### 폴더 추가

**커스텀 필드** 화면 오른쪽 위에 있는 **폴더 추가** 버튼을 클릭하세요. 관련 있는 필드를 폴더로 묶으면 관리하고 찾기가 쉬워져요.

### 폴더 이름 정하기

폴더 이름을 입력하세요(예: “예산 정보”, “상품 정보”). 이름을 알아보기 쉽게 지으면 팀이 어떤 필드가 들어 있는지 바로 알 수 있어요.

### 객체 선택

**객체 선택**에서 **기회**를 고르세요. 그러면 폴더가 기회 레코드에만 적용돼요. 이 폴더에 만든 필드가 연락처나 다른 오브젝트가 아니라 기회에 나타나도록 해 줘요.

폴더 이름과 오브젝트를 정했다면 **저장**을 클릭하세요.

![폴더 추가 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054379944/original/WAQBiC9X50g1rf85uERvXNw4SQKH5ykh0A.png?1758628211)

## 커스텀 필드 관리하기

커스텀 필드와 폴더를 만든 뒤에는 순서를 바꾸고, 필터링하고, 그룹으로 묶고, 삭제하며 관리할 수 있어요. 이 기능들로 기회를 체계적으로 정리하고 필요한 정보를 쉽게 찾을 수 있어요.

### 오브젝트로 필터링하기

오른쪽 위의 드롭다운에서 **오브젝트 유형**(예: 기회, 연락처, 회사)별로 커스텀 필드를 필터링할 수 있어요. **기회**를 선택하면 기회와 연결된 필드만 보여서, 파이프라인 관리에 필요한 필드에 집중하기 쉬워요.

![오브젝트별 필터링](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054382831/original/mzo5MU_Qeyfhb1GhjAbeM-bpV-sZwRQl0w.png?1758629521)

### 폴더별로 묶어 보기

**그룹 기준** 드롭다운을 사용하면 폴더나 카테고리별로 커스텀 필드를 묶어 볼 수 있어요. 예를 들어 예산과 관련된 필드를 “기회 상세” 아래에 모으거나, 고객이 입력하는 항목을 특정 폼 아래에 모으는 식으로 맥락에 맞게 볼 수 있어요.

![그룹 기준으로 묶어 보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054383098/original/oJQwAGj8bvRdQfQ9kCSxC2ENRgcMt0GgCQ.png?1758629674)

### 일괄 작업

체크박스 메뉴로 커스텀 필드를 여러 개 선택한 다음 **일괄 작업** 메뉴에서 편집, 삭제하거나 다른 폴더로 옮길 수 있어요. 필드를 하나씩 고치지 않고 한꺼번에 처리할 수 있어서 시간이 절약돼요.

![일괄 작업 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054383273/original/-z9GcnpsgtJtCXrGEjrSEXLq2UuRXytvGQ.png?1758629760)

### 필드 순서 바꾸기

드래그 앤 드롭으로 움직일 수 있는 햄버거 아이콘을 사용해 목록에서 커스텀 필드를 위아래로 옮기세요. 기회를 만들거나 편집할 때 필드가 나타나는 순서를 정할 수 있어요.

![드래그 앤 드롭으로 필드 순서 바꾸기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054379234/original/sU7SMNt7svHQQqdv0ccR0OSsu8UQBpz6Qg.gif?1758627952)

# 기회 관리 화면에서 커스텀 필드 사용하기

커스텀 필드는 단순한 데이터가 아니에요. 필터링, 리포팅, 파이프라인 화면과 연결되어 영업 관리를 더 쉽게 해 줘요.

### 상세 필터 열기

**기회 관리** 화면에서 **상세 필터**를 클릭하면 파이프라인에 필터를 적용할 수 있어요. 필터 패널이 열리고, 기본 필드와 직접 만든 기회 커스텀 필드를 모두 사용해 결과를 좁힐 수 있어요.

### 커스텀 필드로 필터링하기

필터 패널에서 아래로 스크롤해 **Opportunities Custom Fields**(기회 커스텀 필드) 섹션을 찾으세요. 이 섹션에는 기존에 있던 필드와 새로 만든 필드를 포함해, 만들어 둔 기회 커스텀 필드가 모두 표시돼요. 파이프라인에서 가장 중요한 데이터를 기준으로 기회를 필터링할 수 있어요.

{% hint style="info" %}
커스텀 필드 필터를 여러 개 조합하면 더 정확한 목록을 만들 수 있어요. 예를 들어 특정 조건을 충족하는 고액 리드를 가려낼 수 있어요.
{% endhint %}

![커스텀 필드로 필터링](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054386717/original/3iXwCA98Td7yCvpET2QOGedWZuO55nO_ow.png?1758631026)

## 기회 카드에 커스텀 필드 표시하기

커스텀 필드는 기회 레코드 안에서만 쓰는 것이 아니에요. 파이프라인 카드에도 표시할 수 있어요. 기회를 하나씩 열어 보지 않아도 중요한 정보를 한눈에 확인할 수 있어서 팀이 더 빠르게 일할 수 있어요.

### 필드 관리 열기

**기회 관리** 화면 오른쪽 위에 있는 **필드 관리** 버튼을 클릭하세요. 기회 카드에 표시할 정보를 조정하는 패널이 열려요.

커스텀 필드를 추가하려면 아래로 스크롤해서 **Add Fields**(필드 추가) 섹션으로 이동하세요.

![필드 관리 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155054389290/original/fwI06PtRXIIDKl8fHgZFCkUuHc5cAalezA.png?1758631844)

### 카드에 커스텀 필드 추가하기

**Add Fields** 아래의 **기회 상세** 섹션을 펼치고, 카드에 추가할 커스텀 필드를 체크하세요. 체크한 필드가 카드에 바로 표시되어 예산, 작업 유형, 고객 선호 같은 정보를 빠르게 확인할 수 있어요.

추가할 커스텀 필드를 모두 골랐다면 패널 아래의 **적용** 버튼을 클릭하세요. 기회 카드에 방금 선택한 필드가 바로 반영돼요.

### 빈 필드 숨기기

기회 카드 안에서 위쪽에 있는 **Hide Empty Fields**(빈 필드 숨기기) 옵션을 볼 수 있어요. 이 옵션을 켜면 값이 있는 필드만 보여서 화면이 깔끔해지고, 꼭 필요한 정보에 집중할 수 있어요.

커스텀 필드를 많이 쓰지만 기회마다 실제로 입력된 필드만 확인하고 싶을 때 특히 유용해요.

# 자주 묻는 질문

### 기회 카드에서 필드 관리로 커스텀 필드를 추가하거나 제거하면 계정의 모든 사용자에게 적용되나요?

아니요. **필드 관리** 패널에서 바꾼 내용은 내 화면의 기회 카드에만 적용돼요. 같은 서브 계정의 다른 사용자는 직접 설정을 바꾸기 전까지 자신이 설정한 레이아웃을 그대로 보게 돼요. 그래서 사용자마다 역할에 가장 필요한 필드를 표시할 수 있어요.

### 기회 커스텀 필드를 삭제하면 기존 데이터는 어떻게 되나요?

커스텀 필드를 삭제하면 필드와 그 안에 저장된 데이터가 모든 기회에서 완전히 사라져요. 이 작업은 되돌릴 수 없어요. 데이터를 잃지 않고 필드만 숨기고 싶다면 삭제하는 대신 폴더로 옮기거나 '빈 필드 숨기기' 옵션을 사용해 보세요.

### 모든 커스텀 필드 유형을 기회 필터링에 쓸 수 있나요?

아니요. 드롭다운, 숫자, 날짜, 텍스트 필드 같은 대부분의 기회 커스텀 필드는 필터링에 쓸 수 있지만, **파일 업로드**와 **서명** 같은 일부 필드 유형은 필터링할 수 없어요. 이런 필드도 기회 레코드에는 표시되지만 **상세 필터** 패널에서는 쓸 수 없어요.

### 자동화나 워크플로우에서 기회 커스텀 필드를 어떻게 사용하나요?

기회 커스텀 필드는 워크플로우에서 트리거, 조건, 액션으로 사용할 수 있어요. 예를 들면 다음과 같아요.

- 커스텀 필드를 자동으로 업데이트해요(예: 리드 활동에 따라 “전환 가능성” 값을 높여요).
- 기회 커스텀 필드 데이터를 불러오는 병합 필드로 개인화된 메시지를 보내요.
- 커스텀 필드가 특정 조건을 충족하면 기회를 새 단계로 옮기는 규칙을 만들어요.

  이렇게 연동하면 커스텀 데이터가 저장만 되는 것이 아니라 파이프라인 자동화를 직접 움직이는 역할을 해요.
