# 병합 필드와 이메일 기본 텍스트 사용하기

병합 필드는 이메일, 메시지, 문서, 워크플로우, 캘린더, 일부 AI 프롬프트에 저장된 정보를 자동으로 넣어 주는 기능이에요. 이 문서에서는 병합 필드를 넣는 방법, 이메일에 값이 비어 있을 때 보여 줄 기본 텍스트를 설정하는 방법, 값이 나오지 않을 때 확인할 사항을 안내해요.

## 병합 필드란?

병합 필드는 내용이 만들어질 때 플랫폼의 기록에서 정보를 가져오는 자리표시자예요. 예를 들어 `{{contact.first_name}}` 같은 토큰은 해당 기록의 정보로 바뀌어요. 어떤 값이 나올지는 해당 작업에서 쓸 수 있는 연락처, 예약, 인보이스, 회사, 서비스 예약 같은 기록이 정해요.

템플릿:

`Hi {{contact.first_name}}, your appointment starts at {{appointment.only_start_time}}.`

생성된 메시지:

`Hi Sarah, your appointment starts at 3:30 PM.`

{% hint style="info" %}
추천: 병합 필드나 커스텀 값 선택기로 필드를 넣으세요. 선택기에는 지금 편집 중인 영역에서 쓸 수 있는 필드만 나와서, 토큰을 직접 입력할 때 생기는 오류를 줄일 수 있어요.
{% endhint %}

---

## 병합 필드의 장점

병합 필드를 쓰면 받는 사람마다 내용을 따로 고치지 않아도 재사용 콘텐츠를 더 개인적으로 만들 수 있어요.

- 개인화: 이름, 날짜, 예약 정보, 인보이스 합계 등 저장된 정보를 자동으로 넣어요.
- 일관성: 정보를 다시 입력하지 않고 플랫폼 기록에서 바로 가져와요.
- 재사용 가능한 템플릿: 메시지 하나, 문서 하나를 여러 수신자에게 그대로 써요.
- 더 빠른 자동화: 워크플로우, 캠페인, 리마인더, 일부 AI 프롬프트에 동적 데이터를 넣어요.

## 병합 필드, 커스텀 필드, 커스텀 값

세 기능은 함께 쓰이지만 역할이 서로 달라요.

| 유형 | 용도 | 예시 |
| --- | --- | --- |
| **커스텀 필드** | 연락처, 기회, 회사 등 지원하는 기록마다 달라질 수 있는 정보를 저장해요. | 선호 서비스 |
| **커스텀 값** | 여러 템플릿에서 똑같이 쓰는 재사용 정보를 저장해요. | 지원 이메일 주소 |
| **병합 필드** | 지원하는 콘텐츠 안에서 표준 필드, 커스텀 필드, 커스텀 값을 가져와요. | `{{contact.first_name}}` |

## 병합 필드가 올바른 데이터를 찾는 방식

병합 필드가 값을 가져오려면 알맞은 기록이 있어야 해요. 필드 자체는 올바르더라도 필요한 기록이나 저장된 값이 없으면 빈칸으로 나올 수 있어요.

- 연락처 필드는 연락처가 있어야 해요.
- 예약 필드는 예약이 있어야 해요.
- 인보이스 필드는 인보이스가 있어야 해요.
- 회사 필드는 연락처에 연결된 회사의 정보를 사용해요.
- 서비스 예약 필드는 서비스 예약이 있어야 해요.
- AI 필드는 대화나 통화 중에 쓸 수 있는 기록에 따라 달라져요.

예를 들어 연락처만 있는 워크플로우에서는 `{{contact.first_name}}`은 채워져도, 이 워크플로우에서 쓸 수 있는 예약이 없으면 `{{appointment.start_time}}`은 빈칸으로 나와요.

원시(raw) 전화번호 형식: `_raw`로 끝나는 필드는 공백, 괄호, 하이픈을 뺀 값을 보여 줘요. 링크, 트래킹 파라미터처럼 형식이 없는 번호가 필요한 곳에서는 raw 전화번호 값을 쓰세요.

## 병합 필드 사용하기

선택기를 쓰면 지금 편집기에서 지원하는 정확한 토큰이 들어가서 형식 오류를 막을 수 있어요.

1. 병합 필드를 지원하는 이메일, 메시지, 워크플로우 액션, 문서, 캘린더 설정, AI 프롬프트 중 하나를 열어요.
2. 개인화된 정보가 들어갈 위치에 커서를 놓아요.
3. **병합 필드**, **커스텀 값**, **{ }** 아이콘 중 하나를 클릭해요.
4. 필드를 검색하거나 카테고리를 열어요.
5. 필드를 선택하면 토큰이 삽입돼요.
6. 토큰 앞뒤 문장이 자연스러운지 확인해요.
7. **변경사항 저장**을 클릭해요.
8. 필요한 데이터가 들어 있는 기록으로 테스트해요.
9. 게시하거나 자동화를 활성화하기 전에 올바른 값이 나오는지 확인해요.

{% hint style="info" %}
팁: 토큰을 직접 입력하거나 복사하지 말고 선택기를 쓰세요. 사용할 수 있는 필드는 제품, 계정 구성, 기록 상황에 따라 달라질 수 있어요.
{% endhint %}

### 워크플로우 텍스트 필드에서 목록 값 서식 지정하기

목록(배열) 값에는 주문 상품 항목이나 인바운드 웹훅으로 받은 데이터처럼 여러 기록이 들어 있을 수 있어요. 워크플로우에서 지원하는 목록 데이터를 쓸 수 있으면, 어떤 필드를 꺼낼지 고르고 워크플로우 텍스트 필드 안에서 그 값을 어떤 모양으로 보여 줄지 정할 수 있어요.

**커스텀 값** 선택기에서 감지된 목록을 선택하면 값이 바로 삽입되지 않고 인라인 서식 지정 창이 나타나요.

서식 지정 창에서 설정할 수 있는 항목은 다음과 같아요.

- **필드**: 목록의 각 항목에서 꺼낼 필드를 선택해요.
- **형식**: 꺼낸 값을 쉼표로 구분한 텍스트, 글머리 기호 목록, 번호 목록 중 하나로 보여 주거나 원하는 구분자를 직접 지정해요.
- **Empty-list fallback**(빈 목록 대체 콘텐츠): 목록이 비어 있을 때 보여 줄 내용을 필요하면 입력해요.
- **미리보기**: 삽입하기 전에 선택한 필드와 서식이 어떻게 보이는지 확인해요.

목록 설정을 마친 뒤 **삽입**을 선택하면 커서 위치에 목록이 들어가요. 서식 규칙은 값과 함께 저장되고, 워크플로우가 실행될 때 그 시점의 목록 데이터로 표시돼요.

텍스트, 숫자, 날짜 같은 단일 값 필드는 지금처럼 바로 삽입돼요.

예시: 인바운드 웹훅이 `sku` 필드가 들어 있는 `line_items` 목록을 전달해요. 이때 `sku`를 선택하고 쉼표로 구분하는 형식을 고른 뒤, 서식이 적용된 목록을 지원하는 워크플로우 텍스트 필드에 삽입할 수 있어요.

![목록 값을 선택해 서식을 지정하고 삽입하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081003042/original/pb3FCmp80TVtp7F_5ByU3xowWPexEc16Wg.gif?1789489398)

## 이메일에 기본 텍스트 추가하기

필드에 저장된 값이 없을 때 이메일에 어색한 빈칸이 생기지 않도록 기본 텍스트를 설정할 수 있어요. 이메일 템플릿, 워크플로우 이메일, 캠페인 이메일, 대량 이메일에서 쓸 수 있고, 제목, 미리보기 텍스트, 본문 모두 지원해요.

1. 이메일을 만들거나 편집해요.
2. 병합 필드 태그를 삽입하거나 이미 넣은 태그를 찾아요.
3. 태그를 클릭해 **기본 텍스트** 편집기를 열어요.
4. 원래 값이 비어 있을 때 보여 줄 텍스트를 입력해요.
5. **저장**을 클릭해요.
6. 해당 필드가 비어 있는 연락처로 테스트 메일을 보내요.

![이메일 병합 필드의 기본 텍스트를 입력하는 기본 텍스트 편집기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079788325/original/ZwqbZCfohuF14VOFVitOafJ4ffJJPiMY8Q.png?1788259727)

예시:

`Hi {{contact.first_name}}, your appointment is confirmed.`

기본 텍스트: `there`

이름이 없으면 이메일에 이렇게 표시돼요.

`Hi there, your appointment is confirmed.`

{% hint style="warning" %}
중요: 기본 텍스트는 해당 병합 필드를 쓴 그 자리에만 적용돼요. 연락처 기록은 바뀌지 않고, 같은 필드라도 이메일 안의 다른 자리에는 다른 기본 텍스트를 쓸 수 있어요.
{% endhint %}

## 병합 필드 문제 해결

병합 필드 문제는 대부분 원본 데이터가 없거나, 필요한 기록이 연결되지 않았거나, 지원하지 않는 위치에 필드를 넣었을 때 생겨요.

| 문제 | 확인할 사항 |
| --- | --- |
| 값이 비어 있어요 | 원본 기록에 데이터가 있는지, 그리고 해당 작업에서 필요한 기록을 쓸 수 있는지 확인하세요. |
| 토큰이 그대로 보여요 | 토큰을 지우고 선택기에서 다시 삽입하세요. 그리고 편집기가 해당 필드를 지원하는지 확인하세요. |
| 엉뚱한 사용자가 나와요 | 해당 작업에서 쓸 수 있는 담당 사용자, 예약 소유자, 발신자를 확인하세요. |
| 회사 필드가 비어 있어요 | 연락처가 올바른 회사에 연결되어 있는지, 선택한 필드에 데이터가 있는지 확인하세요. |
| 이메일 기본 텍스트가 나오지 않아요 | 지원하는 이메일 영역에서 해당 태그에 기본 텍스트를 저장했는지 확인하세요. |
| AI 에이전트가 값을 어색하게 사용해요 | 값이 없을 때의 처리 방법을 지침에 추가하고 프롬프트를 다시 테스트하세요. |

## 자주 묻는 질문

### 모든 편집기에서 병합 필드를 쓸 수 있나요?
<!-- 검토 필요: 원문 질문이 'Are merge fields available in editor?'로 되어 있어 '모든 편집기'로 보완함 -->
아니요. 사용할 수 있는 필드는 제품, 편집기, 활성화된 기능, 권한, 기록 상황에 따라 달라요.

### 병합 필드를 직접 입력해도 되나요?
네, 가능해요. 하지만 선택기는 지원하는 정확한 토큰을 넣어 주기 때문에 더 안전해요.

### 이메일 기본 텍스트를 설정하면 CRM 데이터도 바뀌나요?
아니요. 기본 텍스트는 원래 값이 비어 있을 때 생성되는 이메일만 바꿔요.

### 같은 병합 필드에 서로 다른 기본 텍스트를 쓸 수 있나요?
네, 가능해요. 지원하는 이메일 안에서는 필드를 쓴 자리마다 각각 기본 텍스트를 지정할 수 있어요.

### 회사 필드와 계정 필드는 어떻게 달라요?
회사 필드는 연락처에 연결된 회사의 정보를 가져와요. `{{location.name}}` 같은 계정 필드는 계정의 정보를 가져와요.

### 음성 AI와 대화 AI에서도 병합 필드를 쓸 수 있나요?
네, 지원하는 프롬프트와 메시지 필드에서 쓸 수 있어요. **커스텀 값** 선택기를 사용하고, 시작하기 전에 대화를 테스트해 보세요.

## 도움이 필요하신가요?

병합 필드가 비어 있거나, 토큰이 그대로 보이거나, 예상과 다른 정보가 나온다면 먼저 콘텐츠가 만들어지는 시점에 필요한 원본 기록과 값을 쓸 수 있는지 확인하세요.

추가로 문제를 살펴보기 전에 다음을 확인하세요.

- 원본 필드에 저장된 값이 있어요.
- 해당 작업에서 연락처, 예약, 회사, 인보이스, 서비스 예약 같은 필요한 기록에 접근할 수 있어요.
- 병합 필드를 **병합 필드**, **커스텀 값**, **{ }** 선택기로 삽입했어요.
- 선택한 편집기가 지금 쓰는 병합 필드를 지원해요.
- 올바른 연락처, 담당 사용자, 회사, 예약 등 관련 기록이 해당 작업에 연결되어 있어요.
- 이메일 기본 텍스트를 해당 병합 필드를 쓴 자리에 저장했어요.
- 테스트에 쓰는 기록에 필드를 채우는 데 필요한 정보가 들어 있어요.

문제가 계속되면 하이퍼클래스 고객지원에 문의하기 전에 다음 정보를 모아 두세요. 병합 필드 토큰, 사용한 위치, 원본 기록, 생성된 결과예요. 이 정보가 있으면 데이터 누락, 기록 상황, 필드 지원 여부 중 어느 쪽이 원인인지 확인하는 데 도움이 돼요.
