# 사용자 지정 객체 템플릿으로 CRM 한 번에 설정하기

사용자 지정 객체 템플릿을 쓰면 업종에 맞는 CRM 구조를 처음부터 만들지 않고 바로 시작할 수 있어요. 템플릿마다 바로 쓸 수 있는 사용자 지정 객체, 폴더로 묶인 필드, 연결(Association)이 들어 있어요. 덕분에 실제 업무 흐름에 맞춰 데이터를 더 빨리 정리할 수 있어요. 템플릿은 **템플릿 라이브러리**에서 찾을 수 있고, 적용하기 전에 미리 볼 수도 있어요.

## 사용자 지정 객체 템플릿이란?

사용자 지정 객체 템플릿은 자주 쓰는 업종과 사용 사례에 맞게 미리 만들어 둔 구성이에요. 어떤 오브젝트, 필드, 폴더, 연결을 만들지 직접 정하지 않아도 돼요. 만들어진 구조로 시작한 다음, 내 상황에 맞게 고치면 돼요.

사용자 지정 객체는 연락처, 회사, 기회 같은 기본 CRM 기록에 딱 맞지 않는 비즈니스 데이터를 관리할 때 써요. 템플릿은 흔히 쓰는 업무 흐름을 바탕으로 한 시작점을 주기 때문에 이 설정이 더 빨라져요.

사용자 지정 객체 템플릿은 다른 템플릿 모듈과 함께 **템플릿 라이브러리**에 있어요. 지원하는 업종을 둘러보고, 템플릿 상세 정보를 미리 보고, 사용자 지정 객체를 만들 때 템플릿을 적용할 수 있어요.

## 사용자 지정 객체 템플릿의 장점

사용자 지정 객체 템플릿을 쓰면 구조화된 CRM을 빠르게 시작하면서도 내 업무 방식에 맞게 유연하게 바꿀 수 있어요.

- 빠른 설정: 사용자 지정 객체, 필드, 폴더, 연결을 하나씩 만들 필요 없이 한 번에 만들 수 있어요.
- 업종별 시작점: 부동산, 보험, 자동차, SaaS, 이벤트, 반려동물, 홈 서비스처럼 자주 쓰는 업종에 맞춰 만든 템플릿 중에서 고를 수 있어요.
- 쉬운 데이터 정리: 미리 정의된 필드와 폴더로 관련 정보를 깔끔하게 묶어 둘 수 있어요.
- 기본 제공 관계 설정: 템플릿에 연결이 들어 있을 수 있어서, 회사·기회·사용자 지정 객체 사이에 기록을 이어 줄 수 있어요.
- 적용 전 미리보기: 템플릿을 쓰기 전에 오브젝트, 필드, 연결, 설명, 태그, 사전 요건을 확인할 수 있어요.

## 템플릿 라이브러리 공개 설정

**템플릿 라이브러리**에 공개 설정이 켜져 있으면, 관리자가 어떤 템플릿 모듈이나 카테고리를 사용자에게 보여 줄지 정할 수 있어요. 이 설정으로 **템플릿 라이브러리**를 필요한 내용 위주로 정리할 수 있어요.

{% hint style="info" %}
**템플릿 라이브러리** 접근을 숨기면 보통 새 템플릿을 둘러보거나 가져오는 것이 제한돼요. 이미 템플릿으로 만든 항목은 대개 그대로 편집할 수 있어요.
{% endhint %}

## 사용자 지정 객체 템플릿 적용하기

사용자 지정 객체 템플릿을 적용하면 CRM 설정의 시작점으로 쓸 수 있는 오브젝트 구조가 만들어져요. 적용하기 전에 템플릿을 살펴보면 오브젝트, 필드, 연결이 내 업무 방식과 맞는지 확인할 수 있어요.

1. **설정**으로 이동하세요.

   ![설정 메뉴로 이동](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079786629/original/RjTEWwfJPG0_PQJGUum0K5CSzLfCtW4NkQ.png?1788258989)

2. 왼쪽 메뉴에서 **오브젝트**를 선택하세요.

   ![왼쪽 메뉴에서 오브젝트 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079786716/original/sUvIa9q4UtFUnZBePep2kB8LNcr7phPyCQ.png?1788259015)

3. **Add Custom Object**(사용자 지정 객체 추가)를 클릭하세요.

   ![사용자 지정 객체 추가 버튼 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079786809/original/G0XDMkkWlwfdDE3jbJISj-riNDXl7l4qyA.png?1788259063)

4. **템플릿 사용**을 선택하세요. 템플릿으로 오브젝트를 만들 수 있어요.

   ![템플릿 사용 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070638903/original/UsON-5fBOgckqIoZ7zsZoUBMGQu5V32IUQ.png?1777999475)

5. 사용할 수 있는 사용자 지정 객체 템플릿을 둘러보세요.

   ![사용 가능한 템플릿 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070638921/original/4ir-sFGaMcE8PGiBwAIuPZpnx_--GrfnNg.png?1777999496)

6. 내 업종이나 사용 사례에 맞는 템플릿을 선택하세요.

7. 템플릿 미리보기에서 오브젝트, 필드, 연결, 설명, 태그, 사전 요건을 확인하세요.

8. **Import Objects**(오브젝트 가져오기)를 클릭해 템플릿을 적용하세요.

   ![템플릿을 적용하는 과정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155070639016/original/DFY5s-buwGri012gtNDPmYTCeDxs8gJF_Q.gif?1777999552)

9. 만들어진 사용자 지정 객체를 확인하고, 필요하면 고치세요.

템플릿을 적용한 뒤에는 만들어진 오브젝트, 필드, 연결이 내 업무 흐름에 맞는지 확인해 보세요.

## 템플릿 공개 여부 관리하기 (에이전시 관리자)

에이전시 관리자만 쓸 수 있어요. 사용자 지정 객체 템플릿은 다른 **템플릿 라이브러리** 모듈과 같은 공개 설정을 사용해요.

1. **에이전시 대시보드**의 왼쪽 메뉴에서 **템플릿 라이브러리**를 클릭하세요.
2. 오른쪽 위의 **설정**(톱니바퀴) 아이콘을 클릭하세요.
3. 서브 계정별로 공개 여부를 정하려면 다음과 같이 하세요.
   - **Customize for Sub-Account Settings**(서브 계정 설정별 사용자 지정) 탭으로 이동하세요.
   - 서브 계정을 검색한 뒤 **편집**을 클릭하세요.
   - **템플릿 라이브러리**를 모두 숨기거나, 보여 주거나, 일부 모듈에서만 숨기도록 선택하세요. 숨길 모듈에는 **사용자 지정 객체**도 있어요.
4. 전체 서브 계정에 공통으로 보일 카테고리를 정하려면 다음과 같이 하세요.
   - **카테고리** 탭으로 이동해서 카테고리별로 공개 여부를 켜거나 끄세요(예: 부동산, 보험).

## 자주 묻는 질문

### 사용자 지정 객체 템플릿을 적용하면 기록도 자동으로 만들어지나요?
아니요. 사용자 지정 객체 템플릿은 CRM 구조(사용자 지정 객체, 필드, 폴더, 연결)를 만들도록 설계되어 있어요. 고객 기록이나 샘플 기록은 만들어지지 않아요.

### 템플릿을 적용한 뒤에 편집할 수 있나요?
템플릿으로 만들어진 사용자 지정 객체는 편집할 수 있어요. 가져온 뒤에 만들어진 오브젝트, 필드, 연결을 확인하고 필요에 맞게 고치세요.

### 사용자 지정 객체 템플릿을 적용하면 기존 사용자 지정 객체가 덮어써지나요?
템플릿은 새 구조를 추가하도록 설계되어 있어요. 가져오기 전에 템플릿 미리보기를 확인하고, 가져온 뒤에는 설정이 맞는지 확인하세요.

### 이미 사용한 템플릿을 나중에 숨기면 어떻게 되나요?
템플릿으로 만든 항목은 이후에 새 템플릿을 둘러보거나 가져오는 것이 제한되더라도 대개 계속 편집할 수 있어요.

### 사용자 지정 객체 템플릿에도 연결이 들어 있나요?
네. 템플릿에는 회사, 기회, 사용자 지정 객체처럼 관련된 기록을 이어 주는 연결이 들어 있을 수 있어요.

### 사용자 지정 객체 템플릿에 워크플로우나 샘플 데이터도 들어 있나요?
아직은 포함되어 있지 않아요. 지금은 템플릿이 오브젝트 구조(오브젝트, 필드, 폴더, 연결)에 집중하고 있어요.

### 직접 만든 사용자 지정 객체 템플릿을 저장해서 쓸 수 있나요?
아직은 쓸 수 없어요.

### 지금 지원하는 업종은 무엇인가요?
현재 템플릿은 부동산, 보험, 자동차, SaaS, 이벤트, 반려동물, 홈 서비스를 지원해요.
