# Eliza 에이전트 플랫폼 대시보드

대시보드에서는 모든 서브 계정과 각 서브 계정의 우선순위, 에이전트와 진행 중인 대화 수, 미배정 대화 수를 한눈에 볼 수 있어요.

## 대시보드 개요

![Eliza 에이전트 플랫폼 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48290428723/original/ev-B8m5Dsv5S88zZOw3bXCjEFe3Bt6Izmw.png?1680263628)

### 관리자용 사용자 보기

대시보드 오른쪽에서 관리자는 에이전트 목록과 각 에이전트의 온라인 상태, 에이전트별로 진행 중인 대화 수를 볼 수 있어요.

### 미배정 대화

미배정 대화는 누구의 받은 편지함에도 없고 아무도 처리하지 않고 있는 대화예요. 그래서 특히 주의해서 확인하세요. 관리자나 에이전트가 **이동** 버튼을 눌러, 해당 서브 계정에서 일하도록 지정된 에이전트에게 미배정 대화를 넘길 수 있어요.

### 대화 배정하기

미배정 상태의 대화를 에이전트에게 넘기거나, 한 에이전트의 대화를 다른 에이전트에게 넘기려면 다음 순서로 진행하세요.

1. **이동** 버튼을 클릭하세요.
2. 대화를 보내는 에이전트(또는 미배정)를 선택하세요.
3. 넘길 대화 수를 선택하세요.
4. 대화를 받을 에이전트를 선택하세요.
5. **Assign**(배정)을 클릭하세요.

**Assign**을 클릭하면 대화의 담당자가 바뀌어요.
