# 미디어 저장소의 기본 이미지 편집기

이미지를 자르고, 회전하고, 뒤집고, 세밀하게 조정하는 작업을 **미디어 라이브러리** 안에서 바로 할 수 있어요. 편집한 이미지는 **소셜 플래너**, **퍼널**, **이메일 빌더**에서 곧바로 다시 쓸 수 있어요. 외부 도구 없이 하이퍼클래스 안에서 이미지를 일관되게 관리하고, 중복 파일을 줄이고, 제작 시간도 아낄 수 있어요.

[동영상](https://www.youtube.com/embed/A4tKrd4ICgc?&wmode=opaque)

## 기본 이미지 편집기란?

기본 이미지 편집기는 **미디어 라이브러리**에 들어 있는 가벼운 편집 도구예요. 마케터와 팀이 자주 쓰는 핵심 기능만 담았어요. 파일을 내려받거나 다른 앱을 열지 않고, 게시 직전에 이미지를 다듬을 수 있어요.

**미디어 라이브러리**에서 이미지의 **편집**을 클릭하면 편집 창이 열려요. 편집 창에는 자르기, 회전, 뒤집기, 밝기, 대비 도구와 실행 취소/다시 실행, 저장 옵션이 있어요.

## 기본 이미지 편집기의 장점

- 하이퍼클래스 안에서 작업해요: 외부 도구로 오가지 않아도 돼요.
- 자산을 깔끔하게 관리해요: 이미지를 교체하거나 새 이미지로 저장해서 비슷한 파일이 쌓이는 것을 막아요.
- 브랜드에 맞는 이미지를 쓸 수 있어요: 게시 직전에 조정해서 일관성을 유지해요.
- 저장 공간을 아껴요: 거의 같은 이미지를 여러 번 업로드하지 않아도 돼요.
- 여러 기능에서 바로 쓸 수 있어요: 편집한 이미지는 **미디어 라이브러리**가 나오는 모든 곳(예: **소셜 플래너**, **퍼널**, **이메일 빌더**)에서 바로 사용할 수 있어요.

## 기본 이미지 편집기 사용하기

지원되는 어느 기능에서든 다음 단계를 따르세요.

### 1단계: 편집 창 열기

1. 서브 계정에서 **미디어 저장소**(Media Storage)를 클릭하세요.

   ![서브 계정의 미디어 저장소 메뉴](https://jumpshare.com/share/WQSPYy6VbJaPDVQauwKg+/Screen+Shot+2025-10-06+at+9.36.25+PM.png)
2. 또는 **소셜 플래너**처럼 미디어 라이브러리를 지원하는 기능에서 **Upload from Media Storage**(미디어 저장소에서 업로드)를 클릭하세요.

   ![미디어 저장소에서 업로드를 클릭하는 화면](https://jumpshare.com/share/Xf50G226djyrWgmblP82+/GIF+Recording+2025-10-06+at+9.38.12+PM.gif)
3. 편집할 이미지에 마우스를 올리고 오른쪽 위의 점 세 개 아이콘을 클릭하세요.
4. **편집**을 클릭하세요.

   ![이미지 편집 메뉴 선택 화면](https://jumpshare.com/share/FnB9mNqX9qfhalAbfLmZ+/Screen+Shot+2025-10-06+at+9.42.33+PM.png)

### 2단계: 이미지 편집하기

1. **자르기**로 이미지를 자르세요. 비율은 직접 정하거나 미리 준비된 비율 중에서 고를 수 있어요.
2. 이미지를 가로 또는 세로로 뒤집을 수도 있어요.

   ![이미지를 가로·세로로 뒤집는 화면](https://jumpshare.com/share/WL24n4mgzhDQSyxwVH4Y+/GIF+Recording+2025-10-06+at+9.47.13+PM.gif)
3. 다양한 옵션 중에서 골라 이미지에 **필터**를 적용하세요.

   ![이미지에 필터를 적용하는 화면](https://jumpshare.com/share/tGOTI3l9qz6FycCv5NHV+/GIF+Recording+2025-10-06+at+10.01.08+PM.gif)
4. **Adjustments**(조정)에서 **Brightness**(밝기), **Contrast**(대비), **Saturation**(채도), **Blur**(흐림)를 조절하세요.

   ![밝기, 대비, 채도, 흐림을 조정하는 화면](https://jumpshare.com/share/PKfoPxSsFNAk4b4OFYf5+/GIF+Recording+2025-10-06+at+10.03.23+PM.gif)
5. 이미지에 **문자**를 추가하고 **글꼴 패밀리**, **글꼴 크기**, **정렬**, **글꼴 색상**, **배경 색상**, **줄 간격**을 설정하세요.

   ![이미지에 문자를 추가하고 서식을 설정하는 화면](https://jumpshare.com/share/FG5ghofe7vfFYV5UpYj3+/GIF+Recording+2025-10-06+at+10.18.45+PM.gif)
6. **Stickers**(스티커)에서 **이모지**나 **도형**을 추가하고 **불투명도**와 **색상**을 조절하세요.

   ![이모지와 도형 스티커를 추가하는 화면](https://jumpshare.com/share/hzg3J823FugcO1vZ339P+/GIF+Recording+2025-10-06+at+10.28.31+PM.gif)
7. **Brush**(브러시)로 이미지 위에 그림을 그리고, 브러시의 **Hardness**(경도), **크기**, **색상**을 조절하세요.

   ![브러시로 이미지에 그림을 그리는 화면](https://jumpshare.com/share/GR2tDaKP2JcHaiyJMP2e+/GIF+Recording+2025-10-06+at+11.01.39+PM.gif)
8. **실행 취소**와 **다시 실행** 아이콘으로 이전 작업을 되돌리거나 다시 적용하세요.

   ![실행 취소와 다시 실행 아이콘](https://jumpshare.com/share/sTT4GdCawsZcRlzeoW0c+/Screen+Shot+2025-10-06+at+11.08.21+PM.png)
9. **저장**을 클릭하고 이미지 이름을 입력하세요. 원하면 **Save to Folder**(폴더에 저장)에서 **폴더**를 선택할 수 있어요.
10. **저장**을 클릭하면 **미디어 라이브러리**에 새 이미지로 저장돼요.

    ![편집한 이미지를 새 이미지로 저장하는 화면](https://jumpshare.com/share/6E7Sc6l6Tb1mJXGTrEUZ+/GIF+Recording+2025-10-06+at+11.10.49+PM.gif)

## 자주 묻는 질문

### 모바일 앱에서도 편집기를 쓸 수 있나요?
아직 쓸 수 없어요. 지금은 데스크톱에서만 쓸 수 있어요. 데스크톱에서 편집하고 저장한 이미지는 모바일에서도 볼 수 있어요.

### 어떤 파일 형식을 편집할 수 있나요?
PNG와 JPEG 이미지를 편집할 수 있어요.

### 여러 이미지를 한 번에 편집할 수 있나요?
아직은 안 돼요. 이미지를 하나씩 열어서 편집하세요.
