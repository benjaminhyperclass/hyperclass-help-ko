# 도메인 연결 충돌 방지

도메인이 이미 다른 상품에 연결되어 있으면 새 연결을 막아 주는 기능이에요. 도메인을 연결하다가 오류 메시지가 나왔을 때, 원인을 확인하고 해결하는 데 참고하세요.

하이퍼클래스는 기존 설정이 깨질 수 있는 경우 도메인을 여러 상품 유형에 중복 연결하지 못하게 막아요. 도메인을 새 상품에 연결하기 전에, 이미 다른 상품 유형에서 쓰고 있는 도메인인지 먼저 확인해요. 충돌이 있으면 연결을 막고 자세한 오류 메시지를 보여 줘요. 이 장치는 운영 중인 퍼널, 웹사이트, WordPress, 클라이언트 포탈 같은 연결 상품이 실수로 중단되는 일을 막아 줘요.

## 도메인 충돌 감지 방식

상품에 도메인을 연결하면 하이퍼클래스는 DNS 레코드를 검증하기 전에 먼저 충돌 여부를 확인해요.

도메인이 이미 지원 대상인 다른 상품 유형에 연결되어 있으면 다음과 같이 처리해요.

- 새 연결 시도를 막아요.
- 현재 그 도메인을 쓰고 있는 상품을 알려 줘요.
- 문제 해결 안내를 보여 줘요.
- 해당하는 경우 바로 이동할 수 있는 링크를 제공해요.

예를 들어 도메인이 이미 퍼널에 연결되어 있다면, 같은 도메인을 클라이언트 포탈에 연결하려 할 때 기존 설정이 깨질 수 있어서 막힐 수 있어요.

## 충돌 감지 대상 상품 유형

현재 충돌 감지는 다음 상품 유형에 적용돼요.

- 퍼널
- 웹사이트
- 스토어
- 블로그
- 웨비나
- WordPress
- 클라이언트 포탈
- 브랜드 도메인

이메일 상품은 충돌 확인 대상에서 제외돼요.

## 도메인 충돌 해결

도메인 연결 충돌이 감지되면 오류 메시지에 무엇을 해결해야 하는지 안내돼요. 상황에 따라 도메인 설정을 여는 버튼, 문제 해결 안내, 그 밖의 해결 경로가 함께 표시돼요.

### DNS 레코드 충돌

A, AAAA, CAA 레코드가 충돌하는 경우에도 도메인 연결이 막힐 수 있어요.

오류 메시지에는 문제가 되는 DNS 레코드 유형과, 다시 연결하기 전에 DNS 제공업체에서 무엇을 바꿔야 하는지가 나와요.

자주 발생하는 DNS 충돌은 다음과 같아요.

- A 레코드 충돌: 여러 개의 A 레코드가 연결에 필요한 DNS 레코드와 충돌해요.
- AAAA 레코드 충돌: IPv6 레코드가 연결에 필요한 DNS 레코드와 충돌해요.
- CAA 레코드 충돌: 기존 CAA 레코드 때문에 필요한 SSL 인증서를 발급받을 수 없어요.

해결 방법은 [문제 해결 가이드: 도메인 연결](../Domain-Connect/connecting-your-domain-on-hyperclass-a-guide.md)에서 자세히 확인하세요.

### 같은 서브 계정 안의 충돌

충돌하는 상품이 같은 서브 계정에 있으면, 오류 메시지에 기존 도메인 연결로 바로 가는 링크가 표시될 수 있어요.

이 링크로 다음 작업을 할 수 있어요.

- 현재 설정을 확인해요.
- 필요하다면 기존에 연결된 상품의 연결을 해제해요.
- 필요하다면 다른 도메인을 선택해요.

### 다른 서브 계정과의 충돌

같은 에이전시의 다른 서브 계정에서 충돌이 생긴 경우에는 다음과 같이 처리돼요.

- 연결은 똑같이 차단돼요.
- 바로 이동하는 링크는 표시되지 않아요.
- 오류 메시지에 문제가 무엇인지 나오니, 그 내용을 보고 추가로 확인하세요.

## 알아 두세요

- 충돌 확인은 DNS 검증보다 먼저 이루어져요.
- 도메인 충돌은 에이전시에 속한 모든 서브 계정을 기준으로 감지돼요.
- 기존 도메인 연결은 자동으로 바뀌지 않아요.
- 이메일 상품은 상품 유형 충돌 확인을 일으키지 않아요.

## 자주 묻는 질문

### 이미 사용 중인 도메인을 연결하려고 하면 어떻게 되나요?
연결 시도가 차단되고, 충돌 내용을 설명하는 오류 메시지가 표시돼요.

### 충돌 경고를 무시하고 연결할 수 있나요?
아니요. 기존 충돌을 먼저 해결해야 다음 단계로 진행할 수 있어요.

### 이미 연결되어 있는 도메인에도 영향이 있나요?
아니요. 기존 연결은 직접 변경하지 않는 한 그대로 유지돼요.

### 어떤 오류에는 "여기" 링크가 있는데, 왜 그런가요?
충돌하는 상품이 같은 서브 계정에 있을 때 링크가 표시돼요. 이 링크로 해당 도메인 설정으로 바로 이동할 수 있어요.

### 어떤 충돌에는 링크가 없는데, 왜 그런가요?
같은 에이전시의 다른 서브 계정에서 충돌이 생긴 경우에는 바로 이동하는 링크가 표시되지 않아요.

### 이메일 상품도 충돌 감지에 포함되나요?
아니요. 이메일 관련 상품은 이 확인에서 제외돼요.
