# 관리자와 사용자 역할별 권한 범위

에이전시와 서브 계정에서 각 역할이 어떤 권한을 갖는지 정리한 문서예요. 어떤 기능을 에이전시에서만 쓸 수 있는지, 서브 계정에서만 쓸 수 있는지, 둘 다에서 쓸 수 있는지 확인할 때 참고하세요.

## 서브 계정 수준 사용자 역할

## 권한 한눈에 보기

| 에이전시 전용 | 서브 계정 전용 | 둘 다 사용 가능 |
| --- | --- | --- |
| 서브 계정 만들기 / 편집 / 삭제 | 파이프라인 & 기회 | **사용자 관리**(관리자는 자기 수준 안에서 사용자를 추가·편집할 수 있어요) |
| SaaS 모드 및 재판매 관리 | 워크플로우 / 캠페인 | 대시보드 리포팅 |
| 글로벌 연동(Mailgun, Twilio 재청구, Google API 등) | 캘린더 및 예약 설정 | **미디어 라이브러리** |
| 스냅샷 관리 | 대화(SMS, 이메일, 채팅) | 감사 로그 |
| 에이전시 수준 청구 및 브랜딩 | 연락처 관리 및 스마트 리스트 | |
| **에이전시 설정**(회사 정보, **재청구 설정**) | **평판 관리** | |
| 화이트라벨 설정(**사용자 지정 도메인**, 로고, 색상) | 퍼널 & **웹사이트 빌더** | |

{% hint style="info" %}
표에 없는 권한은 해당 수준에서 더 넓은 역할의 기본 권한을 그대로 따른다고 보면 돼요.
{% endhint %}

## 사용자 역할 바꾸기

관리자는 다음 순서로 특정 사용자의 역할을 바꿀 수 있어요.

1. **설정 > 스태프 관리**로 이동하세요.
2. 역할을 바꿀 사용자의 **편집**(연필 아이콘)을 클릭하세요.
3. 아래로 스크롤해서 **사용자 역할**을 펼치세요.

![사용자 역할 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155018238329/original/SO6U66a5eqB-L00Pot42Kknck7OO6w0K8Q.png?1705709967)

## 자주 묻는 질문

### 에이전시와 서브 계정 양쪽에서 쓸 수 있는 권한이면, 에이전시 관리자가 서브 계정 관리자보다 우선하나요?

네. 에이전시 관리자는 전체에 대한 권한을 가져요. 사용자 관리, 리포팅, 미디어 라이브러리 같은 권한은 에이전시 관리자가 한 작업이 모든 서브 계정에 적용돼요. 서브 계정 관리자는 자신에게 배정된 서브 계정 안에서만 관리할 수 있어요.

### 에이전시 수준에서 추가한 사용자에게 서브 계정 접근 권한도 주면 어떻게 되나요?

그 사용자는 두 가지 역할 범위를 갖게 돼요. 에이전시 역할에 따른 에이전시 전체 접근 권한과, 서브 계정 역할에 따른 해당 서브 계정 전용 접근 권한이에요. 두 권한은 서로 상쇄되지 않고 합쳐져요. 겹칠 때는 더 넓은 에이전시 권한이 항상 우선해요.

### 에이전시 관리자는 모두 로그인 기능을 쓸 수 있나요?

아니요. **로그인**은 에이전시 수준의 **Enable Login As**(로그인 활성화) 권한으로 제어돼요. 관리자에게 이 권한이 꺼져 있으면 그 사용자에게는 **로그인** 옵션이 보이지 않아요.
