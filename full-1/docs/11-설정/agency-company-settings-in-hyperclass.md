# 에이전시 회사 설정 살펴보기

에이전시의 이름·이메일·로고를 바꾸고, 사용자 지정 코드를 넣고, AI나 고급 트리거 같은 기능을 켜고 끄는 방법을 안내해요. 업데이트된 화면의 모든 탭과 옵션을 차례대로 살펴봐요.

{% hint style="info" %}
에이전시 관리자만 쓸 수 있는 설정이에요.
{% endhint %}

## 회사 설정으로 할 수 있는 일

에이전시 아래 모든 계정에서 전문적이고 일관된 환경을 제공할 수 있어요.

- 로그인 포털과 화면의 브랜딩을 원하는 대로 바꿔요.
- 에이전시 전체에 적용되는 연락처 정보와 주소를 관리해요.
- 사용자 지정 코드(JS/CSS)를 넣어 플랫폼의 모양과 동작을 조정해요.
- AI 직원, 프리미엄 트리거 같은 고급 도구를 켜고 꺼요.
- 화이트라벨 도메인과 API 도메인을 설정해 브랜딩을 통일해요.
- 세션 타임아웃, 시간대, 고객에게 보이는 경험 설정을 조정해요.

---

## 회사 설정은 무엇이고 어디에서 찾나요?

**회사 설정**(Company Settings)은 모든 서브 계정에 적용되는 에이전시의 정체성, 브랜딩, 전체 플랫폼 설정을 한곳에서 관리하는 화면이에요. 로고와 로그인 도메인 설정부터 워크플로우 AI, 템플릿 라이브러리 같은 도구를 켜는 일까지 모두 여기에서 시작해요. **에이전시 대시보드**에서 아래 순서로 찾아가세요.

1. 왼쪽 아래 탐색 메뉴에서 **설정** 톱니바퀴 아이콘을 클릭하고, 위쪽의 **회사** 탭을 선택하세요.

   ![설정 > 회사 탭 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044335355/original/3d3Wy3s1-BXE8ZNtznjKbzmuN420TfZ_6Q.png?1743516057)

2. 아래에서 자세히 설명하는 세 가지 주요 탭을 확인하세요.

   ![회사 설정의 세 가지 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044341926/original/oN3SPV9ZRauASt7OzRiJQpL4JKXE2s8s0w.jpeg?1743521854)

   1. **기본 정보** – 핵심 비즈니스 정보, 위치, 에이전시 전체 기능을 켜고 끄는 토글
   2. **Whitelabel**(화이트라벨) – 로고, 도메인, 법적 정책 링크, 사용자 지정 코드를 이용한 스타일 설정
   3. **고급 설정** – 보안 설정, 세션 타임아웃, 온보딩 최적화 도구

## 1부. 기본 정보 탭

**기본 정보** 탭에서는 하이퍼클래스 안에서 에이전시의 기본 정체성을 설정해요. 비즈니스 이름과 업종, 연락처, 기능 토글이 모두 여기에 있고, 플랫폼 전반에서 에이전시의 인상을 결정해요.

### 1. 회사 정보와 정체성

에이전시 이름, 연락처, 웹사이트 같은 기본 정보를 업데이트하면 플랫폼 전체에서 브랜딩이 일관되게 유지돼요. 이 항목들은 로그인 포털, 이메일 템플릿, 시스템이 만드는 메시지처럼 고객에게 보이는 곳에 표시돼요.

- **회사명**, **Email**(이메일), **Phone**(전화번호) – 헤더, 이메일, 시스템 요소에 쓰이는 대표 비즈니스 정보예요.
- **웹사이트 URL** – 신뢰도를 높여 주고, 화이트라벨 환경에서 참조돼요.
- **비즈니스 카테고리**와 **Niche**(세부 업종) – 하이퍼클래스 기능을 업종에 맞게 조정하는 데 도움이 돼요.
- **Usage Type**(사용 유형) – 에이전시인지, 하이퍼클래스를 직접 사용하는 비즈니스인지 정해요.

![회사 정보 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044336977/original/kcnSKPrTmWR5gtCQVIk18ws0NzzZo8o0Ow.png?1743517306)

### 2. 회사 주소와 시간대

- **Address**(주소), **City**(도시), **State**(주/도), **Zip**(우편번호), **Country**(국가) – 시스템 템플릿과 규정 준수에 쓰여요.
- **시간대** – 자동화 타이밍, 워크플로우 로그, 캠페인 정확도에 영향을 줘요.

![회사 주소와 시간대 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044337060/original/Iv5JRQ45GcaBIDmN5nSL6vhC7f9Kg3cNZg.png?1743517393)

### 3. 기능 토글

에이전시 수준의 도구와 자동화 보조 기능을 켜거나 끌 수 있어요.

- **AI 직원** – 반복 작업을 맡아 주는 스마트 어시스턴트예요. 자세한 내용은 [AI 직원 개요](../13-AI-Employee/AI-Employee/ai-employee-access-rebilling-and-reselling.md)를 참고하세요.
- **워크플로우 - 외부 AI 모델** – 워크플로우에 AI 로직을 넣어요. 자세한 내용은 [워크플로우 AI를 켜고 재청구하는 방법](../16-SaaS-설정/Saas-Mode/how-to-enable-and-rebill-workflow-external-ai-models.md)을 참고하세요.
- **주소 자동완성** – 고객이 폼을 더 편하게 쓸 수 있어요. 자세한 내용은 [주소 자동완성 사용 및 재청구 방법](../06-사이트/폼/how-to-use-address-auto-complete-in-hyperclass-forms-and-surveys.md)을 참고하세요.
- **워크플로우 - 프리미엄 기능** – 워크플로우에서 프리미엄 트리거와 액션을 쓸 수 있어요. 자세한 내용은 "워크플로우용 프리미엄 트리거 & 액션을 켜고 재청구하는 방법" 문서를 참고하세요.
- **도메인 구매** – 고객이 플랫폼 안에서 도메인을 살 수 있어요. 자세한 내용은 [도메인 구매 활성화 및 재청구 방법](how-to-enable-and-rebill-domain-purchases.md)을 참고하세요.
- **템플릿 라이브러리** – 퍼널, 웹사이트, 템플릿을 공유해요. 자세한 내용은 [템플릿 라이브러리 개요 및 설정](../10-마케팅/template-library-overview-setup.md)을 참고하세요.

## 2부. Whitelabel 탭

**Whitelabel** 탭에서는 고객에게 보이는 환경의 브랜딩을 자유롭게 바꿀 수 있어요. 로고를 추가하고, 내 도메인을 쓰고, 법적 정책을 갖춰 두세요.

### 1. 로고와 브랜딩

에이전시 로고를 올리면 로그인 화면, 앱 헤더, 시스템이 보내는 이메일처럼 고객에게 보이는 주요 위치에 표시돼요. 선명하고 전문적인 로고는 플랫폼 전반에서 브랜드 이미지를 높여 줘요.

- 권장 로고 크기: 350px × 180px, 용량은 2.5MB 이하
- 로고가 표시되는 곳:
  - 로그인 화면
  - 앱 헤더
  - 알림 이메일
  - 일부 위젯과 폼 하단

![로고 업로드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044339561/original/wyTbWYDKlajOFOaNZrPuaqX25oVntcJa0Q.png?1743519515)

### 2. 파비콘과 적용 위치

**파비콘**은 브라우저 탭과 링크 미리보기에 나타나는 작은 아이콘이에요. 하이퍼클래스는 사이트, 클라이언트 포탈, 멤버십/코스 사이트에서 파비콘을 지원해요. 아래에서 어디에 파비콘을 설정하고 어떻게 표시되는지 확인하세요.

- **에이전시 전체 파비콘:** 현재 **회사 설정 > Whitelabel**에는 에이전시 전체에 적용되는 파비콘 업로드가 따로 없어요. 아래의 항목별 옵션을 사용하세요.
- **웹사이트 & 퍼널:** 사이트 빌더에서 파비콘을 설정하면 사이트의 모든 페이지에 표시돼요. **경로:** 서브 계정 > **사이트** > 사이트 열기 > **Site Settings**(사이트 설정) > **파비콘**

  ![사이트 설정의 파비콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063042732/original/_V-A498nab8v9MEzWdP2HEbFfAmFX5luuQ.png?1768905210)

- **클라이언트 포탈:** 서브 계정별 클라이언트 포탈의 파비콘을 브랜드에 맞게 바꿔요. **경로:** 서브 계정 > **클라이언트 포탈** 설정 > **브랜딩** > **파비콘**

  ![클라이언트 포탈 파비콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063043042/original/o8DTwi0iNkDNknSHRzgM5Xuz0pOGLTX2eg.png?1768905284)

- **멤버십:** 테마 커스터마이저에서 코스 사이트의 파비콘을 바꿔요. **경로:** 서브 계정 > **멤버십 > 코스** > **파비콘**

  ![코스 사이트 파비콘 위치](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155063043295/original/NeeLAZjU2qhgGfPKxjD5nD0LchRIzdUgRQ.png?1768905420)

### 3. 사용자 지정 도메인

내 도메인을 설정하면 로그인 환경과 링크 추적까지 완전히 화이트라벨로 만들 수 있어요. 이 도메인을 쓰면 고객과 주고받는 화면과 링크에서 하이퍼클래스 기본 브랜딩이 사라지고, 신뢰도와 전문성이 높아져요.

- **Whitelabel Domain**(화이트라벨 도메인) – 데스크톱 로그인 포털에 쓰는 브랜드 도메인이에요. 자세한 내용은 [데스크톱 웹 앱용 화이트라벨 도메인 설정 방법](../25-애드온-세일즈/Whitelabel-Desktop-App/how-to-set-up-a-whitelabel-domain-for-the-desktop-web-app.md)을 참고하세요.
- **API Domain**(API 도메인) – 에이전시와 서브 계정 수준에서 브랜드(API) 도메인을 설정해, 하이퍼클래스가 만드는 시스템 링크를 내 브랜드로 바꿔요. 자세한 내용은 [시스템 생성 링크 브랜딩(API 도메인)](branding-system-generated-links-api-domain.md)을 참고하세요.

![사용자 지정 도메인 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044339622/original/jTYvfdGNgSGxMssSBWjrQSVZeYDPoXPd8g.png?1743519570)

### 4. 정책 URL

에이전시의 개인정보처리방침과 이용약관 링크를 연결하면 법적 규정을 지키고 투명성을 높일 수 있어요. 이 링크는 필요한 위젯, 폼, 로그인 페이지에 표시돼요.

- **개인정보처리방침 URL** – 대부분의 외부 공개 위젯에서 규정 준수를 위해 필요해요.
- **이용약관 URL** – 고객이 이용 의무를 이해하는 데 도움이 돼요.

자세한 내용은 [GDPR 규정 준수 및 데이터 개인정보 보호](../25-애드온-세일즈/Compliance/gdpr-compliance-and-data-privacy.md)를 참고하세요.

### 5. 사용자 지정 코드(JS & CSS)

사용자 지정 코드로 에이전시 대시보드의 스타일을 바꾸고, 외부 도구나 맞춤 로직을 추가할 수 있어요.

- **Custom JavaScript**(사용자 지정 JavaScript): 라이브 채팅 위젯, Google Analytics, 트래킹 픽셀 등에 써요.
- **사용자 지정 CSS**: 플랫폼 스타일을 바꾸고, 요소를 숨기고, 브랜딩을 조정할 때 써요.

![사용자 지정 코드 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044341106/original/o8YYWXWkJICkEPe8mR4tZWoibxolM50Gow.png?1743521010)

{% hint style="warning" %}
사용자 지정 JS/CSS는 활용도가 높지만 공식 지원 대상이 아니에요. 하이퍼클래스 핵심 화면을 바꾸면 작성한 코드가 깨질 수 있으니 항상 충분히 테스트하세요.
{% endhint %}

### 사용자 지정 CSS: 바꿀 수 있는 것과 없는 것

사용자 지정 CSS로 하이퍼클래스 화면의 모양과 느낌을 조정할 수 있어요. 어떤 항목이 지원되고 어떤 항목이 안 되는지 알아 두세요. 아래에 안전하게 바꿀 수 있는 항목, 활용 예시, 피해야 할 영역을 정리했어요.

#### 바꿀 수 있는 항목

고객에게 보이는 요소와 대시보드 요소의 스타일은 안전하게 조정할 수 있어요.

##### 로그인 페이지

```
/* Change login button color */ .login__button {  background-color: #2E86C1 !important; }
 /* Resize login logo */ .login__logo img {  max-height: 80px !important; }
```

##### 에이전시/계정 사이드바

```
/* Hide Opportunities tab */ .hl_navItem[data-id="opportunities"] {  display: none !important; }
 /* Change sidebar background */ .hl_sidebar {  background: #1F2937 !important; }
```

##### 헤더 바

```
/* Change top header background */ .hl_topHeader {  background: #111827 !important; }
```

##### 캘린더 및 폼 위젯

```
/* Adjust form field styling */ .hl_formField input {  border-radius: 8px !important;  border: 2px solid #2E86C1 !important; }
```

##### 퍼널 및 웹사이트

- 퍼널의 각 단계에는 자체 CSS 패널이 있어요.
- 글로벌 CSS 패널은 모든 단계에 적용돼요.

---

#### 바꿀 수 없는(또는 바꾸지 말아야 할) 항목

아래 영역에는 CSS를 적용하지 마세요. 오류가 생기거나 업데이트 후 깨질 수 있어요.

- 모바일 앱(iOS/Android) — CSS를 지원하지 않아요.
- React 팝업(예: 결제 모달)
- 백엔드에서 생성하는 PDF 인보이스/영수증
- 드래그 앤 드롭 빌더의 핵심 화면(업데이트 후 요소 위치가 달라질 수 있어요.)
- 안정적인 class나 data-id가 없는 요소

{% hint style="warning" %}
플랫폼이 업데이트될 때마다 Chrome DevTools로 CSS를 다시 확인하세요. 지원되지 않는 덮어쓰기는 작동하지 않을 수 있고, 빈 화면이나 레이아웃 깨짐이 생길 수 있어요.

**사용자 지정 CSS** 편집기에 붙여 넣을 때는 항상 규칙을 `<style>...</style>`로 감싸세요.
{% endhint %}

1. 하이퍼클래스 대시보드에서 바꾸려는 요소를 마우스 오른쪽 버튼으로 클릭하세요.
2. **Inspect**(검사)를 선택해 Chrome DevTools를 여세요.
3. 선택자(selector)를 복사하세요.
4. **회사 설정 > Whitelabel > 사용자 지정 CSS**에 붙여 넣으세요.
5. **변경사항 저장**을 클릭하세요.

## 3부. 고급 설정

**고급 설정** 탭에서는 에이전시 계정을 보호하고, 세션 동작을 관리하고, 고객 온보딩 경험을 개선할 수 있어요. 주요 생산성 기능, 얼리 액세스 도구, 플랫폼 보안 설정을 켜고 끄는 토글이 있고, 에이전시와 서브 계정 모두에 영향을 줘요.

이 영역을 알맞게 설정하면 무단 접근을 막고, 고객의 사용 경험을 높이고, 에이전시 운영을 더 매끄럽게 할 수 있어요.

**활용 사례 표**

| 기능 | 활용 사례 | 권장 사용법 |
| --- | --- | --- |
| **강화된 보안** | 에이전시와 고객 데이터 보호 | 레거시 API를 쓰지 않는다면 항상 켜 두세요 |
| **Session Timeout**(세션 타임아웃) | 공용 기기에서 노출 위험 줄이기 | 대부분의 에이전시는 30~60분을 선택하세요 <!-- 검토 필요: 원문 내용이 서로 다름 --> |
| **NPS Survey**(NPS 설문) | 고객 만족도 파악 | 서비스 중심 에이전시라면 켜 두세요 |
| **Product Guides**(상품 가이드) | 고객 온보딩 업무 줄이기 | 새 SaaS 고객을 온보딩할 때 알맞아요 |
| **Daily Updates**(일일 업데이트) | 리드 후속 조치 독려 | 부동산이나 영업 중심 고객에게 좋아요 |
| **Beta Features**(베타 기능) | 출시 전 도구를 먼저 사용 | 적극적으로 테스트할 준비가 되었을 때만 켜세요 |

**기본 개인 캘린더 생성 제어하기**

**Preloaded Example Data**(미리 채워진 예시 데이터) 설정으로, 서브 계정에 새로 추가되는 사용자에게 개인 예약 캘린더를 자동으로 만들어 줄지 정할 수 있어요.

- **Preloaded Example Data**가 켜져 있으면 새 사용자에게 개인 예약 캘린더가 계속 자동으로 만들어져요.
- **Preloaded Example Data**가 꺼져 있으면 새로 추가된 사용자에게 개인 예약 캘린더가 자동으로 만들어지지 않아요.
- 이 변경은 설정을 바꾼 뒤에 추가된 사용자에게만 적용돼요.
- 이미 있는 캘린더는 바뀌지 않아요.

스냅샷이나 체계적인 캘린더 구성을 쓰는 에이전시, 개인 캘린더가 필요 없는 팀원이 있는 에이전시에 유용해요.

### 1. 강화된 보안

**강화된 보안**을 켜면 무단 API 접근 위험을 줄이고 에이전시 데이터를 보호할 수 있어요. 개발자나 외부 앱이 API로 플랫폼과 연동하는 에이전시에 특히 중요해요.

켜면 이렇게 돼요.

- 레거시 API 키가 자동으로 생성되지 않아요.
- 민감한 API 엔드포인트에 대한 CRUD 접근이 제한돼요.
- 열린 접근 때문에 생길 수 있는 실수로 인한 데이터 유출을 막아요.

자세한 내용은 [강화된 계정 보안](../35-개발자/Developer-Resources/enhanced-account-security.md)을 참고하세요.

![강화된 보안 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044341172/original/MpCl51t2fT5IplW1Hp6bAosQy4-8JtyWkg.png?1743521103)

### 2. Session Timeout(세션 타임아웃)

활동이 없을 때 사용자가 하이퍼클래스에 로그인된 상태로 얼마나 있을 수 있는지 정해요. 정해 둔 시간이 지나면 활동이 없는 사용자를 자동으로 로그아웃시켜 에이전시 플랫폼 접근을 안전하게 지켜 줘요.

보통 선택할 수 있는 옵션은 다음과 같아요.

- 15분
- 1시간
- 4시간
- 8시간
- 12시간
- 1일
- 2일
- 3일
- 만료 없음

여럿이 함께 쓰는 사무실이나, 공용 기기 또는 팀 기기에서 하이퍼클래스에 접속할 때 특히 유용해요.

![세션 타임아웃 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155044341213/original/D0slylH8_qbz_Dqyq6A7UJAQ6ICuj_WaeA.png?1743521145)

### 3. Optimize Experience(경험 최적화) 설정

온보딩, 참여, 피드백 수집을 돕는 고객용 도구를 켜거나 끄는 영역이에요. 이 도구들은 고객이 플랫폼을 이해하고 더 빨리 행동하도록 도와줘요.

자세한 내용은 [경험 최적화 기능](에이전시-설정/optimize-experience-features.md)을 참고하세요.

## 자주 묻는 질문

### 어떤 설정이 고객 경험에 가장 큰 영향을 주나요?
**Whitelabel**과 **Optimize Experience** 영역이 고객이 보고 사용하는 화면에 직접 영향을 줘요.

### 로그인과 시스템 링크에 서로 다른 도메인을 쓸 수 있나요?
네. **Whitelabel Domain**은 로그인 포털을, **API Domain**은 SMS/이메일의 추적 링크를 제어해요.

### 강화된 보안을 켜야 하나요?
네, 외부 도구에 레거시 API 키를 쓰는 경우가 아니라면 켜세요. 켜 두는 것이 데이터 안전에 가장 좋아요.

### 사용자 지정 글꼴이나 UI 색상 테마를 올릴 수 있나요?
**Whitelabel** 탭의 사용자 지정 CSS로만 할 수 있어요.

### 에이전시 수준에서 로그인 포털, 모든 서브 계정, 모든 사이트에 적용되는 파비콘을 하나만 올릴 수 있나요?
아니요, 현재는 할 수 없어요. 필요에 따라 사이트, 클라이언트 포탈, 멤버십/코스 수준에서 각각 파비콘을 올리세요.

### 파비콘을 올렸는데 보이지 않아요. 어떻게 해야 하나요?
브라우저 캐시를 지우고, 시크릿 창에서 URL을 열어 보세요. 이미지가 정사각형이고 32×32px 이상인지도 확인하세요.

사이트라면 **Site Settings**(사이트 설정) > **파비콘**에 저장됐는지 확인하세요. 클라이언트 포탈이나 코스라면 각각의 브랜딩/테마 영역에 파비콘이 저장됐는지 확인하세요.
