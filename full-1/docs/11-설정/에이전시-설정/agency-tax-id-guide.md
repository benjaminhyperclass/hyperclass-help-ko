# 에이전시 세금 ID 안내

하이퍼클래스는 세금 의무를 이행하기 위해 전 세계 고객의 세금 ID 번호를 수집하기 시작했어요. 이 문서에서는 에이전시의 세금 정보를 업데이트하는 방법과, 국가별로 알맞은 세금 ID 유형을 고르는 방법을 안내해요.

{% hint style="info" %}
부가가치세(VAT)
조직이 유럽연합, 노르웨이, 튀르키예, 영국에 있다면 구독이나 갱신 같은 구매 금액에 부가가치세(VAT)가 붙어요. 인보이스에는 세금이 별도 항목으로 표시돼요.

VAT 면제
사업자로 등록되어 있다면 이후 구매에서 VAT가 면제될 수 있어요(리버스 차지가 적용될 수 있어요). 이렇게 하려면 **에이전시 설정 > 청구/결제 > 결제** 페이지에 유효한 VAT ID를 입력해야 해요.
{% endhint %}

## 세금 ID 업데이트하기

1. **에이전시 설정 > 청구/결제 > 결제** 페이지로 이동해 세금 ID 정보를 확인해요.

   ![에이전시 설정의 결제 페이지에서 세금 ID 정보를 확인하는 화면](https://jumpshare.com/share/RY1EuputfiVESeSdNQds+/Screen+Shot+2026-08-14+at+18.54.53.png)
2. **편집** 버튼을 선택해 세금 ID 정보 수정을 시작해요.

   ![편집 버튼을 선택하는 화면](https://jumpshare.com/share/NBs3pWcCCPg6j5tW0S83+/Screen+Shot+2026-08-14+at+18.56.18.png)
3. 나타나는 **Tax ID**(세금 ID) 팝업에서 아래 두 가지를 해요.

   1. 지역에 맞는 **Tax ID Type**(세금 ID 유형)을 선택하세요. 국가별로 맞는 지역을 고르는 방법은 아래에서 자세히 안내해요.
   2. **Tax ID** 번호를 입력하세요.
4. **저장**을 선택해요.

   ![세금 ID 팝업에서 유형과 번호를 입력하고 저장하는 화면](https://jumpshare.com/share/lGtNZIzbAOhxkhEmPBw0+/Screen+Shot+2026-08-14+at+18.58.32.png)

{% hint style="info" %}
다음 중 하나에 해당하면 **I do not have a Tax ID**(세금 ID가 없습니다) 체크박스를 선택하세요.

- 세금 ID는 있지만 아래 목록에 없어요.
- 세금 ID 번호가 없어요.
- 세금 ID를 공개하고 싶지 않아요.

세금 ID가 여러 개라면 하이퍼클래스 고객지원에 문의해 어떤 ID를 써야 하는지 확인하세요. 예를 들어 "ca_bn", "ca_gst_hst", "ca_pst_bc"가 모두 있다면, 고객지원에서는 "ca_gst_hst" ID를 사용하라고 안내해요. HST와 PST를 모두 면제받을 수 있는 ID는 이것뿐이기 때문이에요.
{% endhint %}

## 올바른 세금 ID 유형 고르기

하이퍼클래스는 전 세계에서 쓰는 모든 세금 ID 유형을 지원해요. 다만 **Tax ID Type** 선택지는 지역 단위로 나뉘어 있어요. 막힘없이 세금 정보를 업데이트하려면 세금 ID가 등록된 지역을 정확히 알아야 해요. 올바른 지역을 선택한 뒤 국가 단위의 세금 ID 번호를 입력하면, 국가별 세금 ID 유형은 자동으로 확인돼요.
