# 에이전시 주소 바꾸기

에이전시 주소를 최신 상태로 유지하면 청구와 연락, 대외 표시 정보가 하이퍼클래스 전체에서 정확하게 유지돼요. 이 문서에서는 에이전시 주소를 수정하는 방법을 순서대로 안내해요.

{% hint style="info" %}
에이전시 관리자 권한이 있는 사용자만 에이전시 주소를 바꿀 수 있어요.
{% endhint %}

## 에이전시 주소를 최신으로 유지하면 좋은 점

에이전시 주소가 정확해야 하는 이유는 다음과 같아요.

- 정확한 청구: 인보이스와 재무 문서가 올바른 주소로 전달돼요.
- 원활한 소통: 고객과 파트너에게 오는 우편물과 연락이 제때 정확하게 도착해요.
- 전문적인 이미지: 고객에게 보이는 자료에 실제 사업장 위치가 올바르게 표시돼 신뢰도가 높아져요.
- 규정 준수: 사업 운영에 필요한 법적·규제 요건을 충족할 수 있어요.

---

## 에이전시 주소 수정하기

하이퍼클래스에서 에이전시 주소를 수정하는 과정은 간단해요. 아래 순서대로 설정 화면으로 이동해 회사 주소를 바꿔 보세요.

### 1단계: 에이전시 보기로 이동

사이드바 왼쪽 위에 있는 드롭다운 메뉴를 클릭하고 **에이전시 보기로 전환**을 선택하세요.

![에이전시 보기로 전환 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043665310/original/LJngO5SoNSjl18vzd5OCJIu8WGyfjP3NkA.png?1742474366)

### 2단계: 에이전시 설정 열기

사이드바 맨 아래에 있는 **설정** 아이콘을 클릭하세요.

![사이드바 아래쪽 설정 아이콘](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043665486/original/69X9bgaiozPaDGalqjyQXjwoJNonpdUZJw.png?1742474472)

### 3단계: 회사 탭 열기

**설정** 메뉴의 사이드바에서 **회사** 탭을 클릭하세요.

![설정 메뉴의 회사 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043665756/original/8qi-dZC4naDmRhikmGTwaNTu0jSZb_E_uA.png?1742474574)

### 4단계: 회사 주소 수정

1. 화면 오른쪽에서 **회사 주소** 섹션을 찾으세요.
2. 새 정보를 각 필드에 입력하세요. 입력할 항목은 **Address**(주소), **City**(시/도시), **Zip Code**(우편번호), **State**(주/도), **Country**(국가), **Timezone**(시간대)이에요.
3. **변경사항 저장** 버튼을 클릭해 수정 내용을 적용하세요.

![회사 주소 입력 후 변경사항 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043665877/original/4VRHm-5NN8Qrh1zQ0dyYUwZX3hgcMSYkvw.png?1742474665)

## 자주 묻는 질문

### 에이전시 주소를 바꾸려면 특별한 권한이 필요한가요?

네, 에이전시 관리자 수준의 권한이 있는 사용자만 에이전시 주소를 바꿀 수 있어요.

### 주소를 바꾸면 플랫폼 전체에 반영되기까지 얼마나 걸리나요?

에이전시 주소를 바꾸고 저장하면 바로 적용돼요.

### 에이전시 주소를 바꾸면 청구 정보에도 영향이 있나요?

네, 에이전시 주소를 업데이트하면 청구서와 그 밖의 공식 연락이 올바른 주소로 전달돼요.
