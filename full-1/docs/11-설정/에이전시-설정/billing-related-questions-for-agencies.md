# 에이전시 청구 관련 질문 모음

청구 문의는 요금이 어디서 발생했는지, 어떤 기록을 확인해야 하는지 알면 더 빨리 풀려요. 이 문서에서는 하이퍼클래스 에이전시 구독을 관리하는 방법, 구독 요금과 사용량 기반 요금을 구분하는 방법, 인보이스 확인, 결제 문제 해결, 청구 분쟁 문의 방법을 안내해요. 에이전시 청구, 지갑 활동, 마켓플레이스 구매, 고객 결제가 어떻게 다른지도 설명해요.

{% hint style="warning" %}
하이퍼클래스에서 직접 구매하지 않고 다른 에이전시를 통해 이용 권한을 구매했다면, 구독 변경이나 취소는 그 에이전시의 관리자에게 문의하세요. 다른 에이전시가 관리하는 계정은 하이퍼클래스에서 취소할 수 없어요.

에이전시 구독을 취소하려는 것이 목적이고 나머지 안내는 필요 없다면, 이 문서의 "구독 취소하기" 섹션으로 바로 이동하세요.
{% endhint %}

{% hint style="info" %}
에이전시 계정은 일시중지하거나 보류할 수 없어요. 에이전시 계정을 중단하려면 구독을 취소해야 해요. 나중에 구독을 다시 시작하면 계정을 재활성화할 수 있고, 데이터도 복원돼요.
{% endhint %}

## 하이퍼클래스 에이전시 청구란?

에이전시 청구 화면에서는 구독, 결제 수단, 인보이스, 지갑 활동, 사용할 수 있는 추가 서비스를 한곳에서 관리해요. 요금이 어디에 기록되는지 알면 요금의 용도와 해당 서브 계정이나 서비스를 확인하기 쉬워서, 청구 문제를 더 빨리 해결할 수 있어요.

청구 정보에는 다음과 같은 내역이 포함될 수 있어요.

- 하이퍼클래스 에이전시 정기 구독
- 플랜 업그레이드 등으로 발생하는 일할 계산 조정
- 에이전시 지갑 충전과 사용 내역
- 전화, 메시지, 이메일, AI, 워크플로우 요금
- A2P 등록 및 메시지 요금
- 마켓플레이스 앱과 기타 유료 애드온
- 개별 서브 계정에 켜 둔 서비스

하이퍼클래스 구독과 에이전시 지갑은 따로 청구돼요. 지갑 크레딧으로는 에이전시 정기 구독료를 결제할 수 없어요.

{% hint style="info" %}
하이퍼클래스 요금은 요금 안내 가이드를 참고하세요.
{% endhint %}

## 청구 설정 및 관리하기

에이전시 계정에서 청구 관련 작업은 아래 순서대로 간단하게 할 수 있어요.

### 계정 업그레이드하기

1. **에이전시 설정**으로 이동하세요.
2. **청구/결제** 탭을 클릭하세요.
3. **Want to Modify/Cancel Your Subscription?**(구독을 변경하거나 취소하시겠어요?)을 클릭하세요.
4. **업그레이드** 버튼을 클릭하세요.
5. **매월**과 **매년** 청구 옵션 중 하나를 선택한 뒤, 필요에 맞는 플랜을 고르세요.
6. 선택한 플랜의 **지금 업그레이드** 버튼을 클릭하세요.
7. **Pay (amount) & Subscribe**(금액 결제 및 구독) 버튼을 클릭하세요. 일할 계산된 금액이 바로 청구돼요.

![계정 업그레이드 과정 화면 녹화](https://jumpshare.com/share/zljzChMtndfHKYGGkJZp+/GIF+Recording+2026-10-27+at+16.21.53.gif)

### 계정 다운그레이드하기

다운그레이드하기 전에, 낮은 플랜에 포함된 기능과 서브 계정 한도를 먼저 확인하세요.

1. **에이전시 설정 > 청구/결제**로 이동하세요.
2. **Want to Modify/Cancel Your Subscription?**을 클릭하세요.
3. 선택할 수 있는 낮은 등급의 플랜을 고르세요.
4. 새 요금, 적용일, 일할 계산 조정 내역을 확인하세요.
5. 변경을 확정하세요.

![계정 다운그레이드 과정 화면 녹화](https://jumpshare.com/share/2dLnGH8ENVushxkltK4P+/GIF+Recording+2026-10-27+at+16.23.35.gif)

{% hint style="warning" %}
플랜을 다운그레이드해도 애드온, 마켓플레이스 앱, 전화번호 등 다른 유료 서비스는 자동으로 취소되지 않아요.

다운그레이드 옵션이 보이지 않으면 파란색 물음표 아이콘을 눌러 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

### 구독 취소하기

1. **에이전시 설정**으로 이동해 **청구/결제**를 클릭하세요.
2. **Want to modify/cancel your subscription?**을 클릭하세요.
3. 팝업에서 **더 보기**를 클릭하세요.
4. **플랜 취소**를 선택하세요.
5. **Reason for Cancellation**(취소 사유)을 고른 뒤 **다음**을 클릭하세요.
6. 데이터 손실 경고를 확인하세요.
7. **I am sure I want to cancel**(정말 취소하겠습니다)을 클릭하세요.
8. 피드백을 작성하세요. 30단어 이상 써야 해요.
9. **제출**을 클릭하세요.

![구독 취소 과정 화면 녹화](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047001744/original/P_w7n67nuqoWGf1nt33CnXqEIv2ILB3cWQ.gif?1747831561)

### 계정 재활성화하기

1. **Reactivate Account**(계정 재활성화)를 클릭하면 바로 재활성화돼요.
2. 또는 **To modify your current subscription, click here**(현재 구독을 변경하려면 여기를 클릭하세요)를 선택하세요.
3. 새 결제 수단을 추가하라는 안내가 나올 수 있어요.

![계정 재활성화 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077814181/original/z_yZxsbaz_oFbZGSGWNR2D16T1Qqu0d98Q.png?1786027768)

계정이 조건에 맞으면, 고객지원에 문의하지 않고도 구독을 재활성화하면서 낮은 등급의 플랜으로 바꿀 수 있어요.

1. 재활성화 화면에서 현재 구독을 변경하는 옵션 옆의 **Click Here**(여기를 클릭)를 선택하세요.

   ![재활성화 화면에서 구독 변경 옵션 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078459254/original/fldrndZ9MR6IOlqeytJAPCcwCjOol3D0sQ.png?1786717342)
2. 구독 변경 창에서 **플랜 다운그레이드**를 선택하세요.

   ![구독 변경 창에서 플랜 다운그레이드 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078459613/original/tXBTQ2l51LqwirRo3umUmU6bJX2Ya0geIQ.png?1786717393)
3. 내 계정에서 선택할 수 있는 낮은 등급의 플랜을 확인하세요.
4. 화면에 표시된 다운그레이드 정보를 입력하고 확인 사항에 동의하세요.
5. 다운그레이드를 확정하면 낮은 등급의 플랜으로 구독이 재활성화돼요.

   ![다운그레이드 확정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078459653/original/ucsERmjGY7mOCBB5UsXqW6T076jN6bqIQg.png?1786717411)

## 결제 및 재활성화 문제 해결

1. 결제 상태가 **Processing payment**(결제 처리 중)로 보이면 결제를 여러 번 시도하지 마세요. 다시 시도하기 전에 결제 상태부터 확인하세요.
2. 결제에 실패했다면 다음을 확인하세요.

   - 카드 번호, 유효기간, CVV, 청구지 주소, 우편번호가 맞는지 확인하세요.
   - 은행에서 결제를 차단하고 있지 않은지 확인하세요.
   - **에이전시 설정 > 청구/결제 > 결제**로 이동하세요.
   - 가장 최근에 실패한 구독 인보이스를 찾아 **재시도**를 클릭하세요.
   - 3D Secure(3DS), OTP, 은행 인증 안내가 나오면 인증을 완료하세요.

자세한 내용은 [에이전시 구독을 3DS 카드로 결제하려면 어떻게 하나요?](how-to-make-agency-subscription-payments-with-3ds-cards.md)를 참고하세요.

**에이전시 설정 > 청구/결제 > 결제** 화면에서 실패한 구독 인보이스와 **재시도** 옵션을 볼 수 있어요.

3. 결제는 성공했는데 계정이 재활성화되지 않거나 결제가 계속 실패하면, 하이퍼클래스 고객지원에 문의하세요. 자세한 문의 방법은 [24/7 고객 지원 옵션](../../20-고객지원/General-Support-Info/24-7-customer-support-options.md)을 참고하세요.

문의할 때는 에이전시 이름, 에이전시 로그인 이메일, 있다면 에이전시 관계 번호, 관련 인보이스나 결제 정보를 함께 알려 주세요.

에이전시 구독 결제가 실패했거나 계정이 재활성화되지 않았다면, 청구 문의 전에 [결제 및 재활성화 문제 해결](billing-related-questions-for-agencies.md)을 먼저 확인하세요.

## 청구 변경 및 환불

- 결제 정보 업데이트: **에이전시 설정 > 청구/결제**로 이동해 내 계정에서 쓸 수 있는 청구·결제 수단 메뉴를 이용하세요. 계정을 재활성화하는 중이라면 새 결제 수단을 추가하라는 안내가 나올 수 있어요.
- 청구지 주소 오류 해결: **Please Update the Billing Address**(청구지 주소를 업데이트해 주세요) 오류가 나오면, 우편번호, 주소, CVV가 카드 발급사에 등록된 정보와 같은지 확인하세요. 청구지 정보와 카드 정보가 다르면 결제가 실패할 수 있어요.
- 하이퍼클래스에서 직접 변경: 업그레이드, 다운그레이드, 취소, 재활성화, 재정 지원 요청 같은 작업은 해당 옵션이 계정에 표시될 때 **에이전시 설정 > 청구/결제**에서 직접 할 수 있어요.
- 변경 옵션이 없을 때는 고객지원에 문의: 일부 구독 변경은 플랫폼에서 직접 할 수 없어요. 예를 들어 다운그레이드 옵션이 보이지 않거나, 이미 이용 중인 연간 구독을 월간 청구로 되돌리려면 하이퍼클래스 고객지원에 문의하세요.
- 환불·분쟁 요청: 환불 요청과 청구 분쟁은 하이퍼클래스 청구팀의 검토가 필요해요. 에이전시 이름, 에이전시 로그인 이메일, 있다면 에이전시 관계 번호, 문제에 대한 간단한 설명, 관련 인보이스나 결제 정보를 함께 보내 주세요. 청구팀이 요금을 조사하는 데 도움이 돼요.

청구 관련 도움이 필요하면 [24/7 고객 지원 옵션](../../20-고객지원/General-Support-Info/24-7-customer-support-options.md)을 참고하세요.

## 일할 계산 이해하기 (업그레이드 직후 즉시 청구)

하이퍼클래스는 선불 서비스예요. 결제 주기 중간에 업그레이드하면 다음과 같이 처리돼요.

- 새 플랜 요금이 바로 청구돼요.
- 낮은 등급 플랜에서 쓰지 않은 기간만큼 일할 계산된 크레딧이 적용돼요.
- 예시:

  - 3월 15일에 297달러 플랜에서 497달러 플랜으로 업그레이드
  - 297달러 플랜을 10일 사용 → 크레딧 = 99달러 <!-- 검토 필요: 원문 내용이 서로 다름 -->
  - 남은 20일은 새 플랜 기준으로 청구 → 약 133.33달러 청구

## 재정 지원 요청

하이퍼클래스는 재정적으로 어려운 에이전시를 위해 일시적인 지원을 제공해요.

1. **설정**으로 이동해 **청구/결제**를 클릭하세요.
2. **Want to Modify/Cancel Your Subscription?** 버튼을 클릭하세요.
3. **재정 지원 요청** 옵션을 선택하세요.
4. 재정 지원을 요청하는 이유를 자세히 적어 주세요.
5. **확인** 체크박스를 모두 선택한 뒤 **계속하기**를 클릭하세요.
6. 다음 인보이스 내용을 확인하고 **확인 및 적용**을 클릭하세요.

승인된 계정은 플랜 요금의 10%만 내고 1개월 동안 이용할 수 있어요.

{% hint style="info" %}
재정 지원은 한 번만 받을 수 있는 할인이에요.
{% endhint %}

## 오류: "Please Update the Billing Address"

이 오류가 나오는 경우는 다음과 같아요.

- Stripe가 청구지 주소와 카드 정보가 일치하지 않는다고 표시한 거예요.
- 우편번호, 주소, CVV가 모두 카드에 등록된 정보와 같은지 확인하세요.

## 온라인 리스팅 서비스 문제

온라인 리스팅 서비스를 취소하려면 채팅으로 아래 정보를 보내 주세요.

- 위치 이름
- 위치 ID
- 취소 사유

이 서비스에는 3개월 약정이 적용돼요.

온라인 리스팅 서비스와 관련한 다른 문제는 앱 내 채팅이나 지원 티켓으로 하이퍼클래스 고객지원에 문의하세요.

### 카드 결제 문제

카드 결제가 실패하거나 카드 결제 오류가 나오면, 다시 시도하기 전에 다음을 확인하세요.

- 카드 번호, 유효기간, CVV, 청구지 주소를 정확히 입력했는지 확인하세요.
- 청구지 주소와 우편번호가 카드 발급사에 등록된 정보와 같은지 확인하세요.
- 카드에 잔액이나 사용 가능한 한도가 충분한지 확인하세요.
- 은행이나 카드 발급사에 문의해 결제가 차단되거나 의심 거래로 분류되지 않았는지 확인하세요.
- 해당되는 경우, 카드가 온라인·정기·해외 결제에 사용할 수 있게 설정되어 있는지 확인하세요.
- 문제가 계속되면 사용할 수 있는 다른 카드로 결제해 보세요.
- 결제 실패 시 계정 이용과 결제 재시도 기간: 에이전시 구독 결제가 실패해도 결제 실패일로부터 21일 동안은 계정을 계속 사용할 수 있어요. 21일 안에 결제 문제를 해결하지 않으면 계정 접근이 잠겨요. 결제 재시도는 결제 실패일로부터 최대 1개월(30일) 동안 백그라운드에서 계속돼요.

{% hint style="info" %}
일반적인 결제 거절 메시지가 나오면 시크릿 창이나 다른 브라우저로 시도해 보세요. 브라우저 문제로 결제가 막힌 경우 이렇게 하면 해결되는 경우가 많아요.
{% endhint %}

이 항목을 모두 확인했는데도 결제가 되지 않으면 하이퍼클래스 고객지원에 문의하세요.

## 자주 묻는 질문

### 이번 달에 요금이 두 번 청구됐어요. 왜 그런가요?
일할 계산된 요금, 결제 재시도, 별도의 구독이나 애드온 요금일 수 있어요. 일부 서비스는 에이전시 플랜과 가격이 같아요. 예를 들어 AI 직원은 97달러, HIPAA는 297달러예요. **인보이스**와 **지갑 거래**를 확인해서 각 요금이 무엇인지 파악해 보세요.

### 다른 에이전시를 통해 가입했다면 어떻게 하나요?
구독 변경이나 취소는 에이전시 관리자에게 문의하세요. 다른 에이전시를 통해 구매한 계정은 하이퍼클래스에서 관리할 수 없어요.

### 매월 청구와 매년 청구를 바꿀 수 있나요?
업그레이드할 때 매월 또는 매년 청구를 선택할 수 있어요. 이미 이용 중인 연간 플랜을 월간으로 되돌리는 기능은 플랫폼에 없어서, 하이퍼클래스 고객지원에 문의해야 해요.

### 구독을 취소하면 데이터가 삭제되나요?
네. 데이터는 90일 후에 삭제돼요. 데이터를 보관하려면 취소하는 대신 월 27달러의 일시중지 플랜(Pause Plan)을 이용할 수 있어요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

### 변경 또는 취소 버튼이 보이지 않아요. 어떻게 하나요?
라이브 채팅으로 하이퍼클래스 고객지원에 문의하세요. 계정을 확인하고 요청을 도와드려요.
