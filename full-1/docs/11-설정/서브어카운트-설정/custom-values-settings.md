# 커스텀 값 설정

커스텀 값은 한 번 만들어 두면 하이퍼클래스 어디서든 다시 쓸 수 있는 키:값 쌍이에요. 이 문서에서는 커스텀 값을 만드는 방법과 폴더, 검색, 일괄 작업으로 관리하는 방법을 안내해요.

## 커스텀 값이란?

커스텀 값은 키(Key)와 값(Value)으로 이뤄져 있고, 하이퍼클래스 어디서든 불러올 수 있어요. 같은 내용을 여러 곳에 반복해서 입력하는 대신, 모든 곳에 키만 써 두면 돼요. 이후 **커스텀 값** 목록에서 값 하나만 바꾸면 그 키를 쓴 모든 곳이 자동으로 바뀌어요.

## 커스텀 값 만들기

**1단계:** 커스텀 값 메뉴 열기

서브 계정에서 **설정 > 커스텀 값**으로 이동하세요.

![설정 메뉴에서 커스텀 값으로 이동하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457210/original/GKsAQ5KWxCNwdvGJ5CJ6o4sKrzP5-p7JUw.png?1753463469)

![커스텀 값 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457249/original/hfKjk08r-zZpk_8AfL768DREg-q8hwQECQ.png?1753463520)

**2단계:** 커스텀 값 만들기 시작

오른쪽 위에 있는 **New Custom Value**(새 커스텀 값) 버튼을 클릭하세요.

![오른쪽 위의 새 커스텀 값 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457285/original/t55SiIF--MpH5SyvCwniLAdfkrVOs2vQUg.png?1753463602)

**3단계:** 필드 입력

필요한 필드를 모두 입력하세요.

1. **Name**(이름) 필드: 커스텀 값의 키는 이 이름을 바탕으로 만들어져요. 예를 들어 이름이 `My Custom Value`이면 키는 `custom_values.my_custom_value`가 돼요.
2. **Value**(값) 필드
3. **Folder**(폴더) 필드 (선택 사항)

![이름, 값, 폴더를 입력하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457352/original/uWnKj8S5dCfrlcYtDd0xHZUvt3zo7EgKTQ.png?1753463661)

![입력을 마친 커스텀 값 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457367/original/SRmpCDLX7HwI3b_NHa4zYIcvQHOVoAoQYA.png?1753463709)

## 커스텀 값 관리하기

커스텀 값을 만든 뒤에는 여러 가지 방법으로 관리할 수 있어요.

### 폴더

**폴더** 탭을 클릭한 다음 **Add New Custom Value Folder**(새 커스텀 값 폴더 추가) 버튼을 클릭하세요. 커스텀 값이 들어 있는 폴더는 **All Values**(전체 값) 목록의 **Folder**(폴더) 열에 표시돼요. 모든 폴더는 **폴더** 목록에서 볼 수 있어요.

{% hint style="info" %}
커스텀 값은 한 번에 폴더 하나에만 넣을 수 있어요. 폴더 안에 다른 폴더를 만들 수는 없어요.
{% endhint %}

![폴더 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457394/original/OwVtZYxqzYIOZHEdEoIepyS9r9seHZnoFw.png?1753463772)

![새 폴더를 만드는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457410/original/509r9j_xLfLIR-DqZZHzw2VN_r3wqB3rsA.png?1753463808)

![폴더 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457182/original/W8ctMTXRHWML1s9MYdNY4JaZRMHxlUTKag.png?1753463424)

### 폴더 메뉴

폴더 목록에서 항목 오른쪽에 있는 점 세 개 메뉴를 클릭하세요.

![폴더 항목 오른쪽의 점 세 개 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457426/original/Pg7sksW8BSGbnNe4J5iQgOfi-sEokQ-rxw.png?1753463852)

### 폴더 이름 변경

**폴더 이름 변경**을 클릭한 다음 새 폴더 이름을 입력하세요.

![폴더 이름을 변경하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457437/original/xpbGiHkEJ_pAVR4oBWzqOV7-xI9GVa_YcA.png?1753463884)

### 폴더 삭제

**폴더 삭제**를 클릭하면 확인을 묻는 창이 나타나요.

![폴더 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457456/original/m54IEnw2lDzPuPAdMEOscrG2TdHBG4B4Fg.png?1753463959)

### 검색

**All Values**(전체 값) 목록 오른쪽 위에 **검색** 필드가 있어요. 검색어를 입력하면 키워드와 일치하는 커스텀 값만 목록에 표시돼요.

![전체 값 목록의 검색 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457469/original/K6TzrQexRko7lskG4Y0VxJY3rt1xo5vklA.png?1753463994)

### 항목 메뉴

커스텀 값 왼쪽에 있는 점 세 개 메뉴를 클릭하면 메뉴가 열려요.

![커스텀 값 항목의 점 세 개 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457489/original/dnDkO6KYic_mLEy43IaI8NR6uPdxPRZypw.png?1753464045)

### 항목을 폴더로 이동

**폴더로 이동**을 클릭하세요. 나타난 창에서 옮길 폴더를 선택하고 **Move**(이동)를 클릭하면 돼요.

![폴더로 이동 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457506/original/PZjAqO-GAB1lVZeUakHmTpDdZdS36Vwd9g.png?1753464086)

### 항목 편집

**커스텀 값 편집**을 클릭하세요. 나타난 창에서 새 이름이나 새 값을 입력하거나 다른 폴더로 옮길 수 있어요. 이름을 바꿔도 키는 바뀌지 않으니 참고하세요.

![커스텀 값 편집 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457522/original/gWCNfUfgF4LI03jFcjLDxss3AhtTNnFgRg.png?1753464132)

### 항목 삭제

**Delete Custom Value**(커스텀 값 삭제)를 클릭하면 확인을 묻는 창이 나타나요.

![커스텀 값 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457544/original/UiGnKDsv4m7k_mxGhCu8WxTvF2RF3GukuA.png?1753464180)

### 일괄 작업

체크박스를 하나 이상 선택하면 **일괄 작업** 버튼이 나타나요. 버튼을 클릭하면 메뉴가 열려요. 선택을 모두 취소하려면 **전체 선택 해제**를 클릭하세요.

![체크박스를 선택하면 나타나는 일괄 작업 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457629/original/KsUClz-I9MBxWbu5Dffe-b_7HV2NbEwtdg.jpeg?1753464223)

### 일괄 폴더 이동

**폴더로 이동**을 클릭한 다음 나타난 창에서 옮길 폴더를 선택하세요. 선택한 커스텀 값을 옮기면 **Folder**(폴더) 열에 해당 폴더 이름이 표시돼요.

![일괄 작업에서 폴더로 이동 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457654/original/FivusXF53NG11T_sUxQPEZ7Iq8TlhOuXgg.png?1753464273)

![옮길 폴더를 선택하는 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457689/original/PbGqMxQ-PBafLsC-KQmK5_1QCqWLm0JcZQ.png?1753464326)

### 일괄 삭제

**Delete Custom Value**(커스텀 값 삭제)를 클릭하세요. 선택한 커스텀 값을 삭제할지 확인하는 창이 나타나요.

![선택한 커스텀 값 일괄 삭제 확인 창](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050457712/original/5PzM1j5yA1FE_KOdkw8Vjz1pRt_yTXXD_g.png?1753464367)
