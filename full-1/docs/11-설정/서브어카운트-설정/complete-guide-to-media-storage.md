# 미디어 저장소 완전 가이드

하이퍼클래스의 **미디어 저장소**(Media Storage)에서 파일을 열고, 업로드하고, 정리하고, 검색하고, 미리 보고, 관리하고, 복구하는 기본 작업을 모두 안내해요.

대시보드 왼쪽 메뉴에서 **미디어 저장소**를 클릭하세요.

## 미디어 저장소에 파일 업로드하기

### 파일 개별 업로드

컴퓨터에 있는 파일을 **미디어 저장소** 화면으로 끌어다 놓으면 업로드돼요.

지원하는 파일 형식, 업로드 제한, 브라우저 호환성, 고급 동작이 궁금하다면 '미디어 저장소 파일 형식, 제한 및 고급 기능' 문서를 참고하세요.

#### 업로드 진행 상황 확인

파일을 업로드하면 업로드 패널에 진행 상황이 실시간으로 표시돼요. 패널 맨 위에는 업로드 중인 항목 수, 전송된 용량, 전체 진행률이 나와요.

파일마다 진행률과 전송된 용량이 전체 파일 크기와 함께 표시돼요. 각 파일이 업로드 중인지, 완료됐는지, 실패했는지, 취소됐는지도 업로드 패널에서 볼 수 있어요.

#### 업로드 취소

업로드 중인 파일 하나만 취소하려면 파일에 마우스를 올리고 **X**를 클릭하세요. 선택한 파일만 취소되고 나머지 파일은 계속 업로드돼요. 파일 하나를 취소할 때는 확인 창이 나오지 않아요.

파일이 업로드되는 중에 업로드 패널을 닫으면 확인 창이 나타나요. 업로드 패널로 돌아가려면 **계속 업로드**를, 진행 중인 업로드를 모두 멈추려면 **업로드 취소**를 선택하세요.

[동영상](https://jumpshare.com/embed/jshRyKMKlvETglrdnMR6)

### 폴더 업로드

폴더 구조를 그대로 유지한 채 폴더 전체를 업로드할 수 있어요.

업로드하는 동안 폴더 단위 화면에 진행 상황이 표시돼서 하위 폴더와 파일까지 확인할 수 있어요. 건너뛴 항목 수는 알림 메시지로 보여 줘요.

폴더 업로드는 하위 폴더를 최대 3단계까지, 한 번에 최대 1,000개 파일까지 지원해요.

폴더를 업로드하려면 다음 순서를 따르세요.

1. **업로드**를 클릭하세요.
2. **Upload Folder**(폴더 업로드)를 선택하세요.

![폴더 업로드 메뉴](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073303793/original/_aXXVBB2S2AjWZKtcjMN7t4KTPHnH2VkBg.png?1781032490)

### URL로 파일 업로드

파일 주소(URL)를 직접 입력해서 이미지, 동영상, 오디오 파일, 문서를 **미디어 저장소**로 가져올 수 있어요.

URL로 파일을 가져오려면 다음 순서를 따르세요.

1. **업로드**를 클릭하세요.
2. **업로드 URL**을 선택하세요.
3. `.jpg`, `.mp4`, `.mp3`, `.pdf`처럼 이미지, 동영상, 오디오, 문서 파일로 바로 연결되는 링크를 붙여 넣으세요.
4. 미디어 저장소가 파일을 불러올 때까지 기다리세요. URL 입력란에 초록색 체크 표시가 나타나면 파일을 잘 불러왔다는 뜻이에요.
5. 미리보기를 쓸 수 있는 파일이면 미리 확인하세요.
6. 저작권 확인 체크박스를 선택하세요.
7. **가져오기**를 클릭하세요.

이미지, 동영상, 오디오 파일, 문서의 직접 파일 URL은 지금도 그대로 쓸 수 있어요. 같은 **업로드 URL** 옵션에서 일반 웹페이지 URL도 입력할 수 있고, 이 경우 가져올 수 있는 미디어 파일이 선택 가능한 그리드로 표시돼요. 웹페이지에서 여러 파일을 가져오는 방법은 아래 '웹페이지에서 여러 파일 가져오기'를 참고하세요.

동영상 파일로 바로 연결되는 링크도 계속 지원해요. 다만 YouTube, Vimeo, Loom, Google Drive 페이지 URL은 웹페이지 가져오기에서 지원하지 않아요.

지원하는 오디오 형식은 다음과 같아요.

- MP3
- WAV
- M4A
- AAC
- OGG
- FLAC

지원하는 문서 형식은 다음과 같아요.

- PDF
- DOC
- DOCX
- XLS
- XLSX
- PPT
- PPTX
- TXT
- CSV

브라우저에서 파일을 표시할 수 있으면 가져오기 전에 인라인 미리보기가 나와요. 예를 들어 지원하는 오디오는 재생해 보고, PDF는 페이지를 넘겨 볼 수 있어요.

PPT, PPTX, 예전 DOC 파일은 브라우저에서 표시할 수 없어서 **미리보기를 제공하지 않습니다** 카드가 나타날 수 있어요. 이런 파일도 가져오기는 문제없이 돼요.

원본 웹사이트가 브라우저 미리보기를 막는 경우에도 미리보기를 쓸 수 없다는 화면이 나올 수 있어요. 가져오기는 그대로 진행할 수 있어요. 가져올 때는 서버에서 파일을 받아 오기 때문이에요.

가져온 파일은 다른 업로드 파일과 똑같이 라이브러리에 저장되고, 새 URL이 만들어져요.

![URL로 파일을 가져오는 화면 녹화](https://jumpshare.com/share/6YegAlU2PrehtPNNsQIy+/GIF+Recording+2026-09-28+at+21.47.10.gif)

### 웹페이지에서 여러 파일 가져오기

웹페이지에서 지원하는 이미지, 동영상, 오디오 파일, PDF를 파일마다 따로 내려받지 않고 한 번에 가져올 수 있어요. 웹페이지 주소를 입력하고, 찾아 낸 파일을 확인한 뒤, 가져올 파일만 선택하면 돼요. 블로그 글, 랜딩 페이지, 미디어 갤러리에 있는 미디어를 한 번에 모을 수 있어요.

#### 웹페이지에서 여러 파일 가져오는 순서

1. **서브 계정 보기**에서 왼쪽 메뉴의 **미디어 저장소**를 클릭하세요.
2. 오른쪽 위의 **업로드**를 클릭하세요.
3. 드롭다운 메뉴에서 **업로드 URL**을 선택하세요.
4. **URL** 입력란에 웹페이지 주소를 붙여 넣으세요.
5. 미디어 저장소가 웹페이지를 검사할 때까지 기다리세요. 초록색 체크 표시가 나오면 검사가 잘 끝났다는 뜻이에요. 찾아 낸 파일이 미디어 썸네일과 함께 선택 가능한 그리드로 나타나요.

   ![웹페이지에서 찾은 파일 그리드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083606879/original/acHunknBUP0wEpceeATLXXNWAP0-KoY27w.png?1792373582)
6. 결과를 좁히려면 결과 그리드 오른쪽 위의 파일 형식 필터 아이콘을 클릭하세요. GIF, JPG, PDF, PNG처럼 목록에 나온 파일 형식 중 하나를 고르면 찾아 낸 파일이 그 형식으로 걸러져요.

   ![파일 형식 필터 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083606913/original/uXYlkMVMgMPGmjfhO6r7G-fg7e-6WsK-7w.png?1792373775)
7. 가져오기 전에 파일을 확인하세요. 지원하는 동영상은 그 자리에서 재생되고, 오디오 파일은 클릭하면 재생돼요. PDF는 검사 결과 그리드에 첫 페이지가 표시돼요.
8. 가져올 파일은 각 파일의 체크박스로 선택하세요. 한꺼번에 선택하려면 **전체 선택**을 클릭하세요. 선택한 파일 수는 선택 카운터에 표시돼요.

   ![가져올 파일 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083606902/original/AgdsmrtMn52FuASrl2beUBxSO6QrBI-Kpw.png?1792373717)
9. 선택한 미디어를 사용할 권리가 있고 가져와도 다른 사람의 저작권을 침해하지 않는다는 저작권 확인 체크박스를 선택하세요.
10. **Import N files**(N개 파일 가져오기)를 클릭하세요. N은 선택한 파일 수예요. 선택한 파일이 라이브러리로 한꺼번에 들어와요.

#### 웹페이지 가져오기 시 알아 둘 점

- 최대 검사 한도: 웹페이지 한 번 검사에 최대 1,000개 파일까지 찾아내요. 가져올 수 있는 파일이 1,000개를 넘으면 그 한도까지만 결과에 나와요.
- 점진적 로딩: 파일이 많은 웹페이지는 스크롤할 때마다 결과 그리드가 조금씩 더 불러와져요.
- 지원하지 않는 URL: YouTube, Vimeo, Loom, Google Drive 페이지 링크는 지원하지 않아요. 지원하는 직접 미디어 주소가 아니라 플레이어나 파일 서비스 페이지이기 때문이에요.
- 보호된 웹사이트: 봇 차단이 강한 웹사이트는 미디어 저장소가 페이지를 검사하지 못할 수 있어요. 이런 이유로 검사에 실패하면 차단된 소스라는 메시지가 나타나요.
- 직접 파일 가져오기: **업로드 URL**은 이미지, 동영상, 오디오 파일, 문서로 바로 연결되는 링크를 계속 지원해요. 웹페이지 가져오기 기능이 생겨도 기존 직접 파일 업로드 방식은 바뀌지 않아요.
- 권한: 기존 URL 업로드 권한이 웹페이지 가져오기에도 똑같이 적용돼요. 별도 권한은 필요하지 않아요.

## 미디어 정리하고 찾기

### 미디어 저장소 검색

미디어 저장소 검색창에서 라이브러리 전체의 파일과 폴더를 찾을 수 있어요. 파일에 지정한 태그도 검색되므로, 파일 이름이 기억나지 않아도 원하는 자료를 찾을 수 있어요.

### 태그로 파일 검색

태그를 쓰면 파일 이름에 의존하지 않고 의미 있는 이름표로 미디어 파일을 찾을 수 있어요. 파일 이름이 자동으로 만들어진 경우에도 캠페인, 고객, 상품, 주제별로 검색할 수 있어요.

![태그로 파일 검색하기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083607429/original/jxDjG_s2YHWkKH9gzpBWvg5cVTvYQuO-YA.png?1792376381)

태그로 파일을 찾으려면 다음 순서를 따르세요.

1. **서브 계정 보기**에서 왼쪽 메뉴의 **미디어 저장소**를 클릭하세요.
2. 미디어 저장소 검색창을 클릭하세요.
3. 찾으려는 태그를 입력하세요.
4. 검색 결과에서 그 태그가 지정된 파일을 확인하세요.

![태그 검색 결과](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083607423/original/d4lc-5H_R3E-8qq-HheQXl2DjVfFu_ljfQ.png?1792376317)

파일에서 태그를 제거하고 변경 내용을 저장하면, 그 파일은 제거한 태그로 검색해도 더 이상 나오지 않아요.

### 파일 위치 확인

검색 결과에서 파일 위에 마우스를 올리면 폴더 경로가 보여요. 폴더 경로로 그 파일이 미디어 저장소 어디에 있는지 알 수 있어요.

### 포함된 폴더 열기

파일이 있는 위치로 바로 이동하려면 다음 순서를 따르세요.

1. 미디어 저장소 검색창으로 파일을 찾으세요.
2. 파일의 점 3개(⋮) 메뉴를 클릭하세요.
3. **포함된 폴더 열기**를 선택하세요.

미디어 저장소가 그 파일이 들어 있는 폴더를 열고 검색창을 비워요.

### 미디어 정렬

다음 기준으로 미디어를 정렬할 수 있어요.

- **Sort by Name**(이름순): **A to Z**(A→Z) 또는 **Z to A**(Z→A)
- **Sort by Size**(크기순): **Smallest First**(작은 순) 또는 **Largest First**(큰 순)
- **Sort by Modified Date**(수정일순): **최신순** 또는 **오래된 순**

### 그리드 보기와 목록 보기

파일을 둘러보고 싶은 방식에 따라 **그리드 보기**와 **목록 보기**를 오가며 쓸 수 있어요.

- 그리드 보기의 방향 배지: 이미지에 **가로**, **세로 방향**, **정사각형** 중 하나를 알려 주는 배지가 표시돼요.
- 목록 보기의 픽셀 크기: 이미지 이름 옆에 가로 × 세로 값이 표시돼서, 파일을 쓰기 전에 이미지 크기를 확인할 수 있어요.

{% hint style="info" %}
예전에 업로드한 이미지는 백그라운드 처리가 늦어져서 크기가 바로 표시되지 않을 수 있어요.
{% endhint %}

## 미리 보고 삽입하기

웹사이트나 퍼널 빌더처럼 미디어 저장소를 쓰는 하이퍼클래스 제품 안에서는, 작업 중인 화면을 벗어나지 않고 파일을 미리 보고 삽입할 수 있어요.

### 파일 미리보기 열기

파일의 점 3개(⋮) 메뉴를 열고 **미리보기**를 선택하면 파일을 쓰기 전에 확인할 수 있어요.

### 파일 사이 이동

**미리보기**에서 화살표 버튼을 쓰거나 키보드의 왼쪽·오른쪽 화살표 키를 누르면, 파일을 하나씩 닫지 않고 이미지와 동영상 사이를 이동할 수 있어요.

파일 상세 화면에서는 화면의 **←**, **→** 화살표나 키보드의 화살표 키로 파일 사이를 이동해요. 현재 위치는 카운터로 표시돼요. 화면을 닫으려면 **Esc** 키(Esc 키로 닫기)를, 동영상을 재생하거나 일시정지하려면 **스페이스**(스페이스바를 눌러 재생 또는 일시정지)를 누르세요.

#### 상세 보기

**상세 보기**에서는 이미지와 동영상을 미리 보고, 형식, 크기, 규격, 재생 시간, 업로드 날짜, **File ID**(파일 ID) 같은 파일 정보를 확인할 수 있어요. 파일을 내려받지 않고도 어떤 파일인지 알아볼 수 있어요. 파일의 점 3개(⋮) 메뉴에서 상세 화면을 열 수 있고, 이미지 확대, 동영상 재생, File ID 복사도 가능해요.

![파일 상세 보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079729648/original/KYP5P0KDd0X285ADlMcxdh3ZxcVMoVeM6Q.gif?1788193438)

### 이미지 미리보기 컨트롤

**미디어 저장소**에서 이미지를 미리 보면, 파일을 내려받거나 미디어 저장소를 벗어나지 않고도 이미지를 자세히 살펴볼 수 있어요.

- 이미지 확대: 도구 모음, 마우스 휠이나 트랙패드, 핀치 제스처, 키보드로 100%에서 400%까지 확대할 수 있어요. 커서를 따라 확대되므로 보고 싶은 부분에 집중할 수 있어요.
- 확대한 상태에서 이동: 확대한 상태에서 이미지를 클릭한 채 끌면 다른 부분을 볼 수 있어요. 이미지는 미리보기 영역 안에 머물러요.
- 전체 화면으로 보기: 이미지를 전체 화면으로 키워 더 크게 볼 수 있어요. 전체 화면일 때 `Esc`를 누르면 전체 화면이 해제되고 미리보기로 돌아가요.
- 컨트롤 바 이동: 떠 있는 컨트롤 바를 끌어서 위치를 바꿀 수 있어요. 화살표 키로도 옮길 수 있어요.
- 미리보기를 매번 처음 상태로 시작: 파일을 바꾸거나 미리보기를 닫으면 확대 수준, 이동 위치, 컨트롤 바 위치, 전체 화면 상태가 초기화돼요.

이 컨트롤은 이미지 미리보기에만 적용돼요. 다른 파일 형식은 기존 미리보기 방식 그대로예요.

이미지 미리보기는 키보드 탐색과 화면 낭독기를 지원하고, 사용자의 모션 줄이기(Reduce Motion) 설정을 따라요.

![이미지 미리보기 컨트롤 화면 녹화](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079725261/original/dhGQeyIpQfSxqneQNchM03vz2n1ya_qpNw.gif?1788190614)

### 미디어 삽입

- **Insert Media**(미디어 삽입) 버튼으로 파일 하나를 선택해 삽입할 수 있어요.
- **미리보기** 화면에서 바로 파일을 삽입할 수도 있어요.

### 미리보기에서 텍스트 파일 편집

지원하는 텍스트 파일은 내려받았다가 다시 업로드할 필요 없이 미디어 저장소에서 바로 편집할 수 있어요.

편집할 수 있는 파일 형식은 다음과 같아요.

- `.txt`
- `.css`
- `.json`
- `.sql`
- `.rtf`

지원하는 텍스트 파일을 편집하려면 다음 순서를 따르세요.

1. 파일을 **미리보기**로 여세요.
2. 미리보기 도구 모음에서 **편집**을 클릭하세요.
3. 내용을 수정하세요.
4. **저장**을 클릭하세요.

내용을 수정하기 전에는 **저장** 버튼이 비활성화돼 있어요.

저장하면 새 복사본이 만들어지지 않고 기존 파일이 업데이트돼요. 파일 이름과 공개 URL이 그대로라서, 이 파일로 연결된 기존 링크도 같은 URL을 계속 써요.

저장하지 않은 변경 내용이 있는 상태에서 미리보기를 닫거나, 다른 화면으로 이동하거나, 취소하면 변경 내용을 버릴지 확인하는 창이 나타나요.

지원하지 않는 파일 형식에는 **편집** 버튼이 나타나지 않아요.

{% hint style="info" %}
편집한 파일이 5MB보다 크면 저장은 할 수 있지만, 저장 후에는 그 파일을 미리보기로 볼 수 없어요. 저장하기 전에 미디어 저장소가 경고를 보여 줘요.
{% endhint %}

## 파일과 폴더 관리하기

### 빠른 액션

마우스 오른쪽 버튼 메뉴나 마우스를 올리면 나타나는 **빠른 액션** 버튼으로 파일 옵션을 쓸 수 있어요.

사용할 수 있는 작업은 다음과 같아요.

- **이름 변경**
- **삭제**
- **폴더로 이동**
- **미리보기**
- **Insert**(삽입)

### 폴더 섹션 접기와 펼치기

폴더 구조가 크다면 **폴더** 섹션을 접어서 화면을 정리하고 파일에 집중할 수 있어요.

**폴더** 옆의 화살표를 클릭하면 폴더 목록이 접히고, 다시 클릭하면 펼쳐져요.

![폴더 섹션 접기와 펼치기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064213379/original/G4GeHcJHvWE6FQh7TbvL_lxFwkvmKIpD3g.png?1770233460)

### 폴더 통째로 이동

폴더 안에 있는 파일과 하위 폴더까지 포함해 폴더를 통째로 옮길 수 있어요.

폴더를 이동하려면 다음 순서를 따르세요.

1. 폴더 옆의 점 3개(⋮) 메뉴를 클릭하고 **폴더로 이동**을 선택하세요.

   ![폴더 메뉴에서 폴더로 이동 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062681158/original/brQ-banAB_56UTODCRgje7xoH4QnU7-xzw.jpeg?1768421594)
2. 기존 폴더를 고르거나 새 폴더를 만드세요.
3. 이동을 확인하세요.

{% hint style="info" %}
폴더를 이동해도 그 안의 하위 폴더 구조는 그대로 유지돼요.
{% endhint %}

### 폴더를 ZIP 파일로 다운로드

폴더 전체를 ZIP 파일 하나로 내려받을 수 있어요. 하위 폴더를 포함해 원래 폴더 구조가 그대로 유지돼요.

폴더를 내려받으려면 브라우저 환경의 로컬 디스크 공간이 충분해야 해요.

폴더를 다운로드하려면 다음 순서를 따르세요.

1. 폴더 옆의 점 3개(⋮) 아이콘을 클릭하고 **선택**을 클릭하세요.
2. 폴더가 선택됐는지 확인하고, 함께 내려받을 폴더가 더 있으면 추가로 선택하세요.
3. **다운로드**를 클릭하면 선택한 항목이 ZIP 파일로 저장돼요.

![폴더를 선택해 ZIP으로 다운로드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073303954/original/ElMRRds-_Gp0BBmrO942E-t3MdSe_YZk0g.png?1781032766)

## 휴지통과 파일 복구

삭제한 미디어 파일은 **휴지통**으로 이동하고, **30일** 동안 보관된 뒤 영구적으로 삭제돼요.

1. 오른쪽 위의 점 3개(⋮) 메뉴를 클릭하고 **휴지통**을 선택하세요.

   ![점 3개 메뉴에서 휴지통 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062681193/original/XNTvb1LKzxjgQsuL9BM67N6fYXpyt8KMRA.jpeg?1768421700)
2. 파일을 골라 **복원**하거나 **영구 삭제**하세요.

   ![휴지통에서 복원 또는 영구 삭제](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062681195/original/vrmNhmNMZex7hYAbEnDI5yLl6dSCU1qZwA.jpeg?1768421711)

{% hint style="warning" %}
30일이 지나면 파일을 복구할 수 없어요.

휴지통은 로케이션 전체에서 공유돼요. 같은 로케이션에 로그인한 사용자라면 누가 휴지통으로 옮겼든 상관없이 휴지통의 항목을 보고 복원할 수 있어요.
{% endhint %}

## 자주 묻는 질문

### 그리드 보기와 목록 보기를 둘 다 쓸 수 있나요?
네, 쓸 수 있어요. **그리드 보기**에서는 이미지 방향 배지가, **목록 보기**에서는 이미지 픽셀 크기가 표시돼요.

### 어떤 정렬 옵션을 쓸 수 있나요?
이름, 크기, 수정일 기준으로 오름차순 또는 내림차순 정렬을 할 수 있어요.

### 삭제한 파일은 어떻게 되나요?
삭제한 파일은 30일 동안 **휴지통**에 보관돼요. 같은 로케이션의 사용자는 휴지통 항목을 보고 복원하거나 영구 삭제할 수 있어요. 30일이 지나면 파일이 삭제되고 복구할 수 없어요.
