# 도메인 구매 켜고 고객에게 재청구하기

Founder 요금제에서 도메인 구매를 제공한다면, 고객이 도메인을 살 수 있도록 기능을 켜고 연결된 Stripe 계정으로 비용을 재청구(리빌링)할 수 있어요. 이 문서에서는 도메인 재판매를 켜는 방법, 마진을 직접 정하는 방법, 토글 설정에 따라 누가 비용을 내는지 설명해요. 반복 수익을 만들고 고객의 도메인 구매 과정을 간단하게 하려는 에이전시에 알맞아요.

```
- 모든 요금제($97, $970, $297, $2970, $497, $4970)의 에이전시가 도메인 구매를 쓸 수 있어요.

- 에이전시 설정에서 도메인 구매를 켜면, 기존 서브 계정과 새 서브 계정 모두에 도메인 구매 옵션이 표시돼요.

- 기존 서브 계정에서 에이전시에 실행 비용이 쌓이지 않게 하려면, 에이전시 보기에서 서브 계정마다 재청구를 직접 켜야 해요.

- SaaS 구성기에서 도메인 구매를 켜 두면, 새로 만들어지는 서브 계정은 자동으로 도메인 구매에 등록돼요. 에이전시가 따로 할 일은 없어요.
```

## 에이전시 단계에서 도메인 구매 켜기

고객이 도메인을 구매하려면 먼저 에이전시 단계에서 **도메인 구매**를 켜야 해요.

1. **에이전시 보기**에서 **설정 > 회사**로 이동하세요.
2. **도메인 구매** 토글을 찾아 켜세요.

   ![도메인 구매 토글을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084882050/original/VfBPwltXvjE6pDeD-6zxIxFPjwTdnVOl1w.png?1793734914)
3. 도메인 구매 약관에 동의한다는 체크박스를 선택하세요.
4. **활성화**를 눌러 확인하세요.

   ![도메인 구매 활성화 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084882061/original/gi-30RdXDGYRnLaevHB6CaSBxt8umR5N5A.png?1793734926)

켜고 나면 에이전시의 서브 계정에서 도메인 구매를 쓸 수 있어요. 단, 서브 계정마다 설정한 내용에 따라 달라져요. 서브 계정별 도메인 구매 기능과 재청구는 **에이전시 설정 > 도메인 구매**에서 켜고 끌 수 있어요. **서브 계정 설정**은 에이전시 단계에서 도메인 구매를 켠 경우에만 열 수 있어요.

![에이전시 설정의 도메인 구매 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084882718/original/f3Jm31WhBe5U6AEKeSlWtQn0WYOwT9KCxw.png?1793736204)

## 도메인 구매 가격

도메인 구매를 켜면 서브 계정의 **도메인** 페이지에 **도메인 구매** 옵션이 나타나요.

도메인 가격은 도메인 이름과 확장자(TLD)에 따라 달라요. 확장자는 .com, .us, .net 같은 거예요.

## 고객에게 비용을 재청구하고 수익 만들기

{% hint style="info" %}
이 기능은 $497 Founder 요금제 고객만 쓸 수 있어요.
{% endhint %}

도메인 구매를 켜면 고객이 서브 계정에서 바로 도메인을 구매할 수 있어요.

재청구 방식은 둘 중에서 고를 수 있어요.

- 원가로 재청구: 에이전시가 도메인에 낸 금액과 같은 금액을 고객에게 청구해요.
- 마크업 추가: 고객에게 청구하는 금액을 올려 수익을 만들어요.

---

## 고객에게 도메인 재청구 켜기

1. 에이전시 단계에서 [**도메인 구매**](#에이전시-단계에서-도메인-구매-켜기)가 켜져 있는지 확인하세요.
2. **에이전시 보기**에서 **계정**으로 이동하세요.
3. 서브 계정이 아직 SaaS 모드가 아니라면, 해당 서브 계정을 찾아 점 3개 메뉴를 누르고 **SaaS로 전환**을 선택하세요. (자세한 내용은 "서브 계정을 SaaS로 전환하는 방법"을 참고하세요.)
4. 설정할 서브 계정을 찾아 **상세 보기**를 누르세요.
5. **Domain Purchase Re-Sell Settings**(도메인 구매 재판매 설정)까지 스크롤해서 토글을 켜세요.
6. 슬라이더로 원하는 마크업을 설정하세요.
7. **저장**을 누르세요.
8. 재청구를 적용할 다른 서브 계정에서도 같은 과정을 반복하세요.

## 고객 재청구 방식

고객이 도메인을 구매하면, 재청구를 켰는지에 따라 결제 방식이 달라져요.

- 에이전시 청구: 에이전시가 하이퍼클래스에 도메인 비용을 내고, 하이퍼클래스 브랜딩이 들어간 인보이스를 받아요.
- 고객 청구: 재청구를 켜면 고객은 설정한 가격으로 에이전시에 비용을 내고, 에이전시 브랜딩이 들어간 인보이스를 받아요.
- Stripe 결제: 고객이 낸 금액은 에이전시 단계에서 연결한 Stripe 계정으로 입금돼요. 자세한 내용은 "에이전시의 Stripe 계정을 연결해 고객 결제를 받으려면 어떻게 하나요?"를 참고하세요.
- **지갑**: 도메인 구매 재청구는 하이퍼클래스 전화, 하이퍼클래스 이메일 재청구와 마찬가지로 에이전시 지갑과 서브 계정(로케이션) 지갑의 크레딧을 사용해요.

## 자주 묻는 질문

### 도메인 비용은 누가 내나요? 저인가요, 고객인가요?
재청구를 켰는지에 따라 달라요. 재청구가 꺼져 있으면 에이전시가 도메인 비용을 내고 그 비용을 부담해요. 재청구가 켜져 있으면 고객이 설정한 가격으로 에이전시의 Stripe 계정을 통해 결제해요.

### 재청구를 켜려면 Stripe 계정이 꼭 있어야 하나요?
네. 재청구를 쓰려면 SaaS 구성기에서 Stripe를 연결해야 해요. Stripe가 없으면 고객에게 요금이 청구되지 않고, 도메인 비용은 에이전시가 부담해요.

### 고객이 서브 계정에서 직접 도메인을 살 수 있나요?
네. 도메인 재판매를 켜면 고객이 서브 계정의 **설정 > 도메인**에서 도메인을 검색하고, 플랫폼을 벗어나지 않고 바로 구매할 수 있어요.

### 모든 에이전시 요금제에서 쓸 수 있나요?
아니요. 도메인 재청구는 SaaS 모드가 포함된 요금제를 쓰고 Stripe를 연결해야 쓸 수 있어요.

### 도메인 구매 비용은 매달 청구되나요, 매년 청구되나요?
도메인 구매 비용은 선택한 등록 기간만큼 먼저 한 번에 결제돼요. 매달 청구되지 않아요. 도메인 확장자(TLD)에 따라 1년 또는 여러 해 동안 등록할 수 있어요. 총 비용은 구매를 마치기 전 결제 화면에 표시돼요. 자세한 내용은 [도메인 구매 단계별 안내](Domain-Purchase/Transfer/how-to-purchase-domain-step-by-step.md)를 참고하세요.
