# 연락처 중복 허용 설정 (연락처 중복 제거 환경설정)

하이퍼클래스에서 중복 연락처를 어떻게 처리할지 정하는 설정이에요. 필요에 맞게 이 환경설정을 바꾸는 방법을 안내해요.

[동영상](https://www.youtube.com/embed/5VmZ5iSKj-U?&wmode=opaque)

## 연락처 중복 환경설정 개요

**연락처 중복 허용** 설정은 연락처를 만들고 기존 연락처와 맞춰 보는 규칙을 정해요.

- 중복 허용을 끄면, 선택한 기본 항목(선택 사항인 보조 항목 포함)으로 기존 연락처를 찾아요. 새로 들어온 정보는 찾은 연락처에 연결돼요. 일치하는 연락처가 없으면 새 연락처가 만들어져요.
- 중복 허용을 켜면, 같은 이메일이나 전화번호가 이미 있어도 새 연락처가 만들어져요. 필요하면 나중에 병합할 수 있어요.

이 설정은 Zapier나 폼으로 들어오는 연락처에 특히 중요해요. 다만 CSV 연락처 업로드에는 적용되지 않아요. CSV 업로드에서는 전화번호나 이메일 주소를 기준으로 중복을 자동으로 찾아 처리해요.

---

## 꼭 알아야 할 내용

- Zapier, 폼, Facebook, Instagram에 적용돼요
  - **연락처 중복 허용** 설정은 폼, Zapier, Facebook·Instagram Messenger로 들어온 새 정보가 연락처를 새로 만들지, 기존 연락처에 병합할지를 정해요.
  - 활성화되면 이메일이나 전화번호가 이미 있어도 새 연락처가 만들어져요.
  - 비활성화되면 이메일이나 전화번호가 일치하는 기존 연락처가 업데이트되고, 새 연락처는 만들어지지 않아요.
- CSV 가져오기에는 적용되지 않아요
  - CSV로 가져올 때는 이 설정과 관계없이 하이퍼클래스가 전화번호나 이메일 주소를 기준으로 연락처를 자동 병합해요.
  - CSV 업로드로는 중복 연락처를 만들 수 없어요.
- 가져오기 기본 동작
  - CSV로 연락처를 가져올 때, 지정한 기본 항목(이메일 또는 전화번호)으로 기존 연락처가 있는지 확인해요.
  - 정보가 일치하는 연락처는 자동으로 병합돼서 데이터베이스가 깔끔하게 유지돼요.

```
"연락처 중복 허용" 설정을 켜면 중복 연락처가 허용됩니다. 같은 사람이 별도의 연락처로 존재해야 하는 경우(예: 부서가 서로 다른 경우)에 유용할 수 있습니다.

설정을 끄면 중복 연락처가 만들어지지 않습니다. 전화번호나 이메일당 연락처가 하나만 유지되고, 새 연락처를 만드는 대신 기존 연락처가 업데이트됩니다.
```

## 환경설정 항목

연락처 중복 환경설정에서 바꿀 수 있는 항목은 세 가지예요.

#### 연락처 중복 허용

서브 계정이 중복 연락처를 어떻게 처리할지 정하는 설정이에요. 중복 연락처를 허용하려면 이 설정을 켜세요(ON). 허용하지 않으려면 끄세요(OFF).

#### **Find Existing Contacts Based On**(다음 기준으로 기존 연락처 찾기)

하이퍼클래스가 데이터베이스에서 기존 연락처를 찾고 일치 여부를 판단하는 기준을 정하는 필터예요. 연락처를 만들기 전에 기존 연락처를 찾을 때 쓸 기본 항목을 고르세요. 선택할 수 있는 항목은 **이메일**(기본값)과 **전화번호**예요. 접수할 때 더 꾸준히 수집하는 항목을 고르세요.

#### **Second Preferences for Search (Optional)**(검색 보조 기준, 선택 사항)

중복을 찾을 때 쓰는 보조 기준이에요. 한 가지 항목으로만 맞춰 보려면 비워 두세요.

예를 들어 기본 항목을 **이메일**로, 보조 항목을 **전화번호**로 선택하면 먼저 이메일로 일치하는 연락처를 찾아요. 일치하는 연락처가 없으면 전화번호로 다시 확인해요.

## 연락처 유입 경로별 동작

**폼과 Zapier:**

- **활성화됨**: 중복을 허용해요. 이메일이나 전화번호가 같아도 연락처가 따로 만들어져요.
- **비활성화됨**: 중복 연락처를 만드는 대신 기존 연락처를 새 정보로 업데이트해요.

**CSV 가져오기:**

- 전화번호나 이메일을 기준으로 중복 연락처가 자동 병합돼요.
- CSV로 가져올 때는 중복 연락처를 만들 수 없고, 항상 이 설정을 따라요. <!-- 검토 필요: 원문 내용이 서로 다름 (앞에서는 CSV 가져오기에 이 설정이 적용되지 않는다고 설명) -->

**Facebook·Instagram 대화:**

- **비활성화됨**: 처음에 Facebook이나 Instagram Messenger 연락처로 들어온 사람이 나중에 기존 연락처와 일치하는 이메일이나 전화번호를 알려 주면, 하이퍼클래스가 Messenger 연락처를 기존 연락처에 자동으로 병합해요. 대화와 상세 정보가 하나의 연락처 프로필에 모여요.
- **활성화됨**: 이메일이나 전화번호가 기존 연락처와 일치해도 Facebook·Instagram Messenger 연락처가 별도로 만들어질 수 있어요. 이 대화에는 자동 병합이 실행되지 않으므로, 직접 병합하기 전까지 중복이 남아 있을 수 있어요.

```
CSV로 연락처와 기회를 가져오는 방법은 'CSV로 연락처와 기회 가져오기' 문서를 참고하세요.
```

**Facebook·Instagram 연락처**

Facebook이나 Instagram 연락처가 나중에 기존 연락처와 일치하는 이메일 주소나 전화번호를 알려 주면, 중복 연락처가 비활성화된 경우 하이퍼클래스가 두 연락처를 자동으로 병합해요.

**연락처 중복 허용**이 활성화되어 있으면 자동 병합이 일어나지 않고, 별도의 연락처가 그대로 남을 수 있어요.

## 연락처 중복 환경설정 바꾸기

이 설정은 **설정 > 비즈니스 프로필 > Contact Deduplication Preferences**(연락처 중복 제거 환경설정)에 있어요. 중복을 찾는 기본 기준과 보조 기준을 정하는 등 세부 설정을 할 수 있어요. <!-- 검토 필요: 원문 내용이 서로 다름 (패널 이름이 'Contact Deduplication Preferences'와 'Contact Duplication Preferences'로 혼용됨) -->

#### 1단계: 비즈니스 프로필 설정 열기

1. 대시보드 왼쪽 아래의 **설정**을 클릭하세요.
2. **비즈니스 프로필** 화면이 열려요. 두 번째 왼쪽 메뉴 맨 위에도 같은 항목이 있어요.

![설정 메뉴에서 비즈니스 프로필 화면을 연 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052720496/original/YhbxIprLhrmIhlfBN2gDpyg9Z420P4msmQ.png?1756498017)

#### 2단계: 연락처 중복 환경설정 패널 찾기

1. 화면 오른쪽에서 **Contact Duplication Preferences**(연락처 중복 환경설정) 패널이 보일 때까지 아래로 스크롤하세요.
2. 이 패널에서 모든 설정을 바꿀 수 있어요. 각 설정의 자세한 설명은 위의 '환경설정 항목'을 참고하세요.
3. 이 패널에서 바꾼 내용은 자동으로 적용돼요. **저장**이나 **정보 업데이트** 버튼을 누를 필요가 없어요.

![연락처 중복 환경설정 패널 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155040612911/original/p9xvdNia1IYqmsbMrv3inMqwV1AJiqomXw.png?1738106845)

## 자주 묻는 질문

### CSV로 가져올 때도 중복 연락처가 만들어지나요?

아니요. CSV로 가져올 때는 중복 연락처를 만들 수 없어요. 이메일이나 전화번호를 기준으로 연락처가 자동 병합돼요.

### 연락처 중복 허용을 활성화하면 어떻게 되나요?

폼이나 Zapier로 전화번호나 이메일이 같은 연락처를 만들 수 있어요. CSV 업로드로는 중복 연락처를 만들 수 없어요.

### 이 설정을 켠 뒤에 중복 연락처를 병합할 수 있나요?

네, **연락처 병합** 기능으로 중복 연락처를 직접 병합할 수 있어요.

### 연동 서비스에서 중복 연락처가 생기지 않게 하려면 어떻게 하나요?

계정 설정에서 **연락처 중복 허용**을 비활성화하세요. 그러면 연동 서비스가 새 연락처를 만드는 대신 기존 연락처를 업데이트해요.
