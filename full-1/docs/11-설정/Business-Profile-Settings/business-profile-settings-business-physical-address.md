# 비즈니스 프로필 설정 — 비즈니스 주소

**비즈니스 프로필**의 **비즈니스 주소**, **시간대**, **플랫폼 언어** 항목과 커스텀 값 발신 언어 설정을 설명해요. 위치와 언어 관련 설정을 처음 맞출 때나 날짜·시간 표시가 이상할 때 참고하세요.

**비즈니스 주소**는 비즈니스 프로필에서 아주 중요한 항목이에요. 인증이 필요한 일부 기능에서 비즈니스를 확인할 때 이 정보를 쓸 수 있어요. 메시지, 소셜 게시물, 이메일 캠페인, 웹사이트, 퍼널에 커스텀 필드와 커스텀 값을 넣을 때도 쓰여요.

비즈니스 프로필 설정 화면으로 들어가는 방법 등 전체 내용은 [비즈니스 프로필 설정 개요](business-profile-settings.md)에서 확인하세요.

---

## 비즈니스 주소 설정

여기 있는 항목들은 하이퍼클래스에서 위치와 언어·지역 설정의 기준이 돼요. 공식 기록과 맞춰야 한다고 안내된 항목은 그대로 맞춰 꼼꼼히 입력하세요. 변경한 뒤에는 저장하세요. 그다음 예약 페이지와 테스트 이메일/SMS를 열어 날짜, 시간, 표시 형식이 제대로 나오는지 확인하세요.

## 비즈니스 주소

**비즈니스 주소**는 EIN(고용주 식별번호) 등록 정보에 있는 주소와 같아야 해요. 필요할 때 비즈니스를 인증하는 데 이 정보를 쓸 수 있어요.

![비즈니스 주소 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052631748/original/x6--PnYyPjfjHwYmMBMJXqWVqC-ebEb-nA.jpg?1756414676)

## 시간대

캠페인 안의 자동 이벤트는 **시간대** 필드를 기준으로 발송 시점을 정해요. 워크플로우나 이메일 캠페인처럼 기능에 따라 이 기본 시간대를 따로 바꿀 수 있는 경우도 있어요. 비즈니스 프로필 설정과 사용하는 기능의 설정에서 올바른 시간대가 선택되어 있는지 항상 확인하세요.

## 플랫폼 언어

**플랫폼 언어**는 서브 계정 화면이 어떤 언어로 표시될지 정하는 설정이에요. 영어를 읽고 쓴다면 서브 계정을 영어로, 스페인어를 쓴다면 스페인어로 표시하도록 맞추면 돼요.

{% hint style="info" %}
결제하는 사람이 보는 결제 페이지는 **플랫폼 언어** 설정을 따라요. 그래서 **인보이스**, **결제 링크**, **구독**, **카드 관리**, **폼**, 코스 구매의 호스팅 결제 화면에 모두 영향을 줘요.
{% endhint %}

**플랫폼 언어**는 **캘린더**, **서비스**, **대여**의 기본 알림 템플릿 언어도 정해요. 새로 만드는 구성에는 해당 언어의 기본 템플릿이 자동으로 적용돼요. 이미 만들어 둔 구성은 해당 알림 설정에서 **Reset to default**(기본값으로 재설정)를 선택하면 해당 언어 버전으로 불러와요. 직접 수정한 템플릿은 자동으로 덮어쓰이지 않아요.

![플랫폼 언어 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052632745/original/F8NSc17Feejb6xvLtszQGb9QUFHAjDa7LA.jpg?1756417290)

아래 예시는 **플랫폼 언어**를 스페인어로 바꾼 모습이에요. 애플리케이션의 모든 텍스트가 스페인어로 표시돼요.

![플랫폼 언어를 스페인어로 바꾼 화면 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052632740/original/yVaGyJSbiUChOuDogDT8rAa7ebLtLQeCqQ.jpg?1756417268)

## Outbound Communication Language for Custom Values(커스텀 값 발신 언어)

메시지에 커스텀 필드와 커스텀 값을 넣어 보낼 때, 받는 사람에게 그 정보를 어떤 언어로 보여 줄지 하이퍼클래스가 알아야 해요. **Outbound Communication Language for Custom Values**에서 알맞은 언어를 선택하세요. 메시지는 물론 웹사이트와 퍼널 등 커스텀 필드와 커스텀 값을 쓰는 모든 곳에 올바른 언어로 표시돼요.

![커스텀 값 발신 언어 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155052632760/original/N8XsKYkWAOeyiCWyLQBV8Fwkydyu49A1hQ.jpg?1756417360)

기본 언어를 바꾸면 어떤 커스텀 필드와 커스텀 값이 영향을 받는지 아래에서 확인하세요.

#### 지원 언어

- 영어
- 스페인어
- 프랑스어(프랑스)
- 프랑스어(캐나다)
- 네덜란드어
- 독일어
- 포르투갈어(브라질)
- 포르투갈어(포르투갈)
- 이탈리아어
- 스웨덴어
- 덴마크어
- 핀란드어
- 노르웨이어

#### 영향을 받는 커스텀 필드와 커스텀 값

이 설정에서 언어를 바꾸면 아래 커스텀 필드와 커스텀 값이 영향을 받아요. 앞으로 영향을 받는 항목이 더 늘어날 수 있어요. 이 목록은 필요할 때마다 최대한 업데이트할게요.

- *{{appointment.start\_time}}*
- *{{appointment.end\_time}}*
- *{{appointment.only\_start\_date}}*
- *{{appointment.only\_end\_date}}*
- *{{appointment.only\_start\_time}}*
- *{{appointment.only\_end\_time}}*
- *{{appointment.month}}*
- *{{appointment.month}}*
- *{{appointment.day\_of\_week}}*
- *{{right\_now.time}}*
- *{{right\_now.day}}*
- *{{right\_now.day\_of\_week}}*
- *{{right\_now.month}}*
- *{{right\_now.month\_english}}*
- *{{right\_now.month\_name}}*
- *{{right\_now.middle\_endian\_date}}*
- *{{right\_now.little\_endian\_date}}*
- *{{right\_now.hour}}*
- *{{right\_now.hour\_ampm}}*
- *{{right\_now.second}}*
- *{{right\_now.date}}*
