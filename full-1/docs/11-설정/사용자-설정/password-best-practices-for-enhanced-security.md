# 하이퍼클래스 비밀번호 요건과 보안 수칙

강력한 비밀번호와 안전한 인증 습관으로 내 계정과 고객 데이터, 비즈니스 정보를 지킬 수 있어요. 이 문서에서는 하이퍼클래스 자체 계정의 비밀번호 요건과 권장 수칙을 안내해요. 처음 비밀번호를 만드는 방법, 잊어버린 비밀번호를 재설정하는 방법, 로그인한 상태에서 비밀번호를 바꾸는 방법, 추가 보안 수칙도 함께 다뤄요.

## 하이퍼클래스 비밀번호 요건

하이퍼클래스 비밀번호 요건은 이메일 주소와 비밀번호로 로그인하는 자체 계정에 적용되는 기본 보안 기준이에요. 필수 조건과 권장 수칙을 알아 두면 하이퍼클래스가 받아 주는 비밀번호를 만들 수 있고, 무단 접근 위험도 줄일 수 있어요.

새로 만들거나 변경하는 비밀번호는 모두 아래 조건을 충족해야 해요.

- 12자 이상
- 영문자 포함
- 숫자 포함
- 대문자 포함
- 소문자 포함
- !, @, #, $ 같은 특수문자 포함
- 다른 계정에서 쓰지 않는 고유한 조합

조건을 충족하지 못하면 비밀번호를 만들거나 재설정할 때 거부돼요. 그러면 하이퍼클래스가 더 강력한 비밀번호를 만들라고 안내해요.

{% hint style="warning" %}
이 요건은 하이퍼클래스 자체 비밀번호에만 적용돼요. 싱글 사인온(SSO)이나 다른 외부 인증 제공업체로 로그인한다면, 비밀번호를 해당 제공업체에서 관리해야 할 수 있어요.
{% endhint %}

## 강력한 비밀번호의 장점

강력한 비밀번호는 무작위 대입이나 계정 정보를 노린 공격을 어렵게 만들어요. 이 수칙을 꾸준히 지키면 사용자 본인뿐 아니라 계정으로 볼 수 있는 고객 정보도 함께 지킬 수 있어요.

- 계정 탈취 위험 감소: 길고 예측하기 어려운 비밀번호는 권한 없는 사람이나 자동화 도구가 알아내기 더 어려워요.
- 고객 데이터 보호: 사용자 계정을 안전하게 지키면 연락처, 대화, 워크플로우 등 비즈니스 정보에 무단으로 접근하는 일을 막을 수 있어요.
- 비밀번호 재사용 방지: 고유한 비밀번호를 쓰면 다른 웹사이트에서 정보가 유출돼도 하이퍼클래스 계정이 바로 노출되지 않아요.
- 더 안전한 팀 접근: 비밀번호 관리 습관이 좋으면 에이전시와 서브 계정 팀 전체가 더 안전하게 계정을 쓸 수 있어요.
- 2단계 인증과 함께 쓸 때 추가 보호: 강력한 비밀번호에 2단계 인증을 더하면 여러 겹으로 계정을 보호할 수 있어요.

## 로그인 방식별 비밀번호 요건

조직이 사용자를 인증하는 방식에 따라 비밀번호를 복구하는 절차가 달라요. 내 로그인 방식을 먼저 확인하면 불필요하게 재설정을 시도하지 않아도 되고, 하이퍼클래스가 비밀번호를 직접 관리하지 않을 때 누구에게 문의해야 하는지도 알 수 있어요.

### 하이퍼클래스 자체 로그인

하이퍼클래스 로그인 페이지에서 이메일 주소와 하이퍼클래스 비밀번호를 직접 입력해 로그인한다면 위의 비밀번호 요건이 적용돼요.

자체 비밀번호 절차로 다음 작업을 할 수 있어요.

- 계정 접근 권한을 받은 뒤 비밀번호 만들기
- 잊어버린 비밀번호 재설정하기
- 로그인한 상태에서 비밀번호 변경하기

### 싱글 사인온 또는 외부 인증

조직에서 싱글 사인온이나 다른 외부 인증 제공업체로 사용자를 인증할 수 있어요. 이 경우 비밀번호는 하이퍼클래스 밖에서 관리될 수 있어요.

아래와 같은 경우에는 조직 관리자에게 문의하세요.

- 자체 비밀번호 옵션이 보이지 않을 때
- 조직에서 싱글 사인온을 필수로 쓸 때
- 다른 제공업체의 로그인 페이지로 이동할 때
- 하이퍼클래스 비밀번호를 재설정해도 접속 상태가 달라지지 않을 때

## 처음 비밀번호 설정하기

계정을 처음 만들 때 안전한 비밀번호를 설정하면 계정을 지키는 첫 번째 방어선이 생겨요. 받은 계정 이메일로 설정을 진행하고, 비밀번호가 모든 필수 조건을 충족하는지 확인한 뒤 제출하세요.

1. 하이퍼클래스 사용자 계정에 연결된 받은편지함에서 환영 이메일 또는 계정 활성화 이메일을 찾아 열어요. 에이전시가 시스템 이메일 템플릿을 사용자 지정했다면 이메일 문구와 브랜딩이 다를 수 있어요.
2. 이메일에 있는 계정 설정 링크나 버튼을 선택해 비밀번호 설정을 시작해요.
3. 아래 조건을 충족하는 새 비밀번호를 입력해요.
   - 12자 이상
   - 대문자와 소문자 포함
   - 숫자 1개 이상 포함
   - 특수문자 1개 이상 포함
4. 확인 입력란에 같은 비밀번호를 한 번 더 입력해요.
5. **비밀번호 변경**을 선택해 설정을 마쳐요. 안내에 따라 계정 이메일과 새 비밀번호로 로그인하세요.

{% hint style="info" %}
에이전시와 서브 계정 관리자는 사용자 관리 설정에서 로그인 이메일과 비밀번호 입력란을 포함한 사용자 정보를 관리할 수 있어요. 접근 권한과 사용할 수 있는 작업은 관리자의 역할과 권한에 따라 달라요.
{% endhint %}

## 잊어버린 비밀번호 재설정하기

현재 비밀번호를 몰라도 비밀번호를 재설정해서 다시 접속할 수 있어요. 하이퍼클래스는 사용자 프로필에 연결된 주소로 재설정 안내를 보내므로 올바른 계정 이메일을 입력하는 것이 중요해요.

1. 하이퍼클래스 로그인 페이지로 이동해 **비밀번호 찾기**를 선택해요.

   ![로그인 페이지에서 비밀번호 찾기 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077689008/original/VoTDj42r0enJid1QEdJWkeKjsRWlK_gXKA.png?1785930537)

2. 하이퍼클래스 계정에 연결된 이메일 주소를 입력하고 비밀번호 재설정을 요청해요.

   ![이메일 주소 입력 후 재설정 요청](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077689163/original/A7bGmc3T-eZeyo3Lt41y5o3mAI5g9coQgw.png?1785930589)

3. 받은편지함에서 비밀번호 재설정 이메일을 확인하고, 이메일 안의 재설정 링크나 버튼을 선택해요. 이메일 디자인, 브랜딩, 버튼 문구는 에이전시마다 다를 수 있어요.

   ![받은편지함의 비밀번호 재설정 이메일](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077689429/original/u7nXiP1hSSelzRNP8RtKglorxuuHJxaJsQ.png?1785930678)

4. 하이퍼클래스 비밀번호 요건을 충족하는 새 비밀번호를 입력하고, 확인을 위해 한 번 더 입력해요.

   ![새 비밀번호 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077689471/original/N7LHyAFn1v4B3Xc5-q_QeOhi4DcVJgzahQ.png?1785930706)

5. **저장**을 선택해 새 비밀번호를 설정해요. 그다음 로그인 페이지로 돌아가 새 비밀번호로 로그인하세요.

### 재설정 이메일이 오지 않을 때

추가로 도움을 요청하기 전에 아래 방법을 먼저 해 보세요.

- 스팸, 정크, 프로모션 또는 필터링된 메일함을 확인해요.
- 하이퍼클래스 사용자 프로필에 등록된 이메일 주소를 입력했는지 확인해요.
- 받은편지함에서 하이퍼클래스나 소속 에이전시가 보낸 메일을 검색해요.
- 이메일이 도착할 때까지 몇 분 기다려요.
- 비밀번호 재설정을 새로 한 번만 요청하고, 가장 최근에 온 이메일을 사용해요.
- 에이전시 관리자에게 내 사용자 프로필에 등록된 로그인 이메일이 맞는지 확인해 달라고 요청해요.

문제가 계속되면 에이전시 관리자에게 문의하거나 사용할 수 있는 하이퍼클래스 고객지원 채널을 이용하세요. 이용할 수 있는 고객지원 채널은 사용자 역할에 따라 달라요.

## 로그인한 상태에서 비밀번호 변경하기

이전 비밀번호를 바꾸고 싶거나 보안 문제가 의심될 때는 로그인한 상태에서 비밀번호를 변경하면 좋아요. 계정 정보가 노출됐을 수 있을 때 새롭고 고유한 비밀번호로 바꾸면 이후의 무단 접근을 막는 데 도움이 돼요.

1. 하이퍼클래스에 로그인한 뒤 **설정**으로 이동해 **내 프로필**을 열어요.
2. 프로필 페이지에서 **비밀번호 변경** 섹션을 찾아요.

   ![프로필 페이지의 비밀번호 변경 섹션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077689575/original/NHYRISxC2Nbm49N3dkVUqTH4R2SsUtNzRA.png?1785930789)

3. 현재 비밀번호를 해당 입력란에 입력해요.
4. 필수 조건을 충족하는 새 비밀번호를 입력하고, 확인 입력란에 한 번 더 입력해요.
5. **Update Password**(비밀번호 업데이트)를 선택해요. 안내가 나오면 새 비밀번호로 다시 로그인하세요.

{% hint style="info" %}
비밀번호를 바꾸면 진행 중인 세션이 종료되어 다시 로그인해야 할 수 있어요. 변경하기 전에 작업 중인 내용을 저장해 두세요.
{% endhint %}

## 계정을 더 안전하게 지키는 방법

비밀번호 보안은 안전한 인증 습관과 함께할 때 가장 효과적이에요. 다른 인증 수단을 추가하고 계정 복구 경로를 보호하면, 계정 정보 하나가 노출되더라도 무단 접근으로 이어질 가능성을 줄일 수 있어요.

- 인증 앱으로 2단계 인증을 켜세요.
- 백업 코드는 비밀번호와 다른 안전한 곳에 보관하세요.
- 하이퍼클래스에 연결된 이메일 계정의 접근도 보호하세요.
- 예상하지 못한 로그인이나 인증 요청은 승인하지 마세요.
- 사용자 접근 권한을 정기적으로 점검하고, 더 이상 필요 없는 사람은 제거하세요.
- 공용 기기나 공공장소의 기기에서는 로그인하지 마세요.
- 내가 관리하지 않는 기기에서 하이퍼클래스를 쓴 뒤에는 로그아웃하세요.
- 예상하지 못한 비밀번호 재설정 이메일이나 의심스러운 계정 활동은 바로 신고하세요.

### 2단계 인증

하이퍼클래스는 시간 기반 일회용 비밀번호(TOTP) 방식의 인증 앱을 지원해요. Google Authenticator, Microsoft Authenticator, Authy와 호환되는 다른 앱을 쓸 수 있어요. 인증 앱을 사용할 수 없을 때는 백업 코드로 계정을 복구할 수 있어요.
