# 서브 계정 사용자 역할, 권한, 할당된 데이터 설정

사용자 역할과 권한을 설정하면 서브 계정 안에서 사용자마다 접근하고 관리할 수 있는 범위를 정할 수 있어요. **관리자**와 **사용자** 역할을 지정하고, 모듈 권한과 세부 권한을 설정하고, **할당된 데이터만**으로 볼 수 있는 기록을 제한하고, 다른 사용자의 권한 설정을 복사할 수 있어요.

## 사용자 역할과 권한이란?

서브 계정의 역할과 권한은 특정 서브 계정 안에서 사용자가 쓸 수 있는 기능, 볼 수 있는 데이터, 할 수 있는 작업을 정해요.

사용자의 역할은 다음 두 가지 중 하나예요.

- **관리자**: 서브 계정 안에서 관리자 권한을 가져요. 지원되는 세부 권한 설정에 따라 범위가 달라질 수 있어요.
- **사용자**: 해당 사용자에게 설정된 권한에 따라 접근할 수 있어요.

모듈 권한, 세부 권한, **할당된 데이터만**으로 접근 범위를 더 세밀하게 조정할 수 있어요.

## 서브 계정 역할과 권한 설정하기

담당 업무에 필요한 접근 범위에 맞춰 사용자마다 역할과 권한을 설정하세요.

### 1단계: 사용자 화면 열기

관리할 서브 계정을 열고 **설정 > 사용자**로 이동하세요.

![사용자 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082695300/original/_JtVXk0GnvGBwyeVUz9ThQoci3k3Pl6xtA.png?1791346418)

### 2단계: 사용자 열기 또는 추가하기

기존 사용자의 접근 권한을 바꾸려면 해당 사용자를 열고, 새 사용자를 만들려면 **+ Add User**(+ 사용자 추가)를 클릭하세요. <!-- 검토 필요: 원문 내용이 서로 다름 -->

새로 바뀐 사용자 화면에는 사용자 검색, 새로 설계된 추가·편집 화면, 더 알기 쉬운 역할·권한 설정, 개선된 사용자 관리 안내가 들어 있어요.

사용자를 만들 때는 착신 전환과 음성사서함 설정이 함께 나올 수 있어요. 입력한 이메일 주소가 이미 기존 사용자의 주소라면, 사용자를 중복으로 만들지 말고 사용자 화면에 나오는 안내를 따르세요.

![사용자 추가 및 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082695045/original/VMzcxx_nhj1L1Gw-mFc5-OF2SZSob7_CYA.png?1791345816)

### 3단계: 사용자 역할 지정하기

**Roles & Permissions**(역할 및 권한)를 열고 알맞은 역할을 선택하세요.

- **관리자**: 서브 계정 안에서 관리자 권한을 가져요. 지원되는 설정 가능 권한에 따라 범위가 달라질 수 있어요.
- **사용자**: 해당 사용자에게 설정된 권한에 따라 접근 범위가 정해져요.

### 4단계: 모듈 권한과 세부 권한 설정하기

권한 설정 항목에서 지원되는 모듈과 작업의 접근을 허용하거나 제한하세요.

**폼**, **설문**, **퀴즈**, **QR 코드**는 모듈 설정과 **View & manage**(보기 및 관리) 권한으로 조정해요.

### 제휴 지급 권한

**마케팅**에 있는 **Pay Affiliate Manager Payout**(제휴 관리자 지급 결제) 권한은 해당 관리자가 제휴 지급을 처리할 수 있는지를 정해요.

- 서브 계정 관리자: 이 권한이 기본으로 켜져 있고, 켜거나 끌 수 있어요.
- 서브 계정 사용자: 제휴 지급을 처리할 수 없어요.

이 권한을 끄면 **제휴 관리자**에서 **결제**나 **Pay Payout**(지급 결제) 같은 지급 작업이 표시되지 않아요.

![제휴 지급 권한 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082695203/original/l8CcX0M3N6fB7IHpa_t_cG5yJUNn37cdwA.png?1791346093)

### 5단계: 할당된 데이터만 설정하기

지원되는 기록을 사용자에게 할당된 데이터로만 제한하려면 **할당된 데이터만**을 켜세요.

![할당된 데이터만 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082695362/original/O212dDsqAWjRS0bo33uP83UhsEKUgDCAOA.png?1791346510)

### 6단계: 변경 내용 저장하기

**저장**을 클릭하면 사용자의 역할과 권한 설정이 적용돼요.

## 할당된 데이터만으로 볼 수 있는 기록 제한하기

**할당된 데이터만**을 켜면 사용자는 자신과 연결된 기록만 볼 수 있어요. 다른 사용자의 데이터 대신 자기에게 할당된 업무에 집중하게 하고 싶을 때 쓰면 좋아요.

모듈에 따라 할당된 데이터는 다음과 같아요.

- 사용자에게 할당된 연락처
- 사용자가 담당하는 기회
- 사용자와 연결된 예약이나 작업

예를 들어 영업 담당 사용자는 다른 사용자의 파이프라인 데이터 대신 자신에게 할당된 연락처와 기회만 보도록 제한할 수 있어요.

![할당된 데이터만 적용 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082695269/original/KmB3-5eSJsQhF718mZ3y9YXilEcHydbKYg.png?1791346307)

## 사용자 간 권한 복사하기

**권한 복사**를 쓰면 권한을 하나씩 설정하는 대신, 기존 사용자의 세부 권한 설정을 그대로 가져올 수 있어요.

1. **설정 > 사용자**로 이동하세요.
2. 해당 사용자를 열거나, **+ 직원 추가**를 클릭해 새 사용자를 만드세요.
3. **Roles & Permissions**를 선택하세요.
4. **권한 복사**를 클릭하세요.
5. **권한 복사** 드롭다운에서 복사해 올 사용자를 선택하세요.
6. **복사**를 클릭하면 권한 설정이 적용돼요.

저장하기 전에 권한을 받는 사용자의 담당 업무를 확인해서, 복사된 권한이 알맞은지 점검하세요.

![권한 복사 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155082695235/original/zFz_h3i8rIQFkbGHeXYqmh2v7-GvNnAv2g.png?1791346178)

## 모듈별 세부 권한

세부 권한으로 각 모듈 안의 작업을 더 정밀하게 제어할 수 있어요. 사용할 수 있는 권한은 사용자의 역할과 서브 계정에서 쓸 수 있는 기능에 따라 달라요.

권한을 설정할 수 있는 영역은 다음과 같아요.

- **AI 에이전트** — 지원되는 관리형 에이전트, 음성, 채팅 기능 포함
- **AI 스튜디오**
- **계정 설정**
- **계정 도구**
- **자동화** — 워크플로우 포함
- **블로그**
- **캘린더**
- **수료증**
- **커뮤니티**
- **연락처**
- **대화**
- **대시보드**
- **폼**
- **퍼널**
- **GoKollab**
- **연동**
- **마케팅**
- **미디어**
- **멤버십**
- **기회 관리**
- **결제**

- **WordPress**

## 자주 묻는 질문

### 사용자에게 모듈을 비활성화했는데 그 모듈이 워크플로우에서 쓰이고 있으면 어떻게 되나요?
해당 사용자는 비활성화된 모듈에 접근할 수 없지만, 기존 워크플로우는 계속 실행될 수 있어요. 그 자동화를 관리할 권한이 있는 사용자가 필요한 접근 권한을 유지하고 있는지 확인하세요.

### 캘린더마다 다른 권한을 줄 수 있나요?
네. 캘린더 권한은 세부 설정을 지원해서, 지원되는 범위에서 캘린더 접근과 관리 기능을 제한할 수 있어요.

### 여러 사용자에게 권한을 한꺼번에 줄 수 있나요?
아니요. **권한 복사**로 한 사용자의 권한 설정을 다른 사용자에게 복사하세요.

### 에이전시 관리자와 서브 계정 관리자는 무엇이 다른가요?
에이전시 관리자는 에이전시 수준에서 활동하고, 서브 계정 관리자는 해당 서브 계정 안에서 관리자 권한을 가져요.

### 에이전시 관리자가 아니어도 여러 서브 계정을 관리할 수 있나요?
네. 계정 유형 사용자에게 선택한 서브 계정의 접근 권한을 줄 수 있어요. 에이전시 전체에 대한 권한은 받지 않아요.
