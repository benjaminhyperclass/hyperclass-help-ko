# SaaS 멀티 브랜드 개요

하나의 SaaS 계정에서 최대 2개의 독립된 브랜드를 운영할 수 있는 기능이에요. 브랜드마다 브랜딩, 도메인, 화이트라벨 설정을 따로 둘 수 있어요. 이 문서에서는 멀티 브랜드가 무엇인지, 브랜드별로 무엇을 설정하는지, 브랜드를 서브 계정이나 SaaS 플랜 카테고리에 어떻게 연결하는지 설명해요. 에이전시 관리자만 쓸 수 있는 기능이에요.

{% hint style="info" %}
SaaS 멀티 브랜드는 현재 비공개 베타 기능이에요. 일부 에이전시에만 제공되고 있어요. 공개 베타는 2~3주 이내에 시작할 예정이에요. 베타 기간 중 받은 의견에 따라 기능이 달라질 수 있어요.
{% endhint %}

## SaaS 멀티 브랜드란?

SaaS 멀티 브랜드를 쓰면 하나의 하이퍼클래스 SaaS 계정에서 최대 2개의 독립된 브랜드를 관리할 수 있어요. 브랜드마다 화이트라벨 설정이 따로 있어서, 시장이나 고객군, 업종에 맞춰 서로 다른 브랜드로 서비스할 수 있어요. 에이전시 계정은 하나만 있으면 돼요.

각 브랜드는 고유한 브랜딩 요소를 설정할 수 있어요. 특정 서브 계정에 연결할 수도 있고, SaaS 플랜 카테고리를 통해 자동으로 배정할 수도 있어요. 브랜드마다 에이전시 계정을 따로 관리하지 않아도 돼요.

하나의 화면에서 브랜드를 전환하면서 각 브랜드의 설정, 구성, 서브 계정 배정을 관리할 수 있어요.

## 주요 이점

계정을 따로 관리하는 번거로움 없이 여러 브랜드를 운영할 수 있어요.

- 여러 시장 대응: 고객군, 지역, 업종별로 서로 다른 브랜드를 하나의 에이전시 계정에서 운영해요.
- 새로운 틈새시장 탐색: 기존 브랜드는 그대로 두고, 두 번째 브랜드로 새로운 시장이나 서비스를 시험해 볼 수 있어요.
- 간편한 계정 관리: 에이전시 계정이나 로그인 정보를 따로 관리하지 않고, 하나의 에이전시 대시보드에서 여러 브랜드를 관리해요.
- 맞춤형 고객 경험: 브랜드마다 로고, 도메인, 테마, 연락처를 다르게 적용해 브랜드가 분명히 드러나는 환경을 제공해요.
- 유연한 브랜드 배정: 브랜드를 서브 계정에 하나씩 연결하거나, SaaS 플랜 카테고리로 자동 배정할 수 있어요.

## 브랜드별로 설정할 수 있는 항목

각 브랜드는 아래 화이트라벨 설정과 브랜딩 요소를 독립적으로 설정할 수 있어요.

### 1. 브랜드 이름과 로고

브랜드마다 고유한 이름을 정하고 로고를 업로드해요. 고객이 만나는 모든 접점에서 브랜드가 일관되게 보여요.

### 2. 화이트라벨 도메인

브랜드마다 화이트라벨 도메인을 따로 설정해요. 고객은 해당 브랜드의 URL로 계정에 접속해요.

### 3. API 도메인

브랜드마다 사용자 지정 API 도메인을 설정해요. API 연동과 웹훅이 브랜드 정체성과 맞게 동작해요.

### 4. 브랜드 이메일과 전화번호

브랜드마다 연락용 이메일 주소와 **전화번호**를 따로 지정해요. 고객이 브랜드별 지원 채널로 문의할 수 있어요.

### 5. 테마 사용자 지정

브랜드마다 다른 테마를 적용해요. 색상 구성, 버튼 스타일, 레이아웃 설정이 포함돼요.

### 6. 사용자 지정 CSS와 JavaScript

브랜드마다 CSS와 JavaScript를 따로 넣을 수 있어요. 화면과 기능을 더 세밀하게 조정할 수 있어요.

### 7. 개인정보처리방침 및 이용약관 URL

브랜드마다 **개인정보처리방침**과 서비스 이용약관 URL을 따로 지정해요. 브랜드별 법적 문서를 제공할 수 있어요.

{% hint style="info" %}
각 브랜드는 독립된 화이트라벨 설정으로 운영돼요. 한 브랜드의 설정을 바꿔도 다른 브랜드에는 영향이 없어요.
{% endhint %}

## 사용 가능 대상과 플랜 조건

SaaS 멀티 브랜드는 497달러 Founder 플랜을 구독한 고객만 쓸 수 있어요. 다른 플랜을 쓰는 에이전시는 이 기능을 사용할 수 없어요.

비공개 베타 기간에는 처음 20~30개 에이전시에 기능이 켜져 있어요. 2~3주 이내에 공개 베타가 시작되면, 이후에는 Pro 플랜을 쓰는 모든 에이전시가 사용할 수 있어요.

## 멀티 브랜드 설정 방법

여러 브랜드를 만들고 설정하려면 다음 단계를 따르세요. 브랜드 전환, 브랜드별 설정, 서브 계정이나 SaaS 플랜 카테고리 연결을 모두 에이전시 대시보드에서 관리해요.

1. **에이전시 대시보드**에서 **SaaS Configuration**(SaaS 구성) 영역으로 이동하세요. 모든 브랜드 설정을 여기서 관리해요.
2. 새 브랜드를 만드는 옵션을 클릭하세요. 에이전시 계정당 브랜드는 최대 2개까지 만들 수 있어요.
3. 새 브랜드의 이름을 입력하고 로고를 업로드하세요.
4. 새 브랜드의 화이트라벨 설정을 하세요. 화이트라벨 도메인, API 도메인, 브랜드 이메일, **전화번호**, 테마, 사용자 지정 CSS/JavaScript, **개인정보처리방침**·이용약관 URL을 설정해요. 각 설정은 다른 브랜드와 독립적이에요.
5. 기본 브랜드를 지정하세요. 기본 브랜드는 에이전시 전체 설정의 대체 브랜드예요. 서브 계정이나 SaaS 플랜 카테고리에 지정된 브랜드가 없으면 이 브랜드가 쓰여요.
6. 브랜드를 서브 계정에 연결하세요. 서브 계정에 브랜드를 연결하면, 고객이 그 서브 계정에 접속할 때 연결된 브랜드의 브랜딩, 도메인, 설정이 보여요.
7. 브랜드를 SaaS 플랜 카테고리에 연결해 자동으로 배정하세요. 고객이 구독한 플랜에 따라 브랜딩이 자동으로 정해져요. 플랜 등급별로 다른 브랜드 경험을 주면서도 일일이 배정하지 않아도 돼요.
8. 브랜드를 전환하며 설정을 관리하세요. **SaaS Configuration**의 브랜드 전환 기능으로 브랜드를 바꿔 가며 각 브랜드의 설정을 따로 관리할 수 있어요. 한 브랜드를 바꿔도 다른 브랜드에는 영향이 없어요.

{% hint style="info" %}
설정이 끝났어요. 각 브랜드에 연결된 서브 계정이나 플랜에 접속하는 고객에게는 해당 브랜드의 브랜딩과 화이트라벨 설정이 보여요.
{% endhint %}
