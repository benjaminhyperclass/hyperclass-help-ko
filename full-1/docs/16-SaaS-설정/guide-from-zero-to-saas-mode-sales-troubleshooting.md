# SaaS 모드 시작부터 판매까지 가이드 및 문제 해결

SaaS 모드를 쓰면 에이전시가 하이퍼클래스를 자기 브랜드로 재판매할 수 있어요. 이 문서에서는 SaaS가 무엇인지, SaaS 모드를 왜 쓰는지, 설정은 어떤 순서로 하는지 알려 드려요.

SaaS 모드에서는 고객사에 에이전시 브랜드가 적용된 맞춤형 환경을 제공할 수 있어요. 화이트라벨 기능이 하이퍼클래스 브랜드 표시를 모두 없애 주기 때문에, 에이전시는 서비스를 넓히고 반복 수익을 늘리는 방법을 간단하고 부담 없는 비용으로 얻게 돼요.

---

## SaaS란 무엇인가요?

SaaS는 "Software-as-a-Service"의 약자예요. 소프트웨어를 클라우드에 두고, 사용자가 인터넷으로 구독해서 쓰는 제공 방식을 말해요. SaaS를 쓰면 컴퓨터나 기기에 프로그램을 설치하거나 직접 관리하지 않고 웹 브라우저로 소프트웨어와 기능을 이용할 수 있어요.

SaaS에는 다음과 같은 장점이 있어서 널리 쓰이는 소프트웨어 제공 방식이 되었어요.

- 쉬운 확장
- 자동 업데이트
- 낮은 초기 비용
- 높은 접근성

이메일 마케팅 플랫폼, 고객 관계 관리(CRM) 시스템, 프로젝트 관리 도구 같은 많은 소프트웨어가 SaaS 형태로 제공돼요.

---

## SaaS 모드를 왜 쓰나요?

SaaS 모드를 쓰면 에이전시가 하이퍼클래스 소프트웨어를 자기 브랜드로 바꿔서 쓸 수 있어요. 고객사에는 에이전시만의 플랫폼을 제공하면서도, 하이퍼클래스 원래의 기능은 그대로 이용할 수 있어요.

SaaS 모드는 화이트라벨도 지원해요. 소프트웨어를 하이퍼클래스 브랜드 표시 없이 에이전시의 것처럼 꾸밀 수 있어요. 그래서 고객사는 끊김 없이 하나로 연결된 환경을 쓰게 되고, 에이전시는 서비스를 더 쉽게 제공할 수 있어요.

설정이 간단하고 편리하며 비용 부담도 적어요. 서비스 범위를 넓히고 반복 수익을 늘리려는 에이전시에 알맞은 선택이에요.

## SaaS 모드 설정

```
이해하기 어려운 내용이 있으면 용어집이나 하이퍼클래스 기본 개념 개요를 참고하세요.
```
{% endhint %}

아직 하이퍼클래스 에이전시 계정이 없다면 하이퍼클래스 고객지원에 문의하세요.

### 에이전시 서브 계정 설정

1. 에이전시 서브 계정을 만들어요.
2. **전화 시스템**을 활성화해요. 아래 도움말을 참고하세요.
   1. 에이전시와 서브 계정을 하이퍼클래스 전화로 이전하려면 어떻게 하나요?
   2. 하이퍼클래스 전화 시스템이란?
   3. 하이퍼클래스 전화 요금 구조
   4. 하이퍼클래스 전화 시스템 **신뢰 센터**
   5. 하이퍼클래스 전화 관련 전체 도움말
3. 화이트라벨 도메인을 설정해요.
   1. 데스크톱 앱 화이트라벨 설정
4. API 도메인 URL을 설정해요.
   1. 시스템이 만드는 링크에 브랜드 적용하기(API 도메인)
5. 프리미엄 기능을 활성화해요.
   1. **콘텐츠 AI**
   2. 워크플로우용 하이퍼클래스 프리미엄 트리거 및 액션을 활성화하고 재청구하는 방법
   3. 워크플로우 AI를 활성화하고 재청구하는 방법
   4. **템플릿 라이브러리**는 어떻게 작동하나요?
   5. 경험 최적화 기능
6. 에이전시 계정 수준에서 **결제 제공업체 연결**을 해요.

7. SaaS 플랜과 상품을 만들고 설정해요.
   1. SaaS 구성기 온보딩
   2. SaaS 플랜 생성 및 판매 가이드
