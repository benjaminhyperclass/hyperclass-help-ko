# SMTP 서비스에서 이메일 발송 비용 계산하기

사용 중인 SMTP 서비스의 요금제로 이메일 1건당 비용을 계산하는 방법을 안내해요. 어떤 이메일 서비스를 써야 할지 고르는 기준도 함께 정리했어요.

![SMTP 서비스 요금제 화면 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48120436123/original/Tw23HUiCJ8NkoaGoLo4mF2wupkmzxD99JQ.png?1626186619)

## 이메일 비용 계산하기

1. 사용 중인 SMTP 서비스에 로그인한 뒤 요금제 또는 결제 관련 메뉴로 이동해서, 요금제에 이메일이 몇 건 포함되어 있는지 확인하세요.
2. 요금제에 포함된 이메일 수를 요금제 가격으로 나누면 이메일 비용이 나와요.

<!-- 검토 필요: 원문 내용이 서로 다름 -->

예를 들어 월 $35인 Mailgun 요금제에는 이메일 50,000건이 포함돼요. 그래서 35/50000으로 계산하면 이메일 비용은 $0.0007이에요.

## 어떤 이메일 서비스를 써야 할까요?

바로 쓸 수 있는 설정을 원하는지, 이미 쓰던 SMTP 도구가 있는지에 따라 알맞은 서비스가 달라져요.

- 하이퍼클래스 이메일: Mailgun 설정 없이, 활성화하면 하이퍼클래스 안에서 이메일을 보내고 받고 싶을 때 가장 알맞아요.
- Mailgun: 하이퍼클래스에서 대량 이메일을 보낼 때 많이 쓰는 서비스예요. 특히 여러 서브 계정과 도메인을 관리하는 에이전시에서 자주 써요.
- SMTP(기타 서비스): 사용할 수는 있어요. 다만 이메일 열람·클릭 같은 통계를 더 잘 추적할 수 있도록 하이퍼클래스에서는 Mailgun이나 하이퍼클래스 이메일을 권장해요.

```
하이퍼클래스 이메일을 활성화한 경우: Mailgun은 필요 없어요. 하이퍼클래스 이메일은 Mailgun이나 다른 외부 이메일 서비스에 가입하지 않아도 되도록 만들어졌어요.

하이퍼클래스 이메일을 활성화하지 않은 경우: Mailgun(대량 발송에 많이 쓰는 서비스) 또는 지원되는 다른 SMTP 서비스 같은 이메일 서비스를 연결해야 해요.
