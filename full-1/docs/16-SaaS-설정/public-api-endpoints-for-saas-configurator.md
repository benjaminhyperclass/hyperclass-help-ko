# SaaS 구성기 공개 API 엔드포인트

**SaaS 구성기**(SaaS Configurator)에서 쓸 수 있는 공개 API 목록을 소개해요. 개발자와 에이전시 관리자는 이 API로 SaaS 환경을 외부 시스템과 연동하고 자동화할 수 있어요.

## 이런 분께 필요해요

이 API를 쓰면 하이퍼클래스를 다른 업무 시스템과 연결할 수 있어요. 수작업은 줄고 자동화는 늘어서, SaaS 비즈니스 흐름을 직접 제어하기 쉬워져요.

이런 분들에게 맞아요.

- 하이퍼클래스 기반으로 앱을 만드는 마켓플레이스 개발자
- SaaS 온보딩, 결제 관리, 리포팅을 자동화하려는 에이전시
- 맞춤형 대시보드, 앱, 관리자 도구를 만드는 분

## SaaS 구성기 공개 API란?

맞춤 연동이나 대규모 자동화에는 화면을 하나하나 클릭하는 대신 코드로 접근하는 방법이 필요해요. SaaS 구성기 공개 API를 쓰면 에이전시와 개발자가 코드에서 바로 다음 작업을 할 수 있어요.

- 플랜 조회
- SaaS 구독 관리
- 여러 서브 계정에 SaaS 모드 켜기

덕분에 온보딩이 빨라지고, 분석 자료가 풍부해지고, 외부 서비스와 워크플로우를 매끄럽게 연결할 수 있어요.

## 주요 장점

이 엔드포인트를 활용하면 SaaS 운영을 더 유연하게 제어하고 확장할 수 있어요. 번거로운 과정이 줄어서 운영 규모를 키우기도 쉬워져요.

- **깊은 연동:** 데이터를 수동으로 내보내지 않아도 하이퍼클래스를 외부 앱, CRM, 파트너 플랫폼과 연결할 수 있어요.
- **자동 프로비저닝:** 스크립트나 iPaaS 도구로 플랜 배정, 갱신, 업그레이드를 실행할 수 있어요.
- **SaaS 일괄 활성화:** API 호출 한 번으로 서브 계정 수백 개를 몇 분 안에 온보딩할 수 있어요.
- **실시간 분석:** 최신 플랜·구독 데이터를 맞춤형 대시보드로 가져올 수 있어요.
- **운영 효율:** 반복 작업을 없애고, 대규모 이전 작업에서 사람의 실수를 줄여요.

## 새로 추가된 SaaS 구성기 API 엔드포인트

SaaS 워크플로우를 관리하는 개발자를 위한 엔드포인트예요.

{% hint style="warning" %}
**빠른 시작 전 확인하세요.** SaaS 구성기 엔드포인트를 호출하기 전에 아래 항목을 확인하세요.

- 에이전시에서 SaaS 모드가 켜져 있어야 해요.
- `saas/*` 스코프가 있는 OAuth 2.0 자격 증명을 만들고, 액세스 토큰을 받아야 해요.
- 전체 요청 제한인 초당 10건을 지켜야 해요.

단계별 안내는 SaaS 구성기 온보딩 가이드와 하이퍼클래스 API 문서를 참고하세요.
{% endhint %}

### 1. Get All Agency Plans(에이전시 전체 플랜 조회)

에이전시에 설정된 SaaS 플랜을 모두 가져와요. 플랜 선택 메뉴를 동적으로 보여 주거나 플랜 비교 도구를 만들 때 알맞아요. 자세한 내용은 Get All Agency Plans 문서를 참고하세요.

- 활용 예: 외부 앱에 최신 플랜 옵션을 실시간으로 보여 줘요.
- 예시 엔드포인트: `GET /saas/agency/plans`
- 응답 예시: 플랜 ID, 이름, 가격, 포함 기능이 담긴 JSON 배열

### 2. Get Location Subscription Details(서브 계정 구독 세부정보 조회)

특정 서브 계정의 구독 상태, 플랜 세부정보, 결제 제공업체, 청구 데이터를 가져와요. 자세한 내용은 Get Location Subscription Details 문서를 참고하세요.

- 활용 예: 구독 데이터를 맞춤형 CRM 대시보드에 동기화해요.
- 예시 엔드포인트: `GET /saas/location/{locationId}/subscription`
- 응답 예시: 플랜 ID, 활성 상태, 다음 결제일 등이 담긴 JSON 객체

### 3. Bulk Enable SaaS(SaaS 일괄 활성화)

API 호출 한 번으로 여러 서브 계정의 SaaS 모드를 켜요. 대규모 온보딩이나 에이전시 이전 작업에 알맞아요. 자세한 내용은 Bulk Enable SaaS 문서를 참고하세요.

- 활용 예: 서브 계정 수백 개를 같은 설정으로 SaaS에 온보딩해요.
- 예시 엔드포인트: `POST /saas/bulk-enable`
- 페이로드 예시: 서브 계정 ID와 플랜 배정 정보가 담긴 JSON 배열

### 4. Get SaaS Sub-Accounts(SaaS 서브 계정 조회)

에이전시에서 현재 SaaS 모드로 운영 중인 서브 계정 목록을 모두 가져와요. 자세한 내용은 Get SaaS Sub-Accounts 문서를 참고하세요.

- 활용 예: SaaS 도입 현황을 모니터링하는 대시보드를 만들어요.
- 예시 엔드포인트: `GET /saas/agency/sub-accounts`
- 응답 예시: 서브 계정 ID, 이름, 활성 플랜 정보를 담은 JSON 배열

### 5. Get SaaS Plan Details(SaaS 플랜 상세 조회)

특정 SaaS 플랜의 상세 구성과 가격 정보를 가져와요. 자세한 내용은 Get SaaS Plan Details 문서를 참고하세요.

- 활용 예: 맞춤형 요금 페이지에 정확한 기능 제공 여부와 가격 내역을 보여 줘요.
- 예시 엔드포인트: `GET /saas/agency/plan/{planId}`
- 응답 예시: 가격, 사용량 한도, 포함 기능, 약관이 담긴 JSON 객체

## 개발자와 에이전시의 활용 사례

이 API로 에이전시와 외부 개발자는 다양한 일을 할 수 있어요.

- 마켓플레이스 파트너는 고객이 가입하면 SaaS 기능을 자동으로 프로비저닝하는 앱을 만들 수 있어요.
- 에이전시는 담당자 없이 SaaS 플랜을 배정하는 내부 온보딩 자동화를 만들 수 있어요.
- 플랜 도입 지표와 결제 상태를 보여 주는 맞춤형 대시보드나 관리자 도구를 만들 수 있어요.
- 서브 계정 여러 개를 한꺼번에 SaaS 상품으로 옮기는 대규모 이전을 자동화할 수 있어요.
- SaaS 결제 데이터를 다른 비즈니스 분석 도구나 외부 CRM에 연동할 수 있어요.

## 자주 묻는 질문

### 이 API를 쓰려면 특별한 권한이 필요한가요?
네. 알맞은 스코프가 설정된 API 자격 증명이 있어야 해요. 자세한 내용은 API 인증 설정을 확인하세요.

### API로 SaaS 플랜을 만들거나 삭제할 수 있나요?
현재는 플랜 구성을 조회(읽기)하는 것만 가능해요. 플랜 생성과 삭제는 SaaS 구성기 화면에서 해야 해요.

### 모든 에이전시 계정에서 이 API를 쓸 수 있나요?
SaaS 모드가 켜져 있고 API 접근 권한이 있는 에이전시에서 쓸 수 있어요.

### 이 엔드포인트에도 요청 제한이 있나요?
네. 하이퍼클래스 API의 기본 요청 제한이 그대로 적용돼요. 자세한 내용은 API 요청 제한 가이드라인을 참고하세요.

- 새 엔드포인트로 팀에서 구현할 만한 자동화나 연동을 계획해 보세요.
- 맞춤형 대시보드, 앱, 내부 도구에 이 API를 연동해서 SaaS 운영 워크플로우를 개선해 보세요.
- 하이퍼클래스 팀에 피드백을 공유해 주세요. 앞으로의 API 기능과 개선 방향에 도움이 돼요.
