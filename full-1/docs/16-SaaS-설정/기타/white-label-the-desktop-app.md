# 화이트라벨 데스크톱 앱 설정 가이드

하이퍼클래스의 화이트라벨 데스크톱 앱을 쓰면 에이전시가 고객에게 자사 브랜드의 데스크톱 앱을 macOS, Windows, Linux용으로 제공할 수 있어요. 이 문서에서는 **에이전시 대시보드**의 **Desktop App Customizer**(데스크톱 앱 커스터마이저)에서 테마, 아이콘, 이름, 배경 이미지, 플레이스홀더 이미지를 설정하고 앱을 빌드해 배포하는 과정을 안내해요.

앱을 직접 패키징하지 않아도 브랜드가 적용된 데스크톱 앱을 고객에게 전달할 수 있어요.

## 화이트라벨 데스크톱 앱이란?

화이트라벨 데스크톱 앱은 에이전시가 고객에게 배포할 수 있는 브랜드 데스크톱 앱이에요. 기본 하이퍼클래스 데스크톱 앱만 쓰는 대신, 앱의 시각적 정체성을 에이전시 브랜드에 맞게 바꿀 수 있어요.

**Desktop App Customizer**는 **에이전시 대시보드**의 **데스크톱 앱** 탭에서 열 수 있어요. 여기서 브랜딩을 적용하고, 앱을 실시간으로 미리 보고, 빌드를 요청해요. 빌드가 끝나면 앱을 다운로드하거나 접속 링크를 복사할 수 있어요.

{% hint style="info" %}
화이트라벨 데스크톱 앱은 기본 하이퍼클래스 데스크톱 앱과 별개예요. 고객에게 배포할 브랜드 데스크톱 앱을 만들고 싶을 때 사용하세요. 기본 데스크톱 앱은 [하이퍼클래스 데스크톱 앱 다운로드(Windows, macOS, Linux)](../../30-모바일-데스크톱/Desktop-App/download-hyperclass-hyperclass-desktop-app-for-windows-macos-linux.md)를 참고하세요.
{% endhint %}

## 화이트라벨 데스크톱 앱의 장점

브랜드 데스크톱 앱을 쓰면 로그인 페이지, 앱, 고객 온보딩 자료까지 일관된 경험을 줄 수 있어요. 사용자도 브라우저 밖에서 하이퍼클래스에 바로 접속할 수 있어요.

- 완전한 브랜드 데스크톱 경험: 앱 이름, 앱 아이콘, 테마, 로그인 화면의 제목과 자막, 전체 로고, 배경 이미지, 플레이스홀더 이미지를 에이전시 브랜드에 맞게 바꿀 수 있어요.
- 여러 플랫폼 지원: macOS, Windows, Linux용 브랜드 데스크톱 앱을 만들 수 있어요.
- 빌드 전 실시간 미리보기: Desktop App Customizer가 변경 내용을 바로 보여 주기 때문에, 빌드를 요청하기 전에 앱의 모습을 확인할 수 있어요.
- 자동 빌드와 알림: **Build App**(앱 빌드)을 선택하면 하이퍼클래스가 빌드를 자동으로 시작해요. 빌드가 끝나면 애플리케이션 링크를 만들고, 에이전시 소유자와 앱을 설정한 사용자에게 앱 내 알림과 이메일을 보내요.
- 간편한 배포: 완성된 앱을 다운로드하거나 접속 링크를 복사할 수 있어요. 게시된 앱은 앱 내 다운로드 배너로 서브 계정 사용자에게 바로 안내할 수도 있어요.
- 업무에 집중하기 좋은 환경: 브라우저 밖에 전용 작업 공간이 생겨서 방해 요소가 줄고 일상 업무 효율이 좋아져요.

## 지원하는 플랫폼

지원하는 운영체제에 따라 브랜드 데스크톱 앱을 설치해 쓸 수 있는 사용자가 달라져요. 주요 운영체제를 모두 지원하므로 고객이 쓰는 기기나 사내 환경이 달라도 대응할 수 있어요.

화이트라벨 데스크톱 앱은 아래 플랫폼에서 쓸 수 있어요.

- macOS
- Windows
- Linux

## 화이트라벨 데스크톱 앱 설정하기

에이전시 관리자만 쓸 수 있어요. 아래 단계를 순서대로 진행하면 의도한 브랜딩이 반영된 앱을 만들어 고객에게 안심하고 배포할 수 있어요.

### 1단계: Desktop App Customizer 열기

1. **에이전시 대시보드**에 로그인해요.
2. **데스크톱 앱** 탭을 열어요. 여기서 화이트라벨 데스크톱 앱을 설정하고, **실시간 미리보기**로 브랜딩 변경을 확인하고, 빌드를 요청해요.

아직 화이트라벨 데스크톱 앱을 빌드하지 않았다면 **에이전시 대시보드**에 **Setup Banner**(설정 배너)가 보일 수 있어요. 이 배너로 Desktop App Customizer를 열어 설정을 시작하세요.

{% hint style="info" %}
**Setup Banner**는 순차적으로 제공하고 있어서 모든 에이전시에 보이지는 않을 수 있어요.
{% endhint %}

![데스크톱 앱 탭의 설정 배너](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084622474/original/w7bTHP93-_OA5YWx81lV2gjeUiAEKDthcQ.png?1793374009)

### 2단계: 데스크톱 앱 설정하기

고객에게 보여 줄 브랜딩 정보를 입력해요. 이 설정으로 앱의 시각적 정체성, 로그인 화면 내용, 브랜드 표현이 정해져요.

- **테마**: 프리셋 테마를 고르거나 직접 테마를 만들어요.
- **앱 아이콘**: 고객이 데스크톱 앱을 쓸 때 보게 될 앱 아이콘을 업로드해요.
- **앱 이름**: 제목 표시줄과 로그인 버튼에 표시될 앱 이름을 입력해요. 앱을 빌드하는 중에는 앱 이름을 바꿀 수 없어요.
- **제목**: 로그인 화면에 크게 표시되는 제목을 입력해요.
- **자막**: 로그인 화면에서 제목 아래에 표시되는 보조 문구를 입력해요.
- **App Full Logo**(앱 전체 로고): 앱에 쓸 전체 로고를 업로드해요. 이미지는 512 x 128 크기로 조정돼요.
- **배경 이미지**: 데스크톱 앱에 쓸 배경 이미지를 업로드해요.
- **Placeholder Images**(플레이스홀더 이미지): 앱을 더 돋보이게 할 플레이스홀더 이미지를 업로드해요.

![데스크톱 앱 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073832061/original/2KReE4L9jRMhBvWLOgPBc7TF-LjIoZWSfg.gif?1781678376)

### 3단계: 실시간 미리보기 확인하기

**실시간 미리보기**에서 선택한 브랜딩 설정이 데스크톱 앱에 제대로 반영되는지 확인해요. 설정을 바꿀 때마다 미리보기가 함께 바뀌어서, 빌드를 요청하기 전에 완성될 앱의 모습을 미리 볼 수 있어요.

![실시간 미리보기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073832131/original/O3_lPbfpw81X6jTJNi8NW62jm8M1JiKHiw.png?1781678424)

### 4단계: 설정 저장하기

브랜딩 설정을 모두 마쳤으면 **저장**을 선택해요. 저장하면 선택한 테마, 앱 이름, 아이콘, 제목, 자막, 전체 로고, 배경 이미지, 플레이스홀더 이미지가 빌드에 쓸 수 있도록 준비돼요.

### 5단계: 앱 빌드 요청하기

설정을 저장한 뒤 앱 빌드를 요청해요. **Build App** 동작이 실행되면 하이퍼클래스가 빌드를 자동으로 시작해요.

빌드가 끝났는지 확인하려고 커스터마이저에 계속 돌아오지 않아도 돼요. 빌드가 끝나면 하이퍼클래스가 앱 내 알림과 이메일을 보내 줘요. 자세한 내용은 아래 '빌드 완료 알림'을 확인하세요.

![앱 빌드 요청 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073832192/original/omtlz-eI0IEkD_tcqGYlD6-Cy8MsmqLnvw.png?1781678492)

### 빌드 완료 알림

화이트라벨 데스크톱 앱 빌드가 끝나면 하이퍼클래스가 에이전시에 알려 줘요. 빌드 상태를 직접 확인하지 않아도 완성된 앱에 바로 접근할 수 있어요.

#### 알림 방식

- 앱 내 알림: 앱 빌드가 끝나면 알림 창에 시스템 알림이 나타나요. 알림을 선택하면 **데스크톱 앱** 페이지가 열려요.
- 이메일 알림: 하이퍼클래스가 **데스크톱 앱** 페이지로 가는 링크가 담긴 빌드 완료 이메일도 보내요.
- 알림을 받는 사람: 두 알림 모두 에이전시 소유자와 앱을 설정한 사용자에게 전달돼요.
- 언어 지원: 수신자마다 자신이 설정한 플랫폼 언어로 알림을 받아요.

![빌드 완료 알림](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084623670/original/ktjMITsTnECupjo6JCuFRXMfHhKGXCar9Q.png?1793374546)

#### 앱 준비 완료 알림

빌드가 준비되면 하이퍼클래스는 에이전시 알림 창에 **App-Ready Alert**(앱 준비 완료 알림)도 표시해요.

이 알림은 한 번만 나타나고, 사용자가 조치를 할 때까지 남아 있어요. 조치를 하고 나면 다시 나타나지 않아요.

앱이 준비되면 **데스크톱 앱** 페이지를 열어 설치 파일을 다운로드하거나 생성된 접속 링크를 복사하세요.

### 6단계: 다운로드, 복사, 접속 링크 공유하기

빌드가 끝나면 하이퍼클래스가 해당 애플리케이션 링크를 만들어요. 하이퍼클래스에 표시된 기간 안에 앱을 다운로드하거나 접속 링크를 복사한 다음, 사용자에게 알맞은 링크를 공유하세요.

빌드 완료 알림이나 이메일에서 **데스크톱 앱** 페이지를 바로 열 수도 있어요. 커스터마이저로 따로 돌아가지 않아도 완성된 빌드에 접근할 수 있어요.

이 링크는 아래 같은 곳에 넣어 두면 좋아요.

- 온보딩 자료
- 클라이언트 포탈
- 문서
- 고객 지원 답변

![다운로드와 접속 링크 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073832219/original/YpXbTUgOhGNwA3yT1xi_xoaHBy2nRq6n_A.png?1781678530)

### 에이전시 배너와 앱 홍보

하이퍼클래스는 **에이전시 대시보드**에 상황에 맞는 안내를 보여 줘서 화이트라벨 데스크톱 앱의 설정, 빌드, 홍보를 도와줘요. 앱의 현재 단계에 따라 보이는 안내가 달라요.

1. **Setup Banner**: 아직 앱을 빌드하지 않았다면 **에이전시 대시보드**에 설정 배너가 나타날 수 있어요. 배너의 동작 버튼을 선택하면 Desktop App Customizer가 열리고 설정을 시작할 수 있어요.

   Setup Banner는 순차적으로 제공하고 있어서 모든 에이전시에 보이지는 않을 수 있어요.

2. **App-Ready Alert**: 앱 빌드가 끝나면 앱이 준비되었다고 알려 줘요.

   이 알림은 한 번만 나타나고, 조치를 할 때까지 남아 있어요. 자세한 내용은 '빌드 완료 알림'을 참고하세요.

3. **Enable-Promotion Banner**(프로모션 활성화 배너): 앱이 **게시됨** 상태인데 프로모션이 켜져 있지 않으면, 고객에게 앱을 홍보하도록 안내하는 배너가 나타나요.

   **Enable promotion**(프로모션 활성화)을 선택하면 Desktop App Customizer의 프로모션 설정으로 이동해요.

   **Promote**(프로모션) 토글을 켜면 서브 계정 사용자에게 데스크톱 앱 다운로드 배너가 표시돼요.

![프로모션 활성화 배너](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084623792/original/181Hscm_jcQUp6aKiIVkS8B3uIbpifzD5Q.png?1793374606)

{% hint style="warning" %}
**Enable-Promotion Banner**는 데스크톱 앱이 게시되었고 아직 홍보 전일 때만 나타나요. 프로모션을 켠 뒤 서브 계정에 나타나는 고객용 다운로드 배너와는 달라요.
{% endhint %}

### 7단계: 게시된 앱을 서브 계정에 홍보하기

앱이 **게시됨** 상태가 되면 Desktop App Customizer에서 **Promote** 토글을 켜서 서브 계정 안에서 앱을 쓸 수 있게 해요.

![Promote 토글](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076276261/original/CyvUuk3SytyPjrhOzBadcMt2f_rrC1Gq2Q.png?1784308201)

프로모션을 켜면 서브 계정 사용자에게 에이전시의 화이트라벨 데스크톱 앱 다운로드 배너가 표시돼요.

다른 운영체제용 다운로드 링크는 기본 설치 파일 아래에 그대로 있어요. 배너의 모든 다운로드 링크는 가장 최근에 게시된 빌드를 가리켜요.

배너는 사용자의 운영체제를 감지해서 아래 중 맞는 설치 파일을 강조해서 보여 줘요.

- macOS
- Windows
- Linux

![서브 계정의 데스크톱 앱 다운로드 배너](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076276291/original/bcSZcymE6XQyklhPftYoUTuo-0b4jgWNYw.png?1784308262)

## 화이트라벨 도메인과 함께 쓰기

데스크톱 앱 브랜딩은 설치된 화이트라벨 데스크톱 앱의 모습을 정해요. 앱 이름, 아이콘, 테마, 로고, 로그인 화면 디자인이 여기에 속해요. 화이트라벨 도메인은 고객이 브라우저로 하이퍼클래스에 접속할 때 쓰는 브랜드 웹 로그인 URL을 정해요.

두 설정은 따로 하지만 함께 쓰면 고객에게 더 일관된 브랜드 경험을 줄 수 있어요. 데스크톱 앱은 Desktop App Customizer에서 브랜딩하고, 브랜드 웹 로그인 경험을 위한 화이트라벨 도메인은 따로 설정하세요.

설정 방법은 [데스크톱 웹 앱용 화이트라벨 도메인 설정하기](../../25-애드온-세일즈/Whitelabel-Desktop-App/how-to-set-up-a-whitelabel-domain-for-the-desktop-web-app.md)를 참고하세요.

## 자주 묻는 질문

### Desktop App Customizer는 어디에 있나요?
**에이전시 대시보드**의 **데스크톱 앱** 탭에서 열 수 있어요.

### 어떤 플랫폼을 지원하나요?
화이트라벨 데스크톱 앱은 macOS, Windows, Linux에서 쓸 수 있어요.

### 빌드하기 전에 앱을 미리 볼 수 있나요?
네. Desktop App Customizer에는 **실시간 미리보기**가 있어서, 앱 빌드를 요청하기 전에 브랜딩 변경 내용을 바로 확인할 수 있어요.

### Build App을 선택하면 어떻게 되나요?
하이퍼클래스가 화이트라벨 데스크톱 앱 빌드를 자동으로 시작해요. 빌드가 끝나면 애플리케이션 링크를 만들고, 에이전시 소유자와 앱을 설정한 사용자에게 앱 내 알림과 이메일을 보내요.

두 알림 모두 **데스크톱 앱** 페이지로 가는 링크가 있어서, 완성된 빌드에 바로 접근할 수 있어요.

### 완성된 데스크톱 앱을 사용자에게 어떻게 공유하나요?
앱 빌드가 끝나면 **데스크톱 앱** 탭에서 앱을 다운로드하거나 생성된 접속 링크를 복사할 수 있어요. 앱이 **게시됨** 상태가 되면 **Promote** 토글도 켤 수 있어요. 켜면 서브 계정 안에 앱 다운로드 배너가 표시돼요. 온보딩 이메일, 문서, 고객 지원 답변, 클라이언트 포탈로 직접 링크를 계속 공유해도 돼요.

### Mac App Store와 Microsoft Store에 등록할 수 있나요?
릴리스 노트에는 Mac App Store와 Microsoft Store 등록이 향후 개선 사항으로 안내되어 있어요. 지금은 빌드가 끝난 뒤 제공되는 다운로드 링크나 접속 링크를 사용하세요.

### 화이트라벨 도메인도 Desktop App Customizer에서 설정하나요?
아니요. Desktop App Customizer에서는 데스크톱 앱의 브랜딩과 빌드 설정을 관리해요. 화이트라벨 도메인은 브랜드 데스크톱 웹 앱 로그인 경험을 위해 따로 설정해요.

### 다운로드 배너는 어떤 설치 파일을 보여 주나요?
배너가 서브 계정 사용자의 운영체제를 감지해서, 맞는 macOS, Windows, Linux 설치 파일을 강조해서 보여 줘요. 다른 운영체제용 링크는 강조된 설치 파일 아래에 그대로 있어요.
