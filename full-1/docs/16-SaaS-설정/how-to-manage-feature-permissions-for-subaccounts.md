# 서브 계정 기능 권한 관리

**Feature Permissions**(기능 권한)는 에이전시가 고객에게 보여 줄 하이퍼클래스의 도구와 기능을 정하는 설정이에요. 에이전시 전용 기능이에요. 80개 이상의 기능을 그룹별로 나눠서 관리할 수 있어요. 서브 계정 하나하나에 설정할 수도 있고, SaaS 플랜에 포함할 수도 있어요.

## 기능 권한이란?

기능 권한은 서브 계정 안에서 하이퍼클래스의 어떤 부분을 쓸 수 있는지 정해요. 고객에게 필요한 도구만 보여 줄 수 있어서 고객 화면이 깔끔해져요.

예를 들어 한 고객에게는 아래 기능만 열어 줄 수 있어요.

- AI 에이전트
- 캘린더
- 기회 관리
- 전화 시스템

다른 고객에게는 또 다른 기능 조합을 열어 줄 수도 있어요.

모든 고객에게 하이퍼클래스의 모든 기능을 보여 주는 대신, 서브 계정마다 쓸 수 있는 기능을 에이전시가 고르는 방식이에요.

이번에 개선된 기능 권한은 **80개 이상의 기능**을 제어할 수 있어요. 이전에는 제어할 수 있는 항목이 이보다 적었어요.

## 기능 권한의 장점

설정이 더 세분되고 이해하기 쉬워졌어요. 여러 고객을 관리하거나 SaaS 플랜을 다양하게 운영하는 에이전시에 특히 유용해요.

- **더 많은 기능 제어:** 하이퍼클래스 기능 80개 이상의 접근 권한을 관리할 수 있어요.
- **체계적인 구성:** 기능이 **카테고리**, **모듈**, 개별 **기능**으로 묶여 있어요.
- **세밀한 제어:** 플랫폼의 큰 영역 단위가 아니라 특정 기능을 골라서 관리할 수 있어요.
- **쉬운 기능 찾기:** 긴 목록을 넘겨 보는 대신 기능을 검색할 수 있어요.
- **깔끔한 고객 화면:** 고객에게는 에이전시가 열어 준 기능만 보여요.
- **SaaS 플랜 지원:** Pro 에이전시는 SaaS 플랜에 포함할 기능을 직접 고를 수 있어요.
- **기존 접근 권한 유지:** 기존 서브 계정과 SaaS 플랜은 원래 쓰던 기능이 빠지지 않은 채 새 권한 시스템으로 옮겨졌어요.

## 기능 권한의 구성

새 권한 화면은 기능을 세 단계로 나눠 보여 줘요. 하이퍼클래스의 넓은 영역에서 특정 기능까지 폴더를 따라 내려가는 구조라고 생각하면 쉬워요.

세 단계는 다음과 같아요.

- **카테고리:** 하이퍼클래스의 큰 영역이에요.
- **모듈:** 그 카테고리 안에서 서로 관련된 도구 묶음이에요.
- **기능:** 제어할 수 있는 개별 도구나 기능이에요.

예를 들면 이런 식이에요.

- **카테고리:** **CRM**
- **모듈:** **CRM core**(CRM 핵심)
- **기능:** **Contacts & Conversations**(연락처 및 대화)

**CRM** 카테고리에는 아래 같은 기능도 들어 있어요.

- **Custom Objects**(커스텀 오브젝트)
- **Smartlists**(스마트 리스트)
- **Tags**(태그)
- **Email System**(이메일 시스템)
- **Opportunities**(기회 관리)
- **Phone System**(전화 시스템)

이 구조 덕분에 관리하려는 기능을 쉽게 찾을 수 있어요.

## 선택된 기능 개수 보는 방법

카테고리와 모듈 옆의 숫자는 현재 켜져 있는 기능이 몇 개인지 보여 줘요. 그룹을 일일이 열지 않아도 권한 상태를 한눈에 확인할 수 있어요.

예를 들면 이런 뜻이에요.

- **AI 에이전트 (6/6)** 은 사용할 수 있는 AI 에이전트 기능 6개가 모두 선택되었다는 뜻이에요.
- **CRM (1/7)** 은 CRM의 사용 가능한 기능 7개 중 1개가 선택되었다는 뜻이에요.
- **기능 (22/63 선택됨)** 은 해당 권한 설정에서 현재 선택된 기능의 전체 개수를 보여 줘요.

기능을 선택하거나 해제하면 이 숫자도 바로 바뀌어요.

## 기능 검색

카테고리와 모듈을 하나씩 열지 않아도 **기능 검색** 필드로 원하는 기능을 바로 찾을 수 있어요. 켜거나 끄려는 기능의 이름을 이미 알고 있을 때 편해요.

권한 목록 맨 위의 **기능 검색** 필드에 찾으려는 기능 이름을 입력하세요.

이런 이름으로 검색할 수 있어요.

- 전화 시스템
- 기회 관리
- 스마트 리스트
- 캘린더
- AI 에이전트

검색 결과에서 해당 기능을 확인하고 관리할 수 있어요.

## 개별 서브 계정의 기능 권한

특정 고객에게만 다른 기능 조합이 필요할 때는 서브 계정 단위로 권한을 설정해요. 이 설정은 해당 서브 계정 안에서 쓸 수 있는 기능을 정해요.

에이전시는 개별 고객을 관리하면서 기능 권한을 확인하고 바꿀 수 있어요.

이렇게 할 수 있어요.

- 서브 계정에서 현재 쓸 수 있는 기능 확인
- 검색으로 기능 찾기
- 카테고리와 모듈을 열어 개별 기능 찾기
- 해당 고객에게 지원되는 기능을 활성화하거나 비활성화
- 선택된 기능 개수 확인

기능 권한은 **서브 계정 자체**가 쓸 수 있는 기능을 정해요.

그 서브 계정 안의 특정 사용자가 쓸 수 있는 기능을 정하는 개별 사용자 권한과는 달라요.

## SaaS 플랜의 기능 권한

Pro 에이전시는 SaaS 플랜에 포함할 하이퍼클래스 기능을 직접 정할 수 있어요. 새 고객을 받을 때마다 권한을 일일이 설정하지 않아도 되어서, 기능 구성이 다른 플랜을 운영하기 쉬워요.

SaaS 플랜을 만들거나 수정할 때 그 플랜에 포함할 기능을 선택하세요.

서브 계정이 SaaS 플랜을 구독하면 그 플랜의 기능 권한이 해당 서브 계정에 적용돼요.

예를 들어 이렇게 플랜을 나눌 수 있어요.

- CRM과 캘린더만 쓸 수 있는 기본 플랜
- CRM, 캘린더, 자동화, AI 기능까지 쓸 수 있는 상위 플랜

실제로 쓸 수 있는 기능은 에이전시가 플랜에 선택한 내용에 따라 달라요.

{% hint style="info" %}
SaaS 플랜을 저장하려면 기능을 최소 1개 이상 선택해야 해요.
{% endhint %}

## 기능 권한과 사용자 권한의 차이

기능 권한과 **사용자 권한**은 제어하는 범위가 달라요. 차이를 알아 두면 사용자 권한을 켰는데도 기능을 쓸 수 없는 상황을 피할 수 있어요.

- **기능 권한**은 서브 계정 전체가 쓸 수 있는 기능을 정해요.
- **사용자 권한**은 그 서브 계정 안의 개별 사용자가 쓸 수 있는 기능을 정해요.

예를 들어 이런 순서예요.

1. 에이전시가 서브 계정에 **기회 관리**를 활성화해요.
2. 그러면 에이전시는 그 서브 계정의 어떤 사용자가 **기회 관리**를 쓸 수 있는지 정할 수 있어요.

서브 계정에 **기회 관리** 권한이 없으면, 개별 사용자에게 **기회 관리** 권한을 줘도 그 기능을 쓸 수 없어요.

따라서 사용자는 서브 계정과 같거나 더 적은 권한만 가질 수 있고, 더 많이 가질 수는 없어요.

## 기존 권한은 어떻게 되었나요?

기존 서브 계정과 SaaS 플랜은 새 기능 권한 시스템으로 자동으로 옮겨졌어요. 고객이 쓰던 기능이 갑자기 사라지지 않도록 기존 접근 권한을 그대로 유지하게 설계되었어요.

기존 권한 설정을 처음부터 다시 만들 필요는 없어요.

업데이트 후에는 이렇게 돼요.

- 기존 서브 계정은 원래 쓰던 기능을 그대로 쓸 수 있어요.
- 기존 SaaS 플랜은 이미 설정된 접근 권한을 그대로 유지해요.
- 이후에는 새 권한 화면에서 접근 권한을 확인하고 조정할 수 있어요.

## 기능 권한 관리하기

먼저 고객 한 곳의 권한을 바꿀지, SaaS 플랜에 포함할 기능을 설정할지 정하세요. 정리된 새 권한 목록에서 필요한 기능을 쉽게 찾아 선택할 수 있어요.

### 서브 계정 권한 관리

1. 고객을 관리하는 에이전시 화면으로 이동하세요.
2. 권한을 바꿀 서브 계정을 선택하세요.
3. **Feature Permissions** 설정을 여세요.
4. **기능 검색**을 쓰거나 **카테고리**를 직접 둘러보세요.
5. **카테고리**를 펼쳐서 **모듈**과 **기능**을 확인하세요.
6. 관리할 기능을 선택하거나 선택 해제하세요. 지원되는 기능만 바꿀 수 있어요.
7. 선택된 기능 개수를 확인하세요.
8. **변경사항 저장**을 누르세요.

![서브 계정의 기능 권한 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079888236/original/eagMIdahjE_ttz2wYAGGLWXDy8GTkVWjMA.png?1788343721)

### SaaS 플랜 권한 관리

1. **SaaS 구성기**(SaaS Configurator)를 여세요.
2. 새 플랜을 만들거나 기존 플랜을 여세요.
3. 기능을 선택하는 영역으로 이동하세요.
4. 기능을 검색하거나 해당 **카테고리**를 여세요.
5. 플랜에 포함할 기능을 선택하세요.
6. 기능이 최소 1개 이상 선택되었는지 확인하세요.
7. 선택한 기능을 한 번 더 확인하세요.
8. SaaS 플랜을 저장하세요.

SaaS 플랜을 서브 계정에 할당하면 그 플랜의 기능 구성이 해당 계정에 적용돼요.

## 문제 해결

권한 문제는 대부분 서브 계정 단계에서 기능이 열려 있지 않거나, 개별 사용자의 권한이 더 제한되어 있어서 생겨요. 두 단계를 모두 확인하면 고객이 기능에 접근하지 못하는 이유를 찾을 수 있어요.

### 고객이 기능을 볼 수 없어요

서브 계정의 **Feature Permissions**에서 해당 기능이 활성화되어 있는지 확인하세요.

### 서브 계정에는 기능이 있는데 사용자가 접근하지 못해요

그 사용자의 개별 권한을 확인하세요. 서브 계정은 기능을 쓸 수 있어도, 특정 사용자는 그 기능을 쓰지 못하도록 제한되어 있을 수 있어요.

### 기능을 찾을 수 없어요

**기능 검색** 필드를 사용해 보세요. 그래도 나오지 않는다면 현재 그 기능에는 설정할 수 있는 권한이 없을 수 있어요.

### 선택된 개수가 예상보다 적어요

**카테고리**나 **모듈**을 열어서 선택된 개별 기능을 확인하세요.

### 권한 항목을 쓸 수 없는 것처럼 보여요

일부 권한 설정은 하이퍼클래스의 모든 영역에서 동시에 제공되지 않을 수 있어요. 변경하기 전에 내 계정에 표시된 현재 설정을 먼저 확인하세요.

## 자주 묻는 질문

### 카테고리 옆의 1/7은 무슨 뜻인가요?

해당 카테고리에서 사용할 수 있는 기능 7개 중 1개가 현재 선택되어 있다는 뜻이에요.

### 특정 기능만 검색할 수 있나요?

네. **Feature Permissions** 목록 맨 위의 **기능 검색** 필드를 사용하세요.

### 기능 권한과 사용자 권한은 같은 건가요?

아니요. 기능 권한은 서브 계정이 쓸 수 있는 기능을 정하고, **사용자 권한**은 그 서브 계정 안에서 개별 사용자가 쓸 수 있는 기능을 정해요.

### 서브 계정에서 비활성화된 기능을 사용자가 쓸 수 있나요?

아니요. 사용자 권한으로는 서브 계정에서 쓸 수 있는 범위를 넘어서는 접근 권한을 줄 수 없어요.

### SaaS 플랜에서도 기능 권한을 설정할 수 있나요?

네. Pro 에이전시는 각 SaaS 플랜에 포함할, 지원되는 기능을 선택할 수 있어요.

### SaaS 플랜을 서브 계정에 할당하면 어떻게 되나요?

그 SaaS 플랜에 설정된 기능 권한이 서브 계정에 적용돼요.

### 새 권한 시스템이 도입되면서 기존 고객이 쓰던 기능을 잃었나요?

아니요. 기존 서브 계정과 SaaS 플랜은 원래 쓰던 기능 접근 권한을 그대로 유지한 채 새 시스템으로 옮겨졌어요.

### 기능을 비활성화하면 고객의 기존 데이터가 삭제되나요?

기능 권한은 지원되는 기능에 대한 접근을 제어해요. 접근 권한을 바꾸면 기존 고객 데이터가 삭제된다고 가정하지 않아요. 저장된 데이터와 관련된 결정을 하기 전에 해당 기능의 문서를 확인하세요.
