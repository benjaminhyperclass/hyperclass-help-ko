# 모바일 앱 통합 연락처 워크스페이스

하이퍼클래스 모바일 앱의 연락처 워크스페이스는 연락처 한 명의 정보, 작업, 메모, 활동 기록을 한 화면에 모아 보여 줘요. 연락처를 길게 눌러 빠르게 실행할 수 있고, 태그 추가나 일괄 변경도 몇 번의 탭이면 끝나요. 앱을 v3.9 이상으로 업데이트하면 쓸 수 있어요.

[동영상](https://www.youtube.com/embed/ko3z5S_h_-M?&wmode=opaque)

## 모바일 연락처 워크스페이스란?

흩어져 있던 화면을 탭 기반의 화면 하나로 합쳤어요. 연락처의 핵심 정보는 맨 위에 보이고, 통화나 SMS 같은 동작은 한 번만 탭하면 실행돼요. 자세한 데이터는 탭으로 나뉘어 있어서 정리된 채로 바로 열어 볼 수 있어요. 필요한 내용이 한곳에 모여 있으니 스크롤하거나 화면을 오갈 일이 줄어요.

## 연락처 워크스페이스의 장점

왜 좋은지 알아 두면 팀에 새 방식을 알리기 쉬워요.

- 한 화면에서 모두 확인: 기본 정보, 작업, 메모, 전체 활동 기록이 한곳에 모여 있어요.
- 더 빠른 연락: 통화, SMS, 이메일 버튼을 한 번만 탭하면 돼요.
- 탭으로 이동: 복잡한 정보도 깔끔하게 볼 수 있어요. 상세 정보에서 작업 및 메모로 넘어가도 보던 맥락이 끊기지 않아요.
- 태그 일괄 지정: 수백 개의 연락처도 몇 번의 탭으로 정리할 수 있어요.
- 이어질 디자인: 같은 방식이 **기회 관리**(Opportunities), **예약** 등 다른 메뉴에도 적용될 예정이라 어디서나 익숙하게 쓸 수 있어요.

## 연락처 화면 둘러보기

1분이면 기본 사용법을 익힐 수 있어요.

1. 앱에서 **연락처** 탭을 여세요. 앱 v3.9 이상에서 볼 수 있어요.
2. 연락처 타일을 길게 눌러 빠른 실행 메뉴를 여세요.
3. **상세 정보**를 탭해 접혀 있는 섹션(**기본 정보**, **추가 정보**, **Actions**(액션), **수신거부**)을 펼쳐 보세요.
4. 탭 바에서 옆으로 넘겨 **Tasks & Notes**(작업 및 메모)나 **Activities**(활동)로 이동하세요.
5. 연락처 여러 개에 태그를 지정하려면 **•••** 메뉴 > **선택**을 탭해 여러 개를 선택하세요.

## 탭별 안내

탭은 지금 바로 필요한 정보와 지난 기록을 나눠서 보여 줘요. 그래서 집중해서 보면서도 필요한 내용을 놓치지 않아요.

| 탭 | 활용 가치 |
| --- | --- |
| **Tasks & Notes** | 연락처와 관련된 할 일과 미팅 메모를 관리해요. 놓치는 일이 없어요. |
| **상세 정보** | 웹으로 이동하지 않고도 일반 필드, 커스텀 값, 액션, 수신거부 토글을 보고 수정할 수 있어요. |
| **Activities** | 통화, 예약, 설문, 결제, 페이지 방문 등을 시간순으로 스크롤하며 볼 수 있어요. 다시 전화하기 전에 맥락을 빠르게 파악하기 좋아요. |

## 태그 관리와 일괄 작업

태그는 데이터를 깔끔하게 정리해 주고 타깃 캠페인에도 쓰여요. 여러 연락처를 한 번에 선택하면 관리가 훨씬 편해져요.

- 체크박스를 탭해 연락처를 여러 개 선택하세요.
- 하단 작업 바에서 **태그 추가** 또는 **태그 제거**를 사용하세요. 변경 내용은 웹에 바로 동기화돼요.
- 출시 예정: 삭제, 배정, 수신거부 전환 같은 **일괄 작업**이 추가될 예정이에요.

## 연락처별 커스텀 값

커스텀 값을 쓰면 많은 연락처에 맞춤 메시지를 보낼 수 있어요. 값을 연락처에 직접 저장해 두면 문자, 이메일, 워크플로우에서 정확한 값을 불러와요.

- **상세 정보 > 추가 정보**에서 추가하거나 수정하세요.
- 어떤 템플릿에서든 평소처럼 `{{custom_value}}` 형식으로 값을 불러올 수 있어요.
- 커스텀 값은 연락처 기록이 쓰이는 곳이면 자동화 캠페인을 포함해 어디서나 함께 쓰여요.

## 빠른 실행 타일

속도가 중요할 때는 깊은 메뉴를 찾아가는 것보다 길게 누르는 편이 빨라요.

- **통화**: 기기의 전화 앱이 열려요.
- **SMS**: 앱 안의 문자 작성 화면이 열려요.
- **이메일**: 기기의 기본 메일 앱이 열려요.
- **예약하기**: 캘린더 예약 흐름으로 연결돼요.
- **결제 수집**: 앱에 내장된 결제 화면으로 이동해요.

이 동작들은 이미 쓰고 있는 기기 기본 설정을 그대로 따라요. 별도 설정은 필요 없어요.

## 자주 묻는 질문

### 어떤 앱 버전이 필요한가요?
iOS 또는 Android의 하이퍼클래스 모바일 앱 v3.9 이상이 필요해요. 화이트라벨 앱을 쓰는 경우에는 하이퍼클래스 고객지원에 3.9 빌드를 요청하세요.

### 예전 화면으로 되돌릴 수 있나요?
아니요. 코드를 간결하게 유지하고 새 기능을 더 빨리 제공하기 위해 이전 레이아웃은 종료됐어요.

### 웹에서 지정한 태그가 모바일에 바로 반영되나요?
네, 태그는 실시간으로 동기화돼요. 웹에서 수정하면 몇 초 안에 모바일에서 확인할 수 있고, 반대도 마찬가지예요.

### 오프라인에서도 여러 연락처를 선택할 수 있나요?
오프라인에서도 연락처를 선택할 수는 있어요. 다만 태그 변경은 다시 온라인이 될 때까지 대기했다가 반영돼요.

### 한 번에 몇 개의 태그를 일괄 적용할 수 있나요?
일괄 작업 한 번에 최대 연락처 500개, 태그 10개까지 적용할 수 있어요. 실수로 너무 많이 변경하는 일을 막기 위한 제한이에요.

### 커스텀 값을 자동화에서 바로 쓸 수 있나요?
네, 저장하면 **워크플로우**, **이메일 빌더**, SMS 작성 화면에서 바로 쓸 수 있어요.

## 다음 단계

1. 하이퍼클래스 모바일 앱을 v3.9 이상으로 업데이트하세요.
2. 연락처 타일을 길게 눌러 빠른 실행 메뉴를 살펴보세요.
3. 태그를 일괄 지정해 보세요. 연락처 3개를 선택한 뒤 **태그 추가**를 탭하고 "VIP"를 고르세요.
4. 모바일 베타 Slack 채널에 피드백을 남겨 주세요. 여러분의 의견이 3.10 버전에 반영돼요.
