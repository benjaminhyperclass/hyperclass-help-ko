# 하이퍼클래스 모바일 앱으로 발신 통화하기

하이퍼클래스 모바일 앱에서 전화를 걸 때 쓸 수 있는 기능과 발신 방법을 안내해요. 통화 화면에서 바로 후속 일정을 잡고 통화 결과를 기록할 수 있어요. 리드, 고객, 팀원 누구와 통화하든 필요한 작업을 한 번의 탭으로 할 수 있어요.

{% hint style="info" %}
모바일 앱 기능 전체는 모바일 앱 개요 문서를 참고하세요.
{% endhint %}

## 개요

하이퍼클래스 모바일 앱의 통화 기능을 쓰면 스마트폰이 소통과 업무의 중심이 돼요. 전화를 거는 것뿐 아니라 작업 처리, 메모 추가, 후속 일정 예약까지 화면을 옮기지 않고 할 수 있어요. 통화 중에 집중이 끊기지 않아요.

모바일 앱은 데스크톱 환경과 같은 전화 시스템을 사용해요. 그래서 통화, 녹음, 요금 청구가 두 환경에서 똑같이 관리돼요.

---

## 모바일 앱 발신 통화의 장점

모바일 통화는 말하는 데서 끝나지 않고 바로 행동으로 이어져요. 후속 조치, 메모, 결제 등을 한곳에서 처리해 업무 흐름이 간결해져요.

- 실시간 대응: 통화 중에 일정을 잡거나 메모를 남길 수 있어 화면을 오갈 필요가 없어요.
- 효율성: 통화 화면에 들어 있는 작업 생성 도구로 시간을 아낄 수 있어요.
- 고객 경험: 후속 조치를 바로 처리해 고객과의 소통이 좋아져요.
- 일관성: 통화 후 놓치는 작업이나 사라지는 맥락을 줄일 수 있어요.
- 정보 확인: 통화하는 동안 연락처의 프로필과 결제 정보를 전부 볼 수 있어요.
- 유연성: 이동 중에도 CRM 기능을 그대로 쓸 수 있어요.

---

## 통화 중에 쓸 수 있는 고급 기능

통화 화면에서는 대화 외에도 여러 작업을 바로 할 수 있어요. 모든 내용을 정리해 두고 곧바로 실행에 옮길 수 있어요.

- **수신거부**: 통화 화면에서 바로 해당 연락처의 수신거부를 켜거나 끌 수 있어요.
- **전환**: 통화를 다른 팀원에게 넘겨요. 자세한 내용은 통화 전환 기능 문서를 참고하세요.
- **캘린더**: 통화를 끊지 않고 캘린더를 열어 후속 예약을 잡을 수 있어요.
- **메모**: 통화 중에 메모를 직접 입력하거나 음성으로 받아 적을 수 있어요.
- **작업**: 연락처와 관련된 작업을 만들고, 관리하고, 확인해요.
- **결제**: 결제 내역을 확인하거나 기록해요. 자세한 내용은 모바일 앱의 결제 허브 문서를 참고하세요.
- **프로필**: 연락처의 전체 프로필 정보를 확인해요.
- **스피커 / 음소거 / 대기 / 키패드 / 통화 종료**: 기본 통화 제어 버튼이에요.

## 통화 후에 쓸 수 있는 고급 기능

통화가 끝나면 모바일 앱에 요약 화면이 나타나고, 여기서 통화 후 작업을 바로 할 수 있어요. 놓치는 일 없이 후속 조치를 마무리할 수 있어요.

- **메모**: 통화 중에 쓴 메모를 마무리하거나 수정해요.
- **캘린더**: 미팅이나 다시 걸 전화를 예약해요.
- **작업**: 새로운 후속 조치나 할 일을 추가해요.
- **태그**: 연락처에 태그를 붙여 리드를 분류해요.
- **프로필**: 연락처의 상세 정보를 확인해요.
- **수신거부 / 메시지 / Call Back**(다시 걸기): 탭 한 번으로 다음 조치를 바로 해요.

## 모바일 앱으로 발신 통화하는 방법

발신 통화는 하이퍼클래스 모바일 앱으로 걸 수도 있고, 휴대폰의 기본 통화 기능으로 걸 수도 있어요. 어디서 일하든 연락을 이어 갈 수 있어요. 발신 방법이 여러 가지라서 업무 방식에 맞는 방법을 고르면 돼요.

### 지역 번호 발신

서브 계정에서 **지역 번호 발신**이 켜져 있으면, 하이퍼클래스 모바일 앱에서 거는 발신 통화 중 지원되는 통화에 지역 번호 발신자 번호 선택이 적용돼요. 웹 앱에서 **설정 > 전화 시스템 > 음성 > 기타 설정 > 발신 통화**로 이동해 설정하세요.

지원 국가, 번호 매칭 방식, 대체 로직, 예약 번호에 대한 내용은 [하이퍼클래스 전화 시스템의 지역 번호 발신](../../15-전화-시스템/통화/local-presence-dialing-with-the-hyperclass-phone-system-005896.md) 문서를 참고하세요.

{% hint style="info" %}
**지역 번호 발신**은 SIM 기반 통화에는 적용되지 않아요. SIM 기반 통화는 통신사 번호로 발신돼요.
{% endhint %}

### 휴대폰 기본 통화 앱에서 하이퍼클래스로 발신하기

모바일 앱을 설치하면 휴대폰에 저장된 연락처에도 하이퍼클래스로 바로 전화를 걸 수 있어요.

1. 휴대폰의 **연락처** 앱을 열고 통화 버튼을 길게 누르세요.
2. 통화 방법을 고르는 창이 나타나면 **하이퍼클래스**를 선택하세요.

## 자주 묻는 질문

### 모바일 앱에서 통화를 다른 사람에게 전환할 수 있나요?
네. 통화 화면의 **전환** 버튼을 누르면 팀원에게 통화를 넘길 수 있어요. 자세한 내용은 통화 전환 문서를 참고하세요.

### 통화 중에 쓴 메모는 어디에 저장되나요?
CRM의 해당 연락처 기록에 저장돼요. 나중에 후속 조치를 할 때 바로 확인할 수 있어요.

### 모바일 앱에서는 스팸 전화를 어떻게 처리하나요?
앱이 알려졌거나 의심되는 스팸 발신자를 자동으로 표시해요. 이런 전화에는 스팸 표시가 붙어서 원치 않는 전화를 받지 않도록 도와줘요. 자세한 내용은 모바일 스팸 태깅 문서를 참고하세요.

### 전화를 놓치면 어떻게 되나요?
음성사서함을 설정해 두었다면 상대방이 메시지를 남길 수 있어요. 음성사서함 설정 방법은 회사 및 사용자용 음성사서함 문서를 참고하세요. 통화 라우팅을 설정하면 전화가 모바일 앱으로 오도록 할 수도 있어요. 자세한 내용은 수신 통화를 모바일 앱으로 착신 전환하는 방법 문서를 참고하세요.

### 모바일 통화 요금은 어떻게 부과되나요?
모바일 앱으로 건 통화는 Twilio 또는 하이퍼클래스 전화 시스템 사용량을 기준으로 요금이 부과돼요. 발신·수신 통화 시간이 모두 포함되고, 계정에서 확인할 수 있어요. 자세한 내용은 하이퍼클래스 전화 시스템 요금 및 청구 가이드를 참고하세요.
