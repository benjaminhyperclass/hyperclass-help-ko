# 모바일 견적서 대시보드와 빌더

모바일 앱의 **견적서**(Estimates) 메뉴에서 견적서를 만들고 관리할 수 있어요. 이 문서에서는 모바일 견적서의 개념, 대시보드 화면, 견적서를 만드는 순서를 안내해요.

## 모바일 견적서란?

견적서는 보통 숙련된 서비스 기사가 현장에서 작업을 직접 확인한 뒤 만들어요. 해야 할 작업, 부품, 자재, 인력, 소요 시간을 정확하게 정리한 목록이에요. 정확하게 작성하지만 작업이 진행되면서 바뀔 수 있어서 '견적'이라고 해요. 모바일로 견적서를 관리하면 고객이 현장에 있는 동안 모든 과정을 실시간으로 끝낼 수 있어 효율적이에요.

## 견적서 대시보드

대시보드에는 가장 중요한 정보가 모여 있어요.

1. 보낸 견적서
2. 수락된 견적서
3. 거절된 견적서
4. 인보이스로 만든 견적서
5. 필터: 검색창, 견적서 상태 필터, 기간 필터로 검색 결과를 좁힐 수 있어요.
6. 웹에서 만들었든 모바일에서 만들었든 상관없이, 모든 상태(초안, 기한 도래, 결제 완료 등)의 견적서를 한곳에서 볼 수 있어요.
7. **새 견적서**
8. 견적서 카드 조작 방법
   1. 탭: 해당 견적서의 기본 동작을 실행해요. (예: 초안 견적서는 편집 화면이 열려요.)
   2. 길게 누르기: 해당 견적서에서 할 수 있는 모든 동작이 나와요. (예: **Copy link**(링크 복사), **수락됨으로 표시**)
   3. 왼쪽으로 밀기: 가장 중요한 동작 두 가지와 전체 동작을 볼 수 있는 더 보기 옵션이 나와요. (예: 보낸 견적서는 **편집**, **삭제**, 더 보기 옵션이 보여요.)

## 견적서 빌더

|  |  |
| --- | --- |
| 모바일 앱에서 왼쪽 메뉴를 열고 **견적서**를 누른 다음, 더하기 "+" 버튼을 눌러요. |  |
| 기본 정보를 입력해요. 연락처를 연결하고, 견적서 이름, 발행일, 기한, 견적서 번호를 입력해요. |  |
| 견적서에 항목을 추가해요. 직접 입력한 항목, 카탈로그 항목, 또는 둘 다 추가할 수 있어요. 항목을 추가할 때 상품에 세금을 연결하고 알맞은 옵션 조합을 고를 수 있어요. |  |
| **Terms & Notes**(약관 및 메모)를 추가해요. |  |
| 견적서 내용을 검토해요. 견적서를 받을 연락처 정보, 발행일과 기한, 항목 내용을 다시 확인하세요. 이 단계에서 할인도 추가할 수 있어요. 모두 확인했으면 이메일, 문자, 또는 둘 다로 견적서를 보내세요. |  |
| 고객은 견적서를 받은 뒤 수락하거나 거절할 수 있어요. 수락된 견적서는 인보이스로 만들어 결제를 받을 수 있어요. |  |

## 자주 묻는 질문

### 고객이 휴대폰에서 견적서를 수락하거나 거절할 수 있나요?

네. 고객은 받은 링크로 견적서를 열어 모바일 기기에서 바로 **Accept**(수락) 또는 **Reject**(거절)를 누를 수 있어요. 상태는 대시보드에 자동으로 반영돼요.

### 견적서를 보낸 뒤에도 편집할 수 있나요?

아니요. 견적서는 한 번 보내면 편집할 수 없어요. 내용을 바꾸려면 새 견적서를 만들어야 해요.

### 고객이 견적서에 서명하면 알림을 받을 수 있나요?

네. 고객이 견적서에 서명하거나 거절하면 바로 앱 알림을 받아요. 그래서 다음 단계를 곧바로 진행할 수 있어요.
