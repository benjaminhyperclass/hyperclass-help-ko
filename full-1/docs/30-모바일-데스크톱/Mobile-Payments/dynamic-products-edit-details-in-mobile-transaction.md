# 모바일 거래에서 상품 세부 정보 수정하기 (동적 상품)

모바일 앱에서 거래를 진행하는 중에 상품의 이름, 설명, 세금, 가격, 수량을 직접 바꾸는 방법을 안내해요. 바꾼 내용은 카탈로그에 저장해 두었다가 나중에 다시 쓸 수도 있어요.

거래 중에는 상품에 이미 설정해 둔 정보만 써야 하는 것이 아니에요. 이름, 설명, 세금, 가격, 수량을 모두 자유롭게 수정할 수 있어요.

## 할 수 있는 일

- 사용자 지정 항목 편집
  - POS, 인보이스, 견적서에서 **Keypad**(키패드) 탭의 숫자 패드로 금액을 직접 입력하면, 항목 이름 **Custom Item**(사용자 지정 항목)을 원하는 이름으로 바꿀 수 있어요.
  - 금액 바로 아래에 강조 표시된 **항목 세부사항** 버튼을 누르면 돼요.
  - 최종 인보이스나 영수증에 넣고 싶다면 사용자 지정 항목에 설명도 추가할 수 있어요.
- 사용자 지정 항목에 세금 연결
  - 키패드로 추가한 사용자 지정 항목에 세금을 연결할 수 있어요.
  - **Keypad** 탭에서 금액 아래에 있는 **항목 세부사항** 버튼을 누르면 돼요.
- 나중에 사용하도록 저장
  - 사용자 지정 항목을 카탈로그에 저장해 두면 나중에 다시 쓸 수 있어요.
  - **Keypad** 탭에서 금액 아래에 있는 **항목 세부사항** 버튼을 누른 뒤 **나중에 사용하도록 저장**을 켜세요.
- 검토 화면에서 항목 편집
  - 위 기능은 키패드 화면과 검토 화면, 두 곳에서 모두 쓸 수 있어요.
  - 카탈로그 항목도 검토 화면에서 항목 타일을 누르면 필요한 세부 정보를 모두 수정할 수 있어요.

## 동적 상품 화면 구성

**Update Product**(상품 업데이트) 편집 화면에는 다음 항목이 있어요.

1. 이름
2. 설명: 최종 인보이스나 영수증에 표시돼요.
3. 수량
4. 가격
5. 세금
6. **나중에 사용하도록 저장**
7. **업데이트** (변경 내용을 취소할 수도 있어요.)

## 상품 업데이트 편집 화면 여는 방법

**Update Product** 편집 화면은 두 가지 방법으로 열 수 있어요.

1. POS 숫자 패드의 큰 검은색 **edit details**(세부정보 편집) 버튼을 누르세요.
2. **Review Payment**(결제 검토) 화면에서 항목 카드를 누르세요.

## 옵션 조합 추가하기

같은 상품의 다른 옵션 조합을 추가하고 싶다면, 카탈로그 화면의 수량 카운터에서 "+"를 누른 뒤 **new customization**(새 커스터마이징)을 누르세요.

## 동적 상품 사용하기

1. 사용 중인 하이퍼클래스 모바일 앱을 기기에 설치하세요.
2. 앱 하단 바의 "$" 아이콘을 눌러 POS 화면으로 이동하세요.
3. 키패드(사용자 지정 금액)나 카탈로그를 사용해 결제할 항목을 추가하세요. 둘을 함께 써도 돼요.
4. 키패드로 입력한 금액 아래에 강조 표시된 **항목 세부사항** 버튼이 보여요. 이 버튼을 누르세요.
5. 새 화면이 열려요. 이 화면에서 항목 이름 **Custom Item**을 원하는 이름으로 바꿀 수 있어요. 설명 추가, 세금 연결, 수량 조정, 가격 변경도 할 수 있어요. 항목을 카탈로그에 저장해 두고 나중에 쓸 수도 있어요.
6. 카탈로그 항목을 추가했다면 항목 타일을 눌러 이름, 설명, 가격, 수량을 수정할 수 있어요. 옵션이 여러 개인 상품이라면 알맞은 옵션 조합을 선택한 뒤 결제 단계에 추가하세요.
7. 같은 상품의 다른 옵션 조합을 추가하려면 카탈로그 화면의 수량 카운터에서 "+"를 누른 뒤 **new customization**을 누르세요.
8. 결제할 항목을 모두 추가했다면 **청구**를 눌러 검토 단계로 이동하세요.
9. 검토 단계에서도 상품 타일을 누르면 앞에서 본 것과 같은 화면이 열려서 상품 세부 정보를 더 수정할 수 있어요.
10. 거래 내용을 마지막으로 확인한 뒤 **Choose Payment Instruments**(결제 수단 선택) 버튼을 눌러 고객에게 청구할 결제 수단을 고르세요. 거래를 인보이스나 견적서로 바꿀 수도 있어요.
