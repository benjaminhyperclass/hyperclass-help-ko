# 모바일 앱에서 대면 서명 받기

모바일 앱에서 직접 대면 서명을 받을 수 있어요. 미팅이나 행사 현장, 고객을 직접 만나는 자리에서 문서와 계약을 바로 마무리할 때 쓰세요.

[동영상](https://www.youtube.com/embed/5VX9O0cSThk?&wmode=opaque)

받는 사람이 내 모바일 기기에서 바로 서명하므로 인쇄하거나 스캔하거나 이메일로 보낼 필요가 없어요.

이 기능은 하이퍼클래스 모바일 앱과 화이트라벨 모바일 앱에서 쓸 수 있어요.

{% hint style="info" %}
화이트라벨 앱을 쓰고 있다면 이 기능을 쓰기 위해 앱 업데이트를 요청해야 할 수 있어요.
{% endhint %}

## 이런 걸 할 수 있어요

- 서명자로 보기: 게시된 문서를 수신자 중 한 사람의 입장에서 열어 그 사람의 서명을 받을 수 있어요.
- 모바일에서 서명하기: 모바일 앱 화면에서 직접 글자를 입력하거나 손으로 그려서 서명할 수 있어요.
- 템플릿 사용하기: 서명 필드가 하나 이상 들어 있는 기존 템플릿으로 문서를 만들 수 있어요.

## 모바일에서 대면 서명 받는 방법

다음 단계를 따라 모바일 앱에서 문서를 준비하고 서명을 받으세요.

1. 모바일 앱에 로그인하세요. 사용할 서브 계정으로 로그인했는지 확인하세요.
2. 왼쪽 메뉴를 열고 **문서 & 계약** 섹션으로 이동하세요.
3. **새 문서**를 눌러, 서명 필드가 하나 이상 있는 저장된 템플릿으로 문서를 만드세요.
4. 문서가 준비되면 **Share**(공유) 아이콘을 누르고 링크를 복사해서 문서 게시를 마무리하세요.
5. 게시한 문서를 찾으세요.
   1. 문서 편집 화면에서 나가세요.
   2. **All Documents**(전체 문서) 탭으로 이동하세요.
   3. 문서 상태가 아직 **Sent**(발송됨)로 보이지 않으면 화면을 새로 고치세요. 그러면 **Sent**로 표시돼요.
6. **View as**(다음 사용자로 보기) 모드로 문서를 여세요.
   1. 문서 오른쪽의 점 세 개 메뉴(⋮)를 누르세요.
   2. **View as**를 선택하고, 수신자 목록에서 서명할 사람을 고르세요.
      ![View as 선택 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050340028/original/KMbuuMrztDXgyNqOtarTa7KB6Q-J24bI7w.png?1753324686)
      ![View as 선택 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050340036/original/hhOu9_EX9_HTja8FDnh8uZks-7qL_5inbg.png?1753324721)
7. 서명을 받으세요.
   1. 기기를 수신자에게 건네세요.
   2. 수신자는 앱 안에서 글자를 입력하거나 손으로 그려서 서명해요.
   3. 필수 입력 항목이 더 있으면 함께 작성해요.
      ![서명 입력 화면 1](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050340041/original/Ns1beEuKaGI5Cp2bss35Q2A8vkJZrBv2UQ.png?1753324757)
      ![서명 입력 화면 2](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155050340044/original/EsvyAS1l8uYCctOH5_t4WgS7hZLsEx7zVg.png?1753324775)
8. 서명자가 더 있으면 수신자마다 **View as**와 서명 과정을 반복하세요.
9. 모든 사람이 서명하면 문서가 최종 완료되고, 받은 서명이 모두 담긴 채로 저장돼요.

## 참고 사항 및 활용 팁

- 템플릿에 서명자 수만큼 서명 필드가 들어 있는지 확인하세요.
- **View as** 옵션은 문서가 **Sent** 상태가 된 뒤에만 나타나요.
- 화이트라벨 앱을 쓴다면 대면 서명을 지원하는 최신 버전으로 업데이트되어 있는지 확인하세요.

{% hint style="info" %}
모바일 앱에서 바로 대면 서명을 받으면 계약과 합의를 언제 어디서든 더 빠르게 마무리할 수 있어요.

문제가 생기거나 화이트라벨 앱에서 이 기능을 켜는 데 도움이 필요하면 담당 고객지원팀에 문의하세요.
{% endhint %}
