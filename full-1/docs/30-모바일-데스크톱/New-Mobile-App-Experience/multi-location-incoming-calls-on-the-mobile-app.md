# 모바일 앱에서 여러 서브 계정의 수신 전화 받기

하이퍼클래스 모바일 앱에서 서브 계정을 여러 개 운영한다면 **Multi-Location Incoming Calls**(멀티 로케이션 수신 전화) 기능으로 전화를 놓치지 않을 수 있어요. 이 문서에서는 기능의 개념과 켜는 방법, 자주 묻는 질문을 안내해요.

이전에는 지금 로그인해 있는 서브 계정으로 오는 전화만 받을 수 있었어요. 그래서 전화를 놓치거나 응답이 늦어지고, 계정을 불필요하게 전환해야 했어요. 이제는 어느 서브 계정에서 작업 중이든 최대 10개 서브 계정(로케이션)의 전화를 모바일 앱에서 바로 받을 수 있어요. 수신 화면에는 전화가 걸려 온 서브 계정이 표시돼요. 통화 중에 해당 서브 계정으로 바로 전환해서 메모를 남기고, 연락처를 확인하고, CRM 데이터를 업데이트할 수도 있어요.

## Multi-Location Incoming Calls란?

```
현재 모바일 앱에서만 사용할 수 있어요.
전화를 받으려는 모든 서브 계정(로케이션)의 구성원이어야 해요.
한 번에 최대 10개까지 선택할 수 있어요.
```

**Multi-Location Incoming Calls**는 여러 서브 계정(로케이션)으로 오는 전화를 동시에 받도록 사용자가 직접 선택하는 모바일 기능이에요. 기능을 켜면 지금 어느 서브 계정에 로그인해 있든, 선택한 서브 계정 중 어디로 전화가 와도 휴대폰이 울려요.

수신 화면에는 전화가 어느 서브 계정에서 왔는지 알려 주는 **Location Badge**(로케이션 배지)가 표시돼요. 통화 중에는 그 서브 계정으로 바로 전환해서 메모 작성, 파이프라인 업데이트, 통화 기록 같은 CRM 작업을 할 수 있어요.

## Multi-Location Incoming Calls의 장점

여러 서브 계정을 운영하는 조직에서도 리드 응대를 한곳에서 처리할 수 있어요.

- 놓치는 리드 없음: 다른 서브 계정에서 작업 중이어도 최대 10개 서브 계정의 전화를 받을 수 있어요.
- 바로 파악되는 상황: 수신 화면의 로케이션 배지로 해당 리드가 CRM 어디에 있는지 바로 알 수 있어요.
- 한 번 탭해서 전환: 통화 중에 알맞은 서브 계정으로 바로 이동해 연락처, 메모, 딜을 확인할 수 있어요.
- 사용자별 설정: 팀원마다 자기 기기로 전화가 울리게 할 서브 계정을 직접 골라서, 알림이 지나치게 많아지는 것을 막을 수 있어요.
- 업무 효율 향상: 앱을 정신없이 오가지 않아도 되고, 엉뚱한 서브 계정에서 작업해서 생기는 후속 조치 오류도 줄어요.

## 멀티 로케이션 수신 켜는 방법 (모바일)

다음 순서로 Multi-Location Incoming Calls를 켜세요.

![멀티 로케이션 수신 전화 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056084134/original/Ys6ATMFKg-8T-iFeyPXlkv39p5U3ZL8J7A.png?1760546949)

1. 하이퍼클래스 모바일 앱을 열고 **설정 > 전화/음성**으로 이동하세요.
2. **Multi-Location Incoming Calls**를 켜세요.
3. 전화를 받을 서브 계정을 최대 10개까지 선택하세요. 선택하는 서브 계정에는 이미 사용자로 등록되어 있어야 해요.
4. 기능을 켜면 다른 서브 계정에서 작업 중이어도, 선택한 서브 계정으로 오는 전화에 휴대폰이 울려요.
5. 수신 화면에서 다음을 확인하세요.

   - **Location Badge**로 전화가 어느 서브 계정에서 왔는지 확인하세요.
   - 통화 중에 **Switch Location**(로케이션 전환)을 탭하면 해당 서브 계정으로 바로 이동해요.
6. 통화가 끝나면 알맞은 CRM 워크스페이스에서 후속 조치와 메모를 마무리하세요.

![로케이션 배지가 표시된 수신 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056084204/original/kVMQVsKOqOjmHcFEIvx7P1mjwxcFVDZxNg.png?1760547028)

## 자주 묻는 질문

### 10개가 넘는 서브 계정의 전화도 받을 수 있나요?
아니요. 성능 문제를 막고 수신 전화를 명확하게 구분할 수 있도록, 현재는 최대 10개까지만 선택할 수 있어요.

### 이 기능을 켜려면 관리자 권한이 필요한가요?
아니요. 선택하려는 서브 계정의 구성원이기만 하면 누구나 자기 계정에서 Multi-Location Incoming Calls를 켤 수 있어요.

### 전화가 어느 서브 계정으로 온 건지 알 수 있나요?
네. 수신 화면의 **Location Badge**에 전화가 걸려 온 서브 계정의 이름이 표시돼요.

### 통화를 끊지 않고 통화 메모를 남길 수 있나요?
네. 통화 중에 **Switch Location**을 탭해 해당 서브 계정으로 이동하면 CRM 도구를 쓸 수 있어요.

### 데스크톱에서도 사용할 수 있나요?
아니요. 현재 Multi-Location Incoming Calls는 모바일 앱에서만 쓸 수 있어요. 데스크톱에서는 지금 활성화된 서브 계정의 전화만 받아요.

### 이미 다른 전화를 받고 있으면 어떻게 되나요?
새로 걸려 온 전화는 현재 설정된 통화 처리 규칙(예: 통화 대기, 음성사서함)을 따라요.

### 워크플로우도 올바른 서브 계정에서 실행되나요?
네. 통화 중에 알맞은 서브 계정으로 전환하기 때문에, 모든 자동화와 통화 기록이 그 서브 계정에 연결돼요.

### 이 기능을 쓰면 하이퍼클래스 전화 사용량이 추가로 차감되나요?
아니요. 사용량은 해당 번호로 오는 일반 인바운드 통화와 같은 방식으로 청구돼요.
