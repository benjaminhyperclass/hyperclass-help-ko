# 모바일 앱 알림이 오지 않을 때: 알림 진단으로 원인 찾기

알림 진단(Notification Diagnosis)은 하이퍼클래스 모바일 앱 알림이 휴대폰에 오지 않는 이유를 찾는 데 도움을 주는 기능이에요. 한 번에 네트워크, 알림 권한, 소리 설정, 실제 알림 전송 여부를 확인하고, 문제가 계속되면 진단 리포트를 복사해서 고객지원에 전달할 수 있어요.

이 문서에서는 알림 진단을 실행하는 방법, 각 진단 항목의 의미, 테스트 알림 도착 여부를 확인하는 방법, 설정을 바꾼 뒤 다시 진단하는 방법, 리포트를 복사하는 방법을 안내해요.

## 알림 진단이란?

알림 진단은 앱에 들어 있는 문제 해결 도구예요. 알림이 휴대폰에 도착하지 않는 이유를 찾아 줘요.

진단은 **네트워크**, **알림**, **Sound**(소리), **전송 테스트** 네 가지 항목을 확인해요. 항목마다 결과가 나오므로 어느 부분을 점검해야 하는지 알 수 있어요.

**전송 테스트**는 실제 알림을 휴대폰으로 보내요. 문제가 있을 수 있는 항목이 있으면, 앱이 다시 진단하기 전에 무엇을 확인하면 되는지 안내해 줘요.

## 알림 진단의 장점

알림 진단은 알림과 관련해 가장 중요한 확인 항목을 안내 한 번에 모아 줘요. 기기 설정을 하나씩 직접 살펴보지 않아도 문제 범위를 좁힐 수 있어요.

- 여러 항목을 한 번에 확인: **네트워크**, **알림**, **Sound**, **전송 테스트**를 한 번에 점검해요.
- 실제 알림 전송 테스트: 휴대폰으로 테스트 알림을 보내고 도착했는지 확인해요.
- 점검할 부분 파악: 항목별 결과를 보고 확인해야 할 기기 설정이나 연결 상태에 집중할 수 있어요.
- 테스트 알림 다시 받기: 테스트 알림을 한 번 더 받고 싶을 때 **재전송**을 눌러요.
- 변경 사항 확인: 설정을 바꾼 뒤 진단을 다시 실행해요.
- 진단 결과 공유: 문제가 계속되면 리포트를 복사해서 고객지원 문의에 첨부해요.

## 사용 조건과 참고 사항

지원되는 버전의 모바일 앱을 사용해야 해요. 한 항목의 결과만 보지 말고 전체 결과를 함께 확인하세요. 통과한 항목은 테스트한 부분에 문제가 없다는 뜻이에요. 그래도 알림 문제가 계속되면 추가 조사가 필요할 수 있어요.

- 하이퍼클래스 모바일 앱 **4.25.0 버전 이상**을 사용하세요.
- 진단은 **네트워크**, **알림**, **Sound**, **전송 테스트**를 확인해요.
- 확인이 필요한 항목이 있으면 앱에 표시되는 안내를 따르세요.
- 설정을 바꾼 뒤에는 진단을 다시 실행해서 새 결과를 확인하세요.
- 모든 항목이 통과했는데도 알림이 제대로 오지 않으면, 진단 리포트를 복사해서 고객지원에 보내세요.
- 해당 버전을 사용 중이라면 지원되는 화이트라벨 모바일 앱에서도 이 기능을 쓸 수 있어요.

## 알림 진단 실행하기

모바일 알림이 오지 않거나, 내 기기에서 하이퍼클래스 알림을 제대로 받을 수 있는지 확인하고 싶을 때 알림 진단을 실행하세요.

1. **하이퍼클래스 모바일 앱**을 열어요.
2. **설정**을 열어요.
3. **Diagnose Notifications**(알림 진단)를 선택해요.
4. **Start Diagnosis**(진단 시작)를 눌러요.

![알림 진단 화면: 진단 시작과 테스트 알림 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930912/original/uJUnCQWTbjA8TW0arSH0ZE6uhk6kh0mMdA.png?1790468383)

5. 앱이 **네트워크**, **알림**, **Sound**, **전송 테스트** 항목을 확인할 때까지 기다려요.
6. 항목별로 표시되는 결과를 확인해요.
7. 테스트 알림이 전송되면 아래 버튼으로 결과를 알려 주세요.
   - **수신됨**: 테스트 알림이 도착했을 때 선택해요.
   - **Didn't receive**(수신 못 함): 알림이 도착하지 않았을 때 선택해요.
   - **재전송**: 테스트 알림을 한 번 더 보내요.
8. 확인이 필요한 항목에 표시되는 안내를 따라요.

9. 안내에 따라 해당 기기 설정이나 연결 상태를 바꿔요.
10. 알림 진단 화면으로 돌아와 **Run diagnosis again**(진단 다시 실행)을 눌러요.
11. 새로 나온 결과를 확인해요.
12. 그래도 알림이 제대로 오지 않으면 **Copy report**(리포트 복사)를 눌러요.
13. 복사한 진단 리포트를 고객지원 문의에 붙여 넣어요.

![알림 진단 결과 화면: 진단 결과, 실패한 전송 테스트, 진단 다시 실행, 리포트 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155081930920/original/G0mOKaymxPWv7hNrQeesQ3JWXOJPJf3qLA.png?1790468527)

## 알림 진단 항목 이해하기

항목마다 알림 전송 과정의 다른 부분을 확인해요. 네 가지 결과를 모두 살펴보면 연결 상태, 기기 권한, 소리 알림, 실제 알림 전송 중 어느 쪽 문제인지 좁힐 수 있어요.

### 네트워크

**네트워크** 항목은 알림을 받는 데 필요한 연결 상태를 확인해요. 확인이 필요하다고 나오면 앱에 표시되는 안내를 따라 네트워크나 Wi-Fi 연결을 점검한 뒤 진단을 다시 실행하세요.

### 알림

**알림** 항목은 알림에 필요한 권한이 허용되어 있는지 확인해요. 확인이 필요하다고 나오면 앱 안의 안내에 따라 알림 권한을 점검하고, 앱으로 돌아와 진단을 다시 실행하세요.

### Sound

**Sound**(소리) 항목은 알림 소리를 듣지 못하게 만들 수 있는 설정을 찾아 줘요. 벨소리 설정이나 집중 모드(Focus) 같은 설정에 대해 표시되는 안내를 확인하고, 필요한 부분을 바꾼 뒤 진단을 다시 실행하세요.

### 전송 테스트

**전송 테스트**는 휴대폰으로 실제 알림을 보내서 알림 전송이 제대로 되는지 확인해요.

- 알림이 도착했다면 **수신됨**을 선택하세요.
- 알림이 도착하지 않았다면 **Didn't receive**를 선택하세요.
- 테스트 알림을 한 번 더 받고 싶다면 **재전송**을 선택하세요.
- 다른 항목은 모두 통과했는데 **전송 테스트**가 계속 실패하면 **Copy report**를 눌러 진단 결과를 고객지원 문의에 첨부하세요.

## 자주 묻는 질문

### 알림 진단은 무엇을 확인하나요?
**네트워크**, **알림**, **Sound**, **전송 테스트** 네 가지를 확인해요.

### 테스트 알림이 오지 않으면 어떻게 하나요?
**Didn't receive**를 선택하거나 **재전송**을 눌러 보세요. 확인이 필요하다고 나온 항목을 살펴보고 앱에 표시되는 안내를 따른 뒤, 설정을 바꾸면 진단을 다시 실행하세요.

### 기기 설정을 바꾼 뒤에 진단을 다시 실행할 수 있나요?
네. **Run diagnosis again**을 누르면 설정을 바꾼 뒤 문제가 해결됐는지 확인할 수 있어요.

### 모든 항목이 통과했는데도 알림이 오지 않으면 어떻게 하나요?
**Copy report**를 눌러 진단 결과를 고객지원 문의에 첨부하세요. 자세한 조사를 받을 수 있어요.

### 어떤 버전의 하이퍼클래스 모바일 앱에서 알림 진단을 쓸 수 있나요?
**4.25.0 버전 이상**을 사용하세요.

### 알림 진단이 내 알림 환경설정을 바꾸나요?
알림 진단은 문제 해결을 도와주는 기능이에요. 확인이 필요한 설정이 있으면 앱에 표시되는 안내를 따라 직접 필요한 부분을 바꾼 뒤 진단을 다시 실행하세요.
