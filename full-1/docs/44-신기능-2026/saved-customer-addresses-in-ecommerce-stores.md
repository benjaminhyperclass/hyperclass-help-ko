# 이커머스 스토어의 저장된 고객 주소

다시 방문한 고객이 더 빠르게 결제할 수 있도록, 로그인한 고객은 배송지와 청구지 주소를 스토어 프로필에 저장해 두고 다음 주문에서 다시 쓸 수 있어요. 이 문서에서는 저장된 고객 주소 기능이 무엇인지, 로그인 상태의 결제 화면을 어떻게 미리 보는지, 안내 문구를 어떻게 바꾸는지 알려 드려요.

## 저장된 고객 주소란?

로그인한 고객은 배송지와 청구지 주소를 스토어 프로필에 저장해 둘 수 있어요. 그러면 결제할 때마다 같은 정보를 다시 입력하지 않아도 돼요.

- 고객은 스토어마다 주소를 최대 10개까지 저장하고, 그중 하나를 기본 주소로 정할 수 있어요.
- 기본 주소는 결제 화면에서 자동으로 선택돼요. 다른 주소가 필요하면 저장된 주소 중에서 직접 고를 수 있어요.
- 주문하는 중에 새 배송지나 청구지 주소를 저장할 수도 있어요.
- 비회원 결제는 지금처럼 그대로 사용할 수 있어요.

스토어 운영자는 **Store Builder**(스토어 빌더)에서 저장된 주소 관련 문구를 바꾸고, 로그인 상태의 결제 화면을 미리 볼 수 있어요.

{% hint style="info" %}
저장된 주소는 개별 스토어에 속해요. 같은 서브 계정에 있는 다른 스토어와는 공유되지 않아요.
{% endhint %}

## 로그인 상태의 결제 화면 미리 보기

스토어 빌더에서는 로그인한 고객이 보는 결제 화면을 띄울 수 있어요. 게시하기 전에 저장된 주소 카드를 확인하고 수정해 보세요.

1. 스토어 빌더에서 **Navigation Menu**(내비게이션 메뉴) 요소를 선택하세요.
2. **Enable Customer Login**(고객 로그인 활성화)을 켜세요.
3. 결제 캔버스에 표시된 저장된 주소 카드를 확인하고, 필요한 부분을 수정하세요.
4. 비회원 미리보기로 돌아가려면 **Enable Customer Login**을 끄세요.

이 설정을 켜거나 끄면 결제 캔버스가 바로 바뀌어요. 미리보기 상태를 바꾸기 위해 저장하거나 게시할 필요는 없어요.

## 저장된 주소 문구 바꾸기

결제 화면에서 고객에게 보이는 저장된 주소 관련 문구를 바꿀 수 있어요.

1. 스토어 빌더에서 **결제** 페이지를 여세요.
2. **결제** 요소를 선택하세요.
3. **Text Customization**(텍스트 사용자 지정) > **Saved Address Card**(저장된 주소 카드)까지 스크롤하세요.
4. 저장된 주소 레이블을 필요에 맞게 수정하세요.
