# Unified Facebook Connect로 Facebook 페이지 연결하기

Unified Facebook Connect를 쓰면 Facebook 페이지와 여기에 연결된 Instagram 프로페셔널 계정을 하이퍼클래스 **소셜 플래너**(Social Planner)에서 더 쉽게 관리할 수 있어요. **설정 > 연동**에서 Facebook을 한 번만 연결하면, 같은 계정이 소셜 플래너에도 자동으로 나타나요. 이 문서에서는 연결 방법, 계정 동기화 방식, 부족한 권한을 해결하는 방법을 안내해요.

Facebook 페이지와 연결된 Instagram 프로페셔널 계정을 하이퍼클래스 안에서 연결하고 관리하는 과정이 한결 간단해졌어요. 이전에는 같은 Facebook 계정을 **연동**과 **소셜 플래너**에서 따로 연결해야 했어요. 이제는 **설정 > 연동**에서 한 번만 연결하면 **마케팅 > 소셜 플래너 > 설정 > Social Accounts**(소셜 계정)에서 선택한 Facebook 페이지를 바로 쓸 수 있어요.

해당 Facebook 페이지에 연결된 Instagram 프로페셔널 계정도 조건에 맞으면 자동으로 나타나요. 그래서 Facebook에 반복해서 로그인하거나 같은 계정을 두 번 설정할 필요가 없어요. 소셜 계정을 게시할 수 있는 상태로 준비하는 일도 더 쉬워져요. **소셜 플래너**에서 Facebook을 연결할 때도 **연동**에 이미 연결해 둔 정보를 다시 쓸 수 있어서, 계정 연결 방식이 더 일관돼요.

## Facebook 페이지 연결하기

**연동**에서 Facebook을 연결하면 선택한 페이지와 조건에 맞는 Instagram 프로페셔널 계정을 **소셜 플래너**에서 쓸 수 있어요. 이 방법은 **연동**에서 완료한 Facebook 인증을 그대로 사용해요.

1. 서브 계정에서 **설정 > 연동**으로 이동하세요.
2. Facebook 연동 카드를 찾아 **연결**을 클릭하세요.
3. Facebook 인증 창이 열리면, 연결하려는 페이지와 관련된 Facebook 계정으로 로그인하세요.
4. 연결할 Facebook 페이지를 선택하고, 필요한 권한 단계를 모두 완료하세요.
5. 계정이 연결되면 **소셜 플래너**에서 바로 사용할 수 있어요.

## 계정 동기화와 권한

Facebook 연결은 **연동**에서 **소셜 플래너**로 한 방향으로만 동기화돼요. **연동**에서 Facebook 페이지 연결을 해제하면 **소셜 플래너**에서도 사라지고, 그 페이지를 다시 연결하면 **소셜 플래너**에서 다시 쓸 수 있어요. **소셜 플래너**에서 직접 연결한 Facebook 계정은 **연동**으로 동기화되지 않아요.

Instagram 다이렉트 로그인 계정은 계속 양방향으로 동기화돼요. **연동**이나 **소셜 플래너** 중 어느 쪽에서 연결하거나 제거해도 두 곳에 모두 반영돼요.

Facebook 권한이 추가로 필요하면 **소셜 플래너**에 다음 버튼이 표시돼요.

- **새로고침**: 인사이트 접근 같은 추가 권한이 없는 상태예요. 게시에 필요한 권한이 있으면 게시는 계속 쓸 수 있어요.
- **재연결**: 게시에 필요한 권한이 없는 상태예요. Facebook 인증 과정을 완료하면 게시 권한이 복구돼요.

해당하는 버튼을 클릭한 뒤 Facebook 권한 과정을 끝내면 부족한 권한이 허용돼요.
