# 퍼널과 웹사이트에 퀴즈 추가하기

하이퍼클래스의 퀴즈 요소를 쓰면 퍼널과 웹사이트 페이지에 퀴즈를 바로 넣을 수 있어요. 페이지 빌더를 나가지 않고 퀴즈를 새로 만들거나, 만들어 둔 퀴즈를 고르거나, 편집할 수 있어요. 임베드 코드는 필요 없어요. 이 문서에서는 페이지에 퀴즈를 추가하고, 설정하고, 게시하는 방법을 안내해요.

## 퍼널과 웹사이트의 퀴즈 요소란?

퀴즈 요소를 쓰면 퍼널 단계나 웹사이트 페이지에 대화형 퀴즈를 바로 넣을 수 있어요.

예를 들어 리드 선별용 퀴즈를 넣어 방문자 정보를 모으고, 잠재 고객을 더 잘 파악할 수 있어요.

예전에는 임베드 코드를 복사해서 붙여 넣어야 했어요. 이제는 페이지 빌더 안에서 퀴즈를 추가하고 관리할 수 있어요.

## 퍼널 또는 웹사이트에 퀴즈 추가하기

임베드 코드를 복사하지 않고도 페이지에 퀴즈를 넣을 수 있어요. 아래 순서대로 퀴즈를 추가하고, 게시하기 전에 확인해 보세요.

### 1단계: 페이지 빌더 열기

1. **사이트 > 퍼널** 또는 **사이트 > 웹사이트**로 이동하세요.
2. 편집할 퍼널이나 웹사이트를 여세요.
3. 페이지나 퍼널 단계를 선택해 빌더를 여세요.

### 2단계: 퀴즈 요소 추가하기

1. **Quick Add**(빠른 추가)를 여세요.
2. **퀴즈**를 검색하세요.
3. **퀴즈** 요소를 페이지로 끌어다 놓으세요.

![빠른 추가에서 퀴즈 요소를 검색하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084043457/original/ypWmHF4IOX4RDkSStr4Zsb6y4B0lBSOjoQ.png?1792749796)

### 3단계: 퀴즈 만들기 또는 선택하기

둘 중 하나를 고르세요.

#### 새 퀴즈 만들기

1. **Create New Quiz**(새 퀴즈 만들기)를 선택하세요.
2. **퀴즈 빌더**에서 퀴즈를 만드세요.
3. 퀴즈를 **저장**하세요.

#### 기존 퀴즈 사용하기

1. **Add Existing Quiz**(기존 퀴즈 추가)를 선택하세요.
2. 페이지에 표시할 퀴즈를 고르세요.

![새 퀴즈 만들기와 기존 퀴즈 추가 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084044139/original/_Vseesa7XusL5T3QbNX7Ns3zL4xRPsk8vQ.png?1792750109)

### 4단계: 퀴즈 요소 설정하기

1. 페이지에서 퀴즈 요소를 선택하세요.
2. **일반 > Element Options**(요소 옵션)에서 올바른 퀴즈가 선택되어 있는지 확인하세요.
3. 사용할 수 있는 **스타일**과 **Button Actions**(버튼 동작) 설정을 살펴보세요.

![퀴즈 요소의 일반 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084044367/original/FVo8FpHKHfZnfu9w2_1D6clUeWd8o8TFYQ.png?1792750226)

### 5단계: 필요하면 퀴즈 편집하기

1. **Edit Quiz**(퀴즈 편집)를 클릭하세요.
2. 팝업에서 퀴즈 내용을 수정하세요.
3. **저장**을 클릭하세요.
4. 팝업을 닫고 페이지 빌더로 돌아오세요.

![팝업에서 퀴즈를 편집하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084044484/original/5RF_Sy_MaPgjoy493D6vsD5-NcmC9uxZfQ.png?1792750305)

### 6단계: 미리보기 후 게시하기

1. 페이지를 미리보기로 열어 퀴즈가 제대로 표시되는지 확인하세요.
2. 퀴즈 질문과 완료 화면까지 직접 테스트해 보세요.
3. 데스크톱과 모바일 레이아웃에서 모두 어떻게 보이는지 확인하세요.
4. 저장하지 않은 페이지 변경사항이 있으면 저장하세요.
5. 페이지가 준비되면 **게시**를 클릭하세요.

{% hint style="info" %}
팁: 페이지를 공유하기 전에 퀴즈 제출 메시지나 리디렉션을 테스트해 보세요.
{% endhint %}

## 퀴즈 요소 살펴보기

퀴즈 요소는 퍼널 빌더와 웹사이트 빌더에서 쓸 수 있어요.

**Quick Add**에서 **퀴즈**를 검색하거나, 요소 메뉴에서 **Forms, Surveys And Quizzes**(폼, 설문, 퀴즈)를 열면 찾을 수 있어요.

요소를 추가하면 선택한 퀴즈가 페이지에 표시돼요.

![페이지에 추가된 퀴즈 요소 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084044541/original/HJFhFg6GT1k5glhxW7VJEFgHZ0ceODtsBQ.png?1792750342)

## 퀴즈 만들기 또는 선택하기

새 퀴즈를 만들 수도 있고, 이미 만들어 둔 퀴즈를 다시 쓸 수도 있어요.

**Forms, Surveys And Quizzes**에서 다음 중 하나를 선택하세요.

- **Create New Quiz**: **퀴즈 빌더**를 열어 퀴즈를 만들어요.
- **Add Existing Quiz**: 이미 만든 퀴즈 중에서 하나를 골라요.

두 방법 모두 퍼널이나 웹사이트 빌더를 나가지 않고 쓸 수 있어요.

## 페이지 빌더에서 퀴즈 편집하기

퍼널이나 웹사이트 빌더에서 바로 퀴즈 내용을 편집할 수 있어요.

퀴즈 요소를 선택한 뒤 설정 패널에서 **Edit Quiz**를 클릭하세요. **퀴즈 빌더**가 큰 팝업으로 열리고, 여기서 질문과 설정 등 퀴즈 내용을 수정할 수 있어요.

변경사항을 저장하면 페이지 빌더로 돌아와요.

![퀴즈 빌더가 큰 팝업으로 열린 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084044846/original/9X_MuTJmJCA4gN798H37DQLWb52HxWFsFw.png?1792750498)

{% hint style="info" %}
참고: 같은 퀴즈가 여러 페이지에 들어 있다면, 수정하기 전에 다른 페이지에 어떤 영향이 있는지 확인하세요.
{% endhint %}

## 퀴즈 요소 설정 알아보기

퀴즈 요소 설정에서는 페이지에 표시할 퀴즈를 고르고, 모양과 동작을 조정할 수 있어요.

| 설정 | 용도 |
| --- | --- |
| **일반** | 요소 이름과 선택한 퀴즈를 관리해요 |
| **스타일** | 사용할 수 있는 모양 설정을 조정해요 |
| **Element Options** | 표시할 퀴즈를 선택해요 |
| **Edit Quiz** | 퀴즈 빌더를 열어요 |
| **Button Actions** | 사용할 수 있는 리디렉션 동작을 설정해요 |

**Button Actions** 드롭다운에는 **Use action from Quiz Builder**(퀴즈 빌더의 동작 사용) 항목이 있어요.

{% hint style="warning" %}
중요: 특정 리디렉션 동작에 의존하기 전에, 요소의 **Button Actions**가 퀴즈 빌더의 제출 설정과 어떻게 함께 작동하는지 확인하세요.
{% endhint %}

## 퀴즈 제출 내용과 결과 관리하기

질문, 점수 계산, 결과, 제출 내용, 알림은 모두 **퀴즈 빌더**에서 관리해요.

**제출**에서 응답을 확인할 수 있어요. 지원되는 퀴즈 결과는 CRM **커스텀 필드**나 워크플로우와 연결해 쓸 수 있어요.

자세한 설정은 [퀴즈 빌더 가이드](../06-사이트/quiz-builder-guide.md)를 참고하세요.

## 자주 묻는 질문

### 퀴즈를 추가하려면 임베드 코드가 필요한가요?

아니요. 퀴즈 요소를 사용하면 지원되는 퍼널이나 웹사이트 페이지에 퀴즈를 바로 추가할 수 있어요.

### 이미 만든 퀴즈를 사용할 수 있나요?

네. **Add Existing Quiz**를 선택하거나, 퀴즈 요소 설정에서 퀴즈를 고르세요.

### 페이지 빌더를 나가지 않고 퀴즈를 만들 수 있나요?

네. **Create New Quiz**를 선택하면 페이지를 만드는 화면 안에서 **퀴즈 빌더**가 열려요.

### 퀴즈를 추가한 뒤에도 편집할 수 있나요?

네. 퀴즈 요소를 선택하고 **Edit Quiz**를 클릭하세요.

### 같은 퀴즈를 여러 페이지에서 쓸 수 있나요?

다른 페이지에서도 기존 퀴즈를 선택해 쓸 수 있어요. 여러 곳에서 쓰는 퀴즈를 편집하기 전에는 다른 위치에 어떤 영향이 있는지 확인하세요.

### 퀴즈 점수와 결과는 어디에서 바꾸나요?

**퀴즈 빌더**에서 바꿀 수 있어요. 자세한 내용은 [퀴즈 점수, 카테고리, 결과 페이지 설정하기](../06-사이트/퀴즈/how-to-set-up-quiz-scoring-categories-and-result-pages.md)를 참고하세요.

### 퀴즈 제출 내용은 어디에서 볼 수 있나요?

**퀴즈 빌더**를 열고 **제출**을 선택하세요.

### 임베드 코드도 계속 쓸 수 있나요?

네. 기존 임베드 코드는 지원되는 다른 웹사이트 연동에서 계속 유용하게 쓸 수 있어요.

### 퀴즈를 제출한 뒤의 동작을 설정할 수 있나요?

네. 퀴즈 빌더의 제출 설정과 요소의 **Button Actions**를 확인한 다음, 완료 후 동작을 직접 테스트해 보세요.
