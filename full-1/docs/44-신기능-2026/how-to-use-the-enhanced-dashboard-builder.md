# 향상된 대시보드 편집 기능 사용하기

하이퍼클래스의 대시보드 편집 기능을 쓰면 대시보드를 쉽게 꾸미고, 변경 내용을 확인하고, 팀과 함께 작업할 수 있어요. 자동 저장, 실행 취소/다시 실행, 버전 기록, 스티커 메모를 지원해서 안심하고 수정할 수 있어요. 대시보드 데이터를 새로 고치거나, 몇 번의 클릭으로 대시보드를 사용자 지정 리포트로 만들 수도 있어요.

## 대시보드 수정하기

### 1. 대시보드 편집 화면 열기

1. **서브 계정**에서 **대시보드**를 선택하세요.
2. 수정할 대시보드를 선택하세요.
3. **대시보드 수정**을 클릭하세요.
4. 왼쪽의 위젯 패널에서 위젯을 추가하거나 배치하세요.

---

### 2. 변경 취소하기 또는 이전 버전으로 복원하기

최근에 바꾼 내용은 실행 취소/다시 실행으로, 예전 대시보드는 버전 기록으로 되돌릴 수 있어요.

1. 편집 화면에서 **실행 취소** 또는 **다시 실행**을 클릭하면 변경을 되돌리거나 다시 적용할 수 있어요.
2. 이전 버전을 보려면 시계 아이콘(**버전 기록**)을 클릭하세요.
3. 목록에서 버전을 선택해 미리 보세요.
4. 그 버전을 사용하려면 **복원**을 클릭하세요.

현재 버전에는 **라이브**라고 표시돼요.

---

### 3. 스티커 메모 추가하기

스티커 메모를 쓰면 대시보드 위에서 바로 팀에게 알림이나 참고 내용을 남길 수 있어요.

1. 편집 화면에서 스티커 메모 아이콘을 클릭하세요.
2. 메모 내용을 입력하고 색상을 고르세요.
3. 메모를 원하는 위치로 끌어다 놓으세요.
4. 메모를 모두 숨기고 싶을 때는 메모 숨기기 아이콘을 사용하세요.

---

### 4. 빠른 필터 설정하기

**빠른 필터**를 쓰면 지원되는 대시보드 위젯에 표시할 데이터를 조절할 수 있어요.

1. 대시보드를 열고 **대시보드 수정**을 클릭하세요.
2. **빠른 필터** 설정을 여세요.
3. 필터를 추가하거나 수정하세요.
4. 뒤로 가기 화살표를 눌러 대시보드 보기 모드로 돌아오세요.

---

### 5. 대시보드 데이터 새로 고치기

위젯 데이터를 최신으로 보고 싶을 때 대시보드를 새로 고치세요.

1. 대시보드 보기 모드로 돌아오세요.
2. 새로 고침 아이콘 위에 마우스를 올리면 마지막으로 새로 고친 시간을 볼 수 있어요.
3. 새로 고침 아이콘을 클릭하면 모든 위젯이 다시 로드돼요.

---

### 6. 대시보드로 리포트 만들기

대시보드에 있는 위젯을 그대로 활용해 사용자 지정 리포트를 만들 수 있어요.

1. 대시보드를 보기 모드로 여세요.
2. 종이비행기 아이콘(**리포트로 보내기**)을 클릭하세요.
3. **생성 및 전송**을 선택하세요.
4. 대시보드 위젯이 복사되어 **리포팅 > 사용자 지정 리포트**에 새 리포트로 만들어져요.
5. 필요에 맞게 리포트를 수정하고, 내보내고, 보내거나 예약하세요.

{% hint style="info" %}
리포트는 대시보드와 별개로 복사된 사본이에요. 원래 대시보드를 바꿔도 리포트는 자동으로 바뀌지 않아요.
{% endhint %}

## 자주 묻는 질문

### 대시보드 변경 내용을 직접 저장해야 하나요?
아니요. 대시보드 변경 내용은 자동으로 저장돼요. **저장됨** 배지가 보이면 저장이 끝난 거예요.

### 이전 대시보드 버전을 되살릴 수 있나요?
네. **버전 기록**을 열어 이전 버전을 미리 보고 복원할 수 있어요.

### 팀원도 스티커 메모를 볼 수 있나요?
네. 대시보드를 볼 수 있는 권한이 있는 사람은 표시된 스티커 메모를 볼 수 있어요.

### 대시보드를 바꾸면 사용자 지정 리포트도 같이 바뀌나요?
아니요. 리포트는 대시보드 위젯을 복사해 만든 독립된 사본이에요.
