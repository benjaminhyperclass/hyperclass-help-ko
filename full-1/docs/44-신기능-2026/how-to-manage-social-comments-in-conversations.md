# 대화에서 소셜 댓글 관리하기

소셜 플래너로 게시한 Facebook, Instagram, TikTok 게시물의 댓글을 **대화** 받은편지함에서 바로 관리할 수 있어요. 새로 댓글을 단 사람은 자동으로 연락처에 저장되기 때문에, 한곳에서 답글, 후속 연락, 잠재 리드 관리를 할 수 있어요. 이 문서에서는 댓글 동기화를 켜는 방법, 들어온 댓글을 관리하는 방법, 상품이나 서비스에 관심 있는 사람을 찾는 방법을 안내해요.

## 대화의 소셜 댓글이란?

소셜 댓글은 지원되는 **소셜 플래너**(Social Planner) 게시물의 댓글을 **대화** 의 **팀 인박스**로 가져오는 기능이에요. SMS, 이메일, 다이렉트 메시지(DM)와 같은 곳에서 댓글을 볼 수 있어요.

댓글마다 원본 게시물 정보가 담긴 대화 스레드가 만들어져요. 공개 답글을 달 수도 있고, 지원되는 경우 DM으로 대화를 이어갈 수도 있어요. 댓글 작성자는 연락처로 관리할 수 있어요.

지원 플랫폼: Facebook, Instagram, TikTok

{% hint style="warning" %}
소셜 플래너로 게시한 게시물의 댓글만 동기화돼요.
{% endhint %}

---

## 팀 인박스에서 소셜 댓글 확인하기

동기화된 댓글은 **팀 인박스**에 대화 스레드로 표시돼요. 누가 어떤 게시물에 댓글을 달았는지 한눈에 보고, 상황에 맞게 답할 수 있어요.

스레드에는 다음 정보가 표시돼요.

- 댓글 작성자 이름과 댓글 미리보기
- 소셜 플랫폼과 작성 시각
- 원본 게시물 썸네일과 캡션
- 연결된 소셜 계정
- **View Post**(게시물 보기) 링크

**소셜 댓글** 필터를 사용하면 댓글 스레드만 따로 볼 수 있어요. 대화 필터에 대한 자세한 내용은 [대화 필터 개요](../03-대화/overview-of-conversation-filters.md)를 참고하세요.

![팀 인박스의 소셜 댓글 스레드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083655153/original/O8ICVjHPwmPo7skNCCILAEhkce3IjR2D2A.png?1792412064)

## 연락처 자동 생성

적용 대상인 소셜 플래너 게시물에 누군가 댓글을 달면 하이퍼클래스가 그 사람을 자동으로 연락처에 저장해요.

- 처음 댓글을 단 사람: 새 연락처가 만들어져요.
- 이전에 댓글을 단 사람: 해당 소셜 계정과 연결된 기존 연락처에 댓글이 이어져요.

연락처를 직접 만들지 않아도 상호작용을 추적하고 후속 연락을 할 수 있어요.

{% hint style="info" %}
댓글 동기화를 켜면 새로 댓글을 단 사람의 연락처가 자동으로 만들어져요.
{% endhint %}

---

## 댓글에 답글 달고 DM 보내기

**대화** 에서 동기화된 댓글에 바로 답할 수 있어요.

- **Public Reply**(공개 답글): 원래 소셜 미디어 댓글 아래에 답글을 달아요.
- **DM**(다이렉트 메시지): 플랫폼에서 지원하는 경우 비공개로 대화를 이어가요.

DM은 받은편지함에 일반 다이렉트 메시지 대화로 표시돼요. Messenger 연결 방법은 [시작하기: Facebook & Instagram Messenger 연결](../01-시작하기/세일즈-대화/getting-started-setup-facebook-and-instagram-messenger.md)을 참고하세요.

{% hint style="info" %}
DM을 보낼 수 있는지는 플랫폼의 메시지 권한과 제한에 따라 달라요.
{% endhint %}

## 구매 의도가 있는 댓글 찾기

구매 의도 키워드와 필터를 쓰면 상품을 사거나 서비스를 예약하려는 사람의 댓글을 쉽게 찾을 수 있어요.

다음과 같이 활용할 수 있어요.

- "가격", "가능", "예약" 같은 키워드가 들어간 댓글을 찾아요.
- 질문이 들어 있는 댓글만 필터링해요.
- 댓글을 정렬해서 잠재 리드부터 먼저 확인해요.

예를 들어 누군가 "가격이 얼마인가요? 토요일에 예약할 수 있나요?"라고 댓글을 달았다면, "가격", "예약" 같은 키워드를 설정해 두었을 때 후속 연락이 필요한 댓글로 찾을 수 있어요.

## 댓글 동기화 설정 관리

댓글 동기화는 두 단계로 조정할 수 있어요. 에이전시는 어떤 서브 계정과 소셜 플랫폼의 댓글을 **대화** 로 보낼지 정할 수 있어요.

| 구분 | 용도 |
| --- | --- |
| 에이전시 단위 | 서브 계정 한 개 또는 여러 개의 댓글 동기화를 켜거나 꺼요 |
| 채널 단위 | 연결된 소셜 플랫폼 중 댓글을 동기화할 플랫폼을 선택해요 |

{% hint style="warning" %}
동기화를 끄면 새 댓글이 더 이상 **대화** 에 표시되지 않아요. 기존 연락처, 대화, 워크플로우는 삭제되지 않아요.
{% endhint %}

소셜 플래너 안의 댓글 관리는 이와 별개로 계속 사용할 수 있어요. 자세한 내용은 [소셜 플래너에서 댓글 관리하기](../10-마케팅/소셜-플래너/social-planner-manage-comments.md)를 참고하세요.

## 지원 플랫폼과 제한 사항

대화의 소셜 댓글은 출시 시점에 Facebook, Instagram, TikTok에서 쓸 수 있어요.

LinkedIn, YouTube, Pinterest, Threads, Bluesky, 커뮤니티는 앞으로 지원할 예정이에요.

다음 제한 사항을 꼭 알아 두세요.

- 소셜 플래너로 게시한 게시물의 댓글만 동기화돼요.
- 소셜 플랫폼에서 직접 게시한 게시물은 포함되지 않아요.
- 동기화를 꺼도 이전에 동기화된 데이터는 삭제되지 않아요.
- 소셜 계정 연결이 만료되었다면 연결을 복구해야 동기화가 다시 시작돼요.

## 대화에서 소셜 댓글 설정하기

**대화** 에서 소셜 댓글을 받으려면 에이전시 수준에서 댓글 동기화를 켜고, 댓글을 동기화할 연결된 플랫폼을 선택하세요.

### 1단계: 에이전시 수준에서 댓글 동기화 켜기

에이전시 관리자만 쓸 수 있어요. 서브 계정 한 개 또는 여러 개에 대해 이 기능을 켤 수 있어요.

1. 하이퍼클래스 에이전시 계정에 로그인해요.
2. **에이전시 설정 > 소셜 댓글** 로 이동해요.
3. 서브 계정을 하나 또는 여러 개 선택해요.
4. 선택한 계정의 댓글 동기화를 켜요.
5. **변경사항 저장** 을 선택해요.

![에이전시 설정의 소셜 댓글 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083655518/original/e5OzqY7VaZifOKfFL1_AUWNT8iwBLmKo_g.png?1792412287)

### 2단계: 소셜 플랫폼 선택하기

**대화** 로 댓글을 보낼 연결된 소셜 플랫폼을 선택하세요.

1. 사용할 서브 계정을 열어요.
2. **마케팅 > 소셜 플래너 > 설정 > 댓글** 로 이동해요.
3. 사용하려는 지원 플랫폼의 댓글 동기화를 켜요.
4. **변경사항 저장** 을 선택해요.

![소셜 플래너 설정의 댓글 탭 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083655959/original/uvGCML4QPhVJW_BSnXJwdSkPDHyM7OeVeQ.png?1792412458)

{% hint style="info" %}
소셜 계정이 연결되어 있어야 하고, 게시물은 소셜 플래너로 게시한 것이어야 해요. 소셜 플래너 설정 방법은 [시작하기: 소셜 플래너 설정](../01-시작하기/마케팅-리드-생성/getting-started-setup-social-planner.md)을 참고하세요.
{% endhint %}

### 3단계: 대화에서 댓글 찾기

동기화를 켜면 적용 대상 댓글이 **대화** 받은편지함에 표시돼요.

1. **대화 > 팀 인박스** 를 열어요.
2. **소셜 댓글** 필터를 선택해요.
3. 댓글 스레드를 열어요.
4. 댓글과 원본 게시물 정보를 확인해요.

![팀 인박스에서 소셜 댓글 필터를 선택한 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083656198/original/kXj1tNhIdnWK4zCE5RFMPqMRKgO88KveTg.png?1792412593)

### 4단계: 댓글에 답하기

댓글을 열면 사용할 수 있는 메시지 옵션으로 답할 수 있어요.

1. 답하려는 댓글을 선택해요.
2. 원본 게시물을 보고 맥락을 확인해요.
3. **Public Reply** 또는 지원되는 **DM** 옵션을 선택해요.
4. 답변을 입력하고 보내요.

예를 들어 누군가 예약 가능 여부를 물었다면, 공개로 답하고 플랫폼에서 지원하는 경우 비공개로 이어서 상담할 수 있어요.

### 5단계: 리드 우선순위를 정하고 후속 연락하기

구매 의도 키워드, 질문 필터, 정렬을 활용해서 먼저 확인해야 할 댓글을 찾으세요.

1. **소셜 댓글** 의 필터 또는 우선순위 설정을 열어요.
2. "가격", "예약" 같은 관련 키워드를 설정해요.
3. 사용할 수 있는 필터나 정렬 옵션을 적용해요.
4. 조건에 맞는 댓글을 확인하고 답해요.
5. 후속 작업을 자동화하려면 지원되는 워크플로우를 설정해요. Facebook·Instagram 댓글 자동화는 [Facebook & Instagram 댓글 자동화 & AI 가이드](../36-기타/리커버리/guide-to-facebook-instagram-comment-automation-ai.md)를 참고하세요.

{% hint style="info" %}
키워드 설정과 정렬 옵션의 정확한 화면은 출시된 화면에서 확인해야 해요.
{% endhint %}

## 자주 묻는 질문

### 대화의 소셜 댓글은 어떤 플랫폼에서 쓸 수 있나요?
출시 시점에는 Facebook, Instagram, TikTok을 지원해요. 다른 플랫폼도 지원할 예정이에요.

### Instagram이나 Facebook에서 직접 게시한 게시물의 댓글도 표시되나요?
아니요. 소셜 플래너로 게시한 게시물의 댓글만 지원해요.

### 하이퍼클래스가 댓글 작성자를 자동으로 연락처로 만들어 주나요?
네. 새로 댓글을 단 사람은 연락처로 저장돼요. 이미 댓글을 단 적이 있는 사람은 해당 소셜 계정과 연결된 기존 연락처에 이어져요.

### 하이퍼클래스를 벗어나지 않고 댓글에 답할 수 있나요?
네. **대화** 에서 공개 답글을 달 수 있고, 지원되는 DM 옵션도 쓸 수 있어요.

### 특정 플랫폼만 동기화를 끌 수 있나요?
네. **마케팅 > 소셜 플래너 > 설정 > 댓글** 에서 플랫폼별 동기화를 관리할 수 있어요.

### 댓글 동기화를 끄면 어떻게 되나요?
새 댓글은 더 이상 동기화되지 않아요. 기존 연락처, 대화, 워크플로우는 그대로 남아요.

### 대화에 댓글이 표시되지 않아요.
다음을 확인하세요.
- 소셜 플래너로 게시한 게시물인지
- 지원되는 플랫폼인지
- 댓글 동기화가 켜져 있는지
- 소셜 계정 연결이 유효한지

### 소셜 계정 연결이 끊어지면 어떻게 하나요?
**소셜 플래너 설정** 에서 계정을 다시 연결하면 동기화가 다시 시작돼요. 연결이 끊긴 계정 알림은 [소셜 플래너: 연결 끊긴 계정 알림](../10-마케팅/소셜-플래너/social-planner-in-app-notification-banner-for-disconnected-accounts.md)을 참고하세요.
