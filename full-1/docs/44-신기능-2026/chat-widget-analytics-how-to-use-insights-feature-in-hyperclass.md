# 채팅 위젯 분석: 인사이트로 위젯 성과 확인하기

**인사이트**는 채팅 위젯의 성과 데이터를 한 대시보드에 모아 보여 주는 기능이에요. 방문자가 위젯을 불러오고, 열고, 리드가 되기까지의 과정을 따라가며 참여가 줄어드는 지점을 찾을 수 있어요. 이 문서에서는 인사이트를 여는 방법, 필터 적용 방법, 각 리포트를 읽는 방법을 안내해요.

## 인사이트란?

인사이트는 하이퍼클래스의 **채팅 위젯** 영역 안에 있는 **채팅 위젯 분석**(Chat Widget Analytics) 대시보드예요. 참여도, 리드 생성, 위젯별 성과, 고객 감성을 한곳에서 보여 주기 때문에 방문자가 채팅 위젯을 어떻게 쓰는지 평가할 수 있어요.

대시보드는 기존 위젯 이벤트 데이터를 바탕으로 방문자가 위젯 로드, 위젯 열림, 리드 생성 순서로 얼마나 이어지는지 보여 줘요. 계정의 모든 위젯 성과를 한꺼번에 볼 수도 있고, 위젯과 날짜 범위 필터로 결과를 좁힐 수도 있어요.

인사이트에는 다음 항목이 들어 있어요.

- 전환 퍼널
- 핵심 성과 지표
- 위젯별 리포트
- 참여도 차트
- 고객 감성 추이
- 세부 기록 보기

## 인사이트로 할 수 있는 일

방문자가 채팅 위젯을 어떻게 쓰는지 알면 어떤 위젯이 눈길을 끌고, 어떤 위젯이 리드를 만들며, 어느 단계에서 참여가 줄어드는지 파악할 수 있어요. 인사이트는 이런 수치를 하나의 리포트로 보여 줘요.

- 방문자 전환 추적: 위젯 로드, 열림, 리드를 전환 퍼널로 확인해요. 단계별 진행률과 전체 전환율을 보면 방문자가 어디에서 멈추는지 알 수 있어요.
- 한눈에 성과 확인: 만족도, 오픈율, 활성 위젯, 생성된 리드 같은 주요 지표를 위젯 기록을 하나씩 비교하지 않고 볼 수 있어요.
- 위젯별 성과 비교: 위젯마다 로드 수와 열림 수, 오픈율, 리드, 고객 피드백을 확인해요. 성과 열을 정렬하거나 이름으로 위젯을 걸러 볼 수도 있어요.
- 세부 활동 확인: 클릭할 수 있는 지표 값을 선택하면 그 숫자의 바탕이 된 기록을 볼 수 있어요.
- 참여 추이 분석: 일별 차트와 여러 보기 방식으로 열림과 열리지 않음의 변화를 비교해요.
- 고객 감성 파악: 방문자의 긍정·부정 피드백, 전체 만족도, 일별 피드백 추이를 확인해요.

## 인사이트 사용 방법

채팅 위젯 분석은 하이퍼클래스의 **채팅 위젯** 영역에서 열어요. 인사이트를 연 뒤 분석할 기간과 위젯을 고르고 각 리포트를 살펴보세요.

이 문서는 위젯을 새로 설치하는 방법이 아니라, 분석 기능을 사용하는 방법을 다뤄요.

### 1단계: 사이트 열기

1. 하이퍼클래스 **서브 계정**에서 **사이트**를 선택하세요.
2. 사이트 메뉴에서 **채팅 위젯**을 선택하세요.

### 2단계: 인사이트 탭 열기

3. **채팅 위젯** 화면에서 **인사이트**를 선택하세요.
4. 현재 선택된 위젯과 날짜 기준의 분석이 담긴 **채팅 위젯 분석** 대시보드가 열려요.

   ![채팅 위젯 분석 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083635324/original/9kNYiaCD_59Ydt2KhY0_zjFfER55Wdyh5A.png?1792403164)

### 3단계: 분석 기간 선택하기

5. 오른쪽 위에 있는 **date-range picker**(날짜 범위 선택기)를 선택하세요.
6. 분석할 기간을 고르세요.

   ![날짜 범위 선택기에서 분석 기간을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083635412/original/dtMm6DdJxtWturBLMXp0krbImsQT47DC7g.png?1792403216)

### 4단계: 위젯 필터 적용하기

7. 날짜 범위 선택기 옆의 **모든 위젯** 드롭다운을 선택하세요.
8. 리포트에 포함할 위젯을 고르세요. 여러 개를 선택할 수도 있고, 모든 위젯을 그대로 둘 수도 있어요.

   ![모든 위젯 드롭다운에서 위젯을 고르는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083635658/original/KkBf_r897wlAGtun97K8TErXxHR_7c9OBw.png?1792403276)

선택한 위젯과 날짜 필터는 대시보드 전체의 분석에 적용돼요.

### 5단계: 전환 퍼널과 주요 지표 확인하기

9. **전환 퍼널**에서 **위젯 로드**, **위젯 열림**, **생성된 리드**, **전체 전환율**을 확인하세요.
10. 맨 위의 지표 카드 4개로 **오픈율**, **활성 위젯**, **생성된 리드**, **만족도**를 확인하세요.

    ![전환 퍼널과 주요 지표 카드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083635949/original/aPQDII69yLDeXJT7qUApNCALvHqEsj5RjA.png?1792403442)

### 6단계: 위젯별 성과 비교하기

11. **위젯 성과**까지 스크롤하세요.
12. **Filter widgets by name...**(이름으로 위젯 필터) 입력란에서 원하는 위젯을 찾으세요.
13. 열 제목을 선택하면 해당 지표 기준으로 표가 정렬돼요.
14. **생성된 리드** 열의 숫자처럼 선택할 수 있는 지표 값을 눌러 바탕이 된 기록을 확인하세요.
15. 기록 창을 확인한 뒤, 오른쪽 위의 **X**를 선택해 닫으세요.

### 7단계: 참여도와 고객 감성 살펴보기

16. **참여도**까지 스크롤해 전체 오픈율과 일별 로드·열림 현황을 확인하세요.
17. **일별 로드 및 열림 추이** 차트에서 **누적**, **비교**, **이탈** 중 하나를 선택하면 차트 보기 방식이 바뀌어요.
18. **고객 감성**으로 내려가 **전체 만족도**를 확인하세요.
19. **일별 피드백 추이** 차트에서 **누적**, **비교**, **순 감성** 중 하나를 선택하면 피드백을 다른 방식으로 볼 수 있어요.

## 전환 지표와 핵심 지표 이해하기

전환 퍼널과 맨 위의 지표 카드를 보면 채팅 위젯이 방문자의 활동을 리드로 얼마나 잘 바꾸는지 알 수 있어요. 상호작용이 어디서 시작되고 방문자가 어떻게 이어지는지, 위젯이 만든 전체 결과는 어떤지 함께 보여 줘요.

### 전환 퍼널과 위젯 유형별 리드

전환 퍼널은 방문자의 흐름을 세 단계로 보여 줘요. 이 단계를 비교하면 위젯이 페이지에 나타난 뒤 리드가 생성되기까지 어디에서 참여가 줄어드는지 알 수 있어요.

퍼널은 다음 단계로 이루어져 있어요.

1. **위젯 로드**: 선택한 기간에 채팅 위젯이 로드된 횟수예요.
2. **위젯 열림**: 기록된 위젯 열림 횟수예요.
3. **생성된 리드**: 채팅 위젯 상호작용으로 생긴 리드 수예요.

퍼널에는 단계별로 이어진 비율과 **전체 전환율**이 표시돼요. 예시 화면에서 전환율은 위젯 로드 대비 생성된 리드의 비율이에요.

퍼널 아래의 **위젯 유형별 리드**는 생성된 리드를 리포트에 나타난 위젯 유형별로 나누어 보여 줘요.

예시 화면에는 다음 유형이 있어요.

- **실시간 채팅**: 메시지 전송 또는 문의 폼
- **SMS / 이메일 채팅**: 리드 폼 제출
- **음성 AI**: 웹 콜 또는 사전 통화 폼

이 구분을 보면 채팅 방식별로 전체 리드 생성에 얼마나 기여하는지 비교할 수 있어요.

### 핵심 성과 지표

맨 위의 지표 카드는 선택한 위젯과 기간의 주요 결과를 요약해 줘요. 위젯을 하나씩 열지 않아도 위젯 노출, 참여도, 리드 생성, 고객 피드백을 확인할 수 있어요.

| 지표 | 보여 주는 내용 |
| --- | --- |
| **만족도** | 채팅 위젯 피드백으로 집계한 만족도 비율이에요. |
| **오픈율** | 위젯 로드 중 열림으로 이어진 비율이에요. 위젯 열림 ÷ 위젯 로드로 계산해요. |
| **활성 위젯** | 선택한 기간에 로드가 기록된 위젯이에요. 전체 위젯 수와 함께 표시돼요. |
| **생성된 리드** | 대시보드 설명에 따르면, 포함된 위젯과 채팅 유형 전체에서 확보한 고유 연락처의 합계예요. |

예시 대시보드에서는 **만족도**와 **오픈율** 카드에 작은 추이 차트도 함께 표시돼요. 이 차트로 최근 지표 변화를 짐작할 수 있어요.

## 위젯 성과 비교와 기록 확인

**위젯 성과** 표에서는 채팅 위젯별로 참여도, 리드, 피드백이 어떤지 비교할 수 있어요. 계정에 위젯이 여러 개 있고 결과 차이를 알고 싶을 때 유용해요.

### 위젯 성과 표

표에는 위젯마다 다음 정보가 표시돼요.

| 열 | 설명 |
| --- | --- |
| **위젯** | 채팅 위젯의 이름이에요. |
| **채팅 유형** | 위젯에 연결된 채팅 유형이에요. |
| **로드됨** | 기록된 위젯 로드 수예요. |
| **열림** | 기록된 위젯 열림 수예요. |
| **오픈율** | 위젯 로드 중 열림으로 이어진 비율이에요. |
| **생성된 리드** | 해당 위젯으로 생성된 리드 수예요. |
| **긍정적** | 긍정 피드백 수예요. |
| **부정적** | 부정 피드백 수예요. |
| **만족도** | 해당 위젯의 만족도 결과예요. 데이터가 있을 때만 표시돼요. |

위젯 이름 필터를 쓰면 이름이 맞는 위젯만 표에 남길 수 있어요. 열을 정렬해서 활동과 성과를 비교할 수도 있어요.

결과가 한 페이지를 넘으면 표에서 페이지를 넘겨 볼 수 있어요.

### 바탕이 된 기록 확인하기

**위젯 성과**에서는 보고된 값의 바탕이 된 기록을 자세히 볼 수 있어요. 선택할 수 있는 지표를 누르면 세부 정보 창이 열려요.

예를 들어 **생성된 리드** 값을 선택하면 해당 리드 기록 화면이 열려요.

예시 화면의 리드 기록 창에는 다음 항목이 있어요.

- **연락처 ID**
- **이름**
- **이메일**
- **전화번호**
- **생성일**

표시되는 정보는 보이는 기록에 따라 달라요.

## 채팅 위젯 참여도 분석하기

참여도 분석을 보면 방문자가 위젯을 불러온 뒤 실제로 상호작용하는지 알 수 있어요. 선택한 기간의 열림과 열리지 않음을 비교하면 방문자 행동의 변화를 읽을 수 있어요.

### 참여 개요

**참여 개요**는 도넛 차트로 위젯 상호작용을 요약해요.

다음 항목이 표시돼요.

- **오픈율**: 위젯 로드 중 열림으로 이어진 비율이에요.
- **위젯 열림**: 기록된 위젯 열림 수예요.
- **열리지 않음**: 로드됐지만 열리지 않은 위젯 수예요.

이 차트로 위젯 노출 중 얼마나 많은 비율이 직접적인 상호작용으로 이어지는지 빠르게 볼 수 있어요.

### 일별 로드 및 열림 추이

**일별 로드 및 열림 추이** 차트는 선택한 기간의 위젯 활동을 날짜별로 보여 줘요.

다음 두 항목을 구분해서 표시해요.

- **위젯 열림**
- **열리지 않음**

차트 보기 방식은 세 가지 중에서 바꿀 수 있어요.

- **누적**: 활동 데이터를 쌓아 올린 차트로 함께 보여 줘요.
- **비교**: 데이터를 나란히 놓고 비교해요.
- **이탈**: 차트의 이탈 보기 방식으로 보여 줘요.

## 고객 감성 이해하기

고객 감성 분석은 채팅 위젯으로 수집한 피드백을 모아서 보여 줘요. 이 리포트로 방문자 만족도를 평가하고, 시간에 따른 긍정·부정 피드백의 변화를 파악할 수 있어요.

### 전체 만족도

**전체 만족도** 차트는 만족도 비율과 피드백 구성을 시각적으로 보여 줘요.

다음 두 항목을 구분해서 표시해요.

- **긍정적**: 긍정으로 기록된 피드백이에요.
- **부정적**: 부정으로 기록된 피드백이에요.

도넛 차트는 선택한 조건에서의 전체 만족도 결과를 요약해 줘요.

### 일별 피드백 추이

**일별 피드백 추이** 차트는 긍정·부정 피드백 활동을 시간 순서대로 보여 줘요.

표시 방식은 세 가지 중에서 고를 수 있어요.

- **누적**: 긍정과 부정 피드백을 쌓아 올려 함께 보여 줘요.
- **비교**: 긍정과 부정 피드백을 나란히 비교해요.
- **순 감성**: 차트의 순 감성 보기 방식으로 보여 줘요.

## 자주 묻는 질문

### 채팅 위젯 인사이트와 AI 스튜디오의 채팅 위젯 분석은 같은 건가요?

아니요. 채팅 위젯 인사이트는 **사이트 > 채팅 위젯 > 인사이트**에서 열어요. AI 스튜디오에는 AI 스튜디오 프로젝트에서 쓰는 위젯을 위한 별도의 분석 화면이 있고, **AI 스튜디오 > 더보기 > 분석 > 채팅 위젯**에서 열어요. AI 스튜디오에 위젯을 추가하는 방법은 [AI 스튜디오에서 채팅 위젯 추가하기](../13-AI-Employee/how-to-add-chat-widgets-in-ai-studio.md)를 참고하세요.

### 채팅 위젯 인사이트는 Google Analytics 4 트래킹과 어떻게 다른가요?

채팅 위젯 인사이트는 위젯 분석을 하이퍼클래스 안에서 바로 보여 줘요. [Google Analytics 4 트래킹](../06-사이트/채팅-위젯/track-chat-widget-activity-using-google-analytics-4-ga4.md)은 별도의 리포트 방식으로, 채팅 위젯 상호작용 이벤트를 GA4에서 확인할 수 있어요.

### 위젯 유형별 구분에서 실시간 채팅은 무슨 뜻인가요?

하이퍼클래스에서 실시간 채팅(Live Chat)은 웹사이트에서 실시간으로 메시지를 주고받는 Web Chat(웹 채팅) 채널의 설정 이름이에요. 인사이트의 위젯 유형별 구분에서도 **실시간 채팅**이라는 이름을 써요.

### 위젯 로드는 있는데 열림이 0으로 나와요. 왜 그런가요?

위젯 로드와 위젯 열림은 서로 다른 활동으로 기록돼요. 방문자가 위젯을 열지 않아도 페이지에서 위젯은 로드될 수 있어요. 그래서 위젯 성과 표에서 **열림**이 0이어도 **로드됨**에는 숫자가 표시될 수 있어요.
