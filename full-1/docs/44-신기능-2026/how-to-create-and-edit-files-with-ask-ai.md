# AI에게 문의로 파일 만들고 수정하기

하이퍼클래스의 **AI에게 문의**(Ask AI)를 쓰면 간단한 요청만으로 문서, 발표 자료, 스프레드시트, 리포트를 만들 수 있어요. 참고 파일을 올리고, 비즈니스 브랜딩을 적용하고, 다른 앱으로 옮겨 가지 않고 수정까지 요청할 수 있어요. 만든 파일은 **미리보기**로 확인하고, 내려받거나 **미디어 저장소**에 저장할 수 있어요. 이 문서에서는 파일을 만들고, 수정하고, 관리하는 방법을 안내해요.

## 파일 생성·수정 기능이란?

파일 생성·수정 기능은 일상적인 말로 요청해서 내려받을 수 있는 파일을 만들거나, 이미 있는 문서를 다루는 기능이에요.

예를 들어 올려 둔 캠페인 데이터로 6장짜리 고객 성과 발표 자료를 만들어 달라고 요청할 수 있어요. AI가 정보를 정리하고, 차트를 만들고, 쓸 수 있는 브랜드 보드 설정을 적용해요.

그다음 발표 자료를 확인하고, 수정을 요청하고, 완성된 파일을 내려받으면 돼요.

{% hint style="info" %}
내려받을 수 있는 파일은 채팅 창에 바로 표시되는 표나 다이어그램 같은 구조화된 응답과 달라요.
{% endhint %}

## AI에게 문의로 파일을 만들 때 좋은 점

**AI에게 문의**는 내용 작성, 디자인, 수정을 한 흐름에서 처리해 줘요. 비즈니스 파일을 더 간단하게 만들 수 있어요.

- 다양한 형식: PDF, Word 문서, PowerPoint 발표 자료, Excel 통합 문서를 만들 수 있어요.
- 일관된 브랜드: 쓸 수 있는 브랜드 보드의 색상, 글꼴, 로고를 사용해요.
- 파일 분석: 문서나 데이터를 올리면 요약하고 분석해 줘요.
- 조사 지원: 조사한 내용을 만들어 주고, 가능한 경우 출처도 함께 보여 줘요.
- 자동 검토: 파일을 만드는 중에 생성된 페이지와 레이아웃을 확인해요.
- 쉬운 수정: 채팅으로 요청하거나, 지원되는 미리보기에서 영역을 골라 수정을 요청할 수 있어요.
- 파일 관리: 파일을 미리 보고, 내려받거나, **미디어 저장소**에 저장할 수 있어요.
- **반복 작업**: 같은 파일 생성 요청을 반복해야 할 때 지원되는 **Scheduled Tasks**(예약 작업)를 쓸 수 있어요.

## 파일 만들고 수정하는 방법

요청을 구체적으로 쓰고 관련 자료를 함께 주면 원하는 대로 파일이 만들어질 가능성이 높아져요.

### 1단계: AI에게 문의 열기

1. 하이퍼클래스에서 **AI에게 문의**를 엽니다.
2. **새 대화 시작**을 선택해요.

### 2단계: 파일 요청하기

1. 만들고 싶은 파일을 설명해요.
2. 형식, 주제, 대상 독자를 알려 주세요.
3. 꼭 넣어야 할 내용이나 디자인 요구 사항이 있으면 적어요.
4. 요청을 제출해요.

예시 프롬프트:

![예시 프롬프트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084224494/original/y73xsY88az5xoAMKyzfGYHh2GAyFQqNrwQ.png?1793026368)

### 3단계: 참고 파일 올리기

1. 지원되는 문서나 데이터 파일을 첨부해요.
2. 첨부한 파일을 어떻게 쓸지 설명해요.
3. 필요한 분석이 있으면 요청해요.

예를 들어 캠페인 CSV 파일을 올리고, 발표 자료에 넣을 성과 지표를 계산해 달라고 요청할 수 있어요.

### 4단계: 브랜딩과 파일 세부 사항 확인하기

1. AI가 묻는 질문을 확인해요.
2. 형식과 내용 요구 사항을 확인해 주세요.
3. 브랜딩 정보를 물어보면 알려 주세요.
4. 파일 생성을 계속 진행해요.

![브랜딩과 파일 세부 사항을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084227632/original/ewF5lZlg0HIsJtuKINJHjD_0-B_xcyqzaw.png?1793027654)

### 5단계: 생성된 파일 확인하기

1. 생성된 파일 카드를 엽니다.
2. **미리보기**를 클릭해요.
3. 내용, 레이아웃, 시각 자료를 살펴보세요.
4. 중요한 정보와 계산이 맞는지 확인해요.

### 6단계: 수정 요청하기

1. 바꾸고 싶은 내용을 **AI에게 문의**에 설명해요.
2. 지원되는 경우 미리보기에서 영역을 선택해요.
3. 수정 요청을 입력해요.
4. 업데이트된 파일을 확인해 주세요.

### 7단계: 파일 내려받기 또는 저장하기

1. 완성된 파일 카드를 엽니다.
2. **다운로드**를 클릭하면 파일이 내 기기에 저장돼요.
3. 또는 **미디어 저장소에 저장**을 클릭해요.
4. 저장 확인 창이 나타나면 확인해 주세요.

![파일 카드에서 다운로드와 저장을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084227854/original/QuUrzQtjKGEywQ7tZQCwJ9EWqxJnTAnMjA.png?1793027764)

## 지원하는 파일 형식

**AI에게 문의**에서는 자주 쓰는 비즈니스 파일을 만들 수 있고, 올린 파일도 활용할 수 있어요. 형식에 따라 할 수 있는 작업은 달라질 수 있어요.

| 파일 형식 | 주로 쓰는 용도 |
| --- | --- |
| PDF | 리포트, 공유용 문서 |
| Word | 편집할 수 있는 문서, 제안서 |
| PowerPoint | 발표 자료, 피치덱 |
| Excel | 예산표, 데이터 통합 문서 |
| 이미지 | 시각 참고 자료 |
| CSV | 표 형식 데이터 |
| Markdown | 구조화된 텍스트 |
| 텍스트 | 메모, 참고 자료 |
| JSON | 구조화된 데이터 |

{% hint style="warning" %}
지원되는 업로드, 생성, 수정 작업은 달라질 수 있어요. 모든 형식에서 모든 작업을 할 수 있는 것은 아니에요.
{% endhint %}

## 브랜드가 반영된 파일 만들기

**AI에게 문의**는 쓸 수 있는 브랜드 보드 설정을 사용해서, 생성된 파일이 내 비즈니스의 이미지와 어울리도록 도와줘요.

출시 안내에 소개된 브랜딩 정보는 다음과 같아요.

- 브랜드 색상
- 글꼴
- 로고
- 차트와 다이어그램의 시각 스타일

파일을 만들기 전에 AI가 선호하는 브랜드 색상 같은 추가 정보를 물어볼 수 있어요.

![브랜드 색상을 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084228070/original/ngapoJykHFB-fhJgX9_P69eqzf3o5NMhtQ.png?1793027825)

브랜드 보드를 설정하는 방법은 [브랜드 보드 만들기](../10-마케팅/how-to-create-a-brand-board.md)를 참고하세요.

## 올린 파일 활용하기

올린 문서와 데이터는 AI가 파일을 새로 만들거나 업데이트할 때 참고하는 정보가 돼요.

지원되는 형식이라면 다음 작업을 요청할 수 있어요.

- 문서 요약
- 올린 파일 안에서 정보 검색
- CSV 또는 스프레드시트 데이터 분석
- 기존 정보를 바탕으로 리포트 작성
- 올린 내용을 바탕으로 수정본 준비

예를 들어 캠페인 CSV 파일을 올리고, 결과를 요약한 발표 자료를 만들어 달라고 요청할 수 있어요.

{% hint style="warning" %}
민감한 파일은 올리기 전에 내용을 확인하세요. 그 정보를 사용할 권한이 있는지도 확인해 주세요.
{% endhint %}

## 생성된 파일 검토하기

AI는 파일 생성을 계획, 작성, 제작, 검토 같은 단계로 나눠 진행할 수 있어요.

출시 안내에는 파일을 전달하기 전에 생성된 페이지를 확인하는 자동 검토 과정이 소개되어 있어요.

![생성된 파일을 검토하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084228145/original/sSm95ds1Qb2frGrIsKSW5GG-3_qVqQnjgA.png?1793027873)

필요한 경우 생성된 파일에 차트, 다이어그램, 수식, 출처 링크가 들어갈 수 있어요.

{% hint style="warning" %}
파일을 공유하기 전에 중요한 사실, 계산, 수식, 인용, 서식을 직접 확인하세요. 자동 검토가 완전한 정확성을 보장하지는 않아요.
{% endhint %}

## 파일 수정하고 버전 관리하기

생성된 파일을 처음부터 다시 만들지 않고도 수정을 요청할 수 있어요.

#### 채팅으로 수정하기

원하는 변경 사항을 설명해 주세요. 예를 들면 다음과 같아요.

- 도입부를 짧게 줄여 줘.
- 발표 자료의 제목을 바꿔 줘.
- 차트 데이터를 교체해 줘.
- 서식을 조정해 줘.

#### 선택한 영역 수정하기

지원되는 미리보기에서는 파일의 일부를 선택하고 바꾸고 싶은 내용을 설명할 수 있어요.

예를 들어 발표 자료의 제목을 선택하고 더 짧게 바꿔 달라고 요청할 수 있어요.

## 파일 미리 보기, 내려받기, 저장하기

생성된 파일 카드에서 완성된 파일을 열고 관리할 수 있어요.

사용할 수 있는 작업은 다음과 같아요.

- **미리보기**: 생성된 파일을 확인해요.
- **다운로드**: 내 기기에 파일 사본을 저장해요.
- **미디어 저장소에 저장**: 하이퍼클래스에 파일을 저장해요.

![생성된 파일 카드의 작업 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084228432/original/rlIK4WOarHwWDKfMxGUbUfNogNoCqCB-uw.png?1793027945)

자세한 내용은 [AI에게 문의로 미디어 저장소 열고 관리하기](../13-AI-Employee/Ask-AI/how-to-access-and-manage-media-storage-using-ask-ai.md)를 참고하세요.

## 반복 파일을 위한 Scheduled Tasks 사용하기

**Scheduled Tasks**(예약 작업)를 쓰면 월간 비즈니스 리포트 준비처럼 반복되는 **AI에게 문의** 요청을 자동화할 수 있어요.

예를 들어 쓸 수 있는 정보를 바탕으로 월간 성과 요약을 만드는 프롬프트를 예약할 수 있어요.

**Scheduled Tasks**는 반복 프롬프트와 작업 실행 기록을 지원해요.

{% hint style="info" %}
예약한 워크플로우에서 파일 생성이 지원되는지 확인하세요. 파일이 자동으로 전달되거나 **미디어 저장소**에 자동으로 저장된다고 생각하면 안 돼요.
{% endhint %}

설정 방법은 [AI에게 문의에서 Scheduled Tasks로 프롬프트 자동화하기](../13-AI-Employee/Ask-AI/how-to-use-scheduled-tasks-in-ask-ai-to-automate-prompts.md)를 참고하세요.

## 자주 묻는 질문

### AI에게 문의로 어떤 파일을 만들 수 있나요?
출시 안내에는 PDF, Word, PowerPoint, Excel 파일 생성이 소개되어 있어요. 그 밖의 지원 파일 유형은 분석이나 관련 작업에 쓸 수 있어요.

### 이미 있는 문서를 올릴 수 있나요?
네. 지원되는 업로드 파일을 요약, 분석, 새 콘텐츠 준비에 사용할 수 있어요.

### 내 브랜드 보드를 적용할 수 있나요?
네. 색상, 글꼴, 로고를 포함해 쓸 수 있는 브랜딩 정보를 사용할 수 있어요. 추가 확인이 필요할 수 있어요.

### 리포트에 들어갈 내용을 AI가 조사해 줄 수도 있나요?
네. 출시 안내에는 클릭할 수 있는 출처 링크가 포함된 조사 콘텐츠가 소개되어 있어요. 파일을 공유하기 전에 중요한 주장과 출처를 확인하세요.

### 수식이 들어간 스프레드시트도 만들 수 있나요?
출시 안내에는 수정할 수 있는 수식이 포함된 Excel 통합 문서 생성이 소개되어 있어요. 중요한 계산은 직접 확인한 뒤에 사용하세요.

### 파일을 만든 뒤에도 수정할 수 있나요?
네. 채팅으로 변경을 요청하거나, 지원되는 미리보기에서 영역을 선택해 요청할 수 있어요.

### 이전 버전의 파일을 열어 볼 수 있나요?
출시 안내에는 버전별 수정이 소개되어 있어요. 이전 버전을 여는 정확한 방법은 아직 확인이 필요해요.

### 생성된 파일은 어디에 저장할 수 있나요?
파일 카드에서 파일을 내려받거나 **미디어 저장소에 저장**을 선택하세요.

### 반복 리포트도 만들 수 있나요?
**Scheduled Tasks**는 반복되는 **AI에게 문의** 프롬프트를 지원해요. 내 워크플로우에서 쓸 수 있는 파일 생성 및 전달 옵션은 직접 확인하세요.

### AI가 만든 파일은 정확하다고 보장되나요?
아니요. AI가 자동 검토를 하지만, 중요한 사실, 계산, 서식은 직접 확인해야 해요.
