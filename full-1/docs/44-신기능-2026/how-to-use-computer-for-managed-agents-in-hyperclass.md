# 관리형 에이전트에서 컴퓨터 사용하기

하이퍼클래스 **관리형 에이전트**(Managed Agents)에서 컴퓨터 기능을 쓰면 AI 에이전트가 웹사이트를 둘러보고, 파일을 만들어 관리하고, 스크립트를 실행할 수 있어요. 기존 CRM 자동화로는 어려웠던 작업까지 맡길 수 있어요.

에이전트는 정보를 조사하고, 웹 애플리케이션을 다루고, 업무 문서를 만들고, 여러 단계로 이어지는 작업을 대화 하나로 처리해요. 승인 설정, 안전한 웹사이트 로그인, 공유 작업 공간이 있어서 민감한 작업은 직접 통제하면서 에이전트의 활동을 관리할 수 있어요.

## 컴퓨터 기능이란?

컴퓨터는 하이퍼클래스 관리형 에이전트의 기능 중 하나예요. AI 에이전트가 웹사이트, 파일, 스크립트를 다룰 수 있는 컴퓨터 환경을 쓸 수 있게 해 줘요. 기본 제공되는 CRM 작업이나 연결된 앱에만 의존하지 않고, 브라우저 화면을 직접 다루고 작업 공간 도구를 써서 일을 끝낼 수 있어요.

예를 들어 관리형 에이전트가 경쟁사 웹사이트를 둘러보며 상품 가격을 모으고, 상품을 비교해 결과를 정리한 보고서를 만들 수 있어요. 웹 애플리케이션 안에서 이동하고 폼을 작성하는 등 여러 단계가 필요한 업무도 도와줘요.

컴퓨터에는 주요 도구가 세 가지 있어요.

- **브라우저**: 웹사이트를 열고, 페이지를 이동하고, 버튼을 클릭하고, 폼을 작성하고, 웹 애플리케이션을 다뤄요.
- **파일**: 컴퓨터 작업 공간 안에서 파일을 만들고, 읽고, 편집하고, 내보내요.
- **터미널**: 데이터 처리, 계산 같은 고급 작업을 위해 명령어와 스크립트를 실행해요.

이 밖에도 안전한 웹사이트 로그인, 승인 설정, 활동 모니터링 기능이 있어요.

{% hint style="warning" %}
중요: 컴퓨터는 현재 채팅과 수동 실행에서만 쓸 수 있어요. 트리거로 시작되는 실행에서는 컴퓨터 기능을 지원하지 않아요.
{% endhint %}

## 브라우저, 파일, 터미널 기능

컴퓨터의 도구 세 가지는 각각 따로 설정할 수 있어요. 도구별로 할 수 있는 일을 알아 두면 에이전트에 꼭 필요한 기능만 켤 수 있어요.

### 1. 브라우저

**브라우저** 도구를 쓰면 관리형 에이전트가 브라우저 화면으로 웹사이트를 다뤄요. 원래 사람이 직접 해야 했던 페이지 이동, 정보 입력 같은 웹 작업을 에이전트가 처리해요.

할 수 있는 작업은 다음과 같아요.

- 웹사이트를 열고 이동하기
- 웹사이트 내용을 읽고 조사하기
- 버튼을 클릭하고 페이지 요소 다루기
- 정보를 입력하고 폼 작성하기
- 로그인에 성공한 뒤 인증이 필요한 웹사이트 이동하기
- 웹 애플리케이션을 넘나들며 여러 단계로 이루어진 작업 마치기

브라우저 활동은 지켜볼 수 있고, 직접 조작해야 할 때는 제어권을 가져올 수 있어요.

예를 들어 이렇게 요청할 수 있어요. *"경쟁사 웹사이트 세 곳을 방문해서 상품 가격을 비교하고 차이점을 요약해 줘."*

그러면 에이전트가 웹사이트를 돌아다니며 확인되는 정보를 모으고 비교표를 준비해요.

**![브라우저 도구 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084067723/original/i40EXEU1fpZyTh0iHpd3QChOzComqlHzFg.png?1792761520)**

### 2. 파일

**파일** 도구를 쓰면 관리형 에이전트가 서브 계정의 컴퓨터 작업 공간에 있는 파일을 다뤄요. 새 파일을 만들고, 기존 파일을 수정하고, 내려받을 수 있는 결과물을 만들어요.

할 수 있는 작업은 다음과 같아요.

- 보고서와 문서 만들기
- 스프레드시트 같은 업무용 파일 만들기
- 작업 공간 파일 읽기와 수정
- 만든 파일 내보내기
- 작업 공간 파일을 여러 대화에서 다시 쓰기

예를 들어 이렇게 요청할 수 있어요. *"조사한 경쟁사의 가격과 기능을 비교하는 스프레드시트를 만들어 줘."*

그러면 에이전트가 모은 정보를 구조화된 파일로 정리해 줘요.

컴퓨터 작업 공간에 저장된 파일은 에이전트 대화에 바로 첨부한 문서와 달라요. 채팅 첨부파일은 [관리형 에이전트 파일 지원](../13-AI-Employee/Agent-Studio/managed-agents-file-support.md) 문서에서 따로 설명해요.

### 3. 터미널

**터미널** 도구를 쓰면 관리형 에이전트가 컴퓨터 환경 안에서 명령어와 스크립트를 실행해요. 계산이나 데이터 변환처럼 브라우저만으로는 하기 어려운 작업에 유용해요.

할 수 있는 작업은 다음과 같아요.

- Python 스크립트 실행
- 데이터셋 처리와 분석
- 터미널 명령어 실행
- 지원되는 작업에 필요한 패키지 설치
- 처리한 데이터로 보고서 준비

예를 들어 이렇게 요청할 수 있어요. *"이 매출 데이터를 분석해서 월별 매출 성장률을 계산하고 요약 보고서를 만들어 줘."*

그러면 에이전트가 사용할 수 있는 도구로 정보를 처리해서 결과물을 만들어요.

제공된 설정 예시에서는 **터미널**이 기본으로 꺼져 있어요. 에이전트가 코드를 실행해야 할 때 켜면 돼요.

**![터미널 도구 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084067883/original/ZJmaQLtjkvwOrK01arbktyv0t8I8dkgCmg.png?1792761604)**

## 승인과 안전 설정

컴퓨터에는 승인 설정이 있어서 에이전트가 모르는 사이에 민감한 작업을 하지 못하게 막을 수 있어요. **Ask Me Before**(실행 전에 확인 요청) 설정에서 어떤 작업을 하기 전에 내 허락을 받을지 정해요.

### 실행 전 승인 요청 설정

다음 작업에 대해 승인이 필요하도록 설정할 수 있어요.

- **폼 제출**
- **결제 또는 구매**
- **Sending emails or messages**(이메일 또는 메시지 보내기)
- **게시 또는 라이브 전환**
- **파일 또는 레코드 삭제**
- **파일 다운로드**
- **Visiting a new website**(새 웹사이트 방문)

이 설정은 관리형 에이전트마다 따로 해요.

결제와 삭제는 항상 승인이 필요해요. 나머지 작업은 확인을 요청하도록 설정할 수 있고, 지원되는 경우에는 현재 채팅에 한해 허용할 수도 있어요.

예를 들어 에이전트가 새 웹사이트를 열어야 할 때는 이동할 주소가 표시된 승인 요청이 나타날 수 있어요. 요청을 확인하고 에이전트가 계속 진행해도 되는지 결정하세요.

### 대화 중 작업 승인하기

에이전트가 승인이 필요한 작업을 만나면 작업을 멈추고 요청을 보여 줘요.

요청에 응답하는 방법은 다음과 같아요.

1. 요청된 작업과 이동할 주소 또는 영향을 받는 대상을 확인하세요.
2. 맡긴 작업과 맞는 요청인지 확인하세요.
3. 에이전트가 계속하도록 승인하거나, 거절하세요.
4. 현재 채팅에서 이 작업을 허용하는 옵션이 보이면, 안내된 범위 안에서 그 허용을 적용하고 싶을 때만 선택하세요.

예를 들어 웹사이트를 조사하는 에이전트가 해당 주소를 열기 전에 허락을 요청할 수 있어요.

**![에이전트의 승인 요청 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084068487/original/jrCDnStmJuEYHJD49Q_IDu6J0m52YXbX_w.png?1792761902)**

### 데이터 보호

컴퓨터에는 작업 공간에서 접근한 정보를 보호하는 안전장치가 있어요.

에이전트가 작업 공간의 데이터에 접근한 뒤 그 정보를 컴퓨터 환경 밖으로 옮기려 하면, 추가 승인이 필요할 수 있어요. 민감할 수 있는 데이터가 사용자 허락 없이 외부로 공유되지 않도록 하기 위해서예요.

{% hint style="warning" %}
중요: 민감한 작업은 승인하기 전에 이동할 주소와 내용을 확인하세요. 특히 에이전트가 외부 웹사이트나 애플리케이션으로 정보를 보내는 경우에 신경 써 주세요.
{% endhint %}

## 안전한 웹사이트 로그인

브라우저 작업 중에는 아이디와 비밀번호로 보호된 웹사이트에 들어가야 할 때가 있어요. 컴퓨터는 안전한 웹사이트 로그인을 지원해서, 대화에 비밀번호를 적지 않고도 에이전트가 로그인이 필요한 작업을 이어갈 수 있어요.

에이전트가 로그인이 필요한 곳을 만나면 안전한 폼으로 인증 정보를 요청해요.

### 안전한 웹사이트 로그인 순서

1. 에이전트가 인증이 필요한 웹사이트로 이동해요.
2. 에이전트가 로그인이 필요하다는 것을 알아봐요.
3. 대화 또는 **Computer Panel**(컴퓨터 패널)에 로그인 요청이 나타나요.
4. **로그인 추가**를 선택해 안전한 인증 정보 입력 폼을 여세요.
5. 안전한 폼에 웹사이트 인증 정보를 입력하세요.
6. 인증 정보를 제출하세요.
7. 인증에 성공하면 에이전트가 요청받은 작업을 이어가요.

인증 정보는 채팅으로 보내지 않고 안전한 로그인 방식으로 처리돼요. 릴리스 문서에 따르면 비밀번호는 보호되며 에이전트에게 노출되지 않아요.

저장한 로그인 정보는 같은 웹사이트에 접근해야 하는 이후 작업에서 다시 쓸 수 있어요.

**![안전한 로그인 정보 입력 폼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084068375/original/1SKFtFBql1dBJMgbliW_Q_N9v272b41lKg.png?1792761882)**

### 잘못되었거나 만료된 인증 정보 처리하기

저장해 둔 인증 정보가 더 이상 맞지 않으면 에이전트가 로그인 오류를 만나 새 인증 정보를 요청할 수 있어요.

해결 방법은 다음과 같아요.

1. 해당 관리형 에이전트 대화를 여세요.
2. 로그인 요청을 찾으세요.
3. 로그인 정보를 업데이트하거나 입력할 수 있는 옵션을 선택하세요.
4. 안전한 폼에 올바른 인증 정보를 입력하세요.
5. 정보를 제출하고 에이전트가 인증을 다시 시도하게 하세요.

웹사이트 비밀번호를 대화에 직접 보내지 마세요.

## Computer Panel과 Waiting on You

**Computer Panel**(컴퓨터 패널)에서는 컴퓨터 활동을 볼 수 있고, **Waiting on You**(내 응답 대기 중)를 통해 내가 직접 처리해야 하는 요청을 쉽게 찾을 수 있어요. 진행 중인 작업을 확인하고, 막혀 있는 작업을 대화 기록 전체를 뒤지지 않고 해결할 수 있어요.

### Computer Panel

**Computer Panel**은 관리형 에이전트 대화 화면 위쪽의 **컴퓨터** 버튼으로 열어요.

패널에서는 다음 정보를 볼 수 있어요.

- **Computer Status**(컴퓨터 상태): 컴퓨터가 활성 상태인지 비활성 상태인지 보여 줘요.
- **Waiting on You**: 내 승인이나 입력이 필요한 요청이에요.
- **Recent Pages**(최근 페이지): 컴퓨터가 최근에 접속한 웹사이트예요.
- **Allowed in This Chat**(이 채팅에서 허용됨): 현재 채팅에서 허용한 웹사이트 권한이에요.

패널에서는 컴퓨터와 관련된 활동과 설정에도 접근할 수 있어요.

**![컴퓨터 패널 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084069054/original/kbXq0k5RkWfcag5JCFZ8pXrEgG6ZKoocPg.png?1792762159)**

### Waiting on You

**Waiting on You**에서는 내가 참여해야만 진행되는 에이전트의 요청을 찾을 수 있어요.

주로 이런 요청이 있어요.

- 민감한 작업 승인
- 웹사이트 로그인 정보 입력
- 웹사이트 접근 허용
- 그 밖에 사용자 확인이 필요한 응답

처리 대기 중인 작업은 해당 에이전트 화면과 **Computer Panel**에서 볼 수 있어요.

요청을 처리하는 방법은 다음과 같아요.

1. 처리 대기 중인 작업이 있는 관리형 에이전트를 여세요.
2. 에이전트 상세 패널이나 **Computer Panel**에서 **Waiting on You**를 찾으세요.
3. 확인이 필요한 요청을 선택하세요.
4. 요청된 작업이나 정보를 확인하세요.
5. 필요한 입력이나 승인을 해 주세요.
6. 대화로 돌아가 에이전트의 진행 상황을 확인하세요.

예를 들어 에이전트가 LinkedIn 인증이 필요할 때는 **Waiting on You**에 **로그인 추가** 작업이 포함된 로그인 요청이 표시돼요.

### 브라우저 제어권 가져오기

직접 입력하거나 개입해야 하는 작업이면 브라우저 조작을 넘겨받을 수 있어요.

대화에 브라우저 활동이 표시되어 있을 때 다음과 같이 하세요.

1. **브라우저 활동** 카드를 찾으세요.
2. **제어권 가져오기**를 선택하세요.
3. 필요한 브라우저 조작을 마치세요.
4. 화면에 표시되는 제어 버튼으로 제어권을 에이전트에게 돌려주면 에이전트가 이어서 작업해요.

웹사이트에서 사용자가 직접 조작해야 하거나, 진행하기 전에 페이지를 먼저 확인하고 싶을 때 유용해요.

## 공유 컴퓨터 작업 공간과 사용 범위

컴퓨터는 서브 계정 단위의 공유 환경을 써요. 이 작업 공간이 어떻게 동작하는지 알아 두면 파일, 에이전트 접근, 실행 방식을 관리하기 쉬워요.

### 서브 계정의 공유 컴퓨터

서브 계정마다 컴퓨터가 하나 있고, 그 서브 계정의 관리형 에이전트들이 함께 써요.

이는 다음을 뜻해요.

- 같은 서브 계정의 관리형 에이전트는 같은 컴퓨터 환경을 써요.
- 작업 공간 파일은 대화가 바뀌어도 그대로 남아 있을 수 있어요.
- 컴퓨터는 다른 서브 계정과 분리되어 있어요.
- 한 서브 계정의 컴퓨터 환경에 접근할 수 있어도 다른 서브 계정의 환경에는 접근할 수 없어요.

에이전트마다 설정된 기능과 승인 설정은 각자 유지돼요.

### 유지되는 작업 공간과 자동 절전

컴퓨터는 쓰지 않으면 자동으로 절전 상태가 되고, 필요할 때 다시 시작돼요.

절전 상태가 되어도 작업 공간 파일은 보존돼요. 그래서 이후 대화에서도 에이전트가 이전에 만든 파일로 계속 작업할 수 있어요.

예를 들어 에이전트가 한 대화에서 경쟁사 조사 문서를 만들고, 나중에 다른 작업에서 그 파일을 다시 쓸 수 있어요.

### 지원되는 실행 방식

컴퓨터는 현재 다음 방식을 지원해요.

- 관리형 에이전트와의 직접 채팅 대화
- 수동 에이전트 실행
- 에이전트 테스트 화면에서의 테스트

워크플로우 트리거로 시작되는 실행을 포함해, 트리거 기반 실행에서는 컴퓨터를 아직 지원하지 않아요.

관리형 에이전트의 다른 기능은 컴퓨터와 별개로 자동 트리거를 지원할 수 있어요.

## 관리형 에이전트에서 컴퓨터 설정하기

컴퓨터를 제대로 설정하면 관리형 에이전트가 필요한 도구를 쓰면서, 민감한 작업은 적절히 승인받도록 관리할 수 있어요. 아래 순서대로 컴퓨터를 켜고, 도구를 설정하고, 작업을 테스트하고, 확인이 필요한 요청을 처리해 보세요.

### 1단계: 에이전트 스튜디오 열기

1. 하이퍼클래스 서브 계정에 로그인하세요.
2. **AI 에이전트**로 이동하세요.
3. **에이전트 스튜디오**를 선택하세요.
4. **관리형 에이전트** 탭을 여세요.
5. 기존 관리형 에이전트를 선택하거나 새로 만드세요.

에이전트를 만드는 방법이 궁금하면 [에이전트 스튜디오에서 관리형 에이전트 설정하고 사용하기](../13-AI-Employee/Agent-Studio/setup-and-use-managed-agents-in-agent-studio.md)를 참고하세요.

**![에이전트 스튜디오의 관리형 에이전트 탭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084069309/original/_bVAf_yywhauPRGjl2JKApAGvvt5nvgh_Q.png?1792762314)**

### 2단계: 컴퓨터 켜기

1. 설정할 관리형 에이전트를 여세요.
2. 에이전트 설정 패널에서 **기능**을 찾으세요.
3. **컴퓨터 (신규)** 를 찾으세요.
4. **컴퓨터** 토글을 켜세요.

컴퓨터를 켜면 아래에 추가 설정 옵션이 나타나요.

**![기능에서 컴퓨터 토글을 켠 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084069480/original/O58XlMo4pjciQjc8VAVX6BH4BFmLL7PfGA.png?1792762421)**

### 3단계: 컴퓨터 도구 선택하기

**What This Agent May Use**(이 에이전트가 사용할 수 있는 도구)에서 에이전트가 쓸 수 있는 컴퓨터 도구를 설정해요.

1. 에이전트가 웹사이트를 이동하거나, 페이지를 조작하거나, 폼을 작성해야 하면 **브라우저**를 켜세요.
2. 에이전트가 작업 공간 파일을 만들고, 읽고, 수정해야 하면 **파일**을 켜세요.
3. 에이전트가 스크립트나 터미널 명령어를 실행해야 하면 **터미널**을 켜세요.

에이전트 작업에 꼭 필요한 도구만 켜세요.

예를 들어 경쟁사 가격을 조사하고 비교 문서를 만드는 에이전트라면 **브라우저**와 **파일**만 있으면 되고, **터미널**은 필요 없을 수 있어요.

**![컴퓨터 도구 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084069557/original/MXsAUAquzVQRJzXI31dTUCSWfi47UvUOaQ.png?1792762470)**

### 4단계: 실행 전 승인 요청 설정하기

1. 컴퓨터 아래에서 **Ask Me Before** 설정을 찾으세요.
2. 승인이 필요한 작업 목록을 확인하세요.
3. 에이전트의 역할에 맞게 승인 요구 사항을 설정하세요.
4. 실행 전에 검토해야 하는 작업은 추가 승인 요구 사항을 켜 둔 채로 유지하세요.

설정할 수 있는 항목은 다음과 같아요.

- **폼 제출**
- **결제 또는 구매**
- **Sending emails or messages**
- **게시 또는 라이브 전환**
- **파일 또는 레코드 삭제**
- **파일 다운로드**
- **Visiting a new website**

결제와 삭제는 항상 승인이 필요해요.

### 5단계: 에이전트 테스트하기

컴퓨터 설정을 마친 뒤에는 다음과 같이 하세요.

1. **에이전트 테스트**를 선택하거나, 에이전트의 채팅 화면을 여세요.
2. 켜 둔 컴퓨터 도구를 하나 이상 써야 하는 작업을 입력하세요.
3. 지시를 보내세요.
4. 대화에서 에이전트의 활동을 지켜보세요.

예를 들어 이렇게 입력해 보세요.

*"경쟁 상품 세 가지의 가격을 조사하고 기능을 비교해서, 결과를 요약한 스프레드시트를 만들어 줘."*

에이전트는 사용할 수 있는 도구와 권한에 따라 웹사이트를 열고, 정보를 모으고, 파일을 만들어요.

**![에이전트 테스트 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084069834/original/yg4F9GO1-_a_GhmMgvNpdWJdx_JSmCgyUw.png?1792762573)**

### 6단계: 승인 요청 확인하고 응답하기

에이전트가 승인을 요청하면 다음과 같이 하세요.

1. 대화에서 요청을 확인하세요.
2. 필요하면 **Waiting on You**를 여세요.
3. 요청된 작업이 적절한지 확인하세요.
4. 요청을 승인하거나 거절하세요.
5. 인증이 필요하면 **로그인 추가**를 선택하고 안전한 폼에 인증 정보를 입력하세요.

필요한 승인이나 입력을 마치면 에이전트가 작업을 이어가요.

**![승인 요청에 응답하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084069877/original/U_7l6y_5vecyu_FZfRsp9i6V5AVgsU2i5Q.png?1792762612)**

### 7단계: 결과 검토하고 에이전트 게시하기

에이전트가 작업을 마친 뒤에는 다음과 같이 하세요.

1. 에이전트의 답변을 확인하세요.
2. 에이전트가 만든 문서, 스프레드시트, 보고서를 살펴보세요.
3. 업무 판단에 쓰기 전에 중요한 정보는 사실인지 확인하세요.
4. 추가 맥락이 필요하면 브라우저 활동이나 작업 기록을 확인하세요.
5. 결과를 다듬으려면 후속 지시를 보내세요.
6. 에이전트가 아직 게시되지 않았다면 **게시**를 선택하세요.

예를 들어 이렇게 요청할 수 있어요.

*"비교 스프레드시트에 상품 평점을 추가하고, 가격이 가장 낮은 옵션을 강조해 줘."*

에이전트는 사용할 수 있는 컴퓨터 도구와 작업 공간 파일로 작업을 이어가요.

**![결과 검토 후 에이전트를 게시하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084070099/original/p45c-1pc7AO2VLkWWiai1hr5yso78Aif5Q.png?1792762743)**

## 자주 묻는 질문

### 워크플로우 트리거가 실행될 때 컴퓨터가 자동으로 동작하나요?

아니요. 컴퓨터는 현재 채팅과 수동 실행에서만 쓸 수 있어요. 관리형 에이전트가 다른 기능에서는 워크플로우나 이벤트 기반 트리거를 지원할 수 있지만, 트리거 기반 실행에서는 컴퓨터를 쓸 수 없어요.

### 관리형 에이전트 여러 개가 컴퓨터를 같이 쓸 수 있나요?

네. 서브 계정마다 컴퓨터가 하나 있고, 그 서브 계정의 관리형 에이전트들이 함께 써요. 릴리스 문서에는 여러 작업이 동시에 컴퓨터를 쓸 때 어떻게 처리되는지 나와 있지 않아요. 그래서 동시에 작업해도 문제없다고 생각하지는 마세요.

### 에이전트가 웹사이트에 로그인해야 하면 어떻게 되나요?

에이전트가 안전한 로그인을 요청해요. 요청을 열어 보호된 폼에 인증 정보를 입력하면, 인증에 성공한 뒤 에이전트가 작업을 이어가요. 비밀번호는 채팅에 직접 입력하지 마세요.

### 에이전트가 작업 중일 때 브라우저를 직접 조작할 수 있나요?

네. 브라우저 활동이 표시되어 있을 때 **제어권 가져오기**를 선택하면 브라우저를 직접 조작할 수 있어요. 웹사이트를 직접 확인하거나, 사용자가 직접 해야 하는 단계를 처리할 때 유용해요.

### 요청된 작업을 승인하지 않으면 어떻게 되나요?

승인이 필요한 작업을 에이전트가 끝낼 수 없어요. 응답할 때까지 요청이 대기 상태로 남을 수 있고, 그 부분의 작업은 막힐 수 있어요.

### 컴퓨터가 절전 상태가 되면 파일이 사라지나요?

아니요. 컴퓨터가 자동으로 절전 상태가 되어도 작업 공간 파일은 보존돼요. 컴퓨터가 다시 시작되면 그대로 쓸 수 있어요.

### 터미널은 켜지 않고 브라우저만 켤 수 있나요?

네. **브라우저**, **파일**, **터미널**은 각각 따로 설정할 수 있어요. 에이전트 작업에 필요한 도구만 켜세요.

### 에이전트에 Waiting on You가 표시돼요. 왜 그런가요?

**Waiting on You**는 에이전트가 작업을 계속하려면 추가 입력, 인증, 승인이 필요하다는 뜻이에요. 대기 중인 요청을 열어 어떤 내용이 필요한지 확인하세요.

### 컴퓨터의 파일은 관리형 에이전트 대화에 첨부한 파일과 같은 건가요?

아니요. 컴퓨터의 **파일**은 공유 컴퓨터 작업 공간에서 파일을 만들고 관리하는 데 써요. 채팅 파일 지원은 분석을 위해 지원되는 문서와 이미지를 대화에 첨부하는 기능이에요. 두 기능은 목적이 달라요.

### 컴퓨터가 MCP 커넥터를 대신할 수 있나요?

모든 경우에 그렇지는 않아요. 컴퓨터는 에이전트가 브라우저로 웹사이트를 직접 다루게 해 주고, MCP 커넥터는 지원되는 외부 애플리케이션과 연결하기 위해 정해진 도구를 제공해요. 어느 쪽이 나은지는 작업과 사용할 수 있는 연동에 따라 달라요.
