# 연락처 문서를 폴더로 정리하기

연락처 상세 화면의 **문서**를 폴더로 정리하면 중요한 파일을 쉽게 찾고 관리할 수 있어요. 하이퍼클래스에서는 커스텀 폴더 만들기, 폴더 안에 폴더 만들기, 폴더 간 파일 이동, **휴지통**에서 삭제한 항목 복원을 할 수 있어요. 이 문서에서는 연락처 문서를 관리하는 방법과 **시스템 폴더**의 제한 사항을 안내해요.

## 연락처 문서 폴더란?

연락처 문서 폴더를 쓰면 연락처마다 커스텀 폴더와 하위 폴더로 파일을 정리할 수 있어요. 연락처마다 폴더 구조가 따로 있어서, 한 연락처의 문서를 바꿔도 다른 연락처에는 영향이 없어요.

폴더는 두 종류예요.

- **시스템 폴더**: 처음부터 만들어져 있는 폴더예요. **Internal**(내부), **Sent**(보낸 문서), **Received**(받은 문서) 등이 있어요. 이 폴더는 삭제할 수 없고, 안에 있는 파일도 현재는 삭제나 이동이 되지 않아요.
- 커스텀 폴더: 직접 만든 폴더예요. 폴더 안에 폴더를 만들거나, 이동하거나, 삭제할 수 있어요. 커스텀 폴더에 올린 파일도 이동하거나 삭제할 수 있어요.

## 폴더와 하위 폴더 만들기

커스텀 폴더를 만들면 관련 문서를 한곳에 모아 둘 수 있어요. 하위 폴더를 만들면 여러 단계로 파일을 나눠 정리할 수도 있어요.

1. **연락처**로 이동해 연락처를 엽니다.
2. **문서** 패널을 엽니다.
3. **+** 아이콘을 클릭해 폴더를 추가합니다.
4. **폴더 이름**을 입력하고 **섹션**에서 폴더가 만들어질 위치를 확인합니다.
5. **저장**을 클릭합니다.

하위 폴더를 만들려면 상위 폴더를 연 다음 같은 순서로 진행하세요.

## 파일과 폴더 이동하기

파일을 다시 올리지 않고도 문서와 커스텀 폴더를 옮길 수 있어요. 커스텀 폴더는 다른 폴더 단계로도 옮길 수 있어요.

1. 연락처의 **문서** 패널을 엽니다.
2. 옮길 파일이나 커스텀 폴더를 찾습니다.
3. 작업 메뉴를 열고 **이동**을 선택합니다.
4. 옮길 폴더를 선택하고 확인합니다.

이동할 수 있는 파일을 선택한 뒤 선택 도구 모음의 이동 기능을 써도 돼요.

{% hint style="warning" %}
**시스템 폴더** 안의 파일은 현재 이동할 수 없어요.
{% endhint %}

## 파일과 폴더 삭제하기

필요 없는 파일과 커스텀 폴더를 지우면 연락처 문서를 깔끔하게 유지할 수 있어요. 삭제한 항목은 바로 영구 삭제되지 않고 **휴지통**으로 이동해요.

1. 연락처의 **문서** 패널을 엽니다.
2. 삭제할 파일이나 커스텀 폴더를 찾습니다.
3. 작업 메뉴를 열고 **삭제**를 선택합니다.
4. 확인 창이 나타나면 삭제를 확인합니다.

{% hint style="warning" %}
**시스템 폴더**는 삭제할 수 없어요. **시스템 폴더** 안의 파일도 현재는 삭제되지 않도록 보호돼 있어요. 커스텀 폴더를 삭제하면 폴더 안의 내용도 함께 **휴지통**으로 이동해요.
{% endhint %}

## 삭제한 파일과 폴더 복원하기

**휴지통**에서는 삭제한 파일과 커스텀 폴더를 삭제 후 60일 안에 되살릴 수 있어요. 삭제한 폴더를 복원하면 그 안의 하위 폴더와 파일도 함께 복원돼요.

1. 연락처의 **문서** 패널을 엽니다.
2. 패널 아래쪽의 **휴지통**을 클릭합니다.
3. 삭제한 파일이나 폴더를 찾습니다.
4. 항목을 선택하고 **복원**을 클릭합니다.

{% hint style="warning" %}
파일과 폴더는 60일이 지나면 영구 삭제되며 복구할 수 없어요.
{% endhint %}
