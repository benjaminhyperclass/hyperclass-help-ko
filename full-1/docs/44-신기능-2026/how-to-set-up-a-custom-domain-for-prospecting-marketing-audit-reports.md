# 잠재고객 발굴 마케팅 감사 리포트에 사용자 지정 도메인 설정하기

에이전시는 잠재고객 발굴 마케팅 감사 리포트를 공유할 때 기본 도메인 대신 에이전시의 API 도메인을 쓸 수 있어요. 잠재 고객이 공유받은 리포트를 열 때도 에이전시 브랜딩이 일관되게 보여요. 이미 있는 API 도메인을 **잠재고객 발굴**의 리포트 설정에서 고르기만 하면 되고, DNS 설정은 따로 필요 없어요.

## 잠재고객 발굴 리포트에 사용자 지정 도메인 설정하기

리포트 도메인은 에이전시의 화이트라벨 설정에 이미 등록된 API 도메인을 사용해요. 도메인을 선택하면 새로 공유하는 마케팅 감사 리포트부터 에이전시 도메인으로 열려요. 공유 방법은 지금과 같아요.

1. **에이전시 보기 > 실험실**로 이동해 사용자 지정 리포트 도메인 기능을 켜세요.
2. **설정 > 회사 > White Label**(화이트라벨) **> API Domain**(API 도메인)으로 이동해 API 도메인이 설정되어 있는지 확인하세요. 아직 설정하지 않았다면 [API 도메인 설정 가이드](../11-설정/branding-system-generated-links-api-domain.md)를 따라 설정하세요.
3. **에이전시 > 잠재고객 발굴 > 설정 > Report settings**(리포트 설정)로 이동하세요.
4. **Report domain**(리포트 도메인)에서 **사용자 지정 도메인**을 선택하고, 드롭다운에서 설정해 둔 API 도메인을 고르세요. 선택한 내용은 자동으로 저장돼요.
5. 잠재고객 발굴 마케팅 감사 리포트를 열고 기존 공유 옵션으로 공유하세요. 이제부터 새로 공유하는 리포트 링크는 선택한 도메인으로 열려요.

## 사용자 지정 리포트 도메인 참고 사항

**Report domain**(리포트 도메인) 설정은 에이전시 전체에 적용되고, 새로 공유하는 마케팅 감사 리포트에 어떤 도메인을 쓸지 정해요. 도메인을 바꿨을 때 기존 링크가 어떻게 되는지 알아 두면 공유할 때 혼란을 줄일 수 있어요.

- 기본 도메인: 리포트 설정에서 **Default domain**(기본 도메인)을 선택하면 기본 도메인을 계속 쓸 수 있어요.
- 기존 리포트 링크: 도메인을 바꾸기 전에 공유한 링크는 원래 도메인에서 계속 열려요. 새로 공유하는 링크만 선택한 사용자 지정 도메인을 써요.
- 에이전시 전체 설정: 선택한 리포트 도메인은 에이전시 전체에 적용돼요.
- 사용 가능 범위: 사용자 지정 리포트 도메인은 무료와 유료 잠재고객 발굴 모두에서 쓸 수 있어요.
- 기존 API 도메인: 화이트라벨 설정에 API 도메인이 이미 설정되어 있다면 DNS를 따로 설정하지 않아도 돼요.
