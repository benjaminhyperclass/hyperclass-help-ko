# 관리형 에이전트로 후속 조치 예약하기

하이퍼클래스의 관리형 에이전트는 작업을 잠시 멈췄다가 정해 둔 시간에 자동으로 다시 시작할 수 있어요. 이 기능을 쓰면 리마인더 발송, 예약 후속 조치 같은 작업을 에이전트를 직접 다시 켜지 않고도 알맞은 때에 처리할 수 있어요. 이 문서에서는 **에이전트 스튜디오**의 AI 빌더로 예약 후속 조치를 만들고, 테스트하고, 관리하는 방법을 안내해요.

## 관리형 에이전트의 예약 후속 조치란?

예약 후속 조치를 쓰면 관리형 에이전트가 작업을 수행한 뒤 정해진 시간 동안 기다렸다가, 이전 대화 맥락을 그대로 이어서 일할 수 있어요.

예를 들어 고객이 영업 통화를 예약하면 에이전트는 예약 전에 사전 브리핑을 준비하고, 통화 후에 후속 작업을 만들고, 며칠 뒤에 딜이 진행됐는지 확인할 수 있어요. 원하는 내용을 AI 빌더에 설명하면 이런 일정을 만들고 관리할 수 있어요.

{% hint style="info" %}
예약 후속 조치는 예약 트리거와 달라요. 예약 트리거는 정해진 시간에 에이전트를 시작해요. 예약 후속 조치는 이미 시작된 에이전트가 멈췄다가 다시 이어서 일하게 해 줘요.
{% endhint %}

## 후속 조치 일정 이해하기

후속 조치 일정은 관리형 에이전트가 서로 다른 시점에 수행할 작업을 모아 둔 것이에요. 각 단계마다 실행 시점과 지시 내용이 따로 있어요.

작업은 다음 세 가지 방식으로 예약할 수 있어요.

- 지연 후: 예를 들어 에이전트가 시작되고 2시간 뒤에 실행해요.
- 이벤트 전: 예를 들어 예약 1시간 전에 실행해요.
- 이벤트 후: 예를 들어 예약이 끝나고 30분 뒤에 실행해요.

대기 시간은 5분부터 30일까지 정할 수 있어요. 예약된 시간은 서브 계정의 시간대로 표시돼요.

영업 통화 후속 조치 일정은 예를 들어 이렇게 구성할 수 있어요.

1. 통화 1시간 전에 회사 브리핑을 준비해요.
2. 통화 30분 후에 후속 작업을 만들어요.
3. 통화 3일 후에 딜이 진행되지 않았다면 매니저 검토 작업을 만들어요.

## 이벤트에 맞춰 후속 조치 예약하기

이벤트 기반 예약을 쓰면 예약, 웨비나 등 지원되는 이벤트의 시간에 맞춰 작업 시점을 정할 수 있어요. 후속 조치가 이벤트 날짜와 어긋나지 않게 도와줘요.

예를 들어 웨비나 시작 30분 전에 리마인더를 보내고, 웨비나가 끝나고 10분 뒤에 감사 메시지를 보낼 수 있어요.

예약이 변경되면 에이전트가 바뀐 내용을 확인하고, 해당되는 이후 리마인더의 시간을 조정해요. 예약이 취소되면 관련 후속 조치를 건너뛸 수 있어요.

![이벤트 기준 후속 조치 예약](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083662733/original/z6ZDNH88semCE_wR8L_P2mC52ZiOq3Eh0w.png?1792415788)

## 조건과 중단 규칙 추가하기

조건은 예약된 작업을 실행할지 말지를 정해요. 중단 규칙은 남은 후속 조치를 언제 끝낼지 정해요.

예를 들면 이래요.

- 조건: 연락처가 답장하지 않았을 때만 리마인더를 보내요.
- 중단 규칙: 연락처가 예약하면 후속 조치를 멈춰요.

이런 요구 사항은 AI 빌더에 설명하거나 일정 편집기에서 직접 조정할 수 있어요.

## 후속 조치 일정 수정하기

기존 일정은 AI 빌더에 바꿀 내용을 말하거나 일정을 직접 편집해서 수정할 수 있어요.

예를 들어 이렇게 요청할 수 있어요.

- "첫 번째 리마인더를 예약 2시간 전으로 바꿔 줘."
- "리마인더를 이메일 대신 SMS로 보내 줘."
- "웨비나 후속 조치를 금요일로 옮겨 줘."

일정 편집기에서는 작업을 검토하고, 후속 조치를 추가하고, 조건을 바꾸고, 중단 규칙을 관리할 수도 있어요.

{% hint style="warning" %}
수정한 계획을 게시하면 이미 대기 중인 에이전트도 새로 게시한 계획으로 바뀌어요.
{% endhint %}

## 대기 중인 실행 확인하고 취소하기

관리형 에이전트의 **활동**에서는 에이전트 실행 진행 상황을 볼 수 있어요. 다시 시작하기를 기다리는 후속 조치도 여기에 표시돼요.

| 상태 | 의미 |
| --- | --- |
| **대기 중** | 다음 예약 작업까지 에이전트가 멈춰 있어요 |
| **Completed**(완료됨) | 실행이 성공적으로 끝났어요 |
| **Failed**(실패) | 실행을 완료하지 못했어요 |
| **Skipped**(건너뜀) | 예약된 작업이 실행되지 않았어요 |

대기 중인 실행을 확인하거나 취소하려면 다음 순서로 진행하세요.

1. **AI 에이전트 > 에이전트 스튜디오**로 이동하세요.
2. 관리형 에이전트를 여세요.
3. **활동**을 선택하세요.
4. **대기 중**으로 표시된 실행을 찾으세요.
5. 다시 시작될 시간을 확인하거나, 멈추려면 **대기 취소**를 클릭하세요.

![활동에서 대기 중인 실행 확인](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083662825/original/4zWGpmuH8yuVMmo14l2U9j-JiOPO-qHKCQ.png?1792415822)

실행을 열면 각 단계를 하나씩 확인할 수도 있어요.

![실행 단계별 상세 보기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083662913/original/rfD7dCQCBN6Kb0AICVrLi53cDQSrGO7PVg.png?1792415851)

{% hint style="info" %}
관리형 에이전트의 게시를 취소하면 대기 중인 후속 조치 실행이 모두 멈춰요.
{% endhint %}

## 테스트와 요금

테스트를 하면 게시하기 전에 후속 조치 일정을 확인할 수 있어요. 대기와 실행은 요금 방식이 달라요.

테스트

**에이전트 테스트**를 사용하면 예약된 대기 시간을 기다리지 않고 후속 조치 순서를 처음부터 끝까지 실행해 볼 수 있어요.

{% hint style="warning" %}
테스트에서도 실제 메시지가 발송되고 실제 작업이 수행될 수 있어요. 테스트할 때는 항상 본인의 연락처 정보를 사용하세요.
{% endhint %}

요금

- 대기는 10분이든 30일이든 무료예요.
- 에이전트가 다시 시작해서 작업을 수행할 때 해당되는 사용 요금이 발생해요.

자세한 내용은 [AI 상품 요금](../13-AI-Employee/ai-product-pricing-update.md)을 확인하세요.

## 관리형 에이전트에 예약 후속 조치 설정하기

AI 빌더에 작업과 시점을 설명하면 예약 후속 조치를 설정할 수 있어요. 아래 예시는 예약된 영업 통화의 후속 조치 계획을 만드는 과정이에요.

### 1단계: 관리형 에이전트 열기

1. **AI 에이전트 > 에이전트 스튜디오**로 이동하세요.
2. 기존 관리형 에이전트를 열거나 새로 만드세요.
3. 기존 에이전트를 수정하는 경우 **에이전트 편집**을 클릭하세요.

### 2단계: 후속 조치 계획 설명하기

무엇을 언제 해야 하는지 AI 빌더에 알려 주세요.

예를 들면 이렇게 입력해요.

"누군가 영업 통화를 예약하면, 예약 1시간 전에 회사 브리핑을 준비해 줘. 통화가 끝나고 30분 뒤에 후속 작업을 만들어 줘. 3일이 지나도 딜이 진행되지 않았다면 매니저 검토 작업을 만들어 줘. 딜이 고객전환성공이나 고객전환실패가 되면 남은 후속 조치를 멈춰 줘."

AI 빌더가 후속 조치 일정을 만들어 주고, 정보가 더 필요하면 질문할 수도 있어요.

### 3단계: 일정 검토하고 수정하기

게시하기 전에 후속 조치의 시점과 작업이 맞는지 확인하세요.

1. AI 빌더가 만든 타임라인을 검토하세요.
2. 각 단계의 예약 시간을 확인하세요.
3. 조건과 중단 규칙을 검토하세요.
4. 필요하면 AI 빌더에 수정을 요청하세요.
5. 일정 편집기를 사용 중이라면 **변경사항 저장**을 클릭하세요.

![AI 빌더가 만든 일정 검토](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083663063/original/NrvAoVdQg-mjFfwoQabCgxt9x11JayLJLA.png?1792415925)

### 4단계: 일정 테스트하기

1. **에이전트 테스트**를 여세요.
2. 본인의 테스트용 연락처를 사용하세요.
3. 후속 조치 시나리오를 실행하세요.
4. 작업과 결과를 확인하세요.
5. 필요하면 수정하세요.

**에이전트 테스트**는 대기 시간을 건너뛰어요. 몇 시간이나 며칠을 기다리지 않고도 순서를 확인할 수 있어요.

{% hint style="warning" %}
테스트 실행에서도 실제 메시지가 발송될 수 있어요.
{% endhint %}

### 5단계: 관리형 에이전트 게시하기

일정이 맞게 설정되었다면 다음 순서로 진행하세요.

1. 에이전트의 지침과 후속 조치 계획을 다시 검토하세요.
2. 관리형 에이전트를 게시하세요.
3. 게시됨으로 표시되는지 확인하세요.

이후 새로 시작되는 실행은 게시된 일정을 따라요.

### 6단계: 후속 조치 확인하기

1. 관리형 에이전트를 여세요.
2. **활동**을 선택하세요.
3. **대기 중**으로 표시된 실행을 찾으세요.
4. 다시 시작될 예약 시간을 확인하세요.
5. 자세한 내용을 보려면 실행을 열고, 필요하면 **대기 취소**를 선택하세요.

![활동에서 후속 조치 모니터링](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083663390/original/SAq097pUormOCcQymMUwKh3mTude64K5uQ.png?1792416051)

## 자주 묻는 질문

### 관리형 에이전트는 얼마나 오래 기다릴 수 있나요?
대기 한 번에 최소 5분, 최대 30일까지 기다릴 수 있어요.

### 예약을 기준으로 후속 조치를 예약할 수 있나요?
네. 예약이나 지원되는 다른 이벤트의 전후로 작업을 예약할 수 있어요.

### 예약이 변경되면 어떻게 되나요?
에이전트가 바뀐 이벤트 정보를 확인하고, 해당되는 이후 리마인더의 시간을 조정해요.

### 고객이 답장하거나 예약하면 후속 조치를 멈출 수 있나요?
네. 조건과 중단 규칙을 사용하면 불필요한 후속 조치를 막을 수 있어요.

### 게시한 뒤에도 일정을 수정할 수 있나요?
네. 수정한 계획을 게시하면 대기 중인 실행이 새 계획으로 바뀌어요.

### 에이전트 테스트는 예약된 대기 시간을 기다리나요?
아니요. 대기 시간은 건너뛰지만, 실제 작업은 수행될 수 있어요.

### 에이전트가 대기하는 동안에도 요금이 부과되나요?
아니요. 대기는 무료예요. 에이전트가 다시 작업을 시작할 때 해당되는 요금이 발생해요.

### 대기 중인 실행을 취소할 수 있나요?
네. 에이전트의 **활동**을 열고 **대기 취소**를 선택하세요.

### 에이전트의 게시를 취소하면 어떻게 되나요?
대기 중인 후속 조치 실행이 멈춰요.
