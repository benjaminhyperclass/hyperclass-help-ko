# 계산 필드(Calculated Fields) 만들고 확인하기

계산 필드는 CRM에 이미 저장된 정보로 값을 자동 계산해 주는 필드예요. 리드 점수를 관리하거나, 두 날짜 사이의 기간을 구하거나, 다가오는 갱신일까지 남은 시간을 셀 때 쓸 수 있어요. 결과를 직접 고치지 않아도 값이 알아서 갱신돼요.

계산 필드는 웹에서 만들어요. 모바일에서는 **연락처**와 **기회 관리**에서 읽기 전용 값을 볼 수 있어요.

---

## 계산 필드 만들기

1. 하이퍼클래스 서브 계정에서 **설정 > 커스텀 필드**로 이동하세요.
2. **연락처** 또는 **기회**를 선택한 다음 **필드** 탭을 여세요.
3. **필드 만들기**를 클릭하고 **Calculated**(계산형)를 선택하세요.
4. 필드 이름을 입력하고 폴더를 선택하세요.
5. 계산 유형을 선택하세요.

   - **사용자 지정 수식**: 숫자, 텍스트, 날짜, 조건을 사용해 값을 계산해요.
   - **기간 계산**: 두 날짜 사이의 기간을 구해요.
   - **경과 시간**: 어떤 날짜로부터 지난 시간을 계산해요.
   - **남은 시간**: 미래의 특정 날짜까지 남은 시간을 계산해요.
6. 출력 유형을 선택하세요. **Number**(숫자), **Boolean**(참/거짓), **Text**(텍스트), **Date**(날짜), **Date-time**(날짜와 시간) 중에서 고를 수 있어요.
7. 소스 필드를 선택하거나 수식을 입력하세요. 필요하면 숫자 형식도 설정하세요.
8. 샘플 값으로 결과를 **미리보기**한 다음 필드를 **저장**하세요.

---

## 모바일에서 계산 필드 확인하기

먼저 하이퍼클래스 모바일 앱을 **4.25.0 (863) 버전 이상**으로 업데이트하세요.

### 연락처에서 확인하기

1. 모바일 앱을 열고 **연락처**로 이동하세요.
2. 연락처를 선택하고 **상세 정보**를 탭하세요.
3. 계산 필드가 속한 폴더에서 해당 필드를 찾으세요.

### 기회 관리에서 확인하기

1. **기회 관리 > 파이프라인**으로 이동하세요.
2. 기회를 선택하고 **상세 정보**를 여세요.
3. 계산 필드를 찾으세요.

기회 카드에 계산 필드를 표시하려면 다음과 같이 하세요.

1. **기회 관리 > 설정 > Customize Cards**(카드 사용자 지정)로 이동하세요.
2. 표시할 계산 필드를 선택하세요.
3. **저장**을 탭하세요.

*[스크린샷: 모바일 기회 상세 화면에 표시된 계산 필드]*

---

## 계산 값 새로고침하거나 복사하기

- **새로고침**: 필드 옆의 새로고침 아이콘을 탭하면 최신 값을 불러와요.
- **복사**: 계산된 값을 길게 누르면 복사할 수 있어요.

계산 필드의 값은 직접 수정할 수 없어서 필드에 자물쇠 아이콘이 표시돼요.

---

## 알아 두세요

- 계산 필드는 웹에서 만들고 설정해요.
- 소스 필드가 바뀌면 값이 자동으로 다시 계산돼요.
- 계산된 값은 가져오기나 워크플로우로도 직접 수정하거나 덮어쓸 수 없어요.
- 날짜와 시간 계산에는 서브 계정의 시간대가 적용돼요.
- 수식 변경은 웹에서 관리하며, 모바일 앱을 새로 출시하지 않아도 반영돼요.
