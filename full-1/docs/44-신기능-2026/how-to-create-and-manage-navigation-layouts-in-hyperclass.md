# 내비게이션 레이아웃 만들고 관리하기

**Navigation Layouts**(내비게이션 레이아웃)를 쓰면 에이전시가 여러 서브 계정의 메뉴를 일관되게 정리할 수 있어요. 서브 계정마다 메뉴를 따로 설정하지 않아도 돼요. 상품 정리, 그룹 이름 변경, 아이콘 변경, 항목 순서 변경, 불필요한 옵션 숨기기를 레이아웃으로 저장해 두고 다시 쓸 수 있어요. 이 문서에서는 레이아웃을 만들고 적용하고 관리하는 방법과 공유 레이아웃 업데이트, 개별 사용자 지정, 플랜별 사용 범위, 주요 제한 사항을 안내해요.

## 내비게이션 레이아웃의 장점

내비게이션 레이아웃을 쓰면 고객사와 서브 계정마다 메뉴를 체계적으로 유지하면서도 관리 부담은 줄일 수 있어요.

- 일관된 내비게이션: 저장한 설정을 여러 서브 계정에 똑같이 적용해, 익숙한 메뉴 환경을 유지해요.
- 재사용 가능한 설정: 서브 계정마다 같은 메뉴 구조를 처음부터 다시 만들지 않고, 레이아웃을 저장해 두었다가 다시 써요.
- 유연한 구성: 상품 순서를 바꾸고, 그룹 이름과 아이콘을 바꾸고, 불필요한 메뉴 옵션을 숨겨요.
- 한곳에서 관리: 공유 레이아웃을 수정하면 그 레이아웃을 쓰는 서브 계정에 변경 내용이 자동으로 반영돼요.
- 개별 대응: 서브 계정 하나에 다른 메뉴 구성이 필요하면 별도 레이아웃을 저장해요.
- 간결한 메뉴: 상품 사용 가능 여부나 사용자 권한은 바꾸지 않고, 화면에 보이는 메뉴만 줄여요.

## 사용 조건과 제한 사항

에이전시 관리자만 쓸 수 있는 기능이에요.

### 플랜별 사용 범위

| 에이전시 플랜 | 내비게이션 레이아웃 기능 |
| --- | --- |
| $97 플랜 | 기본 내비게이션만 쓸 수 있어요. 내비게이션 사용자 지정은 할 수 없어요. |
| $297 플랜 | 서브 계정 한 곳의 내비게이션을 사용자 지정할 수 있어요. 재사용 레이아웃 관리는 할 수 없어요. |
| $497 플랜 | 내비게이션 레이아웃을 만들고, 저장하고, 편집하고, 이름을 바꾸고, 복제할 수 있어요. 여러 서브 계정에 레이아웃을 적용하고 공유 업데이트를 관리할 수 있어요. |

### 주요 제한 사항

{% hint style="warning" %}
아래 제한 사항을 꼭 확인하세요.
{% endhint %}

- 플랜 조건: 재사용 가능한 내비게이션 레이아웃 관리는 $497 에이전시 플랜에서 쓸 수 있어요.
- $297 플랜의 사용자 지정: $297 플랜 에이전시는 서브 계정 한 곳의 내비게이션을 사용자 지정할 수 있지만, 재사용 레이아웃은 관리할 수 없어요.
- 스냅샷: 내비게이션 레이아웃은 스냅샷에 포함되지 않아요.
- 새 서브 계정: 저장한 레이아웃은 새로 만든 서브 계정에 자동으로 적용되지 않아요. 에이전시에서 직접 적용해야 해요.
- 권한: 메뉴 항목을 숨겨도 해당 기능이 꺼지거나 접근이 제한되지는 않아요.
- 공유 변경: 공유 레이아웃을 편집하면 그 레이아웃을 쓰는 모든 서브 계정에 자동으로 반영될 수 있어요.

### 에이전시가 플랜을 낮추면 어떻게 되나요?

$497 플랜에서 $297 플랜으로 낮춰도 기존 내비게이션 레이아웃은 그대로 남아요.

다만 이후에는 서브 계정 한 곳의 내비게이션만 편집할 수 있어요. $297 플랜에서는 재사용 레이아웃을 더 이상 관리할 수 없어요.

## 내비게이션 레이아웃 설정하기

### 내비게이션 레이아웃 만들고 저장하기

여러 서브 계정에서 같은 내비게이션 설정을 다시 쓰고 싶거나, 일관된 메뉴 구조를 만들고 싶을 때 레이아웃을 만들어요.

1. 하이퍼클래스의 **Agency View**(에이전시 뷰)에서 시작해요.
2. 사용할 수 있는 사용자 지정 옵션으로 내비게이션을 구성해요.

   - 상품과 내비게이션 항목을 정리해요.
   - 내비게이션 그룹 이름을 바꿔요.
   - 아이콘을 바꿔요.
   - 메뉴 항목 순서를 바꿔요.
   - 레이아웃에 보이지 않아야 할 메뉴 옵션을 숨겨요.

### 서브 계정 한 곳에 레이아웃 적용하기

이미 저장한 내비게이션 설정을 특정 서브 계정에 적용하고 싶을 때 저장된 레이아웃을 써요.

단계:

1. 아래 순서로 저장된 레이아웃을 적용해요.

   1. **Agency View**에서 저장된 **Navigation Layouts**를 열어요.
   2. 사용할 레이아웃을 찾아요.
   3. 레이아웃 적용 옵션을 선택해요.
   4. 레이아웃을 쓸 서브 계정을 선택해요.
   5. 선택한 서브 계정에 레이아웃을 적용해요.
   6. 서브 계정의 내비게이션 메뉴에서 적용된 설정을 확인해요.

### 여러 서브 계정에 레이아웃 적용하기

서브 계정마다 따로 설정하지 않아도 저장된 레이아웃 하나를 여러 서브 계정에 똑같이 적용할 수 있어요.

1. **Agency View**에서 저장된 **Navigation Layouts**를 열어요.
2. 적용할 레이아웃을 선택해요.
3. 서브 계정에 레이아웃을 적용하는 옵션을 선택해요.
4. 레이아웃을 쓸 서브 계정을 선택해요.
5. 선택한 계정에 레이아웃을 적용해요.
6. 지정한 서브 계정의 내비게이션 메뉴를 확인해요.

{% hint style="warning" %}
여러 서브 계정이 공유 레이아웃을 쓰고 있으면, 그 공유 레이아웃을 바꿀 때 지정된 모든 서브 계정에 영향을 줄 수 있어요.
{% endhint %}

## 저장된 내비게이션 레이아웃 관리하기

에이전시의 내비게이션 요구가 바뀌면 저장된 레이아웃을 편집하거나 이름을 바꾸거나 복제할 수 있어요. 재사용 레이아웃 관리는 $497 플랜 에이전시에서 할 수 있어요.

### 기존 레이아웃 편집하기

메뉴 순서, 그룹 이름, 아이콘, 숨긴 항목처럼 내비게이션 구조를 바꾸고 싶을 때 기존 레이아웃을 편집해요.

내비게이션 메뉴를 바꿔야 할 때 저장된 레이아웃을 편집하세요.

1. **Agency View**에서 저장된 **Navigation Layouts**를 열어요.
2. 업데이트할 레이아웃을 선택해요.
3. 내비게이션 설정을 편집해요.
4. 항목 순서 바꾸기, 그룹 이름 바꾸기, 아이콘 바꾸기, 옵션 숨기기 같은 변경을 해요.
5. **변경사항 저장**을 선택하세요.

{% hint style="warning" %}
공유 레이아웃을 업데이트하면 그 레이아웃이 지정된 모든 서브 계정이 자동으로 업데이트될 수 있어요. 서브 계정 한 곳만 바꾸고 싶다면 별도 레이아웃을 저장하세요.
{% endhint %}

### 레이아웃 이름 바꾸기

저장된 레이아웃의 이름만으로는 용도를 알아보기 어려워졌을 때 이름을 바꿔요.

단계:

1. 레이아웃 이름은 알아보고 관리하기 쉽게 지어 주세요.

   1. **Agency View**에서 저장된 **Navigation Layouts**를 열어요.
   2. 이름을 바꿀 레이아웃을 찾아요.
   3. 이름 변경 옵션을 선택해요.
   4. 새 레이아웃 이름을 입력해요.
   5. **변경사항 저장**을 선택하세요.

### 레이아웃 복제하기

기존 레이아웃의 설정을 바탕으로 별도의 내비게이션 환경을 만들고 싶을 때 레이아웃을 복제해요.

<!-- 검토 필요: 원문 내용이 서로 다름 -->
단계:

1. 레이아웃 이름은 알아보고 관리하기 쉽게 지어 주세요.

   1. **Agency View**에서 저장된 **Navigation Layouts**를 열어요.
   2. 이름을 바꿀 레이아웃을 찾아요.
   3. 이름 변경 옵션을 선택해요.
   4. 새 레이아웃 이름을 입력해요.
   5. **변경사항 저장**을 선택하세요.

## 공유 레이아웃과 개별 변경 관리하기

### 공유 레이아웃 업데이트하기

여러 서브 계정이 같은 저장 레이아웃을 쓰고 있으면, 공유 레이아웃을 바꿀 때 지정된 모든 계정의 내비게이션이 자동으로 업데이트될 수 있어요.

예를 들어 에이전시가 공유 레이아웃에서 메뉴 순서를 바꾸거나 불필요한 항목을 숨기면, 그 레이아웃을 쓰는 서브 계정에 변경 내용이 반영될 수 있어요.

1. **Agency View**에서 저장된 **Navigation Layouts**를 열어요.
2. 업데이트할 공유 레이아웃을 선택해요.
3. 필요한 내비게이션 변경을 해요.
4. 업데이트한 레이아웃을 저장해요.
5. 지정된 서브 계정의 내비게이션 메뉴를 확인해요.

{% hint style="warning" %}
레이아웃이 지정된 모든 서브 계정에 같은 내비게이션 변경을 적용하려는 경우에만 공유 변경을 사용하세요.
{% endhint %}

### 서브 계정 한 곳만 따로 사용자 지정하기

서브 계정 한 곳에 고유한 메뉴 구성이 필요하고, 원래 공유 레이아웃을 쓰는 다른 서브 계정에는 영향을 주고 싶지 않다면 별도의 내비게이션 레이아웃을 저장하세요.

예를 들어 한 고객사에는 메뉴 순서를 다르게 보이거나 특정 항목을 숨기고, 다른 고객사의 공유 내비게이션은 그대로 두고 싶을 수 있어요.

1. **Agency View**에서 저장된 **Navigation Layouts**를 열어요.
2. 기존 공유 레이아웃을 복제해요.
3. 복사된 레이아웃은 알아보기 쉽게 이름을 바꿔요.
4. 해당 서브 계정에 맞게 새 레이아웃을 사용자 지정해요.
5. 새 레이아웃을 저장해요.
6. 변경이 필요한 서브 계정에만 적용해요.

{% hint style="warning" %}
다른 서브 계정에 영향을 주지 않으려면, 변경이 계정 한 곳에만 필요할 때 원래의 공유 레이아웃은 수정하지 마세요.
{% endhint %}

## 자주 묻는 질문

### 메뉴 항목을 숨기면 사용자가 그 기능을 쓰지 못하나요?

아니요. 항목을 숨기면 내비게이션 화면에서 보이는 상태만 바뀌어요. 기능이 꺼지거나 사용자 권한이 바뀌지는 않아요.

### 내비게이션 레이아웃이 스냅샷에 포함되나요?

아니요. 내비게이션 레이아웃은 스냅샷에 포함되지 않아요. 스냅샷 내용과는 따로 관리해야 해요.

### 저장한 내비게이션 레이아웃이 새 서브 계정에 자동으로 적용되나요?

아니요. 새로 만든 서브 계정에는 저장된 내비게이션 레이아웃이 자동으로 적용되지 않아요. 에이전시에서 원하는 레이아웃을 직접 적용해야 해요.

### 에이전시가 $497 플랜에서 $297 플랜으로 낮추면 어떻게 되나요?

기존 레이아웃은 그대로 남아요. 다만 이후에는 서브 계정 한 곳의 내비게이션만 편집할 수 있고, $297 플랜에서는 재사용 레이아웃을 관리할 수 없어요.

### $297 플랜 에이전시도 여러 서브 계정에 쓸 재사용 레이아웃을 만들 수 있나요?

아니요. $297 플랜에서는 서브 계정 한 곳의 내비게이션 사용자 지정만 할 수 있어요. 재사용 레이아웃 관리와 여러 서브 계정에 레이아웃 적용은 $497 플랜에서 쓸 수 있어요.

### 다른 서브 계정은 그대로 두고 한 곳만 다른 레이아웃을 쓸 수 있나요?

네. 재사용 레이아웃 관리를 쓸 수 있는 에이전시라면 별도의 내비게이션 레이아웃을 저장해 원하는 서브 계정에만 적용할 수 있어요. 원래 공유 레이아웃은 바뀌지 않아요.
