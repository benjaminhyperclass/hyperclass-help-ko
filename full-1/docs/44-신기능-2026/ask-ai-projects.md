# AI에게 문의 프로젝트로 대화·파일·지침 한곳에 정리하기

**Projects**(프로젝트)를 쓰면 관련된 대화, 파일, 지침, 메모리를 작업별 공간에 모아 둘 수 있어요. 'AI에게 문의'가 프로젝트의 맥락을 알고 답하기 때문에, 대화마다 같은 내용을 다시 설명하지 않아도 돼요.

[동영상](https://jumpshare.com/embed/6v3T2izCQMMvK4IeGcfS)

## 프로젝트란?

하이퍼클래스의 'AI에게 문의' 프로젝트는 관련된 대화, 파일, 지침, 메모리를 전용 공간에 모아서 관리하는 기능이에요. 프로젝트마다 'AI에게 문의'가 필요한 맥락을 갖고 있어서, 같은 정보를 대화마다 반복하지 않아도 관련성 높고 일관된 답을 받을 수 있어요. 예약된 작업을 관리하고 프로젝트 활동을 확인하면서, 서로 다른 업무를 한곳에서 정리할 수도 있어요.

## 프로젝트 지침과 맥락

프로젝트 지침은 해당 프로젝트 안에서 'AI에게 문의'가 어떻게 일해야 하는지 정해 두는 내용이에요. 말투, 형식, 브랜드 보이스 같은 요구 사항을 미리 정해 두면, 프롬프트마다 지침을 반복해서 쓰지 않아도 여러 대화에서 일관된 방식으로 작업할 수 있어요.

프로젝트에는 다음 항목을 담을 수 있어요.

- **Project Name**(프로젝트 이름): 작업 공간을 구분해 주는 이름이에요. 다른 프로젝트와 헷갈리지 않게 해 줘요.
- **설명**: 프로젝트의 목적과 작업 배경을 적어요.
- **Custom Instructions**(사용자 지정 지침): 'AI에게 문의'가 따라야 할 규칙, 가이드라인, 형식 선호, 브랜드 보이스를 정해요.
- 관련 대화: 같은 프로젝트에 속한 채팅을 한데 모아요.
- 참고 자료: 업로드한 파일, 미디어 라이브러리 항목, 텍스트 문서로 추가 정보를 제공해요.
- **프로젝트 메모리**: 프로젝트와 관련된 유용한 정보를 기억해 둬요.

예를 들어 "월간 마케팅 캠페인"이라는 프로젝트를 만들고 다음과 같은 지침을 넣을 수 있어요.

"마케팅 콘텐츠는 전문적이면서 친근한 말투로 작성해 주세요. 문단은 간결하게 쓰고, 고객이 얻는 이점을 강조하고, 필요할 때는 분명한 행동 유도 문구를 넣어 주세요."

이 지침은 해당 프로젝트 안의 대화에 적용되어, 일관된 커뮤니케이션을 유지하는 데 도움이 돼요.

## 프로젝트 파일과 지원 형식

참고 자료를 추가하면 'AI에게 문의'가 캠페인 내용, 콘텐츠 가이드라인, 비즈니스 문서 같은 프로젝트 정보를 참고할 수 있어요. 이런 자료를 프로젝트 안에 두면 같은 작업과 관련된 대화에 일관된 맥락이 제공돼요.

### 프로젝트 맥락 추가하기

참고 자료는 세 가지 방법으로 추가할 수 있어요.

- **파일 업로드**: 내 기기에 있는 문서를 바로 추가해요.
- **Select From Media Library**(미디어 라이브러리에서 선택): 하이퍼클래스 미디어 라이브러리에 저장된 파일 중에서 골라요.
- **Add Text Documents**(텍스트 문서 추가): 프로젝트용 텍스트 참고 자료를 만들거나 추가해요.

### 지원하는 파일 형식

'AI에게 문의' 프로젝트는 다음 문서 형식을 지원해요.

| 파일 종류 | 형식 |
| --- | --- |
| PDF 문서 | .pdf |
| Microsoft Word 문서 | .docx |
| 일반 텍스트 문서 | .txt |
| 마크다운 문서 | .md |
| 쉼표로 구분된 값 | .csv |

{% hint style="info" %}
프로젝트 하나에는 파일을 최대 50개까지 추가할 수 있어요.
{% endhint %}

예를 들어 마케팅 프로젝트에 브랜드 가이드라인 PDF, Word로 작성한 캠페인 계획서, 승인된 상품 정보가 담긴 CSV 파일을 함께 넣을 수 있어요.

## 프로젝트 메모리

프로젝트 메모리는 진행 중인 작업과 관련된 유용한 정보를 'AI에게 문의'가 기억하게 해 줘요. 프로젝트 안의 대화를 매번 별개의 요청으로 보지 않고 추가 맥락으로 활용하기 때문에, 이후 답변이 더 관련성 있게 나올 수 있어요.

**프로젝트 메모리**에서는 다음 작업을 할 수 있어요.

- **Review Memories**(메모리 확인): 프로젝트에 저장된 정보를 확인해요.
- **Delete Memories**(메모리 삭제): 오래되었거나 더 이상 필요 없는 정보를 지워요.
- **Import Memories**(메모리 가져오기): 다른 AI 어시스턴트에 있던 메모리를 프로젝트로 가져와요.

예를 들어 교육용 글을 만드는 프로젝트라면 독자층, 글의 스타일, 용어에 관한 선호를 기억해 둘 수 있어요.

프로젝트 메모리는 해당 프로젝트의 작업을 돕기 위한 것이에요. 그래서 목적마다 작업 맥락을 따로 관리하기 쉬워요.

메모리 기능 전반이 궁금하면 [AI에게 문의 메모리란?](../13-AI-Employee/Ask-AI/what-is-ask-ai-memory-007963.md)을 참고하세요.

## 프로젝트의 예약된 작업

**예약된 작업**을 쓰면 'AI에게 문의'가 프로젝트의 지침과 맥락을 바탕으로 반복 프롬프트를 실행해요. 정기적으로 해야 하고, 같은 프로젝트 가이드라인을 따라야 하는 업무에 알맞아요.

프로젝트 기반 예약된 작업으로 다음 같은 반복 업무를 처리할 수 있어요.

- 정기 마케팅 요약 작성
- 프로젝트 브랜드 가이드라인을 활용한 콘텐츠 아이디어 반복 생성
- 관련 비즈니스 정보 검토
- 프로젝트에서 쓸 수 있는 맥락을 바탕으로 한 정기 업데이트 작성

예를 들어 마케팅 프로젝트에 매주 한 번, 프로젝트의 브랜드 보이스와 참고 문서를 활용해 캠페인 아이디어를 만들어 달라는 작업을 넣을 수 있어요.

프로젝트 지침과 예약된 작업을 함께 쓰면 반복 실행에서도 일관된 방식을 유지할 수 있어요.

일반적인 예약 방법은 [AI에게 문의의 예약된 작업으로 프롬프트 자동화하기](../13-AI-Employee/Ask-AI/how-to-use-scheduled-tasks-in-ask-ai-to-automate-prompts.md)를 참고하세요.

## 프로젝트 활동과 관리

프로젝트가 늘어날수록 관리 도구와 활동 추적 기능이 작업 공간을 정돈하고 중요한 변경 사항을 확인하는 데 도움이 돼요. 지침, 참고 파일, 예약된 작업이 서로 다른 프로젝트를 여러 개 관리할 때 특히 유용해요.

### 프로젝트 활동 확인

**프로젝트 활동**에서는 다음 항목의 변경 내역을 볼 수 있어요.

- 프로젝트 지침
- 프로젝트 파일
- 예약된 작업
- 프로젝트 상태

활동을 확인하면 프로젝트 설정이 시간에 따라 어떻게 바뀌었는지 알 수 있어요.

### 프로젝트 정리와 관리

'AI에게 문의'에서는 프로젝트를 관리하는 다음 기능을 쓸 수 있어요.

- **검색**: 프로젝트를 구분할 수 있는 정보로 찾아요.
- **정렬**: 제공되는 정렬 옵션으로 프로젝트 목록을 정리해요.
- **Pin**(고정): 중요한 프로젝트를 쉽게 찾을 수 있게 해요.
- **보관**: 더 이상 진행하지 않는 프로젝트를 기본 프로젝트 목록에서 치워요.
- **복원**: 보관한 프로젝트를 다시 활성 작업 공간으로 되돌려요.

예를 들어 자주 쓰는 프로젝트는 고정하고, 끝난 캠페인은 보관해서 목록을 깔끔하게 유지할 수 있어요. 보관한 프로젝트는 나중에 참고할 수 있도록 그대로 남아 있어요.

## 자주 묻는 질문

### 다른 하이퍼클래스 사용자도 내 'AI에게 문의' 프로젝트를 볼 수 있나요?

아니요. 프로젝트와 프로젝트에 속한 채팅은 사용자 개인에게만 보여요. 에이전시와 서브 계정에서 프로젝트를 쓸 수 있다고 해서, 다른 사용자와 프로젝트가 공유되는 것은 아니에요.

### 에이전시와 서브 계정 사이에 프로젝트가 공유되나요?

아니요. 에이전시와 서브 계정은 각자 프로젝트를 따로 관리해요. 그래서 프로젝트 작업이 해당 계정 안에서 정리돼요.

### 프로젝트에 파일을 몇 개까지 추가할 수 있나요?

프로젝트 하나에 최대 50개까지 추가할 수 있어요. 지원하는 문서 형식은 PDF, Word(.docx), 일반 텍스트, 마크다운, CSV예요.

### 다른 AI 어시스턴트의 메모리를 가져올 수 있나요?

네. 'AI에게 문의' 프로젝트에는 다른 AI 어시스턴트의 메모리를 가져오는 옵션이 있어요. 기존 맥락을 직접 다시 입력하지 않고 프로젝트로 옮겨 올 수 있어요.

### 대화마다 프로젝트를 따로 만들어야 하나요?

아니요. 프로젝트는 관련된 대화를 한데 묶기 위한 기능이에요. 목표, 참고 자료, 지침이 같은 여러 대화에는 프로젝트 하나를 같이 쓰면 돼요.

### 프로젝트 지침과 'AI에게 문의' 스킬은 뭐가 다른가요?

프로젝트 지침은 특정 프로젝트 안의 대화에 적용되는 가이드라인과 맥락이에요. [AI에게 문의 스킬(Skills)](../13-AI-Employee/Ask-AI/ask-ai-skills-and-connectors.md)은 재사용할 수 있는 지침 모음이에요. 요청이 특정 워크플로우와 맞을 때나 사용자가 스킬을 직접 불러낼 때 'AI에게 문의'가 적용해요.

### 보관한 프로젝트를 복원할 수 있나요?

네. 'AI에게 문의' 프로젝트는 보관과 복원을 지원해요. 진행하지 않는 작업을 정리하면서도 프로젝트를 완전히 없애지 않고 작업 공간에 남겨 둘 수 있어요.

### 예약된 작업이 프로젝트의 맥락을 쓸 수 있나요?

네. 프로젝트에 속한 예약된 작업은 해당 프로젝트의 지침과 맥락을 바탕으로 실행돼요. 반복 작업도 프로젝트에 맞는 가이드라인과 참고 정보를 따라요.
