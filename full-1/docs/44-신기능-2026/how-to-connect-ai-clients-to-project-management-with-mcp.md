# MCP로 AI 클라이언트와 프로젝트 관리 연결하기

하이퍼클래스 **프로젝트 관리**(Project Management)를 MCP(Model Context Protocol)로 호환되는 AI 어시스턴트와 연결하면, 일상 언어로 프로젝트 작업을 정리하고 관리할 수 있어요. AI 클라이언트와 하이퍼클래스를 오가지 않고도 작업, 하위 작업, 스페이스, 리스트를 만들고 수정할 수 있습니다. 이 문서에서는 지원되는 AI 클라이언트를 OAuth로 연결하고 MCP로 **프로젝트 관리** 작업을 시작하는 방법을 안내해요.

## Project Management MCP란?

Project Management MCP는 호환되는 AI 클라이언트를 MCP로 하이퍼클래스 **프로젝트 관리**에 연결하는 연동이에요. MCP를 쓰면 AI 어시스턴트가 표준화된 연결을 통해 하이퍼클래스에서 지원하는 기능을 찾아 사용할 수 있어요. 프로젝트 관리 기능에 대한 자세한 내용은 [프로젝트 관리 소개](../36-기타/introduction-to-project-management.md)를 참고하세요.

작업을 만들거나 리스트를 정리하거나 댓글을 확인할 때마다 **프로젝트 관리**를 열 필요 없이, 연결된 AI 클라이언트에 하고 싶은 일을 말하면 돼요.

이 연동으로 작업, 하위 작업, 스페이스, 리스트를 만들고 관리할 수 있어요. 커스텀 상태, 커스텀 필드 값, 작업 댓글도 다룰 수 있어요.

연결은 호스팅된 MCP 엔드포인트와 OAuth 인증으로 이루어져요. 공용 인증 정보를 설정하거나 Projects REST API를 직접 개발할 필요 없이, 내 계정으로 연결을 승인하면 됩니다.

지원하는 AI 클라이언트

- Claude.ai
- ChatGPT
- Cursor
- Codex
- Claude Code
- Muse

---

## Project Management MCP의 장점

Project Management MCP를 쓰면 작업 내용은 하이퍼클래스 안에 두면서, AI 어시스턴트로 프로젝트 작업을 관리할 수 있어요. 자연어로 지시하면 반복되는 메뉴 이동이 줄고, 프로젝트 정보를 다루는 방법이 하나 더 생겨요.

- 자연어로 작업 관리: 하고 싶은 일을 말로 설명해 작업, 하위 작업, 스페이스, 리스트를 만들고 수정해요.
- 화면 전환 감소: 지원되는 프로젝트 활동을 위해 **프로젝트 관리** 화면을 계속 열지 않아도 돼요.
- 커스텀 상태와 커스텀 필드: 알맞은 상태와 커스텀 필드 값을 넣어 작업을 만들 수 있어서, 만든 뒤에 손으로 고치는 일이 줄어요.
- 작업 논의: 연결된 AI 클라이언트에서 작업 댓글을 읽고 새 댓글을 남길 수 있어요.
- 간편한 연동: 호스팅된 MCP 연결로 지원되는 프로젝트 기능을 쓸 수 있어서, Projects REST API를 직접 개발하지 않아도 돼요.
- OAuth 기반 인증: 내 계정으로 인증하고, 요청된 하이퍼클래스 리소스에 대한 접근을 직접 허용해요.
- 로컬 서버 설치 불필요: 호스팅된 엔드포인트를 쓰므로 MCP 서버를 내 컴퓨터에 설치하거나 VPN에 연결할 필요가 없어요.

## 설정 방법

**프로젝트 관리**를 AI 어시스턴트에 연결하려면 호스팅된 MCP 연결을 설정하고 OAuth 인증을 마쳐야 해요. 연결이 끝나면 자연어 요청으로 지원되는 프로젝트 리소스를 다룰 수 있어요.

연결은 AI 클라이언트 안에서 시작해요. 클라이언트가 OAuth 인증을 시작하면 하이퍼클래스 로그인 화면이 나타나요.

### AI 클라이언트 연결

사용하는 AI 클라이언트에 맞는 MCP 엔드포인트를 고르세요. 아래 엔드포인트는 하이퍼클래스 MCP 자료에 안내된 주소예요.

| AI 클라이언트 | 호스팅 MCP 엔드포인트 |
| --- | --- |
| Claude.ai | `https://services.leadconnectorhq.com/mcp/anthropic/v2` |
| Claude Code | `https://services.leadconnectorhq.com/mcp/anthropic/v2` |
| ChatGPT | `https://services.leadconnectorhq.com/mcp/openai/v2/` |
| Codex | `https://services.leadconnectorhq.com/mcp/openai/v2/` |
| Muse | `https://services.leadconnectorhq.com/mcp/muse/v2/` |

#### ChatGPT 연결

ChatGPT는 OAuth 기반 MCP 전용 연결을 지원해요. ChatGPT 계정과 워크스페이스 권한이 허용하면 사용자 지정 MCP 앱으로 연결을 설정할 수 있어요. ChatGPT와 Codex 연결에 대한 자세한 내용은 [ChatGPT와 Codex를 하이퍼클래스 MCP에 연결하기](../13-AI-Employee/MCP-Server/connect-chatgpt-and-codex-to-hyperclass-mcp.md)를 참고하세요.

1. 웹에서 ChatGPT를 엽니다.
2. **설정**을 엽니다.
3. **앱**을 선택합니다.
4. 계정에서 **Developer mode**(개발자 모드)를 요구하면, MCP 연결을 만들기 전에 먼저 켭니다.
5. **만들기**를 선택해 사용자 지정 MCP 앱 만들기를 시작합니다.
6. 연결 이름을 입력합니다. 예: "하이퍼클래스 프로젝트 관리"
7. **설명 추가**에 이 연결이 하이퍼클래스 MCP 연동임을 알 수 있는 설명을 입력합니다.
8. MCP 서버 URL에 아래 주소를 입력합니다.

   `https://services.leadconnectorhq.com/mcp/openai/v2/`
9. MCP 앱 설정을 계속 진행합니다.
10. MCP 도구를 스캔하거나 찾는 옵션이 보이면 선택합니다.
11. 안내가 나오면 OAuth 인증을 시작합니다.
12. 인증을 마친 뒤 ChatGPT로 돌아와 앱 만들기를 완료합니다.

#### Claude.ai 연결

Claude.ai는 사용자 지정 커넥터로 하이퍼클래스 MCP 연결을 지원해요. 호스팅된 엔드포인트를 추가한 뒤 OAuth 인증을 마치면, 승인한 하이퍼클래스 기능을 쓸 수 있어요. 여러 계정을 연결하려면 [Claude용 하이퍼클래스 MCP 다중 계정 지원](../13-AI-Employee/MCP-Server/hyperclass-mcp-multi-account-support-for-claude.md)을 참고하세요.

1. Claude.ai를 엽니다.
2. **설정**을 선택합니다.
3. **커넥터**를 선택합니다.
4. **Add custom connector**(사용자 지정 커넥터 추가)를 클릭합니다.
5. 서버 URL에 아래 주소를 입력합니다.

   `https://services.leadconnectorhq.com/mcp/anthropic/v2`
6. **연결**을 클릭합니다.
7. 하이퍼클래스 OAuth 인증을 완료합니다.
8. 연결이 되면 Claude에서 새 대화를 시작합니다.

#### Codex 연결

Codex는 CLI나 지원되는 IDE 확장 프로그램에서 OpenAI 호환 MCP 엔드포인트를 쓸 수 있어요.

Codex IDE 확장 프로그램으로 연결하려면 다음과 같이 하세요.

1. Codex IDE 확장 프로그램을 엽니다.
2. 톱니바퀴 아이콘 메뉴를 선택합니다.
3. **MCP servers**(MCP 서버)를 선택합니다.
4. **Add server**(서버 추가)를 클릭합니다.
5. **Streamable HTTP**를 선택합니다.
6. 서버 URL에 아래 주소를 입력합니다.

   `https://services.leadconnectorhq.com/mcp/openai/v2/`
7. **Authenticate**(인증)를 선택합니다.
8. 하이퍼클래스 OAuth 인증을 완료합니다.

Codex CLI에서는 아래 명령어로 서버를 추가해요.

`codex mcp add leadconnector --url https://services.leadconnectorhq.com/mcp/openai/v2/`

그다음 아래 명령어로 OAuth 인증을 시작해요.

`codex mcp login leadconnector`

로그인과 인증 안내를 따라가세요.

#### Claude Code 연결

Claude Code는 MCP 설정에서 Anthropic 전용 엔드포인트를 쓸 수 있어요.

1. 터미널을 엽니다.
2. 아래 명령어로 호스팅된 MCP 서버를 추가합니다.

   `claude mcp add --transport http leadconnector https://services.leadconnectorhq.com/mcp/anthropic/v2`
3. 브라우저가 열리면 하이퍼클래스 OAuth 인증을 완료합니다.
4. 아래 명령어로 연결을 확인합니다.

   `claude mcp list`

#### Muse 연결

Muse는 하이퍼클래스 MCP를 공식 앱으로 제공해요. Muse 전용 엔드포인트와 OAuth 인증으로 연결해요. 자세한 내용은 [하이퍼클래스 MCP를 Muse에 연결하기](../01-시작하기/기본-설정/connect-hyperclass-mcp-to-muse.md)를 참고하세요.

1. Muse를 엽니다.
2. 앱 또는 MCP 연결 옵션을 찾습니다.
3. 하이퍼클래스 앱을 선택합니다.
4. 연결을 시작합니다.
5. 하이퍼클래스 OAuth 인증을 완료합니다.
6. Muse로 돌아와 하이퍼클래스가 연결되었는지 확인합니다.

### OAuth로 연결 승인하기

OAuth를 쓰면 공용 계정 정보 없이도 AI 클라이언트가 승인된 하이퍼클래스 리소스에 접근할 수 있어요. 인증하는 동안 접근할 수 있는 서브 계정을 선택하고, 연결이 요청하는 권한을 확인해요.

1. AI 클라이언트에서 OAuth 인증을 시작합니다.
2. 하이퍼클래스 인증 페이지가 열리면 하이퍼클래스 계정 정보로 로그인합니다.
3. 연결할 서브 계정을 선택합니다.
4. 해당하는 에이전시 연결에서 여러 서브 계정 접근을 제공하면, 알맞은 서브 계정을 선택합니다.
5. 연동이 요청하는 OAuth 범위(scope)와 권한을 확인합니다.
6. 인증 요청을 승인합니다.
7. 인증이 끝나면 AI 클라이언트로 돌아갑니다.
8. 하이퍼클래스 MCP 연결이 연결됨으로 표시되는지 확인합니다.

### 첫 프로젝트 관리 요청 보내기

AI 클라이언트가 연결되면 관리하고 싶은 프로젝트 작업을 말로 설명하면 돼요. 대상 리스트, 할 일, 작업 세부 내용을 구체적으로 적어 요청하세요.

1. 연결된 AI 클라이언트를 엽니다.
2. 새 대화를 시작하거나, 하이퍼클래스 MCP 연결을 쓸 수 있는 기존 대화를 사용합니다.
3. 도구를 직접 선택해야 하는 클라이언트라면, 연결된 하이퍼클래스 MCP 앱이나 도구를 선택합니다.
4. 자연어로 요청을 입력합니다.

   예시:

   "온보딩 리스트에 금요일까지 마감인 작업 3개를 만들고, 담당자는 나로 지정해 줘."
5. AI 클라이언트의 응답과 실행 결과를 확인합니다.
6. 하이퍼클래스 **프로젝트 관리**에서 만들어진 작업을 확인합니다.

하이퍼클래스에서 작업을 확인하는 방법은 다음과 같아요.

1. 하이퍼클래스를 열고 해당 **서브 계정**으로 전환합니다.
2. 왼쪽 메뉴에서 **연락처**를 선택합니다.
3. 페이지 위쪽의 **작업** 탭을 선택합니다.
4. 왼쪽 **스페이스** 패널에서 해당 스페이스를 펼칩니다.
5. **온보딩** 리스트를 선택합니다.
6. 작업과 지정된 세부 내용을 확인합니다.

## 자연어로 프로젝트 작업 관리하기

연결이 끝나면 AI 어시스턴트가 지원되는 **프로젝트 관리** 활동을 도와줘요. 모든 작업을 메뉴로 일일이 찾아가지 않고, 하고 싶은 일을 말로 설명하면 돼요.

아래 예시는 이번 릴리스에서 지원하는 기능이에요. 실제로 실행되는 범위는 연결에서 쓸 수 있는 기능과 내가 승인한 권한에 따라 달라져요.

### 작업, 하위 작업, 스페이스, 리스트 만들고 수정하기

**프로젝트 관리**는 스페이스, 선택 사항인 폴더, 리스트, 작업, 하위 작업으로 업무를 정리해요. MCP를 쓰면 호환되는 AI 클라이언트가 자연어 지시로 이런 프로젝트 항목을 만들고 관리할 수 있어요. 스페이스, 폴더, 리스트에 대한 자세한 내용은 [스페이스, 폴더, 리스트로 작업 정리하기](../36-기타/organize-work-with-spaces-folders-and-lists.md)를, 작업을 만드는 방법은 [작업 또는 하위 작업 만들기](../36-기타/create-a-task-or-subtask.md)를 참고하세요.

다음과 같은 일을 요청할 수 있어요.

- 팀이나 업무 흐름별로 새 스페이스 만들기
- 스페이스 안에 리스트 만들기
- 선택한 리스트에 작업 만들기
- 기존 작업 수정하기
- 상위 작업 아래에 하위 작업 만들거나 수정하기

요청 예시:

"클라이언트 온보딩 스페이스를 새로 만들고, 그 안에 온보딩 리스트를 추가해 줘."

### 커스텀 상태와 커스텀 필드 활용하기

커스텀 상태는 팀이 업무 단계별로 작업을 정리하도록 도와주고, 커스텀 필드는 프로젝트에 필요한 추가 정보를 저장해요.

Project Management MCP로 알맞은 상태와 커스텀 필드 값을 넣어 작업을 만들 수 있어요. 작업을 만든 뒤에 손으로 고쳐야 하는 일이 줄어들어요.

요청 예시:

"온보딩 리스트에 내가 말한 상태와 커스텀 필드 값으로 작업을 만들어 줘."

정확한 결과를 얻으려면 작업을 설명할 때 사용할 상태와 커스텀 필드 값을 함께 알려 주세요.

### 작업 댓글 읽고 남기기

작업 댓글을 쓰면 팀원이 프로젝트 작업에 대해 의견을 나누고, 중요한 맥락을 해당 작업 옆에 남길 수 있어요.

Project Management MCP를 쓰면 AI 클라이언트에 기존 작업 댓글을 읽거나 새 댓글을 남기도록 요청할 수 있어요. 작업 화면을 열지 않고도 논의를 확인하고 진행 상황을 남길 수 있어요.

요청 예시:

- "클라이언트 온보딩 작업의 댓글을 읽어 줘."
- "클라이언트 온보딩 작업에 최신 프로젝트 진행 상황을 댓글로 남겨 줘."

## 자주 묻는 질문

### Project Management MCP를 연결하려면 비공개 연동 토큰을 만들어야 하나요?

아니요. Claude, ChatGPT, Codex, Muse용으로 안내된 OAuth 전용 엔드포인트는 로그인과 인증 과정을 거쳐요. 이런 연결에서는 **비공개 연동** 토큰을 직접 만들 필요가 없어요.

이전의 범용 MCP 설정 가이드에는 토큰 기반 연결도 안내되어 있어요. 선택한 엔드포인트에 맞는 인증 방식을 따르세요.

### 에이전시에서 여러 서브 계정을 같은 AI 클라이언트에 연결할 수 있나요?

해당 설치 옵션을 쓸 수 있는 경우에는 에이전시의 여러 서브 계정 연결이 지원돼요. 인증하는 동안 에이전시가 연결로 접근할 서브 계정을 선택할 수 있어요. 자세한 내용은 [Claude용 하이퍼클래스 MCP 다중 계정 지원](../13-AI-Employee/MCP-Server/hyperclass-mcp-multi-account-support-for-claude.md)을 참고하세요.

모든 요청은 한 번에 승인된 서브 계정 하나를 대상으로 실행돼요. 여러 서브 계정 연결은 순차적으로 제공되고 있어서 모든 설치 환경에 나타나지 않을 수 있어요.

### AI 클라이언트를 연결한 뒤 하이퍼클래스 접근 권한을 해지할 수 있나요?

네. 하이퍼클래스 OAuth MCP 문서에 따르면 승인된 연결의 접근 권한을 확인하고 해지할 수 있어요.

인증을 해지하면 그 연결에 이전에 부여한 권한이 제거돼요.
