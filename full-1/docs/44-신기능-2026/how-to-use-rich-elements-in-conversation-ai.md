# 대화 AI에서 리치 요소 사용하기

하이퍼클래스의 **대화 AI**(Conversation AI)는 리치 요소(Rich Elements)를 지원해요. 에이전트가 버튼, 목록, 이미지, 파일, 링크, 서식 있는 텍스트가 담긴 대화형 답장을 보낼 수 있어요. 일반 텍스트만 보내는 대신, 에이전트가 상황에 맞는 메시지 요소를 자동으로 골라 연락처가 더 쉽게 응답하도록 도와줘요.

어떤 요소를 쓸지 직접 정할 수도 있고, 특정 대화 상황에 맞는 응답 규칙(Response Rules)을 만들 수도 있어요.

## 대화 AI의 리치 요소란?

리치 요소는 대화 AI 에이전트가 일반 텍스트를 넘어 정보를 보여 주고 고객과의 대화를 이끌 수 있게 해 주는 대화형 메시지 구성 요소예요. AI가 대화 내용에 따라 알맞은 요소를 자동으로 골라요. 응답 규칙을 추가하면 특정 요소를 언제 쓸지 더 세밀하게 정할 수 있어요.

예를 들어 부동산 에이전트는 동네를 목록으로 보여 주거나, 예약 버튼을 제공하거나, 매물 이미지와 매물 링크를 공유할 수 있어요.

리치 요소는 WhatsApp, Facebook Messenger, Instagram(모바일 앱), 라이브 채팅에서 쓸 수 있어요. 다른 채널에서는 지금처럼 일반 텍스트로 답해요.

---

## 리치 요소 종류

대화 AI는 여섯 가지 리치 요소를 제공해요. 요소마다 정보를 보여 주거나 상호작용하기 쉽게 만들어 줘요.

고객 대화에 가장 도움이 되는 요소를 골라서 켜 두세요.

### 서식 텍스트

굵게나 기울임 서식으로 가격, 영업시간, 안내 사항처럼 중요한 내용을 강조해요. 출시 시점에는 WhatsApp에서의 서식 텍스트 지원이 명시되어 있어요. 다른 채널에서는 다르게 보일 수 있어요.

### 빠른 답장

"구매", "임대"처럼 탭할 수 있는 답변 옵션을 보여 줘요. 연락처가 직접 입력하지 않고도 질문에 답할 수 있어요.

**![빠른 답장 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084079834/original/d09DgXYV0rZurdDyGaFr6v_5enNhsDf3Xg.png?1792767580)**

### 링크 버튼

예약 페이지, 매물 페이지, 상품 카탈로그처럼 웹페이지를 여는 버튼을 제공해요.

![링크 버튼 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084080241/original/FftCpnAsoT5vun_KxLISRPoN94z5hw70-g.png?1792767776)

### 목록

여러 선택지를 고를 수 있는 메뉴로 묶어 보여 줘요. 연락처가 동네, 서비스, 상품 같은 옵션을 쉽게 고를 수 있어요.

**![목록 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084080284/original/ajW9WMdvI7JJQP2AHN8CgTF6QJpLr1rhCQ.png?1792767811)**

### 이미지

대화 안에서 이미지를 바로 보여 줘요. 연락처가 채팅을 벗어나지 않고 상품이나 매물 같은 시각 정보를 볼 수 있어요.

**![이미지 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084080375/original/e7JAX_zLRF8tN8ahr4T9f5DSul_Y-9cTNA.png?1792767857)**

### 파일

연락처가 추가 정보를 요청하면 에이전트가 지원되는 PDF, 문서, 스프레드시트, 프레젠테이션을 공유할 수 있어요.

에이전트가 지원되는 파일 URL에 접근할 수 있어야 해요. 지원하는 확장자, 파일 크기 제한, 호스팅 제한은 따로 확인이 필요해요.

## 지원되는 채널과 메시지 동작

리치 요소는 지원되는 메시징 채널에서 작동해요. 다만 플랫폼에 따라 요소가 다르게 표시될 수 있어요. 이런 차이를 알아 두면 연락처가 중요한 정보를 놓치지 않게 할 수 있어요.

| 채널 | 지원 여부 |
| --- | --- |
| WhatsApp | 지원 |
| Facebook Messenger | 지원 |
| Instagram | 모바일 앱에서 지원 |
| 라이브 채팅 | 지원 |
| 그 외 채널 | 일반 텍스트 |

자동 선택: 대화 AI는 메시지마다 별도 템플릿을 만들지 않아도, 대화 내용에 맞는 요소를 켜 둔 요소 중에서 골라요.

일반 텍스트로 대체: 채널이 요소를 표시하지 못하거나 응답이 채널 제한을 넘으면, 내용이 메시지 텍스트로 옮겨져요.

{% hint style="info" %}
요소 지원 여부와 대체 서식은 채널마다 다를 수 있어요. 비즈니스에서 사용하는 플랫폼에서 중요한 상황을 직접 테스트해 보세요.
{% endhint %}

## 응답 규칙

응답 규칙은 특정 상황에서 대화 AI가 어떤 리치 요소를 쓸지 안내하는 지침이에요.

응답마다 일일이 설정하지 않고도 메시지가 보이는 방식을 조절하고 싶을 때 유용해요.

예를 들어 연락처가 서비스 가능한 동네를 물어볼 때마다 목록을 보여 주도록 에이전트에 지시할 수 있어요.

### 응답 규칙 설정 항목

규칙마다 다음 항목이 있어요.

| 설정 | 용도 |
| --- | --- |
| **Rule Name**(규칙 이름) | 규칙을 구분해요. |
| **Rule Toggle**(규칙 토글) | 규칙을 켜거나 꺼요. |
| **Situation, in your words**(상황을 직접 설명) | 요소를 언제 써야 하는지 설명해요. |
| **요소** | 해당 상황에서 쓸 리치 요소를 골라요. |
| **Element supported on**(요소 지원 채널) | 지원되는 메시징 채널을 보여 줘요. |
| **Save rules**(규칙 저장) | 설정을 저장해요. |

규칙을 추가, 편집, 삭제하는 컨트롤도 있어요. 켜 둔 리치 요소만 선택할 수 있어요.

예시: 동네 선택

- **Rule Name**: 동네
- **Situation**: "리드가 서비스 지역을 묻거나, 동네를 지정하지 않고 집을 보고 싶다고 해요. 서비스하는 동네 목록으로 답하세요."
- **요소**: 목록

**![동네 선택 응답 규칙 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084080544/original/dowQeUucgO_YBAEVj0LGg9RV6Ngtp9y43w.png?1792767941)**

화면에는 **Only honor these rules**(이 규칙만 따르기) 토글도 있어요. 이 토글이 정확히 어떻게 적용되는지는 확인이 필요해요. 자동 요소 선택을 제한하는 용도로 쓰기 전에 먼저 확인하세요.

## 대화 AI에서 리치 요소 설정하기

리치 요소를 설정하려면 기능을 켜고, 보낼 수 있는 메시지 유형을 고르세요. 필요하면 미디어 URL이나 응답 규칙도 추가하세요. 설정을 잘 마치면 에이전트가 지원되는 채널에서 유용한 대화형 응답을 보낼 수 있어요.

### 1단계: 실험실에서 리치 요소 켜기

에이전트에서 설정하기 전에 먼저 기능을 켜야 해요.

1. 하이퍼클래스 계정에서 **실험실**로 이동하세요.
2. **Conversations AI Rich Elements**(대화 AI 리치 요소)를 찾으세요.
3. 기능을 **켜짐**으로 바꾸세요.

{% hint style="info" %}
문서를 게시하는 시점에도 실험실에서 켜야 하는지 확인이 필요해요.
{% endhint %}

### 2단계: 대화 AI 에이전트 열기

리치 요소는 에이전트의 **Response Behavior**(응답 동작) 설정에서 구성해요.

1. **AI 에이전트 > 대화 AI > 에이전트 목록**으로 이동하세요.
2. 편집할 프롬프트 기반 에이전트를 여세요.
3. **Build**(빌드) 화면에서 **Response Behavior**를 찾으세요.

**![에이전트의 Response Behavior 위치 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084081959/original/XzHB1bXCwACRTTlzbVtAIXQwg6Oi2AlT8A.png?1792768630)**

{% hint style="info" %}
이번 출시에서는 프롬프트 기반 에이전트의 설정 방법만 안내하고 있어요. 다른 유형의 에이전트를 지원하는지는 확인이 필요해요.
{% endhint %}

### 3단계: 리치 요소 켜고 설정하기

에이전트가 보낼 수 있는 대화형 메시지 형식을 고르세요.

1. **Response Behavior**를 펼치세요.
2. **Enable Rich Elements Support**(리치 요소 지원 켜기)를 켜세요.
3. **Allow this bot to send**(이 봇이 보낼 수 있는 항목) 아래에서 다음 요소를 켜거나 끄세요.

   - **Formatted text**(서식 텍스트)
   - **Quick replies**(빠른 답장)
   - **Link button**(링크 버튼)
   - **목록**
   - **이미지**
   - **파일**

응답 규칙을 만들 때는 켜 둔 요소만 선택할 수 있어요.

**![허용할 리치 요소를 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084082134/original/V7GlTSInPIJtuWz_RwJA63RXmK3PvizUzQ.png?1792768690)**

### 4단계: 미디어 URL 추가하기 (선택)

에이전트가 특정 이미지나 파일을 공유하게 하려면, 누구나 접근할 수 있는 URL을 알려 주세요.

1. 에이전트의 프롬프트 편집기를 여세요.
2. 지원되는 이미지나 문서의 URL을 추가하세요.
3. 각 자료가 무엇인지 설명하는 내용을 함께 적으세요.
4. 수정한 프롬프트를 저장하세요.

예시:

매물: 4812 Aldrich Street  
설명: 방 4개, 2대 주차 가능한 차고가 있는 주택  
이미지: `https://example.com/images/4812-aldrich.jpg`  
매물 페이지: `https://example.com/listings/4812-aldrich`

{% hint style="info" %}
미디어 URL은 필수가 아니에요. 지원 형식, 최대 파일 크기, URL 제한은 확인이 필요해요.
{% endhint %}

### 5단계: 응답 규칙 설정하기 (선택)

특정 상황에서 에이전트가 정해진 요소를 쓰게 하려면 규칙을 추가하세요.

1. **Response Behavior** 아래에서 **Setup Your Response Rules**(응답 규칙 설정)를 클릭하세요.
2. **규칙 추가**를 클릭하세요.
3. **Rule Name**을 입력하고 **Situation, in your words**에 상황을 설명하세요.
4. 드롭다운에서 **요소**를 고르세요.
5. **Element supported on** 표시를 확인하세요.
6. 필요하면 규칙을 켠 다음 **Save rules**를 클릭하세요.

예시: 이름이 "매물 방문 예약"인 규칙을 만들고 "연락처가 매물 방문 일정을 잡고 싶다고 하면, 링크 버튼으로 예약 링크를 안내하세요."라고 입력해요. 요소는 **Link button**을 선택해요.

**![응답 규칙 설정 예시 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084082965/original/Nus-VBRzp-YPect-jcpVDoR-MpgCLsj_4w.png?1792768977)**

{% hint style="info" %}
팁: 고객이 쓰는 정확한 문구에 맞추기보다, 상황을 자연스럽게 설명하세요.
{% endhint %}

### 6단계: 저장하고 에이전트 테스트하기

고객이 에이전트와 대화하기 전에 테스트해 보세요. 켜 둔 요소와 응답 규칙이 알맞은 답장을 만드는지 확인할 수 있어요.

1. 설정을 확인한 뒤 에이전트 편집기에서 **저장**을 클릭하세요.
2. **에이전트 테스트하기**를 열고 사용할 수 있는 미리보기 옵션을 선택하세요.
3. 다음과 같은 테스트 메시지를 보내 보세요.

   - "어느 동네를 서비스하나요?"
   - "매물을 보러 가고 싶어요."
   - "볼 수 있는 매물을 보여 주세요."
   - "브로슈어가 있나요?"
4. 에이전트가 알맞은 요소를 쓰고 정확한 정보를 알려 주는지 확인하세요.
5. 비즈니스에서 쓰는 메시징 채널에서도 같은 방법으로 반복하세요.

{% hint style="info" %}
팁: 라이브 채팅 미리보기가 잘 작동해도 다른 메시징 채널에서 똑같이 동작한다고 보장할 수는 없어요.
{% endhint %}

## **자주 묻는 질문**

### 리치 요소마다 응답 규칙이 꼭 있어야 하나요?

아니요. 대화 AI는 켜 둔 요소를 자동으로 골라요. 응답 규칙은 특정 상황에서 추가로 안내하는 용도예요.

### 응답 규칙의 드롭다운에 원하는 요소가 안 보여요.

켜 둔 리치 요소만 선택할 수 있어요. **Response Behavior** 아래의 요소별 토글을 확인하세요.

### 에이전트 프롬프트를 바꾸지 않고 리치 요소를 켤 수 있나요?

네, 가능해요. 프롬프트 수정은 필수가 아니에요. 다만 관련 이미지, 파일, 웹페이지 URL을 추가하면 에이전트가 특정 자료를 공유하는 데 도움이 돼요.

### 리치 요소로 연락처가 보낸 이미지를 분석할 수 있나요?

리치 요소만으로는 안 돼요. 이미지 메시지를 보내는 기능과 받은 이미지를 분석하는 기능은 대화 AI에서 서로 별개예요.

### 응답 규칙은 프롬프트 지침과 다른가요?

네, 달라요. 프롬프트는 전체적인 대화 방식을 안내하고, 응답 규칙은 특정 대화형 메시지 형식을 쓰는 방법을 안내해요.

### 예약 링크 버튼을 누르면 예약이 자동으로 잡히나요?

아니요. 링크 버튼은 연락처를 예약 페이지로 안내해 줄 뿐이에요. 실제 예약은 설정해 둔 예약 기능에 따라 이루어져요.
