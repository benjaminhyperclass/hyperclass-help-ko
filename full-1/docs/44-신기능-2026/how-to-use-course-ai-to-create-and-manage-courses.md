# Course AI로 코스 만들고 관리하기

**Course AI**(코스 AI)를 쓰면 간단한 프롬프트와 가지고 있는 자료로 하이퍼클래스에서 코스를 만들 수 있어요. 코스 개요, 모듈, 강의, 퀴즈, 과제, 이미지를 생성한 뒤 수강생에게 공유하기 전에 원하는 대로 고칠 수 있어요.

이 문서에서는 Course AI로 코스를 만드는 방법과 **코스 빌더**에서 AI 도구를 쓰는 방법을 안내해요.

[동영상](https://jumpshare.com/embed/OvZseH7KhpxFIqvqVlpi)

## Course AI로 코스 만들기

1. **멤버십 > 코스 > 상품**으로 이동하세요.

   ![멤버십 > 코스 > 상품 화면](https://jumpshare.com/share/gMniM7avIpYsmRMsZAbp+/Screenshot+2026-10-14+at+18.12.44.png)
2. **새로 만들기 > 처음부터 시작**을 클릭하면 Course AI가 열려요.

   ![새로 만들기 > 처음부터 시작 선택 화면](https://jumpshare.com/share/ayseAFlJQ7o6aNN14e0Z+/Screen+Shot+2026-10-14+at+18.22.20.png)
3. **Course type**(코스 유형)을 선택하세요.

   - **자기 주도형 기술 코스**
   - **Mini-course / lead magnet**(미니 코스 / 리드 마그넷)
   - **Daily bootcamp / challenge**(데일리 부트캠프 / 챌린지)
   - **자격 인증 프로그램**
   - **Recording library / vault**(녹화 라이브러리 / 보관함)
4. 코스의 주제, 대상 수강생, 수강생이 달성해야 할 목표를 포함해 코스를 설명하세요.
5. 필요하면 이미지, PDF, 공개된 참고 링크를 첨부하세요. 음성 입력도 쓸 수 있어요.
6. 프롬프트를 제출하면 코스 개요가 생성돼요.

   ![코스 개요가 생성되는 화면](https://jumpshare.com/share/CSOQWQKrfdrvISHVpzUf+/GIF+Recording+2026-10-14+at+18.24.01.gif)

## 코스 개요 다듬기

**Course AI Studio**(코스 AI 스튜디오)에서는 왼쪽에 대화, 오른쪽에 실시간 코스 개요가 표시돼요. 코스를 만들기 전에 개요를 먼저 다듬을 수 있어요.

1. 생성된 코스 제목, 설명, 모듈, 강의, 퀴즈를 확인하세요.
2. 채팅으로 수정을 요청하거나, 추천 후속 답변을 선택하세요.
3. 필요에 따라 제목, 모듈, 강의를 편집하거나 삭제하세요.
4. **명확하게**, **다르게 표현**, **구체적으로**, **줄이기** 같은 AI 문장 수정 옵션으로 제목을 다듬으세요.
5. 코스 커버 이미지를 생성하거나 직접 업로드하세요.
6. 개요가 마음에 들면 **확인**을 클릭하세요.

![코스 개요를 다듬는 화면](https://jumpshare.com/share/vdoHnG5xGxHeOZSEJ8hQ+/GIF+Recording+2026-10-14+at+18.39.30.gif)

## 동영상으로 강의 콘텐츠 생성하기

Course AI는 새로 업로드하거나 가져온 강의 동영상을 분석해서, 스크립트를 바탕으로 보조 콘텐츠를 제안해요.

1. 코스를 열고 강의를 선택하세요.
2. 강의 동영상을 업로드하거나 가져오세요.
3. Course AI가 동영상 처리를 마치면 **Course AI** 패널에서 제안을 확인하세요.

   동영상 내용에 따라 다음과 같은 제안이 나올 수 있어요.

   - **강의 설명**: 동영상 요약
   - **Quiz questions**(퀴즈 질문): 강의의 중요한 부분을 바탕으로 만든 질문
   - **다운로드용 PDF 요약**: 수강생이 참고용으로 저장할 수 있는 요약

4. 제안 하나를 쓰려면 해당 제안 옆의 **수락**을, 모든 제안을 쓰려면 **모두 적용**을, 건너뛰려면 **닫기**를 클릭하세요.
5. 화면에 표시되는 저장 또는 게시 옵션으로 변경사항을 저장하세요.

수락한 PDF 요약은 강의의 다운로드 자료에 추가돼요.

{% hint style="info" %}
스크립트를 바탕으로 한 자동 제안은 새로 업로드하거나 가져온 동영상에서만 사용할 수 있어요.
{% endhint %}

## AI로 강의 설명 쓰고 편집하기

Course AI로 강의 설명을 새로 만들거나, 이미 쓴 글을 다듬을 수 있어요.

1. **코스 빌더**에서 강의를 여세요.
2. 강의 설명이 비어 있으면 Course AI로 설명을 생성하세요. 강의 제목이나 사용 가능한 동영상 스크립트를 바탕으로 만들어 줘요.
3. 이미 내용이 있으면 AI **편집** 옵션을 여세요.
4. 직접 수정 지시를 입력하거나 빠른 수정 옵션을 선택하세요.

   - **Rewrite**(다시 쓰기)
   - **더 짧게**
   - **더 길게**
   - **더 전문적으로**
   - **More casual**(더 캐주얼하게)
5. 수정된 설명을 확인하고 **변경사항 저장**을 클릭하세요.

![AI로 강의 설명을 편집하는 화면](https://jumpshare.com/share/x5Kxkvxz64yA6XGdlWbf+/GIF+Recording+2026-10-14+at+19.43.25.gif)

## AI로 퀴즈 질문 생성하기

Course AI는 강의 하나, 모듈 전체, 또는 코스 전체를 바탕으로 퀴즈 질문을 만들 수 있어요.

1. **코스 빌더**에서 퀴즈를 열고 **퀴즈 질문 생성**을 선택하세요.
2. AI가 사용할 원본 콘텐츠를 선택하세요.
3. **질문 유형**을 선택하세요.

   - **단일 선택**
   - **객관식**
   - **Mix**(혼합)
4. 난이도를 **쉬움**, **미디엄**, **어려움** 중에서 선택하세요.
5. **질문 수**를 1~20 사이로 설정하세요.
6. **생성**을 클릭하고 질문을 확인한 뒤 **변경사항 저장**을 클릭하세요.

생성된 질문은 수강생에게 퀴즈를 공개하기 전에 편집할 수 있어요.

![AI로 퀴즈 질문을 생성하는 화면](https://jumpshare.com/share/P06vt37CrB45OovjpGMN+/GIF+Recording+2026-10-14+at+19.50.23.gif)

## AI로 썸네일 생성하기

강의, 퀴즈, 과제에 쓸 썸네일을 AI로 만들 수 있어요.

1. 썸네일을 바꾸려는 강의, 퀴즈, 과제를 여세요.
2. **AI 썸네일** 옵션을 여세요.
3. **원하는 이미지 설명**에 만들고 싶은 이미지를 설명하세요.
4. **스타일**을 선택하세요.

   - **Photographic**(사진 스타일)
   - **Illustrated**(일러스트 스타일)
   - **굵은 텍스트 오버레이**
   - **Minimal**(미니멀)
5. **생성**을 클릭하세요.
6. 이미지를 확인하고 사용할 썸네일을 저장하세요.

![AI 썸네일을 생성하는 화면](https://jumpshare.com/share/B5thNhcWjQrkkHRsaWPc+/GIF+Recording+2026-10-14+at+20.01.18.gif)

## 알아 두면 좋은 점

- 파일 제한: 코스를 만들 때 자료로 파일을 최대 5개까지 첨부할 수 있어요. 파일당 최대 크기는 25MB예요.
- 참고 링크: URL은 공개되어 있어야 하고, AI가 접근할 수 있어야 해요.
- 동영상 처리: 강의 콘텐츠 자동 제안은 새로 업로드하거나 가져온 동영상에서만 작동해요.
- AI 콘텐츠: 생성된 개요, 설명, 퀴즈, 이미지는 확인하고 편집할 수 있어요.
- 직접 만들기: AI 없이 코스를 만들고 싶다면 **Skip and set up manually**(건너뛰고 직접 설정)를 선택하세요.

코스 콘텐츠가 준비되면 코스 설정을 확인하고, 수강생 화면을 미리 본 뒤, 필요한 게시 및 접근 설정을 마무리하세요.
