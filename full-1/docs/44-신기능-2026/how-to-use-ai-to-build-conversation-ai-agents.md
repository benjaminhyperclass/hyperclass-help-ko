# AI로 대화 AI 에이전트 만들기

하이퍼클래스에서는 AI의 도움을 받아 **대화 AI** 에이전트를 빠르게 만들 수 있어요. 에이전트가 할 일을 설명하면 하이퍼클래스가 지침, 설정, 액션을 만들어 줘요. 이후 채팅으로 에이전트를 다듬고, 응답을 테스트한 다음 실제로 운영하면 돼요.

[동영상](https://jumpshare.com/embed/IxyYuq4CItuN8hCMWx6n?disableDownload=true)

## AI로 대화 AI 에이전트 만들기

AI 에이전트 빌더를 쓰면 프롬프트와 액션을 일일이 설정하지 않고, 쉬운 말로 설명해서 에이전트를 만들고 구성할 수 있어요. 처음부터 직접 설명해도 되고, 예약, 리드 확보, 후속 조치, 고객 지원 분야의 템플릿 9개 중에서 골라도 돼요.

AI 빌더가 자동으로 구성해 주는 항목은 다음과 같아요.

- 인바운드 채널과 아웃바운드 트리거
- 근무 시간과 답장 지연 시간
- **예약 부킹**과 담당자 전달(사람이 대화를 넘겨받는 것)
- 지식 베이스 연결
- 에이전트 지침과 첫 인사 메시지

어떤 캘린더를 쓸지, 누구에게 대화를 넘길지처럼 더 필요한 정보가 있으면 AI가 채팅으로 직접 물어봐요.

---

## AI로 에이전트 만드는 순서

AI로 에이전트를 만들 때는 원하는 내용을 설명하고, 생성된 구성을 확인한 다음, 활성화하기 전에 응답을 테스트해요.

1. **설정 > 실험실**로 이동해 **대화 AI: AI로 빌드하기**를 활성화하세요.
2. **AI 에이전트 > 대화 AI > 에이전트 만들기**로 이동하세요.
3. **AI로 만들기**를 선택한 다음 **AI로 시작**을 클릭하세요.

   ![AI로 만들기 선택 후 AI로 시작 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254863/original/iQDgvw7RXVWL-vnGw2bDOxQw9PVua1vtsg.png?1793052894)
4. 에이전트가 할 일을 설명하거나 템플릿을 고른 다음 **Build agent**(에이전트 빌드)를 클릭하세요.

   ![에이전트가 할 일을 설명하거나 템플릿을 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254874/original/PTv33U8gC-ZDodd6znSgZqKBwgYHCV8HOg.png?1793052929)
5. **AI로 빌드하기**가 묻는 질문에 답하세요. 예약에 쓸 캘린더나 대화를 넘겨받을 담당자를 고르는 질문이 나와요.

   ![AI로 빌드하기가 묻는 질문에 답하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254873/original/aIO8S5PHeu_dsyldD4cWc8D2cIeA8mg55w.png?1793052929)
6. 생성된 에이전트의 설정, 지침, 채널, 액션을 확인하세요.

   ![생성된 에이전트의 설정과 지침 확인 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254895/original/WrHzkf684NpWNxDlt8XkHtVdh0DjwFaK-w.png?1793052966)
7. 바꾸고 싶은 내용이 있으면 채팅으로 요청하세요. 근무 시간, 답장 지연 시간, 담당자 전달 설정 등을 조정할 수 있어요.

   ![채팅으로 변경을 요청하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254937/original/76vC1j2oHEE6M-P2dcvPoDM4aRxsZFqejg.png?1793053094)
8. **Test agent**(에이전트 테스트)를 클릭해 인바운드 또는 아웃바운드 대화를 테스트하고, 선택한 채널에서 응답을 미리 확인하세요. 운영할 준비가 되면 **저장**을 클릭하고 알맞은 에이전트 모드를 활성화하세요.

   ![에이전트를 테스트하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254943/original/6su-17JiHZFc8kWdC0yhvKmczMr7YME8lA.png?1793053105)

## 채팅으로 에이전트 수정하기

**AI로 빌드하기**를 쓰면 여러 설정 화면을 오가지 않아도 에이전트의 설정과 지침을 바꿀 수 있어요. 바꾸고 싶은 내용을 말하면 빌더가 지원하는 설정을 자동으로 업데이트해 줘요.

예를 들어 이렇게 요청할 수 있어요.

- "월요일부터 토요일까지, 오전 9시부터 오후 8시까지만 답장해 줘."
- "부재중 전화 트리거를 추가해 줘."
- "가격 문의는 영업 매니저에게 보내 줘."
- "첫 인사 메시지를 더 친근하게 바꿔 줘."
- "답장하기 전에 5초 기다려 줘."

에이전트의 지침을 다시 쓰거나, 목표를 바꾸거나, 첫 인사 메시지를 수정해 달라고 요청할 수도 있어요.

![채팅으로 에이전트 설정을 수정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084254909/original/cfaLJ-PQKBWBH5n0EmQH_LjewGc-iJrbtQ.png?1793053005)

## AI로 빌드하기와 수동 편집기 전환하기

에이전트 구성을 더 세밀하게 다루고 싶을 때는 **AI로 빌드하기**와 수동 편집기를 오갈 수 있어요.

설정과 지침을 직접 편집하려면 **Switch to manual editor**(수동 편집기로 전환)를 클릭하세요. 다시 대화로 수정하려면 수동 편집기에서 **AI로 빌드하기**를 클릭하세요.

{% hint style="warning" %}
에이전트를 만들거나 저장해도 자동으로 활성화되지는 않아요. 알맞은 모드로 에이전트를 활성화해야 하고, 아웃바운드 메시지가 필요하다면 따로 활성화해야 해요.
{% endhint %}
