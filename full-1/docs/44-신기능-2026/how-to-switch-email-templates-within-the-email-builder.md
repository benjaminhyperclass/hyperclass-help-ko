# 이메일 빌더에서 이메일 템플릿 바꾸기

이메일 빌더를 나가지 않고도 다른 템플릿으로 바꿀 수 있어요. 템플릿 라이브러리를 열어 디자인을 둘러본 뒤, 작업 중인 이메일에 다른 템플릿을 적용하세요. 이메일에 이미 내용이 있으면 교체 전에 확인 창이 나와요. 이 문서에서는 템플릿을 바꾸는 방법과 기존 내용이 어떻게 되는지 안내해요.

## 이메일 템플릿 전환의 장점

- 나가지 않고 템플릿 전환: 편집기를 떠나지 않고 이메일 빌더에서 바로 템플릿 라이브러리를 열어 다른 디자인을 고를 수 있어요.
- 다양한 디자인 탐색: 이메일을 작업하면서 사용할 수 있는 이메일 템플릿을 둘러보거나 검색할 수 있어요.
- 이메일 제작 시간 절약: 빌더를 나가 다른 템플릿을 고르고 편집기를 다시 여는 과정을 반복하지 않아도 돼요.
- 작업 중 디자인 변경: 이메일 작업을 시작한 뒤에도 다른 템플릿을 고를 수 있어요.
- 내용 교체 전 확인: 이미 내용이 있는 이메일을 교체하기 전에 확인 창을 볼 수 있어요.

## 이메일 빌더에서 이메일 템플릿 바꾸기

### 1단계: 이메일 빌더 열기

1. **서브 계정** 화면의 왼쪽 메뉴에서 **마케팅**을 클릭하세요.
2. **이메일**을 선택하세요.
3. **템플릿**을 클릭하세요.
4. 편집할 이메일 템플릿을 찾으세요.
5. 템플릿을 클릭해 **이메일 빌더**에서 여세요.

### 2단계: 템플릿 라이브러리 열기

**이메일 빌더**에 들어가면 새로 생긴 템플릿 전환 아이콘으로 사용할 수 있는 디자인을 볼 수 있어요.

1. **이메일 빌더**에서 템플릿 전환 아이콘을 찾으세요.
2. 아이콘을 클릭하세요.
3. 기존 **템플릿 라이브러리** 창이 열려요.

### 3단계: 템플릿 둘러보기 또는 검색하기

**템플릿 라이브러리**에서 디자인을 먼저 살펴본 뒤 적용할 템플릿을 고를 수 있어요.

1. **템플릿 라이브러리**에 표시된 템플릿을 둘러보세요.
2. 특정 템플릿을 찾으려면 검색창을 사용하세요.
3. 이메일에 사용할 템플릿을 선택하세요.

### 4단계: 현재 템플릿 교체하기

다른 템플릿을 선택하면 **템플릿 라이브러리**에서 바로 현재 이메일에 적용할 수 있어요.

1. 원하는 템플릿을 선택하세요.
2. **교체**를 클릭하세요.
3. 현재 이메일에 이미 내용이 있으면 확인 창을 읽어 보세요.
4. 교체를 확인하고 진행하세요.

교체가 끝나면 선택한 템플릿이 이메일 캔버스에 나타나요.

1. 새로 적용된 템플릿을 살펴보세요.
2. 내용과 디자인이 원하던 대로인지 확인하세요.
3. **이메일 빌더**의 도구를 사용해 이메일 편집을 이어 가세요.

## 템플릿 교체 시 알아둘 점

### 이메일에 이미 내용이 있을 때

이메일 캔버스에 내용이 있으면 하이퍼클래스에서 선택한 템플릿을 적용하기 전에 확인을 요청해요.

1. **템플릿 라이브러리**에서 다른 템플릿을 선택하세요.
2. **교체**를 클릭하세요.
3. 확인 창을 읽어 보세요.
4. 교체를 확인하면 선택한 템플릿이 적용돼요.

확인하면 선택한 템플릿이 기존 캔버스 내용을 대신해요.

### 이메일에 내용이 없을 때

현재 이메일 캔버스에 내용이 없으면 템플릿을 선택하고 **교체**를 클릭해 바로 적용하세요.

## 자주 묻는 질문

### 이메일 빌더를 나가지 않고 이메일 템플릿을 바꿀 수 있나요?
네, 할 수 있어요. 새로 생긴 템플릿 전환 기능으로 **템플릿 라이브러리**를 열고 다른 템플릿을 선택해 적용할 수 있어요. 빌더를 나갈 필요가 없어요.

### 라이브러리 전체를 둘러보지 않고 템플릿을 검색할 수 있나요?
네, 할 수 있어요. **템플릿 라이브러리**에서는 템플릿을 둘러보거나 검색할 수 있어요.

### 템플릿을 바꾸면 기존 이메일 내용은 어떻게 되나요?
다른 템플릿을 적용하면 이메일 캔버스에 있던 내용이 교체돼요. 이미 내용이 있으면 하이퍼클래스에서 교체 여부를 확인해요.

### 다른 템플릿을 쓰려면 이메일을 처음부터 다시 만들어야 하나요?
아니요. 나가서 처음부터 다시 시작하지 않고 **이메일 빌더**에서 바로 다른 템플릿으로 바꿀 수 있어요.
