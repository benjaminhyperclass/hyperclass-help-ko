# SaaS 멀티 브랜드의 알림 이메일 도메인 설정

브랜드마다 알림 이메일 도메인을 따로 설정하면, 고객에게 가는 이메일에서 일관되고 전문적인 발신자 이미지를 유지할 수 있어요. 이 문서에서는 SaaS 브랜드별 알림 도메인을 설정하고 인증하는 방법을 안내해요.

## 이 문서에서 알려 드리는 내용

이 문서는 SaaS 멀티 브랜드 관리(SaaS Multi-Brand Management)를 쓰는 브랜드의 전용 알림 이메일 도메인을 설정하고, 인증하고, 관리하는 방법을 설명해요.

브랜드별 알림 도메인이 어떻게 동작하는지, 어떻게 설정하는지, 브랜드에 알림 도메인이 없으면 어떻게 되는지 알 수 있어요.

## SaaS 멀티 브랜드 관리란?

SaaS 멀티 브랜드 관리를 쓰면 에이전시가 SaaS 계정 하나에서 **독립된 브랜드를 최대 2개**까지 운영할 수 있어요.

브랜드마다 설정과 브랜딩을 따로 둘 수 있어서, 하나의 계정에서 모든 것을 관리하면서도 브랜드별로 다른 경험을 줄 수 있어요.

- SaaS 브랜드를 최대 2개까지 관리해요.
- 브랜드마다 알림 이메일 도메인을 따로 설정해요.
- 두 브랜드를 한 화면에서 함께 관리해요.

### 알림 이메일 도메인이 중요한 이유

알림 이메일도 고객 경험의 일부예요. 여러 브랜드가 같은 발신 도메인을 쓰면, 고객이 알고 있는 브랜드와 다른 이름으로 시스템 알림을 받을 수 있어요.

브랜드별 알림 이메일 도메인을 쓰면 브랜드마다 자기 발신 도메인을 사용하므로, 고객이 알아보기 쉬운 발신자 이미지를 유지할 수 있어요.

---

## 브랜드별 알림 도메인의 동작 방식

SaaS 브랜드마다 알림 이메일 도메인을 따로 둘 수 있어요. 설정 위치는 **에이전시 설정 > 이메일 서비스 > Dedicated Domain and IP**(전용 도메인 및 IP) **> Notification Section**(알림 섹션)이에요.

| 브랜드 설정 | 알림 이메일에 사용하는 도메인 |
| --- | --- |
| 브랜드에 알림 도메인이 있어요 | 그 브랜드에 설정한 알림 도메인 |
| 브랜드에 알림 도메인이 없어요 | 기본 브랜드의 알림 도메인 |

{% hint style="warning" %}
**중요:** 브랜드에 알림 이메일 도메인을 설정하지 않으면, 그 브랜드의 시스템 알림은 기본 브랜드의 알림 도메인으로 발송돼요.

발신자 이미지를 브랜드별로 나누려면 브랜드마다 알림 도메인을 설정하세요.
{% endhint %}

---

## 시작하기 전에

아래 항목을 먼저 확인하세요.

- SaaS 멀티 브랜드 관리: 에이전시가 멀티 브랜드 관리를 사용 중이어야 해요. 브랜드는 최대 2개까지 지원해요.
- 설정된 브랜드: 설정하려는 브랜드가 SaaS 계정에 이미 있어야 해요.
- 도메인 또는 서브도메인: 브랜드마다 쓸 도메인이나 서브도메인을 준비하세요. 예를 들면 `notify.brandname.com`이에요.
- DNS 접근 권한: 필요한 레코드를 등록할 수 있도록, 각 도메인의 DNS 제공업체에 접속할 수 있어야 해요.

제공 대상: 브랜드별 알림 이메일 도메인은 SaaS 멀티 브랜드 관리를 쓰는 에이전시에서 사용할 수 있어요.

## 브랜드의 알림 도메인 설정하기

아래 순서대로 브랜드마다 알림 이메일 도메인을 설정하세요.

### 1단계: 이메일 서비스 열기

1. 하이퍼클래스 에이전시 계정에 로그인하세요.
2. **에이전시 보기**를 여세요.
3. **설정 > 이메일 서비스**로 이동하세요.
4. **Dedicated Domain and IP**를 여세요.

### 2단계: 알림 섹션 찾기

**Notification Section**까지 스크롤하세요.

이 섹션에서는 SaaS 브랜드별 알림 도메인 설정과 인증 상태를 확인할 수 있어요.

설정할 브랜드를 찾기 어려우면 **브랜드** 필터가 보일 때 사용해 보세요.

![알림 섹션 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155084206008/original/KFCgT_LJopgCe34S8kadteOr7X8bICx1WA.png?1793019110)

### 3단계: 알림 도메인 추가하기

1. 알림 이메일 도메인이 필요한 브랜드를 찾으세요.
2. **도메인 추가**를 선택하세요.
3. 도메인 설정 화면으로 이동하세요.

### 4단계: 도메인 입력하기

선택한 브랜드에서 쓸 도메인이나 서브도메인을 입력하세요.

예: `notify.brandname.com`

그다음 DNS 설정 단계로 넘어가세요.

### 5단계: DNS 레코드 설정하고 인증하기

1. 도메인 설정 중에 표시되는 DNS 레코드를 복사하세요.
2. 도메인의 DNS 제공업체를 여세요.
3. 표시된 대로 필요한 DNS 레코드를 추가하세요.
4. 하이퍼클래스로 돌아오세요.
5. 도메인 인증을 완료하세요.

DNS 변경 사항이 적용되기까지 시간이 걸릴 수 있어요. 인증에 실패하면 DNS 레코드가 요구하는 값과 일치하는지 확인하세요.

### 6단계: 도메인 설정 확인하기

**Notification Section**으로 돌아와 브랜드의 알림 도메인을 확인하세요.

다음 내용을 확인하세요.

- 브랜드에 올바른 알림 도메인이 연결되어 있어요.
- 도메인 인증 상태가 인증 성공으로 표시돼요.

**설정이 끝났어요!**

도메인을 설정하고 인증하면, 그 브랜드의 시스템 알림 이메일이 해당 알림 도메인으로 발송돼요.

고유한 발신자 이미지가 필요한 다른 브랜드에도 같은 순서를 반복하세요.

---

## 알림 섹션 이해하기

**Notification Section**은 SaaS 브랜드의 알림 이메일 도메인을 한곳에서 관리하는 곳이에요.

여기에서 할 수 있는 일은 다음과 같아요.

- 브랜드별로 설정된 알림 도메인을 확인해요.
- 도메인 인증 상태를 확인해요.
- 알림 도메인이 없는 브랜드를 찾아요.
- 알림 도메인을 브랜드별로 따로 인증해요.
- 브랜드의 기존 알림 도메인을 변경해요.
- 브랜드의 알림 도메인을 제거해요.

---

### 도메인 설정이 각 브랜드에 미치는 영향

| 설정 | 동작 |
| --- | --- |
| 브랜드에 알림 도메인이 설정되어 있어요 | 시스템 알림 이메일이 그 브랜드의 도메인으로 발송돼요. |
| 브랜드에 알림 도메인이 설정되어 있지 않아요 | 알림 이메일이 기본 브랜드의 알림 도메인으로 발송돼요. |
| 브랜드의 알림 도메인에 인증이 필요해요 | 인증 상태를 확인하고 필요한 설정을 마치세요. |

### 알림 도메인을 브랜드별로 따로 관리하기

브랜드마다 알림 도메인 설정은 서로 독립적으로 관리돼요.

한 브랜드의 알림 도메인을 인증하거나 변경하거나 제거해도 다른 브랜드의 설정은 바뀌지 않아요.

{% hint style="info" %}
**팁:** 브랜드마다 알림 이메일 발신자를 따로 두려면, 각 브랜드에 알림 도메인을 설정하고 인증하세요.
{% endhint %}

## 자주 묻는 질문

### 알림 이메일 도메인을 따로 둘 수 있는 브랜드는 몇 개인가요?

SaaS 멀티 브랜드 관리는 브랜드를 최대 2개까지 지원해요. 각 브랜드가 자기 알림 이메일 도메인을 가질 수 있어요.

### 브랜드에 알림 이메일 도메인이 없으면 어떻게 되나요?

그 브랜드의 시스템 알림 이메일은 기본 브랜드의 알림 도메인으로 발송돼요.

발신자 이미지를 따로 유지하려면 그 브랜드에 알림 도메인을 설정하세요.

### 브랜드마다 다른 도메인을 설정할 수 있나요?

네. 브랜드마다 알림 이메일 도메인을 독립적으로 설정할 수 있어서, 브랜드별로 다른 도메인이나 서브도메인을 쓸 수 있어요.

### 알림 이메일에 서브도메인을 쓸 수 있나요?

네. 브랜드에 도메인이나 서브도메인(예: notify.brandname.com)을 설정할 수 있어요.

### 알림 이메일 도메인은 어디에서 설정하나요?

**에이전시 설정 > 이메일 서비스 > Dedicated Domain and IP > Notification Section**으로 이동하세요.

### 이미 설정한 알림 도메인을 변경하거나 제거할 수 있나요?

네. 알림 도메인을 브랜드별로 따로 변경하거나 제거할 수 있어요.

### 알림 도메인이 인증됐는지 어떻게 확인하나요?

**Dedicated Domain and IP**의 **Notification Section**을 열면 브랜드별 도메인 인증 상태를 볼 수 있어요.

### 도메인 인증이 안 될 때는 어떻게 하나요?

필요한 DNS 레코드를 DNS 제공업체에 추가했는지, 그리고 값이 설정 중에 안내받은 레코드와 일치하는지 확인하세요.

DNS 변경 사항이 적용될 때까지 시간을 두고, 도메인 인증 상태를 다시 확인하세요.

### 한 브랜드의 알림 도메인을 바꾸면 다른 브랜드에도 영향이 있나요?

아니요. 알림 도메인 설정은 브랜드별로 독립적으로 관리돼요.

### 모든 브랜드에 알림 도메인을 설정해야 하나요?

모든 브랜드에 별도 도메인을 설정해야 하는 것은 아니에요. 다만 자체 알림 도메인이 없는 브랜드는 기본 브랜드의 알림 도메인을 사용해요.

발신자 이미지를 브랜드별로 나누려면 브랜드마다 알림 도메인을 설정하세요.
