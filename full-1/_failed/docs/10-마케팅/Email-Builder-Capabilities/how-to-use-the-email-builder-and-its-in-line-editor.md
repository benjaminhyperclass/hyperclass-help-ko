# 이메일 빌더와 인라인 편집기 사용하기

하이퍼클래스 **이메일 빌더**는 드래그 앤 드롭 방식으로 템플릿과 캠페인용 이메일을 만들고 꾸미는 시각 편집기예요. 이 문서에서는 화면 구성, 이메일 내용 꾸미기, 발송 전 디자인 확인 방법을 안내해요.

텍스트, 이미지, 버튼 같은 콘텐츠 요소를 추가하고, 캔버스에서 바로 서식을 고치고, 연락처 정보로 메시지를 개인화할 수 있어요. 레이아웃, 모바일 서식, 미리보기, 고급 편집 옵션도 제공해서 독자에게 보낼 이메일을 준비하기 쉬워요.

## 이메일 빌더 인라인 편집기란?

**이메일 빌더**는 코드를 쓰지 않고도 이메일 템플릿과 캠페인을 만들 수 있는 시각 디자인 도구예요. 인라인 편집기는 WYSIWYG(What You See Is What You Get, 보이는 대로 편집되는 방식)로 동작해요. 이메일 캔버스에서 서식을 바로 바꾸고 결과를 즉시 확인할 수 있어요.

예를 들어 텍스트를 선택해 글꼴이나 색상을 바꾸고, 버튼을 넣어 행동을 유도하고, 이미지를 넣어 메시지를 보강할 수 있어요.

**이메일 빌더**에서는 콘텐츠 편집, 레이아웃 조정, 개인화, 미리보기 도구를 한 작업 공간에서 모두 쓸 수 있어요.

- 위쪽 여백: 12
- 아래쪽 여백: 12
- 왼쪽 여백: 24
- 오른쪽 여백: 24

## 이메일 빌더 인라인 편집기의 장점

- 시각적 일관성: 모든 이메일에 같은 기본 여백(위쪽 12, 아래쪽 12, 왼쪽 24, 오른쪽 24)을 적용해 통일된 느낌을 유지할 수 있어요.
- 다양한 글꼴 지원: Arial, Georgia, Verdana 등 여러 글꼴을 지원해서 이메일 스타일을 브랜드에 맞출 수 있어요. 예를 들어 브랜드가 Helvetica를 쓴다면 이메일에도 같은 글꼴을 써서 일관성을 지킬 수 있어요.
- 세밀한 텍스트 스타일: 굵게, 기울임, 밑줄, 취소선으로 텍스트 모양을 다듬을 수 있어요. 중요한 내용을 굵게 또는 기울여서 눈에 띄게 할 수 있어요.
- 유연한 색상 지정: 헥스 코드로 텍스트 색상과 강조 색상을 정확하게 지정할 수 있어요. 브랜드 색상이 #AFAFAF라면 이메일 텍스트나 강조 표시에 그 색을 그대로 쓸 수 있어요.
- 하이퍼링크 추가: 단어나 문구에 링크를 걸어 독자가 관련 콘텐츠로 바로 이동하게 할 수 있어요. 예를 들어 상품명에 웹사이트의 상품 페이지 링크를 걸 수 있어요.
- AI 콘텐츠 작성 지원: **콘텐츠 AI**로 콘텐츠를 더 빠르게 만들 수 있어서 이메일을 쓰고 고치는 시간이 크게 줄어요. 처음 입력한 내용을 바탕으로 텍스트를 제안해 주기도 해요.
- 텍스트 서식 정리: 다른 곳에서 복사해 붙여 넣을 수 있어요. 텍스트 서식 기능을 누르면 기존 스타일이 제거돼요. 문서에서 가져온 텍스트에 이메일 스타일을 새로 입히고 싶을 때 편해요.

**요소 추가** 버튼으로 텍스트와 이미지부터 더 복잡한 구조까지 새 콘텐츠를 이메일에 넣을 수 있어요.

![Manage Elements 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083971277/original/ZMtGs31uhu9wtTTG4RLmMGj7y5cV54WjjA.png?1792674267)

### 요소 추가

**요소 추가** 버튼을 누르면 이메일에 넣을 수 있는 콘텐츠 유형 목록이 나와요. 각 요소는 다음과 같아요.

#### **문자**

제목, 본문, 캡션 등 다양하게 쓸 수 있는 요소예요. 인라인 편집기로 글꼴 스타일, 색상, 정렬까지 텍스트의 모든 부분을 세밀하게 고칠 수 있어요. 제목 텍스트(H1~H4)는 제목을 선택한 뒤 도구 모음의 **굵게**(B) 버튼으로 굵게 서식을 켜고 끌 수 있어요. 제목 수준은 그대로 유지돼요.

#### **이미지**

사진, 그래픽 등 시각 콘텐츠를 넣고 싶다면 **이미지** 요소를 쓰세요. 컴퓨터에서 이미지를 바로 올리거나 외부 주소로 연결할 수 있어요.

![이미지 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083971802/original/hPXdzHVEHB6HSwSoya7ctuJ-BtikcUQGFA.png?1792674449)

- **Image Upload**(이미지 업로드): 내 기기에서 이미지를 바로 올려요. 최대 업로드 크기는 10MB이고, 고해상도 사진도 올릴 수 있어요.
- **이미지 URL**: 외부 이미지나 **미디어 라이브러리**의 이미지를 연결할 수 있어요. 입력란에 이미지 URL을 붙여 넣으세요.
- **대체 텍스트**: 화면 낭독기를 쓰는 수신자나 이미지가 표시되지 않을 때를 위해 이메일 접근성을 높여 줘요. 이 필드에 이미지를 짧고 명확하게 설명하세요.
- **Link**(링크, 선택 사항): 이미지를 눌렀을 때 특정 URL로 이동하게 하려면 링크 필드에 주소를 입력하세요.
- **Width**(너비)와 **높이**: 이미지 크기를 조절해요. 픽셀 값을 직접 입력하거나 **높이와 너비를 자동으로 설정**을 체크하면 이미지 원본 비율에 맞춰 자동으로 크기가 정해져요.
- **여백**: 이미지 주변 공간을 조절해요. 디자인에 맞게 위, 아래, 왼쪽, 오른쪽 여백을 각각 설정하세요.
- **정렬**: 이미지 정렬을 정해요. 예를 들어 **중앙**을 고르면 이미지가 해당 영역의 가운데에 놓여요. **왼쪽**, **오른쪽** 정렬도 있어요.

## 유연한 편집 레이아웃 (왼쪽/오른쪽 패널)

편집 패널을 **오른쪽**에 두거나 다시 왼쪽으로 옮길 수 있어요. 특히 **이메일 AI**와 직접 편집을 나란히 쓸 때 작업이 더 효율적이에요.

패널을 오른쪽에 두면 작업 공간이 자연스럽게 나뉘어서, 도구보다 결과물에 집중하며 빠르게 수정을 반복할 수 있어요.

사전 조건: 편집기에서 **이메일 AI**와 패널 전환 버튼이 보이려면 에이전시 **실험실** 설정의 서브 계정 기능에서 **이메일 AI**를 켜야 해요. 이 설정은 에이전시 관리자만 할 수 있어요.

패널 위치를 바꾸는 방법은 다음과 같아요.

1. **마케팅 > 이메일**을 열고, 캠페인이나 템플릿을 편집 모드로 엽니다.
2. AI를 나란히 쓰려면 **이메일 AI**를 켭니다.
3. 편집기의 패널 전환 버튼을 눌러 패널을 **오른쪽**에 두거나 **왼쪽**으로 옮깁니다.
4. **이메일 AI**와 캔버스를 함께 보면서 계속 편집합니다.

#### **버튼**

**버튼** 요소로 독자의 반응을 이끌어 낼 수 있어요. 웹페이지로 연결하거나, 다운로드를 시작하거나, 클릭으로 실행되는 다른 동작을 연결할 수 있어요.

![버튼 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000350397/original/6V5iTscJ-FxQ-PhxDD4BllEydRiK07y0fg.png?1685715704)

![버튼 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972172/original/r2BMhujPK3i4qyeZPOGwRYUv3oBkK9Snaw.png?1792674666)

- **버튼 텍스트**: 버튼에 표시할 문구를 입력해요. 예를 들어 소셜 미디어 페이지로 안내하려면 'Follow Me'라고 쓸 수 있어요.
- **글꼴**과 **크기**: 이메일 분위기에 맞는 글꼴과 크기를 고르세요. 예를 들어 'Arial' 14 크기로 하면 깔끔하고 읽기 쉬워요.
- **글꼴 색상**: 버튼 텍스트 색상을 정해요. 색상은 '#ffffff'(흰색)처럼 헥스 코드로 지정해요.
- **작업**: 버튼을 눌렀을 때 실행할 동작을 정해요.
  - **URL**: 가장 흔한 버튼 동작이에요. 수신자를 특정 웹페이지로 보내요. 버튼에 연결할 페이지의 URL을 입력하세요.
  - **Mail**(메일): 수신자의 기본 이메일 앱을 열어 새 이메일을 쓰게 해요. 받는 사람 이메일 주소를 미리 지정할 수 있어요.
  - **File Download**(파일 다운로드): 버튼으로 파일 다운로드를 시작하게 할 때 골라요. 파일의 직접 다운로드 URL을 입력해야 해요.
  - **Telephone**(전화): 모바일 사용자에게 유용해요. 수신자가 버튼을 누르면 입력한 번호로 전화를 걸어요.
  - **Other**(기타): 위 항목에 없는 동작이 필요할 때 골라요.
- **정렬**: 버튼 정렬을 정해요. **왼쪽**, **중앙**, **오른쪽** 중에서 고를 수 있어요.
- **Total Width**(전체 너비): 버튼이 영역의 전체 너비를 차지하게 하려면 이 옵션을 켜세요.
- **배경 색상**: 버튼 배경 색을 정해요. 글꼴 색상처럼 헥스 코드로 지정해요. 예를 들어 '#000000'이면 검은색 배경이 돼요.

##### 색상 필드에서 커스텀 값 사용 (실시간 반영)

색상 입력란(예: **배경 색상**, **본문 색상**, **버튼 색상**)에 **커스텀 값**을 쓸 수 있어요.

커스텀 값 토큰을 입력하면 빌더가 캔버스에 색상을 바로 적용해요. 색상이 바뀌었는지 확인하려고 **미리보기 모드**로 전환하지 않아도 돼요.

![색상 필드의 커스텀 값 입력](https://jumpshare.com/share/kYtmv6GLLOVU3mU1dAEF+/Screen+Shot+2026-02-09+at+10.20.52+PM.png)

- **모서리 둥글기**: 버튼 모서리의 둥근 정도를 조절해요. 숫자가 클수록 더 둥글어져요. 예를 들어 75로 설정하면 알약 모양이 돼요.
- **여백**: 버튼 텍스트와 버튼 테두리 사이의 간격을 위, 아래, 왼쪽, 오른쪽 값으로 각각 조절해요.

이 설정들로 이메일 전체 분위기와 어울리면서 수신자의 행동을 이끄는 버튼을 만들 수 있어요.

#### **구분선**

**구분선** 요소로 이메일의 섹션을 깔끔하게 나눌 수 있어요. 색상, 너비, 스타일을 디자인에 맞게 바꾸세요.

![구분선 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000352270/original/FoW90aoQ7s2aNo1N77LXlKdAAKRz92OyTg.png?1685717171)

![구분선 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972338/original/_7bpvE0iXY3DsoFPcMw_IZpINsq_mvCWhQ.png?1792674733)

- **높이**: 구분선의 두께를 정해요. 숫자가 클수록 선이 두꺼워져요. 예를 들어 '2'로 하면 적당히 두꺼운 선이 돼요.
- **Width (%)**(너비(%)): 구분선이 영역 안에서 가로로 차지하는 범위예요. 영역 너비에 대한 비율로 입력해요. 예를 들어 '100'이면 영역 전체 너비를 차지해요.
- **선 유형**: 구분선의 모양을 골라요. 보통 **Solid**(실선), **파선**, **점선** 중에서 고를 수 있어요.
- **정렬**: 구분선 정렬을 정해요. **왼쪽**, **중앙**, **오른쪽** 중에서 고르세요.
- **색상**: 구분선 색을 헥스 코드로 지정해요. 예를 들어 '#FED7E2'는 연한 분홍색 구분선이에요.
- **여백**: 구분선과 다른 요소 사이의 간격을 조절해요. 구분선의 위, 아래, 왼쪽, 오른쪽 여백을 각각 다르게 설정할 수 있어요.

#### **소셜**

수신자가 내 소셜 미디어 프로필을 방문하게 하고 싶나요? **소셜** 요소로 여러 소셜 미디어 플랫폼에 연결된 아이콘을 쉽게 넣을 수 있어요.

![소셜 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000355754/original/OAqzqxv2N193IKidWKf7jJNKbEwI046now.png?1685719574)

![소셜 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972524/original/u2Ndt7sqZ75Il0GSQbYFSKV-3kD3seI2Ag.png?1792674797)

- **Social Items**(소셜 항목): 사용할 소셜 미디어 플랫폼을 추가해요. 보통 Facebook, Instagram, Twitter 아이콘을 추가할 수 있어요. 플랫폼을 누르고 계정 이름이나 프로필 URL을 입력하세요.
- **아이콘 스타일**: 소셜 아이콘의 모양을 정해요. 이메일 분위기에 맞는 스타일, 모양, 디자인을 고를 수 있어요.
- **표시**: 아이콘을 어떻게 표시할지 골라요. **아이콘**, **문자**, **Icon and Text**(아이콘과 문자) 중에서 고를 수 있어요.
- **정렬**: 이메일 안에서 아이콘 정렬을 조절해요. **왼쪽**, **중앙**, **오른쪽**으로 맞출 수 있어요.
- **글꼴**: 아이콘과 함께 나오는 플랫폼 이름의 글꼴을 정해요. **Icon and Text** 표시를 쓰면 이 글꼴이 문자에 적용돼요.
- **글꼴 색상**: 소셜 아이콘 색상을 헥스 코드로 지정해요. 예를 들어 '#00a4bd'는 청록색이에요.
- **크기**: 아이콘이 잘 보이되 너무 튀지 않게 크기를 조절해요.
- **스페이스**: 소셜 아이콘 사이의 간격을 정해요.
- **여백**: 소셜 아이콘과 다른 요소 사이의 간격을 조절해요. 소셜 아이콘 영역의 위, 아래, 왼쪽, 오른쪽 여백을 각각 다르게 설정할 수 있어요.

이 값들을 알맞게 설정하면 소셜 미디어 채널을 이메일에 자연스럽게 녹여서, 수신자가 쉽게 연결할 수 있어요.

![푸터 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000366980/original/I8-suzLj0ciFDn4J-wwsA8DnAea7yib-_Q.png?1685734315)

- 텍스트 편집: 푸터 텍스트를 누르면 인라인 편집기가 켜져요. 필요에 맞게 텍스트를 바꾸세요. 회사 주소, 개인정보처리방침 링크, 수신 거부 링크를 푸터에 직접 입력할 수 있어요.
- 글꼴과 스타일: 인라인 편집기로 푸터 텍스트의 글꼴, 크기, 색상을 바꿀 수 있어요. 바꿀 텍스트를 드래그해서 선택하고 편집 도구 모음의 옵션을 고르세요. 굵게, 기울임, 밑줄, 취소선도 쓸 수 있어요.
- 링크: 인라인 편집기로 푸터에 하이퍼링크를 쉽게 넣을 수 있어요. 링크로 만들 텍스트를 선택하고 도구 모음의 링크 아이콘을 눌러 URL을 입력하세요. 회사 웹사이트나 서비스 이용약관, 개인정보처리방침 같은 특정 페이지로 연결할 때 편리해요.
- 정렬과 간격: 디자인에 맞게 텍스트를 왼쪽, 오른쪽, 가운데로 정렬하세요. 줄 간격도 조절해서 푸터 텍스트를 읽기 쉽고 깔끔하게 보이게 할 수 있어요.

![동영상 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367283/original/p-LoL9bxbUTDuCFcYZBfUhLyq5Jo-Vd24Q.png?1685735283)

- **Play Button Opacity**(재생 버튼 불투명도): 재생 버튼이 얼마나 잘 보일지 조절해요. 디자인에 맞게 더 투명하게 또는 더 선명하게 만들 수 있어요.
- **여백**: 동영상 플레이어 주변 공간이에요. 위, 아래, 왼쪽, 오른쪽 여백을 조절해서 이메일 레이아웃에 동영상을 알맞게 맞추세요.

#### **Shopping Cart**(장바구니)

이커머스 업종이라면 **Shopping Cart** 요소로 상품 정보, 가격, 온라인 스토어 직접 링크를 넣을 수 있어요. 고객이 관심을 보인 상품을 다시 알려 주고 구매를 마무리하도록 유도하는 방법이에요.

![Shopping Cart 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367318/original/qXhlqMqV0wHc3GbUJrkKJCF_xEgcQMdQrQ.png?1685735372)

![Shopping Cart 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083972957/original/gx7kkiSt2FNsVDw6kg61TeSk1XBLMjhG9w.png?1792674941)

이 영역은 다음과 같이 설정해요.

- **여백**: 장바구니 콘텐츠 주변 공간을 조절해서 이메일의 다른 섹션과 시각적으로 구분해요. 장바구니 영역의 위, 아래, 왼쪽, 오른쪽 여백을 조절할 수 있어요.
- **글꼴**: 장바구니 텍스트의 글꼴을 골라요. 시스템 기본 글꼴이나 이메일 디자인과 어울리는 다른 스타일을 쓸 수 있어요.
- **텍스트 색상**: 장바구니 텍스트 색상을 정해요. 검은색(#000)이나 이메일 디자인에 맞는 다른 색을 쓸 수 있어요.
- **배경 색상**: 장바구니 배경 색을 골라요. 흰색(#ffffff)이나 텍스트가 잘 읽히는 다른 색을 쓸 수 있어요.

**Shopping Cart** 요소에는 보통 상품마다 다음 정보를 표시해요.

- **상품명**: 웹사이트나 온라인 스토어에 표시되는 상품 이름이에요.
- **가격**: 상품 한 개의 가격이에요.
- **수량**: 고객이 선택한 해당 상품의 개수예요.
- **Line Price**(항목 가격): 해당 항목의 총 가격이에요(가격 × 수량).

장바구니에 담긴 상품마다 같은 방식으로 반복해서 설정하세요. 이렇게 자세한 정보를 보여 주면 고객이 주문 내용을 투명하게 확인할 수 있어서 결제 단계로 넘어갈 가능성이 높아져요.

이렇게 **Shopping Cart** 영역을 설정하면 사용자 경험이 좋아지고, 이메일 전체 디자인과 조화를 이루며, 결국 전환을 높이는 데 도움이 돼요.

#### **RSS Header**

이메일 빌더의 **RSS Header** 블록은 RSS 피드의 `<channel>` 태그 내용을 이메일 캠페인에 자동으로 채워 줘요.

![RSS Header 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367385/original/rRmv-SVDKBIg7IL4acN83y3pI5ggciO17w.png?1685735522)

![RSS Header 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083973043/original/Gpzoljdp-RjIIXK5xMuqG_1lCvV84Coccw.png?1792674978)

쓸 수 있는 태그와 해당하는 커스텀 값은 다음과 같아요.

- `<title>` → `{{rss_feed.title}}`
- `<description>` → `{{rss_feed.description}}`
- `<link>` → `{{rss_feed.url}}`
- `<lastBuildDate>` → `{{rss_feed.date}}`

**RSS Header** 블록에서는 **기본**과 **사용자 지정** 중에서 고를 수 있어요.

**기본**을 고르면 텍스트 편집기에 편집할 수 없는 텍스트가 다음과 같이 추가돼요.

```
<h1 class="h1">{{rss_feed.title}}</h1> {{rss_feed.description}}<br /> <br />
```

**사용자 지정**을 고르면 텍스트 편집기에 편집할 수 있는 텍스트가 다음과 같이 추가돼요.

```
Updates from {{rss_feed.url}} <h1>{{rss_feed.title}}</h1> <strong>{{rss_feed.description}}</strong><br /> <br /> <strong>In the {{rss_feed.date}} edition:</strong><br />
```

이 RSS `<channel>` 변수는 이메일 캠페인의 제목 필드에도 쓸 수 있어요.

#### **RSS Items**

RSS 피드를 쓸 때 **RSS Items** 요소는 이메일 마케팅에서 핵심이 되는 부분이에요. RSS 피드의 콘텐츠를 이메일 캠페인에 자동으로 채워 넣는 콘텐츠 자리 표시자 역할을 해요. RSS 항목은 블로그 게시글, 뉴스 업데이트, 기사처럼 RSS 피드로 볼 수 있는 모든 게시 콘텐츠가 될 수 있어요.

![RSS Items 요소 예시](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000367932/original/KXeCwwcrr1bgCt_nLQJ3g50ATWIIHanFsw.png?1685736584)

![RSS Items 요소 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083973129/original/figwCJPCWESF2EOjGrDIi6tF7BsTSPTb1g.png?1792675024)

RSS 편집 옵션은 다음과 같아요.

- **발췌문**: RSS 피드 항목마다 원문의 요약이나 일부만 보여 줘요. 구독자에게 콘텐츠를 미리 보여 주고, 웹사이트에서 전체 내용을 읽으러 오게 하고 싶을 때 유용해요.
- **Excerpts with Image**(이미지가 있는 발췌문): **발췌문**처럼 원문의 요약이나 일부를 보여 주면서, RSS 피드 항목에 연결된 이미지도 함께 넣어요. 시각적 효과가 커서 참여율을 크게 높이는 데 도움이 돼요.
- **제목**: 이 옵션을 고르면 RSS 피드 항목마다 제목만 표시돼요. 군더더기 없는 방식이고, 제목만으로도 내용이 잘 드러나거나 호기심을 끌어서 독자가 클릭해 더 읽게 만들 수 있을 때 효과적이에요.
- **전체 콘텐츠**: RSS 피드 항목의 전체 콘텐츠를 이메일로 가져와요. 피드 항목이 짧거나 이메일 안에서 완전한 정보를 제공하고 싶을 때 유용해요. 다만 항목이 길면 이메일도 길어질 수 있어요.
- **사용자 지정**: RSS 피드에서 어떤 정보를 이메일에 넣을지, 어떻게 보여 줄지 직접 고를 수 있어요. 예를 들어 제목, 짧은 발췌문, 작성자 이름, 전체 글 링크를 넣을 수 있어요. 설정이 조금 더 필요하지만, 피드 항목을 이메일에 표시하는 방식을 가장 유연하게 맞출 수 있어요.

이 요소는 RSS 항목마다 다음과 같은 속성을 자동으로 가져올 수 있어요.

- 게시글/항목의 제목 (`{{rss_item.title}}`)
- 게시글/항목의 요약 또는 설명 (`{{rss_item.content}}`)
- 원문 게시글/항목의 직접 URL 링크 (`{{rss_item.url}}`)
- 게시글/항목의 게시 날짜 (`{{rss_item.date}}`)
- 게시글/항목의 작성자 (`{{rss_item.author}}`)

이메일에 **RSS Items** 요소를 넣으면 어떤 정보를 어떻게 보여 줄지 정할 수 있어요. 제목만 보여 주거나, 제목과 요약을 함께 보여 주거나, 전체 글로 가는 하이퍼링크까지 넣을 수 있어요.

디자인 설정도 조절할 수 있어요. 예를 들어 요소 주변 여백(위, 아래, 왼쪽, 오른쪽)을 이메일 분위기에 맞게 바꿀 수 있고, 각 게시글의 이미지를 이메일에 넣을지도 고를 수 있어요.

#### **레이아웃**

레이아웃은 이메일 콘텐츠의 구조를 정해요. 간단한 1열 레이아웃부터 더 복잡한 구조까지 고를 수 있어요.

![레이아웃 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155083973224/original/QLwjdXlPElwrmBpWJr22ojjC9-wbLh26aA.png?1792675053)

각 레이아웃은 다음과 같아요.

- **1**: 1열 구조예요. 모든 콘텐츠가 세로 한 줄로 배치돼요. 이메일에서 가장 기본적이고 가장 많이 쓰이는 레이아웃 중 하나예요. 특히 모바일처럼 작은 화면에서 읽기 편해요.
- **2**: 2열 구조예요. 이메일 콘텐츠가 세로 두 열로 나뉘어요. 이미지와 텍스트 블록, RSS 피드의 기사 두 개처럼 두 콘텐츠 그룹을 나란히 보여 줄 때 좋아요.
- **1/3 : 2/3**, **2/3 : 1/3**: 콘텐츠를 폭이 다른 두 열로 나누는 구조예요. 1/3 : 2/3에서는 한 열이 너비의 1/3, 다른 열이 2/3를 차지해요. 2/3 : 1/3은 그 반대예요. 이미지와 설명처럼 한쪽을 더 강조하고 싶을 때, 예를 들어 이미지가 주인공일 때 좋아요.
- **1/4 : 3/4**, **3/4 : 1/4**: 위와 비슷하지만 한 열이 공간의 1/4, 다른 열이 3/4를 차지하고, 반대 경우도 있어요. 작은 내비게이션 메뉴와 넓은 콘텐츠 영역처럼 한쪽 콘텐츠가 훨씬 중요할 때 유용해요.
- **4**: 4열 구조예요. 이메일 콘텐츠가 같은 너비의 세로 네 열로 나뉘어요. 이미지 격자나 RSS 피드의 기사 여러 개처럼 중요도가 같은 콘텐츠 여러 개를 나란히 보여 줄 때 유용해요.

필요와 이메일 유형에 따라 콘텐츠를 다양한 방식으로 구성할 수 있어요. 각 옵션을 이해하면 이메일에 가장 알맞은 레이아웃을 고를 수 있어요.

이 요소들을 이메일에 추가하려면 캔버스로 끌어다 놓으세요. 편집할 요소를 선택하면 인라인 편집기가 나타나고, 선택한 요소를 필요에 맞게 바꿀 수 있는 여러 옵션이 나와요.

![링크 추가 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034104204/original/OdoOabg73mZdyxjKfE1Vkpo6mopk_0p6EA.jpeg?1728042836)

- **Add/Edit Link**(링크 추가/편집): 이메일에 새 하이퍼링크를 추가하거나 기존 링크를 수정해요.

- **표시할 텍스트**: 이메일에 보이고 클릭할 수 있는 텍스트예요. "Read more", "Download now" 같은 행동 유도 문구나 연결할 웹페이지 이름이 될 수 있어요. 짧고, 연결된 내용을 잘 설명하는 문구가 좋아요.
- **제목**: 링크에 대한 추가 정보를 담는 선택 항목이에요. 보통 하이퍼링크 위에 마우스를 올리면 툴팁으로 나타나요. 링크가 어디로 연결되는지 등 추가 맥락을 알려 줄 수 있어요.
- **링크 열기 위치**: 이 옵션에서 새 창을 선택하면 수신자가 링크를 눌렀을 때 현재 창이 아니라 새 브라우저 창이나 탭에서 열려요. 사용자가 이메일이나 현재 웹페이지에서 벗어나지 않게 하고 싶을 때 유용해요.
- **링크 목록**: 이전에 쓰거나 저장한 링크 목록이 들어 있을 수 있는 드롭다운 메뉴예요. 자주 쓰는 링크를 더 빠르고 쉽게 추가할 수 있어요.

텍스트 정렬과 줄 높이를 조절하거나 글머리 기호를 넣을 수도 있어요.

![텍스트 정렬 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108731/original/-sXSCSMBTBgBZnWCUxpSLfdLVTswZUk-tg.png?1728045588)

![글머리 기호 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108788/original/SpHu5N_Z-BymA69QaftnYT24YJuiGGwvMw.png?1728045640)

글머리 기호 유형은 다음과 같아요.

- **Disc**: 채워진 원이에요. HTML에서 순서 없는 목록의 기본 스타일이에요.
- **Circle**: 속이 빈 원이에요. 보통 순서 없는 목록의 두 번째, 세 번째 항목에 써요.
- **정사각형**: 채워진 사각형이에요. 변화를 주거나 강조하고 싶을 때 원 대신 쓸 수 있어요.
- **Decimal**: 일반적인 숫자(1, 2, 3 등) 목록 기호예요. 보통 순서가 중요한 목록에 써요.
- **Lower Alpha**: 소문자 알파벳(a, b, c 등) 목록 기호예요. 순서 있는 목록의 하위 항목에 자주 써요.
- **Lower Greek**: 소문자 그리스 문자(alpha, beta, gamma 등) 목록 기호예요. 자주 쓰이지는 않지만 일반 기호의 색다른 대안이 될 수 있어요.
- **Lower Roman**: 소문자 로마 숫자(i, ii, iii 등) 목록 기호예요. 법률 문서처럼 공식적이거나 전통적인 문서에 자주 써요.
- **Upper Alpha**: 대문자 알파벳(A, B, C 등) 목록 기호예요. 순서 있는 목록의 주요 항목에 자주 써요.
- **Upper Roman**: 대문자 로마 숫자(I, II, III 등) 목록 기호예요. 소문자 로마 숫자처럼 공식적이거나 전통적인 문서에 자주 써요.

## 고급 편집 옵션 사용

인라인 편집기에는 고급 편집 옵션도 있어요. **서식 지우기** 기능은 선택한 텍스트에서 기존 서식을 모두 지워요. 외부에서 복사한 텍스트를 붙여 넣을 때 편리해요.

![서식 지우기 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108820/original/-GVLMpeYCWrPTD6yUTRd5CEeWZFYB1UE3Q.png?1728045677)

**커스텀 값**은 수신자의 이름이나 지역 같은 정보를 넣어서 이메일을 개인화해요. 이렇게 하면 이메일이 수신자에게 더 잘 맞게 느껴져서 참여율을 높이는 데 도움이 돼요.

**서비스** 및 **렌탈** 커스텀 값: 이메일 콘텐츠를 만들거나 편집할 때 **이메일 빌더**의 커스텀 값 선택기에서 지원되는 **서비스**와 **렌탈** 커스텀 값을 바로 고를 수 있어요. 커스텀 값을 직접 입력하거나 외워 두지 않아도 관련 예약 정보를 쉽게 넣을 수 있어요.

선택기에서 필요한 **서비스** 또는 **렌탈** 커스텀 값을 고르면 이메일 콘텐츠에 삽입돼요.

![서비스, 렌탈 커스텀 값 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034109121/original/6oxFeaWK7INztLF5qu_X0HWB4nZkt41iIg.jpeg?1728045887)

**트리거 링크**를 쓰면 수신자가 이메일에서 바로 구독 확인, 수신 거부, 특별 혜택 페이지 이동 같은 동작을 할 수 있어요. 이런 인터랙티브 요소는 사용자 동작을 간단하게 만들어서 참여를 높이고 전환을 늘리는 데 도움이 돼요.

![트리거 링크 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108891/original/O64_8g_YlwM4Xt9Fn6LjDcAYUCOKw8t7lQ.png?1728045724)

**콘텐츠 AI** 기능은 인공지능으로 텍스트 콘텐츠를 만들어 줘요. 콘텐츠 제목, 설명, 키워드를 입력하면 관련 텍스트 콘텐츠를 자동으로 생성해 줘요. <!-- 검토 필요: 원문 문장이 "More on that in"에서 끊겨 있음 -->

![콘텐츠 AI 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155033414105/original/LWVq6Er5rHqRBNePkyPld-KudW2yjGPVXQ.png?1727156790)

![콘텐츠 AI 입력 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034108647/original/L2lZ0LwXKMvXuI7u5VsLzh5V8mWXvtAldw.png?1728045553)

- **맥락**: AI가 생성할 콘텐츠의 맥락을 입력해요. AI가 전체 주제를 이해하는 데 도움이 돼요. "Digital Marketing"이나 "Healthy Recipes" 같은 내용이 될 수 있어요. 맥락이 구체적일수록 생성되는 콘텐츠가 더 정확해져요.
- **Content Title**(콘텐츠 제목): 만들려는 콘텐츠의 핵심 주제나 아이디어를 입력해요. 이 제목이 AI가 원하는 콘텐츠를 생성하는 기준이 돼요. 블로그 제목, 이메일 제목, 상품 설명 등이 될 수 있어요.
- **간단한 콘텐츠 설명 제공**: 원하는 콘텐츠를 간단히 설명해요. AI가 콘텐츠를 만들 때 고려했으면 하는 구체적인 내용이나 관점을 넣을 수 있어요.
- **키워드 추가**: 콘텐츠를 설명하는 구체적인 단어나 문구예요. AI가 이 표현들을 생성되는 콘텐츠에 자연스럽게 녹여 내요. 특히 SEO 목적에 도움이 돼요.
- **작성 톤**: 글의 톤을 정해요. 전문적, 친근함, 격식 없음, 권위적 등으로 고를 수 있어요. AI가 선택한 톤에 맞춰 콘텐츠를 만들어요.
- **Number of Variations**(변형 수): AI가 생성할 콘텐츠 버전의 개수를 정해요. 여러 결과 중 필요에 가장 잘 맞는 것을 고를 수 있어요. 최대 5개까지 만들 수 있어요.

## 요소 관리

**Manage Elements** 기능으로 이메일 안의 각 요소를 관리해요. 이 영역에서 요소를 선택하면 데스크톱, 모바일, 또는 둘 다 중에서 어떤 기기에 표시할지 바꿀 수 있어요.

![Manage Elements 영역](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155034101650/original/wKRH_G0nGBm-HhipPli_f5FPbOudnHGCTA.png?1728041285)

표시 설정으로 기기마다 요소가 어떻게 보이는지 조절해요. 구체적으로 모바일 표시와 데스크톱 표시 설정에서, 이메일이나 웹페이지의 어떤 요소를 데스크톱 또는 모바일 기기에서 보여 줄지 고를 수 있어요.

모바일 표시는 이메일이나 웹페이지 요소가 스마트폰이나 태블릿 같은 모바일 기기에서 어떻게 보이는지를 말해요. 이런 기기는 화면이 작아서, 잘 보이지 않는 요소는 숨기거나 콘텐츠를 단순하게 만들어 모바일에서 보기 쉽게 할 수 있어요. 모바일에 더 알맞게 요소의 구조나 크기를 바꾸는 것도 포함돼요.

![모바일 표시 설정](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155000369146/original/Yvs3IeM4Iq-7TwRlttbuEuV97nsWvc3nLw.png?1685740278)
