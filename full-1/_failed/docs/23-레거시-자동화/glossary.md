# 용어집

하이퍼클래스 소프트웨어에서 자주 보이거나 관련된 용어와 약어를 정리한 목록이에요. 다른 도움말과 함께 보면 소프트웨어를 더 잘 이해할 수 있어요.

## A

### A2P 10 DLC

(기술 용어 약어) 표준 10자리 롱코드(10 DLC)로 보내는 Application-to-Person(A2P) 방식의 메시지예요.

### A Record

A 레코드는 도메인을 그 도메인을 호스팅하는 컴퓨터의 실제 IP 주소에 연결해 줘요. 인터넷 트래픽은 A 레코드로 내 도메인의 DNS 설정을 호스팅하는 컴퓨터를 찾아요. A 레코드의 값은 항상 IP 주소이고, 도메인 이름 하나에 A 레코드를 여러 개 설정할 수 있어요.

### 제휴(Affiliate)

제휴는 더 큰 조직에 공식적으로 소속된 개인이나 조직이에요. 에이전시 수준 사용자는 하이퍼클래스의 제휴예요. 제휴 링크로 다른 사람을 하이퍼클래스에 소개해서 나만의 제휴를 늘릴 수 있어요. 소개받은 사람이 소프트웨어를 구매하면 그 소개에 대한 수수료를 받아요. 제휴 프로그램에 대한 자세한 내용은 하이퍼클래스 고객지원 포털의 솔루션 페이지를 참고하세요.

### 에이전시 뷰(Agency View)

에이전시 사용자가 플랫폼에 로그인하면 처음 보는 화면이에요. 에이전시는 이 화면에서 시스템 전체 설정을 관리하고 하이퍼클래스와 소통해요. 이 수준에서 **마켓플레이스**, **아이디어** 게시판, **대학** 코스, 고객지원에 들어갈 수 있어요. 나머지 기능은 모두 서브 계정 수준에 있어요.

### API

(기술 용어 약어) Application Programming Interface

### API 키(API Key)

API 키는 두 플랫폼 사이에 안전한 연결을 만들 때 써요. 연결할 때마다 로그인하지 않아도 돼요. Mailgun이나 SMTP 서비스를 설정할 때, 또는 하이퍼클래스 플랫폼 안에 아직 만들어져 있지 않은 플랫폼과 연동을 만들 때 API 키가 필요한 경우가 많아요.

### 자동화(Automations, Aut)

자동화는 특정 행동을 계기로 이어지는 일련의 이벤트예요. 도미노를 쭉 세워 놓고 공으로 첫 번째 도미노를 치면 차례로 넘어가는 모습을 떠올려 보세요. 자동화도 마찬가지예요. 연락처가 폼을 제출하거나 예약을 잡는 것처럼 특정 행동을 하면, 일련의 메시지와 백엔드 처리가 이어서 실행되도록 설정할 수 있어요. 자동화에는 **워크플로우**, **캠페인**, **트리거**가 포함돼요.

## B

### B2B

(자주 쓰는 약어) Business-to-Business, 기업 간 거래

### B2C

(자주 쓰는 약어) Business-to-Customer, 기업과 소비자 간 거래

### 일괄 작업(Bulk Actions)

**일괄 작업**은 연락처 여러 개에 한 번에 작업을 적용할 수 있는 편리한 방법이에요.

### BYOC

(자주 쓰는 약어) Bring Your Own Channel

## C

### 캘린더(Calendar, Cal)

**캘린더** 기능이 있으면 외부 예약 위젯이 필요 없어요. 고객은 리드와 통화하며 전략을 논의하거나 시연을 하거나 서비스를 제공하려고 할 때가 많아요. 팀 캘린더를 쓰면 한 사용자가 여러 예약 유형(예: 스파, 살롱)을 제공할 수 있어요. 여러 사용자가 같은 유형의 예약(예: 영업 통화)에 라운드 로빈 방식으로 배정될 수도 있어요.

### 캘린더 > Appointments Per Day(하루 예약 수)

**Appointments Per Day**는 하루에 잡을 수 있는 예약의 총 개수예요. 예를 들어 8시간 동안 30분짜리 예약 슬롯이 있으면 하루 예약이 16건이 돼요. 이 숫자가 원하는 수가 아닐 수도 있어요. 하루 예약 수를 정해 두면 하루에 받는 예약을 그 수까지로 제한할 수 있어요.

### 캘린더 > Appointments Per Slot(슬롯당 예약 수)

**Appointments Per Slot**은 한 슬롯에 예약할 수 있는 사람 수예요. 웨비나처럼 여러 명이 참여하는 이벤트가 아니면 보통 1로 둬요.

### 캘린더 > Buffer Duration(버퍼 시간)

**Buffer Duration**은 모든 예약 뒤에 버퍼 시간을 더해서, 예약과 예약 사이 간격을 정해요. 예를 들어 슬롯 길이가 30분이고 오전 10시 예약에 버퍼가 15분이면, 바로 다음 예약 가능 시간은 오전 10시 45분이에요.

### 캘린더 > 날짜 범위

**날짜 범위**는 예약을 얼마나 먼 미래까지 잡을 수 있는지를 정해요.

### 캘린더 > 최소 예약 안내 기간

**최소 예약 안내 기간**은 원하는 예약 시간보다 최소 얼마 전에 예약해야 하는지를 정해요.

### 캘린더 > Slot Duration(슬롯 길이)

**Slot Duration**은 예약 한 건의 길이를 정해요.

### 캘린더 > Slot Interval(슬롯 간격)

**Slot Interval**은 예약 가능한 시간이 얼마나 자주 나오는지를 정해요.

### 캠페인(Campaign)

캠페인은 상품과 서비스를 홍보할 여러 온라인 경로를 설정하는 소프트웨어 영역이에요.

### 채팅 위젯(Chat Widget)

웹사이트에 팝업을 넣어서 연락처 정보를 받고, 그 연락처의 대화를 만들 수 있어요. 이 기능에는 양방향 채팅이 없으니, 조금 더 정교한 문의 폼이라고 생각하면 돼요. 이후 후속 연락은 모두 전화나 이메일로 해요.

### CNAME Record

Canonical Name 또는 CNAME 레코드는 별칭을 실제(표준) 도메인 이름에 연결하는 DNS(Domain Name System) 레코드 유형이에요. 다시 말해 검색엔진 크롤러가 찾기를 바라는, 웹사이트 페이지의 '마스터 버전'이에요. 마케팅 캠페인을 하고 사용자를 추적하면 고유한 페이지 URL 끝에 정보가 붙어요. 크롤러 입장에서는 같은 페이지 버전이 여러 개인데 어느 쪽이 '맞는' 것인지 알 수 없다는 뜻이에요. 페이지 HTML에 표준(canonical) URL을 설정하면, 방문자에게 보여 주고 싶은 페이지 버전을 검색엔진에 알려 줄 수 있어요.

<!-- 검토 필요: 원문 내용이 서로 다름 -->

### 회사(Company)

**회사**는 고객사의 비즈니스 정보를 수정하는 곳이에요.

### 연락처(Contact, 일명 리드)

플랫폼에서 추적할 수 있는 개인의 프로필이에요. 보통 이름, 연락 방법, 그 사람에 대한 추가 정보, 활동 기록, 잡힌 예약이 들어 있어요. 연락처 프로필에서 대화도 할 수 있어요. (리드 항목도 참고하세요.)

### 대화(Conversations, Convo)

많은 회사가 SMS, 이메일, Facebook Messenger 같은 여러 소통 채널에서 활동해요. **대화**에서는 플랫폼이나 연락 방법과 상관없이 리드가 보낸 모든 메시지를 볼 수 있어요. 고객이 여러 탭과 앱을 오가며 리드에게 어떤 말이 오갔는지 확인하지 않아도 돼요.

### 전환 리드(Conversion Leads)

Facebook 전환 리드 연동은 Facebook 리드 광고가 리드 수가 아니라 리드의 품질에 맞춰 최적화되도록 도와줘요. 사용자가 리드 폼을 제출하면 연락처 정보가 수집되어 하이퍼클래스 CRM에 동기화돼요. 이 연락처 정보로 리드를 팔로업하고 육성해서 영업 퍼널의 다음 단계로 이끌 수 있어요. 리드가 영업 퍼널을 따라 이동할 때마다, 전환 리드 연동으로 광고주가 리드 상태를 Meta와 공유할 수 있어요. 그러면 Meta는 리드에서 판매로 이어지는 전환율이 오르도록 리드 광고를 최적화해요.

### CRM

(기술 용어 약어) Customer Relationship Management, 고객 관계 관리. CRM은 시스템에 있는 연락처 목록과 그 연락처와 소통하는 도구예요. 하이퍼클래스는 예약을 잡고, 메시지를 보내고, 개인별 데이터를 관리하는 옵션을 제공해요.

### CSS

(기술 용어 약어) Cascading Style Sheets

### CSV

(기술 용어 약어) Comma-separated values, 쉼표로 구분된 값

### 커스텀 CSS(커스텀 코딩)

CSS 코딩으로 플랫폼의 모양을 바꿀 수 있고, HTML 코딩으로 플랫폼의 기능을 바꿀 수 있어요. 하이퍼클래스는 보통 커스텀 코딩 구축이나 지원을 하지 않지만, 이런 서비스를 제공하는 파트너가 여러 곳 있어요.

## D

### 에이전시 대시보드(Dashboard, Agency)

에이전시 수준의 **에이전시 대시보드**는 Stripe 매출을 보여 줘요. 에이전시가 하이퍼클래스로 사업을 키우며 번 수익을 빠르게 확인하는 용도예요. 앞으로 지금의 서브 계정 대시보드처럼 이 영역에 더 많은 기능이 표시될 거예요. 대시보드를 바꾸는 설정은 없어서, 기능을 더 넣으려면 커스텀 코딩을 써야 해요.

### 서브 계정 대시보드(Dashboard, Sub-Account)

서브 계정의 **대시보드**는 파이프라인을 바탕으로 한 그래픽과 지표, 그리고 일일 활동을 빠르게 볼 수 있는 항목을 보여 줘요. 모든 파이프라인의 전체 잠재 가치, 플랫폼별 연락처 분포, 소스별 기회 수를 볼 수 있어요.

{% hint style="info" %}
리드 소스 위젯은 **연락처 출처**와 별개로 기회의 출처를 기준으로 보여 줘요.
{% endhint %}

대시보드에서 **수동 작업**과 **작업**도 바로 열 수 있어요.

### DB

(자주 쓰는 약어) Database, 데이터베이스

### DKIM

(기술 용어 약어) Domain Keys Identified Mail

### DMARC

(기술 용어 약어) Domain-based Message Authentication, Reporting, and Conformance

### DNS

(기술 용어 약어) 쉽게 말해 DNS(Domain Name System)는 인터넷의 전화번호부예요. 웹사이트 도메인 이름(호스트 이름)을 숫자 값(IP 주소)으로 바꿔 줘서, 웹 브라우저에서 찾아 불러올 수 있게 해요.

### 도메인(Domains)

도메인은 누군가 온라인에서 내 웹사이트나 웹사이트의 한 페이지를 찾을 때 쓰는 웹 주소의 일부예요. 웹사이트의 숫자 IP 주소와 연결된 문자열이라서, 사람이 기억하고 검색하기가 훨씬 쉬워요. 도메인은 집 주소에 자주 비유돼요. 친구가 집에 올 때 집의 GPS 좌표를 외우지 않고 휴대폰에 주소를 입력하죠. 웹사이트를 방문할 때도 마찬가지예요. 방문자는 IP 주소를 외우는 대신 브라우저에 도메인을 입력해요.

### Drip Mode(드립 모드)

**Drip Mode**는 이메일 캠페인을 전체 수신자에게 한꺼번에 보내지 않고, 시간 간격을 둔 묶음으로 나눠 보내는 기능이에요. 웹사이트나 퍼널로 들어오는 트래픽을 조절하고, 서버에 부담이 갈 수 있는 상황을 막아 줘요.

## E

### Eliza

**Eliza 에이전트 플랫폼**은 하이퍼클래스와 파트너가 제공하는 AI 챗봇이에요. 챗봇을 웹사이트에 두면, 고객이 봇과 대화하면서 대부분의 질문에 대한 답을 얻을 수 있다는 아이디어예요. 봇이 어떻게 답해야 할지 이해하지 못하면 사람 인계 기능이 작동해요. 그러면 파트너 중 한 명이 그 지점부터 채팅을 이어받아요. 이후 상담원이 앞으로 어떻게 답할지 봇에게 가르쳐서, Eliza가 계속 성장하며 가장 정확한 답을 줄 수 있게 돼요. 이 서비스에는 월 비용이 있어요.

## F

### F&S

폼과 설문(Forms and Surveys)의 약어예요.

### F&W

퍼널과 웹사이트(Funnels and Websites)의 약어예요.

### Facebook 픽셀(일명 Meta 픽셀)

Facebook 픽셀은 웹사이트에 넣는 코드 조각이에요. 데이터를 수집해서 Facebook 광고의 전환을 추적하고, 광고를 최적화하고, 이후 광고에 쓸 타깃 오디언스를 만들고, 웹사이트에서 이미 어떤 행동을 한 사람에게 리마케팅하도록 도와줘요. Facebook 픽셀 ID는 내 계정과 연결된 고유한 ID 번호예요.

### FB

(자주 쓰는 약어) Facebook

### 폼(Forms)

리드가 계정 사용자에게 정보를 제공할 수 있게 하는 기능이에요. 모든 필드가 한 페이지에 나열되어 보여요.

### 폼 > 커스텀 필드 > 체크박스

여러 옵션이 나열되고, 체크박스를 여러 개 체크해서 복수 선택할 수 있는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 날짜

숫자만 입력할 수 있고, 입력한 값을 날짜 형식으로 바꿔 주는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 파일

파일을 업로드할 수 있는 커스텀 필드예요. 이 필드에서는 업로드할 수 있는 파일 형식을 제한할 수 있어요.

### 폼 > 커스텀 필드 > Large Text(긴 텍스트)

여러 줄을 입력할 수 있는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 금액

숫자만 입력할 수 있고, 입력한 값을 금액 형식으로 바꿔 주는 커스텀 필드예요.

### 폼 > 커스텀 필드 > Multiple Options(복수 옵션)

드롭다운 목록에서 여러 개를 선택할 수 있는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 숫자

숫자만 입력할 수 있는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 전화번호

숫자만 입력할 수 있고, 입력한 값을 전화번호 형식으로 바꿔 주는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 라디오

여러 옵션이 나열되고, 해당 라디오 버튼을 클릭해서 옵션을 하나만 선택할 수 있는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 서명

서명을 받는 데 쓰는 커스텀 필드예요.

### 폼 > 커스텀 필드 > Single Options(단일 옵션)

드롭다운 목록에서 하나만 선택할 수 있는 커스텀 필드예요.

### 폼 > 커스텀 필드 > 문자

한 줄만 입력할 수 있는 커스텀 필드예요.

### 폼 > 커스텀 필드 > Textbox List(텍스트 상자 목록)

옵션 목록을 보여 주면서, 옵션 옆에 데이터를 입력할 수 있는 텍스트 필드가 함께 있는 커스텀 필드예요. 예를 들어 티셔츠 주문 폼에는 스몰, 미디엄, 라지, 엑스트라 라지 같은 사이즈 옵션이 있을 수 있어요. 각 사이즈 옆에는 사이즈별 수량을 입력하는 텍스트 필드가 있어요.

### 폼 > Open URL(URL 열기)

**Open URL**은 폼이 제출될 때 다른 웹사이트를 여는 백엔드 처리를 뜻해요. 주의할 점은, 이 처리에 열 URL이 없으면 페이지가 새로고침되어 고객에게는 제출이 되지 않은 것처럼 보인다는 거예요.

### 폼 > Sticky Contact(고정 연락처)

**Sticky Contact**는 하이퍼클래스가 폼을 제출하는 기기와, 폼이나 설문에 마지막으로 입력한 정보를 기억하는 기능이에요.

### FTP

(기술 용어 약어) File Transfer Protocol, 파일 전송 프로토콜

### 퍼널(Funnel)

리드가 하나 이상의 행동 단계를 거쳐 마케팅 목표를 달성하도록 안내하는 일련의 웹 페이지예요.

### 퍼널 이벤트(Funnel Events)

퍼널 이벤트는 웹 서버에서 보내져요. 사용자가 페이지를 방문하거나, 장바구니에 상품을 담거나, 구매하거나, 구독하거나, 신청서를 제출하는 등의 이벤트를 기록해요. FB CAPI로 퍼널 이벤트 픽셀을 설정하는 방법을 더 알아보려면 관련 도움말 문서를 참고하세요.
