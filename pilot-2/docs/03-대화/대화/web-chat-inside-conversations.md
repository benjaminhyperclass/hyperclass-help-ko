# 대화에서 웹 채팅 사용하기

웹 채팅을 쓰면 웹사이트 채팅 위젯으로 방문자와 실시간으로 대화할 수 있어요. 위젯에서 보낸 메시지는 **대화**(Conversations)의 받은 메시지함에 바로 들어오고, SMS·이메일 같은 다른 채널과 함께 관리할 수 있어요.

이 문서에서는 웹 채팅이 어떻게 동작하는지, 채팅 위젯은 어떻게 설정하는지, 웹 채팅 대화는 **대화**에서 어떻게 관리하는지 알려 드려요.

{% hint style="warning" %}
웹 채팅은 라이브 채팅과 다릅니다. 두 기능을 쉽게 구분할 수 있도록, 이제 플랫폼 전체에서 채널 이름을 통일해 표시해요.
{% endhint %}

## 웹 채팅이 동작하는 방식

웹 채팅을 쓰면 웹사이트 방문자가 바로 대화를 시작할 수 있어요. 방문자가 채팅 위젯으로 메시지를 보내면, 그 메시지는 서브 계정의 **대화** 받은 메시지함으로 바로 전달돼요.

웹 채팅 메시지는 **대화**에 실시간으로 표시돼요. 담당자는 대화를 열어 바로 답하고, 대화를 배정하거나 다른 채널과 똑같이 관리할 수 있어요.

웹사이트 대화를 한곳에 모아 두기 때문에, 팀이 여러 플랫폼을 오갈 필요가 없어요.

## 웹 채팅 설정하기

웹 채팅을 사용하려면 채팅 위젯을 만들고 설정해야 해요.

1. **사이트 > 채팅 위젯**으로 이동해요.
2. **+ 신규**를 클릭해 위젯을 만들어요.

![채팅 위젯 화면에서 새 위젯 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064712895/original/YYkwwOk7UdKbICVBGF7Bi966rwqh1rMOTA.png?1770826807)

![채팅 위젯 만들기 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713569/original/FxlWfSBKlVY305W8RQ9nPQJEc-ITSM1Jjw.png?1770827200)

3. 채팅 유형에서 **실시간 채팅**을 선택해요. 설정 화면에는 "실시간 채팅"으로 표시되지만, 이 옵션이 웹사이트 메시지를 **대화**로 보내는 웹 채팅 채널을 설정해요.
4. 필요에 맞게 위젯 설정을 바꿔요.

![위젯 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713593/original/OC_HIOJgXVHQfE8HqK9tfrSU1lMGHmru3Q.png?1770827226)

다음 항목을 설정할 수 있어요.

- **인트로 메시지**
- 에이전트 아바타와 브랜딩
- 무응답 시 대체 메시지
- 채팅 시간 초과 메시지

5. 설정을 마치면 위젯을 저장해요.
6. 제공되는 스크립트를 복사해서 웹사이트의 푸터(footer) 또는 본문(body) 영역에 붙여 넣어요. WordPress를 쓴다면 하이퍼클래스 플러그인을 설치해 위젯을 사용할 수 있어요.

설치가 끝나면 방문자가 웹사이트에서 웹 채팅 메시지를 보낼 수 있어요.

## 웹 채팅 대화 관리하기

방문자가 메시지를 보내면 **대화**에 바로 표시돼요.

![대화 화면에 표시된 웹 채팅 메시지](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713051/original/M9s2JNrW0_rpY2_OZcdoRPmYeArr7JCNBA.png?1770826888)

받은 메시지함에서 채팅 아이콘이 붙은 대화가 웹 채팅 대화예요. 대화를 열어 실시간으로 답할 수 있어요. 대화는 직접 배정할 수도 있고, 워크플로우나 소유권 규칙을 이용해 팀원에게 자동으로 배정할 수도 있어요.

웹 채팅 메시지만 보려면 **대화**의 필터 옵션을 사용하세요.

![대화 화면의 필터 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064713123/original/LT60iImtWOgmPVqFgRHF9JM-KmgcemlLng.png?1770826906)

1. **마지막 메시지 채널**에서 **라이브 채팅**을 선택해요.
2. 필터를 적용해요.

이렇게 하면 웹사이트에서 들어온 웹 채팅 대화만 표시돼요.

대화가 끝나면 **End Chat**(채팅 종료) 옵션을 사용할 수 있어요. 위젯에 설정한 비활성 시간 기준에 따라 채팅이 자동으로 종료되기도 해요.

## 자주 묻는 질문

### 웹 채팅 메시지가 대화에 표시되게 하려면 어떻게 하나요?
채팅 위젯을 설치해 활성화하고, **사이트 > 채팅 위젯**에서 **실시간 채팅**을 선택하세요. 메시지가 **대화**로 자동으로 전달돼요.

### 웹 채팅인데 설정 화면에는 왜 "실시간 채팅"이라고 나오나요?
현재 위젯 설정 화면에서는 "실시간 채팅"이라는 이름을 쓰지만, 실제로는 웹사이트 대화를 **대화**로 보내는 웹 채팅 채널을 설정해요.

### 웹 채팅 메시지에 아무도 답하지 않으면 어떻게 되나요?
설정한 비활성 시간 안에 담당자가 답하지 않으면, 대체 메시지가 방문자에게 연락처를 남겨 달라고 안내해요. 그러면 나중에 이어서 응대할 수 있어요.

### 웹 채팅 대화를 특정 팀원에게 배정할 수 있나요?
네. 대화는 직접 배정할 수도 있고, 워크플로우와 배정 규칙을 이용해 자동으로 배정할 수도 있어요.

### 웹 채팅 대화만 따로 볼 수 있나요?
네. **대화**의 필터 옵션에서 메시지 채널 필터의 **라이브 채팅**을 선택하세요.
