# Facebook·Instagram 채팅 위젯 만들기

웹사이트 방문자가 이미 쓰고 있는 Meta 채널(Messenger, Instagram DM)에서 바로 대화를 시작하도록 안내하는 채팅 위젯이에요. 새로 추가된 **Facebook Chat**(Facebook 채팅)과 **Instagram Chat**(Instagram 채팅) 위젯 유형을 쓰면 방문자에게 먼저 인사를 건네고 후속 대화도 이어 갈 수 있어요.

## Facebook·Instagram 채팅 위젯이란?

Facebook 채팅과 Instagram 채팅은 하이퍼클래스 채팅 위젯 안에서 고를 수 있는 채널 전용 유형이에요. 웹사이트 안에서 메신저 창을 여는 대신, 방문자를 선택한 Meta 채널(Messenger 또는 Instagram DM)로 연결해 줘요. 그래서 대화는 Facebook이나 Instagram에서 그대로 이어져요. 빌더에는 유형별 설정 패널이 따로 있어서 알맞은 Facebook 페이지나 Instagram 비즈니스 계정을 선택하거나 연결할 수 있어요.

## 이럴 때 좋아요

- **부담 없는 시작**: 방문자는 사이트 안에 별도의 채팅 스레드를 만들지 않고 Messenger나 Instagram DM에서 바로 대화를 이어 가요.
- **선호하는 채널**: 고객이 평소 메시지를 주고받는 소셜 플랫폼에서 만날 수 있어요.
- **쉬운 이용**: 방문자가 이미 쓰는 Facebook·Instagram 로그인과 앱을 그대로 활용해요.
- **통합 받은편지함**: 모든 Meta 대화를 SMS, 이메일, WhatsApp 대화와 함께 하이퍼클래스 **대화** 받은편지함에서 관리할 수 있어요.
- **기기 간 연속성**: 대화가 사용자의 Messenger·Instagram 앱에 남아 있어서 기기를 바꿔도 대화 내역이 이어져요.

## Facebook·Instagram 채팅 위젯 설정하기

아래 단계를 따라 Facebook 또는 Instagram 채팅 위젯을 만들어 보세요. 만든 위젯은 웹사이트에 설치할 수 있어요.

#### 1단계: 새 위젯 만들기

**사이트 > 채팅 위젯**으로 이동한 뒤 파란색 **+ 신규** 버튼을 선택하세요.

![사이트 > 채팅 위젯 화면에서 신규 버튼을 선택하는 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060348475/original/elOj_5dm-_s2o0sUdzfnGJj623Dq3ovuUw.png?1765388725)

#### 2단계: 채팅 유형 선택

**채팅 유형 선택** 팝업에서 **Facebook Chat**(Facebook 채팅) 또는 **Instagram Chat**(Instagram 채팅)을 선택하세요.

Facebook·Instagram 계정은 연결되어 있지만 선택된 페이지가 없으면 페이지 선택 창이 열려요. 이 창에서 위젯에 쓸 페이지를 선택하세요.

![Facebook 또는 Instagram 채팅 유형을 고르는 팝업](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350088/original/yO7fZsVYCVXXsGVHatbDlcCq6bgQDfR5Vg.jpeg?1765390979)

{% hint style="warning" %}
서브 계정에 해당 계정이 연결되어 있지 않으면 여기서 Facebook 채팅이나 Instagram 채팅을 선택할 수 없어요. 아직 연결한 계정이 없다면 팝업 안의 링크가 계정 연결을 안내해요(예: 연동에서 **Facebook 연결** 또는 **Instagram 연결**). 이 링크를 열어 계정을 연결한 다음, 다시 이 화면으로 돌아와 채팅 유형을 선택하세요.
{% endhint %}

![계정 연결을 안내하는 팝업 링크](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350092/original/jsVdwN__K5cjKScy1fhL_BpcM8DtY01HBQ.png?1765390994)

#### 3단계: 위젯 꾸미기

**스타일**, **채팅 창**, **메시지** 탭에서 색상, 인사말 문구, 위젯을 여는 아이콘 등을 브랜드에 맞게 설정하세요. 더 많은 디자인 옵션은 '채팅 위젯 사용자 지정 개요' 문서를 참고하세요.

**채팅 창** 탭에서는 위젯에 연결된 Facebook·Instagram 계정을 바꿀 수 있어요. 페이지나 계정을 더 추가해야 하면 **연결된 Facebook 페이지 연결** 또는 **연결된 Instagram 계정 연결** 버튼을 눌러 새 연결 창을 여세요.

필요한 설정을 모두 마쳤으면 위젯을 저장하세요.

![채팅 창 탭에서 연결 계정을 설정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060350150/original/hCpviuit3NtfBrynsJe5_HGgO4PThscLtA.png?1765391093)

#### 4단계: 위젯 공유하기

다른 사이트에 위젯을 설치하려면 **코드 가져오기**를 선택한 다음, 위젯을 보여 줄 웹사이트나 퍼널에 코드 스니펫을 넣으세요. WordPress 사이트에 설치한다면 **Get it for WordPress**(WordPress용 받기)를 선택하세요. 이 위젯은 하이퍼클래스 퍼널 빌더와 웹사이트 빌더에도 바로 설치할 수 있어요.

자세한 내용은 '하이퍼클래스 채팅 위젯 설치하기' 문서를 참고하세요.

![코드 가져오기로 위젯 코드를 공유하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060349629/original/tkuC8Q7A2ZfTxvzZkN4MegGTa8PChiaJaw.png?1765390165)

## 자주 묻는 질문

### 위젯 하나에서 Facebook과 Instagram을 함께 쓸 수 있나요?

아니요. 위젯 하나에는 채널 하나만 연결할 수 있어요. 여러 채널을 한 말풍선에 담고 싶다면 **All-in-One Chat**(올인원 채팅) 위젯을 사용하세요.

### 대화가 하이퍼클래스 대화 탭에도 표시되나요?

네. Facebook·Instagram 연동과 권한이 제대로 연결되어 있고 메시지 접근이 활성화되어 있다면 **대화** 탭에 표시돼요.

### 들어오는 메시지에 자동화를 적용할 수 있나요?

네, 할 수 있어요. 워크플로우 트리거 **Facebook Message**(Facebook 메시지) 또는 **Instagram Message**(Instagram 메시지)를 사용하면 채팅에 태그를 달거나 담당자를 배정하거나 경로를 나눌 수 있어요.

### 방문자가 Facebook이나 Instagram에 로그인해 있어야 하나요?

네. 로그인하지 않은 상태라면 Meta 로그인 화면이 먼저 열려요.

### Facebook·Instagram 위젯은 스타일과 메시지 설정이 다르게 동작하나요?

아니요. 스타일과 배치는 다른 채팅 유형과 똑같이 동작해요. 가장 큰 차이는 대화가 이루어지는 곳이에요. Meta 채널에서 대화하는지, 사이트 안에서 대화하는지가 달라요.
