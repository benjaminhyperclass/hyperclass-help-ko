# 라이브 채팅 위젯 설정하기

**채팅 위젯**을 쓰면 웹사이트에 여러 방식의 채팅을 붙일 수 있어요. 이 문서에서는 방문자가 팀 또는 대화 AI와 실시간으로 대화할 수 있는 **라이브 채팅** 위젯을 만들어요. 위젯을 꾸미고 하이퍼클래스 웹사이트나 퍼널에 추가하는 방법도 함께 안내해요.

## 라이브 채팅 위젯 만들기

웹사이트에 라이브 채팅을 추가하려면 **채팅 위젯** 메뉴에서 새 위젯을 만들고 채팅 유형으로 **라이브 채팅**을 선택하세요.

1. **사이트 > 채팅 위젯**으로 이동하세요.
2. **신규**를 클릭하세요. 채팅 유형은 **올인원 채팅**, **SMS / Email chat**(SMS/이메일 채팅), **라이브 채팅**, **WhatsApp** 중에서 고를 수 있어요.

   ![채팅 유형 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078737592/original/A_CPwrjS-U_f-QoywQ3FE3AxrC4r98FzuQ.png?1787081674)
3. **라이브 채팅**을 선택하세요.
4. 브랜드에 맞게 위젯을 꾸미세요.
5. **저장**을 클릭하세요.

   ![위젯 사용자 지정 후 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960759/original/SRZNNj26lxreHm5VbkHahfNcCrcphc350g.png?1747784131)
6. **코드 가져오기 > 복사**를 클릭하세요.
7. 표시된 임베드 코드를 복사하세요.

   ![임베드 코드 복사 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960766/original/VoU2x6UeSm_BfBCXsNEwBdH-IvD1n80R3Q.png?1747784179)

**자세히 보기**

- [라이브 채팅](../../03-대화/대화/live-chat.md) - 라이브 채팅 대화가 하이퍼클래스 대화로 어떻게 전달되고 관리되는지 알아보세요.
- [채팅 위젯 사용자 지정 개요](../../06-사이트/overview-of-chat-widget-customizations.md) - 채팅 위젯의 모양과 동작을 더 세부적으로 바꾸는 방법을 알아보세요.
- [채팅 위젯 시작하기](../../06-사이트/getting-started-with-chat-widget.md) - 사용할 수 있는 채팅 위젯 유형, 설정 옵션, 사용자 지정 설정을 알아보세요.

다음으로 새 위젯을 어떻게 적용할지 정하세요. 아래에서 두 가지 방법을 안내해요.

## 임베드 코드로 적용하기

웹사이트나 퍼널에 스크립트를 직접 넣어 본 적이 있다면 이 방법이 편해요. 사이트 편집기에 채팅 위젯 코드를 바로 붙여 넣으면 돼요.

1. **사이트 > 웹사이트** 또는 **사이트 > 퍼널**로 이동하세요.
2. 위젯을 넣을 웹사이트나 퍼널을 찾아 편집 화면을 여세요.

   ![웹사이트 또는 퍼널 편집 화면 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960787/original/gl7U7-ugo-EDySww14EHX-4Gj2WR2rk96w.png?1747784281)
3. 편집기에서 **추적 코드** 아이콘(`</>`)을 클릭하세요.
4. 복사해 둔 채팅 위젯 코드를 붙여 넣으세요.
5. **저장**을 클릭하세요.

   ![추적 코드에 위젯 코드 붙여 넣고 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960800/original/7j7RzpFPTEufQWAwRrPbk8r82cQKIsBZpg.png?1747784365)

**자세히 보기**

- 다른 설치 방법과 문제 해결 방법은 [하이퍼클래스 채팅 위젯 설치 방법](../../06-사이트/how-to-install-hyperclass-s-chat-widget.md)을 참고하세요.

잘하셨어요! 다음으로 위젯이 제대로 작동하는지 테스트해 보세요.

## 설정에서 적용하기

코드를 직접 다루는 게 부담스럽다면 웹사이트 설정에서 바로 적용할 수 있어요.

1. **사이트 > 웹사이트** 또는 **사이트 > 퍼널**로 이동하세요.
2. 위젯을 넣을 웹사이트나 퍼널을 찾아 설정을 여세요.

   ![웹사이트 또는 퍼널 설정 열기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960805/original/qO6x3foY4mdlFGpt9mJMtShG_K95UyCF2A.png?1747784390)
3. **채팅 위젯** 섹션에서 만들어 둔 라이브 채팅 위젯을 선택하세요.

   ![채팅 위젯 섹션에서 라이브 채팅 위젯 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960820/original/w-Ubwt6xqJS_-CIIhHTfhfcnFa96K3PU5g.png?1747784475)
4. **저장**을 클릭하세요.

   ![설정 저장](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155046960834/original/1BsYAyKDH_J3qdvsMEAcrssP0JqZCeQLFA.png?1747784529)

설정이 끝났어요! 다음으로 고급 사용자 지정 옵션을 살펴보면서 브랜드에 맞는 채팅 환경을 만들어 보세요.
