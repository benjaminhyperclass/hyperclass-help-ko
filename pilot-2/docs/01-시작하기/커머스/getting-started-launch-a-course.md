# 코스 시작하기: 코스 만들고 오픈하기

온라인 코스를 만들고 오픈하는 과정을 처음부터 끝까지 안내해요. 코스 만들기부터 오퍼 설정, 가격 지정, 게시, 수강생에게 공유하기까지 순서대로 따라 해 보세요.

이 문서에서 다루는 내용은 다음과 같아요.

- 코스 만들기
- 코스 콘텐츠 구성하고 정리하기
- 오퍼 만들기
- 가격 설정하기
- 코스 게시하고 테스트하기
- 수강생에게 코스 공유하기

## 개요

하이퍼클래스 코스로 온라인 학습 콘텐츠를 만들고, 정리하고, 판매할 수 있어요. 무료 강의든 유료 프로그램이든, 코스를 오픈하려면 콘텐츠를 만드는 것 외에 오퍼를 만들고 가격을 설정한 뒤 수강생 화면을 직접 확인해야 해요.

## 시작하기 전에

코스를 오픈하기 전에 아래 항목을 준비하세요.

- **멤버십 > 코스** 메뉴에 접근할 수 있는 권한
- 코스 콘텐츠(동영상, 강의, PDF, 퀴즈 등)
- 코스 썸네일 (필수는 아니지만 준비해 두면 좋아요)
- 유료 코스를 판매한다면 연결된 결제 서비스
- 정해 둔 가격 방식(**무료**, **일회성**, **반복** 중 하나)

{% hint style="info" %}
유료 코스를 만든다면 오퍼를 만들기 전에 결제 서비스가 연결되어 있는지 먼저 확인하세요.
{% endhint %}

## 코스 만들기

첫 코스를 만드는 일은 가르치는 일의 기초를 다지는 단계예요. 어렵지 않으니 하나씩 따라 해 보세요.

1. **멤버십 > 코스 > 상품**으로 이동하세요.

   ![멤버십 > 코스 > 상품 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067626946/original/xC3XQuB72es3s71pE5_EkekhCU_5B8GUBA.png?1774365062)
2. **상품 만들기 > 처음부터 시작**을 클릭하세요.

   ![상품 만들기 > 처음부터 시작 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067627035/original/0m0VAHfAtZ1yOMkn-G-ryxllZWGO3pkRTg.png?1774365119)
3. **코스 제목**과 **코스 설명** 등 코스 정보를 입력하고, 코스 썸네일 이미지를 올리세요. 가격 방식은 **무료**, **반복**, **일회성** 중에서 선택한 다음 **코스 생성**을 클릭하세요.

   ![코스 정보 입력과 가격 방식 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067627958/original/ney-1Jg2J9jHWNLg4TvbRYC4p9mSNgh7qg.gif?1774365612)
4. 코스 콘텐츠를 처음부터 직접 만들거나, 제공된 템플릿을 편집하세요.

   ![코스 콘텐츠 편집 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067628139/original/F5AQ6NHbZOYBHs2Q5-38Z9QBNHb1yAr6SA.png?1774365669)

### 새 레이아웃의 코스 편집기 사용하기

코스를 만들면 하이퍼클래스가 넓은 작업 공간에서 **Course Editor**(코스 편집기)를 열어 줘요. 덕분에 콘텐츠를 더 빠르게 만들 수 있어요.

**화면 구성**

- 왼쪽 패널: 코스 구조(모듈, 강의, 퀴즈, 과제)가 보여요.
- 가운데 편집 영역: 선택한 항목을 편집해요.
- 맨 위 경로 표시(브레드크럼): 코스 안에서 현재 위치를 알려 줘요.

**자주 쓰는 동작**

- 왼쪽 패널에서 강의나 퀴즈를 선택하면 편집 영역에서 열려요.
- 왼쪽 패널의 항목을 끌어다 놓아 콘텐츠 순서를 바꿀 수 있어요.
- 모듈을 펼치거나 접어서 한 섹션씩 집중해서 작업할 수 있어요.

{% hint style="info" %}
화면 이름과 버튼 이름은 계정별 적용 시점에 따라 다를 수 있어요.
{% endhint %}

## 코스 콘텐츠 만들기

코스를 만들었다면 이제 학습 콘텐츠를 추가하세요.

**Course Editor**에서 할 수 있는 작업은 다음과 같아요.

- 모듈 또는 섹션 만들기
- 강의 추가하기
- 동영상이나 다운로드 파일 올리기
- 원하는 순서로 콘텐츠 정리하기
- **변경사항 저장**

{% hint style="info" %}
코스에는 수강생이 등록한 뒤에 볼 수 있는 학습 콘텐츠가 들어 있어요.
{% endhint %}

## 오퍼 만들기

코스가 준비되면 오퍼를 만들어요. 오퍼는 코스를 어떤 조건으로 판매할지 정해 포장하는 단계예요. 아래 순서대로 진행하세요.

1. **멤버십 > 코스 > 오퍼**로 이동하세요.
2. **오퍼 만들기**를 클릭하세요.

   ![오퍼 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067628519/original/Kx1BZHkYB3OqEJDLuLu8u13Kq8eZ9j0WtQ.png?1774365815)
3. 오퍼의 가치가 잘 전달되도록 오퍼 정보를 입력하세요.
4. 방금 만든 코스 상품을 오퍼에 연결하세요.
5. 원하는 가격을 설정하세요.
6. **만들기**를 클릭하세요.

   ![오퍼 정보 입력 후 만들기](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067628657/original/T-DMPbjLV2AYbk5t1MpW5Jw_Lu7REW2A-w.png?1774365873)
7. 오퍼 상태를 **Draft**(초안)에서 **Published**(게시됨)로 바꾸고 **저장**을 클릭하세요.

   ![오퍼 상태를 게시됨으로 변경](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067628755/original/m6DDCoJacz7MrnvPcWolZK5RpmFFuljIFg.png?1774365931)
8. 오퍼 목록에서 바로 **Draft**와 **Published** 상태를 바꿀 수도 있어요.

   ![오퍼 목록에서 상태 변경](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067628836/original/xFFnpkpY7jgpQllHmDVWs_wGpTwyRybWIQ.png?1774365968)

**다음으로 할 수 있는 일:** 여러 오퍼를 묶거나 할인 코드를 만들어 더 많은 수강생을 모아 보세요.

## 오퍼 판매하기

오퍼가 준비됐어요. 마지막 단계는 오퍼 링크를 만들어 고객에게 알리는 거예요.

1. **멤버십 > 코스 > 오퍼**로 다시 이동하세요.

   ![오퍼 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067629244/original/EuqFUSfzAvN1Oafi3BMQcIIpiTHWqqeKpA.png?1774366145)
2. 링크를 가져올 오퍼에서 **링크** 아이콘을 클릭하세요.
3. **복사**를 클릭하세요.

   ![오퍼 링크 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155067629363/original/IMZnc01t0Hj7BS4bB5u_Q0wlIMLNW6Jwyg.png?1774366186)
4. 소셜 미디어, 이메일, 웹사이트 등 여러 채널에 링크를 공유하세요.

**다음으로 할 수 있는 일:** 마케팅 전략을 살펴보거나 캠페인을 시작해 코스 판매를 늘려 보세요.

## 오퍼 게시하고 공유하기

오퍼 설정을 마쳤다면 아래 순서로 확인하고 공유하세요.

- 가격 정보를 검토하세요.
- 올바른 코스가 연결되어 있는지 확인하세요.
- 오퍼를 게시하세요.
- 오퍼 링크를 복사하세요.

오퍼 링크는 다음과 같은 방법으로 공유할 수 있어요.

- 이메일 캠페인
- 랜딩 페이지
- 웹사이트
- 소셜 미디어
- 다이렉트 메시지

## 자주 묻는 질문

### 코스가 보이지 않아요.

코스를 찾을 수 없다면 아래 내용을 확인하세요.

- 코스가 정상적으로 만들어졌는지 확인하세요.
- 올바른 서브 계정에서 작업하고 있는지 확인하세요.
- **코스** 페이지를 새로고침해서 최신 변경 내용이 반영됐는지 확인하세요.

### 오퍼가 나타나지 않아요.

오퍼가 보이지 않는다면 아래 내용을 확인하세요.

- 오퍼가 게시되었는지 확인하세요.
- 오퍼에 올바른 코스가 연결되어 있는지 확인하세요.
- 오퍼 설정이 제대로 저장되었는지 확인하세요.

### 고객이 코스를 구매하지 못해요.

수강생이 결제를 끝내지 못한다면 아래 내용을 확인하세요.

- 지원되는 결제 서비스가 계정에 연결되어 있는지 확인하세요.
- 오퍼 가격과 결제 설정을 검토하세요.
- 오퍼가 게시되어 구매할 수 있는 상태인지 확인하세요.

### 수강생이 코스에 접근하지 못해요.

수강생이 구매하거나 등록했는데도 코스를 볼 수 없다면 아래 내용을 확인하세요.

- 수강생이 등록 절차를 정상적으로 마쳤는지 확인하세요.
- 오퍼에 올바른 코스가 연결되어 있는지 확인하세요.
- 워크플로우로 접근 권한을 부여하고 있다면, 워크플로우가 활성화되어 있고 설정대로 동작하는지 검토하세요.

### 동영상이나 파일이 불러와지지 않아요.

코스 미디어가 제대로 불러와지지 않는다면 아래 내용을 확인하세요.

- 페이지를 새로고침하고 업로드가 정상적으로 끝났는지 확인하세요.
- 해당 강의에 올바른 미디어 파일이 들어 있는지 확인하세요.
- 문제가 계속되면 파일을 다시 업로드하고, **Course Editor**에서 지원하는 파일 형식인지 확인하세요.
