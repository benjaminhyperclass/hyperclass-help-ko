# 결제 링크 설정하기

결제 링크를 만들면 고객이 몇 번의 클릭만으로 간편하고 안전하게 결제를 마칠 수 있어요. 이 문서에서는 결제 링크를 만들고 고객에게 보내는 방법을 안내해요.

## 결제 링크 만들기

1. **결제 > 결제 링크**로 이동하세요.
2. **새 결제 링크 만들기**를 클릭하세요.

   ![새 결제 링크 만들기 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047624719/original/_MM6j4vydZwd41nNO5O_bjSd9hQivj78tw.png?1748904864)
3. 판매할 상품을 선택하세요.

   ![상품 선택 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047624723/original/Q4I2By-JHvAQxCXjd9grkULCyopY_j5hfg.png?1748904923)
4. 수량, 옵션 등 원하는 설정을 지정해 상품을 구성하세요.
5. **저장**을 클릭하세요.

   {% hint style="info" %}
   호스팅 결제 페이지는 **비즈니스 프로필**에서 설정한 **플랫폼 언어**에 맞춰 표시돼요. 지원 언어는 영어, 덴마크어, 독일어, 스페인어, 핀란드어, 프랑스어(지역별 변형 포함), 이탈리아어, 네덜란드어, 노르웨이어, 포르투갈어(지역별 변형 포함), 스웨덴어예요.
   {% endhint %}

   ![저장 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047624730/original/GCUnKOREGY3HGzmeguEVz8IWcKeLbxTrwA.png?1748904958)
6. **보내기**를 클릭해 결제 링크를 공유하세요. 공유 방식은 다음과 같아요.

   - **Generic link**(일반 링크): 링크가 있는 모든 사람이 접근할 수 있어요.
   - **Personalized link**(개인 맞춤 링크): 지정한 수신자만 접근할 수 있어요.
   - **Send to contacts**(연락처로 보내기): 저장해 둔 연락처에 바로 공유할 수 있어서 편리해요.

   ![결제 링크 보내기 옵션](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047624748/original/untNNkuIBOCpSBv68Ba4rryGPW6lb5VMJA.png?1748905069)

결제 링크가 준비됐다면 고객이 보는 화면도 다듬어 보세요. **브랜드 색상**으로 결제 링크를 꾸미는 방법을 알아볼 수 있어요.
