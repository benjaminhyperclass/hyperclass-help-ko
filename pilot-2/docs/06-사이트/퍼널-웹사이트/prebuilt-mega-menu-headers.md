# 미리 만들어진 메가 메뉴 헤더 추가하기

하이퍼클래스의 비주얼 에디터로 퍼널이나 웹사이트에 미리 만들어진 메가 메뉴 헤더를 추가하는 방법을 안내해요. 코딩이나 복잡한 설정 없이도 사이트 내비게이션을 깔끔하게 구성할 수 있어요.

## 미리 만들어진 메가 메뉴 헤더란?

미리 만들어진 메가 메뉴 헤더는 퍼널이나 웹사이트의 어느 페이지에나 바로 넣을 수 있는 내비게이션 섹션이에요. 드롭다운이 체계적으로 구성되어 있어서 카테고리, 링크, 서비스 영역이 많은 사이트에 잘 맞아요. 모든 요소를 직접 수정할 수 있고, 방문자가 원하는 정보를 더 쉽게 찾도록 도와줘요.

## 미리 만들어진 메가 메뉴 헤더의 장점

복잡한 내비게이션을 처음부터 만들 필요가 없어서 사이트가 더 쓰기 편해지고 작업 시간도 줄어요.

- 바로 쓸 수 있는 디자인: 전문적인 레이아웃의 템플릿 중에서 고를 수 있어요.
- 편리한 방문자 경험: 규모가 크거나 구조가 복잡한 사이트에서도 방문자가 쉽게 이동할 수 있어요.
- 자유로운 레이아웃 편집: 텍스트, 색상, 간격, 아이콘, 링크 이동 위치를 브랜드에 맞게 수정할 수 있어요.
- 빠른 적용: 끌어다 놓고 게시하면 끝이라서 기술 지식이 필요 없어요.
- 일관된 디자인: 모든 페이지에서 같은 내비게이션을 유지해 사이트 전체가 통일감 있어 보여요.

## 미리 만들어진 메가 메뉴 헤더 추가하기

비주얼 에디터에서 메가 메뉴 헤더를 찾아 퍼널이나 웹사이트에 추가해 보세요.

1. 하이퍼클래스 왼쪽 메뉴에서 **사이트**를 클릭하세요.
2. 메가 메뉴를 추가할 퍼널이나 웹사이트를 선택하고, 비주얼 에디터에서 해당 페이지를 여세요.
3. 비주얼 에디터 오른쪽 위에서 **요소 추가** 버튼을 클릭하세요.
4. 사이드바 메뉴에서 **Prebuilt Sections**(미리 만들어진 섹션)를 선택하세요.
5. 사용할 수 있는 메가 메뉴 레이아웃을 둘러보세요. **클릭하여 미리보기**로 확인한 뒤, 사이트 구조에 가장 잘 맞는 디자인을 선택하세요.
6. 비주얼 에디터에서 메뉴를 원하는 대로 수정하세요. 다음과 같은 작업을 할 수 있어요.
    - 링크 텍스트와 이동할 주소 수정
    - 색상, 글꼴, 간격 조정
    - 아이콘과 하위 카테고리 추가 또는 삭제
    - 필요에 따라 열이나 콘텐츠 블록 순서 바꾸기
7. 레이아웃과 스타일이 마음에 들면 **저장**을 클릭한 다음 **게시**를 클릭해 페이지를 게시하세요.

## 자주 묻는 질문

### 여러 페이지에서 같은 메가 메뉴를 쓸 수 있나요?
네. 수정한 섹션을 저장해 두면 다른 퍼널이나 웹사이트 페이지에서도 다시 사용할 수 있어요. 그러면 내비게이션을 일관되게 유지할 수 있어요.

### 메가 메뉴 템플릿은 모바일에서도 잘 보이나요?
네. 미리 만들어진 메가 메뉴 헤더는 모바일에 맞게 설계되어 있어서 작은 화면에서는 자동으로 크기가 조정돼요.

### 직접 만든 링크나 버튼을 추가할 수 있나요?
네. 메가 메뉴 요소에서 내부 페이지나 외부 URL로 연결할 수 있고, 팝업이나 액션을 실행하도록 설정할 수도 있어요.

### 메가 메뉴의 열 개수를 바꿀 수 있나요?
네. 비주얼 에디터에서 레이아웃을 수정해 열을 추가하거나 삭제하고, 너비를 바꾸거나 콘텐츠 블록 순서를 조정할 수 있어요.

### 메가 메뉴에서 드롭다운 애니메이션을 쓸 수 있나요?
네. 미리 만들어진 디자인 중 상당수에는 드롭다운 동작이 기본으로 들어 있어요. 수정하는 중에 이 동작을 켜거나 바꿀 수 있어요.

## 다음 단계

- 홈페이지에 메가 메뉴를 추가해 상단 내비게이션을 개선해 보세요.
- 브랜드의 시각적 정체성에 맞게 디자인을 수정해 보세요.
- 수정한 헤더를 재사용할 수 있는 섹션으로 저장해 두면 사이트 전체에 쉽게 복제할 수 있어요.
- 모바일 기기에서 테스트해서 방문자 경험에 문제가 없는지 확인해 보세요.
