# WordPress 싱글 사인온(SSO)으로 WP Admin 바로 접속하기

WordPress 대시보드에서 **WP Admin**(WP 관리자) 버튼을 한 번 누르면 WordPress 관리자 화면에 바로 들어갈 수 있어요. 싱글 사인온(SSO) 덕분에 아이디와 비밀번호를 입력하지 않아도 빠르고 안전하게 로그인돼요.

[동영상](https://www.youtube.com/embed/b8niIpmUbf8?&wmode=opaque)

## 주요 기능

- 원클릭 로그인: WordPress 대시보드에서 버튼을 누르면 WP Admin 화면이 바로 열려요.
- 싱글 사인온(SSO): 비밀번호를 노출하지 않고 안전하게 로그인할 수 있어요.
- 매끄러운 연동: WordPress와 자연스럽게 연동되고, 별도 플러그인이 필요 없어요.

## 이럴 때 편해요

여러 웹사이트를 관리할 때 특히 편해요.

- 에이전시: 여러 고객사의 웹사이트를 맡고 있다면, 비밀번호를 일일이 기억하지 않아도 각 사이트의 WP Admin을 빠르게 열 수 있어요.
- 사이트 소유자: 내 사이트를 직접 관리한다면, 로그인 과정 없이 버튼 한 번으로 WP Admin에 들어갈 수 있어요.

## 사용 방법

1. 대시보드로 이동해요. 하이퍼클래스에 로그인한 뒤 WordPress 대시보드를 열어 주세요.

   ![WordPress 대시보드 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036344521/original/ElAzZg_lJq6zOxBf3_9nSBAlXhNcF2u3VA.png?1731329783)

2. 버튼을 찾아요. 각 사이트 옆에 **WP Admin** 버튼이 있어요.

   ![사이트 옆에 표시된 WP Admin 버튼](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036344537/original/eH98xg4l8ybOKn_6W_mU1nmIkBXZTtAqFg.png?1731329799)

3. **WP Admin** 버튼을 눌러요. 로그인 화면 없이 바로 WP Admin으로 이동해요.

   ![WP Admin 버튼을 눌러 관리자 화면으로 이동한 모습](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155036345893/original/HNoDROTwXv9oyHABA8LCsLgzLGaxNVHXTg.png?1731330733)

이제 관리자 화면에서 WordPress 사이트를 관리하면 돼요. 싱글 사인온을 쓰면 비밀번호 없이도 로그인 정보를 안전하게 지킬 수 있어요.
