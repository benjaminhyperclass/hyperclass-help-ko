# 전화번호 구성 편집 (수신 통화 설정)

**Incoming Call Settings**(수신 통화 설정) 화면에서는 수신 통화의 연결 방식, 벨 울림, 음성 메시지, 백업 동작을 한 화면에서 설정할 수 있어요. 이제 이 화면에서 **수신 통화 시간 초과**를 알맞게 정하도록 안내해 줘요. 덕분에 통화가 통신사 음성 메시지가 아닌 CRM 음성 메시지로 연결되고, 통화 상태도 더 정확하게 기록돼요.

---

## 개요

**Incoming Call Settings** 화면에는 수신 통화를 연결하거나, 가로채거나, 다른 곳으로 넘기는 모든 요소가 모여 있어요. 통화 착신 전환, 팀원 벨 울림, IVR, 음성 AI, 음성 메시지, 시간 초과 동작이 여기에 포함돼요.

통화 흐름의 우선순위를 한눈에 보여 주고 권장 설정을 안내하기 때문에, 통화 흐름 문제를 찾아내고 잘못된 설정을 막고 통화가 제대로 처리되는지 확인하기 쉬워요.

---

## 구성 편집(수신 통화 설정)이란?

수신 통화의 연결 규칙을 한 창에 모아서 보여 주는 화면이에요. 각 섹션에서 다음 내용을 확인할 수 있어요.

- 연결 옵션을 사용 중인지 여부
- 어떤 사용자, 번호, 시스템이 통화를 담당하는지
- 시스템이 통화 연결 대상을 확인하는 우선순위

통화가 울리지 않거나 예상과 다르게 연결될 때 원인을 짐작에 의존하지 않고 확인할 수 있어요.

---

## 수신 통화 설정의 주요 장점

- 투명한 확인: 어떤 규칙이 1순위, 2순위, 3순위로 통화를 받는지 정확히 볼 수 있어요.
- 바로 편집: 대부분의 설정을 페이지를 벗어나지 않고 바꿀 수 있어요.
- 명확한 우선순위: 시스템이 연결 경로를 어떤 순서로 확인하는지 이해할 수 있어요.
- 빠른 문제 해결: 잘못 설정된 시간 초과 값이나 사용자를 빠르게 찾을 수 있어요.
- 통화 처리 개선: 부재중 통화와 연결 오류를 줄일 수 있어요.

---

## 전화번호 구성 편집 열기

**Incoming Call Settings** 화면을 여는 방법이에요.

1. **설정 > 전화번호**로 이동하세요.
2. **전화번호** 탭을 여세요.
3. 전화번호 옆의 점 세 개 메뉴를 클릭하세요.
4. **구성 편집**을 선택하세요.

## 기본 정보

**기본 정보** 탭에서 설정할 수 있는 항목이에요.

- **표시 이름**: 전화번호의 이름을 바꿔요.
- **통화 연결 대상**: 기본으로 통화를 받을 팀원을 선택해요.
- **Ring Options**(벨 울림 옵션): 통화가 동시에 울릴 곳을 선택해요.
  - **Web App**(웹 앱)
  - **모바일 앱**
  - **전화번호**
  - **VoIP 데스크폰**
- **통화 녹음**
  - 녹음을 켜거나 꺼요.
  - 녹음 안내 메시지를 재생해요.

## Call Forwarding 탭

**Call Forwarding**(통화 착신 전환) 탭에서는 통화를 바로 받지 않을 때 어디로 연결할지 정해요.

### 통화 연결 대상 (우선순위)

- **IVR**: 워크플로우 또는 메뉴 입력에 따라 통화를 연결해요.
- **Team Member**(팀원) (**1순위**)
- **외부 전화번호** (**2순위**)
- **음성 AI** (**3순위**)

우선순위에 따라 한 번에 한 곳만 울려요.

### Ring More Team Members

- **Ring More Team Members**(팀원 더 울리기)를 켜면 최대 6명의 사용자를 추가로 울릴 수 있어요.
- 기기 아이콘으로 각 사용자가 어떤 기기를 켜 두었는지 확인할 수 있어요.

---

## 수신 통화 시간 초과 (새 안내)

**수신 통화 시간 초과**는 통화가 백업 연결 대상(**음성 AI** 또는 **음성 메시지**)으로 넘어가기 전까지 얼마나 오래 울릴지 정하는 값이에요.

### 권장 시간 범위

값이 적정 범위를 벗어나면 하이퍼클래스가 안내를 보여 줘요.

- 너무 높은 경우(약 20초 초과)
  - 통화가 CRM 음성 메시지가 아닌 통신사 음성 메시지로 연결될 수 있어요.
  - 통화 상태가 **음성 메시지**가 아닌 **완료**로 표시될 수 있어요.
- 너무 낮은 경우(약 15초 미만)
  - 벨이 너무 짧게 울리거나 연결되지 않을 수 있어요.
  - 발신자가 받을 시간이 충분하지 않을 수 있어요.
- **추천**: 약 20초

권장 범위를 벗어난 값을 입력하면 경고 메시지가 나타나서, 더 알맞은 시간을 고르도록 도와줘요.

![권장 범위를 벗어난 수신 통화 시간 초과 값에 경고 메시지가 표시된 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064214884/original/45JX6qVuEXUbp-EZxDcpm-1w3sSX8rWzgw.png?1770236921)

{% hint style="info" %}
이 기능은 안내일 뿐이에요. 권장 범위를 벗어난 값도 저장할 수 있어요. 다만 음성 메시지 연결과 통화 상태의 정확도에 영향을 줄 수 있어요.
{% endhint %}

## 백업 동작

**수신 통화 시간 초과**에 도달하면 통화는 백업 연결 대상으로 넘어가요.

- **음성 AI**: 통화를 AI 에이전트에게 연결해요.
- **음성 메시지**: 통화를 CRM 음성 메시지로 연결해요.

시간 초과 값을 알맞게 정하면 통화가 통신사 음성 메시지 시스템이 아닌 CRM 음성 메시지로 연결돼요.

## 통화 흐름 우선순위 이해하기

시스템은 수신 통화의 연결 경로를 정해진 순서대로 확인해요.

1. 번호에 연결된 워크플로우, IVR 또는 자동화
2. 전화번호에 직접 배정된 사용자
3. 연락처에 배정된 사용자
4. 여러 사용자에게 수신 전화를 동시에 울리기(Ring-All)
5. 착신 전환 번호

사용할 수 있는 순위 중 가장 높은 순위만 울려요. 통화가 연결되거나 전달되면 낮은 순위는 건너뛰어요.

{% hint style="info" %}
비공개 번호나 발신자 표시 제한 번호의 수신 통화를 받으려면 **설정 > 전화 시스템 > 음성 > 기타 설정 > 수신 통화**로 이동해 **비공개 통화 허용**을 켜세요.
{% endhint %}

## 자주 묻는 질문

### 수신 통화 설정은 누가 열 수 있나요?
**전화번호**를 관리할 권한이 있는 사용자라면 누구나 열 수 있어요.

### 새로 생긴 시간 초과 안내가 통화 흐름을 자동으로 바꾸나요?
아니요. 권장 값만 보여 주고, 설정을 강제로 적용하거나 덮어쓰지 않아요.

### 예전에는 왜 일부 통화가 **음성 메시지**가 아닌 **완료**로 표시됐나요?
시간 초과 값이 너무 높으면 통화가 CRM 음성 메시지가 아닌 통신사 음성 메시지로 연결될 수 있어요. 이 경우 통화 상태가 잘못 표시돼요.

### 발신 통화에도 영향이 있나요?
아니요. **발신 통화 시간 제한**은 따로 설정하며, 이 안내의 영향을 받지 않아요.

### 시간 초과 값을 아주 높거나 낮게 설정해도 되나요?
설정할 수는 있지만 권장하지 않아요. 통화 연결과 상태 기록의 정확도에 문제가 생길 수 있어요.
