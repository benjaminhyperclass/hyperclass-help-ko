# 이메일 통계 확인하기

이 문서에서는 하이퍼클래스에서 이메일 통계를 확인하는 위치와 각 지표의 의미를 안내해요. 통계를 보면 캠페인 성과를 점검하고 수신자 반응을 높이는 데 도움이 돼요.

## 이메일 통계란?

하이퍼클래스의 이메일 통계에서는 캠페인, 워크플로우, 일괄 작업으로 보낸 이메일에 수신자가 어떻게 반응했는지 확인할 수 있어요. 이 정보로 이메일 전달률을 높이고, 콘텐츠 전략을 다듬고, 발신자 평판을 관리할 수 있어요.

## 이메일 통계의 장점

통계를 보면 이메일 전달률과 성과를 높이는 데 바로 쓸 수 있는 정보를 얻을 수 있어요.

- 열림, 클릭, 반송, 스팸 지표를 실시간으로 확인해요.
- 캠페인, 워크플로우, 일괄 이메일 단위로 통계를 확인해요.
- 성과가 좋은 제목과 템플릿을 찾아요.
- 연락처별 정보를 보고 문제를 자세히 살펴봐요.
- 통계를 활용해 목록을 나누고 자동화를 설정해요.
- 구독취소나 전달 실패 같은 문제를 빠르게 찾아요.

## 이메일 마케팅 통계

일회성 이메일과 예약 발송 이메일의 성과를 확인할 수 있어요. 이메일 마케팅 통계를 보려면 **마케팅 > 이메일**로 이동하세요.

### 참여 요약

**Engagement Summary**(참여 요약) 그래프에서는 이메일의 전달, 반응, 전환 성과를 한눈에 확인할 수 있어요.

![참여 요약 그래프](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047443663/original/uDOyxXUTTVdB9hcUinOrd8chxwugCgQjng.png?1748532751)

### 성과 분석

**Performance Analysis**(성과 분석)에서는 전달률, 반송률, 구독취소, 스팸 신고 같은 주요 지표가 시간에 따라 어떻게 달라지는지 볼 수 있어요. 드롭다운으로 참여 지표를 바꿔 가며 선택한 기간 동안 캠페인 유형별 성과를 비교해 보세요.

![성과 분석 그래프](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047443908/original/pCFujPNHT4GYiMwU43HXeFAqHz_c0uh8Pg.png?1748532997)

### 성과가 좋은 이메일

**Top Performing Emails**(성과 상위 이메일)에서는 열림률이나 클릭률을 기준으로 가장 성과가 좋은 이메일을 순위로 볼 수 있어요. 어떤 이메일이나 발송 시간대가 수신자에게 반응이 좋은지 파악할 수 있어요.

![성과 상위 이메일 목록](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047444373/original/vXEspSdC_ruYOQnmkJpcuHVIardnXpOBaA.png?1748533403)

## 워크플로우 이메일 통계

워크플로우 안에서 자동 발송되는 이메일 단계별 성과를 바로 확인할 수 있어요. 자동 이메일이 수신자에게 얼마나 잘 도달하고 반응을 얻는지 알 수 있어요. 워크플로우 이메일 통계를 보려면 다음과 같이 하세요.

1. **자동화 > 워크플로우**로 이동해요.
2. 워크플로우를 열고 **Email**(이메일) 액션을 선택해요.
3. 오른쪽 패널에서 **Statistics**(통계)를 클릭해요.

다음 지표를 확인할 수 있어요.

- 전달됨
- 열림
- 클릭됨
- 답장됨
- **Bounced**(반송)
- 구독취소
- **Complained**(스팸 신고)
- 수락됨
- **Rejected**(거부됨)

{% hint style="info" %}
요약 화면과 결과를 맞추기 위해 워크플로우 이메일 통계는 기본으로 **최근 30일** 기준으로 표시돼요.
{% endhint %}

![워크플로우 이메일 통계 패널](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155047444702/original/Z2UIfHmUNTtgGi2GxUcuPxgzx8BKRHC-yQ.png?1748533775)

## 일괄 이메일 통계

**연락처 > 일괄 작업** 탭에서 일회성 일괄 이메일 발송의 성과를 확인할 수 있어요. 자동화나 캠페인과 별개로 대량 발송을 점검할 때 유용해요. 수신자별 성과도 볼 수 있어서 전달 문제를 찾거나 후속 작업 대상을 나누기 쉬워요. 통계를 확인하려면 다음과 같이 하세요.

1. **연락처 > 일괄 작업**으로 이동해요.
2. 작업 목록에서 해당 이메일 발송 건을 찾아요.

다음 항목별 수치를 확인할 수 있어요.

- **Total Attempts**(총 시도 수)
- 전달됨
- 열림
- 클릭됨
- 답장됨
- **Bounced**(반송)
- 구독취소

## 이메일 지표 정의

| 지표 | 의미 |
| --- | --- |
| **수신자** | 발송 대상이 된 연락처 수 |
| **전달됨** | 수신자 서버가 정상적으로 받은 이메일 |
| **열림** | 이메일을 한 번 이상 본 경우 |
| **클릭됨** | 이메일 안의 링크를 클릭한 경우 |
| **Soft Bounce**(일시적 반송) | 일시적인 문제로 전달되지 않은 경우(예: 받은편지함이 가득 참) |
| **Hard Bounce**(영구적 반송) | 영구적인 문제로 전달되지 않은 경우(예: 존재하지 않는 이메일 주소) |
| **구독취소** | 이메일 하단 링크로 수신을 거부한 경우 |
| **실패** | 유효하지 않은 이메일 주소, 잘못된 API 키 등으로 발송되지 않은 경우 |
| **스팸 신고** | 수신자가 스팸으로 신고한 경우 |
| **답장됨** | 연락처가 답장한 경우 |
| **수락됨** / **Rejected**(거부됨) | SMTP 단계에서 수락되었는지 여부 |

## 자주 묻는 질문

### 일시적 반송과 영구적 반송은 어떻게 다른가요?
일시적 반송(Soft Bounce)은 받은편지함이 가득 찬 경우처럼 일시적인 문제예요. 영구적 반송(Hard Bounce)은 존재하지 않는 이메일 주소처럼 영구적인 문제이며, 발신자 평판에 나쁜 영향을 줄 수 있어요.

### 이메일 통계가 업데이트되기까지 얼마나 걸리나요?
대부분의 이메일 통계는 거의 실시간으로 업데이트돼요. 다만 클릭, 구독취소, 스팸 신고 같은 일부 이벤트는 수신자의 활동이나 이메일 제공업체의 지연에 따라 반영되기까지 몇 분 걸릴 수 있어요.

### 전체 이메일 통계를 보려면 Mailgun을 사용해야 하나요?
네. 전달됨, 반송, 구독취소, 스팸 신고 같은 주요 지표를 모두 확인할 수 있는 곳은 Mailgun뿐이에요. 다른 SMTP 제공업체는 열림과 클릭 같은 기본 추적만 지원할 수 있어요.
