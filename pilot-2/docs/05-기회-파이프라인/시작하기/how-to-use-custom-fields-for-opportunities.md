# 기회용 커스텀 필드 사용하기

기회용 커스텀 필드를 쓰면 기회마다 필요한 정보를 직접 정해 담고, 종류별로 정리할 수 있어요. 기회 팝업 창 안에서 커스텀 필드를 만들고, 분류하고, 폴더로 묶을 수 있어요. 연락처와 똑같이 쉽게 설정할 수 있어요.

{% hint style="info" %}
이 기능은 현재 **실험실**에서 사용할 수 있어요.
{% endhint %}

![실험실에서 기능을 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003923483/original/cjLoF2igsC2Qfr8s8sdBc17IoofwOaeQhQ.png?1690539467)

## 이 기능은 무엇인가요?

기회용 커스텀 필드를 쓰면 영업 기회에 필요한 데이터 필드를 직접 추가하고, 설정하고, 정리할 수 있어요.

잠재 매출이나 업무를 더 유연하고 정확하게 추적할 수 있어요. 우리 비즈니스나 영업 과정에만 있는 정보도 항목으로 넣을 수 있어요. 프로젝트 마감일, 상품 사양, 고객 선호 사항 같은 정보가 그 예예요.

커스텀 필드를 여러 폴더로 나누어 더 깔끔하게 볼 수도 있어요. 값이 비어 있는 필드를 숨기는 옵션도 있어서 기회 카드를 간결하게 볼 수 있어요.

### 활용 예시

- 영업 마감일: 기회마다 영업 종료 예정일 필드를 만들어 팀원 모두가 중요한 마감일을 알 수 있게 해요.
- 영업 단계: 최초 접촉, 니즈 파악, 협상, 최종 계약처럼 기회의 영업 단계를 구분해요.
- 상품 상세정보: 상품 모델, SKU, 서비스 유형처럼 기회와 관련된 상품이나 서비스 정보를 기록해요.
- 고객 선호 사항: 선호하는 연락 시간이나 고객이 요청한 특별 사항을 기록해요.
- 리드 유입 경로: 추천, 소셜 미디어, 우편 발송 등 리드가 어디서 들어왔는지 기록해요.
- 고객 예산: 고객의 예산이나 지출 가능 규모를 적어 두면 제안을 더 정확하게 맞출 수 있어요.
- 전환 가능성: 기회가 실제 판매로 이어질 확률을 표시해요. 우선순위를 정할 때 도움이 돼요. 숫자 필드로 만들고, 워크플로우의 **Math Operation**(수학 연산) 액션으로 값을 업데이트할 수 있어요.
- 다음 후속 연락일: 대화를 이어 가고 판매 가능성을 높이려면 언제 다시 연락할지 기록해 두세요.
- 연결된 캠페인: 기회가 특정 마케팅 캠페인과 연결되어 있다면, 어떤 캠페인에서 온 기회인지 추적하는 필드를 만들 수 있어요.
- 고객의 업종 또는 직업: 업종이나 직업을 알면 고객의 요구를 더 잘 이해하고 그에 맞게 소통할 수 있어요.

## 사용 방법

1. 서브 계정의 **설정** 페이지로 이동하세요. 커스텀 필드를 만드는 메뉴가 여기에 있어요. 설정으로 이동하는 방법은 이 한 가지예요.
2. **설정**에서 **커스텀 필드**를 선택한 다음, **필드 추가** 또는 **필드 만들기**를 클릭하세요.

   ![커스텀 필드에서 필드 추가를 클릭하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003926979/original/l5FROAGJ8IFlg3fyI27xzUWJiXYdCRSi-A.png?1690541104)

3. 오브젝트로 **기회**를 선택하고, 커스텀 필드 유형(한 줄 텍스트, 숫자, 드롭다운 등)을 고르세요. 용도에 맞는 이름도 붙이세요. 예를 들면 '프로젝트 시작일', '영업 단계' 같은 이름이에요.

현재 기회에 추가할 수 있는 커스텀 필드 유형은 다음과 같아요.

![추가할 수 있는 필드 유형 목록 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003927631/original/s-ZgSCwM-EvvgQQDaE89KhGVZe6tcCH2dQ.png?1690541399)

- **Text Input**(텍스트 입력)
- **Single Line**(한 줄)
- **Multi-Line**(여러 줄)
- **텍스트 박스 목록**
- **Values**(값)
- **Number**(숫자)
- **Phone**(전화번호)
- **Monetary**(금액)
- **옵션 선택**
- **단일 드롭다운**
- **Dropdown (Multiple)**(다중 드롭다운)
- **라디오 선택**
- **Checkbox**(체크박스)
- **Date Picker**(날짜 선택기)
- **서명**
- **Rich text**(서식 있는 텍스트)
- **URL**: 모든 도메인 허용, 특정 도메인만 허용, 특정 도메인 차단 중에서 고를 수 있어요.
- **날짜 및 시간**: 날짜, 시간 또는 둘 다 받을 수 있어요. 미래 날짜만, 과거 날짜만, 또는 특정 범위로 제한할 수 있고, 선택할 수 있는 요일도 정할 수 있어요.
- **사용자**: **다중 사용자 허용**을 켜면 한 명 이상을 지정할 수 있어요. 나중에 이 설정은 바꿀 수 없어요. 지정된 사용자는 팔로워 수준의 접근 권한을 가져요.

{% hint style="info" %}
**파일 업로드** 필드 유형은 보통 사용할 수 있지만, 기회에서도 쓸 수 있도록 현재 작업 중이에요. 완성되면 기회 섹션의 커스텀 필드에 파일을 바로 올릴 수 있어요.
{% endhint %}

4. 이제 **기회 관리**와 **연락처** 옵션이 보여요. 필요한 정보를 입력한 뒤 **기회 관리**를 선택하고 **저장**을 클릭하세요.

   ![기회 관리를 선택하고 저장하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003927964/original/Dpk6HxzTu7ktlVvscbUdiiOrv1s4Vh_E0A.png?1690541537)

5. 기회용 커스텀 필드를 폴더로 묶으면 필드를 더 잘 분류하고 정리할 수 있어요. **커스텀 필드**의 **폴더**로 이동해 새 폴더를 만들고, 이름을 입력한 다음 오브젝트로 **기회**를 선택하세요.

   ![폴더를 만들고 오브젝트로 기회를 선택하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003928158/original/hqiCkHKiwMvZ4IjsBY5DV6ZMOpJ2Lbm04A.png?1690541617)

6. 기회를 만들거나 편집할 때 **기회 관리** 섹션에 새 커스텀 필드가 나타나요. 필요한 정보를 입력하세요.

   ![기회 편집 화면에 표시된 커스텀 필드](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003928314/original/61fXXWE6LCSQzCWb2yXucfHQvYoVYfomYg.png?1690541722)

7. 커스텀 필드가 많은데 값이 없는 필드는 보고 싶지 않다면 **Hide Empty Fields**(빈 필드 숨기기) 기능을 켜세요.

   ![빈 필드 숨기기를 켜는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155003928544/original/fNguPFyCZ_-nW3ohktcraHSqkr35cvxy3A.png?1690541797)

## 자주 묻는 질문

### 기회에서 커스텀 필드는 어디에서 볼 수 있나요?
**기회 관리**에서 기회를 선택하거나 새로 만들면 커스텀 필드가 목록으로 보여요. 기회를 편집할 때는 이 필드에 값을 입력할 수 있어요. 필드를 폴더로 정리해 두었다면 폴더가 차례대로 표시돼요.

### Hide Empty Fields 기능은 어떤 역할을 하나요?
이 기능을 켜면 현재 값이 없는 필드를 모두 숨겨요. 나에게 필요하거나 관련 있는 필드에만 집중할 수 있어서 기회 데이터를 더 깔끔하게 볼 수 있어요.
