# 제휴 포털 사용하기

새 **제휴 포털**(Affiliate Portal)에서는 제휴 프로그램에 참여하고, 제휴 리포트를 확인하고, 지급을 관리할 수 있어요. 이 문서에서 차례대로 안내해요.

{% hint style="info" %}
하이퍼클래스 계정에 로그인하지 않은 상태에서 **제휴 포털**에 접속하는 방법은 하이퍼클래스 고객지원에 문의하세요.
{% endhint %}

{% hint style="info" %}
이 기능은 에이전시 관리자에게만 보여요.
{% endhint %}

{% hint style="info" %}
현재 **제휴 포털**을 업데이트하는 중이라, 이 문서의 일부 동영상과 이미지가 실제 화면과 다를 수 있어요. 곧 최신 화면으로 모두 바꿀 예정이에요. 그동안 궁금한 점이 있으면 에게 문의하세요.
{% endhint %}

## 하이퍼클래스 제휴 프로그램이 처음이에요

제휴 프로그램에서는 내가 소개한 고객이 소프트웨어를 이용하는 동안 매달 40%의 반복 수수료를 지급해요. 제휴 활동을 시작하는 데 도움이 되는 자료와 리소스도 많이 준비되어 있어요.

시작하려면 **제휴 포털**에서 계정을 설정해야 해요. 아래에서 설정 방법을 안내해요.

![제휴 포털 소개 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068656862/original/5336qhOWDDUaxYzKbL6yRUDUQ26ZvY9MLA.png?1775624687)

## 내가 이미 제휴 회원인지 어떻게 알 수 있나요?

에이전시 계정은 하이퍼클래스에 가입할 때 고유한 제휴 링크(프로모터 추천 코드)를 자동으로 받아요. 링크를 확인하고 홍보를 시작하려면 **제휴 포털**에 들어가 간단한 온보딩 단계를 마치세요.

**제휴 포털**에서는 다음을 할 수 있어요.

- 내 고유 추천 링크 확인
- 성과와 진행 상황 추적
- 수수료 지급 내역 확인

그 밖에도 제휴 활동을 관리하고 키우는 데 필요한 기능이 모여 있어요.

**제휴 포털**에 들어가려면 먼저 **Agency View**(에이전시 보기) 상태인지 확인하세요.

- 왼쪽 메뉴에서 **제휴 포털**을 클릭하세요.

**제휴 포털**을 처음 열면 **대시보드**에 하이퍼클래스 제휴 프로그램의 혜택을 보여 주는 환영 배너가 나와요. 반복 수수료, 제휴 지원, 전용 혜택, 제휴 수익에 대한 정보도 함께 볼 수 있어요.

제휴 프로그램 약관을 확인하고 동의하는 방법은 다음과 같아요.

1. **Agency View**(에이전시 보기)에서 왼쪽 메뉴의 **제휴 포털**을 선택하세요.
2. **대시보드** 탭에서 다음 자료를 확인하세요.
   - **Affiliate Policy**(제휴 정책)
   - **Compliance Video**(규정 준수 영상)
   - **Marketing Toolkit**(마케팅 툴킷)
   - **Compliance Flowchart**(규정 준수 순서도)
3. **I have read and accepted the Affiliate Policy**(제휴 정책을 읽고 동의합니다) 체크박스를 선택하세요.
4. **Accept Terms & Join Now**(약관에 동의하고 지금 가입)를 클릭하세요.

온보딩을 마치면 **제휴 포털**에서 추천 링크 확인, 제휴 성과 조회, 지급 관리를 할 수 있어요.

이제 제휴 회원으로서 하이퍼클래스를 홍보할 수 있어요.

- 포털에서 다음 내용을 확인할 수 있어요.

  - 내 상태와 전체 진행 상황
  - 내 고유 추천 링크로 가입한 사람
  - 제휴 활동을 키우는 데 도움이 되는 자료

### 제휴 링크는 어디에서 찾나요?

기본 제휴 링크(프로모터 추천 코드)는 **제휴 포털 > 대시보드**에서 찾을 수 있어요.

![대시보드에서 제휴 링크를 확인하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155085050963/original/PQLAm_ddhyBcIz8tqrh5BRkdTFJ6C3ajRg.png?1793888898)

### Pro 요금제 제휴 링크와 다른 상품을 홍보하는 링크는 어디에서 찾나요?

먼저 제휴 **대시보드**에서 캠페인을 선택하세요.

{% hint style="info" %}
이미 어떤 캠페인 안에 들어와 있을 수 있어요. 다른 캠페인이 보이지 않으면 **All Campaigns**(전체 캠페인)를 클릭하세요.
{% endhint %}

- "하이퍼클래스 제휴 프로그램" 캠페인을 선택하세요.
- 캠페인마다 고유 링크가 따로 필요하지는 않아요. "하이퍼클래스 제휴 프로그램" 캠페인의 링크를 쓰면 돼요.

### 링크를 바꾸거나 추천 코드를 변경할 수 있나요?

네, 할 수 있어요. 링크 끝에 붙은 추천 토큰을 바꾸려면 링크 사용자 지정 버튼을 클릭하세요.
- 청중이 쉽게 알아볼 수 있는 고유 링크를 만들기 위해 변경하는 것을 권장해요.

**제휴 포털**에서 하이퍼클래스 제휴 프로그램 캠페인에 들어간 뒤 다음 순서로 진행하세요.

![추천 토큰을 사용자 지정하는 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068661679/original/M1sZuHBUzDkU7lgYl-qyJ7IuX2Paf30UvQ.png?1775631403)

1. **Customize Token**(토큰 사용자 지정)을 클릭하세요.
2. 추천 ID를 기억하기 쉽고 알아보기 쉬운 값으로 바꾸세요.

{% hint style="warning" %}
변경 전에 이미 기존 링크를 홍보했다면, 그 링크는 더 이상 작동하지 않아요. 제휴 활동을 시작할 때 미리 바꿔 두는 것을 권장해요.
{% endhint %}

### 링크로 맞춤 추적을 할 수 있나요?

네, 할 수 있어요. 프로모터 ID는 하나만 두고 링크 변형을 여러 개 만들면, 어떤 링크에서 클릭과 추천이 들어왔는지 추적할 수 있어요. 이를 위해 SubID를 만들면 돼요.

SubID를 쓰면 제휴 링크를 홍보하는 채널별로 링크를 따로 만들 수 있어서 전환을 더 잘 추적할 수 있어요.

## 이미 제휴 회원이에요. 리포트는 어디에서 보나요?

### 내가 추천한 사람은 어떻게 확인하나요?

**제휴 포털 > Referrals**(추천 내역)에서 내 제휴 링크로 가입한 최근 사용자 목록을 볼 수 있어요. 내 리드를 체험, 고객, 결제 중, 취소로 나눈 현황도 확인할 수 있어요.

[Referrals 탭에 대한 자세한 내용은 이 문서를 확인하세요.](affiliate-referral-page-leads-customers-cancelled-statuses.md)

성과가 좋은 제휴 회원들은 이 정보를 활용해 추천한 에이전시 고객들을 위한 커뮤니티나 그룹(Slack 채널, Facebook 그룹 등)을 만들어요. 고객들을 멘토링하고 오래 성공하도록 돕기 위해서예요. 하이퍼클래스는 반복 수익을 지급하기 때문에, 이런 활동이 내 지급액에 직접 영향을 줘요.

새 추천이 들어오거나 상태가 바뀔 때 이메일을 받으려면 알림도 꼭 켜 두세요.

## 지급은 어떻게 받나요?

**제휴 포털 > 결제 정보**에서 지급 환경설정을 할 수 있어요.

제휴 지급에는 "Tipalti"라는 플랫폼을 사용해요. Tipalti를 쓰면 제휴 회원이 다양한 결제 방법을 요청하고, 세금 서류를 정리하는 등의 작업을 할 수 있어요.

**결제 정보**로 이동해 계정 정보를 설정하면 Tipalti로 지급을 받을 수 있어요.

![결제 정보 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48179173405/original/YGgsBYyjF3t2Y1dDzbrlTXkO9rn8wNtOVw.png?1642177068)

현재는 Tipalti를 사용하지 않으면 제휴 지급을 받을 수 없어요.

{% hint style="info" %}
이 정보는 에이전시 관리자 권한이 있는 모든 사용자가 볼 수 있어요. 다른 에이전시 사용자에게 보이지 않게 하려면 해당 사용자의 역할을 에이전시 사용자로 바꾸세요.

**에이전시 설정 > 팀 > 사용자 편집 > User roles**(사용자 역할)
{% endhint %}

[설정을 모두 마쳤는데도 포털 오류가 나거나, 결제 대기 상태이거나, 아직 지급을 받지 못했나요? 이 문서를 확인하세요.](affiliate-payouts-where-how-when-can-i-get-paid.md)

Tipalti의 장점은 다음과 같아요. Tipalti는 결제 관리를 돕고, 더 다양한 결제 방법을 제공하고, 제휴 관계에 필요한 서류를 규정에 맞게 처리하도록 도와줘요.

새로운 결제 방법

- 미국 거주 제휴 회원: 계좌 입금, PayPal, 체크카드
- 해외 제휴 회원: ACH 이체, PayPal, 체크카드

간단한 온보딩

- 몇 분 만에 계정을 설정할 수 있어요.
- 가입 과정에서 원하는 결제 방법을 선택하고 설정할 수 있어요.
- 앱에서 필요한 세금 서류를 작성할 수 있어요.

결제를 한곳에서 관리

- 결제 상태와 내역을 바로 확인할 수 있어요.
- 결제 방법을 변경할 수 있어요.

### 지급 방식 이해하기

전월에 발생한 모든 수수료를 매달 15일에 승인하고 지급해요. 예를 들어 3명이 내 제휴 링크로 가입해 9월 1일부터 9월 30일 사이에 $297 구독료를 결제했다면, 10월 15일에 3 x $118($297 x 40% x 3)을 받아요.

{% hint style="info" %}
신규 가입자는 모두 14일 체험으로 시작해요. 수수료는 체험 가입일이 아니라 실제로 유료 고객이 된 날짜를 기준으로 집계해요.

결제 방법에 따라 입금까지 24~48시간 늦어질 수 있어요.
{% endhint %}

## 내가 추천한 사람이 제휴 회원이 되면 나도 보상을 받을 수 있나요?

네, 받을 수 있어요. 내 제휴 계정 아래에 제휴 회원을 더 추가(서브 제휴)하면, 그들이 올린 매출에서 2차 수수료를 받아요. 하이퍼클래스는 1단계 수수료(매월 반복 40%)와 2단계 수수료(매월 반복 5%)를 지원해요.

{% hint style="info" %}
현재 활동 중인 하이퍼클래스 제휴 회원은 이미 모두 내 계정의 서브 제휴로 추가되어 있어요. 이 기능은 하이퍼클래스 에이전시에 로그인하지 않고 제휴 대시보드에만 로그인하려는 사용자에게만 사용하세요.
{% endhint %}

자세한 내용은 제휴 정책을 참고하세요. 정책 링크가 필요하면 하이퍼클래스 고객지원에 문의하세요.

### 서브 제휴는 어디에서 보나요?

**제휴 포털 > Sub-Affiliates**(서브 제휴)에서 내 서브 제휴와 2단계 수수료를 확인할 수 있어요.

**Sub-Affiliates** 탭에서는 내 제휴 고객들이 하이퍼클래스를 얼마나 잘 홍보하고 있는지 볼 수 있어요. 그들이 하이퍼클래스에 추천한 고객에게서도 5% 수수료를 받아요.
