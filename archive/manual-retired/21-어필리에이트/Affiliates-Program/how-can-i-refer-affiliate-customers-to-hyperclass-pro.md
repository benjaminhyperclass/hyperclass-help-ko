# 제휴 고객을 하이퍼클래스 프로 플랜으로 추천하기

이미 제휴로 연결된 기존 고객을 프로 플랜으로 업그레이드하게 하고 싶을 때 보는 문서예요. 제휴 링크를 찾는 방법과 기존 고객·신규 고객별 추천 절차, 자주 묻는 질문을 안내해요.

신규 고객을 프로 플랜으로 추천하려면 **제휴 포털**에 있는 프로 플랜 14일 체험 링크를 쓰세요. 링크 위치는 [제휴 링크는 어디에서 찾나요?](how-to-use-affiliate-portal.md)를 참고하세요.

활성 체험 고객이 100명이고 30일 체험 링크가 필요하다면 

{% hint style="info" %}
**알림:** 지금 **제휴 포털**을 업데이트하는 중이라, 이 문서의 일부 동영상과 이미지가 실제 화면과 다를 수 있어요.

곧 최신 화면으로 모두 바뀔 예정이에요. 그 전에 궁금한 점이 있으면 에게 문의하세요.
{% endhint %}

{% hint style="info" %}
프로 플랜은 "SaaS 플랜" 또는 "월 $497 플랜"이라고도 불러요.
{% endhint %}

{% hint style="info" %}
이미 회원님 아래에 있는 고객이라면 따로 할 일은 없어요. 고객이 업그레이드하기만 하면 프로 플랜 구독에 대한 크레딧과 수수료를 계속 받아요.
{% endhint %}

{% hint style="warning" %}
기존 고객은 이 링크로 추가 14일 체험을 받을 수 없어요. 1~3 영업일 안에 $497 플랜으로 업그레이드되고, 결제일이 초기화되며 일할 계산한 금액이 청구돼요.
{% endhint %}

## 제휴 포털에서 프로 제휴 링크 찾기

1. **제휴 포털**을 클릭하세요.

   ![제휴 포털 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240205691/original/y_hZmzvshg8uhdeqQgV7ZYdXh_VBRTFntg.png?1658421171)

2. 아래로 스크롤해서 **링크**를 클릭하세요.

   ![아래로 스크롤해서 링크 클릭](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240205690/original/QBnrdpQavrNvjGZ-eqPZzSloPK6c2cGAqw.png?1658421171)

3. 링크가 최소 3개 보여요.
   - 기본: $97 스타터 계정용 14일 체험 링크
   - 기존 고객이 하이퍼클래스 $497 프로 플랜으로 업그레이드할 때 쓰는 링크
   - 신규 고객이 하이퍼클래스 $497 프로 플랜을 14일 체험할 때 쓰는 링크

2. 대시보드 맨 아래로 스크롤해서 링크를 찾으세요.

1. **Existing Customer Trial**(기존 고객 체험) 링크를 선택하세요.

   ![기존 고객 체험 링크 선택](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240225514/original/pP_cHHHn7Jl2MG07YVvj3iNfCCYQ-y2beQ.png?1658427039)

2. 새로 만들어진 URL을 복사하세요.

   ![새로 만들어진 URL 복사](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240225515/original/WWg-go_QIBrQO9TBhUc6nSTJpSMlLdovUQ.png?1658427039)

3. 복사한 링크를 고객에게 보내세요.
4. 기존 고객이 폼을 작성하게 하세요. 고객이 회원님의 링크를 **Affiliate Upgrade Credit**(제휴 업그레이드 크레딧) 칸에 붙여 넣어야 해요.

   ![제휴 업그레이드 크레딧 입력 칸](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240225517/original/SbkTpWbodQwgzbY0xr_EbQkGUpHFNZ3pqg.png?1658427039)

5. 페이지 하단의 일할 계산 안내를 확인하세요.

   ![페이지 하단의 일할 계산 안내](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240225516/original/h-6mCpjW2kIangeqFCKrOlaVx900MVqyxQ.png?1658427039)

{% hint style="warning" %}
기존 고객은 이 링크로 추가 14일 체험을 받을 수 없어요. 1~3 영업일 안에 $497 플랜으로 업그레이드되고, 결제일이 초기화되며 일할 계산한 금액이 청구돼요.
{% endhint %}

여기까지 하면 끝이에요. 변경 내용이 FirstPromoter나 **제휴 포털**에 반영되기까지 최대 48시간이 걸릴 수 있어요.

   ![무료 체험 폼 작성](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240231234/original/zjCd_0oJOEPXfJ77ak7PEBvVnA0M0mIaNg.png?1658429339)

## 자주 묻는 질문

### 고객이 $97 플랜을 쓰고 있는데 $297 플랜으로 업그레이드하려고 해요. 어떻게 되나요?

이제 Unlimited(월 $297) 플랜으로 업그레이드할 때도 크레딧을 나눠 받을 수 있어요. 추천 고객이 $97 플랜에서 $297 플랜으로 업그레이드할 때 회원님의 제휴 링크를 사용해야 크레딧을 받아요.

### 이 폼을 제출하면 고객이 자동으로 업그레이드되나요, 아니면 고객이 따로 업그레이드해야 하나요?

자동으로 업그레이드돼요. 처리 예상 시점이 궁금하면 하이퍼클래스 고객지원에 문의하세요.

### 기존 고객에게도 14일 체험을 줄 수 있나요?

아니요. 14일 체험은 신규 고객에게만 제공돼요.

### 다른 제휴 파트너가 30일 연장 프로 체험 링크를 주는 걸 봤어요. 그 링크는 어떻게 받나요?

30일 체험은 실적이 높은 제휴 파트너에게만 제공돼요. 활성 고객이 100명 이상이고 추천 고객에게 30일 체험을 주고 싶다면, 해서 자격이 되는지 확인하세요.

### 고객이 업그레이드하자마자 프로 플랜 요금이 청구됐어요. 무료 체험 아닌가요?

기존 하이퍼클래스 고객은 업그레이드 폼을 제출하면 바로 $497 플랜으로 업그레이드되며, 1~3 영업일이 걸려요. 결제일은 초기화되고 일할 계산한 금액이 청구돼요.

TOP 제휴 파트너라면 현재 구독 기준으로 일할 계산은 똑같이 적용돼요. 대신 한 달 동안 프로 플랜의 모든 기능을 쓸 수 있어요.

이 내용은 고객이 제출하기 전에 업그레이드 폼에도 안내돼 있어요.

### 제가 하이퍼클래스 프로로 추천하는 고객이 아직 어떤 제휴 파트너에게도 배정되지 않았어요. 수수료를 100% 받나요, 일부만 받나요?

회원님이 이 고객을 하이퍼클래스에 처음 추천한 것이 아니기 때문에, 기본 구독이 아니라 프로 구독과 업그레이드분에 대한 수수료만 받아요. 예를 들어 고객이 $297 플랜에서 $497 프로 플랜으로 업그레이드하도록 추천했다면, 고객이 구독료를 내는 매달 차액 $200의 40%를 받아요.
