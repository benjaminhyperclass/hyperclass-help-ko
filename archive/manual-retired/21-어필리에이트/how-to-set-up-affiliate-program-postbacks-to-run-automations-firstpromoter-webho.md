# 제휴 프로그램 포스트백(웹훅)으로 자동화 실행하기 (FirstPromoter)

제휴 링크로 누군가 가입했을 때 판매 흐름에 맞춰 자동화를 실행하려면 포스트백(웹훅)을 설정해야 해요. 이 문서에서는 제휴 링크용 포스트백을 만들고 워크플로우와 연결하는 방법을 안내해요.

{% hint style="info" %}
이 문서는 하이퍼클래스 제휴 프로그램에 관한 내용이에요. 서브 계정에 있는 **제휴 관리자** 기능에 관한 문서가 아니에요.
{% endhint %}

{% hint style="info" %}
**업데이트**

이제 포털에서 추천 활동에 대한 이메일 알림을 받을 수 있어요.

설정하는 방법은 다음과 같아요.

- **Affiliate Dashboard**(제휴 대시보드) 오른쪽 위에서 프로필 이름을 클릭하세요.
- **알림 설정**을 여세요.
- **알림 켜기**를 켜고 원하는 대로 설정하세요.

기본적으로 알림이 꺼져 있을 수 있으니 이 설정을 꼭 확인해 보세요.

알림은 켜 두기를 권장해요. 포털을 매번 열어 보지 않아도 변화를 가장 쉽게 알 수 있는 방법이에요.
{% endhint %}

---

## 포스트백(웹훅) 설정 단계별 안내

### 시작하기 전에 준비할 것

- 코어 포스트백 스냅샷(The Core Postback Snapshot)을 받으세요. 이 튜토리얼을 따라 포스트백을 설정할 때 쓰는 템플릿이 들어 있어요. 스냅샷을 받는 방법은 하이퍼클래스 고객지원에 문의하세요.
- [**Affiliate Dashboard**(제휴 대시보드)](Affiliates-Program/how-to-use-affiliate-portal.md)를 여세요.

### 1. 초기 설정과 이동

1. 에이전시 계정을 여세요.
2. 제휴 전용 서브 계정으로 이동하세요. 다른 캠페인이나 워크플로우가 실행되지 않는 전용 서브 계정이어야 해요.
3. [**제휴 포털**](Affiliates-Program/how-to-use-affiliate-portal.md) 탭을 클릭하세요.
4. **프로모터 리포팅**을 클릭하세요.
5. 아래로 스크롤해 **Postbacks**(포스트백)를 클릭하세요.

### 2. 워크플로우

포스트백마다 [**Inbound Webhook**](../07-워크플로우/빌더/how-to-use-the-inbound-webhook-workflow-premium-trigger.md)(인바운드 웹훅) 트리거로 시작하는 워크플로우가 하나씩 필요해요.

워크플로우마다 다음 순서로 진행하세요.

1. 포스트백 만들기
2. 테스트 포스트백 보내기
3. 워크플로우 안에서 샘플 요청 가져오기
4. 매핑 참조 저장
5. 워크플로우 **저장 및 게시**

샘플 페이로드가 없으면 워크플로우 트리거가 제대로 저장되지 않아요.

| 워크플로우 | 포스트백 이름 | 캠페인 | 트리거 이름 | Referral State(추천 상태) | 용도 |
| --- | --- | --- | --- | --- | --- |
| 1 - Lead 하이퍼클래스 | 1- Lead (Step 1) | 하이퍼클래스 제휴 프로그램 | Lead Subscribed | Subscribed | 결제 폼 1단계를 작성한 리드를 수집해요 |
| 2 - Trial Postback 하이퍼클래스 | 2 - On Trial (Step 2) | 하이퍼클래스 제휴 프로그램 | New Referral | Signup | 고객이 결제를 마치고 체험을 시작할 때를 수집해요 |
| 3 - 하이퍼클래스 Customer | 3 - 하이퍼클래스 Customer | 하이퍼클래스 제휴 프로그램 | 신규 고객 | Lead Becomes Referral | 고객이 앱 안에서 결제할 때를 수집해요(커미션 대상이 아닐 수 있어요) |
| 4 - Paying Affiliate Commission | 4 - Paying Affiliated Customer | 하이퍼클래스 제휴 프로그램 | New Commission | Reward Created | 체험이 끝나거나 고객이 커미션 대상 결제를 할 때를 수집해요 |
| 5 - Cancelled Customers | 5 - Cancellation | 하이퍼클래스 제휴 프로그램 | Lead Cancelled | Lead Cancelled | 고객 취소가 시작되어 구독이 끝날 때를 수집해요 |

### 핵심 포스트백 5가지

위 표를 따라 포스트백 5개를 설정해요. 코어 포스트백 스냅샷에 들어 있는 워크플로우 5개와 하나씩 짝이 맞아요.

1. Lead Subscribed
2. New Referral (체험 시작)
3. 첫 결제 고객
4. New Commission
5. 취소한 고객

---

## 1단계: Lead Subscribed 포스트백

제휴 가입 폼의 첫 단계를 마쳤지만 아직 체험을 시작하지 않은 사람이 있을 때 실행돼요.

### 포스트백 만들기

**Postbacks**에서 다음 순서로 진행하세요.

- **Create Postback**(포스트백 만들기)을 클릭하세요.
- **Name**(이름): `1 - Lead Subscribed`
- **Campaign**(캠페인): 하이퍼클래스 제휴 프로그램
- **Trigger**(트리거): **Lead Subscribed**(리드 구독)

### 워크플로우 연결하기

1. 해당 워크플로우를 여세요.
2. **Webhook URL**(웹훅 URL)을 복사하세요.
3. 복사한 URL을 **Postback URL**(포스트백 URL) 필드에 붙여 넣으세요.

### 테스트 데이터 보내기

1. **Test Postback**(포스트백 테스트)을 클릭하세요.
2. 워크플로우 트리거로 돌아가세요.
3. **Fetch Sample Request**(샘플 요청 가져오기)를 클릭하세요.
4. 매핑 참조를 저장하세요.
5. 트리거를 저장하세요.
6. 워크플로우를 저장하세요.

---

## 2단계: 체험 가입 / New Referral

누군가 체험을 시작할 때 실행돼요.

### 포스트백 만들기

- **Name**: `2 - Trial Signup`
- **Campaign**: 하이퍼클래스 제휴 프로그램
- **Trigger**: **New Referral**(신규 추천)

### 워크플로우 연결하기

두 번째 워크플로우의 웹훅 URL을 **Postback URL** 필드에 붙여 넣으세요.

### 설정 마무리

- **Test Postback**을 클릭하세요.
- 샘플 요청을 가져오세요.
- 매핑 참조를 저장하세요.
- 워크플로우를 저장하세요.

---

## 3단계: 첫 결제 고객

사용자가 처음으로 유료 고객이 될 때 실행돼요.

다음과 같은 경우에 해당해요.

- 체험 사용자가 앱 안에서 결제할 때
- 체험이 유료 고객으로 전환될 때

{% hint style="warning" %}
이 트리거는 고객 한 명당 한 번만 실행돼요.
{% endhint %}

### 포스트백 만들기

- **Name**: `3 - First Payment Customer`
- **Campaign**: 하이퍼클래스 제휴 프로그램
- **Trigger**: **신규 고객**

### 워크플로우 연결하기

세 번째 워크플로우의 웹훅 URL을 붙여 넣으세요.

### 설정 마무리

- **Test Postback**을 클릭하세요.
- 샘플 요청을 가져오세요.
- 매핑 참조를 저장하세요.
- 워크플로우를 저장하세요.

---

## 4단계: New Commission

커미션이 생길 때마다 실행돼요.

앞의 트리거와 달리, 같은 고객에게서 여러 번 실행될 수 있어요.

### 포스트백 만들기

- **Name**: `4 - New Commission`
- **Campaign**: 하이퍼클래스 제휴 프로그램
- **Trigger**: **New Commission**(신규 커미션)

### 워크플로우 연결하기

네 번째 워크플로우의 웹훅 URL을 붙여 넣으세요.

### 설정 마무리

- **Test Postback**을 클릭하세요.
- 샘플 요청을 가져오세요.
- 매핑 참조를 저장하세요.
- 워크플로우를 저장하세요.

{% hint style="info" %}
커미션이 생길 때마다 연락처가 워크플로우에 다시 들어오지 않게 하려면, 워크플로우 재진입을 끄거나 태그 로직을 대신 사용하세요.
{% endhint %}

---

## 5단계: 취소한 고객

고객 계정이 취소될 때 실행돼요.

{% hint style="warning" %}
취소 포스트백은 취소를 요청한 시점이 아니라 계정이 실제로 종료되는 시점에 실행돼요.

예를 들면 다음과 같아요.

- 체험 사용자는 체험이 끝날 때까지 계정이 유지돼요.
- 유료 사용자는 결제 주기가 끝날 때까지 계정이 유지돼요.
{% endhint %}

### 포스트백 만들기

- **Name**: `5 - Cancelled Customer`
- **Campaign**: 하이퍼클래스 제휴 프로그램
- **Trigger**: **Lead Cancelled**(리드 취소)

### 워크플로우 연결하기

다섯 번째 워크플로우의 웹훅 URL을 붙여 넣으세요.

### 설정 마무리

- **Test Postback**을 클릭하세요.
- 샘플 요청을 가져오세요.
- 매핑 참조를 저장하세요.
- 워크플로우를 저장하세요.

---

## 워크플로우 게시하기

워크플로우 5개를 모두 설정한 뒤 다음 순서로 진행하세요.

1. 워크플로우를 하나씩 여세요.
2. **게시**를 클릭하세요.
3. **저장**을 클릭하세요.

워크플로우를 게시하지 않으면 포스트백이 실행되지 않아요.

---

## 서브 ID 추가하기

### 서브 ID 이해하고 설정하기

서브 ID는 리드, 유입 경로, 체험이 어디에서 왔는지 추적하는 데 중요해요. 트래픽이 정확히 어디에서 들어오는지 알 수 있어요.

{% hint style="info" %}
콘텐츠마다 고유 링크를 만드는 건 번거로워요. 그래서 Instagram처럼 플랫폼 하나에 서브 ID를 하나만 만들어 두고, 그 플랫폼 전체의 성과를 추적하는 방법을 권장해요.
{% endhint %}

## 이메일 알림 설정

FirstPromoter에서 보내는 이메일 알림을 켤 수 있어요. 이 이메일로 새 리드와 결제 소식을 받은편지함에서 바로 확인할 수 있어요.
