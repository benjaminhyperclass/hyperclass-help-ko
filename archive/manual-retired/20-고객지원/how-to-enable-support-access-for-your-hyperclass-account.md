# 하이퍼클래스 계정에서 지원팀 액세스 켜기

**지원팀 액세스**를 켜면 문제를 확인하는 동안에만 하이퍼클래스 팀원이 계정에 들어올 수 있게 허용할 수 있어요. 이 설정은 에이전시 관리자만 쓸 수 있어요. 액세스는 하이퍼클래스 안에서 직접 관리하고, 만료일로 기간을 제한하며, 언제든 연장하거나 취소할 수 있어요. 지원을 받으면서도 계정 접근 현황을 더 분명하게 확인하고 통제할 수 있어요.

## 지원팀 액세스란?

지원팀 액세스는 문제 해결을 위해 하이퍼클래스 팀원이 내 계정에 잠시 접근하도록 허용하는 설정이에요. 에이전시가 직접 승인해야만 접근할 수 있고, 정해진 기간 동안만 유지되며, **회사 설정**에서 바로 관리해요.

하이퍼클래스 고객지원과 문의를 진행하면서 팀원이 계정 안에서 문제를 직접 살펴봐야 할 때 유용해요. 액세스가 더 필요 없으면 바로 취소하거나 만료될 때까지 그대로 둘 수 있어요.

![지원팀 액세스 설정 화면](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155072587584/original/9I6QRSn4_t05vE2EQ7oSBSrv-7spDclYPA.png?1780306972)

## 지원팀 액세스의 장점

빠른 문제 해결과 계정 보안을 함께 챙길 수 있어요. 액세스가 임시로 열리고 사용자가 직접 통제하므로, 하이퍼클래스 고객지원이 계정에 접근할 시점과 끝낼 시점을 에이전시가 정할 수 있어요.

- 사용자 승인 방식: 하이퍼클래스 팀원의 접근은 에이전시 계정 안에서 직접 켜야 가능해요.
- 기간 제한: 만료일을 정해 두면 액세스가 계속 열려 있지 않아요.
- 유연한 문제 해결: 문의 처리에 시간이 더 필요하면 액세스를 연장할 수 있어요.
- 즉시 취소: 문제 해결이 끝나면 언제든 지원팀 액세스를 취소할 수 있어요.
- 투명한 확인: 지원팀 액세스가 켜져 있는지, 언제 만료되는지 볼 수 있어요.
- 규정 준수 지원: 내부 보안 기준과 데이터 접근 요건에 맞춰 통제된 방식으로 액세스를 관리할 수 있어요.

## 지원팀 액세스 위치

지원팀 액세스는 **회사 설정**의 **고급 설정**에 있어요. 에이전시 수준의 다른 보안·계정 설정과 가까이 모여 있어요.

1. 하이퍼클래스에서 **에이전시 보기**로 이동하세요.
2. **설정**을 클릭하세요.
3. **회사**를 선택하세요.
4. **고급 설정** 탭을 여세요.
5. **지원팀 액세스** 섹션까지 스크롤하세요.

**지원팀 액세스** 섹션에서 액세스가 켜져 있는지 확인할 수 있어요. 켜져 있으면 지원팀이 접근할 수 있는 만료일도 함께 표시돼요.

## 지원팀 액세스를 켜야 하는 때

하이퍼클래스 고객지원과 문의를 진행 중이고, 문제를 조사하거나 해결하려면 임시로 계정 접근이 필요할 때 켜세요. 실제로 문제를 해결하는 동안에만 켜 두면 불필요한 접근을 줄일 수 있어요.

주로 이런 경우에 써요.

- 계정 설정 문제를 조사할 때
- 예상과 다르게 동작하는 기능을 확인할 때
- 접수한 문의와 관련된 설정을 검토할 때
- 지원팀이 계정 안에서 문제를 직접 확인해야 할 때

지원팀 액세스는 일반 사용자 접근과는 별개예요. 에이전시 사용자, 팀원, 역할, 권한은 사용자 접근 및 역할 설정에서 따로 관리해요.

## 지원팀 액세스 기간

지원팀 액세스는 기간이 정해져 있어요. 선택한 만료일까지만 켜져 있어서, 필요한 기간보다 오래 열려 있지 않아요.

지원팀 액세스가 켜져 있으면 접근이 가능한 날짜가 메시지로 표시돼요. 문제 해결에 시간이 더 필요하면 더 늦은 만료일을 선택해 연장할 수 있어요. 더 필요하지 않으면 바로 취소할 수 있어요.

## 지원팀 액세스 연장하기

액세스를 껐다가 다시 켜지 않고도 하이퍼클래스 고객지원이 계속 문제를 살펴볼 수 있어요. 아직 조사 중이거나 추가 검토가 필요할 때 유용해요.

1. **에이전시 보기 > 설정 > 회사 > 고급 설정**으로 이동하세요.
2. **지원팀 액세스**까지 스크롤하세요.
3. **Extend access**(액세스 연장)를 클릭하세요.
4. **Access expires on**(액세스 만료일) 필드에서 새 만료일을 선택하세요.
5. 지원팀 액세스가 언제까지 유지되는지 알려 주는 확인 메시지를 살펴보세요.
6. **저장**을 클릭하세요.

## 지원팀 액세스 취소하기

액세스를 취소하면 하이퍼클래스 팀원이 지원팀 액세스로 내 계정에 접근하는 것이 바로 차단돼요. 문제 해결이 끝났거나 임시 액세스를 더 유지하고 싶지 않을 때 사용하세요.

1. **에이전시 보기 > 설정 > 회사 > 고급 설정**으로 이동하세요.
2. **지원팀 액세스**까지 스크롤하세요.
3. **액세스 취소**를 클릭하세요.
4. 경고 메시지를 확인하세요.
5. **액세스 취소**를 다시 클릭해 확정하세요.

{% hint style="warning" %}
액세스를 취소하면 진행 중인 지원 세션이 즉시 종료될 수 있어요. 지원팀 액세스를 다시 켜기 전에는 접근을 재개할 수 없어요.
{% endhint %}

## 보안과 감사 가능성

지원팀 액세스를 쓰면 지원 관련 계정 접근을 더 분명하게 통제할 수 있어요. 계정 안에서 직접 승인하고 만료일로 기간을 제한하므로, 지원 과정을 내부 보안·규정 준수 기준에 맞추기 쉬워요.

지원팀 액세스는 다음을 지원해요.

- 하이퍼클래스 팀원이 접근하기 전의 명시적 승인
- 기간이 정해진 접근
- 현재 액세스 상태의 명확한 확인
- 연장과 취소에 대한 더 나은 통제
- 문제 해결을 위한 더 투명한 접근 관리

계정 활동을 더 넓게 확인하려면 하이퍼클래스에서 제공하는 감사 로그 관련 자료를 활용하세요.

## 지원팀 액세스 설정하기

필요할 때만, 선택한 기간 동안만 하이퍼클래스 고객지원이 계정에 접근하도록 설정하세요. 액세스를 켜기 전에 하이퍼클래스 고객지원과 문의를 진행 중인지, 임시 접근이 정말 필요한지 확인하세요.

지원팀 액세스를 켜려면 다음 순서로 진행하세요.

1. 하이퍼클래스에서 **에이전시 보기**로 이동하세요.
2. 왼쪽 메뉴에서 **설정**을 클릭하세요.
3. **회사**를 선택하세요.
4. **고급 설정** 탭을 여세요.
5. **지원팀 액세스**까지 스크롤하세요.
6. **지원팀 액세스** 토글을 켜세요.
7. 만료일을 선택하거나 확인하라는 안내가 나오면 따라 하세요.
8. 저장이 필요하면 설정을 저장하세요.
9. **지원팀 액세스** 섹션에 액세스가 켜져 있다는 메시지가 보이는지 확인하세요.

지원팀 액세스가 켜진 뒤에는 이렇게 관리해요.

- **Extend access**를 클릭하면 더 늦은 만료일을 선택할 수 있어요.
- **액세스 취소**를 클릭하면 액세스가 바로 끝나요.

## 자주 묻는 질문

### 지원팀 액세스는 어떤 기능인가요?
에이전시가 켜 두면 하이퍼클래스 팀원이 문제 해결을 위해 내 계정에 임시로 접근할 수 있어요.

### 지원팀 액세스는 어디에 있나요?
**에이전시 보기 > 설정 > 회사 > 고급 설정**으로 이동한 뒤 **지원팀 액세스** 섹션까지 스크롤하세요.

### 지원팀 액세스는 영구적인가요?
아니요. 지원팀 액세스는 기간이 정해져 있어서, 연장하지 않으면 선택한 만료일까지만 유지돼요.

### 지원팀 액세스를 연장할 수 있나요?
네. **Extend access**를 클릭하고 새 만료일을 선택한 뒤 저장하세요.

### 만료되기 전에 지원팀 액세스를 취소할 수 있나요?
네. **액세스 취소**를 클릭하고 확정하세요. 취소하면 접근이 바로 차단돼요.

### 지원 세션이 진행 중일 때 액세스를 취소하면 어떻게 되나요?
진행 중인 지원 세션이 즉시 종료될 수 있어요. 지원팀 액세스를 다시 켜기 전에는 세션을 재개할 수 없어요.

### 지원팀 액세스를 항상 켜 두어도 되나요?
아니요. 임시 접근이 필요할 때만 켜고, 지원이 끝나면 만료되도록 두거나 취소하세요.

### 지원팀 액세스와 사용자 권한은 같은 건가요?
아니요. 지원팀 액세스는 하이퍼클래스 고객지원을 위한 임시 접근을 관리해요. 에이전시 팀 사용자, 역할, 권한은 따로 관리해요.

### 취소한 지원팀 액세스를 다시 켤 수 있나요?
네. 추가로 문제 해결 접근이 필요하면 지원팀 액세스를 다시 켤 수 있어요.
