# 프리미엄 지원 안내

**프리미엄 지원**은 스탠더드 지원과 우선 지원보다 한 단계 높은, 담당자가 직접 챙기는 지원 서비스예요. 이 문서에서 포함된 내용, 가입 조건, 가입 방법을 확인할 수 있어요.

## 프리미엄 지원이란?

프리미엄 지원은 스탠더드 지원과 우선 지원을 기반으로, 고객과 더 긴밀하게 협력할 수 있는 맞춤 기능을 더한 서비스예요. 전담 기술 계정 매니저, 더 빠른 문제 해결, 실시간 소통 채널을 제공해서 문제를 끊김 없이 처리하고 비즈니스를 안정적으로 이어 갈 수 있게 도와줘요.

## 프리미엄 지원의 주요 장점

프리미엄 지원은 단순한 업그레이드가 아니라, 빠른 문제 해결과 선제적이고 맞춤형인 지원을 함께 제공하는 기술 중심의 고객 지원 방식이에요. 더 자세한 기술 내용이나 운영 지침은 하이퍼클래스 고객지원에 문의하세요.

고객 경험 향상:

- 채팅과 Zoom 대기 시간이 스탠더드 지원의 6분에서 1분으로, 티켓 첫 응답 시간이 10시간에서 3시간으로 줄어요.
- 고객 만족도(CSAT) 점수가 높아지는 등 전반적인 만족도가 좋아져요.

간결한 구성:

- 검증된 우선 지원 기능을 바탕으로 핵심 맞춤 기능을 더했어요. 지원 구조는 복잡해지지 않아요.

차별화된 가치:

- 전담 기술 계정 매니저(TAM)와 실시간 협업용 비공개 Slack 채널 같은 프리미엄 전용 기능을 제공해요.

성장 기회:

- 선제적인 안내와 정기 리뷰로 문제를 빠르고 전략적으로 해결해서, 비즈니스를 효과적으로 키우는 데 도움을 줘요.

프리미엄 지원 사이드바(앱 안에서 쓰는 방법):

프리미엄 지원에는 하이퍼클래스 대시보드 안에서 바로 쓸 수 있는 새 사이드바가 포함돼요. 워크스페이스를 벗어나지 않고 전문가의 도움을 받을 수 있어요. 프리미엄 지원 사이드바는 담당자 지원과 주요 자료를 한곳에 모아 둔 공간이에요.

- **Slack Support**(Slack 지원)를 누르면 프리미엄 지원팀에 직접 메시지를 보낼 수 있어요.
- **Book a Call**(통화 예약)을 누르면 한 번의 클릭으로 실시간 문제 해결 통화를 예약해요.
- **Start Chat**(채팅 시작)을 누르면 실시간 지원 대화를 시작해요.

## 프리미엄 지원으로 업그레이드해야 하는 이유

프리미엄 지원은 빠른 문제 해결뿐 아니라, 선제적이고 파트너십 중심의 지원이 필요한 비즈니스를 위해 만들어졌어요. 더 빠른 응답 시간과 전담 기술 인력을 결합해 다음을 제공해요.

- 우선 문제 해결: 개선된 문의 배정과 직접 에스컬레이션 경로로 서비스 중단 시간을 줄여요.
- 맞춤 지원: 전담 TAM이 그동안의 문제 이력을 자세히 관리하면서 맞춤 안내를 드려요.
- 실시간 협업: 전용 Slack 채널에서 바로 소통하고 진행 상황을 공유해서, 팀이 같은 정보를 보며 움직일 수 있어요.

| 지원 서비스 | 스탠더드 지원 | 프리미엄 지원 |
| --- | --- | --- |
| 24/7 채팅, Zoom, 티켓, 전화 지원 | ✓ | ✓ |
| 지원 포털 및 셀프서비스 도움말 문서 | ✓ | ✓ |
| 프리미엄 지원팀 문의 배정 | ✗ | ✓ |
| 더 빠른 채팅 및 Zoom 응답 | ✗ | ✓ |
| 더 빠른 티켓 응답 | ✗ | ✓ |
| 티켓 처음부터 끝까지 해결 | ✗ | ✓ |
| 기술 계정 매니저 | ✗ | ✓ |
| 프리미엄 지원 킥오프 콜 | ✗ | ✓ |
| 분기별 비즈니스 리뷰 | ✗ | ✓ |
| 전용 Slack 채널 | ✗ | ✓ |
| TAM 직접 예약 | ✗ | ✓ |

## 프리미엄 지원 사용 자격, 요금, 결제

가입하기 전에 사용 자격, 요금, 결제 내용을 확인하세요.

| 항목 | 프리미엄 지원 |
| --- | --- |
| **사용 자격** | 하이퍼클래스를 사용한 지 90일이 지나면 가입할 수 있어요 |
| **월간 플랜** | 월 $500 |
| **연간 플랜** | 연 $5,000 (월간 결제보다 $1,000 절약) |
| **청구/결제** | 프리미엄 지원은 선택형 유료 애드온이며, 하이퍼클래스 기본 구독과 별도로 결제돼요 |
| **취소** | **청구/결제** 설정에서 언제든지 프리미엄 지원을 취소할 수 있어요. 취소해도 현재 결제 주기가 끝날 때까지는 프리미엄 지원 혜택을 계속 쓸 수 있어요. |

### 구독하려면

{% hint style="info" %}
에이전시 관리자만 구독할 수 있어요.
{% endhint %}

에이전시 계정에서 **설정 > 청구/결제**로 이동해요. **애드온** 아래에서 **프리미엄 지원**을 찾아 **지금 구독**을 선택하세요.

![설정 > 청구/결제의 애드온에서 프리미엄 지원 구독](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078234135/original/nfvOSr05nezx4B40yfBlAEIlt9rLa-cWKA.png?1786536054)

구독을 마치기 전에 결제 플랜과 결제 수단을 선택하고, 프리미엄 지원 이용약관에 동의해야 해요.

구독, 결제, 설정, 취소 방법을 단계별로 자세히 알고 싶다면 [프리미엄 고객 지원으로 업그레이드하기](how-to-upgrade-to-premium-customer-support.md)를 확인하세요.

## 구독 시 필요한 동의

프리미엄 지원을 구독할 때는 결제 과정에서 프리미엄 지원 이용약관에 동의해야 구매를 마칠 수 있어요.

## 더 빠른 문제 해결

- 우선 배정과 에스컬레이션: 프리미엄 지원은 개발팀으로 바로 연결되는 에스컬레이션 경로를 갖추고 있어서 문제를 빠르고 효율적으로 처리해요.
- 처음부터 끝까지 책임지는 문제 처리: 티켓이 접수된 순간부터 최종 해결까지 전담팀이 맡아요. 티켓 인계 과정의 지연을 줄이고 책임 소재도 분명해요.
- 응답 지표 개선: 채팅과 Zoom 대기 시간이 1분, 티켓 응답이 3시간으로 줄어서 업무 중단을 최소화해요.

---

## 기술 계정 매니저(TAM)

- 전담 기술 안내: TAM이 단일 연락 창구가 되어, 비즈니스의 어려움과 이전 문제 이력을 파악하고 맞춤 해결책을 제안해요.
- 맞춤형 관리: TAM은 지금 생긴 문제에 대응할 뿐 아니라 반복되는 문제도 추적해서, 장기 목표에 맞는 지원을 제공해요.
- 전략 세션 직접 예약: TAM에게 직접 연락해 집중 전략 세션을 잡을 수 있어요. 지원이 선제적이고 맞춤형으로 이뤄져요.

---

## 전용 Slack 채널

- 비공개 실시간 작업 공간: 프리미엄 지원으로 바로 연결되는 전용 Slack 채널을 이용해요. 티켓 접수, 문의, 실시간 업데이트가 이 채널에 모여요.
- 팀 협업 강화: 팀원을 Slack 채널에 초대하면 모두가 같은 정보를 보며 지원을 받을 수 있어요. 중요한 장애 상황에도 관련자들이 계속 상황을 알 수 있어요.
- 효율적인 티켓 관리: Slack에서 바로 티켓을 접수하면 즉시 TAM에게 전달돼 빠르게 처리돼요.

---

## 선제적·고급 지원

- 분기별 비즈니스 리뷰(QBR): 정기 QBR에서 지난 지원 문제를 깊이 있게 돌아보고, 추세를 분석하고, 앞으로 성과를 높일 전략적 제안을 받아요.
- 선제적 문제 해결: 문제가 생긴 뒤 수습하는 데 그치지 않고, 잠재적인 문제를 미리 찾아 비즈니스 목표에 맞는 해결책을 제안하도록 설계되었어요.

## 프리미엄 지원 설정하기

프리미엄 지원 구독은 간단해요. 급하거나 복잡한 지원이 필요할 때 언제든 대비할 수 있어요.

1. 에이전시 대시보드에서 **애드온**을 클릭하세요.
2. **애드온** 아래에서 **프리미엄 지원** 섹션을 찾으세요.
3. **지금 구독** 버튼을 클릭하세요.

프리미엄 지원 페이지에서 바로 구독할 수도 있어요.

## 자주 묻는 질문

### 스탠더드 지원과 프리미엄 지원은 어떻게 다른가요?
스탠더드 지원은 24/7 지원을 일반 대기 시간으로 제공해요. 프리미엄 지원은 더 빠른 응답 시간, 전담 기술 계정 매니저, 실시간 소통용 비공개 Slack 채널, 선제적인 분기별 비즈니스 리뷰를 제공해요.

### 기술 계정 매니저(TAM)에게는 어떻게 연락하나요?
프리미엄 지원 고객에게는 전담 TAM이 배정돼요. 안내받은 소통 채널로 TAM에게 직접 연락할 수 있고, TAM은 지원 이력을 바탕으로 맞춤 안내를 드려요.

### 팀 전체를 Slack 채널에 초대할 수 있나요?
네, 전용 Slack 채널에 팀원을 초대할 수 있어요. 조직 전체가 원활하게 협업하고 같은 상황을 볼 수 있어요.

### Slack에서 티켓은 어떻게 접수하나요?
전용 Slack 채널에서 바로 지원 티켓을 접수할 수 있어요. 접수된 티켓은 TAM에게 전달돼 즉시 처리돼요.

### 분기별 비즈니스 리뷰에서는 어떤 도움을 받을 수 있나요?
QBR에서는 지난 문제를 체계적으로 검토하고 추세를 분석해요. 지원 효율을 높이고 비즈니스 목표에 맞출 수 있도록 선제적인 제안도 받을 수 있어요.
