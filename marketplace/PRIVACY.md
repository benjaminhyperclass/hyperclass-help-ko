## English

**What the app does.** Korean Language Pack replaces the text of the HighLevel sub-account interface with Korean translations inside the user's browser. It does not change how the software works.

**Data we collect.** None. The app does not read, store or transmit contacts, conversations, payments, user profiles, location or company data, credentials, or any other personal data. It contains no analytics, tracking pixels, cookies of its own, or advertising code.

**Network requests.** To translate the interface, the browser downloads static translation files (JSON) from public content-delivery networks (cdn.jsdelivr.net and raw.githubusercontent.com). These requests contain no personal data; like any web request, the CDN receives the requesting IP address and browser user-agent under its own privacy policy.

**Local storage.** The app caches the translation files and a small version pointer in the browser (Cache Storage and localStorage) so later page loads are faster. This data stays on the device and can be cleared by clearing site data. Users can switch the app off per browser by adding `?hcko=off` to the address.

**OAuth / API access.** The app does not request access to HighLevel APIs and does not receive OAuth tokens.

**Children.** The app is a business tool and is not directed at children.

**Changes.** We will post any change to this policy on this page with a new date.

## 한국어

**앱이 하는 일.** 한국어 UI 팩은 사용자의 브라우저 안에서 HighLevel 서브계정 화면 문구를 한국어 번역으로 바꿉니다. 소프트웨어의 기능은 바꾸지 않습니다.

**수집하는 정보.** 없습니다. 연락처·대화·결제·사용자 프로필·서브 계정·회사 정보·로그인 정보 등 어떤 개인정보도 읽거나 저장하거나 전송하지 않습니다. 분석 도구, 추적 픽셀, 자체 쿠키, 광고 코드가 없습니다.

**네트워크 요청.** 화면을 번역하기 위해 브라우저가 공개 CDN(cdn.jsdelivr.net, raw.githubusercontent.com)에서 정적 번역 파일(JSON)을 내려받습니다. 이 요청에는 개인정보가 들어가지 않으며, 일반적인 웹 요청과 마찬가지로 CDN 은 자체 방침에 따라 요청 IP 주소와 브라우저 정보를 받습니다.

**기기 저장.** 다음 화면을 빠르게 열기 위해 번역 파일과 작은 버전 정보를 브라우저(Cache Storage·localStorage)에 저장합니다. 이 데이터는 기기 안에만 있고 사이트 데이터 삭제로 지울 수 있습니다. 주소에 `?hcko=off` 를 붙이면 그 브라우저에서 앱이 꺼집니다.

**OAuth·API 접근.** 앱은 HighLevel API 접근 권한을 요청하지 않으며 OAuth 토큰을 받지 않습니다.
